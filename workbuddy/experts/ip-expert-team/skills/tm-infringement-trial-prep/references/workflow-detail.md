## Phase 1：输入验证 + 上游输出检查

### 1.1 必填字段检查（含降级分级）

| 降级等级 | 缺失字段 | 触发行为 |
|---------|---------|---------|
| L3 重度 | `plaintiff_mark` 或 `infringement_summary` | → SOFT_DEGRADED：仅输出庭审提纲骨架+法定要素清单 |
| L2 中度 | 上游输出全部缺失 | → 7环节框架+全量占位标注 |
| L1 轻度 | 部分上游输出缺失 | → 已就绪部分消费+缺失部分占位 |
| L0 完整 | 所有必填参数+上游输出齐全 | → 完整庭审提纲+撰写指引 |

### 1.2 上游输出检查（占位标注规范）

| 上游代号 | 上游技能 | 检查项 | 就绪处理 | 缺失处理 |
|---------|---------|--------|---------|---------|
| D2 | tm-infringement-cross-exam | 质证结论 | 消费→填入三、质证要点 | 占位：`[待消费D2(tm-infringement-cross-exam)输出]` |
| B1 | tm-infringement-comparison | 比对结论 | 消费→填入四(一)、侵权构成论证 | 占位：`[待消费B1(tm-infringement-comparison)输出]` |
| A6 | tm-damage-calc | 赔偿计算 | 消费→填入四(二)、赔偿计算论证 | 占位：`[待消费A6(tm-damage-calc)输出]` |
| C3 | tm-infringement-strategy | 诉讼策略 | 消费→填入四(三)、对方抗辩回应 | 占位：`[待消费C3(tm-infringement-strategy)输出]` |

### 1.3 证据编号

- 原告证据：`PE-01`, `PE-02`, ...（Plaintiff Evidence）
- 被告证据：沿用D2的 `DE-01`, `DE-02`, ...

## Phase 2：庭审7环节内容生成

### 2.1 开庭陈述生成

**设计原则**：
- 3分钟以内，简明扼要
- 不读稿——要点式提纲，律师灵活发挥
- 三段式：案件事实概述→核心主张→诉讼请求

**生成步骤**：

| 步骤 | 任务 | 输入 |
|------|------|------|
| 2.1.1 | 概述案件事实 | plaintiff_mark + infringement_summary |
| 2.1.2 | 提炼核心主张 | 侵权构成要点 |
| 2.1.3 | 重述诉讼请求 | 停止侵权+赔偿损失+合理开支 |

### 2.2 举证计划生成

**举证顺序**：

| 顺序 | 证据类型 | 证明目的 |
|------|---------|---------|
| 1 | 权属证据 | 原告享有注册商标专用权 |
| 2 | 侵权行为证据 | 被告实施了侵权行为 |
| 3 | 近似比对证据 | 被告标识与原告商标近似 |
| 4 | 损害赔偿证据 | 原告损失/被告获利/合理开支 |
| 5 | 知名度证据 | 原告商标知名度+混淆可能性 |
| 6 | 其他证据 | 其他待证事实 |

### 2.3 质证要点生成

**设计原则**：
- 引用D2输出的核心质证结论
- 不重复D2的全部内容——提取要点
- 按质证策略优先级排列

**生成步骤**：

| 步骤 | 任务 | 上游依赖 |
|------|------|---------|
| 2.3.1 | 检查D2输出是否就绪 | D2(tm-infringement-cross-exam) |
| 2.3.2 | 从D2输出提取每项被告证据的核心质证要点 | D2 |
| 2.3.3 | 按质证策略建议排序 | D2 |
| 2.3.4 | 生成质证要点速查表 | D2 |

> D2未就绪时：三、质证要点环节整体标注 `[待消费D2(tm-infringement-cross-exam)输出]`

### 2.4 辩论框架生成

**三段式辩论框架**（含上游消费标注）：

```
（一）侵权构成论证
├── 商标近似 → [已消费B1(tm-infringement-comparison)输出] / [待消费B1(tm-infringement-comparison)输出]
├── 商品类似 → 同类/类似商品论证
└── 混淆可能性 → 实际混淆/可能性论证

（二）赔偿计算论证
├── 计算方法 → [已消费A6(tm-damage-calc)输出] / [待消费A6(tm-damage-calc)输出]
├── 数据来源 → 证据支撑
└── 合理开支 → 律师费+公证费+调查费

（三）对方抗辩回应
├── [抗辩1]回应 → [已消费C3(tm-infringement-strategy)输出] / [待消费C3(tm-infringement-strategy)输出]
├── [抗辩2]回应 → [已消费C3输出]
└── 举证责任 → 被告举证不能
```

### 2.5 最后陈述生成

**设计原则**：
- 3分钟以内
- 总结核心论点（3点以内）
- 重述诉讼请求
- 不引入新论点

## Phase 3：法官提问预判（5类15题）

### 3.1 商标案件法官提问5类分类

| 类别 | 问题数 | 来源 |
|------|--------|------|
| **商标近似判断** | 3-4个 | 商标民事纠纷解释第9-10条 |
| **混淆可能性证据** | 3-4个 | 实务经验 |
| **赔偿计算合理性** | 2-3个 | 商标法第63条 |
| **程序问题** | 1-2个 | 民诉法 |
| **特殊情形** | 2-3个 | 驰名商标/平行进口/正当使用 |

### 3.2 预判问题生成

从以下维度生成15个问题：
1. 根据案件争议焦点生成核心问题
2. 根据被告抗辩类型生成针对性问题
3. 根据原告证据薄弱环节生成追问
4. 根据商标法特有规则生成专业问题
5. 根据特殊情形（驰名/正当使用等）生成问题

### 3.3 回答要点设计

每个预判问题的回答要点包含：
- 一句话核心回答
- 支撑论据（法条/证据/逻辑）
- 上游技能输出引用（如有）
- 回答策略（主动说明/被动回应/反问引导）

## Phase 4：时间分配 + 输出质检

### 4.1 7环节时间分配模板

```
总时长 = 用户指定（默认120分钟）

开庭陈述  = 3-5分钟（2-4%）
举证      = 总时长 × 15-20%
质证      = 总时长 × 20-25%
辩论      = 总时长 × 25-35%
法官提问  = 10-15分钟
最后陈述  = 3-5分钟
```

### 4.2 输出质检（20+项）

#### 4.2.1 WR 红线检查（11项）

| # | 检查项 | 合格标准 |
|---|--------|---------|
| WR-01 | 无绝对化表述 | 0处"必然""一定" |
| WR-02 | 结论留边界 | 建议性表述 |
| WR-03 | 事实与意见分离 | 事实段无主观评价 |
| WR-04 | 不替代律师判断 | "建议""供参考" |
| WR-05 | 法条引用标注来源 | 三标注体系全覆盖 |
| WR-06 | 时间分配标注依据 | 每环节建议用时 |
| WR-07 | 不编造法条或判例 | 逐条核对法条编号 |
| WR-08 | 不提供胜诉保证 | 无"庭审必胜" |
| WR-09 | 保守陈述优于激进 | "构成近似"而非"完全一样" |
| WR-10 | 避免不利自认 | 无不利自认表述 |
| WR-11 | 文书风格统一无混搭 | 7环节要点式风格 |

#### 4.2.2 L1/L2/L3 禁止检查（18项）

> 详见 `rules/risk-framework.md` §一

#### 4.2.3 法条标注检查（3项）

| # | 检查项 | 合格标准 |
|---|--------|---------|
| FT-01 | 三标注体系全覆盖 | 每条法条标注[✅已核实]/[📋需核实]/[⚠️存疑] |
| FT-02 | 引用格式规范 | 首次全称+条号汉字 |
| FT-03 | 司法解释格式 | 首次全称，后续可简称 |

#### 4.2.4 占位标注检查（4项）

| # | 检查项 | 合格标准 |
|---|--------|---------|
| PH-01 | 上游输出缺失处有明确占位 | 每个缺失的上游输出均有占位标注 |
| PH-02 | 占位标注格式统一 | `[待消费{上游代号}(tm-xxx)输出]` |
| PH-03 | 上游输出已消费处有明确标注 | `[已消费{上游代号}(tm-xxx)输出]` |
| PH-04 | 全部上游缺失→S2降级 | 7环节框架+全量占位 |
