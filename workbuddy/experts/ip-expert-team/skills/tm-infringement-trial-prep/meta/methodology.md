## 一、三层理论框架

### 认知层（Know-What）

**核心问题**：商标侵权庭审的法律要件是什么？上游技能输出如何消费？

| 要件 | 内容 |
|------|------|
| 庭审法律性质 | 民事诉讼一审/二审庭审，法官主导，双方对抗 |
| 7环节结构 | 开庭陈述→举证计划→质证要点→法庭辩论→法官提问预判→最后陈述→时间分配表 |
| 上游消费关系 | D2(质证)→三环节 / B1(比对)→四(一) / A6(赔偿)→四(二) / C3(策略)→四(三) |
| 占位标注 | `[待消费{上游代号}(tm-xxx)输出]` |
| 法官提问5类 | 近似判断/混淆可能性/赔偿计算/程序问题/特殊情形 |

**常见认知错误**：
- ❌ 把庭审提纲等同于逐字稿——庭审提纲是"要点清单"，律师需灵活应对
- ❌ 忽略上游输出的消费关系——D2/B1/A6/C3的输出必须消费或占位
- ❌ 法官提问只关注己方——法官关注的是"双方争议的核心是什么"
- ❌ 时间分配不重要——庭审超时或遗漏重点是常见失误

### 策略层（Know-Why）

**核心问题**：如何设计庭审策略？

| 环节 | 策略选择 | 依据 |
|------|---------|------|
| 开庭陈述 | 3分钟简明式 | 法官已阅卷，不需要复述——需要"说重点" |
| 举证计划 | 按逻辑顺序（权属→侵权→赔偿） | 法官按因果关系理解证据 |
| 质证要点 | 引用D2输出+策略排序 | 质证已有D2专业分析，庭审只取核心 |
| 辩论框架 | 三段式（侵权+赔偿+抗辩回应） | 对应法官的三个核心关注 |
| 法官提问 | 5类15题预判 | 商标侵权法官提问有高度规律性 |
| 最后陈述 | 3点核心论点+诉求 | 不引入新论点 |

**策略选择的核心原则**：
1. **框架先行**：上游输出未就绪时，7环节框架先行+占位标注，不因等待上游而延误准备
2. **举证-质证-辩论闭环**：举证决定质证方向，质证发现薄弱点→辩论重点攻击
3. **法官视角**：法官想听什么比律师想说什么更重要
4. **时间分配**：防止庭审超时或遗漏重点

### 表达层（Know-How）

**核心问题**：按所选策略如何生成庭审提纲？

**选定风格：7环节要点式风格**（基于3篇以上商标侵权庭审实务经验交叉验证）

| 风格特征 | 说明 |
|---------|------|
| 7环节结构 | 开庭陈述→举证→质证→辩论→提问预判→最后陈述→时间分配 |
| 要点式 | 每个环节要点清单，非逐字稿 |
| 上游消费标注 | 每个消费/占位处标注上游代号+技能名 |
| 时间分配 | 每环节标注建议用时 |
| 禁止 | 逐字稿式、无时间分配、无占位标注 |

**三层硬约束**：不允许跳过任一层——必须先理解庭审要件（认知层），再选择庭审策略（策略层），最后生成提纲（表达层）。

## 二、六操作管线

### 1. 转化

| 客户口语 | 转化为结构化要素 |
|---------|----------------|
| "帮我准备庭审" | `plaintiff_mark` 待识别，需追问商标信息 |
| "被告说合法来源" | `defendant_defense` 含合法来源，需引用D2质证结论 |
| "庭审2小时" | `trial_duration_minutes = 120`，影响时间分配 |

### 2. 细化

| 环节 | 细化为要点 |
|------|-----------|
| 开庭陈述 | 事实概述+核心主张+诉讼请求 |
| 举证 | 权属→侵权→比对→赔偿→知名度→其他 |
| 质证 | 引用D2→核心方向→逐项要点 |
| 辩论 | 侵权构成→赔偿计算→抗辩回应 |
| 提问预判 | 5类15题+回答要点+上游引用 |
| 最后陈述 | 3点核心+诉求 |

### 3. 补充

| 要点 | 补充法律依据 |
|------|-------------|
| 侵权构成 | 商标法第57条[✅已核实]+商标民事纠纷解释第9-10条[✅已核实] |
| 赔偿计算 | 商标法第63条[✅已核实]+解释第13-17条[✅已核实] |
| 合法来源回应 | 商标法第64条[✅已核实] |
| 在先使用回应 | 商标法第59条第3款[✅已核实] |

### 4. 拆分

| 复合环节 | 拆分为独立段 |
|---------|-------------|
| 法庭辩论 | (一)侵权构成+(二)赔偿计算+(三)抗辩回应 |
| 法官提问 | 5类分类：近似/混淆/赔偿/程序/特殊 |

### 5. 去重

| 常见重复模式 | 去重处理 |
|-------------|---------|
| 辩论(一)重复B1比对内容 | 引用B1输出，不重复分析 |
| 质证要点重复D2内容 | 提取核心要点，不复制全部分析 |
| 开庭陈述重复辩论内容 | 开庭陈述只概述，论证留给辩论 |

### 6. 统一

| 统一项 | 标准表述 | 禁止表述 |
|--------|---------|---------|
| 上游消费 | `[已消费D2(tm-infringement-cross-exam)输出]` | "已使用质证结果" |
| 上游占位 | `[待消费B1(tm-infringement-comparison)输出]` | "待补充比对" |

## 三、隐性知识嵌入

### 3.1 庭审提纲不是逐字稿

| 要点 | 说明 |
|------|------|
| 要点清单 | 庭审提纲是"应对策略"而非"朗读稿" |
| 法官随时追问 | 逐字稿在追问时适应性差——要么翻找答案，要么脱稿即兴 |
| 灵活应对 | 要点式提纲让律师知道"每个环节要说什么"，灵活发挥"怎么说" |
| 开庭陈述例外 | 提供简明陈述稿（3分钟），因为这是唯一可以完全准备的部分 |

### 3.2 框架先行+占位标注

| 要点 | 说明 |
|------|------|
| 时间压力 | 开庭日期确定后，各项准备工作可能并行推进 |
| 不等待 | 上游技能（D2/B1/A6/C3）的输出可能尚未完成 |
| 占位标注 | 不因等待上游输出而延误庭审提纲的框架准备 |
| 明确占位 | 让律师清楚知道"哪些部分待补充"，标注格式统一 |

### 3.3 法官提问5类15题的来源

| 要点 | 说明 |
|------|------|
| 规律性 | 商标侵权庭审的法官高频关注点有高度规律性 |
| 5类分类 | 近似判断/混淆可能性/赔偿计算/程序问题/特殊情形 |
| 15题 | 每类2-4题，总计10-15个预判问题 |
| 上游引用 | 回答要点可引用B1/A6/C3/D2的输出 |
