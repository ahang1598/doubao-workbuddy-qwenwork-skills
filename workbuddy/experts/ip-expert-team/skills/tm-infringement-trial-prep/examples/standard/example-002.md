# 标准示例002 — 上游输出部分未就绪

> 技能：tm-infringement-trial-prep | 版本：1.0.0
> 场景：仅有质证输出，其他上游技能输出未就绪

---

## 输入

```json
{
  "plaintiff_mark": {
    "name": "锦绣",
    "category": "第30类（茶叶）",
    "reg_no": "2345678"
  },
  "infringement_summary": "被告在茶叶产品上使用'锦秀'标识，与原告'锦绣'商标近似",
  "cross_exam_result": "被告在先使用证据仅证明设计意图未证明实际使用；三年不使用抗辩不能仅凭网络搜索",
  "comparison_result": null,
  "damage_calc_result": null,
  "defendant_defense": ["在先使用", "三年不使用"],
  "court_name": "福州市鼓楼区人民法院"
}
```

## 输出（节选关键片段）

```markdown
## 四、法庭辩论框架（建议35分钟）

### （一）侵权构成论证

[待消费tm-infringement-comparison输出]

待补充内容：
1. 商标近似论证（音/形/义三维度）
2. 商品类似论证
3. 混淆可能性论证

> 建议先完成商标比对分析（tm-infringement-comparison），再补充本部分。

### （二）赔偿计算论证

[待消费tm-damage-calc输出]

待补充内容：
1. 赔偿计算方法
2. 计算依据和数据来源
3. 合理开支

> 建议先完成赔偿计算（tm-damage-calc），再补充本部分。

### （三）对方抗辩回应

**在先使用抗辩回应**（已消费tm-infringement-cross-exam输出）：
- 被告设计稿仅能证明设计意图而非实际使用
- 5份销售发票中仅部分备注"锦绣茶叶"，商标性使用证据不充分
- 未达到"有一定影响"的程度——仅有设计+少量销售，未提供广告/宣传/市场占有率证据

**三年不使用抗辩回应**（已消费tm-infringement-cross-exam输出）：
- 百度搜索不能证明原告未使用——仅反映搜索时网络信息状态
- 三年起算时间未明确
- 未审查原告是否有正当理由和线下使用情况
```

---

## 教训

- 部分上游输出缺失时，框架先行完成，已有部分消费，缺失部分明确占位
- 占位标注必须指明待补充的具体内容（而非仅写"[待补充]"）
- 法庭辩论框架的"(三)对方抗辩回应"可以基于D2质证结论先行填充
