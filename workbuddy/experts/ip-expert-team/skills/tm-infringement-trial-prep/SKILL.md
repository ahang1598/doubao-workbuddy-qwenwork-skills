# 商标侵权庭审提纲

> **核心定位**：为商标侵权诉讼原告律师生成完整庭审提纲——从开庭陈述到最后的陈述，覆盖庭审全流程7个环节，内置法官提问预判（5类15题：商标近似判断/混淆可能性证据/赔偿计算合理性/程序问题/特殊情形），消费上游技能输出实现证据-质证-辩论一体化。
>
> **蓝本依据**：商标法第57条（侵权行为类型）[✅已核实] + 第63条（赔偿计算）[✅已核实] + 第64条（合法来源免赔）[✅已核实] + 商标民事纠纷解释第9-10条（近似认定标准）[✅已核实]
>
> **隐性知识**：庭审提纲的核心**不是写稿**——是设计"应对策略"。法官关注的是"你方核心论点是什么"而非文书复述。提纲设计为要点式+时间分配，让律师在庭审中能灵活应对而非照本宣科。7环节框架先行，上游输出未就绪时使用占位标注 `[待消费{上游代号}(tm-xxx)输出]`。
>
> 本技能遵循 compiler/ssot.md §17（SSOT）

## 1. 法律合规与风险声明

<!-- Copyright © 深圳市法大大网络科技有限公司 版权所有 | Author: 法大大法律AI产品线 -->

1. **管辖范围**：中国大陆（不含港澳台）。涉外商标案件适用特殊规则时标注"[需核实涉外因素]"
2. **输出性质**：所有输出为**庭审准备草稿**，仅供律师审核确认，不直接用于庭审
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **庭审策略**：庭审提纲为策略参考，律师应结合庭审实际灵活调整——法官可能临时追问或调整审理顺序
5. **知识截止**：法律依据基于截至2026-06-01的法律法规
6. **文书风格声明**：WR-11 选定**7环节要点式风格**（基于3篇以上商标侵权庭审实务经验交叉验证），贯彻到底，禁止混搭逐字稿式或学术论证式
7. **免责声明**：本技能产物为AI辅助工具生成，不构成法律意见，使用者应结合具体案情独立判断

## 5. 适用边界

**适用范围**：
- 商标侵权诉讼庭审全流程提纲的生成（7环节+法官提问预判）
- 律师参考使用，须结合庭审实际灵活调整
- 开庭前的庭审准备阶段

**不适用范围**：
- 商标行政程序口审准备（→ `tm-oral-hearing-prep`）
- 商标侵权质证提纲（→ `tm-infringement-cross-exam`）
- 商标比对分析（→ `tm-infringement-comparison`）
- 刑事庭审/仲裁/调解程序

**硬拒绝条件**：
1. 缺少核心输入（原告商标信息+侵权行为概述） → 拒绝，提示补充案件基础信息
2. 诱导性要求保证"庭审必胜" → 拒绝，输出风险声明
3. 要求直接替代律师出庭 → 拒绝，提示须律师结合庭审实际灵活调整
4. 非商标侵权庭审准备（行政口审/刑事庭审/仲裁） → 拒绝，路由到对应技能

## 6. 常见问题

**Q1**：庭审提纲和质证提纲有什么区别？

**答**：质证提纲（tm-infringement-cross-exam，D2）仅针对被告证据的质证意见。庭审提纲（本技能）是完整的庭审准备——包含7个环节，其中质证要点环节引用D2输出的核心结论（`[已消费D2(tm-infringement-cross-exam)输出]`）。

**Q2**：上游技能输出都没准备好怎么办？

**答**：本技能支持"框架先行"——上游输出未就绪时，在对应位置使用占位标注（如`[待消费B1(tm-infringement-comparison)输出]`），7环节框架先行完成。后续上游输出就绪后，重新调用本技能或手动填充占位部分。

**Q3**：法官提问预判5类15题怎么来的？

**答**：商标侵权庭审的法官高频关注点有规律可循：(1)近似判断3-4题（音/形/义哪些维度近似）；(2)混淆可能性3-4题（实际混淆案例/消费者调查）；(3)赔偿计算2-3题（计算方法/数据来源）；(4)程序问题1-2题（停止侵权通知/侵权期间确定）；(5)特殊情形2-3题（驰名商标/平行进口/正当使用）。

**Q4**：时间分配怎么定？

**答**：一般商标侵权一审庭审时间约2-3小时。7环节建议分配：开庭陈述3-5分钟（2-4%）、举证15-20分钟（15-20%）、质证20-30分钟（20-25%）、辩论30-40分钟（25-35%）、法官提问10-15分钟、最后陈述3-5分钟。具体分配应根据案件复杂度和证据数量调整。
