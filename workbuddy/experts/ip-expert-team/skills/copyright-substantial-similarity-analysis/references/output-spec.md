# 输出规范 — 著作权侵权"实质性相似+接触可能性"分析

> 版本：v3.0.0 | 输出格式：HTML（C-Professional + Richee Design Token）
> HTML 排版细则见 [html-format-spec.md](./html-format-spec.md)

---

## 一、输出格式

**始终输出 HTML 格式**。LLM 按 `templates/html-template.html` 模板填充 CONTENT_SLOT 占位符，生成自包含 HTML 文件，浏览器打开即渲染，支持打印/PDF 导出。

---

## 二、HTML 报告标准结构

```
著作权侵权实质性相似分析报告

├── 页面标题区（PAGE_TITLE + SUBTITLE + PAGE_META）

│   ├── 结构层比对（结构编排/元素组织）
│   ├── 表达层比对（具体表达细节逐点+三性分类+错误复制）
│   └── c12 风险矩阵（相似度×独创性强度×相似性质）

│   └── c09 时间轴

│   ├── 三阶交互判定矩阵（情形A/A'/B/C）

│   └── c06 结论卡

├── 降级说明（如适用）（DOWNGRADE_NOTE）
└── 免责声明（固定内容）
```

## 三、输出块详解

### 3.1 案件概况（CASE_OVERVIEW）

使用 c01 基础表格组件，包含：

| 字段 | 必填 | 说明 |
|------|------|------|
| 案件名称 | 是 | 案件标识 |
| 原告作品 | 是 | 作品名称+类型+发表时间 |
| 被控素材 | 是 | 素材名称+类型+发布时间 |
| 涉诉权利 | 是 | 复制权/改编权/保护作品完整权等 |
| 分析日期 | 是 | YYYY-MM-DD |
| 分析视角 | 否 | 原告/被告/客观 |

### 3.2 独创性剥离对比清单（MODULE_1）

使用 c04 证据目录表组件，三层标注：

| 层级 | 标注 | 说明 | 比对处理 |
|------|------|------|----------|
| 第一层 | 🟢 公共领域 | 历史事实/通用表达/公共符号/常规设计 | 排除，不纳入比对 |
| 第二层 | 🟡 Scenes à faire | 题材必然产生的惯用表达 | 排除，记录排除理由 |
| 第三层 | 🔴 独创性表达 | 原告独创的表达元素 | 纳入实质性相似比对 |

每个剥离元素须记录：元素描述 + 剥离层级 + 剥离理由。

### 3.3 逐层比对结果（MODULE_2）

#### 3.3.1 整体观感锚定与反向验证（IMPRESSION_ANCHOR）【新增】

| 字段 | 说明 |
|------|------|
| 初始锚定（Phase 1.5） | 整体直觉分（高度/中度/弱/不相似）+ 直觉依据 |
| 反向验证（Phase 4.5） | 剥离后验证结果 + 调整方向（维持/上调/下调）+ 调整理由 |
| 修正后结论 | 最终整体观感结论 |

#### 3.3.2 三层逐点比对 + 三性分类

三层逐点比对，使用 c12 风险矩阵汇总（相似度×独创性强度×相似性质）：

**整体层**：整体观感、主题氛围的相似性评估。

**结构层**：结构编排、元素组织的相似性评估。

**表达层**：具体表达细节的逐点比对。

每个相似点须标注：

| 字段 | 说明 |
|------|------|
| 相似点描述 | 具体相似的表达元素 |
| 所在层次 | 整体层/结构层/表达层 |
| 独创性强度 | 强/中/弱 |
| 相似度评估 | 高度相似/中度相似/弱相似/不相似 |
| **相似性质** | 共通表达/共同选择/共同错误 |
| **证明力** | ⭐⭐（共通表达）/⭐⭐⭐（共同选择）/⭐⭐⭐⭐⭐（共同错误） |
| 比对依据 | 具体比对分析 |

#### 3.3.3 错误复制识别结果【新增】

| 字段 | 说明 |
|------|------|
| 错误类型 | 文字错误/事实错误/逻辑漏洞/非常规标注 |
| 错误位置 | 原被告作品中相同位置的瑕疵描述 |
| 证明力 | ⭐⭐⭐⭐⭐（极强） |
| 法律意义 | 巧合无法解释的一致性，反驳独立创作抗辩的核心武器 |

### 3.4 接触可能性评估（MODULE_3）

因果链四阶分析 + c09 时间轴：

| 阶次 | 评估要素 | 传导逻辑 | 判定 |
|------|----------|----------|------|
| 第一阶 | 发表时间线 | 原告先于被告？ | 时序成立/中断 |
| 第二阶 | 传播范围 | 公开发表+被告可触达？ | 接触机会成立/待定 |
| 第三阶 | 行业关系 | 同行业/合作/雇佣？ | 接触可行性高/中/低 |
| 第四阶 | 间接接触链 | 中间环节传播链？ | 间接链存在/不存在 |

**接触等级判定**：

| 等级 | 因果链状态 |
|------|-----------|
| 高 | 四阶因果链传导完整成立 |
| 中 | 部分阶次成立，存在合理接触可能 |
| 低 | 仅个别阶次成立，接触可能性较低 |

### 3.5 综合分析结论（MODULE_4）

#### 3.5.1 三阶交互判定矩阵【新增】

| 情形 | 接触证据 | 相似度 | 判定 | 举证责任 |
|------|----------|--------|------|----------|
| A | 充分（高） | 实质性相似成立 | 侵权成立可能性高 | 原告举证完成 |
| A' | 充分（高） | 不成立 | 侵权不成立 | — |
| B | 不足（中/低） | 高度相似（惊人相似） | 推定接触存在，侵权可能成立 | 被告须提出合理反证 |
| C | 不足（中/低） | 中度/弱相似 | 侵权不成立（巧合/独立创作） | 原告需补强 |

须明确标注最终落入哪种情形。

#### 3.5.2 分权论证

使用 c06 结论卡，**遵循 P7 分权论证**：

对每一项涉诉权利独立论证，四步展开：

```
权利主张：原告主张被告侵犯其[XXX权]
  ↓
构成要件分析：[XXX权]的侵权构成要件为...
  ↓
事实涵摄比对：本案中，被告行为...与原告作品...的比对结果为...
  ↓
判定结论：基于实质性相似[成立/不成立] + 接触可能性[高/中/低] + 三阶交互[情形X]，
         [XXX权]侵权[成立/不成立/证据不足]
```

### 3.6 被告抗辩路径预判（MODULE_5）【新增】

使用 c05 风险清单表组件：

| 抗辩类型 | 可能性 | 依据 | 原告应对要点 |
|----------|--------|------|-------------|
| 独立创作 | 高/中/低/不适用 | 评估依据 | 反驳策略 |
| 合理使用 | 高/中/低/不适用 | 评估依据 | 反驳策略 |
| 接触不可能 | 高/中/低/不适用 | 评估依据 | 反驳策略 |
| 公有领域 | 高/中/低/不适用 | 评估依据 | 反驳策略 |

高可能性抗辩须详细说明原告应对要点。

### 3.7 降级说明（DOWNGRADE_NOTE）

信息不足时输出 C+D+G 最小骨架：

- **C（结论）**：基于现有信息能得出的初步结论
- **D（降级说明）**：标注缺失信息及对结论的影响
- **G（补充建议）**：说明需要哪些额外信息以完成完整分析

## 四、HTML 渲染要求

| 要求 | 规则 |
|------|------|
| 内联样式 | 所有排版使用 `style="..."`，禁止 CSS class 控制（html-spec.md §1.1） |
| 色值来源 | 取自 Richee Design Token（design-tokens.md），禁止自创色值 |
| 字体栈 | `'PingFang SC','Inter',-apple-system,sans-serif` |
| 风险标签 | 高风险 `#d92d20`/`#fef3f2`，中风险 `#b54708`/`#fffaeb`，低风险 `#039855`/`#ecfdf3` |
| 三性标签 | 共通表达 `#6b7280`/`#f6f7f9`，共同选择 `#b54708`/`#fffaeb`，共同错误 `#d92d20`/`#fef3f2` |
| 免责声明 | 固定输出，红色左边框警示样式 |
| 打印适配 | `@media print` 隐藏侧栏/工具栏，展开折叠区 |
| 占位符路由 | 按 html-template.html 的 CONTENT_SLOT 填充 |

> 完整 HTML 排版规范见 [html-format-spec.md](./html-format-spec.md)

## 五、写作红线

| 编号 | 禁止项 | 正确做法 |
|------|--------|----------|
| WR-01 | "必然构成侵权" | "在当前信息范围内，侵权成立可能性为..." |
| WR-02 | 混同多项权利论证 | 每项权利按四步独立论证（P7） |
| WR-03 | 将思想纳入比对 | 严格剥离思想，仅比对表达（P2） |
| WR-04 | 忽略 Scenes à faire | 必须排除题材必然表达（P3） |
| WR-05 | 接触可能性无依据 | 因果链四阶逐一分析，不得笼统推断 |
| WR-06 | 编造法条或判例 | 法条引用须经检索确认（requires_legal_retrieval） |
| WR-07 | 无非法律意见声明 | 所有输出必须附免责声明（P9） |
| WR-08 | 自创 CSS class | 内联样式铁律（HTML-1） |
| WR-09 | 自创色值 | 色值取自 Richee Design Token |
| WR-10 | 缺失剥离理由 | 每个剥离元素须记录理由 |
| WR-11 | 【新增】使用"鉴定"字眼 | 应为"分析"（术语合规） |
| WR-12 | 【新增】相似点无三性标注 | 每个相似点须标注共通表达/共同选择/共同错误（P11） |
| WR-13 | 【新增】未标注三阶交互情形 | 综合结论须标注情形A/A'/B/C（P13） |
| WR-14 | 【新增】未预判被告抗辩 | 须输出抗辩预判模块（P14） |
