# 工作流详述 — 著作权侵权"实质性相似+接触可能性"分析

> 版本：v3.0.0 | 各 Phase 子步骤与检查点

---

## Phase 0: CaseRecord 摄入与输入校验 [L1]

### 子步骤
1. 检测输入模式：CaseRecord IR 存在 → Mode A；否则 → Mode B
2. Mode A：从 CaseRecord 提取 `plaintiff_work`/`defendant_material`/`contact_evidence`/`work_type`/`claimed_rights`
3. Mode B：直接使用用户裸输入
4. 执行输入校验（见 input-spec.md §4）
5. 判定信息完整度：完整→走完整流程；不足→标记降级场景

### 检查点
- [ ] 必填参数（原告作品/被控素材）已获取
- [ ] 作品类型已识别或标注假设
- [ ] 接触线索是否充分（影响 Phase 6 降级判定）

---

## Phase 1: 作品类型分类 [L1]

### 子步骤
1. 根据 `plaintiff_work` 描述识别作品类型（input-spec.md §2.4 枚举）
2. 如用户已指定 `work_type`，确认与自动识别是否一致
3. 根据作品类型选定比对方法论（文字→情节/结构/语言；美术→构图/色彩/线条；音乐→旋律/和声/节奏等）
4. **【新增】锁定该作品类型的典型侵权方式**（见 input-spec.md §2.7 作品类型×侵权方式映射），确定比对重点
5. 标注识别置信度（高/中/低）

### 检查点
- [ ] 作品类型已确定并标注置信度
- [ ] 比对方法论已选定
- [ ] 典型侵权方式已锁定，比对重点已明确

---

## Phase 1.5: 整体观感先行锚定 [L2] 【新增】

### 子步骤
1. 将原告作品与被告素材并置，在**不拆分、不剥离**的状态下形成整体直觉判断
2. 打出整体直觉分（methodology.md §3.2）：
   - 高度相似 / 中度相似 / 弱相似 / 不相似
3. 记录直觉依据——"为什么像/不像"的初步印象
4. 标注整体锚定结论，作为后续剥离比对的**参照系**

### 锚定纪律
- 锚定结论仅作参照，**不直接决定侵权结论**
- 须记录直觉依据，不得笼统标注
- 后续 Phase 4.5 须反向验证此锚定

### 检查点
- [ ] 整体直觉分已打出并记录依据
- [ ] 锚定结论已标注为参照系（非最终结论）

---

## Phase 2: 原告作品独创性元素提取 [L2]

### 子步骤
1. 识别原告作品中主张保护的独创性元素
2. 按作品类型提取：
   - 文字作品：情节链/结构编排/语言风格/人物设定/世界观
   - 美术作品：构图/色彩搭配/线条运用/造型设计/装饰元素
   - 音乐作品：旋律走向/和声进行/节奏型/曲式结构
   - 视听作品：镜头语言/剪辑节奏/画面构图/音画配合
   - 软件作品：代码结构/算法逻辑/界面设计
3. 为每个独创性元素标注：元素描述 + 独创性强度（强/中/弱）+ 独创性依据

### 检查点
- [ ] 独创性元素清单完整
- [ ] 每个元素标注独创性强度与依据
- [ ] 🔴未将思想层面元素误标为表达（P2）

---

## Phase 3: 公共领域剥离 [L3]

### 子步骤
1. 识别并剥离历史事实、通用表达、公共符号、常规设计元素
2. 对每个剥离元素记录：元素描述 + 剥离理由
3. 形成公共领域元素清单
4. 常见公共领域元素：
   - 历史事实、科学原理、数学公式
   - 通用符号、公共标志、常见图案
   - 行业标准设计、常规技术方案
   - 已进入公有领域的作品元素

### 检查点
- [ ] 公共领域元素已逐项剥离
- [ ] 每个剥离元素记录了理由
- [ ] 🔴未将独创性表达误归为公共领域（避免过度剥离）

---

## Phase 4: Scenes à faire 排除 [L2]

### 子步骤
1. 识别因题材/行业必然产生的惯用表达
2. 排除特定类型作品的"标准配置"元素：
   - 悬疑题材：破案线索、反转手法、侦探推理过程
   - 言情题材：相遇/误会/和好情节模式
   - 武侠题材：江湖恩怨、门派争斗、武功修炼
   - 珠宝设计：特定材质的常规工艺、常见造型基础
   - 软件界面：标准菜单布局、常规交互模式
3. 对每个排除元素记录：元素描述 + 排除理由（为何是题材必然）
4. 形成 Scenes à faire 清单

### 检查点
- [ ] Scenes à faire 已识别并排除
- [ ] 排除理由具体到题材必然性
- [ ] 🔴未将独创性表达误归为 Scenes à faire

---

## Phase 4.5: 整体观感反向验证 [L2] 【新增】

### 子步骤
1. 回顾 Phase 1.5 的整体锚定结论
2. 用 Phase 2-4 的剥离结果反向验证初始锚定（methodology.md §3.3）：
   - 初始"高度相似" → 剥离后独创性表达层仍高度重合？→ 维持/下调
   - 初始"中度相似" → 剥离后发现独创性表达层高度重合？→ 上调
   - 初始"弱/不相似" → 剥离后仍有相似？→ 维持/微调
3. 记录调整方向与调整理由
4. 输出修正后的整体观感结论

### 检查点
- [ ] 反向验证已执行
- [ ] 调整方向与理由已记录
- [ ] 修正后的整体观感结论已输出

---

## Phase 5: 独创性表达逐层比对 + 三性分类 + 错误复制识别 [L3] 【增强】

### 子步骤
1. 取 Phase 2-4 剥离后残留的独创性表达作为比对范围
2. **整体层比对**：
   - 整体观感相似性
   - 主题氛围相似性
   - 标注：高度相似/中度相似/弱相似/不相似
   - ⚠️ 此处应为剥离后重新评估，**不得直接复用Phase 1.5结论**；如结论与Phase 1.5一致，须说明理由
3. **结构层比对**：
   - 结构编排相似性
   - 元素组织顺序相似性
   - 标注相似点位置
4. **表达层比对**：
   - 具体表达细节逐点比对
   - 每个相似点标注：所在层次 + 独创性强度 + 相似度评估
5. **【新增】相似点三性分类**（methodology.md §4.3）：
   - 对每个相似点标注性质：共通表达 / 共同选择 / 共同错误
   - 共通表达：证明力⭐⭐，可能源于题材共性
   - 共同选择：证明力⭐⭐⭐，非必然创作取舍一致
   - 共同错误：证明力⭐⭐⭐⭐⭐，巧合无法解释
6. **【新增】错误复制识别**（methodology.md §4.4）：
   - 主动搜索原被告作品在相同位置的一致性瑕疵
   - 检测：错别字/事实错误/逻辑漏洞/非常规标注
   - 发现共同错误时单独提取，标注"证明力极强"
   - ⚠️ 如仅有文字描述无原始作品，错误复制识别降级为"基于描述的有限检测"
7. 汇总比对结果，使用 c12 风险矩阵呈现（相似度×独创性强度×相似性质）

### 检查点
- [ ] 三层逐层比对完整
- [ ] 每个相似点标注层次与独创性强度
- [ ] 🔴每个相似点已标注三性分类（共通表达/共同选择/共同错误）
- [ ] 🔴已执行错误复制识别（主动搜索一致性瑕疵）
- [ ] 🔴比对范围仅限独创性表达（P5）
- [ ] 🔴未将公共领域/Scenes à faire 纳入比对

## Phase 6: 接触可能性因果链评估 [L2] 【重写】

### 子步骤
0. **【新增】第零阶：直接接触证据检测**：
   - 检测是否存在直接接触证据（被告曾为原告员工/合作方、有购买/下载记录、社交媒体转发/评论、签署过保密协议等）
   - 存在直接接触证据 → **跳过四阶推定，直接认定接触等级为"高"**
   - 不存在 → 进入四阶因果链推定
1. **第一阶：发表时间线**（methodology.md §5.2）：
   - 原告作品发表是否早于被告创作时间？
   - 时序不成立 → 接触不成立（因果中断），**且不得适用情形B反推接触**
   - 时序成立 → 进入第二阶
2. **第二阶：传播范围 × 时序可能性**：
   - 原告作品是否公开发表且被告可触达？
   - 公开发表 + 广泛传播 → 合理接触机会成立
   - 公开发表 + 有限传播 → 合理接触机会待定
   - 未公开发表 → 仅间接接触路径（跳至第四阶间接链）
3. **第三阶：合理接触机会 × 行业关系**：
   - 同行业/合作/雇佣 + 合理接触机会 → 接触可行性高
   - 无行业交集 + 合理接触机会 → 接触可行性中
   - 无行业交集 + 接触机会待定 → 接触可行性低
4. **第四阶：接触可行性 × 间接接触链**：
   - 完整组合判定矩阵：

| 接触可行性 | 间接链存在 | 间接链不存在 |
|-----------|-----------|-------------|
| 高 | 接触等级：高 | 接触等级：高（可行性已足够） |
| 中 | 接触等级：中 | 接触等级：低 |
| 低 | 接触等级：低 | 接触等级：低 |

5. 使用 c09 时间轴呈现发表时间线
6. 输出接触等级（高/中/低）及因果链各阶判定

### 接触等级判定标准
- **高**：四阶因果链传导完整成立
- **中**：部分阶次成立，存在合理接触可能
- **低**：仅个别阶次成立，接触可能性较低

### 检查点
- [ ] 因果链四阶逐一评估
- [ ] 各阶判定有依据，因果中断已标注
- [ ] 接触等级已判定并附因果链依据
- [ ] 缺少接触线索时降级标注"接触可能性待补充"

## Phase 7.5: 被告抗辩路径预判 [L2] 【新增】

### 子步骤
1. **独立创作抗辩预判**（methodology.md §8.1）：
   - 评估被告主张独立创作的可能性（高/中/低）
   - 共同错误存在 → 独立创作可能性低
   - 仅共通表达 → 独立创作可能性高
2. **合理使用抗辩预判**：
   - 标注是否可能适用著作权法第24条合理使用
   - 本报告仅提示可能性，不深入分析（属独立法律问题）
3. **接触不可能抗辩预判**：
   - 评估被告主张"接触不可能"的抗辩力度
   - 接触因果链四阶成立 → 抗辩力度低
   - 接触因果链部分中断 → 抗辩力度中/高
4. **公有领域抗辩预判**：
   - 评估被告主张"相似源于公有领域"的可能性
   - 相似点位于独创性表达层 → 抗辩不成立
   - 相似点位于公共领域/Scenes à faire → 抗辩成立（但应在剥离阶段已排除）
5. **【新增】合法来源抗辩预判**（著作权法第59条）：
   - 被告可能主张素材来自第三方授权/购买/委托创作
   - 评估被告作为"使用者"而非"制作者"的合法来源抗辩可能性
   - 如抗辩成立，原告可能需追加实际制造商为共同被告
6. 对每类抗辩给出可能性评估与原告应对要点

### 检查点
- [ ] 四类抗辩路径已逐一预判
- [ ] 每类抗辩标注可能性（高/中/低/不适用）
- [ ] 高可能性抗辩已附原告应对要点

1. 按 `templates/html-template.html` 模板填充 CONTENT_SLOT 占位符
2. 组装八大模块：
   - 案件概况（c01）

## 降级场景处理

| 场景 | 降级措施 | Phase 影响 |
|------|----------|-----------|
| 仅文字描述无原始作品 | Phase 2/5 基于描述定性分析，标注"需补充原始作品"；错误复制识别可能受限 | Phase 2/5 降级 |
| 缺少接触线索 | Phase 6 仅标注"接触可能性待补充"，不判定等级；三阶交互仅能基于相似度判定 | Phase 6 降级 |
| 作品类型不明确 | Phase 1 按最可能类型分析，标注类型假设 | Phase 1 降级 |
| 被告素材描述模糊 | Phase 5 标注模糊点，对可分析部分给出初步意见 | Phase 5 降级 |
| 信息严重不足 | 走 C+D+G 最小骨架，输出初步结论+降级说明+补充建议 | 全流程降级 |
