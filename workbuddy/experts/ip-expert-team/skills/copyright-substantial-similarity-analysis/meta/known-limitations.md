# 已知限制 — 著作权侵权"实质性相似+接触可能性"分析

> 版本：v3.0.0

## 分析精度限制

### 1. 文字描述替代原始作品的局限
- 当用户仅提供文字描述而无法提供原始作品文件时，分析基于描述进行定性判断
- 文字描述可能遗漏重要的视觉/听觉表达细节
- 降级输出会明确标注"需补充原始作品进行精确比对"

### 2. 视觉作品比对的局限
- 对于美术作品、摄影作品、设计稿等视觉作品，纯文字描述的比对精度显著低于直接图像比对
- 无法进行像素级、构图比例等精确量化分析
- 建议视觉作品侵权分析中，用户尽可能提供原始图片文件

### 3. 音乐/视听作品的听觉比对局限
- 对于音乐作品的旋律、和声、节奏等听觉元素的比对，文字描述的分析精度有限
- 视听作品的镜头语言、剪辑节奏等动态表达难以通过文字精确还原
- 建议此类作品提供时间轴标注或关键帧截图

## 法律适用限制

### 4. 仅适用于中国著作权法框架
- 本技能的分析方法论基于《中华人民共和国著作权法》（2020修正）及中国司法实践
- 不直接适用于其他法域（如美国 fair use 原则、欧盟例外与限制制度）
- 涉外案件需注意法律适用问题

### 5. 不替代专业机构认证
- 本输出为技术性比对分析报告，不构成司法鉴定意见或专业机构认证意见
- 法院可能要求委托具有资质的鉴定机构进行正式鉴定
- 本报告可作为律师内部工作文件或诉讼准备材料

### 6. 不覆盖合理使用抗辩
- 本技能专注于实质性相似与接触可能性分析
- 合理使用（著作权法第24条）属于独立抗辩事由，不在本技能分析范围内
- 即使实质性相似成立，被告仍可提出合理使用抗辩
- 本报告在免责声明中提示被告可能提出合理使用抗辩

## 信息获取限制

### 7. 外部数据库访问依赖
- 中国版权登记数据库需要联网搜索访问，离线环境无法查询
- 作品独创性判例库依赖公开裁判文书的可获取性
- 部分作品的发表时间、传播范围等事实依赖用户提供

### 8. 接触证据的间接性
- 接触可能性评估基于可获取的公开信息，可能遗漏非公开的接触渠道
- 行业关系、合作历史等需要用户主动提供
- 间接接触链的完整性依赖案件事实的完整程度

## 方法论限制

### 9. 相似度评估的主观性
- 实质性相似的判断在司法实践中本身存在一定的主观性
- 不同法院、不同法官对相似程度的认定可能存在差异
- 本技能的相似度评估是专业分析而非确定性的法律结论

### 10. 独创性标准的时代演进
- 独创性的认定标准随司法实践不断演进
- 新兴作品类型（如AI生成内容、NFT等）的独创性认定尚在发展中
- 本技能基于截至知识截止日期的司法实践进行分析

### 11. 【新增】错误复制识别的依赖性
- 错误复制识别需要同时持有原被告作品的完整文本/素材
- 仅提供文字描述时，一致性瑕疵可能被遗漏
- 视觉/听觉作品的错误复制识别精度受文字描述充分性限制

### 12. 【新增】整体观感锚定的主观性
- 整体直觉打分依赖分析师的专业经验，存在主观性
- 锚定结论仅作参照系，须经过反向验证修正
- 不同分析师的初始锚定可能存在差异

### 13. 【新增】三阶交互判定的法律复杂性
- 情形B"反推接触"的触发条件在不同法院可能存在认定差异
- 推定接触的法律效力需结合具体案件判断（中国著作权法无法定举证责任转移规则，高度相似→推定接触本质是事实推定）
- 本报告的三阶交互判定为专业分析参考，不构成确定性的法律结论

## HTML 输出限制

### 14. Mermaid 图表依赖 JavaScript
- 接触传播链图（c15 证据链图）使用 Mermaid 渲染，需要浏览器启用 JavaScript
- 禁用 JavaScript 时显示降级提示，需手动复制源码到 mermaid.live 在线渲染
- 打印时 Mermaid 图表隐藏，显示降级表格

### 15. 打印颜色保留依赖浏览器支持
- 打印/PDF 导出时表格着色需浏览器支持 `print-color-adjust:exact`
- 部分旧版浏览器可能无法保留打印颜色
- 建议使用 Chrome/Edge 等现代浏览器打印
