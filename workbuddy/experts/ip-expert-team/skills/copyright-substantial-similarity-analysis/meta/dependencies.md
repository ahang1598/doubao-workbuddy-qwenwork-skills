# 外部依赖 — 著作权侵权"实质性相似+接触可能性"分析

> 版本：v3.0.0

## 内部依赖（Required）

### schemas.case_fact_ir
- **用途**：定义 CaseRecord 的数据结构，用于消费上游技能的输出和产出本技能的结构化结果
- **依赖类型**：数据模式（Schema）
- **使用方式**：作为 Phase 0 输入校验和 Phase 7 输出写入的结构定义
- **最低版本**：v1.0.0

### governance.soft_degraded
- **用途**：定义信息不足时的降级治理策略，确保始终输出有价值的分析结果
- **依赖类型**：治理策略（Governance）
- **使用方式**：在输入校验阶段判定信息完整度，决定执行完整流程或降级至 C+D+G 骨架
- **最低版本**：v1.0.0

### base/rule/format-html（HTML 排版规范）
- **用途**：定义 HTML 输出的排版规范（内联样式铁律、Richee Design Token 视觉体系、C-Professional 参数）
- **依赖类型**：格式规范（Format Spec）
- **使用方式**：Phase 8 生成 HTML 报告时遵循 html-spec.md §1.3 范式唯一性条款 + §2.2 C-Professional 参数
- **最低版本**：v2.0.0

### base/rule/format-html/core/design-tokens.md（Richee Design Token）
- **用途**：定义配色/字体/圆角/阴影的 Richee Design Token 体系
- **依赖类型**：视觉规范（Visual Token）
- **使用方式**：所有内联样式色值取自此文件，禁止自创色值
- **最低版本**：v1.0.0

### base/rule/format-html/components/（Richee 内联组件）
- **用途**：提供 c01/c04/c05/c06/c09/c12/c15 七个 Richee 内联样式组件模板
- **依赖类型**：组件库（Components）
- **使用方式**：Phase 8 生成 HTML 报告时复制组件模板，替换数据
- **引用组件**：c01 基础表格 / c04 证据目录表 / c05 风险清单表 / c06 结论卡 / c09 时间轴 / c12 风险矩阵 / c15 证据链图

## 内部依赖（Optional）

### retrieval.case_search_guide
- **用途**：提供案例检索指南，辅助查找同类著作权侵权判例
- **依赖类型**：检索增强（Retrieval）
- **使用方式**：在接触可能性评估阶段，检索类似作品类型的侵权判例作为参考
- **备注**：缺失不影响核心分析流程

### retrieval.regional_guideline
- **用途**：提供地域性裁判指引，考虑不同地区法院的裁判倾向差异
- **依赖类型**：检索增强（Retrieval）
- **使用方式**：在分析结论中补充地域性裁判倾向说明
- **备注**：缺失不影响核心分析流程

## 上游技能依赖

### ip-infringement-clue-miner (Skill 1)
- **用途**：产出 CaseRecord IR，包含已结构化的案件事实、作品信息与侵权线索
- **依赖类型**：上游数据消费（Upstream Consumer）
- **使用方式**：Phase 0 摄入 CaseRecord，提取作品描述、侵权线索等结构化字段
- **备注**：非强制依赖，本技能也可接受用户裸输入独立运行

## 外部数据依赖

### 中国版权登记数据库
- **用途**：查询作品登记信息，确认作品类型、登记时间、权利归属
- **依赖类型**：外部数据库
- **访问方式**：通过 web_search 间接访问公开登记信息
- **备注**：非强制，缺失时在降级说明中标注

### 作品独创性判例库
- **用途**：检索同类作品类型的独创性认定标准，辅助独创性元素提取
- **依赖类型**：外部知识库
- **访问方式**：通过 web_search 检索公开判例
- **备注**：非强制，缺失时依赖内置方法论

## 工具依赖

### web_search（联网搜索）
- **用途**：检索相关判例、法律条文、作品公开信息
- **依赖类型**：外部工具
- **备注**：无网络连接时，依赖内置知识进行分析，在降级说明中标注。法条检索契约 `requires_legal_retrieval: true`，核心法条须经检索确认现行有效性。
