# trademark-assistant

针对中国商标申请而设计的 skill，覆盖类别规划、可注册性初筛以及申请材料筹备三大环节。其底层依托尼斯分类、中国现行商标法律法规与审查审理规则，最终给出结构化的风险分级、类别建议、商品清单和商标说明。

> 以“这个名字究竟能否注册、应当挑选哪些类别”作为起点，把商标申请前最易被遗漏的信息与潜在风险，提前梳理成一份清晰的清单。

## 适合谁用

- 有意在中国提交商标申请的企业、创业者及自然人
- 希望快速完成类别规划与可注册性初筛的律师、商标代理人、品牌负责人
- 商标设计方案已敲定，需据此整理商品清单和商标说明的申请人

## 典型场景

```text
用户：我想注册“星火”这个商标，做教育软件和在线课程，帮我看看能不能注册，需要选哪些类别。
AI：我会先收集申请主体、商标构成和使用场景，再做尼斯分类规划和可注册性初筛。
    输出包括类别建议、风险分级、待补充信息、免责声明和升级建议。
```

## 它能产出什么

- 商标咨询输入清单
- 依照尼斯分类归整的类别规划表
- 可注册性初筛报告，结果涵盖高/中/低风险或“待补充”
- 商品清单，可按官方导入模板生成 Excel
- 图形商标或组合商标的商标说明文本
- 免责声明、升级建议，以及需由专业律师/代理机构进一步核验的问题

## 当前覆盖范围

- 主要法域：中国大陆商标注册申请
- 分类依据：尼斯分类，当前默认采用 NCL13-2026，并保留 NCL12-2025 供历史回溯
- 法律依据：《中华人民共和国商标法》《商标法实施条例》《商标审查审理指南》等中国法资料
- 交付格式：统一以 Markdown 结构化结论输出；申请材料阶段可生成 Excel 商品清单

尼斯分类本身具备国际通用性，故类别规划思路可作为国际申请的参照；然而可注册性初筛、审查标准与法律判断均只针对中国商标申请。

## 安装方式

1. 进入本仓库的 GitHub Releases 页面。
2. 下载最新版本的 skill 压缩包。
3. 解压后，把 `trademark-assistant/` 文件夹放到你的 skill 目录中。
4. 在支持 `SKILL.md` 的 Agent / Claude 环境里启用该 skill。

若要生成商品清单 Excel，请先安装依赖：

```bash
pip install openpyxl
```

## 使用边界

本 skill 适用于：

- 中国商标申请前的类别规划
- 可注册性的初步筛查与风险分级
- 申请材料中商品清单与商标说明的准备

本 skill 不适用于：

- 取代律师或商标代理机构出具正式法律意见
- 承诺商标注册成功率
- 处理复杂商标争议、异议、无效、撤三、驰名商标或跨类大规模冲突
- 在未检索官方数据库、未核验近似商标和申请主体事实时作最终判断

## 核心设计

### 先收集信息再判断

申请主体、商标构成、使用商品/服务、目标市场与设计稿，都会左右最终结论。当关键信息不足时，输出“待补充”，绝不强行评级。

### 类别规划与可注册性分开

尼斯分类回答“应当保护哪些商品/服务”，可注册性初筛回答“这个标识是否可能被驳回”。二者各自独立分析，再汇合为行动建议。

### 材料准备可落地

待客户确认设计方案后，可进一步生成商品清单和商标说明，直接服务于申请材料筹备，而不止停留在咨询建议层面。
