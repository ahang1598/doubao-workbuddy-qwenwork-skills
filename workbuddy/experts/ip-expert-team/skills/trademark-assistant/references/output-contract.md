## 交付要求

- 提供的应当是能够直接落地的建议，而非泛泛而谈的表述
- 任何一条结论背后，都至少要有一条依据作为支撑
- 当信息不充分时，务必明确标注“未提及/待补充”
- 一旦使用场景、商品/服务范围这类关键信息出现缺失，风险等级即统一填写为“待补充（信息不足，暂不评级）”，不得给出高/中/低的判定
- 交付物统一为单一版本：以 Markdown 结构化报告呈现，不另附 JSON
- 每一份交付都必须带有“免责声明 + 升级建议”；凡遇高风险、复杂争议或信息缺失的情形，必须写明建议咨询专业律师或代理机构
