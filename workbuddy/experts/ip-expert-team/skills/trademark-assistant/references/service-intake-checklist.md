# 服务输入清单（Intake Checklist）

## 一、基础信息

- 申请人/主体全称：
- 核心业务范围说明：
- 现阶段经营覆盖地域：
- 未来 1-3 年规划拓展的业务方向：

## 二、商标信息

- 商标形态：文字 / 图形 / 组合
- 商标具体内容（文字本身或图形描述）：
- 是否已在公开场合投入使用：是 / 否
- 已使用的场景及起始时间：

## 三、类别相关问题

- 申请人已自行考虑的类别：
- 拟纳入保护的商品/服务清单：
- 费用预算倾向：核心优先 / 防御优先 / 平衡

## 四、初筛阶段的必问事项

当申请人仅给出"商标名称"时，至少须追问以下要点：

1. 该商标将用于哪类商品/服务？
2. 目标客群是哪些人群？
3. 是否已持有在先使用证据？

## 五、缺失处理规则

- 核心业务信息缺失：标注为"未提及/待补充"，不直接输出最终类别结论
- 使用场景缺失：仅可提供候选类别，风险等级须标为"待补充（信息不足，暂不评级）"
- 商标内容细节缺失：只输出流程建议，不给出成功率倾向
