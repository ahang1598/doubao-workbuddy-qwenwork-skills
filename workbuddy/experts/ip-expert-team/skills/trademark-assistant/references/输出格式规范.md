# 输出格式规范

> 本文件融入《Richee 输出规范》markdown-preview / word-report / machine-template Profile（v1.1.0）。运行时不读取、不依赖规范库。
> 规则采用记录见同目录 `输出规范融合记录.md`。

## 1. 支持格式

| 交付物 | Profile | 文件命名 |
|---|---|---|
| 对话预览 | markdown-preview | 不落盘（对话内 Markdown） |
| 正式初筛/规划报告 | word-report | `{简称}_{主题}_{YYYYMMDD}.docx` |
| 商标申请商品清单（系统导入） | machine-template | `{商标名}-第{X}类-商品清单.xlsx` |

- 简称：本技能 `商标助手`（trademark-assistant）。
- 报告主题示例：`可注册性初筛`、`类别规划`。

## 2. 通用红线（GATE）

- **免责声明**：正式报告必须在标题之后放置 AI 辅助 + 仅供参考 + 不构成正式法律意见的声明。商品清单为机器导入模板，不插入免责声明块。
- **禁止绝对化法律结论**：不得使用「保证胜诉、必然、绝对、绝无风险、完全合规、一定合法」等措辞。注意：商标法术语「绝对理由/绝对事由」须改写为「禁注事由/禁注理由」，避免触发绝对化检查。
- **风险必须文字+颜色**：风险等级同时显示文字与底色。
- **封闭标签集**：只用第 5 节声明的集合。
- **Word 无 emoji**：Word 全文不得含 emoji。
- **表格宽度**：Word 表格总宽不超过内容区并留约 2mm 余量。
- **商品清单模板契约优先（OUT-TPL-001）**：不得改变 `templates/导入商品信息.xlsx` 的字段、列序（序号/商品类别/类似群/商品名称）与官方版式；只追加数据行。

## 3. 版式（word-report 推荐版式）

- A4；正文 1.5 倍行距；页边距 2.54cm。
- 中文字体微软雅黑（标准优先 PingFang SC，Windows 目标环境缺失，用其回退项）；等宽 Consolas。
- 主体黑白灰；绿色仅用于一级标题线、三级标题等小面积强调。
- 表头黑底白字，正文白底细灰线，数据单元格上下居中。
- 风险：高=浅红底深红字、中=浅琥珀底深琥珀字、低=浅绿底深绿字、待补充=中性灰底灰字。

## 4. 报告 Markdown → docx 契约

正式报告由 pandoc 渲染。你**只写 Markdown + 跑一条命令**，不写 python-docx / 样式代码。

### 渲染命令（在 skill 根目录执行）

```bash
pandoc 报告.md -o "商标助手_{主题}_{YYYYMMDD}.docx" \
  --reference-doc=assets/richee-reference.docx \
  --lua-filter=scripts/richee.lua \
  --from markdown+east_asian_line_breaks
```

> reader 必须是 `markdown`，严禁改成 `gfm`（否则 fenced div 与风险胶囊静默失效）。

### 文档骨架

```markdown
---
title: 商标可注册性初筛报告
---

::: {custom-style="Disclaimer"}
本报告由 AI 辅助生成，仅供参考，不构成正式法律意见。最终以商标局审查裁定为准。
:::

# 一级标题
正文……风险用 [中风险]{.tag .risk-mid} 等胶囊。
```

- 标题用 YAML `title:`；免责声明紧贴标题（`Disclaimer` 样式，含「AI」与「仅供参考/不构成正式法律意见」之一）。
- 风险胶囊：`[高风险]{.tag .risk-high}` / `[中风险]{.tag .risk-mid}` / `[低风险]{.tag .risk-low}` / `[待补充]{.tag .risk-pending}`。
- 分页用 raw openxml 块（整段照抄）：`<w:p><w:r><w:br w:type="page"/></w:r></w:p>` 包在 ` ```{=openxml} ` 围栏内。
- 完整示例见 `examples/markdown-example.md`。

## 5. 商品清单（machine-template）

- 模板：`templates/导入商品信息.xlsx`（官方系统导入格式，**不得修改字段/列序/版式**）。
- 生成：用 openpyxl 加载模板、从第 2 行起追加数据行、另存。商品名须为尼斯分类规范名称。
- 不套 Richee 视觉（OUT-TPL-003）；如需人读版另行生成。
- 一致性校验：由输出规范库校验器比对模板与生成件结构（见 `输出规范融合记录.md` 的 `template_checks`）。

## 6. 封闭标签集（OUT-COM-005）

| 标签类型 | 取值 | 写法 |
|---|---|---|
| 风险等级 | 高风险 / 中风险 / 低风险 / 待补充 | `[高风险]{.tag .risk-high}` 等 |
| 法规引用 | 《法规名》第X条 | 行内纯文本，如「《商标法》第十一条」 |
| 段落样式 | Disclaimer | `::: {custom-style="Disclaimer"}` |

## 7. 生成与验收

- 报告模板：`assets/richee-reference.docx`（由 `scripts/build_reference.py` 生成）；风险胶囊滤镜 `scripts/richee.lua`。
- 商品清单模板：`templates/导入商品信息.xlsx`。
- 代表性样例：`examples/`（初筛报告 docx + 商品清单 xlsx）。
- 自动校验：由开发或评审从工作区根目录，用输出规范库自带的 `validate_skill_output.py` 校验本技能目录与 `examples/`（含 `--run-skill-tests` 时跑商品清单模板一致性校验）。
- 人工目检：报告首页（标题+免责）、含风险胶囊/表格页；商品清单打开核对列序与数据。
