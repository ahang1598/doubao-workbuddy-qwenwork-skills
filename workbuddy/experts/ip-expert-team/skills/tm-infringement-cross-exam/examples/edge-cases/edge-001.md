# 边界示例001 — 证据清单极度缺失

> 技能：tm-infringement-cross-exam | 版本：1.0.0
> 边界场景：用户仅提供被告名称，未提供任何证据清单

---

## 输入

```
帮我做商标侵权质证，被告是XX公司
```

## 预期输出（降级模式 S1）

```markdown
# 质证意见表（骨架版）

## ⚠️ 降级说明
当前输入缺少关键信息，以下为最小骨架产出。请补充缺失信息后重新生成。

---

## C层：待补充事实清单

以下为生成完整质证意见所必需的信息：

| # | 缺失项 | 用途 |
|---|--------|------|
| 1 | 原告注册商标信息（名称/类别/注册号） | 确定权利基础 |
| 2 | 被告证据清单（名称/类型/摘要/证明目的） | 质证对象 |
| 3 | 被告抗辩类型 | 匹配商标特有质证要点 |
| 4 | 原告商标申请日/注册日 | 在先使用时间线审查 |

## D层：治理与禁区声明

- 本输出为骨架版，不包含实质性质证意见
- 任何质证意见需基于完整的证据信息，缺项状态下不提供判断
- 不替代律师独立判断

## G层：可执行下一步

1. 提供原告注册商标信息（名称+类别+注册号）
2. 提供被告提交的证据清单
3. 指定被告抗辩类型（合法来源/在先使用/不近似/三年不使用）
4. 补充后重新调用本技能
```

---

## 教训

- 证据清单是质证的前提，缺少证据清单无法执行任何质证
- S1降级时应明确告知缺失项和下一步操作
- 不应在缺项状态下"猜测"被告证据并生成质证意见
