## 一、三层理论框架

### 认知层（Know-What）

**核心问题**：商标侵权质证的法律要件是什么？举证责任如何分配？

| 要件 | 内容 |
|------|------|
| 质证的法律性质 | 对被告证据的真实性/合法性/关联性/证明力提出异议 |
| 举证责任分配 | 原告对侵权事实举证；被告对合法来源/在先使用等抗辩举证 |
| 四性分析顺序 | 真实性→合法性→关联性→证明力（真实性和合法性是证据能力问题，关联性和证明力是证明力问题） |
| 证据能力 vs 证明力 | 真实性/合法性问题=证据能力异议（证据不可采）；关联性/证明力问题=分量不足（证据可采但不足以证明主张） |
| 商标特有抗辩 | 合法来源（第64条）/ 在先使用（第59条第3款）/ 不近似（解释第9-10条）/ 三年不使用（第49条第2款） |

**常见认知错误**：
- ❌ 把质证等同于"质疑"——质证必须有推理（前提→推理→结论），不能无依据质疑
- ❌ 混淆"证据能力异议"和"证明力异议"——前者是证据不可采，后者是分量不足
- ❌ 只攻击对方而忽略己方举证责任——己方也有举证义务，需注意补强
- ❌ 把"三年不使用"当作侵权抗辩——它只是撤销商标的条件，但可影响赔偿计算

### 策略层（Know-Why）

**核心问题**：如何设计质证策略？

| 抗辩类型 | 质证主攻方向 | 辅助方向 | 策略选择依据 |
|---------|-------------|---------|------------|
| 合法来源 | 合理注意义务+进货渠道不正规 | 供货方资质+价格异常+信息不可追溯 | "不知道"+ "合法取得"须同时满足 |
| 在先使用 | 时间线晚于申请日 | 使用范围不符+未达"有一定影响"+非商标性使用 | 法条要求"申请日前"+ "有一定影响" |
| 不近似 | 比对范围不完整+选择性忽略相似点 | 拆分比对+非相关公众标准+忽略知名度 | 整体比对原则+隔离比对原则 |
| 三年不使用 | 仅网络搜索不能证明未使用 | 起算时间错误+有正当理由+使用证据覆盖 | "未使用"≠"搜索未发现" |

**策略选择的核心原则**：
1. **举证责任利用**：合法来源/在先使用的举证责任在被告——"被告未能完成举证责任"比"证据不真实"更容易被法官接受
2. **先攻最弱**：按证据薄弱程度排序质证策略
3. **己方补强意识**：质证不是只攻击对方——己方也有举证责任，质证后需评估己方证据链是否完整
4. **对有利己方证据的利用**：如果被告证据反而支持原告主张，应指出并利用

### 表达层（Know-How）

**核心问题**：按所选策略如何生成质证意见？

**选定风格：四性逐项分析+商标特有要点增强风格**（基于3篇以上商标侵权质证实务经验交叉验证）

| 风格特征 | 说明 |
|---------|------|
| 四性分析 | 每项证据按真实性→合法性→关联性→证明力逐项分析 |
| 商标特有要点 | 在四性分析后独立列出商标特有质证要点 |
| 举证责任提示 | 每项证据附带举证责任提示 |
| 质证策略总结 | 整体策略+薄弱环节+己方补强方向 |
| 禁止 | 笼统质疑式、纯罗列式、无推理质疑 |

**三层硬约束**：不允许跳过任一层——必须先理解质证法律要件（认知层），再选择质证策略（策略层），最后生成质证意见（表达层）。

## 二、六操作管线

### 1. 转化

| 客户口语 | 转化为结构化要素 |
|---------|----------------|
| "被告提供了进货单" | `defendant_evidence` 含 `invoice_receipt`，抗辩类型=合法来源 |
| "被告说他的商标先用" | `defense_type` = prior_use，需审查时间线 |
| "被告图片对比说不一样" | `defendant_evidence` 含 `product_photo`，抗辩类型=dissimilar |

### 2. 细化

| 抗辩类型 | 细化为审查要点 |
|---------|--------------|
| 合法来源 | 渠道正规性+价格合理性+供货方资质+合理注意义务+可追溯性 |
| 在先使用 | 时间线+使用范围+"有一定影响"+商标性使用 |
| 不近似 | 音形义三维度+整体比对+相关公众标准+选择性展示 |
| 三年不使用 | 搜索方式+起算时间+正当理由+使用证据覆盖 |

### 3. 补充

| 审查要点 | 补充法律依据 |
|---------|-------------|
| 合法来源条件 | 商标法第64条[✅已核实]：不知道+合法取得+说明提供者 |
| 在先使用条件 | 商标法第59条第3款[✅已核实]：申请日前+有一定影响 |
| 近似认定标准 | 商标民事纠纷解释第9-10条[✅已核实] |
| 三年不使用 | 商标法第49条第2款[✅已核实] |

### 4. 拆分

| 复合证据 | 拆分为独立质证 |
|---------|---------------|
| 进货单+供货合同 | DE-01进货单（真实性+渠道）+ DE-02供货合同（关联性+资质） |
| 网页公证+销售记录 | DE-03网页公证（公证程序）+ DE-04销售记录（真实性+关联性） |

### 5. 去重

| 常见重复模式 | 去重处理 |
|-------------|---------|
| 合法来源质证重复进货渠道分析 | 渠道正规性只分析一次，后续引用 |
| 不近似质证重复音形义分析 | 引用B1比对结论，不重复分析 |

### 6. 统一

| 统一项 | 标准表述 | 禁止表述 |
|--------|---------|---------|
| 证据编号 | DE-01, DE-02 | 证据1, 被告证据1 |
| 质证意见 | "真实性存疑" | "肯定是假的""一定不真实" |
| 举证责任 | "被告承担举证责任" | "被告必须证明" |
| 证据能力 | "证据可采/不可采" | "可以用/不能用" |

## 三、隐性知识嵌入

### 3.1 举证责任意识——不只攻击对方，还要补强己方

| 要点 | 说明 |
|------|------|
| 双向意识 | 质证不是只攻击对方——己方也有举证责任 |
| 补强提示 | 质证后评估己方证据链是否完整，提示补强方向 |
| 利用对方 | 如果被告证据反而支持原告主张，指出并利用 |
| 嵌入方式 | Phase 3 每项证据附带举证责任提示+Phase 4 策略总结含己方补强方向 |

### 3.2 四性分析的真正含义

| 要点 | 说明 |
|------|------|
| 真实性是基础 | 伪证无需进一步分析——真实性不过关直接跳过后续 |
| 证据能力 vs 证明力 | 真实性/合法性=证据能力（可不可采）；关联性/证明力=证明力（够不够分量） |
| 顺序不可颠倒 | 必须先真实性→合法性→关联性→证明力 |

### 3.3 商标特有质证不是泛泛质疑

| 要点 | 说明 |
|------|------|
| 精准打击 | 合法来源看渠道+注意义务；在先使用看时间线；不近似看比对范围；三年不使用看搜索方式 |
| 法律依据嵌入 | 每类抗辩质证必须附法条依据 |
| 实务经验 | "被告未能完成举证责任"比"证据不真实"更容易被法官接受 |
