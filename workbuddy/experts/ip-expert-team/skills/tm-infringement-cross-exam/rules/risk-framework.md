## 二、商标侵权质证特有风险规则

### 2.1 质证策略风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 反向自认 | 质证中承认被告证据真实性 | 强制使用"有异议"表述，禁止"无异议" |
| 泛泛质疑 | 无推理过程的质疑 | 强制前提→推理→结论三段式 |
| 只攻击对方 | 忽略己方举证责任 | 每项证据附带举证责任提示+己方补强方向 |
| 对有利证据攻击 | 被告证据反而支持原告主张却仍攻击 | 识别有利证据并指出利用 |

### 2.2 商标特有质证风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 遗漏合法来源质证要点 | 未审查合理注意义务 | 合法来源6项审查清单强制覆盖 |
| 遗漏在先使用时间线 | 未审查时间是否早于申请日 | 强制审查申请日vs使用日 |
| 遗漏不近似比对范围 | 未审查是否选择性忽略相似点 | 音形义三维度+整体比对审查清单 |
| 三年不使用误作抗辩 | 把撤销条件当作侵权抗辩 | 明确标注"三年不使用是撤销条件，非侵权抗辩" |

### 2.3 证据类型风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 公证证据盲目信任 | 未经审查即承认公证证据 | 审查公证程序+封存+时间 |
| 进货单=合法来源 | 有进货单即认为合法来源成立 | 审查进货渠道+价格+供货方资质+注意义务 |
| 网络搜索=未使用 | 网络搜索未发现=商标未使用 | 明确指出搜索≠证明未使用 |

## 三、SOFT_DEGRADED 降级骨架

> 遵循 `base/shared/risk-rules-common.md` C+D+G 最小骨架

### 降级分层 L0-L3

| 等级 | 条件 | 输出范围 |
|------|------|---------|
| **L0 完整** | 所有必填参数齐全 | 完整质证意见 + 证据要点速查卡 + 质证策略总结 |
| **L1 轻度** | 缺少证据清单等可选参数 | 完整质证意见 + 缺失处标注"[待补充]" |
| **L2 中度** | 缺少抗辩类型 | 四性框架 + 占位标注 + 商标特有要点标注"[待律师补充]" |
| **L3 重度→SOFT_DEGRADED** | 缺少原告商标或证据清单 | 仅质证骨架 + 法定要素清单 |

### SOFT_DEGRADED 最小骨架（C + D + G）

| 块 | 内容 |
|----|------|
| **C) 待补充事实清单** | 缺失的原告商标信息/被告证据清单 + 影响程度 + 建议补充方式 |
| **D) 治理与禁区声明** | 输出为最小骨架，不构成完整质证意见；禁止直接用于庭审 |
| **G) 下一步行动** | 用户需提供原告商标信息和被告证据清单以获取完整质证意见 |

### 降级强度映射

| 强度 | 条件 | 渲染等级 |
|------|------|---------|
| S1 | L3 重度 | 仅 C+D+G，不输出实质质证 |
| S2 | L2 中度 | C+D+G + 四性框架，缺失项占位标注 |
| S3 | L1 轻度 | 接近完整输出，可选参数处标注"[待补充]" |
