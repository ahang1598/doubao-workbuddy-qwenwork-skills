| 输出 | 说明 | 渲染条件 | 格式严肃度 |

| **质证意见表** | 逐项证据四性分析+商标特有质证要点+反驳要点+法律依据 | 始终输出 | I-Practical |

## 四、商标特有质证要点模板（4类抗辩）

### 4.1 合法来源抗辩证据

**质证切入点**：进货渠道+价格合理性+供货方资质+合理注意义务+可追溯性
**反驳要点**：渠道不正规/价格异常/供货方无资质/未尽注意义务/信息不可追溯
**法律依据**：《商标法》第64条[✅已核实]

**审查清单**：
- [ ] 进货渠道是否正规（有无正规发票/合同）
- [ ] 进货价格是否合理（是否明显低于市场价）
- [ ] 供货方是否有资质（营业执照/授权）
- [ ] 被告是否尽到合理注意义务（商品是否标注原告商标/是否有授权标识）
- [ ] 供货方信息是否可追溯（名称/地址/联系方式）
- [ ] 证据形成时间是否晚于侵权行为发生时间

### 4.2 在先使用抗辩证据

**质证切入点**：使用时间早于申请日+使用范围+"有一定影响"+商标性使用
**反驳要点**：时间晚于申请日/范围不符/未达"有一定影响"/描述性使用
**法律依据**：《商标法》第59条第3款[✅已核实]

**审查清单**：
- [ ] 使用时间是否早于原告商标**申请日**（非注册日）
- [ ] 使用范围是否与原告商标核定商品相同或类似
- [ ] 是否达到"有一定影响"的程度
- [ ] 使用行为是否是商标性使用（非描述性使用）
- [ ] 证据能否证明在先使用的事实（合同/发票/宣传材料等形成时间）

### 4.3 不近似抗辩证据

**质证切入点**：音形义三维比对+整体比对+相关公众标准+选择性展示
**反驳要点**：比对不完整/拆分比对/忽略相似点/展示方式不客观
**法律依据**：《最高人民法院关于审理商标民事纠纷案件适用法律若干问题的解释》第9-10条[✅已核实]

**审查清单**：
- [ ] 比对是否覆盖音/形/义三个维度
- [ ] 是否将商标作为整体比对（非拆分比对）
- [ ] 是否以相关公众的一般注意力为标准
- [ ] 是否考虑了原告商标的显著性和知名度
- [ ] 是否选择性展示差异点而忽略相似点
- [ ] 对比图的展示方式是否客观（同比例/同角度/同背景）

### 4.4 三年不使用抗辩证据

**质证切入点**：搜索方式合理性+起算时间+正当理由+使用证据覆盖
**反驳要点**：仅网络搜索不能证明未使用/起算时间错误/有正当理由
**法律依据**：《商标法》第49条第2款[✅已核实]

**审查清单**：
- [ ] 搜索方式是否合理（仅网络搜索不能证明未使用）
- [ ] 三年起算时间是否正确（自申请撤销之日起向前推3年）
- [ ] 原告是否有正当理由未使用
- [ ] 原告使用证据是否覆盖争议期间
- [ ] "不使用"抗辩是否在答辩期内提出

## 五、写作红线（WR-01~11）

> 本技能遵守 `base/shared/writing-redlines.md` 全部 11 条通用红线。

| # | 红线 | 说明 | 本技能具体应用 | 违反后果 |
|---|------|------|--------------|---------|
| WR-01 | **不使用绝对化表述** | 禁止"必然""一定""保证""肯定" | 不得出现"该证据一定是伪造的""被告一定无法证明" | 误导当事人 |
| WR-02 | **结论留边界** | 加限定语 | "根据现有信息""建议关注" | 无限定结论构成不当保证 |
| WR-03 | **事实与意见分离** | 事实不加主观评价 | 证据内容客观描述+质证意见分离 | 混淆导致不利自认 |
| WR-04 | **不替代律师判断** | "建议""供参考" | "建议质证时关注XX""可考虑补充YY证据" | 替代判断违反律师法 |
| WR-05 | **法条引用须标注来源** | 全称+条号+三标注 | 《中华人民共和国商标法》第六十四条[✅已核实] | 引用错误损害可信度 |
| WR-06 | **金额/日期须标注计算依据** | 注明计算公式或法律依据 | 举证责任法条标注依据 | 无依据数字构成虚假陈述 |
| WR-07 | **不编造法条或判例** | 不确定时标注[需核实] | 法条标注[📋需核实] | 编造是最严重的专业事故 |
| WR-08 | **不提供胜诉保证** | 禁止"必胜""一定能" | 不得出现"质证一定能成功" | 违反律师执业规范 |
| WR-09 | **保守陈述优于激进** | 选保守者 | "不足以证明"而非"完全不真实" | 激进表述易被反噬 |
| WR-10 | **避免不利自认** | 不承认不利事实 | 不得出现"对真实性无异议""该证据可以采信" | 不利自认损害当事人利益 |
| WR-11 | **文书风格统一，禁止混搭** | 选定一种风格贯彻到底 | 选定**四性逐项分析+商标特有要点增强风格** | 混搭导致质证意见"四不像" |

**偏离项**：[无偏离]
