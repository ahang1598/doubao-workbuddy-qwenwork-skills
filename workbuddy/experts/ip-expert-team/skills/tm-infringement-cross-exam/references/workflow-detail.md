# 工作流详细步骤 — tm-infringement-cross-exam

> **所属技能**：tm-infringement-cross-exam | **文件角色**：工作流定义 | **版本**：v1.1.0

---

## Phase 1：输入验证 + 证据清单补全

### 1.1 必填字段检查（含降级分级）

| 降级等级 | 缺失字段 | 触发行为 |
|---------|---------|---------|
| L3 重度 | `plaintiff_mark` 或 `defendant_evidence` | → SOFT_DEGRADED：仅输出质证骨架+法定要素清单 |
| L2 中度 | 证据类型不明确或抗辩类型未识别 | → 输出四性框架+占位标注 |
| L1 轻度 | `cross_exam_focus` 或 `court_name` | → 完整质证意见+缺失处标注"[待补充]" |
| L0 完整 | 所有必填参数齐全 | → 完整质证意见+撰写指引+举证责任提示 |

### 1.2 缺失信息补全

| 缺失项 | 交互问题 | 降级策略 |
|--------|---------|---------|
| 原告商标注册日/申请日 | "在先使用质证需要原告商标申请日，请提供" | 标注"[需律师补充时间线]" |
| 证据类型不明确 | "证据{XX}的具体类型是？" | 归入 `other` |
| 抗辩类型未指定 | 自动从证据内容和证明目的推断 | 全部标注[待律师确认] |

### 1.3 证据编号

- 统一编号：`DE-01`, `DE-02`, ...
- 按被告证据清单顺序编号

## Phase 2：证据分类 + 抗辩类型识别

### 2.1 证据分类

| 分组 | 包含类型 | 质证侧重点 |
|------|---------|-----------|
| 公证类 | notarized_webpage, notarized_purchase | 公证程序+封存+时间 |
| 商务类 | invoice_receipt, contract, business_license, sales_record | 真实性+关联性 |
| 对比类 | product_photo | 比对范围+展示方式 |
| 商标类 | trademark_cert, use_evidence | 时间线+使用性质 |
| 知名度类 | fame_evidence | 来源+统计口径+覆盖范围 |
| 其他类 | expert_opinion, witness_statement, other | 按具体类型分析 |

### 2.2 抗辩类型识别

| 抗辩类型 | 识别关键词 | 关联证据类型 | 质证切入点 |
|---------|-----------|-------------|---------|
| 合法来源 | "合法取得""正规渠道""进货""供货商" | invoice_receipt, contract, business_license | 进货渠道+合理注意义务+可追溯性 |
| 在先使用 | "在先使用""早于""先用权" | use_evidence, trademark_cert | 使用时间线+使用范围+"有一定影响" |
| 不近似 | "不近似""不相同""区别""差异" | product_photo | 音形义三维比对+整体比对+选择性忽略 |
| 三年不使用 | "未使用""三年不使用""撤销" | notarized_webpage | 搜索方式合理性+起算时间+正当理由 |

### 2.3 关联技能输出检查

| 输出来源 | 检查项 | 处理 |
|---------|--------|------|
| B1(tm-infringement-comparison) | 商标近似判断结论 | 如有→引用于不近似抗辩质证 |
| A6(tm-damage-calc) | 赔偿计算结果 | 如有→引用于赔偿相关证据质证 |

## Phase 3：四性逐项分析（核心 Phase）

### 3.1 分析顺序

```
真实性 → 合法性 → 关联性 → 证明力
   ↓         ↓         ↓         ↓
  基础      程序      方向      效力
  (伪证     (取证     (与争议    (能否
   则停)    合法性)   焦点关系)  证明主张)
```

### 3.2 真实性分析模板

```
前提：该证据的内容为{摘要}
推理：{审查真实性的事实依据——签章/日期/关联性/矛盾点}
结论：{真实性评价——真实/存疑/不真实}
```

**商标案件常见真实性审查要点**：

| 证据类型 | 审查要点 |
|---------|---------|
| 网页公证 | 公证时间是否在争议期间+页面是否完整+是否体现网址 |
| 购买公证 | 购买过程是否完整记录+物品封存是否规范+公证人员是否全程在场 |
| 进货单/收据 | 是否有供货方签章+金额是否合理+日期是否连贯 |
| 销售记录 | 是否为第三方平台数据+能否核实真实性+是否关联到被告 |
| 产品对比图 | 拍摄条件是否一致+是否同比例展示+是否选择性拍摄 |
| 使用证据 | 形成时间是否可核实+是否为商标性使用+使用范围 |

### 3.3 合法性分析模板

```
前提：该证据的取证方式为{方式}
推理：{审查取证程序的合法性}
结论：{合法性评价——合法/程序瑕疵/非法}
```

### 3.4 关联性分析模板

```
前提：被告以该证据证明{目的}
推理：{该证据与争议焦点的关系——是否相关+相关程度}
结论：{关联性评价——强关联/弱关联/无关联}
```

### 3.5 证明力分析模板

```
前提：该证据拟证明{被告主张}
推理：{即使证据可采，其能否充分证明被告主张——有无其他解释/是否需要补强}
结论：{证明力评价——充分/不足/极弱}
```

### 3.6 商标特有质证要点（4类抗辩）

**每类含：质证切入点+反驳要点+法律依据**

| 抗辩类型 | 质证切入点 | 反驳要点 | 法律依据 |
|---------|-----------|---------|---------|
| **合法来源** | 进货渠道+价格合理性+供货方资质+合理注意义务+可追溯性 | 渠道不正规/价格异常/供货方无资质/未尽注意义务/信息不可追溯 | 商标法第64条[✅已核实] |
| **在先使用** | 使用时间早于申请日+使用范围+"有一定影响"+商标性使用 | 时间晚于申请日/范围不符/未达"有一定影响"/描述性使用 | 商标法第59条第3款[✅已核实] |
| **不近似** | 音形义三维比对+整体比对+相关公众标准+选择性展示 | 比对不完整/拆分比对/忽略相似点/展示方式不客观 | 商标民事纠纷解释第9-10条[✅已核实] |
| **三年不使用** | 搜索方式合理性+起算时间+正当理由+使用证据覆盖 | 仅网络搜索不能证明未使用/起算时间错误/有正当理由 | 商标法第49条第2款[✅已核实] |

### 3.7 举证责任意识嵌入

在四性分析后，对每项证据增加举证责任提示：

```
举证责任提示：
- 被告对该证据的举证是否充分？{是/否+说明}
- 己方是否需要补强反证？{是/否+建议补强方向}
```

## Phase 4：质证策略总结 + 输出质检

### 4.1 质证策略总结

| 步骤 | 任务 |
|------|------|
| 4.1.1 | 评估被告抗辩体系整体强度（证据链完整性） |
| 4.1.2 | 识别证据间印证与矛盾 |
| 4.1.3 | 按薄弱程度排序质证策略（先攻最弱） |
| 4.1.4 | 利用举证责任规则提示被告举证不足 |
| 4.1.5 | 己方举证责任提示——提醒律师补强己方证据链 |
| 4.1.6 | 引用关联技能输出（如有） |

### 4.2 证据要点速查卡

从每项证据的四性分析中提取核心质证要点，生成速查卡：
- 编号+证据名称
- 一句话核心要点
- 建议策略方向

### 4.3 输出质检（20+项）

#### 4.3.1 WR 红线检查（11项）

| # | 检查项 | 合格标准 |
|---|--------|---------|
| WR-01 | 无绝对化表述 | 0处"必然""一定" |
| WR-02 | 结论留边界 | 建议性表述 |
| WR-03 | 事实与意见分离 | 质证事实+推理分离 |
