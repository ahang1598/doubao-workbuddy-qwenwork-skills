# 商标侵权质证提纲

> **核心定位**：为商标侵权诉讼原告律师生成质证提纲——针对被告提交的每项证据，按四性（真实性→合法性→关联性→证明力）逐项质证，内置商标案件特有质证要点（在先使用时间审查/合法来源渠道审查/不近似比对范围审查/三年不使用证据强度审查），含举证责任意识——提醒律师注意己方举证责任，不要只攻击对方而忽略补强己方。
>
> **蓝本依据**：商标法第64条（合法来源免赔）[✅已核实] + 第59条第3款（在先使用抗辩）[✅已核实] + 商标民事纠纷解释第9-10条（近似认定标准）[✅已核实] + 民诉法第67条（举证责任）[📋需核实]
>
> **隐性知识**：商标侵权质证的核心**不是泛泛质疑**——而是精准打击被告抗辩的证据基础。被告"在先使用"证据要看时间线是否早于原告注册日，"合法来源"要看进货渠道是否正规+合理注意义务，"不近似"要看比对范围是否选择性忽略相似点。同时，质证不是只攻击对方——己方也有举证责任，质证时需注意补强己方证据链。
>
> 本技能遵循 compiler/ssot.md §17（SSOT）

## 1. 法律合规与风险声明

1. **管辖范围**：中国大陆（不含港澳台）。涉外商标案件适用特殊规则时标注"[需核实涉外因素]"
2. **输出性质**：所有输出为**质证草稿**，仅供律师审核确认，不直接用于庭审
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **举证责任**：商标侵权案件中原告对侵权事实承担举证责任，被告对合法来源/在先使用等抗辩承担举证责任——质证时应利用举证责任分配，同时提醒律师注意补强己方证据
5. **知识截止**：法律依据基于截至2026-06-01的法律法规
6. **文书风格声明**：WR-11 选定**四性逐项分析+商标特有要点增强风格**（基于3篇以上商标侵权质证实务经验交叉验证），贯彻到底，禁止混搭笼统质疑式或纯罗列式
7. **免责声明**：本技能产物为AI辅助工具生成，不构成法律意见，使用者应结合具体案情独立判断

## 2. 快速开始

**一句话定位**：针对被告证据编制商标侵权质证意见，按四性逐项分析，内置商标特有4类抗辩质证要点，含举证责任意识提醒。

**最小示例**：

```
用户输入：商标侵权案，被告提交了3份证据：进货单（合法来源抗辩）、产品对比图（不近似抗辩）、销售记录
预期输出：质证意见表，含逐项证据四性分析+商标特有质证要点+反驳要点+法律依据
```

## 5. 适用边界

**适用范围**：
- 商标侵权诉讼中针对被告证据的质证提纲编制
- 律师参考使用，须结合庭审实际调整
- 证据交换后/庭审前的质证准备阶段

**不适用范围**：
- 商标侵权庭审全流程提纲（→ `tm-infringement-trial-prep`）
- 商标侵权民事起诉状起草（→ `tm-infringement-complaint`）
- 刑事案件质证/非法证据排除申请（→ 对应领域技能）
- 行政程序口审（→ `tm-oral-hearing-prep`）

**硬拒绝条件**：
1. 缺少`defendant_evidence`（无被告证据可质证） → 拒绝，提示补充被告证据清单
2. 诱导性要求保证"质证必胜" → 拒绝，输出风险声明
3. 要求直接替代律师出庭质证 → 拒绝，提示须律师结合庭审实际调整
4. 非商标侵权质证（刑事案件/专利侵权/非诉讼质证） → 拒绝，路由到对应技能

## 6. 常见问题

**Q1**：被告"合法来源"抗辩的质证核心是什么？

**答**：合法来源抗辩需同时满足两个条件（《商标法》第64条第2款）[✅已核实]：(1)不知道是侵权商品；(2)商品是自己合法取得+说明提供者。质证核心是**合理注意义务**——即使进货单真实，如果商品上明确标注了原告商标、进货价格明显低于市场价、供货方无资质，被告仍应知道是侵权商品，不构成"合法来源"。

**Q2**：被告"在先使用"抗辩怎么审查时间线？

**答**：《商标法》第59条第3款[✅已核实]规定的在先使用须满足：(1)在原告商标注册日前已使用；(2)在原告商标申请日前已在同一种商品或类似商品上使用；(3)有一定影响。质证时重点审查：使用证据的形成时间是否早于原告**申请日**（不是注册日——注意法条用的是"申请日前"）；使用范围是否与原告商标核定商品相同或类似；是否达到"有一定影响"的程度。

**Q3**：质证时如何注意己方举证责任？

**答**：质证不是只攻击对方证据——原告对侵权事实承担举证责任。质证时需注意：(1)如果被告证据反而支持原告主张，应指出并利用；(2)质证后需评估己方证据链是否完整；(3)如果己方证据不足，在质证策略中提示补强；(4)质证意见中应标注"建议补充XX证据"。

**Q4**：被告"三年不使用"抗辩的证据怎么审查？

**答**：《商标法》第49条第2款[✅已核实]规定的"三年不使用"是撤销注册商标的条件，不是侵权抗辩。但被告可能以此主张原告商标未实际使用故无损失。质证重点：(1)三年起算时间是否正确；(2)原告使用证据的时间段是否覆盖争议期间；(3)网络搜索截图是否能证明不使用（通常不能——只能证明搜索时未发现，不能证明未使用）；(4)是否存在正当理由未使用。
