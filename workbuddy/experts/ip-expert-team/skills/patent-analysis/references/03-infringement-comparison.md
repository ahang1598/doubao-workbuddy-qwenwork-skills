# 场景三：产品-专利侵权比对

## 适用情形

- 判断某款产品是否落入专利保护范围
- 收到侵权警告函后的初步研判
- 产品正式上市前的风险排查

- 专利文件
- 产品描述 / 产品图片 / 产品技术方案
- 可选：被控侵权一方的基本信息

## 常见错误

| 错误做法 | 正确做法 |
|----------|----------|
| 将从属权利要求的附加特征误作侵权成立的必要条件 | 仅以独立权利要求1的技术特征作为判断依据 |
| 以“产品不具备权利要求2的某个特征”为由认定不侵权 | 即便缺少权2特征，只要权1的全部特征齐备，即构成侵权 |
| 把“技术方案”与“保护范围”混为一谈 | 保护范围以权利要求为准，而非说明书中的实施例 |
