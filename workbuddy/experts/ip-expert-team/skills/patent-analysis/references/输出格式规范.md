# 输出格式规范

> 本文件融入《Richee 输出规范》word-report Profile（v1.1.0）。运行时不读取、不依赖规范库。
> 规则采用记录见同目录 `输出规范融合记录.md`。

## 1. 支持格式

| 交付物 | Profile | 文件命名 |
|---|---|---|
| 对话预览 | markdown-preview | 不落盘（对话内 Markdown） |
| 正式分析报告 | word-report | `{简称}_{主题}_{YYYYMMDD}.docx` |

- 简称：本技能 `专利分析`（patent-analysis）。
- 主题：用简短名词概括，如 `单专利要点`、`侵权比对`、`FTO评估`。
- 日期：报告生成日，`YYYYMMDD`。

## 2. 通用红线（GATE，不可放宽）

- **免责声明**：正式报告必须在标题之后、正文之前放置 AI 辅助 + 仅供参考 + 不构成正式法律意见的声明（见第 4 节，紧贴标题）。
- **禁止绝对化法律结论**：不得使用「保证胜诉、必然、绝对、稳赢、绝无风险、完全合规、一定合法、毫无疑问」等措辞；改用「初步分析、建议、可能、存在风险」等。
- **风险必须文字+颜色**：风险等级同时显示文字「高/中/低/待补充」与底色，不得只靠颜色。
- **封闭标签集**：只使用第 5 节声明的标签集合，不得运行时自创。
- **无 emoji**：Word 全文不得含 emoji；状态、提示一律改为文字标签。
- **表格宽度**：表格总宽不得超过页面内容区，并留约 2mm 安全余量（由模板与滤镜保证）。

## 3. 版式（word-report 推荐版式）

- A4 纸；正文 **1.5 倍行距**；页边距上下左右 2.54cm。
- 中文字体 **微软雅黑**（标准优先 PingFang SC，Windows 目标环境缺失，用其回退项微软雅黑）；等宽 Consolas。
- 主体**黑白灰**；绿色仅用于一级标题线、三级标题等**小面积强调**。
- **表头黑底白字**，正文白底细灰线，数据单元格上下居中。
- 风险等级：高=浅红底深红字、中=浅琥珀底深琥珀字、低=浅绿底深绿字、待补充=中性灰底灰字。

## 4. Markdown → docx 契约

正式报告由 pandoc 渲染。你**只写 Markdown + 跑一条命令**，不写任何 python-docx / 样式代码。

### 渲染命令（在 skill 根目录执行）

```bash
pandoc 输入.md -o "{简称}_{主题}_{YYYYMMDD}.docx" \
  --reference-doc=assets/richee-reference.docx \
  --lua-filter=scripts/richee.lua \
  --from markdown+east_asian_line_breaks
```

> reader **必须是 `markdown`，严禁改成 `gfm`**——gfm 不解析 `:::` fenced div 与 `[x]{.class}`，会导致免责框与风险胶囊静默失效。`east_asian_line_breaks` 保证中文换行不被吞成空格。

### 文档骨架（严格按此顺序）

```markdown
---
title: 报告标题
---

::: {custom-style="Disclaimer"}
本报告由 AI 辅助生成，仅供参考，不构成正式法律意见。实际法律判断应由具有执业资格的律师作出。
:::

# 一级标题

正文段落……

## 二级标题

### 三级标题
```

要点：
- **标题**用 YAML `title:`（渲染为文档标题样式）；**不要**写额外 YAML 字段。
- **免责声明**紧跟标题，用 `::: {custom-style="Disclaimer"}`，文字必须含「AI」与「仅供参考/不构成正式法律意见」之一。
- 标题层级用 `#`/`##`/`###`，不要在正文用 `#` 放大字号。
- **风险等级**用胶囊：`[高风险]{.tag .risk-high}` / `[中风险]{.tag .risk-mid}` / `[低风险]{.tag .risk-low}` / `[待补充]{.tag .risk-pending}`（文字与底色同时存在）。
- **表格**用管道表（自动套用黑表头样式）；不得嵌套表格。
- **分页**用 raw openxml 块（整段照抄）：
  ```` ```{=openxml}
  <w:p><w:r><w:br w:type="page"/></w:r></w:p>
  ``` ````
- 完整示例见 `examples/markdown-example.md`。

### 禁止

- emoji、HTML 内联样式、自创 custom-style 名（拼错会静默退化为正文）。
- 绝对化法律结论措辞。
- 风险只上色不带文字。

## 5. 封闭标签集（OUT-COM-005）

本技能声明的标签集合，运行时不得超出：

| 标签类型 | 取值 | 写法 |
|---|---|---|
| 风险等级 | 高风险 / 中风险 / 低风险 / 待补充 | `[高风险]{.tag .risk-high}` 等（见上） |
| 法规引用 | 《法规名》第X条 | 行内纯文本，如「《专利法》第十一条」 |
| 段落样式 | Disclaimer | `::: {custom-style="Disclaimer"}` |

其余（标题、正文、表格、列表、行内代码）由 Markdown 语法触发 pandoc 自动映射样式，不要手写 custom-style。

## 6. 生成与验收

- 生成脚本：`scripts/build_reference.py`（生成 `assets/richee-reference.docx`，开发机运行）。
- 运行时滤镜：`scripts/richee.lua`（风险胶囊）。
- 代表性样例：`examples/markdown-example.md` → `examples/{简称}_{主题}_{YYYYMMDD}.docx`。
- 自动校验：由开发或评审从工作区根目录，用输出规范库自带的 `validate_skill_output.py` 校验本技能目录与其 `examples/`（该校验脚本不属于本技能运行时依赖）。
- 人工目检：首页（标题+免责）、一个典型内容页、一个含风险胶囊/表格的页面。
