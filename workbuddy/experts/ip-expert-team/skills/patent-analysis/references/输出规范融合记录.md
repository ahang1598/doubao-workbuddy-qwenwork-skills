## 融合位置

| 规则组 | 本技能实现位置 |
|---|---|
| 输出选择与安全红线（OUT-COM-*） | `SKILL.md` 输出格式段 |
| Markdown/Word 版式与契约 | `references/输出格式规范.md` |
| Word 模板（黑表头、1.5 行距、字体） | `assets/richee-reference.docx`（由 `scripts/build_reference.py` 生成） |
| 风险胶囊生成逻辑（OUT-COM-004 颜色+文字） | `scripts/richee.lua` |
| 表宽安全余量（OUT-WORD-003） | `assets/richee-reference.docx` 页边距 + `scripts/richee.lua` |
| 代表性样例 | `examples/` |

## 规则落实说明

- **OUT-COM-001**：报告标题后紧接 `Disclaimer` 段，含「AI 辅助」「仅供参考/不构成正式法律意见」。
- **OUT-COM-003**：契约明列禁用绝对化措辞；样例与说明均回避。
- **OUT-COM-004**：风险胶囊 `[高风险]{.tag .risk-high}` 等同时承载文字与底色。
- **OUT-COM-005**：封闭标签集见 `references/输出格式规范.md` 第 5 节（风险四档 + 法规引用形式 + Disclaimer）。
- **OUT-WORD-001**：契约禁止 emoji；模板与样例无 emoji。
- **OUT-WORD-003**：页边距 2.54cm，pandoc 表与滤镜表均留约 2mm 余量（样例实测通过）。
- **OUT-WORD-004/005**：正文 1.5 倍行距；主体黑白灰，绿色仅用于一级标题线与三级标题；表头黑底白字。
