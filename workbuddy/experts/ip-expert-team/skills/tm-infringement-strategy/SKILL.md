# 商标侵权诉讼策略制定

> **核心定位**：在证据和侵权分析基础上确定诉讼目标、选择管辖法院、设计诉请组合、预判五类抗辩，输出诉讼策略方案。
>
> **蓝本依据**：商标法第57条（侵权行为认定）[✅已核实] + 第63条（赔偿4路径）[✅已核实] + 第64条（三年不使用/合法来源抗辩）[✅已核实] + 第59条（正当使用/在先使用抗辩）[✅已核实]
>
> 本技能遵循 compiler/ssot.md §17（SSOT）

---

## 1. 法律合规与风险声明

<!-- Copyright © 深圳市法大大网络科技有限公司 版权所有 | Author: 法大大法律AI产品线 -->

1. **管辖范围**：中国大陆（不含港澳台）。商标侵权诉讼由知识产权法院/法庭管辖
2. **输出性质**：所有输出为**策略方案**，仅供参考，不构成法律意见
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **上游依赖**：必需 tm-infringement-comparison 侵权比对结论；可选 tm-damage-calc 赔偿测算结论
5. **知识截止**：法律依据基于截至2026-06-01的法律法规
6. **SSOT引用契约**：法条引用遵循三标注体系[✅已核实]/[📋需核实]/[⚠️存疑]，版本号以 `.version` 为单一事实源
7. **免责声明**：本技能产物为AI辅助工具生成，不构成法律意见，使用者应结合具体案情独立判断

## 2. 快速开始

**一句话定位**：在侵权分析基础上确定诉讼目标、选择管辖法院、设计诉请组合、预判五类抗辩，输出诉讼策略方案。

**最小示例**：

```
用户输入：客户"星辉科技"拥有第25类"星辉"注册商标，发现"新晖商行"在同类商品上使用"星晖"标识，侵权比对已完成（近似成立），需要制定诉讼策略
预期输出：目录索引+管辖法院推荐+诉请组合（停止侵权+赔偿+合理费用）+五类抗辩预判+三维风险矩阵+时间表
```

## 3. 核心参数与法律约束

| 参数 | 类型 | 法律含义 | 必填 | 降级等级 |
|------|------|---------|------|---------|
| `infringement_analysis` | object | 侵权比对结论（来自tm-infringement-comparison） | 是 | L3(强引用) |
| `trademark_info` | object | 权利商标信息 | 是 | L3 |
| `opponent_info` | object | 被告信息（住所/经营地/财产线索） | 是 | L3 |
| `client_priority` | enum | 客户优先目标（停止侵权/赔偿最大化/快速解决/全面维权） | 是 | L3 |
| `damage_estimate` | object | 赔偿测算结论（来自tm-damage-calc，可选） | 否 | L1 |
| `evidence_status` | string | 现有证据充分程度 | 否 | L1 |

**核心法律依据**：见 `references/legal-references.md`

**工作流概览**：

| Phase | 任务 | 风险 | 关键门控 |
|-------|------|------|---------|
| **P1** | 输入验证+侵权前提确认 | L1 | 侵权比对结论必须为"近似" |
| **P2** | 管辖法院分析与选择 | L2 | 含知产法院专属管辖规则 |
| **P3** | 诉请组合设计 | L2 | 赔偿4路径按法定顺序 |
| **P4** | 五类抗辩预判与应对+保全评估 | L2 | 三年不使用🔴必须预判 |
| **P5** | 三维风险矩阵+时间表+四输出架构渲染 | L2 | 三维风险全评估 |
| **P6** | 质量检查（20+项） | L3 | WR红线+L1/L2/L3+法条标注+术语一致性 |

> 详细步骤见 `references/workflow-detail.md`

**降级机制**：SOFT_DEGRADED（C+D+G 最小骨架），详见 `rules/risk-framework.md`

**四输出架构**：

| 输出 | 说明 | 条件 |
|------|------|------|
| 诉讼策略方案 | 管辖+诉请+抗辩预判+风险矩阵+时间表 | 始终输出 |

## 5. 适用边界

**适用范围**：
- 商标侵权诉讼策略的制定（管辖/诉请/抗辩预判/风险矩阵）
- 律师参考使用，不直接替代律师制定诉讼决策
- 侵权比对完成后、起诉前的策略规划阶段

**不适用范围**：
- 商标侵权比对分析（→ `tm-infringement-comparison`）
- 商标侵权民事起诉状起草（→ `tm-infringement-complaint`）
- 赔偿金额精确计算（→ `tm-damage-calc`）
- 商标行政争议策略（异议/无效/驳回复审）

**硬拒绝条件**：
1. 侵权比对结论为"不近似" → 拒绝制定诉讼策略，提示无侵权基础
2. 诱导性要求保证"诉讼必胜"或"确定胜率" → 拒绝，输出风险声明
3. 要求直接替代律师制定诉讼决策 → 拒绝，提示仅供参考
4. 非商标侵权诉讼策略（行政争议/非商标纠纷） → 拒绝，路由到对应技能

## 6. 常见问题

**Q1**：网购收货地能否作为管辖连接点？

**答**：可以。最高人民法院在多项裁判中确认，通过网络购买侵权商品的，收货地可作为侵权结果发生地，构成管辖连接点。但需注意部分法院对此持不同态度，需结合具体法院的裁判倾向。

**Q2**：4种赔偿计算路径如何选择？

**答**：按法定优先级排列：(1)权利人实际损失→(2)侵权人获利→(3)商标许可使用费倍数→(4)法定赔偿。建议主位主张(1)或(2)，备位主张(4)。举证难度递减，但赔偿金额也可能递减。

**Q3**：对方主张三年不使用抗辩怎么办？

**答**：根据商标法第64条第1款，注册商标专用权人不能证明此前三年内已使用该注册商标的，被控侵权人不承担赔偿责任。这是本技能必须预判的关键抗辩——需在策略中提前准备使用证据，或在诉请中预置应对方案。注意：此抗辩仅免除赔偿责任，不免除停止侵权责任。
