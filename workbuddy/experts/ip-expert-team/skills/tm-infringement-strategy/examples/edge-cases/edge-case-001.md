# 边界示例001 — 三年不使用抗辩风险场景

## 输入

```
infringement_analysis:
  similarity_conclusion: 近似
  confusion_possibility: 高
  goods_similarity: 相同
trademark_info:
  trademark_text: 星辉
  nice_class: 25
  registration_date: 2019-06-01
opponent_info:
  name: 某贸易公司
  domicile: 广东省深圳市
client_priority: 赔偿最大化
evidence_status: 不足（注册满5年但近3年使用证据缺失）
```

## 输出要点

### 🔴 核心风险：三年不使用抗辩

商标法第64条第1款：注册商标专用权人不能证明此前三年内已使用该注册商标的，被控侵权人不承担赔偿责任。

**本案风险**：注册日期2019年，已满3年。如无法提供近3年使用证据，被告主张三年不使用抗辩，则可能仅获得停止侵权判决，无法获得赔偿。

### 应对策略

1. **紧急收集使用证据**（P0优先）：
   - 销售合同+发票（含商标标识）
   - 广告投放记录
   - 产品包装+标签
   - 网店销售记录+评价
   - 许可他人使用协议

2. **诉请调整**：
   - 主位仍主张赔偿（附使用证据）
   - 增加备位：即使赔偿被驳回，仍坚持停止侵权诉请
   - 注意：三年不使用抗辩仅免除赔偿责任，不免除停止侵权责任

3. **证据保全**：
   - 如使用证据即将灭失，考虑申请证据保全
   - 网店销售记录公证（防止下架后无法取证）

### 风险矩阵更新

| 风险维度 | 等级 | 说明 |
|---------|------|------|
| 证据链 | 🔴高 | 使用证据缺失=赔偿可能被驳回 |
| 法律争议 | 低 | 近似判断明确 |
| 执行 | 中 | 停止侵权可执行，赔偿可能为零 |

### 时间表调整

- 立即启动使用证据收集（2-4周）
- 证据完成后再决定是否起诉
- 如无法补齐使用证据，调整策略为"以停止侵权为主"
