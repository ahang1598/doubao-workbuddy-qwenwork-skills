## Phase 1：输入验证与侵权前提确认

### 1.1 必填字段检查（含降级分级）

| 降级等级 | 缺失字段 | 触发行为 |
|---------|---------|---------|
| L3 重度 | `infringement_analysis` 或 `trademark_info` 或 `opponent_info` 或 `client_priority` | → 无法制定策略，建议先行侵权比对 |
| L2 中度 | `opponent_info.domicile` | → 管辖无法确定，输出策略框架+占位 |
| L1 轻度 | `damage_estimate` 或 `evidence_status` | → 完整策略+简化版赔偿估算 |
| L0 完整 | 所有必填+推荐参数齐全 | → 完整策略方案+四输出架构 |

### 1.2 侵权前提确认（门控）

```
if similarity_conclusion == "近似" + goods_similarity in ["相同", "类似"]:
    → 侵权基础确立，继续制定策略
elif similarity_conclusion == "不近似":
    → ⚠️侵权基础薄弱，建议补充混淆可能性证据
    → 如用户坚持→标注不确定性后继续
elif similarity_conclusion == "存疑":
    → 标注不确定性，策略方案中重点预判"不近似抗辩"
```

### 1.3 信息补全交互（≤3轮）

| 优先级 | 缺失信息 | 默认提示 |
|--------|---------|---------|
| P0 | 侵权比对结论 | "请提供侵权比对分析结论（来自tm-infringement-comparison）" |
| P1 | 被告住所/经营地 | "请提供被告住所地或侵权行为地，以便确定管辖法院" |
| P2 | 客户优先目标 | "请明确客户优先目标（停止侵权/赔偿最大化/快速解决/全面维权）" |

## Phase 2：管辖法院分析与选择

### 2.1 管辖连接点梳理

| 连接点 | 法律依据 | 说明 |
|--------|---------|------|
| 被告住所地 | 民诉法第22条 | 管辖异议风险最低 |
| 侵权行为实施地 | 民诉法第29条 | 侵权行为发生地 |
| 侵权结果发生地 | 民诉法第29条 | 含网购收货地 |
| 知识产权法院专属 | 知产法院管辖规定 | 专利/技术秘密/驰名商标等 |

### 2.2 管辖法院推荐

推荐2-3个候选法院+推荐理由+利弊分析

### 2.3 简化版管辖分析

当tm-jurisdiction-analysis未就绪时：
- 优先推荐被告住所地法院（管辖异议风险最低）
- 网络销售案件可推荐收货地法院（原告便利）
- ⚠️标注："建议使用tm-jurisdiction-analysis做详细管辖分析"

## Phase 3：诉请组合设计

### 3.1 基础诉请

- 停止侵权+赔偿损失+合理费用

### 3.2 赔偿路径选择（按法定顺序）

| 客户优先目标 | 主位赔偿路径 | 备位赔偿路径 |
|-------------|------------|------------|
| 赔偿最大化 | 实际损失+惩罚性赔偿 | 侵权获利+惩罚性赔偿→法定赔偿 |
| 全面维权 | 实际损失/侵权获利+惩罚性赔偿 | 法定赔偿 |
| 快速解决 | 法定赔偿 | — |
| 停止侵权为主 | 法定赔偿（可适度让步） | — |

### 3.3 附加诉请评估

| 诉请 | 条件 | 法律依据 |
|------|------|---------|
| 消除影响 | 侵权影响范围较大 | 商标法第60条 |
| 销毁侵权商品 | 侵权商品仍存在 | 商标法第60条 |
| 惩罚性赔偿 | 恶意侵权 | 商标法第63条第2款 |

### 3.4 主位+备位方案

- 主位：最优诉请组合+法律依据
- 备位：举证不足时的降级诉请

## Phase 4：五类抗辩预判与应对+保全评估

### 4.1 五类抗辩预判（🔴核心组件）

| 抗辩类型 | 法律依据 | 触发条件 | 回应策略 | 证据要求 |
|---------|---------|---------|---------|---------|
| 不近似抗辩 | 商标法第57条 | 被告标识与原告商标差异明显 | 强化音形义论证+消费者调查 | 近似论证+混淆证据 |
| 正当使用抗辩 | 商标法第59条第1款 | 被告主张描述性使用 | 证明非描述性+知名度 | 非描述性证据+知名度证据 |
| 在先使用抗辩 | 商标法第59条第3款 | 被告在原告注册前已使用 | 质疑原有范围+证明注册在先 | 注册在先证据+使用范围证据 |
| 三年不使用抗辩 | 商标法第64条第1款 | 原告商标注册满3年 | 🔴提前准备使用证据 | 此前3年使用证据 |
| 合法来源抗辩 | 商标法第64条第2款 | 销售者主张不知是侵权商品 | 证明明知/应知+追加上游 | 明知应知证据+上游供应商信息 |

### 4.2 保全评估

| 保全类型 | 条件 | 风险 |
|---------|------|------|
| 诉前禁令 | 持续侵权+难以弥补损害+担保能力 | 证明"难以弥补"困难→被驳回风险 |
| 财产保全 | 转移风险+保全金额+财产线索 | 超额保全→反赔风险 |
| 证据保全 | 证据灭失风险 | 保全后仍需诉讼确认 |

## Phase 5：三维风险矩阵+时间表+四输出架构渲染

### 5.1 三维风险评估矩阵

| 风险维度 | 评估内容 | 等级 | 应对措施 | 类案参考 |
|---------|---------|------|---------|---------|
| 证据链风险 | 核心证据充分性+取证难度 | 高/中/低 | 补强证据/备位诉请 | {如提及类案，填列案号+裁判要旨} |
| 法律争议风险 | 近似判断争议+抗辩成功率 | 高/中/低 | 强化论证/调整策略 | {如提及类案，填列案号+裁判要旨} |
| 执行风险 | 偿付能力+财产线索+转移风险 | 高/中/低 | 财产保全/追加被执行人 | {如提及类案，填列案号+裁判要旨} |

> **类案引用规则**：若风险评估中引用类案支撑风险等级判断，须在"类案参考"列对应位置注明案号、法院、裁判要旨摘要。无类案引用则标注"—"。

### 5.2 诉讼时间表（预估）

- 立案1-2周→答辩15-30日→证据交换1-3月→开庭3-6月→判决6-12月→总计约12-18月
- ⚠️标注"预估，受法院排期影响"

## SOFT_DEGRADED 骨架

> 遵循 `base/shared/risk-rules-common.md` C+D+G 最小骨架

### 降级分层 L0-L3

| 等级 | 条件 | 输出范围 |
|------|------|---------|
| **L0 完整** | 所有必填参数齐全 | 完整策略方案 + 五类抗辩预判表 + 三维风险矩阵 + 管辖对比分析 |
| **L1 轻度** | 缺少 damage_estimate | 完整策略 + 简化版赔偿估算 |
| **L2 中度** | 缺少被告住所地 | 策略框架 + 管辖占位标注 |
| **L3 重度→SOFT_DEGRADED** | 缺少侵权比对结论 | 仅策略骨架 + 建议先行比对 |

### SOFT_DEGRADED 最小骨架（C + D + G）

| 块 | 内容 |
|----|------|
| **C) 待补充事实清单** | 缺失的侵权比对结论/被告信息/客户目标 + 影响程度 + 建议补充方式 |
| **D) 治理与禁区声明** | 输出为最小骨架，不构成完整策略；禁止保证胜诉/禁止确定赔偿金额 |
| **G) 下一步行动** | 用户需完成侵权比对/提供被告信息/明确客户目标 |
