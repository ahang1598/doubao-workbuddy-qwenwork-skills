## 二、商标侵权赔偿测算特有风险规则

### 2.1 四路径递进风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 四路径并列选择 | 误将递进关系当并列选择 | 强制按优先级1→2→3→4排列，标注"优先级递进" |
| 跳过优先路径 | 有路径1数据时直接跳到路径4 | Phase 2 必须按优先级逐条评估 |
| 法定赔偿默认500万 | 500万是上限非默认值 | 标注"法定赔偿上限500万，法院根据侵权情节酌定" |
| 惩罚性与法定并用 | 选择法定赔偿路径时叠加惩罚性 | 标注"法定赔偿路径不叠加惩罚性赔偿" |

### 2.2 惩罚性赔偿风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 仅因恶意即适用 | 缺少"情节严重"条件 | 强制检查恶意+情节严重双重条件 |
| 合理开支作为基数 | 合理开支不计入惩罚性赔偿基数 | 合理开支独立列明，不作为惩罚性基数 |
| 倍数过高无支撑 | 建议倍数与恶性程度不匹配 | 倍数需与恶意程度和情节严重程度匹配 |
| 基数来源不明 | 未说明基数取自哪条路径 | 标注"惩罚性赔偿基数取自路径X" |

### 2.3 计算精度风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 输出确定金额 | 给出单一确定数字 | 必须输出金额区间 |
| 省略计算依据 | 金额无计算公式支撑 | 每项金额标注计算公式或法律依据 |
| 证据不足仍计算 | 无数据仍给出具体金额 | 证据不足时标注"[待补充]"，给出参考区间 |
| 时间口径错误 | 年度数据直接用于非全年侵权期间 | 强制时间对齐：按实际侵权月数折算，标注"（1-X月）" |
| 金额前后不一致 | 推荐方案/惩罚性/合理开支/各路径的金额在报告不同位置出现矛盾 | Phase 5 强制逐项交叉校验（CX-01~CX-19），不一致则修正后再输出 |

### 2.4 合理开支风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 合理开支混入赔偿基数 | 影响惩罚性赔偿计算 | 合理开支单独列明，独立于赔偿基数 |
| 无凭证费用列出 | 法院可能不支持 | 标注凭证情况，无凭证的标注"待补充凭证" |
| 遗漏常见费用 | 律师费/公证费/调查费/购买费 | 提供完整费用清单模板 |

## 三、SOFT_DEGRADED 降级骨架

> 遵循 `base/shared/risk-rules-common.md` C+D+G 最小骨架

### 降级分层 L0-L3

| 等级 | 条件 | 输出范围 |
|------|------|---------|
| **L0 完整** | 所有计算参数齐全 | 完整测算报告 + 四路径递进 + 惩罚性评估 + 合理开支 + 推荐方案 |
| **L1 轻度** | 缺少部分可选参数 | 完整测算报告，缺失处标注"[待补充]" |
| **L2 中度** | 仅有1-2条路径数据 | 可用路径测算 + 占位标注 + 举证妨碍提示 |
| **L3 重度→SOFT_DEGRADED** | 无任何计算基础数据 | 仅输出赔偿要素清单 + 法定范围 |

### SOFT_DEGRADED 最小骨架（C + D + G）

| 块 | 内容 |
|----|------|
| **C) 待补充事实清单** | 缺失的计算基础数据 + 影响程度 + 建议补充方式 |
| **D) 治理与禁区声明** | 输出为最小骨架，不构成赔偿建议；禁止直接用于诉讼请求 |
| **G) 下一步行动** | 用户需提供财务数据或经营数据以获取具体测算 |

### 降级强度映射

| 强度 | 条件 | 渲染等级 |
|------|------|---------|
| S1 | L3 重度 | 仅 C+D+G，不输出实质计算 |
| S2 | L2 中度 | C+D+G + 可用路径的测算，缺失路径占位标注 |
| S3 | L1 轻度 | 接近完整输出，可选参数处标注"[待补充]" |
