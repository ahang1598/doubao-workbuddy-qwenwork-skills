# 商标侵权赔偿测算方法论

> **所属技能**：tm-damage-calc | **文件角色**：方法论底座 | **版本**：v1.3.0
>
> **输出禁令**：报告中禁止使用任何 emoji。法条标注仅用 `[已核实]/[需核实]/[存疑]`，不得加 emoji 前缀。

## 一、三层理论框架

赔偿测算不是"四选一"，而是三层认知结构的统一体：

### 认知层（Know-What）

**核心问题**：赔偿计算的法律要件是什么？四路径之间的关系是什么？

| 要件 | 内容 |
|------|------|
| 赔偿计算的法律性质 | 侵权损害赔偿，填补权利人因侵权所受损失 |
| 四路径关系 | **优先级递进**，非并列选择——优先原告损失/被告获利→许可费倍数→法定赔偿兜底 |
| 惩罚性赔偿条件 | 须**恶意+情节严重**双重条件，非仅恶意（商标法第63条第1款但书） |
| 合理开支 | 独立于赔偿基数，单独列明（律师费+公证费+调查费+购买费等） |
| 法定赔偿上限 | 500万元（商标法第63条第3款），非默认值 |
| 举证妨碍 | 侵权人不提供账簿→法院可参考权利人主张判定（第63条第2款） |

**常见认知错误**：
- 把四路径当并列选择——"你选哪种？"是错误问法，应按优先级递进
- 惩罚性赔偿仅因恶意——须同时满足"恶意"和"情节严重"
- 法定赔偿500万是默认值——500万是上限，法院根据侵权情节酌定
- 合理开支计入赔偿基数——合理开支单独列明，不作为惩罚性赔偿基数

### 策略层（Know-Why）

**核心问题**：选择哪条计算路径？策略选择的决定因素是什么？

| 证据情况 | 推荐路径 | 策略选择依据 |
|---------|---------|------------|
| 有原告损失财务数据 | 路径1：权利人实际损失 | 优先级最高，法院倾向采纳 |
| 无损失数据但有被告经营数据 | 路径2：侵权人获利 | 第二优先，可申请法院责令提供账簿 |
| 有许可合同 | 路径3：许可使用费倍数 | 第三优先，需证明许可费合理性 |
| 以上均难以确定 | 路径4：法定赔偿 | 兜底适用，500万以下酌定 |

**策略选择的核心原则**：
1. **递进优先而非并列选择**：法院按优先级审查，有路径1数据时不允许直接跳到路径4
2. **证据最充分原则**：法院倾向于选择证据最充分的计算路径
3. **多路径并行准备**：实务中可同时准备多个路径的计算，供律师选择
4. **惩罚性赔偿独立评估**：先确定赔偿基数，再独立评估是否适用惩罚性赔偿

### 表达层（Know-How）

**核心问题**：按所选路径如何输出测算报告？

**选定风格：结构化测算报告风格**（T-calculation 类型，I-Practical 严肃度）

| 风格特征 | 说明 |
|---------|------|
| 输出结构 | 四路径递进测算 + 惩罚性赔偿评估 + 合理开支 + 推荐方案 |
| 数值表达 | 金额**区间**而非确定值，标注计算依据 |
| 法条标注 | 每条法条标注 [已核实]/[需核实]/[存疑] |
| 免责声明 | "须律师审核"+"不构成法律意见"+"最终以法院裁定为准" |

**三层硬约束**：不允许跳过任一层——必须先理解法律要件（认知层），再选择计算路径（策略层），最后输出测算报告（表达层）。

## 二、六操作管线

从客户口语输入到结构化测算报告输出，经过以下六个操作：

### 1. 转化

**定义**：将客户口语描述转化为结构化计算要素。

| 客户口语 | 转化为结构化要素 |
|---------|----------------|
| "对方赚了很多钱" | `defendant_profit` 待量化，需追问具体金额或估算依据 |
| "我方损失很大" | `plaintiff_loss` 待量化，需收集财务数据 |
| "有许可合同" | `license_fee` + `license_contract_date`，触发路径3 |
| "对方是故意的" | `is_malicious = true`，需补充恶意证据描述 |
| "侵权很严重" | `is_serious = true`，需补充情节严重证据描述 |

**转化规则**：
- 模糊金额 → 追问具体数据或估算依据
- "故意""恶意" → 标记 `is_malicious`，追问具体证据
- "严重""规模大" → 标记 `is_serious`，追问具体情节
- 日期信息 → 计算侵权持续时间

### 2. 细化

**定义**：将概括性赔偿需求细化为具体计算路径和参数。

| 计算路径 | 细化为计算参数 |
|---------|--------------|
| 路径1：实际损失 | 损失金额 + 损失计算依据 + 证据充分性 |
| 路径2：侵权获利 | 获利金额 + 获利计算依据 + 证据充分性 |
| 路径3：许可费倍数 | 许可费基础 + 建议倍数 + 许可合同合理性 |
| 路径4：法定赔偿 | 侵权情节评估 + 建议金额区间 |
| 惩罚性赔偿 | 恶意证据 + 情节严重证据 + 建议倍数(1-5) |
| 合理开支 | 各项费用明细 + 凭证情况 |

**细化原则**：
- 每个路径独立计算，不可混合
- 惩罚性赔偿的基数必须是路径1/2/3之一
- 合理开支不作为惩罚性赔偿的基数

**路径1保守取值（细化子操作，强制）**：

**定义**：路径1（权利人实际损失）的原始计算金额通常为"最优情形"估计，须在此基础上扣除不确定性因素，得出保守取值。保守取值不等于"最低值"，而是"扣除不可归因因素后仍有合理依据支撑的值"。

**扣除因素清单**：

| 扣除因素 | 说明 | 扣除方式 |
|---------|------|---------|
| 不可归因的销量减少 | 侵权期间销量下降可能部分源于市场变化、季节因素等非侵权原因 | 按合理比例扣除（通常10%-30%） |
| 促销降价因素 | 侵权期间权利人主动降价促销导致的利润减少不应全归因于侵权 | 区分降价原因，扣除非竞争性降价部分 |
| 行业整体下行 | 如行业同期整体下滑，应扣除行业因素影响 | 参考行业同期数据确定扣除比例 |
| 产品质量/服务变化 | 权利人自身产品变化导致的销量减少 | 全扣，不计入侵权损失 |
| 其他竞品影响 | 除侵权人外其他竞品的市场影响 | 按合理比例扣除 |

**保守取值输出格式**：

| 项目 | 原始计算 | 扣除因素 | 扣除金额 | 保守取值 |
|------|---------|---------|---------|---------|
| 销量减少损失 | A | 扣除不可归因部分(X%) | A×X% | A×(1-X%) |
| 价格侵蚀损失 | B | 扣除市场因素(Y%) | B×Y% | B×(1-Y%) |
| 商誉损失 | C | （难以量化，仅定性说明） | — | — |
| **合计** | A+B+C | | | **保守合计** |

**扣除规则**：
- 强制：路径1的"测算结果"须同时给出原始计算和保守取值两个口径
- 强制：每项扣除须说明扣除因素和比例依据
- 禁止：扣除比例为零却声明为保守取值
- 禁止：保守取值与原始计算完全相同（至少应有一项扣除）
- 标注：保守取值应标注"已扣除[具体因素]"

**时间对齐（细化子操作，强制）**：

**定义**：将年度口径或月均口径数据按实际侵权期间折算，确保计算期间与侵权期间严格对应。

| 数据口径 | 需要对齐的场景 | 处理方式 | 标注格式 |
|---------|--------------|---------|---------|
| 年度 | 年销售额500万 vs. 侵权8个月 | 500万 × 8/12 = 333.33万 | "约333.33万元（1-8月）" |
| 年度 | 年利润100万 vs. 侵权6个月 | 100万 × 6/12 = 50万 | "约50万元（1-6月）" |
| 年度 | 许可费（年费30万） vs. 侵权3个月 | 30万 × 3/12 = 7.5万 | "约7.5万元（3个月）" |
| 年度 | 年销售额500万 vs. 侵权14个月 | 500万 × 14/12 = 583.33万 | "约583.33万元（14个月）" |
| **月均** | **月均营收5万 vs. 侵权8个月** | **5万 × 8 = 40万** | **"约40万元（1-8月，共8个月）"** |
| 月均 | 月均利润3万 vs. 侵权5个月 | 3万 × 5 = 15万 | "约15万元（1-5月，共5个月）" |
| **多门店月均** | **年均门店数5×单店月均营收11.8万=月均总营收59万，8个月侵权** | **5 × 11.8 × 8 = 472万** | **"年度总营收约472万元（2023年5-12月，年均5店，共8个月）"** |

**对齐原则**：
- 禁止：年度数据直接用于非全年的侵权期间计算
- 禁止：月均数据乘以12替代实际月数（5万×12=60万而非5万×8=40万）
- 禁止：多门店月均场景以12替代实际经营月数（5×11.8×8=472而非5×11.8×12=708）
- 禁止：不标注实际计算期间，混淆年度/月均数据与实际期间数据
- 强制：折算后的金额必须标注实际计算期间，如"（1-8月，共8个月）"或"（2024年1-8月）"
- 强制：多门店场景标注门店数和经营月数，公式为"年均门店数 × 单店月均营收 × 经营月数"
- 精度：跨年或不足月时按实际天数折算
- 标注：若用户数据已明确为实际期间数据（非年度/月均口径），直接使用并标注"（已为实际期间数据）"

### 3. 补充

**定义**：为模糊计算补充明确的法律依据和证据要求。

| 计算路径 | 补充内容 |
|---------|---------|
| 路径1 | 补充商标法第63条第1款 + 损失计算方法（实际损失=因侵权减少的销量×单位利润） |
| 路径2 | 补充第63条第1款 + 侵权获利=侵权销量×单位利润；举证妨碍→第63条第2款 |
| 路径3 | 补充第63条第1款 + 许可费倍数参考因素 |
| 路径4 | 补充第63条第3款 + 法定赔偿考量因素 |
| 惩罚性 | 补充第63条第1款但书 + 恶意认定标准 + 情节严重认定标准 |

**补充规则**：
- 法律依据必须标注三标注体系
- 证据不足时标注"[待补充证据]"
- 金额不确定时标注"[需核实]"

### 4. 拆分

**定义**：将复合计算拆分为独立计算路径。

| 复合计算 | 拆分为 |
|---------|--------|
| "赔偿100万含惩罚性" | 基数计算(路径1/2/3) + 惩罚性赔偿计算(基数×倍数) |
| "赔偿+合理开支共50万" | 赔偿金额计算 + 合理开支单独列明 |
| "惩罚性赔偿1-5倍" | 基数确定 + 倍数选择(需恶性程度证据支撑) |

**拆分规则**：
- 惩罚性赔偿的基数必须明确来源于哪条路径
- 合理开支独立于赔偿基数，不可混入
- 每条路径独立计算，互不干扰

### 5. 去重

**定义**：消除重复计算和重复论证。

| 常见重复模式 | 去重处理 |
|-------------|---------|
| 路径1和路径2重复计算 | 按优先级选路径1，路径2作为备选 |
| 合理开支计入赔偿基数 | 合理开支单独列明，不作为惩罚性赔偿基数 |
| 惩罚性赔偿重复计算 | 基数仅取一次，不重复叠加 |

### 6. 统一

**定义**：术语和表述标准化。

| 统一项 | 标准表述 | 禁止表述 |
|--------|---------|---------|
| 赔偿性质 | "参考性测算" | "确定金额""应赔金额" |
| 输出形式 | "金额区间" | "确定值""精确金额" |
| 四路径关系 | "优先级递进" | "并列选择""四选一" |
| 惩罚性条件 | "恶意+情节严重" | "仅恶意""恶意即可" |
| 免责 | "须律师审核，最终以法院裁定为准" | "法院一定会判""保证拿到" |

**补充操作：报告生成后交叉校验（Phase 5）**

在六操作管线完成后，须对生成的报告进行金额交叉验证：

| 校验维度 | 校验内容 | 不合格处理 |
|---------|---------|-----------|
| 推荐方案自洽 | 推荐总额 = 路径结果 + 惩罚性 + 合理开支 | 修正至一致 |
| 惩罚性基数溯源 | 基数须取自声明路径的结果 | 调整基数 |
| 合理开支合计 | 合计 = 各分项之和 | 逐项重算 |
| 时间对齐全量 | 所有年度/月均数据已折算且标注完整 | 补折算 |
| 前后数值一致 | 同一概念在报告中多处出现时数值统一 | 以首次计算为准修正 |

## 三、隐性知识嵌入

### 3.1 四路径优先级递进的真正含义

| 要点 | 说明 |
|------|------|
| 不是并列选择 | 法院按优先级审查，有路径1数据时不允许直接跳到路径4 |
| 证据决定路径 | 哪条路径的证据最充分，法院倾向于采纳哪条 |
| 多路径准备 | 实务中可同时准备多个路径的计算，供律师选择 |
| 举证妨碍衔接 | 侵权人不提供账簿→法院可参考权利人主张→路径2可能转为对权利人有利的推定 |

**嵌入方式**：Phase 2 计算路径选择时，按优先级递进排列，标注"优先级1→2→3→4"

### 3.2 惩罚性赔偿的双重门槛

| 要点 | 说明 |
|------|------|
| 双重条件 | 须**同时**满足"恶意"和"情节严重"，缺一不可 |
| "恶意"认定 | 重复侵权、侵权规模大、拒不停止、明知仍故意侵权 |
| "情节严重"认定 | 侵权时间长、侵权范围广、侵权获利巨大、造成严重后果 |
| 倍数选择 | 1-5倍，需与恶性程度匹配——恶意程度越高、情节越严重，倍数越高 |
| 基数确定 | 基数必须是路径1/2/3的计算结果，不包含合理开支 |

**嵌入方式**：Phase 2 惩罚性赔偿评估时，必须同时检查恶意和情节严重两个条件

### 3.2b 惩罚性赔偿基数的选择理由

**核心问题**：路径1/2/3均可用时，为何选择其中之一的测算结果作为惩罚性赔偿基数？

| 选择因素 | 权重 | 说明 |
|---------|------|------|
| 证据充分性 | 最高 | 优先选择证据最充分的路径结果（证据充分性为"高"的路径优先于"中""低"） |
| 路径优先级 | 高 | 同等证据充分性下，按路径1→2→3优先级选择 |
| 金额合理性 | 中 | 路径结果应在合理区间内，不过高也不过低 |
| 法院采纳可能性 | 中 | 该路径结果被法院采纳的可能性评估 |
| 不对权利人不利 | 强制 | 选择的路径结果不得低于合理预期 |

**选择理由输出格式**：

报告中惩罚性赔偿评估节须包含：

- 基数选择：[选择路径X的测算结果作为基数]
- 选择理由：
  1. 证据充分性对比（各路径证据充分性排序）
  2. 路径优先级考量
  3. 排除其他路径的原因
- 示例："惩罚性赔偿基数取自路径1（权利人实际损失）。路径1证据充分性为'高'（有财务数据支撑），优先级最高；路径2虽可计算但证据充分性为'中'；路径3许可费倍数参考力较弱。故以路径1的保守取值作为惩罚性赔偿基数。"

**嵌入方式**：Phase 2 惩罚性赔偿评估时，须在选择基数后输出上述选择理由块。

### 3.3 合理开支的独立性

| 要点 | 说明 |
|------|------|
| 独立于赔偿基数 | 合理开支不作为惩罚性赔偿的基数 |
| 具体项目 | 律师费+公证费+调查费+购买侵权产品费+差旅费+其他 |
| 凭证要求 | 须有相应凭证支持，无凭证的可主张但法院可能不支持 |
| 计算方式 | 各项费用相加，独立于赔偿金额 |

### 3.4 法定赔偿不是"默认500万"

| 要点 | 说明 |
|------|------|
| 500万是上限 | 法院根据侵权情节酌定，非默认值 |
| 考量因素 | 侵权持续时间、规模、主观恶性、商标知名度、侵权后果等 |
| 实务区间 | 多数案件法定赔偿金额在5万-100万之间 |
| 与惩罚性不并用 | 选择法定赔偿路径时，不叠加惩罚性赔偿 |
