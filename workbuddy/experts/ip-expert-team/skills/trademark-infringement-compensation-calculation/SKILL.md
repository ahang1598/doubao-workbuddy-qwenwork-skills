# 商标侵权赔偿测算

> **核心定位**：为商标权利人/律师计算侵权赔偿金额，根据证据选择最优计算路径，输出合理赔偿金额区间，支持四路径递进优先级+惩罚性赔偿+合理开支。
>
> **蓝本依据**：商标法第63条（赔偿计算）[已核实] + 第64条（不赔偿抗辩）[已核实]
>
> 本技能遵循 compiler/ssot.md §17（SSOT）
>
> **输出格式禁令**：本技能所有输出（测算报告/撰写指引/证据清单）中**禁止使用任何 emoji 表情符号**（包括但不限于：✅、❌、⚠️、🔴、📋、💡、📊）。法条标注仅使用纯文本 `[已核实]` / `[需核实]` / `[存疑]`，不得在前面添加任何 emoji。

## 2. 快速开始

**一句话定位**：根据证据选择最优赔偿计算路径，输出合理赔偿金额区间，支持四路径递进+惩罚性赔偿+合理开支。

**最小示例**：

```
用户输入：我方商标被侵权，对方年销售额约500万，我方因侵权损失了约100万年利润，
有独占许可合同年费30万。请帮我测算赔偿金额。
预期输出：四路径递进测算+惩罚性赔偿评估+合理开支+推荐方案。
```

| 参数 | 类型 | 法律含义 | 必填 | 降级等级 |

| `infringement_duration` | string | 侵权持续时间 | 是 | L3 |
| `infringement_duration_months` | number | 侵权持续月数（用于时间对齐折算） | 自动计算 | - |
| `infringement_scope` | string | 侵权范围（地域/渠道） | 是 | L3 |
| `data_period_type` | string | 输入数据时间口径（annual=年度/actual=实际期间） | 自动判定 | - |

**核心法律依据**：见 `references/legal-references.md`

**四路径递进优先级**（非并列选择）：

| 优先级 | 计算路径 | 适用条件 | 法律依据 |
|--------|---------|---------|---------|
| **1** | 权利人实际损失 | 有财务数据证明损失 | 第63条第1款[已核实] |
| **2** | 侵权人获利 | 有对方经营数据 | 第63条第1款[已核实] |
| **3** | 许可使用费倍数 | 有许可合同 | 第63条第1款[已核实] |
| **4** | 法定赔偿 | 以上均难以确定 | 第63条第3款[已核实]（500万以下） |

**附加计算**：
- **惩罚性赔偿**：恶意+情节严重 → 基数1-5倍（第63条第1款但书[已核实]）
- **合理开支**：律师费+公证费+调查费+购买侵权产品费等，单独列明

## 5. 常见问题

**Q1**：四种计算方式应该选哪种？

**答**：优先级递进——有原告损失数据时优先用实际损失，无则用侵权人获利，再无则用许可费倍数，都无则法定赔偿。法院也倾向于选择证据最充分的路径。可同时准备多个路径的计算，供律师选择。

**Q2**：惩罚性赔偿如何适用？

**答**：须同时满足两个条件：①被告恶意侵权；②情节严重。赔偿金额=基数×1-5倍。"恶意"包括：重复侵权、侵权规模大、拒不停止等。"情节严重"由法院综合认定。仅恶意但情节不严重，或情节严重但无恶意，均不适用惩罚性赔偿。

**Q3**：法定赔偿500万是上限还是默认值？

**答**：500万是法定赔偿的上限。法院根据侵权行为的情节（持续时间、规模、主观恶性等）在500万以下酌定。并非所有案件都接近500万。实务中多数案件法定赔偿金额在5万-100万之间。

**Q4**：报告中是否包含诉讼时效和管辖权分析？

**答**：报告包含"程序性事项提示"节，提供诉讼时效（三年，自知道权利受损之日起算）、管辖权（侵权行为地或被告住所地中院）、举证责任、诉前保全等基础提示。但具体时效是否届满、是否存在中断/中止、管辖法院级别等须由律师根据案件具体情况判断，本技能不替代律师的程序性专业判断。
