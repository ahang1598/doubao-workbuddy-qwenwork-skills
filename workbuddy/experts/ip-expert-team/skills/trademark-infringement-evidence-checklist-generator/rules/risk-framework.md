## 二、商标侵权证据特有风险规则

### 2.1 证据分类风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 四分类遗漏 | 权利/侵权/损害/知名度任一类缺失 | Phase 2 强制四分类生成 |
| 侵权与损害混淆 | 侵权证据混入损害证据 | 编号前缀区分(E-I/E-D) |
| 知名度证据被忽略 | 知名度影响保护范围和赔偿金额 | 四分类中E-F强制生成 |

### 2.2 诉请映射风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 诉请无证据支撑 | 赔偿诉请无损害证据 | Phase 3 强制映射校验 |
| 映射遗漏 | 部分诉请未做映射 | 完整模式下映射必须全覆盖 |
| 映射状态不一致 | 同一证据映射结果不一致 | 统一🔴缺失/⚠不足/✅充分 |

### 2.3 公证建议风险

| 风险 | 说明 | 防御措施 |
|------|------|---------|
| 关键证据无公证建议 | 侵权产品/网页证据未建议公证 | Phase 2 关键侵权证据强制标注 |
| 公证建议绝对化 | "必须公证"而非"建议公证保全" | 统一使用"建议公证保全" |

## 三、SOFT_DEGRADED 降级骨架

> 遵循 `base/shared/risk-rules-common.md` C+D+G 最小骨架

### 降级分层 L0-L3

| 等级 | 条件 | 输出范围 |
|------|------|---------|
| **L0 完整** | 所有必填参数齐全 | 完整证据清单 + 诉请映射 + 证据收集建议 |
| **L1 轻度** | 缺少侵权行为类型/赔偿依据 | 完整证据清单，缺失处标注"[待补充]" |
| **L2 中度** | 缺少诉请或当事人身份 | 通用证据清单框架+四分类+编号，无诉请映射 |
| **L3 重度→SOFT_DEGRADED** | 缺少案件类型/当事人 | 仅输出通用证据框架+编号体系 |

### SOFT_DEGRADED 最小骨架（C + D + G）

| 块 | 内容 |
|----|------|
| **C) 待补充事实清单** | 缺失的案件类型/当事人/诉请 + 影响程度 + 建议补充方式 |
| **D) 治理与禁区声明** | 输出为降级模式，不含诉请映射；禁止直接用于诉讼 |
| **G) 下一步行动** | 用户需补充案件信息后重新生成完整清单 |

### 降级强度映射

| 强度 | 条件 | 渲染等级 |
|------|------|---------|
| S1 | L3 重度 | 仅 C+D+G，不输出分类清单 |
| S2 | L2 中度 | C+D+G + 通用四分类框架 |
| S3 | L1 轻度 | 接近完整输出，缺失项标注"[待补充]" |
