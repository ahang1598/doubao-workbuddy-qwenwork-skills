# 边界示例 1 — tm-infringement-evidence-checklist

> 版本：1.0.0 | 类型：边界 | 场景：信息不足触发降级

## 输入

```json
{
  "case_type": "infringement_litigation",
  "party_role": "plaintiff",
  "claims": [],
  "existing_evidence": []
}
```

## 预期输出（SOFT_DEGRADED 降级模式）

```markdown
# 商标侵权证据清单（降级模式）

> ⚠️ 因关键信息不足，本清单以降级模式输出。仅提供通用证据清单框架，不含诉请映射校验。

## 一、权利证据（E-R）— 通用框架

| 编号 | 证据名称 | 证明目的 | 备注 |
|------|---------|---------|------|
| E-R-001 | 商标注册证 | 证明商标权属 | 基础证据 |
| E-R-002 | 商标续展证明 | 证明商标持续有效 | 如注册满10年 |
| E-R-003 | 商标变更证明 | 证明商标权人变更 | 如有变更 |

## 二、侵权证据（E-I）— 通用框架

| 编号 | 证据名称 | 证明目的 | 备注 |
|------|---------|---------|------|
| E-I-001 | 侵权产品实物/照片 | 证明侵权标识使用 | 建议公证保全 |
| E-I-002 | 侵权网页截图 | 证明线上侵权 | 建议网页公证 |
| E-I-003 | 公证购买记录 | 证明侵权产品来源 | 关键证据 |

## 三、待补充信息清单

- 🔴 诉讼请求列表（用于诉请映射校验）
- 🔴 已有证据清单（用于三态标记）
- ⚠️ 侵权行为类型（用于定制化侵权证据）
- ⚠️ 赔偿依据（用于定制化损害证据）

## 四、下一步建议

1. 明确诉讼请求（停止侵权/赔偿损失/消除影响等）
2. 整理已有证据清单
3. 补充上述信息后重新运行，获得含诉请映射校验的完整清单

⚠️ **降级声明**：因信息不足，本清单不含诉请映射校验。请在补充信息后重新运行。
```
