> 版本：1.0.0 | 类型：标准 | 场景：原告商标侵权诉讼

## 输入

```json
{
  "case_type": "infringement_litigation",
  "party_role": "plaintiff",
  "claims": ["停止侵权", "赔偿损失", "消除影响"],
  "existing_evidence": ["商标注册证", "侵权产品照片", "律师费发票"],
  "infringement_type": ["sales", "online_infringement"],
  "damage_basis": "statutory_damages"
}
```
