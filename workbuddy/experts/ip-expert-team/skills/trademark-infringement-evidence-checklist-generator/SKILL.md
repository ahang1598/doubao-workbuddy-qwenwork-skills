# 商标侵权证据清单生成

> **核心定位**：按商标侵权诉讼案件类型自动生成定制化证据清单，含四分类体系（E-R/E-I/E-D/E-F）、三态标记和诉请映射校验，确保证据与诉请主张的对应关系完整无遗漏。
>
> **蓝本依据**：商标法第57条（侵权行为）[✅已核实] + 第63条（赔偿计算）[📋需核实] + 第64条（合法来源抗辩）[📋需核实]
>
> 本技能遵循 compiler/ssot.md §17（SSOT）

## 1. 法律合规与风险声明

1. **管辖范围**：中国大陆（不含港澳台）。商标侵权诉讼由人民法院管辖
2. **输出性质**：所有输出为**证据清单参考**，须律师审核后方可用于诉讼活动
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **L3特别提醒**：本技能输出须标注"须律师审核"，不得替代律师对证据的独立判断
5. **知识截止**：法律依据基于截至2026-06-01的法律法规
6. **清单风格声明**：WR-11 选定**结构化清单风格**（四分类+编号+三态标记），贯彻到底
7. **免责声明**：本技能产物为AI辅助工具生成，不构成法律意见，使用者应结合具体案情独立判断

**一句话定位**：按商标侵权诉讼案件类型自动生成定制化证据清单，含四分类体系、三态标记和诉请映射校验。

**最小示例**：

```
用户输入：我要起诉对方商标侵权，我有商标注册证和侵权产品照片，要求停止侵权和赔偿损失。
预期输出：完整的商标侵权证据清单，含四分类（权利/侵权/损害/知名度）、三态标记、诉请映射校验（停止侵权→✅权利+侵权证据，赔偿损失→🔴缺失损害证据）。
```

## 5. 适用边界

**适用范围**：
- 商标侵权诉讼证据清单的生成与诉请映射校验
- 律师参考使用，须经审核后方可用于诉讼活动
- 侵权诉讼证据准备阶段

**不适用范围**：
- 商标行政争议证据清单（→ `tm-admin-evidence-checklist`）
- 商标侵权比对分析（→ `tm-infringement-comparison`）
- 商标侵权民事起诉状起草（→ `tm-infringement-complaint`）
- 专利/著作权/商业秘密证据清单（→ 对应领域技能）

**硬拒绝条件**：
1. `case_type`不在枚举内（非侵权诉讼/行政投诉） → 拒绝，提示正确技能
2. 诱导性要求保证"证据充分"或"必胜" → 拒绝，输出风险声明
3. 要求直接替代律师出具正式证据清单 → 拒绝，提示须律师审核
4. 非商标领域证据需求（专利/著作权/商业秘密） → 拒绝，路由到对应领域技能

## 6. 常见问题

**Q1**：商标案件为什么要特别强调公证？

**答**：商标侵权案件中，侵权产品/侵权网页/侵权门店等证据容易灭失或被修改。公证保全证据在诉讼中具有较高的证明力，法院一般直接采信公证书记载的事实。建议对关键侵权证据优先公证保全。

**Q2**：诉请映射校验有什么意义？

**答**：每项诉讼请求都须有对应的证据支撑，否则法院可能不支持该项诉请。例如，主张"赔偿损失"但未提供任何损害证据，法院可能仅支持法定赔偿最低额。诉请映射校验帮助律师发现证据缺口。

**Q3**：被告如何使用本技能？

**答**：被告方可选择 party_role=被告，系统将生成被告视角的证据清单，侧重合法来源抗辩证据、不侵权证据、现有设计抗辩证据等。

**Q4**：法定赔偿需要准备哪些证据？

**答**：即使选择法定赔偿，仍建议准备：侵权行为的情节证据（侵权持续时间/规模/范围）、侵权人的主观恶意证据、商标知名度证据。这些虽非法定赔偿必要证据，但可影响法定赔偿金额的高低。
