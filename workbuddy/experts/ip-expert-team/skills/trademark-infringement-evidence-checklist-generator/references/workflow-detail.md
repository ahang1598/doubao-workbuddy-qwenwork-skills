# 工作流详细步骤 — tm-infringement-evidence-checklist

> **所属技能**：tm-infringement-evidence-checklist | **文件角色**：工作流定义 | **版本**：v1.1.0

---

## Phase 1：输入验证与案件识别

### 1.1 必填字段检查（含降级分级）

| 降级等级 | 缺失字段 | 触发行为 |
|---------|---------|---------|
| L3 重度 | `case_type` 或 `party_role` | → SOFT_DEGRADED：仅输出通用证据框架+编号体系 |
| L2 中度 | `claims` | → 证据清单+四分类，无诉请映射 |
| L1 轻度 | `infringement_type` 或 `damage_basis` | → 完整清单，缺失处标注"[待补充]" |
| L0 完整 | 所有参数齐全 | → 完整证据清单+诉请映射+证据收集指引 |

### 1.2 Fast-Path 机制

| Fast-Path 触发条件 | 处理方式 |
|-------------------|---------|
| 原告+侵权诉讼+信息完整 | 直接按四分类生成+诉请映射 |
| 被告+合法来源抗辩 | 跳过E-R/E-I/E-F，侧重E-D替代+合法来源证据 |

---

## Phase 2：证据分类与清单生成（六操作管线）

1. **抽取**：提取案件类型/当事人/诉请/已有证据
2. **结构化**：按四分类体系（E-R/E-I/E-D/E-F）组织
3. **细化**：按侵权行为类型细化E-I，按赔偿依据细化E-D
4. **拆分**：复合证据需求拆分为独立证据项
5. **去重**：同一证据不跨类重复
6. **统一**：编号/三态标记/公证建议术语标准化

---

## Phase 3：诉请映射校验

| 诉请 | 必需证据类型 | 最低证据要求 |
|------|-------------|-------------|
| 停止侵权 | 权利证据+侵权证据 | 至少1项权利+1项侵权 |
| 赔偿损失 | 损害证据 | 至少1项损害证据（否则仅法定赔偿） |
| 消除影响 | 侵权影响证据 | 至少1项影响证据 |
| 销毁侵权商品 | 侵权证据 | 至少1项侵权商品证据 |
| 承担合理费用 | 费用证据 | 至少1项费用票据 |
