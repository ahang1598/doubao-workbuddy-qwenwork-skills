# 商标侵权证据清单生成方法论

> **所属技能**：tm-infringement-evidence-checklist | **文件角色**：方法论底座 | **版本**：v1.1.0

## 一、三层理论框架

### 认知层（Know-What）

**核心问题**：商标侵权诉讼的证据体系如何构建？各类证据的法律功能是什么？

| 要件 | 内容 |
|------|------|
| 证据体系的法律基础 | 商标法第57条（侵权行为7项）+ 第63条（赔偿4种计算方式）+ 第64条（合法来源抗辩） |
| 权利证据（E-R） | 证明商标权属和权利范围的证据——侵权诉讼的逻辑起点 |
| 侵权证据（E-I） | 证明侵权事实和侵权方式的证据——侵权诉讼的核心 |
| 损害证据（E-D） | 证明损害程度和赔偿依据的证据——赔偿诉求的支撑 |
| 知名度证据（E-F） | 证明商标知名度和显著性的证据——影响保护范围和赔偿金额 |
| 诉请映射 | 每项诉讼请求须有对应证据支撑——无证据支撑的诉请将被法院驳回 |
| 举证责任 | 民诉法第67条"谁主张谁举证"+商标法第63条举证妨碍规则 |

**常见认知错误**：
- ❌ 把侵权证据与损害证据混为一谈——前者证明侵权事实，后者证明损害程度
- ❌ 忽略知名度证据——知名度影响保护范围和赔偿金额
- ❌ 认为法定赔偿不需要证据——法定赔偿仍需侵权情节/恶意/知名度证据
- ❌ 公证证据绝对可靠——公证文书推定真实，但有相反证据可推翻

### 策略层（Know-Why）

**核心问题**：如何组织证据才能最有效地支撑诉请？

| 当事人身份 | 推荐主攻证据 | 辅助证据 | 策略选择依据 |
|-----------|-------------|---------|------------|
| 原告-侵权诉讼 | 权利证据+侵权证据为核心 | 损害证据+知名度证据 | 先证权利，再证侵权，最后证损害 |
| 原告-行政投诉 | 权利证据+侵权事实为核心 | 知名度证据 | 行政投诉侧重侵权事实的快速认定 |
| 被告-合法来源抗辩 | 合法来源证据为核心 | 不侵权证据 | 合法来源仅免除赔偿责任，不免除停止侵权 |
| 被告-不侵权抗辩 | 不构成近似/不构成类似证据 | 现有设计抗辩证据 | 需推翻标识近似或商品类似的认定 |

**策略选择的核心原则**：
1. **权利证据优先**：无权利证据则侵权诉讼无从谈起
2. **诉请映射驱动**：先明确诉请，再组织证据——每项诉请须有对应证据
3. **公证优先原则**：商标案件关键证据（侵权产品/侵权网页）优先公证保全
4. **损害证据分档**：实际损失→侵权获利→许可费倍数→法定赔偿，有适用顺序

### 表达层（Know-How）

**核心问题**：按策略路径如何撰写证据清单？

**选定风格：结构化清单风格**（基于商标侵权诉讼实务惯例）

| 风格特征 | 说明 |
|---------|------|
| 清单结构 | 四分类（E-R/E-I/E-D/E-F）→ 诉请映射 → 证据收集建议 |
| 证据格式 | 编号+名称+状态+证明目的+取得方式+备注 |
| 三态标记 | ☑已收集 / ☐缺失 / ⚠需补强 |
| 禁止 | 证明力绝对化判断、证据取舍的律师替代 |

**三层硬约束**：不允许跳过任一层。

## 二、六操作管线

### 1. 抽取 → 2. 结构化 → 3. 细化 → 4. 拆分 → 5. 去重 → 6. 统一

| 操作 | 说明 |
|------|------|
| 抽取 | 从客户描述提取案件类型/当事人/诉请/已有证据 |
| 结构化 | 按四分类体系（E-R/E-I/E-D/E-F）组织 |
| 细化 | 按侵权行为类型细化侵权证据，按赔偿依据细化损害证据 |
| 拆分 | 复合证据需求拆分为独立证据项 |
| 去重 | 同一证据不跨类重复 |
| 统一 | 编号/三态标记/公证建议术语标准化 |

## 三、隐性知识嵌入

### 3.1 公证保全的实务价值
- 公证文书推定真实，法院一般直接采信
- 侵权网页/产品/门店等证据容易灭失，优先公证保全
- 嵌入方式：Phase 2 关键侵权证据强制标注"建议公证保全"

### 3.2 赔偿计算的四档递进
- 适用顺序：实际损失→侵权获利→许可费倍数→法定赔偿
- 多数案件最终适用法定赔偿，但仍建议准备前三档证据
- 嵌入方式：Phase 2 损害证据按四档分别组织

### 3.3 诉请映射的实务意义
- 无证据支撑的诉请可能被法院驳回
- 嵌入方式：Phase 3 诉请映射校验，缺失时标注🔴

### 3.4 原告/被告证据策略差异
- 原告侧重完整举证链；被告侧重反驳+合法来源抗辩
- 合法来源抗辩（第64条）仅免除赔偿责任，不免除停止侵权
- 嵌入方式：Phase 1 根据party_role路由到不同证据模板
