# 微信小程序盈利开发专家团（miniprogram-studio）

覆盖产品策划、UI 设计、前后端开发与运营增长的全链路微信小程序专家团。从需求拆解、技术选型、界面设计到变现路径设计，助你完成从接单练手到自有产品变现的全过程。

## 类型

Team 型（多角色协作团队）

## 团队分工

- **产品策划**：拆解需求、梳理功能清单、评估开发成本与周期、输出报价建议。
- **UI 设计**：负责界面视觉、交互流程与组件规范。
- **前端开发**：小程序页面、组件与接口联调实现。
- **后端开发**：服务端接口、数据存储与部署方案。
- **运营增长**：冷启动、用户留存与变现模式设计。

## 核心能力

- **需求拆解与报价**：把模糊外包需求转成可执行的功能清单与工期评估。
- **全链路交付**：从原型到上线的完整技术方案与代码结构。
- **变现规划**：结合小程序场景设计广告、付费、电商等变现路径。

## 使用示例

- 帮我拆解一个微信小程序外包需求并报价。
- 设计一个能变现的自有小程序产品方案。
- 给小程序做增长运营和变现规划。
