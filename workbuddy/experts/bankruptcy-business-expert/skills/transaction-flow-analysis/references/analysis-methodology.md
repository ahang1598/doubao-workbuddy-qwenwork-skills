## 1. 概述

本文件描述6种案件类型的差异分析框架。每种案件类型有独特的：
- **组织逻辑**：按什么维度组织交易记录
- **分类标准**：交易的法律定性依据
- **异常定义**：什么算异常、阈值是多少
- **隐性知识**：实务中容易遗漏的关键判断点

## 2. CT1 婚姻家事分析方法

### 组织逻辑

按**财产归属**维度组织：共同财产支出 → 个人消费 → 疑似转移 → 待定

### 分类方法

#### 共同财产支出识别

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 备注关键词 | 高 | "家用""孩子""房贷""水电""物业""菜""超市" |
| 消费对象 | 中 | 生活必需品、子女教育、家庭医疗 |
| 金额特征 | 中 | 金额合理，与家庭收入匹配 |
| 频率规律 | 低 | 日常消费通常高频小额 |

#### 疑似转移行为识别

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 时间窗口 | 高 | 起诉前1年内的异常转出 |
| 对方关系 | 高 | 父母/兄弟姐妹/好友/新配偶 |
| 金额特征 | 高 | 整数大额（5万以上）或高频小额累计 |
| 交易模式 | 中 | 取现→去向不明 / 转账→可追溯 |
| 余额变化 | 中 | 大额转出后余额骤降 |

#### 隐性知识

1. **取现vs转账的实务差异**：取现后去向不明比转账更难追查，实务中取现比转账更可疑
2. **"小额多次"比"大额一次"更隐蔽**：分批转出3万×10次比一次性30万更难被发现
3. **节假日大额支出**：春节/中秋/国庆期间的大额支出需区分正常人情往来和异常转移
4. **"装修"类备注的双重性**：可能是真实的共同财产支出，也可能是虚增共同债务

### 异常阈值

| 异常类型 | 阈值 | 说明 |
|----------|------|------|
| 大额整数转出 | ≥5万元且为整数 | 或月收入3倍以上 |
| 起诉前密集转出 | 起诉前180天内支出频率>平均值2倍 | 按月计算 |
| 取现后无对应消费 | 单次取现≥2万元且后续无对应消费记录 | |
| 向特定关系人转出 | 起诉前1年内向非共同生活人员转出累计≥10万元 | |

## 3. CT2 劳动争议分析方法

### 组织逻辑

按**收入性质**维度组织：工资 → 加班费 → 报销 → 奖金 → 其他

### 分类方法

#### 工资识别

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 发放规律 | 高 | 每月固定日期（±3天） |
| 金额特征 | 高 | 每月固定金额或固定区间 |
| 对方信息 | 高 | 对公账户，户名为用人单位或代发工资行 |
| 备注关键词 | 中 | "工资""代发""薪资""薪酬" |

#### 加班费识别

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 发放时间 | 高 | 工资发放日之外的额外发放 |
| 备注关键词 | 高 | "加班""OT""加班费" |
| 金额与工资关系 | 中 | 通常为工资的150%/200%/300%的倍数 |

#### 隐性知识

1. **"劳务费"可能是工资**：用人单位为规避社保义务，将工资备注为"劳务费"，但实质仍为劳动报酬——需结合规律性和对公账户判断
2. **报销与工资的发放周期差异**：报销通常不规律，金额波动大；工资固定规律
3. **年终奖的争议性**：年终奖属于工资组成部分（《关于工资总额组成的规定》第7条），但发放条件可能被用人单位设限
4. **代发工资行标注**：银行流水中"代发"标记是认定工资的关键证据

### 异常阈值

| 异常类型 | 阈值 | 说明 |
|----------|------|------|
| 工资断发 | 连续2个月无工资入账 | 需排除已离职情形 |
| 非工资冒充工资 | 不规律金额+备注"劳务费" | 需标注置信度 |
| 低于最低工资 | 月工资低于当地最低工资标准 | 需查当地标准 |

## 4. CT3 民间借贷分析方法

### 组织逻辑

按**本息还款**维度组织：出借本金 → 利息 → 还款 → 其他

### 分类方法

#### 本金识别

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 交易方向 | 高 | 借款人视角为"收入"，出借人视角为"支出" |
| 备注关键词 | 高 | "借款""本金""借""贷" |
| 金额特征 | 中 | 通常为整数或约定金额 |

#### 还款认定

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 交易方向 | 高 | 还款方向与借款方向相反 |
| 金额与借款关系 | 高 | ≤借款本金+约定利息，或分期还款 |
| 备注关键词 | 中 | "还款""还借款""本息" |

#### 利率推算

从还款记录反推约定利率的方法：
1. 识别出借本金P和还款总额R
2. 若R > P，差额Δ = R - P
3. 计算年化利率 r = Δ / P / 借款年限 × 100%
4. 与LPR 4倍比较（民间借贷利率上限）

#### 隐性知识

1. **"还款"不一定是归还本金**：可能包含利息、逾期利息、违约金，需逐笔认定
2. **现金还款的认定困难**：银行流水中无记录的现金还款难以认定，需结合收条等证据
3. **部分还款的冲抵顺序**：无约定时按"先息后本"冲抵（《民法典》第561条）
4. **砍头息的扣除**：借款当日或次日即转回出借人部分，应从本金中扣除（《民法典》第670条）

### 异常阈值

| 异常类型 | 阈值 | 说明 |
|----------|------|------|
| 超出本金还款未标注 | 还款总额>本金但无利息备注 | 需标注可能含利息 |
| 还款日与借款日间隔异常 | 借款后1-2天内即还款 | 可能是砍头息或走账 |
| 利率超LPR4倍 | 推算年化利率>合同成立时LPR4倍 | 超出部分不受保护 |

## 5. CT4 合同纠纷分析方法

### 组织逻辑

按**履约进度**维度组织：约定付款 → 实际付款 → 逾期 → 违约金

### 分类方法

#### 履约验证

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 合同约定 | 高 | 付款时间、金额、条件 |
| 实际付款 | 高 | 与约定时间、金额的匹配度 |
| 付款偏差 | 中 | 迟延天数、金额差额 |

#### 逾期计算

1. 确定每笔约定付款日期D_due
2. 找到对应的实际付款日期D_actual
3. 逾期天数 = D_actual - D_due
4. 逾期金额 = 约定金额 - 实际付款金额（若部分付款）

#### 隐性知识

1. **部分付款的法律效果**：部分付款不免除剩余付款义务，逾期以未付部分为准
2. **付款条件成就的认定**：附条件付款需验证条件是否成就，非仅看时间
3. **发票与付款的对应关系**：先票后款/先款后票的实务差异
4. **质量异议与付款拒付**：以质量问题拒付需区分善意抗辩和恶意拖欠

### 异常阈值

| 异常类型 | 阈值 | 说明 |
|----------|------|------|
| 逾期付款 | 实际付款日>约定付款日 | 按天计算 |
| 部分付款 | 实际付款<约定金额 | 标注差额 |
| 未约定付款但持续交易 | 无合同但长期交易往来 | 适用事实合同（《民法典》第490条） |

## 6. CT5 刑事辩护分析方法

### 组织逻辑

按**涉案关联**维度组织：涉案资金 → 关联资金 → 待定

### 分类方法

#### 涉案金额区间认定

| 判断要素 | 权重 | 说明 |
|----------|------|------|
| 指控事实 | 高 | 起诉书/起诉意见书认定的金额 |
| 交易时间窗口 | 高 | 涉案期间内的交易 |
| 对手方 | 高 | 与涉案人员/公司的交易 |
| 资金流向 | 中 | 资金从何而来、向何而去 |

#### 资金流向拓扑

1. 确定资金起点（当事人/涉案公司）
2. 追踪每笔资金流向（第一层→第二层→第三层）
3. 标注每层停留时间和转出比例
4. 检测资金回流路径（A→B→C→A）
5. 计算涉案金额占全部交易的比例

#### 隐性知识

1. **金额区间直接影响量刑**：不同罪名有不同量刑档次，金额认定必须在区间内标注可能性
2. **资金回流不一定影响定性**：回流可能是正常业务周转，需结合案件事实判断
3. **主观明知推定的谨慎性**：从交易模式推断主观明知仅为辅助分析，不能替代证据
4. **多层转手的资金追踪边界**：通常追踪3层，更深层的转手需侦查手段

> **C类高风险提醒**：CT5所有金额认定结论必须标注"需律师结合案情确认"，禁止给出确定性金额认定。

### 异常阈值

| 异常类型 | 阈值 | 说明 |
|----------|------|------|
| 资金回流 | A→B→C→A 3层内有回流 | 可能是洗钱或走账 |
| 多层转手 | 同一笔资金3次以上转手 | 可能是掩饰隐瞒 |
| 大额进出同日 | 同日大额收入+大额支出 | 可能是走账 |

## 7. CT6 执行追索分析方法

### 组织逻辑

按**财产线索**维度组织：生活消费 → 可执行财产 → 财产转移

### 分类方法

#### 消费画像

| 维度 | 分析内容 | 法律含义 |
|------|----------|----------|
| 消费类别分布 | 餐饮/出行/娱乐/教育/医疗 | 判断生活水平与申报财产是否匹配 |
| 高频消费场所 | 出现频次最高的商户 | 可能为常驻地或财产线索 |
| 异常消费 | 单笔高额消费 | 可能是转移财产或可供执行 |
| 收入能力 | 从交易记录推断月均收入 | 评估还款能力 |

#### 财产线索发现

| 线索类型 | 识别方法 | 依据 |
|----------|----------|------|
| 房产 | 定期向物业/房贷账户付款 | 月供记录 |
| 车辆 | 向4S店/保险公司/加油站付款 | 保险+保养+加油 |
| 投资理财 | 向证券/基金账户转账 | 定投或大额转入 |
| 保险 | 向保险公司缴费 | 年缴记录 |
| 子女教育 | 向学校/培训机构缴费 | 学费+培训费 |

#### 隐性知识

1. **消费水平与申报财产的矛盾**：高消费但申报无财产，可能隐匿财产
2. **支付宝/微信的消费画像比银行更丰富**：日常消费集中在移动支付
3. **定期转账可能是隐藏收入**：每月固定日期的转账可能是租金、分红等收入
4. **消费地点的可执行线索**：消费地点集中在某区域，可能在该区域有房产

### 异常阈值

| 异常类型 | 阈值 | 说明 |
|----------|------|------|
| 高消费 | 单笔消费≥1万元 | 非生活必需消费 |
| 消费水平与申报不符 | 月均消费>执行依据金额的50% | 可能隐匿财产 |
| 定期大额转出 | 每月固定向同一对手方转出≥1万元 | 可能是转移财产 |

## 8. 通用分析方法

### 金额汇总规范

1. 所有金额汇总必须列出计算过程（逐笔累加）
2. 分渠道汇总后再合并，不直接混合计算
3. 百分比保留2位小数
4. 金额单位统一为"元"，千分位分隔

### 时间分析规范

1. 时间窗口按案件类型定义（CT1起诉前180天，CT5涉案期间等）
2. 交易密集期按月统计，标注月交易笔数和金额
3. 时间轴按自然月或季度分段

### 对手方分析规范

1. 同一对手方出现多种名称时尝试归并（如"张三""张*""133xxxx张三"）
2. 对手方分类必须标注推断依据
3. 对手方排行按累计金额降序

## 9. 常见错误与隐性知识

### 通用常见错误

| # | 错误 | 正确做法 |
|---|------|----------|
| 1 | 将银行记账方向作为用户视角方向 | 银行"借"=用户支出，"贷"=用户收入，必须反转 |
| 2 | 同一人在不同渠道的记录未归并 | 需按金额+时间+对手方跨渠道匹配 |
| 3 | 忽略交易后余额的计算验证 | 银行流水应验证：上笔余额±本笔金额=本笔余额 |
| 4 | 将所有整数金额标记为异常 | 需结合案件类型和金额级别判断 |
| 5 | 直接将"备注"作为交易性质 | 备注可能不准确，需结合交易模式交叉验证 |
| 6 | 忽略交易时间与法律事实时间的对应 | 如分居日期/起诉日期/合同签订日期是分析的时间锚点 |

### 各类型特有隐性知识

| 案件类型 | 隐性知识 |
|----------|---------|
| CT1 | 取现→去向不明比转账→可追溯更可疑；小额多次比大额一次更隐蔽 |
| CT2 | "劳务费"备注可能是工资；代发标记是认定工资的关键证据 |
| CT3 | 部分还款按先息后本冲抵；砍头息应从本金扣除 |
| CT4 | 部分付款不免除剩余义务；先票后款/先款后票影响逾期起算 |
| CT5 | 金额区间直接影响量刑；主观明知推定仅为辅助不能替代证据 |
| CT6 | 消费水平与申报财产矛盾可能隐匿；定期转账可能是隐藏收入 |

## 10. case_context 对分析精度的影响（v2.0新增）

### 10.1 设计动机

v1.0的分析管线中，P3/P4/P5 仅依赖 NormalizedTransaction + CaseTypeSpec 进行全部分析。这导致：
- CT3 不知道借款本金是多少 → 还款中利息占多少只能靠猜测
- CT4 不知道约定付款日 → 逾期只能模糊判断"看起来晚了"
- CT2 不知道约定工资 → 只能靠备注和模式推断"这可能是工资"

v2.0 的核心改进：在 P2 归一化数据的同时，加载 `case_context`——案件相关的结构化参考数据——让 P3/P4/P5 的分析从"猜测"变为"比对"。

### 10.2 对比：有无 case_context 的分析精度差异

| 分析步骤 | 无 case_context（v1.0） | 有 case_context（v2.0） |
|----------|----------------------|----------------------|
| **CT2 工资识别** | 依赖备注关键词"工资/代发" + 规律性推断 | 直接按 employer_name 过滤对手方 + agreed_salary ±10% 匹配金额 |
| **CT3 本息拆分** | 还款总额>本金时标注"可能含利息"，无法精确拆分 | 按 principal_amount 逐笔区分本金归还/利息支付，按先息后本冲抵 |
| **CT4 逾期计算** | 看到付款晚于预期，模糊标注"疑似逾期" | 按 payment_schedule 逐节点比对实际付款日，精确计算逾期天数 |
| **CT1 异常转移** | 标记所有大额整数转账为"疑点" | 按 separation_date 确定时间窗口 + known_relations 匹配特定关系人，提升命中精度 |
| **CT5 涉案筛选** | 按用户口头描述的"大概那个时间段"过滤 | 按 crime_period_start/end 精确过滤 + involved_parties 匹配对手方 |
| **CT6 消费分析** | 从消费中归纳"看起来消费水平较高" | 按 execution_amount 计算月均消费/执行金额比例，量化矛盾程度 |

### 10.3 case_context 加载后的置信度提升规则

| case_context 完整度 | P3 分类置信度 | P4 异常敏感度 | P5 追踪深度 |
|---------------------|-------------|-------------|-----------|
| required 全有 | 高(+1级) | 精确量化 | 案型默认深度 |
| required 有 + recommended 有 | 高(+1级) | 精确量化+额外规则激活 | 案型默认深度+1层 |
| required 缺失1-2个 | 不变 | 相关规则跳过 | 案型默认深度 |
| recommended 缺失 | 降1级 | 相关规则置信度降级 | 案型默认深度-1层 |
| case_context 完全缺失 | 按v1.0运行 | 按v1.0运行 | 案型默认深度 |

### 10.4 分析日志输出规范

每次 case_context 辅助分析后，在输出中标注影响：

```
> 🔍 case_context辅助分析：
> · separation_date={2024-02-01} → 激活起诉前180天窗口，识别4笔疑似转移
> · known_relations={张某, 李某} → 关联方交易匹配命中3笔
> · filing_date缺失 → 异常转移窗口使用默认180天（可能不精确，建议补充）
```
