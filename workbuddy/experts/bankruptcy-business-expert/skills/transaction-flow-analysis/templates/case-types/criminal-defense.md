# CT5 刑事辩护分析配置（criminal-defense）

## 基本信息

| 属性 | 值 |
|------|-----|
| 类型ID | CT5 |
| 类型名称 | 刑事辩护 |
| name_en | criminal-defense |
| 族 | 刑事涉案族 |
| 能力层 | C类（高风险） |
| 风险等级 | L3 |

> **C类高风险警告**：CT5涉及刑事涉案金额认定，金额区间直接影响量刑。所有金额认定结论必须标注"需律师结合案情确认"，禁止给出确定性金额认定。

## 分类标签体系

| 标签ID | 分类标签 | 法律要件说明 | 核心法条 | 识别规则 | 置信度影响 |
|--------|----------|-------------|---------|----------|-----------|
| CT5-L01 | 涉案资金 | 与指控事实直接相关的资金往来 | 《刑法》第64条 | 涉案期间+涉案人员+涉案金额范围 | 中 |
| CT5-L02 | 关联资金 | 与涉案人员或账户有关的资金 | 案件具体情况 | 对手方为涉案人员/公司+交易期间重合 | 低 |
| CT5-L03 | 待定 | 无法确定是否与案件相关的资金 | — | 不满足以上规则 | 低 |

### 分类优先级

```
CT5-L01(涉案资金) > CT5-L02(关联资金) > CT5-L03(待定)
```

### 涉案金额区间认定规则

| 规则 | 说明 |
|------|------|
| 以指控事实为基准 | 起诉书/起诉意见书认定的金额为锚点 |
| 交易时间窗口 | 仅统计涉案期间内的交易 |
| 资金流向完整性 | 追踪涉案资金的完整流向路径 |
| 金额区间标注 | 给出最低值-最高值区间，而非确定值 |
| 律师确认强制 | 所有金额认定结论必须标注"需律师确认" |

## v3.0 案型分析参考

> 报告统一为HTML格式（10区块结构），核心发现须含六要素（+对方可能抗辩+策略影响评估）（v3.0）。**C类高风险：所有金额为区间推定，禁止确定性认定。** 以下为CT5案型的分析要点参考，实际输出结构以output-spec.md v3.0为准。

### CT5 六要素核心发现参考

**发现1：涉案金额区间 vs 指控金额**（影响标签：CRITICAL）

| 六要素 | 撰写要点 |
|--------|---------|
| 事实叙事 | 从交易记录推算涉案金额为B-C元区间，指控金额为D元，差异E% |
| 数据锚点 | 3个关键数字：交易推算最低值、最高值、与指控金额差异率+证据行号 |
| 法律分析 | 刑法第64条（违法所得追缴）→本案适用：金额区间B-C元，与指控D元差异E%，直接影响量刑档次认定 |
| 对方可能抗辩 | 抗辩（辩方角度）："交易推算金额低于指控/部分交易非涉案" → 应对（控方角度）：逐笔论证涉案关联性；辩方利用差异主张从轻 |
| 策略影响评估 | 对辩护方向：金额区间下限低于指控→从轻辩护基础；对举证责任：控方负金额认定举证责任；对量刑协商：可基于区间下限谈判 |
| 诉讼策略建议 | ⚠️ C类必须标注"需律师结合案卷确认"；建议向侦查机关申请调取中间账户流水验证资金去向 |

**发现2：资金回流路径**（影响标签：CRITICAL）

事实叙事聚焦"N条资金回流路径A→B→C→A"，对方抗辩预判"资金回流系正常商业往来"，策略影响为"回流模式影响主观明知推定"。

**发现3：资金多层转手与主观明知推定**（影响标签：SIGNIFICANT）

事实叙事聚焦"N笔资金经M层转手+停留时间/转出比例"，对方抗辩预判"不知情+资金用途不明"，策略影响为"仅为间接证据不可替代直接证据"。

### CT5 特有证据附件

| 附件 | 内容 | CT5特有字段 |
|------|------|-------------|
| 逐笔分类明细 | 全部交易分类标注 | 为何认定涉案/关联列+置信度 |
| 涉案金额区间详表 | 推算vs指控对比 | 指控金额/交易最低值/最高值/区间/差异率 |
| 资金分层追踪表 | 逐层资金流向 | 层级/流入/流出/净额/停留时间/转出比例 |
| 主观明知推定依据 | 辅助推定汇总 | 推定依据/涉及交易/推定强度（弱/中/强） |

降级时省略"主观明知推定依据"和"资金分层追踪"，仅保留"涉案金额区间"的粗粒度标注（仅含指控金额与交易总额对比，不给出区间推算）。六要素核心发现对方抗辩和策略影响可简化，但C类必须保留"需律师确认"标注。
