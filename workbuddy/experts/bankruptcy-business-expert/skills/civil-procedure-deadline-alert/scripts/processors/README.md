# Processors for deadline-alerts

本目录包含由 LSO-Lite v3.1.0 自动生成的处理器骨架。

## 设计原则

- 仅生成高置信度脚本化候选
- 所有处理器默认需要人工补全核心逻辑
- 涉及高法律风险内容时，输出必须保留 `needs_human_review`

## 文件说明

| 文件 | 检测器 | 用途 | 置信度 | 更新日期 |
|------|--------|------|--------|----------|
| `date_deadline_alerts.py` | D2_date_calculation | 期限日期计算（含节假日顺延） | 95% | 2026-03-14 |
| `citation_deadline_alerts.py` | D5_citation_validation | 法条引用校验 | 82% | 2026-03-14 |

## 法律依据来源

本处理器使用的法律条文均来源于：
- 《中华人民共和国民法典》（2021年1月1日施行）
- 《中华人民共和国民事诉讼法》（2024年1月1日施行）
- 《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》（2022年修正）
- 《最高人民法院关于民事诉讼证据的若干规定》

法条有效性验证至2024年，后续修订请关注：
- 国家法律法规数据库: https://flk.npc.gov.cn/
- 最高人民法院: https://www.court.gov.cn/

## 开发要求

1. **不得删除输入校验** - 所有处理器必须保留输入参数校验
2. **不得将高风险输出默认标记为无需复核** - 必须保留 `needs_human_review: True`
3. **需在实现后补充单元测试** - 每个处理器需覆盖正常/异常场景
4. **接入官方数据源** - 日期处理器需接入节假日API，法条处理器需接入法律数据库

## 最低测试要求

每个处理器需测试以下场景：

- [ ] 正常输入
- [ ] 缺失必填字段
- [ ] 非法格式输入
- [ ] 边界值（如节假日边界）
- [ ] 高风险场景（触发人工复核）

## 风险说明

### date_deadline_alerts.py
- **节假日数据可能不完整** - 需接入官方节假日数据源
- **特殊情形未处理** - 鉴定、中止、延期等需人工判断
- **地区差异未考虑** - 不同地区可能存在特殊规定

### citation_deadline_alerts.py
- **法条时效性** - 法条库更新至2024年有效法律，后续修订需人工更新
- **司法解释未完全收录** - 主要收录期限相关司法解释，未覆盖全部
- **地方法规未覆盖** - 需补充地方法规库
- **法条引用格式** - 支持《民事诉讼法》《民法典》等常用引用格式
