### 一、企业破产法（2007年6月1日施行）

#### 第一章 总则

| 条文 | 内容摘要 |
|---|---|
| 第1条 | 立法目的：规范企业破产程序，公平清理债权债务，保护债权人和债务人合法权益 |
| 第2条 | 破产原因：不能清偿到期债务+资产不足以清偿全部债务或明显缺乏清偿能力 |
| 第3条 | 管辖：债务人住所地人民法院管辖 |

#### 第二章 申请和受理

| 条文 | 内容摘要 |
|---|---|
| 第7条 | 申请主体：债务人/债权人/负有清算责任的人 |
| 第10条 | 债权人申请的，法院5日内通知债务人，债务人7日内可异议 |
| 第11条 | 法院受理后25日内通知已知债权人并公告 |
| 第13条 | 法院受理同时指定管理人 |

#### 第三章 管理人

| 条文 | 内容摘要 |
|---|---|
| 第24条 | 管理人资格：有关部门/机构/人员组成的清算组/律师事务所/会计师事务所等 |
| 第25条 | 管理人职责：接管/调查/管理/处分债务人财产/代表债务人参加诉讼等 |
| 第27条 | 管理人勤勉忠实义务 |
| 第28条 | 管理人报酬 |

#### 第四章 债务人财产

| 条文 | 内容摘要 |
|---|---|
| 第30条 | 债务人财产范围：受理时属于债务人的全部财产+受理后至程序终结前取得的财产 |
| 第31条 | 可撤销行为（受理前1年内）：无偿转让/不合理价格/追加担保/提前清偿/放弃债权 |
| 第32条 | 偏颇清偿（受理前6个月内）：已具备破产原因仍个别清偿 |
| 第33条 | 无效行为：隐匿转移财产/虚构债务 |
| 第34条 | 追回财产：管理人有权追回因第31/32/33条行为转移的财产 |
| 第35条 | 出资人补缴：出资人未履行的出资义务加速到期 |
| 第36条 | 董监高非正常收入：董事/监事/高管的非正常收入和侵占财产应追回 |
| 第37条 | 质物取回：管理人可通过清偿债务或提供担保取回质物 |
| 第38条 | 取回权：权利人可取回不属于债务人的财产 |
| 第39条 | 出卖人取回权：在途标的物 |
| 第40条 | 抵销权：受理前债权人对债务人负有债务的可主张抵销（三种禁止情形） |

#### 第五章 破产费用和共益债务

| 条文 | 内容摘要 |
|---|---|
| 第41条 | 破产费用：诉讼费/管理人报酬/管理人执行职务费用/工作人员费用 |
| 第42条 | 共益债务：继续营业债务/无因管理/不当得利/劳动报酬/侵权赔偿等 |
| 第43条 | 清偿顺序：破产费用和共益债务随时清偿；不足时先清偿破产费用 |

#### 第六章 债权申报

| 条文 | 内容摘要 |
|---|---|
| 第44条 | 债权人权利：受理时对债务人享有债权的债权人有权申报 |
| 第45条 | 申报期限：法院确定，最短30日最长3个月 |
| 第46条 | 未到期债权视为到期；附利息债权自受理时停止计息 |
| 第48条 | 职工债权免申报，由管理人调查后列清单公示 |
| 第50条 | 连带债权申报：可一人代表申报也可共同申报 |
| 第56条 | 补充申报：逾期可在最后分配前补充申报，但不补充分配 |
| 第57条 | 管理人审查：管理人审查编制债权表 |
| 第58条 | 债权核查：第一次债权人会议核查；无异议由法院裁定确认 |

#### 第七章 债权人会议

| 条文 | 内容摘要 |
|---|---|
| 第59条 | 组成：依法申报债权的债权人，分有表决权/无表决权 |
| 第60条 | 主席：法院从有表决权债权人中指定 |
| 第61条 | 职权：核查债权/监督管理人/选任债委会/营业决定/重整计划/和解协议/管理方案/变价方案/分配方案 |
| 第62条 | 召集：第一次会议由法院召集，于申报期限届满后15日内召开 |
| 第64条 | 表决：出席会议有表决权债权人过半数+所代表债权额占无担保债权总额1/2以上 |
| 第65条 | 未通过处理：方案未通过由法院裁定 |
| 第67-68条 | 债权人委员会：设立与职权 |
| 第69条 | 管理人向人民法院报告工作，并接受债权人会议和债权人委员会的监督 |

### 二、破产法司法解释一（法释〔2011〕22号，2011年9月26日施行）

| 条文 | 内容摘要 |
|---|---|
| 第1条 | 破产原因认定：不能清偿到期债务+资产不足/明显缺乏清偿能力 |
| 第2条 | "不能清偿到期债务"认定：债权债务关系依法成立+履行期限届满+未完全清偿 |
| 第3条 | "资产不足以清偿全部债务"认定：资产负债表/审计报告等显示资产不足 |
| 第4条 | "明显缺乏清偿能力"认定：资金严重不足/财产不能变现/法定代表人下落不明/被强制执行无法清偿/长期亏损经营困难 |
| 第6条 | 债权人申请权：未到期债权人在债务人出现破产原因时可申请 |
| 第7条 | 诉讼费：破产申请费从债务人财产中拨付 |
