# 破产核心权利构成要件库

> 本文件为破产法律研究技能的参考文件，系统梳理破产程序中五项核心权利的构成要件。

---

## 一、撤销权（企业破产法第31条）

| 要件 | 内容 | 审查要点 |
|------|------|---------|
| 时间要件 | 破产申请受理前1年内 | 以受理裁定书日期为基准倒推1年 |
| 行为要件 | 无偿转让财产/明显不合理价格交易/无担保债务追加担保/未到期债务提前清偿/放弃债权 | 逐项核实交易记录 |
| 主体要件 | 管理人行使 | 管理人以自己名义提起撤销之诉 |
| 法律效果 | 行为被撤销，财产追回 | 追回财产纳入债务人财产 |
| 例外 | 无 | 第31条无例外规定 |

### 撤销权五种行为类型详解

| 行为类型 | 识别特征 | 审查要点 | 法律后果 |
|---------|---------|---------|---------|
| 无偿转让财产 | 无对价或明显低对价 | 交易对手/时间/财产价值 | 撤销后财产追回 |
| 明显不合理价格交易 | 价格偏离市场价70%以上 | 市场比价/评估依据 | 撤销后财产追回 |
| 无担保债务追加担保 | 原无担保后追加 | 担保设立时间/债务发生时间 | 撤销担保 |
| 未到期债务提前清偿 | 清偿日在债务到期前 | 清偿时间与到期日间隔 | 撤销后款项追回 |
| 放弃债权 | 明示或默示放弃 | 放弃方式/债权金额 | 撤销后债权恢复 |

## 二、偏颇清偿撤销权（企业破产法第32条）

| 要件 | 内容 | 审查要点 |
|------|------|---------|
| 时间要件 | 破产申请受理前6个月内 | 以受理裁定书日期为基准倒推6个月 |
| 状态要件 | 债务人已具备破产原因 | 资不抵债/不能清偿到期债务 |
| 行为要件 | 对个别债权人进行清偿 | 区分正常清偿与偏颇清偿 |
| 例外1 | 正常经营活动中清偿 | 须证明属于正常经营 |
| 例外2 | 生命身体损害赔偿 | 人身损害赔偿不撤销 |
| 法律效果 | 行为被撤销，清偿款追回 | 追回款项纳入债务人财产 |

---

## 三、抵销权（企业破产法第40条）

| 要件 | 内容 | 审查要点 |
|------|------|---------|
| 时间要件 | 债权人在破产申请受理前对债务人负有债务 | 以受理日为界 |
| 基本条件 | 互负债务可在破产程序中抵销 | 双方债务均合法有效 |
| 禁止情形1 | 受理后取得他人对债务人的债权 | 转让取得不享有抵销权 |
| 禁止情形2 | 明知破产事实负担债务 | 例外：正常经营/生命身体 |
| 禁止情形3 | 明知破产事实取得债权 | 例外：正常经营/生命身体 |
| 法律效果 | 抵销后债务消灭 | 抵销额以较低债务额为限 |

### 抵销权审查清单

- [ ] EC-1: 债权人在破产申请受理前对债务人负有债务？
- [ ] EC-2: 是否存在不得抵销情形（受理后取得/明知破产负担债务/明知破产取得债权）？
- [ ] EC-3: 是否属于正常经营或生命身体损害赔偿例外？
- [ ] EC-4: 抵销金额是否明确、计算是否准确？

## 四、取回权（企业破产法第38条）

| 要件 | 内容 | 审查要点 |
|------|------|---------|
| 权利基础 | 财产不属于债务人 | 所有权保留/租赁/借用/信托等 |
| 占有状态 | 债务人占有该财产 | 实际占有或间接占有 |
| 行使方式 | 通过管理人取回 | 向管理人主张，管理人核实后放行 |
| 行使时间 | 破产申请受理后 | 受理前不得行使 |
| 限制 | 重整期间取回权受限（第76条） | 重整期间取回须符合重整计划 |

---

## 五、别除权（企业破产法第109条）

| 要件 | 内容 | 审查要点 |
|------|------|---------|
| 权利基础 | 对特定财产享有担保物权 | 抵押权/质权/留置权 |
| 优先范围 | 就该特定财产优先受偿 | 以担保物变现价值为限 |
| 超额处理 | 超出担保债权额部分纳入分配 | 超额部分归入债务人财产 |
| 不足处理 | 不足部分转为普通债权 | 不足部分参与普通分配 |
| 重整特殊 | 重整期间担保权暂停行使（第75条） | 但担保物有损坏或价值明显减少的除外 |

## 六、权利竞合处理规则

| 竞合情形 | 处理规则 | 法律依据 |
|---------|---------|---------|
| 撤销权与抵销权竞合 | 先行使撤销权追回财产，再审查抵销权 | 第31条+第40条 |
| 取回权与别除权竞合 | 取回权优先（财产非债务人所有） | 第38条+第109条 |
| 建工优先权与抵押权竞合 | 建工优先权优先于抵押权 | 民法典第807条 |
| 职工债权与担保债权竞合 | 担保债权就担保物优先，职工债权就无担保财产优先 | 第113条+第109条 |
