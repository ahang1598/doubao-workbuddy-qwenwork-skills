# Example 001: 管理人履职报告

## 输入

```yaml
case: "XX制造有限公司破产清算案"
case_number: "（2026）粤03破申056号"
report_type: "duty"   # 履职报告（企业破产法第25条、第69条）
report_period: "2026-07-01 至 2026-09-30"
stages_completed:
  - takeover: "已完成（2026-07-05接管印章证照账簿）"
  - investigation: "进行中（银行流水分析中，已调取16家银行流水）"
  - claim_review: "进行中（已收到32份债权申报，审查完成5份）"
  - creditor_meeting: "第一次债权人会议定于2026-09-15"
```

## 预期输出

O1 管理人报告（docx，C-Professional格式）
- ①接管工作：已完成接管范围+时间节点
- ②调查工作：财产/经营/关联方调查方法及发现
- ③债权审查：审查方法/进度/结果（32份申报，5份完成，0份暂缓）
- ④债权人会议：第一次会议筹备中（9月15日）
- ⑤财产管理/处分：暂无第69条许可事项
- ⑥合规与信息披露：无利益冲突声明

O2 报告数据核对表（json）：data_consistency全通过
