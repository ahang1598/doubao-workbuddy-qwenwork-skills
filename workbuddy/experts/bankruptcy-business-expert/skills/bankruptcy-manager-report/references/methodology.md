# 管理人报告编制方法论

## 核心方法论概要

本技能围绕6种报告类型法定必含章节和数据一致性6项要求展开，确保管理人报告法定章节完整、数据准确、程序合规。

> SKILL.md M4 提供报告类型与法定章节对照表，本文件补充隐性知识、常见错误和地域差异。

---

## 隐性知识补充

### 不同报告类型的写作风格差异

| 报告类型 | 写作风格 | 受众 | 核心定位 |
|---------|---------|------|---------|
| 接管报告 | 事实陈述 | 法院/债权人会议 | 记录接管过程和财产状态 |
| 财产状况报告 | 分析说明 | 法院/债权人会议 | 分析资产负债状况 |
| 债权审查报告 | 结论+依据 | 法院/债权人会议 | 呈现审查结论和依据 |
| 分配方案 | 方案+计算 | 法院/债权人会议 | 提出分配方案供表决 |
| 履职报告 | 述职论证 | 法院 | 论证管理人已忠实勤勉履职 |

### 管理人忠实勤勉义务在报告中的体现

履职报告须体现管理人按照第25条履行了全部法定职责，包括：接管财产、调查财产、决定内部管理、决定营业、管理和处分财产、代表债务人参加诉讼、召开债权人会议、法院指定其他职责。

### 报告提交时限

| 报告类型 | 提交时限 | 法律依据 |
|---------|---------|---------|
| 接管报告 | 接管完成后及时提交 | 第25条 |
| 财产状况报告 | 调查完成后提交 | 第25条 |
| 债权审查报告 | 债权申报期满后编制 | 第57条 |
| 分配方案 | 财产变价完毕后 | 第115条 |
| 履职报告 | 程序终结时 | 第69条 |

### 数据来源标注规范

报告中每项数据须标注来源：债权数据→审查结论表；财产数据→资产调查报告；分配数据→分配计算底稿。不得使用未标注来源的数据。

## 常见错误与防范

| 错误类型 | 防范措施 |
|---------|---------|
| 遗漏法定必含章节 | 须对照法定章节清单逐项检查 |
| 数据与前序成果矛盾 | 须核对审查表/调查报告/计算底稿 |
| 虚构案件信息 | 须基于实际案件材料 |
| 空白章节或裸占位 | 须填充实际内容或标注"待补充" |
| 替代管理人签名盖章 | 须保留管理人签名盖章位置 |
| 数据未标注来源 | 每项数据须标注来源文件 |
