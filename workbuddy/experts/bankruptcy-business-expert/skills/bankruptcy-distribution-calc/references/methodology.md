# 破产分配计算方法论

## 核心方法论概要

本技能以"**三层分配模型（Layer 0→1→2）**"为核心计算方法论，辅以担保债权特殊处理和精度规则（4位小数+精确到分+尾差处理）。

### 三层分配模型

| 层级 | 名称 | 计算逻辑 | 法条依据 |
|------|------|----------|----------|
| **Layer 0** | 财产外扣除 | 担保物变现价款 → 先扣除变现费用 → 清偿别除权（第109条）+ 建工优先权（民法典第807条）→ 超额纳入Layer 1-2 / 不足转普通债权进Layer 2(三) | 第109/110条、民法典第807条 |
| **Layer 1** | 随时清偿 | 可供分配财产（含Layer 0超额部分）→ 先列支破产费用（第41条）→ 再列支共益债务（第42条）；不足时破产费用优先（第43条） | 第41/42/43条 |
| **Layer 2** | 第113条三顺位 | Layer 1剩余财产 → (一)职工债权（含养老/医疗个人账户）→ (二)社保统筹+税款 → (三)普通债权；前顺位未足额→后顺位清零 | 第113条 |

### 分配计算公式

```
Layer 0: 别除权受偿额 = min(担保物变现价款 − 变现费用, 担保债权额)
        超额 = max(0, 担保物变现价款 − 变现费用 − 担保债权额) → 并入Layer 1
        不足 = max(0, 担保债权额 − (担保物变现价款 − 变现费用)) → 转入Layer 2(三)

Layer 1: 可分配财产 = 非担保财产变现价 + Layer 0超额转入
        破产费用分配额 = min(可分配财产, 破产费用总额)
        共益债务分配额 = min(可分配财产 − 破产费用分配额, 共益债务总额)

Layer 2: 剩余财产 = 可分配财产 − 破产费用 − 共益债务
        (一) 职工债权分配额 = min(剩余财产, 职工债权总额)
        (二) 社保税款分配额 = min(剩余财产 − 职工分配额, 社保税款总额)
        (三) 普通债权清偿率 = (剩余财产 − 职工 − 社保税款) / 普通债权总额 × 100%
```

> SKILL.md M4 提供完整计算公式，本文件补充隐性知识、常见错误和地域差异。

## 隐性知识补充

### 模拟分配vs最终分配

- 模拟分配用于方案编制阶段测算清偿率，数据基于审查确认金额
- 最终分配须扣除中间分配已执行部分，确保累计不超过应分配额
- 分配方案中须标注"含中间分配已执行部分"

### 职工债权不足额时的比例计算

当可供分配财产不足以全额清偿职工债权时：
- 职工债权按 `可供分配/职工债权总额` 比例受偿
- 后续顺位（社保税款、普通债权）全部清零
- 须显著标注"职工债权未足额清偿"

### 担保物变现费用处理

担保物变现费用（评估费/拍卖费/保管费等）从担保物变现价款中**优先扣除**，剩余部分才用于担保债权清偿。这是实务中常被忽略的细节。

### 尾差处理实务

- 清偿率4位小数导致逐笔清偿额四舍五入产生尾差
- 尾差通常归入最后一笔清偿或管理人指定账户
- 须在分配方案中明确尾差处理方式
- 总额平衡核验时允许±尾差

### 清偿率精度规则

- 清偿率保留小数点后4位（如12.3456%）
- 清偿金额精确到分（四舍五入）
- 每步计算须列明公式、基数、比例和结果

### 多次中间分配累计核验

破产程序中常有多次中间分配（而非一次性分配），累计核验规则：
- **累计算法**：本次分配后累计已分配额 = 之前N-1次已分配额 + 本次分配额，累计额不得超过该顺位确认债权总额
- **清偿率一致性**：同一顺位的每次中间分配清偿率不必一致，但累计清偿率不得超过最终清偿率
- **核验公式**：`∑累计分配额 ≤ 确认债权总额` + `累计清偿率 = 累计分配额 / 确认债权总额`
- **分配间隔**：两次中间分配之间须预留足够时间处理债权异议和新增申报
- **最后一次分配**：扣除所有提存、预留后的剩余财产全额分配，结算累计清偿率

### 担保物评估价与变现价差异对清偿影响

担保物评估值与实际变现价的差异对担保债权及普通债权的影响：
- **变现价≥评估价**：担保债权全额受偿，超额部分并入破产财产
- **变现价<评估价**：担保债权以变现价受偿，差额转为普通债权
- **对分配方案的影响**：担保物未变现时用评估价预估，须标注预估前提；变现后须以实际变现价修正
- **差额风险**：评估价通常偏乐观，分配方案须额外注明"以实际变现结果为准"
- **交叉影响**：担保物变现差额直接影响普通债权可供分配财产（差额越大→普通债权可分配越少或越多）

### 税收滞纳金的清偿顺位

税收滞纳金在破产分配中的顺位长期存在争议（但因税收债权金额大，影响显著）：
- **主流观点（税务机关立场）**：滞纳金属税款从属，随税款本金在第113条第(二)项优先清偿
- **破产实务界观点**：滞纳金具有惩罚属性，应按普通债权处理（参照《国家税务总局关于税收征管若干事项的公告》（国家税务总局公告2019年第48号）第4条的精神——税收债权包含滞纳金，但实务中滞纳金优先性仍有争议，部分法院按普通债权处理）
- **实务处理**：①税款本金按第113条第(二)项优先 ②税收滞纳金多数法院按普通债权处理 ③须查阅受理法院的裁判倾向 ④如争议大，建议提存相应份额
- **税收罚款**：行政罚款属于惩罚性债权，按普通债权处理

## 常见错误与防范

| 错误类型 | 防范措施 |
|---------|---------|
| 使用未确认金额 | 仅基于审查确认数据，禁止使用申报或待确认金额 |
| 跳过顺位 | 前一顺位未足额清偿时后续顺位清零 |
| 草案与测算表不一致 | 草案（docx）与测算表（csv）数据须完全一致 |
| 仅给结果不给过程 | 每步列明公式/基数/比例/结果 |
| 承诺清偿率不变 | 须标注"测算参考，以法院裁定为准" |
| 遗漏尾差说明 | 须明确尾差处理方式 |
