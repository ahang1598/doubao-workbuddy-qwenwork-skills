# 破产分配计算 — 工作流程详情

## Phase 1：数据接收与校验
读取 claim_review_summary.json 和可供分配财产数据。校验：数据完整性/金额合理性/顺位标注完整性。数据不完整时进入SOFT_DEGRADED。

## Phase 2：汇总债权数据
按三层模型汇总：
- Layer 0：担保债权（担保物对应关系+变现费用+建工优先权）
- Layer 1：破产费用明细+共益债务明细
- Layer 2：职工债权（含养老/医疗个人账户）/ 社保统筹+税款 / 普通债权
统计各层笔数和金额。

## Phase 3：Layer 0 财产外扣除
逐笔处理担保债权：担保物变现价款→扣除变现费用→清偿别除权。超额纳入Layer 1-2分配池，不足转普通债权进入Layer 2(三)。建工优先权就工程变现价款优先。

## Phase 4：Layer 1 随时清偿（L3）
从可供分配财产中列支破产费用和共益债务。不足时先清偿破产费用（第43条）。逐项列明费用和债务明细。

## Phase 5：Layer 2 第113条三顺位清偿（L3）
依次计算：
- (一)职工债权：工资/医疗/伤残补助/抚恤/养老个人账户/医疗个人账户/补偿金。不足时按比例受偿，后续顺位清零，显著标注。
- (二)社保统筹+税款：养老统筹/医疗统筹/工伤/失业/生育+税款。不足时按比例受偿，后续顺位清零。
- (三)普通债权：清偿率 = 剩余可分配 / 普通债权总额 × 100%（保留4位小数）。逐笔计算清偿额（精确到分）。
尾差处理须标注。

## Phase 6：编制分配方案草案与测算表（L3）
编制分配方案草案(docx)和清偿率测算表(csv)。产出 distribution_calc_data.json。草案须含：Layer 0担保债权处理明细→Layer 1费用与共益债务列支→Layer 2三顺位清偿计算→逐笔清偿明细→分配方式与实施时间。每层列明总额/已分配额/清偿比例。担保物评估价与变现价差异须标注。

**自检清单**：数据来源为确认金额/三层模型严格依次/计算公式列明/草案与测算表一致/不足额显著标注/担保物变现费用已扣除/社保个人/统筹已区分/尾差处理说明。
