# 破产成果校验质量标准

## 质量评价维度

| 维度 | 评分标准 |
|------|---------|
| 只核验不改写 | 以问题清单标注，不改写实质内容。越权改写每处扣15分 |
| 来源回溯 | 每个结论回溯到具体文书位置或证据编号。未回溯每处扣5分 |
| 金额一致性优先 | 重点查找审查表与分配方案矛盾。遗漏矛盾扣15分 |
| 独立复核 | 优先级和法条复核独立得出结论。照抄扣15分 |
| 边界清晰 | 只判断是否可交付，不替代采纳决定。越权每处扣10分 |
| 结构化复用 | 优先读取结构化摘要核对。重复解析扣3分 |

## 阻断级检查项

| # | 检查项 | 判定标准 |
|---|--------|---------|
| BLK-01 | 禁止放过金额矛盾 | 逐笔执行五项核验规则 |
| BLK-02 | 禁止照抄审查/计算阶段表述充当独立复核 | 须体现独立验证过程 |
| BLK-03 | 禁止放行结果承诺/越权定性/法域误用 | V6校验须逐条检查 |
| BLK-04 | 禁止声称已修复问题 | 只标注不修复 |
| BLK-05 | 禁止遗漏法定必含章节检查 | report_type有值时必须执行 |
| BLK-06 | 禁止将待核查依据放行不标注 | V7校验须核对待确认项 |

|---|--------|---------|

## 质量评分标准

| 分数区间 | 等级 | 说明 |
|---------|------|------|
| 90-100 | 优秀 | 校验全面准确 |
| 75-89 | 合格 | 校验基本到位 |
| 60-74 | 需修改 | 遗漏校验项 |
| <60 | 不可交付 | 校验形同虚设 |
