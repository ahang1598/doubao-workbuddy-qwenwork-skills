# 破产成果校验方法论

## 核心方法论概要

本技能以八维校验框架（V1-V8）为核心，辅以法定必含章节检查6类、金额一致性核验5项和优先级独立复核，确保破产成果在交付前通过系统性核验。

> SKILL.md M4 提供八维框架和核验规则，本文件补充隐性知识、常见错误和地域差异。

---

## 隐性知识补充

### 独立复核原则的核心——不照抄前序阶段结论

优先级复核和法条复核必须独立进行：
- 重新排序：自行按第113条排序，与审查结论比对
- 重新核验法条：自行检索条文原文，验证条号/内容/施行状态
- 独立计算清偿额：逐笔用"确认金额×清偿率"重新计算

如果复核只是将前序阶段结论复述一遍而未体现独立验证过程，构成阻断级违规。

### 尾差容忍规则

- 单笔清偿额误差≤0.01元视为四舍五入尾差，不标注为问题
- 总额平衡允许±尾差（逐笔四舍五入累积产生）
- 超出0.01元的差异标注为阻断级问题
- 尾差容忍仅适用于四舍五入，不适用于计算公式错误

### 结构化复用优先

第一轮读取结构化摘要完成交叉比对，第二轮仅在发现矛盾时回溯原始文档。避免对整份文档重复解析。

### 校验的边界——只标注问题不改写实质内容

只做：标注问题、指出位置、说明违反规则、建议退回阶段。
不做：修改债权金额/优先级/法条表述/分配方案。不声称"已修复"。

### 法条复核三维度

1. 条文准确性：条号与内容是否一致
2. 施行状态：确认当前有效
3. 适用条件：法条适用前提是否满足

### 跨技能产物一致性校验

破产案件中多个技能的产物互为输入/输出，跨技能一致性校验是阻断级质量防线：
- **金额一致性**：claim-review 的确认债权总额 = distribution-calc 的输入债权总额；asset-investigation 的资产总额 ≥ distribution-calc 的破产费用预估
- **案件信息一致性**：案号/债务人名称/受理日期在所有技能产物中一致
- **顺位一致性**：claim-review 的债权顺位标号与 distribution-calc 的分配顺序对应
- **来源引用一致性**：manager-report 引用的数据来源编号与上游技能产物编号对应

**核验方法**：
- 读取各子代理产出的结构化中间产物文件（`claim_review_summary.json`/`asset_tracing_summary.json`/`distribution_calc_data.json`/`legal_research_summary.json`），按实际 JSON schema 字段路径取数
- 交叉比对：同一数据在不同产物中的值是否一致（如 claim-review 确认债权总额 = distribution-calc 输入债权总额；案号/债务人名称在所有产物中一致；债权顺位标号与分配顺序对应）
- 不一致时标注具体差异值、来源文件和引用位置

### 退回-修复-复校闭环

破产成果校验不是一个终点检查，而是一个迭代闭环：

**闭环流程**：
```
校验报告(初校) → 标注阻断项 → 退回对应阶段技能
    ↓
修复(对应技能重新生成) → 修复后产物提交复校
    ↓
复校(仅校阻断项+受影响项) → 通过则放行 / 不通过则再次退回
```

**关键规则**：
- 初校：全量校验（O1八维框架全部执行）
- 复校：增量校验（仅校验上次阻断项 + 可能被修复影响的相关项）
- 退回指定：每个阻断项须指明退回哪个技能的哪个Phase（而非笼统"退回修改"）
- 迭代上限：最多退回复校2轮，2轮后仍有阻断→标记为"需人工介入"，不进入自动修复循环

**校验报告的追踪能力**：
- 初校报告编号：V-001
- 复校报告编号：V-001-R1（Round 1）/ V-001-R2（Round 2）
- 每份报告记录：哪些问题已修复/新发现哪些问题/哪些遗留/哪些转入人工

## 常见错误与防范

| 错误类型 | 防范措施 |
|---------|---------|
| 放过金额矛盾 | 逐笔执行五项核验规则，超0.01元一律标注 |
| 照抄前序阶段表述 | 须体现"独立排序/独立核验"痕迹 |
| 放行结果承诺或越权定性 | V6校验须逐条检查超授权表述 |
| 声称已修复问题 | 只标注问题，不修复 |
| 遗漏法定必含章节检查 | report_type有值时必须执行 |
| 将待核查依据放行不标注 | V7校验须核对前置阶段待确认项 |
