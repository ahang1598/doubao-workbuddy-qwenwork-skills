## O1: 重整计划草案（docx，必须）

### 写作规则（lawyer_draft 范式，§17.28 D3）

- **WR-01**: 经营方案须论证可行性而非空泛描述——须含市场分析/竞争分析/盈利预测/风险应对
- **WR-02**: 债权调整方案须说明调整理由和计算依据——同类同比例，差别对待须充分论证
- **WR-03**: 清偿方案须含资金来源和期限可行性分析——每项资金来源须评估可靠程度
- **WR-04**: 出资人权益调整须公平对待同类出资人——不同调整须说明理由
- **WR-05**: 清算地板测试须列明模拟清算清偿率对比——重整清偿率低于清算清偿率必须有"重整价值高于清算价值"的论证

### 论证主题清单（替代固定标题槽位）

- **主题1: 经营方案可行性**——市场分析/竞争分析/盈利预测/风险应对
- **主题2: 债权调整公平性**——各类债权调整方案+同类同比例原则+差别对待论证
- **主题3: 清偿方案可行性**——资金来源/期限安排/偿债能力分析
- **主题4: 清算地板测试**——模拟清算清偿率 vs 重整清偿率对比+增益说明
- **主题5: 出资人权益调整**——股权稀释/让渡/转增方案
- **主题6: 执行与监督**——执行期限/监督人/报告义务
- **主题7: 其他有利于重整的方案**

> 第81条仅作论证方向指引（并非固定标题槽位），LLM 可根据债务人具体情况重新组织标题和逻辑，但必须覆盖全部7个论证主题。

### 和解协议草案论证主题
- **主题1: 和解债权范围**——和解条件/债权减免方案
- **主题2: 清偿方案**——资金来源/期限/方式
- **主题3: 担保安排**——增信措施/担保方
- **主题4: 执行监督**——执行期限/违约后果

## O2: 债权调整与清偿对照表（csv，必须）

> 格式从 xlsx 降级为 csv（§17.17：LLM 无法直出二进制 xlsx，csv 可用 Excel 直接打开）。

各类债权调整前后对照：债权类别/调整前金额/调整比例/调整后金额/清偿方式/清偿期限/资金来源/调整依据。

### 格式要求
- UTF-8 BOM 编码（Excel 兼容）
- 逗号分隔，首行为表头
- 数字右对齐（Excel 打开后设置）

## DOCX 排版规格

### 1. 格式严肃度
C-Professional（客户级专业成果，管理人向法院/债权人会议提交的核心文件）

### 2. 结构权威来源
`rule/format-docx/types/bankruptcy/T-reorg-plan.md`

### 3. 页面布局
继承 `families/bankruptcy/spec.md`：
- 纸张：A4 纵向
- 页边距：上2.5cm / 下2.0cm / 左2.8cm / 右2.6cm
- **封面页必须包含**（重整计划为提交法院的核心文件）
- **目录必须包含**（重整计划通常 50-100 页）

### 4. 字体字号矩阵
- 封面标题：黑体、二号（22pt）、加粗、居中
- 文书标题：黑体、三号（16pt）、加粗、居中
- 正文：宋体、小四号（12pt）
- 一级标题：黑体、四号（14pt）
- 二级标题：宋体、小四号（12pt）、加粗
- 表格内容：宋体、五号（10.5pt）
- 表头：宋体、五号（10.5pt）、加粗、居中

### 5. 段落间距参数表
- 行距：1.5 倍行距
- 首行缩进：2 字符
- 表格内行距：单倍行距

### 6. 编号规则
四级编号：一、（一）、1.、（1）——论证复杂时可达四层。

### 7. 偏离声明
参考 T-reorg-plan 类型卡覆盖项（封面必须+目录必须+页眉案号+保密标注）。

### 8. python-docx 渲染指令
LLM 直接生成 docx 内容（script_necessity=none），不含脚本渲染。

### 9. 禁止事项
| 排版禁止项 |
|-----------|
| 经营方案空泛无可行性具体论证 |
| 债权调整方案未区分各类债权且无同比例原则说明 |
| 清偿资金来源无可靠依据 |
| 清算地板测试缺失或核算方法不当 |
| 缺少封面和目录 |
| 落款缺少管理人或债务人公章位置 |
| 缺少保密标注（"内部资料·保密"） |
| 使用"保证"等绝对化表述 |

### 10. 内容结构
详见 T-reorg-plan 类型卡"内容骨架"（lawyer_draft 范式，§7 论证主题：重整必要性/经营方案/债权调整/清偿方案/清算地板/出资人权益/执行监督）。
