### 企业破产法（2007年6月1日施行）

| 条文 | 内容摘要 |
|---|---|
| 第70条 | 重整申请：债务人/债权人/出资额占1/10以上的出资人 |
| 第73条 | 债务人自行管理：经法院批准可在管理人监督下自行管理财产和营业 |
| 第75条 | 担保权暂停：重整期间担保权暂停行使（担保物有损坏或价值明显减少可能时除外） |
| 第77条 | 取回权限制：重整期间取回权行使须符合事先约定条件 |
| 第80条 | 草案提交：债务人或管理人6个月内提交（可延期3个月） |
| 第81条 | 草案内容：经营方案/债权分类/债权调整方案/债权受偿方案/执行期限/监督期限/其他 |
| 第82条 | 表决分组：担保债权组/职工债权组/税款债权组/普通债权组/（出资人组） |
| 第84条 | 表决：出席会议的同一表决组债权人过半数同意+所代表债权额占该组债权总额2/3以上 |
| 第86条 | 通过：各表决组均通过即为通过 |
| 第87条 | 强制批准：部分组未通过时法院可强制批准（条件严格） |
| 第89条 | 执行：债务人负责执行 |
| 第90-91条 | 监督：管理人监督执行 |
| 第93条 | 终止执行：债务人不执行或不能执行，法院裁定终止并宣告破产 |
| 第95条 | 和解申请：债务人可直接申请或在受理后宣告前申请 |
| 第97条 | 和解协议表决：出席会议有表决权债权人过半数+所代表债权额占无担保债权总额2/3以上 |
| 第100条 | 和解协议效力：对全体和解债权人有约束力 |
| 第104条 | 不执行后果：债务人不执行或不能执行，法院裁定终止并宣告破产 |

### 破产法司法解释三（法释〔2019〕3号）

| 条文 | 内容摘要 |
|---|---|
| 第14条 | 重整计划草案提交期限：6个月+延期3个月 |
| 第15条 | 强制批准条件：担保债权获得全额清偿/职工债权和税款全额清偿/普通债权清偿比例不低于清算清偿率 |
