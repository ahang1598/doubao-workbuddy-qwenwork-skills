# 破产资产调查方法论

## 核心方法论概要

本技能围绕三大核心维度展开：七类财产接管范围（现金/应收/存货/固定资产/投资性资产/无形资产/在建工程）、第31/32/33条分类线索梳理、关联交易四步识别法（关联关系识别→交易公允性→时间节点→资金流向穿透）。

> SKILL.md M4 提供概要表格，本文件补充隐性知识、常见错误和地域差异。

## 隐性知识补充

### 高风险信号深度解读

| 信号类型 | 隐性含义 | 调查方向 |
|---------|---------|---------|
| 受理前6个月集中转出 | 可能构成第32条偏颇清偿或第33条隐匿转移 | 逐笔核实转出对手是否为关联方/已知债权人 |
| 账龄异常长 | 应收账款可能已过诉讼时效或为虚假债权 | 核实债务人是否怠于催收或已放弃债权 |
| 大量出库无对应收入 | 可能系低价转让或无偿转让存货 | 比对同期销售合同和发票 |
| 低价转让股权 | 可能构成第31条明显不合理价格交易 | 调取股权评估报告计算价格偏离度 |
| 无偿许可关联方使用 | 可能构成第31条无偿转让财产 | 核实许可协议条款和关联关系链 |

### 资金流向穿透技术

资金流向追踪不能止于第一层交易对手。实践中常见多层嵌套：债务人→关联公司A→关联公司B→实际控制人个人账户。最终流向是否回到债务人或实际控制人是判断"虚假交易"的核心。受限于银行流水获取范围，第二层及以后的穿透往往需要管理人向法院申请调查令。

### 实质合并破产情形下的资产调查特殊规则

关联企业被裁定实质合并破产时：调查范围扩大至全部合并企业；内部交易在合并后消灭；撤销权起算点以最先被裁定受理破产申请的企业的受理日为准；须编制统一接管清单但按原企业归属标注。

### 执转破程序的财产调查衔接

执行转破产程序中须关注：执行法院财产查控信息移交、已拍卖未分配财产纳入接管、已扣划未分配存款确认归属、轮候查封财产梳理、执行异议对财产归属的影响。

### 诉讼时效对撤销权行使的影响

撤销权行使受诉讼时效约束（民法典第188条，3年）。但破产撤销权的起算点比较特殊：
- **第31条（1年期行为）**：从受理日起算，撤销权行使期间参照民法典第188条3年，与1年追溯期是两个独立维度（1年=行为追溯期，3年=权利行使时效）
- **第32条（6个月偏颇清偿）**：同理，6个月追溯期+3年行使时效
- **第33条（无效行为）**：无效行为确认之诉不受诉讼时效限制
- **实务要点**：管理人须在受理后及时核查，发现线索后尽快启动撤销权诉讼，避免临近3年时效届满

### 应收账款保理/质押的追收障碍

应收账款保理和质押对管理人追收的三大障碍：
1. **保理已转让**：有追索权保理中债务人仍为第一还款人，管理人可追收；无追索权保理中债权已真实转让，不属于破产财产
2. **质押已登记**：应收账款质押登记在央行征信中心，登记后即取得优先权，管理人追收后质权人优先受偿（民法典第445条）
3. **虚假应收账款**：债务人（进入破产的企业）与第三方虚构应收账款用于融资——此种情形可构成第33条无效行为或第31条欺诈性转让
4. **核实要点**：核查应收账款是否为真实交易→核查是否已保理/质押→查询央行应收账款质押登记系统→区分追索权类型

### 审计报告与账面差异的线索价值

审计报告与债务人账面数据的差异是财产线索的重要来源：
- **审计调整分录**：调整分录本身解释差异原因（如"应收款核销无依据"→可能隐匿应收款）
- **保留意见/无法表示意见**：审计意见类型暗示财产状况真实性问题（保留意见通常指向特定科目）
- **期后事项调整**：审计报告日至受理日期间的变化须单独核实
- **关联方往来差异**：审计报告中关联方往来差异常指向可撤销的关联交易

## 常见错误与防范

| 错误类型 | 防范措施 |
|---------|---------|
| 虚构流水记录 | 所有流水引用须标注原始凭证编号 |
| 遗漏第31条分类标注 | 每条线索须标注行为类型（第31条第X项/第32条/第33条） |
| 将待核实表述为已查证 | 严格使用"核实状态"字段：已查证/待核实 |
| 改写银行流水金额日期 | 保留原始格式，标注"原始格式" |
| 遗漏犯罪线索报告 | 发现涉嫌犯罪线索须醒目标注并单独列出 |

## 地域差异与特殊情形

| 地区 | 特殊规定 | 影响 |
|------|---------|------|
| 深圳 | 个人破产条例适用于自然人 | 涉个人破产须区分个人与家庭共同财产 |
| 北京 | 破产法庭实质合并细化标准 | 实质合并调查须参照"高度混同"认定标准 |
| 上海 | 预重整期间财产调查专门规定 | 预重整调查结论可直接用于正式重整 |
| 广东 | 跨境破产财产调查规定 | 涉港澳财产须通过司法协助途径调查 |
| 浙江 | 执转破衔接详细规定 | 执行查控信息可直接作为破产财产调查基础 |
