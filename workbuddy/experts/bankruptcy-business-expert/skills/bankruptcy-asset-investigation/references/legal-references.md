### 企业破产法（2007年6月1日施行）

| 条文 | 内容摘要 |
|---|---|
| 第25条 | 管理人职责：接管/调查/管理/处分债务人财产/代表债务人参加诉讼等 |
| 第30条 | 债务人财产范围：受理时属于债务人的全部财产+受理后至程序终结前取得的财产 |
| 第31条 | 可撤销行为（受理前1年内）：无偿转让/不合理价格/追加担保/提前清偿/放弃债权 |
| 第32条 | 偏颇清偿（受理前6个月内）：已具备破产原因仍个别清偿 |
| 第33条 | 无效行为：隐匿转移财产/虚构债务 |
| 第34条 | 追回财产：管理人有权追回因第31/32/33条行为转移的财产 |
| 第35条 | 出资人补缴：出资人未履行的出资义务加速到期 |
| 第36条 | 董监高非正常收入：董事/监事/高管的非正常收入和侵占财产应追回 |
| 第38条 | 取回权：权利人可取回不属于债务人的财产 |

### 破产法司法解释二（法释〔2013〕22号）

| 条文 | 内容摘要 |
|---|---|
| 第9条 | 撤销权行使：管理人依据第31/32条请求撤销 |
| 第10条 | 无偿转让认定：包括无偿转让财产和财产性权利 |
| 第11条 | 不合理价格认定：转让价格明显低于市场价格或明显高于市场价格 |
| 第12条 | 追加担保认定：对原无担保债务追加担保 |
| 第13条 | 提前清偿认定：清偿未到期债务 |
| 第14条 | 放弃债权认定：放弃债权或延长到期债权履行期 |
| 第15条 | 经诉讼/仲裁/执行的个别清偿不得撤销（恶意串通除外） |
| 第16-18条 | 撤销权例外情形 |
| 第44-46条 | 取回权细化规则 |
