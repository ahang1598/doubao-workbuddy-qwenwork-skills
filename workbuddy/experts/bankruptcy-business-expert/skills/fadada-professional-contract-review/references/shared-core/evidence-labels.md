# 依据来源标签规范（共享内核 · SSOT）

> fadada / english 两技能共用的 D1-S4 + D3-S4 依据标注规则单一真源。

## 1. 封闭标签集（仅此四种）

| 标签 | 全称 | 来源 | 优先级 |
|---|---|---|---|
| `[用规]` | 用户规则 | 用户上传的内部规范、清单、红线 | 1（最高）|
| `[要点]` | 审查要点 | 用户提示词中明确指定的关注点 | 2 |
| `[法规]` | 法律法规 | 法律、行政法规、司法解释 | 3 |
| `[惯例]` | 行业惯例 | 行业通行做法 | 4 |

**禁用形式**（任一出现 = D3-S4 fail）：emoji 标签 `📙📕📗📘🟢🟡🔴`、全称 `[用户规则]`、英文 `[USER]`、自创 `[公司规定][国标]`。

## 2. 使用顺序与冲突裁定（D1-S4，显式）

多依据并存时**按优先级排列**：用规 → 要点 → 法规 → 惯例。

冲突裁定：
- 用户规则与法律法规不冲突、用户规则更严 → 按用户规则。
- 用户规则与法律法规**直接冲突**（用户规定违法）→ **按法律法规（强制法覆盖用户规则）**，并在标注中提示用户。
- 用户规则 / 审查要点 高于 行业惯例。

> 强制法（mandatory law）始终覆盖与之冲突的用户规则。

## 3. 依据必须带原文摘录（裸标签 / 纯转述无效）

每条依据**必须引用来源原文片段并用「」包裹**，不得只给标签名、citation 或转述结论：

- `[法规]`：法律名称 + 条款编号 + **该条款原文摘录**。
  例：`[法规]《民法典》第585条「约定的违约金过分高于造成的损失的，人民法院或者仲裁机构可以根据当事人的请求予以适当减少」`
  **原文须经法规检索技能取得并核验现行有效性，禁止凭模型记忆编造法条原文**。按法域路由：
  - 中文法 → 调用「中国法律检索」技能（`skills_download/法律检索专家`，联网验证 + 北大法宝 MCP）取条文原文 + 时效。
  - 英文/美国法 → Descrybe MCP `verify_quote` / `search_laws_and_rules` / `get_case_passages` 核验取原文。
  - 其他法域 / 检索不可用 / 未通过验证 → 标 `待核查`，不写裸 `[法规]`、不出确定法律结论。
- `[用规]`：规则文件名 + 条款号 + **规则原话摘录**。
  例：`[用规]《采购合同审查规范》第3.2条「违约金不得超过合同总金额15%」`
- `[要点]`：**用户提示词原话**。
  例：`[要点]用户提示「重点关注付款条款和违约金」`
- `[惯例]`：行业名称 + **该惯例的具体可核查表述**（惯例无成文原文，须给具体做法，不得只写"业内常见"）。
  例：`[惯例]IT 服务业违约金通常约定为合同金额的 5%–10%`

反例（无效，必须补原文）：`[法规]：违反法律规定`、`[用规]：见公司规定`、`[惯例]：业内常见做法`、`[要点]：见提示词`。

每条风险条款依据块**至少一类不为 `/` 且带原文摘录**；四类皆无可引依据时用兜底语
`基于合理判断，建议专业律师确认`，不得全填 `/`。无法核验的权威 → `待核查`，绝不输出裸 `[法规]`。

**交付前自检**：每条 `[法规]`/`[用规]`/`[要点]` 依据均须含 「」 原文摘录；缺原文的依据视为无效，
必须补全原文或降级为 `待核查`，不得交付带裸标签的报告/批注。

## 4. 出现位置
- 修订版末尾「修订说明汇总表」依据来源列（多标签用中文顿号 `、` 分隔）。
- 带批注修订版批注气泡 `【修改依据】` 块：**只列真实触发（有内容）的标签，无内容者不列**（禁填 "/"）；批注按维度逐行换行。
- 评审报告 / 审查报告正文与「优先级 + 风险等级对照表」依据来源列。
