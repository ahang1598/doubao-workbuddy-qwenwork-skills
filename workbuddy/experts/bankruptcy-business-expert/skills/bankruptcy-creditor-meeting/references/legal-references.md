### 企业破产法（2007年6月1日施行）

| 条文 | 内容摘要 |
|---|---|
| 第59条 | 组成：依法申报债权的债权人，分有表决权/无表决权 |
| 第60条 | 主席：法院从有表决权债权人中指定 |
| 第61条 | 职权：核查债权/监督管理人/选任债委会/营业决定/重整计划/和解协议/管理方案/变价方案/分配方案 |
| 第62条 | 召集：第一次会议由法院召集，于申报期限届满后15日内召开 |
| 第64条 | 表决：出席会议有表决权债权人过半数+所代表债权额占无担保债权总额1/2以上 |
| 第65条 | 未通过处理：方案未通过由法院裁定 |
| 第67-68条 | 债权人委员会：设立与职权 |
| 第69条 | 管理人向人民法院报告工作，并接受债权人会议和债权人委员会的监督 |
| 第82条 | 表决分组：担保债权组/职工债权组/税款债权组/普通债权组/（出资人组） |
| 第84条 | 表决：出席会议的同一表决组债权人过半数同意+所代表债权额占该组债权总额2/3以上 |
| 第86条 | 通过：各表决组均通过即为通过 |
| 第87条 | 强制批准：部分表决组未通过时，法院在满足6项条件下可强制批准重整计划（担保债权全额清偿/职工税款全额清偿/普通债权不低于清算清偿率/同组公平对待/出资人权益调整公平公正/不违反法律行政法规强制性规定） |
| 第97条 | 和解协议表决：出席会议有表决权债权人过半数+所代表债权额占无担保债权总额2/3以上 |
