## 9. 输出格式规范

### 9.1 文件命名规范

| 制品 | 命名规则 |
|------|----------|
| 案件目录 | `{case-id}_{debtor-short-name}` |
| 元数据文件 | `case-meta.yaml` |
| 索引台账 | `portfolio-index.md` |
| 期限看板 | `deadline-dashboard.md` |
| 进度跟踪 | `progress-tracker.md` |
| 履职汇总 | `duty-summary_{start-date}_{end-date}.md` |
| 更新日志 | `update-log.md` |

### 9.2 双轨输出

| 格式 | 用途 | 消费者 |
|------|------|--------|
| YAML | 机读，供 agent/下游技能解析 | bankruptcy-business-expert |
| Markdown | 人读，供管理人查看 | 管理人/团队成员 |
| Excel（可选） | 导出报送 | 法院/管理人协会 |

### 9.3 写入位置规范

| 制品 | 写入位置 |
|------|----------|
| case-meta.yaml | 案件目录根目录 |
| portfolio-index.md | workspace_root |
| deadline-dashboard.md | workspace_root |
| progress-tracker.md | workspace_root |
| duty-summary.md | workspace_root |
| update-log.md | workspace_root |
