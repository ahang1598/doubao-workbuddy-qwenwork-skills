## 2. 破产清算特有目录

```
├── 08-财产变现方案/
│   └── README.md

│   └── README.md
└── 10-分配执行/
```

## 5. 目录说明

| 目录 | 用途 | 法定依据 |
|------|------|----------|
| 01-接管材料 | 接管债务人财产、印章、账簿、文书等 | 企业破产法第25条第1项 |
| 02-债权申报 | 债权申报材料、审查底稿、债权表 | 企业破产法第47-48条 |
| 03-财产调查 | 银行流水、不动产、股权、关联交易线索 | 企业破产法第25条第2项 |
| 04-债权人会议 | 会议通知、材料、表决结果 | 企业破产法第61-64条 |
| 05-履职报告 | 接管报告、财产状况报告、债权审查报告、履职总结 | 企业破产法第25条 |
| 06-程序文件 | 法院文书、公告文件、送达回证 | 程序合规要求 |
| 07-工作底稿 | 法律研究、会议记录、内部审批 | 内部管理要求 |
| 08-财产变现方案（清算） | 财产变价方案、拍卖文件 | 企业破产法第111条 |
| 09-分配方案（清算） | 分配方案草案、分配明细 | 企业破产法第109-113条 |
| 10-分配执行（清算） | 分配执行记录、分配凭证 | 企业破产法第116条 |
| 08-经营方案（重整） | 经营方案、重组计划 | 企业破产法第80条 |
| 09-重整计划草案（重整） | 重整计划草案、债权调整方案 | 企业破产法第79-80条 |
| 10-投资人招募（重整） | 招募公告、投资人材料、投资协议 | 重整实务要求 |
| 11-重整执行监督（重整） | 执行监督报告、执行记录 | 企业破产法第90-91条 |
| 08-和解协议草案（和解） | 和解协议草案、债权调整方案 | 企业破产法第95-96条 |
| 09-和解执行监督（和解） | 执行监督报告、执行记录 | 企业破产法第98-99条 |
