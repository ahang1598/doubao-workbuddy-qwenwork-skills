# 依赖声明

> 本文件声明 bankruptcy-case-portfolio-management 技能的上下游依赖关系

---

## 上游技能

本技能无上游硬依赖。它是破产管理人技能链的起点。

**弱引用**（如果已有，可增强输出）：
- 如果已有 `bankruptcy-business-expert`（破产业务专家团）的子代理产出，可用于补充案件工作空间的详细内容
- 如果已有 `transaction-flow-analysis`（交易流水分析）的产出，可用于补充财产调查目录

---

## 下游技能/Agent

本技能产出被以下技能/Agent消费：

| 下游技能/Agent | 消费内容 | 消费方式 |
|----------------|---------|---------|
| bankruptcy-business-expert（主 Agent） | 案件上下文（case-meta.yaml） | 读取案件元数据，注入会话上下文 |
| 债权审查员（member-claim-review） | 债权申报目录 + 案件元数据 | 定位债权申报材料，读取案件基本信息 |
| 资产追踪员（member-asset-tracing） | 财产调查目录 + 案件元数据 | 定位财产调查材料，读取案件基本信息 |
| 分配计算员（member-distribution-calc） | 分配方案目录 + 债权审查结论 | 定位分配方案材料，读取债权审查数据 |
| 破产法律分析员（member-legal-research） | 案件元数据 + 程序类型 | 读取案件类型和阶段，确定法律研究方向 |
| 破产成果校验员（member-verification） | 全部目录 + 案件元数据 | 校验案件材料完整性和程序合规性 |

---

## 消费指引

下游技能/Agent消费本技能产出时，遵循以下规则：

1. **case-meta.yaml 是主要消费入口**：下游技能读取案件元数据获取案件ID/案号/债务人/程序类型/当前阶段/团队/期限节点，替代手动输入
2. **目录结构是材料定位入口**：下游技能需要特定材料时，按目录结构定位（如债权审查员定位 `02-债权申报/`）
3. **不强制依赖**：下游技能可以在没有本技能产出的情况下独立运行（此时需自行输入案件信息）
4. **弱引用模式**：如果已有本技能的输出，则可用——提升效率和一致性
5. **状态同步**：下游技能更新案件状态后，应通过本技能的 UPDATE 模式同步到 case-meta.yaml 和索引台账

## 与 bankruptcy-business-expert 的协同关系

```
┌─────────────────────────────────────────┐
│  bankruptcy-business-expert（主 Agent） │
│  - 门控：案件上下文感知/传递/守门       │
│  - 调度：5个子代理编排                  │
│  - 报告：管理人报告生成                 │
│  - 不存储案件状态                       │
└─────────────┬───────────────────────────┘
              │ 调用
              ▼
┌─────────────────────────────────────────┐
│  bankruptcy-case-portfolio-management   │
│  （本技能）                             │
│  - 案件工作空间物理管理                 │
│  - 状态持久化到文件系统                 │
│  - 多案件索引台账                       │
│  - 跨案期限看板                         │
└─────────────┬───────────────────────────┘
              │ 读写
              ▼
┌─────────────────────────────────────────┐
│  案件工作空间（文件系统）               │
│  - 案件目录结构                         │
│  - case-meta.yaml                       │
│  - 索引台账/期限看板/进度跟踪           │
└─────────────────────────────────────────┘
```

**边界清晰**：
- 主 Agent 不存储案件状态（约束第9条）
- 本技能将状态持久化到文件系统
- 主 Agent 调用本技能来"读取/初始化/更新"案件工作空间
- 本技能不替代管理人作出履职决定
