### 字段说明

| 字段 | 填写说明 |
|------|---------|
| 申报金额 | 债权人申报的总金额（本金+利息+违约金等） |
| 申报性质 | 债权人主张的债权性质（货款/借款/工程款/工资等） |
| 审查确认金额 | 管理人审查后确认的金额 |
| 债权分类 | 八类法定清偿顺位分类之一（别除权依第109条就担保物优先受偿、单列不占113条顺位）：破产费用/共益债务/职工债权/社保统筹/税款/建工优先权/其他法定优先权/普通债权 |
| 优先顺位 | 1-8顺位 |
| 担保情况 | 有/无；担保物名称；担保物估值 |
| 抵销权审查 | 可抵销/不得抵销（附理由）/不适用/待核查 |
| 审查结论 | 确认/暂缓确认/待确认/不予确认 |
| 审查依据 | 合同/裁判文书/对账单等证据编号 |
| 待确认事项 | 需补充材料或核查的事项 |
