# 破产债权审查 — 工作流程详情

## Phase 1：材料接收与预处理

**输入**：债权申报材料路径、受理日期、案件类型
**动作**：
1. 扫描申报材料目录，建立材料清单（文件名/类型/大小/可读状态）
2. 对扫描件/照片执行OCR（使用 fadada-special-ocr）
3. 对PDF/Word/表格执行文本与结构提取（使用 pdf-processing-toolkit / fadada-contract-extractor）
4. 建立申报清单：申报人/申报金额/债权性质主张/证据材料/可读状态

**输出**：申报材料清单 + 可读文本
**风险**：OCR低置信内容须标注核对建议

## Phase 2：债权性质审查

**输入**：申报清单、案件类型、受理日期
**动作**：
1. 逐笔审查债权性质主张
2. 按三层清偿模型确定分类归属：
   - 是否受理后发生？→ 共益债务/破产费用（Layer 1）
   - 是否有财产担保？→ 别除权（Layer 0，就担保物优先）
   - 是否建设工程价款？→ 建工优先权（Layer 0，就工程优先）
   - 是否职工债权（含养老/医疗个人账户）？→ Layer 2(一)
   - 是否社保统筹/税款？→ Layer 2(二)
   - 否 → 普通债权 Layer 2(三)
3. 标注分类依据的法条和理由
4. 对性质有争议的标记"待确认"

**输出**：逐笔分类结论（含依据）
**风险**：L3 — 错误分类直接影响受偿顺位

## Phase 3：金额核验

**输入**：分类结论、申报金额明细
**动作**：
1. 本金核验：与合同/借据/对账单核对，多口径并列
2. 利息核验：列明计算基数/利率/起止时间/公式；注意LPR变动分段；受理后停止计息
3. 违约金核验：审查约定标准是否过高
4. 迟延履行金核验：生效裁判确定的迟延履行期间双倍利息
5. 诉讼时效标注：标注时效起算点和届满日
6. 金额存在矛盾的标记"待确认"

**输出**：逐笔金额核验结论（含计算过程）
**风险**：L3 — 金额错误直接影响受偿金额

## Phase 4：抵销权审查

**输入**：主张抵销的债权清单
**动作**：
1. 审查抵销时点：是否在受理前对债务人负有债务
2. 审查禁止情形（第40条）：受理后取得/明知负担/明知取得
3. 审查例外：正常经营/生命身体损害赔偿
4. 核验抵销金额计算
5. **审查异议诉讼时效**（破产法解释二第41条【已核实】）：管理人收到抵销主张后，有异议的须在**3个月内**提起诉讼——逾期未起诉则抵销生效。这是管理人最易失权的程序性陷阱，须在审查结论中明确标注"如有异议须在X年X月X日前起诉"
6. 出具结论：可抵销/不得抵销（附理由）/待核查（附待核事项）

**输出**：抵销权审查结论（含异议诉讼时限提醒）
**风险**：L3 — 错误允许抵销将减少可供分配财产；遗漏3个月异议诉讼时限将导致管理人失权

## Phase 5：优先顺位确定

**输入**：分类结论、金额核验结论
**动作**：
1. 按分类结果确定优先顺位
2. 对担保债权标注担保财产对应关系（担保物编号/变现价值）
3. 担保物变现超额部分纳入可供分配财产
4. 担保物变现不足部分转为普通债权
5. 生成优先顺位汇总表

**输出**：优先顺位汇总表
**风险**：L3

## Phase 6：编制审查结论

**输入**：全部审查结论
**动作**：
1. 按申报序号编制债权审查结论表（债权人/性质/申报金额/确认金额/顺位/结论）
2. 按结论分组：确认/暂缓/待确认/不予确认
3. 编制分类统计表（各层债权笔数和金额统计）
4. 编制待确认债权清单（含待确认原因和待核实事项）
5. 生成结构化摘要 claim_review_summary.json
6. 执行结构完整性自检（无空白章节/无裸占位）
7. 生成正式报告（格式严肃度 C-Professional，结构来源 rule/format-docx/types/bankruptcy/T-claim-review-table.md）

**输出**：审查结论表(docx) + 待确认清单(docx) + 结构化摘要(json) + 分类统计(csv)
**自检清单**：
- [ ] 每笔债权有分类结论和依据
- [ ] 每笔债权有金额核验结论和计算过程
- [ ] 抵销权审查结论完整
- [ ] 优先顺位标注正确
- [ ] 待确认债权全部列出
- [ ] 结构化摘要与审查结论表一致
