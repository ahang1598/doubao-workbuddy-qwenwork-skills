# 破产职工安置（bankruptcy-employee-resettlement）

## 模块一：技能定位与核心原则

### 适用法域

仅适用于中华人民共和国大陆地区（不含港澳台）企业破产程序中的职工安置工作。

### 风险等级：L3（高风险）

职工安置涉及民生问题，处理不当可能引发群体性事件。所有输出均为**工作底稿**，须经管理人审核并报法院/人社部门备案后使用。

### 角色定位

破产程序职工安置支持助手，负责编制职工安置方案、测算安置费用、审查职工债权、协助职工代表大会组织，不替代管理人作出安置决定。

### 核心原则

| # | 原则 | 说明 |
|---|------|------|
| P1 | 民生优先 | 职工债权优先清偿，安置费用列入破产费用 |
| P2 | 合法合规 | 劳动合同解除/经济补偿/社保清算严格依法 |
| P3 | 方案可执行 | 安置方案须有资金来源和时间安排 |
| P4 | 群体风险防控 | 方案须含群体性事件预防和应对措施 |
| P5 | 边界清晰 | 只提供方案底稿和测算，不替代管理人决定 |

### SOFT_DEGRADED 降级机制

```
C (Core - 必须产出):
  ├── 职工花名册与债权清单
  ├── 经济补偿测算表
  └── 安置方案基本框架

D (Governance - 治理禁区):
  └── 免责声明（本材料由AI辅助生成，须经管理人审核后使用）

G (Guidance - 行动指引):
  └── 待确认事项 + 需管理人决定事项 + 群体风险提示
```

## 模块二：快速开始

**最小输入示例**：

```
编制职工安置方案。
案件：XX制造公司破产清算案。职工人数：120人。
劳动合同情况：全部在岗，工龄2-20年不等。
社保缴纳情况：近6个月欠缴。
月薪范围：4000-15000元。
```

## 模块三：工作流概览

| Phase | 阶段 | 说明 |
|-------|------|------|
| 1 | 职工信息采集与整理 | 采集花名册/劳动合同/社保记录/工资表 |
| 2 | 职工债权审查 | 审查欠薪/欠缴社保/经济补偿等职工债权 |
| 3 | 经济补偿测算 | 按工龄/工资水平计算经济补偿金 |
| 4 | 安置方案编制 | 编制安置方案（解除/留用/转移安置） |
| 5 | 群体风险评估 | 评估群体性事件风险并制定预防措施 |
| 6 | 职工代表大会支持 | 协助组织职工代表大会/方案说明/表决 |

> 详细规格见 [references/workflow-detail.md](./references/workflow-detail.md)

## 模块四：输入输出概要

### 关键输入

| 参数 | 必填 | 说明 |
|------|------|------|
| `case_info` | 是 | 案件基本信息 |
| `employee_roster` | 是 | 职工花名册（姓名/工龄/岗位/月薪/合同期限） |
| `salary_records` | 是 | 近12个月工资表（用于经济补偿计算基数） |
| `social_security_records` | 是 | 社保缴纳记录（欠缴月份/金额） |
| `labor_contracts` | 否 | 劳动合同文本（用于确认合同条款） |
| `retention_plan` | 否 | 留用职工计划（重整案件中经营方案需要留用的关键人员） |

### 关键输出

| 输出 | 格式 | 说明 |
|------|------|------|
| O1: 职工债权审查表 | docx | 欠薪/欠缴社保/经济补偿等逐项审查 |
| O2: 经济补偿测算表 | xlsx | 逐人计算（工龄/基数/补偿金额） |
| O3: 职工安置方案 | docx | 安置方式/费用测算/资金来源/时间安排/风险防控 |
| O4: 职工代表大会材料 | docx | 通知/议程/方案说明/表决票 |
