# 财报研析团（Bank Retail Analyst）

六成员财报分析专家团：自动下载年报、提取零售数据，做同业对标与战略治理穿透分析，一键交付三份专业报告。

## 类型

Team 型（多角色协作团队）：1 主理人 + 6 成员 + 6 个内置 Skill。

## 功能

一条指令跑完银行零售财报分析全流水线：

1. **自动下载年报**：从巨潮资讯网（cninfo.com.cn）并行下载多家上市银行定期报告，并按页数校验文件真实性（防摘要误下）
2. **标准数据提取**：从年报表格提取零售分部效益、存贷款结构与定价、资产质量、银行卡手续费等标准化指标（粗筛 + 精筛双层架构，逐值可溯源）
3. **文字数据提取**：从年报文字描述提取 AUM、客户数、财富管理收入、信用卡经营等指标（带原文引用）
4. **同业对标分析**：重建对标数据库、计算派生指标（零售营收占比/存贷利差/减值负担率等）、五维排名，输出对标报告 PDF
5. **战略洞察**：高频词 + 组织架构变化 + 战略执行评估，生成 3-5 条优先级排序的核心洞察，输出洞察报告 PDF
6. **战略治理穿透**：领导力时间轴 / 叙事一致性 / 关键节点反事实 / 治理韧性评分四阶段穿透，输出治理分析报告 PDF

## 使用示例

- 以招商银行为基准，对比兴业/中信/平安银行，生成 2025 年零售业务同业对标全套报告（对标+洞察+治理）
- 下载招商银行、兴业银行、中信银行、平安银行 2025 年年度报告，提取零售业务数据并建立对标数据库
- 以招商银行为主角，生成 2025 年零售战略洞察报告与战略治理穿透分析报告

## 安装

将专家包目录（`bank-retail-analyst/`）放到本地专家目录（如 `~/.workbuddy/plugins/marketplaces/my-experts/plugins/`）下，在客户端「专家」入口刷新即可识别启用。启用后以「财报研析团」名称出现在专家市场。

## 打包分享

```bash
zip -r bank-retail-analyst.zip bank-retail-analyst/
```
