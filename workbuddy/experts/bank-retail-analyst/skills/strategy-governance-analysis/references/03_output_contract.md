# Skill 5 · 附录 03：输出契约（JSON Schema + Markdown 八节）

> **触发阅读条件**：生成 result.json / report.md 前必读；排查输出结构不合规时。

## 1. 硬性输出要求（不可协商）

### 硬性要求 1：严禁陈述财报已知事实，必须输出"数据背后的逻辑"

- **绝不重复** skill3 已给出的事实型数据，例如 ❌ "某某银行 2024 年零售营收 xxx 亿、同比 +x.x%"
- **必须穿透到**「**为什么是这个数字**」——指向**决策选择、领导意图、治理约束、组织惯性**四个层面之一
- 每一段结论**必须落在"数据解读 + 行为归因 + 治理解释"**三段式上，不得只堆指标
- **反例**：「A银行零售贷款占比 55%，领先B银行 12pp。」（只是事实）
- **正例**：「A银行零售贷款占比持续领先B银行 10pp+，并非起点差异，而是**田惠宇任期内持续 9 年将 KPI 权重向零售倾斜 60%+**（治理）**叠加** 2013 年钱荒时点**果断压降非标释放的 RWA 被定向分配至零售**（关键节点决策）的复利结果。」（数据 + 决策 + 治理）

### 硬性要求 2：识别风险点 —— 明确指出基准行在历次领导更替中的"战略摇摆"点及诱因

- **至少输出 2 个具体摇摆点案例**，每个必须包含：
  1. **时点**（精确到季度）与**事件名称**
  2. **前任战略口径** vs **新任战略口径**的原文对照
  3. **诱因归因**：从 4 类中明确选择 1~2 类
     - `leader_turnover` 领导更替驱动
     - `shareholder_will` 股东意志（国资深化 / 战投引入）
     - `regulator_push` 监管倒逼
     - `org_inertia` 组织惯性反噬
  4. **三类证据**（须齐备至少 2 类）：
     - 年报口径变化（原文引用）
     - 组织架构调整（部门新设/撤并事件）
     - 资源投向反转（资源指标折返点数据）
  5. **代价评估**：引用第三阶段 what-if 区间，量化摇摆造成的 ROE / 不良率机会成本

### 硬性要求 3：建议方案 —— 为基准行设计一套"战略隔离带"与"治理韧性"提升方案

- **必须分三类**组织建议（**缺一不可**）：

| 建议类别 | 定位 | 数量 | 示例方向 |
|---|---|---|---|
| **① 战略隔离带** | 让核心战略不因领导更替而摇摆 | 3~5 条 | 战略中长期锚定机制 / KPI 多任期权重绑定 / 战略委员会决议不可逆条款 |
| **② 治理韧性** | 提升组织承受外部冲击的弹性 | 3~5 条 | 董事会专业委员会常态化 / 风险偏好白皮书每任更新 / 组织架构稳定性保护机制 |
| **③ 关键人事安排** | 确保人才梯队服务于战略延续性 | 3~5 条 | 核心条线"任期跨周期"人选要求 / 零售+科技+风险三条线接班人池 / 跨任期 KPI 考核 |

- **每条建议必须含四要素**：**动作 → 理由 → 数据依据 → 预期效果**；缺一不可
- **禁止空泛表述**：❌ "建议关注 / 建议重视 / 建议加强" 一律视为不合格

## 2. Markdown 报告标准章节结构（八节）

> 不可随意增删，编号与标题保持一致。每节内部的具体小节可根据数据可得性裁剪，但**章节主干不得缺省**。

```
# 战略与治理分析报告
## 执行摘要（≤ 600 字）
    · 5 条核心结论（战略定力排名 / 基准行 TOP2 摇摆点 / 言行一致度均值 / 政策适配排名 / 建议总览）
    · 战略韧性得分一览表（5 行）

## 01 时间骨架：周期划分、领导画像与组织演进
    · 1.1 五周期表 + 宏观背景
    · 1.2 五行历任董事长/行长 Gantt（含背景类型）
    · 1.3 组织变革热力图（零售/科技/风险 × 年份）

## 02 穿透式"言行比对"
    · 2.1 战略关键词漂移轨迹（基准行 vs 4 标杆，2015~最新）
    · 2.2 "说的 vs 做的" ρ 矩阵（真战略 / 口号 / 话术 三色标注）
    · 2.3 领导更替下的战略延续性三色判定（进化 / 渐进 / 换届）

## 03 关键节点反事实推演
    · 3.1 五个关键节点（2013 钱荒 / 2016 MPA / 2018 资管新规 / 2020 疫情 / 2022 房地产）
    · 3.2 差异化决策逻辑（资本约束 / 风险偏好 / 业务结构依赖三维归因）
    · 3.3 基准行 what-if 模拟（三种资产配置路径 × 当前不良率/ROE 区间）
         —— 每条结论必须标注「模型推演，非事实」+ 置信度

## 04 治理结构影响机制
    · 4.1 董事会专业委员会议事频率 × 业绩波动相关性
    · 4.2 股东意志传导链（股权结构变化 → 风险边界 + 分红策略）
    · 4.3 战略韧性五角雷达 & 得分表

## 05 【风险点】基准行战略摇摆点诊断  ← 硬性要求 2 落点
    · 5.1 摇摆点 #1（YYYY-Qx · 事件名）
         - 前后战略口径原文对照
         - 诱因归因 & 三类证据
         - 代价评估（引用 3.3 区间）
         - 教训提炼
    · 5.2 摇摆点 #2
    · （如有） 5.3 摇摆点 #3

## 06 【建议】战略隔离带 & 治理韧性提升方案  ← 硬性要求 3 落点
    · 6.1 战略隔离带（3~5 条，每条四要素）
    · 6.2 治理韧性（3~5 条，每条四要素）
    · 6.3 关键人事安排（3~5 条，每条四要素）

## 07 数据窗口与降级说明
    · 分析窗口 / 数据窗口 / 已降级条目清单 / 数据源索引

## 08 免责声明
    · "本报告由 AI 基于上市银行公开披露信息生成，仅供研究参考，不构成任何投资建议，亦不构成对任何个股的推荐"
```

## 4. 输出文件清单

| 文件 | 内容 | 面向 |
|---|---|---|
| `~/RetailAnalysis/data/strategy_governance_result.json` | 结构化主输出：5 家银行画像卡 + 四阶段分析结果 + 战略韧性评分 + 基准行风险点 + 建议方案 | 机器可读 |
| `~/RetailAnalysis/output/<bank>/strategy_governance_report.md` | 分析报告（Markdown，面向高管阅读） | 人类阅读 |
| `~/RetailAnalysis/output/<bank>/战略与治理分析报告.pdf` | 默认生成的 PDF 交付物 | 董事会 / 战略委员会 |

## 5. PDF 上下文完整性红线

生成 HTML/PDF 前必须运行 `scripts/render_strategy_governance_report.py`。以下字段全部不得为空：

- `phase1.leader_timeline_html`、`phase1.org_heatmap_html`
- `phase2.consistency_table_html`、`phase2.continuity_items`
- `phase3.key_nodes`（5 个节点，每个包含 `decisions` 和 `what_if`）
- `phase4.board_activity_html`、`phase4.shareholder_events`、`phase4.resilience_scores`
- `swing_points` 至少 2 个
- `recommendations` 三类均非空

禁止直接将原始 `strategy_governance_result.json` 作为模板 `ctx`。原始字段与 PDF 模板字段不一致，直接调用会触发占位符并丢失中间产物信息。

## 6. 质量红线（与"输出要求"三条硬性约束配套）

1. **禁止复述财报事实**（对应硬性要求 1）：任何结论段落不得以"X 银行 YYYY 年零售营收 xxx 亿"类事实开头，必须以"**数据背后的逻辑**"切入；每个结论落在「数据解读 + 行为归因 + 治理解释」三段式。
2. **战略摇摆点 ≥ 2 个、证据 ≥ 2 类、诱因枚举受限**（对应硬性要求 2）：诱因必须从 `leader_turnover / shareholder_will / regulator_push / org_inertia` 四类中选择，不允许自造；三类证据至少齐备 2 项。
3. **建议四要素齐备、三类分栏齐备**（对应硬性要求 3）：「战略隔离带 / 治理韧性 / 关键人事安排」三栏缺一不可；每条建议必须含「动作 → 理由 → 数据依据 → 预期效果」，禁止"建议关注""建议重视"等空泛表述。
4. **反事实必须标注**：所有反事实推演结论显式标注「**模型推演，非事实**」+ 置信度（低/中/高）且给出区间（min ~ max）。
5. **言行一致度必须量化**：不得只写"言行一致"或"名不副实"，必须给出 ρ 值与判定理由（真战略 / 口号 / 话术）。
6. **数据缺失不补**：2004~2014 段数据缺失时显式降级，不插值、不臆测。
7. **领导画像来源明示**：每位领导的任期起止必须注明来自"xx 银行 YYYY 年年报 · 董事会成员简历"，避免网络搜索未校验。
8. **股东影响链须可追溯**：股权结构变化 → 风险偏好改变的因果链必须有年报或公告支撑，不做推测性跳跃。
9. **执行工程硬约束**：
   - 大文件（md/html/json）**禁止**单次 `write_to_file` 写入 >8KB；禁止 `execute_command` 内嵌长 heredoc 脚本
   - `~/RetailAnalysis/data/partial/sg_*.json` 12 个中间产物**必须齐备**
   - 前置核查 `skill5_preflight.sh` 任一项 `BLOCK` 未解决**禁止**进入四阶段分析
   - 再次执行时必须先走 Step 0.5 增量判断
