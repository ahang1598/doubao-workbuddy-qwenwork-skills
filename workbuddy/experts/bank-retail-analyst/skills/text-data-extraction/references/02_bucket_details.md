# Skill 2 · 附录 02：提取指标清单（A-H 七类 bucket）

> **触发阅读条件**：查询具体指标名称、同义词、所属 bucket、口径警示。

## 重点章节

**主要数据来源**：管理层讨论与分析 → 主要业务回顾 → 零售银行业务/零售金融业务

**辅助数据来源**：董事长致辞、行长致辞、业绩亮点、经营概述等章节

## 指标清单（按 bucket 归类）

### A. 零售AUM及相关（bucket: AUM）

| 指标 | 同义词/常见表述 | 提取要素 |
|------|---------------|---------|
| 零售AUM规模 | 客户管理资产、零售客户资产、个人金融资产 | 期末余额 + 变动金额/变动比例 |
| 私行AUM | 私人银行管理资产 | 期末余额 + 变动 |

> **口径警示**：每一期均应记录"本期规模"和"本期变动"两个值，不做算术推导。

### B. 客户数相关（bucket: 客户数）

| 指标 | 同义词/常见表述 | 提取要素 |
|------|---------------|---------|
| 个人客户数 | 零售客户数、个人客户总数 | 期末数量 + 变动 |
| 财富管理客户数 | 贵宾客户、富裕客户、金葵花客户、钻石客户等 | 期末数量 + 变动 |
| 私人银行客户数 | 私行客户 | 期末数量 + 变动 |

### C. 财富管理收入相关（bucket: 财富收入）

| 指标 | 同义词/常见表述 | 提取要素 |
|------|---------------|---------|
| 财富管理收入 | 财富管理手续费收入、代理业务收入 | 金额 + 同比变动 |
| 理财收入 | 理财业务收入、代理理财收入 | 金额 + 同比变动 |
| 保险收入 | 代理保险收入、保险代销收入 | 金额 + 同比变动 |
| 基金收入 | 代理基金收入、基金代销收入 | 金额 + 同比变动 |

### D. 信用卡经营相关（bucket: 信用卡）

| 指标 | 同义词/常见表述 | 提取要素 |
|------|---------------|---------|
| 信用卡累计发卡量 | 信用卡发卡量 | 期末累计数 + 新增数 |
| 信用卡有效卡量 | 有效信用卡 | 期末数量 |
| 信用卡流通卡量 | 流通信用卡 | 期末数量 |
| 信用卡交易量 | 信用卡消费交易额 | 期间累计金额 + 同比变动 |

### F. 分部效益类指标（bucket: 分部效益，关键补充）

> **⚠️ 重要**：A银行、B银行、C银行等银行的年报中，零售分部营收、利润等数据**仅在文字段中披露**，不在分部报告表格中出现。当 Skill 1 无法从表格提取这些数据时，**Skill 2 必须从文字段补充提取**。这是确保后续 Skill 3/4 对标分析完整性的关键环节。

| 指标 | 同义词/常见表述 | 提取要素 |
|------|---------------|---------|
| 零售分部营业净收入(文字) | 零售金融业务营业收入、零售业务营业收入、实现营业收入 | 金额 + 同比变动金额/变动比例 |
| 零售分部税前利润(文字) | 零售金融业务利润总额、零售业务利润总额 | 金额 + 同比变动 |
| 零售非息净收入(文字) | 零售手续费及佣金净收入、零售非利息净收入 | 金额 + 同比变动 |
| 零售信用减值损失(文字) | 零售信用风险减值损失、零售资产减值损失 | 金额 + 同比变动 |

> **口径警示**：文字段披露的零售营收口径可能与有业务线分部报告的银行（如D银行、E银行）不完全一致。提取时必须：
> 1. 记录原文中的口径说明（如"占全行营业收入的 39.93%"可反推全行营收口径一致性）
> 2. 在 `calibration_note` 中标注"来自文字段，非分部报告表格"

### G. 量价类指标（bucket: 量价，补充提取）

> 个人存款余额、存款成本率、贷款收益率等有时仅在文字段中披露，作为 Skill 1 表格提取的补充。

| 指标 | 同义词/常见表述 | 提取要素 |
|------|---------------|---------|
| 个人存款余额(文字) | 零售存款余额、个人存款、储蓄存款余额 | 期末余额 + 变动金额/变动比例 |
| 个人存款成本率(文字) | 零售存款成本率、个人存款付息率 | 比率值 + 同比变动（BPs） |
| 零售贷款收益率(文字) | 个人贷款收益率、零售贷款平均利率 | 比率值 + 同比变动（BPs） |
| 零售贷款不良率(文字) | 个人贷款不良率、零售不良率 | 比率值 + 同比变动（Pct） |

> **口径警示**：注意集团/本行口径、含/不含保证金存款等差异，必须在 `calibration_note` 中标注。

### E/H. 渠道 / 其他文字量化指标（bucket: 渠道 / 其他）

阅读零售业务章节全文时，如发现上述清单之外的**量化指标**（含具体数字），也应一并提取，例如：手机银行MAU、代发客户数、理财产品规模等。

## 子代理输出契约（摘要）

子代理必须按 `scripts/text_extractor_prompt.md` 契约，**输出纯 JSON**（不带 markdown 代码块），写入 `text_extraction/<bucket>.json`：

```json
{
  "bank": "某某银行", "period": "2025年度", "category_bucket": "AUM",
  "metrics": [
    {
      "standard_name": "零售AUM",
      "values": [
        {
          "period_label": "2025年度",
          "period_end_value": 45678.12,
          "change_value": 3456.78,
          "change_pct": 8.20,
          "unit": "亿元",
          "raw_quote": "截至报告期末，个人客户金融资产(AUM)达到 45,678.12 亿元，较上年末增长 3,456.78 亿元，增幅 8.20%。",
          "source_section": "管理层讨论与分析 > 零售银行业务",
          "source_page": 45,
          "candidate_id": "p01",
          "calibration_note": "含个人存款、理财、基金、保险、贵金属等，集团口径",
          "confidence": "high"
        }
      ]
    }
  ],
  "alerts": [], "notes": [...], "warnings": []
}
```

**严格约束**：
- 只能从 `candidates[*].context_text` 取值，找不到必须返回 `values: []`，**禁止编造**
- `period_end_value` 和 `change_value` 必须分别从原文提取，**严禁相减推算**
- `raw_quote` 必须保留完整句子，便于回溯
- `calibration_note` 必须抄录原文中所有口径说明
- 单位必须与 `target_metrics.unit` 一致；原表单位不同时做换算并在 `notes` 注明
- 本期 + 上期都要提取（若候选段落同时披露）
