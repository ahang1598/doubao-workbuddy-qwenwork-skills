# 一票否决红线、引用格式与就绪度

## 一、一票否决清单（先于打分执行）

红线问题的性质与"分数低"完全不同：**分数低是可以救的，红线是必须先处理才能谈其他**。命中任一条，本轮结论一律为**不予通过**，并给出补救路径。

| 代码 | 红线 | 判定要点 | 后果 | 补救路径 |
|------|------|----------|------|----------|
| **F1** | 学术不端 | 数据或图像伪造、篡改；抄袭；代写代投 | 退稿 + 学术声誉风险，可能进入黑名单 | 撤回问题材料，重做实验或如实说明；无法补救的建议放弃本篇 |
| **F2** | 伦理缺失 | 人体 / 动物试验无伦理审批号、无知情同意；隐私数据未脱敏 | 期刊直接拒稿，学位论文可在答辩环节被否 | 补办伦理审批（需原始时间线）、补充知情同意材料、脱敏重写 |
| **F3** | 统计或方法致命 | 方法根本性错误导致结论无效；样本量极端不足仍作强断言；数据来源无法溯源 | 结论不成立，全文论证作废 | 重做分析或降级结论表述，将断言改为探索性发现并明确标注 |
| **F4** | 形式致命 | 查重率超阈值；一稿多投 / 重复发表未声明；署名贡献争议未决；字数严重超限（超出 30% 以上） | 编辑直接退稿或撤稿 | 合法改写降重、撤稿一稿、书面确认署名、大幅删减至阈值内 |

**报告写法**：先列红线结论与证据位置，再给补救路径，最后才展开其余分析。**不得以"总分较高"为由淡化红线。**

## 二、引用格式要点

### 2.1 GB/T 7714（中文论文 / 中文期刊）

**文献类型标识**：专著 `M`、期刊 `J`、论文集 `C`、学位论文 `D`、报告 `R`、标准 `S`、专利 `P`、报纸 `N`、汇编 `G`、电子资源 `EB/OL`。

| 类型 | 著录格式 |
|------|----------|
| 期刊 | `[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码.` |
| 专著 | `[序号] 主要责任者. 题名[M]. 版本项. 出版地: 出版者, 出版年: 引文页码.` |
| 学位论文 | `[序号] 主要责任者. 题名[D]. 保存地: 保存单位, 年份.` |
| 标准 | `[序号] 标准编号 标准名称[S]. 出版地: 出版者, 出版年.` |
| 电子资源 | `[序号] 主要责任者. 题名[EB/OL]. (发布日期)[引用日期]. 访问路径.` |

**常见错例与正确写法**

| 错例 | 问题 | 正确写法 |
|------|------|----------|
| `张三, 李四. 电机控制研究. 汽车工程, 2023, 45: 12-18.` | 缺文献类型标识、卷期混写 | `张三, 李四. 电机控制研究[J]. 汽车工程, 2023, 45(3): 12-18.` |
| `Wang Li, et al. Control strategy[J]. ...` | 英文作者姓名顺序错误 | 英文著录姓在前、名缩写在后：`WANG L, LI M, et al.` |
| `[5] 见文献[3]` | 转引未著录原始文献 | 著录原始文献，或标注"转引自" |
| `张三等. 电机控制研究[J]. 汽车工程, 2023.` | 3 位以上作者、缺卷期页码 | `张三, 李四, 王五, 等. …[J]. 汽车工程, 2023, 45(3): 12-18.` |

> 采用**顺序编码制**时正文标注 `[1]`、`[2-4]`；采用**著者-出版年制**时正文标注 `(张三, 2023)`，文末按著者字顺排列。

### 2.2 APA（第 7 版，社科 / 教育 / 心理）

- 期刊：`Author, A. A., & Author, B. B. (Year). Title of article. Journal Name, volume(issue), page–page. https://doi.org/xxxx`
- 正文引用：`(Author, Year)` 或 `Author (Year)`；3 位及以上作者正文用 `et al.`
- 参考文献表按第一作者姓氏**字母顺序**排列，悬挂缩进；期刊名与卷号斜体
- 常见错：漏 DOI、卷期括号错位、题名大小写不符合 APA 句式大写规则

### 2.3 IEEE（工程 / 计算机）

- 采用顺序编码制，正文用上标 `[1]`，按出现顺序编号
- 期刊：`[1] A. A. Author, "Title of paper," Journal Name, vol. x, no. x, pp. xx–xx, Month Year.`
- 作者姓名：名缩写在前、姓在后；**6 位以上**作者用 `et al.`
- 常见错：期刊名未用规范缩写、页码用连字符而非 `–`、会议论文与期刊论文格式混用

> 三种格式**不可混用**。评审时先确认目标期刊/学校指定的格式，再统一检查；若用户未说明，默认按 GB/T 7714 检查并提示需确认。

## 三、查重、降重与 AI 使用的边界

### 3.1 阈值（以学校或期刊官方规定为准）

| 场景 | 常见阈值 | 说明 |
|------|----------|------|
| 本科毕业论文 | ≤ 30% | 部分学校要求 ≤ 20% |
| 硕士学位论文 | ≤ 15% | 个别学校 ≤ 10% |
| 博士学位论文 | ≤ 10% | 部分要求 ≤ 5% |
| 期刊投稿 | 按刊规 | 多数要求 ≤ 15–20%，且单源重复率有上限 |

> 具体阈值必须由用户向学校 / 编辑部确认，报告中标注 `[需核实]`，不得替用户断言。

### 3.2 合法降重（可以做）

1. **规范引用**：该标引的标引——很多"重复"是因为该引用未标注，而不是抄。
2. **转述而非复制**：用自己的句式重述他人观点，并标注来源。
3. **拆分与重组**：长句拆分、改变论证顺序、合并同类表述。
4. **增补自有内容**：加入自己的分析、数据与判断，稀释重复比例。
5. **合理使用综述与公式**：公式、标准条款、法律条文等通用表述按规范处理。

### 3.3 禁止做法（不做，也不提供方法）

- 同义词机械替换、语序颠倒、插入无意义字符等"技术降重"
- 翻译软件回译、AI 批量改写以规避检测
- **任何"规避查重系统""规避 AI 生成检测"的具体方法或工具推荐**

遇到此类请求，标准回应：可以帮你做**合法改写与引用规范化**来降低不当重复率；规避检测类做法不在能力范围内，且存在学术不端风险。

## 四、投稿就绪度与选刊匹配

### 4.1 就绪度检查表（对应 C8）

| 检查项 | 达标标准 | 常见缺失 |
|--------|----------|----------|
| 模板与字数 | 完全对齐目标刊物/学校模板；字数在上限内 | 字数超出 10–30% |
| 摘要 | 含目的/方法/结果/结论四要素，字数达标 | 只写背景，没有结果数据 |
| 关键词 | 3–6 个，可被检索，避免过泛 | 用了 8 个以上或全是通用词 |
| 作者信息 | 单位、通讯作者、邮箱、ORCID 完整 | 通讯作者未标注 |
| 图表 | 分辨率 ≥ 300 dpi，可编辑源文件，题注自明 | 截图充当数据图 |
| 声明文件 | 利益冲突、数据可获得性、作者贡献 | 全部缺失 |
| 投稿信 | Cover Letter 说明创新点与适配性 | 用模板群发痕迹明显 |
| 查重 | 在阈值内 | 未检测或超标 |

### 4.2 选刊匹配四步

1. **主题—范围匹配**：用题目 + 摘要 + 关键词，核对刊物近两年是否发过同主题文章。
2. **栏目匹配**：确认投的是研究论文、综述还是短通讯，避免栏目错投。
3. **周期与命中率**：结合审稿周期与自身时间要求（毕业、结题），区分**冲刺刊 / 稳妥刊 / 保底刊**三档。
4. **门槛核对**：格式要求、图表要求、伦理声明、基金标注要求。

**输出格式**：三档候选各 1–3 本，每本标注"匹配理由 + 需确认项"。**不得编造期刊名称、分区或影响因子**，不确定处一律标注 `[需核实]`。

### 4.3 投稿信（Cover Letter）结构

1. 一句话说明稿件标题、类型与投稿栏目
2. 研究问题与主要发现（2–3 句，含关键数据）
3. 创新点与对该刊读者的价值（2–3 条）
4. 声明：原创未发表、无一稿多投、全体作者同意
5. 推荐 / 回避审稿人（如刊物要求）与联系方式

### 4.4 审稿回复（Response to Reviewers）结构

逐条对应，每条采用**"感谢—澄清—修改位置"**三段式：

> **Reviewer 1, Comment 3**：样本量偏小，结论可能不稳定。
> **Response**：感谢指出。我们在 3.2 节补充了样本量依据（功效分析，α=0.05，power=0.8），并在 4.4 节新增稳健性检验（去除极端值后结论一致）。修改见修订稿第 8 页第 2 段，标记为蓝色。
> **Changes**：Methods 3.2（新增功效分析）；Results 4.4（新增 Table 5）。

**原则**：不回避、不辩解、不空口承诺；不同意审稿意见时给出证据并礼貌说明，同时提供替代修改方案。
