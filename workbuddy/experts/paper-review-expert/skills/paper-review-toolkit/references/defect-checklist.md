# 缺陷检查清单与 PRI 优先级算法

## 一、为什么要排序

一篇待投稿的论文，问题和问题不一样：**同一个"样本量不足"，写在摘要里和写在附录里，代价完全不同**。评审人的注意力是有限的——他们会先看摘要、再看方法与结论，第一眼看到的问题权重最大。

所以本清单不只列问题，还要给每条问题算一个**修改优先级**，让你先改"改了最值"的那几条，而不是面对一张 66 项的长清单无从下手。

---

## 二、PRI 算法：S × O × E

沿用 FMEA 的 **S × O × D** 三段式结构，但第三项做了**面向本场景的改造**——这是有意为之，请注意语义差异：

| 因子 | 名称 | 1 分 | 3 分 | 5 分 | 判定要点 |
|------|------|------|------|------|----------|
| **S** | 严重度 Severity | 只影响观感 | 明显削弱说服力 | 直接导致退稿/不通过 | 若被评审人抓住，后果有多重 |
| **O** | 普遍程度 Occurrence | 单处出现 | 出现在 2–3 处 | 贯穿全文，是系统性做法 | 不是"别人是否常犯"，而是**本文中蔓延的范围** |
| **E** | 暴露度 Exposure | 藏在细节里，评审人几乎不会注意到 | 认真读能发现 | 摘要/图表/结论里一眼可见 | **本场景中 E 越高越危险**——容易被看到，才会被扣分 |

> **与标准 FMEA 的差异（务必注意）**：标准 FMEA 中 D 表示"检出难度"，越高越坏（因为缺陷逃逸到下游）。本场景的"下游"是评审人本人，逻辑反过来：**越容易被发现的问题越会导致退稿**。因此第三项定义为**暴露度 E**，取值越高代表越显眼、越危险。若需按标准 FMEA 口径汇报，请显式说明这一映射。

**PRI = S × O × E**，取值 1–125。

### 分级与处置

| PRI | 分级 | 含义 | 处置建议 |
|-----|------|------|----------|
| ≥ 45 | **P0 必改** | 不改就可能直接被退/被毙 | 本轮必须完成，改完再投稿 |
| 25–44 | **P1 应改** | 评审人会写进意见并要求回应 | 与 P0 同批处理 |
| 10–24 | **P2 可优化** | 影响印象，不影响结论成立 | 有余力时改 |
| ≤ 9 | **P3 锦上添花** | 细节打磨 | 定稿前顺手处理 |

### 隐性雷区（单独列出）

**S ≥ 4 且 E ≤ 2** 的缺陷要单独标红：评审人当场未必发现，但**一旦深究或被答辩追问就会暴露**，是"看起来能过、结果被毙"的典型原因。这类问题即使 PRI 不高，也建议在投稿前处理——因为返修成本远高于预防成本。

### 一票否决与 PRI 的关系

红线类问题（见 `redlines-and-format.md`）**不参与 PRI 排名**，优先级永远高于任何 P0：命中即"不予通过"，先解决红线再谈其他。

## 三、8 大类 66 项检查清单

### C1 选题与创新性（6 项 → D1）

| ID | 检查点 |
|----|--------|
| C1-1 | 研究问题能否一句话说清，是否指向真实存在的空白 |
| C1-2 | 创新点属于哪一类（方法/应用/发现），是否在摘要与引言中明示 |
| C1-3 | 与已有工作的差异是否有文献对比支撑，而非自述"首次" |
| C1-4 | 标题与内容是否一致，有无夸大（标题党） |
| C1-5 | 研究边界与适用条件是否交代（结论能推广到哪里） |
| C1-6 | 是否回答了"为什么现在做这个"（时效与必要性） |

### C2 结构与逻辑（8 项 → D2）

| ID | 检查点 |
|----|--------|
| C2-1 | 章节骨架是否完整（引言/方法/结果/讨论/结论，或学位论文标准章节） |
| C2-2 | 各章篇幅比例是否失衡（绪论过长、讨论过短） |
| C2-3 | 每章开头是否有承接、结尾是否有小结 |
| C2-4 | 是否存在顺序倒置（如结论先于方法） |
| C2-5 | 结果与讨论是否混写导致论证断裂 |
| C2-6 | 图表是否与正文一一对应，且正文有解读（不能只贴图） |
| C2-7 | 逻辑链能否被读者复述（问题→方法→结果→结论） |
| C2-8 | 是否存在与主线无关的孤立章节 |

### C3 文献与引用规范（10 项 → D3）

| ID | 检查点 |
|----|--------|
| C3-1 | 近 5 年文献占比是否合理（一般不低于 1/3） |
| C3-2 | 关键文献是否遗漏（领域奠基工作、直接竞争工作） |
| C3-3 | 是批判性归类还是逐篇罗列 |
| C3-4 | 正文引用与文末列表是否一一对应（无漏引、无幽灵条目） |
| C3-5 | 格式是否统一合规（GB/T 7714 / APA / IEEE：作者、年份、卷期页码、文献类型标识） |
| C3-6 | 中英文文献著录是否都规范（英文题名大小写、期刊名缩写） |
| C3-7 | 标准、专利、网络资源的著录是否完整 |
| C3-8 | 引用是否真正支撑上下文观点（无错引、无误用） |
| C3-9 | 自引比例是否过高（一般不超过 15–20%） |
| C3-10 | 图表与数据来源是否标注引用 |

### C4 研究方法与数据统计（12 项 → D4）★ 重点区

| ID | 检查点 |
|----|--------|
| C4-1 | 方法是否与研究问题匹配（能定量就别硬凑定性） |
| C4-2 | 样本量是否说明依据（功效分析或经验规则），是否严重不足 |
| C4-3 | 抽样方式是否存在偏差（便利抽样未声明） |
| C4-4 | 变量定义与测量方式是否可操作、可复现 |
| C4-5 | 实验条件、设备、参数是否完整到他人可复现 |
| C4-6 | 统计方法选用是否正确（配对 vs 独立、正态性前提是否检验） |
| C4-7 | 统计报告是否完整（统计量、自由度、p 值、效应量、置信区间） |
| C4-8 | 多重比较是否做了校正 |
| C4-9 | 缺失值、异常值、剔除标准是否说明 |
| C4-10 | 数据可获得性是否声明（数据仓库或附录） |
| C4-11 | 稳健性 / 敏感性分析是否开展（换参数换模型结论是否稳定） |
| C4-12 | 是否存在循环论证或"未来函数"式错误（用结果反推设计条件） |

### C5 论证与证据充分性（9 项 → D5）

| ID | 检查点 |
|----|--------|
| C5-1 | 每个论点是否都有数据或文献支撑 |
| C5-2 | 结论是否强于证据（小样本推大结论） |
| C5-3 | 相关性是否被表述为因果 |
| C5-4 | 是否讨论了反例与不一致结果 |
| C5-5 | 局限是否具体（而非"研究不足，未来改进"套话） |
| C5-6 | 是否出现正文未验证的新主张 |
| C5-7 | 与他人结果不一致时是否给出解释 |
| C5-8 | 是否回应了替代解释（竞争性假设） |
| C5-9 | 图表是被用来支撑论证，还是仅作装饰 |

### C6 学术表达（7 项 → D6）

| ID | 检查点 |
|----|--------|
| C6-1 | 术语是否全文一致（同义混用显不专业） |
| C6-2 | 中英混排与标点是否规范（中英文间空格、全角半角） |
| C6-3 | 是否存在口语化 / 主观化表述（"我们认为""非常好"） |
| C6-4 | 长句嵌套是否影响理解 |
| C6-5 | 摘要与结论是否用词重复堆砌 |
| C6-6 | 图表题注是否自明（脱离正文也能看懂） |
| C6-7 | 缩写首次出现是否给出全称 |

### C7 学术规范与诚信（6 项 → 红线类，不参与 PRI 排名）

| ID | 检查点 |
|----|--------|
| C7-1 | 数据是否真实可溯源（含原始记录） |
| C7-2 | 图像是否重复使用 / 拼接 / 过度美化 |
| C7-3 | 引文是否存在抄袭式改写（洗稿） |
| C7-4 | 伦理审批与知情同意（涉及人体 / 动物 / 隐私数据） |
| C7-5 | 署名与贡献、利益冲突、基金标注是否规范 |
| C7-6 | 是否一稿多投 / 重复发表（自我重复未声明） |

### C8 投稿就绪度与答辩（8 项 → D7）

| ID | 检查点 |
|----|--------|
| C8-1 | 是否对齐目标期刊 / 学校的模板与字数上限 |
| C8-2 | 摘要结构是否符合要求（目的/方法/结果/结论及字数） |
| C8-3 | 关键词数量与质量（3–6 个，可被检索） |
| C8-4 | 作者信息、单位、通讯作者标注是否完整 |
| C8-5 | 图表分辨率与格式是否达标（如 300 dpi、可编辑源文件） |
| C8-6 | 推荐 / 回避审稿人与 Cover Letter 是否准备 |
| C8-7 | 查重率是否在阈值内（以学校或期刊官方规定为准） |
| C8-8 | 答辩材料是否齐备（主线 PPT、可能追问清单、原始数据备查） |

## 四、高频缺陷 PRI 参考表

评审时优先在这张表里比对，命中就直接取用对应 S/O/E，避免逐条临时估值造成标准漂移。

| 缺陷 | 典型位置 | S | O | E | PRI | 分级 |
|------|----------|---|---|---|-----|------|
| 摘要未给出结论或结果数据 | 摘要 | 4 | 5 | 5 | 100 | P0 |
| 结论强于证据（小样本推大结论） | 结论 / 讨论 | 5 | 2 | 4 | 40 | P1 |
| 统计只报 p 值，无样本量与效应量 | 结果 / 表格 | 4 | 4 | 4 | 64 | P0 |
| 样本量严重不足且未说明依据 | 方法 | 5 | 2 | 3 | 30 | P1 |
| 创新点未说清，通篇讲背景 | 引言 | 5 | 3 | 4 | 60 | P0 |
| 参考文献格式前后不统一 | 参考文献表 | 3 | 4 | 3 | 36 | P1 |
| 正文引用与文末列表对不上 | 全文 / 文末 | 4 | 3 | 2 | 24 | P2 |
| 图表无题注或题注不自明 | 全文图表 | 3 | 4 | 3 | 36 | P1 |
| 结果与讨论混写 | 结果章 | 4 | 3 | 3 | 36 | P1 |
| 局限只写"研究不足，未来改进" | 讨论 / 结论 | 3 | 3 | 4 | 36 | P1 |
| 相关性表述为因果 | 结果 / 讨论 | 5 | 2 | 3 | 30 | P1 |
| 未做稳健性 / 敏感性分析 | 方法 / 结果 | 4 | 2 | 2 | 16 | P2（隐性雷区） |
| 术语中英混用不一致 | 全文 | 2 | 5 | 3 | 30 | P1 |
| 存在口语化主观表述 | 全文 | 2 | 4 | 4 | 32 | P1 |
| 关键词不规范（过多/过泛） | 稿件头部 | 3 | 4 | 4 | 48 | P0 |
| 字数超出目标期刊上限 | 全文 | 3 | 2 | 4 | 24 | P2 |
| 未声明数据可获得性 | 方法 / 附录 | 3 | 2 | 2 | 12 | P2（隐形雷区） |
| 图表分辨率不达标 | 图表文件 | 3 | 3 | 3 | 27 | P1 |
| 一稿多投 / 重复发表未声明 | 全流程 | — | — | — | **红线** | 一票否决 |
| 图像重复使用或过度美化 | 图表 | — | — | — | **红线** | 一票否决 |

> 表中未覆盖的缺陷按 S/O/E 定义自行评定，并在报告中写明评定理由，保证可复核。

## 五、合并与行动计划

1. **同一根因合并**：如"摘要无结论 + 结论冗长"往往同一个根因（不会凝练结论），合并为 1 条，标注影响 2 个维度。
2. **改一处带动多项**：优先选"改一改能同时降 3 条以上 PRI"的动作（如统一术语、重排图表题注）。
3. **输出三阶段计划**：
   - 阶段一（红线 + P0）：目标消除退稿级风险，完成后再评一次
   - 阶段二（P1）：目标把整体等级提升一档
   - 阶段三（P2/P3 + 就绪度）：定稿与投稿材料
4. 每条计划写清：**改什么 / 改到什么程度算完成 / 预计耗时 / 需要什么材料**。
