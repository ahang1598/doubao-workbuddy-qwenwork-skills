# 市场顶部/底部综合判断框架

> **本文件定位**：系统化判断市场系统性位置（顶部/底部/中段），直接影响主理人推导战略配置中枢与宏观研究员推导战术偏离。在执行 ETF 分析前，先用本框架判断当前市场处于何种系统性位置。
>
> **R9 合规声明**：本文件的信号阈值（如 PE 分位、ERP 分位、破净率等）是**客观市场事实判据**（可测量的市场状态），保留。但"几个信号触发=加仓多少"的操作映射**不由本文件规定**，由宏观研究员结合周期置信度、用户画像当场推导。

## 一、市场底部六大信号体系

六大信号**同时触发** = 历史级大底部区域。**触发数量越多**，底部信号越强。

| 信号维度 | 客观判据 | 数据获取方式 |
|---------|---------|-------------|
| **① 估值信号** | 沪深300 PE 处于历史10年 10%分位以下；ERP（隐含股权风险溢价）处于历史 90%分位以上 | 中证指数公司 / 理杏仁 |
| **② 情绪信号** | 全市场日均成交额萎缩至历史 20%分位以下；破净率超 15%；新基金募集失败频现 | 东方财富 / 交易所 |
| **③ 技术信号** | 全市场 80%以上个股处于 200日均线以下；指数不再创新低（底部钝化） | 东方财富行情 |
| **④ 基本面信号** | PMI 连续3个月低于荣枯线；PPI 连续负增长；库存周期处于主动去库末期 | 国家统计局 |
| **⑤ 政策信号** | 降准降息连续出台；国务院/证监会级别稳增长政策落地；资本市场改革（如新国九条级别） | 人民银行 / 证监会 |
| **⑥ 资金信号** | 北向资金结束持续流出转为连续净流入；产业资本净增持；长线资金入市信号明确 | 东方财富 / 交易所 |

### ERP（隐含股权风险溢价）测量刻度

> ERP = 1/沪深300 PE(TTM) − 10年期国债收益率。该指标是 A 股最常用的股债性价比/估值水位度量工具。

| ERP 历史分位 | 市场位置（客观描述） |
|------------|------------------|
| ≥90%分位 | 极端低估区（历史经验：2018年10月、2022年10月、2024年10月曾触及） |
| 70%-90%分位 | 偏低估区域 |
| 30%-70%分位 | 合理区间 |
| 10%-30%分位 | 偏高估区域 |
| ≤10%分位 | 极端高估区 |

> **注意**：本表只描述估值水位的客观位置，不直接映射操作。"极度低估区该配多少权益"由宏观研究员结合周期置信度、用户回撤容忍、组合波动率当场推导。

## 三、政策力度打分模型（测量刻度，非决策阈值）

> 政策是 A 股的核心变量之一。本模型用于**量化描述**政策力度，供宏观研究员推导战术偏离时参考。打分维度本身是客观测量刻度，保留；但"多少分对应什么操作"由宏观研究员推导。

四大维度，每维度 0-25 分，总分 100 分：

| 维度 | 细项与评分标准 |
|------|-------------|
| **货币政策（25分）** | 降准（5分/次）、降息/LPR下调（5分/次）、创设新型工具（3分）、公开市场大幅净投放（2分）、政策措辞明确转鸽（5分） |
| **财政政策（25分）** | 新增专项债超预期（5分）、大规模减税降费（5分）、消费补贴/以旧换新（3分）、地产政策放松（5分）、基建投资加码（3分） |
| **产业政策（25分）** | 国家级产业规划出台（5分）、重大补贴/税收优惠（5分）、技术突破国家支持（3分）、限制外资/保护国产替代（3分）、产业基金设立（5分） |
| **资本市场政策（25分）** | 新国九条级别改革（10分）、减持新规收紧（5分）、IPO收紧/暂停（3分）、鼓励分红回购（3分）、长线资金入市政策（5分） |

### 政策见效预期窗口（政策传导时滞）

> 政策力度打分完成后，对高分场景需进一步判断**政策何时见效**，避免"政策已发布≠基本面已改善"的误判。

| 政策类型 | 传导时滞 | 见效标志 |
|---------|---------|---------|
| **货币政策**（降准/降息/创设工具） | 6-9个月 | 社融增速拐头向上 + 新增信贷连续3月多增 |
| **财政政策**（专项债/减税/补贴） | 3-6个月 | 基建投资增速回升 或 社零增速回升 |
| **产业政策**（产业规划/补贴/标准） | 9-12个月 | 龙头企业订单增速提升 或 在建工程增速显著 |

**铁律**：无论政策力度多强，在见效标志未出现前，宏观研究员不得将"政策已发布"作为基本面改善的依据，仅可作情绪催化。

## 四、与团队 SOP 的集成

### 主理人（Phase 0 推导战略配置中枢时）
- 调用本框架判断市场系统性位置 → 作为推导权益/防御/跨境商品中枢比例的输入之一
- 极端底部区域：可在用户风格允许范围内倾向权益上限；极端顶部区域：倾向防御上限
- **中枢具体数值仍由主理人结合用户画像推导，本框架只提供市场位置的客观判据**

### 宏观行业研究员（Phase 1 战术偏离建议时）
- 调用本框架的底部/顶部信号触发情况 → 作为推导战术偏离方向的输入
- 调用 ERP 分位 → 估值水位客观参照
- 调用政策力度打分 → 政策面量化输入
- **偏离幅度由研究员结合周期置信度、资产性价比、政策力度当场推导，不查固定映射表**

### 行情技术分析师（Phase 1 逐只择时时）
- 市场系统性位置 → 影响整体择时倾向的基调（但不替代逐只技术面判断）
- 极端底部区域：技术面买入信号的置信度可适当上调；极端顶部区域：技术面卖出信号的置信度可适当上调
