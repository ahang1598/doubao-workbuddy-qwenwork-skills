# 能源公用大类·共性分析框架与通用信源

> 本文件是 `能源公用/` 大类（煤炭/公用事业）的**共性方法论与跨行业数据源**。具体某个行业的产业链细节请见对应 `.md` 文件。

---

## 一、能源公用的共性商业本质

**资源禀赋 + 政府定价/准入 + 高分红 + 稳现金流**——能源公用本质是"要么资源稀缺且政府定价，要么受准入牌照保护"，因此对经济周期相对不敏感，更像债券替代品：

| 维度 | 煤炭 | 公用事业（电/水/气/环保） |
|---|---|---|
| 定价机制 | 长协（政府指导价 70%）+ 市场煤（30%）| 电价受"煤电联动"管控；水/气受地方政府指导价 |
| 核心驱动 | 煤炭价格 + 动力煤库存 + 进口 | 用电量增速 + 煤价（火电成本）+ 水电来水 |
| 周期属性 | 强周期（3-5 年价格周期） | 弱周期（现金流稳定，股息率锚定） |
| 股息率 | 3-10%（龙头） | 2-6% |
| 估值锚 | PB × ROE（资源型）；股息率替代 10Y 国债 | 股息率 vs 10Y 国债 + DCF |

---

## 二、五大共性关键指标（能源公用通用）

1. **10Y 国债收益率** —— 红利股估值的核心锚（收益率下行 → 高股息股吸引力上升）
2. **动力煤现货价 + 长协价** —— 煤炭业绩 + 火电成本
3. **全国用电量同比（社会用电量）** —— 电力需求总量
4. **水电来水（三峡/澜沧江）** —— 水电利用率
5. **居民/工商业电价调整节奏** —— 电价政策是否顺价

## 四、红利股估值锚速查

能源公用大类 汇总决策最重要的估值逻辑：

```
隐含收益率 ≈ 股息率 − (10Y 国债收益率)
当隐含超额 > 2pct → 估值便宜
当隐含超额 < 0pct → 估值偏贵
```

**典型锚值（仅供定位，实际以最新数据为准）**：
- 煤炭龙头股息率 6-10%，10Y 国债 2.3% → 隐含超额 3.7-7.7pct（较高吸引力）
- 水电龙头股息率 3-4%，10Y 国债 2.3% → 隐含超额 0.7-1.7pct（中性）
- 核电/新能源运营商 股息率 2-3% → 更看装机增速 + 上网电价

## 五、五维复盘模板（能源公用 汇总决策必跑）

1. ✅ 10Y 国债收益率 **近 3 月走势**：下行 → 红利股配置价值提升
2. ✅ 动力煤价格 **近 3 月均值**（对煤炭是量价端、对火电是成本端，影响相反）
3. ✅ 全社会用电量同比 **> 5% 为景气**
4. ✅ 主要水库来水 **偏丰/偏枯**
5. ✅ 电价政策 **近 6 月有无调整**（尖峰电价/居民阶梯/工商分时）

---

## 六、常见传导链（供 §4.1.1 宏观层引用）

- **10Y 国债收益率下行 → 红利股（煤炭/水电/公路/港口）配置吸引力上升 → 估值扩张**
- **动力煤价格上行 → 煤炭股 EPS 弹性放大 + 火电股成本挤压 + 煤电联动滞后反应 3-6 月**
- **主要水库来水偏枯 → 水电出力下降 + 火电替代需求上升 → 煤炭 + 火电双受益**
- **用电量同比 > 8% 夏季/冬季高峰 → 尖峰电价触发 + 火电业绩预告上修**
- **碳市场 CEA 价格持续上行 → 高能耗行业成本增加 + 清洁能源运营商 CCER 收入预期提升**
