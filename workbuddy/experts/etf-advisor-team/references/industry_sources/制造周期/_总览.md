# 制造周期大类·共性分析框架与通用信源

> 本文件是 `制造周期/` 大类（电新/汽车/机械/化工/建材新材料/建筑工程/军工/有色金属）的**共性方法论与跨行业数据源**。具体某个行业的产业链细节请见对应 `.md` 文件。

---

## 一、制造周期的共性商业本质

**量价利润弹性 + 库存周期 + 产能周期 + 全球定价**——制造周期八个子行业共享：

| 维度 | 共性特征 |
|---|---|
| 核心驱动 | **量**（需求总量 + 出货节奏）×**价**（大宗价格/终端提价）×**成本**（上游原料/能源） |
| 周期属性 | **2-3 年库存周期**（去库→被动补库→主动补库→被动去库）+ **5-10 年产能周期** |
| 定价方式 | 大宗（煤/铜/铝/钢/化工品）全球定价，受海外需求+汇率影响 |
| 弹性来源 | 杠杆高、毛利率窄、景气上行期利润弹性远大于营收弹性 |
| 判别技巧 | PB 估值比 PE 更稳定；PE-Bands 在周期股里**反向**——低 PE 往往是景气顶、高 PE 往往是景气底 |

---

## 二、五大共性关键指标（制造周期通用）

1. **PMI（制造业 + 分项新订单/生产/库存/采购价格）** —— 最先行的周期指标
2. **PPI 分行业（工业生产者价格）** —— 提价能力的直接观察
3. **社融 + M1 + 房地产开发投资** —— 资本开支周期起点信号
4. **关键大宗商品价格**（铜/铝/钢/煤/化工品/锂电材料/稀土）—— 量价传导的价端
5. **库存周期位置** —— 工业企业产成品库存同比变化决定周期阶段（四个阶段各有对应的行业配置逻辑）

## 四、库存周期四阶段定位法（制造周期必跑）

> 周期股择时的"通用底层逻辑"，几乎适用于所有制造周期子行业。

| 阶段 | 名称 | 判别（PPI + 库存同比）| 典型配置 |
|---|---|---|---|
| ① | 主动去库 | PPI 下行 + 库存同比下行 | 防御；回避周期股 |
| ② | 被动去库 | PPI 拐头向上 + 库存仍在下行 | **最佳买点**——估值+盈利双击起点 |
| ③ | 主动补库 | PPI 上行 + 库存同比转正 | 持有；享受利润弹性 |
| ④ | 被动补库 | PPI 见顶回落 + 库存仍在补 | **最佳卖点**——盈利预警 |

---

## 五、五维复盘模板（制造周期 汇总决策必跑）

1. ✅ 制造业 PMI **在荣枯线上/下**，新订单分项 **在/不在 50 上方**
2. ✅ PPI 同比 **拐头向上/向下 ≥ 3 个月**
3. ✅ 工业库存同比 **在 ① 主动去库 / ② 被动去库 / ③ 主动补库 / ④ 被动补库** 哪个阶段
4. ✅ 对应品种的**大宗商品价格**近 3 月累计涨跌幅 ±15%
5. ✅ 出口同比 **为正/为负**（海外需求是否支撑）

## 六、常见传导链（供 §4.1.1 宏观层引用）

- **PMI 新订单 > 生产分项 + PPI 拐头向上 → 被动去库阶段确认 → 对应品种的制造周期股为最佳买点**
- **大宗商品价格暴涨 → 中游利润挤压 + 上游资源股爆发**（2021 铜/铝/煤炭逻辑）
- **房地产投资下行 → 建材（水泥/玻璃/钢铁）需求失速 → 水泥熟料价格下跌 → 业绩预警**
- **欧美衰退 + 美元走强 → 出口敏感行业（机械/家电/轻工/汽车零部件）需求回落**
- **碳酸锂价格下行 → 锂电材料毛利率压缩 → 下游新能源车毛利率改善**（负二阶效应）
- **国防预算同比 + 主机厂订单公告 → 军工配套链 6-12 个月后业绩放量**
