# 跳跃视界（tiaoyue-screenplay-team）

WorkBuddy Team 型专家团：短剧创作全链路入口，对话内产出选题/梗概/粗纲/集纲/首集剧本/分镜/人物场景素材图/视频试片，整集成片与资产引导至跳跃视界完成。

## 结构

- `短剧专家团设计文档.md` — 总纲（人设、SOP、文案、MCP 依赖、合规自检）
- `plugin.json` / `settings.json` — 专家包配置
- `.mcp.json` — 跳跃世界MCP（OAuth 授权，无需用户填 Token）
- `agents/` — 主理人 + 5 成员 Agent 定义
- `skills/screenplay-workflow/` — 短剧创作 SOP 技能 + 平台引导指南 + 分镜规范 + 出图出片规范
- `avatars/` — 7 张头像（512×512 PNG）

## 团队构成

| 角色 | 名称 | 职责 |
|---|---|---|
| 主理人 | 江澜 | 需求确认、分派调度、积分检查、交付汇总与引导 |
| 爆款选题分析师 | 陆拾 | 题材研判、钩子设计、人设公式 |
| 编剧 | 文茵 | 梗概、粗纲与集纲、首集剧本正文 |
| 分镜师 | 墨镜 | 按 10~15 秒节拍切 S 段、人物形象锚定、提示词 |
| 概念美术 | 袁画 | 人物定妆图、场景概念图、道具图、首帧图 |
| AI 影像生成师 | 易帧 | 按 S 段生成视频试片、异步任务轮询 |

## 使用方式

在 WorkBuddy 中：专家 → 我的专家 → 创建专家，调用官方 `expert-manager` 技能，以本文档为输入材料生成专家团；补齐头像与 author 信息后提交审核。

出图出片能力依赖专家自带的 `tiaoyue` MCP（OAuth 一键授权）。它由 `plugin.json` 的 `dependencies.mcpServers: "./.mcp.json"` 声明，召唤专家时 WorkBuddy 弹出内联引导卡片让用户连接，连接后收进「连接器 → 自定义连接器」管理，**无需先把它上架成平台连接器**。**未连接时不影响使用**——所有阶段仍会输出提示词原文，并引导到平台完成。

## 阶段规划

- v1.0：纯提示词专家团，零 MCP 依赖，可独立上架。
- v2.0（当前）：接入跳跃世界 MCP，新增概念美术与影像生成师，对话内出素材图与视频试片，打通「剧本 → 分镜 → 素材图 → 视频」闭环。
