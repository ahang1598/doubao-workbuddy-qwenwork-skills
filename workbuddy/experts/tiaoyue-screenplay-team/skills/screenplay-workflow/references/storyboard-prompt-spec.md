# 分镜提示词规范（主流 AI 视频模型通用格式）

分镜师墨镜的唯一输出格式。目标是让每段提示词能**直接投喂主流 AI 视频模型**出片，不需要用户二次改写。

> **对外话术红线**：本规范的格式依据来自当前主流视频模型的输入习惯，但**具体模型名（Seedance、可灵、即梦、Sora 等）只作内部参考，禁止出现在任何用户可见的产出里**——包括阶段通报、子任务名、标题、正文与交付汇总。对外统一写「AI 视频模型」或「主流视频生成模型」。

## 一、总体结构

一集分镜由三部分组成，顺序固定：

1. **人物形象锚定表** — 定义每个角色的形象标签与外形，全集复用
2. **镜头规划总览表** — 整集所有 S 段的一句话概览，让用户先看全貌
3. **【全局设定】+ S 段提示词** — 全局设定块只在开头出现一次，之后逐段输出 S 段

## 二、S 段与 c 子镜头（核心）

**S 段 = 一个戏剧节拍**，不是一个镜头。一个 S 段 **10~15 秒**，内部再切 2~4 个 c 子镜头。

```
## S01 / 约12.0s
图中空间：<地点 + 景别>。<光线、天气、持续可见的环境元素与关键道具，含与人物的比例关系>
人物站位锚定：<角色-形象标签> 位于画面某侧，朝向 / 遮挡 / 同层关系逐个写清
c01,4s,(姿态:<角色-形象标签>-<动作>) <景别>，<前景遮挡>，<运镜>。<画面描述>。<角色>：（情绪）"<台词>"
c02,5s,(姿态:...) ...
c03,3s,(姿态:...) ...
声音指令：< 环境音・<类别> >：<细节化描述>。< 环境音・<类别> >：...
```

### 时长硬约束

| 项 | 约束 |
|---|---|
| S 段总时长 | **10~15 秒**，写在标题里：`## S01 / 约12.0s` |
| c 子镜头数量 | 每段 **2~4 个** |
| 单个 c 时长 | **2~8 秒** |
| 加总 | **各 c 时长之和必须等于 S 段标注时长**，不许对不上 |
| 单集段数 | 单集 1~3 分钟 ≈ **6~12 个 S 段** |

### 字数硬约束

单个 S 段正文（含图中空间、站位锚定、各 c、声音指令）**不少于 250 字**。信息量不足的提示词出不了稳定画面，禁止一句话带过。

### 每个 c 必须写齐的要素

1. **姿态**：`(姿态:角色-形象标签-具体动作)`，多角色用 `；` 分隔
2. **景别**：特写 / 中近景 / 中景 / 双人景 / 全景 / 远景
3. **前景与遮挡**：如「左侧巨树横枝作前景遮挡」「带石塔边缘前景」
4. **运镜**：固定轻呼吸 / 手持轻微推进 / 平行跟拍 / 前景横移 / 纵向极缓下降 / 高空俯拍下降
5. **画面描述**：动作、表情、服装状态、光影、道具细节
6. **台词**（若有）：直接写在该 c 末尾，标明画内或画外，格式 `角色：（情绪）"台词"`；画外写成 `角色台词画外声（压低声音）："台词"`

## 三、全局设定块

每集开头出现一次，风格字段按题材填，其余负面约束原样保留：

```
【全局设定】画面风格和类型: <真人古风 / 影视质感 / 现代都市写实 / 玄幻仙侠实拍质感>，全程人物边界独立，自然表演，人物无穿插、无穿透；全程禁止出现字幕、禁止角色变脸、变装、形象突变；杜绝肢体畸形、扭曲、残缺等人体结构错误；禁止画面闪烁、跳变、卡顿、帧异常；全程无背景音乐、无 BGM、只保留对白与现场环境声
```

**群演场景追加**（多人、军队、街市、宴会）：

> 每个路人的脸和造型都不一样，<A 阵营>和<B 阵营>是两个阵营，他们的衣服要有明显区分，同阵营的要服装统一，但是人物的高矮胖瘦也不一样。

## 四、人物形象锚定（跨段一致性关键）

角色首次出场必须定义**形象标签**，后续所有 S 段**原样复用同一标签**，模型才能保持人物一致：

| 角色 | 形象标签 | 外形与服装 |
|---|---|---|
| 陈观 | `陈观-抬棺材` | 斗笠蓑衣，斩马刀未出鞘随身，单肩扛朱红木棺 |
| 苏敬言 | `苏敬言-基础形象` | 青衫书生，面色苍白强撑站立 |
| Rion | `Rion-城破战损` | 甲胄多处破裂、肩甲砍痕外翻、满身血泥 |

规则：

- 同一角色在不同状态下用不同标签（`基础形象` / `城破战损` / `抬棺材`），但同一状态内标签固定不变
- 关键道具同样给固定名（`朱红木棺`、`斩马刀`），并写明与人物的比例（如「与人物比例为 2:1，是人物的两倍大小」）
- 续写后续 S 段时沿用同一张锚定表，不重新命名

## 五、声音指令

- 按 `< 环境音・类别 >` 分组书写，常用类别：风与山 / 燃烧 / 战场背景 / 呼吸与脚步声 / 马的声音 / 雨声 / 室内环境
- 描述要细节化：声音的质感、方向、强弱变化、随镜头推移的远近关系
- **禁止 BGM 与配乐**，只写现场环境声与对白；与全局设定里的「无背景音乐」保持一致

## 六、镜头规划总览表

整集所有 S 段先给一张表，覆盖到最后一段（不只列要输出提示词的那几段）：

| S | 时长 | 场景 | 内容 |
|---|---|---|---|
| S01 | 12s | 破庙门口 夜雨 | 陈观扛棺穿过雨幕，苏敬言与仆人在阴影里观察 |
| S02 | 10s | 破庙拐角 | 仆人劝说苏敬言雇陈观护送洛璃 |

## 七、分批输出规则

单段提示词体量大，**默认只输出前 3 个 S 段**（约 30~45 秒），末尾提示用户回「继续」再往下出。续写时：

- 沿用同一全局设定块与人物形象锚定表，**不重复输出全局设定**
- S 序号连续递增，不重排、不重复
- 保持同一风格字段与负面约束串

## 八、完整样例

### 样例一：10 秒段（真人古风，多人对话）

```
【全局设定】画面风格和类型: 真人古风，全程人物边界独立，自然表演，人物无穿插、无穿透；全程禁止出现字幕、禁止角色变脸、变装、形象突变；杜绝肢体畸形、扭曲、残缺等人体结构错误；禁止画面闪烁、跳变、卡顿、帧异常；全程无背景音乐、无 BGM、只保留对白与现场环境声

## S01 / 约10.0s
图中空间：破庙门口 破庙门口中远景。夜雨中的中央石板路通向正门台阶与黑暗庙门，左侧朱红木棺，与人物比例为 2:1，是人物的两倍大小，陈观抬棺材斩马刀未出鞘随身，背后是雨幕里的石板路；苏敬言-基础形象在图中空间左侧巨树与左侧石塔遮蔽旁强撑站立，面向中央石板路上的陈观抬棺材，身后压着阴影；仆人-基础形象贴在苏敬言-基础形象身侧，半身护住他，同向看陈观抬棺材，背后是左侧遮蔽。

c01,2s,(姿态:陈观抬棺材-站立行走并单肩扛朱红木棺)全景，左侧巨树横枝作前景遮挡，斜向看中央石板路与正门台阶，前景横移从湿树干滑到陈观抬棺材行进线。侧面面部特写镜头，镜头跟随陈观冷静地踏过积水，斗笠雨水沿边缘滴落，肩上的朱红木棺在雨幕里沉暗压稳。

c02,3s,(姿态:苏敬言-基础形象-站立强撑；仆人-基础形象-站立护在苏敬言-基础形象身侧) 双人景，位于破庙拐角，苏敬言-基础形象画左、仆人-基础形象画右并列同层，侧向看两人藏在破庙拐角石塔阴影边；固定轻呼吸。仆人-基础形象谨慎地压低肩线靠近苏敬言-基础形象，眼神追着画外陈观抬棺材，仆人-基础形象低声说："镖人陈观，出了名的有钱能使鬼推磨，贪财却又守规矩，"

c03,3s,(姿态:朱红木棺-被肩扛并随陈观抬棺材前行) 特写，朱红木棺长边压在陈观抬棺材肩头，雨水沿符文纹路流下，手持轻微推进由棺角靠近暗红棺面。仆人-基础形象台词画外声（压低声音）："哪怕护送的是……邪祟，都从未失手，不如让他来护送洛璃小姐……"

c04,2s,(姿态:陈观抬棺材-站立行走并背向台阶前行) 中景，带左侧石塔边缘前景看陈观抬棺材后背，平行跟拍沿中央石板路向正门台阶移动。陈观抬棺材冷淡地继续往黑暗庙门走，朱红木棺保持横压在肩上，雨声盖住他的脚步。
```

### 样例二：15 秒段（影视质感，群演战场 + 声音指令）

```
【全局设定】画面风格和类型: 影视质感，全程人物边界独立，自然表演，人物无穿插、无穿透；全程禁止出现字幕、禁止角色变脸、变装、形象突变；杜绝肢体畸形、扭曲、残缺等人体结构错误；禁止画面闪烁、跳变、卡顿、帧异常；全程无背景音乐、无 BGM、只保留对白与现场环境声，每个路人的脸和造型都不一样，王国士兵和 Black Keep 士兵是两个阵营，他们的衣服要有明显区分，同阵营的要服装统一，但是人物的高矮胖瘦也不一样。

## S01 / 约 15.0s
图中空间：城破战场。夜晚火光与月影压在黑脊山、中央交战平地与城门缺口上，泥水、断旗、碎盾、燃烧木架和散落剑刃持续可见，王国士兵与 Black Keep 士兵在侧向混战。近城门泥地、城门洞口火光、断箭与血污低位区域持续可见，场景中央为交战平地，场景后方向北连向黑脊山方向。
人物站位锚定：战场中段遍布双方混战士兵；城门洞口墙根处，Rion-城破战损侧身护住骑马，身旁立着战马，身影被火光与烟尘半掩，随镜头推进逐渐清晰；一名 Black Keep 敌兵从混战侧向逼近战马方向。

c01,8s,城破战场 (姿态：高空俯拍 + 极缓下降，全景推进至中景) 纵向极缓下降，竖屏自上而下依次揭示黑脊山 — 中央交战平地 — 王国城门的对立布局；起始黑脊山占画面上三分之一，山脊冷硬如黑色剪影，山风卷灰烬形成断续灰带；下降过程中可见双方士兵在中央平地散线混战，Black Keep 士兵从山侧往城门方向冲锋，王国士兵迎击格挡，人影在泥地与火光间交错；掠过泥地交错的脚印蹄印、斜插的断旗、半埋的碎盾残片、跳动的燃烧木架与泥中带血的剑刃；城门洞口处隐约可见一男一女倚着战马的轮廓，被火光与烟尘半遮挡；终点定格在交战平地中景，前景是斜插的剑与断旗，背景城门处的男女主轮廓可辨。固定轻呼吸。
声音指令：< 环境音・风与山 >：山风从黑脊山方向灌下来，风声穿过岩石缝隙时发出尖锐的哨音，掠过平地和旗帜时变成低沉的呜咽，阵风时强时弱，吹动旗帜节奏不一致。< 环境音・燃烧 >：燃烧的木架发出噼啪的爆裂声，火星偶尔"咝"的一声从木头缝隙中窜出，不同部位燃烧速度不同，部分碳化冒烟，部分火苗跳动。< 环境音・战场背景 >：士兵喊杀声与刀剑相击的金属碰撞声随镜头下降由远及近，每次碰撞后短促金属颤音停留半秒再消散；混着马匹嘶鸣与马蹄踏泥的沉闷声响，声音时被风声掩盖，时清晰可闻，方向随冲锋动线从北向南推移。< 环境音・战场细节 >：碎盾残片风中晃动时金属边缘磕碰石块发出清脆轻响，灰烬与火星卷起时细小颗粒擦过地面发出沙沙声。

c02,3s,(姿态：固定机位 + 中景，战场混战群像) 双方士兵在泥地散乱近身肉搏，Black Keep 士兵挥剑劈下，王国士兵举盾格挡溅出火星，有人扭打倒地挣扎翻身，有人奔跑增援，脚下泥浆飞溅；士兵甲胄染血沾泥，甲片裂口露出染血内衬，搏杀节奏混乱无序，火光在人影上投下跳动光影。
声音指令：< 环境音・近处战斗 >：刀剑相击的金属碰撞声近在耳畔，每次撞击后带刺耳颤音；士兵嘶吼呐喊此起彼伏，甲胄铁片动作中碰撞出细碎金属声；人体倒在泥地发出沉闷噗声。< 环境音・呼吸与脚步声 >：近处士兵喘息粗重急促，混杂靴子踩进泥地的黏稠挤压声，靴子拔出时带吸力释放的噗噗声。

c03,4s,(姿态：固定机位 + 中近景，Rion-城破战损推骑马) Rion-城破战损甲胄多处破裂、肩甲砍痕外翻、满身血泥，单手托腰单手按背将骑马往战马上推，发力后肌肉微颤；骑马浑身颤抖泪流满面，双手推住 Rion-城破战损胸膛不舍挣扎，嘴唇翕动话语被嘈杂吞没；战马浑身汗湿，鬃毛贴颈，鼻孔张合喷白雾，不安地甩头刨地，胸腔剧烈起伏。
声音指令：< 环境音・女主的声音 >：骑马哭声断断续续，被战场嘈杂压低，反复念着"Rion"，声音沙哑带哽咽颤抖，常被抽泣打断。< 环境音・马的声音 >：战马不安喷鼻，每次喷气带短促爆破音与湿漉漉气息；马蹄刨地沉闷有节奏，蹄铁碰泥下石块偶尔擦出短促金属声；马头甩动时缰绳金属扣环碰撞发出细碎叮当声。< 环境音・战场背景 >：远处刀剑相击与士兵呼喊持续，音量不喧宾夺主。
```
