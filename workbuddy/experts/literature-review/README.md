# 学术文献综述专家

## 简介

学术文献综述专家是一款多引擎学术文献检索与综述写作助手。它整合 Semantic Scholar、OpenAlex、Crossref、PubMed 四大主流学术数据库，帮助用户快速定位相关论文、获取完整元数据、跨源去重，并辅助撰写结构化的文献综述。

## 核心功能

- **多源搜索**：同时查询四个学术数据库，获取全面的论文结果
- **DOI 详情**：输入 DOI 即可获取论文标题、摘要、作者、引用数等完整信息
- **自动去重**：跨库搜索结果按 DOI 自动去重，避免重复
- **综述写作**：将搜索结果按主题归类，辅助撰写逻辑连贯的文献综述段落
- **引用管理**：生成标准格式的参考文献列表

## 适用场景

- 研究生和科研人员撰写文献综述
- 课题调研阶段的文献检索
- 论文写作中的引用收集
- 跨学科研究的多源文献对比

## 使用方式

在 WorkBuddy 平台中启用此专家后，直接描述您的研究课题或搜索需求即可。例如：

- "搜索关于肠脑轴的最新论文"
- "查询 DOI 10.1016/j.foodchem.2023.136000 的详细信息"
- "帮我写一段关于益生菌与免疫调节的文献综述"

您可以通过 WorkBuddy 的专家市场搜索"学术文献综述专家"找到本插件并启用。
