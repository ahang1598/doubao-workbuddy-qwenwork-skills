# DataBuddy Expert Team（WorkBuddy 专家团包）

面向企业级用户的一站式**数据专家团**，主理人协调多位数据领域专业成员，基于 DataBuddy 数据知识库（企业真实数据）为你完成端到端的数据任务。

## 团队成员

| 成员 | 职责 | 状态 |
|------|------|------|
| **DataBuddy 数据分析专家** | 智能问数、指标统计、趋势对比、归因分析、趋势预测、相关性、异动检测、智能看板、分析报告 | ✅ 已上线 |
| **DataBuddy 数据治理专家** | 数据资产盘点、数据质量规则、数据剖析、智能异常检测、敏感数据分类、语义模型管理、Unity Catalog 元数据治理、血缘追踪 | ✅ 已上线 |

## 快速开始

1. **前提**：本机已安装并登录 DataBuddy CLI
   ```bash
   npm install -g databuddycli && databuddycli init --host workbuddy
   wedatacli login
   ```
2. 在 WorkBuddy 中召唤本专家团（专家市场搜索 **"DataBuddy Expert Team"**）。
3. 用自然语言描述任务，例如：
   - 统计上个月 GMV 是多少，环比涨跌多少？
   - 基于订单数据知识库，搭建一个订单销售运营看板
   - 分析某车型订单转化率下降的归因维度

主理人会根据任务内容自动调度对应成员完成工作，你无需关心内部编排。

## 与单独使用数据分析专家的区别

| 维度 | DataBuddy 数据分析专家（单 Agent） | DataBuddy Expert Team（专家团） |
|------|-----------------------------------|-------------------------------|
| 定位 | 独立数据分析专家 | 数据专家团队 |
| 内部机制 | 直接对话 | 主理人编排 + 成员协作 |
| 未来扩展 | 单个专家能力边界 | 持续纳入更多数据领域专家 |
