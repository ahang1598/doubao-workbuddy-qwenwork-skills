# 踏歌行专利智多星专家团（Patent Application Expert Team V2.0.7 加强版）

> V2.0.7 更新（2026-08-10）：displayDescription 压至 48 字合规、members 全补 name 字段对齐规范 3.3/10.2、orchestrator SOP 参考 skill 合法回归（13 skill）、官方校验器 0 error 0 warning 通过。

覆盖**发明专利申请全流程**的 13 人专家团，由主理人「衡策远」统一调度，把技术想法（附论文更佳）整理成符合 CNIPA 国标的申报材料包。

## 核心能力

- **板块一 · 专利成果优化（内容质量）**：现有技术 / 学术检索 → 引用匹配著录 → AI 幻觉五步核验（关卡A）→ 乔哈里窗披露审查 → 权利要求优化 → 交底书修订整合 → 内容质量评分与 AI 四级闸门（关卡B）
- **板块二 · 专利申报（格式规范）**：附图国标化 → 上报格式合规终检 → 目录组织与打包（关卡C）
- **延伸服务**：审查意见答复（OA Response）、跨领域衍生专利迁移

## 防幻觉机制（核心）

AI 只负责「生成候选 + 溯源 + 初筛」，人工负责「核验事实 + 专业判断 + 最终决策」。引用真实性（关卡A）、内容质量（关卡B）、终审打包（关卡C）三道关卡必须停留等待用户确认，禁止 AI 自主走完全流程。

## 团队成员（13 位）

衡策远（统筹总监）、文献渊、引证据、查新源、文述理、范方圆、图致准、焦窗明、验真明、法正清、唐辩方、迁迁移、包综汇。

## 使用方式

在专家中心选择「踏歌行专利智多星专家团」，输入技术想法或已有专利，按 SOP 逐步推进，并在三道关卡逐项确认。

> 边界提示：本团聚焦**发明专利申请**；实用新型 / 外观设计 / PCT 海外 / 复审无效 / 诉讼 / FTO 等超出范围，建议委托专业机构。
