# 现有技术检索器

## 一、适用场景

- 新专利申请前的现有技术检索
- 评估新颖性和创造性授权风险
- 检索结果相似度高时，优化和调整技术方案
- 识别审查员可能援引的对比文件方向

## 二、检索策略

### 2.1 检索数据库

| 数据库 | 覆盖范围 | 检索方式 |
|--------|----------|----------|
| CNIPA（国知局） | 中国专利 | WebSearch + 国知局官网 |
| Google Patents | 全球专利 | WebSearch + Google Patents |
| USPTO | 美国专利 | WebSearch + USPTO |
| EPO | 欧洲专利 | WebSearch + Espacenet |
| 学术文献 | SCI/EI/核心期刊 | WebSearch + DOI |
| arXiv | 预印本 | WebSearch + arXiv |

### 2.2 检索关键词组合策略

采用"词组检索 + 分类号检索 + 同义词检索"的组合模式：

```
主关键词 + 同义词 + 上下位概念 + 技术效果词
```

**本项目案例**：
- 主关键词：WiFi CSI、信道状态信息、射频感知
- 同义词：Wi-Fi sensing、RF sensing、channel state information
- 上位概念：射频信道感知、无线感知
- 技术效果词：多模态、协同调度、安防、入侵检测

### 2.3 检索维度

| 维度 | 检索内容 | 目的 |
|------|----------|------|
| 专利检索 | 同类技术方案的在先专利 | 识别对比文件，评估新颖性 |
| 学术检索 | 相关学术论文 | 识别已披露技术，避免丧失新颖性 |
| 标准检索 | 相关技术标准 | 识别标准必要专利风险 |
| 产品检索 | 商业化产品 | 识别公知技术 |

## 三、风险评估

### 3.1 新颖性风险评估

| 风险等级 | 判定标准 | 应对策略 |
|----------|----------|----------|
| 低 | 无相同技术方案的在先专利/论文 | 正常申报 |
| 中 | 有部分相似专利，但技术方案有本质区别 | 在背景技术中区别论述 |
| 高 | 有高度相似的在先专利 | 补充区别技术特征，调整技术方案 |

### 3.2 创造性风险评估

| 风险等级 | 判定标准 | 应对策略 |
|----------|----------|----------|
| 低 | 现有技术无类似组合方案 | 正常申报 |
| 中 | 现有技术有部分组合，但效果不同 | 突出意料不到的技术效果 |
| 高 | 现有技术已公开类似组合 | 补充失败实验证明技术难度 |

### 3.3 风险评估报告模板

```
## 现有技术检索报告

### 1. 检索概要
- 检索数据库：[列表]
- 检索关键词：[列表]
- 检索日期：[日期]
- 命中文献数：[数量]

### 2. 高相关度文献（相似度≥70%）
| 序号 | 文献编号 | 标题 | 相似度 | 相关点 | 区别点 |
|------|----------|------|--------|--------|--------|

### 3. 中相关度文献（相似度40%-70%）
[同上格式]

### 4. 风险评估
- 新颖性风险：低/中/高
- 创造性风险：低/中/高
- 主要风险来源：[说明]

### 5. 建议
- [建议1]
- [建议2]
```

## 四、本项目实战经验

### 4.1 检索结果（本项目案例）

| 对比专利 | 公开号 | 相似度 | 区别点 |
|----------|--------|--------|--------|
| 海康威视红外入侵探测器 | CN115527328B | 中 | PIR单一传感器 vs CSI多模态协同 |
| 南开大学CSI人体感知 | CN116168499A | 高 | 无IMU补偿 vs 有本体位姿补偿 |
| 浙工大CSI+YOLO无人机 | CN121410835A | 中 | 摄像头视觉 vs 非视觉隐私守护 |

### 4.2 关键经验

1. **同时检索专利和学术论文**：学术论文可能比专利更早公开同类技术
2. **关注公开日**：对比文件的公开日必须早于本申请的申请日
3. **区别技术特征要具体**：不能只说"不同"，要说明"怎么不同、为什么不同、不同带来什么效果"
4. **高相似度不是死刑**：只要有区别技术特征+意料不到的效果，仍有授权可能
5. **检索结果用于背景技术**：在背景技术中主动引用对比文件并论述区别，比被审查员引用更主动

## 五、检索流程

```
1. 确定检索策略（关键词+分类号+同义词）
2. 多数据库并行检索
3. 筛选高相关度文献（相似度≥70%）
4. 逐篇分析区别技术特征
5. 评估新颖性和创造性风险
6. 输出《现有技术检索报告》
7. 如风险高，建议技术方案优化方向
```

## 六、与其他Skill的协作

- **输出给** `patent-disclosure-architect`：检索结果用于撰写背景技术
- **输出给** `patent-claim-optimizer`：对比文件用于设计权利要求区别特征
- **输出给** `hallucination-guard`：检索结果用于验证引用真实性

## 七、输入输出定义

### 输入
| 参数 | 类型 | 说明 |
|------|------|------|
| 技术方案描述 | text | 发明人的技术方案核心创新点 |
| 检索关键词 | list | 主关键词+同义词+上位概念+技术效果词 |
| 检索数据库 | list | CNIPA/Google Patents/USPTO/EPO/学术/arXiv |

### 输出
| 参数 | 类型 | 说明 |
|------|------|------|
| 现有技术检索报告 | object | 高/中/低相关度文献+风险评估+建议 |
| 区别技术特征表 | list | 与每篇对比文件的区别点 |

## 八、人机交互节点

| 节点 | 位置 | 用户操作 | 通过条件 |
|------|------|----------|----------|
| 检索方向确认 | 检索前 | 确认关键词和数据库范围 | 用户确认检索策略 |
| 风险评估确认 | 检索报告输出后 | 确认风险等级和应对策略 | 用户确认后进入下一步骤（Step 1.2） |

## 九、工具局限性与Workaround

| 局限性 | 影响 | Workaround | 实战经验 |
|--------|------|------------|----------|
| WebSearch结果数量有限 | 每次搜索只返回前5-10条 | 多轮搜索，每轮换关键词/换语言 | 中英文双语检索提高命中率 |
| 专利数据库覆盖不全 | 某些国家/地区的专利未收录 | 交叉搜索多个数据库（国知局+Google Patents+USPTO） | 海康专利需多源验证 |
| 学术论文检索深度不足 | 无法搜索论文全文内容 | 关键词+标题+摘要检索；必要时人工阅读 | 本项目ACM论文卷期号错误即因检索深度不足 |
| 检索结果时效性 | 新公开专利/论文可能未即时收录 | 标注检索日期，提醒用户可能有遗漏 | 本项目检索日期2026年7月 |

**核心原则**：检索报告必须标注检索日期和数据库范围，提示用户可能存在未检索到的在先技术。
