# 专利申报 闸门检查清单

## Step 2.2 格式终检（11 项）

| # | 核验项 | 通过标准 | python-docx 检测要点 |
|---|--------|----------|----------------------|
| ① | 五大部分齐全 | 含「一、技术领域 / 二、背景技术 / 三、发明内容 / 四、附图说明 / 五、具体实施方式」 | 逐条匹配 `f"{prefix}、{名}"`，**勿对所有章节硬套同一前缀**（曾误报②-⑤缺失） |
| ② | 发明名称居中 | 首行非「一、」开头 | 标题段无编号前缀 |
| ③ | 引用齐全 | [1]–[N] 连续无缺、无旧号残留 | 正则提取引用标号，比对锁定清单 |
| ④ | 权项完整 | 权项 1–N 编号连续 | `re.match(r'^\d+\.\s', t)` 计数 |
| ⑤ | 摘要 ≤300 字 | len ≤ 300（含标点） | 摘要正文 `len()`，改末句后必复算 |
| ⑥ | 说明书嵌图数 | = 附图说明引图号数 | `sum(1 for r in doc.part.rels.values() if "image" in r.reltype)` |
| ⑦ | 绝对化禁用词 | 无「最佳/唯一/第一」等 | 关键词扫描 |
| ⑧ | 附图说明引图号 | 与嵌图数一致（如 [1-7]） | 提取「图N」编号集合 |
| ⑨ | 不含主体信息 | 说明书不应出现发明人/申请人隐私 | 无身份证号/信用代码 |
| ⑩ | 理论/非实验标注 | 参数/效果标「理论推测/非实验」 | 计数标注处 ≥ 阈值 |
| ⑪ | 数据声明段 | 诚实立场存在（自然句或标注，非必须横幅） | 注：去横幅后此「数据声明」关键词检测会假阴性，以自然句/内联标注为准 |

## Gate C 跨文档一致性（Step 2.3）

- [ ] 四文档（权项/说明书/摘要/请求书）发明名称核心词一致
- [ ] 权项含方法独权(1) + 系统独权(10)，共同涵盖名称中「方法及系统」
- [ ] 权项数 = N（本研究 19）
- [ ] 摘要首段 ≤300 字
- [ ] 说明书嵌入图数 = 附图说明引图号数
- [ ] 04_附图 TIFF 数 = 图数（注意清理被否决的旧图冗余，如 matplotlib 旧版）
- [ ] 摘要附图 = 摘要指定图号一致
- [ ] 请求书主体信息留空（标【待用户填写】≥4 处）

## M17 来源影响判定门禁（出说明书前）

- [ ] 每条来源：人工溯源（链接可打开）+ 人工确认准确
- [ ] 每条：判定 加固 / 无价值(删) / 颠覆(重判) + 过程 + 原因
- [ ] 仅保留加固/颠覆相关（无价值已删）
- [ ] 门禁关闭后才出正式说明书
- [ ] 说明书 = 权项/摘要/附图/请求书唯一基础
