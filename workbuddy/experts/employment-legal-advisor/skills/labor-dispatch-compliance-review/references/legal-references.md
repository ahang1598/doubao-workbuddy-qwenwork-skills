## 二、检索调用链

各 Phase 法条闸门触发时，按以下步骤联网检索：

### 检索流程

```
1. 识别需核实的法条编号（如"劳动合同法第57条"）
2. 联网检索：关键词 = 法规全称 + 条文编号（如"劳动合同法第57条全文"）
3. 交叉验证：至少2个来源确认原文
4. 比对结论：核对引用内容与原文一致性
5. 标注来源：记录检索URL和验证时间
```

### 优先检索来源

1. 国家法律法规数据库（flk.npc.gov.cn）
2. 人力资源和社会保障部官网（mohrss.gov.cn）
3. 北大法宝（pkulaw.com）

### 无法检索时的处理

- **🔴 检索返回空结果 ≠ 可以凭记忆引用**：即使你知道条文内容，检索空结果时该法条结论必须标注 `[待核查]`，不得照引不误
- 法条结论标注"待核查"
- 建议律师自行核实
- 报告附注中列出哪些法条未检索到原文
- 不得编造条文内容

## 三、法条引用格式规范

报告中的法条引用统一格式：

- **正文引用**：《法规名称》第X条
- **首次引用**：全称 + 简称说明，如"《中华人民共和国劳动合同法》（以下简称《劳动合同法》）第57条"
- **引用块**：完整条文原文，使用 Markdown 引用块格式

## 五、地方裁审口径检索（Phase 7 强制）

### 检索时机

Phase 7 生成报告前，必须联网检索用工单位所在地的地方裁审倾向。

### 检索关键词模板

```
{用工单位所在省/市} + 劳务派遣 + {审查要点} + 裁审口径
{用工单位所在省/市} + 劳务派遣 + 三性认定 + 典型案例
{用工单位所在省/市} + 人力资源和社会保障厅/局 + 劳务派遣 + 指导意见
```

示例：
- "浙江省 劳务派遣 三性认定 裁审口径"
- "台州市 劳务派遣 辅助性岗位 典型案例"
- "浙江省人力资源和社会保障厅 劳务派遣 指导意见"

### 检索目标

1. **省高院/中院裁判倾向**：对三性认定（尤其是辅助性/边缘岗位）的倾向性意见
2. **地方人社部门规范性文件**：如《浙江省人力资源和社会保障厅关于劳务派遣若干问题的意见》等
3. **当地典型行政处罚案例**：了解本地劳动监察执法力度和处罚标准
4. **裁审口径差异标注**：如发现国家层面法规与地方实践存在差异，必须在报告中标注

### 检索结果使用

- 在三性分析中对边缘岗位（如仓库管理员）标注本地裁审倾向
- 在综合风险评估中标注"以上分析基于国家层面法规，{地名}裁审实践可能另有倾向，建议进一步咨询本地律师"
- 若未检索到相关信息，标注"未检索到{地名}专项裁审口径，结论基于国家层面法规"
