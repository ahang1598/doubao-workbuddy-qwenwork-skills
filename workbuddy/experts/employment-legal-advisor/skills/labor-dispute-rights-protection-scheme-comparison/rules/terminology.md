> 版本: 3.1.0

## §2. 受众语言适配（词级：律师术语→当事人语言）

| 律师内部术语 | 报告中对当事人的表述 |
|------------|-------------------|
| 赔偿金2N | 双倍补偿金（违法解除时的赔偿标准） |
| 经济补偿金N | 法定补偿金（按工作年限计算，每工作1年算1个月工资） |
| 终局裁决 | 裁决后对方不能再起诉，但您还可以 |
| 仲裁时效 | 法律保护的维权期限（通常为1年） |
| 支付令 | 快速要钱程序（不走仲裁，直接向法院申请，15天内可拿到） |
| 恢复劳动关系 | 回原岗位继续工作，同时补发离开期间的工资 |
| 强制执行 | 通过法院强制对方给钱 |
| 竞业限制补偿金 | 离职后不从事同行业工作的补偿 |
| 举证责任倒置 | 需要对方来证明，而不是您来证明 |
| 确认劳动关系 | 先确认您和公司之间存在法律上的劳动关系 |
| 财产保全 | 先冻结对方财产，防止他转移 |
| 双倍工资差额 | 未签合同期间的额外工资（每月多发一倍） |

## §3. 易混淆术语辨析

| 术语A | 术语B | 区别 | 使用场景 |
|-------|-------|------|---------|
| 劳动仲裁 | 劳动监察 | 准司法程序vs行政程序 | 不同救济通道 |
| 工伤认定 | 工伤鉴定 | 行政确认vs劳动能力评估 | 工伤处理不同阶段 |
| 调解 | 和解 | 第三方介入vs双方自行 | 调解书vs和解协议 |
| 终局裁决 | 非终局裁决 | 裁决即生效vs可起诉 | 调解仲裁法第47条 |
| 赔偿金(2N) | 经济补偿金(N) | 违法解除vs合法解除/终止 | 劳动合同法第47vs87条 |
| N+1 | N | +1是未提前30日通知的额外补偿 | 劳动合同法第40条 |

## §4. 禁用词清单

| 禁用词 | 原因 | 替代表述 |
|--------|------|---------|
| 保证/肯定/一定/必然 | 禁止胜诉保证 | 基于现有证据的预期/参考类案的常见结果 |
| 诉讼时效 | 劳动争议用仲裁时效 | 仲裁时效 |
| 信访是主要途径 | 信访无强制力 | 信访可作为补充手段 |
| 打官司就能赢 | 禁止承诺结果 | 需评估证据/时效/对方偿付能力后判断 |

## §5. 受众适配三层规则（Phase 4执行）

### 5.1 词级替换规则（§2 对照表）

**执行方式**：全文扫描，匹配左侧术语 → 替换为右侧表述。注意：
- 法条编号保留（如"第87条"），不加通俗解释
- 金额数字保留原值，不加"约"
- 机构名称保留全称（如"XX区劳动人事争议仲裁委员会"）

### 5.2 段落级改写规则

**核心原则**：法律分析段必须改写为"当事人可理解的方案对比段"，改写目标如下：

| 法律分析段特征 | 改写方向 | 示例 |
|-------------|---------|------|
| "根据《劳动合同法》第87条，用人单位违反本法规定解除或者终止劳动合同的，应当依照第47条规定的经济补偿标准的二倍向劳动者支付赔偿金" | → 告诉当事人"您能得到什么" | "按照法律规定，公司违法解除劳动合同，您有权要求公司支付双倍补偿金。标准是：每工作满1年，赔2个月工资。" |
| "该请求权基础构成要件为：(1)存在劳动关系；(2)用人单位单方解除；(3)解除不符合法定事由" | → 告诉当事人"您需要证明什么" | "您需要向仲裁委证明三件事：①您和公司有劳动关系；②公司确实把您辞退了；③辞退没有合法理由。目前您有合同和微信聊天记录，基本能证明。" |
| "仲裁时效自知道权利被侵害之日起算，期间为1年" | → 告诉当事人"您还有多少时间" | "您需要在XXXX年X月X日之前向仲裁委提出申请（还有X天），超过这个时间，法律可能不再保护您的权益。" |
| "加付赔偿金以责令限期支付为前提条件" | → 告诉当事人"前提条件是什么" | "如果要拿到额外的赔偿金（欠薪金额的50%-100%），需要先经过劳动监察大队责令公司限期支付这一步。" |

**改写质量自检**：改写后的段落应满足——读完能知道"我能做什么/我能拿到多少/我还需要什么/我有什么风险"，而不需要知道法条原文。

### 5.3 全文级适配规则（劳动者版 vs 企业方版）

**识别方式**：Phase 1的classified_input.class_A.role 确定身份视角。

#### 劳动者版全文语气规则

| 方面 | 规则 |
|------|------|
| 称呼 | 使用"您"称呼当事人 |
| 致送对象 | 无需（报告给当事人看，非提交法院） |
| 正面表述 | "您有权要求"、"法律规定您可以" |
| 风险提示 | "需要提醒您注意"、"您需要评估" |
| 行动建议 | "建议您尽快"、"您可以先尝试" |
| 谨慎表述 | "根据现有证据"、"参考类案结果" |
| 禁用 | "你"（非敬语）、"应该"（命令式）、"只能"（绝对化） |

#### 企业方版全文语气规则

| 方面 | 规则 |
|------|------|
| 称呼 | 使用"贵司"或"公司"称呼企业当事人 |
| 正面表述 | "公司可以"、"法律允许公司" |
| 风险提示 | "公司需要关注的风险"、"建议公司评估" |
| 行动建议 | "建议公司采取"、"公司可以考虑" |
| 谨慎表述 | "基于当前信息"、"取决于具体证据" |
| 特别关注 | 增加"连锁风险"提示（个案→群体效应）、"合规整改"建议、反申请可行性 |

#### 两版共有规则

- 头部免责声明相同
- 底部免责声明相同
- 不保证任何结果（两版统一）
- 不煽动对立情绪（两版统一）
- 金额统一用"元"，不用"元人民币"
- 日期格式统一为"YYYY年M月D日"

## §6. 双版本受众适配差异规则（Phase 4 执行）

> 基于 O1 客户版 → O2 律师版的双版本生成流程，以下规则定义两个版本间的差异点。

### 6.1 版本间变换对照表

| 变换维度 | O1 客户版 | O2 律师版 | 变换方向 |
|---------|----------|----------|---------|
| 人称 | "您"/"贵司" | "当事人"/"我方"/"对方" | O1→O2 回退第三人称 |
| 术语 | 通俗化表述（§2对照表右侧） | 法律专业术语（§2对照表左侧） | O1→O2 恢复术语 |
| 内部标注区块 | 不生成 | 生成「七、内部标注」 | O2 新增 |
| 置信度 | 不显示 | 显示置信度矩阵 | O2 新增 |
| 假设条件 | 融入分析 | 显式列出 | O2 新增 |
| 下游技能 | 不显示 | 显示技能衔接建议 | O2 新增 |
| 风险分级 | 客户化表达 | L1/L2/L3 标记 | O2 新增 |
| 路径切换触发 | 不显示 | 显示触发条件表 | O2 新增 |
| 免责措辞 | 客户化（output-spec.md §2.2 对照表右侧） | 律师版（output-spec.md §2.2 对照表左侧） | O1→O2 切换措辞 |

### 6.2 版本间不变内容

以下内容在 O1/O2 两版中保持一致，不做区分：
- 案情摘要与当事人画像
- 方案全景概览（五维标签+通道矩阵）
- 方案对比矩阵（六维对比卡片+金额柱状图+风险色标）
- 推荐方案与五步推理链
- 操作指引（受理机构+材料清单+步骤+时间+费用）
- 时效提醒（限截止日期和红色警告，不含L1/L2/L3标记）
- HTML 模板整体结构和打印适配

### 6.3 律师版生成自检清单

O2 生成完毕后，逐项检查：
- [ ] 全文"您"→"当事人"/"贵司"→"公司或企业方"替换完整
- [ ] 内部标注区块已生成且内容完整（6个子区块：信息充足度/置信度矩阵/假设条件/方案切换触发/下游技能衔接/风险分级）
- [ ] 置信度矩阵覆盖全部 N 个方案的六维
- [ ] 假设条件至少列出 3 条
- [ ] 下游技能衔接建议已给出（至少3个具体技能名）
- [ ] 风险分级含 Phase 级别标注 + 整体 L2
- [ ] 免责声明使用律师版措辞
