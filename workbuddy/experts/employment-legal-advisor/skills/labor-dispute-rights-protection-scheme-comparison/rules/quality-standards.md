# 质量标准 | 劳动争议维权方案对比

> 版本: 3.1.0 | 风险等级: L2

## 1. 六维评价体系

| 维度 | 权重 | 顶级标准(90+) | 及格标准(60) |
|------|------|-------------|-------------|
| 方案覆盖完整性 | 20% | 9通道×5族请求权全考量+身份双视角 | 3个以上可行方案 |
| 对比维度充分性 | 20% | 六维量化对比+金额三区间+风险色谱 | 三维以上基本对比 |
| 受众适配度 | 20% | 客户化语言+通俗解释+阅读指引 | 基本可读 |
| HTML呈现质量 | 15% | 并排卡片+风险色谱+折叠面板+打印适配 | 基本HTML结构 |
| 推荐推理充分性 | 15% | 五步推理链（争议类型→请求权→证据→时效→诉求优先级） | 有推荐+基本理由 |
| 时效风险提示 | 10% | 逐通道逐请求权时效检查+红色倒计时提醒 | 有时效提醒 |

## 2. 阻断级检查项（35项）

### 2.1 方案构建阻断
- [ ] 仲裁前置原则已体现
- [ ] 至少构建3个以上可行方案
- [ ] 劳动者/企业方方案已区分
- [ ] 工伤认定独立程序已标注
- [ ] 欠薪场景支付令已纳入候选

### 2.2 对比维度阻断
- [ ] 每个方案含六维对比（法律依据/胜败概率/预期金额/时间成本/经济成本/风险副作用）
- [ ] 预期金额含三区间（最佳/一般/最差）
- [ ] 胜败概率用高/中/低三级标注
- [ ] 方案推荐有五步推理链

### 2.3 时效风险阻断
- [ ] 每个方案含时效检查
- [ ] 超时效方案已红色警告
- [ ] 15日起诉期限已提示
- [ ] 1年仲裁时效已检查

### 2.4 受众适配阻断
- [ ] 报告语言为客户化语言（非律师内部术语）
- [ ] 头部和底部含免责声明
- [ ] 无"保证胜诉"表述
- [ ] 无煽动性/情绪化语言

### 2.5 HTML质量阻断
- [ ] 六大区块完整
- [ ] 风险色标已渲染（红/琥珀/绿）
- [ ] 折叠面板可用
- [ ] @media print 打印适配已声明

### 2.5-bis 双版本完整性阻断
- [ ] O1 客户版：六大区块完整
- [ ] O1 客户版：人称适配正确（"您"/"贵司"）
- [ ] O1 客户版：术语已通俗化（无内部律师术语裸出）
- [ ] O1 客户版：无内部标注区块（L1/L2/L3/置信度/假设条件/下游技能）
- [ ] O2 律师版：含「七、内部标注」区块
- [ ] O2 律师版：信息充足度 D1-D6 评分表完整
- [ ] O2 律师版：置信度矩阵覆盖全部 N 个方案六维
- [ ] O2 律师版：假设条件 >= 3 条
- [ ] O2 律师版：下游技能衔接 >= 3 个建议
- [ ] O2 律师版：人称回退完成（"您"→"当事人"）
- [ ] O2 律师版：免责声明使用律师版措辞
- [ ] O1/O2 文件名含受众标识（客户版/律师版）

### 2.6 合规阻断
- [ ] 法条编号与原文一致
- [ ] 无替代律师独立判断的表述

## 3. 警告级检查项（10项）

- [ ] 组合方案（仲裁+监察并行等）已评估
- [ ] 对方偿付能力已评估
- [ ] 保全建议已提出（如对方有转移资产风险）
- [ ] 金额估算的假设前提已标注
- [ ] 各方案互斥关系已说明
- [ ] 集体争议特殊通道已标注（10人以上）
- [ ] 终局裁决策略影响已提示
- [ ] 企业方连锁诉讼风险已评估
- [ ] 证据缺口对应的补证建议已给出
- [ ] 地方裁审指导意见差异已提示

## 4. 格式级检查项（10项）

- [ ] O1 客户版 HTML 六大区块完整无遗漏
- [ ] O2 律师版 HTML 六大区块 + 内部标注区块完整
- [ ] 比较矩阵表格对齐
- [ ] 金额单位统一（元）
- [ ] 法条编号格式统一
- [ ] 免责声明位置正确（头部+底部）
- [ ] 折叠面板标签清晰
- [ ] 打印版本无交互残留
- [ ] O1 文件名含"客户版"标识
- [ ] O2 文件名含"律师版"标识
