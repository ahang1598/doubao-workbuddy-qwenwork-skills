# 输入规格 | 劳动争议维权方案对比

> 版本: 3.1.0 | 风险等级: L2
> 模型：九类宽容摄取模型（A-I）

## 1. 九类输入定义

### A. 当事人基本信息

| 子字段 | 必填性 | 说明 | 对方案的影响 |
|--------|--------|------|-------------|
| 身份 | 是 | 劳动者/企业代表 | 决定双视角哪一端 |
| 年龄 | 推荐 | 是否满16周岁/是否接近退休 | 退休年龄影响经济补偿金计算 |
| 用工性质 | 推荐 | 全职/兼职/实习/劳务派遣/外包 | 影响劳动关系确认 |
| 工龄 | 是 | 入职日期 | 计算N的基数 |
| 月工资标准 | 是 | 基本工资+绩效+补贴 | 赔偿/补偿计算基数 |
| 社保缴纳 | 推荐 | 是否缴/基数合规性 | 社保争议+工伤认定前提 |
| 合同状态 | 推荐 | 是否签订/签订次数/固定/无固定 | 未签合同双倍工资/无固定期限 |
| 特殊身份 | 推荐 | 孕期/产期/哺乳期/工伤/职业病/接近退休 | 解雇限制（劳动合同法第42条） |

### B. 诉求意向

| 子字段 | 必填性 | 说明 |
|--------|--------|------|
| 核心诉求 | 是 | 当事人最想实现的目标（要钱的金额/要回岗位/要赔偿） |
| 优先级排序 | 推荐 | 多个诉求间的优先级 |
| 底线预期 | 可选 | 最低可接受结果 |
| 理想预期 | 可选 | 期望达到的结果 |
| 时间要求 | 推荐 | 是否有紧迫性 |
| 情绪状态 | 可选 | 是否愿意调解/和解 |
| 是否愿意继续工作 | 推荐 | 影响恢复劳动关系 vs 赔偿金选择 |
| 已采取的行动 | 推荐 | 是否已投诉/举报/申请仲裁 |

### C. 约束条件

| 子字段 | 必填性 | 说明 |
|--------|--------|------|
| 经济承受能力 | 推荐 | 能否负担律师费/保全费 |
| 时间承受能力 | 推荐 | 能否承受1-2年诉讼周期 |
| 精力承受能力 | 可选 | 是否因健康/工作等原因无法频繁参与 |
| 地域限制 | 可选 | 是否异地（影响出庭成本） |
| 保密需求 | 可选 | 是否不希望公开（同行圈子） |
| 职业影响顾虑 | 推荐 | 是否担心行业口碑影响再就业 |
| 家庭意见 | 可选 | 家属是否支持诉讼 |
| 是否有新工作 | 推荐 | 已入职新单位则恢复劳动关系不可行 |

### D. 案件事实

| 子字段 | 必填性 | 说明 |
|--------|--------|------|
| 入职过程 | 推荐 | 面试/入职时间/入职方式 |
| 工作内容 | 推荐 | 岗位/职责/地点/考勤方式 |
| 薪酬结构 | 是 | 基本工资/绩效/提成/补贴/报销 |
| 加班情况 | 可选 | 频率/时长/审批/是否支付加班费 |
| 争议事件 | 是 | 何时/何地/何人/发生了什么 |
| 解除/终止过程 | 推荐 | 谁提出/什么理由/什么方式/什么时间 |
| 通知送达 | 推荐 | 是否收到书面通知/内容 |
| 协商过程 | 可选 | 是否有过协商/对方态度/已提条件 |
| 历史争议 | 可选 | 是否有过前次仲裁/诉讼 |
| 工伤/职业病 | 可选 | 是否认定/鉴定等级/待遇支付 |

### E. 证据材料

支持6种输入形态：自然语言描述/结构化清单/文件上传引用/对话补全/混合输入/仅关键词

| 证据类别 | 典型证据 | 效力等级 |
|---------|---------|---------|
| 合同类 | 劳动合同/offer/保密协议/竞业协议 | 直接证据（最佳） |
| 工资类 | 银行流水/工资条/个税记录/社保记录 | 直接证据 |
| 考勤类 | 打卡记录/加班审批/请假记录/排班表 | 直接证据 |
| 沟通类 | 微信聊天/邮件/钉钉/录音/录像 | 补强证据 |
| 身份类 | 工牌/名片/工服/工作邮箱/系统账号 | 间接证据（劳动关系确认） |
| 解除类 | 解除通知书/离职证明/交接单 | 直接证据 |
| 行政记录 | 劳动监察投诉记录/行政处罚决定书 | 公文书证（效力最高） |

### F. 法律依据（律师主动检索补充）

- 适用的法律法规（劳动法/劳动合同法/调解仲裁法/劳动争议司法解释一至五）
- 地方裁审指导意见（各高院/中院劳动争议审判指导意见，地域差异极大）
- 类案裁判（本地区类似案件的裁判倾向和结果）

### G. 对方信息

| 子字段 | 劳动者端关注 | 企业端关注 |
|--------|------------|-----------|
| 经营状况 | 是否正常经营/有无注销风险 | 员工在职情况/是否有群体纠纷 |
| 偿付能力 | 注册资本/实缴/资产/执行记录 | 员工经济状况（竞业违约追偿） |
| 历史纠纷 | 企查查/天眼查涉诉记录 | 员工是否有多次仲裁记录 |
| 应诉态度 | 是否愿意协商 | 员工诉求是否合理 |
| 关联风险 | 关联公司/法人变更/资产转移 | 员工是否掌握商业秘密 |

### H. 程序状态

| 子字段 | 必填性 | 说明 |
|--------|--------|------|
| 当前阶段 | 是 | 争议刚发生/已协商/已申请仲裁/仲裁中/已起诉 |
| 时效状态 | 是 | 距离知道权利被侵害多久 |
| 是否已仲裁 | 推荐 | 仲裁结果/是否终局裁决 |
| 是否已起诉 | 推荐 | 一审/二审/再审 |
| 是否有保全 | 可选 | 财产保全/行为保全 |
| 是否有先予执行 | 可选 | 仲裁中是否申请先予执行 |

### I. 外部因素

| 子字段 | 必填性 | 说明 |
|--------|--------|------|
| 政策风向 | 可选 | 当前劳动保障政策倾向 |
| 监管态势 | 可选 | 劳动监察/社保稽核执法力度 |
| 行业惯例 | 可选 | 本行业合同签订/社保缴纳通行做法 |
| 经济环境 | 可选 | 经济下行期经营困难抗辩更易被采信 |

## 2. 完整度四档分级处理

| 完整度 | 输入状态 | 分析策略 | 输出调整 |
|--------|---------|---------|---------|
| ★★★★ | 全部9类齐备 | 精确量化方案对比 | 六维完整对比+三区间金额 |
| ★★★☆ | 缺1-2类 | 标注缺口+条件性分析 | 六维对比+缺口标注+假设前提 |
| ★★☆☆ | 缺3-4类 | 粗略对比+重点补缺建议 | 三维简化对比+补缺清单+SOFT_DEGRADED |
| ★☆☆☆ | 仅知诉求 | 暂缓方案对比 | 输出SOFT_DEGRADED C+D+G骨架 |

## 3. 交互补全规则

当缺少关键信息时，技能交互补全（最多3轮）：

| 缺失项 | 补全问题 | 优先级 |
|--------|---------|--------|
| 当事人身份 | "您是劳动者还是企业代表？" | P0 |
| 核心诉求 | "您最想实现什么目标？（要赔偿/要回岗位/要补缴社保）" | P0 |
| 争议基本事实 | "请简单描述发生了什么？（比如：公司哪天以什么理由解除劳动关系）" | P0 |
| 工龄与工资 | "您什么时候入职？每月工资大约多少？" | P0 |
| 时效状态 | "争议是什么时候发生的？离现在多久了？" | P1 |
| 证据情况 | "您手上有劳动合同/工资记录/解除通知书吗？" | P1 |
| 对方情况 | "公司还在正常经营吗？有没有注销/搬迁的迹象？" | P1 |
| 约束条件 | "您能承受多长的维权周期？预算上有哪些考虑？" | P2 |
