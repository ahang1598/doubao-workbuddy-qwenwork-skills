# 风险框架 | 劳动争议仲裁申请书

> 版本: 3.3.0 | 风险等级: L2

## 1. 风险等级定义

| 等级 | 含义 | 处理方式 |
|------|------|---------|
| L1 | 低风险 | 基础校验，自动处理 |
| L2 | 中等风险 | 须注意，建议律师复核 |
| L3 | 高风险 | 须律师复核，否则可能导致严重后果 |

## 2. Phase 风险分级

| Phase | 风险等级 | 风险点 | 应对措施 |
|-------|---------|--------|---------|
| Phase 0 诉前评估 | L2 | 管辖选择错误/时效误判/请求权基础遗漏 | 四维评估+决策矩阵 |
| Phase 1 输入验证 | L1 | 字段缺失/格式错误 | 交互补全≤3轮 |
| Phase 2 事实建构 | L2 | 事实梳理遗漏/不利自认/法律映射错误/策略叙事不足 | 核心事实+法条支撑+策略叙事技法+缺失证据提示+法律概念映射表 |
| Phase 3 请求论证 | L3 | 金额计算错误/法条引用错误/时效遗漏/主位备位设计不当/计算基数错误 | 金额逐项校验+公式嵌入+法条依据匹配+时效审查+基数确认 |
| Phase 4 文书生成 | L2 | 格式不规范/术语错误/O1内部标注残留/送达地址遗漏/O2内容缺失 | O1/O2双格式严格隔离+术语对照表+O1七段式结构+O2九模块+format-spec渲染 |
| Phase 5 质量检查 | L2 | 红线检查遗漏/格式不合规/O1标注外泄 | 阻断级17项+警告级19项+O1检查13项+O2检查6项 |

## 3. 风险控制规则

### RC-01 法条引用准确性

- **触发条件**：任何法条引用
- **严重程度**：高
- **处理**：P5阻断级检查——编号/内容任一错误即阻断输出；性质标注错误阻断O2输出
- **依据**：§17.15 法条检索强制契约

### RC-02 金额精确性

- **触发条件**：涉及金钱请求
- **严重程度**：高
- **处理**：P5阻断级检查——模糊金额即阻断
- **依据**：仲裁请求须具体确定

### RC-03 仲裁时效审查

- **触发条件**：争议发生距申请时间超过1年
- **严重程度**：中
- **处理**：提示时效风险，不拒绝处理
- **例外**：劳动关系存续期间拖欠工资不受1年限制

### RC-04 举证责任倒置提醒

- **触发条件**：涉及解除合法性/减少报酬/计算工作年限
- **严重程度**：中
- **处理**：在事实与理由中提示由用人单位举证
- **依据**：解释(一)第44条

### RC-05 终局裁决标注

- **触发条件**：追索劳动报酬≤当地月最低工资×12个月
- **严重程度**：低
- **处理**：标注终局裁决，提示用人单位不可起诉
- **依据**：调解仲裁法第47条

### RC-06 保证胜诉表述

- **触发条件**：输出中含"必将胜诉""无疑应予支持"等
- **严重程度**：高
- **处理**：P5阻断级检查——含此类表述即阻断
- **依据**：律师执业规范

### RC-07 不利自认风险

- **触发条件**：事实陈述中包含对己方不利且法律不要求承认的事实
- **严重程度**：高（但AI判定不可靠，降级为警告👤低）
- **处理**：P5警告级检查——发现不利自认列入律师必检清单，不阻断输出（AI对不利自认的判定不可靠，需法律策略上下文判断）
- **常见表现**：
  - "我虽然迟到/旷工..."（自认违纪）
  - "公司说我绩效不达标..."（自认绩效问题）
  - "我也承认有些工作没做好..."（自认过失）
  - "我同意调岗但不同意降薪..."（自认同意调岗）
- **正确做法**：
  - 被申请人主张的负面事实，要求其举证证明
  - 不主动承认对方尚未举证的负面事实
  - 用"被申请人单方主张..."替代自认性表述

### RC-08 计算基数风险

- **触发条件**：经济补偿金/赔偿金/代通知金等涉及月工资基数计算
- **严重程度**：高
- **处理**：P5阻断级检查——基数使用实发工资即阻断
- **核心规则**：
  - 经济补偿金基数 = **应发工资**（税前），非实发工资（税后）
  - 应发工资包括：计时/计件工资、奖金、津贴、补贴等货币性收入
  - 加班费是否计入基数：各地口径不一，须核实当地规定
  - 高于当地上年度职工月平均工资3倍的：按3倍计算（劳动合同法第47条）
- **常见错误**：
  - ❌ 使用扣除社保公积金后的实发工资
  - ❌ 遗漏季度奖/年终奖/高温津贴等
  - ❌ 未封顶（超过3倍社平工资部分应封顶）
- **基数构成校验**（v3.1.1 新增）：
  - 当monthly_salary>5000元时，须确认该金额是否已包含季度奖/年终奖分摊/加班费分摊
  - 季度奖/年终奖是否分摊计入月基数：各地做法不一，标注[需核实当地口径]
  - 加班费是否计入：北京计入，上海部分计入，深圳不计入
  - 交通/通讯/餐补是否计入：各地口径差异

### RC-09 二倍工资时效特殊规则

- **触发条件**：请求未签书面劳动合同二倍工资差额
- **严重程度**：中
- **处理**：P0时效评估时逐月审查，P5质量检查时校验
- **核心规则**：
  - 二倍工资差额按月计算，每月差额独立起算1年时效
  - 非从劳动关系终止之日统一起算
  - 部分地区（如北京）从主张权利之日起往前推1年
  - 部分地区（如广东）从离职之日起算
  - **须核实当地规定**，标注[需核实当地规定]
- **示例**：
  - 2022年6月入职，2022年7月-2023年5月应付二倍工资
  - 2024年8月申请仲裁：
    - 逐月审查：2022年7月差额已超1年时效（2023年7月届满）→ 不予支持
    - 逐月审查：2023年5月差额未超1年时效（2024年5月届满前已申请）→ 可主张
  - 最终仅能主张时效未届满月份的二倍工资差额

### RC-10 管辖策略风险

- **触发条件**：劳动合同履行地与用人单位所在地不在同一地区
- **严重程度**：中
- **处理**：P0诉前评估时进行两地比较，给出选择建议
- **风险点**：
  - 两地裁判口径差异（如同工同酬/加班费基数/经济补偿封顶标准）
  - 选择不利管辖地可能导致请求被驳回或金额减少
  - 部分地区对劳动者保护更充分
- **应对策略**：
  - P0阶段比较两地裁判倾向
  - 优先选择对申请人有利的管辖地
  - 标注[需核实当地规定]当地特殊口径

### RC-11 内部标注外泄风险

- **触发条件**：O1正文生成
- **严重程度**：高
- **处理**：P5阻断级检查——O1中出现任何内部标注即阻断输出
- **禁止出现在O1的标注**：
  - 法条性质标注：（授权性）/（命令性）/（程序性）/（证据性）
  - 分析框架标签：〔策略〕/〔评估〕/〔风险〕/〔建议〕
  - 证据分类标签：〔身份〕/〔事实〕/〔辅助〕
  - 证据-请求映射矩阵
  - 举证责任分析框架
  - "关于XX"独立小标题段落
- **正确归属**：以上标注仅出现在O2使用指引(HTML)中

### RC-12 叙事融合违规

- **触发条件**：O1事实与理由段生成
- **严重程度**：高
- **处理**：P5阻断级检查——O1中出现"关于XX"独立小标题或法条论证独立成段即阻断
- **违规表现**：
  - ❌ "关于拖欠工资：被申请人自2024年11月起..."
  - ❌ "关于违法解除：被申请人以'业务调整'为由..."
  - ❌ "大前提：法律规定...小前提：案件事实...结论：请求支持"
- **正确做法**：
  - ✅ "被申请人自2024年11月起未支付劳动报酬。依照《劳动法》第五十条之规定，被申请人应当向申请人支付拖欠工资27,000元（9,000元/月×3个月）"
  - ✅ "被申请人于2024年12月31日口头通知解除，未出具书面通知。依照《劳动合同法》第四十八条、第八十七条之规定，应支付赔偿金84,000元（12,000元/月×3.5年×2倍）"
  - ✅ 核心事实+法条引用，不过度展开法律评价三步论述

## 4. SOFT_DEGRADED 降级机制

### 4.0 交互优先决策树（v3.1.0 新增）

> v3.1.0 核心改进：明确交互优先于降级，避免本应交互补全的场景直接被降级。

```
输入不足
  → P1 交互补全（≤3轮）
    → 补全成功 → 标准管线 / FAST_TRACK
    → 仍不足
      → 核心信息缺失？(金额/请求/被申请人)
        → 是 → DEGRADED-L2（C+D+G最小骨架）
        → 否 → DEGRADED-L1（缺非核心信息，正常生成+标注补全提醒）
```

### 4.1 触发条件

> v3.1.0 变更：阈值下调（事实简述<100字→<50字）+ 分级降级（DEGRADED-L1/L2）。

| 条件 | 降级级别 | 说明 |
|------|---------|------|
| 事实简述<50字 | DEGRADED-L2 | 无法构建完整事实链条 |
| 证据清单缺失 | DEGRADED-L2 | 无法支撑仲裁请求 |
| 仲裁请求金额未明确 | DEGRADED-L2 | 不符合仲裁请求具体确定原则 |
| 管辖仲裁委未确定 | DEGRADED-L2 | 无法确定受理机构 |
| 用户明确拒绝P0评估 | DEGRADED-L2 | 跳过诉前评估直接降级 |
| 非核心信息缺失（送达地址/工作年限/工资标准等） | DEGRADED-L1 | 正常生成+标注补全提醒 |
| 证据部分缺失但请求可证 | DEGRADED-L1 | 正常生成+标注补证方向 |

**DEGRADED-L1 补全提醒规则**（v3.1.1 新增）：
- 补全提醒仅在O2提交检查清单中以☐待办项呈现，标注"⚠️ 待补全：[字段名] — [影响] — [建议来源]"
- O1中缺失的非核心字段使用占位符（如"___元/月""___市___区劳动人事争议仲裁委员会"），不嵌入任何提醒文本
- O1正文保持严格干净，不得出现DEGRADED标注

### 最小骨架 C+D+G

**C) Missing Facts Checklist**：
| 缺失项 | 影响程度 | 建议来源 |
|--------|---------|---------|
| 事实简述不足 | content_detail | 当事人陈述/工作记录 |
| 证据清单缺失 | evaluation | 劳动合同/工资流水/考勤记录 |
| 金额计算依据 | boundary | 工资条/银行流水 |
| 管辖仲裁委 | content_detail | 劳动合同/工商登记 |
| 送达地址 | content_detail | 申请人确认 |

**D) Governance & Non-Goals**：
- ban_boundary_items：保证胜诉/确定赔偿数额/虚构事实/不利自认
- non_goal_items：伪造证据/教唆作伪证/规避时效

**G) Actionable Next Steps**：
- upgrade_actions：补充事实/提供证据/确认金额/确定管辖/提供送达地址
- target_field：facts_and_reasons / evidence_list / arbitration_claims.amount / arbitration_committee / service_address
