# 格式规范 | 劳动争议仲裁申请书

> 版本: 3.3.0 | 输出格式: O1(DOCX) + O2(HTML) | 适用范围: 打印/电子提交

**排版标准层级**（按优先级）：
1. **当地仲裁委实际要求**（无全国统一标准，以当地要求为准，优先向用户确认）
2. **仲裁委官方样本**：本规范 §9 排版参数源自实际仲裁委申请书样本提取，为目前最权威的排版依据
3. **律师行业惯例**：《法律文书标准排版格式》（《民商法实务精要2》）
4. **兜底参考**：《党政机关公文格式》GB/T 9704-2012 / 《民事诉讼文书样式》（最高人民法院2016版）

**关键设计决策**（基于仲裁委官方样本提取）：
- 页边距3.14cm(上下)/2.98cm(左右)：源自仲裁委官方申请书样本实际测量值。与法院标准（法发〔2016〕13号 37/35/28/26mm）不同——仲裁申请书非法院裁判文书，不适用法院版心标准
- 正文字号宋体三号(16pt)：仲裁委官方样本正文统一使用宋体三号(16pt)，与法院裁判文书正文字号一致。数字/英文使用 Times New Roman
- 标题字体方正小标宋_GBK 22pt(二号)：公文标题专用字体，与法院裁判文书标题字体一致
- 标签字体方正黑体简体 16pt(三号)：段落标题（"申请人""仲裁请求"等）使用黑体，与正文同字号但字体区分
- 行距30pt最小值：官方样本实测值，略宽于法院标准28.5磅，仲裁申请书篇幅较长需适度宽松

## 1. 页面设置

> 完整 DOCX 排版参数详见 [§9.1 DOCX排版规范——页面设置](#91-页面设置)。以下为要点概要：

- A4 纸张，单面打印
- 页边距：3.14cm(上下)/2.98cm(左右)，仲裁委官方样本实测值
- 页眉距边界 1.27cm（空白），页脚距边界 1.27cm
- 页码底部居中，从正文第1页起编

## 2. 字体字号体系

> 完整字体字号规格详见 [§9.2 DOCX排版规范——字体字号体系](#92-字体字号体系)。以下为要点概要：

- 三档字号递减：标题22pt(二号) → 正文16pt(三号) → 附件14pt(四号)
- 中文：方正小标宋_GBK(标题)/方正黑体简体(标签)/宋体(正文)；数字英文：Times New Roman
- 当事人标签"申请人""被申请人""法定代表人"不加粗；"仲裁请求""事实与理由"加粗
- 字体降级链：方正小标宋_GBK→华文中宋→黑体；方正黑体简体→黑体；宋体→仿宋

## 3. 行间距与段落规范

> 完整行间距与段落规格详见 [§9.3 DOCX排版规范——行间距与段落](#93-行间距与段落)。以下为要点概要：

- 行间距：30pt最小值（仲裁委官方样本实测值）
- 首行缩进：0.93cm（约2字符@16pt）
- 标签→内容间距：无空行（"仲裁请求"标签后直接跟请求项，"事实与理由"标签后直接跟正文）
- 孤行控制：开启

## 4. 数字规范

### 4.1 金额格式

| 规则 | 示例 | 说明 |
|------|------|------|
| 千分位 | 56,000元（非56000元） | 从右往左每三位加逗号 |
| 精确到元 | 42,356元 | 不使用"约""左右" |
| 计算公式嵌入 | 56,000元（8,000元/月×3.5年×2倍） | 括号内附计算过程 |
| 合计行 | 以上合计165,000元 | 所有金钱请求汇总 |
| 中文大写 | 伍万陆仟元整 | 仅在签名/盖章处等特殊位置使用 |

### 4.2 日期格式

| 规则 | 示例 | 说明 |
|------|------|------|
| 年月日 | 2025年1月15日 | 中文格式 |
| 期间 | 2024年11月至2025年1月 | 起止日期 |
| 年限 | 2年7个月 | 工作年限 |

### 4.3 法条引用格式

| 规则 | 示例 | 说明 |
|------|------|------|
| 法律全称+条文 | 《中华人民共和国劳动合同法》第四十八条 | 首次引用全称 |
| 后续简称 | 劳动合同法第四十八条 | 后续可用简称 |
| 条款项 | 第四十八条第二款第(三)项 | 精确到项 |
| **法条引用** | 正文"依照《XX法》第X条之规定"直接引用，不加上标数字标记 | **文书末尾集中列出引用法条的编号+条文全文**（位于签名区之后、附件包之前），条文全文不压缩为要旨概括 |
| 性质标注 | **仅在O2和内部方法论中使用**，O1正文禁止出现 | 授权性/命令性/程序性/证据性为内部方法论标签 |

> **法条引用规则**：正文直接引用法条编号（如"依照《劳动合同法》第四十八条、第八十七条之规定"），不加上标数字标记。引用到的全部法条在**文书末尾**（签名区之后、附件包之前）集中列出编号+条文全文，格式为"N. 《法规全称》第X条：条文全文内容"，每条独立一段，按在正文中出现的先后顺序排列。

### 4.4 百分比

| 规则 | 示例 | 说明 |
|------|------|------|
| 加班费率 | 150%/200%/300% | 劳动法第44条 |
| 加付赔偿金 | 50%~100% | 劳动合同法第85条 |

## 5. 证据清单格式

### 5.0 证据清单格式（单独提交文件）

> ⚠️ **本节格式用于单独提交的证据清单文件，非O1正文内嵌段**。O1申请书不含证据清单段（仲裁委实务中证据清单单独提交，不嵌入申请书正文）。

**O1-ONLY 提交格式**：证据清单仅含证据名称和证明目的，不含任何内部方法论标签。

**O1证据格式**：`证据N：证据名称。证明目的：……`

```
证据一：劳动合同（2022年6月1日签订）。证明目的：证明申请人与被申请人存在劳动关系及工资标准约定
证据二：银行流水（2022年6月至2025年1月）。证明目的：证明工资标准12,000元/月及2024年11月至2025年1月拖欠工资事实
证据三：考勤记录（2022年6月至2025年1月）。证明目的：证明申请人持续提供劳动
证据四：微信聊天记录（与被申请人HR张某，2025年1月15日）。证明目的：证明被申请人以"业务调整"为由口头解除劳动合同（原始载体已保留）
证据五：同事李某证人证言。证明目的：证明申请人工作至解除日
```

**O1违禁标签清单**（出现在O1证据清单即阻断）：
- ❌ 分类标签：`[身份]`/`[事实]`/`[辅助]`
- ❌ 持有人标签：`[申请人]`/`[被申请人]`/`[第三方]`
- ❌ 任何方括号元数据标注

### 5.1 O2 证据清单格式（含内部标注）

> ⚠️ **O2-ONLY 内部格式**：本条格式**仅用于 O2 使用指引（HTML）**，O1 中证据清单不含任何分类标签。以下 `[分类]` `[持有人]` 标签为律师内部方法论元数据，与证据名称本体通过语法标记区分，绝不嵌入O1正文。

**O2证据格式**：`证据N：〔元数据：分类|持有人〕 证据名称（来源），证明目的`

| 要素 | 格式 | 说明 |
|------|------|------|
| 元数据标签 | `〔身份|申请人〕`/`〔事实|被申请人〕`/`〔辅助|第三方〕` | 双花括号区分于证据名称本体，O2专属 |
| 分类 | 身份/事实/辅助 | 三分类 |
| 持有人 | 申请人/被申请人/第三方 | 对申请人持有的证据可省略持有人 |
| 电子证据 | 含来源+原始载体声明 | `（与HR张某，2025.1.15，原始载体已保留）` |

```
证据一：〔身份|申请人〕劳动合同（2022年6月1日签订），证明申请人与被申请人存在劳动关系及工资标准约定
证据二：〔事实|申请人〕银行流水（2022年6月至2025年1月），证明工资标准12,000元/月及2024年11月至2025年1月拖欠工资事实
证据三：〔事实|被申请人〕考勤记录（2022年6月至2025年1月），证明申请人持续提供劳动——该证据由被申请人掌握，应由其提供
证据四：〔事实|申请人〕微信聊天记录（与被申请人HR张某，2025年1月15日），证明被申请人以"业务调整"为由口头解除劳动合同（原始载体已保留）
证据五：〔辅助|申请人〕同事李某证人证言，证明申请人工作至解除日
```

### 5.2 电子证据特殊格式（O2专属）

```
证据X：〔事实|申请人〕微信聊天记录（与[对方姓名+职务]，[日期]），证明[证明目的]（原始载体已保留/已公证）
证据X：〔事实|申请人〕录音记录（[通话双方]，[日期]），证明[证明目的]（附文字整理稿）
证据X：〔事实|申请人〕电子邮件（发件人XXX，收件人XXX，[日期]），证明[证明目的]（已保留原始邮件）
```

### 5.3 O2证据-请求映射矩阵（三线表）

在O2证据分析区中附加映射表（三线表格式）：

| 证据 | 支撑请求 |
|------|---------|
| 证据一 | 请求一、请求三 |
| 证据二 | 请求一、请求二 |
| 证据三 | 请求一 |

## 6. 尾部与附件规范

### 6.1 此致格式

```
此致

北京市海淀区劳动人事争议仲裁委员会
```

- "此致"首行缩进0.93cm（2字符）
- 仲裁委名称左顶格
- 仲裁委名称须与首部完全一致

### 6.2 签名要求

```
                              申请人：王明（签名）

                              二〇XX年XX月XX日
```

- "申请人："首行缩进6.21cm（右偏至页面约1/3处），后留空供手写签名
- 日期首行缩进8.47cm（右偏至页面约2/5处）
- 日期使用中文大写（"〇"不写作"零"）
- 签名与日期间距1行

### 6.3 附件包结构

```
附项：
1. 本申请书副本1份
2. 申请人身份证复印件1份
3. 证据材料副本1份（证据清单另行提交，此处为证据材料复印件）
4. 授权委托书1份（如委托代理人）
```

- 附件说明字号降一档：14pt(四号)，首行缩进0.93cm

### 6.4 份数计算

```
份数 = 被申请人数 + 1（仲裁委留存）
```

- 1个被申请人：正本1份 + 副本1份
- 2个被申请人：正本1份 + 副本2份
- 集体争议（10人以上）：按集体争议规则

### 9.5 签名区

```
                              申请人：___（签名）

                              二〇XX年XX月XX日
```

- "申请人："首行缩进6.21cm（右偏至页面约1/3处），后留空供手写签名
- 日期首行缩进8.47cm（右偏至页面约2/5处）
- 日期使用中文大写（"〇"不写作"零"）
- 签名与日期间距1行

> **缩进值说明**：6.21cm/8.47cm 为仲裁委官方样本实测值，与"右对齐"效果接近但更精确——确保签名区和日期区在视觉上与样本完全一致。

### 9.6 文书末尾法条引用

> **核心规则**：正文直接引用法条编号（如"依照《劳动合同法》第四十八条、第八十七条之规定"），不加上标数字标记。引用到的全部法条在**文书末尾**集中列出编号+条文全文。

- **位置**：签名区之后、附件包之前
- **格式**：`N. 《法规全称》第X条：条文全文内容`，每条独立一段，按正文中出现先后顺序排列
- **字号**：宋体+TNR 14pt（四号），与附件说明同字号
- **行距**：30pt最小值，与正文一致
- **编号**：用数字编号"1. ""2. "等，不使用上标
- **首次引用**：法条全称（如"《中华人民共和国劳动合同法》第四十八条"）
- **后续引用**：在文书末尾列表中也使用全称，保持一致性

**文书末尾法条引用示例**：

```
【法条引用】

1. 《中华人民共和国劳动法》第五十条：工资应当以货币形式按月支付给劳动者本人。不得克扣或者无故拖欠劳动者的工资。

2. 《中华人民共和国劳动合同法》第四十八条：用人单位违反本法规定解除或者终止劳动合同，劳动者要求继续履行劳动合同的，用人单位应当继续履行；劳动者不要求继续履行劳动合同或者劳动合同已经不能继续履行的，用人单位应当依照本法第八十七条规定支付赔偿金。

3. 《中华人民共和国劳动合同法》第八十七条：用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。
```

### 9.7 强调方式

- **允许**：加粗 / 加粗+下划线
- **禁止**：斜体（安理指引：勿使用斜体）
- **禁止**：彩色文字（正式文书）

**必须加粗内容**：
1. 段落标题标签（"仲裁请求""事实与理由"——仅标签文字加粗，内容不加粗）
2. 金额数字（"84,000元"）
3. 计算公式（"（12,000元/月×3.5年×2倍）"）
4. 合计行（"以上合计120,000元"）

**禁止加粗内容**：
- ❌ "申请人""被申请人""法定代表人"标签不加粗（使用方正黑体简体已足够区分，额外加粗反而不符合仲裁委文书样式）
- ❌ 当事人信息内容不加粗
- ❌ 仲裁请求编号"一、""二、""三、"不加粗（仅"仲裁请求"标签加粗，请求编号和内容为宋体正常）
- ❌ "（备位请求）"标注不加粗

- 目录仅列一级标题（仲裁请求/事实与理由等）
- 目录字体：宋体 小四号(12pt)
