# 核心方法论 | 劳动争议仲裁申请书

> 版本: 3.3.0 | 技能隐性知识库

## 1. 七步核心方法论

顶级劳动律师撰写仲裁申请书的七步流程：

### 第一步：诉前评估（不评估不动笔）

| 评估维度 | 核心问题 | 评估产出 |
|---------|---------|---------|
| 管辖策略 | 履行地vs所在地，哪地裁判更有利？ | 推荐管辖地+理由 |
| 时效评估 | 每项请求是否在时效内？ | 时效状态+风险提示 |
| 请求权基础 | 每项诉求的法律依据是否充分？ | 构成要件齐备度 |
| 举证能力 | 哪些证据由我方提供？哪些由对方举证？ | 证据强弱点+补证方向 |

### 第二步：请求策略设计

| 策略 | 说明 | 示例 |
|------|------|------|
| 排列策略 | 确认→给付，主位→备位，金额大→小 | 先确认劳动关系，再主张工资 |
| 主位备位 | 主要请求不被支持时，备位请求作为保底 | 主位2N，备位N |
| 计算公式嵌入 | 仲裁员一眼看清计算依据 | "56,000元（8,000×3.5×2）" |
| 终局裁决策略 | 刻意控制金额在终局范围内 | 限制用人单位起诉权 |
| 请求取舍 | 证据不足的请求果断放弃 | 避免弱请求拖累整体说服力 |

### 第三步：精准叙事

| 技法 | 说明 | 示例 |
|------|------|------|
| 选择性叙事 | 有利事实详述，不利事实简略或不提 | 拖欠工资详细列明，迟到等不主动提及 |
| 因果链构建 | 行为→法律后果→权利受损→请求正当 | "未付报酬→拖欠→权益受损→应支付" |
| 关键节点锚定 | 关键时间点明确标注 | 入职日/满1月日/解除日/申请日 |
| 避免不利自认 | 不主动承认对己方不利的事实 | 用"被申请人主张"替代自认 |
| 叙事融合论证 | ~~法条评价融入对应事实段落，段内完成"事实陈述→法律评价→法律后果"连贯论述~~ **v3.2.0 已简化**：O1只写核心事实+法条引用，不展开法律评价三步论述。仲裁申请书不是代理词，写明能支持请求的基本事实就够了 | "被申请人于2024年12月31日口头通知解除，未出具书面通知。依照劳动合同法第48条、第87条之规定，应支付赔偿金84,000元" |
| 一段一事 | 每个自然段只讲一件事，每件事对应一项仲裁请求。判断标准：段落结论句须指向唯一请求项，涉及跨争议背景事实仅在服务于当前请求项的必要范围内简述。段落之间须有因果递进逻辑衔接（因果/递进/转折），不得写成互不关联的并列"字典式"条目。 | 段一（劳动关系基础）→段二（拖欠工资及催要交涉）→段三（因拖欠引发的违法解除）→段四（未签合同的背景缺陷） |
| 交涉记录必写 | 争议产生后双方的交涉过程必须写清楚，但适用策略性叙事规则——有利交涉详写，不利交涉省略或概括处理（避免与"不利自认"红线冲突）。权重因请求类型而异：拖欠工资★★★★★（恶意要件）>违法解除★★★★（程序合法性）>社保损失★★★>二倍工资★★（核心是客观签约事实）。交涉类型含催要、异议提出、协商过程、投诉举报（构成时效中断） | "12月15日及12月28日两次通过微信向HR催要，HR先后回复'公司没钱'、未予回应" |

### 第四步：严密论证

| 论证方法 | 说明 | 示例 |
|---------|------|------|
| 叙事融合论证 | 事实→法律评价→法律后果连贯论述，不设"大前提""小前提""结论"显式标签 | **v3.2.0 已简化**：O1只写核心事实+法条引用，不展开法律评价三步论述 |
| 结论收束 | ~~末段以"综上所述，本案核心争议在于：…"归纳1-3个核心争议焦点~~ **v3.2.0 已修正**：末段改为结论收束。以"申请人认为"起头做立场宣示+法条归总+标准收束语，不归纳争议焦点（那是O2的工作） | "申请人认为，被申请人在无任何合法依据的情况下单方辞退申请人，且恶意克扣工资，其行为已严重违反了《劳动合同法》第四十八条、第八十七条等相关规定。为维护申请人的合法权益，特向贵委提出仲裁申请，恳请依法予以支持。" |

> **注**："综上所述"本身不禁止——"综上所述，为维护申请人的合法权益，特向贵委提出仲裁申请，恳请依法予以支持"是合法收束语。禁止的是其后接"本案核心争议在于"的O2式争议焦点归纳。
| 举证责任引导 | 在事实陈述中引导仲裁员关注用人单位举证义务 | "解除合法性应由被申请人举证" |
| 法条引用提交标准 | O1正文仅写编号+关键内容，性质标注仅用于O2和内部方法论。引用到的全部法条在文书末尾集中列出编号+条文全文 | O1："依劳动合同法第48条"→文书末尾列条文全文；O2："第48条（授权性）" |
| 规范层级递进 | 按需递进：法律依据充分时仅引法律层级即可，法律依据不够明确或存在争议时逐级向下寻找支撑（法律→行政法规→部门规章→地方性法规）。中间层级无相关规定的，可跳过直接引用下一层级，不硬塞无关法条。地方性法规须标注适用地域。 | "劳动合同法第46条/47条→（如需）实施条例第20条→（如需）[北京市]XX规定" |

### 第五步：系统证据

| 分类 | 说明 | 技法 |
|------|------|------|
| 身份证据 | 证明劳动关系和当事人身份 | 劳动合同/社保记录/工牌 |
| 事实证据 | 证明争议事实 | 工资流水/考勤/解除通知 |
| 辅助证据 | 补强/辅助证明 | 证人证言/录音/微信记录 |
| 证据-请求映射 | 每项请求有证据支撑 | 证据→请求对应表 |

### 第六步：格式零瑕疵（双产物）

| 要点 | O1(DOCX/F-Strict) | O2(HTML/I-Practical) |
|------|------|------|
| 排版标准 | 详见format-spec.md §9 | 详见output-spec.md §9 |
| 字体字号 | 方正小标宋_GBK 22pt(标题)+方正黑体简体 16pt(段标)+宋体+TNR 16pt(正文) | 微软雅黑11pt |
| 金额格式 | 千分位/计算公式嵌入/合计行 | 同O1 |
| 当事人信息 | 送达地址/统一社会信用代码/实际经营地址 | 同O1 |
| 附件包 | 副本份数+身份证明+证据材料副本 | — |
| 证据清单 | **不含**（单独提交） | 含三分类+持有人+映射矩阵 |
| 法条引用 | 文书末尾法条引用 | 含性质标注(命令性/授权性) |
| 内部标注 | **严格禁止** | 完整呈现 |

### 第七步：减少裁判者认知负担

**终极检验标准**：仲裁员只读一遍申请书，能否不看其他材料就直接归纳出争议焦点并逐项审理？

| 维度 | 实现方式 | 说明 |
|------|---------|------|
| 预审理功能 | 时间线自动归位、争议焦点预判、计算过程零歧义 | 申请书已替仲裁员完成庭审调查的事实梳理工作 |
| 因果递进 | 段落之间须有逻辑衔接（因果/递进/转折），非并列"字典式"罗列 | 段1（入职关系）→段2（拖欠工资）→段3（交涉冲突升级）→段4（违法解除激化） |
| 格式统一 | 宋体三号/30pt最小值行距/两端对齐 | 仲裁员阅读不费力 |
| 段落分明 | 一段一事、事与法对应，杜绝交叉混述 | 仲裁员逐项审理时不需回翻查找 |
| 请求有序 | 确认→给付/主位→备位/金额大→小 | 仲裁员按顺序逐项裁决 |
| 法条清晰 | 文书末尾集中列出法条引用+按需层级递进 | 法条引用准确即可，不过度展开 |
| 一切都是为了 | 让仲裁员拿到仲裁申请书就能直接审理，不需回翻查找、不需重新计算、不需自己整理事实脉络 | 这是顶级律师隐性竞争力的本质 |

## 2. 8个易踩坑隐性知识

### 坑1：仲裁时效陷阱

**问题**：以为所有劳动争议都是1年时效
**真相**：
- 一般时效1年，从知道或应当知道权利被侵害之日起算
- 拖欠工资：劳动关系存续期间不受1年限制（调解仲裁法第27条第4款）
- 二倍工资：逐月起算1年时效，非从离职统一起算
- 中断事由：主张权利/对方同意/申请仲裁，中断后重新起算
**正确做法**：P0逐项审查时效状态

### 坑2：请求取舍策略

**问题**：所有能想到的请求都写上
**真相**：
- 证据不足的请求会拖累整体说服力
- 仲裁员对"漫天要价"的申请书信任度降低
- 弱请求可能引发对方强抗辩
**正确做法**：只保留有充分证据和法律依据的请求，弱请求可做备位

### 坑3：地方法规差异

**问题**：用全国统一标准处理所有案件
**真相**：
- 高温津贴金额/月份各地不同
- 加班费是否计入经济补偿金基数各地口径不一
- 二倍工资时效起算规则各地不同
- 病假工资标准各地不同
**正确做法**：标注[需核实当地规定]，建议律师核实

### 坑4：终局裁决策略

**问题**：不知道或不会利用终局裁决
**真相**：
- 终局裁决下用人单位不可起诉，劳动者可起诉
- 追索劳动报酬≤当地月最低工资×12个月即为终局
- 可刻意拆分请求使核心请求适用终局裁决
**正确做法**：P3评估终局裁决策略可行性

### 坑5：举证责任倒置领域刻意引导

**问题**：不知道哪些事项由用人单位举证，自己费力收集本不需收集的证据
**真相**：
- 解除合法性→用人单位举证
- 减少报酬→用人单位举证
- 计算工作年限→用人单位举证
- 2年内考勤→用人单位提供
**正确做法**：在事实与理由中主动提出"该项事实应由被申请人举证"，引导仲裁员要求用人单位举证

### 坑6：计算基数之争（应发工资vs实发工资）

**问题**：用扣除社保公积金后的实发工资计算经济补偿金
**真相**：
- 经济补偿金基数=应发工资（税前），包括计时/计件工资、奖金、津贴、补贴等
- 加班费是否计入基数各地口径不一
- 超过3倍社平工资部分应封顶
**正确做法**：明确标注"月工资标准为应发工资"，在公式中体现

### 坑7：二倍工资时效特殊规则

**问题**：认为二倍工资从离职起统一算1年时效
**真相**：
- 二倍工资差额按月独立计算时效
- 每月的差额从应付之日起算1年
- 如入职2年后才申请仲裁，前期月份的二倍工资差额可能已超时效
**正确做法**：P0逐月审查时效，仅主张未超时效月份

### 坑8：管辖选择策略

**问题**：随便选一个管辖地
**真相**：
- 履行地和所在地可能有不同的裁判口径
- 某地可能对劳动者更有利（如更支持加班费主张）
- 选择管辖地也影响举证便利和交通成本
**正确做法**：P0比较两地裁判倾向，推荐对申请人有利的管辖地

### 坑9：遗漏交涉记录

**问题**：直接从争议事实跳到仲裁请求，略过双方交涉过程
**真相**：
- 交涉记录是仲裁员判断用人单位是否存在恶意的关键依据
- 缺交涉记录 = 仲裁员无法判断"申请人是否曾寻求协商解决"
- 交涉及对方的回应（或沉默）直接影响案件说服力
- **交叉联动坑5（举证责任倒置）**：在违法解除案件中，交涉记录证明了"用人单位作出了解除决定"，此时举证责任才转移给用人单位（解释(一)第44条）——交涉记录是触发举证责任倒置的关键事实纽带
**正确做法**：在"争议事实"段落末尾必写交涉过程，含时间、方式、对方回应。但适用策略性叙事规则——有利交涉详写，不利交涉省略或概括处理（避免与"不利自认"红线冲突）

### 坑10：O1内部标注外泄

**问题**：在提交仲裁委的申请书中出现内部方法论标注
**真相**：
- 仲裁委提交文书必须干净——无法条性质标注、无证据分类标签、无分析框架标签
- 法条性质标注（授权性/命令性等）属于律师内部方法论，不应出现在呈堂物中
- 证据三分类标注〔身份〕〔事实〕〔辅助〕属于律师工作方法论，仲裁委不认可
- 证据-请求映射矩阵属于律师办案工具，不应嵌入申请书
**正确做法**：O1(DOCX)严格干净——仅含申请书正文（七段式），所有内部标注归入O2(HTML)使用指引

## 4. 常见错误类型库

| 错误类型 | 表现 | 后果 | 防范 |
|---------|------|------|------|
| 金额模糊 | "约3万元""3万元左右" | 仲裁委要求补正/不受理 | 逐项精确到元 |
| 法条编号错误 | 引用不存在的条文 | 严重影响专业形象 | 联网核实 |
| 不利自认 | "我虽然迟到..." | 对方直接引用 | RC-07检查 |
| 基数错误 | 用实发工资计算 | 金额偏低/仲裁委不采信 | RC-08检查 |
| 时效遗漏 | 未审查时效 | 部分请求被驳回 | P0时效评估 |
| 遗漏交涉记录 | 直接从争议跳到请求 | 仲裁员无法判断恶意程度，削弱说服力 | P2必写交涉过程 |
| 送达地址缺失 | 只写住址 | 仲裁委送达困难 | 专列送达地址 |
| 计算公式缺失 | 只写金额 | 仲裁员无法核对 | 公式嵌入请求项 |
| 证据不足请求 | 证据支撑不了的请求 | 拖累整体说服力 | 请求取舍策略 |
| 分析框架残留 | O1正文含[策略]标签 | 不专业，仲裁委不认可 | O1/O2双格式严格隔离 |
| 术语不当 | 使用"开除""辞退" | 不符合法律用语 | 术语对照表 |
| 段落混述 | 同一段落讲多个争议 | 仲裁员难以逐项审理 | 一段一事 |
