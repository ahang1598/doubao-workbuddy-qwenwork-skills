|:---|:---|:---|:---|
| ≤20人 | 否 | 精简版 | 3 |

## 按规模推荐的模块组合

```
企业规模
├── ≤20人（初创型）
│   ├── 必选：员工手册 + 考勤休假 + 薪酬绩效（3模块）
│   ├── 按需：劳动合同管理要点（如有HR专人）
│   └── 暂不生成：特殊用工管理 / 保密与竞业限制（融入员工手册）
├── 20-200人（中型）
│   ├── 必选：7模块全量
│   └── 可选：反性骚扰制度（如有女职工较多）
└── 200人+（大型）
    ├── 必选：7模块深化
    └── 可选扩展（按需选择）：
        ├── 反性骚扰制度（民法典第1010条+妇女权益保障法）
        ├── 个人信息保护制度（个保法+员工信息收集/使用/存储/删除）
        ├── 远程办公/混合办公管理制度
        ├── 数据安全制度（科技互联网行业必需）
        └── 外籍员工管理制度（外企场景）
```

## 按行业推荐的必选模块

| 行业 | 除7模块外额外推荐 |
|:---|:---|
| **物业管理** | 特殊用工管理（外包管理深度）+ 安全管理制度（物业专项安全） |
| **制造业** | 考勤休假（倒班制/综合工时深度）+ 安全管理制度（生产安全） |
| **餐饮服务** | 考勤休假（排班密集期）+ 薪酬绩效（计件工资） |
| **科技互联网** | 保密与竞业限制（知识产权归属）+ 个人信息保护制度 + 数据安全制度 + 远程办公管理 |
| **建筑施工** | 特殊用工管理（项目制用工/农民工工资专户）+ 安全管理制度（安全生产） |
| **医疗** | 特殊用工管理（执业资质/多点执业）+ 安全管理制度（传染病防控） |

## 精简版模块速配（≤20人）

```
精简版制度包（3模块）：
├── 01_员工手册.docx（精简版，5章）
│   ├── 第一章 总则
│   ├── 第二章 招聘与录用
│   ├── 第三章 考勤与休假（要点）——含年假/产假/病假天数，不引专项制度
│   ├── 第四章 薪酬与福利（要点）——含加班费基数约定和最低工资标准
│   ├── 第五章 行为规范与附则——含保密义务简述+申诉渠道+制度位阶
│   └── 附录：配套表单（精简）
├── 02_考勤与休假制度.docx（标准深度）
│   ├── 标准工时/加班管理/假期申请与审批流程
│   └── 行业专项按需注入
├── 03_薪酬与绩效制度.docx（标准深度）
│   ├── 薪酬结构/工资支付/绩效考核/福利
│   └── 行业专项按需注入
└── 附录_配套表单合集.docx（精简）
```

## 完整版模块速配（200人+）

在标准版7模块基础上深化+按需扩展：

**7模块深化要点**：
- 员工手册：增加分支机构/多岗位适配章节
- 特殊用工管理：增加外籍员工管理、跨区用工管理
- 奖惩制度：增加累计处分升级机制、处分记录消除规则
- 薪酬绩效：增加多岗位薪酬带宽、股权激励交叉条款

**可选扩展模块**（按行业/企业特征加载）：

| 扩展模块 | 加载条件 | 核心内容 |
|:---|:---|:---|
| 反性骚扰制度 | 女职工≥30% / 医疗/餐饮/服务业 | 性骚扰定义+举报渠道+调查程序+处罚+保护举报人 |
| 个人信息保护 | 科技互联网/医疗/物业（有业主信息） | 员工信息收集范围+使用目的+存储期限+删除权+跨区传输 |
| 远程办公管理 | 科技互联网/外企/疫情后常态 | 远程办公申请条件+工作成果考核+信息安全+费用承担 |
| 数据安全制度 | 科技互联网/SaaS企业 | 数据分级管理+访问权限+安全事件响应+员工安全培训 |
| 外籍员工管理 | 外企/有外籍员工 | 工作许可证管理+签证合规+劳动法适用+税收 |

## 特殊场景模块推荐

| 场景 | 模块调整 |
|:---|:---|
| 纯自聘（无派遣/外包） | 特殊用工管理→简化为"非标准劳动关系管理要点"（退休返聘+实习），不生成完整派遣/外包章节 |
| 外企 | 员工手册增加中英双语对照说明 / 可选"外籍员工管理制度" / 地方标准数据匹配注册地（非总部所在地） |
| 集团/多分支机构 | 员工手册增加"适用范围与分支机构"章节 / 各分支机构的地区差异标注 / 特殊用工管理增加"跨区用工管理" |
| 有工会的企业 | 民主程序模板中增加"工会协商函"+"工会回复意见书" / 奖惩制度中增加"工会委员参与处分听证" |
| 拟上市企业 | 制度中增加"内控合规"相关条款 / O3 风险矩阵按上市尽调标准扩展 |

## 决策流程

```
Phase 1 执行流程：
1. 读取企业规模 → 确定复杂度阶梯
2. 读取行业类型 → 确定行业必选模块
3. 读取用工模式 → 确定特殊用工管理深度
4. 读取特殊场景标记（外企/集团/拟上市） → 确定扩展模块
5. 展示推荐模块清单 → 等待律师确认或调整
6. 确认后 → 进入 Phase 2 结构规划
```
