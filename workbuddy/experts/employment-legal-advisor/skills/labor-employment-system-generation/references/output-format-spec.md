## §内容规格

### Mode A 起草输出结构

制度文件包固定**3个输出块**（O1 + O2 + O3），每次生成都必须包含：

```
O1 制度文件包（DOCX）
  ├── 01_员工手册.docx（全员签收）
  │   ├── 封面（公司全称+制度名称+版本/日期+保密声明）
  │   ├── 目录
  │   └── 正文（章→条→款→项→目五层序号体系）
  ├── 02_劳动合同管理要点.docx（HR专用）
  ├── 03_考勤与休假制度.docx（部门传达）
  ├── 04_薪酬与绩效制度.docx（部门传达）
  ├── 05_奖惩制度.docx（全员签收）
  ├── 06_特殊用工管理.docx（HR专用）
  ├── 07_保密与竞业限制.docx（涉密岗位签收）
  ├── 附录_配套表单合集.docx（HR调用）
  ├── 附录_民主程序模板.docx（程序归档）
  └── 制度颁布通知.docx

O2 风险提示清单（MD）
  ├── 模块风险标注汇总（按L1/L2/L3分组）
  ├── 法条来源标注（[来源:检索 | 检索工具:xxx | 检索时间:YYYY-MM-DD]）
  ├── 地方标准数据引用清单（含数据时效提示）
  ├── 待客户确认事项清单
  ├── 待律师复核事项清单
  ├── 制度颁布后30天操作清单
  └── 核验链接（可点击URL参照）

O3 风险矩阵（MD）
  ├── 风险类型×严重度×影响模块矩阵表
  ├── 每类风险≥1个案例锚定（案例名称+案号+裁判要旨+对制度设计的启示）
  ├── 行业高频风险标识
  └── 地方裁判口径差异提示
```

### Mode B 审查优化输出结构

```
O1 审查意见（MD）
  ├── 审查概览（审查对象/范围/日期/方法）
  ├── 变更对比清单（表格：原条文→修改建议→理由+法条依据+严重度）
  ├── 过期法规清单（失效法规+替代法规）
  ├── 缺失模块清单（对照行业标准）
  ├── 程序正义缺陷清单
  ├── 负面清单违规标记
  └── 综合审查结论与优先修复顺序

O2 优化后制度文件（DOCX）
  ├── 包含修订标记的优化后全文
  ├── 修订说明页（修订依据/修订要点/修订日期）
  └── 优化后制度文件（清洁版，可选）
```

### 模式与输出对照表

| 模式 | O1 格式 | O2 格式 | O3 格式 | 适用场景 |
|:---|:---|:---|:---|:---|
| Mode A 精简版 | DOCX（3制度+2附录） | MD | MD（精简矩阵） | 初创≤20人 |
| Mode A 标准版 | DOCX（7制度+2附录） | MD | MD | 20-200人 |
| Mode A 完整版 | DOCX（7制度深化+2附录+扩展模块） | MD | MD（完整矩阵+案例） | 200人+ |
| Mode B 审查 | MD（审查意见） | DOCX（优化后制度） | — | 制度合规审查 |

### 输出层注释规则

| 注释类型 | 规则 | 示例 |
|:---|:---|:---|
| 行业专项注入 | `[XX行业]` 标记 + 解释原因 | `[制造业] 增加倒班制/职业病防护条款——参见industry-specs.md §manufacturing` |
| 地区特殊规则 | `[XX地区]` 标记 + 引用依据 | `[深圳地区] 加班费基数约定：深圳中院（2019）裁判口径支持以基本工资为基数` |
| 待确认参数 | `{参数名}` 占位 | `{董事会人数}` `{竞业限制补偿月数}` |
| 风险标注 | L1/L2/L3 标注 | `[L1] 综合计算工时制未经审批→视为标准工时` |
| 法条引用核实 | 标注核实状态 | `[高确信·已核实]` `[⚠️未联网核验，建议律师确认]` |

### 写作约束

| 约束 | 说明 |
|:---|:---|
| 法条引用禁止模糊化 | 不可写"依据劳动法相关规定"，必须标注具体条文编号 |
| 待确认参数显式标注 | 企业未提供的参数用 `{参数名}` 占位，不可凭空编造 |
| 不可写"保证合规" | 制度文件是内部管理文件，民主程序完成前不具效力 |
| 禁止emoji | 所有输出格式（MD/DOCX）一律不使用emoji（L1/L2/L3标注除外） |
| O1正文清洁无工作标注 | O1制度文件正文不出现 `[来源:检索\|...]` / `[注]` 等律师工作记录 |
| O2核验链接完整 | O2风险提示清单须包含所有联网检索的法条来源标注 |
| 模块间交叉引用格式 | "详见《XX文件》第X章第X条"（不引用页码，因排版后页码变化） |
| 配套表单不编号 | 表单不作为制度正文的第X条，表单编号与制度条款编号分属不同体系 |

### SOFT_DEGRADED 降级产物结构

当触发 SOFT_DEGRADED 降级时，输出以下最小骨架：

```markdown
[SOFT_DEGRADED] 缺失信息：{列出缺失项}

## C块：待补充信息清单

| # | 缺失参数 | 影响的输出部分 | 补充后升级方式 |
|:---:|:---|:---|:---|
| 1 | 企业注册地 | 无法匹配地方性标准数据（最低工资/高温津贴/产假天数） | 提供注册城市→重新执行Phase 0 |
| 2 | 企业规模 | 无法确定制度复杂度（精简/标准/完整版） | 提供员工人数→重新执行Phase 2 |

## D块：法律底线摘要

- 劳动合同法（2012修正）为法律基线
- 不得写入的条款（负面清单关键项）：迟到罚款/剥夺法定假期/低于最低工资...
- {根据已知信息列出适用的法律底线}
- {根据已知信息标注不适用的模块}

## G块：下一步行动

1. 提供{缺失参数1}→可匹配地方标准数据
2. 提供{缺失参数2}→可确定制度颗粒度
3. 确认行业类型→可加载行业专项注入表
4. 确认用工模式→可确定特殊用工管理模块深度
5. 如有现有制度文本→可切换为Mode B审查优化
```

## §交付规格

### format_capabilities（§17.18 视觉输出标准契约）

| 能力 | 说明 |
|:---|:---|
| 输出格式 | Markdown（会话内预览）→ DOCX（主交付物）→ PDF（可选） |
| HTML转换 | 支持 HTML→DOCX/PDF 转换路线（预留） |
| 排版严肃度 | O1（制度文件）= C-Professional（正式公文级，可直接打印交付企业）/ O2（风险提示）= I-Practical（实务参考级）/ O3（风险矩阵）= I-Practical（实务参考级） |
| 打印适配 | A4纵向，页边距兼容主流打印机，表格不跨页 |
| CSS模板 | 预留 `templates/docx-style.css`（当前不使用，声明能力预留） |
| 最低要求 | 即使降级，也须保持DOCX页面布局 + 五层序号体系 + FS2字体字号 |
| 不允许的形式 | PDF（仅当用户明确要求时转换，不主动生成） |

### default_output

| 输出块 | 格式 | 严肃度 | 说明 |
|:---|:---|:---|:---|
| **O1** 制度文件包 | DOCX（主）/ MD（辅） | C-Professional | 封面+目录+正文+配套表单+民主程序模板+保密声明 |
| **O2** 风险提示清单 | MD | I-Practical | 风险标注汇总+法条来源+待核事项+30天操作清单+核验链接 |
| **O3** 风险矩阵 | MD | I-Practical | 风险类型×严重度矩阵+案例锚定+地方裁判口径提示 |

### 产物复用关系（§17.25 产物复用契约）

| 输出产物 | 复用的中间产物 | 复用方式 |
|:---|:---|:---|
| O1 制度文件包 | P3 逐模块填充草稿 | O1 = P4精修后的P3草稿（法条核验+红线校对+交叉一致性校验），禁止从零重新生成 |
| O2 风险提示清单 | P0 输入解析（缺失参数清单） | 直接复用P0的gap_score和缺失参数清单，转为"待确认"提示 |
| O2 风险提示清单 | P4 法律核验结果 | 直接复用P4的核验未通过项和法条来源标注 |
| O3 风险矩阵 | P4 风险标注汇总 + case-anchors.md | 汇总P4所有风险标注点，按类型×严重度矩阵排列，嵌入案例锚定 |
| Mode B O1 审查意见 | 步骤B3 变更清单 | 直接复用B3的变更对比清单，格式化输出 |

> **禁止**：O2/O3 中不得重新分析已在 P0/P2/P3/P4 中完成的工作。

### FS2 覆盖项

| 覆盖项 | FS2默认值 | 覆盖为 | 理由 |
|:---|:---|:---|:---|
| 封面布局 | 律所logo+标题居中+署名底部 | **公司全称顶部居中+制度名称中部居中+版本/日期底部居中** | 制度文件是公司内部文件 |
| 签署页 | 律所盖章位 | **员工签收确认书+民主程序记录** | 制度文件的"生效"是员工签收+民主程序 |
| 保密声明 | "本文档为律所向客户交付的保密文件" | "本制度为公司内部管理文件，未经公司书面许可，不得对外提供" | 内部制度文件 |
| 正文标题 | 黑体小三/四号 | **黑体三号加粗（章标题）+ 黑体四号加粗（条标题）+ 宋体小四（正文）** | 制度文件标题须正式 |
| 交付文件夹 | 单文件DOCX | **文件夹（7制度+2附录+通知，共10个独立DOCX）** | 不同受众签收不同文件 |

**不使用FS2的以下内容**：
- ❌ 律所简介/团队介绍页 — 制度文件不需要
- ❌ 计费说明 — 非报价文件
- ❌ 委托代理关系声明 — 制度文件非委托合同

### delivery_formats

| 格式 | 用途 | 优先级 |
|:---|:---|:---|
| **DOCX** | 主交付物（打印/签收/归档/印用） | ⭐⭐⭐ 必出 |
| **MD** | 辅交付物（律师编辑复核副本/对话内预览/风险提示/风险矩阵） | ⭐⭐ 必出 |
| PDF | 归档版（可选，用户说"导出PDF"时生成） | ⭐ 可选 |

## §A DOCX 排版规范

### A1 封面

```
页面1（封面页），独占Section1:
  顶部: {公司全称}（居中，黑体 二号 加粗）
  中部偏上（距顶部约1/3页高）: XX公司劳动用工制度体系（居中，黑体 小初号 加粗）
  底部（距标题≥8行空白间距后）:
    版本：V{X.X}（居中，宋体 小三）
    颁布日期：____年__月__日（居中，宋体 小三）
  禁止:
    - 封面页显示页码、页眉
    - 版本信息紧贴标题（须≥8行间距）
    - 封面出现"起草依据""律师姓名"等内部工作记录
```

### A2 页面设置

| 项目 | 设置 |
|:---|:---|
| 纸张大小 | A4（210mm × 297mm） |
| 上边距 | 2.54cm |
| 下边距 | 2.54cm |
| 左边距 | 3.17cm（预留装订空间） |
| 右边距 | 2.54cm |

### A3 字体字号体系

| 层级 | 字体 | 字号 | 加粗 | 对齐 |
|:---|:---|:---|:---|:---|
| 封面标题 | 黑体 | 二号（22pt） | ✅ | 居中 |
| 封面制度名称 | 黑体 | 小初号（36pt） | ✅ | 居中 |
| 封面副标题 | 宋体 | 小三（15pt） | ❌ | 居中 |
| 一级标题（章） | 黑体 | 三号（16pt） | ✅ | 居中 |
| 二级标题（条） | 黑体 | 四号（14pt） | ✅（"第X条"部分） | 左对齐 |
| 正文 | 宋体 | 小四（12pt） | ❌ | 两端对齐，首行缩进2字符 |
| 表格内容 | 宋体 | 五号（10.5pt） | ❌ | 左对齐（数字右对齐） |
| 页眉 | 宋体 | 小五（9pt） | ❌ | 居中 |
| 页脚（页码） | 宋体 | 小五（9pt） | ❌ | 居中 |

### A4 段落格式

| 项目 | 设置 |
|:---|:---|
| 行距 | 1.5倍行距（正文） |
| 段前间距 | 0行（正文）/ 0.5行（标题） |
| 段后间距 | 0行（正文）/ 0.5行（标题） |
| 首行缩进 | 2字符（正文段落） |
| 对齐方式 | 标题居中 / 正文两端对齐 |

### A5 标题编号体系（五层层级）

```
第X章 标题（一级，章，黑体三号加粗居中）
  第X条 标题（二级，条，黑体四号加粗左对齐，全文连续编号，跨章不重置）
    款（三级，自然段，宋体小四缩进2字符，不加序号）
      （一）项（四级，中文括号+中文数字，宋体小四缩进2字符，每项独立成行）
        1. 目（五级，阿拉伯数字+半角句点，宋体小四缩进4字符，每日独立成行）
```

### A6 表格规范

| 项目 | 设置 |
|:---|:---|
| 表头行 | 宋体五号加粗，浅灰底色（RGB 240,240,240） |
| 表体行 | 宋体五号，白色底色，斑马条交替可选 |
| 边框 | 0.5pt 实线，黑色 |
| 对齐 | 表头居中，表体左对齐（数字列右对齐） |
| 单元格边距 | 上下0.1cm，左右0.2cm |

### A7 页眉页脚

- **封面页（Section1）**：无页眉、无页码
- **正文页（Section2起）**：
  - 页眉：公司名称（左）+ 制度名称（右），宋体小五
  - 页脚：页码居中，格式"第X页 / 共Y页"（从正文第1页起计为"第1页"）

### A8 风险标注样式

| 等级 | 颜色 | 格式 |
|:---|:---|:---|
| L1 高风险 | 红色文字 (RGB 192,0,0) | 加粗 + 底色浅红(RGB 255,230,230) |
| L2 中风险 | 橙色文字 (RGB 191,127,0) | 加粗 + 底色浅黄(RGB 255,245,220) |
| L3 低风险 | 深灰文字 (RGB 102,102,102) | 底色浅灰(RGB 245,245,245) |

### A9 降级输出

如当前工具不支持 docx 格式生成，以 Markdown 格式输出完整内容，保留标题层级、表格结构和风险标注标识（L1/L2/L3），便于律师后续导入 Word 排版。
