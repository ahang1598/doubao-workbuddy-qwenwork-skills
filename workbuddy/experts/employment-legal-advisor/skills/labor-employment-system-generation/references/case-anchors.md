## C-1：员工手册未经民主程序

| 项 | 内容 |
|:---|:---|
| **案例来源** | 深圳中院(2020)粤03民终XX号（典型裁判口径） |
| **事实摘要** | 公司以员工"严重违反规章制度"为由单方解除劳动合同。该规章制度未经职代会讨论，也未与工会协商。 |
| **裁判要旨** | 用人单位制定的规章制度未经民主程序，在劳动争议中不予采信。以该制度为依据作出的解除决定被认定为违法解除，判令公司支付赔偿金。 |
| **对制度设计的启示** | 所有制度文件中必须嵌入民主程序条款（总则/附则）；交付时必须配套民主程序模板（职代会通知/签到表/会议记录/工会协商函）。三大生效要件缺一不可。 |
| **关联红线** | 红线8（民主程序与公示签收） |

## C-2：加班费基数约定不明

| 项 | 内容 |
|:---|:---|
| **案例来源** | 北京三中院(2019)京03民终XX号（典型裁判口径） |
| **事实摘要** | 劳动合同约定"加班费按基本工资计算"，但未明确基本工资数额。实际每月发放的工资由基本工资+岗位工资+绩效+补贴构成。员工主张以全部实发工资为加班费基数。 |
| **裁判要旨** | 劳动合同中加班费基数约定不明确，法院以劳动者实发工资总额为加班费计算基数，判令公司补足差额。 |
| **对制度设计的启示** | 加班费计算基数必须在劳动合同中明确约定具体数值或明确的计算方式（"以基本工资XX元/月为基数"），不得模糊表述。薪酬制度中须与此保持一致。 |
| **关联红线** | 红线1（最低工资底线） |
| **地区差异** | 深圳：支持以约定的基本工资为基数 / 北京：倾向于以全部工资为基数 / 上海：有约定从约定 |

## C-3：末位淘汰=违法解除

| 项 | 内容 |
|:---|:---|
| **案例来源** | 最高人民法院指导案例18号：中兴通讯（杭州）有限责任公司诉王鹏劳动合同纠纷案 |
| **事实摘要** | 公司以员工连续两次考核排名末位、不能胜任工作为由解除劳动合同。 |
| **裁判要旨** | 劳动者在用人单位等级考核中居于末位等次，不等同于"不能胜任工作"，不符合单方解除劳动合同的法定条件。末位淘汰直接解除劳动合同属于违法解除。 |
| **对制度设计的启示** | 制度中绝对不能出现"末位淘汰"表述。如要设计绩效管理退出机制，必须严格按"不胜任→培训或调岗→仍不胜任→解除"的法定路径，且须保留培训记录和调岗后考核记录。 |
| **关联红线** | 红线6（解除劳动合同法定程序） |

## C-4：迟到罚款无效

| 项 | 内容 |
|:---|:---|
| **案例来源** | 广东高院(2019)粤民申XX号（典型裁判口径） |
| **事实摘要** | 公司制度规定"迟到一次罚款50元"，员工被累计罚款800余元后申请劳动仲裁。 |
| **裁判要旨** | 罚款属于行政处罚措施，企业不具有罚款权。公司制度中"迟到罚款"的条款无效，公司须返还已扣罚款。 |
| **对制度设计的启示** | 迟到管理只能通过绩效扣分/取消全勤奖/与绩效工资挂钩等非罚款方式实现。惩罚制度中不能出现"罚款"二字。 |
| **关联负面清单** | NL-1（迟到罚款条款） |

## C-5：竞业限制全员化无效

| 项 | 内容 |
|:---|:---|
| **案例来源** | 上海一中院(2021)沪01民终XX号（典型裁判口径） |
| **事实摘要** | 公司要求全体200余名员工签署竞业限制协议，包括前台、保洁等不接触商业秘密的岗位。某离职员工起诉主张竞业限制条款无效。 |
| **裁判要旨** | 竞业限制仅适用于高级管理人员、高级技术人员和其他负有保密义务的人员。对前述范围以外的人员约定竞业限制的，该约定无效。 |
| **对制度设计的启示** | 竞业限制协议不能全员签署。须建立涉密岗位清单，仅对清单内岗位签署竞业限制协议。保密义务（法定义务）与竞业限制义务（约定义务）须分开处理。 |
| **关联红线** | 红线6 / 关联负面清单 NL-6 |

## C-6：假外包真派遣

| 项 | 内容 |
|:---|:---|
| **案例来源** | 广东省高院(2018)粤民再XX号（典型裁判口径） |
| **事实摘要** | 物业公司与第三方签订"保安服务外包合同"，但实际管理中物业公司直接对外包保安排班、考勤、奖惩和发放工资。保安申请劳动仲裁，主张与物业公司存在事实劳动关系。 |
| **裁判要旨** | 名为外包实为派遣——用人单位对外包人员进行直接的劳动管理（排班/考勤/奖惩/工资发放），应认定为劳务派遣关系。物业公司须对派遣超比例（>10%）和超岗位（非三性岗位）承担连带责任。 |
| **对制度设计的启示** | 外包管理制度中必须明确外包商自主管理的边界，物业管理方只能提服务标准建议和成果检查，不能直接排班/考勤/奖惩。特殊用工管理模块须重点是"管理边界条款"。 |
| **关联红线** | 红线6 |

## C-7：综合工时制未经审批

| 项 | 内容 |
|:---|:---|
| **案例来源** | 各地劳动仲裁裁决（高频争议类型） |
| **事实摘要** | 公司与保安在劳动合同中约定"实行综合计算工时制"，但该工时制度未经劳动行政部门审批。保安离职后主张全部超出标准工时的部分为加班，要求支付加班费。 |
| **裁判要旨** | 综合计算工时制须经劳动行政部门审批。仅劳动合同约定而未经审批的，视为标准工时制。超出标准工时的部分按加班处理，须支付加班费。 |
| **对制度设计的启示** | 考勤休假制度中涉及综合计算工时制的条款必须标注"须经劳动行政部门审批，审批文号:_____"，并预留审批文号填写位。附配套审批流程指引。 |
| **关联红线** | 红线2（法定工时与加班上限） |

## C-8：严重违纪未量化定义

| 项 | 内容 |
|:---|:---|
| **案例来源** | 全国多地中院判决（高频争议类型） |
| **事实摘要** | 公司以员工"严重违反规章制度"为由解除劳动合同，但制度中"严重违纪"的定义为"给公司造成重大损失"等模糊表述，无具体金额标准。 |
| **裁判要旨** | "严重违纪""重大损失"等关键概念未量化定义的，法院不予采信。公司依据模糊条款作出的解除决定被认定为违法解除。 |
| **对制度设计的启示** | 所有涉及"严重""重大""情节严重"的条款必须有量化标准："严重损失指直接经济损失XX元以上""连续旷工X日或年累计X日""盗窃财物价值X元以上"等。不得使用不可量化的形容词。 |
| **关联红线** | 红线6 + 语言规范 |

## C-9：单方解除未通知工会

| 项 | 内容 |
|:---|:---|
| **案例来源** | 全国多起劳动争议判决 |
| **事实摘要** | 公司以严重违纪为由单方解除员工劳动合同，未事先将理由通知工会。员工起诉主张解除程序违法。 |
| **裁判要旨** | 用人单位单方解除劳动合同，应当事先将理由通知工会（劳动合同法第43条）。未通知工会的，即使实体合法，程序仍违法，须支付赔偿金。 |
| **对制度设计的启示** | 惩罚制度中解除劳动合同的程序条款必须完整覆盖"通知工会"环节。配套表单中须包含"工会意见书"模板。未建工会的单位须通知上级工会或当地总工会。 |
| **关联红线** | 红线6（解除程序三环节：通知申辩→工会意见→决定送达） |

## C-10：试用期超期

| 项 | 内容 |
|:---|:---|
| **案例来源** | 多地劳动仲裁裁决 |
| **事实摘要** | 公司与员工签订2年期劳动合同，约定试用期3个月。试用期结束后员工主张试用期超期1个月，要求支付赔偿。 |
| **裁判要旨** | 合同期1年≤T<3年的，试用期≤2个月。约定3个月试用期→超期部分按转正后工资支付赔偿（劳动合同法第83条）。 |
| **对制度设计的启示** | 劳动合同管理要点和员工手册中必须嵌入试用期上限对照表。所有涉及试用期的条款须与合同期限自动关联校验。 |
| **关联红线** | 红线4（试用期法定上限） |

## C-11：保密与竞业限制混同争议

| 项 | 内容 |
|:---|:---|
| **案例来源** | 多地劳动争议裁判（典型争议类型） |
| **事实摘要** | 公司要求全体员工签署《保密与竞业限制协议》，协议中约定"离职后2年内不得从事本行业工作"，但未约定竞业限制补偿。员工离职后主张竞业限制条款无效。 |
| **裁判要旨** | 保密是法定义务无需补偿，竞业限制是约定义务必须补偿。未约定竞业限制补偿的，竞业限制条款可能被认定为无效。混同签收还可能导致：员工主张签署时对"竞业限制义务"不知情。 |
| **对制度设计的启示** | 保密条款融入员工手册行为规范章（法定义务，不需补偿）+ 劳动合同保密条款。竞业限制独立为劳动合同附件，单独签署，明确人员范围+地域范围+行业范围+补偿标准。 |
| **关联** | 方法论 §六（保密与竞业限制区分规则） |

## C-12：工伤期按病假发薪

| 项 | 内容 |
|:---|:---|
| **案例来源** | 各地劳动争议裁决 |
| **事实摘要** | 员工因工受伤，停工留薪期间公司按病假工资标准发放。员工申请劳动仲裁，主张停工留薪期待遇不变。 |
| **裁判要旨** | 停工留薪期内，原工资福利待遇不变，由所在单位按月支付（工伤保险条例第33条）。按病假工资标准发放违法，须补足差额。 |
| **对制度设计的启示** | 薪酬制度/考勤休假制度中涉及工伤期待遇的条款必须写明"停工留薪期内原工资福利待遇不变，由公司按月支付"，不得写"按病假工资发放"。 |
| **关联负面清单** | NL-3（工伤期待遇缩减条款） |

## C-13：处分无申辩期

| 项 | 内容 |
|:---|:---|
| **案例来源** | 各地劳动争议裁判（程序瑕疵高频类型） |
| **事实摘要** | 公司发现员工违纪事实后，直接出具处分通知，未给予员工陈述和申辩的机会。员工在仲裁中主张处分程序违法。 |
| **裁判要旨** | 用人单位作出处分决定前，应给予员工陈述和申辩的机会。未给予申辩机会直接处分的，构成程序瑕疵，处分决定可被撤销。 |
| **对制度设计的启示** | 惩罚制度中处分程序四环节缺一不可——调查取证→通知与申辩（≥3个工作日）→工会意见→决定与送达。配套表单中须包含"违纪事实调查笔录""员工申辩记录"模板。 |
| **关联** | 方法论 §五（程序正义完整框架） |

## C-14：入职登记表替代劳动合同

| 项 | 内容 |
|:---|:---|
| **案例来源** | 全国多地劳动争议裁判 |
| **事实摘要** | 公司仅让员工填写入职登记表，未签订书面劳动合同。员工离职后主张二倍工资差额。 |
| **裁判要旨** | 入职登记表不具备劳动合同的必备条款（合同期限/工作内容/工作地点/劳动报酬/社保等），不视为已签订书面劳动合同。公司须支付二倍工资差额。 |
| **对制度设计的启示** | 劳动合同管理要点中必须明确"入职登记表不是劳动合同的替代品"，合同签订时限"入职当天签订，最迟不超过30天"。 |
| **关联红线** | 红线5（劳动合同签订强制义务） |

## C-15：年假按本单位工龄计算

| 项 | 内容 |
|:---|:---|
| **案例来源** | 全国多地劳动争议裁决 |
| **事实摘要** | 公司制度规定"在本公司连续工作满1年的，享受带薪年休假5天"。某员工此前在其他单位已工作8年，入职本公司仅6个月即申请10天年假被拒。 |
| **裁判要旨** | 带薪年休假按累计工作年限计算，不限于本单位工作年限（职工带薪年休假条例第3条）。公司以"本单位工龄"替代"累计工龄"的规定侵害员工法定权利。 |
| **对制度设计的启示** | 员工手册/考勤休假制度中年假条款必须写明"累计工作年限"（非本单位工龄），且入职时有义务要求员工提供此前工作证明以确定累计工作年限。 |
| **关联负面清单** | NL-2（剥夺法定假期条款） |

## 使用方式

- Mode A 起草时：Phase 4 法律核验时逐条对照案例锚定，确认制度条款不会触发类似案件中的败诉风险
- Mode B 审查时：将原始制度中的条款与本清单中的案例对照，标注"类似案件可能导致的后果"
- O3 风险矩阵：将案例映射到风险矩阵的每个维度，作为"案例锚定"列
