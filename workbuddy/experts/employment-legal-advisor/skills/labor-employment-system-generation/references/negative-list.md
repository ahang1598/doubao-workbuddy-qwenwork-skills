## NL-1：迟到罚款条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "迟到一次罚款50元""旷工一天扣三天工资""未穿工服罚款20元" |
| **法律依据** | 企业无行政处罚权/罚款权，罚款属于行政处罚措施（《行政处罚法》第9条） |
| **替代方案** | 改为扣除绩效分/取消全勤奖/绩效工资挂钩（非罚款性质） |
| **风险等级** | L1 阻断 |
| **案例** | 广东高院(2019)粤民申XX号：迟到罚款条款被认定无效，须返还已扣款项 |

**正确写法示例**：
> "员工当月迟到累计达3次的，取消当月全勤奖。迟到累计达5次的，当月绩效评分扣减10分，绩效工资相应调整。"

**错误写法示例（禁止）**：
> ~~"员工每迟到一次，罚款50元，从当月工资中扣除。"~~

## NL-2：剥夺法定假期条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "入职不满一年不享受年假""试用期员工不享受法定节假日""产假期间只发基本工资""病假期间按事假处理（全额扣薪）" |
| **法律依据** | 带薪年休假权（累计工作年限≥1年即享有，非本单位工作年限）；法定节假日为全体劳动者权利；产假期间待遇不得降低；病假工资≥最低工资80% |
| **替代方案** | 年假按累计工作年限确定；试用期员工享有全部法定假日；产假期间待遇按法定标准；病假按规定比例支付工资 |
| **风险等级** | L1 阻断 |

**正确写法示例**：
> "员工连续工作满12个月以上的，享受带薪年休假。年休假天数根据累计工作年限确定：满1年不满10年的，年休假5天；满10年不满20年的，年休假10天；满20年的，年休假15天。"

## NL-3：工伤期待遇缩减条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "工伤期间按病假工资标准发放""工伤医疗期间只发基本工资""停工留薪期满后仍未痊愈的按事假处理" |
| **法律依据** | 停工留薪期内，原工资福利待遇不变，由所在单位按月支付（《工伤保险条例》第33条） |
| **替代方案** | 工伤待遇严格按《工伤保险条例》执行，制度中写明"停工留薪期内原工资福利待遇不变，由公司按月支付" |
| **风险等级** | L1 阻断 |

## NL-4：就业歧视条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "限男性""年龄35岁以下""未婚优先""不招XX户籍人员""身高160cm以上""乙肝携带者不录用" |
| **法律依据** | 平等就业权（《就业促进法》第3条、第62条）；除国家规定的不适合妇女的工种或岗位外，不得以性别为由拒绝录用妇女或提高录用标准 |
| **替代方案** | 招聘条件以"胜任岗位能力"为唯一标准，不设置与岗位无关的限制条件；特殊情况（如孕妇禁忌岗位）须注明法律依据 |
| **风险等级** | L1 阻断 |

## NL-5：变相规避社保条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "员工自愿放弃缴纳社保""试用期不缴纳社保""以商业保险替代社会保险""社保费用折算为工资发放""社保缴纳由员工自行处理" |
| **法律依据** | 社保强制缴纳义务（《社会保险法》第58条、第60条）；用人单位和劳动者不得通过约定排除法定社保缴纳义务 |
| **替代方案** | 制度中明确"公司依法为全体员工（含试用期员工）缴纳社会保险，个人应缴部分由公司从工资中代扣代缴" |
| **风险等级** | L1 阻断 |

## NL-6：竞业限制全员化条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "全体员工均须签署竞业限制协议""离职后2年内不得从事本行业任何工作"（无补偿约定）""竞业限制地域范围：中国大陆全境""竞业限制违约金：50万元"（远超合理范围） |
| **法律依据** | 竞业限制仅适用于高级管理人员/高级技术人员/其他负有保密义务的人员（《劳动合同法》第24条）；补偿≥前12月平均工资30%且≥最低工资；期限≤2年；地域和行业范围须合理 |
| **替代方案** | 竞业限制人员范围限定于实际接触核心商业秘密的岗位；补偿标准明确约定；地域和行业范围与公司实际经营区域/竞争关系相匹配 |
| **风险等级** | L1 阻断 |

## NL-7：剥夺申诉权条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "公司作出的处分决定为最终决定，员工不得提出异议""员工签署本制度即视为放弃就制度内容提出异议的权利""员工不得就公司的管理决定向劳动行政部门投诉" |
| **法律依据** | 劳动者享有申请仲裁、提起诉讼的权利，该权利不得通过合同约定排除（《劳动争议调解仲裁法》第5条） |
| **替代方案** | 制度中写入内部申诉渠道（直接上级→部门负责人→人事部→工会→总经理），但不限制员工依法维权的外部途径 |
| **风险等级** | L1 阻断 |

## NL-8：违法解除条款

| 项目 | 内容 |
|:---|:---|
| **禁止写入** | "年度考核末位者公司可解除劳动合同""试用期内公司可随时无条件解除劳动合同""员工生病超过30天的，公司有权解除劳动合同""女员工怀孕期间公司可解除劳动合同" |
| **法律依据** | 末位淘汰=违法解除（指导案例18号）；试用期解除须证明不符合录用条件（劳动合同法第39条）；医疗期内不得解除（劳动合同法第42条）；孕期/产期/哺乳期不得解除（劳动合同法第42条） |
| **替代方案** | 末位淘汰→不胜任→培训/调岗→仍不胜任方可解除；试用期解除须有明确的录用条件+考核记录+不符合结论；医疗期按法定标准执行 |
| **风险等级** | L1 阻断 |

## 过筛检查表（每次起草/审查后逐项打勾）

- [ ] NL-1：无任何"罚款"条款（已改为绩效扣分/取消全勤奖）
- [ ] NL-2：年假按累计工作年限，无"本单位工作满X年"门槛 / 产假病假待遇不低于法定标准
- [ ] NL-3：工伤停工留薪期条款写明"原工资福利待遇不变"
- [ ] NL-4：招聘条款无性别/年龄/户籍/婚育状况限制
- [ ] NL-5：试用期缴社保 / 无"自愿放弃社保" / 无"以商业保险替代"
- [ ] NL-6：竞业限制有明确补偿标准 / 人员范围未含全员 / 地域行业范围合理
- [ ] NL-7：含内部申诉渠道条款 / 未排除员工依法维权的外部途径
- [ ] NL-8：无"末位淘汰" / 试用期解除有"不符合录用条件"前提 / 无孕期/医疗期解除

> **使用提示**：本清单不是"建议"，而是"禁令"——出现任何一条必须修改。法律风险等级全部为 L1 阻断级。
