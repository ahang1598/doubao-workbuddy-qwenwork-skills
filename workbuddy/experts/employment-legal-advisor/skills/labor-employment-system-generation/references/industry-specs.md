## 行业高频风险

1. **农民工工资拖欠**：总包方对分包方欠薪承担先行清偿义务（保障农民工工资支付条例第30条）+工资专户未设立→行政处罚+限制市场准入。制度中必须嵌入工资专户条款
2. **实名制考勤不落实**：未实行实名制管理→行政处罚（保障农民工工资支付条例第55条）+无法证明农民工实际用工人数→工资争议中处于不利地位
3. **工伤风险高但参保率低**：建筑业为工伤高发行业，临时工/短期工漏保→发生工伤时公司全额承担工伤保险待遇
4. **项目制合同终止**："以完成一定工作任务为期限的合同"终止条件不明确→是否构成违法解除存在争议。合同须明确标记项目名称+竣工条件
5. **高温作业**：露天施工作业人员6-10月适用高温津贴（广东300元/月）+高温停工制度→中暑按工伤处理

## 行业高频风险

1. **健康证管理**：员工无有效健康证→食品安全法第126条：警告→罚款5000-50000元→责令停产停业
2. **两头班待命时间**：午餐和晚餐之间2-4小时空档期是否计入工作时间，各地裁判口径不一（深圳：可休息=不计入；北京：不能离开=计入），建议在劳动合同中明确约定
3. **包吃住福利争议**：不可将食宿费用折抵最低工资。制度中须注明"公司提供住宿/工作餐为额外福利，不计入工资"——最低工资规定第12条
4. **高温津贴适用**：厨房灶台区温度常年超过33℃，厨房作业人员适用高温津贴（广东300元/月·6-10月）
5. **食品安全责任**：员工个人卫生不合规导致食品安全事故→公司承担民事赔偿+行政处罚；应在行为规范+奖惩制度中纳入食品安全违规作为严重违纪情形

## 行业高频风险

1. **执业资质管理**：无证/超范围执业→行政处罚（警告→暂停执业→吊销执业证）+民事赔偿+刑事风险（非法行医罪）。入职时必须核查执业资格证有效性和执业范围
2. **患者隐私泄露**：泄露患者隐私→行政处罚+民事赔偿+医师执业证影响（医师法第58条）。制度中须专节规定患者隐私保护+违规后果
3. **多点执业合规**：未备案的多点执业→违规执业，医师法第57条规定由县级以上卫生健康主管部门责令改正+警告→暂停6个月以上1年以下执业活动
4. **职业暴露**：针刺伤/血液体液暴露未建立完善的PEP流程→员工权益受损+职业健康安全管理体系不合规
5. **规培/实习生管理**：规培生/实习生独立执业→带教老师和医疗机构连带责任。制度中须明确"规培生/实习生须在带教老师指导下进行诊疗活动，不得独立执业"
6. **传染病防控**：传染病防治法规定的报告义务+防控措施，制度中须写入"发现法定传染病须立即报告"的条款

| 职业病防护 | 职业病危害因素检测+职业健康检查（上岗前/在岗期间/离岗时）+职业病危害告知+防护用品配备 | 职业病防治法第20/35条 |
| 事故应急 | 应急预案+定期演练+事故报告制度 | 生产安全事故报告和调查处理条例 |

## 行业高频风险

1. **计件工资下加班费**：完成计件定额后的加班，单价须按1.5倍/2倍/3倍计算，不可"做多少算多少"
2. **职业健康检查**：未安排职业健康检查→职业病诊断时举证不利，由用人单位承担不利后果
3. **倒班制合规**：夜班（22:00-6:00）须支付夜班津贴 + 女员工孕期/哺乳期不得安排夜班（女职工劳动保护特别规定第6条）
4. **高温作业保护**：高温天气（≥35℃）应缩短工作时间或停工 + 高温津贴（广东300元/月）+ 中暑按工伤处理
5. **职业病诊断举证**：用人单位未提供职业史+职业病危害接触史→承担不利后果（职业病防治法第47条）

## 行业高频风险

1. **知识产权归属**：未在制度/劳动合同中明确职务发明归属→员工离职时将核心代码/算法带走，公司难以追索。必须写入"在职期间的所有工作成果的知识产权归公司所有"（专利法第6条+实施细则第12条）
2. **竞业限制设计**：竞业限制人员范围过宽（全员签订）→被认定滥用；竞业范围过宽（整个互联网行业）→被认定无效。须精准限定人员和范围
3. **996加班费争议**：互联网行业为高发区。制度中须明确"加班须经事前审批"，不可默许"996"作为默认工时制
4. **开源代码合规**：员工使用开源代码未遵守许可证要求→公司面临知识产权侵权风险。须在制度中增加开源代码使用规范
5. **数据合规**：员工离职带走用户数据/公司内部数据→违反个保法+商业秘密保护。须在保密制度中明确数据分类+离职数据清除义务
6. **弹性工作制边界**：弹性工作制不等于无限制——制度中须明确核心工作时间段+考勤记录方式（如在线打卡）
