## 一、三大生效要件（不可逾越）

员工手册/劳动制度要成为劳动争议中的有效证据，必须同时满足：

1. **内容合法**：条款不得违反法律强制性规定（如低于最低工资、剥夺法定假期）
   - **负面清单**：不得写入"迟到一次罚款XX元"（企业无罚款权）、"入职不满一年不享年假"（侵害法定权利）、"工伤期工资按病假发"（停工留薪期待遇不变）、"超过XX年龄不录用"（就业歧视）
   - 详见 `references/negative-list.md`
2. **民主程序**：经职工代表大会或全体职工讨论→与工会或职工代表协商→公示
   - 职代会讨论：须保留开会通知/签到表/会议记录/表决结果
   - 工会协商：须保留书面协商函和工会回复
   - 公示方式：公告栏张贴拍照+微信群发布截图+纸质版签收
3. **签收闭环**：每位员工签字确认收到并理解制度内容，保留签收记录
   - 签收页单独存档，作为劳动争议关键证据

> **底线提醒**：上述任一要件缺失，法院在劳动争议中可不予采信该制度条款。实践中"未签字员工手册"是企业败诉最高频原因之一。

## 二、制度起草五步法

```
步骤1：定框架 → 章/节/条/款/项/目层级结构（五层序号体系）
步骤2：填内容 → 前言（目的/范围/术语）→ 主文（权利义务）→ 附则（解释/生效/制度位阶）
步骤3：标风险 → 逐条对照法律法规，标注风险等级（L1/L2/L3）+ 嵌入案例锚定
步骤4：走程序 → 嵌入民主程序和签收环节，输出民主程序模板
步骤5：配表单 → 生成全部配套表单（签收/审批/考核/处分）
```

## 三、制度复杂度阶梯

制度不是越多越好，也不是越细越好——根据企业规模匹配合适的颗粒度。

| 档次 | 企业规模 | 制度模块数 | 条款颗粒度 | 典型场景 |
|:---|:---|:---|:---|:---|
| **精简版** | 初创型（≤20人） | 3模块（员工手册+考勤休假+薪酬绩效） | 粗线条，覆盖法定底线+核心条款，~15-20条/模块 | 刚起步的科技公司/小型餐饮 |
| **标准版** | 中型（20-200人） | 7模块（全量） | 中等，补充行业专项+风险提示+程序正义，~25-35条/模块 | 物业管理公司/制造工厂 |
| **完整版** | 大型（200人+） | 7模块深化+可选扩展模块 | 精细，补充分支机构/多岗位/多用工模式适配+扩展模块（反性骚扰/个人信息保护/远程办公/数据安全/外籍管理），~35-50条/模块 | 集团公司/拟上市企业 |

**精简版的应对策略**：
- 不生成独立的"劳动合同管理要点"——在员工手册中加入"劳动合同管理（要点）"章节
- 不生成独立的"特殊用工管理"——如无派遣/外包/返聘需求
- 不生成独立的"保密与竞业限制"——保密条款融入员工手册行为规范章
- 奖惩制度不独立成册——在员工手册中以"奖惩制度（要点）"章节呈现

**初创公司特殊提示**：≤20人的初创公司如无职代会，可以用"全体职工讨论"替代，但仍须保留讨论记录和签收确认。

## 四、员工手册与专项制度职责边界

当前常见错误设计：员工手册全是指向"详见《XX文件》"的索引，员工拿到手里是一本**什么都看不到**的手册。

**重新划分**：

| 维度 | 员工手册 | 专项制度 |
|:---|:---|:---|
| **定位** | 权利性条款——员工可直接引用的权利和基本义务 | 管理性条款——HR操作细则和管理流程 |
| **受众** | 全员签收 | 部门传达 / HR专用 |
| **内容** | 招聘录用·行为规范·薪酬福利（概要）·奖惩（概要）·安全·离职·申诉 | 合同管理操作·考勤排班细则·薪酬岗位标准·绩效考核方法·违纪处分程序·特殊用工管理边界 |
| **引用方式** | "详见《XX制度》第X章第X条"——**但手册本身的权利条款须完整可直接引用** | 无需反向引用员工手册 |
| **保密条款** | 行为规范章中简述保密义务（法定义务简述） | 竞业限制协议（独立劳动合同附件） |

**底线规则**：
- ❌ 员工手册不得全是"详见XX文件"——员工有权通过手册直接了解自己的基本权利和核心义务
- ✅ 法定权利条款（假期天数/加班费标准/申诉渠道）在手册中呈现完整内容，不引用专项制度
- ✅ 操作流程细则（排班方案/KPI指标/违纪处分程序）可以在手册中做概要以"详见专项制度"

## 五、程序正义完整框架

惩罚制度中最容易被法院撤销的不是实体问题，而是程序瑕疵。

### 处分程序四环节（缺一不可）

```
1. 调查取证 → 事实认定+证据固定+调查笔录
2. 通知与申辩 → 书面告知事实和依据，给予≥3个工作日的申辩期
3. 工会意见 → 单方解除须事先将理由通知工会（劳动合同法第43条）
4. 决定与送达 → 书面处分决定+签收/留置送达/邮寄送达
```

### 处分时效制度

| 违纪类型 | 调查启动时限 | 处分决定时限 | 说明 |
|:---|:---|:---|:---|
| 一般违纪 | 知悉后15个工作日内 | 知悉后30个工作日内 | 超期视为放弃处分 |
| 较重违纪 | 知悉后10个工作日内 | 知悉后30个工作日内 | 超期视为放弃处分 |
| 严重违纪 | 知悉后立即启动 | 知悉后30个工作日内 | 解除合同须在30日内完成 |

### 处分记录管理

- 保存期限：一般违纪记录保存1年 / 较重违纪保存2年 / 严重违纪（含解除）永久保存
- 用途限制：处分记录仅用于用工管理，不得对外提供（法律要求除外）
- 消除规则：处分期内无新增违纪记录→处分期满后记录自动消除
- 数据保护：处分记录含个人信息，须遵守《个人信息保护法》相关规定

## 六、保密与竞业限制区分规则

| 维度 | 保密义务 | 竞业限制义务 |
|:---|:---|:---|
| **法律性质** | 法定义务 | 约定义务 |
| **是否需要补偿** | 不需要（在职期间/离职后均无需额外补偿） | **必须支付经济补偿**（≥前12月平均工资30%且≥最低工资） |
| **期限限制** | 永续（只要信息仍属商业秘密） | ≤2年（劳动合同法第24条） |
| **适用范围** | 全体员工（接触商业秘密的） | 高级管理人员+高级技术人员+其他负有保密义务的人员 |
| **文件形式** | 员工手册行为规范章 + 劳动合同保密条款 | 独立的竞业限制协议（劳动合同附件） |

**混同风险**：
- ❌ 保密和竞业限制放在同一份文件签收——员工签收后可能产生"是否同意竞业限制"的法律争议
- ✅ 保密条款融入员工手册行为规范章（简版）+ 劳动合同保密条款（完整版）
- ✅ 竞业限制独立为劳动合同附件，单独签署，明确补偿标准

## 七、制度位阶与冲突解决规则

制度体系中发生条款冲突时的解决顺序：

```
1. 法律强制性规定（最高效力，不可约定排除）
2. 劳动合同约定（个体约定 > 集体约定）
3. 专项制度（实施细则，如"考勤与休假制度"）
4. 员工手册（总纲，权利性条款）
5. 部门操作指引（内部流程文件，不对外）
```

**冲突解决规则**：
- 专项制度与员工手册不一致 → 以专项制度为准（专项制度为实施细则），但专项制度不得缩减员工手册已载明的法定权利
- 劳动合同与制度不一致 → 以劳动合同为准（个体约定优先），但劳动合同约定不得低于法定底线
- 旧版制度与新版制度不一致 → 以新版为准（制度修订须经民主程序），新旧过渡期须明确注明

**附则中必须写入的位阶条款**：
> "本制度与《员工手册》不一致的，以本制度为准，但不得缩减《员工手册》已载明的法定权利。本制度与劳动合同约定不一致的，以劳动合同为准，但劳动合同约定不得低于法定标准。本制度解释权归属公司人力资源部，修订须经民主程序。"

## 八、地方裁判口径差异方法论

同一法律问题在不同地区的法院裁判口径不同，制度起草时须标注地区差异。

> **详细数据见 `references/regional-rules.md` §六"地方裁判口径差异矩阵"**，包含加班费基数约定/待命时间认定/未签合同二倍工资等裁判口径的地区差异。

### 制度设计方法论原则

1. **高风险地区标注**：北京/江苏/浙江等"加班费基数倾向于以全部工资性收入为基数"的地区，必须在劳动合同+薪酬制度中多重明确约定基数
2. **地区差异嵌入方式**：在薪酬制度加班费计算条款中标注"[XX地区] 裁判口径：______，建议______"
3. **全国统一口径**：末位淘汰=违法解除（全国统一，指导案例18号），无需地区差异标注
4. **待命时间条款**：涉及值班/待命时间的条款须标注地区差异认定标准

## 九、制度颁布后30天操作清单

制度起草完毕不等于工作完成。以下为制度颁布后企业须执行的30天操作清单：

| 天数 | 操作项 | 产出/证据 | 风险标注 |
|:---|:---|:---|:---:|
| D-15 | 制度草案发送工会/职工代表征求意见 | 征求意见函+工会回复 | L2 |
| D-10 | 召开职代会（或全体职工大会）讨论制度草案 | 会议通知+签到表+会议记录+表决结果 | L1 |
| D-7 | 根据讨论意见修改定稿 | 修改对照表 | L2 |
| D-3 | 印刷制度文件、准备签收材料 | 制度文件纸质版/电子版 | L2 |
| D-Day | 颁布通知发布 | 颁布通知（含施行日期） | L1 |
| D+1~7 | 全员签收（按部门分批进行） | 签收确认书（每人一份） | L1 |
| D+1~7 | 制度张贴公示 | 公告栏照片+微信群截图 | L2 |
| D+7 | 签收记录归档（未签收人员追踪） | 签收汇总表+未签收人员追踪记录 | L1 |
| D+14 | 新员工入职培训中增加制度培训 | 培训签到表+培训记录 | L2 |
| D+30 | 制度施行初期反馈收集 | 反馈汇总表 | L3 |
| D+30 | 制度修订触发条件确认（如需修订） | 修订需求登记 | L2 |

> **关键操作提示**：未在30天内完成全员签收的，须重点标注"未签收即不能证明员工知晓"，劳动争议中将处于不利地位。

## 十、法律风险矩阵框架

制度文件包的风险矩阵应覆盖以下维度（交付时作为 O3 风险矩阵输出）：

| 风险维度 | 评估要点 | 案例锚定 |
|:---|:---|:---|
| 制度效力风险 | 民主程序完整性·签收闭环·修订程序合法性 | 深圳中院(2020)粤03民终XX号：员工手册未经民主程序→不予采信 |
| 工资支付风险 | 最低工资·加班费基数·加班时长上限·离职结算时效 | 北京三中院(2019)京03民终XX号：加班费基数约定不明→以全部工资为基数 |
| 解除程序风险 | 末位淘汰·"严重违纪"量化·工会通知·处分时效 | 指导案例18号：末位淘汰=违法解除 |
| 竞业限制风险 | 人员范围·补偿标准·竞业范围合理性 | 上海一中院(2021)沪01民终XX号：全员竞业限制→条款无效 |
| 外包派遣风险 | 假外包真派遣·10%比例·三性岗位 | 广东省高院(2018)粤民再XX号：假外包真派遣→承担连带责任 |
| 社保合规风险 | 试用期社保·基数合规·自愿放弃无效 | — |
| 个人信息风险 | 员工信息收集范围·使用目的·存储期限·删除权 | 个人信息保护法第6条+第47条 |
| 反歧视风险 | 招聘年龄限制·性别限制·婚育状况询问 | 就业促进法第3条+第62条 |

> 详细案例锚定见 `references/case-anchors.md`

## 十一、语言规范与写作红线

### 语言规范

- 法言法语、规范化用词，避免：
  - ❌ 行政化语言（如"要""应该"→ 应使用"应当""须"）
  - ❌ 带有感情色彩的语言（如"严厉处罚"→ 应具体描述处罚措施）
  - ❌ 口语化表达
- 关键术语必须定义（如"严重违纪""重大损失""情节严重"须量化标准）
- 条款序号体系统一规范：章→条→款→项→目（五层）

### 写作红线（不可逾越）

1. **禁止绝对化表述**："保证""必然""100%""万无一失"一律改为客观表述
2. **禁止模糊定义**："严重违纪""重大损失"必须有量化标准（金额/次数/后果）
3. **禁止违法条款**：不得写入企业无权执行的处罚（罚款/体罚/限制人身自由）
4. **禁止歧视性条款**：不得以性别/年龄/民族/婚育状况设置录用门槛
5. **禁止剥夺法定权利**：不得变相缩减法定假期/法定待遇/法定程序
6. **禁止回避义务**：不得通过制度设计实质架空法定义务（如社保缴纳）

### 常见错误

1. **末位淘汰写进制度**：法院普遍认定为违法解除
2. **迟到罚款超过工资20%**：违反《工资支付暂行规定》第16条
3. **试用期不缴社保**：违法，试用期包含在劳动合同期内
4. **以"严重违反规章制度"解除但制度未定义何谓严重**：法院不予采信
5. **制度修订不走民主程序**：单方修订无效
6. **保密和竞业限制混同**：法定义务与约定义务混淆
7. **综合计算工时未经审批**：合同约定也无效

## 十二、融入本技能的方式

- 三大生效要件 → 嵌入所有制度"附则"章节
- 制度复杂度阶梯 → Phase 1 根据企业规模确定
- 员工手册与专项制度边界 → Phase 3 逐模块填充时执行
- 程序正义四环节 → 嵌入"奖惩制度"模块
- 保密与竞业区分 → 员工手册行为规范章（保密）+ 独立附件（竞业限制）
- 制度位阶规则 → 嵌入所有制度"附则"章节
- 地方裁判口径差异 → Phase 4 法律核验时注入
- 30天操作清单 → Phase 5 交付时嵌入 O2 风险提示清单
- 风险矩阵框架 → Phase 5 交付时生成 O3 风险矩阵
