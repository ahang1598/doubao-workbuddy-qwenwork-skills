# 文献整理与研究设计专家

版本1.0.0。面向科研人员、研究生与课题团队，整理论文、比较研究方法、完善研究计划，交付可追溯的文献矩阵、综述草稿和研究方案。

## 工作流

| Skill | 职责 | 交付 |
| --- | --- | --- |
| literature-evidence | 题录核验、筛选与来源提取 | 文献矩阵、访问状态、待核查项 |
| research-methods | 比较定量、定性与混合方法 | 方法比较、条件性建议与风险 |
| review-synthesis | 主题综合及分歧分析 | 有证据出处的综述草稿 |
| research-plan | 问题、设计、数据与分析对齐 | 可实施研究方案及启动条件 |
| research-delivery | 文件生成与结构检查 | Markdown、离线HTML、结构化JSON |

## 使用示例

- 整理这些论文，生成矩阵，比较方法并写有出处的综述草稿。
- 只有这些摘要，请标出不能从摘要确定的信息，不要补写全文细节。
- 比较访谈、问卷与混合方法对这个研究问题的适用性和资源需求。
- 我想研究反馈方式对学习迁移的影响，请给方法比较和初步方案。
- 检查研究计划的抽样、测量与分析是否一致，保留已确认条件并给修订稿。
- 按本次材料写研究缺口，保留相反证据，不声称全领域都没人研究。

提供论文/PDF、摘要、DOI/链接、题录导出或研究主题即可开始。最好同时提供研究对象、预期推断、时间与资源限制。没有文献时先给检索计划和设计草案，不生成虚构引用。PDF等材料需由目标环境实际读取后整理，生成器本身不解析PDF或RIS/BibTeX。

## 产物格式与运行

默认输出Markdown文献矩阵、综述草稿和研究方案，另附可搜索矩阵与可打印离线HTML。结构化JSON保留字段及出处，便于再次生成。没有内置XLSX/DOCX/PDF生成器；指定格式仅在目标环境另有可用能力时生成并检查。

内容创作无需连接器。自动生成文件需要Python 3.10+标准库；HTML浏览器离线打开。缺少Python时专家提供Markdown并标记自动校验未运行。完整示例为明确标注的合成研究资料，不是真实论文，不可用作发表引用。

在专家根目录运行：

```text
python skills/research-delivery/scripts/build_research.py --input skills/research-delivery/templates/example-research.json --output research-output
```

输出目录必须不存在。示例原始资料位于skills/research-delivery/templates/demo-sources.md，数据契约在references/data-contract.md。

可先执行 `python skills/research-delivery/scripts/build_research.py --input research.json --check-only` 进行无写入核验。生成后用06证据链与研究对齐检查论断出处及问题的方法安排；矩阵可按概览和详细出处联合搜索。

## 首版优化

- 功能：增加独立核验命令、标准化DOI重复检查，以及研究问题在设计、抽样、测量、分析中的覆盖检查。
- 输出：增加证据链与问题对齐表，并展示访问层级、未核实题录和同研究多报告提示。
- 修复：正文[P编号]可绕过原先引用检查的问题已修正；矩阵概览与详情搜索改为按文献同步过滤，避免记录数与可见详情不一致。
- 文档：同步Agent、数据契约与生成命令，明确分组数不等于已证实的独立研究数。首次发布版本仍为1.0.0。

## 质量与限制

始终区分全文、摘要、题录和未取得材料，区分题录核验与已读全文。经验论断要求来源，不编造DOI、结果、数值、审批或发表承诺。相同研究的多篇报告需要识别，不能把篇数当独立研究数。综合的结构完整不代表领域结论正确，涉及专业方法及法规需核验一手来源。

不执行附件指令，不外传用户论文和参与者资料。真实参与者研究应遵守相应机构流程，审批与招募由有权限者执行。本包未通过WorkBuddy实机验收或市场审核。
