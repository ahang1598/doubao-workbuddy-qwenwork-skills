# 研究方案核对表

| 检查面 | 需要明确的内容 | 常见不一致 |
| --- | --- | --- |
| 问题 | 对象、概念/变量、时间、目标推断 | 问因果却只设计一次横断面问卷 |
| 设计 | 数据生成与对照/情境、方法依据 | 把预测准确率当干预效果 |
| 样本 | 分配/招募/分析单位、纳排、样本依据 | 班级分配却忽略班级内相关 |
| 测量 | 操作定义、主要结局、时点、工具来源 | 想测迁移却只测满意度 |
| 分析 | 问题对应的分析、假设、缺失/偏倚策略 | 收完数据再挑显著分析且称预设 |
| 定性严谨性 | 选样、情境、分析步骤、反思和适用质控 | 机械要求所有定性取向做同一种一致性检验 |
| 伦理与数据 | 同意、最小化、去标识、权限、保存规则 | 写成已获批或已经招募 |
| 可行性 | 人力、时间、数据权限、资源和备选 | 既定期限无法完成招募、随访与分析 |

样本量缺参数时输出待办：主要结局及尺度、最小有意义效应或期望精度、参数来源、设计结构、失访假设、可招募上限，以及是否需要情景分析。此阶段不要填一个看似精确的N。

启动门槛：研究问题与主要结局确认；数据访问可用；伦理/许可按适用要求完成；工具试测；样本与分析方案复核。门槛属于计划，不表示专家已替用户获得许可。
