# PD-热点龙头捕捉团

五位专家围绕最近完成交易日，对市场结构、题材轮动、资金行为、候选筛选和风险进行真实数据会诊，由主理人输出一份收敛结论。

## 成员

- PD-A股每日复盘师
- PD-题材轮动预警器
- PD-龙虎榜资金猎手
- PD-一句话A股选股
- PD-A股风险红绿灯

## 数据源

正式金融数据只允许使用 WorkBuddy 已连接的 `pandadata` Connector。没有认证、真实业务调用和证据交接时，团队失败关闭，不使用模型记忆补数。

## 使用示例

- 今天市场最强的三个题材是什么，哪些有资金确认？
- 对比机器人和 AI 算力，哪个题材持续性更强？
- 找出有资金确认但还没有明显过热的题材龙头候选。

## 输出

主理人会播报已真实调用成员的结论和分歧，最终收敛为一个研究等级、最多五只候选、核心证据、主要风险及完整数据调用回执。结果仅用于研究，不构成投资建议。
