# 术语规范

| 术语 | 规范表述 | 说明 |
|------|----------|------|
| Term Sheet | 投资意向书 / 条款清单 / TS | 原则性商业意向记录，大部分条款不具约束力 |
| SPA | 股份购买协议 | 正式投资文件，非本技能范围 |
| SHA | 股东协议 | 正式投资文件，非本技能范围 |
| VIE | 可变利益实体 / 协议控制 | 境外主体通过协议控制境内运营实体 |
| WFOE | 外商独资企业 | 返程投资设立的境内实体 |
| 37号文登记 | 境内居民境外投资外汇登记 | 汇发[2014]37号 |
| ODI | 境外直接投资备案 | 商务部门+发改委+外管局三部门 |
| 负面清单 | 外商投资准入特别管理措施（负面清单） | 定期更新，须查阅现行最新版 |
| 名股实债 | 名股实债 | 以股权形式表现但实质为债权的投资结构 |
| 让与担保 | 让与担保 | 担保制度解释第68条正式入法 |
| 排他期 | 排他期 / No-Shop / Exclusivity | TS中约束力条款，限制被投公司接触其他投资方 |
| 定向减资 | 定向减资 | 新公司法第224条第3款：定向减资（不等比减资）须经全体股东另有约定或章程另有规定，默认须等比减资 |
| 资本维持原则 | 资本维持原则 | 限制公司回购股权的法理基础 |
| 外观主义 | 外观主义 | 以工商登记为准保护善意第三人 |
| 衡平居次 | 衡平居次 / 深石原则 | 出资不实股东的债权可能劣后受偿 |
