# 核心方法论

## 一、TS约束力判断方法论

### 核心原则

TS的法律性质是**原则性商业意向记录**，大部分条款不具法律约束力。少量条款会单独注明具约束力——这些条款是风险集中点。

### G/Y/R三级分流

| 级别 | 含义 | 典型场景 |
|------|------|----------|
| GREEN | 条款清晰，风险可控 | 排他期合理/费用过错原则清晰/保密标准化/管辖无陷阱 |
| YELLOW | 存在需关注条款，建议修改后签署 | 排他期过长但可谈判/费用无上限/保密范围过宽 |
| RED | 存在重大风险条款，须律师深度介入 | 排他期构成"卖身契"/费用可能致巨额中介费/约束力条款被埋 |

### 四类约束力条款

1. **排他期**：≤60天GREEN / 60-120天YELLOW / >120天RED
2. **保密**：3-5年GREEN / 5-10年YELLOW / 永久RED
3. **费用承担**：过错原则+上限GREEN / 无上限YELLOW / 一刀切RED
4. **管辖权**：PE/VC项目93%选择仲裁

## 二、行业准入方法论

### 四步判断法

```
查阅现行负面清单 → 判断行业类别 → 评估替代路径 → 出具合规结论
```

### 行业分类

- **禁止类**：互联网新闻/网络出版/网络视听/互联网文化经营（音乐除外）
- **限制类**：增值电信（外资≤50%）/医疗机构（合资合作）/教育（中外合作办学）
- **允许类**：一般制造业/一般服务业

### VIE架构评估维度

```
行业是否在负面清单内？
  ├── 否 → VIE非必需
  └── 是 → 该行业有VIE被否定先例？
            ├── 是 → 高风险
            └── 否 → 境外上市目的地披露要求？+ 拆除VIE备选方案？
```

## 三、股债定性四维分析法（V07）

当投资性质发生争议时，法院从四个维度综合判断——**不依赖单一因素，四维加权后综合定性**。

| 维度 | 指向"债"的信号 | 指向"股"的信号 |
|------|----------------|----------------|
| 缔约磋商过程 | 借款申请/还款计划/股东会借款决议 | 讨论估值/董事会席位/增资方案 |
| 转让价格 | 1元受让90%股权（明显偏离价值） | 转让价格与公司估值匹配 |
| 收益安排 | 固定回报/不参与经营/到期无条件回购 | 回报与业绩挂钩/委派董事/行使表决权 |
| 担保机制 | 抵押/质押/连带保证 | 无担保措施 |

### 内外有别规则

- **内部关系**（当事人之间）：实质重于形式，四维分析探明真实意思
- **外部关系**（涉及第三人，尤其破产时）：外观主义，以工商登记为准

### 市场惯例基准（顶级律所TS谈判方法）

顶级律所审查TS时，不只判断"风险有无"，更以PE/VC市场惯例为基准给出**可谈判区间**，支撑客户谈判立场：

| TS条款 | 市场常见基准 | 偏离信号 |
|--------|--------------|----------|
| 排他期 | 30-60天（少数至90天） | >120天视为异常 |
| 费用承担 | 过错原则+合理上限（如交易费50万封顶） | 一刀切由被投方承担为异常 |
| 保密期限 | 3-5年（少数永久仅限核心保密信息） | 全条款永久保密为异常 |
| 分手费/反向分手费 | 交易金额1%-3% | >5%视为异常 |
| 最惠国条款 | 仅经济权利+同等估值豁免 | 无差别回溯全部条款为异常 |

> 基准为市场常见实践的非约束性参考，须结合交易规模/阶段/谈判地位调整；不替代个案商业判断。

## 四、名股实债四步防范法（V08）

### 第一步：资金融出方式选择

| 方式 | 破产场景下债权保护 |
|------|-------------------|
| 直接支付股权转让款 | 弱——被登记为股东，破产时无法以债权人身份申报 |
| 收购股权/项目收益权 | 中等——不具有股东身份，申报债权障碍较小 |
| 股东借款（先成为股东再借款） | 较强——法律未限制股东申报债权 |

### 第二步：本金收回路径设计

**重大更新**：新公司法第224条第3款——定向减资（不等比减资）非默认，须经有限责任公司全体股东另有约定或股份有限公司章程另有规定；默认须按股东出资比例等比减资。

| 回购义务人 | 效力 | 实操难点 |
|------------|------|----------|
| 目标公司 | 受资本维持原则严格限制 | 定向减资须全体股东另有约定或章程另有规定，路径易被堵 |
| 创始股东/实控人 | 效力最无争议 | 须评估个人偿付能力 |
| 第三方（非股东） | 须解决优先购买权问题 | 可加入现有股东作为共同行动人 |

**建议优先选择"创始股东回购+目标公司连带担保"模式**。

### 第三步：固定回报率风险

企业间借贷合同有效的三个要件：
1. 资金用途为生产经营
2. 资金来源为自有资金
3. 借贷行为是临时性资金拆借，不以经常性放贷为业

若具有反复性/经常性/营业性→可能被认定未经许可从事金融业务→合同无效。

### 第四步：增信措施叠加

按重要性排序：创始股东连带保证 > 股权质押 > 不动产抵押 > 反稀释 > 参与公司治理 > 资金使用监管
