# 使用说明

## 快速开始

### 场景1：起草TS

```
用户：帮我起草一份Term Sheet，投资方是美元基金，目标公司是互联网教育平台，投资1000万美元，投前估值4000万美元。
```

技能将执行子流程A（TS草案生成），输出含约束力条款标注的TS草案。

### 场景2：审查TS

```
用户：审查这个投资意向书 [附TS全文]
```

技能将执行子流程A（TS审查），输出逐条约束力标注+G/Y/R风险分流+修改建议。

### 场景3：投前合规检查

```
用户：境外基金想投资一家增值电信企业，外资能投吗？需要什么手续？
```

技能将执行子流程B（投前合规检查），输出行业准入结论+VIE评估+外汇手续路径图。

### 场景4：交易结构风险评估

```
用户：投资人以1元受让目标公司90%股权，约定年化12%固定回报，三年后由创始股东回购，这个结构有什么风险？
```

技能将执行子流程C（交易结构风险评估），输出股债定性四维分析+名股实债四步防范建议。

## 使用建议

1. **提供完整信息**：TS全文/目标行业/投资方类型/交易结构描述等信息越完整，分析越精准
2. **标注投资方类型**：境内/境外/跨境，影响合规检查路径
3. **关注待核查项**：报告中标注"待核查"的事项须由持证律师核实
4. **每次核实负面清单版本**：外商投资负面清单定期更新

## 输出格式

- Markdown或docx格式
- 无emoji
- 每次输出附免责声明
- 法条引用标注条文性质和时效
