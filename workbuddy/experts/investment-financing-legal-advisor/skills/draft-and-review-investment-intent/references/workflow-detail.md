# 工作流详细步骤

## Phase 1: 意图识别+信息收集

1. 识别用户任务类型（draft_ts/review_ts/compliance_check/risk_assessment）
2. 收集必要输入参数（参照 `input-spec.md`）
3. 信息不足时一次性追问全部缺口（≤1次）
4. 多需求按 B→C→A 顺序执行

## Phase 2: 子流程A — 起草/审查Term Sheet

> 详见 `投资意向书约束力判断.md`

1. **约束力条款识别** — 逐条标注约束力状态（约束/非约束）
   - 具约束力：排他期/保密/费用承担/管辖权和争议解决
   - 不具约束力：估值/投资金额/股权比例/公司治理安排等商业条款

2. **排他期条款审查** — 三个考量因素
   - 双方交易意愿的紧迫性
   - 被投公司现金流压力
   - 投资方尽调所需时间
   - 风险点：排他期过长可能构成"限制竞争"

3. **费用承担条款审查** — 按过错原则设计
   - 哪方导致交割失败，哪方承担中介费用
   - 被投公司承担金额须设上限

4. **TS草案生成**（如需起草） — 按标准化结构输出

## Phase 3: 子流程B — 投前合规检查

> 详见 `行业准入与外汇合规.md`

1. **行业准入判断** — 外商投资负面清单+特殊行业限制
   - 查阅现行《外商投资准入特别管理措施（负面清单）》（最新版）
   - 判断禁止类/限制类/允许类
   - 禁止类→评估VIE架构或放弃直投
   - 限制类→满足外资股比限制/高管国籍要求

2. **VIE架构合规性评估** — 如涉及限制类行业
   - VIE协议合法性在中国法律下尚未有明确立法结论
   - 司法实践：最高院(2015)民二终字第117号案
   - 返程投资VIE豁免适用范围有限

3. **跨境外汇手续** — "投进来"vs"走出去"
   - 投进来：直接投资/红筹架构（37号文登记）
   - 走出去：商务部门+发改委+外管局三部门各管一段

## Phase 4: 子流程C — 交易结构风险评估

> 详见 `交易结构风险分析.md`

1. **股债定性四维分析** — 预判争议时的定性方向
   - 维度一（缔约磋商过程）
   - 维度二（转让价格）
   - 维度三（收益安排）
   - 维度四（担保机制）
   - 内外有别：内部实质重于形式，外部外观主义优先

2. **名股实债四步防范** — 若拟采用名股实债结构
   - 第一步（资金融出方式）
   - 第二步（本金收回路径）— 优先创始股东回购+目标公司连带担保
   - 第三步（固定回报率风险）— 核查放贷资质和经常性
   - 第四步（增信措施叠加）

## Phase 5: 自检纠错+报告组装

### 自检清单

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| TS约束力条款标注 | 未逐条区分约束/非约束 | 重新逐条审查TS |
| 负面清单版本 | 引用了旧版负面清单 | 更新为现行有效版本+标注生效日期 |
| VIE评估 | 直接断言"VIE合法"或"VIE违法" | 改为概率判断+风险等级+司法判例支撑 |
| 跨境手续路径 | 遗漏了商务/发改/外汇任一环节 | 补充完整路径图 |
| 股债定性 | 仅依赖单一维度判断 | 执行完整四维分析+标注权重 |
| 名股实债回购义务人 | 仅设目标公司为回购主体 | 建议创始股东回购+目标公司连带担保 |
| 固定回报率 | 未核查放贷资质和经常性 | 补充核查 |

### 已知失败模式 → 替代方案

- **负面清单"允许类"但实际被卡住**：建议提前与主管部门非正式沟通
- **37号文登记被拒**：委托有成功案例的地方代理机构，或准备替代结构
- **VIE架构被交易对手质疑合法性**：以(2015)民二终字第117号案为论据+准备拆除VIE备选方案

### 熔断（防token黑洞）

同一步骤连续纠正2次仍不达标 → 停止重试，汇报"已完成部分+卡在哪+已试过哪些方案+需要用户/人工提供什么"，交回控制权。
