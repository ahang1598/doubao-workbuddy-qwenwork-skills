# 术语规范

| 术语 | 说明 |
|------|------|
| 特殊权利 | 投资人优于普通股股东的权利 |
| 优先清算权 | Liquidation Preference |
| 反稀释权 | Anti-dilution Right |
| 回购权 | Redemption Right |
| 优先购买权 | Right of First Refusal |
| 跟售权 | Tag-along Right |
| 拖售权 | Drag-along Right |
| 优先认购权 | Pre-emptive Right |
| 信息权 | Information Right |
| 保护性条款 | Protective Provisions |
| 股权成熟期 | Vesting Period |
| 竞业禁止 | Non-compete |
| 陈述与保证 | Reps & Warranties |
| 交割条件 | Closing Conditions |
| 转换权 | Conversion Right |
| 知情权穿透 | Information Right Look-through |
| 参与型/非参与型 | Participating/Non-participating |
| 加权平均/完全棘轮 | Weighted Average/Full Ratchet |
| cliff | 成熟期起始门槛（通常1年） |
| 最惠国条款 | MFN / Most Favored Nation；后续轮次更优条款自动惠及前期投资人的回溯机制 |
| 市场惯例基准 | market standard；区分标准条款与投资人过度主张的参照系 |
| 离职员工竞业限制 | 创始人以离职员工身份承担的竞业限制，适用劳动合同法第23-24条（区别于董监高同业竞争第184条） |
