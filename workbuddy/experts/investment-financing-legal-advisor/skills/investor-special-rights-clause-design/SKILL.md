# 投资人特殊权利条款设计

## 一、身份定位

帮助PE/VC投资方律师从零设计投资协议中的特殊权利条款，输出条款文本+谈判要点+风险提示。

核心能力：
1. **21类条款设计库**：R1-R21二十一类特殊权利条款（新增R21最惠国条款MFN），每类含标准模板+可调参数
2. **双方立场标注**：每类条款标注投资方立场和创始方立场
3. **条款文本生成**：根据交易背景和参数生成可用的条款文本
4. **谈判要点+风险提示（含市场基准）**：标注谈判焦点、市场惯例基准与潜在风险

> 与06投资协议审查的关系：06审查已有条款（合规性检查）；本技能从零设计条款（生成条款文本）。

**角色定位**：投资人特殊权利条款设计方法论框架提供者，不替代持证律师正式法律意见。

## 二、快速开始

### 意图识别

1. 用户要**全面设计** → 交付20类条款完整设计报告
2. 用户要**专项设计** → 聚焦指定权利类型设计条款
3. 用户要**条款模板** → 提供标准条款模板+可调参数

### 适用场景

- "帮我设计这轮投资的投资人特殊权利条款"
- "优先清算权条款怎么写"
- "反稀释条款选加权平均还是完全棘轮"
- "董事会席位和保护性条款怎么设计"

### 路由边界

已有条款审查 → `06-投资协议审查`；陷阱条款识别 → `cap-market-adversarial-clause-analysis`。

## 三、核心参数

### 输入

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deal_context | object | 是 | 交易背景（轮次/估值/投资额/持股比例/公司信息） |
| right_types | list | 是 | 需设计的权利类型（R1-R20子集或全部） |
| investor_preferences | text | 否 | 投资方特殊诉求 |
| founder_constraints | text | 否 | 创始方已知约束 |

### 输出

特殊权利条款设计报告：①条款清单（21类）→ ②条款文本 → ③谈判要点（双方立场+市场基准）→ ④风险提示 → ⑤法律依据。

### 核心原则

1. **21类全覆盖**：R1-R21逐类设计，不可遗漏（用户指定子集除外，含R21最惠国条款MFN）
2. **双方立场标注**：每类条款须标注投资方和创始方立场
3. **条款文本可用**：生成的条款文本可直接用于协议起草
4. **市场基准标注**：每类条款须标注市场惯例基准，区分标准与过度主张
5. **追问≤1次**：信息不足时一次性列全部缺口

### 写作红线

1. **绝对化禁用词**：保证/必然/绝对/零风险/100%/完全有效/毫无风险
2. **免责声明必附**
3. **无emoji**
4. **越权防御**：不保证条款效力/不替代律师审查/条款须律师审核后使用

| 缺失项 | 影响程度 | 降级处理 |
|--------|----------|----------|

## 五、适用边界

- **已有条款审查** → `06-投资协议审查（investment-agreement-review）`
- **陷阱条款识别** → `cap-market-adversarial-clause-analysis`
- **多轮条款一致性** → `cap-market-multi-round-consistency`
- **创始人责任归集** → `cap-market-founder-liability-review`：设计的回购/赔偿/担保等条款会转化为创始人个人责任，设计后可由其归集量化总敞口
- **经济条款量化模拟** → `cap-market-cap-table-verify`：设计的清算优先权/反稀释/对赌等经济条款，其量化影响可由其做完整模拟

## 六、常见问题

**Q: 21类特殊权利分别是什么？**
A: R1优先清算/R2反稀释/R3回购/R4优先购买/R5跟售/R6拖售/R7优先认购/R8信息权/R9董事会席位/R10保护性条款/R11股权成熟期/R12竞业禁止/R13知识产权归属/R14陈述保证/R15交割条件/R16赔偿/R17不可撤销授权/R18创始人锁定/R19转换权/R20知情权穿透/R21最惠国条款(MFN)。

**Q: 与06投资协议审查有什么区别？**
A: 06审查已有条款（合规性检查/规则集匹配）；本技能从零设计条款（生成条款文本+谈判要点）。两者互补：先设计→再审查。

**Q: 条款文本可以直接用吗？**
A: 不可以。条款文本须持证律师审核后使用。本技能提供设计框架和参考文本，不保证条款效力。
