# 术语规范

| 术语 | 说明 |
|------|------|
| 创始人个人责任 | 创始人以个人名义承担的法律义务（区别于目标公司义务） |
| L1回购义务 | 特定条件下创始股东须回购投资人股权 |
| L2赔偿义务 | 因违约/陈述不实须赔偿对方损失 |
| L3竞业禁止 | 不得从事与目标公司竞争的业务 |
| L4知识产权归属 | 职务成果归目标公司+历史IP转让 |
| L5不可撤销授权 | 表决权委托/股权处置限制等不可撤销授权 |
| L6股权锁定/质扣 | 成熟期/转让限制/股权质押 |
| L7连带责任 | 与目标公司/其他创始人对同一债务承担连带 |
| L8个人担保 | 为目标公司债务/回购义务提供个人担保 |
| D1责任上限 | 责任金额是否有上限 |
| D2触发条件 | 触发条件是否明确 |
| D3持续期间 | 责任存续时间 |
| D4可保险性 | 是否可通过保险转移 |
| D5条款联动 | 与其他条款的交叉引用关系 |
| 条款联动 | 条款间通过交叉引用形成的触发关系 |
| 成熟期 | Vesting Period；创始人股权分期成熟 |
| 个人责任总敞口 | 最不利假设下创始人个人承担的所有现金责任汇总金额 |
| 资产覆盖比 | 总敞口 / 创始人可变现资产；>1 即资不抵债风险高 |
| 市场惯例基准 | market standard；区分标准条款与投资人过度主张的参照系 |
| D&O险 | 董责险；可覆盖陈述保证类赔偿与履职过失，通常不含回购本金与惩罚性赔偿 |
| 谈判优先级 | 必争(Must-fight)/可谈(Negotiable)/接受(Accept) 三级 |
