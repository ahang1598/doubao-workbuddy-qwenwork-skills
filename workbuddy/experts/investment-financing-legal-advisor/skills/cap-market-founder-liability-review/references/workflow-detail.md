# 工作流详细步骤

## Phase 1: 文件解析+创始人识别

1. 解析交易文件（PDF/Word→文本）
2. 识别目标创始人在文件中的称呼：
   - 直接姓名（如"张三"）
   - 角色定义（如"创始股东""创始人""[姓名]先生"）
   - 定义条款引用（如"创始人指XXX"）
3. 识别文件间的交叉引用关系（如SHA引用SPA第X条）

## Phase 2: 八类责任系统提取

逐文件逐条款扫描，按L1-L8八类分类标注：

### L1 回购义务
- 关键词：回购/赎回/redemption/buyback
- 检查：回购义务人是否为创始人/触发条件/回购价格/回购期限

### L2 赔偿义务
- 关键词：赔偿/补偿/indemnify/compensate
- 检查：赔偿触发条件/赔偿上限/赔偿存续期

### L3 竞业禁止
- 关键词：竞业/禁止/同业/non-compete
- 检查：竞业范围/竞业期限/违反后果

### L4 知识产权归属
- 关键词：知识产权/专利/商标/著作权/IP/职务成果
- 检查：归属方向/历史IP转让/不侵权保证

### L5 不可撤销授权
- 关键词：授权/委托/不可撤销/irrevocable
- 检查：授权范围/授权期限/撤销条件

### L6 股权锁定/质扣
- 关键词：锁定/成熟期/转让限制/质押/lock-up/vesting
- 检查：锁定期/成熟期安排/质押范围

### L7 连带责任
- 关键词：连带/共同/jointly and severally
- 检查：连带对象/连带范围/连带份额

### L8 个人担保
- 关键词：担保/保证/guarantee
- 检查：担保对象/担保范围/担保期限

## Phase 3: 五维风险评估

对每条责任执行D1-D5评估：

| 维度 | 评估内容 |
|------|----------|
| D1 责任上限 | 无限/有限/按比例/有上限（金额） |
| D2 触发条件 | 明确/模糊/自由裁量 |
| D3 持续期间 | 永久/交割后N年/随交割终止 |
| D4 可保险性 | 不可投保/部分可投保/可投保 |
| D5 条款联动 | 多条款联动/单一条款 |

综合风险等级：3+维度为高=高 / 2维度为高=中 / 0-1维度为高=低

> **情境调节**：D1-D5 的"高/中/低"须随交易情境调节（交易阶段/创始人议价力/资产规模/轮次结构/财务依赖），每命中一个"上调因子"综合风险可上调一级，并标注调节理由（详见 `methodology.md §二`）。

## Phase 4: 条款联动性分析

1. 识别条款间交叉引用（"详见第X条""按照第Y条约定"）
2. 分析联动触发关系：
   - 回购联动反稀释（回购时反稀释调整）
   - 竞业联动股权成熟（违反竞业→未成熟股权回购）
   - 陈述联动赔偿上限（违约赔偿受上限约束）
   - 质押联动回购（质押为回购担保）
3. 绘制责任联动图

## Phase 5: 报告组装+谈判建议

1. 组装责任清单总表
2. 高风险条款专项分析（综合风险=高的条款，含情境调节后上调者）
3. **个人责任总敞口测算**（必附）：按最不利假设汇总 L1/L2/L7/L8 现金敞口 + 资产覆盖比（详见 `methodology.md §五`）
4. 谈判建议分类（须含市场基准与优先级）：
   - 必争（Must-fight）：直接威胁资不抵债（无上限回购/无限连带/无上限赔偿）
   - 可谈（Negotiable）：可设上限/缩范围/加门槛（竞业范围/历史IP排除/成熟期）
   - 接受（Accept）：市场惯例，强争无意义（1×回购/DQ赔偿100%上限/4年vesting）
   - 策略：用市场基准反驳过度主张，可谈项以替代方案（门槛/carve-out/双向化）换取
5. 列出待核查项

> **与对抗性审查分工**：责任归集量化由本技能完成；条款对抗性识别（T1-T12）由 `cap-market-adversarial-clause-analysis` 完成；含对赌现金回购的 Cap Table 量化由 `cap-market-cap-table-verify`（§十）完成。

## 自检清单

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 八类覆盖 | 遗漏某一类 | 逐类检查补充 |
| 条款编号 | 未标注编号 | 补充准确条款编号 |
| 五维评估 | 维度遗漏 | 补充缺失维度 |
| 联动分析 | 未分析交叉引用 | 补充联动分析 |
| 谈判建议 | 不可操作 | 补充具体操作建议 |
