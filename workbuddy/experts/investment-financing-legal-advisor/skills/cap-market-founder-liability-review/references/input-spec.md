# 输入规格

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| agreement_files | file[] | 是 | 交易文件（SPA/SHA/增资协议/股权转让协议/补充协议等） |
| founder_name | text | 是 | 目标创始人姓名 |
| role_context | text | 否 | 创始人角色（CEO/CTO/董事长等） |
| existing_obligations | text | 否 | 已知存量责任（增量模式时提供） |
| focus_categories | list | 否 | 聚焦分析的责任类型（L1-L8子集） |

## 输入模式

### Mode A: 单文件提取
提供一份SPA/SHA，技能提取该文件中所有创始人个人责任。

### Mode B: 多文件交叉提取
提供多份文件（SPA+SHA+补充协议+侧协议），技能交叉提取并标注每条责任的来源文件。

### Mode C: 增量提取
提供已有责任清单+新文件，技能在已有清单基础上补充新增责任。

## 文件解析

- 支持格式：PDF（可复制）/ Word / 纯文本
- 解析失败→提示提供可复制文本或Word版
- 多文件须标注文件间交叉引用关系
