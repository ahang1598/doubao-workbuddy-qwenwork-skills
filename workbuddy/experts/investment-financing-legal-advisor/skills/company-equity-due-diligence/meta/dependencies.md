# 上下游技能依赖

## 下游技能（本技能调用其做深度分析）

| 技能 | 依赖程度 | 说明 |
|------|----------|------|
| 01-起草和审查投资意向书 | 推荐 | 投前合规是尽调的轻量替代 |
| 02-股东确权与代持风险处置 | 必需 | 红旗发现代持问题→深度分析 |
| 03-公司治理诊断与合规审查 | 必需 | 红旗发现治理/关联交易问题→深度分析 |
| 04-投后股东维权与失权处置 | 推荐 | 红旗发现出资问题→失权处置 |
| 05-投融资退出方案与争议解决 | 推荐 | 红旗发现退出障碍→退出路径分析 |
| 06-投资协议审查 | 必需 | 红旗发现投资条款问题→条款审查 |
| cap-market-adversarial-clause-analysis | 推荐 | 红旗发现条款陷阱/对抗性条款→对抗分析 |
| cap-market-founder-liability-review | 推荐 | 红旗发现创始人个人责任→责任提取 |
| cap-market-cap-table-verify | 推荐 | 红旗发现股权结构/稀释问题→核验模拟 |
| cap-market-special-rights-design | 推荐 | 红旗涉及特殊权利条款设计→从零设计 |
| cap-market-multi-round-consistency | 推荐 | 多轮融资红旗→一致性比对 |

## 对比/协同技能

| 技能 | 区分点 |
|------|--------|
| 01-投资意向书 | 完整尽调 vs 投前合规快筛 |
| 02-05专项技能 | 全面尽调 vs 单一维度深度分析 |
| 5个P0资本技能 | 全面尽调 vs 专项深度分析（条款/责任/股权/设计/一致性） |
