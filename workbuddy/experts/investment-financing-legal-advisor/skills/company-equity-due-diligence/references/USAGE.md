# 使用说明

## 快速开始

### 场景1：投资并购尽调
```
用户：我要收购某科技公司，需要全面尽调
```
技能执行投资并购场景路由→全面深度尽调→十部分全覆盖→红旗发现调用专项技能。

### 场景2：IPO尽调
```
用户：公司准备上市，帮我梳理股权方面需要整改的问题
```
技能执行IPO场景路由→最高标准→历史沿革全程+合规逐项→输出整改建议。

### 场景3：贷款融资评估
```
用户：银行要求对抵押标的公司做股权评估
```
技能执行贷款融资场景路由→中等偏财务→重点核查股权质押/偿债能力。

### 场景4：战略合作评估
```
用户：准备和这家公司合资，先做股权背景调查
```
技能执行战略合作场景路由→中等偏治理→重点核查控制权/退出机制。

## 使用建议

1. 提供目标公司准确全称
2. 明确尽调场景（影响深度和覆盖范围）
3. 确认天眼查MCP是否可用（不可用则降级）
4. 提供已获取的内部资料（加速尽调）
5. 关注红旗发现→须专项技能深度分析
6. 尽调结果必须转化为合同附件
