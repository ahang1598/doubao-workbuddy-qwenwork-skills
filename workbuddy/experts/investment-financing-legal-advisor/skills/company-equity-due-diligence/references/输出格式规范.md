# 输出格式规范（公司股权尽职调查）

> SKILL.md 正文只保留格式要点；各格式的完整规范、版式、免责声明落位、无 emoji 安全网在此文件。
> 尽调报告是**正式律所实务交付物**，面向律师/投委会/客户——多数本地无 Markdown 工具，
> 必须提供 Word 正式报告 + Excel 附表 + 对外 PDF，Markdown 仅作在线预览。

---

## 0. 适用性映射（本技能）

| 用户要什么 | 给什么格式 |
|---|---|
| 在线看 / 预览 / 复制（默认） | Markdown 对话内预览（含 Mermaid 股权图） |
| 正式尽调报告 / 报投委会 / 下载留档 | **Word(.docx)** 律所实务尽调报告（十大部分+附表） |
| 16 维核查清单 / 五张附表 / 可筛选可排序 | **Excel(.xlsx)** 核查清单 + 附表一~五 |
| 对外提交 / 客户阅读 / 打印归档 | **PDF**（由 Word 转） |

触发下载的词：「下载/导出/生成 Word/Excel/PDF/出正式报告/给客户/报投委会」。默认先出 Markdown，再按需生成文件。

---

## 1. 免责声明模板（D2 强制，每种格式都要有）

固定文案（沿用报告末尾五条免责条款），并在正式报告首部附一句：
```
本尽调报告由 AI 辅助生成，仅从法律角度提示重大影响问题，供律师/委托人复核，不构成正式法律意见，
不含估值/定价/谈判策略；数据来源于公开渠道及公司提供资料，本所不对文件真实性独立验证。
```
落位：Word 释义页前/标题正下方 + 报告末尾完整五条；Excel 第 1 行说明区；PDF 同 Word；Markdown 开头引用块。

---

## 2. 报告结构（律所实务，所有格式一致）

释义 → 股权结构图 → 第一部分 主要法律问题及解决建议（仅列 `[红旗]`）→ 第二~十部分系统核查 → 附件清单（附件一+附表一~五）→ 免责条款。
- 第一部分每项含：类别 \| 事实/存在问题 \| 解决建议 \| 依据来源 \| 不确定性说明。
- 依据来源标签：`[用规]` / `[要点]` / `[法规]` / `[惯例]`（至少标一类）。
- 仅单一数据源且无法交叉验证的发现标 `【待核实】` + 来源 + 时间戳。

---

## 3. Markdown 规范（在线默认）

| 要素 | 规范 |
|---|---|
| 标题层级 | 报告题 `#`；十大部分各 `##`；分项 `###` |
| 股权结构图 | Mermaid `graph TD`，穿透至最终权益持有人 |
| 红旗标注 | 文字 `[红旗]`；**本技能各下载格式一律不使用 emoji** |
| 依据标签 | `[用规]`/`[要点]`/`[法规]`/`[惯例]` 写在条目内 |
| 待核实 | `【待核实】` + 数据来源 + 时间戳 |

---

## 4. Word(.docx) 规范（正式尽调报告）

| 要素 | 规范 |
|---|---|
| 字体 | 正文宋体小四 1.5 倍行距；标题黑体；首部自动目录；逐页页码 |
| 结构 | 严格按第 2 节，十大部分用一级标题样式，便于目录与跳转 |
| 股权结构图 | Mermaid 转为图片插入；无法渲染时改用层级表格/缩进列表呈现穿透关系 |
| 红旗/风险 | 纯文字 `[红旗]`/`[高风险]`/`[中风险]`/`[低风险]`，无色块/emoji |
| 表格 | 股东出资表、股本沿革变更前后股比表、关联交易表等一律用 Word 表格 |
| 依据标签 | `[用规]`/`[要点]`/`[法规]`/`[惯例]` 方括号文字，禁用 emoji |
| 免责声明 | 标题正下方一句 + 末尾完整五条 |
| 命名 | `尽调报告_{目标公司简称}_{YYYYMMDD}.docx` |
| 保存 | `/mnt/user-data/outputs/` |

---

## 5. Excel(.xlsx) 规范（核查清单 + 附表）

### 5.1 16 维核查清单（Sheet「核查清单」）
- 表头（冻结）：`编号 | 核查维度 | 民事 | 行政 | 刑事 | 对应报告部分 | 发现摘要 | 风险等级 | 依据标签 | 待核实(来源/时间戳)`
- `民事/行政/刑事` 列用文字 `涉/不涉`（替代复选框，不用 emoji）；`风险等级` 枚举 `高/中/低`。

### 5.2 五张附表（各一 Sheet）
- 附表一 股权激励计划详情 / 附表二 房屋租赁汇总 / 附表三 专利权·商标权详情 / 附表四 社保公积金缴纳明细 / 附表五 重大合同清单。
- 每表首行标题 + 数据来源说明；逐行一条目；单元格内禁用 emoji。
- 命名 `尽调附表_{目标公司简称}_{YYYYMMDD}.xlsx`，存 `/mnt/user-data/outputs/`。

---

## 6. PDF 规范（对外提交/归档）

- 由定稿 Word 转 PDF，保留目录、页码、表格、股权图；不另起排版。
- 命名 `尽调报告_{目标公司简称}_{YYYYMMDD}.pdf`。

---

## 7. 状态/分级一律用文字标签（无 emoji 安全网）

| 外部符号 | 改写为 |
|---|---|
| [红旗] / [高风险] / [中风险] / [低风险] | `[红旗]` / `[高风险]` / `[中风险]` / `[低风险]` |
| [已核实] / 【待核实】 / [不符] | `[已核实]` / `【待核实】` / `[不符]` |

---

## 8. 生成机制

- 复用平台文档技能（docx / xlsx / pdf）生成；PDF 由 Word 转，附表由 Excel 承载。
- 运行时不支持时回退 Markdown 并告知，不杜撰文件路径。
- 法条引用须经现行有效性核验；单一来源未交叉验证项必须 `【待核实】`，不得在正式件中略去。
- 任一格式对外件须先过执业安全红线（免责声明、禁用词、无 emoji、依据标签）。
