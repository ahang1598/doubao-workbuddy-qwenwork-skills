# 天眼查MCP数据采集流程

## 一、前置检查

调用前先检测 `mcp__tianyancha__search_companies` 是否可用。如不可用，引导用户访问 https://mcp.tianyancha.com/ 注册获取API Key（每日100次免费调用），并配置到 `~/.claude/.mcp.json`：

```json
"tianyancha": {
  "type": "sse",
  "url": "https://mcp-service.tianyancha.com/sse",
  "headers": {
    "Authorization": "Bearer <用户提供的key>"
  }
}
```

## 二、采集流程

### 步骤1：搜索企业获取company_id

```
search_companies(keyword="企业全称") → 获取company_id（gid/cgid）
同时提取：联系方式（电话/邮箱/官网/地址）
```

### 步骤2：并行调用各维度工具

各维度工具相互无依赖，应一次性并行发起：

| MCP工具 | 获取内容 | 对应报告部分 |
|---------|---------|------------|
| `get_company_info(company_id)` | 工商登记全量信息 | 第二部分 基本信息 |
| `get_company_shareholders(company_id)` | 股东名称/类型/持股比例/出资金额 | 第二部分·股权结构 |
| `get_company_personnel(company_id)` | 董监高名单及职务 | 第二部分·董监高 |
| `get_company_risks(company_id, risk_type="自身风险")` | 司法案件/开庭公告/裁判文书/行政处罚 | 第十部分 |
| `get_company_risks(company_id, risk_type="周边风险")` | 关联方风险传导 | 第四部分+第十部分 |
| `get_company_risks(company_id, risk_type="预警提醒")` | 实时风险预警 | 第十部分 |
| `get_company_risks(company_id, risk_type="历史风险")` | 历史风险记录 | 第十部分 |
| `search_bidding_info(keyword="企业名称")` | 招标公告/中标结果 | 第三部分 业务情况 |

> 人员简介如需深入，可从personnel返回中提取`hcgid`，再调用`get_person_profile(hcgid)`查询。

### 步骤3：处理MCP超时

- 单次MCP调用超时阈值：30秒
- 超时处理：跳过该工具并在报告中标注数据缺失

## 三、MCP降级路径（MCP不可用时）

当天眼查MCP不可用时，降级为**核查清单框架+引导用户自助采集**：

1. 输出完整的十部分核查框架（见 `dd-framework.md`）
2. 引导用户通过以下公开数据源自助采集：

| 数据源 | 网址 | 适用于 |
|--------|------|--------|
| 国家企业信用信息公示系统 | http://www.gsxt.gov.cn/ | 工商登记/年报/行政处罚/经营异常 |
| 中国裁判文书网 | https://wenshu.court.gov.cn/ | 涉诉案件详情/判决书全文 |
| 中国执行信息公开网 | http://zxgk.court.gov.cn/ | 失信被执行人/限制消费令 |
| 信用中国 | https://www.creditchina.gov.cn/ | 行政处罚/信用评级/联合惩戒 |
| 国家知识产权局 | https://www.cnipa.gov.cn/ | 专利/商标/著作权权属及状态 |
| 中国版权保护中心 | https://www.ccopyright.com.cn/ | 软件著作权登记 |
| 不动产登记中心 | 各地不动产登记中心 | 土地/房产权属及抵押 |
| 全国认证认可信息平台 | http://cx.cnca.cn/ | 资质认证/许可证 |
| 各地生态环境局网站 | 各地生态环境局 | 环保处罚/环评批复 |

3. 汇总MCP无法覆盖的维度（知识产权/社保/税务/不动产/环保）为一次性待补充信息清单

## 四、信息源优先级

当多源数据冲突时，按以下顺序采信：

1. **工商登记/裁判文书/不动产登记**（官方登记，公示公信力最高）
2. **征信报告/税务完税证明**（权威第三方出具）
3. **天眼查聚合数据**（商业数据库，存在滞后和不完整可能）
4. **公司内部提供资料**（须与外部数据源交叉验证）
5. **公司管理层口头说明**（仅作参考，不可作为尽调结论唯一依据）

## 五、内部资料清单（需目标公司配合提供）

| 资料类别 | 具体文件 |
|---------|---------|
| 公司章程及修正案 | 现行章程+历次修正案全文 |
| 股东名册 | 公司内部股东名册（与工商登记交叉比对） |
| 股东协议/代持协议 | 所有股东间协议、一致行动协议、对赌/VAM协议 |
| 历次股东会/董事会决议 | 设立至今的全部决议 |
| 股权激励文件 | 激励计划/授予协议/行权记录 |
| 重大合同 | 贷款/担保/战略合作/关联交易/核心客户/核心供应商合同 |
| 财务资料 | 审计报告/财务报表/应收账款明细/应付账款明细 |
| 劳动关系资料 | 劳动合同台账/社保公积金缴纳记录/劳动争议记录/竞业限制协议 |
| 知识产权清单 | 专利/商标/著作权登记证书及年费缴纳记录 |
| 资质证照 | 行业许可证/特许经营证/资质证书 |
| 税务资料 | 完税证明/税务稽查结论/税收优惠文件 |
