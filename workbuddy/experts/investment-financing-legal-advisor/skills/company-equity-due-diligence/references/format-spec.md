# 输出格式规范

## 格式严肃度：C-Professional

- 无emoji
- 法条引用须联网核实+标注条文性质
- 律所尽调实务结构报告

## 报告结构

```
释义（简称定义）
股权结构图（Mermaid graph TD）
第一部分 主要法律问题及解决建议
第二部分 基本信息
...
第十部分 重大诉讼/仲裁/行政处罚
附表
```

## 每部分格式

| 核查项 | 核查结果 | 风险评级 | 信息来源 | 依据来源标签 |
|--------|----------|----------|----------|-------------|
| | | 正常/需关注/[红旗] | | [用规]/[要点]/[法规]/[惯例] |

## 免责声明（每次对外输出必附）

> 本尽调报告为AI辅助的初步尽职调查分析，供律师/法务复核，不构成正式法律意见；具体法律判断应以现行有效法律法规及持证律师意见为准。
