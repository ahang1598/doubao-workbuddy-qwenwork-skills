# 核心方法论

## 一、九维一致性检查框架

| 维度 | 检查内容 | 典型冲突/叠加 | 关联法条 | 方法论要点 |
|------|----------|--------------|----------|-----------|
| C1 反稀释 | 各轮反稀释方式是否一致 | A轮加权平均+B轮完全棘轮→B轮优先 | 新公司法第84条（股权调整机制）/民法典合同编 | 反稀释调整涉及股权比例变更，须审查调整后的股权转让是否触发优先购买权程序；完全棘轮与加权平均的差异须量化计算转换价格影响 |
| C2 清算优先权 | 多轮优先权叠加分配顺序 | 3轮各1倍参与型→投资人拿走大部分 | 新公司法第224条（定向减资与回购退出）/九民纪要第5-6条 | 参与型与非参与型清算优先权的倍数陷阱须逐轮量化；多轮叠加后须模拟退出场景计算各方实际所得比例 |
| C3 董事会席位 | 各轮委派董事累计 | A轮2席+B轮2席→投资人超半数 | 新公司法第67条（董事会职权） | 董事席位超额导致投资人实质控制董事会，须审查各轮委派总数是否超50%；投资人控制董事会后保护性条款否决权可能被滥用 |
| C4 回购义务人 | 各轮回购义务人是否一致 | A轮创始股东+B轮目标公司→冲突 | 九民纪要第5-6条（对赌协议履行）/新公司法第224条（定向减资） | 目标公司回购须完成减资程序（第224条），创始股东回购无须减资但受偿能力有限；多轮义务人不一致导致执行路径分化 |
| C5 优先购买权 | 各轮行权顺序 | A轮和B轮都要求优先→顺序冲突 | 新公司法第84条（优先购买权） | 多轮投资人同时主张优先购买权时行权顺序须明确；须审查各轮是否约定按比例行使或顺序优先 |
| C6 信息权 | 各轮信息权范围 | A轮月报+B轮季报→标准不一 | 新公司法第57条（股东知情权含穿透全资子公司） | 信息权范围不得低于法定知情权底线（第57条）；月报/季报/年报须统一标准，否则执行成本过高 |
| C7 保护性条款 | 各轮一票否决权范围 | A轮和B轮否决权范围重叠 | 新公司法第67条（董事会职权范围） | 保护性条款一票否决权范围须审查是否侵蚀董事会法定职权（第67条）；多轮否决权叠加可能导致公司决策瘫痪 |
| C8 跟售/拖售权 | 各轮行权条件 | A轮跟售条件比B轮宽松 | 民法典合同编（合同效力与履行） | 跟售权在不同轮次投资人之间的顺位冲突须明确触发比例与行权顺序；拖售权的估值门槛和同意比例须审查是否合理 |
| C9 最惠国条款(MFN) | 各轮是否含MFN及适用范围 | A轮MFN自动适用后续轮更优条款→B轮更优条件回溯惠及A轮 | 民法典合同编（合同条款效力） | MFN使早期轮次投资人自动享受后续轮次更优条件，导致"条款回溯"与权利叠加；须审查适用范围（仅经济条款 or 含治理条款）、是否设例外（善意第三方交易/后续轮同等估值豁免）、回溯触发条件与最惠待遇定义 |

## 二、叠加效应分析方法

### 清算优先权叠加计算

假设退出估值X元：

```
Step 1: 各轮投资人按优先权倍数取回投资额
  A轮投资人：投资额×1倍 = a
  B轮投资人：投资额×1倍 = b
  C轮投资人：投资额×1倍 = c

Step 2: 剩余金额按持股比例分配
  剩余 = X - (a+b+c)
  创始人所得 = 剩余 × 创始人持股比例
  A轮投资人额外 = 剩余 × A轮持股比例（参与型）
  ...

Step 3: 输出各方实际获得
  A轮投资人总额 = a + 额外分配
  B轮投资人总额 = b + 额外分配
  创始人总额 = 剩余 × 持股比例
```

**参与型与非参与型的倍数陷阱**：

| 退出估值 | A轮1倍参与型所得 | A轮1倍非参与型所得 | 差异 |
|----------|-----------------|-------------------|------|
| 5000万（低于总投资额） | 1000万（优先取回） | 1000万（优先取回） | 0 |
| 1亿 | 1000万+1200万=2200万(22%) | 1000万(10%) | 差1200万 |
| 3亿 | 1000万+5400万=6400万(21.3%) | 1000万(3.3%) | 差5400万 |

> 参与型在中等估值退出时差异最大——投资人既拿回投资额又参与剩余分配。建议每轮设参与上限（如投资额2倍封顶），避免投资人获得超额回报。

### 反稀释条款叠加导致创始人股权被稀释至失控的真实案例推演

**场景**：A轮投资1000万/持股20%，B轮投资3000万/持股15%，C轮后公司以低于B轮估值的D轮融资续命。

```
A轮：加权平均反稀释 → 调整后持股约22-25%
B轮：完全棘轮反稀释 → 调整后持股约18-20%
创始人原始持股65% → 经三轮反稀释调整后降至约40-45%

若D轮继续下调估值：
  B轮完全棘轮再次触发 → B轮持股升至25%+
  创始人持股降至35%以下 → 失去控制权
```

> 关键风险：完全棘轮对创始人杀伤力远大于加权平均。多轮叠加后创始人股权可能从65%跌至35%以下，丧失对公司控制权。建议所有轮次统一采用加权平均，禁止完全棘轮。

### 董事会席位累计

```
董事会总席位 = N
各轮投资方委派 = A席 + B席 + C席
累计比例 = (A+B+C) / N
如累计比例 > 50% → 投资人控制董事会风险
```

### 跟售/拖售权在不同轮次投资人之间的顺位冲突

```
拖售权触发：A轮持股20%要求拖售（门槛为30%同意）→ B轮持股15%反对拖售
  冲突1：拖售同意比例计算口径（按持股比例or按投资人数量）
  冲突2：拖售后各轮投资人退出分配顺序（按清算优先权顺序or按持股比例）
  冲突3：跟售权的触发阈值与拖售权是否联动
```

> 建议：明确拖售权的同意比例计算口径（持股比例），明确各轮退出分配顺序（清算优先权顺序优先），明确跟售权与拖售权的联动机制。

## 三、跨轮风险识别

| 风险类型 | 说明 | 应对 |
|----------|------|------|
| 优先权冲突 | 多轮优先权顺序不明确 | 明确各轮优先顺序 |
| 叠加过度 | 叠加后投资人获得过多 | 设定参与上限 |
| 控制权丧失 | 董事席位累计超半数 | 限制投资方委派总数 |
| 执行困难 | 各轮标准不一无法执行 | 统一各轮标准 |

## 四、多轮审查常见失败模式表

| 编号 | 失败模式 | 症状 | 后果 | 对策 |
|------|---------|------|------|------|
| FM-1 | 漏审叠加效应 | 仅逐轮审查未叠加计算 | 清算退出时创始人所得远低于预期 | 每次审查须模拟退出场景量化叠加影响 |
| FM-2 | 忽略清算优先权参与型与非参与型差异 | 将"1倍清算优先权"等同处理 | 参与型投资人获得超额回报（2-3倍投资额） | 明确每轮类型，参与型须设上限 |
| FM-3 | 董事席位超额 | 各轮委派董事总数超半数未识别 | 投资人实质控制董事会，公司决策偏离创始人意图 | 限制投资方委派总数不超过董事会1/3 |
| FM-4 | 信息权穿透过度 | B轮要求穿透全资子公司+关联方 | 公司运营成本激增，商业秘密泄露风险 | 信息权范围统一为母公司+全资子公司，不扩展至关联方 |
| FM-5 | 优先购买权顺位冲突 | A轮和B轮均要求"最优先"购买权 | 股权转让时无法确定行权顺序，交易僵局 | 约定按轮次倒序（后轮优先）或按持股比例分配 |
| FM-6 | 保护性条款范围蔓延 | A轮5项否决→B轮8项→C轮12项 | 公司日常经营决策须逐一征询3轮投资人同意 | 合并否决权清单去重，设否决权上限（不超过10项） |
| FM-7 | 跟售/拖售权顺位冲突 | A轮跟售条件宽松+B轮拖售门槛低 | 拖售触发后各轮退出顺序不清，投资人互相博弈 | 明确拖售同意比例口径和各轮退出分配顺序 |
| FM-8 | 反稀释基数口径不一致 | A轮按投前估值调整+B轮按投后估值调整 | 同一轮下调估值下两轮调整幅度差异巨大 | 统一反稀释计算口径（建议投前估值口径） |
| FM-9 | 回购义务人不一致 | A轮创始人回购+B轮目标公司回购 | 目标公司回购须减资程序（第224条），创始人回购无须但偿付能力有限 | 统一为创始人回购+目标公司连带担保 |
| FM-10 | 期权池预留口径遗漏 | 各轮持股比例未含期权池预留 | 20%/15%/65%比例不自洽（合计100%但含期权池后超出） | 各轮持股比例须标注"含/不含期权池"，期权池须单独列示 |
| FM-11 | 最惠国条款(MFN)遗漏 | 未检查各轮MFN及其回溯适用 | B轮给出更优反稀释/优先权→自动回溯惠及A轮，创始人实得被二次稀释却未提示 | 逐轮检查MFN条款；标注适用范围（经济/治理）、例外情形与最惠待遇定义；评估回溯后的叠加影响 |
