# 术语规范

| 术语 | 说明 |
|------|------|
| 多轮融资 | 公司经历多轮股权融资（A轮/B轮/C轮...） |
| 反稀释 | Anti-dilution；加权平均/完全棘轮 |
| 清算优先权 | Liquidation Preference；参与型/非参与型 |
| 叠加效应 | 多轮条款叠加后的累积效果 |
| 跨轮冲突 | 不同轮次间条款不一致导致的冲突 |
| 董事会席位累计 | 各轮投资方委派董事数量之和 |
| 优先购买权 | Right of First Refusal |
| 保护性条款 | Protective Provisions；一票否决权 |
| 跟售权 | Tag-along Right |
| 拖售权 | Drag-along Right |
| 最惠国条款 | MFN / Most Favored Nation；后续轮次更优条款自动惠及早期投资人的回溯机制 |
| 条款回溯 | MFN触发后后续轮次优惠条件自动适用于前期轮次投资人的效果 |
