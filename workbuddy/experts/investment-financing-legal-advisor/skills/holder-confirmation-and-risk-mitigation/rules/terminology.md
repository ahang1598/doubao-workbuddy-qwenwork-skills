# 术语规范

| 术语 | 规范表述 | 说明 |
|------|----------|------|
| 代持 | 股权代持 | 实际出资人委托名义股东代为持有股权 |
| 名义股东 | 名义股东 | 代持关系中的登记股东 |
| 实际出资人 | 实际出资人 | 代持关系中的真实出资人 |
| 显名 | 显名 | 实际出资人变更为登记股东 |
| 让与担保 | 让与担保 | 债务人将股权转移至债权人名下作为担保 |
| 善意取得 | 善意取得 | 民法典第311条；善意+合理价格+已登记 |
| 外观主义 | 外观主义 | 以工商登记为准保护善意第三人 |
| 三层递进 | 三层递进验证法 | 出资证明书→股东名册→工商登记 |
| 三层收紧 | 代持效力三层判断 | 一般有效→管理性规定→公共利益无效 |
| 半数同意 | 其他股东半数以上同意 | 人数半数，非表决权半数 |
| 确权之诉 | 确权之诉 | 确认股东资格的诉讼，不具对外公示效果 |
| 显名诉讼 | 显名诉讼 | 请求变更股东登记的诉讼 |
