# 风险规则框架

## RC-01: 代持效力一刀切

| 属性 | 值 |
|------|-----|
| rule_id | RC-01 |
| trigger_condition | 断言"代持无效"或"代持有效"未分层判断 |
| severity | 阻断 |
| effect_on_output | 须按三层收紧判断（一般有效→管理性规定→公共利益无效） |

## RC-02: 内外风险遗漏

| 属性 | 值 |
|------|-----|
| rule_id | RC-02 |
| trigger_condition | 仅分析内部关系，遗漏外部风险 |
| severity | 阻断 |
| effect_on_output | 须补充三类外部风险（转让/执行/破产） |

## RC-03: 显名条件混淆

| 属性 | 值 |
|------|-----|
| rule_id | RC-03 |
| trigger_condition | 将"知晓代持"等同于"同意显名" |
| severity | 阻断 |
| effect_on_output | 须严格区分：知晓不等于同意；须评估默示同意证据 |

## RC-04: 第69条扩大适用

| 属性 | 值 |
|------|-----|
| rule_id | RC-04 |
| trigger_condition | 将担保制度解释第69条扩大适用到一般代持 |
| severity | 警告 |
| effect_on_output | 须标注"仅适用让与担保，不适用一般代持" |

## RC-05: 旧法条引用

| 属性 | 值 |
|------|-----|
| rule_id | RC-05 |
| trigger_condition | 引用合同法第52条/物权法第106条等已废止法条 |
| severity | 阻断 |
| effect_on_output | 须替换为民法典第153条/第311条 |

## RC-06: 敞口未量化

| 属性 | 值 |
|------|-----|
| rule_id | RC-06 |
| trigger_condition | 代持风险分析未量化经济敞口（标的股权价值×代持比例） |
| severity | 警告 |
| effect_on_output | 须补充对内/对外敞口测算+分级处置决策（§七） |
