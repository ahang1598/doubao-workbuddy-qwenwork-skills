## 一、代持效力三层判断（V04）

### 第一层：一般原则——原则上有效

**法条基础**：《公司法解释三》第24条第1款

> 有限责任公司的实际出资人与名义出资人订立合同，约定由实际出资人出资并享有投资权益，以名义出资人为名义股东，实际出资人与名义股东对该合同效力发生争议的，如无合同法第52条（现民法典第153条）规定的情形，人民法院应当认定该合同有效。

**三个注意事项**（来自书中）：
1. **代持协议名称不限**：隐名投资合同/代持股合同/信托持股协议——只要实质内容为"实际出资人出资+名义股东代持+收益归实际出资人"即可。
2. **合意形式不限**：书面/口头/事实合意均可——但书面协议是保护自身权益的最基本要求。
3. **投资权益≠股东权益**：实际出资人只能通过名义股东**间接**行使股东权益。

### 第二层：特殊身份——违反管理性规定≠无效

**公务员代持**（书中重点分析）：
- 《公务员法》第59条第(16)项：公务员不得从事或参与营利性活动
- 该条文属**管理性规范**，非效力性规范
- 协议不一定无效，但公务员须承担行政处分责任
- 北京市一中院(2015)一中民(商)终字第5296号：持股协议书不因公务员身份而无效

**退休公务员**受限期间：
- 原领导成员/县处级以上：离职3年内不得在原业务相关企业任职
- 其他公务员：离职2年内

### 第三层：特殊行业——损害公共利益→无效

**判断标准**（最高院(2017)最高法民终529号——代持保险公司股权案）：
1. 部门规章禁止代持的规定是否具有**实质正当性与合法性**
2. 违反该规定是否将**损害社会公共利益**
3. 即使仅违反部门规章（非法律/行政法规），若损害金融安全+社会公共利益→无效

**高风险行业清单**：
| 行业 | 代持效力 | 关键依据 |
|---|---|---|
| 保险 | 无效 | 《保险公司股权管理办法》第31条+最高院判例 |
| 银行 | 极大可能无效 | 《商业银行股权管理暂行办法》 |
| 证券 | 极大可能无效 | 《证券公司股权管理规定》 |
| 上市公司 | 无效（近年强监管趋势） | 损害资本市场交易秩序+金融安全 |
| 一般非金融行业 | 原则上有效 | 民法典第153条 |

## 二、内外有别原则（V06）

### 核心逻辑

```
对内关系（出资人 vs 名义股东）          对外关系（涉及第三人）
┌────────────────────────┐      ┌────────────────────────┐
│ 实质重于形式              │      │ 外观主义优先              │
│ 尊重当事人真实意思          │      │ 保护善意第三人信赖利益     │
│ 代持协议有效              │      │ 以工商登记/股东名册为准    │
│ 实际出资人可依据协议主张权益   │      │ 第三人可依据登记内容主张权利 │
└────────────────────────┘      └────────────────────────┘
```

### 三类外部风险

| 风险类型 | 法律规则 | 后果 | 防范 |
|---|---|---|---|
| **名义股东擅自转让股权** | 善意取得（民法典第311条）：善意+合理价格+已登记→受让人取得股权 | 实际出资人只能向名义股东追偿，不能追回股权 | 代持协议中设置高额违约金条款+股权质押给实际出资人 |
| **名义股东债权人强制执行** | 外观主义——股权登记在名义股东名下→债权人有权申请执行 | 代持股权可能被执行 | 确权之诉固定事实+提前告知债权人代持事实（破坏善意） |
| **名义股东破产** | 代持股权属于名义股东的破产财产（外观主义，江西高院(2017)赣民终255号） | 实际出资人只能以普通债权人身份申报债权 | 代持协议中约定"名义股东破产时实际出资人享有取回权"（效力有限） |

### 担保制度解释第69条——适用范围有限

> 股东以将其股权转移至债权人名下的方式为债务履行提供担保，公司或者公司的债权人以股东未履行或者未全面履行出资义务、抽逃出资等为由，请求作为名义股东的债权人与股东承担连带责任的，人民法院不予支持。

**适用前提**：股权让与担保（为债务提供担保而转移股权）
**不适用**：一般股权代持（非担保目的）
**核心价值**：让与担保情境下名义股东不承担出资瑕疵连带责任——但**一般代持场景下名义股东仍可能承担**。

## 三、显名路径设计（子流程C）

### 3.1 法定条件："其他股东半数以上同意"

| 要点 | 具体规则 |
|---|---|
| "半数"含义 | **人数半数**，非表决权半数 |
| 明示同意 | 其他股东出具书面同意文件——最稳妥 |
| 默示同意 | 参与经营管理从未异议+诉讼中法院征询时表示同意 |
| 重要区分 | **知晓代持** ≠ **同意显名**——知晓是消极事实（知道了没反对），同意是积极意思表示 |
| 严格标准 | 法院"宜采用较为严格的标准，不得随意扩大解释" |

### 3.2 两条互补路径

**路径一：显名诉讼**
- 被告：标的公司（《公司法解释三》第21条）
- 第三人：与争议股权有利害关系的人（其他股东）
- 管辖：公司住所地法院（《民事诉讼法》第26条）
- 级别管辖：按股权价值确定诉讼标的额
- 诉讼时效：不适用（确认之诉，主流观点）

**路径二：确权之诉（先行固定事实）**
- 适用场景：其他股东不同意显名
- 目的：固定代持事实和股权归属，让其他股东知晓
- 价值：约束其他股东协助名义股东处分股权
- 局限：**无对外公示效果**——不能替代显名登记，不能对抗善意第三人

**推荐策略**：先确权→等待时机→启动显名（时机：核心股东退出/公司增资/其他股东态度转变）

### 3.3 投资前保护措施（"三件套"）

1. **书面协议**：签订书面代持/投资协议，明确资金性质（股权vs借款）、代持目的、显名条件
2. **出资凭证附言**：资金汇转时在银行凭证添加用途附言（如"XX公司股权投资款，由XX代持"）
3. **沟通留痕**：留存参与公司治理的全部记录（股东会通知/表决记录/邮件/微信/会议纪要）
