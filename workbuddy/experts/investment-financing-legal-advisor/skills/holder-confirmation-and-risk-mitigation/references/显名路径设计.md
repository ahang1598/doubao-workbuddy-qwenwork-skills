# 显名路径设计

## 一、法定条件

### "其他股东半数以上同意"

- "半数"指**人数半数**，非表决权半数
- 明示同意：其他股东出具书面同意文件（最稳妥）
- 默示同意：参与经营管理而其他股东从未异议+诉讼中法院征询时表示同意
- **知晓代持事实不等于同意显名**（书中明确区分）

### 条件成就判断

| 情形 | 条件是否成就 | 下一步 |
|------|------------|--------|
| 其他股东出具书面同意 | 成就 | 直接启动显名诉讼 |
| 其他股东知晓但未表态 | 未成就 | 收集默示同意证据→评估诉讼可行性 |
| 其他股东明确反对 | 未成就 | 转确权之诉策略 |

## 二、两条互补路径

### 路径一：显名诉讼

| 要素 | 内容 |
|------|------|
| 被告 | 标的公司 |
| 第三人 | 其他股东 |
| 管辖 | 公司住所地法院 |
| 级别管辖 | 按股权价值确定 |
| 诉讼时效 | 不适用诉讼时效（确认之诉，主流观点） |
| 适用条件 | 其他股东同意或默示同意 |

### 路径二：确权之诉+固定事实

| 要素 | 内容 |
|------|------|
| 目的 | 固定代持事实和股权归属 |
| 效果 | 约束标的公司和其他股东的协助处分行为 |
| 局限 | **无对外公示效果**，不能完全替代显名 |
| 适用条件 | 其他股东不同意显名时的过渡策略 |

## 三、风险缓释方案（显名前过渡保护）

1. **书面代持协议**：明确资金性质+代持目的+显名条件
2. **资金汇转凭证**：添加用途附言（"代[公司名]股权出资款"）
3. **参与治理记录**：留存参与公司治理的全部沟通记录
4. **同意文件**：条件适当时请求其他股东出具默示/明示同意文件
5. **股权质押**：名义股东将代持股权质押给实际出资人（增加一道保障）

## 四、路径选择决策树

```
其他股东半数以上同意？
├── 是 → 显名诉讼（路径一）
│         └── 以标的公司为被告，其他股东为第三人
└── 否 → 确权之诉+固定事实（路径二）
          └── 固定代持事实→通知其他股东→收集默示同意证据
              └── 时机成熟后启动显名诉讼
```
