# 使用说明

## 快速开始

### 场景1：确认股东资格
```
用户：我是实际出资人，但工商登记上没有我的名字，我怎么确认股东身份？
```
技能执行子流程A（三层递进验证+穿透实质审查），输出股东资格确认意见。

### 场景2：代持风险分析
```
用户：我和朋友签了代持协议，他帮我持有某公司10%股权，这个协议有效吗？有什么风险？
```
技能执行子流程B（代持效力三层判断+内外风险敞口评估），输出代持风险分析报告。

### 场景3：显名路径设计
```
用户：我是实际出资人，现在想把股权登记到自己名下，怎么操作？
```
技能执行子流程C（显名条件判断+路径选择+风险缓释），输出显名路径方案。

### 场景4：名义股东擅自转让
```
用户：名义股东未经我同意把股权卖了，受让人已经登记了，我怎么办？
```
技能核查受让人是否构成善意取得，输出应对方案。

## 使用建议

1. 提供完整代持协议文本，分析更精准
2. 标注标的公司所属行业（金融行业代持风险更高）
3. 提供其他股东是否知晓/同意代持的描述
4. 关注待核查项，须由持证律师核实
