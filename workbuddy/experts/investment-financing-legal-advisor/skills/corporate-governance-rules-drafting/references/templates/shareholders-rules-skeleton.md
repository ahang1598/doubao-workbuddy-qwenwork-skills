## 章节骨架（11章完整版 / 精简版可省略标记[*]的章节）

### 第一章 总则

**必含条款**：
1. 制定目的：规范股东会的议事方式和表决程序，保障股东依法行使权利
2. 制定依据：2023年修订《中华人民共和国公司法》第62-67条 + {公司章程}
3. 适用范围：本规则适用于{公司全称}股东会的召集、召开、审议、表决、记录全过程
4. 章程关系：本规则为公司章程的配套文件，与章程不一致的以章程为准

**条件性条款**（有限公司/股份公司差异）：
- [ ] 【股份公司】增加"依据《上市公司治理准则》"（如拟上市）
- [ ] 【股份公司】增加累积投票制的适用说明（如有）

**起草注释**：
- 第一条"制定目的"避免空话（如"为完善公司治理结构，规范公司运作"），聚焦"议事和表决"
- 第二条须确认公司是否已有现行有效的章程

---

### 第二章 股东会的职权

**必含条款**：
1. 法定职权（引用《公司法》第63条，不复述全文）
2. 章程增加的职权（如章程有特别规定）

**条件性条款**：
- [ ] 【一人公司】本章简化——一人公司不召开股东会，由股东直接作出书面决定

**起草注释**：
- ⚠️ **2023修订重大变更**：旧§37(一)"经营方针和投资计划"、(五)"年度财务预算决算方案"已被删除，不可写入股东会职权清单。§63法定职权共9项，不得照搬旧法11项
- 不抄法条全文——引用"依据《公司法》第63条"
- 章程增加的职权须与法定职权不冲突（如章程不可剥夺股东知情权）

---

### 第三章 股东权利行使

**必含条款**：

**第一节 提案权**
1. 提案主体：有限公司股东（章程约定提案权门槛）+ 股份公司单独或合计持股≥3%的股东（提前10日书面提交）
2. 提案受理：董事会（或召集人）收到提案后{5}个工作日内审查
3. 提案不予受理的情形：不属于股东会职权范围/违反法律法规或章程/未在通知发出前送达
4. 不予受理的救济：召集人在收到提案后{3}个工作日内书面说明理由

**第二节 质询权**
5. 股东在股东会上有权就会议议题及公司经营事项向董事、监事、高级管理人员提出质询
6. 被质询人应当当场或在{5}个工作日内书面答复；当场无法完整答复的，应在会后书面补充

**第三节 知情权行使**
7. 股东有权依据《公司法》第57条查阅、复制公司章程、股东名册、股东会会议记录、董事会会议决议、监事会会议决议和财务会计报告
8. 股东要求查阅公司会计账簿的，应当向公司提出书面请求并说明目的

**条件性条款**：
- [ ] 【股份公司】临时提案权须明确"同一股东不得就同一事项重复提案"和"提案须于股东大会召开10日前书面提交"
- [ ] 【有限公司】提案权门槛由章程自定（建议≥代表1/10表决权的股东）

**起草注释**：
- 提案权和质询权不可合并到"通知"章——通知是召集人的单向发送，提案和质询是股东的双向参与
- 知情权条款不抄法条全文，引用§57编号即可
- 质询答复期限须合理（5个工作日是实务惯例），过短则流于形式
- ⚠️ **条级禁止裸名词标题**："第一节 提案权""第二节 质询权"是节级标签（起草时用于内容组织），生成制度全文时**不得**降级为"第六条 提案权。"。正确写法："第X条"后直接接规范语句（如"第六条 单独或者合计持有公司十分之一以上表决权的股东，有权向股东会提出书面提案。内容应当属于股东会职权范围……"），无需独立的条标题行

---

### 第四章 股东会的召集（第一段：召集程序）

**必含条款**：
1. 定期会议：每年召开{1}次，于{上年度审计报告出具后30日内}召开
2. 临时会议召集条件（以下任一）：
   - 代表≥{1/10}表决权的股东提议
   - ≥{1/3}董事提议
   - 监事会提议
3. 召集权人：董事会（执行董事）；董事会不召集→监事会召集→代表≥{1/10}表决权的股东自行召集
4. 召集通知发出人：董事长/执行董事

**条件性条款**：
- [ ] 【有限公司】通知期限≥15日（章程可约定更长）
- [ ] 【股份公司】通知期限≥20日/临时股东大会≥15日+临时提案权（持股≥3%）
- [ ] 【股份公司】年度股东大会须在上一会计年度结束后6个月内召开

**起草注释**：
- 第三项"替代召集路径"必须完整链式覆盖（董事会→监事会→股东），缺一环可导致僵局
- 通知期限不可短于法定底线（有限公司15日/股份公司20日）

---

### 第五章 股东会的通知（第二段：通知期限）

**必含条款**：
1. 通知方式：书面通知（含电子邮件/公告）
2. 通知内容（最少包含）：会议时间/地点/方式/议题/召集人
3. 通知期限：{≥15日有限公司 / ≥20日股份公司}
4. 议题提案权：{持股≥3%股份公司股东有临时提案权}（有限公司股东也有提案权，章程约定）
5. 延期/取消规则：提前{3}日通知全体股东

**条件性条款**：
- [ ] 【有限公司】全体股东书面同意可缩短通知期限
- [ ] 【股份公司】公告方式：指定报纸+证券交易所网站（如上市）

**起草注释**：
- 通知内容清单至少包含5项（时间/地点/方式/议题/召集人），缺失任何一项可导致决议效力瑕疵
- 股份公司公告须同时满足《证券法》信息披露要求（如上市）

---

### 第六章 股东会的出席（第三段：法定人数）

**必含条款**：
1. 出席方式：现场出席 / 书面委托代理出席 / 视频/通讯方式出席
2. 委托出席规则：书面委托书+载明授权范围+代理人在授权范围内表决
3. 出席法定人数（章程约定，建议≥代表1/2表决权的股东出席）
4. 不足法定人数时的处理：延期{7}日重新召集

**条件性条款**：
- [ ] 【股份公司】可增加"征集投票权"制度
- [ ] 【一人公司】本章不适用——由股东直接作出书面决定，无需"出席人数"

**起草注释**：
- 委托书须留存备查（至少保存至决议作出后10年）
- 通讯方式出席须能确认出席人身份并实时参与表决

---

### 第七章 股东会的表决（第四段：表决规则）

**必含条款**：
1. 表决权计算：按出资比例/持股比例行使表决权（章程另有约定除外）
2. 普通决议：出席股东所持表决权过半数通过
3. 特别决议：出席股东所持表决权≥2/3通过
   - 适用事项：修改章程/增资/减资/合并/分立/解散/变更公司形式
4. 表决方式：举手/投票/书面，以{投票表决}为原则
5. 计票与监票：指定计票人/监票人各≥{2}人

**董事、监事选举表决规则**：
6. 选举董事、监事原则上应当逐一表决（非一揽子表决），经出席股东所持表决权过半数通过
7. 等额选举：股东对每位候选人逐一投票（同意/反对/弃权）
8. 差额选举：当候选人数多于应选人数时，以得票多者当选（均须过半数）

**条件性条款**：
- [ ] 【股份公司】累积投票制（选举董事/监事时可选，须在公司章程和议事规则中同步明示）
- [ ] 【类别股】如有优先股/特别表决权股份，须在本章明确各类别表决权行使规则

**起草注释**：
- 特别决议事项清单不存在"兜底条款"——枚举须穷举（修章/增减资/合并分立解散/变更形式，共5项+章程自定）
- 表决权若有特殊安排（如AB股），本章必须与章程完全一致
- 选举条款中"逐一表决"是默认原则——一揽子表决剥夺了股东对个别候选人的反对权，有决议效力风险

---

### 第八章 股东会的记录（第五段：会议记录签字）

**必含条款**：
1. 记录内容（最少包含）：时间/地点/方式/召集人/主持人/出席人/列席人/议题/表决结果/决议内容
2. 记录签字人：**出席会议的全体股东**（非仅主持人或记录人）
3. 记录保存：原件由{董事会办公室/档案室}保存≥{10}年
4. 记录查阅权：股东有权查阅、复制股东会会议记录

**起草注释**：
- 签字人必须全覆盖——仅主持人签字不满足公司法要求
- 保存期限≥10年（《公司法》未明文规定会议记录保存年限，参照档案管理+诉讼时效10年）

---

### 第九章 利害回避（第六段：利害回避规则）

**必含条款**：
1. 回避范围：与决议事项有关联关系的股东必须回避
2. 回避后果：该股东所持表决权不计入表决权总数
3. 回避后仍可达法定比例的确认机制：若全体股东均须回避→提交上级机构或另行决策

**起草注释**：
- "关联关系"定义可引用《公司法》附则或章程的定义
- 回避后表决基数调整为"出席非关联股东所持表决权"

---

### 第十章 决议执行与跟踪（第七段：决议执行与跟踪）

**必含条款**：
1. 决议传达：股东会决议由{董事会办公室/行政部}在会后{5}个工作日内以书面形式送达执行部门和相关人员
2. 执行责任人：每项决议事项须指定执行责任人（由董事会或总经理在会后{10}个工作日内指定并书面通知）
3. 执行期限：决议事项原则上应在决议作出后{30}日内启动执行；需分步执行的事项须附阶段执行计划
4. 执行报告：上次股东会决议执行情况应列为下次股东会会议的第一项报告议题
5. 未执行处理：逾期未执行的，执行责任人须在下次会议前{10}日向董事会书面说明原因并提出延期方案

**条件性条款**：
- [ ] 【精简版】本章可省略——初创企业决议事项少、执行跟踪可通过日常管理完成

**起草注释**：
- 本章是七段骨架的第七段——决议执行跟踪是股东监督权的延伸，制度无跟踪机制则决议可能"决而不行"
- 执行报告列为下次会议首项议题，确保每期会议的连续性

---

### 第十一章 附则

**必含条款**：
1. 解释权：本规则由{董事会}负责解释
2. 生效条件：经股东会以特别决议审议通过后施行，修订亦同
3. 冲突处理：与本规则抵触的既往内部规定自动失效
4. 施行日期：{YYYY年MM月DD日}

**起草注释**：
- 生效条件必须明确"特别决议审议通过"——议事规则本身属于章程配套文件，施行门槛宜高不宜低
