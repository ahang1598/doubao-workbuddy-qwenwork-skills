## 章节骨架（11章完整版 / 精简版可省略标记[*]的章节）

### 第一章 总则

**必含条款**：
1. 制定目的：规范董事会的议事方式和表决程序，保障董事会依法行使职权、科学决策
2. 制定依据：2023年修订《中华人民共和国公司法》第68-75条 + {公司章程}
3. 适用范围：本规则适用于{公司全称}董事会的召集、召开、审议、表决、记录全过程
4. 董事会组成：设董事{N}人，其中董事长1人{、副董事长X人}，任期{3}年（连选可连任）
5. 章程关系：本规则为公司章程的配套文件，与章程不一致的以章程为准

**条件性条款**：
- [ ] 【股份公司】增加"依据《上市公司治理准则》+独立董事制度相关规则"
- [ ] 【拟上市】增加董事会专门委员会（审计委员会/薪酬委员会/提名委员会）设置规则

**起草注释**：
- 第四条须确认"是否有职工代表董事"（国有独资/控股公司须有）
- "任期3年"是法定上限，不可写"任期X年（可连任超过3年）"

---

### 第二章 董事会的职权

**必含条款**：
1. 法定职权（引用《公司法》第69条，不复述全文）
2. 章程增加的职权
3. 授权体系：董事会可向总经理授权的范围和金额上限

**起草注释**：
- 不抄法条全文，引用编号即可
- 第三条"向总经理授权"须与《总经理工作细则》中的授权金额协调一致（如该制度已存在）

---

### 第三章 董事会的召集（第一段：召集程序）

**必含条款**：
1. 定期会议：每年至少召开{2}次（法定底线：≥2次/年）
2. 临时会议召集条件（以下任一）：
   - 代表≥{1/10}表决权的股东提议
   - ≥{1/3}董事提议
   - 监事会提议
3. 召集权人：董事长→副董事长→由≥半数董事共同推举一名董事
4. 董事长不履行职务时：副董事长召集→由≥半数董事推举一名董事召集

**条件性条款**：
- [ ] 【特殊情况】董事长/副董事长均不履行职务时的补充规则

**起草注释**：
- 第三项"替代召集路径"必须完整链式覆盖（董事长→副董事长→推举董事），缺一环可导致僵局
- 定期会议次数"≥2次/年"为法定底线，不可低于此数

---

### 第四章 董事会的通知（第二段：通知期限）

**必含条款**：
1. 通知方式：书面通知（含电子邮件/即时通讯工具留痕）
2. 通知内容（最少包含）：时间/地点/方式/议题/召集人
3. 通知期限：{章程自定（常见3-7日）}
4. 通知送达确认：董事收到通知后{24}小时内回复确认
5. 紧急会议通知：可缩短至{24}小时（但须经全体董事同意）
6. 议题材料发送：与通知同步发送议题相关材料

**起草注释**：
- 通知期限无上位的法定底线（公司法未规定董事会通知期限），但不可过长（影响效率）或过短（影响准备）
- 紧急会议须有"全体董事同意"的例外条件，避免单方面通知导致的效力争议

---

### 第五章 董事会的出席（第三段：法定人数）

**必含条款**：
1. 出席方式：现场出席 / 书面委托代理出席 / 视频/通讯方式出席
2. 委托出席规则：书面委托书+委托给其他董事+载明授权范围+代理人在授权范围内表决

   > ⚠️ **红线提醒**：董事不可委托非董事人士代为出席
3. 出席法定人数：**出席董事≥全体董事过半数**（法定底线，不可降低）
4. 不足法定人数时的处理：延期{3}日重新通知召开

**起草注释**：
- 第2条"只能委托其他董事"是实务中最容易出错的地方——禁止"董助/秘书"代出席
- 第3条"≥全体董事过半数"中的"全体"是指编制内总人数，非"出席人数"，如全体10人→须≥6人出席才有效
- 通讯方式出席须能确认出席人身份并实时参与讨论表决

---

### 第六章 董事会的表决（第四段：表决规则）

**必含条款**：
1. 表决权计算：**一人一票**（法定底线，不可改为按持股比例或其他方式）
2. 通过比例：**≥全体董事过半数**同意（法定底线，不可降低）
3. 表决方式：举手/投票/书面，以{投票表决}为原则
4. 计票规则：董事长{1}票 / 副董事长{1}票 / 其他董事各{1}票
5. 平票处理：{提交股东会审议 / 董事长多投一票（章程须明示）/ 搁置再议}
6. 弃权票处理：{计入表决基数但不计入同意数 / 不计入表决基数（章程自定）}

**书面决议（书面传签）制度**：
7. 在全体董事同意以书面方式作出决议的前提下，董事会决议可以采用书面传签方式作出
8. 书面决议与现场会议决议具有同等效力
9. 书面传签程序：议题材料发送全体董事 → 董事在{5}个工作日内签字传回 → 达到全体董事过半数同意即为通过
10. 书面决议的会议记录应当收录全部董事的签字页，由董事会办公室归档保存

**起草注释**：
- "一人一票"是法定底线，章程不可改为"按出资比例"/"董事长两票"
- "全体董事过半数"中的"全体"是指编制内总人数，如全体11人→须≥6票同意才通过
- 弃权票的处理方式必须在制度中明示（不同公司的做法不同，无上位法强制规定）
- 书面决议是中小心企业最高频的决策方式——必须明确"经全体董事同意"的前提条件和"与现场会议同等效力"

---

### 第七章 董事会的记录（第五段：会议记录签字）

**必含条款**：
1. 记录内容（最少包含）：时间/地点/方式/召集人/主持人/出席人/列席人/议题/
   各董事发言要点（异议须记录）/表决结果/决议内容
2. 记录签字人：**出席会议的全体董事**（非仅主持人或记录人）
3. 对决议投反对票/弃权票的董事，其异议意见必须记入会议记录
4. 记录保存：原件由{董事会办公室/行政部}保存≥{10}年
5. 董事对会议记录的查阅权/复制权

**起草注释**：
- 第三项"异议记入记录"是董事免责的关键——公司法规定"董事对违法决议未提异议且记录无记载"时承担赔偿责任
- 签字人须全覆盖，仅主持人签字不满足法定要求

---

### 第八章 利害回避（第六段：利害回避规则）

**必含条款**：
1. 回避范围：与决议事项有关联关系的董事必须回避
2. 回避后果：该董事不计入表决权总数（表决基数调整）
3. 关联关系定义：引用《公司法》附则或章程的定义
4. 回避后仍可达法定比例的确认机制：
   - 回避后出席董事仍≥全体董事过半数 → 按回避后基数表决
   - 回避后出席董事不足全体董事过半数 → 提交股东会审议
5. 故意不回避的后果：所作表决无效，造成公司损失的承担赔偿责任

**起草注释**：
- 第四项"全体董事回避→提交股东会"是极端但必须覆盖的情形（如全体董事均为关联方）
- 第五项"故意不回避→表决无效+赔偿"有公司法依据

---

### 第九章 董事辞职与补选

**必含条款**：
1. 辞职生效：董事辞职自书面辞职报告送达董事会之日起生效；董事长辞职的，其董事长职务同时解除
2. 辞职后义务：董事辞职后，在补选出的董事就任前，原董事仍应依照法律、行政法规和公司章程的规定履行董事职务
3. 补选程序：董事会应在董事辞职生效后{30}日内提名候选人并提请股东会补选
4. 表决基数过渡：在补选完成前，董事会表决的"全体董事"基数**仍按原编制人数计算**（非按辞职后实际人数），以保护治理制衡不因董事辞职而松动
5. 董事资格终止：董事任期届满未及时改选，或者董事在任期内辞职导致董事会成员低于法定人数的（有限公司<3人/股份公司<3人），在改选出的董事就任前，原董事应当继续履行职务

**起草注释**：
- 第四条"表决基数仍按原编制人数"是治理制衡的核心保护——否则会出现"11人董事会辞职3人→剩余8人→全体过半数仅需5票"的治理滑坡
- 第五条"低于法定人数时原董事继续履职"有公司法直接依据

---

### 第十章 决议执行与跟踪（第七段：决议执行与跟踪）

**必含条款**：
1. 决议传达：董事会决议由{董事会办公室/行政部}在会后{3}个工作日内以书面形式送达执行部门和相关人员，同时抄送全体董事和监事
2. 执行责任人：每项决议事项指定执行责任人（董事或高管），在决议中明确记载
3. 执行期限：决议事项原则上应在决议作出后{15}日内启动执行
4. 执行报告：上次董事会决议执行情况应列为下次董事会会议的第一项议题
5. 未执行处理：逾期未执行的，执行责任人须在{3}个工作日内向董事会书面说明原因并提出延期方案
6. 董事会监督：董事会每半年度对决议执行情况进行专项评估

**条件性条款**：
- [ ] 【精简版*】本章可省略——初创企业董事人数少、决策事项少，执行跟踪可通过日常沟通完成

**起草注释**：
- 决议执行跟踪是董事勤勉义务的具体体现（公司法§180）——制度无跟踪机制，董事可能因"决议后不闻不问"承担监督失职责任
- 执行报告列为每次会议第一项议题，实现闭环管理

## 起草完成后的自检清单

- [ ] 出席法定人数≥全体董事过半数（±1人即不达标）
- [ ] 表决规则严格一人一票（无按股权/按职位加权）
- [ ] 书面决议制度完整（前提条件/期限/同等效力/签字归档）
- [ ] 委托出席只能委托其他董事（不能委托非董事人士）
- [ ] 记录签字人=全体出席董事（非仅主持人）
- [ ] 董事异议意见强制记入会议记录
- [ ] 利害回避规则完整（4步：范围→后果→定义→回避后机制）
- [ ] 董事辞职与补选条款完整（辞职生效/过渡期表决基数/补选时限）
- [ ] 决议执行与跟踪条款完整（传达/责任人/期限/报告）
- [ ] 所有法条编号为2023新公司法
- [ ] 一人公司已裁剪（如适用）
