## §1 七段程序法骨架

所有三会议事规则起草均遵循以下七段程序法骨架（从召集到执行跟踪的完整程序闭环）：

### 第一段：召集程序

**核心问题**：谁有权召集？什么条件下必须召集？

| 要素 | 起草要点 |
|:---|:---|
| 召集权人 | 列明法定召集权人 + 章程可能增加的召集权人 |
| 临时会议召集条件 | 明确持股比例/董事人数触发阈值 |
| 召集通知发出人 | 明确由谁（董事长/执行董事/监事会主席）发出通知 |
| 召集权冲突处理 | 董事会不召集时的替代路径 |

**起草检查**：
- [ ] 召集权人与公司法/章程一致
- [ ] 临时会议召集条件有明确量化阈值
- [ ] 替代召集路径完备（如董事会不召集→监事会→股东自行召集）

### 第二段：通知期限

**核心问题**：提前多久通知？通知包含什么内容？

| 公司类型 | 股东会通知期限 | 董事会通知期限 | 监事会通知期限 |
|:---|:---|:---|:---|
| 有限公司 | ≥15日（章程可另定） | 章程自定（常见3-7日） | 章程自定 |
| 股份公司 | ≥20日（临时股东大会≥15日） | 章程自定（常见7-10日） | 章程自定 |

**起草检查**：
- [ ] 有限公司≥15日 / 股份公司≥20日（法定底线不可突破）
- [ ] 通知内容清单至少包含：时间/地点/议题/会议形式
- [ ] 紧急会议通知期限是否有特别规定

### 第三段：法定人数

**核心问题**：多少人到会才算有效会议？

| 会议类型 | 出席法定人数 |
|:---|:---|
| 股东会 | 无强制出席人数要求（章程自定，常见≥代表1/2表决权） |
| 董事会 | 出席董事≥全体董事过半数（法定底线） |
| 监事会 | 出席监事≥全体监事过半数（法定底线） |

**起草检查**：
- [ ] 董事会出席法定人数≥全体董事过半数（不可降低）
- [ ] 监事会出席法定人数≥全体监事过半数（不可降低）
- [ ] 委托出席规则明确（书面委托+授权范围）

### 第四段：表决规则

**核心问题**：怎么投票？多少票通过？

| 决议类型 | 通过比例 | 适用事项 |
|:---|:---|:---|
| 股东会普通决议 | ≥出席表决权过半数 | 一般事项 |
| 股东会特别决议 | ≥出席表决权2/3 | 修改章程/增减资/合并分立解散/变更形式 |
| 董事会决议 | ≥全体董事过半数 | 一般事项 |
| 监事会决议 | ≥全体监事过半数 | 一般事项 |
| 董事会一人一票 | — | 所有表决事项 |

**起草检查**：
- [ ] 特别决议事项清单是否列全（修改章程/增减资/合并分立解散/变更形式）
- [ ] 董事会一人一票制度明确写入
- [ ] 表决方式（举手/投票/书面）有明确规则

### 第五段：会议记录签字

**核心问题**：谁记录？谁签字？记录保存多久？

| 会议类型 | 记录签字人 |
|:---|:---|
| 股东会 | 出席会议的**全体股东**（非仅主持人） |
| 董事会 | 出席会议的**全体董事** |
| 监事会 | 出席会议的**全体监事** |

**起草检查**：
- [ ] 签字人范围全覆盖（非选择性签字）
- [ ] 记录保存期限≥10年（符合《公司法》+档案管理要求）
- [ ] 记录内容至少包含：时间/地点/出席人/议题/表决结果/决议内容

### 第六段：利害回避规则

**核心问题**：什么情况下必须回避？回避后表决怎么算？

**起草检查**：
- [ ] 关联交易事项→关联董事/股东必须回避
- [ ] 回避后表决基数是否调整（回避人所持表决权不计入基数）
- [ ] 回避后仍可达法定比例（极端情形：所有董事均需回避→提交股东会审议）

### 第七段：决议执行与跟踪

**核心问题**：决议作出后如何执行？谁来跟踪？执行情况如何报告？

| 要素 | 起草要点 |
|:---|:---|
| 决议传达 | 明确决议送达对象（执行部门/总经理/财务部）和时限（会后X个工作日内） |
| 执行责任人 | 每项决议事项指定执行责任人（董事/高管/部门负责人） |
| 执行时间表 | 决议事项须附执行期限（"决议作出后XX日内启动执行"） |
| 执行报告 | 上次会议决议执行情况列入下次会议第一项议题 |
| 未执行的处理 | 逾期未执行的说明原因+延长期限申请程序 |

**起草检查**：
- [ ] 决议传达机制明确（谁传给谁/几个工作日内/书面形式）
- [ ] 执行情况反馈机制写入（下次会议首项议题）
- [ ] 未执行事项的说明和延期机制有规定
- [ ] 区分"即时执行"与"分步执行"两类决议的跟踪方式

**实务理由**：决议执行跟踪是董事勤勉义务的具体体现——如果制度只规定怎么开会但没有跟踪机制，董事可能因"决议后不闻不问"而承担监督失职责任。

## §2 三会差异对照表

| 维度 | 股东会 | 董事会 | 监事会 |
|:---|:---|:---|:---|
| 法定人数底线 | 章程自定（≥1/2常见） | ≥全体董事过半数 | ≥全体监事过半数 |
| 表决单位 | 按出资比例/股份 | 一人一票 | 一人一票 |
| 通知期限（有限公司） | ≥15日 | 章程自定 | 章程自定 |
| 通知期限（股份公司） | ≥20日 | 章程自定 | 章程自定 |
| 记录签字人 | 出席全体股东 | 出席全体董事 | 出席全体监事 |
| 主持人 | 章程约定（通常董事长） | 董事长/副董事长/推举董事 | 监事会主席/副主席/推举监事 |
| 召集权人 | 董事会/监事会/≥10%股东 | 董事长/≥1/3董事/监事会 | 监事会主席/≥半数监事 |
| 是否有提案权 | 股东有提案权（股份公司≥3%） | 董事有提案权 | 监事有提案权（向股东会） |
| 利害回避 | 关联股东回避 | 关联董事回避 | （监事会审议时关联监事应回避） |

## §3 治理复杂度阶梯

根据企业规模和发展阶段，制度文件颗粒度分为三档：

| 档次 | 企业规模 | 制度章数 | 条款颗粒度 | 典型特征 |
|:---|:---|:---|:---|:---|
| **精简版** | 初创型（≤20人） | 5-6章 | 粗线条，只覆盖法定底线+核心程序段 | 一人公司不设董事会/监事会，仅需股东会规则；可省略决议执行跟踪章 |
| **标准版** | 成长型（20-200人） | 7-9章 | 中等，补充常见治理场景 | 三会齐全，七段骨架全覆盖，补充书面决议/辞职补选/选举程序 |
| **完整版** | 成熟/拟上市 | 10-11章 | 精细，覆盖全面治理场景 | 补充累积投票制/类别股表决/征集投票权/董秘列席/专门委员会等 |

**关键原则**：不越级。不要给初创企业生成拟上市级别的完整版议事规则——过度精细的制度反而难执行。

## §4 起草优先级规则

同一议题在多个法律渊源中有不同规定时，优先级：

```
上位法强制规定 > 司法解释 > 章程约定 > 行业惯例/上市公司准则（拟上市参考） > 起草人建议
```

1. **上位法强制规定**（不可突破）：法定人数底线、2/3特别决议、一人一票等，制度中须以"必须/应当"表述
2. **司法解释**（细化上位法的具体适用规则）：公司法司法解释三/四/五中关于公司决议效力、股东知情权、董事选举的具体规则，制度条款设计时须参照
3. **章程约定**（从章程提取或建议章程补充）：若章程已有约定，制度须与之保持一致；若章程缺失，在制度中标注"建议章程补充"
4. **行业惯例**（参考但不强制）：上市公司治理准则、行业最佳实践，标注为"建议"或"可"

## §5 弹性留白规则

以下三种情况应"故意不写"，而非面面俱到：

| 情况 | 示例 | 理由 |
|:---|:---|:---|
| **法律已有明确规定** | 《公司法》第63条股东会职权——引用法条编号即可，照抄全文无增值且法条修改时制度需同步修订 | 避免"法条搬家"式条款 |
| **快速变化阶段的企业** | 初创企业"每年至少召开N次董事会"——以法定底线≥2次为基准，不强行规定具体次数 | 留待企业稳定后视需要细化 |
| **行业惯例已有共识** | 内部管理类细节（如会议室预订流程、会议茶水安排、签到表格式） | 操作层面惯例无需上升为制度条款 |

**起草处理方式**：
- 情况1：引用法条编号（"依据《公司法》第X条"），不复述全文
- 情况2：留白 + 标注"【待企业稳定后补充】"
- 情况3：不写入制度，在制度末尾"操作指引"中简略提及"参见公司内部会议管理规范"

**重要区分**：涉及法定权利行使方式的事项（如电子通信方式出席/表决）**不属于弹性留白范围**——2023公司法已明确允许电子通信方式开会，写入制度是提供合法依据，而非"限制灵活性"。

## §6 常见起草错误

| 错误 | 后果 | 正确做法 |
|:---|:---|:---|
| 董事会出席人数<过半数 | 会议决议可被撤销 | 严格≥全体董事过半数 |
| 股东会通知期限<15日（有限公司） | 决议可被撤销（全体股东同意除外） | 严格≥15日（全体股东书面同意可缩短） |
| 仅主持人签字而非全体出席人签字 | 记录证明力弱 | 全体出席股东/董事/监事签字 |
| 遗漏利害回避规则 | 关联交易决议效力瑕疵 | 强制写入关联人回避规则 |
| 照抄2018公司法条文编号 | 法条编号与现行法不一致 | 使用2023公司法编号 |
| 给一人公司编董事会规则 | 无法执行的空头文件 | 裁剪不适用的规则 |
| 股份公司用15日通知期限 | 违反法定底线 | 股份公司≥20日 |
