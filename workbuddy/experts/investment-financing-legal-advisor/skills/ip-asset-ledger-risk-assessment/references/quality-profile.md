## 二、阻断级检查项（未通过阻断输出）

1. xlsx 8个Sheet未齐全 → 阻断
2. 封面摘要数据与各Sheet不一致 → 阻断
3. 必填字段填充率<60% → 阻断
4. 法条编号错误 → 阻断
5. 免责声明缺失 → 阻断
6. 场景与输出不匹配（如pre_investment输出R&W） → 阻断
7. RC-07出资瑕疵未标注法律依据 → 阻断
8. [红旗]标记的IP未附应对建议 → 阻断

## 三、警告级检查项（不阻断但标注）

1. 字段填充率60%-80% → 警告
2. 官方状态层未核实（标注待核实） → 警告
3. 许可链断点（标注断点） → 警告
4. 商业秘密措施未评估 → 警告
5. R&W条款未含谈判要点 → 警告
6. 年费/续展到期日3个月内 → 警告
7. 许可合同含"任意终止"条款未标注 → 警告

## 四、P7质量检查流程（25项自检）

```
P7质量检查
  ├── 产物完整性检查（5项）
  │   ├── xlsx文件可打开
  │   ├── 8个Sheet齐全
  │   ├── md报告可读
  │   ├── 免责声明已附
  │   └── 封面摘要数据正确
  ├── 字段填充率检查（5项）
  │   ├── 专利Sheet必填字段填充率≥80%
  │   ├── 商标Sheet必填字段填充率≥80%
  │   ├── 著作权Sheet必填字段填充率≥80%
  │   ├── 商业秘密Sheet必填字段填充率≥80%
  │   └── 许可Sheet必填字段填充率≥80%
  ├── 风险识别率检查（5项）
  │   ├── 10项RC规则全部执行
  │   ├── 每项IP至少评估1项RC
  │   ├── 高风险（L3）IP已重点标注
  │   ├── 许可链风险已识别
  │   └── 出资瑕疵已识别（investment场景）
  ├── 法条引用检查（5项）
  │   ├── 法条编号正确
  │   ├── 法条标注核实状态
  │   ├── 法律核验闸门5项已检查
  │   ├── 法条引用与法律依据一致
  │   └── 无过时法条引用
  └── R&W条款检查（5项，仅post_investment）
      ├── 每条R&W关联RC规则
      ├── 7类标准条款全覆盖（有风险的部分）
      ├── R&W条款含谈判要点
      ├── 无风险IP未出R&W
      └── R&W条款标注"需律师复核"
       ├── 阻断项 → 修复后重新输出
       └── 警告项 → 标注后输出
```

## 六、核心术语（统一规范）

### IP类型
- **专利权**：国家专利行政部门授予发明创造的独占权，包括发明/实用新型/外观设计
- **商标权**：经商标局核准注册的商标专用权
- **著作权**：作者对作品享有的专有权利，自创作完成自动产生
- **商业秘密**：不为公众所知悉、具有商业价值并经权利人采取保密措施的技术/经营信息（反不正当竞争法第9条）
- **域名**：互联网上的地址标识
- **集成电路布图设计**：集成电路中至少有一个是有源元件的两个以上元件和部分或者全部互连线路的三维配置
- **植物新品种**：经人工培育或发现后开发的具备新颖性/特异性/一致性和稳定性并命名的植物品种
- **地理标志**：标示商品来源于某地区的标志

### 权属术语
- **职务发明**：执行本单位任务或主要利用本单位物质技术条件完成的发明创造（专利法第6条）
- **权属来源**：自主研发/受让/许可/出资
- **权属瑕疵**：IP权属存在不完整/不清晰/有争议等问题
- **共有权属**：两个以上主体共同拥有的IP权利
- **代持**：一方代另一方持有IP权利（非登记权利人）

### 许可术语
- **独占许可**：许可人在许可期限内/地域内不得自己使用也不得许可他人使用
- **排他许可**：许可人不得许可他人使用但可自己使用
- **普通许可**：许可人可自己使用也可许可他人使用
- **分许可（再许可）**：被许可人将许可权利再许可给第三方
- **许可链**：从原始权利人到最终权利人的许可传递路径

### 出资术语
- **IP出资**：以IP资产作为非货币财产出资（公司法第48条）
- **评估合规**：IP出资须经合法评估机构评估
- **交付完整**：IP出资须完成权属变更和资料移交
- **公示合规**：IP出资须在股东名册和工商变更登记/信息公示中体现（公司法第34条+第40条+第86条）
- **出资瑕疵**：IP出资在评估/交付/公示/决议方面的不合规问题

### R&W术语
- **R&W**：Representations and Warranties，陈述与保证条款
- **权属完整性R&W**：保证公司合法拥有全部IP，权属无争议
- **无负担R&W**：保证IP未设定质押/冻结等权利负担
- **无侵权R&W**：保证公司使用IP未侵犯第三方权利

### 核验术语
- **证书层核验**：通过权利证书/登记证书扫描件核验权属
- **登记层核验**：通过工商档案/版权登记查询核验权属
- **官方状态层核验**：通过专利局/商标局/版权中心实时数据核验IP状态
- **三级核验法**：证书层→登记层→官方状态层的逐层递进核验方法

## 八、已知限制

### AI能力边界
1. 不替代官方查询：AI无法实时访问专利局/商标局/版权中心数据库
2. 不确认权属效力：权属效力判断须持证律师作出
3. 不提供投资决策建议：IP价值评估须专业评估机构判断
4. 不保证数据时效性：IP状态可能随时变化

### 数据准确性限制

| 限制项 | 应对措施 |
|--------|----------|
| 专利年费状态 | 标注"年费状态待核实"+提示用户查询 |
| 商标续展状态 | 标注"续展状态待核实"+提示用户查询 |
| 著作权登记状态 | 标注"登记状态待核实" |
| 许可合同真实性 | 仅基于提供文件分析，标注来源 |
| 商业秘密措施有效性 | 标注"措施待律师评估" |

### 场景限制
- 投前IP尽调：仅清单+初步标记，不做深度评估
- 年度盘点：追加模式仅比对既有台账，不重新核验权属
- 跨境IP资产：不处理外国专利/商标/著作权，路由至涉外律师

### 输出限制
- xlsx台账不含公式，仅静态数据
- Markdown报告不含法律意见，仅风险标记和建议
- R&W条款为建议草稿，须律师审查后使用
