# 工作流详情

## Phase 1：场景路由与输入验证

### 步骤

1. 识别用户意图，匹配四场景之一
2. 校验必填参数（scenario/company_info/ip_list或ip_assets）
3. 确认场景特定要求（annual_review需existing_ledger等）
4. 信息不足时一次性追问全部缺口（≤1次）

### 检查点

- [ ] scenario已确认
- [ ] company_info完整
- [ ] IP清单已获取（ip_list或ip_assets）
- [ ] 场景特定前置条件满足

### 风险：L1

---

## Phase 2：资产信息结构化

### 步骤

1. 逐项解析IP资产信息
2. 按类型分类（专利/商标/著作权/商业秘密/其他）
3. 补充字段（到期日/年费状态/权属来源等）
4. 生成初步资产清单

### 检查点

- [ ] 每项IP已分类
- [ ] 到期日字段已填充（适用类型）
- [ ] 权属来源已标注（自主研发/受让/许可/出资）
- [ ] 缺失字段已标注"待核实"

### 风险：L1

---

## Phase 3：权属状态核验

### 步骤

1. **证书层核验**：检查IP证书扫描件
2. **登记层核验**：检查工商档案/版权登记信息
3. **官方状态层核验**：标注官方查询状态（不可查时标注待核实）
4. 生成权属状态矩阵
5. 标注权属瑕疵（RC-01）

### 检查点

- [ ] 证书层结果已记录
- [ ] 登记层结果已记录
- [ ] 官方状态层结果已记录（或标注待核实）
- [ ] 权属瑕疵已标记RC-01
- [ ] 职务发明/委托开发已核验（专利适用）

### 风险：L2

---

## Phase 4：许可链与出资质检

### 步骤

1. **许可链追踪**：从原始权利人逐级追踪至最终权利人
2. 标记许可链断裂/过长/未授权转许可（RC-02/RC-03）
3. **出资质检**：评估合规+交付完整+公示合规+决议程序四要素
4. 标记出资瑕疵（RC-07）
5. 标记质押/冻结等负担（RC-05）

### 检查点

- [ ] 许可链已追踪至最终权利人（或标注断点）
- [ ] 许可链超3层已标记RC-02
- [ ] 未授权转许可已标记[红旗]
- [ ] 出资四要素已逐项检查
- [ ] 出资瑕疵已标记RC-07
- [ ] 质押/负担已标记RC-05

### 风险：L3

---

## Phase 5：风险评级与R&W映射

### 步骤

1. 逐项IP执行10项RC规则评估
2. 汇总风险矩阵（Sheet 8）
3. 确定风险等级（L1/L2/L3）
4. **R&W映射**（仅post_investment场景）：风险→条款类型→条款建议
5. 生成R&W条款建议草稿

### 检查点

- [ ] 10项RC规则已全部执行
- [ ] 风险等级已确定
- [ ] 每条R&W关联具体RC规则（post_investment场景）
- [ ] 无风险IP不出具R&W条款

### 风险：L3

---

## Phase 6：双产物生成

### 步骤

1. **生成xlsx台账**（8个Sheet）
2. **生成Markdown报告**（10章节，从xlsx取数确保一致）
3. 场景裁剪（pre_investment精简/annual_review追加对比）
4. 附加免责声明

### 检查点

- [ ] xlsx 8个Sheet完整
- [ ] md报告章节完整（按场景裁剪）
- [ ] xlsx与md数据一致
- [ ] 免责声明已附加

### 风险：L2

---

## Phase 7：质量检查与降级

### 步骤

1. 执行25项自检
2. 检查产物完整性
3. 检查字段填充率
4. 检查风险识别率
5. 检查法条引用准确性
6. 检查R&W条款完整性（post_investment场景）
7. 必要时触发SOFT_DEGRADED降级

### 25项自检清单

**产物完整性（5项）**
- [ ] xlsx文件可打开
- [ ] 8个Sheet齐全
- [ ] md报告可读
- [ ] 免责声明已附
- [ ] 封面摘要数据正确

**字段填充率（5项）**
- [ ] 专利Sheet必填字段填充率≥80%
- [ ] 商标Sheet必填字段填充率≥80%
- [ ] 著作权Sheet必填字段填充率≥80%
- [ ] 商业秘密Sheet必填字段填充率≥80%
- [ ] 许可Sheet必填字段填充率≥80%

**风险识别率（5项）**
- [ ] 10项RC规则全部执行
- [ ] 每项IP至少评估1项RC
- [ ] 高风险（L3）IP已重点标注
- [ ] 许可链风险已识别
- [ ] 出资瑕疵已识别（investment场景）

**法条引用准确性（5项）**
- [ ] 法条编号正确
- [ ] 法条标注核实状态
- [ ] 法律核验闸门5项已检查
- [ ] 法条引用与法律依据一致
- [ ] 无过时法条引用

**R&W条款完整性（5项，仅post_investment）**
- [ ] 每条R&W关联RC规则
- [ ] 7类标准条款全覆盖（有风险的部分）
- [ ] R&W条款含谈判要点
- [ ] 无风险IP未出R&W
- [ ] R&W条款标注"需律师复核"

### 风险：L3
