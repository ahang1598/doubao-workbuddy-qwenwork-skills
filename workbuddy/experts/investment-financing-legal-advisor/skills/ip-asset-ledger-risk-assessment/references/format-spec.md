# 格式规格

## 1. xlsx格式规范

### 1.1 通用规则

- 文件扩展名：.xlsx
- 编码：UTF-8
- Sheet命名：中文（见output-spec.md §2）
- 表头行：首行冻结
- 条件格式：金额缺失/类型不明/状态过期 → 标红
- 日期格式：YYYY-MM-DD

### 1.2 数值精度

| 字段类型 | 精度 | 示例 |
|----------|------|------|
| 金额 | 保留2位小数 | 1000000.00 |
| 比例/百分比 | 保留2位小数 | 33.33% |
| 数量 | 整数 | 15 |
| 日期 | YYYY-MM-DD | 2026-07-07 |

### 1.3 字段填充规则

- 缺失值统一填"待核实"
- 不使用空单元格
- 不使用"N/A"或"null"
- 日期缺失填"待核实"而非"1900-01-01"

## 2. Markdown格式规范

### 2.1 标题层级

- `#` 报告标题
- `##` 章节标题（第1-10章节）
- `###` 小节标题
- `####` 子小节标题

### 2.2 表格规范

- 使用标准Markdown表格
- 表头必填
- 单元格内容简明
- 长文本拆分为多行

### 2.3 风险标记格式

| 标记 | 含义 |
|------|------|
| [红旗] | 严重风险（未授权转许可等） |
| [待核实] | 信息缺失需核实 |
| [已核实] | 法条已核实 |
| [需核实] | 法条需核实 |
| [存疑] | 法条存疑 |

### 2.4 免责声明格式

报告末尾固定附：

```
---

## 免责声明

本报告由AI辅助生成，不构成法律意见。所有风险标记和R&W条款建议须持证律师复核后使用。IP状态信息（年费/续展/无效等）以官方查询结果为准，本报告不保证数据时效性。
```

## 3. R&W条款格式（post_investment场景）

### 3.1 条款结构

```
### R&W-{编号}：{条款类型}

**关联风险**：RC-{XX} {风险描述}
**条款建议**：
{条款正文}

**谈判要点**：
1. {要点1}
2. {要点2}

**备注**：本条款为建议草稿，须律师审查后使用。
```
