# USAGE.md — 使用说明

## 快速开始

### 1. 投前IP尽调

```
输入：目标公司信息 + IP资产清单（或证书文件）
输出：IP资产清单xlsx + 初步风险标记报告
```

示例对话：
- 用户："帮我把目标公司的IP资产盘一下，做投前尽调"
- 技能：确认场景→收集IP清单→结构化→初步风险标记→输出台账+报告

### 2. 投中IP评估

```
输入：IP资产清单 + 许可合同 + 出资信息
输出：深度评估报告（权属核验+许可链+出资瑕疵+风险矩阵+R&W建议）
```

示例对话：
- 用户："这家公司IP权属有没有问题？许可链是否完整？有没有出资瑕疵？"
- 技能：场景路由→深度核验→许可链追踪→出资质检→风险评级→R&W映射

### 3. 投后R&W映射

```
输入：既有IP台账（投中产出） + 投资协议草稿
输出：R&W条款建议（关联风险标记）
```

示例对话：
- 用户："投资协议的IP相关R&W条款该怎么写？"
- 技能：加载台账→风险筛选→条款映射→生成R&W建议草稿

### 4. 年度合规盘点

```
输入：既有IP台账 + 新增IP资产信息
输出：更新后台账 + 风险变化追踪报告
```

示例对话：
- 用户："年度盘点一下IP资产的风险变化"
- 技能：加载既有台账→比对新增/变更→风险等级变化追踪

## 输入说明

### 必填信息

- 目标公司名称和统一社会信用代码
- IP资产清单（至少包含名称/类型/编号）

### 推荐信息

- IP证书扫描件
- 许可与转让合同
- IP出资评估报告
- 既有IP台账（年度盘点模式）

## 输出说明

### xlsx台账（8个Sheet）

1. 封面摘要 — 资产全景+风险分布
2. 专利权 — 专利台账
3. 商标权 — 商标台账
4. 著作权 — 著作权台账
5. 商业秘密 — 商业秘密清单
6. 其他IP — 域名/集成电路/植物新品种/地理标志
7. 许可与转让 — 合同台账
8. 风险矩阵+R&W — 风险评估+条款建议

### Markdown报告（10章节）

1. 摘要 → 2. 工作方法 → 3. 资产分类 → 4. 权属状态 → 5. 许可与转让 → 6. 风险矩阵 → 7. 出资瑕疵 → 8. R&W条款映射 → 9. 应对建议 → 10. 局限性说明

## 注意事项

- 所有风险标记须律师复核后使用
- R&W条款为建议草稿，须律师审查
- 官方状态（年费/续展/无效）须用户自行核实
- 台账标注查询日期，不保证数据时效性
- 本技能遵守 `base/shared/writing-redlines.md` 全部11条通用红线
