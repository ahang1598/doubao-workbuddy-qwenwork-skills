# 质量标准

## 六维评价体系

| 维度 | 标准 | 权重 |
|------|------|------|
| 资产分类准确性 | IP类型分类无误，字段填充完整 | 20% |
| 权属核验深度 | 三级核验逐层执行，结果记录完整 | 20% |
| 风险识别全面性 | 10项RC全部执行，无遗漏 | 20% |
| 法条引用准确性 | 法条编号正确，核实状态标注 | 15% |
| 双产物一致性 | xlsx与md数据一致 | 15% |
| R&W条款关联性 | 每条R&W关联RC规则（post_investment） | 10% |

## 阻断级检查项

以下检查项未通过时阻断输出：

1. xlsx 8个Sheet未齐全 → 阻断
2. 封面摘要数据与各Sheet不一致 → 阻断
3. 必填字段填充率<60% → 阻断
4. 法条编号错误 → 阻断
5. 免责声明缺失 → 阻断
6. 场景与输出不匹配（如pre_investment输出R&W） → 阻断

## 警告级检查项

以下检查项未通过时标注警告但不阻断：

1. 字段填充率60%-80% → 警告
2. 官方状态层未核实（标注待核实） → 警告
3. 许可链断点（标注断点） → 警告
4. 商业秘密措施未评估 → 警告
5. R&W条款未含谈判要点 → 警告

## 质量检查流程

```
P7质量检查
  ├── 产物完整性检查（5项）
  ├── 字段填充率检查（5项）
  ├── 风险识别率检查（5项）
  ├── 法条引用检查（5项）
  └── R&W条款检查（5项，仅post_investment）
       ├── 阻断项 → 修复后重新输出
       └── 警告项 → 标注后输出
```

## 输出质量标注

每个产物输出时附带质量标注：

| 标注 | 含义 |
|------|------|
| [质量合格] | 所有阻断项通过，警告项≤2 |
| [质量警告] | 所有阻断项通过，警告项≥3 |
| [质量不合格] | 存在阻断项，需修复 |
