# 核心方法论

## 1. 三级权属核验法

### 1.1 核验层级

| 层级 | 核验对象 | 数据来源 | 可信度 |
|------|----------|----------|--------|
| L1 证书层 | 权利证书/登记证书 | 用户提供扫描件 | 中（可伪造） |
| L2 登记层 | 工商档案/版权登记 | 工商系统/版权中心 | 高 |
| L3 官方状态层 | 实时状态 | 专利局/商标局/版权中心API | 最高 |

### 1.2 递进规则

- 前层通过才进下层：L1未通过（无证书）→标注"证书待核实"→仍可进入L2
- L3不可查时标注"官方状态待核实"，不阻断流程
- 各层结果分别记录，不覆盖

### 1.3 各IP类型核验要点

**专利权**：
- 证书层：专利证书扫描件
- 登记层：专利登记簿副本
- 官方状态层：年费缴纳状态/无效宣告状态/转让状态

**商标权**：
- 证书层：商标注册证扫描件
- 登记层：商标注册信息（商标局官网）
- 官方状态层：续展状态/无效/撤销状态/许可备案状态

**著作权**：
- 证书层：著作权登记证书扫描件
- 登记层：版权中心登记信息
- 官方状态层：登记状态（注意：著作权自创作完成自动产生，登记非取得要件）

**商业秘密**：
- 证书层：无证书（商业秘密不登记）
- 登记层：无登记
- 官方状态层：无官方查询
- 替代核验：保密措施清单+保密协议+接触人员名单

## 2. 许可链追踪法

### 2.1 追踪流程

```
原始权利人 → 一级被许可人 → 二级被许可人 → ... → N级
```

### 2.2 风险判断规则

| 情形 | 风险标记 | RC规则 |
|------|----------|--------|
| 许可链超过3层 | [许可链过长] | RC-02 |
| 未授权转许可 | [红旗-未授权转许可] | RC-02 |
| 许可合同缺失 | [许可记录待核实] | — |
| 分许可权条款不清 | [分许可权限待核实] | RC-03 |
| 许可地域/范围超出 | [许可范围超限] | RC-03 |
| 独占许可+多重许可 | [独占许可冲突] | RC-02 |

### 2.3 追踪深度

- 默认追踪至最终权利人
- 超过5层标注"链路过长，建议律师审查"
- 合同缺失时标注断点，不继续追踪

## 3. 出资瑕疵识别法

### 3.1 四要素检查

| 要素 | 检查内容 | 法律依据 |
|------|----------|----------|
| 评估合规 | 评估机构资质/评估方法/评估时点 | 公司法第50条 [已核实] |
| 交付完整 | 权属变更登记/资料移交 | 公司法第49条（非货币财产依法办理权属转移） [已核实] |
| 公示合规 | 股东名册记载/工商变更登记/信息公示 | 公司法第34条（变更登记不得对抗善意相对人）+第40条（出资信息公示）+第86条（股东名册） [已核实] |
| 决议程序 | 股东会决议/董事会决议 | 公司法第59条 [已核实] |

### 3.2 瑕疵类型

| 瑕疵类型 | 表现 | 风险等级 | RC规则 |
|----------|------|----------|--------|
| 未评估/评估不合规 | 无评估报告/评估机构无资质 | L3 | RC-07 |
| 未交付/交付不完整 | 权属未变更/资料未移交 | L3 | RC-07 |
| 未公示/公示不一致 | 工商登记与实际不符 | L2 | RC-07 |
| 未决议/决议程序瑕疵 | 无股东会决议/决议程序违法 | L2 | RC-07 |
| 高估出资 | 评估值显著高于实际价值 | L3 | RC-07 |

## 4. R&W条款映射法

### 4.1 映射流程

```
风险识别（RC规则） → 条款类型 → 条款建议 → 谈判要点
```

### 4.2 七类标准条款

| 条款类型 | 触发风险 | 条款要点 |
|----------|----------|----------|
| 权属完整性 | RC-01权属瑕疵 | 公司合法拥有全部IP，权属无争议 |
| 无负担 | RC-05质押/冻结 | IP未设定质押/冻结/其他权利负担 |
| 无许可违约 | RC-02许可链断裂 | 公司未违反任何IP许可协议 |
| 无质押 | RC-05质押 | IP未设定任何质押权 |
| 出资真实 | RC-07出资瑕疵 | IP出资已完成合法评估和权属变更 |
| 无侵权 | RC-08侵权 | 公司使用IP未侵犯第三方权利 |
| 未缴费用 | RC-04维护义务 | 公司已缴纳全部IP维持费用（年费/续展费） |

### 4.3 映射规则

- 每条R&W须关联具体RC规则编号
- 无对应风险的IP资产不出具R&W条款
- R&W条款为建议草稿，须律师审查后使用
- 投后场景（post_investment）才输出R&W条款

## 5. 场景差异化方法论

### 5.1 投前IP尽调（pre_investment）

- 深度：清单+初步标记
- 不做：深度权属核验/许可链追踪/出资瑕疵分析
- 输出：资产清单xlsx（8 Sheet）+ 初步风险标记报告（精简版）

### 5.2 投中IP评估（investment）

- 深度：完整7 Phase
- 核心：P3权属核验+P4许可链+出资+P5风险评级
- 输出：完整台账+完整报告

### 5.3 投后R&W映射（post_investment）

- 前置：须有投中产出的台账
- 深度：风险筛选+条款映射
- 输出：R&W条款建议（独立文件）

### 5.4 年度合规盘点（annual_review）

- 前置：须有既有台账
- 深度：增量比对+风险变化追踪
- 输出：更新后台账+风险变化报告

## 6. 常见错误清单

| # | 错误模式 | 正确处理 | 典型场景 |
|---|----------|----------|----------|
| E-01 | 将公司法第227条（增资优先认缴权）误作"公示合规"依据 | 公示合规应引用第34条（变更登记不得对抗善意相对人）+第40条（出资信息公示）+第86条（股东名册） | 出资瑕疵四要素-公示合规 |
| E-02 | 仅引用公司法第48条（出资方式）作为出资交付依据 | 出资交付应引用第49条（非货币财产依法办理权属转移），第48条仅规定出资方式范围 | 出资瑕疵四要素-交付完整 |
| E-03 | 将"合同法"作为引用（已废止） | 应引用民法典合同编具体条文（第509/512/563/545条） | RC-02/09法律依据 |
| E-04 | 仅标注"民法典物权编"不指明条文 | 应引用第440条（知识产权质押范围）+第443条（质押登记效力） | RC-05法律依据 |
| E-05 | 将商业秘密与专利/商标同级别核验 | 商业秘密无证书/无登记/无官方查询，应使用替代核验（保密措施清单+保密协议+接触人员名单） | 三级权属核验-商业秘密 |
| E-06 | 许可链仅记录直接许可方 | 应从原始权利人逐级追踪至最终权利人，超3层标记RC-02 | 许可链追踪法 |
| E-07 | IP出资"公示合规"仅查工商登记 | 应同时核验股东名册记载（第86条）+信息公示（第40条）+变更登记（第34条）三维度 | 出资瑕疵识别法 |
| E-08 | 投前场景输出出资瑕疵深度分析 | 投前仅做清单+初步标记，深度分析仅在投中场景 | 场景差异化方法论 |
| E-09 | R&W条款模板化套用不关联风险 | 每条R&W须关联具体RC规则编号，无对应风险的IP不出具R&W条款 | R&W条款映射法 |
| E-10 | 著作权登记号视为权属取得要件 | 著作权自创作完成自动产生，登记非取得要件，仅具有初步证据效力 | 三级权属核验-著作权 |

## 7. 隐性知识

### 7.1 出资瑕疵实务经验

1. **评估时点陷阱**：IP出资评估值在评估基准日有效，但出资完成可能在数月后——评估值与实际价值可能已显著偏离，须核实评估基准日与权属变更完成日的时间差
2. **权属变更≠工商登记**：专利/商标的权属变更须在国家知识产权局完成转让登记，工商登记仅体现股东名册层面的出资事实——两者缺一均构成瑕疵
3. **高估出资的隐蔽形态**：IP评估值显著高于实际价值不一定表现为"评估值>市场价"，可能表现为"评估方法不当"（如用收益法评估尚未产生收益的早期专利），须审查评估方法论而非仅看数值

### 7.2 许可链实务经验

1. **交叉许可的隐性风险**：芯片/通信行业常见交叉许可，看似"双向授权"实则可能含不对等条款（如一方获全球许可、另一方仅获中国许可），须逐项核对地域/范围/期限
2. **独占许可+多重许可**：独占许可并不意味着不存在其他许可——可能存在"独占许可签订前已授权的普通许可"，独占许可冲突须查历史许可记录
3. **许可到期后的过渡安排**：许可到期不等于立即停止使用——可能有库存消化期、过渡期条款，须核实到期后的实际影响

### 7.3 风险敞口量化（顶级律师风险分层）

IP风险标记不应止步于定性，须提示经济敞口以支撑交易定价与谈判：

| 风险类型 | 量化维度 | 用途 |
|----------|----------|------|
| IP出资瑕疵 | 评估值×瑕疵概率（高估/未交付/未公示） | 调整交易对价/设置陈述保证赔偿 |
| 许可链断裂（红旗） | 被许可方停业/转许可无效导致的收入损失区间 | 交割前提/赔偿条款 |
| 侵权风险 | 潜在赔偿额（法定赔偿上限/实际损失） | 投保知识产权险/价格折让 |

> 量化结果为初步估算，不替代评估或鉴定机构意见；须标注假设与不确定性。
