## 3. Markdown报告（10章节）

### 章节结构

1. **摘要**：资产全景+风险概要+核心建议
2. **工作方法**：场景+Phase说明
3. **资产分类**：按IP类型统计
4. **权属状态**：来源+登记+官方三层核验结果
5. **许可与转让**：链图+负担
6. **风险矩阵**：10项RC结果
7. **出资瑕疵**：历史问题（investment场景）
8. **R&W条款映射**：风险→条款（post_investment场景）
9. **应对建议**：按优先级
10. **局限性说明**：AI边界+人工核验项

### 场景裁剪

| 场景 | 精简章节 |
|------|----------|
| pre_investment | 第7/8章节省略 |
| investment | 全部10章节 |
| post_investment | 仅第8章节（R&W条款） |
| annual_review | 第7/8章节省略+新增"风险变化对比" |

## 4. 越权防御表

| 禁止行为 | 理由 |
|----------|------|
| 不出具法律意见书 | AI非持证律师 |
| 不替代官方查询 | 无法实时访问官方数据库 |
| 不确认权属效力 | 须持证律师判断 |
| 不提供投资决策建议 | 须投资团队判断 |
| 不评估IP商业价值 | 须专业评估机构 |
| 不处理外国IP资产 | 路由至涉外律师 |
