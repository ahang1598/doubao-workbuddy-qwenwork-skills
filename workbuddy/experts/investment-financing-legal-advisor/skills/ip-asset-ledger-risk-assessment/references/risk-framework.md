# 风险框架

## 10项RC风险规则

### RC-01：权属瑕疵

| 项目 | 内容 |
|------|------|
| 类别 | 权属 |
| trigger_condition | IP权属不清/权属争议/权属人不一致/无权属证明 |
| severity | L2/L3（视瑕疵程度） |
| effect_on_output | 标注风险+权属状态矩阵标记瑕疵+R&W权属完整性条款 |
| 法律依据 | 专利法第6条/第8条；商标法第4条；著作权法第11条 |

### RC-02：许可链断裂/过长

| 项目 | 内容 |
|------|------|
| 类别 | 许可 |
| trigger_condition | 许可链超过3层/许可合同缺失/许可链断点 |
| severity | L2 |
| effect_on_output | 标注"许可链过长"或"许可记录待核实"+R&W无许可违约条款 |
| 法律依据 | 民法典合同编第512条（许可合同履行规则）+第545条（债权转让） [需核实] |

### RC-03：许可范围超限/分许可违规

| 项目 | 内容 |
|------|------|
| 类别 | 许可 |
| trigger_condition | 许可地域/范围超出约定/未授权分许可/分许可权不清 |
| severity | L2/L3（未授权分许可为L3） |
| effect_on_output | 标注[红旗]或"许可范围待核实"+R&W无许可违约条款 |
| 法律依据 | 专利法第10条；商标法第43条 |

### RC-04：维护义务缺失（年费/续展）

| 项目 | 内容 |
|------|------|
| 类别 | 续展 |
| trigger_condition | 年费未缴/续展过期/年费状态不明 |
| severity | L1/L2（过期为L2） |
| effect_on_output | 标注"年费待核实"或"续展过期"+R&W未缴费用条款 |
| 法律依据 | 专利法第43条；商标法第40条 |

### RC-05：权利负担（质押/冻结）

| 项目 | 内容 |
|------|------|
| 类别 | 负担 |
| trigger_condition | IP被质押/冻结/查封/其他权利负担 |
| severity | L3 |
| effect_on_output | 标注[红旗]+R&W无负担/无质押条款 |
| 法律依据 | 民法典物权编第440条（知识产权质押）+第443条（质押登记效力） [需核实] |

### RC-06：共有权属未约定

| 项目 | 内容 |
|------|------|
| 类别 | 共有 |
| trigger_condition | IP为共有/共有协议缺失/共有权约定不清 |
| severity | L2 |
| effect_on_output | 标注"共有权属待核实" |
| 法律依据 | 专利法第8条；著作权法第13条 |

### RC-07：出资瑕疵

| 项目 | 内容 |
|------|------|
| 类别 | 出资 |
| trigger_condition | IP出资未评估/未交付/未公示/未决议/高估出资 |
| severity | L3 |
| effect_on_output | 标注出资瑕疵类型+R&W出资真实条款 |
| 法律依据 | 公司法第48条/第49条/第50条/第59条/第34条/第40条/第86条 |

### RC-08：侵权风险

| 项目 | 内容 |
|------|------|
| 类别 | 涉诉 |
| trigger_condition | IP涉嫌侵权第三方权利/收到侵权警告/正在侵权诉讼 |
| severity | L3 |
| effect_on_output | 标注[红旗]+R&W无侵权条款 |
| 法律依据 | 专利法第11条；著作权法第52条；商标法第57条 |

### RC-09：合同风险（许可合同条款不利）

| 项目 | 内容 |
|------|------|
| 类别 | 合同 |
| trigger_condition | 许可合同含不利条款/独占许可冲突/许可期限过长 |
| severity | L2 |
| effect_on_output | 标注合同风险点 |
| 法律依据 | 民法典合同编第509条（合同履行原则）+第563条（合同解除） [需核实] |

### RC-10：商业秘密措施不足

| 项目 | 内容 |
|------|------|
| 类别 | 商业秘密 |
| trigger_condition | 无保密措施/保密协议未签/保密措施不充分 |
| severity | L2/L3 |
| effect_on_output | 标注"措施待律师评估" |
| 法律依据 | 反不正当竞争法第9条 |

## 风险等级定义

| 等级 | 含义 | 应对 |
|------|------|------|
| L1 | 信息性风险 | 标注+提示核实 |
| L2 | 需关注风险 | 标注+建议律师审查+R&W条款 |
| L3 | 高风险 | [红旗]标注+强制律师审查+R&W条款+应对建议 |
