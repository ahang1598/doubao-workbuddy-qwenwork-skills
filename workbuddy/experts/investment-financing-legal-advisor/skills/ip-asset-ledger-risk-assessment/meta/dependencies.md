# 上下游依赖

## 上游依赖

| 依赖技能 | 类型 | 必需 | 缺失处理 |
|----------|------|------|----------|
| `07-公司股权尽职调查` | 数据来源 | 推荐 | 用户自行提供IP资产清单 |
| 用户提供IP证书/登记文件 | 数据来源 | 必需 | 标注"证书待核实"，按用户提供信息登记 |
| 用户提供许可/转让合同 | 数据来源 | 推荐 | 不输出许可链分析 |

## 下游消费者

| 消费技能 | 消费内容 | 协同类型 |
|----------|----------|----------|
| `06-投资协议审查` | R&W条款建议 | 强协同 |
| `02-股东确权` | 出资质检结果 | 弱协同 |
| `03-公司治理诊断` | IP资产风险标记 | 弱协同 |
| `cap-market-special-rights-design` | R&W/IP条款设计参考 | 强协同 |
| `cap-market-founder-liability-review` | IP出资瑕疵→创始人个人责任 | 推荐 |
| `cap-market-cap-table-verify` | IP出资影响股权结构/估值 | 推荐 |
| `cap-market-adversarial-clause-analysis` | IP条款中的不对等/陷阱识别 | 推荐 |
| `cap-market-multi-round-consistency` | 多轮融资IP条款一致性 | 推荐 |

## 数据流

```
07-公司股权尽职调查（附表三：专利权·商标权详情）
        ↓ 原始数据采集
ip-portfolio-ledger（台账生成+风险评估+R&W映射）
        ↓ R&W条款建议
06-投资协议审查（IP条款审查） / cap-market-special-rights-design（IP条款设计）
        ↓ 出资质检结果
02-股东确权（出资合规性判断） / cap-market-founder-liability-review（创始人责任）
```

## 版本兼容性

- 上游 `07-公司股权尽职调查` v1.0.0+：附表三字段兼容
- 下游 `06-投资协议审查` v1.0.0+：R&W条款格式兼容
- 本技能输出xlsx格式，可独立使用，不强制依赖上下游
