# 术语规范

| 术语 | 规范表述 | 说明 |
|------|----------|------|
| 决议不成立 | 决议不成立 | 第27条；基本事实欠缺（未开会/未表决/不达标） |
| 决议无效 | 决议无效 | 第25条；内容违反法律/行政法规强制性规定 |
| 决议可撤销 | 决议可撤销 | 第26条；程序瑕疵或内容违反章程 |
| 决议效力后果 | 决议效力后果 | 第28条；决议无效/被撤销/不成立后的登记撤销等法律后果 |
| 裁量驳回 | 裁量驳回 | 第26条；三要件全满足方可驳回撤销请求 |
| 除斥期间 | 除斥期间 | 第27条；决议不成立之诉≤1年 |
| 一票否决权 | 一票否决权 | 特定股东/董事对特定事项的否决权 |
| 双重否决 | 双重否决 | 约定否决权+法定一致同意事项叠加 |
| 自我交易 | 自我交易 | 新公司法第182条；董监高与公司交易 |
| 公司商业机会 | 谋取公司商业机会 | 新公司法第183条 |
| 同业竞争 | 同业竞争 | 新公司法第184条；经营同类业务 |
| 关联交易披露 | 关联交易披露 | 新公司法第185条 |
| 归入权 | 归入权 | 违反第182-184条→所得收入归公司所有 |
| 股东同意不免责 | 股东同意不免责 | 公司法解释五第1条 |
| 善意第三人 | 善意第三人 | 第67条第3款章程限制不得对抗 |
