# 使用说明

## 快速开始

### 场景1：决议效力审查
```
用户：董事会决议通过了向大股东关联公司采购的方案，小股东反对，这个决议有效吗？
```
技能执行决议效力三分法判断，输出决议效力状态+法律依据。

### 场景2：一票否决权诊断
```
用户：章程给了投资方一票否决权，范围包括所有50万以上交易，这会不会有问题？
```
技能执行否决权四要点检查+僵局风险评估。

### 场景3：同业竞争检查
```
用户：创始人另外开了一家同行业公司，这算同业竞争吗？
```
技能执行同业竞争三要素判断，引用新公司法第184条。

### 场景4：关联交易合规
```
用户：大股东通过关联交易把公司利润转移走了，虽然经过股东会同意，能追回吗？
```
技能执行关联交易合规检查，引用《公司法解释五》第1条"股东同意不免责"规则。

## 使用建议

1. 提供公司章程相关条款
2. 提供决议全文和程序细节
3. 标注PE机构持股情况（影响同业竞争判断）
4. 关注新公司法第182-185条体系变化
