# 场景路由配置说明

## 1. 五种交易场景

| 场景 | 标识 | 配置文件 | 适用情况 |
|------|------|---------|---------|
| 投资并购 | S-MNA | scenario-mna.json | 股权收购/合并/控股收购 |
| PE/VC投资 | S-PE | scenario-pe.json | 增资扩股/股权转让/创投 |
| IPO | S-IPO | scenario-ipo.json | 上市前尽职调查 |
| 资产收购 | S-ASSET | scenario-asset.json | 特定资产交易（不收购股权） |
| 跨境投资 | S-CROSSBORDER | scenario-crossborder.json | FDI（外商直接投资）/ODI（对外投资） |

## 2. 模块选择规则

### 2.1 各场景模块启用矩阵

| 模块 | S-MNA | S-PE | S-IPO | S-ASSET | S-CROSSBORDER | 说明 |
|------|:-----:|:----:|:-----:|:-------:|:-------------:|------|
| M1 公司基本信息 | Y | Y | Y | Y | Y | 全场景必需 |
| M2 股权结构 | Y重点 | Y重点 | Y重点 | N | Y重点 | 资产收购不关注股权 |
| M3 公司治理 | Y | Y | Y重点 | N | Y | IPO需完整三会文件 |
| M4 财务税务 | Y | Y | Y重点 | Y | Y | IPO需3年+1期审计 |
| M5 资产知识产权 | Y | Y重点 | Y | Y重点 | Y | 资产收购为重点 |
| M6 重大合同债权债务 | Y重点 | Y | Y | Y重点 | Y | M&A关注或有负债 |
| M7 劳动人事 | Y | Y | Y | N | Y | PE关注核心团队 |
| M8 诉讼仲裁 | Y | Y | Y | Y | Y | 全场景必需 |
| M9 环保合规 | Y | N条件 | Y重点 | N条件 | N条件 | 制造业/IPO必需 |
| M10 场景特定 | Y | Y | Y | Y | Y | 动态扩展 |
| M11 数据安全 | N条件 | Y | Y重点 | N | Y | 软件/互联网/金融/IPO必需；资产收购禁用 |
| M12 保险 | Y重点 | Y推荐 | Y重点 | Y低 | Y | M&A/IPO强制，PE推荐，资产收购低优先级 |

Y = 启用 / Y重点 = 启用且重点 / Y推荐 = 启用推荐级 / N = 不启用 / N条件 = 视行业启用

### 2.2 模块优先级标注

| 优先级 | 含义 | 材料项深度 |
|--------|------|-----------|
| 高 | 该场景核心关注模块 | 全面覆盖（10-20项） |
| 中 | 重要但非核心模块 | 标准覆盖（6-12项） |
| 低 | 辅助模块 | 精简覆盖（3-8项） |

### 2.3 各场景重点模块

**S-MNA（投资并购）**：
- 重点：M2股权结构、M3公司治理、M6重大合同与债权债务、M12保险
- 核心关切：或有负债、真实价值、控制权、保险覆盖

**S-PE（PE/VC投资）**：
- 重点：M2股权结构（估值依据/投资者权利）、M5资产与知识产权（核心资产）、M7劳动人事（核心团队）
- 核心关切：投资回报、退出机制、核心资产价值、投资者权利保护

**S-IPO（IPO）**：
- 重点：全部12模块（最深入），特别关注 M3公司治理（三会规范）、M4财务税务（3年+1期）、M9环保合规、M11数据安全、M12保险
- 核心关切：股权清晰、合规性、信息披露、董监高责任

**S-ASSET（资产收购）**：
- 重点：M5资产与知识产权（权属证明）、M6重大合同与债权债务（资产相关合同）
- 核心关切：资产权属清晰、资产无负担

**S-CROSSBORDER（跨境投资）**：
- 重点：M2股权结构（穿透至最终受益人）、M4财务税务（转移定价）、M10场景特定（FDI/ODI审批文件）、M11数据安全（数据出境）
- 核心关切：外资准入合规、国家安全审查、数据跨境合规、外汇管理

## 3. 行业适配规则

### 3.1 M9 环保合规模块的行业适配

| 行业 | M9处理 | 说明 |
|------|--------|------|
| 制造业 | 全量启用 | 环评报告/排污许可证/安全生产许可证 |
| 采矿/能源 | 全量启用+加强 | 采矿许可证/安全生产许可证/环境恢复方案 |
| 软件开发/IT | 精简（3项） | 仅保留消防验收等基础项 |
| 金融服务 | 精简（3项） | 仅保留监管合规项 |
| 房地产 | 全量启用 | 建设用地规划许可证/建设工程规划许可证 |
| 农业 | 全量启用 | 农用地审批/环评 |
| 新能源 | 全量启用 | 碳排放配额/可再生能源补贴/发电业务许可证 |

### 3.2 M10 场景特定模块的行业适配

| 行业 | M10追加内容 |
|------|-----------|
| 软件/互联网 | 数据合规（转入M11专项处理）+ ICP备案 |
| 金融 | 监管许可（金融牌照/业务许可证） |
| 跨境贸易 | 外汇管理/海关合规/FDI/ODI审批 |
| 医疗 | 医疗机构执业许可证/药品注册证/临床试验批件 |
| 食品 | 食品经营许可证/SC认证 |
| 房地产 | 预售许可证/竣工验收备案/土地出让合同 |
| 教育 | 办学许可证 |
| 半导体 | 集成电路设计企业认定 |
| 新能源 | 发电业务许可证/碳排放配额/可再生能源补贴 |

### 3.3 M11 数据安全模块的行业适配

| 行业 | M11处理 | 说明 |
|------|---------|------|
| 软件/互联网 | 全量启用 | 15+项全面覆盖 |
| 金融 | 全量启用 | 含金融数据安全特殊要求 |
| 医疗 | 全量启用 | 含健康医疗数据保护 |
| 跨境（FDI/ODI） | 全量启用 | 含数据出境安全评估 |
| IPO | 全量启用 | 强制要求 |
| 制造业 | 精简（5项） | 基础数据安全制度 |
| 其他 | 条件启用 | 根据数据量/业务类型判断 |

## 4. 深度调整规则

| 深度 | M1-M4 | M5-M8 | M9-M12 | 总计 |
|------|-------|-------|--------|------|
| 快速 | 仅必须项 | 仅必须项 | 禁用M10/M11/M12 | 35-50项 |
| 标准 | 必须+推荐 | 必须+推荐 | 仅必须项 | 65-100项 |
| 深入 | 全部 | 全部 | 必须+推荐 | 100-150项 |

## 5. 配置文件格式

每个场景配置 JSON 文件的结构：

```json
{
  "scenario_id": "S-PE",
  "scenario_name": "PE/VC投资",
  "modules": {
    "M1": {"enabled": true, "priority": "high", "depth": "standard"},
    "M2": {"enabled": true, "priority": "high", "depth": "full"},
    ...
  },
  "industry_adaptation": {
    "manufacturing": {"M9": {"enabled": true, "priority": "high"}},
    "software": {"M9": {"enabled": false}, "M11": {"enabled": true, "priority": "high"}}
  }
}
```
