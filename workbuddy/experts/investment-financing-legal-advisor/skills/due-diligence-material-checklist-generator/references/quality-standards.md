# 质量标准

## 1. 六维评价体系

| 维度 | 权重 | 评价标准 | 检查方法 |
|------|------|---------|---------|
| 场景适配性 | 25% | 清单是否精准匹配交易场景的重点模块和深度 | 对照场景路由表检查模块启用和优先级 |
| 模块覆盖度 | 20% | 12大模块是否按场景需要充分覆盖 | 检查启用模块数和重点模块覆盖 |
| 必需性合理性 | 20% | 必须项/推荐项/可选项的标注是否合理，场景必需性矩阵是否生效 | 检查必须项占比（30-50%）和标注依据 |
| 编号规范性 | 10% | 序号/模块号/场景标识是否规范连续 | 检查编号连续性和格式一致性 |
| 提交阶段合理性 | 15% | 三阶段分配是否均衡合理 | 检查各阶段项数分布 |
| 备注完整性 | 10% | 备注是否标注原件/复印件/特殊要求/法条依据 | 检查备注列填充率 |

## 2. 阻断检查项（必须为0才能通过）

| # | 检查项 | 通过条件 |
|---|--------|---------|
| QC-01 | 模块覆盖度 | 启用模块 ≥ 5 |
| QC-02 | 模块材料项数 | 每启用模块 ≥ 3项 |
| QC-03 | 编号连续性 | 无跳号（M1-001→M1-002→...） |
| QC-04 | 必需性标注 | 100%覆盖（每项都有标注） |
| QC-05 | 场景重点模块 | 场景路由表中标注"重点"的模块全部启用 |
| QC-06 | 免责声明 | 输出含免责声明 |
| QC-07 | Excel文件生成 | Excel文件成功生成（退出码=0）或已降级标注 |
| QC-08 | 不产出清单 | 无越界产出（不含尽调报告/法律意见等） |

## 3. 警告检查项（标注但不阻断）

| # | 检查项 | 警告条件 |
|---|--------|---------|
| QC-09 | 提交阶段分配 | 第一阶段项数 > 总项数50% |
| QC-10 | 必须项占比 | < 30% 或 > 50% |
| QC-11 | 备注填充率 | < 60% |
| QC-12 | 可选项占比 | > 40%（可选项过多可能清单不够聚焦） |
| QC-13 | M9行业适配 | 行业=制造业但M9未启用 |
| QC-14 | M10场景特定 | 特定关注点输入有值但M10未追加 |

## 5. 质量检查流程

```
Phase 5 质量检查：
  1. 执行 QC-01~QC-08 阻断检查（基础）
  2. 执行 QC-15~QC-19 阻断检查（v1.2.0场景增强）
     → 任一失败 → 标注问题 + 降级处理
  3. 执行 QC-09~QC-14 警告检查（基础）
  4. 执行 QC-20~QC-22 警告检查（v1.2.0增强）
     → 标注警告项（不阻断）
  5. 生成质量检查摘要
     → 阻断项数 / 警告项数 / 通过/不通过
```

## 6. 质量检查摘要格式

```markdown
## 质量检查摘要

| 类型 | 数量 | 详情 |
|------|------|------|
| 阻断项 | 0 | — |
| 警告项 | 2 | QC-09: 第一阶段项数占比55%（建议<50%）; QC-11: 备注填充率55%（建议>60%） |

**结论**: 通过（有警告项，建议律师关注）
```
