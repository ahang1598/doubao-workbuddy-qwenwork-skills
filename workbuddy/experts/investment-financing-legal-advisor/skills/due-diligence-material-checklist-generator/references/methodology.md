# 清单构建方法论

## 1. 核心方法论

### 1.1 风险驱动原则（v1.2.0 新增）

> **从"模块覆盖型"升级为"风险驱动型"**

清单不应从"有哪些模块"出发，而应从"有哪些风险假设"出发：
对每个风险假设，设计针对性验证材料，确保每个高风险假设至少有1项验证材料。

| 风险假设 | 验证材料（示例） | 对应模块 |
|----------|----------------|---------|
| 出资不实 | 验资报告/银行流水/出资凭证 | M2 |
| 股权代持 | 代持协议/访谈记录/资金来源说明 | M2 |
| 关联输送 | 关联交易合同/定价政策/同类交易比价 | M3/M6 |
| 同业竞争 | 实际控制人其他公司清单/相关业务合同 | M3 |
| 隐性负债/或有负债 | 对外担保合同/或有负债说明/诉讼清单 | M6/M8 |
| 核心IP权属瑕疵 | 职务发明确认书/IP权属转让协议/许可协议 | M5 |
| 税务风险 | 纳税申报表/税务检查报告/税收优惠文件 | M4 |
| 社保合规风险 | 社保缴纳凭证/社保基数核定/工伤记录 | M7 |
| 员工集体流失 | 核心员工合同/竞业限制/股权激励 | M7 |
| 数据合规风险 | PIA报告/等保备案/数据出境评估 | M11 |
| 环境违规风险 | 环评报告/排污许可/环保处罚记录 | M9 |
| 投资者权利未登记 | 对赌协议/优先权文件/回购权文件 | M2 |
| 保险覆盖不足 | 全部有效保单/理赔记录 | M12 |

### 1.2 交叉验证原则（v1.2.0 新增）

> **用A验证B——顶级尽调清单的灵魂**

清单不只是"列材料"，而应内置材料间的交叉验证逻辑。同一事实从2+个独立来源交叉印证，大幅提升尽调可靠性。

| 验证关系 | 材料A | 材料B | 验证内容 |
|----------|------|------|---------|
| 收入真实性 | 前十大客户合同 | 银行流水（近1年） | 合同金额与回款是否匹配 |
| 纳税真实性 | 纳税申报表 | 审计报告 | 收入/利润是否一致 |
| 员工真实性 | 员工名册 | 社保缴纳凭证 | 人数/身份是否匹配 |
| 固定资产存在 | 固定资产台账 | 资产照片/实物盘点 | 数量/型号/状态 |
| 应收账款真实 | 应收账款明细表 | 客户合同 | 欠款对象/金额/账龄 |
| 股权出资真实 | 验资报告 | 银行流水 | 出资款是否实际到账 |
| 关联交易公允 | 关联交易合同 | 同类交易合同（非关联方） | 价格/条件是否有差异 |
| 环保合规性 | 环评批复 | 排污许可证 | 排污许可是否覆盖环评要求 |
| 诉讼披露完整 | 未决诉讼清单 | 企业信用报告/企查查 | 是否遗漏公开可查诉讼 |
| 数据合规落地 | 隐私政策/用户协议 | PIA报告 | 告知内容与实际做法是否一致 |

### 1.3 场景驱动原则（v1.0继承）

尽调清单不是"通用清单加几项"——不同交易场景的尽调目的完全不同，清单必须从场景出发：

| 场景 | 尽调核心目的 | 清单设计重心 |
|------|------------|------------|
| M&A | 发现或有负债、确认真实价值 | M2股权/M3治理/M6合同债权债务/M12保险 |
| PE | 确认投资回报与退出路径 | M2股权(估值+投资者权利)/M5核心资产/M7核心团队 |
| IPO | 确认上市合规性 | 全模块最深入，M3三会规范/M4财务/M11数据安全/M12保险 |
| 资产收购 | 确认资产权属清晰 | M5资产权属/M6资产相关合同 |
| 跨境投资 | 确认外资准入合规 | M2穿透/M4转移定价/M10 FDI-ODI审批/M11数据出境 |

### 1.4 模块化组合原则（v1.0继承）

12大模块不是固定不变的——根据场景灵活组合：
- 全场景必需模块：M1/M4/M8（基本信息/财务/诉讼）
- 场景重点模块：根据场景路由表标注"重点"的模块
- 条件启用模块：M9（视行业）、M10（动态扩展）、M11（软件/互联网/金融/IPO）、M12（M&A/IPO强制）
- 资产收购场景特例：M2/M3/M7/M11禁用（不关注公司主体）

### 1.5 必需性分级原则（v1.0继承）

三级必需性标注的标准：

**必须** [高]：
- 缺失将导致无法做出尽调基本判断
- 法律法规明确要求的文件
- 交易核心关切直接相关的材料
- **场景必需性**：同一材料在不同场景下必需性不同（v1.2.0 增强）

**推荐** [中]：
- 缺失可能影响尽调深度但不影响基本判断
- 深入了解公司状况所需的材料
- 风险识别所需的补充材料

**可选** [低]：
- 视交易具体情况决定是否索取
- 非核心但有参考价值的材料
- 特殊情况才需要的材料

### 1.6 提交阶段分配原则（v1.0继承）

三阶段分配的逻辑：

**第一阶段（基础信息类）**：
- 公司基本证照、股权结构、组织架构
- 目标：快速建立公司基本画像
- 项数控制：总项数的30-40%

**第二阶段（核心经营类）**：
- 财务税务、资产IP、重大合同
- 目标：深入了解经营状况和价值
- 项数控制：总项数的40-50%

**第三阶段（补充完善类）**：
- 劳动人事、诉讼仲裁、环保合规、数据安全、保险
- 目标：排查风险点和合规问题
- 项数控制：总项数的15-25%

### 1.7 动态迭代原则（v1.2.0 新增）

> **"先发基本清单，后发补充清单"**

第一阶段清单发出后，根据收回的材料发现新问题，再发补充清单。不要一次性发全量清单让目标公司感到压力过大。

**补充清单生成触发条件**：
- 发现新风险（如实际控制人存在同业竞争嫌疑 → 补充同业竞争核查材料）
- 交叉验证发现矛盾（如纳税申报与审计报告收入不一致 → 补充收入确认材料）
- 未收回核心材料（如未提供对赌协议 → 补充索取催收函）

**补充清单标注**：在备注列标注"补充清单v{N}，原因：{触发条件}"

### 1.8 材料获取难度分级（v1.2.0 新增）

| 获取难度 | 含义 | 提交阶段建议 | 示例 |
|----------|------|------------|------|
| 易 | 公司内部常规存档，随时可取 | 第一阶段 | 营业执照/公司章程/组织架构图 |
| 中 | 需协调内部多部门 | 第二阶段 | 审计报告/纳税申报/劳动合同 |
| 难 | 需第三方/政府部门出具 | 第三阶段 | D&O保险/营评结果/政府批文 |
| 极难 | 需目标公司专项编写 | 第三阶段 | 或有负债说明/历史沿革说明/IP权属确认书 |

## 2. 隐性知识

### 2.1 律师实务中的清单经验

1. **"先发基本清单，后发补充清单"**：第一阶段清单发出后，根据收回的材料发现新问题，再发补充清单。不要一次性发全量清单让目标公司感到压力过大。（v1.2.0 升级为正式方法论 §1.7）

2. **"必须项宁少勿多"**：必须项过多会导致目标公司准备困难，反而拖延整体进度。建议必须项控制在总项数的30-40%。

3. **"行业特定材料要单列"**：不要把行业特定材料混在通用模块中，应在 M10 模块单列，便于目标公司对口部门准备。

4. **"原件与复印件要标注"**：备注列中明确标注"需提供原件核对"或"复印件加盖公章"，避免来回沟通。

5. **"负面信息要主动索取"**：诉讼仲裁/行政处罚/环保处罚等负面信息材料，目标公司可能不会主动提供，必须在清单中明确列示。

6. **"关联交易要穿透"**：M6 中的关联交易合同，要追溯关联方的股权结构，要求提供关联关系说明。

7. **"核心团队稳定性"**：PE 场景下，M7 中要特别关注核心员工的竞业限制和股权激励，评估团队稳定性。

8. **"资产收购不等于公司尽调"**：资产收购场景下，M2/M3/M7/M11 大量禁用或精简，重心放在 M5 资产权属和 M6 资产相关合同上。

9. **"PE尽调必须查投资者权利"**：PE 投资清单如缺对赌协议/反稀释/优先清算权等投资者权利文件，等于没查核心。这些文件是 PE 尽调的灵魂。（v1.2.0 新增）

10. **"数据合规是新尽调维度"**：2021-2022年数据三法出台后，数据安全已成独立尽调维度，与环保合规/劳动人事并列。软件/互联网/金融类目标公司若不查数据合规，属重大遗漏。（v1.2.0 新增）

11. **"保险覆盖不可遗漏"**：M&A 交易中，目标公司的保险覆盖情况关系到交易后风险承担——特别是 D&O 保险是否覆盖历史行为/产品责任险是否覆盖已售产品。（v1.2.0 新增）

12. **"跨境投资要查三关"**：FDI 查三关——外资准入（负面清单）/安全审查/反垄断审查；ODI 查三关——发改委/商务部/外汇局。（v1.2.0 新增）

### 2.2 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 通用清单不分场景 | 部分场景信息冗余，部分场景关键材料遗漏 | 按场景路由差异化清单 |
| 必须项过多 | 目标公司准备困难，拖延进度 | 控制必须项在30-40% |
| 未标注原件/复印件 | 来回沟通效率低 | 备注列明确标注 |
| 未索取负面信息 | 尽调不全面，遗漏重大风险 | 诉讼/处罚材料必须列示 |
| 未考虑行业特殊性 | 行业特定合规要求遗漏 | M10/M11 模块行业适配 |
| 一次性发全量清单 | 目标公司压力大，配合度低 | 分三阶段逐步索取 |
| 未追踪已有材料 | 重复索取，影响配合度 | 参照 existing_materials 标注 |
| PE尽调缺投资者权利文件 | 投资条款保护无法验证，重大风险遗漏 | M2模块完整列出对赌/反稀释/优先权等 |
| 科技公司缺数据安全材料 | 数据合规风险完全遗漏 | 科技类目标公司强制启用 M11 |
| 缺乏交叉验证设计 | 材料真实性问题无法发现 | 内置交叉验证关系对 |

## 3. 场景特定方法论

### 3.1 M&A 场景清单要点

- M2 股权结构：穿透到实际控制人，索取代持协议/一致行动协议/投资者权利文件
- M6 重大合同：重点关注或有负债——担保合同/对赌协议/回购条款
- M3 公司治理：三会决议完整性，特别关注关联交易决策程序
- M12 保险：全部有效保单+理赔记录，特别关注D&O保险

### 3.2 PE 场景清单要点

- M2 股权结构：估值依据——历轮融资协议/估值调整条款/反稀释条款/对赌协议/优先清算权（v1.2.0 增强）
- M5 资产IP：核心资产权属——专利/商标/著作权/软著的权属清晰性
- M7 劳动人事：核心团队——核心员工合同/竞业限制/股权激励
- M11 数据安全：科技类目标公司必查

### 3.3 IPO 场景清单要点

- M3 公司治理：三会规范——近3年完整三会文件/议事规则/内控制度
- M4 财务税务：3年+1期——审计报告/纳税申报/税务合规/内控审计报告
- M9 环保合规：最严格要求——环评/排污许可/安全生产/消防验收
- M11 数据安全：全量启用——15+项数据合规审查
- M12 保险：D&O保险/财产险/公众责任险

### 3.4 资产收购场景清单要点

- M5 资产权属：权属证明——不动产产权/专利证书/商标注册证/车辆登记
- M6 资产相关合同：资产关联——与资产相关的采购/销售/租赁/担保合同
- 精简原则：M2/M3/M7/M11 禁用，仅保留与资产直接相关的部分

### 3.5 跨境投资场景清单要点（v1.2.0 新增）

- FDI方向：外资准入合规——负面清单核查/外商投资信息报告/安全审查决定/经营者集中申报
- ODI方向：境外投资审批——发改委备案/核准+商务部备案+外汇登记
- M4 转移定价：关联交易同期资料/跨境税务安排证明
- M11 数据出境：数据出境安全评估/标准合同/个人信息保护合规
- M2 穿透：最终受益人穿透至自然人（符合外商投资安全审查要求）
