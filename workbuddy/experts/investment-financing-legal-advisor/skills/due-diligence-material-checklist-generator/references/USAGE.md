# 尽调材料清单生成 — 使用说明 (v1.2.0)

## 快速上手

### 1. 确定交易场景

| 场景 | 适用情况 | 标识 |
|------|---------|------|
| 投资并购 (M&A) | 股权收购/合并/控股收购 | S-MNA |
| PE/VC投资 | 增资扩股/股权转让/创投 | S-PE |
| IPO | 上市前尽职调查 | S-IPO |
| 资产收购 | 特定资产交易（不收购股权） | S-ASSET |
| 跨境投资 | FDI/ODI | S-CROSSBORDER（v1.2.0新增） |

### 2. 提供基本信息

**必需**：
- 交易场景类型（从上表选择）
- 目标公司全称

**推荐提供**（提升清单精确度）：
- 目标公司行业（如：制造业/软件开发/金融服务）
- 公司类型（有限责任公司/股份有限公司/合伙企业/外商投资企业）
- 尽调深度（快速/标准/深入）

### 3. 获取输出

技能将生成：
- **Excel 文件**：`尽调材料清单_{场景标识}_{公司名}_{日期}.xlsx`（含4 Sheet + 仪表盘）
- **Markdown 预览**：会话窗口即时显示
- **Cover Letter**：尽调材料索取函（v1.2.0新增）

## 场景选择指引

### M&A（投资并购）

适用：收购方全面收购目标公司股权，需全面了解公司状况。
重点模块：M2股权结构（含投资者权利）、M3公司治理、M6重大合同与债权债务、M12保险。
预计材料项：80-120项。
**v1.2.0 增强**：新增 M12 保险模块（财产险/D&O/公众责任险）+ M11 条件启用。

### PE/VC投资

适用：投资方对目标公司进行增资或受让老股，关注投资回报与退出。
重点模块：M2股权结构（估值依据+投资者权利）、M5资产与知识产权（核心资产）、M7劳动人事（核心团队）。
预计材料项：65-95项。
**v1.2.0 增强**：强制包含对赌协议/反稀释条款/优先清算权/回购权等投资者权利文件。

### IPO

适用：拟上市企业上市前全面尽职调查，标准最高。
重点模块：全部12模块（最深入），特别关注M3公司治理（三会规范）、M4财务税务（3年+1期审计）、M9环保合规、M11数据安全、M12保险。
预计材料项：100-150项。
**v1.2.0 增强**：新增 M11 数据安全（全量启用）+ M12 保险（全量启用）+ M4 补充内控审计/高企证书。

### 资产收购

适用：收购特定资产（不收购股权），关注资产权属清晰。
重点模块：M5资产与知识产权（权属证明）、M6重大合同与债权债务（资产相关合同）。
预计材料项：50-75项。

### 跨境投资（v1.2.0新增）

适用：外商直接投资(FDI)或境外投资(ODI)。
重点模块：M2穿透至最终受益人、M4转移定价、M10 FDI/ODI审批文件、M11数据出境。
预计材料项：70-100项。
**包含**：FDI备案/核准、ODI备案/核准、国家安全审查、反垄断审查、数据出境安全评估。

## 输出说明

### Excel 文件结构

| Sheet | 名称 | 内容 | 条件 |
|-------|------|------|------|
| Sheet1 | 尽调材料清单 | 主表，11列+状态仪表盘（v1.2.0） | 始终生成 |
| Sheet2 | 场景说明与填写指引 | 场景类型/模块覆盖/填写说明/接收状态说明 | 始终生成 |
| Sheet3 | 提交阶段分配 | 按阶段分组的材料清单 | 材料项>30时 |
| Sheet4 | 部门分派视图 | 按目标公司部门分组的材料清单（v1.2.0新增） | 材料项>30时 |

### Excel 主表列说明（v1.2.0 列7→11）

| 列 | 名称 | 说明 |
|----|------|------|
| A | 序号 | 模块号+3位序号，如 M1-001 |
| B | 模块 | 十二大模块名称 |
| C | 资料名称 | 具体材料名称 |
| D | 资料类型 | 证照/合同/决议/财务报表/其他 |
| E | 必需性 | 必须(红底) / 推荐(黄底) / 可选(灰底) |
| F | 提交阶段 | 第一阶段 / 第二阶段 / 第三阶段 |
| G | 存档部门 | 行政部/财务部/法务部/人力资源部/IT部/业务部（v1.2.0新增） |
| H | 接收状态 | 下拉框：已收(绿)/未收(红)/部分提供(黄)/拒绝提供(蓝)（v1.2.0新增） |
| I | 收件日期 | 收到材料日期（v1.2.0新增） |
| J | 提供形式 | 原件/复印件(盖章)/电子版PDF/电子版扫描件（v1.2.0新增） |
| K | 备注 | 特殊说明/法条依据（含原件/复印件/公证/电子版要求） |

### 必需性标注说明

- **必须** [高]：核心材料，缺失将影响尽调基本判断
- **推荐** [中]：重要材料，缺失可能影响尽调深度
- **可选** [低]：辅助材料，视交易具体情况决定是否索取

### 接收状态说明（v1.2.0新增）

清单发送后，在Excel中更新各材料的接收状态：
- **未收(红)**：尚未收到该材料（初始状态）
- **已收(绿)**：已收到该材料
- **部分提供(黄)**：仅提供部分内容，需继续跟进
- **拒绝提供(蓝)**：目标公司明确拒绝提供

Sheet1底部自动统计各状态材料数量。

## Cover Letter 使用说明（v1.2.0新增）

技能默认生成尽调材料索取函，包含：
- 律所抬头/目标公司收件人
- 索取依据（交易协议/法律依据）
- 材料提交要求（格式/期限/联系人）
- 清单结构概述（三阶段+N项）

**律师使用前须补充**：
1. 律所名称和律师信息
2. 回复期限（请根据交易时间线确定）
3. 联系人电话和邮箱

**注意**：索取函中的律师信息为占位符，请务必替换为实际信息。

## 补充清单机制（v1.2.0新增）

v1.2.0 支持动态迭代——先发基本清单，根据已收材料发现新问题后发补充清单：

**触发条件**：
- 发现新风险（如实际控制人存在同业竞争嫌疑）
- 交叉验证发现矛盾（如纳税申报与审计报告不一致）
- 未收回核心材料（需催收）

**使用方式**：
- 将已收材料填入 existing_materials 字段
- 新增关注点填入 specific_concerns 字段
- 再次生成——技能自动标注"补充清单v2"并仅输出新增/变更项

## 律师必检清单

发送目标公司前，律师应检查以下 7 项（v1.2.0新增2项）：

1. **模块覆盖度**：清单是否覆盖了本次交易需要了解的全部领域？
2. **必需性合理性**：每项材料的"必须/推荐/可选"标注是否合理？
3. **提交阶段分配**：三阶段分配是否符合交易时间线？
4. **场景适配性**：清单是否针对本次交易场景做了差异化调整？
5. **场景必查材料**：PE场景是否含对赌协议？IPO是否含D&O保险？科技公司是否含数据安全？
6. **特殊关注点**：是否有特定关注点未在清单中体现？
7. **Cover Letter**：索取函中的律师信息和回复期限是否已更新？

## 常见问题

**Q: Excel 文件无法打开？**
A: 确保系统安装了 Excel 或 WPS。如脚本执行失败，技能会自动降级为仅输出 Markdown 预览。

**Q: PE 场景不想要对赌协议材料？**
A: 不建议删除。对赌协议是 PE 尽调的核心，缺失可能导致投资条款无法验证。如确无对赌，请在备注列标注"目标公司确认无对赌协议"。

**Q: 如何跟踪材料提交状态？**
A: v1.2.0 已内置状态跟踪——在 Excel H列下拉框选择状态，I列填写日期，J列填写形式。底部仪表盘自动统计。

**Q: 可以生成英文版清单吗？**
A: v1.2.0 仅支持中文。v3.0 将支持多语言输出。

**Q: 跨境投资清单有什么区别？**
A: S-CROSSBORDER 场景额外包含 FDI/ODI 审批文件、外商投资安全审查、数据出境评估、转移定价文档等跨境专项材料。
