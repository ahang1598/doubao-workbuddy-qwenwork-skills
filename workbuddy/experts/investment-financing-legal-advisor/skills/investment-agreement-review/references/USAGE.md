# 使用说明

## 快速开始

### 场景1：审查投资协议
```
用户：审查这份增资协议 [附协议文件]
```
技能先解析协议→按六组规则集逐条审查→输出结构化检查表。

### 场景2：检索条款
```
用户：协议里有没有回购触发条款？回购条件是什么？
```
技能在解析后的结构化JSON中检索→三态回复。

### 场景3：系统性改写
```
用户：把对赌条款从单方对赌改成双方对赌，同时调整反稀释条款
```
技能跨条款系统性修改→一致性校验→输出docx修订版（须人审）。

### 场景4：处置方案
```
用户：投资人要退出，协议里有回购权和拖售权，帮我设计处置方案
```
技能基于协议条款和现状→设计≥2套处置路径。

## 使用建议

1. 提供完整协议文件（PDF可复制/Word/文本）
2. 明确协议类型（SPA/SHA/增资/股权转让）
3. 审查时可指定启用规则组（默认全部六组）
4. 改写后须经持证律师人工审核
5. 关注规则未覆盖条款→建议人工审查
