# 术语规范

| 术语 | 规范表述 | 说明 |
|------|----------|------|
| SPA | 股份购买协议 | Share Purchase Agreement |
| SHA | 股东协议 | Shareholders' Agreement |
| VA | 估值调整规则组 | 对赌/回购/反稀释/业绩补偿 |
| GOV | 治理规则组 | 董事会/表决权/一票否决/保护性条款 |
| EX | 退出规则组 | 清算优先/拖售/跟售/转换权 |
| FP | 创始人保护规则组 | 股权锁定/成熟期/转让限制/竞业禁止/知识产权归属 |
| IR | 信息权规则组 | 知情权/报告义务/检查权/审计权 |
| MR | 多轮一致性规则组 | 反稀释跨轮/清算叠加/董事席位累计 |
| 对赌 | 对赌协议/VAM | 估值调整机制 |
| 反稀释 | 反稀释 | Anti-dilution；加权平均/完全棘轮 |
| 清算优先 | 清算优先权 | Liquidation Preference |
| 拖售权 | 拖售权 | Drag-along Right |
| 跟售权 | 跟售权 | Tag-along Right |
| 成熟期 | 股权成熟期 | Vesting Period |
| 三态回复 | 三态回复 | 明确有/明确无/需人工确认 |
| 人审关卡 | 人审关卡 | 改写输出须经人工审核 |
| 一致性校验 | 一致性校验 | 改写后检查关联条款是否冲突 |
