# 术语规范

| 术语 | 说明 |
|------|------|
| 陷阱条款 | 表面看似中性但实际赋予投资方不对称权利或稀释创始人权益的条款 |
| 控制轴 | T1-T7，关注不对等控制权/单方裁量 |
| 经济轴 | T8-T12，关注经济机制稀释创始人权益 |
| T1不对称触发 | 投资方有权但无义务 |
| T2隐性控制权 | 通过信息/检查/审批权变相控制 |
| T3瀑布式赔偿 | 赔偿无上限/无时效 |
| T4锁死条款 | 转让限制过严无例外 |
| T5惩罚性违约金 | 违约金远超实际损失 |
| T6单方裁量 | 投资方单方决定权过大 |
| T7隐蔽交叉引用 | 通过引用扩大权利范围 |
| T8反稀释 | full ratchet/不利加权平均，稀释创始人股权 |
| T9清算优先权 | 1x+参与权等结构压低创始人 exit 收益 |
| T10对赌/VAM | 与创始人/目标公司对赌的回购或补偿义务 |
| T11最惠国(MFN) | 后续轮次更优条款自动回溯适用 |
| T12拖售权 | 低门槛强制创始人出售 |
| 对抗性分析 | 从创始方视角分析条款不利影响（含经济量化） |
| 严重度 | 高/中/低三级，情境依赖 |
| 市场惯例基准 | 判断条款属市场标准还是投资人过度主张 |
| 谈判优先级 | 必争/可谈/市场惯例 三级 |
