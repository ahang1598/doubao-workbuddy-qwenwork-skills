# 工作流详细步骤

## Phase 1: 协议解析
1. 解析投资协议（PDF/Word→文本）
2. 提取定义术语表（defined terms），识别嵌套定义
3. 识别条款结构和交叉引用，建立引用链图谱

## Phase 2: 双轴十二类陷阱逐类扫描

### 控制轴（T1-T7）
- **T1 不对称触发**：关键词 有权/可以/shall not be obligated to；识别投资方有权无义务
- **T2 隐性控制权**：关键词 审批/同意/批准/合理判断；识别信息权/检查权/审批权变相控制
- **T3 瀑布式赔偿**：关键词 赔偿/补偿/无上限/无限连带；识别无上限/无时效/无限连带
- **T4 锁死条款**：关键词 不得转让/限制转让/lock-up；识别无例外严格限制
- **T5 惩罚性违约金**：关键词 违约金/万分之/每日；识别超实际损失且无上限
- **T6 单方裁量**：关键词 合理判断/自行决定/sole discretion；识别单方决定权过大
- **T7 隐蔽交叉引用**：关键词 详见/按照/依据第X条；识别引用扩大权利范围

### 经济轴（T8-T12，新增）
- **T8 反稀释**：关键词 反稀释/anti-dilution/full ratchet/加权平均；识别完全棘轮或不利基数
- **T9 清算优先权**：关键词 清算优先权/liquidation preference/participating/参与分配；识别参与权叠加
- **T10 对赌/VAM**：关键词 对赌/估值调整/业绩承诺/回购/现金补偿；识别复利/无上限/对赌对象
- **T11 最惠国(MFN)**：关键词 最惠国/most favored nation/同等权利；识别范围无限制/无轮次失效
- **T12 拖售权**：关键词 拖售/drag-along/强制出售；识别低门槛/无最低价/无跟随出售

## Phase 3: 情境严重度评估
- 高：严重不对称/可能导致创始人重大损失
- 中：适度不对称/可通过谈判平衡
- 低：轻微不对称/风险可控
- **情境调节**：结合交易阶段（早期/成长期/Pre-IPO）、投资人地位（控股/少数）、创始人议价力、个人财务依赖、轮次结构，上调或下调一档（详见 methodology.md §二）

## Phase 4: 对抗性分析（含经济量化）
1. 分析每条陷阱对创始方的实际不利影响
2. 评估触发概率和损失程度
3. 对 T8/T9/T10/T12 计算量化影响（稀释比例/exit 实得差额/或有负债总额）
4. 标注联动 `cap-market-cap-table-verify` 的完整模拟建议

## Phase 5: 报告+修改建议
1. 组装双轴十二类陷阱清单（含情境严重度）
2. 对抗性分析（含经济量化影响）
3. 修改建议：先标市场惯例基准 → 定谈判优先级（必争/可谈/接受）→ 给替代方案（门槛/双向化/carve-out/封顶）
4. 待核查项

## 自检清单

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 双轴覆盖 | 遗漏 T1-T12 任一类型 | 逐类检查补充 |
| 严重度情境 | 机械给定未调节 | 补充交易情境调节 |
| 经济量化 | T8-T12 仅定性无量化 | 补量化影响摘要+联动建议 |
| 市场基准 | 修改建议无市场惯例判断 | 补必争/可谈/接受分级 |
| 修改建议 | 不可操作/仅删除 | 补具体替代方案 |
