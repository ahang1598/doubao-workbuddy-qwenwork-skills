# 风险规则框架

## RC-01: 旧除名制度套用

| 属性 | 值 |
|------|-----|
| rule_id | RC-01 |
| trigger_condition | 以旧《公司法解释三》第17条"除名"制度套用新"失权"制度 |
| severity | 阻断 |
| effect_on_output | 须更正为《中华人民共和国公司法》（2023年修订）第52条：决议主体为董事会（非股东会）；适用范围为任何未按期缴纳（非仅全部未出资） |

## RC-02: 知情权范围引用旧法

| 属性 | 值 |
|------|-----|
| rule_id | RC-02 |
| trigger_condition | 知情权查阅范围仅提会计账簿不提会计凭证 |
| severity | 阻断 |
| effect_on_output | 须更新为《中华人民共和国公司法》（2023年修订）第57条：会计凭证明确可查+可穿透全资子公司 |

## RC-03: 催缴程序跳过

| 属性 | 值 |
|------|-----|
| rule_id | RC-03 |
| trigger_condition | 未发出书面催缴书直接启动失权 |
| severity | 阻断 |
| effect_on_output | 须先补催缴书+等待≥60日宽限期 |

## RC-04: 失权决议主体错误

| 属性 | 值 |
|------|-----|
| rule_id | RC-04 |
| trigger_condition | 以股东会决议替代董事会决议 |
| severity | 阻断 |
| effect_on_output | 须更正为第52条：须董事会决议（全体董事过半数通过） |

## RC-05: 送达证据缺失

| 属性 | 值 |
|------|-----|
| rule_id | RC-05 |
| trigger_condition | 失权通知未留存送达证据 |
| severity | 阻断 |
| effect_on_output | 须建议公证送达或EMS回执+见证人签字（三重保障） |

## RC-06: 新法实践未标注

| 属性 | 值 |
|------|-----|
| rule_id | RC-06 |
| trigger_condition | 失权制度结论未标注"新法实践有限" |
| severity | 警告 |
| effect_on_output | 须补充保守标注 |

## RC-07: 董事会僵局未预案

| 属性 | 值 |
|------|-----|
| rule_id | RC-07 |
| trigger_condition | 失权处置方案未包含董事会无法通过决议时的替代方案 |
| severity | 警告 |
| effect_on_output | 须补充替代策略：股东会路径（须章程授权）/股东代表诉讼/司法解散之诉（第231条） |

## RC-08: 定向减资未经全体同意

| 属性 | 值 |
|------|-----|
| rule_id | RC-08 |
| trigger_condition | 失权股权减资注销方案采用定向减资（不等比减资）但未取得有限责任公司全体股东另有约定或章程另有规定 |
| severity | 阻断 |
| effect_on_output | 须按第224条第3款更正：定向减资须经全体股东另有约定或章程另有规定；或改采等比例减资方案 |

## RC-09: 新旧法衔接适用错误

| 属性 | 值 |
|------|-----|
| rule_id | RC-09 |
| trigger_condition | 2024.7.1前发生的出资违约直接适用新法失权制度，未标注过渡风险 |
| severity | 警告 |
| effect_on_output | 须补充新旧法衔接分析：原则上适用旧法除名制度（法不溯及既往），若诉讼程序在新法施行后可主张适用新法但须标注过渡风险 |

## RC-10: 诉讼时效未审查

| 属性 | 值 |
|------|-----|
| rule_id | RC-10 |
| trigger_condition | 知情权诉讼或失权救济未审查诉讼时效/除斥期间 |
| severity | 阻断 |
| effect_on_output | 须补充时效审查：知情权诉讼适用民法典第188条三年普通时效；失权救济适用第52条第4款30日除斥期间 |

## RC-11: 知情权书面请求证据不足

| 属性 | 值 |
|------|-----|
| rule_id | RC-11 |
| trigger_condition | 知情权行使方案未要求留存书面请求送达证据 |
| severity | 警告 |
| effect_on_output | 须建议通过EMS快递+保留回执，或当面提交并要求签收，以证明已履行前置程序 |
