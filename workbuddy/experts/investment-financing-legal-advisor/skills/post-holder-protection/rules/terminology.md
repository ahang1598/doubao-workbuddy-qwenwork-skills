# 术语规范

| 术语 | 规范表述 | 说明 |
|------|----------|------|
| 知情权 | 股东知情权 | 查阅公司文件的权利 |
| 失权 | 股东失权 | 未按期缴纳出资的股东丧失股权 |
| 除名 | 股东除名（旧制度） | 已被新法失权制度取代 |
| 催缴书 | 书面催缴书 | 董事会发出的催缴出资通知 |
| 宽限期 | 宽限期 | 催缴书发出之日起不少于60日 |
| 失权通知 | 失权通知 | 董事会发出的失权书面通知 |
| 发出主义 | 发出主义 | 失权通知发出之日生效（非到达主义） |
| 除斥期间 | 除斥期间 | 30日内起诉，逾期失权 |
| 兜底缴纳 | 兜底缴纳 | 6个月内未处置→其他股东按比例缴纳 |
| 会计凭证 | 会计凭证（含原始凭证） | 《中华人民共和国公司法》（2023年修订）第57条明确可查 |
| 穿透查阅 | 穿透全资子公司查阅 | 《中华人民共和国公司法》（2023年修订）第57条扩展权利 |
| 不正当目的 | 不正当目的 | 四种法定情形（同业竞争等） |
