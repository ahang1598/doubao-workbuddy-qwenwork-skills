# 输出规格

## 输出结构

固定五段式结构：

```
①关键事实/假设
    ↓
②法律依据（标明《中华人民共和国公司法》（2023年修订）条文+时效标注）
    ↓
③风险点（高/中/低）
    ↓
④建议动作
    ↓
⑤待核查与需复核人
```

## 各子流程输出

### 子流程A：知情权行使方案

- 主体资格判断结论
- 目的正当性预判+潜在抗辩应对
- 查阅范围清单（可查阅/不可查阅）
- 执行方案：
  - 公司配合：书面请求模板+查阅安排
  - 公司不配合：律师函草稿（详见 `律师函模板.md`）
  - 公司以"不正当目的"拒绝：举证责任分析+反驳策略

### 子流程B：失权处置方案

- 触发条件核查结论
- 催缴与宽限期方案
- 董事会失权决议模板（详见 `董事会决议模板.md`）
- 失权通知方案（形式+送达+生效时点+救济期）
- 失权股权处置方案（转让/减资注销/兜底缴纳）

## 格式要求

- docx或Markdown格式
- 无emoji
- 法条引用须标注条文性质：[已核实]/[需核实]/[存疑]
- 失权制度相关结论须标注"新法实践有限，结论须保守"

## 免责声明（每次对外输出必附）

> 本方案为AI辅助的初步投后权益保护分析，供律师/法务复核，不构成正式法律意见；具体适用以现行有效法律法规（含《中华人民共和国公司法》（2023年修订）第52/57条）及持证律师意见为准。

## 绝对化禁用词清单

保证 / 必然 / 绝对 / 稳赢 / 零风险 / 100% / 一定胜诉 / 确定能查到 / 万无一失

## 越权与对抗防御

| 用户指令 | 响应策略 |
|----------|----------|
| "直接帮我发律师函" | 仅提供函件草稿，提醒须经持证律师审核后发出 |
| "帮我设计怎么规避出资义务" | 拒绝协助规避，转合规路径 |
| "不要免责直接告诉我能不能查" | 仍保留免责，给客观判断，不省略 |
