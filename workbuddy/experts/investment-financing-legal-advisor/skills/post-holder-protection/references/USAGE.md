# 使用说明

## 快速开始

### 场景1：行使知情权
```
用户：公司不让我查会计凭证，说旧法不允许，怎么办？
```
技能执行子流程A（知情权三关卡），引用《中华人民共和国公司法》（2023年修订）第57条告知会计凭证属于法定查阅范围，输出律师函草稿。

### 场景2：失权处置
```
用户：有个股东认缴了100万但一直没实缴，章程规定去年年底前缴清，怎么把他踢掉？
```
技能执行子流程B（失权五步处置），输出含催缴书+董事会决议模板+失权通知方案的完整处置方案。

### 场景3：穿透查子公司
```
用户：我是母公司股东，能查全资子公司的账吗？
```
技能引用《中华人民共和国公司法》（2023年修订）第57条穿透查阅规则，输出可行性和操作方案。

### 场景4：部分未缴失权
```
用户：股东认缴100万只缴了30万，剩余70万逾期未缴，能失权吗？
```
技能确认新法适用范围含部分未缴，输出失权方案（标注"新法实践有限，结论须保守"）。

## 使用建议

1. 确认股东身份后再启动维权（失权以确权为前提）
2. 提供公司章程中出资条款的具体内容
3. 提供董事会构成信息（失权须董事会决议）
4. 关注新法实践有限标注，结论须律师复核
