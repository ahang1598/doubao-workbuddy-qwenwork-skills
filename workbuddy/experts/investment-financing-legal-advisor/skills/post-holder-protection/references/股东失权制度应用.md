# 股东失权制度应用（子流程B）

> 来源：《股权投融资：风险防范及争议解决》第7章第3节（原"股东除名制度"）
> 方法论ID：V11（股东除名四要件框架→失权更新版）
> [注意] **关键变化**：旧《公司法解释三》第17条"股东除名"制度已被《中华人民共和国公司法》（2023年修订）第52条"股东失权"制度取代（2024.7.1施行）

---

## 制度对比：除名→失权

| 对比维度 | 旧除名制度（公司法解释三第17条） | 新失权制度（《中华人民共和国公司法》（2023年修订）第52条） |
|---|---|---|
| **适用范围** | 仅有限责任公司 | 有限责任公司 + 股份有限公司（第107条） |
| **适用情形** | "未履行出资义务"或"抽逃**全部**出资" | "未按期缴纳出资"（包含**部分未缴**） |
| **决议主体** | **股东会** | **董事会** |
| **宽限期** | "合理期限"（未明确具体天数） | **不少于60日**（自催缴书发出之日起） |
| **生效时点** | 通知到达（实践中存争议） | **通知发出之日**（发出主义） |
| **法律后果** | 解除全部股东资格 | 丧失**未缴纳出资部分**的股权（比例失权） |
| **股权处置** | 减资或由其他股东/第三人缴纳 | ①依法转让 ②减资注销 ③6个月未处理→**其他股东按出资比例兜底** |
| **股东救济** | 可请求确认解除无效（无明确期限） | 接到通知后**30日内**起诉（除斥期间） |
| **催缴义务人** | 公司（主体模糊） | **董事会**（第51条明确董事未催缴的赔偿责任） |

---

## 制度重构后的四要件框架

旧书的"除名四要件"（公司类型+事由+程序+期限）在新制度下逻辑内核不变，但每个要件的内容需要更新：

### 要件一：适用范围

| 类别 | 旧制度 | 新制度 |
|---|---|---|
| 有限责任公司 | [适用] | [适用] |
| 股份有限公司 | [不适用] | [适用]（第107条） |

### 要件二：触发事由

- 旧制度：仅"未出资"或"抽逃**全部**出资"（"部分未缴"不适用，法院严格把握）
- 新制度：**任何未按期缴纳出资**（含部分未缴）——适用范围大幅拓宽
- [重要] **争议点**：抽逃出资是否适用失权制度？
  - 新法第53条单独规定抽逃出资的后果（返还+赔偿）
  - 新法第52条条文仅用"未按期缴纳出资"，未明确是否包含抽逃
  - **保守做法**：优先适用第53条（返还+赔偿+董监高连带责任）+同时启动失权作为并行手段

### 要件三：法定程序（五步走）

```
董事会核查出资 → 催缴书(宽限期≥60日) → 董事会失权决议 → 书面失权通知 → 股权处置(6个月内)
```

**步骤1**：董事会核查出资（新法第51条）
- 董事会是核查出资+催缴的**法定义务主体**
- 未尽责的董事对给公司造成的损失承担**赔偿责任**

**步骤2**：催缴书+宽限期
- 书面催缴书**可**载明缴纳出资的宽限期
- 宽限期**不少于60日**（自催缴书发出之日起算）
- [注意] 旧法说"合理期限"，法院自由裁量——新法明确60日底线

**步骤3**：董事会失权决议
- 决议主体：**董事会**（非股东会——这是最重要的变化）
- 决议标准：全体董事过半数通过（新法第73条）
- 关联董事回避：法律未明确要求，但建议关联董事回避以降低决议被挑战风险

**步骤4**：书面失权通知
- 通知形式：书面（建议公证送达或EMS快递存证）
- 生效时点：**通知发出之日**（发出主义——不经送达即生效）
- [重要] 注意：发出即生效→股东可能在不知情的情况下被失权。因此建议同时通过短信/微信/邮件多渠道通知

**步骤5**：失权股权处置（6个月内）
- 优先：依法转让（其他股东或第三人受让）
- 备选：减少注册资本并注销该股权
- [注意] 减资注意事项：《中华人民共和国公司法》（2023年修订）第224条第3款：定向减资（不等比减资）须经有限责任公司全体股东另有约定或股份公司章程另有规定，默认须等比减资
- **兜底机制**（新法首创）：6个月内未转让/注销→**其他股东按其出资比例足额缴纳**对应出资
  - 这意味着其他股东承担"横向兜底"的强制义务

### 要件四：股东救济

- 被失权股东自接到通知之日起**30日内**可向法院起诉
- 这是**除斥期间**（非诉讼时效）——超过30日则丧失诉权
- 诉由：可提起确认之诉（确认仍享有股权）或撤销之诉（撤销董事会决议）

## 操作决策树

```
是否存在出资违约？
├── 全部未缴 → [可] 可启动失权（新旧制度均可）
├── 部分未缴 → [可] 可启动失权（新制度新增适用，旧制度不适用）
├── 抽逃全部出资 → [注意] 优先适用第53条返还+赔偿，同时并行启动失权
└── 抽逃部分出资 → [注意] 同抽逃全部的处理（保守方案：并行）

第一步：董事会发出催缴书
├── 董事会是否已核查出资？（第51条）→ 若未核查，先完成核查
├── 催缴书须书面形式
└── 明确宽限期≥60日

等待宽限期届满

第二步：宽限期届满后，该股东是否仍未缴纳？
├── 已缴纳（含部分缴纳）→ 不能失权；仅针对仍未缴纳的部分启动
├── 完全未缴纳 → [可] 启动失权
└── 部分未缴纳 → [可] 仅丧失未缴纳部分对应的股权

第三步：董事会失权决议
├── 召开董事会会议（须过半数董事出席）
├── 决议须经全体董事过半数通过
├── 关联董事建议回避
└── 决议通过 → 进入第四步

第四步：发出失权通知
├── 书面形式（公证送达/EMS存证/同时多渠道通知）
├── 通知发出即生效（发出主义）
└── 告知30日内的诉权

第五步：6个月内处置失权股权
├── 优先方案：依法转让
│   ├── 其他股东受让→优先购买权适用
│   └── 第三人受让→通知其他股东+过半数同意
├── 备选方案：减资注销
│   └── [注意] 须全体股东另有约定或章程另有规定（第224条第3款）——实操难点
└── 兜底方案：6个月届满未完成 → 其他股东按出资比例足额缴纳
    └── 注意：此兜底方案对诚信股东是额外的财务负担

被失权股东在30日内起诉？
├── 准备应诉
│   ├── 论证董事会决议程序合法
│   ├── 论证出资违约事实清楚
│   └── 论证宽限期已满且催缴已送达
└── 若30日内未起诉→失权不可逆转（除斥期间届满）
```

## 新旧制度衔接注意事项

1. **2024年7月1日前**发生的出资违约：原则上适用旧《公司法解释三》第17条（除名）
2. **2024年7月1日后**发生的出资违约：适用《中华人民共和国公司法》（2023年修订）第52条（失权）
3. **跨新旧法的持续违约**（如2023年未出资+持续到2024年下半年）：建议适用新法
4. **旧章程约定"除名"条款但未更新**：建议立即修订章程，将"除名"改为"失权"，并明确董事会为决议主体

## 法律依据速查

| 法条 | 时效 | 核心内容 |
|---|---|---|
| 《中华人民共和国公司法》（2023年修订）第52条 | [现行有效] | 股东失权制度（催缴→董事会决议→失权通知→6个月处置） |
| 《中华人民共和国公司法》（2023年修订）第51条 | [现行有效] | 董事会出资核查+催缴义务（未尽责董事的赔偿责任） |
| 《中华人民共和国公司法》（2023年修订）第53条 | [现行有效] | 抽逃出资的返还+赔偿+董监高连带责任 |
| 《中华人民共和国公司法》（2023年修订）第73条 | [现行有效] | 董事会决议规则（过半数出席+全体过半数通过） |
| 《中华人民共和国公司法》（2023年修订）第107条 | [现行有效] | 股份有限公司适用失权制度 |
| 《中华人民共和国公司法》（2023年修订）第224条第3款 | [现行有效] | 定向减资（不等比减资）须经有限责任公司全体股东另有约定或股份公司章程另有规定，默认须等比减资 |
| 旧《公司法解释三》第17条 | [已失效] | 已被新法第52条替代（仅对2024.7.1前行为有过渡价值） |
