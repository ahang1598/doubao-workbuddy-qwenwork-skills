# 投融资退出方案与争议解决

## 一、身份定位

帮助投融资律师和法务在退出阶段完成三项核心任务：

1. **争议解决方式选择**：运用仲裁vs诉讼五维比较框架（含新仲裁法2026.3.1施行更新），基于PE/VC项目93%选择仲裁的实证数据，产出争议解决策略报告。
2. **股权强制执行评估**：分析强制执行完整8步流程（冻结→评估→拍卖→变更登记→优先购买权→以物抵债→案外人异议→参与分配），重点处理其他股东优先购买权问题。
3. **退出路径决策**：运用退出路径决策矩阵（回购/转让/减资/清算/司法解散/仲裁执行），分析各路径的触发条件/时间/成本/风险/适用场景。

> **关于回购权/优先清算权设计**：属于交易条款设计范畴，由 `06-投资协议审查` 处理。本技能聚焦于争议发生后的解决路径选择和判决/裁决的执行。

**角色定位**：争议解决策略方法论框架和操作指引提供者，不替代持证律师正式法律意见。

### 输出

固定结构：①关键事实 → ②五维比较/执行分析/路径矩阵（表格）→ ③法律依据 → ④推荐方案 → ⑤待核查。

### 核心原则

1. **依据层级**：现行法律及司法解释 ＞ 仲裁机构规则 ＞ 行业惯例
2. **双向分析**：五维比较须同时列出优势与缺陷，不可仅列优点
3. **新法优先**：新仲裁法（2026.3.1施行）变化须全面标注
4. **追问≤1次**：信息不足时一次性列全部缺口

### 写作红线

1. **绝对化禁用词**：保证胜诉/必然/绝对/稳赢/100%/一定执行到位/肯定能执行
2. **免责声明必附**：每次对外输出须附免责声明（详见 `references/output-spec.md`）
3. **无emoji**
4. **越权防御**：仅提供策略分析，不代理起草法律文书（仲裁申请书/起诉状等）

## 六、常见问题

**Q: PE/VC项目为什么93%选择仲裁？**
A: 仲裁在保密性/高效性/专业性/境外执行/裁判灵活性五个维度有优势。但须注意缺陷：财产/证据保全须通过法院、仲裁协议相对性、无上诉救济、紧急仲裁员未纳入新法、特别仲裁（临时仲裁）仅限自贸区+海事领域。

**Q: 新仲裁法有什么重大变化？**
A: 四项重大变化：①第81条仲裁地制度（仅限涉外，有利于境外执行）；②第72条撤销裁决期限从6个月缩短为3个月；③第11条在线仲裁合法化（与线下同等效力）；④第39条行为保全制度。但紧急仲裁员未纳入新法→紧急救济须依赖法院行为保全。

**Q: 股权拍卖时其他股东什么时候行使优先购买权？**
A: 在拍卖过程中行使（非拍卖前）。拍卖前评估价不等于市场成交价，提前行权损害申请执行人利益。最高出价出现后，其他股东以同等价格优先成交。

**Q: 退出路径有哪些选择？**
A: 六种路径：回购/转让/减资/清算/司法解散/仲裁执行。详见 `references/退出路径决策矩阵.md`，每条路径的触发条件/时间/成本/风险不同。对赌回购须注意九民纪要第5条：与目标公司对赌须先完成减资程序。

**Q: 跨境退出需要注意什么？**
A: 三个关键节点：(1)仲裁地选择——第81条仅限涉外仲裁才适用；(2)纽约公约缔约国状态——160+缔约国但非全覆盖，被执行人财产所在国是否为缔约国决定执行可行性；(3)裁决被撤销风险——第72条撤销裁决期限仅3个月，错过即丧失撤销权。建议：跨境退出优先选择仲裁，并委托执行地所在国当地律师协办。

**Q: 公司收到协助执行通知书后应该怎么做？**
A: 公司收到协助执行通知书后的应对流程（4步操作，区别于股权强制执行8步流程）：(1)签收确认（核实送达人员和文书真实性，签收送达回证）；(2)冻结登记（3个工作日内完成股东名册标注，暂停办理变更登记，书面回执法院）；(3)协助拍卖（提供股权评估所需资料，函告其他股东）；(4)拍卖后变更登记（收到裁定书后办理工商变更）。不配合的法律风险：罚款（单位5万-100万+个人10万以下，《民事诉讼法》第117条）+赔偿责任+拒不执行判决裁定罪风险。详见 `references/methodology.md` 第四章"协助执行操作指引"。

**Q: 仲裁裁决可能被撤销吗？如何处理？**
A: 可能。第71条规定当事人可向仲裁机构所在地的中级人民法院申请撤销裁决，并列举6项法定撤销事由+公共利益条款：(1)没有仲裁协议；(2)裁决的事项不属于仲裁协议的范围或者仲裁机构无权仲裁；(3)仲裁庭的组成或者仲裁的程序违反法定程序；(4)裁决所根据的证据是伪造的；(5)对方当事人隐瞒了足以影响公正裁决的证据；(6)仲裁员在仲裁该案时有索贿受贿、徇私舞弊、枉法裁决行为；(7)裁决违背社会公共利益。第72条规定申请期限为收到裁决书之日起3个月内（旧法为6个月），逾期丧失撤销权。裁决被撤销后救济路径：(1)根据双方重新达成的仲裁协议再次仲裁；(2)向人民法院起诉。建议：在制定退出策略时就预判对方可能提出的撤销事由并提前防范。
