# 协助执行通知书操作指引

## 使用场景

目标公司收到法院送达的《协助执行通知书》（冻结/拍卖被执行人持有的公司股权）时，公司的应对方针和操作步骤。

## 一、核查步骤

### 步骤1：核实执行依据（收到后立即）

1. 核对法院送达人员身份（工作证/执行公务证）
2. 核对协助执行通知书内容：执行案号/被执行股东姓名或名称/冻结股权比例和数额/执行法院名称和联系方式
3. 核对民事裁定书与协助执行通知书的一致性
4. 签收送达回证并注明签收日期

**禁止行为**：以"法人不在/需要请示/没有公章"等理由拒绝签收

### 步骤2：冻结登记（收到后3个工作日内）

1. 在股东名册中标注：冻结起始日期/执行案号/冻结股权数额/执行法院
2. 在工商登记系统中暂缓办理该股权的转让/质押/增资/减资等变更登记申请
3. 向法院出具书面回执：

```
协助执行回执

XX人民法院：

贵院（XXXX）X法执字第XX号协助执行通知书已收悉。

我司已于XXXX年XX月XX日在股东名册中对被执行人XX持有的我司XX%股权（出资额XX万元）予以冻结登记。

在冻结期间，我司将暂停办理该股权的转让、质押等变更登记。

特此回执。

XX有限公司（盖章）
XXXX年XX月XX日

联系人：XXX
联系电话：XXX
```

### 步骤3：协助拍卖（收到拍卖通知后）

1. **提供评估所需资料**：
   - 公司章程及修正案
   - 历次工商变更登记材料
   - 股东名册
   - 最近一期财务报表（资产负责表/利润表/现金流量表）
   - 关联交易清单（近3年）
   - 重大合同清单（标的额超过净资产10%的合同）

2. **函告其他股东**：

```
关于法院拍卖XX股权暨优先购买权行使的通知

致：XX有限公司全体股东

根据XX人民法院（XXXX）X法执字第XX号执行裁定书，法院拟对被执行人XX持有的我司XX%股权进行司法拍卖。拍卖信息如下：

- 拍卖平台：XX（如淘宝司法拍卖/京东司法拍卖）
- 拍卖时间：XXXX年XX月XX日XX时起至XXXX年XX月XX日XX时止
- 评估价：人民币XX万元
- 起拍价：人民币XX万元
- 保证金：人民币XX万元

根据相关法律规定，你方作为公司其他股东，在拍卖过程中对上述股权享有优先购买权。如有意行使优先购买权，请关注拍卖平台公告，在拍卖过程中以最高出价的同等条件行使。

XX有限公司（盖章）
XXXX年XX月XX日
```

### 步骤4：拍卖后变更登记

收到法院裁定书（股权归买受人所有）后：

1. 注销原股东（被执行人）在股东名册中的股权登记
2. 为买受人办理股东登记
3. 办理工商变更登记（买受人→新股东）
4. 向法院出具变更登记完成回执

## 二、常见问题

### Q1：被执行股东主张股权已转让给第三方，要求公司不予协助

**A**：以工商登记和股东名册为准。如工商登记仍为被执行股东，公司须按法院通知执行。同时应书面告知被执行股东向执行法院提出案外人异议，由法院裁定是否停止执行。

### Q2：被执行人持有的股权存在代持/质押等权利负担

**A**：如实向法院报告权利负担情况，但不停止协助执行。质权人/实际出资人须自行向执行法院主张权利（案外人异议/参与分配）。

### Q3：公司能否以"正在准备增资/股改"为由拖延办理

**A**：不能。协助执行通知书具有强制执行力，拖延或拒绝协助执行将面临以下法律后果：

| 后果类型 | 具体内容 | 法律依据 |
|----------|----------|----------|
| 罚款 | 对单位：5万-100万元；对直接责任人：10万元以下 | 《民事诉讼法》第117条 |
| 拘留 | 对直接责任人：15日以下拘留 | 《民事诉讼法》第117条 |
| 赔偿 | 因拒不协助造成损失→承担赔偿责任 | 《民事诉讼法》第117条 |
| 刑事责任 | 情节严重→拒不执行判决、裁定罪（3年以下有期徒刑/拘役/罚金；情节特别严重3-7年） | 《刑法》第313条 |

## 三、时限要求

| 动作 | 时限 | 逾期后果 |
|------|------|----------|
| 签收送达回证 | 送达当日 | 不影响送达效力 |
| 股权冻结登记 | 收到后3个工作日 | 罚款+赔偿风险 |
| 向法院回执 | 冻结登记完成后立即 | 法院催告/罚款风险 |
| 提供评估资料 | 按法院通知时限 | 影响拍卖进程/罚款风险 |
| 拍卖后变更登记 | 收到裁定书后15个工作日内 | 罚款+赔偿风险 |

## 四、存档要求

收到协助执行通知书后，建议建立专项档案，保存以下材料：

1. 协助执行通知书原件/复印件
2. 民事裁定书复印件
3. 送达回证复印件
4. 股东名册冻结标注页复印件
5. 给法院的回执复印件
6. 给其他股东的优先购买权通知复印件
7. 拍卖后工商变更登记材料
8. 与法院的全部往来函件

存档期限：执行终结后至少保存5年。
