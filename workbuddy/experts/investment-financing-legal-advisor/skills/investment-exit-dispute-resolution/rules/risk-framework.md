# 风险规则框架

## RC-01: 五维比较单向

| 属性 | 值 |
|------|-----|
| rule_id | RC-01 |
| trigger_condition | 仅列仲裁优点不列缺陷 |
| severity | 阻断 |
| effect_on_output | 须补充反向维度+新仲裁法最新变化（仲裁缺陷5项：保全须通过法院/协议相对性/无上诉救济/紧急仲裁员缺失/特别仲裁限制） |

## RC-02: 紧急仲裁员错误建议

| 属性 | 值 |
|------|-----|
| rule_id | RC-02 |
| trigger_condition | 建议使用紧急仲裁员 |
| severity | 阻断 |
| effect_on_output | 新仲裁法未纳入，改建议法院行为保全（第39条） |

## RC-03: 优先购买权时点错误

| 属性 | 值 |
|------|-----|
| rule_id | RC-03 |
| trigger_condition | 建议拍卖前行使优先购买权 |
| severity | 阻断 |
| effect_on_output | 更正为拍卖过程中行使+说明理由（拍卖前评估价不等于市场成交价） |

## RC-04: 退出路径单一

| 属性 | 值 |
|------|-----|
| rule_id | RC-04 |
| trigger_condition | 仅列一种退出路径 |
| severity | 阻断 |
| effect_on_output | 须补充六种路径决策矩阵（回购/转让/减资/清算/司法解散/仲裁执行） |

## RC-05: 新仲裁法遗漏

| 属性 | 值 |
|------|-----|
| rule_id | RC-05 |
| trigger_condition | 未提及新仲裁法2026.3.1施行变化 |
| severity | 阻断 |
| effect_on_output | 须补充四项重大变化（第81条仲裁地/第72条撤销期限3个月/第11条在线仲裁/第39条行为保全） |

## RC-06: 跨境执行遗漏

| 属性 | 值 |
|------|-----|
| rule_id | RC-06 |
| trigger_condition | 对跨境争议未评估境外执行可行性 |
| severity | 阻断 |
| effect_on_output | 补充纽约公约第V条5种拒绝承认情形分析+执行地缔约国状态核查+执行地法域对外国裁决/判决的承认政策 |

## RC-07: 仲裁裁决被撤销

| 属性 | 值 |
|------|-----|
| rule_id | RC-07 |
| trigger_condition | 仅给出"仲裁裁决终局有执行力"结论，未提示撤销风险 |
| severity | 阻断 |
| effect_on_output | 补充第71条法定撤销事由（无仲裁协议/超裁/程序违法/证据伪造/仲裁员徇私舞弊/违背公共利益）+第72条3个月申请期限+裁决被撤销后的救济路径（重新仲裁或诉讼） |

## RC-08: 法条时效错误

| 属性 | 值 |
|------|-----|
| rule_id | RC-08 |
| trigger_condition | 引用旧仲裁法条文（1994版/2009修正版）或未标注新仲裁法施行日期2026.3.1 |
| severity | 阻断 |
| effect_on_output | 替换为新仲裁法对应条文编号+标注[已核实]+注明2026.3.1施行 |

## RC-09: 仲裁规则版本错误

| 属性 | 值 |
|------|-----|
| rule_id | RC-09 |
| trigger_condition | 引用仲裁机构过时规则版本（如CIETAC 2015规则而非2024规则） |
| severity | 警告 |
| effect_on_output | 标注"须核实仲裁机构最新规则版本"+提示用户自行查询仲裁机构官网确认 |

## RC-10: 执行地实践缺失

| 属性 | 值 |
|------|-----|
| rule_id | RC-10 |
| trigger_condition | 对具体管辖地的执行实践未给出属地指引（如执行周期/拍卖平台/法院效率等） |
| severity | 警告 |
| effect_on_output | 补充执行地实践提示+标注"具体执行周期须以管辖法院实际情况为准"+建议当事人委托当地律师评估 |

## RC-11: 对赌退出路径错误

| 属性 | 值 |
|------|-----|
| rule_id | RC-11 |
| trigger_condition | 直接建议要求目标公司回购而未先评估减资程序可行性 |
| severity | 阻断 |
| effect_on_output | 补充九民纪要第5条分析：与目标公司对赌→须完成减资程序后方可履行回购义务→评估减资可行性（须经全体股东另有约定或章程另有规定+债权人异议程序） |
