# 术语规范

| 术语 | 规范表述 | 说明 |
|------|----------|------|
| 仲裁地 | 仲裁地 | 新仲裁法第81条；仅限涉外 |
| 撤销裁决 | 撤销仲裁裁决 | 新法期限3个月（旧法6个月） |
| 在线仲裁 | 在线仲裁 | 新仲裁法合法化 |
| 行为保全 | 行为保全 | 新仲裁法新增 |
| 紧急仲裁员 | 紧急仲裁员 | 新仲裁法未纳入 |
| 特别仲裁 | 特别仲裁（临时仲裁） | 仅限自贸区+海事领域 |
| 纽约公约 | 纽约公约 | 160+缔约国，跨境仲裁裁决执行 |
| 优先购买权 | 优先购买权 | 拍卖过程中行使（非拍卖前） |
| 以物抵债 | 以物抵债 | 拍卖流拍后裁定 |
| 案外人异议 | 案外人异议 | 对执行标的提出异议 |
| 参与分配 | 参与分配 | 多个债权人分配执行款 |
| 定向减资 | 定向减资 | 新公司法第224条第3款：不等比减资须经全体股东另有约定或章程另有规定，默认等比减资 |
| 司法解散 | 司法解散 | 新公司法第231条公司僵局 |
