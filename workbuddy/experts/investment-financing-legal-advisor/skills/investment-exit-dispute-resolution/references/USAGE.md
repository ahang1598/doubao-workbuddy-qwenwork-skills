# 使用说明

## 快速开始

### 场景1：争议解决方式选择
```
用户：投资协议到期，创始人未履行回购义务，仲裁还是诉讼？
```
技能执行五维比较，输出争议解决策略报告（含新仲裁法变化）。

### 场景2：股权强制执行
```
用户：仲裁裁决下来了，创始人不履行，能强制执行他的股权吗？
```
技能执行8步股权强制执行流程评估，输出执行可行性分析。

### 场景3：退出路径选择
```
用户：投资失败了，公司经营困难，怎么退出最划算？
```
技能执行退出路径决策矩阵分析，对比六种路径推荐最优方案。

### 场景4：新仲裁法影响
```
用户：新仲裁法对PE/VC争议解决有什么影响？
```
技能输出新仲裁法四项重大变化分析+对PE/VC项目的影响评估。

## 使用建议

1. 提供争议性质和管辖地信息
2. 标注是否跨境争议（影响境外执行分析）
3. 提供现有仲裁条款（如有）
4. 关注新仲裁法2026.3.1施行变化
