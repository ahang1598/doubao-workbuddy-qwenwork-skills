## 仲裁vs诉讼五维比较（V12）

### 实证基础
书中引用汉坤2016/2017年PE/VC项目数据：**93%+的项目选择仲裁**。

### 五维比较表

| 维度 | 仲裁 | 诉讼 | 权重建议 |
|---|---|---|---|
| **保密性** | 仲裁不公开进行（《仲裁法》第52条），裁决不上网 | 公开审理为原则，判决文书上网 | 高（PE/VC项目核心考量） |
| **高效性** | 一裁终局，组庭后4-6个月裁决。撤销裁决期限**3个月**（新法缩短） | 一审6个月+二审3个月+再审可能数年 | 高 |
| **专业性** | 可从行业专家中选任仲裁员；对PE/VC前沿问题理解更深 | 法官多为法律通才，对行业惯例了解有限 | 中 |
| **境外执行** | 纽约公约160+缔约国，执行便利 | 依赖双边司法条约或互惠关系，执行难度大 | 高（跨境项目关键） |
| **裁判灵活性** | 不受指导案例约束，独立判断前沿问题（如对赌条款效力） | 须遵循上级法院裁判指引和指导性案例 | 中 |

### 新仲裁法（2026.3.1施行）关键变化

| 变化 | 影响 |
|---|---|
| 撤销裁决期限：6个月→**3个月** | 强化仲裁效率优势，但被错误裁决的当事人救济窗口更窄 |
| 在线仲裁合法化（第11条） | 便利性提升，但**可能模糊保密性边界** |
| 行为保全及仲裁前保全（第39条，含仲裁前向法院申请保全） | 部分弥补了旧法保全须通过法院的不足 |
| 仲裁地制度确立（第81条，仅涉外） | 跨境仲裁确定性增强 |
| 特别仲裁（临时仲裁）引入（第82条） | 仅限自贸区+海事——适用范围有限 |
| 紧急仲裁员未纳入 | 紧急救济须依赖法院行为保全 |
| 境外仲裁机构可在自贸区设业务机构 | 涉外仲裁选择更多 |

## 反向维度：仲裁的三个缺陷

1. **财产/证据保全须通过法院**：仲裁庭无权直接保全→通过法院转递→延迟风险。新法新增行为保全+仲裁前保全有所缓解。
2. **仲裁协议相对性**：效力扩张至保证人/关联方困难——主合同仲裁条款不当然约束担保人
3. **合并仲裁困难**：关联交易中多名当事人分别约定仲裁→无统一程序合并

## 选择决策树

```
是否涉及跨境执行？
├── 是 → 仲裁（纽约公约优势明显）
└── 否 → 继续

是否需要保密（商誉/商业秘密）？
├── 是 → 仲裁
└── 否 → 继续

是否有紧急保全需求？
├── 是 → 确认仲裁规则含紧急保全条款+新法法院行为保全并行
└── 否 → 继续

争议标的是否涉及前沿法律问题（如对赌效力）？
├── 是 → 仲裁（更灵活，不受指导案例约束）
└── 否 → 诉讼也可

是否在意上诉救济？
├── 是 → 诉讼（仲裁一裁终局，纠错窗口窄）
└── 否 → 仲裁
```
