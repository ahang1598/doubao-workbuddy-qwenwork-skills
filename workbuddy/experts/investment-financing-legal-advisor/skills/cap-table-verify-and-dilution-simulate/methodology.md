# 核心方法论

## 一、历轮股权变动重建

### 重建流程

```
公司设立（初始注册资本/创始股东持股）
  ↓
A轮增资（投资额/估值/新发股数→各股东稀释）
  ↓
B轮增资（投资额/估值/新发股数→各股东稀释）
  ↓
期权池设立（预留比例→各股东稀释）
  ↓
股权转让（创始人间转让/老股转让→持股比例变动）
  ↓
当前Cap Table
```

### 计算公式

- 增资后新持股比例 = 原持股数 / (总股数 + 新发股数)
- 转让后持股比例 = (原持股数 + 受让股数 - 转让股数) / 总股数
- 注册资本变动 = 原注册资本 + 本轮新增注册资本

### 逐轮重建检查点

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 轮次时间顺序 | 协议日期乱序 | 按签署日期重新排列 |
| 股数守恒 | 前后轮总股数不一致 | 追查差额来源（新发/注销/转股） |
| 比例合计 | 各轮比例合计≠100% | 重新计算或追查遗漏股东 |

## 二、工商登记交叉验证

| 差异类型 | 可能原因 | 处理方式 |
|----------|----------|----------|
| 持股比例不一致 | 登记延迟/代持/期权池未登记 | 标注差异+建议核实 |
| 注册资本不一致 | 增资未登记/减资未完成 | 标注差异+建议补登记 |
| 股东名单不一致 | 转让未登记/代持/股权激励平台 | 标注差异+建议核实 |
| 实缴比例不一致 | 实缴时间差/部分实缴 | 标注差异+建议核实出资证明书 |

## 三、稀释模拟

### 输入参数

- 投前估值：X万元
- 投资额：Y万元
- 新发比例：Y / (X + Y)

### 计算公式

- 稀释后持股比例 = 原持股比例 × (1 - 新发比例)
- 新股东持股比例 = 新发比例
- 投后估值 = 投前估值 + 投资额

### 期权池刷新（Top-up）处理

当新一轮融资前需同步扩大期权池时，期权池扩大部分先于新发股份计算稀释：

1. 期权池扩大比例（如从10%扩大到15%）
2. 各股东按扩大后比例先稀释一次
3. 再按新发比例稀释
4. 总稀释 = (1 - 期权池扩大后剩余比例) × (1 - 新发比例)

## 四、反稀释调整

### 加权平均法

调整价 = (已发股数 × 原价 + 新发股数 × 新价) / (已发股数 + 新发股数)

调整后持股数 = 原投资额 / 调整价

### 完全棘轮法

调整价 = 新发价格

调整后持股数 = 原投资额 / 新发价格

### 对比

| 方式 | 调整价 | 对投资人 | 对创始人 |
|------|--------|----------|----------|
| 加权平均 | 介于原价和新价之间 | 中等保护 | 中等稀释 |
| 完全棘轮 | 等于新发价格 | 最大保护 | 最大稀释 |

### 调整后额外股数计算

额外股数 = 调整后持股数 - 原持股数

该额外股数从创始人（或约定的反稀释补偿方）持股中调整给投资人，不改变总股数。

## 五、可转债转换计算

### 转换场景

可转债在转股时按约定的转换价或转换折扣转换为普通股，影响Cap Table。

### 计算公式

- 转换股数 = 债券本息总额 / 转换价
- 转换后持股比例 = 转换股数 / (原总股数 + 转换股数)
- 转换价 = 约定方式（如本轮估值每股价格 × (1 - 转换折扣)）

### 检查点

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 转换价来源 | 协议未明确转换价定义 | 追问协议条款 |
| 本息计算 | 未含利息 | 按协议利率计算到期本息 |
| 转换顺序 | 多笔可转债转换顺序混乱 | 按到期日先后排列 |

## 六、代持还原计算

### 场景说明

显名股东（名义股东）代隐名股东持有股权时，核验时须还原实际持股结构。

### 还原流程

1. 识别代持关系：通过代持协议/实际出资记录/股东会决议等确认
2. 将名义股东持股拆分：名义部分 + 代持部分
3. 代持部分归入隐名股东
4. 重建还原后Cap Table

### 检查点

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 代持协议有效性 | 未提供书面代持协议 | 标注"代持关系待核实"+不在报告中确认还原 |
| 代持比例明确 | 协议未明确代持比例 | 追问代持范围 |
| 多层代持 | 存在名义股东再代他人 | 逐层穿透至最终受益人 |

## 七、有限合伙持股平台穿透

### 场景说明

员工持股平台通常为有限合伙企业，GP为创始人/关联方，LP为被激励员工。核验时须判断是否需要穿透至最终自然人。

### 穿透判断规则

| 情形 | 是否穿透 | 依据 |
|------|----------|------|
| GP为创始人且GP持股比例小（<1%） | 穿透LP部分 | GP仅为执行事务合伙人 |
| GP持股比例较大（>20%） | 部分穿透 | GP自身有实质性持股 |
| 平台已有明确份额分配表 | 按分配表穿透 | 份额分配表反映实际经济利益 |
| 无份额分配表 | 仅标注平台整体持股 | 无法确认内部分配 |

### 计算公式

- 穿透后某LP持股比例 = 平台持股比例 × 该LP在平台中的份额比例
- 平台整体持股比例不变，仅拆分至最终持有人

## 八、股改（整体变更）处理

### 场景说明

有限责任公司整体变更为股份有限公司时，折股比例影响每股价格但通常不改变持股比例。

### 计算要点

1. 折股比例 = 折合的股份总数 / 变更前净资产
2. 各股东持股比例通常不变（按原比例折股）
3. 每股净资产 = 变更前净资产 / 折合股份总数
4. 须验证折股后注册资本与审计净资产一致

### 检查点

- 股改基准日审计报告是否提供
- 折股比例是否合理（通常不低于1:1）
- 股改前后各股东持股比例是否一致

## 九、清算优先权瀑布分析

> **法律精度提示**：清算优先权完全依 SPA 约定，并非法定顺序。本节"后轮优先于前轮"仅为 PE/VC 行业**常见约定**，须以各轮 SPA 明示的优先级条款为准；约定不明时不得径行假定后轮优先，应标注"优先级约定不明，建议核查 SPA"并提示律师确认。

### 9.1 三种优先权结构（核心区分）

| 结构 | 英文 | 分配逻辑 | 对创始人影响 |
|------|------|----------|--------------|
| 不参与权（Non-participating） | Non-participating | 优先股**二选一取高**：优先清算额 **或** 按普通股比例分配，二者取高者 | 对创始人最有利（投资人要么拿优先额退出，要么当普通股，不双重获利） |
| 参与权（Participating） | Participating | 优先股先收回优先清算额，**再**按持股比例参与剩余资产分配 | 对创始人最不利（投资人双重获利） |
| 封顶参与权（Capped Participating） | Capped Participating | 参与权基础上设总回报上限（如 3× 投资额），达上限后转纯普通股分配 | 介于二者之间 |

**Non-participating 取高逻辑（必须实现）**：
```
优先清算额 = 投资额 × 倍数（1× 即等于投资额，见 9.2）
普通股路径金额 = 清算资产 × 优先股持股比例
投资人实际所得 = max(优先清算额, 普通股路径金额)
```
注意：non-participating 投资人取高后**不再**参与剩余分配；若取"普通股路径"则与普通股东同权。

### 9.2 优先清算金额公式（修正）

- **优先清算金额 = 投资额 × 约定倍数**（如 1× 即等于投资额；2× 即投资额的两倍）
- ⚠️ 常见错误写法"投资额 × (1 + 倍数)"会把 1× 算成 2×，属事实错误，须避免。
- 倍数常见为 1×，偶有 1×~2×；无约定时按行业惯例默认 **1×** 并标注。

### 9.3 参与权与上限

- 参与权（participating）：投资人收回优先清算额后，按**其优先股对应持股比例**（非全公司比例误解）参与剩余分配。
- 参与权上限（cap）：优先股总回报（优先清算额 + 参与分配额）达到"投资额 × 上限倍数"（如 3×）后，停止参与，剩余资产全归普通股。上限是"总回报上限"而非"参与分配单独上限"。

### 9.4 多轮优先级叠加规则

- 优先级顺序**以 SPA 约定为准**；行业常见为后轮 > 前轮（后投先分）。
- 同轮内部按持股比例分摊；跨轮先满足高优先级轮次优先清算额，再依次向下。

### 9.5 计算示例（participating vs non-participating 对比）

```
清算资产 Z = 5000万元；A轮优先股投资额1000万(持股20%)，倍数1×
─────────────────────────────────────
Non-participating：
  优先清算额 = 1000万 × 1 = 1000万
  普通股路径 = 5000万 × 20% = 1000万
  取高 = max(1000, 1000) = 1000万  → 与普通股东同权时二者相等
Participating：
  优先清算额 = 1000万
  剩余 = 5000 - 1000 = 4000万
  参与分配 = 4000万 × 20% = 800万
  投资人总得 = 1000 + 800 = 1800万（多拿800万）
```
→ 该对比应作为交付物核心，向创始人直观展示"参与权"的稀释代价。

### 检查点

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 优先权结构 | 未区分 non/participating/capped | 按 SPA 标注结构类型 |
| 倍数公式 | 写成"投资额×(1+倍数)" | 修正为"投资额×倍数" |
| 取高逻辑 | non-participating 未取高 | 实现 max(优先清算额, 普通股路径) |
| 优先级顺序 | 各轮优先级未在协议中明确 | 标注"约定不明"并提示核查 SPA |
| 参与权上限 | 协议有参与权但未设上限 | 按无上限处理+标注风险 |
| 参与比例 | 误用全公司比例代替优先股对应比例 | 用优先股自身持股比例参与 |

## 十、对赌（VAM）触发后的股权调整

> 与 `cap-market-adversarial-clause-analysis`（T10 对赌条款识别）、`cap-market-founder-liability-review`（创始人回购责任）联动：本技能仅做 Cap Table 层面的量化，不评判对赌效力。

### 场景说明

对赌失败触发股权补偿或现金补偿，直接影响 Cap Table：
- **股权补偿型**：创始人/公司无偿或低价向投资人转让股权（补偿股数），各原股东被稀释。
- **回购型（现金）**：公司/创始人回购投资人股权，通常须**减资程序**（新公司法第224条第3款定向减资须经全体股东另有约定或章程另有规定，默认须等比减资；第162条回购后须减资或转让）。回购完成后投资人退出，剩余股东持股比例上升。
- **回购型（股份）**：公司回购自身股份形成库存股，不改变其他股东比例但影响总股本与每股价值。

### 计算要点

- 补偿股数 = 应补偿金额 / 补偿时每股价格（或按公式直接定股数）
- 回购减资后：剩余股东持股比例 = 原持股数 / (总股数 - 回购注销股数)
- 须标注减资程序的合规前置（须股东会决议+债权人保护程序），本技能不替代该法律判断

### 检查点

| 检查项 | 不达标信号 | 纠正动作 |
|--------|------------|----------|
| 补偿/回购类型 | 未区分股权补偿/现金回购/股份回购 | 按 SPA 对赌条款标注类型 |
| 减资程序 | 现金回购未提示减资合规 | 标注"须减资程序，由律师确认" |
| 比例重算 | 回购后各股东比例未重算 | 按剩余股数重算比例 |
