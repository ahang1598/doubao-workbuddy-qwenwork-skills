# 质量标准

| # | 检查项 | 类型 | 说明 |
|---|--------|------|------|
| Q1 | 历轮完整 | 阻断 | 所有轮次数据须提供，不可跳过中间轮次 |
| Q2 | 计算准确 | 阻断 | 持股比例合计=100%（每轮检查） |
| Q3 | 差异分析 | 阻断 | 工商差异须逐项分析原因 |
| Q4 | 免责声明 | 阻断 | 须附标准免责声明 |
| Q5 | 绝对化禁用词 | 阻断 | 不可使用保证/必然/绝对/零误差/100%准确/完全无误 |
| Q6 | 稀释计算 | 阻断 | 稀释后比例须准确，含Top-up时先计算池扩大 |
| Q7 | 反稀释标注 | 警告 | 须标注调整方式（加权平均/完全棘轮）和调整价 |
| Q8 | 来源文件标注 | 阻断 | 每个数据项须标注来源文件（协议/工商/推算/用户提供） |
| Q9 | 计算精度 | 警告 | 持股比例/持股数/金额保留四位小数，变动率保留两位小数 |
| Q10 | 期权池处理 | 阻断 | 期权池须单列，拆分授予/未授予，不混入普通股 |
| Q11 | 穿透验证 | 阻断 | 有限合伙持股平台须判断是否穿透并标注理由 |
| Q12 | 代持还原 | 阻断 | 存在代持时须基于书面协议还原或标注"待核实" |
| Q13 | 越权防御 | 阻断 | 不出具法律意见/不替代律师核验/不确认代持效力 |
| Q14 | 反稀释总股数 | 阻断 | 反稀释调整后总股数不变，仅调整持股 |
| Q15 | 清算瀑布顺序 | 警告 | 清算优先权按 SPA 约定优先级分配（如含优先清算权条款）；约定不明须标注并提示核查 |
| Q16 | 优先权结构区分 | 阻断 | 须区分 non-participating/participating/capped participating；non-participating 须实现取高 max(优先清算额, 普通股路径) |
| Q17 | 优先清算公式 | 阻断 | 优先清算金额 = 投资额 × 倍数（1× 即投资额），禁用"投资额×(1+倍数)" |
| Q18 | 对赌减资标注 | 警告 | 含对赌(VAM)触发时须标注补偿/回购类型 + 减资程序提示（如现金回购） |
