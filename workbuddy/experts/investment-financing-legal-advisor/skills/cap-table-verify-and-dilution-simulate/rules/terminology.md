# 术语规范

## 一、股权基础术语

| 术语 | 英文 | 说明 |
|------|------|------|
| Cap Table | Capitalization Table | 股权结构表/资本化表，反映公司各股东持股情况 |
| 稀释 | Dilution | 融资后持股比例下降 |
| 反稀释 | Anti-dilution | 低价融资时保护投资人的调整机制 |
| 加权平均 | Weighted Average | 考虑已发和新发股数加权的反稀释方式 |
| 完全棘轮 | Full Ratchet | 调整价直接等于新发价格的反稀释方式 |
| 投前估值 | Pre-money Valuation | 新融资轮次前的公司估值 |
| 投后估值 | Post-money Valuation | 投前估值 + 本轮投资额 |
| 认缴出资 | Subscribed Capital | 股东承诺缴纳的出资额 |
| 实缴出资 | Paid-in Capital | 股东实际缴纳的出资额 |
| 持股比例 | Ownership % | 持股数 / 总股数 |

## 二、优先股与投资条款术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 优先股 | Preferred Stock | 享有优先权的股份，如优先清算/优先分红 |
| 转换率 | Conversion Ratio | 优先股转普通股的比例 |
| 转换价 | Conversion Price | 优先股转换为普通股时的每股价格 |
| 优先清算权 | Liquidation Preference | 清算时优先股先于普通股收回投资额 |
| 参与权 | Participation Right | 优先股收回优先清算额后按比例参与剩余分配 |
| 参与权上限 | Participation Cap | 参与分配达到上限后转为纯普通股分配 |
| 清算瀑布 | Liquidation Waterfall | 清算资产按优先级顺序分配的流程 |
| 不参与权 | Non-participating | 优先股二选一取高：优先清算额 或 按普通股比例分配，取高者 |
| 参与权上限 | Participation Cap | 优先股总回报（优先清算额+参与分配）达到上限倍数（如3×）后停止参与 |
| 封顶参与权 | Capped Participating | 参与权基础上设总回报上限 |
| 取高逻辑 | Take-the-higher | non-participating 下 max(优先清算额, 普通股路径金额) 的计算规则 |
| 对赌 | VAM / Valuation Adjustment Mechanism | 估值调整机制，未达业绩/上市对赌时触发补偿或回购 |

## 三、期权与激励术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 期权池 | Option Pool / ESOP | 为股权激励预留的股份池 |
| 期权池刷新 | Top-up | 融资前扩大期权池比例 |
| 授予 | Grant | 期权池中已分配给员工的份额 |
| 未授予 | Ungranted | 期权池中尚未分配的份额 |
| 新发股数 | New Shares Issued | 新融资轮次发行的股份数 |

## 四、合伙与穿透术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 有限合伙 | Limited Partnership (LP) | 至少1名GP+1名LP组成的合伙企业 |
| 普通合伙人 | General Partner (GP) | 执行合伙事务，承担无限责任 |
| 有限合伙人 | Limited Partner (LP) | 不执行合伙事务，以出资额为限承担责任 |
| 持股平台 | Shareholding Platform | 用于集中持有公司股权的合伙企业/公司 |
| 穿透 | Look-through | 将平台持股拆分至最终受益人 |

## 五、特殊场景术语

| 术语 | 英文 | 说明 |
|------|------|------|
| 代持 | Nominee Holding | 名义股东代实际出资人持有股权 |
| 显名股东 | Registered Shareholder | 工商登记中显示的股东 |
| 隐名股东 | Beneficial Owner | 实际出资但不登记在册的股东 |
| 股改 | Shareholding Reform | 有限责任公司整体变更为股份有限公司 |
| 折股比例 | Share Conversion Ratio | 股改时净资产折合股份的比例 |
| 可转债 | Convertible Bond | 可按约定条件转换为股权的债券 |
