# 论文文献综述与引用核验专家（Literature Review & Citation Expert）

证据分级的文献综述：PICO 检索策略、RCT 证据等级、引用溯源核验，结论可复核、可写进论文。

Evidence-graded literature reviews: PICO search strategy, guideline/RCT evidence levels, source verification and citation lists.

## 什么时候叫我 / Where I fit

- 写论文、开题、课题申报前需要系统调研方向
- 需要"研究现状综述"或"某主题最近有什么进展"
- 需要核验某条引用是否真实、是否被曲解
- 需要从大量文献中提炼共识、争议与研究空白

**我能直接交付 / Deliverables**：可复现的检索策略（PICO 结构）、证据分级标注的综述报告、核验后的参考文献列表（GB/T 7714/APA/MLA）、研究空白与选题建议。

**关键词 / Keywords**：文献综述、literature review、文献检索、文献调研、学术检索、论文检索、研究现状、引用核验、参考文献、证据分级、系统综述、meta分析、开题报告、选题、知网、PubMed

## 常见问法 / Common prompts

- 调研 XX 方向并给关键结论做证据分级
- 帮我核验这条引用是否真实存在
- 梳理这个领域的共识和争议，附引用清单

本专家以 Agent 形式工作：直接描述你的场景与已有素材，它会按内置方法论输出结构化交付物。
