# 学术论文配图设计专家

把论文文案或参考截图转化为发表级学术配图。默认输出可直接嵌入论文的 LaTeX/TikZ 矢量代码，也支持输出可自由编辑的 draw.io 文件，并通过编译验证与多轮视觉审查闭环，保证最终交付的图在排版、配色与信息密度上达标。

## 这个专家解决什么问题

- 论文里的系统架构、协议流程、数据流水线、方案对比、几何原理，难以画出有设计感的图。
- 已有参考图想复刻成可编辑代码，手工量尺寸、调坐标极其耗时。
- 图能生成，但标签重叠、箭头穿框、版式松散，反复返工。
- 示意图只有方框和箭头，缺少公式、指标与嵌入图表，被审稿人认为信息密度不足。

## 核心能力

- **文案驱动**：解析论文段落，识别学科领域与核心结论，先写图契约再设计版面。
- **图片复刻**：测量参考图比例与布局，复刻为可编辑矢量代码。
- **双格式输出**：TikZ（嵌入论文、公式精确）与 draw.io（路线图、展示图）。
- **数据可视化嵌入**：热力图、混淆矩阵、损失曲线、柱状图、雷达图、散点图、公式框等。
- **复杂度分档**：极简 / 中等 / 复杂按需选择，简单图保持简洁，复杂图才展开细节。
- **迭代闭环**：编译、渲染 300dpi 预览、逐项视觉审查、独立多镜头对抗审查，直到零 blocker。

## 支持的图表类型

| 类型 | 布局 | 典型场景 |
|------|------|---------|
| 系统架构图 | 垂直分层 | 端→云→链、硬件→中间件→应用 |
| 时序交互图 | 多列生命线 | 多方协议、握手流程 |
| 对比方案图 | 左右并列 | 原方案 vs 改进方案 |
| 数据流水线图 | 水平多阶段 | 输入→处理→输出 |
| 三栏映射图 | 左-中-右 | 格式转换、API 适配、编码映射 |
| 几何 / 数学示意图 | 坐标系 | 算法原理、向量关系、曲线族 |
| 多实例汇聚图 | 横排→汇聚 | 联邦学习、分布式系统 |
| 数据可视化混合图 | 框图 + 嵌入图表 | 模型架构 + 热力图 / 曲线 / 柱状图 |
| 技术路线图 | 多层分区 | 研究框架、论文路线图 |
| 时序 / 交互 / 嵌套展示 | 多层嵌套 | 从宏观到微观、侧栏 + 中心 |

## 工作方式

专家按连续阶段推进：环境检查与路径分流 → 图契约与画图指令 → 布局与配色选择 → 代码生成（复杂图分模块验证）→ 编译与渲染验证 → 视觉审查闭环与用户终审。任何阶段发现问题都会回到对应环节重做，而不是"差不多就交付"。

## 环境要求

TikZ 输出需要本地具备：

- TeX Live（含 `xelatex`）
- 中文字体（如 Noto Sans CJK SC / PingFang SC / SimHei）
- `poppler-utils`（提供 `pdftoppm`，用于 PDF 转 PNG）

draw.io 输出可直接在浏览器版编辑器中打开编辑。缺少编译环境时，专家会提示安装方式并说明替代方案。

## 使用方式

在专家市场启用「学术论文配图设计专家」后，新建对话即可使用。你可以：

1. 粘贴论文段落，例如"帮我根据以下论文内容画一张系统架构图"，专家会自动识别领域、选择格式、生成代码并编译验证。
2. 上传一张参考截图，要求"复刻成可编辑的 TikZ 矢量图"，专家会测量布局并复刻。
3. 指定输出格式，例如"用 draw.io 画一张毕业论文技术路线图"。

专家会先确认复杂度档位与生成路径（模板复用或原创设计），再开始生成，并在交付前完成编译验证与视觉审查。
