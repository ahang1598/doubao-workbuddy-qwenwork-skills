# Brand-tag 映射表（7 个专家 · 固定职能名）

Banner 顶部 `brand-tag` 必须用**专家职能名**，禁止用花名。以下是 7 个专家包的固定映射，agent 生成 HTML 时直接照搬 —— **不要自造措辞、不要改词序、不要加前后缀**。

## 固定映射（唯一权威）

| 专家包（plugin dir） | 花名（仅页脚可用） | Banner brand-tag 全文 |
|---|---|---|
| `social-content-team` | —— | `营销通 · 社媒内容专家团` |
| `account-launch-expert` | 启号 | `营销通 · 起号规划师` |
| `brand-deal-expert` | 卞现 | `营销通 · 内容变现顾问` |
| `content-strategy-expert` | 梗王 | `营销通 · 首席内容策略官` |
| `content-topic-expert` | 郝选题 | `营销通 · 选题助手` |
| `style-training-expert` | 赵写 | `营销通 · 内容风格教练` |
| `viral-analysis-expert` | 包火 | `营销通 · 爆款分析师` |

## HTML 用法

```html
<div class="banner">
  <p class="brand-tag">营销通<span class="sep">·</span>选题助手</p>
  <h1 class="title">深圳平价美食号</h1>
  ...
</div>
```

**注意**：
- 中间的 `·` 用 `<span class="sep">·</span>` 包裹（走 CSS 半透明分隔）
- 前后各留一个中文全角空格视觉更舒服（可选，template 用了）
- 整行纯白小字，无胶囊、无底色、无 icon

## 花名允许出现的位置（唯一）

**页脚 `.disclaimer`**，格式：
```html
<p class="disclaimer">—— 营销通 · 郝选题 出品｜本报告仅供参考，实际执行请结合具体场景判断。</p>
```

- 花名 = 内部人格化标签（记忆锚点）
- 职能名 = 对外能力域声明（正式感）
- 一份产出物里两者可以共存：banner 用职能名 / 页脚用花名，各司其职

## 为什么要固定映射

1. **一致性**：7 个专家产物放一起时视觉体系统一
2. **可识别**：老板/同事扫读 banner 一眼知道是"哪个能力域的产物"
3. **可维护**：agent 不用现场自造名字，避免出现"选题专家"、"选题分析师"、"内容规划师"等漂移措辞
4. **可扩展**：未来新增专家时，在本表加一行即可

## 违反示例（禁止）

- ❌ `营销通 · 郝选题`（花名，只能页脚）
- ❌ `by 郝选题`（前缀不对）
- ❌ `选题助手 · 营销通`（词序颠倒）
- ❌ `【选题】深圳平价美食号`（把职能塞进 title）
- ❌ `营销通 · 选题助手 V1.0`（版本号）
- ❌ 只写 `选题助手`（缺品牌前缀）
- ❌ 自造名字：`选题专家` / `选题分析师` / `内容选题师` —— 必须严格按上表照搬
