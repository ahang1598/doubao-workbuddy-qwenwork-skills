# 行业包：金融商单合规（微信生态）

> 来源：**L1** 微信公众号金融行业商单合规知识库（26 条卡审词，2026-08-14）+ 视频号金融商单卡审注意点（真实互选 Brief 附录）
> 适用场景：**接金融类商单**（公众号互选、视频号互选）的创作者自查与改写
> ⚠️ 与其他文档的分层：`ad-risk-words.md`（广告法通用）→ `finance-social.md`（金融监管法规，管"谁能做"）→ **本文档（管"这个字能不能写"，最末端最具体）**

## 0. 使用前必读：这份词表为什么这么严

金融商单的审核标准**远严于**普通内容，且严格方式很特殊：

1. **中性术语也禁用**：牛市、熊市、龙头、龙虎榜、买入、卖出、政策、会议——这些在财经语境里是纯中性词，但在金融商单里就是卡审点
2. **严到单字级**：稳、赚、涨、收益——命中范围极大，**必须结合语境判断，不能机械匹配**（"稳健配置"是风险表述，"稳赚不赔"是红线）
3. **部分规则只在商单场景生效**：扫码、商务、美股——创作者自己发内容不受限，接商单则禁止
4. **平台政策 > 品牌诉求**：品牌方 Brief 常要求写平台不让写的内容，此时**以平台规则为准**，并给品牌方替代方案

## 1. 三级卡审词表

### P0 红线（命中必改，不可协商）

| 词/情形 | 原因 | 改法 |
|---|---|---|
| 美股（及境外股票、境外理财服务） | 涉及境外理财，互选商单禁止出现 | 删除，改为泛化表述或聚焦境内市场 |
| 扫码、商务、加群、私信我 | 互选商单禁止诱导加群/加好友/私域引流 | 删除全部导流话术与联系方式 |
| 具体资产名称、产品代码、个股名称 | 不可明示或暗示单一资产推荐 | 改为赛道/品类层面表述（"某类主题 ETF"而非具体产品名） |
| 收益承诺类（稳赚、保本、必赚、零风险） | 收益承诺，违反广告法与金融监管规定 | 删除，改为风险提示 |
| 国家背书类：国家队、中国、国运 | 不可用国家背书 | 删除 |
| 政府、政策报告、发文号、具体政策文件引用 | 不可引用具体政策/政府报告 | 改为宏观环境的中性描述，不引用文件 |

### P1 高风险（中性术语但金融商单禁用，须改写）

| 词 | 原因 | 建议替代 |
|---|---|---|
| 牛市 / 熊市 / 慢牛 | 夸大市场判断 | 市场情绪偏暖/偏弱、阶段性行情、市场波动加大 |
| 龙头 / 龙虎榜 | 暗示个股推荐、夸大 | 行业内规模较大的公司（不点名）、资金关注度较高的方向 |
| 买入 / 卖出 | 明显行为引导 | 配置思路、参与方式（仅讲方法不给指令） |
| 跑赢 | 业绩比较承诺 | 与基准的差异（须有数据来源）、历史表现（须标注不预示未来） |
| 政策 / 十五五 / 会议 | 涉及国家政策 | 宏观环境变化、行业发展阶段（不引用具体文件与会议） |
| 中美 / 贸易战 | 涉政敏感 | 外部环境变化、国际市场波动 |
| 无限 | 夸大 | 删除该修饰 |
| 红利 | 易被理解为收益暗示 | 视语境改为"分红类策略"（讲方法不讲收益） |
| 放水 | 表述不规范易生歧义 | 流动性环境变化 |
| 韭菜 | 引发读者负面情绪 | 中性表述（普通投资者、新手投资者） |
| 羊毛 | 暗示短期套利 | 删除，不做套利导向表述 |

### P2 需看语境（单字类，判定必须结合上下文）

`稳` `赚` `涨` `收益` `回报`

**判定规则**：

| 语境 | 判定 | 例子 |
|---|---|---|
| 与承诺/保证连用 | **P0 红线** | 稳赚不赔、保本保收益、稳定回报 |
| 作为形容或预测 | **P1 须改** | 收益可观、稳步上涨、大概率会涨 |
| 客观陈述 + 有来源 + 有风险提示 | **可保留但需标注** | "该指数近三年年化波动率为 X%（数据来源：XX，历史表现不预示未来）" |
| 出现在风险提示语中 | **保留** | "投资有风险""收益与风险并存" |

⚠️ **不要机械替换单字**——把"稳健"改成"健"、"上涨"改成"上X"会破坏文意。命中时给出**整句改写建议**，而非替换单字。

## 2. 视频号金融商单专项（口播/画面）

> 来源：真实互选 Brief 附录的卡审注意点

**口播与配图文案**：
- 不可明示暗示具体资产推荐，不露产品代码与名称
- 不提个股名称与代码；不提牛市/牛股/慢牛/龙虎榜等夸大描述
- 不可用国家背书（国家队/中国/国运）
- 不可引用具体政策报告、政府报告，不出现"政府"与发文号
- 不能贬低同类产品；不提第三方品牌
- 配图花字/字幕中 ETF 须**全部大写**

**画面要求**：
- 涉及数据处必须**展示数据来源**
- **全程添加风险提示**，需避开左右各 44px、上 147px、下 103px 区域，且不与视频号原生文案位置重叠
- 引导点击组件时手势指向必须准确（组件在左下角；镜面拍摄注意方向相反），**不能加箭头图标**
- 打码产品配图中的数据（如"10万+人使用"）
- 打码配图中的涉政信息（政策方针、政府名称、国外时事热点）

**必带项**：
- 风险提示文案："市场有风险，投资需谨慎"（全程含封面）
- 品牌方指定话题标签

## 3. 商单审核流程（创作者需知的节奏）

以真实互选 Brief 为例，**脚本要过两轮内部 + 一轮平台预审**，视频还要再走一遍：

```
脚本初稿 → 客户内部审核 → 脚本修改稿 → 平台预审
  → 视频初稿 → 客户内部审核 → 视频修改稿 → 确认封面生成预览
  → 提交平台审核定稿 → 按约定时间发布
```

**给创作者的实操提醒**：
- **脚本阶段就要过合规**，等视频拍完才发现卡审点，返工成本极高
- 平台预审有时效，排期要留足（公众号加热类审核约 1-3 工作日，视频号互选审核另计）
- 发布后**未经品牌方同意不得自行删改内容**

## 4. 品牌要求与平台规则冲突时怎么办

这是真实场景中最高频的困境——品牌方想要的表述平台不让写。处理原则：

1. **平台规则优先**，不可为满足品牌方而写违规内容（拒审浪费双方时间，严重的影响账号）
2. **给替代方案而非直接拒绝**：品牌想强调"稳健收益"→ 改为讲"这类资产的波动特征与配置逻辑"，既传递品牌意图又合规
3. **明确告知品牌方冲突点**，并附平台规则依据——这是专业度体现，也是保护创作者
4. **保留沟通话术**：帮创作者准备一段可直接发给品牌方的说明（哪条要求不可行、为什么、建议怎么改）

典型冲突映射：

| 品牌方常提的要求 | 平台不允许 | 合规替代 |
|---|---|---|
| 突出产品收益表现 | 收益承诺/业绩排序 | 讲品类特征与投资方法，数据须标来源与免责 |
| 点名主推产品 | 不可露具体资产名称代码 | 讲赛道/主题方向，不点名 |
| 引导下载/开户/加群 | 明显行为引导与私域引流 | 只做认知科普，转化交给官方组件 |
| 引用政策利好 | 不可引用政策/政府报告 | 改为行业发展阶段的中性描述 |
| 强调"跑赢大盘" | 业绩比较承诺 | 删除比较表述，或用有来源的历史数据 + 免责声明 |

## 5. 免责边界（必须向用户说明）

预检的作用是**清除已知卡审点**，**不能保证平台一定通过**——平台审核存在人工判断与政策动态调整。表述口径：

> "已知卡审点都帮你清掉了，但平台审核有主观空间和动态调整，不能保证 100% 通过。建议脚本阶段先提交预审。"

禁止承诺"改完必过审""包过"。
