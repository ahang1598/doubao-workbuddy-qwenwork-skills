## 一、通用高危类别

| 类别 | 代表词 | 说明 |
|---|---|---|
| 绝对化用语 | 最/第一/首/唯一/NO.1/顶级/极致/绝版/XX级（国家级/世界级）/XX之王/天花板 | 广告法明令禁止，最高发违规点 |
| 夸张禁用 | 至臻/无人能及/绝无仅有/万人疯抢/再不抢就没了/错过就没机会 | 制造虚假紧迫与夸大 |
| 国家形象 | 国家免检/驰名商标/国家机关推荐/领导人推荐/国宴/部队/武警 | 借国家背书，严禁 |
| 承诺保证 | 零风险/特效/奇效/根治/1天见效/100%有效/无效退款（须符合真实性） | 效果承诺类 |
| 金融投资 | 收益率/包回报/保底收益/保本稳赚/年化收益/快速回报 | 普通商品禁用，金融产品需资质 |
| 医疗保健 | 药方/治疗/消炎/抗癌/治愈率/疾病名称/华佗/李时珍/靶向 | 非医疗资质内容禁用 |
| 封建迷信 | 招财进宝/化解小人/风水/开光/转运/看相 | 一律禁用 |

## 二、分行业高危点

| 行业 | 高危规则（节选） |
|---|---|
| 化妆品 | 禁用"药妆""医学护肤品"；美白针/童颜针/溶脂针/线雕等医美项目名为非规范用语；防脱发类仅限特殊用途化妆品 |
| 医疗器械 | 禁代言、禁"保险公司承保"、禁评比/获奖/推荐表述 |
| 保健食品 | 禁"消除焦虑""生活必需"等超范围功效 |
| 酒类 | 禁"消除紧张/焦虑"、禁诱导饮酒表述 |
| 婴幼儿奶粉 | 禁"替代母乳""接近母乳/人乳" |
| 教育培训 | 禁"保证提高学习成绩""保证就业""免考包过""无需学习" |
| 房地产 | 禁风水宝地/龙脉、禁"车程 X 分钟""步行至"、禁升值承诺、禁"不限购不限贷" |
| 医疗美容 | 大量项目名（热玛吉类/针剂类）为非规范用语，投放基本需资质 |
