# 行业包：宠物（食品 / 用品 / 医疗 / 服务）

> **可信度：L1（二手权威汇总）** —— 依据行业媒体对 2026 年上半年国家层面监管新政的系统梳理整理，**具体条款以各主管部门官方原文为准**。
> 认知截止：2026-08
> 适用场景：宠物类内容创作、商单合规预检、品牌投放方法论提炼

## 0. 使用前必读：宠物行业已进入强监管常态化

2026 年是中国宠物行业从"野蛮生长"转向**强监管常态化**的关键年。多部门协同发力，密集出台覆盖**食品、医疗、服务、用品全产业链**的新政。

**对内容营销影响最直接的两条**：

1. **《网络测评活动规范》**（2026-06，国家网信办 + 市场监管总局联合印发）——**宠物食品、用品等测评乱象高发领域被列为重点治理对象**。而"测评"恰恰是宠物类内容最主流的形态之一，这条直接影响能不能规模化复制测评形态。
2. **《直播电商监督管理办法》**（2026-02，市场监管总局 + 国家网信办）——直播带货兴起以来首个全国性、系统性监管规定。

⚠️ **不要把宠物当成"无监管品类"来做内容规划。** 功效宣称的空间在 2026 年被显著压缩。

## 2. 内容红线（P0 / P1 / P2 三级，与通用框架叠加）

### P0 红线（命中必改）

| 情形 | 原因 | 改法 |
|---|---|---|
| 宣称**治疗、预防、治愈**疾病 | 宠物食品/用品**不是药品也不是医疗器械** | 删除疾病相关表述；改为讲配方特点与适用场景 |
| **处方粮**作为普通粮宣传，或推荐给健康宠物 | 处方粮有专门标准与适用条件，应在专业指导下使用 | 明确标注适用条件；建议咨询执业兽医 |
| 虚构使用效果、虚假对比实验 | 违反广告法；测评规范重点治理 | 只讲真实使用记录；对比须有真实可复现依据 |
| 绝对化用语（最好的粮 / 第一 / 唯一 / 顶级） | 广告法第九条 | 删除绝对化修饰 |
| 承诺保证类（保证不挑食 / 一定长胖 / 无效退款式承诺） | 效果承诺 | 改为个体差异说明 |
| 贬低同类产品或点名踩竞品 | 广告法第十三条 | 删除比较，只讲自己 |
| 无资质做诊疗建议 | 宠物医疗需执业资质 | 改为"建议就医"，不给诊疗方案 |

### P1 高风险（须改写）

| 表述 | 问题 | 建议替代 |
|---|---|---|
| 提高免疫力 / 增强抵抗力 | 近似保健功效宣称 | 描述配方成分与营养构成，不宣称身体效果 |
| 修复肠胃 / 改善泪痕 / 去毛球 | 疗效暗示 | 讲成分与适用场景，标注个体差异 |
| 天然 / 无添加 / 零添加 | 需有依据且符合标签规范 | 按实际配方如实描述，不做泛化宣称 |
| 兽医推荐 / 医生都在用 | 涉专业身份背书，须真实可查 | 无法证实则删除 |
| 人食级 / 人用标准 | 概念模糊易误导 | 改为具体的原料与工艺描述 |
| 吃了就爱吃 / 挑食猫都吃 | 效果承诺 | 改为"我家猫的反应是…"并说明个体差异 |
| 救命粮 / 神粮 | 夸大且带医疗暗示 | 删除 |

### P2 需看语境

`改善` `修复` `健康` `营养` `安全` `最` `第一`

| 语境 | 判定 |
|---|---|
| 与疾病、症状连用（改善肠胃炎） | **升级 P0** |
| 泛化功效宣称（改善体质） | **P1** |
| 客观描述配方或标准（符合 XX 营养指南的营养配比） | **可保留**，须标依据 |
| 日常固定用法（最近换粮 / 第一次开罐） | **保留** |

⚠️ 同样禁止机械替换单字，命中给整句改写。

## 3. 测评类内容专项（重点，因为这是宠物内容主流形态）

《网络测评活动规范》把宠物食品、用品列为重点治理对象。做测评类内容或让达人做测评时须注意：

| 要点 | 说明 |
|---|---|
| 测评过程须真实可复现 | 不得虚构测试、编造数据、摆拍"实验" |
| 结论须与测试范围匹配 | 用一只猫两周的体验，不能得出"这款粮更健康"的普适结论 |
| 不得以测评之名行贬低之实 | 拉竞品做对照并给出优劣结论，风险很高 |
| 商业合作须标识 | 收费测评未标注属于典型违规 |
| 专业结论须有资质支撑 | 成分安全性、营养充足性等专业判断，非专业人士不宜下定论 |

**对品牌方规模化复制的直接影响**：如果自来水样本里大量是测评形态，**不能简单照搬去投达人**——自发测评与收费测评在规范上是两种性质。规模化时须改造形态（如改为使用记录、场景化分享），或确保测评合规且标识到位。

## 4. 品牌方投放时的额外注意

| 项 | 说明 |
|---|---|
| 报备与流量池 | 小红书蒲公英、抖音星图、腾讯互选报备后进入商业流量池，分发逻辑与自然流不同（详见 `cross-platform.md`） |
| 素材授权 | 使用用户自发内容（自来水）做二次传播或广告素材，**须取得授权**，不得直接搬运 |
| 达人资质 | 涉及宠物医疗、营养专业结论的内容，须核对达人是否有相应资质 |
| 直播带货 | 适用《直播电商监督管理办法》，宣称口径与货品资质须同步合规 |
