# 平台玩法知识库（Platform Playbook）

国内主流社媒平台的认知与玩法参考库，供社媒内容专家团全体成员使用。

## 使用方式

1. **按需读取，不全量加载**：本 SKILL.md 只是索引。需要哪个平台的认知，就读取 `references/` 下对应文档
2. **每个平台文档统一 9 维度**：内容形态与规格 / 流量分发机制 / 起号要点 / 爆款范式 / 变现路径 / 限流红线 / 发布节奏 / 付费加热 / **商单报备与流量池**
3. **跨平台问题读 `cross-platform.md`**：对照矩阵 + 一鱼多发 + 付费加热双层框架 + **自然流量池 vs 报备商业流量池**（第 7 节，重要认知框架）
4. **用词合规读 `ad-risk-words.md`**：广告法高危词蒸馏表（L1），所有文案产出前的合规自查依据

## 行业包机制

- **通用内核 + 行业包**：平台文档是行业无关的通用认知；用户属于特定赛道时，先查 `references/industry-*.md` 有无对应行业包，有则叠加使用
- **优先级：L0 法规 > 行业包 > 平台通用文档**。涉及强监管行业时，先确认主体资质与法规边界，再谈内容与投放方案
- 行业包内容结构：监管前提（如有）/ 账号体系与资质 / 合规红线 / 内容范式 / 转化链路与 benchmark
- ⚠️ **行业中立铁律**：**没有对应行业包时如实告知**"这个行业没有专门规则库，建议基于通用广告法与平台规范"，然后用通用内核 + WebSearch 兜底。**严禁拿相近行业的规则硬套**——把金融规则套到医美上会给出错误的合规建议。也**不要因为金融材料最多就默认用户是金融行业**
- 服务跑通后可沉淀新行业包
- ⚠️ **金融赛道特别注意**：《金融产品网络营销管理办法》2026-09-30 实施，非持牌主体（含达人/素人号）不得开展或变相开展金融产品营销——服务金融客户前必读 `industry-finance-social.md` 第 0 节
- ⚠️ **强监管不只有金融**：医疗、医美、药品、保健食品、教育培训、房产、酒类、**宠物食品与医疗**均属强监管。宠物行业 2026 年已进入强监管常态化，且《网络测评活动规范》直接管到内容形态

## 时效性规则（重要）

- 每篇平台文档顶部标注了**认知截止日期**，那是快照不是真理
- 涉及**当前热点、最新政策、平台规则变动**时，必须用 WebSearch 查实时信息，不得只依赖包内快照
- 发现包内文档与现实明显不符时，明确告知用户"该条认知可能已过期"，并给出核实建议
