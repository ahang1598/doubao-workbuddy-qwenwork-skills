# 社媒内容专家团 (Social Content Expert Team)

帮自媒体和品牌号搞定起号涨粉、爆款拆解、投流和变现，个人和小团队都能找到自己的做法。

定位是**教练 + 分析师**，不是代写工厂——核心资产是个人风格养成（含去 AI 味）、爆款拆解，以及对微信 / 小红书 / 抖音生态规则与投流机制的一手认知。

## 类型

Team 型（多角色协作团队）：主理人 + 5 位成员

## 六条预设工作流（SOP）

1. **起号陪跑**：启号（赛道+定位+对标+30天路线图）→ 郝选题（首月内容日历）→ 主理人汇编
2. **涨粉诊断**：启号（四维体检+重规划）→ 包火（内容层面拆解）→ 优化优先级 + 行动方案
3. **风格养成**：赵写（有作品→12 维提取 / 无作品→五问访谈共创 → 去 AI 味 → 按自己风格写）→ 主理人存档到 workspace memory
4. **爆款复制**：包火（拆模板）→ 郝选题（选题变体）→ 赵写（照风格成稿）
5. **变现规划**：启号（账号资产盘点）→ 卞现（路径+报价+合作评估）；商单场景可直接进卞现拆 Brief
6. **自来水方法论提炼**（品牌方/小团队）：包火（跨样本九步归纳）→ 赵写（行业合规核对）→ 卞现（达人分配与条款）→ 主理人汇编方法论报告 + 达人 Brief 骨架

主理人按用户需求信息是否齐全，决定先追问还是直接派活；用户的风格档案由主理人写入 workspace memory，跨会话可持续养成。

### 平台知识库覆盖（均基于官方材料）

- **付费加热全覆盖**：公众号加热工具、视频号微信豆 + 互选二次推广矩阵、小红书薯条 + 聚光/蒲公英/灵犀、抖音 DOU+ 产品矩阵
- **流量池分层认知**：社区自然流量 vs **报备商业流量**（星图/腾讯互选/蒲公英）vs 付费加热工具，三者正交；含"报备不等于观众看到广告标识"的关键区分与跨池衰减机制
- **限流红线**：四平台官方运营规范（诱导分享、洗稿判定、搜索作弊、AI 内容标识、主体连坐等）
- **合规工具**：广告物料高危词表（绝对化/夸张/承诺保证/金融/医疗/迷信等 7 类 + 9 个分行业规则）
- **行业包**：金融 × 社媒（《金融产品网络营销管理办法》持牌主体要求与 KOS 模式）；金融 × 微信商单（三级词表、审核流程、品牌要求冲突处理）；宠物（2026 监管新政、网络测评规范、功效宣称边界）

### 行业中立设计

主干方法与技能**行业无关**——分析的是"怎么做"，不是"做什么"。行业规则全部隔离在 `references/industries/` 下按需加载。

- 用户未说明行业时**不默认任何行业**（包括不默认金融，尽管当前金融材料最多）
- 无对应行业包时**如实告知**并只给通用框架建议，**严禁拿相近行业规则硬套**
- 主理人会**主动引导用户想清楚**自己在什么行业、要达成什么目标——涉及合规、投流、商单时行业必须明确；涉及方法论提炼时业务目标必须明确

## 时效性说明

平台规则变化快，知识库文档均标注了「认知截止日期」。涉及最新政策与热点时，成员会用实时检索核实，不只依赖包内快照。建议每季度校验一次平台文档。

1. 解压到专家目录：`~/.workbuddy/plugins/marketplaces/my-experts/plugins/social-content-team/`
2. 注册使其在专家中心可见：
