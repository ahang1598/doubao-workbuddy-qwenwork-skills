# 选题与脚本方法论 · 深度指南

> AI CMO · 内容段参考。对应专家：hot-topic-expert（热点选题专家）。
> 前置依赖：定位段产出的人设资产 + 主受众 persona + 内容支柱。
> 方法论来源【领域知识】：AIDA(St. Elmo Lewis, 1898)、Schwartz《Breakthrough Advertising》(1966)、Vogler《The Writer's Journey》(1992)。年份按业界引用口径标注；完播率/钩子阈值为平台经验值，勿当精确数。

## 〇、必填信息清单（按产出类型 · 产出前硬性核验）
| 产出 | 必填项 | 缺则 |
|---|---|---|
| 选题池 | 人设资产 + 核心受众 + 内容支柱 | 停下追问，不产选题池 |
| 脚本 | 选定选题 + 人设语气 | 停下追问，不产脚本 |

选填缺失（平台倾向/形态偏好）可标【假设-需验证】继续。详见 SKILL.md「信息门槛」节。产出前硬性核验，缺则停下追问、不产完整方案。

## 一、选题池挖掘（把灵感变池子）
单条即兴 = 靠运气；选题池 = 靠系统。多源沉淀成**可排期表格**：

| 来源 | 怎么挖 |
|---|---|
| 对标爆款复刻 | 拆对标爆款选题，用自己人设重做 |
| 平台热点/搜索词 | 热榜、搜索下拉词、行业关键词 |
| 用户评论问号 | 评论区/私信反复被问的问题 |
| 人设可延展主题 | 从人设资产与内容支柱往下延展 |
| 季节/事件节点 | 行业日历、节日、热点事件 |

## 二、AIDA（钩子的祖模型）
Attention → Interest → Desire → Action。迁移到短视频：开场 1 句抢 Attention(钩子)，中段制造 Interest/Desire(信息差/情绪/反转)，结尾给 Action(关注/收藏/评论)。

**可落地**：脚本第一句强制套"AIDA 第一锤"——承诺反常识结论 / 抛未解之谜 / 直接给利益。

## 三、钩子模板库（操作化，源自 Schwartz 认知层级）
Schwartz 核心：**市场并非对产品有意识，而是对解决自身已有问题的意识**。所以钩子不是介绍内容，而是**对接观众脑中已有的欲望/焦虑**。

| 模板 | 示例 |
|---|---|
| 数字清单型 | "3 个让你少走一年弯路的…" |
| 反共识型 | "你以为…其实错了" |
| 痛点放大型 | "还在因为…卡住？" |
| 身份归属型 | "做…的人必看" |
| 结果前置型 | "我用 30 天做到…，方法是…" |

**可落地**：建钩子模板库，每条选题配 1 模板 + A/B 变体（算法对首句/封面极敏感，单钩子不够）。

## 四、故事 4 拍弧线（Vogler 英雄之旅压缩）
案例/经历/故事类内容用 4 拍弧线最稳：**常态 → 触发事件 → 试炼 → 转变**。

知识/清单类用 AIDA。**不混用**——故事类用弧线查起伏，清单类用 AIDA 查漏斗。

## 五、完播率三段结构 + 流失风险线（平台经验，阈值勿当精确数）
① **开场 3s**（钩子，决定是否划走）→ ② **中段每 5-8s** 设一个小钩子/信息增量，维持预期外回报防流失 → ③ **结尾 5s** 情绪收口 + 轻引导（不强 CTA 以免影响自然完播）。

**核心动作**：脚本标注"流失风险线"——标出预计最可能被划走的 2 个点，各放一个微反转/新信息。

**反模式**：钩子不兑现（完播上但取关）；中段信息密度过高无起伏断崖；强 CTA 放最前破沉浸；只写 1 钩子不做变体。

## 六、各平台内容形态
| 平台 | 内容形态 | 脚本要点 |
|---|---|---|
| 抖音 | 短视频 | 完播率为王，前 3 秒+中段钩子 |
| 视频号 | 短视频 | 社交裂变，开场即价值，鼓励转发 |
| 小红书 | 图文/短视频 | 种草导向，标题+封面+正文结构化 |
| 公众号 | 长文 | 深度，标题驱动打开 |
| B站 | 中长视频 | 信息密度，开头留人+中段干货 |

多平台是按形态**适配改写**，非搬脚本。

## 七、脚本结构校准三查
1. 钩子够不够强（前 3 秒能不能让人不划走）
2. 中段掉不掉人（每 5-8s 有没有小钩子；流失风险线有没有补）
3. 结尾有没有 CTA（引导动作是否清晰，且不破坏沉浸）

## 八、常见陷阱
- 选题不在支柱内 → 人设漂移，回定位段
- 钩子平淡（"今天分享一个方法"）→ 没人留
- 脚本无 CTA 或 CTA 过重 → 互动率低/破沉浸
- 一稿多投不改编 → 形态不适配
- 选题池不排期 → 有池不用
- 信息不足就硬出方案 → 选题漂移、脚本无语气，违反必填门（见§〇必填信息清单）
- 产出暴露内部代号/英文ID，或文风机械像AI → 用户看不懂署名代号、口播稿像作文；遵守主理人 MD「面向用户文档呈现规范」（脱敏+文风铁律）
