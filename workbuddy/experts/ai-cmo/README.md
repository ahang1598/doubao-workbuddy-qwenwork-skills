# AI CMO

3 位专家接力协作，跑通「账号定位 → 选题脚本 → 涨粉变现」全链路，含数据复盘与反哺选题的闭环。

## 类型

Team 型（3 人团队：1 主理人 + 3 专家）

## 功能

- **账号定位与人设**：人设资产梳理、核心受众定义、对标账号拆解、内容支柱提炼
- **选题与脚本创作**：选题池挖掘、爆款钩子设计、脚本结构校准、各平台内容形态适配
- **涨粉与变现**：发布前优化、评论区互动、数据分层复盘、多平台分发、变现路径设计
- **全链路编排**：主理人按「定位 → 内容 → 增长」接力，数据复盘反哺选题形成闭环

## 技能

| 技能包 | 说明 |
|---|---|
| `skills/self-media-ops` | 3 专家共用的自媒体运营方法论中枢（定位/选题脚本/涨粉变现三大模块 + 深度 references） |

## 团队成员

| 角色 | 职责 |
|------|------|
| 主理人 | 编排三段链路、建团队、消息中转、汇总交付 |
| IP孵化操盘手 | 人设资产梳理、核心受众定义、对标账号拆解 |
| 热点选题专家 | 选题池挖掘、爆款钩子设计、脚本结构校准 |
| 多平台内容操盘手 | 发布前优化、评论区互动、数据复盘、多平台分发、变现路径 |

## 使用示例

- 我想做一个账号，但不知道怎么定位，能帮我从零起号吗
- 这周该发什么？帮我写个能爆的脚本
- 我的号卡在几千粉涨不动，怎么办
- 我有几万粉了，怎么开始变现不伤人设
- 这条数据为什么不好，帮我复盘并改下个选题
- 一条内容怎么做多平台分发

## 头像

头像已生成在 `avatars/` 目录。**由 AI 生成，统一专业漫画插画风格 + 粉品红背景，512×512 PNG，可直接使用；如需更换美术风格，按下方 SOP 同名替换即可。**

### 替换 SOP

1. **规格**：PNG（推荐）或 JPG，512×512 px，单张 <500KB，统一漫画/插画风格，专业自然。
2. **文件名必须与 `plugin.json` 路径一致**（同名替换，勿改名）：`team.png` / `ai-cmo-team-lead.png` / `ip-incubation-lead.png` / `hot-topic-expert.png` / `multi-platform-content-lead.png`。
3. **替换后复验**（在 `ai-cmo/` 目录下执行）：
   ```bash
   cd avatars
   for f in *.png; do
     echo -n "$f  "
     sips -g pixelWidth -g pixelHeight "$f" | awk '/pixel/{printf "%s ", $2}'
     echo "(bytes: $(stat -f%z "$f"))"
   done
   ```
   确认每张 `pixelWidth=512 pixelHeight=512`、`bytes < 512000`。
4. **一致性复核**：替换不改动 `plugin.json` 的 `avatar` / `members[].avatar` 路径；替换后仍应满足 §8.6 头像约束（本地文件非 URL、指向真实文件）。
5. 头像替换属纯资产替换，不影响 §8.7 一致性约束的其余 9 条。
