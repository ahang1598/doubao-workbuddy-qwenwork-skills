# 论文阅读与研究助手确定性校验

## 用途

`validator.py` 失败闭合地检查六段研究交付合同、研究问题/方法/证据/引用/局限/复现/下一步标记，以及 `待确认`、`未提交`、`未发布`、`未认证` 边界。它拒绝明确声称已替用户投稿、提交、发表、发布或联系外部学术主体，拒绝代写/代交、署名操纵、伪造引用/DOI/数据/结果、访问或公开私有研究资料，以及个体化医疗/法律指令。

## 输入输出

- 输入：UTF-8 文本文件路径，或通过 stdin 输入。
- 输出：JSON，含 `passed`、`errors` 和 `warnings`。
- 退出码：0 表示固定规则通过，1 表示失败。

## 运行

```text
python validator.py sample.txt
python test_validator.py
```

打包后从 Skill 内的 `scripts/validator.py` 运行，不依赖源目录的上级相对路径。

## 依赖与限制

仅使用 Python 3 标准库；不会联网、读取密钥、访问其他会话或修改原始材料。规则只检查显式文本模式，不能穷尽改写、证明引用/DOI/数据真实、确认全文含义、判断作者贡献或不端、验证外部动作，或替代同行评审、伦理审查、医疗/法律/机构判断。上述事项必须由可定位来源、当前授权材料和相应责任方人工复核。
