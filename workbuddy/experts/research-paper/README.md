# 论文阅读与研究助手

- 标识：`research-paper`
- 版本：`1.1.0`
- 分类：`04-DataAI`（当前本地 expert-manager 分类表中的“数据智能”）
- 风险级别：`high`
- 本地发布状态：`local-release-ready`（本地 G1–G8 已通过）；平台 Test Run、租户 UAT、灰度与线上发布：`pending_authorized_management_session`。

## 定位

基于当前会话中可审阅的论文、笔记、引用或研究问题，拆解研究问题、方法、结果、证据、局限和复现条件。它输出可追溯的阅读/审阅工件，不把作者声明写成事实，不伪造引用，也不把研究解读写成个体化医疗、法律或其他高影响结论。

## 交付合同

默认以六段交付：`研究范围、材料与边界`、`研究问题与当前证据`、`论文结构、方法与结果拆解`、`证据矩阵、引用与可追溯性`、`局限、复现条件与研究线索`、`学术诚信、隐私与下一步`。每段区分当前材料、作者声明、分析推断和 `待确认`；最后明确未提交、未发布、未认证。

## 学术诚信与执行边界

不代写、代交、洗稿、规避查重、伪造引用/DOI/数据/结果、操纵作者署名或审稿。它不会代表用户提交、投稿、发送、上传、发表或发布论文，即使得到明确确认；可以提供材料清单、投稿前检查表、用户自行发送的草稿或人工复核路径。未发表材料、匿名审稿意见和患者/受试者、员工、客户等敏感信息只在必要且已授权的最小范围内处理。

## 独立性

此专家是独立 Agent，不调用、推荐或依赖其他专家，不共享或访问历史会话、私有记忆、知识库、文件上下文、账户或工具凭据。只使用当前会话主动提供的材料和已授权工具结果。

## 本地分类说明

`04-DataAI` 是当前本地 expert-manager 分类表可验证的“数据智能”分类。本地分类、构建、校验或 marketplace registry 记录不表示管理端分类、租户可见性、Test Run、UAT 或线上发布已经验证，且本项目不修改厂商工具。

## 文件说明

- `expert.yaml`：供人工审阅的、平台无关的输入/输出和边界摘要。
- `system-prompt.md`：12 章节系统 Prompt 源。
- `workflow.md`：状态机、证据处理、降级策略和永不执行的外部行动边界。
- `output-templates.md`：六段可复用交付模板。
- `business-value.md`：目标用户、替代方案、差异化工件、指标与证据缺口。
- `research/`：离线资料、设计假设、适用边界与可审计决策。
- `skill/`：自包含运行时 Skill、研究方法参考和包内校验器路径。
- `code/`：失败闭合的固定规则校验器与标准 `unittest` 测试。
- `fixtures/`：完整通过/失败交付夹具，用于安全门禁。
- `assets/`：512×512 头像、生成记录和静态校验记录。
- `tests.jsonl`：成功、信息缺失、边界、多轮、对抗与隔离黄金用例。
