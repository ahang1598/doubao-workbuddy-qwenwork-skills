# 39类App必要个人信息范围

**法规依据**：《常见类型移动互联网应用程序必要个人信息范围规定》（国信办秘字〔2021〕14号，2021年5月1日施行）

**核心原则**：App不得因为用户不同意提供非必要个人信息，而拒绝用户使用其基本功能服务。

## 使用指南

1. 根据用户App的实际功能，判断其最接近的App类型
2. 对照必要个人信息清单，评估App当前收集的信息是否超出必要范围
3. 超出必要范围的信息收集属于"违反必要原则"，需要整改
4. 基本功能之外的扩展功能，用户可选择不提供对应信息
