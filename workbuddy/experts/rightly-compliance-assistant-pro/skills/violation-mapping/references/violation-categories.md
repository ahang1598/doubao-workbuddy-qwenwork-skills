# 合规违规行为分类与技术模块映射

## 一、六大类违规行为

### 第一类：未公开收集使用规则

**法规依据**：《App违法违规收集使用个人信息行为认定方法》第一条

**认定行为**：
1. App中没有隐私政策，或者隐私政策中没有收集使用个人信息规则
2. 首次运行时未通过弹窗等明显方式提示用户阅读隐私政策
3. 隐私政策访问路径超过4次点击
4. 隐私政策文字过小过密、颜色过淡、模糊不清，或未提供简体中文版

**对应技术模块**：隐私政策展示模块
- 隐私弹窗组件
- 隐私政策页面（需确保4次点击内可达）
- 首次启动流程管理

---

### 第二类：未明示收集使用个人信息的目的、方式和范围

**法规依据**：《App违法违规收集使用个人信息行为认定方法》第二条

**认定行为**：
1. 未逐一列出App（包括第三方SDK）收集使用个人信息的目的、方式、范围
2. 收集规则变化时未适当通知用户
3. 申请权限或收集敏感信息时未同步告知目的
4. 收集使用规则内容晦涩难懂、冗长繁琐

**对应技术模块**：
| 模块 | 说明 |
|------|------|
| 三方SDK披露模块 | 需完整列出所有SDK名称、收集的信息类型、目的 |
| 权限申请说明模块 | 权限弹窗需同步展示申请目的 |
| 敏感信息告知模块 | 收集身份证、银行账号等敏感信息时需单独告知 |

---

### 第三类：未经用户同意收集使用个人信息

**法规依据**：《App违法违规收集使用个人信息行为认定方法》第三条

**认定行为**：
1. 征得同意前就开始收集个人信息或打开权限
2. 用户拒绝后仍收集或频繁征求同意
3. 实际收集超出用户授权范围
4. 以默认选择同意等非明示方式征求同意
5. 更新时自动恢复权限默认状态
6. 定向推送未提供非定向选项
7. 以欺诈、诱骗方式误导用户同意
8. 未提供撤回同意的途径
9. 违反所声明的收集使用规则

**对应技术模块**：
| 模块 | 说明 |
|------|------|
| 隐私同意前管控模块 | 同意隐私政策前禁止调用敏感API（ruleBeforeStrategy） |
| 权限状态管理模块 | 禁止更新后自动恢复已拒绝的权限 |
| 用户授权管理模块 | 提供撤回同意的途径和机制 |
| 定向推送管理模块 | 个性化推荐开关、关闭后停止收集 |

---

### 第四类：违反必要原则，收集与其提供的服务无关的个人信息

**法规依据**：《App违法违规收集使用个人信息行为认定方法》第四条

**认定行为**：
1. 收集的信息类型或权限与现有业务功能无关
2. 不同意收集非必要信息就拒绝提供服务
3. 新增功能申请超出原有同意范围，不同意则拒绝原有功能
4. 收集频度超出业务实际需要
5. 仅以改善服务为由强制收集
6. 一次性要求同意多个非必要权限

**对应技术模块**：
| 模块 | 说明 |
|------|------|
| 设备信息类模块 | IMEI/IMSI/MAC/Android ID/SN/ICCID等设备标识 |
| 定位类模块 | 经纬度/WiFi列表/基站信息/IP地址 |
| 通讯录类模块 | 联系人信息读取 |
| 剪贴板类模块 | 剪贴板数据访问 |
| 传感器类模块 | 相机/录音/加速度计/陀螺仪/气压计等 |
| 应用列表类模块 | 已安装应用信息查询/运行进程查询 |
| 网络传输类模块 | 后台静默数据上传/网络状态获取 |
| 存储访问类模块 | 非媒体文件读取/删除/创建 |
| 广播监听类模块 | 安装/卸载广播监听 |
| 短信/通话记录类模块 | 短信读取/通话记录访问 |
| SIM状态类模块 | SIM卡状态读取/运营商信息 |
| 蓝牙类模块 | 蓝牙扫描/连接 |

---

### 第五类：未经同意向他人提供个人信息

**法规依据**：《App违法违规收集使用个人信息行为认定方法》第五条

**认定行为**：
1. 客户端通过第三方SDK直接向第三方提供个人信息
2. 数据传输至后台后向第三方提供
3. App接入第三方应用，向其提供个人信息

**对应技术模块**：
| 模块 | 说明 |
|------|------|
| 三方SDK数据流监控模块 | 监控SDK的数据采集与传输行为 |
| 网络传输监控模块 | 监控后台上传的敏感字段和目标域名 |
| 数据共享管控模块 | 管控与第三方应用间的数据传输 |

---

### 第六类：未按法律规定提供删除或更正功能 / 未公布投诉举报方式

**法规依据**：《App违法违规收集使用个人信息行为认定方法》第六条

**认定行为**：
1. 未提供有效的更正、删除个人信息及注销账号功能
2. 为更正/删除/注销设置不必要或不合理条件
3. 操作已执行但后台未完成（15个工作日内）
4. 未建立并公布个人信息安全投诉举报渠道

**对应技术模块**：
| 模块 | 说明 |
|------|------|
| 账号注销模块 | 提供便捷的注销功能，不得捆绑注销 |
| 个人信息管理模块 | 查询、更正、删除、导出功能 |
| 投诉举报模块 | 投诉渠道公布、15个工作日内响应 |

## 二、工信部8类重点整治问题（2019年起）

| 类别 | 问题 | 对应技术模块 |
|------|------|-----------|
| 违规收集 | 私自收集个人信息 | 隐私同意前管控模块 |

| 注销障碍 | 账号注销难 | 账号注销模块 |

## 三、个人信息分类参考（GB/T 35273-2020）

### 个人信息示例（附录A）
- 个人基本资料：姓名、生日、性别、民族、国籍、家庭住址等
- 个人身份信息：身份证、护照、驾驶证等
- 个人生物识别信息：指纹、声纹、面部特征、虹膜等
- 网络身份标识信息：系统账号、邮箱、IP地址、Cookie等
- 个人健康生理信息：病症、病历、体检记录等
- 个人教育工作信息：学历、学位、工作经历等
- 个人财产信息：银行账户、房产、车辆等
- 个人通信信息：通讯录、短信、邮件等
- 联系人信息：联系人的姓名、电话等
- 个人上网记录：网站浏览记录、搜索记录等
- 个人常用设备信息：IMEI、MAC地址、设备序列号等
- 个人位置信息：精确定位、行踪轨迹等

### 个人敏感信息示例（附录B）
- 身份证号码、银行卡号、生物识别信息
- 宗教信仰、性取向、未公开的违法犯罪记录
- 通讯记录和内容、行踪轨迹
- 网页浏览记录、住宿信息、精准定位
- 不满十四周岁的未成年人个人信息

## 四、终端敏感行为管理参考（GB/T 47469-2026 附录A）

| 类型 | 信息/功能描述 | 是否提示 | 是否记录 | 授权粒度 |
|------|------------|---------|---------|---------|
| 应用程序列表 | 已安装App信息（名称、包名、版本） | 否 | 是 | 允许、拒绝 |
| 位置信息 | 经纬度/粗略位置 | 是 | 是 | 始终允许、拒绝、每次使用询问、仅使用期间允许 |
| 剪切板信息 | 系统共享缓存数据 | 是 | 是 | 允许、拒绝 |
| 屏幕截图 | 屏幕快照/图片 | 是 | 是 | 允许、拒绝 |
| 相机 | 拍照、摄像、扫描 | 是 | 是 | 拒绝、每次使用询问、仅使用期间允许 |
| 麦克风 | 语音通话等 | 是 | 是 | 拒绝、每次使用询问、仅使用期间允许 |
| 通讯录 | 联系人信息 | 否 | 是 | 允许、拒绝 |
| 短信 | 短文本信息 | 否 | 是 | 允许、拒绝 |
| 通话记录 | 主叫/被叫通话记录 | 否 | 是 | 允许、拒绝 |
