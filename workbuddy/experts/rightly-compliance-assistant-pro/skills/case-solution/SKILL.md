# 案例解决方案

## 功能说明

基于真实合规违规案例，提供堆栈分析方法和可执行的整改方案。涵盖后台监听、过度采集、SDK治理、权限管控等各类场景的解决策略。

## 使用场景

- 用户提供了违规调用堆栈需要分析
- 用户收到通报需要具体整改方案
- 用户需要SDK合规自查
- 用户需要配置合规监控工具（Rightly/PMonitor）
- 用户需要了解具体API与模块的对应关系
