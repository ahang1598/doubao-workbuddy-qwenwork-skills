# PDF 光栅化（把页面渲染成像素图, 供视觉 OCR 用）
#
# ⚠️ 注意: 这里装的库是用来做「光栅化渲染」的, 不是用来「提取文本层」的。
#    腾讯公益票据 PDF 普遍是 subset 加密字体, 文本层字符经 CID 映射不可信,
#    必须光栅化后交给视觉 OCR。详见 invoice-processing/SKILL.md 门禁 3。
#
# pdf_to_images.py 会按以下优先级自动探测, 任一可用即可:
#   1. pypdfium2  ← 首选: 纯 wheel, 无系统依赖, 速度快
#   2. fitz       ← PyMuPDF, 功能强 (注意 AGPL license)
#   3. pdf2image  ← 需系统装 poppler (pdftoppm), 兼容性兜底
# 若三者都不可用，脚本会把 pypdfium2 + Pillow 一次性安装到插件专属隔离目录。
# ---------------------------------------------------------------------------

# 可选备用渲染后端（AGPL license, 按需启用）
# PyMuPDF>=1.24.0

# 可选备用渲染后端（额外需要系统安装 poppler）
# pdf2image>=1.17.0

# 图像处理（pypdfium2 输出转 PIL Image 时用）
Pillow>=10.0.0
