# 证件 K-V 合理性校验规则

> 本文件是 `alert-cert-forms` skill 的 reference，描述云OCR 返回的 K-V 字段的**合理性校验规则**——用于"类型识别是否可疑"的判定。
> **与提交前校验的区别**：本文件规则用于 OCR 结果拿到后的"类型自检"（阶段：Step 2 类型判定分支）；提交前校验见各证件 references（`references/legal-registration.md` / `references/fundraising-cert.md` / `references/idcard.md`）。

## 校验目的

云OCR 可能被误调（如把身份证图传给通用证件OCR），或 alert-ocr 的类型粗判阶段判错——K-V 字段错位或缺失时，Skill 应识别到并提示"疑似类型识别错误，请确认"，而不是强行往前走。

## 校验规则表

### `cert_type=1` 社会组织法人登记证书

| 字段 | 期望格式 | 异常判定 |
|-----|--------|---------|
| 机构名称 | 中文，通常含"中心/协会/基金会/服务中心" | 含"公司"字样 → 存疑（可能是营业执照）|
| 统一社会信用代码 | 18 位字母数字组合 | 位数不对或含中文 → 异常 |
| 业务主管单位 | 中文机构名（如"XX市民政局"） | 空或纯数字 → 异常 |
| 业务范围 | 自由文本（通常一段话）| 空 → 异常 |
| 有效期止 | `YYYY-MM-DD` 或识别为"长期" | 其他格式 → 异常 |

### `cert_type=2`慈善组织公开募捐资格证书

| 字段 | 期望格式 | 异常判定 |
|-----|--------|---------|
| 机构名称 | 中文机构名 | 空 → 异常 |
| 发证机关 | 民政部/ 省级民政厅 / 市级民政局 | 空或非民政部门 → 存疑 |
| 有效期起 | `YYYY-MM-DD` | 其他格式 → 异常 |
| 有效期止 | `YYYY-MM-DD` 或"长期" | 其他 → 异常 |

**⚠️ 上下文校验**：`cert_type=2` 仅公募机构会出现。若当前机构 `institution_type != 1`（非公募/专项基金）却识别到本类型证件 → 强烈存疑，提示用户核对类型。

### `cert_type=3` 负责人身份证

| 字段 | 期望格式 | 异常判定 |
|-----|--------|---------|
| 姓名 | 中文 2-4 字 | 含数字/字母/超长 → 异常（可能识别到了其他字段）|
| 身份证号 | 18 位；前 17 位数字；第 18 位数字或 `X`（大写） | 位数不对/含小写 x/含中文 → 异常 |
| 有效期起 | `YYYY-MM-DD`（从背面识别）| 其他 → 异常 |
| 有效期止 | `YYYY-MM-DD` 或"长期" | 其他 → 异常 |

**⚠️ 正反面完整性**：身份证 K-V 需要正反面合并——若某次OCR 只有姓名+身份证号（正面）或只有有效期（反面），Skill 应继续等用户上传另一面，不进入 UI 二次确认。

## 类型识别可疑时的提示模板

```
⚠️ 检测到可能的识别错误:
[异常字段列表: 如"身份证号仅 15 位,疑似不完整"]

这可能是证件类型识别错误。请确认这是哪种证件:
1. 社会组织法人登记证书 (cert_type=1)
2. 慈善组织公开募捐资格证书 (cert_type=2, 仅公募机构会有)
3. 负责人身份证 (cert_type=3)

若您选择的类型与识别不符, 我会重新按您指定的类型解析字段。
```

## 与后续步骤的关系

- **校验通过** → 进入表单确认（会话内展示 K-V），暂存到 cert_types_done
- **校验异常** → 展示异常字段 + 类型选择提示，让用户手动确认或重新上传
- **无法判定类型** → 由 alert-ocr 的 Stage 1 类型粗判层负责，本文件不覆盖该分支
