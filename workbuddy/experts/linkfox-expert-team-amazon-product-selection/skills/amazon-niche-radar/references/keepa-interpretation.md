# Keepa 历史数据解读维度

基于 `linkfox-keepa-product-series` 返回的字段，对 Top ASIN 做 8 个维度的深度解读。适用于市场洞察报告中对头部竞品的深度拆解。

## 返回字段

| 字段 | 类型 | 说明 |
|------|------|------|
| buyboxPrice | list[{time, value}] | Buy Box 价格历史（频繁更新，可识别 Deal 降价） |
| bsrSub | list[{categoryName, points}] | 子类目 BSR 排名历史（points 含 time + value） |
| rating | list[{time, value}] | 星级评分历史（-1=无数据） |
| ratingCount | list[{time, value}] | 评论数历史（增长曲线） |
| monthlySold | list[{time, value}] | 月销量历史 |

## 8 个解读维度

### 维度 1：价格波动分析（buyboxPrice）
- **最高价 / 最低价 / 当前价**：从序列提取极值和末值，判断当前价格处于历史什么分位
- **价格波动率**：`std(price) / mean(price) × 100%`，>10% 为高波动
- **价格区间稳定性**：价格频繁在 $39.99-$40.99 之间跳动 = 正常 Buy Box 竞争；大幅降价 = Deal 或清仓

### 维度 2：BSR 排名稳定性（bsrSub）
- **排名趋势**：BSR 值越小越好。序列是持续改善（变小）/稳定/恶化（变大）？
- **排名波动幅度**：BSR 在 #1-#4 之间波动 = 稳居头部；大幅跳动（#1→#50→#1）= 流量不稳定
- **排名区间**：`min(bsr)` ~ `max(bsr)`，判断该 ASIN 在子类目中的位置区间

### 维度 3：Deal 依赖判断（buyboxPrice × bsrSub 交叉分析）
- **识别 Deal 时段**：buyboxPrice 中价格突然下降的时段
- **Deal 期 BSR 表现**：价格下降期间 BSR 是否改善（排名变小）
- **Deal 后 BSR 回落判断**：价格恢复后 BSR 是否回落到 Deal 前水平
  - 回落 = 秒杀依赖（产品力不足以维持自然排名，靠降价撑排名）
  - 不回落 = Deal 带来了真实转化和评论积累，排名有沉淀
- **秒杀依赖指数**：Deal 后 BSR 回落幅度 / Deal 期间 BSR 改善幅度 × 100%

### 维度 4：评论增长趋势（ratingCount）
- **总增长量**：`末值 - 首值`
- **日均增长速度**：`总增长量 / 天数`，判断评论积累速度
- **异常突增检测**：单日/短期增长 > 200 条 = 疑似刷评或 Vine 批量投放
- **增长加速度**：近期增速 vs 历史增速，加速 = 产品热度上升

### 维度 5：评分波动（rating）
- **当前评分**：序列末值
- **评分区间**：`min` ~ `max`（排除 -1 无数据点）
- **评分趋势**：稳定 / 下滑 / 上升
- **突然下降检测**：评分单次下降 ≥ 0.3 = 差评冲击事件，需关注对应时段的评论内容

### 维度 6：月销量趋势（monthlySold）
- **当前月销量**：序列末值
- **历史峰值**：`max(monthlySold)`，判断当前是否处于销量高位
- **同比变化**：最近月份 vs 同期去年，判断增长/衰退
- **销量阶梯**：是否出现台阶式增长（如从 400→1000→2000），每级台阶对应什么事件（Deal/旺季/外部引流）

### 维度 7：价格-BSR 相关性（buyboxPrice × bsrSub 交叉）
- **价格弹性**：价格每下降 $1，BSR 改善多少名？
- **价格敏感度**：价格小幅波动（<$2）是否引起 BSR 大幅变化？是 = 消费者价格敏感；否 = 品牌力强
- **背离信号**：价格持续下降但 BSR 不改善 = 品牌衰退或市场萎缩；价格不变但 BSR 改善 = 外部流量引入或市场扩容

### 维度 8：生命周期阶段判断（monthlySold × bsrSub × ratingCount 综合判断）
- **成长期**：月销量上升 + BSR 改善 + 评论加速增长
- **成熟期**：月销量稳定 + BSR 波动小 + 评论匀速增长
- **衰退期**：月销量下降 + BSR 恶化 + 评论增速放缓
- **入场时机**：成长期中段入场（已验证需求，竞争尚未固化）；衰退期不入场

## 报告输出建议

用 Data Table 展示 8 个维度的诊断结果，每行：维度名 | 当前值 | 趋势 | 判断（正常/警告/风险）。
对 Deal 依赖和生命周期阶段两个维度追加 Summary Box 文字解读。
