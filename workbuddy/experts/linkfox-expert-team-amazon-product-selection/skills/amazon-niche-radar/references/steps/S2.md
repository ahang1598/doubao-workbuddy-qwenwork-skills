# 步骤 S2：类目与细分市场发现

- **输入**：S1 的 `Top ASIN`、`种子词`、S1.1 搜索结果中的商品类目信息
- **依赖**：S1
- **用途**：为 S3 提供 `nodeIdPath`（喂给 sellersprite-market-statistics）和确认的 `精准词`（喂给 jiimore/ABA）；为 S6.4-A 预取 Keepa 商品详情（缓存复用）；向用户展示 nicheTitle 列表

## 操作

S2-A 和 S2-B 互不依赖，同一轮并行发起。

### S2-A 类目节点查询 + Keepa 商品详情预取

用 S1 的 `Top ASIN` 调用 `linkfox-keepa-product-request`（`history=0`），一次调用同时获取：

1. **`categoryTreeId`** → 作为 `nodeIdPath` 喂给 S3.2 卖家精灵统计
2. **商品详情字段** → 预取给 S6.4-A 复用（Keepa 24h 缓存，S6.4-A 命中缓存不额外消耗积分）：
   - `price`（售价）、`fbaFees`（FBA 配送费）、`referralFeePercentage`（佣金比例）
   - `imageUrl`（主图 URL）、`title`（标题）
   - `packageLength`/`packageWidth`/`packageHeight`（包装尺寸 mm）、`packageWeight`（包装重量 g）

```json
{"asin": "<S1 Top ASIN>", "domain": 1, "history": 0}
```

取 `products[0].categoryTreeId` 作为 `nodeIdPath`（如 `172282:541966:1292115011`）。

**回退方案**（Keepa 失败或 categoryTreeId 为空时）：用 `linkfox-amazon-category-lookup` 递归钻取子类目获取 `nodeIdPath`。

→ 得到：`nodeIdPath` + Keepa 商品详情（S6.4-A 缓存复用）

> **为什么在 S2-A 调 Keepa 而不是 S6.4-A**：S6.4-A 本来就要调 Keepa 获取商品详情用于利润核算。提前到 S2-A 调一次，S6.4-A 命中 24h 缓存，不额外消耗积分。同时 S2-A 拿到 categoryTreeId 喂给 S3.2，一次调用解决两个需求。

### S2-B 细分市场发现 + 关键词交叉验证

调用 `linkfox-jiimore-get-niche-info-by-keyword`，参数：

```json
{"keyword": "<种子词>", "countryCode": "US", "page": 1, "pageSize": 50, "sortField": "unitsSoldT7", "sortType": "desc"}
```

从返回的 `data` 数组中提取所有 niche（nicheTitle + translationZh + 完整指标）。

如果该词查询失败（errcode≠200 或 data 为空），取 S1 的精准关键词集合中搜索量第二大的词重试，依此类推。

#### 交叉验证：nicheTitle × SIF 标签词

jiimore 返回多个 nicheTitle（如 "mp3 player" 查询返回 26 个），只取第一个会浪费数据。将所有 nicheTitle 与 S1.2 中 SIF 反查出的 isMainKw/isAccurateKw 关键词做交叉匹配：

1. 遍历每个 nicheTitle，检查它是否出现在 SIF 的 isMainKw/isAccurateKw 关键词集合中（精确匹配或包含关系）
2. 匹配上的 niche 标记为"已验证"，其完整指标纳入报告数据源
3. 未匹配上的 niche 保留展示但标注"未验证"

例如：SIF 返回 `mp3 player`(isMainKw), `ipod`(isMainKw), `mp3 player with bluetooth`(isMainKw), `music player`(isMainKw) 均为标签词；jiimore 返回的 nicheTitle 中 "mp3 player"、"ipod classic"、"ipod shuffle" 等与标签词相关，均可纳入有效数据源。

→ 得到：`已验证 niche 列表`（含完整指标）、`全部 nicheTitle 列表`（展示用）

## 输出

- `nodeIdPath`：类目节点路径
- `精准词`：确认用于后续查询的种子词
- `已验证 niche 列表`：与 SIF 标签词交叉匹配上的 niche，每个含完整指标（S3 复用，无需重调极目）
- `全部 nicheTitle 列表`：展示给用户的全部细分市场选项

## 用户交互

向用户展示全部 nicheTitle 列表，标注哪些已通过 SIF 交叉验证。默认使用所有已验证 niche 的数据纳入报告分析；如果用户只关注某个细分市场，可缩小范围。
