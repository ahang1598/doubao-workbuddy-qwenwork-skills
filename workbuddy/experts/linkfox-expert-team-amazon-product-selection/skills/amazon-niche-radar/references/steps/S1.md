# 步骤 S1：关键词验证

- **输入**：用户输入的品类入口词 `keyword`（如 "pet water fountain"）
- **依赖**：无（仅依赖运行时入参）
- **用途**：为 S2 提供 `精准关键词` 和 `Top ASIN`；为 S3 的 ABA 查询和 jiimore 查询提供精准词；为 S6 深度拆解提供目标 ASIN

## 操作

### S1.1 亚马逊前台搜索（默认排序，动态翻页至结果耗尽）

调用 `linkfox-amazon-search`，使用**默认相关性排序**（不指定 sort）。先并行搜 page 1-3，检查是否有更多结果，若有则继续翻页至结果耗尽（通常 3-5 页）：

```json
{"keyword": "<用户关键词>", "amazonDomain": "amazon.com", "language": "en_US", "page": 1}
{"keyword": "<用户关键词>", "amazonDomain": "amazon.com", "language": "en_US", "page": 2}
{"keyword": "<用户关键词>", "amazonDomain": "amazon.com", "language": "en_US", "page": 3}
// 若 page 3 有结果，继续并行搜 page 4-5，直到某页返回空或 < 5 个商品
```

三页合并后：
1. 过滤 `sponsored: false` 的非广告商品，按 `monthlySalesRevenue`（月销售额 = monthlySalesUnits × extractedPrice）降序排列，取**月销售额最高**的商品 → `Top ASIN`
   > **为什么按月销售额而非月销量**：月销量最高可能是低价走量产品（如 $44.99 月销 4000 = $179,960），但其 SIF 流量数据/Keepa 历史/ABA 点击转化数据可能不足。月销售额最高（如 $94.99 月销 3000 = $284,970）通常是品类的头部竞品，数据覆盖更完整，更适合作为深度拆解目标。
2. 三页合并数据**直接作为 S3.3 的数据源**（S3.3 不再重复搜索，复用 S1.1 的结果）

→ 得到：`Top ASIN` + `S3.3 前台搜索 3 页合并数据`（一次搜索解决两个需求）

### S1.2 SIF 关键词反查

调用 `linkfox-sif-asin-keywords`，参数：

```json
{"asin": "<Top ASIN>", "site": "US"}
```

从返回的关键词列表中，筛选 `isMainKw: true` 或 `isAccurateKw: true` 的词。

将筛选后的词按搜索量（searchVolume）降序排列。

→ 得到：`精准关键词集合`（有序列表）

### S1.3 确定种子词

取精准关键词集合中搜索量最大的词，作为后续 jiimore 和 ABA 查询的种子词。

如果集合为空（极端情况），回退使用用户原始输入词作为种子词，并在报告中注明"未通过 SIF 验证，使用原始输入词"。

## 输出

- `Top ASIN`：S1.1 获取的销量最高非广告商品 ASIN（同时作为 SIF 反查基准和 S6 深度拆解目标）
- `S3.3 前台搜索 3 页合并数据`：S1.1 搜索的 3 页结果（S3.3 直接复用，不重复搜索）
- `精准关键词集合`：S1.2 筛选后的有序关键词列表
- `种子词`：集合中搜索量最大的词

## 大响应处理

SIF 反查返回的关键词列表可能较长（几十到上百条），需要落盘后按需读取字段。

```bash
python scripts/response_io.py run \
    --script <sif-asin-keywords 主脚本路径> \
    --out-dir <output_dir> \
    --label S1_sif_reverse \
    '{"asin":"<Top ASIN>","site":"US"}'
```

读取时投影 `keyword, searchVolume, isMainKw, isAccurateKw` 字段筛选精准词。
