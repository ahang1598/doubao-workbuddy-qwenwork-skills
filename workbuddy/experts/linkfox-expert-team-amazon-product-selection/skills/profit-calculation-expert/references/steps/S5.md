# 步骤 5：报告生成

- **输入**：S4 的净利润数据 JSON
- **依赖**：S4（需要完整的净利润核算结果）
- **操作**：按 `references/report-template.md` 章节定义，编写 HTML 内容片段，然后调用 `linkfox-report-generator` 生成最终 HTML 报告。

  流程：
  1. Read `linkfox-report-generator` 的 `references/analysis-layouts.md` 了解可用组件
  2. 按报告章节写 HTML 片段（`.fragment.html` 文件）
  3. 调用注入脚本生成最终 HTML

- **输出**：HTML 报告文件，落盘到 `reports/` 目录

- **报告章节**：
  1. 核心指标 KPI 卡片（ASIN 总数 / 最高净利润率 / 平均净利润率 / 负利润 ASIN 数）
  2. 净利润汇总表（按净利润降序，含全部 11 项成本拆解 + 净利润 + 净利润率）
  3. 成本拆解瀑布图（ECharts，从售价逐项扣减到净利润）
  4. 利润率对比柱状图（绿>20% / 黄10-20% / 红<10% / 黑=亏损）
  5. 1688 货源匹配明细表（每个 ASIN 3 个供应商对比，含 B1/B2 来源标注 + AIGC 验证结果）
  6. 货源初步筛选提醒（醒目展示：利润核算基于初步筛选货源，用户确认货源后可重新核算）
  7. 关键洞察与建议（Insight List，按优先级标注）

- **数字规则**：千分位分隔，百分比保留 1 位小数，金额保留 2 位小数。净利润颜色：绿(#10b981) > 20%，黄(#f59e0b) 10-20%，红(#ef4444) 0-10%，黑(#1f2937) < 0(亏损)。
