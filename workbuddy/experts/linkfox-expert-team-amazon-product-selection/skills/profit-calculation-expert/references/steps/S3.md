# 步骤 3：市场指标获取

- **输入**：S1 输出的 `categoryTree` 末段和 `title` 字段
- **依赖**：S1（需要类目和标题）
- **操作**：按类目查询极目退货率 + ACoS + sponsored%，三阶段递进：

  **阶段 1 — 类目直接映射**

  从 S1 的 `categoryTree` 提取末段类目名，映射为搜索关键词。常见映射：
  | categoryTree 末段 | 搜索关键词 |
  |---|---|
  | Nightgowns & Sleepshirts | nightgowns for women |
  | Sets | pajama sets for women |
  | Sleep Sets | mens sleepwear |
  | Robes | robes for women |
  | Cover-Ups | beach coverup dress |
  | Dresses | dresses for women |
  | 其他 | 取末段原文转小写 |

  对每个关键词调用 `linkfox-jiimore-get-niche-info-by-keyword`，从返回结果中选取标题最匹配的 niche，提取 `nicheId`。

  **阶段 2 — AIGC 提炼关键词（阶段 1 无匹配时）**

  取该类目下所有 ASIN 的 `title`，调用 `linkfox-aigc-textgen` 提炼核心搜索词，重新查询。

  **阶段 3 — 宽泛词兜底（阶段 2 仍无匹配时）**

  使用更宽泛的品类词重试，最多 2 次。

  **最终查询 — 获取市场指标**

  对每个 `nicheId`，调用 `linkfox-jiimore-get-niche-info`，提取：
  - `returnRateAnnual` — 年度退货率（0-1 小数）
  - `acos` — ACoS 广告销售成本比（小数形式，如 0.1275 = 12.75%）
  - `sponsoredProductsPercentageNow` — 广告商品占比（0-1 小数）
  - 计算 `nicheTACoS` = acos × sponsoredProductsPercentageNow × 100（结果为百分比数值）

- **输出**：类目 → 市场指标映射表，每条含：
  - `category` — 类目名
  - `returnRateAnnual` — 退货率（小数）
  - `acos` — ACoS（数值）
  - `sponsoredProductsPercentageNow` — 广告占比（小数）
  - `nicheTACoS` — 类目估算 TACoS（小数）
  - `source` — 数据来源（"jiimore" 或 "默认值"）
  - `asins` — 关联 ASIN 列表

- **用途**：为 S4 提供按类目区分的实际退货率（替代默认 15%）和类目 TACoS（替代默认 10%）

- **落盘**：映射表落盘到 `data/market_metrics.json`

- **错误降级**：三阶段均无匹配 → 使用默认退货率 15% 和默认 TACoS 10%
