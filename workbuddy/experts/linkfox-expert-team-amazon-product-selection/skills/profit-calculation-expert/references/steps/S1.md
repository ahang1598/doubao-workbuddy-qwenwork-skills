# 步骤 1：Keepa 批量拉取

- **输入**：运行时入参 `asins`（逗号分隔）、`domain`（站点 ID，默认 1）
- **依赖**：无（仅依赖运行时入参）
- **操作**：

  **1a — Keepa 商品详情**

  将 ASIN 列表按每 5 个一批分组，对每批调用 `linkfox-keepa-product-request`：
  - `asin`: 逗号分隔的 5 个 ASIN
  - `domain`: 用户指定的站点 ID
  - `history`: 0（仅需当前数据，不需要历史销量）

  调用方式（所有批次并行发起）：
  ```
  python <skill_path>/scripts/keepa_product_detail.py '{"asin":"B0XXX1,B0XXX2,B0XXX3,B0XXX4,B0XXX5","domain":1,"history":0}'
  ```

  如果有 N 个 ASIN，则分 ceil(N/5) 批，全部在同一轮并行发起。

  **1b — Keepa 历史时序（与 1a 并行）**

  对每个 ASIN 调用 `linkfox-keepa-product-series`，拉取 `buyboxPrice` 历史曲线，用于 S4 取**正常售卖价**（非秒杀价）。

  - `asin`: 单个 ASIN
  - `domain`: 用户指定的站点 ID

  buyboxPrice 曲线中可能出现两个价格水平交替（如 $44.99↔$49.99），较低的是 Deal/促销价，较高的是正常 Buy Box 价。S4 脚本会自动取较高的那个。

- **输出**：每个 ASIN 的商品详情，关键提取字段：
  - `price` — 当前售价($)
  - `fbaFees` — FBA 配送费($)
  - `referralFeePercentage` — 亚马逊佣金比例(%)
  - `salesRank` — BSR 排名
  - `rating` — 评分
  - `imageUrl` — 主图 URL
  - `title` — 标题
  - `brand` — 品牌
  - `categoryTree` — 类目树（用于 S3 提取类目关键词）
  - `packageLength` / `packageWidth` / `packageHeight` — 包装尺寸(mm)
  - `packageWeight` — 包装重量(g)
  - `asinUrl` — 亚马逊链接
  - `buyboxPrice` — 历史价格曲线（来自 1b，供 S4 取正常售卖价）

- **用途**：`imageUrl` 供 S2 做 1688 以图搜图；`categoryTree` 末段供 S3 查极目退货率；`price`/`fbaFees`/`referralFeePercentage`/包装尺寸供 S4 利润核算；`buyboxPrice` 曲线供 S4 取正常售卖价（非秒杀价）

- **落盘**：每批返回数据落盘到 `data/` 目录。

- **错误降级**：某个 ASIN 在 Keepa 中无数据时，该 ASIN 标注"Keepa 数据缺失"，跳过后续步骤。如果整批请求失败，重试 1 次后报错。1b 历史时序拉取失败时，S4 回退用 1a 的 `price` 字段并在 stderr 输出警告。
