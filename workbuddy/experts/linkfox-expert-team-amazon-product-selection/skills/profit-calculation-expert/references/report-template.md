# 报告模板

## 元信息块

- 生成时间（ISO 8601）
- 参数快照：ASIN列表 / 站点 / 汇率 / 头程 / TACoS / 退货率 / 仓储费率 / 弃置费 / 入库配置费
- 数据来源：Keepa / 1688 / 极目
- 局限性说明

## 章节定义

### 1. 核心指标 KPI 卡片
- ASIN 总数
- 最高净利润率
- 平均净利润率
- 负利润 ASIN 数

### 2. 净利润汇总表
- 按净利润降序
- 列：ASIN / 标题 / 类目 / 售价 / 1688成本 / FBA费 / 佣金 / 广告费 / 退货损失 / 仓储费 / 入库配置费 / 头程 / 净利润 / 净利润率

### 3. 成本拆解瀑布图（ECharts）
- 从售价开始，逐项扣减到净利润
- 颜色：扣减项红色，净利润绿色

### 4. 利润率对比柱状图（ECharts）
- X轴：ASIN，Y轴：净利润率
- 颜色：绿>20% / 黄10-20% / 红0-10% / 黑<0(亏损)

### 5. 1688货源匹配明细表
- 每个 ASIN 一个子表，3行供应商对比

### 6. 关键洞察与建议
- Insight List，priority-high / medium / low
