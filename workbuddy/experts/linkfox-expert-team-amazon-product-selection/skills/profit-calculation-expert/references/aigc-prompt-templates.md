# AIGC Prompt 模板

## 1. 三合一分析（Step 1 入参推导）

```
图 10 是目标 Amazon 商品（{目标ASIN标题}，售价${目标ASIN价格}）。

请完成三个任务：

任务1 — 视觉+标题综合相似度匹配：对全部 9 个候选（图1-9）逐一判断与目标商品（图10）的相似度。判断维度包括：图片外观形态（形状、结构、颜色）+ 标题关键词（产品类型、核心功能、规格参数、使用场景）。输出每个候选的「匹配/部分匹配/不匹配」+ 一句话理由。不只取 Top 3，而是全部判断。

任务2 — 价格区间：取所有「匹配」和「部分匹配」的 ASIN 的价格最低价和最高价（USD）。不限于 Top 3，匹配几个就取几个的价格。

任务3 — 1688 中文搜索词推荐：基于目标商品和所有匹配商品的标题关键词 + 图片特征，推荐 1 个最适合在 1688 搜索的中文关键词（1 个品类词 + 1 个最有区分度的特征词，≤ 20 字符）。不要太宽泛，也不要太长。

候选信息：
图1: ${候选1价格} | {候选1标题}
图2: ${候选2价格} | {候选2标题}
...
图9: ${候选9价格} | {候选9标题}

输出格式：
任务1：候选1: 匹配/部分匹配/不匹配 — 理由 ... 到候选9
任务2：$最低 ~ $最高
任务3：中文搜索词
```

**AIGC 参数**：`model: GEM_3_FLASH`，`thinkingLevel: low`，`imageUrls`: [9 张候选图 URL, 1 张目标 ASIN 主图 URL]

## 2. 货源验证（Step 3 AIGC 验证）

```
图 {N} 是目标 Amazon 商品（{目标ASIN标题}，售价${目标ASIN价格}，{核心卖点摘要}）。

请对比图 {N} 与图 1-{N-1} 的 {N-1} 个 1688 候选商品，判断每个候选是否与目标商品为同款或高度相似产品。

判断维度：
1. 产品类型是否一致
2. 核心功能/规格是否匹配
3. 外观是否相似

输出格式：
候选1: 匹配/部分匹配/不匹配 — 一句话理由
...到候选{N-1}

候选信息：
图1(B1,¥{价格}): {标题}
图2(B1,¥{价格}): {标题}
...
```

**AIGC 参数**：`model: GEM_3_FLASH`，`thinkingLevel: low`，`imageUrls`: [N-1 张 1688 候选图 URL, 1 张 Amazon 目标图 URL]

## 3. 标题预筛选规则（Step 3 第一步，Python 脚本）

预筛选条件（在 AIGC 验证前过滤明显不相关的）：
- B1 结果：标题必须包含品类词（如"化妆镜"、"便携显示器"），排除标题不含品类词的
- B2 结果：同样按品类词过滤
- 预筛后在报告中注明被过滤的商品数及原因

品类词来源：AIGC 三合一分析任务 3 推荐的搜索词中的品类部分。
