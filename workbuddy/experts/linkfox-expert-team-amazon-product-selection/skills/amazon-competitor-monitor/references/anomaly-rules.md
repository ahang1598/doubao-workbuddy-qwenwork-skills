# 竞品异常检测规则

## 1. 评分数 / 评分异常
- **激增**：评分数增长 ≥ 30% 或绝对增加 ≥ 500 条（疑似 Vine / 集中补评）
- **骤降**：评分数下降 ≥ 30% 或绝对减少 ≥ 300 条（疑似 Amazon 评论清理 / 变体合并）
- **评分变化**：评分下降 ≥ 0.2 分 且伴随评分数异常
- 行动建议：立即核查 Listing 评论来源与变体结构；观察后续转化率

## 2. 价格 / 促销异常
- 价格变动 ≥ 5%（上涨或下降）
- 出现或取消 Limited time deal / Lightning Deal / Coupon
- 价格下降同时启动 Deal → 可能主动抢排名
- 价格上涨同时取消折扣 → 观察销量是否逆势增长
- 行动建议：评估是否跟价；记录 Deal 起止时间

## 3. 销量异常
- 月销量下降 ≥ 50% 或归零
- 月销量翻倍及以上（逆势增长）
- 关键前提：BSR 仍存在且非断货状态（排除数据源延迟）
- 行动建议：核实库存与 Listing 状态；分析是否广告驱动

## 4. BSR 异常
- 大类 BSR 恶化（数值上升）≥ 20%
- 小类 BSR 恶化 ≥ 20% 或提升 ≥ 20%
- 小类排名从 Top 20 跌出或进入
- 行动建议：结合价格与广告位变化综合判断

## 5. Listing 内容变更
- 主图 URL 或风格明显变化
- 标题关键词大幅调整（长度变化 >20% 或核心词替换）
- 五点描述新增 / 删除 / 重写
- A+ 内容上线或重大更新
- 行动建议：记录变更前后对比，评估对转化的影响

## 6. 关键词流量异常
- 核心流量词自然排名下滑 ≥ 10 位
- 新增高流量广告位（SP 排名突然进入前 3 页）
- 流量占比 Top 关键词结构发生显著变化
- 行动建议：检查自身广告与自然排名联动

## 7. 综合高优先级异常
同时满足以下任意两条即标记为「高优先级」：
- 评分数异常 + 价格变动
- 销量归零 + BSR 仍在
- 价格降幅 ≥ 10% + 启动 Deal
- Listing 主图变更 + 评分数激增

## 误报过滤
- 数据源延迟（Keepa / 前台不同步）时，优先以 Keepa series 为准
- 明确标注「非断货」再判断销量归零
- 变体合并导致的评论数骤降需人工二次确认
