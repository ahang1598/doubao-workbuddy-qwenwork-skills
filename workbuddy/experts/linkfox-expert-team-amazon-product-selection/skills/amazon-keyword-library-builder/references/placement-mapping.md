# Keyword Placement Mapping Rules

## Organic Listing

### Title
- Lead with Brand (if registered) + 核心产品词
- Add 1–2 highest-priority 属性词 or 功能卖点词
- Keep readable; avoid pure keyword stuffing
- Character limits vary by category (often 200, sometimes tighter)

### Bullet Points (五点描述)
- One main idea per bullet
- Weave in 功能卖点词, 场景词, 人群词, secondary 属性词
- Front-load the most important benefit keywords

### Product Description & A+ Content
- Longer form 场景 + storytelling
- Additional long-tail combinations
- Comparison and objection-handling language

### Backend Search Terms (generic_keywords)
- Maximum ~249 bytes (Amazon counts bytes, not characters)
- Space-separated, no commas needed
- No brand names (own or competitor)
- No ASINs
- No words already used in Title / Bullets / Description (waste of bytes)
- Ideal content: spelling variants, synonyms, lower-priority long-tail, plural/singular forms not already covered
- Do not repeat any word

## PPC Structure Suggestions

### Exact Match Campaigns
- P1 高相关 + 高/中流量 converters
- Own brand terms
- Proven search terms from Search Term Reports

### Phrase Match
- P2 terms and good mid-length combinations
- Controlled discovery

### Broad Match / Auto
- Lower priority discovery
- Harvest new search terms → move winners to Exact

### Negative Keywords
- All 低相关 terms that generate clicks but no sales
- Common waste words (free, cheap, used, etc.)
- Irrelevant competitor or category terms

## Keyword Matrix Thinking (Chinese-seller style)

Many experienced sellers build a matrix:

Rows = 词性 groups (核心 / 属性 / 场景 / 功能 …)
Columns = Volume or Match type

This makes it easy to:
- Allocate Title real estate
- Create themed ad groups
- Track performance by nature of keyword
