# BAF / FABE 文案框架详解

> **何时读取本文件：** Phase C.3 五点描述生成时必读，Phase C.4 产品描述生成时参考。本文件提供完整的 FABE + BAF 倒叙法则，确保每条五点都能精准击中买家痛点并提升转化率。

---

## 一、框架概览：FABE vs BAF

### FABE（原始学术框架）

```
Feature（属性特征）→ Advantage（产品优势）→ Benefit（客户收益）→ Evidence（佐证数据）
```

### BAF 倒叙法（亚马逊五点实战优化版）

```
Benefit（收益）→ Advantage（优势）→ Feature（属性）
```

**为什么要倒叙？**
亚马逊买家扫描速度极快，首先看到的是五点的开头。以 **Benefit（收益）** 开头，直接回答买家"对我有什么用"，更能留住注意力。Feature 收尾提供可信的"技术背书"。

---

## 二、五点描述结构模板

### 标准格式

```
**[BENEFIT — 粗体，3-8 个单词]** [Advantage 说明为何能实现这个收益，1-2 句] [Feature 参数/认证/数据作为落地证据，1 句]
```

### 字符预算参考

⚠️ **重要更正：** 之前文献建议 ≤ 250 字符是为了**可读性**，但亚马逊实际允许每条最多 **≤ 1000 字符**。卖家应充分利用这个空间来嵌入关键词和详细信息，同时保持句子结构清晰。

| 区域 | 建议字符数 | 目的 |
|------|---------|------|
| **BENEFIT（粗体）** | 20-50 字符 | 标题式钩子，吸引扫描视线 |
| Advantage 说明 | 150-300 字符 | 详细解释优势机制，自然嵌入 2-3 个关键词 |
| Feature 证据 | 100-200 字符 | 增加可信度，包含具体规格/认证 |
| 使用场景补充（可选） | 100-200 字符 | 覆盖 Rufus 场景型意图（第 3-5 条优先） |
| **单条总计** | **200-600 字符** | **充分利用空间，但保持逻辑清晰** |
| **5 条合计** | **约 1500-3000 字符** | 完整覆盖多个维度和关键词埋词 |

**为什么增加字符上限：**
1. 关键词埋词需要空间（单靠 250 字/条无法覆盖足够的长尾词）
2. Rufus 算法重视"完整性"，场景描述越详细，匹配度越高
3. 移动端虽然折叠显示，但完整内容仍被索引

## 三、五条五点的差异化策略

每条五点必须覆盖**不同维度**，不得重复同一卖点。推荐覆盖以下 5 个维度：

| 条目 | 维度 | 核心问题 |
|------|------|---------|
| 第 1 条 | 核心功能 / 主卖点 | "这个产品最强的一点是什么？" |
| 第 2 条 | 材质 / 工艺 / 安全 | "是用什么做的？安全吗？" |
| 第 3 条 | 适用场景 / 人群 | "谁在什么情况下用？" |
| 第 4 条 | 易用性 / 安装 / 维护 | "好不好上手？好不好打理？" |
| 第 5 条 | 规格 / 套装内容 / 售后 | "买到手是什么？有什么保障？" |

### 移动端展示规则（重要，影响优先级）

⚠️ **2024-2025 年数据显示，超 60% 的浏览来自手机 App**

**移动端折叠规则：**
- 手机 App 默认**仅显示前 2-3 条**五点（需点击"See More"才展开全部）
- 桌面端显示全部 5 条

**实操建议：**
1. **前 2 条必须包含的信息：**
   - 第 1 条：**核心功能**（最重要的卖点）+ 最高搜索量关键词
   - 第 2 条：**关键属性**（材质/认证/安全）+ 次级高频词

2. **这两条是"首屏卖点"**，直接影响转化率，不能浪费在附属信息

3. **第 3-5 条在移动端**需点击才见，因此可用于：
   - 补充场景词、长尾词、轮转内容
   - 但仍需满足"不同维度"要求（不能重复核心卖点）

## 四、各维度写法示例库

### 4.1 核心功能维度

**模板：**
```
**[解决的核心痛点]** — [产品怎么解决] because [核心特性/设计], [量化收益/对比数据]
```

**示例（防水蓝牙音箱）：**
```
**Music That Goes Anywhere You Do** — IPX7 waterproof rating means full submersion up to 1 meter
for 30 minutes, letting you take calls in the shower or blast playlists at the pool without worry
```

### 4.2 材质 / 安全维度

**模板：**
```
**[安全/品质承诺]** — Made from [材质描述], [为什么安全/环保], tested/certified to [认证或标准]
```

**示例（儿童水杯）：**
```
**Safe for Every Sip, Every Day** — Crafted from food-grade 18/8 stainless steel with zero BPA,
phthalates, or lead — independently lab-tested and certified to meet US FDA standards
```

### 4.3 场景 / 人群维度

**模板：**
```
**[场景描述式收益]** — Whether you're [场景A] or [场景B], [产品如何适配两种需求]
```

**示例（折叠椅）：**
```
**Perfect for Any Outdoor Occasion** — Whether you're setting up at a tailgate, camping trip, or
backyard barbecue, the lightweight 4.2 lb frame folds flat in seconds and fits in most car trunks
```

### 4.4 易用性维度

**模板：**
```
**[零摩擦承诺]** — [具体如何简单], [时间/步骤数量化], [适合的用户群]
```

**示例（组装家具）：**
```
**Assembly in Under 15 Minutes, No Tools Needed** — Pre-drilled holes and color-coded hardware
mean even first-time assemblers can follow the illustrated guide and build a stable shelf in one sitting
```

### 4.5 规格 / 套装 / 售后维度

**模板：**
```
**[完整交付承诺]** — Package includes [套装内容清单]; [尺寸/重量/兼容性]; backed by [保修/退换政策]
```

**示例（工具套装）：**
```
**Everything You Need, Backed by Our Guarantee** — Includes 12-piece set with storage case;
fits standard 1/4" drive sockets; backed by a 2-year manufacturer warranty and 30-day hassle-free returns
```

## 五、Evidence（佐证）类型速查

好的 Evidence 让 Benefit 可信，让竞品难以复制：

| Evidence 类型 | 示例 | 效果 |
|-------------|------|------|
| **数字量化** | "10,000+ uses tested" | 具体可信 |
| **认证背书** | "FDA approved / CE certified" | 权威可信 |
| **对比数据** | "30% lighter than standard models" | 竞争力可见 |
| **时间保证** | "2-year warranty" | 降低风险感 |
| **用户规模** | "Trusted by 500,000+ customers" | 社会证明 |
| **工艺说明** | "Double-stitched seams, reinforced at stress points" | 工艺可感知 |

> ⚠️ **禁止使用无数据支撑的极限词**："#1 Best"、"World's Best"、"Unbeatable"等 → 详见 `compliance-banned-words.md`

## 六、产品描述（Description）BAF 应用

产品描述不是五点的复制，而是**叙事性场景展开**：

### 推荐结构

```
1. 开场钩子（1-2句）：用买家视角的痛点或场景切入
2. 核心卖点展开（3-4句）：BAF 逻辑，比五点更详细地讲 1-2 个主要优势
3. 使用场景画面（2-3句）：具体描绘使用情境，让买家产生代入感
4. 规格/细节补充（1-2句）：五点中未提及的参数
5. 收尾（可选）：产品适用人群总结，或质量承诺（禁止 CTA 语言）
```

### 铺货卖家无品牌故事时的替代策略

| 替代内容 | 示例 |
|---------|------|
| 产品使用场景指引 | "Start your morning ritual with..." |
| 规格参数详述 | "Dimensions: 12" × 8" × 4"; Weight: 1.2 lbs; Capacity: 32 oz" |
| 适用人群扩展 | "Designed for home cooks, outdoor enthusiasts, and busy parents who..." |
| 材质工艺细节 | "The triple-layer insulation uses vacuum-sealed copper technology that..." |

## 七、常见错误 vs 正确示例对照

| ❌ 常见错误 | ✅ 正确示范 |
|-----------|-----------|
| "Great quality yoga mat" | **Sweat-Proof Grip That Keeps Up With You** — Non-slip texture tested at 95° heat... |
| "Perfect for outdoor use" | **Rain or Shine, Your Gear Stays Protected** — IPX6-rated housing tested in... |
| Feature 先行："Made of 304 stainless steel, this mug..." | Benefit 先行："**Never Taste Yesterday's Coffee** — 18/8 stainless steel keeps..." |
| 五条五点都讲"高质量" | 每条覆盖不同维度：功能/材质/场景/易用/套装 |
| 产品描述 = 五点复制 | 产品描述展开场景叙事，补充五点未涉及的细节 |
