# Seedance 2.5 PE 模式路由与输出合同

## 当前对话模式

`peMode` 只在当前对话中保存，不声称跨会话记忆。

1. 用户明确要求「最佳版 / 单版 / 直接生成」时，设置 `peMode=single`。
2. 用户明确要求「A/B / 两版 / 稳健版和增强版 / 盲测」时，设置 `peMode=dual`。
3. 用户未表态且本对话尚未设置模式时，只询问一次：
   - 单一最佳版（推荐）：输出一份综合 Prompt。
   - A/B 对照版：输出同源的稳健基线版与优化增强版。
4. 用户后续明确切换时覆盖当前模式；否则不得重复询问。

## 单一最佳版合同

单一最佳版同时使用稳健基线的事实边界和优化策略的场景表达，按以下顺序交付：

1. 用户意图摘要。
2. 最终 Seedance 2.5 Prompt。
3. 素材职责与未采用素材。
4. Prompt 外的参数建议。
5. 如需执行，展示模型、路由、价格快照摘要与付费确认。

## A/B 对照版合同

按以下五段交付，不自动生成视频：

1. 用户意图摘要。
2. A：稳健基线 PE Prompt。
3. B：优化增强 PE Prompt。
4. 两版核心差异。
5. 建议选择。

两版必须共享任务类型、主体数量、事实台账、素材集合、素材职责和用户硬约束；不得用新增事实或故意弱化 A 版制造差异。

## 付费执行守卫

- 先定义 `generationUnit`：一条用户要求的独立成片或独立片段就是一个付费生成单元。单版模式限制的是每个已确认生成单元最多创建一个任务，不代表多条独立片段可以只按一次任务报价。
- 用户要求一条支持多镜头的成片，且实时模型支持目标总时长时，优先把多个镜头编译进一个生成单元；用户要求多条独立片段时，明确 `plannedTaskCount`、每条时长和总预估费用后再确认。
- 双版默认先让用户选择 A 或 B；选定版本只决定每个生成单元使用哪份 Prompt，不得静默把 A/B 变成双倍任务。
- 只有用户明确要求真实 A/B 双跑，并确认两次调用的总预估费用后，才可创建两个任务。
- 两个任务分别保留各自 `taskId`；不得自动双跑，不得因其中一个失败自动创建替代任务。
- 任何修改参数、模型、路由或 Prompt 后的再次生成，都属于新付费任务，必须重新获得用户确认。

## 参数与 Prompt 分离

画幅、总时长、分辨率、音频开关、输出格式和模型路由进入 `generate_video.params` 或调用摘要，不混入可提交 Prompt。用户给出的事件时间或节拍可以保留在 Prompt 中。
