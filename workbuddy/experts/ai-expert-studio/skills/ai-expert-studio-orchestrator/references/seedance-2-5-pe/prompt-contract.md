# Prompt Contract

## 双 PE 同源一致性规则

生成版本 A / 版本 B 前，必须先冻结以下信息，两版共用，不得冲突：

1. 用户核心意图；
2. 任务类型：Generate / Edit / Extend；
3. 主体数量与身份；
4. 素材列表与素材职责；
5. 必须保留的事实；
6. 禁止编造的信息；
7. 画面、动作、声音、风格相关硬约束；
8. 未采用素材列表。

任一冻结项在两版之间发生冲突，即为不合格输出，必须回到冻结阶段修正。

## A/B 差异合法来源

两版可以在以下维度产生差异：

1. 镜头组织；
2. 事件节奏；
3. 场景 knowhow；
4. 主体动作细节；
5. 商业表达方式；
6. 叙事张力；
7. 视觉风格组织；
8. 声音层次；
9. 素材调用策略；
10. 生成稳定性控制。

两版不得在以下维度产生差异：

1. 主体身份；
2. 主体数量；
3. 素材事实；
4. 商品参数；
5. 品牌授权；
6. 价格、奖项、数据；
7. 用户明确约束；
8. Edit / Extend 的母版关系。

## 可观察指令顺序

每个事件阶段按 `起始状态 → 一个主要动作/变化 → 直接可见终态 → 镜头关系 → 可听事件` 组织；先因后果。把内心状态改为可观察表演、对白、旁白或声音。两版都遵守此顺序，差异只体现在镜头、节奏与表现密度上。

## 时间纪律

- 不因为知道总时长就自动生成时间码；
- 用户给出的有效事件时间可保留；
- 只有卡点、对白对齐、关键事件边界或长片段确实含糊时才加时间；
- 使用连续、不重叠的整数秒范围，不用小数秒或帧号；
- 每个时间段必须有可观察变化，不允许空段；
- 总时长是 Prompt 外参数，除非用户独立提供节拍或事件时间。

## Prompt 质量要求

两版 Prompt 都应满足：

- 主体明确；
- 场景明确；
- 动作或事件明确；
- 镜头表达可执行；
- 声音要求不越界；
- 多素材职责清晰；
- 不包含分析过程；
- 不包含与生成无关的评测标签。

## 纯净度检查

可提交 Prompt 不得包含：分析、置信度、评估或修改理由；模型 ID、端点、API Key、参数表、比例、分辨率、帧率或输出格式；虚构别名或后端 ID；未受支持保证；未解决占位符；用户未要求的额外备选。
