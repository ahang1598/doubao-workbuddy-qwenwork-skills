# 优化增强 PE 生成策略（版本 B）

版本 B 的目标：在不突破用户事实和素材边界的前提下，生成更具视频表现力、场景专业度和生产可控性的 Seedance 2.5 中文 Prompt。本策略取自 sd25-pe-rc v1.6.0-rc.2 的三层可组合体系，把「核心场景 + 领域配置 + 修饰器」的专业 knowhow 下沉到单版增强中。

> 隔离声明：本文件只服务版本 B。版本 A 的稳健基线见 [stable-baseline.md](stable-baseline.md)，两者互不覆盖。版本 B 的一切增强都不得改变版本 A/B 共享的冻结事实与素材职责。

## 三层组合心智（B 版增强的来源结构）

版本 B 在内部按下式组织增强，但仍只输出一个 Prompt：

`一个核心场景 + 零或一个主领域配置 + 零或一个独立次级证明配置 + 零或一个视觉修饰器 + 零或一个受众/安全修饰器`

- **核心场景**负责主任务、因果、连续性与失败回退；
- **领域配置**只增加行业事实、素材职责、证明点和专项 QA，不重写主任务；
- **视觉修饰器**只改表面风格、运动可读性和视觉语言，不改事实、身份、产品几何、事件顺序或编辑范围；
- **受众/安全修饰器**可与一个视觉修饰器共存，危险模仿冲突时优先级更高。

组合前在内部建立「证明义务账本」：`义务 → 负责人 → 来源 → 不变量 → QA`。只有第二个配置拥有与主配置不同且不可省略的硬义务时才叠加；职责竞争时只保留主配置。

## B 版核心场景库（选一个主场景）

创意短视频、电商产品展示、剧情类短片、科普教育、品牌一键成片、人物一致短剧、视频局部精修（Edit）、视频延长续写（Extend）、爆款复刻、无缝转场拼接、分镜转视频、AI 视频改配音（Edit）、Vlog、风格迁移、舞蹈模仿。

**重叠场景优先级**（按「首要成功标准」选，不按表面动词）：只改声音 → 改配音；保留参考钩子/节拍/镜头关系/转场机制 → 爆款复刻；商品身份/几何/操作/卖点决定成败 → 电商产品；唯一变化是视觉风格 → 风格迁移；动作或编舞迁移决定成败 → 舞蹈模仿；其余单母版编辑 → 局部精修。任何延长进视频延长；双视频生成式桥接进无缝转场。

## B 版领域配置库（最多叠一个主配置）

汽车广告、效果/信息流广告、短漫剧、企业宣传、时装型录、影视解说、美食探店、知识口播、Logo 片头、音乐 MV、宠物、房产、旅行、UGC 评测、虚拟试穿、出海本地化、电商直播、影视前期/后期制作、游戏营销、工业制造、原创解说短剧。

**相邻赛道判别**（易混对，命中信号即选，不确定则澄清一次）：

- 原创剧情/无既有源片 → 原创解说短剧；二创既有影视/受版权约束 → 影视解说；
- 主体是游戏本身/买量投流 → 游戏营销；泛商品效果广告/非游戏 IP → 效果广告；
- 官方带货口播/使用指导 → 电商直播；素人第一人称种草测评 → UGC 评测；
- 核心是多语种/跨地区本地化 → 出海本地化；核心是效果转化且语言单一 → 效果广告；
- 前期概念/分镜预演或后期编辑 → 影视制作；对既有影视做解说回顾 → 影视解说。

`auto-ad` 只表示汽车广告，不表示「自动口播」。

## B 版修饰器库（视觉插槽 + 受众插槽）

视觉：动漫/二维动画风、游戏 CG/预告/过场风；受众/安全：儿童动画/亲子友好。动漫与游戏争用同一视觉插槽；儿童向可与其中一个共存。提到受保护作品/工作室/艺术家时，转换为可观察的构图、材质、色彩、运动和镜头属性，不承诺精确复制。

## B 版增强方向

1. 场景化 knowhow；
2. 镜头节奏设计；
3. 主体动作连续性；
4. 画面调度；
5. 声音层次；
6. 商业表达；
7. 叙事张力；
8. 情绪递进；
9. 多素材职责协同；
10. 生成风险控制。

## B 版不得通过以下方式获得优势

1. 编造素材中不存在的信息；
2. 添加用户未提供的品牌、价格、参数、奖项；
3. 改变主体身份或数量；
4. 改变任务类型；
5. 改变 Edit / Extend 母版关系；
6. 把版本 A 故意写差。

## 场景增强方法

### 短漫剧 / 剧情类

增强人物动机、冲突铺垫、情绪转折和结尾钩子；用触发事件分阶段推进情绪，但不新增未给定人物关系或身份。

### 商品广告 / 电商类

增强商品展示顺序、使用场景、质感细节和转化表达（开场吸引 → 拿取 → 使用 → 质感特写 → 收束），但不编造功能参数、价格、销量和权威背书。

### 人物口播 / 直播类

增强开场吸引力、镜头亲近感、手势节奏和声音层次，但不编造身份、资历和经历。

### 图生视频类

增强从静态图到动态视频的动作设计，保持人物外貌、服装、商品结构和主体数量稳定。

### 视频编辑类（Edit）

增强编辑目标与原视频的光影、透视、接触阴影和遮挡融合；明确修改范围与保持范围，避免污染非目标区域，给出范围闭环句。

### 视频延长类（Extend）

增强边界帧衔接、动作惯性、镜头延续和情绪/环境声延续；同一主体始终单一连续实例，不改原视频既有事实。

### 无缝转场 / 分镜转视频

增强转场机制的可读性、镜头关系交接与分镜读取顺序，不新增分镜外的剧情或主体。

## 专业镜头与声音增量

- 镜头写成 `技术 + 目标主体 + 起始关系 + 方向/速度 + 结束关系`，维持屏幕方向与空间锚点；
- 热门运镜（一镜到底、希区柯克变焦、航拍、FPV、子弹时间、手持、回弹变速）可直接写，小众术语展开为可观察结果；
- 声音按官方语义记号：音乐 `()`、音效 `<>`、对白 `{}`、字幕 `【】`；台词只来自用户对白账本，用户没给语言/口音就不补。

## B 版写法

版本 B 应像「专业导演 + 场景 PE」的产物，而非同义改写。评测人应能明确感知差异来自镜头、节奏、场景 knowhow、素材调度或声音层次等合法维度，而不是来自新增的事实或身份。
