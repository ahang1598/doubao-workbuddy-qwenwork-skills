# QA Fallback

## `peMode=dual` 双版输出前自检

输出前必须逐项检查：

1. A/B 是否使用同一任务类型；
2. A/B 是否使用同一素材集合；
3. A/B 是否遵守同一事实边界；
4. A/B 是否都没有编造不可见、不可听、用户未提供的信息；
5. 版本 A 是否足够稳健，而非故意写弱；
6. 版本 B 是否真正有场景增强，而非同义改写；
7. 版本 B 增强是否来自合法差异维度；
8. 未采用素材是否逐个列出；
9. 是否避免把接口参数写入任一版 Prompt；
10. 是否没有声称视频已经生成；
11. 两版是否各自独立成篇、不互相引用。

任一项不满足，先修正再输出。

## 何时澄清

只有当以下缺口会影响输出正确性时才澄清，且一次只合并问一个问题：

- 无法判断任务类型；
- Edit 或 Extend 缺少母版视频；
- Extend 无法判断前延长或后延长；
- 多素材职责互相冲突；
- 主体身份或数量不可判定；
- 用户要求涉及高风险事实但没有依据。

Prompt-only / 对照请求不得强制确认；用户说「你决定」时采用保守选择并继续。

## 何时纠偏

当用户要求以下内容时，先纠偏再输出：

- 要求保证成片一定成功；
- 要求编造品牌、价格、参数、奖项、授权；
- 要求从素材中读取不可见或不可听信息；
- 要求改变 Edit / Extend 的母版事实；
- 要求把接口参数写成 Prompt 内容；
- 要求执行自升级、联网或调用生成接口。

## 失败行为

只阻断不受支持或无法核实的部分，继续完成其余有效目标；两版同步处理，不得一版规避、一版照写：

- 非核心素材不可访问：两版同时省略，并按需在 Prompt 外披露；
- 唯一编辑母版或延长源不可访问：停止并索取访问；
- 素材超限：两版按同一优先级选最小充分集；
- 动作过载：两版都简化阶段、拆段或回退到镜头计划；
- 素材职责冲突：两版都强化同一映射；仍影响身份时只问一次；
- 真人或权利状态未知：在合法且技术可支持范围内编译创意，同时在 Prompt 外标记提交前门槛，不伪造准入。
