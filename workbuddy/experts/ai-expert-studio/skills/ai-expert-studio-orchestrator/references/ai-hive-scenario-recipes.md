# AI-HIVE 场景配方（按需组合 SOP）

这些配方定义任务数量、角色边界和付费确认，不替代运行时模型目录。Planner 负责需求、事实、素材职责和 Prompt；Model Scout 只从 `list_models` 选择实时模型、路由、参数和价格；Executor 只执行已确认方案。

## 通用执行合同

1. 先定义 `generationUnit`：一条独立成片、独立片段、独立图片或一次文本交付是一个生成单元。
2. Planner 交接 `generationUnits`、`plannedTaskCount`、每单元产出数与时长、素材职责和 Prompt；不得指定具体模型。
3. Model Scout 为每类单元提供实时可用模型、路由、受支持参数和价格快照，不修改 Prompt。
4. Lead 在执行前展示调用次数、预期产出数、逐项价格依据与总预估费用，并取得用户确认。
5. Executor 不扩大 `batchSize`、任务数量或 A/B 数量；任何重试、换模型、换路由、改 Prompt 或改参数都是新付费任务，必须重新报价并取得用户确认。
6. QA 只验证工具状态、结果 URL、数量和元数据。没有媒体预览或查看能力时不得判断画面、声音、文字渲染或品牌一致性，必须标记“待用户视觉验收”。

## 1. 电商主图四张

**目标**：用户提供一张产品图，要求四张不同构图的主图。

两种方案只能选一种：

- 同一 Prompt 可覆盖四张变化且实时模型支持批量时：1 次 `generate_image`，`batchSize=4`。
- 四张需要不同 Prompt 时：4 次 `generate_image`，每次 `batchSize=1`。

不得采用“四次调用且每次批量四张”的十六张方案。Prompt 只描述产品、背景、构图、光线、保持项和禁止内容；分辨率、比例、格式等只放入所选模型实时支持的 `params`。QA 没有预览能力时不判断白底、居中或清晰度。

## 2. 单张横版详情图

Planner 交付一张图片的构图、产品事实和文案保持项。Model Scout 从实时 IMAGE 目录选择模型，并按该模型 `imageConfig` 给出支持的比例、分辨率和输出格式。Lead 按一次调用报价并获得确认，Executor 创建一个任务。

## 3. 带参考图的竖版海报

1. Planner 将产品图定义为主体参考，冻结用户提供的标题、卖点和品牌事实；不承诺模型一定正确渲染文字。
2. Model Scout 选择实时可用且适合文字或海报的 IMAGE 模型，不使用预设模型名。
3. Executor 经授权上传参考图，将返回 ID 放入 `imageMediaIds`；调用次数和 `batchSize` 必须等于已确认方案。
4. QA 只在具备媒体查看能力时判断构图与文字；否则交由用户视觉验收。

## 4. 五到十秒产品视频

Planner 产出一个连续场景的镜头、主体动作、环境运动、声音职责和保持项。若用户提供产品图，上传后按职责放入 `imageMediaIds`，首帧需求才使用 `firstFrameMediaId`。总时长、比例、分辨率、帧率、音频开关和输出格式均放入运行时支持的 `params`，不写进 Prompt。

若需先生成首帧，再生成视频，这是两个付费生成单元；Lead 必须展示两次调用的总预估费用并取得用户确认。没有必要时不得自动增加首帧生图任务。

## 5. 三十秒多镜头成片或三条片段

先区分交付物，不能把三条五秒片段描述成三十秒成片：

- 用户要一条三十秒、多镜头成片，且实时模型支持目标时长：Planner 在同一 Prompt 内编排三个连续镜头，作为一个 `generationUnit` 和一个视频任务。
- 用户要三条独立片段：Planner 分别给出三条时长；若总交付要求三十秒，可采用 10 秒 + 10 秒 + 10 秒，作为三个 `generationUnit` 和三个视频任务。

`peMode=single|dual` 只控制每个生成单元采用单版 Prompt 还是候选 A/B，不改变已确认任务数量。双版默认等待用户选择 A 或 B；只有用户明确要求真实双跑并确认双倍调用的总预估费用时才执行两版。

## 6. 对话与文案

Planner 交付目标受众、事实、语气、长度和输出格式。Model Scout 只从实时 TEXT 目录选择模型和路由，不硬编码模型名。`chat_text` 是同步付费调用，不使用生成任务轮询；Lead 仍需在调用前展示价格依据并取得用户确认。

## 7. 图文混合任务

分别计算文本和图片生成单元。例如“一篇文案 + 五张不同 Prompt 图片”通常是一次 `chat_text` 加五次 `generate_image(batchSize=1)`；若五张共用一个 Prompt 且模型支持批量，也可是一次数量为五的图片调用。Lead 必须展示每类调用数量、总预期产出和总预估费用，不能把“调用次数”和“产出张数”混为一谈。

## 8. 音频参考视频

音频只接受 MP3/WAV，单文件不超过 15 MiB；上传后确认 `mediaType=AUDIO`。运行时 `generate_video` schema 必须包含 `audioMediaIds`，否则停止音频执行并提示更新 Connector。Seedance 2.0 的参考音频不能作为唯一参考输入，必须搭配所选模型支持的一份图片或视频参考。

## 9. 失败与降级

| 情况 | 处理 |
|---|---|
| 单任务失败 | 展示 `failure.code`、`failure.summary`、`failure.suggestion`，保留原 `taskId`；新方案不得自动执行。 |
| 余额不足 | 停止执行并提示用户处理余额。 |
| 模型不支持参数或素材组合 | 刷新 `list_models`，由 Planner/Scout 各自修正职责范围，再重新报价确认。 |
| 任务仍在处理 | 只查询原 `taskId`，不得创建替代任务。 |
| 视觉效果待判断 | 有查看能力才做视觉 QA；否则标记“待用户视觉验收”。 |
