# 跨境并购交易文件起草

> 本文件遵循 base/governance/ssot-compiler.md §17（SSOT）：六模块强制结构

## 模块一：法律合规与风险声明

**免责声明**：本技能为 AI 辅助工具，产出内容不构成正式法律意见，仅为律师团队起草交易文件提供条款框架与谈判参考。使用者应结合具体交易背景进行独立判断，所有输出条款均须标注"须律师审核"后方可纳入正式协议。

**适用法域**：中华人民共和国（大陆地区）+ 香港/开曼/BVI 等离岸控股架构法域（离岸法域条款标注"[需离岸法域律师核实]"）+ 美国（涉美并购标注"[需美国律师核实]"）。SPA/SHA 涉及多法域时，各法域条款分别标注适用法律。

**风险等级**：L3（见 `meta/manifest.json`）

---

## 模块二：快速开始

**一句话定位**：根据交易类型和谈判立场生成SPA/SHA核心条款框架，含陈述保证、赔偿、交割条件、过渡期承诺、终止条款，每条标注谈判敏感性和替代方案。

**最小示例**：

```
用户输入：交易类型=股权收购，买方=深圳上市公司，卖方=BVI控股公司，交易金额=5000万美元，谈判立场=买方，目标法域=中国内地+BVI，特别关注=知识产权权属风险
预期输出：SPA核心条款框架（12章结构）+ 陈述保证条款包（卖方对知识产权的陈述+买方补充要求）+ 赔偿条款（买方保护版）+ 交割条件清单 + 谈判敏感性标注（高/中/低）+ 替代方案建议 + L3风险提示"须律师审核"
```

## 模块三：核心参数与法律约束

| 参数 | 类型 | 法律含义 | 必填 |
|------|------|---------|------|
| transaction_type | enum | 交易类型决定文件路由（SPA vs SHA）及条款侧重 | 是 |
| buyer_info | text | 买方信息（名称/注册地/上市状态影响审批与披露条款） | 是 |
| seller_info | text | 卖方信息（名称/注册地/持股架构影响陈述保证范围） | 是 |
| transaction_amount | text | 交易金额（影响定价条款结构、赔偿上限计算） | 是 |
| negotiation_stance | enum | 谈判立场决定条款保护倾向（买方保护 vs 卖方保护 vs 中性平衡） | 是 |
| target_jurisdiction | enum | 目标法域决定适用法律和条款合规要求 | 是 |
| closing_conditions | text | 交割条件清单（用户自定义先决条件） | 否 |
| key_risk_areas | text | 特别关注的风险领域（增强对应条款深度） | 否 |
| deal_structure | text | 交易结构细节（支付方式/对价调整/托管安排） | 否 |

**核心法律依据**：见 `references/legal-references.md`

**工作流概览**：

| Phase | 任务 | 风险 |
|-------|------|------|
| **Phase 1** | 输入验证+文件类型路由（SPA/SHA） | L1 |
| **Phase 2** | 核心条款框架生成（12章SPA/10章SHA） | L3 |
| **Phase 3** | 关键条款深度填充（陈述保证/赔偿/交割/终止） | L3 |
| **Phase 4** | 谈判标注+替代方案+风险提示 | L2 |
| **Phase 5** | 交叉校验+降级检查+须律师审核标注 | L3 |

## 模块四：输出格式与质量标准

**输出格式**：DOCX（C-Professional，主格式，正式申报/签发用）+ Markdown（辅格式，内部参考）

**质量检查项**：
- Q1：条款编号体系完整性（SPA 12章/SHA 10章全覆盖）
- Q2：谈判敏感性标注一致性（每条核心条款标注高/中/低）
- Q3：陈述保证/赔偿/终止条款含替代方案（关键条款≥2个替代方案）
- Q4：买方/卖方视角条款倾向与 negotiation_stance 参数匹配
- Q5：L3风险标注——所有输出均标注"须律师审核"
- Q6：离岸法域条款标注"[需离岸法域律师核实]"
- Q7：降级时仅输出条款骨架，禁止生成确定性法律建议条款

> 完整字段定义见 `references/input-spec.md` + `references/output-spec.md`

## 模块五：常见问题

**Q1**：能否直接用于签署正式交易文件？——不能。本技能产出为条款框架与谈判参考，所有条款均标注"须律师审核"。SPA/SHA起草错误可能导致数千万美元交易风险，正式协议须经执业律师独立审核签发。

**Q2**：买方视角和卖方视角有何区别？——买方视角条款倾向买方保护：陈述保证范围扩大、赔偿条款强化卖方责任、交割条件增加、终止权扩大；卖方视角条款倾向卖方保护：陈述保证范围缩小、赔偿上限设封顶、交割条件简化、终止权限制。中性平衡版兼顾双方利益。

**Q3**：离岸架构（BVI/开曼）条款如何处理？——涉及离岸法域的条款（如离岸公司设立/股权转让/董事责任）标注"[需离岸法域律师核实]"，本技能提供中国大陆法域条款框架和离岸法域条款参考结构，但不对离岸法域法律做确定性引用。
