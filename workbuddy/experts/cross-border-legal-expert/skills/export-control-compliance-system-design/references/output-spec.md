> 版本：2.0.0 | 配套技能：export-control-compliance-system-gen

## 1. 输出格式

**主格式**：DOCX（制度文件——合规手册/SOP/违规流程）+ XLSX（表格文件——表格模板/角色矩阵）

**输出形态**：多文件体系——每类文件独立输出，打包为文件夹交付

> ⚠️ v2.0.0 breaking change：从"单HTML/Markdown文件"重构为"多文件DOCX+XLSX体系"。制度文件天然是DOCX格式（正式制度文件行业标准），表格模板天然是XLSX格式（可填写可计算）。详见 `development/CHANGELOG.md`。

## 2. 各输出块详细规格

### O1 合规手册（DOCX）

**文件**：`{企业名称}-出口管制合规手册.docx`

**行数范围**：500-1500行（视企业规模和产品线复杂度）

**DOCX结构**：

| 部分 | 内容 |
|------|------|
| 封面 | 企业名称+文件标题+版本号+发布日期+"内部底稿，不构成正式法律意见"水印 |
| 目录 | 13章自动目录 |
| 正文 | 13章制度正文（见下表） |
| 页眉 | 文件标题+版本号 |
| 页脚 | 页码+"内部底稿"标注 |

**必须覆盖的12大核心要素**：

| # | 要素 | 对应章节 | 来源 |
|---|------|---------|------|
| E1 | 合规政策声明 | 第一章 | BIS合规指南+行业实践 |
| E2 | 组织架构与职责 | 第三章 | 15 CFR §744.6合规要求 |
| E3 | ECCN分类流程 | 第四章 | 引用#46技能方法论 |
| E4 | 许可证申请流程 | 第五章 | 15 CFR §748 |
| E5 | 红色标志识别 | 第六章 | 15 CFR §732 Supp.3 + §744.21-6 |
| E6 | 交易筛选流程 | 第六章 | 引用#47技能方法论 |
| E7 | 培训计划 | 第八章 | BIS合规指引 |
| E8 | 审计计划 | 第九章 | BIS合规指引 |
| E9 | 违规报告机制 | 第十章 | 15 CFR §764 |
| **E2-R** | **风险评估（Risk Assessment）** | 第二章 | BIS EMCP核心要素——按产品线/出口目的地/最终用户维度评估出口管制风险等级和管控重点方向 |
| **E10** | **纠正措施（Corrective Actions）** | 第十章 | BIS EMCP核心要素——违规调查根本原因分析→流程变更→全员再培训→必要时提交自愿披露(VSD) |
| **E11** | **第三方合规与反腐败（Third-Party & Anti-Corruption）** | 第十三章 | FCPA/UK Bribery Act合规维度——代理商/中间人尽职调查+反腐败风险识别+第三方合规审查流程 |

### O2 SOP文件集（7套，每套独立DOCX）

**每套SOP统一结构**：

| 部分 | 内容 |
|------|------|
| 文件头 | SOP编号+名称+版本号+生效日期+"须结合企业实际情况调整"标注 |
| 正文 | 8段统一结构（见下） |
| 页脚 | 页码+SOP编号 |

**8段统一结构**：

```
1. 目的与适用范围
2. 法律依据
3. 职责分工
4. 操作步骤（4.1 步骤一 / 4.2 步骤二 / ...）
5. 关联表格模板
6. 异常处理与升级
7. 记录保存要求
8. 修订记录
```

**SOP-01 ECCN分类管理SOP**：
- 如用户提供了existing_eccn_results：引用#46技能的分类流程，本SOP聚焦分类的持续维护、更新、新产品分类触发机制
- 如未提供：生成完整的ECCN分类操作流程（基于#46技能方法论，标注"建议配合export-control-item-classification技能使用"）

**SOP-02 制裁清单筛查SOP**：
- 如用户提供了sanctions_screening_setup：引用#47技能的筛查方案，本SOP聚焦筛查频率、触发条件、筛查结果处理
- 如未提供：生成独立的筛查流程（基于#47技能方法论）

### O3 表格模板集（7份，每份独立XLSX）

**每份表格模板统一结构**：

| Sheet | 内容 |
|-------|------|
| Sheet 1：填写区 | 表头（名称+编号+版本+日期）+字段行（字段名称+填写说明+示例值）+签字区（填写人+复核人+日期） |
| Sheet 2：填写说明 | 各字段详细填写指引+示例+注意事项 |

**XLSX格式要求**：
- 表头行冻结（冻结首行+首列）
- 必填字段标注底色（浅黄）
- 字段宽度自适应
- 数据验证规则（如下拉选项、日期格式、数字范围）

### O4 角色与职责分配矩阵（XLSX）

**文件**：`{企业名称}-角色职责矩阵.xlsx`

**格式**：矩阵表格

| 岗位 | 合规手册职责 | SOP职责 | 签字权限 | 上报权限 |
|------|-------------|---------|---------|---------|

**岗位层级**（按企业规模调整）：
- 大型企业：首席合规官→合规经理→部门合规接口人→业务操作员
- 中型企业：合规官→关键部门接口人→业务操作员
- 小型企业：合规负责人（高管兼任）→业务操作员

### O5 违规上报与调查流程（DOCX）

**文件**：`{企业名称}-违规上报与调查流程.docx`

**必须包含**：
- 上报渠道（内部上报→合规官→高管层→外部律师→BIS自愿披露）
- 调查程序（初步评估→正式调查→事实确认→处置决定→记录保存）
- 处置措施分类（行政处理/业务调整/自愿披露/外部报告）
- 5天自愿披露规则（15 CFR §764.5）——初始通知5天内提交
- ⚠️ 2024年9月BIS Final Rule更新：BIS引入"fast-track"60天快速处理通道——BIS对轻微/技术性违规的**处理时限**为60天，并非将narrative account提交期限缩短。正式narrative account提交期限仍为180天
- BIS"fast-track"快速处理通道：轻微/技术性违规可在60天内获得BIS处理结果（no-action letter或警告信），但VSD narrative提交期限仍为180天

## 3. 写作红线

| ID | 红线 | 违反示例 |
|----|------|---------|
| WR-C01 | 合规手册封面必须标注"内部底稿，不构成正式法律意见" | 未标注免责声明 |
| WR-C02 | 每套SOP文件头必须标注"须结合企业实际情况调整" | SOP未标注调整提示 |
| WR-C03 | ECCN分类SOP如引用#46技能成果，必须标注引用来源 | 直接复制分类流程未标注来源 |
| WR-C04 | 制裁筛查SOP如引用#47技能成果，必须标注引用来源 | 同上 |
| WR-C05 | 许可证要求不得编造——不确定时标注"[需核实]" | 编造不存在许可证例外 |
| WR-C06 | Country Group映射须标注来源（15 CFR §738补1） | 未标注商业国家列表来源 |
| WR-C07 | 红色标志识别清单须覆盖15 CFR §732 Supplement No.3主要红旗场景（含2024年12月BIS新增AI相关红旗指标），≥18条 | 仅列出3-4条红旗场景 |
| WR-C08 | 角色职责矩阵不得遗漏任何SOP中提及的岗位 | SOP提到"合规官"但矩阵无此岗位 |
| WR-C09 | 违规上报流程须包含自愿披露选项（15 CFR §764.5） | 未提及BIS自愿披露机制 |
| WR-C10 | 不得对合规制度的有效性做出绝对保证 | "本制度确保完全合规" |
| WR-C11 | 每类文件必须独立输出为一个文件，不得合并为单一文件 | 将合规手册+SOP+表格揉进一个文件 |
| WR-C12 | 制度文件必须为DOCX格式，表格文件必须为XLSX格式 | 制度文件输出为HTML/Markdown |

**DOCX框架文件**（`{企业名称}-出口管制合规制度框架（降级模式）.docx`）：

|------|------|

## 5. 置信度标准

| 等级 | 标注 | 含义 |
|------|------|------|
| 高 | ✅已核实 | 法规引用已核实原文，管控要求明确 |
| 中 | 📋需核实 | 法规引用来自二手来源，或管控要求存在更新可能 |
| 低 | ⚠️存疑 | 无法确认法规要求，或该领域法规有重大修订动向 |

## 6. DOCX/XLSX生成规格

### 6.1 DOCX生成方式

**生成工具**：python-docx（或调用docx skill）

**DOCX排版规格**：

| 元素 | 规格 |
|------|------|
| 页面 | A4纵向，页边距上下2.54cm/左右3.18cm |
| 正文字体 | 宋体（中文）+ Times New Roman（英文），小四（12pt） |
| 标题字体 | 黑体（中文）+ Arial（英文） |
| 一级标题 | 二号（22pt），加粗，居中 |
| 二级标题 | 三号（16pt），加粗，左对齐 |
| 三级标题 | 四号（14pt），加粗，左对齐 |
| 行距 | 1.5倍行距 |
| 段前段后 | 0.5行 |
| 页眉 | 文件标题+版本号，小五（9pt），居中 |
| 页脚 | 页码+"内部底稿"标注，小五（9pt），居中 |
| 封面 | 企业名称+文件标题+版本号+发布日期+"内部底稿"水印 |

**合规手册特殊规格**：
- 封面后插入自动目录（TOC）
- 章节编号采用"第X章"格式
- 法条引用采用脚注格式

**SOP特殊规格**：
- 文件头表格（SOP编号/名称/版本/生效日期/调整标注）
- 步骤编号采用"4.1/4.2/..."格式

### 6.2 XLSX生成方式

**生成工具**：openpyxl（或调用xlsx skill）

**XLSX排版规格**：

| 元素 | 规格 |
|------|------|
| 工作表 | 每份表格含2个Sheet（填写区+填写说明） |
| 表头行 | 冻结首行+首列 |
| 表头样式 | 深蓝底色+白字+加粗+居中 |
| 字段行 | 白底+黑字+左对齐 |
| 必填字段 | 浅黄底色标注 |
| 列宽 | 自适应内容宽度（最小10字符/最大40字符） |
| 字体 | 微软雅黑（中文）+ Calibri（英文），11pt |
| 边框 | 全表细线边框 |
| 数据验证 | 下拉选项/日期格式/数字范围（按字段类型） |
| 签字区 | 底部合并单元格，含填写人/复核人/日期 |

**角色职责矩阵特殊规格**：
- 岗位列冻结
- 职责单元格支持换行
- 权限层级用颜色区分（高=红/中=黄/低=绿）

### 6.3 文件打包

**打包方式**：
- 输出文件夹：`{企业名称}-出口管制合规制度文件包/`
- 文件夹内含17个文件
- 可选：压缩为zip包 `{企业名称}-出口管制合规制度文件包.zip`

**文件命名规则**：
- 中文文件名（企业名称部分使用实际企业名称，如未提供则用"XX企业"）
- SOP/表格编号固定（SOP-01~SOP-07 / TM-01~TM-07）
- 版本号体现在DOCX封面和XLSX表头，不体现在文件名中
