# 默认要点清单

当用户未提供自定义要点清单时，可使用以下默认清单供用户选择。

---

## 基本信息抽取 — 默认要点清单

适用于通用民商事合同、工程合同、服务合同等。

```
合同名称：合同文本标题或封面注明的合同名称
合同编号：合同文本中标注的编号或合同号
甲方（发包方/需求方）：合同中甲方的完整名称
乙方（承包方/供应方）：合同中乙方的完整名称
合同签订日期：合同签署或盖章的日期
合同签订地点：合同签署或盖章时所在的地点
合同履行期限：合同规定的开始至结束时间段
合同总价（小写）：合同中以阿拉伯数字标注的总金额
合同总价（大写）：合同中以中文大写标注的总金额
税率：合同约定的增值税税率
付款方式：合同中关于付款节奏、比例、条件的约定
付款时间：合同中各付款节点的具体时间约定
交付时间：合同中约定的交付完成时间或期限
交付地点：合同中约定的交付物品或成果的地点
交付物品：合同中约定的交付标的物名称、规格及数量
质量标准：合同中对交付物或工程质量的要求
质保期：合同约定的质量保证期限
验收标准：合同约定的验收条件与方式
甲方单方解除情形：甲方有权单方解除合同的情形列举
乙方单方解除情形：乙方有权单方解除合同的情形列举
违约责任（甲方）：甲方违约时应承担的责任条款
违约责任（乙方）：乙方违约时应承担的责任条款
争议解决方式：合同约定的纠纷解决机制（仲裁/诉讼/协商等）
管辖法院：合同约定的诉讼管辖法院名称
适用法律：合同适用的法律管辖
合同附件：合同正文提及的附件列表
```

## 履约信息抽取 — 默认抽取字段

适用于工程施工合同、采购合同、服务合同等含履约节点的合同。

```
履约事件标准名称：对本次履约事件的标准化命名（如"预付款支付"、"竣工验收"）
履约类型：从枚举值选取 付款/收款/交付/质量保证/验收/其他
履约标的物：履约所涉及的具体工程部位、材料或服务内容
具体履约截止日期：明确的履约完成日期（YYYY-MM-DD格式，相对日期保持null）
履约金额：履约事件对应的金额（人民币元，阿拉伯数字）
责任自然人姓名：合同中明确指定负责该履约事件的自然人姓名
特别履约条件：完成该履约事件需满足的前提条件或特殊要求
对应的完整合同原文段落：该履约事件对应的原始合同条款全文
```

## 自定义要点说明

用户可按以下格式提交自定义要点，每行一个：

```
要点名称：要点释义（说明在合同中对应什么内容）
```

示例：
```
保密条款：合同中关于双方保密义务的约定
知识产权归属：合同中对于工作成果或产品知识产权归属的约定
不可抗力条款：合同中关于不可抗力事件认定及处理方式的约定
```

若用户只提供要点名称而无释义，按字面意思理解并提取。若存在歧义，主动向用户确认后再提取。
