## 1. Markdown 格式规范

适用：在线阅读、AI 工具内查看、复制粘贴。

| 要素 | 规范 |
|------|------|
| 标题层级 | 报告题 `#`；一级 `##`；二级 `###`；三级 `####` |
| 脚注语法 | GFM 标准：正文 `[^N]`，脚注区 `[^N]: 内容`（渲染器自动跳转） |
| 引用编号 | `[^1]…[^N]` 全文连续，不按章节重置 |
| 表格 | `|---|` 语法，列对齐 `:---:`/`:---`/`---:` |
| 强调 | 结论 `**粗体**`；术语首现 `*斜体*` 附英文 |
| 参考文献区 | 报告末尾 `## 参考文献（N条）`，有序列表每条含可点击 URL（单独成行）+ `Source` 出处标注，详见 §7 |
| 访问状态 | 行内纯文字标签 `[已验证]`、`[需注册]`、`[付费]`、`[反爬]`、`[未找到]`、`[未验证]` |

> Markdown 本身不带样式；导出/渲染为 HTML/Word 时统一套用 **Richee 设计系统**（§2/§3、`references/richee-design-system.md`）。

## 2. HTML 格式规范（Richee 设计系统）

适用：存档、分享、打印。**视觉风格统一遵循 Richee 设计系统**（黑白极简 + 浅灰底 + 单绿强调 +
无衬线 PingFang SC + 状态色仅用于标签）。完整规范、令牌、组件类、技能语义→组件映射、HTML 骨架见
**`references/richee-design-system.md`**；完整 CSS 见 **`assets/richee-report.css`**。

**生成步骤**：
1. 读 `assets/richee-report.css` 全文，**内联**进头部 style 标签（保证自包含、可离线/打印）。
   注意：内联的 CSS **不得含 style 闭合标签字面量**，否则会提前关闭 style 块、CSS 外泄为正文。
2. 按 `richee-design-system.md §3` 骨架搭页：`topbar → hero → content(免责声明 → 执行摘要结论卡/指标卡
   → 分章+脚注跳转 → 比较矩阵/时间轴) → footnotes → footer`。
   **长报告（路径 B/C，章节 ≥3）必须加左侧导航目录**：`.layout.with-nav` + `<aside class="nav">`，
   每个 `<section>` 给唯一 `id`、nav `<a href="#id">` 对应，可点击跳转（含 scrollspy 高亮，见骨架）。
   路径 A 快速概览（1-2 屏）用单栏 `.layout`、省略目录。
3. 按 `richee-design-system.md §2` 映射把技能语义元素落到组件类。

| 要素 | 规范（Richee） |
|------|------|
| 字体/字号 | `--font-sans`（PingFang SC/Inter 无衬线）；正文 14px、标题 clamp、脚注 12.5px |
| 容器/底色 | `.content` 白卡 + `--bg` 浅灰底；`max-width:1080px` 居中 |
| 确定性标签 | `.lbl .lbl-l1/l2/l3/l4`（L1 黑/L2 蓝/L3 灰/L4 琥珀），闭集禁自创 |
| 访问状态 | `.acc .acc-ok/reg/pay/bot/warn/none`（绿/琥珀/红/灰/琥珀/红） |
| 时效性 | `.fresh .fresh-critical/high/mid/low`（红/琥珀/黄/绿） |
| 风险等级 | `.tag .high/.mid/.low/.info` |
| 置信度 | `.confidence`（星级文字 + `.track/.fill` 进度条） |
| 结论/指标 | `.conclusion` 结论卡 + `.grid-4 .kpi` 指标卡组 |
| 脚注跳转 | 正文 `<sup><a class="ref-link" href="#fn-N" id="ref-N">`；脚注 `.fn-item` + `.back-ref ↩` |
| 打印 | `@media print` 去阴影/边框、链接转黑、卡片避免跨页（CSS 内置） |

> 正式 Markdown、HTML 和 Word 输出均禁止 emoji；颜色只能作为纯文字标签的辅助视觉编码。

## 3. Word (.docx) 格式规范

适用：正式交付、客户汇报、合规报告。**视觉语言对齐 Richee 设计系统**（无衬线、黑白灰为主 +
克制绿强调 + 状态色仅用于标签），详见 `references/richee-design-system.md §4`。
**调用 `docx` skill 生成**；不可用时输出 Markdown 并提示 `pandoc input.md -o output.docx`。

| 要素 | 规范（Richee 对齐） |
|------|------|
| 正文字体 | **PingFang SC 无衬线**（中，fallback 苹方→微软雅黑→Noto Sans CJK）/ Inter（英，fallback Calibri）12pt |
| 标题 | 题加粗 16pt；一级加粗 14pt；二级加粗 12pt；标题色 `#0a0d12`，可加细绿装饰线 |
| 行距/边距 | 1.5 倍；上下 2.54cm，左右 3.17cm |
| 脚注 | **Word 原生脚注**（非尾注），自动编号+书签双向跳转；10pt |
| 页眉/页脚 | 页眉：标题\|日期；页脚：页码居中（首页不显示）+"数据路径：LDH/仅预置源" |
| 首页声明 | 标题、法域、主题、日期、"仅供参考，不构成法律意见" |
| 整体风格 | **黑白灰为主 + 克制绿强调**（标题装饰线/正向结论 `#039855`）；状态色仅用于标签与风险单元格，不大面积铺底；表头黑底白字、白底正文、细灰线（#e2e5ea）；禁花哨边框/装饰 |
| **表格宽度** | 表格总宽不得超出 A4 内容区（页宽 21cm − 左右边距 3.17cm×2 ≈ 14.6cm）；比较矩阵≤5 列；超宽时拆分或转纵向列表，禁止撑满整页越界 |

### D3-S2：所有正式输出禁用 emoji

正式报告需要跨平台稳定渲染和便于无障碍阅读。生成任何正式输出时，状态/标记一律使用方括号
文字标签：

| 文字标签 | 含义 |
|---|---|
| `[3–6月复核]` | 极高时效风险 |
| `[6–12月复核]` | 高时效风险 |
| `[1–3年复核]` | 中时效风险 |
| `[稳定]` | 相对稳定 |
| `[已验证]` | URL 可访问且锚点已核验 |
| `[需注册]` | 需免费注册 |
| `[付费]` | 需订阅 |
| `[反爬]` | 自动化被拦但浏览器可访问 |
| `[未找到]` | 资源不覆盖 |
| `[未验证]` | 警告或未完成核验 |
| `置信度 N%` | 使用数值而不是星级 |
| 纯文字小标题 | 不使用装饰图标 |

> 上表仅供转换历史模板；新输出直接生成右栏的纯文字标签，不先生成 emoji。

## 6. FAQ

**Q1 能替代律师吗？** 不能。本技能是研究助手，帮你定位筛选资源、整理信息；正式法律意见须聘执业律师。
**Q2 资源都免费吗？** Tier1-2 多数免费（Chambers/Legal500 全免，ICLG 免费注册）；付费源仅在用户有权限时推荐。
**Q3 中文用户优势？** 检测中文时优先中文资源（商务部国别指南、法大大法律法规检索、法大大法律法规检索），保留英文源交叉验证。
**Q4 WebSearch/WebFetch 不可用？** 5 级降级：静态URL→Google模板→替代平台→区域库→手动指引（resources.md §8/§9）。
**Q5 支持哪些语言？** 中英双语交互；资源覆盖英文(主)、中文(补)、本地语种工具。
**Q6 Word 可直接给客户？** 可作内部底稿；首页含免责声明，对外前请律师复核。
**Q7 为什么有些问题无法回答？** 核验引擎要求每条结论实时验证；找不到/打不开/付费墙/来源矛盾时明示"无法验证"+手动方向+建议律师类型——这是负责任的输出。
**Q8 脚注与普通引用区别？** 脚注是**核验证据记录**，6 必填字段(标签+来源+URL+验证时间+锚点+访问状态)，读者可沿脚注复现验证过程。

## 7. 参考文献格式规范（所有路径强制）

> 参考文献区是用户**核验报告结论**的唯一入口。每条参考文献必须让用户能
> 一眼看到来源出处、点击链接直达原文。本节定义 Markdown / HTML / Word 三类输出的统一规范。

### 7.1 总体要求

所有报告末尾必须包含 `## 参考文献（N条）` 章节（N = 实际引用来源数），每条参考文献按以下结构呈现：

```
[编号]. [确定性标签] [访问状态] 来源全称.
   Source: 出处数据库名称
   URL: 可点击URL
```

**字段说明**：

| 字段 | 必填 | 说明 |
|------|------|------|
| 编号 | 必填 | 全文连续编号（1. 2. ...），与正文 `[^N]` 对应 |
| 确定性标签 | 必填 | `[法规原文]` / `[权威指南]` / `[一般评论]` / `[待验证]` 四选一 |
| 访问状态 | 必填 | `[已验证]` / `[需注册]` / `[付费]` / `[反爬]` / `[未验证]` |
| 来源全称 | 必填 | 含文件标题、法规编号、版本/年份 |
| Source | 必填 | 出处数据库/平台名称（如 US/FederalRegister、CN/NPC、Chambers and Partners） |
| URL | 必填 | 完整可点击链接，**单独成行**，不与其它字段混排 |

### 7.2 Markdown 格式

```markdown
## 参考文献（3条，经实时来源核验）

1. **[法规原文]** `[已验证]` Department of Commerce, BIS.
```

### 7.3 HTML 格式（Richee 设计系统）

与信达生物报告格式一致，使用 `.footnotes` + `.fn-item` 结构：

```html
<section class="footnotes" id="sref">
  <h2>参考文献（23条，LDH实时核验 + 预置官方源交叉验证）</h2>

  <div class="fn-item" id="fn-1">
    <strong>[1]</strong>
    <span class="lbl lbl-l1">L1 法规原文</span>
    <span class="acc acc-ok">已验证</span>
    Department of Commerce, BIS.
    <em>Controls on Certain Laboratory Equipment...</em>, 90 FR 4612.
    <span class="src">Source: US/FederalRegister</span><br>
    URL: <a href="https://www.federalregister.gov/documents/2025/01/16/2025-00723"
          target="_blank" rel="noopener">https://www.federalregister.gov/documents/2025/01/16/2025-00723</a>
    <a href="#ref-1" class="back-ref">↩</a>
  </div>
</section>
```

**与信达生物报告的对应关系**：
- `.lbl` 确定性标签（l1=黑色/L2=蓝色/L3=灰色/L4=琥珀色）
- `.acc` 访问状态（ok=绿/warn=琥珀/...）
- `.src` Source 出处（灰色小字）
- `.back-ref` 返回正文的 `↩` 链接
- 正文用 `<sup><a href="#fn-N" id="ref-N" class="ref-link">[N]</a></sup>` 做双向跳转

### 7.4 Word (.docx) 格式

- 使用 Word 原生**尾注**（Endnote，非脚注），集中位于文档末尾
- 尾注文本按 7.1 字段结构排列，URL 字段**蓝色 + 下划线**，可点击
- 正文用 Word 原生脚注/尾注编号，自动双向跳转
- 确定性标签和访问状态转为方括号文字（遵循 §3 emoji→文字映射规则）

### 7.5 路径差异

| 路径 | 参考文献要求 |
|------|-------------|
| **A 快速概览** | 每条结论 ≥1 来源，参考文献精简为有序列表 + URL，省略 Source 字段（如来源明确） |
| **B 全面报告** | 所有 7 字段完整；路径 A 省略字段在此补齐 |
| **C 比较矩阵** | 按法域分小节（`### 新加坡` / `### 越南`），每法域独立编号；跨法域共用来源标注"参见编号 N" |

### 7.6 标题格式

参考文献区标题须包含来源统计和核验路径：

- **仅预置源**：`## 参考文献（N条，经实时来源核验）`
- **LDH + 预置源**：`## 参考文献（N条，LDH实时核验 + 预置官方源交叉验证）`
- **仅 LDH**：`## 参考文献（N条，LDH实时核验）`
