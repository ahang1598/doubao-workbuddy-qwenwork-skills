# 法律术语中英对照表 (Glossary)

> 本术语表用于确保输出报告中法律术语的一致性和准确性。首次出现术语时建议附英文对照。

## 核心概念

| 中文 | 英文 | 说明 |
|------|------|------|
| 法域 | Jurisdiction | 具有独立法律体系的国家或地区 |
| 管辖权 | Jurisdiction (另一含义) | 法院审理特定案件的权力范围 |
| 成文法 / 法典法 | Civil Law / Codified Law | 大陆法系，以成文法典为主要渊源 |
| 普通法 | Common Law / Case Law | 英美法系，以判例法为主要渊源 |
| 法规原文 | Primary Law / Statute | 立法机关制定的正式法律文本 |
| 权威指南 | Authoritative Guide | 由合格律师/机构撰写的二级来源 |
| 交叉验证 | Cross-Validation | 用多个独立来源核实同一信息 |
| 时效性 | Timeliness / Currency | 信息与当前法律状态的一致程度 |

## 公司与投资

| 中文 | 英文 | 说明 |
|------|------|------|
| 外商投资 | Foreign Direct Investment (FDI) | 非居民在该国设立或收购企业 |
| 外资比例限制 | Foreign Ownership Cap | 外资在某行业可持有的最大股权比例 |
| 投资登记证书 | Investment Registration Certificate (IRC) | 越南等国投资批准文件 |
| 企业注册证书 | Enterprise Registration Certificate (ERC) | 企业法人登记证明 |
| 尽职调查 | Due Diligence | 投资前的全面调查 |
| 并购 | Merger & Acquisition (M&A) | 收购或合并现有企业 |
| 控股公司 | Holding Company | 通过持股控制子公司的母公司 |
| 代表处 | Representative Office | 外国公司在东道国的非经营性分支机构 |
| 分支机构 | Branch Office | 外国公司的经营性分支机构 |
| 特殊目的载体 | Special Purpose Vehicle (SPV) | 为特定交易设立的实体 |

## 劳动与雇佣

| 中文 | 英文 | 说明 |
|------|------|------|
| 劳动合同 | Employment Contract | 雇佣双方的权利义务协议 |
| 试用期 | Probation Period | 新员工试用期限，各国上限不同 |
| 社会保险 | Social Insurance | 养老、医疗、失业等法定保险 |
| 解雇通知期 | Notice Period | 终止合同需提前通知的时限 |
| 遣散费 | Severance Payment | 合同终止时的经济补偿 |
| 工作签证 | Work Visa/Permit | 外国人合法工作的许可 |
| 居留许可 | Residence Permit | 在该国的合法居留资格 |
| 集体谈判 | Collective Bargaining | 工会代表工人与雇主的谈判 |

## 数据隐私

| 中文 | 英文 | 说明 |
|------|------|------|
| 数据保护法 | Data Protection Law | 规范个人信息处理的立法 |
| GDPR通用标准 | GDPR-Equivalent | 与欧盟GDPR类似的数据保护框架 |
| 数据保护官 | Data Protection Officer (DPO) | 负责数据合规的指定人员 |
| 数据处理者 | Data Processor | 受委托处理数据的第三方 |
| 数据控制者 | Data Controller | 决定数据处理目的和方式的主体 |
| 跨境数据传输 | Cross-Border Data Transfer | 个人数据跨国界流动 |
| 标准合同条款 | Standard Contractual Clauses (SCCs) | 欧盟批准的跨境传输机制之一 |
| 同意 | Consent | GDPR等法规的核心合法性基础之一 |

## 争议解决

| 中文 | 英文 | 说明 |
|------|------|------|
| 国际仲裁 | International Arbitration | 跨国商事争议的非诉讼解决方式 |
| 临时仲裁 | Ad Hoc Arbitration | 非机构管理的仲裁 |
| 机构仲裁 | Institutional Arbitration | 由仲裁机构（如SIAC, ICC）管理 |
| 仲裁裁决 | Arbitral Award | 仲裁庭作出的终局决定 |
| 执行与承认 | Recognition and Enforcement | 使裁决在法域外生效的程序 |
| 管辖权条款 | Jurisdiction Clause | 约定争议解决法院的合同条款 |
| 仲裁条款 | Arbitration Clause | 约定将争议提交仲裁的合同条款 |
| 伦敦国际仲裁院 | LCIA (London Court of Int'l Arbitration) | 主要国际仲裁机构之一 |
| 新加坡国际仲裁中心 | SIAC (Singapore Int'l Arb Centre) | 亚洲领先仲裁机构 |

## 知识产权

| 中文 | 英文 | 说明 |
|------|------|------|
| 商标 | Trademark | 区分商品/服务来源的标志 |
| 专利 | Patent | 技术发明的独占权 |
| 版权 | Copyright | 原创作品的表达保护 |
| 商业秘密 | Trade Secret | 未公开的商业信息保护 |
| 工业设计 | Industrial Design | 产品外观的保护 |
| 知识产权局 | Intellectual Property Office (IPO/IP Office) | 各国的IP注册管理机构 |
| 在先权 | Priority Right | 巴黎公约等的优先权制度 |
| 驳回 | Refusal / Rejection | IP申请被拒绝 |

## 合规与监管

| 中文 | 英文 | 说明 |
|------|------|------|
| 反垄断 | Antitrust / Competition | 防止市场垄断的法律制度 |
| 经营者集中 | Concentration of Undertakings | EU反垄断术语（=并购审查） |
| 反洗钱 | Anti-Money Laundering (AML) | 防止非法资金流动的合规要求 |
| 了解你的客户 | Know Your Customer (KYC) | 客户身份识别合规要求 |
| 制裁 | Sanctions | 国家对特定主体/国家的经济限制措施 |
| 出口管制 | Export Controls | 敏感物品/技术出口的限制 |
| ESG | Environmental, Social, Governance | 环境、社会和公司治理 |
| 实益所有人 | Beneficial Owner (UBO) | 最终控制实体的自然人 |

## 研究方法相关术语

| 中文 | 英文 | 说明 |
|------|------|------|
| 一级来源 | Primary Source | L1: 法规、判例、官方文书 |
| 二级来源 | Secondary Source | L2/L3: 评论、指南、分析文章 |
| 幻觉 | Hallucination | AI生成的不实信息 |
| 确定性膨胀 | Certainty Inflation | 将不确定性表述升级为确定性 |
| 薄覆盖法域 | Thin-Coverage Jurisdiction | 英语法律资源稀少的法域 |
| 实务注释 | Practice Note | 律所发布的实务操作指引 |
| 客户提示 | Client Alert | 律所就最新动态向客户发出的简报 |
