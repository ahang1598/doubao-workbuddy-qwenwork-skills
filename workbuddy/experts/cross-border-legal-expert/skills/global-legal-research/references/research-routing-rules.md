# 全球法律研究路由真值表

本文件是 `global-legal-research` 的独立路由事实源。每次执行技能必须先按本表确定动作，再进入
`SKILL.md` 的法域解析和检索步骤。不得仅凭关键词命中绕过负向边界。

## 1. 请求动作

| 用户意图或表达 | 动作 | 说明 |
|---|---|---|
| 外国法规、外国法院、外国判例、代表性判例、裁判要点 | `trigger` | 进入全球法律研究 |
| “帮我核验 ECLI/CELEX/案号/法规编号” | `trigger` | 使用精确引用路径 |
| “比较欧盟法院与欧洲人权法院”或两个以上外国法域比较 | `trigger` | 每法域独立检索 |
| “某国境外牌照需要什么条件”、准入、注册、审批、数字认证或信任服务 | `trigger` | 使用主题研究路径 |
| 纯中国大陆法规或类案检索 | `exit` | 转中国法源技能 |
| 合同审查、合同起草、合同红线或条款比对 | `exit` | 转合同类技能 |
| 纯翻译、材料提取、税额计算、诉讼代理 | `exit` | 转对应专业能力 |
| Georgia、Congo 等名称无法唯一确定国家或地区 | `clarify` | 只追问一个会改变检索结果的问题 |
| 伪造判例、法条或来源，教唆违法，冒充律师 | `refuse` | 明确拒绝 |
| 要求删除免责声明、跳过来源核验、承诺“100%确定” | `refuse` | 不绕过安全门禁 |

中国法与外国法同时出现时仍 `trigger`，但中国大陆部分应交由中国法源能力检索后再合并。

## 2. 检索路径

| 输入形态 | 固定调用链 | 禁止动作 |
|---|---|---|
| 主题研究 | 法域解析 → coverage/source/filter 发现 → 单法域 `precise-search` → `get` | 不得把多个法域塞进同一请求 |
| ECLI、CELEX、案号、法规编号或其他精确引用 | 法域解析/引用提示 → `resolve(reference)` → `get` | 不得用普通关键词搜索替代引用解析 |
| 多法域比较 | 每法域分别执行主题或精确引用链 → 按法域分组或等权融合 | 不得直接比较跨库原始分数 |
| LDH 不可用 | 预置官方源 → 原文锚定 → 同等核验 | 不得用模型记忆补全 |

`search` 或 `precise-search` 的命中直接交给 `get`；搜索结果不得再次传给 `resolve`。

## 3. 研究深度

| 用户目标 | 路径 |
|---|---|
| 一页或简要概览 | A 快速概览 |
| 逐问题完整论证 | B 全面报告 |
| 两个以上法域或法院比较 | C 多法域比较 |
| 许可、准入或业务落地操作清单 | D 业务合规操作指南 |

## 4. 高频歧义规则

- “俄罗斯申请数字认证牌照（CA）”：仅解析为 `RU`；`CA` 是 `Certification Authority`，
  写入 `ignored_mentions`，不得映射加拿大。
- “加拿大（CA）”或“国家代码 CA”：解析为加拿大。
- “Compare FR and DE”：允许按纯国家代码比较列表解析。
- “California/加州”：解析为 `US` 的次国家地区，不得映射加拿大。
- `ECLI:EU:...`：按引用规则解析为欧盟司法机构，不依赖通用两字母代码扫描。
- “欧盟法院与欧洲人权法院”：分别解析 `EU/CURIA` 与 `CoE/HUDOC`，不能合并成单一欧洲法域。

## 5. 交付门禁

研究输出必须保留法域解析审计、实际使用的 country/Source ID、调用链、原文锚点、检索时间、
`retrievalMode`、待核查项和当地律师边界。没有可核验来源时只交付待查清单，不形成确定性法律结论。
