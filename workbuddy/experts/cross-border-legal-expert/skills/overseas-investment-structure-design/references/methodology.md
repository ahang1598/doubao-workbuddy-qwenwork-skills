# 方法论 — overseas-investment-structure-design

## 1. 架构设计核心原理

### 1.1 多层控股架构的价值

```
价值来源：
1. 税负优化：利用双边税收协定降低预提税
2. 风险隔离：SPV隔离东道国政治/法律风险
3. 退出灵活：股权转让在SPV层完成，避免东道国资产过户
4. 资金调度：控股平台集中管理多国资金
5. 未来扩展：控股平台可承载多国子公司
```

### 1.2 架构层级设计原则

| 层级 | 功能 | 典型注册地 |
|------|------|-----------|
| L0 | 中国母公司（最终受益人） | 中国 |
| L1 | 中间控股SPV（资金通道+协定利用） | 香港/新加坡/BVI |
| L2 | 东道国运营实体（WFOE/JV/分支） | 目标国 |

**层数决策**：
- 直投（L0→L2）：适用小规模/无协定优化空间
- 单层SPV（L0→L1→L2）：适用大多数制造业出海
- 多层SPV（L0→L1→L1'→L2）：适用IPO规划/多区域控股

## 2. 控股地选择逻辑

### 2.1 评估框架（6维度）

| 维度 | 权重 | 评估要点 |
|------|------|---------|
| 税负优化 | 30% | 控股地所得税+协定预提税+参股豁免 |
| 协定网络 | 20% | 与东道国+中国的双边税收协定覆盖度 |
| 设立成本 | 15% | 注册费+初始合规 |
| 维护成本 | 15% | 年审+审计+董事 |
| 退出便利 | 10% | 资本利得税+股权转让限制 |
| 合规难度 | 10% | 经济实质法+CRS+反避税 |

### 2.2 控股地特征对比

| 控股地 | 税率 | 协定网络 | 经济实质 | 适用场景 |
|--------|------|---------|---------|---------|
| 香港 | 16.5%（境外免税） | 45+ | FSIE被动收入需满足实质 | 东南亚投资首选 |
| 新加坡 | 17%（境外免税） | 80+ | 区域激励可满足 | 全球多区域控股 |
| BVI | 0% | 少 | 纯持股简化合规 | 纯持股+退出 |
| 开曼 | 0% | 少 | 纯持股简化合规 | IPO架构 |

### 2.3 选择决策树

```
投资目的=manufacturing？
  → 是 → 目标国在东南亚？
    → 是 → 首选香港（中港+港越协定叠加最优）
    → 否 → 首选新加坡（协定网络更广）
  → 否 → 投资目的=regional_holding？
    → 是 → 首选新加坡（多国协调+区域中心）
    → 否 → 投资目的=holding且exit_plan=IPO？
      → 是 → 首选开曼（上市标准路径）
      → 否 → 首选BVI（零税+退出灵活）
```

## 3. 税负测算方法

### 3.1 综合有效税率模型

```
综合有效税率 = 1 - (1 - 东道国CIT) × (1 - 汇回预提税)

⚠ 重要：东道国预提税须优先查证东道国国内法实际征收税率。
税收协定税率仅为上限，若东道国国内法征收更低税率（或0%），则适用国内法。

示例1（香港→越南）：
  越南CIT = 20%
  越南→香港股息预提 = 5%（港越协定）⚠但越南国内法对外国法人股东征收0%！
  → 实际适用0%（国内法优于协定时，协定税率仅为上限，不能增加税负）
  → 经香港SPV：越南→香港股息预提实际为0%
  香港所得税 = 0%（境外免税）
  香港→中国股息预提 = 5%（中港安排）
  
  利润100 → 越南税后80 → 香港收到80（80×1.00，越南国内法0%预提）→ 中国收到76（80×0.95）
  综合有效税率 = 1 - 76/100 = 24%

示例2（直投中国→越南）：
  越南CIT = 20%
  越南→中国股息预提 = ⚠越南国内法对外国法人股东征收0%，协定10%仅为上限
  → 实际适用0%（国内法优先）
  
  利润100 → 越南税后80 → 中国收到80（80×1.00，越南国内法0%预提）
  综合有效税率 = 1 - 80/100 = 20%

⚠ 关键结论修正：
直投架构综合有效税率=20%（低于SPV架构24%）
SPV架构在股息路径上反而增加5%税负（香港→中国预提5%）
SPV架构的核心优势转为退出灵活（转让SPV股权0%资本利得 vs 直投越南股权20%）
→ 纯股息汇回场景：直投更优
→ 退出+再投资+多国协调场景：SPV仍具结构性优势

对比（旧模型 vs 新模型）：
  旧模型（错误假设越南预提10%）：
    直投28% vs SPV 27.8% → SPV微优0.2%
  新模型（越南国内法0%）：
    直投20% vs SPV 24% → 直投优4%，但退出SPV仍优
```

### 3.2 退出税负测算

| 退出方式 | 直投架构 | SPV架构 |
|---------|---------|---------|
| 转让东道国股权 | 东道国资本利得税（20%） | 转让SPV股权，0% |
| 股息清算汇回 | 0%预提（越南国内法对外国法人0%）⚠ | 5%预提（SPV→中国，中港安排）⚠ |

## 4. ODI审批路径决策

### 4.1 核准vs备案判定

```
是否敏感类？
  → 是（敏感国家/行业） → 发改委核准
  → 否 → 投资规模>3亿USD？
    → 是 → 国家发改委备案
    → 否 → 省级发改委备案
```

### 4.2 敏感类判定

- 敏感国家：受制裁/未建交/战争地区
- 敏感行业：武器/跨境水资源/新闻媒体

## 5. 经济实质法合规策略

### 5.1 香港FSIE

```
2023年起，被动收入（股息/利息/特许权使用费）免税需满足：
1. 经济实质测试：足够人手+足够运营开支+合适办公场所
   - 纯持股：简化要求（注册代理+公司秘书）
2. 或参股豁免：持股≥5%+被投资方税率≥15%+收入<50%被动
```

### 5.2 BVI/Cayman经济实质法

```
纯持股实体：
- 满足简化要求（注册代理+董事会议）
- 无需当地员工/办公场所
非纯持股：需满足完整经济实质（当地员工+决策+核心业务）
```

## 6. 反避税风险防控

### 6.1 CFC（受控外国公司）

```
中国CFC条款触发条件：
1. 中国居民企业/个人持股≥10%
2. 实际税负≤12.5%（对比中国法定25%）
3. 无合理经营需要（纯持股/被动收入）

防控策略：
- 控股地选择税率≥15%（如新加坡17%/香港16.5%）
- SPV保留合理商业目的（区域管理/资金调度）
```

### 6.2 转让定价

```
关联交易须遵循独立交易原则：
1. 股东贷款利率：参考市场利率
2. 管理费分摊：成本+合理利润
3. 特许权使用费：需有IP登记+合理定价
```
