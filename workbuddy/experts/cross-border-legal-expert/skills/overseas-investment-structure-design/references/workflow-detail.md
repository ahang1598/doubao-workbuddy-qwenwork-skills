# 工作流详细 — overseas-investment-structure-design

## Phase 0: 需求确认与约束识别 [L1]

### Step 0.1 验证必需输入

```
验证逻辑：
1. target_country存在？→ 否：[阻断]
2. investment_purpose有效？→ 否：提示选择
3. investment_amount可解析？→ 否：[阻断]
4. target_country受制裁？→ 是：[阻断]（详见Step 0.4）
```

### Step 0.2 约束识别

```
识别以下约束：
1. 东道国准入约束：负面清单/行业限制/外资比例
2. 中国侧ODI路径约束：投资规模→核准vs备案
3. 控股地约束：经济实质法/CRS/协定网络
4. 退出约束：退出计划→架构灵活性要求
```

### Step 0.3 制裁清单核查 [阻断级-新增R4]

```
核查逻辑（制裁/出口管制合规前置审查）：
1. 东道国制裁状态核查：
   - 联合国制裁名单（UN Security Council Sanctions List）
   - 美国制裁名单（OFAC SDN List/Non-SDN List）
   - 欧盟制裁名单（EU Consolidated Sanctions List）
   - 中国制裁/管制名单（不可靠实体清单/出口管制清单）
   → 命中：[阻断]——"目标国/交易对手受制裁，架构设计不适用，建议终止或咨询合规律师"
2. 交易对手/关联方核查：
   - 投资标的实际控制人是否在制裁名单
   - 供应链关键环节是否涉及制裁管制物项
   → 命中：[限制]——需额外合规审查后方可继续
3. 出口管制物项核查：
   - 投资涉及的技术/产品是否落入中国《出口管制法》管制物项清单
   - 目标行业是否触发美国EAR/欧盟双用途物项管制
   → 命中：[限制]——需取得出口许可后方可继续
4. 制裁风险标注：
   - 即使未命中制裁名单，仍须在O7风险提示中标注：
     "当前核查基于[日期]制裁清单，制裁状态可能随时变化，投资前须由合规律师复核"
```

### Step 0.4 需求确认

```
向用户确认：
1. 投资概况：[目标国]+[目的]+[规模]
2. 控股地候选：[自动推荐]+用户可调整
3. 退出计划：[如未提供]提示确认
4. 输出预期：7个输出块（O1-O7）
```

## Phase 1: 东道国准入分析 [L2]

### Step 1.1 负面清单核查

```
核查流程：
1. 检索东道国外商投资负面清单/限制目录
2. 判定industry_sector是否落入限制类
3. 判定investment_purpose对应的外资政策
4. 输出准入结论：
   - [允许] 允许类：WFOE可直接设立
   - [限制] 限制类：需额外审批/合资要求/外资比例限制
   - [阻断] 禁止类：阻断，建议调整行业或模式
```

### Step 1.2 行业许可要求

```
识别行业特殊许可：
1. 制造业：环保许可/安全生产许可/特殊行业许可
2. 销售：批发零售许可（部分国家限制外资）
3. 研发：技术进出口管制
4. 金融/电信/媒体：通常限制外资
```

### Step 1.3 优惠政策评估

```
评估可适用的东道国优惠：
1. 经济特区/工业园区优惠（如越南VSIP）
2. 行业优惠（高新技术/出口导向）
3. BOI/投资促进机构优惠（如泰国BOI）
4. 税收减免（企业所得税减免/进口设备免税）
```

### Step 1.4 安全审查风险评估 [阻断级-新增R3]

```
安全审查风险评估（CFIUS/EU FDI/东道国安全审查）：
1. 美国CFIUS审查（如投资涉及美国资产/技术）：
   - 投资标的是否涉及美国关键基础设施/关键技术/敏感数据
   - 收购控制权程度（≥50%表决权/董事会多数席位→高风险）
   - 投资者是否受外国政府控制
   → 高风险：建议主动申报CFIUS或设计架构规避美国资产
2. 欧盟FDI审查（如投资涉及欧盟成员国资产）：
   - 目标行业是否属于欧盟2026修订版审查清单（AI/半导体/关键原材料/国防/能源）
   - 成员国国内审查制度差异（法国/德国/意大利审查最严格）
   → 需审查：在O6合规清单中增加各成员国FDI申报步骤
3. 东道国国家安全审查：
   - 核查东道国是否有外资安全审查制度（如越南2020投资法无专门审查但行业限制覆盖部分）
   - 中国国务院837号令§7对外投资安全审查（中国侧）
   → 在O4设立路径中增加安全审查申报环节
4. 安全审查风险分级：
   - [低风险] 低风险：非敏感行业+非敏感区域+无控制权转让
   - [中等风险] 中等风险：涉及技术/基础设施/数据，需审查但通常可通过
   - [高风险] 高风险：国防/半导体/关键基础设施/外国政府背景→建议架构重构或放弃
5. 输出：
   - 安全审查风险等级判定
   - 需申报的安全审查清单（如适用）
   - 架构调整建议（如需规避审查触发条件）
```

## Phase 2: 控股地比选与架构设计 [L2]

### Step 2.1 控股地候选生成

```
基于target_country + investment_purpose生成候选：
1. 默认候选：HK + SG + BVI/Cayman
2. 如有用户指定holding_jurisdiction → 加入候选
3. 如有existing_structure → 以现有架构为基础优化
```

### Step 2.2 多维评估

```
评估维度（6维）：
1. 税负优化（30%）：股息/利息/特许权使用费预提税+控股地所得税
2. 协定网络（20%）：与东道国+中国的双边税收协定覆盖
3. 设立成本（15%）：注册费+初始合规成本
4. 维护成本（15%）：年审+审计+董事费
5. 退出便利（10%）：资本利得税+股权转让限制
6. 合规难度（10%）：经济实质法/CRS/反避税要求
```

### Step 2.3 架构方案设计

```
设计方案（2-3个）：
方案A（推荐）：最优综合评分
方案B（备选）：次优或特殊场景适用
方案C（简化）：如直投或减少层级

每方案输出：
1. Mermaid架构图
2. 各层实体说明（注册地/类型/功能/注册资本）
3. 资金流向（注资/利润汇回/退出）
4. 适用场景说明
```

## Phase 3: 设立路径与税负测算 [L2]

### Step 3.1 设立路径设计

```
设计步骤（按时间顺序）：
1. 中国侧ODI：
   - 发改委核准/备案（规模>3亿USD需核准）
   - 商务部ODI证书
   - 外汇登记
2. 控股地设立：
   - 公司注册
   - 银行开户
   - 董事/秘书任命
3. 东道国设立：
   - 投资许可（IRC/类似）
   - 企业注册（ERC/类似）
   - 税务登记
   - 银行开户
4. 资金注入：
   - 境外放款/注册资本汇出
   - 验资
```

### Step 3.2 时间线生成

```
生成甘特图或时间线表：
- 各步骤耗时（基于目标国典型周期）
- 前置依赖关系
- 关键里程碑
- 总周期估算
```

### Step 3.3 综合税负测算

```
测算模型：
1. 东道国企业所得税（法定税率×有效税率调整）
2. 利润汇回预提税：
   ⚠ 关键修正：须优先查证东道国国内法实际征收税率，协定税率仅为上限
   - 股息：东道国→控股地（国内法实际税率优先；协定税率作为上限参考）
   - 股息：控股地→中国（协定税率）
   例：越南国内法对外国法人股东股息预提税=0%，协定10%仅为上限，实际适用0%
3. 控股地所得税（境外股息通常免税/参股豁免）
4. 退出税负：资本利得税
5. 综合有效税率 = 1 - (1-东道国CIT) × (1-汇回预提税)

多方案对比：直投 vs 单层SPV vs 多层SPV
```

## Phase 4: 合规清单生成 [L2]

### Step 4.1 中国侧ODI合规

```
清单项：
1. 发改委核准/备案
   - 核准：敏感行业/敏感国家/投资额>3亿USD
   - 备案：非敏感类
2. 商务部ODI证书（境外投资管理办法，商务部令2014年第3号）
3. 外汇登记（银行直接办理）
4. 国资审批（如适用，国有企业）
5. 反垄断申报（如适用，营业额达标）
6. 对外投资安全审查（国务院837号令§7，如适用）
7. 后续年报（联合年报+ODI存量权益登记）
```

### Step 4.2 东道国准入合规

```
清单项：
1. 负面清单核查
2. 投资许可/注册证书
3. 行业特殊许可
4. 环评/安评（制造业）
5. 土地使用许可（制造业建厂）
6. 外汇登记（东道国侧）
7. 税务登记
8. 劳动用工合规（见cross-border-employment-compliance-review技能）
```

### Step 4.3 中间控股地合规

```
清单项：
1. 经济实质法合规
   - 香港：境外被动收入免税需满足"足够人手"测试
   - BVI/Cayman：纯持股可简化，但需注册代理+董事
2. CRS申报（银行自动）
3. 年度审计+报税
4. 董事会决议记录
5. 重要控制人登记（SCR）
```

## SOFT_DEGRADED降级规则

### 触发条件
- 东道国投资法规信息不全
- 税收协定信息缺失
- 控股地最新法规未检索到

### 降级产出

| 层 | 内容 |
|---|------|
| **C层** | 缺失信息项清单 |
| **D层** | 输出限制声明——"部分结论基于[年份]数据" |
| **G层** | 建议咨询当地律师/税务顾问确认 |
