# 质量标准 — overseas-investment-structure-design

## 1. 四维评价体系

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 合规性 | 30% | ODI审批路径正确/准入结论准确/合规清单完整 |
| 税负优化 | 25% | 测算准确/协定适用正确/方案对比充分 |
| 可行性 | 25% | 设立路径可执行/时间线合理/成本可接受 |
| 风险覆盖 | 20% | 风险识别全面/缓解措施具体/置信度标注到位 |

## 2. 阻断级检查项（P0）

- [ ] O1执行摘要≤400字且含推荐架构
- [ ] O2架构图含全部层级+资金流向标注
- [ ] O3比选矩阵含≥3候选+加权评分+推荐结论
- [ ] O4设立步骤含中国侧ODI三部门+东道国设立全流程
- [ ] O5税负测算含多方案对比+计算路径
- [ ] O6合规清单覆盖中国侧+东道国+控股地三侧
- [ ] O7风险提示含下一步具体建议
- [ ] 免责声明完整
- [ ] 受制裁国家阻断

## 3. 警告级检查项（P1）

- [ ] 税率数据标注协定条款号+检索日期
- [ ] 东道国法规不确定时标注高风险（HTML内联色标，非emoji）
- [ ] 金额注明币种
- [ ] Mermaid架构图实体标注注册地+功能
- [ ] 控股地推荐理由与investment_purpose对应
- [ ] 退出计划影响架构灵活性已说明
- [ ] 经济实质法合规建议具体

## 4. 建议级检查项（P2）

- [ ] 置信度标注三级一致（已核实/参考来源/需当地确认，HTML内联色标）
- [ ] 时间线含关键里程碑
- [ ] 优惠政策评估（如适用）
- [ ] CFC反避税风险提示
- [ ] CRS信息交换说明
- [ ] 后续持续合规要求（年报/审计）

## 5. 置信度标准

| 级别 | 标准 | 标注位置 | HTML色标 |
|------|------|---------|---------|
| 已核实 | 法条原文/官方文件/税收协定原文确认 | 法规引用+税率数据 | `<span style="color:#039855;">●</span>` |
| 参考来源 | 律所指南/二次来源/需当地确认 | 非官方来源信息 | `<span style="color:#b54708;">●</span>` |
| 需当地确认 | 信息可能过时/不确定/法律更新频繁 | 小众国家/新法规 | `<span style="color:#d92d20;">●</span>` |

## 6. HTML格式专项检查（v1.2.0新增）

- [ ] 全文无 emoji 风险标记（🔴🟡🟢⚠️）
- [ ] 所有风险标注使用 HTML 内联色标
- [ ] 无残留 CONTENT_SLOT 占位符
- [ ] 所有元素使用 `style="..."` 内联样式
- [ ] 色值取自 Richee Design Token
- [ ] @media print 规则完整
- [ ] Mermaid 渲染正常（或降级提示完整）
