# Settlement, Release and Waiver Review Cards

中文类型：和解、豁免与权利放弃协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## SET-R01 Claims and Release Scope / 请求与豁免范围
- Check: 已知未知请求、时间、主体、关联方、衍生请求、法定权利和保留。
- Red flags: 放弃范围超过争议和对价；无意释放第三方或未来行为。
- Missing protection: 请求清单、明确保留、不可放弃权利和例外。
- Linked clauses: 陈述、赔偿、争议
- Default risk: high.
- Mandatory-law check: 不可放弃权利、劳动消费者及公共政策限制。

## SET-R02 Consideration and Timing / 对价与履行时点
- Check: 付款、撤诉、返还、税务、条件、分期、托管和违约后果。
- Red flags: 先全面释放后才支付；付款条件由一方控制。
- Missing protection: 同步履行、托管、逾期、撤回期和支付证据。
- Linked clauses: 解除、保密、执行
- Default risk: high.
- Mandatory-law check: 和解生效、税务、工资及撤回期限。

## SET-R03 No Admission and Confidentiality / 不承认责任与保密
- Check: 不承认、和解存在和条款保密、法定披露、顾问和监管沟通。
- Red flags: 保密阻止依法举报或配合监管；违约金不成比例。
- Missing protection: 法定例外、真诚陈述、允许披露和比例救济。
- Linked clauses: 非贬损、争议、税务
- Default risk: high.
- Mandatory-law check: 举报人、证券、劳动和监管披露规则。

## SET-R04 Covenants and Non-Disparagement / 承诺与非贬损
- Check: 不诉、撤诉、协作、非贬损、推荐、客户沟通和未来行为。
- Red flags: 一方可公开攻击而另一方全面沉默；不诉覆盖未来新侵权。
- Missing protection: 互惠范围、真实陈述例外和未来行为保留。
- Linked clauses: 保密、释放、执行
- Default risk: medium.
- Mandatory-law check: 言论、劳动、消费者和竞争规则。

## SET-R05 Enforcement, Tax and Breach / 执行、税务与违约
- Check: 违约通知、补救、特定履行、费用、税务分配、赔偿和责任。
- Red flags: 任何轻微违约导致返还全部和解款；税务陈述越权。
- Missing protection: 重大性、比例救济、税务独立确认和费用规则。
- Linked clauses: 对价、争议、存续
- Default risk: high.
- Mandatory-law check: 违约金、税务、律师费和司法确认。

## SET-R06 Authority, Dismissal and Carve-outs / 授权、撤诉与保留事项
- Check: 签署授权、请求所有权、无转让、撤诉文件、法院管辖和第三方权利。
- Red flags: 签署人无权释放全部请求；撤诉与付款时点错位。
- Missing protection: 授权证明、撤诉条件、执行法院和保留索赔。
- Linked clauses: 对价、释放、争议
- Default risk: high.
- Mandatory-law check: 诉讼程序、仲裁、代理和请求转让规则。

## Family Routing
- Aliases: settlement agreement, release, waiver, compromise agreement, 和解协议, 豁免书, 权利放弃.
- Typical roles: releasing party, released party, claimant, respondent.
- Distinguish from: 单纯争议条款仍按原合同类型审查；本类要求存在既有或潜在请求的解决。
