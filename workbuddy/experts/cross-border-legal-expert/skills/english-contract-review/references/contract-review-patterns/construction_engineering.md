# Construction, Engineering and EPC Review Cards

中文类型：建设工程、工程咨询与 EPC 协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## CON-R01 Scope, Design and Site / 范围、设计与现场
- Check: 工作范围、设计责任、现场资料、接口、许可、标准和业主提供项。
- Red flags: 承包商无条件承担业主资料错误；范围通过笼统适用性保证扩张。
- Missing protection: 界面矩阵、现场条件、设计审查和依赖。
- Linked clauses: 变更、工期、验收
- Default risk: high.
- Mandatory-law check: 建设资质、强制标准、规划和安全许可。

## CON-R02 Schedule and Delay / 工期与延误
- Check: 开工、基准计划、里程碑、关键路径、延期事件、通知和赶工。
- Red flags: 任何通知迟延即永久丧权；双方延误无分配方法。
- Missing protection: 延误分类、并发延误、时限和恢复计划。
- Linked clauses: 违约金、不可抗力、变更
- Default risk: high.
- Mandatory-law check: 工期索赔、违约金调整和不可抗力规则。

## CON-R03 Changes and Claims / 变更与索赔
- Check: 变更权限、书面指令、紧急工作、估价、工期影响和索赔记录。
- Red flags: 口头变更不付费但业主可要求立即施工；现场指令权限不明。
- Missing protection: 授权人、暂定价、继续履行和争议保留。
- Linked clauses: 付款、工期、争议
- Default risk: high.
- Mandatory-law check: 工程变更、签证和强制结算规则。

## CON-R04 Payment and Security / 付款与工程担保
- Check: 合同价、计量、进度款、保留金、发票、付款证明、履约和付款担保。
- Red flags: 付款完全取决于上游收款；保留金无释放条件。
- Missing protection: 支付时间、无争议款、担保金额递减和解除。
- Linked clauses: 验收、终止、分包
- Default risk: high.
- Mandatory-law check: 工程价款优先、保证、发票和农民工工资规则。

## CON-R05 Quality, Acceptance and Warranty / 质量、验收与缺陷责任
- Check: 检查、测试、竣工、性能、移交文件、缺陷期和最终验收。
- Red flags: 竣工证书自动放弃隐蔽缺陷；性能标准不可测。
- Missing protection: 整改、复验、延长保证和替代修复。
- Linked clauses: 付款、责任、移交
- Default risk: high.
- Mandatory-law check: 工程质量、竣工验收和法定保修期限。

## CON-R06 Insurance, Indemnity and Termination / 保险、赔偿与终止
- Check: 工程险、责任险、现场风险、赔偿、停工、接管、便利终止和分包。
- Red flags: 承包商承担业主过错全部风险；终止后现场和材料无人管理。
- Missing protection: 保险证据、比例责任、撤场、材料估值和接管。
- Linked clauses: 安全、付款、争议
- Default risk: high.
- Mandatory-law check: 安全生产、保险、建设合同解除和分包限制。

## Family Routing
- Aliases: construction contract, EPC, engineering agreement, design-build, 建设工程, 工程总承包.
- Typical roles: owner/employer, contractor, engineer, subcontractor.
- Distinguish from: 设备单纯采购选采购；纯设计咨询可选专业服务但叠加建设规则。
