# Logistics, Transport and Warehousing Review Cards

中文类型：物流、运输与仓储协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## LOG-R01 Service Scope and Routing / 服务范围与路线
- Check: 运输方式、路线、时效、装卸、仓储、温控、特殊货物和指令。
- Red flags: 服务范围依承运人内部规则；特殊条件未写入。
- Missing protection: 操作手册优先级、偏航批准和关键里程碑。
- Linked clauses: 费用、责任、分包
- Default risk: high.
- Mandatory-law check: 运输许可、危险品和行业监管。

## LOG-R02 Custody, Title and Risk / 占有、所有权与风险
- Check: 交接点、保管责任、风险转移、留置权、盘点和差异。
- Red flags: 货物风险与实际控制脱节；承运人拥有过宽留置权。
- Missing protection: 交接证据、库存差异标准和紧急处置。
- Linked clauses: 保险、索赔、付款
- Default risk: high.
- Mandatory-law check: 运输、仓储、物权和留置规则。

## LOG-R03 Documents and Customs / 单证与海关
- Check: 运单、装箱、申报、原产地、税费、进口商身份和记录。
- Red flags: 一方承担其无法控制的全部申报后果；文件错误无补救。
- Missing protection: 文件清单、批准、纠错和查验协助。
- Linked clauses: 交付、制裁、税费
- Default risk: high.
- Mandatory-law check: 海关、出口管制、制裁和税务规则。

## LOG-R04 Service Levels and Delay / 服务水平与延误
- Check: 提货、运输、入库、出库时效、例外、证据、补救和高峰期。
- Red flags: 延误定义排除大部分事件；赔偿与实际业务损失无联系。
- Missing protection: 慢性失败、替代运输、升级和恢复计划。
- Linked clauses: 不可抗力、责任、终止
- Default risk: medium.
- Mandatory-law check: 法定承运责任和不可排除时效义务。

## LOG-R05 Claims, Liability and Insurance / 索赔、责任与保险
- Check: 索赔通知、证据、时限、货损计算、责任限制、保险和代位。
- Red flags: 索赔期限短于可操作窗口；责任上限与货值无关。
- Missing protection: 隐蔽损坏、共同检验、保险凭证和差额责任。
- Linked clauses: 风险、赔偿、争议
- Default risk: high.
- Mandatory-law check: 强制承运责任、国际公约和保险规则。

## LOG-R06 Security, Subcontracting and Exit / 安全、分包与退出
- Check: 设施安全、人员、盗损、分包承运、数据、库存移交和终止。
- Red flags: 无限分包且不保留责任；终止时货物被扣留。
- Missing protection: 分包名单、等效义务、库存核对和有序迁移。
- Linked clauses: 保密、留置、付款
- Default risk: high.
- Mandatory-law check: 治安、数据、分包许可和留置权限制。

## Family Routing
- Aliases: logistics agreement, transportation agreement, freight, warehousing, 物流协议, 运输合同, 仓储合同.
- Typical roles: shipper/customer, carrier, warehouse operator, freight forwarder.
- Distinguish from: 货物买卖选采购；仅代理报关或咨询需按实际服务确定专业服务叠加。
