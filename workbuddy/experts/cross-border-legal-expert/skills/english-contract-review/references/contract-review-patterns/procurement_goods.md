# Procurement and Sale of Goods Review Cards

中文类型：采购与货物买卖协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## SUP-R01 Orders and Forecasts / 订单与预测
- Check: 订单接受、预测约束、最低量、优先级、变更、取消和冲突。
- Red flags: 所有预测均有约束力；供应商政策覆盖主协议。
- Missing protection: 产能承诺、取消费用和订单确认期限。
- Linked clauses: 价格、交付、终止
- Default risk: high.
- Mandatory-law check: 格式条款、电子订单和竞争规则。

## SUP-R02 Specifications and Changes / 规格与变更
- Check: 规格、图纸、法规要求、工程变更、版本和批准证据。
- Red flags: 单方变更但不调整成本、库存或交期。
- Missing protection: 变更委员会、旧料处理、验证和批准时限。
- Linked clauses: 质量、验收、价格
- Default risk: high.
- Mandatory-law check: 产品标准、认证和监管变更。

## SUP-R03 Delivery, Title and Risk / 交付、所有权与风险
- Check: 贸易术语及版本、地点、日期、包装、海关、所有权和风险。
- Red flags: 所有权、风险、保险和验收点冲突。
- Missing protection: 延误证据、部分交付、短缺和替代采购。
- Linked clauses: 验收、保险、付款
- Default risk: high.
- Mandatory-law check: 海关、进口、制裁和物权转移规则。

## SUP-R04 Inspection and Acceptance / 检验与验收
- Check: 检验期、隐蔽缺陷、拒收、返修、更换、退款和复验。
- Red flags: 付款放弃全部缺陷；视为验收期限过短。
- Missing protection: 隐蔽缺陷、重复失败和召回保留。
- Linked clauses: 保证、付款、终止
- Default risk: high.
- Mandatory-law check: 产品质量、消费者和强制检验规则。

## SUP-R05 Warranty, Recall and Continuity / 保证、召回与连续供应
- Check: 合格、质量体系、保证期、召回、根因、备件和灾备。
- Red flags: 排他救济阻止召回或监管行动；无停产通知。
- Missing protection: 纠正措施、连续供应、备件和退出库存。
- Linked clauses: 赔偿、保险、终止
- Default risk: high.
- Mandatory-law check: 产品安全、召回和行业许可。

## SUP-R06 Price, Indemnity and Exit / 价格、赔偿与退出
- Check: 价格调整、税费、抵销、产品和知识产权索赔、工具、退出。
- Red flags: 供应商和解损害买方权利；退出库存和模具无人处理。
- Missing protection: 抗辩控制、保险、库存回购和工具返还。
- Linked clauses: 责任、保险、终止
- Default risk: high.
- Mandatory-law check: 税务、赔偿范围、担保和竞争规则。

## Family Routing
- Aliases: supply agreement, purchase agreement, vendor agreement, sale of goods, 采购协议, 供货协议.
- Typical roles: supplier, buyer.
- Distinguish from: 以代工生产流程为核心选制造；以运输仓储为核心选物流。
