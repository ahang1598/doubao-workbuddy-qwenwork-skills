# Loan, Credit, Guarantee and Security Review Cards

中文类型：借款、授信、保证与担保协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## FIN-R01 Facility and Purpose / 融资额度与用途
- Check: 承诺或非承诺额度、提取、币种、用途、期限和参与方。
- Red flags: 贷款人可任意取消已承诺额度；用途违约与实际损害不匹配。
- Missing protection: 提取程序、可用期、目的变更和资金路径。
- Linked clauses: 先决条件、违约、担保
- Default risk: high.
- Mandatory-law check: 金融许可、外债、反洗钱和用途监管。

## FIN-R02 Interest, Fees and Payments / 利息、费用与支付
- Check: 利率基准、替代基准、复利、违约利率、费用、日计数和预扣税。
- Red flags: 利率机制不可计算；费用重复；违约利率无限叠加。
- Missing protection: 基准失效、税收补足、提前还款和付款顺序。
- Linked clauses: 违约、税务、责任
- Default risk: high.
- Mandatory-law check: 利率、费用、税务、外汇和金融消费者规则。

## FIN-R03 Conditions and Repayment / 先决条件与偿还
- Check: 首次与后续提款条件、陈述重复、摊还、到期、提前还款和清偿。
- Red flags: 主观满意条件无限延续；偿还公式与现金流不匹配。
- Missing protection: 客观材料清单、豁免权限和强制提前还款顺序。
- Linked clauses: 陈述、承诺、违约
- Default risk: high.
- Mandatory-law check: 放款条件、资本项目和偿债限制。

## FIN-R04 Representations, Covenants and Default / 陈述、承诺与违约
- Check: 重大性、知情限定、财务承诺、信息义务、交叉违约和重大不利变化。
- Red flags: 任何不准确均立即违约；重大不利变化完全由贷款人判断。
- Missing protection: 补救期、阈值、交叉加速和客观指标。
- Linked clauses: 加速、担保、争议
- Default risk: high.
- Mandatory-law check: 破产、公司治理和强制执行规则。

## FIN-R05 Guarantee and Security / 保证与担保
- Check: 保证范围、期间、独立性、担保物、登记、优先权、负面质押和补充文件。
- Red flags: 担保人责任无限扩展到未经同意的变更；登记条件遗漏。
- Missing protection: 公司批准、最高额、担保清单、登记和解除。
- Linked clauses: 债务、违约、执行
- Default risk: high.
- Mandatory-law check: 公司对外担保、保证期间、登记和优先顺位。

## FIN-R06 Acceleration and Enforcement / 加速到期与实现
- Check: 违约后加速、抵销、账户控制、担保实现、收益分配和从属。
- Red flags: 技术性违约立即实现全部担保；执行收益顺序不清。
- Missing protection: 通知补救、比例执行、释放文件和剩余款返还。
- Linked clauses: 担保、争议、破产
- Default risk: high.
- Mandatory-law check: 担保实现、司法执行、破产和跨境执行规则。

## Family Routing
- Aliases: loan agreement, credit facility, promissory note, guarantee, security agreement, 借款协议, 授信协议, 保证合同.
- Typical roles: lender, borrower, guarantor, security provider.
- Distinguish from: 可转换融资或股权安排选投资并购；普通延期付款不当然属于本类。
