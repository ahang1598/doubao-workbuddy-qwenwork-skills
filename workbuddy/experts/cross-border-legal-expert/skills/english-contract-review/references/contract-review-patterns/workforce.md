# Employment, Executive and Independent Contractor Review Cards

中文类型：雇佣、高管与独立承包人协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## WRK-R01 Classification and Control / 人员分类与实际控制
- Check: 身份、工作控制、经济依赖、工具、替代权、排他、税务和福利。
- Red flags: 仅靠合同标签规避劳动关系；实际管理与独立身份冲突。
- Missing protection: 分类事实清单、定期复核和重新分类机制。
- Linked clauses: 职责、费用、终止
- Default risk: high.
- Mandatory-law check: 人员所在地劳动、税务、社保及分类测试。

## WRK-R02 Duties, Location and Policies / 职责、地点与制度
- Check: 职位、汇报、工作地、远程、差旅、工作时间、政策纳入和变更。
- Red flags: 职责无限扩张；政策可单方改变核心报酬或身份。
- Missing protection: 重大变更同意、费用、健康安全和远程边界。
- Linked clauses: 薪酬、终止、合规
- Default risk: high.
- Mandatory-law check: 工时、休假、职业安全和跨境用工规则。

## WRK-R03 Compensation, Benefits and Tax / 薪酬、福利与税务
- Check: 基本薪酬、奖金条件、佣金、股权、福利、费用、扣款和税。
- Red flags: 奖金完全任意但已形成报酬预期；离职后佣金被没收。
- Missing protection: 计算公式、支付日期、终止处理和税务责任。
- Linked clauses: 绩效、终止、股权文件
- Default risk: high.
- Mandatory-law check: 最低工资、奖金、社保、税务和工资扣除。

## WRK-R04 Confidentiality and IP / 保密与成果权利
- Check: 保密范围、职务成果、预有成果、道德权利、开源和返还。
- Red flags: 转让范围覆盖个人全部未来创作；无预有成果例外。
- Missing protection: 成果清单、与职责关联、协作签署和法定补偿。
- Linked clauses: 限制性约定、终止、数据
- Default risk: high.
- Mandatory-law check: 职务成果、发明奖励、商业秘密和人格权。

## WRK-R05 Restrictions and Conduct / 限制性约定与行为
- Check: 竞业、招揽、客户、兼业、社交媒体、调查和纪律程序。
- Red flags: 地域期限业务范围无限；放弃集体或法定权利不显著。
- Missing protection: 必要范围、补偿、可分割性和本地法保留。
- Linked clauses: 保密、终止、争议
- Default risk: high.
- Mandatory-law check: 竞业、劳动权利、仲裁和反歧视规则。

## WRK-R06 Term, Termination and Disputes / 期限、终止与争议
- Check: 固定或无固定期限、原因、通知、补偿、交接、豁免和仲裁。
- Red flags: 即时解除条件过宽；承包人仲裁条款掩盖分类争议。
- Missing protection: 法定程序、最终报酬、财物返还和替代论坛。
- Linked clauses: 薪酬、限制、存续
- Default risk: high.
- Mandatory-law check: 解除、经济补偿、争议解决和集体权利。

## Family Routing
- Aliases: employment agreement, executive employment, independent contractor, freelancer agreement, 雇佣协议, 劳动合同, 独立承包人.
- Typical roles: employer/client, employee/executive/contractor.
- Distinguish from: 公司采购一般服务但不涉及个人分类时选专业服务；本类必须明确人员身份变体。
