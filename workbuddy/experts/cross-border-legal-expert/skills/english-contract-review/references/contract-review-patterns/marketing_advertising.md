# Marketing, Advertising, Influencer and Sponsorship Review Cards

中文类型：营销、广告、达人与赞助协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## MKT-R01 Scope, Deliverables and Approvals / 范围、交付与审批
- Check: 活动、渠道、内容数量、时间、格式、审批轮次、修改和发布。
- Red flags: 审批沉默视为通过；品牌可无限返工且无费用调整。
- Missing protection: 创意简报、审批时限、版本和变更机制。
- Linked clauses: 费用、知识产权、下架
- Default risk: high.
- Mandatory-law check: 广告发布、特定媒介和行业许可规则。

## MKT-R02 Claims and Compliance / 宣传主张与合规
- Check: 主张证据、比较广告、披露、代言、促销、抽奖、敏感行业和地域。
- Red flags: 代理或达人可自行作产品功效承诺；商业关系未显著披露。
- Missing protection: 主张清单、合规审批、证据保留和地域限制。
- Linked clauses: 赔偿、下架、品牌
- Default risk: high.
- Mandatory-law check: 广告、消费者、反不正当竞争和行业监管。

## MKT-R03 Content, Talent and IP / 内容、人才与知识产权
- Check: 创意权属、素材、音乐、肖像、姓名、生成式 AI、使用期和地域。
- Red flags: 品牌永久拥有达人全部人格化内容；第三方素材无授权链。
- Missing protection: 许可矩阵、权利证明、道德权利和生成内容政策。
- Linked clauses: 保密、赔偿、终止
- Default risk: high.
- Mandatory-law check: 著作权、肖像姓名、表演者和人工智能内容规则。

## MKT-R04 Media, Metrics and Fees / 媒体、指标与费用
- Check: 媒体预算、采购透明度、返点、展示口径、无效流量、报告和付款。
- Red flags: 代理保留未披露返点；指标由单方平台数据最终决定。
- Missing protection: 审计、第三方验证、预算偏差和补投规则。
- Linked clauses: 范围、责任、终止
- Default risk: medium.
- Mandatory-law check: 税务、发票、广告监测和平台规则。

## MKT-R05 Exclusivity and Reputation / 排他与声誉
- Check: 品类排他、期限、竞品定义、道德条款、暂停和危机配合。
- Red flags: 排他覆盖所有商业活动；道德条款仅约束一方且标准模糊。
- Missing protection: 限定品类地域、客观触发、调查和比例救济。
- Linked clauses: 终止、费用、内容使用
- Default risk: high.
- Mandatory-law check: 劳动分类、竞争、人格权和公共政策。

## MKT-R06 Takedown, Indemnity and Exit / 下架、赔偿与退出
- Check: 下架时限、平台控制、危机通知、第三方索赔、终止和存量内容。
- Red flags: 品牌要求即时删除但平台权限不在创作者控制；责任无上限。
- Missing protection: 可控范围、证据保存、替代发布和终止后许可。
- Linked clauses: 合规、知识产权、责任
- Default risk: high.
- Mandatory-law check: 平台下架、消费者救济和不可排除责任。

## Family Routing
- Aliases: marketing services, advertising agreement, influencer agreement, sponsorship agreement, 营销协议, 广告合同, 达人合作.
- Typical roles: advertiser/brand, agency, publisher/platform, creator/influencer.
- Distinguish from: 一般咨询无媒体或内容合规风险选专业服务；平台自有条款选平台协议。
