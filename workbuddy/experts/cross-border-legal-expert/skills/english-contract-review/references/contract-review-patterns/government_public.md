# Government Contracting, Public Procurement and Teaming Review Cards

中文类型：政府合同、公共采购与联合投标协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## GOV-R01 Solicitation and Flow-downs / 招标文件与下传条款
- Check: 招标文件、主合同、技术要求、补遗、下传条款、优先级和变更。
- Red flags: 笼统下传全部主合同义务但不给文本；冲突顺序不明。
- Missing protection: 适用条款清单、访问权、变更通知和不适用项。
- Linked clauses: 范围、付款、终止
- Default risk: high.
- Mandatory-law check: 政府采购、招投标及项目特定强制条款。

## GOV-R02 Eligibility and Representations / 资格与陈述
- Check: 投标资格、许可证、规模、关联关系、利益冲突、制裁和持续准确性。
- Red flags: 陈述覆盖未知关联方；更新义务无重大性或知情限定。
- Missing protection: 资格清单、证据、变化通知和补救。
- Linked clauses: 合规、终止、赔偿
- Default risk: high.
- Mandatory-law check: 供应商资格、失信、制裁和反腐败规则。

## GOV-R03 Pricing, Audit and Records / 定价、审计与记录
- Check: 成本或固定价、价格真实性、开放账簿、审计、记录期限和超额追回。
- Red flags: 审计无限期且覆盖无关业务；成本口径与报价不一致。
- Missing protection: 范围、保密、保存期限和争议程序。
- Linked clauses: 付款、税务、合规
- Default risk: high.
- Mandatory-law check: 财政审计、价格、档案和保密规则。

## GOV-R04 Performance, Change and Payment / 履约、变更与付款
- Check: 里程碑、验收、政府指令、停工、变更、付款前提和上游收款。
- Red flags: 未经书面变更仍须履行；分包款完全取决于政府付款。
- Missing protection: 授权变更、无争议款、停工费用和索赔通知。
- Linked clauses: 范围、工期、终止
- Default risk: high.
- Mandatory-law check: 政府付款、工程或服务验收及强制时限。

## GOV-R05 Compliance, Data and IP / 合规、数据与知识产权
- Check: 廉洁、出口、信息安全、保密等级、政府数据权、成果和披露。
- Red flags: 政府取得超出项目需要的全部背景知识产权；安全义务未分级。
- Missing protection: 权利类别、背景清单、安全附件和事件程序。
- Linked clauses: 赔偿、审计、退出
- Default risk: high.
- Mandatory-law check: 国家秘密、数据安全、出口、政府成果权利。

## GOV-R06 Teaming, Subcontract and Termination / 联合投标、分包与终止
- Check: 独家组队、工作份额、主合同授予、分包谈判义务、终止和争议。
- Red flags: 中标后主承包商无义务授予约定份额；排他无限期。
- Missing protection: 关键条款、善意谈判边界、失标终止和成本分配。
- Linked clauses: 排他、知识产权、争议
- Default risk: high.
- Mandatory-law check: 招标联合体、分包限制、竞争和争议规则。

## Family Routing
- Aliases: government contract, public procurement, subcontract, teaming agreement, 政府采购, 政府项目分包, 联合投标.
- Typical roles: government customer, prime contractor, subcontractor, teaming partner.
- Distinguish from: 普通企业采购选采购；存在招投标、政府资金或强制下传条款时主选本类。
