# Platform, Marketplace and Terms of Service Review Cards

中文类型：平台、交易市场与服务条款

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## PLT-R01 Formation, Notice and Versioning / 合同成立、提示与版本
- Check: 点击路径、显著提示、适用用户、版本、更新通知和既有交易。
- Red flags: 仅网页底部链接；修改立即追溯适用于既有争议。
- Missing protection: 同意证据、版本存档、重大变更再同意和生效期。
- Linked clauses: 争议、消费者、终止
- Default risk: high.
- Mandatory-law check: 电子合同、格式条款和消费者提示规则。

## PLT-R02 Accounts and Acceptable Use / 账号与可接受使用
- Check: 资格、认证、账号共享、禁止行为、自动化、未成年人和企业管理员。
- Red flags: 平台可基于未公开规则处罚；企业管理员权力无限。
- Missing protection: 规则层级、通知、申诉和账号恢复。
- Linked clauses: 暂停、数据、终止
- Default risk: high.
- Mandatory-law check: 平台治理、未成年人、网络安全和消费者规则。

## PLT-R03 User Content and Data / 用户内容与数据
- Check: 内容所有权、平台许可、推荐训练、可见性、数据使用、导出和删除。
- Red flags: 永久全球许可超出运营需要；删除账号仍无限利用内容。
- Missing protection: 目的限定、许可终止、备份例外和数据可移植。
- Linked clauses: 隐私、知识产权、退出
- Default risk: high.
- Mandatory-law check: 个人信息、著作权、人格权和数据出境规则。

## PLT-R04 Moderation and Suspension / 内容治理与暂停
- Check: 审核标准、自动决策、通知、紧急处置、申诉、重复违规和透明度。
- Red flags: 可无理由永久封禁并没收余额；无申诉或证据。
- Missing protection: 客观触发、比例措施、紧急例外和人工复核。
- Linked clauses: 账号、费用、争议
- Default risk: high.
- Mandatory-law check: 平台责任、言论内容、消费者和算法规则。

## PLT-R05 Transactions, Fees and Refunds / 交易、费用与退款
- Check: 平台角色、付款、佣金、税费、退款、拒付、托管和卖家义务。
- Red flags: 平台否认交易角色但控制价格、付款和履约；费用可追溯调整。
- Missing protection: 角色披露、资金路径、争议款和退款责任。
- Linked clauses: 责任、消费者、终止
- Default risk: high.
- Mandatory-law check: 支付、电子商务、税务和消费者权益。

## PLT-R06 Liability, Disputes and Changes / 责任、争议与规则变更
- Check: 免责声明、上限、集体放弃、仲裁、法律、服务变化和终止。
- Red flags: 对平台核心义务全面免责；争议条款提示不足。
- Missing protection: 不可排除责任、合理上限、替代论坛和无罚退出。
- Linked clauses: 版本、消费者、赔偿
- Default risk: high.
- Mandatory-law check: 消费者、仲裁、竞争和平台强制义务。

## Family Routing
- Aliases: terms of service, terms of use, marketplace agreement, platform terms, 服务条款, 平台规则.
- Typical roles: platform operator, business user, consumer/user, seller/buyer.
- Distinguish from: 企业专属云订阅选 SaaS；本类聚焦多边平台、用户规则和点击同意。
