# Manufacturing, OEM and ODM Review Cards

中文类型：制造、OEM 与 ODM 协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## MFG-R01 Quality System and Specifications / 质量体系与规格
- Check: BOM、工艺、样品、质量标准、良率、认证、检验和记录。
- Red flags: 制造商可自行替换材料；规格与批准样不一致。
- Missing protection: 首件批准、变更验证、质量协议和记录期限。
- Linked clauses: 变更、验收、召回
- Default risk: high.
- Mandatory-law check: 产品质量、生产许可和行业认证。

## MFG-R02 Tooling and Materials / 模具与物料
- Check: 模具所有权、保管、标识、维护、专用性、客户物料和损耗。
- Red flags: 客户付款模具仍归制造商；可为竞争对手使用。
- Missing protection: 盘点、保险、返还、留置权处理和报废批准。
- Linked clauses: 知识产权、终止、担保
- Default risk: high.
- Mandatory-law check: 物权、留置、海关和税务规则。

## MFG-R03 Capacity and Forecasting / 产能与预测
- Check: 预测约束、预留产能、最低量、交付窗口、短缺分配和扩产。
- Red flags: 客户承担全部预测风险但无产能承诺；供应短缺任意分配。
- Missing protection: 冻结期、弹性区间、优先供应和恢复计划。
- Linked clauses: 订单、价格、不可抗力
- Default risk: high.
- Mandatory-law check: 竞争、供应保障和出口限制。

## MFG-R04 Process Changes and Subcontracting / 工艺变更与分包
- Check: 厂址、工艺、材料、关键设备、分包商和转移生产批准。
- Red flags: 未通知迁厂或分包；变更未经验证即量产。
- Missing protection: 事前批准、等效义务、审计和重新认证。
- Linked clauses: 质量、保密、数据
- Default risk: high.
- Mandatory-law check: 生产许可、环境、安全和出口规则。

## MFG-R05 Audit, Defects and Recall / 审计、缺陷与召回
- Check: 审计、纠正预防、批次追溯、现场失败、召回决策和费用。
- Red flags: 审计受过度限制；召回费用仅限更换价。
- Missing protection: 根因时限、监管协作、客户通知和扩大损失分配。
- Linked clauses: 保证、赔偿、保险
- Default risk: high.
- Mandatory-law check: 产品安全、召回报告和证据保全。

## MFG-R06 IP, Confidentiality and Exit / 知识产权、保密与退出
- Check: 设计权属、工艺诀窍、改进、超量生产、销毁、转厂和库存。
- Red flags: 制造商可使用客户设计生产自有产品；退出时扣留技术资料。
- Missing protection: 禁止超产、在制品处理、转厂协助和工具返还。
- Linked clauses: 模具、订单、终止
- Default risk: high.
- Mandatory-law check: 商业秘密、委托开发、海关和技术出口。

## Family Routing
- Aliases: manufacturing agreement, OEM, ODM, contract manufacturing, 委托生产, 代工协议.
- Typical roles: manufacturer, customer/brand owner.
- Distinguish from: 简单现货采购选采购；研发主导且生产尚非核心时选技术开发。
