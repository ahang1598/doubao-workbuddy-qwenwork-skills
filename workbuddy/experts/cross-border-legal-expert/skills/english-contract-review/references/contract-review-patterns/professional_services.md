# Professional Services and Consulting Review Cards

中文类型：专业服务与咨询协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## PSV-R01 Scope and Work Orders / 范围与工单
- Check: 服务边界、成果、假设、客户依赖、工单签署和优先级。
- Red flags: 开放式范围；工单口头生效；供应商政策单方优先。
- Missing protection: 排除项、依赖延误后果和工单模板。
- Linked clauses: 费用、验收、变更
- Default risk: high.
- Mandatory-law check: 行业许可及专业服务强制标准。

## PSV-R02 Personnel and Relationship / 人员与关系性质
- Check: 关键人员、替换、分包、控制方式、独立承包人身份。
- Red flags: 合同称独立承包但客户控制日常工作；无限制分包。
- Missing protection: 人员资质、背景核查、替换和分类补救。
- Linked clauses: 保密、知识产权、合规
- Default risk: high.
- Mandatory-law check: 劳动关系、劳务派遣、税务和社会保险规则。

## PSV-R03 Fees and Expenses / 费用与支出
- Check: 固定价或工时制、里程碑、费率、预批准支出、税费和争议发票。
- Red flags: 费用口径不明；全部支出自动报销；争议款也触发停工。
- Missing protection: 工时证据、预算上限、发票条件和抵销。
- Linked clauses: 范围、变更、暂停
- Default risk: medium.
- Mandatory-law check: 税务、发票和跨境付款规则。

## PSV-R04 Acceptance and Change / 验收与变更
- Check: 客观标准、测试窗口、拒收说明、修复重测、变更批准。
- Red flags: 生产使用或付款即视为验收；变更无价格和工期后果。
- Missing protection: 重复失败救济、基线版本和授权矩阵。
- Linked clauses: 付款、保证、终止
- Default risk: high.
- Mandatory-law check: 特定成果的法定验收或质量要求。

## PSV-R05 Warranties and Risk Allocation / 保证与风险分配
- Check: 专业标准、合规、非侵权、赔偿、责任上限、保险。
- Red flags: 保证排除吞掉核心承诺；客户无限责任而服务方封顶过低。
- Missing protection: 返工、退款、第三方索赔抗辩和保险证据。
- Linked clauses: 验收、赔偿、责任
- Default risk: high.
- Mandatory-law check: 专业责任、消费者及不可排除责任。

## PSV-R06 Term and Exit / 期限与退出
- Check: 项目期限、便利终止、在制成果、移交、费用结算和存续。
- Red flags: 客户终止仍支付全部未发生费用；服务方可立即停工不移交。
- Missing protection: 过渡协助、文件返还、人员和知识转移。
- Linked clauses: 知识产权、保密、付款
- Default risk: high.
- Mandatory-law check: 终止补偿、人员安置和记录保存。

## Family Routing
- Aliases: consulting agreement, professional services, MSA, statement of work, 咨询协议, 服务协议.
- Typical roles: service provider, customer.
- Distinguish from: 持续在线产品访问以 SaaS 为主；以代码或技术成果开发为主时选技术开发。
