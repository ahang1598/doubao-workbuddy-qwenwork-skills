# SaaS and Cloud Services Review Cards

中文类型：SaaS 与云服务协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## SAS-R01 Architecture and Precedence / 合同架构与优先级
- Check: 主协议、订单、SLA、DPA、文档、可接受使用政策及冲突顺序。
- Red flags: 网页政策可单方更新并优先；订单与主协议冲突无规则。
- Missing protection: 版本锁定、重大变更通知和签署文件优先。
- Linked clauses: 变更、续展、终止
- Default risk: high.
- Mandatory-law check: 电子合同、消费者及格式条款规则。

## SAS-R02 Access and Suspension / 访问权与暂停
- Check: 用户、关联方、API、账号安全、使用限制和暂停触发。
- Red flags: 争议款或疑似违约即可全面立即暂停；无恢复标准。
- Missing protection: 通知、比例原则、紧急例外和恢复时限。
- Linked clauses: 付款、安全、终止
- Default risk: high.
- Mandatory-law check: 平台治理、消费者及关键服务连续性要求。

## SAS-R03 SLA and Support / 服务水平与支持
- Check: 可用率公式、监控源、排除项、维护、严重级别、响应和慢性失败。
- Red flags: 排除项吞掉承诺；服务积分是重复失败的唯一救济。
- Missing protection: 证据访问、升级、根因分析和终止阈值。
- Linked clauses: 费用、责任、业务连续性
- Default risk: high.
- Mandatory-law check: 受监管服务的可用性和外包管理要求。

## SAS-R04 Data and Security / 数据、安全与隐私
- Check: 数据角色、用途、隔离、事件、分包商、跨境、导出和删除。
- Red flags: 服务商可将客户数据用于无关目的；事件从确认后才起算。
- Missing protection: 安全附件、审计证据、可移植性和删除证明。
- Linked clauses: DPA、保密、责任、退出
- Default risk: high.
- Mandatory-law check: 适用隐私、网络安全、数据本地化和出境规则。

## SAS-R05 Fees and Service Changes / 费用与服务变更
- Check: 计费指标、超量、税费、续费调价、功能弃用和迁移。
- Red flags: 计费数据仅由服务商控制；可无条件删除关键功能。
- Missing protection: 用量证据、价格保护、等效替代和无罚退出。
- Linked clauses: 订单、续展、终止
- Default risk: medium.
- Mandatory-law check: 自动续费、价格展示及消费者规则。

## SAS-R06 Liability and Exit / 责任与退出
- Check: 服务积分、退款、赔偿、责任上限、数据导出、过渡和删除。
- Red flags: 客户暴露无上限而服务商责任极低；终止即无法取回数据。
- Missing protection: 导出窗口、可读格式、过渡协助和慢性失败权利。
- Linked clauses: SLA、数据、赔偿、存续
- Default risk: high.
- Mandatory-law check: 不可排除责任、数据事件责任及监管退出要求。

## Family Routing
- Aliases: SaaS agreement, cloud services, subscription agreement, software as a service, 云服务, 订阅协议.
- Typical roles: provider, customer.
- Distinguish from: 本地部署软件以许可为主；纯项目交付以专业服务或技术开发为主。
