# Distribution and Reseller Review Cards

中文类型：分销与经销协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## DIS-R01 Relationship and Authority / 关系性质与权限
- Check: 独立主体、代理权限、客户承诺、签约和收款权限。
- Red flags: 名称否认代理但实际可约束供应商；权限边界不明。
- Missing protection: 授权矩阵、批准证据和无权承诺责任。
- Linked clauses: 品牌、合规、赔偿
- Default risk: high.
- Mandatory-law check: 代理、商业特许和当地登记规则。

## DIS-R02 Territory, Channels and Customers / 地域、渠道与客户
- Check: 国家、线上销售、命名客户、行业、保留渠道和被动销售。
- Red flags: 地域模糊；渠道限制可能违反竞争规则。
- Missing protection: 电商、关联方、重点客户和跨区订单处理。
- Linked clauses: 排他、业绩、价格
- Default risk: high.
- Mandatory-law check: 竞争、平台、特许经营和进出口规则。

## DIS-R03 Exclusivity and Performance / 排他与业绩
- Check: 受益方、最低采购、目标、计量、补救、转非独家和供应依赖。
- Red flags: 无条件排他但供应商不保证供应；业绩算法可单方改变。
- Missing protection: 调整机制、例外、补救期和降级程序。
- Linked clauses: 预测、终止、不可抗力
- Default risk: high.
- Mandatory-law check: 竞争、经销商保护和商业代理强制规则。

## DIS-R04 Brand and Compliance / 品牌与合规
- Check: 商标范围、物料批准、广告陈述、注册、反贿赂、制裁和投诉。
- Red flags: 经销商可修改或注册商标；宣传承诺无审批。
- Missing protection: 审批时限、翻译、撤下、记录和培训。
- Linked clauses: 知识产权、赔偿、终止
- Default risk: high.
- Mandatory-law check: 广告、商标、反贿赂和消费者规则。

## DIS-R05 Pricing, Inventory and Operations / 定价、库存与运营
- Check: 建议价、折扣、预测、库存、退货、售后、税费和渠道冲突。
- Red flags: 供应商直接固定转售价；滞销库存无退出安排。
- Missing protection: 独立定价声明、库存保护和客户保证分配。
- Linked clauses: 排他、终止、付款
- Default risk: high.
- Mandatory-law check: 转售价格、税务和消费者售后规则。

## DIS-R06 Termination and Transition / 终止与过渡
- Check: 有因、便利、目标、控制权变更、清售、回购、佣金和客户交接。
- Red flags: 立即终止造成库存和客户搁置；当地强制补偿被忽略。
- Missing protection: 通知期、清售或回购、品牌撤下和数据移交。
- Linked clauses: 存续、知识产权、争议
- Default risk: high.
- Mandatory-law check: 商业代理、经销商补偿和竞争规则。

## Family Routing
- Aliases: distribution agreement, reseller agreement, dealer agreement, sales agency, 分销协议, 经销协议.
- Typical roles: supplier/principal, distributor/reseller/agent.
- Distinguish from: 双方共同投入和治理选合作合资；仅引荐或佣金服务可选专业服务并审代理风险。
