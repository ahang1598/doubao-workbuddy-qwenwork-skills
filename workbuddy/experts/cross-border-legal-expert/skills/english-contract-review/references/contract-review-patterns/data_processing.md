# Data Processing and Data Sharing Review Cards

中文类型：数据处理与数据共享协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## DPA-R01 Roles and Instructions / 角色与处理指令
- Check: 逐数据流确认角色、书面指令、独立目的和超范围处理。
- Red flags: 机械套用控制者或处理者标签；服务方保留广泛独立使用权。
- Missing protection: 角色变化通知、违法指令处理和目的限制。
- Linked clauses: 主协议、数据清单、责任
- Default risk: high.
- Mandatory-law check: 适用隐私法中的角色定义和法定义务。

## DPA-R02 Data Scope and Data Subjects / 数据与主体范围
- Check: 数据类别、敏感程度、主体、来源、地域、规模和处理期限。
- Red flags: 附件留空；敏感数据和儿童数据未区分。
- Missing protection: 处理活动表、最小化、保留周期和禁止数据。
- Linked clauses: 安全、跨境、删除
- Default risk: high.
- Mandatory-law check: 敏感个人信息、儿童信息及行业数据规则。

## DPA-R03 Security and Incidents / 安全与事件
- Check: 技术组织措施、认证、访问控制、加密、事件起算、通知内容和协作。
- Red flags: 仅承诺合理安全；事件通知从最终确认后起算且无最迟期限。
- Missing protection: 基线控制、证据更新、分阶段通知和根因报告。
- Linked clauses: 责任、审计、业务连续性
- Default risk: high.
- Mandatory-law check: 法定安全义务和事件报告期限。

## DPA-R04 Subprocessors / 分处理者
- Check: 名单、服务地点、等效义务、通知、异议和替代方案。
- Red flags: 无限制新增分处理者；客户异议只能接受或终止且无退款。
- Missing protection: 变更通知、客观异议、替代服务和责任保留。
- Linked clauses: 跨境、安全、终止
- Default risk: high.
- Mandatory-law check: 分处理委托、共同处理及监管外包要求。

## DPA-R05 Transfers and Localization / 跨境与本地化
- Check: 数据存储、远程访问、传输机制、补充措施和政府访问请求。
- Red flags: 笼统全球处理；无有效传输机制或本地化安排。
- Missing protection: 传输影响评估、地点清单和机制失效补救。
- Linked clauses: 分处理者、安全、政府披露
- Default risk: high.
- Mandatory-law check: 数据出境、本地化和国家安全审查规则。

## DPA-R06 Audit, Deletion and Liability / 审计、删除与责任
- Check: 审计证据、现场审计、协助、返还删除、证明、赔偿和上限。
- Red flags: 审计权不可使用；终止后无限保留；隐私责任完全排除。
- Missing protection: 分层证据、删除例外、协助费用和责任协调。
- Linked clauses: 主协议责任、终止、记录
- Default risk: high.
- Mandatory-law check: 法定审计、数据主体权利和记录保存义务。

## Family Routing
- Aliases: DPA, data processing agreement, data sharing agreement, privacy addendum, 数据处理协议, 数据共享协议.
- Typical roles: controller/business, processor/service provider, data recipient.
- Distinguish from: 若仅有一般保密而无持续个人信息处理，主类型选 NDA；云服务合同可将本类作为叠加。
