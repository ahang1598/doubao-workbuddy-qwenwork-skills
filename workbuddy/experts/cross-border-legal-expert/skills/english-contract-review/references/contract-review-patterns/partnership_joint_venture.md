# Partnership, Joint Venture and Strategic Collaboration Review Cards

中文类型：合作、合资与战略协作协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## JVC-R01 Purpose, Scope and Contributions / 目的、范围与投入
- Check: 合作目标、项目边界、现金、人员、资产、许可和投入时点。
- Red flags: 仅写共同合作但无可执行投入；投入价值和所有权不明。
- Missing protection: 投入清单、依赖、迟延后果和额外投入机制。
- Linked clauses: 治理、经济、退出
- Default risk: high.
- Mandatory-law check: 合伙、合资、外商投资及行业准入规则。

## JVC-R02 Governance and Authority / 治理与权限
- Check: 委员会组成、表决、保留事项、授权、记录、关联交易和合规。
- Red flags: 一方名义平等但拥有单方控制；代表可无限对外承诺。
- Missing protection: 法定人数、利益冲突、授权矩阵和会议记录。
- Linked clauses: 死锁、预算、责任
- Default risk: high.
- Mandatory-law check: 公司治理、合伙责任和授权规则。

## JVC-R03 Economics and Accounting / 经济安排与核算
- Check: 收入、成本、预算、费用、利润分配、审计、税务和资金保管。
- Red flags: 收入定义不完整；成本可由一方单方计入。
- Missing protection: 会计政策、审批阈值、审计和税务分配。
- Linked clauses: 投入、治理、退出
- Default risk: high.
- Mandatory-law check: 税务、外汇、财务和反洗钱规则。

## JVC-R04 IP, Data and Opportunities / 知识产权、数据与商业机会
- Check: 背景权利、共同成果、数据、品牌、机会归属和持续许可。
- Red flags: 合作成果一概共同所有但无管理机制；机会条款过度扩张。
- Missing protection: 分类权属、使用许可、申请控制和退出许可。
- Linked clauses: 保密、竞争、终止
- Default risk: high.
- Mandatory-law check: 共同知识产权、数据和竞争规则。

## JVC-R05 Exclusivity, Conflicts and Compliance / 排他、冲突与合规
- Check: 竞业范围、关联方交易、反贿赂、制裁、信息隔离和审批。
- Red flags: 全球长期排他与投入不匹配；未处理竞争敏感信息。
- Missing protection: 限定领域期限、例外、洁净团队和冲突程序。
- Linked clauses: 治理、保密、终止
- Default risk: high.
- Mandatory-law check: 竞争、反贿赂、证券和行业监管。

## JVC-R06 Deadlock, Transfer and Exit / 僵局、转让与退出
- Check: 升级、调解、买卖机制、估值、转让限制、终止和清算。
- Red flags: 僵局只有终止但无资产分配；单方期权定价失衡。
- Missing protection: 独立估值、过渡、知识产权、客户和债务处理。
- Linked clauses: 治理、经济、争议
- Default risk: high.
- Mandatory-law check: 公司、合伙、外汇和资产转让规则。

## Family Routing
- Aliases: collaboration agreement, joint venture, strategic partnership, consortium, 合作协议, 合资协议, 联合体协议.
- Typical roles: partner, joint venturer, collaborator.
- Distinguish from: 单纯销售渠道选分销；形成公司或证券权益时叠加投资并购。
