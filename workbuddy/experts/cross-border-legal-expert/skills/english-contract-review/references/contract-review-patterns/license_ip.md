# Software and IP License Review Cards

中文类型：软件与知识产权许可协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## LIC-R01 Licensed Assets and Title / 许可资产与权属
- Check: 资产清单、版本、登记、文档、第三方组件、权属链和排除项。
- Red flags: 许可对象无法识别；以合同陈述代替权属证明。
- Missing protection: 资产附表、登记信息、开源和第三方材料清单。
- Linked clauses: 陈述保证、赔偿、交付
- Default risk: high.
- Mandatory-law check: 权属、登记、商誉和法定许可限制。

## LIC-R02 Grant Architecture / 许可授予结构
- Check: 授权人、被授权人、用途、地域、领域、期限、排他、转让和转许可。
- Red flags: 授权范围藏在定义中；权利方向反转；排他无保留权。
- Missing protection: 关联方、承包商、托管、备份和灾备使用。
- Linked clauses: 费用、限制、终止
- Default risk: high.
- Mandatory-law check: 竞争、登记、用尽和不可放弃使用权。

## LIC-R03 Restrictions / 使用限制
- Check: 复制、修改、反向工程、基准测试、通知、出口和安全限制。
- Red flags: 限制与法定互操作或研究权冲突；限制超出许可资产。
- Missing protection: 备份、支持、合规测试和法律保留。
- Linked clauses: 授权、审计、终止
- Default risk: high.
- Mandatory-law check: 反向工程、竞争、出口和消费者规则。

## LIC-R04 Ownership and Improvements / 权属与改进
- Check: 背景知识产权、成果、反馈、修改、改进和共同开发。
- Red flags: 一条笼统权属句吞并无关背景资产；未处理共同成果。
- Missing protection: 回授许可、人员转让、登记协作和独立开发。
- Linked clauses: 开发、保密、终止
- Default risk: high.
- Mandatory-law check: 委托开发、职务成果、共同权利及登记规则。

## LIC-R05 Control and Enforcement / 控制与维权
- Check: 申请、维护、费用、监控、起诉资格、和解、收益和协作。
- Red flags: 权利人可放弃或不利和解；被许可人无通知或介入权。
- Missing protection: 协商、同意、接管、费用和收益分配。
- Linked clauses: 权属、赔偿、终止
- Default risk: high.
- Mandatory-law check: 诉权、登记维护、和解及竞争限制。

## LIC-R06 Economics, Audit and Exit / 费用、审计与退出
- Check: 许可费、版税、报表、审计限制、库存清售、删除和过渡。
- Red flags: 无限审计；立即停止导致业务中断；费用口径不闭合。
- Missing protection: 币种、扣除项、逾期、清售期和托管。
- Linked clauses: 授权、责任、终止
- Default risk: high.
- Mandatory-law check: 预提税、外汇、许可备案及终止后使用权。

## Family Routing
- Aliases: software license, IP license, trademark license, patent license, 软件许可, 知识产权许可.
- Typical roles: licensor, licensee.
- Distinguish from: 资产所有权发生转移时可能属于投资并购或知识产权转让；在线访问以 SaaS 为主。
