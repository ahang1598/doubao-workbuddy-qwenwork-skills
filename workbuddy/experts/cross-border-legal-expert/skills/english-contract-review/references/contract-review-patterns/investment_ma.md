# Investment, Shareholders and M&A Review Cards

中文类型：投资、股东与并购协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## IMA-R01 Structure, Parties and Securities / 交易结构、主体与证券
- Check: 股权或资产、工具类型、发行主体、卖方、受益所有人、监管身份和授权。
- Red flags: 名为合作实为证券发行；签约主体不拥有目标资产。
- Missing protection: 结构图、资本表、权属证明和批准清单。
- Linked clauses: 价格、交割、陈述
- Default risk: high.
- Mandatory-law check: 公司、证券、外商投资、反垄断和行业准入。

## IMA-R02 Valuation, Price and Adjustments / 估值、价格与调整
- Check: 估值口径、上限、折扣、对价、营运资金、锁箱、托管和计算示例。
- Red flags: 转换或调整公式在边界场景失效；同一指标多种定义。
- Missing protection: 情景计算、会计政策、争议专家和付款顺序。
- Linked clauses: 交割、税务、赔偿
- Default risk: high.
- Mandatory-law check: 税务、外汇、会计和定价监管。

## IMA-R03 Conditions and Closing / 先决条件与交割
- Check: 批准、尽调、第三方同意、融资、文件、长停日、满足和放弃。
- Red flags: 条件完全由一方满意决定；交割文件与权利转移不同步。
- Missing protection: 责任方、证据、部分放弃限制和交割清单。
- Linked clauses: 陈述、终止、过渡
- Default risk: high.
- Mandatory-law check: 登记、审批、反垄断和证券交割规则。

## IMA-R04 Representations and Disclosure / 陈述保证与披露
- Check: 基础与业务陈述、知情、重大性、披露函、重复、存续和保险。
- Red flags: 披露标准过宽导致陈述失效；数据室自动全面披露。
- Missing protection: 具体披露、更新义务、索赔时限和保留责任。
- Linked clauses: 赔偿、交割、责任
- Default risk: high.
- Mandatory-law check: 欺诈、证券披露和不可排除责任。

## IMA-R05 Covenants, Indemnity and Remedies / 承诺、赔偿与救济
- Check: 过渡期经营、禁止事项、赔偿、门槛、上限、排他救济和特定履行。
- Red flags: 一般责任上限意外限制产权或欺诈索赔；抗辩控制失衡。
- Missing protection: 索赔程序、抵销、托管、特别赔偿和损失减轻。
- Linked clauses: 陈述、价格、争议
- Default risk: high.
- Mandatory-law check: 违约金、欺诈、税务和第三方索赔规则。

## IMA-R06 Governance, Conversion and Exit / 治理、转换与退出
- Check: 董事席位、保留事项、信息权、转换、稀释、优先权、转让和退出。
- Red flags: 转换顺序不闭合；小股东承担义务但无信息或退出权。
- Missing protection: 资本表示例、失效机制、跟售拖售和清算顺序。
- Linked clauses: 公司章程、融资、争议
- Default risk: high.
- Mandatory-law check: 公司治理、证券、外汇和股东权利规则。

## Family Routing
- Aliases: share purchase agreement, asset purchase agreement, shareholders agreement, SAFE, convertible note, 股权投资, 并购协议, 股东协议.
- Typical roles: buyer/investor, seller/founder, company/target.
- Distinguish from: 纯债务融资选融资担保；仅合作不取得权益或资产控制选合作合资。
