# NDA and Confidentiality Review Cards

中文类型：保密协议

These internal cards are general issue-spotting aids. Apply them as `[惯例]`
and verify current law for the governing law and each performance jurisdiction.

## NDA-R01 Protected Information / 保密信息范围
- Check: 定义方式、标识要求、口头披露、签约前信息、关联方信息。
- Red flags: 所有信息永久保密；无合理知悉标准；定义循环。
- Missing protection: 排除项、举证标准、商业秘密单独存续。
- Linked clauses: 目的、期限、返还销毁
- Default risk: high.
- Mandatory-law check: 商业秘密、个人信息及证券监管披露规则。

## NDA-R02 Purpose and Use / 目的与使用限制
- Check: 允许目的、内部使用、模型训练、基准测试、反向工程。
- Red flags: 允许使用范围超过拟议交易；默认取得知识产权许可。
- Missing protection: 无许可保留、书面例外和用途变更机制。
- Linked clauses: 知识产权、代表人、救济
- Default risk: high.
- Mandatory-law check: 竞争、反向工程及数据使用的强制性限制。

## NDA-R03 Representatives / 代表人与下游披露
- Check: 知悉必要、员工顾问关联方范围、下游义务和责任标准。
- Red flags: 关联方无限披露；对无法控制的第三方承担无条件责任。
- Missing protection: 等效义务、执行义务及顾问例外。
- Linked clauses: 定义、必需披露、赔偿
- Default risk: medium.
- Mandatory-law check: 律师等专业保密义务及劳动用工规则。

## NDA-R04 Exclusions and Compelled Disclosure / 排除项与强制披露
- Check: 既有知悉、公开信息、独立开发、第三方来源、法律要求披露。
- Red flags: 因接收方违约而公开仍被排除；未限制披露范围。
- Missing protection: 允许时提前通知、仅披露必要部分、保护令协助。
- Linked clauses: 代表人、救济、通知
- Default risk: high.
- Mandatory-law check: 监管、法院和证券披露义务。

## NDA-R05 Duration and Return / 期限与返还销毁
- Check: 协议期限、普通信息保护期、商业秘密、备份和法定留存。
- Red flags: 普通信息无期限；要求立即删除不可访问备份。
- Missing protection: 留存副本继续保护、删除证明和例外。
- Linked clauses: 终止、存续、审计
- Default risk: medium.
- Mandatory-law check: 记录保存、诉讼保全和商业秘密期限。

## NDA-R06 Remedies and Boilerplate / 救济与通用条款
- Check: 衡平救济、损害赔偿、无交易义务、保证排除、准据法和论坛。
- Red flags: 自动授予禁令；未确定准据法却断言救济。
- Missing protection: 送达、费用、转让和完整协议安排。
- Linked clauses: 责任、争议、签署
- Default risk: high.
- Mandatory-law check: 禁令、违约金、限制性约定及争议条款效力。

## Family Routing
- Aliases: NDA, CDA, mutual NDA, one-way NDA, 保密协议, 保密承诺.
- Typical roles: disclosing party, receiving party.
- Distinguish from: 若核心是持续数据处理而非信息披露，主类型选数据处理；若保密仅为主交易附件，作为叠加类型。
