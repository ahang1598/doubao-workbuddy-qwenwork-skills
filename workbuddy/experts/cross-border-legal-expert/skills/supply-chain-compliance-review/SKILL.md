# 供应链合规审查

> **核心定位**：供应链合规"扫描仪"——审查UFLPA强迫劳动风险+供应商制裁风险+FDPR适用性，生成多级供应链地图+风险评分+合规承诺书模板。

---

## 模块一：法律合规与风险声明

**免责声明**：本技能为AI辅助工具，产出内容不构成正式法律意见或供应链合规审计报告。审查结论需经贸易合规律师审核后方可用于正式合规文件。使用者应结合企业实际供应链情况进行独立判断。

**适用法域**：美国（UFLPA/EAR/OFAC法规）+ 欧盟（CSDDD/冲突矿产法规）+ 中国（出口管制法/反外国制裁法/反外国不当域外管辖条例/产业链供应链安全规定）。跨法域审查需标注各法域适用范围，并特别标注"双轨合规冲突"场景（见legal-references.md §7）。

**风险等级**：L3（供应链合规遗漏可能导致CBP扣货/OFAC/BIS执法处罚）

### 风险分级机制

| 等级 | 触发条件 | 行为约束 |
|------|---------|---------|
| L1 | 供应链数据完整、Tier层级清晰 | 正常输出 |
| L2 | 部分层级数据缺失、需补全 | 标注信息缺口，限制确定性结论 |
| L3 | 供应链数据严重缺失/涉及UFLPA高风险/制裁匹配 | SOFT_DEGRADED降级，硬拒绝 |

### SOFT_DEGRADED 降级机制（C+D+G 最小骨架）

> 遵循 `base/shared/risk-rules-common.md` C/D/G 骨架定义，以下为本技能特化。

| 层 | 内容（本技能特化） | 说明 |
|----|------|------|
| C（缺失信息清单） | 列出缺失的供应链层级/供应商/地区信息+已识别风险（不含合规承诺书模板） | 避免在数据不足时给出不可靠模板 |
| D（治理与禁区声明） | 声明降级原因+供应链层级缺口+本次输出覆盖范围 | "因Tier-2/Tier-3数据缺失，以下分析仅覆盖Tier-1" |
| G（可执行下一步） | 供应链数据补全指引+推荐专业服务机构+补全后重新审查 | 建议用户补全后重新审查 |

**核心法律依据**：见 `references/legal-references.md`

## 模块二：快速开始

**最小示例**：

```
用户输入：我司生产消费电子产品，供应链含Tier-1供应商10家（中国/越南/马来西亚）、Tier-2约50家、Tier-3不详。产品含美国技术组件。请做供应链合规审查。
预期输出：多级供应链地图 + 各供应商风险评分 + UFLPA高风险标注 + FDPR适用性分析 + 合规承诺书模板
```

## 模块三：核心参数与法律约束

| 参数 | 类型 | 法律含义 | 必填 |
|------|------|---------|------|
| company_profile | text | 企业主体信息 | 是 |
| supply_chain_data | text | 供应链数据（供应商列表+层级+产品/材料+地区） | 是 |
| product_info | text | 产品信息（含原材料来源国家） | 是 |
| target_markets | enum | 目标市场：US/EU/CN/multi | 否(默认US) |
| screening_results | text | 制裁筛查结果（来自上游sanctions-list-batch-screening） | 否 |
| existing_commitments | text | 现有供应商合规承诺 | 否 |
| audit_scope | enum | 审查范围：UFLPA/sanctions/forced_labor/FDPR/all | 否(默认all) |
| tier_depth | number | 供应链层级深度（默认3层） | 否(默认3) |

## 模块四：输出格式与质量标准

**输出格式**：HTML（C-Professional，主格式，支持供应链地图可视化+风险色标）+ Markdown（辅格式）

**核心输出块**（10个，与 `references/output-spec.md` §2 骨架对齐）：

| # | 输出块 | 内容 |
|---|--------|------|
| O1 | 执行摘要 | 审查范围+供应商总数+各Tier覆盖+总体风险评级（高/中/低）+核心建议 |
| O2 | 多级供应链地图 | Tier-1/Tier-2/Tier-3供应商可视化+地区+产品+关键节点 |
| O3 | UFLPA合规审查结果 | 高风险地区标注+rebuttable presumption分析+溯源评估 |
| O4 | 供应商制裁风险评估 | 制裁筛查结果整合+50%规则分析+问题供应商清单 |
| O5 | FDPR适用性分析 | 美国技术含量+FDPR适用判定+供应链影响范围 |
| O6 | 供应商风险评分表 | 每个供应商综合评分（地区/行业/制裁/透明度/FDPR五维度）+高风险清单 |
| O7 | 合规承诺书模板 | 供应商合规承诺书（含UFLPA/制裁/强迫劳动条款） |
| O8 | 依据追踪表 | 每项结论对应的法条/规范来源 |
| O9 | 供应链合规改进建议 | 短期措施+中长期改进路线图+持续监控建议 |
| O10 | 下一步行动建议 | 基于审查结果的可执行行动项 |

**质量检查项**：

> 完整质量检查清单见 `references/output-spec.md` QC-01~QC-10。本技能额外强制检查项：
> - UFLPA 2025 Strategy新增5个优先行业必须识别（烧碱/铜/锂/红枣/钢铁）
> - SOFT_DEGRADED时禁止生成合规承诺书模板

**写作红线**：

> 本技能遵守 `base/shared/writing-redlines.md` 全部11条通用红线。技能专属禁止事项（禁止代CBP裁定/禁止编造供应商/禁止虚假声明/禁止混入sanctions筛查/rebuttable presumption不可缺失/禁止双轨合规替用户决策/禁止遗漏2025 Strategy新增行业等）见 `rules/risk-framework.md` HR-01~HR-03 + RC-01~RC-10。偏离项见 `references/output-spec.md` §4。

## 模块五：常见问题

**Q1**：UFLPA可反驳推定如何分析？UFLPA第2条规定：全部新疆生产货物推定为强迫劳动生产，进口商需提供"明确和令人信服的证据"反驳推定。本技能分析企业供应链是否触发推定、反驳证据可行性和供应链溯源建议，但不代替CBP做裁定。**注意**：截至2025年8月，UFLPA实体清单已扩至144家实体，优先行业从6个增至14个（2022年6个→2024年3个→2025年5个新增），含烧碱/铜/锂/红枣/钢铁等新行业。

**Q5**：中国反制裁法与外国制裁合规如何交叉？企业可能同时面临UFLPA/OFAC合规要求和中国《反外国制裁法》（2021年）/《实施规定》（803号令，2025年3月）/《反外国不当域外管辖条例》（835号令，2026年4月）的合规要求。遵守外国制裁可能违反中国反制裁法（构成"歧视性限制措施"），遵守中国反制裁可能违反外国制裁。**本技能仅标注冲突场景，不替用户做合规策略决策**——冲突标注为"[⚠️双轨合规冲突]"，用户应寻求专业律师意见。

**Q2**：与sanctions-list-batch-screening如何衔接？本技能负责供应链合规审查（UFLPA+FDPR+强迫劳动），sanctions-list-batch-screening负责名单匹配筛查。本技能可调用上游筛查结果整合到供应商风险评分中，但不执行名单匹配本身。

**Q3**：Tier-2/Tier-3数据缺失如何处理？标注层级缺口，仅对已有数据层级执行审查。缺失层级标注为"[数据缺失，需补全]"，降级时仅输出已覆盖层级审查结果+降级声明。

**Q4**：合规承诺书模板是否可直接使用？模板为参考范本，需根据企业实际供应链情况调整，并经贸易合规律师审核后方可正式使用。
