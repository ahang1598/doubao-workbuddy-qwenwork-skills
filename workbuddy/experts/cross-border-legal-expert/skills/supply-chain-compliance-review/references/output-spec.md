# 输出规格 — supply-chain-compliance-review

> 版本：1.2.0 | 更新日期：2026-06-28

---

## 1. 输出格式

HTML（C-Professional，主格式）+ Markdown（辅格式）

## 2. 输出骨架结构

```
1. 执行摘要
   1.1 供应链合规风险总体评级（高/中/低）
   1.2 关键风险点数量
   1.3 核心建议

2. 供应链地图
   2.1 多级供应链可视化（Tier-1/Tier-2/Tier-3）
   2.2 地理分布图
   2.3 关键节点标注

3. UFLPA合规审查
   3.1 高风险地区识别
   3.2 强迫劳动红旗信号检测
   3.3 Rebuttable Presumption分析
   3.4 供应链溯源建议

4. 供应商制裁风险评估
   4.1 制裁筛查结果整合
   4.2 50%规则分析
   4.3 问题供应商清单

5. FDPR供应链适用性分析
   5.1 美国技术/软件在供应链中的使用
   5.2 外国直接产品识别
   5.3 FDPR管辖判定

6. 供应商风险评分
   6.1 风险评分矩阵（地区/行业/制裁/透明度/FDPR适用）
   6.2 逐供应商评分
   6.3 高风险供应商清单

7. 供应商合规承诺书模板
   7.1 承诺书模板
   7.2 使用说明
   7.3 定制化建议

8. 依据追踪表
   8.1 审查结论→法条/规范来源映射
   8.2 引用来源标注

9. 供应链合规改进建议
   9.1 短期措施
   9.2 中长期改进路线图
   9.3 持续监控建议

10. 下一步行动建议
```

## 3. 质量检查项

| # | 检查项 | 通过条件 |
|---|--------|---------|
| QC-01 | 供应链地图层级完整 | 至少覆盖Tier-1/Tier-2，建议Tier-3 |
| QC-02 | UFLPA高风险地区已识别 | 新疆地区及其他UFLPA高风险地区已标注 |
| QC-03 | 强迫劳动红旗信号检测完整 | 至少检测5类红旗信号 |
| QC-04 | Rebuttable Presumption分析 | 含推定适用判断和反驳路径 |
| QC-05 | 制裁筛查结果整合 | 如有上游结果已纳入分析 |
| QC-06 | FDPR适用性分析 | 外国直接产品规则已评估 |
| QC-07 | 供应商风险评分有依据 | 评分矩阵可追溯 |
| QC-08 | 合规承诺书模板完整 | 含核心承诺条款和签署要求 |
| QC-09 | 改进建议可操作 | 含短期和中长期措施 |
| QC-10 | 法条三标注完整 | 无缺失标注 |

## 4. 写作红线

本技能遵守 `base/shared/writing-redlines.md` 全部11条通用红线。

偏离项：
- WR-01 补充：风险评分不得给出"零风险"结论（绝对化表述禁令延伸）
- WR-03 补充：供应链地图（事实）与风险分析（意见）必须用分隔标记区分
- WR-05 强化：UFLPA/FDPR法规引用须标注条款号+段落
