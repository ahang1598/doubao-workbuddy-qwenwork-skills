## 1. 核心法律

### 1.1 《中华人民共和国个人信息保护法》（2021年11月1日施行）

| 条文 | 内容摘要 | 标注 |
|------|---------|------|
| 第4条 | 个人信息定义：以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。个人信息的处理包括个人信息的收集、存储、使用、加工、传输、提供、公开等 | [✅已核实] |
| 第6条 | 处理个人信息应当具有明确、合理的目的，并与处理目的直接相关。最小必要原则 | [✅已核实] |
| 第7条 | 处理个人信息应当遵循公开、透明原则，明示处理的目的、方式、范围 | [✅已核实] |
| 第8条 | 处理个人信息应当保证个人信息的质量，避免因个人信息不准确、不完整对个人权益造成不利影响 | [✅已核实] |
| 第9条 | 个人信息处理者应当对其个人信息处理活动负责，并采取必要措施保障所处理的个人信息的安全 | [✅已核实] |
| 第13条 | 处理个人信息的合法性基础：7类（同意/合同/法定职责/法定义务/突发公共卫生/公共利益/已公开） | [✅已核实] |
| 第21条 | 委托处理：委托方应与受托方订立合同，约定处理目的/期限/方式/种类/保护措施等 | [✅已核实] |
| 第23条 | 向第三方提供：应当向个人告知接收方名称/联系方式/处理目的/方式/种类，并取得单独同意 | [✅已核实] |
| 第24条 | 自动化决策：应当保证决策的透明度和结果公平公正，不得在交易条件上实施不合理的差别待遇 | [✅已核实] |
| 第25条 | 公开个人信息：应当取得个人单独同意 | [✅已核实] |
| 第28条 | 敏感个人信息定义：一旦泄露或非法使用容易导致人格尊严侵害或人身财产安全危害 | [✅已核实] |
| 第29条 | 处理敏感个人信息应当取得个人的单独同意；法律行政法规规定应取得书面同意的从其规定 | [✅已核实] |
| 第38条 | 向境外提供个人信息四条件之一：（一）安全评估；（二）认证；（三）标准合同；（四）其他 | [✅已核实] |
| 第40条 | CIIO和达到规定数量的处理者应在境内存储，确需出境应通过安全评估 | [✅已核实] |
| 第51条 | 个人信息处理者应当根据个人信息的处理目的/方式/种类以及对个人权益的影响/可能存在的安全风险等，采取下列措施确保个人信息处理活动符合法律行政法规的规定：（一）制定内部管理制度；（二）对个人信息实行分类管理；（三）采取相应的加密/去标识化等安全技术措施；（四）合理确定个人信息处理的操作权限；（五）定期对从业人员进行安全教育和培训；（六）制定并组织实施个人信息安全事件应急预案 | [✅已核实] |
| 第55条 | PIA触发场景：敏感信息/自动化决策/委托/跨境/公开/第三方提供 | [✅已核实] |
| 第56条 | PIA应包括：目的方式合法性/权益影响安全风险/保护措施合法有效与风险相适应。报告至少保存三年 | [✅已核实] |
| 第66条 | 行政处罚：情节特别严重的，5000万元以下或上一年度营业额5%以下 | [✅已核实] |

### 2.2 《网络数据安全管理条例》（国务院令第790号，2025年1月1日施行）

> **🔴 关键法规**：本条例第五章"网络数据跨境安全管理"是数据出境安全评估的最新行政法规依据，与部门规章（安全评估办法/促进规定）形成上下位法配合。

| 条文 | 内容摘要 | 标注 |
|------|---------|------|
| 第34条 | 国家网信部门统筹协调有关部门建立国家数据出境安全管理专项工作机制，负责研究制定相关政策及协调处理重大事项 | [✅已核实] |
| 第35条 | 个人信息出境8种法定条件：（一）安全评估；（二）认证；（三）标准合同；（四）订立/履行合同确需；（五）跨境人力资源管理确需；（六）法定职责/义务；（七）紧急情况保护生命健康财产安全；（八）其他 | [✅已核实] **与PIPL第38条衔接** |
| 第36条 | 中国缔结或参加的国际条约、协定对个人信息出境条件有规定的，可以按其规定执行 | [✅已核实] **涉外法域衔接条款** |
| 第37条 | **重要数据出境安全评估**：境内运营中收集和产生的重要数据确需向境外提供的，必须通过国家网信部门组织的数据出境安全评估。豁免情形：已被识别申报但未被相关地区部门告知或公开发布为重要数据的，不需要将其作为重要数据申报数据出境安全评估 | [✅已核实] **🔴核心法条——重要数据零阈值触发** |
| 第38条 | 通过安全评估后向境外提供个人信息和重要数据时，不得超出评估时明确的目的、方式、范围、种类和规模 | [✅已核实] |
| 第39条 | 防范处置跨境安全风险。禁止提供专门用于破坏、避开技术措施的程序/工具；明知他人从事此类活动的不得提供技术支持或帮助 | [✅已核实] |
| 第45条 | 大型网络平台服务提供者跨境提供网络数据，必须遵守国家数据跨境安全管理要求，健全相关技术和管理措施，防范跨境安全风险 | [✅已核实] **大型平台专项义务** |

## 3. 部门规章

### 3.1 《数据出境安全评估办法》（国家互联网信息办公室令第11号，2022年9月1日施行）

| 条文 | 内容摘要 | 标注 |
|------|---------|------|
| 第4条 | 应申报安全评估的情形（已被《促进规定》修订阈值，实际适用见§3.2第7条） | [✅已核实] |
| 第5条 | **申报前应开展数据出境风险自评估**，6大重点评估事项：（一）出境必要性；（二）数据类型范围数量；（三）境外接收方基本情况；（四）境外法律环境；（五）数据安全保护措施；（六）合同法律文件 | [✅已核实] **核心法条** |
| 第6条 | 申报材料：申报书+自评估报告+法律文件+其他 | [✅已核实] |
| 第7条 | 网信部门收到申报后7个工作日内确定是否受理 | [✅已核实] |
| 第8条 | 评估重点：出境必要性+数据范围+接收方+境外法律环境+保护措施+合同 | [✅已核实] |
| 第14条 | 评估结果有效期2年（已被《促进规定》第9条修订为3年，实际适用见§3.2第9条） | [✅已核实] |
