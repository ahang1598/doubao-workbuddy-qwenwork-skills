## 版本：v2.0.0

## 输出格式

### 双产物
- **HTML**（C-Professional）：浏览器打开即渲染，含时间线图表+侧栏导航
- **Markdown**：纯文本版本，便于编辑与内部分发

### HTML规格
- 内联样式铁律（禁止CSS class/外部样式表）
- Richee Design Token色彩体系
- 含打印适配（@page + @media print）
- 含侧栏导航（9个输出块快速跳转）
- 含法规变更时间线（Mermaid或HTML timeline）

### 客户简报独立产物（O7）
- **格式**：独立Markdown文件（中文版+英文版）
- **长度**：≤2页（每语言版本）
- **用途**：可直接对外发送给客户
- **命名**：`client-briefing-CN.md` + `client-briefing-EN.md`

## 输出结构（9个块）

### O1：法规变更中文摘要
- 法规标题（中英文对照）
- 法规编号/来源
- 发布日期+生效日期
- 法规状态（✅final rule / 📋proposed rule）
- 核心变化概要（3-5条要点）
- 公众评论截止日期（proposed rule适用）

### O2：法规变更内容解读
- 逐条解读变更要点
- 原文关键段落引用（英文原文+中文翻译）
- 变更前后对照（修订类法规）
- 专业术语中文翻译对照表
- 解读不确定性标注[⚠️待律师确认]

### O3a：通用影响分析（v2.0.0从O3拆分）
- 受影响产品清单（ECCN→产品→影响类型）
- 受影响市场清单（国家/地区→影响类型）
- 受影响交易方清单（名单新增/移除）
- 许可证影响（新增要求/放松要求/政策变更）
- 影响程度标注（🔴直接影响 / 🟡间接影响 / ⚪暂无影响）
- **说明**：通用影响分析不依赖客户画像，适用于所有企业

### O3b：客户特定影响映射（v2.0.0新增）
> **依赖**：`client_profile`（轻量版客户画像）。缺失时本块标注"待补充客户画像后生成"。

- **客户业务场景影响路径**——将 O3a 通用影响精准映射到客户实际业务
  - 示例："此变更影响客户沙特项目的设备出口许可（客户行业：半导体，目标市场含沙特）"
- **进行中交易/项目影响**——标注哪些客户在途交易受影响
  - 示例："越南封装基地的设备采购合同需重新评估"
- **与客户现有合规制度的差距**
  - 示例："客户已有EAR内控制度，但缺少新增§744.21的筛查节点"
- **禁运国家交叉检查**——变更涉及的受限制国家与客户 `blocked_countries` 的交叉
  - 示例："变更新增对俄限制，客户blocked_countries已含俄罗斯，无新增风险"
- **客户特定行动优先级**——基于客户画像重新排序行动建议

### O4：多法域法规冲突点标注（v2.0.0增强——含冲突处置决策路径）
- 冲突点列表（变更法域法规 vs 对冲法域法规）
- 每个冲突点含：
  - 变更法域法规条款（如EAR/OFAC/EU Council/UK OFSI/UN SC）
  - 对冲法域法规条款（如中国出口管制法/阻断法/反制裁法/不可靠实体清单）
  - 冲突性质（管辖权冲突/合规义务冲突/制裁对象冲突/多法域制裁叠加）
  - 企业双重合规困境
  - 冲突缓解路径建议
- **v2.0.0新增——冲突处置决策路径**（每个冲突点须含）：
  - **冲突紧急程度分级**：
    - 🔴立即决策——双方法域均有即时处罚风险（如OFAC制裁 vs 阻断法禁令）
    - 🟡评估窗口内决策——一方有评估缓冲期
    - ⚪持续关注——冲突存在但无即时处罚风险
  - **历史执法案例参考**——有无先例？（如阻断法首个禁令：商务部公告2026年第21号）
  - **豁免/许可申请路径**——如OFAC通用许可、中国反制裁法豁免、阻断法报告豁免
  - **最坏情景预判**——双方法域同时处罚的风险评估

### O5：行动建议
- 分类复核建议（受影响ECCN须重新评估分类）
- 许可申请调整建议（新增许可证要求/现有许可证受影响）
- 名单筛查更新建议（Entity List/SDN/不可靠实体清单更新）
- 合规制度修订建议（内部控制/培训/审计）
- 每条建议须与O3a/O3b影响分析一对一匹配
- 优先级标注（🔴紧急 / 🟡近期 / ⚪关注）
- **v2.0.0新增——制裁名单筛查衔接提示**：
  - 若 change_type=list_update 或 regulation_category=sanctions_list，须提示"是否对客户现有交易方进行名单重新筛查"
  - 衔接说明："本技能提供影响分析，实际名单筛查请使用专业名单筛查系统"

### O6：法规变更时间线（v2.0.0增强——含战略窗口期）
- 发布日期→公众评论期→生效日期→企业响应窗口
- 关键节点标注
- 企业行动截止日期提醒
- **v2.0.0新增——战略窗口期建议**（涉外律师视角的战略价值挖掘）：
  - **过渡期利用**——新规生效前可加速出货/完成在途交易
  - **祖父条款评估**——变更是否有祖父条款保护既有交易
  - **提前许可申请**——新规生效前提前申请许可证是否更有利
  - **合规制度调整窗口**——在生效日前完成内控制度修订
  - 示例："新规2026-08-01生效，建议7月15日前完成在途设备出货，7月20日前提交许可申请"

### O7：客户简报（v2.0.0新增——中英文双语独立产物）
> **定位**：可直接对外发送给客户的简报，区别于O1-O6内部工作底稿。依赖 `client_profile`。

- **中文版**（`client-briefing-CN.md`）：
  1. **核心变化**（≤3句话，非技术性表述）
  2. **对贵司的影响**（基于O3b客户特定影响，3-5条要点）
  3. **建议行动**（3-5条，按优先级排序，含时间要求）
  4. **风险提示**（1-2条关键风险，含免责声明）
  5. **联系我们**（占位符）
- **英文版**（`client-briefing-EN.md`）：
  - 与中文版结构一致，英文表述
  - 法规原文术语保留英文
- **长度约束**：每语言版本≤2页（约800字中文/600词英文）
- **语气约束**：客户简报面向非法律专业人员，须避免过度技术性表述

### O8：检索策略与可追溯性附录（v2.0.0新增）
> **定位**：涉外律师工作留痕要求——每一份合规意见都要能追溯到数据源。

- **检索策略记录**：
  - 检索模式（全量/增量）
  - 检索时间范围（start - end）
  - 检索关键词列表
  - 数据源子集（按regulation_category选择的数据源列表）
  - 检索时间戳
- **检索结果可追溯性**（每条检索结果须含）：
  - 源URL
  - 访问时间戳
  - 原文关键段落引用（英文原文快照）
  - 数据源最后更新日期（如OFAC清单的Last Updated日期）
- **检索完整性声明**（v2.0.0核心合规要求）：
  - 声明文本："本检索为辅助发现手段，不替代专业合规监控服务，可能存在遗漏"
  - 检索结果置信度标注：
    - 🟢高置信度——API结构化数据检索（如OFAC List API）
    - 🟡中置信度——网页非结构化检索（如Federal Register网页）
    - 🔴低置信度——基于摘要/二手来源推断
  - 漏检风险等级（来自input-spec.md差异化处置矩阵）
  - 建议补充检索的数据源（如有）
- **增量检索记录**（如提供last_scan_timestamp）：
  - 上次检索时间戳
  - 本次检索时间戳
  - 增量变更条数

## 质量检查项（Phase 6）

| ID | 检查项 | 阻断条件 |
|----|--------|---------|
| QC-01 | 法规解读与原文一致 | 不一致→阻断 |
| QC-02 | final/proposed已区分 | 未区分→阻断 |
| QC-03 | 生效日期标注准确 | 错误→阻断 |
| QC-04 | 影响分析有依据 | 无依据→阻断 |
| QC-05 | 行动建议与影响匹配 | 不匹配→阻断 |
| QC-06 | 多法域冲突点已标注 | 遗漏→警告 |
| QC-07 | 中文翻译准确性 | 重大偏差→阻断 |
| QC-08 | O3b客户特定影响映射已生成（如提供client_profile） | 缺失→阻断 |
| QC-09 | O4冲突处置决策路径完整（紧急程度+历史案例+豁免路径+最坏情景） | 不完整→阻断 |
| QC-10 | O7客户简报中英文双语均已生成 | 缺失→阻断 |
| QC-11 | O8检索结果可追溯性记录完整（源URL+时间戳+原文快照） | 不完整→阻断 |
| QC-12 | 检索完整性声明已包含 | 缺失→阻断 |
| QC-13 | 增量检索记录正确（如提供last_scan_timestamp） | 错误→警告 |
| QC-14 | 制裁名单筛查衔接提示已包含（list_update场景） | 缺失→警告 |

## 写作红线

1. 禁止代替监管机构做法规解释
2. 禁止法规变更信息不足时强行解读
3. 禁止出具正式法律意见
4. 禁止混淆final rule与proposed rule
5. 禁止泛化行动建议（须与影响分析匹配）
6. 禁止回避多法域法规冲突点（含EU/UK/UN制裁冲突）
7. 禁止对法规影响范围做过度解读
8. 禁止声称检索结果100%完整无遗漏（须含检索完整性声明）
9. 禁止O7客户简报使用过度技术性表述（须面向非法律专业人员）
10. 禁止O8可追溯性记录缺失源URL或访问时间戳
