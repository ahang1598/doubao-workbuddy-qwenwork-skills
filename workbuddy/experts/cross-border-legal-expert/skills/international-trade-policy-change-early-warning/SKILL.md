# 国际贸易政策变化预警

> **核心定位**：检索并解读国际贸易法规变更/制裁名单更新，生成中文法规变更简报（摘要+影响分析+行动建议+冲突点标注+客户简报+可追溯性附录），助力企业快速响应合规环境变化。
>
> **v2.0.0定位升级**：从"被动解读"升级为"检索+解读"双能力——Phase 0 可执行检索（Mode B/C/D），也可接受用户主动获取的变更信息（Mode A）。覆盖7大涉外法律领域（出口管制/制裁、跨境投资审查、数据跨境、贸易救济、反腐败、供应链合规、国际仲裁）。

## 模块1：法律合规与风险声明

### 免责声明
本技能生成的法规变更简报为信息性参考材料，不构成正式法律意见。法规解读可能存在偏差，企业应结合专业法律顾问意见做出决策。法规变更的实际影响需结合企业具体业务场景评估。

### 检索完整性声明（v2.0.0核心合规要求）
本技能 Phase 0 检索为辅助发现手段，不替代专业合规监控服务，可能存在遗漏。对于制裁名单类（sanctions_list）等极高风险法规，强烈建议使用专业合规监控服务交叉验证。本技能不保证检索结果100%完整无遗漏（HR-04）。

### 适用法域
- 美国：EAR（15 CFR Parts 730-774）、OFAC制裁法规（31 CFR Chapter V）、APA（5 USC §553）、Federal Register Act（44 USC Chapter 15）、CFIUS、FCPA
- 中国：出口管制法（2020）、两用物项出口管制条例（2024.12.1）、反外国制裁法+实施规定（国令第803号，2025.3.21）、阻断法（商务部令2021年第1号）+首个禁令（公告2026年第21号）、不可靠实体清单规定、数据出境评估
- EU：EU Council制裁法规+名单、EU FDI审查、GDPR、EU供应链法
- UK：OFSI金融制裁名单、UK Bribery Act
- UN：安理会制裁决议+名单
- 国际仲裁：ICC/SIAC/HKIAC规则
- 适用情形：企业合规解读与法规变更响应

### 风险等级
- **整体**：L2（中等风险——法规解读可能存在偏差）
- Phase 0（法规变更检索）：L2
- Phase 1（输入验证）：L1
- Phase 2（法规解读）：L2
- Phase 3（影响分析）：L2
- Phase 4（冲突点标注）：L2
- Phase 5（行动建议）：L2
- Phase 6（质量检查）：L1

### 风险分级机制
| 级别 | 含义 | 触发条件 |
|------|------|---------|
| L1 | 低风险——信息性 | 输入验证、格式检查 |
| L2 | 中风险——需律师复核 | 法规检索、解读、影响分析 |
| L3 | 高风险——可能影响决策 | 本技能无L3阶段 |

### SOFT_DEGRADED 降级机制（C+D+G）
- **C层（内容降级）**：法规原文缺失时标注[📋待补充原文]，不编造法规内容
- **D层（细节降级）**：影响范围不确定时标注"影响范围待评估"
- **G层（整体降级）**：法规变更信息严重不足且无法补全时标注"无法解读，建议咨询律师"
- **v2.0.0扩展场景**：检索结果不可信/客户画像缺失/检索不可追溯等场景的降级处理详见 `rules/risk-framework.md` SOFT_DEGRADED 章节

## 模块2：快速开始

### 一句话定位
法规变了，帮你检索+解读变化、评估影响、生成中文简报+客户简报、标注冲突点、留痕可追溯。

### 最小示例
```
输入：
  regulation_change: "BIS发布新规则，将6个ECCN条目从CCL中修订"
  change_type: "eccn_revision"
  change_source: "BIS"
  regulation_category: "export_control_rule"
  company_context: "出口3A001类设备到中东市场"
  client_profile: {industry: "半导体", target_markets: ["美国", "沙特"], blocked_countries: ["伊朗"]}

输出：
  - 法规变更中文摘要
  - 法规变更内容解读
  - 通用影响分析（O3a）+ 客户特定影响映射（O3b）
  - 多法域法规冲突点标注（含冲突处置决策路径）
  - 行动建议（含名单筛查衔接提示+战略窗口期建议）
  - 法规变更时间线（含战略窗口期）
  - 客户简报（中英文双语，≤2页）
  - 检索策略与可追溯性附录
```

## 模块3：核心参数与法律约束

### 输入参数
| 参数 | 必填 | 说明 |
|------|------|------|
| regulation_change | ✅ | 法规变更信息：来源/标题/编号/发布日期/生效日期 |
| change_type | ✅ | 变更类型：new_rule/amendment/list_update/license_policy/eccn_revision |
| change_source | ✅ | 变更来源：BIS/OFAC/Federal_Register/中国商务部/EU_Council/UK_OFSI/UN_Security_Council/CFIUS/EU_FDI/国家网信办/WTO/ICC/SIAC/HKIAC/其他 |
| regulation_category | ✅ | 法规类别（v2.0.0新增）：sanctions_list/export_control_rule/general_regulation/investment_review/data_cross_border/trade_remedy/anti_bribery/supply_chain/intl_arbitration |
| company_context | ✅ | 企业背景：主要产品/出口市场/受影响ECCN/交易方 |
| client_profile | ⬜ | 轻量版客户画像（v2.0.0新增）：客户行业/目标市场/禁运国家 |
| raw_text | ⬜ | 法规原文或摘要 |
| monitoring_period | ⬜ | 监控周期 |
| last_scan_timestamp | ⬜ | 上次检索时间戳（v2.0.0新增，增量检索） |

### 核心法律约束
1. 须区分final rule（已生效）与proposed rule（征求意见）
2. 法规生效日期须准确标注，误标可能误导企业决策
3. 中美法规冲突点须如实标注，不可回避
4. 行动建议须与影响分析匹配，不可泛化推荐
5. 法规解读不得代替监管机构的官方解释
6. **v2.0.0新增**：检索结果须包含完整性声明，不保证100%完整无遗漏
7. **v2.0.0新增**：检索结果须经用户确认后才进入解读流程（人工复核门控）
8. **v2.0.0新增**：每条检索结果须可追溯（源URL+访问时间戳+原文快照）
9. **v2.0.0新增**：制裁名单类法规须差异化处置（Mode D）

### 工作流概览
```
Phase 0 → 法规变更检索（L2）——差异化检索+完整性声明+人工复核门控+可追溯性记录
Phase 1 → 输入验证与法规变更识别（L1）
Phase 2 → 法规变更内容解读（L2）
Phase 3 → 企业影响分析（L2）——O3a通用影响+O3b客户特定影响映射
Phase 4 → 多法域法规冲突点标注（L2）——含冲突处置决策路径
Phase 5 → 行动建议生成（L2）——含名单筛查衔接+战略窗口期
Phase 6 → 质量检查与简报组装（L1）——含O7客户简报+O8可追溯性附录
```

## 模块4：输出格式与质量标准

### 输出格式
- HTML（C-Professional，浏览器打开即渲染，含时间线图表）
- Markdown（纯文本版本）
- 客户简报（独立Markdown，中英文双语）

### 输出结构（9个块）
1. **法规变更中文摘要**（标题/编号/来源/生效日期/核心变化）
2. **法规变更内容解读**（逐条解读变更要点+原文对照）
3. **通用影响分析O3a**（受影响产品/市场/交易方/许可证）
4. **客户特定影响映射O3b**（v2.0.0新增，依赖client_profile：业务场景影响路径/在途交易影响/合规制度差距/禁运国家交叉检查）
5. **多法域法规冲突点标注**（EAR/OFAC vs 中国出口管制法/阻断法/反制裁法 + EU/UK/UN制裁冲突 + **冲突处置决策路径**）
6. **行动建议**（分类复核/许可申请调整/名单筛查更新/合规制度修订 + **名单筛查衔接提示** + **战略窗口期建议**）
7. **法规变更时间线**（发布→公众评论→生效→企业响应 + **战略窗口期建议**）
8. **客户简报O7**（v2.0.0新增，中英文双语，≤2页，可直接对外发送）
9. **检索策略与可追溯性附录O8**（v2.0.0新增，检索策略记录+检索结果可追溯+完整性声明+增量检索记录）

### 质量检查项（14项）
- QC-01：法规变更解读与原文一致性
- QC-02：final rule与proposed rule已区分
- QC-03：生效日期标注准确
- QC-04：企业影响分析有依据
- QC-05：行动建议与影响分析匹配
- QC-06：多法域冲突点已标注（含EU/UK/UN制裁冲突）
- QC-07：中文翻译准确性检查
- QC-08：O3b客户特定影响映射已生成（如提供client_profile）
- QC-09：O4冲突处置决策路径完整（紧急程度+历史案例+豁免路径+最坏情景）
- QC-10：O7客户简报中英文双语均已生成
- QC-11：O8检索结果可追溯性记录完整（源URL+时间戳+原文快照）
- QC-12：检索完整性声明已包含
- QC-13：增量检索记录正确（如提供last_scan_timestamp）
- QC-14：制裁名单筛查衔接提示已包含（list_update场景）

### 写作红线
1. 禁止代替监管机构做法规解释（HR-01）
2. 禁止法规变更信息严重不足且无法补全时强行解读（HR-02）
3. 禁止出具正式法律意见（HR-03）
4. 禁止混淆final rule与proposed rule
5. 禁止泛化行动建议（须与影响分析匹配）
6. 禁止回避多法域法规冲突点（含中美+EU/UK/UN制裁冲突）
7. 禁止对法规影响范围做过度解读
8. 禁止声称检索结果100%完整无遗漏（须含检索完整性声明）
9. 禁止O7客户简报使用过度技术性表述（须面向非法律专业人员）
10. 禁止O8可追溯性记录缺失源URL或访问时间戳

## 模块5：常见问题

**Q：如何区分final rule和proposed rule？**
A：Federal Register中final rule标注"Final Rule"并有明确生效日期；proposed rule标注"Proposed Rule"并有公众评论期。本技能在Phase 2强制区分二者。

**Q：多法域法规冲突点如何标注？**
A：Phase 4逐一比对法规变更与各法域相关法规，标注具体冲突条款+冲突性质+企业合规建议+冲突处置决策路径（紧急程度+历史案例+豁免路径+最坏情景）。

**Q：Phase 0检索结果是否可靠？**
A：Phase 0检索为辅助发现手段，不替代专业合规监控服务。每条检索结果标注置信度（🟢高/🟡中/🔴低），并须经用户确认后才进入解读流程。对于制裁名单类等极高风险法规，强烈建议使用专业合规监控服务交叉验证。

**Q：client_profile轻量版包含哪些字段？**
A：仅3个关键字段：industry（客户行业）、target_markets（目标市场）、blocked_countries（禁运国家）。提供后可生成O3b客户特定影响映射；缺失时仅输出O3a通用影响分析。

**Q：增量检索如何工作？**
A：提供last_scan_timestamp（上次检索时间戳）后，Phase 0仅检索此时间戳之后的变更。缺失时执行全量检索。
