# 第四届因子大赛评分规则（0811 口径）

来源：用户提供的《因子大赛规则口径-0811.pdf》，确认日期 2026-08-11。
本文件只作研究参考；平台后台正式结算、原始精度和最新接口行为优先。

## 固定口径

- 股票池为沪深全 A / 中证全指，剔除 ST、当日停牌和当日一字板。
- 每个截面因子先做 1%--99% Winsorize，再做 Z-score；池内有效因子等权合成。
- 有效因子少于 5 个时，当月积分冻结，历史累计积分保留。
- 池统一配置 1--10 个交易日调仓周期，提交后不能修改；所有因子和组合按同一周期采样。
- 合成组合按综合因子排序持有前 10%；反向因子持有低值端。
- 单边交易成本为 0.3%；基准为中证全指。
- 每个统一调仓日生成一条 IC、RankIC、ICIR 和 IC 胜率记录；非调仓日沿用信号，不产生新的调仓统计。
- IC 使用 Pearson 相关；RankIC 使用 Spearman 相关。

## A：因子历史绩效（20%）

~~~
S_i^A = |RankIC_i| × |ICIR_i| × IC胜率_i
rawA = sum(S_i^A) / M
NA = min(max(rawA / 0.08, 0), 1) × Decay
~~~

- RankIC 是所有有效统一调仓周期 RankIC_t 的算术平均，不取月度 RankIC 均值作为 A 输入。
- ICIR = mean(IC_t) / sample_std(IC_t)，使用完整统一调仓周期 IC 序列，样本标准差 ddof=1，不年化。
- 正向因子胜率为 count(IC_t > 0.02) / count(valid IC_t)；负向因子为 count(IC_t < -0.02) / count(valid IC_t)。
- 每个因子在入池时固定使用入池日前五年历史；因子版本不变时不随自然月滚动，也不清空。
- 另外纳入该因子正式生效后的全部历史样本外记录。
- 新生效不足 6 个月时，NA 另封顶 0.70；Decay 的具体档位以平台后台确认值为准，不在本地擅自推断。

## B：样本外外推绩效（35%）

~~~
S_i^B = |RankIC_new| × |ICIR_new| × IC胜率_new
rawB = sum(S_i^B) / M
NB = min(max(rawB / 0.06, 0), 1)
~~~

- 只使用因子正式生效后新增的统一调仓周期记录。
- 样本外 ICIR、RankIC 和胜率从正式生效后持续累计，不随自然月清零。
- 公式或代码形成新版本时，原样本外序列、ICIR、胜率和 NB 重新累计；只改名称或描述不触发新版本。
- 提交前没有官方 B；本地历史区间只能作为稳健性代理，不能冒充正式 B。

## C：多头组合绩效（45%）

官方使用池内等权合成因子的月度日频组合账本：

~~~
R_p = product(1 + PortfolioReturn_daily) - 1
R_b = product(1 + BenchmarkReturn_daily) - 1

Rex_ann = [(1 + R_p)^(252 / N) - 1]
          - [(1 + R_b)^(252 / N) - 1]

SR_ann = mean(Return_daily) / sample_std(Return_daily) × sqrt(252)

rawC = max(Rex_ann, 0) / max(Turnover_month, 0.3)
       × SR_ann × (1 - 1.2 × MaxDD_month)
NC = min(max(rawC / 0.6, 0), 1)
~~~

- N 是当月组合与基准均有效的交易日数；组合和基准分别复合、分别年化，最后相减。
- Return_daily 是扣除交易成本后的组合日收益，不是每日超额收益；无风险收益按 0。
- 样本少于 2 个或样本标准差为 0 时，SR_ann = 0。
- Turnover_k = sum(abs(w_new - w_old)) / 2；Turnover_month 是当月所有统一调仓日 Turnover_k 的总和，可超过 100%。
- 非统一调仓日换手为 0；首建仓、最终清仓和现金变化按实际买卖金额计成本，不能机械乘 2。
- MaxDD_month 使用当月日频组合净值曲线；每个自然月组合和基准净值从 1 重新计算，但真实持仓跨月延续，不虚拟清仓或重复扣成本。
- 当 1 - 1.2 × MaxDD_month 小于 0 时，最终边界以平台后台实现为准；本地代理应显式标记该不确定性。
- 月末数据完整后才正式结算；缺少必要日账本的月份不入账。

MonthlyRex 仅用于展示：

~~~
MonthlyReturn_p = (1 + R_p)^(21 / N) - 1
MonthlyReturn_b = (1 + R_b)^(21 / N) - 1
MonthlyRex = MonthlyReturn_p - MonthlyReturn_b
~~~

它不能作为 Rex_ann 的输入，也不能用 (1 + MonthlyRex)^12 - 1 替代 Rex_ann。

## 综合积分、季度和年度

~~~
Comb_m = 0.20 × NA_m + 0.35 × NB_m + 0.45 × NC_m
monthly_points_m = min(Comb_m × 40000 × newcomer_bonus_m, 40000)
~~~

- 月度使用月末正式结算快照；新人加成按平台条件执行，单月封顶 40000。
- official、revised、preview 同月只保留一份：revised 替换 official；preview 只用于实时预估，不进入正式季度或年度统计。
- 缺月不补 0，只用实际存在的有效月份作为分母。
- 季度质量榜：季度内有效月末 Na 和 Nb 分别取算术平均后相加，缺月不补。
- 季度超额收益榜：每月单独计算 AnnualRex_m，再对有效月份做算术平均；不合并季度日频收益后重新年化。
- 季度稳健榜：取季度内最大月回撤所在月份 m*，RobustScore = 季度平均 SR_ann - 2 × MaxDD_month,m*。
- 年度主榜：全年各月最终积分直接相加，不把全年日数据重新合并计算一次 A/B/C。
- 页面四舍五入只影响展示，排序和积分使用后台原始精度。

## 因子生命周期与提交

- 建池当天可自由增删；提交因子池后，修改和删除仅限每月 1--3 日窗口，并受页面状态与每日 19:00 截止约束。
- 每日 19:00 前提交计入当天，19:00 后计入下一交易日；新增因子在提交后的下一个统一调仓日进入合成。
- 首个统一调仓日没有完整持有期，首条有效 IC 在再下一个统一调仓日生成。
- 删除因子后，删除前已结算历史积分保留。
- 公式或代码相同的重复因子可被自动删除；明显异常、刷量和无效因子会被人工排查。
- 因子池内因子总数不超过 50 只的限制同时适用于 Skill 辅助研发和人工手动提交。若平台另有每日新增限制，以后台最新提示为准。
- 本地 AI 辅助研发合规，由参赛者本人确认和提交，无需额外报备。

## 本地代理边界

本地可以使用 CLI 返回的统一调仓 RankIC/IC 序列做 A 稳定性分析，使用组合日账本做 C 代理。
但 CLI 没有因子池创建、平台标准化后的池级合成、动态股票池和完整月度日频账本接口，因此：

- 不能把五个单因子 C 相加或平均来声称官方 NC；
- 缺少 Pearson IC 序列时，不能计算严格的 A/B；
- 缺少组合和基准日收益时，不能计算严格的 Rex_ann；
- 所有本地结果必须标为“比赛规则代理”。
