# PandaAI Factor Online

This repository is a portable Hermes runtime entrypoint for PandaAI factor work.

Before any PandaAI factor task:

1. Read [`SKILL.md`](SKILL.md), or [`SKILL.zh-CN.md`](SKILL.zh-CN.md) for the Chinese workflow.
2. Follow its Core Workflow: preflight, login resolution, balance check, parameter agreement, and
   probe approval before any `factor_run`.
3. Keep credentials in the user's private CLI configuration. Never copy tokens into this repository,
   candidate files, prompts, or chat.

The skill is research guidance, not an investment recommendation. Competition A/B/C scoring is an
optional, explicitly selected proxy workflow; it does not replace the normal formula-first/Python-
fallback factor-mining workflow.
