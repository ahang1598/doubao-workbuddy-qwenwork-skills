# 指标术语表 (metrics-glossary)

每个绩效指标的定义、公式与中文解读。所有年化指标依赖 `periods_per_year`（简称 ppy），
**必须与序列频率一致**：日频 252、周频 52、月频 12。ppy 用错会让夏普/波动等系统性失真。

约定：`r_t` 为逐期算术收益，`n` 为期数，`ppy` 为年化期数，`rf` 为年化无风险利率（单期 = rf/ppy）。

## 收益 / 风险

| 指标 | 公式 | 解读 |
|---|---|---|
| 累计收益 | `∏(1+r_t) − 1` | 区间总回报 |
| 年化收益 | `(∏(1+r_t))^(ppy/n) − 1` | 几何年化，可复现且可比 |
| 年化波动 | `std(r) × √ppy` | 收益的年化标准差，衡量总波动 |
| 最优/最差单期 | `max(r)` / `min(r)` | 单期极值，观察尾部冲击 |

## 风险调整

| 指标 | 公式 | 解读 |
|---|---|---|
| 夏普 Sharpe | `mean(r−rf/ppy) / std(r−rf/ppy) × √ppy` | 每单位总风险的超额回报；>1 尚可，>2 优秀 |
| 索提诺 Sortino | `mean(excess) / 下行标准差 × √ppy` | 只惩罚下行波动，更贴近“亏损厌恶” |
| Calmar | `年化收益 / |最大回撤|` | 收益相对最痛回撤的性价比 |
| Omega | `Σ(r>阈值 部分) / Σ(r<阈值 损失)` | 阈值以上收益与以下损失之比，捕捉全分布信息 |

> 下行标准差：`sqrt(mean(min(excess,0)^2))`，只对低于目标的偏差取平方平均。

## 回撤

| 指标 | 定义 | 解读 |
|---|---|---|
| 回撤序列 | `nav_t / cummax(nav)_t − 1` | 每一期相对历史最高点的跌幅（≤0） |
| 最大回撤 (MDD) | `min(回撤序列)` | 最痛的一次从峰到谷跌幅 |
| 回撤持续期 | 峰值日 → 谷底日 的天数 | 下跌持续多久 |
| 恢复时间 | 谷底日 → 重回前高 的天数 | 修复损失需要多久；`None`=尚未恢复 |
| Top-N 回撤表 | 按深度排序的前 N 段回撤区间 | 定位历史最痛时段与其修复情况 |

## 分布 / 尾部

| 指标 | 公式 | 解读 |
|---|---|---|
| 偏度 Skewness | 三阶标准化矩 | <0 左偏（大跌风险），>0 右偏（大涨居多） |
| 超额峰度 Kurtosis | 四阶标准化矩 − 3 | >0 厚尾（极端事件比正态更频繁） |
| VaR(95%) | 收益 5% 历史分位数 | 95% 置信下单期最大可能损失（历史法） |
| CVaR(95%) | 最差 5% 收益的均值 | 尾部一旦发生的平均损失，比 VaR 更保守 |
| 胜率 | `mean(r>0)` | 正收益期占比 |
| 盈亏比 | `平均盈利 / |平均亏损|` | 单次盈利相对单次亏损的幅度 |

## 滚动指标

| 指标 | 说明 |
|---|---|
| 滚动夏普 | 在固定窗口内滚动计算夏普，观察风险调整收益是否稳定 |
| 滚动波动 | 滚动年化波动，识别波动率聚集期 |
| 滚动回撤 | 即逐期回撤序列，配合净值双轴图直观展示水下时段 |

> 滚动窗口默认取 `min(ppy, n//2)`，即约一年或序列一半，孰小。

## 时间聚合

| 指标 | 说明 |
|---|---|
| 月度收益矩阵 | 年×月 复利聚合，`∏(1+日收益)−1`；热力图绿涨红跌 |
| 年度收益 | 按年复利聚合 |

> 月度热力图要求序列跨度 ≥ 2 个月才有意义；跨度 ≥ 12 个月才能看出季节性。

## 相对基准（可选）

| 指标 | 公式 | 解读 |
|---|---|---|
| 超额年化 | `年化收益_策略 − 年化收益_基准` | 相对基准的年化超额 |
| 信息比率 IR | `mean(active) / std(active) × √ppy` | 每单位跟踪误差的超额，衡量主动管理效率 |
| Beta | `cov(策略,基准) / var(基准)` | 对基准的系统性暴露；1=同步，<1=防御 |
| 跟踪误差 TE | `std(active) × √ppy` | 相对基准偏离的年化幅度 |
| 相关性 | `corr(策略,基准)` | 与基准的同向程度 |

> `active_t = r_策略 − r_基准`（对齐日期后逐期主动收益）。基准与策略必须先按日期对齐再计算。

## 免责

本表仅用于绩效分析方法论说明。所有指标为历史统计，不构成任何投资建议；历史绩效不代表未来表现。
