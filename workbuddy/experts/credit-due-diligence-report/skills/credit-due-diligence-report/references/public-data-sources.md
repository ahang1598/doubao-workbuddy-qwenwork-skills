# 基于公开数据撰写贷前调查报告 — 数据源清单

> 当用户处于"行外 / demo 场景"——拿不到行内核心材料（流水、纳税表、人行征信、抵押查册）时，使用本清单替代。
>
> **重要原则：公开数据 demo 报告不替代行内正式尽调**，必须在报告抬头明确声明。

---

## 九、demo 与行内的差异速查表

| 信息维度 | 行内能拿 | Demo 能拿 | 缺口处理 |
|---------|---------|----------|---------|
| 现场走访 | ✅ | ❌ | demo 报告标注"以本行实际走访为准" |
| 银行流水 | ✅ | ❌ | 用"销售商品收到现金"代替 |
| 纳税申报表 | ✅ | ❌ | 用"已交税费"代替 |
| 企业征信 | ✅ | ⚠️ 公开部分 | 用工商 + 司法 + 公告替代 |
| 实控人个人征信 | ✅ | ❌ | demo 仅靠裁判文书 + 限高 + 被执行替代 |
| 配偶资产 | ✅ | ❌ | demo 缺失，行内必查 |
| 不动产协查 | ✅ | ❌ | demo 缺失，行内必查 |
| 抵押物权属查册 | ✅ | ❌ | demo 仅引用公告披露 |
| 内部评级 | ✅ | ❌ | 用外部评级（中诚信等）替代 |

## 使用建议

1. **demo 报告必须在抬头明确声明数据来源**
2. **每个章节标注数据来源**，让读者知道哪些是公开数据、哪些是行内补充
3. **关键人风险章节**：公开能查的全查到，行内才能查的明确列出"待行内补充"
4. **不要伪造数据**：拿不到就如实标注"需行内补充"，不要编造
