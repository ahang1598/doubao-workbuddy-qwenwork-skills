# 贷前调查报告 — 各章节填写要点

> 当撰写过程中遇到具体章节不知如何下笔时，加载本文件查询对应章节的填写要点、常见错误、数据获取方式。

---

## 第一章 受信人基本情况

**填写要点**：
- 基本信息务必与营业执照、最新工商公示信息一致；上市公司以最新年报为准
- "实控人"与"法定代表人"不一定相同，必须区分
- "股东背景与平台地位评价"是城投与民企的关键区分章节：
  - 城投：填写实控人国资层级（央/省/市/区县）、政府支持力度
  - 民企：填写实控人持股比例、家族持股、一致行动人安排
- 核心管理团队至少列出 5 人（董事长 / 总经理 / 副总 / 财务总监 / 董事会秘书）

**常见错误**：
- 把"控股股东"误写为"实控人"（控股股东可能是另一家公司，需穿透到自然人）
- 子公司只列名称不列经营数据
- 上市公司不附最新市值与流通股本

---

## 第二章 区域与宏观环境

**填写要点**：
- **城投/区域型必填**：完整填写五节，特别是 (二) 区域经济数据、(五) 区域融资环境
- **全国型上市公司**：填写 (一) 区域简介 + (五) 区域融资环境，跳过 (二)(三)(四)
- 区域经济数据建议至少 3 年趋势，识别"财政恶化"信号（一般预算下降、土地出让金断崖）
- (四) "区域内我行同层级城投存量授信"是行内场景独有，Demo 场景可标注"行内补充"

**关键数据源**：
- 区域经济：地方统计公报 / 财政预决算报告
- 政府债务余额：国务院、财政部公开数据
- 区域融资环境：21 世纪经济报道、财新等媒体公开报道

---

## 第三章 行业分析

**填写要点**：
- 必须分析营收占比 > 30% 的所有业务所处行业
- 多元化经营企业可能要分析 2-3 个行业
- 行业政策必须列出近 3 年主要政策文件 + 文件号
- 公司行业地位用市占率 / 排名 / 头部客户来佐证，不能空说"行业领先"
- 竞争对手对比必须用同口径财务数据（营收 / 毛利率 / ROE）

**AI 辅助场景**：
- 可使用券商研报、Wind 行业数据快速形成初稿
- AI 生成的行业判断必须人工核验关键数据

---

## 第四章 受信人经营情况分析

**填写要点**：
- 业务板块拆分必须与年报披露口径一致
- 至少 3 年板块对比，识别业务结构变化
- 各板块要写清楚：商业模式、上下游、定价机制、核心客户、关键风险
- "在建、拟建工程"是识别"激进扩张"的关键章节，重点关注资金来源

---

## 第五章 财务报表分析（核心章节）

**填写要点**：
- **数据至少 3 年**：少于 3 年无法看趋势
- **刚性负债必须独立列示**：识别真实有息负债压力，包括明股实债、永续债等隐藏负债
- **母公司报表**（上市公司必查）：识别"合并粉饰"——合并好看但母公司空心化
- **营收真实性核查**：至少做 2 项交叉验证

**财务异常信号清单**：
| 信号 | 含义 |
|------|------|
| 经营 CF 持续为负 + 净利润为正 | 利润含金量低、可能虚增收入 |
| 货币资金充裕 + 大量短期借款 | "存贷双高"——典型造假信号 |
| 应收账款增速 > 营收增速 | 销售质量下降 / 提前确认收入 |
| 商誉占比过高（> 净资产 30%） | 并购泡沫 / 减值压力 |
| 其他应收款异常增长 | 关联方占款 / 资金被挪用 |
| 在建工程长期挂账不转固 | 调节折旧 / 虚增资产 |
| 财务费用率明显低于行业 | 利息资本化过度 |
| 审计意见非标 | 重大问题信号 |

**Demo 场景常见做法**：
- "销售商品收到的现金"→ 替代银行流水做营收交叉
- "支付的各项税费"→ 替代纳税申报表

## 第六章 关键人 / 实控人风险分析

**填写要点**：
- **UBO 识别（25% 红线）**：穿透到最终自然人，符合反洗钱要求
- 实控人公开核查必须做齐 12 项：裁判文书 / 失信 / 限高 / 被执行 / 行政处罚 / 涉税 / 公开舆情 / 涉刑 / 配偶征信 / 不动产 / 个人征信 / 央行征信
- "💼 行内必查"项不能用公开数据替代
- 关键风险信号：
  - 股权质押率 > 50% → 重点关注
  - 股权质押率 > 80% → 重大警示
  - 频繁股权变更（12 个月内 ≥ 3 次） → 异常
  - 实控人取得境外身份 → 资产转移信号

**民企家族治理风险点**：
- 一人多职（董事长兼总经理兼 CFO）
- 配偶 / 子女在公司任职
- 实控人对外投资多家不相关业务（跨界并购通常是亏损源）

---

## 第七章 集团情况分析

**填写要点**：
- 单一客户跳过本章
- 集团股权架构图必须穿透至最终控制人
- 核心子公司至少列 5 家，列出资产、净利润、经营状态
- 重点关注"统借统还""集团资金归集"安排——影响子公司还款能力

---

## 第八章 受信人授信情况分析

**填写要点**：
- **流贷额度测算必须按《流动资金贷款管理办法》营运资金需求模型**，不能拍脑袋
- 营运资金周转次数 = 360 / 营业周期
- 营业周期 = 应收账款周转天数 + 存货周转天数
- 同业授信余额关注 "他行授信集中度"——对单家银行依赖度过高有挤兑风险
- 公开市场融资（债券）情况是大型企业的重要信息

**测算示例**：
```
某客户上年营收 100 亿，预计增速 10%，销售利润率 8%，营业周期 90 天，
预收 5 亿，应付 8 亿，其他渠道资金 3 亿。

流贷需求 = (100 × 1.1 × (1 - 0.08)) / (360/90) - 5 - 8 - 3
        = (110 × 0.92) / 4 - 16
        = 25.3 - 16
        = 9.3 亿元
```

## 第九章 外部信息核查

**填写要点**：
- 11 项核查必须全部覆盖，不可跳过
- 即使核查结果均为"无"，也必须列出查询来源 + 查询日期
- 重大负面必须详细说明，不能一笔带过

**核查的最小动作清单**：
1. 国家企业信用信息公示系统（gsxt.gov.cn）—— 工商负面、列入经营异常
2. 中国裁判文书网（wenshu.court.gov.cn）—— 涉诉
3. 中国执行信息公开网（zxgk.court.gov.cn）—— 被执行 + 失信 + 限高
4. 信用中国（creditchina.gov.cn）—— 行政处罚 + 失信记录
5. 国家税务总局 + 各省税务局 —— 涉税违法
6. 生态环境部 —— 环保处罚
7. 应急管理部 —— 安全生产事故
8. 主流财经媒体 —— 媒体负面舆情
9. 央行 + 国际制裁名单 —— 反洗钱

## 第十章 授信保障方式

**填写要点**：
- 抵押率不能简单填"按行内规定"——必须列出具体数值
- 不动产抵押的"权属"必须查清是否纯净（无司法查封 / 无租赁权 / 无在建工程抵押冲突）
- 保证人独立列表，每个保证人都要单独评估担保能力
- 担保结构合理性：第一还款来源 + 第二还款来源是否匹配

**Demo 场景说明**：
- 抵押物查册不可得，标注"以行内不动产登记中心查册为准"
- 保证人能力评估可基于公开财务数据

## 第十一章 综述

**填写要点**：
- 优势 / 劣势 / 风控措施 必须一一对应
- 风险等级判断要有依据，不能拍脑袋
- 风控措施必须是"可执行"的（不能只写"加强贷后管理"这种废话）

**标准风控措施模板**：
| 风险类型 | 标准缓释措施 |
|---------|------------|
| 行业下行风险 | 降低敞口 / 缩短期限 / 提高担保比例 |
| 财务恶化风险 | 财务契约（资产负债率不超过 X%、利息保障倍数不低于 Y）|
| 实控人风险 | 实控人无限连带保证 + 配偶共同担保 |
| 现金流不稳定 | 受托支付 + 销售回款监管账户 |
| 关联方占款 | 关联交易披露契约 + 资金往来定期报告 |

---

## 第十二章 调查意见与结论

**填写要点**：
- 三选一必须明确，不能模糊
- 建议授信要素必须是"可审批"的具体值，不能是"建议适当额度"这种话
- 利率水平按 LPR 加点形式给出建议（如 LPR + 0~50BP）
- 审批层级建议：分行 / 总行 / 总行授信审批委员会，按本行制度
