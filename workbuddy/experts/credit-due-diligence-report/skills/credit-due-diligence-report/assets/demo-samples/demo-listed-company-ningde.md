## 第三章 行业分析 ⭐

### (一) 受信人所在行业发展概况
- 行业：锂离子电池制造（C3841），新能源产业链核心环节
- 2024 年全球动力电池装机量约 894 GWh，同比 +27.2%
- 2024 年全球储能电池出货量约 314.7 GWh，同比 +64%
- 行业进入成熟期，增速从 50%+ 回落至 25%-30%

- **国内**：国家鼓励类，"双碳"目标驱动；《新能源汽车产业发展规划（2021-2035）》
- **欧盟**：新电池法（Battery Regulation）— 强化碳足迹、回收要求
- **美国**：IRA 法案 — 海外建厂本地化要求

### (四) 受信人流贷额度测算 ⭐

按《流动资金贷款管理办法》模型：

```
流贷需求量 = (上年度销售收入 × (1 + 预计增长率) × (1 - 预计销售利润率)) / 周转次数
            - 预收账款 - 应付账款 - 其他渠道资金
```

| 测算项 | 数据 |
|--------|------|
| 上年度销售收入（2024）| ¥3,620.13 亿 |
| 预计销售收入增长率（2025）| +5%（保守）|
| 预计销售利润率 | 14.92% |
| 营运资金周转次数（360 / 营业周期 133.42 天）| 2.70 次 |
| 预收账款 | 约 100 亿 |
| 应付账款 | 约 1,500 亿 |
| 其他渠道资金（自有 + 公开市场）| 约 1,000 亿 |

**流贷需求量 = (3,620 × 1.05 × (1 - 14.92%)) / 2.70 - 100 - 1,500 - 1,000 ≈ 约 -800 亿**

⚠️ 测算结果为负，说明客户**自有资金 + 应付账款 + 公开市场融资** 已能覆盖营运资金需求，**严格按公式测算无新增流贷需求**。

实际操作中，本行可考虑**额度备用**性质的流贷（用于应急 + 综合贡献），建议额度 ¥100-150 亿。
