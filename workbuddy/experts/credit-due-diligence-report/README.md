# 对公贷前尽调专家团（credit-due-diligence-report）

一个面向商业银行对公信贷部门的 **AI 专家团**，由 5 名 Agent 协作，自动生成一份完整的《对公贷前调查报告》（12 章 + 6 附表）。

## 一、用途

- **适用场景**：对公客户（城投/平台、经营性国企、民营企业、上市公司、集团客户、单一客户）贷前尽职调查。
- **交付物**：结构规范的《对公贷前调查报告》，含数据来源声明、财务分析、外部信息核查、合规校验与免责声明。
- **两种数据模式**：行内场景（有完整核查材料）／ Demo 场景（仅基于互联网公开数据）。

## 二、团队成员

| Agent | 角色 | 职责 |
|-------|------|------|
| `dd-team-lead` | 陈实（尽调总监·主理人） | 任务识别 → 建团队 → 调度成员 → 阶段流转 → 汇总交付，纯编排不代写 |
| `data-collector` | 罗辑（信息核查员） | 11 项外部核查（工商/司法/失信/税务/环保/舆情等）+ 行内缺口标注 |
| `financial-analyst` | 钱明（财务分析师） | 3 年财务趋势、刚性负债列示、流贷测算、营收真实性核查 |
| `report-writer` | 毕成（报告撰写员） | 12 章模板裁剪、按客户类型定稿、数据来源标注 |
| `compliance-officer` | 何桂（合规审查员） | 数据来源声明、行内标注、编造拦截、免责声明检查（交付前最后一道闸门） |

## 三、使用方式

1. 在 WorkBuddy 专家中心选中本专家团并开始对话；
2. 直接提出需求，例如："为 XX 公司生成一份对公贷前调查报告"；
3. 主理人会先确认**数据来源场景**（行内 / Demo）与**客户类型**，随后自动建立团队、分阶段调度成员完成；
4. 最终交付完整报告，并附合规审查意见与免责声明。

> 快速提示词见 `plugin.json` 中的 `quickPrompts`。

## 五、与其他技能的边界

| 技能 | 职责 |
|------|------|
| **本专家团 `credit-due-diligence-report`** | 只产出《对公贷前调查报告》这一份文档 |
| `credit-pre-loan-process` | 贷前流程八阶段、授信方案、信贷申报书、审批意见等 |

若需求是「流程说明 / 授信申报书 / 审批意见」而非调查报告本身，应改用 `credit-pre-loan-process` 技能；本报告可作为其输入材料。

## 六、合规声明

- 本专家团**严禁编造数据**：公开查不到的项写「未公开披露」，行内才能查的项标「💼 待行内补充」。
- 所有交付报告末尾附免责声明：**「AI 辅助生成，需信贷员人工核实后使用；本报告不构成授信审批结论，最终以行内有权审批机构意见为准」**。
- Demo 场景报告仅基于互联网公开材料，不替代行内正式尽调。
