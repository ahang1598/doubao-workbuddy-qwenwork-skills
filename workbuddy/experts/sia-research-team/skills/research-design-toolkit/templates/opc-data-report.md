方括号为填写说明，输出时删除。**这是给人看的决策报告，不是数据堆砌——每一条结论都要落到"所以我下周该做什么"。**

## 一、总体判断

> **[可行 / 调整后可行 / 建议暂停] —— [一句话理由]，[八成/六成/五成]把握。**

把握度的说法：
- 八成以上：多类数据指向一致，没发现反例
- 六七成：方向清楚但有关键空白
- 五成左右：数据互相矛盾或样本太小，只能算初步信号

---

## 二、核心发现（3-5 条）

每条 = 结论一句 + 双证据支撑。**优先写假设的回答——哪条成立、哪条被推翻、推翻的证据是什么（被推翻的假设往往比成立的更有信息量）。**

**【发现标题写成结论，如"最想要的不是更多功能，是不用重复填写"】**

**同一条结论只出现一次**——无论定性定量数据是否都指向它，都写一次结论，下面同时挂两类证据：

📊 [图表证据：问卷中 68% 选了 X（n=156，显著高于 Y 组 21 个百分点）]
> 💬 "[用户原话]" —— [先生/女士]，[职业/关键特征]

- 只有一种数据时，给对应的一类证据即可
- **两类证据矛盾时**：写"证据不一致"——图表说A（附数据），原话说B（附引用），给可能的解释，**不硬编统一结论**

**这意味着**：[对产品/生意的一个具体含义]

---

## 三、机会点（2-3 个）

每个机会点必须说全三件事——**谁 + 什么场景 + 为什么现在没人满足**。

| # | 机会点 | 谁需要 | 在什么场景 | 为什么现在没被满足 |
|---|---|---|---|---|
| 1 | | | | |
| 2 | | | | |

> 缺任何一件都算没说清——"谁需要"空着的机会点不能写进来。

## 四、第一批用户

**画像**：[他们是谁、什么状态、有什么共同点]

**在哪能找到**：[具体渠道/社群/场景，不是"线上渠道"这种废话]

**用什么话能打动**：[用他们的原话改的吸引点，不写卖点文案]

---

## 五、最大的风险 + 怎么验证

**最可能让这事失败的一件事**：[具体的事，不是"市场竞争激烈"]

**最快的验证办法**：[一周内能做的最小验证，附要花的成本]

## 写作自检

- [ ] 报告前已完成假设确认（5-7 条，来源用户输入+原始大纲/问卷）；用户跳过时在开头列明所用假设
- [ ] 定量数据先给过交叉表；交叉表每格标了样本量
- [ ] 每条假设在报告里有明确回答（成立/不成立/部分成立）
- [ ] 第一行就是总体判断，没有铺垫
- [ ] 每个发现带数据或原话，不空谈
- [ ] 混合数据时：同一条结论只出现一次，图表+原话双证据
- [ ] 定量结论标了显著性；定性原话一字未改带身份
- [ ] 数据类型识别在前（定性/定量/混合），调对了对应 Skill
- [ ] 定性数据（<30 人）用"X 人中 Y 人"，没报百分比
- [ ] 机会点说全了"谁+场景+为什么没人满足"
- [ ] 第一批用户给了具体渠道，能照着去找人
- [ ] 风险是具体的一件事，且附了验证办法
- [ ] 用户说的 / 我的推断 已分开标注
- [ ] 回答不了的明说了，没硬编结论
- [ ] 没有术语，没有"综上所述"，没有无用大数
