# 数据分析与报告撰写

---

## 一、定性数据分析

### 三步走

**1. 逐份整理** — 每份笔录按访谈提纲的模块归位，把原话摘出来，不要一开始就总结

**2. 编码归类** — 把相似的说法归成一类，给这类起个名字
- 名字要用**用户的语言**，不要用你的抽象概括
- ✗「便利性诉求」 ✓「不想多点几下」
- 一条原话可以归多类，不必强行互斥

**3. 按频次排序 + 引原话** — 每个结论标明多少人提到，并配 1-2 句典型原话

### 呈现规范（重要）

**格式：观点 + 用户原话 + 人数统计**

> **想省事，不愿意多学一套操作**（12 人中 8 人提到）
> "我就想快点弄完，还要研究怎么用，太麻烦了。"——A 先生，自由职业
> "本来两步能搞定的事，现在要点五六下。"——B 女士，教师

**受访者标识规范**：姓 + 职业 + 关键分类特征（如付费状态、使用时长）。不要用真名全称。

### 定性数据的边界

| 能做的 | 不能做的 |
|---|---|
| 说清有哪几类看法 | **报占比**（"60% 用户认为…"）—— 小样本没有代表性 |
| 还原完整行为过程 | 说这是普遍现象 |
| 找出原因与动机的可能性 | 断定因果关系 |
| 发现没想到的新问题 | 用来做最终决策的唯一依据 |

**样本量小于 30 时，一律用"多数/部分/少数"或"X 人中 Y 人"，不要给百分比。**

### 主观判断要标注

分析里区分三种内容，写清楚哪是哪：
- **用户说的** — 直接引用
- **我们观察到的** — 行为、表情、犹豫（访谈现场记录）
- **我们的推断** — 明确标为"推测""可能"，并说明依据

## 二、定量数据分析

### 分析顺序

```
1. 数据清洗    剔除无效样本
2. 频次分布    先看每题的整体分布
3. 交叉分析    按关键分层维度分开看
4. 差异检验    差异是真差异还是抽样波动
5. 深度分析    相关、回归、聚类（按需）
```

### 数据清洗要剔除的

- 完成时长明显过短（低于中位数的 1/3）
- 矩阵题一路点同一列（直线作答）
- 前后逻辑矛盾（如说没用过但后面答了使用频率）
- 开放题填无意义字符
- 陷阱题答错（若设置了）

**清洗后要报告有效样本量与剔除比例。**

### 交叉分析的关键

**贯穿型分层维度必须逐题交叉。** 如果方案里定了"本地用户 vs 外来用户"要对比，那每个核心指标都要分开报，不是最后加一节"人群差异"。

### 差异是否真实

| 情况 | 怎么处理 |
|---|---|
| 各组样本量 ≥100 | 可做显著性检验，报出检验结果 |
| 各组样本量 30-100 | 谨慎解读，只说趋势不说结论 |
| 某组样本量 <30 | **不单独报该组数据**，或明确标注样本量过小 |

**新手最常犯**：拿 n=15 的子组和 n=200 的子组比，看到 10 个点的差距就下结论。**小组样本量必须标出来。**

### 不能做的解读

- **相关当因果** — "用了 A 功能的用户留存高"通常是高意向用户才会用 A，不是 A 提升了留存
- **意愿当行为** — 问卷里说会买的人，实际转化率通常远低于此
- **忽略基数** — "增长 200%"要看绝对数是从 1 到 3 还是从 100 到 300
- **过度精确** — n=200 的样本报"67.3%"是伪精确，报"约 67%"或"三分之二"

## 三、报告撰写

### 结构

| 章节 | 内容 | 占比 |
|---|---|---|
| **核心结论** | 3-5 条，直接回答研究目标，每条一句话 | 5% |
| **对决策的建议** | 建议做什么，及依据 | 10% |
| **研究概况** | 目标、方法、样本、时间 | 5% |
| **分主题发现** | 按研究目标逐块展开 | 65% |
| **人群差异** | 若有贯穿型分层，此处汇总（各主题内也要体现） | 10% |
| **局限与待解** | 这份研究回答不了什么 | 5% |

### 八条写作规范

1. **结论先行** — 每一页/每一节的第一句就是结论，不要铺垫完才说
2. **数据锚定** — 每个结论后面跟支撑数据或原话，不给空判断
3. **对比呈现** — 单个数字没有意义，要有对比对象（竞品/历史/其他人群）
4. **克制表达** — 不用"极大""显著提升""颠覆性"这类形容词，用具体数字
5. **符号化标注** — 用统一符号标注数据强度（如 ▲ 高于基准、▼ 低于基准）
6. **句式短促** — 一句话说一件事，长句拆开
7. **场景化分层** — 按用户实际场景组织发现，不按问卷题号顺序
8. **专业表述** — 用行业通用说法，但避免只有研究员懂的术语

### 标题写法

**标题必须是结论，不是主题。**

| ✗ 主题式 | ✓ 结论式 |
|---|---|
| 用户使用频率分析 | 高频用户集中在通勤场景，占整体使用量的六成 |
| 品牌认知情况 | 本品认知度追平头部竞品，但考虑度落后 15 个点 |
| 满意度调查结果 | 满意度整体持平，但新用户首月满意度明显偏低 |

### 图表选择

| 想表达 | 用什么 |
|---|---|
| 各项占比 | 条形图（不用饼图，超过 5 项就看不清） |
| 随时间变化 | 折线图 |
| 多组对比 | 分组条形图 |
| 漏斗各级流失 | 漏斗图或阶梯条形 |
| 两个维度的定位 | 散点图 / 四象限 |
| 多维度对比多品牌 | 雷达图（维度 5-8 个） |

**图表规范**
- 每张图有结论式标题
- 标注样本量（n=XXX）
- 小样本子组必须标注
- 不用 3D、不用渐变、不做无意义的美化

### 每个发现的标准结构

```
【结论句】高频用户主要在通勤时使用，这部分场景贡献六成使用量

【数据支撑】通勤场景使用占比 61%（n=380），远高于居家 22%、办公 17%

【原因解释】通勤时段有大段碎片时间，且用户处于"等待"状态
（来自定性：12 人中 9 人提到"路上没事干才会打开"）

【对决策的含义】产品优化应优先考虑单手操作与弱网环境
```

## 四、常见问题

**"数据没结论怎么办"**
如实说明。"本轮数据未显示明显差异"是有效结论——它说明这个因素不是关键，可以把资源投别处。不要为了有结论而强行解读。

**"结论和业务预期相反"**
照实报，但要做三件事：确认数据没问题、说明可能的原因、给出验证建议。**不要因为结论不受欢迎就软化表述。**

**"定性和定量结论矛盾"**
这是有价值的发现，不是错误。通常意味着：定性发现的是少数人的强烈需求，定量说明它不普遍。两者都报，说明各自的适用范围。

## 五、自检清单

**分析层面**
- [ ] 有效样本量与剔除比例已报告
- [ ] 定性结论用"X 人中 Y 人"，未报百分比
- [ ] 小样本子组（<30）已标注或未单独报
- [ ] 关键指标已按贯穿型分层维度交叉
- [ ] 显著性检验结果已报（若样本量支持）
- [ ] 未把相关当因果、未把意愿当行为
- [ ] 用户说的 / 观察到的 / 我们推断的，三者已区分标注

**报告层面**
- [ ] 核心结论在最前面，3-5 条
- [ ] 每个标题是结论不是主题
- [ ] 每个结论有数据或原话支撑
- [ ] 每个数字有对比对象
- [ ] 每个发现说明了对决策的含义
- [ ] 图表有结论式标题与样本量标注
- [ ] 已列出研究回答不了什么
- [ ] 每个研究目标都有对应的发现章节，无目标落空
- [ ] 无"极大""显著""颠覆"等空泛形容词
- [ ] 术语已换成业务方能懂的说法
