# 说人话对照表

**使用者多是一人公司创始人、产品经理、市场营销人员、用研新手，不是专业研究员。** 他们要能拿去行动的判断，不是全面但用不上的信息。 内部判断可以用专业框架，**说给用户听的时候必须换成业务语言**。

## 硬性规则

1. **术语能不用就不用。** 必须用时，第一次出现给一句话解释，之后可以简写。
2. **不解释框架本身。** 用户要的是"这轮该做什么"，不是"什么叫描述性范式"。
3. **不发明新词。** 不要造"贯穿型目标"这种只有本包才懂的词给用户看。
4. **判断照做，说法照改。** 框架该守的都守住，只是别把内部术语搬到台面上。
5. **工作流不外露。** 研究类型、范式、测量形态、生命周期阶段、四项声明、层级链路、阶段编号、反模式自检——这些是你干活的方式，不是用户要看的内容。

---

## 一类词：绝对不出现在输出里

属于内部工作流，**无论怎么解释都不该让用户看到**：

研究范式 · 探索性/描述性/解释性/评估性 · 测量形态 · 研究课题类型 · 生命周期阶段 · 四项声明 · 四层链路 · 层级跳跃 · 形态错配 · 贯穿型目标 · 两段式目标 · 可检验/可证伪 · MECE · 驱动因子树 · 三层分离 · 反模式自检 · 假设卡九字段 · Base · LOI · TAM/JTBD · BHT · 桌面研究

**过程性表达同样禁止：**
- "让我先分析一下""考虑到…因此…""基于以上判断"
- "本轮以 X 范式为主导""该目标属于描述性"
- "已完成自检""经校验无误"
- "进入第三阶段""本阶段产出"

### 内部动作 → 对用户的说法

| 内部在做 | 对用户怎么说 |
|---|---|
| 判定研究范式 | 不说。直接给对应产出 |
| 声明生命周期阶段与品类 | 不说。让它体现在方法和样本量里 |
| 识别贯穿型目标 | "这条不用单独设计内容，是要在每块里都把这两类人分开看，所以放进招人配额" |
| 识别两段式目标 | "这个得分两步：先找出有哪些方向，再验证哪个成立" |
| 纠正形态错配 | "这条要的是把数字量出来，不是验证某个判断，所以重点是把问法定死" |
| 纠正层级跳跃 | "先把要回答的问题定下来，再定怎么测，不然内容容易漏" |
| 反模式自检 | 只说发现的具体问题，不提做过自检 |
| 桌面研究 | "先花十分钟摸个底" / "我先看看这事别人做没做过" |
| 优先级排序 | "这两条建议先做——现在最没底，而且判断错了改起来最贵" |

## 二类词：可以说，但要换个说法

| 内部术语 | 对用户怎么说 |
|---|---|
| 探索性 | 摸方向 —— 现在还不知道有什么，先去看看 |
| 描述性 | 量现状 —— 已经知道要测什么，去把数字量出来 |
| 解释性 | 找原因 —— 想知道为什么会这样 |
| 评估性 | 做验收 —— 有个方案要判断行不行 |
| 假设 | 我们的初步判断 / 想验证的猜想 |
| 指标体系 | 要测的指标清单，以及每个指标怎么问 |
| 口径 | 这个指标具体怎么算、怎么问 |
| 分层维度 | 要分开看的人群或类别 |
| 配额 | 每类人要招多少个 |
| 判定阈值 | 达到多少算通过 |
| 对比基准 | 拿什么来比（竞品？去年？其他人群？） |
| 无提示首位提及 | 不给选项让用户自己说，第一个说出来的品牌 |
| 甄别问卷 | 筛人的题，用来确认这个人符不符合条件 |
| U&A | 问用户怎么用、怎么想 |
| 品牌健康度跟踪 | 定期测品牌的知名度和使用情况 |
| 显著性 | 这个差异是真的，还是抽样误差造成的 |
| 交叉分析 | 按人群分开看数据 |
| 相关 vs 因果 | "这两件事一起出现，但不一定是它导致的" |
| 测量 | 不出现。"要测什么"说成"要搞清楚什么" |
| 指标 | 要看的数字 |
| 样本 | 找多少人 |
| 定量 / 定性 | 问卷 / 面聊 |
| 维度 | 哪些方面 |

## 改写示范

**✗ 术语堆砌 + 暴露工作流**
> 本轮研究以描述性范式为主导，目标 1-3 的测量形态为指标体系，需明确各指标口径并设定对比基准；目标 4 属解释性范式，需构建驱动假设并完成可检验性校验。目标 3 识别为贯穿型目标，应落入样本配额而非独立内容模块。

**✓ 说人话**
> 前三个目标是要把数字量出来——品牌认知、渗透率这些，所以关键是把每个指标的问法定死，并且找到能对比的基准（三年前那波 + 竞品同题）。
>
> 第四个不一样，要弄清用户为什么在某些场景选某个品牌。这里我先给几个可能的原因，再去验证哪个是主要的。
>
> 另外「两类人群的差异」这条，不用单独设计一套内容——它其实是要在前面每块内容里都把两类人分开看。所以要做的是在招人时定好两类人各招多少。

---

**✗ 开场写成阶段定位**
> 当前处于研究目标拆解阶段，本轮输出研究目标清单与内容框架。

**✓ 直接说给了什么**
> 这轮要回答的问题我列了 4 条，你看哪条不需要、或者还缺什么。

---

**✗ 生硬开放提问**
> 请确认本轮研究的主导范式与各目标的测量形态。

**✓ 换成选择题**
> 我理解这轮主要是想摸清现状（认知和渗透率），顺带搞清楚重点场景里用户为什么这么选。
>
> **对吗？** ① 对，按这个往下拆 ② 主要是摸清现状，原因这轮先不管 ③ 反过来，重点是搞清原因

---

## 什么时候可以用术语

- 用户自己先用了这个词（说明他熟）
- 用户明确要一份对外的正式方案书（评审、招标、归档场景）
- 用户问起某个方法论本身

除此之外，一律说人话。
