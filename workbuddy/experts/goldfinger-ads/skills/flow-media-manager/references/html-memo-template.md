### 段 A：投放策略（v1.20.0 补五维分档推导）

**KPI 卡（6 个，v1.20.0 扩展）**，每个格式：
```html
<div class="kpi">
  <div class="k-label">{{标签}}</div>
  <div class="k-val">{{大数字}}<small>{{单位}}</small></div>
  <div class="k-sub">{{补充说明}}</div>
</div>
```
推荐 KPI 卡：投放方式 / **账户数（k-sub 显示分档依据）** / **广告结构（k-sub 显示分档结果）** / 出价方式 / 日预算 / **素材池总量**（衔接段B）。

**字段块（14-16 个，v1.20.0 扩展）**，每个格式：
```html
<div class="field">
  <div class="f-label">{{字段名}}</div>
  <div class="f-value">{{值}}</div>
</div>
```
字段清单：投放方式 / 账户（**含分档推导小字**）/ 主投版位 / 排除版位 / 广告结构（**分档结果**）/ 出价方式 / 出价金额区间（**附公式小字**）/ 考核指标 / 日预算总预算 / 上线日期 / 人群定向（**含定向方式默认值**）/ 投放时段（**含日内基线**）/ **素材池储备**（衔接段B）/ **上新节奏** / 盯盘节奏（**含盯指标**）。

**v1.20.0 分档推导表**（填字段值时按预算档给具体值，不给裸区间）：
- **账户数**（日预算 4 档）：<1000 → 1 ｜ 1000-5000 → 1-2 ｜ 5000-20000 → 2-3 ｜ >20000 → 3-5。字段值附小字"日预算 X 元 → 推 N 个账户"。账户类型三选一：白户首选/老户重启/灰户避开
- **广告结构**（日预算 3 档）：<2000 → 3×3×5 ｜ 2000-10000 → 3-5×3-5×5-10 ｜ >10000 → 5×5×10。字段值给分档结果（如"日预算 3000 → 4×4×8"）
- **出价公式**：初始出价 = 考核成本 × 50%-70%。字段值附小字"考核成本 X 元 × 0.5-0.7 = 初始出价 Y-Z 元"；调价节奏（≤10%/观察 4h/冷启动别频繁调/5-10 转化后回调）并入字段值
- **定向方式默认值**：系统智能定向（首选），有老客种子叠加 lookalike
- **投放时段基线**：00-07 低/暂停 ｜ 09-11 放量 ｜ 14-17 观察 ｜ 20-23 高峰（用户经验可覆盖）
- **素材池储备**：按段B 预算驱动测算结果填（如"20 张图片（总预算 6000 → 20 张档）"）
- **上新节奏**：每 3-5 天补 1-2 条素材进池
- **盯盘节奏盯指标**：出量广告占比 / 各广告消耗分布 / 素材跑速 / 红线预警 / 冷启动进度

**投放方式字段特殊渲染**：值用 `class="f-value brand"` + 附 `pill brand`。**v1.20.0 格式固定**：`智投 AIM+（tencentads-delivery-smart-create）` / `标准投放（tencentads-delivery-standard-create）`——skill 名括号附后，ai投手直接复制。

**跨列字段**：需要整行的字段（如人群定向逻辑）加 `style="grid-column:1 / -1"`。

**doc-head 路径判定依据**（v1.20.0）：`{{基建路径/诊断路径}}` 后附一行小字"依据：立项单是否提及在投账户"——让判定可解释。

🚨 **段A 末不输出"前置条件 alert"**（v1.18.0 起）：**账户未配置项的配置指引 / "针对可行性评估风险的处理"alert / "合规文案自检"等一律不输出**——执行单只交付策略与可施工内容，前置检查交给用户按段A「盯盘节奏」+金手指"项目管理→腾讯广告 Key 托管"自行处理。
- ⚠️ **v1.20.0 边界澄清**：分档推导小字（账户/结构/出价公式/定向默认值/时段基线）**属于"策略可施工内容"**，与"待办型警告"不同——推导说明**保留**，待办警告**禁止**。两者别混

### 段 B：素材策略（v1.17.0 按素材策略规范重写）

**KPI 卡（3-4 个）**：素材总量（预算驱动）/ 图片类型数 / 视频规划（无视频则标"本预算档不做视频"）/ 核心主张短句。

**结构（对照 SKILL.md 段B 的 ①-⑥ 顺序）**：
- **核心主张**（跨列 `grid-column:1 / -1`，加粗主张 + 判断理由，`class="f-value brand"`）——放段B最前
- **创意类型推荐**：每类一行/一卡——官方类型名（🚨 只能 13 种原名或视频 4 类）+ 优先级 + 尺寸 + 数量 + 「怎么给用户传信息」大白话（🚨 不出现"海报类/原生类/平台样式类/业务元素类"内部黑话）。推荐用融合表：**创意类型 · 优先级 · 尺寸 · 数量 · 怎么给用户传信息**（列序固定）
- **数量测算**（跨列）：预算档 → 数量依据一句话（档位 v1.20.0 改互斥：<1000 / 1000-5000 / 5000-10000 / >10000，如"总预算 2 万 > 1 万门槛 → 单账户约 50 张封顶 + 可做视频"）
- **视频规划**（满足门槛时）：哪几类、各几条、为什么 + 叙事套路标注；不满足门槛一句话交代"该预算档默认不做视频，先用图片跑方向"
- **一句话卖点**（跨列，`class="f-value brand"`）
- **成品规格**：按推荐类型的横/竖/方给对应尺寸 + JPEG <1MB 压缩要求

**品牌资产透传**（ba-box）：4 项字段块，**引用**立项单的品牌资产：
- logo / 产品图 / 主色或品牌色 / slogan或风险提示语
- 缺失→`pill miss`（仅状态标记，**不附"建议联系设计/品牌方"等待办型话术**）
- 待确认→`pill warn` + 用户原话
- 已确认→实际值

🚨 **段 C 已删除**（v1.18.0 起）：投手执行手册（仅上传+建创意 SOP）整个段在 v1.18.0 被砍——ai投手上传拿 ID + 建创意的 SOP 属于 ai投手自身的 SOP，不进媒介经理的执行单（边界问题：媒介经理管策略与可施工内容，ai投手管系统操作）。模板仅剩段A + 段B 两段。

### 交接摘要
