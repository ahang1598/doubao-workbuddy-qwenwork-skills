# og（优化目标）枚举库 · 层1 语义路由层（全量浅层，不含深度转化目标）

> 用途：flow-media-manager 段A「优化目标 og」字段的判定依据。**只用浅层 og，不规划深度转化目标**（ROI/次留/变现类深转不进本库，v1.24.0 定）。
> 来源：腾讯营销知识库（attribution_basic/deep.md、promotion_product_basic/deep.md、general_launch.md、landing_page_basic/deep.md）+ Marketing API 官方 action_type 枚举（2026-08-23 核对）。
> 版本：v1.24.0

## 一、判定链（官方四元组 + 归因硬门槛，五步）

```
Step 1 营销目的（输入 C2 投放目标；C1 已删 v2.24.0，品牌宣传由 C3"品牌声量优先"单信号路由）
      商品销售→商品销售；留资表单→线索留资；加企微/关注→加粉互动；APP/小游戏→用户增长；C3 声量优先→品牌宣传
Step 2 推广产品 + 营销载体（营销目的决定可选范围；输入 C2 + C10 线上门面勾选资产）
      载体 = 用户完成转化的场景：页面/小程序/应用/公众号/视频号直播
Step 3 查层1 表过滤标签（营销目的 → 载体 → 归因），得 og 候选
Step 4 归因门槛（输入 C10 + C14）
      小店=平台自动归因；落地页=JS；App=SDK/API；无归因=只能点击/曝光兜底
Step 5 出价联动校验：
      选转化 og → 计费只能 oCPX（与段A bidding 交叉校验，矛盾即报）
      选点击 og（兜底）→ bidding 必须为 CPC（按点击计费，不优化转化）
```

**核心铁律**（attribution_basic.md 原话）：**不接归因 = 不能用优化目标投放**。归因先于 og。

## 三、推荐位（平台自归因优先，前提=用户自行搭建官方落地页）

| 推荐路径 | 适用前提 | 用户负担 |
|---|---|---|
| **微信小店/视频号小店**（首选） | 用户自行搭建官方小店落地页 | **无需 JS/SDK/API、无需开发**；接通后下单/付费类 og 全部可用（attribution_deep.md 第十一节） |
| Web 落地页 + JS | 有落地页 + 嵌密钥能力 | 自行嵌 JS、排查 1801106 |
| App + SDK/API | 有开发团队（C14） | 技术对接 |
| **点击 og + CPC 出价**（兜底） | 无任何归因 | og=AD_CLICK + bidding=CPC，按点击计费，模型不优化转化 |

**用户确认话术**：
- 命中推荐：建议走微信小店——平台自动归因，您只需自行搭建小店，无需开发；归因接通后下单 og 可直接启用。
- 命中兜底：目前您没接归因，**用点击 og + CPC 出价**（按点击计费）；建议先建微信小店/视频号小店，平台自动归因后转化 og 即可升级。

## 四、维护规则

1. **只用浅层**：本库不含深度转化目标（ROI/次留/变现/白名单深转类），需要时另行立项
2. **不含行业特化 og**：金融（开户/入金/绑卡）、教育（低价课/选课）、短剧（看剧）、网文（小说阅读）等不进本库——涉行业项目时调知识库（tencent-ads-delivery-guide）查官方枚举后按判定链路由
3. **官方全量枚举（不进本文件）**：https://developers.e.qq.com/v3.0/docs/enums#api_action_type ——`action_type` 是数据上报词汇表（150+），建单可选 og 以平台联动下拉为准，**skill 不维护全量**
4. **枚举校验**：判定产出 og 后，调知识库（tencent-ads-delivery-guide）核对枚举有效性与版位兼容；查不到 → 如实告知 + 点击兜底，**不编造枚举**
5. **action_type ≠ 优化目标可选集**：上报词汇表 ≠ 建单可选集（后者按营销目的×载体×行业过滤）——判定链管语义路由，平台下拉管最终可选
