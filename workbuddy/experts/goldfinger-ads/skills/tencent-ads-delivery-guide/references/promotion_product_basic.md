# 腾讯广告推广产品（基础版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20
> 定位：推广产品（商品）快速上手指引。类型全集、字段规范、批量录入、DPA 等细节见《腾讯广告推广产品（深入版）》。

---

## 一、推广产品是什么

你这次投放**要推广、要考核的最小对象**——某个商品、某门课程、某个楼盘、某家店铺。

它是"营销内容"（四元组）四大要素之一：

| 要素 | 含义 |
|------|------|
| 营销目的 | 想达成什么（商品销售/线索留资/品牌宣传/加粉互动/用户增长） |
| **推广产品** | 本次推广考核的**最小单元**（某商品/某课程/某楼盘…） |
| 营销载体 | 用户完成转化的场景（页面/小程序/应用/公众号/视频号直播） |
| 优化目标 | 优化哪个转化行为（下单/付费/注册/领券） |

> 推广产品是**必填项**，不设置无法创建营销。它帮系统理解"你卖的是什么"，直接决定人群匹配和起量效果。

---

## 二、在哪里创建

**客户工作台/服务商系统 → 业务单元 →【资产】→ 推广产品/推广内容**
（商品类走【商品管理】→ 商品库管理 → 新建商品库）

⚠️ 商品库的**名称、行业、规模创建后不可修改**。

---

## 三、怎么创建（3 步）

```
① 选类型 → ② 选类目填关键属性 → ③ 审核通过
```

1. **选类型**：商品、商品集合、店铺、活动、教育课程、房产楼盘、商务服务等
2. **选类目**：系统按类目**联动展示关键属性，全部必填**（如商品填价格/图片/落地页，课程填产品形式/学科方向）
3. 提交审核，通过后即可被广告选用

---

## 四、怎么用（搭广告时）

投放管理平台 →【竞价推广】→【新建营销】→ 填【营销内容】→ 在"推广产品"处**点选已建好的产品**。

**联动顺序（前置决定后置）**：

```
营销目的 → 决定推广产品可选类型 → 决定营销载体可选范围 → 决定优化目标
```

> 选不到某类推广产品 = 该类型与当前营销目的/行业不匹配。

---

## 五、速记规则

- **类目必须与产品匹配**：乱选类目后续验真会被拒
- **验真规则**：推广产品与创意/落地页不一致 → 初审拒绝，一致率低"0 扶持、0 赔付"
- **商品要可推状态**：审核通过 + 已上架 + 有素材，缺一不可
- **批量投放门槛**：商品集合（MPA）要求商品库**不少于 100 个商品**
- **落地页 URL 不可重复**：同一业务单元内商品落地页唯一

---

## 六、全流程一图

```
建产品资产（业务单元-资产-推广产品/商品库）
→ 选类型 → 选类目 → 填关键属性 → 过审
→ 新建营销：营销目的 → 推广产品（点选）→ 营销载体 → 优化目标
→ 搭创意投放
```

> 商品库批量上传（XML/定时拉取/API）、动态创意自动组合等进阶玩法见深入版。
