# 腾讯广告落地页（基础版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20
> 定位：落地页快速上手指引。全部类型配置、组件清单、驳回排查等细节见《腾讯广告落地页（深入版）》。

---

## 一、落地页是什么

用户**点击广告后跳转到的页面**，转化（留资/下单/下载/关注）发生的地方。它直接决定"点击之后能不能成交"。

---

## 二、怎么选：三大类 + 一句话建议

| 大类 | 当前可选 | 什么时候用 |
|------|---------|-----------|
| 落地页跳转 | **官方落地页（首选）**、自定义链接 | 绝大多数场景直接用官方落地页；自有 H5 且行业允许时用自定义链接 |
| 腾讯生态跳转 | 微信小程序、公众号详情页、微信客服、企业微信、视频号直播间 | 转化发生在微信生态内（加粉/咨询/小程序下单） |
| 直达跳转 | 应用直达、厂商直达、一键下载 | App 下载/促活 |

> 官方落地页 = 蹊径/原生推广页等历史类型整合后的唯一官方产品，**一次制作、全流量通投**。历史蹊径资产在【资产】-【官方落地页】里统一管理。

---

## 三、怎么创建（官方落地页，两步）

**第 1 步：建落地页**
1. 投放管理平台 →【资产】→【官方落地页】→【新建落地页】
2. 左侧选组件拖入画布（图片、表单、咨询、电话等）
3.【页面设置】改名称、标题、分享设置
4. 发布 → 等审核（工作日 24 小时内、节假日 48 小时内）

**第 2 步：关联广告**
1. 建广告时在【创意】环节点【跳转类型】
2. 选「官方落地页」→ 勾选已过审的落地页

---

## 四、常用组件速览

| 组件 | 用途 |
|------|------|
| 表单 | 收集线索（支持报名计数、跑马灯） |
| 咨询 | 智能咨询 / 微信客服聊天 |
| 电话 | 一键拨号留资 |
| 下载 | App 下载（Android/iOS） |
| 跳转链接 | 跳外部网页 |
| 公众号/视频号关注 | 涨粉转化 |

> ⚠️ 组件互斥：配了"表单"不能加"下载"；配了"直播内容"不能加其他组件。完整组件清单见深入版。

---

## 五、审核避坑速记

- **先过审才能被广告关联**；审核期间不能修改
- 外层宣传的产品/价格/活动必须与落地页**一致**（被拒第 1 高频原因）
- 不要"0 元、免费领取、直接送"类话术
- 不能强制登录/注册，不能静默下载
- **选不到落地页时**查三件事：推广目标是否匹配、是否"已发布"状态、版位是否适配

---

## 六、数据在哪里看

**投放管理平台 →【报表】→【落地页分析】**：曝光、点击、CVR、组件点击、人均停留时长。

> 重点看：CVR 和组件点击，定位哪个模块流失高。

---

## 七、全流程一图

```
选类型（默认官方落地页）→ 编辑器拖组件建页 → 发布过审
→ 建广告创意时勾选落地页（最多 3 组，系统智能优选）
→ 报表-落地页分析 看数据 → 迭代页面
```

> 配置信息获取（小程序原始 ID、App ID、微信客服链接等从哪拿）见深入版第三章。
