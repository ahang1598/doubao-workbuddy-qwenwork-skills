# 腾讯广告推广产品（深入版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20
> 定位：推广产品（商品/产品库）完整细节手册。快速上手见《腾讯广告推广产品（基础版）》。

---

## 一、推广产品概念与作用

**定义**：投放时主要想推广、以及考核的对象——具体产品或服务。

**在"营销内容"（四元组）中的位置**：

| 要素 | 含义 |
|------|------|
| 营销目的 | 商品销售 / 线索留资 / 品牌宣传 / 加粉互动 / 用户增长 |
| **推广产品** | 基于业务场景，本次推广考核的**最小单元**（某商品、某课程、某楼盘…） |
| 营销载体 | 页面 / 小程序 / 公众号 / 应用 / 视频号直播等 |
| 优化目标 | 下单、付费、注册、领券等转化行为 |

**作用**：推广产品是精准投放的核心资产——选对了，系统才能准确理解"你卖的是什么"，从而匹配更精准的人群、正确的营销形态和计费方式。选错或填不准，直接影响起量和成本。**必填项，不设置无法创建营销。**

---

## 二、推广产品与产品库的关系

- **产品库（商品库）是推广产品的载体**：推广产品是大概念，商品库是具体某类产品（商品）的存放与分组管理方式。推广"某款商品"需先在商品库建好 3.0 商品
- **创建位置**：客户工作台/服务商系统 → 进入"业务单元" →【资产】→ 左侧"推广产品/推广内容"（**仅业务单元支持创建和管理**）
- **商品库专门入口**：【商品管理】页面 → 商品库管理 → 新建商品库
- ⚠️ 商品库的**名称、行业、规模一旦创建不可修改**；仅在业务单元下创建的商品库才可应用于腾讯 3.0 广告投放
- 商品信息越完整准确，模型匹配越精准

## 三、推广产品类型全集

| 产品类型 | 创建方式 |
|---------|---------|
| **商品**（单商品） | 商品库创建 3.0 商品 → 投放流程推广产品选"商品"，点选具体商品 |
| **商品集合**（批量） | 商品库创建 3.0 商品并打包为"商品集合" → 投放时选"商品集合" |
| **店铺**（平台店铺/个人店铺） | 业务单元资产下建"平台店铺库/个人店铺库"，填店铺主页类型 + 地址 |
| **活动** | 业务单元下创建活动资产 |
| **教育产品（课程）** | 选类目（成长课堂/少儿教辅等）→ 联动关键属性（产品形式、学科方向、推广价格等） |
| **房产产品** | 产品类型分"品牌 / 楼盘 / 户型"三种，下拉选择可投放对象 |
| **商务服务产品** | 选类目（如律师法律服务）→ 联动关键属性（业务范围等） |
| **家居产品**（装修服务/家具建材） | 资产-推广内容-装修产品库/家居建材库 |
| **运营商产品** | 资产-推广产品-运营商产品库 |
| **小说** | 业务单元下从书城选小说创建为产品 |
| **两品一械商品** | adhome 上传药品及资质并审核，再由运营/销售做风控分配 |

> 关于"门店"：官方文档更常见的对应资产是"店铺"（平台店铺库/个人店铺库），未检索到单独"门店库"的专项说明。线下门店推广建议按"店铺"资产或"本地门店"能力确认。

## 四、创建流程与字段规范

**核心规律**：先选"类目"，系统**根据类目联动展示不同的"关键属性"，所有关键属性必填**。

| 字段 | 规范说明 |
|------|---------|
| 产品名称 | 客户自定义，仅用于区分和管理 |
| 类目 | 务必选与推广产品本身匹配的类目（否则后续验真可能被拒） |
| 品牌 | 品牌声量大可搜索/选择自己品牌；否则选"默认"反而更利于投放 |
| 推广价格 | 免费或仅留资 → 选"无"；有付费（如体验课）→ 选"有"并填价格（两位小数，单位"元"） |
| 落地页类型 | ①自定义落地页（填 url）②小程序落地页（填小程序 id + path）③应用直达（填 deeplink）。系统校验 URL 唯一性，相同值限制重复创建 |
| 店铺类 | 关键属性 = 店铺主页类型 + 店铺主页地址；同业务单元不可建完全相同店铺，最多 1500 个 |
| 房产类 | 品牌/楼盘/户型下拉选择，同业务单元不可重复创建关键属性相同的资产 |

## 五、广告搭建中的选用与联动

**选用位置**：投放管理平台 →【竞价推广】tab →【新建营销】→ 填写【营销内容】模块 → "推广产品"处点选已建好的产品。

**联动关系（严格按顺序，前置决定后置）**：

```
营销目的 → 决定"推广产品"可选类型 → 决定"营销载体"可选范围 → 决定"优化目标"
```

- 先选营销目的，系统据此缩小推广产品可选类型范围
- **不同营销目的 × 不同行业，支持的推广产品类型不同**，需在"行业及营销目的支持范围内"选择
- 选不到的类型 = 与当前营销目的/行业不匹配

## 六、商品库批量录入与批量投放（MPA/DPA）

### 6.1 商品录入方式（四种）

| 录入方式 | 适用场景 | 说明 |
|---------|---------|------|
| **在线录入** | 首次使用 / 商品 ≤100 个 | 手动逐条填 |
| **手动上传（XML）** | 数量较少、更新需求低 | 按 XML 模板一次性批量上传（注：未检索到 Excel 模板，官方为 XML） |
| **定时拉取** | 数量多、需频繁更新 | 用 XML 文件地址自动化对接，**需研发配置服务器地址** |
| **MARKETING-API 录入** | 数量多、更新时效要求高 | API 对接 |

**批量上传流程**：录入商品 → 选录入方式（手动上传/定时拉取）→ 按 XML 模板填类目/品牌/商品名称 → 关联标品 → 传图片/填落地页 → 创建成功。

**技术对接文档**：[腾讯AMS商品营销商品数据对接技术白皮书](https://docs.qq.com/doc/DVUN6RXpjQ0liUGl1)

### 6.2 商品集合批量投放（MPA）

1. 商品库创建 3.0 商品（单个）
2. 将多个商品**打包成"商品集合"**
3. 投放时推广产品选"商品集合"，点选具体集合名称

> ⚠️ 门槛：投放 MPA（商品集合批量投放）要求商品库商品数量**不少于 100 个**，因此商品录入建议用"手动上传/定时拉取/API"而非逐条在线录入。

### 6.3 动态创意自动生成

- 创意层级选"**动态创意**"，可同时上传多个素材元素，系统自动**笛卡尔组合**生成多个创意
- 例：视频×3、文案×3、封面图×3、落地页×3 → 自动生成 **81 个创意**（旧版上限 27 个）
- 单商品广告（sDPA）同样支持动态创意，支持"优选/轮播"展现模式及智选广告能力
- 动态创意是"多素材元素组合"自动生成；**商品级动态匹配**（根据用户行为自动换商品）由 DPA 底层推荐模型完成——商品数据越完整，人货匹配越准

## 七、审核规则

### 7.1 审核时长

- 营销/落地页口径：**工作日 24 小时内**，周末/节假日 **48 小时内**；时效内不支持催审
- 特定库另有口径：招商加盟产品库录入审核一般 **1-3 个工作日**

### 7.2 商品状态与可选用性

| 状态 | 含义 | 能否选用 |
|------|------|---------|
| 推广中 | 正常推广中 | ✅ |
| 未开启 | 已暂停推广 | 手动开启后可推 |
| 暂停中（无推广素材） | 商品信息审核未通过且未上传素材 | ❌ 需先上传素材 |
| 不可推广 | 商品已在小店下架 | ❌ 不可推不可改 |

> 商品信息需**审核通过 + 已上架 + 有可用素材**，才会出现在可选列表。

### 7.3 常见驳回原因

1. 使用夸大、承诺、绝对化用语及虚假宣传描述
2. 违反社会公序良俗/不良导向内容
3. 涉及知名人士肖像或名义，缺授权证明
4. 推广内容与**开户行业不一致**
5. 缺资质或资质不合要求

### 7.4 两条特有硬规则

- **验真规则**：推广产品与创意/落地页不一致 → 初审拒绝；一致率低的主体"0 扶持、0 赔付"
- **防卷规则**：故意卷类目/乱填关键属性 → 同样"0 扶持、0 赔付"
