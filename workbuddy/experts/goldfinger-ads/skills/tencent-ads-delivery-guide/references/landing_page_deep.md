# 腾讯广告竞价广告「落地页」操作指引与概念解释

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20

---

## 一、落地页是什么

落地页是用户**点击广告外层创意后跳转到的页面**，是用户完成转化（留资、下单、下载、关注等）的场所或中转页面。它直接决定"点击之后能不能成交"，因此落地页的选择和质量是影响转化率的关键因素。

---

## 二、落地页类型全貌

落地页按跳转特性分为**三大类**：

| 大类 | 含义 | 包含类型 |
|------|------|---------|
| **① 落地页跳转** | 点击后跳转到对应页面，在页面内完成转化 | 官方落地页（推荐）、自定义链接、微信原生推广页、简易原生页、蹊径性能版、蹊径网页、枫页单品页、原生推广页小程序版（阿丽塔）、手机QQ小程序 |
| **② 腾讯生态落地页跳转** | 利用腾讯生态链路能力完成转化 | 微信小程序落地页、微信公众号详情页、微信客服、企业微信、视频号直播间 |
| **③ 直达跳转** | 点击后直接打开 App 页面或跳转厂商商店 | 应用直达、厂商直达、一键下载、Android 默认落地页、iOS 默认落地页 |

### 当前新建广告实际可选清单

| 大类 | 当前实际可选类型 |
|------|-----------------|
| ① 落地页跳转 | **官方落地页**（主力推荐）、自定义链接 |
| ② 腾讯生态落地页跳转 | 微信小程序落地页、微信公众号详情页、微信客服、企业微信、视频号直播间 |
| ③ 直达跳转 | 应用直达（deeplink）、厂商直达（跳转厂商商店）、一键下载（Android/iOS 默认落地页） |

> ⚠️ 实际可选项与**推广目标、营销载体、版位**强绑定，并非所有类型一直可选；部分行业（教育、金融、电商等）开户审核通过后**禁止使用自定义链接**，须改用官方组件。以投放端实际展示为准。

### 历史类型现状

| 类型 | 现状 |
|------|------|
| 蹊径网页 / 蹊径性能版 | ✅ **已整合进官方落地页**——蹊径建站已更名"官方落地页"，不再作为独立新建入口；历史蹊径资产可在建站平台**切换转换为官方落地页**继续使用 |
| 微信原生推广页 / 简易原生页 | 同上，已整合（历史原生资产同样支持转换） |
| 枫页单品页 | ✅ **仍在使用**，已升级为"枫页小店"（小程序商城 + H5），独立于官方落地页，服务直营电商；早期为邀请制，需联系销售/运营开通 |
| 原生推广页小程序版（阿丽塔）、手机QQ小程序 | ⚠️ 仍出现在类型清单中，但无专门配置文档、无下线公告，属历史/小众类型，以投放端实际可选项或运营经理确认为准 |

> **重要变化**：腾讯营销已将「原生推广页、蹊径丰富版、蹊径性能版」等落地页类型统一整合升级，推出**官方唯一的落地页产品「官方落地页」**，依托蹊径建站工具统一管理新老资产。现在新建落地页，**官方落地页是首选**。

## 三、各类型配置方法与信息获取

### 1. 官方落地页（推荐）

- **怎么配**：
  1. 投放管理平台 →【资产】→【官方落地页】→【新建落地页】→ 进入编辑器
  2. 拖拽组件（图片、表单、文本等）设计页面
  3. 在导航栏【页面设置】中修改名称、标题及分享设置
  4. 发布并通过审核
  5. 创建广告时在【创意】环节选「跳转类型 = 官方落地页」，勾选已过审的落地页
- **信息怎么获取**：无需填任何链接/ID，直接选择已建好的落地页资产，落地页 ID 由系统生成
- **适用**：几乎全流量通投，一次制作全流量通用

**官方落地页的优势**：
1. 编辑器支持十余种转化/互动组件，满足各行业建站需求
2. 一次制作、全流量通投，无需为不同流量分别制作
3. 微信流量下原生播放，浏览与跳转体验更流畅

#### 1.1 官方落地页编辑器与组件清单

编辑器分三区：**左侧组件选择区**（选组件）、**中部画布区**（排版）、**右侧属性面板区**（配置）。

**转化组件**（承载转化行为，核心）：

| 组件 | 说明 |
|------|------|
| 表单 | 信息收集载体。需先在"营销组件"中创建表单再选用；支持"计数设置"（展示报名人数）、"已报名用户"跑马灯、"提交后内容"（提交后弹文案/跳转） |
| 咨询 | 跳转咨询聊天页，分"智能咨询"和"微信客服"两种；微信客服页面更原生、用户可在微信消息列表收到聊天入口 |
| 电话 | 一键拨号留资（销售线索收集类推广目标必备转化组件之一） |
| 跳转链接 | 跳转外部网页链接；支持"应用直达"（已装 APP 用户直达指定页）、ClickID 归因 |
| 下载 | APP 下载，分 Android/iOS；支持应用直达、跳转厂商应用商店 |
| 快应用 | 跳转快应用详情页，需填 hap 链接 |
| 小程序 / 小游戏 | 跳转对应小程序/小游戏 |
| 微信客服 / 企业微信 | 微信生态咨询/加粉转化 |
| 公众号关注 / 视频号关注 / 视频号直播预约 | 微信生态涨粉转化 |
| 一键取号 / 全屏咨询 / 卡券 | 取号、全屏咨询页、优惠卡券转化 |
| 直播内容 | 展示直播间标题+实时画面，点击跳转直播间（需先做视频号授权；此组件与其他组件互斥） |

**内容组件**：

| 组件 | 说明 |
|------|------|
| 图片 | 单图展示 |
| 轮播图 | 一个模块内滑动查看多张图，2~6 张；播放效果可选"平滑滚动/居中播放" |
| 引用外层素材 | 朋友圈常规样式版位必须使用（引用广告外层素材） |

**互动组件**：

| 组件 | 说明 |
|------|------|
| 问答聊天 | 交互式问答，可配置"问题题干+选项"，用户点不同选项跳转下一题/指定题/结束对话/结束并唤起转化按钮 |

> ⚠️ **组件互斥规则**：配了"表单"就不能再加"下载"按钮；配了"直播内容"就不能再加其他任何组件；微信流量版位不支持含"快应用"或"全屏咨询"组件的落地页。

### 2. 自定义链接

- **怎么配**：跳转类型选「自定义链接」，输入 H5 地址
- **信息怎么获取**：填写你自己的 H5 页面链接，须以 `https://` 开头；⚠️ 投放前需先完成**自定义推广链接备案**（ICP 备案电子版等）
- **限制**：应用推广不支持；部分行业（教育、金融、电商等）开户审核后禁止使用，须改用官方组件

### 3. 微信小程序落地页

- **怎么配**：跳转类型选「小程序落地页」，可复用已用过的组件或点"➕"新建
- **信息怎么获取**（三个关键字段的来源）：

| 字段 | 获取位置 |
|------|---------|
| 小程序原始 ID | 小程序管理后台 → 设置 → 账号信息 → 小程序原始 ID |
| 跳转页面路径 | 小程序管理后台 → 工具 → 生成小程序码 → 获取页面路径 |
| 兜底网页链接（选填） | 小程序跳转失败时打开的页面，自行填写 |

- **适用**：微信流量、PCAD 流量、联盟流量；朋友圈多图创意支持每张图设不同小程序链接

### 4. 微信公众号详情页

- **怎么配**：跳转类型选「公众号详情页」，选择要推广的公众号
- **信息怎么获取**：需选择**已授权**的公众号，授权在投放管理平台完成
- **适用**：引导关注公众号、沉淀私域

### 5. 微信客服

- **怎么配**：在官方落地页编辑器中添加「咨询组件（选微信客服类型）」或「微信客服组件」
- **信息怎么获取**：**微信客服链接需从微信客服平台获取**，并提前在官方落地页建站平台的营销组件中配置
- ⚠️ 微信客服链接不要填进"跳转链接"组件里，会破坏归因

### 6. 企业微信

- **怎么配**：
  1. 投放管理平台 →【工具】→【企业微信授权与客服管理】完成授权、创建客服组/客户群
  2. 落地页添加企业微信组件，选择客服组（分配方式决定加好友/入群逻辑）
- **信息怎么获取**：选择已授权的企业微信及客服组，无需填写外部 ID
- **限制**：仅微信流量下原生播放，非微信流量需先唤起微信

### 7. 应用直达 / 一键下载 / 厂商直达

- **怎么配**：直达类通过官方落地页编辑器的「下载」组件配置
  - 应用直达：需输入 deeplink 指定 App 内详情页，用于已安装用户直接打开 App 内指定页面
  - 厂商直达：通过下载组件的**"跳转商店"开关**实现（Android 跳厂商商店，规避权限验证和厂商劫持、提升安装率；iOS 默认就是 App Store）
  - 一键下载：即 Android/iOS 默认落地页，Android 默认走下载器下载，iOS 默认拉起 App Store
- **信息怎么获取**：

| 字段 | 获取位置 |
|------|---------|
| App ID（Android） | 腾讯开放平台，应用上架后获取 |
| App ID（iOS） | iTunes Store / iTunes Connect |
| deeplink | 由 App 技术团队提供 |

- **适用**：App 下载/促活场景

### 8. 视频号直播间

- **怎么配**：属腾讯生态落地页跳转，需先绑定视频号
- **适用**：视频号直播推广场景

## 四、落地页审核规范与最佳实践

**审核时长**：
- 工作日：提交后 **24 小时内**审核
- 周末/节假日：**48 小时内**审核
- 审核时效内**不支持催审**；紧急投放建议预留充足时间，或联系代理商/渠道经理沟通
- 提交后审核期间**不可修改落地页**，需等审核通过或驳回后按提示调整

**常见驳回原因**：

| # | 驳回原因 | 说明 |
|---|---------|------|
| 1 | **推广不一致**（电商被拒 Top 原因） | 外层宣传的产品/型号/奖项与落地页实际内容不对应 |
| 2 | 落地页自动跳转小程序 | 视频号等版位因影响用户体验，不支持页面自动跳转小程序 |
| 3 | 违禁促销话术 | "0 元、免费领取、直接领取、直接送"等（部分行业如零售百货门店不支持） |
| 4 | 未如实宣传 | 商品/服务/价格/销量/折扣等与事实不符 |

**核心审核规则（易踩坑）**：

1. **应用下载需满足"七要素"**：应用名称、版本号、开发者信息、权限详情、隐私协议、App 功能介绍、App 核准号，且需与下载按钮**同屏可见**；下载按钮要明确标示"下载"或"安装"
2. **禁止强制登录/强制交互**：不能强制用户登录、注册，也不能用纯对话框形式强制聊天
3. **禁止无效或违规页面**：页面需能正常打开，不能推广已下架商品/服务
4. **内容需完整**：不能只有一张图或单一商品，要提供完整业务信息
5. **推广内容与素材一致**：落地页里的价格、折扣、品牌、活动等必须与广告外层素材一致
6. **禁止静默下载**：不能用静默方式推广应用

**落地页过滤逻辑（为什么选不到某落地页）**：

- **推广目标匹配性**：如投放"视频号推广"，落地页必须包含视频号关注/直播预约组件，否则无法被选中
- **落地页状态**：需为"已发布"状态，且无违规/审核未通过记录
- **版位适配性**：不同版位（如 PCAD、视频号）对格式和内容要求不同

**行业准入注意**：

- 部分行业（医药、二手回收、房屋维修、公益等）对落地页类型有监管控制，需以合规口径为准
- 直营电商行业仅支持使用腾讯官方建站落地页
- 多商品盲盒活动仅支持官方建站落地页、苹果商店或应用宝下载页，不支持自定义外链

## 五、通用规则

1. **落地页必须先创建并审核通过**，才能在广告创建流程中被关联使用
2. **一个创意最多可设 3 组不同类型落地页**，系统自动把用户跳转到最可能转化的那一个
3. **选不到某落地页时**先检查三件事：推广目标是否匹配、落地页是否"已发布"状态、版位是否适配

## 六、落地页数据查看

落地页数据在**投放管理平台**查看（不在建站平台），两条路径：

1. **【报表】→【落地页分析】**：查看曝光、点击、转化率（CVR）、落地页组件点击、人均停留时长等
2. **广告/创意详情页 →【数据】→【效果数据】**：自定义选择"落地页曝光次数""落地页组件点击次数""落地页人均停留"等指标，定位流失节点

> 重点指标：**落地页曝光次数、落地页组件点击次数、人均停留时长、CVR**——用于定位哪个模块流失率高。

## 七、落地页预览与分享

**预览（编辑器内）**：
1. 编辑器顶部导航栏点【预览】，页面会**自动保存**
2. 选择预览屏幕规格（手机/PC）
3. 选择对应流量的 **App 扫码**，或**打开 H5 链接**（非微信流量）预览效果

**分享给他人**：预览时产生的 **H5 链接/二维码**即可用于分享；已发布落地页的审核结果通知可关注落地页公众号实时接收。

## 八、高级能力核实结论（截至检索时点）

| 能力 | 结论 |
|------|------|
| 动态商品页/动态落地页（按商品库自动生成） | ❌ 官方落地页文档未检索到支持说明 |
| 一个落地页下多个子页面（多页面结构） | ❌ 不支持，当前为单页面结构（组件纵向排列） |
| AB 测试/多落地页对比 | ✅ 通过「组件化创意」实现：一个创意最多 **3 组落地页**，系统智能优选跳转（非等分随机 AB）；官方落地页本身无内置 AB 测试模块 |
| 行业/快捷模板 | ⚠️ 未检索到明确说明；官方落地页为组件化自由搭建 |
| 历史蹊径/原生资产转换 | ✅ 蹊径已并入官方落地页体系，入口在投放端【资产】-【官方落地页】；一键迁移的单独操作细节未检索到，建议进入资产页面查看现有资产 |
