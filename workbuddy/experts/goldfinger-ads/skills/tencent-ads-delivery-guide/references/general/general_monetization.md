# 第七部分　变现与商业模式

这部分决定了你的**出价上限**——不搞清怎么赚钱，就不知道能花多少钱买用户。

## 7.1 两种基础变现模式

| 模式      | 全称                 | 含义      | 收入来源           |
| ------- | ------------------ | ------- | -------------- |
| **IAA** | In-App Advertising | 应用内广告变现 | 用户看广告，你从广告平台分钱 |
| **IAP** | In-App Purchase    | 应用内购买   | 用户直接付费         |

**混合变现**：Total LTV = **Ad LTV + IAP LTV**

⚠️ 关键原则：**别让广告收益伤害了内购收益**——给付费用户展示大量广告，会损害其留存和付费意愿。

## 7.2 IAA + IAP 混合变现的协同设计

典型用户结构（以工具/休闲游戏为例）：

| 用户类型   | 占比  | ARPU  |
| ------ | --- | ----- |
| 广告变现用户 | 95% | 约 $2  |
| 内购变现用户 | 5%  | 约 $50 |

**三条协同策略**：

1. **激励视频解锁试用**——看广告 → 试用高级功能 → 提升付费转化（约 +30%）
2. **付费用户广告优化**——VIP 去广告/减少广告 → 提升付费用户留存（约 +50%）
3. **广告币系统**——看广告获得虚拟币 → 购买道具 → 培养付费习惯

**用户价值升级路径**：免费用户(F2P) → 广告用户(Ad) → 试用用户(Trial) → 付费用户(Pay)

## 7.3 判断产品是否适合接广告变现

自查清单（每项 1 分）：

- 用户量足够大（DAU 有规模）？
- 用户使用时长/频次高？
- 用户对免费有强需求？
- 不是高端付费工具？
- 次日留存超过 30%？

| 得分    | 判断              |
| ----- | --------------- |
| 0-2 分 | 不适合接广告，优先考虑 IAP |
| 3-4 分 | 可小流量测试，谨慎推进     |
| 5-7 分 | 非常适合，立即启动变现     |

## 7.4 广告聚合：从 Waterfall 到 Header Bidding

### 两种模式的本质区别

|      | **Waterfall 瀑布流** | **Header Bidding 竞价** |
| ---- | ----------------- | --------------------- |
| 机制   | 按预设顺序依次询价         | 所有广告源实时竞价             |
| 问题   | 顺序固定，错失高价         | ——                    |
| eCPM | $12-15            | **$18-25（+60%）**      |
| 填充率  | 85%               | **95%（+10%）**         |
| 延迟   | 200ms             | 300ms                 |

举例：Waterfall 按 AdMob $20 → Facebook $15 → Unity $10 顺序问，实际拿到 $15；而竞价模式下各家实时报价（$22/$18/$19/$25/$12），价高者得，实际拿到 **$25\*\*。

> **2024 年后，不用 Header Bidding 就是在给竞争对手送钱。**

### 广告源组合的 5+2+1 配置

- **Layer 1 核心广告源（5 个）**：AdMob（填充率 95%、eCPM $15-20、全球覆盖）、Facebook（90%、$18-25、精准定向）、Unity Ads（85%、$12-18）等
- **Layer 2 补充源（2 个）**：填补特定地区/场景
- **Layer 3 兜底源（1 个）**：保证填充率

## 7.5 动态底价与多阶底价（媒体侧收益优化）

### 核心公式

> **动态底价 = 基准价 × 用户系数 × 时段系数 × 竞争系数**

### 多阶底价的黄金配置（5 阶）

| 阶级    | 用户特征    | 占比  | 底价  | 收益贡献 |
| ----- | ------- | --- | --- | ---- |
| 第 1 阶 | 长尾用户    | 40% | ¥3  | 10%  |
| 第 2 阶 | 普通活跃    | 30% | ¥8  | 20%  |
| 第 3 阶 | 高活跃     | 20% | ¥15 | 30%  |
| 第 4 阶 | 付费用户    | 8%  | ¥30 | 25%  |
| 第 5 阶 | 高价值 VIP | 2%  | ¥50 | 15%  |

**关键洞察**：2% 的高价值用户贡献 15% 收益，值得重点优化。二八定律在广告变现中同样适用。

### 用户分层与时段调价参考

**用户系数**：付费用户 ×2.5、活跃用户 ×1.5、新用户 ×0.8

**时段系数**：晚高峰 19-23 点 +80%、工作时间 9-18 点 +20%、深夜 0-6 点 −50%

**竞争系数**：

- 低竞争（< 3 个竞价者）→ 低底价吸引广告主，提高填充率
- 中竞争（3-8 个）→ 适中底价，平衡收益和填充
- 高竞争（> 8 个）→ 高底价筛选，确保收益最大化

### 动态底价的五个误区

| 误区        | 真相                       |
| --------- | ------------------------ |
| 底价越高越赚钱   | 过高底价会导致填充率下降，要找收益与填充的平衡点 |
| 阶梯越多越好    | 过多阶梯增加管理复杂度，**3-5 阶最优**  |
| 一次设置永久有效  | 市场在变，每月复盘、季度调整           |
| 所有广告位统一策略 | 开屏、信息流、详情页价值差异巨大，应分别设置   |
| 忽视广告主体验   | 底价过高会赶走优质广告主，要保持合理梯度     |

## 7.6 变现侧的三层指标体系

| 层级         | 指标                             |
| ---------- | ------------------------------ |
| **L1 北极星** | ARPDAU（如 $0.15）、广告 LTV（如 $8.5） |
| **L2 过程**  | eCPM、CTR、填充率、CVR、展示率、延迟        |
| **L3 细分**  | 分广告源 eCPM、分广告位填充率、分地区收入、分时段表现  |

### 异常检测规则

- eCPM 环比下降 > 20%
- 填充率 < 80%
- 延迟 > 500ms
- CTR 异常波动 > 50%

**复盘节奏**：实时监控 → 日报 → 周报 → 月度深度分析。

## 7.7 激励广告的设计原则

**核心：在「峰终时刻」植入价值，绝不在用户正在进行核心操作时打断。**

情绪曲线上的时机选择：

| 时机    | 是否适合              |
| ----- | ----------------- |
| 游戏失败后 | ✅ 适合（用户想复活）       |
| 任务成功时 | ✅ 适合（情绪高峰，愿意接受奖励） |
| 返回主页  | ✅ 适合（场景切换的间隙）     |
| 游戏进行中 | ❌ 绝对不要            |
| 看排行榜时 | ❌ 危险（用户专注中）       |

**原则**：在句子的结尾做广告，而不是在句子的中间。

## 7.8 用倒推定价法算清合理出价

这是把变现数据转化为投放决策的关键一步。

**逻辑链**：

1. 先算清 **LTV**（用户终身价值）
2. 确定**目标 ROI**（或目标利润率）
3. 反推**可接受的 CAC / CPA 上限**
4. 再由 CPA 反推**可接受的 CPM**

> 可接受最高 CPM = (LTV × 目标ROI) × CTR × CVR × 1000  
> 盈亏平衡 CPM = 目标CPA × CTR × CVR × 1000

**判断线**：LTV > CAC 才不亏；LTV / CAC > 3 才有充足利润。

## 7.9 订阅制变现的四个模块

1. **周期策略**——按周/月/年设计，不同周期的心理定价和续订率差异极大
2. **定价参考**——定价心理学（锚定、对比、阶梯）
3. **用户分级**——不同价值用户给不同权益和价格
4. **流失召回**——识别流失前信号，设计召回触点

## 7.10 停掉买量后收入会断崖式下滑吗

这是评估买量真实价值的关键问题。

判断依据是**自然量与买量的关系**：

- 若买量带来的用户能沉淀为长期留存和自然口碑，停投后有缓冲
- 若买量用户留存差、纯靠持续注入维持数据，停投即断崖

**评估方法**：用增量归因思路——对比投放期与非投放期的大盘数据差值，而非只看广告平台报告的转化数。
