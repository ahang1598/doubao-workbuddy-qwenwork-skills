# 第五部分　素材与创意

## 5.1 先破一个认知：素材决定上限，但账户健康度是前提

> **优先级：账户健康度 > 素材质量 > 投放技巧**
>
> 先让系统相信你，再谈素材创意。

素材不起量时，**素材顶多背一半的锅**，另一半是「用素材的姿势错了、账户底子烂了」。

**天天换素材、天天新建计划、天天删老计划 = 逼系统天天猜、永远不让它毕业。**

正确做法：

1. **老带新**——在表现稳定的老计划里悄悄加新素材。系统会用已验证的高转化人群试探新素材，**冷启动成功率翻倍**
2. **做减法、做隔离**——一个账户专注一件事（一个优化目标、一类人群）。测不同转化目标就开新户
3. **给素材耐心**——允许它学两三天，别成本一波动就关
4. **控制变量**——一次只改一个东西

⚠️ **账户是一个整体人设**：系统会根据账户内所有在跑/跑过的计划给账户打标签、建模型。一个账户同时跑三种人群包、两种出价方式、四个转化目标，系统会「精神分裂」，流量撒得更散、预估更保守；不同计划还会互相抢量、自己抬价。

## 5.2 素材与创意的配比体系

### 素材总数 : 创意总数 = 1 : 2~4

创意的核心作用是**测试不同投放变量**（定向、出价、标题、落地页），而非单纯堆数量。

| 配比            | 后果                                 |
| ------------- | ---------------------------------- |
| 低于 1:2        | 变量测试不充分，可能错过最优投放组合                 |
| **1:2 ~ 1:4** | **推荐区间**                           |
| 高于 1:4        | 多创意抢同一素材流量，eCPM 内耗，多数创意因预算不足无法过冷启动 |

### 单个素材配几个创意

| 创意数       | 效果                                            |
| --------- | --------------------------------------------- |
| 1 个       | 测试维度太窄，若定向/出价不合适，素材潜力无法被挖掘                    |
| **2-3 个** | **性价比最高**——兼顾测试广度和避免内耗                        |
| 4 个以上     | 同素材创意形成内部竞争，系统无法判断优先级，所有关联创意的 eCPM 权重下降，预算被稀释 |

### 按阶段调整配比

| 阶段                 | 配比        | 逻辑                                          |
| ------------------ | --------- | ------------------------------------------- |
| 冷启动测试期（新账户上线 7 天内） | 1:3 ~ 1:4 | 需快速测试不同出价（目标成本 1.2 倍/1.5 倍）和版位组合，找高潜力创意     |
| 稳定放量期（已过冷启动）       | 1:2 ~ 1:3 | 聚焦已验证方向                                     |
| 爆款素材               | 1:1 ~ 1:2 | 例：主力版位+目标出价占 70% 预算，朋友圈版位+高出价占 30%，聚焦放量避免内耗 |
| 素材衰退期              | 1:1 或直接关停 | 衰退素材竞争力已下降，无需多创意测试                          |

## 5.3 素材全流程的量化管控指标

### 上新质量指标（预防低质素材浪费资源）

- **新素材与核心素材差异度 ≥ 30%**——避免与已有爆款高度同质化导致内耗。例：核心素材是「口播测评」，新素材需改为「剧情植入」或「用户 UGC」

### 测试阶段指标

| 指标          | 标准                                                                      |
| ----------- | ----------------------------------------------------------------------- |
| 单素材测试预算     | **常规渠道：目标 CPA × 15**（CPA 50 元 → 750 元），确保拿到至少 10 个转化；**千川：目标 CPA × 50** |
| 48 小时冷启动通过率 | ≥ 50%（48 小时内消耗 ≥ 测试预算 80% 且转化成本 ≤ 目标 120% 视为通过，进入潜力池）。未通过直接关停           |

> **分渠道口径**（按投放渠道选用，不要混用）：
>
> | 渠道                              | 单素材测试预算         | 说明                                      |
> | ------------------------------- | --------------- | --------------------------------------- |
> | 常规渠道（巨量竞价 / 腾讯 / 小红书 / 快手 / 百度） | **目标 CPA × 15** | CPA 50 元 → 750 元，目标是拿到约 10 个转化          |
> | **千川**（电商直播）                    | **目标 CPA × 50** | CPA 80 元 → 4000 元；同时测 3-5 条，总预算 1.2-2 万 |

### 放量阶段指标

| 指标          | 标准                                        |
| ----------- | ----------------------------------------- |
| 新素材日均消耗增速   | ≤ 50%（首日 1000 元，次日最高 1500 元），避免快速放量导致模型跑偏 |
| 新素材成本波动率    | ≤ 15%（连续 3 天波动超 15% 需暂停放量，排查定向或素材内容）      |
| 新素材 7 天 ROI | ≥ 核心素材的 90%（否则仅适合补流量，不可作主力）               |

### 账户内素材结构：核心稳盘 + 新素材补量

| 素材类型       | 消耗占比    | 功能定位   |
| ---------- | ------- | ------ |
| 核心素材（已跑量）  | 70%-80% | 承担稳定消耗 |
| 潜力新素材（测试中） | 20%-30% | 补量与储备  |

⚠️ **禁忌：新素材消耗占比不可超过 40%**，否则会导致账户整体成本波动率超过 ±20%（算法对新素材的模型学习需要 3-5 天）。

### 稳定期素材上新的三个公式

> 每周上新数量 = 现有核心素材数量 × 30%-50%  
> 新素材消耗占比 = 20%-30%  
> 单素材测试预算 = 目标 CPA × 15 倍（常规渠道；千川为 × 50）

**核心素材留存率 ≥ 60%**：每周结束后，上周核心素材中仍能稳定消耗的比例需 ≥ 60%，否则说明上新质量不足。

## 5.4 素材衰退：四个模型解释为什么会死

素材衰退的本质是**某些预估数据被系统持续下调的过程**。规律是：**前端数据的持续下滑，先行于消耗崩塌和成本飙升。**

| 模型              | 来源   | 机制                                                                    |
| --------------- | ---- | --------------------------------------------------------------------- |
| **用户新鲜感衰减**     | 用户端  | 同一用户看到次数越多，点击欲望越低（边际效用递减 + 广告疲劳）                                      |
| **eCPM 竞价能力衰减** | 系统逻辑 | 前端数据下降 → 拿量变少 → 数据稀疏 → 系统更不自信 → 竞争力进一步压低。**正反馈加速，所以衰退常呈「断崖式」而非「斜坡式」** |
| **生命周期（探索→利用）** | 系统机制 | 素材先在最易转化人群「利用」，洗完后到泛化人群「探索」。**不是素材变差，是系统分配的人群变水了**                    |
| **竞争挤压与同质化**    | 大盘生态 | 创意爆了，海量相似素材涌入，系统按画面指纹/语义归为一类，用户对「整个品类」的疲劳感共享加倍                        |

### 衰退速度取决于哪些变量

| 模型   | 核心变量                                              |
| ---- | ------------------------------------------------- |
| 新鲜感  | 素材耐看度（广告感浓度）+ 用户群同质化程度。**原生到几乎看不出是广告的剧情视频，衰减极平缓** |
| 生命周期 | 定向人群规模（总容量）+ 每日消耗速率。亿级通投 vs 百万级精准人群，「探索」边界天差地别    |
| 竞争挤压 | 赛道竞争烈度 + 素材可复制性。美妆、大健康是重灾区；高度依赖人设/技术的 B2B 相对安全    |

## 5.5 素材衰退的分级预警（口径已统一为三级）

不同资料给出的阈值不同，本质是**不同严重程度对应不同动作**，因此整理为分级：

| 级别          | 信号                                             | 动作              |
| ----------- | ---------------------------------------------- | --------------- |
| 🟢 **早期预警** | CTR 环比下降 10-15%；或 CPM +20%                     | 还能救。启动微调、准备储备素材 |
| 🟡 **中期处理** | CTR 连续 3 天环比下降 ≥ 20%；或转化成本环比上升 ≥ 15%；或频次 > 3 次 | 标记「待淘汰」，启动替换流程  |
| 🔴 **晚期淘汰** | 转化率降 30%+；或 CTR 下降 30%+；或成本连续 2 天超预期 30%       | 建议停投，全量更新素材     |

**其他可用信号**：

- eCPM 连续 3 天下跌 > 15% → 立刻换素材，别等系统降权
- 消耗速度低于历史同时段 30% 且持续 2-3 天
- CPM 持续上涨但转化不涨
- 评论区负面反馈增多

**高客单价场景例外**：素材周期本身较长（3-4 周），可容忍到 CTR 下降 30%+ 再全量更新。

### 换素材的判断依据：看指标不看天数

> **点击率掉了，马上换。点击率稳定，7 天也不用换。**

| eCTR 状态 | 判断                  |
| ------- | ------------------- |
| 稳定或上升   | 继续用——用户还有兴趣，频控还没起作用 |
| 下降 20%+ | 立即换——素材疲劳           |
| 一直很低    | 素材根本不行，别纠结，换新的      |

### 素材迭代效率要求

**从「衰退预警」到「新素材上线承接流量」的时间 ≤ 24 小时**——靠提前储备同类素材实现（核心素材是「办公室场景」，就提前储备「居家场景」变体）。

**黄金窗口**：从衰退信号出现到完全失效只有 **48-72 小时**，必须在窗口内完成动作。

### 抢救衰退计划的三步急救法

1. **诊断**：查 CPM、CTR、CVR 三大指标走势，对比 7 天前数据确认下降幅度，判断是素材问题还是人群枯竭
2. **原计划抢救**：方案 A 复制计划 + 提价 10-20%；方案 B 原计划阶梯提价 + 智能放量。观察 2-4 小时，ROI 为正继续、为负关闭
3. **素材迭代**：立即启动素材裂变，1:1 剪辑/翻拍，保留爆点重置废点，新素材 + 新计划 + 换定向重新探索

## 5.6 素材公式化：把创意变成可批量生产的工程

核心思路：**把素材拆解为最小元素，再排列组合批量生产。** 创意工作从「想点子」升级为「定义元素 + 设计组合规则」。

### 第一步：元素拆解

| 维度 | 可拆元素               |
| -- | ------------------ |
| 画面 | 人物 / 场景 / 色调       |
| 文案 | 标题句式 / 卖点词 / 行动号召  |
| 音频 | BGM / 配音 / 音效      |
| 结构 | 开头钩子 / 中段展示 / 结尾转化 |
| 样式 | 版式 / 字体 / 贴纸特效     |
|    |                    |

**颗粒度越细，组合空间越大。**

### 第二步：排列组合

例：画面 5 × 文案 6 × 音频 4 × 结构 3 × 样式 4 = **1440 种理论组合**。即便只有 10% 有效率，仍有 144 种差异化素材。

### 第三步：组合规则（不能乱配）

| 规则   | 要求                             |
| ---- | ------------------------------ |
| 语义一致 | 钩子 / 展示 / 转化的逻辑必须连贯            |
| 人群匹配 | 不同组合对应不同人群                     |
| 去重   | 素材 + 标题 + 落地页完全差异化，违反会触发频控判同质化 |

### 第四步：效果归因

每条素材由明确的元素组合构成，可精确拆解**哪些元素在起作用**，反向优化元素池：高表现元素加权重、增变体；低表现淘汰降级。

### 结构化重组法（应对判重）

**不是改素材本身，而是改素材的「组装逻辑」。**

把一个 15 秒视频拆成 5 个 3 秒片段（A B C D E），重新排列组合（C A E / B D A / E C B），加不同转场和文案，可生成 20 个全新素材——**视觉指纹完全不同，但信息传达一致**。

### ❌ 这些"洗稿"手法已经失效

| 无效手法     | 原因         |
| -------- | ---------- |
| 同义词替换文案  | NLP 照样识破   |
| 只调亮度/对比度 | 视觉指纹算法对此免疫 |
| 截取中间片段   | 部分匹配也会触发判重 |
| 镜像翻转     | 已被识别       |

⚠️ **搬运素材现阶段被识别后会打上搬运标签，后续基本被限制跑量。** 全扒/混剪别人的视频基本没量。

## 5.7 素材微调的黄金准则

| 标准       | 要求                  |
| -------- | ------------------- |
| **最低标准** | 改一项可过审，但系统仍可能识别为重复  |
| **安全标准** | 改两项以上，基本可规避影子计划     |
| **最佳标准** | 混剪、翻拍，**画面差异 60%+** |

可改的项：换标题（文案钩子完全不同）、换 BGM（改变情绪节奏）、调顺序（前后段落互换）、换封面（缩略图差异化）、60% 画面不重复。

### 首发标识：让平台认为这是新素材

**平台首发判定：相似分镜占比 < 10% 即可获得首发标识。**

获得首发标识的收益：冷启动率提升约 40%、7 天榜单保护期、1 小时优先审核、策略倾斜。

做法：重拍前 3 秒（新场景/角度）、重剪节奏（调整分镜）、插新镜头，使**画面差异度 > 60%**。

### 反向清理法：删掉僵尸素材

**被忽视的真相：不是老素材不行了，是被同质化素材"挤压"窒息了。**

- 拥挤账户：10 条相似素材互相挤压，单个素材曝光不足
- 清理后：保留 2 条最优素材，流量集中爆发

**执行**：至少 3 天/次；对象是低消耗（< 500 元/周）且相似的素材。

### 跨平台改造清单

抖音跑量素材搬到快手/朋友圈，这 5 处必改：

| 改造项    | 快手方向                  |
| ------ | --------------------- |
| 口播语速   | 放慢 10%                |
| 文案风格   | 方言 ok、接地气、去网红感        |
| 视频时长   | 15-30s                |
| 结尾 CTA | 按平台习惯调整               |
| BGM    | 使用当前平台热榜 Top10，借势推荐算法 |

⚠️ 禁止使用有版权风险的音乐。

## 5.8 素材内容方法论：怎么做出能转化的素材

### 有需求 vs 无需求，素材逻辑完全不同

| 用户状态       | 素材策略                                                    |
| ---------- | ------------------------------------------------------- |
| **已有明确需求** | 素材只需输出好产品卖点，引导有需求的用户选择                                  |
| **还无需求**   | 通过内容共鸣让用户发现问题、产生兴趣、激发需求。需回答：**什么人群、在什么情况下、会因为什么问题产生需求** |

### 三种素材的本质区别

**「能否起量」「能否有转化」「能否起量同时稳定转化」是三种完全不同的素材：**

- 起量看能否吸引用户、持续让用户停留
- 转化关键在于**精准击中用户转化点/痛点**，而非自卖自夸讲好卖点

### 拿到新品先搞清六件事

1. 核心差异点/竞争力是什么
2. 核心目标人群是谁
3. 核心卖点是什么
4. 用户痛点有哪些
5. 主使用场景在哪
6. 行业当前跑量素材的类型/结构/开头是什么

搞清楚后再输出新素材。

### 前 3 秒：不是用来美的，是用来筛人的

- **判断开头能否让人停留的土办法**：**直接静音看画面**，是否还有吸引力
- 素材是跟用户打招呼的第一照面
- 素材前需明确：**人群（受众是谁）+ 卖点（核心利益点/钩子）+ 差异化（对比竞品的核心优势）**

### 竞价素材不需要精致

**越精致越不消耗。** 做好内容/画面、讲清卖点，核心是吸引目标人群持续停留，同时降低决策成本、提高信任度。

### 20 条素材实操要点（原文精选保留）

1. 不仅关注新素材能不能起量，更要关注**持续的消耗能力、转化能力、后端用户质量和留存**
2. 很多人看似上了很多素材，但只是增加数量——场景/内容/开头/卖点都一样，**没给用户新视角、新转化理由**
3. 学习期没结束的新素材不要轻易否定，除非转化成本超正常太多或一直空耗
4. 素材投放周期不仅和自身结构有关，还和投放策略、投手操作有关
5. 衰退跑量素材要优化，重点放在**素材开头和核心卖点可视化**；原素材中的高光/高留存画面可拉出来给新素材继续用
6. **不要单一优化某个素材数据**。如点击率低只优化开头、忽略开头与后文关联性，会导致点击率高但后端转化骤降
7. 爆款素材结构/框架**并非固定不变**，需根据行业/人群/客单/偏好/消费习惯针对性调整，硬套公式不适用
8. 输出素材前想清楚：这条素材想让哪些人群看到、要筛掉哪些人群
9. 新手抓不住卖点时，**先拆 20 条行业跑量素材**的结构、开头、节奏、卖点、高光画面、场景，每条总结一个可借鉴点（**拆解不是搬运**）
10. 每个素材都有生命周期。**在跑量和转化巅峰期，就是准备迭代、输出新素材的最佳时机**
11. 很多素材痛点刺激到位了但卖点没讲清，或开头吸引的人群和真正转化人群不一致——这种不是放弃，而是找到问题环节优化
12. 素材转化差/投产低，抛开计划端因素，很大程度是对产品卖点/目标人群痛点的挖掘认知还不够深
13. **素材复制不是追多，而是追准**——提炼确定性/有效的信息内容进行放大

## 5.9 素材 AB 测试的正确做法

**AB 测试的核心是控制变量。**

- 一般单变量、双计划形式
- 部分账户选 AABB 模式（单变量、四计划），但大部分行业双计划已足够
- 测素材时：A、B 计划除素材不同外，**转化目标、定向、出价、投放时段、预算、竞价模式必须全部一样**

**AB 测试黄金公式**：同定向 + 同出价 + 不同素材。

❌ **避免变量重复**：2 条创意仅标题不同、定向/出价一致，属浪费测试资源。

### 素材筛选的通过标准

| 指标  | 参考标准                  |
| --- | --------------------- |
| CTR | ≥ 行业均值 1.2 倍，或 > 1.5% |

### 素材上线前的自查清单

- 画面清晰无拉伸/无水印/无模糊
- 前 3 秒有明确价值钩子
- 落地页加载速度 < 2 秒
- 避免绝对化用词（最、第一、保证等）
- 准备好备用素材（A 素材不行立刻换 B）
