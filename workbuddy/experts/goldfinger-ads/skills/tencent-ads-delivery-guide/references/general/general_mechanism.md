# 第一部分　底层机制：广告是怎么被卖出去的

## 1.1 最重要的认知：你买的不是广告位，是每一次曝光的竞拍资格

同一个广告位，每次用户刷新都**重开一次拍卖**，一天被拍卖千万次。

| 同一广告位   | 中标者   | 中标原因   |
| ------- | ----- | ------ |
| 第 1 次曝光 | 广告主 A | A 出价最高 |
| 第 2 次曝光 | 广告主 B | B 素材更好 |
| 第 3 次曝光 | 广告主 C | C 定向更准 |

所以「广告位好不好」是伪问题，真问题是「你这一次的竞拍能力够不够」。

## 1.2 程序化广告的五个角色

```
广告主（投放后台）  设定 定向 / 出价 / 预算 / 素材
      ↓
DSP 需求方平台      替广告主自动竞价、买量
      ↓
ADX 广告交易市场    拍卖在这里发生，全程约 100ms
      ↓
SSP 供给方平台      替媒体接询价、卖流量
      ↓
媒体 App            广告位的主人
      ↓
用户屏幕            0.1 秒后刷到广告
```

外加 **DMP 人群数据银行**，在旁边为定向和预估供料。

一句话：买卖双方各请一个代理，在中间市场成交，数据银行供料。

## 1.3 eCPM：决定一切的唯一货币

> **eCPM = 出价 × 预估点击率(pCTR) × 预估转化率(pCVR) × 1000**
>
> 部分资料会加上 **+ hiddencost**（平台隐藏调控手段），指平台不公开的干预项。

**eCPM 是平台视角的指标，不是广告主视角的。** 它衡量的是「这 1000 次曝光给你，平台能赚多少钱」。平台只做一件事：把曝光卖给愿意为它付最多钱的人。

**不同计费方式如何统一折算**：

| 计费方式 | eCPM 算法                          | 说明                       |
| ---- | -------------------------------- | ------------------------ |
| CPM  | eCPM = CPM 出价                    | 最简单，无预估环节                |
| CPC  | eCPM = CPC 出价 × CTR × 1000       | 点击率越高，同价平台赚越多            |
| CPA  | eCPM = CPA 出价 × CTR × CVR × 1000 | CTR 和 CVR 任一拉胯，eCPM 都上不去 |
| oCPX | 同 CPA                            | 平台内部预估 CTR/CVR 后折算排序     |

**为什么需要统一折算**：不同出价方式像不同货币，同样金额的美元和英镑价值不同，必须换算成同一标准才能比较。

举例：A（CPC 2 元，CTR 3%）→ eCPM 60；B（CPA 100 元，CTR 3%，CVR 5%）→ eCPM 150；C（CPM 30 元）→ eCPM 30。**平台把曝光给 B。**



**推论（极其重要）**：

- 相同出价下，点击率和转化率越高，跑出概率越高；
- 相同 eCPM 下，点击率和转化率越高，**能接受的出价就越低**，最终成本越低；
- 所以「把素材做好」等于「变相加价」。

## 1.4 广告从请求到展示的完整链路（约 100 毫秒）

**第 1 站 · 触发**：用户刷出下一屏 → 广告位 → SSP 接住请求，打包成 Ad Request：

- **谁**：设备 ID、人群标签、历史行为
- **哪**：哪个 App、哪个广告位、内容场景
- **何时**：时间、地理、网络（WiFi/4G）

**第 2 站 · 询价**：ADX 把这次曝光连同请求包，同时群发给所有 DSP（Bid Request）。

**第 3 站 · 决策**：DSP 在 100ms 内做 4 道判断：

1. 定向匹配上了吗？否 → 连价都不出，直接放弃
2. 预估 pCTR × pCVR（调用 DMP 数据 + 历史模型）
3. 套上你的出价，算这次曝光该报多少
4. 提交 Bid，进入竞价排序

**第 4 站 · 竞价**：按 eCPM 排序，最高者胜出。

**第 5 站 · 展示**，时间分布：

| 时间点      | 发生什么               |
| -------- | ------------------ |
| 0 ms     | 用户刷新，发起请求          |
| 约 12 ms  | ADX 广播询价           |
| 30–80 ms | DSP 并行出价（耗时大头，占一半） |
| 约 85 ms  | 竞价排序定胜负            |
| 约 95 ms  | 赢家返回 + 渲染          |
| 100 ms   | 用户看到广告             |

**关键推论**：定向太窄，DSP 连出价资格都没有——你可能是自己把自己挡在了竞价门外。

## 1.5 流量分配的六道关卡：eCPM 排序之前和之后

很多人只知道 eCPM 排序，却不知道排序前有四道资格赛、排序本身分粗排精排两轮。**任一道没过，eCPM 再高都没用。**

### 资格赛（eCPM 排序之前的四道过滤）

| 关卡   | 管什么   | 常见踩坑                                     |
| ---- | ----- | ---------------------------------------- |
| 定向过滤 | 谁可以看  | 三个定向条件叠加可能筛掉 90% 用户，"精准过头就是自己把自己关在门外"    |
| 预算余额 | 有没有钱  | 余额为零立刻停投，日预算耗完当天结束                       |
| 频次控制 | 看太多不行 | 同一用户一天看 1 次正常、3 次还行、5 次以上系统干预、10 次以上直接降权 |
| 用户体验 | 用户烦不烦 | 点过"不感兴趣"、举报、长时间暂停、创意多样性太差（判同质化）都会降权      |

### 预赛：粗排

一个广告位只能展示 3-10 条，候选池有几百到几千条。粗排用**轻量级模型**快速砍掉 80%，只留前 20%。因为一次广告展示只有约 100 毫秒，全送深度模型算不过来。

粗排只认基本指标：出价、**历史** CTR、**历史** eCPM、类目匹配度、基础人群标签。原则是「快」不是「准」，宁可误杀不能拖慢。

⚠️ 注意「历史」二字——**新账户、新素材天然劣势**：没历史 CTR、没历史 eCPM，预估空白≈保守预估。这是"同样素材老账户有量新账户没量"的根本原因，解法不是提价，是熬过冷启动。

### 决赛：精排

粗排筛出的 200-500 条进精排，深度模型上场，特征从几十维升到 200 多维，选出前 50 条进 GSP 竞价。算力是粗排的几十倍。

精排看的远不止出价×CTR×CVR，还包括：

- 实时预估 CTR（这个人此刻在这个页面看到这条广告的点击概率）
- 实时预估 CVR（用回传信号训练）
- 素材多模态特征（AI 视觉模型分析标题/图片/画面）
- 用户行为序列（意图轨迹）
- 上下文特征（时间/天气/城市/页面内容）
- 交叉注意力（动态匹配度）

## 1.6 GSP 计费：你赢了却只付第二名的钱

**广义第二价格拍卖（GSP）**：赢家实付的不是自己的出价，而是「压过第二名所需的最低价」。

现代广告系统采用的是**第二密封价格拍卖**（维克里拍卖），改良后的非公开拍卖方式。

**两种等价表述**（不同资料写法不同，本质一致）：

- 简化版：你出 ¥10，第 2 名 ¥6 → 实付 ¥6.01
- 折算版：你出价 60、CTR 2.5%、eCPM 100 最高，第二名 eCPM 85 → 实际扣费 = 85 ÷ 2.5% = ¥34（而非 60）

**为什么这么设计**：机制鼓励说真话。高出价不会让你多花钱，只会让你多赢。

**但要注意边界**：GSP 保证「价高者不亏」，**不保证「价高者一定赚」**——竞争激烈时实际扣费会被顶高。

**时段套利**：晚 8-10 点竞争最激烈、实际扣费高；上午 10-12 点竞争缓和，实际扣费可能低 30%。

## 1.7 名义公式之外的三个隐藏变量

### 变量一：账户历史权重（信任分）

> **实际 eCPM = 名义 eCPM × 账户权重**

| 加分项     | 扣分项        |
| ------- | ---------- |
| 历史累计转化多 | 成本忽高忽低     |
| 消耗稳定    | 经常暂停、频繁修改  |
| 素材持续更新  | 素材长期不换     |
| 无违规记录   | 有拒审、举报     |
| 账户活跃度高  | 长期不投突然大量新建 |

这解释了**马太效应**：大账户数据多 → 模型准 → 预估准 → 拿量效率高 → 越跑越便宜；小账户反之，越跑越贵。

### 变量二：素材新鲜度衰减

**最近 7 天数据的权重是 30 天前的 3-4 倍。** 素材跑两周后，系统评分已在悄悄下调。

所以素材要持续上新——不是为了堆量，是为了**维持新鲜度评分**。

### 变量三：平台策略干预（不透明、不可改）

- 某些行业有流量配额
- 大促期间品牌广告吃掉优质流量
- 新账户可能被分到「低优先级」队列
- 平台自身商业化策略（某时段优先推某品类）

对这类变量只能预判、不能对抗，把可控变量做好即可。

## 1.8 账户被限量的常见原因

不是"被针对"，而是踩了具体规则：

1. 定向过窄，候选池不足
2. 预算/余额不足触发流控
3. 频次控制触发（同一用户重复曝光过多）
4. 负向反馈累积（不感兴趣、举报）
5. 创意同质化被判定重复投放
6. 素材搬运被识别，打上搬运标签后基本限制跑量
7. 账户权重低（新户或有违规史）

## 1.9 你能控的四个旋钮，与系统的黑箱边界

| 你能控             | 系统决定（黑箱）        |
| --------------- | --------------- |
| **定向**：圈谁来看     | 竞价怎么排（按 eCPM）   |
| **出价**：为一次转化报的价 | 出价怎么翻译（转化价→曝光价） |
| **预算**：每天弹药与节奏  | 流量给谁多少（探索与分配）   |
| **素材+落地页**：钩子强弱 | 要学多久才稳（冷启动节奏）   |

**核心原则**：别跟系统抢方向盘。把这 4 个旋钮拧到最好，剩下的信任并喂养黑箱。

## 1.10 三方博弈：理解平台的真实动机

投放不是广告主和平台较劲，是**平台、广告主、用户**三方博弈。

| 角色  | 核心诉求                   | 真实底线            |
| --- | ---------------------- | --------------- |
| 平台  | 每个流量商业价值最大化（eCPM 越高越好） | 体验不能差到导致用户流失    |
| 广告主 | 最低成本拿最多有效转化（ROI 越高越好）  | 成本不能高于盈亏平衡点     |
| 用户  | 看感兴趣的内容，最好别有广告         | 广告别太烦，烦了就卸载/切竞品 |

**权力结构**：平台是规则制定者（最强），广告主是出钱的乙方（夹心层），用户个体最弱、集体最强（用脚投票）。

**平台算法的四个隐性倾向**：

1. 偏好高质量广告（pCTR×pCVR 高天然 eCPM 高）
2. 偏好大预算广告主——**注意，偏好的不是"钱多"，是大预算带来的"模型确定性"**，pCVR 预估更准、风险更小
3. 偏好贴近原生内容的广告——**素材不是要做得像广告，是要做得不像广告**
4. 偏好合规、生态友好的广告

**平台没有偏见，只有利益最大化**——短期利益与长期利益的平衡。

### 处于 eCPM 劣势时的四条对抗策略

| 策略                 | 做法                                   | 原理                |
| ------------------ | ------------------------------------ | ----------------- |
| 深度转化目标绕开浅层竞争       | 大家投激活时，你改投付费/ROI/次留                  | 避开红海              |
| 人群包精准化降低 pCVR 不确定性 | 用一方数据（高价值用户 lookalike）告诉系统"这些人大概率转化" | 抬升 eCPM 预估        |
| 预算节奏与时段错峰          | 错开黄金档，走凌晨/午间/工作日上午                   | 竞争缓和，扣费低          |
| 找生态位蓝海             | 判断标准：这个流量池里 eCPM 比你高的广告主不够多          | 头部扎堆是红海，头部看不上的是蓝海 |

**记住**：你的真正对手不是平台，是同一流量池里的所有广告主。
