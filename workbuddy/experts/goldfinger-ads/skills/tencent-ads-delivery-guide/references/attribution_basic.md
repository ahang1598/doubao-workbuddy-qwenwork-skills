# 腾讯广告转化归因（基础版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20
> 定位：转化归因快速上手指引。接入步骤、DN 配置、深度优化、归因差异排查等细节见《腾讯广告转化归因（深入版）》。

---

## 一、转化归因是什么

把用户的一条**转化行为**（购买/下载/留资等）归属到一条具体**广告**上的过程。归因数据用于衡量转化量、转化成本，也是 oCPX 模型优化的依据。

> 不接归因 = 不能用优化目标投放，模型不知道什么是"好转化"。

---

## 二、归因方式（2 种）

| 方式 | 逻辑 | 说明 |
|------|------|------|
| **点击归因**（默认） | 关联最后一次点击 | 大多数场景 |
| 曝光归因 | 优先点击，关联不到回溯曝光 | 增转化/摊成本；**需联系行业运营申请** |

---

## 三、上报方式怎么选

| 你的场景 | 用什么 |
|---------|--------|
| Web 落地页 | **JS 上报**（落地页嵌密钥，一页一密钥） |
| App | **SDK 上报**（推荐，接入一次全账户通用）或 API |
| 技术能力强、多端统一 | **API 自归因**（新版无需反复拿 token） |
| 已有 DataNexus 数据源 | 直接创建转化 |
| **微信小店/视频号小店** | **无需接入**——平台上报自动归因 |

---

## 四、配置 5 步（以自建上报为例）

```
入口：【资产】→【数据营销】→【转化归因】
```

1. 【新建转化】→ 选"首次数据接入"（推荐）
2. 填基本信息：转化名称、转化类型（网页/应用/小程序/公众号/企微）、落地页链接或 APPID、优化目标
3. 配归因方式（默认点击归因）
4. **联调**：生成联调预览广告（有效期 **1 小时**）→ 触发一次转化行为 → 数据上报成功 → 完成激活
5. 新建广告时选择该转化

---

## 五、速记

- 设置优化目标后，计费只能用 **oCPX**
- 联调预览广告只有 **1 小时**有效期，联调前先准备好触发动作
- 转化必须**先激活**，广告端才可选
- 数据回传要求**全量准确**，漏报/延迟直接影响模型学习
- 看数据以 **T+1** 为准，当天数据不全

---

## 六、后台数据和自己统计对不上？（快速排查 4 步）

1. 确认报表**统计口径**（默认"转化回传口径"，可切"营销播放口径"）
2. 检查**去重规则**：重复线索（clickid 相同）不进转化量也不计费，但你自己的 CRM 可能算全量
3. 以 **T+1 数据**再比对
4. 仍不符 → 检查上报打点是否遗漏、回传量是否与实际一致

---

## 七、全流程一图

```
选上报方式（JS/SDK/API/平台自动）→ DN 建数据源（自建方式才需要）
→ 转化归因新建转化 → 联调通过激活 → 广告端选转化投放
→ 看数据以 T+1 为准 → 数据异常按四步排查
```
