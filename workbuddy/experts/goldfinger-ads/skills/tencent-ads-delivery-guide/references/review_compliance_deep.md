# 腾讯广告审核与合规答疑（深入版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-21（第二版：补齐通用素材规范细则、通用内容红线判定标准、八大分行业审核细则）
> 定位：审核与合规完整细节手册。快速上手见《腾讯广告审核与合规答疑（基础版）》。

## 一、审核环节与时效全景

| 审核环节 | 承诺时效 | 说明 |
|---------|---------|------|
| **开户资质审核** | 工作日 24h / 周末节假日 48h | 主体资质、行业资质等 |
| **广告/创意审核** | 一般 1 小时；整体 1-2 工作日（通常 5-6 小时） | 高峰期（17:00-24:00）可能延时；直播类一般 4 小时内 |
| **内容/素材审核** | 工作日 4h / 周末节假日 24h | 图片、视频、文案等创意元素 |
| **营销/落地页审核** | 工作日 24h / 周末节假日 48h | 落地页、推广链接 |
| **财务/结算信息审核** | 7 个工作日内 | 不含周末节假日，遇假期顺延 |

**审核工作时间**：审核人员工作日 **9:00-24:00**；周末及节假日**有值班审核**（照常审但时效更慢）；素材审核人工咨询仅工作日 9:00-20:00。

## 二、审核状态与含义

| 状态 | 含义 |
|------|------|
| 审核中 | 已提交排队/审核中；组件已过但整体状态延迟同步时稍后刷新 |
| 审核通过 | 合规，按设定时间自动上线 |
| 审核拒绝（不通过） | 点「管理」进详情看具体拒审原因，改后重提 |
| 复审中 / 复审通过 / 复审拒绝 | 申诉复审流程的三种状态 |

> 无独立"退回修改"状态；"被拒后修改重提"即"审核拒绝 → 修改 → 重新提交"。

## 三、通用素材审核规范细则

### 3.1 图片素材规范

**尺寸/格式**：

| 项目 | 规范 |
|------|------|
| 支持比例及像素 | 1:1（800×800）、3:4（960×1280）、4:3（1280×960）、5:4（1280×1024）、4:5（1024×1280）、9:16（720×1280）、16:9（1280×720） |
| 朋友圈常规大图 | 仅支持 **800×800**（800×640、640×800、640×960、640×1136 已下线） |
| 格式 | JPG、PNG 等常见格式 |
| 封面图 | 与视频尺寸一致，JPG/JPEG/PNG，≤140KB |
| 资质/证件图 | 通常 ≤200K、分辨率不低于 1500×1100 |

**内容禁止项**：
- **文字占比**：朋友圈外层图片中所有文字（含 Logo、广告语、活动信息）面积**不得超过图片总面积 30%**，超出以"文字过多"驳回
- **二维码**：图片上不得使用二维码
- **联系方式**：不得出现联系方式、网站地址等信息
- **描边/空白**：禁止大量空白、不必要的描边效果
- **颜色**：不得高饱和度背景与文字对比过大、颜色过亮
- **清晰度**：文字不能过小影响阅读；主视觉应包含品牌信息

### 3.2 视频素材规范

| 项目 | 规范 |
|------|------|
| 时长 | **5-300 秒** |
| 格式 | MP4 / MOV / AVI |
| 大小 | **≤500M** |
| 支持尺寸 | 4:3（640×480）、16:9（1280×720）、9:16（720×1280 / 1080×1920） |
| 横版建议 | 1242×828（朋友圈适配） |
| 竖版建议 | 1080×1920（视频号、公众号适配） |

**警示语位置与边距安全区（重点）**：
- **竖版视频**：警示语须在视频中间左右两侧展示，不得进入四周边距——左右各 **44px**、上侧 **147px**、下侧 **103px**
- **横版视频**：警示语须在中间左右两侧展示，不得进入左右边距（各 44px）
- **警示语通用要求**：清晰完整可识别，不过小/模糊/重叠/与背景混淆；不被其他文字遮挡；**全程展示**；颜色与背景明显区别；不放在易被遮挡区域（如视频号组件区域）
- 实操：创意编辑右侧「预览」面板有**安全区域预览**可自查

**其他内容规范**：
- 不得为 GIF 式或 PPT 式播放效果；口播清晰
- 视频号广告：**开头 3 秒内不建议硬广贴片、开头 10 秒内不建议硬广植入**；去掉营销内容后其余内容应具消费价值且独立成章
- 不得直接搬运品牌 TVC 或他人内容；音画时差 0.5s 内（小店素材）

### 3.3 文案/标题规范

**字数限制**：

| 场景 | 限制 |
|------|------|
| 朋友圈图文广告标题（外层文案） | **1-30 字**；一个创意最多 3 组文案 |
| 原生推广页/落地页核心标题 | 建议 14-30 字 |
| 视频号互选组件标题 | 建议 14-20 字，与视频内容高度相关 |

**文字规范 7 条**：
1. 不得单独使用谐音字宣传（需加引号或突出设计，且不含不良含义）
2. 不得单独或不规范使用方言文字
3. 不得故意使用错别字或字形相近的汉字
4. 不得使用不符合逻辑、不通顺、表达不完整的语句
5. 不得单独使用汉语拼音或字母缩写
6. 不得使用特定负面关联词指代某人某事
7. 不得使用违反社会良好风尚的不良网络用语、低俗描述

**标点/字段规范**：企业名称等字段所有符号须用中文状态（"简称•项目""简称-项目"形式）；不得出现动词/主谓宾句型、活动折扣信息。

## 四、通用内容红线判定标准

### 4.1 低俗内容判定细则

**着装类**：
- 裸露敏感部位（含成年人、未成年人、婴儿、卡通角色）
- 情趣/暴露着装：情趣内衣、透视装、肉色紧身衣、内衣内裤外穿、半截抹胸、渔网袜、吊带袜、三角短裤、裹浴巾/被单、内裤套头等
- 上装不雅：衣服过紧过薄、大面积裸露胸部/背部；下装同标准

**动作/场景类**：
- 剪影"人物疑似未穿衣服"、人物"凸点"
- 聚焦臀部/丁字裤外露/聚焦胸部、人物脱去内衣
- 两性场景惊叹句、引起低俗联想的不完整内容
- 以隐私场所为噱头营造低俗氛围
- 成人用品、私密物品、低俗壁纸/表情包、未成年人软色情、污秽文字

### 4.2 恐怖惊悚内容判定

- 禁止消极、恐怖、血腥及暴力倾向元素：**血腥、病变、僵尸丧尸、鬼魂、道士形象**
- 禁止易引起不适场景：死人、尸体、尸检、满身伤痕
- 视频**人物轻微流血形象不得超过 5 秒或时长一半**
- 禁止文字描述自杀、自尽、灭族、满门抄斩、诛灭九族、斩首、酷刑、刑场等血腥内容
- 禁止介绍暴力细节、美化暴力场景、宣扬以暴制暴；禁止打砸摔场景、过度暴力打架
- 禁止引人不适的卡通元素（卡通昆虫蠕动、产卵等）

### 4.3 诱导点击判定标准

**箭头**：图片/视频画面中出现**任何指向组件区域**（引导购买、下载、咨询）的箭头——**无论指向位置方向是否一致，均不支持**。

**手势/口播**：
- 图片中不支持任何指向性箭头、手势
- 口播/手势引导点击头像购买或下载，若该动作不能实现则不支持；指向方向错误需管控——**头像组件位于左下方，评论在右下方**

**文案/情绪诱导**：
- 不支持操控用户情绪诱导点击：卖惨、替父代言、疾病恐慌、身材焦虑、急迫表述、悲伤表情
- 不支持仿系统通知/仿朋友圈/仿官方界面的误导样式

### 4.4 素材一致性要求

- **外层与落地页一致**：价格、折扣、品牌、活动等宣传描述不得不一致
- **推广内容一致**：素材展示的商品/品牌与设置的推广产品类目相符（游戏：App 名称/Logo 与落地页一致，素材无游戏名称即拒审）
- **活动信息一致**：奖品、规则、领取/升级条件须与备案及落地页一致（如奖品"Pura80"与规则"Pura70"不一致、门槛奖品"手机 512G"与备案不符、"黄金"未明确克数 → 均拒审）
- **医疗特别要求**：广审文号须与提交资质一致，同一广告元素内不支持多个广审文号

## 五、高频拒审原因清单

**通用 8 条**：
1. 夸大/承诺/绝对化用语（"几秒钟烧开""充一次电用 60 天""国内第一""行业领先"）
2. 虚假宣传/无法核实的效果承诺（"7 天瘦 10 斤"）
3. 低俗导向内容（暴露着装、性暗示动作、私密场景）
4. 指向性诱导（箭头/手势指向组件区域、方向错误）
5. 拉踩贬低第三方
6. 命中敏感词库（常"秒拒"）
7. 创意元素与推广产品不一致
8. 隐私泄露（车牌未打码、身份证未处理）

**分类型**：图片看画质/马赛克、AIGC 人物畸形（脸/手）、黑边、仿官方界面、二维码导流；视频看无声/播放异常、恐怖画面、混剪、开头与业务无关、警示语遮挡（边距安全区）、车牌未打码；文案看错别字/繁体字/方言、绝对化用语、虚假承诺、诱导话术、警示语缺失。

## 六、分行业审核细则

### 6.1 金融行业

**通用合规（所有金融细分）**：
- 资质先行：须提供金融业务经营许可资质，投放内容不超监管许可范围；涉及第三方机构需合作证明
- 产品属性明示：标明金融产品名称 + 本质属性（存款/贷款/债券/基金/股票/理财保险等）+ 产品信息查询方式
- 风险提示必加："产品有风险，投资需谨慎""投资有风险，入市需谨慎"（图片/视频/落地页均需）

**分品类细则**：

| 品类 | 细则 |
|------|------|
| 贷款 | 个人消费信用贷授信 ≤20 万、期限 ≤1 年；企业贷上限 100 万；额度仅支持"区间"（0-20万）或"最高可贷"（旁加"具体金额以实际审批为准"）；须有合规**年化利率区间 + 单利/复利说明** + "贷款有风险，借款需谨慎"及"额度/放款时间以实际审批为准"；禁"大学生可贷款""凭身份证即可贷款""信用黑户也可贷款"、不得向未成年人放贷 |
| 保险 | 不得夸大保险责任或收益，不得与存款/资管产品等同对比；须明确**承保公司、产品名称、险种**；第三方平台须披露合作保险机构及备案信息；宣传资料须载有保险机构名称和地址 |
| 理财/投资 | 须标注忠告语；存款营销使用到期收益需说明存款时间和利率 |
| 证券 | 禁用"推荐/分享 XX 支股"等暗指推荐股票质量的描述 |
| 典当 | 不涉绝当物品销售、旧物收购寄售；不得发放信用贷款、集资吸储；房产抵押须体现典当属性 |

**利率/收益率表述规范**：

| 项目 | 规范 |
|------|------|
| 贷款年化利率 | 须以**明显方式**清晰展示**年化利率（区间形式）**为主；日/月利率不得比年化更醒目 |
| 利率区间范围 | 符合国家要求，当前 **6%-24%**；素材利率须与推广产品填写的利率区间一致 |
| 单利/复利 | 必须注明（如"贷款年化利率 4.8%（单利）"） |
| 日息/月息举例 | 须注明还款方式（等额本息/先息后本/等额本金）；不承诺具体金额，须加"起"；举例金额用整数；参照物指代利息须同时体现利息值 |
| 收益率表述 | 须说明参考期限和来源；须含**"过去的业绩并不代表未来的收益率"** |
| 收益上限 | 年化收益率**不得超过 16%** |
| 禁误导低息 | 不得仅写"最低利率""利率低至"；不得以与实际执行利率不一致的"日利率/日还款"宣传 |
| 第三方对比 | 可用"某平台、某机构"中性表述；不得贬低具体第三方品牌；不得用"上当、受骗、骗局"等负面词 |

**金融落地页合规**：须提供经营者信息（地址/联系方式）、服务信息（数量质量/价款费用/履行期限方式）、风险与责任（安全注意事项/风险警示/售后/民事责任）；保险销售页须显著披露产品性质、利息收益、费用费率、主要风险、违约责任、免责条款；**助贷撮合**须标示委托方名称、不作保证性承诺、无担保资质不宣传增信兜底、承诺"在贷款机构息费外不再收取息费或变相收取"。

**违规典型案例**（市监处罚真实案例）："保本保息""简单操作，更是 0 风险"（保证性承诺，罚 3600 元）等——明示/暗示保本、保证性收益承诺均为违法红线。

### 6.2 医疗健康行业

**文案禁用语**：
- 不得保证诊疗安全、保证治愈或隐含保证；不得宣传"治愈率、有效率"
- 不支持"具体时间+具体功效"（"三分钟摘镜"须加"最快"）
- 不得用有疾病特征的人物名义推广（"10 年糖友的控糖法宝"）
- 服务人员名称不得用"专家/顾问"等暗示专业身份；不得出现疾病名称、药品信息
- 不得使用"试用、囤货、热销、抢购"等怂恿任意/过量购买词汇

**图片/视频要求**：
- 医美**不得使用患者名义或形象做诊疗前后效果对比**；无法核实的前后对比、差异过大、不符客观事实即违规；客观展示须标注"**效果因人而异**"
- 医美不得利用"推荐官/体验官"等营销代言人推荐证明
- **非医疗行业不得出现医护形象**（白大褂/手术服/护士服、医生护士身份）
- 健康资讯/心理评估不得出现专业医生形象、疾病诊断、开处方药内容

**医疗广告"三要素"（缺一即拒审）**：
1. 机构资质：《医疗广告审查证明》（省级卫生行政部门签发、有效期内）+ 成品样件表
2. 机构要素标注：素材须添加**医疗机构第一名称 + 广审文号**，且在**图片、视频封面及视频前三秒清晰展示**
3. 医疗要素一致：广审文号与资质文号一致，同一广告元素内不支持多个广审文号

**医疗投放内容限定（仅 8 项）**：医疗机构第一名称、地址、所有制形式、机构类别、诊疗科目、床位数、接诊时间、联系电话（前 6 项须与《医疗机构执业许可证》一致）。

**药品/OTC**：
- 须显著标明：禁忌、不良反应、忠告语、药品广告批准文号
- OTC 须显著标明 **OTC 标识 + 忠告语"请按药品说明书或者在药师指导下购买和使用"**（视频中持续显示）
- **OTC 广告六要素**：产品名称、OTC 标识、广审文号、忠告语、禁忌内容、注意事项
- 处方药禁止通过互联网发布广告
- 不得超出广审表/说明书范围宣传（超广审即拒审）；禁"安全无毒副作用"等安全性断言、禁"无效退款/保险公司保险"等保证性内容、禁"评比/排序/指定/获奖"等综合评价

**保健食品**：普通食品/膳食补充剂禁用 **24 项保健功能声称**（"增强免疫力""辅助降血脂"等）；禁"宝、灵、精、强力、特效、全效、奇效、高效、速效、神效"；禁"神、仙、神丹"；不得与药品/保健食品/化妆品对比；不得明示暗示适用于未成年人、老人、孕产妇、病人。

### 6.3 教育培训行业

**文案禁用语**：
- **效果承诺（红线）**：不得对升学、通过考试、获得学位学历或培训效果作保证性承诺——"英语提高 XX 分""3 天记住 800 词""1 个月从 80 分提到 140 分""1 个月包过""一辈子不会失业"均禁
- 学历类：不支持"时间+拿证/毕业""2 年以下学制""毕业 3 证""手机考本科"；不得出现买卖学历描述
- 薪资承诺：非招聘行业不得提"考取本科学历月薪 1 万""工资翻倍"
- 名师名校："名师执教"等客观描述通常合规；涉及具体老师姓名/院校背景/执教经历需师资证明 + 肖像授权 + 师资承诺函；不得冒用第三方院校名义、校徽、校门
- 不得利用"科研单位/学术机构/教育机构/行业协会/专业人士/受益者"名义推荐证明；口才培训禁"成功学""PUA""说服他人"

**资质展示**：除"教学辅助工具"和"留学"外，营业执照须含教育/培训经营范围；师资证明：≤3 人全提供，>3 人提供 3-5 份；清北师资需清北资质证明；院校毕业背景需毕业证+肖像授权，院校执教需在职证明+肖像授权；非学位授予单位不得声称可授予学位。

**K12 红线（最严）**：
- K12 学科类培训（线上线下）**禁投**；K12 非学科类培训（线上线下）**同样禁投**
- 不得暗示 K12 内容：教室/学校场地场景、能力分级、代替学校常规上课、帮助校内成绩提升、赠送讲解/解析内容、学习规划/成长规划、拍题搜题、超前学
- 可宣传边界：仅校内同质化兴趣能力（"词汇量积累更多、文章写得更好、提升阅读能力/专注力/记忆力"），**不得涉及校内成绩**
- 除测评及 K12 书籍作者外，不得自称"老师""规划师"

### 6.4 电商/实物商品

**价格表述规范**：
- **禁止使用"原价"一词**；不得虚构原价/现价（"9.9 元购 iPhone""0.5 折""1 元购"）
- 被比较价须真实有据（吊牌价/专柜价/品牌官网价），**基准以促销活动前 7 日内最低成交价为准**（无交易则以最后一次交易价为准）
- 展示页标价须与落地页一致；折扣/减价须显著标明期限和附加条件
- 活动价不得与其他渠道/商家/商品价格对比（与自身前期价对比仅限推广页且真实准确）

**促销话术**：活动须真实有效、规则清晰（明示时间、数量、价格、门槛、路径）；不得虚假优惠、提前涨价后降价；赠品须明示品种/规格/数量/期限/方式；自动续费须显著标明。

**功效宣传边界**（高频违规）：
- 护发禁"卷发还原直发"；酒类禁"不伤胃"；美妆个护禁"安全/无毒/无副作用/0 刺激"
- 数码家电禁"0 噪音/无油烟"；预包装产品禁"零添加/无添加"；胶水禁"比电焊厉害"
- 服饰：外穿衣物禁低于 -20℃ 抗寒宣传、内穿禁低于 0℃；冰丝内裤禁"比冰箱还清凉"
- 食品禁暗示医疗功效、禁"时间+功效"（"2 周保持体重 2 位数""轻松甩掉 20 斤"）、禁与药品/保健食品对比、禁特定人群暗示

### 6.5 游戏行业

**画面要求**：真人形象须与游戏行业关联（支持特工/cosplay 等游戏元素形象），不支持无游戏背景的日常休闲生活着装；App 名称/Logo 须与落地页一致；**素材须体现推广游戏名称**（无名称即拒审）。

**未成年人保护**：素材（视频/图片/文案/落地页）**不得出现未成年人玩游戏**的场景及描述；广告素材及 App 内不得出现充值内容。

**抽奖/爆率表述**：
- 落地页须明确中奖概率及奖品内容；互动试玩类奖品须与备案及活动内容一致
- 完成任务抽奖：**活动奖品最高不超过 5 万元**
- 完成任务兑换现金：外层素材展示金额**不超过 300 元**；小额实物奖品价值不超 300 元（超过需活动证明）
- **禁止**：具体兑换比例（"1600 金币=1 元"）；具体任务完成情况+收益保证（"今日收入 xx 元""玩游戏过 xx 关赚 xx 元"）
- 涉赌红线：禁"上下分""回收金币""一夜暴富/一炮暴富""赚钱赚到爽"等暗示赌博描述
- 下载领奖：不得无规则用"下载领/下载就领"误导，改为"下载完成首单任务可领取"等有前提描述

**落地页**：游戏行业**不支持使用外链投放**。

### 6.6 食品/酒类

**食品功效禁用语**：同保健食品边界（禁 24 项功能声称、禁夸大绝对化词、禁迷信庸俗词、禁与药品对比、禁特定人群暗示、禁功效承诺）。

**酒类画面和文案限制**：
- **禁止出现饮酒动作**；禁止酒后失控、乱性、不良导向饮酒动作
- 禁止诱导/怂恿饮酒、宣传无节制饮酒
- **禁止表现驾驶车、船、飞机等活动**
- 禁止暗示饮酒功效（消除紧张焦虑、增加体力）；禁止把成功归因于饮酒
- 不得针对未成年人发布；**不得以未成年人名义/形象介绍酒类**，不得出现未成年人购买消费酒类内容
- 不支持山寨品牌酒/山寨包装酒；不支持"个人经历+软文"推广；获奖内容须真实并标明评奖单位/范围/时间

### 6.7 本地生活服务与婚介

**服务承诺表述**：
- 房屋维修：不支持"具体时间+质保承诺"（"10 年质保""质保无忧"）；不支持承诺退款/一次性解决（"修不好不要钱""全额退款""一次性修复/补漏"）
- 美发护发：不得明示/暗示生发、防脱发、治疗脱发
- 美容/SPA：不得使用不可逆功效承诺（"祛斑""祛痘坑/痘印""去皱/眼袋"）
- 时效承诺通用：存在不可抗因素的须加"最快/快至"前缀（"同城配送最快 1 小时送达"）

**婚介特殊规范**：不得以"社交交友"形式推广（"陌生人交友""美女搭讪"）；不得含前卫婚恋理念（"试婚"）、擦边内容（"寂寞/情趣/激情/一夜情"）；不得出现"美女+床""美女+浴室/卧室"等敏感搭配；不得出现脱衣、劈腿、下蹲、扭臀等暗示动作；不得使用泄露个人信息的定位描述（"一分钟找到附近美女"类）。

### 6.8 房地产

**价格表述**：
- 不得使用具体价格，须**模糊表述**（"xxx 万起"）；须说明价格类型（"首付 XXX 万元起""XXX 万元起/平方"）
- 推广均价/一口价房需说明房源信息
- 首付比例：商性个人住房最低首付**不低于 15%**；支持"首期分期"且付款比例需 100%，**不支持"首付分期"描述**
- 房产平台/中介推广楼盘个数**不得少于 3 个**

**升值/投资回报禁用**："即将成为又一个陆家嘴""升值空间不可估量""增值/保值明智选择""高回报率""稀缺资产""楼王""地王""帝王核心区""买到即赚""稳升值"均禁。

**学区房限制**：
- 禁止承诺升学/学位；**禁止"学区房/学位房"字样**及"学府大盘、学府大宅、学院房"
- 禁止暗示性描述："XXX 学校在小区内""下楼就是学校""家门口""步行可达 XX 中学""直升 XX 校区"
- 禁止为入住者办理户口、就业、升学等承诺
- ✅ 支持：仅客观描述楼盘周围有学校（不承诺入学）；预售证项目名含"状元府/学院府"；自建幼儿园

**必须展示**：
- **预售证号**：新盘须在广告外层或落地页首屏标注；视频广告全程标注
- 面积须标注类型（套内建筑面积/建筑面积/使用面积）
- 规划/建设中设施须注明"规划中/建设中"并提交地图截图
- 须明确**代理商及开发商（产权方）**且与预售证开发商一致
- 推广贷款服务需说明付款方式、条件及时间；外层宣传周边地标未明确距离时，落地页须文字说明具体距离并标注数据来源

## 七、被拒后的处理流程

### 7.1 查看拒审原因

广告/创意详情页 →「管理」或「审核详情」→ 具体拒审理由和违规位置。

### 7.2 修改重提

按原因整改 → 重新提交，**重提无数量限制**。

### 7.3 申诉/复审

- 入口：投放管理平台「推广 - 广告创意 - 审核详情」侧「我要复审」
- 支持复审的订单需处于"审核中/已预约/推广中"状态
- 复审有**额度限制**（页面可查剩余额度）；**复审通过不占当天额度**
- 复审中不能重复提交；复审拒绝（元素未变更）不能再次申诉；复审通过则元素状态变更为通过
- 页面无复审按钮 → "编辑广告重新提交"

### 7.4 人工咨询

页面右上角 →「平台咨询」→ 输"转人工" → 选"素材审核"分类；备好广告 ID、素材 ID、拒审截图。

## 八、催审渠道与规则

| 审核对象 | 正常时效 | 超时效催审 |
|---------|---------|-----------|
| 开户/资质 | 工作日 24h / 节假日 48h | 超 8 小时 → 邮件 `ads_ss@tencent.com`（注明广告主 UID，多个逗号分隔、不同主体分开发）；催后约 3h 内完成 |
| 推广链接 | 工作日 24h / 非工作日 48h | 超时效 → 按文档流程发邮件提报催复审 |
| 广告专用视频号 | 工作日 24h / 节假日 48h | 超时效 → 按文档流程发邮件提报催审 |
| 普通广告/创意（素材） | 工作日 4h / 节假日 24h | 投放端**创意层级**点「催审/复审」按钮（广告创建满 24h 才显示） |

> 邮件催审参考文档（开户催复审 SOP）：https://docs.qq.com/doc/DVkt6WFBiWkFGYnZH

**普通创意催审三步走**：① 投放端创意层级自助催审 → ② 妙问输入「转人工」（与找行业经理时效一致）→ ③ 前两步试过且至少过 2 小时未解决，带妙问对话截图 + 催审模板找行业经理。**模板字段**：主体、账户 id、广告 id、创意 id、开户行业、诉求。多个 ID 用英文逗号分隔。

**关键规则**：时效内不支持催审（素材上线 24h 内、落地页 4h 内）；超 24 小时才有催审入口；开户催审工作日 21:00 后、周末节假日 17:00 后无法处理。

## 九、违规处罚体系

### 9.1 处置手段（从轻到重）

| 处置类型 | 具体措施 |
|---------|---------|
| 拒绝投放 | 自动驳回相关投放申请 |
| 下线内容 | 下线违规营销、清除违规内容、终止存量营销合作 |
| 限流 | 降低曝光优先级、限制商品/店铺/短视频流量 |
| 限制功能 | 限制投放新建、限制使用广告投放/短视频加热/直播带货 |
| 封停账户 | 封停违规账户、已开账户；情节严重封停主体下**全部有效账户** |
| 主体资格处罚 | **永久禁止该主体注册成为客户**、配置自动拒绝 |

## 十、广告合规核心要点

### 10.1 绝对化用语（《广告法》第九条）

**禁用**：国家级、最高级、最佳、顶级、第一品牌、极品、至尊、最受欢迎及同义近似词；**"最……之一"也禁用**。

**5 类客观表述可用（需证据）**：

| 类型 | 示例 | 证据 |
|------|------|------|
| 客观事实 | "XX 大赛第一名" | 获奖证明 |
| 时空顺序 | "首款/首发/独家/唯一" | 授权书/著作权证书 |
| 自我比较的分级 | "X 公司最大户型" | — |
| 行业标准认定的分级 | "特级/一级" | — |
| 经营理念 | "顾客第一、力求完美"（不误导） | — |

### 10.2 警示语规范

- 投资理财/招商加盟：图片、视频、落地页显著位置必须标注"产品有风险，投资需谨慎""投资有风险，入市需谨慎"；招商加盟需体现"创业/加盟有风险，投资需谨慎"，**视频需全程展示**
- 视频/音频广告：警示、免责信息须以**足以引起消费者注意**的形式（字体/颜色/时长）披露，不能被快速略过
- 警示语须避开边距安全区（竖版：左右 44px、上 147px、下 103px）

## 十二、答疑速查

| 问题 | 答案 |
|------|------|
| 周末审不审？ | 审（有值班），但时效更慢（素材 24h、落地页 48h） |
| 催审按钮在哪？ | 投放端**创意层级**，广告创建满 24h 才显示 |
| 被拒后能重提几次？ | 无数量限制 |
| 复审和重提怎么选？ | 有异议且订单为"审核中/已预约/推广中"→ 复审；元素要改 → 编辑重提 |
| 高峰期什么时候？ | 17:00-24:00 提交的审核可能延时 |
| 朋友圈图片文字能占多大？ | ≤ 图片总面积 30% |
| 视频警示语放哪？ | 中间左右两侧，避开边距安全区（竖版左右 44px/上 147px/下 103px），全程展示 |
| 贷款利率怎么写？ | 年化利率区间（6%-24%）+ 单利/复利注明，为主展示；不得只写日息 |
| 医美能用前后对比图吗？ | 不能用患者名义/形象做对比；客观展示须标"效果因人而异" |
| 学区房能提吗？ | 禁"学区房/学位房"字样及承诺入学；只能客观描述周边有学校 |
| 电商能写"原价"吗？ | 不能；被比较价以促销前 7 日内最低成交价为基准 |
| 什么情况封户？ | 一级违规封主体全部账户+永久禁入；二级违规多账户屡犯清退主体 |
