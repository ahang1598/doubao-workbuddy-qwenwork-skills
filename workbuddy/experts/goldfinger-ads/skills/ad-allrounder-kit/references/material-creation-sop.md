# 金融类产品素材创作 SOP（Material Creation SOP）

> 本文件是 `ai-analysis-expert-02` 产出**素材建议**时的条件触发参考：**当用户的产品是金融类产品时**，素材内容创作（文案/视频脚本）必须遵循本 SOP，先过合规、再出内容；**非金融产品走原有素材建议逻辑**（见诊断包 `account_buildup_strategy.md` 第六节）。
>
> 本 SOP 从 `ad-script-audit` skill 的 `script-creation-rules.md` 提炼通用化为"金融广告"创作框架。理财通/微证券等腾讯金融业务线的**完整 offer 专项细则、卖点池、参考文案库**仍以 `ad-script-audit` 为准，深度创作时加载该 skill。

---

## 〇、触发条件：什么时候用本 SOP

### 金融类产品识别
当项目基本盘的"行业/产品"属于以下任一，即触发本 SOP：

| 类别 | 举例 |
| :-- | :-- |
| 理财 | 银行理财、基金、固收+、定投、养老理财、腾讯理财通类 |
| 证券 | 股票开户、ETF、微证券类、券商服务 |
| 保险 | 险种推广、保险经纪 |
| 信贷 | 贷款、信用卡、消费金融（信贷类合规另有红线，参考本 SOP 通用部分） |
| 支付/钱包 | 余额理财、支付绑卡、数字货币（按监管口径） |

> 不确定时问用户一句："你这个产品涉及理财/证券/保险/信贷这些金融业务吗？" 是→用本 SOP；否→走原逻辑。

### 为什么金融要单独一套
金融广告受强监管：收益承诺、拉踩同业、绝对化用语、风险揭示等都有硬红线，违规直接无法过审甚至处罚。所以金融素材必须**合规先行**，不能像普通商品文案那样自由发挥。

---

## 一、创作 SOP（合规先行 · 强制顺序）

> ⚠️ **合规先行原则**：必须严格按"第0步 → 第一步 → …… → 第六步"顺序执行。**第0步是所有创作的硬门槛，必须在动笔写任何一句文案之前完成**，不得先写后审。任何一句文案落笔前都要先过第0步红线清单，命中即不许写。

### 第0步：合规红线前置门槛（落笔前必过）

动笔前先加载并锁定合规红线，作为写作全程的硬约束：

**锁定高频踩坑红线（写作全程不得触碰）：**
- ❌ "存钱"/"储蓄"/"攒钱"及同义表达（金融广告硬红线，最易漏）
- ❌ 拉踩/负面定性其他投资方式（"比活期强"/"比定期划算"/"比股票稳"/"活期利息少得可怜"/"不想像股票那样大起大落"等，含"用户不想要"口吻的点名对比）
- ❌ 收益承诺未加缓和词（"安心/心安/稳健/稳中求进/收益升级"等前面须有"力争/争取/追求/或"；"省心/求稳求赚"除外）
- ❌ 术语化/结论悬空（行话堆砌，或把配置比例单独甩出而无产品名铺垫）
- ❌ 政治敏感/热点舆情/借势负向事件
- ❌ 绝对化用语（"最""第一""保证""稳赚""保本"等，金融广告法禁词）

**锁定痛点写法（求稳类金融产品强制）：**
痛点只能从**用户自身需求/偏好**切入，**不得靠贬低活期、对比银行、点名股票/炒股制造痛点**。
- ✅ 推荐："既想求稳，又想比活期多赚一点"（"活期"作中性参照）/ "想让闲钱稳中有进" / "想要波动小一点，又不甘心太保守"
- ❌ 禁止：任何点名"股票/炒股"的对比，含"用户不想要"口吻（"不想像股票那样大起大落"等）

**锁定配置比例/术语用法（固收+/配置类强制）：**
- 配置比例（如 70%固收/30%权益）是产品独有卖点，**必须先亮产品名、再展开配置**，禁止单独甩出。
- **短文案（≤30字）禁止硬塞配置比例细节**（放不下且结论悬空），只在能讲清楚的长文案/脚本里用。
- 禁止行话（"股市弹性机会"等），改说人话。

> 腾讯理财通/微证券的 offer 专项红线（固收+/机构代投/额度宝/亲情账户/免股票开户/微证券等）详见 `ad-script-audit` 的 `references/offer-rules.md`，深度创作时加载。

完成第0步后方可进入第一步。

### 第一步：收集创意简报

确认以下信息（用户已提供的跳过）：

| 信息项 | 说明 |
| :-- | :-- |
| 业务线/产品 | 具体金融产品（理财/证券/保险/信贷等） |
| Offer | 细分卖点包（如固收+/机构代投/ETF等） |
| 素材类型 | 信息流外层文案（≤30字）/ 15s创意短视频 / 30-60s单人口播 / 30-60s多人剧情 |
| 核心卖点 | 1-2 个，来自产品卖点池（非伪卖点） |
| 目标用户 | 谁在看？他们的痛点是什么？ |
| 传播场景 | 朋友圈 / 视频号 / 公众号 / 搜一搜 |

### 第二步：加载规则和参考

- 本 SOP（通用金融创作框架）
- 腾讯金融业务线：加载 `ad-script-audit` 的 `offer-rules.md`（卖点池+offer专项红线）+ `script-review-rules.md`（脚本结构规范）+（机构代投时）`offer-copy-reference.md`（参考文案库）
- 其他金融机构产品：参考本 SOP 通用红线 + 该机构/平台的合规要求

### 第三步：结构搭建

按脚本结构规范搭建框架：

```
【标题】（非必要，15字以内）
【钩子】（非必要，≤15字，身份筛选/身份认同）
【痛点】（必要，核心矛盾/反差/悬念/共鸣——须从用户自身需求切入，见第0步）
【利益锚定】（必要，不行动的后果或行动的好处）
【产品植入】（必要，品牌+卖点+解决方案）
【行动指令】（非必要，CTA引导）
```

⚠️ **15s 短视频**：只保留【钩子】+【产品植入】+【行动指令】，一个核心冲突+一个卖点+CTA。

### 第四步：文案/脚本撰写

#### 外层文案规则（≤30字）
- 只打一个核心卖点，不堆砌
- 一字不差嵌入合规备案词（金融产品常有备案要求）
- 围绕产品卖点池选取表达
- 短文案禁塞配置比例/术语细节

#### 脚本撰写规则

**单人口播（150-250字）：**
- 对话感：像一个人在跟朋友说话
- 人设一致：前后语气/用词/立场一致
- 口语自然：有语气词和停顿感
- 逻辑递进：发现问题 → 分析困境 → 给方向
- 节奏控制：信息密度有变化

**多人剧情（250-300字）：**
- 场景真实：贴近目标受众生活
- 角色区分：A/B/C 辨识度清晰
- 冲突设计：有效冲突推动剧情
- 产品植入自然：聊着天自然引出产品，避免硬念广告
- 对话真实度：允许不完整句，拒绝像背台词

### 第五步：自审自查（产出后必过）

逐条对照清单自查，不通过的当场改：

- [ ] 【通用红线】是否出现"存钱"/"储蓄"/"攒钱"及同义表达？（🔴 硬违规，最易漏，必查）
- [ ] 卖点是否来自产品卖点池（非伪卖点）？
- [ ] 产品名是否完整出现？
- [ ] 是否有收益承诺（赚钱/发财/稳健/收益升级等未加缓和词）？
- [ ] 是否拉踩/负面定性其他投资方式（"比XX强"/"活期利息少得可怜"/"不想像股票那样大起大落"等）？
- [ ] 【痛点写法】痛点是否从用户自身需求切入，而非靠贬低活期/对比银行/点名股票制造？
- [ ] 【术语与配置】短文案是否硬塞了配置比例或术语行话？配置比例是否先亮产品名再展开？
- [ ] 是否有绝对化用语（"最/第一/保证/稳赚/保本"）？
- [ ] 开头是否为寒暄式开场（"大家好""今天分享"等）？
- [ ] 字数是否在合理范围内（15s:80-120字 / 单人:150-250字 / 多人:250-300字）？
- [ ] 文案是否含合规备案词且一字不差？

自审不通过的条目，当场修改后重新过清单。全部通过后再输出。

### 第六步：输出

输出的脚本末尾标注字数（只统计台词文字，不含画面描述，标点不计入），并附自审通过标记（须显式勾选"无存/攒/储蓄""痛点未贬活期/未点名股票"两项高频踩坑项）。

## 二、写作禁区（通用）

- ❌ 不要用"首先...其次...最后"结构（AI感）
- ❌ 不要用排比堆砌、无停顿感的长句
- ❌ 不要用外显广告腔（"我不允许你不知道""安利给你"等）
- ❌ 不要拼接感——不能像把多段合规表达无脑拼在一起
- ❌ 不要机械重复产品名——首次出现后自然指代
- ❌ 不要"大家好""今天分享""hello朋友们"等寒暄开场

## 三、写作好标准

- ✅ 钩子让用户刷到前 1.5 秒想停下来看
- ✅ 好钩子特征：先给结果/冲突再补背景、用疑问/感叹制造情绪张力
- ✅ 每句话读完，下一句是用户自然想问或想知道的
- ✅ 痛点精准、有情绪冲击力
- ✅ 产品植入丝滑不突兀
- ✅ **合规但情绪不塌**——不能用合规的方式写出平淡的文案

## 四、与 02 包素材建议的衔接

### 起量路径（基建纪要输入）
02 包 Step3 第4项"素材准备清单"产出素材池建议时：
- **金融产品** → 素材池的"内容怎么写"叠加本 SOP：每条素材的脚本/文案创作走"合规先行→简报→结构→撰写→自审→输出"，产出时附自审标记
- **非金融产品** → 走原有素材建议逻辑（形式/卖点矩阵/钩子/池轮换，见 `account_buildup_strategy.md` 第六节），不强制本 SOP

### 优化路径（诊断纪要输入）
02 包 Step3 优化路径涉及素材维度（换素材/调素材/上新素材）时：
- **金融产品** → 新产出的素材内容同样走本 SOP 合规先行 + 自审
- **非金融产品** → 走原逻辑

### 判定等级（素材审核时参考 `ad-script-audit`）
金融素材若需审核，判定等级沿用 `ad-script-audit`：
- 🔴 必须修改：合规红线/严重逻辑错误，不改不能用
- 🟡 建议修改：表达生硬/逻辑衔接弱/吸引力不足
- 🟠 需要关注：模糊地带或争议点，需人工确认
- 🟢 可以通过

## 五、Pitfalls（金融素材专项）

1. **合规先行不能事后补**：第0步必须在动笔前完成，先写后审必踩红线。
2. **"存/攒/储蓄"最易漏**：口语化表达里很容易冒出来，自审必查。
3. **拉踩不只"比XX强"**："不想像股票那样大起大落"这种"用户不想要"口吻的点名对比也算拉踩。
4. **痛点别贬活期/点名股票**：求稳类痛点只从用户自身偏好切入。
5. **短文案别塞配置比例**：≤30字放不下且结论悬空，配置比例只在长文案/脚本用且先亮产品名。
6. **合规但情绪不塌**：不能因为怕违规就写出平淡文案，合规与吸引力要兼顾。
7. **腾讯金融业务线深度创作**：固收+/机构代投/额度宝等 offer 的完整卖点池和专项细则，加载 `ad-script-audit` 的 `offer-rules.md`，别凭记忆写。
