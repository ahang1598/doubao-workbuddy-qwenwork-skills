# 三维优化方法论 (Optimization Logic) — 人群 / 版位 / 素材

> 本文是「AI投手·优化包」的核心方法论，**行业通用、不绑定具体项目**。它回答两个问题：
> 1. 拿到诊断结论后，**从哪三个维度往下找优化空间**（人群 / 版位 / 素材）？
> 2. 每个维度怎么**诊断**（找问题）、往**哪个方向优化**（给方向）？
>
> ⚠️ 通用方法论给的是**方向和框架**，不是某个项目的具体打法。真正贴合项目的策略，必须叠加用户的**历史优化经验**——见文末「历史打法注入闸门」。

---

## 〇、三维总览

广告效果 = **对的人（人群）× 在对的地方看到（版位）× 看到对的东西（素材）**。
三者任一短板都会拖垮 CPA/ROI。优化时按「**先定位短板维度，再在该维度下钻**」的顺序，不要三维同时大改（无法归因）。

| 维度 | 一句话 | 主要抓手 | 短板的典型信号 |
| :-- | :-- | :-- | :-- |
| **人群** | 投给谁 | 定向方式、人群包、出价模型找人 | CVR 低、转化人群与目标人群错位、跑不出量 |
| **版位** | 在哪露出 | 自动/手动版位、各版位成本结构 | 某版位吃量但成本高、版位间 CTR/CVR 断层 |
| **素材** | 给他看什么 | 创意形式、卖点、衰退节奏 | CTR 低、素材衰退、同质化、单素材吃量 |

**与三因子的对应**（CPA = CPM /(CTR×CVR×1000)）：
- **CTR 低** → 优先查 **素材**（吸引力）与 **版位**（人货场匹配）
- **CVR 低** → 优先查 **人群**（精准度）与 **落地页/转化链路**
- **CPM 高** → 优先查 **版位**（竞争激烈版位）与 **人群**（人群包过窄推高竞价）

---

## 一、人群维度（投给谁）

### 1.1 诊断（找问题）
- **定向结构**：当前用的是系统智能定向 / 人群包 / 自定义标签？过窄（推高 CPM、跑不出量）还是过宽（CVR 低、空耗）？
- **人群分化**：把计划按人群标签（新客/流失/兴趣/地域/年龄）下钻，看各人群的 CVR 与 CPA 分化，定位高价值与高耗损人群。
- **模型找人质量**：oCPM/oCPA 下模型找的人和你的目标人群是否一致（看转化人群画像 vs 目标画像）。
- **学习期状态**：人群包是否还在冷启动、是否频繁改定向打断模型学习。

### 1.2 优化方向（给方向，不是定论）
| 信号 | 优化方向 |
| :-- | :-- |
| 定向过窄、CPM 高跑不出量 | 放宽定向 / 用系统智能扩量 / 叠加 lookalike 放大种子人群 |
| 定向过宽、CVR 低空耗 | 收窄到高转化人群包 / 排除低质人群 / 用转化数据回流训练模型 |
| 某高价值人群被淹没 | 拆分独立计划单独出价，给足预算保护 |
| 模型找人偏移 | 用高质量转化回传校正模型 / 重设优化目标到更深层转化 |
| 人群包枯竭、频次过高 | 拓新人群包 / 排除已转化人群 / 控频 |

### 1.3 纪律
- 改定向 = 打断模型学习，**单次只改一处**，给足重新学习的观察窗口（通常 1-3 天）。
- 高价值人群「拆出来单独投」优于「在大计划里混投」。

## 二、版位维度（在哪露出）

### 2.1 诊断（找问题）
- **自动 vs 手动**：当前是优选（自动）版位还是手动指定？自动版位时，各版位的消耗/成本是否被系统拉偏到某个低质版位？
- **版位成本结构**：按版位下钻 CPM / CTR / CVR / CPA，定位「吃量但成本高」和「成本低但量小」的版位。
- **版位与素材匹配**：同一素材在不同版位的表现差异（如信息流 vs 激励视频 vs 搜索）。
- **版位与人货场**：版位的流量场景是否匹配产品（如重决策产品放在沉浸式版位转化更好）。

### 2.2 优化方向
| 信号 | 优化方向 |
| :-- | :-- |
| 自动版位被拉偏到低质版位空耗 | 切手动版位排除低质 / 用版位出价系数压制 |
| 某版位 CPA 显著低 | 单独建计划放大该版位预算 |
| 某版位 CTR 高但 CVR 低 | 该版位人群浅，配更强转化引导素材或换深层目标 |
| 版位太集中、量级见顶 | 谨慎放开更多版位探索增量（小预算测试） |
| 高竞争版位 CPM 飙升 | 错峰投放 / 转向竞争较小的版位补量 |

### 2.3 纪律
- 版位调整先用**小预算测试**再放量，避免一次性切版位导致模型重启。
- 不要为了"覆盖全版位"而牺牲成本，**优先保成本达标的版位**。

## 三、素材维度（给他看什么）

### 3.1 诊断（找问题）
- **CTR 表现**：素材 CTR 是否低于账户/行业基线？低 CTR 直接推高 CPM。
- **素材衰退**：单素材的 CTR/转化随时间下滑曲线，是否进入衰退期（通常 >14-21 天或 3 日连续下滑）。
- **同质化与集中度**：是否单条素材吃掉大部分消耗（抗风险差）？素材库是否同质化（卖点/形式雷同）？
- **形式与卖点**：当前主力是图片/视频/原生？主打卖点是否打中目标人群的核心诉求（JTBD）？
- **前 3 秒 / 首屏**：视频前 3 秒、图片首屏的钩子是否够强（这是 CTR 的核心杠杆）。

### 3.2 优化方向
| 信号 | 优化方向 |
| :-- | :-- |
| CTR 全面偏低 | 换钩子/前 3 秒、测新卖点、提升素材原生感 |
| 单素材吃量、抗风险差 | 批量上新同方向变体，分散依赖 |
| 素材进入衰退期 | 提前上新替换，不等跑死才补 |
| 同质化严重 | 拓展卖点矩阵（功能/情感/价格/场景多角度） |
| CTR 高但 CVR 低 | 素材"标题党"与落地页脱节，统一素材与转化承诺 |
| 某卖点/形式跑得好 | 围绕爆款做系列衍生，复制成功结构 |

### 3.3 上新节奏（通用基线）
- 每 3-5 天上新 1-2 条测试素材，保持素材库始终有新鲜供给。
- 新素材小预算冷启动，跑出来的进主力，跑不动的快速淘汰。
- **爆款不是终点**：爆款素材也会衰退，提前准备接棒。

### 3.4 纪律
- 素材测试要**控制变量**（一次测一个钩子/卖点），否则无法归因。
- 不要因单日数据仓促判死一条素材，给冷启动窗口。

## 四、三维联动与优化顺序

```
诊断结论（来自诊断包）
   │
   ├─ 主因是 CVR 低 ──→ 先查【人群】是否错位、再查转化链路
   ├─ 主因是 CTR 低 ──→ 先查【素材】钩子、再查【版位】匹配
   └─ 主因是 CPM 高 ──→ 先查【版位】竞争、再查【人群】过窄
        │
        ▼
   定位单一短板维度 → 在该维度下钻出 1-2 个具体动作 → 小步验证 → 再动下一维度
```

> **核心纪律：一次只动一个维度的一个变量**，否则效果无法归因，优化会变成赌博。

## 五、防误杀止损框架（跨优化师通用纪律）

> 三维优化会不断产生「关停 / 保留 / 扩量」的止损决策。为避免被单日流量与转化波动误导而**误杀好计划**，所有优化师（尤其 CostCutter / Profiteer / Balancer）在做止损判定时都应引用本框架。

### 5.1 决策口径纪律
- **主口径用近 7 天综合数据**，单日实时值**仅作异动预警**，不作直接关停依据。
- **只用真实转化宽口径**（如付费 ROI = 付费金额 / 消耗、有效线索成本），**坚决剔除曝光归因等虚荣口径**，避免高估效益导致该关的没关。

### 5.2 预警 → 复核两步走
1. **预警（单日实时）**：今日有一定消耗（超过最低门槛）且实时 ROI/CPA 破盈亏线 → 列入观察名单，**先不动**。
2. **复核（7 天判定）**：进入 7 天阶梯判定；7 天指标达标则**坚定保留**（防误杀），破红线才关停。

### 5.3 三层阶梯防误杀（按消耗体量分档）
越低耗容忍越松、越高耗要求越严，避免用同一把尺子误杀试错期计划：

| 档位 | 消耗体量 | 判定思路 |
| :-- | :-- | :-- |
| 低耗试错期 | 消耗很低 | 用**最宽松**阈值判死（还没跑出数据，多给机会） |
| 放量观察期 | 中等消耗 | 用**中档**阈值 |
| 稳定拓量期 | 高消耗 | 用**最严**阈值（体量大，破线即失血） |

> ⚠️ 各档的**具体阈值随项目考核口径填**（写入项目 config / 诊断纪要），通用框架只固定「三层阶梯」结构与「低耗松、高耗严」的方向。

### 5.4 衰退与素材枯竭
- **衰退止损**：监控昔日霸榜计划，一旦 7 天指标跌破所在档红线，立即确认衰退并关停，规避「最大亏损源」陷阱。
- **素材枯竭预警**：每日盘点「通过防误杀保留的计划数 + 日均消耗承接力」，当保留计划撑不起日预算时触发最高级预警、催新素材——**止损不能把盘子砍到没量可跑**。

## 🚪 历史打法注入闸门（必做，本文方法论的"最后一公里"）

通用方法论只能给**方向**。要产出**真正贴合你项目的策略**，必须叠加你的历史经验。在进入具体优化动作前，请用户提供：

> **请提供你现成的人群 / 版位 / 素材打法文档或要点**（任意形式：文档、表格、几条经验、过往复盘）。我会据此把上面的通用方向，改写成更贴合你项目实际情况的策略。

采集要点（缺什么问什么，不强求全有）：

| 维度 | 想了解的历史经验 |
| :-- | :-- |
| 人群 | 哪些人群包/定向跑得好？哪些是禁区？有没有沉淀的高质量种子人群？ |
| 版位 | 哪些版位是主力/雷区？版位出价系数的历史经验？ |
| 素材 | 哪些卖点/形式/钩子是爆款规律？素材衰退周期一般多久？上新节奏惯例？ |
| 规则 | 历史上固化的操作规则（如"CTR<X% 就换素材""某版位永远排除"）？ |

**处理逻辑**：
1. 用户**有**历史打法文档/要点 → 读取后，把本文的通用方向**逐条对齐到用户经验**，冲突处以用户实战经验为准，并标注"据你的历史打法调整"。
2. 用户**暂无** → 先用通用方法论搭出初版策略，明确标注"基于通用方法论，建议跑通后沉淀为项目专属打法"，并在后续运行中逐步积累。

> 这一步把"通用框架"变成"你的打法"，是优化策略能落地的关键。产出的项目专属策略，应写入《优化策略纪要》供执行环节使用。
