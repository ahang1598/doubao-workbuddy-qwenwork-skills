# 第一部分　底层机制：广告是怎么被卖出去的

## 1.1 最重要的认知：你买的不是广告位，是每一次曝光的竞拍资格

同一个广告位，每次用户刷新都**重开一次拍卖**，一天被拍卖千万次。

| 同一广告位   | 中标者   | 中标原因   |
| ------- | ----- | ------ |
| 第 1 次曝光 | 广告主 A | A 出价最高 |
| 第 2 次曝光 | 广告主 B | B 素材更好 |
| 第 3 次曝光 | 广告主 C | C 定向更准 |

所以「广告位好不好」是伪问题，真问题是「你这一次的竞拍能力够不够」。

## 1.2 程序化广告的五个角色

```
广告主（投放后台）  设定 定向 / 出价 / 预算 / 素材
      ↓
DSP 需求方平台      替广告主自动竞价、买量
      ↓
ADX 广告交易市场    拍卖在这里发生，全程约 100ms
      ↓
SSP 供给方平台      替媒体接询价、卖流量
      ↓
媒体 App            广告位的主人
      ↓
用户屏幕            0.1 秒后刷到广告
```

外加 **DMP 人群数据银行**，在旁边为定向和预估供料。

一句话：买卖双方各请一个代理，在中间市场成交，数据银行供料。

## 1.3 eCPM：决定一切的唯一货币

> **eCPM = 出价 × 预估点击率(pCTR) × 预估转化率(pCVR) × 1000**
>
> 部分资料会加上 **+ hiddencost**（平台隐藏调控手段），指平台不公开的干预项。

**eCPM 是平台视角的指标，不是广告主视角的。** 它衡量的是「这 1000 次曝光给你，平台能赚多少钱」。平台只做一件事：把曝光卖给愿意为它付最多钱的人。

**不同计费方式如何统一折算**：

| 计费方式 | eCPM 算法                          | 说明                       |
| ---- | -------------------------------- | ------------------------ |
| CPM  | eCPM = CPM 出价                    | 最简单，无预估环节                |
| CPC  | eCPM = CPC 出价 × CTR × 1000       | 点击率越高，同价平台赚越多            |
| CPA  | eCPM = CPA 出价 × CTR × CVR × 1000 | CTR 和 CVR 任一拉胯，eCPM 都上不去 |
| oCPX | 同 CPA                            | 平台内部预估 CTR/CVR 后折算排序     |

**为什么需要统一折算**：不同出价方式像不同货币，同样金额的美元和英镑价值不同，必须换算成同一标准才能比较。

举例：A（CPC 2 元，CTR 3%）→ eCPM 60；B（CPA 100 元，CTR 3%，CVR 5%）→ eCPM 150；C（CPM 30 元）→ eCPM 30。**平台把曝光给 B。**



**推论（极其重要）**：

- 相同出价下，点击率和转化率越高，跑出概率越高；
- 相同 eCPM 下，点击率和转化率越高，**能接受的出价就越低**，最终成本越低；
- 所以「把素材做好」等于「变相加价」。

## 1.4 广告从请求到展示的完整链路（约 100 毫秒）

**第 1 站 · 触发**：用户刷出下一屏 → 广告位 → SSP 接住请求，打包成 Ad Request：

- **谁**：设备 ID、人群标签、历史行为
- **哪**：哪个 App、哪个广告位、内容场景
- **何时**：时间、地理、网络（WiFi/4G）

**第 2 站 · 询价**：ADX 把这次曝光连同请求包，同时群发给所有 DSP（Bid Request）。

**第 3 站 · 决策**：DSP 在 100ms 内做 4 道判断：

1. 定向匹配上了吗？否 → 连价都不出，直接放弃
2. 预估 pCTR × pCVR（调用 DMP 数据 + 历史模型）
3. 套上你的出价，算这次曝光该报多少
4. 提交 Bid，进入竞价排序

**第 4 站 · 竞价**：按 eCPM 排序，最高者胜出。

**第 5 站 · 展示**，时间分布：

| 时间点      | 发生什么               |
| -------- | ------------------ |
| 0 ms     | 用户刷新，发起请求          |
| 约 12 ms  | ADX 广播询价           |
| 30–80 ms | DSP 并行出价（耗时大头，占一半） |
| 约 85 ms  | 竞价排序定胜负            |
| 约 95 ms  | 赢家返回 + 渲染          |
| 100 ms   | 用户看到广告             |

**关键推论**：定向太窄，DSP 连出价资格都没有——你可能是自己把自己挡在了竞价门外。

## 1.5 流量分配的六道关卡：eCPM 排序之前和之后

很多人只知道 eCPM 排序，却不知道排序前有四道资格赛、排序本身分粗排精排两轮。**任一道没过，eCPM 再高都没用。**

### 资格赛（eCPM 排序之前的四道过滤）

| 关卡   | 管什么   | 常见踩坑                                     |
| ---- | ----- | ---------------------------------------- |
| 定向过滤 | 谁可以看  | 三个定向条件叠加可能筛掉 90% 用户，"精准过头就是自己把自己关在门外"    |
| 预算余额 | 有没有钱  | 余额为零立刻停投，日预算耗完当天结束                       |
| 频次控制 | 看太多不行 | 同一用户一天看 1 次正常、3 次还行、5 次以上系统干预、10 次以上直接降权 |
| 用户体验 | 用户烦不烦 | 点过"不感兴趣"、举报、长时间暂停、创意多样性太差（判同质化）都会降权      |

### 预赛：粗排

一个广告位只能展示 3-10 条，候选池有几百到几千条。粗排用**轻量级模型**快速砍掉 80%，只留前 20%。因为一次广告展示只有约 100 毫秒，全送深度模型算不过来。

粗排只认基本指标：出价、**历史** CTR、**历史** eCPM、类目匹配度、基础人群标签。原则是「快」不是「准」，宁可误杀不能拖慢。

⚠️ 注意「历史」二字——**新账户、新素材天然劣势**：没历史 CTR、没历史 eCPM，预估空白≈保守预估。这是"同样素材老账户有量新账户没量"的根本原因，解法不是提价，是熬过冷启动。

### 决赛：精排

粗排筛出的 200-500 条进精排，深度模型上场，特征从几十维升到 200 多维，选出前 50 条进 GSP 竞价。算力是粗排的几十倍。

精排看的远不止出价×CTR×CVR，还包括：

- 实时预估 CTR（这个人此刻在这个页面看到这条广告的点击概率）
- 实时预估 CVR（用回传信号训练）
- 素材多模态特征（AI 视觉模型分析标题/图片/画面）
- 用户行为序列（意图轨迹）
- 上下文特征（时间/天气/城市/页面内容）
- 交叉注意力（动态匹配度）

## 1.6 GSP 计费：你赢了却只付第二名的钱

**广义第二价格拍卖（GSP）**：赢家实付的不是自己的出价，而是「压过第二名所需的最低价」。

现代广告系统采用的是**第二密封价格拍卖**（维克里拍卖），改良后的非公开拍卖方式。

**两种等价表述**（不同资料写法不同，本质一致）：

- 简化版：你出 ¥10，第 2 名 ¥6 → 实付 ¥6.01
- 折算版：你出价 60、CTR 2.5%、eCPM 100 最高，第二名 eCPM 85 → 实际扣费 = 85 ÷ 2.5% = ¥34（而非 60）

**为什么这么设计**：机制鼓励说真话。高出价不会让你多花钱，只会让你多赢。

**但要注意边界**：GSP 保证「价高者不亏」，**不保证「价高者一定赚」**——竞争激烈时实际扣费会被顶高。

**时段套利**：晚 8-10 点竞争最激烈、实际扣费高；上午 10-12 点竞争缓和，实际扣费可能低 30%。

## 1.7 名义公式之外的三个隐藏变量

### 变量一：账户历史权重（信任分）

> **实际 eCPM = 名义 eCPM × 账户权重**

| 加分项     | 扣分项        |
| ------- | ---------- |
| 历史累计转化多 | 成本忽高忽低     |
| 消耗稳定    | 经常暂停、频繁修改  |
| 素材持续更新  | 素材长期不换     |
| 无违规记录   | 有拒审、举报     |
| 账户活跃度高  | 长期不投突然大量新建 |

这解释了**马太效应**：大账户数据多 → 模型准 → 预估准 → 拿量效率高 → 越跑越便宜；小账户反之，越跑越贵。

### 变量二：素材新鲜度衰减

**最近 7 天数据的权重是 30 天前的 3-4 倍。** 素材跑两周后，系统评分已在悄悄下调。

所以素材要持续上新——不是为了堆量，是为了**维持新鲜度评分**。

### 变量三：平台策略干预（不透明、不可改）

- 某些行业有流量配额
- 大促期间品牌广告吃掉优质流量
- 新账户可能被分到「低优先级」队列
- 平台自身商业化策略（某时段优先推某品类）

对这类变量只能预判、不能对抗，把可控变量做好即可。

## 1.8 账户被限量的常见原因

不是"被针对"，而是踩了具体规则：

1. 定向过窄，候选池不足
2. 预算/余额不足触发流控
3. 频次控制触发（同一用户重复曝光过多）
4. 负向反馈累积（不感兴趣、举报）
5. 创意同质化被判定重复投放
6. 素材搬运被识别，打上搬运标签后基本限制跑量
7. 账户权重低（新户或有违规史）

## 1.9 你能控的四个旋钮，与系统的黑箱边界

| 你能控             | 系统决定（黑箱）        |
| --------------- | --------------- |
| **定向**：圈谁来看     | 竞价怎么排（按 eCPM）   |
| **出价**：为一次转化报的价 | 出价怎么翻译（转化价→曝光价） |
| **预算**：每天弹药与节奏  | 流量给谁多少（探索与分配）   |
| **素材+落地页**：钩子强弱 | 要学多久才稳（冷启动节奏）   |

**核心原则**：别跟系统抢方向盘。把这 4 个旋钮拧到最好，剩下的信任并喂养黑箱。

## 1.10 三方博弈：理解平台的真实动机

投放不是广告主和平台较劲，是**平台、广告主、用户**三方博弈。

| 角色  | 核心诉求                   | 真实底线            |
| --- | ---------------------- | --------------- |
| 平台  | 每个流量商业价值最大化（eCPM 越高越好） | 体验不能差到导致用户流失    |
| 广告主 | 最低成本拿最多有效转化（ROI 越高越好）  | 成本不能高于盈亏平衡点     |
| 用户  | 看感兴趣的内容，最好别有广告         | 广告别太烦，烦了就卸载/切竞品 |

**权力结构**：平台是规则制定者（最强），广告主是出钱的乙方（夹心层），用户个体最弱、集体最强（用脚投票）。

**平台算法的四个隐性倾向**：

1. 偏好高质量广告（pCTR×pCVR 高天然 eCPM 高）
2. 偏好大预算广告主——**注意，偏好的不是"钱多"，是大预算带来的"模型确定性"**，pCVR 预估更准、风险更小
3. 偏好贴近原生内容的广告——**素材不是要做得像广告，是要做得不像广告**
4. 偏好合规、生态友好的广告

**平台没有偏见，只有利益最大化**——短期利益与长期利益的平衡。

### 处于 eCPM 劣势时的四条对抗策略

| 策略                 | 做法                                   | 原理                |
| ------------------ | ------------------------------------ | ----------------- |
| 深度转化目标绕开浅层竞争       | 大家投激活时，你改投付费/ROI/次留                  | 避开红海              |
| 人群包精准化降低 pCVR 不确定性 | 用一方数据（高价值用户 lookalike）告诉系统"这些人大概率转化" | 抬升 eCPM 预估        |
| 预算节奏与时段错峰          | 错开黄金档，走凌晨/午间/工作日上午                   | 竞争缓和，扣费低          |
| 找生态位蓝海             | 判断标准：这个流量池里 eCPM 比你高的广告主不够多          | 头部扎堆是红海，头部看不上的是蓝海 |

**记住**：你的真正对手不是平台，是同一流量池里的所有广告主。

# 第二部分　指标体系：每个数字到底在衡量什么

## 2.1 一张图看懂：所有指标都挂在转化链路上

```
展现 → 点击 → 下载 → 安装激活 → 行为(注册等) → 付费
 ↓      ↓      ↓        ↓            ↓          ↓
CPM    CPC    CPD      CPI          CPA        CPP
CTR    CVR                                   ROI/ROAS
```

**每一个指标就是这条链路上的一个节点。** 指标不是孤立的，是沿用户路径一环扣一环。

## 2.2 成本类指标：分母决定了它是谁

| 指标      | 全称                | 公式              | 衡量什么         |
| ------- | ----------------- | --------------- | ------------ |
| **CPM** | Cost Per Mille    | 消耗 ÷ 展示量 × 1000 | 流量价格（千次曝光成本） |
| **CPC** | Cost Per Click    | 消耗 ÷ 点击量        | 单次点击成本       |
| **CPD** | Cost Per Download | 消耗 ÷ 下载量        | 单次下载成本       |
| **CPI** | Cost Per Install  | 消耗 ÷ 安装(激活)量    | 单个新增用户成本     |
| **CPA** | Cost Per Action   | 消耗 ÷ 行动完成数      | 单次指定行动成本     |
| **CPP** | Cost Per Purchase | 消耗 ÷ 付费次数       | 单次付费成本       |

**推导关系**（同一件事的不同拆法，都成立）：

> CPC = CPM ÷ (CTR × 1000)  
> **CPA = CPC ÷ CVR**  
> CPA = CPM ÷ (CTR × CVR × 1000)

> ⚠️ **勘误**：部分原始资料把 CPA 写成 `CPC + CVR`、`CPC - CVR` 或 `CPC × CVR`，均为笔误。**正确关系是除法：CPA = CPC ÷ CVR。**
>
> **数值验算**：消耗 1000 元、点击 500 次、转化 25 个 → CPC = 2 元，CVR = 5%，真实 CPA = 1000 ÷ 25 = **40 元**。  
> `CPC ÷ CVR = 2 ÷ 0.05 = 40` ✓ 吻合；`CPC × CVR = 2 × 0.05 = 0.1` ✗ 差 400 倍。
>
> **量纲验算**：元/点击 ÷ (转化/点击) = 元/转化 ✓；乘法得「元·转化/点击²」无意义 ✗。
>
> **直觉判断**：一次转化至少需要一次点击，所以 **CPA 必然 ≥ CPC**，而乘法必然得出比 CPC 更小的值。
>
> 💡 **易混淆点**：乘法出现在 eCPM 公式（`eCPM = 出价 × CTR × CVR × 1000`）——那里 CTR/CVR 作为**概率连乘**是正确的；但 CPA 的拆解方向相反，是除法。

**降 CPA 只有两条路**（由公式直接得出）：前端提 CTR（优化素材），后端提 CVR（优化落地页与承接）。

### 几个容易踩的坑

- **CPM 高不一定是坏事**。各平台/行业/产品都有正常波动区间，在区间内确保覆盖目标人群即可。不建议为降 CPM 硬铺低价值泛流量。CPM 异常高通常是竞争激烈，或平台判定内容质量低。
- **CPC 只是过程指标**。CPC 高但进来的是精准高质量用户就不亏。要看「点击质量的代价」而非单纯点击成本。
- **CPD ≠ CPI**。有人下载到一半取消、下载完没安装。若 CPD 和 CPI 差距异常大，说明下载安装流程有卡点。
- **CPD 有两个含义**：投放圈常指 Cost Per Download，品牌广告里也可能指 Cost Per Day（按天包断），需看上下文。
- **CPP 只看"有没有付费"，不看"付了多少"**。首充 1 元和首充 100 元在 CPP 里都算一次付费。

## 2.3 效率类指标

| 指标          | 公式                           | 衡量什么       |
| ----------- | ---------------------------- | ---------- |
| **CTR** 点击率 | 点击量 ÷ 展示量 **× 100%**         | 素材和标题吸不吸引人 |
| **CVR** 转化率 | 转化数 ÷ 点击量 **× 100%**         | 流量承接效率     |
| **CTCVR**   | CTR × CVR = 转化量 ÷ 曝光量 × 100% | 曝光到转化的整体效率 |

> ⚠️ **勘误**：部分原始资料把 CTR/CVR 写成「× 1000」，是笔误。点击率、转化率都是**百分比**，乘数为 100%。若按 ×1000 计算会得出"点击率 20"这种无意义的值。

**分工要分清**：素材决定前端 CTR，落地页和产品承接决定后端 CVR。

**CTR 不是越高越好**——标题党骗点击会拉高 CTR，但点进来发现货不对板，后端转化会很差。**CTR 必须和后端转化一起看。**

**CTCVR 的意义**：CTR 1% × CVR 10% 和 CTR 10% × CVR 1% 的 CTCVR 都是 0.1%，但两者问题完全不同——前者素材差，后者承接差。所以不能只看 CTCVR，要拆开看。

## 2.4 结果类指标：ROI 与 ROAS 的根本区别

|       | **ROAS**（广告支出回报率）  | **ROI**（投资回报率）        |
| ----- | ------------------ | --------------------- |
| 公式    | 广告收入 ÷ 广告消耗 × 100% | (收入 − 成本) ÷ 成本 × 100% |
| 成本口径  | **只算广告费**          | **算所有成本**             |
| 回答的问题 | 广告费回本了吗            | 项目赚钱了吗                |

一句话：**ROAS 告诉你广告效率，ROI 告诉你商业结果。**

⚠️ **ROAS = 100% 不代表不亏不赚**。分子是收入不是利润，还要扣产品成本、渠道分成、税费、运营成本。**ROAS 等于 1 时多半是大亏。**

### 盈亏平衡线怎么算

> **盈亏平衡 ROAS = 1 ÷ 利润率**

| 利润率 | 盈亏平衡 ROAS |
| --- | --------- |
| 20% | 500%      |
| 30% | 333%      |
| 40% | 250%      |
| 50% | 200%      |
| 70% | 143%      |

举例：直播类 IAP 产品，用户充 100 元，扣主播分成 35 元、苹果税 15 元，毛利 50 元（利润率 50%）→ 盈亏平衡 ROAS = 200%。

## 2.5 LTV：决定你出价上限的锚

**LTV（用户终身价值）** = 用户整个生命周期为产品带来的总收益。

多种等价算法（按数据可得性选用）：

> LTV = 平均客单 × 平均购买次数 × 平均用户生命周期  
> LTV = ARPU × LT（用户平均生命周期）  
> LTV = ARPU × (1 ÷ 月流失率)  
> LTV = ARPU × 平均留存周期（可按 D7/D30/D90 分段）  
> LTV = DAU × ARPDAU × 留存天数  
> LTV = 付费用户数 × ARPPU × 付费周期

混合变现产品：**Total LTV = Ad LTV + IAP LTV**（详见第七部分）。

### 两条硬性判断线

> **LTV > CAC**：每个用户至少不亏  
> **LTV / CAC > 3**：才有充足利润

**由 LTV 反推出价上限**：

> 可接受最高 CPM = (LTV × 目标ROI) × CTR × CVR × 1000  
> 盈亏平衡 CPM = 目标CPA × CTR × CVR × 1000

举例：CPA=80，LTV=200，则提价到 120 仍然赚钱——**这就是"敢提价"的依据**。

## 2.6 归因：广告效果评估里最大的玄学

### 自归因 vs 三方归因

| 维度   | 自归因        | 三方归因（MMP） |
| ---- | ---------- | --------- |
| 数据来源 | 平台自己       | 第三方 MMP   |
| 中立性  | 有利益冲突      | 中立        |
| 归因逻辑 | 谁的广告带来转化归谁 | 统一裁判      |

**为什么需要三方**：各平台都自称带来了转化，加总常常超过实际转化数。

### 归因窗口期

窗口期设错会直接导致效果失真：

- 窗口太短：真实转化被漏掉，低估效果
- 窗口太长：把自然转化算成广告功劳，高估效果

原则：**窗口期长度应匹配你的产品决策周期。** 决策周期长的高客单产品（教育、B2B）不能用短窗口。

### 抢归因的常见手法（要能识别）

- **助攻归因滥用**：黑产用大量低成本点击"埋伏"，等真实转化发生时抢走归因
- **排查方法**：查助攻报表。若渠道 B 的激活 95% 都有助攻，且助攻来源 100% 是渠道 A，说明 B 在抢 A 的量——立即封停 B，A 的量会恢复正常
- **同一 IP 段/数据中心 IP/VPN 节点 IP 大量激活** = 虚假流量特征
- **后续行为留存率异常低** = 劫持的量虽是真人但非目标用户

行业数据参考：约 15% 的广告预算被作弊吞噬（AppsFlyer 2023）。

### 增量归因：更本质的评估方法

传统归因纠结"每个用户从哪来"，增量归因问的&#x662F;**"投了广告 vs 不投广告，业务大盘差多少"**。

做法是用统计学模型评估整个营销活动对大盘的增量贡献，而非追踪单个用户。适合无法标准追踪的场景（直接访问、社群跳转、线下推荐）。

**非标流量量化方法**：给每个社群/线下物料生成内嵌渠道参数的专属二维码或渠道码，后台记录订单来源，让每个渠道的贡献可量化。

## 2.7 数据分析的两条纪律

### 纪律一：前端指标与后端指标分开看

| 类型   | 指标                | 与什么相关   |
| ---- | ----------------- | ------- |
| 前端指标 | CPM / CPC / CTR   | 算法模型、素材 |
| 后端指标 | 注册率 / 关键行为率 / 付费率 | 产品承接    |

前端好后端差 = 承接问题；前端就差 = 素材或竞价问题。**不拆开就找不到断点。**

### 纪律二：核算口径必须统一

同一个指标可能有多种算法，不统一就无法横向对比。

举例：次留率有 3 种核算逻辑——按激活当天算、按激活次日算、按注册数算。**必须先统一口径。**

### 判断异常的基准：跟自己比，不套用行业标准值

所有异常判断都应对比：

1. **本账户同平台近 7 天中位数**
2. **异常发生前的基线**

⚠️ 不要直接套用跨行业的"标准值"。行业差异极大，同一个 CTR 数值在不同行业含义完全不同。

### 每日必看三件事

1. 花了多少（消耗 vs 预算，消耗率低于 70% 需警惕）
2. 来了什么（展示量 vs 昨日，20% 以内正常）
3. 赚没赚钱（CPA vs 目标，超 30% 立即处理）

# 第三部分　账户搭建与冷启动

## 3.1 新产品投放的三步走总纲

> **跑出去 → 降成本 → 放大消耗**（在 ROI 和成本范围内做最大规模的探索与优化）

### 投放前必须确认的四件事

| 项目          | 含义                        |
| ----------- | ------------------------- |
| **预算**      | 能够支持投放的最大消耗规模             |
| **offer**   | 我要投什么产品/服务                |
| **周期**      | 能够支持投放的时长                 |
| **目标 + 出价** | 投放目标是什么 + ROI 范围下能接受的最高成本 |

⚠️ **必须先接受的前提**：效果广告**不保量**，且**不能 100% 保障效果**。新产品投放初期需要一定预算做成本、出价、投放方式的探索，**必须接受一段时间的高成本周期**。

### 第一步：跑出去

任何 offer 的第一步都是**先消耗出去**，让系统认识这个产品，建立最初的数据。这个阶段会带来一定高成本，因为前期没有成熟模型，需要消耗曝光帮系统学习。

怎么才能跑出去？回到 eCPM 公式——提高出价、提高 CTR、提高 CVR 三条路。

**提升 CVR 的特殊手段（深转产品适用）**：深度转化产品回传数少，冷启期容易出现「没有转化 → 广告持续空耗 → 系统认为没有拿量竞争力 → 广告跑死」。这时可以**放宽回传口径人为拉高 CVR**，例如回传 7 天内的转化数据、或回传部分大盘数据。

> ⚠️ 前提：**回传的人群画像必须与转化目标一致**，否则会污染后续模型。

另一手段是**圈定特定人群**（RTA / 定向人群包），直接提升人群中的转化比例。

### 第二步：降成本

前提：产品已过冷启期，账户有稳定回传，广告能持续跑量。

**超成本的定义**：计费比（实际成本 ÷ 目标成本）> 1.2，即实际成本高出目标 20%。

分三种情况处理：

| 情况                                  | 判断        | 处理                                                             |
| ----------------------------------- | --------- | -------------------------------------------------------------- |
| 跑量速度符合预期甚至过快（预期 2 万花 10 天，结果 2 天花完） | 跑太快、出价高了  | 适当下调出价，把跑速拉回合理范围                                               |
| 跑量速度本身很慢（日均消耗 < 1000）且成本偏高          | 本质是「跑不出去」 | 回到第一步，观察全流程数据，打磨产品/素材/投放目标/版位后再测                               |
| 跑量速度中等、比较均匀                         | 状态健康      | 寻求版位拓展或素材精细化，放大规模后**小幅**下探出价；或出价不动，用降低空耗、提升全流程转化效率的方式（**更推荐**） |

### 第三步：提消耗

问题从「怎么投」变成「怎么在 ROI 考核下花出去更多预算」。三条提量路径：

1. **看成本/出价**——回到 eCPM 公式，投放模式稳定时，出价是最直接的提量手段
2. **看人群**——人群包/定向拓展。量级遇瓶颈时扩包，特别是定向较窄的业务
3. **换产品和 offer**——深转链路瓶颈期，换商品或 offer 也是新的提量思路

## 3.2 账户结构与预算设置

### 账户搭建建议

- **在投项目：每个账户至少 5 条广告**
- **账户组合**：建立「测试账户 + 主力账户 + 备用账户」三级组合，分散风险并加速模型迭代
- **新户初期计划数**：大部分新户 2-3 条就够，预算较高的可 3-5 条
  - ⚠️ 新建一堆计划很多是相似计划，会**内部竞争、卷量的同时拉高后端成本**
- **预算分配**：初期可平均分配；投放一段时间后核心预算主给主力计划，去拿量、降成本、快速积累基础数据完善账户模型

> 🐧 **腾讯广告是例外**：上面「多建几条广告」的通用建议**不适用于腾讯广告 3.0**。3.0 是「广告–创意」两层结构 + 广告唯一性校验，**在投广告建议只留 2–5 条**，靠「资产维度数据聚合」而不是「堆广告」起量。诊断 / 复盘腾讯广告账户时，一律以 8.3「腾讯广告 3.0」小节为准，别让用户去堆广告。

### 预算设置的量化标准

| 层级        | 标准                                             |
| --------- | ---------------------------------------------- |
| 账户维度      | 预算 ≥ 目标转化成本 × 10（目标 CPA 50 元 → 单创意预算不低于 500 元） |
| 广告维度      | 初始预算 ≥ 目标转化成本 × 5                              |
| **日预算下限** | **≥ 目标 CPA × 20**（统一标准）                        |

> **统一口径**：日预算下限 = **目标 CPA × 20**，全平台通用。  
> **唯一例外**：巨量 UBMax 等自动化投放产品需 **≥ 目标成本 × 50**，因为机器需要更大探索空间。  
> （部分资料提到 ×5，那是绝对底线而非推荐值，按 ×20 执行。）

## 3.3 冷启动机制：系统在"面试"你的计划

### 定义与本质

**冷启动**：新计划上线后、数据积累不足、预估模型尚未收敛的阶段。  
一句话：**平台还没学够你的数据，不敢给你放量。**

**为什么平台要保守**：平台排序靠 eCPM，pCTR/pCVR 靠模型算，模型靠历史数据。新计划数据为零，只能给保守值——宁可低估不能高估，因为高估意味着平台承担机会成本（曝光给了不转化的计划）。**保守预估是平台的自我保护。**

**本质**：冷启动是平台与广告主之间的「信号投资」——**你投入预算换数据，平台投入算力换模型，你获得回报。** 真正发生的是：平台在尝试建立信任，决定未来是否值得把更多流量交给你。

### 冷启动的四个阶段

| 阶段           | 时间             | 发生什么                                              |
| ------------ | -------------- | ------------------------------------------------- |
| 分配试探流量       | T+0 ~ T+6 小时   | 从相似计划「借」预估值（同行业/同出价/同定向的邻居历史数据），模糊保守；分配几百到几千次曝光采样 |
| 数据积累、模型学习    | T+6 小时 ~ T+3 天 | pCTR/pCVR 从「借来的模糊值」向「自己的真实值」靠拢，即模型收敛              |
| 预估准确、eCPM 提升 | T+3 ~ T+7 天    | 真实 eCPM 高则排名上升放量，低则拿不到量                           |
| 模型收敛、进入稳定期   | T+7 天后         | pCTR/pCVR 稳定，量级稳定                                 |

### 冷启动阶段系统在学什么

1. **学用户特征匹配**——什么样的人看到这条广告会停下来（输入年龄/性别/地域/兴趣/行为序列，输出匹配度）
2. **学 pCTR 和 pCVR**——注意 CTR 高 ≠ CVR 高，标题党拉高 CTR 但点进来人走了，CVR 崩，eCPM 照样上不去
3. **学出价策略**——oCPX 下模型学"什么用户在什么场景转化概率多少"，反算每次曝光该扣多少钱。**冷启动成本忽高忽低，是出价策略还没学准**

### 帮助计划顺利过冷启动的六个做法

| 做法    | 具体操作                                  | 核心原则                 |
| ----- | ------------------------------------- | -------------------- |
| 预算给足  | 日预算 ≥ 目标 CPA × 20                     | 让模型有足够样本             |
| 出价偏高  | 目标成本的 **1.2–1.5 倍**                   | 补偿冷启动期 pCTR/pCVR 的低估 |
| 定向放宽  | 只设必要定向，稳定期再收窄。人群覆盖至少 3000 万，最好 5000 万 | 池子够大才能找到会转化的人        |
| 素材多方向 | 一个计划配 3-5 条**不同方向**素材                 | 扩大找到正确方向的概率          |
| 配置稳定  | 前 3 天不动，之后一次只调一个变量；出价每天最多调 1 次        | 不打断模型学习              |
| 给时间   | 浅层转化 3-5 天，深度转化 7 天以上                 | 学习需要周期，不是调出来的        |

**补充技巧**（来自实战）：

- 用**过往跑量或竞品验证过的素材方向**，切忌堆很多方向或盲目测新
- 用过往跑量文案**略微改写**（不要 1:1 抄，避免同质化）
- 用**一方人群加强**功能助力系统快速建模（注意新户建议 3 天后再用）
- **A 计划养 B 计划**：用老计划的高转化数据，复制出新计划的定向包和素材。新计划会继承部分历史权重，pCVR 起步更高，可以用更低出价

### 三个常见误区

| 误区       | 真相                                                                         |
| -------- | -------------------------------------------------------------------------- |
| 素材越多过得越快 | 模型学习样本按「计划」汇聚，塞十几条素材每条分到的试探流量都少，学不出来。要**方向多样化**而非数量堆砌——3-5 条不同方向优于 10 条同方向 |
| 频繁调整能加速  | 每次调整关联模型预估的变量（出价/定向/转化目标）都会**打断学习、从头重来**。调三次就是三次重置                         |
| 三天没过就该放弃 | 判断标准不是「几天」，而是**转化数据是否累积到让模型初步收敛的量**                                        |

### 学习期成功的五个信号

1. 后台状态显示"学习成功"或"稳定投放"（显示"学习中"就还没到）
2. 增加预算不失控——预算提高 20-30%，成本不明显上涨
3. CVR/CTR 趋于稳定——波动幅度小于 10%
4. 转化成本稳定落在目标附近
5. 新计划的初始消耗流量明显加快

## 3.4 冷启动期四种情况的处置动作

| 情况         | 定义                            | 动作                                                  |
| ---------- | ----------------------------- | --------------------------------------------------- |
| **空耗**     | 消耗了 2-3 个目标转化金额的预算，无目标转化      | **暂停**                                              |
| **不起量**    | 只有 3 个以内目标转化，且当日转化成本在 2 倍以内   | 提价 5%-10%（分 2-3 次），单次不超过 3%；或使用一键起量                 |
| **广告衰退**   | 消耗速度低于历史同时段 30% 及以上，且持续 2-3 天 | 提价 5%-10% 观察；无法刺激消耗或持续波动则关停后新建                      |
| **未通过冷启动** | 开启后 7 天内仍处于空耗/不起量             | 复制原创意并调整变量（定向/出价/素材）重新测试；或延长观测至 10 天（部分广告后期会逐步积累转化） |

**学习期失败的处理**：可采用「**72 小时静默期 + 模型重置**」——暂停投放 3 天后重新开启，系统会清除部分无效数据。

## 3.5 止损时间表：什么时候该停

这是判断"继续观察还是关停"的量化标准。

### 前 5 个转化成本判断法

**为什么是"前 5 个"**：这是模型学习的最小有效样本。

| 前 5 转化成本 | 判断   | 动作                                 |
| -------- | ---- | ---------------------------------- |
| ≤ 2× 出价  | 继续投放 | 系统还在探索，成本会逐步拉平。保持预算，耐心观察           |
| 2-3× 出价  | 拉长观察 | 再跑 500-1000 元，看系统能否拉低成本；不行就调整素材/定向 |
| > 3× 出价  | 立即止损 | 方向错了，继续跑就是烧钱。关停、复盘、重建              |

> 前提是确认数据回传实时。如果是 T+1 回传，要拉长观察周期。

### 黄金止损时间表

| 消耗节点              | 检查内容      | 结论            |
| ----------------- | --------- | ------------- |
| 消耗 = 出价 × 1.3~1.5 | 必须查看是否有转化 | 第一观察窗口        |
| 消耗 = 出价 × 5~20    | 仍然没有转化    | 建议暂停          |
| 成本 = 出价 × 2       | ——        | **绝对红线，立即关停** |

### 2 倍出价：绝对红线

**老广告成本超过出价 2 倍 = 必须立即暂停。**

为什么是 2 倍：老计划已有足够学习样本，还跑到 2 倍成本，说明**模型已经失效**。

区分新老计划：

- 新计划：可容忍 1.5-2 倍超成本
- 老计划（跑了 7 天+）：超 2 倍直接关

⚠️ 操作要点：**不可反复开启关停**，会破坏模型。可以复制广告重新拿量。

### 三个必须刹车的信号

1. 消耗快但零转化（消耗达出价 5-20 倍仍无转化）
2. 点击率 5%+ 但转化率 0.01%——说明流量根本不精准
3. 前 5 个转化成本已达出价 3 倍+，系统拉不平

## 3.6 账户操作的禁忌清单

以下操作会直接损害账户权重和模型稳定性：

| 禁忌            | 原因                  |
| ------------- | ------------------- |
| 广告无差异全复制      | 内部竞争、抢量抬价，系统无法判断优先级 |
| 一个广告一天调整超 2 次 | 打断模型学习              |
| 创意多次关停和开启     | 开关 > 3 次会被系统判定异常    |
| 大幅修改定向、出价、创意  | 修改幅度 > 20% 等于重置学习期  |
| 暂停广告超过 2 小时   | 影响模型连续性             |

**反之即为正向操作。**

### 必要负向操作时如何规避负向表达

遵循 **1+N 原则**（N ≥ 1）：**一个负向操作，同时搭配一个以上正向操作。**

例：降价 → 同时放开部分定向 + 提预算。

## 3.7 养户：与算法建立信任

**什么是养户**：投放初期（通常 3-7 天）通过精细化、策略性操作，引导算法充分了解并信任你的账户，建立高质量、高权重的初始模型。

**核心是与算法建立信任**。算法目标与广告主一致（预算内找最可能转化的人群），但一开始对你不了解。宽泛定向只会引来无效点击、成本高，算法会判断你不是优质客户，后续流量分配变谨慎。所以养户期做的所有事，都是在给算法**提供清晰、高质量的数据样本**。

| 维度     | 做法                                                |
| ------ | ------------------------------------------------- |
| 账户结构   | 小而精，不追求大而全。基于核心标签 + 精选素材搭多条计划，每条预算保守              |
| 出价     | 温和而坚定。不追最低价（跑不出去），不盲目抬价。参考系统建议 + 转化价值判断           |
| 素材与落地页 | 素材是「信任状」，优先用已验证的高点击/高转化素材；落地页任何卡顿都在给脆弱的信任链条减分     |
| 数据调整   | 忍住频繁插手。新计划给 24-48 小时学习期，只要不是成本离谱、完全没消耗、或快速跑完预算就观察 |

**做「微创手术」而非大动作**：好的小加预算；消耗慢但转化不错的微调推一把；持续差的快干预。

**养户成功的质变标志**（快则 2-3 天，慢则 5-7 天）：账户健康稳定、新计划更容易起量（继承账户权重）、计划生命周期变长、转化成本可控。

> **养户看似慢、实则快。** 根基扎实、被算法信任的账户，起量是源源不断、可复制、成本最优的；靠一条爆款素材起的量往往昙花一现。

## 3.8 新账户起量四步法

**起量公式**：起量 = 最能打的素材 × 最有竞争力的出价 × 最流畅的账户流速

### 第一步：选素材——用「起量概率」做减法

结合三点判断起量概率：历史跑量素材、后台创意库/行业竞品跑量素材、自身经验。把素材分四档（如 30 个素材）：A 档高概率 6 个、B 档中概率 6 个、C 档中低概率 6 个、D 档待定 12 个。

核心不是赌哪个能爆，而是**结构化筛选，把有限预算优先集中在概率最高的素材上**。

### 第二步：测出价看数据

1. **定出价**：无历史数据就打听出价区间（如 35-50），**直接取中上水平**（如 44-46）。不要从最低开始测——新账户没人群模型、探索慢，低价起步只会半死不活
2. **建计划**：A/B/C/D 各选 6 个，共 12 条。第一天出价 44，早 6 点 A+C 六条启动、11 点 B+D 六条启动
3. **看数据**：找转化数最多的前 5 条，看转化成本与出价的差值（出价 44 而成本 47-50，说明出价偏低，需提价）
4. **第二天操作**：出价提到 50；新上 A+C、B+D 各 6 条；复制第一天转化 >1 的计划，出价 44→50
   - **关闭规则**：空耗大于出价 1.7 倍的计划，果断关
   - **观察规则**：消耗 TOP5 的计划，只要转化成本不高于 70 元就继续探索；出价 50 而成本飙到 100 以上才考虑关
   - **一键起量**：给消耗转化前 5 的计划各 100 元，结束后再给 100 元——**小步多频，试探上限**

### 第三步：拔价拉消耗层级

第三天，对消耗转化前三名的计划出价 50 → 58，继续多频次给一键起量 100 元，把账户总消耗快速拉到更高层级。

**敢提价的依据**：前两天数据已验证素材和出价的有效性。

### 第四步：稳消耗降成本

⚠️ **刚起量时千万不要马上降价！** 先「新建 + 复制」，把高消耗状态稳住 3 天。

3 天后出现两个信号说明账户进入稳定流量层级，再开始降价：

1. 新计划初始消耗流量明显加快
2. 跑量计划流速持续增加

降价方法：

- 跑量计划**一次只降 1-2 元**
- 新计划出价直接用跑量计划出价 **+1-2 元**（保持出价优势，不被老计划压着）

2-3 天精细调控后，可把综合成本压到 52-54 元，总消耗依然很稳甚至不降反增。

## 3.9 新账户就是跑不动时的应急手段

按顺序尝试：

1. 用最小预算搭一个**跑浅层目标**的创意，让账户先花点钱出去
2. 用**一键起量**工具刺激（注意控制预算）
3. **找直客排查账户是否有限流**
4. 每天保持新建计划持续 3-5 天，顺序测试：手动出价 → 放量投放 → 一键起量 → 投放管家
5. 7-14 天仍不行，考虑**换新户**

⚠️ 巨量引擎信息流新账户 **80%-90% 都会遇到起量困难**，不必焦虑，也**不要一股脑提价**（光提价不一定带来展现，反而拉高整体成本）。

## 3.10 深层转化为什么更难起量

|    | 浅层转化                 | 深层转化                |
| -- | -------------------- | ------------------- |
| 例子 | 激活/注册、表单提交、咨询入群、下载完成 | 首次付费、次日留存、下单成交、关键行为 |
| 特征 | 转化路径短、数据量大           | 转化路径长、数据稀疏          |
| 本质 | 用户兴趣                 | 真金白银                |

深层转化数据稀疏 → 模型学得慢 → 冷启动周期长、成本波动大。这也是为什么深度转化的学习期门槛和时间都要放宽。

# 第四部分　出价与预算

## 4.1 出价模式的演进：理解你在用的工具从哪来

### 手动出价时代（2012-2016）：CPM → CPC → CPA

早期围绕「前链路 → 后链路」发展。CPM、CPC 都是**平台话语权 > 广告主话语权**。

CPA 看似最好（有转化才结算），但存在**信任博弈**：如果广告主不真实上报转化数量、或用很低的价格结算，平台就亏了。所以 CPA 在信息流竞价里不受待见（基本都是后结算、争议太大），后来演变成 CPS 分佣、包量投放等形式。

### 智能出价时代（2016-2020）：oCPA / oCPX

**oCPX = Optimized Cost per X**，核心是**把「出价点」和「计费点」分离**：

> 广告主仍按期望的目标转化成本出价（如 30 元/激活）；  
> 平台用自己的 pCTR、pCVR 模型预估，精准计算每个流量的 eCPM，帮广告主达成转化成本；  
> 但**不再按转化收费，而是按曝光/点击收费**。

- 按曝光收费 → 称 **oCPM**
- 按点击收费 → 称 **oCPC**
- oCPX 中的 X 指的是**扣费模式**，原名实际是 oCPA

**如何解决信任博弈**：平台引入**成本反馈机制**（第三方公证）——找不到/找错了就赔。由此双方建立良性博弈：广告主不再瞒报，平台用大模型能力精准找人。

冷知识：早期谷歌称 tCPA（target-CPA），京东广告、微信广告早期直接套用叫 tCPA；后来广点通、巨量引擎等改良成如今主流的 oCPX。

**博弈点在哪**：广告平台把除出价以外的所有因素掌握在自己手里，广告主则获得成本可控与效果保证。**本质是平台用「帮你优化」换取「我来控场」——广告主让渡出价微调权，换来成本可控的省心。**

**为什么 oCPM 成为主流**：按曝光扣费，曝光发生就有收入，**平台收入确定性最高**；而广告主出价方式没变（仍按转化目标出价），综合成本逼近目标即可。巨量引擎、腾讯广告等主流平台的智能出价默认都是 oCPM。

### 自动出价时代（当下）：NoBid / MCB

**NoBid**：无需广告主表达出价，一切交给系统自动出价。

核心逻辑：**广告主只需表达要花多少钱，系统在投放时段内尽可能高效花出去，并确保整体成本尽可能低。**

注意「成本尽可能的低」这个措辞——系统的高低线参考来源有两个：① 账户的平均成本；② 客户填写的期望成本（**不保证完成**）。核心是**保障预算尽可能花完**。所以这里不再有出价限制，平台的手脚也放得更开。

各平台叫法：阿里 **MCB**（Multiple Constraint Bidding，多重约束出价）、快手有类似 MCB 产品、谷歌和字节称「最大化转化出价」。本质都是一回事。

⚠️ **当前成熟度**：这个模式相对还不成熟。由于**没有出价上限保护**，广告主可能得到超出预期成本的结果，所以腾讯、字节、阿里等大媒体都还在探索。

用 MCB 来称呼它更合适——新时代的出价模式一定是**多种约束条件**：广告主表达预算与期望成本，平台表达收益目标，算法依据多重约束达成「广告主花完钱拿到足够转化 + 平台收益最大化」。

## 4.2 oCPX 的能力边界：三个必须认清的误区

| 误区             | 真相                                                                                                  |
| -------------- | --------------------------------------------------------------------------------------------------- |
| oCPX 一定能跑出目标成本 | oCPX 只是**尽量优化，不是承诺**。目标本身不现实（行业均价 50 你定 10），模型再聪明也做不到。目标出价要基于历史数据、行业大盘、产品 LTV                       |
| 用了 oCPX 就不用管素材 | oCPX 优化的是「在给定素材和定向下找成本最优的流量分配」，**不会把烂素材变爆款**。素材 CTR 崩了 → pCTR 低 → eCPM 低 → 拿不到量。**oCPX 是放大器，不是制造机** |
| 回传不准也没关系       | 回传是模型的「教材」，教材错了模型必然学歪。常见问题：漏报（埋点缺失、网络丢包）、延迟（付费几天后才回传）、错报（把点击下载当激活）。**上线前必须确保回传链路准确完整**              |

### oCPX 的优缺点总览

**优点**：广告主省心、成本可控、精准触达（模型把流量优先分给高转化用户）、跨计费方式统一、降低门槛。

**缺点**：依赖数据积累（冷启动预估不准）、目标不合理模型救不了、依赖回传准确性（垃圾进垃圾出）、对素材仍有要求、黑盒不可控、深度转化学习慢。

**局限的本质**是「模型依赖」的代价——把优化权交给模型，就得承受模型不精准的波动和无法直接干预的被动。

## 4.3 出价的一个反直觉真相：出价 ≠ 转化成本

**出价更多是影响计划竞争力和流速的关键因素之一，不直接等于最终转化成本。**

- 很多时候高出价不一定导致高转化成本（因为拿到的是优质流量，CVR 更高）
- 低出价反而影响跑量，转化成本也可能波动更大

**正确做法**：搞清楚「自身计划能稳定跑量、且最终平均转化成本在可接受范围内」的大概出价区间即可。

**成本高时反而要提价的逻辑**：  
降价 → eCPM 降低 → 拿到更差流量 → 转化更差 → 成本更高（恶性循环）  
短期提价 → 拿好流量 → 模型跑正 → 成本反而下降

## 4.4 调价纪律：幅度、频率与时机

这是最容易出事的地方，纪律比技巧重要。

### 降价纪律

| 项目          | 标准                         |
| ----------- | -------------------------- |
| 单次降价幅度      | **5-10%**，观察 2-4 小时再决定是否继续 |
| 一天对同一计划降价   | **不超过 2 次**                |
| 单次幅度上限      | 不超过 10%                    |
| 新计划上线 4 小时内 | **不要降价**                   |

❌ 错误操作：看到超成本立刻降价 20-30%，一天内反复调价 5 次以上。

**什么时候不该降价**：

- **新计划前 48 小时**——系统还在学 pCTR/pCVR，此时降价等于自杀。应给够预算让系统建模，出价建议高于行业中位数 20%
- **素材衰退期**——如果 pCTR 已从 3% 跌到 1.5%，降价救不了它。正确做法是**换素材**

### 提价纪律

| 场景         | 做法                                        |
| ---------- | ----------------------------------------- |
| 新建计划冷启动    | 出价直接设为目标 CPA 的 **1.5 倍**，跑出 50 个转化后逐步降价   |
| 不起量需刺激     | 提价 5%-10%（分 2-3 次），单次不要太高                 |
| 高峰时段维持排名   | 晚 8-10 点竞争激烈，可提价 5-10% 维持 eCPM 排名         |
| ROI 尚有利润空间 | CPA=80、LTV=200，提价到 120 也赚——快速提价抢量         |
| 阶梯提价法      | 原价 100 → 第 1 次 +20%（120）→ 第 2 次 +30%（156） |
| 单次调价上限     | 不超过 **15%**                               |

**提价的一个隐藏好处**：全行业都在提价时，你的"异常"变成了"正常"。

### 调价前必问的一个问题

> **这次调整，会让 pCTR 和 pCVR 发生变化吗？**

如果不会，那你调的只是数字，不是 eCPM。

## 4.5 超成本的分级容忍度

新计划刚上线时超成本是正常现象，**关键是知道能忍多久**。

| 超成本幅度   | 判断   | 动作                              |
| ------- | ---- | ------------------------------- |
| 20-50%  | 正常波动 | 不要立即调整，继续观察，系统后续会拉平             |
| 50-100% | 警惕区间 | 拉长观察时间，看系统能否拉低成本；持续偏高则考虑调整或放弃   |
| > 100%  | 危险信号 | 成本翻倍说明方向可能有问题，及时调整素材/定向，或直接关停重建 |

⚠️ 容忍超成本 ≠ 放任不管，要持续监控趋势变化。

**冷启动期（前 72 小时）的特殊规则**：成本波动 20%-30% 属正常震荡，操作应为「**绝对静止**」——此时干预会打断模型学习，直接废掉计划。

## 4.6 超成本的系统排查法：3D 诊断模型

看到超成本第一反应就降价/关停是错的。正确解法分三个维度：

### 维度一：时间轴（Time）——先确认生命周期阶段

| 阶段            | 操作                                                   |
| ------------- | ---------------------------------------------------- |
| 冷启动期（前 72 小时） | **绝对静止**。模型正在探索高潜人群，20%-30% 波动属正常                    |
| 成熟稳定期         | **立即干预**。稳定跑量超 3 天且转化 > 20 个后突然成本飙升，意味着外部环境或核心指标发生质变 |

### 维度二：颗粒度（Granularity）——大盘崩盘还是单点失效

- 所有计划成本全涨 → 外部环境变化（竞争加剧、大盘涨价、节点）
- 只有头部计划猝死 → 单点问题（素材衰退、承接失效、产品端改动）

### 维度三：归因漏斗（Funnel）——定位断点

从上到下查一遍，定位「哪一层先崩」：

1. **展现量**还在不在？骤降 → 竞争/预算/审核问题
2. **点击率**掉了吗？掉 → 素材衰退/人群跑偏
3. **转化率**崩了吗？崩 → 落地页/承接/人群质量
4. **出价**是否被动调过？频繁改 → 模型重学
5. **大盘竞争**变贵了吗？同行抢量/节点涨价

**核心纪律**：定位到哪层，只动那一层。**单变量验证——一次只改一件事**，否则成本回落了你也不知道是哪一步起的作用。

## 4.7 空耗的处置流程

**空耗定义**：有消耗但无转化。

处置四步：

1. **判断**：消耗达一定金额且成本 > 2 倍出价
2. **诊断数据漏斗**：CTR 低？CVR 低？定位问题
3. **新建计划调整变量**：CTR 低 → 换素材；CVR 低 → 改落地页/定向
4. **降低出价 10-15%** 重新测试成本

⚠️ **禁忌**：千万别在原计划上反复调价，会打乱模型学习。

**消耗过快但无转化时**：降价 5-10%，降低消耗速度，给模型更多时间学习。

## 4.8 放量：过了冷启动之后怎么加

**放量的前提**：10 个转化 + 成本达标。

### 三个核心认知

1. **放量不是加预算，是复制成功单元**
2. 一个计划跑正后不要立刻大改，先**横向复制**
3. **真正的放量是「成本略升但利润倍增」**——不要指望放量后成本不变

### 放量的三种方式

1. **智能放量**：开启"自动扩量"
2. **一键起量**：平台批量复制工具
3. **虫洞复用/继承**：继承老计划模型

### 阶梯放量节奏

预算提升不能一次拉满：

| 步骤            | 动作   | 观察      |
| ------------- | ---- | ------- |
| 第 1 次         | +20% | 观察 3 天  |
| 第 2 次（ROI 稳定） | +30% | 观察 3 天  |
| 持续稳定          | +50% | 直到触及天花板 |

**天花板信号**：CTR 下降、CVR 下降、成本上涨超 30%。此时不要硬推，应启动新素材测试。

**测试期到放量期的预算分配参考**：

- 测试期（20%）：开 5-10 个计划，每个日预算 500-1000，快速找能跑的组合
- 优化期（30%）：砍掉差的，保留 ROI > 100% 的，加大预算
- 放量期（50%）：集中火力在最优计划，逐步提量

### 放量失败的主因

**80% 是承接端没跟上**——不是投放问题，是落地页、客服、库存、产能跟不上突增的量。

### 出价调整策略（放量期）

| 情况         | 动作        |
| ---------- | --------- |
| 成本低于目标 20% | 降价 5%     |
| 成本等于目标     | 保持不动      |
| 量级不足       | 提价 10% 抢量 |

## 4.9 一键起量：加速探索工具的正确用法

**本质**：花一笔钱加速广告曝光，使计划获得更多探索增量、加速模型探索。可设置起量预算/生效时间/起量时间。

### 注意事项

1. 开启后 **6 小时内**尽可能花完起量预算
2. 一键起量产生的消费和转化**没有赔付**
3. 6 小时内成本有可能上涨
4. 预算不宜太多，一般设 **15-20 个转化成本**的预算
5. **智能调控和一键起量不能同时使用**
6. 起量预算越高，获得优质流量的机会越大，成本也相对越高

### 三个适用场景

1. **计划冷启动期**：持续测试跑不起来的新计划，用一键起量破冰、加速冷启动
2. **外部竞争激烈**（电商大促等）：出价已到可接受最大值仍跑不动
3. **老计划快衰退时**：再搏一搏（预算不要过多），延长生命周期、争取转化增量

### 价值点

- 加大探索**不一定**能过学习期，但可帮助判断计划是否优质
- 新计划可验证计划和素材是否优质、是否有起量趋势
- 老计划衰退时可再加大探索，延缓衰退

## 4.10 实时监控 SOP

**核心原则：勤观察 + 慢调整 + 准判断。**

| 时间段         | 频率         | 动作                           |
| ----------- | ---------- | ---------------------------- |
| 新计划上线前 4 小时 | 每 30 分钟看一次 | 观察消耗速度和曝光情况，**不要调整**，让模型自由探索 |
| 上线 4-24 小时  | 每 2 小时     | 关注前 5 个转化的成本                 |
| 24-48 小时    | 每半天        | 判断是否进入学习期成功状态                |
| 稳定期         | 每天         | 只监控趋势，不手痒                    |

**监控频率参考（素材维度）**：新素材每 2 小时看一次；成熟素材每天看。

## 4.11 通投与预算分配的判断

**通投（不设定向）适用场景**：产品受众极广、素材本身有强筛选能力、冷启动期需要放宽池子。

**不适用**：定向精准度依赖强的行业、素材无法起到人群筛选作用时——此时通投会让账户模型越跑越偏。

**关键前提**：如果用素材圈人群，**前提是素材内容真能起到筛选作用**。否则各计划定向不做限制直接系统推或小通投拉满，模型只会越跑越偏。

# 第五部分　素材与创意

## 5.1 先破一个认知：素材决定上限，但账户健康度是前提

> **优先级：账户健康度 > 素材质量 > 投放技巧**
>
> 先让系统相信你，再谈素材创意。

素材不起量时，**素材顶多背一半的锅**，另一半是「用素材的姿势错了、账户底子烂了」。

**天天换素材、天天新建计划、天天删老计划 = 逼系统天天猜、永远不让它毕业。**

正确做法：

1. **老带新**——在表现稳定的老计划里悄悄加新素材。系统会用已验证的高转化人群试探新素材，**冷启动成功率翻倍**
2. **做减法、做隔离**——一个账户专注一件事（一个优化目标、一类人群）。测不同转化目标就开新户
3. **给素材耐心**——允许它学两三天，别成本一波动就关
4. **控制变量**——一次只改一个东西

⚠️ **账户是一个整体人设**：系统会根据账户内所有在跑/跑过的计划给账户打标签、建模型。一个账户同时跑三种人群包、两种出价方式、四个转化目标，系统会「精神分裂」，流量撒得更散、预估更保守；不同计划还会互相抢量、自己抬价。

## 5.2 素材与创意的配比体系

### 素材总数 : 创意总数 = 1 : 2~4

创意的核心作用是**测试不同投放变量**（定向、出价、标题、落地页），而非单纯堆数量。

| 配比            | 后果                                 |
| ------------- | ---------------------------------- |
| 低于 1:2        | 变量测试不充分，可能错过最优投放组合                 |
| **1:2 ~ 1:4** | **推荐区间**                           |
| 高于 1:4        | 多创意抢同一素材流量，eCPM 内耗，多数创意因预算不足无法过冷启动 |

### 单个素材配几个创意

| 创意数       | 效果                                            |
| --------- | --------------------------------------------- |
| 1 个       | 测试维度太窄，若定向/出价不合适，素材潜力无法被挖掘                    |
| **2-3 个** | **性价比最高**——兼顾测试广度和避免内耗                        |
| 4 个以上     | 同素材创意形成内部竞争，系统无法判断优先级，所有关联创意的 eCPM 权重下降，预算被稀释 |

### 按阶段调整配比

| 阶段                 | 配比        | 逻辑                                          |
| ------------------ | --------- | ------------------------------------------- |
| 冷启动测试期（新账户上线 7 天内） | 1:3 ~ 1:4 | 需快速测试不同出价（目标成本 1.2 倍/1.5 倍）和版位组合，找高潜力创意     |
| 稳定放量期（已过冷启动）       | 1:2 ~ 1:3 | 聚焦已验证方向                                     |
| 爆款素材               | 1:1 ~ 1:2 | 例：主力版位+目标出价占 70% 预算，朋友圈版位+高出价占 30%，聚焦放量避免内耗 |
| 素材衰退期              | 1:1 或直接关停 | 衰退素材竞争力已下降，无需多创意测试                          |

## 5.3 素材全流程的量化管控指标

### 上新质量指标（预防低质素材浪费资源）

- **新素材与核心素材差异度 ≥ 30%**——避免与已有爆款高度同质化导致内耗。例：核心素材是「口播测评」，新素材需改为「剧情植入」或「用户 UGC」

### 测试阶段指标

| 指标          | 标准                                                                      |
| ----------- | ----------------------------------------------------------------------- |
| 单素材测试预算     | **常规渠道：目标 CPA × 15**（CPA 50 元 → 750 元），确保拿到至少 10 个转化；**千川：目标 CPA × 50** |
| 48 小时冷启动通过率 | ≥ 50%（48 小时内消耗 ≥ 测试预算 80% 且转化成本 ≤ 目标 120% 视为通过，进入潜力池）。未通过直接关停           |

> **分渠道口径**（按投放渠道选用，不要混用）：
>
> | 渠道                              | 单素材测试预算         | 说明                                      |
> | ------------------------------- | --------------- | --------------------------------------- |
> | 常规渠道（巨量竞价 / 腾讯 / 小红书 / 快手 / 百度） | **目标 CPA × 15** | CPA 50 元 → 750 元，目标是拿到约 10 个转化          |
> | **千川**（电商直播）                    | **目标 CPA × 50** | CPA 80 元 → 4000 元；同时测 3-5 条，总预算 1.2-2 万 |

### 放量阶段指标

| 指标          | 标准                                        |
| ----------- | ----------------------------------------- |
| 新素材日均消耗增速   | ≤ 50%（首日 1000 元，次日最高 1500 元），避免快速放量导致模型跑偏 |
| 新素材成本波动率    | ≤ 15%（连续 3 天波动超 15% 需暂停放量，排查定向或素材内容）      |
| 新素材 7 天 ROI | ≥ 核心素材的 90%（否则仅适合补流量，不可作主力）               |

### 账户内素材结构：核心稳盘 + 新素材补量

| 素材类型       | 消耗占比    | 功能定位   |
| ---------- | ------- | ------ |
| 核心素材（已跑量）  | 70%-80% | 承担稳定消耗 |
| 潜力新素材（测试中） | 20%-30% | 补量与储备  |

⚠️ **禁忌：新素材消耗占比不可超过 40%**，否则会导致账户整体成本波动率超过 ±20%（算法对新素材的模型学习需要 3-5 天）。

### 稳定期素材上新的三个公式

> 每周上新数量 = 现有核心素材数量 × 30%-50%  
> 新素材消耗占比 = 20%-30%  
> 单素材测试预算 = 目标 CPA × 15 倍（常规渠道；千川为 × 50）

**核心素材留存率 ≥ 60%**：每周结束后，上周核心素材中仍能稳定消耗的比例需 ≥ 60%，否则说明上新质量不足。

## 5.4 素材衰退：四个模型解释为什么会死

素材衰退的本质是**某些预估数据被系统持续下调的过程**。规律是：**前端数据的持续下滑，先行于消耗崩塌和成本飙升。**

| 模型              | 来源   | 机制                                                                    |
| --------------- | ---- | --------------------------------------------------------------------- |
| **用户新鲜感衰减**     | 用户端  | 同一用户看到次数越多，点击欲望越低（边际效用递减 + 广告疲劳）                                      |
| **eCPM 竞价能力衰减** | 系统逻辑 | 前端数据下降 → 拿量变少 → 数据稀疏 → 系统更不自信 → 竞争力进一步压低。**正反馈加速，所以衰退常呈「断崖式」而非「斜坡式」** |
| **生命周期（探索→利用）** | 系统机制 | 素材先在最易转化人群「利用」，洗完后到泛化人群「探索」。**不是素材变差，是系统分配的人群变水了**                    |
| **竞争挤压与同质化**    | 大盘生态 | 创意爆了，海量相似素材涌入，系统按画面指纹/语义归为一类，用户对「整个品类」的疲劳感共享加倍                        |

### 衰退速度取决于哪些变量

| 模型   | 核心变量                                              |
| ---- | ------------------------------------------------- |
| 新鲜感  | 素材耐看度（广告感浓度）+ 用户群同质化程度。**原生到几乎看不出是广告的剧情视频，衰减极平缓** |
| 生命周期 | 定向人群规模（总容量）+ 每日消耗速率。亿级通投 vs 百万级精准人群，「探索」边界天差地别    |
| 竞争挤压 | 赛道竞争烈度 + 素材可复制性。美妆、大健康是重灾区；高度依赖人设/技术的 B2B 相对安全    |

## 5.5 素材衰退的分级预警（口径已统一为三级）

不同资料给出的阈值不同，本质是**不同严重程度对应不同动作**，因此整理为分级：

| 级别          | 信号                                             | 动作              |
| ----------- | ---------------------------------------------- | --------------- |
| 🟢 **早期预警** | CTR 环比下降 10-15%；或 CPM +20%                     | 还能救。启动微调、准备储备素材 |
| 🟡 **中期处理** | CTR 连续 3 天环比下降 ≥ 20%；或转化成本环比上升 ≥ 15%；或频次 > 3 次 | 标记「待淘汰」，启动替换流程  |
| 🔴 **晚期淘汰** | 转化率降 30%+；或 CTR 下降 30%+；或成本连续 2 天超预期 30%       | 建议停投，全量更新素材     |

**其他可用信号**：

- eCPM 连续 3 天下跌 > 15% → 立刻换素材，别等系统降权
- 消耗速度低于历史同时段 30% 且持续 2-3 天
- CPM 持续上涨但转化不涨
- 评论区负面反馈增多

**高客单价场景例外**：素材周期本身较长（3-4 周），可容忍到 CTR 下降 30%+ 再全量更新。

### 换素材的判断依据：看指标不看天数

> **点击率掉了，马上换。点击率稳定，7 天也不用换。**

| eCTR 状态 | 判断                  |
| ------- | ------------------- |
| 稳定或上升   | 继续用——用户还有兴趣，频控还没起作用 |
| 下降 20%+ | 立即换——素材疲劳           |
| 一直很低    | 素材根本不行，别纠结，换新的      |

### 素材迭代效率要求

**从「衰退预警」到「新素材上线承接流量」的时间 ≤ 24 小时**——靠提前储备同类素材实现（核心素材是「办公室场景」，就提前储备「居家场景」变体）。

**黄金窗口**：从衰退信号出现到完全失效只有 **48-72 小时**，必须在窗口内完成动作。

### 抢救衰退计划的三步急救法

1. **诊断**：查 CPM、CTR、CVR 三大指标走势，对比 7 天前数据确认下降幅度，判断是素材问题还是人群枯竭
2. **原计划抢救**：方案 A 复制计划 + 提价 10-20%；方案 B 原计划阶梯提价 + 智能放量。观察 2-4 小时，ROI 为正继续、为负关闭
3. **素材迭代**：立即启动素材裂变，1:1 剪辑/翻拍，保留爆点重置废点，新素材 + 新计划 + 换定向重新探索

## 5.6 素材公式化：把创意变成可批量生产的工程

核心思路：**把素材拆解为最小元素，再排列组合批量生产。** 创意工作从「想点子」升级为「定义元素 + 设计组合规则」。

### 第一步：元素拆解

| 维度 | 可拆元素               |
| -- | ------------------ |
| 画面 | 人物 / 场景 / 色调       |
| 文案 | 标题句式 / 卖点词 / 行动号召  |
| 音频 | BGM / 配音 / 音效      |
| 结构 | 开头钩子 / 中段展示 / 结尾转化 |
| 样式 | 版式 / 字体 / 贴纸特效     |
|    |                    |

**颗粒度越细，组合空间越大。**

### 第二步：排列组合

例：画面 5 × 文案 6 × 音频 4 × 结构 3 × 样式 4 = **1440 种理论组合**。即便只有 10% 有效率，仍有 144 种差异化素材。

### 第三步：组合规则（不能乱配）

| 规则   | 要求                             |
| ---- | ------------------------------ |
| 语义一致 | 钩子 / 展示 / 转化的逻辑必须连贯            |
| 人群匹配 | 不同组合对应不同人群                     |
| 去重   | 素材 + 标题 + 落地页完全差异化，违反会触发频控判同质化 |

### 第四步：效果归因

每条素材由明确的元素组合构成，可精确拆解**哪些元素在起作用**，反向优化元素池：高表现元素加权重、增变体；低表现淘汰降级。

### 结构化重组法（应对判重）

**不是改素材本身，而是改素材的「组装逻辑」。**

把一个 15 秒视频拆成 5 个 3 秒片段（A B C D E），重新排列组合（C A E / B D A / E C B），加不同转场和文案，可生成 20 个全新素材——**视觉指纹完全不同，但信息传达一致**。

### ❌ 这些"洗稿"手法已经失效

| 无效手法     | 原因         |
| -------- | ---------- |
| 同义词替换文案  | NLP 照样识破   |
| 只调亮度/对比度 | 视觉指纹算法对此免疫 |
| 截取中间片段   | 部分匹配也会触发判重 |
| 镜像翻转     | 已被识别       |

⚠️ **搬运素材现阶段被识别后会打上搬运标签，后续基本被限制跑量。** 全扒/混剪别人的视频基本没量。

## 5.7 素材微调的黄金准则

| 标准       | 要求                  |
| -------- | ------------------- |
| **最低标准** | 改一项可过审，但系统仍可能识别为重复  |
| **安全标准** | 改两项以上，基本可规避影子计划     |
| **最佳标准** | 混剪、翻拍，**画面差异 60%+** |

可改的项：换标题（文案钩子完全不同）、换 BGM（改变情绪节奏）、调顺序（前后段落互换）、换封面（缩略图差异化）、60% 画面不重复。

### 首发标识：让平台认为这是新素材

**平台首发判定：相似分镜占比 < 10% 即可获得首发标识。**

获得首发标识的收益：冷启动率提升约 40%、7 天榜单保护期、1 小时优先审核、策略倾斜。

做法：重拍前 3 秒（新场景/角度）、重剪节奏（调整分镜）、插新镜头，使**画面差异度 > 60%**。

### 反向清理法：删掉僵尸素材

**被忽视的真相：不是老素材不行了，是被同质化素材"挤压"窒息了。**

- 拥挤账户：10 条相似素材互相挤压，单个素材曝光不足
- 清理后：保留 2 条最优素材，流量集中爆发

**执行**：至少 3 天/次；对象是低消耗（< 500 元/周）且相似的素材。

### 跨平台改造清单

抖音跑量素材搬到快手/朋友圈，这 5 处必改：

| 改造项    | 快手方向                  |
| ------ | --------------------- |
| 口播语速   | 放慢 10%                |
| 文案风格   | 方言 ok、接地气、去网红感        |
| 视频时长   | 15-30s                |
| 结尾 CTA | 按平台习惯调整               |
| BGM    | 使用当前平台热榜 Top10，借势推荐算法 |

⚠️ 禁止使用有版权风险的音乐。

## 5.8 素材内容方法论：怎么做出能转化的素材

### 有需求 vs 无需求，素材逻辑完全不同

| 用户状态       | 素材策略                                                    |
| ---------- | ------------------------------------------------------- |
| **已有明确需求** | 素材只需输出好产品卖点，引导有需求的用户选择                                  |
| **还无需求**   | 通过内容共鸣让用户发现问题、产生兴趣、激发需求。需回答：**什么人群、在什么情况下、会因为什么问题产生需求** |

### 三种素材的本质区别

**「能否起量」「能否有转化」「能否起量同时稳定转化」是三种完全不同的素材：**

- 起量看能否吸引用户、持续让用户停留
- 转化关键在于**精准击中用户转化点/痛点**，而非自卖自夸讲好卖点

### 拿到新品先搞清六件事

1. 核心差异点/竞争力是什么
2. 核心目标人群是谁
3. 核心卖点是什么
4. 用户痛点有哪些
5. 主使用场景在哪
6. 行业当前跑量素材的类型/结构/开头是什么

搞清楚后再输出新素材。

### 前 3 秒：不是用来美的，是用来筛人的

- **判断开头能否让人停留的土办法**：**直接静音看画面**，是否还有吸引力
- 素材是跟用户打招呼的第一照面
- 素材前需明确：**人群（受众是谁）+ 卖点（核心利益点/钩子）+ 差异化（对比竞品的核心优势）**

### 竞价素材不需要精致

**越精致越不消耗。** 做好内容/画面、讲清卖点，核心是吸引目标人群持续停留，同时降低决策成本、提高信任度。

### 20 条素材实操要点（原文精选保留）

1. 不仅关注新素材能不能起量，更要关注**持续的消耗能力、转化能力、后端用户质量和留存**
2. 很多人看似上了很多素材，但只是增加数量——场景/内容/开头/卖点都一样，**没给用户新视角、新转化理由**
3. 学习期没结束的新素材不要轻易否定，除非转化成本超正常太多或一直空耗
4. 素材投放周期不仅和自身结构有关，还和投放策略、投手操作有关
5. 衰退跑量素材要优化，重点放在**素材开头和核心卖点可视化**；原素材中的高光/高留存画面可拉出来给新素材继续用
6. **不要单一优化某个素材数据**。如点击率低只优化开头、忽略开头与后文关联性，会导致点击率高但后端转化骤降
7. 爆款素材结构/框架**并非固定不变**，需根据行业/人群/客单/偏好/消费习惯针对性调整，硬套公式不适用
8. 输出素材前想清楚：这条素材想让哪些人群看到、要筛掉哪些人群
9. 新手抓不住卖点时，**先拆 20 条行业跑量素材**的结构、开头、节奏、卖点、高光画面、场景，每条总结一个可借鉴点（**拆解不是搬运**）
10. 每个素材都有生命周期。**在跑量和转化巅峰期，就是准备迭代、输出新素材的最佳时机**
11. 很多素材痛点刺激到位了但卖点没讲清，或开头吸引的人群和真正转化人群不一致——这种不是放弃，而是找到问题环节优化
12. 素材转化差/投产低，抛开计划端因素，很大程度是对产品卖点/目标人群痛点的挖掘认知还不够深
13. **素材复制不是追多，而是追准**——提炼确定性/有效的信息内容进行放大

## 5.9 素材 AB 测试的正确做法

**AB 测试的核心是控制变量。**

- 一般单变量、双计划形式
- 部分账户选 AABB 模式（单变量、四计划），但大部分行业双计划已足够
- 测素材时：A、B 计划除素材不同外，**转化目标、定向、出价、投放时段、预算、竞价模式必须全部一样**

**AB 测试黄金公式**：同定向 + 同出价 + 不同素材。

❌ **避免变量重复**：2 条创意仅标题不同、定向/出价一致，属浪费测试资源。

### 素材筛选的通过标准

| 指标  | 参考标准                  |
| --- | --------------------- |
| CTR | ≥ 行业均值 1.2 倍，或 > 1.5% |
| CVR | ≥ 3%                  |
| 停留  | > 10s                 |

### 素材上线前的自查清单

- 画面清晰无拉伸/无水印/无模糊
- 前 3 秒有明确价值钩子
- 落地页加载速度 < 2 秒
- 避免绝对化用词（最、第一、保证等）
- 准备好备用素材（A 素材不行立刻换 B）

## 5.10 素材更新频率参考

| 行业    | 建议翻拍频率         |
| ----- | -------------- |
| 游戏    | 每 2 天          |
| 电商    | 每 3 天 1:1 翻拍一次 |
| 金融、教育 | 每 5 天          |

**主力素材生命周期：7-14 天。** 迭代策略：每周测试 2-3 条新素材保持素材库活跃度。**替换时机：当新素材 ROI > 老素材 1.2 倍时逐步切换预算。**

**素材来源优先级**：

1. 首选：混剪（同行爆款 + 你的话术）
2. 次选：直播录屏切片（实时监控留存高的片段，性价比最高）
3. 补充：自制拍摄（需要编导+演员+场地，成本 ¥200+/条）

# 第六部分　人群定向与承接转化

## 6.1 定向是双刃剑：精准过头就是自己关门

**每多一个定向条件就筛掉一批人**，三个条件叠加可能 90% 用户都不在池子里。

> **定向过窄死于曝光不足，定向过宽死于人群不精准。**

### 定向的漏斗效应（示例）

```
10 亿   全体用户
 2 亿   + 地域：北上广深
3000万  + 年龄 25-35、性别
 50万   + 兴趣/近期行为  → 你的广告只去抢这 50 万人的曝光
```

### 分阶段的定向策略

| 阶段   | 策略                                                                               |
| ---- | -------------------------------------------------------------------------------- |
| 冷启动期 | **优先使用系统推荐定向**；如需自定义，只限制 1-2 个核心维度。人群覆盖至少 3000 万，最好 5000 万；预估日曝光量 > 5000（低于此需调整） |
| 稳定期  | 模型稳了再逐步收窄                                                                        |

**现阶段的现实**：定向作用已没以前那么大，很多人用素材圈人群——但**前提是素材内容真能起到人群筛选作用**。

**新户初期人群包的正确用法**：更多用于**排除低质低效人群**，而非精准圈定。

## 6.2 人群包与 RTA

- **一方数据人群包**：用已转化用户、高价值用户做种子，做 lookalike 相似人群扩展。作用是告诉系统"这些人大概率转化"，**抬升 pCVR 预估、降低不确定性**
- **RTA（Real Time API）**：实时决策接口，由广告主侧实时判断该不该对这个用户出价
- **交并差人群包**：通过人群包的交集、并集、差集运算精细化圈人，可节省预算

**用一方人群加强功能时注意**：新户建议 3 天后再用（太早会限制模型的自主探索）。

## 6.3 承接端：CVR 崩了通常不是投放的问题

### 落地页的四条铁律

1. **第一屏只解决一个问题：值不值得往下看**
2. **转化按钮不是越多越好，而是越明确越好**
3. **每多一个选择，转化率就少一点**
4. **不要让用户"想一下"，要让他"顺手做"**

**落地页加载速度必须 < 2 秒。** 任何卡顿都在损耗已经花钱买来的流量。

### 转化链路的放大效应

> **转化链路中任何一步不顺，都会被广告费放大。**

排查顺序（从后往前）：

| 现象                 | 排查方向               |
| ------------------ | ------------------ |
| CTR 高但到达率低（如 60%）  | 页面加载太慢             |
| 到达率正常但 CVR 低（如 5%） | 落地页说服力差 / 人群不精准    |
| CVR 正常但线索质量差       | 素材承诺过度 / 前端吸引来的人不对 |

### 点击高但转化差的根因

**多半是前端承诺过度**——素材吸引的是谁，决定了后端累不累。

「素材吸引的人群」和「真正转化的人群」不一致，是最常见的隐性问题。

### 线索质量差的排查顺序

> **先查话术，再查素材，最后查平台。**

⚠️ **承接人员的情绪会直接影响广告 ROI**——这是常被忽略的变量。

**转化话术不是销售编的，是数据筛出来的。**

## 6.4 数据回传：模型的教材

**回传是模型的「教材」，教材错了模型必然学歪。**

### 三类常见回传问题

| 问题 | 表现        |
| -- | --------- |
| 漏报 | 埋点缺失、网络丢包 |
| 延迟 | 付费几天后才回传  |
| 错报 | 把点击下载当激活  |

⚠️ **数据回传断一天，模型可能废一周。**

### 回传的第一原则：明确唯一核心目标

**最常见的错误是「什么都要」**——把回传事件一股脑全塞进去，算法会向**最低门槛的目标**收敛。

**正确做法：只回传与核心目标直接相关的转化信号。**

### 进阶：按价值权重回传

IAP 产品不要只回传「是否付费」——算法分不清 1 元和 100 元，会优先收割低价值用户。

**应该回传「付费多少」，按金额权重学习**；并用 LTV 最高的 Top 10% 用户做种子，做价值权重 lookalike。

### 回传口径可以作为调控手段

冷启期若因转化太少导致空耗跑死，可放宽回传口径（如回传 7 天内转化、回传部分大盘数据）人为拉高 CVR。  
⚠️ 前提：**回传的人群画像必须与转化目标一致**，否则污染模型。

## 6.5 用户洞察：怎么找到真实痛点

### 三种信息来源

| 来源     | 具体做法                                |
| ------ | ----------------------------------- |
| 已购用户提取 | 巨量广告 → 竞价数据 → 受众分析；腾讯广告 → 如翼 → 人群洞察 |
| 跨部门沟通  | 找销售、客服拿一线反馈                         |
| 行业报告   | 看行业白皮书、趋势报告（消费习惯：购买品类/频次、预算分配、偏好）   |

**评论区是免费的用户调研。** 素材跑不动时，先看评论区，再看后台。

**能被骂的素材，往往比没人看的素材更有价值。**

# 第七部分　变现与商业模式

这部分决定了你的**出价上限**——不搞清怎么赚钱，就不知道能花多少钱买用户。

## 7.1 两种基础变现模式

| 模式      | 全称                 | 含义      | 收入来源           |
| ------- | ------------------ | ------- | -------------- |
| **IAA** | In-App Advertising | 应用内广告变现 | 用户看广告，你从广告平台分钱 |
| **IAP** | In-App Purchase    | 应用内购买   | 用户直接付费         |

**混合变现**：Total LTV = **Ad LTV + IAP LTV**

⚠️ 关键原则：**别让广告收益伤害了内购收益**——给付费用户展示大量广告，会损害其留存和付费意愿。

## 7.2 IAA + IAP 混合变现的协同设计

典型用户结构（以工具/休闲游戏为例）：

| 用户类型   | 占比  | ARPU  |
| ------ | --- | ----- |
| 广告变现用户 | 95% | 约 $2  |
| 内购变现用户 | 5%  | 约 $50 |

**三条协同策略**：

1. **激励视频解锁试用**——看广告 → 试用高级功能 → 提升付费转化（约 +30%）
2. **付费用户广告优化**——VIP 去广告/减少广告 → 提升付费用户留存（约 +50%）
3. **广告币系统**——看广告获得虚拟币 → 购买道具 → 培养付费习惯

**用户价值升级路径**：免费用户(F2P) → 广告用户(Ad) → 试用用户(Trial) → 付费用户(Pay)

## 7.3 判断产品是否适合接广告变现

自查清单（每项 1 分）：

- 用户量足够大（DAU 有规模）？
- 用户使用时长/频次高？
- 用户对免费有强需求？
- 不是高端付费工具？
- 次日留存超过 30%？

| 得分    | 判断              |
| ----- | --------------- |
| 0-2 分 | 不适合接广告，优先考虑 IAP |
| 3-4 分 | 可小流量测试，谨慎推进     |
| 5-7 分 | 非常适合，立即启动变现     |

## 7.4 广告聚合：从 Waterfall 到 Header Bidding

### 两种模式的本质区别

|      | **Waterfall 瀑布流** | **Header Bidding 竞价** |
| ---- | ----------------- | --------------------- |
| 机制   | 按预设顺序依次询价         | 所有广告源实时竞价             |
| 问题   | 顺序固定，错失高价         | ——                    |
| eCPM | $12-15            | **$18-25（+60%）**      |
| 填充率  | 85%               | **95%（+10%）**         |
| 延迟   | 200ms             | 300ms                 |

举例：Waterfall 按 AdMob $20 → Facebook $15 → Unity $10 顺序问，实际拿到 $15；而竞价模式下各家实时报价（$22/$18/$19/$25/$12），价高者得，实际拿到 **$25\*\*。

> **2024 年后，不用 Header Bidding 就是在给竞争对手送钱。**

### 广告源组合的 5+2+1 配置

- **Layer 1 核心广告源（5 个）**：AdMob（填充率 95%、eCPM $15-20、全球覆盖）、Facebook（90%、$18-25、精准定向）、Unity Ads（85%、$12-18）等
- **Layer 2 补充源（2 个）**：填补特定地区/场景
- **Layer 3 兜底源（1 个）**：保证填充率

## 7.5 动态底价与多阶底价（媒体侧收益优化）

### 核心公式

> **动态底价 = 基准价 × 用户系数 × 时段系数 × 竞争系数**

### 多阶底价的黄金配置（5 阶）

| 阶级    | 用户特征    | 占比  | 底价  | 收益贡献 |
| ----- | ------- | --- | --- | ---- |
| 第 1 阶 | 长尾用户    | 40% | ¥3  | 10%  |
| 第 2 阶 | 普通活跃    | 30% | ¥8  | 20%  |
| 第 3 阶 | 高活跃     | 20% | ¥15 | 30%  |
| 第 4 阶 | 付费用户    | 8%  | ¥30 | 25%  |
| 第 5 阶 | 高价值 VIP | 2%  | ¥50 | 15%  |

**关键洞察**：2% 的高价值用户贡献 15% 收益，值得重点优化。二八定律在广告变现中同样适用。

### 用户分层与时段调价参考

**用户系数**：付费用户 ×2.5、活跃用户 ×1.5、新用户 ×0.8

**时段系数**：晚高峰 19-23 点 +80%、工作时间 9-18 点 +20%、深夜 0-6 点 −50%

**竞争系数**：

- 低竞争（< 3 个竞价者）→ 低底价吸引广告主，提高填充率
- 中竞争（3-8 个）→ 适中底价，平衡收益和填充
- 高竞争（> 8 个）→ 高底价筛选，确保收益最大化

### 动态底价的五个误区

| 误区        | 真相                       |
| --------- | ------------------------ |
| 底价越高越赚钱   | 过高底价会导致填充率下降，要找收益与填充的平衡点 |
| 阶梯越多越好    | 过多阶梯增加管理复杂度，**3-5 阶最优**  |
| 一次设置永久有效  | 市场在变，每月复盘、季度调整           |
| 所有广告位统一策略 | 开屏、信息流、详情页价值差异巨大，应分别设置   |
| 忽视广告主体验   | 底价过高会赶走优质广告主，要保持合理梯度     |

## 7.6 变现侧的三层指标体系

| 层级         | 指标                             |
| ---------- | ------------------------------ |
| **L1 北极星** | ARPDAU（如 $0.15）、广告 LTV（如 $8.5） |
| **L2 过程**  | eCPM、CTR、填充率、CVR、展示率、延迟        |
| **L3 细分**  | 分广告源 eCPM、分广告位填充率、分地区收入、分时段表现  |

### 异常检测规则

- eCPM 环比下降 > 20%
- 填充率 < 80%
- 延迟 > 500ms
- CTR 异常波动 > 50%

**复盘节奏**：实时监控 → 日报 → 周报 → 月度深度分析。

## 7.7 激励广告的设计原则

**核心：在「峰终时刻」植入价值，绝不在用户正在进行核心操作时打断。**

情绪曲线上的时机选择：

| 时机    | 是否适合              |
| ----- | ----------------- |
| 游戏失败后 | ✅ 适合（用户想复活）       |
| 任务成功时 | ✅ 适合（情绪高峰，愿意接受奖励） |
| 返回主页  | ✅ 适合（场景切换的间隙）     |
| 游戏进行中 | ❌ 绝对不要            |
| 看排行榜时 | ❌ 危险（用户专注中）       |

**原则**：在句子的结尾做广告，而不是在句子的中间。

## 7.8 用倒推定价法算清合理出价

这是把变现数据转化为投放决策的关键一步。

**逻辑链**：

1. 先算清 **LTV**（用户终身价值）
2. 确定**目标 ROI**（或目标利润率）
3. 反推**可接受的 CAC / CPA 上限**
4. 再由 CPA 反推**可接受的 CPM**

> 可接受最高 CPM = (LTV × 目标ROI) × CTR × CVR × 1000  
> 盈亏平衡 CPM = 目标CPA × CTR × CVR × 1000

**判断线**：LTV > CAC 才不亏；LTV / CAC > 3 才有充足利润。

## 7.9 订阅制变现的四个模块

1. **周期策略**——按周/月/年设计，不同周期的心理定价和续订率差异极大
2. **定价参考**——定价心理学（锚定、对比、阶梯）
3. **用户分级**——不同价值用户给不同权益和价格
4. **流失召回**——识别流失前信号，设计召回触点

## 7.10 停掉买量后收入会断崖式下滑吗

这是评估买量真实价值的关键问题。

判断依据是**自然量与买量的关系**：

- 若买量带来的用户能沉淀为长期留存和自然口碑，停投后有缓冲
- 若买量用户留存差、纯靠持续注入维持数据，停投即断崖

**评估方法**：用增量归因思路——对比投放期与非投放期的大盘数据差值，而非只看广告平台报告的转化数。

- 千川不能只调广告参数——**商品、价格、库存、直播间承接会实时改变投放结果**

### 千川素材测试 SOP

**测试前三件事**：

1. **账户权重确认**——新账户先跑 100 单建立模型；老账户检查近 7 日 ROI 是否 ≥ 目标值。权重低时强测 = 烧钱
2. **测试预算分配**——单素材测试预算 = 目标 CPA × 50（CPA 80 元 → 单素材 4000 元），同时测 3-5 条，总预算 1.2-2 万
3. **计划结构**——投放方式：专业推广（精准控量）；出价方式：控成本投放（目标成本 = 1.2 倍预期 CPA）；投放时段：全天或高峰（18:00-23:00）

**72 小时黄金测试周期**：24h 看趋势（CTR）→ 48h 看转化 → 72h 定去留。

**UBMax 自动化投放**：日预算建议 ≥ 目标成本 × 50，给机器足够探索空间；素材丰富度 = 机器优化的上限。

## 8.3 腾讯广告（AMS）

**产品矩阵**：ADQ（投放平台）、广点通、优量汇（联盟）。

> ⚠️ **重要：腾讯广告已升级到 3.0 版本**，账户 / 广告结构和投放策略跟 2.0 时代完全不一样了。诊断和复盘腾讯广告账户时，**必须先按 3.0 的逻辑来看**（下面「腾讯广告 3.0」小节），不要再用老的「堆计划、博概率」那一套。

### 🔑 腾讯广告 3.0：从「用广告找人」到「用产品找人」

#### 一句话讲清楚变化

- **2.0（旧版）**：以「广告」为中心，逻辑是**用广告找人**。系统盯的是单条广告能不能起量，投手只能**多建广告堆基建、博起量概率**——建一堆相似广告，看哪条能跑出来。缺点：内部抢量、人力大、盯盘累、冷启动慢、起量像开盲盒。
- **3.0（现版）**：以「产品 / 资产」为中心，逻辑升级成**用产品找人**。系统把你要推的商品、课程、App、短剧、小说、活动等当成一个**「营销资产」**，同一个产品下的多条广告，转化 / 人群 / 创意数据**全部汇聚到这个资产名下，一起训练一个更强的模型**。数据聚合 → 模型更准 → 起量更快更稳。

> **大白话**：以前是「广告越建越多、碰运气」，现在是「把一个产品讲清楚、让系统帮你找会买的人」。所以 3.0 时代花钱是真花钱、不花钱也是真不花钱——不能再靠堆数量刷存在感了。

#### 变化 1：账户 & 广告结构（重点）

| 维度 | 2.0 旧版 | 3.0 现版 |
|---|---|---|
| 层级架构 | **计划 – 广告 – 创意** 三层 | **广告 – 创意** 两层（精简掉一层） |
| 建广告逻辑 | 无严格唯一性校验，可无限新建相似广告 | 新增**广告唯一性校验**，本质相同的广告只允许 1 条 |
| 单账户在投广告数 | 堆得越多越好（博概率） | **建议控制在 2–5 条**，精力从「堆数量」转向「打磨质量」 |
| 起量方式 | 分散预算给多条广告博概率 | 少量广告 + 数据聚合，系统自动把预算给头部广告 |

- **广告唯一性校验（4+m 原则）**：系统基于【**推广产品 + 目标人群 + 投放目标 + 投放周期**】等核心维度给每条广告一个**唯一的「新广告 ID」**。当「**营销内容 + 版位 + 地域 + 年龄**」四个维度完全相同时，只允许建 1 条广告。重复堆叠只有细微差别的广告 = 被判定为同一条，**堆基建直接失效**。
  - 反过来利用它：**想合规地多建几条广告，就在「营销内容 / 版位 / 地域 / 年龄」四个维度里至少错开一个**——不同版位算不同广告，不同地域、不同年龄段同理。顺便还能分维度监测数据差异。
  - ⚠️ **建第 2 条及以上广告的硬动作**：新建广告前，先跟账户里**历史在投广告**逐一比对上面四个维度，**只要人群定向 / 地域和历史广告完全重合，就必然撞唯一性校验、建不出来**。所以第 2 条起必须主动做区分，常用两招：① **收敛目标人群年龄定向**（例：第 1 条 18–45 岁，第 2 条收成 25–35 岁核心段）；② **剔除 / 错开部分城市**（例：第 1 条投一二线全量，第 2 条剔除已投城市、只投新增下沉城市）。这样既绕开校验、又避免自己跟自己抢量（内耗）。
- **账户结构按素材形式来分**（3.0 稳账户的关键）：不要一个账户全是同一种素材形式（比如全组图），否则跑量依赖单一类型、天花板低、一衰退就整体掉量。建议**按素材形式拆账户结构**，例如：组图账户 60% 预算、单图账户 20%、视频账户 20%，分散风险、抬高整体消耗上限。

> **对诊断的影响**：腾讯广告账户「不起量 / 花不出去钱」时，先别急着让用户加广告！先看是不是**触发了唯一性校验**（建的广告本质重复、被判成同一条）、或者**在投广告太少 / 太多**（3.0 建议 2–5 条）、以及**资产信息是否填全**（见下）。这跟 2.0 「计划建少了就多建」的诊断思路完全相反。

#### 变化 2：资产筑基——完善产品信息库（3.0 的起跑线）

3.0 起量的前提是让系统「看懂你的产品」。所以要先把**资产 / 产品信息库填全填好**：清晰完整的产品标题、详情、卖点图 / 视频、行业属性。信息越丰富越精准，系统理解越快、起量越有保障。**这一步没做好，后面创意再好也难起量。**

- 优化师的视角要从「盯单条计划」升级到「**管资产**」：首先关注**在投资产的整体表现**（消耗趋势、转化成本、转化量级），而不是单条广告的波动。
  - 举例：单条广告「掉量」了？先看**资产整体消耗**是不是还在涨。如果在涨，多半是广告之间此消彼长的正常轮动，**别手贱去干预**。

#### 变化 3：素材创意——素材指纹 + 组件化

| 维度 | 2.0 旧版 | 3.0 现版 |
|---|---|---|
| 同质素材 | 容忍度高，可重复投相似素材 | 引入**「素材指纹」**作为核心考核指标 |
| 判重逻辑 | —— | 按画面布局、人物动作、BGM 节奏、文案结构等生成**唯一指纹**，高度相似 = 判重 → **直接触发限流** |
| 单广告素材数 | 越多越好 | 需 **5–10 个不同指纹**的素材，给系统足够探索空间；但保留的**优质创意 2–5 条**即可 |

- **组件化创意**：可把素材拆成独立组件（主体、卖点、背景等），系统自动组合生成多版本创意。创意形式：图片（卡片 / 大图 / 组图 / 橱窗 / 竖图）+ 视频（竖版 / 横版），**样式 × 内容主题**组合出差异化。
- **创意营销组件**（基础文字链接、图文链接、首评、浮层、标签等）合理搭配能显著提升点击率。
- **素材迭代流水线**（稳账户防衰退）：跑量素材会老化，采用 **「70% 延展 + 30% 创新」**——基于当前跑量素材快速衍生新变体（换背景 / 文案 / 局部元素），同时留部分预算测全新方向。
- **创意永动机**（促增长）：3.0 时代创意即流量入口，**提高上新数量与频率**；紧跟大盘跑量方向 + 爆款延展复用 + 勇于测新；对 CTR/CVR 低或持续低消耗的创意果断关停、释放预算。

#### 变化 4：定向体系——宽定向 + 全版位通投

| 维度 | 2.0 旧版 | 3.0 现版 |
|---|---|---|
| 定向核心 | 兴趣 / 行为标签（泛兴趣，与转化关联弱，易高曝光低转化） | **产品维度精准定向**，系统按产品属性自动匹配高意向转化人群 |
| 逻辑 | 「找感兴趣的人」 | 「找**会买、会转化**的人」 |
| 建议做法 | 定向包与广告强绑定，试错成本高 | **宽定向 + 全版位通投**：除年龄、性别外，地域、兴趣等尽量放开，给系统探索空间 |

> **对诊断的影响**：腾讯广告账户如果定向卡太窄（除年龄性别外还锁一堆兴趣 / 行为标签），在 3.0 下反而会**限制系统找人、拉低起量**。诊断时看到「定向太窄」，3.0 的建议是**放开、通投**，而不是继续加标签。

#### 变化 5：出价与预算——精简为两种

| 出价方式 | 特点 | 适用场景 |
|---|---|---|
| **稳定拿量** | 稳成本、平稳跑量 | 常规场景、稳定期 |
| **最大转化量投放** | 预算内尽可能多拿转化、快速起量 | 新品测试、大促爆发等需快速起量 |

- **冷启动出价**：新广告初始出价建议为**目标成本的 1.2–1.5 倍**；**日预算预留 2–3 个转化成本**的探索空间，帮广告快速过冷启动。
- **起量后**：逐步下调出价，系统自动识别头部广告优先分配预算、低效广告自动限流。
- **广告层预算别设太窄**：最低不要低于 **10 个 CPA**，否则拿量低。

#### 变化 6：投放策略三阶段（3.0 实战节奏）

**① 冷启动期（给模型清晰指引）**
- 先做**资产筑基**（产品信息库填全）——这是起跑线。
- 选贴合当前行业大盘跑量的素材；用好一键起量 / 最大转化 / 自动衍生等工具辅助冷启。
- **新广告 / 新创意观察 5–7 天**，其中**前 48–72 小时消耗趋势**是关键信号：高潜创意（CTR/CVR 突出）果断加预算培养成明星创意；低潜创意（持续低消耗、被打「低潜」标签）及时换素材，别占资源。
- **控制调整频率**：不要频繁上 / 删广告、频繁改时段定向预算。

**② 稳账户期（构建稳定器，破解波动）** — 波动通常来自三方面：
- **账户结构同质化** → 按素材形式区分账户结构（组图 / 单图 / 视频分开）。
- **素材生命周期衰退** → 建素材迭代流水线（70% 延展 + 30% 创新）。
- **日常操作干扰**（人为波动）→ **操作要克制**：
  - 减少非必要操作，小波动（20% 内）先观察 1–2 天；
  - **单日单次原则**：单账户每天调整（出价 / 预算）不超过 1 次；
  - **温和调整**：出价调整幅度控制在 **5%–10%** 以内（尤其降价别一次 > 30%，会触发系统惩罚）。

**③ 促增长期（打造增长飞轮）**
- **数据 API 回传**（核心燃料）：把后端真实转化（下单 / 付费 / 留资）及时准确回传给系统，模型才能越跑越准。没有高质量回传，3.0 的优势发挥不出来。
- **多品测试探路**：账户内测不同属性 / 价格带 / 卖点的商品，快速找出「潜力品」，帮模型定位高价值人群。
- **创意永动机**：持续上新 + 爆款延展 + 测新 + 及时淘汰低效。

#### 「出价调整四象限」黄金法则（3.0 稳账户日常操作）

| 场景 | 操作建议 |
|---|---|
| 成本 < 出价 **且** 消耗快 | **阶梯降价**：按 5%–10% 逐步降、每日观察，别一次降到成本线以下 |
| 成本 < 出价 **且** 消耗下降 | **提价 + 追量**：提价并考虑用「一键起量」提升竞争力，避免被系统打压 |
| 成本 > 出价 **且** 消耗慢 | **阶梯提价 + 检查**：按 5%–10% 逐步提，同时重点查素材质量、定向、落地页 |
| 成本 > 出价 **且** 消耗快（超 20% 以内） | **以观察为主**：成本略超但消耗好，系统可能在优化，拉长观察窗口往往会回落 |
| 成本 > 出价 **且** 消耗快（超 20% 以上） | **谨慎关停**：优先关停持续严重超成本的广告 / 创意，把预算释放给优质计划 |

#### 3.0 时代优化师的角色转变

从「基建工人」→ 变成「**产品经理 + 创意总监**」。核心竞争力 = ①对产品价值的理解与表达（资产建设）②持续产出高质量多样化创意的能力 ③基于数据洞察和全局视角管资产、调策略。**一条 3.0 广告 = 推广产品 / 考核目标 + 出价测试方案 + 差异化创意素材。**

> 官方「建广告分行业唯一性校验说明」：https://support.e.qq.com/detail?cid=4587&pid=10141

### 版位与形态

> 本节只列**效果竞价**可投版位。闪屏 / 蒙层 / OneShot / Phonemax / 互动闪屏 / 信息流破框 / TVmax 等属品牌互动形态，按排期采买，不在此列。

| 版位类型 | 具体形态 |
|---|---|
| 微信生态 | 朋友圈广告、公众号（文中 / 底部）广告、小程序广告、视频号信息流与原生广告、搜一搜广告、看一看广告 |
| 微信交易场 | 微信小店（视频号小店智投）、小程序推广 |

**朋友圈广告的用户数据参考**：日均渗透率接近 75%；超 8 成用户看完朋友圈广告后会有行动。

**朋友圈竞价广告特点**：CTR 高、转化高；支持首条评论、支持挂载图文组件、支持一键下载/应用直达、支持直接留企业微信名片。

### 关键操作差异

- ⚠️ **不要把朋友圈和视频号混为同一种流量**——版位合并会掩盖真实问题，必须**拆分版位**排查
- 腾讯 ADQ 视频号有三个入口：原生内容（主页内容拉取）、互动沉淀原视频、直播推广（短视频推直播）
- **ADQ 原生内容赛马**：目标不是买播放，是挑出值得追投的主页内容。做法是 5 条主页内容同题不同钩子（同产品、同利益点，只换前 3 秒和钩子），点击 × 停留 × 组件点击同时过线者胜出，5 选 1 进入原生放大
- 视频号小店智投配置：单账户预算建议 > 5000 元（预算太抠系统没探索空间）；小店管理员扫码确认绑定视频号，最多可批量绑定 20 个

### 企业微信获客链路

腾讯全流量（微信广告、腾讯平台与内容广告、优量汇）均支持企业微信获客：

- **直跳链路**：各流量版位直跳企业微信名片，高效获客
- **筛客链路**：通过落地页组件、公众号关注等二跳加微，高效筛客

## 8.4 小红书（聚光 / 薯条）

### 版位与形态

> 本节只列**效果竞价**可投版位。开屏、火焰话题、商业话题等 GD 排期采买的品牌资源不在此列。

| 版位类型 | 具体形态与插入位 |
|---|---|
| 信息流 | 发现页，第 **6 位**起顺位投放，之后 **+10** 递增（6 / 16 / 26…） |
| 搜索 | 社区搜索结果页第 **3 位**起 **+10** 递增（3 / 13 / 23…）；商城搜索结果页第 **1 位**起 **+5** 递增 |
| 视频流 | 单列视频流场景（从发现页点进视频后的上下滑），第 **7 位**起 **+10** 递增 |
| 全站智投 | 一个计划同时覆盖信息流 + 搜索 + 视频流，由系统智能分配流量 |
| 内容加热 | 薯条（笔记加热，轻量级自助投放） |

**版位的心智差异**：信息流与视频流是**被动触达**（用户在闲逛，靠内容破防）；搜索是**主动意图**（用户已被种草，正在比价决策）。所以信息流适合前期种草打爆文，搜索适合后期拦截需求收割。

⚠️ **信息流与搜索的预算配比**是小红书投放的核心变量。常见节奏：蓄水期 信息流 : 搜索 ≈ 7:3 → 爆发期 ≈ 1:1 → 收割期可反转到 3:7。

> 蒲公英（达人合作报备笔记）不是版位，而是**投放标的来源**——报备笔记可作为聚光的投放素材。

### 聚光 vs 薯条：流量基因完全不同

|      | **聚光（收割型）**                   | **薯条（种草型）**  |
| ---- | ----------------------------- | ------------ |
| 用户来源 | 搜索关键词、笔记评论区、商品详情页             | 发现页信息流、关注页推荐 |
| 心智状态 | 已被种草，正在比价决策                   | 闲逛状态，等待内容破防  |
| 核心特征 | 主动寻找                          | 被动触达，冲动决策    |
| 真相   | **聚光的流量不是"推"出来的，是用户自己"找"过来的** | 规模种草         |
|      |                               |              |
|      |                               |              |
|      |                               |              |

### 出价方式

| 方式          | 特点                                  | 适用                    |
| ----------- | ----------------------------------- | --------------------- |
| oCPC（推荐）    | 转化成本可控，±20% 波动范围。**成本超 20% 平台赔付差价** | 有明确转化目标、预算适中、追求稳定 ROI |
| Nobid（新手友好） | 只设预算不设出价，系统智能托管，预算内最大化转化数           | 预算明确、缺少成本概念           |

### 平台特性与限制

- ⚠️ **聚光不是纯竞价问题**——笔记内容价值、社区语境、搜索意图会直接影响分发
- 低质广告即使出价高也会被降权
- 原生品牌笔记 eCPM 权重更高
- 平台重视社区氛围保护
- **信息流与搜索需分别起量**，不能混在一起看
- KOS（企业号+员工号矩阵）：多账号消息聚合管理，客资来源清晰归类

**产品矩阵**：磁力引擎（投放平台）、磁力金牛（电商）、磁力方舟（数据）、磁力追踪（线索管理）、快分销、快手联盟。

### 版位与形态

> 本节只列**效果竞价**可投版位。Eyemax、轻互动开屏、开屏首刷、Pop-play / Pop-show 彩蛋、品牌专区、搜索首页悬浮球等属品牌资源，按排期采买，不在此列。

### 投放要点

- ⚠️ **磁力流量对社区表达和素材标签敏感**，生硬搬运其他平台素材容易匹配错误人群
- **素材方向**：强人设口播、真实场景、直播切片、"老铁"信任表达
- **速推版**（中小客户简化入口）会**屏蔽联盟等渠道**，只投主站与极速版，流量质量更稳
- **排查入口**：磁力引擎投放诊断与转化追踪
- **转化链路**：表单、私信（行为数 / 私信消息 / 私信留资三档深度）、落地页跳微信或企微加粉、CID 电商、App 下载激活、直播间小铃铛 / 小钥匙、快手小程序、快手号加热
- **计费方式**：CPC 与 oCPM，oCPM 超目标出价 20% 有赔付

# 第九部分　问题诊断手册（18 类问题速查）

> 完整的分平台排查路径（108 条，覆盖巨量引擎/千川/腾讯广告/小红书聚光/磁力引擎/百度营销）见各渠道文件的「问题诊断与排查」章节。此处是**通用排查框架 + 18 类问题索引**。

## 9.1 所有问题的通用排查框架

### 第一步：校准判断基准

任何异常都对比两个基准：

1. **本账户同平台近 7 天中位数**
2. **异常发生前的基线**

⚠️ 不套用跨行业"标准值"。

### 第二步：确认生命周期阶段（决定该不该动手）

| 阶段            | 动作                    |
| ------------- | --------------------- |
| 冷启动期（前 72 小时） | **绝对静止**，20-30% 波动属正常 |
| 成熟稳定期         | 立即干预                  |

### 第三步：判断颗粒度

- 所有计划都出问题 → 外部环境（竞争、大盘、节点、审核政策）
- 单个/头部计划出问题 → 单点原因（素材衰退、承接失效、产品端改动）

### 第四步：漏斗定位断点

按顺序检查，找到**第一个崩掉的环节**：

```
展现量 → 点击率 → 到达率 → 转化率 → 线索质量/ROI
  ↓        ↓        ↓        ↓          ↓
竞争/预算  素材衰退  页面加载  落地页/     素材承诺过度/
/审核     /人群偏   速度      人群质量    人群不对
```

### 第五步：单变量修改 + 定观察窗口

- **一次只改一件事**，否则回落了也不知道是谁的功劳
- 观察周期：**至少 24 小时或一个完整转化窗口**；样本过少时不提前判断
- **回退条件**：若样本充足后核心成本连续恶化，恢复上一版稳定设置，并保留调整记录

| 15 | 页面到达率低 | 转化承接  | 加载速度（须 < 2 秒）、跳转链路                |
| 16 | 负面反馈增加 | 素材反馈  | 频次是否过高、内容是否引起反感                   |
| 17 | 计划互相抢量 | 账户结构  | 是否存在无差异复制、同质化计划                   |
| 18 | 放量后失控  | 规模增长  | 承接端是否跟上（80% 的放量失败源于此）             |

> 🐧 **腾讯广告 3.0 补充**：第 01「不起量 / 花不出去钱」和第 17「计划互相抢量」在腾讯广告上，首先要查是否**触发了广告唯一性校验**（本质重复的广告被判成同一条）、在投广告是否偏离 2–5 条、以及资产信息 / 定向是否过窄。诊断动作以 8.3「腾讯广告 3.0」小节为准，**不要建议用户继续堆广告**。

## 9.3 每条诊断的标准结构

分平台诊断手册里，每个问题都按这个结构组织，可直接照做：

1. **STEP01 平台化排查**——去哪个后台、看哪些层级、确认异常开始时间与最近一次操作
2. **STEP02 解决动作**——保持什么不变、只测哪一个变量
3. **DATA CHECK 数据判断口径**——与自己账户近 7 天中位数和异常前基线对比
4. **建议观察周期**——至少 24 小时或一个完整转化窗口
5. **回退条件**——什么情况下恢复上一版设置
6. **案例记录标准**——记录唯一变量与实际结果，便于复盘复用

| 类别 | 公式                                           |

## 十条核心结论

1. **eCPM 是唯一货币**——能否拿量看 eCPM，不看出价高低。把素材做好等于变相加价。
2. **出价是资格证，实付看第二名**（GSP）——这是你敢提价的底气，但竞争激烈时实付会被顶高。
3. **冷启动的门槛是转化数，不是天数**——喂不满就别开投。
4. **学习期任何修改都是推倒重学**，调三次就是三次重置。
5. **超成本先诊断再动手**——时间轴 → 颗粒度 → 漏斗，单变量修改。
6. **素材衰退是系统性现象**（用户疲劳 + eCPM 负反馈 + 生命周期 + 同质化），靠持续上新而非修补老素材。
7. **智能出价是放大器不是制造机**——回传不准、素材不行，模型救不了。
8. **放量不是加预算，是复制成功单元**；放量失败 80% 是承接端没跟上。
9. **算法学的是你教的东西，不是你想要的东西**——回传口径必须只对准唯一核心目标。
10. **所有异常都跟自己账户近 7 天中位数和异常前基线比**，不套用跨行业标准值。
