# 腾讯广告操作手册 (Operation Playbook)

本手册总结了针对多种投放场景的深度调优方法论，适用于 ROI、CPL、CPA 等不同考核模式。

## 1. 分层诊断框架

### Layer 1: 账户级健康度

| 指标 | 健康 | 预警 | 危险 |
|------|------|------|------|
| 达标率 | > 70% | 50-70% | < 50% |
| 在投广告数 | 5-15 | < 5 或 > 20 | < 3 |
| 消耗集中度 | 前3条 < 60% | 前3条 60-80% | 前3条 > 80% |

### Layer 2: 广告级评估维度

1. **效果维度**：核心指标是否达标
2. **效率维度**：跑速是否正常（日消耗是否符合预期）
3. **趋势维度**：近3天指标走势
4. **生命周期**：机龄与衰退信号

### Layer 3: 执行优先级

```
止损 (立即) > 扩量 (当日) > 提价 (观察后) > 上新 (规划中)
```

---

## 2. 出价策略方法论

### 场景 A：跑速慢 / 消耗不出

**诊断**：模型探索受限或出价竞争力不足

**对策 - 递进式提价**：
- 每次提价 3-5%，观察 4 小时消耗变化
- **锚定原则**：只要实际指标远超目标，可大胆提价至"实际成本"的 80%

**示例**：
> 目标 ROI 1.0，当前实际 ROI 2.5，出价 100 元
> → 实际付费成本约 40 元，可提价至 80 元（40 × 2）

### 场景 B：成本高于出价但指标达标

**诊断**：系统在用高价获取高质量人群

**对策**：**保持不动**
- 不要因为 CPA 高而降价
- 只要核心指标达标，优先保护跑量模型

### 场景 C：指标达标但量级不足

**诊断**：竞争力不足或预算约束

**对策 - 一键起量**：
- 仅在指标达标且急需补量时使用
- 单次持续时间不超过 2 小时
- 起量期间密切监控成本

## 3. 止损判定准则

### 硬性止损（无需犹豫）

| 信号 | 判定 | 操作 |
|------|------|------|
| 消耗 > 止损线 且 核心指标=0 | 确定性空耗 | **立即软关停** |
| 核心指标 < 目标的 40% | 严重偏离 | **立即软关停** |
| 连续 3 天指标恶化 | 不可逆衰退 | **软关停并替换** |

### 软性止损（需观察）

| 信号 | 判定 | 操作 |
|------|------|------|
| 核心指标在 40%-60% 目标 | 边缘状态 | 减量观察 4 小时 |
| 消耗占比 > 40% 但指标不佳 | "吸血鬼"计划 | 平滑降价 |
| 机龄 > 21 天且指标下滑 | 生命周期末端 | 准备替换素材 |

### 止损线参考值

| 模式 | 默认止损线 | 说明 |
|------|------------|------|
| ROI | 500 元 | 高客单价场景可上调至 800 元 |
| CPL | 目标 × 3 | 如目标 25 元，止损线 75 元 |
| CPA | 目标 × 5 | 转化周期长，容忍度更高 |

### 软关停操作规范

```
修改 begin_date = 明天日期
保持 time_series = "5-24" 不变
不要直接暂停，便于次日恢复
```

## 4. 扩量时机与方法

### 扩量信号识别

| 信号 | 扩量方式 | 预期效果 |
|------|----------|----------|
| ROI > 目标 × 2 且跑速慢 | 梯度提价 5-10% | 提升竞争力 |
| 指标达标 + CPM < 15 | 一键起量 | 快速放量 |
| 连续 3 天指标稳定 | 放开预算上限 | 稳态扩量 |
| 新计划冷启动成功 | 加大预算 50% | 抢占模型窗口 |

### 扩量节奏控制

```
冷启动期 (0-3天):  谨慎扩量，优先验证模型
成长期 (3-7天):    可积极扩量，抓住红利期
成熟期 (7-14天):   稳健扩量，关注边际效应
衰退期 (14天+):    停止扩量，准备替换
```

## 5. 预算与时段管理

### 日内节奏参考

| 时段 | 策略 | 原因 |
|------|------|------|
| 00:00 - 07:00 | 低预算 / 暂停 | 凌晨流量质量差，易空耗 |
| 09:00 - 11:00 | 第一次放量 | 上班高峰，转化意愿强 |
| 14:00 - 17:00 | 观察 + 二次放量 | 下午转化稳定期 |
| 20:00 - 23:00 | 高峰冲刺 | 晚高峰，量级最大 |

### 预算分配原则

- **头部集中**：70% 预算给 Top 3 王牌计划
- **梯队备份**：20% 预算给潜力计划培养
- **测试探索**：10% 预算给新计划冷启动

## 6. 生命周期管理

### 广告生命周期阶段

```
┌─────────────────────────────────────────────────────────────┐
│  冷启动期        成长期         成熟期         衰退期       │
│  (0-3天)        (3-7天)        (7-14天)       (14天+)      │
│                                                             │
│  ●───────────●───────────●───────────●───────────●        │
│  观察模型      积极扩量      稳健优化      准备替换        │
└─────────────────────────────────────────────────────────────┘
```

### 各阶段操作要点

| 阶段 | 核心目标 | 关键动作 |
|------|----------|----------|
| 冷启动 | 验证模型可行性 | 小预算测试，容忍波动 |
| 成长期 | 抓住红利窗口 | 积极提价/起量，抢量 |
| 成熟期 | 最大化 ROI | 稳定出价，优化素材 |
| 衰退期 | 平稳过渡 | 逐步降价，准备新计划 |

### 上新节奏建议

- 每 3-5 天新建 1-2 条测试广告
- 不要等老广告全衰退才补新
- 保持账户始终有 5-10 条在投广告（⚠️ **腾讯广告 3.0 例外：在投控制在 2-5 条**，见 6.4）

### 6.4 腾讯广告 3.0 建广告规则（AMS 3.0 唯一性校验 · 强制）

> 适用范围：腾讯广告（AMS）3.0 账户。诊断/建单/上新时**强制**遵守；其他平台不受此约束。

**规则一 · 广告唯一性校验（建单硬约束）**
- AMS 3.0 更新后新增校验：当【**营销内容 + 版位 + 地域 + 年龄**】四个维度**完全相同**时，系统**只允许创建 1 条广告**；本质重复的广告会被判为同一条，**建不出来 / 堆基建无效**。

**规则二 · 单账户在投广告数**
- 建议**控制在 2-5 条**（不是越多越好），精力从"堆数量"转向"打磨质量 + 管资产"。

**规则三 · 建第 2 条及以上的强制操作（避免撞校验 + 避免内耗）**
- 新建第 2 条起，**必须先跟账户里历史在投广告逐一比对上面四个维度**，只要人群定向/地域与历史广告完全重合 → 必撞校验。所以第 2 条起**必须主动与历史广告做人群定向 + 地域区分**，常用两招（至少用一招，可叠加）：
  1. **收敛目标人群年龄定向**：例 第 1 条 18-45 岁 → 第 2 条收成 25-35 岁核心段；
  2. **剔除/错开部分城市**：例 第 1 条投一二线全量 → 第 2 条剔除已投城市、只投新增下沉城市。
- 也可用「版位/营销内容」维度错开（不同版位算不同广告），但优先用人群+地域区分，顺带分维度看数据、避免自己跟自己抢量。

**对诊断的影响**：腾讯广告账户"不起量/花不出去钱"时，**先别急着让用户加广告**——先查：① 是否触发唯一性校验（广告本质重复）；② 在投广告是否 2-5 条区间；③ 资产信息是否填全。（详见知识手册 8.3）

## 7. 异常情况处理

### 突发流量暴涨

1. 检查是否触发一键起量
2. 检查竞品是否下线导致流量溢出
3. 若 ROI 下滑，立即降价 5-10%

### 突发成本飙升

1. 检查素材是否审核异常
2. 检查是否遇到行业大盘波动
3. 检查出价是否被系统自动调整
4. 若持续 2 小时不恢复，执行软关停

### 转化数据回传延迟

1. 优先排查技术链路（事件回传是否正常）
2. 使用 T+1 数据作为决策依据
3. 不要因为当日数据延迟就仓促止损

## 附录：常用计算公式

```
ROI = 付费金额 / 广告消耗
CPL = 广告消耗 / 线索数
CPA = 广告消耗 / 转化数

提价幅度 = (目标成本 - 当前成本) / 当前出价 × 50%
止损线 = 目标成本 × 止损倍数 (ROI:无, CPL:3x, CPA:5x)
```
