# 账户基建策略 (Account Buildup Strategy) — 纯新项目从 0 到 1 搭建

> 本文是「AI投手·诊断包」**纯新项目路径**的核心参考。当用户没有在投账户、想从零开始投放时，本包跳过账户诊断，直接依据本文给出**五维基建策略**（账户 / 版位 / 广告 / 出价 / 素材），让用户确认后产出《新项目基建纪要》交给优化包。
>
> ⚠️ 纯新项目的受众是**普通人**（非专业优化师），全文遵循「语言风格指南」，用大白话交流、给具体数字区间、术语配白话解释。

---

## 〇、普通人语言风格指南（纯新项目路径必读）

纯新项目用户多为企业老板、市场新手、个人创业者，**不是专业优化师**。沟通必须降门槛：

| 原则 | 错误示范 | 正确示范 |
| :-- | :-- | :-- |
| 用"你"，不用"贵司/您" | "请问贵司考核口径" | "你想花多少钱带来一个客户？" |
| 术语配白话括号 | "CPA 控制在 80" | "CPA（每个客户花多少钱）控制在 80 元左右" |
| 一次只问一个事 | 一口气问 5 个字段 | 先问"你卖什么、想花多少钱"，再逐步补 |
| 给选项不给填空 | "考核指标是？" | "你想达到的效果是？A.卖货 B.留资 C.下载App D.其他" |
| 数字给区间不给单点 | "出价 100" | "出价先设 80-120 元试试" |
| 解释"为什么这么做" | "用 oCPM 出价" | "用 oCPM（系统自动找人）出价，让平台帮你找最可能下单的人" |
| 避免 jargon 堆砌 | "用 lookalike + oCPM + 优选版位" | "用系统自动找相似人群 + 自动挑展示位置" |

> 纯新项目路径全程按本指南说话。原诊断路径（专业优化师）保持原专业语气。

## 一、五维基建策略总览

从 0 到 1 搭账户，按以下五个维度逐项给建议。**每个维度都给"具体数字区间 + 一句白话解释"**，不要只给方向。

```
①账户 → ②版位 → ③广告(计划) → ④出价 → ⑤素材
 建几个   放哪    建几条        怎么花   做几个
```

| 维度 | 一句话 | 普通人最常踩的坑 |
| :-- | :-- | :-- |
| **账户** | 开几个、什么类型 | 开一个账户死磕，量起来撑不住；或开太多每个都跑不出模型 |
| **版位** | 广告放在哪展示 | 全开版位导致钱花在低质流量；或只开一个版位量太小 |
| **广告(计划)** | 建几条、怎么定向 | 只建 1-2 条计划不敢铺量；或一上来建几十条预算稀释 |
| **出价** | 怎么花钱、出多少 | 出价太低跑不出量；或出价太高直接烧爆成本 |
| **素材** | 做几个、什么内容 | 只做 1 个素材赌运气；或素材同质化没法测试 |

> ⚠️ **默认基线 vs 用户经验适配（重要原则）**：本文件所有数字（账户数、广告结构、出价区间、素材池构成、盯盘时间点等）均为**默认基线建议**，适用于无项目经验的纯新项目起步。**当用户有自己的项目经验时（如"我们行业一般建 8 条广告""出价习惯设 60""素材以视频为主"），优先用用户经验覆盖默认基线**，生成适配用户项目的策略，而非硬套默认值。采集环节主动问一句"你有没有自己的投放经验或偏好"，有则按经验调，无则用默认基线。

## 二、账户建议

### 2.1 决策逻辑
账户数量按**日预算量级**决定，不是越多越好：

| 日预算 | 账户数 | 说明 |
| :-- | :-- | :-- |
| < 1000 元 | 1 个 | 单账户起量，预算别稀释 |
| 1000-5000 元 | 1-2 个 | 单账户为主，量起来再开第二个分流 |
| 5000-20000 元 | 2-3 个 | 主账户跑模型，辅账户测素材/版位 |
| > 20000 元 | 3-5 个 | 多账户分散，避免单账户过审风险与量级天花板 |

### 2.2 账户类型（腾讯广告为例）
- **白户**：资质干净、审核快、模型学习稳，**纯新项目首选**。
- **老户重启**：有历史数据可继承模型，但要确认历史数据是否干净（有没有跑过违规品）。
- **避免**：跑过违规品的灰户，模型被污染，新项目上去会被历史数据带偏。

### 2.3 给用户的白话建议模板
> "建议你开 [1-3] 个账户。原因：你日预算大概 [X] 元，[1] 个账户跑得起来，预算不会太分散。等量跑起来（一般 [7-14] 天）再考虑开第二个账户分流测试。"

## 三、版位建议

### 3.1 决策逻辑
版位 = 广告展示在哪（朋友圈 / 公众号 / 视频号 / QQ / 腾讯新闻 / 优量汇等）。两条路线：

| 路线 | 适用 | 建议 |
| :-- | :-- | :-- |
| **自动优选版位**（推荐纯新项目） | 不确定哪个版位好、想让系统找量 | 系统自动挑表现好的版位，省心，适合新手 |
| **手动指定版位** | 已知目标人群在哪活跃 | 手动勾选 2-3 个主力版位，排除低质版位 |

### 3.2 常见版位适配（腾讯广告）
| 版位 | 适合 | 备注 |
| :-- | :-- | :-- |
| 朋友圈 | 品牌曝光 + 高客单转化 | CPM 高，适合预算充足 |
| 视频号 | 短视频素材、年轻人群 | 近年红利版位，量级增长快 |
| 公众号文章中/底部 | 长决策产品、内容种草 | CVR 较稳，适合留资 |
| QQ 看板/QQ 浏览器 | 年轻人群、低客单 | CPM 低，跑量快 |
| 优量汇（联盟） | App 下载、低成本跑量 | 量最大但质杂，需配转化目标 |
| 腾讯新闻/腾讯视频 | 泛人群曝光 | 适合品牌类 |

### 3.3 给用户的白话建议模板
> "建议你先用【自动优选版位】，让系统帮你挑展示位置，省得自己猜哪个版位好。等跑 [7] 天看出哪个版位效果好，再手动调整。你的行业是 [X]，[视频号/朋友圈] 可能比较对口，可以重点观察。"

## 四、广告（计划）建议

### 4.1 广告结构基线（新底层逻辑）
新账户广告按"广告 → 创意组 → 素材"三级结构搭建，素材从项目素材池（见第六节，储备 50 条）里挑、可跨广告/创意组重复挂：

**结构**：1 账户 → 3-5 条广告 → 每条广告 3-5 个创意组 → 每个创意组挂 5-10 个素材

| 日预算 | 广告数 | 每条广告创意组数 | 每创意组素材数 | 说明 |
| :-- | :-- | :-- | :-- | :-- |
| < 2000 元 | 3 条 | 3 个 | 5 个 | 集中预算，让模型学得动 |
| 2000-10000 元 | 3-5 条 | 3-5 个 | 5-10 个 | 主力广告 + 测试广告组合 |
| > 10000 元 | 5 条 | 5 个 | 10 个 | 分人群/分素材矩阵铺开 |

> 素材从第六节的"项目储备 50 条素材池"里挑，**素材可跨广告/创意组重复挂**——好素材重复用放大跑量，测不同人群/版位组合。

### 4.2 定向方式（投给谁）
纯新项目定向**从宽到窄**，让模型先学起来：

| 定向方式 | 说明 | 纯新项目建议 |
| :-- | :-- | :-- |
| 系统智能定向 | 平台自动找人 | **首选**，给足模型学习空间 |
| 自定义人群包 | 上传老客/种子人群 | 有老客数据时叠加，提升冷启动 |
| lookalike（相似人群） | 基于种子扩展 | 有种子人群时用，放大高价值人群 |
| 兴趣标签 | 手动勾兴趣 | 模型跑稳后再用，初期别卡太死 |
| 行为定向 | 按搜索/购买行为 | 重决策产品适用 |

### 4.3 预算分配
- 首批广告**平均分预算**，别把宝压在一条上。
- 跑 3-5 天后，把预算向"出量且成本达标"的广告集中（70/20/10）。

### 4.4 给用户的白话建议模板
> "建议你建 [3-5] 条广告，每条广告下 [3-5] 个创意组，每个创意组挂 [5-10] 个素材（从 50 条素材池里挑，好素材可重复挂）。原因：你日预算 [X] 元，[3-5] 条广告每条分到 [Y] 元，够模型学习又不会太散。定向先用【系统智能定向】，让平台帮你找人，别一开始就卡太死。有老客户名单的话可以传上来当种子，冷启动更快。"

## 五、出价建议

### 5.1 出价方式选择
| 出价方式 | 说明 | 纯新项目建议 |
| :-- | :-- | :-- |
| oCPM / oCPC（按转化目标出价） | 系统按"你想要的结果"优化 | **首选**，最省心 |
| CPM（按千次曝光出价） | 按曝光付费 | 仅品牌曝光用，不适合效果 |
| CPC（按点击出价） | 按点击付费 | 不推荐，系统找不到转化人群 |

### 5.2 初始出价区间（关键 · 给具体数字）
出价 = **你愿意为一个转化（一个客户/一个订单/一次下载）付多少钱**。纯新项目冷启动出价建议：

> **初始出价 = 考核成本（你能接受的最高单客成本）× 50%-70%**

理由：冷启动期要给系统略高于真实目标的"出价信号"让模型敢跑量，但别顶到考核成本（顶满容易烧爆）。

| 考核成本 | 初始出价区间 | 说明 |
| :-- | :-- | :-- |
| 50 元 | 25-35 元 | 5-7 折 |
| 100 元 | 50-70 元 | 5-7 折 |
| 200 元 | 100-140 元 | 5-7 折 |
| 500 元 | 250-350 元 | 5-7 折 |

> 跑出 5-10 个转化后，按真实成本回调出价：真实成本 < 出价 → 降 5-10%；真实成本 > 出价 → 提 5% 或观察。

### 5.3 调价节奏
- **单次调价幅度 ≤ 10%**，别大起大落。
- 每次调价后**观察 4 小时**再决定下一步。
- 冷启动期（前 3-7 天）**别频繁调价**，打断模型学习。

### 5.4 给用户的白话建议模板
> "建议你用【oCPM】出价（系统按你想要的结果优化，最省心）。你说能接受一个客户花 [考核成本] 元，那初始出价先设 [考核成本×0.6] 元试试——给系统留点空间敢跑量，但别顶满，怕烧爆。跑出 [5-10] 个客户后，看真实花多少再回调。"

## 六、素材建议

### 6.1 素材池储备基线（新底层逻辑）
项目储备 50 条素材池（不是一次性全用，是建素材库供广告挑选）。建广告时从池里挑挂到创意组，**素材可跨广告/创意组重复挂**——好素材重复用放大跑量。

| 素材池构成 | 默认数量 | 说明 |
| :-- | :-- | :-- |
| 视频 | 约 10 条 | 补充抓眼球，朋友圈/视频号用（用户行业偏好不同可调） |
| 图文 | 约 40 条 | 留资 CVR 稳的主力，公众号深度种草，多卖点矩阵 |
| 合计 | 50 条 | 项目素材池，建广告时从中挑可重复挂 |

> 50 条是项目储备量，不是每条广告都要用 50 个。每个创意组挂 5-10 个（见 4.1），从池里挑，好素材可挂到多个创意组测不同人群/版位组合。

### 6.2 素材形式选择
| 形式 | 适合 | 纯新项目建议 |
| :-- | :-- | :-- |
| 竖版短视频（9:16） | 视频号/朋友圈/信息流 | 抓眼球，CTR 通常较高（是否主力看行业/用户经验） |
| 横版视频（16:9） | 腾讯新闻/优量汇 | 补充覆盖 |
| 图片（大图/三图） | 公众号/QQ | 低成本测试，适合多卖点矩阵 |
| 原生图文 | 内容种草 | 长决策产品 |

### 6.3 素材卖点矩阵（避免同质化）
首批素材至少覆盖 3 类卖点，别全打一个点：
| 卖点类型 | 举例 |
| :-- | :-- |
| 功能型 | 产品能做什么、解决什么问题 |
| 价格型 | 优惠、性价比、限时 |
| 场景型 | 在什么情况下用、谁在用 |
| 情感型 | 焦虑缓解、身份认同、信任背书 |

### 6.4 素材钩子（前 3 秒 / 首屏）
CTR 的核心杠杆是前 3 秒 / 首屏。建议首批素材测 2-3 个不同钩子：
- 痛点开场（"你是不是也遇到 XX 问题"）
- 利益开场（"XX 元就能搞定 XX"）
- 场景开场（直接演示使用场景）
- 信任开场（"XX 万人都在用 / XX 机构推荐"）

### 6.5 素材池轮换节奏
- 跑 3-5 天后，CTR 高的素材 → 多挂几个创意组放大跑量，并做系列衍生补进池子。
- CTR 低的素材 → 从创意组摘掉，换池里其他素材。
- **每 3-5 天补 1-2 条新素材进池**，保持池子新鲜。
- 爆款素材也会衰退（通常 14-21 天），提前 5 天准备接棒的，保持池子里始终有新鲜素材。

### 6.6 给用户的白话建议模板
> "建议你项目储备 [50] 条素材池：默认 [10] 个视频 + [40] 张图文（你有经验按你的经验调）。素材别全打一个卖点，至少覆盖 [功能/价格/场景/信任] 四类。前 3 秒/首屏很重要，是用户划不划走的关键，建议测多个不同开头。建广告时从池里挑挂到创意组，好素材可重复挂到多个创意组放大跑量。跑 [5] 天后看哪个好，好的多做几个变体补进池子，差的从创意组摘掉换池里其他的。"

## 七、行业基线参数表（冷启动参考）

> 以下为通用冷启动基线，**实际以用户给的考核成本为准**。出价 = 考核成本 × 50%-70%；计划数/素材数按日预算量级查上方表格。

| 行业 | 典型考核口径 | 冷启动周期 | 版位偏好 | 出价/调价注意 |
| :-- | :-- | :-- | :-- | :-- |
| 电商（实物） | ROI / 下单成本 | 3-5 天 | 视频号 + 朋友圈 + 优量汇 | 转化快，调价可稍激进；关注退货率 |
| 电商（虚拟/服务） | 下单成本 | 5-7 天 | 公众号 + 视频号 | CVR 偏低，出价别压太狠 |
| 线索收集（教育/装修/B2B） | 有效线索成本 | 7-10 天 | 公众号 + 朋友圈 | 转化链路长，给足冷启动；有效/表单口径要校准 |
| App 下载/注册 | 注册成本 | 3-7 天 | 优量汇 + QQ系 | 量大质杂，配深度转化目标（激活/付费） |
| 金融（理财/保险/信贷） | 开户/授信成本 | 10-14 天 | 朋友圈 + 公众号 + 视频号 | 合规严，转化深，冷启动长，出价别低于考核 50% |
| 本地生活（到店/团购） | 核销成本 | 3-5 天 | 朋友圈（LBS）+ 视频号 | 地域定向，单店预算别开太多计划 |
| 游戏（下载/付费） | 激活/付费成本 | 5-10 天 | 视频号 + 优量汇 + QQ系 | 大R稀疏，付费口径冷启动长，先优化激活再切付费 |

> 行业不在表内时，按"转化链路长短"类推：链路短（电商/App）冷启动快、出价可激进；链路长（金融/线索）冷启动慢、出价别压太狠。

基建闸门（闸门N1）通过后，产出结构化纪要，作为优化包（ai-analysis-expert-02）的输入：

```markdown
## 1. 项目基本盘

## 2. 账户建议

## 3. 版位建议
- 自动 or 手动 / 主力版位 / 排除版位 / 理由
## 4. 广告（计划）建议
- 广告结构（广告数 / 每条创意组数 / 每组素材数）/ 定向方式 / 预算分配 / 理由
## 5. 出价建议
- 出价方式 / 初始出价区间 / 调价节奏 / 理由
## 6. 素材建议
- 素材池储备（50 条：默认 10 视频 + 40 图文，用户经验适配）/ 形式 / 卖点矩阵 / 钩子 / 池轮换节奏
## 7. 用户确认
- 基建策略确认：✓ / 调整记录：…
## 8. 给优化包的提示
- 起量阶段重点关注（冷启动进度 / 出量广告 / 素材池轮换）/ 每天 5 时间点盯盘（9:00/12:00/14:00/16:00/18:00）

```

> 这份纪要就是优化包 `ai-analysis-expert-02` 在「新项目输入」分支下的标准入口。

## 九、Pitfalls（基建策略专项）

1. **别让用户开太多账户**：纯新项目预算有限，账户多了每个都跑不出模型，不如集中。
2. **出价别顶满考核成本**：冷启动出价 = 考核 × 50%-70%，顶满容易烧爆；别低于 50%，跑不出量。
3. **定向别卡太死**：纯新项目首选系统智能定向，让模型先学；手动定向太窄会推高 CPM 跑不出量。
4. **素材别只做 1 个**：单素材赌运气，无法归因；首批至少 3-5 个覆盖多卖点。
5. **计划数匹配预算**：计划多预算少 = 每条都学不动；按日预算量级查表，别拍脑袋。
6. **给具体数字**：纯新项目用户是普通人，"出价 80-120 元"远比"出价按考核成本一定比例"可执行。
7. **每个建议都要说"为什么"**：普通人不理解行业逻辑，每个数字建议都配一句白话理由。
