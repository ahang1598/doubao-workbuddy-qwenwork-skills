## 一、投前必备：底层机制 & 建广告前的判断

### 1.1 eCPM = 决定拿量的唯一货币（手册 1.3）
```
eCPM = 出价 × 预估点击率(pCTR) × 预估转化率(pCVR) × 1000
```
- **推论**：相同出价下，CTR/CVR 越高越容易跑出；把素材做好 = 变相加价。
- 建广告时向用户强调：定向不是越窄越好，**过窄会把自己关在竞价门外**（三个定向条件叠加可能筛掉 90% 用户，手册 1.5）。

### 1.2 新账户天生劣势的根因（手册 1.5 / 1.7）
- 粗排只认**历史** CTR/eCPM，新账户/新素材没历史 = 保守预估 = 没量。
- 解法**不是提价，是熬过冷启动**。这是"同素材老账户有量、新账户没量"的根本原因。
- **账户信任分**（手册 1.7）：历史转化多/消耗稳/素材常更新/无违规 = 加分；成本忽高忽低/频繁暂停改动/素材长期不换 = 扣分。→ 投前提醒用户别频繁操作。

### 1.3 账户被限量的常见原因（手册 1.8）—— 投前复核清单来源
1. 定向过窄，候选池不足
2. 预算/余额不足触发流控
3. 频次控制触发（同一用户重复曝光过多）
4. 负向反馈累积（不感兴趣、举报）
5. 创意同质化被判重复投放
6. 素材搬运被识别（打搬运标签基本限跑）
7. 账户权重低（新户或有违规史）

### 1.4 四个可控旋钮（手册 1.9）
| 你能控 | 系统黑箱 |
| :-- | :-- |
| **定向**：圈谁看 / **出价**：一次转化报价 / **预算**：弹药与节奏 / **素材+落地页**：钩子强弱 | 竞价排序、出价翻译、流量分配、冷启动学多久 |
> 核心原则：别跟系统抢方向盘，把 4 个旋钮拧到最好，剩下信任并喂养黑箱。

## 二、账户搭建与冷启动（投前建广告核心，手册第三部分）

### 2.1 投放前必须确认的四件事（手册 3.1）
产品/受众定位、考核口径与出价上限、转化回传链路是否通、落地页/承接是否就绪。

### 2.2 预算设置量化标准（手册 3.2）
- **日预算下限 = 目标转化成本 × 20**（自动化产品如 UBMax ×50）。低于此模型学不动。
- 单素材测试预算：常规渠道 ×15，千川 ×50。

### 2.3 冷启动机制（手册 3.3 / 腾讯 3.0 见 8.3）
- 系统在"面试"你的计划，学习期转化门槛（手册 8.1）：**巨量 20 / 腾讯 30 / 百度 30 / Meta 50** 个转化。
- 腾讯 3.0：**新广告/新创意观察 5-7 天，前 48-72 小时消耗趋势是关键信号**。
- 帮助过冷启动：给足预算、别频繁改、宽定向+优质素材、用一键起量辅助。
- 学习期成功信号：消耗稳定上升、成本收敛到目标附近、转化持续、无大幅波动、系统标"学习成功"。

### 2.4 起量四步法（手册 3.8）
选素材（用起量概率做减法）→ 测出价看数据 → 拔价拉消耗层级 → 稳消耗降成本。

## 三、出价与预算调整（投中核心，手册第四部分）

### 3.1 出价 ≠ 转化成本（手册 4.3）
出价是"愿意为一次转化报的价"，实际成本由 GSP 竞价 + 模型预估决定。别把出价当成本调。

### 3.2 调价纪律（手册 4.4 + 腾讯 3.0 单日单次原则 8.3）
- **单次调价幅度 ≤ 10%**（降价尤其别一次 >30%，触发系统惩罚）。
- **单账户每天调整（出价/预算）不超过 1 次**（腾讯 3.0）。
- 调价后观察 ≥ 4 小时再续动作；冷启动期别频繁调。

### 3.3 ⭐ 腾讯 3.0「出价调整四象限」黄金法则（手册 8.3）—— 投中调优主表
| 场景 | 操作建议 |
| :-- | :-- |
| 成本 < 出价 **且** 消耗快 | **阶梯降价** 5-10%，每日观察，别一次降到成本线以下 |
| 成本 < 出价 **且** 消耗下降 | **提价 + 追量**，可用一键起量提竞争力，避免被打压 |
| 成本 > 出价 **且** 消耗慢 | **阶梯提价 5-10% + 检查**素材/定向/落地页 |
| 成本 > 出价 **且** 消耗快（超 20% 以内）| **以观察为主**，系统可能在优化，拉长窗口常回落 |
| 成本 > 出价 **且** 消耗快（超 20% 以上）| **谨慎关停**，把预算释放给优质计划 |

### 3.4 ⭐ 止损时间表（手册 3.5）—— 投中"该不该停"量化标准
**前 5 个转化成本判断法**（模型学习最小有效样本）：
| 前 5 转化成本 | 判断 | 动作 |
| :-- | :-- | :-- |
| ≤ 2× 出价 | 继续投放 | 系统还在探索，保持预算耐心观察 |
| 2-3× 出价 | 拉长观察 | 再跑 500-1000 元看能否拉低；不行调素材/定向 |
| > 3× 出价 | 立即止损 | 方向错了，关停复盘重建 |

**黄金止损节点**：
- 消耗 = 出价×1.3~1.5 → 第一观察窗口，查是否有转化
- 消耗 = 出价×5~20 仍无转化 → 建议暂停
- **成本 = 出价×2 → 绝对红线，立即关停**

**新老计划区分**：新计划容忍 1.5-2 倍超成本；**老计划（跑了 7 天+）超 2 倍直接关**。
⚠️ 不可反复开启关停（破坏模型），可复制广告重新拿量。止损优先"改起投日为次日"而非硬暂停。

### 3.5 放量：阶梯节奏（手册 4.8）
| 步骤 | 动作 | 观察 |
| :-- | :-- | :-- |
| 第 1 次 | 日预算 +20% | 观察 3 天 |
| 第 2 次（ROI 稳）| +30% | 观察 3 天 |
| 持续稳定 | +50% | 直到触天花板 |
- **天花板信号**：CTR↓、CVR↓、成本涨超 30% → 别硬推，启动新素材测试。
- **放量失败 80% 是承接端没跟上**（落地页/客服/库存），不是投放问题。

### 3.6 一键起量正确用法（手册 4.9）
- 预算设 **15-20 个转化成本**；开启后 6 小时内花完；无赔付；不与智能调控同用。
- 适用：新计划破冰冷启动 / 大促竞争激烈 / 老计划衰退再搏。

## 四、实时监控 SOP（投中盯盘节奏，手册 4.10）

**核心原则：勤观察 + 慢调整 + 准判断。**
| 时间段 | 频率 | 动作 |
| :-- | :-- | :-- |
| 新计划上线前 4 小时 | 每 30 分钟 | 只看消耗/曝光，**不要调整**，让模型探索 |
| 上线 4-24 小时 | 每 2 小时 | 关注前 5 个转化成本 |
| 24-48 小时 | 每半天 | 判断是否学习期成功 |
| 稳定期 | 每天 | 只监控趋势，不手痒 |
> 素材维度：新素材每 2 小时看，成熟素材每天看。

## 五、超成本 3D 诊断模型（手册 4.6）—— 投中定位问题
先看**时间轴**（生命周期阶段，冷启动期别急着动）→ 再看**颗粒度**（大盘崩还是单点失效）→ 最后看**归因漏斗**（曝光→点击→转化哪一段断）。
配合三因子拆解：**CPA = CPM /(CTR×CVR×1000)**（CTR/CVR 取小数）。
- CTR 低 → 查素材/版位；CVR 低 → 查人群/落地页；CPM 高 → 查版位竞争/人群过窄。

## 六、素材与创意（手册第五部分）
- **素材总数 : 创意总数 = 1 : 2~4**。
- **素材衰退三级**：预警 −10~15% / 处理 −20% / 淘汰 −30%；最近 7 天数据权重是 30 天前的 3-4 倍。
- 上新节奏：每 3-5 天补 1-2 条测试素材，维持新鲜度评分。
- 前 3 秒不是用来美的，是用来**筛人**的。

## 七、腾讯广告 3.0 关键变化（手册 8.3）—— 投前建广告须知
1. **资产筑基是起跑线**：产品信息库填全（转化归因链路 + 品牌形象组件新版 512×512 + 落地页）。
2. **素材指纹 + 组件化**：一条 3.0 广告 = 推广产品/考核目标 + 出价测试方案 + 差异化创意素材。
3. **宽定向 + 全版位通投**：3.0 从"用广告找人"转向"用产品找人"。
4. **出价精简为两种**；日常靠"出价调整四象限"运营。
5. **数据 API 回传是核心燃料**：后端真实转化及时准确回传，模型才越跑越准。

## 附：核心公式速查（手册附录）
- eCPM = 出价 × pCTR × pCVR × 1000
- CPA = CPM /(CTR×CVR×1000)
- 日预算下限 = 目标转化成本 × 20（自动化 ×50）
- 冷启动初始出价 = 考核成本 × 50%-70%
- 一键起量预算 = 15-20 个转化成本
- 绝对止损红线 = 成本达出价 2 倍
