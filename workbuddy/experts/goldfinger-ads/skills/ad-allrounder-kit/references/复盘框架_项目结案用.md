# 投放复盘框架（项目已完成 / 阶段性结案时用）

> 用途：当一个投放项目**已经结束**（活动跑完、预算花完、产品下架、或用户明确说"这波投完了/想总结一下"），不再是"边投边改"，而是"回头看这一仗打得怎么样、下次怎么更好"。
>
> 与「诊断」的区别：诊断是**治病**（还在投，哪出问题就改哪），复盘是**复盘一场已经打完的仗**（算总账 + 提炼经验 + 给下次的行动清单）。
>
> 本框架给「投得懂」小白顾问使用，所有话术都要**翻译成大白话**输出，不要把下面的字段名直接甩给用户。

---

## 一、复盘前要凑齐的账（先问用户，缺什么补什么）

复盘是"算总账"，没有数据算不了。用大白话问用户拿到这几样（能拿几样是几样，缺的就说明"这块看不了"）：

| 要素 | 大白话怎么问 | 为什么要 |
|---|---|---|
| 花了多少钱 | "这一波总共花了多少广告费？" | 分母，算单价用 |
| 换来多少结果 | "带来了多少个订单 / 多少条留资 / 多少个加粉？" | 分子，算划不划算用 |
| 卖了多少钱（有的话） | "这些订单大概成交了多少金额？" | 算 ROI / 回本用 |
| 投了多久 | "从哪天投到哪天，一共几天？" | 算节奏、看衰退用 |
| 目标是什么 | "当初投这波，主要想要啥？（涨粉/卖货/收集客户线索/打知名度）" | 判断到底达没达标 |
| 中间动过啥 | "中间你换过素材 / 改过预算出价吗？大概啥时候动的？" | 找到哪一下起了作用 |

> 如果用户连"花了多少、换来多少"都答不上来，就先友好地让他去后台导一份**投放时间段内的整体报表**（消耗、转化数、转化成本这几列），再回来复盘。

---

## 二、复盘四步（内部逻辑，输出时翻译成人话）

### 第 1 步：算总账——这波到底划不划算

先把三笔账算清楚（用用户给的数，能算哪笔算哪笔）：

1. **一个结果花了多少钱** = 总花费 ÷ 结果数（订单/留资/加粉）
   - 大白话："你这波平均花 ¥X 换来一个 __。"
2. **划不划算**（有成交金额时）= 成交总额 ÷ 广告花费
   - 大于 1 = 广告费赚回来了还有的赚；等于 1 = 打平；小于 1 = 暂时还没回本（广告费还没完全赚回来）。
   - 大白话："你花 1 块广告费，换回来 X 块生意。"
3. **达没达当初的目标**：把结果对照用户一开始说的目标，直接下判断"达标 / 差一点 / 没达到"。

> 铁律：**不要拿"行业平均是多少"来评判好坏**。好不好，看他自己当初的目标、以及这波前后期的自身对比。

### 第 2 步：找亮点——这波哪里做对了，下次接着用

从这几个角度找"做得好的地方"，至少找出 1~2 个，讲清楚"为什么这是对的"：
- **哪条素材/哪个创意最能打**（花钱最多还便宜、或转化最多）→ 下次围绕它多做几条同类的。
- **哪个平台/版位最划算**（同样的钱，这里换来的结果最多）→ 下次预算往这倾斜。
- **哪个时间段/人群转化最好** → 下次重点投这个。
- **哪次调整之后变好了** → 记下来，这是有效动作。

### 第 3 步：找可优化点——这波哪里还能更好，下次怎么调

从这几个角度找"还能更好的地方"，讲清楚"当时为什么会这样、下次怎么做更好"（用中性、建设性的说法，别用"亏/花冤了/烧钱"责备用户）：
- **有些预算效率偏低**：哪条素材/哪个计划花了不少钱、换来的结果偏少 → 下次早点关掉，把这部分预算省下来给更能打的。
- **调整的频率/时机可以更稳**：是不是刚投没两天就一直动，让系统重新摸索了。
- **落地页/承接可以再顺一点**：是不是点的人不少，但到了页面转化不高 → 下次先把页面和客服/话术准备好再投。
- **目标可以更对齐**：想要订单就按"下单"去优化，别只盯着"多少人点"。
- **样本够了再下结论**：别没跑够量就急着判断"这素材不行"。

### 第 4 步：提炼可复用的经验（这是复盘最值钱的部分）

把这波的经验沉淀成"下次能直接用的规律"，比如：
- "我这类产品，__ 这种开头的视频最抓人。"
- "我的客户主要在 __ 平台、__ 时间段活跃。"
- "预算低于 __ 就跑不动，得给够。"
- "一条素材大概 __ 天就看腻了，得提前备新的。"

## 三、复盘输出长什么样（固定四段，全程大白话）

**① 这波的总账**：用两三句话把"花了多少、换来多少、一个结果多少钱、划不划算、达没达标"讲清楚。可以用一句话总结定调，比如"整体是赚的，后半程还有一部分预算的效率可以再提一提"。

**② 做对了什么（亮点）**：列 1~3 条，每条说清"做对的地方 + 为什么对 + 下次怎么接着用"。

**③ 还能更好的地方（可优化点）**：列 1~3 条，每条说清"可以更好的地方 + 为什么会这样 + 下次怎么做更好"。用中性、建设性的说法，别用"亏/花冤了/烧钱"，别只说问题，一定带"下次怎么办"。

**④ 【下次这样投】**：编号行动清单，把上面的亮点和教训变成 3~5 条下次可以直接照做的动作。结尾固定一句："这波先总结到这，你下次开投前可以照着这几条来，投起来了有问题再来找我看。"

> 复盘不给"马上改"的动作（因为项目已经结束了），而是给"下一波怎么做更好"的经验和清单。这是复盘和诊断最大的区别。

---

## 四、复盘时的底线（和诊断一致，用人话）

- **不打包票**：复盘是总结过去、给下次的建议，不能保证下次一定更好。
- **不给行业标准值**：好不好只跟他自己的目标和前后对比。
- **数据缺就说清楚**：用户给不出的数据，就直说"这块没数据，看不了"，不要瞎编或估算一个数糊弄。
- **敏感行业照样提醒合规**：医疗/金融/教育/美妆/保健品等，复盘里如果发现用了违禁词或打了擦边球，要提醒下次注意《广告法》和平台规则。
