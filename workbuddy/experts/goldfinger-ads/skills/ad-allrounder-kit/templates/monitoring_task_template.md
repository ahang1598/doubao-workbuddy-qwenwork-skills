# 每日「巡检 + 实时调优」自动化任务模板（投前 Step 4 用 · 首次新增项目/账户后必落）

> 把"每天盯什么、几点盯、破什么线怎么调"固化成一条**每日定时自动化任务**。
> **核心纪律：这条任务首次新增项目/账户后就帮用户建好，但创建时默认 `status=PAUSED`（不开启），需用户自己手动开启后才会跑。绝不擅自开启。**
> 先用大白话跟用户确认下表每一项，用户确认后再创建（PAUSED）并告知开启方式。

## 一、巡检+调优方案确认表（跟用户逐项对齐）

| 项 | 默认基线 | 用户确认/调整 |
| :-- | :-- | :-- |
| 项目/账户 | {项目名} / {账户ID列表} | |
| 是否首次新增该项目/账户 | 是（首次→必落这条自动化）| |
| 考核指标 | {真实字段，如"表单预约数"} | |
| 考核成本 + 红线 | {考核成本}，红线 = {上限，可按人群分档} | |
| 巡检时间点 | 每天 5 点：9:00 / 12:00 / 14:00 / 16:00 / 18:00 | |
| 巡检频率（冷启动期）| 上线前4小时每30分钟只看不动；4-24h 每2小时；24-48h 每半天 | |
| 任务初始状态 | **PAUSED（默认不开启，需用户手动开启）** | |

## 二、巡检指标清单（每个时间点看这些）

1. **出量情况**：各广告是否出量、出量广告占比、冷启动进度（累计消耗/转化数）。
2. **消耗分布与成本**：各广告消耗占比、实时成本 vs 考核成本。
3. **素材跑速/衰退**：单素材 CTR/转化随时间曲线，是否进衰退期（>14-21天或3日连降）。
4. **是否破考核红线**：实时成本是否破线（单日仅预警，7天主口径定生死）。

## 三、预警触发规则（if-then，跟用户确认阈值）

| 触发条件 | 建议动作（默认只出建议，不自动改账户）|
| :-- | :-- |
| 某广告成本 > 出价 × 2（老计划跑7天+）| 🔴 报警：建议关停（改起投日为次日，保模型）|
| 某广告消耗达出价 5-20 倍仍零转化 | 🔴 报警：建议暂停 |
| 前 5 个转化成本 > 出价 × 3 | 🔴 报警：方向可能错，建议止损复盘 |
| 某广告 3 天没量（冷启动）| 🟡 报警：建议阶梯提价 5-10%，观察4小时 |
| 成本 < 出价且消耗快 | 🟢 提示：可阶梯降价 5-10% |
| 成本 < 出价且消耗下降 | 🟢 提示：可提价+追量/一键起量 |
| CTR↓ + CVR↓ + 成本涨>30% | 🟡 提示：触天花板，启动新素材测试 |

## 四、创建定时自动化任务（用户确认后 · 创建即 PAUSED）

- **调度**：默认每天 09:00 首次汇总（或按 5 时间点分次），`scheduleType=recurring`，rrule 如 `FREQ=DAILY`（可按确认时间点细化）。
- **任务名**：建议 `投投·{项目名}每日巡检调优`，方便用户在后台一眼找到。
- **⭐ 初始状态**：**必须 `status=PAUSED`**——创建即暂停、不自动跑，等用户手动开启。
- **prompt 描述**（写进 automation，自包含）：
  > "每日对项目 {项目名}（账户 {账户ID}）跑巡检+实时调优：拉分广告实时数据，检查各广告出量/消耗/成本/素材跑速/是否破考核红线 {红线}，用 ad_analyzer 打分级，按腾讯3.0出价四象限法则 + 止损时间表产出分广告调整建议清单，破红线项标🔴，待我确认。默认只出清单，不自动改账户。"
- **双重安全**：① 任务 PAUSED 不自动跑；② 即使开启后也只产出待确认清单，不无人值守改账户。

## 五、告知用户如何手动开启（必须说清）

- 一句话交付：**"这条每日巡检调优任务我已经帮你建好了，但默认是关着的，你确认没问题后自己开启就行。"**
- 开启入口指引：在自动化 / 定时任务管理列表里，找到名为「投投·{项目名}每日巡检调优」的任务，把状态从 **已暂停 → 开启/启用**。
- 补充：开启后每天按点自动跑，只给你待确认的分广告调整清单；不想跑了随时可以再暂停或删除。

## 六、升级提示

- 跑满 3-7 天 / 累计消耗 ≥ 预算×5 后，这条巡检任务可升级为"诊断+优化"模式（拉全漏斗做归因）。
