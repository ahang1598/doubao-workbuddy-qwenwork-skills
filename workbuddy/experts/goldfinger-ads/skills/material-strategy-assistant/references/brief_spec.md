# 素材策略结构规范（创意提需）

> 用途：根据广告主投放目标 → 生成一份**素材策略**，最终交付为 **PDF（策略解读 + 执行手册合一）**。  
> 本质：**素材策略 = 创意提需**。它回答三个问题：**呈现什么、做哪些形态、做多少个**，并逐条落成可施工的执行手册。  
> 上游：提需助手；媒介经理/投手
>
> 下游：文案助手（逐条 1:1 生成文案）；生图助手（**已启用**，提示词按类型模板逐条写实）。  
> 版本：v3.2｜ 平台：腾讯广告系 ｜ 案例：手工香薰蜡烛店主小林
>
> **v3.2 变更**：① 补齐 13 类**典型提示词模板**，生图提示词由"暂缓/建设中"改为**逐条写实、可出图**；② 每类补上**标准样式示例图**（🆕 已外置平台案例库，`fetch_case_samples.js` 运行时拉取、本地兜底），选型与交付时内嵌展示；③ 下一步建议模型推荐更新为 GPT Image 2 > Nano Banana Pro（质量）｜混元（效率）。
> v3.1 变更：① **取消单列"模块A关键洞察"**，核心主张并入"洞察"，避免与人群/卖点重合；② **模块B创意类型 + 模块C数量测算 融合为「内容策略与素材组合」**；③ 尺寸**按创意类型分横/竖/方**，整体兜底约 **4:4:2**（见 2.6）；④ 执行手册逐条表统一 **5 列**（#/创意类型/尺寸/文案/生成提示词）。

## 0. 定位

**它是素材策略——创意提需内容**，服务对象是"制作方（AI/设计师）"，核心价值是把广告主的投放目标，翻译成一份**可直接开工的创意需求单**，并最终以 PDF（策略解读+执行手册）交付。

一份素材策略的构成（v3.2 · 🚨 融合成一块「素材策略」，模块简短）：

| 部分 | 回答的问题 | 这一块要产出什么（极简，不大段文字） |
| ---- | ---- | ---- |
| **一句话目标** | 推什么/给谁/撬动什么动作 | 一句话 |
| **目标 · 人群 · 产品分析** | 目标、人群、卖点 | 三行式：推广目标 / 目标人群 / 主打卖点，各一行 |
| **创意思路和规划**（🚨 唯一策略板块，"做多少·要不要视频"并入此处） | 主张、做多少、做哪几类、怎么打动人 | 一条核心主张（加粗+理由，🚨 只此一处）+ 一句话总量与视频（预算→总张数、做不做视频）+ 建议做哪几类（每类卡片：官方类型名 + **一行小参数条 优先级·数量·尺寸** + 一句大白话「怎么给用户传信息」+ 一张标准样式示例图（`fetch_case_samples.js` 平台落地后内嵌））🚨 参数标在卡片上，**不单开"做多少素材"板块或配置表** |
| **素材执行手册** | 每条素材具体怎么做 | 🚨 开头不复述背景、不重复样式图，一句过渡直接进表 + 逐条 5 列表（#/创意类型/尺寸/文案/生成提示词）+（文末）文案按钮汇总 |

> 🚨 **两条红线**：① 给用户的任何文字**不出现内部黑话**（海报类/原生类/平台样式类/业务元素类、"沟通策略/内容套路"术语），一律翻译成「怎么给用户传信息」的大白话；② **创意类型只用官方 13 类原名**，禁止自创/改名。
> 🚨 **核心主张**（原关键洞察）作为一条贯穿全局的加粗主张 + 理由，放进「创意思路和规划」，不单列成章。

## 1. 核心主张（并入"目标用户与产品洞察"，🚨 不单列为模块A）

**逻辑**：结合 `产品卖点 × 目标人群 × 投放目标` → 提炼一条**贯穿全局的核心主张**（广告内容应重点呈现的那条信息），并入洞察段落，**不再单独成章**（否则与人群/卖点重合）。

**核心主张包含以下内容（在洞察里以"一条加粗主张 + 判断理由"呈现）：**

| 内容项            | 说明             | 小林案例                                             |
| -------------- | -------------- | ------------------------------------------------ |
| 核心卖点           | 从卖点中选定的主打点（单一） | 助眠                                               |
| 目标人群           | 谁              | 睡眠困扰的都市女性 25-40                                  |
| 营销目标           | 想撬动的动作         | 购买                                               |
| **要重点呈现的核心信息** | 广告里最该突出的那一条    | 睡前点一支，让房间和情绪都慢下来                                 |
| 判断理由           | 为什么呈现这条能提升效果   | 该人群痛点是睡前焦虑，购买由"情绪价值"驱动，故重点呈现"助眠仪式感"而非成分参数，最能促发下单 |
| 期望动作           | 用户看完应做什么       | 点击→下单                                            |

**产出要求**："要重点呈现的核心信息"必须单一聚焦（一条），并给出"判断理由"——这是 Brief 的灵魂，制作方据此决定画面与文案的取舍。

### 2.4 小林案例的推荐结果（决策链跑出来的，非随机）

**① 优先版位：微信朋友圈** —— 理由（据本地投放指引判断）：

- 人群最准：25-40 都市女性是朋友圈核心用户，"熟人推荐"场域天然适合情感驱动型消费；
- 场景完美：成交高峰在 20-23 点，正是准备入睡时段，与助眠卖点无缝契合；
- 转化最优：手工蜡烛有客单价，需要品质感与信任背书，朋友圈调性最匹配。

**②③尺寸与创意形式：**

| 优先级 | 创意形式       | 尺寸            | 做法                             | 需要的文案位             | 语气        |
| :-: | ---------- | ------------- | ------------------------------ | ------------------ | --------- |
|  主推 | 常规多图（6/9图） | 1:1 800×800   | 多图讲睡前氛围故事：烛光→卧室→放松→入睡，像安静的图文日记 | 外层文案/图片文案/首条评论/CTA | 温柔治愈、第一人称 |
|  次选 | 竖版大图       | 9:16 720×1280 | 一张高质量氛围场景图（暖调烛光+卧室），全屏沉浸       | 同上                 | 同上        |

**④ 扩量路径**：朋友圈跑稳后，用同一套 **9:16 竖版素材**接入腾讯新闻信息流做场景化种草扩量；优量汇留到后期低成本拓量。

**创意类型库**：
- **图片（🚨 固定 13 种，不许自行命名）**：常规海报 / 模拟朋友圈 / 小红书笔记 / 仿对话 / 数字人海报 / 公众号资讯 / 榜单素材 / 户外海报 / 备忘录 / 大字报 / 九图拼接 / 四图拼接 / IP海报。各类型画面规范见 `prompt_method.md`、文案规范见 `copywriting_method.md`。
- **视频（4 种）**：情景剧 / 单人口播 / 动图（图片动态化）/ 混剪（旁白+画面剪辑）。**按第3节规则决定是否规划**（无渠道要求时预算 ≥1万 做视频、占比 20%；有渠道要求查内置指引）。

**策略只负责"从上述类型里推荐哪种+为什么"，制作方负责实现。**

### 2.6 各创意类型的尺寸优先级（🚨 权威，按类型定横/竖/方）

尺寸**不再一刀切**，按创意类型的画面特性定优先方向；同一批素材整体的横/竖/方比例**兜底约 4:4:2**。

| 创意类型 | 优先方向 | 推荐尺寸（高清标准值） |
| ---- | ---- | ---- |
| 榜单素材 | **竖** | 9:16 1080×1920 |
| 常规海报 | **横** | 16:9 1920×1080 |
| 公众号资讯 | **横** | 16:9 1920×1080 |
| 数字人海报 | **横** | 16:9 1920×1080 |
| 大字报 | **竖** | 9:16 1080×1920 |
| 动图（视频） | **横** | 16:9 1920×1080 |
| 其他视频（情景剧/单人口播/混剪） | **竖** | 9:16 1080×1920 |
| 方图兜底 | 方 | 1:1 800×800 |

> 规格标准值：竖 9:16 1080×1920 / 方 1:1 800×800 / 横 16:9 1920×1080。
> 未在上表列出的类型，按画面特性判断：信息密、需竖屏沉浸的走竖；横向排版/图文卡片走横；不确定时用方图兜底。整体一批素材的横竖方比例**尽量落在 4:4:2 附近**。

> 🚨 **交付时融合为「创意思路和规划 + 做多少·要不要视频」**：先给核心主张，再说明"针对 XX 渠道 → 适合做 XX 类型 → 怎么给用户传信息"（每类一句大白话 + 一张标准样式示例图，`fetch_case_samples.js` 平台落地后内嵌），最后给融合表，列序固定为：**创意类型 · 优先级 · 尺寸 · 数量 · 怎么给用户传信息**（🚨 不用"素材大类""沟通策略"等内部列名；最后一列填大白话，不填分类名/术语句）。用户对"哪种渠道适配哪些素材类型"没有概念，此处必须做**信息输入**（用大白话说明为什么适配），不能只甩结果。
>
> 🚨🚨 **「沟通策略/内容套路」这一列必须填【具体策略句】，不许填分类名**：图片行填 2.7 表格里对应策略的**「含义」那句话**（如"模仿用户所在平台的原生界面，削弱防备心""以品牌方身份，正面传递信息""仿真实用户自发分享，弱化广告感""直接展示用户最关心的核心内容/利益物"），**不要填"平台样式类/海报类/原生类/业务元素类"这种分类名**；视频行填具体套路句（如"痛点共鸣→解决方案→行动引导"），而非"套路A"。分类名只用于策略讲解时归类，落进融合表和执行手册的那一列一律用具体句。

### 2.7 沟通策略 vs 内容套路（🚨 仅内部选型用，绝不对用户展示）

> 🚨🚨 **本节四类分类名（海报类/原生类/平台样式类/业务元素类）与"沟通策略/内容套路"术语，均为内部信息，只用于你判断该选哪几类创意。给用户看的策略/执行手册里，绝不出现这些词——一律翻译成「怎么给用户传信息」的大白话**（如"做成公众号里的真实推荐图文""像朋友晒店，熟人口吻+评论互动，显得真实"）。融合表里那一列的列名就叫**「怎么给用户传信息」**，填大白话，不填分类名、不填术语句。

**核心区分**：**图片**——怎么把信息快速、可信地递出去（图片简单直接）；**视频**——用什么叙事结构把人带进来。不要把"痛点→方案→行动"当成所有素材的统一流程——那基本是视频的套路之一。

**① 图片 · 四类选型依据（内部用，13 种图片类型各归其位）**

> 🚨 下表仅供你内部选型；「含义」是你判断时的依据，对用户要改写成一句「怎么给用户传信息」的大白话。左侧"XX类"**绝不出现在给用户的任何文字里**。

| 内部分类（不对用户） | 含义（内部判断依据） | 典型图片类型 |
| ---- | ---- | ---- |
| **海报类** | 以品牌方身份，正面传递信息 | 常规海报 · 数字人海报 · IP海报 · 户外海报 · 榜单素材 · 大字报 |
| **原生类** | 仿真实用户自发分享，弱化广告感 | 仿对话 · 备忘录 |
| **平台样式类** | 模仿用户所在平台的原生界面，削弱防备心 | 模拟朋友圈 · 小红书笔记 · 公众号资讯 |
| **业务元素类** | 直接展示用户最关心的核心内容/利益物 | 九图拼接 · 四图拼接（榜单素材也常偏此策略） |

> 选型提示：金融等强合规品类，**原生类（仿素人分享）风险高**（易触"受益人口吻/亲测有效"红线），优先海报类 + 平台样式类。

**② 视频 · 内容套路库（叙事结构，按选题选，非固定流程）**

| 套路 | 结构 | 适合选题 |
| ---- | ---- | ---- |
| **A 痛点式** | 痛点共鸣 → 解决方案 → 行动引导 | 痛点清晰的常规带货，口播/混剪通用 |
| **B 话题式** | 热门话题 → 与用户的相关性 → 行动引导 | 借势时事/热点，拉相关性 |
| **C 冲突式** | 冲突开头（抛误解/争论）→ 解释冲突 → 消弭冲突 → 达成共识 → 行动引导 | 破除误解、建立信任 |

> 套路库可扩展；产出时按每条视频的选题**挑一个套路标注**（如"套路A""套路C"），不要全部套同一条。动图这类复用静态素材的，通常**不套长叙事**。

## 3. 模块 C · 素材与物料数量测算（🚨 公式驱动，唯一权威）

**逻辑**：素材数量、文案条数与"是否做视频"**由公式强驱动**——先算「广告数」，再由广告数推出素材数与文案数。🚨 **以本 skill 为准，不再参考其他 skill 的测算方式。**

### 3.1 数量测算公式（唯一权威）

**必备输入（缺则必须问用户）：总预算、预计投放天数、CPA（预期单次转化成本）。**

**四步公式（按顺序算）：**

1. **日预算** = 总预算 ÷ 预计投放天数
2. **广告数** = 日预算 ÷ (CPA × 20)　（向下取整；至少 1 条）
3. **素材数** = 广告数 × 3　~　广告数 × 5　（区间，取中位落地）
4. **文案数**：**外层文案 = 广告数**；**首条评论 = 广告数**（首评仅朋友圈版位有）

**两条硬约束：**
- 🚨 **首次投放素材储备不低于 30**：公式算出的素材数 < 30 时，**一律按 30 张兜底**。
- 广告数、外层文案、首条评论均不低于 1。

### 3.2 是否做视频（按有无渠道要求分流）

| 情况 | 是否做视频 | 视频数量 |
| ---- | ---- | ---- |
| **无渠道要求、无指定素材类型**，整体预算 **< 10000 元** | ❌ 不做视频 | — |
| **无渠道要求、无指定素材类型**，整体预算 **≥ 10000 元** | ✅ 做视频 | **视频数量 ≈ 素材总数 × 20%**（其余为图片） |
| **有渠道要求 / 指定素材类型**（如点名视频号、指定做某类视频） | 按渠道要求 | **查本 skill 内置指引** `references/tencent-ads-delivery-guide/`（v2.4.0，随 skill 打包）获取该渠道创意形式与视频建议 |

> 🚨 内置指引已随 skill 分发、任何人装了都能直读，**不依赖任何外部临时文件路径**。版位/尺寸/创意形式查 `creative_inspiration_deep.md`；通用方法论（CPA/学习期/放量/素材衰退）查 `references/general/`（先看 `general_index.md`）。

### 3.3 视频素材规划（需要做视频时）

| 视频类型 | 含义 | 何时优先 |
| ---- | ---- | ---- |
| 情景剧 | 有人物、有剧情的短剧 | 场景化种草、情感驱动、有转化钩子 |
| 单人口播 | 单人出镜对镜讲解 | 观点/卖点直给、知识科普、信任背书 |
| 动图 | 图片动态化（静图加动效） | 复用图片素材、低成本补充动态版位 |
| 混剪 | 旁白 + 画面剪辑 | 素材丰富、快节奏信息密集、大盘验证过的结构 |

**规划要素**：要做哪几类、各几条、为什么；条数以 3.2 算出的「视频数量」为准（视频占比 20%）。
🆕 **有视频需求时**，执行手册阶段按 `references/video_script_method.md` 产出「表二 · 完整视频脚本表」；无视频需求时本能力不启用。

### 3.4 数量测算示例

| 场景 | 总预算 | 天数 | CPA | 日预算 | 广告数 | 素材数 | 视频 | 外层文案/首评 |
| ---- | ---- | :-: | :-: | ---- | :-: | ---- | ---- | ---- |
| 低预算试水 | 5000 | 30 | 50 | 167 | <1→1 | 3~5→**兜底30** | 无（<1万） | 各 1 |
| 中等 | 8000 | 20 | 30 | 400 | 400÷600≈0 →1 | 兜底 30 | 无（<1万） | 各 1 |
| 广告数较高 | — | — | — | 日预算大/CPA低使广告数=12 | 12 | 36~60（中位≈48） | 无渠道且≥1万→≈48×20%≈10 条 | 各 12 |
| 有渠道要求 | 6000 | 30 | 40 | 200 | 200÷800≈0→1 | 兜底 30 | 查内置指引定 | 各 1 |

> **文案与素材 1:1**：图片素材有多少条，就逐条配多少条**图片文案**（不复用凑数）。外层文案/首条评论则按公式 = 广告数量产。

## 4. 完整素材策略的构成（三块合一 + PDF 交付）

一份完整素材策略由以下部分组成，最终**组织成 PDF（策略解读 + 执行手册合一）**交付：

| 组成部分        | 内容                                                       |
| ----------- | -------------------------------------------------------- |
| 广告主原始输入（透传） | 产品（名称/行业/卖点）、人群（性别/年龄/标签）、投放目标、**总预算 / 预计投放天数 / CPA**、品牌资产（logo/slogan/主色） |
| 需求分析        | 一句话目标（推什么/给谁/撬动什么动作）                                     |
| 目标用户与产品洞察   | 人群解读 + 卖点匹配                                              |
| 策略概览（方案解读式） | 人群解读 / 卖点匹配 / 版位适配 / 素材形式，四条式，重点加粗                       |
| A 关键洞察      | 见第1节                                                     |
| B创意类型推荐     | 见第2节（图片13类 + 视频4类按门槛）                                    |
| C 素材数量测算    | 见第3节（公式驱动：广告数→素材数→文案数 + 视频规划）                                        |
| 执行手册        | 表一素材制作总表（逐条 1:1 配文案，生图提示词列**按类型模板逐条写实**）+ 表二文案与按钮汇总表 |
| 系统标记        | 行业风险等级、版本号等                                              |

> **PDF 输出规范见 SKILL.md 文末「PDF 输出规范」**：HTML → 无头浏览器打印为 PDF → present_files 交付。

## 5. 上游交互采集清单（怎么从广告主拿到生成 Brief 所需信息）

面向小白，必问项≤6，能推导/给默认的不问。

| #  | 采集项               |  必填 | 用途           | 缺省处理                 |
| -- | ----------------- | :-: | ------------ | -------------------- |
| 1  | 产品/服务名称           |  ✓  | 主体           | —                    |
| 2  | 一级行业              |  ✓  | 风险/默认人群/渠道推荐 | —                    |
| 3  | 一句话卖点             |  ✓  | 关键洞察         | —                    |
| 4  | 投放目标              |  ✓  | 洞察/CTA/渠道    | —                    |
| 5  | 投放渠道              |  △  | 创意类型推荐；有渠道要求时查内置指引定视频 | 按目标推荐默认渠道            |
| 6  | 总预算               |  ✓  | 算日预算→素材/视频量 | —               |
| 7  | 预计投放天数            |  ✓  | 算日预算（总预算÷天数）  | —               |
| 8  | CPA（预期单次转化成本）     |  ✓  | 算广告数（日预算÷(CPA×20)） | 空→按行业经验值兜底并告知是估算 |
| 9  | 更多卖点              |     | 洞察备选         | 空→自动挖掘               |
| 10 | 目标人群              |     | 洞察           | 空→行业默认               |
| 11 | 品牌资产              |     | 透传组装         | 空→行业调性；若提供，必须是干净原始素材 |

> 🚨 第 6/7/8 项（总预算 / 天数 / CPA）是数量公式核心输入，缺一必问。广告数/素材数/文案数全部由这三个值算出，不再用"预算档位/基建计划"估。

### 5.1 品牌资产采集要求（避免用户随手截图）

品牌资产会在后续「妙思」或组装环节用于精确叠加，因此要提前把素材质量说清楚，避免用户直接从网页、聊天记录或海报里截一张模糊图回来。

| 资产             | 建议提供                      | 不建议                |
| -------------- | ------------------------- | ------------------ |
| logo           | 透明底 PNG / SVG / 高清原图，边缘干净 | 从海报、商品页、聊天记录里随手截图  |
| 产品图            | 高清产品实拍/官方图，背景干净，主体完整      | 带水印、压缩严重、截图裁切不完整的图 |
| 主色/品牌色         | 色值（如 #C9A063）或品牌规范截图      | 模糊截图里靠肉眼猜颜色        |
| slogan / 风险提示语 | 可复制文字原文                   | 只给一张糊图让系统识别文字      |

**提示语建议**：

> 如果有 logo 或产品图，请尽量上传原始高清文件；截图只能作为参考，不建议作为最终品牌资产使用，否则可能出现清晰度不够、图片不干净、格式混乱、文字识别错误等问题。

## 6. 校验规则

| 规则         | 说明              |
| ---------- | --------------- |
| A/B/C 三块齐全 | 缺一不成策略      |
| 核心信息单一聚焦   | 只一条，附判断理由       |
| 每个渠道一条创意推荐 | 类型/尺寸/风格/文案需求齐全 |
| 数量符合公式规则   | 按第3节公式：广告数=日预算÷(CPA×20)、素材=广告数×3~5、外层文案=首评=广告数；首投素材≥30 |
| 视频规则正确     | 无渠道要求：预算<1万不做视频、≥1万视频占比20%；有渠道要求：查内置指引定 |
| 文案配齐  | 图片文案与素材 1:1 逐条对应不复用；外层文案/首评 = 广告数 |
| 生图提示词写实    | 每条按 `prompt_method.md` 类型模板逐条写出完整提示词，不留"建设中" |
| 标准样式图内嵌    | 每个推荐类型内嵌示例图（`fetch_case_samples.js` 平台落地，本地兜底） |
| 尺寸合法       | 匹配渠道规格（以官方后台为准） |
| 最终交付 PDF   | 产出 PDF（策略解读+执行手册），present_files 交付 |

## 备注：logo / 风险提示语

Brief 中 logo 与法定风险语仅**透传**，不参与 AI 生成、本轮不做拼接，留待后置「妙思」组装。制作方在文案需求/设计风格里预留其位置即可。
