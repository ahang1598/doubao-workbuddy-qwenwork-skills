# 第六部分　人群定向与承接转化

## 6.1 定向是双刃剑：精准过头就是自己关门

**每多一个定向条件就筛掉一批人**，三个条件叠加可能 90% 用户都不在池子里。

> **定向过窄死于曝光不足，定向过宽死于人群不精准。**

### 定向的漏斗效应（示例）

```
10 亿   全体用户
 2 亿   + 地域：北上广深
3000万  + 年龄 25-35、性别
 50万   + 兴趣/近期行为  → 你的广告只去抢这 50 万人的曝光
```

### 分阶段的定向策略

| 阶段   | 策略                                                                               |
| ---- | -------------------------------------------------------------------------------- |
| 冷启动期 | **优先使用系统推荐定向**；如需自定义，只限制 1-2 个核心维度。人群覆盖至少 3000 万，最好 5000 万；预估日曝光量 > 5000（低于此需调整） |
| 稳定期  | 模型稳了再逐步收窄                                                                        |

**现阶段的现实**：定向作用已没以前那么大，很多人用素材圈人群——但**前提是素材内容真能起到人群筛选作用**。

**新户初期人群包的正确用法**：更多用于**排除低质低效人群**，而非精准圈定。

## 6.2 人群包与 RTA

- **一方数据人群包**：用已转化用户、高价值用户做种子，做 lookalike 相似人群扩展。作用是告诉系统"这些人大概率转化"，**抬升 pCVR 预估、降低不确定性**
- **RTA（Real Time API）**：实时决策接口，由广告主侧实时判断该不该对这个用户出价
- **交并差人群包**：通过人群包的交集、并集、差集运算精细化圈人，可节省预算

**用一方人群加强功能时注意**：新户建议 3 天后再用（太早会限制模型的自主探索）。

## 6.3 承接端：CVR 崩了通常不是投放的问题

### 落地页的四条铁律

1. **第一屏只解决一个问题：值不值得往下看**
2. **转化按钮不是越多越好，而是越明确越好**
3. **每多一个选择，转化率就少一点**
4. **不要让用户"想一下"，要让他"顺手做"**

**落地页加载速度必须 < 2 秒。** 任何卡顿都在损耗已经花钱买来的流量。

### 转化链路的放大效应

> **转化链路中任何一步不顺，都会被广告费放大。**

排查顺序（从后往前）：

| 现象                 | 排查方向               |
| ------------------ | ------------------ |
| CTR 高但到达率低（如 60%）  | 页面加载太慢             |
| 到达率正常但 CVR 低（如 5%） | 落地页说服力差 / 人群不精准    |
| CVR 正常但线索质量差       | 素材承诺过度 / 前端吸引来的人不对 |

### 点击高但转化差的根因

**多半是前端承诺过度**——素材吸引的是谁，决定了后端累不累。

「素材吸引的人群」和「真正转化的人群」不一致，是最常见的隐性问题。

### 线索质量差的排查顺序

> **先查话术，再查素材，最后查平台。**

⚠️ **承接人员的情绪会直接影响广告 ROI**——这是常被忽略的变量。

**转化话术不是销售编的，是数据筛出来的。**

## 6.4 数据回传：模型的教材

**回传是模型的「教材」，教材错了模型必然学歪。**

### 三类常见回传问题

| 问题 | 表现        |
| -- | --------- |
| 漏报 | 埋点缺失、网络丢包 |
| 延迟 | 付费几天后才回传  |
| 错报 | 把点击下载当激活  |

⚠️ **数据回传断一天，模型可能废一周。**

### 回传的第一原则：明确唯一核心目标

**最常见的错误是「什么都要」**——把回传事件一股脑全塞进去，算法会向**最低门槛的目标**收敛。

**正确做法：只回传与核心目标直接相关的转化信号。**

### 进阶：按价值权重回传

IAP 产品不要只回传「是否付费」——算法分不清 1 元和 100 元，会优先收割低价值用户。

**应该回传「付费多少」，按金额权重学习**；并用 LTV 最高的 Top 10% 用户做种子，做价值权重 lookalike。

### 回传口径可以作为调控手段

冷启期若因转化太少导致空耗跑死，可放宽回传口径（如回传 7 天内转化、回传部分大盘数据）人为拉高 CVR。  
⚠️ 前提：**回传的人群画像必须与转化目标一致**，否则污染模型。

## 6.5 用户洞察：怎么找到真实痛点

### 三种信息来源

| 来源     | 具体做法                                |
| ------ | ----------------------------------- |
| 已购用户提取 | 巨量广告 → 竞价数据 → 受众分析；腾讯广告 → 如翼 → 人群洞察 |
| 跨部门沟通  | 找销售、客服拿一线反馈                         |
| 行业报告   | 看行业白皮书、趋势报告（消费习惯：购买品类/频次、预算分配、偏好）   |

**评论区是免费的用户调研。** 素材跑不动时，先看评论区，再看后台。

**能被骂的素材，往往比没人看的素材更有价值。**
