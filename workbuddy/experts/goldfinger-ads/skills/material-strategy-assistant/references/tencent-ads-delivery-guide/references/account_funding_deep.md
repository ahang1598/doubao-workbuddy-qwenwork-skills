# 腾讯广告「开户」操作指引与概念解释

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20

---

## 一、开户是什么

开户即在腾讯广告（腾讯营销）平台注册广告主账户、完成主体资质认证并获得投放权限的过程。开户时选定的**行业与资质**决定了后续可投放的业务范围，是投放的第一道门槛。

---

## 二、开户方式与渠道（3 种）

| 渠道 | 说明 | 适用客户 |
|------|------|---------|
| **自助开户** | 通过腾讯营销官网自己提交资料完成开户 | 绝大多数企业，资质标准、流程熟悉的客户 |
| **联系直客团队** | 已绑定腾讯直客服务的企业，由直客团队协助开户 | 已签约直客的大客户 |
| **认证代理商开户** | 联系腾讯认证服务商协助办理 | 资质复杂（如工程/医疗）、需多账户管理、缺乏运营团队的客户 |

**关键规则**：
- 自助户与代理商户**相互独立，不能互相转换**
- 一个微信号默认只能绑定一个主体下的一个账户；已开代理商户的客户想开自助户，需用**全新未注册过腾讯营销的微信号**
- 代理商开户优势：适用行业更广（可协助处理特殊资质）、专业支持、账户管理服务、解决复杂资质难题

---

## 三、开户前资质材料准备

### 1. 通用主体资质（按主体类型选其一，必须项）

| 主体类型 | 需提供 |
|---------|--------|
| 企业 | 营业执照（或组织机构代码证）+ 法人身份证正反面 |
| 个体工商户 | 个体工商户营业执照 + 经营者身份证 |
| 民办非企/社会团体 | 民办非企业单位登记证书 / 社会团体法人登记证 + 负责人身份证 |
| 政府/事业单位 | 事业单位法人证书 / 统一社会信用代码证书 + 负责人身份证 |
| 个人（仅限特定行业） | 身份证正反面照片 |

### 2. 通用准入前提（所有行业适用）

1. **主体资质**：企业需《营业执照》、个体工商户需个体户执照、其他主体对应登记证书，且**经营范围须覆盖**所报主营业务
2. **资质主体一致性**：资质材料主体须与账户主体一致；关联企业关系可提供关联证明（全国企业信用信息公示系统股东截图等）；业务合作关系可提供合作协议、授权书、供货协议
3. 多数行业**不支持个人开户**，下文逐行业单独标注

### 3. 逐行业正面资质清单（准入所需的证明文件）

#### （1）金融类

**贷款 / 小额贷款 / 消费金融**

| 细分 | 行业资质（必填） |
|------|------------------|
| 消费金融 | 《金融许可证》 |
| 贷款业务 | 《金融许可证》/《小额贷款机构经营许可证》/《小额贷款公司经营许可证》/省级及以上金融办批文（四选一）+ **广告主承诺函** |
| 汽车金融 | 《金融许可证》或融资租赁企业批复文件 |
| 助贷平台 | 上述"四选一" + 承诺函 + **与所有合作放贷机构的合作协议** |

- 主体要求：企业；经营范围须含"金融/投资/借贷"相关；不支持境外主体、不支持个人开户

**保险**

| 细分 | 行业资质 |
|------|---------|
| 保险公司 | 《保险许可证》/《保险机构法人许可证》/《经营保险业务许可证》/《经营保险公估业务许可证》/《保险营销服务许可证》（任一） |
| 保险经纪/代理 | 对应《经营保险经纪业务许可证》/《经营保险代理业务许可证》/《保险兼业代理业务许可证》等 |

- 主体要求：企业；经营范围须含"保险"；不支持境外主体、不支持个人开户
- 禁投：车辆统筹险、代理退保、非法销售境外保险产品

**银行 / 信用卡**

| 细分 | 行业资质 |
|------|---------|
| 银行 | 《金融许可证》（15 家主流银行仅需此证） |
| 银行理财子公司 | 《金融许可证》+ 银保监会关于理财子公司开业的核准文件 |
| 信用卡中心 | 《金融许可证》+ 金融监管总局关于开办信用卡业务的批复 |

- 主体要求：企业；不支持境外主体、不支持个人开户；主体名称含"村镇"的银行一律拒绝（头部"兴县汇泽村镇银行"除外）

**证券**：《经营证券期货业务许可证》（企业主体，不支持个人）

#### （2）电商（综合电商平台 / 实物电商）

| 情形 | 资质 |
|------|------|
| 行业资质 | 无 |
| 第三方商家入驻 | 《增值电信业务经营许可证》（B21 经营类电子商务） |
| 自营销售（无第三方） | 《增值电信业务经营许可证》（B21）或 应用宝/苹果商店 APP 截图 |
| 经营特殊商品 | 另按商品提交对应资质（如药品经营许可证、食品经营许可证等） |

- 不支持个人开户

#### （3）游戏（手游 / 页游 / 端游 / 小游戏）

| 品类 | 行业资质 |
|------|---------|
| 各类游戏（角色扮演/休闲/益智/MOBA/养成/卡牌等） | ①《网络游戏出版物号（ISBN）核发单》②《计算机软件著作权登记证书》或应用宝/苹果商店 APP 应用截图 |
| 游戏综合服务平台 | 《增值电信业务经营许可证》（B25 互联网信息服务业务）；涉及游戏出版另需《网络出版服务许可证》 |

- **支持个人开户**：是（仅限个体工商户/自然人类型）
- 版号（ISBN 核发单）是游戏准入核心门槛

#### （4）房地产（新房 / 二手房 / 租房）

| 主体类型 | 行业资质 | 业务范围资质（按业务补充） |
|---------|---------|--------------------------|
| 房地产开发商 | 无 | 企业品牌广告：《房地产开发资质等级证书》；新盘销售：《商品房预售许可证》或《商品房现售备案证明》；二手房：房屋产权证明；产业园/商业地产出租：《不动产登记证》或房屋产权证明 |
| 房地产中介服务 | 《房地产中介机构备案证明》/《房地产经纪机构备案证书》/住房租赁交易服务平台备案（任一） | 新盘/二手房/出租另需对应预售证、产权证明、销售/出租委托书等 |

- 不支持个人开户；主体名称含"地产/房地产/房产/置业"时仅能进房地产、旅游出行、零售百货三个一级行业
- 禁投：小产权房、自建房、顶账房、土地交易、以房养老、房产投资移民等

#### （5）招聘（招聘平台 / 人力资源服务）

- 行业归属：一级行业「商务服务」→ 二级「人力资源服务」
- 主体资质：企业营业执照，经营范围含人力资源服务相关；支持子客账户；不支持境外主体、不支持个人开户
- 特殊主体要求：涉及"兼职"业务需**注册资金 ≥500 万、公司年限 ≥1 年**
- 行业资质（必填）：《人力资源服务许可证》
- 附加资质（选填）：人力资源服务平台 →《增值电信业务经营许可证》；劳务派遣 →《劳务派遣经营许可证》
- 禁投：招聘外籍人员、刷单/代练/资金转账等高风险兼职、打字员/手工加工欺诈招聘、"产品试用员/寄拍模特"、公关服务人员

#### （6）旅游（OTA / 旅行社 / 机票酒店）

| 细分 | 主体 | 行业资质 |
|------|------|---------|
| 旅行社 | 企业/个体工商户 | 《旅行社业务经营许可证》 |
| OTA 平台 | 企业 | 《增值电信业务经营许可证》（B25） |
| 酒店住宿 | 企业 | 《特种行业许可证》 |
| 客运交通（机票/包车等） | 企业 | 《铁路运输许可证》/《道路运输经营许可证》/《国内水路运输经营许可证》（按方式） |

- 特殊准入：境外包车游（含司机）需经营范围含"出境旅游业务"；境外租车（自驾）需经营范围含"境内租车"+ 与境外租车机构合作协议
- 均不支持个人开户；禁投：海外私人导游、美女伴游/女仆陪玩

#### （7）餐饮食品

| 细分 | 行业资质 |
|------|---------|
| 餐饮服务提供者 | 营业执照 + 《食品经营许可证》（按载明主体业态/经营项目经营，不得超范围） |
| 食品饮料销售（乳制品/零食等） | 《食品生产许可证》或《食品经营许可证》或"仅销售预包装食品"备案 |
| 进口食品 | 另需《入境货物检验检疫证明》/卫生证书 + 供货协议 |

- 主体：企业/个体工商户均可；支持个人开户视具体类目
- 禁投：槟榔及其制品、1/2 段婴儿配方乳制品、长江江鲜、壮阳类食品、含 NAD/NMN 食品

#### （8）汽车（新车 / 二手车 / 驾校）

| 细分 | 行业资质 | 个人开户 |
|------|---------|---------|
| 汽车厂商（自有品牌） | 《道路机动车辆生产企业许可证明》或生产企业及产品信息查询系统公示截图（进口车免） | 否 |
| 4S 店/经销商 | 汽车厂商品牌授权 或 汽车品牌官网经销商查询截图（二选一） | 否 |
| 二手车经营 | 无行业资质；拍卖需《拍卖经营批准证书》、交易市场/经营主体需商务主管部门备案 | 是（个体户） |
| 驾校 | 《道路运输经营许可证》（载明"普通机动车驾驶员培训"）或驾驶培训学校/培训班备案证明 | 否 |

- 特殊准入：**4S 店/经销商需服务商开户，直客禁投**
- 禁投：套牌/走私/罚没/抵押车、拼装/组装车、车辆过户挂靠、抵押车销售

#### （9）婚介婚恋交友

- 行业归属：一级行业「婚恋」→ 二级「婚介所」
- 主体资质：营业执照，经营范围须含"婚姻服务/婚介服务"；支持企业及个体工商户；不支持境外主体
- 特殊主体要求：企业**注册资金 ≥100 万、公司年限 ≥1 年**（个体户无注册资金限制）
- 行业资质：无（仅凭主体资质即可开户）
- 附加资质（选填）：涉及 APP 投放 →《增值电信业务经营许可证》
- 特殊准入：个体户需申请才能投放
- 禁投：境外婚恋、同性交友

#### （10）本地生活服务（家政 / 美业 / 维修）

| 细分 | 行业资质 |
|------|---------|
| 生活综合服务平台 | 无；第三方商家入驻需《增值电信业务经营许可证》 |
| 专业维修（家电/数码等） | 无（家电维修需公司年限 ≥3 年、经营范围含"家电维修"） |
| 家政/美业等便民服务 | 无（家政须经营范围含"家政服务"） |

- 主体：企业/个体工商户均可
- 禁投：线下陪聊/陪玩、上门按摩、男士会所/SPA、遗嘱订立（合规律所豁免）、废旧危险废物回收

#### （11）酒类（白酒 / 啤酒 / 红酒）

| 主体类型 | 资质要求 |
|---------|---------|
| 生产企业（酒厂） | 《食品生产许可证》/《酒类生产许可证》/《全国工业产品生产许可证》（三选一）+ **《商标注册证》**（必填） |
| 经营企业（经销商/批发商） | 《食品经营许可证》/《酒类批发许可证》/《酒类零售许可证》（三选一）+《食品生产许可证》/《酒类生产许可证》/《全国工业产品生产许可证》（三选一）+ **《商标注册证》**（必填） |

| 补充情形 | 附加资质 |
|---------|---------|
| 进口酒 | 《出入境检验检疫卫生证书》/《进出口食品标签审核证书》/其他进口检验检疫证明 |
| 国产酒 | 《产品质检报告》+《商标注册证》 |
| 酒品电商平台（第三方入驻） | 《增值电信业务经营许可证》（B21） |

- 分销层级限制：知名品牌白酒「核心产品矩阵」内产品 → **限一级分销商**；非核心矩阵的知名酒水品牌 → 支持二级分销商
- 地方性要求：上海/广州/湖北/天津酒类批发另备《酒类商品批发许可证》；湖南国产酒/进口酒批发需对应省级许可证
- 主体：企业/个体工商户均可；支持境外主体；不支持个人开户

#### （12）医疗健康非处方类

**OTC 非处方药品销售**

| 资质类型 | 要求 |
|---------|------|
| 行业资质（必填，二选一） | 《药品生产许可证》/《药品经营许可证》 |
| 广告审查（必填，二选一） | 《药品广告审查表》/《广告审查准予许可决定书》 |
| 线上售药（选填） | 《互联网药品信息服务资格证书》 |
| 进口药品（选填） | 《进口药品注册证》+ 海关通关单或口岸药检所检验报告 |

**保健食品（蓝帽子）**

| 资质类型 | 要求 |
|---------|------|
| 许可（必填，二选一） | 《食品生产许可证》/《食品经营许可证》 |
| 广告审查（必填，二选一） | 《保健食品广告审查表》/《广告审查准予许可决定书》 |
| 产品批件（必填，三选一） | 《国产保健食品批准证书》/《保健食品备案凭证》/《保健食品注册证书》 |

- 关键识别：需有"蓝帽子"标识；没有蓝帽子的灵芝孢子粉等应进「营养及健康食品」而非保健食品
- 禁投：壮阳产品、"权健"相关主体、直销保健品

**医疗器械（一类 / 二类）**

| 细分 | 行业资质 |
|------|---------|
| 生产一类 | 《第一类医疗器械备案凭证》+《第一类医疗器械生产备案凭证》+ 广告审查表/决定书 |
| 生产二类 | 《医疗器械生产许可证》+ 广告审查表/决定书 |
| 经营一类 | 《第一类医疗器械备案凭证》+《第一类医疗器械生产备案凭证》+ 生产商授权 + 广告审查表/决定书 |
| 经营二类 | 《第二类医疗器械经营备案凭证》或《医疗器械经营许可证》+ 生产商授权 + 广告审查表/决定书 |
| 进口二类 | 《医疗器械注册证》+ 经营备案/生产/经营许可证（任一） |
| 网络销售（选填） | 《互联网药品信息服务资格证书》+《医疗器械网络交易服务第三方平台备案凭证》 |

- 均不支持个人开户；禁投：祛斑美容仪、特定冷敷凝胶/治疗仪等
- 备注：《第一类医疗器械备案信息表》可替代《第一类医疗器械备案凭证》

**消费医疗（医疗服务机构）**：《医疗机构执业许可证》《医疗广告审查证明》《医疗广告成品样表》

#### （13）教育培训

- 办学许可证（或相关资质）；面向中小学/幼儿园的校外培训广告禁投

#### （14）家装建材（装修 / 建材）

| 细分 | 行业资质 |
|------|---------|
| 装修公司 | 无特殊行业资质（仅凭主体资质开户）；涉及施工：《建筑业企业资质证书》；勘察：《工程勘察资质证书》；监理：《工程监理资质证书》；设计：《工程设计资质证书》 |

## 四、开户操作流程（4 步）

**Step 1：注册账户**
1. 进入腾讯营销官网 → 点击【注册】（ad.qq.com/account-center/register）
2. 用微信或 QQ 登录（**推荐微信**）
3. 输入微信号/QQ号、手机号、验证码 → 点击【注册广告账户】

**Step 2：主体认证**
- 上传营业执照等主体资质 + 法人身份证，确保信息一致

**Step 3：联系人认证（身份认证）**
- **推荐选【法人】**：微信扫码实时人脸识别，实时通过，并**豁免后续对公验证**，最快
- 选【企业员工】：需上传加盖公章的授权书（审核 1-2 个工作日），通过后还需完成对公验证

**Step 4：对公验证（如非法人认证）**
- 通过"人脸识别"或"银行账户实名"等方式完成

> 资料齐全、法人人脸认证顺利时，**最快 10 分钟**可开通。

## 五、审核时间与常见被拒原因

**审核时效**：
- 工作日：24 小时内；周末/节假日：48 小时内
- 整体（含主体、联系人、对公验证）通常 **1-2 个工作日**完成
- 超时未审可邮件至 ads_ss@tencent.com 发起催审（需注明广告主 UID）

**常见被拒原因**：

| # | 原因 | 说明 |
|---|------|------|
| 1 | **行业不一致**（最高频） | 广告实际推广的行业与开户行业不符，如投宽带业务却开在"物联网技术服务商" |
| 2 | 营业执照名称不一致 | 系统中录入名称与营业执照/协议名称不符 |
| 3 | 经营范围不涵盖 | 经营范围未涵盖待推广业务 |
| 4 | 营业期限问题 | 营业期限未覆盖投放期限 |
| 5 | 年审异常 | 企业被列入经营异常名录 |
| 6 | 法人身份证不一致 | 身份证信息与营业执照法人不符 |

## 六、开户后首次使用指引

### 1. 充值

#### 1.1 充值方式对比

| 充值方式 | 单次限额 | 到账时间 | 说明 |
|---------|---------|---------|------|
| **微信支付** | 1000 元 - 5 万元 | 实时到账 | 需支付人实名与账户主体一致 |
| **网银支付** | 1000 元 - 1000 万元 | 实时到账 | 分企业网银/个人网银 |
| **银行转账** | 无明确上限 | 约 3 个工作日 | 需附言以"WQ"开头 |

**方式细节**：
- **网银支付支持银行**：企业网银支持浦发、工商、招商、建设、农业、光大等银行（持续扩展），通过"更多银行"功能可用全量企业网银；个人网银部分场景支持
- **微信支付限额双口径**：标准广告主充值场景为单次 1000 元-5 万元；部分场景（如微信小店，基于监管要求）单用户单笔限 1 万、单日限 3 万。**大额充值建议直接用网银或银行转账**
- **银行转账**：收款开户行为**招商银行深圳汉京中心支行**（行号 308584001475），转账附言必须以 **"WQ"** 开头，否则可能被退回

#### 1.2 充值入口与操作步骤

**入口**：登录投放管理平台 → 顶端【财务】标签 → 资金总览/充值（或首页"充值"按钮）

**步骤**：
1. 点击【充值】→ 选择"在线充值"（充值类别为现金账户）
2. 进入"充值方式"选择页，选微信支付/网银支付/银行转账
3. 输入充值金额 → 按所选方式完成支付
4. 实时方式（微信/网银）付款成功即到账；银行转账约 3 个工作日到账

**最低充值**：系统单次最低 100 元，常规建议 5,000 元起步。
**消耗顺序**：优先消耗赠送金 → 现金 → 合约信用金。

#### 1.3 退款 / 余额退回

**退款条件（关键限制）**：
1. **满 24 小时**：网银/转账/微信支付充值后均需等待至少 24 小时才可发起退款（节假日顺延）。例：周一上午充值，建议周二下午申请；周五充值，建议下周一下午申请
2. **已开票需先退票**：已开具发票的资金无法直接退款，需先完成退票（邮件申请）再退款
3. **避开结算期**：每月 1-5 号为财务结算时间，期间充值可能退款失败，需等每月 6 号后重新发起
4. **退款去向**：仅支持退到与账户主体名称一致的银行账户（或原路退回）

**入口**：投放管理平台 → 顶端【财务】→ 二级导航【退款管理】

**流程与时效**：
- 线上提交退款申请，填写《腾讯营销退款申请表》并附相关资料
- 无需退回发票：约 1 个月到账；需退回发票：约 2 个月到账（节假日顺延）
- ⚠️ 申请退款时，账户内未消耗的虚拟金（赠送金）将**一律清除**
- 由服务商管理的客户，退款需直接联系服务商沟通

#### 1.4 发票开具

**入口**：投放管理平台 → 顶端【财务】→ 二级导航【发票管理】
> 仅限账户**超级管理员、管理员、财务人员**可查询和提交开票。

**步骤**：
1. 点击【发票开具】进入发票申请页面
2. 填写开票信息（抬头、税号等）→ 提交
3. 在发票管理首页查看申请记录，点击【电子发票】预览，或下载 PDF/XML/OFD 格式

**开票规则（2026 年 6 月 1 日起生效）**：

| 投放类型 | 服务费构成 | 开票类目 |
|---------|-----------|---------|
| 竞价投放 | 技术服务费（91.5%）+ 广告发布服务费（8.5%） | 信息技术服务费 + 广告发布费/广告费 |
| 合约投放 | 广告发布服务费 | 广告发布费/广告费 |
| 互选投放 | 平台技术服务费 | 信息技术服务费 |

> 预付费/后付费均**按实际消耗金额**开票，最终开票周期、类目、金额以提交申请时平台展示为准。

#### 1.5 其他财务注意事项

1. **"三流合一"合规**：资金流、发票流、货物流须一致——合同、资金、发票、服务主体信息一致；必须用与账户主体名称一致的银行账户或实名电子支付账户充值/退款，否则会被系统拦截或人工驳回
2. **资金账户体系**：2026 年 6 月 1 日起在线充值充入的资金归入**预存账户**（性质与原"现金"账户一致，按实际消耗开票）；另有 **IAA 分成收入快周转账户**（小程序/公众号/视频号流量变现的 IAA 现金分成收入）等，以平台实际展示为准

### 2. 账户结构（新投放平台 3.0）

```
账户
 └── 广告（营销单元）  ← 承载营销内容、定向、出价、预算、版位、排期
      └── 创意        ← 外层素材 + 落地页
```

| 层级 | 作用 | 数量上限 |
|------|------|---------|
| 广告（营销单元） | 区分物料管理，承载营销内容、定向、出价、预算、版位、排期 | 单账户最多 2 万个 |
| 创意 | 用户看到的前端广告内容 + 落地页 | 单广告最多 100 组（组件化）/ 1000 个（自定义） |

> 旧版"计划"层级已下线；部分智投/搜索场景还有"项目"层，常规展示广告核心就是「广告 + 创意」两层。
