# 腾讯广告创意与灵感（基础版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-21
> 定位：创意与灵感快速上手指引。组合测试、素材分层、CTR 基准等细节见《腾讯广告创意与灵感（深入版）》。

---

## 一、创意公式（一句话）

**黄金 3 秒 + 痛点切入 + 利益点前置 + 转化引导明确**

- **前 3 秒**：产品/核心卖点/最吸引人的画面立即出现，开头不要无关内容
- **痛点**：直接切用户最关心的 1-2 个痛点，让用户觉得"与我有关"
- **引导**：明确提示"领取优惠/了解详情/提交信息"

---

## 二、文案怎么写：6 类钩子

| 钩子 | 示例 |
|------|------|
| 痛点直击 | "还在为选礼发愁？一键定制专属好礼" |
| 利益前置 | "0 元领手机，今日仅限 100 名" |
| 情感共鸣 | "让爱回家，春节团圆礼首选" |
| 行动指令 | 【立即领取】【马上体验】 |
| 紧迫感 | "限时""限量""最后 XX 名" |
| 社交背书 | "10 万+用户已购买" |

> 结合行业高频关键词；禁绝对化用语、错别字、谐音字（详见审核合规文档）。

## 三、灵感从哪来（两个工具）

**1. 妙思灵感榜单**（【工具 - 妙思灵感】）：

**2. 妙思 AIGC**（【工具 - 妙思】）：
- 文生图、图生视频、数字人口播，一句话出素材
- 自动加警示语可直接投，**享 AIGC 专属广告扶持**
- 流程：生成 → 人工复核 → 同步到业务单元 → 投放选用

## 四、怎么测试：组件化创意

- 一个创意传 **多个视频（≤15）+ 多条文案（≤3）+ 多个落地页（≤3）**，系统自动组合并**优选表现最好的组合**
- 例：3 视频 × 3 文案 × 3 落地页 = 系统自动组合出 81 个创意
- 看数据：【报表】选"创意"维度；看单素材效果下钻到【创意详情】

## 五、版位适配速记

| 版位 | 创意要点 |
|------|---------|
| 视频号 | 竖版 9:16，真人/场景演示，重要信息放画面中间安全区 |
| 朋友圈 | 图片 800×800、文案 ≤30 字，**首帧/封面决定点击**（用户只看约 4.6 秒） |
| 公众号 | 横版大图 16:9 / 横竖版视频 |
| 联盟（优量汇） | **激励视频**（看视频换奖励）为主 |

---

## 六、素材迭代速记

- 素材有"保鲜期"，跑几天就会衰退
- **每 3 天至少补 10 条新素材**
- 2-3 天无消耗/低 ROI → 换掉；跑量好的 → 加预算
- CTR 三档：**<3% 改素材、3%-5% 打磨、>5% 加码**

---

## 七、全流程一图

```
找灵感（妙思榜单）→ 做素材（自研 or 妙思 AIGC）
→ 组件化创意组合测试（多素材×多文案）
→ 跑 2-3 天看数据 → 好的加预算、差的汰换
→ 每 3 天补新素材维持新鲜度
```
