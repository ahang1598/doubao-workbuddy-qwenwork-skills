> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20
> 定位：开户与充值的快速上手指引。逐行业资质清单、禁止投放全清单、退款/发票等细节见《腾讯广告开户与充值（深入版）》。

## 一、开户

### 1. 开户是什么

在腾讯广告（腾讯营销）平台注册广告主账户、完成主体资质认证并获得投放权限。开户时选定的**行业与资质决定后续可投的业务范围**。

### 2. 选择开户渠道（3 选 1）

| 渠道 | 适合谁 | 一句话 |
|------|--------|--------|
| **自助开户** | 绝大多数企业 | 官网自己提交，流程最快 |
| **直客团队** | 已签约大客户 | 有直客服务直接找团队 |
| **认证代理商** | 资质复杂/多账户/缺运营 | 服务商代办，可处理特殊资质 |

> 自助户与代理商户互不转换；一个微信号只能绑一个账户。

### 3. 开户前自查清单

**① 主体材料**（按主体类型备其一）：

| 主体 | 材料 |
|------|------|
| 企业 | 营业执照 + 法人身份证正反面 |
| 个体工商户 | 个体户营业执照 + 经营者身份证 |
| 其他主体 | 对应登记证书 + 负责人身份证 |

**② 行业资质**：部分行业需额外牌照才能开户，常见的有——

| 行业 | 关键资质 |
|------|---------|
| 贷款/金融 | 金融许可证 / 小贷经营许可证（+承诺函） |
| 保险 | 保险业务经营许可证 |
| 医疗 | 医疗机构执业许可证 + 医疗广告审查证明 |
| 药品/保健食品 | 药品经营许可证 + 广告审查表 |
| 游戏 | 游戏版号（ISBN 核发单）+ 软著 |
| 教育 | 办学许可证 |
| 旅行社 | 旅行社业务经营许可证 |
| 招聘 | 人力资源服务许可证 |

> 完整 15 大行业资质清单见深入版第一章。

**③ 是否命中禁投**：博彩、烟草（含电子烟）、处方药、校园贷、槟榔、代孕、风水算命等禁止投放（完整清单见深入版）。

### 4. 开户 4 步

```
① 注册账户 → ② 主体认证 → ③ 联系人认证 → ④ 对公验证（可免）
```

1. **注册**：官网 ad.qq.com/account-center/register → 微信登录（推荐）→ 手机号验证码 →【注册广告账户】
2. **主体认证**：上传营业执照 + 法人身份证，信息保持一致
3. **联系人认证**：**推荐选【法人】**——微信扫码人脸识别，实时通过，且**免做第 4 步**
4. **对公验证**：仅非法人认证时需要（人脸识别或银行账户实名）

> 资料齐全 + 法人认证顺利，**最快 10 分钟**开通。

### 5. 审核时效与被拒高频原因

- 时效：工作日 24 小时内、节假日 48 小时内；整体通常 1-2 个工作日
- 超时可催审：ads_ss@tencent.com（注明广告主 UID）

| 被拒原因（高频排序） | 一句话规避 |
|---------------------|-----------|
| **行业不一致**（第 1 高频） | 开户行业必须与实际推广业务一致 |
| 执照名称不一致 | 系统录入名称逐字核对执照 |
| 经营范围不涵盖 | 推广业务要在经营范围内 |
| 营业期限/年审异常 | 确保执照在有效期内、无经营异常 |
| 法人身份证不一致 | 身份证与执照法人信息一致 |

## 二、充值

### 1. 充值入口

投放管理平台 → 顶端【财务】→ 充值/资金总览（或首页"充值"按钮）

### 2. 三种充值方式

| 方式 | 单次限额 | 到账时间 | 适合 |
|------|---------|---------|------|
| **微信支付** | 1千 - 5万 | 实时 | 小额快速充值 |
| **网银支付** | 1千 - 1000万 | 实时 | **大额首选** |
| **银行转账** | 无明确上限 | 约 3 个工作日 | 超大额（附言须以"WQ"开头） |

### 3. 操作步骤（4 步）

1. 点击【充值】→ 选"在线充值"（现金账户）
2. 选择充值方式（微信/网银/转账）
3. 输入充值金额 → 完成支付
4. 实时方式付款即到账；银行转账约 3 个工作日

### 4. 关键规则速记

- **最低充值**：单次 100 元；常规建议 5,000 元起步
- **三流合一**：必须用**与账户主体一致**的银行账户/实名账户充值，否则被拦截
- **大额避开微信支付**：存在单笔/单日限额，直接用网银或转账
- **银行转账附言"WQ"开头**：否则可能被退回
- **消耗顺序**：赠送金 → 现金 → 合约信用金
- **退款有门槛**：充值满 24 小时才能退；已开票先退票；每月 1-5 号结算期别申请退款（细则见深入版第二章）

## 三、开户 + 充值全流程一图

```
备齐主体材料 + 行业资质 → 确认不命中禁投
→ 官网注册（微信登录）→ 主体认证 → 法人人脸认证（免对公验证）
→ 1-2 个工作日过审 → 财务入口充值（新户建议 ≥5000 元）
→ 开始搭建首个广告
```

> 转化归因接入、账户结构、落地页配置等投放环节指引，见其他主题文档。
