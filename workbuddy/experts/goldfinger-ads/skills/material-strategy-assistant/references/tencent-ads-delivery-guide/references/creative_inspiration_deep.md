## 一、高点击创意方法论（外层素材）

### 1.1 视频：开头黄金 3 秒

- **前 3 秒决定用户是否继续看**——产品、核心卖点或最吸引人的画面必须立即出现（如服装/美妆直接展示"模特上身"效果，迅速交代产品外观和使用场景）
- 开头禁用无关元素：不得用解压内容、街拍美女、夸张视频等与业务无关素材

### 1.2 痛点切入

直接、明确切入用户最关心的**一到两个核心痛点**。如产品解决"皮肤干燥"，就直接展示皮肤干燥的困扰并立即给出解决方案，让用户觉得"与我有关"。

### 1.3 转化好的创意的 6 个特点

1. **卖点清晰**，精准匹配用户需求（突出核心利益点）
2. **前三秒吸引力强**（视觉冲击画面/直接展示核心卖点）
3. **创意形式与版位适配**
4. **文案结合行业高频关键词**（行业热词提升点击转化）
5. **转化引导明确**（清晰提示"领取优惠/了解详情/提交信息"）
6. **素材执行质量高**（清晰度、拍摄方式、场景、BGM；真人展示、使用场景、功能演示表现较好）

## 二、高转化文案写法

首屏设置"钩子"是提升 CTR 的核心：

| 钩子类型 | 写法 | 示例 |
|---------|------|------|
| **痛点/需求直击** | 短句直接回应用户潜在需求 | "还在为选礼发愁？一键定制专属好礼" |
| **利益点前置** | 优惠/服务/结果放首句 | "0 元领手机，今日仅限 100 名" |
| **情感共鸣** | 场景化引发情感认同 | "让爱回家，春节团圆礼首选" |
| **行动指令** | 强引导按钮文案降低决策门槛 | 【立即领取】【马上体验】【查看详情】 |
| **紧迫感营造** | 限时限量提示 | "限时""限量""最后 XX 名" |
| **社交背书** | 销量/评价/授权增强信任 | "10 万+用户已购买""XX 品牌官方授权" |

> 数字式（具体数值增强可信）、对比式（前后反差）是"痛点直击/利益点前置"的变体，可结合行业高频关键词灵活运用。文案须遵守审核规范（禁绝对化用语、错别字、谐音字等，详见《审核与合规答疑（深入版）》）。

## 三、创意灵感从哪获取

### 3.1 妙思「灵感」功能

**定位**：解决"不知道做什么素材"，提供创意榜单、标签榜单、脚本榜单。

- **入口**：投放管理平台【工具 - 妙思灵感】，或妙思灵感站（admuse.qq.com）
- **筛选维度**：行业/类目、投放版位、素材类型、创意形式、效果数据（数据时效最快支持近 1 天）

**三大榜单**：

| 榜单 | 内容 |
|------|------|
| **创意榜单** | 朋友圈九图/视频/图片/游戏试玩 4 类；详情页披露投放效果数据、人群分析、视频号内容偏好分析、高光时序分析、创意标签分析 |
| **标签榜单** | 按"开场钩子、制作形式、场景背景"等标签聚合，支持关键词/年龄/性别/行业筛选 |
| **脚本榜单** | 按跑量脚本套路聚合，支持行业筛选 |

> ⚠️ 灵感素材**仅用于参考，不建议直接搬运**，应结合品牌调性、卖点、投放规范改写。

### 3.2 妙思平台（AIGC 生成素材）

**定位**：以腾讯自研混元大模型为底座的商业内容 AIGC 制作与分发平台，优化师/剪辑/设计师零门槛上手。

**制作路线**：

| 素材类型 | 路线 | 说明 |
|---------|------|------|
| 图片 | **无限画布** | 对话式生成、裂变、多版位适配、分图层精修——适合多轮精修、沉淀主视觉 |
| 图片 | **图片生成** | 商品图文/海报/家居生成等一键出图——适合快速批量出初稿 |
| 视频 | **视频生成** | 一句话/一张图生成营销视频，走"**选技能 → 填信息 → 出片**"标准流程（对话式 Skill 调用 + 灵感广场一键复刻双路径） |
| 视频 | **商品口播/混剪** | 上传商品细节/模特展示/直播切片 → 自动配脚本、字幕、BGM、数字人解说 |
| 数字人 | **数字人制作** | 输入口播文案即生成数字人口播视频，无需真人拍摄 |

- 文生图支持生成**免授权可商用**的 AI 人像模特

**生成后投放（3 步）**：
1. 妙思生成初稿 → **人工复核**（内容、版权、行业合规、审核风险）
2. 生成页点"**同步**" → 选择目标"**业务单元**" → 该业务单元下所有关联账户的素材库可使用
3. 也可保存至组件库/素材库后在投放流程中选用

> ⚠️ AI 生成结果 ≠ 可直接投放素材，投放前仍需人工复核 + 平台审核。

**AIGC 专属扶持细则**：
- 妙思生成并**线上保存至「组件库/素材库/创量素材库」投放**的素材，**自动享受** AIGC 素材创意专属广告扶持
- 素材带创意 ID 直接导入账户投放 → 自动获扶持
- 下载后二次创作 → 同样可扶持但**需手动提报**（联系销售经理填素材 ID）
- 图片/数字人素材可自动识别追溯，轻量二编可覆盖、无需单独提报；仅少数"视频生成"素材需用【AI 生产平台标签】补充提报

## 四、动态创意/组件化创意：素材组合测试

### 4.1 两种投放模式

| 模式 | 定义 | 特点 |
|------|------|------|
| **组件化创意** | 上传多个图片/视频/文案/落地页，系统自动组合并优选展示 | 按 CTR/ROI 动态选最优组合；组件可独立复用 |
| **自定义创意** | 固定组合，系统按指定组合展示 | 完全可控，但灵活性低 |

### 4.2 组合逻辑与数量上限

系统将素材、文案、落地页**两两组合（笛卡尔积）**生成"展开创意"：
> 例：图片 A、图片 B × 文案 A、文案 B = **4 个创意**；视频×3 + 文案×3 + 封面×3 + 落地页×3 = **81 个创意**（早期 27 个上限已解除）

| 项目 | 上限 |
|------|------|
| 单个组件化创意的图片/视频 | **15 个** |
| 单个创意的文案 | **3 个** |
| 单个创意的落地页（跳转链路） | **3 个** |
| 单个广告的创意数 | **100 个** |
| 单个广告的"展开组合" | **1000 个** |

### 4.3 系统怎么优选

组件化创意系统根据**用户行为和广告目标（CTR、ROI 等）动态选择最优组件组合**展示——组合出更多创意提升拿量，并优选组合提升整体竞争力。组件作为整体优选展示（同一视频不同封面图 = 不同组件；9 图素材顺序不同也会生成不同组件）。

### 4.4 测试结果怎么看

| 看什么 | 路径 |
|--------|------|
| 创意维度数据 | 投放端【报表 → 效果数据】，维度选"创意" |
| 组件维度数据 | 【报表 → 创意组件】（图片/视频/文案/落地页一级组件） |
| 单创意下各组件效果 | 【推广 → 创意 → 详情 → 创意详情】下钻 |
| 分版位数据 | 报表创意分析页勾选【版位细分】 |
| 跨账户素材表现 | Creative+ → 报表（创意资产报表 / 视频聚合分析报表） |

> 用 CTR、CVR 判断素材价值；视频重点看**点击、互动、流失、转化**判断结构是否需优化。⚠️ 一个营销用多个创意时组件指标总计会"复计"，看单组件价值要下钻到具体创意，别直接看总计。

## 五、各版位适合的创意形式与爆款特点

### ① 视频号（竖版短视频为主）

- 规格：竖版 9:16（720×1280）为主，另有横版 16:9、4:3（动态推广不支持 4:3）
- **卡片形式**：
  - 轮播卡片：左下角全程展示 3-5 个，可滑动/自动轮播，点击跳不同落地页，"边看边买"
  - 浮层卡片：视频播放中展示，最后一秒展开，可开**数据外显**（"最近已有超 X 人购买"）
- 爆款特点：沉浸式竖版全屏、真人展示/场景演示；注意安全区（左右各裁切 46px、上 154px、下 196px），**重要信息放安全区内**

### ② 朋友圈（共 9 个营销形态）

- 常规广告：单图/多图（**最多 9 张**）/视频，与信息流样式一致
- 卡片系列：视频/图片卡片，轮播式卡片 **4-6 个素材**（每视频 5-15 秒，第二张起加行动按钮）
- 规格：常规大图/多图**仅保留 800×800**；卡片横版视频 16:9 分辨率 1280×720
- 文案：上限约 30 字，简洁直给
- 爆款特点：**强广告属性开头**（用户观看时间仅约 4.6 秒但质量高）；竖版视频外层不自动播放，**"吸睛首帧/封面 + 简洁文案"是核心公式**

### ③ 公众号与小程序

- 创意形式：16:9 横版大图、横版视频 16:9、竖版视频 9:16；文底关键词广告外层视频 6-30 秒
- 售卖：CPC/CPM/oCPC/oCPM

### ④ 腾讯平台与内容媒体（PCAD：腾讯视频/新闻等）

- 创意形式：banner、常规多图 1:1 六图、视频等
- 售卖：CPC/CPM/oCPC/oCPM；通投覆盖广、泛化流量大

### ⑤ 腾讯营销联盟（优量汇）

- 创意形式：**激励视频**（全屏沉浸，看完整视频换奖励）、奖励式插屏全屏视频、banner、六图
- 典型场景：手游"看视频复活/解锁道具"、工具 APP"看视频免广告"
- 不支持横版 4:3 视频；流量多元、规模大

> 版位简称对照：MP=朋友圈/视频号等微信场景；XS=腾讯视频/新闻；XQ=QQ/腾讯音乐/游戏；LM=联盟（优量汇）。全流量通投时建议同时勾选以获取更优效果。

## 六、创意测试策略与赛马机制

### 6.1 新账户/新素材测试参数

| 维度 | 建议 |
|------|------|
| **测试预算** | **为目标付费成本的 10 倍以上**，看 CTR/转化率趋势判断 |
| **起测数量** | 起量阶段基建 **2-4 条广告**、稳定放量 **10-18 条**；单账户日建广告 ≥5 条、平均在线 10-20 条 |
| **跑多久看数据** | 观察 **2-3 天**；2 天消耗小/无曝光/ROI 低即汰换 |
| **账户余额** | 测试期 2 万+/账户，起量期 10 万+/账户 |

### 6.2 赛马机制

- **核心思路**：1 条计划下放多条创意、1 个创意下 1 个视频，让系统并行跑，用数据跑出爆款
- **3.0 最佳实践（重要）**：平台**不鼓励为测创意而新建营销**——营销诉求不变时，**新创意直接加到"老营销/老计划"中测试**，可借助老营销积累的数据让新创意更快完成模型预估、更容易曝光（新竞价链路下创意单独参与大盘竞争）
- **保持单一性**：同一营销尽量保持创意形式单一（竖版图片就只放竖版图），避免不同版位素材内部竞争浪费
- 只在有**全新经营诉求**（推新品、测全新人群）时才新建营销

## 七、素材衰减与更新节奏

### 7.1 什么是素材衰减

广告素材有"**保鲜期**"：即使一开始跑得好，随时间推移用户会产生"审美疲劳"，效果逐渐下降（素材新陈代谢）。爆款素材也可能跑几天到一周后突然"跑不动"、转化成本升高。

### 7.2 更新节奏

- **核心节奏：每 3 天至少补充 10 个新素材**（约每天 3-4 条）；项目生命周期 ≥3 天时即建议启动
- 老营销里建议**每天保持上新 5-20 条新创意**——素材必然衰退，不上新就会被新创意挤掉

### 7.3 判断该下线/迭代的信号

| 信号 | 处理动作 |
|------|---------|
| 3 天无消耗/消耗极低且无转化 | 删除或补充新创意组件 |
| 观察 2 天消耗量级小/无曝光/ROI 低 | 删除暂停、汰换，保持广告总创意量 |
| 存量素材审核通过后 **3 个月未曝光** | 系统自动发起下线预警，需重新提交 |

> ⚠️ 判断前先排查其他因素：创意审核是否通过、预算是否充足、定向是否过窄、出价是否偏低——别把"不起量"全归因于素材。

## 八、素材分层管理与 Creative+

### 8.1 按效果分层

| 层级 | 判定 | 动作 |
|------|------|------|
| **跑量素材** | 能持续跑量、CTR/CVR 达标 | 加预算、关不起量创意让预算集中；无需急着加新创意组 |
| **潜力素材** | 有消耗但未达量、CTR 接近均值 | 继续观察、小预算打磨、裂变同款 |
| **待淘汰素材** | 2-3 天无消耗/低 CTR/低 ROI | 删除暂停、汰换，保持创意总量 |

### 8.2 Creative+ 创意资产库（五大模块闭环）

| 模块 | 用途 | 关键动作 |
|------|------|---------|
| **洞察** | 诊断创意资产状态，与同行/同类对比 | 看组件充分度、审核、跑量、首发情况，定位短板 |
| **灵感** | 找同行/跨行业优质创意 | 按行业/版位/素材类型筛榜单，拆解复用元素 |
| **制作** | 集成妙思 AIGC 生成素材 | 图片/视频/数字人三路线生成初稿 |
| **管理** | 统一管理图片/视频/文案/落地页/组件 | 按类型、创建时间、投放状态、评级筛选；批量打标签/删除/解绑低效重复素材 |
| **报表** | 聚合创意效果数据 | 创意资产报表 + 视频聚合分析，跨账户查看导出 |

> 分场景路径：发现问题用"洞察"、找灵感用"灵感榜单"、做素材用"妙思制作"、管资产用"管理"、看效果用"报表"。

## 九、CTR 基准与优化

### 9.1 CTR 三档分级标准（直播/信息流通用口径）

| CTR 区间 | 评级 | 含义 | 优化动作 |
|---------|------|------|---------|
| **0%-3%** | **超低** | 素材有大问题 | 重点优化素材本身：视频开头/文案/创意方向 |
| **3%-5%** | **平平无奇** | 还可以更好 | 继续打磨素材、优化开场与利益点表达 |
| **5% 以上** | **优秀** | 保持并加码 | 继续保持，可考虑加大投放 |

> CTR = 点击量 ÷ 展现量 ×100%；另有案例口径约 2.72% 已被视为"非常优秀"（不同行业/版位有差异）。更细的五档分级官方无记载。

### 9.2 创意优质辅助指标（点击量 ≥50 时可参考）

| 辅助指标 | 建议阈值 |
|---------|---------|
| 点击率 | ≥ 4% |
| 视频 3 秒完播率 | ≥ 60% |
| 视频平均播放时长 | ≥ 16 秒 |

### 9.3 CTR 偏低的排查顺序

1. **优化外层素材**：挖用户痛点、更吸引人的文案/图片（直击"痛点+使用场景"）
2. **调整定向**：细分人群、尝试不同定向组合
3. **优化广告样式/位置**：调整样式与展现位置
4. **排查深层原因**：产品价值难讲清，还是受众不精准（人群设置/版位选择不当）

## 十、常见误区

| 误区 | 具体表现与后果 |
|------|---------------|
| **素材同质化** | 内容/形式/表现手法缺乏差异，用户感知重复 → CTR、兴趣度、ROI 下降 |
| **盲目堆数量（堆基建）** | 同素材拆多个营销、多账户投放会被判同质化；应"正确表达营销内容 + 多上优质差异化素材" |
| **为测创意新建营销** | 3.0 不鼓励；新创意应加到老营销中借数据更快起量 |
| **忽视版位适配** | 创意形式与版位不匹配（联盟 4:3 横版不支持、朋友圈首帧不吸引）→ 拿量差 |
| **只看总量不看下钻** | 组件指标总计会"复计"，不看单组件下钻数据会误判素材价值 |
| **AI 素材直接投** | 妙思生成后未人工复核直接投放，有合规与审核风险 |

## 十一、速记

- **创意公式**：黄金 3 秒 + 痛点切入 + 利益点前置 + 转化引导明确
