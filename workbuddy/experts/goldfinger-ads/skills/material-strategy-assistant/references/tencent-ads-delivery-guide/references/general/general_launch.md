# 第三部分　账户搭建与冷启动

## 3.1 新产品投放的三步走总纲

> **跑出去 → 降成本 → 放大消耗**（在 ROI 和成本范围内做最大规模的探索与优化）

### 投放前必须确认的四件事

| 项目          | 含义                        |
| ----------- | ------------------------- |
| **预算**      | 能够支持投放的最大消耗规模             |
| **offer**   | 我要投什么产品/服务                |
| **周期**      | 能够支持投放的时长                 |
| **目标 + 出价** | 投放目标是什么 + ROI 范围下能接受的最高成本 |

⚠️ **必须先接受的前提**：效果广告**不保量**，且**不能 100% 保障效果**。新产品投放初期需要一定预算做成本、出价、投放方式的探索，**必须接受一段时间的高成本周期**。

### 第一步：跑出去

任何 offer 的第一步都是**先消耗出去**，让系统认识这个产品，建立最初的数据。这个阶段会带来一定高成本，因为前期没有成熟模型，需要消耗曝光帮系统学习。

怎么才能跑出去？回到 eCPM 公式——提高出价、提高 CTR、提高 CVR 三条路。

**提升 CVR 的特殊手段（深转产品适用）**：深度转化产品回传数少，冷启期容易出现「没有转化 → 广告持续空耗 → 系统认为没有拿量竞争力 → 广告跑死」。这时可以**放宽回传口径人为拉高 CVR**，例如回传 7 天内的转化数据、或回传部分大盘数据。

> ⚠️ 前提：**回传的人群画像必须与转化目标一致**，否则会污染后续模型。

另一手段是**圈定特定人群**（RTA / 定向人群包），直接提升人群中的转化比例。

### 第二步：降成本

前提：产品已过冷启期，账户有稳定回传，广告能持续跑量。

**超成本的定义**：计费比（实际成本 ÷ 目标成本）> 1.2，即实际成本高出目标 20%。

分三种情况处理：

| 情况                                  | 判断        | 处理                                                             |
| ----------------------------------- | --------- | -------------------------------------------------------------- |
| 跑量速度符合预期甚至过快（预期 2 万花 10 天，结果 2 天花完） | 跑太快、出价高了  | 适当下调出价，把跑速拉回合理范围                                               |
| 跑量速度本身很慢（日均消耗 < 1000）且成本偏高          | 本质是「跑不出去」 | 回到第一步，观察全流程数据，打磨产品/素材/投放目标/版位后再测                               |
| 跑量速度中等、比较均匀                         | 状态健康      | 寻求版位拓展或素材精细化，放大规模后**小幅**下探出价；或出价不动，用降低空耗、提升全流程转化效率的方式（**更推荐**） |

### 第三步：提消耗

问题从「怎么投」变成「怎么在 ROI 考核下花出去更多预算」。三条提量路径：

1. **看成本/出价**——回到 eCPM 公式，投放模式稳定时，出价是最直接的提量手段
2. **看人群**——人群包/定向拓展。量级遇瓶颈时扩包，特别是定向较窄的业务
3. **换产品和 offer**——深转链路瓶颈期，换商品或 offer 也是新的提量思路

## 3.2 账户结构与预算设置

### 账户搭建建议

- **在投项目：每个账户至少 5 条广告**
- **账户组合**：建立「测试账户 + 主力账户 + 备用账户」三级组合，分散风险并加速模型迭代
- **新户初期计划数**：大部分新户 2-3 条就够，预算较高的可 3-5 条
  - ⚠️ 新建一堆计划很多是相似计划，会**内部竞争、卷量的同时拉高后端成本**
- **预算分配**：初期可平均分配；投放一段时间后核心预算主给主力计划，去拿量、降成本、快速积累基础数据完善账户模型

### 预算设置的量化标准

| 层级        | 标准                                             |
| --------- | ---------------------------------------------- |
| 账户维度      | 预算 ≥ 目标转化成本 × 10（目标 CPA 50 元 → 单创意预算不低于 500 元） |
| 广告维度      | 初始预算 ≥ 目标转化成本 × 5                              |
| **日预算下限** | **≥ 目标 CPA × 20**（统一标准）                        |

> **统一口径**：日预算下限 = **目标 CPA × 20**，全平台通用。  
> **唯一例外**：巨量 UBMax 等自动化投放产品需 **≥ 目标成本 × 50**，因为机器需要更大探索空间。  
> （部分资料提到 ×5，那是绝对底线而非推荐值，按 ×20 执行。）

## 3.3 冷启动机制：系统在"面试"你的计划

### 定义与本质

**冷启动**：新计划上线后、数据积累不足、预估模型尚未收敛的阶段。  
一句话：**平台还没学够你的数据，不敢给你放量。**

**为什么平台要保守**：平台排序靠 eCPM，pCTR/pCVR 靠模型算，模型靠历史数据。新计划数据为零，只能给保守值——宁可低估不能高估，因为高估意味着平台承担机会成本（曝光给了不转化的计划）。**保守预估是平台的自我保护。**

**本质**：冷启动是平台与广告主之间的「信号投资」——**你投入预算换数据，平台投入算力换模型，你获得回报。** 真正发生的是：平台在尝试建立信任，决定未来是否值得把更多流量交给你。

### 冷启动的四个阶段

| 阶段           | 时间             | 发生什么                                              |
| ------------ | -------------- | ------------------------------------------------- |
| 分配试探流量       | T+0 ~ T+6 小时   | 从相似计划「借」预估值（同行业/同出价/同定向的邻居历史数据），模糊保守；分配几百到几千次曝光采样 |
| 数据积累、模型学习    | T+6 小时 ~ T+3 天 | pCTR/pCVR 从「借来的模糊值」向「自己的真实值」靠拢，即模型收敛              |
| 预估准确、eCPM 提升 | T+3 ~ T+7 天    | 真实 eCPM 高则排名上升放量，低则拿不到量                           |
| 模型收敛、进入稳定期   | T+7 天后         | pCTR/pCVR 稳定，量级稳定                                 |

### 冷启动阶段系统在学什么

1. **学用户特征匹配**——什么样的人看到这条广告会停下来（输入年龄/性别/地域/兴趣/行为序列，输出匹配度）
2. **学 pCTR 和 pCVR**——注意 CTR 高 ≠ CVR 高，标题党拉高 CTR 但点进来人走了，CVR 崩，eCPM 照样上不去
3. **学出价策略**——oCPX 下模型学"什么用户在什么场景转化概率多少"，反算每次曝光该扣多少钱。**冷启动成本忽高忽低，是出价策略还没学准**

### 帮助计划顺利过冷启动的六个做法

| 做法    | 具体操作                                  | 核心原则                 |
| ----- | ------------------------------------- | -------------------- |
| 预算给足  | 日预算 ≥ 目标 CPA × 20                     | 让模型有足够样本             |
| 出价偏高  | 目标成本的 **1.2–1.5 倍**                   | 补偿冷启动期 pCTR/pCVR 的低估 |
| 定向放宽  | 只设必要定向，稳定期再收窄。人群覆盖至少 3000 万，最好 5000 万 | 池子够大才能找到会转化的人        |
| 素材多方向 | 一个计划配 3-5 条**不同方向**素材                 | 扩大找到正确方向的概率          |
| 配置稳定  | 前 3 天不动，之后一次只调一个变量；出价每天最多调 1 次        | 不打断模型学习              |
| 给时间   | 浅层转化 3-5 天，深度转化 7 天以上                 | 学习需要周期，不是调出来的        |

**补充技巧**（来自实战）：

- 用**过往跑量或竞品验证过的素材方向**，切忌堆很多方向或盲目测新
- 用过往跑量文案**略微改写**（不要 1:1 抄，避免同质化）
- 用**一方人群加强**功能助力系统快速建模（注意新户建议 3 天后再用）
- **A 计划养 B 计划**：用老计划的高转化数据，复制出新计划的定向包和素材。新计划会继承部分历史权重，pCVR 起步更高，可以用更低出价

### 三个常见误区

| 误区       | 真相                                                                         |
| -------- | -------------------------------------------------------------------------- |
| 素材越多过得越快 | 模型学习样本按「计划」汇聚，塞十几条素材每条分到的试探流量都少，学不出来。要**方向多样化**而非数量堆砌——3-5 条不同方向优于 10 条同方向 |
| 频繁调整能加速  | 每次调整关联模型预估的变量（出价/定向/转化目标）都会**打断学习、从头重来**。调三次就是三次重置                         |
| 三天没过就该放弃 | 判断标准不是「几天」，而是**转化数据是否累积到让模型初步收敛的量**                                        |

### 学习期成功的五个信号

1. 后台状态显示"学习成功"或"稳定投放"（显示"学习中"就还没到）
2. 增加预算不失控——预算提高 20-30%，成本不明显上涨
3. CVR/CTR 趋于稳定——波动幅度小于 10%
4. 转化成本稳定落在目标附近
5. 新计划的初始消耗流量明显加快

## 3.4 冷启动期四种情况的处置动作

| 情况         | 定义                            | 动作                                                  |
| ---------- | ----------------------------- | --------------------------------------------------- |
| **空耗**     | 消耗了 2-3 个目标转化金额的预算，无目标转化      | **暂停**                                              |
| **不起量**    | 只有 3 个以内目标转化，且当日转化成本在 2 倍以内   | 提价 5%-10%（分 2-3 次），单次不超过 3%；或使用一键起量                 |
| **广告衰退**   | 消耗速度低于历史同时段 30% 及以上，且持续 2-3 天 | 提价 5%-10% 观察；无法刺激消耗或持续波动则关停后新建                      |
| **未通过冷启动** | 开启后 7 天内仍处于空耗/不起量             | 复制原创意并调整变量（定向/出价/素材）重新测试；或延长观测至 10 天（部分广告后期会逐步积累转化） |

**学习期失败的处理**：可采用「**72 小时静默期 + 模型重置**」——暂停投放 3 天后重新开启，系统会清除部分无效数据。

## 3.5 止损时间表：什么时候该停

这是判断"继续观察还是关停"的量化标准。

### 前 5 个转化成本判断法

**为什么是"前 5 个"**：这是模型学习的最小有效样本。

| 前 5 转化成本 | 判断   | 动作                                 |
| -------- | ---- | ---------------------------------- |
| ≤ 2× 出价  | 继续投放 | 系统还在探索，成本会逐步拉平。保持预算，耐心观察           |
| 2-3× 出价  | 拉长观察 | 再跑 500-1000 元，看系统能否拉低成本；不行就调整素材/定向 |
| > 3× 出价  | 立即止损 | 方向错了，继续跑就是烧钱。关停、复盘、重建              |

> 前提是确认数据回传实时。如果是 T+1 回传，要拉长观察周期。

### 黄金止损时间表

| 消耗节点              | 检查内容      | 结论            |
| ----------------- | --------- | ------------- |
| 消耗 = 出价 × 1.3~1.5 | 必须查看是否有转化 | 第一观察窗口        |
| 消耗 = 出价 × 5~20    | 仍然没有转化    | 建议暂停          |
| 成本 = 出价 × 2       | ——        | **绝对红线，立即关停** |

### 2 倍出价：绝对红线

**老广告成本超过出价 2 倍 = 必须立即暂停。**

为什么是 2 倍：老计划已有足够学习样本，还跑到 2 倍成本，说明**模型已经失效**。

区分新老计划：

- 新计划：可容忍 1.5-2 倍超成本
- 老计划（跑了 7 天+）：超 2 倍直接关

⚠️ 操作要点：**不可反复开启关停**，会破坏模型。可以复制广告重新拿量。

### 三个必须刹车的信号

1. 消耗快但零转化（消耗达出价 5-20 倍仍无转化）
2. 点击率 5%+ 但转化率 0.01%——说明流量根本不精准
3. 前 5 个转化成本已达出价 3 倍+，系统拉不平

## 3.6 账户操作的禁忌清单

以下操作会直接损害账户权重和模型稳定性：

| 禁忌            | 原因                  |
| ------------- | ------------------- |
| 广告无差异全复制      | 内部竞争、抢量抬价，系统无法判断优先级 |
| 一个广告一天调整超 2 次 | 打断模型学习              |
| 创意多次关停和开启     | 开关 > 3 次会被系统判定异常    |
| 大幅修改定向、出价、创意  | 修改幅度 > 20% 等于重置学习期  |
| 暂停广告超过 2 小时   | 影响模型连续性             |

**反之即为正向操作。**

### 必要负向操作时如何规避负向表达

遵循 **1+N 原则**（N ≥ 1）：**一个负向操作，同时搭配一个以上正向操作。**

例：降价 → 同时放开部分定向 + 提预算。

## 3.7 养户：与算法建立信任

**什么是养户**：投放初期（通常 3-7 天）通过精细化、策略性操作，引导算法充分了解并信任你的账户，建立高质量、高权重的初始模型。

**核心是与算法建立信任**。算法目标与广告主一致（预算内找最可能转化的人群），但一开始对你不了解。宽泛定向只会引来无效点击、成本高，算法会判断你不是优质客户，后续流量分配变谨慎。所以养户期做的所有事，都是在给算法**提供清晰、高质量的数据样本**。

| 维度     | 做法                                                |
| ------ | ------------------------------------------------- |
| 账户结构   | 小而精，不追求大而全。基于核心标签 + 精选素材搭多条计划，每条预算保守              |
| 出价     | 温和而坚定。不追最低价（跑不出去），不盲目抬价。参考系统建议 + 转化价值判断           |
| 素材与落地页 | 素材是「信任状」，优先用已验证的高点击/高转化素材；落地页任何卡顿都在给脆弱的信任链条减分     |
| 数据调整   | 忍住频繁插手。新计划给 24-48 小时学习期，只要不是成本离谱、完全没消耗、或快速跑完预算就观察 |

**做「微创手术」而非大动作**：好的小加预算；消耗慢但转化不错的微调推一把；持续差的快干预。

**养户成功的质变标志**（快则 2-3 天，慢则 5-7 天）：账户健康稳定、新计划更容易起量（继承账户权重）、计划生命周期变长、转化成本可控。

> **养户看似慢、实则快。** 根基扎实、被算法信任的账户，起量是源源不断、可复制、成本最优的；靠一条爆款素材起的量往往昙花一现。

## 3.8 新账户起量四步法

**起量公式**：起量 = 最能打的素材 × 最有竞争力的出价 × 最流畅的账户流速

### 第一步：选素材——用「起量概率」做减法

结合三点判断起量概率：历史跑量素材、后台创意库/行业竞品跑量素材、自身经验。把素材分四档（如 30 个素材）：A 档高概率 6 个、B 档中概率 6 个、C 档中低概率 6 个、D 档待定 12 个。

核心不是赌哪个能爆，而是**结构化筛选，把有限预算优先集中在概率最高的素材上**。

### 第二步：测出价看数据

1. **定出价**：无历史数据就打听出价区间（如 35-50），**直接取中上水平**（如 44-46）。不要从最低开始测——新账户没人群模型、探索慢，低价起步只会半死不活
2. **建计划**：A/B/C/D 各选 6 个，共 12 条。第一天出价 44，早 6 点 A+C 六条启动、11 点 B+D 六条启动
3. **看数据**：找转化数最多的前 5 条，看转化成本与出价的差值（出价 44 而成本 47-50，说明出价偏低，需提价）
4. **第二天操作**：出价提到 50；新上 A+C、B+D 各 6 条；复制第一天转化 >1 的计划，出价 44→50
   - **关闭规则**：空耗大于出价 1.7 倍的计划，果断关
   - **观察规则**：消耗 TOP5 的计划，只要转化成本不高于 70 元就继续探索；出价 50 而成本飙到 100 以上才考虑关
   - **一键起量**：给消耗转化前 5 的计划各 100 元，结束后再给 100 元——**小步多频，试探上限**

### 第三步：拔价拉消耗层级

第三天，对消耗转化前三名的计划出价 50 → 58，继续多频次给一键起量 100 元，把账户总消耗快速拉到更高层级。

**敢提价的依据**：前两天数据已验证素材和出价的有效性。

### 第四步：稳消耗降成本

⚠️ **刚起量时千万不要马上降价！** 先「新建 + 复制」，把高消耗状态稳住 3 天。

3 天后出现两个信号说明账户进入稳定流量层级，再开始降价：

1. 新计划初始消耗流量明显加快
2. 跑量计划流速持续增加

降价方法：

- 跑量计划**一次只降 1-2 元**
- 新计划出价直接用跑量计划出价 **+1-2 元**（保持出价优势，不被老计划压着）

2-3 天精细调控后，可把综合成本压到 52-54 元，总消耗依然很稳甚至不降反增。

## 3.9 新账户就是跑不动时的应急手段

按顺序尝试：

1. 用最小预算搭一个**跑浅层目标**的创意，让账户先花点钱出去
2. 用**一键起量**工具刺激（注意控制预算）
3. **找直客排查账户是否有限流**
4. 每天保持新建计划持续 3-5 天，顺序测试：手动出价 → 放量投放 → 一键起量 → 投放管家
5. 7-14 天仍不行，考虑**换新户**

⚠️ 巨量引擎信息流新账户 **80%-90% 都会遇到起量困难**，不必焦虑，也**不要一股脑提价**（光提价不一定带来展现，反而拉高整体成本）。

## 3.10 深层转化为什么更难起量

|    | 浅层转化                 | 深层转化                |
| -- | -------------------- | ------------------- |
| 例子 | 激活/注册、表单提交、咨询入群、下载完成 | 首次付费、次日留存、下单成交、关键行为 |
| 特征 | 转化路径短、数据量大           | 转化路径长、数据稀疏          |
| 本质 | 用户兴趣                 | 真金白银                |

深层转化数据稀疏 → 模型学得慢 → 冷启动周期长、成本波动大。这也是为什么深度转化的学习期门槛和时间都要放宽。
