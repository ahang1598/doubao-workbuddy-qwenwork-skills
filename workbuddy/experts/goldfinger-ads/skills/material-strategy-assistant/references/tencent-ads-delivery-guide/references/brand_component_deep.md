# 腾讯广告品牌形象组件（深入版）

> 来源：腾讯营销知识库（官方口径），整理日期：2026-08-20
> 定位：品牌形象组件完整细节手册。快速上手见《腾讯广告品牌形象组件（基础版）》。

---

## 一、概念与作用

**品牌形象**是广告外层创意中展示广告主身份的**固定组件**，统一展示品牌标识（**头像 + 昵称/品牌名称**）。

- **视频号**：品牌形象作为推广视频的账号载体（头像+昵称）
- **朋友圈**：作为广告展示时的账号头像和昵称；点击可跳转品牌简介页或搜一搜品牌主页

**作用**：
1. 统一品牌视觉：集中管理品牌头像等视觉资产，保证各广告品牌露出一致
2. 增强辨识度与信任：以官方账号形象展示
3. 作为创意组件参与投放：组件化创意和自定义创意都可调用的核心组件，独立创建、可复用

---

## 二、类型全集与版位差异

| 类型 | 支持/限制的版位 | 关键差异 |
|------|---------------|---------|
| **视频号品牌形象** | 视频号版位 | **仅选视频号品牌形象的创意才能在视频号版位曝光**；用视频号头像+名称 |
| **公众号品牌形象** | 朋友圈、公众号与小程序等（视频号除外） | 用公众号头像+名称 |
| **品牌简介页** | 朋友圈等 | 点击外层头像/昵称进入系统预设的品牌介绍页 |
| **自定义** | 各版位（视频号版位受限） | 自由上传头像、填名称 |
| **搜一搜超级品专品牌形象** | 微信搜索结果页首页 | 品牌门户形态：品牌背景（图片/视频，视频可自动播放）、基础信息、官方账号（1~50 个）、进店组件、热门活动等 |
| **微信小店店铺品牌形象** | 朋友圈、公众号与小程序、腾讯平台与内容媒体、腾讯营销联盟 | 展示小店店铺头像昵称（自动拉取不可改）；**不支持视频号** |

**通用规则**：
- 通投场景（含视频号版位）下选了非视频号品牌形象 → 广告在视频号版位**无法曝光**
- 腾讯平台与内容媒体版位：创意形式为**竖版大图 16:9、方形大图 1:1、闪屏视频 16:9** 时，**品牌形象 + 行动按钮为必填组件**

## 三、各类型配置步骤（授权流程详解）

### 3.1 视频号品牌形象（关联视频号）

**授权入口**：投放管理平台 →【工具】→【微信生态授权管理】→【微信视频号授权】→ 输入视频号名称 → 校验 → 勾选授权协议 → 发起授权。

| 场景 | 流程 |
|------|------|
| **同主体**（视频号主体 = 投放账户主体） | 管理员微信扫码确认即绑定成功 |
| **跨主体** | 需补充**商业模式证明材料**，管理员扫码 + 资质广审通过后才绑定成功 |

> 坑：若视频号有名称却无法绑定，可能是误用了"互选二次推广授权"而非"生态视频号授权"，需到【工具-微信生态授权管理】重新发起。

### 3.2 公众号品牌形象（关联公众号）

**授权入口**：【工具】→【微信生态授权管理】→【公众号授权】，输入公众号**开发者 ID（AppID）**校验后发起授权。

| 场景 | 流程 |
|------|------|
| 同主体 | 系统校验通过后直接完成授权 |
| 跨主体 | 需补充公众号管理员资质，管理员扫码 + 资质广审通过后绑定 |

- 授权有效期可设 **1 天至永久**
- 一个客户账号暂只支持绑定 **1 个**公众号（1 个公众号可授权多个客户账号）

### 3.3 微信小店店铺品牌形象

**前置**：先在【工具】→【微信生态授权管理】→【微信小店授权】完成小店授权（输入小店名称 → 校验 → 勾选协议 → 发起授权）。

**使用条件（缺一不可）**：
1. 营销目的选「商品销售」或「品牌宣传」
2. 推广产品选「微信小店商品」并选定具体商品
3. 落地页必须选【微信小店商品页】
4. 品牌形象处选【微信小店店铺】→ 系统**自动拉取小店店铺头像、名称，不支持修改**

### 3.4 搜一搜超级品专品牌形象

- 搜一搜超级品牌专区是**招商制品牌产品**（微信生态内的"品牌门面 + 私域中心化入口"），**非自助开通**
- 触发场景：用户在【对话框顶部搜索】【发现-搜一搜】【朋友圈/聊天框 #关键词】等搜索品牌词时展示
- 开通需通过**招商/行业运营**对接，创意设计遵循 MR 指南；知识库未给出自助开通条件清单

### 3.5 自定义品牌形象

【资产】→【创意资产管理】→【品牌形象】→【新建】→【自定义】→ 上传头像（512×512、≤120KB）→ 填品牌名称 → 提交审核。

## 四、品牌简介页

- **是什么**：品牌形象的类型之一——**系统预设的、标准化展示品牌官方信息的页面**（区别于可自由设计的自定义推广页）
- **展示内容**：点击广告外层头像/昵称进入品牌合作介绍页，标准化展示：合作关系介绍、品牌名称、品牌头像、品牌介绍等
- **适用场景**：需要建立品牌信任、展示官方背景的投放（尤其朋友圈等版位）
- **创建**：统一在【资产 → 创意资产管理 → 品牌形象】创建，品牌简介页类调用系统预设模板

## 五、规格与审核规范

### 5.1 头像规格

- 方形头像：**512×512 像素、≤120KB**，支持 bmp/png/jpeg/jpg
- 有口径提示 PNG 建议 ≤400KB，以投放页提示为准
- 文案规格：可完整展示至少 4 个文字，超出部分可能被省略号代替

### 5.2 审核时长

品牌形象属创意/素材类组件，参考素材审核时效：**工作日一般 4 小时内、周末/节假日 24 小时内**（另一相邻口径为 1-2 工作日、一般 5-6 小时，高峰期可能延长）。知识库无品牌形象单独的精确实效，以实际审核结果为准。

### 5.3 品牌名称审核要点

**必达要求**：企业名称需体现**品牌信息/主体信息/简称**，简称必须**包含业务内容**。

| ✅ 支持 | ❌ 不支持 |
|--------|----------|
| 商标、品牌名称、App 名称（七猫、滴滴打车） | 截取公司主体名称的部分文字当简称（缺业务属性） |
| 含业务属性的公司简称（搬大师搬家） | 单独人物名称/明星艺人名（王老师、刘经理） |
| 公司全称 | 无意义字母数字（纯拼音、拼音首字母、与品牌无关的英文/数字组合） |
| — | 单独使用地域名（北京、上海） |

### 5.4 头像审核要点

**必达要求**：头像需体现**业务属性**，须与推广内容**有关联**。

| ✅ 支持 | ❌ 不支持 |
|--------|----------|
| 真人头像（须与推广内容关联：战争游戏用"美女军官"、金融用客服/职场着装、教育用学习场景生活照、电商用商品/模特图、美妆用关联形象） | 单独二维码 |
| 体现业务的品牌 logo/图形 | 真实/仿造的证件、资质图 |

## 六、修改更新与在投广告影响

### 6.1 修改路径

| 类型 | 修改方式 |
|------|---------|
| 自定义类 | 【资产 → 创意资产管理 → 品牌形象】→ 对应品牌右侧【编辑】→ 改头像/名称 → 重新提交 |
| 视频号/公众号/小店店铺类 | 头像名称由授权账号**自动拉取**，改**源头账号**信息后自动体现，品牌形象处不能直接改 |
| 微信小店商品"推广形象" | 商品托管/推广详情页可改，**1 天限改 1 次**，改后素材**重新送审** |

### 6.2 对在投广告的影响（关键结论）

- 修改品牌形象（头像/名称）属于**修改创意内容**，会**触发重新审核**
- **审核机制**：审核完成前，**在投广告以原（旧）品牌形象继续投放，不会下线停投**；新形象**审核通过后自动替换**展示；**审核不通过则维持原品牌形象继续投放**
- 建议改前预留审核时间，避免影响关键节点的品牌露出
- 注：此为"修改创意内容/品牌形象类组件"的通用审核替换机制，品牌形象组件单独的逐字说明知识库未记载，与素材/创意修改规则一致

---

## 七、数量规则

- **账户维度**：官方知识库**无明确数量上限**；可确认的相邻规则——账户维度组件暂不限制创建总数，但按**内容唯一性去重**（内容完全一致的组件只保留一个），实际以投放端系统提示为准
- **创意维度**：品牌形象是创意中的**固定组件**，创建创意时"选择品牌形象"环节选 **1 个**——一条创意通常绑定 1 个品牌形象，无"一条创意挂多个品牌形象"的用法
