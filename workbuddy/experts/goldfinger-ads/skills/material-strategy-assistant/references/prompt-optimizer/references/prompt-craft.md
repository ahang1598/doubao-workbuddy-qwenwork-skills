## 提示词生成模板（需求描述 / Brief 风格）

根据图片类型，选择对应模板。**关键：不是描述画面，而是描述需求**——像给设计师、摄影师或艺术家下brief一样。

### 模板 A（影像类 / 摄影 / 电影感）—— 摄影Brief风格

**核心思路**：告诉AI你要拍什么、怎么拍、什么情绪、什么用途

**结构**：
```
[用途说明] + [主体与行为描述] + [拍摄要求：构图/镜头/光影] + [情绪与风格参考] + [技术规格与输出要求]
```

**❌ 错误示例（画面描述）**：
> 一位年轻女性，一只眼睛上方戴着光滑的机械植入体，独自坐在雨水条纹的窗边，她的剪影映在夜晚霓虹灯闪烁的城市景观中...

**✅ 正确示例（需求描述/Brief）**：
> 生成一张电影感肖像照片，用于科幻电影海报。主体是一位年轻女性，坐在窗边，窗外是霓虹城市夜景。需要捕捉孤独忧郁的情绪，参考《银翼杀手2049》的视觉风格。使用85mm镜头，浅景深，确保背景虚化但城市灯光形成美丽的光斑。输出8K分辨率，超写实纹理，适合大尺寸印刷。

**另一个示例（产品摄影）**：
> 为高端手表品牌创作一张产品摄影。手表平放在深色大理石桌面上，侧光照射，在表盘上形成精细的高光。背景是模糊的办公室环境，暗示成功商务人士的生活方式。需要微距细节，展现表盘纹理和皮革表带的质感。输出4K分辨率，适合电商详情页使用。

### 模板 B（设计类 / 海报 / 插画 / 信息图）—— 设计Brief风格

**核心思路**：告诉AI你要设计什么、给谁用、什么信息层级、什么风格、什么规格

**结构**：
```
[用途与受众说明] + [网格系统与信息架构] + [文字层级与字号比例] + [核心视觉隐喻与主体] + [风格与质感要求] + [技术规格与输出要求]
```

**❌ 错误示例（画面描述）**：
> 一张竖版音乐节海报，带有0.5英寸的白色边距，为"平行世界文学节2026"设计，版面有清晰的视觉层级：左上角是粗体几何无衬线体的大标题...

**✅ 正确示例（需求描述/Brief）**：
> 设计一张竖版音乐节海报，尺寸750×1000px，留白边距。活动名称是"平行世界文学节2026"，目标受众是18-35岁的文艺青年。网格系统：上方40%为主视觉区，下方60%为信息区。信息层级：主标题（画面高度约1/7，最粗字重）在上方居中，副标题（主标题字号的55%，行高1.4倍）在其下方，日期场地（最小字号，底部对齐）。主要视觉元素是一本打开的书，书页变成鸟群，然后变成星图——这个隐喻要表达"文字让想象力飞翔"的概念。风格融合1920年代俄罗斯构成主义和现代绘本风格。色彩方案：午夜蓝主色，赭石棕辅助色，纯白强调色。需要丝网印刷质感，适合街头张贴和社交媒体分享。

**另一个示例（信息图）**：
> 创作一张信息图，解释"如何在家烘焙咖啡豆"。目标读者是咖啡爱好者初学者。版式要求：上方是大标题，中间是6个步骤的图解，下方是小贴士和注意事项。每个步骤要用图标+简短文字说明，风格是手绘插画风，温暖友好。色彩方案：咖啡棕主色，奶油白背景，绿色强调色用于小贴士。输出尺寸是A4，300DPI，适合打印和网页使用。

### 模板 C（艺术抽象类 / 纯艺术）—— 艺术创作Brief风格

**核心思路**：告诉AI你要创作什么类型的艺术品、表达什么情绪/概念、用什么技法、什么质感

**结构**：
```
[艺术类型说明] + [情绪/概念表达目标] + [色彩与构图要求] + [技法与材料质感] + [输出规格与用途]
```

**❌ 错误示例（画面描述）**：
> 一幅抽象表现主义绘画，深木炭色背景上有着大胆的猩红色和金色笔触，构图螺旋从画面左下角引导视线到中心...

**✅ 正确示例（需求描述/Brief）**：
> 创作一幅抽象表现主义绘画，表达"动荡的喜悦"这种复杂情绪——既有能量和激情，又有一丝不安。色彩以深木炭色为背景，用猩红色和金色创造大胆的笔触。构图需要有螺旋感，引导视线从画面左下角流向中心。使用厚涂技法，让调色刀痕迹可见，灵感来自德·库宁和晚期特纳。需要8K分辨率扫描级细节，适合艺术印刷和画廊展示。

**另一个示例（3D抽象艺术）**：
> 创作一件3D抽象艺术品，探索"秩序与混沌"的对比。主体是一组几何形状，从整齐的立方体逐渐演变成破碎的不规则碎片。材质是半透明的蓝色玻璃，内部有光线折射。背景是纯黑色，让玻璃的折射成为焦点。需要超写实渲染，展现玻璃的透明感和光线追踪效果。输出8K分辨率，适合作为专辑封面或艺术展览背景。

## 端到端完整示例

以下是从一张图片出发，使用 SOCAWT 框架完整分析，最终转化为 brief 的完整流程。这是最能体现"设计思维"的练习。

### 示例：一张人像摄影

**阶段 1：第一眼观察（3 秒）**
> 一张年轻女性的肖像照，光线柔和，背景虚化，看起来很有"电影感"。

**阶段 2：SOCAWT 六维分析**

**S — Space（空间构图）**
- 构图：近景特写，从肩膀以上裁切，人物略微偏右（三分法右交点）
- 视角：平视角度，有亲近感和真实感
- 镜头感：85mm 左右的中长焦，背景被压缩虚化
- 景深：极浅景深，背景完全虚化成奶油色光斑
- 动势：静态构图，但人物眼神看向镜头左上方，创造微妙的视线引导

**O — Object（主体对象）**
- 主体：年轻女性，约25岁
- 外貌：深棕色头发带有金色挑染，自然散落
- 表情：略带自信的微笑，眼神直视镜头
- 状态：放松但挺拔的肩膀姿态

**C — Core（核心视觉）**
- 视觉锚点：人物的眼睛（眼神接触是绝对的视觉焦点）
- 核心隐喻：真实、自然、不做作的美——不是"完美"而是"真实"
- 决定性瞬间：捕捉到的是"被看见"的瞬间——她直视观者，建立连接
- 视觉张力轴：真实 vs 修饰（画面刻意保留了自然的皮肤纹理，不追求过度磨皮）

**A — Artistry（艺术表现）**
- 质感对比：柔滑的皮肤 vs 粗糙的头发纹理
- 强调技巧：眼神被 catch light（眼神光）强调
- 艺术手法：自然主义摄影，参考当代时尚杂志的"无修图"美学

**W — Wash（色彩色调）**
- 光照体系：自然窗光从侧面 45 度射入，属于柔和的漫射光
- 阴影：柔和渐变，没有锐利边缘
- 色彩温度：整体偏暖，皮肤呈现蜜桃色调
- 背景色彩：虚化的背景呈现柔和的蓝绿色调（可能是窗外的植物），与暖色皮肤形成冷暖互补
- 阴影色：偏冷蓝色，不是死黑

**T — Type（视觉层级）**
- 无文字。视觉层级：第一层是眼睛 → 第二层是面部轮廓 → 第三层是头发和虚化背景

**阶段 3：转化为 Brief**

```
创作一张当代时尚肖像摄影，用于高端护肤品牌广告。

主体是一位年轻女性（约25岁），深棕色头发自然散落，带有金色挑染。
她直视镜头，眼神要有"被看见"的真实感——不是完美的模特照，
而是有生命力的自然表情。捕捉到她略带自信的微笑。

构图是 85mm 镜头的中长焦特写，从肩膀以上裁切，
人物位于画面右侧三分法交点。使用 f/1.8 级别的浅景深，
背景完全虚化成奶油般的 bokeh。

光照：自然窗光从侧面 45 度射入，柔和的漫射光创造自然的面部体积感。
阴影边缘要柔和渐变，不是锐利切割。阴影区域偏冷蓝色（不是死黑）。
人物眼睛中要有自然的 catch light（眼神光），这是生命力的关键。

色彩：整体偏暖色调，皮肤呈现蜜桃色调。背景虚化为柔和的蓝绿色调，
与暖色皮肤形成冷暖互补。参考《Kinfolk》杂志的自然美学。

质感要求：保留自然皮肤纹理，不要过度修饰。传达"真实就是美"的品牌理念。
输出：竖版 3:4，4K分辨率，适合社交媒体和品牌官网。
```

> **注意**：这个 brief 没有写"rule of thirds"、"f/1.8"、"golden hour"等技术参数，而是用自然语言描述需求——因为 AI（GPT-Image-2、即梦）理解的是"什么意思"，而不是"什么参数"。

## 实战技巧：如何组织高质量的需求描述（补充资料）

### 一、组织需求描述的四步法

写一个好的需求描述/Brief，建议按照以下四个步骤进行：

**第一步：明确图片类型**
- 是海报、信息图、UI 页面、商品主图还是写实照片？
- 先点明"这是一张什么图"，为后续描述定调

**第二步：列出主体与视觉重点**
- 主角是谁？
- 最想让人一眼看到什么？
- 横版还是竖版？主体居中还是偏左？留白怎么做？

**第三步：补充关键细节**
- 材质、光线、镜头感、版式、颜色、氛围、姿态等
- 这些细节让AI理解"具体要什么"，而不是"大概那样"

**第四步：添加限制条件**
- 有哪些元素必须有、不该有、不能动？
- 文字要求、logo 是否出现、背景能否变化

**关键原则**：
- 把以上四步写完整后，一个实用 prompt 更像"任务单"，不是"咒语"
- 复杂场景下建议分段、换行、短句写，不用刻意拼成长句
- 对实际使用来说，能复查、能补充、能继续改，比文笔更重要

---

### 二、场景补充说明

#### 1. 带字图片

**务必将出现的原文用引号或大写标出**
- ✅ 正确：`"NEW ARRIVAL"`、`"限时优惠"`
- ❌ 错误：只写"促销标题"，否则模型会自行猜内容

**明确说明文字样式**
- 包括字体、大小、颜色、位置、对齐等
- 对带字图来说，文字放对位置，往往比"把字画出来"更难

**小字和版面多时，优先用 medium/high 档**
- 官方建议：小字体、信息图、多字体布局场景首选 medium 或 high
- low 更适合先试结构和方向，文字一多就容易返工

#### 2. 图像编辑（改图）

**重点不是"要改什么"，而是"除了这个，别动别的"**
- OpenAI 编辑场景反复提醒用 `change only X` 和 `keep everything else the same`
- 比如只写"背景换成咖啡馆"，模型很可能把整张图重做一遍，反而不准

**更可取写法示例**：
```
这是一张产品发布海报，竖版构图。

主体是一部放在深色桌面的银色手机，手机保持当前外形比例和摆放角度不变。

标题文字使用 "NEW ARRIVAL"，放在上方居中，白色无衬线字体，字距略宽。

桌面有轻微反光，整体风格克制、真实，强调金属质感和边缘高光。

不要出现额外文字，不要出现品牌 logo，不要增加配件，不要改变主体位置。
```

**这么写清楚任务类型、主体、细节和约束，稳定性明显提升。**

---

### 三、实用提示

1. **效果稳定的 prompt，通常不是词多，而是结构清楚**
   - 中文信息图、社媒封面、UI、商品页这类场景，拼的不是修辞，而是规格描述

2. **复杂任务最好拆成两到三步，不要一次全压进去**
   - 如果一条提示词同时要求：重做构图、换背景、加文字、改风格、保主体
   - 最好拆成 2-3 步，逐步完成

3. **一句话总结：写提示词，少写空泛形容，多写任务、对象和边界**
   - 越像可执行说明，结果通常越稳

4. **能复查、能补充、能继续改，比文笔更重要**
   - 复杂场景下建议分段、换行、短句写
   - 不用刻意拼成长句

## 高级技巧（如何写好需求描述 / Brief）

### 1. 明确用途和目标受众
不要只说"画一个咖啡杯"，要说：
- ❌ "一个咖啡杯，冒着热气"
- ✅ "为精品咖啡品牌设计一张产品海报，目标受众是25-35岁的都市白领。画面中心是一个白色陶瓷咖啡杯，冒着轻柔的热气。需要传递'早晨的第一杯咖啡'的温暖感。背景是柔和的浅木色，暗示自然和质感。输出尺寸是 square 1080×1080px，适合Instagram发布。"

### 2. 用类比和参考描述风格
不要只说"梵高风格"，要说：
- ❌ "梵高风格的星空"
- ✅ "创作一幅星空夜景，笔触要像梵高那样充满能量和旋转感，色彩要大胆使用蓝色和金色对比。但不是直接模仿《星夜》，而是用梵高的笔触语言来表达现代城市夜景——高楼大厦变成抽象的几何形状，窗户的灯光像星星一样闪烁。输出8K分辨率，适合艺术印刷。"

### 3. 描述情绪和氛围，而不只是视觉元素
不要只说"孤独的人"，要说：
- ❌ "一个人坐在窗边，看起来很孤独"
- ✅ "捕捉一种'安静的孤独'情绪——不是悲伤，而是一种自我反思的宁静。主体是一位年轻人，坐在窗边，侧脸朝向窗外。光线从窗外照进来，在室内形成柔和的光影对比。窗外是模糊的城市夜景，暗示着更大的世界。画面要有电影感，参考《咖啡公社》的视觉风格。输出4K分辨率，适合用作小说封面。"

### 4. 指定技术要求和输出规格
在brief中明确说明用途和规格：
```
用途：科幻杂志封面
尺寸：210×297mm，A4竖版
分辨率：300 DPI，适合印刷
色彩模式：CMYK
风格参考：《银翼杀手2049》+ 斯派克·琼斯电影的色彩感
情绪：孤独、未来感、一丝希望
```

### 5. 跨界混搭的写法
描述不同风格的结合，用"但"、"然而"、"同时"等转折词：
- "未来主义机械，但用中国水墨画的笔触和留白表现"
- "赛博朋克城市景观，但用梵高的笔触和色彩呈现，创造一种'高科技、低生活'的荒诞感"
- "古典肖像画，但主体换成机器人，保持伦勃朗的光影，探讨'什么是人性'的议题"

### 6. 媒介与物性描述（去"AI 塑料感"）
描述真实的物理媒介质感，避免使用"完美"、"无瑕疵"等词：
- "丝网印刷油墨感，颜色有轻微的套色错位，边缘不够锐利"
- "30年代旧书封面的烫金凹凸效果，有磨损和氧化痕迹"
- "手工丝印质感，纸张纹理清晰可见，油墨有不均匀的厚重感"
- "水彩画风格，颜色有自然的流动和混色，边缘柔和，有水滴痕迹"

### 7. 使用"任务规格式"写法（适用于复杂需求）
对于带文字的图片、信息图、商品图等复杂需求，使用结构化brief：

```
【项目类型】竖版活动海报
【尺寸规格】750×1000px，留白边距
【活动信息】"平行世界文学节2026"，日期：2026年7月15-20日，地点：城市文化艺术中心
【目标受众】18-35岁文艺青年，喜欢阅读和独立文化
【信息层级】
  - 主标题："平行世界文学节2026"（最大，最醒目）
  - 副标题："当文字打破维度"（中等大小）
  - 详细信息：日期和地点（较小，底部）
【视觉隐喻】一本打开的书，书页变成鸟群，然后变成星图——表达"文字让想象力飞翔"
【风格参考】1920年代俄罗斯构成主义 + 现代绘本（参考陈志勇）
【色彩方案】
  - 主色：午夜蓝（#191970）- 60%
  - 辅助色：赭石棕（#CC5500）- 30%
  - 强调色：纯纸白（#FFFFF0）- 10%
【质感要求】丝网印刷质感，可见纸张纹理和油墨不均匀感
【输出要求】8K分辨率，适合街头张贴和社交媒体分享
```

## 去"AI 塑料感"：缺陷美学专题

当代 AI 生成图像最大的隐形杀手不是"不像"，而是**"太像了"**——完美无瑕的皮肤、过于光滑的表面、毫无意外的构图。人类视觉已经对"AI 完美感"产生了审美抗体。有意识地加入缺陷和物性，是区分"AI 图"和"好设计"的分水岭。

### 缺陷美学的 5 个维度

| 维度 | 缺陷类型 | 写作示例 | 效果 |
|---|---|---|---|
| **材质缺陷** | 磨损、氧化、划痕、污渍 | "30年代旧书封面的烫金凹凸效果，有磨损和氧化痕迹" | 增加历史感和真实触感 |
| **光学缺陷** | 过曝、镜头眩光、运动模糊、景深不完美 | "画面左上角有轻微过曝，阳光从窗帘缝隙射入形成自然眩光" | 增加摄影感和现场感 |
| **印刷缺陷** | 套色错位、油墨不均、纸张纹理 | "丝网印刷油墨感，颜色有轻微的套色错位，边缘不够锐利" | 增加手工质感和工艺温度 |
| **手绘缺陷** | 笔触不完美、颜料流淌、铅笔草稿线 | "水彩画风格，颜色有自然的流动和混色，边缘柔和，有水滴痕迹" | 增加艺术家手作感 |
| **结构缺陷** | 不对称、倾斜、不规则边缘 | "木桌表面有自然裂纹，不是机器切割的完美直线" | 打破 AI 对称性，增加有机感 |

### 缺陷美学的写作原则

1. **不要过度描述"完美"**：避免"完美无瑕的表面"、"毫无瑕疵的材质"、"绝对对称的构图"等词
2. **主动描述"不完美"**：加入磨损、痕迹、随机性、手工感
3. **缺陷要有目的**：不是为瑕疵而瑕疵，而是为"真实感"和"故事感"服务
4. **控制在 10%-20%**：缺陷是点缀，不是主体。一张图有 1-2 处精心设计的"不完美"就够了

> **一句话总结**：AI 画的是"理想中的样子"，设计师要的是"真实存在的样子"。给 AI 的 brief 里，少一些"完美"，多一些"lived-in 的痕迹"。

## 进阶技巧：从优秀案例中学习

通过学习其他高质量的提示词写法，我们可以进一步提升需求描述/Brief 的质量。

### 一、JSON 模板格式（给 Agent 调用）

对于程序化调用或 Agent 自动化场景，使用 JSON 格式结构化提示词：

**优势**：
- 结构化字段，方便程序解析和复用
- 明确 `type` 字段，指定图片类型
- `constraints` 字段非常重要，明确"不要什么"

**UI与界面示例**：
```json
{
  "type": "UI Screenshot",
  "platform": "iOS",
  "product": "Fitness App",
  "layout": "Card-based feed with bottom tab bar",
  "style": {
    "theme": "Dark Mode",
    "primary_color": "Neon Green",
    "typography": "Clean sans-serif"
  },
  "content": {
    "header": "Today's Activity",
    "cards": [
      {"title": "Running", "data": "5.2 km", "button": "Start"},
      {"title": "Calories", "data": "340 kcal"}
    ]
  },
  "constraints": "High fidelity, readable text, 9:16 aspect ratio"
}
```

**图表与信息可视化示例**：
```json
{
  "type": "Infographic",
  "topic": "Urban Metabolism",
  "audience": "General Public",
  "structure": {
    "title_area": "城市生命系统图谱",
    "layout": "Isometric cutaway, 12 numbered panels",
    "modules": [
      {"title": "能源", "icon": "lightning", "text": "Power flows"},
      {"title": "水循环", "icon": "water_drop", "text": "Water flows"}

  "style": {
    "aesthetic": "Scientific atlas",
    "colors": "Low saturation, color-coded flows",
    "background": "Light paper texture"
  },
  "constraints": "No cyberpunk, no gibberish text, strict structural layout"
}
```

**使用建议**：
- 当需要通过 Agent 或程序自动生成提示词时，使用 JSON 格式
- 手动编写提示词时，也可以参考 JSON 的字段结构来组织内容

### 二、分阶段写作方法（PHASE 1/2/3/4）

对于复杂任务，使用分阶段方法，逐步完成：

**品牌包络产品广告模板（四阶段法）**：

```
INPUT: [产品图]、[品牌身份]、[输出格式]

PHASE 1 / ANCHOR（锚定品牌世界）：
用 2 行描述[品牌身份]，包括调色板、材质、光影和情绪。

PHASE 2 / INJECT（注入产品）：
把[产品]放入这个品牌世界中，产品要服从品牌气质和环境语言。

PHASE 3 / FORMAT（指定输出格式）：
指定[输出格式]，例如 hero 图、方形广告、竖版 story 或电商头图。

PHASE 4 / SIGNATURE（加入品牌签名）：
加入[品牌元素]，例如颗粒、阴影、叠加纹理、包装符号或图形边框。
```

**变量**：
[品牌身份] / [产品] / [输出格式] / [品牌元素]

**目标**：同一品牌下替换不同产品时，视觉世界保持一致，广告图仍然有明确主角和商业质感。

**使用建议**：
- 当一条提示词同时要求：重做构图、换背景、加文字、改风格、保主体时
- 最好拆成 2-3 步，逐步完成，不要一次全压进去

### 三、详细约束条件（负面提示）

从优秀案例中学习：明确"不要什么"和"要什么"同样重要。

**通用约束模板**：
```
约束：
- 不要：[列表，例如：不要乱码文字、不要占位文本、不要过度拼贴]
- 必须：[列表，例如：必须显示指定的中文、必须保持主体位置不变]
- 禁止：[列表，例如：禁止使用默认字体、禁止改变品牌色]
```

**带字图片的特殊约束**：
```
文字约束：
- 务必将出现的原文用引号或大写标出，例如："NEW ARRIVAL"
- 明确说明文字样式：包括字体、大小、颜色、位置、对齐等
- 小字和版面多时，优先用 medium/high 档
```

**图像编辑（改图）的特殊约束**：
```
编辑约束：
- 重点不是"要改什么"，而是"除了这个，别动别的"
- 使用 `change only X` 和 `keep everything else the same`
- 例如：只写"背景换成咖啡馆"，模型很可能把整张图重做一遍，反而不准
```

**更可取写法示例**：
```
这是一张产品发布海报，竖版构图。

主体是一部放在深色桌面的银色手机，手机保持当前外形比例和摆放角度不变。

标题文字使用 "NEW ARRIVAL"，放在上方居中，白色无衬线字体，字距略宽。

桌面有轻微反光，整体风格克制、真实，强调金属质感和边缘高光。

不要出现额外文字，不要出现品牌 logo，不要增加配件，不要改变主体位置。
```

### 四、场景化模板示例

#### 1. UI与界面

**常规模板**：
```
为[产品类型]生成一张[平台，如 iOS/Android/Web]界面图。
核心功能：[功能点A]、[功能点B]、[功能点C]。
视觉风格：[极简/科技/拟物]，主色[颜色]，强调色[颜色]。
布局：[顶部导航/双栏/卡片流]，信息层级清晰，留白充足。
输出：高保真UI截图，文字清晰可读，比例[9:16/16:9]。
```

**避坑指南**：
- 不要给模糊指令：明确"平台 + 比例 + 布局"，否则模型会像个实习生一样乱排版
- 强制文字锁定：要求"文字绝对可读，必须显示指定的中文"，避免出现乱码按钮和毫无意义的火星文
- 截图区分平台特征：X（Twitter）有蓝勾认证、转发/引用区分；抖音有音乐碟片和点赞动画；小红书有双列瀑布流特征。生成前指定平台，否则模型会混搭

#### 2. 图表与信息可视化

**常规模板**：
```
生成[主题：明确、具体，避免宽泛。例如："老年人日常健康管理指南"而非"健康"]信息图，目标读者为[人群:细化人群特征，如年龄段、职业、兴趣等]。
结构：标题区 + [3-5]个模块（每模块含图标、短标题、1-2句说明,模块间逻辑：可用箭头、颜色区分或连接线提示信息流或关系等适当的方式）。
图表类型：[流程图/对比图/关系图/时间线]。
风格：[专业报告/科普插画/儿童教育等]，主色[颜色]，背景[浅色/深色]。
输出：信息层级清晰、可读性高的中文信息图。
```

**避坑指南**：
- 控制模块数量：强制定制"模块数量"和"图表类型"，能极大降低画面混乱和信息溢出
- 文案克制：图表场景优先使用短句文案，千万不要把大段正文塞进画面里，模型不是排版工人

#### 3. 海报与排版

**概念字体海报模板**：
```
Create ONE finished premium conceptual typography poster for the exact title:

"[标题/词语/短句]"

Single poster only. No moodboard, grid, presentation board, mockup, captions, prompt text, process sheet, or sample labels.

The title must be the dominant visual structure of the poster: huge, readable, and spelled exactly. Do not translate, shorten, replace, or misspell it. Do not add other large readable text.

Silently interpret the title's meaning, mood, cultural aura, symbolic associations, psychological tension, and visual rhythm. Turn that interpretation into one strong visual metaphor.

Typography is the hero. Design custom-looking letterforms whose weight, width, contrast, spacing, rhythm, distortion, negative space, edge quality, and ink texture express the temperament of the title. The type should feel intentionally designed, not like a default font.

If the title refers to a widely known person, make a large editorial portrait or half-body figure a major visual presence, occupying roughly 40%-70% of the composition. The figure should interact with the typography: overlapping the letters, emerging from them, being framed by them, casting shadows on them, breaking through them, or being partially hidden behind them.

For abstract or non-person titles, use a human figure, landscape, object, or atmospheric setting only when it strengthens the meaning. It must interact with the typography and deepen the concept, not decorate it.

Use a restrained 4-6 color system matched to the theme: dominant background color, primary typography color, figure / landscape tone, emotional accent color, muted support color, and subtle paper / ink texture tone.

Composition style: high-end editorial poster, museum-quality graphic design, dramatic scale, strong hierarchy, few elements, intelligent whitespace, bold flat color areas, sharp cropping, silkscreen / lithograph / risograph grain, paper fibers, subtle ink imperfections, refined visual tension.

Avoid generic word art, glossy 3D lettering, random icons, stock-photo realism, cluttered collage, excessive grunge, tourist clichés, official logos, copied slogans, copied campaign aesthetics, unrelated text, and misspelled typography.
```

**避坑指南**：
- 不要偷懒：写清"主视觉到底是什么玩意儿"，不要只丢一句"做一张海报"就指望出神图
- 文案硬编码：主标题与副标题都要写死，否则模型会给你疯狂加戏，自动瞎编不知所云的文字
- 字体海报先锁标题：概念字体海报必须明确"标题必须拼写完全正确且成为主视觉"，否则很容易变成漂亮但不可读的字效图
- 图像要和字互动：人物、物体或场景必须嵌入、遮挡、穿过或托起字形，只摆在旁边会像装饰素材
- 禁止 moodboard 化：明确要求 single poster only，避免模型生成多方案展示板、过程稿或样张拼贴

#### 4. 商品与电商

**常规模板**：
```
生成[商品名]电商主图，卖点为[卖点1]、[卖点2]。
场景：[纯色棚拍/生活方式场景]，镜头：[特写/半身/全景]。
材质细节：[材质关键词]，灯光：[柔光/侧光/轮廓光]。
附加元素：[价格角标/卖点icon/促销文案]。
输出：电商平台可直接使用的商品展示图。
```

**避坑指南**：
- 材质和光影是灵魂：一定要堆叠材质（如"磨砂质感"）和灯光（如"轮廓光"）的关键词，商品图一旦没有光影，立刻变成地摊货
- 别把促销贴满全屏：文案只给核心的 1-2 句（如"新品上市"），字多了画面就毁了

### 五、一句话总结

**写提示词，少写空泛形容，多写任务、对象和边界。越像可执行说明，结果通常越稳。**

**从优秀案例中学习的关键**：
1. **结构化思维**：所有模板都遵循 `类型/平台 → 核心内容 → 视觉风格 → 布局 → 约束条件 → 输出要求`
2. **具体化**：用"35mm 镜头"代替"浅景深"，用 f/1.4 代替"背景虚化"
3. **约束条件至关重要**：明确"不要什么"和"要什么"同样重要
4. **JSON 格式**：方便程序化调用和 Agent 自动化
5. **分阶段方法**：复杂任务拆解成多个阶段，逐步完成

### 即梦（Jimeng）—— 详细写作指南
- 支持自然语言brief，但喜欢具体的视觉要求
- 建议：使用详细的需求描述，明确用途、风格、输出规格
- ❌ 错误示例（画面描述）："一个女孩站在雨中，雨水打湿她的头发，霓虹灯的光反射在水洼里"

## 核心原则总结（需求描述 / Brief 风格）

1. **不是描述画面，而是描述需求** —— 像给设计师下brief一样，说明用途、受众、目标
2. **用完整句子写brief，不堆砌关键词** —— AI需要理解"为什么"，而不仅仅是"是什么"
3. **明确用途和输出规格** —— 说明图片用来做什么，输出多大、什么格式、什么分辨率
4. **描述情绪和氛围，而不只是视觉元素** —— "孤独的宇航员"vs"传达深深孤独和对家园的思念"
5. **使用类比和参考，让AI理解你的意图** —— "梵高笔触"vs"充满能量和旋转感的笔触，大胆的蓝金对比"
6. **针对不同模型调整brief风格** —— 即梦喜欢具体视觉要求，GPT-Image-2擅长理解复杂情绪和语境
7. **加入媒介与物性描述，去"AI塑料感"** —— 描述真实的物理质感，避免"完美无瑕"
8. **永远给一个参考系作为锚点** —— "梵高风格"不够，"梵高的笔触语言+现代城市夜景"才够。视觉是相对感知，没有锚点就没有方向

**关键心态转变**：
- ❌ 旧思维："我要让AI画一张图"
- ✅ 新思维："我要给AI下一个设计brief，让它帮我实现这个需求"

**提示词写作的秘诀**：
1. 先通过SOCAWT框架**解读图片**（分析六个维度）
2. 然后将分析结果转化为**需求描述/brief**，而不是画面描述
3. 在brief中明确：用途、受众、情绪、风格参考、技术要求、输出规格
