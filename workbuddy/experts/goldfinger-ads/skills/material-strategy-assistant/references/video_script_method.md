# 视频脚本方法（video_script_method）

> 本文件是 material-strategy-assistant 的**可独立编辑**方法板块，封装"从策略里已规划的视频，产出一份完整视频脚本表"的全套方法。
>
> 🚨🚨 **启用边界（最高优先级，务必遵守）**：
> - **只有在本项目触发了视频需求时才用本文件**——即第3步「素材数量测算规则」判定要做视频（预算 >10000 元，或用户明确要视频/点名投视频号）。
> - **没有视频需求时，本文件完全不参与**，skill 的输出（表头→策略→执行手册表一→下一步建议）与原来一字不差，绝不出现任何视频脚本表内容。
> - 视频脚本表**并入执行手册**：作为「表一 · 素材制作总表」之后的「表二 · 完整视频脚本表」，只覆盖策略里已规划的视频（哪几类、各几条），**不新增、不改动策略里的视频规划**。
> - 视频类型命名**严格用官方四类原名**：情景剧 / 单人口播 / 动图 / 混剪（禁自创，禁改名如"剧情"）。

---

## 一、总原则

1. **脚本表严格服从策略**：策略「创意思路和规划」里规划了几条视频、各是什么类型，视频脚本表就产出对应的几条，一一对应，不多不少、不改类型。
2. **演员只给提示词、不实际生图**：本方法产出演员**形象生成提示词（真人版）**，由用户自行拿去生图。**不调用生图工具**。
3. **一致性靠"固定演员"**：先把该项目所有视频里出现的角色去重，固定成一个演员库；每个演员一版真人形象提示词，全片各分镜复用同一演员设定，保证"同一个人"。
4. **分段视频提示词=每段独立自带质感词**：生视频平台是每段分别生成再拼接，所以每段提示词都要自带完整质感词，用户复制单段即可进平台生成。

---

### 🚨🚨🚨 分镜三条铁律（v2，最高优先级，写分段提示词必须逐条遵守）

这三条是把脚本拆成分段提示词时的核心规则，**推翻了旧版"每段 6s、段间靠文字承接、按节奏切景别"的做法**——旧做法会让成片跳、让用户跑太多次模型、让模型读不懂衔接。

**铁律 1 · 段长拉到 12-15s，整片压到 3 段左右**
- AI 生视频模型单段上限约 15s。**不要再一段只做 5-7s**——那样一支 30 多秒的视频要拆 5+ 段，用户得跑 5+ 次模型，太费。
- **每段做 12-15s**（留 1-3s 缓冲防模型念不完被截），整片分段数压到 **2-3 段**。
  - 单人口播（约 30s）：拆 **2-3 段**（如 铺垫 / 方案 / CTA，或 痛点 / 方案+CTA）。
  - 情景剧（约 40-45s）：拆 **3 段**。
- 台词偏满卡不进 15s 时，把末句（常是 CTA）单独拆成一个约 4s 的短段，宁可多一段也别让模型截断。

**铁律 2 · 段间衔接靠"视觉锚点"，绝不用"承接上段"这类文字**
- ⚠️ **模型每段独立生成、只看到本段提示词，根本不知道"上段"是什么**——写"承接上段A前倾的姿态""机位不变框架收紧"等于废话，模型读完就丢。
- **彻底删掉**所有"承接上段/上一段/延续前段"字眼。
- 改用 **`[视觉锚点]` 行**：每段提示词里写死一行**完全相同**的绝对视觉设定——**同一演员（外貌/年龄/服装）· 同一景别 · 同一机位 · 同一场景 · 同一光线**，各段一字不改。模型按相同绝对设定渲染，拼接自然不跳。
- 本质：跨段衔接的"信号"从"文字指令"迁移到"每段都写死的相同视觉参数"。

**铁律 3 · 场景不变，全程锁死同一景别，不为节奏硬切**
- 只要演员没有物理换场景（一直坐工位 / 一直在沙发 / 一直在茶水间），**整支视频就用同一景别**（如全程中景），**不再**为了"有节奏感"而硬切近景/特写/全景。
- 情绪推进靠**动作、表情、台词节奏、手势**，**不靠景别切换**。
- **唯一允许换景/换景别的情形**：场景物理上真的变了（如人物从工位走到茶水间）——那才是真换景。
- 反面（禁止）：单人口播"段1中景→段2近景→段3特写"这种为变而变的切换；情景剧"全景建场→双人近景→退回中景"反复横跳。

## 二、产出步骤

### 步骤 1 · 固定演员阵容
扫描本项目要做的所有视频（按策略规划的类型/条数），把出现的角色去重成演员库，标注每人：编号、角色、出现在哪些视频、一句话人设、选角气质。主角（出镜最多者）优先定死。
- 单人口播/动图：通常 1 个主播（+可选出镜配角）。
- 情景剧：2-3 个角色 + 场景。
- 混剪：无出镜主播（画面+旁白），可无演员或仅产品/手部出镜。

### 步骤 2 · 演员形象生成提示词（真人版）
每个演员写**一版真人版**形象提示词，格式：
```
半身正面定妆照，一位[年龄][性别][气质特征]，[发型][服装][神态][背景]。[通用画质词]
```
通用画质词统一：`真实人像摄影，自然光，柔和肤色，浅景深，清晰能看清五官，无广告修图痕迹`

> 一致性铁律：每个演员只定 1 张定妆参考图，全片所有分镜都用它垫图；产品/道具也定 1 张参考图垫同款。

### 步骤 3 · 分段视频提示词（每段独立自带质感词，直接进平台）
把每条视频拆成若干段，**每段都是一条可独立复制生成的提示词**。🚨 严格套用「分镜三条铁律」：段长 12-15s、每段写死 `[视觉锚点]` 行、场景不变全程同景别。分段提示词本身已含画面、动作、台词，用户读它即可看懂这条视频讲什么，**无需再单写一段纯脚本**。

> 🚨 **画面/动作描写不能单薄**（旧版常见毛病）：每段的"画面"要写齐**环境三件套（光线 + 关键道具 + 空间位置）**，每个出镜角色至少给 **2 条微动作（眼神/表情/手部/姿态）**。别只写"A 说…B 说…"的台词流水账——那样生出来的视频空洞、没生活感。

**格式（v2，含视觉锚点）：**
```
【段N】（时间码s）质感提示词全文。
[视觉锚点] 同一演员（外貌/服装）/ 同一景别 / 同一机位 / 同一场景 / 同一光线 —— 各段一字不改。
画面：本段景别不动，人物动作/表情/手势/台词节奏推进。
台词："……"
```
- 段号从 1 连续，段数压到 **2-3 段**（见铁律 1）。
- **每一段都要带上完整质感词**（不是只写一次后续拼接）。
- **`[视觉锚点]` 行各段完全相同**（见铁律 2）——这是拼接不跳的关键，别改。
- 只要场景没物理切换，**所有段景别一致**（见铁律 3）。
- 质感词默认用项目约定的固定质感提示词（见下方「默认质感词」，可被项目实际需求覆盖）。
- 时间码用全角括号累加，如（0-13s）（13-28s）。单人口播总时长约 30s（2-3 段），情景剧约 40-45s（3 段）。

**✅ 正例（单人口播·全程坐工位·全程中景·2 段）：**
```
【段1】（0-13s）真实自然的手机广告质感，柔和均匀布光，低饱和…（质感词全文）。
[视觉锚点] 主播A（35岁男性，浅色商务休闲衬衫）/ 中景胸部以上 / 固定机位平视 / 办公室工位（身后虚化办公环境）/ 柔和均匀顶光。
画面：主播A坐工位对镜头，说到"头大"时皱眉摊手摇头。中景不动，靠表情手势推进。
台词："很多老板想投广告，一打开后台就头大。定向、出价、创意，全是术语。"
【段2】（13-28s）真实自然的手机广告质感，柔和均匀布光，低饱和…（质感词全文，与段1一字不差）。
[视觉锚点] 主播A（35岁男性，浅色商务休闲衬衫）/ 中景胸部以上 / 固定机位平视 / 办公室工位（身后虚化办公环境）/ 柔和均匀顶光。
画面：主播A表情转轻松，手掌打节奏，最后手指向下引导。中景不动。
台词："现在有金手指，你说预算和目标——策略它定、广告它配、数据它盯、调整它做。想了解的，点下面留个联系方式。"
```

**❌ 反例（旧做法，禁止）：**
```
【段1】（0-6s）…近景：…
【段2】（6-12s）承接上段A前倾的姿态，机位不变框架收紧，中近景：…   ← 段太短（6s）+ "承接上段"模型读不懂 + 场景没变却切了景别
```

**默认质感词**（真人手机广告风；如项目另有调性要求则替换）：
```
真实自然的手机广告质感，柔和均匀布光，低饱和度自然色调（saturation 40-55%），对比度适中不过度，肤色自然偏暖黄不美白不磨皮，整体色彩克制柔和如手机前置镜头直拍效果，避免电影级浓烈调色和HDR过曝，高清细腻；需要配音，不要添加任何字幕。
```

## 三、并入执行手册的表格格式

在「表一 · 素材制作总表」之后，加「表二 · 完整视频脚本表」。10 条以内同一张表，**4 列**：

| # | 视频类型 | 演员图片生成提示词（真人版） | 分段视频提示词（每段独立自带质感词+视觉锚点，复制单段即可进平台生成） |
|:-:|---|---|---|
| V1 | 单人口播 | 【演员A·真人版】…真人形象提示词… | 【段1】（0-13s）[质感词全文]。[视觉锚点]同演员/同景别/同机位/同场景/同光线。画面：中景不动，靠表情手势推进。"…"<br>【段2】（13-28s）[质感词全文]。[视觉锚点]（与段1一字不差）。画面：…。"…" |
| V2 | 情景剧 | 【演员A·真人版】…<br>【演员B·真人版】… | 【段1】（0-15s）[质感词全文]。[视觉锚点]双人同场景/同景别/同机位。画面：…。A："…" B："…"<br>【段2】（15-30s）[质感词全文]。[视觉锚点]（同上）。…<br>【段3】（30-42s）… |

> 🚨 **视频类型列只填官方四类**：情景剧 / 单人口播 / 动图 / 混剪。条数与类型必须与策略「创意思路和规划」里规划的视频完全一致。
> 🚨 **分段提示词严守三条铁律**：段长 12-15s（整片 2-3 段）、每段写死相同 `[视觉锚点]` 行、场景不变全程同景别（详见第一节「分镜三条铁律」）。
> 🚨 混剪无出镜主播时，"演员图片生成提示词"列可填"—（无真人出镜，画面为产品/空镜+旁白）"，分段提示词列写旁白+画面分段；分段仍按 12-15s/段、写死场景+景别锚点。
> 🚨 编号用 V1、V2…（与图片素材的 1、2… 区分），承接执行手册表一。
> 🚨🚨 **视频输出分辨率备注（务必在表格附近提示用户）**：本方法只出提示词，用户拿去生成视频时——**信息流广告 720p 就够用，条件允许上 1080p 更清晰**。在交付物里表二下方加一行说明，如"视频建议输出分辨率：信息流广告 720p 够用，1080p 更好"，让用户生成时按此设置。

## 四、实操要点（若要在 WorkBuddy 内直接生视频，务必看这节）

> 本方法默认「只给提示词、不实际生图/生视频」。但当用户明确要求"直接把这段生成视频"时，按下面走——这些是实证跑通的经验。

1. **真人视频直接垫真人定妆图**：真人写实口播/情景剧走 image-to-video，输入的是**真人定妆参考图**。演员一致性靠"同一张定妆图垫全片"实现。
2. **演员一致性=同一张定妆图垫全片**：先生成 1 张演员定妆图，本条视频所有段都用这**同一张图**垫图 + 每段写死相同 `[视觉锚点]`，才能保证跨段是同一个人、同一机位。
3. **VideoGen 图生视频不要传 `aspect_ratio`**：image-to-video 比例由输入图决定，传 `aspect_ratio:"9:16"` 会报 400 `unsupported video aspect_ratio`。竖版靠输入图本身是竖版（如 1024×1536）实现；VideoGen 只传 `image / prompt / seconds / resolution / enable_audio`。
4. **分辨率 `resolution`**：信息流广告 **720p 够用**，条件允许传 **1080p 更清晰**。默认可用 720p 省积分、快出片；对画质要求高或要复用到其他版位时上 1080p。
4. **段长参数**：`seconds` 传 13-15（对应铁律 1）；`enable_audio:true` 出中文配音。schema 无 max，但实操上限约 15s，别贪传 20+。
5. **VideoGen 走积分、属增值功能**：一条 13-15s 约 150-300 积分。批量出片前先算成本，别一次跑太多。
6. **拼接/加字幕/变速等后处理**：本机常无系统 ffmpeg，用 managed Python 装 `imageio-ffmpeg`（自带 ffmpeg 二进制）处理。各段编码参数一致时用 `-f concat -c copy` 无损直拼；加硬字幕用 `subtitles` 滤镜 + `PingFang.ttc`（macOS 中文字体）避免方块；整体变速用 `setpts`（视频）+ `atempo`（音频）同步，防声画错位。

## 五、合规（与图片一致）

- 消费品广告**禁绝对化**（无"绝对/零风险/百分百/稳赚"）。
- 效果/安全卖点软化（如儿童玩具："圆角设计/材质做过安全处理/用着更放心"，不写"绝对安全/无毒"这类医疗式承诺）。
- 数据必须可溯源，无数据用趋势描述，不编造。
- 合规红线细节对照 `references/tencent-ads-delivery-guide/references/review_compliance_deep.md` 与 `copywriting_method.md` 的行业合规补充。
