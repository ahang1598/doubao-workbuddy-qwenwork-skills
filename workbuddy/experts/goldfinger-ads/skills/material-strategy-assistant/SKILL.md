## 何时用这个 skill

用户表达以下意图时使用：

- 想做广告素材，但不知道从哪下手
- 需要"素材策略""创意方向""版位怎么选""尺寸多大""要做多少素材"
- 已有产品信息，想生成投放创意需求

## 最终交付物：一份 HTML 版《素材策略》

本 skill 的最终产物是**一份结构清晰、重点明确、可离线打开的单文件 HTML 卡片**，不是零散的聊天表格，更不是依赖网络的网页。HTML = **策略本身 + 执行手册合一**，包含两大部分：

> 🚨 **品牌门面与组件规范（先记这条，详见文末「HTML 输出规范」）**：本工具品牌「**金手指·素材经理**」。交付物一律按本专家包内嵌的 `../html-report-card-suce/` skill（16 条硬规则）渲染：
> - 蓝色 banner 头部（主色腾讯蓝 `#0052D9`，banner 右上角带金手指 logo 白底 chip）+ brand-tag 写死「金手指·素材经理」；
> - 主体白底、章节标题用 `<h2 class="section-title">` + 蓝色序号 `01/02/03...`（无 h3 降级）；
> - 蓝色仅在 banner / 序号 / `.callout` / `pill-recommend` 处点缀，主体克制；
> - 文件名以 `金手指-广告素材专家_{产品名}素材策略_{YYYYMMDD}.html` 开头；落盘到用户当前工作目录；
> - **结尾固定「下一步建议」章节**（生成素材 → 准备文案 → 投放找金手指）。
>
> 该组件库完整规则见 `../html-report-card-suce/SKILL.md` 和 `../html-report-card-suce/references/design-rules.md`。所有视觉相关问题（banner / 表格 / callout / lead / 风险并列 / 决策分支 / markdown 残留自检）按那套规则执行，**不允许自创样式**。


**第一部分 · 素材策略**（🚨 融合成一块连贯输出，模块简短、不要大段文字；标题就叫「素材策略」，不是「投放策略」）

按下面固定顺序，每块**极简呈现**（能用一句话/三行表就不写成段落）：

> 🚨🚨🚨 **用户视角措辞铁律（最高优先级，贯穿整份输出）**：交付物是给**不懂投放的小白老板**看的，所有措辞都要**站在他的视角说人话**，禁止内部/投手/系统黑话。逐条对照：
> - "预算未过1万、没点名视频号" ❌ → "预算不超过1万、也没要求投视频" ✅
> - "透传占位 / 后置组装环节 / 由后续流程补齐 / 门槛 / 封顶 / 兜底 4:4:2" ❌ → 说人话（如"你的logo这轮先不放进画面，出图后再单独精准叠加""这轮先做图片，视频等你预算提上来或想投视频号时再补"）✅
> - 任何"参数条/标签"里只写一个孤立的值（如只写"高""中"）❌ → 必须带标签让人看懂（如"优先级：高"）✅
> 写完通读一遍：**每一句，一个没接触过广告投放的老板能不能看懂？** 看不懂就改。

> 🚨🚨🚨 **去重铁律（最高优先级，贯穿整份输出）**：**每个信息只讲一次，讲清后续不再重复**。三条具体落法，务必遵守：
> 1. **核心主张只在「创意思路和规划」出现一次**。执行手册开头**绝不再复述主张**。
> 2. **🚨 不单独立「做多少素材」板块**——优先级/数量/尺寸**直接标进「创意思路和规划」每张思路卡的一行小参数条**（如 `主推 · 6张 · 横16:9`），与该类型的"怎么传信息"大白话同卡呈现；**总量与要不要视频**用一句话融进创意规划开头。**绝不再单开一个板块或一张表重列类型/数量/尺寸**（那正是用户反馈的"案例库和做多少重合"）。
> 3. **执行手册开头不再介绍任何背景**（不复述主张、不复述素材组合），直接一句"照下表逐条做即可"然后进表。
>
> 🚨 **生成 HTML 时去除 SKILL.md 内的 emoji 🚨 / ❌ / ✅**：这些标记只在 SKILL.md 里辅助 agent 阅读，渲染进 HTML 时一律替换为语义颜色（`.callout` / `.callout-warn` / `.tag-ok` / `.tag-bad`）与标题词（建议 / 风险提示 / 红线 / 不建议）；html-report-card 规则 3 明确禁止在产物里使用 emoji。

1. **一句话目标**：把诉求翻译成一句话（推什么·给谁·撬动什么动作）。一句即可。可直接写成 `.callout` 单段高亮。
2. **目标 · 人群 · 产品分析**：用**三行式**简短展示——推广目标 / 目标人群 / 主打卖点，各一行。**不要展开成大段文字。** 推荐用 `table.data-table` 的 **KV 型两列表**（左列字段名如「推广目标」/「目标人群」/「主打卖点」，右列内容）。
3. **创意思路和规划**（🚨 唯一的策略板块，原"创意思路"+"建议做哪几类"+"做多少素材"三者全部合并到这里）：
   - 先给**一条核心主张**（加粗主张 + 一两句理由，即"创意思路"）——**这是主张唯一出现的地方**。推荐放在 section 内的首个 `.callout`（蓝色）。
   - 紧接一句**总量与视频**：把"按你的预算、投放天数和转化成本，大概配多少张素材、要不要视频"融进一句话（🚨 用户视角措辞，如"按你的预算和投放计划，先备 30 张图、这轮先不做视频（预算不到 1 万，先用图片把方向跑出来）"或"算下来配约 48 张图 + 10 条视频"），**不单独立标题、不展开成段**；可继续放在同一个 `.callout` 内或其后用 `<p class="lead">` 引出。
   - 再给**建议做哪几类素材**：每类用一张卡片，卡片含 **① 类型名（官方 13 类之一）② 一行小参数条：优先级 · 数量 · 尺寸（🚨 优先级必须带标签，写「优先级：主推」而非孤立的「主推」；如 `优先级：主推 · 6张 · 横16:9 1920×1080`）③ 一句「怎么给用户传信息」的大白话 ④ 一张该类型的标准样式示例图**（按第 2.5 步由 `fetch_case_samples.js` 落地后内嵌）。🚨 **参数就标在卡片上，不再另做一张配置表/另开一个"做多少"板块**。
   - 每张类型卡推荐用 `<table class="data-table">` + `<thead>`（类型名 / 优先级·数量·尺寸 / 怎么传信息），下方跟示例图 `<img>`（容器必须 `.img-frame`，`object-fit:contain` 防裁切；打印前 `inline_assets.js` 把图转 base64 不丢图）。

**第二部分 · 素材执行手册**（逐条可施工清单；🚨 标题固定「素材执行手册」）
- **🚨 开头不复述背景**：执行手册开头**不再介绍核心主张、不再复述素材组合**（前面都讲过了）。只用一句话过渡（如"照着下表逐条做即可，每条都配好了文案和可直接出图的生成提示词"），随即进表。
- **每条素材 1:1 逐条列出**：有 N 条素材就列 N 行。逐条表统一 **5 列**：**# · 创意类型 · 尺寸 · 文案 · 生成提示词**（🚨 不加"样式参考"列；不再用"素材大类"列）。
- **文案逐条生成**：素材数量是多少，就写多少条文案（1:1 配齐，不复用凑数）。视频行在"文案"列给脚本方向。
- **生成提示词：逐条真正输出**。执行手册里"生成提示词"这一列，按 `references/prompt_method.md` 对应类型的**典型提示词模板**，代入本项目产品/卖点/文案，逐条写出**完整可用的提示词**（不再填"建设中"）。视频行该列填 —。🚨 这一列**必须逐条填实**，别遗漏。
- **视频素材**：本轮**不生成视频物料（分镜/口播稿/旁白）**，但策略层**必须规划到位**——明确哪几类视频、各做几条、什么套路，保证策略不遗漏视频。

> 🚨🚨 **两条硬红线（面向用户输出时务必遵守）：**
> 1. **禁用内部黑话**：给用户看的任何文字里，**绝不出现「平台样式类 / 原生类 / 海报类 / 业务元素类」**这类内部分类名。这些只用于你内部选型判断；对用户一律翻译成**「怎么给用户传信息」的大白话**（如"做成公众号里的真实推荐图文""像朋友晒店，熟人口吻+评论互动"）。
> 2. **创意类型只能用官方 13 类原名**（常规海报 / 模拟朋友圈 / 小红书笔记 / 仿对话 / 数字人海报 / 公众号资讯 / 榜单素材 / 户外海报 / 备忘录 / 大字报 / 九图拼接 / 四图拼接 / IP海报），**严禁自行延展、改名或造新名**（如"探店笔记图/品牌海报/理由清单图/好友分享图"这类野生命名一律禁止）。
> 3. **标准样式示例图（已就位）**：凡出现创意类型推荐的地方都要内嵌该类型的**标准样式示例图**（平台案例库官方样例，第 2.5 步脚本落地、本地自动兜底）。**首次展示位置=第一部分「创意思路和规划」首次列出类型时，每类配一张。执行手册开头默认【不再重复】展示同一批样式图**（第一部分已展示过，重复会啰嗦；用户也明确反馈过"上面介绍过样式，下面不要再介绍"）。这些图仅示意**版式结构**，供用户参考"这类素材长什么样"。
>    🚨🚨 **图必须完整显示、严禁裁切**：case_samples 里横竖比例不一（常规海报/数字人/公众号/户外/IP 是横图 ~16:9；模拟朋友圈/榜单/大字报等是竖图 ~9:16）。内嵌时**绝不能用 `object-fit:cover`+固定高度**——那会把横图两侧、竖图上下切掉，导致"图片显示不完整"。正确做法：给一个**浅灰底、flex 居中的容器盒子**，图片用 `object-fit:contain; max-width:100%; max-height:100%`，让整张图完整装进盒子里（留白可接受，裁切不可接受）。
>    🚨🚨 **防分页裁切（卡片整体被切开）**：上面只是"图片本身不被切"，**但横向布局的卡片（图左文右）单张高度容易撞页边、被 PDF 分页从中切开**——结果是"图在上一页底部空白、文字在下一页顶部消失"，看起来更糟。**强制加 `page-break-inside:avoid; break-inside:avoid` 包裹整张卡片**（建议 .card 和 .card .img 容器都加），并把图区高度收到 max-height:200px 左右保证卡片整体高度更小。这条与"图本身不裁切"是两层不同的问题，都要防。
>    🚨🚨 **不丢图**：HTML 里样式图按**第 2.5 步脚本 `[RESULT]` 给出的实际文件名**（形如 `assets/case_samples/{类型}.webp`，扩展名以脚本输出为准）相对路径写即可，但**打印 PDF 前必须先跑 `scripts/inline_assets.js` 把它们转成 base64 内联**（详见文末「PDF 输出规范」的不丢图硬规则）。这保证换任何模型/机器/PDF 引擎（含不认 webp 的 wkhtmltopdf）都不会丢图。
>    🚨🚨 **图实在拉不到就走文字兜底**：若某类型的样式图平台和本地都没有（脚本标 `❌ 未获取到`），**不要留空图框**，改用 1-2 句话描述该类型版式特征代替（详见第 2.5 步「🚨 图拉不到时的文字兜底」）。

> PDF 生成方式见文末「PDF 输出规范」。每次跑完 skill，最终都要产出并交付这份 PDF。

## 核心工作流（4 步）

### 第 1 步：收集信息（不足就主动问）

小白用户通常在提问时把已有信息一股脑给你。你先从用户输入里提取，对照下面的**必备信息**清单，缺什么就用**一次性、选项化**的方式追问补齐（面向小白，别用术语轰炸）。

**必备信息（缺则必须问）：**

| 信息      | 为什么需要      | 追问方式（小白友好）        |
| ------- | ---------- | ----------------- |
| 产品/服务名称 | 素材主体       | "你要推广的产品是什么？"     |
| 所属行业    | 决定合规与默认人群  | 给几个行业选项让选         |
| 一句话卖点   | 关键洞察的核心    | "你的产品最打动人的一点是什么？" |
| 推广目标    | 决定创意方向与CTA | 选项：涨粉/引流/留资/卖货/曝光 |
| 总预算      | 算日预算、素材数、视频量 | "这个项目大概总预算多少？"（驱动数量测算，见第3步公式） |
| 预计投放天数  | 算日预算（总预算÷天数） | "打算投多少天？"（如 15 天 / 30 天） |
| CPA（预期单次转化成本） | 算广告数（日预算÷(CPA×20)） | "你能接受一次转化/下单大概多少钱成本？不清楚可给个大致范围"（不懂可帮判断，按行业给经验值兜底） |

> 🚨 **总预算 / 预计投放天数 / CPA 三者是新版数量公式的核心输入，缺一不可**（第3步「素材与物料数量测算规则」全靠它们算广告数→素材数→文案数）。缺失时必须问；用户实在给不出 CPA，可结合本 skill 内置指引 `references/tencent-ads-delivery-guide/references/general/general_metrics.md` 的行业经验值兜底，并明确告知这是估算。

**可选信息（不填给默认，不必都问）：**

- 投放渠道（不填→由本地指引按产品推荐；**有渠道要求时，按第3步查内置指引获取该渠道创意形式与视频建议**）
- 目标人群（不填→行业默认）
- 品牌资产：logo/主色/slogan/产品图/风险提示语（不填→行业通用调性；若提供，必须是干净原始素材，不要随手截图）

**品牌资产采集备注（给小白用户说清楚，如果没有的话，要提醒用户，这个可以跳过，但是最终投放还是需要）：**

| 资产             | 建议提供                      | 不建议                |
| -------------- | ------------------------- | ------------------ |
| logo           | 透明底 PNG / SVG / 高清原图，边缘干净 | 从海报、商品页、聊天记录里随手截图  |
| 产品图            | 高清产品实拍/官方图，背景干净，主体完整      | 带水印、压缩严重、截图裁切不完整的图 |
| 主色/品牌色         | 色值（如 #C9A063）或品牌规范截图      | 模糊截图里靠肉眼猜颜色        |
| slogan / 风险提示语 | 可复制文字原文                   | 只给一张糊图让系统识别文字      |

> 原因：品牌资产后续会用于后置组装环节做精确叠加。若用户随手截屏，容易出现清晰度不够、背景不干净、格式混乱、logo边缘毛糙、文字识别错误等问题。截图可作为参考，但**不要作为最终可用品牌资产**。

> 追问原则：必备信息缺失才追问，且**最多追问1-2 轮**、每轮给选项。可选信息一律先用默认值推进，不要为了凑齐信息反复打断小白。

### 第 2 步：需要版位/尺寸/渠道数据时，查本地投放指引

当要产出"模块B创意类型推荐"（选版位、定尺寸、定创意形式）时，**自动调用**封装脚本，从本 skill 内置的《腾讯广告投放全链路操作指引》本地知识库里抽官方口径数据，而不是拍脑袋、也**不再依赖腾讯广告妙问（无需任何 API Key）**：

```bash
node {baseDir}/scripts/query_placement.js '{"product":"手工香薰蜡烛","industry":"家居/香氛","sellingPoint":"助眠","audience":"25-40都市女性","goal":"购买转化"}'
```

- 脚本读取 `references/tencent-ads-delivery-guide/references/creative_inspiration_deep.md`「各版位适合的创意形式与爆款特点」章节，返回：推荐版位+理由、主跑尺寸/比例、创意形式、文案调性，并附原文版位规格表供核对。
- 输出含 `[PROGRESS]` 过程行和 `[RESULT]` 结果段，**取 `[RESULT]` 后的内容**用于组装策略。
- **退出码处理**：
  - `4 [INPUT_ERROR]`：入参缺失（至少要 product 和 sellingPoint）→ 补齐后重跑。
  - `5 [GUIDE_ERROR]`：未找到本地指引知识库 → 确认 skill 安装完整（`references/tencent-ads-delivery-guide/` 是否存在）。

> 数据全部来自本地打包文档，**用户不会因为缺妙问 Key 而拿不到版位/尺寸信息**。若脚本因故不可用，直接用 `references/brief_spec.md` 里的标准尺寸表（9:16 竖版 + 1:1 方图通吃）+ 上述本地指引原文兜底出策略即可。

### 第 2.5 步：拉取官方示例图（🆕 平台案例库，平台优先、本地兜底）

**两组官方示例图均已外置到平台案例库**（生产库 `creative_examples` 表，全平台共享一份，不属于任何项目），不再依赖 skill 包内文件作为唯一来源：

**素材与物料数量测算规则（🚨 公式驱动，唯一权威，务必遵守）：**

> 🚨 本规则以本 skill 为准，**不再参考其他 skill 的测算方式**。核心是先算「广告数」，再由广告数推出素材数与文案数。

**必备输入（缺则必须问用户，见第1步必备信息）：**
- **总预算**（元）
- **预计投放天数**（天）
- **CPA**（预期单次转化成本，元/次转化）

**四步公式（按顺序算）：**

1. **日预算** = 总预算 ÷ 预计投放天数
2. **广告数** = 日预算 ÷ (CPA × 20)　（结果向下取整；至少 1 条广告）
3. **素材数** = 广告数 × 3　~　广告数 × 5　（给一个区间，取中位数落地即可）
4. **文案数**：
   - **外层文案** = 广告数
   - **首条评论** = 广告数（仅朋友圈版位有首评；其他版位不产出首评）

**两条硬约束：**
- 🚨 **首次投放素材储备不低于 30**：若公式算出的素材数 < 30，**一律按 30 张兜底**（首投必须备够 30 条，避免素材不足跑不起量）。
- 广告数、外层文案、首条评论均**至少为公式算出值**，不低于 1。

**是否做视频（按有无渠道要求分流）：**

| 情况 | 是否做视频 | 视频数量 |
| ---- | ---- | ---- |
| **无渠道要求、无指定素材类型**，整体预算 **< 10000 元** | ❌ 不做视频 | — |
| **无渠道要求、无指定素材类型**，整体预算 **≥ 10000 元** | ✅ 做视频 | **视频数量 ≈ 素材总数 × 20%**（视频占比 20%，其余为图片） |
| **有渠道要求 / 指定素材类型**（如点名视频号、指定要做某类视频） | 按渠道要求 | **查本 skill 内置指引获取该渠道的创意形式与视频建议**（见下方「有渠道要求时」） |

> **有渠道要求时（务必查内置指引，不要拍脑袋）：** 当用户点名了投放渠道（视频号/朋友圈/公众号/平台与内容信息流/开屏等）或指定了素材类型，**读本 skill 内置的《腾讯广告投放全链路操作指引》**（已随 skill 打包，路径 `references/tencent-ads-delivery-guide/`，v2.4.0）获取该渠道适配的创意形式、视频规格与建议：
> - 版位/尺寸/创意形式：跑 `scripts/query_placement.js`（读 `creative_inspiration_deep.md`），或直读 `references/tencent-ads-delivery-guide/references/creative_inspiration_deep.md`「各版位适合的创意形式与爆款特点」。
> - 通用投放方法论（CPA/学习期/放量/素材衰退等）：读 `references/tencent-ads-delivery-guide/references/general/`（v2.4.0 新增，先看 `general_index.md` 路由）。
> - 🚨 该指引**已内置在 skill 内、随 skill 分发**，任何人装了本 skill 都能直接读，**不依赖任何外部临时文件路径**。

> 视频规划：需要做视频时，在策略里明确**要做哪几类视频（情景剧/单人口播/动图/混剪）、各几条、为什么**；条数以上表算出的「视频数量」为准。
> 🆕 **视频物料产出（仅当有视频需求时启用）**：一旦触发视频，执行手册阶段就**默认按 `references/video_script_method.md` 产出一份「完整视频脚本表」并入执行手册**（见「执行手册」表二），覆盖策略里已规划的那几条视频，**无需再单独询问用户**。**未触发视频时，本能力完全不启用，输出结构与原来一字不差。**

**测算示例（帮助理解公式）：**
> 总预算 20000 元、预计投放 30 天、CPA 100 元：
> ① 日预算 = 20000 ÷ 30 ≈ 667 元　② 广告数 = 667 ÷ (100×20) = 667÷2000 ≈ 0.33 → 向下取整不足 1，按至少 1 条广告 → **但首投素材储备不低于 30**，故素材按 **30 张**兜底；外层文案/首条评论按广告数（此例偏低，实操中广告数常为个位数到十几条）。
> 若 CPA=30、天数=15：日预算=1333，广告数=1333÷600≈2 → 素材=2×3~2×5=6~10 张 → 不足 30，**按 30 兜底**；外层文案=2、首条评论=2。
> 若日预算大、CPA 低使广告数达 12：素材=12×3~12×5=36~60 张（取中位≈48）、外层文案=12、首条评论=12；预算≥1万且无渠道要求 → 视频≈48×20%≈10 条。

## 关键原则

1. **替小白决策，别抛术语**：版位/尺寸/创意形式尽量自动定，用户只做"要不要"的确认。
2. **一图一卖点**：关键洞察的核心信息必须单一聚焦。
3. **数据有据可依**：版位/尺寸来自本地投放指引知识库（官方口径整理稿），不随机推荐。
4. **公式驱动数量与视频**：素材数、文案数、是否做视频严格按第3步公式（广告数=日预算÷(CPA×20)→素材=广告数×3~5→文案=广告数；首投素材≥30），不拍脑袋。
5. **文案 1:1 逐条配齐**：有多少素材就写多少条文案，不复用凑数。
6. **生图提示词已启用**：执行手册"生成提示词"列按类型模板逐条写实、可据此出图；模板见 `references/prompt_method.md`。
7. **最终交付 PDF**：结果是一份结构清晰的 PDF，不是零散聊天表格。
8. **logo/风险语只透传**：不参与生成，留待后置「妙思」组装。

## 完整示例

用户说："我想推广我做的手工香薰蜡烛，主打助眠，主要卖给上班的年轻女性，想让大家下单买，总预算 5000，打算投 30 天。"

1. 提取到：产品=手工香薰蜡烛、卖点=助眠、人群=年轻女性、目标=卖货、总预算=5000、投放天数=30。行业可推断为家居/香氛。🚨 **CPA 未给 → 必须追问**（"一次下单大概能接受多少成本？不清楚我按香氛行业经验给你个估值"）；假设用户答 CPA≈50。
2. 调 `query_placement.js` → 本地指引返回：优先朋友圈（人群精准+微信生态+品质转化）、主跑 800×800（1:1）多图 / 卡片横版视频 16:9 1280×720、强广告属性开头+吸睛首帧的温柔治愈调性。
3. **公式算数量**：日预算=5000÷30≈167；广告数=167÷(50×20)=167÷1000≈0.17 → 不足 1，按至少 1 条；素材=1×3~1×5=3~5 张 → **不足 30，按首投兜底 30 张**；外层文案=广告数、首条评论=广告数。**无渠道要求且预算<1万 → 不做视频。** 产出三块策略：A 重点呈现"睡前仪式感"；B 朋友圈图片（常规海报/数字人海报等）；C 素材 30 张、不做视频。
4. 组织成策略解读 + 执行手册（30 条素材逐行、文案按公式配齐、生图提示词按类型模板逐条写实、每类内嵌标准样式示例图）→ 生成 PDF → present_files 交付。
5. 若预算改为 2 万、天数 30、CPA 100：日预算≈667、广告数=667÷2000≈0.33→按兜底 30 张；**预算≥1万且无渠道要求 → 视频≈素材数×20%**，在策略里规划视频（如单人口播×?、混剪×?），并按 `video_script_method.md` 产出「表二 · 完整视频脚本表」。若用户**点名投视频号或指定素材类型**：读内置指引 `references/tencent-ads-delivery-guide/` 获取该渠道创意形式与视频建议后再定。
