# Goldfinger Ads · 金手指 · 广告投放（专家团）

金手指广告投放专家团（Team 型）：由投放总指挥（金运筹）调度四位专家——媒介经理（齐亮）、素材经理（苏策）、AI 广告投手（艾投）、投放答疑小助手（百晓），覆盖腾讯广告从提需到开投、盯盘复盘、素材规划、规则咨询的全链路。

## 团队构成

| 成员 | 角色 | 职责 |
|------|------|------|
| 金运筹（主理人） | 金手指 · 投放总指挥 | 建团、点将、汇编、衔接点拍板；不代写成员产出 |
| 齐亮 | 金手指 · 媒介经理 | 提需对话 → 需求立项单 → 《投放可行性评估》→ 策略全量直灌金手指策略配置页开投 |
| 苏策 | 金手指 · 素材经理 | 素材策略 + 逐条执行手册（官方 13 类创意选型、数量测算、文案与生图提示词、视频脚本），单文件 HTML 卡片 |
| 艾投 | 金手指 · AI 广告投手 | 大白话全能投手：建广告、调在跑广告、查毛病、每日盯盘日报、结案复盘、完整分析报告 |
| 百晓 | 金手指 · 投放答疑小助手 | 开户资质/审核申诉/归因配置等规则查证 + eCPM/学习期/出价预算等机制讲解 |

## 功能

1. **全链路投放（主流程）**：齐亮提需评估 → 苏策素材策略 → 齐亮策略直灌金手指开投 → 开投后艾投盯盘复盘
2. **投放执行与诊断**：建广告清单、调优、常见问题诊断、每日日报、结案复盘（艾投）
3. **素材专项**：素材策略 + 执行手册 HTML 卡片（苏策）
4. **规则与机制问答**：查准了才答的腾讯广告规则与投放常识（百晓）

依赖金手指 MCP 连接器（jinshouzhi，**v1.6.0 起与专家团分离，独立安装**，OAuth 授权、无需配置 Token）：策略确认单可全量灌入金手指策略配置页直接开投，并可拉取真实投放数据。

## 安装

将专家包目录放入 WorkBuddy 专家目录（`<配置目录>/plugins/marketplaces/my-experts/plugins/`），随后在专家目录执行注册：

```bash
python3 scripts/register_expert.py <专家包目录>
```

注册后专家团即在 WorkBuddy 专家中心可见可用。金手指连接器为独立安装的连接器包（与专家团分开）——WorkBuddy → 连接器（Connector）市场，搜索「金手指 / Goldfinger」安装并**重启 WorkBuddy**；首次使用涉及金手指开投/数据拉取时，点对话下方的「金手指 MCP」连接按钮完成 OAuth 授权即可（无需填任何凭证）。
