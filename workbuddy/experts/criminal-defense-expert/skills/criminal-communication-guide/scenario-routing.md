## 路由逻辑

```
输入 → 提取(对象, 阶段, 目标) → 查表匹配场景编号
  ├─ 精确匹配 → 加载对应策略
  ├─ 近似匹配（目标不同） → 加载同对象同阶段策略+调整力度
  └─ 无匹配 → 使用最接近场景+标注"场景近似匹配"
```
