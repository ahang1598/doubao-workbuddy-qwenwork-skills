# 工作流详述

> 本文件定义 criminal-evidence-request 技能的各Phase子步骤与检查点 | 版本: v3.2.0

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 证据清单组织 → Phase 3: 无法收集论证
    ↓
Phase 4: 申请书起草 → Phase 5: 质量检查 → Phase 6: 输出交付 → Phase 7: DOCX渲染
```

## 2. Phase 1: 辸入验证

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1 | 解析输入 | 结构化字段 |
| 1.2 | 确定申请对象 | 检察院/法院（禁止向公安局申请） |
| 1.3 | 提取证据描述 | evidence_description |

**检查点**：[ ] 必需字段已提取 [ ] 申请对象已确定（非公安局）

## 3. Phase 2: 证据清单组织

| 步骤 | 操作 | 产出 |
|------|------|------|
| 2.1 | 按证据类型分类 | 证据分类清单（对齐刑诉法第50条8类） |
| 2.2 | 提取证据来源 | 来源/持有人 |
| 2.3 | 确定待证事实 | 证据-事实映射 |
| 2.4 | 提取证据线索 | 如何知道该证据存在 |

**检查点**：[ ] 证据已分类 [ ] 待证事实已确定 [ ] 证据线索已提取

## 4. Phase 3: 无法收集论证

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.1 | 分析无法自行收集的原因 | 原因分类（法律限制/持有人不配合/技术限制/客观不能） |
| 3.2 | 组织论证 | 无法收集论证 |

**检查点**：[ ] 无法收集原因已论证（具体非笼统）

## 5. Phase 4: 申请书起草

按 output-spec.md §1 模板。关键规则：
- 致送机关按阶段正确选择（与 legal-references.md §4 一致）
- 每项证据五要素完整（名称+类型+来源持有人+待证事实+证据线索）
- 无法自行收集原因必须具体
- 审判阶段须满足刑诉法解释第57条（书面+线索）
- 法律依据按阶段引用（审查起诉→第41条；审判→第43条第1款后段+第57条）

**检查点**：[ ] 格式正确 [ ] 证据清单完整 [ ] 原因论证具体 [ ] 审判阶段第57条满足

## 6. Phase 5: 质量检查

| 检查项 | 标准 | 等级 |
|--------|------|------|
| 法条引用与阶段匹配 | 第41条/第43条第1款后段+第57条；禁止第39条 | 阻断 |
| 无法收集原因 | 具体非笼统（法律限制/持有人不配合/技术限制/客观不能） | 阻断 |
| 证据描述五要素 | 名称+类型+来源持有人+待证事实+证据线索 | 阻断 |
| 致送机关正确 | 审查起诉→检察院；审判→法院；侦查→检察院 | 阻断 |
| 无罪推定 | 无"罪犯"表述 | 阻断 |
| 审判阶段第57条 | 书面申请+提供线索/材料 | 阻断 |

> 完整质量检查项见 quality-standards.md

## 7. Phase 6: 输出交付

| 输出项 | 内容 |
|--------|------|
| O1 | 收集、调取证据申请书草稿（Markdown） |
| O2 | 收集、调取证据申请书正式稿（DOCX） |

---

## 8. Phase 7: DOCX 渲染 [L3 高风险]

> 风险等级：L3 —— 收集、调取证据申请书为F-Strict正式文书，格式错误直接影响检察院/法院审查

### 7.1 渲染准备

| 步骤 | 操作 | 参考文件 |
|------|------|----------|
| 7.1.1 | 读取 L3 类型规格卡 | `base/rule/format-docx/types/application/T-evidence-request-criminal.md` |
| 7.1.2 | 读取薄层排版规范 | `references/docx-format-spec.md` |

### 7.2 组件序列渲染

按 `T-evidence-request-criminal.md` §组件清单 顺序渲染8组件。特殊注意：
- 申请事项区分"调取证据"与"传唤证人"两种格式
- 事实与理由按五要素结构（证据线索→卷宗缺失→关联性→必要性→法律依据）
- 法条区分：审查起诉→第41条；审判→第43条第1款后段+刑诉法解释第57条

### 7.3 Phase 7 检查点

- [ ] 8组件序列完整
- [ ] 调取对象明确（证据名称+持有人/存放处所或证人信息）
- [ ] 法条区分第41条/第43条第1款后段/刑诉法解释第57条
- [ ] 禁止事项全部满足
- [ ] 审判阶段满足第57条书面+线索要求
