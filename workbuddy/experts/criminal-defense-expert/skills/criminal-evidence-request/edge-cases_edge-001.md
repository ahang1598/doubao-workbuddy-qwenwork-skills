# 边缘示例001：申请调取隐私性证据（微信聊天记录）

> criminal-evidence-request | 边缘示例 | v3.2.0

## 输入

```markdown
我要申请法院调取张三的个人微信聊天记录，证明他跟同伙密谋了诈骗。
```

## 边界问题

申请调取微信聊天记录涉及多重法律问题：（1）隐私权与证据收集的平衡——微信聊天记录属于通信自由和隐私权保护范围；（2）关联性论证——须证明聊天记录与案件事实有直接关联；（3）必要性论证——须说明为何无法自行获取（刑诉法第43条第1款后段）；（4）合法性要求——个人通信的调取需符合法定程序。此案例触及证据收集申请的合法性与必要性边界。

## 预期输出特征

- 识别隐私性证据的调取限制
- 要求用户补充关联性论证和必要性论证
- 说明申请调取通信记录的法律条件
- 生成申请书时增加关联性和必要性论证模块
- 提示非法获取证据的法律风险
- 审判阶段须满足刑诉法解释第57条书面+线索要求

## 预期输出摘要

```markdown

一、关于微信聊天记录的调取必要性
```
