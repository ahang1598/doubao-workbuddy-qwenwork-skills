# 边缘示例002：多项证据同时申请（审查起诉阶段，3项证据）

> criminal-evidence-request | 边缘示例 | v3.2.0

## 输入

```markdown
王某涉嫌合同诈骗罪审查起诉阶段，申请检察院调取：
1. 合同履行过程中的全部往来邮件（在对方服务器）
2. 第三方支付平台交易流水（证明款项用途）
3. 鉴定机构原始检测数据（对鉴定意见有异议）
```

## 边界问题

一次申请调取多项证据时，需注意：(1) 申请范围控制——建议不超过3项，每项充分论证；(2) 每项证据需独立完成五要素描述和双重论证；(3) 不同类型证据的必要性论证重点不同——邮件和流水属法律限制，鉴定数据属鉴定机构不配合；(4) 清单式逐条列出的段落组织方式。

## 预期输出特征

- 3项证据清单式列出
- 每项证据独立设段，五要素完整
- 每项证据双重论证（关联性+必要性）完整
- 不同类型证据的必要性论证各有侧重
- 总体不超过3项（符合申请范围控制原则）

## 预期输出摘要

```markdown
# 关于王某涉嫌合同诈骗罪一案收集、调取证据申请书

XX市XX区人民检察院：

申请人：XXX，XX律师事务所律师……

申请事项：

1. 申请调取XX公司与李某所在公司之间关于合同编号XX-2024-001的全部往来邮件。侦查卷宗中未见双方邮件往来记录。
2. 申请调取第三方支付平台（支付宝/微信支付）王某名下账户2024年1月至6月交易流水。侦查卷宗中未见第三方支付交易记录。
3. 申请调取XX司法鉴定中心对合同文本真实性鉴定（编号XX司鉴[2024]XX号）的原始检测数据。侦查卷宗中仅附鉴定意见书，未见原始数据。

事实与理由：

一、关于合同往来邮件的调取必要性

证据线索：起诉意见书认定王某"未实际履行合同义务"，但卷宗第2册第35页王某与李某的微信聊天记录显示双方确有邮件沟通合同履行事宜，且李某曾发送邮件确认收货……

[五要素完整+双重论证]

二、关于第三方支付交易流水的调取必要性

证据线索：卷宗第1册第22页银行流水显示王某收到合同款项后随即转出，但未显示转出方向。辩护人经阅卷发现转账备注为"支付宝-XX公司"，提示存在第三方支付流转……

[五要素完整+双重论证]

三、关于鉴定原始检测数据的调取必要性

证据线索：鉴定意见书认定"合同印章与样本不一致"，但鉴定过程未说明取样来源和比对方法……

[五要素完整+双重论证]

法律依据：

根据《中华人民共和国刑事诉讼法》第四十一条之规定……

此致
XX市XX区人民检察院

申请人：XXX
XX律师事务所
[日期]
```
