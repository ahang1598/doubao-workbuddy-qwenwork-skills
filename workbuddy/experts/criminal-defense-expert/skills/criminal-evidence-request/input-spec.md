# 输入规格

> 本文件定义 criminal-evidence-request 技能的完整输入参数规格
> 版本: v3.2.0
> 遵循 compiler/ssot.md §17（SSOT）：输入宽容度契约

## 1. 必需输入

| 字段 | 类型 | 枚举值 | 说明 | 验证规则 |
|------|------|--------|------|----------|
| `case_name` | string | - | 案件名称（如"张某涉嫌受贿罪一案"） | 非空 |
| `evidence_description` | string | - | 申请调取的证据描述（名称+形式+所在位置） | 非空 |
| `evidence_source` | string | - | 证据来源/持有者 | 非空 |
| `fact_to_prove` | string | - | 待证事实（该证据能证明什么） | 非空 |
| `relevance_reason` | string | - | 证据与本案的关联性及对辩护的意义 | 非空 |

> ⚠️ 上述5个必填字段与 SKILL.md 核心参数表一致，为本技能的输入唯一事实源

## 2. 可选输入

### 2.1 案件信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `alleged_crime` | string | [待补充] | 涉嫌罪名 |
| `case_stage` | enum | 审查起诉 | 审查起诉/一审/二审 |
| `suspect_name` | string | [待补充] | 犯罪嫌疑人/被告人姓名 |
| `court_name` | string | [待补充] | 审理法院 |

### 2.2 证据详情

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `evidence_type` | enum | 书证 | 物证/书证/证人证言/被害人陈述/犯罪嫌疑人被告人供述和辩解/鉴定意见/勘验检查辨认侦查实验等笔录/视听资料电子数据（对齐刑诉法第50条8类） |
| `evidence_location` | string | [待补充] | 证据存放地点 |
| `evidence_holder` | string | [待补充] | 证据持有人/单位 |
| `collection_reason` | string | [待补充] | 无法自行收集的原因（法律限制/持有人不配合/技术限制/客观不能） |
| `evidence_clue` | string | [待补充] | 如何知道该证据存在的线索 |

### 2.3 申请人信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `applicant_name` | string | [待补充] | 申请人姓名 |
| `applicant_role` | enum | 辩护人 | 辩护人/自诉人/被害人 |
| `lawyer_firm` | string | [待补充] | 律师事务所 |

## 3. 输入宽容度契约

| 最小输入 | 处理方式 |
|----------|----------|
| 仅案件+证据描述+来源+待证事实+关联性 | 生成申请书完整草稿 |
| 仅案件+证据描述 | 交互补全来源、待证事实、关联性 |
| 仅"调查取证"/"申请取证" | 询问案件和证据信息 |

交互补全最多3轮。

## 4. 场景适配规则

### 4.1 申请对象适配（与 legal-references.md §4 法条适用场景路由一致）

| 案件阶段 | 申请对象 | 致送机关 | 核心法条 | 辅助法条 |
|----------|----------|----------|---------|---------|
| 审查起诉 | 人民检察院 | XX市XX区人民检察院 | 第41条 | 检察院规则第48条 |
| 一审审判 | 人民法院 | XX市XX区人民法院 | 第43条第1款后段 | 刑诉法解释第57条 |
| 二审 | 中级人民法院 | XX市中级人民法院 | 第43条第1款后段 | 刑诉法解释第57条 |
| 侦查阶段 | 人民检察院 | XX市XX区人民检察院 | 第41条 | — |

> ⚠️ **禁止**向公安机关申请调取证据——刑诉法第41条仅规定向检察院、法院申请，公安机关不在受理范围内。侦查阶段律师如认为公安未移送有利证据，应向检察院申请。

### 4.2 无法自行收集的原因

| 原因类型 | 说明 | 论证要点 |
|----------|------|----------|
| 证据由国家机关持有 | 个人无法获取 | 列明持有机关 |
| 证据涉及他人隐私 | 需司法机关调取 | 说明必要性 |
| 证人拒绝配合 | 需司法机关传唤 | 说明证人身份 |
| 技术手段限制 | 个人无法完成 | 说明技术要求 |
