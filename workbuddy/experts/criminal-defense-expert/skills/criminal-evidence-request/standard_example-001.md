# 标准示例001：向检察院申请调取银行流水（审查起诉阶段）

## 输入

```
帮我写一份收集、调取证据申请书。张某涉嫌受贿罪审查起诉阶段，
申请检察院调取中国工商银行XX支行张某名下账号6222XXXXXXXX的
2024年1月至6月交易流水。
理由：该流水能证明涉案30万元为正常业务往来款而非受贿款，
辩护人无法自行获取银行记录。
```

## 预期输出

```markdown
---
草稿声明：此申请书仅为草稿，未经律师审核不得直接提交。
生成时间：2026-06-19 10:00:00
致送机关：XX市XX区人民检察院
---

# 关于张某涉嫌受贿罪一案收集、调取证据申请书

XX市XX区人民检察院：

申请人：XXX，XX律师事务所律师，执业证号：XXXXXXXXXX，系犯罪嫌疑人张某涉嫌受贿罪一案中张某的辩护人。

申请事项：

1. 申请调取中国工商银行XX支行张某名下账号6222XXXXXXXX的2024年1月至6月交易流水。侦查卷宗中未见该账户完整交易记录。

事实与理由：

一、关于中国工商银行XX支行张某名下账号6222XXXXXXXX交易流水的调取必要性

证据线索：起诉意见书认定张某收受李某现金30万元，但卷宗中仅有张某名下农业银行账户的交易记录，未见工商银行账户记录。辩护人经阅卷发现，张某与李某所在公司之间的业务合同显示合同款项通过工商银行账户结算，该账户交易流水可能证明涉案30万元为合同款项而非受贿款。

卷宗缺失：侦查机关仅调取了张某农业银行账户交易记录，未调取工商银行账户交易记录，导致涉案30万元资金来源和去向无法完整呈现。

关联性论证：该交易流水能够证明：(1)30万元入账的资金来源——是否为李某所在公司支付的合同款项；(2)30万元入账后的资金去向——是否转至XX公司账户用于支付合同货款；(3)该款项的性质——是正常业务往来款还是受贿款。该流水直接关系到罪与非罪的认定，对辩护有重大意义。

必要性论证：上述银行交易流水存储于中国工商银行系统内，根据《商业银行法》第二十九条和银行内部规定，个人客户交易信息仅应司法机构要求方可提供。辩护律师无权直接调取银行客户交易记录，必须通过司法机关调取。

法律依据：

根据《中华人民共和国刑事诉讼法》第四十一条之规定，辩护人认为在侦查、审查起诉期间公安机关、人民检察院收集的证明犯罪嫌疑人、被告人无罪或者罪轻的证据材料未提交的，有权申请人民检察院、人民法院调取。

综上，上述银行交易流水对本案定罪量刑有重大影响，申请人因法律规定无法自行收集，恳请贵院依法调取。

此致

申请人：XXX
XX律师事务所
二〇二六年六月十九日
```

## 质量标注

| 维度 | 评分 | 说明 |
|------|------|------|
| 关联性论证 | A | 三层递进：证明资金来源→与受贿指控的关系→影响罪与非罪认定 |
