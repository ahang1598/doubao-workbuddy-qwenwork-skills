# 收集、调取证据申请书 DOCX 模板

> 版本: v3.2.0 | 适用于 criminal-evidence-request 技能
>
> 本模板定义收集、调取证据申请书的 DOCX 段落结构，供 LLM 或 `generate_docx.py` 参考。

## 模板结构

```
[BLOCK-TITLE]         关于[被告人]涉嫌[罪名]一案收集、调取证据申请书
                      二号方正小标宋简体，居中加粗

[BLOCK-INFO-TABLE]    申请人信息区（无边框两列表格）
                      申请人 | [律师姓名]，[律所]律师，执业证号[XXX]
                      系[被告人]涉嫌[罪名]一案中[被告人]的辩护人

[BLOCK-ADDRESSEE]     [XX人民检察院/人民法院]：
                      仿宋三号，顶格

[BLOCK-REQUESTS-TITLE] 申请事项：
                       黑体三号

[BLOCK-REQUEST-ITEM]  1. 申请调取[证据名称]。[卷宗缺失情况]
                      2. 申请调取[证据名称]。[同上]
                      仿宋三号，每项独立段落

[BLOCK-SECTION-FACTS] 事实与理由：
                      黑体三号

[BLOCK-H2-ARG1]       一、[证据1的调取必要性论证]
                      楷体三号加粗，首行缩进2字符

[BLOCK-ARG1-BODY]     [证据线索→卷宗缺失→关联性论证→必要性论证→法律依据]
                      仿宋三号，每论证点独立段落

[BLOCK-H2-ARG2]       二、[证据2的调取必要性论证]
                      同上格式

[BLOCK-LAW]           法律依据：
                      黑体三号

[BLOCK-LAW-BODY]      审查起诉：根据《中华人民共和国刑事诉讼法》第四十一条之规定……
                      审判：根据《中华人民共和国刑事诉讼法》第四十三条第一款及最高法
                      《关于适用〈刑事诉讼法〉的解释》第五十七条之规定……
                      楷体三号，首行缩进2字符

[BLOCK-SUMMARY]       综上，恳请贵院依法调取上述证据。
                      仿宋三号，首行缩进2字符

[BLOCK-CHIZHI]        此致
                      仿宋三号，首行缩进2字符

[BLOCK-ADDRESSEE2]    [致送机关全称]
                      仿宋三号，顶格

[BLOCK-SIGNATURE]     申请人：[签名]      （右对齐）
                      [律所名称]           （右对齐）
                      [日期]               （右对齐）

[BLOCK-ATTACH-TITLE]  附件清单
                      仿宋三号加粗，左对齐，段前18pt

[BLOCK-ATTACH-ITEM]   1. [法条索引]
                      仿宋三号，首行缩进2字符
```

## 致送机关路由

| 阶段 | 致送机关 | 核心法条 | 辅助法条 |
|------|----------|---------|---------|
| 侦查 | XX市XX区人民检察院 | 第41条 | — |
| 审查起诉 | XX市XX区人民检察院 | 第41条 | 检察院规则第48条 |
| 一审 | XX市XX区人民法院 | 第43条第1款后段 | 刑诉法解释第57条 |
| 二审 | XX市中级人民法院 | 第43条第1款后段 | 刑诉法解释第57条 |

> ⚠️ 禁止向公安机关申请调取证据——刑诉法第41条仅规定向检察院、法院申请

## 证据清单格式

每项申请调取的证据含五要素（与 methodology.md §七 统一标准）：
1. **证据名称**：具体明确
2. **证据类型**：对齐刑诉法第50条8类法定证据种类
3. **证据来源/持有人**：持有人/存放地点
4. **待证事实**：该证据能证明什么
5. **证据线索**：如何知道该证据存在
