# 边缘示例003：申请调取的证据可能已灭失（过保存期监控）

> criminal-evidence-request | 边缘示例 | v3.2.0

## 输入

```markdown
张某盗窃案，申请调取案发地监控录像，但案件发生已过6个月
```

## 边界问题

监控录像通常保存30-90天，6个月后录像已被覆盖，申请调取已无实际意义。技能应：
1. 提示证据可能已灭失
2. 建议替代方案（如：证人证言、电子痕迹等）
3. 说明申请调取不存在的证据可能浪费申请机会
4. 如用户坚持申请，应同时请求调取监控系统的存储记录/日志

## 预期输出摘要

```markdown
> ⚠️ **证据灭失风险提示**
> 案发已过6个月，监控录像通常保存30-90天，已被覆盖的可能性极大。
> 建议优先考虑以下替代方案：

替代方案建议：

1. 申请银行/手机定位记录（可行性：高，保存期限较长）——证明案发时段张某不在案发现场
2. 申请证人出庭作证（可行性：中，目击者证言替代）——使用 criminal-witness-appearance 技能
3. 申请电子数据提取（可行性：中，手机通话/微信记录）——证明张某案发时段的活动轨迹

> 如坚持申请调取监控，建议同时请求调取以下替代性证据：
> - 监控系统的存储记录/日志（证明录像已被覆盖的事实）
> - 监控系统运维记录（证明录像保存期限设置）
> 这些记录本身可以证明"原物证灭失非因辩护方原因"，为后续程序性主张提供依据。
```

## 降级说明

此场景触发 SOFT_DEGRADED S2 降级：证据可能灭失→提供降级提示+替代方案，而非直接生成完整的调取证据申请书。如用户坚持申请，应生成包含替代请求的申请书。
