# 标准示例002：向法院申请调取鉴定原始数据（一审审判阶段）

> criminal-evidence-request | 标准示例 | v3.2.0

## 输入

```
李某涉嫌故意伤害罪一审中，申请法院调取鉴定机构的原始检测数据。
理由：鉴定意见认定被害人损伤程度为轻伤二级，但辩护人认为鉴定方法
不符合规范，原始数据可能证明损伤程度未达轻伤标准。鉴定原始数据
由XX司法鉴定中心保存，辩护人无法自行获取。
```

# 关于李某涉嫌故意伤害罪一案收集、调取证据申请书

XX市XX区人民法院：

申请人：XXX，XX律师事务所律师，执业证号：XXXXXXXXXX，系被告人李某涉嫌故意伤害罪一案中李某的辩护人。

申请事项：

1. 申请调取XX司法鉴定中心对被害人王某损伤程度鉴定（鉴定书编号：XX司鉴[2024]XX号）的原始检测数据、检验记录及检材提取记录。侦查卷宗中仅附鉴定意见书，未见原始检测数据及检验过程记录。

事实与理由：

一、关于XX司法鉴定中心鉴定原始检测数据的调取必要性

证据线索：卷宗所附鉴定意见书（第3册第78-82页）载明"依据《人体损伤程度鉴定标准》第5.10.4条认定轻伤二级"，但该意见书未附检测原始数据、影像学检查原始图片及检验过程记录。辩护人经咨询法医专家，该鉴定所依据的CT影像学表现存在解读争议，原始数据可能揭示损伤程度未达轻伤二级标准。

卷宗缺失：侦查机关移送的卷宗中仅包含鉴定意见书正本，未包含鉴定原始检测数据、检验记录、检材提取记录等鉴定过程性材料，导致辩护人无法对鉴定方法、检测过程进行实质性审查。

关联性论证：鉴定原始检测数据能够证明：(1)被害人损伤的实际程度——CT影像原始数据是否支持"轻伤二级"的认定；(2)鉴定方法是否符合规范——是否存在将不构成轻伤的损伤升级认定的情形；(3)该鉴定意见是否可靠——若原始数据不支持鉴定结论，则直接影响罪与非罪的认定（故意伤害罪以轻伤为入罪门槛）。该证据对定罪有决定性影响。

必要性论证：鉴定原始数据由XX司法鉴定中心保存，辩护律师曾于2026年5月XX日向该鉴定中心申请调取，鉴定中心以"仅应司法机关要求提供"为由拒绝。根据《司法鉴定程序通则》第三十二条，鉴定机构应当向委托的司法机关提供鉴定档案。辩护人无法自行获取，需法院依职权调取。

法律依据：

根据《中华人民共和国刑事诉讼法》第四十三条第一款及最高人民法院《关于适用〈中华人民共和国刑事诉讼法〉的解释》第五十七条之规定，辩护人认为在调查、侦查、审查起诉期间公安机关、人民检察院收集的证明被告人无罪或者罪轻的证据材料未随案移送，申请人民法院调取的，应当以书面形式提出，并提供相关线索或者材料。人民法院接受申请后，应当向人民检察院调取。

综上，上述鉴定原始检测数据对本案定罪有决定性影响，申请人因鉴定机构拒绝提供而无法自行获取，恳请贵院依法调取。

3. 法医专家咨询意见书
