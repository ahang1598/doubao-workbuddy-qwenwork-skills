# 风险框架：criminal-evidence-request

> 调查取证申请 | 版本: v3.2.0

## 1. 风险等级

**L2（中等风险）**——双重论证质量影响申请成功率，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 证据信息结构化 | L2 | 中风险 |
| Phase 3 双重论证（关联性+必要性） | **L3** | **高风险**——论证质量影响申请是否获批准 |
| Phase 4 申请书生成 | L2 | 中风险 |
| Phase 5 质量检查 | L1 | 低风险 |
| Phase 6 输出交付 | L1 | 低风险 |
| Phase 7 DOCX渲染 | **L3** | **高风险**——F-Strict文书，格式错误直接影响检察院/法院审查 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 双重论证完整 | 生成申请书时 | 关联性+必要性缺一不可 |
| RC-02 | 禁止承诺批准 | 询问能否获批 | 拒绝+说明由检察院/法院决定 |
| RC-03 | 证据保全提示 | 证据可能灭失 | 建议同时申请保全 |
| RC-04 | 致送机关正确 | 生成致送机关 | 审查起诉→检察院；审判→法院；侦查→检察院（禁止向公安局申请） |
| RC-05 | 法条引用正确 | 引用法条时 | 以 legal-references.md §4 为唯一事实源；禁止引用第39条 |
| RC-06 | 审判阶段第57条 | 审判阶段申请 | 须书面+提供线索/材料 |

## 4. 行为约束

- 不保证申请获批准
- 不保证调取的证据对辩护有利
- 双重论证缺一不可
- 禁止为证据补充用户未提供的具体细节
- 禁止向公安机关申请调取证据
