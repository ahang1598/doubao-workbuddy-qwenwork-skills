## 3. 段落间距规则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制。

| 元素 | 段前 | 段后 |
|------|------|------|
| 标题 | 0 | 24pt |
| 节标题 | 12pt | 6pt |
| 信息区行 | 0 | 0 |
| 致送机关 | 6pt | 0 |
| 一级标题 | 12pt | 6pt |
| 二级标题 | 6pt | 3pt |
| 正文段落 | 0 | 0 |
| "此致" | 12pt | 0 |
| 落款第一行 | 12pt | 0 |
| 附件清单标题 | 18pt | 6pt |

## 4. 段落粒度规则

**一个段落 = 一个语义单元。**

| 语义单元类型 | 段落数 |
|-------------|--------|
| 申请调取证据详述 | 1段/项证据 |
| 证据关联性论证 | 1段/论证点 |
| 请求事项 | 1段/项 |

## 5. 编号规则

**使用 Word 原生 List Numbering。** 致送机关为信头不编号。正文首标题"一、"。

| 层级 | 编号 | 字体 |
|------|------|------|
| 一级 | "一、""二、" | 黑体三号 |
| 二级 | "（一）""（二）" | 楷体三号加粗 |
| 三级 | "1. ""2. "（Word List） | 仿宋三号 |

## 6. 区块分隔规则

信息区无边框两列表格（左25%+右75%）。正文区块分隔：标题→信息区（24pt）→致送机关（6pt）→前言（紧接）。"此致"→致送机关名（紧接）。落款→附件清单（段前18pt）。

## 7. 申请调取证据清单格式

每项证据独立成段，含五要素（与 methodology.md §七 统一标准）：
```
证据名称：[具体证据名称]，证据类型：[对齐刑诉法第50条8类]，
保存单位/持有人：[具体信息]，待证事实：[该证据能证明什么]，
证据线索：[如何发现/为何知道该证据存在]，
关联性：[与案件的关联性论证]，法律依据：审查起诉→刑诉法第41条；审判→第43条第1款后段+刑诉法解释第57条。
```

## 8. 理由部分三要素结构

申请调取证据的理由按以下顺序展开（五要素统一标准）：
1. **证据线索**：该证据存在/可能存在的具体线索
2. **卷宗缺失**：该证据为何不在现有卷宗中
3. **关联性**：该证据与案件的关联性论证（三层递进）
4. **必要性**：辩护人无法自行获取的原因（两层论证）
5. **法律依据**：审查起诉→刑诉法第41条；审判→第43条第1款后段+刑诉法解释第57条

## 9. 特殊格式规则

### 9.1 标题

```
文书标题居中，二号方正小标宋简体加粗，独占一行。
标题格式："关于[被告人姓名]涉嫌[罪名]一案收集、调取证据申请书"
段后间距24pt。
```

### 9.2 致送机关

```
致送机关按阶段确定：
- 侦查阶段 → XX市XX区人民检察院（向检察院申请，非公安局）
- 审查起诉阶段 → XX市XX区人民检察院
- 一审审判阶段 → XX市XX区人民法院
- 二审阶段 → XX市中级人民法院
"XX人民检察院/人民法院："顶格写，不加缩进。
冒号后不换行，正文紧接其后。
```

### 9.3 信息区表格化规则

申请人信息区使用**无边框两列表格**组织：

```
┌────────────────────────────────────────────┐
│ 申请人信息                                 │ ← 节标题（黑体三号加粗，左对齐）
├────────────────────────────────────────────┤
│ 申请人        │ [律师姓名]，[律所]律师     │
│ 执业证号      │ [XXX]                      │
│ 联系电话       │ [138-XXXX-XXXX]           │
│ 通讯地址       │ [XX市XX区XX路XX号]        │
│ 日期          │ [YYYY年MM月DD日]           │
└────────────────────────────────────────────┘
```

表格样式参数：
| 参数 | 值 |
|------|-----|
| 边框 | **无边框**（`w:val="none"`） |
| 列宽 | 左列 25%（字段名列），右列 75%（字段值列） |
| 行高 | 与 28 磅行距一致 |
| 字段名列字体 | 仿宋_GB2312 三号 **加粗**，左对齐 |
| 字段值列字体 | 仿宋_GB2312 三号，左对齐 |

### 9.4 "此致"与致送机关

```
"此致"：首行缩进2字符
致送机关全称：另起一行，顶格
"此致"与致送机关名之间不插空行
```

### 9.5 落款签名区

```
申请人：[律师签名]        （右对齐）
[律所名称]                （右对齐）
[日期]                    （右对齐，阿拉伯数字）
```

### 9.6 附件清单

```
签名后独立列出，不参与正文编号体系。
"附件清单"：仿宋三号加粗，左对齐，无缩进，段前18pt。
附件项：仿宋三号，首行缩进2字符。
包含法条索引等程序性附属信息。
```

### 9.7 O1 正式提交稿约束

- **禁止输出免责声明**：O1(.docx) 是提交给检察院/法院的正式文书，不得包含"免责声明"。免责声明仅限 O2(Markdown) 编辑稿保留。
- **正文禁止表格**：申请调取证据的理由论证正文中禁止使用任何表格，必须逐项分段叙述（证据线索→关联性→法律依据三要素自然衔接）。

## 10. 禁止事项

| # | 禁止项 | 正确做法 |
|---|--------|----------|
| F1 | 纸张非A4 | 必须A4 |
| F2 | 用空行分段 | 用段前/段后间距 |
| F3 | 多语义单元挤同一段落 | 每语义单元独立段落 |
| F4 | 手动编号 | Word原生List Numbering |
| F5 | 用"———"模拟分隔线 | Word段落底边框 |
| F6 | 图片/占位符 | 纯文字文书 |
| F7 | 段落缩进随机 | 首行缩进2字符 |
| F8 | 信息区纯文本分行 | 无边框表格 |
| F9 | "此致"与致送机关间空行 | 紧接 |
| F10 | 落款未右对齐 | 右对齐 |
| F11 | 证据详述混在正文 | 独立成段 |
| F12 | 致送机关错误 | 按阶段确定正确机关 |
| F13 | 正文论证表格 | 纯文字叙述 |
| F14 | O1含免责声明 | O1正式提交稿无免责声明 |
| F15 | 理由缺五要素任一项 | 证据线索+卷宗缺失+关联性+必要性+法律依据齐全 |
| F16 | 混淆第41条与第43条/引用第39条 | 第41条=申请调取（审查起诉）；第43条第1款后段=申请法院调取（审判）；第43条第1款前段=自行取证；禁止引用第39条（=会见通信权） |
| F17 | 申请调取范围无边界 | 明确具体证据/不泛泛申请/一次不超过3项 |
| F18 | 附件清单参与正文编号 | 签名后独立列出 |

## 13. 排版规范来源

| 来源 | 适用范围 | 说明 |
|------|----------|------|
| GB/T 9704-2012 | 页边距/行距/页码 | 国家标准（T0） |
| 法发〔2016〕13号 | 标题/正文字号层级 | T1 司法规范 |
| 全国律协《律师办理刑事案件规范》(2017)第41-50条 | 调查取证申请 | T2 |
| 最高法《刑事诉讼文书样式》2020版 | 文书结构参照 | T1 |
| 律师行业实务惯例 | 致送/落款格式 | T3行业惯例 |

> **注**：律师向办案机关提交的收集、调取证据申请书无国家强制统一排版标准，上述规范参照 GB/T 9704-2012 及司法文书排版习惯，为行业通行专业惯例。
