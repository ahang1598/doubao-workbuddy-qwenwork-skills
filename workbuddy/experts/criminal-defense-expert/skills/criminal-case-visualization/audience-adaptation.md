# 受众适配规则 — 刑事案件可视化

## 1. 术语对照表

| 法律术语 | 家属版替换 | 使用场景 |
|---------|-----------|---------|
| 侦查 | 调查阶段 | 阶段说明 |
| 审查起诉 | 检察院审查阶段 | 阶段说明 |
| 强制措施 | 强制限制人身自由的措施 | 概念解释 |
| 拘留 | 先行关押 | 状态说明 |
| 逮捕 | 正式批准关押 | 状态说明 |
| 取保候审 | 交保证金先放出来 | 措施说明 |
| 监视居住 | 在指定地方居住，不能随便离开 | 措施说明 |
| 法定刑 | 法律规定的处罚范围 | 量刑说明 |
| 基准刑 | 一般情况下的处罚标准 | 量刑说明 |
| 从轻处罚 | 比一般情况判得轻 | 量刑说明 |
| 从重处罚 | 比一般情况判得重 | 量刑说明 |
| 缓刑 | 暂时不执行，观察期表现好就不执行了 | 刑罚说明 |
| 数罪并罚 | 多个罪名一起算总刑期 | 量刑说明 |
| 退回补充侦查 | 检察院觉得证据不够，退回公安继续查 | 流程说明 |

## 2. 语气规范

### 律师版

- **人称**：第三人称客观描述（"当事人""嫌疑人""被告人"）
- **语气**：中性、专业、简洁
- **法条**：直接引用〔刑诉法第XX条〕
- **数据**：精确数字（"37日""2个月""3-10年"）

### 家属版

- **人称**：第二人称（"您""您的家人"）
- **语气**：温暖、专业、不恐慌、有希望但务实
- **法条**：不标注编号，用脚注通俗解释
- **数据**：概数+类比（"大约1个月左右""法律允许最多关2个月""最轻可能判缓刑"）

## 3. 情感支持话术（家属版专用）

### 开场白

```
您好，这份图表是根据您提供的案件信息生成的，目的是帮助您了解案件目前的进展和可能的走向。
请注意，以下内容仅供参考，不构成法律意见，具体案件请咨询您的律师。
```

### 羁押时间线

```
根据法律规定，目前您家人处于XX阶段。法律对这个阶段有明确的时间限制，
最长不能超过XX天。我们用时间线帮您看清楚现在走到哪里了。
```

### 量刑路径

```
关于量刑，法律对XX罪规定了处罚范围。每个案件的具体情况不同，
最终判决由法院决定。下面展示的是法律规定的范围，供您了解。
```

### 结尾

```
以上信息基于当前了解的案件情况。案件进展可能有变化，
建议您定期与律师沟通了解最新情况。如有疑问，请随时联系您的律师。
```

## 4. 详略策略

| 内容类型 | 律师版 | 家属版 |
|---------|--------|--------|
| 流程阶段 | 6阶段全列+法定期限条文 | 6阶段简化+通俗时间估计 |
| 羁押数据 | 精确天数+法定期限+条文 | "已关X天/最长Y天"+关键节点 |
| 量刑范围 | 法定刑档位+条文+情节调节 | "最轻→最重"+非预测声明 |
| 当事人权利 | 法条引用+权利清单 | "您可以做什么"+通俗说明 |
| 免责声明 | 页脚一行 | 首页顶部+每页页脚 |

## 5. 家属版红线

| # | 红线 | 原因 |
|---|------|------|
| 1 | 不说"一定会判XX年" | 非预测，可能误导 |
| 2 | 不说"肯定能取保" | 取保由办案机关决定 |
| 3 | 不说"不用担心" | 过度安抚可能误导 |
| 4 | 不渲染"最坏情况" | 制造恐慌，不利于理性决策 |
| 5 | 不提供"建议您采取XX行动" | 非法律建议 |
