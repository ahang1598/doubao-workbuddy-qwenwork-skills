# 羁押期限规则 — 刑事案件可视化

## 1. 拘留期限

| 起算点 | 一般期限 | 延长期限 | 最长期限 | 法条 |
|--------|---------|---------|---------|------|
| 拘留之日 | 3日 | +1-4日（流窜/结伙/多次） | 37日（含批捕审查） | 《刑事诉讼法》第91条 |

### 计算方法

```
拘留日 → 第3日：公安决定是否提请批捕
  ↓（一般情况）
提请批捕 → 检察院7日内决定
  ↓
总拘留期限 = 3+7 = 10日（一般）

  ↓（流窜/结伙/多次作案）
提请批捕可延长1-4日 → +检察院30日内决定
  ↓
总拘留期限 = 3+4+30 = 37日（最长）
```

## 2. 逮捕后侦查羁押期限

| 层级 | 期限 | 条件 | 法条 |
|------|------|------|------|
| 基本期限 | 2个月 | 逮捕后 | 《刑事诉讼法》第156条 |
| 一延 | +1个月 | 案情复杂，上一级检察院批准 | 《刑事诉讼法》第156条 |
| 二延 | +2个月 | 四类重大复杂案件，省级检察院批准 | 《刑事诉讼法》第158条 |
| 三延 | +2个月 | 可能判10年以上，省级检察院批准 | 《刑事诉讼法》第159条 |

**四类重大复杂案件**：交通不便边远地区/犯罪集团/流窜作案/面广取证困难

### 计算方法

```
逮捕日 → 2个月：基本侦查羁押期
  ↓（案情复杂，经上一级检察院批准）
+1个月 → 共3个月
  ↓（四类重大复杂，经省/自治区/直辖市检察院批准）
+2个月 → 共5个月
  ↓（可能判10年以上，经省/自治区/直辖市检察院批准）
+2个月 → 共7个月
```

## 3. 审查起诉期限

| 层级 | 期限 | 条件 | 法条 |
|------|------|------|------|
| 基本期限 | 1个月 | 受理后 | 《刑事诉讼法》第172条 |
| 延长 | +15日 | 重大复杂案件 | 《刑事诉讼法》第172条 |
| 退回补充侦查 | 1个月/次 | 证据不足 | 《刑事诉讼法》第175条 |
| 退查后重新计算 | 1个月 | 补侦后 | 《刑事诉讼法》第175条 |

### 计算方法

```
受理日 → 1个月（+15日延长）
  ↓（退回补充侦查）
1个月补侦 → 重新计算1个月（+15日延长）
  ↓（最多退回2次）
最长 = (1+0.5) + 1 + (1+0.5) + 1 + (1+0.5) = 6.5个月
```

## 4. 审判期限

| 层级 | 期限 | 条件 | 法条 |
|------|------|------|------|
| 一审基本 | 2个月 | 受理后 | 《刑事诉讼法》第208条 |
| 一审延长 | +1个月 | 至迟3个月 | 《刑事诉讼法》第208条 |
| 一审再延 | +3个月 | 死刑+附带民事等，高院批准 | 《刑事诉讼法》第208条 |
| 二审基本 | 2个月 | 受理后 | 《刑事诉讼法》第243条 |
| 二审延长 | +2个月 | 死刑+附带民事等，高院批准 | 《刑事诉讼法》第243条 |

## 5. 家属版通俗推算

| 阶段 | 通俗表述 | 大约时间 |
|------|---------|---------|
| 拘留 | "关在里面等批捕" | 10-37天 |
| 逮捕后侦查 | "公安继续查案" | 2-7个月 |
| 审查起诉 | "检察院看案卷决定要不要起诉" | 1-1.5个月（可能退回补侦） |
| 一审 | "法院第一次开庭审理" | 2-6个月 |
| 二审 | "如果上诉，上级法院再审一次" | 2-4个月 |

**从拘留到一审判决**：最短约5个月，最长可能1-2年（视案件复杂度）。

> **注意**：以上为一般情况推算，个别案件可能因特殊情况（如补充侦查、中止审理等）延长。
