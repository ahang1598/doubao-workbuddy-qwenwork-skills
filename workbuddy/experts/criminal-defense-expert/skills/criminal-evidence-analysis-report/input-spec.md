# 输入规格

> 本文件定义 criminal-evidence-analysis 技能的完整输入参数规格
> 遵循 compiler/ssot.md §17（SSOT）：输入宽容度契约

## 1. 必需输入

### 1.1 案件基本信息

| 字段 | 类型 | 枚举值 | 说明 | 验证规则 |
|------|------|--------|------|----------|
| `case_name` | string | - | 案件名称（被告人+罪名） | 非空 |
| `alleged_crime` | string | - | 涉嫌罪名 | 非空 |
| `analysis_perspective` | enum | defense/prosecution/third_party | 分析视角 | 必须为枚举值 |

### 1.2 证据材料

| 字段 | 类型 | 说明 | 验证规则 |
|------|------|------|----------|
| `evidence_materials` | string | 证据材料描述 | 非空，自由文本或结构化清单 |

## 2. 可选输入

### 2.1 案件信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `case_stage` | enum | 一审 | 侦查/审查起诉/一审/二审 |
| `suspect_name` | string | [待补充] | 犯罪嫌疑人/被告人姓名 |
| `defendant_status` | enum | 在押 | 在押/取保/监视居住 |
| `prosecution_facts` | string | [待补充] | 指控事实概要 |

### 2.2 证据详细信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `witness_testimony` | array[string] | [] | 证人证言要点 |
| `defendant_statement` | string | [待补充] | 被告人供述/辩解 |
| `documentary_evidence` | array[string] | [] | 书证清单 |
| `physical_evidence` | array[string] | [] | 物证清单 |
| `expert_opinion` | array[string] | [] | 鉴定意见清单 |
| `audio_visual` | array[string] | [] | 视听资料/电子数据 |
| `other_evidence` | array[string] | [] | 其他证据 |

### 2.3 分析参数

| 字段 | 类型 | 枚举值 | 默认值 | 说明 |
|------|------|--------|--------|------|
| `analysis_depth` | enum | overview/detailed/comprehensive | comprehensive | 分析深度 |
| `focus_areas` | array[string] | [] | [] | 重点关注领域（如"非法证据排除"） |
| `defense_objective` | enum | 无罪/罪轻/减轻/量刑 | 量刑 | 辩护目标（defense视角时） |

## 3. 输入宽容度契约

### 3.1 最小输入识别

| 最小输入 | 触发条件 | 处理方式 |
|----------|----------|----------|
| 仅案件名称+罪名 | 基础二要素 | 生成证据分析框架，待补充 |
| 仅证据清单 | 最小输入 | 按证据类型自动分类分析 |
| 上游技能产物 | criminal-case-reading-notes | 直接消费结构化数据 |
| 自然语言描述 | 非结构化输入 | 提取结构化字段 |

### 3.2 信息补全策略

1. **从证据描述中提取**：按证据八大类自动分类
2. **推理补全**：根据罪名推理常见证据类型
3. **上游消费**：优先使用criminal-case-reading-notes产物
4. **占位符标注**：无法提取的信息用 `[待补充]` 标注

### 3.3 交互补全限制

交互补全最多3轮，超过后强制进入 SOFT_DEGRADED 模式。

## 4. 场景适配规则

### 4.1 分析视角适配

| 视角 | 分析侧重点 | 典型用户 |
|------|-----------|----------|
| defense（辩护） | 证据弱点+质证要点+补证方向 | 辩护律师 |
| prosecution（控诉） | 证据链完整性+证明力+补强建议 | 公诉人/被害方代理 |
| third_party（第三方） | 客观评估+专家意见 | 法院/鉴定机构 |

### 4.2 证据三性分析维度

| 维度 | 定义 | 辩护视角重点 | 控诉视角重点 |
|------|------|-------------|-------------|
| 客观性 | 证据是否真实可靠 | 可疑点/矛盾/失真风险 | 来源合法/内容可靠 |
| 关联性 | 证据与待证事实的联系 | 关联度不足 | 直接/间接关联 |
| 合法性 | 证据收集程序合法 | 程序违法/非法证据 | 程序合规/取证规范 |

### 4.3 证明力评估标准

| 等级 | 标准 | 典型证据 |
|------|------|----------|
| 强 | 直接证明待证事实，无相反证据 | 视听资料完整记录/鉴定意见明确 |
| 中 | 间接证明或需补强 | 证人证言一致/书证佐证 |
| 弱 | 证明力有限或存在疑点 | 孤证/传闻证据/有矛盾的证言 |
