# 工作流详述

> 本文件定义 criminal-evidence-analysis 技能的各Phase子步骤与检查点
> 遵循 compiler/ssot.md §17（SSOT）：按需拆分规则
> v2.1.0：Phase 3 拆分为言词/实物双路径审查；Phase 4 增加排除合理怀疑论证路径；Phase 3.5 增加矛盾点结构化分析

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 证据分类 → Phase 3: 三性分析[L3]（言词/实物双路径）
    ↓
Phase 3.5: 矛盾点结构化分析 → Phase 4: 证据链分析[L3]（含排除合理怀疑论证路径）
    ↓
Phase 5: 质证要点 → Phase 6: 补证方向 → Phase 7: 输出交付
```

## 2. Phase 1: 输入验证

### 1.1 输入解析

| 步骤 | 操作 | 产出 |

| 1.1.2 | 提取案件基本信息 | case_name, alleged_crime, analysis_perspective |
| 1.1.3 | 提取证据材料清单 | 按八大类分类 |

## 3. Phase 2: 证据分类

### 2.1 按法定八大类分类

| 证据类别 | 定义 | 典型形式 | 审查路径 |
|----------|------|----------|---------|
| 物证 | 以外部特征/物质属性证明案件事实 | 凶器/毒品/赃物 | → 实物证据路径 |
| 书证 | 以记载内容证明案件事实 | 合同/账本/信件 | → 实物证据路径 |
| 证人证言 | 证人就其所了解的案件情况所作陈述 | 询问笔录/书面证言 | → 言词证据路径 |
| 被害人陈述 | 被害人就案件情况所作陈述 | 询问笔录 | → 言词证据路径 |
| 犯罪嫌疑人/被告人供述和辩解 | 嫌疑人/被告人就案件情况所作陈述 | 讯问笔录 | → 言词证据路径 |
| 鉴定意见 | 鉴定人运用专门知识作出的判断 | 法医鉴定/毒品鉴定/指纹鉴定 | → 鉴定意见专项审查 |
| 勘验/检查/辨认/侦查实验笔录 | 侦查活动记录 | 现场勘查笔录/辨认笔录 | → 实物证据路径 |
| 视听资料/电子数据 | 录音录像/电子数据 | 监控录像/微信记录/通话记录 | → 实物证据路径（含电子数据专项） |

### 2.2 证据分类时的来源可信度标注

| 来源类型 | 可信度等级 | 标注方式 |
|---------|-----------|---------|
| 中立第三方（银行/监控/鉴定机构） | 较高 | `[来源可信度：较高]` |
| 侦查机关 | 需审查 | `[来源可信度：需审查取证程序]` |
| 利害关系人（被害人/行贿人/同案犯） | 较低 | `[来源可信度：较低-利害关系人]` |

### 2.3 Phase 2 检查点

- [ ] 证据已按八大类分类
- [ ] 分类无遗漏
- [ ] 证据编号已建立
- [ ] 来源可信度已标注

## 4. Phase 3: 三性分析 [L3高风险]（言词/实物双路径审查）

> **v2.1.0 关键变更**：将原统一的三性审查框架拆分为言词证据与实物证据两套并行审查流程。言词证据和实物证据的审查逻辑完全不同，用一套框架套所有证据会导致输出浅薄。

### 3.0 路径选择

```
证据分类结果 → 言词证据（证人证言/被害人陈述/被告人供述）→ 路径A
             → 实物证据（物证/书证/视听资料/电子数据/笔录类）→ 路径B
             → 鉴定意见 → 路径C（专项审查）
```

### 3.1 路径A：言词证据三性审查

#### 3.1.1 客观性（真实性）审查

| 审查维度 | 审查要点 | 评估标准 |
|----------|----------|----------|
| 陈述的稳定性 | 多次陈述是否一致？不一致的具体点在哪里？ | 稳定/部分不稳定/频繁翻转 |
| 陈述的变化规律 | 是"由模糊到清晰"还是"由清晰到模糊"？ | 由模糊到清晰→可疑 / 由清晰到模糊→正常 |
| 陈述的合理细节 | 是否包含"只有亲历者才知道"的细节？ | 暗合（高证明力）/ 明合（低证明力）/ 无细节 |
| 陈述者的感知能力 | 观察条件、记忆能力、表达能力 | 充分/受限/严重受限 |
| 陈述者的利害关系 | 与当事人/案件结果有无利益关联 | 无/间接/直接利害关系 |

#### 3.1.2 关联性审查

| 审查维度 | 审查要点 | 评估标准 |
|----------|----------|----------|
| 待证事实指向 | 该陈述指向哪个具体的待证事实？ | 必须标注具体待证事实，不能笼统说"与案件有关" |
| 证明价值 | 证明待证事实的价值大小 | 直接证明/间接证明/仅背景信息 |
| 累积效果 | 与其他证据的印证/矛盾关系 | 印证（暗合/明合）/独立/矛盾 |

#### 3.1.3 合法性审查

| 审查维度 | 审查要点 | 评估标准 |
|----------|----------|----------|
| 询问/讯问主体 | 是否为法定人员？是否两人以上？ | 合规/瑕疵/违法 |
| 询问/讯问程序 | 是否告知权利义务？是否保障律师权利？ | 合规/瑕疵/违法 |
| 同步录音录像 | 是否全程、有无中断、有无剪辑？ | 完整/有缺失/无录音录像 |
| 询问/讯问方式 | 是否诱导性提问/指供/诱供？ | 正常/有诱导/疑似刑讯 |

### 3.2 路径B：实物证据三性审查

#### 3.2.1 客观性（真实性）审查

| 审查维度 | 审查要点 | 评估标准 |
|----------|----------|----------|
| 来源可靠性 | 提取程序是否合法？提取人是否有权？ | 可信/存疑/不可信 |
| 内容真实性 | 证据内容是否完整？有无删改痕迹？ | 真实/有矛盾/虚假 |
| 保管链完整性 | 从提取到法庭出示的完整流转记录 | 完整/有缺口/断裂 |
| 技术可靠性 | 鉴定方法/技术手段是否可靠？ | 可靠/存疑/不可靠 |
| 原始性审查 | 是否为原件/原物？复制品与原件一致性？ | 原件/核对无误的复制件/无法核对 |

#### 3.2.2 关联性审查

| 审查维度 | 审查要点 | 评估标准 |
|----------|----------|----------|
| 待证事实指向 | 该证据指向哪个具体的待证事实？ | 必须标注具体待证事实 |
| 关联的间接性 | 实物证据通常只能间接证明，不能过度推导 | 直接关联/间接关联需推理/无关联 |
| 证明价值衰减 | 推理链条越长，证明力越弱 | 无衰减/一度衰减/多度衰减 |

> **过度推导防控**：指纹→盗窃行为（过度）；指纹→到过现场（适当）。银行流水→受贿（过度）；银行流水→资金往来（适当）。

#### 3.2.3 合法性审查

| 审查维度 | 审查要点 | 评估标准 |
|----------|----------|----------|
| 提取程序的合法性 | 搜查扣押手续、勘验检查笔录是否齐全？ | 合法/瑕疵/违法 |
| 保管程序的合规性 | 保管链各环节是否可追溯？见证人签名？ | 合规/有缺口/断裂 |
| 鉴定的必要性 | 是否需要鉴定？鉴定是否充分？ | 已充分鉴定/需补充鉴定/未鉴定 |
| 权利保障 | 当事人权利是否得到保障？ | 保障/部分保障/未保障 |

### 3.3 路径C：鉴定意见专项审查

#### 3.3.1 鉴定意见四要素审查

| 要素 | 审查要点 | 不合格标准 |
|------|---------|-----------|
| ①检材来源 | 检材是否合法提取？保管链是否完整？ | 检材来源不明→鉴定意见失去基础 |
| ②鉴定方法 | 方法是否科学可靠？是否有国家/行业标准？ | 非标准方法且未说明→可靠性存疑 |
| ③比对标准 | 比对样本是否充分？方法是否可靠？ | 样本量不足→比对结论不可靠 |
| ④结论逻辑链 | 结论是否由前提必然推出？是否超出鉴定范围？ | 超出鉴定范围→越权鉴定，不可采 |

### 3.4 Phase 3 检查点

- [ ] 言词证据已按路径A审查
- [ ] 实物证据已按路径B审查
- [ ] 鉴定意见已按路径C审查
- [ ] 每项证据的来源可信度已标注
- [ ] 非法证据排除建议已提出（如有）

## 5. Phase 3.5: 矛盾点结构化分析

> **v2.1.0 新增**：证据矛盾是辩护的弹药，必须做结构化分析。

### 3.5.1 矛盾类型分类

| 矛盾类型 | 定义 | 示例 |
|---------|------|------|
| 自相矛盾 | 同一证据内部前后不一致 | 同一次供述中先说"在A地"后说"在B地" |
| 横向矛盾 | 不同证据之间的矛盾 | 证人A说"晴天"，证人B说"下雨" |
| 纵向矛盾 | 同一证据在不同时间的矛盾 | 第1次证言说"9点"，第3次说"下午3点" |
| 证据与客观事实矛盾 | 证据内容与可验证的客观事实不符 | 证言说"晴天"但气象记录显示下雨 |

### 3.5.2 矛盾点优先级标注

| 优先级 | 定义 | 辩护价值 |
|--------|------|---------|
| 🔴核心矛盾 | 涉及定罪要件的矛盾 | 必须重点标注，作为主攻方向 |
| 🟡次要矛盾 | 涉及量刑情节的矛盾 | 标注但不作为主攻方向 |
| 🟢表面矛盾 | 可能只是表述差异 | 标注但说明可能解释，避免过度解读 |

### 3.5.3 矛盾的处理建议

| 处理等级 | 适用情形 | 处理方式 |
|---------|---------|---------|
| 排除 | 证据因矛盾导致不可信，且可申请排除 | 标注排除依据（刑诉法第56条/第60条） |
| 解释 | 矛盾有合理解释，但不影响证据采信 | 标注合理解释 |
| 容忍 | 矛盾属于正常记忆偏差或表述差异 | 标注但说明属正常范围 |

### 3.5.4 Phase 3.5 检查点

- [ ] 所有证据间的矛盾已识别
- [ ] 矛盾类型已分类
- [ ] 优先级已标注
- [ ] 处理建议已给出

## 6. Phase 4: 证据链分析 [L3高风险]（含排除合理怀疑论证路径）

> **v2.1.0 关键变更**：增加按犯罪构成要件维度拆分证据链 + 排除合理怀疑论证路径。

### 4.1 控方证据链

| 步骤 | 操作 | 产出 |
|------|------|------|
| 4.1.1 | 按犯罪构成要件维度梳理控方证据链条 | 按要件拆分的证据链图 |
| 4.1.2 | 逐一检验每个要件的证据链闭合性 | 每个要件的闭合/薄弱/断裂评估 |
| 4.1.3 | 识别关键节点 | 核心证据/辅助证据 |

### 4.2 证据链缺口

| 缺口类型 | 定义 | 辩护价值 |
|----------|------|----------|
| 事实缺口 | 待证事实缺乏证据 | 可主张事实不清 |
| 关联缺口 | 证据间关联薄弱 | 可主张证据不足 |
| 补强缺口 | 证据需补强而无补强 | 可主张孤证不能定案 |

### 4.3 排除合理怀疑论证路径

#### 4.3.1 合理替代解释提出步骤

| 步骤 | 操作 | 产出 |
|------|------|------|
| 步骤1 | 识别控方证据链的所有节点 | 按犯罪构成要件维度梳理的完整证据链图 |
| 步骤2 | 对每个节点逐一提出替代解释 | 每个节点的替代解释清单 |
| 步骤3 | 评估替代解释是否"合理"（而非"可能"） | 合理=有证据/逻辑支撑；可能=纯粹想象 |
| 步骤4 | 如存在合理替代解释，即存在合理怀疑 | 合理怀疑清单 |
| 步骤5 | 合理怀疑不需要辩方证明，只需提出合理性质疑 | 辩护策略建议 |

#### 4.3.2 合理替代解释示例

| 控方证据链节点 | 控方主张 | 合理替代解释 | 评估 |
|--------------|---------|-------------|------|
| 指纹匹配95% | 被告人到过现场 | 被告人此前作为访客到过（有合理来源） | 合理——需排除此前到访可能 |
| 银行存款28万 | 印证受贿30万 | 28万可能是工资/投资收益/借款（金额也不一致） | 合理——金额不吻合且来源有多种可能 |
| 行贿人证言 | 证实行贿行为 | 行贿人系利害关系人，可能推卸责任或减轻自身处罚 | 合理——利害关系人动机明显 |

### 4.4 证明标准阶梯适用

| 案件阶段 | 适用标准 | 分析要求 |
|---------|---------|---------|
| 逮捕 | 有证据证明有犯罪事实（第81条） | 评估是否达到逮捕标准 |
| 审查起诉 | 证据确实充分（第176条） | 评估是否达到起诉标准 |
| 一审定罪 | 排除合理怀疑（第55条第2款第3项） | 评估是否达到定罪标准 |
