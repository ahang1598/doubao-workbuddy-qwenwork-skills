## 2. mandatory 法条（必须引用）

### 2.1 核心法条

| 序号 | 法条 | 内容摘要 | 引用场景 | 注意事项 |
|------|------|---------|---------|---------|
| 1 | 刑诉法第50条 | 证据种类（八大类） | 证据分类 | 必须准确识别证据种类 |
| 2 | 刑诉法第51条 | 举证责任 | 举证责任分配 | 公诉案件由检察院承担举证责任 |
| 3 | 刑诉法第55条 | 证明标准（证据确实充分） | 证明力评估 | **最核心法条**。第55条第2款第3项="排除合理怀疑" |
| 4 | 刑诉法第56条 | 非法证据排除（言词证据+物证/书证） | 合法性审查 | 言词=应当排除；物证/书证=严重影响+不能补正→应当排除 |
| 5 | 刑诉法第57条 | 检察院对非法取证的监督职责 | 非法证据排除启动 | 辩方申请排除时"向谁主张、怎么启动"的关键法条。审查起诉阶段主张排除的程序依据 |
| 6 | 刑诉法第58条 | 法庭对证据合法性调查 | 合法性审查启动 | 审判人员认为可能存在非法→应当调查；当事人有权申请排除 |
| 7 | 刑诉法第59条 | 证据合法性举证责任 | 合法性审查 | 检察院对证据收集合法性举证；可提请侦查人员出庭说明 |
| 8 | 刑诉法第60条 | 非法证据排除的法庭处理规则 | 合法性审查结论 | 确认或不能排除存在第56条情形→应当排除。⚠️非"证人证言审查" |

> **G5 易错法条防御**：刑诉法第56-60条系列是错误高发区（known-pitfalls-registry.md §1.4）。所有引用第56/57/58/59/60条时强制检查内容标注是否正确。

### 2.2 法条原文引用

#### 刑诉法第50条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十条：

可以用于证明案件事实的材料，都是证据。

证据包括：
（一）物证；
（二）书证；
（三）证人证言；
（四）被害人陈述；
（五）犯罪嫌疑人、被告人供述和辩解；
（六）鉴定意见；
（七）勘验、检查、辨认、侦查实验等笔录；
（八）视听资料、电子数据。

证据必须经过查证属实，才能作为定案的根据。
```

#### 刑诉法第55条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十五条：

对一切案件的判处都要重证据，重调查研究，不轻信口供。只有被告人供述，没有其他证据的，不能认定被告人有罪和处以刑罚；没有被告人供述，证据确实、充分的，可以认定被告人有罪和处以刑罚。

证据确实、充分，应当符合以下条件：
（一）定罪量刑的事实都有证据证明；
（二）据以定案的证据均经法定程序查证属实；
（三）综合全案证据，对所认定事实已排除合理怀疑。
```

#### 刑诉法第56条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十六条：

采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述和采用暴力、威胁等非法方法收集的证人证言、被害人陈述，应当予以排除。收集物证、书证不符合法定程序，可能严重影响司法公正的，应当予以补正或者作出合理解释；不能补正或者作出合理解释的，对该证据应当予以排除。

在侦查、审查起诉、审判时发现有应当排除的证据的，应当依法予以排除，不得作为起诉意见、起诉决定和判决的依据。
```

#### 刑诉法第57条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十七条：

人民检察院接到报案、控告、举报或者发现侦查人员以非法方法收集证据的，应当进行调查核实。对于确有以非法方法收集证据情形的，应当提出纠正意见；构成犯罪的，依法追究刑事责任。
```

#### 刑诉法第60条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第六十条：

对于经过法庭审理，确认或者不能排除存在本法第五十六条规定的以非法方法收集证据情形的，对有关证据应当予以排除。
```

#### 刑诉法第61条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第六十一条：

证人证言必须在法庭上经过公诉人、被害人和被告人、辩护人双方质证并且查实以后，才能作为定案的根据。法庭查明证人有意作伪证或者隐匿罪证的时候，应当依法处理。
```

#### 刑诉法第62条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第六十二条：

凡是知道案件情况的人，都有作证的义务。
生理上、精神上有缺陷或者年幼，不能辨别是非、不能正确表达的人，不能作证人。
```

### 3.1 最高法刑诉法解释第四章（2021年）完整条文范围

## 4. misuse_warnings（易混淆法条警告）

| 易混淆 | 正确法条 | 错误风险 | 区分要点 |
|--------|----------|----------|----------|
| 非法证据排除≠全案证据排除 | 第56条 | 过度排除 | 仅排除特定非法证据 |
| 言词证据排除≠物证排除标准 | 第56条第1款 vs 第2款 | 标准不同 | 言词=应当排除，物证=可能严重影响+不能补正 |
| 第60条≠证人证言审查 | 第60条=非法证据排除法庭处理 | ⚠️ v2.0.1版标错 | 证人证言审查依据是最高法刑诉法解释第三节（第86-94条），不是刑诉法第60条 |
| 第62条≠证据关联性 | 第62条=证人作证义务与证人资格 | ⚠️ v2.0.1版标错 | 关联性审查无单独法条，依据是最高法刑诉法解释第69条的一般规定 |
| 证明责任≠举证责任 | 第55条 | 混淆概念 | 证明责任在控方，辩护人不承担 |
| 补强证据≠印证证据 | 第55条 | 概念混淆 | 补强=支持主证据，印证=互相支持 |
| 鉴定意见≠鉴定结论 | 第50条第6项 | 术语过时 | 2012年修正后改为"鉴定意见" |
| 第57条≠第59条 | 第57条=检察监督 / 第59条=举证责任 | 程序阶段混淆 | 第57条=审查起诉阶段主张排除的程序依据；第59条=法庭调查阶段的举证责任分配 |

## 5. 地区规定

| 地区 | 规定名称 | 主要内容 | 引用优先级 | 规范层级 |

> **地区差异提示**：虽然法律合规声明中标注"证据规则适用全国统一标准"，但实务中各地对非法证据排除的把握宽严不一，电子证据取证标准也有地区差异。分析报告中应提醒律师注意当地实践差异。

## 6. 证据要求

### 6.1 证据分析建议收集的信息

| 信息类型 | 对应分析 | 说明 |
|----------|----------|------|
| 证据原件/复印件 | 三性审查 | 尽可能查看原件 |
| 取证过程说明 | 合法性审查 | 了解取证程序 |
| 鉴定原始材料 | 鉴定意见审查 | 检材/样本/方法 |
| 证人背景信息 | 证言可靠性 | 与当事人关系/利益关联 |
| 保管链记录 | 客观性审查 | 证据保管过程 |
| 同步录音录像 | 供述/证言合法性 | 是否全程、有无中断、有无剪辑 |
