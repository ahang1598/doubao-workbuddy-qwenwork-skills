# 风险框架：criminal-evidence-analysis

> 刑事证据分析 | 版本: v1.2.0

## 1. 风险等级

**L2（中等风险）**——证据分析影响案件走向，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 事实框架构建 | L2 | 中风险 |
| Phase 3 证据三性初筛 | **L3** | **高风险**——证据合法性判断涉及专业判断 |
| Phase 4 证据链完整性分析 | **L3** | **高风险**——证据链闭合性影响定罪 |
| Phase 5 不利证据风险 | L2 | 中风险 |
| Phase 6 补证策略 | L2 | 中风险 |
| Phase 7 报告组装 | L1 | 低风险 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 禁止替代律师判断 | 评估证明力时 | 标注"供律师参考" |
| RC-02 | 孤证标注 | 仅有单一证据 | 标注"孤证不能定案" |
| RC-03 | 非法证据提示 | 发现程序违法 | 建议使用evidence-exclusion |
| RC-04 | 鉴定意见专项审查 | 涉及鉴定意见 | 四要素必须审查 |

## 4. 行为约束

- 证明力评估供参考，不替代律师判断
- 孤证不能定案原则必须标注
- 发现非法证据线索须提示排除申请
