# 质量评价标准

> 本文件定义 criminal-electronic-evidence-analysis 技能的质量评价标准

## 1. 输出质量维度

### 1.1 完整性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 12维度覆盖 | A1-A4/B5-B8/C9-C12 每项电子证据均有评估 | 🔴阻断（遗漏维度→分析不完整） |
| 证据清单覆盖 | 每项电子证据均在解构清单中有条目 | 🔴阻断（遗漏证据→分析不完整） |
| 哈希值审查 | 每项电子证据标注哈希值状态 | 🔴阻断（遗漏哈希值状态→完整性审查失效） |
| 取证程序审查 | 每项电子证据标注取证方式及合规性 | 🔴阻断（遗漏程序审查→合法性审查失效） |
| 下游动作 | 每个辩护点均有可执行建议 | ⚠️警告 |

### 1.2 准确性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 法条精确 | 引用精确到条/款/项，标明法规简称 | 🔴阻断（笼统引用→必须修正） |
| 法条内容 | 引用的法条内容与现行有效版本一致 | 🔴阻断（法条错误→阻断级修复） |
| 哈希值比对 | 哈希值比对结果与输入一致 | 🔴阻断（比对错误→核心功能失效） |
| 瑕疵vs非法 | 第27条瑕疵与第28条非法严格区分 | 🔴阻断（混淆→法律后果严重） |
| 风险等级 | 风险等级与事实依据一致 | ⚠️警告 |

### 1.3 安全性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 无罪推定 | "涉嫌"而非"构成"，无"罪犯"等表述 | 🔴阻断 |
| 无真实性终判 | 无"数据真实/虚假"等断言，仅标注校验结果 | 🔴阻断 |
| 无替代判断 | 辩护建议标注"建议"而非"应当" | ⚠️警告 |
| 设备≠人 | 关联性分析须独立论证主体同一性 | 🔴阻断（直接等同→关联性审查失效） |
| 置信度标注 | 主体同一性/时间线重建标注置信度 | ⚠️警告 |

### 1.4 可操作性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 下游推荐 | 每个辩护点映射到具体下游技能 | ⚠️警告 |
| 法条依据 | 每个排除/质证建议含法条依据 | 🔴阻断（无法条→建议不可操作） |
| 同一性缺口 | 主体同一性映射链缺口头显性标注 | ⚠️警告 |
| 哈希值缺失显性化 | 未提供哈希值的证据显性标注风险 | 🔴阻断 |

## 2. 各维度质量标准

| 维度 | 核心质量指标 | 最低标准 |
|------|------------|---------|
| A1 载体识别 | 载体类型标注完整 | 每项证据标注载体类型和扣押状态 |
| A2 完整性核验 | 哈希值状态显性标注 | 每项证据标注是否有哈希值及校验结果；哈希值不一致时必须分析原因（系统性变化vs针对性篡改）并给出降级判断（第27条瑕疵vs第28条非法） |
| A3 取证程序合法性 | 程序合规性逐项审查 | 扣押/见证/笔录/签名四项至少审查3项 |
| A4 收集方式合法性 | 收集方式与授权匹配 | 标注收集方式并审查审批手续 |
| A2.5 保管链连续性 | 保管链逐环节审查 | 扣押→提取→移送→展示，每环节标注交接记录和校验值状态 |
| B5 主体同一性 | 映射链完整性评估 | 网络ID→现实身份的映射至少评估1步 |
| B6 时间线重建 | 关键时间节点提取 | 至少标注最早/最晚时间戳 |
| B7 多源印证 | 印证方向标注 | 每项证据标注印证状态（印证/矛盾/孤证） |
| B8 删除/篡改痕迹 | 痕迹检查 | 标注是否有删除/修改记录 |
| C9 客观性挑战 | 污染环节识别 | 至少识别1个潜在污染环节 |
| C10 关联性切断 | 在场≠操作论证 | 每项涉及网络身份的证据均论证同一性 |
| C11 合法性排除 | 第27/28条区分 | 明确标注属于瑕疵还是非法排除 |
| C12 量刑有利 | 有利情节标注 | 至少标注1个有利情节（如存在） |

## 3. 置信度评估标准

| 等级 | 标准 | 表述方式 |
|------|------|---------|
| 高 | 有直接客观证据支持+法条明确+逻辑无矛盾 | [置信度：**高**] |
| 中 | 有间接证据支持+法条基本明确+逻辑基本通顺 | [置信度：**中**] |
| 低 | 仅有推测+法条适用存疑+逻辑有跳跃 | [置信度：**低**] |

## 4. SOFT_DEGRADED 质量标准

| 降级等级 | 触发条件 | 最低质量标准 |
|---------|---------|-------------|
| S1 | 必需字段缺失（evidence_list为空） | 不输出分析，仅提示补充 |
| S2 | 推荐字段缺失过半/证据描述简略 | 基础块（一~二）按标准执行，12维度标注[待补充] |
| S3 | 选填输入缺失（无哈希值/无鉴定意见/无扣押清单） | 全量维度按标准执行，缺失项标注影响+风险提升 |
