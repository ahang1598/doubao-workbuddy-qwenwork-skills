# 边缘示例001：单项证据无哈希值无鉴定意见

> criminal-electronic-evidence-analysis | 边缘示例 | v1.1.0

## 输入

```
帮我分析这个电子证据。
案件名称：李某涉嫌盗窃案
涉嫌罪名：盗窃罪

证据只有1项：
- 手机取证报告1份（无哈希值，无鉴定意见，无扣押清单）

```

## 边界问题

1. **单项证据**：仅有1项电子证据，B6时间线重建和B7多源印证严重受限
2. **无哈希值**：A2完整性核验维度无法执行校验，只能标注"未提供哈希值，原始性可质疑"
3. **无鉴定意见**：C1鉴定意见专项审查无法触发，跳过
4. **无扣押清单**：A1载体识别和A3扣押程序审查受限，只能基于取证报告推断
5. **非T1-T5罪名**：盗窃罪不在5类高频罪名中，走通用路由
6. **推荐字段全部缺失**：hash_values/forensic_report/media_inventory均缺失，触发S3降级

## 预期输出特征

- **走快速路径**：单项证据+无鉴定意见+无哈希值 → Phase 1→2→4→5，跳过Phase 3中B6/B7简化
- **SOFT_DEGRADED**：S3轻度降级，缺失项标注影响+风险等级提升
- **O1 解构清单**：仅1项，哈希值列标"未提供"（红色），完整性列标"缺失"（红色），风险等级"高"
- **O2 12维度报告**：
  - A2：标注"未提供哈希值，原始性可质疑"（第27条瑕疵风险）
  - A3：标注"未提供扣押清单，取证程序无法完整审查"
  - B5：无身份映射信息→"待验证"
  - B6/B7：简化，标注"单项证据，时间线/印证分析受限"
  - C9：手机取证报告的客观性挑战（是否通过写保护设备、是否改变了原始数据）
  - C10：手机使用≠本人操作
- **O3 三维映射**：简化版，仅标注"数据不足，映射为示意性"
- **O4 下游动作**：P0-调取扣押清单和哈希值；P1-申请司法鉴定
- **C1不触发**：无鉴定意见输入
- **C2不触发**：罪名非T1-T5
