# 标准示例002：洗钱案多账户分析

> criminal-electronic-evidence-analysis | 标准示例 | v1.1.0

## 输入

```
分析洗钱案件的电子证据。王某涉嫌洗钱罪，案件信息：
- 案件名称：王某涉嫌洗钱案
- 涉嫌罪名：洗钱罪
- 罪名类型：T3

证据清单：
1. 银行流水3份（工商银行/建设银行/招商银行，SHA-256已提供，由银行调取）
2. 支付宝账户交易记录（2个UID，由支付宝公司调取，有调取回执）
3. 微信转账记录（1个微信号，由财付通调取，有调取回执）
4. 服务器日志（境外服务器，远程勘验提取，无哈希值）
5. 电子数据鉴定意见书（鉴定机构：XX司法鉴定中心，鉴定人：李某/赵某）

哈希值：
- E01: SHA-256 7f8a9b...c4d5e6（银行调取时）
- E02: SHA-256 1a2b3c...d4e5f6（支付宝调取时）
- E03: SHA-256 9g0h1i...j2k3l4（微信调取时）

鉴定意见关键结论：
- 从扣押硬盘镜像中提取投注记录58000条
- 鉴定方法：EnCase v8.07取证分析
- 鉴定人：李某（司法鉴定执业证号：XXX）、赵某（证号：YYY）

扣押清单：联想笔记本电脑1台、移动硬盘2块

辩护视角：无罪辩护（资金来源合法，系正常经商收入）
```

## 预期输出特征

- **O1 解构清单**：5项证据逐条解构，E04（服务器日志）无哈希值+远程勘验→高风险
- **O2 12维度报告**：
  - A1载体识别：E04境外服务器→未扣押，载体不明
  - A2完整性核验：E01/E02/E03有哈希值→可校验；E04无哈希值→存疑
  - A4收集方式：E04远程勘验→需审查审批手续（2019规则第27条）；T3洗钱专攻→多账户调取授权
  - B5主体同一性：2个支付宝UID→同一人？需实名认证映射链
  - B6时间线：资金分层路径（入金→中转→出金）
  - B7多源印证：银行流水 vs 支付宝 vs 微信的交叉验证
  - C10关联性切断：账户控制人≠资金所有人（代持/借卡可能性）
  - C11合法性排除：E04远程勘验无审批→第28条排除可能性
  - C1鉴定意见审查：鉴定资质/程序/方法/结论范围四要素
- **O3 三维映射**：多账户资金分层路径图+人物关系图（王某-多账户-上下游）
- **O4 下游动作**：P0-对E04申请排除（远程勘验无审批）；P1-核实2个支付宝UID同一性；P2-补充境外服务器取证手续

## 关键验证点

| 验证项 | 预期 |
|--------|------|
| T3罪名路由 | 激活洗钱专攻审查点（A4多账户调取授权+B5多账号映射+B6资金分层路径） |
| 鉴定意见审查 | C1条件输出块激活，四要素逐项审查 |
| 多账户同一性 | 2个支付宝UID→同一人映射链评估 |
| 远程勘验审批 | E04需审查是否经县级以上公安机关负责人批准 |
| 完整路径 | Phase 1→2→3→4→5，不走快速路径 |
