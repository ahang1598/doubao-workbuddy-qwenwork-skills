# 边缘示例002：认罪认罚+量刑建议明显不当

> criminal-defense-speech-trial | 边缘示例 | v4.2.0

## 输入

```markdown
被告人赵某，男，28岁，涉嫌盗窃罪，盗窃金额8000元。
已签署认罪认罚具结书。
检察院量刑建议：有期徒刑1年6个月。
但同地区同类案件（盗窃8000-10000元，有坦白+退赃+初犯）
普遍判处6-8个月，个别适用缓刑。
赵某有坦白、全部退赃、初犯、被害人谅解等全部从轻情节。
请写一审辩护词。
```

## 边界问题

认罪认罚案件，但检察院量刑建议（1年6个月）显著高于同类案件量刑水平（6-8个月），构成刑诉法第201条第2款规定的"明显不当"。辩护人在认罪认罚框架下仍有权对量刑建议提出异议，这是独立辩护权的体现。但须注意：
1. 不得直接否定认罪认罚的效力
2. 须以"量刑建议明显不当"为法律依据，而非简单主张"太重了"
3. 须提供同类案件量刑数据作为对比依据
4. 须完成三维量刑计算，用数字说话

## 预期输出特征

- **认罪认罚策略**：不否定认罪认罚效力，但论证量刑建议"明显不当"（刑诉法第201条第2款）
- **量刑三维计算**：法定刑幅度→基准刑→情节调节→建议刑期，全程用数字说话
- **同类案件对比**：列举3-5个同类案件的量刑结果，证明本案建议偏重
- **不利自认防线**：不得写"被告人虽构成盗窃罪"等定罪自认，应写"关于量刑问题"
- **从宽幅度论证**：论证侦查阶段即认罪→应适用较大从宽比例（30%）

## 预期输出摘要

```markdown
辩护人总体认为：被告人赵某已签署认罪认罚具结书，对指控事实和

水平及量刑指导意见的计算结果存在明显差距，恳请贵院依法调整。

第一，量刑建议与量刑指导意见的计算结果存在显著偏差

法定刑幅度：根据刑法第264条，盗窃数额较大，三年以下有期徒刑、
拘役或者管制。
基准刑：根据《量刑指导意见》，盗窃8000元属于数额较大，基准刑
约6-8个月。

情节调节：
- 坦白（法定从轻）：减少20% × 8 = -1.6月
- 全额退赃（酌定从轻）：减少10% × 8 = -0.8月
- 被害人谅解（酌定从轻）：减少20% × 8 = -1.6月
- 初犯（酌定从轻）：减少10% × 8 = -0.8月
- 认罪认罚（侦查阶段即认罪）：减少30% × 8 = -2.4月
合计调节：-7.2月（-90%）→ 上限约束60%
修正后调节：-60% × 8 = -4.8月
建议刑期：8 - 4.8 = 3.2月 ≈ 3个月至6个月

缓刑评估：刑期≤3年✓ 无再犯罪危险✓ → 建议适用缓刑
```
