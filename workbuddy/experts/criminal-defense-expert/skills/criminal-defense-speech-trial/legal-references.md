### 法条原文引用

#### 刑诉法第55条

```
对一切案件的判处都要重证据，重调查研究，不轻信口供。只有被告人供述，没有其他证据的，不能认定被告人有罪和处以刑罚；没有被告人供述，证据确实、充分的，可以认定被告人有罪和处以刑罚。

证据确实、充分，应当符合以下条件：
（一）定罪量刑的事实都有证据证明；
（二）据以定案的证据均经法定程序查证属实；
（三）综合全案证据，对所认定事实已排除合理怀疑。
```

#### 刑诉法第200条

```
在被告人最后陈述后，审判长宣布休庭，合议庭进行评议，根据已经查明的事实、证据和有关的法律规定，分别作出以下判决：
（一）案件事实清楚，证据确实、充分，依据法律认定被告人有罪的，应当作出有罪判决；
（二）依据法律认定被告人无罪的，应当作出无罪判决；
（三）证据不足，不能认定被告人有罪的，应当作出证据不足、指控的犯罪不能成立的无罪判决。
```

#### 刑诉法第15条

```
犯罪嫌疑人、被告人自愿如实供述自己的罪行，承认指控的犯罪事实，愿意接受处罚的，可以依法从宽处理。
```

#### 刑诉法第56条

```
采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述和采用暴力、威胁等非法方法收集的证人证言、被害人陈述，应当予以排除。收集物证、书证不符合法定程序，可能严重影响司法公正的，应当予以补正或者作出合理解释；不能补正或者作出合理解释的，对该证据应当予以排除。
在侦查、审查起诉、审判时发现有应当排除的证据的，应当依法予以排除，不得作为起诉意见、起诉决定和判决的依据。
```

### 法条原文引用

#### 刑诉法第33条

```
犯罪嫌疑人、被告人除自己行使辩护权以外，还可以委托一至二人作为辩护人。下列的人可以被委托为辩护人：
（一）律师；
（二）人民团体或者犯罪嫌疑人、被告人所在单位推荐的人；
（三）犯罪嫌疑人、被告人的监护人、亲友。
正在被执行刑罚或者依法被剥夺、限制人身自由的人，不得担任辩护人。
被开除公职和被吊销律师、公证员执业证书的人，不得担任辩护人，但系犯罪嫌疑人、被告人的监护人、近亲属的除外。
```

#### 刑诉法第34条

```
犯罪嫌疑人自被侦查机关第一次讯问或者采取强制措施之日起，有权委托辩护人；在侦查期间，只能委托律师作为辩护人。被告人有权随时委托辩护人。
侦查机关在第一次讯问犯罪嫌疑人或者对犯罪嫌疑人采取强制措施的时候，应当告知犯罪嫌疑人有权委托辩护人。……
```

#### 刑诉法第38条

```
辩护律师在侦查期间可以为犯罪嫌疑人提供法律帮助；代理申诉、控告；申请变更强制措施；向侦查机关了解犯罪嫌疑人涉嫌的罪名和案件有关情况，提出意见。
```

## 6. misuse_warnings

| 易混淆 | 正确区分 | 区分要点 |
|--------|----------|----------|
| 无罪辩护≠罪轻辩护 | 互斥策略 | 不得在同一论点中并存（可备位但须分离） |
| 从轻≠减轻 | 刑法第62条 vs 第63条 | 从轻在法定刑内，减轻可低于法定刑 |
| 自首≠坦白 | 刑法第67条第1款 vs 第3款 | 自首=主动投案+如实供述；坦白=被动归案+如实供述 |
| 缓刑≠减刑 | 刑法第72条 vs 第78条 | 缓刑=暂缓执行（未入监）；减刑=缩短刑期（已入监） |
| 辩护词≠代理词 | 被告方 vs 被害方 | 辩护词=被告方立场；代理词=被害方立场 |
| "应当"≠"可以" | 命令性 vs 授权性 | "应当从轻"（法定强制）≠"可以从轻"（酌定裁量） |
| 证据不足≠事实不清 | 刑诉法第55条第3款 vs 第200条第3款 | 证据不足=达不到证明标准→无罪；事实不清=需补查→可能发回 |
| 第56条≠第58条 | 排除规则 vs 法庭调查 | 第56条=什么该排；第58条=庭上怎么查 |
| 第57条≠第59条 | 检察院调查核实+纠正 vs 检察院举证证明合法性 | 第57条=谁来查+纠正；第59条=谁来证明 |

## 7. 法律依据误用清单 ⚠️

> 以下列出辩护词中常见的法律依据误用情形，Phase 5 检查须逐项核对

| 误用编号 | 误用情形 | 正确引用 | 区分要点 |
|----------|---------|----------|----------|
| MU-01 | 诈骗数额认定引用"主客观相一致原则" | 最高法《关于审理诈骗案件具体应用法律的若干问题的解释》/最高法《关于审理非法集资刑事案件具体应用法律若干问题的解释》 | 诈骗数额以"实际骗取的数额"认定，非"主客观相一致"原则。主客观相一致是定罪原则，不是数额认定规则 |
| MU-02 | 合同诈骗罪引用"以非法占有为目的"笼统论述 | 刑法第224条各项行为模式须逐项分析 | 须针对指控的具体行为模式逐一反驳 |
| MU-03 | 坦白引用刑法第67条第1款（自首） | 第67条第3款（坦白） | 第1款=自动投案+如实供述（自首）；第3款=被动归案+如实供述（坦白） |
| MU-04 | "可以"型条文用绝对化语气 | 须用"建议""恳请"等非绝对语气 | 刑法第67条第3款"可以"从轻→论证应为"建议从轻" |
| MU-05 | 退赃退赔引用为法定从轻情节 | 退赃退赔为酌定从轻情节，非法定的 | 无专门法条规定为法定从轻，属于刑法第61条"酌情"考量范围 |
| MU-06 | 合同诈骗"部分履行"直接扣除诈骗数额 | 须分析是否属于"先履行小额合同诱骗"（刑法第224条第（三）项） | 部分履行可能是犯罪手段 |
| MU-07 | 犯意转化（演变型故意）无依据论述 | 须引用司法解释或指导案例支撑 | 不能仅作断言 |
| MU-08 | V3混淆第56条与第58条 | 第56条=排除规则，第58条=法庭调查 | 须逐条核对编号（P0高发区） |
| MU-09 | V3混淆第57条与第59条 | 第57条=检察院调查，第59条=检察院举证 | 须逐条核对编号 |

## 8. 罪名法条完整性清单

> 辩护涉及以下罪名时，须完整引用法条各项并逐一分析

### 8.1 合同诈骗罪（刑法第224条）

| 法条项 | 行为模式 | 辩护须回应 |
|--------|---------|-----------|
| 第（一）项 | 以虚构的单位或者冒用他人名义签订合同的 | 如指控此项，须分析是否虚构/冒用+是否构成刑法意义的"虚构" |
| 第（二）项 | 以伪造、变造、作废的票据或者其他虚假的产权证明作担保的 | 如指控此项，须分析票据/产权证明的真实性质 |
| 第（三）项 | 没有实际履行能力，以先履行小额合同或者部分履行合同的方法，诱骗对方当事人继续签订和履行合同的 | ⚠️ 高频指控项 |
| 第（四）项 | 收受对方当事人给付的货物、货款、预付款或者担保财产后逃匿的 | 如指控此项，须分析"逃匿"是否成立 |
| 第（五）项 | 以其他方法骗取对方当事人财物的 | 兜底条款，须分析是否符合同类解释规则 |

### 8.2 诈骗罪（刑法第266条）

| 要素 | 辩护要点 |
|------|----------|
| 虚构事实/隐瞒真相 | 区分"夸大宣传"与"刑法意义的虚构事实" |
| 非法占有目的 | 时间节点分析：签约时还是履约中产生 |
| 数额认定 | "实际骗取数额"vs"合同约定数额" |
| 既有部分履行 | 是否属于犯罪成本还是真实履约 |
