## 1. 页面布局（含 DXA 精确值）

### 1.1 纸张

| 参数 | 标准值 | DXA 值 | 说明 |
|------|--------|--------|------|
| 纸张 | A4（210mm × 297mm） | 11906 × 16838 | 标准公文用纸，**禁止** US Letter |

> **DXA 单位说明**：Word 内部以 DXA（twips）为长度单位，1 DXA = 1/20 pt = 1/1440 inch。A4 宽度 = 210mm = 11906 DXA，高度 = 297mm = 16838 DXA。

### 1.2 页边距

| 参数 | 标准值 | DXA 值 | 依据 |
|------|--------|--------|------|
| 上边距 | 3.7cm | 2100 | GB/T 9704-2012 |
| 下边距 | 3.5cm | 1984 | GB/T 9704-2012 |
| 左边距 | 2.8cm | 1588 | GB/T 9704-2012 |
| 右边距 | 2.6cm | 1474 | GB/T 9704-2012 |

### 1.3 行距与页码

| 参数 | 标准值 | DXA 值 | 说明 |
|------|--------|--------|------|
| 行距 | 固定值 28 磅 | 560 DXA | 全文统一，含标题 |
| 首行缩进 | 2 字符（约32磅） | 640 DXA | 正文/各级标题统一 |
| 页码 | 页脚居中，"– N –" 格式 | — | 四号宋体（14pt） |

> **页码偏离声明**：F-Strict 默认禁止页脚，但辩护词为多页文书，需页码保护页序。此偏离遵循 known-pitfalls-registry §4.1（私人法律文书允许页码），属合规偏离。

## 3. 段落间距规则

### 3.1 核心原则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制，禁止插入仅含空白字符的空段落。

### 3.2 间距值（均为磅值 Pt）

| 元素 | 段前 | 段后 | 说明 |
|------|------|------|------|
| 标题"辩护词" | 0 | 24pt | 标题后留较大间距 |
| 首部称呼段 | 12pt | 6pt | — |
| 委托关系声明段 | 0 | 12pt | — |
| 一级标题 | 12pt | 6pt | — |
| 二级标题 | 6pt | 3pt | — |
| 三级标题 | 3pt | 0 | — |
| 正文段落 | 0 | 0 | 28磅固定行距即为段落间隔 |
| 法条引用块 | 3pt | 3pt | 与上下文区分 |
| 证据引用块 | 3pt | 3pt | — |
| "此致" | 12pt | 0 | 结语到"此致"留空 |
| 致送机关名 | 0 | 0 | 紧接"此致" |
| 落款第一行 | 12pt | 0 | 致送机关到落款留空 |
| 落款各行间 | 0 | 0 | 落款内部紧凑 |
| 页码 | — | — | 页脚区，不参与正文间距 |

## 4. 段落粒度规则

### 4.1 核心原则

**一个段落 = 一个语义单元。** 禁止将多个语义单元塞入同一段落用 `<br/>` 换行。每个独立的事实陈述、论证要点、证据列举项各占一个段落。

### 4.2 拆分规则

| 语义单元类型 | 段落数 | 示例 |
|-------------|--------|------|
| 首部称呼 | 1段 | "审判长、审判员：" |
| 委托关系声明 | 1段 | "[律所]接受委托……" |
| 事实异议项 | 1段/异议 | 每项独立异议1段 |
| 定性异议论证 | 1段/论证子项 | 每项论证独立1段 |
| 量刑情节论证 | 1段/情节 | 每项情节1段 |
| 法条引用 | 1段/法条 | 每条法条1段 |
| 证据列举 | 1段/项证据 | 每项证据1段 |
| 非法证据排除项（V3） | 1段/项 | 每项排除申请1段 |

### 4.3 反例

```
❌ 错误（单段落挤多个含义）：
辩护人认为：第一，证据不足；第二，定性错误；第三，量刑过重。

✅ 正确（每项独立段落）：
辩护人认为起诉书指控事实证据不足，具体分析如下：
[段落1] 关于第一项指控，证据之间存在矛盾……
[段落2] 关于第二项指控，定性不当……
[段落3] 关于量刑，被告人具有从轻情节……
```

## 5. 编号规则

### 5.1 核心原则

**使用 Word 原生 List Numbering，禁止手动"1. ""2. ""3. "编号。** 手动编号在编辑/打印时容易出现数字不对齐、序号混乱问题。

### 5.2 四层编号体系

| 层级 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 一级 | "第一，/第二，/第三，" | 第一，[案件具体争议] | 黑体三号（与范文惯例+SKILL.md/output-spec一致） |
| 二级 | "（一）（二）（三）" | （一）指控事实证据不足 | 楷体三号加粗 |
| 三级 | "1. 2. 3." | 1.自首 | 仿宋三号加粗 |
| 四级 | "①②③" | ①签约前 | 仿宋三号 |

### 5.3 python-docx 实现

```python
from docx.enum.text import WD_LIST_NUMBERING

# 添加编号段落
para = doc.add_paragraph("自首", style='List Number')
# 或手动设置
para.style = doc.styles['List Number']
```

## 7. 法条引用格式

### 7.1 样式

| 属性 | 值 |
|------|-----|
| 字体 | 楷体_GB2312 |
| 字号 | 三号（16pt） |
| 对齐 | 两端对齐 |
| 缩进 | 首行缩进2字符 |
| 段前/段后 | 各 3pt |

### 7.2 引用格式规范

| 引用类型 | 格式 | 示例 |
|----------|------|------|
| 法律 | 《法律名称》第X条第X款 | 《刑事诉讼法》第五十六条第一款 |
| 司法解释 | 《解释名称》第X条 | 《关于适用刑事诉讼法的解释》第一百零一条 |

> ⚠️ 法条编号在 DOCX 中使用中文数字（"第五十六条"），不使用阿拉伯数字（"第56条"）。这与 Markdown 草稿不同。

## 9. 特殊排版规则

### 9.1 标题

```
文书标题居中，二号方正小标宋简体加粗，独占一行。
标题格式："辩护词"（仅此两字，不加"关于"前缀）
```

### 9.2 首部称呼

```
"审判长、审判员：" 或 "审判长、人民陪审员："，左对齐，冒号后不换行。
根据合议庭组成选择：合议庭含人民陪审员→后者；纯法官→前者。
```

### 9.3 "此致"与致送机关

```
"此致"：首行缩进2字符
致送法院全称：另起一行，顶格
"此致"与致送法院名之间不插空行
```

### 9.4 落款签名区

```
辩护人：XXX律师        （右对齐）
XXX律师事务所           （右对齐）
二〇XX年X月X日          （右对齐，中文大写日期）
```

### 9.5 日期格式

```
日期使用中文大写：二〇二六年六月十日
禁止使用阿拉伯数字：~~2026年6月10日~~
"〇"用中文数字零，非英文字母O
```

### 9.6 O1 正式提交稿约束

- **禁止输出免责声明**：O1(.docx) 是提交给法院的正式文书，不得包含"免责声明"——这等同于告诉法官"这份辩护词可能是错的"。免责声明仅限 O2(Markdown) 编辑稿保留。
- **禁止正文表格**：辩护词论证正文中禁止使用任何有框表格。中国司法文书行文惯例为纯文字叙述，表格会打断论证连贯性。V3非法证据排除项必须改为逐项分段叙述（证据名称→非法收集方式→法律依据→排除请求，自然衔接于同一段落中）。

## 10. 多变体排版适配

### 10.1 V1 无罪辩护

| 差异点 | 排版适配 |
|--------|----------|
| 无量刑之辩主体 | 一级标题仅有"事实之辩""定罪之辩"，无"量刑之辩"独立章节 |
| 备位量刑意见 | 如有备位意见，须标注"退一步"开头，字体不变 |
| 综合意见收尾 | "依法判决被告人无罪"，请求明确 |
| 疑罪从无收尾 | 须引用刑诉法第200条第3款 |

### 10.2 V2 罪轻辩护

| 差异点 | 排版适配 |
|--------|----------|
| 指控逐项回应 | 使用编号列举，每项指控1段回应 |
| 不利事实正面回应 | 独立段落，以"对……这一事实，辩护人认为"开头 |
| 量刑建议四要素 | 法定刑幅度→基准刑→情节调节→建议刑期，各1段 |

### 10.3 V3 程序辩护

| 差异点 | 排版适配 |
|--------|----------|
| 非法证据排除申请 | 逐项分段叙述，不使用有框表格。格式："[证据名称]：[非法收集方式]。根据《刑事诉讼法》第五十六条，该证据应当予以排除。" |
| 程序违法论证 | 独立一级标题"关于程序合法性" |
| 第56-60条系列引用 | 须完整标注法条编号，楷体引用块 |

## 11. 禁止事项

| # | 禁止项 | 正确做法 |
|---|--------|----------|
| F1 | 纸张非 A4（如 US Letter） | 纸张必须设置为 A4（210mm×297mm / 11906×16838 DXA） |
| F2 | 用空行分段 | 用段前/段后间距控制段落间距 |
| F3 | 多个语义单元挤在同一段落（`<br/>` 换行） | 每个语义单元独立为一个段落 |
| F4 | 手动 "1. 2. 3." 编号 | 使用 Word 原生 List Numbering |
| F5 | 用 "———" 字符串模拟分隔线 | 使用 Word 段落底边框 |
| F6 | `@image`、`![xxx](xxx)` 等图片/占位符 | 辩护词是纯文字文书，禁止任何图片引用 |
| F7 | 段落缩进为 0 或随机值 | 正文和各级标题统一首行缩进 2 字符（640 DXA） |
| F8 | 正文使用有框表格 | 辩护词正文纯文字叙述，禁止有框表格 |
| F9 | "此致"—空行—"致送机关名" | "此致"与致送机关名之间不插空行（紧接） |
| F10 | 落款签名无右对齐 | 落款区全部右对齐 |
| F11 | 证据列举混在正文段落中 | 证据独立成段，楷体小四号，整段缩进 2 字符 |
| F12 | 结语出现不利自认（如"虽涉及不当行为"） | 结语严格按请求事项总结，禁止任何不利自认表述 |
| F13 | 日期使用阿拉伯数字 | 使用中文大写日期：二〇XX年X月X日 |
| F14 | O1(.docx) 包含"免责声明" | O1 为正式提交稿，删除免责声明；仅 O2(Markdown) 保留 |
| F15 | 法条编号使用阿拉伯数字 | DOCX 中法条编号使用中文数字：第五十六条（非"第56条"） |
| F16 | 标题加"关于"前缀 | 辩护词标题仅为"辩护词"两字 |
| F17 | 落款标签写"代理人" | 辩护词落款标签="辩护人"（非"代理人"） |
| F18 | 首部称呼缺少"人民陪审员"选项 | 根据合议庭组成选择含/不含"人民陪审员" |
