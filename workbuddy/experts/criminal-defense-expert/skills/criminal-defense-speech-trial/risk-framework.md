# 风险框架：criminal-defense-speech-trial

> 一审辩护词 | 版本: v4.2.0

## 1. 风险等级

**L2（中等风险）**——辩护词影响量刑，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 案件信息结构化 | L2 | 中风险 |
| Phase 3 辩护方向论证 | **L3** | **高风险**——辩护方向影响案件走向 |
| Phase 4 辩护词生成 | L2 | 中风险 |
| Phase 5 质量检查 | **L3** | **高风险**——质量检查遗漏直接导致辩护词缺陷 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 辩护方向统一 | 无罪与罪轻并行 | 警告+建议选择 |
| RC-02 | 禁止承诺结果 | 询问能否判无罪/缓刑 | 拒绝+说明理由 |
| RC-03 | 去分析化 | 生成辩护词 | 正文中禁止出现分析框架标签 |
| RC-04 | 证据驱动 | 论证无罪/罪轻 | 须以证据为基础 |
| RC-05 | **指控回避检测** | 起诉书核心指控未在辩护词中回应 | 阻断+回Phase 3补充回应 |
| RC-06 | **认罪认罚遗漏** | 量刑辩护中未评估认罪认罚从宽 | 阻断+补充认罪认罚评估段落 |
| RC-07 | **论证深度不足** | 存在结论式断言（无推理链条） | 阻断+展开三步论证 |
| RC-08 | **法律依据误用** | 引用场景与法律原则不匹配（对照legal-references §5） | 阻断+修正法律依据 |
| RC-09 | **不利事实回避** | 对辩护不利的关键事实完全未回应 | 阻断+补充不利事实正面应对 |
| RC-10 | **从轻情节未验证** | "退赃意愿""赔偿意愿"等作为已落实从轻情节 | 警告+标注"尚未落实"+降低论证力度 |

## 4. 行为约束

- 不得替代律师的专业判断
- 不得承诺判决结果
- 辩护词正文须"去分析化"
- 辩护方向须明确
- 不得回避控方核心指控事实
- 不得将"意愿"等同于"已落实"
