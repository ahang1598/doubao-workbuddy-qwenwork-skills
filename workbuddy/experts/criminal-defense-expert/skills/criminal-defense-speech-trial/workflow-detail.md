# 工作流详述

> 本文件定义 criminal-defense-speech-trial 技能的各Phase子步骤与检查点
> 版本: v4.2.0 | 更新: 2026-06-13

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 辩护类型路由(V1/V2/V3) → Phase 3: 论点组织
    ↓
Phase 4: 辩护词起草 → Phase 5: 质量检查(19项) → Phase 6: 输出交付
    ↓
Phase 7: DOCX 渲染 (F-Strict)
```

## 2. Phase 1: 输入验证

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1 | 解析输入 | 结构化字段 |
| 1.2 | 确定辩护类型 | defense_direction（无罪/罪轻/程序） |
| 1.3 | 提取案件事实 | case_facts |
| 1.4 | 识别V3专用输入 | procedural_violations（程序违法事项） |

**检查点**：[ ] 必需字段已提取 [ ] 辩护类型已确定

## 3. Phase 2: 辩护类型路由

| defense_direction | 变体 | 论证模板 | 核心法条 |
|------------------|------|---------|---------|
| 无罪 | V1 | 事实之辩+证据不足+疑罪从无 | 刑诉法第55条/第200条第3款 |
| 罪轻 | V2 | 定罪之辩+此罪彼罪+指控逐项回应 | 刑法相关条文 |
| 程序 | V3 | 程序之辩+非法证据排除 | 刑诉法第56-60条 |
| 备位 | V1+V2 | 先V1后V2（分离） | V1+V2法条合集 |

**检查点**：[ ] 路由已完成 [ ] 变体代号已确定

## 4. Phase 3: 论点组织

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.1 | **提取控方核心指控** | 指控清单（逐项列出起诉书核心指控事实） |
| 3.2 | **逐项匹配回应策略** | 指控-回应映射表（每项指控→反驳/削弱/承认） |
| 3.3 | 识别不利事实 | 不利事实清单（对辩护不利但无法回避的关键事实） |
| 3.4 | 制定不利事实回应策略 | 不利事实回应方案（正面回应+削弱论证+替代解释） |
| 3.5 | 组织事实认定论点 | 事实论点清单 |
| 3.6 | 组织法律适用论点 | 法律论点清单（含罪名法条完整性检查） |
| 3.7 | 组织量刑论点 | 量刑论点清单（含认罪认罚评估+从轻情节验证） |
| 3.8 | **V3专用：识别程序违法事项** | 程序违法清单（逐项列出+法条依据） |
| 3.9 | **V3专用：组织非法证据排除申请** | 排除申请清单（证据名称+非法方式+法律依据） |
| 3.10 | 按优先级排列 | 论点序列 |

**检查点**：
- [ ] 控方核心指控已全部提取并逐项匹配回应策略
- [ ] 不利事实已识别并有回应方案
- [ ] 认罪认罚适用性已评估
- [ ] 从轻情节已区分"已落实"与"仅有意愿"
- [ ] V3：程序违法事项已识别+非法证据排除申请已组织
- [ ] 论点已组织，优先级已确定

## 5. Phase 4: 辩护词起草

按 output-spec.md O1 模板起草。关键规则：
- V1无罪辩护不得在同一论点中含量刑辩护
- V2罪轻辩护须含指控逐项回应+不利事实正面回应
- V3程序辩护须含非法证据排除申请+第56-60条引用
- 事实之辩→定罪之辩→量刑之辩三层次
- 致送法院全称
- **指控逐项回应**：事实之辩须逐项回应起诉书核心指控
- **不利事实正面应对**：不得回避对辩护不利的关键事实
- **论证深度**：每个论点须三步推理（前提→推理→结论），禁止跳步
- **从轻情节验证**：区分"已落实"与"仅有意愿"的情节

**检查点**：[ ] 格式正确 [ ] 变体路由正确 [ ] 无罪推定 [ ] 指控逐项回应 [ ] 不利事实未回避 [ ] V3非法证据排除

## 6. Phase 5: 质量检查（21项）

| # | 检查项 | 标准 | 等级 | 修复方式 |
|---|--------|------|------|----------|
| 1 | 无罪推定 | 无"罪犯""确定有罪"等表述 | 阻断 | 替换为"被告人""涉嫌" |
| 2 | 辩护方向一致 | 辩护方向与论证不矛盾 | 阻断 | 调整论证或修改辩护方向 |
| 3 | **指控逐项回应** | 起诉书每项核心指控均有回应 | 阻断 | 补充遗漏指控的回应段落 |
| 4 | **不利事实未回避** | 对辩护不利的关键事实有正面回应 | 阻断 | 补充不利事实的正面应对论证 |
| 5 | **论证深度** | 无结论式断言，每个论点有三步推理 | 阻断 | 展开推理链条 |
| 6 | **认罪认罚评估** | 量刑辩护须评估认罪认罚从宽适用性 | 阻断 | 补充认罪认罚评估段落 |
| 7 | 法条引用 | mandatory法条正确 | 阻断 | 检索确认法条原文 |
| 8 | **法律依据匹配** | 引用场景与法律原则匹配 | 阻断 | 核对legal-references §7误用清单 |
| 9 | **第56-60条编号** | V3引用时编号逐条正确 | 阻断 | 核对速查表 |
| 10 | **V3非法证据排除** | 程序辩护含非法证据排除申请 | 阻断 | 补充排除申请段落 |
| 11 | **🔴 不利自认识别** | 执行6步不利自认识别审查，全文无不利自认 | 阻断 | 按methodology §11修复 |
| 12 | **🔴 写作红线** | 遵守output-spec §0A全部红线 | 阻断 | 对照红线清单逐项修复 |
| 13 | 去分析化 | 无框架标签 | 警告 | 删除标签，直接叙述 |
| 14 | **量刑建议具体** | 三维计算法→建议刑期区间+与检察官建议对比 | 警告 | 按methodology §13补充 |
| 15 | **条文性质一致** | "可以"类条文论证语气非绝对化 | 警告 | 调整为"建议""恳请"等非绝对语气 |
| 16 | **法条完整覆盖** | 罪名相关法条各项行为模式均有涉及 | 警告 | 补充遗漏的法条项 |
| 17 | **从轻情节验证** | 区分已落实/仅有意愿，后者有警示 | 警告 | 标注"尚未落实"+降低论证力度 |
| 18 | 事实论证有据 | 每个异议有证据支撑 | 警告 | 补充证据引用或标注证据不足 |
| 19 | 语气控制 | 无攻击性/侮辱性语言 | 警告 | 调整语气 |
| 20 | DOCX排版合规 | F-Strict：无空行/无有框表格/中文日期/页码 | 警告 | 按docx-format-spec修正 |
| 21 | O1禁止免责声明 | DOCX版不含免责声明 | 阻断 | 删除免责声明 |

### Phase 5 子步骤

```
5.1  逐项核对指控回应完整性 → 缺失则阻断，回Phase 3补充
5.2  扫描不利事实回避 → 发现回避则阻断，回Phase 3.3-3.4补充
5.3  抽查论证深度 → 发现结论式断言则阻断，展开推理
5.4  检查认罪认罚评估 → 量刑辩护中未评估则阻断
5.5  核对法律依据匹配 → 对照误用清单，发现误用则阻断
5.6  V3专项：核对第56-60条编号 → 编号错误则阻断
5.7  V3专项：检查非法证据排除申请 → 缺失则阻断
5.8  🔴 不利自认识别审查 → 执行6步审查法(methodology §11)，发现不利自认则阻断修复
5.9  🔴 写作红线检查 → 对照output-spec §0A全部红线，违反则阻断
5.10 执行原4项检查（无罪推定/类型一致/法条引用/去分析化）
5.11 执行7项警告级检查（含量刑建议三维计算法检查）
5.12 DOCX排版合规检查
5.13 O1禁止免责声明检查
```
