# 标准示例002：无罪辩护（故意伤害案·含因果链打断）

> criminal-defense-speech-trial | 标准示例 | v4.2.0

## 输入

```
被告人李某，男，42岁，涉嫌故意伤害罪（致人死亡）。
检察院指控：李某于2026年1月15日在XX小区门口拳击被害人王某面部，
致王某倒地后头部撞击路面，经医院抢救无效于1月20日死亡。
法医鉴定：王某系颅脑损伤死亡。
辩护方向：无罪辩护
辩护要点：
1. 李某的拳击行为与王某死亡之间因果关系不成立
2. 王某拒绝治疗是死亡的独立介入因素
3. 王某自身患有凝血障碍，与常人不同
4. 侦查阶段讯问存在程序问题
```

# 辩护词

审判长、审判员：

XX律师事务所接受被告人李某的委托，指派XXX律师担任李某涉嫌故意伤害罪一案一审辩护人。辩护人经阅卷、会见被告人、参加庭审，现发表如下辩护意见。

辩护人总体认为：被告人李某的行为与被害人王某的死亡结果之间不存在刑法上的因果关系，王某的死亡系由其拒绝正规治疗及自身特殊体质等多重独立因素导致，不应归责于李某。

第一，李某的拳击行为仅造成轻微伤，不足以致人死亡

根据法医鉴定报告（卷一P45-48），王某面部损伤程度为轻微伤，该伤情本身不可能导致死亡。王某的死亡原因系"颅脑损伤"，但该颅脑损伤并非拳击直接造成，而是王某倒地后头部撞击路面所致。拳击行为与颅脑损伤之间隔了"倒地撞击"这一中间环节，该中间环节的发生具有偶然性，非李某拳击行为的合乎逻辑的必然结果。

第二，被害人拒绝正规治疗系死亡的独立介入因素

根据住院病历（卷一P52-56），王某在急诊初步处理后，拒绝医生建议的住院观察和进一步检查，自行要求出院。出院后王某出现剧烈头痛，仍未及时就医，直至1月18日才再次入院，此时已错过最佳治疗时机。根据医学常识，颅脑损伤的早期治疗至关重要，王某拒绝住院和延迟就医的行为，切断了李某行为与死亡结果之间的因果关系链条。该拒绝治疗行为具有独立性和异常性——正常人在医生建议住院的情况下不会拒绝，王某的拒绝系其自主选择，非李某行为合乎逻辑的延续。

第三，被害人自身凝血障碍是死亡的重要促进因素

根据血液检查报告（卷一P60），王某患有先天性凝血因子缺乏症，该特殊体质使得同等程度的颅脑损伤在其身上产生的后果远比正常人严重。如果王某不具有凝血障碍，即使发生颅脑损伤，其出血量和颅内压升高速度也会显著低于实际情况，死亡风险大幅降低。因此，王某的特殊体质是导致其死亡的独立因素，不能将该特殊体质导致的严重后果全部归责于李某。

第四，侦查阶段讯问存在程序问题

根据讯问同步录音录像（证据编号：录-001），李某在2026年1月16日第二次讯问时，侦查人员存在疲劳审讯情形——连续讯问时间超过8小时且无合理休息间隔。根据《刑事诉讼法》第五十六条，以非法方法收集的犯罪嫌疑人供述应当予以排除。虽然该程序问题不直接改变案件事实认定，但相关讯问笔录的证明力存在瑕疵。

第五，同类案例参考

经检索人民法院案例库，在"入库案例编号2024-XX-XXX号"案件中，被告人拳击致被害人倒地后颅脑损伤，但被害人存在延迟就医情形，法院认定因果关系中断，判决被告人不承担致人死亡的刑事责任。[需核实案例编号及裁判要旨]

综上，辩护人认为，被告人李某的拳击行为与被害人王某的死亡结果之间不存在刑法上的因果关系。王某的死亡系由其拒绝正规治疗（独立介入因素）和自身凝血障碍（第三方因素）共同导致，不应归责于李某。恳请贵院依法宣告李某不承担致人死亡的刑事责任。
