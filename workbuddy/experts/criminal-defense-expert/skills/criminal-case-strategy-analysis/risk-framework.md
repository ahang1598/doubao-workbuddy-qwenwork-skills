# 风险框架：criminal-case-strategy

> 案件策略分析 | 版本: v1.2.0

## 1. 风险等级

**L2（中等风险）**——策略选择影响案件走向，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 事实信息结构化 | L2 | 中风险 |
| Phase 3 策略选项评估 | **L3** | **高风险**——策略选择影响案件走向 |
| Phase 4 风险评估+退路设计 | L2 | 中风险 |
| Phase 5 输出组装 | L1 | 低风险 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 禁止承诺结果 | 用户询问胜率/结果 | 拒绝+说明不确定性 |
| RC-02 | 多策略并列 | 生成策略时 | 至少提供2个选项+利弊分析 |
| RC-03 | 辩护方向互斥 | 无罪与罪轻并行 | 警告+建议选择 |
| RC-04 | 信息不足降级 | 输入严重不足 | SOFT_DEGRADED G档 |

## 4. 行为约束

- 不得替代律师的策略决策
- 不保证策略效果
- 提供多种策略选项而非单一推荐
- 每种策略须附风险评估
