# 工作流详述

> 本文件定义 criminal-case-strategy 技能的各Phase子步骤与检查点
> 遵循 compiler/ssot.md §17（SSOT）：按需拆分规则

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 事实评估 → Phase 3: 法律分析
    ↓
Phase 4: 证据评估 → Phase 5: 策略制定 → Phase 6: 质量检查 → Phase 7: 输出交付
```

## 2. Phase 1: 输入验证

### 1.1 输入解析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1.1 | 解析自然语言输入 | 结构化字段字典 |
| 1.1.2 | 提取案件基本信息 | suspect_name, alleged_crime, case_stage |
| 1.1.3 | 识别辩护目标 | defense_objective（默认"最轻"） |
| 1.1.4 | 识别辩护层次 | defense_type（默认"综合"） |
| 1.1.5 | 识别上下游技能产物 | 阅卷笔录/证据分析报告 |

### 1.2 输入校验

| 检查项 | 校验规则 | 失败行为 |
|--------|----------|----------|
| suspect_name 存在 | 非空 | 进入SOFT_DEGRADED C块 |
| alleged_crime 存在 | 非空 | 进入SOFT_DEGRADED C块 |
| case_stage 有效 | 枚举值 | 默认"审查起诉" |
| case_facts 存在 | 非空 | 交互补全 |

### 1.3 Phase 1 检查点

- [ ] 输入已结构化
- [ ] 必需字段已提取或标注 [待补充]
- [ ] 辩护目标已确定
- [ ] 上下游技能产物已识别

## 3. Phase 2: 事实评估

### 2.1 指控事实分析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 2.1.1 | 提取指控事实要点 | 事实要点清单 |
| 2.1.2 | 评估每项事实的确定性 | 确定性等级（高/中/低/争议） |
| 2.1.3 | 识别事实争议点 | 争议事实清单 |
| 2.1.4 | 识别有利事实 | 有利事实清单 |
| 2.1.5 | 识别不利事实 | 不利事实清单 |

### 2.2 事实分层

| 层次 | 评估维度 | 产出 |
|------|----------|------|
| 核心事实 | 是否能被证据充分证明 | 事实确定性评估 |
| 边缘事实 | 证明力较弱但有支持 | 补强取证建议 |
| 争议事实 | 控辩双方有分歧 | 争点聚焦 |
| 缺口事实 | 尚待查清 | 取证方向 |

### 2.3 Phase 2 检查点

- [ ] 指控事实已逐项分析
- [ ] 事实确定性已评估
- [ ] 有利/不利事实已识别
- [ ] 事实缺口已标注

## 4. Phase 3: 法律分析

### 3.1 构成要件分析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.1.1 | 确定涉嫌罪名构成要件 | 构成要件清单 |
| 3.1.2 | 将指控事实与要件逐项对应 | 事实-要件映射表 |
| 3.1.3 | 识别要件欠缺 | 辩护空间评估 |
| 3.1.4 | 分析此罪与彼罪 | 定性分析 |

### 3.2 法定刑分析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.2.1 | 确定法定刑幅度 | 刑期范围 |
| 3.2.2 | 分析量刑情节 | 从重/从轻情节清单 |
| 3.2.3 | 估算量刑区间 | 可能的刑期范围 |

### 3.3 Phase 3 检查点

- [ ] 构成要件已逐项分析
- [ ] 事实-要件映射完成
- [ ] 法定刑已确定
- [ ] 量刑情节已识别

## 5. Phase 4: 证据评估

### 4.1 控方证据体系分析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 4.1.1 | 列出控方主要证据 | 证据清单 |
| 4.1.2 | 评估每项证据三性 | 客观性/关联性/合法性评估 |
| 4.1.3 | 评估证明力 | 强/中/弱 |
| 4.1.4 | 识别可质疑点 | 质证要点 |
| 4.1.5 | 评估证据链完整性 | 完整/有缺口/有断裂 |

### 4.2 辩方证据线索

| 步骤 | 操作 | 产出 |
|------|------|------|
| 4.2.1 | 列出已有辩方证据 | 证据清单 |
| 4.2.2 | 识别待取证据 | 取证方向 |
| 4.2.3 | 评估证据缺口 | 补证策略 |

### 4.3 Phase 4 检查点

- [ ] 控方证据已逐项评估
- [ ] 可质疑点已识别
- [ ] 证据链完整性已评估
- [ ] 辩方取证方向已确定

## 6. Phase 5: 策略制定

### 5.1 辩护三层次策略

| 层次 | 策略 | 论证重点 | 适用条件 |
|------|------|----------|----------|
| 事实之辩 | 否认指控事实 | 证据不足/事实不清/证据矛盾 | 证据薄弱/事实争议大 |
| 定罪之辩 | 争定性争罪名 | 构成要件不符/此罪彼罪 | 事实基本无争议但定性有分歧 |
| 量刑之辩 | 争从轻争减轻 | 遗漏情节/量刑不公 | 事实和罪名争议不大 |

### 5.2 策略选择决策

| 决策因素 | 权重 | 评估方法 |
|----------|------|----------|
| 证据强度 | 40% | 控方证据链完整性评估 |
| 法律空间 | 30% | 构成要件对应分析 |
| 当事人意愿 | 20% | defense_objective |
| 风险承受 | 10% | 策略失败后果评估 |

### 5.3 策略实施路径

| 阶段 | 具体行动 | 产出 |
|------|----------|------|
| 当前阶段→下一阶段 | [具体行动步骤] | [预期产出] |

### 5.4 Phase 5 检查点

- [ ] 辩护三层次均已分析
- [ ] 推荐策略已确定
- [ ] 实施路径已规划
- [ ] 风险已评估

## 7. Phase 6: 质量检查

### 6.1 自检清单

| 检查项 | 标准 | 问题等级 |
|--------|------|----------|
| 无罪推定 | 无"罪犯"等表述 | 阻断 |
| 策略可行性 | 有充分依据支撑 | 阻断 |
| 法条引用 | mandatory法条正确 | 阻断 |
| 风险评估 | 策略风险已明确 | 警告 |
| 证据评估 | 逐项评估无遗漏 | 警告 |
| 去分析化 | 策略报告无框架标签外泄 | 警告 |

### 6.2 修复策略

| 问题类型 | 修复方式 |
|----------|----------|
| 阻断级 | 直接修复 |
| 警告级 | 标注+建议，用户确认 |
