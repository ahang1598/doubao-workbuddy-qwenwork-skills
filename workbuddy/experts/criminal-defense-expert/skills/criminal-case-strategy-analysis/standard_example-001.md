# 示例001：故意伤害案审查起诉阶段辩护策略

## 基本信息

| 字段 | 值 |
|------|-----|
| 案件名称 | 张某故意伤害案 |
| 诉讼阶段 | 审查起诉 |
| 涉嫌罪名 | 故意伤害罪 |
| 当事人 | 张某（犯罪嫌疑人） |
| 输入模式 | M1（丰富输入+策略分析） |

## 用户输入

```
案件名称：张某故意伤害案
诉讼阶段：审查起诉
涉嫌罪名：故意伤害罪
当事人角色：犯罪嫌疑人
案件事实：2025年8月15日，张某与邻居李某因琐事发生口角，张某推搡李某致其倒地，李某右桡骨骨折。经鉴定，李某损伤程度为轻伤二级。张某案发后主动拨打120并陪同就医，已赔偿李某8万元并取得书面谅解。张某无前科。
核心诉求：争取不起诉或最轻处罚
已有材料：起诉意见书、鉴定意见、赔偿协议、谅解书
```

## 期望输出摘要

### 策略选项矩阵

| 选项 | 策略方向 | 核心论点 | 胜算评估 | 风险评估 | 成本效益比 |
|:---:|----------|----------|:---:|----------|:---:|
| A | 酌定不起诉 | 情节轻微+已赔偿谅解+初犯偶犯 | 60% | 如检察院不同意则转入量刑辩护 | 高 |
| B | 认罪认罚从宽 | 认罪+赔偿+谅解→建议缓刑 | 80% | 需签署具结书，限制后续辩护空间 | 中高 |
| C | 罪轻辩护（轻伤二级存疑） | 质疑鉴定意见 | 30% | 如失败则失去从宽机会 | 低 |

### 推荐策略：选项A+B组合

**第一阶段**：优先申请酌定不起诉
- 论证依据：刑法第37条"犯罪情节轻微不需要判处刑罚"+刑诉法第177条第2款
- 支撑事实：轻伤二级（下限）+主动施救+全额赔偿+书面谅解+初犯偶犯

**第二阶段**（如不起诉未获批准）：转入认罪认罚
- 签署具结书，建议量刑：有期徒刑6个月，缓刑1年
- 依据：最高法量刑指导意见，轻伤二级基准刑6-12个月，赔偿谅解可减30%以下

### 退路设计

如不起诉未果且认罪认罚后法院未采纳缓刑建议：
- 提交社会调查报告（无再犯风险）
- 申请社区矫正当庭宣判

### 下游技能调用建议

1. `criminal-non-prosecution` — 起草不起诉辩护意见
2. `criminal-plea-negotiation` — 如转入认罪认罚，准备协商方案
3. `criminal-cross-examination` — 如进入一审，准备质证提纲（重点质疑鉴定意见）
