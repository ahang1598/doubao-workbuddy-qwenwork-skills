## 1. 输出类型定义

### 1.1 O1: 刑事案件策略分析报告（HTML）

**触发条件**：始终输出

**格式**：纯 HTML，C-Professional + 方案B经典沉稳，浏览器打开即渲染

**HTML 模板**：`templates/html/strategy-template.html`

**报告结构**：

```
┌─────────────────────────────────────────┐
│  文档控制页（§13）                        │
│  版本历史 + 分发清单 + 保密等级           │
├─────────────────────────────────────────┤
│  一、执行摘要（§12）                      │
│  [c06 结论卡] 核心判断                   │
│  关键发现 + 风险概览 + 建议行动           │
├─────────────────────────────────────────┤
│  二、案件基本信息                         │
│  被告人/罪名/阶段/法定刑/辩护目标         │
├─────────────────────────────────────────┤
│  三、案件事实评估                         │
│  指控要点 + 争议点 + 风险评估             │
├─────────────────────────────────────────┤
│  四、证据评估                            │
│  控方证据体系 + 证据链分析 + 辩方机会     │
├─────────────────────────────────────────┤
│  五、法律适用评估                         │
│  构成要件分析 + 定性争议 + 法定刑         │
├─────────────────────────────────────────┤
│  六、策略选项                            │
│  [c12 风险矩阵] 可行性×影响力            │
│  策略对比交互表（三层次×多维度）           │
│  策略A/B/C 详情卡片                      │
├─────────────────────────────────────────┤
│  七、推荐方案                            │
│  [c06 结论卡] 推荐策略                   │
│  推荐理由 + 注意事项                     │
├─────────────────────────────────────────┤
│  八、阶段行动计划                         │
│  [c13 流程图] 策略实施路径               │
│  [c09 时间轴] 关键节点时间线             │
├─────────────────────────────────────────┤
│  九、风险提示                            │
│  策略风险 + 程序风险 + 证据风险           │
├─────────────────────────────────────────┤
│  十、下一步行动建议                       │
│  策略确认 + 证据补充 + 时限关注 + 技能衔接 │
├─────────────────────────────────────────┤
│  免责声明（templates/disclaimer-templates.md）│
└─────────────────────────────────────────┘
```

**Richee 组件映射**：

| 报告位置 | 组件 | 编号 | 说明 |
|----------|------|------|------|
| 执行摘要/推荐方案 | 结论卡 | c06 | 核心判断展示 |
| 策略选项 | 风险矩阵 | c12 | 可行性×影响力二维判断 |
| 阶段行动计划 | 流程图 | c13 | 策略实施路径 |
| 阶段行动计划 | 时间轴 | c09 | 关键节点/诉讼阶段 |

### 1.2 O2: 下一步推荐动作（嵌入 HTML 报告末尾）

**触发条件**：始终输出（嵌入 O1 报告的"十、下一步行动建议"章节内）

**格式**：HTML 有序列表 + 行动项卡片

**内容**：

```
1. 策略确认：与当事人确认辩护方向和目标
2. 证据补充：[具体取证建议]
3. 时限关注：[关键期限提醒]
4. 技能衔接：[推荐使用的下游技能]
5. 风险防范：[需要特别注意的事项]
```

## 2. SOFT_DEGRADED 输出

当输入不足或关键信息缺失时，输出 HTML 最小骨架：

### 2.1 HTML 降级骨架

```html
<!-- C) Missing Facts Checklist -->
<h2 style="...">待补充事实清单</h2>
<table style="...">
  <tr><th>缺失字段</th><th>影响程度</th><th>建议来源</th></tr>
  <tr><td>[缺失字段1]</td><td>[影响]</td><td>[建议来源]</td></tr>
</table>

<!-- D) Governance & Non-Goals -->
<h2 style="...">治理与禁区</h2>
<ul style="...">
  <li>禁止输出确定性胜诉承诺</li>
  <li>禁止输出"构成犯罪"等违反无罪推定原则的表述</li>
  <li>禁止替代律师做出策略决策（仅提供分析参考）</li>
</ul>

<!-- G) Actionable Next Steps -->
<h2 style="...">下一步行动</h2>
<ol style="...">
  <li>补充：[缺失字段1]</li>
  <li>补充：[缺失字段2]</li>
</ol>
```

### 2.2 降级触发条件

| 降级强度 | 触发条件 | 骨架内容 |
|----------|----------|----------|
| S1（最强约束） | 必需字段缺失（suspect_name/alleged_crime/case_stage） | G档（骨架版） |
| S2（中度） | 推荐字段缺失过半 | C+D+G+结构描述 |
| S3（轻度） | 可选字段缺失 | C+D+G+内容初稿（关键结论标注[待核实]） |

## 3. 写作红线（禁止事项）

### 3.1 内容禁止

| 禁止项 | 正确做法 |
|--------|----------|
| "罪犯"/"犯人" | 犯罪嫌疑人/被告人 |
| "构成[罪名]" | "涉嫌[罪名]"或"原判认定构成[罪名]" |
| "一定会胜诉" | "根据现有证据分析，[策略]具有[一定程度]的可行性" |
| "建议认罪" | "认罪认罚可能是[可选]策略之一，需当事人自行决定" |
| "本案应当无罪" | "现有证据可能不足以证明有罪，无罪辩护具有[可行性]" |
| 确定性胜诉预测 | 量化为"可行性评估：高/中/低" |

### 3.2 格式禁止

| 禁止项 | 正确做法 |
|--------|----------|
| 分析框架标签外泄到文书正文 | 仅在策略分析报告中使用结构化标签 |
| 确定性法律结论 | 标注为"法律分析意见"而非"法律结论" |
| 策略分析报告混同法律文书 | 明确区分：本报告为策略参考，非法律文书 |
| Markdown 格式输出 | 始终输出纯 HTML，不再保留 Markdown 格式 |
| CSS 类名选择器 | 所有排版使用内联样式 `style=""`（@page/@media 例外） |
| 外部 CSS/JS 依赖 | 完全自包含，复制粘贴即可渲染（Mermaid CDN 例外） |
