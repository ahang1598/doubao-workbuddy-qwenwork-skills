# 边缘示例001：证据不足无法确定策略

> criminal-case-strategy | 边缘示例 | v1.2.0

## 输入

```markdown
张某被拘留了，涉嫌什么罪不清楚，家属只知道被带走
```

## 边界问题

信息严重不足：不知道涉嫌罪名、不知道案件事实、没有任何材料。技能应：
1. SOFT_DEGRADED降级为G档（骨架版）
2. 提供建议信息收集清单
3. 建议优先会见了解情况
4. 不得在信息不足时给出任何策略建议

## 预期输出特征

- 降级为信息收集指引
- 不提供具体策略建议
- 列明需收集的关键信息

## 预期输出摘要

```markdown
> ⚠️ **信息不足提示**
> 当前信息不足以进行策略分析。请优先收集以下信息：

## 第一步：紧急信息收集

| 优先级 | 信息 | 获取途径 |
|--------|------|----------|
| P1 | 涉嫌罪名 | 向办案机关查询（拘留通知书） |
| P1 | 羁押地点 | 向办案机关查询 |
| P1 | 拘留时间 | 计算黄金37天 |
| P2 | 案件基本事实 | 律师会见 |
| P2 | 证据情况 | 阅卷/会见 |

## 第二步：紧急措施

1. **37天黄金期**：从拘留到逮捕决定最长37天，此期间是取保候审最佳时机
2. **委托律师会见**：了解案件真实情况
3. **申请取保候审**：即使信息不足，也应尽快申请

> 建议优先使用 criminal-meeting-guide 技能准备会见提纲，
> 会见后再使用本技能进行策略分析。
```
