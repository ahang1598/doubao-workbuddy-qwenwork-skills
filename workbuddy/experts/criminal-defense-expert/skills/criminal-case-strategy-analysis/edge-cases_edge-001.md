# 边缘示例001：证据不足无法确定策略

> criminal-case-strategy | 边缘示例 | v1.2.0

## 输入

```markdown
我朋友被警察带走了，好像是涉嫌什么罪，但我不清楚具体情况，
也不知道有什么证据，请帮我分析一下案件策略。
```

## 边界问题

输入信息极为模糊，缺乏案件策略分析的最基本要素：（1）涉嫌罪名不明；（2）案件事实不清；（3）证据状况未知；（4）诉讼阶段未知。策略分析需要建立在具体事实和证据基础上，无事实则无策略。这触及了技能的最低输入门槛。

## 预期输出特征

- SOFT_DEGRADED G档（骨架版）：输出策略分析框架，但所有实质内容标注为"需补充"
- 明确列出策略分析必需的最低输入要素
- 不得在无事实基础上给出任何倾向性策略建议
- 交互补全：提示用户补充关键信息

## 预期输出摘要

```markdown
# 案件策略分析

> ⚠️ **信息严重不足提示**：当前输入缺乏策略分析的最基本要素，以下为分析框架，
> 所有实质内容需补充完整信息后方可填充。

## 一、案件基本信息

| 项目 | 内容 |
|------|------|
| 涉嫌罪名 | [需补充]——罪名决定法律适用方向 |
| 诉讼阶段 | [需补充]——阶段决定可用策略空间 |
| 当事人身份 | [需补充]——嫌疑人/被告人 |
| 强制措施 | [需补充]——是否被羁押影响策略紧迫性 |

## 二、策略分析框架

### 事实维度
[需补充案件基本事实后方可分析]

### 证据维度
[需了解控方证据和辩方证据后方可评估]

### 法律维度
[需明确罪名后方可进行法律适用分析]

### 程序维度
[需明确诉讼阶段后方可评估程序性策略]

## 三、最低信息需求

请补充以下信息以便进行有意义的策略分析：
1. 涉嫌的具体罪名
2. 案件基本事实（发生了什么）
3. 当前诉讼阶段（侦查/审查起诉/审判）
4. 已知的主要证据
5. 当事人的诉求和立场
```
