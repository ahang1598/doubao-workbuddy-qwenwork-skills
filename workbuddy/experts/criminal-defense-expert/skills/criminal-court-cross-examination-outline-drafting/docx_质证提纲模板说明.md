# 质证提纲DOCX模板说明

> criminal-cross-examination | templates | v2.2.0
> 排版规范：I-Practical 内部级，自定义排版
> 详见 `references/docx-format-spec.md`

## 模板用途

本模板供智能体环境渲染质证提纲DOCX打印版，用于庭审携带。

## 模板结构

```
┌─────────────────────────────────────────────────────┐
│                    质证提纲                          │ ← 标题：微软雅黑14pt加粗居中
│        案件：[被告人姓名]涉嫌[罪名]                   │ ← 案件元信息：微软雅黑10.5pt右对齐
│        辩护方向：[事实之辩/定罪之辩/量刑之辩]           │
│        生成时间：[YYYY-MM-DD]                        │
├─────┬──────────┬────────────────────┬──────────┬────┤
│编号 │ 证据名称 │    质证意见        │ 法律依据 │备注│ ← 表头：加粗灰底(RGB:#D9D9D9)
│10%  │   20%    │      38%          │   17%    │15%│
├─────┼──────────┼────────────────────┼──────────┼────┤
│E-   │          │ 合法性：...        │          │□同意│
│Oral │ [名称]   │ 真实性：...        │ [法条]   │□部分│
│-01  │          │ 关联性：...        │          │同意│
│     │          │ 综合：...          │          │□异议│
│     │          │                    │          │[批注]│
├─────┼──────────┼────────────────────┼──────────┼────┤
│ ... │  ...     │      ...          │   ...    │ ... │
└─────┴──────────┴────────────────────┴──────────┴────┘
│                                                     │
│  附：exclusion转交提示（如有）                        │ ← 独立段落
│  附：法条索引                                        │
└─────────────────────────────────────────────────────┘
```

## 渲染注意事项

1. 🔴/🟡 标记在DOCX中备选方案：【严重】/【注意】（emoji渲染不稳定的备选）
2. 表格跨页规则：允许行跨页，表头在每页重复
3. 勾选框实现方式：优先使用Unicode字符 □/☑，备选Content Control
4. 打印适配：可双面打印节省纸张
