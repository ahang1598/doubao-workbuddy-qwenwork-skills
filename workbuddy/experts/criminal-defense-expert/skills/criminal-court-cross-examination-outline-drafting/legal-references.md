### 2.3 法条原文引用

#### 刑诉法第50条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十条：

可以用于证明案件事实的材料，都是证据。
证据包括：
（一）物证；
（二）书证；
（三）证人证言；
（四）被害人陈述；
（五）犯罪嫌疑人、被告人供述和辩解；
（六）鉴定意见；
（七）勘验、检查、辨认、侦查实验等笔录；
（八）视听资料、电子数据。
证据必须经过查证属实，才能作为定案的根据。
```

#### 刑诉法第55条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十五条：

对一切案件的判处都要重证据，重调查研究，不轻信口供。只有被告人供述，没有其他证据的，不能认定被告人有罪和处以刑罚；没有被告人供述，证据确实、充分的，可以认定被告人有罪和处以刑罚。
证据确实、充分，应当符合以下条件：
（一）定罪量刑的事实都有证据证明；
（二）据以定案的证据均经法定程序查证属实；
（三）综合全案证据，对所认定事实已排除合理怀疑。
```

#### 刑诉法第56条（2018年修正，现行有效）

```
《中华人民共和国刑事诉讼法》第五十六条：

采用刑讯逼供等非法方法收集的犯罪嫌疑人、被告人供述和采用暴力、威胁等非法方法收集的证人证言、被害人陈述，应当予以排除。收集物证、书证不符合法定程序，可能严重影响司法公正的，应当予以补正或者作出合理解释；不能补正或者作出合理解释的，对该证据应当予以排除。
在侦查、审查起诉、审判时发现有应当排除的证据的，应当依法予以排除，不得作为起诉意见、起诉决定和判决的依据。
```

> **关键区分**：第1款 = 言词证据非法取证 → 强制排除（一票否决）。第2款 = 实物证据程序违法 → 有条件排除（可补正或合理解释后不排除）。

### 4.4 misuse_warnings（易混淆法条警告）

| 易混淆 | 正确法条 | 错误风险 | 区分要点 |
|--------|----------|----------|----------|
| 证据标准≠证明力 | 第55条 vs 第50条 | 混淆概念 | 第55条是"排除合理怀疑"标准，第50条是证据种类定义 |
| 质证程序≠仅证人出庭 | 第192条 vs 第195条 | **⚠️ 概念混淆**（第195条是关于当庭出示物证和听取意见的质证程序，第192条是关于证人/鉴定人出庭） | 第192条是证人/鉴定人出庭作证，第195条是物证/书证等出示质证的法庭调查程序 |
| 非法证据排除≠证据不可信 | 第56条 | 程序vs实体 | 第56条是程序性排除，证据可能真实但程序违法 |
| 旧版第48条≠现行第50条 | 2018年前 vs 2018年后 | 法条编号错误 | 确认适用版本（2018年修正后编号变化） |
| 言词排除≠实物排除 | 第56条第1款 vs 第2款 | 混淆排除规则 | 言词 = 强制排除（一票否决），实物 = 有条件排除（可补正） |
| 辨认审查条款 | **第104-105条** vs 第87-92条 | **⚠️ 法条编号错误**（第87-92条是鉴定意见审查，2021年解释辨认笔录审查在第104-105条） | 辨认笔录审查在2021年刑诉法解释第104-105条，鉴定意见在第89-95条 |
| 讯问录音录像≠询问录音录像 | **第123条** vs **第124-127条** | **⚠️ 法条适用对象错误**（第123条仅适用于讯问犯罪嫌疑人，不适用于询问被害人/证人） | 第123条="侦查人员在讯问犯罪嫌疑人的时候"的录音录像；询问被害人/证人的程序规定在第124-127条。将第123条套用于被害人陈述是张冠李戴，质证意见将被驳回 |
