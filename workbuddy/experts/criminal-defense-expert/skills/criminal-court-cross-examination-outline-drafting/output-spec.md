| 输出格式 | 说明 | 触发条件 |

## 0.5 写作红线（🔴 必须首先阅读）

> **为什么写作红线在最前面**：写作红线是质证提纲的"安全底线"，违反任一条都可能导致执业风险。在生成任何内容前，必须先了解这些红线。

### 0.5.1 通用红线（引用 `base/shared/writing-redlines.md`）

本技能遵守 `base/shared/writing-redlines.md` 全部 11 条通用红线（WR-01~WR-11），以下5条为本技能的高频触发项：

| # | 红线 | 本技能特别提示 |
|---|------|-------------|
| **RL-01** | 不使用绝对化表述（WR-01） | 禁止"必然构成犯罪""肯定无法排除"等绝对化用词。质证意见应留边界："建议质证时关注""在当前信息范围内" |
| **RL-02** | 事实与意见分离（WR-03） | 质证意见中"证据内容"与"质证评价"必须分离，不得混排导致反向自认风险 |
| **RL-03** | 不替代律师判断（WR-04） | 使用"建议质证时关注""可考虑"而非"应当质证""必须质疑"。质证提纲是草稿，不是庭审指令 |
| **RL-04** | 法条引用须标注来源（WR-05） | 引用法条须写全称+条号+款项，标注是否经核实。刑诉法条文编号必须为2018修正后版本 |
| **RL-05** | 避免不利自认（WR-10） | 质证中绝不能对控方证据的任何维度做正面承认。详见下方专属红线 |

### 0.5.2 专属红线（质证提纲专项）

| # | 红线 | 违反后果 | 正确做法 |
|---|------|---------|---------|
| **EX-01** | **质证反向自认**——"对真实性无异议"/"形式上合法"/"该证据证明了XX事实"/"虽然该证据合法，但……" | 法庭视为认可证据，律师不当承认成为有罪判决依据 | 明确表态"有异议"+说明理由；改用"该证据的合法性仍需审查以下问题"；改用"即使该证据内容属实，其至多能说明XX，不能证明YY" |
| **EX-02** | **质证过度**——对有利量刑证据进行合法性攻击 | 排除对己方有利的从轻情节证据=自毁从轻情节 | 量刑之辩中，不利证据攻击合法性+有利证据防守真实性，绝不攻击有利证据 |
| **EX-03** | **质证无关证据**——对与辩护方向无关的证据大篇幅质证 | 浪费质证时间，分散法官注意力 | 对无关证据简要表态即可，质证火力集中在核心证据 |

### 0.5.3 LLM常见违规（AI质证提纲高发错误模式）

| # | 违规模式 | 出现频率 | 示例 | 修正 |
|---|---------|---------|------|------|
| **LLM-01** | 默认承认证据真实性后转折 | 高频 | "该证据真实性无异议，但关联性不足" | "该证据的真实性仍需审查以下问题：……" |
| **LLM-02** | 对鉴定意见部分维度正面评价 | 高频 | "鉴定方法科学合理，但检材来源存疑" | "鉴定意见存在多项审查要点，辩护人对鉴定方法、检材来源均有异议" |
| **LLM-03** | 用"虽然……但……"承认不利事实 | 中频 | "虽然50万元确实转入，但不能证明诈骗故意" | "即使50万元转入张某账户属实，该资金流转也不足以证明非法占有目的" |
| **LLM-04** | 量刑之辩中对所有证据一刀切攻击 | 中频 | 量刑之辩中对自首材料也质疑取证程序 | 不利证据攻击+有利证据防守的二元策略，自首材料应确保采信 |
| **LLM-05** | 将刑诉法第123条套用于被害人陈述 | 低频（已在v2.1.2修复） | "询问被害人应全程录音录像（第123条）" | 第123条仅适用于讯问犯罪嫌疑人，被害人陈述审查依据第124-127条 |

### 0.5.4 内容禁止

| 禁止项 | 正确做法 |
|--------|----------|
| "罪犯"/"犯人" | 犯罪嫌疑人/被告人 |
| "构成[罪名]" | "涉嫌[罪名]" |
| 无依据质疑（"该证据不真实"） | 有推理的质疑（"该陈述与XX证据矛盾，真实性存疑"） |
| 替代律师判断（"必须质证"） | 建议性质证（"建议质证时关注XX"） |
| "该证据应当排除" | "建议申请排除该证据（请同步使用 criminal-evidence-exclusion）" |
| 诱导性提问（"你是不是看错了？""是不是受人指使？"） | 开放性问题（"你在事发当时的视线情况如何？""是否有他人向你提供过相关信息？"） |
| 证据能力与证明力混为一谈 | 明确标注攻击维度（证据能力异议 / 证明力异议） |
| 反向自认——"对真实性无异议"/"形式上合法"/"该证据证明了XX事实" | 明确表态"有异议"+说明理由；改用"该证据的合法性仍需审查以下问题"；改用"即使该证据内容属实，其至多能说明XX，不能证明YY" |
| 部分维度承认——"对关联性不持异议，但对证明力有异议" | 区分"认可部分关联方向"与"对整体关联方向有异议"，避免被解读为承认该证据与指控事实有关 |

### 0.5.5 格式禁止（去分析化约束）

| 禁止项 | 正确做法 |
|--------|----------|
| 分析框架标签（"【分析】"/"【结论】"） | 直接叙述 |
| Markdown表格（正文内） | 文字叙述 |
| 策略标注（"攻防分析"/"争点"） | 直接叙述 |

### 0.5.6 证据编号规则

| 证据类型 | 编号前缀 | 示例 |
|----------|---------|------|
| 言词证据 | E-Oral | E-Oral-01（被害人陈述）、E-Oral-02（证人证言） |
| 实物证据 | E-Obj | E-Obj-01（物证）、E-Obj-02（书证） |
| 鉴定意见 | E-Exp | E-Exp-01（法医鉴定）、E-Exp-02（会计鉴定） |
| 程序性证据 | E-Pro | E-Pro-01（辨认笔录）、E-Pro-02（勘验笔录） |

### 0.5.7 DOCX格式要求（由智能体环境实现）

- 页面：A4，上下2.0cm，左3.0cm（装订+批注），右1.5cm
- 标题：微软雅黑14pt加粗居中
- 正文：微软雅黑10.5pt，行距1.15倍
- 质证表格为五列（证据编号/证据名称/质证意见/法律依据/备注）
- 日期格式：标准日期

## 2. SOFT_DEGRADED 输出

当输入不足或关键信息缺失时，输出最小骨架：

### 2.1 骨架内容

```
## C) Missing Facts Checklist（待补充事实清单）
- [缺失证据清单]: boundary - 提供控方证据清单
- [缺失质证重点]: evaluation - 指定重点质证证据
- [缺失辩护方向]: strategy - 指定辩护方向（影响质证策略）

## D) Governance & Non-Goals（治理与禁区）
- 按合法性→真实性→关联性顺序质证（金标准）
- 区分证据能力异议（动议排除）与证明力异议（质证削弱）
- 禁止无依据质疑证据真实性
- 禁止替代律师庭审判断
- 禁止"确定有罪"等违反无罪推定原则的表述
- 禁止诱导性提问

## G) Actionable Next Steps（下一步行动）
- 补充：控方证据清单
- 补充：质证重点
- 补充：辩护方向
```
