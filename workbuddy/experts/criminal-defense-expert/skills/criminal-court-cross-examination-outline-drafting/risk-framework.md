# 风险框架：criminal-cross-examination

> 质证提纲 | 版本: v2.2.0

## 1. 风险等级

**L2（中等风险）**——质证意见影响证据采信，需律师复核。Phase 3 三性分析标注 L3 高风险。

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 证据分类+编号 | L2 | 中风险——分类错误将导致质证策略偏移 |
| Phase 3 三性分析 | **L3** | **🔴 高风险**——质证意见正确性直接影响证据采信，错误将导致质证无效 |
| Phase 4 质证意见组织+交叉询问 | L2 | 中风险——质证方向错误将导致庭审策略偏移 |
| Phase 5 质量检查 | L1 | 低风险 |
| Phase 6 输出交付 | L1 | 低风险 |
| Phase 7 DOCX渲染 | L1 | 低风险 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 禁止替代律师庭审判断 | 生成质证意见时 | 标注"供参考" |
| RC-02 | 合法性优先质证 | 每份证据 | 合法性→真实性→关联性顺序不可颠倒 |
| RC-03 | 证据能力/证明力区分 | 每份证据合法性段 | 明确标注证据能力异议（动议排除）vs 证明力异议（质证削弱） |
| RC-04 | 鉴定意见专项审查 | 涉及鉴定意见 | 六要素必须审查 |
| RC-05 | 辨认笔录专项审查 | 涉及辨认笔录 | 四要素必须审查（混同规则/单独辨认/辨认前接触/见证人） |
| RC-06 | 电子证据专项审查 | 涉及电子数据 | 七要素必须审查 |
| RC-07 | exclusion 转交规则 | 发现重大违法（刑讯逼供/暴力取证/伪造签名等） | 必须标注"建议同步调用 criminal-evidence-exclusion" |
| RC-08 | 言词vs实物一票否决区分 | 合法性质证 | 言词=强制排除（第56条第1款），实物=有条件排除（第2款） |
| RC-09 | 禁止诱导性提问 | 生成交叉询问问题时 | 问题必须开放、非诱导 |
| RC-10 | 辩护方向适配 | Phase 3 三性分析 | 事实之辩=合法性优先，定罪之辩=关联性优先，量刑之辩=不利证据攻击+有利证据防守二元策略 |
| RC-11 | 反向自认防御 | 每份质证意见 | 禁止"对真实性无异议"/"形式上合法"/"该证据证明了XX事实"等可能构成默认承认的表述 |

## 4. 行为约束

- 质证意见供参考，不替代律师庭审判断
- 每条质证意见必须附论证理由
- 证据能力异议与证明力异议必须区分标注
- 发现重大违法=必须提示转交 exclusion，不得在质证中替代产排除申请书
- 有条件出庭质证效果优于书面意见
- 交叉询问问题必须开放无诱导性
