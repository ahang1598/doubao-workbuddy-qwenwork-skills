# 质量标准：刑事质证提纲

> criminal-cross-examination | v2.2.0

## 六维评价体系

| 维度 | 权重 | 优秀 | 合格 | 不合格 |
|------|------|------|------|--------|
| 质证顺序规范 | 10% | 严格按合法性→真实性→关联性，合法性优先（金标准） | 三性均已分析但顺序有误 | 三性分析缺项或顺序混乱 |
| 证据能力/证明力区分 | 15% | 每份证据明确标注攻击维度（证据能力/证明力），区分动议排除vs质证削弱 | 关键证据有区分，但有1-2处混淆 | 未区分证据能力与证明力 |
| 三性质证完整 | 20% | 每份证据三性均有质证 | 主要证据三性质证 | 遗漏关键证据 |
| 专项质证 | 15% | 鉴定意见六要素+辨认笔录四要素+电子数据七要素全覆盖 | 鉴定意见/辨认笔录已质证 | 未对鉴定意见/辨认笔录专项质证 |
| 证明力论证 | 15% | 含攻击维度标注+推理过程+综合评价 | 关键证据有评价 | 无证明力分析 |
| 交叉询问 | 10% | 言词证据/鉴定意见各附3-5个开放性问题，无诱导性 | 关键证据附问题但有1-2处诱导 | 无交叉询问问题 |
| 言词vs实物区分 | 5% | 完全区分策略不同，一票否决规则（言词强制vs实物有条件）正确 | 基本区分 | 未区分 |
| 质证逻辑 | 10% | 形成攻击体系，证据间矛盾已分析，exclusion转交已处理 | 有逻辑 | 零散罗列 |

## 阻断/警告检查项

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 三性质证完整 | 阻断 | 每份关键证据须有合法/真实/关联质证（合法性优先） |
| 质证顺序 | 阻断 | 必须按合法性→真实性→关联性顺序（金标准） |
| 证据能力/证明力区分 | 阻断 | 必须明确标注证据能力异议（动议排除）vs 证明力异议（质证削弱） |
| 鉴定意见六要素 | 阻断 | 鉴定意见须专项质证 |
| 辨认笔录四要素 | 阻断 | 辨认笔录须审查混同规则/单独辨认/辨认前接触/见证人 |
| 质证理由 | 阻断 | "有异议"须附具体理由 |
| 非法证据排除 | 阻断 | 发现非法取证须标注 exclusion 转交建议 |
| 证明力评价 | 警告 | 应有证明力评估 |
| 证人利害关系 | 警告 | 证人证言须审查利害关系 |
| 证据编号 | 阻断 | 所有证据须使用 E-Oral/E-Obj/E-Exp/E-Pro 编号 |
| 交叉询问 | 警告 | 言词证据/鉴定意见须附3-5个参考问题 |
| 禁止诱导性提问 | 阻断 | 交叉询问问题不得有诱导性 |
| 辩护方向一致性 | 阻断 | 质证重点须与辩护方向匹配（三方向不同结构顺序） |
| 反向自认扫描 | 阻断 | 禁止"对真实性无异议"/"形式上合法"等可能构成默认承认的表述 |
