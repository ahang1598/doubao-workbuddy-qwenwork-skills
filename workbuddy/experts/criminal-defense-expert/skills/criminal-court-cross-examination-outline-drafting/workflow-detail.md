# 工作流详述

> 本文件定义 criminal-cross-examination 技能的各Phase子步骤与检查点
> 遵循 compiler/ssot.md §17（SSOT）：按需拆分规则
> 版本：v2.2.0

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 证据分类[L2] → Phase 3: 三性分析[L3]
    ↓
Phase 4: 质证意见组织+交叉询问[L2] → Phase 5: 质量检查[L1] → Phase 6: 输出交付
```

## 2. Phase 1: 输入验证

### 1.1 输入解析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1.1 | 解析自然语言输入 | 结构化字段字典 |
| 1.1.2 | 提取案件基本信息 | defendant_name, alleged_crime |
| 1.1.3 | 提取证据清单 | evidence_list（含名称、类型、摘要） |
| 1.1.4 | 识别质证重点 | cross_exam_focus |
| 1.1.5 | 识别辩护方向 | defense_type（事实之辩/定罪之辩/量刑之辩） |

### 1.2 输入校验

| 检查项 | 校验规则 | 失败行为 |
|--------|----------|----------|
| defendant_name 存在 | 非空 | 进入SOFT_DEGRADED C块 |
| alleged_crime 存在 | 非空 | 进入SOFT_DEGRADED C块 |
| evidence_list 非空 | 至少1项 | 交互补全（最多3轮） |
| 证据类型有效 | 枚举值 | 自动推断类型 |
| defense_type 有效 | 枚举值 | 默认"事实之辩" |

### 1.3 Phase 1 检查点

- [ ] 输入已结构化
- [ ] 必需字段已提取或标注 [待补充]
- [ ] 证据类型已正确分类
- [ ] 辩护方向已确认（影响后续所有Phase的质证策略）

## 3. Phase 2: 证据分类 [L2风险]

> 风险标注：证据类型分类错误将导致质证策略偏移

### 2.1 证据编号分配

为所有证据分配统一编号：

| 证据类型 | 编号前缀 | 起始编号 |
|----------|---------|----------|
| 言词证据 | E-Oral | E-Oral-01, E-Oral-02, ... |
| 实物证据 | E-Obj | E-Obj-01, E-Obj-02, ... |
| 鉴定意见 | E-Exp | E-Exp-01, E-Exp-02, ... |
| 程序性证据 | E-Pro | E-Pro-01, E-Pro-02, ... |

### 2.2 证据类型分类

| 分类标准 | 类型 | 证据类型枚举值 | 质证策略差异 |
|----------|------|---------------|-------------|
| 言词证据 | 证人证言/被害人陈述/被告人供述 | witness_testimony/victim_statement/suspect_statement | 侧重真实性+一致性，附交叉询问问题 |
| 实物证据 | 物证/书证/视听资料/电子数据 | physical/documentary/audio_visual/electronic_data | 侧重同一性+完整性 |
| 鉴定意见 | 鉴定意见/检验报告 | expert_opinion | 侧重鉴定资质+方法+检材，附交叉询问问题 |
| 程序性证据 | 勘验/检查/辨认/侦查实验笔录 | investigation_record/identification_record/inspection_record | 侧重程序合规性（混同规则/见证人/条件相似性） |

### 2.3 证据重要性排序

| 优先级 | 判断标准 | 质证策略 |
|--------|----------|----------|
| 核心证据 | 直接证明犯罪构成要件 | 重点质证三性（合法性优先） |
| 间接证据 | 佐证核心证据 | 关注关联性 |
| 程序性证据 | 证明取证过程/程序合法性 | 关注合法性（辨认/勘验/侦查实验程序） |
| 补强证据 | 增强其他证据证明力 | 关注独立性 |

### 2.4 Phase 2 检查点

- [ ] 每份证据已分配统一编号（E-Oral/E-Obj/E-Exp/E-Pro）
- [ ] 每份证据类型已正确分类（使用细化后的枚举值）
- [ ] 证据重要性已排序
- [ ] 言词/实物/鉴定/程序性区分明确

## 4. Phase 3: 三性分析 [L3风险] 🔴

> ⚠️ **L3 高风险**：三性分析是质证提纲的核心，分析错误将直接导致质证无效。
> **金标准**：合法性（先"打掉"）→ 真实性（"评判"可靠性）→ 关联性（"校准"方向）。
> 非法证据一票否决，不复存在，后续分析无意义。

### 3.1 合法性分析（证据能力——一票否决）🔴

**通用程序审查**：

| 检查项 | 方法 | 发现问题标注 |
|--------|------|-------------|
| 收集程序 | 是否符合法定程序 | "取证程序[具体违法情形]" |
| 证据形式 | 是否符合法定形式 | "证据形式[不合规情形]" |
| 权利告知 | 是否告知相关权利 | "未告知[具体权利]" |
| 辩护权保障 | 是否保障律师参与 | "辩护律师未参与[具体环节]" |

**言词证据合法性专项**（刑诉法第56条第1款——一票否决）：

| 检查项 | 违法类型 | 处理 |
|--------|---------|------|
| 刑讯逼供 | 重大违法 | 🔴 标注"建议同步调用 criminal-evidence-exclusion" |
| 暴力/威胁取证 | 重大违法 | 🔴 同上 |
| 引诱/欺骗 | 违法 | 🔴 同上 |
| 非法拘禁 | 重大违法 | 🔴 同上 |
| 讯问时间/地点违规 | 程序瑕疵 | 🟡 标注"程序瑕疵，提请法庭注意" |

**实物证据合法性专项**（刑诉法第56条第2款——有条件排除）：

| 检查项 | 处理 |
|--------|------|
| 非法搜查/扣押 | 🟡 需先评估是否可补正。不能补正→🔴 建议排除 |
| 提取程序违规 | 🟡 评估是否严重影响司法公正 |
| 保管链中断 | 🟡 标注"证据完整性存疑" |

**程序性证据合法性专项**：

| 证据类型 | 审查要点 | 发现违法时处理 |
|----------|---------|---------------|
| 辨认笔录 | ①混同规则（真人辨认人≥7/照片辨认≥10张，陪衬特征无显著差异）②单独辨认③辨认前不得接触/暗示④见证人 | 违反①→🔴 辨认结果不能作为定案依据（刑诉法解释第105条）|
| 侦查实验笔录 | ①实验条件相似性②多次实验一致性③见证人 | 条件明显不同→真实性异议 |
| 现场勘验笔录 | ①见证人（2人）②当场签字③物品提取清单 | 无见证人→合法性异议 |

**exclusion 转交硬规则**（🔴 必须执行）：

```
发现以下任一情形时，必须在合法性段末尾标注：
"🔴 建议同步调用 criminal-evidence-exclusion 起草《非法证据排除申请书》"
- 刑讯逼供
- 暴力取证
- 威胁/引诱/欺骗
- 非法拘禁
- 伪造签名/伪造笔录
- 剥夺辩护权
- 非法搜查/扣押且不能补正

⚠️ 不得在质证提纲中替代 criminal-evidence-exclusion 产出排除申请书内容。
```

### 3.2 真实性分析（证明力——评判可靠性）

**言词证据真实性检查**：

| 检查项 | 方法 | 发现问题标注 |
|--------|------|-------------|
| 陈述一致性 | 前后陈述是否矛盾 | "与XX陈述存在矛盾" |
| 细节合理性 | 细节是否合理可信 | "细节[具体描述]与常理不符" |
| 有无诱导 | 询问方式是否诱导 | "可能受到[诱导/暗示]" |
| 与客观证据吻合度 | 是否与物证/书证一致 | "与[XX证据]不一致" |
| 利害关系 | 证人与案件有无利害关系 | "证人系[利害关系]，陈述可信度受影响" |

**实物证据真实性检查**：

| 检查项 | 方法 | 发现问题标注 |
|--------|------|-------------|
| 同一性 | 是否为原始证据 | "系复印件/复制品，原始证据未出示" |
| 完整性 | 是否完整未被篡改 | "[部分]缺失/不完整" |
| 鉴定可靠性 | 鉴定方法是否科学 | "鉴定方法[具体问题]" |

**电子数据真实性专项**：

| 检查项 | 方法 | 发现问题标注 |
|--------|------|-------------|
| 介质原始性 | 是否有原始存储介质 | "无原始存储介质，不能确认未被篡改" |
| 技术完整性（哈希值） | 是否有哈希值（MD5/SHA-256） | "未计算完整性校验值，无法证明电子数据完整" |
| 内容完整性（提取范围） | 提取范围是否完整？是否存在选择性提取？格式转换是否丢失信息？ | "提取范围不完整，遗漏XX时间段数据"/"格式转换导致元数据丢失" |
| 时间戳 | 时间戳是否与案情时间吻合 | "时间戳[具体问题]" |

### 3.3 关联性分析（证明力——校准方向）

| 检查项 | 方法 | 发现问题标注 |
|--------|------|-------------|
| 与待证事实关联 | 证据能否证明指控事实 | "仅能证明[XX]，无法证明[指控事实]" |
| 关联程度 | 直接关联vs间接关联 | "系间接证据，需其他证据补强" |
| 关联方向 | 是否反而支持辩护 | "该证据也可说明[辩护方向]" |
| 行为定性 | 能否证明指控罪名的构成要件 | "该证据指向的行为可能构成[他罪]"（定罪之辩场景） |

### 3.4 三辩护方向下的三性分析权重调整

| 辩护方向 | 合法性权重 | 真实性权重 | 关联性权重 | 说明 |
|----------|-----------|-----------|-----------|------|
| 事实之辩（无罪） | **最高**——积极寻找排除机会 | 高——攻击每一份证据可靠性 | 中——证据链断裂论证 | 先打掉证据，再打破链条 |
| 定罪之辩（重罪→轻罪） | 中——选择性使用 | 低 | **最高**——切断与指控罪名关联 | 重点在"这个行为不是这个罪" |
| 量刑之辩（罪轻） | **最高（不利证据）**——量刑证据程序合规性 | 中——弱化不利情节+强化有利情节 | **最高（有利证据）**——确保从轻情节被采信 | 攻防二元：不利证据攻击合法性，有利证据防守真实性+确保采信 |

### 3.5 Phase 3 检查点

- [ ] 每份证据三性均已分析，合法性优先
- [ ] 合法性段已区分：证据能力异议（动议排除）vs 证明力异议（程序瑕疵）
- [ ] 发现重大违法时已标注 exclusion 转交建议
- [ ] 程序性证据（辨认/勘验/侦查实验）已逐项审查
- [ ] 电子数据已逐项审查八要素（含内容完整性/提取范围审查）
- [ ] 论证有推理过程（非断言堆叠）
- [ ] 三性分析权重与辩护方向匹配
- [ ] 发现的问题已标注

## 5. Phase 4: 质证意见组织+交叉询问 [L2风险]

> 风险标注：质证意见组织错误将导致庭审质证方向偏移

### 4.1 质证意见编写规则

**论证模板（因果推理）**：
```
[前提]：该证据内容为[具体内容]
[推理]：[矛盾/不足/瑕疵]→因此[影响证据能力/证明力的理由]
[结论]：[证据能力/证明力标注]该证据[评价]，建议质证时[方向]
```

**反面论证**：
```
不仅论证"为什么该证据不可信"，也论证"为什么控方依赖该证据定案不充分"
```

**证据能力 vs 证明力标注（必需）**：
- 证据能力异议：标注"🔴 建议动议排除"
- 证明力异议：标注"🟡 建议质证削弱"

### 4.2 辩护方向适配

| 辩护方向 | 质证意见侧重 | 结构顺序 |
|----------|-------------|---------|
| 事实之辩 | 攻击证据真实性，寻找证据链断裂 | 合法性优先（先打掉）→ 真实性 → 关联性 |
| 定罪之辩 | 攻击证据关联性，质疑行为与罪名对应 | 关联性优先 → 合法性 → 真实性 |
| 量刑之辩 | 不利量刑证据攻击合法性+有利量刑证据防守真实性，攻防二元 | 不利证据：合法性→真实性→关联性；有利证据：真实性→关联性→确保采信 |

### 4.3 交叉询问问题生成（P1必须做）

> **触发条件**：言词证据 / 鉴定意见 → 自动生成3-5个交叉询问参考问题

**问题设计原则**：
1. 基于该证据的矛盾点/疑点设计
2. 开放性问题（禁止诱导性提问："你是不是……""难道不是……"）
3. 层层递进（从大问题到具体细节）
4. 不得暗示答案

**问题类型**：
| 类型 | 设计方法 | 示例 |
|------|---------|------|
| 矛盾质证 | 基于前后陈述矛盾 | "你在8月15日笔录中称'保证收益20%'，9月3日改称'保本保息'，这两次陈述哪一次是准确的？" |
| 细节质证 | 基于细节不合理 | "事发时你在房间的什么位置？当时的光线情况如何？你对看到的内容有多确定？" |
| 能力质证 | 基于感知/记忆/表达能力 | "事发时间是凌晨2点，你当时的状态是怎样的？是否有饮酒或服药？" |
| 利害关系质证 | 基于利害关系 | "你与被告人之间是否存在经济往来？你之前是否与被告人有过纠纷？" |
| 鉴定方法质证 | 基于鉴定方法科学性 | "鉴定使用的检材来源是什么？检材是否经过双方确认？鉴定方法是否为行业通用标准？" |

### 4.4 证据间关系分析

| 关系类型 | 处理方式 |
|----------|----------|
| 相互印证 | 在策略总结中指出印证关系，评估是否真实印证 |
| 存在矛盾 | 在策略总结中重点标注，建议庭审利用，附交叉询问问题利用矛盾 |
| 独立存在 | 评估是否有其他证据补强 |

### 4.5 Phase 4 检查点

- [ ] 每份证据有综合质证意见（含证据能力/证明力标注）
- [ ] 质证意见有推理过程
- [ ] 辩护方向与质证策略一致（含结构顺序调整）
- [ ] 证据间关系已分析
- [ ] 言词证据/鉴定意见已生成3-5个交叉询问参考问题
- [ ] 交叉询问问题无诱导性

## 6. Phase 5: 质量检查 [L1风险]

### 5.1 自检清单

| 检查项 | 标准 | 发现问题 |
|--------|------|----------|
| 证据覆盖 | 控方每份证据均已质证 | 阻断 |
| 三性完整 | 每份证据三性均有分析，合法性优先 | 阻断 |
| 论证有据 | 每条质证意见有推理 | 阻断 |
| 无罪推定 | 无"罪犯"等表述 | 阻断 |
| 去分析化 | 无框架标签外泄 | 阻断 |
| 法条编号 | mandatory法条全引用 | 警告 |
| 禁止承诺 | 无"一定胜诉"等 | 阻断 |
| 条文性质 | "可以"≠"应当"正确使用 | 阻断 |
| 证据编号 | 所有证据使用E-Oral/E-Obj/E-Exp/E-Pro编号 | 阻断 |
| exclusion转交 | 发现重大违法已标注转交 | 阻断 |
| 交叉询问 | 言词证据/鉴定意见已附问题 | 警告 |
| 证据能力标注 | 已区分证据能力/证明力异议 | 阻断 |
| 禁止诱导性提问 | 交叉询问问题无诱导性 | 阻断 |
| 辩护方向一致性 | 质证重点与辩护方向匹配 | 阻断 |
| 反向自认扫描 | 无"对真实性无异议"/"形式上合法"/"该证据证明了XX事实"等表述 | 阻断 |
| 质证过度扫描 | 量刑之辩中未对有利量刑证据进行合法性攻击 | 阻断 |
| 质证无关证据扫描 | 与辩护方向无关的证据未大篇幅质证 | 警告 |
| 鉴定人出庭审查 | 对鉴定意见有异议时已建议申请鉴定人出庭 | 警告 |

### 5.2 修复策略

| 问题类型 | 修复方式 |
|----------|----------|
| 阻断级 | 直接修复 |
| 警告级 | 标注+建议，用户确认 |

## 8. Phase 7: DOCX 渲染 [L1 低风险]

> 风险等级：L1 —— I-Practical 内部级，庭审打印携带

### 7.1 渲染准备

| 步骤 | 操作 | 参考文件 |
|------|------|----------|
| 7.1.1 | 读取自定义排版规范 | `references/docx-format-spec.md` |

### 7.2 组件序列渲染

按自定义排版规范渲染。特殊注意：
- I-Practical 排版参数（微软雅黑10.5pt/1.15倍行距）
- 证据清单-编号对照表三列（编号/证据名称/证据类型）
- 质证主表格五列（证据编号10%/证据名称20%/质证意见38%/法律依据17%/备注15%）
- 庭审打印携带——左宽3.0cm便于装订+手写批注
- 备注列含庭审查看勾选框（□ 同意 / □ 部分同意 / □ 异议）+ 手写批注区
- 发现重大违法时质证意见以"🔴"前缀标识
