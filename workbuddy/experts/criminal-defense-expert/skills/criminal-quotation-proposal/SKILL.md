# 刑事案件服务报价方案

> **核心定位**：输入刑事案件信息，生成结构化法律服务报价方案。按案件阶段拆解服务范围与费用结构，强制提示风险代理禁止，确保报价合规。
>
> **蓝本依据**：《律师服务收费管理办法》、发改价格〔2014〕2755号、《关于进一步规范律师服务收费的意见》、各地律协收费指引、刑事案件风险代理禁止规定

---

## 模块一：法律合规声明

> 本模块遵循 compiler/ssot.md §17（SSOT）：可维护度约束六模块编排

1. **管辖范围**：中国大陆（不含港澳台）。报价方案适用于刑事诉讼各阶段
2. **输出性质**：所有输出为**报价方案草稿**，不替代律师独立定价决策，供当事人参考
3. **风险代理禁止（命令式）**：刑事案件**禁止风险代理收费**（《律师服务收费管理办法》第12条）。本技能在任何情况下均不得输出风险代理方案，不得在费用结构中包含风险代理方式
4. **费用估算性质**：费用为**参考估算**，非最终报价。最终收费由律师根据当地律协指引、案件实际情况和自身经验确定
5. **法条检索契约**：`requires_legal_retrieval: true`。收费相关法规须经外部检索确认现行有效性
6. **收费政策时效性**：2014年发改价格〔2014〕2755号放开律师服务市场调节价（刑事案件辩护除外），2021年《意见》后刑事案件收费全面实行市场调节价+风险代理禁止。报价方案不得引用已失效的"政府指导价"作为定价依据
6. **无罪推定**：涉及案件描述时，使用"涉嫌""嫌疑人/被告人"等表述，禁止"罪犯""确定有罪"等表述
7. **免责声明**：报价方案仅供参考，不构成法律建议，不保证案件结果

## 模块二：快速开始

> 最少输入即可启动，技能自动补全缺项

### 最简用法

```
帮我出一个刑事案件的报价方案。张某涉嫌盗窃罪，一审阶段。
```

### 指定复杂程度

```
刑事辩护报价方案。李某涉嫌诈骗罪，金额200万，审查起诉阶段，
案件比较复杂，涉及多笔交易。
```

### 提供完整信息

```
出具刑事报价方案：
- 罪名：故意伤害罪
- 阶段：侦查+审查起诉+一审（全流程）
- 复杂程度：中等
- 涉案金额：无
- 审理地区：广东省深圳市
- 当事人角色：被告人
- 律师费参考：按广东省律协收费指引
```

## 模块三：核心参数与法律约束

### 关键输入

> 详细规格见 [input-spec.md](./input-spec.md)

| 类型 | 参数 | 必填 | 法律含义 |
|------|------|------|---------|
| 必填 | `suspected_crime` | 是 | 涉嫌罪名——决定案件类型和收费基准 |
| 必填 | `case_stage` | 是 | 案件阶段——决定服务范围和阶段划分 |
| 推荐 | `custom_fee_standards` | 否 | 律所/律师自有收费标准——优先于地区指引定价 |
| 推荐 | `complexity` | 否 | 案件复杂程度——影响费用估算区间 |
| 推荐 | `amount_involved` | 否 | 涉案金额——部分罪名影响收费基准 |
| 推荐 | `jurisdiction` | 否 | 审理地区——决定适用哪个地区律协收费指引 |
| 选填 | `special_case_type` | 否 | 特殊案件类型（涉黑涉恶/职务犯罪/毒品/共同犯罪/无罪辩护/认罪认罚）——显著影响服务和收费 |
| 选填 | `client_role` | 否 | 当事人角色——辩护或被害人代理，决定服务项目路由 |
| 选填 | `fee_preference` | 否 | 费用计算偏好——固定/计时/分段 |
| 选填 | `lawyer_experience` | 否 | 律师执业年限——影响费率参考 |

### 关键输出

> 详细规格见 [output-spec.md](./output-spec.md)

| 输出块 | 内容 | 强制性 |
|--------|------|--------|
| O1 方案抬头 | 当事人+案件+律所标识信息（含特殊案件类型标注） | ✅ |
| O2 案件概况 | 罪名+阶段+复杂度+当事人角色+特殊案件类型 | ✅ |
| O3 服务范围与内容 | 各阶段服务项目+工作内容（按client_role路由：辩护/被害人代理） | ✅ |
| O4 费用结构与估算 | 各阶段费用+计算方式+汇总（含特殊案件类型调整） | ✅ |
| O5 风险代理禁止声明 | 法律依据+替代方式 | ✅ 强制 |
| O6 风险提示与免责 | 服务限制+不确定性+费用调整+退费规则摘要 | ✅ |
| O7 律师必检清单 | 需核验关键项（含特殊类型/被害人代理检查） | ✅ |
| C5 自定义标准合规审查 | 用户收费标准违法条目标识+合规建议 | 有自定义标准时触发 |

### 核心原则

| # | 原则 | 说明 |
|---|------|------|
| P1 | **风险代理零容忍** | 刑事案件禁止风险代理是法律红线，任何情况下不得输出风险代理方案 |
| P2 | **报价是谈判工具** | 报价方案是律师与当事人建立信任的谈判起点，非定价工具——先展示服务价值再出现费用，费用给区间非单一数字，区间设计含策略意图 |
| P3 | **费用估算必标来源** | 每项费用估算必须标注来源（用户指定/地区指引/参考区间），不可无依据估算 |
| P4 | **阶段拆解为纲** | 报价方案以案件阶段为骨架，每阶段独立列明服务内容与费用 |
| P5 | **服务内容先于费用** | 先确定服务范围和内容，再估算费用——费用跟着服务走 |
| P6 | **信息不足降级不阻断** | 缺少地区/金额等信息时，输出参考区间而非拒绝服务；信息不足时区间必须加宽（至少±30%） |
| P7 | **免责声明必附** | 所有输出末尾必须包含风险提示和免责声明 |
| P8 | **当事人视角表达** | 方案面向当事人，使用当事人可理解的语言，避免纯法律术语；涉及"申请""争取"等服务须标注"结果取决于案件事实和法律条件" |
| P9 | **律师最终定价权** | AI提供参考方案，律师保留最终定价权，方案不约束律师 |
| P10 | **用户收费标准优先** | 用户提供了律所/律师自己的收费标准时，优先按用户标准定价；用户标准未覆盖的部分，再降级到地区指引或参考区间 |
| P11 | **违法条目显式标识** | 用户收费标准中如存在违反法律强制性规定的条目（如刑事案件风险代理、低于最低收费保障等），必须以⚠️醒目标识并说明违法理由，不得执行 |
| P12 | **方案→合同衔接必提示** | 报价方案必须包含"方案→委托合同衔接提示"，提醒律师将区间确定具体金额、支付节点条款化、退费规则写入合同 |

## 模块四：工作流

### 4.1 流程概览（5 Phase）

```
Phase 1: 输入验证与案件画像  [L1]
  → 提取罪名/阶段/复杂度/特殊案件类型 → 判断案件画像 → 校验必需字段
  → 识别 client_role（辩护 vs 被害人代理）→ 路由服务项目模板
  → 检查是否提供自定义收费标准 → 未提供时提示用户可提供

Phase 2: 合规校验与风险代理审查  [L2]
  → 确认刑事案件 → 风险代理禁止确认 → 收费方式合规
  → 审查自定义收费标准合规性 → 违法条目标识⚠️
  → 特殊案件类型合规检查（涉黑涉恶报备/监察委阶段说明）

Phase 3: 服务范围与阶段拆解  [L1]
  → 按 client_role 选择服务模板 → 确定各阶段服务项目 → 匹配工作内容 → 服务清单
  → 补齐死刑复核阶段/被害人代理等遗漏阶段

Phase 4: 费用估算与结构设计  [L2]
  → 优先按自定义标准估算 → 降级到地区指引 → 再降级到参考区间
  → 应用特殊案件类型调整系数（涉黑涉恶+50%~+200%等）
  → 按阶段估算费用 → 设计费用结构 → 计算汇总 → 来源标注

Phase 5: 方案组装与质检  [L2]
  → 组装完整方案 → 格式排版 → 合规复核 → 律师必检清单
```

**快速路径**：用户输入完整（罪名+阶段+地区）→ 跳过追问，直接计算。

**工作流详述**：见 [workflow-detail.md](./workflow-detail.md)。
