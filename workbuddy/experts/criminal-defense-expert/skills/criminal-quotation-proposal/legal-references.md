## 1. 律师收费管理法规

### 1.1 《律师服务收费管理办法》

| 条文 | 内容概要 | 与本技能关系 |
|------|---------|-------------|
| 第4条 | 律师服务收费实行政府指导价和市场调节价 | 确定收费方式范围 |
| 第5条 | 律师事务所依法提供下列法律服务实行政府指导价：（一）代理民事诉讼案件；（二）代理行政诉讼案件；（三）代理国家赔偿案件；（四）为刑事案件犯罪嫌疑人提供法律咨询、代理申诉和控告、申请取保候审，担任被告人的辩护人或自诉人、被害人的诉讼代理人；（五）代理各类诉讼案件的申诉。律师事务所提供其他法律服务的收费实行市场调节价 | ⚠️ **政策重大转向**：第5条原规定的政府指导价范围已因2014年政策调整而变化——见§1.4 |
| 第9条 | 实行市场调节的律师服务收费，由律师事务所与委托人协商确定 | 固定收费/计时收费的法律依据 |
| 第10条 | 律师服务收费可以根据不同的服务内容，采取计件收费、按标的额比例收费和计时收费等方式 | 费用结构设计依据 |
| 第11条 | 办理涉及财产关系的民事案件时可实行风险代理，但婚姻继承等案件除外 | 风险代理适用范围 |
| 第12条 | **禁止刑事诉讼案件、行政诉讼案件、国家赔偿案件以及群体性诉讼案件实行风险代理收费** | ⚠️ **核心红线**：风险代理禁止 |
| 第13条 | 律师事务所应当与委托人签订书面协议 | 提示用户需另行签订委托合同 |

### 1.2 《关于进一步规范律师服务收费的意见》（司发通〔2021〕87号）

> ⚠️ 注意：该文件采用"部分+（X）项"编号体系，不使用"第X条"编号。

| 条文 | 内容概要 | 与本技能关系 |
|------|---------|-------------|
| 第一部分总则 | 律师服务收费遵循公平、公开、自愿原则 | 收费原则声明 |
| 第（四）项 | 严格限制风险代理适用范围——刑事案件、行政案件、国家赔偿案件以及群体性诉讼案件禁止风险代理 | 扩展风险代理禁止范围 |
| 第（五）项 | 严格规范风险代理行为（约定比例/金额限制等） | 风险代理合规边界 |
| 第（八）项 | 规范律师服务收费行为——律师事务所应当公示收费标准 | 提示律师需公示 |
| 第（十四）项 | 禁止以不正当方式承揽业务 | 报价方式合规边界 |

### 1.3 《国家发展改革委关于放开部分服务价格意见的通知》（发改价格〔2014〕2755号）

> ⚠️ 本文件是刑事案件收费政策的重大转向节点

| 条文 | 内容概要 | 与本技能关系 |
|------|---------|-------------|
| 第四项（律师服务） | 律师服务（**刑事案件辩护和部分民事诉讼、行政诉讼、国家赔偿案件代理除外**）实行市场调节价 | 刑事案件辩护仍保留政府指导价——这是2014年放开时明确保留的例外 |
| 保留政府指导价的律师服务 | ①刑事案件辩护；②民事诉讼中涉及人身关系（婚姻、继承等）的案件；③行政诉讼案件；④国家赔偿案件 | 确认刑事案件辩护收费仍适用政府指导价 |

**政策要点**：
1. 2014年放开的大背景：十八届三中全会"使市场在资源配置中起决定性作用"
2. 刑事案件辩护被明确排除在放开范围之外——保留政府指导价
3. 但2018年后各地陆续放开，刑事案件收费逐渐转入市场调节价
4. 2021年《意见》出台后，刑事案件收费已全面实行市场调节价+风险代理禁止的双轨制

### 1.4 刑事案件收费政策演变（关键时间线）

> ⚠️ 报价方案中涉及政府指导价/市场调节价表述时，必须以当前政策为准，不可沿用已失效的历史规定

| 时间 | 政策文件 | 刑事案件收费定位 | 对报价方案的影响 |
|------|---------|----------------|----------------|
| 2006年 | 《律师服务收费管理办法》 | 刑事案件实行**政府指导价**（第5条第（四）项） | 律师须在政府指导价范围内收费 |
| 2014年 | 发改价格〔2014〕2755号 | 刑事案件辩护**仍保留政府指导价**（被排除在放开范围外） | 刑事案件收费未放开 |
| 2018年后 | 各地陆续放开定价 | 各省逐步将刑事案件收费**转入市场调节价** | 过渡期，各地政策不一 |
| 2021年 | 《关于进一步规范律师服务收费的意见》 | 刑事案件收费**全面市场调节价+风险代理禁止**（双轨制） | 当前有效政策：自主定价但禁止风险代理 |

**⚠️ 当前有效规则（2021年起）**：
- 刑事案件收费实行**市场调节价**——律师/律所在合理范围内自主定价
- **风险代理禁止**——刑事案件绝对禁止风险代理收费（第12条+《意见》第（四）项）
- 律师事务所应当公示收费标准（《意见》第（八）项）
- 报价方案中不得再引用"政府指导价"作为定价依据

### 1.5 《中华人民共和国律师法》

| 条文 | 内容概要 | 与本技能关系 |
|------|---------|-------------|
| 第25条 | 律师承办业务，由律师事务所统一接受委托，与委托人签订书面委托合同 | 确认报价方案≠委托合同 |
| 第40条 | 律师在执业活动中不得私自接受委托、收取费用 | 费用收取合规 |
| 第49条 | 律师违反规定执业（含故意提供虚假证据、干扰诉讼活动等）的处罚——停止执业6个月至1年，情节严重吊销执业证书 | 律师被取消辩护资格的法律依据（非刑诉法第45条） |

### 2.2 收费影响因素

| 因素 | 影响方向 | 说明 |
|------|---------|------|
| 案件复杂程度 | 复杂→费用上浮 | 多被告人/多罪名/跨地区/涉外因素 |
| 涉案金额 | 金额大→费用上浮 | 部分罪名（诈骗/贪污/受贿等）按标的额比例 |
| 律师经验 | 经验丰富→费率较高 | 执业年限/专业领域/社会影响力 |
| 地区差异 | 一线城市→费率较高 | 当地经济发展水平和市场行情 |
| 阶段差异 | 审判阶段→费用较高 | 出庭辩护工作量大于侦查阶段 |

## 3. 刑事案件收费特殊规则

### 3.1 风险代理禁止（核心红线）

**法律依据**：
- 《律师服务收费管理办法》第12条
- 《关于进一步规范律师服务收费的意见》第（四）项

**禁止范围**：
- 刑事诉讼案件（全部阶段）
- 行政诉讼案件
- 国家赔偿案件
- 群体性诉讼案件

**允许的收费方式**：
1. **固定收费**：按阶段/按项目约定固定金额
2. **计时收费**：按律师实际工作时间计费
3. **分段固定收费**：按案件阶段分别约定固定金额（推荐）

### 3.2 最低收费保障

部分律协规定了刑事案件最低收费标准，报价方案不应低于当地最低标准。

### 3.3 费用退还规则

> 报价方案中 O6 风险提示必须包含退费规则摘要。

| 情形 | 处理方式 | 实务说明 |
|------|---------|---------|
| 律师原因终止委托 | 退还全部未提供服务部分的费用 | 含律师被取消辩护资格/拒绝辩护情形（《律师法》第49条、《刑事诉讼法》第44条） |
| 律师被取消辩护资格/拒绝辩护 | 退还全部未提供服务阶段的费用 | 《律师法》第49条（违法执业处罚）+《刑事诉讼法》第44条（辩护人干扰诉讼活动禁止） |
| 当事人原因终止委托 | 已完成阶段费用不退，未开始阶段全额退还 | 需在委托合同中预先明确 |
| 案件被撤回起诉/不起诉 | 已完成阶段费用不退，后续阶段费用全额退回 | 实务中最常见的退费争议场景 |
| 认罪认罚后案件速裁结案 | 审判阶段费用按比例酌减或全额退还不适用部分 | 当事人可能认为"出庭半小时不应收全款"——需在报价方案中预先说明 |
| 阶段内服务部分完成 | 按实际完成工作量比例计费 | 需在委托合同中约定比例计算方式 |
| 案件移送/管辖变更 | 根据实际情况协商调整 | 通常已完成阶段费用不调整 |
| 多阶段委托中途解除 | 已完成阶段不退 + 未开始阶段全额退 + 进行中阶段按比例 | 报价方案中应预设此场景 |
| 全流程委托中途解除 | 按阶段结算，已服务阶段费用×110%（单阶段溢价补差）+ 未服务阶段全额退 | 全流程优惠价以完整履约为前提 |

> ⚠️ 退费争议是律师收费投诉的第一大原因。建议在报价方案 O6 风险提示中明确写入退费规则，并在委托合同中逐条确认。

## 6. 用户收费标准违法检测规则

> 本节定义用户自定义收费标准的合规审查规则，用于 Phase 2.4 合规审查。

### 6.1 检测项与法律依据

| 检测ID | 检测项 | 违法判定标准 | 法律依据 | 严重级别 | 处理方式 |
|--------|--------|------------|---------|---------|---------|
| ILL-01 | 风险代理条款 | 用户标准包含刑事案件风险代理收费约定 | 《律师服务收费管理办法》第12条 | 🔴 致命 | ⚠️标识+拒绝执行+说明违法 |
| ILL-02 | 低于最低收费保障 | 用户标准中某阶段费用低于当地律协最低标准 | 各地律协收费指引 | 🟡 警告 | ⚠️标识+建议调整+提供当地标准 |
| ILL-03 | 无依据过高收费 | 用户标准中某阶段费用显著高于当地市场水平（超出指引上限200%以上） | 《关于进一步规范律师服务收费的意见》第（十四）项 | 🟡 警告 | ⚠️标识+提示风险+建议核实 |
| ILL-04 | 歧视性定价 | 同类案件同类服务无合理理由差异化定价 | 律师执业规范+《律师法》第40条 | 🟡 警告 | ⚠️标识+建议核实定价依据 |

### 6.2 检测执行逻辑

```
对 custom_fee_standards 逐条检查：
  1. 是否包含风险代理收费方式？
     → 是 → ILL-01 命中 → usable = false
  2. 该阶段费用是否低于当地律协最低标准？（需 jurisdiction 支持检索）
     → 是 → ILL-02 命中 → usable = false（建议调整至合规线以上）
  3. 该阶段费用是否超出当地指引上限200%？
     → 是 → ILL-03 命中 → usable = true + ⚠️警告（不阻断，但标识风险）
  4. 是否存在同类案件不同定价且无合理区分依据？
     → 是 → ILL-04 命中 → usable = true + ⚠️警告（不阻断，但标识风险）

综合判断：
  → 全部合规 → 直接使用用户标准
  → 有ILL-01 → 违法条目拒绝执行，改用降级来源
  → 有ILL-02 → 违法条目拒绝执行，建议调整至合规线
  → 有ILL-03/04 → 标识警告，仍可使用（律师最终定价权）
```
