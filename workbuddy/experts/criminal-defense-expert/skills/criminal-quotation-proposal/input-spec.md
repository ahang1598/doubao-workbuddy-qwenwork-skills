# 输入规格 — 刑事报价方案

> 本文件遵循 compiler/ssot.md §17（SSOT）：可维护度约束·按需拆分

---

## 1. 输入模型

### 1.1 必需输入

| # | 字段 | 类型 | 校验规则 | 缺失处理 | 法律含义 |
|---|------|------|---------|---------|---------|
| 1 | `suspected_crime` | string | 可识别为中国刑法罪名（含常见俗称） | 追问1轮→hard_reject | 决定案件类型和收费基准 |
| 2 | `case_stage` | enum | ∈ {侦查, 审查起诉, 一审, 二审, 申诉, 死刑复核} | 追问1轮→默认"一审"+标注 | 决定服务范围和阶段划分 |

### 1.2 推荐输入

| # | 字段 | 类型 | 校验规则 | 缺失处理 | 法律含义 |
|---|------|------|---------|---------|---------|
| 3 | `custom_fee_standards` | object | 见§1.4 自定义收费标准校验 | 不影响主流程，首次运行时提示用户可提供 | 律所/律师自有收费标准，优先于地区指引 |
| 4 | `complexity` | enum | ∈ {简单, 中等, 复杂} | 默认"中等"+标注 | 影响费用估算区间 |
| 5 | `amount_involved` | number | ≥ 0 或 null | 不影响主流程 | 部分罪名影响收费基准 |
| 6 | `jurisdiction` | string | 可识别的中国省级行政区 | 不影响主流程 | 决定适用地区律协指引 |

### 1.3 可选输入

| # | 字段 | 类型 | 校验规则 | 缺失处理 | 法律含义 |
|---|------|------|---------|---------|---------|
| 7 | `special_case_type` | array | ⊆ {涉黑涉恶, 职务犯罪/监察委调查, 毒品犯罪, 共同犯罪/多被告人, 无罪辩护, 认罪认罚从宽} | 不影响主流程，缺失时按普通案件处理 | 特殊案件类型——显著影响服务范围和收费基准 |
| 8 | `client_role` | enum | ∈ {嫌疑人/被告人(辩护), 被害人(代理)} | 默认"嫌疑人/被告人(辩护)" | 当事人身份——辩护与代理的服务项目完全不同 |
| 9 | `fee_preference` | enum | ∈ {固定收费, 计时收费, 分段固定收费} | 默认"分段固定收费" | 费用计算方式偏好 |
| 10 | `lawyer_experience` | enum | ∈ {1-3年, 3-5年, 5-10年, 10年以上} | 不影响主流程 | 影响费率参考区间 |
| 11 | `case_facts_summary` | string | 非空字符串 | 不影响主流程 | 案情简述（写入方案概况） |
| 12 | `client_name` | string | 非空字符串 | 方案中标注"[当事人姓名]" | 当事人标识 |
| 13 | `law_firm_name` | string | 非空字符串 | 方案中标注"[律师事务所名称]" | 律所标识 |

## 1.4 自定义收费标准（custom_fee_standards）

用户可提供律所/律师自己的收费标准，技能将**优先按用户标准定价**，并对其中违反法律强制性规定的条目进行⚠️标识。

### 提供方式

用户以自然语言描述收费标准即可，例如：

```
我们律所的收费标准：
- 侦查阶段：1万-3万
- 审查起诉阶段：1.5万-4万
- 一审阶段：2万-8万
- 复杂案件在此基础上浮30%
```

或提供文件/截图内容。

### 结构化字段

技能从用户输入中提取以下结构化信息：

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `standards_source` | string | 标准来源标识 | "XX律所2025年收费标准" |
| `stage_fees` | object | 各阶段费用区间 | `{"侦查": [10000, 30000], "一审": [20000, 80000]}` |
| `complexity_multiplier` | number | 复杂案件系数 | 1.3（上浮30%） |
| `hourly_rate` | object | 计时收费标准 | `{"标准": 1000, "资深": 2000}` |
| `additional_rules` | array | 附加规则描述 | ["差旅费实报实销", "鉴定费另行收取"] |

### 首次运行提示

当用户未提供 `custom_fee_standards` 时，Phase 1 结束前应提示：

```
💡 您可以提供律所/律师的自有收费标准，技能将优先按您的标准进行定价。
   后续使用时也可随时提供或更新。如无需提供，请忽略此提示。
```

### 违法条目检测

用户标准中如包含以下情形，必须以⚠️标识并说明违法理由：

| 检测项 | 违法情形 | 法律依据 | 处理方式 |
|--------|---------|---------|---------|
| 风险代理 | 刑事案件约定风险代理收费 | 《律师服务收费管理办法》第12条 | ⚠️标识+拒绝执行+说明违法 |
| 最低收费 | 低于当地律协最低收费标准 | 各地律协收费指引 | ⚠️标识+建议调整+提供当地标准参考 |
| 乱收费 | 无依据的过高收费 | 《律师法》第40条、《关于进一步规范律师服务收费的意见》 | ⚠️标识+提示风险 |
| 歧视性定价 | 同类案件不合理差异化定价 | 律师执业规范 | ⚠️标识+建议核实 |

## 2. 输入形态

**主模式**：text_paste（自然语言描述）

用户以自然语言描述案件信息，技能通过自然语言理解提取上述字段。

**提取策略**：
- 罪名：匹配刑法罪名库（含常见俗称，如"醉驾"→危险驾驶罪）
- 阶段：关键词匹配（侦查/审查起诉/一审/二审/申诉/死刑复核）
- 复杂度：根据涉案金额、罪名严重程度、案件事实描述推断
- 地区：省级行政区名称匹配

---

## 3. 缺失降级策略

**策略**：classified_handling（关键字段拒绝+次要字段降级）

| 字段类别 | 缺失处理 | 降级方案 |
|---------|---------|---------|
| 必需字段 | 追问1轮→hard_reject | 无降级（必须提供） |
| 推荐字段 | 使用默认值+标注"待确认" | 中等复杂度/无涉案金额/无地区指引 |
| 可选字段 | 不影响主流程 | 方案中使用占位符 |
