# 风险分级矩阵（共享内核 · SSOT）

> fadada / english 两技能共用的 D1-S3 风险定级规则单一真源。

## 1. 影响 × 概率矩阵

每个风险点按「影响程度 × 发生概率」定级为 高 / 中 / 低，并陈述假设：

| 等级 | 判定标准 |
|---|---|
| **高** | 可能影响合同效力、重大责任、监管处罚、核心交易目的或签署决策 |
| **中** | 影响履行、付款、举证、索赔或争议解决，但可通过修改缓释 |
| **低** | 文字、流程或可签后监控事项 |

概率维度只用 高 / 中 / 低，禁百分比确定性表述（见 safety-redlines.md §3）。

## 2. 风险扫描覆盖维度（D1-S2，不得跳过）

最小覆盖集（取两技能并集，按合同实际取用）：
```
民事 / 行政 / 刑事 / 税务 / 制裁(sanctions) / 执行(execution) /
交易 / 数据合规 / 保密 / 知识产权 / 终止 / 争议解决 /
强制性法律(mandatory-law) / 文本结构
```

## 3. 每个高/中风险条款必带三件套（D1-S7）

- **可直接落地的替换措辞**（directly usable wording，非方向性描述）；
- **谈判退让位（fallback）**；
- **商业影响说明（business effect）**。

知识产权另需分别测试：归属(ownership) / 申请与控制(prosecution-control) / 维权(enforcement)。
