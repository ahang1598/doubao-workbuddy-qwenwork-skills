> 羁押必要性审查申请 | 版本: v4.1.0 | 更新: 2026-06-10

---

## §0. 双轨输出表

| 输出格式 | 用途 | 严肃度 | 规范来源 | O1/O2 |
|----------|------|--------|----------|-------|
| **DOCX** | 直接打印提交检察院/公安机关 | F-Strict | [docx-format-spec.md](./docx-format-spec.md) + GB/T 9704-2012 | O1 正式提交稿 |
| **Markdown** | 会话界面预览/律师编辑 | — | 双风格独立模板完整渲染 | O2 编辑稿 |

> **DOCX 严肃度**：F-Strict（法院级排版）。参照 GB/T 9704-2012 页边距行距标准，仿宋三号16pt正文，方正小标宋简体二号标题。
> **排版规范权威来源**：T2 全国律协《律师办理刑事案件规范》(2017) + T3 行业惯例

### 输出决策

| 条件 | 输出模式 |
|------|----------|
| 会话交互 | 仅 Markdown（O2） |
| 用户要求打印/提交 | Markdown + DOCX（O1 按 docx-format-spec.md 生成 python-docx 代码） |
| 用户指定格式 | 按指定格式 |

### 双风格路由

| 条件 | 风格 | 说明 |
|------|------|------|
| 含定性争议（罪名有争议/轻罪重罪选择/无罪可能） | **Style B** 金翰明风 | 需要精炼概括型论证 |
| release_reasons 含无罪/证据不足/定性错误 | **Style B** 金翰明风 | 争议型案件 |
| 涉及10类负面清单罪名 | **Style B** 金翰明风 | 复杂案件需要更强论证 |
| prior_rejection 非空 | **Style B** 金翰明风 | 需策略性递进论证 |
| 用户显式指定 style=A/B | 按用户指定 | — |
| 默认（无上述特征） | **Style A** 宋瑞学风 | 常规案件，平实直接 |

> **关键约束**：两种风格**完全独立**，禁止交叉混搭。Style A 不出现让步论证/引附法律意见书/退一步论证；Style B 不出现五段式结构/社会危险性独立分段。

## 1. Style A（宋瑞学标准风）完整模板

> 适用：常规案件，事实清楚、争议不大、从宽情节明确

```markdown
# 羁押必要性审查申请书

[XX市XX区人民检察院]：

申请人：[姓名]，[律所名称]律师，执业证号[XXX]，系[犯罪嫌疑人/被告人]
[当事人姓名]的辩护人。联系方式：[电话/地址]。

申请事项：
请求对[当事人姓名]进行羁押必要性审查，并向办案机关
建议变更强制措施为取保候审。

事实与理由：
[当事人姓名]因涉嫌[罪名]，于[日期]被逮捕，现羁押于[看守所名称]，
已羁押[时长]。申请人受[当事人姓名]家属委托，担任其辩护人。
现依据《中华人民共和国刑事诉讼法》第九十五条及
《人民检察院 公安机关羁押必要性审查、评估工作规定》之规定，
申请羁押必要性审查，理由如下：

一、[案件基本情况——融入当事人姓名+罪名+程序进程]
[案件事实简述。程序进程（逮捕时间/侦查进展/阶段变化）。
如涉及第7条8类应立即审查情形，在此融入。]

二、[存在法定从宽情节——融入具体从宽事实]
[自首/从犯/初犯/退赃退赔/认罪认罚等，逐条匹配第17条相关款项。
如符合第16条5类应当释放情形，优先论证。
每个从宽情节一段，含事实+法条依据。]

三、无继续羁押的必要
关于再犯可能性，[当事人]系初犯/偶犯，涉案行为系过失/一时冲动，
无前科劣迹，不存在实施新的犯罪的现实危险。
关于毁灭、伪造证据的风险，本案核心证据已收集固定，
[当事人]无串供条件，不存在毁灭、伪造证据的可能。
关于干扰证人作证的风险，本案已取证完毕，
[当事人]与证人无利益冲突，不存在妨碍作证的可能。
关于打击报复被害人的风险，[当事人]已与被害方达成和解/取得谅解，
不存在打击报复的现实可能。
关于自杀、逃跑的风险，[当事人]在本地有固定住所和稳定职业，
[保证人姓名]愿意担任保证人，配合诉讼程序，
不存在逃避侦查、审判的可能。
综上，[当事人]不具有《刑事诉讼法》第八十一条规定的
社会危险性，继续羁押已无必要。

四、[替代措施足以保障诉讼——融入具体保证方案]
取保候审足以保障诉讼程序正常进行。[保证人情况/保证金方案]。
[如适用监视居住则论证监视居住条件。]

综上所述，恳请贵院对[当事人姓名]启动羁押必要性审查，
依法变更强制措施为取保候审。依据新规第二十三条，
恳请出具《羁押必要性审查结果通知书》书面告知审查结果。

此致
[XX市XX区人民检察院]

申请人：[律师签名]
[律所名称]
二〇XX年X月X日

附：
1. [A类证据附件：和解协议/赔偿凭证/病历/保证人材料等]
2. [B类法条附件：核心法条全文]
3. 依据新规第二十三条，恳请出具书面结果通知书
```

### Style A 写作规范

| 要素 | 说明 |
|------|------|
| 四段式结构 | 案件基本情况→法定从宽情节→无继续羁押必要→替代措施可行 |
| 社会危险性段 | 第三段"无继续羁押必要"，采用"关于……，[当事人]……"逐项自然语言叙述 |
| 法条融入 | 🔴 禁止在第四段后附加"五、法律依据"段。法条分散在各论证段落中（段一引第7条、段二引第16/17条、段三引第81条、段四引第67条） |
| 论证风格 | 平实直接，不使用让步论证、退一步论证 |
| 段落标题 | 融入案件具体事实，禁止模板化标签 |

## 2. Style B（金翰明精炼风）完整模板

> 适用：定性争议案件、无罪可能、10类负面清单、被拒后再申请等复杂案件

```markdown
# 羁押必要性审查申请书

[XX市XX区人民检察院]：

申请人：[姓名]，[律所名称]律师，执业证号[XXX]，系[犯罪嫌疑人/被告人]
[当事人姓名]的辩护人。联系方式：[电话/地址]。

申请事项：
请求对[当事人姓名]进行羁押必要性审查，并向办案机关
建议变更强制措施为取保候审。

事实与理由：
[当事人姓名]因涉嫌[罪名]，于[日期]被逮捕，现羁押于[看守所名称]，
已羁押[时长]。
现依据《中华人民共和国刑事诉讼法》第九十五条及
《人民检察院 公安机关羁押必要性审查、评估工作规定》之规定，
申请羁押必要性审查，理由如下：

一、[定性论证——融入具体罪名争议]
[如存在定性争议：本案应认定为XX罪而非XX罪，理由如下：
首先，[构成要件分析]；其次，[事实定性差异]；
再次，[法律适用分歧]；故此，[定性结论]。]
[如涉及无罪可能：本案现有证据不足以证明[当事人]构成犯罪，
具体分析详见法律意见书。]
即使退一步讲，即便认定[当事人]构成[指控罪名]，
其也具有以下从宽情节，继续羁押已无必要。

二、[当事人]具有法定从宽情节，且无社会危险性
[自首/认罪认罚/退赃退赔/初犯等概括。
关于社会危险性，[当事人]系初犯、有固定住所和稳定职业、
核心证据已固定、已取得谅解，不具有《刑事诉讼法》
第八十一条规定的社会危险性。]

三、涉案风险可控，无逃匿或妨碍诉讼之虞
[退赃/谅解/保证人/涉案款项可控]。
[当事人]在本地有固定住所，[保证人]愿意担任保证人，
变更强制措施足以保障诉讼程序正常进行。
继续羁押不符合比例原则——[羁押时长vs可能刑期]。

四、[特殊因素+政策考量]
[如适用：少捕慎诉慎押刑事司法政策/
民营企业保护/人民法院案例库入库案例参照/
人道主义因素。]

综上所述，恳请贵院对[当事人姓名]启动羁押必要性审查，
依法变更强制措施为取保候审。依据新规第二十三条，
恳请出具《羁押必要性审查结果通知书》书面告知审查结果。
[如涉及定性争议：建议贵院同步审查本案法律意见书。]

此致
[XX市XX区人民检察院]

申请人：[律师签名]
[律所名称]
二〇XX年X月X日

附：
1. [A类证据附件：和解协议/赔偿凭证/病历/保证人材料等]
2. [B类法条附件：核心法条全文]
3. 依据新规第二十三条，恳请出具书面结果通知书
4. [如涉及定性争议：建议同步提交法律意见书（详见法律意见书）]
```

### Style B 写作规范

| 要素 | 说明 |
|------|------|
| 四论点递进 | 定性论证→从宽+无社会危险性→涉案风险可控→特殊因素+政策 |
| 定性论证段 | 可含让步论证（"即使退一步讲……也应当……"），可引"详见法律意见书"但不生成 |
| 社会危险性 | 融入第二段概括叙述，不独立分段 |
| 法条融入 | 分散在各论点段落中，不设独立法律依据段 |
| 论证风格 | 精炼概括，递进设防，从最强论点到次强论点 |
| 段落标题 | 融入案件具体事实，禁止模板化标签 |

## 3. 附件三分类策略

| 类别 | 内容 | 目的 | 出现位置 |
|------|------|------|----------|
| A类证据附件 | 和解协议/赔偿凭证/病历/保证人材料/在押表现材料/退赃凭证 | 增强说服力 | 落款后"附"区第1项 |
| B类法条附件 | 核心法条全文（第7/16/17条等） | 方便审查人员查阅 | 落款后"附"区第2项 |
| C类意见书提示 | 仅O2策略提示："本案涉及无罪/定性争议，建议另行提交法律意见书" | 提示律师后续动作 | O2策略提示区，不出现在O1正文中 |

> **关键约束**：本技能只输出申请书。法律意见书仅在O2策略提示中建议另行提交（通过其他技能完成），不在本技能输出中生成。

## 4. 预判反驳模板

> 嵌入申请书对应论证段落，针对检方4大常见拒绝理由。反驳融入论证段落，不单独成章。

### 反驳1："罪行严重，社会危险性高"

> 罪重≠社会危险性高（新规第18条区分犯罪类型与社会危险性）。论证：罪名本身不能单独推断社会危险性，须结合案件具体事实+当事人个人情况综合判断。

### 反驳2："事实未查清"

> 核心证据是否已固定（第16条(四)）。论证：主要事实已查清（列明已固定证据），无串供/毁灭证据风险。

### 反驳3："未达成赔偿谅解"

> 赔偿谅解非唯一指标（第17条(六)-(八)为并列条件）。论证：已完成的赔偿/部分履行/担保情况。

### 反驳4："非羁押保障不足"

> 具体保证方案：人保+财保双保险。论证：保证人资质/保证金金额/取保足以保障。

## 5. SOFT_DEGRADED 三档输出

### 5.1 C档（完整版，标准输入）

- 双风格按路由输出完整论证
- 预判反驳融入对应段落
- 附件按A/B/C三类分类
- 落款后附法律条文+附件清单+程序闭环

### 5.2 D档（框架版，信息不足时）

- 论证框架完整，缺失信息用 `[需补充：XXX]` 标注
- 法律法规匹配标注"待匹配"
- 包含"信息不足提示"段落

### 5.3 G档（骨架版，极简输入时）

- 论证仅标标题+待论证
- 大部分段落用 `[需补充：XXX]` 占位
- 增加**免责声明**（仅O2）："本申请书基于有限信息生成，需律师补充完善后方可使用"
- ⚠️ **O1(.docx) 删除免责声明**

## 6. 写作红线

| # | 禁止项 | 原因 | 正确做法 |
|---|--------|------|----------|
| W1 | 承诺或暗示审查必然通过 | 违反职业伦理 | "恳请审查""建议变更" |
| W2 | 使用"保释"一词 | 中国法律无此概念 | "取保候审" |
| W3 | 对检察机关使用施压性语言 | 不利申请通过 | 客观陈述+法条依据+逻辑论证 |
| W4 | 评价办案机关逮捕决定 | 应聚焦"变化后"无继续羁押必要 | "鉴于案件情况发生变化……" |
| W5 | O1正文含配套文书触发/法条堆砌/程序闭环独立章 | 真实范文不用此结构 | 融入正文论证+落款后附属 |
| W6 | O1(.docx)正文使用表格 | F-Strict纯文字叙述 | 逐项分段叙述 |
| W7 | O1(.docx)包含免责声明 | 正式提交稿不得含免责声明 | 仅O2(Markdown)保留 |
| W8 | 笼统断言"无社会危险性" | 须逐项论证 | 逐项+证据支撑 |
| W9 | 法条引用笼统 | 须融入论证段落+具体款项 | 每个论点配对应法条依据 |
| W10 | 段落标题用模板化标签或内部编码 | 须融入案件具体事实 | "王某某应定性为职务侵占罪"而非"一、关于定性" |
| W11 | 使用D1/D2/V1/V2等内部编码标签 | 面向审查人员的正式文书不得出现内部编码 | 用自然法言法语描述论证内容 |
| W12 | 双风格混搭 | 两种风格完全独立 | Style A不出现让步论证/引附意见书；Style B不出现五段式结构/社会危险性独立分段 |

## 7. 质量标准

### 7.1 论证力度要求

| 层级 | 要求 | Style A | Style B |
|------|------|---------|---------|
| 第一层：法定从宽 | 第16/17条匹配 | 第二段逐条匹配 | 第二段概括匹配 |
| 第二层：社会危险性排除 | 逐项排除 | 第三段独立逐项叙述 | 融入第二段概括叙述 |
| 第三层：量刑推算 | 入库案例类比 | 可选（融入基本情况段） | 融入第三段比例原则论证 |
| 第四层：政策支撑 | 少捕慎诉慎押+案例库 | 可融入第四段替代措施段后附加说明 | 第四段政策考量 |

### 7.2 证据引用要求

| 要求 | 说明 |
|------|------|
| 每个论证点必须引用具体证据来源 | 卷宗页码/证据编号/同案人供述 |
| 电子证据 | 原始载体+哈希值 |
| 疾病证明 | 近3个月连续诊疗记录 |
| 和解谅解 | 和解协议+收款收据+谅解书三件配套 |
| 在押表现 | 看守所出具的羁押期间表现材料 |

### 7.3 阶段差异化检查

| 阶段 | 致送机关 | 特殊要求 |
|------|----------|----------|
| 侦查 | 公安+检察双轨 | 标注"请公安机关评估" |
| 审查起诉 | 检察院 | 策略提示调取证据申请书 |
| 审判 | 检察院 | 说明审判阶段审查特点 |
