# 标准示例001：盗窃罪羁押必要性审查申请（Style A）

> criminal-custody-review | 标准示例 | C档（完整版）| Style A（宋瑞学标准风）| v4.1.0

## 输入

```markdown
当事人：李某
涉嫌罪名：盗窃罪
当前阶段：审查起诉（prosecution）
已羁押时长：4个月
案件事实：李某因涉嫌盗窃罪于2025年1月被逮捕。涉案金额3000元，已全部退赃并取得被害人谅解。李某系初犯，有固定住所和稳定职业，家庭经济困难，妻子待产需要照顾。
申请理由：1.涉案金额较小；2.已退赃并获得谅解；3.社会危险性已消除；4.家庭困难需要照顾
建议措施：取保候审
```

## 风格路由说明

本案为常规盗窃案件，事实清楚、罪名无争议、从宽情节明确，不涉及定性争议/10类负面清单/被拒后再申请，自动路由为 **Style A**（宋瑞学标准风）。

## 预期输出

```markdown
# 羁押必要性审查申请书

XX市XX区人民检察院：

申请人系犯罪嫌疑人李某的辩护律师，现依据《中华人民共和国刑事诉讼法》第九十五条之规定，请求贵院对李某的羁押必要性进行审查，并决定释放或者变更强制措施为取保候审。

事实与理由：

一、李某涉嫌盗窃金额3000元，属于盗窃罪"数额较大"起点，结合全部退赃、取得谅解、初犯等情节，可能被判处拘役或者管制，符合新规第7条第(六)项"应当立即审查"情形，贵院应当立即开展羁押必要性审查。

二、根据《规定》第十六条，李某符合应当释放情形：第16条第(二)项——事实、情节变化可能被判处拘役或者管制；第16条第(四)项——案件事实基本查清，证据已经收集固定，符合取保候审条件。贵院应当及时决定释放或者变更强制措施。此外，根据《规定》第十七条，李某具有以下从宽情形，且具有悔罪表现，不予羁押不致发生社会危险性：第17条(二)主观恶性较小的初犯；第17条(六)认罪认罚；第17条(七)已取得被害人书面谅解；第17条(八)已全部退赃3000元；第17条(十四)可能被判处一年以下有期徒刑。

三、无继续羁押的必要
关于再犯可能性，李某系初犯偶犯，涉案金额小，无前科劣迹，不存在实施新的犯罪的现实危险。
关于毁灭、伪造证据的风险，案件已进入审查起诉阶段，核心证据已收集固定，不存在毁灭、伪造证据的可能。
关于干扰证人作证的风险，本案已取证完毕，李某与证人无利益冲突，不存在妨碍作证的可能。
关于打击报复被害人的风险，李某已与被害人达成和解并取得谅解，不存在打击报复的现实可能。
关于自杀、逃跑的风险，李某在本地有固定住所和稳定职业，其妻子愿意担任保证人，配合诉讼程序，不存在逃避侦查、审判的可能。
综上，李某不具有《刑事诉讼法》第八十一条规定的社会危险性，继续羁押已无必要。

四、替代措施足以保障诉讼
李某有固定住所和稳定职业，变更强制措施为取保候审后，由其妻子作为保证人，保证李某随传随到，不会影响诉讼正常进行。

综上所述，李某涉嫌轻微犯罪，已退赃谅解，社会危险性已消除，继续羁押不符合比例原则。依据新规第二十三条，恳请贵院将审查结果书面告知申请人，出具《羁押必要性审查结果通知书》。

此致
XX市XX区人民检察院

申请人：XXX律师
XXX律师事务所
二〇二五年五月九日

---

附：
1. A类证据附件：（1）退赃凭证（银行转账记录复印件1页）（2）被害人谅解书（原件1页）（3）房产证（复印件3页）（4）劳动合同+社保缴纳记录（复印件5页）（5）保证人身份证明（复印件1页）
2. B类法条附件：《刑事诉讼法》第95/96/97条、《羁押必要性审查、评估工作规定》第7/16/17/23条
3. 依据新规第二十三条，恳请贵院将审查结果书面告知申请人
```

### 与 v3.0.0 的关键差异

| 维度 | v3.0.0 六段式 | v4.1.0 Style A 四段式 |
|------|-------------|---------------------|
| 结构 | 六段（一~六） | 四段（一~四） |
| 社会危险性 | D1-D6内部编码标签 | "关于……"自然法言法语 |
| 法律依据 | 分散在各段 | 法条融入各论证段落，不设独立段 |
| 量刑推算 | 独立段（第五段） | 可融入第一段基本情况 |
| 替代措施 | 独立段（第六段） | 第四段替代措施可行 |
