# 边缘示例001：信息不足的羁押必要性审查申请（D档骨架）

> criminal-custody-review | 边缘示例 | D档（框架版）| v4.1.0

## 输入

```markdown
王某，故意伤害罪，侦查阶段，被逮捕了
```

## 风格路由说明

信息极简，无法判断是否涉及定性争议/负面清单，默认路由为 **Style A**（宋瑞学标准风）。如后续补充信息显示需要 Style B，则重新路由。

## 预期输出

```markdown
# 羁押必要性审查申请书

XX市公安局XX分局（评估）+ XX市XX区人民检察院（审查）：

[注] 本案处于侦查阶段，依据新规第一条第二款，应向公安机关申请评估并同时向检察院申请审查，充分利用双轨机制。

申请人系犯罪嫌疑人王某的辩护律师，现依据《中华人民共和国刑事诉讼法》第九十五条之规定，请求贵局/贵院对王某的羁押必要性进行审查/评估，并建议释放或者变更强制措施为[需补充：取保候审/监视居住]。

事实与理由：

一、[需补充：案件基本情况——王某涉嫌故意伤害罪，根据新规第7条8类情形逐条匹配。请提供：王某是否有严重疾病？是否怀孕/哺乳？羁押期限是否将超过可能判处的刑期？事实/法律/证据是否发生变化？]

二、[需补充：存在法定从宽情节——根据新规第16条5类应当释放情形和第17条16类可以变更情形逐条匹配。请提供：是否认罪认罚？是否与被害方和解/获得谅解？是否已赔偿或提供担保？是否初犯/偶犯？]

三、[需补充：无继续羁押的必要——按《刑事诉讼法》第81条五种社会危险性情形逐项自然语言评估：
关于再犯可能性，……
关于毁灭、伪造证据的风险，……
关于干扰证人作证的风险，……
关于打击报复被害人的风险，……
关于自杀、逃跑的风险，……]

> ⚠️ **信息不足提示**：当前输入信息极为有限，无法进行充分的法条匹配和论证。建议补充以下信息：
> 1. 案件具体事实和伤害后果
> 2. 是否已赔偿被害人
> 3. 当事人是否有前科
> 4. 已羁押具体时长
> 5. 当事人是否有固定住所和职业
> 6. 是否有严重疾病

四、[需补充：替代措施足以保障诉讼——保证人信息或保证金数额]

综上所述，恳请贵局/贵院对王某的羁押必要性进行审查/评估。依据新规第二十三条，恳请将审查结果书面告知申请人。
```

### 与 v3.0.0 的关键差异

| 维度 | v3.0.0 D档六段式 | v4.1.0 D档 Style A 四段式 |
|------|-----------------|--------------------------|
| 结构 | 六段（一~六）含独立"政策与案例支撑"段 | 四段（一~四），法条融入论证段落 |
| 社会危险性 | 第三段无自然语言模板 | 第三段提供"关于……"逐项自然语言模板 |
| 法律依据 | 分散在各段 | 法条融入各论证段落，不设独立段 |
| 量刑推算 | 独立第四段 | 可融入第一段基本情况 |
