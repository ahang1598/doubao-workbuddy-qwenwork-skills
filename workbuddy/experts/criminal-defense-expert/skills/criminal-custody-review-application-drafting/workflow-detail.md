# 工作流详情：criminal-custody-review

> 羁押必要性审查申请 | 版本: v4.1.0 | 更新: 2026-06-10

---

## Phase 1: 输入验证 + 时机评估 + 风格路由 [L2]

### 1.1 输入验证

- 检查4个必填字段是否完整
- 验证 current_stage 枚举值合法（investigation / prosecution / trial）
- 检查 hard_reject 条件（当事人是否已被逮捕）

### 1.2 风格路由

> v4.0.0 引入，v4.1.0 保留：从 V1/V2 变体路由重构为 Style A/Style B 双风格路由

| 条件 | 风格 | 说明 |
|------|------|------|
| 含定性争议（罪名有争议/轻罪重罪选择/无罪可能） | **Style B** 金翰明风 | 需要精炼概括型论证 |
| release_reasons 含无罪/证据不足/定性错误 | **Style B** 金翰明风 | 争议型案件 |
| 涉及10类负面清单罪名 | **Style B** 金翰明风 | 复杂案件需要更强论证 |
| prior_rejection 非空（被拒后再申请） | **Style B** 金翰明风 | 需策略性递进论证 |
| 用户显式指定 style=A/B | 按用户指定 | — |
| 默认（无上述特征） | **Style A** 宋瑞学风 | 常规案件，平实直接 |

### 1.3 时机评估

| 评估项 | 判断逻辑 | 处理 |
|--------|----------|------|
| 逮捕日期 vs 当前日期 | 逮捕后多久？ | 逮捕后约1个月为黄金窗口1（情绪缓和+证据固定） |
| 当前阶段 | 是否审查起诉阶段？ | 是→标注黄金窗口2，提示成功率最高 |
| 是否可能判3年以下 | 审查起诉阶段+可能判3年以下？ | 是→检察院应依职权审查（新规第6条） |
| 是否再申请 | prior_rejection是否非空？ | 是→要求提供新证据/新理由（新规第9条） |

### 1.4 致送路由确定

| current_stage | 致送机关 | 说明 |
|---------------|----------|------|
| investigation | 公安机关（评估）+ 检察院（审查） | 双轨致送。**不得向法院申请** |
| prosecution | 检察院 | 单轨。**不得向法院申请** |
| trial | 检察院 | 单轨。**不得向法院申请** |

**检查点**: 必填字段完整 + 无 hard_reject 触发 + 致送路由确定 + 风格路由确定

## Phase 2: 案件信息结构化 + 证据标准化 [L2]

### 2.1 信息结构化

- 从自然语言输入中提取结构化信息
- 识别申请审查的核心理由
- 判断诉讼阶段，确定论证策略
- 评估输入充分度 → 决定输出档次（C/D/G）

### 2.2 证据标准化检查

| 证据类型 | 检查项 | 标记 |
|----------|--------|------|
| 电子证据 | 是否有原始载体+哈希值 | 不达标→标注[⚠️建议补充] |
| 疾病证明 | 是否有近3月连续诊疗记录 | 不达标→标注[⚠️建议补充] |
| 固定住所 | 是否有房产证/租房合同 | 不达标→标注[⚠️建议补充] |
| 稳定职业 | 是否有劳动合同+社保记录 | 不达标→标注[⚠️建议补充] |
| 和解谅解 | 是否有三件配套（协议+收据+谅解书） | 不达标→标注[⚠️建议补充] |
| 退赃凭证 | 是否有银行转账/公安机关收据 | 不达标→标注[⚠️建议补充] |
| 社会调查 | 是否有社区表现/帮教条件证明（新规第14条） | 可选→建议补充 |

### 2.3 配套文书触发判断

| 条件 | 触发 |
|------|------|
| current_stage = prosecution | O2策略提示调取证据申请书 |
| 涉及10类负面清单罪名 / prior_rejection 非空 | O2策略提示建议提交法律意见书 |
| 用户申请听证 | 程序闭环提示中建议申请听证（新规第15条） |

> **关键约束**：配套文书仅O2策略提示，不出现在O1正文中。本技能只输出申请书，不生成法律意见书。

**检查点**: 结构化信息完整 + 输出档次确定 + 证据标准化标注完成 + 配套文书触发确定

## Phase 3: 理由分点论证构建 [L3]

> v4.0.0 引入，v4.1.0 保留：Phase 3 根据风格路由走双路径论证构建

### 3.1 Style A 路径：四段式论证构建

| 分点 | 内容 | 匹配法条 | 优先级 |
|------|------|----------|--------|
| 一 | 案件基本情况 | 第7条8类（融入） | 🔥🔥🔥 最高 |
| 二 | 存在法定从宽情节 | 第16条5类优先+第17条16类逐条匹配 | 🔥🔥🔥 最高 |
| 三 | 无继续羁押必要 | 第81条五种社会危险性情形逐项自然语言排除 | 🔥🔥 高 |
| 四 | 替代措施足以保障诉讼 | 第67条取保条件 | 🔥🔥 高 |

**Style A 第三段"无继续羁押必要"逐项自然语言论证**：

> 不使用D1/D2等内部编码标签，采用"关于……，[当事人]……"式自然法言法语逐项叙述：

- 关于再犯可能性，[当事人]系初犯/偶犯，无前科劣迹……
- 关于毁灭、伪造证据的风险，本案核心证据已收集固定……
- 关于干扰证人作证的风险，本案已取证完毕……
- 关于打击报复被害人的风险，[当事人]已与被害方达成和解/取得谅解……
- 关于自杀、逃跑的风险，[当事人]在本地有固定住所和稳定职业……
- 综上，[当事人]不具有《刑事诉讼法》第八十一条规定的社会危险性。

### 3.2 Style B 路径：四论点递进论证构建

| 论点 | 内容 | 匹配法条 | 优先级 |
|------|------|----------|--------|
| 一 | 定性论证（如有争议优先） | 第17条相关+第7条6-7类 | 🔥🔥🔥 最高 |
| 二 | 从宽情节+无社会危险性（概括） | 第16条5类+第17条16类+第81条 | 🔥🔥🔥 最高 |
| 三 | 涉案风险可控+比例原则 | 第16条(三)+第17条(八)+(十四) | 🔥🔥 高 |
| 四 | 特殊因素+政策考量 | 第7条(一)-(四)+案例库 | 🔥 中 |

**Style B 论证技法**：

1. **让步论证**：第一段定性论证后可接"即使退一步讲，即便认定……也应当……"，层层设防
2. **引附法律意见书**：如涉及无罪/定性争议，可写"具体分析详见法律意见书"，但不生成
3. **递进概括**：第二段将社会危险性概括融入从宽段，不独立分段逐项
4. **法条融入各论点**：不设独立法律依据段，法条分散在各论点中

### 3.3 量刑推算三步法（双风格共享）

> 两种风格均可使用量刑推算，但融入方式不同：

**步骤**：
1. 检索入库案例中同类事实的量刑情况
2. 确定基准刑（本省量刑指导意见）
3. 量化扣减从宽情节 → 推算最终可能刑期
4. 如推算刑期低于已羁押时长 → 触发第16条(三)应当变更

**风格融入差异**：

| 方面 | Style A | Style B |
|------|---------|---------|
| 融入位置 | 可融入"案件基本情况"或独立段 | 融入第三段"涉案风险可控"比例原则论证 |
| 论证方式 | 平实列出数据 | 与比例原则结合精炼概括 |
| 法条引用 | 第16条(三)集中引用 | 融入论证段落 |

### 3.4 预判反驳（双风格共享）

| 拒绝理由 | 反驳策略 | 嵌入位置 |
|----------|----------|----------|
| "罪行严重" | 罪重≠社会危险性高（第18条区分） | Style A 第三段 / Style B 第二段 |
| "事实未查清" | 核心证据已固定（第16条(四)） | Style A 第一段 / Style B 第一段 |
| "未赔偿谅解" | 第17条(六)-(八)为并列条件 | Style A 第二段 / Style B 第二段 |
| "保障不足" | 具体保证方案 | Style A 第四段 / Style B 第三段 |

**检查点**: 论证分点完整 + 风格路由一致 + 量刑推算步骤完整 + 预判反驳嵌入

## Phase 4: 预判反驳 [L3]

### 4.1 识别检方可能拒绝理由

| 拒绝理由 | 触发条件 | 预判逻辑 |
|----------|----------|----------|
| "罪行严重" | 涉嫌重罪/涉案金额大 | 罪重≠社会危险性高（第18条） |
| "事实未查清" | 侦查阶段/案情复杂 | 核心证据是否已固定（第16条(四)） |
| "未达成赔偿谅解" | 有被害人但未和解 | 赔偿谅解非唯一指标（第17条(六)-(八)） |
| "非羁押保障不足" | 无保证人/保证金 | 具体保证方案 |

### 4.2 逐项构建针对性反驳

对每个预判拒绝理由：
1. 引用新规法条反驳
2. 列明已有证据/措施
3. 嵌入申请书对应章节（按双风格各自位置）

**检查点**: 预判反驳完整嵌入 + 无逻辑矛盾

### 5.4 法条引用嵌入

- Style A：法条融入各段论证
- Style B：法条分散融入各论点段落，不设独立法律依据段
- 第16条（应当释放，无需悔罪前提）vs第17条（可以变更，须悔罪+无社会危险性）严格区分
- 首次引用须法规全名+条文

### 5.5 格式处理

- Markdown格式：双风格按各自模板渲染
- DOCX格式：按 docx-format-spec.md 双风格渲染规范（F-Strict）
- 降级处理：按 SOFT_DEGRADED 三档输出
- O1/O2区分：O1(.docx)禁止免责声明+禁止正文表格+禁止配套文书触发逻辑
