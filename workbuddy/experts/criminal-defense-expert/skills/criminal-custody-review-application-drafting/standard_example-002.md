# 标准示例002：侦查阶段双轨致送（Style A）

> criminal-custody-review | 标准示例 | C档（完整版）| Style A（宋瑞学标准风）| v4.1.0

## 输入

```markdown
当事人：赵某
涉嫌罪名：职务侵占罪
当前阶段：侦查（investigation）
已羁押时长：3个月
案件事实：赵某因涉嫌职务侵占罪于2026年1月被逮捕。涉案金额5万元，已全部退赔并取得公司谅解。
赵某患有严重糖尿病，近3个月连续诊疗记录显示需长期治疗。
申请理由：1.已退赔并取得谅解；2.严重疾病不适宜继续羁押；3.社会危险性已消除
建议措施：取保候审（人保+财保双保险）
侦查机关：XX市公安局XX分局
```

## 风格路由说明

本案虽涉及职务侵占（第18条(四)重大职务犯罪负面清单），但不存在定性争议/无罪可能/被拒后再申请，且用户未显式指定 Style B，因此默认路由为 **Style A**（宋瑞学标准风）。O2 策略提示中将建议提交法律意见书以突破负面清单。

## 预期输出要点

### 关键特征（侦查阶段双轨）

1. **致送机关双轨**：
   - XX市公安局XX分局（评估）
   - XX市XX区人民检察院（审查）

2. **第7条双重匹配**：
   - 第7条(一)严重疾病/生活不能自理——强制启动审查
   - 第7条(六)事实/法律变化可能判轻刑——强制启动审查

3. **第16条双重匹配**：
   - 第16条(二)事实/法律变化可能判轻刑（已退赔+谅解）
   - 第16条(四)事实查清+符合取保条件（侦查阶段部分固定）

4. **疾病论证重点**：
   - 近3个月连续诊疗记录（证据标准化达标）
   - 看守所医疗条件不足以保障治疗
   - 不适宜继续羁押（第7条(一)+第17条(九)）

5. **保证方式双保险**：
   - 人保：配偶作为保证人
   - 财保：准备保证金5万元

6. **策略提示（仅O2）**：
   - 建议提交调取证据申请书（向看守所调取在押表现+医疗记录）
   - 建议提交法律意见书（职务侵占属第18条(四)重大职务犯罪负面清单，需额外论证突破）

### 输出结构（Style A 四段式）

```
致送机关：XX市公安局XX分局（评估）+ XX市XX区人民检察院（审查）

委托声明 + 申请事项（叙述性引言段落）

事实与理由：
一、[案件基本情况——赵某涉嫌职务侵占5万元，已退赔+严重糖尿病] ← 第7条(一)(六)
二、[存在法定从宽情节——应当释放：第16条(二)(四)；可以变更：第17条(二)(六)(七)(八)(九)(十四)]
三、[无继续羁押的必要——按第81条五种情形逐项自然语言论证]
四、[替代措施足以保障诉讼——人保+财保双保险]

结语（融合请求+程序闭环）

此致 + 落款

附：法律条文 / 附件清单 / 程序闭环请求
策略提示（仅O2）：建议提交调取证据申请书+法律意见书（职务侵占负面清单突破论证）
```

### 与example-001的关键差异

| 维度 | example-001（审查起诉 Style A） | example-002（侦查阶段 Style A） |
|------|----------------------|----------------------|
| 致送机关 | 检察院单轨 | 公安+检察双轨 |
| 第7条匹配 | 仅(六) | (一)+(六)双重匹配 |
| 第16条论证 | "贵院应当决定释放"（审查起诉直接决定） | "贵院应当向公安机关提出释放建议"（向公安机关建议） |
| 疾病论证 | 无 | 核心论证+3月连续诊疗记录 |
| 保证方式 | 人保 | 人保+财保双保险 |
| 法律意见书 | 不触发 | 触发（职务侵占负面清单） |
| 程序措辞 | "贵院可直接决定释放" | "贵院应当向公安机关提出释放建议" |
