# DOCX 排版规范：criminal-custody-review

> 羁押必要性审查申请书 .docx 输出排版标准 | 版本: v4.1.0
>
> **定位**：本文件是 docx 输出的**单一排版事实源**。docx 不从 Markdown 转换而来，而是按本文档的段落级规范直接调用 python-docx API 生成。
>
> **v4.1.0 核心变更**：首部信息区从无边框表格重构为叙述性段落；双风格DOCX渲染路径（Style A四段式/Style B四论点递进）；全量消除D1-D6等内部编码标签；法条融入论证段落不设独立法律依据段。

## 3. 段落间距规则

### 3.1 核心原则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制，禁止插入仅含空白字符的空段落。

### 3.2 间距值（均为磅值 Pt）

| 元素 | 段前 | 段后 | 说明 |
|------|------|------|------|
| 标题 | 0 | 24pt | 标题后留较大间距 |
| 致送机关 | 6pt | 0 | 标题后到致送机关 |
| 申请人信息段 | 0 | 0 | 紧接致送机关 |
| 申请事项 | 6pt | 0 | 信息段后到申请事项 |
| 一级标题 | 12pt | 6pt | — |
| 二级标题 | 6pt | 3pt | — |
| 正文段落 | 0 | 0 | 28磅固定行距即为段落间隔 |
| 法条引用块 | 3pt | 3pt | 与上下文区分 |
| 证据引用块 | 3pt | 3pt | 与上下文区分 |
| "此致" | 12pt | 0 | 结语到"此致"留空 |
| 落款第一行 | 12pt | 0 | 致送机关到落款留空 |
| 落款各行间 | 0 | 0 | 落款内部紧凑 |
| 附件清单标题 | 18pt | 6pt | 签名字后到附件清单留大间距 |

## 4. 段落粒度规则

### 4.1 核心原则

**一个段落 = 一个语义单元。** 禁止将多个语义单元塞入同一段落用 `<br/>` 换行。

### 4.2 拆分规则

| 语义单元类型 | 段落数 | 示例 |
|-------------|--------|------|
| 申请人信息 | 1段 | "申请人：张三，XX律所律师，执业证号XXX。联系方式：XXX。" |
| 申请事项 | 1段 | 每项请求1段 |
| 第7条8类逐条匹配 | 1段/类 | 每类情形独立1段 |
| 第16条5类逐条匹配 | 1段/类 | 每类情形独立1段 |
| 第17条16类逐条匹配 | 1段/类 | 每类从宽理由1段 |
| 社会危险性排除项 | 1段/项 | 按第81条五种情形逐项自然语言叙述 |
| 预判反驳论证 | 1段/反驳 | 每项反驳独立1段 |
| 法条索引项 | 1段/法条 | 每条法条1段 |
| 证据列举 | 1段/项 | 每项证据1段 |

## 5. 编号规则

### 5.1 核心原则

**使用 Word 原生 List Numbering，禁止手动"1. ""2. ""3. "编号。**

### 5.2 编号应用场景

| 证据列举 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 法条索引 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |

## 8. 双风格正文渲染规范（v4.1.0 更新）

### 8.1 Style A 渲染步骤

| 步骤 | 操作 | 排版要点 |
|------|------|----------|
| R7A | 一级标题"一、[案件基本情况]"（黑体三号）+ 正文（仿宋三号16pt首行缩进2字符） | 平实叙述，含第7条8类融入 |
| R8A | 一级标题"二、[存在法定从宽情节]"+ 逐条匹配正文 | 每个从宽情节一段，第16条优先+第17条逐条 |
| R9A | 一级标题"三、无继续羁押的必要"+ 逐项自然语言段落 | "关于再犯可能性，……关于毁灭、伪造证据的风险，……"逐项叙述 |
| R10A | 一级标题"四、[替代措施足以保障诉讼]"+ 正文 | 保证方案+取保条件 |

**Style A 社会危险性排除排版**：

```
三、无继续羁押的必要                          ← 黑体三号一级标题

关于再犯可能性，[当事人]系初犯/偶犯……          ← 仿宋三号，每项1段
关于毁灭、伪造证据的风险，本案核心证据已收集固定……
关于干扰证人作证的风险，本案已取证完毕……
关于打击报复被害人的风险，[当事人]已与被害方达成和解……
关于自杀、逃跑的风险，[当事人]在本地有固定住所……
综上，[当事人]不具有《刑事诉讼法》第八十一条
规定的社会危险性。                              ← 收束段
```

### 8.2 Style B 渲染步骤

| 步骤 | 操作 | 排版要点 |
|------|------|----------|
| R7B | 一级标题"一、[定性论证]"+ 让步论证段落 | 可含二级标题"（一）（二）"+ 让步论证（"即使退一步讲，……也应当……"）作为独立段落 |
| R8B | 一级标题"二、[从宽情节]+无社会危险性"+ 概括叙述 | 社会危险性融入此段概括叙述，不独立分段 |
| R9B | 一级标题"三、[涉案风险可控]"+ 比例原则论证 | 含量刑推算+比例原则论证 |
| R10B | 一级标题"四、[特殊因素+政策考量]"+ 案例库参照段落 | 含少捕慎诉慎押+案例库参照 |

**Style B 让步论证排版**：

```
一、[定性论证标题]                              ← 黑体三号一级标题

[概括论点]。                                   ← 仿宋三号正文
（如涉及定性争议：具体分析详见法律意见书。）      ← 仿宋三号，引附说明
即使退一步讲，即便认定[当事人]构成[指控罪名]，   ← 让步论证段落
其也具有以下从宽情节，继续羁押已无必要。
```

### 8.3 双风格排版差异对照

| 排版元素 | Style A | Style B |
|----------|---------|---------|
| 事实与理由段落数 | 4个一级标题 | 4个一级标题 |
| 一级标题内容 | 案件基本情况/法定从宽/无继续羁押必要/替代措施 | 定性论证/从宽+无社会危险性/涉案风险可控/特殊因素+政策 |
| 段落内部结构 | 一级标题→直接正文（平实叙述） | 一级标题→可能含二级标题→正文（纵深递进） |
| 二级标题使用 | 基本不用 | 定性论证段/从宽段内可用"（一）（二）"分点 |
| 让步论证排版 | 无 | "即使退一步讲，……也应当……"作为独立段落 |
| 社会危险性段 | 第三段独立逐项自然叙述（"关于……"） | 融入第二段概括叙述 |
| 法律依据段 | 无独立段，法条融入各论证段落 | 无独立段，融入各论点 |
| 法条引用块 | 分散在各论证段落中 | 分散在各论点段落中 |

## 9. 特殊排版规则

### 9.1 标题

```
文书标题居中，二号方正小标宋简体加粗，独占一行。
标题格式："羁押必要性审查申请书"
```

### 9.2 致送机关

```
侦查阶段（双轨致送）：
"XX市公安局XX分局："顶格写，不加缩进。
"XX市XX区人民检察院："另起一行顶格写。

审查起诉/审判阶段（单轨致送）：
"XX市XX区人民检察院："顶格写，不加缩进。
冒号后不换行，申请人信息段紧接其后。
```

### 9.3 "此致"与致送机关

```
"此致"：首行缩进2字符
致送机关全称：另起一行，顶格
"此致"与致送机关名之间不插空行
```

### 9.4 落款签名区

```
申请人：XXX律师               （右对齐）
XXX律师事务所                  （右对齐）
二〇二六年六月十日             （右对齐，中文小写）
```

> **日期"〇"规范**：不可写作"零"或"0"，必须使用"〇"（中文小写）。

### 9.5 附件清单

```
签名后独立列出，不参与正文编号体系。
"附："：仿宋三号加粗，左对齐，无缩进，段前18pt。
附件项：仿宋三号，首行缩进2字符，Word 原生编号"1. 2. 3."。
A类证据附件 + B类法条附件 + 程序闭环请求。
```

### 9.6 O1 正式提交稿约束

- **禁止输出免责声明**：O1(.docx) 是提交给检察院/公安机关的正式文书，不得包含"免责声明"。免责声明仅限 O2(Markdown) 编辑稿保留。
- **禁止正文表格**：申请书论证正文中禁止使用任何表格。社会危险性排除必须逐项分段自然语言叙述（"关于……，[当事人]……"式自然衔接于同一段落中），不得使用表格。
- **禁止Markdown痕迹**：O1(.docx) 中不得出现 `**加粗**`、`[注]`、`---` 等 Markdown 语法残留。
- **禁止内部编码标签**：不得出现 D1/D2/V1/V2 等内部编码标签。

### 9.7 侦查阶段双轨致送排版

侦查阶段需同时致送公安机关（评估）和检察院（审查），排版策略：

```
方案一（推荐）：生成两份独立文书，致送机关分别填写
方案二：一份文书，致送机关分两行列出：
  XX市公安局XX分局
  XX市XX区人民检察院
```

## 10. 禁止事项

| # | 禁止项 | 正确做法 |
|---|--------|----------|
| F1 | 纸张非 A4（如 US Letter） | 纸张必须设置为 A4 |
| F2 | 用空行分段 | 用段前/段后间距控制段落间距 |
| F3 | 多个语义单元挤在同一段落 | 每个语义单元独立为一个段落 |
| F4 | 手动 "1. 2. 3." 编号 | 使用 Word 原生 List Numbering |
| F5 | 用 "———" 字符串模拟分隔线 | 使用 Word 段落底边框 |
| F6 | `@image`、`![xxx](xxx)` 等图片/占位符 | 申请书是纯文字文书，禁止任何图片引用 |
| F7 | 段落缩进为 0 或随机值 | 正文和各级标题统一首行缩进 2 字符（640 DXA） |
| F8 | 信息区用无边框表格 | 使用叙述性段落（v4.0.0引入，v4.1.0保留） |
| F9 | "此致"—空行—"致送机关名" | "此致"与致送机关名之间不插空行 |
| F10 | 落款签名无右对齐 | 落款区全部右对齐 |
| F11 | 证据列举混在正文段落中 | 证据独立成段，楷体小四号 |
| F12 | 结语出现不利自认 | 结语严格按请求事项总结 |
| F13 | 正文论证中使用表格 | 社会危险性排除逐项分段自然语言叙述 |
| F14 | O1(.docx) 包含"免责声明" | O1 正式提交稿删除免责声明 |
| F15 | 日期使用阿拉伯数字或"零" | 日期必须使用中文小写"二〇XX年X月X日" |
| F16 | 法条引用用简称首次出现 | 首次引用须法规全名+条文 |
| F17 | 使用"保释"等非中国法律概念 | 使用"取保候审"，禁止"保释" |
| F18 | 页码格式为"1/N" | 页码格式为"– N –"居中，四号宋体 |
| F19 | 使用D1/D2/V1/V2等内部编码标签 | 用自然法言法语描述论证内容 |

## 13. 排版规范来源

| 来源 | 适用范围 | 权威级别 | 说明 |
|------|----------|---------|------|
| GB/T 9704-2012《党政机关公文格式》 | 页边距/行距/页码 | T1 | 国家标准，律师文书参照执行 |
| 最高法《刑事诉讼文书样式》(2020版) | — | **不适用** | 仅含法院/检察院官方文书样式 |
| 最高检《刑事诉讼法律文书格式样本》(2020版) | — | **不适用** | 含检察院羁押审查文书，但不含律师意见书样式 |
| 全国律协《律师办理刑事案件规范》(2017) | 羁押必要性审查申请程序指引 | **T2** | 第59-61条规定了律师申请变更/解除强制措施的权利和程序 |
| 律师行业实务惯例 | 致送机关/落款格式/首部排版 | **T3** | 无国标但通行做法 |
| 宋瑞学律师范文 | Style A 四段式结构 | **T3** | 标准模板化风格 |
| 金翰明律师范文 | Style B 四论点递进结构 | **T3** | 精炼论证风格 |

> **诚实标注**：羁押必要性审查申请书无国家强制统一排版标准。上述规范参照 GB/T 9704-2012 页边距行距、全国律协规范(T2)程序指引、律师行业通行惯例(T3)，属行业专业惯例。
