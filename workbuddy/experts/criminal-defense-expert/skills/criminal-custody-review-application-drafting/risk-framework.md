# 风险框架：criminal-custody-review

> 羁押必要性审查申请 | 版本: v4.1.0

## 1. 风险等级

**L2（中等风险）**——涉及人身自由权利，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证+时机评估+风格路由 | L1 | 低风险——仅验证输入+评估时机+判定风格 |
| Phase 2 案件信息结构化+证据标准化 | L2 | 中风险——需准确提取关键信息+证据达标判定 |
| Phase 3 双风格论证构建 | **L3** | **高风险**——社会危险性评估涉及专业判断+法条匹配精度+风格路由一致性 |
| Phase 4 预判反驳 | **L3** | **高风险**——反驳逻辑正确性+嵌入位置准确性（双风格各自位置） |
| Phase 5 双风格模板组装 | L2 | 中风险——需格式合规+风格纯净+模板结构正确 |
| Phase 6 律师策略提示（仅O2） | L1 | 低风险——仅提示 |
| Phase 7 质量检查 | L1 | 低风险——仅检查 |
| Phase 8 输出组装+程序闭环提示 | L1 | 低风险——仅组装 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 强制律师复核标注 | 涉及死刑/无期/重大职务犯罪 | 输出增加⚠️标注 |
| RC-02 | 禁止承诺审查结果 | 用户询问"能通过吗" | 拒绝回答+说明理由 |
| RC-03 | 社会危险性排除必须完整 | 生成论证时 | 按第81条五种情形逐项自然语言回应 |
| RC-04 | 法条引用强制校验 | 引用法条时 | 仅引用mandatory+supplementary清单中的法条 |
| RC-05 | 输入不充分降级 | 输入不足以支撑论证 | SOFT_DEGRADED C→D→G |
| RC-06 | 应当释放/可以变更匹配必须标注规范性质 | 匹配第16条或第17条时 | 第16条→所有阶段均为"应当"（命令性，无需悔罪前提）；第17条→所有阶段均为"可以"（裁量性，须悔罪+无社会危险性） |
| RC-07 | 致送机关阶段差异化 | 生成致送机关时 | 侦查阶段双轨/其他阶段单轨 |
| RC-08 | 再申请限制警告 | 无新证据/新理由再次申请 | 警告新规第9条可不再审查+建议补充新证据 |
| RC-09 | 双风格纯净度控制 | 生成论证时 | Style A不出现让步论证/引附意见书；Style B不出现五段式结构/社会危险性独立分段 |
| RC-10 | 禁止内部编码标签 | 生成正文时 | 不得出现D1/D2/V1/V2等内部编码，用自然法言法语 |

## 4. 行为约束

- 不得替代律师的专业判断
- 不得对审查结果做出任何形式的承诺或暗示
- 社会危险性评估仅为辅助论证，不构成法律意见
- 输出需律师审查后方可提交
- 第16条与第17条不得混淆——第16条所有阶段均为"应当"（命令性，无需悔罪前提）；第17条所有阶段均为"可以"（裁量性，须悔罪+无社会危险性）
- 本技能只输出申请书，法律意见书仅在O2策略提示中建议另行提交
