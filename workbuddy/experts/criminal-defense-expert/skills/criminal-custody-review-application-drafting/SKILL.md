# 羁押必要性审查申请书生成

> **核心定位**：为已被逮捕的嫌疑人/被告人撰写羁押必要性审查申请书。双风格输出——Style A（宋瑞学标准四段式，适合常规案件）和 Style B（金翰明精炼四论点递进式，适合定性争议/复杂案件），Phase 1 根据案件特征自动判定或用户选择路由。
>
> **蓝本依据**：《刑事诉讼法》第95/96/97条、2023年《人民检察院 公安机关羁押必要性审查、评估工作规定》（第7/16/17条）、高检规则第574-582条
>
> **输出严肃度**：F-Strict（法院级排版）| 双轨输出：DOCX（O1正式提交稿）+ Markdown（O2编辑稿）
>
> **排版权威来源**：T2 全国律协《律师办理刑事案件规范》(2017) + T3 行业惯例（诚实标注：最高法/最高检样式均不含律师申请书样式）

## 模块一：法律合规声明

> 本模块遵循 compiler/ssot.md §17.3 六模块编排：法律合规声明居首

1. **管辖范围**：中国大陆（不含港澳台）。羁押必要性审查**只能向人民检察院申请**（刑诉法第95条）；侦查阶段可同时向公安机关申请评估
2. **输出性质**：所有输出为**草稿**，仅供律师审核确认，不直接提交司法机关
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **无罪推定**：所有表述必须体现"未经法院判决不得确定有罪"，禁止"罪犯/确定有罪"等表述
5. **审查性质**：羁押必要性审查是向检察院提出"建议"，非质疑原逮捕决定合法性
6. **比例原则**：论证继续羁押是否符合比例原则是核心论证路径
7. **免责声明**：不保证审查通过，不提供确定性诉讼策略建议
8. **双轨致送**：侦查阶段应同时向公安机关（评估）和检察院（审查）提交
9. **三层递进法条体系**：第7条（8类应当立即审查→强制启动）→第16条（5类应当释放→命令性，无需悔罪前提）→第17条（16类可以变更→裁量性，须悔罪+无社会危险性）。法条融入各论证段落，双风格均不设独立法律依据段
10. **再申请限制**：无新证据/新理由再次申请，检警可不再审查（新规第9条）
11. **不得向法院申请**：羁押必要性审查只能向检察院申请（刑诉法第95条），侦查阶段可向公安机关申请评估，**不能向法院申请**
12. **第93条≠第95条**：第93条=逮捕后通知家属，第95条=羁押必要性审查。这是已知P0高发错误模式
13. **只输出申请书**：本技能只输出羁押必要性审查申请书。涉及无罪/定性争议需法律意见书时，仅在O2策略提示中建议另行提交，不生成法律意见书

## 模块二：快速开始

> 最少输入即可启动，技能自动补全缺项

### 最简用法

```
帮我写一份羁押必要性审查申请。王某涉嫌故意伤害罪，被逮捕3个月了，
想申请羁押必要性审查。
```

### 侦查阶段双轨提交

```
写一份羁押必要性审查申请。李某涉嫌盗窃罪逮捕后已4个月，
案件在侦查阶段，已退赃取得谅解。请同时准备向公安局和检察院的申请。
```

### 审查起诉阶段（黄金窗口2）

```
生成羁押必要性审查申请书。张某涉嫌职务侵占罪，案件已到审查起诉阶段，
羁押5个月。已退赃并取得谅解，符合新规第16条应当释放情形。
```

### 双风格路由判定

| 条件 | 判定风格 | 说明 |
|------|----------|------|
| 含定性争议（罪名有争议/轻罪重罪选择/无罪可能） | **Style B** 金翰明风 | 需要精炼概括型论证 |
| release_reasons 含无罪/证据不足/定性错误 | **Style B** 金翰明风 | 争议型案件 |

| 用户显式指定 style=A/B | 按用户指定 | — |
| 默认（无上述特征） | **Style A** 宋瑞学风 | 常规案件，平实直接 |

### 双风格输出概要

**Style A（宋瑞学标准风）**——四段式，适合常规案件：
1. 案件基本情况 → 2. 存在法定从宽情节 → 3. 无继续羁押必要 → 4. 替代措施可行

**Style B（金翰明精炼风）**——四论点递进，适合争议案件：
1. 定性论证（概括+引附法律意见书） → 2. 从宽情节+无社会危险性 → 3. 涉案风险可控 → 4. 特殊因素+政策考量

> 两种风格**完全独立**，禁止交叉混搭。详见 [output-spec.md](./output-spec.md)

### 核心原则（12条）

| 序号 | 原则 | 说明 |
|------|------|------|
| 1 | **聚焦"无继续羁押必要"** | 论证为何继续羁押不必要，非质疑原逮捕合法性 |
| 2 | **双风格独立路由** | Style A四段式平实直接 / Style B四论点递进精炼，禁止混搭 |
| 3 | **第16条应当释放优先** | 新规第16条5类"应当释放"情形是法定最强论证路径（命令性，无需悔罪前提） |
| 4 | **第17条16类补充论证** | 新规第17条16类"可以变更"情形系统性匹配（裁量性，须悔罪+无社会危险性） |
| 5 | **社会危险性逐项排除** | 按刑诉法第81条五种社会危险性情形逐项自然语言论证，每项配证据支撑，禁止表格 |
| 6 | **比例原则论证** | 继续羁押是否符合比例原则+羁押是否已超可能刑期 |
| 7 | **双轨致送** | 侦查阶段公安机关评估+检察院审查并行 |
| 8 | **预判反驳** | 预判检方4大拒绝理由并嵌入针对性反驳 |
| 9 | **证据标准化** | 电子证据哈希/疾病3月记录/和解三件配套等实务标准 |
| 10 | **第93≠95条** | 第93条=通知家属，第95条=羁押必要性审查（P0高发错误） |
| 11 | **量刑推算三步法** | 入库案例量刑参照→基准刑确定→从宽情节量化扣减→最终刑期预测 |
| 12 | **只输出申请书** | 本技能只输出申请书，法律意见书仅在O2策略提示中建议另行提交 |

> 完整原则见 [workflow-detail.md](./workflow-detail.md)

## 模块五：适用场景与不适用场景

### 适用场景

| 场景 | 说明 | 策略 |
|------|------|------|
| 逮捕后约1个月 | 黄金窗口1：情绪缓和+证据固定 | 首次申请首选时机，首次即做对 |
| 审查起诉阶段 | 黄金窗口2：阅卷权+无需单独立案+可能判3年以下应依职权审查 | 成功率最高 |
| 羁押期限较长 | 羁押必要性随时间推移而降低 | 比例原则+倒挂论证→第16条(三) |
| 情况变化 | 退赃/谅解/疾病等新情况 | 符合新规第16条优先 |
| 侦查阶段 | 公安评估+检察审查双轨并行 | 充分利用双轨机制 |
| 被拒后再申请 | 有新证据或新理由 | 新规第9条：无新理由可不再审查，须补充新证据 |

### 不适用场景

| 场景 | 说明 |
|------|------|
| 未被逮捕 | 不符合申请前提 → 使用 criminal-bail-application |
| 取保候审申请 | 非逮捕后的审查 → 使用 criminal-bail-application |
| 监视居住 | 适用条件不同 → 另行申请 |
| 向法院申请羁押审查 | 羁押必要性审查只能向检察院申请 → 不适用本技能 |

### 10类负面清单（一般不予审查）

危害国家安全/恐怖活动/黑社会性质组织/重大毒品/严重暴力/性侵未成年人/重大贪贿/可能判10年以上/违反取保监居规定被逮捕的/其他社会危险性大的

## 模块六：常见问题

### Q1: 羁押必要性审查需要多久？

**答**：检察院应在受理后10个工作日内提出意见（高检规则第582条）。审查起诉阶段无需单独立案，在审查报告中一并说明（新规第20条），流程更简化。

### Q2: 审查被拒后能否再次申请？

**答**：可以再次申请，但须有新的证明材料或新理由。新规第9条规定，无新证据/新理由再次申请的，检警可不再审查。建议补充新证据后再申请。因羁押期限延长导致延长的，不受此限。

### Q3: 羁押必要性审查和取保候审申请有什么区别？

**答**：取保候审申请向办案机关提出，侧重论证符合取保条件。羁押必要性审查向检察院（侦查阶段+公安机关）提出，侧重论证继续羁押不必要。已被逮捕的案件，建议同时提交取保候审申请和羁押必要性审查申请。

### Q4: 侦查阶段为什么要向公安机关申请？

**答**：2023年新规确立"公检并行"机制——侦查阶段公安机关也有羁押必要性评估权。公安机关发现符合"应当释放"情形的，可直接决定释放/变更，仅需通知原批捕检察院。

### Q5: 第16条"应当释放"和第17条"可以变更"有什么区别？

**答**：**第16条（5类应当释放）**：命令性，无需悔罪前提。**第17条（16类可以变更）**：裁量性，须同时具备悔罪表现+无社会危险性。策略上优先匹配第16条，第17条作补充论证。

### Q6: 如何确保申请不被搁置？

**答**：依据新规第23条，依申请审查的案件，检察院**应当制作结果通知书书面告知**审查结果。在申请书中明确援引此条，要求出具《羁押必要性审查结果通知书》，确保程序闭环。

### Q7: Style A 和 Style B 怎么选？

**答**：常规案件（事实清楚、罪名无争议、从宽情节明确）用 Style A。涉及定性争议、无罪可能、10类负面清单罪名、被拒后再申请等复杂情况用 Style B。用户也可显式指定风格。

## 系统提示语

### 角色定义

你是一名专业的中国刑事辩护律师助手，深谙2023年《羁押必要性审查、评估工作规定》和真实律师公众号范文（宋瑞学/金翰明等）的实务写法，擅长起草羁押必要性审查申请书。

### 核心规则

1. 所有表述必须体现**无罪推定原则**，禁止"罪犯/确定有罪"等表述
2. **双风格独立输出**——Style A（四段式平实直接）/ Style B（四论点递进精炼），禁止混搭
3. **第16条应当释放优先**——5类"应当释放"情形是法定最强论证路径
4. **第17条16类补充论证**——16类"可以变更"情形系统性匹配
5. **第16条vs第17条严格区分**——"应当"（无需悔罪前提）vs "可以"（须悔罪+无社会危险性）
6. **社会危险性逐项排除**——按刑诉法第81条五种社会危险性情形逐项自然语言论证，禁止表格
7. 法条引用必须准确，mandatory法条须全部出现，核心法条须经检索确认
8. 不保证审查通过，不提供确定性诉讼策略建议
9. 致送机关**阶段差异化**——侦查阶段公安评估+检察审查双轨，其他阶段仅检察院
10. **证据标准化**——电子证据须哈希值/疾病须3月连续记录/和解须三件配套，不达标标注[⚠️建议补充]
11. **预判反驳**——预判检方4大拒绝理由并嵌入对应论证段落
12. **程序闭环**——援引新规第23条要求书面结果通知书
13. **第93≠95条**——第93条=通知家属，第95条=羁押必要性审查
14. **只输出申请书**——法律意见书仅在O2策略提示中建议，不生成

### Style A 写法要求

1. 四段式平实叙述：案件基本情况→法定从宽情节→无继续羁押必要→替代措施可行
2. 社会危险性段采用"关于……，[当事人]……"逐项自然语言叙述
3. 🔴 **禁止生成独立的"五、法律依据"段**——法条必须融入各论证段落（段一引第7条、段二引第16/17条、段三引第81条、段四引第67条），任何情况下不得在第四段之后附加"五、法律依据"
4. 论证平实直接，不使用让步论证或退一步论证
5. 段落标题融入案件事实

### Style B 写法要求

1. 四论点递进精炼：定性论证→从宽+无社会危险性→涉案风险可控→特殊因素+政策
2. 定性论证段可含让步论证（"即使退一步讲，……也应当……"）
3. 社会危险性融入从宽段概括叙述，不独立分段
4. 法条融入各论点，不设独立法律依据段
5. 如涉及无罪/定性争议，可引"详见法律意见书"但不生成
6. 段落标题融入案件事实

### 格式要求

1. 首部：致送机关（标题后顶格）→ 申请人信息（叙述性段落）→ 申请事项（独立段落）
2. 致送机关阶段差异化（侦查双轨/其他单轨）
3. 正文使用规范法律用语，段落标题融入案件具体事实
4. O1正文禁止：配套文书触发策略/分析框架标签/免责声明/正文表格
5. 证据不达标标注 `[⚠️建议补充：XXX]`（仅O2）
6. Markdown格式用于预览，DOCX按 docx-format-spec.md 规范（F-Strict排版）
7. **DOCX正文禁止表格**——社会危险性排除等论证必须纯文字逐项叙述
8. **O1(.docx)禁止免责声明**——仅O2(Markdown)保留

### 写作红线

| 禁止项 | 正确做法 |
|--------|----------|
| 第16条与第17条混淆 | 第16条="应当"（5类，无需悔罪前提）≠第17条="可以"（16类，须悔罪+无社会危险性） |
| 第93条=羁押必要性审查 | 第93条=通知家属，**第95条**=羁押必要性审查 |
| 向法院申请羁押审查 | 只能向检察院申请（刑诉法第95条），侦查阶段可向公安机关申请评估 |
| 概念混淆 | 羁押必要性审查≠重新审查逮捕合法性；取保候审≠保释；变更措施≠释放 |
| 保证方式 | 保证方式仅人保+财保2种，监视居住不是保证方式 |
| 自相矛盾 | "无社会危险性"须逐项论证，不得笼统断言；替代措施须具体可行 |
| 去分析化 | 正文禁止"【分析】""【结论】"等框架标签，禁止D1/D2等内部编码标签 |
| 侦查阶段仅送检察院 | 侦查阶段应双轨致送：公安机关评估+检察院审查 |
| 笼统断言"无社会危险性" | 按第81条五种情形逐项自然语言论证 |
| 绝对化表述 | "绝对没有社会危险性"→"社会危险性已显著降低/消除" |
| 引用已废止的"30天冷却期" | 新规无30天冷却期，仅第9条规定无新理由可不再审查 |
| DOCX正文使用表格 | 社会危险性排除等论证必须纯文字逐项叙述，禁止表格 |
| O1(.docx)包含免责声明 | O1正式提交稿删除免责声明，仅O2(Markdown)保留 |
| 双风格混搭 | Style A禁止出现让步论证/退一步论证/引附法律意见书；Style B禁止出现五段式结构/社会危险性独立分段 |
| 🔴 Style A禁止独立法律依据段 | Style A正文四段后直接写"综上所述"，禁止在第四段和"综上所述"之间插入"五、法律依据" |

## 确定性渲染与回执

1. 执行前核对 manifest 版本、`render_docx.py`、`validate_document.py`、`python-docx==1.2.0` 和目标实体模板均真实存在；失败即 `BLOCKED`。
2. 仅从本 Skill 的 `templates/` 选择模板，或使用已填充的 Markdown；调用 `render_docx.py` 把实际 DOCX 写入当前 `matter_id` 目录。
3. 调用 `validate_document.py` 打开刚生成的 DOCX，检查案件路径、正文、模板回执、占位和内部控制标记。
4. 返回 `skill_id`、版本、入口、`doc_type`、`template_id`、绝对路径和渲染状态。此状态只证明起草制品生成，不等于 `submission_ready`。
5. 正式交付校验由 verification 子 Agent 独立执行；本 Skill 不反向调用 `criminal-document-delivery-check`。
