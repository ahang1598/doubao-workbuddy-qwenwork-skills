# 输入规格：criminal-custody-review

> 羁押必要性审查申请 | 版本: v4.1.0 | 更新: 2026-06-10

---

## 1. 输入模型

### 1.1 宽容摄取原则

本技能采用宽容摄取模型，接受以下6种输入形态：

| 形态 | 描述 | 示例 |
|------|------|------|
| I1 结构化 | 所有字段按schema提供 | JSON/表格/清单 |
| I2 自然语言 | 口头描述案件情况 | "我当事人张某因涉嫌诈骗被逮捕已6个月……" |
| I3 混合式 | 部分结构化+部分自然语言 | 罪名+阶段用结构化，案情用自然语言 |
| I4 渐进式 | 分多轮逐步提供信息 | 先提供基本信息，再补充证据 |
| I5 模板填充 | 基于模板填写 | 使用预设模板填写 |
| I6 最小化 | 仅提供核心必填字段 | 仅姓名+罪名+阶段 |

### 1.2 交互补全

当输入信息不足时，可交互补全，**最多3轮**：

| 轮次 | 触发条件 | 询问内容 |
|------|----------|----------|
| R1 | 缺少必填字段 | 逐项询问缺失的必填字段 |
| R2 | 论证关键信息缺失 | 询问：羁押理由/社会危险性情况/和解赔偿状态 |
| R3 | 证据/替代措施信息缺失 | 询问：已有证据材料/建议变更的强制措施/保证方式 |

3轮后仍不足 → 进入 SOFT_DEGRADED 降级模式

## 2. 字段定义

### 2.1 必填字段（4个）

| # | 字段名 | 类型 | 说明 | 示例 |
|---|--------|------|------|------|
| F1 | suspect_name | string | 犯罪嫌疑人/被告人姓名 | "张某" |
| F2 | alleged_crime | string | 涉嫌罪名（需与刑法罪名一致） | "诈骗罪" |
| F3 | current_stage | enum | 当前诉讼阶段 | investigation / prosecution / trial |
| F4 | case_facts | text | 案件基本事实（自然语言描述） | "张某因涉嫌诈骗罪于2025年3月被逮捕……" |

### 2.2 推荐字段（7个，影响论证质量）

| # | 字段名 | 类型 | 说明 | 默认值 |
|---|--------|------|------|--------|
| R1 | detention_duration | string | 已羁押时长 | 需用户确认 |
| R2 | release_reasons | array[string] | 申请审查的理由 | 从case_facts中推断 |
| R3 | proposed_measure | enum | 建议变更的强制措施 | bail（取保候审） |
| R4 | detention_facility | string | 羁押场所 | 需用户确认 |
| R5 | reconciliation_status | enum | 和解/谅解/赔偿状态 | none / partial / completed |
| R6 | prior_rejection | string | 前次被拒理由（再申请时必填） | 无（首次申请） |
| R7 | evidence_items | array[object] | 已有证据材料清单 | 无 |

### 2.3 可选字段（6个，增强论证力度）

| # | 字段名 | 类型 | 说明 | 默认值 |
|---|--------|------|------|--------|
| O1 | suspect_background | text | 当事人背景信息 | 无 |
| O2 | health_condition | text | 健康状况（需近3月连续诊疗记录） | 无 |
| O3 | detention_performance | text | 在押期间表现 | 无 |
| O4 | guarantor_info | text | 保证人信息 | 无 |
| O5 | supporting_evidence | text | 其他支持性证据材料 | 无 |
| O6 | output_style | enum | 输出风格（A/B），不指定则自动判定 | auto |

**output_style 枚举值**：

| 值 | 说明 | 判定逻辑 |
|----|------|----------|
| A | Style A（宋瑞学标准风） | 四段式平实直接，适合常规案件 |
| B | Style B（金翰明精炼风） | 四论点递进精炼，适合争议案件 |
| auto | 自动判定（默认） | 详见 SKILL.md 双风格路由判定表 |

## 3. 阶段差异化字段

### 3.1 侦查阶段特有字段

| 字段 | 说明 | 重要性 |
|------|------|--------|
| investigating_organ | 侦查机关名称（致送公安机关用） | 高——双轨致送必填 |
| arrest_date | 逮捕日期（计算已羁押时长用） | 高——比例原则论证+刑期倒挂分析 |

### 3.2 审查起诉阶段特有字段

| 字段 | 说明 | 重要性 |
|------|------|--------|
| case_number | 案号 | 推荐——页眉显示 |
| prosecution_organ | 审查起诉检察院名称 | 高——致送机关 |

### 3.3 审判阶段特有字段

| 字段 | 说明 | 重要性 |
|------|------|--------|
| court_name | 审理法院名称 | 推荐 |
| trial_stage | 审级（一审/二审） | 推荐 |

## 4. 证据标准化要求

> 依据顶级律师团队实务经验，不同证据类型有不同提交标准

| 证据类型 | 实务标准 | 不合格风险 |
|----------|----------|-----------|
| 电子证据 | 原始载体+哈希值同步提交 | 仅提交打印件→证明力不足 |
| 疾病证明 | 近3个月连续诊疗记录 | 单次诊断→被认定证据不足 |
| 固定住所证明 | 房产证/租房合同+社区证明 | 仅口头说明→无法采信 |
| 稳定职业证明 | 劳动合同+社保缴纳记录 | 仅口头说明→无法采信 |
| 和解谅解材料 | 和解协议+收款收据+谅解书三件配套 | 仅谅解书→对方可能反悔 |
| 在押表现材料 | 看守所出具的羁押期间表现材料 | 无→新规要求可调取 |
| 退赃凭证 | 银行转账记录/公安机关收据 | 仅口头说明→无法采信 |

**技能行为**：在生成附件清单时，对每类证据标注实务标准要求；若用户提供的证据不达标，在输出中标注 `[⚠️ 建议补充：XXX]`。

## 5. 配套文书触发条件

### 5.1 调取证据申请书

| 触发条件 | 说明 |
|----------|------|
| current_stage = prosecution | 审查起诉阶段自动触发 |
| 存在需要公诉部门调取的证据 | 如在押表现材料、医疗记录等 |

### 5.2 法律意见书

| 触发条件 | 说明 |
|----------|------|
| 案件涉及10类负面清单罪名 | 需更系统法律论证 |
| prior_rejection 非空 | 前次被拒后再次申请 |
| 用户明确要求 | 用户主动触发 |

## 6. 输入验证规则

### 6.1 硬拒绝条件（hard_reject）

| # | 条件 | 原因 | 处理 |
|---|------|------|------|
| HR-01 | 当事人未被逮捕 | 羁押必要性审查仅适用于已被逮捕的在押人员 | 提示用户使用 criminal-bail-application |
| HR-02 | 要求预测审查结果 | 违反职业伦理 | 拒绝并说明理由 |
| HR-03 | 要求生成检察院内部文书 | 非律师文书范围 | 拒绝并说明理由 |
| HR-04 | 无新证据/新理由再次申请 | 新规第9条：无新证明材料或新理由再次申请，检警可不再审查 | ⚠️警告再申请限制+建议补充新证据/新理由；如用户坚持则继续生成并标注再申请风险 |

### 6.2 软降级条件（soft_degraded）

| # | 条件 | 降级方式 | 降级后输出 |
|---|------|----------|-----------|
| SD-01 | 仅提供姓名+罪名 | G档（骨架版） | 仅含法定格式+基本信息 |
| SD-02 | 无法判断社会危险性 | D档（框架版） | 标注"需补充社会危险性评估" |
| SD-03 | 证据材料不达标 | C档（附标注） | 正常输出+证据标注[⚠️建议补充] |

## 7. 时机评估

### 7.1 黄金窗口

| 窗口 | 时间 | 原因 | 策略 |
|------|------|------|------|
| 黄金窗口1 | 逮捕后约1个月 | 逮捕时紧张情绪缓和，证据部分固定，检察官对案件有更全面了解 | 首次申请首选时机 |
| 黄金窗口2 | 审查起诉阶段 | 阅卷权激活，无需单独立案（新规第20条），检察官不增加程序负担 | 成功率最高 |

### 7.2 再申请限制

- **再申请限制**：无新证据/新理由再次申请，检警可不再审查（新规第9条）
- **例外**：因羁押期限延长（延长侦查羁押期限/重新计算期限/退回补充侦查）导致的变更申请不受此限
- **实务建议**：首次申请即做对，充分准备后再提交。逮捕后约1个月为黄金窗口1

## 8. 输入示例

### 标准输入

```markdown
当事人：李某
涉嫌罪名：盗窃罪
当前阶段：审查起诉
已羁押时长：4个月
羁押场所：XX市看守所
案件事实：李某因涉嫌盗窃罪于2025年1月被逮捕。涉案金额3000元，已全部退赃并取得被害人谅解。
申请理由：
1. 涉案金额较小（符合第17条(十四)：可能被判处一年以下有期徒刑）
2. 已退赃并获得谅解（符合第17条(七)+(八)）
3. 社会危险性已消除（按第81条五种情形逐项排除）
4. 继续羁押将超过可能判处的刑期（符合新规第17条第3项）
建议措施：取保候审
已有证据：
1. 退赃凭证（银行转账记录）
2. 被害人谅解书
3. 房产证复印件
4. 劳动合同+社保记录
```

### 最小化输入

```markdown
王某，故意伤害罪，审查起诉阶段，被逮捕3个月了，想申请羁押必要性审查
```

### 侦查阶段双轨输入

```markdown
赵某，诈骗罪，侦查阶段，被逮捕2个月了。
侦查机关：XX市公安局XX分局
想同时向公安局和检察院申请。
已退赃，有谅解书。
```
