# 顶级方法论详解：criminal-custody-review

> 羁押必要性审查申请 | 版本: v4.1.0 | 更新: 2026-06-10

## 1. 核心方法论：三轴九步法

### 轴一：法律武器轴（发现→匹配→嵌入）

**核心逻辑**：2023年新规构建了三层递进的法律武器体系，顶级律师团队的关键能力是精准识别并层层部署。

#### 步骤1：发现武器

| 条文 | 武器属性 | 规范性质 | 适用前提 | 论证目标 |
|------|----------|----------|----------|----------|
| 第7条（8类） | 强制启动武器 | 命令性："应当立即审查" | 无额外前提 | 审查机关必须启动审查 |
| 第16条（5类） | 尚方宝剑 | 命令性："应当释放/变更" | 无悔罪前提 | 必须释放/变更 |
| 第17条（16类） | 补充武器 | 裁量性："可以变更" | 悔罪+无社会危险性 | 增强说服力 |

#### 步骤2：匹配事实

匹配优先级：第16条 > 第17条 > 证据/比例/替代

```
案件事实 → 第7条8类扫描（启动审查）→ 第16条5类扫描（应当释放）→ 第17条16类扫描（可以变更）
```

**匹配技巧**：
- 第16条(一)-(三)无需悔罪前提，是"客观倒挂"型论证——用数据说话
- 第17条(六)-(八)认罪认罚/和解/赔偿是"主观修复"型论证——用行为证明
- 第17条(九)-(十三)特殊主体是"人道主义"型论证——用不适宜性证明

#### 步骤3：嵌入论证

将匹配结果嵌入申请书正文论证段落：

| 理由分点位置 | 匹配内容 | 论证策略 |
|----------|---------|----------|
| Style A 第一段/Style B 第一段 | 第7条8类（启动武器） | "本案属于应当立即审查的情形" |
| Style A 第二段/Style B 第二段 | 第16条5类（应当释放） | "本案符合应当释放情形" |
| Style A 第二段/Style B 第二段 | 第17条16类（可以变更） | "此外，本案还符合以下从宽情形" |
| Style A 第三段/Style B 第二段 | 社会危险性逐项排除 | "不存在第81条规定的社会危险性" |

### 轴二：攻防一体轴（预判→反驳→加固）

#### 步骤4：预判拒绝

| 拒绝理由 | 检方逻辑 | 常见场景 |
|----------|---------|---------|
| "罪行严重" | 涉嫌重罪→社会危险性高 | 暴力犯罪/数额巨大 |
| "事实未查清" | 证据尚未固定→可能妨碍诉讼 | 侦查阶段/多人作案 |
| "未赔偿谅解" | 未与被害方和解→矛盾未化解 | 有被害人的案件 |
| "保障不足" | 无保证人/保证金→可能逃跑 | 外地人/无固定住所 |

#### 步骤5：针对性反驳

**"罪行严重"反驳**：
- 新规第18条区分犯罪类型与社会危险性——涉嫌重罪≠社会危险性高
- 引用第17条(六)认罪认罚/第17条(二)初犯等从宽情节
- 按第81条五种社会危险性情形逐项自然语言排除

**"事实未查清"反驳**：
- 如核心证据已固定→援引第16条(四)"事实查清+符合取保"
- 如确未查清→论证不固定的部分不影响社会危险性判断

**"未赔偿谅解"反驳**：
- 第17条(六)-(八)为并列条件，非唯一条件
- 部分履行/提供担保也符合第17条(八)
- 第16条(一)-(三)无需赔偿谅解前提

**"保障不足"反驳**：
- 提供具体保证方案（人保/财保/双保险）
- 引用社会调查报告证明帮教条件

#### 步骤6：证据加固

| 论证环节 | 证据标准 | 不达标处理 |
|----------|---------|-----------|
| 退赃/赔偿 | 银行转账/公安机关收据 | 标注[⚠️建议补充：银行转账凭证] |
| 谅解 | 和解协议+收款收据+谅解书三件配套 | 标注[⚠️建议补充：和解协议或收款收据] |
| 固定住所 | 房产证/租房合同+社区证明 | 标注[⚠️建议补充：房产证或租房合同] |
| 稳定职业 | 劳动合同+社保记录 | 标注[⚠️建议补充：劳动合同或社保记录] |
| 疾病 | 近3月连续诊疗记录 | 标注[⚠️建议补充：近3月连续诊疗记录] |

### 轴三：程序闭环轴（启动→决定→告知→再申请）

#### 步骤7：强制启动

援引第7条"应当立即审查"——审查机关无裁量空间。

> "根据新规第7条第(X)项，本案属于应当立即开展羁押必要性审查的情形，恳请贵院依法启动审查程序。"

#### 步骤8：强制决定

- 符合第16条 → 检察院"应当"提出释放建议/决定释放
- 关键区分：第16条无需悔罪前提，第17条须悔罪+无社会危险性

> "根据新规第16条第(X)项，本案符合应当释放/变更的情形，请贵院依法提出释放建议/决定释放。"

#### 步骤9：强制告知

- 新规第23条：检察院应当制作结果通知书书面告知
- 新规第22条：公安/法院收到建议书后10日内须回复

> "依据新规第23条，恳请贵院将审查结果书面告知申请人，出具《羁押必要性审查结果通知书》。"

## 2. 量刑推算三步法

> v4.0.0 引入，v4.1.0 保留。源自王涛律师公众号范文的实操推算方法。

### 2.1 三步法步骤

**第一步：入库案例量刑参照**

- 检索人民法院案例库中同类事实（罪名+金额+情节）的量刑情况
- 确定同类案件的量刑区间

**第二步：基准刑确定**

- 依据本省高级人民法院量刑指导意见
- 确定本案基准刑期

**第三步：从宽情节量化扣减**

- 逐一列明从宽情节及其对应的刑期扣减比例
- 自首(-20%~-30%)、从犯(-20%~-50%)、退赃退赔(-30%以下)、认罪认罚(-10%~-20%)、初犯(-10%以下)
- 推算最终可能刑期

### 2.2 量刑推算的论证价值

| 推算结果 | 法条触发 | 论证路径 |
|----------|----------|----------|
| 推算刑期 < 已羁押时长 | 第16条(三)羁押将超刑期 | 应当释放/变更（命令性） |
| 推算刑期可能为缓刑 | 第17条(十五)可能宣告缓刑 | 可以变更（裁量性） |
| 推算刑期可能判1年以下 | 第17条(十四)可能判1年以下 | 可以变更（裁量性） |

### 2.3 双风格融入差异

| 方面 | Style A | Style B |
|------|---------|---------|
| 融入位置 | 可融入"案件基本情况"段或单独段 | 融入"涉案风险可控"段的比例原则论证 |
| 论证方式 | 平实列出数据 | 与比例原则结合精炼概括 |
| 法条引用 | 融入各论证段落 | 融入论证段落 |

|------|------|----------|
| 第19条 | 各级人民法院审理案件时应当查询案例库 | 检索同类案例是审查机关的义务 |
| 第20条 | 类案参照规则 | 入库案例对同类案件有参照效力 |

## 4. 双风格方法论

### 4.1 Style A 方法论（宋瑞学标准风）

**写作特征**：
- 四段式平实叙述
- 社会危险性独立分段逐项排除（"关于……，[当事人]……"自然语言叙述）
- 法条融入各论证段落，不设独立法律依据段
- 不使用让步论证、退一步论证、引附法律意见书
- 论证平实直接，证据+法条+结论

**适用案件**：事实清楚、罪名无争议、从宽情节明确、常规羁押审查

**社会危险性排除技法**：
```
关于再犯可能性，[当事人]系初犯/偶犯……
关于毁灭、伪造证据的风险，本案核心证据已收集固定……
关于干扰证人作证的风险，本案已取证完毕……
关于打击报复被害人的风险，[当事人]已与被害方达成和解……
关于自杀、逃跑的风险，[当事人]在本地有固定住所和稳定职业……
综上，[当事人]不具有《刑事诉讼法》第八十一条规定的社会危险性。
```

### 4.2 Style B 方法论（金翰明精炼风）

**写作特征**：
- 四论点递进精炼
- 社会危险性融入从宽段概括叙述
- 法条融入各论点，不设独立法律依据段
- 使用让步论证（"即使退一步讲，……也应当……"）
- 可引"详见法律意见书"但不生成
- 从最强论点到次强论点递进设防

**适用案件**：定性争议、无罪可能、10类负面清单、被拒后再申请

**让步论证技法**：
```
[概括定性论点]。[如有定性争议]（具体分析详见法律意见书）。
即使退一步讲，即便认定[当事人]构成[指控罪名]，
其也具有以下从宽情节，继续羁押已无必要。
```

## 5. 隐性知识（Tacit Knowledge）

> 以下内容来自顶级刑事律师团队的实务经验，非法律条文直接规定

### 5.1 多渠道触发策略

| 渠道 | 法条依据 | 操作方式 |
|------|----------|---------|
| 律师申请 | 第8条 | 直接向检察院提交申请书 |
| 看守所建议 | 第11条 | 协调看守所出具书面建议→检察院应当立即审查 |
| 依职权审查 | 第6条 | 审查起诉阶段可能判3年以下→检察院应当依职权审查 |
| 听证程序 | 第15条 | 主动申请听证→当面陈述增强说服力 |

### 5.2 时序策略

| 阶段 | 最佳时机 | 策略 |
|------|----------|------|
| 逮捕后约1个月 | 黄金窗口1 | 情绪缓和+证据部分固定 |
| 审查起诉阶段 | 黄金窗口2 | 无需单独立案+阅卷权+可能判3年以下应依职权审查 |
| 羁押即将超刑期 | 倒挂窗口 | 第16条(三)客观倒挂数据 |
| 新情况出现 | 变化窗口 | 退赃/谅解/疾病等新证据 |

### 5.3 第16条 vs 第17条的选择策略

| 场景 | 优先选择 | 原因 |
|------|----------|------|
| 证据明显不足 | 第16条(一) | 无需悔罪前提，最强论证 |
| 可能判轻刑/免罚 | 第16条(二) | 无需悔罪前提 |
| 羁押已超刑期 | 第16条(三) | 客观数据，不可反驳 |
| 事实查清+符合取保 | 第16条(四) | 无需悔罪前提 |
| 认罪认罚 | 第17条(六) | 需悔罪+无社会危险性 |
| 和解/谅解 | 第17条(七) | 需悔罪+无社会危险性 |
| 初犯偶犯 | 第17条(二) | 需悔罪+无社会危险性 |
| 严重疾病 | 第17条(九)+第7条(一) | 双重武器 |

### 5.4 羁押必要性审查只能向检察院申请

> ⚠️ **关键隐性知识**：羁押必要性审查**只能向检察院申请**（刑诉法第95条），**不能向法院申请**。这与取保候审申请（可向办案机关申请）不同。侦查阶段可同时向公安机关申请"评估"（非"审查"），但正式的"羁押必要性审查"仍由检察院进行。

### 5.5 新规(2023) vs 高检规则(2019)冲突处理

> 新规效力高于高检规则中不一致的条款。具体冲突点：
> - 高检规则第579条4类"应当释放"→新规第16条扩展为5类
> - 高检规则第580条"可以变更"若干情形→新规第17条扩展为16类
> - 高检规则第582条10个工作日审查期限→仍有效
> - 高检规则第578条初审+立案程序→新规简化了审查启动程序

### 5.6 DOCX输出中社会危险性排除禁止表格

> F-Strict文书正文禁止使用表格。社会危险性排除必须逐项分段自然语言叙述（"关于……，[当事人]……"式自然衔接），不得使用Markdown表格。这是中国司法文书行文惯例。

## 6. 负面清单突破策略

> 即便案件属于第18条10类负面清单，仍有突破路径

### 6.1 第18条第2款突破口

> "犯罪嫌疑人、被告人具有前款规定情形之一，但因患有严重疾病或者具有其他不适宜继续羁押的特殊情形，不予羁押不致发生社会危险性的，可以依法变更强制措施为监视居住、取保候审。"

**突破策略**：
1. 严重疾病 → 第7条(一)+第18条第2款双重突破
2. 不适宜继续羁押的特殊情形 → 逐一论证
3. 不予羁押不致发生社会危险性 → 逐项自然语言排除+社会调查报告

### 6.2 社会危险性类别（第18条(七)(八)(九)）的证据排除

不同于犯罪类型类别（第18条(一)-(六)），社会危险性类别可通过证据论证排除：
- (七)可能毁灭/伪造证据/干扰证人/串供 → 核心证据已固定+已取证
- (八)可能打击报复 → 已和解/谅解
- (九)企图自杀/逃跑 → 固定住所+在押表现良好+保证人

## 7. 审查起诉阶段特殊策略

### 7.1 依职权审查触发

新规第6条：审查起诉阶段可能判3年以下 → 检察院应依职权审查

### 7.2 简化审查程序

新规第20条：审查起诉阶段无需单独立案，在审查报告中一并说明

### 7.3 直接决定权

新规第16条：审查起诉阶段检察院可直接决定释放/变更（无需向其他机关建议）

## 8. 常见错误（P0×5 / P1×4）

### P0 错误（阻断级）

| # | 错误模式 | 正确处理 | 来源 |
|---|----------|----------|------|
| P0-1 | 第93条=羁押必要性审查 | 第93条=通知家属，**第95条**=羁押必要性审查 | known-pitfalls §1.2 |
| P0-2 | 第16条与第17条混淆 | 第16条="应当"（5类，无需悔罪前提）≠第17条="可以"（16类，须悔罪+无社会危险性） | MW6 |
| P0-3 | 向法院申请羁押必要性审查 | 只能向检察院申请（刑诉法第95条） | MW10 |
| P0-4 | 监视居住=取保候审的保证方式 | 监视居住是独立强制措施，保证方式只有人保+财保2种 | known-pitfalls §2.1 |
| P0-5 | 引用已废止的"30天冷却期" | 新规无此规定，仅第9条规定无新理由可不再审查 | MW7 |
