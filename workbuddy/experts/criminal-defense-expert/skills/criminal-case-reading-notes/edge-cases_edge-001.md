# 边缘示例001：侦查阶段阅卷受限

> criminal-case-reading-notes | 边缘示例 | v2.0.0

## 输入

```markdown
案件还在侦查阶段，我是辩护律师，想看看卷宗，请帮我做阅卷笔录。
嫌疑人张三，涉嫌故意伤害罪，刚被逮捕不久。
```

## 边界问题

侦查阶段辩护律师的阅卷权受到严格限制。刑诉法第40条规定，辩护律师自检察院对案件审查起诉之日起，可以查阅、摘抄、复制本案的案卷材料。侦查阶段依据第38条，律师仅可向侦查机关了解犯罪嫌疑人涉嫌的罪名和案件有关情况，无权查阅完整卷宗。此时阅卷笔录技能的输入极为有限，无法进行实质性的证据分析和事实梳理。

## 预期输出特征

- SOFT_DEGRADED D档（框架版）：仅生成程序性信息模块和事实摘要占位
- 明确标注"侦查阶段阅卷受限"的法律依据
- 列出侦查阶段可获取的信息范围
- 提供审查起诉阶段的准备建议
- 不得在信息不足的情况下进行证据分析

## 预期输出摘要

```markdown
# 阅卷笔录

> ⚠️ **侦查阶段阅卷受限提示**
>
> 本案尚处于侦查阶段，依据《刑事诉讼法》第40条，辩护律师在审查起诉之前
> 无权查阅完整卷宗材料。以下笔录仅基于可获取的有限信息，待案件进入审查
> 起诉阶段后再行补充完善。

## 一、案件基本信息

| 项目 | 内容 |
|------|------|
| 嫌疑人 | 张三 |
| 涉嫌罪名 | 故意伤害罪 |
| 诉讼阶段 | 侦查阶段 |
| 强制措施 | 逮捕 |
| 逮捕日期 | [需补充] |

## 二、侦查阶段可获取信息

| 信息类型 | 可否获取 | 法律依据 |
|----------|----------|----------|
| 涉嫌罪名 | ✅ 可以 | 刑诉法第38条（了解罪名） |
| 案件有关情况 | ✅ 可以（概要） | 刑诉法第38条（了解案件情况） |
| 完整卷宗材料 | ❌ 不可以 | 刑诉法第40条（审查起诉后可阅卷） |
| 会见嫌疑人 | ✅ 可以（一般案件） | 刑诉法第39条 |

## 三、事实摘要

[侦查阶段暂无法获取——待审查起诉阶段补充]

## 四、证据清单

[侦查阶段暂无法获取——待审查起诉阶段补充]

## 五、阅卷准备建议

1. 向侦查机关了解涉嫌罪名和案件基本事实
2. 会见嫌疑人了解案情
3. 案件移送审查起诉后，第一时间申请阅卷
4. 阅卷重点关注：伤情鉴定、目击证人、作案工具、因果关系
```
