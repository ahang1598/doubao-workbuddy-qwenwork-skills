### 1.5 五色批注法

| 颜色 | 含义 | 使用场景 | Markdown标记 |
|------|------|----------|-------------|
| 🟡 摘录 | 直接摘录卷宗原文 | 关键事实/关键表述摘录 | `🟡[摘录内容]` |
| 🔴 矛盾 | 发现证据间矛盾 | 同一证据前后矛盾/不同证据矛盾 | `🔴[矛盾描述]` |
| 🟢 有利 | 对辩护有利的信息 | 无罪/罪轻证据/程序瑕疵 | `🟢[有利信息]` |
| 🔵 待补 | 需要补充核实的信息 | 事实不清/证据不足 | `🔵[待补信息]` |
| ⚫ 无关 | 与辩护无关但需记录 | 案件背景/程序性事项 | `⚫[无关信息]` |

## 2. O2: HTML 可视化增强版

**触发条件**：`output_format=html` 或 `output_format=both`（默认both）
**严肃度**：**I-Practical**（内部级），遵循 `base/rule/format-html/format/html-spec.md` §19
**视觉方案**：**C-现代轻量**（方案C色值：青灰 `#005f73` + 暖橙 `#EE9B00`）
**内联样式铁律**：所有排版格式使用 `style="..."` 内联，不依赖 CSS class（遵循 `html-spec.md` §1.1）
**双轨原则**：HTML 不是对 Markdown 的重新排版，而是可视化增强版。内容与 O1 完全一致，但增加侧栏导航、Mermaid图表渲染、表格行级着色、信息卡片、风险标记等视觉增强。
**Richee 组件**：c04-evidence-catalog（证据目录表）

### 2.2 HTML vs Markdown 对照

| 维度 | Markdown (O1) | HTML (O2) |
|------|--------------|-----------|
| 定位 | 一等公民，下游技能消费+版本管理 | 可视化增强版，律师阅读+打印+庭审速查 |
| 图表 | 文字描述/表格 | Mermaid实时渲染（时间线/证据链/控方逻辑链/人物关系） |
| 表格 | 纯文本表格 | 行级着色（风险标记/印证状态/辩护价值） |
| 导航 | 无 | 固定侧栏240px |
| 批注 | Emoji标记（🟡🔴🟢🔵⚫） | 语义色板着色卡片 |
| 折叠 | 无 | `<details>` 折叠高级模块 |
| 打印 | 需额外排版 | @media print适配 |
