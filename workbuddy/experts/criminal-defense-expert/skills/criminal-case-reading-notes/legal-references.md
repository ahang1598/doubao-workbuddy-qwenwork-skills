### 法条原文引用

#### 刑诉法第38条（侦查期间辩护律师的权利）

```
辩护律师在侦查期间可以为犯罪嫌疑人提供法律帮助；代理申诉、控告；申请变更强制措施；向侦查机关了解犯罪嫌疑人涉嫌的罪名和案件有关情况，提出意见。
```

#### 刑诉法第40条（辩护人阅卷权）

```
辩护律师自人民检察院对案件审查起诉之日起，可以查阅、摘抄、复制本案的案卷材料。其他辩护人经人民法院、人民检察院许可，也可以查阅、摘抄、复制上述材料。
```

#### 刑诉法第42条（无罪证据告知义务）

```
辩护人收集的有关犯罪嫌疑人不在犯罪现场、未达到刑事责任年龄、属于依法不负刑事责任的精神病人的证据，应当及时告知公安机关、人民检察院。
```

#### 刑诉法第50条（证据种类）

```
可以用于证明案件事实的材料，都是证据。
证据包括：
（一）物证；
（二）书证；
（三）证人证言；
（四）被害人陈述；
（五）犯罪嫌疑人、被告人供述和辩解；
（六）鉴定意见；
（七）勘验、检查、辨认、侦查实验等笔录；
（八）视听资料、电子数据。
```

**编号映射**：第(三)(四)(五)项 → E-Oral | 第(一)(二)项 → E-Phy | 第(六)项 → E-Exp | 第(七)项 → E-Pro | 第(八)项 → E-Video

## 4. misuse_warnings

| 易混淆 | 正确区分 | 区分要点 |
|--------|----------|----------|
| 第38条vs第40条 | 第38条=侦查期间权利≠阅卷权；第40条=阅卷权 | **最易混淆**——2018年修正后编号变化，旧版阅卷权在第38条 |
| 第40条vs第42条 | 第40条=阅卷权；第42条=无罪证据告知义务 | 第42条才是"告知义务"法条 |
| 阅卷权起始点 | 审查起诉日（第40条） | 侦查阶段无完整阅卷权，第38条仅为了解罪名和案件情况 |
| 阅卷≠复制 | 第40条 | 阅卷=查阅+摘抄+复制 |
| 摘抄≠全文 | 可以选择性摘抄 | 按需摘抄关键内容 |
| 三性初筛≠质证意见 | 阅卷笔录≠证据分析 | 初筛为审查要点提示，深度评估→criminal-evidence-analysis |
| 编号体系≠证据分类 | 编号是引用机制 | 编号用于跨文书证据引用一致性 |
