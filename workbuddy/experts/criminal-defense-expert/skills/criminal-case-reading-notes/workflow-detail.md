## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 卷宗梳理+编号分配 → Phase 3: 事实提取+五色批注
    ↓
Phase 4: 证据要点+矛盾发现+控方逻辑链还原
    ↓
Phase 5: 笔录组装+高级模块+HTML渲染
    ↓
Phase 6: 质量检查 → Phase 7: 输出交付
```

### 1.1 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 | L1 | 低风险 |
| Phase 2 | L2 | 中风险 |
| Phase 3 | L2 | 中风险 |
| Phase 4 | **L3** | **高风险**——矛盾发现+逻辑链还原影响辩护方向 |
| Phase 5 | **L3** | **高风险**——HTML渲染需严格遵守模板约束 |
| Phase 6 | L1 | 低风险 |
| Phase 7 | L1 | 低风险 |

## 3. Phase 2: 卷宗梳理+编号分配

### 3.1 卷宗分类

| 类别 | 内容 | 处理方式 |
|------|------|----------|
| 诉讼文书卷 | 起诉书/拘留证/逮捕证等 | 提取程序信息 |
| 证据卷 | 各类证据材料 | 逐项提取要点+分配编号 |
| 侦查卷 | 讯问笔录/勘验笔录等 | 重点审查合法性 |
| 技术卷 | 鉴定意见/检验报告 | 审查鉴定资质/方法 |

### 3.2 证据编号分配

| 步骤 | 操作 | 产出 |
|------|------|------|
| 2.1 | 按卷宗出现顺序遍历材料 | 材料清单 |
| 2.2 | 按类型分配编号（E-Oral/E-Phy/E-Exp/E-Pro/E-Video/E-Other） | 证据编号索引 |
| 2.3 | 建立编号↔卷宗位置映射 | 对位索引表 |

**检查点**：[ ] 卷宗已分类 [ ] 每项材料已分配编号 [ ] 编号索引已建立

## 4. Phase 3: 事实提取+五色批注

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.1 | 提取指控事实 | 指控事实概要 |
| 3.2 | 构建时间线 | 关键事件时序表 |
| 3.3 | 识别争议点 | 事实争议清单 |
| 3.4 | **五色批注标注** | 🟡摘录/🔴矛盾/🟢有利/🔵待补/⚫无关 |

### 3.3 五色批注标注规则

1. 关键事实摘录 → 🟡摘录
2. 发现证据矛盾 → 🔴矛盾（须双注——在两处证据上均标注）
3. 对辩护有利信息 → 🟢有利（须评估辩护价值高/中/低）
4. 需要补充核实 → 🔵待补（须建议核实方向）
5. 与辩护无关但需记录 → ⚫无关（内容从简）

**检查点**：[ ] 指控事实已提取 [ ] 时间线已构建 [ ] 争议点已识别 [ ] 五色批注已完成

## 5. Phase 4: 证据要点+矛盾发现+控方逻辑链还原

| 步骤 | 操作 | 产出 |
|------|------|------|
| 4.1 | 按八大类整理证据 | 证据清单（含编号） |
| 4.2 | 提取每项证据要点 | 证据要点表 |
| 4.3 | 标注质证切入点 | 质证要点 + `质证切入点` 标签 |
| 4.4 | 评估证明力 | 强/中/弱 |
| 4.5 | **还原控方逻辑链** | 控方逻辑链图 + 断裂点分析 |
| 4.6 | **构建言词证据九宫格** | 九宫格对比矩阵 |
| 4.7 | **证据三性初筛** | 真实性/合法性/关联性初筛 |

### 4.5 控方逻辑链还原步骤

1. 从起诉书提取每项事实主张
2. 将事实主张与构成要件一一对应
3. 找出支撑每项主张的证据及编号
4. 评估证据链完整度（✅印证/⚠️部分印证/❌无印证）
5. 定位断裂点并评估辩护价值

### 4.6 九宫格分析步骤

1. 确定比较维度（核心事实1/2/3...）
2. 横向填写各方言词证据
3. 纵向按维度对比
4. 标注矛盾类型（核心矛盾/细节差异/倾向偏移/漏洞矛盾）

**检查点**：[ ] 证据已逐项整理 [ ] 质证要点已标注 [ ] 控方逻辑链已还原 [ ] 九宫格已完成 [ ] 三性初筛已完成

### 5.4 HTML渲染约束

- **内联样式铁律**：所有 HTML 元素使用 `style="..."` 内联样式，**禁止使用任何 CSS class 进行样式控制**（功能类名白名单见 html-format-spec.md §1.1）
- LLM **仅填充** CONTENT_SLOT 占位符
- LLM **禁止修改** HARD_BLOCK 内任何代码（`<style>` + `<script>`）
- LLM **禁止创建** `<style>` 块或 `<link>` 标签
- 五色批注转为表格行级着色（`<tr style="background:#FFF8EE;">` 等）
- 风险标记转为内联徽章（`<span style="display:inline-block;padding:1px 8px;...">`）
- 下游标签转为内联标签徽章
- **模块三证据要点**：必须使用5列表格格式（证据编号/证据名称/卷宗页码/要点与批注/下游标签），**禁止**使用 evidence-card div 卡片
- Mermaid 图表使用 mermaid-wrap 容器 + 降级表格
- 高级模块使用 `<details>` 折叠（standard模式默认折叠）
- 内联样式模板详见 [html-format-spec.md](./html-format-spec.md)

**检查点**：[ ] 笔录已按选定方式组织 [ ] 所有卷宗内容已覆盖 [ ] 高级模块已填充 [ ] HTML占位符已填充（如需） [ ] HARD_BLOCK未被修改+无CSS class+内联样式
