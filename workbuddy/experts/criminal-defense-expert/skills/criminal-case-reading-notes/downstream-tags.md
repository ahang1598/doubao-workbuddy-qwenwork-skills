# 下游对接标签体系

> 本文件定义 criminal-case-reading-notes v2.0.0 阅卷笔录中使用的下游对接标签规范
> 目的：确保阅卷笔录→下游技能（质证/辩护/取证等）的信号传递一致性

## 1. 标签定义

| 标签 | 含义 | 标注场景 | 下游技能 | 优先级 |
|------|------|----------|----------|--------|
| `质证切入点` | 可用于质证的证据弱点 | 发现证据矛盾/程序瑕疵/证明力薄弱 | criminal-cross-examination | P0 |
| `辩护价值:高` | 对辩护策略有重大价值的线索 | 发现关键无罪/罪轻证据或控方致命断裂 | criminal-case-strategy | P0 |
| `辩护价值:中` | 对辩护策略有中等价值的线索 | 发现部分有利事实或控方重要断裂 | criminal-case-strategy | P1 |
| `辩护价值:低` | 对辩护策略价值有限的线索 | 发现次要有利事实或一般断裂 | criminal-case-strategy | P2 |
| `庭审查询` | 庭审时需询问/核实的的事项 | 事实不清/需当庭确认 | criminal-meeting-guide | P1 |
| `补充证据` | 需要补充取证的线索 | 证据不足/需核实 | criminal-evidence-request | P1 |
| `程序违法` | 程序违法线索 | 非法取证/程序瑕疵 | criminal-evidence-exclusion | P0 |

## 2. 标注规则

### 2.1 标注时机

| 模块 | 可标注标签 |
|------|-----------|
| 三、证据要点 | `质证切入点` `程序违法` |
| 四、程序信息 | `程序违法` `庭审查询` |
| 五、辩护线索 | `辩护价值:高/中/低` `质证切入点` `补充证据` |
| 八、控方逻辑链 | `辩护价值:高/中/低` `质证切入点` |
| 九、九宫格对比 | `质证切入点` `庭审查询` |
| 十、三性初筛 | `质证切入点` `程序违法` |
| 十一、突破点矩阵 | `辩护价值:高/中/低` `质证切入点` `补充证据` |

### 2.2 标注格式

- **Markdown**：行末反引号标注，如 `` `质证切入点` ``
- **HTML**：使用标签徽章，如 `<span class="tag-cross-exam">质证切入点</span>`

### 2.3 标签去重

同一信息在多个模块出现时，只标注最高优先级标签。例如：
- 证据既在"证据要点"又在"三性初筛"出现 → 两侧均标注`质证切入点`
- 同一矛盾在"九宫格"和"控方逻辑链"出现 → 分别标注对应标签

## 3. 下游技能消费规则

| 下游技能 | 消费标签 | 消费方式 |
|----------|----------|----------|
| criminal-cross-examination | `质证切入点` | 收集所有标注项，按证据编号组织质证提纲 |
| criminal-case-strategy | `辩护价值:高/中/低` | 优先处理高价值线索，构建辩护策略 |
| criminal-meeting-guide | `庭审查询` | 整理为会见面谈问题清单 |
| criminal-evidence-request | `补充证据` | 制定取证申请方向 |
| criminal-evidence-exclusion | `程序违法` | 评估是否达到排除标准，准备排除申请 |
