# 风险框架：criminal-case-reading-notes

> 阅卷笔录 | 版本: v2.0.0

## 1. 风险等级

**L2（中等风险）**——证据矛盾发现影响辩护方向，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 卷宗梳理+编号分配 | L2 | 中风险——编号分配影响下游一致性 |
| Phase 3 事实提取+五色批注 | L2 | 中风险——批注遗漏可能影响辩护 |
| Phase 4 证据要点+矛盾发现+逻辑链还原 | **L3** | **高风险**——矛盾发现+逻辑链还原影响辩护方向 |
| Phase 5 笔录组装+HTML渲染 | **L3** | **高风险**——HTML渲染需严格遵守模板约束 |
| Phase 6 质量检查 | L1 | 低风险 |
| Phase 7 输出交付 | L1 | 低风险 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 禁止替代律师阅卷 | 生成笔录时 | 标注"供参考，不替代独立阅卷" |
| RC-02 | 无罪证据特别标注 | 发现有利证据 | 🟢批注+`辩护价值`标签+建议纳入辩护 |
| RC-03 | 非法取证线索 | 发现程序违法 | `程序违法`标签+建议使用evidence-exclusion |
| RC-04 | 阅卷权保障 | 侦查阶段阅卷受限 | 标注权利受限+可获取的材料范围 |
| RC-05 | 编号一致性 | 编号分配时 | 编号一旦确定，下游文书必须沿用 |
| RC-06 | 三性初筛边界 | 三性初筛时 | 明确标注"初筛，非质证意见" |
| RC-07 | HTML模板完整性 | HTML渲染时 | 禁止修改HARD_BLOCK CSS，仅填充CONTENT_SLOT |
| RC-08 | 五色批注密度 | 批注标注时 | 控制密度，避免全本标注等于无标注 |
| RC-09 | 控方逻辑链客观性 | 逻辑链还原时 | 须客观还原，不得预设立场 |
| RC-10 | 下游标签一致性 | 标签标注时 | 标签名称严格使用定义值，不得自由发挥 |

## 4. 行为约束

- 阅卷笔录供参考，不替代律师独立阅卷
- 须特别关注无罪/罪轻证据
- 发现非法取证线索须提示
- 三性初筛不替代证据分析
- 证据编号一旦确定不得随意变更
- HTML输出不得修改模板CSS
