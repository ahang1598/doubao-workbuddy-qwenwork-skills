# 工作流详述

> 本文件定义 criminal-interrogation-analysis 技能的各Phase子步骤与检查点

## 1. 工作流概览

```
Phase 1: 输入解析与笔录结构化 → Phase 2: 供述演变分析[L2]
    ↓
Phase 3: 客观证据印证矩阵[L2] → Phase 4: 翻供与违法模式识别[L2]
    ↓
Phase 5: 深度交叉分析[L2] → Phase 6: 供述可采性与策略映射[L2]
    ↓
Phase 7: 输出交付与下游推荐
```

### 深度模式路径

| 模式 | Phase路径 | 覆盖层 |
|------|----------|--------|
| quick | 1→2→7 | 第1-2层 |
| standard | 1→2→3→4→5→7 | 第1-6层 |
| deep | 1→2→3→4→5→6→7 | 第1-10层 |

### 快速模式强制突破条件

> quick模式检测到以下情形时，**必须突破模式限制**，输出对应层的预警。

| 触发条件 | 突破到层 | 预警内容 |
|---------|---------|---------|
| 未成年人/盲聋哑人 | 第4层（特殊保护） | "检测到特殊主体，需审查合适成年人/翻译人员是否到场" |
| 笔录反映可能存在刑讯逼供线索 | 第4层（程序合规） | "检测到可能存在刑讯逼供线索，需进行程序合规审查" |
| 讯问时间严重违法（超24小时/净讯问≥8小时） | 第4层（时间合规） | "检测到疑似疲劳审讯，需进行时间合规审查" |
| 翻供+理由涉及逼供/诱供 | 第3层（翻供分析） | "检测到翻供且理由涉及违法讯问，需进行翻供可信度分析" |

## 2. Phase 1: 输入解析与笔录结构化

### 1.1 输入解析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1.1 | 解析自然语言/结构化输入 | 结构化字段字典 |
| 1.1.2 | 提取案件基本信息 | case_name, case_stage, suspect_role |
| 1.1.3 | 提取讯问笔录要素 | 按份分类：时间/地点/人员/内容/签字 |
| 1.1.4 | 按时间轴排列笔录 | 时间序列笔录数组 |
| 1.1.5 | 确定分析深度 | analysis_depth |
| 1.1.6 | 提取辅助材料 | 客观证据/录音录像转写/同案犯供述 |

### 1.2 输入校验

| 检查项 | 校验规则 | 失败行为 |
|--------|----------|----------|
| case_name 存在 | 非空 | 交互补全 |
| interrogation_text 存在 | 非空 ∧ ≥50字符 | 交互补全 |
| 笔录日期可提取 | 至少1份有日期 | 标注[日期待补充]，按原文顺序排列 |
| analysis_depth 有效 | 枚举值 | 默认"standard" |

### 1.3 Phase 1 检查点

- [ ] 输入已结构化
- [ ] 必需字段已提取
- [ ] 笔录已按时间轴排列
- [ ] 分析深度已确定
- [ ] 辅助材料已分类

## 3. Phase 2: 供述演变分析 [L2]

### 2.1 第1层：供述演变轨迹分析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 2.1.1 | 逐份提取核心事实要素 | F-001~F-NNN事实要素表 |
| 2.1.2 | 标注各要素在不同笔录中的表述 | 事实要素×笔录矩阵 |
| 2.1.3 | 判断演变类型 | 稳定/渐变/突变/翻供 |
| 2.1.4 | 计算不一致度 | 笔录对不一致度评分 |
| 2.1.5 | 识别供述变化的时间节点 | 变化节点列表 |
| 2.1.6 | 关联关键事件 | 变化节点×关键事件关联表 |

关键事件识别范围：
- 更换侦查人员
- 律师会见
- 认罪认罚告知/签署
- 取保候审/逮捕变更
- 同案犯供述变化

### 2.2 第4层：讯问语境还原与违法线索识别

| 步骤 | 操作 | 产出 |
|------|------|------|
| 2.2.1 | 时间合规审查 | 时长/时段/夜间讯问判定 |
| 2.2.2 | 地点合规审查 | 讯问场所合法性判定 |
| 2.2.3 | 人员合规审查 | 不少于2人/回避审查 |
| 2.2.4 | 间隔合规审查 | 两次讯问间隔时间 |
| 2.2.5 | 权利告知审查 | 权利告知是否完整 |
| 2.2.6 | 特殊保护审查 | 未成年人/聋哑人等特殊保护 |
| 2.2.7 | 跨笔录违法模式识别 | 同类型程序违法出现频次+排除成功率评估 |

### 2.3 Phase 2 检查点

- [ ] 事实要素已提取并编号
- [ ] 演变类型已判定
- [ ] 不一致度已计算
- [ ] 关键事件已关联
- [ ] 程序合规审查完成
- [ ] 违法模式已识别（如有）

## 4. Phase 3: 客观证据印证矩阵 [L2]

### 3.1 第2层：供述×客观证据精确印证矩阵

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.1.1 | 逐项事实要素与客观证据对照 | 印证对照表 |
| 3.1.2 | 标注印证状态 | ✅印证/⚠️部分印证/❌无印证 |
| 3.1.3 | 识别"有供无证"危险区 | 有供无证清单 |
| 3.1.4 | 识别"有证无供"危险区 | 有证无供清单 |
| 3.1.5 | 计算客观印证率 | 印证要素数/总要素数 |

### 3.2 Phase 3 检查点

- [ ] 逐要素印证对照完成
- [ ] 有供无证/有证无供危险区已标注
- [ ] 客观印证率已计算

## 5. Phase 4: 翻供与违法模式识别 [L2]

### 4.1 第3层：翻供层次化分析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 4.1.1 | 识别翻供情形 | 翻供事件列表 |
| 4.1.2 | 五维分析 | 类型×范围×时机×理由×可信度 |
| 4.1.3 | 可信度关键判断 | 对照四种可信度情形 |
| 4.1.4 | 前提条件标注（如audio_transcript未提供） | "⚠️本判断未基于同步录音录像比对"强制标注 |

### 4.2 第7层：隐性诱供/指供模式识别

| 步骤 | 操作 | 产出 |
|------|------|------|
| 4.2.1 | 信息注入型检测 | 嫌疑人不应当知晓的信息出现 |
| 4.2.2 | 渐进修正型检测 | 供述逐步向侦查方向靠拢 |
| 4.2.3 | 模板雷同型检测 | 不同笔录高度雷同的表述 |
| 4.2.4 | 威胁暗示型检测 | 笔录中反映的威胁/暗示线索 |
| 4.2.5 | 诱供vs合法策略边界判断 | 按methodology §8.3四情形逐一判断，防止误标 |

### 4.3 Phase 4 检查点

- [ ] 翻供五维分析完成（如有翻供）
- [ ] 可信度关键判断完成
- [ ] 诱供/指供模式识别完成（如有线索）

## 6. Phase 5: 深度交叉分析 [L2]

### 5.1 第5层：同步录音录像×笔录内容对照

| 步骤 | 操作 | 产出 |
|------|------|------|
| 5.1.1 | **录音录像三要素审查（必检项）** | 三要素审查表 |
| 5.1.1a | 起止时间比对：录音起止时间vs笔录记载起止时间 | 时长差异+异常判定 |
| 5.1.1b | 录制中断检查：中断时段/原因/中断前后供述变化 | 中断记录+供述变化判定 |
| 5.1.1c | 选择性录制审查：录制义务/实际录制/缺失部分/缺失与供述转折关系 | 缺失审查+异常判定 |
| 5.1.2 | 逐段对照笔录与录音录像 | 差异对照表 |
| 5.1.3 | 差异类型分类 | 选择性记录/概括性记录/诱供指供/时间不一致 |
| 5.1.4 | 未录制情形识别 | 缺失时段+事由 |
| 5.1.5 | 评估辩护价值 | 每项差异的辩护价值 |

### 5.2 第6层：多人供述交叉印证

| 步骤 | 操作 | 产出 |
|------|------|------|
| 5.2.1 | 构建多人口供对照矩阵 | 事实要素×供述人矩阵 |
| 5.2.2 | 高度一致警示 | 串供/指供风险标注 |
| 5.2.3 | 矛盾热力图 | 各事实要素争议程度 |
| 5.2.4 | 评估辩护价值 | 矛盾点的辩护价值 |

### 5.3 Phase 5 检查点

- [ ] 录音录像对照完成（如有转写稿）
- [ ] 多人供述交叉印证完成（如有同案犯供述）
- [ ] 条件输出块已触发判定

## 7. Phase 6: 供述可采性与策略映射 [L2]

### 7.1 第8层：供述可采性法律评估

| 步骤 | 操作 | 产出 |
|------|------|------|
| 7.1.1 | 汇总全部问题发现 | 问题清单 |
| 7.1.2 | 问题→法条依据映射 | 法条引用表 |
| 7.1.3 | 法条→法律后果映射 | 应当排除/瑕疵需补正区分 |
| 7.1.4 | 可采性综合评估 | 每份笔录可采性判定 |

### 7.2 第9层：供述→辩护策略系统映射

| 步骤 | 操作 | 产出 |
|------|------|------|
| 7.2.1 | 事实之辩策略 | 供述发现→事实争议策略 |
| 7.2.2 | 定罪之辩策略 | 供述发现→定罪争议策略 |
| 7.2.3 | 量刑辩护策略 | 供述发现→量刑从宽策略 |
| 7.2.4 | 下游技能推荐 | 推荐对应的下游技能调用 |

### 7.3 第10层：动态变化风险评估

| 步骤 | 操作 | 产出 |
|------|------|------|
| 7.3.1 | 评估当前供述稳定性 | 稳定性等级 |
| 7.3.2 | 评估翻供可能性 | 可能性等级 |
| 7.3.3 | 评估排除成功率 | 成功率等级 |
| 7.3.4 | 定义触发更新条件 | 新笔录/翻供/新证据/排除程序 |

### 7.4 Phase 6 检查点

- [ ] 可采性法律评估完成
- [ ] 三层次辩护策略已映射
- [ ] 下游技能推荐已给出
- [ ] 动态风险评估完成
- [ ] 触发更新条件已定义

## 8. Phase 7: 输出交付与下游推荐

### 7.1 输出类型与顺序

| 序号 | 输出项 | 内容 | 格式 |
|------|--------|------|------|
| O1 | 讯问笔录深度分析报告 | 十层分析结构化输出 | Markdown |
| O2 | 下一步推荐动作 | 下游技能调用建议 | Markdown |
| O3 | 讯问笔录深度分析报告 | 同 O1 内容 | **HTML**（自包含，双轨输出） |

### 7.2 Markdown 输出（O1/O2）

按 `output-spec.md` §1.1/§1.2 模板输出。

### 7.3 HTML 输出（O3）[L2]

#### 7.3.1 模板加载

读取 `templates/html/interrogation-analysis-template.html`，确认 8 个 CONTENT_SLOT 占位符位置。

#### 7.3.2 占位符填充

| 步骤 | 操作 | 填充目标 | 数据来源 |
|------|------|---------|---------|
| 7.3.2.1 | 填充 PAGE_TITLE | `<h1>` 标题 | O1 报告标题 |
| 7.3.2.2 | 填充 GENERATED_AT | 时间戳占位符 | 当前时间 YYYY-MM-DD HH:mm:ss |
| 7.3.2.3 | 填充 ANALYSIS_META | 工具栏信息区 | analysis_depth + case_stage + 草稿声明 |
| 7.3.2.4 | 填充 CASE_OVERVIEW | page-header 内 | O1 "案件概览"块 → HTML |
| 7.3.2.5 | 填充 LAYER_1_TO_10 | 主内容区 | O1 第1~10层 → HTML（按深度模式） |
| 7.3.2.6 | 填充 CONCLUSION | 结论区 | O1 "结论与建议" → HTML |
| 7.3.2.7 | 填充 CHECKLIST | 清单区 | O1 "律师必检清单" → HTML |
| 7.3.2.8 | 侧栏锚点验证 | 侧栏 `<a href="#layer-N">` | 确认与各层 section id 对应 |

#### 7.3.3 层渲染规则

| 层 | 渲染要求 | 关键 class | 参见 |

#### 7.3.4 深度模式折叠

| 深度 | 折叠策略 |
|------|---------|
| quick | 仅渲染第1~2层，不折叠 |
| standard | 第1~7层全展开，第8~10层 `<details>` 折叠 |
| deep | 全部展开（`<details open>`），每层可选 `page-break-before` |

#### 7.3.5 HTML 输出禁止事项

| 禁止项 | 说明 |
|--------|------|
| ❌ 修改 HARD_BLOCK 内 CSS | `<style>` 块不可增删改 |
| ❌ 使用内联 `style=""` | 模板已提供全部 class，LLM 仅引用 class |
| ❌ 添加额外 `<script>` | 模板已含侧栏导航 JS |
| ❌ 删除或改名 CONTENT_SLOT | 8 个占位符必须全部保留 |
| ❌ 修改 class 名称 | 所有 CSS class 由模板定义 |

### 7.4 质量自检

| 检查项 | 标准 |
|--------|------|
| 十层覆盖 | 已执行的分析层均有输出 |
| 置信度标注 | 每项结论标注高/中/低 |
| 无真实性终判 | 无"供述真实/虚假"等断言 |
| 无刑讯断言 | 无"存在刑讯逼供"等断言 |
| 法条精确 | 引用精确到条/款/项 |
| 无罪推定 | "涉嫌"而非"构成" |
| 无分析标签 | 正文无"【分析】""【结论】"等标签 |
| HTML HARD_BLOCK 完整 | `<style>` 块未被修改 |
| HTML CONTENT_SLOT 全部填充 | 8 个占位符均已替换 |
| HTML 侧栏锚点有效 | 侧栏 12 个 `href` 对应实际 `id` |
