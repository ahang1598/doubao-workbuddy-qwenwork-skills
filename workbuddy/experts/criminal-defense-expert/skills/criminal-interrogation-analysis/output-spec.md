# 输出规格

> 本文件定义 criminal-interrogation-analysis 技能的完整输出结构模板

## §0.5 写作红线（禁止事项）

> 🔴 写作红线是LLM生成的硬性约束，违反任一项即阻断输出。

### 3.0 红线前三条（最高优先级，LLM生成前必须校验）

| 优先级 | 禁止项 | 正确做法 | 违反后果 |
|--------|--------|----------|---------|
| **R1** | "供述是真实的/虚假的" | "供述与XX证据印证/矛盾，可靠性评估为XX" | 🔴阻断——真实性终判违反核心原则 |
| **R2** | "存在刑讯逼供" | "存在程序违法（XX），需进一步核实" | 🔴阻断——程序违法留边界原则 |
| **R3** | 误将合法讯问策略标记为诱供 | 区分"出示客观证据/提示回忆/告知法律后果"（合法）与"信息注入/欺骗/威胁"（违法），详见methodology §8.3 | 🔴阻断——误标诱供在庭审中被公诉人反噬，比漏识别诱供更危险 |

### 3.1 内容禁止

| 禁止项 | 正确做法 |
|--------|----------|
| "供述是真实的/虚假的" | "供述与XX证据印证/矛盾，可靠性评估为XX" |
| "存在刑讯逼供" | "存在程序违法（XX），需进一步核实" |
| "翻供一定成功/失败" | "翻供可信度评估为XX" |
| 笼统法条引用 | 精确到条/款/项 |
| "罪犯"/"犯人" | 犯罪嫌疑人/被告人 |
| 未调取录音录像就做出翻供可信度终判 | 必须附加前提条件标注："本判断未基于同步录音录像比对" |
| 将合法讯问策略标记为诱供 | 严格按methodology §8.3边界判断指引标注 |

### 3.2 格式禁止

| 禁止项 | 正确做法 |
|--------|----------|
| 分析框架标签外泄 | 去分析化，直接叙述 |
| 无置信度结论 | 每项结论标注置信度 |
| 缺少前提条件标注 | 依赖不完整信息的结论必须标注"结论受限于未提供[XX材料]" |

### 3.3 LLM违规专项检查

> 本节针对LLM生成中最常见的违规模式，作为输出前的强制校验项。

| 违规模式 | 检测关键词 | 修正方式 |
|---------|-----------|---------|
| 真实性终判 | "供述真实"/"供述虚假"/"确系" | 替换为"供述与XX证据印证/矛盾" |
| 刑讯逼供断言 | "刑讯逼供"/"严刑拷打"/"逼供" | 替换为"程序违法（XX），需进一步核实" |
| 法条笼统引用 | "刑诉法相关规定"/"法律规定" | 补全精确条文编号 |
| 误标诱供 | "诱供"出现在出示客观证据后的供述变化处 | 替换为"证据出示后供述变化（中性）" |
| 翻供终判无前提 | 翻供可信度判断出现但未标注前提条件 | 追加"⚠️前提条件：本判断未基于同步录音录像比对" |
| 疲劳审讯无阈值 | "超时长"出现但未给出具体判断标准 | 追加净讯问时间计算和阈值对照（methodology §5.3） |

### 1.3 O3: 讯问笔录深度分析报告（HTML）

**触发条件**：始终输出（Markdown O1 与 HTML O3 双轨并行）

**格式**：自包含 HTML 文件（内联样式 + HARD_BLOCK `<style>` 块），可直接在浏览器中打开

**严肃度**：I-Practical（内部级），参见 `references/html-format-spec.md`

**模板**：`templates/html/interrogation-analysis-template.html`

**核心特性**：
- 侧栏 10 层固定导航（屏幕可见 / 打印隐藏）
- 7 色语义色板（印证绿/瑕疵琥珀/排除红/稳定青/警告橙/中性灰/正文黑）
- 行级着色（十层表格各自的行背景色规则）
- 深度模式自适应折叠（quick/standard/deep）
- 打印优化（左侧 3cm 装订边距 / 背景色打印 / 分页策略）
- A4 纵向排版

**内容与 O1 Markdown 完全一致**，仅渲染格式不同。LLM 在生成阶段直接按 HTML 结构输出，填充模板 7 个 CONTENT_SLOT 占位符。

**占位符映射**：

| 占位符 | 映射来源 | 说明 |
|--------|---------|------|
| `PAGE_TITLE` | O1 标题 | "讯问笔录深度分析报告" |

| `ANALYSIS_META` | analysis_depth + case_stage | 分析深度/诉讼阶段/草稿声明 |
