# 质量评价标准

> 本文件定义 criminal-interrogation-analysis 技能的质量评价标准

## 1. 输出质量维度

### 1.1 完整性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 十层覆盖 | 已执行的分析层均有输出 | ⚠️警告（缺失层标注[待补充]可接受） |
| 笔录覆盖 | 每份笔录均被纳入分析 | 🔴阻断（遗漏笔录→分析不完整） |
| 事实要素覆盖 | 关键事实要素均被提取和编号 | ⚠️警告 |
| 法条覆盖 | mandatory法条在相关场景中被引用 | 🔴阻断 |

### 1.2 准确性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 法条精确 | 引用精确到条/款/项 | 🔴阻断（笼统引用→必须修正） |
| 法条内容 | 引用的法条内容与现行有效版本一致 | 🔴阻断（法条错误→阻断级修复） |
| 笔录引用 | 笔录编号和日期与原文一致 | 🔴阻断 |
| 客观印证率 | 计算逻辑正确（印证数/总数） | ⚠️警告 |

### 1.3 安全性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 无真实性终判 | 无"供述真实/虚假"等断言 | 🔴阻断 |
| 无刑讯断言 | 无"存在刑讯逼供"等断言 | 🔴阻断 |
| 无罪推定 | "涉嫌"而非"构成"，无"罪犯"等表述 | 🔴阻断 |
| 无替代判断 | 策略建议标注"建议"而非"应当" | ⚠️警告 |
| 置信度标注 | 每项结论标注置信度 | ⚠️警告 |
| 前提条件标注 | 依赖不完整信息的结论标注"结论受限于未提供[XX材料]" | 🔴阻断（翻供可信度判断未基于录音录像且无前提标注→阻断） |
| 诱供边界判断 | 不得将合法讯问策略误标为诱供 | 🔴阻断（误标诱供→庭审反噬风险） |

### 1.4 可操作性

| 检查项 | 标准 | 阻断级别 |
|--------|------|---------|
| 下游推荐 | 每个关键发现映射到具体下游技能 | ⚠️警告 |
| 律师必检清单 | 包含至少5项需律师核实的事项 | ⚠️警告 |
| 危险区显性化 | "有供无证""有证无供"显性标注 | 🔴阻断（遗漏危险区→分析价值丧失） |

## 2. 各分析层质量标准

| 层 | 核心质量指标 | 最低标准 |
|----|------------|---------|
| 第1层 | 事实要素提取完整性 | 核心要素（时间/地点/人物/行为）至少提取3项 |
| 第2层 | 印证矩阵准确性 | 逐要素标注印证状态，客观印证率计算正确 |
| 第3层 | 翻供五维分析完整性+前提条件标注 | 五个维度均有评估（有翻供情形时）；audio_transcript未提供时必须附加前提条件标注 |
| 第4层 | 程序合规审查覆盖度 | 七维度审查均完成 |
| 第5层 | 录音录像差异识别度+三要素审查 | 至少标注差异类型和辩护价值；三要素（起止时间/中断/选择性录制）必检 |
| 第6层 | 多人供述一致性评估 | 对照矩阵+高度一致警示+矛盾热力图 |
| 第7层 | 诱供模式识别准确度+边界判断 | 至少识别1种模式（有线索时）；诱供vs合法策略边界判断无误标 |
| 第8层 | 法条映射精确度 | 每个问题映射到精确法条 |
| 第9层 | 策略映射可操作性 | 三层次策略均有具体内容 |
| 第10层 | 动态风险评估前瞻性 | 三个维度均有评估+触发条件已定义 |

## 3. 置信度评估标准

| 等级 | 标准 | 表述方式 |
|------|------|---------|
| 高 | 有直接客观证据支持+法条明确+逻辑无矛盾 | [置信度：**高**] |
| 中 | 有间接证据支持+法条基本明确+逻辑基本通顺 | [置信度：**中**] |
| 低 | 仅有推测+法条适用存疑+逻辑有跳跃 | [置信度：**低**] |

## 4. SOFT_DEGRADED 质量标准

| 降级等级 | 触发条件 | 最低质量标准 |
|---------|---------|-------------|
| S1 | 必需字段缺失 | C+D+G三段完整 |
| S2 | 笔录不完整/仅1份 | 已有层按标准执行，缺失层标注[待补充] |
| S3 | 选填输入缺失 | 核心层按标准执行，选填层标注[待补充] |
