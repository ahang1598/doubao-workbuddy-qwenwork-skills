# 输入规格：criminal-investigation-defense

> 侦查阶段辩护意见书 | Step3产出 | 版本: v2.6.1

## 1. 输入模型

### 1.1 宽容摄取原则

接受6种输入形态：结构化(I1)/自然语言(I2)/混合式(I3)/渐进式(I4)/模板填充(I5)/最小化(I6)

### 1.2 交互补全（最多3轮）

| 轮次 | 触发条件 | 询问内容 |
|------|----------|----------|
| R1 | 缺少必填字段 | "请补充：①犯罪嫌疑人姓名 ②涉嫌罪名 ③辩护方向（不构成犯罪/情节轻微/无逮捕必要/罪名争议）" |
| R2 | 辩护依据不充分 | "请补充：①辩护要点 ②案件基本事实 ③拘留信息（日期/机关）" |
| R3 | 致送机关不明确 | "请确认：①当前处于拘留期间还是审查批捕期间？②致送公安机关还是检察院？" |

3轮后仍不足 → SOFT_DEGRADED

---

## 2. 字段定义

### 2.1 必填字段（5个）

| # | 字段名 | 类型 | 说明 |
|---|--------|------|------|
| F1 | suspect_name | string | 犯罪嫌疑人姓名 |
| F2 | alleged_crime | string | 涉嫌罪名 |
| F3 | defense_direction | enum | 辩护方向：no_crime/lighter_crime/no_arrest_necessity/dispute_qualification |
| F4 | case_facts | text | 案件基本事实 |
| F5 | defense_points | array[text] | 辩护要点/理由 |

### 2.2 推荐字段（3个）

| # | 字段名 | 类型 | 说明 | 默认值 |
|---|--------|------|------|--------|
| R1 | detention_info | object | 拘留信息（日期/机关/期限） | 从case_facts推断 |
| R2 | evidence_issues | text | 证据问题 | 从defense_points提取 |
| R3 | mitigating_factors | array[string] | 从轻/减轻情节 | 从case_facts提取 |

### 2.3 可选字段（4个）

| # | 字段名 | 类型 | 说明 | 默认值 |
|---|--------|------|------|--------|
| O1 | illegal_evidence_clues | text | 非法取证线索 | 无 |
| O2 | meeting_notes_summary | text | 会见笔录摘要 | 无 |
| O3 | favorable_evidence | text | 有利证据材料 | 无 |
| O4 | bail_status | text | 取保候审申请状态 | 无 |

---

## 3. 输入验证规则

### 3.1 硬拒绝条件

| # | 条件 | 处理 |
|---|------|------|
| HR-01 | 要求保证不批捕结果 | 拒绝+说明理由 |
| HR-02 | 要求捏造或歪曲证据 | 拒绝+说明理由 |
| HR-03 | 要求对办案人员人身攻击 | 拒绝+说明理由 |
| HR-04 | 非侦查阶段案件 | 拒绝+引导至对应技能 |

### 3.2 软降级条件

| # | 条件 | 降级方式 |
|---|------|----------|
| SD-01 | 仅姓名+罪名 | D档→G档 |
| SD-02 | 辩护方向不明确 | D档+提示选择 |
| SD-03 | 无法判断案件基本事实 | D档+框架填充 |
| SD-04 | 拘留信息缺失 | 不降级，标注"拘留信息待补充" |
