# 侦查阶段辩护意见起草

> **核心定位**：为辩护律师在侦查阶段生成辩护意见书，正文精简至3-4段（定罪分析→从宽情节→危险性/羁押必要性→请求），向侦查机关（公安局/批捕检察院）提出辩护意见。因侦查阶段尚不能阅卷，篇幅控制在1-2页，前言和结语必须声明信息有限。

---

## 模块一：法律合规声明

1. **管辖范围**：中国大陆（不含港澳台）。辩护意见书致送侦查机关（公安局）或检察院（批捕审查阶段）
2. **输出性质**：O1(.docx)为排版正式稿，O2(Markdown)为编辑稿；均为**草稿**，仅供律师审核确认，不直接提交侦查机关或检察院
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **无罪推定**：所有表述必须体现"未经法院判决不得确定有罪"，禁止"罪犯/确定有罪"等表述
5. **四维度论证**：不构成犯罪论证/犯罪情节轻微论证/无逮捕必要性论证/罪名定性争议论证，论证逻辑须与辩护方向匹配
6. **认罪认罚**：如适用认罪认罚从宽制度（刑诉法第15条），须单独论述，且不得与"不构成犯罪"论证同时主张
7. **免责声明**：不保证不批捕结果，不提供确定性诉讼策略建议
8. **法条核验**：核心法条须经检索确认——第34条（辩护人介入）、第38条（侦查阶段辩护权）、第39条（会见权）、第40条（阅卷权——侦查阶段无）、第88条（批捕讯问）、第90条（批捕决定）、第91条（提请批捕时限），条号不可混淆

## 核心禁止规则——必须遵守

1. **禁止有罪推定**："涉嫌"而非"构成"，"犯罪嫌疑人"而非"罪犯"（全文）
2. **禁止不利自认**：正文禁止"当事人确实实施了XX行为"，结语禁止"虽涉及不当行为"等（正文+结语）
3. **禁止结果承诺**：不使用"一定不批捕""肯定能出来""保证可以取保"等（全文）
4. **禁止排版违规**：docx禁止空行分段/禁止@image/正文禁止表格/O1禁止免责声明（O1 docx）
5. **禁止逻辑矛盾**：不构成犯罪与认罪认罚不得同时主张，批捕标准≠定罪标准
6. **禁止策略暴露**：致送公安的意见以程序性论证为主，实体辩护留到检察院阶段（侦查阶段特有）
7. **禁止越界输出**：不产出取保候审申请书/羁押审查申请等超出范围的内容
8. **禁止框架标签泄露**：正文禁止"【分析】""【结论】"等标签
9. **禁止法条混淆**：第89条≠提请批捕期限（第91条）；第88条≠批捕决定（第90条）；第38条≠阅卷权（第40条）

## 模块二：快速开始

> 最少输入即可启动，技能自动补全缺项

### 最简用法

```
帮我写一份侦查阶段的辩护意见书。张某涉嫌轻伤案，
已赔偿谅解，受害方出具谅解书，认为不构成犯罪。
```

### 指定辩护方向

```
写一份无逮捕必要的辩护意见。李某涉嫌非国家工作人员受贿罪，
有固定住所、稳定工作、无前科，已全额退赃。
```

### 提供完整信息

```
生成侦查阶段辩护意见书。王某涉嫌职务侵占罪，2025年4月15日被刑事拘留，
现处于报请批捕前阶段。辩护要点：
1.第2笔35万系正常业务往来（有合同+付款凭证）
2.如认定为职务侵占，金额应从87万减至20万
3.王某有自首情节（主动到案+如实供述第1笔）
4.已全额退赃20万
辩护方向：罪名定性争议（职务侵占vs挪用资金）+无逮捕必要
```

### 核心原则

| 序号 | 原则 | 说明 |
|------|------|------|
| 1 | **侦查阶段信息有限** | 律师无法阅卷（刑诉法第40条），事实陈述仅基于会见和外围信息——前言和结语必须声明 |
| 2 | **正文精简3-4段** | 定性→从宽情节→危险性/羁押必要性→请求，篇幅控制在1-2页 |
| 3 | **致送机关区分** | 拘留期间致送公安机关；提请批捕后致送检察院 |
| 4 | **证据论证为核心** | 不构成犯罪论证须逐项论证证据不足；无逮捕必要论证须逐项论证无社会危险性 |
| 5 | **禁止承诺** | 不保证不批捕结果，不提供确定性诉讼策略建议 |
| 6 | **不利自认禁止** | 不得生成"当事人确实实施了XX行为"等对当事人不利的表述 |
| 7 | **Docx 独立生成** | O1(.docx) 不由 O2(Markdown) 转换而来——python-docx 直接操作 Word API 生成 |
| 8 | **法条引用精确** | 第34条（介入权）/第39条（会见权）/第40条（阅卷权——侦查阶段无）/第88条（批捕讯问）/第90条（批捕决定）/第91条（提请时限）——条号不可混淆 |
| 9 | **辩护策略分层** | 向公安提交意见以程序性论证为主（避免暴露策略）；向检察院提交意见可充分论证实体问题 |
| 10 | **退一步论证可用** | 骨架A+骨架C组合（"首先不构成犯罪，退一步即使构成也无逮捕必要"）——措辞须避免不利自认 |
| 11 | **批捕标准≠定罪标准** | 针对"有证据证明有犯罪事实"标准论证，非"排除合理怀疑"标准 |
| 12 | **羁押必要性审查** | 批捕后可依据第95条申请羁押必要性审查——在结语或策略提示中提示此救济途径 |
| 13 | **L3结构合规** | 文书结构须对标 L3 类型规格卡 `T-investigation-defense-opinion.md`（本技能偏离：10组件——无独立案情概述段，案情事实融入论证主体）；含证据线索段+强制措施与羁押必要性段；C-party-info偏离为开篇叙述段 |
| 14 | **强制措施阶梯方案** | 强制措施与羁押必要性段必须包含变更强制措施阶梯方案（撤销→取保→监居），不得仅提"请求变更"而无具体方案。**custody_status=on_bail豁免**——已取保时改用维持取保论证（见原则16） |
| 15 | **lawyer_draft 范式** | 本技能遵循 §17.28 lawyer_draft 范式——以写作规则为核心，论证主体允许自然段落连续叙述，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）；5种动态骨架+模块池+反机械化规则（AM-01~AM-05c）+文书声音+受众适配 |

| 17 | **结语声明按致送机关区分** | 致送公安→"本意见因侦查阶段接触证据有限，仅供参考"；致送检察院→"本意见仅供审查批捕时参考"——禁止跨机关混用 |

### 🔴 格式关键约束（LLM 注意力高峰区）

> 以下规则从文件末尾"格式要求"区前移至此，确保 LLM 优先获取。

1. **O1 生成路径（python-docx 直接生成）**：O1(.docx) 由 LLM 直接使用 python-docx API 按排版规格生成，非 Markdown 转换
2. **段落粒度**：每个语义单元独立 Word 段落，禁止多语义单元挤同一段落
3. **禁止 @image**：纯文字文书，任何图片/占位符零容忍
4. **正文禁止表格**：论证正文禁止任何表格（含D1-D5），必须逐项分段叙述；**信息区不用表格**——身份信息以开篇叙述段融入
5. **O1 禁止免责声明**：.docx 正式稿不含免责声明，签名后接附件清单
6. **正文禁止空行**：段间距用段前/段后间距控制，禁止插入空段落
7. **结语必须"综上所述"**：结语段必须以加粗"**综上所述**"开头
8. **禁止确定断言语气**：侦查阶段信息有限，宜用"据了解""初步认为"等审慎表述
9. **排版参数覆盖声明**：本技能选择 F-Strict 排版参数（仿宋三号/黑体三号/28磅行距）覆盖 L3 类型卡 C-Professional 默认，依据：提交侦查机关/检察院的正式文书

## 模块四：输出格式与质量标准

### 行文结构

> **lawyer_draft 范式**（§17.28 D3）：论证主体以自然段落连续叙述展开，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）。各骨架定义"必须论证哪些主题"，LLM自主拟定段落组织与路标表述。
>
> 输出结构：标题→致送机关→开篇叙述段（辩护人/委托人/嫌疑人信息融入叙述，非信息区表格）→辩护意见论证主体（按骨架A/B/C/D/E，连续叙述）→证据线索（如有，自然过渡）→强制措施与羁押必要性（按custody_status路由，自然过渡）→请求事项（自然过渡）→结语（"综上所述"+信息有限声明，按致送机关区分）→此致→辩护人签名+日期→附件清单。
> 
> **🔴 禁止模板标签式章节标题，但须设加粗路标**：整个辩护意见是连续叙述段，禁止出现模板标签式`## `或`### `标题（如"## 强制措施与羁押必要性""## 请求事项""## 结语"等跨案件通用槽位）——这些都是模板标签，不传递本案论证信息。各内容块之间应以**加粗陈述句路标**（AM-05b）分隔（如"**王某有固定住所、稳定工作、无前科，无社会危险性**"），路标禁破折号（AM-05c）；可选在路标前加 Word 原生编号（一、/（一））。
> 完整写作规则、动态骨架体系、模块池、反机械化规则见 [output-spec.md §1A](./output-spec.md#1a-docx-渲染规格lawyer_draft-范式)

> **lawyer_draft 范式**（§17.28）：5种论证骨架按案情动态选择，LLM自主拟定论证主题和段落组织，不强制固定子标题。可组合（如A+C/D+C）。

| 骨架 | 论证核心 | 论证主题清单 |
|------|----------|-------------|
| A 不构成犯罪型 | 定性否定（证据不足/构成要件不符） | 证据不足→构成要件不符→批捕标准未达 |
| B 情节轻微型 | 情节论证+社会危险性排除 | 情节轻微→不需判处刑罚→社会危险性排除+取保可行 |
| C 无逮捕必要型 | 第81条逮捕条件逐项排除 | 社会危险性排除→取保可行→羁押不必要 |
| D 罪名争议型 | 此罪彼罪之辩 | 指控罪名要件→应定罪名要件对比→事实匹配→批捕影响 |
| E 侦查终结从宽建议型 | 已取保+轻罪+侦查终结 | 维持取保论证→情节轻微→不需判处刑罚→从宽处理建议 |

## 模块五：常见问题

### Q1: 侦查阶段辩护意见书和审查起诉阶段辩护意见书有什么区别？
**答**：核心区别有三：(1)致送机关不同——侦查阶段致送公安机关/检察院（批捕审查），审查起诉阶段致送检察院；(2)论证目标不同——侦查阶段论证"不批捕/不构成犯罪"，审查起诉阶段论证"不起诉"；(3)信息基础不同——侦查阶段律师无法阅卷（刑诉法第40条），只能基于会见和外围信息，审查起诉阶段可以阅卷。

### Q2: 四种辩护方向如何选择？
**答**：(1)不构成犯罪（no_crime）：认为行为根本不构成犯罪；(2)犯罪情节轻微（lighter_crime）：可能构成犯罪但情节轻微；(3)无逮捕必要性（no_arrest_necessity）：即使可能构成犯罪也无逮捕必要；(4)罪名定性争议（dispute_qualification）：指控罪名有误。实务中可组合，如"罪名争议+无逮捕必要"。

### Q3: 侦查阶段律师看不到案卷，怎么写辩护意见？
**答**：事实基础来自：(1)会见当事人了解的情况（刑诉法第39条）；(2)家属提供的外围信息；(3)律师自行收集的客观证据。文书须标注"根据会见及有限信息了解"，论证重点放在"现有证据不足以达到批捕标准"而非"全面还原案件事实"——"破"的论证而非"立"的论证。

## 技法要求

1. **篇幅控制**：正文1-2页，不展开D1-D5详细社会危险性论证
2. **方向识别**：首先判断辩护方向，选择对应论证路径
3. **证据论证**：不构成犯罪——逐项论证证据不足，针对批捕标准而非定罪标准
4. **结论安全**：结语严格按请求总结，不出现不利自认
5. **docx 不转换**：O1 由 LLM 直接使用 python-docx API 生成，不从 Markdown 转换

## 格式要求

> 以下仅列出 LLM 需遵守的规则。完整排版规格详见 output-spec.md "DOCX 排版规格"专章

1. **O1 生成路径（python-docx 直接生成）**：O1(.docx) 由 LLM 直接使用 python-docx API 按排版规格生成，非 Markdown 转换
2. **段落粒度**：每个语义单元独立 Word 段落，禁止多语义单元挤同一段落
3. **禁止 @image**：纯文字文书，任何图片/占位符零容忍
4. **正文禁止表格**：论证正文禁止任何表格（含D1-D5），必须逐项分段叙述
5. **O1 禁止免责声明**：.docx 正式稿不含免责声明，签名后接附件清单
6. 正文使用规范法律用语；禁止框架标签泄露；`[注]` 标注法条来源
