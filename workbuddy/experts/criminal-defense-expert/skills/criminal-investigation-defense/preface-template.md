> 致送机关顶格置于标题之下、正文之前；辩护人/委托人/嫌疑人信息及前言以自然叙述融入开篇段，不再独立成段。

```
XX市公安局XX分局：

辩护人XXX，XXX律师事务所律师（执业证号XXX），接受犯罪嫌疑人XXX之[关系]XXX的委托，担任XXX涉嫌XX罪一案侦查阶段的辩护人。辩护人依法会见了犯罪嫌疑人XXX（刑诉法第三十九条），了解到其于XXXX年XX月XX日被刑事拘留，至今已羁押XX日。因侦查阶段尚不能查阅全部案卷材料（刑诉法第四十条），辩护人根据现有了解的情况，依据《中华人民共和国刑事诉讼法》第三十四条、第三十八条之规定，提出如下辩护意见。
```

## 标准备注

- **第34条**：辩护人介入时间的法律依据——"犯罪嫌疑人自被侦查机关第一次讯问或者采取强制措施之日起，有权委托辩护人"
- **第38条**：侦查阶段辩护权的法律依据——"辩护律师在侦查期间可以为犯罪嫌疑人提供法律帮助；代理申诉、控告；申请变更强制措施；向侦查机关了解犯罪嫌疑人涉嫌的罪名和案件有关情况，提出意见"
- **第39条**：会见权的法律依据——"辩护律师可以同在押的犯罪嫌疑人、被告人会见和通信"
- **第40条**：阅卷权的反向论证——"辩护律师自人民检察院对案件审查起诉之日起，可以查阅、摘抄、复制本案的案卷材料"——据此声明侦查阶段无阅卷权
- **第88条**：律师要求当面陈述意见的强制性权利——"辩护律师提出要求的，应当听取辩护律师的意见"（轻罪场景豁免，见legal-references §5）

## 标准结语模板（v2.6.0 按致送机关区分）

> 结语段必须以加粗"**综上所述**"开头（D14 必填），后接辩护意见要点总结+信息有限声明。
> **v2.6.0 变更**：结语声明按致送机关区分——致送公安禁用"审查批捕时参考"，致送检察院禁用"侦查阶段接触证据有限"（output-spec §1A.0 结语模块池 / 组件8 / W17）。

### 致送公安机关版（拘留期间）

> 信息有限声明使用"因侦查阶段接触证据有限，仅供参考"。

#### 骨架A 不构成犯罪结语（公安版）

```
综上所述，辩护人认为现有证据不足以证明[嫌疑人姓名]构成[罪名]，其行为不符合该罪的构成要件。鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准。
```

#### 骨架B 犯罪情节轻微结语（公安版）

```
综上所述，辩护人认为[嫌疑人姓名]的犯罪情节轻微，不需要判处刑罚或可免除刑罚。鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准。
```

#### 骨架C 无逮捕必要性结语（公安版）

```
综上所述，辩护人认为[嫌疑人姓名]不具有逮捕必要性，无社会危险性。鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准。
```

#### 骨架D 罪名定性争议结语（公安版）

```
综上所述，辩护人认为指控罪名认定有误，应认定为较轻罪名。鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准。
```

#### 骨架E 侦查终结从宽建议结语（公安版）

```
综上所述，[嫌疑人姓名]取保期间遵守规定，犯罪情节轻微，建议在侦查终结时依法从宽处理。鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准。
```
