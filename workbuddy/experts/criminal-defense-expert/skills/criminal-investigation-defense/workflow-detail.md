# 工作流详情：criminal-investigation-defense

> 侦查阶段辩护意见书 | 版本: v2.6.1

## Phase 1: 输入验证

- 检查5个必填字段
- 验证 defense_direction 枚举值
- 检查 hard_reject 条件（保证结果/捏造证据/人身攻击/非侦查阶段）
- 信息不足 → 交互补全（最多3轮）

## Phase 2: 动态骨架选择与信息结构化 [L2]

> **lawyer_draft 范式**（§17.28）：4种论证骨架按案情动态选择，LLM自主拟定论证主题和段落组织。

### 2.1 辩护方向路由（动态骨架选择）

| defense_direction | 骨架 | 论证主题清单 | 触发条件 |
|-------------|----------|-------------|----------|
| no_crime | A 不构成犯罪型 | 证据不足→构成要件不符→批捕标准未达 | `defense_direction=no_crime` |
| lighter_crime | B 情节轻微型 / E 侦查终结从宽建议型 | 情节轻微→不需判处刑罚→社会危险性排除+取保可行 | `defense_direction=lighter_crime`；若 `custody_status=on_bail` + 轻罪 → 骨架E |
| no_arrest_necessity | C 无逮捕必要型 | 社会危险性排除→取保可行→羁押不必要 | `defense_direction=no_arrest_necessity` |
| dispute_qualification | D 罪名争议型 | 指控罪名要件→应定罪名要件对比→事实匹配→批捕影响 | `defense_direction=dispute_qualification` |

> **可组合**：A+C（不构成犯罪退一步+无逮捕必要）、D+C（罪名争议+无逮捕必要）。组合时措辞须避免不利自认。
> **骨架E特殊触发**：lighter_crime + custody_status=on_bail + 轻罪三个条件同时满足时走骨架E；仅 lighter_crime 但 custody_status=in_detention 仍走骨架B。
> **P4.0 内部判断流程**：骨架选择→custody_status判定→论证密度→对抗程度→文书声音→受众适配，详见 output-spec.md §1A.1

### 2.2 信息提取

- 从自然语言中提取结构化辩护要点
- 识别拘留信息（日期/机关/期限）→ 计算37天时间窗口
- 识别羁押状态（in_detention/on_bail/arrested）→ 影响组件7内容路由
- 识别从轻/减轻情节
- 评估输入充分度 → 确定输出档次（C/D/G）

### 2.3 致送机关判定

| 当前阶段 | 致送机关 | 论证侧重点 |
|---------|---------|-----------|
| 拘留期间（公安侦查） | XX公安局XX分局 | 不构成犯罪/无社会危险性 |
| 审查批捕期间（7天） | XX人民检察院 | 不符合批捕条件/无逮捕必要 |

## Phase 3: 论证构建 [L3]

> **lawyer_draft 范式**：论证主体以自然段落连续叙述展开，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）。各骨架定义"必须论证哪些主题"，LLM自主拟定段落组织。写作规则（论证张力四层递进/行为定性/法条嵌入/文书声音/受众适配）详见 output-spec.md §1A.2。

### 骨架A 不构成犯罪型

- 论证主题1：证据不足论证——逐项论证哪些证据不足，针对批捕标准非定罪标准
- 论证主题2：构成要件不符论证——行为不符合犯罪构成要件
- 论证主题3：批捕标准未达论证——针对第81条"有证据证明有犯罪事实"标准

### 骨架B 情节轻微型

- 论证主题1：情节轻微论证——金额小/后果轻/偶犯/从犯等
- 论证主题2：不需判处刑罚论证——刑法相关规定
- 论证主题3：社会危险性排除+取保可行——逐项排除+保证方式

### 骨架C 无逮捕必要型

- 论证主题1：社会危险性排除——固定住所+稳定工作+无前科+家庭纽带
- 论证主题2：取保候审可行——保证人/保证金方案
- 论证主题3：羁押不必要论证——对照第81条逐项反驳

### 骨架D 罪名争议型

- 论证主题1：指控罪名要件分析——拆解指控罪名构成要件
- 论证主题2：应定罪名要件对比——对比应定罪名构成要件
- 论证主题3：事实匹配论证——事实与应定罪名要件匹配
- 论证主题4：批捕影响论证——较轻罪名的社会危险性+批捕必要性降低

### 骨架E 侦查终结从宽建议型

- 触发条件：lighter_crime + custody_status=on_bail + 轻罪（最高刑拘役或管制）
- 论证主题1：维持取保论证——取保期间遵守规定/无违反行为
- 论证主题2：情节轻微论证——金额小/后果轻/偶犯/从犯等
- 论证主题3：不需判处刑罚论证——刑法相关规定（轻罪特有）
- 论证主题4：侦查终结从宽处理建议——请求侦查机关在侦查终结时依法从宽处理
- **禁止输出37天时间轴**（已取保不适用）
- **禁止输出阶梯方案**（取保已实现）

### 证据线索与申请（L3 类型卡组件6，所有类型共享）

1. [条件必填] 已掌握的对当事人有利的证据线索（不在场证明/无罪证据等），须说明证据类型+大致内容+可核实线索
2. [推荐] 申请调取证据（引用刑诉法第38条，含书证/物证/视听资料/电子数据）
3. [推荐] 同步录音录像审查建议（如存在刑讯逼供/诱供/指供疑点）
4. 如无证据线索，此段可省略

### 强制措施与羁押必要性（L3 类型卡组件7，所有类型必填，按 custody_status 路由）

**7a. 在押嫌疑人（custody_status=in_detention，默认）**：

1. [必填] 37天时间轴策略：拘留后1-7天（侦查初期：了解罪名+评估强制措施必要性）→7-30天（提请批捕前：提交不予批捕意见）→30-37天（审查批捕期：检察院7日内决定）
2. [必填] 羁押必要性分析：对照刑诉法第81条逮捕条件逐项反驳（无社会危险性+无串供可能+无在逃风险）
3. [必填] 变更强制措施阶梯方案：首选撤销案件/解除强制措施→次选取保候审（保证人+保证金方案）→再次监视居住
4. [推荐] 社会危险性评估反驳：无在逃风险/无串供可能/无危害社会风险

**7b. 已取保嫌疑人（custody_status=on_bail）**：

1. [必填] 维持取保论证：取保期间遵守规定/未违反取保义务/按时报到
2. [推荐] 无变更强制措施必要论证：取保措施已足以保证诉讼进行
3. [必填] 侦查终结从宽处理建议：建议侦查机关在侦查终结时依法从宽处理
4. **禁止37天时间轴+阶梯方案**（取保已实现，不适用）

**7c. 已批捕嫌疑人（custody_status=arrested）**：

1. [必填] 羁押必要性审查提示：批捕后可依第95条申请审查
2. [推荐] 批捕后救济途径说明：变更强制措施申请/羁押必要性审查申请

### 4a.2 组件序列渲染

> **内容结构单一事实源**（遵循 `base/governance/ssot-compiler.md` §17.26 D5）：
> 10 组件渲染序列见 `references/output-spec.md` §1A.3（组件渲染序列与段落级写作指引），含组件1-10的渲染方式和写作指引。
> **lawyer_draft 偏离声明**：L3 类型卡组件3 C-party-info（信息区表格）在本技能中偏离为开篇叙述段——辩护人/委托人/嫌疑人信息以自然叙述融入，不使用表格。

> 本文件**禁止重复定义**组件渲染序列和写作指引。LLM 按 output-spec.md §1A.3 的组件顺序使用 python-docx API 逐组件渲染。

### 4a.3 特殊格式注意

- **开篇叙述段（非信息区表格）**：辩护人/委托人/嫌疑人信息以自然叙述融入开篇段，不使用表格，详见 output-spec.md §6.1/§9
- 证据引用块：楷体小四号，整段缩进2字符，详见 output-spec.md §7
- 正文禁止表格：论证正文纯文字叙述，D1-D5 改逐项分段论证
- 页码：页脚居中，"– N –"格式，宋体四号
- 段落间距：按 output-spec.md "段落间距参数表"设置 before/after/line/lineRule
- 空段落禁令：章节间间距通过段前/段后间距属性实现，禁止插入空段落
- **lawyer_draft 不强制模板标签，但须设路标**：论证主体允许自然段落连续叙述，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）

## Phase 4b: Markdown 生成（O2）[L2]

> O2 为 LLM 直接输出的 Markdown 文本，用于预览和编辑。结构与 O1 内容一致但不含排版参数。

- 按 `references/output-spec.md` §1B Markdown 结构模板输出
- 辩护人/犯罪嫌疑人信息用列表格式（`- **字段名**：字段值`）
- 正文用自然段落，不包含字体/间距/缩进等排版参数
- 证据引用用 `> ` 引用块形式
- 法条索引用 `1. ` 编号列表
