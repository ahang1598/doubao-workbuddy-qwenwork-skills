**换算关系**：1行=560 twips=28磅；0.5行=280 twips=14pt

#### 空段落禁令

**禁止使用空 `<w:p>` 元素作为视觉分隔**。章节间间距完全通过 `before`/`after` 段间距属性实现，不得插入空段落。违反此禁令会导致：
1. DOCX 打印时产生非预期空白页
2. 违反 F-Strict "仅允许章节间最多1个空行" 规范
3. 与侦查机关/检察院格式审查标准不符

3. **打印规范**：F-Strict 排版参数确保打印后版面与公文标准一致

### §3 段落间距规则

#### §3.1 核心原则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制，禁止插入仅含空白字符的空段落。

#### §3.2 间距值（均为磅值 Pt）

| 元素 | 段前 | 段后 | 说明 |
|------|------|------|------|
| 标题 | 0 | 24pt | 标题后留较大间距 |
| 致送机关 | 0 | 6pt | 标题段后24pt已隔离，致送机关顶格紧接 |
| 开篇叙述段 | 6pt | 6pt | 辩护人/委托人/嫌疑人信息融入叙述 |
| 一级标题 | 12pt | 6pt | — |
| 二级标题 | 6pt | 3pt | — |
| 三级标题 | 3pt | 0 | — |
| 正文段落 | 0 | 0 | 28磅固定行距即为段落间隔 |
| 证据引用块 | 3pt | 3pt | 与上下文区分 |
| "此致" | 12pt | 0 | 结语到"此致"留空 |
| 落款第一行 | 12pt | 0 | 致送机关到落款留空 |
| 落款各行间 | 0 | 0 | 落款内部紧凑 |
| 附件清单标题 | 18pt | 6pt | 签名字后到附件清单留大间距 |

### §4 段落粒度规则

#### §4.1 核心原则

**一个段落 = 一个语义单元。** 禁止将多个语义单元塞入同一段落用 `<br/>` 换行。每个独立的事实陈述、论证要点、证据列举项、请求事项各占一个段落。

#### §4.2 拆分规则

| 语义单元类型 | 段落数 | 示例 |
|-------------|--------|------|
| 字段名-字段值对 | 1段/对 | `**律师**：张三` → 1段 |
| 前言 | 1段 | 前言整体1段（如过长可拆） |
| 案件基本事实叙述 | 1段/事实 | 每项独立事实1段 |
| 37天窗口信息 | 1段 | 独立段落，紧随事实 |
| 辩护意见论证点 | 1段/论证子项 | 每项论证独立1段 |
| 证据列举 | 1段/项证据 | 每项证据1段，用 Word 编号 |
| 请求事项 | 1段/项 | 每项请求1段，用 Word 编号 |
| 法条索引项 | 1段/法条 | 每条法条1段 |

#### §4.3 反例

```
❌ 错误（单段落挤多个含义）：
案件事实（一个段落）：
2025年4月1日拘留；2025年4月3日延长至7天；涉嫌三笔款项分别为20万/35万/32万。

✅ 正确（每项独立段落）：
2025年4月1日，王某某被XX公安分局以涉嫌职务侵占罪刑事拘留。
2025年4月3日，拘留期限延长至7天。
案件涉及三笔款项争议：第一笔20万元；第二笔35万元；第三笔32万元。
```

### §5 编号规则

#### §5.1 核心原则

**使用 Word 原生 List Numbering，禁止手动"1. ""2. ""3. "编号。** 手动编号在编辑/打印时容易出现数字不对齐、序号混乱问题。

#### §5.2 编号应用场景

| 场景 | 编号方式 | Word List | 层级 |
|------|----------|-----------|------|
| 请求事项 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 证据列举 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 法条索引 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 辩护意见子项 | "1. 2. 3." | `wdListSimpleNumbering` | 三级标题下 |

#### §5.3 python-docx 实现

```python
from docx.enum.text import WD_LIST_NUMBERING

# 添加编号段落
para = doc.add_paragraph("不予批准逮捕", style='List Number')
# 或手动设置
para.style = doc.styles['List Number']
```

### §6 区块分隔规则

#### §6.1 开篇叙述段（替代信息区表格）

> **lawyer_draft 偏离声明**：L3 类型卡 C-party-info 组件在本技能中偏离为开篇叙述段。辩护意见书属论证性文书，不以表格罗列信息，而以自然叙述融入开篇。

辩护人/委托人/嫌疑人信息以**自然叙述段落**呈现（仿宋三号，首行缩进2字符），不使用表格：

```
辩护人XXX，XXX律师事务所律师（执业证号XXX），接受犯罪嫌疑人XXX之
[关系]XXX的委托，担任XXX涉嫌XX罪一案侦查阶段的辩护人。辩护人依法
会见了犯罪嫌疑人XXX（刑诉法第三十九条），了解到其于XXXX年XX月XX日
被刑事拘留，至今已羁押XX日。因侦查阶段尚不能查阅全部案卷材料（刑诉法
第四十条），辩护人根据现有了解的情况，依据《中华人民共和国刑事诉讼法》
第三十四条、第三十八条之规定，提出如下辩护意见。
```

**必含信息**：律师姓名+律所+执业证号、委托人+与嫌疑人关系、嫌疑人姓名+涉嫌罪名、强制措施状态+羁押起始日期+已羁押天数、法条嵌入（第34/39/40条）。

#### §6.2 正文区块分隔

| 区块 | 分隔方式 |
|------|----------|
| 标题→致送机关 | 段后间距 24pt |
| 致送机关→开篇叙述段 | 段前间距 6pt |
| "此致"→致送机关名 | 紧接 |
| 落款→附件清单 | 段前间距 18pt |

- **禁止输出免责声明**：O1(.docx) 是提交给侦查机关的正式文书，不得包含"免责声明"——这等同于告诉检察官"这份意见可能是错的"。免责声明仅限 O2(Markdown) 编辑稿保留。

## 1A. DOCX 渲染规格（lawyer_draft 范式）

> **范式声明**：本技能遵循 `base/governance/ssot-compiler.md` §17.28——起草范式为 `lawyer_draft`（律师自主起草型）。output-spec 以**写作规则**为核心组织，而非固定标题槽位。正文允许自然段落连续叙述，不强制编号子标题（§17.28 D3）。

### 1A.0 动态结构体系总则

> **核心原则**：侦查阶段辩护意见书不存在"唯一正确"的论证结构。不同案件的事实强弱、辩护策略重心、致送机关不同，辩护意见书的结构和表述应当随之变化。本章提供**4种论证骨架 + 模块池 + 写作规则 + 文书声音 + 受众适配**五位一体的动态结构体系，替代原有的固定BLOCK模板。

#### 4种论证骨架速查表

| 骨架 | 适用场景 | 论证重心排序 | 触发条件 |
|------|----------|-------------|----------|
| **A. 不构成犯罪型** | 行为根本不构成犯罪/证据严重不足 | 证据不足论证 → 构成要件不符 → 批捕标准未达 → 强制措施 | `defense_direction=no_crime` |
| **B. 情节轻微型** | 可能构成犯罪但情节显著轻微 | 情节轻微 → 不需判处刑罚 → 社会危险性排除 → 取保可行 | `defense_direction=lighter_crime` |
| **C. 无逮捕必要型** | 可能构成犯罪但无逮捕必要 | 社会危险性排除 → 取保可行 → 羁押不必要 → 第81条逐项反驳 | `defense_direction=no_arrest_necessity` |
| **D. 罪名争议型** | 指控罪名有误/此罪彼罪之辩 | 指控罪名要件分析 → 应定罪名要件对比 → 事实匹配 → 批捕影响 | `defense_direction=dispute_qualification` |
| **E. 侦查终结从宽建议型** | 已取保+轻罪+侦查终结阶段 | 维持取保论证 → 情节轻微→不需判处刑罚 → 侦查终结从宽处理建议 | `defense_direction=lighter_crime` + `custody_status=on_bail` + 轻罪 |

> **可组合**：实务中常组合使用，如 A+C（"首先不构成犯罪，退一步即使构成也无逮捕必要"）、D+C（"罪名争议+无逮捕必要"）。组合时措辞须避免不利自认。

#### 策略参数（LLM自动推导，用户可覆盖）

| 参数 | 可选值 | 默认推导逻辑 |
|------|--------|-------------|
| `argument_density` | `brief` / `standard` / `detailed` | 事实复杂多论点→`detailed`；简单案→`brief`；默认→`standard` |
| `confrontation_level` | `mild` / `standard` / `strong` | 致送检察院→`strong`；致送公安→`mild`；默认→`standard` |
| `custody_status` | `in_detention` / `on_bail` / `arrested` | 用户提供或从输入推断；影响组件7强制措施段路由——已取保时37天时间轴+阶梯方案改为"维持取保论证+侦查终结从宽建议" |
| `fact_presentation` | `narrative` / `focus` | 事实复杂→`narrative`；单一争点→`focus`；默认→`focus` |

#### 模块池（LLM每次从各池选取，禁止固定使用同一变体）

**开篇叙述模块（3选1）**：
- M1 律师代理型（默认）："辩护人XXX，XXX律师事务所律师（执业证号XXX），接受犯罪嫌疑人XXX之[关系]XXX的委托，担任XXX涉嫌XX罪一案侦查阶段的辩护人。"
- M2 律所指派型："XXX律师事务所接受犯罪嫌疑人XXX近亲属XXX的委托，指派XXX律师担任XXX涉嫌XX罪一案的辩护人。"
- M3 简明委托型："辩护人XXX依法接受委托，担任XXX涉嫌XX罪一案辩护人。"

**结语模块（按致送机关区分，3+2选1）**：

> **致送公安（拘留期间）**：
> - GM1 审慎型："综上所述，辩护人认为……鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准。"
> - GM2 恳请型："综上，辩护人恳请贵局充分考虑上述意见，依法对XXX[撤销案件/变更强制措施]。本意见因侦查阶段接触证据有限，仅供参考。"

> **致送检察院（审查批捕期）**：
> - PM1 审慎型："综上所述，辩护人认为……鉴于侦查阶段尚不能查阅全部案卷，本意见仅供审查批捕时参考，以全案最终查明事实为准。"
> - PM2 恳请型："综上，辩护人恳请贵院充分考虑上述意见，依法对XXX不予批准逮捕。本意见因侦查阶段接触证据有限，仅供参考。"
> - PM3 策略型："综上所述，基于现有信息，辩护人认为[核心论点]。恳请贵院依法审查并采纳辩护意见。"

> **默认选择**：致送公安→GM1/GM2随机；致送检察院→PM1/PM2/PM3随机。禁止跨致送机关混用（如致送公安用"审查批捕时参考"）。

#### 受众适配规则

| 致送机关 | 核心关切 | 笔墨侧重 |
|----------|----------|----------|
| **区县公安（侦查阶段）** | 逃跑风险/再犯可能/是否需提请批捕 | 加重"无社会危险性""无逃跑风险"论证，以程序性论证为主，实体辩护留底牌 |
| **检察院（审查批捕7天）** | 是否符合批捕条件/有无逮捕必要/证据是否达"有证据证明有犯罪事实"标准 | 加重"不符合批捕条件""无逮捕必要"论证，可充分展开实体问题 |

### 1A.1 生成前内部判断流程（P4.0，嵌入Phase 4执行）

> **LLM内部判断，不暴露给用户。** 每次生成前必须按以下10步执行：

```
P4.0 结构选择（LLM内部判断）：
1. 识别辩护方向（no_crime/lighter_crime/no_arrest_necessity/dispute_qualification）
2. 识别羁押状态（in_detention/on_bail/arrested）——影响骨架路由（lighter_crime+on_bail+轻罪→骨架E）+ 组件7内容
3. 按触发条件匹配骨架（A→B→C→D→E，可组合如A+C/D+C）
4. 确定论证密度（argument_density）和对抗程度（confrontation_level）
5. 确定事实呈现方式（fact_presentation）
6. 从模块池随机选择开篇模块和结语模块（按致送机关区分，禁止与上次生成重复）
7. 选择文书声音（voice:cold/firm/data）
8. 识别受众适配（致送公安→程序性侧重/致送检察院→实体侧重）
9. 按骨架顺序组织论证段落（骨架决定论证主题顺序，不是固定标题顺序）
10. 按 custody_status 路由组件7内容（in_detention→37天时间轴+阶梯方案 / on_bail→维持取保+从宽建议 / arrested→羁押必要性审查提示）
```

### 1A.2 写作规则总则（lawyer_draft 核心）

> 遵循 `base/governance/ssot-compiler.md` §17.28 D3——lawyer_draft 范式的 output-spec 以写作规则为核心组织。

#### 论证张力四层递进

每段论证须遵循"行为定性→效果递进→法条支撑→价值判断"四层递进结构，避免平铺事实：

| 层次 | 说明 | 示例（证据不足段） |
|------|------|-------------------|
| 1. **行为定性** | 用定性词汇描述，非平铺事实 | "现有证据尚不足以形成完整的证据链条"（而非"证据不够"） |
| 2. **效果递进** | 从证据缺口上升到证明标准层面 | "关键事实缺乏独立证据印证，无法排除合理怀疑" |
| 3. **法条支撑** | 法条作为论证自然落点嵌入 | "……根据《刑事诉讼法》第八十一条，逮捕须'有证据证明有犯罪事实'，现有证据尚达不到此标准" |
| 4. **价值判断** | 以价值判断收尾 | "在此证据条件下提请批捕，不符合法定证明标准" |

**禁写模式**：

| 禁写模式 | 表现形式 | 为什么低水平 |
|----------|----------|-------------|
| 法条→事实→结论三段论 | "根据第X条，[法条原文]。本案[事实]。故不符合。" | 法条与事实分离，读感机械 |
| 平铺式累积 | "此外……同时……另外……还有……" | 无递进张力 |
| 空洞套话 | "证据不足""情节轻微" | 未具体化到个案事实 |

#### 行为定性规则

| 普通事实陈述 | 优秀行为定性 | 定性策略 |
|-------------|-------------|----------|
| "证据不够" | "现有证据**尚不足以形成**完整的证据链条" | 程度词"尚不足以"+ 范围词"完整" |
| "已赔偿谅解" | "案发后**已主动赔偿**被害人损失并**取得书面谅解**" | 态度副词"主动"+ 证据化"书面谅解" |
| "无前科" | "系**初犯、偶犯**，**此前无任何违法犯罪记录**" | 关键词升级"初犯偶犯"+ 范围扩大"任何" |
| "有固定住所" | "**长期**居住于XX市XX区，**与配偶及未成年子女**共同生活" | 时间深度"长期"+ 家庭纽带 |

#### 法条嵌入方式

法条须内嵌论述，**禁止独立成句前置**：
- ✅ 正确："……现有证据尚达不到'有证据证明有犯罪事实'的批捕标准（依据《刑事诉讼法》第八十一条）。"
- ❌ 错误："根据《刑事诉讼法》第八十一条之规定。现有证据不足。故不应批捕。"

#### 论证路标写法（AM-05b + AM-05c）

> 论证主体不是"纯连续段落"也不是"模板标签"，而是**以加粗陈述句路标分隔的论证流**。路标替代了模板标题，既保持连续叙述的有机感，又给办案人员清晰的结构锚点。路标写法直接决定文书是否达到顶级律师水准。

| # | 铁律 | 说明 |
|---|------|------|
| 1 | 路标是陈述句，不是标签 | 路标传递论证结论，而非标注"这是哪一段"。读完路标即知律师观点 |
| 2 | 路标含具体案情 | 出现本案特有金额/行为/量级，换一个案子这句路标即作废（"有机"含义） |
| 3 | 路标禁破折号（AM-05c） | 不用 `XX——YY` 格式，避免"标签:值"机械感 |
| 4 | 编号可选 | 可加 Word 原生 `一、`/`（一）` 编号，但编号后文字仍须是陈述句而非标签 |
| 5 | 标题连读成摘要 | 办案人员只扫路标即可串出结论链，扫正文只是确认细节 |

**正反对照（无逮捕必要为例）**：

| 写法 | 示例 | 评价 |
|------|------|------|
| ❌ 模板标签 | `## 强制措施与羁押必要性` | 任何案件都能用，零信息量 |
| ❌ 破折号式 | `社会危险性——已逐项排除` | 机械填表感 |
| ✅ 陈述句路标 | `**王某有固定住所、稳定工作、无前科，无社会危险性**` | 含具体案情+结论 |
| ✅ 陈述句路标 | `**第2笔35万元系正常业务往来，犯罪金额应减至20万元**` | 有事实依据 |

### 1A.3 组件渲染序列与段落级写作指引

> **组件清单单一事实源**：10组件清单见 L3 类型卡 `T-investigation-defense-opinion.md` §组件清单（本技能偏离：无独立案情概述段）。本节描述每个组件的渲染方式和写作指引。
>
> **信息区偏离声明**：L3 类型卡组件3 `C-party-info`（委托人/犯罪嫌疑人信息表格化）在本技能中**偏离为开篇叙述段**——辩护意见书不以表格罗列信息，而以自然叙述融入开篇。偏离理由：意见书/辩护词属论证性文书，顶级律师以叙述方式呈现身份信息，非申请书式填表。

#### 组件1-2：律所信头 + 标题

- [可选] 律所信头（C-law-firm-letterhead）
- [必填] 标题"关于XXX涉嫌XX罪一案的辩护意见"或"辩护意见书"（C-court-header），二号方正小标宋，居中加粗

#### 组件3：致送机关

- [必填] 致送机关顶格（"XX市公安局XX分局："或"XX市人民检察院："），置于标题之下、正文之前
- 拘留期间→公安机关；审查批捕7天→检察院

#### 组件4：开篇叙述段（替代信息区表格）

> **偏离声明**：L3 类型卡 C-party-info 组件在本技能中偏离为开篇叙述段。辩护人/委托人/嫌疑人信息以自然叙述融入，不使用表格。

**写作指引**：
- 起句：以"辩护人"开头（律师视角），不以"犯罪嫌疑人"开头
- 必含信息：律师姓名+律所+执业证号、委托人+与嫌疑人关系、嫌疑人姓名+涉嫌罪名、强制措施状态+羁押起始日期+已羁押天数
- 法条嵌入：委托依据（第34条）+会见权（第39条）+信息有限声明（第40条——侦查阶段无阅卷权）自然融入叙述
- 信息有限声明必须出现："因侦查阶段尚不能查阅全部案卷材料（刑诉法第四十条），本意见基于会见及有限信息出具"

**正文示例·M1律师代理型**：
> 辩护人XXX，XXX律师事务所律师（执业证号XXX），接受犯罪嫌疑人XXX之配偶XXX的委托，担任XXX涉嫌XX罪一案侦查阶段的辩护人。辩护人依法会见了犯罪嫌疑人XXX（刑诉法第三十九条），了解到其于XXXX年XX月XX日被刑事拘留，至今已羁押XX日。因侦查阶段尚不能查阅全部案卷材料（刑诉法第四十条），辩护人根据现有了解的情况，依据《中华人民共和国刑事诉讼法》第三十四条、第三十八条之规定，提出如下辩护意见。

#### 组件5：辩护意见论证主体（C-numbered-arguments）

> **偏离声明**：无独立案情概述段。侦查阶段律师无阅卷权（刑诉法第40条），案情概述缺乏案卷材料支撑，强制独立叙述只能照抄嫌疑人一面之词。顶级律师将案情事实直接融入各论证主题——"以论证带事实"（在论证每个主题时自然引入支撑该论点的事实信息），而非"先叙述后论证"。37天时间窗口信息及羁押状态自然融入第一论证主题。

> **lawyer_draft 核心区域**：论证主体以自然段落连续叙述展开，**不强制模板标签式编号子标题**（AM-05），但**必须以加粗陈述句路标分隔各论证主题**（AM-05b，禁止纯连续文字墙）。各骨架定义"必须论证哪些主题"，LLM自主拟定段落组织与路标表述。

##### 骨架A：不构成犯罪型

> **触发条件**：`defense_direction=no_crime`
> **论证主题清单**（必须论证，顺序可调，标题LLM自拟）：

| 论证主题 | 写作指引 | 禁写陷阱 |
|---------|----------|----------|
| 1. 证据不足论证 | 逐项论证哪些证据不足，针对批捕标准（"有证据证明有犯罪事实"）非定罪标准 | 禁止做完整证据分析（无阅卷权）；禁止"显然证据不足"断言 |
| 2. 构成要件不符论证 | 论证行为不符合犯罪构成要件 | 禁止确定断言"不构成犯罪"；宜用"据现有信息初步认为" |
| 3. 批捕标准未达论证 | 针对第81条"有证据证明有犯罪事实"标准论证 | 禁止混淆批捕标准与定罪标准 |

##### 骨架B：情节轻微型

> **触发条件**：`defense_direction=lighter_crime`
> **论证主题清单**：

| 论证主题 | 写作指引 | 禁写陷阱 |
|---------|----------|----------|
| 1. 情节轻微论证 | 金额小/后果轻/偶犯/从犯等，须有具体事实支撑。**致送公安时"点到为止"**——让公安了解核心要点即可（如酒精含量数值/行驶距离/认罪态度），充分实体论证策略留给检察院阶段（W15），避免暴露完整辩护底牌 | 禁止空洞套话"情节较轻"；致送公安禁止展开完整实体论证 |
| 2. 不需判处刑罚论证 | 刑法相关规定引用 | 禁止与"不构成犯罪"同时主张 |
| 3. 社会危险性排除+取保可行 | 逐项排除+保证方式建议 | 禁止过场式列举 |

##### 骨架C：无逮捕必要型

> **触发条件**：`defense_direction=no_arrest_necessity`
> **论证主题清单**：

| 论证主题 | 写作指引 | 禁写陷阱 |
|---------|----------|----------|
| 1. 社会危险性排除 | 固定住所+稳定工作+无前科+家庭纽带，逐项排除 | 禁止D1-D5表格；禁止过场式列举 |
| 2. 取保候审可行 | 保证人/保证金方案 | 保证方式须明确 |
| 3. 羁押不必要论证 | 对照第81条逐项反驳 | 禁止"继续羁押违法"断言 |

##### 骨架D：罪名争议型

> **触发条件**：`defense_direction=dispute_qualification`
> **论证主题清单**：

| 论证主题 | 写作指引 | 禁写陷阱 |
|---------|----------|----------|
| 1. 指控罪名要件分析 | 拆解指控罪名的构成要件 | 禁止确定断言"应定XX罪" |
| 2. 应定罪名要件对比 | 对比应定罪名的构成要件 | 宜用"据现有信息初步认为更符合" |
| 3. 事实匹配论证 | 事实与应定罪名要件匹配 | 禁止引用案卷材料 |
| 4. 批捕影响论证 | 较轻罪名的社会危险性评价+批捕必要性降低 | — |

##### 骨架E：侦查终结从宽建议型

> **触发条件**：`defense_direction=lighter_crime` + `custody_status=on_bail` + 轻罪（如危险驾驶罪、轻微盗窃等最高刑拘役或管制之罪）
> **适用场景**：嫌疑人已被取保候审，37天时间窗口已过，当前处于侦查终结阶段，辩护目标从"不批捕"转变为"侦查终结时从宽处理建议"
> **论证主题清单**：

| 论证主题 | 写作指引 | 禁写陷阱 |
|---------|----------|----------|
| 1. 维持取保论证 | 说明取保期间遵守规定/无违反行为，论证无变更强制措施必要 | 禁止37天时间轴（已取保不适用）；禁止阶梯方案（取保已实现） |
| 2. 情节轻微论证 | 金额小/后果轻/偶犯/从犯等，须有具体事实支撑 | 禁止空洞套话"情节较轻" |
| 3. 不需判处刑罚论证 | 刑法相关规定引用（轻罪特有：危险驾驶罪拘役、盗窃罪数额较大但退赃退赔等） | 禁止与"不构成犯罪"同时主张 |
| 4. 侦查终结从宽处理建议 | 请求侦查机关在侦查终结时依法从宽处理（如撤销案件/不移送审查起诉/移送时建议从宽） | 禁止确定断言"应当不移送"；宜用"建议在侦查终结时依法从宽处理" |

> **与骨架B的区别**：骨架B针对在押嫌疑人（含37天时间轴+阶梯方案），骨架E针对已取保嫌疑人（无需37天时间轴+维持取保替代阶梯方案+侦查终结收尾而非批捕应对）。

#### 组件6：证据线索与申请段

**写作指引**：
- [条件必填] 已掌握的对当事人有利的证据线索（不在场证明/无罪证据等），须说明证据类型+大致内容+可核实线索
- [推荐] 申请调取证据（引用刑诉法第38条，含书证/物证/视听资料/电子数据）
- [推荐] 同步录音录像审查建议（如存在刑讯逼供/诱供/指供疑点）
- 如无证据线索，此段可省略

#### 组件7：强制措施与羁押必要性段（必填，按 custody_status 路由）

> **路由规则**：组件7的内容结构由 `custody_status` 参数（§1A.0 策略参数）控制。LLM须先判定 custody_status，再按路由输出对应内容。

##### 7a. 在押嫌疑人（custody_status=in_detention，默认）

**写作指引**：
- [必填] 37天时间轴策略：拘留后1-7天（侦查初期）→7-30天（提请批捕前）→30-37天（审查批捕期）三阶段布局
- [必填] 羁押必要性分析：对照刑诉法第81条逮捕条件逐项反驳
- [必填] 变更强制措施阶梯方案：首选撤销案件/解除强制措施→次选取保候审→再次监视居住
- [推荐] 取保候审保证方式（保证人/保证金）
- [推荐] 社会危险性评估反驳

##### 7b. 已取保嫌疑人（custody_status=on_bail）

**写作指引**：
- [必填] 维持取保论证：说明取保期间嫌疑人遵守规定/未违反取保义务/按时报到
- [推荐] 无变更强制措施必要论证：取保措施已足以保证诉讼进行
- [必填] 侦查终结从宽处理建议：建议侦查机关在侦查终结时依法从宽处理
- **禁止37天时间轴**（已取保，37天窗口已过）
- **禁止阶梯方案**（取保已实现，无需"撤销→取保→监居"阶梯）

##### 7c. 已批捕嫌疑人（custody_status=arrested）

**写作指引**：
- [必填] 羁押必要性审查提示：批捕后可依据刑诉法第95条申请羁押必要性审查
- [推荐] 批捕后救济途径说明：变更强制措施申请/羁押必要性审查申请
- 此场景超出本技能核心范围（批捕后辩护意见），内容从简——提示救济途径即可

#### 组件8：结论与请求段

**写作指引**：
- 结语必须以加粗"**综上所述**"开头
- 严格按请求总结，禁止不利自认
- 信息有限声明按致送机关区分：
  - **致送公安**："鉴于侦查阶段接触证据有限，本意见仅供参考，以全案最终查明事实为准"
  - **致送检察院**："鉴于侦查阶段尚不能查阅全部案卷，本意见仅供审查批捕时参考，以全案最终查明事实为准"
- 请求事项：不予批准逮捕/变更强制措施/撤销案件等，取保候审建议并入请求
- **禁止跨致送机关混用声明**——致送公安不得出现"审查批捕时参考"

#### 组件9-10：落款 + 日期 + 附件

- [必填] "辩护人：" + 律师签名 + 律所 + 执业证号（右对齐）
- [必填] 出具日期（阿拉伯数字格式）
- 附件清单（签名后独立列出，不参与正文编号）

| D11 | **lawyer_draft 不强制模板标签，但须设路标** | 正文允许自然段落连续叙述，不强制"一、案件事实"等模板标签式编号子标题（AM-05），但论证主题须以加粗陈述句路标分隔（AM-05b，禁止纯连续文字墙）；路标禁止破折号（AM-05c）。O1 docx 中路标=加粗首句或独立加粗行（仿宋加粗），可选 Word 原生编号 |
| D12 | **禁止确定断言语气** | 侦查阶段信息有限，宜用"据了解""初步认为"等审慎表述，禁止"显然""毫无疑问""可以确定"等断言 |
| D13 | **禁止引用案卷材料** | 侦查阶段辩护意见不得引用案卷材料/提"查阅案卷后"/做完整的证据分析（律师在侦查阶段无阅卷权） |
| D14 | **"综上所述"必填** | 结语段必须以加粗"**综上所述**"开头，后接辩护意见要点总结 |
| D15 | **DOCX禁止Markdown标题泄漏，但允许加粗路标** | O1(.docx)正文中禁止渲染`## `或`### `级Markdown标题（如"## 强制措施与羁押必要性""## 请求事项""## 结语"等孤立标题行）。这些模板标签式标题是O2 Markdown预览的结构锚点，O1须以**加粗陈述句路标**（AM-05b）替代——如"**王某有固定住所、稳定工作、无前科，无社会危险性**"作为独立加粗行或主题段落首句。section间用段前间距12pt分隔，禁止出现孤立的模板标签标题行+大片空白 |

## 1B. Markdown 结构模板

> 本节描述 O2(Markdown) 的结构。Markdown 版本为纯文本，不含排版参数，用于快速预览和编辑。**O2 同样遵循 lawyer_draft 范式**（§17.28 D3）：以开篇叙述段代替信息区罗列，论证主体允许自然段落连续叙述，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b），按骨架 A/B/C/D 组织。

### 1B.0 开篇叙述段（所有骨架共享）

> **替代信息区表格**：辩护人/委托人/嫌疑人信息以自然叙述融入开篇段，不使用列表/表格（与 §1A D7 / §6.1 / §9 一致——意见书属论证性文书，顶级律师以叙述呈现身份信息）。

```markdown
# 关于XXX涉嫌XX罪的辩护意见书

XX市公安局XX分局：

辩护人XXX，XXX律师事务所律师（执业证号XXX），接受犯罪嫌疑人XXX之[关系]XXX的委托，担任XXX涉嫌XX罪一案侦查阶段的辩护人。辩护人依法会见了犯罪嫌疑人XXX（刑诉法第三十九条），了解到其于XXXX年XX月XX日被刑事拘留，至今已羁押XX日。因侦查阶段尚不能查阅全部案卷材料（刑诉法第四十条），辩护人根据现有了解的情况，依据《中华人民共和国刑事诉讼法》第三十四条、第三十八条之规定，提出如下辩护意见。
```

### 1B.1 骨架A（不构成犯罪型）论证主体

> 论证主体须以加粗陈述句路标（AM-05b）分隔各论证主题——路标为含具体案情、无破折号（AM-05c）的完整陈述句；禁止模板标签式标题（AM-05）。下列为论证主题指引（非输出标题），LLM 将每个主题转化为一句陈述句路标。
