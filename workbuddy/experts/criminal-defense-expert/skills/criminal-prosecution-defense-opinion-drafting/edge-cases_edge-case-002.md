# 边界示例002：程序辩护+实体辩护交叉场景

> criminal-prosecution-defense | 边界示例 | defense_direction: comprehensive | C档
> 版本: v3.2.0 | 2026-06-13 新增
> 场景：多罪名案件——程序辩护（非法证据排除）+实体辩护（部分罪名不构成犯罪）组合

## 输入

```markdown
当事人：陈某
涉嫌罪名：受贿罪（第1笔20万）+ 行贿罪（第2笔15万）
辩护方向：comprehensive（综合性辩护）
案件事实：陈某被指控受贿20万和行贿15万。第1笔受贿仅有行贿人单方证言，无其他证据印证；第2笔行贿系正常业务招待，不构成行贿罪。第1笔受贿的讯问笔录存在疲劳审讯嫌疑（连续讯问18小时，无休息记录）。
辩护要点：
1.第1笔受贿——证据不足（孤证）+非法证据排除（疲劳审讯）
2.第2笔行贿——不构成犯罪（正常业务招待）
3.避免"拆东墙补西墙"——为受贿辩护时不构成对行贿的自认
```

## 预期输出

```markdown
# 关于陈某涉嫌受贿罪、行贿罪的辩护意见书

XX市XX区人民检察院：

辩护人XXX，XX律师事务所律师，执业证号XXX，系犯罪嫌疑人陈某涉嫌受贿罪、行贿罪一案的辩护人。辩护人已查阅全部侦查卷宗，经认真研究，现提出如下辩护意见：

一、事实方面

起诉意见书认定陈某两项犯罪事实，辩护人分述如下：

（一）关于受贿事实（第1笔20万元）

起诉意见书认定陈某收受XX公司法定代表人刘某20万元。辩护人认为该事实认定证据不足：

1.该笔受贿仅有行贿人刘某的证言（卷2第15-18页），无银行转账记录、无资金来源证明、无其他知情人员证言佐证，属于孤证。

2.陈某自始至终否认收受过该笔款项（卷1第22-25页），且其银行账户在该时段无异常大额存入（卷3第33-35页，银行流水）。

（二）关于行贿事实（第2笔15万元）

起诉意见书认定陈某向XX部门负责人行贿15万元。辩护人认为该行为不构成行贿罪：

1.该笔款项系正常业务招待费用支出，有公司财务报销凭证（卷3第56-58页）及费用明细（卷3第60页）佐证。

2.根据《刑法》第389条，行贿罪要求"为谋取不正当利益，给予国家工作人员以财物"。本案中，陈某的公司与XX部门系正常业务合作关系，所涉项目均经公开招投标程序（卷3第65-70页），不存在谋取不正当利益的情形。

二、证据方面

（一）受贿罪证据不足

1.如前所述，受贿事实仅有行贿人刘某的单方言词证据（卷2第15-18页），缺乏客观证据印证。根据《刑事诉讼法》第55条"证据确实、充分"的证明标准，孤证不能定案。

2.行贿人刘某与陈某所在公司存在商业竞争关系（卷3第42页，工商登记信息），其证言可信性存疑，存在诬告陷害的动机。

（二）受贿罪讯问程序违法

1.根据讯问笔录记载（卷1第22-25页），对陈某的讯问持续18小时（2025年3月5日8:00至3月6日2:00），期间无休息记录、无饮食记录。

2.根据《刑事诉讼法》第118条及《公安机关办理刑事案件程序规定》第198条，讯问犯罪嫌疑人应当保证其必要的休息和饮食时间。连续讯问18小时无休息，属于疲劳审讯，相关讯问笔录的合法性存疑。

3.辩护人申请排除该时段讯问笔录（具体线索：卷1第22-25页，讯问时间连续18小时无中断），并建议贵院调取讯问同步录音录像予以核实。

三、适用法律方面

（一）受贿罪——证据不足

退一步讲，即便暂不考虑非法证据排除问题，现有合法证据亦不足以证明陈某收受20万元的事实。根据《刑事诉讼法》第175条第4款，经补充侦查后证据仍不足的，应当作出不起诉决定。

（二）行贿罪——不构成犯罪

根据《刑法》第389条，行贿罪的构成要件要求"为谋取不正当利益"。陈某的行为系正常业务招待，所涉项目均经公开招投标，不符合行贿罪的构成要件。根据《刑事诉讼法》第177条第1款，不构成犯罪的，应当作出不起诉决定。

四、定罪量刑方面

鉴于受贿罪证据不足、行贿罪不构成犯罪，辩护人分别建议：

1.关于受贿罪：现有证据不足，且存在非法证据排除事由。建议贵院对受贿罪部分作出存疑不起诉决定。

2.关于行贿罪：不构成犯罪，建议贵院依法作出法定不起诉决定。

如果贵院对受贿罪部分认为仍需进一步审查，辩护人建议：如认定受贿20万元，陈某系初犯，且愿意退赃，建议从宽处理。

综上，受贿罪证据不足且存在程序违法事由，行贿罪不构成犯罪。根据《刑事诉讼法》第175条第4款、第177条第1款之规定，建议贵院分别作出存疑不起诉和法定不起诉决定。

此致
XX市XX区人民检察院

辩护人：XXX律师
XX律师事务所
2025年6月13日

附件清单
1. 法条索引：《刑法》第389条；《刑事诉讼法》第55条、第118条、第175条第4款、第177条第1款
2. 证据材料：银行流水（卷3第33-35页）、公司财务凭证（卷3第56-58页）、招投标文件（卷3第65-70页）、工商登记信息（卷3第42页）
3. 非法证据排除线索：讯问笔录（卷1第22-25页，连续18小时无休息记录）
```
