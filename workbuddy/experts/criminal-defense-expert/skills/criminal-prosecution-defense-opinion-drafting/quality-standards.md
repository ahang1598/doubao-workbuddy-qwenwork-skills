# 质量标准：审查起诉辩护意见书

> 定义审查起诉辩护意见书的质量评价维度和标准

## 一、六维评价体系

| 维度 | 权重 | 优秀标准 | 合格标准 | 不合格 |
|------|------|---------|---------|--------|
| 不起诉类型准确 | 25% | 三类不起诉区分精准 | 类型基本正确 | 混淆不起诉类型 |
| 证据论证 | 20% | 逐项论证证据不足/充分 | 有证据论证 | 无证据分析 |
| 法条适用 | 20% | 不起诉法条与类型完全匹配 | 法条引用正确 | 法条引用错误 |
| 认罪认罚 | 15% | 单独论述从宽建议 | 已提及认罪认罚 | 忽略认罪认罚 |
| 致送机关 | 10% | 人民检察院 | 人民检察院 | 致送法院 |
| 表达精炼 | 10% | 3-5页、重点突出 | 表达规范 | 冗长混乱 |

## 二、特有质量检查项

| 检查项 | 阻断/警告 | 说明 |
|--------|----------|------|
| 三类不起诉区分 | 阻断 | 法定/酌定/存疑论证逻辑不同 |
| 存疑不起诉须经退补 | 阻断 | 须经补充侦查程序 |
| "犯罪情节轻微"≠"显著轻微" | 阻断 | 前者第177条第2款，后者第16条 |
| 存疑不起诉与认罪认罚不得矛盾 | 阻断 | 不能既说证据不足又认罪 |
| 刑诉法第173条已引用 | 阻断 | 审查起诉阶段听取辩护意见核心法条（2018修正版编号，旧版第170条已改为第173条） |
| 致送检察院 | 阻断 | 不得致送法院 |
| 无罪推定 | 阻断 | 无"罪犯"等表述 |
| 法定不起诉须对应法定情形 | 警告 | 须列举具体的第16条情形 |
| 致送"XX人民检察院" | 阻断 | 不得致送人民法院 |
| 称呼"检察官" | 阻断 | 不得写"审判长/审判员" |
| 前言声明"已查阅全部侦查卷宗" | 警告 | 审查起诉阶段已可阅卷 |
| F13正文无表格 | 阻断 | DOCX论证正文禁止表格 |
| F14 O1无免责声明 | 阻断 | O1(.docx)正式提交稿不含免责声明 |
| F15 "应当"/"可以"不起诉区分 | 阻断 | 法定/存疑=应当，酌定=可以 |
| F17 V3与V4不得同时主张 | 阻断 | 存疑不起诉+认罪认罚矛盾 |
| F18 O1致送机关正确 | 阻断 | 致送"XX人民检察院"非法院 |
