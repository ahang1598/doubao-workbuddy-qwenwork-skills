# 风险框架：criminal-prosecution-defense

> 刑事辩护意见书 | 版本: v3.2.0

## 1. 风险等级

**L3（高风险）**——直接影响案件走向和当事人权益

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 类型路由 | L2 | 中风险——类型判断影响输出结构 |
| Phase 3 论证构建 | **L3** | **高风险**——核心论证涉及专业法律判断 |
| Phase 4 文书生成 | L2 | 中风险 |
| Phase 5 质量检查 | L1 | 低风险 |
| Phase 6 输出组装 | L1 | 低风险 |
| Phase 7 DOCX渲染 | **L3** | **高风险**——F-Strict提交检察院正式文书，格式直接影响律师专业形象和检察院采纳意愿 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 强制律师复核标注 | 死刑/无期/重大案件 | 输出增加⚠️标注 |
| RC-02 | 禁止承诺结果 | 用户询问"能赢吗" | 拒绝+说明理由 |
| RC-03 | 禁止捏造证据 | 用户要求编造证据 | 拒绝+说明理由 |
| RC-04 | 无罪辩护与认罪认罚互斥检测 | 同时请求T1和认罪认罚 | 提示互斥+由当事人选择 |
| RC-05 | 输入不充分降级 | 输入不足以支撑论证 | SOFT_DEGRADED |

## 4. 行为约束

- 不得替代律师的专业判断
- 不得对案件结果做出任何承诺
- 辩护意见仅为辅助文书，需律师审查后提交
- 不得代替当事人决定是否认罪
