## 1. 页面布局（含 DXA 精确值）

### 1.1 纸张

| 右边距 | 2.6cm | 1474 | GB/T 9704-2012 |

| 参数 | 标准值 | DXA 值 | 说明 |

## 3. 段落间距规则

### 3.1 核心原则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制，禁止插入仅含空白字符的空段落。

### 3.2 间距值（均为磅值 Pt）

| 元素 | 段前 | 段后 | 说明 |
|------|------|------|------|
| 标题 | 0 | 24pt | 标题后留较大间距 |
| 节标题（"辩护人信息"等） | 12pt | 6pt | — |
| 信息区行（字段名+字段值） | 0 | 0 | 同一信息区内各行紧凑 |
| 信息区块间（辩护人→嫌疑人） | 6pt | 0 | 区块间用间距分隔 |
| 致送机关 | 6pt | 0 | 信息区结束后到致送机关 |
| 一级标题 | 12pt | 6pt | — |
| 二级标题 | 6pt | 3pt | — |
| 三级标题 | 3pt | 0 | — |
| 正文段落 | 0 | 0 | 28磅固定行距即为段落间隔 |
| 证据引用块 | 3pt | 3pt | 与上下文区分 |
| "此致" | 12pt | 0 | 结语到"此致"留空 |
| 落款第一行 | 12pt | 0 | 致送机关到落款留空 |
| 落款各行间 | 0 | 0 | 落款内部紧凑 |
| 附件清单标题 | 18pt | 6pt | 签名后到附件清单留大间距 |

## 4. 段落粒度规则

### 4.1 核心原则

**一个段落 = 一个语义单元。** 禁止将多个语义单元塞入同一段落用 `<br/>` 换行。

### 4.2 拆分规则

| 语义单元类型 | 段落数 | 示例 |
|-------------|--------|------|
| 字段名-字段值对 | 1段/对 | `**律师**：张三` → 1段 |
| 阅卷情况说明 | 1段 | 前言中说明已阅卷 |
| 案件基本事实叙述 | 1段/事实 | 每项独立事实1段 |
| 辩护意见论证点 | 1段/论证子项 | 每项论证独立1段 |
| 不起诉类型论证 | 1-3段/类型 | 法定/酌定/存疑各有独立论证段落 |
| 认罪认罚从宽建议 | 1段 | 独立论述 |
| 请求事项 | 1段/项 | 每项请求1段，用Word编号 |
| 法条索引项 | 1段/法条 | 每条法条1段 |

## 5. 编号规则

### 5.1 核心原则

**使用 Word 原生 List Numbering，禁止手动"1. ""2. ""3. "编号。**

### 5.2 正文编号体系

| 层级 | 编号方式 | 字体 | 示例 |
|------|----------|------|------|
| 一级（章节标题） | "一、"、"二、"、...顺延 | 黑体三号 | **一、案件基本情况** |
| 二级（论证子项） | "（一）"、"（二）"、... | 楷体三号加粗 | **（一）证据不足论证** |
| 三级（具体要点） | "1. ""2. ""3. "（Word List） | 仿宋三号 | 1. 监控录像模糊无法辨认 |
| 请求事项 | "1. ""2. ""3. "（Word List） | 仿宋三号 | 1. 建议贵院依法作出不起诉决定 |

### 5.3 信头不参与编号体系

致送机关"XX人民检察院："为信头，不参与正文编号。正文首个标题硬编码为"一、"。

## 6. 区块分隔规则

### 6.1 信息区表格化

辩护人信息和犯罪嫌疑人信息区改用**无边框两列表格**：

```
┌────────────────────────────────────────────┐
│ 辩护人信息                                 │ ← 节标题（黑体三号加粗，左对齐）
├────────────────────────────────────────────┤
│ 律师        │ 张三                         │
│ 律所        │ XX律师事务所                 │
│ 执业证号    │ XXX                          │
│ 联系电话    │ 138-XXXX-XXXX                │
│ 通讯地址    │ XX市XX区XX路XX号             │
│ 日期        │ 2025年4月10日                │
├────────────────────────────────────────────┤
│ 犯罪嫌疑人信息                             │ ← 节标题
├────────────────────────────────────────────┤
│ 姓名        │ 赵某                         │
│ 涉嫌罪名    │ 受贿罪（《刑法》第385条）    │
│ 强制措施    │ 逮捕，2025年3月1日           │
│ 羁押地点    │ XX市XX区看守所               │
│ 案件阶段    │ 审查起诉阶段                 │
└────────────────────────────────────────────┘
```

### 6.2 表格样式

| 参数 | 值 |
|------|-----|
| 边框 | **无边框**（`w:val="none"`） |
| 列宽 | 左列 25%（字段名列），右列 75%（字段值列） |
| 字段名列字体 | 仿宋_GB2312 三号 **加粗**，左对齐 |
| 字段值列字体 | 仿宋_GB2312 三号，左对齐 |
| 节标题行 | 合并左右列，黑体三号加粗 |

### 6.3 正文区块分隔

| 区块 | 分隔方式 |
|------|----------|
| 标题→信息区 | 段后间距 24pt |
| 信息区→致送机关 | 段前间距 6pt |
| 致送机关→前言 | 紧接（无额外间距） |
| "此致"→致送机关名 | 紧接 |
| 落款→附件清单 | 段前间距 18pt |

## 7. 四类不起诉论证适配

### 7.1 变体与请求措辞

| 变体 | 不起诉类型 | 规范性质 | 请求措辞 | 论证重点 |
|------|-----------|---------|---------|---------|
| V1 | 法定不起诉（第177条第1款） | "应当" | "建议贵院依法作出不起诉决定" | 不构成犯罪/已过时效等法定情形逐项对应 |
| V2 | 酌定不起诉（第177条第2款） | "可以" | "恳请贵院考虑作出酌定不起诉决定" | 犯罪情节轻微+不需要判处刑罚 |
| V3 | 存疑不起诉（第175条第4款） | "应当" | "建议贵院对证据不足部分作存疑不起诉决定" | 逐项论证证据不足+不能排除合理怀疑 |
| V4 | 认罪认罚从宽 | — | "建议贵院在量刑时依法从宽处理" | 认罪认罚意愿+从宽幅度 |

### 7.2 不起诉类型标记约束

- **V1 法定不起诉**："应当"不起诉——检察院无裁量余地，请求措辞用"建议"而非"恳请"
- **V2 酌定不起诉**："可以"不起诉——检察院有裁量权，请求措辞用"恳请"
- **V3 存疑不起诉**：须经补充侦查程序，"应当"不起诉——同V1用"建议"
- **V4 认罪认罚**：不单独请求不起诉，作为从宽因素融入V2

## 9. 特殊格式规则

### 9.1 标题

```
文书标题居中，二号方正小标宋简体加粗，独占一行。
标题格式："审查起诉辩护意见书"
或"关于[嫌疑人姓名]涉嫌[罪名]的辩护意见书"
```

### 9.2 致送机关

```
"XX人民检察院："顶格写，不加缩进。
冒号后不换行，前言段落紧接其后。
**区别于一审辩护词**：致送"人民检察院"而非"人民法院"。
```

### 9.3 前言格式

```
"[律师姓名]，[律所名称]律师，系犯罪嫌疑人[姓名]涉嫌[罪名]一案
的辩护人。本辩护人已于审查起诉阶段查阅全部侦查卷宗，现依据
《中华人民共和国刑事诉讼法》第173条之规定，提出如下辩护意见："
```

### 9.4 "此致"与致送机关

```
"此致"：首行缩进2字符
致送机关全称：另起一行，顶格
"XX人民检察院"（非"XX人民法院"）
"此致"与致送机关名之间不插空行
```

### 9.5 落款签名区

```
辩护人：XXX律师        （右对齐）
XXX律师事务所           （右对齐）
2025年4月10日           （右对齐，阿拉伯数字）
```

### 9.6 附件清单

```
签名后独立列出，不参与正文编号体系。
"附件清单"：仿宋三号加粗，左对齐，无缩进，段前18pt。
附件项：仿宋三号，首行缩进2字符，手动编号。
包含：法条索引/证据清单/案例参考等程序性附属信息。
```

## 10. 审查起诉阶段特有约束

### 10.1 阅卷情况声明

审查起诉阶段律师可查阅全部侦查卷宗，前言必须声明"已查阅全部侦查卷宗"（区别于侦查阶段不能阅卷）。

### 10.2 证据引用

- 可引用案卷中已有证据（侦查卷宗页码标注）
- 不得声称自行调取的新证据（审查起诉阶段律师调查取证权有限）

### 10.3 致送机关约束

| 正确 | 错误 | 理由 |
|------|------|------|
| XX人民检察院 | XX人民法院 | 审查起诉阶段致送检察院 |
| 检察官 | 审判长/审判员 | 检察院人员称呼 |
| 贵院（检察院） | 法庭 | 尚未进入审判阶段 |

### 10.4 O1 正式提交稿约束

- **禁止输出免责声明**：O1(.docx) 是提交检察院的正式文书，不得包含"免责声明"。免责声明仅限 O2(Markdown) 编辑稿。
- **禁止正文表格**：辩护意见论证正文中禁止使用任何表格。不起诉类型对照表等必须改为逐项分段叙述。
- **不起诉类型严格区分**：法定("应当")/酌定("可以")/存疑("应当"+"退补")不得混淆。

## 11. 禁止事项

| # | 禁止项 | 正确做法 |
|---|--------|----------|
| F1 | 纸张非 A4（如 US Letter） | 纸张必须设置为 A4（210mm×297mm） |
| F2 | 用空行分段 | 用段前/段后间距控制段落间距 |
| F3 | 多个语义单元挤在同一段落 | 每个语义单元独立为一个段落 |
| F4 | 手动"1. 2. 3."编号 | 使用 Word 原生 List Numbering |
| F5 | 用"———"字符串模拟分隔线 | 使用 Word 段落底边框 |
| F6 | `@image`、`![xxx](xxx)` 等图片/占位符 | 辩护意见书是纯文字文书 |
| F7 | 段落缩进为 0 或随机值 | 正文统一首行缩进 2 字符 |
| F8 | 信息区用纯文本分行 | 使用无边框表格 |
| F9 | "此致"—空行—"致送机关名" | "此致"与致送机关名之间不插空行 |
| F10 | 落款签名无右对齐 | 落款区全部右对齐 |
| F11 | 证据列举混在正文段落中 | 证据独立成段，楷体小四号，整段缩进2字符 |
| F12 | 致送"人民法院" | 审查起诉阶段致送"人民检察院" |
| F13 | 正文论证中使用表格 | 辩护意见正文纯文字叙述 |
| F14 | O1(.docx) 包含"免责声明" | O1 为正式提交稿，删除免责声明 |
| F15 | 混淆"应当"与"可以"不起诉 | 法定/存疑="应当"，酌定="可以" |
| F16 | 存疑不起诉未论证退补程序 | V3 须说明补充侦查情况 |
| F17 | V3 存疑不起诉+认罪认罚同时主张 | 证据不足≠认罪认罚，二者不得同时主张 |
| F18 | O1致送机关写"审判长/法官" | 审查起诉阶段致送"XX人民检察院" |
