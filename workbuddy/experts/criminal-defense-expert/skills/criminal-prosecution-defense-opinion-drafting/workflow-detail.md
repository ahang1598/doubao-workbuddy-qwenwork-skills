# 工作流详情：criminal-prosecution-defense

> 刑事辩护意见书 | 版本: v3.2.0 | format_seriousness: F-Strict
> defense_direction枚举: innocent / lesser_crime / procedural / mitigated / comprehensive

## Phase 1: 输入验证

- 检查5个必填字段
- 验证 defense_direction 枚举值（innocent / lesser_crime / procedural / mitigated / comprehensive）
- 检查 hard_reject 条件
- 信息不足 → 交互补全（最多3轮）

## Phase 2: 类型路由与信息结构化 [L2]

### 2.1 不起诉类型路由（V1-V4）

| 路由 | 不起诉类型 | 法条 | "应当/可以" | 请求措辞 |
|------|-----------|------|------------|---------|
| V1 | 法定不起诉 | 第177条第1款 | 应当 | "建议贵院依法作出不起诉决定" |
| V2 | 酌定不起诉 | 第177条第2款 | 可以 | "恳请贵院考虑作出酌定不起诉决定" |
| V3 | 存疑不起诉 | 第175条第4款 | 应当 | "建议对证据不足部分作存疑不起诉决定" |
| V4 | 认罪认罚从宽 | 第15条+第173条第2-3款 | — | "建议在量刑时依法从宽处理" |

### 2.2 信息提取

- 从自然语言中提取结构化辩护要点
- 识别不起诉类型
- 评估输入充分度 → 确定输出档次

## Phase 3: 论证构建 [L3]

### V1 法定不起诉论证

1. 明确法定情形（第16条/不构成犯罪）
2. 事实→法条→结论逐项对应
3. "应当"不起诉，检察院无裁量余地

### V2 酌定不起诉论证

1. 犯罪情节轻微论证
2. 不需要判处刑罚/免除刑罚依据
3. "可以"不起诉，检察院有裁量权
4. 须区分"情节轻微"≠"情节显著轻微"（后者第16条）

### V3 存疑不起诉论证

1. 逐项论证哪些证据不足
2. 不能达到"排除合理怀疑"标准
3. 须经补充侦查程序（1-2次）
4. "应当"不起诉

### V4 认罪认罚从宽论证

1. 认罪认罚意愿
2. 法定/酌定从轻情节
3. 从宽幅度建议

## Phase 4: 文书生成 [L2]

- 按类型路由的输出结构组装
- 致送机关：XX人民检察院
- 法条引用嵌入（第37/40/173/177条）
- 论证逻辑链条检查

## Phase 5: 质量检查 [L1]

| 检查项 | 标准 |
|--------|------|
| 禁用词检查 | 无绝对化表述 |
| 法条引用 | 第37/40/173条必须出现 |
| 论证完整度 | 符合类型最低要求 |
| 无罪推定 | 无有罪预设 |
| 致送机关 | 为"XX人民检察院" |
| 不起诉措辞 | V1/V3="建议"，V2="恳请" |

## Phase 6: Markdown输出组装 [L1]

- 生成 O2 编辑稿（Markdown）
- 含免责声明（仅限O2编辑稿）
- 附法条索引+下一步建议

## Phase 7: DOCX 渲染 [L3 高风险·F-Strict]

> 风险等级：L3 —— F-Strict 提交检察院的正式辩护意见书，格式直接影响律师专业形象和检察院采纳意愿
>
> LLM 运行时按 `references/docx-format-spec.md` 完整排版规范直接写 python-docx 代码生成。不需要预存脚本。

### 7.1 排版规范加载（LLM执行指令）

1. 读取 `references/docx-format-spec.md` —— 单一排版事实源（F-Strict版370+行）
2. 读取 `base/rule/format-docx/base/prohibitions.md` —— F1-F18禁止事项+刑事实战审查清单
3. 依 §1 页面布局设置 DXA 精确值（页边距 2100/1984/1588/1474，行距560，缩进640）
4. 依 §2 字体字号矩阵设置（标题22pt方正小标宋→正文16pt仿宋→证据12pt楷体）
5. 依 §3 段落间距规则设置段前/段后值（不得用空行分段）
6. 依 §6 信息区无边框表格（辩护人信息+犯罪嫌疑人信息，左列25%右列75%）
7. 依 §7 四类不起诉论证适配（V1/V2/V3/V4措辞+请求差异+规范性质）
8. 依 §10.4 O1正式提交稿约束（无免责声明/无正文表格/不起诉类型严格区分）

### 7.2 python-docx 代码生成步骤（LLM 14步执行序列）

```
Step  1: from docx import Document; document = Document()
Step  2: 设置页面 §1（A4/页边距/行距28磅/页码）
Step  3: 渲染标题 §9.1（22pt方正小标宋居中，"审查起诉辩护意见书"）
Step  4: 渲染信息区 §6（无边框两列表格—辩护人+犯罪嫌疑人信息）
Step  5: 渲染致送机关 §9.2（"XX人民检察院："顶格，不加缩进）
Step  6: 渲染前言 §9.3（含阅卷声明+第173条第1款依据）
Step  7: 渲染辩护意见正文 §7（按V1/V2/V3/V4变体路由，逐项分段）
Step  8: 渲染结论与请求 §7.1（对应变体的规范措辞）
Step  9: 渲染"此致"区 §9.4（首行缩进2字符→顶格"XX人民检察院"）
Step 10: 渲染落款签名区 §9.5（右对齐：辩护人/律所/日期）
Step 11: 渲染附件清单 §9.6（签名后独立列出，段前18pt，不参与正文编号）
Step 12: 保存 docx
```

### 7.3 F-Strict 禁止事项必检（§11 F12-F18）

- [ ] F12: 致送机关为"XX人民检察院"（非人民法院）
- [ ] F13: 正文论证无表格（D1-D5等对照表改为逐项分段）
- [ ] F14: O1(.docx) 无免责声明（仅O2 Markdown保留）
- [ ] F15: "应当"/"可以"不起诉措辞正确
- [ ] F16: V3存疑不起诉论证了退补程序
- [ ] F17: V3+V4不同时主张（存疑不起诉≠认罪认罚）
- [ ] F18: 称呼"检察官"（非审判长/法官）

### 7.4 O1-MD vs O1-DOCX 区分

| 内容 | O1-DOCX（正式提交稿） | O1-MD（律师编辑稿） |
|------|---------------------|-------------------|
| 免责声明 | ❌ 禁止 | ✅ 保留 |
| 正文表格 | ❌ 禁止 | ✅ 可保留（编辑参考） |
| 编号体系 | Word原生List Numbering | Markdown手动编号 |
| 证据引用 | 楷体12pt独立段 | Markdown引用格式 |
