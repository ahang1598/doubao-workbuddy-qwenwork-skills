# 边缘示例001：辩护类型冲突

> criminal-prosecution-defense | 边缘示例 | 无罪辩护与认罪认罚冲突

## 输入

```markdown
当事人：赵某
涉嫌罪名：盗窃罪
辩护类型：无罪辩护，但当事人想认罪认罚
```

## 预期处理

**硬拒绝**：无罪辩护与认罪认罚从宽制度互斥，需由当事人自主选择。

```markdown
⚠️ 辩护策略冲突提示

无罪辩护与认罪认罚从宽制度互斥，不能同时适用：

1. **无罪辩护**：主张不构成犯罪，争取不起诉决定
2. **认罪认罚**：承认犯罪事实，争取从宽处理

请与当事人充分沟通后选择其中一种策略：
- 若选择无罪辩护 → 继续使用本技能，defense_type=innocent
- 若选择认罪认罚 → 使用 criminal-plea-negotiation 技能

**重要提示**：此选择应由当事人自主决定，律师应向当事人充分说明两种策略的利弊。
```
