# 标准示例001：诈骗罪无罪辩护意见书

> criminal-prosecution-defense | 标准示例 | defense_direction: innocent | V1法定不起诉 | C档
> 版本: v3.2.0 | 2026-06-13 第二轮深度优化

## 输入

```markdown
当事人：张某
涉嫌罪名：诈骗罪
辩护方向：innocent（无罪辩护→法定不起诉）
案件事实：张某被指控以投资理财名义骗取王某50万元。经阅卷发现，张某实际参与的是正规理财产品销售，未虚构事实、未隐瞒真相，投资失败系市场风险导致。
辩护要点：1.主观上无非法占有目的；2.客观上未实施欺骗行为；3.现有证据不足以证明诈骗事实
证据分析：仅有被害人陈述，无客观证据证明张某实施了欺骗行为，银行流水显示资金用于正常投资
法律论证：诈骗罪要求"以非法占有为目的，采用虚构事实或隐瞒真相的方法"，本案不符合
```

## 预期输出

```markdown
# 关于张某涉嫌诈骗罪的辩护意见书

XX市XX区人民检察院：

辩护人XXX，XX律师事务所律师，执业证号XXX，系犯罪嫌疑人张某涉嫌诈骗罪一案的辩护人。辩护人已查阅全部侦查卷宗，经认真研究，现提出如下辩护意见：

一、事实方面

起诉意见书认定张某"以投资理财名义骗取王某50万元"，辩护人对此提出异议：

1.张某实际参与的是正规理财产品销售，并非虚构投资项目。根据银行流水（卷3第45-52页），涉案资金50万元全部进入XX证券公司正规金融产品账户，不存在资金被挪用或挥霍的情形。

2.投资失败系市场风险所致，并非张某故意造成。根据张某与王某的微信聊天记录（卷2第88-95页），张某已向王某如实说明产品风险，王某系在充分知情的情况下自愿投资。

3.张某未虚构事实、未隐瞒真相。根据产品说明书（卷3第23-28页）及XX证券公司出具的证明（卷3第60页），涉案产品系合法金融产品，张某未对产品信息做任何虚假陈述。

二、证据方面

现有证据不足以证明张某构成诈骗罪：

1.起诉意见书指控的"张某承诺保本保息"仅有被害人王某陈述（卷1第15-18页），无录音、书面协议等客观证据支持，属于孤证。根据《刑事诉讼法》第55条"证据确实、充分"的证明标准，孤证不能定案。

2.银行流水印证资金去向（卷3第45-52页），50万元全部进入正规金融产品账户，不存在被张某非法占有的情形，无法证明张某具有非法占有目的。

3.起诉意见书未提供任何证明张某实施欺骗行为的客观证据，仅凭被害人的单方陈述，无法达到"排除合理怀疑"的证明标准。

三、适用法律方面

诈骗罪的构成要件要求"以非法占有为目的，采用虚构事实或隐瞒真相的方法，骗取数额较大的公私财物"（《刑法》第266条）。本案中：

1.主观上无非法占有目的：张某未将投资款据为己有，资金全部用于购买合法金融产品，资金流向清晰可查（卷3第45-52页）。

2.客观上未实施欺骗行为：未虚构事实，未隐瞒真相，产品信息真实（卷3第23-28页），已向投资人说明风险（卷2第88-95页）。

3.张某的行为不符合诈骗罪的构成要件，依法不构成诈骗罪。

四、定罪量刑方面

鉴于张某的行为不构成诈骗罪，本案不存在量刑问题。辩护人建议贵院依法作出不起诉决定。

如果贵院认为仍需进一步审查，辩护人提请关注：张某系初犯（卷1第5页，无前科记录），且在投资失败后积极协助王某向XX证券公司索赔（卷2第112页），其行为表现与诈骗犯罪的典型特征明显不符。

综上，张某的行为不构成诈骗罪，现有证据不足以证明张某主观上有非法占有目的，客观上实施了欺骗行为。根据《刑事诉讼法》第177条第1款之规定，建议贵院依法作出不起诉决定。

此致

辩护人：XXX律师

2. 证据材料：银行流水（卷3第45-52页）、产品说明书（卷3第23-28页）、微信聊天记录（卷2第88-95页）
```
