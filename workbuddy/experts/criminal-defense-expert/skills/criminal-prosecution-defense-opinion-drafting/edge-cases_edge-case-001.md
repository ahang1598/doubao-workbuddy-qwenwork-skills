# 边界示例001：存疑不起诉与认罪认罚的边界

> criminal-prosecution-defense | 边界示例 | defense_direction冲突检测 | C档
> 版本: v3.2.0 | 2026-06-13 新增
> 场景：用户同时请求存疑不起诉和认罪认罚——逻辑矛盾，须由用户选择

## 输入

```markdown
当事人：赵某
涉嫌罪名：故意伤害罪（轻伤）
辩护方向：既要存疑不起诉，也要认罪认罚从宽
案件事实：赵某被指控殴打被害人致轻伤。但赵某称系正当防卫，现场监控有死角，证人证言矛盾。
辩护要点：1.证据不足——监控有死角+证人矛盾；2.退一步讲，即使认定有罪，赵某愿意认罪认罚
```

## 预期处理（技能应拒绝同时主张，提示用户择一）

```markdown
⚠️ 辩护方向冲突检测

您同时选择了"存疑不起诉"和"认罪认罚从宽"，两者存在逻辑矛盾：

- **存疑不起诉**的核心逻辑是：证据不足，不能证明犯罪事实成立
- **认罪认罚从宽**的核心逻辑是：承认犯罪事实，接受处罚，换取从宽处理

二者不可兼得——"证据不足"意味着犯罪事实无法确认，"认罪"意味着承认犯罪事实。

---

请您选择辩护方向：

**方案A：存疑不起诉（推荐）**
- 适用条件：监控有死角+证人证言矛盾→证据链条断裂→不能排除合理怀疑
- 论证重点：逐项论证证据不足
- 风险提示：存疑不起诉后如发现新证据，检察院可重新起诉

**方案B：认罪认罚从宽**
- 适用条件：承认故意伤害事实+退赔+谅解
- 论证重点：认罪态度+从宽幅度建议
- 风险提示：认罪认罚后反悔可能导致从宽幅度收回

请回复 A 或 B，我将据此生成辩护意见书。
```
