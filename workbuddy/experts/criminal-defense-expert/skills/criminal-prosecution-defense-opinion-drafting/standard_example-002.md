# 标准示例002：盗窃罪量刑辩护意见书

> criminal-prosecution-defense | 标准示例 | defense_direction: mitigated | V2酌定不起诉 | C档
> 版本: v3.2.0 | 2026-06-13 新增

## 输入

```markdown
当事人：李某
涉嫌罪名：盗窃罪
辩护方向：mitigated（量刑辩护→酌定不起诉）
案件事实：李某涉嫌盗窃同事手机一部（价值3200元），案发后主动退赃退赔，取得被害人书面谅解。李某系初犯，有固定工作和住所。
辩护要点：1.盗窃金额刚过入罪标准（3000元），边际性明显；2.已退赃退赔+被害人谅解；3.初犯+固定住所+社会危险性低；4.情节轻微，建议酌定不起诉
从轻情节：初犯、退赃退赔、被害人谅解、认罪态度好
认罪认罚：愿意认罪认罚
```

## 预期输出

```markdown
# 关于李某涉嫌盗窃罪的辩护意见书

XX市XX区人民检察院：

辩护人XXX，XX律师事务所律师，执业证号XXX，系犯罪嫌疑人李某涉嫌盗窃罪一案的辩护人。辩护人已查阅全部侦查卷宗，经认真研究，现提出如下辩护意见：

一、事实方面

起诉意见书认定李某盗窃同事王某手机一部，价值3200元。辩护人对盗窃事实的基本认定无异议，但提请贵院关注以下情节：

1.盗窃金额3200元，刚过本地区盗窃罪入罪标准3000元，边际性明显（卷2第12页，价格鉴定意见）。

2.李某系因一时贪念实施盗窃，非预谋犯罪，主观恶性较小（卷1第8-10页，李某供述）。

3.案发后李某主动向单位领导坦白（卷1第25页），并积极联系被害人退赃退赔（卷2第35页，退还凭证）。

二、证据方面

本案证据确实充分，辩护人对证据的合法性、关联性不持异议。但提请贵院注意：

1.被害人在收到退赃后出具了书面谅解书（卷2第36页），明确表示"对李某的行为予以谅解，希望司法机关从轻处理"。

2.李某所在单位出具证明（卷2第40-41页），证实李某平时表现良好，无违纪记录，愿意继续留用。

三、适用法律方面

根据《刑法》第264条，盗窃公私财物，数额较大的，处三年以下有期徒刑、拘役或者管制。本案盗窃金额3200元，属于"数额较大"的起点。

根据《刑事诉讼法》第177条第2款，对于犯罪情节轻微，依照刑法规定不需要判处刑罚或者免除刑罚的，人民检察院可以作出不起诉决定。

四、定罪量刑方面

辩护人认为，李某犯罪情节轻微，符合酌定不起诉条件，理由如下：

1.法定从轻情节：李某到案后如实供述犯罪事实，系坦白（《刑法》第67条第3款），可从轻处罚。

2.酌定从轻情节：(1)已退赃退赔（卷2第35页），被害人损失已全部弥补；(2)取得被害人书面谅解（卷2第36页）；(3)初犯，无前科劣迹（卷1第5页）；(4)认罪态度好，愿意认罪认罚。

3.品格证据：李某有固定工作和住所（卷2第40页，单位证明），社会危险性低，再犯可能性小。

4.社会危害性分析：盗窃金额刚过入罪标准，已退赃退赔+谅解，社会危害性已降至最低。根据"少捕慎诉慎押"刑事政策，对李某作出不起诉决定更符合刑罚教育改造的目的。

如果贵院认为仍需起诉，辩护人建议：判处拘役三个月，可适用缓刑，并处罚金。

综上，李某盗窃金额刚过入罪标准，已退赃退赔并取得被害人谅解，系初犯，认罪态度好，社会危害性低。根据《刑事诉讼法》第177条第2款之规定，恳请贵院考虑作出酌定不起诉决定。

此致
XX市XX区人民检察院

辩护人：XXX律师
XX律师事务所
2025年6月13日

附件清单
1. 法条索引：《刑法》第264条、第67条第3款；《刑事诉讼法》第177条第2款
2. 证据材料：价格鉴定意见（卷2第12页）、退还凭证（卷2第35页）、谅解书（卷2第36页）、单位证明（卷2第40-41页）
```
