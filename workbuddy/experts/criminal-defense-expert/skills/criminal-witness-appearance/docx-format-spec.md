## 3. 段落间距规则

**禁止用空行分段。** 段前/段后间距控制：标题后24pt，节标题前12pt后6pt，一级标题前12pt后6pt，正文0/0，"此致"前12pt，落款前12pt，附件清单标题前18pt。

## 4. 段落粒度规则

一个段落 = 一个语义单元。证人信息独立成段，待证事实逐项独立成段，请求事项逐项编号。

## 5. 编号规则

Word 原生 List Numbering。致送机关信头不编号。正文首标题"一、"。

## 6. 区块分隔规则

信息区无边框两列表格。标题→信息区（24pt）→致送机关（6pt）→前言（紧接）。"此致"→致送机关名（紧接）。落款→附件清单（18pt）。

## 7. 证人信息与待证事实格式

证人信息：
```
申请证人：[姓名]，性别：[男/女]，身份证号：[ID]，
住址：[地址]，联系电话：[电话]。
与案件关系：[目击证人/鉴定人/侦查人员等]，出庭必要性：[必要性论证]。
```

待证事实（逐项）：
```
待证事实1：[具体待证事实内容]。关联性论证：[与案件争议焦点的关联]。法律依据：刑诉法第192条。
```

## 8. 特殊格式规则

- 标题："证人出庭申请书"，22pt方正小标宋居中
- 致送："XX人民法院"（致送法院——证人出庭申请在审判阶段提出）
- 致送机关称呼："XX人民法院"顶格
- 落款右对齐
- 附件清单签名后独立列出

## 9. 禁止事项

| # | 禁止项 | 正确做法 |
|---|--------|----------|
| F1 | 纸张非A4 | 必须A4 |
| F2 | 空行分段 | 段前/段后间距 |
| F3 | 多语义单元挤一段 | 独立段 |
| F4 | 手动编号 | Word List Numbering |
| F5 | 手动分隔线 | 段落底边框 |
| F6 | 图片/占位符 | 纯文字 |
| F7 | 缩进随机 | 首行缩进2字符 |
| F8 | 信息区纯文本 | 无边框表格 |
| F9 | "此致"与致送间空行 | 紧接 |
| F10 | 落款未右对齐 | 右对齐 |
| F11 | 证人信息混在正文 | 独立成段 |
| F12 | 致送非法院 | 证人出庭申请致送法院 |
| F13 | 正文表格 | 纯文字 |
| F14 | O1含免责声明 | 正式提交稿无免责声明 |
| F15 | 证人与案件无关 | 须论证关联性 |
| F16 | 混淆第192条与第197条 | 第192条=证人/鉴定人出庭，第193条=强制出庭，第197条=有专门知识的人出庭 |
| F17 | 证人信息不完整 | 姓名/住址/联系方式齐全 |
| F18 | 附件清单参与正文编号 | 签名后独立列出 |
