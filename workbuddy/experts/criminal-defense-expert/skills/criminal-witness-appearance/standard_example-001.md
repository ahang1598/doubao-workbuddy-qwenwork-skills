# 标准示例001：申请关键证人出庭作证

> criminal-witness-appearance | 标准示例 | v3.2.0 | witness_type=证人

## 输入

```
帮我写一份证人出庭申请书。张某涉嫌故意伤害罪案，一审阶段。
证人王某目击了案发全过程，其证言对认定张某是否正当防卫至关重要。
王某在侦查阶段作过证，但证言对张某有利（证实被害人先动手），
检察机关未申请王某出庭。辩护人认为王某必须出庭接受质证。
联系方式：王某，138XXXXXXXX。
```

```markdown
# 关于张某涉嫌故意伤害罪一案证人出庭申请书

XX市XX区人民法院：

申请人：XXX，XX律师事务所律师，执业证号：XXXXXXXXXX，系被告人张某涉嫌故意伤害罪一案中张某的辩护人。

申请事项：准许证人王某出庭作证。

事实与理由：

一、证人王某的证言对认定被告人张某的行为是否构成正当防卫具有关键作用，对定罪量刑有重大影响。王某在2025年8月10日侦查阶段询问笔录中证实："我看到那个男的（被害人赵某）先推了张某一下，然后张某才还手"，并证实"赵某推了张某之后，又从旁边捡了个啤酒瓶，张某才拿的凳子挡"。该证言直接证明被害人赵某首先实施了侵害行为且侵害具有持续性，对认定张某行为是否构成正当防卫具有决定性意义。辩护人对王某证言中"推了一下"的具体力度、方向等细节需要当庭询问核实，仅凭书面证言无法充分质证——书面证言无法澄清推搡的具体情境、被害人持啤酒瓶后的威胁程度等关键细节，必须通过出庭作证、当庭接受询问才能查清事实。[注：刑诉法第192条第1款]

二、证人王某出庭所要证明的具体事实为：被害人赵某首先实施了推搡张某的侵害行为，随后又拿起啤酒瓶威胁张某，张某的行为系被动防卫而非主动攻击。该事实对本案正当防卫辩护具有直接支撑作用。

三、证人王某具备出庭条件，不属于刑诉法第193条规定的正当理由不能出庭的情形。王某身体健康，居住在本地，已明确表示愿意出庭作证。

综上，证人王某的证言对认定被告人张某是否构成正当防卫具有关键作用，且具备出庭条件，恳请贵院依法通知其出庭作证。

此致
XX市XX区人民法院

申请人：XXX 律师
XX律师事务所
2026年6月15日
```

## 质量标注

| 维度 | 评分 | 说明 |
|------|------|------|
| 三重论证 | A | ARG-1：证言对正当防卫认定有决定性影响+异议具体（推搡力度/方向/情境）+反面论证（书面证言无法澄清关键细节）；ARG-2：被害人先动手+持续侵害+被动防卫；ARG-3：身体健康+居住本地+愿意出庭 |
| 待证事实 | A | 三个递进事实+证言原文引用+与辩护策略（正当防卫）呼应 |
| 法条引用 | A | 第192条第1款[注]标注正确；未误引第193条；第61条原则已融入ARG-1论证逻辑而非独立引用 |
| 专属红线合规 | A | 未承诺法院准许（RL-02）；未绝对化请求（RL-04）；法条编号正确（RL-07）；反面论证完整（RL-09） |
