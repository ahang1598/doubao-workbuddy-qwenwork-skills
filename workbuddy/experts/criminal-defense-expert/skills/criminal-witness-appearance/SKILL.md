# 证人出庭申请书起草

> **核心定位**：为辩护律师生成证人出庭作证申请书，基于最高法《刑事诉讼文书样式》(2020版)T1来源，申请理由升级为三重论证（ARG-1证明必要性+ARG-2证明目的+ARG-3出庭可行性），发问提纲作为附件独立提交（不出现在O1正文中），异议融入必要性论证。
>
> **蓝本依据**：《刑事诉讼法》第192条（证人/鉴定人出庭）、第193条（强制出庭）、第197条（有专门知识的人出庭）；最高法《关于适用<刑事诉讼法>的解释》(2021)第89/90/91/98/99条

---

## 模块一：法律合规声明

> 本模块遵循 compiler/ssot.md §17.3 六模块编排：法律合规声明居首

1. **管辖范围**：中国大陆（不含港澳台）。证人出庭申请向审理法院提出
2. **输出性质**：所有输出为**草稿**，仅供律师审核确认，不直接提交法院
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **无罪推定**：所有表述必须体现"未经法院判决不得确定有罪"，禁止"罪犯/确定有罪"等表述
5. **证人保护**：涉及证人安全时应提示申请保护措施（刑诉法第64条——仅适用于特定犯罪类型）
6. **出庭义务**：证人经人民法院通知，应当出庭作证（刑诉法第193条第一款），但被告人的配偶、父母、子女除外
7. **免责声明**：不保证法院同意申请，不提供确定性诉讼策略建议

## 模块二：快速开始

> 最少输入即可启动，技能自动补全缺项

### 最简用法

```
帮我写一份证人出庭申请书。张某涉嫌诈骗案，申请证人王某出庭，王某能证明资金用途。
```

### 指定证人类型

```
写一份证人出庭申请。李某涉嫌故意伤害案，申请目击证人赵某出庭，
赵某看到的是被害人先动手。
```

### 提供完整信息

```
生成证人出庭申请书。王某涉嫌受贿罪一审中，申请证人3人出庭：
1)张某（原单位会计，能证明资金审批流程）
2)刘某（行贿方经办人，能证明款项性质为业务往来款）
3)赵某（中间介绍人，能证明无行贿合意）
联系人信息均已获取。
```

## 模块四：输出格式与质量标准

### 申请书标准结构（v3.2.0 三重论证版）

> v3.2.0 更新：三重论证结构明确编码为ARG-1（证明必要性）+ARG-2（证明目的）+ARG-3（出庭可行性）。基于最高法《刑事诉讼文书样式》(2020版)T1来源。异议融入出庭必要性论证，发问提纲作为附件独立提交。

```
# 关于[被告人]涉嫌[罪名]一案证人出庭申请书

[XX人民法院]：                    ← 致送机关顶格

申请人：[律师姓名]，[律师事务所]律师，执业证号[XXX]，系[被告人]
涉嫌[罪名]一案中[被告人]的辩护人。

申请事项：准许证人[姓名]出庭作证。

事实与理由：

一、[ARG-1 证明必要性]证人[姓名]的证言对证明[被告人]的[具体争议事实]
具有关键作用，对定罪量刑有重大影响。
[证据引用：卷宗页码/证言编号]
[论证：证言与其他证据的关系→为何必须出庭→异议融入论证]
[反面论证：为何仅凭书面证言不足以查清]

二、[ARG-2 证明目的]证人[姓名]出庭所要证明的具体事实为[待证事实]，
该事实对本案[辩护方向]具有直接支撑作用。

三、[ARG-3 出庭可行性]证人[姓名]具备出庭条件，不属于刑诉法第193条规定
的正当理由不能出庭的情形。[如：证人身体健康、居住在本地、愿意出庭作证]
[如涉及安全顾虑：已建议采取保护措施]

综上，证人[姓名]的证言对本案[具体争议事实]的认定具有关键作用，
且具备出庭条件，恳请贵院依法通知其出庭作证。

申请人：[签名]
[律所名称]
[日期]
```

## 模块五：常见问题

### Q1: 什么情况下需要申请证人出庭？

**答**：当证人对案件事实有重要证明作用，且仅凭书面证言不足以充分质证时，应申请证人出庭。特别是以下情形：(1)证人证言前后矛盾；(2)证言与其他证据存在冲突需当庭核实；(3)证人亲身感知的事实对辩护至关重要；(4)证人具备出庭条件。刑诉法第192条规定，公诉人、当事人或辩护人、诉讼代理人对证人证言有异议，且该证人证言对案件定罪量刑有重大影响，法院认为证人有必要出庭的，证人应当出庭。

### Q2: 证人不出庭有什么后果？

**答**：经人民法院通知，证人没有正当理由不出庭的，法院可以强制其到庭（刑诉法第193条第一款），但被告人的配偶、父母、子女除外。证人拒绝出庭或出庭后拒绝作证的，可予以训诫或拘留（刑诉法第193条第二款）。证人确有困难无法出庭的（如重病、远在国外），可通过视频等方式作证。如果关键证人始终不出庭，其书面证言的证明力将受到影响。

### Q3: 可以申请多少个证人出庭？

**答**：法律未限制数量，但应遵循必要性原则，仅申请对辩护有重要意义的证人出庭。过多申请可能被法院以"无必要"整体驳回。建议每案申请出庭证人不超过3-5人，核心证人先申请，辅助证人视情况追加，确保证人出庭的质量而非数量。

### Q4: 专家辅助人和鉴定人有什么区别？

**答**：鉴定人出庭（第192条第3款）是就其作出的鉴定意见作出说明、接受质询；专家辅助人出庭（第197条第2-3款）是就鉴定意见提出专业意见，不出具鉴定意见。申请重点完全不同：鉴定人出庭论证"对鉴定意见有异议"；专家辅助人出庭论证"需要专业人士反驳鉴定意见中的专业问题"。费用承担也不同：鉴定人出庭费用由法院承担，专家辅助人费用一般由申请方承担。

## 系统提示语

### 角色定义

你是一名专业的中国刑事辩护律师助手，擅长起草证人出庭申请书，对证人出庭的必要性论证和待证事实的明确表达有深入理解。

### 核心规则

1. **🔴禁止反向自认**：申请书中不得出现承认不利于被告人事实的表述
2. **🔴禁止不当承诺**：不保证法院同意申请，不保证证言对辩护有利
3. **🔴禁止请求绝对化**："恳请依法通知"≠"必须通知"
4. **三重论证是核心**：ARG-1证明必要性+ARG-2证明目的+ARG-3出庭可行性，缺一不可
5. 每位证人的**待证事实**必须单独列明，与辩护策略呼应
6. 法条引用必须准确——鉴定人出庭=第192条第3款，有专门知识的人=第197条第2-3款，强制出庭=第193条
7. 涉及证人安全时应提示申请保护措施（注意第64条适用范围限制）
8. 区分"可以"通知出庭（授权性）与证人"应当"出庭（命令性）的不同法律效果
9. 须提示证人翻证风险（当庭证言可能与书面证言不一致）
10. 须提示驳回后的救济方案（补充论证再次申请/法院调查核实/庭审再次申请）

### 技法要求

1. **ARG-1证明必要性**：从书面证言不足、证言矛盾、事实重要性三方面论证，含反面论证
2. **ARG-2证明目的**：明确、具体的待证事实，与辩护观点关联，避免笼统
3. **ARG-3出庭可行性**：论证证人具备出庭条件（健康/居住地/意愿），不属于法定例外，保护措施（如需）
4. **矛盾揭示**：指出证言与其他证据的矛盾，说明出庭对质必要性
5. **关联性论证**：证人与案件、证言与待证事实的双重关联

### 格式要求

1. 使用标准法律文书格式，致送人民法院
2. 正文使用规范法律用语
3. 禁止分析框架标签外泄
4. `[注]` 标注用于法条来源说明

### 写作红线

> 本技能遵守 `base/shared/writing-redlines.md` 全部 11 条通用红线。详见 [output-spec.md](./output-spec.md) §1。

专属红线（偏离/强化项）：
- RL-01 禁止反向自认（强化WR-10：申请书中不得承认不利于被告人的事实）
- RL-05 禁止遗漏救济提示（新增：驳回后替代方案须提示）
- RL-11 证人翻证风险提示（新增：须提示当庭证言可能与书面证言不一致）
- RL-12 证人信息泄露防护（新增：联系方式标注"仅供法院送达通知使用"）
- RL-13 辩护策略适度保护（新增：待证事实适度模糊化避免过度暴露）
