# 边缘示例001：证人害怕报复拒绝出庭

> criminal-witness-appearance | 边缘示例 | v3.2.0 | 证人拒绝出庭+保护措施路径选择

## 输入

```markdown
证人王五是故意伤害案的目击者，已向公安机关作过证言笔录。
现在案件到了审判阶段，王五说害怕被告人报复，拒绝出庭作证。
请问怎么办？能强制他出庭吗？
```

## 边界问题

证人拒绝出庭是刑事审判中的常见难题，涉及多重法律问题：（1）证人出庭义务与不出庭后果（刑诉法第192条）；（2）证人保护措施——本案系普通故意伤害案，第64条不直接适用，须引用刑诉法解释相关条款；（3）证言笔录能否作为定案依据（刑诉法解释第91条）；（4）强制出庭的适用条件与限制（刑诉法第193条：被告人的配偶、父母、子女除外）。此案例触及证人出庭申请技能的核心边界——当证人拒绝出庭时的替代方案设计。

**关键区分**：本案系普通故意伤害案，非刑诉法第64条特定犯罪类型，不得引用第64条申请人身安全保护措施。应使用路径一（不公开个人信息）+路径三（不暴露外貌声音）。

## 预期输出特征

- 分析证人拒绝出庭的法律后果和应对方案
- 列出保护措施申请选项——普通案件路径（不公开个人信息+不暴露外貌声音），不得引用第64条
- 说明庭前证言笔录的证据效力（未经质证可能不被采纳）
- 不建议强制普通证人出庭（实务中极少适用）
- 提供替代方案：保护措施消除顾虑+视频作证+书面证言补强

## 预期输出摘要

```markdown
# 关于[被告人]涉嫌故意伤害罪一案证人出庭申请书

XX市XX区人民法院：

申请人：XXX，XX律师事务所律师，执业证号：XXXXXXXXXX，
系[被告人]涉嫌故意伤害罪一案辩护人。

申请事项：
一、准许证人王五出庭作证；
二、对证人王五采取以下保护措施：
   1. 对证人王五的个人信息不予公开；
   2. 采取不暴露外貌和真实声音的出庭方式。

事实与理由：

一、证人王五的证言对查明案发经过具有关键作用，对定罪量刑有重大影响。
王五在侦查阶段询问笔录中证实了案发时的关键事实，该证言与被害人陈述
存在重大矛盾，辩护人对矛盾之处有具体异议，必须通过当庭质证才能查清。
仅凭书面证言无法澄清矛盾细节，且未经当庭质证的证言真实性无法确认，
可能不被采信为定案根据。[注：刑诉法第192条第1款+刑诉法解释第91条]

二、证人王五出庭所要证明的具体事实为[待证事实——如案发时的具体情况]，
该事实对本案辩护具有直接支撑作用。

三、证人王五因担心出庭作证遭到报复，对出庭有安全顾虑，但在采取保护
措施的前提下愿意出庭作证。王五身体健康，居住在本地，具备出庭的身体
条件和客观条件。

关于证人保护措施：证人王五因出庭作证存在安全顾虑，恳请贵院采取以下
保护措施：（一）对证人王五的个人信息不予公开；（二）采取不暴露外貌
和真实声音的出庭方式。在采取上述保护措施后，证人出庭的安全顾虑可以
消除。[注：刑诉法解释第91条]

综上，证人王五的证言对本案定罪量刑具有重大影响，在采取保护措施后
证人具备出庭条件，恳请贵院依法通知其出庭作证，并采取上述保护措施。

此致
XX市XX区人民法院

申请人：XXX 律师
XX律师事务所
2026年6月15日

> 如发生翻证，可依据刑诉法解释第91条主张"庭前证言有其他证据印证的，
```

## 关键教学点

| 要点 | 说明 |
|------|------|
| 第64条不适用 | 本案系普通故意伤害案→第64条不直接适用，不得引用第64条申请人身安全保护——使用路径一（不公开信息）+路径三（不暴露外貌声音） |
| 证人"有条件愿意" | 证人不是"完全拒绝"而是"有安全顾虑"——在保护措施前提下愿意出庭，构成可行性论证基础 |
| 保护措施与出庭申请同步 | 保护措施应在出庭申请中同步提出，而非单独另行申请 |
| 庭前证言未经质证的风险 | 刑诉法解释第91条：证人拒不出庭，证言真实性无法确认的，不得作为定案根据 |
| 翻证风险提示 | O3中须包含翻证风险提示（RL-11） |
| 驳回救济提示 | O3中须包含驳回后替代方案（RL-05） |
