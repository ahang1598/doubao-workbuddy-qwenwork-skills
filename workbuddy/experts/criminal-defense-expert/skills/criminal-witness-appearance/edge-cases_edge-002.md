# 边缘示例002：证人安全性存疑——需保护措施

> criminal-witness-appearance | 边缘示例 | v3.2.0 | 证人安全+保护措施路径

## 输入

```markdown
涉黑案件，被告人刘某被控组织、领导黑社会性质组织罪等罪名。
证人陈某某是刘某公司前员工，曾向公安机关作证证明刘某组织架构和
违法犯罪事实。现在案件到了审判阶段，陈某某害怕出庭作证被报复，
但愿意在不暴露身份的情况下出庭。请问怎么办？
```

## 边界问题

此案例涉及证人出庭申请中最敏感的安全性问题，涉及多重法律问题：
1. 证人保护措施的适用——本案属于涉黑案件，刑诉法第64条保护措施可直接适用
2. 不暴露外貌声音的出庭方式——所有刑事案件均可申请
3. 证人出庭意愿与安全顾虑的平衡——证人"有条件愿意"出庭时的可行性论证
4. 保护措施的申请程序——应在出庭申请中同步提出

**与edge-001的关键区别**：edge-001是普通刑事案件证人害怕报复（第64条不适用），本例是涉黑案件（第64条适用），保护路径不同。

## 预期输出特征

- 分析证人安全顾虑的性质和程度
- 明确本案属于刑诉法第64条特定犯罪类型，可申请人身安全保护
- 同时申请多种保护措施（不公开个人信息+不暴露外貌声音+禁止特定接触）
- 论证证人"有条件愿意"出庭构成可行性基础
- 提供保护措施的具体实施方案

## 预期输出摘要

```markdown
# 证人出庭申请书

XX市中级人民法院：

申请人：XXX，XX律师事务所律师，执业证号：XXXXXXXXXX，系被告人刘某涉嫌
组织、领导黑社会性质组织罪等一案辩护人。

申请事项：
一、准许证人陈某某出庭作证；
二、对证人陈某某采取以下保护措施：
   1. 不公开真实姓名、住址和工作单位等个人信息；
   2. 采取不暴露外貌和真实声音的出庭方式；
   3. 禁止被告人刘某及其关联人员接触证人陈某某及其近亲属。

事实与理由：

一、证人陈某某的证言对证明刘某组织架构的层级关系、违法犯罪事实的
组织性特征具有关键作用，对定罪量刑有重大影响。陈某某在侦查阶段证实：
刘某系组织核心，下设多个层级，实施敲诈勒索、寻衅滋事等违法犯罪活动。
该证言直接涉及黑社会性质组织"组织特征"的认定，对定罪量刑具有决定性影响。
辩护人对证言中关于"刘某直接指挥"的部分存在异议，需要当庭核实指挥链的
具体方式。[注：刑诉法第192条第1款]

二、证人陈某某出庭所要证明的具体事实为：刘某在组织中的实际地位和作用，
以及相关违法犯罪活动是否系刘某直接指挥。该事实对本案黑社会性质组织
的"组织特征"和"行为特征"认定具有直接支撑作用。

三、证人陈某某因担心出庭作证遭到报复，对出庭有安全顾虑，但在采取
保护措施的前提下愿意出庭作证。陈某某身体健康，居住在本地，具备出庭的
身体条件和客观条件。在法院采取不暴露外貌声音、不公开个人信息等保护措施
后，证人出庭的安全顾虑可以消除。[注：刑诉法第193条+刑诉法解释第91条]

关于证人保护措施：本案系涉黑案件，属于刑诉法第64条规定的特定犯罪类型。
证人陈某某因作证面临人身安全危险，根据刑诉法第64条，恳请贵院对证人
采取以下保护措施：
（一）不公开真实姓名、住址和工作单位等个人信息；
（二）采取不暴露外貌和真实声音的出庭方式；
（三）禁止被告人刘某及其辩护人、诉讼代理人等接触证人陈某某及其近亲属。

综上，证人陈某某的证言对本案定罪量刑具有重大影响，在采取保护措施后
证人具备出庭条件，恳请贵院依法通知其出庭作证，并采取上述保护措施。

此致
XX市中级人民法院

申请人：XXX 律师
XX律师事务所
2026年6月15日

---

> ⚠️ **证人翻证风险提示**：证人陈某某的当庭证言可能与侦查阶段证言不一致。
> 如发生翻证，可依据刑诉法解释第91条主张"庭前证言有其他证据印证的，
> 可以采信庭前证言"。
>
> 💡 **如法院驳回出庭申请**，建议：(1)补充论证再次申请；
> (2)申请法院调查核实证言真实性；(3)庭审中当庭再次申请。
```

## 关键教学点

| 要点 | 说明 |
|------|------|
| 第64条适用条件 | 本案属于涉黑案件→第64条直接适用，可申请人身安全保护全套措施 |
| 证人"有条件愿意" | 证人不是"拒绝出庭"而是"有条件愿意"——在保护措施前提下愿意出庭，构成可行性论证基础 |
| 保护措施与出庭申请同步 | 保护措施应在出庭申请中同步提出，而非单独另行申请 |
| 翻证风险提示 | O3中须包含翻证风险提示（RL-11） |
| 驳回救济提示 | O3中须包含驳回后替代方案（RL-05） |
