# 风险框架：criminal-witness-appearance

> 证人出庭申请 | 版本: v3.2.0

## 1. 风险等级

**L2（中风险）**——申请书性质，但必要性论证和法条引用准确性影响法院是否准许

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 证人信息结构化 | L1 | 低风险 |
| Phase 3 必要性论证 | **L2** | **中风险**——必要性论证影响法院是否准许 |
| Phase 4 文书生成 | L1 | 低风险 |
| Phase 5 质量检查 | L1 | 低风险 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 必要性论证充分 | 生成申请书时 | 须论证为何书面证言不够 |
| RC-02 | 禁止承诺准许 | 询问能否出庭 | 拒绝+说明由法院决定 |
| RC-03 | 证人保护 | 涉及证人安全 | 建议申请保护措施（注意第64条仅适用于特定犯罪类型） |
| RC-04 | 致送机关正确 | 生成致送机关 | 一审→审理法院，二审→上级法院 |

## 4. 行为约束

- 不保证法院同意申请
- 不保证证言对辩护有利
- 涉及证人安全须建议保护措施
