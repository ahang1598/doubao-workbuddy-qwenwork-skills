# 输入规格

> 本文件定义 criminal-witness-appearance 技能的完整输入参数规格
> 遵循 compiler/ssot.md §17（SSOT）：输入宽容度契约
> 版本: v3.2.0

## 1. 必需输入

| 字段 | 类型 | 枚举值 | 说明 | 验证规则 |
|------|------|--------|------|----------|
| `case_name` | string | - | 案件名称 | 非空 |
| `witness_name` | string | - | 证人/鉴定人姓名 | 非空 |
| `appearance_reason` | string | - | 申请出庭的理由 | 非空 |

## 2. 可选输入

### 2.1 案件信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `alleged_crime` | string | [待补充] | 涉嫌罪名 |
| `case_stage` | enum | 一审 | 侦查/审查起诉/一审/二审 |
| `court_name` | string | [待补充] | 审理法院 |
| `case_number` | string | [待补充] | 案号 |

### 2.2 证人/鉴定人信息

| 字段 | 类型 | 枚举值 | 默认值 | 说明 |
|------|------|--------|--------|------|
| `witness_type` | enum | 证人/鉴定人/侦查人员/有专门知识的人 | 证人 | 出庭人员类型 |
| `witness_identity` | string | [待补充] | 身份/职业 |
| `witness_contact` | string | [待补充] | 联系方式 |
| `witness_address` | string | [待补充] | 住址 |

### 2.3 出庭必要性

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `testimony_summary` | string | [待补充] | 证人证言/鉴定意见概要 |
| `dispute_points` | string | [待补充] | 对该证言/意见的争议点 |
| `expected_questions` | array[string] | [] | 拟向证人/鉴定人发问的问题 |
| `relevance_to_defense` | string | [待补充] | 出庭对辩护的意义 |

### 2.4 申请人信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `applicant_name` | string | [待补充] | 申请人姓名 |
| `applicant_role` | enum | 辩护人/自诉人/被告人 | 辩护人 |
| `lawyer_firm` | string | [待补充] | 律师事务所 |

## 3. 输入宽容度契约

| 最小输入 | 处理方式 |
|----------|----------|
| 仅案件+证人+理由 | 生成申请书框架 |
| 仅"证人出庭"/"鉴定人出庭" | 询问案件和证人信息 |
| 自然语言描述 | 提取结构化字段 |

交互补全最多3轮。

## 4. 场景适配规则

### 4.1 出庭人员类型适配

| 人员类型 | 核心法条 | 出庭条件 | 申请重点 |
|----------|----------|----------|----------|
| 证人 | 刑诉法第192条第1款 | 控辩双方有异议+对定罪量刑有影响 | 证明异议+影响 |
| 鉴定人 | 刑诉法第192条第3款 | 对鉴定意见有异议 | 证明异议必要性 |
| 侦查人员 | 刑诉法第192条第2款 | 侦查活动合法性 | 证明取证合法性争议 |
| 有专门知识的人 | 刑诉法第197条第2-3款 | 鉴定意见有争议 | 补充专业意见 |

### 4.2 出庭必要性论证要点

| 论证维度 | 要求 | 标注 |
|----------|------|------|
| 证言/意见有异议 | 具体指出异议内容 | [注1] |
| 对定罪量刑有影响 | 说明影响的具体方面 | [注2] |
| 出庭有必要性 | 不出庭无法查明事实 | [注3] |
