# 工作流详述

> 本文件定义 criminal-witness-appearance 技能的各Phase子步骤与检查点 | 版本: v3.2.0

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 出庭三重论证 → Phase 3: 申请书起草
    ↓
Phase 4: 质量检查 → Phase 5: 输出交付
```

## 2. Phase 1: 输入验证

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1 | 解析输入 | 结构化字段 |
| 1.2 | 确定出庭人员类型 | witness_type |
| 1.3 | 提取异议内容 | dispute_points |
| 1.4 | 确定适用法条 | 按类型路由 |

**检查点**：[ ] 必需字段已提取 [ ] 人员类型已确定

## 3. Phase 2: 出庭三重论证

### 3.1 按类型论证

| 人员类型 | 论证路径 | 核心法条 |
|----------|----------|----------|
| 证人 | 有异议+对定罪量刑有影响 | 第192条第1款 |
| 鉴定人 | 对鉴定意见有异议 | 第192条第3款 |
| 侦查人员 | 侦查活动合法性 | 第192条第2款 |
| 有专门知识的人 | 鉴定意见有争议 | 第197条第2-3款 |

### 3.2 三重论证要素

| 论证层次 | 编码 | 要素 | 要求 | 标注 |
|----------|------|------|------|------|
| 证明必要性 | ARG-1 | 异议具体+影响重大+不出庭无法查明+反面论证 | 指出证言/意见的具体问题，说明对定罪量刑的影响，含反面论证 | [注1] |
| 证明目的 | ARG-2 | 待证事实明确 | 证人出庭所要证明的具体事实，与辩护策略呼应 | [注2] |
| 出庭可行性 | ARG-3 | 证人具备出庭条件 | 证人不属于法定不能出庭情形，身体健康/居住本地/可视频作证，保护措施（如需） | [注3] |

**检查点**：[ ] 三重论证已完成 [ ] 法条已正确引用

## 4. Phase 3: 申请书起草

按 output-spec.md O1 模板起草（三重论证ARG-1/2/3三段）。注意：
- 致送机关为审理法院
- 法条按人员类型正确引用（鉴定人→第192条第3款，有专门知识的人→第197条第2-3款）
- 拟发问要点应中立客观
- ARG-3须论证出庭可行性
- 18条写作红线逐项自查

**检查点**：[ ] 格式正确 [ ] 法条正确 [ ] ARG-1/2/3三重论证完整 [ ] 发问要点中立 [ ] 18条红线合规

## 5. Phase 4: 质量检查

| 检查项 | 标准 | 等级 |
|--------|------|------|
| 法条引用 | 第192/193/197条正确归位 | 阻断 |
| 异议具体 | 有具体异议内容 | 阻断 |
| 三重论证 | ARG-1+ARG-2+ARG-3完整 | 阻断 |
| 出庭可行性 | 证人具备出庭条件已论证 | 阻断 |
| 红线合规 | 18条写作红线逐项自查 | 阻断 |
| 去分析化 | 无框架标签 | 警告 |
| 证人翻证风险 | O3中已提示翻证风险 | 警告 |

## 6. Phase 5: 输出交付

| 输出项 | 内容 |
|--------|------|
| O1 | 出庭申请书草稿 |
| O2 | 发问提纲（按需） |
| O3 | 下一步推荐动作 |

---

## 7. Phase 6: DOCX 渲染 [L2 中风险]

> 风险等级：L2 —— 证人出庭作证申请书为F-Strict法院文书，证人信息错误可导致申请被驳回

### 6.1 渲染准备

| 步骤 | 操作 | 参考文件 |
|------|------|----------|
| 6.1.1 | 读取 L3 类型规格卡 | `base/rule/format-docx/types/application/T-witness-appearance.md` |
| 6.1.2 | 读取薄层排版规范 | `references/docx-format-spec.md` |

### 6.2 组件序列渲染

按 `T-witness-appearance.md` §组件清单 顺序渲染8组件。特殊注意：
- 证人基本信息段含7项必填/条件必填要素（姓名/性别/出生日期/身份证号/住址/联系方式/与案件关系）
- 证明目的与必要性段三重论证（ARG-1证明必要性→ARG-2证明目的→ARG-3出庭可行性）
- 致送机关仅法院（不可致送检察院）

### 6.3 Phase 6 检查点

- [ ] 8组件序列完整
- [ ] 证人信息完整（法院可据此送达出庭通知）
- [ ] ARG-1/2/3三重论证充分
- [ ] 18条红线合规
- [ ] 禁止事项全部满足
