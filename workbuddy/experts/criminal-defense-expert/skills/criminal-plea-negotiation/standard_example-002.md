# 示例002：审查起诉阶段量刑协商

> criminal-plea-negotiation | 标准示例 | v2.1.0

## 输入

```markdown
犯罪嫌疑人李某，涉嫌受贿罪，审查起诉阶段。
案件事实：
- 涉嫌受贿87万元，共3笔
- 第1笔20万元（主动交代+已退赃）
- 第2笔35万元（辩称正常业务往来，但有风险）
- 第3笔32万元（证据薄弱，仅有行贿人单方陈述）
从轻情节：第1笔主动交代、已退缴第1笔款项、初犯
检察院量刑建议初步沟通：有期徒刑8-10年
当事人意愿：希望5年以下
negotiation_stage: 量刑协商
case_stage: 审查起诉
```

## 输出（M2 量刑协商方案 摘要）

```markdown
# 量刑协商方案

——审查起诉阶段·量刑协商——

当事人：李某，涉嫌受贿罪，审查起诉阶段。

## 一、检察院量刑建议评估

检察院初步建议有期徒刑8-10年。根据《关于常见犯罪的量刑指导意见》，
受贿87万元的基准刑约为7-10年。

### 量刑建议说理审查（高检发〔2026〕5号第36条）
- [ ] 检察官是否说明了量刑建议的理由和依据
- [ ] 是否逐项列明从宽/从重情节及对应幅度
- [ ] 是否释明主刑、附加刑、罚金的计算依据

## 二、辩方从宽情节

| 从宽情节 | 证据支撑 | 从宽幅度参考 |
|---------|---------|-------------|
| 第1笔主动交代 | 交代时间早于侦查掌握+退赃凭证 | 基准刑-10%~-30% |
| 退缴第1笔款项 | 退赃凭证 | 基准刑-10%~-20% |
| 认罪认罚（审查起诉阶段） | 签署具结书 | 基准刑-15%~-25% |
| 初犯偶犯 | 无前科记录 | 基准刑-5%~-10% |
| 第3笔证据薄弱 | 仅有行贿人单方陈述，无其他佐证 | 建议剔除第3笔 |

> **注意**：上述从宽幅度仅供参考，不可简单叠加。认罪认罚与自首不作重复评价
> （高检发〔2026〕5号第11条），具体由法院综合考量确定。

## 三、量刑建议对比表

| 对比项 | 检察院建议 | 辩方意见 | 差距分析 |
|--------|-----------|---------|---------|
| 主刑 | 有期徒刑8-10年 | 有期徒刑4-6年 | 差距较大，核心争议在第3笔是否计入 |
| 认定金额 | 87万元 | 55万元（剔除第3笔32万元） | 第3笔证据薄弱，应剔除 |
| 罚金 | 未明确 | 参照主刑从宽幅度 | 罚金应与主刑从宽协调 |
| 缓刑 | 未提及 | 如刑期3年以下可争取 | 需先解决金额争议 |

## 四、协商路径设计

1. **与承办检察官沟通量刑意向**：提出第3笔证据薄弱应剔除，调整认定金额为55万元
2. **提交书面量刑意见**：逐项论证从宽情节+同类案件量刑参考+建议量刑4-6年
3. **就主刑、附加刑、缓刑分别协商**：优先解决金额争议，再协商具体刑期
4. **锁定有利条款后签署具结书**：待就量刑达成基本共识后再签署，避免先签后谈

## 五、具结书签署时机策略

建议"先谈后签"：
- 量刑建议有争议（8-10年 vs 期望5年以下），签署后协商空间骤降
- 辩方有谈判筹码（第3笔证据薄弱+主动交代+退赃）
- 具结书签署后检察机关不得单方撤销（高检发〔2026〕5号第33条）——
  须锁定有利条款后再签

## 六、期望结果

基于第3笔证据薄弱+第1笔主动交代+退赃+认罪认罚，
量刑参考区间为有期徒刑4-6年。

> **声明**：上述量刑参考区间仅为评估参考，不可视为承诺或保证，
> 具体量刑由法院依法判决。

## 反悔权告知

当事人签署认罪认罚具结书后、判决前有权反悔。但须了解以下后果：

一、从宽不再适用——检察院可调整量刑建议（从从宽建议调整为标准量刑建议），
实质可能导致更重刑罚。

二、已认罪供述仍可作证据——反悔仅撤回具结书的程序效力，
不撤回此前已做出的有罪供述。

三、仅以量刑过重上诉的风险——如致从宽量刑明显不当，
检察院可依法抗诉，抗诉后不受上诉不加刑限制（高检发〔2026〕5号第62条）。

四、反悔应以书面方式在判决前向检察院/法院提出。
```

## 设计要点

1. **审查起诉阶段特征**：量刑协商黄金窗口，须体现"先谈后签"策略
2. **部分认罪策略**：第3笔证据薄弱建议剔除，不盲目全部认罪
3. **量刑建议说理审查**：检察官须说明依据（高检发〔2026〕5号第36条）
4. **量刑参考区间而非承诺**：标注"仅供参考，由法院依法判决"
5. **反悔权完整告知**：分4个梯度告知后果
