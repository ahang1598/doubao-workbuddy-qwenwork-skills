# 示例001：盗窃罪认罪认罚协商（审查起诉阶段）

## 输入

```
犯罪嫌疑人：张某
涉嫌罪名：盗窃罪
涉案金额：5000元
案件阶段：审查起诉
已退赃：是（5000元全额退赃）
初犯：是
被害人谅解：是（已签署谅解书）
认罪认罚意愿：愿意认罪认罚，希望争取缓刑
律师评估：事实清楚，证据充分，建议认罪认罚从宽
```

## 输出（v2.1.0 标准四模块）

### M1 策略选择

**适配评估**：高度适合认罪认罚从宽程序

| 评估维度 | 评估结果 | 说明 |
|----------|----------|------|
| 事实基础 | 清楚稳定 | 犯罪嫌疑人多次供述稳定，与监控录像、证人证言相互印证 |
| 证据充分性 | 充分 | 监控录像1份+证人证言2份+退赃收据1份 |
| 认罪自愿性 | 自愿 | 经3次会见确认，无刑讯逼供、诱供情形 |
| 从宽空间 | 较大 | 初犯+全额退赃+被害人谅解，三重从轻情节叠加 |
| 风险评估 | 低风险 | 涉案金额刚达立案标准，无加重情节 |

**策略结论**：建议走认罪认罚从宽程序，目标为拘役3-6个月+缓刑

**⚠️ 策略提示**：
- 根据《认罪认罚从宽制度指导意见》第6条，认罪认罚从宽贯穿刑事诉讼全过程，但越早认罪从宽幅度越大
- 本案处于审查起诉阶段，从宽幅度优于审判阶段
- 需告知当事人：认罪认罚不影响辩护人独立行使辩护权（刑诉法第37条）

---

### M2 量刑分析

**法定刑幅度**：根据刑法第264条，盗窃5000元属"数额较大"，法定刑三年以下有期徒刑、拘役或者管制，并处或者单处罚金。

**基准刑确定**：

| 步骤 | 内容 | 依据 |
|------|------|------|
| 法定刑幅度 | 拘役至有期徒刑1年 | 刑法第264条"数额较大" |
| 基准刑 | 6-12个月 | 本省量刑指导意见实施细则，盗窃5000元基准刑 |
| 从轻调节 | -30%~-40% | 初犯(-10%)+全额退赃(-10%)+被害人谅解(-10%~15%)+认罪认罚(-10%) |

**⚠️ 调节计算说明**：
- 量刑情节采用**同向累计调节**，非逐项连乘
- 认罪认罚与自首的从宽不叠加计算（本案无自首情节，不涉及竞合）
- 各地从宽幅度存在差异，以上为参考区间

**建议刑期**：拘役3-6个月，并处罚金1000-3000元

**缓刑可行性评估**：

| 条件 | 是否满足 | 说明 |
|------|----------|------|
| 刑期条件（≤3年） | ✅ | 建议刑期在3年以下 |
| 悔罪表现 | ✅ | 全额退赃+被害人谅解 |
| 再犯危险 | ✅ | 初犯，无前科 |
| 社区影响 | ✅ | 非暴力犯罪，社区接纳可能性高 |

**结论**：符合刑法第72条缓刑条件，建议争取缓刑

---

### M3 协商方案

**协商筹码排序**：

| 优先级 | 筹码 | 价值评估 | 使用策略 |
|--------|------|----------|----------|
| 1 | 全额退赃 | 高 | 已完成，直接作为从轻依据 |
| 2 | 被害人谅解书 | 高 | 已取得，配合退赃形成"修复性"论证 |
| 3 | 初犯 | 中 | 配合"再犯危险性低"论证 |
| 4 | 认罪认罚态度 | 中 | 从审查起诉阶段即认罪，从宽幅度优于审判阶段 |

**协商话术要点**：
- 开场："辩护人认为本案符合认罪认罚从宽条件，建议量刑为拘役3-6个月并适用缓刑"
- 论证："张某全额退赃并取得谅解，社会危害性已极大降低，适用缓刑不致再危害社会"
- 让步预案：如检察官坚持实刑，可退一步请求"拘役3个月+缓刑6个月"

**具结书签署建议**：
- 签署时机：确认量刑建议为"拘役3-6个月+缓刑"后再签署
- ⚠️ 如量刑建议超出预期（如实刑6个月以上），有权暂缓签署、继续协商
- 反悔权告知：签署后审判阶段仍有反悔权，但反悔可能导致从宽幅度收回

---

### M4 自愿性审查与风险提示

**自愿性审查清单**：

| 审查项 | 状态 | 说明 |
|--------|------|------|
| 认罪自愿性 | ✅ | 无刑讯、诱供、胁迫情形 |
| 后果理解 | ✅ | 理解认罪认罚将导致有罪判决 |
| 律师帮助 | ✅ | 辩护人已就认罪认罚后果充分告知 |
| 量刑预期 | ✅ | 理解建议量刑为3-6个月拘役+缓刑 |
| 程序选择 | ✅ | 理解适用速裁/简易程序将简化庭审 |

**风险提示**：

1. **量刑建议"明显不当"判断**：如检察官提出"有期徒刑8个月不缓刑"，辩方可依据《认罪认罚从宽制度指导意见》第54条提出异议——建议刑期偏离基准刑上浮超过30%可视为"明显不当"
2. **反悔风险**：签署具结书后如反悔，从宽幅度可能被收回，且可能影响后续辩护策略
3. **被害人反悔风险**：谅解书签署后被害人反悔不影响已签署文件的效力，但可能影响法官心证
4. **上诉权保留**：认罪认罚案件被告人仍有上诉权，但需注意上诉不加刑原则的适用条件

**后续步骤**：
- 与检察官确认量刑建议 → 签署具结书 → 适用速裁/简易程序 → 法院判决
