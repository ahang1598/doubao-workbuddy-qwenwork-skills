# 边缘示例001：当事人反悔撤回认罪认罚

> criminal-plea-negotiation | 边缘示例 | v2.1.0

## 输入

```markdown
张某签署认罪认罚具结书后，开庭前反悔，要求撤回
```

## 边界问题

签署具结书后判决前有权反悔（撤回认罪认罚），但后果需明确告知：
1. 撤回后不再享受从宽待遇
2. 原具结书中的有罪供述可能被用作证据（反悔不撤回此前有罪供述）
3. 检察院可能调整量刑建议（从宽→标准量刑），实质可能导致更重刑罚
4. 仅以量刑过重上诉致从宽量刑明显不当的，检察院可依法抗诉，抗诉后不受上诉不加刑限制（高检发〔2026〕5号）

## 预期输出摘要

```markdown
> ⚠️ **反悔权利告知**
> 当事人有权在判决前撤回认罪认罚，但须了解以下后果：

## 反悔后果

| 后果 | 说明 |
|------|------|
| 不再享受从宽 | 量刑建议可能从"建议缓刑"调整为"建议实刑" |
| 有罪供述风险 | 具结书中的有罪供述仍可能被用作证据，反悔不撤回此前供述 |
| 检察院调整 | 检察院可能调整量刑建议（从宽→标准量刑），实质可能更重 |
| 抗诉加刑风险 | 仅以量刑过重上诉致从宽明显不当的，检察院可抗诉加刑 |

## 建议处理方式

1. 充分了解反悔原因——是否有新证据/被强迫/未理解后果
2. 评估反悔后的辩护方案——是否有无罪/罪轻辩护空间
3. 如决定反悔，应书面通知检察院和法院
4. 重新确定辩护方向

> 关键原则：不得因当事人反悔认罪认罚而对其进行不利评价或施加压力。
```
