# 输入规格

> 本文件定义 criminal-plea-negotiation 技能的完整输入参数规格
> 遵循 compiler/ssot.md §17（SSOT）：输入宽容度契约

## 1. 必需输入

| 字段 | 类型 | 枚举值 | 说明 | 验证规则 |
|------|------|--------|------|----------|
| `suspect_name` | string | - | 犯罪嫌疑人/被告人姓名 | 非空 |
| `alleged_crime` | string | - | 涉嫌罪名 | 非空 |
| `negotiation_stage` | enum | 策略评估/量刑协商/具结审查 | 协商阶段 | 必须为枚举值 |

## 2. 可选输入

### 2.1 犯罪嫌疑人信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `suspect_gender` | string | [待补充] | 性别 |
| `suspect_age` | string | [待补充] | 年龄 |
| `prior_record` | boolean | false | 是否有前科 |
| `has_confessed` | boolean | false | 是否已认罪 |

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|

| `evidence_status` | string | [待补充] | 证据状况 |
| `statutory_penalty` | string | [待补充] | 法定刑幅度 |
| `case_stage` | enum | 审查起诉 | 侦查/审查起诉/一审 |

### 2.3 协商参数

| 字段 | 类型 | 默认值 | 说明 |

| `victim_attitude` | enum | 谅解/无意见/反对 | 被害人态度 |

| `defendant_willingness` | enum | 主动/被动/犹豫 | 认罪认罚意愿 |

## 3. 输入宽容度契约

| 最小输入 | 处理方式 |
|----------|----------|
| 仅嫌疑人+罪名+阶段 | 生成协商策略框架 |
| 仅"认罪认罚"/"协商" | 询问案件信息 |

交互补全最多3轮。

## 4. 场景适配规则

### 4.1 协商阶段适配

| negotiation_stage | 工作重点 | 典型输出 |
|-------------------|----------|----------|
| 策略评估 | 是否认罪认罚+利弊分析 | 策略评估报告 |
| 量刑协商 | 与检察院协商量刑+争取从宽 | 量刑协商方案 |
| 具结审查 | 审查具结书+权利保障 | 具结书审查意见 |

### 4.2 认罪认罚从宽制度核心

> **刑诉法第15条**：犯罪嫌疑人、被告人自愿如实供述自己的罪行，承认指控的犯罪事实，愿意接受处罚的，可以依法从宽处理。
>
> **从宽≠减轻**：从宽包括从轻处罚和减轻处罚，但不等于必然减轻。
> **自愿性是核心**：认罪认罚必须自愿，不得强迫。

### 4.3 风险提示

| 风险 | 说明 | 应对 |
|------|------|------|
| 认罪后反悔 | 可能导致从宽情节丧失 | 充分评估后再决定 |
| 量刑建议偏高 | 检察院建议可能高于预期 | 可提出异议 |
| 具结书内容不利 | 可能包含不利条款 | 仔细审查 |
| 程序简化 | 可能减少质证机会 | 评估是否接受 |
