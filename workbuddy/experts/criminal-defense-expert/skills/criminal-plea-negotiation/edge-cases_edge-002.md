# 边缘示例002：量刑预期差距过大（协商破裂场景）

> criminal-plea-negotiation | 边缘示例 | v2.1.0

## 输入

```markdown
犯罪嫌疑人王某，涉嫌诈骗罪，审查起诉阶段。
案件事实：涉嫌诈骗金额120万元，3名被害人
从轻情节：已退赔30万元（约25%），初犯
检察院量刑建议：有期徒刑7-9年
当事人意愿：希望3年以下或缓刑
negotiation_stage: 量刑协商
case_stage: 审查起诉
```

## 边界问题

当事人量刑预期（3年以下或缓刑）与检察院量刑建议（7-9年）差距极大。诈骗120万元的法定刑为3-10年，检察院建议7-9年处于法定刑中上段。缓刑适用条件为3年以下有期徒刑+不致再危害社会，而诈骗120万元退赔仅25%+建议刑期7-9年，缓刑几乎不可能。此场景下协商极可能破裂，律师须做好降级方案准备。

## 预期输出特征

- **如实评估协商空间**：不因当事人期望而虚高预期——标注"协商空间有限"
- **量化差距分析**：明确检察院建议7-9年 vs 当事人期望3年以下/缓刑的差距
- **降级方案准备**：协商破裂时的替代策略
- **不得承诺或暗示可达目标**：禁止"争取3年以下""有望缓刑"等表述
- **反悔风险前置告知**：即使协商破裂，也须完整告知权利

## 预期输出摘要

```markdown
# 量刑协商方案

——审查起诉阶段·量刑协商——

## 一、协商空间评估

⚠️ **协商空间有限**：当事人期望（3年以下/缓刑）与检察院建议
（7-9年）差距显著，核心障碍如下：

| 障碍项 | 说明 |
|--------|------|
| 法定刑幅度 | 诈骗120万元法定刑3-10年，检察院建议7-9年在法定范围内 |
| 退赔不完全 | 仅退赔30万元（约25%），远未全额退赔 |
| 缓刑条件不符 | 缓刑须3年以下有期徒刑，检察院建议7-9年，差距过大 |
| 被害人态度 | 3名被害人有2名未获赔偿，可能反对缓刑 |

## 二、辩方可用的协商筹码

| 筹码 | 证据状态 | 协商价值 |
|------|---------|---------|
| 继续退赔 | 当事人家属正在筹款 | 中——可争取从宽但幅度有限 |
| 初犯偶犯 | 无前科 | 低——对大幅减刑作用有限 |
| 认罪认罚 | 当事人愿意认罪 | 中——审查起诉阶段认罪可获15%-25%从宽 |
| 被害人谅解 | 1名已退赔被害人可争取谅解 | 中——可争取个别被害人谅解 |

## 三、现实可行方案

### 方案A：全力退赔+谅解（推荐）
- 筹集资金退赔剩余90万元
- 争取3名被害人书面谅解
- 预期结果参考：5-7年（仍有较大不确定性）
- 风险：退赔后量刑仍可能高于当事人预期

### 方案B：部分退赔+认罪认罚
- 继续退赔至50%以上
- 争取至少2名被害人谅解
- 预期结果参考：6-8年
- 风险：退赔不完全+部分被害人反对

### 方案C：拒绝认罪认罚+无罪/罪轻辩护
- 对诈骗金额提出异议
- 适用技能：criminal-prosecution-defense
- 风险：如辩护失败，可能判处8-10年且无从宽

> **声明**：以上方案预期结果仅为参考，不构成任何承诺或保证。
> 具体量刑由法院依法判决。

## 四、具结书签署建议

⚠️ **不建议在当前条件下签署具结书**：
- 检察院量刑建议（7-9年）与当事人预期（3年以下/缓刑）差距过大
- 签署具结书后检察机关不得单方撤销（高检发〔2026〕5号第33条）
- 建议先全力退赔+争取谅解后重新协商

## 五、协商不成后的应对

1. 案件正常起诉至法院——进入审判阶段
2. 审判阶段可依据高检发〔2026〕5号第48条提出"明显不当"异议
3. 如认罪认罚基础动摇，可转为普通程序审理
4. 无论是否认罪认罚，均有权获得辩护

## 反悔权告知

[按标准模板告知，同示例002]
```

## 设计要点

1. **如实评估**：协商空间有限时不虚高预期——标注"⚠️协商空间有限"
2. **量化差距**：明确检察院建议 vs 当事人期望的具体差距
3. **降级方案**：方案A/B/C分级应对，而非仅一个方案
4. **不承诺结果**：所有预期结果标注"仅供参考，不构成承诺或保证"
5. **签署时机建议**：差距过大时不建议签署具结书
6. **协商破裂路径**：审判阶段异议+程序转换+持续辩护
