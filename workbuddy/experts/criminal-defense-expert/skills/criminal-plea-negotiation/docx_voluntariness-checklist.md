# 自愿性审查表模板

> criminal-plea-negotiation | DOCX 模板 | v2.1.0
> 排版规范见 docx-format-spec.md §8.2

## 模板结构

```
自愿性审查清单

☐ V1 当事人是否自愿认罪——有无强迫、诱导、欺骗
☐ V2 当事人是否理解认罪认罚的法律后果（"认罪"="承认犯罪事实"+"接受处罚"）
☐ V3 当事人是否理解可以选择不认罪
☐ V4 是否存在刑讯逼供等非法取证情形
☐ V5-1 辩护律师是否在场见证（已委托辩护人的，应由辩护律师见证）
☐ V5-2 如为值班律师在场，是否充分了解案情
☐ V5-3 是否已同步录音录像（高检发〔2026〕5号第38条要求）
☐ V6 当事人是否区分"认罪"与"认罚"的不同——可认罪不认罚
☐ V7 如为部分认罪，是否就不认部分进行了风险告知

排版参数：
- 字体：仿宋_GB2312 三号（16pt）
- 缩进：首行缩进2字符
- checkbox 字符：☐（Unicode 2610）/ ☑（Unicode 2611）
- 间距：各项间段后0pt
- 标题："自愿性审查清单"——黑体三号加粗
```

## 填写指南

| 审查项 | 审查要点 | 常见问题 |
|--------|---------|---------|
| V1 | 当事人真实意思表示，非受胁迫/诱导/欺骗 | 侦查人员"认了就放人"的口头承诺 |
| V2 | 理解"认罪=承认事实+接受处罚"的双重含义 | 当事人以为"认罪"只是态度好 |
| V3 | 理解"可以选择不认罪"的权利 | 当事人以为"必须认罪" |
| V4 | 排除刑讯逼供/威胁/引诱/疲劳审讯 | 当事人不敢说被刑讯 |
| V5-1 | 已委托辩护人的，须辩护律师见证 | 检察官绕开辩护律师安排值班律师 |
| V5-2 | 值班律师须充分了解案情 | 值班律师仅签字不看卷 |
| V5-3 | 签署具结书须同步录音录像 | 未录音录像=违反新规 |
| V6 | 区分"认罪"与"认罚"——可认罪不认罚 | 当事人认罪但不同意量刑建议 |
| V7 | 部分认罪须就不认部分进行风险告知 | 未告知"不认部分仍需辩护" |

    checked_items = checked_items or []
    
    checklist_items = [

        ("V3", "当事人是否理解可以选择不认罪"),
        ("V4", "是否存在刑讯逼供等非法取证情形"),
        ("V5-1", "辩护律师是否在场见证（已委托辩护人的，应由辩护律师见证）"),
        ("V5-2", "如为值班律师在场，是否充分了解案情"),
        ("V5-3", "是否已同步录音录像（高检发〔2026〕5号第38条要求）"),
        ("V6", "当事人是否区分"认罪"与"认罚"的不同——可认罪不认罚"),
        ("V7", "如为部分认罪，是否就不认部分进行了风险告知"),
    ]
    
    # 标题
    title = doc.add_paragraph("自愿性审查清单")
    # 黑体三号加粗
    
    for item_id, item_text in checklist_items:
        checkbox = "☑" if item_id in checked_items else "☐"
