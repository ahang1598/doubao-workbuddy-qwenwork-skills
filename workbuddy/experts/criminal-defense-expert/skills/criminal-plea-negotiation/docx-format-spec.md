## 3. 段落间距规则

### 3.1 核心原则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制，禁止插入仅含空白字符的空段落。

### 3.2 间距值（均为磅值 Pt）

| 元素 | 段前 | 段后 | 说明 |
|------|------|------|------|
| 标题 | 0 | 24pt | 标题后留较大间距 |
| 副标题 | 0 | 12pt | 阶段标识与正文间距 |
| 当事人信息段 | 6pt | 0 | 标题后到信息段 |
| 一级标题 | 12pt | 6pt | — |
| 二级标题 | 6pt | 3pt | — |
| 正文段落 | 0 | 0 | 28磅固定行距即为段落间隔 |
| 法条引用块 | 3pt | 3pt | 与上下文区分 |
| 表格标题 | 12pt | 6pt | 表前间距 |
| checkbox 清单项 | 0 | 0 | 连续排列 |
| 落款第一行 | 12pt | 0 | 正文到落款留空 |
| 落款各行间 | 0 | 0 | 落款内部紧凑 |

## 4. 段落粒度规则

### 4.1 核心原则

**一个段落 = 一个语义单元。** 禁止将多个语义单元塞入同一段落用 `<br/>` 换行。

### 4.2 拆分规则

| 语义单元类型 | 段落数 | 示例 |
|-------------|--------|------|
| 当事人信息 | 1段 | "当事人：张三，涉嫌盗窃罪，审查起诉阶段。" |
| 策略分析要点 | 1段/要点 | 每个利弊要点独立1段 |
| 量刑情节分析 | 1段/情节 | 每个从宽/从重情节独立1段 |
| 协商步骤 | 1段/步骤 | 每步协商动作独立1段 |
| 具结书条款审查 | 1段/条款 | 逐条审查意见独立1段 |
| 法条引用 | 1段/法条 | 每条法条1段 |
| 反悔权告知 | 1段/情形 | 分情形逐段叙述 |

## 5. 编号规则

### 5.1 核心原则

**使用 Word 原生 List Numbering，禁止手动"1. ""2. ""3. "编号。**

### 5.2 编号应用场景

| 场景 | 编号方式 | Word List | 层级 |

| 从宽情节列举 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |

## 7. 三阶段路由差异化排版

> **核心设计**：认罪认罚协商在不同诉讼阶段的策略重心、从宽幅度、风险等级天差地别。本章节定义各阶段的排版差异，确保输出内容对齐阶段特征。

### 7.1 侦查阶段（case_stage = 侦查）

**排版特征**：

| 维度 | 侦查阶段专属规则 |
|------|----------------|
| 协商核心 | 争取取保+固定有利事实+评估"认什么" |
| 从宽幅度区间 | 侦查阶段认罪从宽幅度通常最大（20%-30%） |
| 信息充分度 | 低——证据未完全开示，需风险对冲排版 |
| 策略重心 | 认罪范围选择（全部/部分/不认）+退赃时机 |

**输出模块 M1 策略评估——侦查阶段增补**：

```
一、侦查阶段认罪范围评估
  （一）全部认罪的利弊
  （二）部分认罪的可行性（仅认无争议事实）
  （三）不认罪的风险评估
二、退赃时机选择
  （一）立即退赃的利弊
  （二）等到审查起诉再退的利弊
三、取保候审与认罪认罚联动策略
四、信息不充分下的风险对冲建议
```

**M1 侦查阶段正文渲染**：

| 步骤 | 操作 | 排版要点 |
|------|------|----------|
| R1 | 一级标题"一、侦查阶段认罪范围评估"+ 正文 | 黑体三号一级标题+仿宋三号正文，每评估项1段 |
| R2 | 一级标题"二、退赃时机选择"+ 双栏利弊对照 | 利弊分两段，各以"利："和"弊："开头 |
| R3 | 一级标题"三、取保候审与认罪认罚联动"+ 正文 | 叙述性段落，法条融入论证 |
| R4 | 一级标题"四、风险对冲建议"+ 步骤列举 | Word原生编号 |

### 7.2 审查起诉阶段（case_stage = 审查起诉）

**排版特征**：

| 维度 | 审查起诉阶段专属规则 |
|------|----------------|
| 协商核心 | 量刑协商黄金窗口——检察院有量刑建议权 |
| 从宽幅度区间 | 审查起诉阶段认罪从宽幅度中等（15%-25%） |
| 信息充分度 | 中——阅卷后证据可评估 |
| 策略重心 | 量刑建议协商+具结书签署时机 |

**输出模块 M2 量刑协商——审查起诉阶段增补**：

```
一、检察院量刑建议评估
  （一）量刑建议合理性分析
  （二）与同类案件量刑对比
  （三）确定刑 vs 幅度刑建议的选择
二、辩方量刑意见
  （一）从宽情节逐项论证
  （二）建议量刑及依据
三、协商路径设计
  （一）与承办检察官沟通量刑意向
  （二）提交书面量刑意见
  （三）就主刑、附加刑、缓刑分别协商
  （四）锁定有利条款后签署具结书
四、具结书签署时机策略
  （一）先谈后签 vs 先签后谈
  （二）签署时点与从宽幅度的关系
  （三）先行具结的策略考量
  （四）重新具结程序（高检发〔2026〕5号）
```

**M2 量刑建议对比表排版**：

```

| 对比项 | 检察院建议 | 辩方意见 | 差距分析 |

表格内容：仿宋小四号。
```

| R5 | 一级标题"一、检察院量刑建议评估"+ 正文+量刑建议对比表 | 表格按§8.1规范 |
| R6 | 一级标题"二、辩方量刑意见"+ 逐项论证 | 每个从宽情节1段 |

### 7.3 审判阶段（case_stage = 一审）

**排版特征**：

| 维度 | 审判阶段专属规则 |
|------|----------------|
| 协商核心 | 量刑建议异议+量刑辩护 |
| 从宽幅度区间 | 审判阶段认罪从宽幅度最小（10%-15%） |
| 信息充分度 | 高——证据全开示 |
| 策略重心 | "明显不当"论证+反悔风险评估 |

**输出模块 M3 具结审查——审判阶段增补**：

```
一、量刑建议"明显不当"评估
  （一）与同类案件量刑差距
  （二）未充分考虑法定从宽/从重情节
  （三）超出法定刑幅度
  （四）与犯罪事实、情节严重不符
  （五）计算方法有误
二、审判阶段异议策略
  （一）量刑建议异议的提出方式
  （二）量刑辩护要点
三、反悔/上诉风险告知
  （一）反悔后的后果梯度
  （二）仅以量刑过重上诉的风险
  （三）检察院抗诉加刑风险
四、协商不成后的应对
```

### 8.2 自愿性审查表

**适用阶段**：所有阶段（M1/M2/M3 均须包含）

**格式**：checkbox 清单（非表格），段落级排版。

```
自愿性审查清单

☐ V1 当事人是否自愿认罪——有无强迫、诱导、欺骗
☐ V2 当事人是否理解认罪认罚的法律后果（"认罪"="承认犯罪事实"+"接受处罚"）
☐ V3 当事人是否理解可以选择不认罪
☐ V4 是否存在刑讯逼供等非法取证情形
☐ V5-1 辩护律师是否在场见证（已委托辩护人的，应由辩护律师见证）
☐ V5-2 如为值班律师在场，是否充分了解案情
☐ V5-3 是否已同步录音录像（高检发〔2026〕5号要求）
☐ V6 当事人是否区分"认罪"与"认罚"的不同——可认罪不认罚
☐ V7 如为部分认罪，是否就不认部分进行了风险告知
```

| 属性 | 值 |
|------|-----|

| checkbox 字符 | ☐（Unicode 2610） |
| 间距 | 各项间段后0pt |
| 标题 | "自愿性审查清单"——黑体三号加粗 |

> **v2.0.1 变更说明**：V5 从单一项扩展为 V5-1/V5-2/V5-3 三子项（区分辩护律师/值班律师/同步录音录像），新增 V6（认罪与认罚区分）和 V7（部分认罪风险告知），对应高检发〔2026〕5号强化要求。

### 8.4 反悔权告知组件

**适用阶段**：所有阶段（须在输出文末包含）

**格式**：分级叙述段落（禁止表格），按后果梯度排列。

```
反悔权告知

当事人签署认罪认罚具结书后、判决前有权反悔。但须了解以下后果：

一、从宽不再适用
反悔后认罪认罚从宽不再适用，检察院可以调整量刑建议，
从"从宽量刑建议"调整为"标准量刑建议"，实质上可能导致更重刑罚。

二、已认罪供述的证据效力
反悔仅撤回具结书的程序效力，不撤回此前已做出的有罪供述。
已认罪内容仍可能被作为证据使用，且通常难以推翻。

三、上诉加刑风险
仅以量刑过重为由提出上诉，如导致从宽量刑明显不当，
检察院可以依法抗诉，抗诉后不受上诉不加刑限制，
可能被判处更重刑罚（高检发〔2026〕5号）。

四、反悔的操作要求
反悔应以书面方式向检察院/法院提出；
应在判决前提出；
建议在反悔前充分评估替代辩护方案。
```

**排版参数**：

| 属性 | 值 |
|------|-----|
| 标题 | "反悔权告知"——黑体三号加粗 |
| 引言段 | 仿宋三号，首行缩进2字符 |
| 各梯度 | 一级标题"一、""二、""三、""四、"——黑体三号 |
| 正文 | 仿宋三号，首行缩进2字符 |

> **v2.0.1 变更说明**：旧版核心原则第7条"反悔后不会被加刑"表述不准确，已修正为分级后果告知，纳入检察院抗诉加刑风险和已认罪供述不可撤回等关键信息。

## 9. 特殊排版规则

### 9.1 标题

```
文书标题居中，二号方正小标宋简体加粗，独占一行。
标题格式："认罪认罚协商指引"
副标题格式："——[阶段标识]——" 楷体三号居中
```

### 9.2 阶段标识

```
副标题紧跟标题之后，楷体三号居中。
阶段标识映射：
  策略评估 → "——策略评估——"
  量刑协商 → "——量刑协商——"
  具结审查 → "——具结书审查——"
同时标注 case_stage：
  侦查 / 审查起诉 / 一审
示例："——审查起诉阶段·量刑协商——"
```

### 9.3 落款签名区

```
辩护人：XXX律师               （右对齐）
XXX律师事务所                  （右对齐）
二〇二六年六月十日             （右对齐，中文小写）
```

> **日期"〇"规范**：不可写作"零"或"0"，必须使用"〇"（中文小写）。

### 9.4 O1 正式提交稿约束

- **禁止输出免责声明**：O1(.docx) 提交稿不得包含"免责声明"或"草稿"标识。免责声明仅限 O2(Markdown) 编辑稿保留。
- **正文表格限制**：仅量刑建议对比表和"明显不当"评估清单可使用表格，其余内容必须纯文字叙述+编号段落。
- **禁止Markdown痕迹**：O1(.docx) 中不得出现 `**加粗**`、`[注]`、`---` 等 Markdown 语法残留。
- **禁止内部编码标签**：不得出现 M1/M2/M3/M4、V1/V2、D1/D2 等内部编码标签。用自然法言法语描述。
- **协商记录须标注录音录像状态**：按高检发〔2026〕5号要求，签署具结书须同步录音录像。

### 9.5 法条融入规则

法条引用不设独立"法律依据"段，而是融入各论证段落中。

```
示例：
"根据《刑事诉讼法》第一百七十六条第二款，犯罪嫌疑人认罪认罚的，
人民检察院应当就主刑、附加刑、是否适用缓刑等提出量刑建议……"
```

首次引用须法规全名+条文号，后续可用简称。

## 附录A：三阶段从宽幅度参考

> **重要声明**：以下从宽幅度仅供参考，不可简单叠加。具体从宽幅度由法院综合考量犯罪性质、情节、认罪主动性、退赃赔偿等情况确定。认罪认罚从宽是"可以"从宽（授权性），非"应当"从宽（命令性）。

| 诉讼阶段 | 认罪认罚从宽幅度参考 | 说明 |
|----------|---------------------|------|
| 侦查阶段 | 基准刑的20%-30% | 最早认罪，从宽幅度最大，但信息最不充分 |
| 审查起诉阶段 | 基准刑的15%-25% | 量刑协商黄金窗口，检察院有量刑建议权 |
| 审判阶段 | 基准刑的10%-15% | 最晚认罪，从宽幅度最小，异议空间窄 |

**影响幅度的关键变量**：

| 变量 | 幅度影响 |
|------|---------|
| 主动认罪 vs 被动认罪 | 主动 > 被动 |
| 全部认罪 vs 部分认罪 | 全部 > 部分 |
| 退赃退赔完成度 | 全额 > 部分 > 未退 |
| 被害人谅解 | 有谅解 > 无谅解 |
| 犯罪性质 | 严重经济/毒品/黑恶犯罪从严把握 |
