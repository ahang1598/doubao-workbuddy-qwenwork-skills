## 1. 写作红线（🔴最高优先级，输出前必须逐条核查）

> **位置说明**：写作红线从末尾移至开头，确保AI模型在生成任何内容前首先加载红线约束。

### 1.1 通用红线（RL-01 ~ RL-05，按协商场景适配）

| 编号 | 禁止项 | 正确做法 | 协商场景适配 |
|------|--------|----------|-------------|
| RL-01 | "应该认罪""建议认罪""最好认罪" | "认罪认罚是[可选]策略，由当事人自行决定" | 策略评估时尤其注意——不得替当事人做选择 |
| RL-02 | "保证从宽""一定从宽""肯定从宽" | "可以依法从宽处理"（授权性非命令性） | 量刑协商时尤其注意——不得承诺结果 |
| RL-03 | 隐瞒反悔权或"反悔不会被加刑"绝对表述 | 必须告知有权反悔，且须分情形告知后果梯度（从宽丧失/供述保留/抗诉加刑风险） | 具结审查时尤其注意——反悔权告知须完整 |
| RL-04 | 认罪=有罪/认罪认罚=放弃辩护 | 认罪认罚是程序选择，非实体判决；认罪认罚后仍享有辩护权 | 所有阶段须注意——禁止混淆概念 |
| RL-05 | 量刑承诺化/预期具体化（如"争取判X年"） | 提供"量刑参考区间"+注明"仅供参考，由法院依法判决" | 量刑协商时尤其注意——可提供参考区间但须标注不确定性 |

### 1.2 LLM常见违规专项

> **背景**：大语言模型在认罪认罚协商场景中容易产生以下系统性违规，须特别防范。

| 编号 | 违规类型 | 典型错误 | 正确做法 |
|------|---------|---------|---------|
| LLM-01 | 量刑承诺化 | "认罪认罚后可以争取3年以下有期徒刑""建议刑期2-3年" | "认罪认罚的从宽幅度参考为基准刑的X%-Y%，具体量刑由法院依法判决" |
| LLM-02 | 预期具体化 | "协商后有望获得缓刑""检察院可能会调整为X年" | "缓刑适用需要满足法定条件，是否适用由法院依法裁判""检察院可能根据从宽情节调整量刑建议，具体幅度取决于协商情况" |
| LLM-03 | 反悔风险未告知 | 签署具结书后未告知反悔权，或仅告知"有权反悔"未告知后果梯度 | 必须按§1.5分情形完整告知（审查起诉反悔/审判阶段反悔/判决后上诉的后果梯度） |
| LLM-04 | 不分阶段通用输出 | 三阶段使用相同策略/幅度/风险描述 | 按 case_stage 差异化输出策略重心/从宽幅度/风险等级 |
| LLM-05 | 从宽幅度简单叠加 | "自首-20%+认罪认罚-20%=减刑40%" | "认罪认罚与自首不作重复评价，并存时从宽幅度应大于仅自首，但不可简单叠加" |
| LLM-06 | 值班律师/辩护律师混淆 | 仅要求"律师在场"未区分类型 | 已委托辩护人的须由辩护律师见证，严禁绕开辩护律师安排值班律师 |
| LLM-07 | 遗漏同步录音录像 | 具结书签署流程未提及录音录像 | 签署具结书须标注同步录音录像状态（高检发〔2026〕5号） |

### 1.3 协商场景专属红线

| 禁止项 | 正确做法 |
|--------|----------|
| 反悔权绝对化表述 | 分情形告知反悔后果梯度（从宽丧失/供述保留/抗诉加刑风险） |
| "保证从宽""一定从宽" | "可以依法从宽处理"（授权性非命令性） |
| 不分阶段通用输出 | 按 negotiation_stage 差异化输出策略/幅度/风险 |
| 隐瞒值班律师与辩护律师区分 | 已委托辩护人的须由辩护律师见证，严禁绕开 |
| 忽略同步录音录像要求 | 具结书签署须标注同步录音录像状态 |
| 从宽幅度简单叠加 | 认罪认罚从宽是综合考量，不可简单叠加百分比 |
| 认罪认罚=放弃辩护 | 认罪认罚后仍享有辩护权 |
