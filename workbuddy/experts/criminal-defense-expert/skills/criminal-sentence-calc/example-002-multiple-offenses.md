# 示例2：数罪并罚（完整路径）

## 输入

```
当事人涉嫌两个罪名：
1. 盗窃罪（刑法第264条），建议量刑2年（24个月），自首从轻20%
2. 诈骗罪（刑法第266条），建议量刑3年（36个月），退赃退赔从轻15%

2024-03-15被刑事拘留，一直羁押至判决日2025-06-01。
两个罪都在判决宣告前发现。
```

## 预期输出

# 刑期计算报告

## 一、案件信息摘要

- **涉嫌罪名**：盗窃罪（《刑法》第264条）+ 诈骗罪（《刑法》第266条）
- **量刑情节**：盗窃罪自首（建议从轻20%）/ 诈骗罪退赃退赔（建议从轻15%）
- **羁押概况**：2024-03-15拘留 → 持续羁押至判决日2025-06-01（共444天）
- **并罚情形**：判决宣告前发现数罪 → 适用《刑法》第69条

---

## 二、宣告刑期（各罪）

### 盗窃罪（《刑法》第264条）

```
宣告刑 = 24个月 × (1 − 0.20) = 24 × 0.80 = 19.2个月 ≈ 19个月
```

### 诈骗罪（《刑法》第266条）

```
宣告刑 = 36个月 × (1 − 0.15) = 36 × 0.85 = 30.6个月 ≈ 31个月
```

> **量刑竞合检查**：盗窃罪仅自首一项从轻，诈骗罪仅退赃一项从轻，无重复评价风险。

---

## 三、数罪并罚规则适用

### （一）并罚情形判定

盗窃罪（19个月）+ 诈骗罪（31个月），均在判决宣告前发现
→ 适用《刑法》第69条

### （二）各罪刑期对照

| 罪名 | 宣告刑 | 量刑情节 | 法条 |
|------|--------|---------|------|
| 盗窃罪 | 19个月 | 自首从轻20% | 第264条 |
| 诈骗罪 | 31个月 | 退赃从轻15% | 第266条 |

### （三）并罚上限

| 项目 | 值 |
|------|-----|
| 总和刑期 | 19 + 31 = **50个月** |
| 最高刑期 | **31个月** |
| 第一档上限（总和<35年） | 50个月 < 35年 → **20年(240个月)** |
| 并罚范围 | **31个月 ~ 50个月** |

### （四）最终宣告刑

假设酌情在40%位置：31 + (50 − 31) × 0.40 = 31 + 7.6 ≈ **39个月（3年3个月）**

## 五、折抵后剩余刑期

```
宣告刑（并罚后）：39个月 ≈ 1,170天
折抵天数：444天
剩余刑期 = 1,170天 − 444天 = 726天
         ≈ 24个月6天（2年0个月6天）
```
