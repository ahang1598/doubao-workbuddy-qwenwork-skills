## 一、羁押折抵计算

### 1.1 折抵比例速查

| 羁押/强制措施类型 | 主刑类型 | 折抵比例 | 法条 | 示例 |
|----------------|---------|---------|------|------|
| 羁押（拘留/逮捕） | 管制 | 1:2 | 第41条 | 羁押30天 → 折抵60天管制 |
| 羁押（拘留/逮捕） | 拘役 | 1:1 | 第44条 | 羁押30天 → 折抵30天拘役 |
| 羁押（拘留/逮捕） | 有期徒刑 | 1:1 | 第47条 | 羁押30天 → 折抵30天有期徒刑 |
| 指定居所监视居住 | 管制 | 1:1 | 刑诉法第76条 | 监视居住30天 → 折抵30天管制 |
| 指定居所监视居住 | 拘役/有期徒刑 | 2:1 | 刑诉法第76条 | 监视居住60天 → 折抵30天拘役/有期徒刑 |
| 一般监视居住 | — | 不折抵 | — | 仅限制人身自由，非剥夺 |
| 取保候审 | — | 不折抵 | — | 同上 |

**v2.2.0 新增**：指定居所监视居住折抵比例（刑诉法第76条），与羁押折抵比例不同。

### 1.2 连续羁押计算（v2.2.0 修正）

```
羁押天数（事实描述）= 含首尾天数（inclusive=True）
  → 用于O3明细表展示，如"羁押448天"

折抵基数（计算用）= 数学差天数（inclusive=False）
  → 用于折抵回溯和释放日计算，如"折抵基数447天"
```

**示例**：
```
拘留：2024-03-15
审判日：2025-06-05
含首尾天数：448天（O3展示用）
数学差天数：447天（折抵计算用）

折抵回溯验证：
  判决日 - 数学差天数 = 2025-06-05 - 447天 = 2024-03-15 ✅ 与羁押起始日重合
  判决日 - 含首尾天数 = 2025-06-05 - 448天 = 2024-03-14 ❌ 偏早1天
```

**隐性规则**：
- 羁押首尾均计：拘留当日计入羁押天数（O3事实描述）
- 取保候审/一般监视居住期间**不计入**羁押——只计实际在看守所的期间
- 指定居所监视居住期间按2:1比例单独计算折抵（拘役/有期徒刑）

### 1.3 分段羁押计算

当羁押有中断时，分段计算：

```
羁押段1：2024-03-15 → 2024-05-20（取保候审）= 67天（含首尾）/ 66天（数学差）
羁押段2：2024-08-01 → 2025-06-05（重新羁押）= 309天（含首尾）/ 308天（数学差）
总羁押天数（展示）：67 + 309 = 376天
折抵基数（计算）：66 + 308 = 374天
```

**中断识别信号**：用户输入含"取保候审""监视居住""释放"等关键词。

### 1.4 混合羁押类型计算（v2.2.0 新增）

当羁押期间包含指定居所监视居住时：

```
示例：有期徒刑，羁押90天 + 指定居所监视居住60天
  羁押折抵天数 = 90 × 1 = 90天（1:1）
  监视居住折抵天数 = 60 ÷ 2 = 30天（2:1）
  总折抵天数 = 90 + 30 = 120天
```

### 1.5 折抵后剩余刑期

```
剩余天数 = 宣告刑天数（逐月推算） − 折抵天数（数学差计算）

如剩余 ≤ 0：
  → "羁押已超宣告刑期，应立即释放"
  → 折抵溢出的天数不结转（仅释放）
```

## 二、宣告刑期计算

### 2.1 计算公式（v2.2.0 增强）

```
宣告刑 = 基准刑 × (1 − 累计从轻减轻幅度)
```

**v2.2.0 增强规则**：
1. 累计从轻幅度通常不宜超过60%（超过→警告+标注"请核实"）
2. 自首+认罪认罚不得重复评价同一悔罪事实
3. 从轻情节：宣告刑 ≥ 法定刑下限
4. 减轻情节：宣告刑可 < 法定刑下限（标注"含减轻情节"）

```
如仅有从轻情节：
  宣告刑 = max(法定刑下限, 基准刑 × (1 − 累计从轻幅度))

如有减轻情节：
  宣告刑 = 基准刑 × (1 − 累计幅度)  # 可突破法定刑下限
  ⚠️ 标注："含减轻情节，宣告刑可能低于法定刑下限"
```

### 2.2 量刑情节幅度速查（v2.2.0 校准，依据法发〔2021〕21号）

| 情节 | 类型 | 幅度 | 法条 | 来源 |
|------|------|------|------|------|
| 自首（一般） | 从轻/减轻 | 减少基准刑的40%以下 | 第67条第1款 | 法发〔2021〕21号 |
| 自首（犯罪较轻） | 减轻/免除 | 可减少40%以上或依法免除 | 第67条第1款 | 法发〔2021〕21号 |
| 坦白（如实供述） | 从轻 | 减少基准刑的20%以下 | 第67条第3款 | 法发〔2021〕21号 |
| 立功（一般） | 从轻/减轻 | 减少基准刑的20%以下 | 第68条 | 法发〔2021〕21号 |
| 立功（重大） | 减轻 | 减少基准刑的20%-50% | 第68条 | 法发〔2021〕21号 |
| 从犯 | 从轻/减轻/免除 | 减少基准刑的20%-50% | 第27条 | 法发〔2021〕21号 |
| 未遂 | 从轻/减轻 | 比照既遂减少50%以下 | 第23条 | 法发〔2021〕21号 |
| 认罪认罚 | 从轻 | 减少基准刑的30%以下；含自首/坦白/退赃退赔等可减少60%以下 | 刑诉法第15条 | 法发〔2021〕21号 |
| 退赃退赔 | 从轻 | 减少基准刑的30%以下 | 相关司法解释 | 法发〔2021〕21号 |

**重要**：幅度仅为估算参考值，实际以用户提供的幅度为准。

### 2.3 法定刑区间确定

| 步骤 | 操作 |
|------|------|
| 1 | 根据罪名找到刑法条文 |
| 2 | 读取基本法定刑区间（如"3年以上10年以下"） |
| 3 | 检查有无加重/减轻情节配置（如"数额特别巨大"→10年以上） |
| 4 | 应用量刑情节后，检查宣告刑是否在法定刑区间内（含减轻后下限） |

### 2.4 量刑情节竞合处理（v2.2.0 新增）

| 场景 | 处理规则 |
|------|---------|
| 自首 + 认罪认罚 | ⚠️ 禁止重复评价"如实供述"——自首已含悔罪评价，认罪认罚在此基础上给予增量，通常累计不超过25% |
| 坦白 + 认罪认罚 | 坦白是认罪认罚的前提，不应重复计算 |
| 多个从轻情节 | 同向相加，但累计不宜超过60% |
| 从轻 + 减轻 | 减轻可突破法定刑下限，从轻不可 |
| 从轻 + 从重 | 逆向相减，结果可能为0或正值 |

## 三、数罪并罚计算

### 3.1 三种情形对比

| 情形 | 法条 | 计算方法 | 公式 |
|------|------|---------|------|
| 宣告前数罪 | 第69条 | 直接并罚 | 总和以下/最高以上 |
| 漏罪（已执行中） | 第70条 | 先并后减 | (前+后按69条并罚) − 已执行 |
| 新罪（执行中） | 第71条 | 先减后并 | (前罪剩余) + 后罪按69条并罚 |

### 3.2 第69条并罚上限公式

```
设各罪刑期为 T1, T2, ..., Tn
总和 = Σ Ti
最高 = max(T1, T2, ..., Tn)

如总和 < 35年：
  上限 = min(总和, 20年)
  下限 = 最高
  并罚范围 = [最高, min(总和, 20年)]

如总和 ≥ 35年：
  上限 = min(总和, 25年)
  下限 = 最高
  并罚范围 = [最高, min(总和, 25年)]
```

### 3.3 异种主刑并罚处理（v2.2.0 新增，第69条第2款）

| 并罚组合 | 处理规则 | 计算 |
|---------|---------|------|
| 有期徒刑 + 拘役 | **执行有期徒刑**，拘役被吸收 | 有期2年+拘役6月=执行有期2年 |
| 有期徒刑 + 管制 | 执行有期徒刑，**管制另计** | 有期2年+管制1年=有期2年+管制1年(另计) |
| 拘役 + 管制 | 执行拘役，**管制另计** | 拘役6月+管制1年=拘役6月+管制1年(另计) |

**隐性知识**：有期徒刑吸收拘役是刚性规则——即使拘役刑期更长也不叠加。管制不被吸收，有期徒刑/拘役执行完毕后管制仍须执行。

### 3.4 附加刑并罚（v2.2.0 新增，第69条第3款）

| 附加刑组合 | 处理规则 | 示例 |
|-----------|---------|------|
| 种类相同 | 合并执行 | 罚金5万+罚金3万=罚金8万 |
| 种类不同 | 分别执行 | 罚金5万+剥夺政治权利3年=两者分别执行 |

### 3.5 第70条 漏罪（先并后减）

```
1. 前罪宣告刑 + 漏罪宣告刑 → 按第69条并罚 → 第69条结果刑
2. 实际剩余 = 第69条结果刑 − 已执行刑期
3. 实际剩余 ≥ 0
```

### 3.6 第71条 新罪（先减后并）

```
1. 前罪剩余 = 前罪宣告刑 − 已执行刑期
2. 前罪剩余 + 新罪宣告刑 → 按第69条并罚 → 最终执行刑
```

**隐性知识**：第71条（先减后并）通常比第70条（先并后减）结果更重，因为"先减"后剩余刑期基数更小，与新罪并罚时新罪刑期占比更高。

## 四、刑期起止日推算

### 4.1 推算公式

```
释放日 = 起算日 + 宣告刑天数（逐月推算）
       = 判决日 + 剩余刑期天数
```

### 4.2 折抵回溯（v2.2.0 修正）

```
刑期起算日 = 判决日 − 折抵天数（数学差）
（即：折抵天数从判决日往前回溯，决定"刑期从哪天起算"）

⚠️ 必须使用数学差（inclusive=False），否则起算日偏早1天
```

### 4.3 示例（v2.2.0 修正后）

```
判决日：2025-06-05
宣告刑：29个月（逐月推算=883天含首尾 / 882天数学差）
折抵基数：447天（数学差，原448天含首尾导致偏早1天）
剩余天数：882 − 447 = 435天

刑期起算日：2025-06-05 − 447天 = 2024-03-15（✅ 与羁押起始日重合）
释放日：2024-03-15 + 883天 = 2026-08-15
       或 2025-06-05 + 435天 = 2026-08-14（差1天因含首尾计差异，以逐月推算为准）

逐月推算验证：起算日2024-03-15 + 29个月 = 终止日2026-08-14
释放日 = 2026-08-15（刑期终止日的次日）
```

### 4.4 刑期起算日判定（v2.2.0 增强）

| 情形 | 刑期起算日 | 说明 |
|------|-----------|------|
| 已被连续羁押者 | 首次羁押日 | 刑期回溯至首次羁押日 |
| 取保候审后判实刑 | 实际收监日 | 可能远晚于判决宣告日 |
| 判决执行之日 | 交付执行机关执行之日 | 刑法第47条规定的法定起算基准 |

**特殊规则**：
- 判决日 ≠ 判决生效日：判决宣告后10日内可能上诉，生效日 = 上诉期满日
- 本技能以判决日为基准计算，律师需根据判决生效日自行调整
- 执行通知书上有正式刑期起止——本计算结果为预估参考

## 五、跨年/闰年/月份天数处理

### 5.1 闰年判断

```
年份能被4整除但不能被100整除，或能被400整除 → 闰年
闰年2月有29天
```

### 5.2 月→天换算：逐月推算法（v2.2.0，替代30天/月概算）

> ⚠️ 废弃"30天/月概算"——按刑诉法解释第202条逐月推算

**法律依据**：最高人民法院《关于适用〈刑事诉讼法〉的解释》第202条
> "以月计算的刑期，自本月某日至下月同日的前1日为1个月；没有下月同日的，本月末日为1个月的最后一日。"

**逐月推算步骤**：
1. 起算日 + 1个月 = 下月同日的前1日
2. 下月无同日 → 本月末日
3. 每月天数 = 28/29/30/31天（视月份和闰年而定）
4. 终止日 = 起算日 + N个月的逐月推算终点
5. 释放日 = 终止日的次日

**月份天数参考**：

| 月 | 天数 | 月 | 天数 |
|---|------|---|------|
| 1 | 31 | 7 | 31 |
| 2 | 28/29 | 8 | 31 |
| 3 | 31 | 9 | 30 |
| 4 | 30 | 10 | 31 |
| 5 | 31 | 11 | 30 |
| 6 | 30 | 12 | 31 |

**逐月推算示例**（起算日2024-03-15，29个月）：

| 月份 | 起始日 | 终止日 | 天数 |
|------|--------|--------|------|
| 1 | 2024-03-15 | 2024-04-14 | 31 |
| 2 | 2024-04-15 | 2024-05-14 | 30 |
| 3 | 2024-05-15 | 2024-06-14 | 31 |
| ... | ... | ... | ... |
| 12 | 2025-02-15 | 2025-03-14 | 28（非闰年） |
| ... | ... | ... | ... |
| 29 | 2026-07-15 | 2026-08-14 | 31 |
| **终止日** | — | **2026-08-14** | **883天（含首尾）** |

30天/月概算：29×30=870天 → **误差13天**❌

**实现**：date_calculator.py `months_to_days(start_date, months)` 函数

### 5.3 跨年计算

当羁押期跨越年份时：
- 同一年内：直接相减
- 跨一年：365/366天基准
- 跨多年：分段逐年计算

## 六、常见错误与纠正

| # | 常见错误 | 纠正 |
|---|---------|------|
| 1 | 60个月 = 5年0月 → 错误 | 60个月 = 5年 = 5年0月 ✅ |
| 2 | 29.4个月 = 29个月12天 → 错误 | 先将0.4月按逐月推算换算天数（非×30） |
| 3 | 折抵比例管制1:2写为1:1 | 仅管制为1:2，拘役和有期徒刑都是1:1 |
| 4 | 取保候审期间计入羁押 | 取保候审/一般监视居住不计入羁押折抵 |
| 5 | 第70条和第71条公式混淆 | 漏罪=先并后减，新罪=先减后并 |
| 6 | 数罪并罚上限25年无条件适用 | 仅总和≥35年时上限才为25年，总和<35年上限为20年 |
| 7 | 月→天使用30天/月概算 | 逐月推算（刑诉法解释第202条），29个月误差13天（v2.2.0） |
| 8 | 折抵计算使用含首尾天数 | 折抵使用数学差，含首尾仅用于事实描述（v2.2.0） |
| 9 | 指定居所监视居住按1:1折抵 | 拘役/有期徒刑2:1折抵（刑诉法第76条）（v2.2.0） |
| 10 | 有期徒刑+拘役简单叠加 | 有期徒刑吸收拘役（第69条第2款）（v2.2.0） |
