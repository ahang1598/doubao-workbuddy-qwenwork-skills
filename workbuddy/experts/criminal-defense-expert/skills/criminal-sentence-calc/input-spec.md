# input-spec.md

## 一、输入模型

### 1.1 必需输入

| # | 字段 | 类型 | 说明 | 最低要求 | 缺失处理 |
|---|------|------|------|---------|---------|
| R1 | 罪名信息 | 自然语言 | 涉嫌罪名的刑法条文编号或罪名名称 | 至少能识别1个罪名 | 拒接："请提供涉嫌罪名（至少一个），例如'盗窃罪（刑法第264条）'" |
| R2 | 量刑情节 | 自然语言 | 自首/立功/从犯/未遂/认罪认罚等从轻减轻情节及幅度 | 至少标注"无从轻减轻情节"或直接给出宣告刑 | 默认"无特殊量刑情节"，标注"如存在从轻/减轻情节请补充" |
| R3 | 羁押信息 | 自然语言+日期 | 拘留日期+逮捕日期+是否连续羁押 | 至少提供羁押起始日期 | 追问1轮→仍无则切换"纯宣告刑模式"（不含折抵），标注"未计算羁押折抵" |

### 1.2 可选输入

| # | 字段 | 类型 | 说明 | 缺失处理 |
|---|------|------|------|---------|
| O1 | 数罪信息 | 自然语言 | 各罪罪名+刑期+宣告前后关系 | 假定单罪计算 + 标注"若为单罪：" |
| O2 | 判决日期 | YYYY-MM-DD | 判决宣告日期 | 按当前日期推算 + 标注"基于假设计算" |
| O3 | 附加刑 | 自然语言 | 罚金/没收财产/剥夺政治权利 | 跳过附加刑计算 |
| O4 | 缓刑/假释违规 | 自然语言 | 缓刑/假释期间违规信息 | 跳过违规处理 |
| O5 | **审理地区** | 自然语言 | 审理省份/直辖市（如"广东省""北京市"） | 仅使用全国统一标准 + 标注"未检索地区细则" |
| O6 | **指定居所监视居住期间** | 自然语言+日期 | 指定居所监视居住的起止日期（触发2:1折抵） | 不计算监视居住折抵，仅计算羁押折抵 |
| O7 | **判决日类型** | 自然语言 | "判决宣告日"（默认）/"实际收监日"——取保后判实刑者需标注 | 默认为"判决宣告日"，标注"如当事人取保候审后判实刑，请提供实际收监日" | |

### 1.3 输入形态

| 模式 | 说明 | 示例 |
|------|------|------|
| 自然语言 | 律师以自然语言描述案情和计算需求 | "当事人盗窃罪，羁押一年多，估计判3年" |
| 结构化片段 | 律师提供分项信息（罪名/刑期/羁押日期分列） | "罪名：盗窃罪，宣告刑：有期徒刑3年，拘留：2024-03-15" |

**处理策略**：均在 Phase 1 归一化为结构化中间表示（OffenseRecord + CustodyTimeline + SentencingFactors）。

## 二、校验规则

### 2.1 罪名校验

| 规则 | 检测方式 | 失败处理 |
|------|---------|---------|
| 非空 | 含刑法条文编号或罪名关键字 | 拒接 |
| 法域正确 | 可识别为刑法罪名 | 若为民事/行政 → 拒接并指引 |
| 罪名可识别 | 在刑法分则中有对应条文 | 无法匹配 → 提示手动输入条文编号，继续计算 |

### 2.2 羁押日期校验

| 规则 | 检测方式 | 失败处理 |
|------|---------|---------|
| 非空 | 含日期或明确的时间范围 | 追问1轮 |
| 格式统一 | YYYY-MM-DD 或可换算 | 自动转换为 YYYY-MM-DD |
| 逻辑合理 | 拘留日 ≤ 逮捕日 ≤ 判决日 | 警告，标注"日期顺序异常，请核实" |

### 2.3 量刑情节校验

| 规则 | 检测方式 | 失败处理 |
|------|---------|---------|
| 非空 | 含量刑相关关键词（自首/立功/从犯/未遂/认罪认罚/从轻/减轻等） | 默认"无特殊情节" |
| 幅度明确 | 含百分比或具体年/月 | 模糊 → 输出区间 + 置信度 low |

### 2.4 审理地区校验

| 规则 | 检测方式 | 失败处理 |
|------|---------|---------|
| 非空 | 含省级行政区名称 | 仅使用 P0 全国统一标准 |
| 可检索 | 匹配 31 省关键词映射表 | 无法匹配 → 通用搜索词，标注 province_match_type: unknown |

## 三、量刑幅度来源优先级

宣告刑计算的量刑幅度遵循三级来源优先级（P0→P1→P2），在输出中标注来源：

| 优先级 | 来源 | 说明 | 来源标注 |
|--------|------|------|---------|
| **P0** | 全国统一标准 | 最高人民法院量刑指导意见（内置） | `source: national_baseline` |
| **P1** | 地区细则 | 各省高院量刑指导意见实施细则（agent 联网检索） | `source: regional_guideline` + 来源 URL |
| **P2** | 用户自定 | 用户明确提供的量刑幅度 | `source: user_specified`（**最高优先级，始终覆盖 P0/P1**） |

**规则**：P2 > P1 > P0。仅当用户未明确提供幅度时，才检索 P1/P0 补充。

## 四、缺失降级路径

```
输入验证 Phase 1 门控：
  ┌─ 罪名缺失 → 拒接，输出提示
  ├─ 羁押日期缺失 → 追问1轮 → 仍无 → 切换"纯宣告刑模式"
  ├─ 审理地区缺失 → 仅使用 P0 全国统一标准 + 标注"未检索地区细则"
  ├─ 数罪信息不完整 → 假定单罪 + 标注
  ├─ 量刑幅度模糊 → 输出区间（min-max）+ confidence: low
  └─ 通过 → 进入 Phase 2
```
