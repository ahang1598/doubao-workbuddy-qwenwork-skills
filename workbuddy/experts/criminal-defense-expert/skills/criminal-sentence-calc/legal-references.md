## 一、羁押折抵法条

### 《刑法》第41条（管制刑期折抵）

> 管制的刑期，从判决执行之日起计算；判决执行以前先行羁押的，羁押一日折抵刑期二日。

| 要素 | 值 |
|------|-----|
| 适用刑罚 | 管制 |
| 折抵比例 | **1:2**（羁押1日 = 折抵2日） |
| 起算基准 | 判决执行之日 |
| 适用条件 | 判决执行以前的先行羁押 |

### 《刑法》第44条（拘役刑期折抵）

> 拘役的刑期，从判决执行之日起计算；判决执行以前先行羁押的，羁押一日折抵刑期一日。

| 要素 | 值 |
|------|-----|
| 适用刑罚 | 拘役 |
| 折抵比例 | **1:1** |
| 起算基准 | 判决执行之日 |
| 注 | 拘役期限：1个月以上6个月以下，数罪并罚≤1年 |

### 《刑法》第47条（有期徒刑折抵）

> 有期徒刑的刑期，从判决执行之日起计算；判决执行以前先行羁押的，羁押一日折抵刑期一日。

| 要素 | 值 |
|------|-----|
| 适用刑罚 | 有期徒刑 |
| 折抵比例 | **1:1** |
| 起算基准 | 判决执行之日 |
| 注 | 有期徒刑期限：6个月以上15年以下，数罪并罚≤25年 |

## 二、监视居住折抵法条

### 《刑事诉讼法》第76条（指定居所监视居住折抵）

> 指定居所监视居住的期限应当折抵刑期。被判处管制的，监视居住一日折抵刑期一日；被判处拘役、有期徒刑的，监视居住二日折抵刑期一日。

| 要素 | 值 |
|------|-----|
| 适用情形 | 指定居所监视居住（非一般监视居住） |
| 管制折抵 | **1:1**（监视居住1日 = 折抵1日管制） |
| 拘役/有期徒刑折抵 | **2:1**（监视居住2日 = 折抵1日拘役/有期徒刑） |
| 法条依据 | 《刑事诉讼法》第76条 |

**重要区分**：
- 一般监视居住（刑诉法第74条）**不计入**羁押折抵——与取保候审同理，仅限制人身自由但未完全剥夺
- **指定居所监视居住**（刑诉法第75条）方可折抵——因其实际上剥夺了人身自由
- 实务场景：监委调查阶段的留置+指定居所监视居住，转入刑事诉讼后，留置期间1:1折抵，指定居所监视居住期间2:1折抵（拘役/有期徒刑）

## 三、数罪并罚法条

### 《刑法》第69条（判决宣告前数罪并罚）

**第1款**：

> 判决宣告以前一人犯数罪的，除判处死刑和无期徒刑的以外，应当在总和刑期以下、数刑中最高刑期以上，酌情决定执行的刑期，但是管制最高不能超过三年，拘役最高不能超过一年，有期徒刑总和刑期不满三十五年的，最高不能超过二十年，总和刑期在三十五年以上的，最高不能超过二十五年。

**第2款**：

> 数罪中有判处有期徒刑和拘役的，执行有期徒刑。数罪中有判处有期徒刑和管制，或者拘役和管制的，有期徒刑、拘役执行完毕后，管制仍须执行。

**第3款**：

> 数罪中有判处附加刑的，附加刑仍须执行，其中附加刑种类相同的，合并执行，种类不同的，分别执行。

| 要素 | 值 |
|------|-----|
| 适用情形 | 判决宣告前，所有罪行均已发现 |
| 并罚范围（第1款） | 总和刑期以下、最高刑期以上 |
| 管制上限 | ≤ 3年 |
| 拘役上限 | ≤ 1年 |
| 有期徒刑上限（总和<35年） | ≤ 20年 |
| 有期徒刑上限（总和≥35年） | ≤ 25年 |
| **有期徒刑吸收拘役（第2款）** | 数罪中有有期徒刑+拘役 → 只执行有期徒刑，拘役被吸收 |
| **管制仍须执行（第2款）** | 有期徒刑+管制 → 有期徒刑执行完毕后，管制仍须执行 |
| **附加刑并罚（第3款）** | 附加刑仍须执行；种类相同合并执行，种类不同分别执行 |

### 《刑法》第70条（漏罪并罚——"先并后减"）

> 判决宣告以后，刑罚执行完毕以前，发现被判刑的犯罪分子在判决宣告以前还有其他罪没有判决的，应当对新发现的罪作出判决，把前后两个判决所判处的刑罚，依照本法第六十九条的规定，决定执行的刑罚。已经执行的刑期，应当计算在新判决决定的刑期以内。

| 要素 | 值 |
|------|-----|
| 适用情形 | 判决宣告后、执行完毕前，发现漏罪（漏罪发生在宣告前） |
| 计算方法 | 先并（前后罪按69条并罚）→ 后减（减去已执行刑期） |

### 《刑法》第71条（新罪并罚——"先减后并"）

> 判决宣告以后，刑罚执行完毕以前，被判刑的犯罪分子又犯罪的，应当对新犯的罪作出判决，把前罪没有执行的刑罚和后罪所判处的刑罚，依照本法第六十九条的规定，决定执行的刑罚。

| 要素 | 值 |
|------|-----|
| 适用情形 | 判决宣告后、执行完毕前，又犯新罪 |
| 计算方法 | 先减（前罪剩余刑期）→ 后并（与后罪按69条并罚） |

## 四、刑期起算法条

### 《刑法》第51条（死缓减为有期徒刑的起算）

> 死刑缓期执行的期间，从判决确定之日起计算。死刑缓期执行减为有期徒刑的刑期，从死刑缓期执行期满之日起计算。

### 《刑法》第73条（缓刑考验期）

> 拘役的缓刑考验期限为原判刑期以上一年以下，但是不能少于二个月。有期徒刑的缓刑考验期限为原判刑期以上五年以下，但是不能少于一年。

## 五、刑期计算规则

### 最高人民法院《关于适用〈刑事诉讼法〉的解释》第202条（以月计算刑期的换算规则）

> 以月计算的刑期，自本月某日至下月同日的前1日为1个月；没有下月同日的，本月末日为1个月的最后一日。

**计算规则**：
- 1个月 ≠ 30天（法律上不存在"1个月=30天"的换算规则）
- 1个月可能是28天、29天、30天或31天
- **必须逐月推算**，考虑2月28/29天、大小月天数差异
- 废弃"30天/月概算"——29个月×30=870天（概算）vs 883天（逐月推算），误差达13天

**示例**（起算日2024-03-15，刑期29个月）：
```
第1个月：2024-03-15 → 2024-04-14 = 31天
第2个月：2024-04-15 → 2024-05-14 = 30天
...
第29个月：2026-07-15 → 2026-08-14 = 31天
终止日：2026-08-14
释放日：2026-08-15（刑期终止日的次日）
```

### 《刑法》第47条与刑期起算

> 有期徒刑的刑期，从判决执行之日起计算。

**三种日期区分**：
| 日期类型 | 含义 | 对计算的影响 |
|---------|------|------------|
| 判决宣告之日 | 判决书落款日期 | 仅作参考 |
| 判决生效之日 | 上诉期满日或二审裁定送达日 | 法律效力起始 |
| 判决执行之日 | 判决生效后交付执行机关执行之日 | 刑期起算基准 |

**实务规则**：
- 已被连续羁押者 → 刑期起算日回溯至首次羁押日
- 取保候审后判实刑者 → 刑期起算日=实际收监日（可能远晚于判决宣告日）

## 六、缓刑/减刑法条

### 《刑法》第78条（减刑条件与限度）

> 被判处管制、拘役、有期徒刑、无期徒刑的犯罪分子，在执行期间，如果认真遵守监规，接受教育改造，确有悔改表现的，或者有立功表现的，可以减刑……

| 要素 | 值 |
|------|-----|
| 减刑后实际执行最低年限（无期→有期） | **≥ 13年**（第78条第2款） |
| 减刑后实际执行最低年限（管制/拘役/有期徒刑） | **≥ 原判刑期的1/2** |

### 《刑法》第79条（减刑程序）

> 对于犯罪分子的减刑，由执行机关向中级以上人民法院提出减刑建议书。

### 《刑法》第80条（无期徒刑减刑的刑期计算）

> 无期徒刑减为有期徒刑的刑期，从裁定减刑之日起计算。

## 七、执行程序法条

### 《刑事诉讼法》第264条（交付执行）

> 罪犯被交付执行刑罚的时候，应当由交付执行的人民法院在判决生效后十日以内将有关的法律文书送达公安机关、监狱或者其他执行机关。
