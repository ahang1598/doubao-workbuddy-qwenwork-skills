# 风险框架：criminal-arrest-review

> 不予批捕法律意见书 | 版本: v2.1.0

## 1. 风险等级

**L3（高风险）**——涉及人身自由权利，审查批捕是刑事程序中最关键的程序节点之一，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证+7天窗口评估 | L1 | 低风险——仅验证输入+评估时机 |
| Phase 2 案件信息结构化+证据标准化 | L2 | 中风险——需准确提取关键信息+证据达标判定 |
| Phase 3 三条件逐项击破论证构建 | **L3** | **高风险**——社会危险性评估涉及专业判断+法条匹配精度 |
| Phase 4 预判反驳 | **L3** | **高风险**——反驳逻辑正确性+嵌入位置准确性 |
| Phase 5 文书生成 | L2 | 中风险——需格式合规+结构完整 |
| Phase 6 质量检查+输出组装 | L2 | 中风险——需检查法条准确性+内容完整性 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 强制律师复核标注 | 涉及死刑/无期/重大职务犯罪 | 输出增加⚠️标注 |
| RC-02 | 禁止承诺批捕结果 | 用户询问"能不批捕吗" | 拒绝回答+说明理由 |
| RC-03 | 社会危险性排除必须完整 | 生成论证时 | D1-D5逐项回应 |
| RC-04 | 法条引用强制校验 | 引用法条时 | 仅引用mandatory+supplementary清单中的法条 |
| RC-05 | 输入不充分降级 | 输入不足以支撑论证 | SOFT_DEGRADED C→D→G |
| RC-06 | 禁止引用批捕后法条 | 生成法律依据时 | 不得引用第95条/羁押审查新规 |
| RC-07 | 认罪认罚路径互斥检查 | evidence_insufficient+认罪认罚 | 提醒矛盾并请用户选择 |
| RC-08 | 致送机关固定 | 生成致送机关时 | 审查批捕阶段仅检察院 |
| RC-09 | 质效标准应当不捕条款优先 | 案件满足第27/28条情形 | 优先引用应当不捕条款，不得降级为论证性表述 |
| RC-10 | 第11条举证检查 | 社会危险性论证 | 必须检查公安机关是否提交社会危险性专项证据 |

## 4. 行为约束

- 不得替代律师的专业判断
- 不得对批捕结果做出任何形式的承诺或暗示
- 社会危险性评估仅为辅助论证，不构成法律意见
- 输出需律师审查后方可提交
- 不得在证据条件论证中同时主张认罪认罚（逻辑矛盾）
- 不得引用逮捕后才适用的法条（第95-97条/羁押审查新规）
- 满足质效标准第27/28条应当不捕条款情形时，必须优先引用应当不捕条款，不得仅使用"不符合条件"等论证性表述
- 社会危险性论证中必须检查公安机关是否提交了专项证据（第11条倒逼）
