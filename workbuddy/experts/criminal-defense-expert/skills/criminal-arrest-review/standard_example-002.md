# 标准示例2：轻微暴力犯罪——社会危险性路径

> criminal-arrest-review | example-002

## 输入

```markdown
当事人：赵某
涉嫌罪名：故意伤害罪
拘留日期：2025年6月1日
提请批捕日期：2025年6月8日
案件事实：赵某因邻里纠纷与被害人王某发生口角，推搡中致王某轻伤二级。
辩护要点：
1. 系邻里纠纷引发，非蓄意伤害
2. 已赔偿医疗费3.5万元+精神抚慰金1万元
3. 已取得被害人书面谅解
4. 初犯，无前科
5. 固定住所（本地户籍，住在案发小区），稳定工作（XX公司员工，5年工龄）
6. 家中有8岁女儿需要照顾
论证路径：no_social_danger
和解状态：completed（已全额赔偿+谅解书）
建议措施：取保候审
保证方式：人保（弟弟赵某某，本市户籍，公务员）
```

## 期望输出要点

1. **社会危险性排除**：D1-D5逐项排除——邻里纠纷非蓄意/已赔偿谅解/初犯/固定住所+稳定工作/家中有未成年子女
2. **轻伤案特征**：邻里纠纷引发，非恶性暴力犯罪，社会危害性显著低于蓄意伤害
3. **预判反驳**：
   - "可能实施新犯罪"→邻里纠纷已和解，矛盾已化解
   - "可能打击报复"→已取得谅解，无报复动机
4. **变更措施**：保证人为本市公务员+弟弟关系，约束力强
5. **法条引用**：第81条(社会危险性)+第88条+第90条+第91条+第67条(取保条件)
