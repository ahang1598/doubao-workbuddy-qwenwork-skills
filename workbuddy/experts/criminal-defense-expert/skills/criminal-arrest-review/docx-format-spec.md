# DOCX 排版规范：criminal-arrest-review

> 不予批捕法律意见书 .docx 输出排版标准 | 版本: v2.1.0
>
> **定位**：本文件是 docx 输出的**单一排版事实源**。docx 不从 Markdown 转换而来，而是由 `scripts/generate_docx.py` 按本文档的段落级规范直接调用 python-docx API 生成。
>
> **来源体系**：
> - [参照] GB/T 9704-2012《党政机关公文格式》（页边距/行距/页面布局）
> - [参照] 法发〔2016〕13号《法院诉讼文书格式》（标题/正文字号层级）
> - [参照] 全国律协《律师办理刑事案件规范》(2017) 第105-118条（辩护意见类文书）
> - [惯例] 律师行业实务惯例（致送机关/落款格式）
>
> **权威来源诚实标注**：律师向检察院提交的不予批捕法律意见书无国家强制统一排版标准。上述规范参照 GB/T 9704-2012 及法院文书排版习惯，为行业通行专业惯例。权威来源分级：**T2 全国律协《律师办理刑事案件规范》(2017)** + **T3 行业惯例**。

## 1. 页面布局（含 DXA 精确值）

### 1.1 纸张

| 参数 | 标准值 | DXA 值 | 说明 |
|------|--------|--------|------|
| 纸张 | A4（210mm × 297mm） | 11906 × 16838 | 标准公文用纸，**禁止** US Letter |

> **DXA 单位说明**：Word 内部以 DXA（twips）为长度单位，1 DXA = 1/20 pt = 1/1440 inch。A4 宽度 = 210mm = 11906 DXA，高度 = 297mm = 16838 DXA。

### 1.2 页边距

| 参数 | 标准值 | DXA 值 | 依据 |
|------|--------|--------|------|
| 上边距 | 3.7cm | 2100 | GB/T 9704-2012 |
| 下边距 | 3.5cm | 1984 | GB/T 9704-2012 |
| 左边距 | 2.8cm | 1588 | GB/T 9704-2012 |
| 右边距 | 2.6cm | 1474 | GB/T 9704-2012 |

### 1.3 行距与页码

| 参数 | 标准值 | DXA 值 | 说明 |
|------|--------|--------|------|
| 行距 | 固定值 28 磅 | 560 DXA | 全文统一，含标题 |
| 首行缩进 | 2 字符（约32磅） | 640 DXA | 正文/各级标题统一 |
| 页码 | 页脚居中，"– N –" 格式 | — | 四号宋体（14pt） |

> **页码偏离声明**：F-Strict 默认禁止页脚，但私人法律文书多页情况下需页码保护页序。本技能允许页码（"– N –"居中，宋体四号，距底端1.5cm）。

## 3. 段落间距规则

### 3.1 核心原则

**禁止用空行分段。** 段与段之间通过段前/段后间距控制，禁止插入仅含空白字符的空段落。

### 3.2 间距值（均为磅值 Pt）

| 元素 | 段前 | 段后 | 说明 |
|------|------|------|------|
| 标题 | 0 | 24pt | 标题后留较大间距 |
| 致送机关 | 6pt | 0 | 标题结束后到致送机关 |
| 一级标题 | 12pt | 6pt | — |
| 二级标题 | 6pt | 3pt | — |
| 正文段落 | 0 | 0 | 28磅固定行距即为段落间隔 |
| 法条引用块 | 3pt | 3pt | 与上下文区分 |
| 证据引用块 | 3pt | 3pt | 与上下文区分 |
| "此致" | 12pt | 0 | 结语到"此致"留空 |
| 落款第一行 | 12pt | 0 | 致送机关到落款留空 |
| 落款各行间 | 0 | 0 | 落款内部紧凑 |
| 附件清单标题 | 18pt | 6pt | 签名字后到附件清单留大间距 |

## 4. 段落粒度规则

### 4.1 核心原则

**一个段落 = 一个语义单元。** 禁止将多个语义单元塞入同一段落用 `<br/>` 换行。每个独立的事实陈述、论证要点、证据列举项、请求事项各占一个段落。

### 4.2 拆分规则

| 语义单元类型 | 段落数 | 示例 |
|-------------|--------|------|
| 前言 | 1段 | 前言整体1段（如过长可拆） |
| 案件基本事实叙述 | 1段/事实 | 每项独立事实1段 |
| 7天窗口信息 | 1段 | 独立段落，紧随事实 |
| 逮捕条件论证子项 | 1段/论证子项 | 每项论证独立1段 |
| 证据列举 | 1段/项证据 | 每项证据1段，用 Word 编号 |
| 请求事项 | 1段/项 | 每项请求1段，用 Word 编号 |
| 法条索引项 | 1段/法条 | 每条法条1段 |
| 社会危险性排除项 | 1段/项（D1-D5） | V1/V2变体中逐项分段叙述 |

### 4.3 反例

```
❌ 错误（单段落挤多个含义）：
案件事实（一个段落）：
2025年4月1日拘留；2025年4月3日延长至7天；涉嫌三笔款项分别为20万/35万/32万。

✅ 正确（每项独立段落）：
2025年4月1日，王某某被XX公安分局以涉嫌职务侵占罪刑事拘留。
2025年4月3日，拘留期限延长至7天。
案件涉及三笔款项争议：第一笔20万元；第二笔35万元；第三笔32万元。
```

## 5. 编号规则

### 5.1 核心原则

**使用 Word 原生 List Numbering，禁止手动"1. ""2. ""3. "编号。** 手动编号在编辑/打印时容易出现数字不对齐、序号混乱问题。

### 5.2 编号应用场景

| 场景 | 编号方式 | Word List | 层级 |
|------|----------|-----------|------|
| 请求事项 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 证据列举 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 法条索引 | "1. 2. 3." | `wdListSimpleNumbering` | 一级 |
| 论证子项 | "1. 2. 3." | `wdListSimpleNumbering` | 二级标题下 |
| 社会危险性逐项论证 | "1. 2. 3." | `wdListSimpleNumbering` | 二级标题下（V1/V2变体） |

### 5.3 python-docx 实现

```python
from docx.enum.text import WD_LIST_NUMBERING

# 添加编号段落
para = doc.add_paragraph("不予批准逮捕", style='List Number')
# 或手动设置
para.style = doc.styles['List Number']
```

## 6. 法条引用格式

### 6.1 样式

| 属性 | 值 |
|------|-----|
| 字体 | 楷体_GB2312 |
| 字号 | 三号（16pt） |
| 首行缩进 | 2 字符 |
| 段前/段后 | 各 3pt |
| 对齐 | 两端对齐 |

### 6.2 示例

```
[注] 《中华人民共和国刑事诉讼法》第八十一条第一款第（一）项：
"有证据证明有犯罪事实"——本案现有证据不足以达到此证明标准。
```

### 6.3 法条引用铁律

- 法条编号必须使用中文数字（第八十一条，非第81条）——正文引用时
- 法条简称须加书名号（《刑事诉讼法》，非刑事诉讼法），正文中须**加粗**
- 引用具体款项须标注完整（第八十一条第一款第（一）项）
- `[注]` 标注紧跟法条引用，楷体与正文仿宋区分

## 7. 特殊排版规则

### 7.1 标题

```
文书标题居中，二号方正小标宋简体加粗，独占一行。
标题格式："关于对[嫌疑人姓名]不予批准逮捕的法律意见书"
```

### 7.2 致送机关

```
"[XX市XX区人民检察院]"顶格写，不加缩进。
冒号后不换行，前言段落紧接其后。
```

### 7.3 "此致"与致送机关

```
"此致"：首行缩进2字符
致送机关全称：另起一行，顶格
"此致"与致送机关名之间不插空行
```

### 7.4 落款签名区

```
辩护人：XXX律师        （右对齐）
XXX律师事务所           （右对齐）
2025年4月10日           （右对齐，阿拉伯数字）
```

### 7.5 附件清单

```
签名后独立列出，不参与正文编号体系。
"附件清单"：仿宋三号加粗，左对齐，无缩进，段前18pt。
附件项：仿宋三号，首行缩进2字符，手动编号"1. 2. 3."。
包含法条索引等程序性附属信息。
```

### 7.6 O1 正式提交稿约束

- **禁止输出免责声明**：O1(.docx) 是提交给检察院的正式文书，不得包含"免责声明"——这等同于告诉检察官"这份意见可能是错的"。免责声明仅限 O2(Markdown) 编辑稿保留。
- **禁止正文表格**：法律意见书论证正文中禁止使用任何表格（含 D1-D5 社会危险性对照表）。中国司法文书行文惯例为纯文字叙述，表格会打断论证连贯性。D1-D5 必须改为逐项分段叙述（风险因素→排除理由→证据支撑，自然衔接于同一段落中）。

## 8. 禁止事项

| # | 禁止项 | 正确做法 |
|---|--------|----------|
| F1 | 纸张非 A4（如 US Letter） | 纸张必须设置为 A4（210mm×297mm / 11906×16838 DXA） |
| F2 | 用空行分段 | 用段前/段后间距控制段落间距 |
| F3 | 多个语义单元挤在同一段落（`<br/>` 换行） | 每个语义单元独立为一个段落 |
| F4 | 手动 "1. 2. 3." 编号 | 使用 Word 原生 List Numbering |
| F5 | 用 "———" 字符串模拟分隔线 | 使用 Word 段落底边框 |
| F6 | `@image`、`![xxx](xxx)` 等图片/占位符 | 法律意见书是纯文字文书，禁止任何图片引用 |
| F7 | 段落缩进为 0 或随机值 | 正文和各级标题统一首行缩进 2 字符（640 DXA） |
| F8 | "此致"—空行—"致送机关名" | "此致"与致送机关名之间不插空行（紧接） |
| F9 | 落款签名无右对齐 | 落款区全部右对齐 |
| F10 | 证据列举混在正文段落中 | 证据独立成段，楷体小四号，整段缩进 2 字符 |
| F11 | 结语出现不利自认（如"虽涉及不当行为"） | 结语严格按请求事项总结，禁止任何不利自认表述 |
| F12 | 正文论证中使用表格（D1-D5 社会危险性对照表等） | 法律意见书正文纯文字叙述，D1-D5 改为逐项分段论证 |
| F13 | O1(.docx) 包含"免责声明" | O1 为正式提交稿，删除免责声明；仅 O2(Markdown) 保留 |
| F14 | 保证方式出现"监视居住" | 保证方式仅人保+财保2种（刑诉法第68条），监视居住是独立强制措施 |
| F15 | 正文使用阿拉伯数字法条编号（如"第81条"） | 正文引用须使用中文数字（如"第八十一条"），legal-references.md 可用阿拉伯数字 |
| F16 | 日期使用中文大写（如"二〇XX年"） | 日期使用阿拉伯数字（如"2025年4月10日"），符合律师文书惯例 |
| F17 | 正文字号低于三号（16pt） | 全文统一三号仿宋，标题二号方正小标宋——对标 GB/T 9704 及法院文书习惯 |
