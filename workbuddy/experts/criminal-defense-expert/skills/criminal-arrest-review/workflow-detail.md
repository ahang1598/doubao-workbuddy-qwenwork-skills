# 工作流详情：criminal-arrest-review

> 不予批捕法律意见书 | 版本: v2.1.0 | 更新: 2026-06-10

---

## Phase 1: 输入验证 + 7天窗口评估 + 变体路由 [L2]

### 1.1 输入验证

- 检查4个必填字段是否完整（suspect_name / alleged_crime / case_facts / defense_direction）
- 验证 defense_direction 枚举值合法
- 检查 hard_reject 条件（当事人是否已被逮捕/是否要求预测结果）

### 1.2 7天窗口评估

| 评估项 | 判断逻辑 | 处理 |
|--------|----------|------|
| 拘留日期 vs 当前日期 | 拘留多久了？ | 3-7天一般/30天特殊→即将提请批捕 |
| 是否已提请批捕 | arrest_review_date是否提供？ | 是→7天窗口已开启，标注紧迫性 |
| 提请批捕日期+7天 | 审查批捕截止日 | 标注截止日+建议最迟提交日（截止前2天） |
| defense_direction | 用户指定了什么论证路径？ | 未指定→交互补全询问 |

### 1.3 变体路由

| defense_direction | 自动路由 | 说明 |
|-------------------|----------|------|
| evidence_insufficient | **V1 不构成犯罪** | 证据不足优先→证据条件为主论证 |
| insufficient_culpability | **V2 情节轻微** | 罪责条件路径→罪责+社会危险性为主论证 |
| no_social_danger | **V2 情节轻微** | 社会危险性路径→罪责+社会危险性为主论证 |
| mixed（含evidence_insufficient） | **V1+V2 混合** | 证据条件为主+社会危险性为辅 |
| mixed（不含evidence_insufficient） | **V2 情节轻微** | 罪责+社会危险性双路径 |
| 用户指定程序辩护 | **V3 程序辩护** | 需用户明确指定 |

**检查点**: 必填字段完整 + 无 hard_reject 触发 + 变体路由确定 + 7天窗口信息

## Phase 2: 案件信息结构化 + 证据标准化 [L2]

### 2.1 信息结构化

- 从自然语言输入中提取结构化信息
- 识别论证路径对应的辩护要点
- 评估输入充分度 → 决定输出档次（C/D/G）

### 2.2 证据标准化检查

| 证据类型 | 检查项 | 标记 |
|----------|--------|------|
| 退赃凭证 | 是否有银行转账/公安机关收据 | 不达标→标注[⚠️建议补充] |
| 谅解材料 | 是否有三件配套 | 不达标→标注[⚠️建议补充] |
| 固定住所 | 是否有房产证/租房合同 | 不达标→标注[⚠️建议补充] |
| 稳定职业 | 是否有劳动合同+社保记录 | 不达标→标注[⚠️建议补充] |
| 自首证明 | 是否有到案经过 | 不达标→标注[⚠️建议补充] |
| 前科查询 | 是否有无犯罪记录证明 | 不达标→标注[⚠️建议补充] |
| 疾病证明 | 是否有近3月连续诊疗记录 | 不达标→标注[⚠️建议补充] |

### 2.3 认罪认罚与不构成犯罪的兼容性检查

| 路径组合 | 兼容性 | 处理 |
|----------|--------|------|
| evidence_insufficient + 认罪认罚 | ❌ 不兼容 | 提醒用户选择一条路径 |
| insufficient_culpability + 认罪认罚 | ⚠️ 部分兼容 | 可在罪责条件中引用认罪认罚作为从宽情节，但不得同时主张不构成犯罪 |
| no_social_danger + 认罪认罚 | ✅ 完全兼容 | 认罪认罚是社会危险性排除的有力证据 |
| mixed(含evidence_insufficient) + 认罪认罚 | ⚠️ 须分段 | 在证据条件部分不主张认罪认罚，在社会危险性部分主张 |

**检查点**: 结构化信息完整 + 输出档次确定 + 证据标准化标注完成 + 认罪认罚兼容性确认

## Phase 3: 三条件逐项击破论证构建（按变体路由） [L3]

### 3.1 V1 不构成犯罪：证据条件击破（主论证）

> 刑诉法第81条第1款第(一)项："有证据证明有犯罪事实"
> **v2.1.0 质效标准武器**：第27条（证据瑕疵应当不捕条款）+ 第8条（三项要求标准）

**论证策略**：

| 攻击点 | 适用场景 | 论证方法 | 质效标准引用 |
|--------|----------|----------|-------------|
| 证据数量不足 | 仅有言词证据/单方证言 | 逐一列出现有证据→指出缺失的客观证据→论证不能形成证据链 | **第27条第1项**（仅有有罪供述无印证） |
| 证据质量缺陷 | 证据之间存在矛盾 | 列出矛盾点→论证矛盾导致证据不可靠→达不到证明标准 | **第27条第2项**（主要证据重大矛盾） |
| 证据合法性存疑 | 取证程序可能违法 | 指出程序瑕疵→援引非法证据排除规则（第14条）→论证证据证明力受损 | **第27条第5项**（排非后证据不足） |
| 关键证据缺失 | 缺少定罪核心证据 | 列出应当有但缺失的证据→论证没有该证据不能证明犯罪事实 | **第27条第4项**（间接证据链断裂） |
| 间接证据未形成链条 | 仅有间接证据 | 逐一分析间接证据→指出链条断裂→论证达不到"有证据证明" | **第27条第4项** |
| 事实指向断裂 | 能证明犯罪事实但无法证明当事人实施 | 论证证据仅能证明犯罪发生→无法指向嫌疑人 | **第27条第7项+第8条三项要求** |

> **v2.1.0 策略升级**：在传统"五路攻击法"基础上，每种攻击路径对应第27条的具体情形。论证从"现有证据不足以证明"升级为"属于第27条第X项'[具体情形]'，应当不予批准逮捕"。

**辅论证**：社会危险性条件简述——"即使按照指控事实，本案亦不存在社会危险性"

### 3.2 V2 情节轻微：罪责条件+社会危险性条件击破

**罪责条件论证**：

| 攻击点 | 适用场景 | 论证方法 |
|--------|----------|----------|
| 情节显著轻微 | 危害不大 | 引用刑法第13条但书+量刑指导意见 |
| 可能判拘役/管制 | 量刑预测 | 量刑情节分析→可能刑期<6个月 |
| 可能免予刑事处罚 | 自首+退赃+初犯 | 综合从宽情节→免罚论证 |
| 罪名定性有误 | 应定较轻罪名 | 构成要件对比→应定罪名不达徒刑标准 |
| 涉案金额/数量争议 | 实际金额低于指控 | 金额核减→新金额对应的法定刑档次 |

**社会危险性条件论证**（D1-D5逐项排除）：

> **v2.1.0 质效标准武器**：第11条举证责任倒逼——先检查公安是否提交了社会危险性专项证据；第28条轻罪应当不捕清单；第10条双源引用增强权威

| 因素 | 排除论证方向 | 证据支撑 | 质效标准引用 |
|------|-------------|----------|-------------|
| D1 实施新犯罪 | 案件性质+前科+主观恶性 | 无前科证明/初犯/过失犯/已退赃 | 第28条（初犯/过失犯→应当不捕） |
| D2 危害国家安全/公共安全 | 案件性质排除 | 非国安/公共安全犯罪 | — |
| D3 毁灭/伪造证据/干扰证人 | 证据固定情况 | 核心证据已固定/已取证 | 第11条（公安未提交专项证据→倒逼） |
| D4 打击报复被害人/举报人 | 和解情况 | 已达成和解/谅解 | 第28条（刑事和解→应当不捕） |
| D5 自杀/逃跑 | 住所+职业+家庭 | 固定住所+稳定工作+家庭牵挂+保证人 | — |

**替代措施论证**：
- 取保候审可行性：保证方式**仅人保+财保2种**（刑诉法第68条），**不含监视居住**
- 取保候审足以保障诉讼的具体论证
- 保证人资质/保证金金额

### 3.3 V3 程序辩护：程序违法论证（主论证）

**程序违法攻击点**：

| 攻击点 | 适用场景 | 论证方法 |
|--------|----------|----------|
| 超期羁押 | 拘留超期提请 | 列明拘留日期+法定期限→论证提请批捕超期 |
| 管辖异议 | 不应由本地管辖 | 论证管辖权依据→请求移送 |
| 取证违法 | 非法证据 | 援引第56-60条非法证据排除→论证程序违法 |
| 期限违法 | 各阶段超期 | 逐项列明违法期限→论证程序正义 |

**辅论证**：社会危险性条件——程序违法+无社会危险性→不应当逮捕

> **⚠️ 注意**：刑诉法第56-60条是已知错误高发区（known-pitfalls §1.4），引用时须逐条核验编号与内容匹配。

### 3.4 认罪认罚嵌入（如适用）

> 在社会危险性论证中嵌入认罪认罚作为从宽情节

- 认罪认罚→悔罪表现→社会危险性降低
- 但不得在"证据条件"路径中同时主张
- 须在"社会危险性"路径下单独论述

**检查点**: 变体路由正确 + 三条件击破论证完整（至少一项有实质论证）+ D1-D5逐项排除（如适用）+ 法条引用准确（含质效标准引用）+ 认罪认罚兼容性正确

## Phase 4: 预判反驳 [L3]

### 4.1 识别检方可能批捕理由

| 批捕理由 | 触发条件 | 预判逻辑 | 质效标准武器 |
|----------|----------|----------|-------------|
| "有证据证明有犯罪事实" | 公安机关已收集初步证据 | 逐项分析证据缺陷——数量/质量/合法性/完整性 | **第27条**应当不捕条款 |
| "罪行严重" | 涉嫌重罪/涉案金额大 | 罪重≠社会危险性高（第81条区分犯罪事实与社会危险性） | **第11条**举证责任倒逼（注意轻罪前提） |
| "可能妨碍诉讼" | 侦查未终结/多人作案 | 核心证据是否已固定+保证方案 | **第23/24条**质效考量辅助（当面沟通策略，不写入书面意见） |
| "需要继续侦查" | 案件复杂 | 不批捕≠不侦查（第91条第3款取保继续侦查） | **第23/24条**质效考量辅助（当面沟通策略，不写入书面意见） |

### 4.2 逐项构建针对性反驳

对每个预判批捕理由：
1. 引用法条反驳（优先引用质效标准应当不捕条款）
2. 列明已有证据/措施
3. 嵌入法律意见书对应章节

### 4.3 反驳嵌入策略

- "有证据证明犯罪事实"反驳 → 嵌入V1"不构成XX罪的论证"或V2"不符合逮捕条件"对应段落（优先引用第27条）
- "罪行严重"反驳 → 嵌入社会危险性排除段落（嵌入第11条倒逼）
- "可能妨碍诉讼"反驳 → 嵌入"社会危险性排除"章节（结合第23/24条质效考量辅助说明）
- "需要继续侦查"反驳 → 嵌入"替代措施"章节（结合第23/24条质效考量辅助说明）

> **v2.1.0 新增质效考量辅助说明**（不写入书面意见正文，仅在当面沟通时使用）：
> "恳请贵院充分考量本案证据现状，依法对逮捕必要性进行审慎审查。"

**检查点**: 预判反驳完整嵌入 + 无逻辑矛盾 + 质效标准引用恰当

## Phase 5: 文书生成——主法律意见书 [L2]

### 5.1 按变体结构组装

| 章节 | V1 不构成犯罪 | V2 情节轻微 | V3 程序辩护 |
|------|-------------|------------|------------|
| 前言 | 辩护权来源+案件阶段+核心诉求 | 同 | 同 |
| 一 | 案件基本事实 | 从轻/减轻情节 | 程序违法事实 |
| 二 | 不构成XX罪的论证 | 不符合逮捕条件（D1-D5+第11条） | 程序违法的法律后果 |
| 三 | 无逮捕必要（D1-D5排除） | 政策与情理考量 | 无逮捕必要（D1-D5排除） |
| 结语+取保 | 不予批捕+取保 | 不予批捕+取保（详尽保证方案） | 不予批捕+程序纠正+取保 |
| 附件 | 标准 | 标准+退赃/谅解凭证 | 标准+程序违法证据 |

### 5.2 法条引用嵌入

- mandatory法条必须全部出现
- supplementary法条按论证需要嵌入
- `[注]` 标注法条来源
- **第81条三条件必须逐一对应引用**
- **O1(.docx)正文法条编号使用中文数字**（第八十一条）

### 5.3 格式处理——双格式输出

#### 5.3a Markdown 输出（O2）

- 行业实务结构（抬头+前言+正文+结语+落款），会话界面即时预览
- D1-D5可使用表格
- 保留免责声明
- 降级处理：按 SOFT_DEGRADED 三档输出

#### 5.3b DOCX 输出（O1，F-Strict）

- 使用 python-docx 库直接生成 .docx 文件
- **非 Markdown→DOCX 转换**，而是根据语义标签独立渲染
- 排版参数来源：[docx-format-spec.md](./docx-format-spec.md)
- **正文字号三号（16pt）仿宋**，非小四（12pt）
- **D1-D5不使用表格**，改为逐项分段叙述
- **不含免责声明**
- **法条编号中文数字**

**DOCX 渲染流程**：

```
Phase 5.1 组装内容 + 语义标签
    → Phase 5.3b-1 页面设置（A4/边距/DXA精确值）
    → Phase 5.3b-2 字体注册（方正小标宋/仿宋_GB2312/黑体/楷体_GB2312/宋体）
    → Phase 5.3b-3 默认样式设定（仿宋三号16pt/固定28磅行距）
    → Phase 5.3b-4 逐段落渲染（查docx-format-spec §2字体矩阵）
    → Phase 5.3b-5 D1-D5逐项分段叙述（非表格）
    → Phase 5.3b-6 页脚页码（"– N –"居中/宋体四号）
    → Phase 5.3b-7 保存验证（命名+自检）
```

**检查点**: 变体结构正确 + 格式合规（O1/O2差异处理）+ 法条引用准确 + 三条件与第81条对应正确

### 6.4 程序闭环提示

在输出末尾附加程序闭环提示：

```markdown
---
**程序闭环提示**：
1. 依据刑诉法第88条，辩护律师提出要求的，检察院**应当听取律师意见**。
   建议在提交书面意见的同时，主动要求当面陈述。
2. 检察院应在接到提请批捕书后7日内作出决定（第91条）。
3. 如检察院决定批捕，后续可依法申请羁押必要性审查（刑诉法第95条）。
4. 如检察院不批捕，公安机关须立即释放（第91条第3款），
   但可依法取保候审继续侦查。
5. 建议同步向检察院提交取保候审申请，形成"不批捕+取保"双轨保障。
```

**检查点**: 15项合规检查全部通过 + P0阻断检查全不命中 + 输出文档格式正确（O1/O2差异处理）+ 程序闭环提示完整
