## 2. 内容框架多变体

### 2.1 变体定义

不予批捕法律意见书根据辩护方向，分为三种变体：

| 变体 | 辩护方向 | 核心论证 | 触发条件 |
|------|----------|----------|----------|
| **V1 不构成犯罪** | 证据条件为主论证 | 证据不足/行为不构成犯罪→达不到"有证据证明有犯罪事实" | defense_direction=evidence_insufficient 且存在证据缺陷 |
| **V2 情节轻微** | 罪责条件+社会危险性条件为主论证 | 无逮捕必要→可能判拘役管制/已退赃谅解/无社会危险性 | defense_direction=insufficient_culpability 或 no_social_danger 或 mixed（无证据缺陷时） |
| **V3 程序辩护** | 程序违法为主论证 | 超期羁押/管辖异议/取证违法→程序阻却 | 涉及程序违法且用户明确要求程序辩护路径 |

### 2.2 变体结构差异

| 章节 | V1 不构成犯罪 | V2 情节轻微 | V3 程序辩护 |
|------|-------------|------------|------------|
| 前言 | 辩护权来源+案件阶段+核心诉求 | 同 | 同 |
| 一、[变体核心论证1] | 案件基本事实 | 从轻/减轻情节 | 程序违法事实 |
| 二、[变体核心论证2] | 不构成XX罪的论证（证据不足/行为不构成） | 不符合逮捕条件（D1-D5排除+第11条） | 程序违法的法律后果 |
| 三、[变体核心论证3] | 无逮捕必要（D1-D5排除） | 政策与情理考量 | 无逮捕必要（D1-D5排除） |
| 结语+取保建议 | 不予批捕+取保建议 | 不予批捕+取保建议（详尽保证方案） | 不予批捕+程序纠正+取保建议 |
| 附件 | 标准 | 标准+退赃/谅解凭证 | 标准+程序违法证据 |

### 2.3 变体论证逻辑

**V1 不构成犯罪**：
```
证据条件击破（主） → 达不到"有证据证明有犯罪事实" → 必须不批捕
  + 社会危险性排除（辅） → 无社会危险性 → 加强论证
```

**V2 情节轻微**：
```
罪责条件击破（主） → 不可能判徒刑以上 → 不符合逮捕条件
  + 社会危险性排除（主） → D1-D5逐项排除+替代措施 → 无逮捕必要
```

**V3 程序辩护**：
```
程序违法论证（主） → 超期/管辖/取证违法 → 程序阻却批捕
  + 社会危险性排除（辅） → 加强论证
```

### 2.4 变体路由规则

| 用户输入 | 自动路由 | 说明 |
|----------|----------|------|
| evidence_insufficient | V1 | 证据不足优先 |
| insufficient_culpability | V2 | 罪责条件路径 |
| no_social_danger | V2 | 社会危险性路径 |
| mixed（含evidence_insufficient） | V1+V2混合 | 证据条件为主+社会危险性为辅 |
| mixed（不含evidence_insufficient） | V2 | 罪责+社会危险性双路径 |
| 用户指定程序辩护 | V3 | 需用户明确指定 |

## 3. 主输出：不予批捕法律意见书

### 3.1 行文结构（对齐行业实务惯例）

> 行业实务中，顶级刑辩律师的法律意见书结构为：**抬头+前言+正文论证+结语+落款+附件**。
> 致送机关为抬头称谓，非正文章节；辩护人信息在前言交代，非独立章节；法条嵌入论证过程，非独立章节；附件为文末附属，非编号章节。

#### 3.1.1 通用框架

```markdown
关于对[犯罪嫌疑人姓名]涉嫌[罪名]一案不予批准逮捕的法律意见书

[XX市XX区人民检察院]：

[事务所名称]律师事务所接受[犯罪嫌疑人或家属]的委托，并征得其本人同意，指派[律师姓名]律师担任[嫌疑人姓名]涉嫌[罪名]一案的辩护人。本案现由[公安机关名称]侦查，该局已提请贵院审查批准逮捕。

辩护人依法会见了犯罪嫌疑人，基于所了解的本案基本事实，根据《中华人民共和国刑事诉讼法》及相关规定，请求贵院对犯罪嫌疑人***作出不予批准逮捕的决定。具体事实和理由如下：

一、[变体核心论证章节1]

二、[变体核心论证章节2]

三、[变体核心论证章节3]

……

并建议变更强制措施为取保候审。
保证方式：[人保/财保/双保险]，取保候审足以保障诉讼进行。

此致

辩护人：[律师签名]
```

> **O1(DOCX)** 不含免责声明，法条编号使用中文数字，D1-D5逐段叙述非表格。

#### 3.1.2 V1 变体（不构成犯罪）

```markdown
[逐项论证现有证据不足以证明有犯罪事实：证据矛盾/关键证据缺失/间接证据链断裂/非法证据排除]

[论证即使按照指控事实，行为也不符合XX罪构成要件]

D1 实施新犯罪：[论证+证据]
```


### 3.2 预判反驳嵌入规则

> 预判反驳不独立成章，嵌入正文对应论证段落中，针对检方4大常见批捕理由

### 反驳1："有证据证明有犯罪事实"

> 检方逻辑：公安机关已收集到初步证据，足以证明有犯罪事实。
> 反驳策略：逐项分析现有证据的缺陷——[具体论证哪些证据不足/矛盾/非法]。
> 批捕证明标准虽低于定罪标准，但"有证据证明"仍要求证据具有客观性、关联性和合法性，本案现有证据[具体缺陷]……

### 反驳2："罪行严重，社会危险性高"

> 罪行严重与社会危险性是两个不同的法律概念。刑诉法第81条将"社会危险性"明确限定为5种具体情形，而非仅凭罪名/金额判断。本案虽涉嫌[罪名]，但[具体论证为何不存在5种社会危险性]……另，依据《质效标准》第11条，社会危险性认定须以公安机关移送的专项证据为依据。经审查，公安机关未提供关于犯罪嫌疑人具有[具体危险性]的专项证据。

### 反驳3："可能妨碍诉讼"

> 本案核心证据已固定，不存在串供/毁灭证据的现实风险。具体而言：[列明已固定的证据]。当事人有固定住所+稳定工作+保证人，取保候审完全可以保障诉讼顺利进行……

### 反驳4："需要继续侦查"

> 检察院不批捕的，公安机关可依法取保候审继续侦查（刑诉法第91条第3款）。不批捕不等于案件终结，不影响侦查继续进行。取保候审状态下完全可以继续侦查……另，如贵院在现有证据存在[具体瑕疵]的情况下批准逮捕，依据《质效标准》第23/24条之规定，该案将面临质效评价风险。

## 4. SOFT_DEGRADED 三档输出

### 4.1 C档（完整版，标准输入）

- 完整结构输出（抬头+前言+正文论证+结语+落款+附件）
- 三条件逐项击破论证（依据变体路由确定主/辅论证）
- 社会危险性D1-D5逐项排除（O2表格/O1逐段叙述）
- 预判反驳完整嵌入
- 附件清单完整
- 法条引用完整
- 变更强制措施建议+保证方案

### 4.2 D档（框架版，信息不足时）

- 结构框架完整
- 已知信息填入对应章节
- 缺失信息用 `[需补充：XXX]` 标注
- 论证方向标注"待论证"，按变体章节框架占位
- 包含"信息不足提示"段落

### 4.3 G档（骨架版，极简输入时）

- 仅含法定必要格式
- 基本信息（姓名/罪名）填入
- 大部分章节用 `[需补充：XXX]` 占位
- 增加**免责声明**："本意见书基于有限信息生成，需律师补充完善后方可使用"

## 5. 写作红线

| # | 禁止项 | 原因 | 正确做法 |
|---|--------|------|----------|
| W1 | 承诺或暗示不批捕 | 违反职业伦理，可能误导当事人 | "恳请审查""建议不予批准"，不预判结果 |
| W2 | 引用刑诉法第95条或第93条 | 本技能是批捕前，第93条=通知家属，第95条=羁押审查（批捕后） | 仅引用第81/88/90/91条 |
| W3 | 对公安机关使用批评性语言 | 维护与办案机关的协作关系 | 客观陈述+法条依据+逻辑论证 |
| W4 | 同时主张"不构成犯罪"和"认罪认罚" | 逻辑矛盾 | 在不同论证路径下分别使用 |
| W5 | 笼统断言"无社会危险性" | 须逐项论证 | D1-D5逐项论证+证据支撑 |
| W6 | 使用绝对化表述 | "绝对没有社会危险性"不可证 | "社会危险性已显著降低/不存在" |
| W7 | 引用"排除合理怀疑"标准 | 批捕标准低于定罪标准 | 论证达不到"有证据证明有犯罪事实" |
| W8 | 致送公安机关 | 审查批捕阶段仅致送检察院 | 致送检察院审查批捕部门 |
| W9 | 保证方式含"监视居住" | 监视居住是独立强制措施，非保证方式 | 保证方式仅人保+财保（刑诉法第68条） |
| W10 | 第67条取保条件当"且"关系 | 四项为"或"关系 | 满足其一即可取保 |
| W11 | 不引用质效标准应当不捕条款 | 满足第27/28条应当不捕条款情形必须引用 | 从"论证不符合"升级为"引用应当不捕" |
| W12 | 社会危险性论证不查第11条 | 须检查公安是否提交专项证据 | 第11条举证责任倒逼 |

## 6. 质量标准

### 6.1 论证力度要求（三级递进）

| 层级 | 要求 | 示例 |
|------|------|------|
| 第一层：证据条件击破 | 逐项论证证据不足 | "现有证据仅有被害人陈述，缺乏客观证据印证，不足以证明有犯罪事实" |
| 第二层：社会危险性排除 | D1-D5逐项+预判反驳 | "不存在D3毁灭证据——核心证据已固定（见附件1-3）" |
| 第三层：替代措施论证 | 具体保证方案 | "人保（妻子XX，本地户籍，有固定住所）+财保（保证金5万元）" |

### 6.2 证据标准化要求

| 证据类型 | 实务标准 | 不合格示例 |
|----------|----------|-----------|
| 退赃凭证 | 银行转账/公安机关收据 | 仅口头说明 |
| 谅解材料 | 协议+收据+谅解书三件 | 仅谅解书 |
| 固定住所 | 房产证/租房合同+社区证明 | 仅口头说明 |
| 稳定职业 | 劳动合同+社保记录 | 仅口头说明 |
| 自首证明 | 到案经过/投案记录 | 仅当事人陈述 |

### 6.3 输出质量检查表

| # | 检查项 | 通过条件 | 适用格式 |
|---|--------|----------|----------|
| QC1 | 变体路由正确 | V1/V2/V3与defense_direction匹配 | O1+O2 |
| QC2 | 三条件至少击破一项 | 至少论证一项不符合逮捕条件 | O1+O2 |
| QC3 | 证据条件论证 | 如选择此路径，须逐项论证证据缺陷 | O1+O2 |
