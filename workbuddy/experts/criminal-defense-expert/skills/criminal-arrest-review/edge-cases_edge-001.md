# 边界示例1：认罪认罚与证据条件路径的逻辑矛盾

> criminal-arrest-review | edge-001

## 场景描述

用户同时要求论证"证据不足"和"当事人认罪认罚"，这两个主张在逻辑上矛盾——如果证据不足则无犯罪可认，如果认罪则说明承认有犯罪事实。

## 输入

```markdown
当事人：陈某
涉嫌罪名：盗窃罪
案件事实：陈某被指控在超市盗窃价值3000元的商品。
辩护要点：1. 监控录像模糊，无法确认是陈某；2. 陈某愿意认罪认罚
论证路径：evidence_insufficient + 认罪认罚
```

## 期望处理

1. **RC-07触发**：检测到 evidence_insufficient + 认罪认罚的组合
2. **交互提醒**：告知用户逻辑矛盾——"证据不足"意味着不构成犯罪，"认罪认罚"意味着承认犯罪事实，两者不能同时主张
3. **请用户选择**：
   - 选项A：坚持证据条件路径→不主张认罪认罚，集中攻击证据不足
   - 选项B：改为社会危险性路径→可主张认罪认罚作为从宽情节
   - 选项C：混合路径→在证据条件部分不提认罪认罚，在社会危险性部分单独主张
4. **用户选择后**：按选定路径生成，确保逻辑自洽
