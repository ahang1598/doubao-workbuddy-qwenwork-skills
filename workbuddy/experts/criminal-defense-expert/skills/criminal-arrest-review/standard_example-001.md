# 标准示例1：经济犯罪——证据条件+社会危险性组合路径

> criminal-arrest-review | example-001

## 输入

```markdown
当事人：李某
涉嫌罪名：非国家工作人员受贿罪
拘留日期：2025年5月1日
提请批捕日期：2025年5月15日
案件事实：李某系XX公司采购经理，被指控在2023-2024年间收受供应商张某回扣共计35万元。
辩护要点：
1. 第2笔15万系正常居间服务费（有居间协议+完税证明+服务成果交付记录）
2. 如认定受贿，金额应从35万减至20万
3. 李某有自首情节（2025年4月30日主动到派出所交代第1笔）
4. 已全额退赃20万（银行转账至公安机关指定账户）
5. 无前科，有固定住所（本市XX区XX路XX号，房产证号XX），有稳定工作（在职10年，劳动合同+社保）
论证路径：evidence_insufficient + no_social_danger
和解状态：部分（第1笔已退赃，第2笔有争议）
建议措施：取保候审
保证方式：人保（妻子王某，XX公司会计，本市户籍）+财保（保证金5万元）
```

## 期望输出要点

1. **证据条件击破**：第2笔15万不应认定为受贿——居间协议+完税证明+服务成果形成完整证据链，证明系合法居间服务费；扣除后实际受贿金额为20万
2. **社会危险性排除**：D1-D5逐项排除——初犯+已退赃+固定住所+稳定工作+保证人
3. **预判反驳**：
   - "有证据证明犯罪事实"→第2笔有合法来源证据，不应计入
   - "罪行严重"→扣除争议金额后仅20万，非数额巨大
4. **变更措施**：人保+财保双保险，取保候审足以保障诉讼
5. **法条引用**：第81条(证据+社会危险性)+第88条(听取意见)+第90条+第91条

## 质量检查

- [ ] 三条件至少击破一项 ✓（证据+社会危险性）
- [ ] D1-D5逐项排除 ✓
- [ ] 预判反驳至少2项 ✓
- [ ] 法条编号正确 ✓
- [ ] 无有罪推定 ✓
- [ ] 无不利自认 ✓
- [ ] 取保配套 ✓
