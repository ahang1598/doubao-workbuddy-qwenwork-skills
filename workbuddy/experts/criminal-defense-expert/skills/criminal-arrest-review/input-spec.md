# 输入规格：criminal-arrest-review

> 不予批捕法律意见书 | 版本: v2.1.0 | 更新: 2026-06-10

---

## 1. 输入模型

### 1.1 宽容摄取原则

本技能采用宽容摄取模型，接受以下6种输入形态：

| 形态 | 描述 | 示例 |
|------|------|------|
| I1 结构化 | 所有字段按schema提供 | JSON/表格/清单 |
| I2 自然语言 | 口头描述案件情况 | "我当事人张某因涉嫌诈骗被刑拘，现在要提请批捕了……" |
| I3 混合式 | 部分结构化+部分自然语言 | 罪名用结构化，案情用自然语言 |
| I4 渐进式 | 分多轮逐步提供信息 | 先提供基本信息，再补充辩护要点 |
| I5 模板填充 | 基于模板填写 | 使用预设模板填写 |
| I6 最小化 | 仅提供核心必填字段 | 仅姓名+罪名+案情 |

### 1.2 交互补全

当输入信息不足时，可交互补全，**最多3轮**：

| 轮次 | 触发条件 | 询问内容 |
|------|----------|----------|
| R1 | 缺少必填字段 | 逐项询问缺失的必填字段（姓名/罪名/案情） |
| R2 | defense_direction未指定 | 询问：主要论证方向？证据不足/情节轻微/无社会危险性/组合 |
| R3 | 论证关键信息缺失 | 询问：从轻情节/和解赔偿/保证方式/证据问题 |

3轮后仍不足 → 进入 SOFT_DEGRADED 降级模式

## 2. 字段定义

### 2.1 必填字段（4个）

| # | 字段名 | 类型 | 说明 | 示例 |
|---|--------|------|------|------|
| F1 | suspect_name | string | 犯罪嫌疑人姓名 | "张某" |
| F2 | alleged_crime | string | 涉嫌罪名（需与刑法罪名一致） | "诈骗罪" |
| F3 | case_facts | text | 案件基本事实（自然语言描述） | "张某因涉嫌诈骗罪于2025年4月被刑事拘留……" |
| F4 | defense_direction | enum | 论证路径 | evidence_insufficient / insufficient_culpability / no_social_danger / mixed |

### 2.2 推荐字段（6个，影响论证质量）

| # | 字段名 | 类型 | 说明 | 默认值 |
|---|--------|------|------|--------|
| R1 | detention_date | string | 拘留日期 | 需用户确认 |
| R2 | arrest_review_date | string | 提请批捕日期（计算7天窗口用） | 需用户确认 |
| R3 | defense_points | array[string] | 辩护要点 | 从case_facts中推断 |
| R4 | mitigating_factors | array[string] | 从轻/减轻情节 | 从case_facts中推断 |
| R5 | reconciliation_status | enum | 和解/谅解/赔偿状态 | none / partial / completed |
| R6 | proposed_measure | enum | 建议变更的强制措施 | bail（取保候审） |

### 2.3 可选字段（5个，增强论证力度）

| # | 字段名 | 类型 | 说明 | 默认值 |
|---|--------|------|------|--------|
| O1 | evidence_issues | text | 证据问题（矛盾/缺失/非法） | 无 |
| O2 | guarantor_info | text | 保证人信息 | 无 |
| O3 | suspect_background | text | 当事人背景（住所/职业/家庭） | 无 |
| O4 | prior_criminal_record | text | 前科情况 | 无 |
| O5 | health_condition | text | 健康状况 | 无 |

## 3. 论证路径（defense_direction）详解

### 3.1 evidence_insufficient（证据条件路径）

**适用场景**：现有证据达不到"有证据证明有犯罪事实"的批捕证明标准

**典型论证点**：
- 关键证据缺失（如无客观证据仅有言词证据）
- 证据之间存在重大矛盾
- 证据来源合法性存疑
- 指控事实仅有单方证言
- 间接证据无法形成完整证据链

### 3.2 insufficient_culpability（罪责条件路径）

**适用场景**：即使认定事实，也不可能判处徒刑以上刑罚

**典型论证点**：
- 情节显著轻微危害不大（刑法第13条但书）
- 可能判处拘役/管制/独立适用附加刑
- 可能免予刑事处罚
- 涉案金额/数量刚达立案标准或有争议
- 罪名定性有误（应定较轻罪名）

### 3.3 no_social_danger（社会危险性路径）

**适用场景**：虽可能构成犯罪，但不具有社会危险性

**典型论证点**：
- D1 无实施新犯罪的可能（初犯/偶犯/过失犯）
- D2 无危害国家安全/公共安全的可能
- D3 无毁灭/伪造证据/干扰证人的可能（证据已固定）
- D4 无打击报复被害人的可能（已和解/谅解）
- D5 无自杀/逃跑的可能（固定住所+稳定工作+保证人）

### 3.4 mixed（组合路径）

**适用场景**：同时具备多种论证路径

**典型组合**：
- 证据条件+社会危险性（最强组合）
- 罪责条件+社会危险性
- 三条件全部论证

## 4. 证据标准化要求

| 证据类型 | 实务标准 | 不合格风险 |
|----------|----------|-----------|
| 退赃凭证 | 银行转账记录/公安机关收据 | 仅口头说明→无法采信 |
| 谅解材料 | 和解协议+收款收据+谅解书三件配套 | 仅谅解书→对方可能反悔 |
| 固定住所证明 | 房产证/租房合同+社区证明 | 仅口头说明→无法采信 |
| 稳定职业证明 | 劳动合同+社保缴纳记录 | 仅口头说明→无法采信 |
| 自首证明 | 到案经过/投案记录 | 仅当事人陈述→需办案机关确认 |
| 疾病证明 | 近3个月连续诊疗记录 | 单次诊断→证明力不足 |
| 前科查询 | 无犯罪记录证明 | 仅口头说明→无法采信 |

**技能行为**：在生成附件清单时，对每类证据标注实务标准要求；若用户提供的证据不达标，在输出中标注 `[⚠️ 建议补充：XXX]`。

## 5. 输入验证规则

### 5.1 硬拒绝条件（hard_reject）

| # | 条件 | 原因 | 处理 |
|---|------|------|------|
| HR-01 | 当事人已被逮捕 | 审查批捕阶段仅适用于批捕前的拘留期间 | 提示用户使用 criminal-custody-review |
| HR-02 | 要求预测批捕结果 | 违反职业伦理 | 拒绝并说明理由 |
| HR-03 | 要求生成检察院内部文书 | 非律师文书范围 | 拒绝并说明理由 |
| HR-04 | 同时主张"不构成犯罪"和"认罪认罚" | 逻辑矛盾——不构成犯罪则无犯罪可认 | 提醒矛盾并请用户选择路径 |

### 5.2 软降级条件（soft_degraded）

| # | 条件 | 降级方式 | 降级后输出 |
|---|------|----------|-----------|
| SD-01 | 仅提供姓名+罪名+案情 | G档（骨架版） | 仅含法定格式+基本信息 |
| SD-02 | defense_direction未指定 | D档（框架版） | 三条件均列出待论证框架 |
| SD-03 | 证据材料不达标 | C档（附标注） | 正常输出+证据标注[⚠️建议补充] |

## 6. 7天窗口计算

### 6.1 时间节点

| 节点 | 计算规则 | 法条依据 |
|------|----------|----------|
| 拘留起始 | 拘留当日不计，次日起算 | 刑诉法第91条 |
| 提请批捕最迟 | 一般3日+延长4日=7日；流窜/多次/结伙最长30日 | 刑诉法第91条第1-2款 |
| 审查批捕期限 | 接到提请批捕书后7日 | 刑诉法第91条第3款 |
| 法律意见提交截止 | 审查批捕第5日前（留2天缓冲） | 实务建议 |

### 6.2 黄金37天分解

```
拘留 → [3-7天(一般)/30天(特殊)] → 提请批捕 → [7天审查] → 决定
|                                    |            |
|  侦查阶段辩护意见                  |  不予批捕   |
|  (criminal-investigation-defense)  |  法律意见   |
|  向公安机关提交                    |  (本技能)   |
|                                    |  向检察院   |
```

## 7. 输入示例

### 标准输入

```markdown
当事人：李某
涉嫌罪名：非国家工作人员受贿罪
拘留日期：2025年5月1日
提请批捕日期：2025年5月15日
案件事实：李某系XX公司采购经理，被指控收受供应商回扣35万元。
辩护要点：
1. 第2笔15万系正常业务佣金（有居间协议+完税证明）
2. 如认定受贿，金额应从35万减至20万
3. 李某有自首情节（主动交代第1笔）
4. 已全额退赃20万
5. 固定住所+稳定工作+无前科
论证路径：evidence_insufficient + no_social_danger
和解状态：部分（第1笔已退赃，第2笔有争议）
建议措施：取保候审
保证方式：人保（妻子为保证人）+财保（保证金5万元）
```

### 最小化输入

```markdown
王某，诈骗罪，被拘留了，要提请批捕了，想写不批捕意见
```

### 社会危险性路径输入

```markdown
赵某涉嫌故意伤害（轻伤）案，已赔偿谅解，是初犯，
有固定住所和稳定工作，无前科。请求论证无社会危险性。
```
