# 工作流详述

> 本文件定义 criminal-meeting-guide 技能的各Phase子步骤与检查点

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 会见目的路由 → Phase 3: 问题清单生成
    ↓
Phase 4: 提纲组装 → Phase 5: 质量检查 → Phase 6: 输出交付
```

## 2. Phase 1: 输入验证

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1 | 解析输入 | 结构化字段 |
| 1.2 | 确定会见目的 | meeting_purpose |
| 1.3 | 确定案件阶段 | case_stage |
| 1.4 | 识别首次会见 vs 后续会见 | meeting_sequence |

**检查点**：[ ] 必需字段已提取 [ ] 目的和阶段已确定 [ ] 首次/后续已识别

## 3. Phase 2: 会见目的路由

| meeting_purpose | 问题类型权重 | 典型问题数 |
|-----------------|-------------|-----------|
| 初次会见 | 三确认(15%)+权利(15%)+到案(10%)+事实(25%)+程序(15%)+同案犯(10%)+从轻(10%) | 18-25题 |
| 案件核实 | 笔录(20%)+事实(30%)+证据(15%)+程序(10%)+同案犯(10%)+从轻(15%) | 12-18题 |
| 策略沟通 | 事实(15%)+策略(35%)+预期管理(20%)+同案犯(10%)+从轻(20%) | 10-15题 |
| 庭前准备 | 庭审流程(35%)+质证预演(30%)+陈述(20%)+其他(15%) | 8-12题 |
| 宣判后 | 判决解读(45%)+上诉(30%)+其他(25%) | 5-8题 |

**检查点**：[ ] 问题类型权重已确定 [ ] 首次会见包含三确认框架

## 4. Phase 3: 问题清单生成

| 步骤 | 操作 | 产出 |
|------|------|------|
| 3.0 | 罪名构成要件解析（生成罪名独有的核实问题骨架） | 构成要件核实问题 |
| 3.1 | 按目的生成核心问题 | 问题清单 |
| 3.2 | 按阶段适配问题 | 阶段专属问题 |
| 3.3 | 加入三确认框架（首次会见） | 三确认问题 |
| 3.4 | 加入权利告知项 | 告知清单 |
| 3.5 | 加入到案方式核实问题 | 到案核实问题 |
| 3.6 | 加入同案犯信息核实问题（有同案犯时） | 同案犯核实问题 |
| 3.7 | 加入程序合法性7项审查 | 程序审查问题 |
| 3.8 | 加入财产处置核实问题 | 财产核实问题 |
| 3.9 | 笔录内容核实问题设计（聚焦签字笔录而非主观陈述） | 笔录核实问题 |

**检查点**：[ ] 构成要件核实问题已生成 [ ] 问题清单已生成 [ ] 阶段适配完成 [ ] 首次会见包含三确认框架

## 5. Phase 4: 提纲组装

按 output-spec.md O1 模板组装（13段结构）。注意：
- 首次会见必须包含三确认框架
- 事实核实须笔录优先——聚焦签字确认的笔录内容
- 到案方式须独立板块——关联自首/立功/取保
- 程序合法性须逐项审查——7项必问
- 罪名构成要件须专项核实——根据3.0产出的骨架填充
- 侦查阶段问题需注意会见权限制
- 问题应开放式而非诱导性

**检查点**：[ ] 格式正确 [ ] 三确认完整 [ ] 到案方式板块 [ ] 程序审查板块 [ ] 构成要件板块 [ ] 问题开放式

## 6. Phase 5: 质量检查

| 检查项 | 标准 | 等级 |
|--------|------|------|
| 阶段适配 | 会见提纲须与当前阶段匹配 | 阻断 |
| 三确认框架 | 首次会见须包含 | 阻断 |
| 权利告知完整 | 诉讼权利告知须完整 | 阻断 |
| 笔录聚焦 | 事实核实须聚焦签字笔录内容 | 阻断 |
| 到案方式核实 | 须包含到案方式核实板块 | 阻断 |
| 构成要件覆盖 | 根据罪名构成要件设计核实问题 | 阻断 |
| 程序合法性审查 | 包含7项程序合法性审查 | 阻断 |
| 事实核实具体 | 核实问题须具体，非笼统 | 阻断 |
| 同案犯信息 | 有同案犯时包含核实板块 | 警告 |
| 财产处置 | 涉财产案件包含核实 | 警告 |
| 预期管理 | 策略沟通阶段包含 | 警告 |
| 辩护方向 | 了解当事人对辩护方向的意愿 | 警告 |

### 7.2 组件序列渲染

按自定义排版规范渲染（纯检查清单，不含笔录功能）。特殊注意：
- I-Practical 排版参数（微软雅黑10.5pt/1.8倍行距——确保速记空间充足）
- **优先级分区排版**：🔴必问项（实线边框+背景色）/ 🟡选问题（虚线边框）
- 三确认框架头部（首次会见）
- ☐复选框 + 1行备注线（非笔录记录区）
- 行动项表格四列
- 单面打印
- 页码"第X页/共Y页"
- **不包含**：会见记录空白区、笔录确认签章区、落款签名区
