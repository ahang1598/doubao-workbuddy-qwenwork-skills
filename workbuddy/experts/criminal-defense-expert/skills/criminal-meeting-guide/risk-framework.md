# 风险框架：criminal-meeting-guide

> 会见提纲 | 版本: v2.1.0

## 1. 风险等级

**L1（低风险）**——会见提纲为辅助工具，不涉及实质性法律判断

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 案件信息结构化 | L1 | 低风险 |
| Phase 3 问题清单生成 | **L2** | **中风险**——问题设计影响信息获取质量，构成要件驱动 |
| Phase 4 会见提纲组装 | L1 | 低风险 |
| Phase 5 质量检查 | **L2** | **中风险**——须确保笔录聚焦/到案方式/程序审查等必问项不遗漏 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 非法取证排查 | 每次会见 | 必须包含刑讯逼供排查问题 |
| RC-02 | 权利告知 | 生成提纲时 | 包含诉讼权利告知 |
| RC-03 | 阶段适配 | 侦查阶段 | 标注会见需批准+权利受限 |
| RC-04 | 认罪认罚审查 | 当事人已认罪 | 审查自愿性+理解法律后果 |
| RC-05 | 到案方式核实 | 每次会见 | 必须包含到案方式核实问题（自首/立功/取保关联） |
| RC-06 | 同案犯信息 | 有同案犯 | 必须包含同案犯信息核实板块 |
| RC-07 | 笔录内容聚焦 | 事实核实阶段 | 核实问题须聚焦签字笔录内容，区分主观陈述 |
| RC-08 | 违规请求应对 | 当事人要求传递信息 | 果断拒绝+告知法律后果（妨害作证罪风险） |
| RC-09 | 程序合法性审查 | 每次会见 | 必须包含7项程序合法性审查问题 |
| RC-10 | 构成要件覆盖 | 生成提纲时 | 必须根据具体罪名构成要件设计核实问题 |
| RC-11 | 预期管理 | 策略沟通阶段 | 须包含量刑范围/缓刑可能性的初步分析 |
| RC-12 | 诉讼时效排查 | 多年旧案 | 须排查是否已过追诉时效 |

## 4. 行为约束

- 会见提纲供参考，不替代律师当庭应变
- 每次会见须排查非法取证
- 侦查阶段须标注会见限制
- **坚决拒绝**当事人要求传递信息给同案犯家属——告知妨害作证罪风险
- 首次会见不宜过早深入辩护策略，先夯实事实基础
- 事实核实聚焦签字笔录内容，区分"客观事实≠卷宗事实"
