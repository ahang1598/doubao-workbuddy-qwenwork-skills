# 边缘示例001：侦查阶段会见需批准

> criminal-meeting-guide | 边缘示例 | v1.2.0

## 输入

```markdown
张某涉嫌危害国家安全罪，侦查阶段，律师申请会见被拒绝
```

## 边界问题

危害国家安全罪、恐怖活动犯罪、特别重大贿赂犯罪三类案件，侦查阶段律师会见需经侦查机关许可（刑诉法第39条第3款）。技能应：
1. 标注会见受限的法律依据
2. 提供争取会见的方案
3. 列明即使不能会见也可采取的措施

## 预期输出摘要

```markdown
> ⚠️ **会见受限提示**
> 危害国家安全罪属于侦查阶段需经许可才能会见的案件（刑诉法第39条）。

## 争取会见的方案

1. 向侦查机关提交会见申请+说明会见必要性
2. 如侦查机关48小时内不许可，可向检察院申诉
3. 即使不能会见，仍可：
   - 向侦查机关了解涉嫌罪名
   - 代理申诉/控告
   - 申请变更强制措施

## 会见提纲调整

如获得会见许可，重点调整为：
- 核实侦查机关告知的权利义务
- 排查刑讯逼供/非法取证
- 了解案件真实情况
```
