# 输出规格

> 本文件定义 criminal-meeting-guide 技能的完整输出结构模板
> 核心定位：**纯会见提纲（问题清单）**，不生成会见笔录

## 0. 输出形式

| 输出格式 | 说明 | 触发条件 |
|----------|------|----------|
| **Markdown** | 会见提纲（会话窗口即时查看） | 始终输出 |
| **DOCX** | 会见提纲打印版（携带看守所，☐检查清单+1.8倍行距+行动项表格） | 始终输出 |
| format_seriousness | **I-Practical**（内部级，打印携带看守所） | — |
| docx排版规范 | `references/docx-format-spec.md`（纯检查清单排版，I-Practical不适用权威检索） | — |

> DOCX 排版规范详见 [docx-format-spec.md](./docx-format-spec.md)。I-Practical 特殊排版：Unicode复选框☐/优先级分区/1.8倍行距/行动项表格。**不包含笔录功能**。

## 4. 写作红线

> 本文件写作红线是 SKILL.md "写作红线" 的**补充**，聚焦输出格式相关问题。完整写作红线见 SKILL.md "写作红线" 章节（8条）。

| 禁止项 | 正确做法 |
|--------|----------|
| 引导翻供 | 客观询问，不暗示答案 |
| 传递案件信息给同案犯家属 | 坚决拒绝+告知法律后果 |
| 承诺结果 | 不承诺取保/无罪等 |
| 诱导性提问 | 开放式问题 |
| 混淆提纲与笔录 | 提纲是问题清单，不是记录 |
| 笔录内容与主观陈述混淆 | 聚焦签字确认的笔录内容，区分当事人主观陈述 |
| 首次会见过早深入策略 | 先夯实事实基础，再讨论辩护方向 |
