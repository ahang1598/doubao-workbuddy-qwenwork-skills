# 标准示例001：审查起诉阶段诈骗罪会见提纲

## 输入

```
帮我写一份会见提纲。嫌疑人张某涉嫌诈骗罪，审查起诉阶段。
涉案金额50万元，已认罪认罚，量刑建议3-4年。
首次会见该嫌疑人，需核实案件事实。
到案方式：电话传唤后主动到案。
同案犯：暂无。
```

## 预期输出

```markdown
---
草稿声明：此会见提纲仅为参考，律师应根据实际情况调整。
生成时间：2026-06-10 10:00:00
会见目的：初次会见
案件阶段：审查起诉
---

# 会见提纲

## 一、三确认框架（首次会见必做）

### （一）委托关系确认
- [ ] 确认身份：您是张某吗？身份证号？
- [ ] 委托确认：我是XX律师事务所XXX律师，受您家属委托担任您的辩护人，您是否同意？

### （二）权利告知确认
- [ ] 告知有权拒绝回答与本案无关的问题
- [ ] 告知有权申请回避
- [ ] 告知有权申请取保候审
- [ ] 告知有权自行辩护
- [ ] 告知认罪认罚从宽制度
- [ ] 告知有权申请非法证据排除

### （三）程序合法性确认
- [ ] 询问是否被刑讯逼供/威胁/引诱/欺骗
- [ ] 询问讯问时是否同步录音录像
- [ ] 询问是否存在连续审讯/疲劳审讯
- [ ] 询问是否被强迫签字
- [ ] 询问辨认程序是否合法（如有辨认环节）

## 二、会见基本信息

- 被会见人：张某
- 涉嫌罪名：诈骗罪
- 会见目的：初次会见——核实事实+认罪认罚审查+辩护方向
- 羁押地点：[看守所名称]
- 会见时间：[建议日期]

## 三、到案方式与自首情节

- [ ] 到案方式确认：办案机关称系"抓获"，实际是否为电话传唤后主动到案？
- [ ] 到案经过详情（时间/地点/在场人员）
- [ ] 是否存在自首情节——电话传唤后主动到案可能构成自首（刑法第67条）
- [ ] 到案方式对量刑的影响评估——如构成自首，可从轻或减轻处罚

## 四、同案犯信息核实

- [ ] 本案是否有同案犯？
- [ ] 如有同案犯：是否到案、强制措施、认罪认罚情况
- [ ] 各涉案人员分工/获利
- [ ] 供述一致性检查

> 本案暂无同案犯信息，此板块可简略。

## 五、事实核实问题

### （一）笔录内容核实（优先）
- [ ] [笔录] 公安讯问时，笔录上是怎么写的？您签字时内容是否看过？
- [ ] [笔录] 笔录中关于50万元的表述——您当时原话是什么？
- [ ] [笔录] 签字时有没有人让您不看内容就签？

### （二）案件基本事实
- [ ] 您和被害人李某是什么关系？怎么认识的？
- [ ] 50万元是怎么收到的？一次还是分次？转账还是现金？
- [ ] 收到50万元后做了什么？钱用到哪里了？

### （三）与案卷矛盾之处
- [ ] 起诉意见书认定的金额50万元，您是否认可？实际到手金额是多少？
- [ ] 您的供述和起诉意见书认定的事实有无出入？

### （四）有利事实确认
- [ ] 是否有向被害人还款的记录？
- [ ] 是否有证据证明部分款项系正常业务往来？

### （五）不在场证明排查
- [ ] 案发时间段您实际在何处？
- [ ] 有无不在场证据或证人？

## 六、证据与财产相关问题

### （一）证据线索
- [ ] 是否有新的证据线索或证人？

### （二）证据质疑
- [ ] 对哪些证据有异议？证据来源是否合法？

### （三）财产处置核实
- [ ] 手机是否被扣押？（可能存有关键证据——通话记录/聊天记录/转账记录）
- [ ] 银行账户是否被冻结？冻结金额？
- [ ] 其他财产处置情况

## 七、程序合法性逐项审查

- [ ] 讯问时同步录音录像是否开启
- [ ] 是否存在连续审讯/疲劳审讯
- [ ] 是否被强迫签字或在不清楚内容的文件上签字
- [ ] 辨认程序是否合法（如有辨认环节）
- [ ] 是否被引供/诱供（如"认了就放人"等）
- [ ] 取保候审申请是否被不当拒绝
- [ ] 羁押期限是否合法

## 八、诈骗罪构成要件专项核实

| 构成要件 | 核实问题 |
|----------|----------|
| 主体 | 您是否具备刑事责任能力？有无精神疾病史？ |
| 主观故意 | 您收钱时是怎么想的？打算还吗？是否具有非法占有目的？ |
| 客观行为 | 是否虚构事实/隐瞒真相？向李某说过"投资""项目"之类的话吗？ |
| 数额 | 50万元认定是否准确？实际到手金额？合同金额与到手金额是否一致？ |
| 加重情节 | 是否数额特别巨大/是否有其他严重情节？ |

## 九、量刑相关

### （一）从轻/减轻情节
- [ ] 是否有退赃退赔？退了多少？
- [ ] 是否取得被害人谅解？
- [ ] 到案方式——是否构成自首（电话传唤后主动到案）
- [ ] 是否有立功情节——到案后有无揭发他人犯罪
- [ ] 初犯/偶犯
- [ ] 认罪态度

### （二）预期管理
- [ ] 量刑范围初步分析：诈骗50万元属于"数额巨大"，法定刑3-10年
- [ ] 缓刑可能性评估：如退赃+谅解+初犯，有缓刑可能
- [ ] 认罪认罚量刑建议3-4年的合理性分析

## 十、辩护方向沟通

### （一）辩护策略选择
- [ ] 对诈骗罪的定性有无异议？
- [ ] 无罪辩护vs罪轻辩护——结合证据分析
- [ ] 如罪轻辩护：金额认定/从犯/自首/立功等辩点

### （二）认罪认罚
- [ ] 认罪认罚是自愿的吗？有无被强迫或诱导？
- [ ] 量刑建议3-4年是否认可？
- [ ] 告知：即使签署认罪认罚具结书，在判决前有权反悔
- [ ] 反悔的后果：不再享受从宽，但不会被加重处罚

## 十一、生活与健康

- [ ] 看守所生活条件如何？饮食、医疗有无问题？
- [ ] 身体状况如何？有无疾病/伤情需要就医？
- [ ] 作息是否正常？有无异常情况？

## 十二、家属沟通

- [ ] 有无需要转达家属的话？（经当事人同意）
- [ ] 家属有无要求转达的事项？
- [ ] 收集家属提供的新信息

## 十三、下次会见重点与行动项

### 下次会见重点
- 核实退赃金额和谅解书情况
- 如发现笔录不一致，下次重点核实

### 行动项

| 序号 | 行动内容 | 负责人 | 完成时限 |
|------|---------|--------|---------|
| 1 | 核实退赃金额和谅解书情况 | 律师 | 下次会见前 |
| 2 | 审查认罪认罚具结书内容 | 律师 | 下次会见前 |
| 3 | 如有非法取证线索，准备非法证据排除申请 | 律师 | 一周内 |
| 4 | 与检察院沟通量刑建议合理性 | 律师 | 两周内 |
| 5 | 调取对张某有利的证据（还款记录/聊天记录） | 律师 | 两周内 |
```
