# 质量标准：会见提纲

| 维度 | 权重 | 优秀 | 合格 | 不合格 |
|------|------|------|------|--------|
| 阶段适配 | 15% | 会见重点与阶段完全匹配 | 基本适配 | 未区分阶段 |
| 权利告知 | 15% | 三确认框架完整 | 核心权利已告知 | 未做权利告知 |
| 事实核实 | 20% | 关键事实全部核实+笔录聚焦 | 主要事实已核实 | 未核实事实 |
| 构成要件覆盖 | 15% | 罪名构成要件逐项设计核实问题 | 部分要件覆盖 | 未区分罪名 |
| 程序合法性 | 10% | 7项必问全部覆盖 | 核心项已覆盖 | 未排查程序违法 |
| 到案方式/同案犯 | 10% | 到案三关联+同案犯地位比对完整 | 基本信息已核实 | 完全遗漏 |
| 矛盾排查 | 5% | 证据矛盾已排查+供述一致性检查 | 有矛盾排查 | 未排查矛盾 |
| 策略讨论 | 5% | 辩护方向+预期管理已讨论 | 有策略讨论 | 未讨论策略 |
| 首次/后续区分 | 5% | 首次会见三确认+后续聚焦核实 | 基本区分 | 无差异 |

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 阶段适配 | 阻断 | 会见提纲须与当前阶段匹配 |
| 三确认框架 | 阻断 | 首次会见须包含三确认框架 |
| 权利告知完整 | 阻断 | 诉讼权利告知须完整 |
| 笔录聚焦 | 阻断 | 事实核实须聚焦签字笔录内容 |
| 到案方式核实 | 阻断 | 须包含到案方式核实（自首/立功/取保关联） |
| 构成要件覆盖 | 阻断 | 须根据具体罪名构成要件设计核实问题 |
| 程序合法性审查 | 阻断 | 须包含7项程序合法性审查 |
| 事实核实具体 | 阻断 | 核实问题须具体，非笼统 |
| 同案犯信息 | 警告 | 有同案犯时须包含同案犯信息核实 |
| 财产处置 | 警告 | 涉财产案件须核实扣押冻结情况 |
| 预期管理 | 警告 | 策略沟通阶段须含量刑预期分析 |
| 辩护方向 | 警告 | 了解当事人对辩护方向的意愿 |
