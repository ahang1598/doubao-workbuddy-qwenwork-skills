# 方法论：会见提纲

> 本文件嵌入顶级刑事辩护方法论，供 SKILL.md 和 workflow-detail.md 引用

## 一、会见提纲核心方法论

### 1.1 阶段适配矩阵

| 阶段 | 会见重点 | 核心问题 |
|------|---------|---------|
| 侦查 | 了解案情+权利告知+到案方式+程序合法性 | 做了什么？如何到案？有无刑讯？是否取保？ |
| 审查起诉 | 阅卷核实+笔录聚焦+辩护方向 | 笔录内容是否属实？签字是否自愿？同案犯量刑比对？ |
| 一审 | 庭审准备+质证意见+预期管理 | 庭审怎么辩护？是否认罪？量刑预期？ |
| 二审 | 上诉理由+新证据+一审批判 | 一审判决有何问题？有无新证据？刑期是否合理？ |

### 1.2 会见三阶段结构

1. **三确认阶段**：委托关系确认→权利告知确认→程序合法性确认（首次会见必做，30秒速检）
2. **事实核实阶段**：笔录聚焦→案件事实→证据矛盾→到案方式→同案犯→财产处置
3. **策略讨论阶段**：辩护方向/认罪认罚/量刑预期/取保评估

### 1.3 构成要件驱动的问题设计法

> 核心认知：会见问题设计须以**具体罪名的构成要件为骨架**

**方法论**：
1. 解析涉嫌罪名的基本构成要件（主体/主观/客观/客体）
2. 逐要件设计核实问题——"主体是否符合？"、"主观故意如何认定？"、"客观行为有无争议？"
3. 识别法定刑升格条件，专项设计加重情节核实问题
4. 识别常见辩护要点，设计有利事实确认问题

**示例（组织他人偷越国境罪）**：
- 基本构成要件→核实人数/次数/违法所得→确定基本刑档
- 加重情节→是否致人重伤死亡/是否限制人身自由→判断刑档是否升格

### 1.4 笔录回溯法

> 核心认知：**客观事实 ≠ 卷宗事实**。律师核实的对象是当事人**签字确认的笔录内容**，而非当事人的主观叙述。

**方法论**：
1. 优先询问："公安机关讯问时，笔录上是怎么写的？你签字时内容是否看过？"
2. 核对笔录表述与当事人真实意思："笔录上写'我承认XXX'，当时你的原话是什么？"
3. 追问签字自愿性："签字时有没有人让你不看内容就签？"
4. 发现矛盾时标记："当事人说法与笔录不一致——需要阅卷时重点关注"

### 1.5 到案三关联法

> 到案方式直接决定三个关键法律问题

| 到案方式 | 自首认定 | 立功认定 | 取保可行性 |
|----------|----------|----------|-----------|
| 抓捕 | ❌ 不构成自首 | 视情况 | 一般 |
| 电话传唤后主动到案 | ✅ 可能构成自首 | 视情况 | 较高 |
| 主动投案 | ✅ 构成自首 | 视情况 | 高 |
| 通缉到案 | ❌ 不构成自首 | ❌ | 低 |

### 1.6 同案犯地位比对法

> 核心认知：通过同案犯量刑建议，可以**预判自身刑期区间**

**方法论**：
1. 了解同案犯是否到案、认罪认罚情况
2. 获取同案犯量刑建议
3. 对比自身在共同犯罪中的地位和作用（主犯/从犯/胁从犯）
4. 如自身地位较轻，可争取从犯认定；如地位相当，量刑预期应与同案犯相近
5. 关注供述一致性——同案犯供述与当事人供述有无矛盾

### 1.7 程序合法性7项必问清单

1. 讯问时同步录音录像是否开启
2. 是否存在连续审讯/疲劳审讯
3. 是否被强迫签字或在不清楚内容的文件上签字
4. 辨认程序是否合法（是否有暗示/人数是否符合规定）
5. 是否被引供/诱供
6. 取保候审申请是否被不当拒绝
7. 羁押期限是否合法

## 二、隐性知识

> 本节约化知识对应 SKILL.md 核心原则，括号内为对应原则编号

- 侦查阶段涉及三类特殊案件（国安/恐怖/重大贿赂）须许可方可会见（原则2：权利保障）
- 会见不被监听——但须遵守保密义务（原则10：非法取证排查）
- 每次会见应有明确目的，避免无准备会见（原则1：阶段适配）
- **客观事实 ≠ 卷宗事实**——律师核实的对象是签字笔录内容，不是当事人主观叙述（原则4：笔录优先）
- 到案方式直接决定自首/立功/取保的认定，不可遗漏（原则6：到案三关联）
- 同案犯量刑建议是预判自身刑期区间的关键参照（原则7：同案犯地位比对）
- 手机扣押可能存有关键无罪证据（通话记录/聊天记录/定位信息）（原则6：到案三关联）
- 首次会见不宜过早深入辩护策略，先夯实事实基础（原则13：预期管理）
- 诉讼时效排查——多年旧案可能已过追诉时效，直接导致无罪结果（原则9：矛盾排查）
- 当事人要求传递信息给同案犯家属——**坚决拒绝+告知法律后果**（妨害作证罪风险）（原则14：违规请求应对）

## 三、常见错误

- 未做权利告知
- 会见目的不明确
- 代替当事人做决定
- 未核实案件事实
- 只听当事人主观陈述，未聚焦签字笔录内容
- 遗漏到案方式核实——导致自首情节未被认定
- 遗漏同案犯信息——无法进行地位比对和刑期预判
- 首次会见过早深入辩护策略——事实基础未夯实就讨论方向

## 四、罪名构成要件驱动模板（常见罪名示例）

### 4.1 诈骗罪

| 构成要件 | 核实问题 |
|----------|----------|
| 主体 | 是否具备刑事责任能力 |
| 主观故意 | 是否具有非法占有目的——"以借款之名行诈骗之实" |
| 客观行为 | 是否实施虚构事实/隐瞒真相的行为 |
| 数额 | 涉案金额认定——实际到手金额 vs 合同金额 |
| 加重情节 | 是否数额特别巨大/是否有其他严重情节 |

### 4.2 故意伤害罪

| 构成要件 | 核实问题 |
|----------|----------|
| 主体 | 是否具备刑事责任能力 |
| 主观故意 | 是否具有伤害故意——"是故意还是过失/意外" |
| 客观行为 | 具体伤害行为——"谁先动手/是否正当防卫" |
| 后果 | 伤情鉴定——"轻伤/重伤的鉴定依据是否充分" |
| 加重情节 | 是否致人重伤/死亡——刑档升格条件 |

### 4.3 受贿罪

| 构成要件 | 核实问题 |
|----------|----------|
| 主体 | 是否为国家工作人员 |
| 主观故意 | 是否具有受贿故意——"是正常人情往来还是权钱交易" |
| 客观行为 | 是否利用职务便利为他人谋取利益 |
| 数额 | 受贿金额认定——"每笔款项的性质和证据" |
| 加重情节 | 是否数额特别巨大/是否造成重大损失 |
| 特殊情节 | 是否有索贿情节——从重处罚 |
