## 侦查阶段（investigation）

### O6 流程图数据

```
[拘留] ──14/37天──→ [批捕审查7天] ──→ [逮捕/释放]
  │                                    │
  └─💡 取保黄金窗口                    └─ 可申请羁押审查
```

| 节点 | 期限 | CSS 类 | 法条 | 关键动作 |
|------|------|--------|------|---------|
| 刑事拘留 | 一般14天/最长37天 | `current` | 刑诉法第91条 | 律师可会见、可申请取保 |
| 批捕审查 | 7天 | `future` | 刑诉法第91条 | 检察院决定是否批捕 |
| 逮捕后侦查 | 2-7个月 | `future` | 刑诉法第156/158条 | 可申请羁押必要性审查（第95条） |

**注释行**：💡 取保黄金窗口：拘留后即可申请，3日内应当作出决定

### 详细时间线

| 节点 | 期限 | 法条依据 | 说明 |
|------|------|---------|------|
| 刑事拘留 | 一般14天，流窜/结伙/多次37天 | 刑诉法第91条 | 公安提请批捕+检察院审查批捕期限 |
| 批捕审查 | 7天 | 刑诉法第91条 | 检察院审查是否批准逮捕 |
| 逮捕后通知 | 24小时内 | 刑诉法第93条 | 逮捕后须通知家属（除无法通知外） |
| 逮捕后侦查羁押 | 2个月 | 刑诉法第156条 | 基本期限 |
| 羁押延长（四类重大复杂） | +2个月 | 刑诉法第158条 | 边远/犯罪集团/流窜/取证困难，省级检察院批准 |
| 羁押延长（可能判10年以上） | +2个月 | 刑诉法第158条 | 省级检察院批准，可再延长 |
| 特殊延期（不宜交付审判） | 无明确期限 | 刑诉法第157条 | 最高检报请全国人大常委会批准 |
| **最长侦查羁押** | **7个月** | — | 不含拘留期+特殊延期 |

### 关键时间窗口

| 事项 | 时间窗口 | 说明 |
|------|---------|------|
| 取保候审申请 | 拘留后即可申请 | 3日内应当作出决定 |
| 律师首次会见 | 持三证即可会见 | 三类案件需经许可 |
| 批捕决定窗口 | 拘留后37天内 | 检察院须在此期限内决定是否批准逮捕，建议尽早委托律师 |

## 审查起诉阶段（review_prosecution）

### O6 流程图数据

```
[审查起诉] ──1-1.5月──→ [补充侦查?] ──→ [起诉/不起诉]
  │                        │
  └─💡 律师可阅卷          └─ 1月/次×2
```

| 节点 | 期限 | CSS 类 | 法条 | 关键动作 |
|------|------|--------|------|---------|
| 审查起诉 | 1-1.5个月 | `current` | 刑诉法第172条 | 律师阅卷、约见检察官 |
| 退回补充侦查 | 1月/次×2 | `future` | 刑诉法第175条 | 审查期限重新计算 |
| 起诉/不起诉 | — | `future` | — | 律师可提交不起诉意见 |

### 详细时间线

| 节点 | 期限 | 法条依据 | 说明 |
|------|------|---------|------|
| 审查起诉期限 | 1个月 | 刑诉法第172条 | 基本期限 |
| 期限延长 | +15日 | 刑诉法第172条 | 重大复杂案件 |
| 退回补充侦查 | 1个月/次 | 刑诉法第175条 | 最多2次 |
| 补充侦查后重新计算 | 1个月+15日 | 刑诉法第175条 | 每次退回后重新计算 |
| **最长审查起诉** | **6.5个月** | — | 1.5月+1月×2次退补+1.5月×2次重计 |

## 审判阶段（trial）

### O6 流程图数据

```
[一审审理] ──2-3月──→ [判决] ──10日──→ [上诉期结束]
  │                      │
  └─💡 律师出庭辩护      └─ 近亲属可上诉
```

| 节点 | 期限 | CSS 类 | 法条 | 关键动作 |
|------|------|--------|------|---------|
| 一审审理 | 2-3个月 | `current` | 刑诉法第208条 | 律师出庭辩护 |
| 上诉期 | 判决10日/裁定5日 | `future` | 刑诉法第230条 | 近亲属经同意可上诉（第227条） |

### 详细时间线

| 节点 | 期限 | 法条依据 | 说明 |
|------|------|---------|------|
| 一审审理期限 | 2个月+可延长1个月 | 刑诉法第208条 | 基本期限+经上级法院批准 |
| 一审进一步延长 | +3个月 | 刑诉法第208条 | 省级法院批准 |
| 简易程序审理 | 20日内（可能判3年以上可延长至一个半月） | 刑诉法第220条 | 适用条件见第214-215条 |
| 速裁程序审理 | 10-15日内 | 刑诉法第222条 | 基层法院管辖/可能判3年以下/认罪认罚 |
| 上诉期限 | 判决10日/裁定5日 | 刑诉法第230条 | 从收到判决书次日起算；近亲属经被告人同意可上诉（第227条） |
| 二审审理期限 | 2个月+可延长 | 刑诉法第243条 | 经省级法院批准可再延长2个月 |

## 三阶段时间线总览（O7 可视化数据）

```
[拘留] ────14/37天────→ [批捕审查7天] ────→ [逮捕后侦查2-7月] ────→ [审查起诉1-6.5月] ────→ [一审2-6月] ────→ [判决]
  │                        │                      │                       │                    │
  │ 律师可会见              │ 取保黄金窗口          │ 律师可阅卷             │ 律师出庭辩护         │ 上诉10日
  │ 可申请取保               │ 37天批捕决定窗口          │ 可约见检察官           │ 可质证辩论           │
```

> 💡 注：上表中的"取保黄金窗口""律师可阅卷"等为流程中的关键提示，使用 💡 emoji 中性标注，不使用 🟢 等阶段色/动作色，避免与 v2.1 视觉层级四色语义冲突。

### 阶段色彩标注

- 🔴 侦查阶段：`#E74C3C`（高焦虑期——信息最少、限制最多）
- 🟡 审查起诉：`#F39C12`（关键决策期——认罪认罚/不起诉等重大决定）
- 🟢 审判阶段：`#27AE60`（权利实现期——律师全面参与、公开审理）
