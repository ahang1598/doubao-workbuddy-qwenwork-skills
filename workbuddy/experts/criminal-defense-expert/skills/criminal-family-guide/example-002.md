# 示例 002：侦查阶段速览卡

## 输入

```
侦查阶段，速览卡，嫌疑人张三
```

## 输入解析

| 字段 | 值 |
|------|-----|
| stage | investigation（侦查） |
| depth | pocket（速览卡） |
| suspect_name | 张三 |
| charge | 无 |
| family_concern | 无 |

## 预期输出

速览卡 HTML（半页 A4），阶段色系 #E74C3C（侦查🔴），字数≤300

### O0a 当前状态

```
🔴 侦查阶段 · 嫌疑人张三
```

### O0b 律师在做

| 律师在做 |
|---------|
| 会见 · 申请取保 · 了解案情 |

### O0c 你要做

| 你要做 |
|-------|
| 配合律师 · 准备保证人 |

### O0d 别做！

| 🚫 别做！ |
|----------|
| 找关系 · 联系同案 · 毁灭证据 |

### O0e 关键时间

```
⏰ 4月14日前 → 取保申请窗口
📞 律师电话：______________
```

### O13/O14

```
XX律师事务所 | 📞 律师电话：________________
仅供参考·不构成法律意见
```

## 边界测试覆盖

本示例覆盖以下边界条件：
- **depth=pocket**：速览卡仅含 O0a-O0e + O13-O14，不含 O1-O12
- **有 suspect_name**：抬头显示"嫌疑人张三"
- **无 charge**：无罪名简介
- **无 family_concern**：无定制 Q&A
