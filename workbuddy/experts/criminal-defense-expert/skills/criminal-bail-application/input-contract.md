# 输入协议 — 取保候审申请书

## 1 必填输入

| 字段 | 类型 | 法律含义 | 缺失时的行为 |
|------|------|---------|------------|
| suspect_name | string | 犯罪嫌疑人/被告人姓名 | 🔴 必须追问 |
| detention_type | enum(拘留/逮捕) | 逮捕时触发条件性规则（第95条论证+羁押必要性审查推荐） | 🔴 必须追问 |
| case_brief | text | 涉嫌罪名+基本案情 | 🔴 必须追问 |
| bail_reason | enum(4项之一) | 第67条取保候审条件（4项为"或"关系） | 🔴 必须追问 |

## 2 可选输入

| 字段 | 类型 | 默认行为 |
|------|------|---------|
| detention_date | date | 标注"羁押日期待补充" |
| guarantor_info | object(姓名/关系/身份证号) | 标注"保证人信息待补充" |
| bail_amount | float | 标注"保证金数额待协商确定" |
| medical_condition | text | 仅患严重疾病时填写（第67条第3项） |

## 3 不可接受输入

| 输入类型 | 拒绝原因 |
|---------|---------|
| 保外就医申请 | 保外就医≠取保候审（第254条），程序完全不同 |
| 监视居住转取保 | 监视居住是独立强制措施（第74-77条），不是取保的保证方式 |
| 仅提供姓名无其他信息 | 无法论证取保条件，最少需提供罪名+羁押类型 |

## 4 事实冲突处理

- 用户声称"无社会危险性"但案件事实显示暴力犯罪 → 标注冲突，提示风险
- 多个取保理由并存 → 按"或"关系处理（第67条四项满足其一即可）

## 5 默认假设声明

- 适用法域：中华人民共和国
- detention_type=逮捕 → 触发条件性规则（增设第95条论证+羁押必要性审查并行推荐）
- detention_type=拘留 → 仅第67条论证
- 默认审级：侦查阶段
