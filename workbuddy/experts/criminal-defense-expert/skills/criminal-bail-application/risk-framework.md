# 风险分级框架

> criminal-bail-application v2.1.2 风险控制文档
> 风险等级：L2（中等风险）

## 1. 风险识别

### 1.1 法律风险

| 风险项 | 风险等级 | 触发条件 | 控制措施 |
|--------|----------|----------|----------|
| 法条引用错误 | L3 | 引用旧版编号/已废止法条 | mandatory法条必须检索核实；**逮捕后须引用第95条** |
| 承诺申请结果 | L3 | 输出包含"一定批准"等表述 | 写作红线禁止承诺 |
| 违反无罪推定 | L3 | 使用"罪犯/确定有罪"表述 | 术语禁用清单 |
| 建议不当 | L2 | 提供不适当的诉讼策略建议 | 仅生成申请书草稿，不提供策略 |
| **逮捕后条件性规则遗漏** | L3 | 逮捕后未增设第95条论证 | Phase 2条件性规则标记+检查 |
| **第67条并列论证** | L3 | 四项条件全部论证而非"或"关系 | Phase 4仅论证适用项 |
| **无证据断言** | L2 | "深刻反省""无暴力倾向"等 | 证据限定语规则+禁用表述清单 |
| **风险表述** | L2 | "交友不慎""亦不排除" | 禁用表述清单 |

### 1.2 输出质量风险

| 风险项 | 风险等级 | 触发条件 | 控制措施 |
|--------|----------|----------|----------|
| 信息不完整 | L2 | 必需字段缺失 | SOFT_DEGRADED C块补全 |
| 阶段不适配 | L2 | 致送机关错误 | 阶段识别逻辑+检查 |
| 论证不充分 | L2 | 社会危险性未逐项排除 | **罪名相关性筛选+检查清单** |
| **遗漏退赃退赔/认罪认罚** | L3 | 有此情形却未论证 | 策略优先级规则+检查 |
| **逮捕决定书文号缺失** | L2 | 逮捕后缺少文号 | 标注[待补充] |
| **正文包含表格** | L2 | Markdown表格出现在正文 | 写作红线禁止 |

## 2. 复核机制

### 2.1 强制复核条件

以下情况**必须**由执业律师审核后才能提交：

1. 涉及外国人/无国籍人案件
2. 涉及国家安全案件
3. 涉及未成年人案件
4. 可能判处十年以上有期徒刑的重罪案件
5. 累犯/惯犯案件
6. **逮捕后取保候审申请**（涉及羁押必要性审查双轨策略，论证复杂度较高）

### 2.2 建议复核条件

以下情况**建议**由执业律师审核：

1. 嫌疑人系初犯偶犯但有前科记录
2. 涉案金额较大（超过法定刑升档标准）
3. 涉及多个罪名
4. 有同案犯
5. **证据不足需加限定语的情况**
6. **保证方式选择存疑**（财产犯罪是否适合财保）

## 3. 免责声明模板

所有输出的申请书必须包含以下免责声明：

```
---
草稿声明：此申请书仅为草稿，未经律师审核不得直接提交办案机关。
---
```

**逮捕后额外免责提示**：

```
并行救济提示：建议同步向检察院申请羁押必要性审查（刑诉法第95条），作为取保候审申请的并行救济途径。此建议亦需律师审核确认。
```

## 4. 降级触发

| 触发条件 | 降级强度 | 输出内容 | 条件性规则适配 |
|----------|----------|----------|---------|
| 必需字段缺失 | S1 | G档（骨架版） | 不触发条件性规则 |
| 推荐字段缺失过半 | S2 | C+D+G+结构描述 | **信息不足时不触发条件性规则+标注建议补充逮捕信息** |
| 可选字段缺失 | S3 | C+D+G+内容初稿（标注[待核实]） | **detention_type=逮捕但缺arrest_warrant_no→仍触发条件性规则但标注[逮捕决定书文号待补充]** |
