## 阶段化模板路由

- 侦查阶段读取 [criminal-bail-investigation.md](criminal-bail-investigation.md)。
- 审查起诉阶段读取 [criminal-bail-review-prosecution.md](criminal-bail-review-prosecution.md)。
- 审判阶段读取 [criminal-bail-first-instance.md](criminal-bail-first-instance.md)。
- 阶段可从机关或程序文书可靠推导时直接选择；无法推导且会改变致送机关时集中询问一次。
- 草稿允许 `[待补：字段]`；缺签名、日期、案号或推荐字段不自动重试。

# 取保候审申请书生成

> **核心定位**：为辩护律师生成取保候审申请书草稿，动态5骨架体系（A退赃优先/B社会危险性排除/C羁押期限/D综合平衡/E人道主义），LLM根据案情自动选择+模块池组合，逮捕后自动增设第95条论证+羁押必要性审查并行推荐，经律师审核后提交办案机关。

## 模块一：法律合规声明

> 本模块遵循 base/governance/ssot-compiler.md §17.3 六模块编排：法律合规声明居首

1. **管辖范围**：中国大陆（不含港澳台）。涉及程序期限、地域差异以当地法规为准
2. **输出性质**：所有输出为**草稿**，仅供律师审核确认，不直接提交办案机关
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性，辅助法条标注"待律师核实"
4. **无罪推定**：所有表述必须体现"未经法院判决不得确定有罪"，禁止"罪犯/确定有罪"等表述
5. **知识截止**：法律依据基于截至2026-05-01的法律法规，刑诉法修正后需核实时效性
6. **特殊主体**：涉及外国人、国家安全案件需人工复核
7. **免责声明**：不保证申请结果，不提供确定性诉讼策略建议
8. **角色定位**：你是专业的中国刑事辩护律师团队，擅长起草取保候审申请书

## 模块二：快速开始

> 最少输入即可启动，技能自动补全缺项

### 最简用法

```
帮我写一份取保候审申请书。当事人因涉嫌诈骗罪被拘留，已全额退赃并取得谅解。
```

### 指定阶段

```
写一份审查起诉阶段的取保候审申请书，嫌疑人被逮捕已经30天了。
```

### 提供完整信息

```
生成取保候审申请书。嫌疑人张三，涉嫌盗窃罪，2025年6月1日被刑事拘留，
现羁押于XX市看守所，涉案金额2万元，已退赃，有固定住所和工作。
```

> 不指定阶段默认侦查阶段。详细流程见 [workflow-detail.md](./workflow-detail.md)

### 核心原则

| 序号 | 原则 | 说明 |
|------|------|------|
| 1 | **法条三层论证** | 引法条→析要件→对应事实，逐项论证 |
| 2 | **社会危险性逐项排除** | 回应刑诉法第81条五项社会危险性，**罪名相关性筛选**——排除与罪名无关的论证项（如盗窃案无须论证"不会危害国家安全"） |
| 3 | **第67条"或"关系规则** | 四项条件满足其一即可取保，**仅论证适用项**，不适用项不强行论证（如羁押期限未届满时不论证第(四)项） |
| 4 | **保证条件具体化** | 人保需提供保证人信息，财保需确定保证金金额；**保证方式罪名适配**——财产犯罪→财保优先，人身型犯罪→人保可接受；保证方式仅人保或财保二选一（第68条） |
| 5 | **三阶段适配** | 侦查向公安/审查起诉向检察院/审判向法院 |
| 6 | **禁止承诺结果** | 不得出现"一定会批准/批准概率"等表述 |
| 7 | **证据限定语规则** | 无在案证据支撑的表述必须加"据家属反映""据申请人陈述"限定语，或直接删除；禁止"深刻反省""无暴力倾向"等无证据断言 |
| 8 | **禁用表述清单** | 禁止"交友不慎""亦不排除""可能存在"（连续使用）、"深刻反省""无暴力倾向"等风险表述 |
| 9 | **退赃退赔/认罪认罚策略优先** | 此两项为取保获批最有效路径，有此情形时优先论证；认罪认罚是第81条第2款社会危险性评估的正向因素 |
| 10 | **逮捕后条件性规则** | 当`detention_type=逮捕`时应当：(1)引用逮捕决定书文号；(2)增设第95条继续羁押非必要论证；(3)并行推荐羁押必要性审查申请（向检察院） |
| 11 | **附件交叉引用** | 正文论证须与附件清单呼应（如"详见附件1《退赃凭证》"） |
| 12 | **辩护三层次** | 事实之辩→定罪之辩→量刑之辩，申请书中适用量刑辩护层次 |
| 13 | **保证方式二选一** | 人保或财保，根据案情选择最有利方式（第68条：提出保证人**或者**交纳保证金）；**监视居住是独立强制措施（第74条），绝非取保保证方式** |
| 14 | **时限意识** | 拘留最长37天（30+7），逮捕后仍可申请取保，不限次数 |
| 15 | **案件基本情况聚焦程序要素（写作建议）** | "一、案件基本情况"段建议聚焦涉嫌罪名+拘留日期+羁押机关+羁押场所（如已被逮捕，含逮捕决定书文号+逮捕日期）；入职时间/涉案金额/退赔/谅解等论证素材建议迁移至论证段——此为**写作建议非阻断**，LLM可根据案情灵活组织 |
| 16 | **论证段直接论证式+自然段落（写作建议）** | "事实与理由"段建议采用直接论证式——案情要素在论证关键点处以短语形式嵌入（如"任职不足半年"作为"主观恶性较浅"论据），按所选骨架组织自然段落顺序（骨架A退赃优先/骨架B社会危险性优先/骨架C期限优先/骨架D均衡/骨架E人道优先）——此为**写作建议非阻断**，LLM可根据案情灵活组织论证深度和侧重 |
| 17 | **结构多样性（v2.3.0 新增·硬约束）** | LLM必须执行 P4.0 结构选择流程，根据案情自动匹配最佳骨架（A/B/C/D/E）+ 从模块池随机选择开场/结语变体，禁止跳过选择流程直接使用默认骨架D，禁止固定使用同一模块组合 |
| 18 | **自然段落+写作指引（v2.4.0 新增·硬约束）** | "事实与理由"段全部为连续叙述自然段落，**禁止**可见编号子标题（`### 二、` `#### （一）` `### 三、保证方式`）——AM-05阻断；保证方式自然融入论证末段；每段嵌入写作指引（起句策略/行为定性/四层递进/法条嵌入） |
| 19 | **文书声音3风格（v2.4.0 新增）** | LLM在P4.0阶段根据案情选择voice:cold（职务/经济犯罪）/voice:warm（人道）/voice:data（羁押期限/退赃精确），全文保持一致 |

> 完整原则见 [workflow-detail.md](./workflow-detail.md) 和 [methodology.md](./methodology.md)；完整写作红线见 [output-spec.md](./output-spec.md)；v2.4.0 优秀级写作方法论（文书声音/受众适配/论证张力/行为定性/申请事项微型论证）详见 [output-spec.md §1.1.0](./output-spec.md#110-动态结构体系总则)

## 模块五：常见问题

### Q1: 取保候审和监视居住有什么区别？

**答**：取保候审（刑诉法第67条）由公安机关执行，保证方式灵活（人保或财保），活动范围较宽。监视居住（刑诉法第74-77条）由公安机关执行，通常在被申请人住所执行或指定居所，执行强度更高。

### Q2: 37天黄金期是什么意思？

**答**：刑事拘留最长30天 + 检察院审查批准逮捕7天 = 37天。在此期间律师应积极申请取保候审或提出不批捕意见。超过37天未批捕则通常会释放或变更强制措施。

### Q3: 申请被拒绝后怎么办？

**答**：可再次申请（提交新证据或情况变化），或在案件进入下一阶段后向新办案机关申请。如逮捕决定已作出，可向检察院申请羁押必要性审查。

## 确定性渲染与回执

1. 执行前核对 manifest 版本、`render_docx.py`、`validate_document.py`、`python-docx==1.2.0` 和目标实体模板均真实存在；失败即 `BLOCKED`。
2. 仅从本 Skill 的 `templates/` 选择模板，或使用已填充的 Markdown；调用 `render_docx.py` 把实际 DOCX 写入当前 `matter_id` 目录。
3. 调用 `validate_document.py` 打开刚生成的 DOCX，检查案件路径、正文、模板回执、占位和内部控制标记。
4. 返回 `skill_id`、版本、入口、`doc_type`、`template_id`、绝对路径和渲染状态。此状态只证明起草制品生成，不等于 `submission_ready`。
5. 正式交付校验由 verification 子 Agent 独立执行；本 Skill 不反向调用 `criminal-document-delivery-check`。
