# 工作流详述

> 本文件定义 criminal-bail-application 技能的各Phase子步骤与检查点
> 遵循 base/governance/ssot-compiler.md §17（SSOT）：按需拆分规则

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 阶段适配 → Phase 3: 信息提取
    ↓
Phase 4: 申请书起草（动态5骨架体系） → Phase 5: 质量检查（28项） → Phase 6: 输出交付
    ↓
Phase 7: DOCX 渲染 [L3]
```

## 2. Phase 1: 输入验证

### 1.1 输入解析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1.1 | 解析自然语言输入 | 结构化字段字典 |
| 1.1.2 | 提取案件基本信息 | suspect_name, alleged_crime, case_stage |
| 1.1.3 | 识别羁押信息 | detention_date, detention_type, detention_location, arrest_warrant_no, arrest_date |
| 1.1.4 | 识别保证方式 | guarantee_method, guarantor_info |
| 1.1.5 | 识别特殊情形 | special_circumstances（优先提取restitution+plea_bargain） |

### 1.2 输入校验

| 检查项 | 校验规则 | 失败行为 |
|--------|----------|----------|
| suspect_name 存在 | 非空 | 进入SOFT_DEGRADED C块 |
| alleged_crime 存在 | 非空 | 进入SOFT_DEGRADED C块 |
| case_stage 存在 | 枚举值 | 自动推断阶段 |
| 无矛盾信息 | 前后一致 | 标注潜在矛盾 |

### 1.3 Phase 1 检查点

- [ ] 输入已结构化
- [ ] 必需字段已提取或标注 [待补充]
- [ ] 潜在矛盾已标注

## 3. Phase 2: 阶段适配

### 2.1 阶段识别

| 用户输入 | 推断阶段 | 致送机关 |
|----------|----------|----------|
| "拘留"/"公安"/"侦查" | 侦查 | XX市公安局XX分局 |
| "逮捕"/"检察院"/"审查起诉" | 审查起诉 | XX市人民检察院 |
| "审判"/"法院"/"开庭" | 审判 | XX市中级人民法院/区人民法院 |

### 2.2 阶段差异化策略

| 阶段 | 侧重点 | 论证强度 |
|------|--------|----------|
| 侦查 | 时效性、紧急性、黄金期 | 中等 |
| 审查起诉 | 证据已固定、社会危险性持续评估 | 较强 |
| 审判 | 量刑预判、羁押必要性 | 强 |

### 2.3 逮捕后条件性规则识别

> 当`detention_type=逮捕`时，标记后续Phase需触发条件性规则：第95条论证+逮捕决定书文号+羁押必要性审查并行推荐。

### 2.4 Phase 2 检查点

- [ ] 阶段已正确识别
- [ ] 致送机关已确定
- [ ] **逮捕后条件性规则已标记**（如detention_type=逮捕）
- [ ] 差异化策略已选择

## 4. Phase 3: 信息提取与组织

### 3.1 案件事实提取

| 提取项 | 来源 | 标注要求 |
|--------|------|----------|
| 涉案罪名 | alleged_crime | 必须是涉嫌罪名 |
| 涉案金额 | 案件描述 | [待补充] 如缺失 |
| 认罪认罚 | special_circumstances | 布尔值 |
| 退赃退赔 | special_circumstances | 布尔值+金额 |
| 取得谅解 | special_circumstances | 布尔值 |
| 前科劣迹 | special_circumstances | 布尔值 |
| 家庭情况 | 案件描述/special_circumstances | 具体描述 |

### 3.2 法条要件映射

**第67条要件映射**：

| 刑诉法第67条要件 | 案件事实对应 | 论证策略 |
|-----------------|-------------|---------|
| 可能判处管制、拘役或独立适用附加刑 | 罪名法定刑+情节 | 仅适用项论证，金额未知时保守论证 |
| 可能判处有期徒刑以上刑罚，但已取保不致危害社会 | 社会危险性评估 | 五项逐项排除+罪名筛选 |
| 患有严重疾病/生活不能自理 | 医疗证明 | 仅在适用时论证 |
| 怀孕或正在哺乳 | 孕产证明 | 仅在适用时论证 |
| 羁押期限届满 | 羁押时长 | 仅在期限确实届满时论证 |

**逮捕后条件性法条映射**（detention_type=逮捕时触发）：

| 法条 | 论证定位 | 论证策略 |
|------|---------|---------|
| 第95条 | **主论证** | 逮捕后情况变化→继续羁押非必要→建议释放/变更 |
| 2023年羁押必要性审查规定 | 配套细则 | 审查标准+评估因素+申请程序 |
| 第81条第2款 | 认罪认罚正向因素 | 认罪认罚作为社会危险性评估的正向因素 |

## 5. Phase 4: 申请书起草（动态5骨架体系 + 自然段落 v2.4.0）

> Phase 4 按动态5骨架体系起草。LLM 在起草前须先执行 P4.0 结构选择，根据案情自动匹配最佳骨架（A/B/C/D/E）+ 文书声音（voice:cold/warm/data）+ 受众适配 + 模块组合。"事实与理由"段全部为连续叙述自然段落，无可见编号子标题（AM-05）。detention_type=逮捕时所有骨架均触发条件性规则（第95条论证+逮捕决定书文号+羁押必要性审查并行推荐）。

### 4.0 结构选择（LLM内部判断，不暴露给用户）🔴强制执行

> **此步骤必须在起草前执行，不得跳过。** 直接进入起草而不先执行结构选择将被 Phase 5 质量检查阻断（AM-04）。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 4.0.1 | 识别案件类型 | 财产型（盗窃/诈骗/贪污等）/ 人身型（伤害/强奸等）/ 综合型 |
| 4.0.2 | 识别最强有利因素 | 退赃退赔→认罪认罚→羁押期限→固定住所+无前科→医疗/人道→无特殊因素 |
| 4.0.3 | **按触发条件匹配骨架** | A（退赃/认罪）→ B（固定住所+无前科）→ C（羁押近期限）→ E（医疗人道）→ D（默认）：按优先级递减匹配，首个满足即选中 |
| 4.0.4 | 确定论证密度 | 事实复杂多节点→`detailed`；简单案→`brief`；默认→`standard` |
| 4.0.5 | 确定对抗程度 | 逮捕后→`strong`；有退赃+侦查阶段→`mild`；默认→`standard` |
| 4.0.6 | 确定事实呈现方式 | 事实复杂多节点→`timeline`；单一违约→`comparative`；大部分案→`focus`；信息有限→`brief` |
| 4.0.7 | **选择文书声音**（v2.4.0 新增·强制执行） | 职务犯罪/重大经济犯罪→`voice:cold`；医疗/人道/哺乳→`voice:warm`；羁押期限+金额明确→`voice:data`；其余→`voice:cold`（默认）。详见 output-spec.md §1.1.0 文书声音3风格 |
| 4.0.8 | **识别受众适配**（v2.4.0 新增·强制执行） | 区县公安→侧重逃跑风险/社区联系；市检→侧重证据固定/逮捕后变化；经侦→侧重退赃弥补；法院→侧重量刑预判。详见 output-spec.md §1.1.0 受众适配规则 |
| 4.0.9 | 从模块池选择开场/结语 | **随机选择，禁止连续2次使用同一变体**；首次使用时随机选择 |
| 4.0.10 | 确定保证方式 | 财产型→财保；人身型/其他→人保 |

> **骨架确认后**，按 `output-spec.md` §1.1.2 对应骨架的论证段落顺序组织自然段落结构。
