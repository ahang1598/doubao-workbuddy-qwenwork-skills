# 项目配置模板

> 本模板定义 `00-案件管理/00-项目配置.md` 的结构，用于持久化用户选择的文件命名方案。Phase 1 项目检测后自动读取，若存在则跳过交互直接使用；若不存在则进入方案选择交互。

## 1. 配置格式

```yaml
# 项目配置 | 生成时间: YYYY-MM-DD HH:MM | 操作模式: INIT
naming_scheme: A                    # 方案A/B/C
field_overrides:                    # 字段级微调（可选）
  date_field: file_modified_date    # file_modified_date / material_date / none
  include_subject: true             # true / false
  include_case_number: false        # true / false
  separator: "-"                    # "-" / "_"
```

## 2. 三种预设命名方案

### 方案A：标准规范（默认）

**格式**：`YYYYMMDD-材料类别-主体标识-核心内容.ext`

| 字段 | 说明 | 示例 |
|------|------|------|
| YYYYMMDD | 文件修改日期或材料形成日期（8位） | 20240115 |
| 材料类别 | 8大类材料类型简写 | 讯问笔录/起诉意见书/鉴定意见/判决书 |
| 主体标识 | 嫌疑人/被害人/证人姓名 | 张某/李某 |
| 核心内容 | 材料核心内容简述（≤20字） | 第1次供述/被盗经过/价格鉴定 |
| .ext | 原始扩展名 | .pdf/.docx/.jpg |

**完整示例**：
- `20240115-讯问笔录-张某-第1次供述.pdf`
- `20240120-起诉意见书-公安局-指控盗窃.pdf`
- `20240201-鉴定意见-价格中心-被盗物品价值.pdf`

**适用场景**：多主体案件、团队协作、需严格版本管理。

## 3. 字段级微调选项

方案选定后，用户可对以下字段进行独立调整：

| 微调字段 | 选项 | 说明 |
|----------|------|------|
| `date_field` | `file_modified_date`（默认） | 使用材料来源文件的最后修改日期 |
|  | `material_date` | 使用材料本身的形成日期（如讯问日期/判决日期），需从文件内容中提取 |
|  | `none` | 不包含日期字段 |
| `include_subject` | `true`（默认） | 包含主体标识（嫌疑人/被害人/证人姓名） |
|  | `false` | 不包含主体标识（方案B的行为） |
| `include_case_number` | `false`（默认） | 不包含案号 |
|  | `true` | 在主体标识后添加案号简写 |
| `separator` | `"-"`（默认） | 使用连字符分隔 |
|  | `"_"` | 使用下划线分隔 |

### 微调示例

默认方案A + `include_subject: false` → 退化为方案B格式
默认方案A + `date_field: none` → `材料类别-主体标识-核心内容.ext`
方案C + `separator: "_"` → `材料类别_主体_核心内容_YYYYMMDD.ext`

## 4. 交互流程

### INIT 模式

```
Phase 1.5 项目配置检测:
  └── 读取 00-案件管理/00-项目配置.md
      ├── 文件存在 → 读取 naming_scheme + field_overrides → 跳过交互
      └── 文件不存在 → 进入方案选择交互

方案选择交互：
  展示3种方案的格式+示例 → 用户选择A/B/C
    ↓
  展示可微调字段 → 用户可选调整
    ↓
  确认方案 → 写入 00-案件管理/00-项目配置.md
```

### UPDATE 模式

```
Phase 1 读取:
  └── 读取 00-案件管理/00-项目配置.md
      ├── 文件存在 → 使用已有方案 → 不打断用户
      └── 文件不存在（旧项目） → 使用默认方案A → 不打断用户
```

## 5. 降级策略

| 场景 | 行为 |
|------|------|
| 用户跳过方案选择 | 使用默认方案A |
| 配置文件损坏/无法解析 | 使用默认方案A + 警告提示 |
| UPDATE 模式配置文件不存在 | 使用默认方案A（不生成配置文件） |
