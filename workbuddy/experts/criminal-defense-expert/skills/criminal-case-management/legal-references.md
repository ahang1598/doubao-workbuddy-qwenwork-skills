### 法条原文引用

#### 刑诉法第40条

```
辩护律师自人民检察院对案件审查起诉之日起，可以查阅、摘抄、复制本案的案卷材料。其他辩护人经人民法院、人民检察院许可，也可以查阅、摘抄、复制上述材料。
```

> 注：2018年刑诉法修正后，原第38条变更为第40条。

#### 刑诉法第91条

```
公安机关对被拘留的人，认为需要逮捕的，应当在拘留后的三日以内，提请人民检察院审查批准。在特殊情况下，提请审查批准的时间可以延长一日至四日。
对于流窜作案、多次作案、结伙作案的重大嫌疑分子，提请审查批准的时间可以延长至三十日。
```

#### 刑诉法第94条

```
人民法院、人民检察院对于各自决定逮捕的人，公安机关对于经人民检察院批准逮捕的人，都必须在逮捕后的二十四小时以内进行讯问。在发现不应当逮捕的时候，必须立即释放，发给释放证明。
```

#### 刑诉法第172条

```
人民检察院对于公安机关移送起诉的案件，应当在一个月以内作出决定，重大、复杂的案件，可以延长十五日；犯罪嫌疑人认罪认罚，符合速裁程序适用条件的，应当在十日以内作出决定，对可能判处的有期徒刑超过一年的，可以延长至十五日。
```

## 4. misuse_warnings

| 易混淆 | 正确区分 | 区分要点 |
|--------|----------|---------|
| 拘留≠逮捕 | 第91条vs第94条 | 拘留是紧急措施，逮捕是正式羁押，期限计算不同 |
| 审查起诉期限≠一审审限 | 第172条vs第208条 | 审查起诉1月+延15日，一审2月+延 |
| 退补后期限重算 | 第175条第3款 | 每次退补后审查起诉期限重新计算 |
| 羁押期限≠办案期限 | 区分概念 | 羁押期限以人身自由为限，办案期限以程序节点为限 |
| 阅卷权条文编号 | 第40条（非第38条） | 2018年修正后编号变更，旧版第38条已失效 |
