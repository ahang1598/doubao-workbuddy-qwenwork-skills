# 材料索引表模板

> 本模板定义刑事案件材料索引表的标准结构

## 表格结构

| 编号 | 材料名称 | 类型 | 所在阶段 | 册号页码 | 内容摘要 | 关键度 |
|------|----------|------|---------|---------|---------|--------|
| M-001 | {材料名称} | {类型} | {阶段} | 卷{X}第{Y}-{Z}页 | {50字以内摘要} | {high/medium/low/待评估} |
| M-002 | ... | ... | ... | ... | ... | ... |

## 字段填写规则

### 编号
- 格式：M-XXX（从M-001开始，连续编号）
- 不跳号，不重复

### 材料名称
- 使用材料原始名称或规范化名称
- 多份同类材料加序号区分（如：讯问笔录第1次/第2次）

### 类型
- 枚举值：言词证据 / 实物证据 / 鉴定意见 / 程序文书 / 诉讼文书 / 法律文书 / 技术材料 / 律师工作成果 / 待分类
- 无法确定时归入"待分类"

### 所在阶段
- 枚举值：侦查 / 审查起诉 / 一审 / 二审 / 死刑复核 / 执行 / 申诉再审 / 待确认
- 按材料产生阶段标注，非当前案件阶段

### 册号页码
- 格式：卷{X}第{Y}-{Z}页
- 无法确定时标注"待查"
- 电子材料标注"电子卷宗第X页"

### 内容摘要
- 50字以内，提炼核心内容
- 包含：关键人物+关键事件+关键结论
- 不做分析判断，仅客观摘录

### 关键度
- 枚举值：high / medium / low / 待评估
- 评估标准见 methodology.md §5
