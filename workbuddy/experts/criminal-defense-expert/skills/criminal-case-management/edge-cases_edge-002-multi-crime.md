# 边界示例：多罪名案件初始化

> 场景：涉嫌2个罪名，材料较多

## 用户输入

```
初始化刑事案件。王某涉嫌受贿罪、滥用职权罪，一审阶段。
案号：（2024）京01刑初456号。
案卷材料：
1.起诉书
2.被告人讯问笔录8份
3.行贿人赵某讯问笔录5份
4.其他证人证言6份
5.银行流水记录
6.扣押物品清单
7.笔记本（扣押物）照片及说明
8.鉴定意见（笔迹鉴定）
9.审计报告
10.滥用职权相关行政审批材料
11.拘留通知书（2024-02-01）
12.逮捕决定书（2024-02-15）
被告人现羁押于YY看守所。
```

## 技能输出说明

本示例展示多罪名案件的处理方式：

1. **目录结构**：与单罪名相同，但在00-案件管理/01-案情表.md中按罪名分别组织构成要件

2. **材料索引表**：材料编号连续（M-001~M-012），但关键度评估需考虑两个罪名的分别影响

3. **案情表特殊结构**：
   - （二）犯罪构成要件事实 → 分为"受贿罪"和"滥用职权罪"两个子板块
   - 每个罪名各有：客体/客观/主体/主观四要件
   - （三）量刑情节 → 区分"受贿罪情节"和"滥用职权罪情节"以及"数罪并罚情节"

4. **下游消费指引**：
   - criminal-sentencing-analysis 需读取两个罪名的量刑情节
   - criminal-evidence-analysis 需分别分析两个罪名的证据链

### 案情表多罪名结构示例

```markdown
### （二）犯罪构成要件事实

#### 罪名一：受贿罪

##### 1. 客体要件
[F-001] 涉嫌侵犯国家工作人员职务行为的廉洁性 [来源：M-001]

##### 2. 客观要件
[F-002] 据指控，王某利用职务便利收受赵某贿赂XX万元 [来源：M-001]
[F-003] 银行流水显示大额资金流入 [来源：M-005]

##### 3. 主体要件
[F-004] 王某，国家工作人员，XX局局长 [来源：M-001]

##### 4. 主观要件
[F-005] 据指控，王某明知是贿赂仍予以收受 [来源：M-001]

#### 罪名二：滥用职权罪

##### 1. 客体要件
[F-006] 涉嫌侵犯国家机关正常活动 [来源：M-001]

##### 2. 客观要件
[F-007] 据指控，王某超越职权审批XX项目 [来源：M-001, M-010]

##### 3. 主体要件
[F-008] 同[F-004]，国家工作人员 [来源：M-001]

##### 4. 主观要件
[F-009] 据指控，王某明知超越职权仍予以审批 [来源：M-001]
```

### 争议焦点多罪名示例

```markdown
### （五）争议焦点

#### 受贿罪争议
1. **受贿金额认定**：指控XX万元 vs 辩方对部分金额性质有异议 [M-001 vs M-002]
2. **利用职务便利**：是否属于利用职务上的便利 [待阅卷确认]

#### 滥用职权罪争议
1. **是否超越职权**：审批是否在法定权限内 [M-010]
2. **损失认定**：滥用职权造成的损失金额待确认

#### 数罪并罚问题
1. 两罪是否为独立行为，应数罪并罚
```
