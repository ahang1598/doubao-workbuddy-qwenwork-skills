# 工作流详述

> 本文件定义 criminal-non-prosecution 技能的各Phase子步骤与检查点 | 版本: v4.0.1
>
> **范式声明**：本技能遵循 §17.28 lawyer_draft 范式。Phase 4 意见书起草前须执行 P4.0 骨架选择流程（5种动态骨架A/B/C/D/E），论证主体以自然段落连续叙述，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）。

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 类型路由 → Phase 3: 论证组织
    ↓
Phase 4: 意见书起草 → Phase 5: 质量检查 → Phase 6: 输出交付
```

## 5. Phase 4: 意见书起草

### 4.0 骨架选择（P4.0，LLM内部判断，不暴露给用户）

> **lawyer_draft 范式核心**：每次生成前必须按以下8步执行骨架选择流程，不得跳过（AM-04）。

```
1. 确认不起诉类型（statutory/discretionary/insufficient_evidence/conditional/special）
2. 按触发条件匹配骨架（A→B→C→D→E，可组合如B+D）
3. 确定论证密度（argument_density: brief/standard/detailed）
4. 确定事实呈现方式（fact_presentation: narrative/focus）
5. 从模块池随机选择开篇模块和结语模块（禁止与上次生成重复，AM-01）
6. 选择文书声音（voice:cold/firm/sincere）
7. 识别受众适配（承办检察官→实体侧重/检委会→社会效果侧重）
8. 按骨架顺序组织论证段落（骨架决定论证主题顺序，不是固定标题顺序）
```

### 4.1 按 output-spec.md §1A 渲染

按 output-spec.md §1A 组件渲染序列。关键规则：
- **lawyer_draft 范式**：论证主体以自然段落连续叙述，不输出模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙）
- **无独立案件事实段**：事实融入各论证主题"以论证带事实"
- **开篇叙述段**：辩护人/委托人/嫌疑人信息以自然叙述融入，不使用表格
- 五类不起诉严格区分，不得混用论证逻辑
- 法定不起诉=应当（命令性）
- 酌定不起诉=可以（授权性，须三维论证：情节轻微+社会危害性消除+修复性实现）
- 存疑不起诉=应当（命令性，但退补程序有三级路径）
- 附条件不起诉=可以（附考验期，仅限未成年人）
- 特殊不起诉=须经最高检核准
- **O1(.docx) 删除免责声明**：仅 O2(Markdown) 保留

**检查点**：[ ] P4.0骨架选择已执行 [ ] 格式正确 [ ] 类型路由正确 [ ] 法条准确 [ ] 无独立案件事实段 [ ] 信息区无表格 [ ] O1无免责声明 [ ] 论证正文无模板标签式标题（AM-05）且以加粗陈述句路标分隔（AM-05b）且无破折号（AM-05c）
