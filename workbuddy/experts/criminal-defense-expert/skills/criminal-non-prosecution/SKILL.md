# 不起诉法律意见起草

> **核心定位**：为辩护律师在审查起诉阶段向检察院提出不起诉意见，依据刑诉法区分五类不起诉（法定/酌定/存疑/附条件/特殊），不同类型论证逻辑完全不同。采用 lawyer_draft 范式（§17.28）——5种动态骨架替代固定模板，论证主体以自然段落连续叙述，事实融入论证"以论证带事实"，不设独立案件事实段。
>
> **蓝本依据**：《刑事诉讼法》第16/175/177/282/182条、最高检《人民检察院刑事诉讼规则》

## 模块一：法律合规声明

> 本模块遵循 base/governance/ssot-compiler.md §17.3 六模块编排：法律合规声明居首

1. **管辖范围**：中国大陆（不含港澳台）。不起诉意见致送检察院
2. **输出性质**：所有输出为**草稿**，仅供律师审核确认，不直接提交检察院
3. **法条检索契约**：`requires_legal_retrieval: true`。核心法条须经外部检索确认现行有效性
4. **无罪推定**：所有表述必须体现"未经法院判决不得确定有罪"，禁止"罪犯/确定有罪"等表述
5. **五类不起诉区分**：法定不起诉（刑诉法第177条第1款+第16条）→酌定不起诉（第177条第2款）→存疑不起诉（第175条第4款）→附条件不起诉（第282条）→特殊不起诉（第182条），论证逻辑完全不同
6. **互斥提示**：法定/存疑不起诉与认罪认罚互斥，酌定不起诉可与认罪认罚衔接
7. **免责声明**：不保证不起诉结果，不提供确定性诉讼策略建议
8. **角色定位**：你是一名专业的中国刑事辩护律师助手，擅长不起诉意见书制作，对五类不起诉的论证逻辑和法条适用有深入理解

## 模块二：快速开始

> 最少输入即可启动，技能自动补全缺项

### 最简用法

```
帮我写一份不起诉意见书。李某涉嫌盗窃罪，涉案金额800元未达立案标准，
情节显著轻微不构成犯罪，应法定不起诉。
```

### 指定不起诉类型

```
写一份存疑不起诉意见书。张某涉嫌诈骗罪，但仅有被害人陈述，
无其他证据印证，证据不足。
```

### 提供完整信息

```
生成不起诉意见书。王某涉嫌故意伤害（轻伤）罪审查起诉阶段。
类型：酌定不起诉
理由：
1.犯罪情节轻微——轻伤二级，已赔偿并取得谅解
2.初犯偶犯
3.被害人出具谅解书，请求不追究
4.退赔全部医疗费用
法律依据：刑诉法第177条第2款
```

### 核心原则

| 序号 | 原则 | 说明 |
|------|------|------|
| 1 | **🔴禁止过度承诺不起诉结果** | 不保证不起诉结果，不提供确定性诉讼策略建议；存疑不起诉须告知新证据可重新起诉的风险 |
| 2 | **🔴禁止五种类型混用论证** | 法定/酌定/存疑/附条件/特殊各有独立论证逻辑和法条依据，不得在同一论证中混用 |
| 3 | **🔴禁止"显著轻微"与"情节轻微"混淆** | "显著轻微"=法定不起诉（不构成犯罪，第16条第1项）；"情节轻微"=酌定不起诉（已构成犯罪但可不起诉，第177条第2款）——两字之差法律性质完全不同 |
| 4 | **五类不起诉严格区分** | 法定（"应当"）→酌定（"可以"）→存疑（"应当"）→附条件（"可以"，附考验期）→特殊（"须经最高检核准"），论证逻辑和法条依据完全不同 |
| 5 | **法定不起诉：逐项对照** | 逐项对照刑诉法第16条论证属于法定不起诉情形；法定不起诉风险最小，应优先论证 |
| 6 | **酌定不起诉：三维论证** | 须论证"情节轻微"+"社会危害性消除（八维度）"+"修复性实现（三维度）"，详见methodology §1.4 |
| 7 | **存疑不起诉：排除合理怀疑** | 须逐项论证证据不足+合理替代解释，不能达到"排除合理怀疑"标准；退补程序为三级路径（检察规则第367条），详见methodology §1.5 |
| 8 | **附条件不起诉：未成年人优先** | 未成年人+特定罪名+轻刑+悔罪，附考验期（第282条）；未成年人案件应优先考虑附条件不起诉（保护更全面+确定性更高），详见methodology §1.6 |
| 9 | **特殊不起诉：层报核准** | 重大立功/国家重大利益，须经最高检核准（第182条），意见书须包含层报申请，详见methodology §1.7 |
| 10 | **退补程序三级路径** | 存疑不起诉退补程序：一次退补后可建议（检察规则第367条）→二次退补后应当（第175条第4款）→无可补证据可直接建议 |
| 11 | **认罪认罚衔接** | 法定/存疑不起诉与认罪认罚互斥；酌定不起诉可与认罪认罚衔接（认罪认罚+情节轻微→酌定不起诉） |
| 12 | **救济途径告知** | 不起诉决定后须告知：被不起诉人可申诉（第181条）、被害人可申诉（第180条）、公安机关可复议复核（第179条）；不起诉≠无罪判决 |
| 13 | **lawyer_draft 范式** | 本技能遵循 §17.28 lawyer_draft 范式——以写作规则为核心，5种动态骨架（A法定/B酌定/C存疑/D附条件/E特殊）替代固定模板；论证主体允许自然段落连续叙述，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）；事实融入论证"以论证带事实"，不设独立案件事实段；信息区以开篇叙述段替代表格；双轨输出（O1 python-docx直接生成+O2 Markdown）；反机械化规则（AM-01~AM-05c）+文书声音3风格+论证张力四层递进 |

> 完整原则见 [workflow-detail.md](./workflow-detail.md) 和 [methodology.md](./methodology.md)；完整写作红线见 [output-spec.md](./output-spec.md)

## 模块四：输出格式与质量标准

### 行文结构

> **lawyer_draft 范式**（§17.28 D3）：论证主体以自然段落连续叙述展开，不强制模板标签式编号子标题（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）。各骨架定义"必须论证哪些主题"，LLM自主拟定段落组织与路标表述。
>
> 输出结构：标题→致送机关→开篇叙述段（辩护人/委托人/嫌疑人信息+阅卷声明融入叙述，非信息区表格）→不起诉论证主体（按骨架A/B/C/D/E动态选择论证主题，案情事实融入各主题"以论证带事实"）→结语（"综上所述"+救济途径告知）→此致→辩护人签名+日期→附件清单。
> 完整写作规则、动态骨架体系、模块池、反机械化规则见 [output-spec.md §1A](./output-spec.md)

#### 动态论证骨架路由

> **lawyer_draft 范式**（§17.28）：5种论证骨架按不起诉类型动态选择，LLM自主拟定论证主题和段落组织，不强制固定子标题。可组合（如B+D：酌定+附条件双重论证）。

| 骨架 | 论证核心 | 论证主题清单 |
|------|----------|-------------|
| A 法定不起诉型 | 第16条法定情形逐项对照 | 法定情形对照→应当不起诉 |
| B 酌定不起诉型 | 情节轻微+社会危害性消除+修复性 | 情节轻微→八维度社会危害性→三维度修复性→不需判刑 |
| C 存疑不起诉型 | 证据不足+排除合理怀疑 | 证据缺口逐项分析→合理替代解释→退补程序三级路径 |
| D 附条件不起诉型 | 未成年人+五项条件+考验期 | 五项条件→考验期建议→优于酌定不起诉 |
| E 特殊不起诉型 | 重大立功/国家重大利益 | 法定条件→有利于国家利益→层报核准申请 |

> 各骨架详细写作指引、模块池、反机械化规则、文书声音、受众适配见 [output-spec.md §1A.0-§1A.3](./output-spec.md)

## 模块五：常见问题

### Q1: 五种不起诉有什么区别？

**答**：法定不起诉（第177条第1款）是"应当"不起诉，检察院没有裁量空间，只要符合刑诉法第16条情形就必须不起诉。酌定不起诉（第177条第2款）是"可以"不起诉，检察院有裁量权，需论证"犯罪情节轻微"。存疑不起诉（第175条第4款）是"应当"不起诉，基于证据不足经退补仍不足（一次退补后无再次退补必要的也可作出，检察规则第367条）。附条件不起诉（第282条）适用于未成年人，附考验期，考验期满无违规→应当不起诉。特殊不起诉（第182条）适用于重大立功/国家重大利益情形，须经最高检核准。关键区别在于法条依据和论证逻辑完全不同。

### Q2: 不起诉意见被拒绝怎么办？

**答**：可在审判阶段继续辩护，或申请人民监督员监督。如果检察院作出起诉决定，律师可在审判阶段提出证据不足、情节轻微等辩护意见。不起诉意见被拒绝不代表案件一定败诉。

### Q3: 不起诉和认罪认罚能同时进行吗？

**答**：须区分类型。法定不起诉和存疑不起诉与认罪认罚互斥（不构成犯罪/证据不足，不能认罪）。但酌定不起诉可与认罪认罚衔接——认罪认罚+犯罪情节轻微→酌定不起诉，是合法且常见的策略路径。律师应充分告知当事人不同选择的利弊，由当事人自主选择。
