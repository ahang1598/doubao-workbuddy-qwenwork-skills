# 输入规格

> 本文件定义 criminal-non-prosecution 技能的完整输入参数规格
> 遵循 base/governance/ssot-compiler.md §17（SSOT）：输入宽容度契约

## 1. 必需输入

| 字段 | 类型 | 枚举值 | 说明 | 验证规则 |
|------|------|--------|------|----------|
| `suspect_name` | string | - | 犯罪嫌疑人姓名 | 非空 |
| `alleged_crime` | string | - | 涉嫌罪名 | 非空 |
| `non_prosecution_type` | enum | statutory/discretionary/insufficient_evidence/conditional/special | 不起诉类型 | 必须为枚举值 |
| `case_facts` | string | - | 案件事实 | 非空 |
| `legal_grounds` | string | - | 法律依据和理由 | 非空 |

> **派生字段** `arguments`：指经 P4.0 按骨架 A/B/C/D/E 组织后的**论证主体文本**，由 `case_facts` + `legal_grounds` + 不起诉类型加工而成，非用户直接输入。workflow-detail §1.3 与 templates/docx 模板均以 `arguments` 承接该派生结果。

## 2. 可选输入

### 2.1 犯罪嫌疑人信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `suspect_gender` | string | [待补充] | 性别 |
| `suspect_age` | string | [待补充] | 年龄 |
| `suspect_custody` | boolean | true | 是否在押 |
| `prior_record` | boolean | false | 是否有前科 |

### 2.2 案件信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `evidence_status` | string | [待补充] | 证据状况 |
| `case_stage` | enum | 审查起诉 | 案件阶段 |
| `prosecutor_name` | string | [待补充] | 承办检察官 |

### 2.3 不起诉理由详情

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `statutory_ground` | enum | 无犯罪事实/已过追诉时效/特赦/告诉才处理未告诉/犯罪嫌疑人死亡/其他 | 法定不起诉理由 |
| `discretionary_ground` | string | [待补充] | 酌定不起诉理由（犯罪情节轻微） |
| `insufficient_evidence_ground` | string | [待补充] | 存疑不起诉理由（证据不足） |
| `conditional_ground` | string | [待补充] | 附条件不起诉理由（未成年人+特定罪名+轻刑+悔罪） |
| `special_ground` | string | [待补充] | 特殊不起诉理由（重大立功/国家重大利益） |
| `suspect_minor` | boolean | false | 犯罪时是否未成年人（T4必需） |

## 3. 输入宽容度契约

| 最小输入 | 处理方式 |
|----------|----------|
| 仅嫌疑人+罪名+类型+理由 | 生成不起诉意见书框架 |
| 仅"不起诉" | 询问案件信息和类型 |

交互补全最多3轮。

## 4. 场景适配规则

### 4.1 不起诉类型适配

| 类型 | 法条 | 适用条件 | 法律性质 |
|------|------|----------|----------|
| 法定不起诉(T1) | 刑诉法第177条第1款 | 六种法定情形 | 应当不起诉（命令性） |
| 酌定不起诉(T2) | 刑诉法第177条第2款 | 犯罪情节轻微+不需要判刑 | 可以不起诉（授权性） |
| 存疑不起诉(T3) | 刑诉法第175条第4款 | 证据不足+退补流程（三级路径） | 应当不起诉（命令性） |
| 附条件不起诉(T4) | 刑诉法第282条 | 未成年人+特定罪名+轻刑+悔罪 | 可以不起诉（附考验期） |
| 特殊不起诉(T5) | 刑诉法第182条 | 重大立功/国家重大利益 | 须经最高检核准 |

### 4.2 重要区分

> **法定不起诉**：检察院"应当"作出，无裁量权
> **酌定不起诉**：检察院"可以"作出，有裁量权
> **存疑不起诉**：退补后仍证据不足"应当"作出（一次退补后无再次退补必要的也可作出，检察规则第367条）
> **附条件不起诉**：未成年人案件，附考验期，考验期满无违规→应当不起诉
> **特殊不起诉**：重大立功/国家重大利益，须经最高检核准
