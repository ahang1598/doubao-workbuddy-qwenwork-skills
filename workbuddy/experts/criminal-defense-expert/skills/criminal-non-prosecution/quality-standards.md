# 质量标准：不起诉意见书

> 定义不起诉意见书的质量评价维度和标准
> 版本: v4.0.1

## 一、六维评价体系

| 维度 | 权重 | 优秀标准 | 合格标准 | 不合格 |
|------|------|---------|---------|--------|
| 类型准确性 | 25% | 五类不起诉区分精准 | 类型基本正确 | 混淆不起诉类型 |
| 法条匹配 | 20% | 法条与类型完全匹配 | 法条引用正确 | 法条引用错误 |
| 论证充分性 | 20% | 逐项论证+具体分析 | 有论证过程 | 无论证断言 |
| 退补程序 | 15% | 存疑不起诉按三级路径论证 | 已提及退补 | 存疑不起诉机械"须经二次退补" |
| 互斥检查 | 10% | 法定/存疑与认罪认罚无矛盾 | 已确认选择 | 逻辑矛盾 |
| 表达精炼 | 10% | 3-5页重点突出 | 表达规范 | 冗长混乱 |

## 二、特有质量检查项

| 检查项 | 阻断/警告 | 说明 |
|--------|----------|------|
| 五类不起诉区分 | 阻断 | 法定/酌定/存疑/附条件/特殊论证逻辑不同 |
| 法定不起诉→第16条+第177条第1款 | 阻断 | 须逐项对照第16条 |
| 酌定不起诉→第177条第2款 | 阻断 | 须三维论证："情节轻微"+"社会危害性消除（八维度）"+"修复性实现（三维度）" |
| 存疑不起诉→第175条第4款 | 阻断 | 退补程序为三级路径（检察规则第367条），不得机械"须经二次退补"；须排除合理怀疑论证（证据缺口+合理替代解释） |
| 附条件不起诉→第282条 | 阻断 | 须满足五项条件，含考验期建议；未成年人案件应优先考虑附条件不起诉 |
| 特殊不起诉→第182条 | 阻断 | 须层报最高检核准；须包含重大立功/国家重大利益详述 |
| "犯罪情节轻微"≠"显著轻微" | 阻断 | 前者酌定不起诉，后者法定不起诉 |
| 存疑/法定不起诉与认罪认罚不并存 | 阻断 | 逻辑矛盾；酌定不起诉可与认罪认罚衔接 |
| 救济途径告知 | 阻断 | 不起诉决定后须告知第179/180/181条救济途径 |
| 无过度承诺 | 阻断 | 禁止"必然不起诉""肯定不起诉"等确定性表述 |
| 附条件不起诉优先于酌定不起诉 | 警告 | 未成年人案件应优先考虑附条件不起诉 |
| 八维度社会危害性论证 | 警告 | 酌定不起诉须覆盖八维度 |
| 修复性三维度论证 | 警告 | 酌定不起诉须含退赃退赔+被害人谅解+社区接纳 |
| 致送检察院 | 阻断 | 不得致送法院 |

## 三、lawyer_draft 范式写作质量维度（v4.0.0新增，§17.28 D3）

| 检查项 | 阻断/警告 | 说明 |
|--------|----------|------|
| 论证张力 | 警告 | 每段论证须含"行为定性→效果递进→法条支撑→价值判断"四层递进，非平铺事实 |
| 行为定性 | 警告 | 核心事实须有定性词汇（时间副词/态度副词/程度词），非口语描述 |
| 法条嵌入方式 | 警告 | 法条内嵌论述自然落点，禁止独立成句前置 |
| 文书声音 | 警告 | 须按P4.0选择文书声音（cold/firm/sincere）并贯穿全文 |
| 反机械化AM-01 | 阻断 | 开篇/结语模块组合非固定（M1+M1禁止） |
| 反机械化AM-02 | 阻断 | "辩护人认为"全文≤3次 |
| 反机械化AM-03 | 阻断 | "恳请贵院"全文≤3次 |
| 反机械化AM-04 | 阻断 | P4.0骨架选择流程已执行（非默认骨架跳过） |
| 反机械化AM-05 | 阻断 | 论证正文无模板标签式标题（`一、案件事实`/`## 请求事项`等跨案件通用槽位不输出到文书） |
| 反机械化AM-05b | 阻断 | 论证主体须以加粗陈述句路标分隔各论证主题（含具体案情、传递结论、无破折号），禁止纯连续无结构文字墙 |
| 反机械化AM-05c | 阻断 | 论证路标/标题中无破折号`——`格式 |
| 骨架论证完整性 | 阻断 | 所选骨架的论证主题清单全部覆盖 |
| 阅卷声明 | 阻断 | 开篇叙述段含"辩护人已于审查起诉阶段查阅全部侦查卷宗" |
| 信息区无表格 | 阻断 | 辩护人/嫌疑人信息以开篇叙述段融入 |
| 无独立案件事实段 | 阻断 | 事实融入各论证主题"以论证带事实" |
| O1无免责声明 | 阻断 | .docx正式提交稿不含免责声明，仅O2(Markdown)保留 |
