# DOCX 模板：不起诉法律意见书

> criminal-non-prosecution | DOCX模板 | v4.0.1
>
> **范式声明**：本模板遵循 §17.28 lawyer_draft 范式。以下各骨架模板中的编号为**论证主题指引**（LLM内部分类标签），非输出标题。LLM须以自然段落连续叙述展开论证，**不输出模板标签式编号子标题到文书正文（AM-05），但须以加粗陈述句路标分隔各论证主题（AM-05b，禁止纯连续文字墙），路标禁破折号（AM-05c）**。O1 docx 中路标=加粗首句或独立加粗行（仿宋加粗），可选 Word 原生编号（一、/（一））。
>
> 本模板供 LLM 运行时调用 python-docx API 生成 DOCX 时参考。排版参数详见 `references/output-spec.md` "DOCX 排版规格"专章。

## 1. 通用 python-docx 框架

```python
from docx import Document
from docx.shared import Pt, Cm, DXA, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH

def create_non_prosecution_opinion(
    suspect_name: str,
    alleged_crime: str,
    non_prosecution_type: str,  # statutory/discretionary/insufficient_evidence/conditional/special
    prosecutor_office: str,
    lawyer_name: str,
    law_firm: str,
    license_no: str,
    arguments: str,  # 已按骨架A/B/C/D/E组织的论证主体文本
    conclusion: str,
    evidence_list: list = None,
):
    doc = Document()

    # === 页面设置 ===
    section = doc.sections[0]
    section.page_width = DXA(11906)
    section.page_height = DXA(16838)
    section.top_margin = DXA(2100)    # 3.7cm
    section.bottom_margin = DXA(1984) # 3.5cm
    section.left_margin = DXA(1588)   # 2.8cm
    section.right_margin = DXA(1474)  # 2.6cm

    # === 页眉页脚 ===
    _setup_header_footer(section)

    # === 标题 ===
    _add_title(doc, f"关于{suspect_name}涉嫌{alleged_crime}的不起诉意见")

    # === 致送机关 ===
    _add_addressee(doc, prosecutor_office)

    # === 开篇叙述段（替代信息区表格，含阅卷声明+不起诉类型标识） ===
    _add_introduction(doc, lawyer_name, law_firm, license_no,
                      suspect_name, alleged_crime, non_prosecution_type)

    # === 论证主体（按骨架A/B/C/D/E动态组织，无独立案件事实段） ===
    # arguments 已由 LLM 按 lawyer_draft 范式生成：自然段落连续叙述，不输出模板标签式编号子标题，须以加粗陈述句路标分隔各论证主题（AM-05b）
    _add_body_text(doc, arguments)

    # === 结语段（"综上所述"+救济途径告知） ===
    _add_conclusion(doc, suspect_name, conclusion, non_prosecution_type)

    # === 此致 ===
    _add_courtesy(doc, prosecutor_office)

    # === 落款 ===
    _add_signature_block(doc, lawyer_name, law_firm)

    # === 附件清单 ===
    if evidence_list:
        _add_evidence_list(doc, evidence_list)

    # 注意：O1(.docx) 不含免责声明（仅 O2 Markdown 保留）

    return doc
```

## 2. 五种骨架论证主题指引

> 以下为各骨架的**论证主题清单**（必须论证，顺序可调，标题LLM自拟）。LLM以自然段落连续叙述展开，**不输出模板标签式编号子标题（AM-05），但须将每个主题转化为一句加粗陈述句路标（AM-05b）——含本案具体事实、传递论证结论、无破折号（AM-05c）**，事实融入各主题"以论证带事实"。

### 2.1 骨架A：法定不起诉型

**论证主题清单**：

- **法定情形对照**：逐项对照刑诉法第16条六种法定情形，论证本案符合哪种情形。事实在对照中自然引入（引用卷宗页码/证据编号）。法条嵌入论证自然落点——"XXX的行为符合《刑事诉讼法》第十六条第[X]项规定的[法定情形]，依据第一百七十七条第一款之规定，人民检察院应当作出不起诉决定。"
- **应当不起诉**：论证检察院无裁量权，"应当"作出不起诉决定。禁止与认罪认罚同时主张。

### 2.2 骨架B：酌定不起诉型

**论证主题清单**：

- **犯罪情节轻微**：金额小/后果轻/偶犯/从犯等，须有具体事实支撑。禁止空洞套话。
- **社会危害性消除（八维度）**：犯罪性质/犯罪情节/主观恶性/悔罪表现/社会关系修复/再犯可能性/社会影响/公共利益，逐维度论证。禁止仅罗列从轻情节。事实在各维度中自然呈现。
- **修复性实现（三维度）**：退赃退赔+被害人谅解+社区接纳，须附凭证。禁止仅有谅解书无实际赔偿。退赃>赔偿>谅解的权重排序。
- **不需判处刑罚**：引用刑法具体条文（第37条免除刑罚/第67条自首/第68条立功/第24条中止犯等）。禁止仅有"情节轻微"无法条依据。

### 2.3 骨架C：存疑不起诉型

**论证主题清单**：

- **证据缺口逐项分析**：客观方面/主观方面/因果关系逐项论证证据不足，引用卷宗页码。禁止笼统说"证据不足"。事实在证据分析中自然呈现。
- **合理替代解释**：提出不能排除的合理怀疑（不在场/他人作案/行为性质其他解释）。禁止做完整无罪论证（仅论证证据不足）。
- **退补程序说明**：说明退补情况，引用检察规则第367条三级路径。禁止机械"须经二次退补"。

### 2.4 骨架D：附条件不起诉型

**论证主题清单**：

- **五项条件论证**：未成年人+特定罪名+轻刑+符合起诉条件+悔罪，逐项论证。禁止遗漏考验期建议。事实在条件论证中自然呈现。
- **考验期建议**：根据犯罪情节/悔罪表现提出考验期建议（6-12个月），含监督考察方案。
- **优于酌定不起诉**：论证附条件不起诉对未成年人保护更全面+确定性更高。禁止与酌定不起诉混用论证逻辑。

### 2.5 骨架E：特殊不起诉型

**论证主题清单**：

- **法定条件论证**：自愿如实供述+重大立功/国家重大利益，详述事实。禁止无查证材料即主张重大立功。事实在条件论证中自然呈现。
- **有利于国家利益**：具体论证继续追诉可能影响的方面。
- **层报核准申请**：引用第182条，申请层报最高检核准。禁止遗漏层报程序。

### 论证路标示例（AM-05b / AM-05c）

> 下列展示同一骨架（B酌定不起诉）"主题指引 → 输出路标"的转化。路标为加粗陈述句，含具体案情、无破折号。

| 主题指引（内部） | 输出路标（加粗陈述句） | 评价 |
|------|------|------|
| 犯罪情节轻微 | `**涉案金额800元，未达盗窃罪立案标准，犯罪情节显著轻微**` | ✅ 含具体金额+结论 |
| 社会危害性消除（八维度） | `**案发后全额退赃并取得书面谅解，社会危害性已实质性消除**` | ✅ 有事实依据 |
| 修复性实现（三维度） | `**已赔偿被害人全部医疗费并获书面谅解，修复性充分实现**` | ✅ 具体凭证 |
| ❌ 错误示范 | `一、犯罪情节轻微` / `涉案金额——仅800元` | 模板标签 / 破折号机械感 |

## 3. 存疑不起诉风险提示标准文本（仅O2）

```
特别说明：存疑不起诉决定作出后，如发现新的证据，人民检察院可以重新起诉。
辩护人已向当事人充分告知此风险。
```

## 4. 开篇叙述段模块池（3选1，AM-01禁止固定）

**M1 律师代理型（默认）**：
```
辩护人XXX，XXX律师事务所律师（执业证号XXX），接受犯罪嫌疑人XXX之[关系]
XXX的委托，担任XXX涉嫌XX罪一案审查起诉阶段的辩护人。辩护人已于审查
起诉阶段查阅全部侦查卷宗并会见了XXX（刑诉法第四十条），现提出**[法定/
酌定/存疑/附条件/特殊]**不起诉意见如下。
```

**M2 律所指派型**：
```
XXX律师事务所接受犯罪嫌疑人XXX近亲属XXX的委托，指派XXX律师担任XXX
涉嫌XX罪一案审查起诉阶段的辩护人。辩护人经查阅全部侦查卷宗并会见XXX，
依法提出**[类型]**不起诉意见如下。
```

**M3 简明委托型**：
```
辩护人XXX依法接受委托，担任XXX涉嫌XX罪一案辩护人。经查阅全部侦查
卷宗，现提出**[类型]**不起诉意见如下。
```

## 5. 结语模块池（3选1，AM-01禁止固定）

**M1 审慎型**：
```
综上所述，辩护人认为……根据《中华人民共和国刑事诉讼法》第X条之规定，
[建议/恳请]贵院依法对XXX作出不起诉决定。如贵院作出不起诉决定，
被不起诉人/被害人/公安机关依法享有申诉/复议权利（第179/180/181条）。
```

**M2 恳请型**：
```
综上，辩护人[建议/恳请]贵院充分考虑上述意见，依法对XXX作出不起诉
决定。如贵院作出不起诉决定，被不起诉人对酌定不起诉可申诉（第181条）；
被害人不服可申诉（第180条）；公安机关可复议复核（第179条）。
```

**M3 策略型**：
```
综上所述，基于现有证据和案件情况，辩护人认为[核心论点]。
[建议/恳请]贵院依法审查并采纳辩护意见。
```
