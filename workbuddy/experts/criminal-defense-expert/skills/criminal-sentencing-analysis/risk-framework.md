# 风险框架：criminal-sentencing-analysis

> 量刑分析 | 版本: v2.1.0

## 1. 风险等级

**L2（中等风险）**——量刑计算影响辩护策略，需律师复核

## 2. 风险分级标注

| Phase | 风险等级 | 说明 |
|-------|----------|------|
| Phase 1 输入验证 | L1 | 低风险 |
| Phase 2 案件信息结构化 | L2 | 中风险 |
| Phase 3 基准刑确定 | **L3** | **高风险**——基准刑确定错误导致全部结果偏移 |
| Phase 4 情节调节 | **L3** | **高风险**——同向累计调节+先/后适用分步，计算错误为最高风险项 |
| Phase 5 缓刑可行性分析 | L2 | 中风险 |
| Phase 6 辩护建议 | L1 | 低风险 |

## 3. 风险控制规则

| # | 规则 | 触发条件 | 效果 |
|---|------|----------|------|
| RC-01 | 禁止承诺结果 | "一定判XX年" | 拒绝+标注为估算 |
| RC-02 | 地区差异标注 | 涉及数额标准 | 标注"[需核实当地规定]" |
| RC-03 | 条文性质区分 | 引用从轻从重法条 | 区分命令性（应当）/授权性（可以） |
| RC-04 | 计算透明 | 生成量刑分析 | 每步计算公开+法条依据 |
| RC-05 | **禁止逐项连乘** | 情节调节计算 | **必须使用同向累计调节法** |
| RC-06 | **禁止概率百分比** | 量刑预测输出 | **使用"最可能/可能/较小可能"三级区间** |
| RC-07 | **法定最低刑约束** | 从轻累计调节后低于法定最低刑 | **标注以法定最低刑为限** |
| RC-08 | 先/后适用情节分步 | 存在先适用情节（从犯/未遂/中止） | 先适用先行调节，后适用再调节 |

## 4. 行为约束

- 量刑分析供参考，不替代律师判断
- 不得出现确定性量刑结论
- 涉及地区差异须标注核实要求
- 计算过程必须公开透明
- **不得使用逐项连乘计算情节调节**
- **不得给出量刑概率百分比**
- **刑期取整到月，禁止伪精确小数**
