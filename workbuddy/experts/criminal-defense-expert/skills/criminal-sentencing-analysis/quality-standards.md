# 质量标准：量刑预测与辩护

> v2.1.0 | 2026-06-18 从1.17KB扩展，补充8个评分维度和6个检查项

## 1. 评分维度

| 维度 | 权重 | 优秀 | 合格 | 不合格 |
|------|------|------|------|--------|
| 量刑计算透明 | 15% | 四步法完整（基准刑→先适用调节→后适用调节→法定最低刑约束检查）+计算过程可追溯 | 有量刑计算 | 量刑计算不透明或使用逐项连乘 |
| 情节调节方法 | 15% | 同向累计调节+先/后适用分步+法定最低刑约束 | 有情节调节 | 逐项连乘或未区分先/后适用 |
| 条文性质标注 | 10% | "应当"/"可以"标注全部正确+第63条分款标注 | 主要标注正确 | 标注错误（如第63条整条标为授权性） |
| 情节对应法条 | 10% | 每个情节有法条依据+适用顺序标注 | 主要情节有依据 | 情节无法条支撑 |
| 隐性知识覆盖 | 10% | 覆盖自首双要件/退赔梯度/认罪认罚叠加/竞合规则/偏差容忍度中的≥4项 | 覆盖≥2项 | 仅泛泛而谈无实务深度 |
| 缓刑评估完整性 | 10% | 5项逐项+禁止情形+隐性门槛+社区矫正前置+罚金影响 | 5项逐项 | 缺少关键条件分析 |
| 禁止承诺/隐性承诺 | 15% | 无概率百分比+无伪精确+刑期取整到月+区间描述 | 无显性承诺 | 有概率百分比或伪精确小数 |
| 地区差异标注 | 5% | 已标注地区差异+隐性门槛+提示核实 | 已提及地区差异 | 未考虑地区差异 |
| 从轻/减轻区分 | 5% | 区分清晰+计算正确+低于法定最低刑时标注 | 基本区分 | 混淆从轻与减轻 |
| 辩护策略可操作性 | 5% | 5-8项具体策略（含认罪认罚时机/社区矫正/协商底线） | 3项以上策略 | 仅笼统3行 |

## 2. 检查清单

| 检查项 | 级别 | 说明 |
|--------|------|------|
| 条文性质标注 | 阻断 | "应当"（命令性）≠"可以"（授权性），不得混淆；第63条第1款为命令性 |
| 量刑计算透明 | 阻断 | 须展示计算过程，同向累计调节（非逐项连乘） |
| 情节对应法条 | 阻断 | 每个从轻/减轻情节须有法条依据 |
| 地区差异提示 | 阻断 | 须提示地区差异+建议核实当地规定 |
| 从轻≠减轻 | 阻断 | 从轻在法定刑内，减轻可低于法定刑；从轻累计低于法定最低刑时须标注 |
| 禁止承诺结果 | 阻断 | 量刑预测不等于确定结果 |
| **禁止概率百分比** | **阻断** | 不得出现"60%可能判XX"等概率表述 |
| **禁止逐项连乘** | **阻断** | 情节调节不得逐项连乘，必须同向累计 |
| **禁止伪精确** | **阻断** | 刑期取整到月，不得出现"7.86个月"等小数 |
| 情节调节先/后适用 | 阻断 | 须区分先适用（从犯/未遂/中止）与后适用（自首/坦白等）情节 |
| 法定最低刑约束 | 阻断 | 从轻累计调节后低于法定最低刑时必须标注 |
| 第68条历史变更 | 阻断 | 不得引用已删除的原第68条第2款"应当减轻" |
