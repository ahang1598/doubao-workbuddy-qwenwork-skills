# 边缘示例001：跨地区数额标准差异

> criminal-sentencing-analysis | 边缘示例 | v1.2.0

## 输入

```markdown
被告人李四，在A省盗窃3万元后逃到B省又盗窃2万元。
A省盗窃"数额较大"标准为2000元，"数额巨大"标准为3万元；
B省盗窃"数额较大"标准为3000元，"数额巨大"标准为5万元。
请分析量刑。
```

## 边界问题

跨地区犯罪面临数额标准适用困境：（1）两省盗窃罪量刑数额标准不同；（2）盗窃行为发生在不同省份，应适用哪个省的标准；（3）盗窃数额是分别计算还是累计计算。最高人民法院、最高人民检察院《关于办理盗窃刑事案件适用法律若干问题的解释》第1条授权各省确定本地区具体数额标准，但跨地区犯罪的法律适用存在争议。此案例触及量刑分析技能的地域适用边界。

## 预期输出特征

- 识别跨地区数额标准冲突问题
- 列出两省标准差异对照表
- 说明不同学术观点和实务做法
- 不做确定性的法律适用结论，标注"需律师结合当地司法实践判断"
- 累计盗窃数额的计算方式应注明争议

## 预期输出摘要

```markdown
# 量刑分析报告

## 一、基本事实

| 项目 | 内容 |
|------|------|
| 被告人 | 李四 |
| 涉嫌罪名 | 盗窃罪 |
| A省盗窃 | 3万元 |
| B省盗窃 | 2万元 |
| 累计数额 | 5万元 |

## 二、数额标准适用分析

### 两省标准对照

| 量刑档次 | A省标准 | B省标准 | 差异 |
|----------|---------|---------|------|
| 数额较大 | 2,000元 | 3,000元 | A省门槛更低 |
| 数额巨大 | 30,000元 | 50,000元 | A省入罪门槛更低 |
| 数额特别巨大 | 300,000元 | 500,000元 | A省入罪门槛更低 |

### 法律适用争议

> ⚠️ **跨地区数额标准适用存在争议，以下为不同观点：**

| 观点 | 适用规则 | 结果 |
|------|----------|------|
| 观点一：就高不就低 | 适用B省（标准更宽松） | A省3万属"数额巨大"，B省2万属"数额较大" |
| 观点二：分别适用 | 各地行为适用当地标准 | 分段计算后并罚 |
| 观点三：受理法院地标准 | 以审理法院所在地标准统一适用 | 取决于管辖法院 |

### 建议

1. 管辖法院确定后，以受理法院所在地标准为基准
2. 分别计算两段盗窃行为的量刑档次
3. 如累计计算为5万元，在A省属"数额巨大"（3年以上10年以下），在B省仍属"数额较大"（3年以下）
4. **需律师结合当地司法实践和具体管辖确定适用标准**

## 三、量刑预测

| 情形 | 量刑档次 | 法定刑 |
|------|----------|--------|
| A省单独计算 | 数额巨大 | 3-10年 |
| B省单独计算 | 数额较大 | 3年以下/拘役/管制 |
| 累计（按A省标准） | 数额巨大 | 3-10年 |
| 累计（按B省标准） | 数额较大 | 3年以下/拘役/管制 |

> **重要提示**：跨地区数额标准差异可能对量刑产生重大影响（3年以下 vs 3-10年），
> 建议辩护律师重点争取适用对被告人有利的标准。
```
