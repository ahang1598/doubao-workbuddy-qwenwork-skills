# 工作流详述

> 本文件定义 criminal-sentencing-analysis 技能的各Phase子步骤与检查点
> 遵循 compiler/ssot.md §17（SSOT）：按需拆分规则

## 1. 工作流概览

```
Phase 1: 输入验证 → Phase 2: 法定刑分析[L2] → Phase 3: 基准刑确定[L3]
    ↓
Phase 4: 情节调节[L3] → Phase 5: 缓刑评估[L2] → Phase 6: 辩护建议[L1]
    ↓
Phase 7: 质量检查[L1] → Phase 8: 输出交付
```

## 2. Phase 1: 输入验证

### 1.1 输入解析

| 步骤 | 操作 | 产出 |
|------|------|------|
| 1.1.1 | 解析自然语言输入 | 结构化字段字典 |
| 1.1.2 | 提取案件基本信息 | defendant_name, alleged_crime, case_facts |
| 1.1.3 | 识别从重情节 | aggravating_factors |
| 1.1.4 | 识别从轻/减轻情节 | mitigating_factors |
| 1.1.5 | 识别管辖地区 | jurisdiction |

### 1.2 输入校验

| 检查项 | 校验规则 | 失败行为 |

## 4. Phase 3: 基准刑确定 [L3风险]

> 风险标注：基准刑是量刑计算的起点，确定错误将导致全部结果偏移

### 3.1 基准刑计算

| 步骤 | 操作 | 依据 |
|------|------|------|
| 3.1.1 | 确定量刑起点 | 量刑指导意见 |
| 3.1.2 | 增加刑罚量 | 根据金额/情节增加 |
| 3.1.3 | 确定基准刑 | 量刑起点+增加刑罚量 |

### 3.2 常见罪名基准刑参考

| 罪名 | 量刑起点 | 增加刑罚量 |
|------|----------|-----------|
| 盗窃（1000-3000元起点） | 3-6个月 | 每2000元增加1-2个月 |
| 诈骗（3000元起点） | 3-6个月 | 每3000元增加1-2个月 |
| 故意伤害（轻伤二级） | 6-12个月 | 每增加轻伤一级增加3-6个月 |
| 交通肇事（致1人死亡） | 12-18个月 | 每增加1人增加6-12个月 |

> **注意**：以上为参考值，具体以量刑指导意见为准。

### 3.3 Phase 3 检查点

- [ ] 量刑起点已确定
- [ ] 增加刑罚量已计算
- [ ] 基准刑已确定

## 5. Phase 4: 情节调节 [L3风险]

> 风险标注：情节调节是量刑计算的核心环节，每个情节必须有法条依据
> v2.1.0 核心修正：逐项连乘→同向累计调节+先/后适用分步调节

### 4.1 情节分类：先适用 vs 后适用

**量刑指导意见明确区分两种情节的适用顺序**：

| 类型 | 情节 | 调节特点 |
|------|------|----------|
| **先适用情节** | 未成年人犯罪、从犯、未遂、中止 | 先行调节基准刑 |
| **后适用情节** | 自首、坦白、退赃退赔、立功、认罪认罚、取得谅解、初犯偶犯、累犯 | 在先适用情节调节结果上再调节 |

> 详见 [methodology.md §1.4](./methodology.md#14-先适用情节与后适用情节区分)

### 4.2 从重情节调节

**论证模板**：
```
[情节]：根据刑法第XX条，[情节描述]属于[法定/酌定]从重情节
[调节比例]：根据量刑指导意见，调节比例为+[X]%
[条文性质]：[命令性"应当"/授权性"可以"]
[适用顺序]：[先适用/后适用]
```

### 4.3 从轻/减轻情节调节

**论证模板**：
```
[情节]：根据刑法第XX条，[情节描述]属于[法定/酌定]从轻/减轻情节
[调节比例]：根据量刑指导意见，调节比例为-[X]%
[条文性质]：[命令性"应当"/授权性"可以"]
[适用顺序]：[先适用/后适用]
```

### 4.4 综合调节计算（同向累计调节法）

**正确计算公式**：

```
第1步：先适用情节调节
  从重先适用累计% = Σ(各先适用从重情节调节比例)
  从轻先适用累计% = Σ(各先适用从轻情节调节比例)
  先适用调节结果 = 基准刑 × (1 + 从重先适用累计% - 从轻先适用累计%)

第2步：后适用情节调节
  从重后适用累计% = Σ(各后适用从重情节调节比例)
  从轻后适用累计% = Σ(各后适用从轻情节调节比例)
  最终调节结果 = 先适用调节结果 × (1 + 从重后适用累计% - 从轻后适用累计%)

第3步：法定最低刑约束检查
  如果 最终调节结果 < 法定最低刑 且 无减轻处罚情节
  → 宣告刑 = 法定最低刑，并标注 ⚠️ "从轻累计调节后低于法定最低刑，以法定最低刑为限"
  如果 最终调节结果 < 法定最低刑 且 有减轻处罚情节
  → 宣告刑可在下一量刑幅度内，标注 "因存在[减轻情节]，可在法定最低刑以下判处"
```

**计算示例**：

```
案件：盗窃罪，基准刑19.5个月（法定刑3年以下），从犯（先适用），坦白+退赃+谅解（后适用）

第1步：先适用情节调节
  从犯：-30%（先适用从轻）
  先适用调节结果 = 19.5 × (1 - 30%) = 13.65个月

第2步：后适用情节调节
  坦白：-15%（后适用从轻）
  退赃：-25%（后适用从轻，全额退赔）
  谅解：-10%（后适用从轻）
  后适用从轻累计 = -(15%+25%+10%) = -50%
  最终调节结果 = 13.65 × (1 - 50%) = 6.825个月 ≈ 7个月

第3步：法定最低刑约束检查
  盗窃罪"数额较大"法定最低刑为管制/拘役，7个月有期徒刑未低于法定最低刑 → 无需调整
```

**禁止的计算方法**：

| 错误方法 | 为什么错 | 示例（4项各-20%从轻） |
|----------|---------|---------------------|
| 逐项连乘 | 基准刑被指数级压缩 | 19.5×0.8×0.8×0.8×0.8=7.99（压缩到41%） |
| 正确：同向累计 | 符合量刑指导意见 | 19.5×(1-80%)=3.9（累计调节后取法定最低刑约束） |

> 详见 [methodology.md §1.2](./methodology.md#12-情节调节正确计算方法同向累计调节)

### 4.5 Phase 4 检查点

- [ ] 每个情节有法条依据
- [ ] 每个调节比例有来源
- [ ] 条文性质（"可以"/"应当"）正确标注
- [ ] 先适用/后适用情节已分类
- [ ] 综合调节采用同向累计法（非逐项连乘）
- [ ] 法定最低刑约束已检查
- [ ] 从轻累计调节后低于法定最低刑时已标注

## 6. Phase 5: 缓刑评估 [L2风险]

> 风险标注：缓刑评估直接关系当事人人身自由，必须严谨
> v2.1.0 增强：社区矫正评估前置性+隐性不判缓刑情形+罚金刑影响

### 5.1 缓刑适用条件逐项分析（刑法第72条）

| 条件 | 分析要点 |
|------|----------|
| 被判处三年以下有期徒刑 | 预计刑期是否≤3年；注意数罪并罚后的总刑期是否仍≤3年 |
| 犯罪情节较轻 | 案件性质和情节评估 |
| 有悔罪表现 | 认罪认罚/退赃/赔偿/谅解；注意罚金刑缴纳能力可能影响"悔罪表现"认定 |
| 没有再犯罪的危险 | 初犯偶犯/有固定住所/稳定工作 |
| 对所居住社区无重大不良影响 | **须司法行政机关社区矫正评估意见**（准前置条件） |

### 5.2 禁止缓刑的情形

| 情形 | 法条 | 说明 |
|------|------|------|
| 累犯 | 刑法第74条 | 法定禁止，绝对不适用 |
| 判处三年以上有期徒刑 | 刑法第72条 | 法定禁止（但数罪并罚后≤3年有争议） |

### 5.3 隐性不判缓刑情形

> 以下情形法律未明文禁止缓刑，但实务中缓刑率极低或几乎不判缓刑

| 情形 | 说明 | 地区差异 |
|------|------|---------|
| 涉黑恶势力犯罪 | 即使个人角色较轻 | 全国普遍 |
| 性侵未成年人犯罪 | 司法政策从严 | 全国普遍 |
| 食品药品安全犯罪 | 涉公共安全 | 全国普遍 |
| 毒品再犯 | 刑法第356条从重 | 全国普遍 |
| 特定地区特定罪名 | 如北京盗窃罪缓刑率约15%，浙江约35% | 地区差异大 |
| 无固定住所/无稳定收入 | 社区矫正评估难通过 | 全国普遍 |
| 未赔偿/未获谅解 | "悔罪表现"难以成立 | 全国普遍 |

### 5.4 社区矫正评估前置性

- 刑法第72条第4项"对所居住社区没有重大不良影响"在实务中需要司法行政机关出具**社区矫正评估意见**
- favorable 的评估意见是缓刑适用的**准前置条件**
- 评估内容：居所情况、家庭关系、社区态度、再犯风险
- **辩护提示**：如缓刑可能性较高，应建议当事人提前申请社区矫正评估

### 5.5 Phase 5 检查点

- [ ] 缓刑5项逐项分析（1前提+4实质条件）
- [ ] 禁止缓刑情形已排除（含累犯和三年以上）
- [ ] 隐性不判缓刑情形已提示
- [ ] 社区矫正评估前置性已说明
- [ ] 缓刑可能性评估合理（使用区间描述，禁止概率百分比）

## 7. Phase 6: 辩护建议 [L1风险]

### 6.1 量刑辩护策略

| 辩护层次 | 策略 | 适用条件 |
|----------|------|----------|
| 事实之辩 | 质疑量刑事实基础 | 事实有争议 |
| 定罪之辩 | 变更为较轻罪名 | 定性有争议 |
| 量刑之辩 | 争取最轻刑罚 | 事实无争议 |

### 6.2 量刑辩护具体策略（5-8项）

> v2.1.0 新增：从笼统3行扩展为具体可操作的辩护策略

**从轻情节争取策略**：

| 策略 | 适用条件 | 具体做法 |
|------|----------|---------|
| 自首认定争取 | 存在非典型投案情形 | 对照7种非典型投案情形逐一核查，补强投案主动性证据（如亲友规劝证言、电话通知到案记录） |
| 从犯地位论证 | 共同犯罪中作用较小 | 具体说明从犯在共同犯罪中的地位和作用，论证其参与程度和获利情况 |
| 退赔计划制定 | 尚未退赔或部分退赔 | 制定分期退赔计划，争取在审查起诉阶段完成退赔以获更大折减 |

**从重情节否认策略**：

| 策略 | 适用条件 | 具体做法 |
|------|----------|---------|
| 累犯构成要件核查 | 被指控为累犯 | 核查前罪刑满释放日期是否在5年内、前后罪是否均为故意犯罪 |
| 情节严重程度质疑 | 被指控情节严重 | 核查"情节严重"的认定标准是否满足，是否有证据支撑 |

**程序性策略**：

| 策略 | 适用条件 | 具体做法 |
|------|----------|---------|
| 社区影响评估申请 | 缓刑可能性较高 | 建议当事人提前申请司法行政机关社区矫正评估 |
| 认罪认罚时机选择 | 事实无争议 | 建议在侦查阶段签署认罪认罚具结书以获最大从宽（-20%~-30%） |
| 量刑建议协商 | 审查起诉阶段 | 基于量刑预测结果，确定协商底线（建议在预测区间中位值以下10%作为协商起点） |
| 羁押折抵提示 | 判决前已羁押时间较长 | 核查羁押期限，评估是否影响缓刑适用；如羁押时间接近预计刑期，建议争取变更强制措施 |
