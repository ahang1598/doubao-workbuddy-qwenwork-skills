# 输入规格

> 本文件定义 criminal-sentencing-analysis 技能的完整输入参数规格
> 遵循 compiler/ssot.md §17（SSOT）：输入宽容度契约

## 1. 必需输入

### 1.1 案件基本信息

| 字段 | 类型 | 说明 | 验证规则 |
|------|------|------|----------|
| `defendant_name` | string | 被告人姓名 | 非空 |
| `alleged_crime` | string | 涉嫌罪名 | 非空 |
| `case_facts` | string | 案件事实描述 | 非空 |

## 2. 可选输入

### 2.1 量刑情节

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `aggravating_factors` | array[string] | [] | 从重情节清单 |
| `mitigating_factors` | array[string] | [] | 从轻/减轻情节清单 |

**常见从重情节**：
| 情节 | 法条依据 | 调节比例参考 |
|------|----------|-------------|
| 累犯 | 刑法第65条 | +10%~+30% |
| 前科劣迹 | 刑法第61条 | +10%以下 |
| 手段残忍 | 量刑指导意见 | +10%~+20% |
| 拒不认罪 | 量刑指导意见 | +10%以下 |

**常见从轻/减轻情节**：
| 情节 | 法条依据 | 调节比例参考 | 适用顺序 |
|------|----------|-------------|---------|
| 从犯 | 刑法第27条 | -20%~-50% | **先适用** |
| 未遂 | 刑法第23条 | -30%~-50% | **先适用** |
| 中止 | 刑法第24条 | -50%~-100% | **先适用** |
| 未成年人犯罪 | 刑法第17条 | -30%~-60% | **先适用** |
| 自首 | 刑法第67条 | -40%以下 | 后适用 |
| 坦白 | 刑法第67条第3款 | -20%以下 | 后适用 |
| 立功 | 刑法第68条 | -20%~-50% | 后适用 |
| 退赃退赔 | 量刑指导意见 | -30%以下 | 后适用 |
| 取得谅解 | 量刑指导意见 | -20%以下 | 后适用 |
| 认罪认罚 | 刑诉法第15条 | -10%~-30% | 后适用 |
| 初犯偶犯 | 量刑指导意见 | -10%以下 | 后适用 |

### 2.2 案件补充信息

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `jurisdiction` | string | 全国统一标准 | 管辖地区（省+市） |
| `amount_involved` | number | [待补充] | 涉案金额（元） |
| `victim_count` | number | 1 | 被害人数量 |
| `injury_level` | enum | 无 | 伤害等级（轻微伤/轻伤一级/轻伤二级/重伤一级/重伤二级） |
| `crime_count` | enum | 一罪 | 罪数（一罪/数罪） |
| `detention_date` | string | [待补充] | 羁押起始日期（格式YYYY-MM-DD），直接影响刑期折抵和缓刑可行性 |
| `prior_conviction` | boolean | false | 是否有前科 |
| `prior_conviction_detail` | string | [待补充] | 前科详情（罪名/刑期/释放日期），直接影响累犯认定 |
| `is_recidivist` | boolean | false | 是否累犯 |
| `has_confession` | boolean | false | 是否供述 |
| `has_repentance` | boolean | false | 是否认罪认罚 |
| `repentance_stage` | enum | [待补充] | 认罪认罚阶段（侦查/审查起诉/审判），影响从宽幅度 |
| `victim_attitude` | string | [待补充] | 被害人态度（谅解/部分谅解/不谅解/无法联系） |
| `restitution_status` | enum | [待补充] | 退赔状态（全额/大部分/部分/未退赔） |
| `accomplice_info` | string | [待补充] | 同案犯情况（有/无/同案犯量刑情况），影响从犯认定和量刑平衡 |

## 3. 输入宽容度契约

### 3.1 最小输入识别

| 最小输入 | 触发条件 | 行为 |
|----------|----------|------|
| 仅被告人+罪名 | 无案件事实 | 交互询问案件事实（最多3轮） |
| 仅"量刑"关键词 | 无任何信息 | 询问案件基本信息 |
| 自然语言描述 | 非结构化输入 | 提取关键信息生成量刑分析 |

### 3.2 信息补全策略

1. **从描述中提取**：自然语言处理提取罪名、金额、情节
2. **推理补全**：根据罪名推断法定刑幅度
3. **占位符标注**：无法提取的信息用 `[待补充]` 标注

### 3.3 交互补全限制

交互补全最多3轮，超过后强制进入 SOFT_DEGRADED 模式。

## 4. 场景适配规则

### 4.1 阶段适配

| 阶段 | 量刑分析侧重点 |
|------|----------------|
| 审查起诉 | 量刑预期评估+认罪认罚决策参考 |
| 一审 | 量刑辩护策略+缓刑申请准备 |
| 二审 | 一审量刑过重分析+改判可能性评估 |

### 4.2 罪名适配

| 罪名类别 | 量刑计算特点 |
|----------|-------------|
| 侵犯财产罪 | 以金额为基准确定刑期档次 |
| 侵犯人身罪 | 以伤害等级为基准确定刑期档次 |
| 职务犯罪 | 以金额+主体身份确定刑期档次 |
| 毒品犯罪 | 以数量为基准确定刑期档次 |
