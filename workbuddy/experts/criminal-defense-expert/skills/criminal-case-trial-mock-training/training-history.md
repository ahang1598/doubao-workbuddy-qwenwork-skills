# 训练历史追踪与能力成长

## 概述

本规范定义训练历史的记录格式、能力成长曲线的生成算法、以及基于训练历史的下次训练推荐逻辑。

---

## 1. 训练历史记录格式

### 记录时机
- 每次完成 P5 复盘后，**自动追加**一条记录
- 用户主动调用"基于上次训练继续"时读取历史

### 记录字段

```yaml
- record_id: "{时间戳}-{序号}"
  date: 2026-06-10
  case_id: "{罪名}_{时间戳}"
  case_name: "张某故意伤害案"
  config:
    procedure_type: "普通程序"
    user_role: "辩护人"
    training_goal: "全流程"
    case_category: "暴力"
    difficulty_level: "中等"
    training_mode: "完整模拟"
  scores:
    procedural_compliance: 4
    argument_persuasiveness: 3
    strategy_selection: 4
    questioning_quality: 3
    objection_accuracy: 2
    tactical_flexibility: 3
  total_score: 19  # 6维度之和（满分30）
  average_score: 3.17
  weakest_dimension: "异议准确度"
  strongest_dimension: "程序规范性"
  key_feedback:
    - "异议类型识别不准确"
    - "程序衔接熟练"
  recommended_next: "异议专项"
  completed_phases: ["P0", "P0.5", "P1", "P2", "IG-C", "P3", "P4", "P5"]
  rounds_count: 35
```

### 存储位置
- **会话内**：在 AI 的工作记忆中维护（最近10条）
- **跨会话**：用户提供历史记录时，AI读取并继续
- **持久化存储**：可选（v3.0.0暂未提供持久化存储能力）

## 2. 能力成长曲线

### 曲线类型

#### 2.1 6维度独立曲线

每个维度一条曲线：
- 横轴：训练次数（按时间顺序）
- 纵轴：维度评分（1-5）
- 折线图或文字描述

#### 2.2 综合能力曲线

总评分曲线：
- 横轴：训练次数
- 纵轴：6维度总分（6-30）
- 折线图或文字描述

#### 2.3 罪名类型能力曲线

按罪名类型分组：
- 暴力犯罪总能力
- 财产犯罪总能力
- 等

### 趋势分析

#### 上升趋势
- 连续3次训练在某个维度评分上升
- 提示：该维度在进步

#### 下降趋势
- 连续3次训练在某个维度评分下降
- 提示：该维度需要加强

#### 平台期
- 连续5次训练评分在同一区间（±0.5分）
- 提示：需要专项训练突破

#### 异常波动
- 单次训练评分与历史均值差距>1.5分
- 提示：可能训练难度不当或发挥失常

## 3. 基于训练历史的下次训练推荐

### 推荐算法

#### 步骤1：识别最弱维度
- 取最近3次训练的平均分
- 找到平均分最低的维度
- 如有并列最低，取最近一次训练中最低的

#### 步骤2：识别最常用程序类型
- 统计最近5次训练的程序类型分布
- 推荐训练用户较少使用的程序类型（拓展能力）

#### 步骤3：识别最常用角色
- 统计最近5次训练的角色分布
- 推荐训练用户较少使用的角色（换位思考）

#### 步骤4：组合推荐
```
推荐训练配置：
- 程序类型：{用户较少使用的程序}
- 角色：{用户较少使用的角色}
- 训练目标：{针对最弱维度的专项训练}
- 罪名类型：{最近3次未训练的罪名类型}
- 强度：{根据最近表现调整}
```

### 推荐示例

#### 示例1：基于最弱维度推荐
- 用户历史：质证3分、辩论4分、异议2分
- 最弱维度：异议准确度（2分）
- 推荐：异议专项 + 激烈强度

#### 示例2：基于程序拓展推荐
- 用户历史：4次普通程序 + 1次二审
- 推荐：简易程序或认罪认罚程序（拓展程序经验）

#### 示例3：基于角色拓展推荐
- 用户历史：5次辩护人
- 推荐：公诉人或审判员（换位思考）

## 5. 训练历史的使用边界

### AI能做
- 维护会话内的训练历史（最近10条）
- 生成能力曲线（文字描述）
- 推荐下次训练配置
- 展示历史记录

### AI不能做
- 持久化存储训练历史（v3.0.0能力限制）
- 跨会话自动读取历史（需要用户提供）
- 自动应用推荐（需要用户确认）
- 评估历史训练的客观真实性

### 用户可提供历史
如用户有真实训练记录（来自其他工具或自己记录），可以粘贴给AI，AI会基于此继续分析。

---

## 6. 数据脱敏与隐私

### 脱敏要求
- 训练历史中不直接记录真实案件信息
- 案例ID使用罪名+时间戳的伪标识
- 不记录被告人/当事人/律师的真实姓名

### 用户控制
- 用户可随时要求清除训练历史
- 用户可选择性提供历史数据

## 7. 训练历史在P6的应用

### "基于上次训练继续"指令的处理

```
IF 用户说"基于上次训练继续":
    1. 读取最近一次训练记录
    2. 展示上次配置和评分
    3. 展示推荐配置
    4. 询问用户：
       - 选项1：使用推荐配置开始
       - 选项2：基于上次案件延续（同案换角色）
       - 选项3：自定义新配置
```

### "切换立场"指令的处理

```
IF 用户说"切换立场":
    1. 读取当前案件信息
    2. 展示前次训练要点速览（O5）
    3. 询问用户选择新角色
    4. 重新分配AI角色
    5. 继续训练
```

### "复盘"指令的处理

```
IF 用户说"复盘":
    1. 跳转到P5
    2. 进行6维度评估
    3. 生成复盘报告
    4. 追加到训练历史
```
