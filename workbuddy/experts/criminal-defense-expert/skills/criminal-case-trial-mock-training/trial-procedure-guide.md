# 庭审程序指引

## 概述

本指引覆盖6种程序类型的庭审流程差异。所有程序均受无罪推定、程序合法、证据裁判三大原则约束。

---

## 一、普通程序（一审普通程序）

### 阶段1：开庭

**程序要点**：
1. 书记员宣布法庭纪律
2. 审判长宣布开庭
3. 核对被告人身份
4. 宣布案由和合议庭组成
5. 告知当事人权利（申请回避权、辩护权、最后陈述权）
6. 询问是否申请回避

**关键法条**：《刑事诉讼法》第190条

**角色分工**：

| 环节 | 主导角色 | 其他角色 |
|------|---------|---------|
| 宣布开庭 | 审判员 | — |
| 核对身份 | 审判员 | 被告人回答 |
| 告知权利 | 审判员 | — |
| 申请回避 | 审判员询问 | 当事人/辩护人可申请 |

### 阶段2：法庭调查

#### 2.1 公诉人宣读起诉书
- 公诉人宣读起诉书全文
- 被告人就起诉书指控事实陈述意见

#### 2.2 讯问/发问被告人
- **公诉人讯问**：围绕指控事实，逐项核实
  - 禁止诱导性提问
  - 禁止威胁引诱
- **辩护人发问**（经审判长许可）：围绕有利于被告人的事实
  - 优先使用开放式问题
  - 避免暗示性提问
- **被害人代理人发问**（经审判长许可）：围绕被害人权益相关事实
- **审判员补充讯问**：澄清关键事实

**关键法条**：《刑事诉讼法》第191条

#### 2.3 举证质证
- **举证方**：说明证据名称、来源、证明目的
- **质证方**：围绕真实性、合法性、关联性质证
- **举证顺序**（一般规则）：
  1. 物证、书证
  2. 证人证言
  3. 被害人陈述
  4. 被告人供述和辩解
  5. 鉴定意见
  6. 视听资料、电子数据
- **质证要点**：
  - 真实性：证据是否客观真实
  - 合法性：收集程序是否合法
  - 关联性：与待证事实是否有关联

**关键法条**：《刑事诉讼法》第50-60条

#### 2.4 证人出庭（如适用）
- 公诉人/辩护人申请证人出庭
- 审判长决定是否准许
- 证人作证后接受各方询问

**关键法条**：《刑事诉讼法》第192条

#### 2.5 鉴定人出庭（如适用）
- 公诉人/辩护人申请鉴定人出庭
- 鉴定人作证后接受各方询问
- 重点：鉴定资质、鉴定方法、检材来源

**关键法条**：《刑事诉讼法》第192条（鉴定人出庭）

#### 2.6 法庭调查结束
- 审判长询问是否需要补充证据
- 双方确认无新证据后宣布调查结束

### 阶段3：法庭辩论与最后陈述

> 注意：根据《刑事诉讼法》第198条，法庭辩论与最后陈述在同一法条中规定

#### 3.1 公诉人发表公诉意见
- 概括指控事实
- 引用法律依据
- 提出量刑建议

#### 3.2 辩护人发表辩护意见
- 归纳质证意见
- 提出辩护观点（无罪/罪轻/从宽）
- 引用法律依据

#### 3.3 互相辩论
- 公诉人反驳辩护观点
- 辩护人回应反驳
- 可进行2-3轮
- 对与定罪量刑有关的事实证据都应当进行调查、辩论

**关键法条**：《刑事诉讼法》第198条

**辩论规则**：
- 围绕定罪和量刑问题
- 不得进行人身攻击
- 新观点须在辩论中提出
- 经审判长许可方可发言

#### 3.4 被告人最后陈述
- 审判长宣布辩论终结后，告知被告人最后陈述权
- 被告人自由陈述
- 任何人不得打断
- 如被告人拒绝陈述，记录在案

**关键法条**：《刑事诉讼法》第198条

### 阶段4：休庭与宣判
- 宣布休庭，合议庭评议
- 告知宣判时间（择期/当庭）
- 根据已查明的事实、证据和法律规定作出判决

**关键法条**：《刑事诉讼法》第200条

## 二、简易程序

### 适用条件（《刑诉法》第214条）
- 案件事实清楚、证据充分
- 被告人承认所犯罪行
- 对所指控的犯罪事实没有异议
- **可能判处3年以下有期徒刑**的案件（可适用）

### 流程差异（vs 普通程序）
1. **简化环节**：
   - 简化举证质证（对无异议的证据可简化出示）
   - 公诉人讯问可简化
   - 辩护人发问可简化
2. **审判组织**：
   - 审判员**独任审判**（而非合议庭）
3. **期限**：
   - 一般应当在受理后**20日内审结**
   - 可能判处超过3年有期徒刑的，应转为普通程序

### 关键法条
- 《刑诉法》第214条（适用条件）
- 《刑诉法》第215条（审判组织简化）
- 《刑诉法》第216条（审理期限）
- 《刑诉法》第217条（程序简化）

### AI模拟要点
- 审判员独立主持
- 简化但不省略权利告知
- 被告人认罪的情况下，举证质证可简化为宣读证据名称+证明目的
- **不允许出现**：被告人翻供（如出现，应转为普通程序）

---

## 三、速裁程序

### 适用条件（《刑诉法》第223条）
- 基层法院管辖
- 可能判处**1年以下有期徒刑**
- 案件事实清楚，证据充分
- 被告人认罪认罚
- 征得被告人同意

### 流程差异（vs 简易程序）
1. **进一步简化**：
   - 法庭调查与法庭辩论**可合并**
   - 简化举证质证
2. **审理期限**：
   - 应当在受理后**10日以内**审结
3. **文书简化**：
   - 判决书可简化

### 关键法条
- 《刑诉法》第223条（适用条件）
- 《刑诉法》第224条（程序简化）
- 《刑诉法》第225条（审理期限）

### AI模拟要点
- 极致简化但权利告知不可省略
- 重点审查被告人认罪认罚的自愿性
- 法庭调查与辩论可合并为"综合调查辩论"
- **不允许出现**：被告人不同意适用速裁（如出现，应转为简易或普通程序）

## 四、认罪认罚从宽程序

### 适用条件
- 被告人**自愿认罪**（承认指控的犯罪事实）
- 被告人**认罚**（同意量刑建议/检察机关量刑建议）
- 适用**所有程序**（普通/简易/速裁均可）

### 流程差异
1. **审查自愿性**：
   - 审判员须审查认罪认罚的**自愿性**
   - 审查认罪认罚的**真实性**
   - 审查认罪认罚的**合法性**
2. **量刑协议**：
   - 公诉人提出量刑建议
   - 被告人同意量刑建议
   - 辩护人在场见证
3. **权利告知**：
   - 告知被告人有权**获得法律帮助**
   - 告知被告人有权**撤回认罪认罚**
   - 告知被告人认罪认罚的**法律后果**
4. **文书**：
   - 判决书中应当体现认罪认罚情况

### 关键法条
- 《刑诉法》第15条（认罪认罚从宽原则）
- 《刑诉法》第174-176条（人民检察院在认罪认罚中的职责）
- 《刑诉法》第190条第2款（审判员审查认罪认罚自愿性）
- 《刑诉法》第201条（认罪认罚案件的量刑建议）

### AI模拟要点
- 重点是审查自愿性，不省略权利告知
- 公诉人提出明确量刑建议
- 辩护人应审查量刑协议合法性
- 被告人明确表达认罪认罚意愿
- **关键差异**：虽然简化了部分流程，但权利告知环节必须**比普通程序更详细**
- **不允许出现**：认罪非自愿 / 量刑协议违法 / 律师未参与

## 五、二审程序

### 适用条件
- 不服一审**未生效**判决/裁定的当事人/检察院
- 上诉期内提出上诉（一审判决后**10日内**，一审裁定后**5日内**）

### 流程差异（vs 一审普通程序）
1. **审查重点**：
   - 一审**事实认定**是否清楚
   - 一审**证据**是否充分
   - 一审**法律适用**是否正确
   - 一审**量刑**是否适当
2. **审理方式**：
   - 应当组成**合议庭**审理
   - 二审可以**不开庭审理**（《刑诉法》第234条，特定情形下）
3. **审理范围**：
   - **全面审查**原则（《刑诉法》第233条），不受上诉/抗诉范围的限制
4. **审理结果**：
   - 维持原判
   - 改判
   - 发回重审
   - 撤销原判
5. **审理期限**：
   - 一般**2个月内**审结
   - 重大复杂案件可延长2个月（最高法批准）

### 关键法条
- 《刑诉法》第228-237条（二审程序）
- 《刑诉法》第234条（二审审理方式）
- 《刑诉法》第236条（二审处理结果）

### AI模拟要点
- 重点是审查一审判决，不重复一审全部内容
- 辩护人（上诉人）重点攻击一审的证据/法律适用/量刑
- 公诉人（被上诉人）重点维护一审判决
- 审理范围全面审查（不受上诉范围限制）
- **不允许出现**：超范围改判（超出上诉请求范围）/程序违法（如未组成合议庭）

## 六、再审程序

### 适用条件（《刑诉法》第253条）
- 有新的证据证明原判决、裁定认定的事实确有错误
- 据以定罪量刑的证据不确实、不充分或证明案件事实的主要证据之间存在矛盾
- 原判决、裁定适用法律确有错误
- 审判人员在审理该案件时有贪污受贿、徇私舞弊、枉法裁判行为

### 启动主体
- 当事人/法定代理人/近亲属（向法院/检察院申诉）
- 检察院（抗诉）
- 法院（主动再审——仅限本院/上级法院）

### 流程差异
1. **审查重点**：
   - 新证据
   - 原审程序违法
   - 原审法律适用错误
2. **审理方式**：
   - 应当组成**合议庭**审理
   - 重大/疑难案件可邀请陪审员
3. **审理结果**：
   - 维持原判（再审理由不成立）
   - 改判
   - 撤销原判
4. **审理期限**：
   - 应当在**3个月内**审结
   - 需延长的不得超过6个月

### 关键法条
- 《刑诉法》第253-256条（再审启动条件）
- 《刑诉法》第257-260条（再审审理程序）

### AI模拟要点
- 重点是审查再审理由（新证据/程序违法/法律适用错误）
- 由再审申请人启动，AI应明确再审申请人角色
- 同样受无罪推定、证据裁判原则约束
- **不允许出现**：超出再审范围审理 / 程序违法
- **v3.0.0范围限定**：暂不支持死刑复核程序

## 程序违规常见情形

| 违规情形 | 应对角色 | 处理方式 |
|---------|---------|---------|
| 质证环节发表辩护意见 | 审判员 | 提醒"请围绕证据发表质证意见" |
| 法庭调查阶段辩论事实 | 审判员 | 提醒"请在辩论阶段发表" |
| 未经许可发言 | 审判员 | 提醒"请经法庭许可" |
| 诱导性提问 | 对方/审判员 | 异议→裁定 |
| 举证未说明证明目的 | 审判员 | 要求补充说明 |
| 质证未针对证据三性 | 审判员 | 引导聚焦 |
| 被告人自行举证 | 审判员 | 提醒"被告人不需要举证，由控方承担举证责任" |
| 辩护人越权控制程序 | 审判员 | 提醒"程序由审判员控制" |
| 被害人代理人越位指控 | 审判员 | 提醒"指控权属于公诉人" |

## 6种程序类型对照表

| 程序类型 | 适用条件 | 审判组织 | 简化程度 | 审理期限 |
|---------|---------|---------|---------|---------|
| 普通程序 | 全部 | 合议庭 | 无简化 | 2个月（可延长） |
| 简易程序 | 事实清楚+证据充分+被告人认罪+可能判3年以下 | 独任审判员 | 简化举证质证 | 20日 |
| 速裁程序 | 基层法院+可能判1年以下+被告人认罪认罚+同意 | 独任审判员 | 进一步简化 | 10日 |
| 认罪认罚从宽 | 全部程序均可适用 | 视具体程序 | 视具体程序 | 视具体程序 |
| 二审程序 | 不服一审上诉 | 合议庭 | 重点审查一审 | 2个月（可延长） |
| 再审程序 | 法定再审条件 | 合议庭 | 重点审查再审理由 | 3个月（可延长） |
