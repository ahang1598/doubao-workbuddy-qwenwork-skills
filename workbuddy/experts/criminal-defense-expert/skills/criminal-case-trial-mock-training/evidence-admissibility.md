# 证据可采性判断规则

## 证据种类（刑诉法第50条）

| 种类 | 说明 | 质证要点 |
|------|------|---------|
| 物证 | 以其外在特征证明案件事实的物品 | 真实性（是否原件/原物）、关联性、收集合法性 |
| 书证 | 以其内容证明案件事实的书面材料 | 真实性（是否原件）、形成时间、收集合法性 |
| 证人证言 | 证人对案件事实的陈述 | 证人与当事人关系、证言前后一致性、感知能力 |
| 被害人陈述 | 被害人对案件事实的陈述 | 与其他证据印证、情绪影响客观性 |
| 被告人供述和辩解 | 被告人的供述和辩解 | 是否自愿、是否与客观证据一致 |
| 鉴定意见 | 鉴定人出具的专业意见 | 鉴定资质、鉴定方法、检材来源 |
| 视听资料 | 录音录像等 | 是否经过剪辑、制作时间、原始载体 |
| 电子数据 | 数字化信息 | 存储介质、提取过程、完整性校验 |

## 非法证据排除规则

### 排除范围

| 证据类型 | 排除条件 | 法条依据 |
|---------|---------|---------|
| 被告人供述 | 刑讯逼供等非法方法收集 | 第54条第1款 |
| 证人证言 | 暴力、威胁等非法方法收集 | 第54条第1款 |
| 被害人陈述 | 暴力、威胁等非法方法收集 | 第54条第1款 |
| 物证/书证 | 收集程序严重违法，可能影响公正审判 | 第54条第2款 |

### 不自动排除
- 收集程序有瑕疵但能补正或合理解释的物证、书证
- 仅有程序瑕疵不影响真实性的证据

### 排除程序
1. **申请**：辩护人提出排除申请 + 提供线索或证据
2. **证明责任**：公诉人证明证据收集的合法性
3. **审查方式**：
   - 听取出示证据方的说明
   - 查看讯问录音录像
   - 通知侦查人员出庭说明
4. **裁定**：审判员裁定是否排除

**法条依据**：《刑事诉讼法》第56-58条

### 庭前会议中的非法证据排除
- 在开庭前，审判人员可以**召开庭前会议**
- 庭前会议中可以就非法证据排除问题了解情况、听取意见
- 是否在庭前会议中作出处理决定，由审判人员决定

**法条依据**：《刑诉法》第187条第2款

## 质证三性审查

### 真实性审查

| 审查要点 | 适用证据类型 |
|---------|------------|
| 是否为原件/原物 | 物证、书证 |
| 内容是否完整 | 书证、视听资料、电子数据 |
| 是否经过篡改 | 视听资料、电子数据 |
| 证言是否前后一致 | 证人证言、被害人陈述 |
| 供述是否自愿 | 被告人供述 |

### 合法性审查

| 审查要点 | 适用证据类型 |
|---------|------------|
| 收集主体是否适格 | 全部 |
| 收集程序是否合法 | 全部 |
| 是否告知权利 | 被告人供述、证人证言 |
| 搜查扣押是否有合法手续 | 物证、书证 |
| 鉴定人是否有资质 | 鉴定意见 |
| 电子数据提取是否规范 | 电子数据 |

### 关联性审查

| 审查要点 | 说明 |
|---------|------|
| 与待证事实是否有联系 | 直接关联 vs 间接关联 |
| 证明力大小 | 核心证据 vs 补充证据 |
| 是否属于品格证据 | 品格证据原则上不可采（例外：与犯罪行为直接相关） |

## 证据认证标准

### 定罪证据标准
- 证据确实、充分（《刑诉法》第53条）
- 排除合理怀疑
- 证据之间相互印证

### 量刑证据标准
- 优势证据标准（较定罪标准略低）
- 从轻/减轻情节不要求达到排除合理怀疑

## 按程序类型区分的证据规则侧重

### 普通程序
- 完整证据规则适用
- 严格审查证据三性
- 充分举证质证

### 简易程序
- **简化但不全省略**证据规则
- 对控辩双方**无异议**的证据，可以简化出示
- 对**有异议**的证据，仍需严格质证
- 重点：审查被告人认罪的自愿性 + 证据基本充分性

### 速裁程序
- 进一步简化
- 重点审查**认罪认罚的自愿性**
- 证据审查更简略（因被告人认罪）

### 认罪认罚程序
- **重点审查**：
  - 认罪认罚的**自愿性**
  - 认罪认罚的**真实性**
  - 认罪认罚的**合法性**
  - 证据是否达到"事实清楚、证据充分"的程度
- **法律依据**：《刑诉法》第201条

### 二审程序
- 重点审查**一审证据规则适用**
- 重点审查**新证据**（一审未出现）
- 重点审查**原审程序违法**（如一审未告知权利）

### 再审程序
- 重点审查**新证据**
- 重点审查**原审程序违法**
- 重点审查**原审法律适用错误**
- 证据标准与一审一致

## 模拟中的证据裁定逻辑

```
IF 证据排除申请:
    IF 收集方法 = 刑讯逼供/暴力/威胁:
        → 裁定排除（确定性高）
    ELIF 收集程序有瑕疵 AND 不能补正:
        → 裁定排除（物证/书证）
    ELIF 收集程序有瑕疵 AND 可以补正:
        → 裁定不排除 + 标注瑕疵
    ELSE:
        → 要求公诉方说明合法性 → 再裁定

IF 质证异议:
    IF 证据真实性存疑:
        → 标注"真实性待定"，降低证明力评估
    IF 证据合法性存疑:
        → 启动排除审查程序
    IF 证据关联性存疑:
        → 审判员裁定是否可采

IF 程序类型 = 认罪认罚:
    → 重点审查认罪自愿性（被告人是否理解认罪后果）
    → 审查量刑协议合法性
    → 审查律师参与情况
```

## 6种程序类型下的证据规则速查

| 程序类型 | 审查重点 | 简化程度 | 关键法条 |
|---------|---------|---------|---------|
| 普通程序 | 完整三性+完整质证 | 无 | 第50-60条 |
| 简易程序 | 认罪自愿性+证据基本充分 | 中度简化 | 第214-217条 |
| 速裁程序 | 认罪认罚自愿性 | 高度简化 | 第223-225条 |
| 认罪认罚 | 认罪认罚自愿性+量刑协议 | 视具体程序 | 第15条+第190条第2款 |
| 二审 | 一审证据规则+新证据 | 重点审查 | 第228-237条 |
| 再审 | 新证据+原审违法 | 重点审查 | 第253-260条 |

## 证据分类的模拟处理建议

### 高频质证证据（应在模拟中重点训练）

| 罪名类型 | 高频质证证据 |
|---------|------------|
| 交通肇事 | 血液酒精含量鉴定、事故责任认定书、行车记录仪视频 |
| 故意伤害 | 伤情鉴定意见、医院诊断证明、凶器、监控视频 |
| 故意杀人 | 死亡鉴定意见、凶器、DNA鉴定、监控视频 |
| 抢劫/强奸 | 被害人陈述、DNA鉴定、监控视频、被告人供述 |
| 盗窃/诈骗 | 转账记录、合同、监控视频、电子数据 |
| 毒品 | 称量笔录、成分鉴定、特情证言、被告人供述 |
| 贪污/受贿 | 财务记录、银行流水、证人证言、被告人供述 |

### 常见证据瑕疵（应在模拟中考察辩护人识别能力）

| 瑕疵类型 | 表现 | 辩护策略 |
|---------|------|---------|
| 笔录瑕疵 | 签名缺失/时间矛盾/记录不完整 | 真实性异议 |
| 程序瑕疵 | 未告知权利/未出示证件/超期羁押 | 合法性异议 |
| 关联瑕疵 | 品格证据/传闻证据/不相关证据 | 关联性异议 |
| 形式瑕疵 | 复印件未核验/电子数据未封存 | 三性综合异议 |
