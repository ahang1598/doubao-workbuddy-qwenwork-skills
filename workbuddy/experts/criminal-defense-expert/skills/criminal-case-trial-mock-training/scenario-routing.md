# 场景路由规则（三层化路由）

## 路由决策优先级链

**程序类型 > 训练目标 > 罪名类型**

即：
1. 先确定程序框架（走哪个程序的工作流）
2. 再确定训练重点（走完整流程还是只练某个环节）
3. 最后加载罪名相关的策略差异

---

## 第一层：程序类型路由

| 程序类型 | 适用条件 | 工作流分支 |
|---------|---------|----------|
| 普通程序 | 全部 | 完整6 Phase（开庭→调查→辩论→陈述→休庭→复盘） |
| 简易程序 | 事实清楚+证据充分+被告人认罪+可能判3年以下 | 简化6 Phase（独任审判+简化举证质证） |
| 速裁程序 | 基层法院+可能判1年以下+被告人认罪认罚+同意 | 极致简化（调查+辩论可合并） |
| 认罪认罚从宽 | 全部程序均可适用 | 在选定程序上叠加认罪认罚审查环节 |
| 二审程序 | 不服一审上诉 | 二审6 Phase（重点审查一审） |
| 再审程序 | 法定再审条件 | 再审6 Phase（重点审查再审理由） |

---

## 第二层：训练目标路由

| 训练目标 | 重点Phase | 跳过Phase | 时长 |
|---------|---------|---------|------|
| 全流程 | P3+P4 | 无 | 30-50轮 |
| 质证专项 | P3（重点） | P4简化 | 20-30轮 |
| 辩论专项 | P4（重点） | P3简化 | 20-30轮 |
| 发问专项 | P3讯问/发问环节（重点） | 其他P3环节简化 | 15-25轮 |
| 异议专项 | P3+触发多异议 | 减少非异议环节 | 20-30轮 |
| 程序熟悉 | 全部Phase | 无，但简化深度 | 30-50轮 |
| 复盘 | 跳过P3+P4 | 仅P5（基于已有材料） | 5-10轮 |

## 庭审阶段侧重

### 证据质证侧重

| 罪名类型 | 质证重点证据类型 |
|---------|----------------|
| 交通安全 | 鉴定意见（血检/车检/死因）、视听资料（执法记录仪/道路监控）、事故认定书 |
| 暴力犯罪 | 鉴定意见（伤情）、物证（凶器）、目击证人证言 |
| 财产犯罪 | 书证（转账记录/合同）、电子数据、被害人陈述 |
| 网络犯罪 | 电子数据、银行流水、鉴定意见（软件鉴定）、被告人供述 |
| 毒品犯罪 | 物证（毒品）、称量笔录、特情证言 |
| 妨害司法 | 电子数据（微信/支付宝记录）、银行流水、物证（涉案物品）、证人证言 |
| 经济犯罪 | 书证（财务记录）、电子数据、证人证言 |

| 罪名类型 | 辩论核心争议 |
|---------|------------|
| 交通安全 | 证据合法性（鉴定程序）、责任认定、情节是否显著轻微 |
| 暴力犯罪 | 主观故意vs过失、正当防卫、被害人过错 |
| 财产犯罪 | 非法占有目的、数额认定、既遂未遂 |
| 网络犯罪 | 主观明知、情节严重认定、帮助行为/经营行为性质 |
| 毒品犯罪 | 主观明知、贩卖vs持有、特情引诱 |
| 妨害司法 | 主观明知、上游犯罪关联、情节严重认定 |

## 角色策略差异

### 辩护人策略矩阵

| 案件强度 | 策略选择 | 辩论方向 |
|---------|---------|---------|
| 证据充分 | 罪轻辩护/量刑辩护 | 从轻/减轻情节、认罪态度、退赃赔偿 |
| 证据有瑕疵 | 证据辩护 | 证据不足、非法证据排除、合理怀疑 |
| 证据严重不足 | 无罪辩护 | 证据链断裂、举证责任在控方、疑罪从无 |

### 公诉人策略矩阵

| 案件强度 | 策略选择 | 举证重心 |
|---------|---------|---------|
| 证据充分 | 完整举证+从重量刑建议 | 全部证据逐项出示、强调社会危害性 |
| 证据有瑕疵 | 重点举证+补强证据 | 核心证据详尽出示、瑕疵证据补强说明 |
| 证据临界 | 精准举证+量刑弹性 | 关键证据充分展示、对薄弱环节坦诚说明 |

### 审判员策略矩阵

| 案件类型 | 主持重点 |
|---------|---------|
| 事实争议大 | 引导举证质证深入、确保双方充分发表意见 |
| 法律适用争议 | 引导辩论聚焦法律问题、澄清争议焦点 |
| 认罪认罚 | 确保自愿性审查、简化程序但不省略权利告知 |

## 484全罪名通用路由（DEGRADED-L3）

> 当用户输入的罪名不在18个核心罪名范围内时，使用通用路由。

### 通用路由模板

#### Phase 1 通用争议焦点（适用于所有罪名）

1. **主体适格性**：被告人是否达到刑事责任年龄、是否具备刑事责任能力
2. **主观要件**：故意/过失、动机、目的
3. **客观要件**：行为、结果、因果关系
4. **客体要件**：所侵犯的法益
5. **量刑情节**：自首/立功/退赃/赔偿/谅解/前科

#### Phase 2 通用证据审查规则

- 真实性：证据是否为原件/原物
- 合法性：收集程序是否符合法定程序
- 关联性：与待证事实是否相关

#### Phase 3 通用辩护策略（按案件强度）

- 证据充分 → 罪轻辩护
- 证据有瑕疵 → 证据辩护
- 证据严重不足 → 无罪辩护

#### Phase 4 通用庭审节奏

- 开庭5轮 → 调查15-20轮 → 辩论5-10轮 → 陈述3-5轮 → 复盘5-10轮

## 三层化路由示例

### 示例1：用户输入"诈骗罪，被告人不认罪，二审程序，辩论专项，激烈强度"

**路由过程**：
1. **第一层（程序类型）**：二审程序 → 走二审6 Phase，重点审查一审
2. **第二层（训练目标）**：辩论专项 → 重点P4辩论环节，P3简化
3. **第三层（罪名类型）**：诈骗罪 → 加载诈骗罪的辩护人策略（真实交易抗辩/无非法占有目的/数额异议）

**组合结果**：二审程序下的诈骗罪辩论专项训练，重点训练用户对"非法占有目的"的辩论能力。

### 示例2：用户输入"危险驾驶罪，认罪认罚从宽，速裁程序"

**路由过程**：
1. **第一层（程序类型）**：速裁程序（叠加认罪认罚）→ 极致简化
2. **第二层（训练目标）**：默认全流程（用户未指定）
3. **第三层（罪名类型）**：危险驾驶罪 → 重点血液酒精含量鉴定

**组合结果**：危险驾驶罪的速裁程序+认罪认罚全流程训练，重点训练认罪认罚自愿性审查。
