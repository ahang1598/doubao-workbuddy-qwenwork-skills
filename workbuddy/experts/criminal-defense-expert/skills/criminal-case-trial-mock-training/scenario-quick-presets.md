# 快速训练预设情景库

## 概述

## 预设使用流程

1. 用户选择快速训练入口（IG-A选项1）
2. 展示预设列表
3. 用户选择预设编号
4. AI自动配置6维度参数
5. 展示配置确认（不要求用户重新配置）
6. 用户确认后进入P1

```
📋 预设已选择：P02 质证专项·暴力犯罪

自动配置：
- 程序类型：普通程序
- 角色：辩护人
- 训练目标：质证专项
- 罪名类型：暴力
- 强度：激烈
- 模式：完整模拟
- 示例案件：故意伤害罪（重伤）

请提供案件基本信息（如已有），或使用默认示例案件。
回复"开始"使用默认示例案件开始训练。
```

## 自定义预设

高级用户可基于上述预设微调：
- 保持训练目标和角色不变
- 仅修改罪名/程序/强度中的1-2项
- AI展示微调后的配置

---

## 预设的扩展性

随着技能发展，可扩展：
- 按罪名类型分组的预设（如"毒品犯罪预设"3-5个）
- 按角色分组的预设（如"审判员预设"3-5个）
- 按程序分组的预设（如"再审程序预设"2-3个）

v3.0.0 暂提供12个核心预设，v3.1.0+计划扩展。
