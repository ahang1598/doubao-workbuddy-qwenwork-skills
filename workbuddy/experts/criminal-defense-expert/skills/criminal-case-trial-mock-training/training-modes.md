# 训练目标方法论手册

## 概述

本文档定义7种训练目标的方法论、流程、时长和输出差异。每种训练目标对应不同的Phase跳过逻辑和重点强化环节。

---

## 1. 全流程模拟（full_process）

### 方法论
- 走完整6 Phase（开庭→调查→辩论→陈述→休庭→复盘）
- 完整呈现刑事庭审的全貌
- 适合系统训练

### 流程
```
P0（入口选择）→ P0.5（配置确认）→ P1（案件初始化）→ P2（场景构建）→ IG-C（争议焦点确认）
→ P3（法庭调查）→ P4（法庭辩论与最后陈述）→ P5（复盘）→ P6（立场切换/再训练）
```

### 时长
- 30-50轮对话
- 完整走完所有环节

### 输出差异
- 完整6维度复盘
- 训练历史自动记录
- 适合新手律师/系统训练

### Phase跳过
- 无跳过

---

## 2. 质证专项（cross_exam）

### 方法论
- 重点训练**对控方/辩方证据的质证能力**
- 围绕证据三性（真实性、合法性、关联性）展开
- 多次循环质证环节

### 流程
```
P0 → P0.5 → P1（简化）→ P2（简化，跳过非质证争议焦点）→ IG-C
→ P3（重点循环：举证→质证→异议→裁定，可多轮循环）
→ P5（重点评估质证能力）→ P6
```

### 时长
- 20-30轮对话
- 重点在P3的质证环节

### 输出差异
- 复盘6维度中**发问质量、异议准确度**权重提升
- **程序规范性、战术灵活性**权重相对降低
- 重点评语：质证角度是否穷尽、证据三性是否到位

### Phase跳过
- P4辩论环节大幅简化（仅保留简短总结）
- 跳过P3中的非质证环节（如法庭讯问、证人出庭等可简化）

---

## 3. 辩论专项（debate）

### 方法论
- 重点训练**法庭辩论能力**（公诉意见/辩护意见/互相辩论）
- 围绕法律适用和量刑展开
- 多次循环辩论环节

### 流程
```
P0 → P0.5 → P1（简化）→ P2（重点：设定辩论焦点）→ IG-C
→ P3（简化：仅保留基本举证）→ P4（重点循环：公诉意见→辩护意见→互相辩论，可多轮）
→ P5（重点评估辩论能力）→ P6
```

### 时长
- 20-30轮对话
- 重点在P4的辩论环节

### 输出差异
- 复盘6维度中**论点说服力、策略选择**权重提升
- **发问质量、异议准确度**权重相对降低
- 重点评语：法律论据是否充分、逻辑是否严密、攻防是否到位

### Phase跳过
- P3举证质证环节大幅简化
- 跳过P4中的最后陈述环节（被告人可一句话带过）

---

## 4. 发问专项（questioning）

### 方法论
- 重点训练**对被告人/证人的发问技巧**
- 围绕开放式问题、追问策略、引出关键事实展开
- 多次循环讯问/发问环节

### 流程
```
P0 → P0.5 → P1（简化）→ P2（重点：设定发问目标）→ IG-C
→ P3（重点循环：公诉人讯问→辩护人发问→审判员补充讯问，可多轮）
→ P4（简化）→ P5（重点评估发问能力）→ P6
```

### 时长
- 15-25轮对话
- 重点在P3的讯问/发问环节

### 输出差异
- 复盘6维度中**发问质量**权重最高
- 重点评语：问题是否开放式、是否引出关键事实、追问是否有效

### Phase跳过
- P3的举证质证环节大幅简化
- P4辩论环节简化

---

## 5. 异议专项（objection）

### 方法论
- 重点训练**提出异议的准确性和时机把握**
- 围绕6类异议类型（诱导性/关联性/非法证据/假设性/重复性/人身攻击）+ 4类陷阱异议（v3.0.0新增）
- 频繁触发异议场景

### 流程
```
P0 → P0.5 → P1（简化）→ P2（重点：触发异议的争议点）→ IG-C
→ P3（重点：频繁触发各类异议）→ P4（简化）→ P5（重点评估异议能力）→ P6
```

### 时长
- 20-30轮对话
- 重点在P3的异议环节

### 输出差异
- 复盘6维度中**异议准确度**权重最高
- **程序规范性**权重也较高（异议需在正确程序阶段提出）
- 重点评语：异议类型是否准确、时机是否恰当、依据是否充分

### Phase跳过
- P4辩论环节简化
- 部分非争议环节简化

### 训练强度建议
- 推荐使用**激烈**或**压力**强度
- AI主动制造异议场景

---

## 6. 程序熟悉（procedure_familiar）

### 方法论
- 重点训练**对庭审程序的整体熟悉度**
- 围绕各程序阶段的目的、角色行为、程序衔接展开
- 减少实质争议，专注程序本身

### 流程
```
P0 → P0.5 → P1（重点：介绍各程序）→ P2（重点：程序衔接）→ IG-C
→ P3（程序示范）→ P4（程序示范）→ P5（重点评估程序理解）→ P6
```

### 时长
- 30-50轮对话
- 重点是程序完整呈现

### 输出差异
- 复盘6维度中**程序规范性**权重最高
- 其他维度权重相对降低
- 重点评语：是否理解各程序阶段目的、是否正确处理程序衔接

### Phase跳过
- 无跳过，但可减少实质争议深度

### 特别说明
- 适合**新手律师**或**刚接触刑事业务的律师**
- 重点不是赢得模拟，而是理解程序

---

## 7. 复盘（debrief）

### 方法论
- 跳过P3+P4的实质模拟
- 重点在**P5复盘环节**
- 基于已有材料（用户提供的庭审笔录/录像/描述）进行复盘
- 纯分析性训练

### 流程
```
P0（询问用户已有材料）→ P0.5（确认复盘对象）→ P1（材料解析）→ P2（争议点提取）
→ 跳过P3+P4（用户已有实质材料）
→ P5（重点：6维度深度复盘）→ P6
```

### 时长
- 5-10轮对话
- 重点是P5的深度复盘

### 输出差异
- 复盘6维度**全部展开**，权重相等
- 重点评语：综合评估，提供具体改进方向
- 不进行对话式模拟，仅进行文本分析

### Phase跳过
- P3+P4完全跳过
- 仅保留P1+P2+P5+P6

### 适用场景
- 真实庭审后想要复盘
- 已有完整材料，不需要重新模拟
- 想要深度分析某个庭审策略

## 7种训练目标对照表

| 训练目标 | 重点Phase | 跳过Phase | 时长 | 重点维度 |
|---------|---------|---------|------|---------|
| 全流程 | P3+P4 | 无 | 30-50轮 | 综合 |
| 质证专项 | P3质证 | P4简化 | 20-30轮 | 发问质量、异议准确度 |
| 辩论专项 | P4辩论 | P3简化 | 20-30轮 | 论点说服力、策略选择 |
| 发问专项 | P3讯问/发问 | P3其他+ P4简化 | 15-25轮 | 发问质量 |
| 异议专项 | P3异议 | P4简化 | 20-30轮 | 异议准确度、程序规范性 |
| 程序熟悉 | 全部（程序示范） | 无（减少争议深度） | 30-50轮 | 程序规范性 |
| 复盘 | P5 | P3+P4 | 5-10轮 | 综合 |

## 训练目标选择建议

### 按律师阶段
- **实习律师**：程序熟悉 → 全流程 → 复盘
- **执业1-3年**：全流程 → 质证专项/辩论专项 → 复盘
- **资深律师**：辩论专项/异议专项/发问专项 → 复盘

### 按案件类型
- **暴力犯罪**：质证专项（重点伤情鉴定/因果关系）
- **财产犯罪**：辩论专项（重点非法占有目的）
- **网络犯罪**：质证专项（重点电子数据）
- **毒品犯罪**：异议专项（重点特情引诱/数量异议）
- **经济犯罪**：辩论专项（重点主体身份/利用职务便利）

### 按训练目的
- **准备新案件**：程序熟悉 → 全流程
- **复盘旧案件**：复盘
- **突破薄弱环节**：针对该环节的专项训练
- **保持手感**：全流程
