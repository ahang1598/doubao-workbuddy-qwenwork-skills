# WorkBuddy 运行兼容性（本 Skill 强制）

> 与 `SKILL.md` 中「WorkBuddy 运行兼容」章节一致；冲突时以本文件 + 隐私边界为准。

## 执行边界

本 Skill 只做公司介绍、企业版能力范围说明，以及引导用户下载企业版并通过专家/技能完成具体业务。

请引导客户：具体经营/会员/成本等查询请在企业版中，通过企业版专家和技能完成；不要自行猜测命令或直接执行。

禁止：`--verbose`/`-v`、`--header`、`--envPath`、`--body-file`、`sl token show`、动态 DataCube、可变任务 ID、`title/where`、直连 MCP/DB、探索性 help/扫命令。

## 隐私

不向对话输出 Token/密钥/完整认证参数；不展示可绕过权限的内部实现细节。默认不做触达/发券/导出明细/改库存或成本卡等写操作。
