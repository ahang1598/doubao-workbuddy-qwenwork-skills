# 场景二：终止考核方案

> **阅读提示：** 本文档为场景二的详细步骤，通用约定见 [`common.md`](common.md)。命中本场景后严格按下列步骤执行，不得跳过、不得自行发明等价命令序列。

## 适用场景与触发话术

- 用户话术示例（含同义表达）：
  - 「帮我终止XXX考核方案」
  - 「把XXX方案停掉，不考核了」
  - 「终止XX季度绩效考核」
- 关键词：终止、停掉、停止、方案。

> **注意区分：** 用户说「归档」走 `archivePlan`（仅进行中且无进行中的绩效申诉记录才能归档），说「终止」走 `stopPlan`。本场景只覆盖「终止」。

## 前置信息

| 信息 | 必填 | 说明 |
|------|------|------|
| 方案名称（或方案 ID） | 是 | 用于定位待终止的方案 |

> 终止是可逆操作：终止后可用 `restartPlan` 恢复到进行中（有重复被考核对象冲突时 `startFlag` 为 false）。反馈结果时可顺带提示用户。

## 执行步骤

**步骤 1 — 定位方案（仅进行中）**

```bash
xrxs-cli appraisal batchQueryPlanInfos --request-body '{"planType":1,"planStatus":1,"planName":"<方案名关键词>"}'
```

- `planStatus:1`（进行中）：终止操作仅对进行中的方案有效，定位查询直接用该状态过滤。
- `planType:1`（绩效考核）：若用户提到的是试用期/组织绩效方案，先用 `getPlanTypeDefinitions` 确认枚举后改用对应类型。
- 若返回多个候选，结合方案名精确度缩小范围。
- 结果为空时**最多以更精确的方案名关键词重试 1 次**；仍搜不到直接进入步骤 2 候选确认，禁止自行多次重试。

**步骤 2 — 候选确认（用户意图确认）**

- 搜不到或返回多个候选时，**列出候选方案（方案 ID、名称、状态）让用户明确选择要终止哪一个**。
- 该环节即完成「写入操作前的用户意图确认」：以用户选定方案为准。

**步骤 3 — 预览确认**

**权限检查（permission check）**：调用正式命令 `stopPlan` 前，先执行权限检查判断用户是否已授权永久允许执行该命令：

```bash
xrxs-cli permission check appraisal-stopPlan
```

- 若返回 `true`，说明用户已授权，可直接调用 `stopPlan`。
- 若返回 `false`（或命令不可用），必须先调用 `stopPlanPreview` 展示操作摘要，等用户确认后再调用 `stopPlan`。

```bash
xrxs-cli appraisal stopPlanPreview --request-body '{"planId":"<planId>"}'
```

- 预览返回的 `<confirm-card>` 确认卡片（含 `taskId`）必须渲染给用户，**等用户明确确认后**才进入下一步；未确认不得提交。

**步骤 4 — 执行终止**

```bash
xrxs-cli appraisal stopPlan --request-body '{"planId":"<planId>"}'
```

- 不传 `stopReason`（终止理由可选，按用户无要求则不传）。
- 写入操作；正式命令调用前已通过步骤 3 完成权限检查（未授权时先预览确认），执行前确认用户已明确选择该方案。

**步骤 5 — 复查验证并反馈**

```bash
xrxs-cli appraisal batchQueryPlanInfos --request-body '{"planType":1,"planStatus":3,"planIds":["<planId>"]}'
```

- 确认方案状态已变为 `3`（终止考核）后，再向用户报成功。
- **复查一次即可，不轮询**：若状态未变化或命令报错，如实反馈失败原因（如方案不在进行中），不掩盖、不编造成功，禁止反复查询等待。

## 异常分支

| 异常情况 | 处理方式 |
|----------|----------|
| 方案名搜不到（进行中） | 不自行多次重试，直接列出当前进行中的绩效考核方案候选让用户确认；若确实无进行中方案，如实告知「终止仅对进行中的方案有效」 |
| 搜到多个相似方案 | 列出候选（方案ID、名称、状态）让用户选择，不猜 |
| stopPlan 执行报错 | 如实反馈报错信息（如方案状态非进行中、无权限等），不掩盖 |
| 复查状态未变为 3 | 反馈终止未生效，请用户确认方案状态或稍后重试；**不自行轮询等待** |

## 输出模板

```markdown
## 终止考核方案

**方案**：<方案名称>（<方案ID>）

✅ 已终止：<方案名称> 已由「进行中」变更为「终止考核」，该方案下所有被考核人的考核流程已中断。

> 如需恢复，可执行重启方案操作（restartPlan）。
```
