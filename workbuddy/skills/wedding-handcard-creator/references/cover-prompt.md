# 封面图生成提示词

## 提示词模板（直接复制，替换占位符）

```
你是一个有丰富经验的封面设计师，设计一张竖版图片（高度大于宽度），用于婚礼主持手卡的背面。图片沿一条水平横线可以上下裁成两半，上半部分和下半部分各有一个完全相同的结婚请柬封面，两个封面是上下堆叠排列的（绝对不是左右并排）。每个封面都是独立完整的：统一的高级酒红色背景，带细微纸张纹理，四角点缀淡雅的牡丹暗纹，四周有一圈完整的细金色边框，四个角有精致的中式回纹角花装饰。每个封面的偏上区域居中排版：一个大的烫金质感"囍"字（传统书法体，金属光泽），囍字下方一行烫金字"{{新郎姓名}} {{新娘姓名}}"，再下方一行烫金字"{{结婚日期}}"。每个封面文字以下为纯净酒红色留白。两个封面上下堆叠，中间没有竖线、没有额外分割线、没有折痕。整体风格简约高级，烫金压纹印刷质感，专业婚礼请柬设计，无人物，纯版式。
```

## 占位符说明

| 占位符 | 示例 | 说明 |
|--------|------|------|
| `{{新郎姓名}}` | 张鹏程 | 中文名，直接写 |
| `{{新娘姓名}}` | 陈利凤 | 中文名，直接写 |
| `{{结婚日期}}` | 2026.10.06 | 建议用点分隔，与囍字风格统一 |

## 生成参数

- **尺寸**：1754 × 2480 px（A5 竖版，300dpi，比例 1:1.414）
- **单张封面尺寸**：对半裁开后每张为 1754 × 1240 px（148.5×105mm，300dpi）
- **比例**：竖版（上下各一张相同的请柬封面）
- **模型**：默认文生图模型即可

## 图片结构要求（用于 A5 竖版拼版背面）

1. **整体**：A5 竖版图片，上下两半完全相同
2. **每半张**：一个完整的结婚请柬封面（囍字+姓名+日期+金色边框+四角回纹角花+牡丹暗纹）
3. **中间区域**：完全无线条、无压痕、无折痕、无分割痕迹，上下两个封面自然排列
4. **背景**：统一的高级酒红色，色调完全一致，可带细微纸张纹理和四角牡丹暗纹
5. **关键禁忌**：不要信封造型、不要中间粗金线、不要上下分层断裂感、不要只在上半有字下半纯红
6. **提示词写法注意**：不要使用"上半部分""下半部分""对折""中线"等可能导致模型生成分割线的词；改用"上下两半完全相同的两个独立请柬封面"等表述

## 使用方式

1. 用上述提示词生成图片
2. 下载到与手卡 HTML 同一目录
3. HTML 中背面页通过 `background-image: url('图片文件名')` 引用
4. CSS 设置 `background-size: 100% 200%`，上半卡 `background-position: top`，下半卡 `background-position: bottom`
5. 由于上下两半完全相同，裁开后每张手卡的背面都是完整的囍字请柬封面
