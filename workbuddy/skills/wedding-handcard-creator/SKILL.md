# Wedding Handcard Creator

将婚礼主持稿转化为现场可手持、可打印的主持人手卡。核心产出：一个 HTML 文件（浏览器打开后 Ctrl+P 打印）+ 一张背面封面图，或直接生成 PDF。

## 工作流程

按以下顺序执行，不要跳步：

### 1. 读取主持稿

完整读取用户提供的主持稿（.md/.txt/.docx），提取每个环节的：
- 环节名称、预计时长
- 新郎台词（逐字稿）
- 动作/走位/音乐/道具提示（不念出来的部分）
- 新娘或父母的发言占位

如果用户没有主持稿，先询问是否需要先撰写主持稿，或基于用户提供的环节大纲生成简版台词再做手卡。

### 2. 拆分卡片

按环节拆卡，内容多的环节拆成两张。每张卡控制在小卡可容纳的字数（约 150–220 字台词）。

标准 8 环节婚礼通常拆为 12 张卡：
00 流程速览封面 → 01 开场白 → 02 介绍来宾 → 03 迎接新娘 → 04 献花牵手 → 05 新郎誓言 → 06 新娘回应+收尾 → 07 戴戒指 → 08 敬茶改口 → 09 父母致辞 → 10 敬酒礼成 → 11 救场锦囊

### 3. 生成背面封面图

调用图片生成工具，使用 `references/cover-prompt.md` 中的提示词模板，替换新人姓名和日期后生成。图片要求：
- A5 竖版，1754×2480px（300dpi）
- **上下两半是完全相同的两个独立囍字封面**（上下堆叠排列，不是左右并排）
- 每个半张：囍字+姓名+日期+金色边框+四角回纹角花+牡丹暗纹
- 上下两半各自有完整边框，裁开后每张卡背面都是完整的囍字封面
- 背景统一高级酒红色，可带细微纸张纹理

生成后下载到与 HTML 同目录，文件名建议 `手卡背面.jpg`。

### 4. 组装 HTML

复制 `assets/handcard-template.html` 到用户指定的输出目录（通常与主持稿同目录），然后：
- 将每张卡的台词填入对应 `.card` 区域
- 动作提示填入左侧 `.cue` 框
- 酒红色加粗 `<strong>` 标注骨架句/关键梗（不能说错的句子）
- 确认每页右下角页号（`01/12` 格式）与卡片顺序一致
- 背面图文件名与 HTML 中 `background-image: url('...')` 一致
- 确认图片与 HTML 在同一目录

### 5. 验证

在浏览器中打开 HTML 检查：
- 每张卡内容不溢出、不被截断
- 背面上下两半都是囍字封面，裁开后一致
- 共 6 张 A5 正面 + 6 张 A5 背面（12 页）
- 每页右下角有页号
- 打印预览（Ctrl+P）中分页正确

### 6. 交付

交付物包含以下两种（按需提供，默认两种都给）：

**A. A5 竖版拼版 HTML（需手动打印）**
- 交付 HTML + 背面图
- 打印说明：Edge/Chrome 打开 → Ctrl+P → 纸张 A5、方向纵向、边距无 → **勾选双面打印，沿短边翻转** → 勾选背景图形 → 沿中间虚线裁开 → 12 张小卡
- 建议 160–200g 厚纸/白卡纸

**B. A5 竖版拼版 PDF（直接打印）**
- 用脚本将 HTML 转为 PDF，每页为 A5 竖版，上下各一张小卡
- 详见下方「PDF 直出」

## PDF 直出

当用户要求"直接给 PDF""不要 HTML 要 PDF"时：

1. 确认 HTML 已按步骤 4 组装完成（含背面图）
2. 运行脚本生成 PDF：
   ```
   python <skill目录>/scripts/generate_pdf.py <输入.html> <输出.pdf>
   ```
3. 脚本自动调用系统 Edge/Chrome（零额外依赖），生成 A5 竖版 PDF
4. 验证 PDF 页数 = 12 页（6 正面 + 6 背面），每页上下两张小卡，中间有虚线裁切线，右下角有页号

**打印 PDF**：PDF 阅读器打开 → 纸张 A5、方向纵向、无边距、勾选背景图形 → **双面打印，沿短边翻转** → 沿中间虚线裁开 → 12 张小卡。

**脚本注意事项**：必须使用旧版 `--headless`（非 `--headless=new`），新版 headless 不尊重 @page 尺寸，会导致页面大小错误（内容只占上半）。

## 手卡设计规范

### 尺寸与拼版
- 单卡：148.5mm × 105mm（A5 竖版对半裁开）
- 拼版：A5 竖版（148.5×210mm）上下各一张卡，中间虚线裁切线
- 双面：正面页（两张台词卡）+ 背面页（两张囍字封面，上下相同）
- 页号：每张卡右下角，格式 `NN / 12`

### 卡片内部布局（横版左右分栏）
- 顶部色条：编号（酒红底白字）| 环节名（酒红加粗）| 时长（灰色小字）
- 左侧栏（约 32% 宽）：动作/音乐/道具提示（灰底左边框）+ 下一环节衔接
- 右侧主区（约 68% 宽）：台词正文
- 右下角：页号

### 视觉规范
- 主色：酒红 `#8f2c3a`（标题、骨架句、编号底）
- 提示灰：`#f5f2f0` 底 + `#b9a8a2` 左边框
- 台词字号：10.5pt，行距 1.62
- 动作提示：8–8.5pt，灰色
- 骨架句/关键梗：`<strong>` 酒红色加粗
- 页号：8pt，浅灰 `#b0a8a3`
- 中文字体：Microsoft YaHei / PingFang SC

### 内容处理原则
- 台词保留完整逐字稿（现场紧张时可直接念）
- 动作/走位/音乐提示放左侧灰框，标注"不念"
- 新娘/父母发言用占位框标注，不写具体内容
- 每张卡左上角编号 + 右下角页号，方便排序和翻页
- 最后一张必为"救场锦囊"（忘词/冷场/设备故障的应对句）
