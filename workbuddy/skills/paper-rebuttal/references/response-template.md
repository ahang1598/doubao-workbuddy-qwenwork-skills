# Response Letter 模板（Point-by-Point）

使用时复制本模板并填充；语言与审稿意见一致（此处以英文为例）。占位符用 `<...>` 标出。

---

```markdown
# Response to Reviewers

**Paper**: <论文标题> (<投稿编号/会议期刊名>)
**Authors**: <作者>

Dear Editor and Reviewers,

We thank the editor and all reviewers for their time and constructive feedback.
<1–2 句回应 meta-review / 整体评价：认可了什么、主要关切是什么。>
In this revision, we have made the following major changes:

1. <主要修改 1，如：新增在 X 数据集上的实验（§4.3, Table 5）>
2. <主要修改 2，如：补充复杂度分析与 Limitations 小节（§3.4, §6）>
3. <主要修改 3>

All changes are highlighted in the revised manuscript. Below we address each
comment point by point. Reviewer comments are shown in *italics*.

---

## Reviewer 1

> Overall assessment acknowledged: <简短回应 R1 的总体评价，一句即可>

### [R1.1] <意见主题词，如 "Novelty compared to [X]">

*<审稿人原话或精确概括>*

**Response**: <结论先行的回答。引用论文位置或给出证据。>

**Change made**: <仅 B/C 类。如 "We have added a discussion in §2 (Page 3)
clarifying the differences from [X]: ...">（A 类删除此行）

### [R1.2] ...

*<评论>*

**Response**: ...

**Change made**: ...

---

## Reviewer 2

<同上结构>

---

## Summary of Changes

| Comment | Location in Revision | Change |
|---------|---------------------|--------|
| R1.1 | §2, Page 3 | Added comparison discussion with [X] |
| R1.2 | §4.3, Table 5 | New experiment on dataset Y |
| R2.1 | §6 | Added Limitations section |
| ... | ... | ... |

We hope the revised manuscript and our responses address all concerns. We would
be happy to incorporate any further suggestions.

Sincerely,
<作者>
```

---

## 使用说明

- **Summary of Changes 表**必须与实际修改日志完全一致，作为审稿人快速核查入口。
- 意见非常多时（如 3+ 审稿人共 30+ 条），总述段的"major changes"列表控制在 3–5 条，挑选 Major 级修改。
- 期刊 major revision 场景：在开头补充对原稿编号、修改稿高亮方式的说明（如 "changes marked in blue"）。
- 会议 rebuttal（不改论文、仅回复）场景：删除所有 "Change made" 行与 Summary 表，回复以证据和澄清为主；若能提交补充材料，注明 "see supplementary material, Section X"。
- 中文场景替换标题为《审稿意见回复》，结构不变。
