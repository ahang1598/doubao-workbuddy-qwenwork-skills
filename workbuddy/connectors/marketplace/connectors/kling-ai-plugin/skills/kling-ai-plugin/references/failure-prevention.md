# 生成失败预防门禁

本文件把已观察到的错误类型转化为提交前检查和明确停止条件。错误名称只是诊断标签，不改变实时工具 schema，也不授权重试、改写用户意图或绕过提供方限制。

## 每次收费生成的五道门禁

1. **连接与账号：**先调用 `who_am_i`；需要 Element 时再对目标 ID 调用 `element_get`，确认当前账号可访问且资源类型适合目标工具。
2. **余额与会员：**紧邻每次收费生成前调用 `query_membership_and_credits`。余额为零、非正数或接口明确表示不足时停止；余额为正但接口没有给出本次任务精确成本时，不声称一定充足。模型、清晰度和会员能力只使用当前账号 `who_am_i` 返回的可用集合。
3. **队列与并发：**同一用户目标同一时间最多保留一个未终态收费任务。多结果优先使用单次请求合法的 `imageCount`；确需多个不同任务时逐个等待终态，不并发提交。
4. **请求结构：**按所选模型建立顶层、arguments 和 inputs 三层封闭白名单；补齐必填与默认值，精确校验枚举、数量、互斥关系和字符串类型。切换模型后从空请求重建。
5. **素材与模式：**历史 Kling 结果按任务编号刷新；检查素材类型、大小、尺寸、比例、角色、来源和 Element 类型；动作控制还要检查主体、动作来源、方向与已声明时长限制。

## 账号、余额与队列

| 错误 | 提交前规避 | 出现后处理 |
| --- | --- | --- |
| `PointNotEnough` | 每次收费调用前查询余额；已知不足则不提交。不要用多张、多条、较长时长或更高清晰度试探余额。 | 告知余额不足并停止；用户明确表示余额已变化前，不再提交同一或其他收费生成。若余额显示充足却报错，按计费异常调用一次 `feedback`。 |
| `MembershipNeed` | 只选择当前账号实时可用的模型和允许值，不根据其他账号或快照猜测会员能力。 | 说明该能力需要会员；只有用户明确选择可用替代方案时才更换模型或参数。 |
| `MembershipQueueLimit` | 当前任务中的收费生成严格串行，上一任务未终态前不提交下一任务。 | 说明账号队列已满并停止；不要等待后自动重试，也不要切模型规避队列。 |
| `RateLimitExceeded` | 收费任务严格串行；同一意图不重复提交，状态查询遵守提供方允许的间隔。 | 返回提供方限流消息并停止；不要等待后自动重试、切换模型或修改参数创建新任务。 |
| `Unauthorized` | 以本轮成功的 `who_am_i` 作为授权门禁；失败时不进入生成准备。 | 触发宿主原生重新连接流程；重新授权完成前不调用其他 Kling 工具。 |
| `RiskUnauthorized`、`BehaviorRiskPOther` | 不构造规避风控的同义改写，不伪装主体、用途或素材来源。 | 原样说明限制并停止；原因不透明时调用一次 `feedback`，不重试。 |

## 参数、模式与 Element

| 错误 | 提交前规避 | 出现后处理 |
| --- | --- | --- |
| `InvalidParameter`、`InvalidArguments` | 使用实时封闭白名单；`model` 必填且使用规范名；所有 argument 值为字符串；没有声明的参数、input、枚举或空占位不得传。 | 指出被拒绝字段，重新读取 schema；只有用户批准再次生成时才用修正后的完整参数重新提交。 |
| `ImageTaskDisallowsVideoElement` | `element_get` 显示 `resource.video` 时不得用于图像任务；视频 Element 只交给实时说明允许的 `image_to_video` 模型。 | 保留 Element ID，说明需要视频任务或图片 Element；不降级成封面图或文字描述。 |
| `ElementNotBelongToUser` | 使用 Element 前调用 `element_get`，确认它在当前授权账号可访问；不要复用其他账号、退出前或历史会话中的裸 ID。 | 请用户在当前账号重新选择可访问 Element；不猜测或替换 ID。 |
| `AioImageRatio`、`ImageRatio` | 画幅只取所选模型的 `aspect_ratio` 枚举；没有该参数的模型必须省略。参考图本身还须满足下面的素材长短边比例限制。 | 说明是输出画幅还是输入图片比例不合规，给出该模型当次允许值；不自动裁切用户素材。 |

## 图片与文件素材

图生图和图生视频当前工具说明要求输入图片为 PNG/JPG、文件不超过 30 MB、分辨率低于 4K、长短边比不超过 2:1。不要把这些限制推广到实时说明没有声明的其他工具；账号或版本返回更严格要求时采用更严格值。

| 错误 | 提交前规避 | 出现后处理 |
| --- | --- | --- |
| `UnsupportedFileType` | 能读取元数据时确认图片确为 PNG/JPG；扩展名与实际 MIME 不一致时停止。 | 请用户改用真实 PNG/JPG 文件，不只修改扩展名。 |
| `FileTooLarge` | 能读取大小时确认不超过 30 MB。 | 请用户压缩或重新导出；未经用户要求不自行改变画质。 |
| `ImageSize` | 能读取尺寸时确认低于当前工具声明的 4K 上限；不要自行换算或猜测未声明的最小像素。 | 告知实际尺寸与实时限制，请用户重新提供合规图片。 |
| `FileUploadFailed`、`InvalidBucketName` | 提交生成前确认素材引用已由宿主成功提供、URL 非空且来源被所选模型接受。 | 这是素材接入或存储链路错误，不调用收费生成；调用一次 `feedback`，让用户稍后重试或重新提供素材。 |
| `ResourceNotFound` | 历史 Kling 结果不得复用旧 URL；紧邻提交前按 `generationId` 与作品序号查询一次当前 URL。 | 本轮刷新后仍失败则停止并请用户重新附图，不再次查询或换 URL 字段。 |

宿主无法读取文件元数据时，不要声称完成了类型、大小、尺寸或比例检查；只依赖宿主和提供方已明确验证的事实。

## 动作控制

| 错误 | 提交前规避 | 出现后处理 |
| --- | --- | --- |
| `MOTION.DURATION_MORE_THAN_EXPECTED`、`MOTION.DURATION_LESS` | 主体图 `image` 必填；`motionId` 与动作视频严格二选一。`motionDirection=image_direction` 时动作来源必须为 3–10 秒；其他方向只采用实时工具明确给出的时长限制，不猜范围。 | 说明实际时长与提供方要求，请用户选择其他动作或裁剪素材；不自动裁剪或重试。 |
| `MOTION.PIC_NOT_MATCHED` | 主体图必须清楚包含人或动物；在提交前确认用户指定的是主体图而非场景、风格或产品图。 | 请用户换用主体清晰的图片，并重新确认主体角色；不改成普通图生视频。 |
| `MOTION.RESOLUTION_TOO_SMALL` | 若实时 schema 或宿主给出动作主体图最小尺寸则据此校验；当前未声明精确最小值时不得猜测。 | 请用户提供更清晰、更高分辨率的主体图；同时以 `CAPABILITY_SPEC_MISMATCH` 调用一次 `feedback`，记录服务端未公开最小值。 |

## 内容与平台异常

| 错误 | 提交前规避 | 出现后处理 |
| --- | --- | --- |
| `Copyright` | 不承诺复制受保护角色、作品或标识一定成功；涉及参考素材时保留用户声明的授权边界，不自动替换成规避检测的描述。 | 请用户改用其拥有权利的素材或原创替代；不通过同义改写绕过限制。 |
| `Unknown`、`GenImageOther`、`POther`、`Unexpected`、`TaskSubmitFailed` | 完成账号、余额、schema、素材与队列门禁后只提交一次，并保留 `generationId`、模型和 `taskTraceId`。 | 报告提供方消息并停止；按错误性质调用一次 `feedback`，不得自动重试。 |

`feedback` 只用于报告，不会重试、退款或修复原任务。一次异常最多调用一次；反馈后仍按当前错误的停止条件处理。
