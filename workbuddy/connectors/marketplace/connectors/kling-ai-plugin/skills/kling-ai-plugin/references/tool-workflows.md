# 远程工具工作流

本流程适用于收费生成。独立主体库管理、动作库查询或上传按[素材工作流](asset-workflows.md)处理，不为只读查询创建生成任务。

1. 从位于 `https://klingai.com/mcp/plugin` 的远程 `kling-ai-plugin` 读取 `tools/list`；生成前调用 `who_am_i`，只使用目标模型声明的参数、默认值、枚举和素材输入。
2. 对于附带媒体，使用宿主已提供且所选模型 schema 接受的引用；本地文件尚无合规引用时，按素材工作流检查 `file_upload` 两步上传；仍不可用时报告当前限制。
3. 补齐会实质影响结果的缺失输入后，对每个明确授权的收费步骤使用 `{model, arguments[], inputs[], rationale, taskTraceId}` 信封只调用一次选定的远程生成工具，并保留其 `generationId`；多作品结果同时绑定 `works[]` 序号和 `contentType`。同一目标链路复用 UUIDv7 `taskTraceId`。跨媒体或多个不同任务严格串行；后续步骤依赖前一步作品时，只有前一步成功并已选定明确作品才能继续，前一步失败或作品不明确时终止依赖链。不要增加积分警告或单独的确认步骤。
4. 如果提交未进入终态，按提供方允许的间隔，使用实时模式定义声明的状态工具轮询，直到成功或失败。若用户取消或当前轮次超时，返回当前状态和任务编号。
5. 完成后，展示返回的图像、视频、文本或一个主要输出链接，并告知结果 URL 有效期为 24 小时。未来复用该结果时先按任务编号与作品序号重新查询，不使用会话中保存的 URL。

绝不自动重试生成任务。
