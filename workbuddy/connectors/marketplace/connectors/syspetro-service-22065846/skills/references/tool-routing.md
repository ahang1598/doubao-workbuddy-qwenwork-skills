# PROPDB 工具路由

## 规范工具表

| 规范工具名 | 使用条件 | 输入 | 不用于 |
| --- | --- | --- | --- |
| `post_sys_component_app_mcp_get_mixture_components_by_keywork`（源 schema 规范名） | 用户给出名称、别名、分子式或 CAS，需要取得候选 ID | `keyword` | 空关键词、全库浏览、性质搜索 |
| `post_sys_component_app_mcp_get_component_details` | 用户要查看一个已知 ID 的身份详情 | `Id` | 用名称直接查询、物性详情 |
| `post_sys_component_app_mcp_get_components_details` | 用户要一次对照多个已知 ID 的身份详情 | `ids` | 搜索消歧、枚举 ID、查询物性 |
| `post_sys_prop_app_mcp_get_component_dp_propeties` | 用户要查看一个已选组分的基础标量物性 | `Id` | 温压序列、模型参数、指定条件计算 |
| `post_sys_prop_app_mcp_get_mixture_properties` | 用户要查看明确组分对有哪些混合物物性数据 | `ids` | 实验值、模型参数、文献详情、通用枚举 |

运行时名称可能带命名空间。详情、批量详情、标量物性和混合物物性按以上完整名称后缀匹配。2026-08-17 实际挂载的关键词工具为 `mcp__propdb__post_sys_component_app_mcp_get_mixture_e2ed9f7b98db`；哈希可能变化，因此在 `propdb` 命名空间内按描述“根据关键词查询混合物组分”和唯一字符串输入 `keyword` 识别。只允许唯一匹配；不要修正源名称中的 `keywork` 或 `propeties`。

## 组分解析

### 已有 ID

用户明确给出 `PCdataCompID` 时直接用于目标查询。不要再次关键词搜索，除非用户要求核对身份。

### 只有人类可读标识

对每个不同的组分词分别调用关键词检索，原样传递去除首尾空白后的用户输入。文档明确的查询标识是名称、别名、分子式和 CAS；不要承诺 SMILES、InChI、IUPAC 或性质名称一定可被该输入检索。

判定顺序：

1. `data` 为空：未找到，要求更准确的名称、公式、CAS 或 ID。
2. 只有一项：选择该项。
3. 多项中只有一个与用户输入存在可核对的精确匹配：选择该项。
4. 其余多项：展示必要字段并等待用户选择。

精确匹配只使用实际返回字段：CAS 和公式去除首尾空白后完整相等；名称和中英文名不区分大小写完整相等。别名字段的分隔契约尚未确认，不要自行拆分复杂字符串来制造唯一匹配。多个精确匹配仍需用户选择。

消歧输出示例结构：

```text
找到多个可能的组分，请选择后我再继续原查询：

1. 中文名/英文名｜分子式｜CAS｜IUPAC（必要时）｜组分 ID
2. ...
```

空字段省略。不要为消歧默认调用单个或批量详情；检索结果已含主要身份字段。

实测搜索摘要可能返回 `mw=null`、`canCalcPureProperty=false`，而同一对象的详情返回实际分子量和 `true`。因此搜索结果中的这两个字段一律不用于用户结论；需要时查询详情。

## 最小调用链

### 单个详情

- 有 ID：单 ID 详情，共 1 次。
- 无 ID：关键词检索；唯一化后单 ID 详情，共 2 次。

### 批量身份对照

- 对没有 ID 的每个不同组分词各检索 1 次。
- 所有对象唯一化后调用一次批量详情。
- 通过返回的 `pCdataCompID` 关联用户输入；不要依赖数组位置。

### 纯组分标量物性

- 解析一个 ID。
- 调用一次组分物性查询。
- 用 `property`、`property_Zh` 和 `propAbbreviation` 识别用户目标，只展示实际返回的命中项。
- 未命中目标物性时说明本次标量列表没有该项；不要扩展为数据库永久不存在，也不要调用混合物工具替代。

分子量同时可能出现在详情 `mw` 和物性列表。用户只要身份与分子量时优先详情；用户同时查询多项基础物性时使用物性列表，避免为同一值增加调用。

### 二元物性数据可用性

- 按用户顺序解析两个组分 ID。
- 调用一次混合物物性查询，传入这两个 ID。
- 通过返回的两个组分 ID 识别组分对，不假设响应保持输入顺序；实测服务端会规范化乙醇—水的顺序。
- 报告返回的组分对、物性名称、文献数和数据计数。
- 三个以上组分时先要求指定组分对；不要自动生成全部两两组合。

## 停止条件

- 任一组分未唯一化；
- `keyword` 为空或意图是数据库枚举；
- 输入 ID 是猜测、顺序生成或为批量导出而提供；
- 用户需要的字段只能由当前未开放的详情/计算接口提供；
- 工具返回无权限、限流、超时或系统失败。

停止时保留已解析对象和原始目标，用户补充信息后从中断点继续，不要求重述全部请求。
