# 场景五：设置方案截止前自动提醒未提交的员工

> **阅读提示：** 本文档为场景五的详细步骤，通用约定见 [`common.md`](common.md)。命中本场景后严格按下列步骤执行，不得跳过、不得自行发明等价命令序列。

## 适用场景与触发话术

- 用户话术示例（含同义表达）：
  - 「帮我设置方案截止前X天自动提醒未提交的员工」
  - 「开启考核截止前的自动提醒」
  - 「把自动提醒关掉」
- 关键词：自动提醒、截止前、未提交、提醒时间、remindSetting。

> **能力边界（重要）：** `updateRemindSetting` 是**公司级**配置，请求体仅支持 `enabled`（0-关闭 1-开启）与 `remindTime`（HH:mm 整点，08:00-22:00），**没有「提前 X 天」「未提交员工筛选」「方案 ID」参数**。「截止前 X 天自动提醒未提交的员工」是系统开启自动提醒后的固有行为，X 天由系统规则决定，本场景不涉及 X 天配置。

## 前置信息

| 信息 | 必填 | 说明 |
|------|------|------|
| 操作意图 | 是 | 开启 / 关闭自动提醒（由用户话术判断，含糊时追问） |
| 提醒时间 | 开启时必填 | HH:mm 整点、08:00-22:00；用户未指定时默认 **10:00** |

> **注意：** 公司级配置，一旦修改影响全公司绩效考核的自动提醒行为。设置前向用户复述将要写入的配置（开关 + 时间），确认后执行。

## 执行步骤

**步骤 1 — 收集参数并校验**

- 确认用户意图是**开启**还是**关闭**自动提醒（含糊则追问）。
- 开启时确认提醒时间：优先询问用户；未指定默认 `10:00`。
- 校验提醒时间格式：必须为整点 HH:mm 且 `08:00 ≤ 时间 ≤ 22:00`（如 `10:00`、`18:00`），**不合法则提示用户重新提供，不执行**。

**步骤 2 — 执行设置**

开启：

```bash
xrxs-cli appraisal updateRemindSetting --enabled 1 --remind-time 10:00
```

关闭：

```bash
xrxs-cli appraisal updateRemindSetting --enabled 0
```

- 开启时必须传 `--remind-time`（必填）；关闭时可不传时间。
- 写入操作，执行前向用户复述配置（如「将开启自动提醒，每天 10:00 提醒」）确认。

**步骤 3 — 反馈结果**

- 以命令返回结果为准向用户反馈，不复查、不轮询；报错则如实反馈报错信息。

## 异常分支

| 异常情况 | 处理方式 |
|----------|----------|
| 提醒时间格式不合法（非整点/超出 08:00-22:00） | 提示用户重新提供合法时间，**不执行** |
| 用户意图含糊（无法判断开启/关闭） | 追问确认后再执行 |
| 执行报错 | 如实反馈报错信息，不掩盖 |

## 输出模板

```markdown
## 设置自动提醒

✅ 已开启：绩效考核自动提醒已开启，每天 <10:00> 自动提醒截止前未提交的员工（提前天数由系统规则决定）。
```

```markdown
## 设置自动提醒

✅ 已关闭：绩效考核自动提醒已关闭。
```
