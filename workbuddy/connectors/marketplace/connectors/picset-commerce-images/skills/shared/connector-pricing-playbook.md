# Picset 连接器充值面板共享手册

本手册定义 Picset MCP 连接器统一充值面板的标准操作。主 Skill、电商套图 Skill、单图文生图/图生图 Skill 与 Agent Canvas Skill 共用，不在各处重复实现。

**充值面板定位**：充值面板是对整个 MCP 连接器统一计费的独立支付入口，服务于电商套图、单图文生图/图生图、画布操作等所有消耗积分的功能。它与万能画布（Agent Canvas）在业务上没有依赖关系——充值面板不需要画布会话即可独立打开，画布也不依赖充值面板才能工作。两者仅在技术层面共享 skybridge 面板渲染框架。

调用 MCP 工具前，必须使用 `tool_search` 按工具名获取完整参数定义，再按取回的定义发起调用。禁止凭工具名猜测参数结构。

---

## 一、调用时机

以下两种场景调用充值面板：

1. **积分不足**：生成提交或任务执行返回 `INSUFFICIENT_CREDITS` 错误时，自动打开充值面板。
2. **用户主动要求充值**：用户明确说"充值""买积分""打开充值页面""看套餐"等时，打开充值面板。

---

## 二、工具：open_agent_pricing

### 用途

在 MCP host 内打开 Picset 连接器统一充值套餐面板。

### 入参

```json
{
  "conversation_id": "<可选，当前对话 ID，便于宿主关联面板>",
  "scene": "<可选，充值场景标记>"
}
```

- `conversation_id`：可选，字符串。当前对话 ID，便于宿主关联面板。
- `scene`：可选，字符串。充值场景标记，用于区分不同入口的充值需求（如电商套图生成、单图生成等）。

### 行为

- 调用后由宿主在面板内渲染充值套餐页面，用户可在面板内完成查看套餐和支付。
- 支付完成后，积分自动到账，用户可返回对话继续之前的生成任务。

---

## 三、积分不足处理流程

当生成提交或任务执行返回积分不足时：

1. **立即停止**：停止后续生成提交和轮询，不重试、不新建任务。
2. **打开充值面板**：调用 `open_agent_pricing`，传入 `conversation_id`（如可用）和 `scene`（如适用）。
3. **告知用户**：简要说明积分不足、已打开充值面板、充值后可重试。
4. **保留状态**：保留已生成的 `task_id`（套图）或 `request_id` + `job_id`（单图），用户充值后可凭原标识恢复或重试。

---

## 四、禁止事项

- **不得向用户展示充值 URL**：充值面板由宿主内渲染，不输出任何链接。
- **不得展示 ticket 或 functionsUrl**：这些是内部鉴权和端点信息，不暴露给用户。
- **不得编造套餐价目**：套餐内容由充值面板展示，skill 不硬编码价格。
- **不得在积分不足时继续生成或轮询**：必须先停止，等用户充值后再继续。
- **不得将充值面板与画布混为一谈**：充值面板是连接器统一支付入口，不是画布的子功能；描述时使用"连接器充值面板"或"积分充值面板"，不使用"画布充值"。

---

## 五、工具速查

| 工具 | 用途 | 调用阶段 |
| --- | --- | --- |
| `open_agent_pricing` | 打开连接器统一充值套餐面板 | 积分不足 / 用户主动充值 |

> 注：本工具名中不含 "canvas"，因为充值面板与万能画布在业务上相互独立。服务端历史版本中曾使用 `open_agent_canvas_pricing`，已更名为 `open_agent_pricing`。
