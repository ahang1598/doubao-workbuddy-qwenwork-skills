# 错误处理参考

## HTTP 状态码

| 状态码 | 含义 | Agent 处理 |
|--------|------|-----------|
| 200 | 成功 | 正常处理结果 |
| 400 | 参数错误 | 检查参数格式和必填项，修正后重试 |
| 401 | 认证失败 | 提示用户重新连接 CamScanner 连接器（不重试） |
| 403 | 无权限 | 该 tool 未授权，告知用户 |
| 404 | 资源不存在 | file_id 已过期或 tool 名称错误 |
| 429 | 限流 | 等待 10 秒后重试 1 次 |
| 500 | 服务端错误 | 等待 5 秒后重试 1 次 |
| 504 | 网关超时 | 增加 timeout_sec 后重试 1 次 |

## 业务错误

| 错误消息 | 原因 | 处理 |
|----------|------|------|
| `file size exceeds the maximum limit` | 文件超过大小限制 | 告知用户压缩文件或拆分 |
| `unsupported file type` | 不支持的文件格式 | 告知用户支持的格式列表 |
| `file_id not found` | file_id 已过期（通常 24h） | 重新上传文件 |
| `invalid enhance_mode` | 增强模式值不合法 | 检查 mode 是否在 1-10 范围内 |
| `too many files` | 超过合并上限 | 分批处理（每批 ≤100） |
| `PKCE verification failed` | OAuth 认证流程异常 | 提示用户断开并重新连接 |
| `user session expired` | cs_token 已过期 | 提示用户重新连接连接器 |

## 重试决策

| 条件 | 是否重试 | 说明 |
|------|----------|------|
| HTTP 429 | ✅ 等 10s 重试 1 次 | 限流保护，稍后即可恢复 |
| HTTP 500 | ✅ 等 5s 重试 1 次 | 偶发服务端错误 |
| HTTP 504 | ✅ 增加 timeout_sec | 处理时间超出默认超时 |
| HTTP 400 | ❌ | 参数错误，需修正 |
| HTTP 401 | ❌ | 认证问题，需用户操作 |
| HTTP 403 | ❌ | 权限不足 |
| 网络超时 | ✅ 重试 1 次 | 网络抖动 |
| 文件过大 | ❌ | 需用户处理 |

## 停止规则

遇到以下情况时 Agent 应停止操作并告知用户：

1. 认证失败（401）— 需要用户重新连接
2. 文件格式不支持 — 无法自动转换
3. 连续 2 次相同错误 — 可能是服务端问题
4. 参数无法推断 — 需要用户提供更多信息
5. 操作超出能力范围 — 如 PDF 合并、视频处理等
