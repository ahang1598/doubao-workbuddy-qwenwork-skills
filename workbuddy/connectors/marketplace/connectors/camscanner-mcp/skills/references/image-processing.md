# 图片处理工具参考

## enhance_image — 图片增强

增强模式详细说明：

| mode | 名称 | 说明 | 适用场景 |
|------|------|------|----------|
| 1 | 亮度增强 | 提升文档亮度和对比度 | 手机拍摄文档、光线偏暗 |
| 2 | 锐化 | 增强边缘细节，提升清晰度 | 轻微模糊、细节不够清晰 |
| 3 | 黑白（二值化） | 转为纯黑白、高对比度 | 需要清晰打印的文档、身份证复印 |
| 4 | 灰度 | 转为灰度图 | 需要灰度效果的文档 |
| 5 | 去阴影 | 去除拍照文档的阴影和暗角 | 手机拍摄文档、有手影的照片 |
| 6 | 去点阵/网纹 | 去除印刷品的网点干扰 | 扫描/翻拍印刷品 |
| 7 | 超级滤镜/高清 | 综合画质提升 | 整体画质优化 |
| 8 | 去摩尔纹 | 去除翻拍屏幕产生的干涉条纹 | 拍摄电脑/手机屏幕内容 |
| 9 | 手写擦除 | 去除图片上的手写标注 | 需要去除笔迹/批注 |
| 10 | 去水印 | 去除图片上的水印文字 | 有文字水印覆盖的图片 |

其他参数：
- `crop`：自动裁剪文档边界（0=关闭，1=开启），适合拍照文档倾斜/有多余背景

**选择决策**：
- 文档拍照偏暗 → mode 1
- 照片模糊但分辨率足够 → mode 2（若分辨率不足改用 `image_hd`）
- 要打印/复印效果 → mode 3
- 文档有阴影 → mode 5
- 翻拍屏幕 → mode 8
- 有水印文字 → mode 10
- 拍歪了/有多余边框 → crop=1

## image_hd — 图片高清化

可选参数 `hd_mode`：不传使用超级滤镜（默认），传 `demoire` 使用去摩尔纹模式（适合屏幕翻拍照片）。

适用于：
- 低分辨率图片需要放大
- 模糊照片需要提升清晰度
- 老照片画质差

与 enhance_image mode=2 的区别：`image_hd` 是 AI 超分辨率，会增加像素数量；enhance_image mode=2 是锐化滤镜，不改变分辨率。

## restore_photo — 老照片修复

无额外参数，AI 自动修复。适用于：
- 有划痕、折痕的老照片
- 褪色泛黄的旧照片
- 有噪点、颗粒感的老照片

## translate_image — 图片翻译

保留原图排版，将文字区域翻译后回填。

参数 `to`（目标语言代码）：

| 代码 | 语言 |
|------|------|
| zh | 中文 |
| en | 英文 |
| ja | 日文 |
| ko | 韩文 |
| fr | 法文 |
| de | 德文 |
| es | 西班牙文 |
| pt | 葡萄牙文 |
| ru | 俄文 |
| ar | 阿拉伯文 |
| it | 意大利文 |
| th | 泰文 |
| vi | 越南文 |

源语言自动检测，无需指定。

## watermark_image — 图片添加水印

水印文字覆盖整张图片，斜 45° 排列。参数：
- `text`（必填）：水印文字，最长 200 字符
- `color`：颜色，十六进制如 #FF0000，默认 #000000
- `opacity`：透明度 0-1，默认 0.4
- `size`：字体大小 1-200，默认 36

## validate_image — 篡改/AI 生成检测

| validate_mode | 功能 | 输出 |
|-------------|------|------|
| 1 | 篡改检测 | 检测图片是否经过 PS 修改，返回置信度和可疑区域 |
| 2 | AI 生成检测 | 检测图片是否由 AI 生成（如 Midjourney、DALL-E），返回置信度 |

注意：`validate_image` 不支持 base64_content，必须先上传文件获得 file_id。

## scan_image_edit + edit_image — 图片文字编辑

两步流程：
1. `scan_image_edit`：分析图片中的文字区域，返回字符索引和位置信息
2. `edit_image`：基于 scan 结果，指定要替换/删除的文字区域和新内容

这是高级功能，适用于需要精确编辑图片中文字的场景（如修改证件上的信息、更正文档中的错别字）。

## extract_image — 公式提取

识别图片中的数学公式区域，裁剪并拼接为一张 PNG 图片返回。适用于：
- 拍摄的数学公式/方程
- 教材截图中的公式
- 手写公式

输出为 PNG 二进制（file_id），需通过 `download_file` 获取，也可通过 `create_cloud_doc` 保存到云端。

参数：
- `file_id`（必填）：上传后获得的图片文件 ID
- `extract_mode`（必填）：提取模式，固定为 `formula`（数学公式识别与裁剪拼接）
