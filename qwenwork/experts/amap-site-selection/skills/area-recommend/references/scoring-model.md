# 评分模型详细说明

本文档仅在需要深度解释评分逻辑时读取（如用户问"为什么分数高但星级低"、"分数怎么算的"等）。

---

## 模型概述

高德开店选址评估模型基于**行业内优质门店所在地块特征**构建算法，对目标区域进行五维综合评分。

> **使用建议**：评估数据仅供参考，建议用宏观数据把握方向，结合实地考察和物业条件综合判断。

---

## 分数逻辑

| 指标 | 说明 |
|------|------|
| **综合总分** | 基于行业优质点位模型综合计算，**不是**各维度分数的加和或平均 |
| **客群聚集分** | 该区域人口维度综合评价，分数越高越接近行业优质水平 |
| **潜客匹配分** | 该区域行业潜客综合评价，分数越高越接近行业优质水平 |
| **同行竞争分** | 该区域竞争综合评价，分数越高越接近行业优质水平 |
| **交通便利分** | 该区域交通条件综合评价，分数越高越接近行业优质水平 |
| **商业成熟分** | 该区域商业配套综合评价，分数越高越接近行业优质水平 |

**雷达图取值说明**：各维度得分取自当前评估区域内行业 100m×100m 地块得分的**平均值**。区域范围较大时，平均值可能偏低，但不影响局部优质点位的识别。

---

## 分数与星级的区别（核心概念）

**「分数」和「星级」是两套完全不同的评价体系，禁止混用或互相推断。**

| 评价体系 | 含义 | 衡量标准 |
|---------|------|---------|
| **分数（score）** | 与行业优质点位模型的**接近程度** | 越高越接近优质水平，≠数量，≠排名 |
| **星级（starLevel）** | 该指标数量在**城市内所有商圈中的相对排名** | 越高表示数量排名越靠前，≠与优质模型接近程度 |
| **综合总分** | 行业优质点位模型综合计算结果 | **不是**各维度分数简单加和 |

### 禁止的错误推理

- ❌ 不要将星级视为分数的映射（星级高 ≠ 分数高）
- ❌ 不要将分数视为数量或排名（分数高 ≠ 该维度数量多）
- ❌ 不要根据维度星级推断维度分数
- ❌ 不要将总分视为维度分数的简单加总
- ✅ 若分数和星级不一致，解释为「评价口径不同」，属正常现象

### 示例说明

**示例1：同行竞争分数8.88（高），但星级0.5星（低）**

- **分数8.88高**：表示该区域竞争环境与行业优质点位模型高度接近。优质奶茶点位不需要周边一家同行都没有，适度竞争反而说明消费需求存在。
- **星级0.5星低**：表示周边同业门店数量在城市内排名靠后（数量少）。
- **解读**：周边同类店少（数量少→星级低），但竞争环境恰好符合行业优质模型（结构合理→分数高）。两者不矛盾。

**示例2：交通便利星级高，但分数中等**

- **星级高**：该区域地铁/公交站数量在城市中排名靠前。
- **分数中等**：该区域交通特征（如人流方向、时段分布）与行业优质点位的交通模型匹配度中等。
- **解读**：有很多交通设施不等于交通结构对该业态最优。

## 指标解读标准

| 指标 | 解读标准 |
|------|---------|
| **score（综合评分）** | >8分优质选址，5-8分一般，<5分不推荐 |
| **starLevel（星级）** | 1-5星，3星为中等；4-5星优秀；1-2星较差 |
| **abovePercent（超越百分比）** | >70%为显著优势；30-70%为中等；<30%为竞争力不足 |

## 特殊指标定义

| 指标 | 定义 |
|------|------|
| **潜客** | 区域在高德地图上当月内搜索或导航过选址行业线下门店的群体（UV） |
| **搜索群体** | 当月在高德地图搜索过选址行业线下门店的UV，反映"有多少人在找这类店" |
| **导航群体** | 当月在高德地图导航去过选址行业线下门店的UV，反映"有多少人已经行动去了" |
| **潜客总数** | 搜索+导航去重后的总UV |
| **点位热力值** | 基于该点位在高德地图的搜索、导航、到达人数综合计算的指数 |
| **存续时长** | 基于该点位在高德地图上线时间推算已存续时长 |

## 统一解读原则

Agent 在解读评估结果时，应**围绕五维综合评估逻辑**，而不是孤立复述单一指标：

1. 先说明这是基于**五个维度综合评估**（客群聚集、潜客匹配、同行竞争、交通便利、商业成熟）
2. 概括最突出的**优势维度**（高分/高abovePercent）
3. 指出需关注的**短板或风险维度**（低分/低abovePercent）
4. 结合用户行业，给出简要经营建议
5. **不要绝对判断**选址好坏，数据仅供参考
