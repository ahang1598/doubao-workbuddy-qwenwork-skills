# 通用前置查询接口与参数推断规则（套件共享）

本文件被套件内全部技能共享引用。技能内引用路径：`./references/common-api.md`

所有接口通过 POST `${YT_GATEWAY_BASE_URL}/proxy/yt-xd-lite/openapi/v1/gateway` 调用，认证 Header 按 `gateway-auth.md` 规范携带。

---

## 1. POI 搜索 `common:place:text`

```json
{"action": "common:place:text", "params": {"keywords": "望京SOHO", "city": "北京", "extensions": "all"}}
```

返回：`id`（poiId）、`name`、`address`、`location`、`cityname`、`adname`

---

## 2. 行业类型查询 `common:atag:list`

```json
{"action": "common:atag:list", "params": {"name": "饮品"}}
```

返回多级行业树，取叶子节点的 `cid` 作为 category 编码（完整层级路径，如 `"621122;621376;621377"`）

**常见行业编码速查**：

| 用户表述 | 推荐搜索词 |
|---------|-----------|
| 餐厅、餐饮、饭店 | "中餐"或"西餐" |
| 奶茶、茶饮、咖啡 | "饮品" |
| 便利店、超市 | "便利"或"超市" |
| 美容、美发 | "美容" |
| 健身、运动 | "健身" |
| 教育、培训 | "教育" |
| 轻食 | "轻食" |

---

## 3. 行政区划查询 `common:adcode:tree`

```json
{"action": "common:adcode:tree", "params": {}}
```

返回全国行政区划树（省→市→区），每个节点含 `code` 和 `name`，响应 `data` 字段为数组，用 `.data[]` 遍历。

---

## 4. 品牌查询 `common:brand:list`

```json
{"action": "common:brand:list", "params": {"key": "星巴克"}}
```

## 默认参数推断规则

当用户未明确指定区域范围时，按以下规则自动推断 `regionType` 和 `regionInfo`：

| 用户表述 | regionType | regionInfo | 说明 |
|---------|-----------|-----------|------|
| "附近"、"周边"、"旁边"（未指定距离） | 3（半径） | "1" | **默认1公里半径** |
| "附近1公里"、"周边2km" | 3（半径） | "1"/"2" | 按用户指定的公里数 |
| "步行范围"、"走路能到的" | 0（步行） | "15" | 默认步行15分钟 |
| "开车能到"、"驾车范围" | 1（驾车） | "5" | 默认驾车5分钟 |
| "骑车范围" | 2（骑行） | "15" | 默认骑行15分钟 |
| "这个商场/小区里面" | 4（面域内） | "0" | 面域内模式 |

## 主动反问规则

**当用户提供的信息不完整时，应主动反问，而不是自行假设。**

| 缺失信息 | 反问示例 |
|---------|---------|
| 行业/业态 | "您计划开什么类型的店？比如餐饮、奶茶、便利店等" |
| 区域/城市（商圈推荐） | "您想在哪个城市或区域找店铺位置？" |
| 候选点位不足（多点位对比） | "您目前只提供了一个地点，请至少提供两个候选地址进行对比" |
| 地点模糊不可识别 | "您说的地方具体是哪里？能提供店名、商场名或详细地址吗？" |

**可以自动推断（无需反问）**：

| 信息 | 推断规则 |
|------|---------|
| regionType/regionInfo | 按上方默认参数推断规则自动填充 |
| num | 不传默认10，用户说"推荐几个"时用5，说"多推荐一些"时用20 |
| modules | 用户没指定维度时默认传 `base` |
| 客单价、毛利率 | 根据行业类型使用行业默认值（见 `financial-params.md`） |

---

## 通用约束

- **adcode 格式**：支持 6 位或 12 位行政区划编码，不能为 `"000000"`
- **category 编码**：必须使用完整层级路径（如 `621122;621376;621377`），不能只传末级编码
- **仅 POI 模式**：点位类评估必须传入 poiId，不支持传入 xy 坐标或自定义 WKT（regionType=5）
- **regionType 范围**：仅支持 0–4
