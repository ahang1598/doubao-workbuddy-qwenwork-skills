# 数据连接说明

本套件不连任何数据源也能运行。连上之后，检索类与核验类能力从"靠模型知识"升级为"逐条可溯源"。

---

## 设计原则

1. **只写能力，不绑供应商**。技能内部只声明需要哪类能力（法规检索 / 案例与裁判文书 / 企业工商与涉诉风险），运行时按能力语义自动发现已连接的数据源。换供应商不需要改技能。
2. **同类多家自动灾备**。先判断错误类型并做有限重试；当前来源仍失败后才切下一家。**本文档列出的候选按拼音排列，排列顺序不代表优先顺序**——运行时按能力匹配度选择。
3. **调用前先验结构**。匹配到候选后先确认返回结构符合预期再正式取数，不符合就切下一家。
4. **分级降级，权威引用拒绝降级**。见下。

---

## 三类能力

### 一、法规检索

| 项目 | 说明 |
|---|---|
| 用途 | 法律法规与法条检索、条文原文获取、时效状态判定 |
| 候选数据源 | 北大法宝、法智、元典（拼音序，非优先序） |
| 用到它的技能 | 律师法规检索、法条案例一键验真、起诉状分析与攻防策略、案情法律分析报告、各文书类技能的引用核验 |
| 未连接时 | **拒绝降级**——停止执行并告知需接入法规检索类数据源。不使用通用网页搜索或模型记忆生成法条 |

### 二、案例与裁判文书

| 项目 | 说明 |
|---|---|
| 用途 | 类案检索、裁判观点提取、按案号获取裁判文书详情 |
| 候选数据源 | 北大法宝、元典（拼音序，非优先序） |
| 用到它的技能 | 律师类案检索与报告、法条案例一键验真、律师模拟裁判报告、诉讼风险与清偿评估 |
| 未连接时 | **拒绝降级**——同上。绝不虚构案号或裁判要旨 |

### 三、企业工商与涉诉风险

| 项目 | 说明 |
|---|---|
| 用途 | 企业主体核验（名称、统一社会信用代码、法定代表人一致性）、股东与出资、经营与资质、涉诉与被执行记录、财产线索 |
| 候选数据源 | 企查查、天眼查、元典、Qibook（拼音序，非优先序） |
| 用到它的技能 | 律师企业尽调报告、起诉状生成（主体信息核验）、诉讼风险与清偿评估、合同相对方核验类能力 |
| 未连接时 | 允许降级：可用律师提供的信息继续，但结论对应位置强制标注 `[L4-主体信息待核验]`，且交付说明中写明降级原因 |

## 能力探测

技能内部只使用左列名称，运行时按关键词在已连接的数据源里做语义匹配：

| 能力类别 | 探测关键词（能力中文名 / 英文通用词 / 供应商名） |
|---|---|
| 法规检索 | 法规、法条、法律检索、regulation、statute、law search，及各候选供应商名 |
| 案例与裁判文书 | 案例、判例、裁判文书、case、judgment，及各候选供应商名 |
| 企业工商与涉诉风险 | 企业信息、工商、股东、涉诉、企业风险、company、business registration，及各候选供应商名 |

**另有两项可选能力**（不属上述三类，缺位不影响主流程）：

| 能力 | 用途 | 缺位时 |
|---|---|---|
| 浏览器访问 | 按案号到公开渠道取裁判文书全文（属实验性路径） | 该模式停用并提示改走类案检索 |
| 在线表格 | 案件台账团队协同 | 降级本地文件，标注"本地模式" |

**另有两项按需前置能力**（也不计入套件 23 个 Skill）：

| 能力 | 用途 | 缺位时 |
|---|---|---|
| 材料文字化 | 将不可直接读取的 PDF、扫描件、图片转为可分析文本 | 请求用户提供可读文本；具备安全本地读取条件时才受控兜底，并标注覆盖范围 |
| Word 生成 | 用户明确要求 DOCX | 降级为 Markdown；在线文档不得冒充 DOCX |

## 失败处理顺序

一次失败不等于能力不可用。每次调用按以下顺序处理：

1. 重新探测本次任务需要的能力，检查参数和预期返回结构。
2. 参数或格式错误：修正后重试一次，不原样重复。
3. 超时、限流、临时服务异常：同一能力额外重试最多两次。
4. 查询无结果：改写关键词、条件或范围，最多尝试三组有实质差异的查询。
5. 当前来源仍失败：切换另一个结构匹配的同类来源，不预设供应商顺序。
6. 登录、授权或权限错误：不对同一来源盲目重试；切换合法替代来源，没有替代时提示用户处理权限。
7. 所有合理候选均失败后，才按本文件和 `套件运行规则.md` 的能力矩阵降级；不得无限重试。

降级后必须说明受影响的能力、结论边界和待补动作，不向用户展示内部错误堆栈。

## 降级标注词表

降级运行时，结论里必须出现对应标注，不允许静默降级：

| 标注 | 含义 |
|---|---|
| `[L4-主体信息待核验]` | 工商信息未经数据源核验 |
| `[L4-信息待核验]` | 其他一般信息未经核验 |
| `[本地模式-在线表格未连接]` | 台账降级为本地文件 |
| `[待核验:事实]` / `[需引用:法条]` | 事实或法条待补 |

**不存在** `[L4-法条待验证]` 这类"标注后照样输出"的做法——法条与案例属权威引用，数据源缺位时是停下，不是标注放行。

## 怎么配

在千问办公的**数据连接**里启用对应连接器即可，套件会在下次运行时自动发现。

- 想知道当前哪些能力可用：喊**律师办案中枢**，它每次启动都会做一次健康检查并告诉你缺什么、会影响哪个技能
- 想把探测结果记进个人画像：喊**冷启动访谈**，它会把可用情况写进 `办案画像.md`
- 装套件时如勾选了随附的数据连接，会复用你已有的授权，无需重复登录

---

## 一句话总结

没有数据源，这个套件仍然能帮你写文书、理证据、管案件和期限；有了数据源，它写进文书的每一条法条和案例都是核验过的。**它不会为了看起来能干，给你编一条法条。**
