# 财产保全申请书模板（执行中保全）

执行立案时一并提交的财产保全申请书。法律依据：《民事诉讼法》第249条。

---

## 正文结构

```
（免责声明）

                    财产保全申请书

申请人：[同执行申请书的申请执行人信息]

被申请人：[同执行申请书的被执行人信息]

申请请求：
请求贵院依法采取财产保全措施，查封、扣押、冻结被申请人名下以下财产，价值以人民币XXX元为限：
1. [具体财产描述一]；
2. [具体财产描述二]；
3. [具体财产描述三]；
……
或查封、扣押、冻结被申请人的其他等值财产。

事实与理由：

申请人与被申请人[案由]一案，[管辖法院/仲裁委]已于YYYY年MM月DD日作出（XX）XX号[判决书/裁决书/调解书]，判令/裁决被申请人向申请人支付XXX元。该法律文书已于YYYY年MM月DD日生效。

被申请人至今未履行上述生效法律文书确定的义务。申请人已依法向贵院申请强制执行。

申请人有理由认为，被申请人存在转移、隐匿、变卖财产的可能，如不及时采取保全措施，将可能导致生效法律文书无法执行或难以执行。为保障申请人合法权益的实现，特依据《中华人民共和国民事诉讼法》第二百四十九条之规定，申请贵院对被申请人上述财产采取查封、扣押、冻结等保全措施。

此致
[管辖法院全称]

                              申请人：[签名/盖章]
                              YYYY年MM月DD日
```

---

## 保全请求的财产列明规则

1. **引用财产线索**：保全请求中列明的财产应与执行申请书「被执行人财产线索」部分一致
2. **价值限额**：保全总价值不得超过执行标的总额
3. **兜底条款**：末尾加"或查封、扣押、冻结被申请人的其他等值财产"
4. **措施匹配**：
   - 银行账户 → 冻结
   - 不动产 → 查封
   - 车辆 → 查封、扣押
   - 股权 → 冻结
   - 应收账款 → 冻结
   - 其他 → 视具体类型确定
