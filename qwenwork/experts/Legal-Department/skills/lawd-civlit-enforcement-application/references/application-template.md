# 强制执行申请书正文模板

按执行依据类型选用对应模板。标题层级遵循 [docx-format-standard.md](docx-format-standard.md)。

---

## 通用结构

所有类型共享以下结构，仅在称谓、管辖表述、附件清单上有差异：

```
（免责声明）

                    强制执行申请书

申请执行人：[全称/姓名]，[自然人：性别，YYYY年MM月DD日出生，身份证号码：XXXXXXXXXXXXXXXXXX，住所地：XX / 法人：统一社会信用代码：XXXXXXXXXXXXXXXXXX，住所地：XX，法定代表人：XXX，职务：XX]。
联系电话：XXXXXXXXXXX
委托代理人：XXX，XX律师事务所律师。（如有）

被执行人：[全称/姓名]，[同上格式]。
联系电话：XXXXXXXXXXX（如有）

申请事项：
一、依法强制被执行人履行[执行依据称谓]确定的全部义务；
二、被执行人向申请执行人支付本金XXX元；
三、被执行人向申请执行人支付一般债务利息XXX元（以XXX元为基数，按年利率X%，自YYYY年MM月DD日起暂计至YYYY年MM月DD日，此后至实际清偿之日止另行计算）；
四、被执行人向申请执行人支付迟延履行期间的加倍部分债务利息XXX元（以未履行本金XXX元为基数，按日万分之一点七五，自YYYY年MM月DD日起暂计至YYYY年MM月DD日，此后至实际清偿之日止另行计算）；
五、被执行人负担案件受理费XXX元；
六、本案执行费用由被执行人承担。

事实与理由：
  [案件基本事实概述]
  [执行依据内容摘要：XX法院/仲裁委于YYYY年MM月DD日作出XX号判决/裁决，判令/裁决……]
  [生效情况：该判决/裁决已于YYYY年MM月DD日生效。]
  [未履行事实：然而，被执行人至今未履行上述生效法律文书确定的义务。]
  [法律依据：根据《中华人民共和国民事诉讼法》第XXX条之规定，申请执行人特向贵院申请强制执行。]

被执行人财产线索：
  [按 property-classification.md 格式分类列出]

附件清单：
  [按依据类型差异化，见下方]

此致
[管辖法院全称]

                              申请执行人：[签名/盖章]
                              （或：委托代理人：XXX）
                              YYYY年MM月DD日
```

## 场景 A：法院判决书

**称谓**：依据（XX）XX号民事判决书
**致**：[一审法院全称]
**事实与理由法律依据段**：根据《中华人民共和国民事诉讼法》第二百四十三条、第二百五十条之规定
**附件清单**：
1. （XX）XX号民事判决书 副本 X份
2. 生效证明书 X份
3. 申请执行人身份证明 X份
4. 委托代理手续（如有） X份
5. 财产线索材料 X份

## 申请事项调整规则

| 情形 | 调整 |
|------|------|
| 无一般债务利息 | 删除第三项 |
| 非金钱给付义务 | 第二至五项改为具体行为义务描述 |
| 多个被执行人 | 按连带/按份分别列明各被执行人应承担的金额 |
| 已部分履行 | 在事实与理由中注明已付金额，申请事项中填入剩余金额 |
| 案件受理费被执行人不负担 | 删除对应项 |

## 段落写作要求

1. 事实段：客观、简洁，不掺杂主观评价
2. 金额数字：大写与小写并列（如"人民币壹佰万元整（¥1,000,000.00元）"）
3. 日期：统一使用"YYYY年MM月DD日"格式
4. 称谓：全文统一使用法律术语（申请执行人/被执行人），不用简称
5. 法条引用：条号准确，引用现行有效法律
