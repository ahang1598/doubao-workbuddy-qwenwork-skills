# 财产线索分类标准

将用户提供的原始财产线索材料智能分类为六大类，生成结构化清单附在申请书中。

---

## 分类规则

遇到以下关键词/信息特征时，自动归入对应类别：

### 一、银行账户

**识别关键词**：银行、账号、开户行、存款、余额、流水、账户
**必录信息**：
- 开户银行全称（精确到支行）
- 银行账号
- 账户类型（如可知）
**格式示例**：
```
被执行人在中国建设银行杭州XX支行开设账户，账号：XXXXXXXXXXXXXXXXXXXX。
```
**对应保全/执行措施**：冻结、扣划

### 二、不动产

**识别关键词**：房产、房屋、不动产、土地、产权证、房产证、坐落、建筑面积
**必录信息**：
- 不动产权证号 / 房产证号
- 坐落地址
- 建筑面积（如可知）
- 权利人（确认为被执行人名下）
**格式示例**：
```
被执行人名下位于XX市XX区XX路XX号XX室的房产一套（不动产权证号：XXXXXXXXX，建筑面积XX平方米）。
```
**对应保全/执行措施**：查封、评估拍卖

### 三、车辆

**识别关键词**：车辆、汽车、车牌、车架号、VIN、机动车
**必录信息**：
- 车牌号码
- 车辆品牌型号（如可知）
- 车架号/VIN（如可知）
**格式示例**：
```
被执行人名下机动车一辆（车牌号：浙AXXXXX，品牌型号：XX）。
```
**对应保全/执行措施**：查封、扣押

### 四、股权/投资权益

**识别关键词**：股权、股份、持股、投资、出资、工商、股东
**必录信息**：
- 持股公司全称
- 持股比例或出资额
- 统一社会信用代码（如可知）
**格式示例**：
```
被执行人持有XX有限公司XX%的股权（统一社会信用代码：XXXXXXXXXXXXXXXXXX）。
```
**对应保全/执行措施**：冻结、强制转让

### 五、应收账款/到期债权

**识别关键词**：应收账款、到期债权、欠款、合同款、工程款、第三人
**必录信息**：
- 第三人名称
- 债权金额或合同信息
- 到期日（如可知）
**格式示例**：
```
被执行人对XX公司享有应收账款XX万元（依据XXXX合同）。
```
**对应保全/执行措施**：冻结、提取

### 六、其他财产

**识别关键词**：知识产权、专利、商标、设备、存货、应收租金、理财产品
**必录信息**：
- 财产名称和描述
- 登记/证书编号（如有）
- 估计价值（如可知）
**格式示例**：
```
被执行人名下注册商标一枚（注册号：XXXXXXX，核定使用类别：第XX类）。
```
**对应保全/执行措施**：视具体类型确定

---

## 分类输出格式

在申请书「被执行人财产线索」一节中，按类别分列，无线索的类别不出现：

```markdown
被执行人财产线索：

一、银行账户
1. 被执行人在XX银行XX支行开设账户，账号：XXXX。

二、不动产
1. 被执行人名下位于……的房产一套。

三、车辆
（无线索则不列出本节）

四、股权/投资权益
1. 被执行人持有XX公司XX%股权。

五、应收账款/到期债权
（无线索则不列出本节）
```

## 线索来源标注

每条线索在内部工作底稿中标注来源：
- `[用户提供]` — 用户直接给出的信息
- `[律师企业尽调报告]` — 通过企业工商查询获得
- `[被执行人记录查询]` — 通过执行公开查询获得
- `[文书提及]` — 执行依据或附件中提及的财产信息

申请书正文中**不写来源标注**，仅在工作底稿中保留。

---

## 线索质量评估

| 质量等级 | 判断标准 | 处理 |
|----------|----------|------|
| 高 | 有具体账号/证号/地址 | 直接写入申请书 |
| 中 | 有大致信息但缺关键编号 | 写入申请书，标注已知信息，建议法院调查核实 |
| 低 | 仅有模糊线索（如"在某银行可能有存款"） | 写入申请书但标注"线索待核实"，建议申请法院调查令 |
