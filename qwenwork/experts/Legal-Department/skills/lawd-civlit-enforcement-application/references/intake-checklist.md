# 强制执行申请材料收集清单

按**执行依据类型**勾选。缺失项在开工前向用户列出；最低启动条件见 SKILL.md。

---

## 材料文字化（有 PDF/扫描件时）

| 项 | 必需 | 说明 |
|----|------|------|
| 材料解析已跑或用户确认跳过 | 有 PDF/扫描件时 ✓ | 将 `input/` 转为 `input/_text/*.md` + `*.json` |
| `input/_text/` 与主文书对应 | 有文字化时 ✓ | 相对路径与 `input/` 源文件一致 |

---

## 通用（所有依据类型）

| 材料 | 必需 | 说明 |
|------|------|------|
| 执行依据类型 | ✓ | 判决/裁定/调解书/仲裁裁决/公证债权文书/支付令 |
| 执行依据原件或副本 | ✓ | PDF/Word/图片均可，需含完整主文 |
| 申请执行人信息 | ✓ | 名称/姓名 + 身份证号或统一社会信用代码 + 地址 |
| 被执行人信息 | ✓ | 同上 |
| 生效日期或生效证明 | ✓（调解书除外） | 法院出具的生效证明书；调解书送达即生效 |
| 判决主文中的金额/利率/期限 | ✓ | 从执行依据主文中提取 |
| 财产线索材料 | 强烈建议 | 银行流水/不动产查询/车辆登记/工商信息等 |
| 委托代理手续 | 如有 | 授权委托书 + 律所函 |
| 已部分履行的证据 | 如有 | 转账记录、收条等（影响标的扣减） |

---

## 法院判决书

| 材料 | 必需 |
|------|------|
| 判决书（含主文和判项） | ✓ |
| 生效证明书 | ✓ |
| 送达回证（如有，确定生效日） | 建议 |

---

## 法院裁定书

| 材料 | 必需 |
|------|------|
| 裁定书 | ✓ |
| 生效证明书 | ✓ |

---

## 法院调解书

| 材料 | 必需 |
|------|------|
| 调解书 | ✓ |
| 签收记录（确定生效日） | 建议 |

---

## 仲裁裁决书

| 材料 | 必需 |
|------|------|
| 仲裁裁决书 | ✓ |
| 仲裁协议/仲裁条款 | 建议 |
| 送达证明 | ✓ |
| 未被法院撤销/不予执行的说明 | 建议 |

---

## 公证债权文书

| 材料 | 必需 |
|------|------|
| 公证债权文书 | ✓ |
| 执行证书 | ✓（必须有，否则无法申请执行） |
| 公证处信息 | ✓ |

---

## 支付令

| 材料 | 必需 |
|------|------|
| 支付令 | ✓ |
| 生效证明书 | ✓ |
| 被申请人未在异议期提出异议的证明 | 建议 |

---

## 财产线索材料（分类收集）

| 类别 | 典型材料 | 必需 |
|------|----------|------|
| 银行账户 | 银行流水、开户信息 | 如有 |
| 不动产 | 不动产查询结果、产权证复印件 | 如有 |
| 车辆 | 车辆登记信息 | 如有 |
| 股权 | 工商登记信息、股权结构 | 如有 |
| 应收账款 | 合同、应收款证明 | 如有 |
| 其他 | 知识产权证书、设备清单等 | 如有 |

---

## 渐进式引导（用户首次使用）

1. **第一轮**：执行依据类型 + 主文书
2. **第二轮**：当事人详细信息 + 生效日期/生效证明
3. **第三轮**：财产线索材料 + 已部分履行证据

---

## 最低启动条件

- [ ] 能确定执行依据类型
- [ ] 至少有主文书一份（含完整判项/主文）
- [ ] 申请执行人基本信息（名称 + 身份标识）

未达条件时：输出材料缺口清单（见 [material-gap-checklist.md](material-gap-checklist.md)），不生成文书。

---

## 与材料缺口清单的关系

核对后发现未达最低启动条件时：
- **必须**向用户展示 [material-gap-checklist.md](material-gap-checklist.md) 结构化清单
- 清单中「待补充」项须与本节各场景「必需/建议」列一一对应
