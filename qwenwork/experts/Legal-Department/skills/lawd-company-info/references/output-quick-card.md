# 企业速查卡 — 输出模板

快速核验模式下使用此模板输出。仅基于 3 个维度数据（工商基础 + 风险概览 + 经营状态）生成。

---

## 模板

```markdown
# 企业速查卡 · {企业全称}

| 字段 | 内容 |
|------|------|
| 企业全称 | {全称} |
| 统一社会信用代码 | {USCC} |
| 登记状态 | {状态} {✅/⚠️/❌} |
| 法定代表人 | {法代} |
| 成立日期 | {日期}（满 {N} 年） |
| 注册资本 | {金额}（实缴 {金额}，{比率}%） |

---

### 风险速览

| 指标 | 结果 |
|------|------|
| 诉讼 | {N} 件（被告 {N} 件） |
| 被执行 | {N} 件 / {金额}万 |
| 失信 | {否 ✅ / 是 ❌} |
| 限高 | {否 ✅ / 是 ❌} |
| 经营异常 | {否 ✅ / 是 ⚠️} |
| 行政处罚 | {N} 件 |

---

### 速评：{正常 ✅ / 需关注 ⚠️ / 高风险 ❌}

{一句话总结，不超过 50 字}

---

**数据来源：** 企业工商信息查询连接器（运行时探测）
**查询时间：** {YYYY-MM-DD HH:MM}

> 如需完整尽调报告或专项查询，请告诉我。
```

---

## 速评判定规则

**判定顺序（强制）**：先判高风险 → 再判需关注 → 最后判正常；**任一高级别条件命中即取高级别**，不得因同时满足低级别条件而降级。规则存在交叉歧义时一律取更保守的评级，并在速评中备注"取保守评级"。

| 级别 | 判定条件 |
|------|---------|
| **高风险 ❌** | 有失信/限高；或被执行金额大(>100万)；或已注销/吊销；或经营异常在列 |
| **需关注 ⚠️** | 有诉讼/被执行记录但无失信（件数多时结合频率、标的额评估是否升高风险档）；或有经营异常但已移出；或成立时间短（≤2年） |
| **正常 ✅** | 登记存续 且 失信=0 且 被执行=0 且 无经营异常 且 无诉讼记录 |

---

## 填写规则

1. 所有数值字段从连接器返回数据中直接提取，不做推算
2. 数据缺失的字段写 `—`（em-dash），不写"数据缺失"（速查卡追求简洁）
3. 速评一句话：直接给结论，不做分析展开
4. 不输出法律建议、不输出交叉分析、不输出待核实事项
5. 保持整卡简洁，让用户 10 秒内看完核心信息
