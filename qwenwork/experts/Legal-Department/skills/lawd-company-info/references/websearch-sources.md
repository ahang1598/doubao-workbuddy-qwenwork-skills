# WebSearch 补充数据源策略

在 MCP 结构化数据收集完成后，按条件触发 WebSearch 深度补充。WebSearch 是**辅助数据层**，不替代 MCP。

---

## 通用规则

1. **先 MCP 后 WebSearch**：WebSearch 仅在 MCP 数据收集完毕后触发，用于补充深度信息
2. **按条件触发**：不是每次都全部搜索，而是根据 MCP 结果判断哪些需要补充
3. **来源标注**：WebSearch 获取的数据须在报告中标注来源及检索时间
4. **频次上限**：单次综合报告 WebSearch 调用不超过 10 次（避免耗时过长）
5. **可靠性排序**：政府官网 > 行业协会 > 商业数据平台 > 新闻媒体

---

## 必做搜索（综合报告模式）

以下搜索在所有综合报告中**必须执行**：

### 1. 新闻舆情搜索

| 项目 | 内容 |
|------|------|
| 搜索策略 | `"{企业全称}" 纠纷 OR 处罚 OR 违规 OR 诉讼 OR 事故` |
| 备选策略 | `"{企业全称}" site:finance.sina.com.cn OR site:caixin.com` |
| 预期信息 | 重大负面事件、行业报道、媒体关注的合规问题 |
| 输出位置 | 风险评估 → 舆情风险 |
| 上限 | 仅关注近 3 年内的新闻 |

### 2. 信用中国查询

| 项目 | 内容 |
|------|------|
| 搜索策略 | `site:creditchina.gov.cn "{企业全称}"` |
| 备选策略 | `"{企业全称}" 信用中国 行政处罚 OR 红名单 OR 黑名单` |
| 预期信息 | 行政处罚公示、严重失信名单、守信红名单 |
| 输出位置 | 风险评估 → 信用记录 |

## 条件触发搜索

### 3. 裁判文书网查询

| 项目 | 内容 |
|------|------|
| 触发条件 | MCP 发现诉讼/被执行/失信记录 |
| 搜索策略 | `site:wenshu.court.gov.cn "{企业全称}"` |
| 备选策略 | `"{企业全称}" 裁判文书 判决 {案由关键词}` |
| 预期信息 | 判决书摘要、案由、标的额、判决结果 |
| 输出位置 | 风险评估 → 司法风险 → 重点案件详情 |
| 上限 | 最多搜索 3 件重大案件（按标的额排序） |
| 注意 | 裁判文书网可能需要登录才能查看全文，搜索结果可能仅含摘要 |

### 4. 基金业协会查询

| 项目 | 内容 |
|------|------|
| 触发条件 | 股东中存在基金/合伙企业（名称含"投资""基金""合伙"） |
| 搜索策略 | `site:amac.org.cn "{基金/管理人名称}"` |
| 备选策略 | `"{基金名称}" 基金业协会 备案` |
| 预期信息 | 基金备案编号、备案状态、管理人登记状态、基金类型 |
| 输出位置 | 股权结构 → 股东合规性说明 |
| 提示 | 未备案的私募基金存在合规风险，应在报告中标注 |

### 5. 行业资质查询 — 医疗器械

| 项目 | 内容 |
|------|------|
| 触发条件 | 经营范围含"医疗器械" |
| 搜索策略 | `site:nmpa.gov.cn "{企业全称}"` |
| 备选策略 | `"{企业全称}" 医疗器械注册证 OR 生产许可证` |
| 预期信息 | 注册证编号、产品名称、有效期、生产许可证信息 |
| 输出位置 | 行业资质与许可证 |

### 6. 行业资质查询 — 建筑业

| 项目 | 内容 |
|------|------|
| 触发条件 | 经营范围含"建筑""施工""工程" |
| 搜索策略 | `site:jzsc.mohurd.gov.cn "{企业全称}"` |
| 备选策略 | `"{企业全称}" 建筑资质 OR 施工许可` |
| 预期信息 | 资质等级、资质类别、有效期、是否有不良行为记录 |
| 输出位置 | 行业资质与许可证 |

### 7. 行业资质查询 — 食品

| 项目 | 内容 |
|------|------|
| 触发条件 | 经营范围含"食品" |
| 搜索策略 | `"{企业全称}" 食品经营许可证 OR 食品生产许可证` |
| 预期信息 | 许可证编号、许可范围、有效期 |
| 输出位置 | 行业资质与许可证 |

### 7b. 行业资质查询 — 互联网/软件

| 项目 | 内容 |
|------|------|
| 触发条件 | 经营范围含"互联网信息服务""增值电信""软件开发" |
| 搜索策略 | `"{企业全称}" ICP许可证 OR ICP备案 OR 增值电信业务经营许可` |
| 备选策略 | `site:beian.miit.gov.cn "{企业全称}"` |
| 预期信息 | ICP备案号/许可证号、业务种类、有效期 |
| 输出位置 | 行业资质与许可证 |

### 8. 高校/科研人员任职验证

| 项目 | 内容 |
|------|------|
| 触发条件 | 股东/发明人/高管疑似高校或科研院所人员（通过 MCP 人员信息或专利发明人信息判断） |
| 搜索策略 | `"{人员姓名}" "{疑似单位名称}" 教授 OR 研究员 OR 副教授 OR 博导` |
| 预期信息 | 任职单位、职务级别、研究方向、是否担任行政职务 |
| 输出位置 | 主要人员 → 人员交叉任职分析 |
| 法律意义 | 高校/科研人员兼职持股需单位审批，担任行政领导职务的限制更严格 |

### 9. 专利详情补充

| 项目 | 内容 |
|------|------|
| 触发条件 | MCP 返回发明专利且满足以下任一：①发明人同时在其他企业任职（交叉模式2相关）②专利为公司核心业务且涉及投融资/合作对价 ③专利状态显示异常（如"未缴年费"） |
| 搜索策略 | `"{专利名称}" "{申请号}" site:cnipa.gov.cn` |
| 备选策略 | `"{专利名称}" 专利 法律状态 OR 无效宣告` |
| 预期信息 | 专利当前法律状态、是否有无效宣告请求、年费缴纳情况 |
| 输出位置 | 知识产权 → 专利详情 |
| 上限 | 仅对核心专利（发明专利）补充查询，实用新型/外观一般跳过 |

### 10. 国家企信公示系统补充

| 项目 | 内容 |
|------|------|
| 触发条件 | MCP 某维度数据缺失（如年报、经营异常详情） |
| 搜索策略 | `site:gsxt.gov.cn "{企业全称}"` |
| 备选策略 | `"{企业全称}" 国家企业信用信息公示 年报 OR 经营异常` |
| 预期信息 | 年报数据、经营异常列入/移出记录、行政处罚详情 |
| 输出位置 | 对应缺失章节 |

## 数据来源标注格式

WebSearch 获取的数据在报告中必须标注来源：

```
> 来源：{网站名称}（{URL 域名}），检索时间：{YYYY-MM-DD}
```

示例：
```
> 来源：中国裁判文书网（wenshu.court.gov.cn），检索时间：2026-05-21
> 来源：中国证券投资基金业协会（amac.org.cn），检索时间：2026-05-21
> 来源：国家药品监督管理局（nmpa.gov.cn），检索时间：2026-05-21
```

## 搜索失败处理

| 场景 | 处理 |
|------|------|
| 搜索无结果 | 标注"未查询到相关公开信息"，不影响报告生成 |
| 网站不可访问 | 标注"该来源暂不可访问"，继续其他搜索 |
| 结果疑似不准确 | 标注"搜索结果待人工核实"，不作为确定性结论 |
| 超出频次上限 | 按优先级截断，优先保证必做搜索 + 高风险触发搜索 |

---

## 搜索优先级排序（当接近频次上限时）

1. 必做：新闻舆情 + 信用中国
2. 高优先：裁判文书（已发现诉讼风险时）
3. 中优先：行业资质验证、基金备案
4. 低优先：专利详情补充、人员背景验证、企信公示补充
