# 法律分析框架

执行第五步「分析处理」时**必须先阅读本文件**。本文件定义：风险严重性判断标准、跨维度关联模式、待线下核实事项触发规则、经营范围-资质匹配表。

---

## 一、风险严重性判断标准

### 1.1 司法风险评估矩阵

#### 诉讼严重性

| 指标 | 低风险 | 中等风险 | 高风险 |
|------|--------|---------|--------|
| 作为被告案件数 / 公司年龄 | < 0.5件/年 | 0.5-2件/年 | > 2件/年 |
| 累计标的额 / 注册资本 | < 10% | 10%-50% | > 50% |
| 同一原告重复起诉 | 无 | 2次 | ≥3次（提示持续履约问题） |
| 案由集中度 | 分散 | 某类案由占比>50% | 某类案由占比>80%（系统性问题） |

#### 被执行/失信严重性

| 指标 | 低风险 | 中等风险 | 高风险 |
|------|--------|---------|--------|
| 未结被执行案件数 | 0 | 1-2件 | ≥3件 |
| 被执行总金额 / 注册资本 | < 5% | 5%-30% | > 30% |
| 是否列入失信名单 | 否 | 曾列入已移出 | 当前在列 |
| 是否被限制高消费 | 否 | — | 是（法人被限高） |

#### 法律分析输出模板

```
**法律分析**：企业近{N}年涉及{案由}纠纷{X}起，累计标的额{Y}万元，占注册资本{Z}%。
{模式判断，如"其中3起为同一原告，提示可能存在持续性履约问题"}。
风险严重性：{低/中/高}。

**建议**：{具体建议}
```

### 1.2 行政处罚严重性

| 指标 | 低风险 | 中等风险 | 高风险 |
|------|--------|---------|--------|
| 处罚次数（近3年） | 0-1次 | 2-3次 | ≥4次（系统性合规问题） |
| 处罚金额 | < 5万元 | 5-50万元 | > 50万元 |
| 处罚类型 | 一般性违规 | 安全/环保/税务 | 涉及资质/许可吊销 |
| 重复性 | 不同事由 | 同类事由重复 | 同一事由≥3次（整改无效） |
| 近期性 | > 2年前 | 1-2年内 | 6个月内 |

### 1.3 经营异常严重性

| 情况 | 风险判断 |
|------|---------|
| 曾列入已移出，原因为"未按时公示年报" | 低风险（常见疏忽） |
| 曾列入已移出，原因为"通过登记住所无法联系" | 中风险（经营地址异常） |
| 当前在列，原因为"公示信息弄虚作假" | 高风险（诚信问题） |
| 多次反复列入移出 | 高风险（管理混乱） |

## 二、跨维度风险关联模式

Agent 在完成数据收集后，**必须**逐一检查以下 5 个模式。匹配时在报告「风险交叉分析」节输出。

### 模式 1：内部不稳定

| 项目 | 内容 |
|------|------|
| 触发数据点 | ① 近3年法人变更≥2次 OR 股东变更≥3次 ② 主要人员变动频繁（董事/监事变更≥3次） ③ 公司成立≤5年 |
| 匹配条件 | 满足①②中任一 + ③ |
| 风险推断 | 企业经营稳定性存疑，内部治理可能存在问题 |
| 建议 | 建议核实频繁变更原因，了解是否存在股东纠纷、经营方向调整或实控人变化 |

### 模式 2：知识产权权属争议风险

| 项目 | 内容 |
|------|------|
| 触发数据点 | ① 核心发明人同时为公司股东/高管 ② 该发明人在其他企业或高校/科研机构任职 ③ 专利申请期间该人同时在其他单位任职 |
| 匹配条件 | ①+②+③ 同时满足 |
| 风险推断 | 存在专利被认定为"职务发明"归属其他单位的风险 |
| 建议 | 建议核实发明人与任职单位是否签署了知识产权归属协议，确认专利不构成职务发明 |

### 模式 3：财务困境信号

| 项目 | 内容 |
|------|------|
| 触发数据点 | ① 作为被告的诉讼≥3件 ② 存在被执行记录（未结） ③ 曾列入经营异常名录 ④ 存在股权冻结/质押 |
| 匹配条件 | 满足≥3项 |
| 风险推断 | 企业可能面临财务困境，偿债能力存疑 |
| 建议 | 合作前建议要求提供近期财务报表，或要求提供履约担保 |

### 模式 4：系统性合规缺陷

| 项目 | 内容 |
|------|------|
| 触发数据点 | ① 存在行政处罚记录（近3年） ② 曾列入经营异常 ③ 经营范围应持有的资质/许可证缺失或过期 ④ 税务相关异常（如地址注册在税收洼地但实际经营在他处） |
| 匹配条件 | 满足≥2项 |
| 风险推断 | 企业合规管理体系薄弱，存在系统性风险 |
| 建议 | 合作前建议全面核查资质有效性，了解处罚整改情况 |

### 模式 5：空壳公司嫌疑

| 项目 | 内容 |
|------|------|
| 触发数据点 | ① 注册资本≥1000万且实缴=0或极低 ② 成立时间≤2年 ③ 无专利/商标/软著 ④ 主要人员≤2人 ⑤ 无分支机构、无对外投资 ⑥ 联系方式缺失或无法验证 |
| 匹配条件 | 满足≥4项 |
| 风险推断 | 企业可能为空壳公司，不具备实际经营能力 |
| 建议 | 建议进行实地走访，核实经营场所和实际业务开展情况 |

## 三、待线下核实事项触发规则

以下条件满足时，自动在"待线下核实事项清单"中生成对应条目：

| 触发条件 | 生成事项 | 核实方式建议 | 优先级 |
|---------|---------|-------------|--------|
| 近3年股权变更≥3次 | 核实历次股权转让的定价依据及纳税合规性 | 索取股权转让协议、完税证明 | 高 |
| 认缴远大于实缴（实缴率<30%） | 核实股东出资能力及出资计划 | 索取出资承诺函或银行验资证明 | 中 |
| 核心发明人在其他企业/机构任职 | 核实知识产权权属，确认无职务发明争议 | 索取任职单位出具的无争议证明 | 高 |
| 存在共有专利 | 核实共有专利的实施权和商业化安排 | 索取合作协议或补充协议 | 高 |
| 实控人为高校/科研院所人员 | 确认是否已获得任职单位兼职创业审批 | 索取审批或备案文件 | 高 |
| 存在被执行/失信记录 | 核实债务化解方案和当前财务状况 | 索取近期财务报表和债务清偿计划 | 高 |
| 经营范围含特殊行业但未查到对应资质 | 核实是否持有相关资质或是否在申请中 | 索取资质证书复印件 | 中 |
| 存在不动产但产权受限 | 核实不动产权属是否影响正常经营 | 索取不动产权证及相关限制协议 | 中 |
| 存在对外担保 | 核实担保详情及被担保方信用状况 | 索取担保合同及被担保方资信证明 | 中 |
| 关联企业存在经营异常/严重违法 | 核实关联交易情况及风险隔离措施 | 索取关联交易协议及审计报告 | 中 |
| 前轮投资方享有特殊权利（如查到融资信息） | 核实前轮投资协议中的反稀释、优先清算等条款 | 索取增资协议和股东协议 | 高 |
| 商标状态为"无效"或"驳回" | 核实品牌使用权是否受影响 | 确认是否有替代商标或许可协议 | 低 |
| 法人变更频繁（近3年≥2次） | 核实变更原因及当前管理层稳定性 | 进行管理层访谈 | 中 |

## 四、经营范围-资质匹配表

当经营范围含以下关键词时，应检查是否持有对应资质：

| 经营范围关键词 | 应持有资质 | 缺失风险说明 |
|-------------|-----------|------------|
| 医疗器械生产 | 医疗器械生产许可证 | 无证生产属违法行为，可能面临停产整改及罚款 |
| 医疗器械经营/销售（第三类） | 医疗器械经营许可证 | 无证经营面临行政处罚 |
| 食品生产 | 食品生产许可证 | 无证生产属重大食品安全违法行为 |
| 食品经营/销售 | 食品经营许可证 | 无证经营面临行政处罚 |
| 药品生产 | 药品生产许可证 + GMP 证书 | 无证生产可能构成刑事犯罪 |
| 药品经营 | 药品经营许可证 + GSP 证书 | 无证经营面临严厉处罚 |
| 建筑施工/工程承包 | 建筑业企业资质证书 + 安全生产许可证 | 无资质承揽工程合同可能无效 |
| 危险化学品 | 危险化学品经营许可证 | 无证经营属严重安全违法 |
| 道路运输 | 道路运输经营许可证 | 无证运营面临处罚 |
| 互联网信息服务 | ICP 经营许可证 / ICP 备案 | 经营性网站无 ICP 许可属违规 |
| 劳务派遣 | 劳务派遣经营许可证 | 无证派遣面临处罚及合同效力问题 |
| 进出口 | 对外贸易经营者备案 | 影响进出口业务合法性 |
| 特种设备 | 特种设备生产/使用许可证 | 安全生产重大违法 |
| 金融/贷款/融资担保 | 金融许可证/融资担保业务经营许可证 | 无牌照经营可能构成非法金融活动 |
| 人力资源服务 | 人力资源服务许可证 | 无证经营面临处罚 |
| 安防/安保 | 安防工程企业资质 / 保安服务许可证 | 无证经营面临处罚 |

### 匹配检查逻辑

1. 提取目标企业经营范围文本
2. 逐行扫描上表关键词
3. 匹配到时：在 MCP 返回的行政许可/资质数据中搜索对应证书
4. 未找到对应证书 → 在报告「行业资质与许可证」章节标注：

```
⚠️ 经营范围含"{关键词}"，但未在公开数据中查询到对应的{资质名称}。
可能原因：①资质信息尚未公示 ②通过子公司持有 ③正在申请中 ④确实缺失
建议：核实企业是否持有该资质的有效证书。
```

## 五、风险评级汇总规则

### 分维度评级

| 维度 | 低风险 | 中等风险 | 高风险 |
|------|--------|---------|--------|
| 工商合规 | 经营正常，无异常记录 | 曾有经营异常但已移出 | 当前在经营异常/严重违法名录 |
| 司法风险 | 无诉讼或仅作为原告 | 少量被告诉讼（标的额<注册资本10%） | 多起被告诉讼/被执行/失信 |
| 股权稳定性 | 近3年无重大变更 | 1-2次合理变更 | 频繁变更/股权冻结/实缴极低 |
| 经营连续性 | 存续≥5年，业务正常 | 存续3-5年，偶有波动 | 新设<3年 + 多项风险指标 |
| 知识产权 | 有自主IP，权属清晰 | 有IP但存在共有/权属待确认 | 无IP / IP存在明显争议风险 |

### 综合评级

- **低风险**：所有维度均为低风险，或仅1个维度为中等风险
- **中等风险**：2个以上维度为中等风险，或1个维度为高风险
- **高风险**：2个以上维度为高风险
- **极高风险**：3个以上维度为高风险，或触发交叉模式3（财务困境）/模式5（空壳嫌疑）
