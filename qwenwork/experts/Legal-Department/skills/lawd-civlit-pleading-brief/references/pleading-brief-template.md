# 代理词 Word 正文模板（分场景）

扩写时从已确认的 Markdown 提纲映射到下列结构。标题层级遵循 [docx-format-standard.md](docx-format-standard.md)。

---

## 通用首部

```
致：[XX]人民法院 / [XX]仲裁委员会

案号：
案由：
我方当事人：
我方诉讼/仲裁地位：
代理人：XXX 律师，XXX律师事务所

（免责声明段）
```

## 场景 A：一审原告

```
代理词

尊敬的审判长、审判员：

一、开篇意见
   我方认为，原告的诉讼请求事实清楚、证据充分、于法有据，恳请法庭依法支持原告全部（或部分）诉讼请求。

二、案件事实
   （按争点或时间线，事实+ [证X-PX]）

三、诉讼请求及理由
   （与起诉状诉请逐项对应）

四、争议焦点及我方意见
   （一）关于焦点1……
   （二）关于焦点2……

五、对被告答辩及证据的回应
   （针对答辩状核心抗辩）

六、综合意见

综上所述，……恳请法庭依法判决：……

此致
敬礼

XXX律师事务所
代理人：XXX
年  月  日
```

## 段落写作要求

1. 每节首句为**主题句**（立场明确）。
2. 事实段：先结论后展开，证据索引紧跟事实句。
3. 法律段：条文 → 要件 → 本案涵摄 → 结论。
4. 类案段：「参照XXX案，裁判要旨为……，与本案相同/相似之处在于……」
5. 反驳段：先引对方观点（可概括），再「然而……」「事实上……」
6. 禁止口语、情绪化表达；禁止「笔者认为」等学术用语。
