# 案号提取、标准化与示例

执行**模式B（按案号取裁判文书全文）步骤 B1** 时以本节为权威细则；主文件 `SKILL.md` 仅保留模式简介与分流规则；完整步骤索引与硬约束见 `references/mode-b-fetch-judgment.md`。

> 迁入说明：本文件原属 `lawd-case-detail-query`（旧名「裁判文书网抓取/案号取全文」），已并入 `律师类案检索与报告` 模式B。下文出现的「步骤 1」「步骤 4」「步骤 5」分别对应模式B 工作流（references/mode-b-fetch-judgment.md） 的 **B1 / B4 / B5**，规则内容未作改动。

## 裁判文书网标准形态（校验目标）

**caseNo** 须与站点列表/检索中常见的展示一致，采用：

- **年份四位**为半角阿拉伯数字 `0`–`9`；
- **年份外括号**为**全角圆括号** `（` U+FF08、`）` U+FF09；
- **整串无空白**（无空格、制表符等）。

**示例（标准 caseNo）**：`（2026）最高法刑申3号`

标准化与步骤 5 比对均以**与该字符串规范完全一致**为目标（逐字符相等，含括号形态）；**禁止**把全角括号改为半角「以方便输入」。

## 格式标准化规则（步骤 1.1）

以下变换**仅**整理书写形式，**禁止**改动四位年份数字、法院及审级代字、案件类型代字、顺序号数字的**取值**（全角数字与半角数字表示同一数码时，转为半角视为排版统一，不增删数位）。

1. **去首尾空白**，确定待处理字符串边界；中间若含空白，在完成第 2～5 条后由第 7 条**全部删除**，**不作为**最终 **caseNo** 的一部分保留。
2. **全角数字 → 半角**：将 Unicode 区间 U+FF10～U+FF19 的全角数字转为半角 ASCII 数字（数位个数不变）。**须在本条之后**再应用第 3～4 条年份与括号规则，以免 `YYYY年` 或「首四位为年份」无法识别。
3. **年份段外括号统一为全角**：凡**直接包裹四位半角年份数字**的括号，无论是半角 `(` `)` 还是全角 `（` `）`，一律规范为 **`（YYYY）`**。案号中不应在年份段以外另行插入括号；若输入出现破坏配对或多组年份括号的歧义结构，须请用户澄清，**禁止**猜测性重组。
4. **年份与括号**：
   - 若案号**已**以 `（YYYY）` 或 `(YYYY)` 开头（经第 2～3 条后应为 `（YYYY）`），**不**在年份后追加「年」。
   - 若案号以 **`YYYY年`** 开头（Y 为半角数字；全角年份应先经第 2 条转换）且该段尚未被括号包裹，将首部改为 **`（YYYY）`** 并去掉该处的 **`年`**。
   - 若案号以连续四位半角数字开头，**无**括号、**无**紧跟的「年」，且其后紧邻法院代字（如 `沪`、`京`、`最高法`），仅在**结合用户上下文可唯一认定**该四位为年份时，在该四位外添加 **`（YYYY）`**（全角括号）；认定存疑时须请用户确认，**禁止**猜测。
5. **结尾「号」**：若除末尾外主体已具备完整案号结构（年份段 + 法院/类型/序号），仅缺结尾 **`号`**，可补全 **`号`**。
6. **空白与实质字符**：在应用第 7 条之前，**不得**通过插入或删除**非空白**字符来改变年份、法院/审级代字、案件类型代字、顺序号；**不得**借「疏密排版」改动实质内容。连续空白可先合并为单空格以便人工核对（可选），但最终 **caseNo** 以第 7 条为准。
7. **删除全部空白字符（本技能强制）**：在完成第 2～5 条后，从字符串中移除**所有**空白类字符（含 ASCII 空格、制表符、全角空格 U+3000、不换行空格 U+00A0 等；实现上可按字符的 Unicode 空白语义或语言自带的 `isspace` 判定）。得到的 **caseNo** 为**仅由非空白字符组成的连续串**，**不得**再含任何空格或空白；**步骤 4 搜索框键入、步骤 5 与 caseNo 的相等判定、异常处理中「实际用于检索的 caseNo」**均只使用该串。步骤 5 从列表解析出的案号须经**与步骤 1 相同顺序**的 1.1 全流程（含本条）后再与 **caseNo** 比较。

## 禁止事项（步骤 1.2）

- **禁止**在缺乏用户确认时，修改顺序号位数（除全角转半角外）、替换案件类型代字、或改动年份/法院代字。
- **禁止**将无法唯一映射到常见结构的输入**猜测**补全为某个案号；若缺少年份等关键段，应请用户补全，而非编造。

## 对用户说明（步骤 1.3）

若原始输入与标准化后的 **caseNo** 在字面上不一致（例如 `YYYY年` 改为 `（YYYY）`、半角括号改为全角、去掉词间空格和空白），在**首次执行步骤 4 搜索前**用一句话告知用户：已整理为裁判文书网常见形态的 `caseNo`（全角年份括号、无空格），后续检索与步骤 5 比对均以 **caseNo** 为准。**不得**表述为用户「写错案号」，除非用户自行承认。

## 验证（步骤 1.4）

1. 经 1.1 后仍缺少年份、法院代字或明显不构成案号结构 → 提示用户补充或修正输入。
2. **形态自检**：`caseNo` 须以 **`（` + 四位半角数字 + `）`** 开头，且全串无空白；否则视为标准化未完成，回到 1.1 修正或请用户确认。

## 非规范写法与标准化对照（实质要素不变）

用户口语或转载中常见**缺括号、年份后多写「年」**等，可按步骤 1.1 整理为检索用 **caseNo**（下表右侧）。**不得**在未经用户确认时改动顺序号位数或代字。

| 常见非规范/混排写法 | 标准化后（示例目标 caseNo） |
|--------------------|------------------------------|
| `2017年沪01刑更761号` | `（2017）沪01刑更761号` |
| `（2025）辽 10 执复 24 号`（词间带普通空格，常见于复制/OCR） | `（2025）辽10执复24号` |
| `(2017)沪01刑更761号` | `（2017）沪01刑更761号` |
| 年份为全角数字（U+FF10～U+FF19）且缺结尾「号」 | `（2017）沪01刑更761号` |
| `2017沪01刑更761号`（无「年」也无括号，但年份四位在首且后接法院代字） | `（2017）沪01刑更761号` |

说明：最后一行仅在**上下文可唯一判定**首四位为年份（其后紧跟法院代字如 `沪`/`京` 等）时适用；若无法判定，应请用户补全或确认，**禁止**猜测。

**匹配原则**：步骤 5 从列表页解析每条结果的展示案号，经与步骤 **1.1 相同顺序的全流程规范化（含第 7 条删除全部空白）**后，与 **caseNo** 做**字符串完全相等**比较；**不得**借机修改年份、法院及审级代字、案件类型代字、顺序号等实质要素。
