# 保存路径与文件命名

服务于 `律师类案检索与报告` **模式B（按案号取裁判文书全文）**，原属 `lawd-case-detail-query`（旧名「裁判文书网抓取/案号取全文」）。下文「步骤 1」对应模式B 工作流（references/mode-b-fetch-judgment.md） 的 **B1**。

## 保存路径

所有模式B 生成的文件统一保存到：

```
{当前工作区}/outputs/
```

**落盘前检查（与 SKILL 硬约束及本节「同名文件」一致）**：

- 写入前须确认该目录可写；若创建目录或写入失败，按模式B 工作流（references/mode-b-fetch-judgment.md）异常处理中的「output 目录或权限失败」执行，**禁止**改写到系统临时目录并声称已完成交付（除非用户明确同意其他路径）。
- 建议预留足够磁盘空间（尤其 PDF）；若写入中报错「No space left」等，立即停机并告知用户。

## 文件命名规则

- **Markdown**：`{案号}_案例详情.md`（`{案号}` 为步骤 B1 的 **caseNo**；写入文件名前经 `sanitize_filename` 处理）  
  示例案号：`（2023）京01民初1234号` → `2023_京01民初1234号_案例详情.md`
- **PDF**：`{案号}_案例详情.pdf`  
  示例：`2023_京01民初1234号_案例详情.pdf`  
  **只能通过**「浏览器页面操作」能力的 **PDF 导出/打印为 PDF** 动作生成（能力语义，不写死工具名）；若运行时首写路径在 `artifacts/`、`snapshot/` 等，**须再复制/移动**为上述 `output` 目录下的终态文件名，**以 `output` 中文件为准**。匹配到的浏览器能力**不提供** PDF 导出动作时，只交付 Markdown 并如实说明「本次未生成 PDF」，**禁止**伪造 PDF 路径或用截图拼接冒充 PDF。


## 文件名安全处理（sanitize）

将案号转为文件名时：

1. 将以下字符替换为下划线：`\ / * ? : " < > | ( ) （ ）` 与空格（半角、全角括号均处理）。
2. 合并连续下划线为单个下划线。
3. 去掉首尾下划线。

与 `scripts/convert_to_md.py` 中 `sanitize_filename` 保持一致，避免脚本产出路径与 Agent 手工命名不一致。

## 同名文件与增量保存

- **禁止**在未经用户确认的情况下**静默覆盖**已有 `{案号}_案例详情.md` / `.pdf`。
- 若用户同意保留历史版本，可使用带时间戳的文件名，例如：`{案号}_案例详情_YYYYMMDD_HHMMSS.md`（与 `convert_to_md.py` 的 `--on-collision timestamp` 行为对齐）。
- 若用户明确要求覆盖，须在对话中留下明确依据后再写入。
