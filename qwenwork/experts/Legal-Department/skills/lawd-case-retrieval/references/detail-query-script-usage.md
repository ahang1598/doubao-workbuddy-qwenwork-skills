# 模式B 辅助脚本与浏览器页面操作参考

本文件服务于 `律师类案检索与报告` **模式B（按案号取裁判文书全文）**，原属 `lawd-case-detail-query`（旧名「裁判文书网抓取/案号取全文」）。下文出现的「步骤 1 / 4 / 5 / 9 / 10」对应模式B 工作流（references/mode-b-fetch-judgment.md） 的 **B1 / B4 / B5 / B9 / B10**。

> **重要改造说明**：原技能依赖旧版平台自带的 `browser_use` 浏览器自动化工具，该方案在千问办公**已作废**。模式B 现改用「**浏览器页面操作**」能力（千问办公内置浏览器连接器），按 SKILL 连接器写法三铁律**只写能力语义、不写死工具名**；探测、匹配与 A 档降级规则见主文件「模式B 的浏览器能力段」。本文件只描述**需要浏览器做什么动作**，不指定用哪个工具名执行。

## 1. normalize_case_no_for_search.py（步骤 B4 搜索框前强制）

从任意来源得到的案号**原始串**中删除**全部** Unicode 空白（`str.isspace`）及常见零宽/BOM 噪声，向 stdout 输出**单行**结果，供整段复制进裁判文书网搜索框。与 `detail-query-case-no-examples.md` 步骤 1.1 第 7 条一致；**不**替代步骤 B1 的括号/全角数字等完整标准化，仅保证**无空白**。

**工作目录**：下列命令默认在**本技能包根目录**（`lawd-case-retrieval/`，含 `scripts/` 子目录）下执行；若当前 shell 不在该目录，请 `cd` 到技能根或使用脚本的绝对路径。

### 用法

```bash
python3 scripts/normalize_case_no_for_search.py "（2025）辽 10 执复 24 号"
# 输出：（2025）辽10执复24号
```

从 stdin 读取（注意勿额外换行污染案号时可用 `printf`）：

```bash
printf '%s' '（2025）辽 10 执复 24 号' | python3 scripts/normalize_case_no_for_search.py
```

### 退出约定

- 成功：stdout 仅为去空白后的串（末尾无换行亦可由调用方接受；脚本 `write` 不写尾换行，与 shell 行为一致时可显式换行）。
- 失败：去除空白后为空 → stderr 提示，**非零**退出码。

**Agent 约束**：步骤 B4 键入前**必须**完成去空白（本脚本或等价手工按 1.1§7）；**禁止**把含空格的采集串直接粘贴进搜索框。

## 2. convert_to_md.py

将裁判文书内容转换为 Markdown 文件。

### 常用参数

| 参数 | 说明 |
|------|------|
| `--dry-run` | 不写入文件；向 stdout 输出拟写入路径与内容摘要（字符数等），并输出 `DRY_RUN_PATH:<path>` |
| `--on-collision` | `abort` \| `timestamp` \| `overwrite`。默认 `timestamp`：同名存在时自动改用带时间戳文件名，避免静默覆盖 |

### 命令示例

```bash
python3 scripts/convert_to_md.py \
  --case-no "(2023) 京 01 民初 1234 号" \
  --court "北京市第一中级人民法院" \
  --date "2023-06-15" \
  --parties "原告：张三；被告：李四" \
  --cause "劳动争议" \
  --content "完整文书内容..." \
  --judgment-result "判决如下：..." \
  --dispute-focus "争议焦点：..." \
  --legal-basis "援引法条：..." \
  --output-dir "{当前工作区}/output"
```

仅预览（不写盘）：

```bash
python3 scripts/convert_to_md.py --dry-run \
  --case-no "(2023) 京 01 民初 1234 号" \
  --court "北京市第一中级人民法院" \
  --date "2023-06-15" \
  --cause "劳动争议" \
  --content "完整文书内容..." \
  --output-dir "{当前工作区}/output"
```

成功写入后，stdout 会包含 `FILE_PATH:<path>`。

### 退出约定（供 Agent 解析）

- `FILE_PATH:<path>`：已成功写入。
- `DRY_RUN_PATH:<path>`：`--dry-run` 模式下拟写入路径。
- `FILE_EXISTS_ABORT:<path>`：`'--on-collision abort'` 且文件已存在时退出（非零退出码），Agent 应转用户确认或改用 `timestamp` /明确覆盖。

## 3. 浏览器页面操作：模式B 需要的动作清单（不写死工具名）

模式B 需要「浏览器页面操作」能力提供以下动作语义。**匹配到的工具实际参数名以 `qwenwork_mcp_tool_get` 返回的 schema 为准**；下表只说明动作语义与用途。

| 动作语义 | 模式B 用途 | 关键约束 |
|---|---|---|
| **导航**（打开指定网址） | 打开 `https://wenshu.court.gov.cn/`；进入检索结果详情页 | 不得用网页搜索或外站页面替代本站 |
| **读取页面内容**（取正文/DOM/可见文本） | 判定是否被拦登录；抓取列表页每条结果的案号文本；抓取详情页文书正文 | 页面未渲染完成时不得把空白当作已加载 |
| **输入**（向输入框写入文本） | 把经步骤 B4.0 去空白核对后的 **caseNo** 整段写入搜索框 | 串内**不得**含任何空白 |
| **点击**（点击元素/按钮/链接） | 提交检索；点开用户确认后的那一条结果；触发站内下载 | 步骤 B5 未完成核对前不得点开任意一条 |
| **截图** | 登录轮询取证；正文渲染状态取证；抓取失败时保留现场 | 截图不得替代文书正文 |
| **等待 / 滚动**（若能力提供） | 长文书懒加载：向下滚动到底并等待 2～3 秒后再读取或导出 | 未滚到底即读取会截断正文 |
| **导出 PDF / 打印为 PDF**（可选增强） | 详情页整页导出为 PDF | 见下文「PDF 落盘契约」；能力不提供时按缺失处理，不伪造 PDF |

**能力缺失的处理**：探测不到「浏览器页面操作」能力，或匹配到的工具 schema **不具备导航 + 页面内容读取**两项基础动作时，模式B 按主文件 **A 档降级**停止执行并提示用户启用浏览器连接器；**禁止**改用网页搜索摘要、外站转载或模型记忆冒充文书全文。

**导出 PDF 能力缺失**时不视为模式B 整体失败：Markdown 正文交付成功即可，只需在交付时明确「本次未生成 PDF」，**禁止**伪造 PDF 路径。

### 等待与滚动的执行要点

页面异步加载时，先等待再读取；长文书须重复「向下滚动 → 等待 → 读取」直到页面内容不再增长，确认正文尾部（如「审判长」「书记员」「本判决为终审判决」等落款段）已出现，再进入下一步。

## 4. PDF 落盘契约（与模式B 工作流（references/mode-b-fetch-judgment.md） 步骤 B9 第 2 点一致）

浏览器能力的 PDF 导出动作**往往**只产生**临时/制品路径**；无论返回的是临时路径、二进制流还是 `artifacts/…`、`snapshot/browser-pdf-*.pdf`，**仅完成工具返回不等于契约履行**。**必须**再落一步：复制/移动到 **`{工作区}/outputs/`**，终态文件名为 `detail-query-file-naming.md` 中的 `{案号}_案例详情.pdf`（sanitize 后）；并确认该文件在 `outputs/` **真实存在**后再向用户报告。须同时符合模式B 工作流（references/mode-b-fetch-judgment.md） 硬约束（同名覆盖、路径可写等；`convert_to_md.py` 的 `--dry-run` 见上文）。

## 5. 推荐执行顺序

1. 探测并匹配「浏览器页面操作」能力（含 schema 验证）→ 导航打开裁判文书网 → 步骤 B3 登录等待（5 分钟窗口内持续轮询 + 周期性提示）→ **步骤 B4.0** `normalize_case_no_for_search.py`（或等价去空白）→ 步骤 B4 输入并提交检索 → 步骤 B5 列表核对与用户确认。
2. 点开选定条目进入详情 → 滚动到底并等待 → 读取页面正文 → 调用 `convert_to_md.py`（可先 `--dry-run`）。
3. 若浏览器能力提供 PDF 导出：导出 → 按第 4 节落盘到 `outputs/` 并核对存在。
4. 步骤 B10 返回 Markdown 路径、PDF 路径（若成功）与详情 URL；失败时按模式B 工作流（references/mode-b-fetch-judgment.md） 降级策略，**严禁**编造正文。
