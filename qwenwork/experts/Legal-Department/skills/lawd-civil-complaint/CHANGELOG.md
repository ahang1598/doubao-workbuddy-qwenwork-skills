## v1.1.0 (2026-08-10)

企业工商信息连接器改造 + 降级标注防污染修复：

- **正文防污染（P1）**：「（用户自报，待核验）」「（待补全街道）」等核验状态标注不再写入 JSON 字段/文书正文（脚本会把字段值原样拼进当事人段落，会导致立案窗口退件）；正文只允许真实值或中性占位「（待补充）」，核验状态一律移至**交付说明/质量自检报告**。落点：`references/parties-format.md` §9.2 第五步 + §9.4「标注位置铁律」、`SKILL.md` Step 5.5 与 Step 8、`references/script-usage.md` 字段值洁净规则
- **两段能力两步取数（P1）**：企业信息调用由「一次调用取全字段」改为「先用『企业主体定位/模糊搜索』能力确认唯一企业全称（多候选须用户确认，禁止自行选择）→ 再用『工商登记信息查询』能力取字段」；补充「所选工具不返回 USCC 时须在同一连接器下继续探测可提供 USCC 的能力」规则。仍只写能力语义，不写死任何工具名
- **降级唯一真源（P2）**：`references/parties-format.md` §9.4 定为全技能唯一真源，覆盖三种触发情形（探测不到连接器 / 调用失败 / 字段不全）与三个统一出口；`SKILL.md` Step 5.5 与 `references/templates/contracts/contract-general.md` §八改为引用该节，消除三套话术漂移
- **交付门槛（P1）**：Step 8 新增「企业主体工商核验状态」交付说明必写项（已经连接器核验 / 用户自报未核验），后者须显著提示「立案前须律师核对营业执照或国家企业信用信息公示系统」；质量自检清单新增第 15 项与第 1a 子项
- **减少重复打扰（P2）**：最小要素清单不再要求用户先提供企业 USCC / 法定代表人 / 住所地（改由 Step 5.5 自动补全），仅需企业全称 + 联系方式
- **探测关键词补全（P2）**：`qwenwork_mcp_tool_list` 关键词补入中文供应商名（企查查 / 天眼查 / 元典 / 启信宝）及「企业信息」「工商登记」
- **字段表口径一致（P2）**：`references/script-usage.md` 法人 / 合伙企业的 `uscc`、`address`、`legal_rep_name` 标注「降级时可为（待补充）」
- 未改动 `scripts/*.py`（改动通过文档层约束 JSON 组装即可阻止正文污染）
