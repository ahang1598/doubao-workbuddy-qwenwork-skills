# 民事案由速查表

> 仅在 SKILL.md Step 2（案由识别）阶段读取。本文档**只放索引**：案由名称 → 主要请求权基础法条 → 推荐使用的 template → 是否有要素式模板。构成要件、抗辩事由等详情在对应 template 内。

依据：《最高人民法院关于印发〈民事案件案由规定〉的通知》（法〔2020〕346 号）；要素式列依据《关于印发部分案件民事起诉状、答辩状示范文本（试行）的通知》。

---

## 使用方法

根据用户描述的纠纷事实匹配最贴切的具体案由（精确到三级或四级），然后只读取「推荐 template」列对应的文件。

**合同纠纷加载规则（重要）**：合同纠纷须加载**两个文件**：
1. 先读取 `templates/contracts/contract-general.md`（合同纠纷通识规则，所有合同案由必读）
2. 再读取「推荐 template」列对应的**细分案由文件**（仅读取对应的1个文件）

> ⚠️ **注意**：旧版 `templates/contract.md` 已废弃，禁止读取。

**要素式列说明**：
- 🅰 = 《通知》11 类白名单，**必须在 Step 2.5 主动重点提示**用户考虑使用要素式；
- 🅱 = 非白名单但本技能附带空白模板，用户选要素式时可严格按模板填充；
- — = 无模板，用户选要素式时走通用要素式路径并附警示语。

## 案由匹配要点

1. **就低不就高**：能精确到三级、四级案由就不要停在二级案由
2. **请求权竞合时**：合同与侵权竞合（如违约 + 侵权），原告可择一主张，案由按选择确定
3. **多个法律关系**：原则上一案一诉一案由，可根据实际诉讼策略合并起诉或分案起诉
4. **常见误判**：
   - 雇主对外赔偿后追偿 → 「追偿权纠纷」而非「侵权责任纠纷」
   - 装修瑕疵 → 「装饰装修合同纠纷」（合同）而非「财产损害赔偿」（侵权）
   - 劳务报酬纠纷 → 先判断是劳动关系（仲裁前置）还是劳务关系（直接起诉）
