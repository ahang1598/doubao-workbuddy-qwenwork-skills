# 管辖法院确定指南

> 仅在 SKILL.md Step 4（管辖审查）阶段读取。本文档帮助快速定位有管辖权的法院全称（精确到「XX 市 XX 区/县人民法院」），并避免常见管辖错误。

依据：《民事诉讼法》（2023 修正）、《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》（2022 修正）。

## 一、级别管辖

### 基层人民法院
**第一审管辖**绝大多数民事案件（兜底原则），是默认起点。

### 中级人民法院
《民诉法》§19 + 各高级法院的标的额标准。常见情形：
- 重大涉外案件、当事人人数众多的共同诉讼
- 在本辖区有重大影响的案件
- 各地高级法院公布的**一审标的额标准**（例如：北京中院通常 5 亿元以上；上海中院 5 亿元以上；广东 1 亿/3 亿；浙江/江苏 1 亿等。**实务中需查询管辖法院当地高院最新文件**）

### 高级人民法院 / 最高人民法院
- 高院：本辖区内有重大影响的第一审案件
- 最高法：在全国有重大影响 / 应当由其审理

> 大多数民事案件起点是**基层法院**。仅当标的额、影响力达到中院级以上才考虑提级。

## 二、地域管辖

### 一般地域管辖（《民诉法》§24）
**「原告就被告」原则**：

- 被告住所地（自然人 = 户籍地或经常居住地）人民法院管辖
- 法人 / 非法人组织以**主要办事机构所在地**为住所地
- 多个被告住所地不在同一辖区时，各该住所地法院均有管辖权

### 特殊地域管辖（《民诉法》§25–§35）

| 案件类型 | 管辖法院 | 法条 |
|---------|---------|------|
| 合同纠纷 | 被告住所地 / 合同履行地 | §25 |
| 保险合同 | 被告住所地 / 保险标的物所在地 | §26 |
| 票据纠纷 | 票据支付地 / 被告住所地 | §27 |
| 公司诉讼 | 公司住所地 | §28 |
| 运输合同 | 始发地 / 目的地 / 被告住所地 | §29 |
| 侵权行为 | 侵权行为地 / 被告住所地 | §30 |
| 道交事故 | 事故发生地 / 车辆始发地、目的地 / 被告住所地 | §31 |
| 海事侵权 | 碰撞发生地 / 船舶最先到达地 / 加害船舶被扣押地 / 被告住所地 | §32 |
| 海难救助 | 救助地 / 被救助船舶最先到达地 | §33 |
| 共同海损 | 船舶最先到达地 / 共同海损理算地 / 航程终止地 | §34 |

### 专属管辖（《民诉法》§35）
**只能由特定法院管辖，协议管辖无效**：
1. 不动产纠纷 → **不动产所在地**法院
2. 港口作业纠纷 → 港口所在地法院
3. 继承遗产纠纷 → 被继承人死亡时住所地 / 主要遗产所在地法院

### 协议管辖（《民诉法》§36）
当事人可以书面协议选择以下与争议有实际联系地点的法院：
- 被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地

**有效要件**：
1. 必须是合同 / 财产权益纠纷（身份关系不可协议）
2. 书面形式
3. 选择五种法定连接点之一
4. 不违反级别管辖、专属管辖

> **实务陷阱**：约定"由原告所在地法院管辖"无效（非五种法定连接点之一）；约定"由原告户籍地"应为"由原告住所地"。

## 三、合同履行地认定（实务高频）

依据《民诉法司法解释》§18：
- 合同**约定履行地**的，从约定
- 未约定的，按以下规则：
  - 给付货币：**接收货币一方所在地**（民间借贷案件——出借人所在地）
  - 交付不动产：不动产所在地
  - 其他标的：履行义务一方所在地
- 合同未实际履行 + 双方住所地都不在合同约定履行地 → **被告住所地**法院

## 四、专门法院管辖

| 法院 | 专属管辖范围 |
|------|------------|
| **互联网法院**（北京、杭州、广州） | 辖区内通过互联网订立、履行的网络购物 / 服务 / 借款合同纠纷；网络著作权权属、侵权纠纷；网络侵权纠纷等 |
| **知识产权法院**（北京、上海、广州、海南自贸港等） | 专利、植物新品种、集成电路布图设计、技术秘密、计算机软件等技术类一审案件 |
| **金融法院**（上海、北京） | 辖区内重大金融民商事案件 |
| **铁路 / 海事 / 林业等专门法院** | 各自专属业务案件 |

## 五、常见案由的管辖速查

| 案由 | 推荐管辖 | 备注 |
|------|---------|------|
| 买卖合同 | 合同履行地 / 被告住所地 | 货款给付地 = 卖方所在地 |
| 民间借贷 | 出借人所在地 / 被告住所地 | 接收货币一方所在地 |
| 房屋买卖 / 租赁 | **不动产所在地**（专属） | 不可协议变更 |
| 装饰装修 | 不动产所在地（专属）/ 合同履行地 | 倾向认定为不动产专属 |
| 建工合同 | **施工不动产所在地**（专属） | 建工司法解释明确 |
| 一般侵权 | 侵权行为地（含侵权行为实施地、结果发生地）/ 被告住所地 | |
| 网络侵权 | 侵权行为地（含被侵权人住所地）/ 被告住所地 | 司法解释扩展 |
| 道交事故 | 事故发生地 / 被告住所地 | 通常起诉至事故发生地基层 |
| 离婚 | 被告住所地；被告下落不明 / 被劳教 / 在监狱服刑 → 原告住所地 | 「原告就被告」例外 |
| 劳动争议 | 用人单位所在地 / 劳动合同履行地（一般为工作地） | 必须先经劳动仲裁 |
| 公司诉讼 | 公司住所地（专属） | §28 |
| 股东资格 / 出资 / 分红 / 解散 | 公司住所地 | |
| 继承 | 被继承人死亡时住所地 / 主要遗产所在地（专属） | |

## 六、管辖法院全称的写法

格式：「**省/直辖市/自治区** + **市/自治州** + **区/县/县级市/自治县/旗** + **人民法院**」

示例：
- ✅ 北京市朝阳区人民法院
- ✅ 上海市浦东新区人民法院
- ✅ 广东省深圳市南山区人民法院
- ✅ 浙江省杭州市西湖区人民法院
- ✅ 北京互联网法院
- ✅ 北京知识产权法院
- ❌ 朝阳人民法院（缺市级）
- ❌ 浦东法院（缺级别 + 行政层级）
- ❌ 深圳市中级人民法院（标的不到中院标准时不应越级）

## 七、管辖向用户确认的标准话术

如有多个管辖连接点可选，应向用户列示选项与利弊，由其拍板：

> 根据您提供的案件情况，下列法院对本案均有管辖权：
> 1. **北京市朝阳区人民法院**（被告住所地）— 利于被告应诉，送达方便
> 2. **上海市浦东新区人民法院**（合同履行地 / 货款接收地）— 利于您方便参加庭审
> 3. **协议约定法院**（如合同有有效管辖约定）
>
> 请您确认选择哪一家立案？

## 八、管辖错误的常见后果

- 立案被裁定不予受理 → 需重新起草起诉状改投有管辖权法院
- 立案后被裁定移送管辖 → 浪费时间，对方可能利用此期间转移资产
- 越级管辖（错告中院 / 高院）→ 直接驳回起诉

> **核对清单**：
> □ 法院级别正确（标的额对照高院标准）？
> □ 地域管辖连接点准确（住所地 / 履行地 / 行为地 / 不动产）？
> □ 是否专属管辖（不动产、港口、继承、公司）？
> □ 协议管辖条款是否有效（书面 + 五连接点 + 不违反专属/级别）？
> □ 法院名称写到区/县级且无错别字？

## 九、仲裁管辖识别与处理规则（⚠ 合同纠纷必须执行）

> **适用范围**：所有合同纠纷案由，在 Step 3 读取合同材料时必须同步执行本节检查。

### 9.1 仲裁协议有效要件（《仲裁法》第16条）

有效的仲裁协议须同时满足：
1. **仲裁意思表示明确**：约定"提交仲裁""通过仲裁解决"等，不得含糊
2. **约定了具体仲裁机构**：须能确定唯一的仲裁机构名称
3. **约定了仲裁事项**：通常表述为"因本合同引起的一切争议"

### 9.2 仲裁条款无效情形（《仲裁法》第17条）

| 无效情形 | 典型表述 | 法律依据 |
|---------|---------|---------|
| 约定的仲裁机构不存在 | "提交中国仲裁委员会仲裁" | 仲裁法§17(3) |
| 仲裁机构名称有歧义，无法确定 | "提交北京仲裁" | 仲裁法§17(3) |
| 选择性条款（仲裁或诉讼二选一） | "可仲裁，也可向法院起诉" | 仲裁法§4 |
| 仅约定协商解决 | "双方友好协商解决" | 仲裁法§16 |
| 约定仲裁但未约定机构且未约定仲裁地 | "提交仲裁解决" | 仲裁法§16 |

### 9.3 常见仲裁机构名称核查表

| 正确名称 | 常见错误写法 | 是否导致无效 |
|---------|------------|------------|
| 中国国际经济贸易仲裁委员会（CIETAC） | 中国仲裁委员会 | **是**（机构不存在） |
| 北京仲裁委员会（BAC） | 北京仲裁 | **是**（歧义） |
| 上海国际仲裁中心（SHIAC） | 上海仲裁委员会 | **是**（名称不符） |
| 中国海事仲裁委员会（CMAC） | 海事仲裁委 | **是**（不完整） |
| 深圳国际仲裁院（SCIA） | 深圳仲裁委员会 | **是**（名称不符） |

### 9.4 处理流程

```
Step 1：识别合同争议解决条款原文
    ↓
Step 2：判断是否含"仲裁"字样
    ↓ 无 → 继续正常起草
    ↓ 有
Step 3：判断仲裁条款是否有效（对照9.2节）
    ↓ 无效 → 继续正常起草，在事实理由中简短说明仲裁条款无效
    ↓ 有效或存疑
Step 4：执行 contract-general.md §十一 仲裁管辖提示流程
    ↓ 用户选择继续起诉
Step 5：在起诉状中增加仲裁条款无效论证段落（见contract-general.md §11.2）
```

### 9.5 仲裁与诉讼的管辖权竞合

- 当事人在仲裁协议有效的情况下向法院起诉的，**被告须在首次开庭前**提出仲裁管辖异议（《民事诉讼法》第127条）
- 被告未及时提出异议的，视为接受法院管辖
- 法院已受理案件且被告已应诉答辩的，不得再提仲裁管辖异议

> ⚠ **实务提示**：即便认为仲裁条款无效，起诉前仍应在起诉状中预留论证段落，以防被告提出管辖异议时措手不及。
