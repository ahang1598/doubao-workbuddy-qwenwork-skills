# 离婚后财产纠纷专项规则（divorce-property.md）

> **前置加载**：使用本文件前必须先读 `family/family-general.md`。  
> **案由识别**：当事人**已离婚**，就离婚时未涉及的夫妻共同财产或隐匿财产另行起诉。  
> 区别于离婚纠纷（尚未离婚）——案由不同，请求权基础不同。

---

## 一、三种典型诉因

| 诉因类型 | 请求权基础 | 胜诉率参考 |
|----------|------------|------------|
| 离婚时未涉及的遗漏财产 | 婚家解释（一）第83条 | 约75% |
| 一方隐匿转移财产，请求再次分割 | 民法典第1092条 | 约50% |
| 对方未按离婚协议履行（过户/支付） | 合同法/民法典第1076条 | 约80% |

---

## 二、诉讼请求结构

### 模板A：遗漏财产型（最常见，胜诉率最高）

```
一、请求依法分割原、被告离婚时遗漏的夫妻共同财产：
    位于×市×区×路×号×室（建筑面积×㎡，不动产权证号：×），
    判令上述房屋归原告所有，原告向被告支付折价补偿款×元；
    （或：判令该房屋由原、被告各享有50%份额，
    被告向原告支付折价补偿款×元，房屋归被告所有。）
二、本案诉讼费由被告承担。
```

### 模板B：隐匿转移财产型

```
一、请求依法对被告婚姻关系存续期间隐匿转移的夫妻共同财产进行再次分割：
    被告名下×银行账户（账号：×）于×年×月×日前后转出的人民币×元，
    属于夫妻共同财产，请求判令被告向原告支付其中50%即×元；
二、请求判令被告赔偿原告因上述隐匿转移行为所受损失×元；
三、本案诉讼费由被告承担。
```

### 模板C：协议未履行型（要求对方按协议过户/支付）

```
一、请求判令被告依照×年×月×日签订的《离婚协议书》第×条约定，
    协助原告办理位于×市×区×路×号×室房屋的不动产转移登记手续，
    将上述房屋产权登记至原告名下；
二、请求判令被告向原告支付逾期未履行产生的违约损失×元（自×年×月×日
    起至实际过户之日止，按同期LPR利率计算）；
三、本案诉讼费由被告承担。
```

## 三、核心举证要点

### 3.1 遗漏财产型

- 证明财产属婚姻存续期间所得（购房合同、付款凭证、登记证书）
- 证明离婚时该财产未被协议或判决涉及（原离婚协议书/离婚判决书）
- 原告举证负担相对轻，被告举证「已协议处理完毕」负担重

### 3.2 隐匿转移财产型（举证难度高，须充分准备）

**关键证据链**（缺一项则胜诉率降至30%以下）：
1. 银行流水——显示大额异常转出时间、金额、收款方
2. 被告无法提供合理解释——债务凭证/消费记录缺失
3. 转账特殊性——「520」「1314」等情感金额直接认定为隐匿
4. 资产评估报告——股权类隐匿须有评估

> **注意**：仅有「账户有大额取现」不足以认定隐匿，被告提供「对外借款」「家庭消费」等解释即可抗辩。

### 3.3 协议未履行型

核心证据：离婚协议书（原件）+ 证明对方知晓且拒绝履行（催告函/往来消息记录）

## 四、股权分割请求写法

```
请求依法分割被告名下×公司×%股权中属于夫妻共同财产的部分：
委托具有资质的评估机构对上述股权价值进行评估，
原告获得评估价值的50%即×元折价补偿款，
或原告获得×%股权，被告获得×%股权。
```

> **代持股权特殊处理**：须先确认被告为实际出资人，再主张分割代持份额。
> 请求写法：「请求确认被告系×公司×%股权的实际持有人，并依法分割其中属于夫妻共同财产的部分」。

---

## 五、核心法条援引顺序

1. 婚姻家庭编解释（一）第83条（遗漏财产再次分割——首要依据）
2. 民法典第1062条（夫妻共同财产认定）
3. 民法典第1063条（个人财产排除）
4. 民法典第1092条（隐匿转移——如适用）
5. 民法典第1076条+第1087条（协议分割效力——如适用）

---

## 六、事实陈述四段式结构

1. **婚姻状况**：原、被告于×年×月×日经×民政局/×法院判决离婚
2. **财产归属**：涉案财产系婚姻关系存续期间×原因所得，属夫妻共同财产
3. **未分割事由**：离婚时因×原因（双方遗漏/一方隐匿）未予处理
4. **请求权基础**：依据婚家解释（一）第83条/民法典第1092条，原告有权请求分割
