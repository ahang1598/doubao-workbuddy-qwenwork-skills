# 法定继承纠纷专项规则（legal-inheritance.md）

> **前置加载**：本文件须在读取 `family-general.md` 后使用。  
> 数据来源：581条近五年案例总结，胜诉率约67%。

---

## 一、核心裁判规律

- **整体胜诉率约67%**，部分支持约24%，驳回约9%
- **败诉主因三项**：①继承人身份无法证明（亲属关系证明缺失）；②遗产范围争议（无产权证明/无银行流水）；③遗嘱效力争议（形式要件不符）
- **遗嘱优先原则**：有遗嘱时法定继承仅适用于遗嘱未涉及的遗产部分
- **代位继承**：被继承人的子女先于被继承人死亡的，由其晚辈直系血亲代位继承（民法典§1128）

## 二、诉讼请求类型与互斥规则

| 请求类型 | 胜诉率 | 互斥/并列规则 |
|---------|--------|-------------|
| 分割不动产（按份额确认所有权） | 最高频 | 可与确认继承人身份并列（先确认后分割） |
| 分割存款/理财/股票 | 高频 | 须提供金融机构证明；可与不动产分割并列 |
| 确认继承人身份 | 中频 | 通常作为分割遗产的前提请求，不互斥 |
| 析产后继承（先析产再继承） | 中频 | **程序顺序不可颠倒**：须先析出被继承人份额，再分割继承 |
| 遗嘱继承+法定继承并存 | 低频 | 遗嘱处分部分按遗嘱，未处分部分按法定；**不互斥** |
| 继承权确认+分割遗产 | 高频 | 可并列；确认是分割的前提 |
| **要求一次性分割 + 要求轮流使用** | **互斥** | 不动产分割方式须择一 |

## 三、诉讼请求标准表述

**标准型法定继承（不动产+存款）：**
```
一、请求判令确认原告依法享有对被继承人×××（生于×年×月×日，
    殁于×年×月×日）遗产的继承权；
二、请求判令依法分割被继承人×××名下遗产：
    （一）位于×市×区×路×号×室的房屋（不动产权证书号：×），
          建筑面积×平方米，原告分得×份额（折价人民币×元），
          被告×××分得×份额（折价人民币×元），
          取得房屋所有权一方向另一方支付折价补偿款人民币×元；
    （二）被继承人在×银行（账号尾号×）的存款人民币×元，
          由各继承人按法定份额各分得×元；
三、本案诉讼费由各方按继承份额比例承担。
```

**析产后继承（夫妻共同财产中的遗产）：**
```
一、请求判令先行析出被继承人×××名下夫妻共同财产中属于其个人
    的二分之一份额，计人民币×元（或不动产×份额）；
二、请求判令依法对上述析出的×××个人份额按法定继承规则进行分割，
    原告依法分得×份额；
三、本案诉讼费由各方按继承份额比例承担。
```

## 四、事实理由四段式结构（法定继承专项）

```
[第1段] 被继承人基本情况
    ×××（生于×年×月×日），于×年×月×日在×地去世，
    死亡时具有完全民事行为能力（或说明死亡原因）。
    被继承人生前留有遗产如下：（逐项列明，括注证据编号）

[第2段] 继承人范围与身份关系
    被继承人之第一顺位继承人为：
    配偶×××（婚姻关系证明见证据×）；
    子女×××（亲子关系证明见证据×）；
    父母×××（如已先于被继承人死亡，说明并附死亡证明）；
    ——无第一顺位继承人时，第二顺位继承人参与继承——
    代位继承人（如有）：×××之子/女×××（亲属关系证明见证据×）

[第3段] 遗产范围与权属证明
    逐项列明：不动产（产权证/不动产权证书）、存款（银行流水/对账单）、
    车辆（行驶证/登记证）、股权（工商登记/出资证明）、其他财产；
    如有夫妻共同财产，须先析产后继承，注明析产依据（民法典§1153）

[第4段] 请求权基础
    援引顺序：民法典§1127（继承顺位）→§1130（按份继承原则）→
    §1131（酌情分配情形）→§1153（析产后继承）→
    §1161（遗产债务清偿顺序）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 五、核心法律依据

| 条文 | 内容 | 援引场景 |
|------|------|---------| 
| 民法典§1127 | 法定继承顺位 | 所有法定继承案件 |
| 民法典§1128 | 代位继承 | 被继承人子女先于其死亡 |
| 民法典§1129 | 丧偶儿媳/女婿的继承权 | 丧偶方尽了主要赡养义务时 |
| 民法典§1130 | 同一顺位继承人原则均等分配 | 标准分割 |
| 民法典§1131 | 酌情少分/多分情形 | 对被继承人尽了主要扶养义务的 |
| 民法典§1153 | 遗产中的共有财产先分割 | 夫妻共同财产中的继承 |
| 民法典§1161 | 继承人以所得遗产为限清偿债务 | 涉及被继承人债务 |

## 六、专项术语规则

- "遗产"（规范）；禁用"财产""资产"
- "法定继承"（规范）；须与"遗嘱继承"明确区分
- "折价补偿款"（规范）；禁用"补偿金""赔偿款"
- "代位继承人"（规范）；禁用"孙子女代替继承"
- "丧偶儿媳/女婿"（规范，民法典§1129原文）；须证明"尽了主要赡养义务"
- 继承遗产份额须用分数表述：如"原告依法享有遗产的四分之一份额"
- 不动产分割须注明：取得房屋所有权一方须向其他继承人支付"折价补偿款"，而非"买断"

## 七、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 亲属关系证明缺失 | 提前准备：户籍证明+出生医学证明+民政局婚姻登记记录 |
| 遗产范围无法证明 | 申请法院调查令（银行账户、不动产登记）；公证遗产清单 |
| 遗嘱效力争议 | 核查形式要件：自书遗嘱须本人全文手写+签名+日期；公证遗嘱效力最高 |
| 继承权丧失（民法典§1125） | 排除：故意杀害被继承人/为争遗产杀害其他继承人/遗弃被继承人/伪造遗嘱 |
| 析产比例争议 | 提供婚姻关系存续期间共同出资证明，默认各半（民法典§1062） |
