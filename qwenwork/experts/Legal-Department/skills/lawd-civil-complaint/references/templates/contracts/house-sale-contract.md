# 房屋买卖合同纠纷专项规则（house-sale-contract.md）

> **前置加载**：使用本文件前必须先读 `contracts/contract-general.md`。  
> **独立文件原则**：本文件独立于 `sale-contract.md`，不得合并——房屋买卖是买卖合同的特别类型，  
> 适用特殊规则（商品房司法解释、预售许可、网签备案等），一般买卖规则无法覆盖。  
> **案由识别**：涉及商品房（含期房）、二手房、二手住房买卖合同的签订、履行、解除或损害赔偿纠纷。

---

## 一、裁判规律（基于276条样本，2021—2026年）

| 裁判结果 | 数量 | 占比 |
|----------|------|------|
| 完全胜诉 | 45件 | 16.3% |
| 部分胜诉 | 108件 | 39.1% |
| 合计胜诉 | 153件 | 55.4% |
| 败诉 | 123件 | 44.6% |

> **核心规律**：部分胜诉是最典型裁判形态——法院通常支持合同解除和主债权，  
> 但对违约金数额酌减（约定超过实际损失30%时几乎必然调减），  
> 对律师费、差价损失等附属请求支持率约40%。

---

## 二、六类核心争议焦点

| 争议焦点 | 案件数 | 关键认定规则 |
|----------|--------|--------------|
| 违约方认定与违约金计算 | 134件 | 约定超实际损失30%→酌减；调减后以损失1.1—1.3倍或房价10%—15%为准 |
| 逾期交房违约责任 | 高频 | 起算节点：竣工验收合格日 vs. 合同约定交付日（以较晚者为准） |
| 合同解除与退款 | 高频 | 解除后退款+资金占用损失（LPR利率），不同时计算违约金 |
| 欺诈撤销合同 | 中频 | 须证明销售人员主动虚假陈述，"未尽如实告知义务"举证难 |
| 质量瑕疵索赔 | 中频 | 须有工程质量鉴定报告；法院普遍支持修复费用，不支持"无损失主张" |
| 按揭贷款纠纷 | 中频 | 贷款未获批→解除合同退款，不认定为任何一方违约 |

## 三、诉讼请求结构

### 模板A：买方要求解除合同退款（开发商/卖方违约）

```
一、请求依法解除原、被告于×年×月×日签订的《商品房买卖合同》
    （合同编号：×）；
二、请求判令被告退还原告已付购房款人民币×元整
    （大写：×万×仟×佰×拾×元整），并支付以×元为基数，
    按全国银行间同业拆借中心公布的贷款市场报价利率（LPR）
    计算的资金占用损失，自×年×月×日（原告付款之日）起至实际清偿之日止；
三、请求判令被告按合同第×条约定，支付逾期交房违约金×元
    （以已付购房款×元为基数，按日万分之×计算，
    自合同约定交付日×年×月×日起至本诉状递交之日止）；
    若法院认为约定违约金过高，请求依法调整为不低于原告实际损失×元的130%；
四、请求判令被告赔偿原告律师费×元（依据合同第×条约定）；
五、本案诉讼费由被告承担。
```

### 模板B：二手房买方要求卖方协助过户

```
一、请求判令被告协助原告办理位于×市×区×路×号×室
    （建筑面积×㎡，不动产权证号：×）的不动产转移登记手续，
    将上述房屋产权登记至原告名下；
二、请求判令被告支付逾期履行合同义务的违约金×元
    （以房屋总价款×元为基数，按×%计算，
    自合同约定过户日×年×月×日起至实际办理过户之日止）；
    若法院认为约定违约金过高，请求依法调整为不低于原告实际损失×元的130%；
三、请求判令被告赔偿原告律师费×元；
四、本案诉讼费由被告承担。
```

### 模板C：欺诈撤销合同并赔偿损失

```
一、请求依法撤销原、被告于×年×月×日签订的《房屋买卖合同》
    （合同编号：×）；
二、请求判令被告返还原告已付购房款×元，并支付以×元为基数，
    按全国银行间同业拆借中心公布的贷款市场报价利率（LPR）
    计算的资金占用损失，自×年×月×日（原告付款之日）起至实际清偿之日止；
三、请求判令被告赔偿原告因被告欺诈行为造成的其他损失×元
    （包括：中介费×元、评估费×元、贷款手续费×元）；
四、本案诉讼费由被告承担。
```

### 模板D：质量瑕疵索赔（不解除合同）

```
一、请求判令被告对位于×市×区×路×号×室（不动产权证号：×）
    存在的×（具体质量问题：渗漏/裂缝/面积误差等）质量瑕疵
    予以修复，修复期限不超过×日；
二、如被告逾期未修复，请求判令被告赔偿原告修复费用×元
    （依据×（检测机构）出具的《工程质量鉴定报告》）；
三、请求判令被告支付逾期修复期间的违约金×元；
四、本案诉讼费由被告承担。
```

## 四、违约金计算与调减规则

### 4.1 逾期交房违约金计算公式

```
违约金 = 已付购房款 × 日违约金率 × 逾期天数
```

**起算节点争议处理**：
- 合同约定交付日（最常见约定）
- 竣工验收合格日（如合同约定以此为准）
- 原告须在起诉状中明确主张的起算日

**计算示例写法**：
> 「自合同约定交付日×年×月×日起，至本诉状递交之日止，
> 共计×天，以已付购房款×元为基数，按日万分之×（即年利率×%）计算，
> 共计违约金×元。」

### 4.2 违约金调减预防写法

在请求中加入备用请求，避免法院调减后无据可依：

> 「若法院认为约定违约金过高，请求依法调整为不低于原告实际损失×元的130%」

## 五、合同解除后的并行请求注意事项

- **不能同时主张解除合同退款+继续履行**（二者互斥）
- **解除后退款利率**：按LPR利率，不适用逾期交房违约金条款
- **律师费主张**：须有合同明确约定 + 律师费合同原件 + 发票；无合同约定则胜诉率约20%

## 六、核心法条援引顺序

1. 合同法/民法典第563条（合同解除——首要依据）
2. 最高人民法院关于审理商品房买卖合同纠纷案件适用法律若干问题的解释（2020修正）
3. 民法典第577条（违约责任）
4. 民法典第585条（违约金调整）
5. 民法典第148条（欺诈撤销——如适用）
6. 民法典第157条（撤销后的返还与赔偿）

---

## 七、事实陈述六段式结构

1. **合同签订**：×年×月×日，原告与被告签订《×合同》，约定购买×房屋，总价×元
2. **付款履行**：原告依约支付购房款×元（见证据×：付款凭证）
3. **被告违约**：被告未能按约在×年×月×日前交付/过户，至今已逾期×天
4. **损失计算**：原告因此遭受违约金损失×元、差价损失×元、其他损失×元
5. **催告无果**：原告多次催告（见证据×：催告函/短信记录），被告未予理会
6. **请求权基础**：依据民法典×条，原告有权请求解除合同/继续履行/赔偿损失
