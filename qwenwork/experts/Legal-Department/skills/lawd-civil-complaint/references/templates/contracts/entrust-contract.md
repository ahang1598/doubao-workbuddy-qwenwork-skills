# 委托合同纠纷 / 委托理财合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「委托合同纠纷」「委托理财合同纠纷」「资产管理合同纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年235件委托理财案例，原告胜诉率约81.3%。

## 一、委托合同 vs 委托理财合同的区分

| 类型 | 典型场景 | 主要法条 | 特殊规则 |
|------|---------|---------|---------|
| 委托合同（普通） | 委托代理事务、诉讼代理、商务代理 | 民法典 §919—§933 | 任意解除权（§933）；受托人忠实义务（§929） |
| 委托理财合同 | 委托炒股、私募基金、银行理财、信托 | 民法典 §919；《九民纪要》§72—§92 | 保底条款效力分裂；适当性义务 |

## 二、委托合同（普通）诉讼请求标准表述

### 委托人作为原告（受托人违约/越权/擅自转委托）

**第一项：赔偿损失**
```
判令被告赔偿原告因[受托人违约行为]造成的损失
人民币×元，具体包括：
①[损失项目一]×元（见证据×）；
②[损失项目二]×元（见证据×）；
合计×元；
```

**第二项：返还委托财产/款项**
```
判令被告向原告返还委托财产（款项）人民币×元，
并自×年×月×日起至实际返还之日止，
按照全国银行间同业拆借中心公布的
贷款市场报价利率（LPR）计算资金占用损失；
```

**第三项：支付报酬（受托人作为原告时）**
```
判令被告向原告支付委托报酬人民币×元；
```

### 受托人任意解除权（§933）场景
若委托人行使任意解除权，须赔偿受托人损失（限于直接损失）：
```
判令被告赔偿原告因委托人不当解除委托合同造成的直接损失
人民币×元（含：已支出费用×元；可得报酬损失×元）；
```

## 三、委托理财合同纠纷诉讼请求标准表述

### 3.1 委托人作为原告（最常见）

**情形一：受托人违规操作/挪用资金导致亏损**
```
一、请求判令解除原、被告于×年×月×日签订的
    《×××委托理财合同》（合同编号：×××）；
二、请求判令被告向原告返还委托理财本金人民币×元；
三、请求判令被告赔偿原告因违规操作造成的投资损失
    人民币×元；
四、请求判令被告支付以×元为基数，自×年×月×日起
    至实际清偿之日止，按照贷款市场报价利率（LPR）
    计算的资金占用损失；
五、本案诉讼费由被告承担。
```

**情形二：保底条款纠纷（民间委托理财）**
```
一、请求判令被告向原告返还委托理财本金人民币×元；
二、请求判令被告支付以×元为基数，自×年×月×日起
    至实际清偿之日止，按照贷款市场报价利率（LPR）
    计算的资金占用损失；
三、本案诉讼费由被告承担。
```
（注：保底条款本身无效，但本金返还+LPR利息可获支持）

**情形三：金融机构适当性义务违反**
```
一、请求判令被告赔偿原告投资损失人民币×元
    （损失的×%，依据适当性义务违反程度确定）；
二、请求判令被告支付以×元为基数，自×年×月×日起
    至实际清偿之日止，按LPR计算的资金占用损失；
三、本案诉讼费由被告承担。
```

## 四、委托理财合同纠纷特殊规则

### 4.1 保底条款效力（最高频争议，约38%案件）

| 受托人类型 | 保底条款效力 | 法院处理方式 |
|----------|------------|------------|
| 金融机构（持牌）之间 | **一律无效**（违反监管规定） | 合同无效，按过错分担损失 |
| 民间委托理财（个人/私募） | **效力分裂**：保底条款无效，其余条款有效 | 受托人有过错→赔偿；无过错（市场风险）→驳回保底赔偿 |

**起诉策略**：
- 不要在诉请中直接援引保底条款主张「保证收益」
- 转而主张「受托人违规操作/未按约止损/超越授权」导致损失
- 请求返还本金 + LPR利息，成功率最高

### 4.2 适当性义务违反（金融机构类，约39案）

须在事实与理由中论证：
```
被告作为金融机构，在向原告销售[产品名称]时，
未履行「了解客户、了解产品、将适当的产品销售给适当客户」的义务，
具体表现为：
①未进行风险评级或评级与产品风险不匹配；
②风险揭示流于形式（仅有签字无实质告知）；
③原告的风险承受能力为[保守型/稳健型]，而被告销售的产品风险等级为[激进型]；
上述行为违反了《九民纪要》第72—77条关于适当性义务的规定，
被告应对原告的投资损失承担赔偿责任。
```

### 4.3 受托人操作义务违反（委托炒股类，约30%案件）

须在事实中明确陈述：
- 受托人擅自改变投资策略（须有书面约定的策略作为对比）
- 受托人超越授权操作（须有授权范围的书面约定）
- 受托人将账户转委托给第三人操作（须有账户操作记录）
- 受托人未按约定止损或强制平仓（须有约定止损线的书面记录）

## 五、普通委托合同事实与理由结构

```
[第1段] 合同签订
    ×年×月×日，原告（委托人）与被告（受托人）签订
    《×××委托合同》（合同编号：×××），约定：
    委托事项：[具体委托内容，须明确范围]；
    委托权限：[有权/无权转委托；权限边界]；
    委托报酬：人民币×元（或：按×%提取）；
    委托期限：×年×月×日至×年×月×日（见证据1）。

[第2段] 原告履约（支付费用/配合提供材料）
    合同签订后，原告于×年×月×日支付委托费用×元
    （见证据×：付款凭证），并向被告提供了[委托所需材料]
    （见证据×：交接清单）。

[第3段] 被告违约行为
    然而，被告在履行委托事务过程中，
    [擅自处分委托财产/怠于履行/越权转委托/未按约定时间完成]，
    违反了合同第×条第×款的约定（见证据×）。

[第4段] 损失与因果关系
    被告的违约行为致使/造成/导致原告损失人民币×元，
    损失金额计算依据：[评估报告/发票/合同约定]（见证据×）。
    催告过程：原告曾多次催告，被告[未予回应/推脱]（见证据×）。

[第5段] 法律依据
    综上，特依照《中华人民共和国民法典》第九百一十九条、
    第九百二十九条及《中华人民共和国民事诉讼法》第一百二十二条
    之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 六、委托合同纠纷自检清单

- ☐ 合同性质已明确点明为「委托合同」（避免与居间、行纪、代理混淆）
- ☐ 委托事项范围具体（附件编号、工作量、地域、再委托权限）
- ☐ 被告违约行为引用合同条款编号
- ☐ 损失金额有计算依据（合同约定/发票/评估）
- ☐ 催告/协商过程在事实中陈述（主张违约金时必备）
- ☐ 利息请求含三要素（基数+起算日+利率标准）
- ☐ 任意解除权（§933）情形下损失赔偿范围合理（一般限于直接损失）
- ☐ 委托理财：保底条款风险已评估，诉请策略已调整为「本金+LPR利息」
