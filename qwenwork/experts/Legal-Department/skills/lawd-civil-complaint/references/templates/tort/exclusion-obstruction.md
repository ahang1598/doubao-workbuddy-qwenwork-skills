# 排除妨害纠纷专项规则（exclusion-obstruction.md）

> **前置加载**：本文件须在读取 `tort-general.md` 后使用。  
> 数据来源：228条近五年案例总结。

---

## 一、核心裁判规律

- **胜诉率约21%**，举证责任重：物权基础清晰 + 妨害行为客观存在是胜诉关键
- **相邻关系纠纷占比约72%**（通行、采光、排水、宅基地相邻）
- 败诉主因：①原告无法证明妨害行为客观存在（约55%）；②土地权属争议（约30%）；③诉求超出相邻关系保护范围（约15%）
- 近三年约67%判决包含迟延履行金条款，须在诉讼请求中明确写入

---

## 二、诉讼请求类型与互斥规则

| 请求类型 | 胜诉率 | 互斥/并列规则 |
|---------|--------|-------------|
| 排除妨害（拆除/清除/恢复通行） | ~21% | 须具体化妨害行为，不可笼统 |
| 排除妨害 + 赔偿损失 | ~35% | 可并列；损失须有评估报告 |
| 排除妨害 + 消除危险 | 可并列 | 针对不同后果，不互斥 |
| 排除妨害 + 返还原物 | 可并列 | 返还解决占有，排除解决持续干扰 |
| 确认通行权 + 排除妨害 | 可并列 | 先确认权利，再请求保护 |

---

## 三、诉讼请求标准表述

```
一、请求判令被告于本判决生效之日起×日内[拆除/清除/移除]
    [具体妨害物描述及位置]，恢复[通道/排水/采光]正常状态；
二、请求判令被告赔偿原告因妨害行为造成的财产损失人民币×元
    （见评估报告）；
三、如被告逾期未履行判决，请求按日支付迟延履行金；
四、本案诉讼费由被告承担。
```

---

## 四、专项术语规则

- 妨害行为须具体化：描述被告实施的具体行为（如"拆除擅自设置的隔断""清除堆放在××处的物品"），不能笼统表述"排除妨害"
- 请求权基础：民法典第235条（排除妨害）+ 第236条（消除危险），并列援引
- 迟延履行金：援引《民事诉讼法》第264条（原第253条），必须在诉讼请求中写明
- **物权请求权不适用诉讼时效**（民法典§196），被告时效抗辩几乎全部失败

## 五、事实理由四段式结构（排除妨害专项）

```
[第1段] 原告物权基础
    不动产权证书/土地使用权证/宅基地使用权证明 + 权利范围

[第2段] 妨害行为事实
    被告实施妨害的时间 + 具体行为 + 妨害物描述 + 位置坐标（见证据×）
    催告记录：时间+方式+对方回应（见证据×）

[第3段] 损害后果
    妨害对原告使用权益的具体影响（通行受阻/采光遮挡/排水堵塞等）
    损失数额及评估依据（见证据×）

[第4段] 请求权基础
    援引顺序：民法典§235（排除妨害）→§236（消除危险）→
    §288（相邻关系一般规定，如为相邻纠纷）→
    民诉法§264（迟延履行金）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 六、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 妨害行为无法证明 | 起诉前公证保全现场照片/视频；申请法院勘验 |
| 土地权属争议 | 先行确权（申请行政确权或提起确权诉讼）再主张排除妨害 |
| 诉求超出相邻关系范围 | 严格对照§288–§296所列情形，不扩大主张 |
| 遗漏迟延履行金 | 诉讼请求第三项固定写入"逾期按日支付迟延履行金" |
