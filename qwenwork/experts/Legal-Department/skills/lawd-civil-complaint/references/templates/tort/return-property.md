# 返还原物纠纷专项规则（return-property.md）

> **前置加载**：本文件须在读取 `tort-general.md` 后使用。  
> 数据来源：206条近五年案例总结。

---

## 一、核心裁判规律

- **合并胜诉率约45.6%**（完全支持19.9% + 部分支持25.7%）
- **所有权证明是胜诉关键**：不动产权证书、机动车登记证书等权属凭证持有者胜诉率显著更高
- **善意取得抗辩**：法院严格审查"有偿取得""合理价格""登记或交付"三要件，实践中大多数善意取得抗辩被驳回
- **附带占用费请求支持率约68%**：法院通常同时支持"返还原物+支付占用使用费"的组合请求
- **物权请求权不适用诉讼时效**（民法典§196），被告时效抗辩几乎全部失败
- 迟延履行条款固定适用：支持金钱给付的判决几乎全部附加迟延履行金

---

## 二、诉讼请求类型与互斥规则

| 请求类型 | 胜诉率 | 互斥/并列规则 |
|---------|--------|-------------|
| 返还原物（单独） | ~45% | 须证明所有权 + 被告无权占有 |
| 返还原物 + 支付占用使用费 | ~68%（附带支持） | **可并列**，最常见组合 |
| 返还原物 + 恢复原状 | ~48% | **可并列**；恢复原状须具体化 |
| 返还原物 + 排除妨害 | 可并列 | 返还解决占有，排除解决持续干扰 |
| **返还原物 + 折价赔偿** | 主位/备位 | **互斥**：原物存在时优先返还；不能返还时折价赔偿（须评估报告） |

## 三、诉讼请求标准表述

```
一、请求判令被告于本判决生效之日起×日内将[标的物具体描述]
    返还原告；
二、请求判令被告支付自×年×月×日至实际返还之日止的
    占用使用费（参照市场租金标准，暂计至×年×月×日为×元）；
三、如被告不能返还原物，请求判令被告赔偿原告折价损失
    人民币×元（以评估报告确定的市场价值为准）；
四、本案诉讼费由被告承担。
```

---

## 四、专项术语规则

- "返还原物"（民法典§235，物权请求权）；禁用"归还""交回"
- 占用费表述：须明确起算日（被告占有之日）和参照标准（市场租金）
- 诉讼时效：明确援引民法典§196"物权请求权不适用诉讼时效"预防被告抗辩
- 折价赔偿须附评估报告，不能凭空主张金额

## 五、事实理由四段式结构（返还原物专项）

```
[第1段] 原告所有权基础
    权属证明（不动产权证/机动车登记证/购买凭证/合同）
    取得方式（购买/继承/受赠/生产）+ 时间节点（见证据×）

[第2段] 被告占有事实
    被告取得占有的时间、方式（租赁到期/借用未还/擅自占用）
    催告记录：时间+方式+对方回应（见证据×）
    被告占有至今的事实（见证据×）

[第3段] 占用损失
    占用期间原告无法使用的损失
    市场租金标准（评估报告/同期同类市场价格）（见证据×）
    暂计金额及起算日

[第4段] 请求权基础
    援引顺序：民法典§235（返还原物，物权请求权）→
    §196（物权请求权不适用诉讼时效，预防时效抗辩）→
    §1184（占用使用费损失赔偿）→
    民诉法§264（迟延履行金）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 六、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 所有权证明不足 | 提前准备权属证明链：购买合同+付款凭证+交付记录+登记证书 |
| 善意取得抗辩 | 在事实理由中论证被告取得时知道或应知原告权利；或指出价格明显不合理 |
| 原物已灭失/毁损 | 设主位/备位请求：主位返还原物，备位折价赔偿（须附评估报告） |
| 占用费无依据 | 起诉前委托评估机构出具市场租金评估报告 |
