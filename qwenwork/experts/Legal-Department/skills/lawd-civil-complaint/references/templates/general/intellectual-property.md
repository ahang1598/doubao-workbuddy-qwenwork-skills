# 知识产权类纠纷专项规则（intellectual-property.md）

> **前置加载**：本文件须在读取 `general-general.md` 后使用。  
> 涵盖：著作权侵权、商标权侵权、专利权侵权、不正当竞争、商业秘密。

---

## 一、知识产权类常见请求权基础

| 子案由 | 主要法条 | 主要主张 |
|-------|---------|---------| 
| 著作权侵权 | 著作权法 §3、§10、§52 | 停止侵害、赔偿损失、消除影响 |
| 商标权侵权 | 商标法 §57、§63 | 停止侵害、赔偿损失（侵权获利 / 实际损失 / 法定赔偿） |
| 专利权侵权 | 专利法 §11、§71 | 停止侵害、赔偿损失 |
| 不正当竞争 | 反不正当竞争法 §6–§12、§17 | 停止行为、赔偿、惩罚性赔偿 |
| 商业秘密 | 反不正当竞争法 §9 | 停止侵害、赔偿、销毁载体 |

## 二、诉讼请求范例

### 1. 著作权侵权
```
1. 判令被告立即停止侵害原告对作品《___》（登记号 ___）的著作权，
   包括但不限于停止 ___（具体侵权行为）；
2. 判令被告于全国发行的 ___ 报或 ___ 网站显著位置登载致歉声明，
   连续刊登 ___ 日，内容须经法院审核；
3. 判令被告赔偿原告经济损失人民币 ___ 元
   （依据：被告侵权获利 / 原告实际损失 / 法定赔偿）；
4. 判令被告赔偿原告为制止侵权所支出的合理开支人民币 ___ 元
   （律师费 ___ 元、公证费 ___ 元、调查费 ___ 元）；
5. 本案诉讼费由被告承担。
```

### 2. 商标侵权（销售假冒）
```
1. 判令被告立即停止生产 / 销售标注「___」（注册商标号 ___）的假冒商品，
   销毁库存侵权商品及专用模具；
2. 判令被告赔偿原告经济损失及合理维权开支共计人民币 ___ 元；
3. 判令被告在 ___ 范围内消除影响（在 ___ 媒体登载声明）；
4. 本案诉讼费由被告承担。
```

### 3. 不正当竞争（虚假宣传 / 商业诋毁）
```
1. 判令被告立即停止 ___（具体不正当竞争行为）；
2. 判令被告于 ___ 媒体显著位置刊登声明消除影响，内容须经法院审核；
3. 判令被告赔偿原告经济损失人民币 ___ 元；
4. 本案诉讼费由被告承担。
```

## 三、特别注意事项

### 1. 管辖
- **专门法院管辖**：技术类（专利、技术秘密、计算机软件等）一审由知产法院 / 中院
- 普通商标著作权案件由具有知产管辖权的中院
- **管辖连接点**：侵权行为地（含信息网络销售、信息网络传播）+ 被告住所地

### 2. 赔偿计算顺位
实际损失 → 侵权获利 → 许可费合理倍数 → 法定赔偿

### 3. 法定赔偿额上限
- 著作权法：500元–500万元
- 商标法：5万元–500万元
- 专利法：3万元–500万元
- **恶意侵权**可主张惩罚性赔偿（1–5倍）

### 4. 证据保全 / 行为保全
- 应在起诉前或起诉时及时申请
- 公证保全侵权页面、销售记录、传播范围

### 5. 不正当竞争类
- 主体要件：原被告均应为经营者
- 行为要件：违反商业道德 + 损害其他经营者合法权益 + 扰乱市场秩序
- 注意与商标 / 著作权侵权的择一选择

## 四、事实理由结构（知识产权类通用）

```
[第1段] 原告权利基础
    权利登记证书（著作权登记/商标注册证/专利证书）+权利范围（见证据×）

[第2段] 被告侵权行为
    具体侵权行为+时间+平台/渠道+传播范围（见公证书）（见证据×）
    被告侵权获利（如可证明）（见证据×）

[第3段] 损害后果
    原告实际损失（销量下降/授权费损失）（见证据×）
    维权合理开支（律师费/公证费/调查费）（见证据×）

[第4段] 请求权基础
    著作权：著作权法§52（停止侵害）→§54（赔偿计算）→民诉法§122
    商标：商标法§57（侵权行为）→§63（赔偿计算）→民诉法§122
    专利：专利法§11（禁止行为）→§71（赔偿计算）→民诉法§122
    不正当竞争：反不正当竞争法§6–§12→§17（赔偿）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```
