# 特别程序专项规则（special-procedures.md）

> **前置加载**：本文件须在读取 `general-general.md` 后使用。  
> 涵盖：申请人身安全保护令、第三人撤销之诉、案外人执行异议之诉。

---

## 一、三类特别程序对照

| 程序 | 请求权基础 | 时效 | 特殊要求 |
|------|----------|------|---------|
| 人身安全保护令 | 反家庭暴力法 §27–§32 | 无诉讼时效（随时可申请） | 无需正在离婚诉讼；72小时内裁定 |
| 第三人撤销之诉 | 民诉法 §59 | 自知道权利受损之日起**6个月**内 | 原审原被告均为被告 |
| 案外人执行异议之诉 | 民诉法 §234；执行解释 §305、§307 | 异议被驳回后**15日**内 | 须先经执行法院异议程序 |

---

## 二、诉讼请求范例

### 1. 申请人身安全保护令
```
申请请求事项：
1. 禁止被申请人 ___ 对申请人 ___ 实施家庭暴力；
2. 禁止被申请人 ___ 骚扰、跟踪、接触申请人 ___ 及其相关近亲属；
3. 责令被申请人 ___ 迁出申请人 ___ 的住所（地址：___）；
4. 保护申请人人身安全的其他措施。

事实和理由：
（按反家庭暴力法§27申请要件填写：明确的被申请人 + 具体的请求 + 面临家暴现实危险的情况）
```

### 2. 第三人撤销之诉
```
1. 判令撤销贵院（___）___号 [民事判决书 / 调解书] 中关于 ___ 的裁判内容
   （该内容损害了原告的 ___ 权利）；
2. 本案诉讼费由被告承担。
```

### 3. 案外人执行异议之诉
```
1. 判令停止对位于 ___ 的 ___（被执行财产名称、规格、编号）的执行
   （贵院（___）执 ___ 号执行案件中查封 / 扣押 / 拍卖措施）；
2. 判令解除对上述财产的查封 / 扣押 / 冻结措施；
3. 本案诉讼费由被告承担。
```

## 三、特别注意事项

### 1. 人身安全保护令
- **不要求当事人正在离婚诉讼中**（反家庭暴力法 §23）
- 法院应当在 72 小时（情况紧急 24 小时）内作出
- 失效期 6 个月，可申请延长
- 申请材料：报警记录 / 告诫书 / 医疗诊断证明 / 证人证词

### 2. 第三人撤销之诉
- 时效：自知道或应当知道权利受损害之日起 **6 个月**内（民诉法 §59）
- 当事人列法：原审原被告均为本案被告
- 须证明：①原审判决/调解书损害了第三人的民事权益；②第三人非因自身原因未能参加原审诉讼
- 不能用于纠正法律适用错误，只能针对损害第三人权益的内容

### 3. 案外人执行异议之诉
- **前置程序**：先向执行法院提出书面异议，异议被驳回后 15 日内提起
- 当事人列法：原执行案申请人和被执行人均为被告
- 须证明：①案外人对被执行财产享有足以排除强制执行的民事权益
- 常见情形：登记在被执行人名下但实际属于案外人的财产（如借名购房）

## 四、事实理由结构

### 人身安全保护令
```
[第1段] 申请人身份与家庭关系（婚姻关系/同居关系/家庭成员关系）
[第2段] 家庭暴力事实（时间+地点+具体行为+伤情，见证据×）
[第3段] 面临的现实危险（被申请人的威胁行为/继续施暴的可能性）
[第4段] 请求权基础：反家庭暴力法§23（无需离婚诉讼）→§27（申请要件）→§28（裁定内容）
```

### 第三人撤销之诉
```
[第1段] 原审案件基本情况（案号+裁判内容摘要）
[第2段] 原审裁判损害第三人权益的具体内容（见证据×）
[第3段] 第三人未能参加原审的原因（非因自身原因）
[第4段] 请求权基础：民诉法§59（第三人撤销之诉）→时效论证→民诉法§122
```

### 案外人执行异议之诉
```
[第1段] 执行案件基本情况（执行案号+被执行财产描述）
[第2段] 案外人对财产的权利基础（购买合同/登记证书/实际占有）（见证据×）
[第3段] 异议程序已履行（书面异议+被驳回裁定）（见证据×）
[第4段] 请求权基础：民诉法§234→执行解释§305→民诉法§122
```
