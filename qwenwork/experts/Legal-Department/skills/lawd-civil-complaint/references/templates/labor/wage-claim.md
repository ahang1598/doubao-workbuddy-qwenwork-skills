# 追索劳动报酬专项规则（wage-claim.md）

> **前置加载**：本文件须在读取 `labor-general.md` 后使用。

---

## 一、常见请求项目清单

| 请求项目 | 计算依据 | 可并列 |
|---------|---------|--------|
| 拖欠工资 | 应发工资-实发工资 | ✅ |
| 加班费（工作日延时） | 日工资÷8×1.5×加班小时数 | ✅ |
| 加班费（休息日） | 日工资×2×天数 | ✅ |
| 加班费（法定节假日） | 日工资×3×天数 | ✅ |
| 未休年休假工资 | 日工资×300%×未休天数 | ✅ |
| 未签书面合同二倍工资差额 | 月工资×（实际工作月数-1），上限11个月 | ✅ |
| 经济补偿金（N） | 月均工资×工作年限 | ✅（合法解除时） |
| 违法解除赔偿金（2N） | 月均工资×工作年限×2 | **与经济补偿金互斥** |

## 二、诉讼请求标准表述

```
一、判令被告向原告支付拖欠工资人民币×元
    （自×年×月至×年×月，每月×元，共×个月）；
二、判令被告向原告支付未签订书面劳动合同期间
    （自×年×月×日至×年×月×日，共×个月）的二倍工资差额
    人民币×元（劳动合同法§82）；
三、判令被告向原告支付加班费人民币×元
    （工作日延时加班×小时×1.5倍=×元；
     休息日加班×天×2倍=×元；
     法定节假日加班×天×3倍=×元）；
四、判令被告向原告支付未休年休假工资×元
    （按未休天数×天×日工资×元×300%计算）；
五、判令被告向原告支付解除劳动合同的经济补偿金×元
    （按工作年限×年×月平均工资×元）；
六、本案诉讼费由被告承担。
```

## 三、专项术语规则

- "劳动报酬"（规范，含工资、奖金、津贴、补贴）；禁用"工钱"
- "经济补偿金"（合法解除，N）；"赔偿金"（违法解除，2N）；**两者严格区分，不可混用**
- "年休假工资"须按"300%"计算，禁用"三倍工资"（含正常工资，差额实为200%）
- 二倍工资差额：最多11个月（第1个月已签合同，第2至12个月为差额期）

## 四、事实理由结构

```
[第1段] 劳动关系基本情况
    入职时间+岗位+薪资标准+工作地点+是否签订书面合同
    仲裁前置程序（裁决书文号+收到时间）

[第2段] 工资拖欠事实
    应发工资标准（劳动合同/工资条/银行流水）（见证据×）
    实发金额（银行流水）（见证据×）
    欠付金额计算：应发-实发=欠付

[第3段] 加班事实（如主张加班费）
    加班记录（考勤系统/邮件指令/客户接待记录）（见证据×）
    各类型加班时长计算

[第4段] 请求权基础
    援引顺序：劳动法§50（按时足额支付工资）→
    劳动合同法§30（工资支付义务）→§82（二倍工资）→
    §46、§47（经济补偿金）→民诉法§122
    收尾固定语
```
