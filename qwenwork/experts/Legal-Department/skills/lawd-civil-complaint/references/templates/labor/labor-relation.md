# 确认劳动关系专项规则（labor-relation.md）

> **前置加载**：本文件须在读取 `labor-general.md` 后使用。

---

## 一、核心规则

- 确认劳动关系通常是追索工资、经济补偿、工伤待遇等实体请求的**前提**
- 可与工资追索、工伤待遇等请求**并列**提起
- 举证责任：劳动者承担初步证明责任，用人单位承担反驳责任

---

## 二、事实劳动关系认定标准

依据《关于确立劳动关系有关事项的通知》（劳社部发〔2005〕12号）§1：

同时具备以下情形，可认定为劳动关系：
1. 用人单位和劳动者**符合法律规定的主体资格**
2. 用人单位**依法制定的各项劳动规章制度适用于劳动者**，劳动者受用人单位的劳动管理，从事用人单位安排的有报酬的劳动
3. 劳动者提供的劳动是**用人单位业务的组成部分**

---

## 三、诉讼请求标准表述

```
一、判令确认原告与被告之间自×年×月×日起至×年×月×日止
    存在劳动关系；
二、本案诉讼费由被告承担。
```

**与工资追索并列：**
```
一、判令确认原告与被告之间自×年×月×日起至×年×月×日止
    存在劳动关系；
二、判令被告向原告支付拖欠工资人民币×元……
三、本案诉讼费由被告承担。
```

---

## 四、专项术语规则

- "劳动关系"（规范）；禁用"雇佣关系""用工关系"（后者是口语）
- "事实劳动关系"（规范，未签书面合同时）；禁用"事实雇佣"
- 关系起止时间须精确到年月日
- 劳务派遣：须区分"用人单位（派遣公司）"与"用工单位"，确认劳动关系对象是派遣公司

---

## 五、证据清单（认定劳动关系的关键证据）

| 证据类型 | 证明内容 |
|---------|---------|
| 工资条/银行流水 | 用人单位向劳动者支付报酬 |
| 考勤记录/打卡记录 | 劳动者接受用人单位的劳动管理 |
| 工作证/工牌/员工手册 | 劳动者系用人单位的工作人员 |
| 社保缴纳记录 | 用人单位为劳动者缴纳社保 |
| 工作邮件/钉钉/微信记录 | 劳动者在用人单位的工作内容和管理关系 |
| 证人证词 | 同事证明劳动者在该单位工作 |
| 工作成果/项目文件 | 劳动者提供的劳动是用人单位业务的组成部分 |

---

## 六、事实理由结构

```
[第1段] 用工事实
    入职时间+岗位+工作地点+薪资标准
    仲裁前置程序（裁决书文号+收到时间）

[第2段] 劳动管理关系证明
    用人单位制度适用（考勤制度/规章制度/绩效考核）（见证据×）
    受用人单位劳动管理的事实（工作安排/汇报关系/绩效考核）（见证据×）
    报酬支付（工资条/银行流水）（见证据×）

[第3段] 被告否认劳动关系的事实
    被告主张的性质（劳务关系/承揽关系/合作关系）
    反驳：与上述认定标准逐一比对

[第4段] 请求权基础
    援引顺序：劳动合同法§10（应签书面劳动合同）→§11（未签合同的处理）→
    《关于确立劳动关系有关事项的通知》§1（认定标准）→
    民诉法§122
    收尾固定语
```
