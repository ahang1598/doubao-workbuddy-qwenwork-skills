## 一、工伤待遇请求项目清单

| 待遇项目 | 计算依据 | 承担主体 |
|---------|---------|---------|
| 一次性伤残补助金 | 伤残等级×月工资（1–10级：27–6个月） | 工伤保险基金（已参保）/ 用人单位（未参保） |
| 停工留薪期工资 | 原工资福利待遇，最长12个月 | 用人单位（全额） |
| 一次性工伤医疗补助金 | 按各省标准（解除/终止劳动关系时） | 工伤保险基金（已参保）/ 用人单位（未参保） |
| 一次性伤残就业补助金 | 按各省标准（解除/终止劳动关系时） | 用人单位（全额） |
| 医疗费 | 实际发生的符合规定的医疗费用 | 工伤保险基金（已参保）/ 用人单位（未参保） |
| 护理费 | 护理依赖程度×当地护工标准 | 工伤保险基金（已参保）/ 用人单位（未参保） |
| 住院伙食补助费 | 住院天数×当地标准（一般50–100元/天） | 工伤保险基金（已参保）/ 用人单位（未参保） |
| 交通食宿费 | 实际发生的合理费用 | 工伤保险基金（已参保）/ 用人单位（未参保） |

## 二、诉讼请求标准表述

```
一、判令被告向原告支付一次性伤残补助金×元
    （×级伤残×月工资×元）；
二、判令被告向原告支付停工留薪期工资×元
    （自×年×月×日至×年×月×日，共×个月，月工资×元）；
三、判令被告向原告支付一次性工伤医疗补助金×元
    （依据×省工伤保险条例第×条）；
四、判令被告向原告支付一次性伤残就业补助金×元；
五、判令被告承担护理费×元（×天×日均护工费×元）、
    住院伙食补助费×元（×天×元/天）、
    交通费×元；
六、本案诉讼费由被告承担。
```

## 三、工伤纠纷的特别程序要点

1. **工伤认定决定书**：必须先取得（劳动行政部门出具），是起诉的前提
2. **劳动能力鉴定结论书**：由劳动能力鉴定委员会出具，确定伤残等级
3. **未参保情形**：用人单位承担全部工伤保险待遇，不得以未参保为由拒绝赔偿
4. **参保情形**：部分待遇由基金支付，用人单位仅承担基金不覆盖的部分（停工留薪期工资、一次性伤残就业补助金等）
5. **仲裁前置**：工伤待遇纠纷须经劳动仲裁，仲裁裁决后15日内起诉

## 四、专项术语规则

- "一次性伤残补助金"（工伤保险条例规范用语）；禁用"赔偿金""补偿金"
- "停工留薪期"（规范）；禁用"休养期""养伤期"
- "劳动能力鉴定"（规范）；禁用"伤残鉴定""残疾鉴定"
- 伤残等级须写明：如"十级伤残"，并附劳动能力鉴定结论书

## 五、事实理由结构

```
[第1段] 劳动关系与工伤事实
    入职时间+岗位+受伤时间+受伤经过+是否参加工伤保险
    仲裁前置程序（裁决书文号+收到时间）

[第2段] 工伤认定与鉴定结论
    工伤认定决定书（出具机关+文号+认定结论）（见证据×）
    劳动能力鉴定结论书（鉴定机构+文号+伤残等级）（见证据×）

[第3段] 各项待遇计算
    停工留薪期起止时间+月工资基数（见证据×）
    各项补助金计算依据+适用的省级标准（见证据×）
    医疗费、护理费等实际支出（见证据×）

[第4段] 请求权基础
    援引顺序：工伤保险条例§30（医疗待遇）→§33（停工留薪）→
    §35/§36/§37（各级伤残待遇）→§62（未参保用人单位责任）→
    劳动合同法§17→民诉法§122
    收尾固定语
```
