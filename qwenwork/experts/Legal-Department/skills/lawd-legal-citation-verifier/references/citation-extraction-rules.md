# 法条/案号引用提取规则

## 概述

本文档定义从 AI 生成文本中自动提取法条引用和案例引用的规则。提取结果作为 Phase 2 权威检索的输入。

## 一、法条引用提取

### 1.1 法规名提取

**基本模式**：`《[^》]+》`

匹配示例：
- `《中华人民共和国民法典》`
- `《民法典》`
- `《劳动合同法》`
- `《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》`

**简称与全称映射**：

| 常见简称 | 全称 |
|---------|------|
| 《民法典》 | 《中华人民共和国民法典》 |
| 《劳动合同法》 | 《中华人民共和国劳动合同法》 |
| 《公司法》 | 《中华人民共和国公司法》 |
| 《刑法》 | 《中华人民共和国刑法》 |
| 《民事诉讼法》 | 《中华人民共和国民事诉讼法》 |
| 《行政诉讼法》 | 《中华人民共和国行政诉讼法》 |

检索时优先使用全称；全称无结果时退回简称重试。

### 1.2 条号提取

**条**：`第[零一二三四五六七八九十百千万\d]+条`

**款**：`第[零一二三四五六七八九十百千万\d]+款`

**项**：`第[（(][零一二三四五六七八九十百千万\d]+[）)]项` 或 `第[零一二三四五六七八九十百千万\d]+项`

**组合模式**：`第X条第X款第（X）项`

匹配示例：
- `第五百七十七条`
- `第47条` (阿拉伯数字)
- `第五百八十四条第一款`
- `第九十四条第（四）项`
- `第563条第1款第（4）项`

**中文数字转换**：提取后统一转为阿拉伯数字用于检索。

| 中文 | 阿拉伯 |
|------|--------|
| 第一条 | 第1条 |
| 第五百七十七条 | 第577条 |
| 第一千零六十二条 | 第1062条 |

### 1.3 引用文本提取

按优先级依次尝试以下模式提取 AI 生成的法条引文：

1. **引号内文本**：法条引用后紧跟的引号内容
   - `"当事人一方不履行合同义务..."`
   - `"当事人一方不履行合同义务..."`（中文引号）

2. **"规定"/"规定："后的句子**：
   - `...第577条规定，当事人一方不履行合同义务或者履行不符合约定的，应当承担违约责任。`
   - 提取从"规定"后到句号（。）的内容

3. **冒号后的句子**：
   - `...第577条：当事人一方不履行...`
   - 提取从冒号后到句号的内容

4. **无明确分隔符**：取条号后到下一个句号之间的文本
   - `根据《民法典》第577条当事人一方不履行合同义务...。`

### 1.4 完整法条引用结构

一条完整的法条引用包含：

```
{
  lawName: "《中华人民共和国民法典》",    // 法规名
  article: "第五百七十七条",              // 条号
  paragraph: "第一款",                    // 款号（可选）
  item: "第（四）项",                     // 项号（可选）
  aiText: "当事人一方不履行合同义务..."    // AI 引用文本
}
```

## 二、案例引用提取

### 2.1 案号提取

**基本模式**：`[（(]\d{4}[）)][^\s，。,\.]{2,30}[号號]`

匹配示例：
- `（2023）京01民终5678号`
- `(2024)最高法民申1234号`
- `（2022）粤03民初9876号`
- `（2021）沪0115民初12345号`

**案号结构说明**：
```
（年份）法院代字 + 案件类型代字 + 序号 + 号
```

### 2.2 案例引用文本提取

案例引用文本的提取比法条更灵活，常见模式：

1. **"认为"后的内容**：
   - `...法院认为，出卖人迟延交货超过30日的...`

2. **"判决/裁定"后的内容**：
   - `...法院判决被告赔偿原告损失...`

3. **整段引用**：案号出现后到段落结束的所有内容

### 2.3 完整案例引用结构

```
{
  caseNo: "（2023）京01民终5678号",       // 案号
  court: "北京市第一中级人民法院",         // 审理法院（可选，从文本中提取）
  aiText: "出卖人迟延交货超过30日..."      // AI 引用文本
}
```

## 三、边界处理

### 3.1 多法条连续引用

```
根据《民法典》第五百七十七条、第五百八十四条的规定...
```

应拆分为 2 条独立引用。注意此时两条引用共享同一段 AI 引用文本，需在确认阶段向用户说明。

### 3.2 嵌套引用

```
《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》第三条
```

法规名中包含书名号的情况（`〈〉`），应完整提取外层法规名。

### 3.3 无书名号的法规引用

```
依据民法典第577条...
```

无书名号时仍应尝试识别常见法规简称（民法典、劳动法、公司法等），但需在确认阶段向用户标注"已自动补充书名号"。

### 3.4 非法条引用的排除

以下不作为法条引用提取：
- 文书名称中的法规名：`本院依据《民法典》作出如下判决`（这是对法规的笼统提及，不是条文引用）
- 仅有法规名无条号：`根据《民法典》的相关规定`（无具体条号，无法校验）

**规则**：必须同时提取到法规名 + 条号，才构成一条有效的法条引用。仅有法规名的笼统提及不纳入校验范围。
