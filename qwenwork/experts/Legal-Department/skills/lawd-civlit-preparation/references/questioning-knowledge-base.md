# 庭审发问知识库

本文件包含各类案件的发问要点、庭审心理学技巧、证人交叉询问技巧、不同审级策略等参考知识。分析案件时按需读取相关部分。

---

## 一、各类案件发问要点

### 合同纠纷
- 合同签订过程：时间、地点、参与人员，是否存在胁迫、欺诈、重大误解
- 合同条款理解：关键条款（标的、数量、质量、价款、履行期限）双方理解是否一致
- 合同履行情况：是否按约履行，违约原因和后果
- 合同变更或解除：原因、过程、协商情况

### 侵权纠纷
- 侵权行为经过：时间、地点、方式、手段
- 主观故意或过失：是否明知行为会损害他人
- 损害后果关联性：因果关系、损害程度
- 免责事由：正当防卫、紧急避险、受害人同意

### 婚姻家庭纠纷
- 婚姻关系存续：结婚时间地点、登记情况、无效或可撤销情形
- 感情状况：破裂原因、家庭暴力、分居时间
- 子女抚养：抚养意愿、能力、探视权
- 财产分割：共同财产范围、来源、隐匿转移行为

### 继承纠纷
- 被继承人死亡情况：时间、原因、遗嘱或遗赠扶养协议
- 继承人范围和资格：身份关系、丧失继承权情形
- 遗产范围和价值：种类、数量、共有财产或债务
- 遗嘱效力：订立时间地点、见证人、伪造篡改胁迫

### 劳动争议纠纷
- 劳动关系建立和解除：时间方式、劳动合同、解除原因
- 工资待遇：构成、发放方式时间、拖欠克扣
- 工作时间：加班、未付加班工资、休息休假
- 劳动保护：劳动条件、安全隐患、职业危害

### 知识产权纠纷
- 权属：归属、共有或委托创作
- 侵权认定：未经许可使用、复制、传播、销售，合理使用或法定许可
- 主观故意或过失：是否明知侵权
- 损害后果：因果关系、损害程度

### 公司纠纷
- 股东会程序：召集、通知、表决是否合规
- 出资情况：是否到位、抽逃出资
- 利益分配：分红决议、比例、程序

### 建设工程纠纷
- 施工过程：范围、标准、变更
- 验收情况：时间、标准、结果
- 结算协商：依据、金额、争议

### 借贷纠纷
- 借款用途：目的、资金流向
- 还款情况：金额、时间、方式
- 担保协商：方式、范围、效力

## 二、证人交叉询问技巧

### 核心原则
1. **控制证人**：通过封闭式问题控制回答范围
2. **逐点击破**：一次只问一个事实点
3. **已有答案**：只问知道答案的问题
4. **适可而止**：达到目的即停止，不给解释机会

### 可信度攻击路径

**感知能力**：位置距离、环境因素（光线、声音）、感官状况

**记忆能力**：时间跨度、事件特殊性、记忆习惯

**诚实性**：利害关系、既往诚信、证言内在矛盾

**证言来源**：亲历还是传闻、信息可靠性、转述失真

### 话术模板

揭示利害关系：
```
问：请问您与原告是什么关系？
问：您是否在原告公司任职？任职多长时间？
问：您是否希望原告胜诉？
```

揭示记忆模糊：
```
问：您说当时在场，请问具体是几点？
问：当天天气如何？现场有几个人？您站在什么位置？
```

揭示证言矛盾：
```
问：您刚才说A，对吗？
问：但在笔录中您说的是B，对吗？
问：请问哪个是真实的？
```

### 禁区
- 不要让证人解释（只让确认或否认）
- 不要问不知道答案的问题
- 不要与证人争辩
- 禁止"为什么"类问题、开放式问题、复合问题

## 三、不同审级发问策略

### 一审
- 核心目标：查明事实、固定证据
- 重点：基础事实确认、证据真实性、履行过程还原、违约/侵权事实确认
- 法官（仲裁案件为仲裁员）关注：事实是否清楚、证据是否充分、法律关系是否明确

### 二审
- 核心目标：揭示一审判决/裁决错误
- 重点：一审认定事实错误、遗漏重要事实、新证据证明力、法律适用争议
- 特殊技巧：对比一审笔录与判决书/裁决书矛盾、追问一审未查明事实、强调程序问题

### 再审
- 核心目标：证明生效判决/裁决重大错误
- 重点：重大事实认定错误、关键证据采信问题、程序违法、法律适用错误
- 特殊技巧：聚焦再审法定事由、强调原审未质证关键证据、揭示程序重大瑕疵

## 四、对方发问陷阱识别

| 陷阱类型 | 形式 | 应对 |
|----------|------|------|
| 二选一陷阱 | "是A还是B？" | "两者都不准确，实际情况是..." |
| 复合问题陷阱 | 一个问题包含多个事实 | "请问您问的是哪个事实？" |
| 假设性陷阱 | "如果...，您会..." | "该假设与本案无关" |
| 时间错位陷阱 | 混淆不同时间点事实 | "请问您问的是哪个时间点？" |

## 五、发问失败补救措施

| 失败情形 | 补救方法 | 话术 |
|----------|----------|------|
| 对方拒绝回答 | 申请法庭要求回答 | "审判长，该问题与本案核心事实直接相关，请求法庭要求对方回答。" |
| 回答超出预期 | 不纠缠，转向备用问题 | "审判长，对方回答与证据X不符，我方将在质证阶段详细说明。" |
| 法官/仲裁员制止发问 | 调整表述，说明关联性 | "审判长，该问题与XX争议焦点直接相关，目的是..." |
| 对方反问 | 拒绝回答，坚持原问题 | "审判长，现在是举证质证阶段，由我方向对方发问。" |
| 对方承认不利事实 | 立即固定，请求记录 | "审判长，对方已承认XX事实，请求法庭记录在案。" |

## 六、电子证据发问要点

| 证据类型 | 核心发问点 | 常见问题 |
|----------|------------|----------|
| 微信聊天 | 账号归属、完整性、身份确认 | "该微信号是否为你本人使用？" |
| 电子邮件 | 邮箱归属、发送接收时间、附件 | "该邮箱是否为公司工作邮箱？" |
| 电子合同 | 签署平台、身份认证、签署时间 | "签署时是否经过人脸识别？" |
| 转账记录 | 转账用途、双方关系、后续处理 | "该笔转账的用途是什么？" |
| 录音录像 | 录制时间、参与人、完整性 | "该录音是否完整，有无剪辑？" |

## 七、法官（仲裁案件为仲裁员）类型适配

| 法官/仲裁员类型 | 关注重点 | 准备策略 |
|----------|----------|----------|
| 细节型 | 事实细节 | 准备详实的事实说明 |
| 效率型 | 争议焦点 | 准备简洁有力的观点 |
| 学术型 | 理论深度 | 准备法理分析 |
| 实务型 | 商业逻辑 | 准备行业惯例说明 |
