# 案件事实梳理（大事记/时间轴）制作规范

## 一、目标与功能

**目标**：按时间顺序罗列关键事实、证据、行为，理清案件脉络，结构清晰，同时保留与案件审理相关的具体细节，方便律师在庭审过程中快速索引查询。

**功能**：
- 全面呈现案件事实发展脉络
- 重点突出关键节点和争议事实
- 细节不缺失，便于庭审快速定位
- 标注来源，便于证据调取
- 提示事实断层，指导补充调查

## 二、事实来源

事实梳理应综合以下来源，确保全面性：

| 来源类型 | 具体内容 | 标注格式 |
|----------|----------|----------|
| 当事人陈述 | 与当事人沟通了解的案情、背景信息 | [陈述 - 原告/被告/第三人] |
| 诉讼文书 | 起诉状/仲裁申请书、答辩状、反诉状、代理词 | [诉状-PX]/[答辩状-PX] |
| 证据材料 | 书证、物证、电子数据、证人证言等 | [证 X-PX] |
| 庭审笔录 | 庭前会议、证据交换笔录 | [笔录 - 日期] |
| 网络检索 | 企业公示信息、裁判文书网等 | [检索 - 来源名称] |
| 调查取证 | 律师调查令调取的材料 | [调查 - 日期] |
| 鉴定勘验 | 司法鉴定意见、现场勘验笔录 | [鉴定/勘验 - 日期] |

## 三、时间轴格式规范

### 标准格式

```
【YYYY-MM-DD（精确到日的，如仅知月份写"YYYY 年 MM 月"）】事件标题（如有）
事件描述：[清晰描述事实，如时间、地点、人物、行为、经过，保留关键细节]
事实来源：[来源标注，如：证 1-P3、起诉状 P2]
关键程度：★★★（高）/★★（中）/★（低）
争议状态：□无争议  □原告主张  □被告抗辩  □待查证
备注说明：[需要特别说明的事项]
```

### 简化格式（用于密集事实罗列）

```
YYYY-MM-DD | 事件描述 | 相关材料
```

## 四、时间轴分类呈现

根据案件复杂程度，可选择以下呈现方式：

### 方式一：单一时间轴（适用于简单案件）

按时间顺序线性罗列所有事实节点。

### 方式二：多线并行时间轴（适用于复杂案件）

按不同主体或不同法律关系分别制作时间轴：
- 原告行为线
- 被告行为线
- 第三方行为线
- 资金流向线
- 合同履行线

### 方式三：分阶段时间轴（适用于跨阶段案件）

按案件发展阶段划分：
- 缔约阶段（YYYY-MM 至 YYYY-MM）
- 履行阶段（YYYY-MM 至 YYYY-MM）
- 违约/争议阶段（YYYY-MM 至 YYYY-MM）
- 诉讼阶段（YYYY-MM 至今）

## 五、关键事实标注规则

### 1. 关键程度分级

| 等级 | 标识 | 标准 |
|------|------|------|
| 高 | ★★★ | 直接影响诉讼请求成立与否、法律关系定性、责任承担 |
| 中 | ★★ | 影响赔偿金额计算、责任比例划分 |
| 低 | ★ | 辅助性事实、背景信息 |

### 2. 争议状态标注

| 状态 | 标识 | 说明 |
|------|------|------|
| 无争议 | □无争议 | 双方均认可的事实 |
| 原告主张 | □原告主张 | 仅原告方主张，被告不认可 |
| 被告抗辩 | □被告抗辩 | 仅被告方主张，原告不认可 |
| 待查证 | □待查证 | 双方证据矛盾，需庭审查明 |

### 3. 证据冲突提示

当不同证据对同一事实有不同记载时，使用以下格式提示：

```
【冲突提示】
关于 XXX 事实，存在以下证据冲突：
- 证据 A（证 1-P3）记载：......
- 证据 B（证 3-P1）记载：......
→ 建议庭审重点询问/申请证人出庭/申请调查取证
```

## 六、事实断层提示

对于现有证据无法完整反映的关键事实，或存在断层的事实细节，应明确提示：

```
【事实断层提示】
时间区间：YYYY-MM-DD 至 YYYY-MM-DD
缺失内容：[具体说明缺失的事实环节]
影响分析：[说明对案件的影响]
建议行动：
1. 询问当事人：[具体问题建议]
2. 补充取证：[取证方向建议]
3. 申请调查：[如需法院调查令]
```

## 七、时间轴制作流程

1. **收集事实素材**：从所有来源提取事实信息
2. **时间排序**：按时间先后排序
3. **来源标注**：为每个事实节点标注来源
4. **关键程度评估**：标记★★★/★★/★
5. **争议状态识别**：标注争议状态
6. **冲突检测**：识别证据冲突
7. **断层提示**：标注需要补充的事实
8. **索引编制**：制作快速索引工具

## 八、示例模板

```
第二部分  案件事实梳理（大事记/时间轴）

【2023-01-15】合同签订 ★★★
事件描述：2023 年 1 月 15 日，原告与被告签订《XXX 合同》，约定......
事实来源：[证 1-P1]、[起诉状 P2]
关键程度：★★★
争议状态：□无争议

【2023-01-20】首付款支付 ★★
时间：2023 年 1 月 20 日
事件描述：2023 年 1 月 20 日，原告通过其XXXXXX银行账户以转账方式向被告XXXX银行账户支付首付款 XX 万元
事实来源：[证 2-P1]、[起诉状 P3]
关键程度：★★
争议状态：□无争议

【2023-02-10】货物交付争议 ★★★
时间：2023 年 2 月 10 日
事件描述：被告向原告交付货物，原告签收
事实来源：[证 3-P1]、[答辩状 P2]
关键程度：★★★
争议状态：□原告主张 □被告抗辩
备注说明：原告主张货物存在质量问题，被告主张质量合格

【冲突提示】
关于货物质量，存在以下证据冲突：
- 证据 3（送货单）：记载"货物完好"
- 证据 5（原告单方检测报告）：记载"质量不合格"
→ 建议：申请司法鉴定

【事实断层提示】
时间区间：2023-02-10 至 2023-02-25
缺失内容：货物实际使用情况、质量异议提出的具体时间
影响分析：影响质量抗辩是否成立的认定
建议行动：
1. 询问当事人：货物何时开始使用？使用过程有无异常？
2. 补充取证：调取双方往来邮件、微信记录
```
