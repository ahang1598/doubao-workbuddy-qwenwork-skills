# 证据链组织报告模板

本文件定义证据链组织报告的输出结构。使用时按此模板生成完整报告。

```
=== 证据链组织报告 ===

一、案件基本信息
- 案由：[案由]
- 管辖法院：[法院名称]
- 诉讼阶段：[一审/二审/仲裁等]

二、主张-证据映射总表
[完整的五层映射表，包含全部主张和对应证据]

三、证据缺口清单
[按风险等级排序的缺口清单，每个缺口包含：
  - 缺口类型
  - 对应主张和要件
  - 风险等级
  - 补救建议
  - 论证节点预检结果]

四、证明力总评
- 强证明力证据：[数量] 个
- 中证明力证据：[数量] 个
- 弱证明力证据：[数量] 个

五、证据目录（格式化）
[按法院要求格式整理的证据目录，可直接提交]
```
