# 证据"三性"审查标准与方法

本文档系统阐述证据真实性、合法性、关联性（"三性"）的审查标准、方法和具体操作要点。"三性"审查是证据能力判断的核心，所有证据分析的基础。

---

## 一、三性的基本概念与法律依据

### 1. 真实性（客观性）
**定义**：证据本身是真实存在的、未经伪造或变造的、能客观反映案件事实。

**法律依据**：
- 《最高人民法院关于民事诉讼证据的若干规定》（法释〔2019〕19号，以下简称《证据规定》）第87条
- 《民事诉讼法》（2023年修正）第66条、第71条

### 2. 合法性（适格性）
**定义**：证据的取得方式、形式、程序符合法律规定。

**法律依据**：
- 《证据规定》第106条（非法证据排除）
- 《民事诉讼法》第71条

### 3. 关联性（相关性）
**定义**：证据与待证事实之间具有逻辑联系，能证明待证事实的全部或一部分。

**法律依据**：
- 《证据规定》第85条
- 《民事诉讼法》第71条

**只有同时具备三性的证据，才具备证据能力，可被法庭采纳。**

## 二、真实性审查

### A. 形式真实性审查

| 审查维度 | 审查要点 | 典型质疑点 |
|---------|---------|----------|
| 原件/复印件 | 是否为原件？复印件是否与原件核对一致？ | 仅有复印件且对方拒绝核对 |
| 完整性 | 是否完整？有无遗漏页？骑缝章是否完整？ | 缺页、关键页缺失 |
| 修改痕迹 | 有无涂改、添加、删减？修改是否双方确认？ | 单方修改未确认 |
| 签字盖章 | 签字是否清晰？印章是否完整？ | 签字模糊、印章不清 |
| 落款 | 落款日期是否清晰？落款人是否明确？ | 落款日期不明、落款人不清 |
| 装订 | 装订顺序是否符合形成时间？ | 装订错乱、装订掉页 |

### B. 来源真实性审查

| 审查维度 | 审查要点 |
|---------|---------|
| 形成主体 | 证据形成主体是否具有相应资格？ |
| 形成时间 | 形成时间是否与所证事实相符？ |
| 形成场景 | 证据形成的场合、目的是否合理？ |
| 取得方式 | 证据如何取得？来源是否可信？ |
| 持有过程 | 自形成至提交期间，是否处于持有人控制下？ |
| 流转过程 | 证据流转过程是否清晰？有无可能被篡改？ |

### C. 内容真实性审查

| 审查维度 | 审查要点 |
|---------|---------|
| 内部一致 | 证据内部表述是否一致？ |
| 与其他证据印证 | 是否与其他证据相印证？ |
| 与陈述吻合 | 是否与当事人陈述吻合？ |
| 符合常理 | 是否符合一般生活经验和交易习惯？ |
| 关键信息 | 日期、金额、签章等关键信息是否合理？ |

### D. 真实性审查方法

#### 方法 1：与原件核对
- 携带原件至法庭核对
- 申请法庭主持双方共同核对
- 如对方未提交原件，主张该证据不具备真实性

#### 方法 2：申请笔迹/印章鉴定
- 适用：对签字、印章真实性有异议
- 法律依据：《证据规定》第31条
- 申请时点：举证期限内或庭前会议时

#### 方法 3：申请文书鉴定
- 适用：对文书的形成时间、是否变造有异议
- 鉴定事项：墨迹书写时间、纸张形成时间、是否拼接修改

#### 方法 4：电子数据校验
- 哈希值校验（MD5/SHA256）
- 时间戳认证
- 区块链存证查询
- 原始载体核对

#### 方法 5：证人作证 / 当事人核对
- 申请知情人出庭作证
- 申请当事人本人到庭核对

### E. 真实性瑕疵的法律后果

| 瑕疵程度 | 法律后果 |
|---------|---------|
| 严重瑕疵（伪造、变造） | 证据不予采信，伪造者可能承担伪证责任 |
| 较重瑕疵（明显修改） | 证据不予采信，或证明力减弱 |
| 一般瑕疵（复印件无原件） | 单独不能定案，需其他证据印证 |
| 轻微瑕疵（笔误等） | 不影响真实性认定 |

## 三、合法性审查

### A. 取证主体合法性

| 审查维度 | 审查要点 |
|---------|---------|
| 主体资格 | 取证主体是否具备取证资格？ |
| 律师调查 | 律师调查取证是否符合《律师法》第35条？ |
| 法院取证 | 是否依《民诉法》第67条由法院调取？ |
| 鉴定取证 | 鉴定机构是否有资质？鉴定人是否有执业资格？ |
| 公证取证 | 公证处是否依《公证法》规范取证？ |

### B. 取证方式合法性

| 审查维度 | 审查要点 | 法律依据 |
|---------|---------|---------|
| 偷拍偷录 | 是否严重侵犯他人合法权益、违反公序良俗？ | 《证据规定》第106条 |
| 引诱欺骗 | 是否以欺骗、胁迫、贿买等方式获取？ | 《证据规定》第106条 |
| 侵犯隐私 | 是否侵犯当事人隐私？是否泄露商业秘密？ | 《民诉法》第137条 |
| 非法搜查 | 是否未经允许搜查他人住宅或财物？ | 《宪法》第39条 |
| 非法监听 | 是否非法窃听他人通讯？ | 《电信条例》 |
| 公证程序 | 公证程序是否合法？是否全程公证？ | 《公证法》 |

**重要提示**：根据《证据规定》第106条，**严重侵害他人合法权益、违反法律禁止性规定或者严重违背公序良俗的方法形成或者获取的证据**，不得作为认定案件事实的根据。

### C. 形式合法性

| 证据类型 | 形式要件 | 法律依据 |
|---------|---------|---------|
| 书证 | 应当提交原件，复印件需经核对 | 《证据规定》第60条 |
| 物证 | 应当提交原物 | 《证据规定》第60条 |
| 视听资料 | 应当提供原始载体 | 《证据规定》第15条 |
| 电子数据 | 应当提供原件（原始存储介质） | 《证据规定》第15条 |
| 证人证言 | 一般应当出庭作证 | 《民诉法》第75条 |
| 鉴定意见 | 应当具备完整的鉴定要件 | 《证据规定》第36条 |
| 公证文书 | 应符合《公证法》规定的形式 | 《公证法》 |
| 域外证据 | 应办理公证认证手续 | 《证据规定》第16条 |

### D. 程序合法性

| 审查维度 | 审查要点 |
|---------|---------|
| 举证期限 | 是否在举证期限内提交？逾期是否说明理由？ |
| 证据交换 | 是否经过证据交换程序？ |
| 证据保全 | 证据保全申请是否经法院批准？ |
| 鉴定程序 | 鉴定委托、受理、实施程序是否合法？ |
| 公证程序 | 公证流程是否完整？是否全程公证？ |

### E. 合法性瑕疵的法律后果

| 瑕疵程度 | 法律后果 |
|---------|---------|
| 严重违法（《证据规定》第106条情形） | 非法证据排除 |
| 形式不合（如缺乏原件） | 证明力减弱，需补强 |
| 程序瑕疵（如逾期举证） | 可能不予采纳或被对方质证拒绝 |
| 轻微瑕疵 | 不影响合法性认定 |

## 四、关联性审查

### A. 关联程度审查

| 关联程度 | 含义 | 证明力 |
|---------|------|--------|
| 直接关联 | 直接证明待证事实 | 证明力强 |
| 间接关联 | 通过推理证明待证事实 | 证明力中 |
| 弱关联 | 与待证事实有间接联系，证明力弱 | 证明力弱 |
| 无关联 | 与待证事实无逻辑联系 | 不予采纳 |

### B. 关联性审查维度

| 审查维度 | 审查要点 |
|---------|---------|
| 时间关联 | 证据指向的时间是否覆盖争议时段？ |
| 主体关联 | 证据涉及的主体是否为本案当事人？ |
| 客体关联 | 证据涉及的标的是否为本案争议标的？ |
| 法律关系关联 | 证据反映的法律关系是否为本案争议法律关系？ |
| 因果关联 | 证据与待证事实之间是否有因果联系？ |
| 推理关联 | 证据通过何种推理证明待证事实？推理是否成立？ |

### C. 关联性质疑思路

```
质疑路径 1：时间不匹配
"该证据形成于 2023年5月，而本案争议事项发生于 2022年12月，
时间上不能覆盖争议事实。"

质疑路径 2：主体不匹配
"该证据涉及的是 XX 公司，并非本案被告 YY 公司，主体不一致。"

质疑路径 3：标的不匹配
"该证据涉及的是 A 合同项下的交易，而本案争议为 B 合同，
标的不同，不能证明本案事实。"

质疑路径 4：法律关系不匹配
"该证据反映的是借款关系，而本案是买卖合同关系，
法律关系不同，证据无关联性。"

质疑路径 5：推理跳跃
"该证据仅能证明 X 事实，对方主张能证明 Y 事实，
中间存在推理跳跃，不具备直接关联性。"
```

### D. 关联性瑕疵的法律后果

| 瑕疵程度 | 法律后果 |
|---------|---------|
| 完全无关联 | 不予采纳 |
| 弱关联 | 单独证明力不足，需其他证据印证 |
| 关联性存疑 | 由法庭综合判断 |

## 五、三性综合审查流程

对每份证据，按以下顺序审查：

```
Step 1: 形式审查（原件/复印件/完整性）
   ↓
Step 2: 真实性审查（来源 + 内容）
   ↓ （真实性通过）
Step 3: 合法性审查（主体 + 方式 + 形式 + 程序）
   ↓ （合法性通过）
Step 4: 关联性审查（时间/主体/客体/法律关系/因果/推理）
   ↓ （关联性通过）
Step 5: 证据能力结论（具备/不具备）
   ↓
Step 6: 证明力判断（强/中/弱）
```

## 六、三性审查输出模板

```
【证据 X 三性审查结论】

真实性：
- 审查结论：认可/部分认可/不认可
- 具体理由：
  · 形式：[原件/复印件、完整性]
  · 来源：[形成主体、形成场景]
  · 内容：[是否与其他证据印证]
- 异议要点：[具体质疑点 1, 2, 3]
- 法律依据：《证据规定》第 X 条

合法性：
- 审查结论：认可/不认可
- 具体理由：
  · 主体：[取证主体是否适格]
  · 方式：[取证方式是否合法]
  · 形式：[是否符合法定形式]
  · 程序：[是否符合举证程序]
- 异议要点：[具体质疑点]
- 法律依据：《证据规定》第 X 条 / 《民诉法》第 X 条

关联性：
- 审查结论：认可/部分认可/不认可（关联性弱）
- 具体理由：
  · 关联程度：[直接/间接/弱关联/无关联]
  · 关联维度：[时间/主体/客体/法律关系是否匹配]
- 异议要点：[具体质疑点]
- 法律依据：《证据规定》第 X 条

证据能力综合结论：具备/不具备 / 部分具备
证明力等级：强/中/弱/无
```

## 七、常见三性问题速查表

| 常见情形 | 涉及三性 | 应对方法 |
|---------|---------|---------|
| 仅有复印件，无原件 | 真实性 | 申请法庭组织核对；如对方无原件，主张证明力减弱 |
| 微信记录截图，无原始载体 | 真实性、合法性 | 申请提供原始载体；申请鉴定 |
| 录音/录像未经公证 | 真实性、合法性 | 审查取得方式是否合法；申请鉴定 |
| 证人证言未出庭 | 合法性 | 申请证人出庭；如不能出庭，证明力减弱 |
| 鉴定意见无鉴定人签名 | 合法性 | 主张形式瑕疵；申请重新鉴定 |
| 域外证据未公证认证 | 合法性 | 不予采纳，要求补正 |
| 与待证事实时间不匹配 | 关联性 | 主张无关联，不予采纳 |
| 证据涉及第三人，与本案无关 | 关联性 | 主张关联性弱或无关联 |
| 证据形成早于争议发生 | 关联性 | 区分情况：是否为先合同义务、是否构成背景事实 |
| 偷录的对方陈述 | 合法性 | 视情况：未严重侵权且未违反公序良俗的，可采纳；反之排除 |
