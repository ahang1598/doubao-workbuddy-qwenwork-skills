# 验收用例：3 个构造案件

> 全景（组合看板、异常巡检）与归档（案卷目录、完整性核对）在首版**没有真实案件量**，容易变成「写了但从没验过」。
> 本文件构造 3 个虚拟案件走完整生命周期，把这两个子模式逼出可观察的行为。
>
> ⚠️ 三个案件的当事人、案号、法院、金额**全部虚构**，仅用于自测，不得混入真实案件台账。跑验收请另建 `cases-selftest/` 目录，验完删除。
> 本验收与「每技能跑 2 真实案例」是两回事，两者都要过。
> 基准日统一取 **2026-08-10**（脚本一律带 `--today 2026-08-10`，否则临期分档结果会随运行日漂移）。

| 对方当事人 | 虚构乙工程有限公司 |

| 案号 | (2026)虚民初1001号 |
| 当前阶段 | 一审 |

| 举证期限 | 法院指定 30 日，起算日 2026-07-15 |
| 开庭日 | 2026-09-08 |

**验哪些判据**

| 子模式 | 判据 |
|---|---|
| 建档 | 律师模式下利益冲突确认未完成时**必须拦下**，不得进入后续动线；法务模式跳过该门槛。生成 `案件画像.md` + `办案历程.md` 两个文件，画像第四节留有「建档时结果预判」 |
| 期限 | `--type 举证期限 --scene 普通` 不传 `--court-days` 时**拒绝自算**（退出码 2）；传 `--court-days 30` 后届满日为 2026-08-14，紧迫度落「7 天内」档 |
| 全景 | 单案简报能同时列出举证届满与开庭日；组合看板里本案进「7 天内」临期档、阶段分布计入「一审」 |
| 跟进 | 追加一条「收到对方证据交换通知」事件后，`办案历程.md` 行数 +1 且**原有行一字不变**，`最后更新` 刷新 |

**期限自测命令**

```bash
python3 scripts/compute_deadline.py --start-date 2026-07-15 --type 举证期限 --scene 普通 --court-days 30 --today 2026-08-10
```

预期：退出码 0；原始末日 2026-08-14（周五），无需顺延，紧迫度「7 天内」（距基准日 4 天）。当前规则行为 `[待验真]`，输出必须明确标为「辅助草算-法条依据待验真」，不得冒充已验真结论。

## 案件 B · 二审阶段且上诉期刚过

| 字段 | 值 |
|---|---|
| 案件简称 | 丙科技-股权转让 |
| 案件编号 | SELFTEST-B |
| 案由 | 股权转让纠纷 |
| 我方当事人与地位 | 虚构丙科技有限公司 / 上诉人（一审被告） |
| 对方当事人 | 虚构丁投资合伙企业 |
| 标的额 | 940 万元 |
| 审理机关 | 虚构市中级人民法院 |
| 案号 | 一审 (2026)虚民初2002号 / 二审 (2026)虚民终302号 |
| 当前阶段 | 二审 |
| 风险等级 | 高 |
| 一审判决送达日 | 2026-07-15 |
| 保全情况 | 银行存款冻结，冻结裁定执行日 2026-01-20 |
| 最后更新 | 2026-06-28 |

**验哪些判据**

| 子模式 | 判据 |
|---|---|
| 期限 | 上诉期 15 日自 2026-07-15 送达次日起算 → 届满 2026-07-30，相对基准日**已过期**，四档呈现进「已过期」档且提示上诉状是否已提交 |
| 期限（节假日表过期保护） | 保全冻结（存款 1 年）自 2026-01-20 起算 → 原始末日 2027-01-20 落在**没有节假日表的年份**，脚本必须**拒绝输出顺延后日期**（退出码 4），只给「原始末日 + 该日可能为节假日，顺延需人工核对」 |
| 全景（异常巡检） | 同时命中三条异常：① 高风险且有临期/过期期限 ② 保全将到期未见续封记录 ③ **长期未更新**（最后更新 2026-06-28，距基准日 43 天，超 30 天阈值） |
| 全景（分档） | 风险分布里本案计入「高」；阶段分布计入「二审」 |
| 跟进（重要变化联动） | 录入「二审改判风险升档」后，风险从「高」升「重大」，并提示联动模拟裁判/代理词类技能，**但不自动调用** |

**期限自测命令**

```bash
python3 scripts/compute_deadline.py --start-date 2026-07-15 --type 上诉期 --scene 判决 --today 2026-08-10
python3 scripts/compute_deadline.py --start-date 2026-01-20 --type 保全冻结 --scene 存款 --today 2026-08-10
```

预期：第一条退出码 0，届满日 2026-07-30（周四，无需顺延），紧迫度「已过期」，并显示「辅助草算-法条依据待验真」；第二条退出码 4，只输出原始末日，不输出顺延后届满日。

| 对方当事人 | 虚构己贸易有限公司 |

| 案号 | (2025)虚民初3003号 |
| 当前阶段 | 已结案 |
| 风险等级 | 低 |
| 建档时结果预判 | 预计部分胜诉，赔付区间 20–30 万元 |
| 结案日 | 2026-05-20 |
| 审理结果 | 调解结案，我方赔付 18 万元 |
| 归档状态 | 未归档 |
| 最后更新 | 2026-05-22 |

**故意留的案卷缺口**（用来验完整性核对能不能捞出来）

- 缺 授权委托书原件
- 缺 调解书送达回证
- 缺 结案报告
- 有 工作底稿（律师模式移交时须抽出，不随案卷移交）

**验哪些判据**

| 子模式 | 判据 |
|---|---|
| 结案 | 捕获结案日 2026-05-20 与结果「调解，赔付 18 万」，并**与建档预判逐项对比**——预判 20–30 万、实际 18 万，须明确写出「优于预判」及差异原因待复盘；阶段标「已结案」但**记录保留不删** |
| 归档 | 按标准装订顺序生成案卷目录清单；完整性核对**必须逐项标出上面 3 个缺失项**，不得静默略过 |
| 归档（双模式） | 律师模式输出移交确认要点并**显式提示工作底稿抽出**；法务模式改出公司归档清单 |
| 全景（分档） | 组合看板「本月/近期结案数」能统计到本案；风险分布计入「低」；**不再**进临期档 |
| 全景（异常巡检） | 已结案但未归档 → 应作为一条待办异常提示，而不是当作正常状态 |

## 组合验收（三案齐跑）

| 检查项 | 通过标准 |
|---|---|
| 组合看板·风险分布 | 重大 0（跟进联动后 1）/ 高 1 / 中 1 / 低 1 |
| 组合看板·阶段分布 | 一审 1 / 二审 1 / 已结案 1 |
| 组合看板·临期四档 | 已过期 ≥1（案件 B 上诉期）/ 7 天内 ≥1（案件 A 举证）/ 30 天内 ≥1（案件 A 开庭） |
| 组合看板·长期未更新 | 恰好捞出案件 B（43 天）；案件 A（4 天）、案件 C（80 天，已结案另计口径）不误报为在办滞后 |
| 异常巡检 | 至少产出 4 条：高风险+过期、保全临期未续封、长期未更新、已结案未归档 |
| 只呈现不决定 | 全景输出通篇**不出现**「建议撤诉」「应当上诉」这类替律师决策的表述，只给事实、异常与可选下一步 |
| 追加不覆盖 | 三案 `办案历程.md` 全程只增行；用 `wc -l` 前后对比 + 首行内容一致性检查 |
| 降级透明 | 台账载体不可用时，三案全部落本地并在每次输出显式标注「本地模式」 |
| 失权警示 | 每一处期限输出都带失权警示句，一处不漏 |

## 已知未覆盖（诚实登记，别当作已验）

1. **真实案件量下的看板性能与可读性**未验——3 个案件验不出 50 个案件时的排序与截断策略。
2. **多年份跨期限**只验到「拒绝顺延」这一档，未验补齐后续年份节假日表后的正确顺延（须等权威放假安排公布）。
3. **法条依据条号**全表为 `[条号待验真]` 占位，验收时验的是「未验真是否清晰标成辅助草算」，不是「条号对不对」。
