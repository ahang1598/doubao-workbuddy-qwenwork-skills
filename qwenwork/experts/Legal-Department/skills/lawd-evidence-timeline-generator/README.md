# 证据时间线生成技能

## 概述

专业的证据时间线生成技能，帮助律师从案件材料中提取时间信息，按时间顺序梳理事件脉络，生成结构化的时间线 Markdown 文档和可视化 HTML 思维导图。

## 功能特性

- ✅ 从证据材料中自动提取时间信息
- ✅ 按时间顺序整理事件（从早到晚）
- ✅ 智能事件分组（前期准备、合同签署、履约、违约、催告、诉讼准备等）
- ✅ 生成结构化 Markdown 时间线文档
- ✅ 生成交互式 HTML 思维导图（基于 ECharts）
- ✅ 为每个时间线事件提炼核心摘要
- ✅ 保持 Markdown 输出以时间线为主，不附加关键争议点或证据清单章节

## 快速开始

### 1. 触发技能

当用户提及以下关键词时自动触发：
- "时间线"、"时间轴"
- "事件排序"、"按时间整理"
- "证据时间线"、"案件时间线"
- "可视化展示案件发展过程"

### 2. 提供材料

用户需要提供以下材料之一：
- 证据材料（合同、协议、往来函件、聊天记录、付款凭证等）
- 案件事实描述（包含时间信息）
- 证据清单或证据说明
- 案件相关文档（PDF、Word、图片等）

### 3. 自动生成

技能将自动执行以下流程：
1. 接收并分析材料
2. 提取时间信息
3. 按时间排序和分组
4. 生成 Markdown 时间线文档
5. 生成 HTML 思维导图
6. 输出文件并确认

## 输出文件

### 1. Markdown 时间线文档

**文件名**：`{案件名称}_时间线.md`

**内容结构**：
- 案件基本信息（表格）
- 时间线事件（按分组和月份组织）
- 每个事件包含时间、事件、核心摘要、证据、页码和备注
- 不包含关键争议点、证据清单等非时间线章节

### 2. HTML 思维导图

**文件名**：`{案件名称}_时间线思维导图.html`

**功能特性**：
- 交互式树形图（可展开/折叠节点）
- 鼠标悬停显示详细信息
- 响应式布局（自适应窗口大小）
- 美观的渐变色背景
- 节点按类型着色

**打开方式**：直接用浏览器打开 HTML 文件即可查看

## 技术实现

### Python 脚本

脚本路径：`scripts/generate_timeline_mindmap.py`

**使用方法**：

```bash
# 使用 JSON 字符串
python3 scripts/generate_timeline_mindmap.py \
    --case-name "案件名称" \
    --output "outputs/案件名称_时间线思维导图.html" \
    --data '{"case_name": "案件名称", "basic_info": [...]}'

# 使用 JSON 文件
python3 scripts/generate_timeline_mindmap.py \
    --case-name "案件名称" \
    --output "outputs/案件名称_时间线思维导图.html" \
    --data-file "data/timeline_data.json"
```

**依赖要求**：
- Python 3.7+
- 无需额外 pip 包（仅使用标准库和 CDN 资源）

### 数据格式

JSON 数据结构：

```json
{
  "case_name": "案件名称",
  "basic_info": [
    {"name": "协议编号：XXX"},
    {"name": "甲方：XXX"},
    {"name": "乙方：XXX"}
  ],
  "timeline": [
    {
      "month": "2019年3月",
      "events": [
        {"date": "3月25日", "event": "合作协议签署", "page": "P1-10"}
      ]
    }
  ],
  "disputes": [
    {
      "name": "争议点名称",
      "items": [
        {"name": "约定：XXX"},
        {"name": "实际：XXX"}
      ]
    }
  ],
  "evidence_list": [
    {"name": "证据1<br>证据名称<br>时间<br>页码"}
  ]
}
```

## 约束原则

1. **真实性**：所有事件、时间必须基于用户提供的材料，严禁编造
2. **时间准确性**：时间格式统一，无法确认的时间标注"时间不详"
3. **完整性**：材料中所有包含时间信息的事件都应提取
4. **逻辑性**：事件严格按时间顺序排列，合理分组

## 异常处理

### 用户未提供材料
- 明确告知用户需要提供的材料类型
- 不得基于不充分的信息强行生成

### 时间信息缺失
- 在时间线中标注"时间不详"
- 向用户说明并询问是否可补充

### 时间信息矛盾
- 同时列出多个时间
- 标注"时间存在矛盾，请用户确认"

### HTML 生成失败
- 检查 Python 环境
- 降级方案：仅提供 Markdown 文档
