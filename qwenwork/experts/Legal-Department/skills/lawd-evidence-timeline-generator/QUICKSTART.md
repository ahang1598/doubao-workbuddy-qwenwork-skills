# 证据时间线生成技能 - 快速使用指南

## 什么是证据时间线技能？

这个技能可以帮助你：
- 📅 从案件材料中提取所有时间信息
- 📊 按时间顺序整理事件（从早到晚）
- 🗂️ 智能分组（前期准备、合同签署、履约、违约等）
- 📝 生成专业的 Markdown 时间线文档
- 🌳 生成交互式 HTML 思维导图（可在浏览器中查看）

## 如何使用？

### 步骤 1：触发技能

告诉 AI 你需要生成时间线，例如：
- "帮我生成这个案件的时间线"
- "按时间整理这些证据"
- "生成证据时间线和思维导图"

### 步骤 2：提供材料

提供以下材料之一：
- ✅ 证据材料（合同、协议、往来函件等）
- ✅ 案件事实描述
- ✅ 证据清单
- ✅ 案件相关文档

### 步骤 3：等待生成

AI 将自动：
1. 分析你的材料
2. 提取时间信息
3. 按时间排序和分组
4. 生成 Markdown 文档
5. 生成 HTML 思维导图
6. 输出文件给你

### 步骤 4：查看结果

你会得到两个文件：

#### 1. Markdown 时间线文档
```
outputs/案件名称_时间线.md
```
可以用任何 Markdown 编辑器打开，或导入到 Word/钉钉文档。

#### 2. HTML 思维导图
```
outputs/案件名称_时间线思维导图.html
```
**直接用浏览器打开**，可以看到：
- 🎨 漂亮的渐变色背景
- 🌳 交互式树形图
- 🔍 鼠标悬停显示详情
- 📱 自适应窗口大小
- ➕ 点击节点可展开/折叠

## 示例

### 你说：
```
帮我生成锦溪颐景御府项目的时间线

材料：
- 合作协议（2019年3月签署）
- 股东会决议（2019年2月25日）
- 电子回单（2019年4月1日支付保证金3000万）
- 法务函（2019年8月16日发出）
- 保险费凭证（2019年10月2日）
- 律师费凭证（2019年10月8日）
```

### AI 输出：
1. `outputs/锦溪颐景御府项目_时间线.md` - 完整的时间线文档
2. `outputs/锦溪颐景御府项目_时间线思维导图.html` - 可交互的可视化思维导图

## 技术细节

- **Python 脚本**：`scripts/generate_timeline_mindmap.py`
- **依赖**：Python 3.7+，无需额外 pip 包
- **可视化库**：ECharts 5.x（通过 CDN 加载）
- **输出目录**：`outputs/`

## 注意事项

1. 所有时间信息必须基于实际提供的材料
2. 无法确认的时间标注为"时间不详"
3. 时间矛盾的事件会特别标注
4. 关键节点（截止日期、违约时间等）会特别标记
