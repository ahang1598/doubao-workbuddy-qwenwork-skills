# 劳动争议纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对工资支付诉请 | 确认 / 异议 |
| 2 | 对未签订书面劳动合同双倍工资诉请 | 确认 / 异议 |
| 3 | 对加班费诉请 | 确认 / 异议 |
| 4 | 对未休年休假工资诉请 | 确认 / 异议 |
| 5 | 对未依法缴纳社会保险费造成的经济损失诉请 | 确认 / 异议 |
| 6 | 对解除劳动合同经济补偿诉请 | 确认 / 异议 |
| 7 | 对违法解除劳动合同赔偿金诉请 | 确认 / 异议 |
| 8 | 对劳动仲裁相关情况 | 确认 / 异议 |
| 9 | 其他事由 | 自由填写 |
| 10 | 答辩的依据 | 法律及司法解释的规定（写明具体条文） |

## 二、特殊说明

劳动争议案由的答辩状模板将"答辩事项"和"事实和理由"合并为一张表，不单独设"事实和理由"模块。每项诉请直接选择"确认/异议"并附事由。

## 三、常用法律依据

- 《中华人民共和国劳动合同法》第7条（劳动关系建立）、第10条（书面合同）、第44条（终止）、第46条（经济补偿）、第47条（补偿计算）、第82条（双倍工资）、第87条（赔偿金）
- 《中华人民共和国劳动法》第44条（加班费）、第45条（年休假）
- 《职工带薪年休假条例》
- 《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》
