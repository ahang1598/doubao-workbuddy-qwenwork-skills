# 物业服务合同纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对物业费 | 无异议 / 有异议 |
| 2 | 对违约金 | 无异议 / 有异议 |
| 3 | 对其他请求 | 无异议 / 有异议 |
| 4 | 对标的总额 | 无异议 / 有异议 |
| 5 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实和理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对物业服务合同或前期物业服务合同签订情况（名称、编号、签订时间、地点等） | 无异议 / 有异议 |
| 2 | 对签订主体 | 无异议 / 有异议 |
| 3 | 对物业项目情况 | 无异议 / 有异议 |
| 4 | 对物业费标准 | 无异议 / 有异议 |
| 5 | 对物业服务期限 | 无异议 / 有异议 |
| 6 | 对物业费支付方式 | 无异议 / 有异议 |
| 7 | 对逾期支付物业费违约金标准 | 无异议 / 有异议 |
| 8 | 对欠付物业费数额及计算方式 | 无异议 / 有异议 |
| 9 | 对应付违约金数额及计算方式 | 无异议 / 有异议 |
| 10 | 对催缴情况 | 无异议 / 有异议 |
| 11 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《中华人民共和国民法典》第九百三十七条至第九百五十条（物业服务合同）
- 《物业管理条例》
- 《最高人民法院关于审理物业服务纠纷案件适用法律若干问题的解释》
