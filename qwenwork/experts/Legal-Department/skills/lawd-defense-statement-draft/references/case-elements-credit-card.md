# 银行信用卡纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对透支本金 | 确认 / 异议 |
| 2 | 对利息、罚息、复利、滞纳金、违约金、手续费等 | 确认 / 异议 |
| 3 | 对担保权利诉请 | 确认 / 异议 |
| 4 | 对实现债权的费用 | 无异议 / 有异议 |
| 5 | 对其他请求 | 无异议 / 有异议 |
| 6 | 对标的总额 | 无异议 / 有异议 |
| 7 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实与理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对信用卡办理情况 | 确认 / 异议 |
| 2 | 对信用卡合约的主要约定 | 确认 / 异议 |
| 3 | 对原告对被告就信用卡合约主要条款进行提示注意、说明的情况 | 确认 / 异议 |
| 4 | 对被告已还款金额 | 确认 / 异议 |
| 5 | 对被告逾期未还款金额 | 确认 / 异议 |
| 6 | 对是否向被告进行通知和催收 | 确认 / 异议 |
| 7 | 对是否签订物的担保合同 | 无异议 / 有异议 |
| 8 | 对担保人、担保物 | 无异议 / 有异议 |
| 9 | 对最高额抵押担保 | 无异议 / 有异议 |
| 10 | 对是否办理抵押/质押登记 | 无异议 / 有异议 |
| 11 | 对是否签订保证合同 | 无异议 / 有异议 |
| 12 | 对保证方式 | 无异议 / 有异议 |
| 13 | 对其他担保方式 | 无异议 / 有异议 |
| 14 | 有无其他免责/减责事由 | 无 / 有 |
| 15 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《银行卡业务管理办法》
- 《中华人民共和国民法典》第四百九十六条（格式条款）
- 《中华人民共和国民法典》第六百八十一条至第七百零二条（保证合同）
- 《最高人民法院关于审理银行卡民事纠纷案件若干问题的规定》
