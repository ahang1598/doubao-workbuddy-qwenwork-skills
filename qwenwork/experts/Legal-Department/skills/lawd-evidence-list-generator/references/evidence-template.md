# 证据清单标准模板

## 模板结构

证据清单应严格遵循以下标准结构：

```
                        证 据 清 单（原告提供）
                        
┌────────────────────────────┬──────┬──────────┬────────────────────────────────────┐
│ 序号 │     证 据 名 称      │ 页码 │ 原/复印件 │           证 明 对 象              │
├──────┼──────────────────────┼──────┼──────────┼────────────────────────────────────┤
│      │                      │      │          │                                    │
│      │                      │      │          │                                    │
│      │                      │      │          │                                    │
└────────────────────────────┴──────┴──────────┴────────────────────────────────────┘


提交人（代理律师）：_______________

提交日期：YYYY年MM月DD日
```

## 证据提供者标题规则

根据证据提供者不同，证据清单标题应动态调整：

| 提供者 | 标题格式 | 适用场景 |
|--------|---------|----------|
| 原告 | 证据清单（原告提供） | 原告起诉时提交的证据 |
| 被告 | 证据清单（被告提供） | 被告答辩时提交的证据 |
| 第三人 | 证据清单（第三人提供） | 第三人参与诉讼时提交的证据 |
| 不明确 | 证据清单 | 无法确定提供者时的通用格式 |

**询问话术**：
> 「请问这份证据清单是由哪一方提供的？（原告/被告/第三人/其他）」

## 完整示例：民间借贷纠纷

### 案情简介

原告李某向被告王某出借 50 万元，约定年利率 12%，借期一年。到期后王某仅偿还 20 万元，剩余 30 万元及利息未还。

## 填写要点

### 证据名称
- **必须包含**：形成时间 + 证据类型 + 核心内容
- **示例**：
  - ✅ "2021年3月20日签署的协议书、46万元打款凭证"
  - ❌ "协议书"（缺少时间和核心内容）
  - ❌ "2021年的文件"（过于模糊）

### 证明对象
- **标准表述**：使用"证明……的事实"
- **多项目标**：按逻辑顺序分条列明（1. 2. 3. …）
- **客观准确**：不得夸大或缩小证明范围
- **示例**：
  - ✅ "证明原被告之间存在居间关系，双方明确约定'非原告原因居间不成功则返还全部已交居间费'"
  - ❌ "证明被告恶意违约"（主观推断）
  - ❌ "证明案件事实"（过于宽泛）

### 页码标注
- **连续页码**：使用"起始页-结束页"格式，如"1-3"、"4-8"
- **单页**：直接标注页码，如"5"
- **多份材料页码重排**（重要）：
  - 当用户提供多份证据材料时，必须重新编排连续页码
  - 第 1 份证据从第 1 页开始，后续依次延续
  - 示例：
    - 原始材料：证据1（1-3页）、证据2（5-9页）、证据3（12-15页）
    - 重排后：证据1（1-3）、证据2（4-8）、证据3（9-12）
  - **计算方法**：
    - 第 1 份：起始页=1，结束页=页数
    - 第 N 份（N>1）：起始页=上一份结束页+1，结束页=起始页+页数-1
- **未确认**：标注"待确认"，并在生成后提示用户补充

### 原/复印件标注
- **明确标注**："原件" 或 "复印件"
- **未核实**：标注"复印件（待核实）"，并提示用户核实
- **多份组合**：如"原件3份、复印件2份"

## 注意事项

1. **证据排序**：
   - 按证明目的分组（如先证明合同关系成立，再证明违约事实，最后证明损失金额）
   - 组内按时间先后排序
   - 保持逻辑清晰，便于法官审查

2. **避免重复**：
   - 同一份证据只列一次
   - 多项证明对象在同一证据项下列明，不拆分

3. **页码连续**：
   - 确保证据材料的页码编号连续、无遗漏
   - 如证据材料重新装订，需更新页码

4. **份数准备**：
   - 证据清单正本一份交法院
   - 副本数量 = 对方当事人数量 + 1 份自存
