# 证明对象撰写规范

## 核心原则

证明对象是证据清单的核心内容，必须**精准、具体、客观**，直接体现证据与案件事实的关联性。

## 标准表述格式

### 基本格式

```
证明……的事实
```

### 多项证明对象

同一证据可有多项证明对象时，按逻辑顺序分条列明：

```
1. 证明……的事实。
2. 证明……的事实。
3. 证明……的事实。
```

**排序规则**：
- 先证明基础事实，后证明衍生事实
- 先证明合同/法律关系成立，后证明履行/违约事实
- 先证明主体资格，后证明具体行为

## 撰写规则

### ✅ 应当使用的表述

| 场景 | 标准表述 |
|------|----------|
| 证明合同关系 | "证明原被告之间存在XX合同关系" |
| 证明付款事实 | "证明原告向被告支付了XX元款项的事实" |
| 证明交货事实 | "证明原告已按约向被告交付XX货物的事实" |
| 证明违约事实 | "证明被告未按约履行XX义务的事实" |
| 证明损失金额 | "证明原告因XX遭受损失XX元的事实" |
| 证明催告行为 | "证明原告多次催告被告履行XX义务的事实" |
| 证明时效中断 | "证明原告于XX日向被告主张权利，诉讼时效中断的事实" |
| 证明主体资格 | "证明原告系XX权利合法权利人/利害关系人的事实" |

### ❌ 禁止使用的表述

| 错误类型 | 错误示例 | 正确表述 |
|----------|----------|----------|
| 主观推断 | "证明被告恶意违约" | "证明被告未按约履行付款义务的事实" |
| 夸大证明范围 | "证明被告构成欺诈" | "证明被告在XX方面作出不实陈述的事实" |
| 模糊表述 | "证明案件事实" | "证明XX的具体事实" |
| 法律结论 | "证明被告应承担违约责任" | "证明被告未按约履行义务的事实" |
| 内部分析 | "初步判断被告存在过错" | "证明被告实施了XX行为的事实" |

## 典型场景示例

### 1. 合同纠纷

#### 买卖合同

| 证据 | 证明对象 |
|------|----------|
| 买卖合同 | 1. 证明原被告之间存在钢材买卖合同关系。<br>2. 证明合同约定钢材总价款为120万元。<br>3. 证明合同约定付款期限为货到后30日内。 |
| 送货单 | 1. 证明原告已按约履行交货义务。<br>2. 证明被告于XX日收到全部货物并签收确认。 |
| 催款函 | 1. 证明原告多次催告被告支付剩余货款。<br>2. 证明被告收到催款函后仍未履行付款义务。 |

#### 借款合同

| 证据 | 证明对象 |
|------|----------|
| 借款合同 | 1. 证明原被告之间存在借款合同关系，借款本金为XX万元。<br>2. 证明双方约定借款期限为X年，年利率为X%。<br>3. 证明双方约定逾期还款应承担违约责任。 |
| 转账凭证 | 1. 证明原告已按约向被告交付借款本金XX万元。<br>2. 证明借款交付时间为XX年XX月XX日。 |
| 催款记录 | 1. 证明借款到期后原告多次催要剩余借款。<br>2. 证明被告收到催款通知后仍未履行还款义务。 |

#### 租赁合同

| 证据 | 证明对象 |
|------|----------|
| 租赁合同 | 1. 证明原被告之间存在房屋租赁合同关系。<br>2. 证明合同约定月租金为XX元，押一付三。<br>3. 证明合同约定租赁期限为X年。 |
| 交租凭证 | 1. 证明原告已按约支付租金XX元。<br>2. 证明租金支付时间为XX年XX月XX日。 |
| 退租通知 | 1. 证明被告于XX日单方面通知解除合同。<br>2. 证明被告未按约提前30日通知。 |

### 2. 劳动争议

| 证据 | 证明对象 |
|------|----------|
| 入职登记表 | 1. 证明原告于XX年XX月XX日入职被告公司。<br>2. 证明双方建立劳动关系。 |
| 工资流水 | 1. 证明原告在职期间每月工资发放情况。<br>2. 证明原告离职前12个月平均工资为XX元。<br>3. 证明双方存在事实劳动关系。 |
| 考勤记录 | 1. 证明原告在职期间正常出勤。<br>2. 证明原告不存在严重违纪行为。 |
| 辞退通知书 | 1. 证明被告于XX年XX月XX日单方面解除劳动关系。<br>2. 证明辞退理由为"XX"，非原告过错。 |

### 3. 知识产权侵权

| 证据 | 证明对象 |
|------|----------|
| 专利证书 | 1. 证明原告合法拥有涉案专利权。<br>2. 证明涉案专利目前处于有效状态。<br>3. 证明专利权利要求保护的技术方案。 |
| 侵权产品 | 1. 证明被告生产、销售涉案产品。<br>2. 证明被告产品使用了与涉案专利相同的技术方案。 |
| 技术比对报告 | 1. 证明被告产品技术特征落入涉案专利保护范围。<br>2. 证明被告产品与涉案专利权利要求的技术特征相同/等同。 |

### 4. 侵权责任纠纷

| 证据 | 证明对象 |
|------|----------|
| 交通事故认定书 | 1. 证明被告对事故负全部责任。<br>2. 证明事故发生时间为XX年XX月XX日。<br>3. 证明事故造成原告车辆受损。 |
| 医疗费票据 | 1. 证明原告因事故支出医疗费XX元。<br>2. 证明原告在XX医院接受治疗。 |
| 修车发票 | 1. 证明原告车辆维修费用为XX元。<br>2. 证明车辆维修时间为XX年XX月XX日。 |

## 常见错误及修正

### 错误 1：主观推断

**错误示例**：
```
证明被告恶意违约、欺诈原告的事实
```

**修正**：
```
1. 证明被告未按约履行付款义务的事实。
2. 证明被告在签订合同时隐瞒XX事实的情况。
```

### 错误 2：证明范围过宽

**错误示例**：
```
证明本案全部事实
```

**修正**：
```
1. 证明原被告之间存在XX合同关系的事实。
2. 证明被告未按约履行XX义务的事实。
3. 证明原告因此遭受损失XX元的事实。
```

### 错误 3：法律结论

**错误示例**：
```
证明被告应承担违约责任
```

**修正**：
```
证明被告未按约履行XX义务的事实
```

### 错误 4：内部分析语言

**错误示例**：
```
初步判断被告存在重大过错
```

**修正**：
```
证明被告实施了XX行为的事实
```

## 审查清单

在撰写证明对象后，逐项检查：

| 检查项 | 标准 | 处理方法 |
|--------|------|----------|
| 是否客观准确 | 无主观推断、无夸大 | 删除"恶意""欺诈"等主观词汇 |
| 是否具体明确 | 指向具体事实而非宽泛概念 | 补充具体金额、时间、行为 |
| 是否符合标准表述 | 使用"证明……的事实" | 修正不符合格式的表述 |
| 是否超出证据范围 | 证明对象不超出证据能证明的范围 | 删除无法证明的内容 |
| 是否多项目标已分条 | 多项证明对象按逻辑编号 | 使用"1. 2. 3."分条列明 |
| 是否避免法律结论 | 不写"应承担XX责任" | 改为"证明……的事实" |

## 注意事项

1. **证明对象与证据内容必须匹配**：不得要求证据承担超出其证明能力的证明任务

2. **多项证明对象应逻辑递进**：
   - 先证明基础法律关系（合同/侵权/劳动关系等）
   - 再证明履行/违约/侵权事实
   - 最后证明损失/后果

3. **避免重复**：同一事实在多份证据中都有证明时，应在每份证据的证明对象中都列明，不可省略

4. **与诉请对应**：证明对象应能支撑诉讼请求的每一项主张

5. **简明扼要**：每项证明对象控制在 50 字以内，避免冗长表述
