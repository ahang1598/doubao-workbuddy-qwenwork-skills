**查询时间：** {YYYY-MM-DD HH:MM}
**数据来源：** {运行时实际匹配到的企业工商信息连接器展示名}（能力域与探测规则见 SKILL.md §四）

### 来源代码规范

按**数据能力域**定义来源代码（不按供应商定义；具体连接器展示名在「来源名称」列由运行时填写）：

| 数据能力域 | 代码 |
|---------|------|
| 企业主体定位 / 工商登记 | `[REG]` |
| 股权结构与关联穿透 | `[EQT]` |
| 裁判文书 / 涉诉记录 | `[JUD]` |
| 强制执行与信用惩戒（被执行/失信/限高/终本） | `[EXEC]` |
| 历史司法（历史涉诉/历史执行/公告） | `[HIST]` |
| 经营异常与合规负面（异常/处罚/欠税/破产） | `[NEG]` |
| 指定人员涉诉与执行 | `[PSN]` |
| 补充检索 · 信用中国 | `[WEB-CREDIT]` |
| 补充检索 · 裁判文书网 | `[WEB-WENSHU]` |
| 补充检索 · 新闻舆情 | `[WEB-NEWS]` |

> `[WEB-*]` 类来源为**补充增信**，可靠性一律标注为「未核验」，**不得**用于顶替 `[REG]`/`[JUD]`/`[EXEC]` 等工商连接器数据（见 SKILL.md §四降级规则）。

## 填写规则

1. **章节不得省略**：即使数据缺失也保留章节框架，标注"数据缺失"
2. **一句话结论必须明确**：Decision Pack 的结论不得含糊（如"需进一步评估"），必须给出方向性判断
3. **数据必须有锚**：每个判断必须附带证据来源代码
4. **金额统一**：全文统一使用"万元"为单位（超过 1 亿的用"亿元"）
5. **执行风险评级唯一**：整份报告只有一个执行风险评级，在 Decision Pack 和 §7.2 中保持一致
