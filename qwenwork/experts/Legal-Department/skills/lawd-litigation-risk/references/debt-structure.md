# 债务压力三层结构与清偿率公式

## 三层债务结构

### 第一层：显性优先顺位债务

在清偿顺序中排在普通债权之前。

| 类型 | 优先依据 | 数据来源（能力语义） |
|------|---------|---------|
| 欠税 | 税收优先权（《税收征收管理法》第四十五条） | 「欠税公告」能力 |
| 职工工资 / 社保 | 工资优先权（《企业破产法》第一百一十三条） | 无直接数据，可从参保人数估算 |
| 有抵押担保的债权 | 优先受偿权（《民法典》第四百一十条） | 「资产与权利负担」能力：动产抵押 + 土地抵押 + 股权质押金额 |

### 第二层：已判决未执行债务

属于"已在排队等执行"的先行债权人，与原告处于相同顺位。

| 数据 | 来源（能力语义） |
|------|------|
| 当前被执行案件金额总和 | 「被执行人」能力返回的涉案金额汇总 |
| 终本案件未执行金额 | 「终本案件」能力返回的涉案金额汇总 |

### 第三层：潜在债务

不直接影响当前保全，但在清偿率测算时需考虑。

| 类型 | 来源（能力语义） |
|------|------|
| 对外担保（或有债务） | 「对外担保」能力 |
| 在诉未结案件潜在判赔 | 「涉诉记录」能力中的在诉案件 |

## 清偿率测算公式

```
原告预期回收率 ≈ (可执行资产净值 - 第一层优先债务) × (原告债权 / 所有等同顺位债权总和) / 原告债权
```

### 分步计算

1. **可分配资产** = 可执行资产净值 - 第一层优先债务
2. **等同顺位债权总和** = 第二层（已判决未执行） + 原告债权
3. **原告占比** = 原告债权 / 等同顺位债权总和
4. **预期回收金额** = 可分配资产 × 原告占比
5. **回收率** = 预期回收金额 / 原告债权

### 计算示例

```
假设：
- 被告可执行资产净值 = 500 万
- 第一层优先债务（欠税+抵押）= 100 万
- 第二层已判决未执行 = 800 万
- 原告债权 = 200 万

计算：
- 可分配资产 = 500 - 100 = 400 万
- 等同顺位总和 = 800 + 200 = 1000 万
- 原告占比 = 200 / 1000 = 20%
- 预期回收 = 400 × 20% = 80 万
- 回收率 = 80 / 200 = 40%
```

## 回收率区间（非单一数字）

必须给出区间，不得只给单一数字：

| 假设类型 | 处理方式 |
|---------|---------|
| **保守假设** | 资产按下限估值、第一层优先债务按上限计、不计入未明确的潜在资产 |
| **中性假设** | 资产按中值估值、第一层按实际已知金额 |
| **激进假设** | 资产按上限估值、将部分可能资产纳入计算 |

输出格式：`预期回收率：{保守}% - {激进}%（中性 {中性}%）`

## 保全金额建议

| 场景 | 建议保全金额 |
|------|------------|
| 可执行资产 > 债权金额 | 保全金额 = 债权金额（全额保全） |
| 可执行资产 < 债权金额 | 保全金额 = 可执行资产 × 80-90%（避免浪费保全担保金） |
| 可执行资产极少 | 保全金额 = 实际可保全标的总额 |

**保全担保金提示**：法院一般要求申请人提供保全金额 10-30% 的担保，报告中应提醒律师预留担保金预算。
