### 模式A ｜ 诉讼风险评估

> **外移说明**：本文件为 Mode A（诉讼风险评估）完整工作流细则，自 `SKILL.md` 三、模式工作流 原样移出。数据源（企业工商信息查询）的探测/匹配/调用/降级规则见 `SKILL.md` §四，交付门禁脚本见 §五，交付物要求见 §六。

立案前的对手方诉讼风险全景评估。三层穿透扫描（企业当前司法 × 企业历史轨迹 × 核心人员涉诉），输出执行风险评级与立案建议。

#### A · 工作流程概览

| 阶段 | 职责 | 详见 |
|------|------|------|
| Step A0 | **实体锚定**：消歧到唯一企业 | §A0 |
| Step A1 | **数据源探测与匹配** | §四 |
| Step A2 | **企业当前层**：5 维司法 + 风险概览 | §A2 |
| Step A3 | **企业历史层**：历史司法时间序列 | §A3 |
| Step A4 | **核心人员层**：法代/实控人涉诉 | §A4 |
| Step A5 | **补充检索**：信用中国 + 裁判文书 + 舆情 | §A5 + [websearch-strategy.md](websearch-strategy.md) |
| Step A6 | **综合分析与输出**：9 章报告 | §A6 + [output-report.md](output-report.md) |

#### A · 输入要求

| 字段 | 必填 | 说明 |
|------|------|------|
| `searchKey` | ✅ | 对手方企业名 / USCC / 简称 |
| `humanName` | ❌ | 目标人员姓名（法代/实控人，用于 Step A4） |

#### §A0：实体锚定

**输入分流（仅作用于 searchKey）**

| 输入形式 | 处理 |
|---------|------|
| **USCC**（正则 `^[0-9A-Z]{18}$`） | 直接进数据采集 |
| **完整企业名**（含"有限公司/股份/集团"后缀且长度 ≥ 6） | 直接进数据采集 |
| **简称 / 品牌名** | 用「企业主体定位」能力消歧 → 用户确认 |
| **企业名被遮挡/脱敏**（从诉讼材料中读取时常见） | 用间接线索组合推导：合同编号、项目名、注册地址片段、USCC 末位、法代姓名等，拼成候选搜索词走消歧流程；仍无法确定时向用户询问 |

**消歧流程**

1. 调用 §四 匹配到的「企业主体定位」能力（模糊搜索/企业检索语义）
2. 候选 = 1 → 自动锚定
3. 候选 ≥ 2 → 列出候选清单，让用户选择
4. 候选 = 0 → 终止流程，提示"未找到匹配企业，请提供更完整的名称或 USCC"

**注意**：不自行猜选。错锚定的代价远大于等待。

`humanName` 不参与 §A0，原样透传至 §A4。

#### §A2：企业当前层（5 维司法 + 风险概览）

**所需能力与语义关键词**（用于 §四 的匹配与 schema 验证，不写死工具名）

| 维度 | 语义关键词（工具名或 description 命中即可） | 必需返回字段 |
|------|------|------|
| 裁判文书 / 涉诉 | 裁判文书、涉诉、判决、judicial、writ、litigation | 案号、案由、当事人身份、裁判日期、涉案金额（或至少件数统计） |
| 失信被执行人 | 失信、dishonest | 记录数、立案时间、执行法院、失信情形 |
| 被执行人 | 被执行、执行、judgment_debtor、executed | 案件数、执行标的金额、执行法院 |
| 限制高消费 | 限高、限制高消费、high_consumption | 记录数、限制对象、立案日期 |
| 终本案件 | 终本、终结本次执行、terminated | 案件数、未执行金额 |
| 风险概览（可选） | 风险概览、风险、risk_overview | 各风险项计数 |

**执行规则**

- 6 项**并行调用**
- 失败维度标记"数据获取失败"，不阻断
- **全部维度均失败** = 工商数据未取得 → 走 §四 A 档降级

**分析要点**

输出**五维司法清查表**：

| 风险维度 | 记录数 | 评级 |
|---------|--------|------|
| 裁判文书 | N 件 | ✅安全 / ⚠️警示 / ❌高危 |
| 被执行人 | N 件 | ... |
| 失信 | N 条 | ... |
| 限高 | N 条 | ... |
| 终本 | N 件 | ... |

评级标准见 [risk-scoring.md](risk-scoring.md)（含行业调节因子、诉讼频率严重性判断、案由集中度分析）。

#### §A3：企业历史层

**所需能力与语义关键词**

| 维度 | 语义关键词 |
|------|------|
| 历史裁判文书 | 历史裁判、历史涉诉、historical_judicial |
| 历史失信 | 历史失信、historical_dishonest |
| 历史被执行 | 历史被执行、historical_judgment_debtor |
| 历史法院公告 | 法院公告、court_notice |
| 历史开庭公告 | 开庭公告、hearing_notice |

**执行规则**

- 5 项并行调用
- 已匹配连接器不提供历史维度时跳过本层，标注"历史司法层未核验（已匹配连接器不提供历史司法能力）"，并在置信度章节下调

**分析要点**

按年分桶统计，输出**年度诉讼趋势表**：

| 年度 | 裁判文书 | 失信 | 被执行 | 趋势标注 |
|------|---------|------|--------|---------|
| 2026 | N | 0 | 0 | ... |
| 2025 | N | 0 | 0 | ... |
| ... | ... | ... | ... | ... |

识别趋势：上升/平稳/下降/峰值年/集中爆发。

#### §A4：核心人员层（条件必做）

**触发规则**：默认查询法定代表人；**实控人控制比例 ≥ 30% 或通过多层架构间接控制企业时，实控人风险画像为必做项**（高比例实控人的个人信用与企业偿债能力直接相关，尤其房地产项目公司）。

**前置条件**

- 需要 `humanName`（由用户提供，或从 §A2 工商登记信息中获取法代姓名）
- 若用户未提供且工商数据中可获取法代姓名，自动使用法代姓名

**所需能力与语义关键词**

| 维度 | 语义关键词 |
|------|------|
| 人员失信 | 人员失信、personnel_dishonest、person + 失信 |
| 人员被执行 | 人员被执行、personnel_judgment_debtor |
| 人员限高 | 人员限高、personnel_high_consumption |
| 人员终本 | 人员终本、personnel_terminated |

**执行规则**

- 4 项并行调用
- 入参按所选工具 schema 适配（一般需「企业标识」+「人员姓名」两个语义入参；只支持姓名时须在结果中人工核对企业归属）
- 无人员维度能力时跳过，标注"核心人员涉诉未核验"

#### §A5：补充检索

**执行前必须实际 Read [websearch-strategy.md](websearch-strategy.md)**，未读取不得开始补充检索。

| 触发条件 | 搜索策略 | 最大次数 |
|---------|---------|---------|
| **必做** | `"{企业全称}" site:creditchina.gov.cn` | 1 |
| §A2 发现裁判文书 ≥ 5 件 | `"{企业全称}" 案号 裁判文书`（重点案件详情） | 2 |
| §A2 开庭公告中多次出现与本案直接相关的案件（如同一相对方、同一项目多次开庭） | 针对该案件做 1-2 次详情检索（审理进展、争议焦点），不受 ≥5 件阈值限制 | 2 |
| §A2 发现被执行/失信 | `"{企业全称}" 被执行人 OR 失信 最新` | 1 |
| 可选 | `"{企业全称}" 风险 OR 诉讼 OR 纠纷`（舆情） | 1 |

- 单次报告补充检索 **不超过 5 次**
- 搜索失败不阻断
- 所有补充检索结果必须标注 `[WEB-*]` 来源代码与「未核验」；**不得**用于顶替工商连接器数据（详见 §四降级规则与 [websearch-strategy.md](websearch-strategy.md)）

#### §A6：综合分析与输出

**报告模板**

**必读** [output-report.md](output-report.md)：含完整 9 章报告模板、来源代码规范与填写规则。

**9 章结构**

| 章节 | 内容 |
|------|------|
| 一、执行摘要 · Decision Pack | 一句话结论 + 推荐 Action（按优先级） + 执行风险评级 |
| 二、数据来源与说明 | 来源代码 + 采集时间 + 可靠性星级 + 法律约束力 + 互证方法 |
| 三、主体工商基本信息 | 企业身份核实 + 资质 + 融资阶段 |
| 四、企业当前诉讼地位 | 五维司法清查 + 案由分布 |
| 五、企业历史诉讼轨迹 | 年度趋势 + 历史扫描汇总 |
| 六、关键案件文书摘要 | 重点案件表（案号/案由/角色/结果/金额/参考意义） |
| 七、诉讼类型风险模式分析 | 结构性特征 + 执行风险矩阵 |
| 八、立案建议 | 胜诉概率推演 + 执行风险评级 + 建议措施 |
| 九、置信度分布 | 各章节置信度 + 证据锚 + 综合置信度 |

**执行风险评级**

| 等级 | 条件 | 含义 |
|------|------|------|
| **极低** | 失信/被执行/限高/终本 全零 + 历史清洁 | 判决后执行无障碍 |
| **低** | 当前无失信/限高/终本，被执行少量 | 判决后大概率可执行 |
| **中** | 有被执行但无失信，或历史有失信已修复 | 需配合保全措施 |
| **高** | 当前失信或终本 | 执行困难，需保全+追加被告 |
| **极高** | 多件终本 + 失信 + 限高 + 已注销/破产 | 执行几乎不可能 |

**胜诉概率表述规则（门禁项）**：胜诉概率**不得**给无依据的单一精确数值。必须①以区间表述（如"55%-70%"），或②给出明确依据（对应的历史同类案件样本、五维司法结果、财务/执行事实），二者至少满足其一。

**门禁已知陷阱**：门禁脚本对全文检测概率类表述——**概率/清偿率分析只允许出现在第八章「立案建议」的胜诉概率推演部分**；Decision Pack、执行摘要等其他章节一律用定性表述（如"证据链完整""主要风险在于…"），出现"胜诉概率较高"等表述会被拦截。
