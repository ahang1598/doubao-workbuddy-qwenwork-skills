# 法律分析建议书模板

本模板定义了《法律分析建议书》(.docx) 的标准结构和排版要求。
报告撰写时必须严格按照以下结构展开，整体风格对标正式律所出具的法律分析建议书/法律服务建议书，拒绝简报式输出。

---

## 封面页

封面页为独立一页，包含两部分：

### 第一部分：信息栏（页面顶部，表格形式）

| 项目 | 内容 |
|------|------|
| **致/To** | {客户公司全称}（以下简称"贵司"或"贵方"） |
| **抄送/CC** | {如有，列出抄送对象} |
| **自/From** | {律所/法务团队名称} |
| **事由/Subject** | 关于{案件简述}之法律分析建议书 |
| **出具日期/Date** | {YYYY年M月D日} |
| **文件编号** | {如有} |

### 第二部分：标题页（页面居中，独立排版）

```
{律所/法务团队名称}

关于

{客户公司全称}

{案件/事务描述}

之

法律分析建议书

{中文日期，如"二〇二六年四月"}
```

## 前言

> 前言为独立一页，包含致辞、免责声明和敬语。格式如下：

```
{客户公司全称}（以下称"贵司"/"贵方"）、{抄送对象}：

关于贵方所涉{案件/事务简述}，我们准备了本法律分析建议书，将我们对该法律事务的
初步分析、法律意见及应对策略等向贵方作出介绍，供贵方卓参。

【重要声明与保密限制】

1. 基于给定事实：本意见书系基于贵方截至{日期}向我们提供的口述背景、书面材料及
   电子数据出具。我们假定贵方提供的所有材料及陈述均是真实、完整且未经隐瞒的。
   若基础事实发生变化，本意见书之结论可能需相应调整。

2. 适用法律：本意见书仅依据出具日现行有效的中国大陆法律、行政法规及最高人民法院
   的司法解释/裁判指导意见作出，不涵盖其他司法管辖区的法律评估。

3. 非诉讼保证：本意见书为独立专业判断，不代表法院、仲裁机构或行政机关的最终裁决
   结果。随着调查的深入以及案情的发展，我们随时有可能调整本法律分析建议。

4. 保密性：本文件属于保密信息，未经书面同意，不得向任何第三方披露或作为呈交
   司法机关的证据。

以上法律分析建议，供贵方参酌。

顺颂商祺！

{律所/法务团队名称}
{中文日期}
```
