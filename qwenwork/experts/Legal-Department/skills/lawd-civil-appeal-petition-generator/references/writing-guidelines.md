# 上诉请求与上诉理由写作指南

## 一、上诉状的写作定位

民事上诉状的核心不是“再讲一遍案件事实”，而是围绕一审裁判进行纠错。文书应服务于三个目标：

1. 让二审法官迅速知道上诉人不服哪几项判决；
2. 让二审法官明确上诉人希望如何改判或是否请求发回重审；
3. 让二审法官看到原审裁判在事实、证据、法律或程序上的具体错误。

## 二、上诉请求写作规则

### 1. 必须对应一审判项

写请求前，先逐项拆解一审判决主文：

| 一审判项 | 是否不服 | 上诉请求写法 |
|----------|----------|--------------|
| 第1项 | 不服 | 请求撤销第1项并改判…… |
| 第2项 | 部分不服 | 请求撤销第2项中关于……部分并改判…… |
| 第3项 | 服从 | 可写维持第3项，或不写 |

### 2. 避免模糊请求

| 不推荐 | 推荐 |
|--------|------|
| 请求二审法院依法改判 | 请求撤销原判第一项，改判被上诉人向上诉人支付货款人民币××元及逾期付款损失 |
| 请求维护上诉人合法权益 | 请求依法驳回被上诉人一审全部诉讼请求 |
| 请求重新审理本案 | 请求裁定撤销原判，发回××人民法院重审 |
| 请求减少赔偿金额 | 请求将原判第二项赔偿金额由××元改判为××元 |

### 3. 常见请求类型

**撤销型：**

```markdown
撤销【一审法院】【案号】民事判决第【】项。
```

**改判型：**

```markdown
依法改判被上诉人向上诉人支付【款项性质】人民币【金额】元及【利息/违约金/损失】。
```

**驳回型：**

```markdown
依法改判驳回被上诉人一审全部/部分诉讼请求。
```

**发回型：**

```markdown
依法裁定撤销原判，发回【一审法院】重审。
```

**费用型：**

```markdown
本案一、二审诉讼费用由被上诉人承担。
```

## 三、上诉理由写作框架

每一项上诉理由建议采用以下链条：

```markdown
原审认定/处理 → 错误所在 → 证据或法律依据 → 应如何认定/处理 → 对应上诉请求
```

### 标准段落结构

```markdown
原审认为：【概括原审认定】。

上诉人认为，原审上述认定缺乏充分证据支持/适用法律错误/未对关键证据予以审查，理由如下：

首先，【说明证据或事实】。
其次，【说明原审逻辑漏洞或法律适用问题】。
再次，【说明正确认定或处理方式】。

因此，原审关于【事项】的认定/处理应予纠正，二审法院应据此支持上诉人第【】项上诉请求。
```

## 四、常见上诉理由类型

### 1. 事实认定错误

适用情形：原审认定的关键事实与证据不符，或遗漏影响裁判结果的事实。

常用表达：
- 原审关于【事实】的认定缺乏充分证据支持；
- 原审未查明【关键事实】，导致裁判基础不完整；
- 原审对【事实】的认定与【证据】所反映的客观情况不符；
- 原审仅依据【单一证据】即认定【事实】，未综合审查全案证据。

### 2. 证据采信或证明力评价错误

适用情形：原审遗漏关键证据、片面采信对方证据、未回应质证意见或证据链断裂。

常用表达：
- 原审未对【证据名称】的真实性、关联性及证明力作出充分评价；
- 【证据A】与【证据B】能够相互印证，足以证明【事实】；
- 被上诉人提交的【证据】不能达到其证明目的，原审予以采信不当；
- 原审忽视【证据组】之间形成的完整证据链。

### 3. 法律适用错误

适用情形：法律关系定性错误、适用法条错误、法律后果判断错误。

常用表达：
- 原审对本案法律关系性质认定不当；
- 原审未结合合同约定及实际履行情况判断双方权利义务；
- 原审适用【法律规则】处理本案，与本案事实基础不符；
- 根据现行法律关于【事项】的规定，本案应认定为【正确结论】。

### 4. 程序违法或程序处理不当

适用情形：剥夺辩论权、未经合法传唤、遗漏必要当事人、遗漏诉请、超出诉请裁判等。

常用表达：
- 原审未就【事项】充分组织举证质证，影响案件事实查明；
- 原审遗漏审理上诉人在一审中提出的【诉请/抗辩】；
- 原审对【程序事项】的处理可能影响案件公正裁判；
- 原审判项超出当事人诉讼请求范围，应予纠正。

## 五、新证据说明规则

如存在二审新证据，不要混入理由正文，应单独列明：

```markdown
## 关于二审新证据的说明

上诉人拟向二审法院提交以下新证据：

1. 【证据名称】
   - 来源：【说明来源】
   - 证明目的：证明【具体事实】
   - 一审未提交原因：【说明客观原因】
   - 与本案关系：该证据足以证明原审关于【事项】的认定存在错误。
```

注意：不能仅写“现有新证据”，必须说明来源、证明目的和未在一审提交的原因。

## 六、语言风格规范

### 推荐风格

- 专业、克制、精准；
- 直接指向裁判错误；
- 用事实、证据和法律说服；
- 避免复杂套娃编号，优先使用清晰分点。

### 推荐表达

- 原审认定缺乏充分证据支持；
- 原审未对全案证据予以综合审查；
- 原审对关键证据的证明力评价不当；
- 原审适用法律存在偏差；
- 原审对本案法律关系性质认定不当；
- 上述错误已经影响本案实体处理结果。

### 避免表达

- 原审明显偏袒对方；
- 被上诉人恶意狡辩；
- 一审判决完全错误、荒唐；
- 请求法院主持公道；
- 上诉人实在不能接受；
- 事实非常清楚、无需多言。

## 七、质量自检表

| 检查项 | 合格标准 |
|--------|----------|
| 请求明确性 | 每项请求有明确撤销、改判、发回或费用承担内容 |
| 判项对应性 | 上诉请求能对应一审判决主文具体项 |
| 理由针对性 | 理由直接指向原审裁判错误，而非泛泛陈述纠纷经过 |
| 证据支撑 | 每个事实类理由至少对应一组证据或庭审材料 |
| 法律审慎 | 未核验法条不写死条号，使用保守规范表述 |
| 语言克制 | 无情绪化、人身攻击或口号化表达 |
| 缺失处理 | 缺失信息标注待补充，不自行编造 |

## 八、生成策略

信息充分时，生成正式完整版本。

信息部分缺失但用户要求先出草稿时：
- 使用占位符标明待补充信息；
- 在文末列出“提交前需补充/核验事项”；
- 不得声称该版本可直接提交。

信息严重不足时，先列出补充清单，不生成正式上诉状。
