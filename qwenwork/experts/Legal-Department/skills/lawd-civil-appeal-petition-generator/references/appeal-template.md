# 民事上诉状标准模板

## 模板一：基础民事上诉状

> **格式说明**：
> - 标题：居中，宋体，二号
> - 正文：仿宋，三号，1.5倍行距，首行缩进2字符
> - 尾部：全部靠右对齐

```markdown
【居中】民事上诉状【/居中】

上诉人（原审×告）：【姓名/名称】，【性别】，【出生日期】，【民族】，【职业】，【住所地】，【联系方式】。

法定代表人/负责人：【姓名】，【职务】。

被上诉人（原审×告）：【姓名/名称】，【性别】，【出生日期】，【民族】，【职业】，【住所地】，【联系方式】。

法定代表人/负责人：【姓名】，【职务】。

上诉人因与被上诉人【案由】一案，不服【一审法院】于【裁判日期】作出的【案号】民事判决/裁定，现依法提起上诉。

## 上诉请求

1. 撤销【一审法院】【案号】民事判决第【】项；
2. 依法改判【写明具体改判内容：金额、行为给付、责任承担、驳回对方请求等】；
3. 本案一、二审诉讼费用由被上诉人承担。

## 事实与理由

一、原审关于【争议事项】的事实认定缺乏充分证据支持，应予纠正。

原审认为：【概括原审认定】。

但根据【证据名称/庭审查明事实/双方陈述】可以证明：【说明相反或补充事实】。原审未对【关键证据或事实】予以综合审查，导致对【关键争议事实】的认定存在偏差。

因此，二审法院应依法重新审查上述事实，并据此支持上诉人的上诉请求。

二、原审对【证据名称/证据组】的采信或评价存在错误，影响案件基本事实认定。

【说明原审如何采信/未采信】。该处理存在以下问题：
1. 【问题一：真实性、关联性、证明力或证据链问题】；
2. 【问题二：与其他证据相互印证或矛盾之处】；
3. 【问题三：原审遗漏审查或片面理解之处】。

上述证据足以证明【拟证明事实】，原审未予采纳或未充分评价，导致裁判结果不当。

三、原审适用法律存在错误，应依法改判。

本案法律关系应认定为【法律关系】，而非原审认定的【法律关系】。基于【合同约定/交易模式/履行情况/法律规定】，本案应适用【法律依据或保守表述：现行法律关于……的规定】。

原审适用【法律或裁判规则】处理本案，未能准确评价【关键法律事实】，导致判决结果错误。故请求二审法院依法予以纠正。

四、原审存在程序处理不当，可能影响案件公正审理。（如适用）

原审在【举证、质证、审理范围、缺席审理、诉请处理等】方面存在【具体程序问题】。该程序问题导致【具体影响】，已可能影响案件实体处理结果，依法应予纠正。

综上，原审判决认定事实不清、证据评价不当、适用法律错误/程序处理不当，依法应予撤销或改判。为维护上诉人的合法权益，特提起上诉，请求二审法院依法支持上诉人的全部上诉请求。

【右对齐】
此致

【二审法院】

上诉人：【签名/盖章待补充】

【日期待补充】

附：本上诉状副本【】份。
【/右对齐】
```

## 模板二：请求发回重审版本

适用于原审存在严重事实不清、基本事实缺乏证据证明、程序违法或遗漏必要当事人等情形。

```markdown
## 上诉请求

1. 撤销【一审法院】【案号】民事判决；
2. 依法将本案发回【一审法院】重审；
3. 本案一、二审诉讼费用由被上诉人承担。
```

理由部分应重点论证：
- 原审基本事实尚未查清；
- 关键证据未经充分质证或审查；
- 程序问题已经影响实体裁判；
- 二审直接改判的事实基础不足。

## 模板三：部分改判版本

适用于只对一审判决部分判项不服。

```markdown
## 上诉请求

1. 撤销【一审法院】【案号】民事判决第【】项；
2. 依法改判【具体改判事项】；
3. 维持原判第【】项；
4. 本案一、二审诉讼费用由被上诉人承担。
```

注意：
- 必须说明不服的具体判项；
- 对有利判项避免误写为全部撤销；
- 改判请求须与撤销判项一一对应。

## 上诉起因固定句式

```markdown
上诉人因与被上诉人【案由】一案，不服【一审法院】于【裁判日期】作出的【案号】民事判决/裁定，现依法提起上诉。
```

## 尾部格式

> **重要**：尾部所有内容必须靠右对齐

```markdown
【右对齐】
此致

【二审法院】

上诉人：【签名/盖章待补充】

【日期待补充】

附：本上诉状副本【按对方当事人人数填写】份。
【/右对齐】
```

## 信息缺失占位规则

信息缺失时使用以下占位，不得自行编造：
- 法院不明：`【法院名称待补充】`
- 案号不明：`【案号待补充】`
- 日期不明：`【裁判日期待补充】`
- 金额不明：`【金额待核实】`
- 证据不明：`【证据名称/页码待补充】`
- 法条未核验：`依据现行法律关于【事项】的规定`
