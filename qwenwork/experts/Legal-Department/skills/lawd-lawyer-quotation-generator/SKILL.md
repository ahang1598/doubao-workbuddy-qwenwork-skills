# 法律服务方案生成器

## 概述

根据用户提供的案件信息和服务需求，生成专业的法律服务报价方案文档。支持多种报价模板和收费模式，输出符合律所商务规范的完整报价方案。

## 约束原则

### 1. 模板规范性
**所有输出必须遵循律师事务所的商务文书规范**，包括正式称谓、结构化排版、规范用语。严禁输出非正式或口语化的内容。

### 2. 收费合规性
报价方案中的收费标准应符合相关法律法规规定，包括：
- 司法部、国家发展和改革委员会等相关收费规定
- 各省/市律师服务收费管理办法
- 风险代理收费限制（最高不超过标的额30%，刑事案件禁止风险代理）

### 3. 信息完整性
每份报价方案必须包含：
- 委托事项描述
- 收费模式及金额
- 付费时间/条件
- 必要的脚注和说明

### 4. 灵活性条款
每份报价方案应包含弹性条款，如"复杂程度超出合理预期可另行协商"等，保护双方利益。

## 支持范围

### 报价模板类型

| 模板类型 | 适用场景 | 核心模块 |
|---------|---------|---------|
| **仅报价** | 案件简单明确、客户已了解服务内容 | 报价表格 + 脚注 |
| **报价+服务内容** | 需要明确服务范围的标准案件 | 报价表格 + 服务内容清单 |
| **标准+费用** | 需要引用法规标准增强说服力的案件 | 收费标准法规引用 + 收费方案 |
| **服务内容+团队+价格** | 高端/复杂案件，需全面展示律所实力 | 服务内容 + 团队介绍 + 价格方案 |
| **团队+费用** | 再审/疑难案件，需突出团队专业性 | 团队介绍 + 费用报价 + 律师简历 |

### 收费模式

| 收费模式 | 说明 | 适用场景 |
|---------|------|---------|
| **分阶段固定费用** | 按诉讼进度分批支付固定金额 | 诉讼案件（一审、二审、再审） |
| **基础代理费 + 风险代理费** | 基础固定费用 + 按结果支付比例费用 | 胜诉可能性较大的案件 |
| **计时收费** | 基础包含固定时长，超时按小时计费 | 非诉讼法律服务、商业谈判 |
| **固定费 + 比例风险费** | 固定金额 + 按减损/收回金额的百分比 | 仲裁案件、债务纠纷 |
| **阶段固定 + 风险代理费** | 分阶段固定金额 + 按结果支付比例费用 | 再审、复杂诉讼 |

### 案件类型覆盖
- 股东纠纷（资格确认、知情权、损害公司利益等）
- 合同纠纷（买卖、借款、投资等）
- 投融资纠纷（私募基金、股权投资等）
- 公司纠纷（股权转让、公司治理等）
- 民事再审案件
- 仲裁案件
- 其他商事争议

## 工作流程

**以下步骤必须严格按顺序执行，不得跳步。**

### Step 1：信息收集

通过提问引导用户提供必要信息：

**必选项：**
- **客户名称**：报价对象的公司/个人名称（可用"XXXX"代替）
- **案件类型**：股东纠纷/合同纠纷/投融资纠纷/公司纠纷/仲裁/再审等
- **委托事项描述**：简要描述案件基本情况
- **收费模式偏好**：分阶段固定/基础代理费+风险代理费/计时/固定+比例/阶段固定+风险代理费

**需向用户确认（不得自行填写）：**
- **各阶段/项目的具体律师费金额**：必须向用户逐项确认每个收费项目的金额，用户未确认的金额一律使用"{待确认}"占位符
- **风险代理费金额或比例**：必须向用户确认具体数额或百分比
- **如有多个方案**：需为每个方案确认不同的金额设置，方案间应体现差异化（如高/中/低三档）
- **计时收费的小时费率和包含时长**：必须向用户确认
- **费用上限/封顶金额**：如涉及费用封顶，必须向用户确认

**条件必选项：**
- **标的金额**：涉及财产争议的案件需提供
- **诉讼阶段**：一审/二审/再审/仲裁/执行
- **相对方信息**：对方当事人的基本描述

**可选项：**
- **模板类型**：仅报价/报价+服务内容/标准+费用/服务内容+团队+价格/团队+费用
- **律师团队信息**：主办律师姓名、执业年限、专长领域
- **律所名称**：默认使用"XX律师事务所"
- **期望报价区间**：基础费用、风险费用的大致范围
- **日期**：报价方案的签发日期

### Step 2：模板选择

根据用户需求和案件特点，推荐或确认使用的模板类型：

| 判断条件 | 推荐模板 |
|---------|---------|
| 客户已了解律所实力，案件简单 | 仅报价 |
| 标准商事诉讼 | 报价+服务内容 |
| 需要法规依据增强报价合理性 | 标准+费用 |
| 高端客户、复杂案件、首次合作 | 服务内容+团队+价格 |
| 再审/疑难案件，需展示专业团队 | 团队+费用 |

### Step 3：方案生成

根据收集的信息和选定的模板，按照 [references/quotation-templates.md](references/quotation-templates.md) 中的模板结构生成报价方案。

**生成规则：**
1. 报价表格必须包含：付费时间/条件、律师费金额
2. **所有金额字段必须经用户明确确认后才能填写具体数值；用户未提供或未确认的金额，一律使用"{待确认}"占位符，严禁自行编造或推算金额**
3. 风险代理费必须明确触发条件和金额/比例（金额/比例须经用户确认）
4. 计时收费必须标明包含时长、超时费率、有效期（费率须经用户确认）
5. 脚注用于解释专业术语和特殊条款
6. 所有金额以"万元"或"元"为单位，保持一致
7. 付费条件统一采用"某事件之日起5日内"的表述

### Step 4：结果输出

**默认且强制输出 DOCX (Word) 文档**。完成方案内容确认后，调用 [scripts/generate_quotation.py](scripts/generate_quotation.py) 脚本生成 .docx 文件。

#### 生成步骤

1. 根据方案内容，构造符合脚本要求的 JSON 数据
2. 将 JSON 数据写入临时文件（或直接传参）
3. 执行以下命令生成 DOCX：

```bash
python3 scripts/generate_quotation.py --json '<JSON数据或文件路径>' --output '法律服务报价方案.docx'
```

4. 向用户告知文件输出路径

## 异常处理

### 信息不完整
若用户提供的信息不足以生成报价方案：
- 向用户说明缺少哪些必要信息
- 提供默认值建议（如"客户名称可暂用XXXX代替"）
- 等待用户补充后再生成

### 收费金额未确定
若用户未提供具体报价金额：
- **必须向用户询问确认具体金额，不得自行填写**
- 可参考 [references/fee-standards-reference.md](references/fee-standards-reference.md) 中的行业参考标准向用户提供建议区间，但最终金额由用户决定
- 用户明确表示暂不确定的，在方案中使用"{待确认}"占位符
- 用户拒绝回答或跳过金额确认的，所有金额字段统一使用"{待确认}"占位符

### 特殊情况处理

| 特殊情况 | 处理方式 |
|---------|---------|
| 刑事案件 | 提示禁止风险代理，仅支持固定收费模式 |
| 法律援助案件 | 提示不适用商业报价 |
| 跨境案件 | 提示可能涉及不同法域的收费标准 |
| 群体性案件 | 建议协商定价，不按标的额累加 |
| 衍生诉讼 | 在方案中注明需另行签订补充合同 |

## 注意事项

> **重要提示**
> 1. 生成的报价方案仅供参考，实际报价需由律所最终确认
> 2. 风险代理收费须遵守各地司法行政部门的限制规定
> 3. 刑事案件、行政案件、国家赔偿案件禁止风险代理
> 4. 报价方案中的金额应基于实际案件复杂度和工作量合理确定
> 5. 律师团队信息应基于真实律师资料，不得虚构
> 6. 建议在报价方案中保留弹性条款，应对案件复杂程度变化

## 可选套件上下文（不影响独立使用）

1. 工作目录根存在 `套件运行规则.md` 时必须先读取并执行；不存在时以本技能硬规则为准，不影响独立使用。
2. 工作目录根存在 `办案画像.md` 时，只读取与当前任务有关的诉讼立场、风险偏好和文书风格；不存在时按本技能默认运行，不追问、不报错。
3. 仅当用户明确切换到某案或提供唯一案件路径时，读取 `cases/{案件简称}/案件画像.md`；不得猜测案件，不得跨案带入。
4. 画像只影响表达与偏好，不得覆盖事实、法律依据、必备结构、验证结果或本技能硬规则。
5. 已明确绑定唯一案件且案件管家可用时，成果完成后提交标准案件事件；无案件不建档、不回写，回写失败不得阻塞成果交付。
