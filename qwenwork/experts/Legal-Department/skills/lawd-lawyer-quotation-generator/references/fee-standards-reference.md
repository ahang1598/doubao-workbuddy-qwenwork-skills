# 律师服务收费标准法规参考

> 本文件汇总律师服务报价相关的法律法规和行业参考标准，供生成报价方案时引用。

---

## 一、国家层面法规

### 1. 《关于进一步规范律师服务收费的意见》

- **发文单位**：司法部、国家发展和改革委员会、国家市场监督管理总局
- **文号**：司发通〔2021〕87号
- **核心要点**：

#### 风险代理收费上限

律师事务所在风险代理各个环节收取的律师服务费合计最高金额：

| 标的额区间 | 最高比例 |
|-----------|---------|
| 不足100万元的部分 | 不超过标的额的18% |
| 100万元以上不足500万元的部分 | 不超过标的额的15% |
| 500万元以上不足1000万元的部分 | 不超过标的额的12% |
| 1000万元以上不足5000万元的部分 | 不超过标的额的9% |
| 5000万元以上的部分 | 不超过标的额的6% |

#### 禁止风险代理的案件类型
- 刑事案件
- 行政案件
- 国家赔偿案件
- 婚姻继承案件
- 群体性案件

---

### 2. 《律师服务收费管理办法》

- **发文单位**：国家发展和改革委员会、司法部
- **文号**：发改价格〔2006〕611号
- **核心要点**：

#### 收费方式
| 收费方式 | 说明 |
|---------|------|
| 计件收费 | 按案件数量和一定的标准确定 |
| 按标的额比例收费 | 按涉及财产标的额的一定比例收费 |
| 计时收费 | 按律师实际工作时间计算 |
| 风险代理收费 | 全部或部分根据案件结果收费 |

#### 计时收费参考
- 律师计时收费：一般500-5,000元/小时
- 高级合伙人/资深律师：3,000-5,000元/小时
- 合伙人/高级律师：2,000-3,000元/小时
- 执业律师：500-2,000元/小时

## 二、地方层面法规

### 1. 浙江省

**《浙江省物价局 浙江省司法厅关于完善律师和基层法律服务收费的通知》**
- **文号**：浙价服〔2015〕203号
- **核心要点**：律师服务收费实行政府指导价和市场调节价

#### 民事案件收费标准（按标的额比例）

| 标的额区间 | 收费比例 |
|-----------|---------|
| 10万元以下（含10万元） | 6% |
| 10万元至50万元（含50万元） | 5.5% |
| 50万元至100万元（含100万元） | 5% |
| 100万元至500万元（含500万元） | 4% |
| 500万元至1000万元（含1000万元） | 3% |
| 1000万元以上 | 2% |

**注**：每件案件不低于5,000元。

### 2. 北京市

**《北京市司法局、北京市律师协会关于全面放开我市律师法律服务收费的通知》**
- 自2018年4月1日起，律师法律服务收费全面实行**市场调节价**
- 不就收费标准进行统一限定

**《北京市律师诉讼代理服务收费政府指导价标准》**（供参考）
- **文号**：京发改规〔2016〕10号

#### 按标的额比例收费标准（每一阶段）

| 标的额区间 | 收费比例 |
|-----------|---------|
| 10万元以下（含10万元） | 10%（最低收费3,000元） |
| 10万元至100万元（含100万元） | 6% |
| 100万元至1000万元（含1000万元） | 4% |
| 1000万元以上 | 2% |

**注**：按当事人争议标的额差额累进计费。

### 3. 上海市

#### 民事案件收费标准（按标的额比例）

| 标的额区间 | 收费比例 |
|-----------|---------|

| 10万元至100万元（含100万元） | 5%-7% |

## 三、行业参考报价区间

### 1. 按案件类型参考报价

以下为行业常见报价区间，仅供参考，实际报价应根据案件复杂度、标的金额、律师资历等因素综合确定。

#### 诉讼案件

| 案件类型 | 标的金额区间 | 基础服务费参考（万元） | 风险代理费参考 |
|---------|------------|---------------------|-------------|
| 股东纠纷 | 100万以下 | 5-15 | 胜诉后10-30万 |
| 股东纠纷 | 100万-1000万 | 15-50 | 胜诉后50-150万 |
| 股东纠纷 | 1000万以上 | 50-100 | 胜诉后100-300万或按比例 |
| 合同纠纷 | 100万以下 | 3-10 | 收回金额的3%-8% |
| 合同纠纷 | 100万-1000万 | 10-30 | 收回金额的2%-5% |
| 合同纠纷 | 1000万以上 | 30-80 | 收回金额的1%-3% |
| 民事再审 | - | 10-30（申请阶段） | 改判后100-300万 |
| 仲裁案件 | 100万-5000万 | 10-30 | 减损金额的1%-3% |

#### 非诉讼法律服务

| 服务类型 | 基础固定费用（万元） | 包含时长 | 超时费率（元/小时） |
|---------|---------------------|---------|-----------------|
| 商业谈判 | 10-30 | 30-100小时 | 2,000-5,000 |
| 法律尽职调查 | 15-50 | 按项目 | 2,000-5,000 |
| 合同审核 | 2-10 | 按件 | 1,500-3,000 |
| 常年法律顾问 | 10-50/年 | 按月 | 1,500-3,000 |

### 2. 按诉讼阶段参考报价

| 诉讼阶段 | 占总费用比例参考 | 说明 |
|---------|---------------|------|
| 一审 | 50%-60% | 主要工作量集中在此阶段 |
| 二审 | 30%-40% | 在一审基础上的补充工作 |
| 再审 | 20%-30% | 特殊程序，难度较高 |
| 执行 | 10%-20% | 视执行难度确定 |

### 3. 风险代理费参考区间

| 案件结果 | 奖励费参考 | 适用模式 |
|---------|-----------|---------|
| 调解/和解达成 | 基础费的50%-100% | 基础+风险模式 |
| 判决胜诉 | 基础费的100%-200% | 基础+风险模式 |
| 减损金额 | 减损金额的1%-3% | 固定+比例模式 |
| 收回财产 | 收回金额的3%-8% | 纯风险模式 |
| 改判成功（再审） | 50-300万元（固定） | 阶段+成果模式 |

## 四、报价合规性检查清单

生成报价方案时，应确认以下合规性要点：

| 检查项 | 合规要求 |
|-------|---------|
| 风险代理比例 | 不得超过标的额30%（总上限） |
| 分段风险上限 | 符合司发通〔2021〕87号规定的分段比例上限 |
| 案件类型限制 | 刑事、行政、国家赔偿案件不得风险代理 |
| 费用透明 | 收费标准、计算方式必须在合同中明确 |
| 退费机制 | 合同解除时的退费规则应明确 |
| 差旅费 | 另行约定，实报实销 |
| 税费 | 报价应注明是否含税 |

## 五、报价计算参考公式

### 基础+风险模式

```
总费用 = 基础服务费 + 风险代理费
风险代理费 = 触发条件达成时 × 约定金额或比例
合规上限 = 按司发通〔2021〕87号分段计算的最高金额
最终风险代理费 = min(约定金额, 合规上限 - 基础服务费)
```

### 计时模式

```
总费用 = 基础固定费用 + 超时费用
超时费用 = max(0, 实际工作时长 - 包含时长) × 超时费率
```

### 北京市参考标准计算示例

以标的额7000万元为例（按京发改规〔2016〕10号标准）：
```
10万 × 10% = 1万元
90万 × 6% = 5.4万元
900万 × 4% = 36万元
6000万 × 2% = 120万元
每一阶段合计 = 1 + 5.4 + 36 + 120 = 162.4万元
```
