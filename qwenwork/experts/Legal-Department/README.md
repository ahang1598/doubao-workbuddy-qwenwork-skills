# 律师办案大管家

面向执业律师的民商事诉讼办案助手。**23 项能力**串起一条完整动线：接案 → 检索 → 分析 → 证据 → 文书 → 庭审 → 执行 → 结案。

它与"一堆零散技能"的区别在三处：**一个入口**（办案中枢识别你要干什么并编排流水线）、**一份画像**（5 分钟冷启动，此后不再重复问你是谁、文书要什么语调、台账放哪里）、**一道闸门**（任何正式文书出门前必过法条案例验真，脚本级校验，不通过就是不通过）。

> **免责声明**：本套件辅助律师工作，不替代执业判断。所有交付物均须承办律师复核后使用。诉讼期限计算仅供参考，最终以法院文书载明并由承办律师核实为准。

---

## 适用角色

- **执业律师**——民商事诉讼全流程办案，从接案报价到结案归档
- **公司法务**——对外诉讼案件管理、外部律师协同、诉讼风险评估
- **律师助理**——材料解析、证据整理、检索与文书初稿

---

## 技能清单（23 项）

> 「指令」是你在对话里喊的名字，「目录名」是技能在包内的标识——技能正文里互相引用时用的是目录名，对文档时以此列为准。
>
> 个别技能的引导会提到 `lawd-case-summary`、`lawd-lawyer-letter`、`lawd-zxgk-enforcement-query`、`lawd-counterparty-check`、`lawd-argument-chain-constructor`——它们属其他套件或独立技能，不在本清单 23 项内，需另行安装。
>
> **材料文字化也是外部前置能力，不计入 23 项**：遇到不可直接读取的 PDF、扫描件或图片时按需调用；不可用时请求可读文本，不能猜测材料内容。

## 典型办案流水线

中枢会自动编排，你也可以直接照着喊：

| 场景 | 技能序列 |
|---|---|
| 新案子进来 | 案件管家（建档）→ 咨询信息采集清单 → 材料文字化（外部前置能力，按需） |
| 准备起诉 | 起诉状分析与攻防策略 → 法规检索 / 类案检索 → 起诉状生成 → 证据清单生成 |
| 收到起诉状要答辩 | 材料文字化（外部前置能力，按需）→ 起诉状分析与攻防策略 → 综合证据策略 → 答辩状一键起草 |
| 出正式分析结论 | 案情法律分析报告 → 诉讼风险与清偿评估 |
| 开庭前 | 律师庭前准备 → 律师模拟裁判报告 → 质证意见生成 |
| 庭后 | 代理词生成（补充意见） |
| 判决后 | 上诉状生成 或 强制执行申请书 → 案件管家（结案） |
| 查对方底细 | 律师企业尽调报告 → 诉讼风险与清偿评估 |

编排规则：一次不超过 4 步；读取、整理、检索和运行检查可连续完成，诉讼请求、关键事实、金额、期限、外部写入与成果状态升级按风险确认。正式文书出门前自动过验真；明确绑定唯一案件时，中枢或业务 Skill 通过案件管家回写标准案件事件。

## 数据连接（可选增强）

| 你想做的事 | 没连数据源时 | 连上之后 |
|---|---|---|
| 查法条、查案例 | **停下来告诉你需要接入哪类数据源**，不会拿通用搜索凑法条 | 逐条核验、可溯源，引用敢写进法院文书 |
| 查对方工商与涉诉风险 | 能出结论，但标注 `[L4-主体信息待核验]` | 主体信息、股东、涉诉记录直接核验 |
| 案件台账团队协同 | 降级为本地文件，标注"本地模式" | 台账在线共享，团队同看一份 |

套件不连任何数据源也能跑，但权威引用类能力会拒绝降级——这是刻意设计：**宁可停下，也不给你一条编出来的法条**。详见 [CONNECTORS.md](CONNECTORS.md)。

## 交付物与格式

- 所有交付物落在工作区 `outputs/` 目录（界面唯一扫描目录）；编排型技能的子产物落 `outputs/sub/`；案件档案落 `cases/{案件简称}/`
- **先 Markdown 过验真闸门，放行后再询问是否转 Word**——不先出 md 就不转 Word
- 交法院的文书按正式文书排版规范（小三仿宋正文、28 磅行距、A4、上下 3.7cm 左右 2.8cm）
- 个人偏好集中在 `办案画像.md`；不可由画像覆盖的护栏、连接器、来源核验、Word 与成果状态规范集中在 [`套件运行规则.md`](套件运行规则.md)

### 成果状态

| 状态 | 含义 |
|---|---|
| 草稿 | 允许缺信息、占位符或未确认策略，仅供内部修改 |
| 待核验稿 | 结构基本完成，但事实、引用、金额或日期仍待核验 |
| 门禁通过稿 | 引用与适用机械检查已经通过，可以交律师最终审阅 |
| 律师确认稿 | 律师明确审阅并确认当前版本；系统不会自行升级到此状态 |

## 两处需要你知道的限制

1. **只有明确绑定唯一案件才回写台账**。通过中枢时由中枢触发；直接调用业务 Skill 时，在案件管家可用的情况下提交标准案件事件。临时起草、未建档事项或案件不明确时，不新建无效台账，也不跨案回写。
2. **诉讼期限属于辅助草算**。脚本负责日历计算；规则依据待验真时会显著标注，存在明确风险时停止计算，目标年份缺少节假日数据时拒绝给出顺延结论。最终期限仍以法院文书及律师核实为准。
