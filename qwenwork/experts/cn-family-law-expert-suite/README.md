# 婚姻家事法律专家

版本：1.2.1

本套件面向中国大陆婚姻家事律师、律所团队、企业法务及在律师指导下处理家事安排的用户。它按一流家事团队的工作方式，把“访谈与安全筛查—事实和证据—现行法与类案—方案比较—协议起草—履行设计—正式文档—质量门禁”连成可追溯流程。

## 包含的技能

- 婚姻家事法律总编排、家事事项访谈与材料清单、法律咨询与综合分析。
- 家事材料与银行流水证据账本、家庭财产与权属账本、家庭债务与责任账本、子女抚养与共同养育方案。
- 婚姻家事法规检索、婚姻家事类案检索。
- 婚前财产约定、婚内财产约定、离婚协议、同居协议、分家析产协议、成年意定监护协议；六项协议均附包内通用完整模板和可选条款模块。
- 家事交付物模板与正式文档生成、家事协议法律与文档质检。

## 使用原则

- 推荐先调用“婚姻家事法律总编排”；目标单一时可直接调用对应技能。用户只要空白或快速模板时，套件不启动完整访谈，直接交付预生成 DOCX；已提供部分信息时复用该信息并用占位符承载缺项。
- 提问前先读取提示词、对话和授权材料，已有信息不得再次询问。千问办公每个问题配置 2 至 4 个选项，平台自动追加“其他”；单次最多 4 个问题，可按需要设置多选，推荐项排第一。
- 严格区分已核验事实、当事人陈述、合理推断、争议事实和待核实事项；不把材料中的主张自动当作事实。
- 内嵌模板是无品牌通用底稿，不是填空后即可签署的定稿。技能应按家庭结构、财产、债务、子女、履行条件和当地办理口径增删条款，并保留修改理由和待确认项。
- 所有正式法律结论必须注明分析基准日并核验现行有效法律。任何协议终稿、律师函式结论或可对外法律成果，均须经中国大陆执业律师实质复核批准。

## 外部系统与降级

首版不分发 `.mcp.json`，也不声明强制连接器。用户可以依靠本次任务上传的材料、千问办公已有文档能力和可访问的官方公开来源使用套件。

- 无法访问官方来源时：输出检索式、已尝试来源、访问限制和待人工核验项，不编造法条、案号或办理口径。
- 扫描件或图片无法可靠识别时：标记需 OCR/视觉复核及具体页码，不臆造签名、印章或文字。
- 无法生成 DOCX/PDF 时：降级输出结构完整的 Markdown 正文和附件表，不声称已经通过版式检查。
- 外部系统未授权时：不绕过授权，不上传、外发、提交或覆盖任何数据。

## 安全与隐私

套件处理身份、住址、未成年人、医疗健康、金融账户和家庭冲突等高敏感信息。应坚持最小必要、项目隔离、账号掩码、原件只读和按交付目的披露。发现家暴、胁迫、跟踪、儿童危险、自伤他伤或其他紧急风险时，先进入安全响应，不继续推动共同签约。

## 重要限制

五类协议范本的条款级整合及大陆法审计见 [模板整合审计记录](references/agreement-template-integration-audit.md)。

本套件是专业法律工作辅助工具，不替代律师执业判断、身份核验、冲突检索、见证、公证、登记、税务、评估、心理或医疗服务。涉及诉讼、刑事风险、跨境资产、港澳台关系、农村集体权益、国资或上市公司股权、信托、复杂税务、行为能力争议或重大第三人权利时，应升级给相应专项专业人员。

## 速度设计

- 空白模板：直接返回对应技能的 `assets/quick-template.docx`，不重复生成或重复渲染。
- 按现有信息出草案：只加载一个对应模板，单次填充，默认只生成用户要求的格式；使用包内纯 OOXML 校验器检查结构和正文，不调用 LibreOffice。
- 审查级成果：才启用事实证据账本、争点法源核验、必要类案、正式文档和完整质量门禁。
- 千问办公中禁止调用 `libreoffice_bridge.py`、`soffice` 或 `pdftoppm` 进行 DOCX 验证，也不通过反复切换 `python/python3`、搜索应用目录或探测替代程序来补救。确需 PDF 或逐页视觉质检时，直接说明当前运行环境不提供该能力，先交付 DOCX 和结构校验结果。
