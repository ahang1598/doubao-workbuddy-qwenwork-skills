# 内容创作专家

面向自媒体运营、内容创作者、短视频/直播团队与市场品牌岗，把内容创作全链路（选题、拆解、沉淀、创作、成片、发布）打包成一套开箱即用的 AI 工作台。内置 10 个能力，覆盖抖音、小红书、微信公众号、微博、B站、视频号、Twitter、Instagram、今日头条、百家号等主流平台的适配规范；内置爆款钩子模板、平台字数与排版规则、12 大行业口播模板、668 个实战生图案例，以及个人风格学习与知识库沉淀的持续训练机制。

> **提醒：** 本套件辅助内容创作，最终发布前请人工复核合规性（版权、平台规则、事实核查、行业敏感词），涉及金融、医疗、法律等垂直领域的内容尤其需要专业审校。

## 适用角色

- **自媒体创作者 / 知识博主** — 从选题发现、爆款拆解到多平台一稿多发的全流程提效
- **短视频 / 直播运营** — 12 大行业口播模板 + 视频编导工作流，快速批量出脚本与分镜
- **市场 / 品牌 / PR** — 结合品牌调性生成图文与海报，跨平台统一发布
- **咨询顾问 / 研究员 / 律师 / 投资人** — 素材投喂到知识管家，长期沉淀成越用越聪明的个人知识库
- **企业新媒体小组** — 通过风格说明书统一团队笔调，通过发布助手集中管控多平台账号

## 推荐工作流

一个典型的"爆款生产线"可以这样串起来：

1. **选题** — 用「内容雷达」在目标垂类找 3–5 个高潜力选题
2. **拆稿** — 用「爆款拆解」把对标账号的高互动内容提取为逐字稿 / 正文 / 图片文字
3. **沉淀** — 用「知识管家」把拆稿与素材投喂到个人知识库，长期训练
4. **学风格** — 用「风格说明书」提炼自己或对标账号的表达习惯
5. **写正文** — 用「写作专家」按目标平台生成图文，或用「口播脚本生成器」/「视频编导」出视频稿
6. **出图/配图** — 用「内容生图」按平台规范生成配图、封面与轮播图
7. **排版** — 用「智能排版」把稿件适配到小红书 / 公众号 / 微博
8. **发布** — 用「跨平台发布」一键投递到目标平台（先草稿模式复核）

## Connectors（可选增强）

| 场景 | 无连接器 | 连上后 |
|------|---------|--------|
| 素材沉淀 / 会议纪要导入 | 手动粘贴文本 / 上传文件 | 从 **钉钉听记** 批量拉纪要进知识库 |
| 平台数据采集 / 内容拆解 | curl / yt-dlp / 浏览器兜底 | 通过 **mcp-autocli** 稳定获取 8 大平台字幕、正文、热榜 |
| 跨平台发布 | 生成稿件后人工登录发布 | 通过 **mcp-autocli publish** 一键投递 6 平台（含草稿模式） |
| 素材归档 / 团队协作 | 输出到本地文件 | 结果自动同步到 **文档平台**（钉钉文档 / 飞书文档 / Notion） |
| 待办跟进 | 打印任务清单 | 自动创建 **任务工具** 待办（钉钉待办 / Linear / Todoist） |

> 所有 Skill 在没有连接器的情况下均可独立运行，连接后体验升级。详见 [CONNECTORS.md](./CONNECTORS.md)。
