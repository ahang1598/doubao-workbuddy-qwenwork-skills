# 洞察页模板

> 本文件按需加载——创建洞察页前 Read。

## 模板

```markdown
---
title: 跨主题洞察标题
type: insight
kind: synthesis | comparison | qa-archive
created: YYYY-MM-DD
related_topics: ["[[A]]", "[[B]]"]
sources: ["[[摘要-X]]", "[[摘要-Y]]"]
---

## 核心发现
...

## 证据链
- [[摘要-X]]：...
- [[摘要-Y]]：...

## 开放问题（如有）
```

## kind 取值

| kind | 什么时候用 |
|---|---|
| synthesis | 跨多专题的综合分析 |
| comparison | 两个专题/观点的对比 |
| qa-archive | Query 回答归档 |
