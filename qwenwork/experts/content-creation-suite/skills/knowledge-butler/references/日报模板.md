# 日报模板（workflow 6 用）

> 本文件是**模板库**，AI 根据 `daily_digest.py` 的 JSON 输出里的 `scale` 字段选对应档填写。
> 模板里的 `{变量}` 占位符由 AI 从 JSON 数据映射填入。
> 输出文件：`3-AI工作记录/日报/YYYY-MM-DD.md`。

---

## 通用 Frontmatter（**所有档必填**）

```yaml
---
date: {YYYY-MM-DD}
type: daily_digest
scale: {init|空动|轻量|中等|深度}
variance_score: {0-∞ 浮点数}
new_materials_count: {N}
new_topics_count: {M}
touched_topics_count: {K}
generator: workflow_6_v1
---
```

**结构化字段**：`type: daily_digest` 便于按类型筛选；日期在 frontmatter 便于排序。

---

## 📅 Init 档（首次运行，仪式感）

**触发条件**：`is_first_run == true`（`3-AI工作记录/日报/` 目录不存在或空）
**不按 variance_score 判档**，所有首次运行都用此模板。

```markdown
---
date: {YYYY-MM-DD}
type: daily_digest
scale: init
variance_score: 0
new_materials_count: 0
new_topics_count: 0
touched_topics_count: 0
generator: workflow_6_init
---

# 📅 {YYYY-MM-DD} · 知识管家每日日报（首次）

欢迎使用知识管家每日日报。

从今天开始，我会每天早上 08:00 自动：
- 🎙️ 同步你昨日在钉钉的所有听记
- 🕸️ 编译进AI 知识库（生成摘要、识别专题、建立反向链接）
- 📊 生成一份"昨日发生了什么"的日报（就是你现在看到的这种）

**本次初始化**已整理 **{初始化整理条数}** 条历史素材到 `1-素材/录音/`，识别出 **{初始化专题数}** 个专题。
你的AI 知识库从今天起正式启用——每多一条素材，知识越密。

---
📬 下一份日报：明日 08:00
📂 日报目录：`3-AI工作记录/日报/`
🔧 修改定时任务：在悟空里说"修改定时任务的执行时间为每天 XX:XX"
```

**推悟空对话流**（简短版）：
```
🎉 知识管家每日日报已启动，明日 08:00 为你生成第一份日报
📦 本次初始化整理 {N} 条历史素材 · 识别 {M} 个专题
📂 查看本次结果：3-AI工作记录/日报/{YYYY-MM-DD}.md
```

## 🟢 空动档（variance_score == 0）

**触发条件**：昨日一天都没有新素材 / 新专题 / 触达旧专题
**特点**：不推悟空对话流（避免打扰）、只写 md 文件作为"考勤"记录

```markdown
---
date: {YYYY-MM-DD}
type: daily_digest
scale: 空动
variance_score: 0
new_materials_count: 0
new_topics_count: 0
touched_topics_count: 0
generator: workflow_6_v1
---

# 📅 {YYYY-MM-DD} · 知识管家每日日报

昨日无新素材，AI 知识库保持稳定。
```

**推悟空对话流**：无（空动档不推送）

## 字段说明

| 字段 | 来源 | 含义 |
|---|---|---|
| `{N}` / `{M}` / `{K}` | JSON `.stats.*_count` | 统计数字 |
| `{variance_score}` | JSON `.variance_score` | 变化量得分 |
| `{past_7d_avg_variance}` | JSON `.stats.past_7d_avg_variance` | 近 7 天均值（用于对比） |
| `{标题}` | JSON `.new_materials[*].title` | 素材标题 |
| `{分类}` | JSON `.new_materials[*].category` | 会议/AI听记/AI硬件/其他 |
| `{时长}` | `.new_materials[*].duration_seconds` 格式化为分/秒 | 可读时长 |
| `{专题名}` | `.new_topics[*].name` 或 `.touched_topics[*].name` | 专题名 |
| `{count}` | `.touched_topics[*].count` | 专题被触达次数 |

## 文案规则

1. **双链格式**：所有专题 / 素材摘要必须用 `[[专题名]]` 格式，不要用普通链接（便于跨文档跳转）
2. **中文排版**：中英文之间加空格（如 "整理 3 条素材"，不是 "整理3条"）
3. **时间用相对+绝对**：说"昨日"或"2026-04-23"而非"前天"
4. **深度档的洞察要真**：AI 必须从数据里读出有实据的模式，不要瞎编
5. **推送简短**：悟空对话流推送都是 3-4 行，不超过 100 字
