# 钉钉听记集成说明 · 运行时参考

> 本文件是 SKILL.md 工作流 5 的详细参考。
> **SKILL 执行听记归档时必读**。
> 面向运行时 AI，不暴露 API key / 鉴权细节。

---

## 架构概览

```
用户对话（悟空）
     ↓ 触发听记归档
SKILL.md 工作流 5（Phase 0a/0b/1/2/3-5/6）
     ↓ 调用
scripts/wukong_minutes_to_md.py
     ↓ 调用
dws CLI（~/.real/.bin/dws/bin/dws）
     ↓ 请求
钉钉 AI 听记 API
     ↓ 返回
JSON 数据 → markdown 文件 → 知识管家素材
```

**关键约定**：SKILL 不直接调 DWS CLI，只调 Python 脚本。脚本负责封装所有 DWS 交互 + 数据转换。

## 脚本的 3 个子命令

### list · 列出听记元信息

```bash
.venv/bin/python scripts/wukong_minutes_to_md.py list [options]

选项：
  --scope mine|all|shared    所有权（默认 mine）
  --days N                   最近 N 天
  --since ISO-8601           起始时间
  --until ISO-8601           结束时间
  --query 关键词             标题筛选
  --category 会议,AI听记...  分类筛选（逗号分隔）
  -f table|json              输出格式（默认 table）
```

**输出字段**（每条）：
- `uuid` / `title` / `start_str`（人读时间）/ `duration_min`
- `category`（会议/AI 硬件/AI 听记/其他）
- `biz_type`（数字）/ `biz_type_raw`（原始语义）
- `keywords`（关键词列表）
- `orgName`（list all/shared 才有）

**SKILL 使用场景**：Phase 0b 预检页扫描听记总量 + 分类分布。

### fetch · 抓单条听记转写

```bash
.venv/bin/python scripts/wukong_minutes_to_md.py fetch <uuid> [-o output.md]
```

**关键修复**（对测试版）：
- 测试脚本用 `list mine --max 50` 找 meta —— 超过 50 条会丢
- 完整版用 `get info --id <uuid>` 直接定位 —— 无条数限制

**输出**：完整 markdown 文件（frontmatter + 正文 + 时间戳）

### batch · 批量归档

```bash
.venv/bin/python scripts/wukong_minutes_to_md.py batch \
    --output-dir "$ORIGINAL_PWD/1-素材/录音/" \   # ORIGINAL_PWD = workspace 根（知识管家根）
    [其他过滤参数同 list] \
    [--skip-existing]        # 按 frontmatter.uuid 去重
    [--retry 3]              # 单条失败重试次数
    [--dry-run]              # 仅列出,不实际抓
```

**输出**（stdout 进度流）：
每条完成打印一行 JSON：
```json
{"uuid": "...", "title": "...", "status": "ok|failed", "path": "..."}
```

SKILL 读这个流实时汇报"N/M 已归档"。

**失败处理**：
- 单条 fetch 失败 → 自动重试 3 次（指数退避 1s / 2s / 4s）
- 仍失败 → 记录到 `<output-dir>/_failed.jsonl`
- 批处理不因单条失败中止 —— 继续抓剩下的

## UUID 编码与 bizType 分类

### UUID 解码规则

听记 UUID 是 hex 编码的字符串，解码后格式：
```
v2uid{task_id}_{creator_uid}_{biz_type}
```

**脚本的解码函数**（`decode_uuid`）自动处理，SKILL 不用自己解。

### biz_type 原始语义（来自钉钉内部）

| biz_type | 原始语义 | 本项目分类 |
|---|---|---|
| 0 | 视频会议录制 | **会议** |
| 1 | 闪记（线上） | 其他 |
| 2 | 录音上传 | **AI 硬件** |
| 3 | 直播录制 | 其他 |
| 4 | 直播回放 | 其他 |
| 5 | 手机录音（线下） | **AI 听记** |
| 6 | 闪会（线下） | 其他 |
| 7 | 钉钉文档（线下） | 其他 |
| 8 | 通话闪记 | 其他 |
| 9 | 智能摘要 | **会议** |

### 4 个分类的含义（给用户）

- **会议**（0 + 9）：视频会议录制 + AI 生成的会议纪要
- **AI 硬件**（2）：硬件设备（录音笔等）上传的录音
- **AI 听记**（5）：手机 App 主动录的（语音备忘、语音通话等）
- **其他**（1/3/4/6/7/8）：闪记/直播/钉钉文档/通话闪记等不常见类型

**默认勾选策略**：会议 + AI 硬件 + AI 听记（均为用户主动记录行为），"其他"默认不勾。

## DWS CLI 参数速查

### `dws minutes list {mine|all|shared}` 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--max <N>` | 每页条数 | 10 |
| `--next-token <token>` | 分页 token（首页留空） | — |
| `--start <ISO-8601>` | 起始时间 | — |
| `--end <ISO-8601>` | 结束时间 | — |
| `--query <keyword>` | 标题关键词 | — |

**分页返回**：`result.hasMore` 和 `result.nextToken` 控制翻页。

### `dws minutes get transcription --id <uuid>` 参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `--id <uuid>` | 听记 uuid（必填） | — |
| `--direction <0\|1>` | 0 正序 / 1 倒序 | 0 |
| `--next-token <token>` | 段落分页 token | — |

**分页返回**：`result.hasNext` 和 `result.nextToken`。

### `dws minutes get info --id <uuid>`

返回字段：`duration` / `endTime` / `startTime` / `taskUuid` / `title` / `url`

`url` 字段 = 钉钉听记的访问链接，写入 frontmatter 的 `source_url`。

### `dws minutes get batch --ids uuid1,uuid2`

**仅返回元信息**（不返回转写）—— 用于批量元信息查询，不适合批量抓原文。

## 常见错误码和处理

| 现象 | 原因 | SKILL 应该做什么 |
|---|---|---|
| DWS 命令非零退出 | CLI 未登录 / 网络问题 | 告知用户"无法连接钉钉听记，请检查登录状态/网络" |
| DWS 返回空 itemList | 时间范围内无听记 | 告知"未找到听记",问用户是否扩时间范围 |
| `get info` 返回 null | uuid 不存在或已删除 | 不编造,明确告知"未找到对应听记" |
| 单条 fetch 超时 | 听记内容过长 / 网络波动 | 脚本自动重试 3 次;仍失败进 `_failed.jsonl` |
| 用户无权限 | scope=all/shared 但无访问权 | 告知权限问题,建议用户先找分享者开权限 |

## 性能和规模

- **list** 单页 50 条，300 条用户约 6 页 + 6 次 DWS 调用，**< 10 秒**
- **fetch** 单条听记（含 `get info` + `get transcription` 分页）**~2-5 秒**
- **batch** 归档 100 条 ≈ 3-8 分钟

**超过 20 条的批处理**必须在 Phase 0b 预检页二次确认——给用户明确的时间预期。

## 与钉钉的关系

- DWS CLI 是悟空平台内部的钉钉 API 封装，由**悟空平台的听记团队**维护
- 钉钉听记 API 本身可能升级 —— DWS 团队会跟进，本脚本只用稳定参数（`list --scope --start --end`、`get transcription/info`）
- **未来迁移通道**：若听记团队做了独立 skill（比如 `dingtalk-minutes` skill），本脚本可改为调用该 skill 的 MCP 接口，**无需改 SKILL.md 工作流 5 的 Phase 结构**

## 隐私和敏感内容

- **所有听记** 都是用户主动触发的钉钉 AI 功能（不存在"偷录"）
- 默认勾选策略（会议+AI 硬件+AI 听记）都是用户主动行为
- **"其他"类别** 默认不勾选 —— 含闪记/直播/通话闪记等不常见类型，让用户明确选择
- 若用户不希望归档某条 → 直接从 `1-素材/录音/` 删 md 文件即可；脚本不记缓存，下次 `--skip-existing` 就不重复抓

## 故障排查 checklist

AI 遇到问题时按这个顺序排查：

1. **脚本能跑吗**：`.venv/bin/python scripts/wukong_minutes_to_md.py --help` 有输出吗？无 → 跑 `bash setup.sh` 初始化
2. **DWS 能跑吗**：`~/.real/.bin/dws/bin/dws --help` 有输出吗？无 → 告知用户 DWS 未安装
3. **能 list 吗**：`list --days 1 -f json` 有数据吗？无 → 检查钉钉登录状态
4. **能 fetch 单条吗**：用一个真实 uuid 跑 `fetch` 测试
5. **能 batch 吗**：先跑 `preflight --days 1` 拿到 `session_id`，再跑 `batch --session-id <id> --output-dir /tmp/test --dry-run` 列出条目

**每一步失败都明确告知用户具体原因，不笼统说"归档失败"**。
