# 工作流 6：每日日报

> 本文件按需加载——仅在日报场景才 Read。

**触发词**：见 SKILL.md frontmatter 描述。

**前置**：workflow 5 已完成（或本日无同步需求）。

## Phase 0：幂等 + 首次判定

- 目录不存在 → 冷启动欢迎日报
- 今日已有日报 → skip
- 否则 → 正常生成

## Phase 1：收集 delta

```bash
cd "$SKILL_DIR" && .venv/bin/python scripts/daily_digest.py collect \
    --date $(date -v-1d +%Y-%m-%d) \
    --kb-root "$KB_ROOT"
```

## Phase 2：按档生成日报

| 档位 | 条件 | 内容 |
|---|---|---|
| 空动 | 无新素材 | "昨日无新素材，AI 知识库保持稳定" |
| 轻量 | 1-3 条 | 简短列表 + 1-2 条观察 |
| 中等 | 4-10 条 | 2-3 条观察 + 新专题解析 |
| 深度 | >10 条 | 3-5 条跨素材洞察 + 行动线索 |

写入 `3-AI工作记录/日报/YYYY-MM-DD.md`。

## Phase 3：推悟空对话流

除非空动档，推送简短摘要：

```
📅 2026-04-23 日报已生成（中等档）
📥 新增 3 条素材 · 建立 1 个新专题 · 触达 2 个旧专题
🔗 详情：3-AI工作记录/日报/2026-04-23.md
```

## Phase 4：失败兜底

| 失败场景 | 处理 |
|---|---|
| DWS 登录过期 | 告知用户重新登录 |
| 脚本异常 | 退到轻量档兜底 |
| 编译超时 | 退到无洞察档 |

**永远不要默默失败**。
