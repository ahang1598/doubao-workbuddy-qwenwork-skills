# 工作流 0：初始化

> 本文件按需加载——仅在初始化/升级场景才 Read。

## 触发场景

- 用户首次调用本技能
- 用户说"初始化知识管家"、"重新初始化"、"升级知识管家"、"修复目录结构"
- 用户投喂/提问但目录不存在——先初始化再继续

## 步骤

1. **解析 `$KB_ROOT`**：按 SKILL.md「路径变量」段的规则——用户给了绝对路径就从路径推导，否则用 `~/Desktop/知识管家/`
2. **检查现状 + 选择分支**（6 状态机）：

```bash
if [ ! -d "$KB_ROOT" ]; then
    STATE="A_全新"
elif [ -d "$PWD/知识管家" ] && [ ! -L "$PWD/知识管家" ]; then
    STATE="E_老架构"
elif [ -d "$KB_ROOT/2-AI知识库/概念" ] || [ ! -f "$KB_ROOT/规则手册.md" ]; then
    STATE="F_旧schema升级"
elif [ -f "$KB_ROOT/0-使用说明.md" ] && [ -f "$KB_ROOT/3-AI工作记录/操作记录.md" ]; then
    STATE="D_已新版"
elif /bin/ls "$KB_ROOT"/**/README.md 2>/dev/null | head -1 | grep -q .; then
    STATE="B_README版"
else
    STATE="C_中期版"
fi
```

3. **按状态分支处理**（所有分支保留用户数据）：
   - **A 全新**：建目录 → `kb_pipeline.py init --mode full` → 汇报
   - **B/C 旧版**：重命名/补齐说明文件 → 汇报
   - **D 已新版**：检查缺失补齐 → 汇报
   - **E 老架构**：问用户是否迁移 workspace 残留数据
   - **F 旧 schema**：概念→专题迁移 + 补创规则手册

4. **汇报给用户**（0 技术词）：

```
✅ 知识管家已就绪

📖 你可以：
• 投喂第一份素材：把文字、链接发给我
• 同步钉钉听记：说"整理最近 3 天的会议"
• 开启每日日报：说"创建每日自动整理任务"
```

## 什么时候不触发

- 用户只是寒暄（"你是谁"）——不创建文件夹
- 用户明确说"先不要创建"——尊重
