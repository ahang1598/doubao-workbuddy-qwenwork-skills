## 场景

### 骨架抽取（来自"📄 提取内容原文"）

```
开头钩子（疑问 + 悬念）：X 很难？/ 先看原片
↓
身份背书（句式重复，营造权威）：作为帮助上万名学员...的老师
↓
3 步骤递进（每步前重复身份背书）：
  第一步 → 示范
  第二步 → 示范
  第三步 → 示范
↓
情感升华（从教技巧 → 使命感）：那些深夜...让我觉得...
```

**钩子组合识别**：疑问式（开头）+ 悬念（先看原片）+ 数字冲击（3 步）+ 身份背书重复（非 8 种之一，按素材实际特征命名为"身份钩"）+ 情感共鸣（升华段）

**句长节奏**：极短句 + 并列结构。几乎无长句。每行 5-12 字。

**口头禅 / 句式**：
- "X 很难？按照我这个顺序，X 一秒变 Y" 命名公式
- "作为帮助上万名学员通过 X 的老师" 身份重复句式
- "深夜打磨...每一次的付出..." 升华句式

## 关键启示（写给消费本示例的 AI）

1. **时长 ≻ 默认字数**：素材 01:09 → 305 字，**不要**强行写到默认 500-700 字
2. **超出 8 钩子分类要敢命名**：本案例中"身份钩"不属于 SKILL.md 列出的 8 种，按素材实际特征命名即可，不要硬塞到"共情代入"或"利益诱惑"里
3. **重复示范段不是结构 bug**：同一段身份句反复出现是参考素材的核心节奏特征，要原样保留这种"重复套娃"结构，不要去重
4. **情感升华段是核心爆款基因**：高赞高收藏样本几乎都有"从技巧 → 使命感"的升华句，主题再换，升华骨架也要保留
5. **互动 CTA 是 skill 默认补齐**：素材没有"评论区告诉我"时，按 Phase 4 默认骨架补一条，不算违反 reference_mode 总则（属于"素材未覆盖字段才用默认"）
