## 示例 2：图生图输出（用户提供参考图）

**用户输入**：[上传了一张赛博朋克风格的城市夜景图] 帮我生成一张类似的，但把城市换成上海

**输出**：

```
📌 用途：无特定排版用途（纯画面）
📌 类型：场景与叙事
📌 主题：赛博朋克上海夜景
📌 比例：参考原图比例
📌 参考来源：用户提供参考图 + db/场景与叙事/cases.md L1-12

🎨 提示词：

将画面中的城市替换为上海，保留赛博朋克风格。前景为黄浦江面，倒影着霓虹灯光；中景是陆家嘴天际线，东方明珠塔和上海中心大厦发出蓝紫色霓虹光芒，建筑表面有全息投影广告和飞行汽车轨迹；天空是深紫色到品红色的渐变，带有数字雨和无人机编队。保持原图的暗调高对比度光影、湿润路面反射效果、蓝紫+橙色的互补色配色方案。

📝 创作说明：
- 用户明确要求"换成上海"，prompt 只描述变化部分（城市替换 + 上海地标）
- 视觉风格、光影、配色均对标参考图，不重复描述
- db 案例仅借鉴了"场景与叙事"类型的 prompt 结构写法
```

然后立即调用：

```python
generate_image(
  prompt="<上述完整提示词>",
  model="gpt-image-2",
  image_urls=["<用户参考图路径或URL>"],
  size="1696*960"
)
```
