# 用途约束详情与平台尺寸参考

## 用途类型约束

当用途类型已确认时，按以下约束调整提示词：

### 营销海报

- 竖版/方图为主，大标题+副标题，视觉冲击力强，CTA 明显
- **必填信息**：活动文案（品类名称、折扣力度、促销标语等）
- 用户未提供活动文案时：根据行业/场景**自动推荐**一套文案，让用户确认或修改（不再强制从零填写）
- 若用户明确说"不要文字"，则跳过文案要求

### 封面图

- 横版为主，主体突出，留白给标题区域，适合缩略图辨识
- **必填信息**：
  - 封面标题（渲染到封面上的主标题文字）
  - 目标平台（小红书/B站/抖音/公众号/视频号）
- 提取不到必须用 `ask_human` 询问
- 平台默认比例——小红书 1:1、B站 16:9、抖音 9:16、公众号 2.35:1，未指定平台时默认横版

### 文章配图

- 横版为主，信息辅助型，风格与文章调性一致，不喧宾夺主
- **必填信息**：文章正文（完整文章内容，自动识别配图位置）
- 提取不到必须用 `ask_human` 询问

### 轮播图

- 方图/竖版，系列感统一，每张有独立信息点，适合左右滑动浏览
- **必填信息**：内容正文（完整教程/清单/测评内容，自动拆分为多页）
- 提取不到必须用 `ask_human` 询问

## 平台尺寸参考表

| 平台 | 尺寸比例 | 分辨率参考 | 适用类型 |
|------|---------|-----------|---------|
| 小红书 | 1:1 | 1080×1080 | 封面图、轮播图 |
| B站 | 16:9 | 1920×1080 | 封面图 |
| 抖音 | 9:16 | 1080×1920 | 封面图 |
| 公众号 | 2.35:1 | 900×383 | 封面图 |
| 公众号文中 | 16:9 或 3:2 | 1080×608 或 1080×720 | 文章配图 |
| 知乎文中 | 16:9 | 1080×608 | 文章配图 |
| 营销海报（竖版） | 9:16 或 3:4 | 1080×1920 或 1080×1440 | 营销海报 |
| 营销海报（方版） | 1:1 | 1080×1080 | 营销海报 |

### size 参数速查

未指定平台时，按用途/方向选择：

| 方向 | size 参数 |
|------|----------|
| 竖版（9:16 类） | `1104*1472` |
| 横版（16:9 类） | `1696*960` |
| 方图（1:1 类） | `1280*1280` |
