# 汇总拆解报告模板

本文件定义批量提取完成后生成的汇总拆解报告格式。

**保存路径**：`~/.content-breakdown/output/汇总拆解报告_{YYYYMMDD_HHMMSS}.md`

---

```markdown

## 二、爆款共性分析

基于所有成功提取的内容，横向对比分析以下维度：

### 2.1 选题规律
- **高频主题**：{提炼出现频率最高的主题方向}
- **切入角度**：{各内容分别从什么角度切入同一话题}
- **差异化亮点**：{数据最好的内容 vs 其他内容的差异点}

### 2.2 标题/封面套路
- **标题共性**：{提炼标题的共同模式，如数字、疑问句、对比等}
- **高点击标题特征**：{数据最好的 2-3 条标题为什么吸引人}

### 2.3 内容结构对比
- **开头钩子**：{各内容的开头类型对比}
- **正文结构**：{各内容的叙事结构类型}
- **结尾引导**：{各内容的收尾方式}

### 2.4 互动数据洞察
- **数据最佳**：{标注点赞/收藏最高的内容及可能原因}
- **平台差异**：{同一话题在不同平台的数据差异}
- **值得复用的亮点**：{哪些内容的哪些技巧值得直接模仿}
```

## 汇总报告的分析要求

- **内容概览**：必须包含所有成功提取内容的基本信息和一句话主题概括
- **爆款共性分析**：必须是基于实际提取内容的横向对比，不得泛泛而谈
- **创作建议**：必须具体可执行，结合实际分析内容给出建议
- **跳过的链接**：如没有跳过的链接，此部分省略
