# 输出格式规范

本文件定义所有平台提取成功后的统一输出格式。

> ⚠️ **两个动作都必须执行**：
> 1. 在对话中按三部分格式**完整输出**给用户
> 2. 将完整报告**保存为 Markdown 文件**到 output 目录

## 报告文件要求

- **文件路径**：`~/.content-breakdown/output/{平台}_{标题摘要}_{日期}.md`
  - 平台：`douyin` / `xhs` / `bilibili` / `wechat` / `xiaoyuzhou`
  - 标题摘要：取标题前10个字符（去除特殊字符）
  - 日期：`YYYYMMDD` 格式
  - 示例：`~/.content-breakdown/output/xhs_怎么样让男生喜_20260527.md`
- **文件内容**：与对话输出完全一致（三部分完整内容）
- **生成时机**：Agent 完成内容分析后，使用终端命令将报告写入文件
- **输出给用户时**：在对话末尾告知报告文件路径："📁 完整报告已保存：{文件路径}"

## 标准输出结构

> ⚠️ **必须严格按此三部分格式输出，不得自行组织输出结构，不得省略任何部分。**

---

### 第一部分：📋 内容元数据

展示提取到的基本信息（来源、作者、互动数据等），让用户快速了解内容概况：

| 字段 | 展示条件 |
|------|---------|
| 标题 | 始终展示 |
| 作者/UP主/讲师 | 有则展示 |
| 平台 | 始终展示 |
| 发布时间 | 有则展示 |
| 时长 | 视频/音频类始终展示 |
| 播放量/阅读量 | 有则展示 |
| 点赞数 | 有则展示 |
| 收藏数 | 有则展示 |
| 评论数 | 有则展示 |
| 提取方式 | 始终展示（如：API字幕 / 必剪ASR / Whisper / OCR） |

---

### 第二部分：📄 提取内容原文

直接将提取到的原始内容**完整输出**，不做删减：

- **图文内容**（小红书图文笔记、微信公众号）：
  - 正文文字
  - 每张图片的 OCR 文字，格式为"**图片1：**{OCR文字}"、"**图片2：**{OCR文字}"……
  - ⚠️ 图片 OCR 是**必须步骤**，不是可选步骤。如果 `image_texts` 为空或未执行 OCR，必须补充执行后再输出
- **视频/音频内容**（抖音、B站、小宇宙、小红书视频笔记）：完整转写文字（字幕或 ASR 转录）

> ⚠️ 如果内容超过 3000 字，原文部分可截断并注明：
> "（内容较长，已截取前 3000 字，完整内容见报告文件：{report_path}）"
> 但**分析部分必须基于完整内容**。

---

### 第三部分：📊 内容分析

对提取内容进行结构化分析：
- **核心主题**：一句话概括内容讲了什么
- **主要观点/要点**：3-5 条关键信息提炼
- **适用场景**（可选）：这个内容适合用在哪些场景

---

```
## 📋 内容元数据

| 项目 | 信息 |
|------|------|
| 标题 | {标题} |
| 作者 | {作者名} |
| 平台 | {平台名} |

| 收藏 | {收藏数} |
| 评论 | {评论数} |
| 提取方式 | {API字幕 / 必剪ASR / Whisper / 图片OCR} |

---

## 📄 提取内容原文

{正文 / 转录 / OCR 文字完整内容}

---

## 📊 内容分析

**核心主题**：{一句话概括}

**主要观点**：

2. {要点2}

**适用场景**：{这个内容适合用在哪些场景}
```

## 各平台元数据来源

> ⚠️ **互动数据（点赞/收藏/评论/转发）只要 API 返回了就必须展示**，不得因为"侧重转录"而省略。

| 平台 | 元数据来源 | 互动数据字段 |
|------|-----------|-------------|
| 抖音 | browser_use 从详情 API 获取 | `statistics.digg_count`(点赞)、`statistics.comment_count`(评论)、`statistics.share_count`(转发)、`statistics.collect_count`(收藏) — **必有** |
| 小红书 | `__INITIAL_STATE__` 中的 interactInfo | `liked_count`(点赞)、`collected_count`(收藏)、`comment_count`(评论) — **必有** |
| B 站 | 公开 API `/x/web-interface/view` 的 `stat` 字段 | `view`(播放)、`like`(点赞)、`coin`(投币)、`favorite`(收藏)、`reply`(评论) — **必有** |
| 微信公众号 | 页面 HTML 中的 meta 标签和正文头部信息 | 通常无公开互动数据 |
| 小宇宙 | 页面 HTML 或 API 返回的 episode 信息 | 有则展示 |
| 百家号 | 页面 HTML 中的文章信息和 meta 标签 | 通常无公开互动数据 |
| 微博 | 移动端 API `$render_data` JSON | `attitudes_count`(点赞)、`comments_count`(评论)、`reposts_count`(转发) — **有则展示** |
| 今日头条 | 页面 SSR 数据或 HTML | 通常无公开互动数据 |

## 各平台原文说明

| 平台 | 原文内容构成 |
|------|------------|
| 抖音 | 字幕文本 或 ASR 转录文本 |
| 小红书（图文） | 笔记正文 + 各图片 OCR 文字（标注"图片1："、"图片2："） |
| 小红书（视频） | 笔记正文 + ASR 转录文本 |
| B 站 | 字幕文本 或 ASR 转录文本 |
| 微信公众号 | 文章正文 + 各图片 OCR 文字 |
| 小宇宙 | ASR 转录文本（或节目简介，若跳过转录） |
| 百家号 | 文章正文 + 各图片 OCR 文字 |
| 微博 | 微博正文 + 各图片 OCR 文字（长文自动展开） |
| 今日头条 | 文章正文 + 各图片 OCR 文字 |
