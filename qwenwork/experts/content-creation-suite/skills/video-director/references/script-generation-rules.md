# 视频脚本生成规则

> 本文件供 Step 3（生成脚本）执行时参考。

---

## 零、输出格式选择

生成脚本时，根据用户需求选择输出格式：

| 格式 | 适用场景 | 说明 |
| :--- | :--- | :--- |
| **口播脚本格式**（默认） | 真人口播、直播引流、种草带货 | 轻量，直接给演员/主播用 |
| 分镜脚本格式 | 多场景叙事、剧情短片、品牌 TVC、产品推广 | 完整分镜表，给拍摄团队用 |

**默认使用口播脚本格式**。仅在以下情况使用分镜格式：
- 用户明确要求分镜脚本（"要分镜表"、"出分镜"、"给拍摄团队用"）
- 用户说"要完整分镜"或"多场景拍摄"

---

## 零.1 口播脚本格式（默认）

每条脚本按以下结构输出：

```
{产品名}-{序号}-[{项目编号}]

场景：{拍摄场景}
人物：{出镜人物身份}
视频形式：{横版/竖版}
服装：{服装要求}
全程警示语：{合规/风险提示文本，如有}
测试点：{本条脚本的核心卖点方向}
{开场钩子类型}：{钩子文案}

{完整口播文稿}
```

**字段说明：**

| 字段 | 必填 | 说明 |
| :--- | :---: | :--- |
| 标题行 | ✓ | 格式：`产品名-序号-[编号]` |
| 场景 | ✓ | 简要描述拍摄环境 |
| 人物 | ✓ | 出镜人物身份定位 |
| 视频形式 | ✓ | 横版 / 竖版 |
| 服装 | ○ | 有特定要求时填写 |
| 全程警示语 | ○ | 金融/医疗/食品等合规行业必填 |
| 测试点 | ✓ | 本条脚本切入的核心卖点 |
| 开场钩子 | ✓ | 类型标注 + 钩子文案（如"读评论：xxx"、"上标题：xxx"） |
| 口播文稿 | ✓ | 完整连续文本，口语化，含产品信息和 CTA |

**开场钩子类型**（标注在钩子文案前）：

- `读评论`：模拟回复评论区问题
- `上标题` / `上方标题`：画面叠加文字标题
- 直接开场：无标注，文稿第一句即为钩子

**口播文稿要求：**

- 口语化，像对面聊天而非念稿
- 节奏：开头 3 秒抓注意力 → 痛点/场景共鸣 → 产品卖点 → 信任背书 → CTA
- 合规内容用括号标注（如免责声明），不打断阅读节奏
- 单条文稿长度：15-60 秒口播对应 200-600 字

**批量输出规则：**

当一次生成多条脚本时（如用户确认了多个创意方案）：
- 共享字段（场景、人物、视频形式、服装、警示语）相同时，首条完整写出，后续标注"同上"
- 每条脚本的测试点和开场钩子必须不同
- 脚本之间用空行分隔

## 一、脚本输入

从《创意方案报告》中提取以下信息：

| 输入项 | 来源 | 说明 |
| :--- | :--- | :--- |
| 确认的创意方案 | 报告「三、创意方案详情」 | 每条方案作为独立脚本的蓝本 |
| 创意主题 | 方案字段「创意主题」 | 脚本的核心概念锚点 |
| 叙事大纲 | 方案字段「叙事大纲」 | 脚本的故事骨架 |
| 开场钩子 | 方案字段「开场钩子」 | 脚本第一镜的画面与台词 |
| 情绪曲线 | 方案字段「情绪曲线」 | 脚本的情绪节奏参考 |
| 核心卖点 | 方案字段「核心卖点」 | 脚本中必须呈现的产品卖点 |
| 平台适配 | 方案字段「平台适配」 | 脚本的时长、节奏、画幅要求 |
| 风险标注 | 方案字段「风险标注」 | 脚本中需规避的表述方式 |

**多条方案处理：** 若用户选择了多条方案，为每条方案独立生成脚本，编号与方案编号一一对应（方案 A → 脚本 A）。

**独立进入时：** 若用户直接提供创意方案描述，将输入映射为上述结构，缺失字段主动追问。

## 三、全局设定

在分镜表之前，定义整条视频的全局参数：

| 字段 | 说明 | 示例 |
| :--- | :--- | :--- |
| **脚本编号** | 与创意方案编号对应 | 脚本 A |
| **视频标题** | 内部管理用标题 | 悟空AI-痛点解决型-开场Hook版 |
| **视频形式** | 横版(16:9) / 竖版(9:16) / 方形(1:1) | 竖版 (9:16) |
| **总时长** | 目标总时长（秒） | 45 秒 |
| **拍摄场景** | 主要拍摄地点及场景描述 | 现代简约办公室，自然光 + 环形灯补光 |
| **人物设定** | 出镜人物的身份、年龄、气质 | 28 岁男性知识博主，休闲商务着装 |
| **服装要求** | 服装风格、颜色、配饰 | 深蓝色休闲西装 + 白色 T 恤内搭 |
| **道具清单** | 所需道具及用途 | 手机、笔记本电脑、咖啡杯 |
| **核心卖点** | 本脚本重点呈现的卖点 | 全自动化工作流 / 多平台一键分发 |
| **品牌调性** | 整体视觉与叙事风格 | 专业、科技感、极简 |
| **背景音乐** | BGM 风格及情绪走向 | 轻电子节奏感，前 3 秒渐强，结尾上扬 |
| **参考来源** | 借鉴的历史脚本/分镜图 | scripts/科技类/悟空-开场Hook-v2.md |

## 四、分镜脚本表

### 必填字段（所有脚本必须包含）

| 字段 | 说明 |
| :--- | :--- |
| **镜头号** | 顺序编号，从 1 开始 |
| **景别** | 特写 / 近景 / 中景 / 全景 / 远景 |
| **时长(s)** | 该镜头持续秒数，所有镜头时长之和 = 总时长 |
| **画面描述** | 视觉元素、构图、运镜方式（推/拉/摇/移/跟） |
| **口播文案** | 台词，需口语化、有节奏感 |

### 可选字段（根据场景需要添加）

| 字段 | 说明 | 何时需要 |
| :--- | :--- | :--- |
| **场景** | 该镜头所处的具体位置 | 多场景切换时 |
| **人物动作/表情** | 出镜人物的动作和表情要求 | 有真人出镜时 |
| **字幕/花字** | 画面叠加的文字内容及样式 | 需要强化信息传达时 |
| **音效/BGM** | 音效细节或 BGM 变化节点 | 有明确音效设计时 |
| **道具** | 该镜头使用的道具 | 有道具交互时 |
| **备注** | 特殊说明（如"钩子镜头"、"CTA 镜头"） | 需要标注特殊功能时 |

### 字段选择规则

- **快速模式：** 仅使用必填字段
- **标准模式：** 必填字段 + 根据视频类型自动补充相关可选字段
- 用户可随时要求增减字段

| :---: | :--- | :---: | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |

## 五、关键帧设计

- **必选关键帧：** 开场钩子镜头（镜头 1）、产品特写镜头、结尾 CTA 镜头
- **可选关键帧：** 情绪转折点镜头、场景切换镜头
- **生成方式：** 输出文字描述（构图、光影、色彩），或从 AssetVault 分镜参考图库中检索历史素材
- **设计规范：** 每张关键帧需标注构图建议、光影风格、色彩基调

---

## 六、拍摄注意事项

在脚本末尾附加拍摄执行建议：

- **光线要求：** 主光源方向、色温范围、是否需补光
- **收音要求：** 麦克风类型建议、环境噪音控制
- **表演指导：** 语速（字/秒）、情绪层次、关键停顿点
- **AI 生成提示：** 若使用 AI 视频工具生成，需补充的 negative prompt 和风格参数

详细的景别建议、节奏参考、口播规范见 `references/methodologies.md`。
