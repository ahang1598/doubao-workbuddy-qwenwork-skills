# 产品资料解析规则

> 本文件供 Step 1（分析产品资料，拆解卖点）执行时参考。

---

## 一、结构化字段提取

从用户提供的原始产品资料中提取以下字段。若某字段缺失，主动向用户提问补全：

| 字段 | 说明 | 示例 |
| :--- | :--- | :--- |
| 产品名称 | 产品的正式名称或代号 | 悟空 AI Agent |
| 产品品类 | 所属行业/赛道 | AI 办公工具 / 短视频 SaaS |
| 目标人群 | 核心受众画像（年龄、职业、痛点） | 25-35 岁职场白领、内容创作者 |
| 宣传平台 | 计划发布的平台 | 抖音 / 小红书 / B站 / 视频号 |
| 品牌调性 | 甲方期望的视觉与叙事风格 | 专业、科技感、极简 |
| 核心诉求 | 本次宣传的主要目标 | 提升品牌知名度 / 引导下载转化 |
| 禁忌事项 | 不可提及的内容或竞品 | 不得提竞品名称、不得使用夸张用语 |

## 三、卖点拆解

结合提取的结构化字段和检索到的沉淀数据，产出 **至少 6 个**产品卖点。每个卖点需包含：

| 字段 | 说明 |
| :--- | :--- |
| **卖点名称** | 一句话概括卖点（≤15 字） |
| **卖点类型** | 功能卖点 / 情感卖点 / 社交卖点 / 价格卖点 |
| **支撑论据** | 为什么这个卖点成立？（数据、场景、用户证言） |
| **目标人群匹配度** | 该卖点对 TA 的吸引力评级（高/中/低） |
| **平台适配建议** | 该卖点最适合在哪个平台重点呈现 |
| **参考来源** | 该卖点借鉴了哪些沉淀数据或竞品案例 |

### 拆解方法论

- **FAB 法则：** 特征 (Feature) → 优势 (Advantage) → 利益 (Benefit)
- **SCQA 模型：** 情境 (Situation) → 冲突 (Complication) → 问题 (Question) → 答案 (Answer)
- **竞品对标：** 从爆款案例库中提取同类产品的卖点切入角度，避免重复并寻找差异化空间

详细方法论示例见 `references/methodologies.md`。
