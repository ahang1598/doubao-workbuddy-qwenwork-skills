# 内置方法论模板

> 当 AssetVault 不可用且外部搜索无结果时，使用以下通用方法论作为兜底支撑。

---

## 一、卖点拆解方法论（节点 1）

### FAB 法则

| 步骤 | 说明 | 示例 |
| :--- | :--- | :--- |
| Feature（特征） | 产品有什么 | 内置 AI 自动生成引擎 |
| Advantage（优势） | 比别人好在哪 | 无需手动编辑，一键出片 |
| Benefit（利益） | 用户得到什么 | 每周省 10 小时剪辑时间 |

### SCQA 模型

| 步骤 | 说明 |
| :--- | :--- |
| Situation（情境） | 用户当前的状态或背景 |
| Complication（冲突） | 打破现状的痛点或矛盾 |
| Question（问题） | 用户心中的核心疑问 |
| Answer（答案） | 产品如何解决这个问题 |

### 卖点类型分类

| 类型 | 适用场景 | 典型话术方向 |
| :--- | :--- | :--- |
| 功能卖点 | 产品有明确可量化的优势 | "比 XX 快 3 倍" |
| 情感卖点 | 产品触达用户深层需求 | "终于不用加班了" |
| 社交卖点 | 产品带来社交货币 | "发出去朋友都问链接" |
| 价格卖点 | 性价比突出 | "不到一杯咖啡的价格" |

## 二、创意研判方法论（节点 2）

### 开场钩子类型库

| 钩子类型 | 适用场景 | 示例 |
| :--- | :--- | :--- |
| 悬念型 | 制造好奇心，提升完播率 | "99% 的人不知道这个功能" |
| 痛点直击型 | 精准打击目标人群 | "还在熬夜做 PPT？" |
| 反转型 | 设置认知反差 | "我以为 AI 剪辑是噱头，直到……" |
| 数据冲击型 | 用数字建立可信度 | "3 分钟生成 50 条脚本" |
| 身份认同型 | 引发群体共鸣 | "打工人必看" |

### 叙事类型与适用场景

| 叙事类型 | 核心逻辑 | 最佳平台 |
| :--- | :--- | :--- |
| 痛点解决型 | 焦虑 → 方案 → 效果 | 抖音、视频号 |
| 情感共鸣型 | 故事 → 共鸣 → 品牌 | 小红书、B站 |
| 硬核测评型 | 数据 → 对比 → 结论 | B站、知乎 |
| 剧情反转型 | 铺垫 → 反转 → 产品 | 抖音、快手 |
| 社会议题型 | 热点 → 观点 → 品牌态度 | 微博、视频号 |

### 情绪曲线模板

| 阶段 | 情绪 | 对应镜头功能 |
| :--- | :--- | :--- |
| 开场（0-3s） | 好奇/震惊 | 钩子镜头 |
| 铺垫（3-10s） | 共鸣/焦虑 | 痛点场景 |
| 转折（10-20s） | 希望/惊喜 | 产品登场 |
| 展示（20-35s） | 信任/向往 | 功能演示/效果呈现 |
| 收尾（35-45s） | 行动/紧迫 | CTA 镜头 |

## 三、脚本生成方法论（节点 3）

### 景别使用建议

| 景别 | 适用场景 | 情绪效果 |
| :--- | :--- | :--- |
| 特写 | 产品细节、表情、关键动作 | 聚焦、紧张、强调 |
| 近景 | 人物口播、表情传递 | 亲近、信任 |
| 中景 | 人物动作、互动场景 | 自然、叙事 |
| 全景 | 环境交代、场景切换 | 开阔、过渡 |
| 远景 | 开场/结尾氛围 | 宏大、留白 |

### 短视频节奏参考

| 视频时长 | 建议镜头数 | 平均镜头时长 | 适用平台 |
| :--- | :--- | :--- | :--- |
| 15s | 5-7 | 2-3s | 抖音信息流 |
| 30s | 8-12 | 2.5-3.5s | 抖音/快手 |
| 45s | 10-15 | 3-4s | 小红书/视频号 |
| 60s | 12-18 | 3-5s | B站/视频号 |

### 口播文案节奏

| 指标 | 建议值 | 说明 |
| :--- | :--- | :--- |
| 语速 | 4-5 字/秒 | 口语化，不能像念稿 |
| 单句长度 | ≤20 字 | 短句为主，便于字幕呈现 |
| 停顿点 | 每 2-3 句 | 给用户消化信息的空间 |
| 关键词重复 | 核心卖点至少出现 2 次 | 强化记忆 |
