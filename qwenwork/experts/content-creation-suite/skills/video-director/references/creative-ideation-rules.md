# 创意方案生成规则

> 本文件供 Step 2（创意研判 + 生成创意方案）执行时参考。

---

## 一、创意输入

从《产品卖点解析报告》中提取以下信息作为创意方案的输入：

| 输入项 | 来源 | 说明 |
| :--- | :--- | :--- |
| 确认的核心卖点 | 报告「三、核心卖点拆解」 | 用户选中的卖点，作为每条创意必须覆盖的主题 |
| 备选卖点 | 报告「四、备选卖点」 | 可在创意中作为辅助卖点穿插 |
| 产品基础信息 | 报告「一、基础信息」 | 产品名、品类、目标人群、宣传平台、品牌调性 |
| 平台分发建议 | 报告「五、平台分发建议」 | 各卖点在不同平台的优先级 |
| 风险提示 | 报告「六、风险提示」 | 避免触及甲方雷区 |

**独立进入时：** 若用户直接提供产品卖点而非从上一步衔接，将用户输入映射为上述结构，缺失字段主动追问。

## 二、三渠道研判

### 2.1 沉淀数据读取

Step 2 开始前读取以下文件（不存在则跳过）：

| 文件路径 | 用途 |
| :--- | :--- |
| `patterns/methodologies/video_analysis.md` | 视频分析方法论 |
| `industry/{行业}/what_works.md` | 该行业有效的内容模式 |
| `industry/{行业}/audience.md` | 该行业受众特征 |
| `benchmarks/by-platform/{平台}.md` | 平台表现基准 |
| `_index/by_industry.json` | 同行业历史项目索引（可选，读取历史脚本参考） |

所有路径相对于 `asset-vault/` 根目录。

### 2.2 竞品调研（可选）

若用户提供了竞品链接或关键词：

- **竞品拆解：** 若 Agent 提供 `content-breakdown` 技能，调用其深度拆解竞品视频的钩子设计、叙事结构、评论区高互动点。否则由用户手动提供竞品分析。
- **素材搜索：** 若 Agent 提供 `smart-web-search` 技能，调用其检索同类题材的最新爆款趋势。否则跳过。
- **差异化分析：** 对比竞品与自身产品的卖点差异，标注「竞品已覆盖」和「可差异化的空白地带」。

### 2.3 爆款拆解（可选）

若用户提供了爆款视频链接，或 AssetVault 中有匹配的爆款案例：

- 提取爆款的「开场钩子类型」（悬念型/反转型/痛点直击型/数据冲击型）
- 提取爆款的「情绪曲线」（共鸣→焦虑→希望→行动）
- 提取爆款的「转化链路」（种草→信任→下单→复购）

### 2.4 研判摘要

综合以上渠道，生成《创意研判摘要》：

```
- 可复用的创意模式：（3-5 个有效模式）
- 应规避的方向：（甲方曾驳回 + 竞品已饱和）
- 差异化机会：（竞品未覆盖的卖点角度 + 空白叙事空间）
```

## 三、创意方案字段

生成 **至少 3 条**创意方案。每条方案需包含：

| 字段 | 说明 |
| :--- | :--- |
| **方案编号** | 方案 A / B / C ... |
| **创意主题** | 一句话概括核心概念（≤20 字） |
| **叙事类型** | 痛点解决型 / 情感共鸣型 / 硬核测评型 / 剧情反转型 / 社会议题型 |
| **核心卖点** | 本方案重点呈现的卖点（1-3 个） |
| **目标人群** | 本方案主要打动的人群细分 |
| **开场钩子** | 黄金前三秒的具体设计（含画面 + 台词） |
| **叙事大纲** | 起承转合的故事结构（200-300 字） |
| **情绪曲线** | 关键节点的情绪变化（如：好奇→共鸣→震撼→行动） |
| **平台适配** | 适合的平台及时长/节奏建议 |
| **预期效果** | 定性评估（如"高完播潜力"），可对标同类案例数据，不给出具体百分比 |
| **研判依据** | 本方案借鉴了哪些沉淀数据/竞品/爆款的模式 |
| **风险标注** | 本方案可能被甲方驳回的点（若有） |

---

## 四、叙事类型强制分布

生成的方案必须覆盖以下类型中的 **至少 3 种**：

| 类型 | 核心逻辑 | 适用场景 |
| :--- | :--- | :--- |
| 痛点解决型 | 先制造焦虑，再给出解决方案 | 功能型产品 |
| 情感共鸣型 | 通过故事建立情感连接 | 品牌向宣传 |
| 硬核测评型 | 用数据和实测说服用户 | 参数敏感型受众 |
| 剧情反转型 | 设置意料之外的转折 | 短视频完播率优化 |
| 社会议题型 | 绑定社会热点或价值观 | 品牌出圈 |

详细的钩子类型库、情绪曲线模板见 `references/methodologies.md`。
