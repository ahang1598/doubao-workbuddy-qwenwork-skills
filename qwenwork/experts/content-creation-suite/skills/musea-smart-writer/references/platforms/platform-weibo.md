# 微博风格规范

本文档定义微博平台的内容排版规则，供 Agent 生成微博内容时读取。

## 平台概览

| 属性         | 规则                                         |
| ------------ | -------------------------------------------- |
| 平台定位     | 短平快/热点借势/话题互动/观点输出            |
| 正文字数     | **≤ 2000 字**（建议 ≤ 300 字，短博更易传播） |
| 话题标签     | 1-3 个，格式 `#话题名#`（双井号包裹）        |
| 段落长度     | 每段 1-3 行                                  |
| 内容形式     | 短文案 + 配图/视频                           |
| 核心算法偏好 | 互动率（转发 > 评论 > 点赞）                 |

## 一、文案策略

### 1.1 首句即观点

微博用户刷信息流速度极快，**第一句话决定是否停留**。

规则：
1. 第一句必须是强观点、数据冲击或争议性表述
2. 禁止平淡开头（"今天想分享一下..."、"最近在思考..."）
3. 字数控制：首句 ≤ 30 字

**好首句示例**：
- `月薪 3 万和月薪 3 千的人，差的不是能力，是信息差。`
- `说一个反常识的事实：越努力的人，往往越穷。`
- `AI 不会取代你，但会用 AI 的人会。`
- `刚刚发现一个让我后悔没早知道的方法👇`

### 1.2 正文结构

微博正文建议 **≤ 300 字**，采用以下结构：

**短博文结构**（≤ 300 字，推荐）：
```
[强观点/数据冲击首句]

[2-3 句展开论述或个人经历]

[1-2 条核心干货/方法]

[互动引导 + 话题标签]
```

**长博文结构**（300-2000 字，需"展开全文"）：
```
[强观点首句]

[背景/问题描述，2-3 句]

[核心观点展开，分 2-3 个要点]
1️⃣ [要点一]
2️⃣ [要点二]
3️⃣ [要点三]

[总结 + 互动引导]

#话题一# #话题二#
```

### 1.3 排版细节

1. **极短句**：每句 ≤ 15 字为最佳，15-25 字可接受
2. **大量换行**：每 1-2 句就换行，制造呼吸感
3. **emoji 适度**：每 3-5 行 1 个 emoji，点缀而非堆砌
4. **数字序号**：多要点用 1️⃣ 2️⃣ 3️⃣ 或 ①②③ 标记
5. **口语化但有力度**：简短有力，不啰嗦
6. **善用省略号**：制造悬念感（"结果……"、"没想到……"）

### 1.4 emoji 使用

- 微博 emoji 使用介于小红书和公众号之间
- 适度使用，每条博文 2-5 个
- 常用：👇（引导阅读）、🔥（热门）、💡（观点）、⚡（冲击）、👀（吸引注意）
- 禁止堆砌，禁止用 emoji 替代标点

## 二、话题标签

### 2.1 格式规范

微博话题标签使用 **双井号包裹**：`#话题名#`（注意：与小红书的 `#标签名` 不同）

### 2.2 标签策略

建议 1-3 个话题标签，分两层：

1. **热门话题**（1-2 个）：蹭平台热门话题的流量
   - 查看微博热搜，选择与内容相关的热门话题
   - 示例：`#AI时代# ` `#职场干货#`

2. **精准话题**（1 个）：垂直领域的精准话题
   - 示例：`#知识管理#` `#效率工具#`

**格式要求**：话题标签放在正文末尾，每个标签用空格分隔

**正确示例**：
```
#AI时代# #职场效率# #知识管理#
```

**错误示例**：
```
#AI时代 #职场效率 #知识管理    ← ❌ 缺少结尾的 #
```

### 2.3 @提及

微博特有的社交互动方式，适当 @相关账号可增加曝光：
- @行业 KOL 或相关账号（需确保内容相关，不要硬蹭）
- @品牌官方账号（推广类内容）
- 放在正文中或结尾均可

## 三、互动引导

微博的互动核心是 **转发**（权重最高），其次是评论和点赞。

互动引导策略：

**争议型**（引发讨论）：
```
你觉得呢？评论区说说你的看法👇
```

**投票型**（降低参与门槛）：
```
同意的转发，不同意的评论区反驳！
```

**求助型**（激发分享欲）：
```
还有什么好方法？求评论区大佬补充🙏
```

**利他型**（促进转发）：
```
觉得有用就转发给需要的朋友吧～
```

## 四、排版风格对比（vs 其他平台）

| 维度     | 微博               | 小红书                 | 公众号         |
| -------- | ------------------ | ---------------------- | -------------- |
| 字数     | ≤ 300 字（建议）   | ≤ 1000 字              | 1500-2500 字   |
| 段落     | 1-3 行/段          | ≤ 3 行/段              | 3-5 行/段      |
| 语气     | 犀利、直接、有态度 | 口语化、亲近           | 理性、专业     |
| 话题标签 | `#话题#`（双井号） | `#标签`（单井号）      | 无             |
| 互动重点 | 转发 > 评论        | 收藏 > 评论            | 转发 > 留言    |
| emoji    | 适度（2-5 个）     | 高频（每 2-3 行 1 个） | 克制（3-5 个） |
| 核心特点 | 短平快、强观点     | 种草、干货             | 深度、专业     |

## 五、配图建议

| 图片数量 | 适用场景         | 说明                     |
| -------- | ---------------- | ------------------------ |
| 1 张     | 观点型、热点评论 | 精选 1 张有冲击力的图    |
| 4 张     | 对比、步骤展示   | 2×2 网格布局             |
| 9 张     | 教程、产品展示   | 3×3 九宫格，第一张为封面 |

配图规则：
1. 微博配图比例不限，但建议 **16:9 横版** 或 **1:1 方图**
2. 第一张图最重要（信息流中只显示第一张）
3. 图片要有信息量（数据图、对比图、步骤图），非纯装饰
4. 避免纯文字截图（可读性差）

## 六、输出格式模板

### 短博文模板（≤ 300 字，推荐）

```markdown
# 微博短博文

## 正文
[强观点首句]

[2-3 句展开]

[核心干货]

[互动引导]

#话题一# #话题二#

## 配图建议
[1-4 张配图描述]
```

### 长博文模板（300-2000 字）

```markdown
# 微博长博文

## 正文
[强观点首句]

[背景描述]

1️⃣ [要点一]
[展开]

2️⃣ [要点二]
[展开]

3️⃣ [要点三]
[展开]

[总结 + 互动引导]

#话题一# #话题二# #话题三#

## 配图建议
[配图描述]
```

## 七、自检清单（微博专属）

- [ ] **首句有冲击力？**（强观点/数据/争议，≤ 30 字）
- [ ] **正文字数合理？**（短博 ≤ 300 字，长博 ≤ 2000 字）
- [ ] **段落够短？**（每段 1-3 行）
- [ ] **话题标签格式正确？**（`#话题名#` 双井号包裹）
- [ ] **话题标签 1-3 个？**
- [ ] **emoji 使用适度？**（2-5 个，无堆砌）
- [ ] **包含互动引导？**（转发/评论/讨论）
- [ ] **语气犀利有态度？**（非温吞平淡）
- [ ] **无错别字和语法问题？**

**如果任何一项不通过，必须修改后再输出。不得妥协。**

## 八、示例

### 示例 1：观点型短博（186 字）

**输入**：分享一个观点，AI 时代学习能力比知识存量更重要

**输出**：
```
AI 不会取代你，但会用 AI 的人会。

说真的，2026 年还在靠"记住知识"吃饭的人，已经很危险了。

ChatGPT 10 秒能查到的东西，你花 3 小时背下来，意义在哪？

真正值钱的能力只有一个👇
——学习速度比知识淘汰速度更快。

具体怎么做：
1️⃣ 每天花 30 分钟用 AI 工具学一个新概念
2️⃣ 把学到的东西当天用出来（哪怕只是写条微博）
3️⃣ 每周复盘，砍掉无效的学习内容

你觉得呢？同意的转发，不同意的来评论区辩👇

#AI时代# #终身学习# #认知升级#
```

### 示例 2：热点借势短博（127 字）

**输入**：借 AI 热点，分享自己用 AI 提升工作效率的经历

**输出**：
```
刚用 AI 帮我写完一份原本要花 3 小时的报告。

用时：27 分钟。

不是 AI 多厉害，是我终于学会了正确的提问方式。

90% 的人用 AI 没效果，不是工具不行，是 prompt 写得太烂。

分享一个我每天都在用的 prompt 公式👇
「角色 + 任务 + 格式 + 约束」

试试看，效率至少翻 3 倍🔥

#AI效率# #职场干货#
```
