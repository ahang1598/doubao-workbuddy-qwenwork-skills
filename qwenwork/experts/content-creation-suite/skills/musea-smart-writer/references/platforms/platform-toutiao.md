# 今日头条风格规范

本文档定义今日头条平台的内容排版规则，供 Agent 生成头条文章时读取。

## 平台概览

| 属性 | 规则 |
|------|------|
| 平台定位 | 信息流推荐、深度优质图文、知识分享 |
| 标题字数 | **8-30 字**（建议 18-26 字，手机端完整显示约 26 字） |
| 正文字数 | **800-3000 字**（推荐 1500-2500 字，深度内容可达 5000+） |
| 段落长度 | 每段 **3-5 行**，手机端阅读友好 |
| 配图 | 封面图（16:9，推荐 1080×608px）+ 正文插图（3-8 张） |
| 话题标签 | 2-5 个（文末添加） |
| 内容形式 | 图文文章 |
| 产出格式 | `.html`（CSS + base64 图片，浏览器打开复制粘贴到头条编辑器） |

## 一、标题策略

### 1.1 标题公式（6 种类型）

标题字数控制在 **18-26 字**，核心信息前置（手机端信息流只显示前 15 字左右）。

| 类型 | 公式 | 示例 |
|------|------|------|
| **数字型** | 数字 + 核心价值 + 受众/场景 | 5个被90%的人忽略的AI提效技巧 |
| **反差型** | 常识反说 + 转折 + 真相 | 别再用ChatGPT写文章了，这才是正确姿势 |
| **悬念型** | 信息缺口 + 吸引探索 | 为什么越来越多的程序员开始学写作？答案出乎意料 |
| **热点型** | 热点事件 + 独特视角 | GPT-5发布48小时，我发现了3个所有人都忽略的变化 |
| **实用型** | 场景痛点 + 解决方案 + 效果承诺 | 工作汇报总写不好？用这个模板5分钟搞定 |
| **身份型** | 身份标签 + 经验/行动 + 结果 | 10年产品经理转行AI，3个月后我后悔了吗？ |

### 1.2 标题规则

1. 字数 **18-26 字**，前 15 字必须包含核心信息
2. 包含具体数字或明确场景
3. 禁止标题党（"震惊！"、"不转不是中国人" 等头条会降权）
4. 禁止全标点、全大写、堆砌感叹号
5. 标题与正文内容必须一致
6. 可使用竖线 `｜`、冒号 `：`、破折号 `——` 分隔信息层

### 1.3 标题禁忌

- ❌ 标题党（夸大事实、制造恐慌、虚假承诺）
- ❌ 极限词（最、第一、绝对、100%）
- ❌ 诱导点击（"不看后悔"、"看到最后"）
- ❌ 与正文严重不符
- ❌ 纯符号或无意义标题

## 二、正文排版

### 2.1 开头钩子（前 3 行决定留存率）

头条信息流中用户划过速度极快，前 3 行必须抓住注意力：

**开头模板**（三选一）：

**① 场景切入**：
```
[具体场景/痛点描述]
[转折 + 个人经历佐证]
[价值承诺：看完你会得到什么]
```

**② 数据开头**：
```
[一个让人意外的数据或事实]
[引出话题：这意味着什么]
[预告本文将解答什么]
```

**③ 反常识开头**：
```
[反常识结论]
[为什么大多数人都错了]
[引出正确方法/真相]
```

### 2.2 正文字数指南

| 类型 | 字数 | 阅读时长 | 适用场景 |
|------|------|---------|---------|
| 短文章 | 800-1200 字 | 2-4 分钟 | 资讯速报、单点观点、热点快评 |
| **标准文章** | **1500-2500 字** | **5-8 分钟** | **干货教程、深度解读、案例分析（推荐）** |
| 深度长文 | 3000-5000 字 | 10-15 分钟 | 行业分析、年度盘点、完整教程 |

> 💡 头条 2025 年明确提出"优质深度"战略，1500 字以上的深度图文获得更多推荐权重。

### 2.3 正文结构

采用 **"总—分—总"** 架构，小标题分段：

```
开头钩子（3行）

## 一、[小标题1：分论点一]
观点句 → 论据/案例 → 小结
[配图]

## 二、[小标题2：分论点二]
观点句 → 论据/案例 → 小结
[配图]

## 三、[小标题3：分论点三]
观点句 → 论据/案例 → 小结

---
[结尾总结 + CTA互动引导]
```

### 2.4 排版细节

1. **段落控制**：单段 **3-5 行**，手机端阅读友好
2. **视觉分隔**：每 **300-400 字** 必须有视觉分隔（小标题/图片/引用）
3. **小标题**：全文 **3-6 个** 小标题，使用 `##` 格式
4. **不缩进**：头条阅读习惯不使用首行缩进
5. **加粗强调**：只加粗 **关键词或金句**，禁止大段加粗
6. **引用块**：重要观点或金句使用引用格式
7. **列表清晰**：步骤、要点使用有序/无序列表
8. **数据支撑**：每个核心观点至少配 1 个数据或案例
9. **过渡自然**：段落间要有逻辑衔接

### 2.5 HTML 排版规范（字号、颜色、间距）

生成的 HTML 文件需遵循以下样式参数，确保阅读体验：

| 元素 | 样式 | 说明 |
|------|------|------|
| 正文 | `font-size: 16px; color: #333; line-height: 1.75` | 舒适阅读 |
| 小标题 | `font-size: 18px; font-weight: bold; color: #222` | 加粗，上下留空 |
| 引用/重点 | `font-size: 15px; color: #666; border-left: 3px solid #ddd; padding-left: 12px` | 左边框引用 |
| 注释/来源 | `font-size: 13px; color: #999` | 图片说明、备注 |
| 页面宽度 | `max-width: 750px; margin: 0 auto` | 居中适配移动端 |

**间距规范**：
- 行高：`1.75`
- 段间距：段落之间 `margin-bottom: 16px`
- 小标题上方：`margin-top: 28px`
- 图片与正文：上下 `margin: 16px 0`
- 左右边距：`padding: 0 16px`

### 2.6 emoji 使用

- 头条正文**谨慎使用 emoji**，保持信息感和专业感
- 允许在小标题、重点强调处适度使用（每篇 **3-5 个** 为宜）
- 禁止堆砌，禁止替代标点
- 适合的 emoji：📌 要点、💡 技巧、⚠️ 注意、✅ 正确、❌ 错误

### 2.7 结尾 CTA

结尾 CTA 不超过 2 个：

**互动引导**（推荐）：
```
你觉得AI未来会取代哪些岗位？欢迎在评论区说说你的看法。
```

**关注引导**：
```
如果觉得有用，欢迎点赞+收藏，关注我获取更多AI实战技巧。
```

**转发引导**：
```
觉得对身边人有帮助，可以转发给他们看看。
```

## 三、封面图规范

### 3.1 封面图尺寸

| 类型 | 尺寸 | 比例 | 说明 |
|------|------|------|------|
| **单图大图** | 1080×608px | **16:9** | 推荐，信息流展示效果最佳 |
| 三图模式 | 每张 340×192px | 16:9 | 三张封面图并排展示 |
| 小图模式 | 右侧缩略图 | 1:1 | 系统自动裁剪 |

### 3.2 封面图原则

1. **画质清晰**，分辨率不低于 1080px 宽度
2. 封面图与文章内容**强相关**
3. 如有文字，文字区域占比不超过封面面积的 **30%**
4. 避免纯文字封面（低质感）
5. 优先级：**信息图 > 场景图 > 纯文字图**
6. 避免使用 BMP、GIF 格式

## 四、正文配图规范

1. 每篇文章 **3-8 张图**，太少枯燥太多影响加载
2. 图片宽度建议 **750px** 左右（适配移动端）
3. 图片与正文内容**强相关**，不用纯装饰性配图
4. 每 **300-500 字** 建议配一张图，作为视觉休息点
5. 图片下方建议加**一行说明文字**（灰色小字）
6. 优先级：**信息图/截图 > 数据图 > 摄影图**（干货类内容）

## 五、话题标签（2-5 个）

### 5.1 标签策略

| 类型 | 建议数量 | 示例 |
|------|----------|------|
| 垂直领域标签 | 1-2 个 | `#人工智能` `#AI工具` |
| 内容主题标签 | 1-2 个 | `#效率提升` `#职场技能` |
| 热点/泛流量标签 | 0-1 个 | `#今日头条` `#干货分享` |

### 5.2 标签规则

1. 格式：`#标签名#`（头条标签前后都有 `#`）
2. 总数 **2-5 个**，质量优于数量
3. 标签与文章内容强相关
4. 优先使用平台已有的热门标签

## 六、推荐机制要点

### 6.1 阶梯式推荐

头条采用算法推荐机制，文章发布后经历：
1. **冷启动**：推给小范围用户（约 200-500 人）
2. **数据验证**：根据点击率、阅读完成率、互动率决定是否扩大推荐
3. **放量推荐**：数据达标后逐步放大到更大流量池

### 6.2 关键数据指标

| 指标 | 优质标准 | 说明 |
|------|---------|------|
| 点击率 | ≥ 3% | 标题 + 封面图的吸引力 |
| 阅读完成率 | ≥ 40% | 正文质量、结构、排版的综合体现 |
| 互动率 | ≥ 1% | 评论 + 收藏 + 转发 |
| 粉丝阅读占比 | ≤ 70% | 非粉丝阅读占比越高，说明内容越有公域价值 |

### 6.3 权重加分项

- ✅ 原创内容（开通原创标签后推荐权重+30%）
- ✅ 深度图文（1500 字以上 + 3 张以上配图）
- ✅ 垂直领域持续输出
- ✅ 评论区活跃互动

### 6.4 权重减分项

- ❌ 标题党
- ❌ 搬运/低原创度内容
- ❌ 配图模糊/无关
- ❌ 频繁删文重发

## 七、发布时间建议

| 时段 | 适合内容 | 推荐指数 |
|------|---------|---------|
| **07:00-09:00** | 通勤碎片阅读，资讯/干货类 | ⭐⭐⭐⭐ |
| **11:30-13:00** | 午休时间，轻松/实用内容 | ⭐⭐⭐ |
| **17:30-19:00** | 晚通勤，深度内容 | ⭐⭐⭐⭐ |
| **20:00-22:00** | **黄金时段**，全天活跃度最高 | ⭐⭐⭐⭐⭐ |

> 💡 头条推荐是算法驱动，发布时间影响相对较小，但黄金时段冷启动速度更快。

## 八、合规红线

- ⛔ 标题党（虚假、夸大、诱导）
- ⛔ 政治敏感内容
- ⛔ 虚假信息 / 造谣传谣
- ⛔ 未授权转载
- ⛔ 低俗/擦边内容
- ⛔ 恶意营销 / 硬广
- ⛔ 极限词（最、第一、绝对等）
- ⛔ AI 批量生产低质内容
