## 黄金公式

> **好文案 = 50% 内容价值 + 30% 情绪共鸣 + 20% 关键词布局**

| 要素 | 说明 |
|------|------|
| 内容价值（50%） | 能帮到用户，解决实际问题 |
| 情绪共鸣（30%） | 触发情感按钮，让人有感觉 |
| 关键词布局（20%） | 精准匹配搜索，提升可发现性 |
| 真实体验（2026 核心） | 真人创作、真实感受，算法优先推荐 |

### 1.2 标题 4 大核心要素（写完对照检查）

- **价值感**：明确告诉用户"能获得什么"
- **好奇心**：制造适当悬念和缺口
- **情绪共鸣**：触发用户的情感按钮
- **关键词布局**：精准匹配搜索流量，建议 2-3 个关键词

> 💬 含数字/问号的标题点击率平均提升 **42%**，标题需在 **3秒内** 抓住注意力。

### 1.3 标题规则

1. 字数 ≤ 20 字（含 emoji，不含空格），写完必须数一遍
2. 必须包含至少 1 个 emoji（放在语义转折处或末尾，不要堆砌）
3. 使用竖线 `｜` 或中文逗号分隔信息层
4. 优先使用数字开头（"3步"、"5个"、"10分钟"）
5. 标题需包含 2-3 个精准关键词，匹配用户搜索习惯
6. 禁止使用引号包裹整个标题

### 1.4 标题 5 大雷区

| 雷区类型 | 错误示例 | 问题说明 |
|----------|----------|----------|
| 夸大不实 | 三天瘦十斤的惊天秘密 | 虚假承诺，触发平台审查 |
| 低质诱导 | 看到最后有惊喜 | 诱导性标题，算法降权 |
| 模糊不清 | 分享一个好用的东西 | 缺乏具体性，无法抓人眼球 |
| 关键词堆砌 | 护肤 美白 精华 推荐 2026 | 影响阅读体验，无流量价值 |

## 二、正文排版

### 2.1 黄金三段式结构

```
【开头】快速切入主题，制造悬念或直击共鸣（前 2 行决定展开率）
  ↓
【正文】分段清晰，每段 ≤ 3-4 行，干货 + 场景 + 真实体验
  ↓
【结尾】互动引导语 → "你们觉得呢？" / "需要清单的评论区dd~"
```

### 2.2 开头钩子（前 2-3 行定生死）

必须在前 2-3 行内抓住读者，以下模板任选：

**① 痛点切入**：
```
[痛点提问/你是不是也……]❗
[具体场景描述]
[转折 + 方法预告]💪
```

**② 反常识开头**：
```
[反常识结论]
[个人经历佐证]
[引出方法论]👇
```

### 2.3 3 大核心写作公式

**① 痛点 + 解决方案**
- 开头用"你是不是也……"句式直击痛点
- 正文清晰列出步骤，加粗关键信息（成分/效果/使用频率）
- 示例：「熬夜脸黄气色差？急救护肤3步走：①……②……③……」

**② 场景化 + 价值前置**
- 把内容嵌入高频生活场景
- 标题最前亮出用户最关心的结果（省钱/懒人/小众）
- 示例：「周末闺蜜聚会，5分钟快速出门伪素颜妆教」

**③ 情绪价值 + 实用干货**
- 注入"治愈""解压""安全感"等情绪词
- 情绪之后必须用实在内容支撑，不能只喊口号
- 示例：「独居女孩的夜晚安全感，是这盏灯给的 [附布置清单]」

### 2.4 正文结构模板

采用 **"总—分—总"** 架构：

```
开头钩子（2-3行）
———————————————————
核心概念解释（3-5行）
———————————————————
方法/步骤（每步3-4行，用序号标记）
———————————————————
效果/数据佐证（3-5行）
———————————————————
避坑提醒（2-4条）
———————————————————
互动引导（2-3行）
```

### 2.5 提升"网感"的关键技巧

| 技巧 | 方法 | 示例 |
|------|------|------|
| 表情符号 | 段落开头或关键信息处，每段 1-2 个 | 🌟 📝 ✅ 🔥 |
| 口语化表达 | 避免书面语，多用流行口语 | 咱就是说、真的绝了、姐妹们、沉浸式 |
| 互动钩子 | 提问或引导动作，促进评论收藏 | 需要清单的评论区dd / 你们有没有同款烦恼？ |
| 段落控制 | 每段不超过 3-4 行，适时空行 | 增加留白，移动端体验更好 |

> ⚠️ **2026 去AI味提示**：AI 生成内容发布前**必须口语化改写并加入真实体验细节**，否则容易被识别为低质内容导致限流。

### 2.6 emoji 使用规范

| 位置 | 用法 | 示例 |
|------|------|------|
| 段落开头 | 标记内容类型 | 🧠 概念、📋 步骤、🔥 重点、💡 技巧 |
| 强调处 | 情绪放大 | ❗警示、✅ 正确、❌ 错误、👉 指向 |
| 结尾 | 互动引导 | 💾 收藏、👇 评论、🥰 情感 |
| 序号替代 | 步骤编号 | 𝟭｜ 𝟮｜ 𝟯｜ 或 ❶ ❷ ❸ |

**密度控制**：每段 1-2 个 emoji，禁止连续 3 个以上 emoji 堆砌。

### 2.7 文字排版细节

1. **短句为王**：每句 ≤ 20 字，长句必须拆分
2. **换行即分段**：小红书没有段落缩进，靠换行制造呼吸感
3. **对比句式（推荐）**：适合时可使用 `不是A❌ 而是B✅` 格式制造认知冲突，增强表达力
   - 示例：`不是盲目日更❌ 而是精准选题✅`
   - 非强制，视内容类型灵活使用
4. **数据锚点**：用具体数字替代模糊描述（"提升了" → "提升了35%"）
5. **口语化表达**：用"咱就是说"、"真的绝了"、"姐妹们"、"划重点"等拉近距离
6. **禁止长段落**：超过 3-4 行的段落必须拆分或删减
7. **互动引导（强制）**：正文结尾必须包含互动引导模块：
   ```
   💬 你在[相关场景]中遇到过什么问题？
   👇 评论区告诉我，我来帮你解答！
   💾 觉得有用就收藏起来，下次照着做～
   ```
   或使用更口语化的引导：`需要清单的评论区dd~` / `你们有没有同款烦恼？`

> ✅ 总数建议 **3-5 个**，不要堆砌无关标签。平台会对无关标签做降权处理，质量优于数量。

### 3.1 标签分类策略

| 类型 | 建议数量 | 示例 |
|------|----------|------|
| 热点/泛流量标签 | 1-2 个 | `#今天学到了` `#种草` |
| 垂直品类标签 | 1-2 个 | `#小红书运营` `#AI工具` |
| 人群+场景+产品组合标签 | 1-2 个 | `#25岁职场穿搭` `#通勤必备` |
| 地域标签（本地内容时） | 按需 | `#北京探店` `#上海周末` |

### 3.2 标签规则

1. **格式要求**：每个标签前加 `#`，标签之间用空格分隔
2. **总数 3-5 个**：质量优于数量，不堆砌无关标签
3. **禁止生造标签**：优先使用平台已有的热门标签
4. **关键词匹配**：标签需与正文内容强相关，无关标签会被算法降权

**正确示例**：
```
#AI工具 #效率提升 #职场干货 #打工人必备
```

**错误示例**：
```
#AI工具 #护肤 #穿搭 #美食 #旅行 #减肥 #考研    ← ❌ 堆砌无关标签，会被降权
```
