# 微信公众号风格规范

本文档定义微信公众号平台的内容排版规则，供 Agent 生成公众号内容时读取。

## 平台概览

| 属性 | 规则 |
|------|------|
| 平台定位 | 深度内容/观点输出/知识分享 |
| 标题字数 | **18-28 字**（手机端完整显示约 26 字） |
| 正文字数 | **建议 1500-2500 字**（最佳完读率区间，单篇最长支持约 20000 字） |
| 摘要 | **30-54 字**（补充信息/制造悬念，不重复标题） |
| 段落长度 | 每段 ≤ 4 行，手机端阅读友好 |
| 配图 | 封面图（横版 2.35:1 或 1:1）+ 正文插图（3-6 张） |
| 话题标签 | 2-3 个（可选） |
| 内容形式 | 长图文推送 |

## 一、标题策略

### 1.1 标题公式（5 种类型）

标题字数控制在 **18-28 字**，手机端完整显示约 26 字。

| 类型 | 公式 | 示例 |
|------|------|------|
| **数字型** | 数字 + 痛点/结果 | 3个让AI写出人味文章的技巧 |
| **反差型** | 常识反说 + 悬念 | 别再这么用ChatGPT了，你可能一直在浪费时间 |
| **身份型** | 身份 + 行动 + 收益 | 工程师实测：这5个AI工具真正改变了我的工作流 |
| **热点型** | 热点事件 + 你的视角 | GPT-5发布后，我发现的3个被忽略的变化 |
| **清单型** | 主题 + 数量 + 场景 | 程序员必备的7个AI代码助手对比 |

规则：
1. 标题 18-28 字，前 15 字必须包含核心信息（手机端只显示前 15 字左右）
2. 包含具体数字或场景，让读者能预判文章价值
3. 可使用竖线 `｜`、冒号 `：` 分隔信息层
4. 符合用户搜索习惯的关键词
5. 标题本身能引发好奇或共鸣

### 1.2 标题禁忌

- ❌ 全标点 / 全数字 / 滥用 emoji
- ❌ 标题党（"震惊！"、"必看！"等微信会降权）
- ❌ 标题前后加空格或特殊符号
- ❌ 标题与正文严重不符
- ❌ 无信息量标题（"聊聊最近的感悟"）

## 二、摘要（30-54 字）

摘要显示在消息列表和分享卡片中，直接影响打开率。

**摘要公式**：不重复标题 → 补充关键信息 / 制造悬念

规则：
1. 字数控制在 **30-54 字**
2. 不重复标题内容，而是补充信息或制造悬念
3. 第一句话必须有吸引力，呼应标题中的悬念
4. 避免"点击阅读全文"等无意义引导

**示例**：
```
标题："3个让AI写出人味文章的技巧"
摘要："第三条90%的人都不知道，建议收藏"
```

```
标题："被AI取代之前，你需要学会这3件事"
摘要："不是学技术，而是学一种新的思维方式。最后一条最反常识。"
```

## 三、正文排版

### 3.1 开头钩子（前 3 行决定留存率）

开头必须在前 3 行内完成：**场景/痛点 → 引出话题 → 价值承诺**

**开头模板**：
```
[场景/痛点] 描述读者正在面临的问题或场景
[引出话题] 自然的过渡，引出本文要讲的核心
[价值承诺] 明确告诉读者看完能得到什么
```

**示例**：
```
上周帮一个朋友整理年度报告，花了整整两天才搞定。（场景）
后来我试着用AI重新做了一遍，同样的内容只用了2小时。（引出话题）
今天把我摸索出来的完整流程分享给你。（价值承诺）
```

### 3.2 正文字数指南

微信公众号正文没有强制字数限制，单篇最长支持约 20000 字，但实际运营中有明确的"有效区间"：

| 类型 | 字数 | 阅读时长 | 适用场景 |
|------|------|---------|---------|
| 短图文 | 300-800 字 | 1-3 分钟 | 资讯速报、观点输出、金句分享 |
| **标准图文** | **1500-2500 字** | **5-8 分钟** | **干货教程、深度解读、案例分析（推荐）** |
| 长文/深度 | 3000-5000 字 | 10-15 分钟 | 年度盘点、行业报告、完整教程 |
| 超长文 | 5000 字+ | 15 分钟+ | 白皮书、连载（极少数场景） |

**关键数据参考**：
- **最佳区间是 1500-2500 字**，这个长度完读率最高，也是大多数头部公众号的主力区间
- 超过 3000 字完读率会明显下降（通常跌到 30% 以下）
- 超过 5000 字的文章，建议拆成系列连载，每篇控制在 2500 字以内
- 手机端阅读速度约 300-400 字/分钟

**字数速算公式**：`目标阅读时长 × 350字/分钟 ≈ 推荐字数`
- 例如：想让读者花 5 分钟看完 → 5 × 350 = 1750 字

> 💡 不需要刻意凑字数，核心是信息密度——用最少的字把事说清楚，比堆字数有效得多。

### 3.3 正文结构

采用 **"总—分—总"** 架构，每个小标题下遵循 **观点 + 论据 + 案例/总结** 的展开方式：

```
开头钩子（3行）

## 一、[小标题1：分论点一]
观点句 → 论据（数据/案例/引用）→ 总结
[视觉分隔] 图片 / 引用块 / 分割线

## 二、[小标题2：分论点二]
观点句 → 论据（数据/案例/引用）→ 总结
[视觉分隔] 图片 / 引用块 / 分割线

## 三、[小标题3：分论点三]（可选）
观点句 → 论据（数据/案例/引用）→ 总结

---
[结尾CTA：互动引导 / 关注引导 / 转发引导（不超过2个）]
```

### 3.4 排版细节

1. **段落控制**：单段不超过 **4 行**，手机端阅读友好
2. **视觉分隔**：每 **300 字**必须有视觉分隔（小标题/图片/引用块）
3. **小标题**：全文 **3-5 个**小标题，编号或符号风格统一
4. **不缩进**：微信阅读习惯不使用首行缩进
5. **引用块**：重要观点或金句使用引用格式
   ```
   > 不是信息太多，而是你的筛选能力太弱。
   ```
6. **加粗强调**：只加粗**关键词或金句**，禁止大段文字整段加粗
7. **对齐方式**：长段落左对齐，仅短句/金句可居中
8. **列表清晰**：步骤、要点使用有序/无序列表
9. **数据支撑**：每个核心观点至少配 1 个数据或案例
10. **过渡自然**：段落间要有逻辑衔接，不是简单堆砌

### 3.5 排版规范（字号、颜色、间距）

| 元素 | 字号 | 颜色 | 说明 |
|------|------|------|------|
| 正文 | **14-15px** | `#3F3F3F` | 不用纯黑 #000，太刺眼 |
| 小标题 | **16-17px** | 品牌主色 | 加粗，上下留 1 行空 |
| 引用/重点 | 同正文 | `#888` 或主色 | 避免大面积高亮 |
| 注释/来源 | **12-13px** | `#999` | 图片说明、备注 |

**间距规范**：
- 段间距：1.5 倍行高（推荐行高 **1.75**）
- 行间距：段落之间 **空 1 行**
- 左右边距：**15-20px**（编辑器默认即可）
- 图片与正文：空 **1 行**

**配色原则**：
- **主色**：1 种品牌色（用于小标题、重点标注）
- **辅助色**：1-2 种（引用块、提示框、分隔线）
- 全文颜色 **不超过 3 种**（不含黑白灰），固定配色形成品牌识别

### 3.6 emoji 使用

- 公众号正文 **谨慎使用 emoji**，保持专业感
- 允许在小标题、重点强调处适度使用（每篇 3-5 个为宜）
- 禁止堆砌，禁止替代标点
- 适合的 emoji：📌 要点、💡 技巧、⚠️ 注意、✅ 正确、❌ 错误

### 3.7 结尾 CTA（不超过 2 个）

结尾的 CTA 不要超过 2 个，太多会降低用户行动意愿。优先选「互动引导」，评论率直接提升算法推荐权重。

**三种 CTA 模板（三选一或组合，最多选 2 个）**：

**互动引导**（推荐优先）：提一个开放性问题，引导评论
```
你平时最常用的AI工具有哪些？欢迎评论区聊聊
```

**关注引导**：一句话总结公众号价值
```
关注我，每周分享一个AI提效实战技巧
```

**转发引导**：提炼一个金句，方便截图分享
```
好工具不在于多，在于用得对。
```

## 四、排版常见错误

| ❌ 避免这样做 | ✅ 推荐这样做 |
|-------------|-------------|
| 首行缩进 2 字符 | 不缩进（微信阅读习惯） |
| 纯文字堆叠无视觉休息点 | 每 300 字插入图片/小标题/引用 |
| 大段文字整段加粗 | 只加粗关键词或金句 |
| 居中对齐长段落 | 长段落左对齐，仅短句居中 |
| 彩虹配色（超过 3 种颜色） | 固定品牌配色方案 |

## 五、排版风格对比（vs 小红书）

| 维度 | 公众号 | 小红书 |
|------|--------|--------|
| 字数 | 1500-2500 字 | ≤ 1000 字 |
| 段落 | ≤ 4 行/段 | ≤ 3 行/段 |
| 结构 | 小标题分段（3-5 个） | 分隔线分段 |
| emoji | 谨慎使用（3-5 个） | 高频使用（每 2-3 行 1 个） |
| 语气 | 理性、专业、有深度 | 口语化、亲近、有人设 |
| 标签 | 话题标签 2-3 个（可选） | 5-10 个 hashtag |
| 互动 | CTA 不超过 2 个（转发/关注/留言） | 收藏 + 评论 + 关注 |
| 图片 | 封面图 + 正文插图（3-6 张） | 封面图 + 内容卡片 |

## 六、话题标签与关键词引导

### 6.1 话题标签（2-3 个，可选）

公众号支持添加话题标签，建议 2-3 个：
- 选择与内容强相关的垂直领域话题
- 优先使用平台已有的热门话题

### 6.2 关键词引导（可选）

文末可设置关键词引导和相关阅读：

```
**相关阅读**：
- [文章标题一](链接)
- [文章标题二](链接)

**关键词回复**：回复「[关键词]」获取 [资源名称]
```

## 七、配图规范

### 7.1 尺寸与格式

| 图片类型 | 尺寸 | 大小限制 | 格式 |
|---------|------|---------|------|
| 封面图 | 900×383px（2.35:1）或 1:1 | < 2MB | JPG / PNG |
| 正文图 | 宽度 750px 左右 | < 5MB | JPG / PNG |
| 动图 GIF | 宽度 ≤ 750px | < 2MB，时长 < 5秒 | GIF |
| 二维码 | 适中，带品牌色边框 | 清晰可扫 | PNG |

### 7.2 配图原则

1. 每篇文章 **3-6 张图**，太少枯燥太多影响加载
2. 优先级：**信息图 > 截图 > 摄影图**（干货类内容）
3. 图片与正文内容 **强相关**，不用纯装饰性配图
4. 避免 BMP / WebP 格式（兼容性问题）
5. 图片下方建议加 **一行说明文字**（12px，灰色）
6. **封面图**：标题核心信息 + 品牌色调，避免文字过多
7. **数据图**：核心数据用可视化图表呈现
8. **金句图**：文中传播力最强的 1 句话，适合读者截图分享

## 八、发布时机建议

| 时段 | 适合内容 | 推荐指数 |
|------|---------|---------|
| **07:30-08:30** | 通勤早高峰，资讯/干货类 | ⭐⭐⭐⭐ |
| **11:30-12:30** | 午休时间，轻松/趣味内容 | ⭐⭐⭐ |
| **18:00-19:00** | 晚通勤高峰，**全天第一黄金时段** | ⭐⭐⭐⭐⭐ |
| **20:30-22:00** | 睡前深度阅读，**全天第二黄金时段** | ⭐⭐⭐⭐⭐ |
| 22:00 之后 | 尽量避免，打扰用户休息 | ⭐⭐ |

> 💡 选定固定发布时间后坚持至少 **2 个月**，让用户形成阅读肌肉记忆。固定时间发布比随机发布打开率高 **15-20%**。

## 九、合规红线（触碰即封号风险）

- ⛔ 政治敏感内容（人物、体制、政策）
- ⛔ 虚假信息 / 造谣传谣
- ⛔ 未授权转载他人作品
- ⛔ 诱导分享（"转发才能看"、"集赞送礼品"等）
- ⛔ 过度营销（超过 30% 推文为硬广）
- ⛔ 标题与内容严重不符
- ⛔ 恶意刷量 / 购买粉丝

## 十一、自检清单（公众号专属）

- [ ] **标题 18-28 字？**（前 15 字包含核心信息）
- [ ] **标题无敏感词和标题党？**（无全标点/滥用 emoji）
- [ ] **摘要 30-54 字？**（不重复标题，补充信息/制造悬念）
- [ ] **正文字数在合理区间？**（标准图文 1500-2500 字，短图文 300-800 字，长文 3000-5000 字）
- [ ] **正文段落不超过 4 行？**（无首行缩进）
- [ ] **小标题 3-5 个？**（编号/符号风格统一）
- [ ] **每 300 字有视觉分隔？**（小标题/图片/引用块）
- [ ] **全文颜色不超过 3 种？**（不含黑白灰）
- [ ] **图片 3-6 张？**（尺寸和格式符合规范）
- [ ] **图片下方有说明文字？**
- [ ] **结尾 CTA 不超过 2 个？**（评论/关注/转发）
- [ ] **话题标签已添加？**（2-3 个）
- [ ] **emoji 使用克制？**（整篇 3-5 个为宜）
- [ ] **正文无错别字？**（标点符号规范，中文用全角）
- [ ] **发布时间在推荐时段内？**
- [ ] **内容不触碰合规红线？**

**如果任何一项不通过，必须修改后再输出。不得妥协。**

## 写作核心口诀

> **标题定生死，开头定留存**
> **段落短小精悍，视觉节奏分明**
> **配色固定不超三，固定时间发不停**
> **合规红线绝不碰，CTA引导要克制**
