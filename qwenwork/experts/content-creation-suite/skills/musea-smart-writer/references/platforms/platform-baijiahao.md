# 百家号风格规范

本文档定义百度百家号平台的内容排版规则，供 Agent 生成百家号文章时读取。

## 平台概览

| 属性 | 规则 |
|------|------|
| 平台定位 | 百度搜索生态内容分发、SEO 友好、知识型内容 |
| 标题字数 | **9-30 字**（建议 18-26 字，搜索结果显示前 28 字左右） |
| 正文字数 | **800-3000 字**（推荐 1500-2500 字，SEO 最佳区间） |
| 段落长度 | 每段 **3-5 行**，手机端阅读友好 |
| 配图 | 封面图（16:9，推荐 1080×608px）+ 正文插图（3-8 张） |
| 话题标签 | 2-5 个 |
| 内容形式 | 图文文章 |
| 产出格式 | `.html`（CSS + base64 图片，浏览器打开复制粘贴到百家号编辑器） |

## 一、标题策略

### 1.1 标题公式（6 种类型）

百家号标题**兼顾推荐流量和搜索流量**，需要包含用户搜索关键词。

| 类型 | 公式 | 示例 |
|------|------|------|
| **关键词型** | 核心关键词 + 场景/痛点 + 解决方案 | AI写作工具怎么选？3款实测对比告诉你答案 |
| **数字型** | 数字 + 核心价值 + 场景限定 | 2026年最值得学习的5个AI技能，第3个门槛最低 |
| **问答型** | 疑问句 + 关键词 + 悬念 | 为什么你的公众号阅读量总是上不去？可能忽略了这3点 |
| **热点型** | 热点事件 + 深度解读角度 | DeepSeek发布新模型，对普通人意味着什么？ |
| **教程型** | 操作动词 + 具体目标 + 效果承诺 | 手把手教你用AI做PPT，10分钟搞定年终汇报 |
| **对比型** | A vs B + 评判维度 + 结论暗示 | ChatGPT vs Claude：6个维度实测对比，差距比想象中大 |

### 1.2 标题 SEO 规则

1. 字数 **18-26 字**，包含 **2-3 个搜索关键词**
2. 核心关键词尽量**前置**（搜索结果中前 15 字权重最高）
3. 标题本身可被搜索引擎匹配（用户搜什么词能找到这篇文章？）
4. 禁止关键词堆砌（"AI AI工具 AI效率 AI写作"）
5. 自然语义通顺，兼顾可读性和 SEO

### 1.3 标题禁忌

- ❌ 标题党（夸大、恐慌、虚假承诺）
- ❌ 极限词（最、第一、绝对、100%）
- ❌ 诱导点击
- ❌ 标题与正文不符
- ❌ 纯符号、纯数字标题

## 二、正文排版

### 2.1 SEO 友好的内容结构

百家号文章天然分发在百度搜索结果中，正文结构需**兼顾读者体验和搜索引擎抓取**：

1. **关键词自然分布**：核心关键词在全文出现 **3-5 次**，分布在标题、开头、小标题、结尾
2. **小标题包含关键词**：小标题本身可被搜索匹配
3. **首段包含核心信息**：搜索摘要通常抓取首段，首段必须包含核心关键词和价值承诺
4. **段落语义完整**：每段表达一个完整观点，搜索引擎按段落提取摘要

### 2.2 开头钩子

与头条类似，前 3 行决定留存率：

**开头模板**：
```
[搜索意图回应：直接回答用户可能搜索的问题]
[深入引导：但事情没有这么简单 / 但很多人忽略了关键一步]
[价值承诺：这篇文章将从X个维度帮你彻底搞清楚]
```

**示例**：
```
很多人问：AI写作工具到底能不能替代人工写作？（搜索意图回应）
答案是：能，但前提是你得会用。90%的人用错了方法。（深入引导）
今天我从效率、质量、成本三个维度实测对比3款主流工具，帮你找到最适合的。（价值承诺）
```

### 2.3 正文字数指南

| 类型 | 字数 | 适用场景 |
|------|------|---------|
| 短文章 | 800-1200 字 | 资讯速报、单点解答 |
| **标准文章** | **1500-2500 字** | **干货教程、深度解读、测评对比（推荐）** |
| 深度长文 | 3000-5000 字 | 行业报告、完整教程、白皮书 |

> 💡 百家号原创权益要求文章不少于 **300 字**，但 1500 字以上的深度原创内容获得更多搜索权重。

### 2.4 正文结构

```
开头钩子（3行，包含核心关键词）

## 一、[小标题1：包含关键词]
观点句 → 论据/案例 → 数据佐证 → 小结
[配图]

## 二、[小标题2：包含关键词]
观点句 → 步骤/方法 → 实操示例 → 小结
[配图]

## 三、[小标题3]
观点句 → 对比/总结 → 行动建议

---
[结尾总结：回扣标题 + CTA]
```

### 2.5 排版细节

1. **段落控制**：单段 **3-5 行**
2. **视觉分隔**：每 **300-400 字** 有小标题或图片
3. **小标题**：全文 **3-6 个**，使用 `##` 格式，包含搜索关键词
4. **不缩进**：无首行缩进
5. **加粗强调**：只加粗**关键词、关键数据、核心结论**
6. **引用块**：重要观点、数据引用使用引用格式
7. **列表清晰**：步骤和要点使用有序/无序列表
8. **内链价值**：可引用其他权威来源增强可信度

### 2.6 HTML 排版规范（字号、颜色、间距）

| 元素 | 样式 | 说明 |
|------|------|------|
| 正文 | `font-size: 16px; color: #333; line-height: 1.75` | 舒适阅读 |
| 小标题 | `font-size: 18px; font-weight: bold; color: #222` | 加粗，上下留空 |
| 引用/重点 | `font-size: 15px; color: #666; border-left: 3px solid #ddd; padding-left: 12px` | 左边框引用 |
| 注释/来源 | `font-size: 13px; color: #999` | 图片说明、数据来源 |
| 页面宽度 | `max-width: 750px; margin: 0 auto` | 居中适配移动端 |

**间距规范**：
- 行高：`1.75`
- 段间距：`margin-bottom: 16px`
- 小标题上方：`margin-top: 28px`
- 图片与正文：`margin: 16px 0`
- 左右边距：`padding: 0 16px`

### 2.7 emoji 使用

- 百家号正文**极度克制使用 emoji**，保持专业信息感
- 仅在小标题前标记内容类型时使用（每篇 **2-4 个** 为宜）
- 禁止堆砌
- 适合的 emoji：📌 要点、💡 技巧、⚠️ 注意、✅ 推荐、❌ 不推荐

### 2.8 结尾 CTA

```
[总结段：一句话回扣标题，总结核心结论]

如果这篇文章对你有帮助，欢迎点赞收藏。你还想了解哪方面的AI工具？评论区告诉我。
```

## 三、封面图规范

| 类型 | 尺寸 | 比例 | 说明 |
|------|------|------|------|
| **单图大图** | 1080×608px | **16:9** | 推荐，搜索结果展示效果最佳 |
| 三图模式 | 每张 340×192px | 16:9 | 三张封面并排 |

**封面图原则**：
1. 画质清晰，不低于 1080px 宽
2. 与文章内容强相关
3. 文字区域不超过封面 30%
4. 避免纯文字封面
5. 百度对封面图质量有审核，模糊/低质图片影响推荐

## 四、正文配图规范

1. 每篇文章 **3-8 张图**
2. 图片宽度 **750px** 左右
3. 图片与正文**强相关**
4. 每 **300-500 字** 配一张图
5. 图片下方加**说明文字**（灰色小字，标注来源）
6. 优先级：**截图/信息图 > 数据图 > 摄影图**
7. 百度对图片版权审核严格，优先使用自制图或合规素材

## 五、关键词 SEO 策略

### 5.1 关键词布局

| 位置 | 要求 |
|------|------|
| 标题 | 包含 **1-2 个** 核心关键词 |
| 首段 | 包含核心关键词 **1 次** |
| 小标题 | 至少 **1 个** 小标题包含关键词 |
| 正文 | 核心关键词全文出现 **3-5 次**，自然分布 |
| 结尾 | 包含核心关键词 **1 次** |

### 5.2 关键词选择原则

1. **用户视角**：用户会搜什么词来找到这篇文章？
2. **长尾优先**：比如用 "AI写作工具推荐2026" 而非 "AI"
3. **自然融入**：关键词必须语义自然，禁止生硬插入
4. **同义词覆盖**：适当使用同义词/近义词增加匹配面

## 六、话题标签（2-5 个）

1. 格式：`#标签名#`
2. 总数 2-5 个
3. 包含核心搜索关键词
4. 优先使用百度已有的热门话题
5. 标签与文章内容强相关

## 七、推荐机制要点

### 7.1 双引擎分发

百家号文章同时通过**推荐引擎**和**搜索引擎**获取流量：

| 引擎 | 流量来源 | 优化重点 |
|------|---------|---------|
| 推荐引擎 | 百度 APP 信息流 | 标题吸引力、封面图、互动率 |
| 搜索引擎 | 百度搜索结果 | 关键词布局、内容深度、权威性 |

### 7.2 百家号指数

百家号通过"百家号指数"评估创作者质量，影响推荐权重：

| 维度 | 权重 | 优化建议 |
|------|------|---------|
| 内容质量 | 最高 | 原创深度内容、字数 1500+、配图清晰 |
| 原创度 | 高 | 开通原创标签、内容重复率 < 10% |
| 活跃度 | 中 | 稳定更新频率 |
| 用户喜爱 | 中 | 互动率、完读率 |
| 领域专注 | 中 | 垂直领域持续输出 |

## 九、合规红线

- ⛔ 标题党 / 低俗擦边
- ⛔ 政治敏感内容
- ⛔ 虚假信息 / 伪科学
- ⛔ 未授权转载（百度版权审核严格）
- ⛔ 恶意营销 / 软文硬广
- ⛔ 极限词
- ⛔ AI 批量生产低质内容
- ⛔ 医疗/金融/法律领域需资质
