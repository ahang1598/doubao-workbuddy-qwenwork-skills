# FAB 写作框架

## 全称

**F**eature → **A**dvantage → **B**enefit
特点 → 优势 → 利益

## 适用场景

- 产品测评、个人实测
- 电商产品描述
- 卖点提炼
- 资源盘点（每个资源用 FAB 结构）

## 默认适配文章类型

| 文章类型 | 适配理由 |
|---------|---------|
| 产品测评 | 测评天然是"功能→优势→用户价值"结构 |
| 资源盘点 | 每个资源/工具都需要讲清"好在哪里" |

## 三段结构

### F - Feature（特点）| 占全文 30%

**目标**：客观描述产品/工具/方法的功能、参数、规格。

**常用技巧**：
- **参数列举**："支持 [N] 种格式，最大处理 [N] GB 文件"
- **功能分类**：按使用场景分类介绍功能
- **技术规格**：给出客观的技术参数
- **与前代对比**："相比上一代，新增了 [X] 功能"

**要求**：
- 准确、客观，不夸大
- 用用户能理解的语言，而非纯技术术语
- 聚焦最重要的 3-5 个特点

### A - Advantage（优势）| 占全文 30%

**⚠️ 这是 FAB 的核心，不可跳过。**

**目标**：解释这个特点为什么好——它比竞品/旧方案好在哪里。Advantage 是让 Benefit 可信的"解释桥梁"。

**常用技巧**：
- **对比竞品**："同价位唯一支持 [X] 的产品"
- **技术解释**："采用了 [技术]，所以能做到 [效果]"
- **差异化**："市面上大部分 [X] 只能 [Y]，但这个可以 [Z]"
- **量化优势**："速度提升 3 倍"、"体积减小 50%"

**要求**：
- 必须回答"怎么做到的？"这个问题
- Advantage 是 Feature 和 Benefit 之间的桥梁
- **禁止跳过 Advantage 直接从 Feature 到 Benefit**——没有 Advantage 的 Benefit 就是空头承诺

### B - Benefit（利益）| 占全文 40%

**目标**：翻译成用户关心的结果——省了多少钱/时间/精力。

**常用技巧**：
- **场景化收益**："这意味着你每天下班可以早 1 小时"
- **成本节省**："一年可以省下 [N] 元"
- **效率提升**："原来要 3 天的工作，现在 3 小时就搞定"
- **情感收益**："再也不用为 [X] 焦虑了"
- **对不同人群的不同收益**：学生、职场人、自由职业者各自的收益点

**要求**：
- 针对目标受众的具体收益
- 不同受众的 Benefit 可能不同——选择最匹配的
- Benefit 是篇幅最大的段落（40%）

## FAB 的核心原则

```
Feature → "这是什么？做了什么？"
Advantage → "怎么做到的？为什么好？"  ← 这是关键桥梁
Benefit → "对我有什么用？"

❌ 错误：Feature → Benefit（跳过 Advantage）
   "这款手机有 5000mAh 电池（Feature），所以你一天不用充电（Benefit）"
   → 读者会想："凭什么？别的手机也有大电池啊"

✅ 正确：Feature → Advantage → Benefit
   "这款手机有 5000mAh 电池（Feature），
    搭配自研的低功耗芯片，待机功耗降低了 40%（Advantage），
    所以即使重度使用也能撑一整天（Benefit）"
   → 读者会想："原来如此，确实合理"
```

## 段落骨架模板

### 单产品模板

```
[Feature - 产品特点]
[功能一：客观描述]
[功能二：客观描述]
[功能三：客观描述]

[Advantage - 核心优势]
[为什么功能一好：对比/技术解释]
[为什么功能二好：量化优势]
[为什么功能三好：差异化]

[Benefit - 用户收益]
[场景化收益展示]
[成本/效率/情感收益]
[不同人群的收益]
[总结推荐]
```

### 多产品/资源盘点模板

```
[资源/工具 1]
  F：[功能描述]
  A：[核心优势]
  B：[用户收益]

[资源/工具 2]
  F：[功能描述]
  A：[核心优势]
  B：[用户收益]

[资源/工具 3]
  F：[功能描述]
  A：[核心优势]
  B：[用户收益]

[总结对比表格]
[推荐建议]
```

## 注意事项

- FAB 最适合有"产品/工具/方法"可介绍的内容
- Advantage 是 FAB 的灵魂——写不好 Advantage，整篇文章就没有说服力
- 资源盘点类文章中，每个资源都应该走一遍 FAB 结构
- 与 4P 的区别：FAB 聚焦产品本身的"功能→优势→收益"链，4P 聚焦"营销场景→证明→行动"
