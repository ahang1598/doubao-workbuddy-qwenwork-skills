# ACCA 写作框架

## 全称

**A**wareness → **C**omprehension → **C**onviction → **A**ction
认知 → 理解 → 信念 → 行动

## 适用场景

- 知识科普、概念解释
- 需要教育用户的内容
- 新概念/新趋势介绍
- 百家号的知识型文章

## 默认适配文章类型

ACCA 不作为任何文章类型的默认框架，但适合以下场景手动选择：
- 需要先让读者"认识到问题存在"的科普内容
- 读者对话题完全陌生、需要从零建立认知的教育型文章

## 四段结构

### Awareness（制造认知）| 占全文 20%

**目标**：让读者意识到一个他们可能忽略的问题或机会。

**常用技巧**：
- **数据唤醒**："90% 的人不知道，他们每天浪费 3 小时在低效工作上"
- **反常识事实**："你以为的 [A] 其实是 [B]"
- **趋势提示**："2026 年，[X] 正在悄悄改变 [Y]"
- **问题暴露**："你有没有注意到，最近 [现象] 越来越严重了？"

**要求**：
- 让读者从"不知道"到"知道了"
- 信息要有冲击力（数据、反常识、趋势）
- 不需要深入解释，只需要"打开一扇门"

### Comprehension（帮助理解）| 占全文 30%

**目标**：用通俗语言解释问题的本质和影响，让读者真正理解。

**常用技巧**：
- **类比法**："这就好比你家的水管，表面看没问题，但里面已经…"
- **拆解法**：把复杂概念拆成 3 个简单部分
- **图表辅助**：用对比表格、流程图辅助理解
- **案例说明**：用一个具体案例把抽象概念讲清楚
- **FAQ 式**：预判读者的疑问并解答

**要求**：
- 从"知道"到"理解"——信息量最密集的段落
- 用人话，不用术语（或用完术语立刻解释）
- 类比要贴近读者的日常生活
- 这是全文最考验写作功力的段落

### Conviction（建立信念）| 占全文 30%

**目标**：用证据让读者相信你的解决方案有效，处理可能的反对意见。

**常用技巧**：
- **社会证明**："已经有 [N] 家企业/[N] 万用户采用了这个方案"
- **实验数据**："根据 [研究/测试]，使用后效果提升了 [N]%"
- **专家背书**："[行业专家] 也推荐这种方法"
- **反驳预设**："我知道有人会说 '[反对意见]'，但实际上…"
- **亲身验证**："我自己试了 3 个月，结果是…"

**要求**：
- 处理读者可能有的 1-2 个反对意见
- 证据要多维度（数据+案例+权威）
- 从"理解"到"相信"

### Action（促进行动）| 占全文 20%

**目标**：给出明确、具体的下一步行动，门槛要低。

**常用技巧**：
- **最小行动**："今天就可以试试：[一个5分钟能完成的行动]"
- **分级行动**："初级：[X]；进阶：[Y]；高级：[Z]"
- **资源提供**："我整理了一份 [X] 资源包，获取方式在评论区"
- **社交行动**："转发给你身边可能需要的朋友"

**要求**：
- 行动门槛要低，先让读者迈出第一步
- 一个清晰的核心 CTA
- 可以附带一个次要 CTA（如关注/收藏）

## 段落骨架模板

```
[Awareness - 唤醒认知]
[数据/反常识/趋势，打开一扇门]

[Comprehension - 深入理解]
[类比/拆解/案例]
[图表/对比（可选）]
[FAQ（可选）]

[Conviction - 建立信念]
[社会证明/数据/专家背书]
[处理反对意见]
[亲身验证]

[Action - 促进行动]
[最小行动步骤]
[资源提供（可选）]
[CTA]
```

## 注意事项

- ACCA 适合读者对话题完全陌生的场景（需要从零建立认知）
- 与 AIDA 的区别：AIDA 假设读者已经有初步认知（直接抓注意力），ACCA 假设读者还不知道问题存在（先唤醒认知）
- Comprehension 段是 ACCA 的核心——如果读者看完还是不理解，后面的 Conviction 和 Action 都没意义
- 适合百家号的知识科普类文章（SEO 导向的教育型内容）
