# AIDA 写作框架

## 全称

**A**ttention → **I**nterest → **D**esire → **A**ction
注意 → 兴趣 → 欲望 → 行动

## 适用场景

- 资讯快评、热点评论
- 高流量/爆款科普
- 广告文案、落地页
- 需要引导读者行动的内容

## 默认适配文章类型

| 文章类型 | 适配理由 |
|---------|---------|
| 资讯快评 | 快评需要在短篇幅内抓住注意力并引导行动 |
| 高流量/爆款科普 | 科普需要先用 hook 抓住注意力 |

## 四段结构

### A - Attention（抓注意力）| 占全文 10-15%

**目标**：在前 3 行内完成 hook，让读者停下来继续看。

**常用技巧**：
- **数据冲击**："90% 的人不知道，他们每天浪费 3 小时在低效工作上"
- **反常识结论**："你以为的努力，其实是最大的偷懒"
- **痛点提问**："为什么你学了那么多方法，效率还是上不去？"
- **悬念开场**："3 个月前，我还在为这件事焦虑到失眠…"
- **时事挂钩**："昨天 [热点事件]，背后藏着一个很多人忽略的问题…"

**要求**：
- 前 3 行必须完成 hook
- 禁止平淡开头（"大家好，今天来聊聊…"）
- 钩子必须与正文主题强相关

### I - Interest（引兴趣）| 占全文 25-30%

**目标**：连接到读者的具体场景，让他觉得"这跟我有关"。

**常用技巧**：
- 展开背景故事
- 代入感场景描写（"想象一下，周一早上你打开电脑…"）
- 展示问题的普遍性（"不只是你，[N]% 的人都有这个困扰"）
- 引用相关案例或研究

**要求**：
- 提供有价值的信息，展示专业性
- 从"注意"过渡到"与我相关"
- 不要急于给解决方案

### D - Desire（激欲望）| 占全文 35-40%

**目标**：从"理解"到"想要"，让读者渴望你的解决方案。

**常用技巧**：
- 展示解决方案的核心内容
- 社会证明（"已经有 [N] 人用这个方法…"）
- 用户证言和成功案例
- 数据支撑（"使用后效率提升 [N]%"）
- 对比展示（前后对比、有无对比）

**要求**：
- 具体的效果描述，而非抽象承诺
- 至少包含 1 个真实案例或数据
- 信息增量最密集的段落

### A - Action（促行动）| 占全文 10-15%

**目标**：给出一个清晰的行动指令，让读者"现在就做"。

**常用技巧**：
- 明确 CTA："现在就试试，第一步只需要 5 分钟"
- 制造紧迫感："这个方法窗口期很短，越早越好"
- 降低行动门槛："不需要任何基础，打开 [X] 就能开始"
- 社交行动："转发给你身边需要的朋友"

**要求**：
- 一个清晰的行动指令
- CTA 不超过 2 个（多了会分散注意力）
- 行动门槛要低

## 段落骨架模板

```
[Attention - 钩子]
[1-3 句数据冲击/反常识/痛点提问]

[Interest - 展开背景]
[场景代入 + 问题普遍性]
[相关案例/研究引用]

[Desire - 核心内容]
[解决方案展示]
[案例/数据/社会证明]
[效果对比]

[Action - 行动号召]
[明确 CTA + 降低门槛]
```

## 注意事项

- AIDA 适合中短篇（800-2500 字），不适合超长深度文
- Attention 段不宜过长，3 行以内完成 hook
- Desire 是篇幅最大的段落，信息密度要最高
- Action 要简洁有力，不要在最后又展开新话题
