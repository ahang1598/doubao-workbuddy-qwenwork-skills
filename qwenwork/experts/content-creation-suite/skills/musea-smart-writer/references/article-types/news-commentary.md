# 资讯快评

## 适用场景

针对热点新闻、行业动态、趋势变化，快速输出评论和观点。适合时效性强的内容，如热搜解读、行业政策分析、技术发布点评。

## 推荐平台与字数适配

| 平台 | 字数范围 | 适配要点 |
|------|---------|---------|
| 微博 | 140-800 字 | 极简版，强观点+话题标签 |
| 今日头条 | 800-1500 字 | 中等篇幅，信息密度高 |
| 微信公众号 | 1000-2000 字 | 深度版，观点+分析+预测 |

## 推荐写作框架

**AIDA**（Attention → Interest → Desire → Action）

快评需要在短篇幅内抓住注意力：用新闻事件本身抓注意力（A），展开背景引发兴趣（I），给出独到分析激发认同（D），引导互动讨论（A）。

## 写作角色定义

**Journalist**（资深评论员）
- 人设：有行业视野的观察者，能看到新闻背后的深层逻辑
- 语气：观点鲜明、分析犀利、不和稀泥
- 风格：结论先行、论据充分、快速有力

## 核心写作规范

- **篇幅**：800-2000 字（根据平台调整）
- **核心原则**：
  1. 时效性第一——热点 24 小时内必须发布
  2. 必须有独到观点——不做新闻搬运工
  3. 结论先行——前 3 行给出核心观点
  4. 观点必须有论据支撑（数据、案例、逻辑推导）
  5. 给出"So what?"——这件事对读者意味着什么
- **开头策略**：新闻事件+立场型
  - 模板："[事件一句话总结]。关于这件事，我的看法是：[核心观点]"
  - 示例："OpenAI 刚发布了 GPT-5。别急着兴奋，这次真正值得关注的不是性能，而是定价策略"
- **正文结构**：观点→背景→分析→预测→CTA
- **结尾动作**：预测/展望 + 互动讨论
- **语气要求**：直接、有态度、不拐弯
- **金句要求**：开头或结尾必须有一句可被引用的"评论金句"
- **SEO 要点**：标题含热点关键词+观点词

## 结构模板

```
[标题：热点关键词 + 核心观点]

[开头钩子：新闻事件 + 立场]
"[事件一句话总结]。
 关于这件事，我的看法是：[核心观点]。"

## 发生了什么？
[事件背景：3-5 句话交代清楚]
[关键数据/时间线]

## 为什么重要？
[深层分析：这件事背后的逻辑/趋势]
[对比分析：与历史事件/竞品/行业的对比]
[核心论据：数据/案例/专家观点]

## 对你有什么影响？
[So what：翻译成读者关心的具体影响]
[不同人群的影响差异（可选）]

## 我的预测
[对后续发展的判断]
[时间节点预测（如果有的话）]

[评论金句加粗]

[CTA：你怎么看？评论区聊聊]
```

## 自检清单

- [ ] 前 3 行给出了核心观点？
- [ ] 有独到分析（不是新闻搬运）？
- [ ] 观点有论据支撑？
- [ ] 分析了"对读者有什么影响"？
- [ ] 有评论金句？
- [ ] 结尾有互动引导？
- [ ] 时效性足够？
- [ ] 标题含热点关键词？
