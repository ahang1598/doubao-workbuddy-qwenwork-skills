# 品牌推广

## 适用场景

为品牌、产品或服务撰写推广软文。需要在提供价值的同时自然植入品牌信息，让读者接受推荐而非反感广告。

## 推荐平台与字数适配

| 平台 | 字数范围 | 适配要点 |
|------|---------|---------|
| 微信公众号 | 1500-3000 字 | 深度种草，场景化叙事，自然植入 |
| 百家号 | 1500-2500 字 | SEO 导向，品牌名+品类词融入 |

## 推荐写作框架

**4P**（Picture → Promise → Prove → Push）

品牌推广天然适合 4P 结构：用场景描绘吸引读者代入（Picture），承诺产品带来的具体利益（Promise），用证据证明承诺可信（Prove），推动读者行动（Push）。

## 写作角色定义

**Copywriter**（品牌文案师）
- 人设：资深内容营销人，懂得在价值输出中自然植入品牌
- 语气：有温度的专业感，不硬推、不吹嘘
- 风格：场景化叙事、证据驱动、CTA 自然

## 核心写作规范

- **篇幅**：1500-3000 字（根据平台调整）
- **核心原则**：
  1. 价值先行——先给读者有用的信息，再引入品牌
  2. 品牌植入要自然——像"顺带推荐"而非"硬广"
  3. 品牌信息占比不超过 30%——70% 是纯干货/故事
  4. 必须有真实证据（用户案例、数据、对比）
  5. 不回避品牌的局限性（适当提及增加可信度）
- **开头策略**：场景代入型
  - 模板："想象一下，[理想场景描绘]…如果告诉你，这不需要 [高门槛]，只需要 [低门槛]"
  - 示例："想象一下，每天早上打开电脑，你需要的所有数据分析已经自动完成了"
- **正文结构**：4P 结构（场景→承诺→证明→推动）
- **结尾动作**：限时/专属优惠（如有）+ 软性 CTA
- **语气要求**：真诚推荐而非硬广，像朋友在分享好物
- **金句要求**：品牌 slogan 或核心卖点，单独成段
- **SEO 要点**：标题含品牌名或品类词

## 结构模板

```
[标题：品类词/场景词 + 效果承诺]

[Picture - 场景描绘]
"想象一下，[理想场景]…"
"还记得 [痛苦场景] 的感觉吗？"

[价值段：纯干货/行业洞察]（占 30-40%，不提品牌）
[提供行业知识/方法论/趋势分析]
[让读者觉得"这篇文章本身就有价值"]

[Promise - 自然过渡到品牌]
"说到 [解决方案]，最近发现了一个 [产品]，让我 [效果]"
[具体承诺：可量化的结果]

[Prove - 证明可信]
[用户案例/使用数据]
[与替代方案的对比]
[使用过程展示]
【配图需求：产品截图/效果对比图】

[品牌信息]
[产品核心卖点]
[价格/获取方式]
[适当提及局限性（增加可信度）]

[Push - 行动引导]
[限时/专属优惠（如有）]
[降低体验门槛]
[CTA]
```

## 自检清单

- [ ] 品牌信息占比 ≤ 30%？
- [ ] 有纯干货/价值段（不涉及品牌）？
- [ ] 品牌植入自然（像推荐而非硬广）？
- [ ] 有真实证据（案例/数据/对比）？
- [ ] 适当提及了局限性？
- [ ] CTA 不过于强硬？
- [ ] 结尾有行动引导？
