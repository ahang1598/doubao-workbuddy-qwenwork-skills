# 排版公式详解

本文档包含小红书排版的所有规则和公式，供 Agent 按需读取。

## 硬性约束

| 约束项 | 规则 | 说明 |
|--------|------|------|
| 标题字数 | **≤ 20 字**（含 emoji，不含空格） | 超出必须精简，不得妥协 |
| 正文字数 | **≤ 1000 字**（含 emoji 和标点） | 超出必须删减，优先砍案例和过渡句 |
| 话题标签 | 5–10 个 | 格式：`#标签名` 空格分隔 |
| 段落长度 | 每段 ≤ 3 行 | 超过 3 行必须换段 |
| 分隔线 | 用 `———————————————————` | 每个大模块之间用一条 |

## 一、标题（≤ 20 字）

**结构公式**：`数字/痛点 + 核心价值 + 情绪钩子`

规则：
1. 必须包含至少 1 个 emoji（放在语义转折处或末尾，不要堆砌）
2. 优先使用数字开头（"3步"、"5个"、"10分钟"）
3. 使用竖线 `｜` 或中文逗号分隔信息层
4. 禁止使用引号包裹整个标题
5. 字数精确控制：写完后必须数一遍，超出就砍

**好标题示例**：
- `每天15分钟AI早会☕️选题效率翻3倍`（18字）
- `3步搭建知识体系📚越做越轻松`（14字）
- `停止无效努力💡这5个习惯改变我`（15字）

## 二、正文排版

### 2.1 开头钩子（前 3 行定生死）

必须在前 3 行内完成：**引发共鸣 → 制造冲突 → 给出承诺**

模板选一：
```
[痛点提问]❗
[具体场景描述]
[转折 + 方法预告]💪
```

模板选二：
```
[反常识结论]
[个人经历佐证]
[引出方法论]👇
```

### 2.2 正文结构

采用 **"总—分—总"** 架构：

```
开头钩子（3行）
———————————————————
核心概念解释（3-5行）
———————————————————
方法/步骤（每步3-4行，用序号标记）
———————————————————
效果/数据佐证（3-5行）
———————————————————
避坑提醒（2-4条）
———————————————————
互动引导（2-3行）
```

### 2.3 emoji 使用规范

| 位置 | 用法 | 示例 |
|------|------|------|
| 段落开头 | 标记内容类型 | 🧠 概念、📋 步骤、🔥 重点、💡 技巧 |
| 强调处 | 情绪放大 | ❗警示、✅ 正确、❌ 错误、👉 指向 |
| 结尾 | 互动引导 | 💾 收藏、👇 评论、🥰 情感 |
| 序号替代 | 步骤编号 | 𝟭｜ 𝟮｜ 𝟯｜ 或 ❶ ❷ ❸ |

**密度控制**：平均每 2-3 行出现 1 个 emoji，禁止连续 3 个以上 emoji 堆砌。

### 2.4 文字排版细节

1. **短句为王**：每句 ≤ 20 字，长句必须拆分
2. **换行即分段**：小红书没有段落缩进，靠换行制造呼吸感
3. **对比句式（强制）**：必须使用 `不是A❌ 而是B✅` 格式制造认知冲突，至少出现 1 次
   - 示例：`不是盲目日更❌ 而是精准选题✅`
   - 示例：`不是追求完美❌ 而是快速迭代✅`
4. **数据锚点**：用具体数字替代模糊描述（"提升了" → "提升了35%"）
5. **口语化表达**：用"姐妹们"、"说真的"、"划重点"等拉近距离
6. **禁止长段落**：超过 3 行的段落必须拆分或删减
7. **互动引导（强制）**：正文结尾必须包含互动引导模块，格式如下：
   ```
   💬 你在[相关场景]中遇到过什么问题？
   👇 评论区告诉我，我来帮你解答！
   💾 觉得有用就收藏起来，下次照着做～
   ```

## 三、话题标签（三层结构）

**必须严格按照以下三层结构生成 5-10 个标签：**

1. **前 3 个标签：高流量通用词**（固定使用以下高频词，不得替换为内容相关词）
   - 知识博主类内容：`#知识博主` `#自媒体运营` `#干货分享`
   - 穿搭类内容：`#穿搭` `#日常穿搭` `#穿搭技巧`
   - 通用高频词池：`#个人成长` `#学习打卡` `#经验分享`
   
2. **中间 2-4 个标签：内容相关精准词**（根据文章主题生成）
   - 示例：`#AI写作` `#ChatGPT` `#内容创作`
   
3. **最后 2-3 个标签：长尾情感词**（必须包含情感属性，不得使用功能性标签）
   - 示例：`#越努力越幸运` `#成为更好的自己` `#加油打工人`
   - 示例：`#治愈系` `#正能量` `#生活碎片`
   - ❌ 禁止使用：`#涨粉技巧` `#效率提升` `#新媒体运营`（这些是功能性标签，不是情感词）

4. **格式要求**：每个标签前加 `#`，标签之间用空格分隔
5. **禁止生造标签**：优先使用平台已有的热门标签

**正确示例**：
```
#知识博主 #自媒体运营 #干货分享 #AI写作 #内容创作 #小红书运营 #越努力越幸运 #成为更好的自己
```

**错误示例**（前3个不是高流量通用词）：
```
#AI写作 #自媒体运营 #ChatGPT ...  ← ❌ #AI写作 和 #ChatGPT 不是高流量通用词
```

**错误示例**（最后缺少情感词）：
```
... #涨粉技巧 #新媒体运营 #效率提升  ← ❌ 都是功能性标签，没有情感属性
```

## 四、封面大字建议

为配合封面图设计，输出 1 行封面大字文案：
- 字数：6-12 字
- 要求：一眼看懂核心价值，适合大字排版
- 示例：`AI早会｜选题翻3倍`、`知识体系搭建3步法`

## 五、配图建议

输出 3-6 张配图的内容建议：
- 封面图：封面大字 + 简洁背景（3:4 竖版）
- 内容图：方法步骤的可视化卡片
- 数据图：前后对比、效果展示
- 金句图：文中最有传播力的 1 句话
