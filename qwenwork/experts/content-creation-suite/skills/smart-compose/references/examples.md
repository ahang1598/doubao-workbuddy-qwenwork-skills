## 示例 2：穿搭技巧分享（经历型）

### 输入

```
我想分享一个穿搭技巧，就是如何用平价衣服搭出高级感。
我自己用了这个方法，效果很好。
核心就是：选对颜色、选对版型、选对配饰。
```

### 输出

#### 标题（16 字）
```
平价穿搭｜3 招搭出高级感💎
```

#### 封面大字（8 字）
```
平价穿搭｜高级感法则
```

#### 正文

```
买不起大牌？其实不是钱的问题。

我见过很多人花几千块穿得很廉价，也见过有人用百元衣服穿出气质。
差别在哪？就在于这 3 个细节。

———————————————————

不是衣服价格❌ 而是搭配逻辑✅

第一招：色彩统一

选 2-3 个主色调，全身衣服都围绕这几个颜色搭。
比如：黑 + 米色 + 卡其色
这样看起来就很高级，不会显得杂乱。

第二招：版型要修身

再便宜的衣服，只要版型贴身，就能显气质。
关键是腰线、肩线、裤长这三处要精准。

第三招：配饰点睛

一条好腰带、一个好包包，能瞬间提升整体质感。
不用全身大牌，只需 1-2 个精致配饰就够了。

———————————————————

🔥 实际案例：
我最近的一套穿搭，成本不到 300 块。
黑色 T + 卡其色裤 + 棕色腰带。
评论里有人以为我穿的是大牌，其实都是平价品牌。

———————————————————

💬 你最常踩的穿搭坑是什么？
👇 评论区告诉我，我来帮你避坑！
💾 觉得有用就收藏起来，下次购物时参考～
```

#### 话题标签（8 个）


#### 配图建议

1. **封面图**：大字"平价穿搭｜高级感法则" + 优雅背景
2. **色彩示意图**：黑 + 米色 + 卡其色的配色方案

```
———————————————————

不是追求完美❌ 而是快速迭代✅

后来我改变了思路：
与其花 3 个月做一个完美的视频，不如花 1 周做 3 个还不错的视频。

第一个视频可能不完美，但我能从评论里看到用户真实的反馈。
第二个视频就能根据反馈改进。
第三个视频就开始爆了。

———————————————————

我用这个方法，用了 2 个月从 0 涨到 10000 粉。
如果还在等完美的那一天，可能永远都发不了。

———————————————————

🧠 核心思路：
• 80 分的作品，今天就发
• 不要等 100 分的完美
• 在用户反馈中找到改进方向
```

## 使用说明

这 3 个示例分别代表小红书内容的三种常见类型：

1. **教程型**（示例 1）：分享工具、方法、技巧
2. **经历型**（示例 2）：分享个人经验、案例
3. **观点型**（示例 3）：分享思想、观念、启发

**如何使用这些示例**：

- **学习排版结构**：观察每个示例的正文如何用分隔线分段，如何安排钩子、主体、案例、互动引导
- **学习标签策略**：看前 3 个标签如何选择，中间标签和最后标签如何组织
- **学习配图思路**：理解每张配图的用途（封面、说明、数据、案例、金句）
- **参考 emoji 密度**：观察 emoji 的出现频率，学习何时加 emoji，何时不加

**生成新内容时**：

1. 先判断用户的内容属于哪种类型（教程 / 经历 / 观点）
2. 参考对应示例的结构和风格
3. 调整具体的内容和数据，但保持框架不变
