# Connectors — 连接器配置说明

内容创作专家使用**品类占位符**引用外部工具。实际使用时，对应品类连上任意一个工具即可获得对应增强能力；未连接时套件也能独立跑通。

## 品类总览

| 品类 | 连上后能做什么 | 支持的工具（示例） | 配置方式 |
|------|---------------|-------------------|----------|
| 平台数据采集 | 稳定获取抖音/小红书/B站/微博/公众号等平台的字幕、正文、热榜、评论；也是跨平台发布的通道 | **mcp-autocli**（推荐） | 参考 mcp-autocli 的官方配置文档，在应用的 Connector 设置里安装 |
| 会议纪要 / 素材导入 | 从钉钉听记批量拉取会议纪要进知识管家；打通日常听会与内容沉淀 | **钉钉听记**（钉钉 AI 能力中心） | 打开 [钉钉 AI 能力中心](https://aihub.dingtalk.com/#/mcp) → 找到「钉钉听记 MCP」→ 生成个人配置 → 粘贴到应用 |
| 文档平台 | 生成的稿件、脚本、拆解结果自动发布为文档，无需手动复制 | 钉钉文档 / 飞书文档 / Notion / 语雀 | 钉钉/飞书：去 MCP 配置页生成个人配置；Notion：应用内的 Connector 设置一键开启 |
| 任务工具 | 内容排期、发布跟进、跨平台任务自动创建为待办 | 钉钉待办 / Linear / Todoist / 飞书任务 | 钉钉/飞书：MCP 配置页生成；Linear/Todoist：应用内的 Connector 设置授权 |
| 云盘 / 素材库 | 生成的图片、视频、动画自动上传归档，便于团队复用 | 钉钉云盘 / 飞书云文档 / Google Drive | 应用 Connector 设置里授权对应云盘 |
| 沟通平台 | 发布完成、日报生成后自动推送到群 | 钉钉 / 飞书 / Slack / 企业微信 | 应用 Connector 设置里授权对应 IM |

## 各 Skill 的连接器依赖

| Skill | 强依赖 | 可选增强 |
|-------|-------|---------|
| 内容雷达 | **平台数据采集**（mcp-autocli） | 文档平台（把选题报告发布为文档） |
| 爆款拆解 | 无（走 curl / yt-dlp 兜底） | **平台数据采集**（更稳定）、云盘（原始素材归档） |
| 知识管家 | 无 | **钉钉听记**（批量导入会议）、云盘（长期素材备份） |
| 风格说明书 | 无 | 文档平台（风格说明书归档） |
| 写作专家 | 无 | 文档平台（成稿归档）、任务工具（发布排期） |
| 视频编导 | 无 | 云盘（分镜脚本、参考素材沉淀）、文档平台 |
| 口播脚本生成器 | 无 | 文档平台（脚本归档）、任务工具（拍摄计划） |
| 内容生图 | 无（走内置生图能力） | 云盘（成品图归档） |
| 智能排版 | 无 | 文档平台（多平台版本归档） |
| 跨平台发布 | **平台数据采集**（mcp-autocli publish） | 任务工具（发布跟进）、沟通平台（发布结果推送） |

## 推荐组合

**最小可用组合（不装任何连接器）**  
所有 11 个 Skill 均可独立运行，只是"拆解"和"发布"两个环节需要手动兜底（拆解走 curl/yt-dlp，发布走人工登录）。

**推荐组合（自媒体单人）**  
- **mcp-autocli**：拆解 + 发布的核心通道
- **钉钉听记**：日常会议 / 访谈素材直接进知识管家
- **文档平台任一**：稿件与知识库归档

**团队组合（品牌 / 市场部）**  
在推荐组合基础上追加：
- **任务工具**：内容排期、跨平台发布跟进
- **云盘**：图片、视频、动画素材集中归档
- **沟通平台**：发布结果 / 日报自动推群
