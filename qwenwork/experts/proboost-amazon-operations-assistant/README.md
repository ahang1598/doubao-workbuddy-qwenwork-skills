# 亚马逊运营助手

使用 OpenBoost 数据，把类目调研、机会选品、榜单验证、关键词研究、流量分析和 ASIN 诊断串成一套可复查的 Amazon 运营流程。

## 适合谁

- 亚马逊运营、选品和广告人员
- 需要研究市场、竞品、关键词或单个 ASIN 的团队
- 希望得到“数据证据 + 风险提示 + 下一步行动”的用户

## 包含的 Skill

1. Amazon类目市场分析
2. Amazon产品机会筛选
3. Amazon榜单机会发现
4. Amazon关键词研究
5. Amazon流量结构分析
6. Amazon ASIN综合诊断

## 工作方式

- 每日：检查重点 ASIN、关键词和流量变化，形成异常与待办。
- 每周：复盘类目、竞品、榜单和选品候选，调整优先级。
- 每月：重做市场结构与产品组合评估，更新机会池和风险清单。

专家先调用 `proboost-Amazon-mcp` 获取实时工具与数据。若连接器不可用，可改用用户提供的 CSV、XLSX、JSON、截图或平台导出文件做离线分析，并明确标注“用户提供数据 / 离线降级”；没有连接器也没有材料时，只给出所需输入模板，不编造结果。

## 重要说明

分析结论受站点、时间范围和样本覆盖影响。请在关键商品调整、预算变更或商业决策前，由用户确认范围和执行动作。
