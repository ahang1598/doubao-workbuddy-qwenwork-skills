# 时间线格式规范

## 概述

本文档定义了证据时间线的标准格式和结构，用于确保证据时间线文档的一致性和专业性。

## 文档结构

### 1. 标题层级

```markdown
# {案件名称} - 证据材料时间线          <- 一级标题

## 案件基本信息                        <- 二级标题

## 时间线事件                          <- 二级标题

### {时间分组}                         <- 三级标题（如：前期准备阶段）

#### {YYYY年MM月}                      <- 四级标题（按月份组织）
```

**禁止结构**：Markdown 时间线文档不得生成“关键争议点”“证据清单”“法律分析意见”或“诉讼策略”章节；如用户另行要求，应作为独立交付物处理。

### 2. 时间格式标准

| 精度 | 格式 | 示例 | 说明 |
|------|------|------|------|
| 完整日期 | YYYY年MM月DD日 | 2019年3月25日 | 推荐格式 |
| 仅月份 | YYYY年MM月 | 2019年3月 | 日期不详时使用 |
| 仅年份 | YYYY年 | 2019年 | 月份不详时使用 |
| 时间段 | YYYY年MM月DD日-YYYY年MM月DD日 | 2019年3月25日-2019年4月1日 | 持续事件 |
| 模糊时间 | 描述性时间 | 2019年初、2019年3月下旬 | 时间不精确时保留原描述 |
| 时间不详 | 时间不详 | 时间不详 | 完全无法确认时 |

**注意**：
- 所有日期使用阿拉伯数字，不使用汉字（如"2019年3月25日"而非"二零一九年三月二十五日"）
- 月份和日期不补零（如"3月"而非"03月"，"5日"而非"05日"）
- 在表格中使用 YYYY-MM-DD 格式便于排序

### 3. 表格格式

#### 案件基本信息表

```markdown
| 项目 | 内容 |
|------|------|
| 案件名称 | {案件名称} |
| 协议编号 | {协议编号} |
| 甲方 | {甲方名称} |
| 乙方 | {乙方名称} |
| 丙方 | {丙方名称}（如有） |
| 担保人 | {担保人名称}（如有） |
```

#### 时间线事件表

```markdown
| 时间 | 事件 | 核心摘要 | 证据 | 页码 | 备注 |
|------|------|----------|------|------|------|
| YYYY-MM-DD | {事件标题或简要描述} | {1-2句核心法律事实摘要} | {证据名称} | P{页码} | {备注} |
```

**格式说明**：
- **时间列**：使用 YYYY-MM-DD 格式，便于排序
- **事件列**：简要描述事件标题或核心行为，控制在 30 字以内
- **核心摘要列**：从材料中提炼 1-2 句法律事实摘要，说明主体、行为、金额、期限、法律意义或履行状态，不得编造
- **证据列**：证据名称，控制在 30 字以内
- **页码列**：使用 "P{页码}" 格式，如 "P1-10"、"P11"
- **备注列**：补充说明（如"截止日期"、"约定节点"、"时间存在矛盾待确认"等）

### 4. 事件分组建议

根据案件类型，建议使用以下分组：

#### 合同纠纷案件

1. **前期准备阶段**
   - 意向书、备忘录
   - 尽职调查
   - 股东会/董事会决议

2. **合同签署阶段**
   - 正式合同签署
   - 补充协议
   - 担保设定

3. **履约阶段**
   - 付款行为
   - 交付行为
   - 验收行为
   - 阶段性成果

4. **违约阶段**
   - 未履行行为
   - 延迟履行
   - 质量不合格
   - 其他违约行为

5. **催告与协商阶段**
   - 法务函
   - 律师函
   - 协商会议
   - 催告行为

6. **诉讼准备阶段**
   - 律师委托
   - 律师费支付
   - 保险费支付
   - 保全申请
   - 证据保全

#### 劳动争议案件

1. **入职阶段**
2. **劳动合同阶段**
3. **工资发放阶段**
4. **社保缴纳阶段**
5. **解除劳动关系阶段**
6. **劳动仲裁阶段**

### 5. 关键节点标注

以下时间节点应特别标注（使用 **加粗** 或 `> 引用` 格式）：

- **合同生效日**
- **重要付款截止日**
- **交付截止日**
- **违约发生日**
- **催告日**
- **诉讼时效节点**
- **合同期限届满日**
- **解除通知日**

**示例**：

```markdown
> **关键节点**：2019年8月15日前应取得预售许可证，实际未取得，构成违约。
```

### 6. 金额格式

- 使用阿拉伯数字 + 单位
- 单位：万、亿
- 示例：3000万、450万、10万、1.5亿
- 在表格中可使用 **关键金额**：3000万 格式加粗标注

### 7. 页码格式

- 单页：P{页码}，如 "P11"
- 多页：P{起始页}-{结束页}，如 "P1-10"
- 不连续页：P{页码1}、P{页码2}，如 "P5、P8"
- 若页码不详：标注"待确认"

### 8. Markdown 排版规范

- 标题与正文之间空一行
- 表格前后各空一行
- 列表项之间不空行（紧凑列表）
- 不同分组之间使用分隔线 `---`
- 引用使用 `>` 符号
- 关键信息使用 `**加粗**`
- 文档主体以时间线事件为主，不追加争议点归纳或证据清单

## 注意事项

1. **时间准确性**：所有时间必须基于证据材料，不得编造或推测
2. **完整性**：材料中所有包含时间信息的事件都应列入
3. **逻辑性**：事件严格按时间顺序排列
4. **清晰性**：表格对齐清晰，便于阅读
5. **专业性**：使用规范的法言法语
6. **可追溯性**：每个事件都应标注证据来源和页码
