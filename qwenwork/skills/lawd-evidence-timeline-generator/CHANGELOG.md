# Changelog

## v1.1.0 (2026-08-11)

依据 QwenWork 真机测试轮（合同时间线场景，普通/高级模型两次执行）整改 6 项：

1. **相对时间零推算**（阶段一）：原规则"相对时间需换算具体日期"诱导推算编造绝对日期 → 改为仅当触发日期已确认时才换算，未确认一律保留原文相对表述并备注"待实际发生后确定"
2. **条件触发型事件专项规则**（阶段二）：无确定时间的条件触发型事件不参与时间排序，归入「约定期限与条件」分组并标注"按类型排列，非时间排序"，化解与严格排序约束的张力
3. **--mode timeline 显式化**（阶段四 + 脚本）：SKILL 示例命令显式加 `--mode timeline`；`generate_timeline_print.py` 默认模式由 mindmap 改为 timeline（docstring 与函数默认值同步）
4. **着色关键词表对齐脚本**：SKILL 关键词表与脚本 TYPE_RULES 逐项对齐，补充"未匹配时使用默认灰色"兜底说明
5. **页码条款编号替代**：材料无物理页码时用条款编号（如"协议书§3.1"）替代，不得留空或写"P-"（阶段一提取表 + JSON page 字段两处）
6. **month 格式与矛盾分工**：month 字段强制"YYYY年MM月"标准格式，括号说明移入 note；矛盾事件 summary 写法律事实、矛盾说明写 note
