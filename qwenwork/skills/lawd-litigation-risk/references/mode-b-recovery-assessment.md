### 模式B ｜ 债务清偿能力评估

> **外移说明**：本文件为 Mode B（债务清偿能力评估）完整工作流细则，自 `SKILL.md` 三、模式工作流 原样移出。数据源（企业工商信息查询）的探测/匹配/调用/降级规则见 `SKILL.md` §四，交付门禁脚本见 §五，交付物要求见 §六；§B0 所引「同 §A0」的实体锚定流程位于 `mode-a-litigation-risk.md`。

诉前财产保全决策的核心评估工具。对被告方执行"财务底盘 + 可执行资产 + 债务压力 + 历史偿债模式 + 实控人兜底"五维度穿透，输出追偿评级、清偿率区间与保全标的清单。

#### B · 6 大执行原则（强制）

1. **财务底盘先行**：有财务数据时以速动比率/资产负债率/货币资金为第一判据，司法事件为辅助验证
2. **资产必须可执行**：输出的每项资产必须是律师可据以申请保全的具体标的，不得笼统写"有XX亿资产"
3. **历史与当前并列**：连年失信型 vs 短期偶发纠纷的追偿期望值差异巨大，必须区分
4. **实控人独立评估**：企业壳化时追偿最后一条路是刺破面纱，须独立评估实控人
5. **保全金额≠债权金额**：可执行资产不足时，保全金额以可执行资产上限的 80-90% 为限
6. **追偿率须落数字**：必须给出 0-100% 的回收率**区间**，附推演依据

#### §B0：实体锚定 + 参数确认

**企业锚定**：同 §A0（USCC 正则 / 完整企业名 / 简称消歧）。

#### §B2：维度一 — 企业财务底盘

**所需能力与语义关键词**

| 数据 | 语义关键词 | 必需返回字段 |
|------|------|------|
| 工商登记 | 工商、登记、registration、company_info | 法代、注册资本/实缴、成立日期、登记状态、地址 |
| 财务数据 | 财务、财报、资产负债、financial | 总资产/总负债、流动资产/流动负债、货币资金、应收账款、有息负债（能给几项就给几项） |
| 股东信息 | 股东、shareholder、partner | 股东名称、认缴/实缴、持股比例 |
| 实际控制人 | 实控人、actual_controller、受益所有人、UBO | 姓名、控制路径、持股比例 |
| 注销备案 | 注销、清算、cancellation | 注销日期、清算组信息 |
| 破产重整 | 破产、重整、bankruptcy | 受理法院、受理日期、程序阶段 |

**分析要点**

**必读** [financial-indicators.md](financial-indicators.md)

财务数据可得时，提取：
- 速动比率、资产负债率、流动比率
- 货币资金余额、应收账款规模
- 有息负债 / EBITDA

财务数据**不可得**时（非上市/小微，或已匹配连接器不提供财务能力）：
- 明示"无直接财务数据，偿债能力估算基于事件信号间接推断，置信度降低"
- 综合评级下调 1 级保守处理

**企业状态关键拐点**

| 状态 | 影响 |
|------|------|
| 注销 | 追偿路径切换为"刺破面纱+追缴未缴出资" |
| 破产受理 | 须在债权申报期内申报，过期丧失受偿权 |
| 吊销/经营异常 | 预判是否进入注销流程 |

#### §B6：维度五 — 实控人兜底

**前置条件**：从 §B2 获取法代 + 实控人姓名。

**所需能力与语义关键词**

| 数据 | 语义关键词 |
|------|------|
| 个人控制企业 | 控制企业、controlled_companies |
| 个人投资 | 个人投资、personnel_investments |
| 个人股权出质 | 个人股权出质、personnel_equity_pledge |
| 个人被执行 | 个人被执行、personnel_judgment_debtor |
| 个人失信 | 个人失信、personnel_dishonest |
| 个人限高 | 个人限高、personnel_high_consumption |
| 个人限出境 | 限制出境、exit_restriction |
| 个人股权冻结 | 个人股权冻结、personnel_equity_freeze |

**分析要点**

判断三种典型情境：
- **A · 企业存续、实控人清洁** → 追偿针对企业本体
- **B · 企业壳化、实控人殷实** → 核心路径为刺破面纱
- **C · 企业存续、实控人已跑路** → 窗口期极短，立即保全

并评估刺破面纱可行性（未缴出资 / 人格混同 / 抽逃出资）。

无人员维度能力或人员能力不完整时 → 维度跳过，标注"实控人兜底未核验"，综合评级按保守口径处理。

#### §B7：补充检索

| 触发条件 | 搜索策略 | 最大次数 |
|---------|---------|---------|
| **必做** | `"{企业全称}" site:creditchina.gov.cn` | 1 |

- 所有结果标注 `[WEB-*]` 与「未核验」；补充检索所得财务概览只能作定性辅助信号，不得用于比率类定量结论；**不得**顶替工商连接器数据（见 §四）

#### §B8：综合评级与输出

**报告模板**

**必读** [recovery-output-report.md](recovery-output-report.md)：含完整 9 章报告模板与填写规则。

**S/A/B/C/D 追偿评级**

**必读** [rating-rules.md](rating-rules.md)（五维度 1-5 分打分、综合分映射、一票否决规则）

| 等级 | 预期回收率 | 含义 |
|------|-----------|------|
| **S 级** | 60-85% | 强烈追偿 |
| **A 级** | 40-65% | 积极追偿 |
| **B 级** | 20-40% | 有限追偿 |
| **C 级** | 10-25% | 困难追偿 |
| **D 级** | < 10% | 不建议追偿 |

**清偿率表述规则（门禁项）**：预期回收率/清偿率**必须是区间**（如"25%-45%"），不得只给单一精确数值；区间须附推演依据（可执行资产净值、第一层优先债务、等同顺位债权总和、原告占比）。

**保全标的清单**：对 S/A/B 级案件输出建议保全标的清单（按优先级排序），并提示保全担保金预算（保全金额的 10-30%）。

**T+N 行动时间线**

**必读** [action-timeline.md](action-timeline.md)：按 T+0 / T+3 / T+7 / T+14 / T+30 给出与评级匹配的行动建议，含条件性行动触发表。
