# 4+2 深度蒸馏模型详解

## 基础层

### M1: 结构化元数据

从论文中提取以下结构化信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 标题 | 论文完整标题 | Attention Is All You Need |
| 作者 | 全部作者列表 | Vaswani, Shazeer, Parmar 等 |
| 机构 | 作者所属机构 | Google Brain, U Toronto |
| 来源 | 期刊/会议名称 | NeurIPS 2017 |
| 年份 | 发表年份 | 2017 |
| DOI | 数字对象标识符 | 10.1000/xyz |
| 学科分类 | 自动分类标签 | #NLP #深度学习 #注意力机制 |
| 研究方法 | 方法类型 | #实证 #实验研究 |
| 核心变量 | 研究中的关键变量 | 注意力头数、层数、维度 |

### M2: 逻辑骨架还原

还原作者的论证链条：

```
问题陈述 → 理论基础 → 方法设计 → 实验验证 → 结论
```

每个环节需要：
- **问题陈述**：研究动机是什么？现有方法的不足？
- **理论基础**：基于什么已有理论？
- **方法设计**：核心创新点是什么？为什么这样设计？
- **实验验证**：用了什么数据集？对比了哪些基线？
- **结论**：最终结论是否支持初始假设？

### M3: 引用文献网络

整理三个维度的引用信息：

1. **参考文献**：本文引用了哪些重要文献（Top 10）
2. **引证文献**：本文被哪些重要文献引用
3. **共引关系**：与哪些文献经常被共同引用

## 洞察层

### M4: 批判性思考

从以下角度分析：

- **研究缺口 (Gaps)**：论文未解决但暗示了的问题
- **局限性深挖**：方法/数据/实验设计中的不足
- **跨界联想**：与其他领域方法的潜在联系
- **后续方向**：基于本文的合理后续研究方向

### M5: 知识图谱关联

- **前置知识锚点**：理解本文需要的前置知识
- **后续延伸方向**：本文启发了哪些后续工作
- **同类文献对比**：与同领域其他方法的对比
