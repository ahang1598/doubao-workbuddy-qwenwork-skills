# 更新日志 (Changelog)

## v5.0 - 在线链接支持与用户目的确认 (2026-05-08)

### 🎯 重大变更

**定位升级**：从"本地论文文件速览"扩展为"论文文献速览与蒸馏助手"，支持在线链接和用户目的确认

### ✨ 新增功能

#### 1. 在线链接支持
- ✅ 支持 arXiv、bioRxiv、medRxiv、PubMed Central 等开源平台链接
- ✅ 自动判断开源/非开源网站
- ✅ 非开源网站降级方案：全网搜索公开信息生成快速阅读报告

#### 2. 用户目的确认
- 新增"深度蒸馏/快速阅读/简单了解"三档模式选择
- 处理前必须询问用户分析目的
- 默认建议"快速阅读"模式

#### 3. 非开源链接处理
- 检测到非开源链接时询问用户是否接受降级方案
- 降级方案使用 WebSearch 全网搜索论文信息
- 在生成的文档中明确标注数据来源限制

### 📝 文档更新

#### SKILL.md 更新
- 新增在线链接处理流程（步骤 2B）
- 新增用户目的确认步骤（步骤 0）
- 新增非开源链接降级方案
- 更新触发条件，包含在线链接场景

## v3.0 - 本地论文文件速览版 (2026-05-07)

### 🎯 重大变更

**定位调整**：从"文献深度蒸馏助手"转型为"本地论文文件速览助手"

### ✨ 新增功能

#### 1. 纯本地 PDF 支持
- ✅ 仅支持用户上传的本地 PDF 文件
- ✅ 完全离线处理，不依赖任何在线服务
- ✅ 更快的响应速度和更好的隐私保护

#### 2. 双模式处理
- **快捷模式** (`--quick`)：仅生成 M1+M2 核心摘要，30 秒内完成
- **完整模式**：深度分析 M1-M5 全部模块，提供全面洞察

#### 3. 增强的批量处理
- 自定义输入输出路径 (`--input`, `--output`)
- 单文件快速处理 (`--single`)
- 改进的进度显示和错误处理
- 自动生成带时间戳的报告文件名

#### 4. 优化的输出结构
- 新的输出目录名：`distilled_papers/`（更直观）
- 汇总报告包含处理时长、平均耗时等统计信息
- 文献清单包含文件大小和状态标记

### ❌ 移除功能

- ❌ 知网 URL 支持
- ❌ arXiv/PubMed 等在线数据库链接处理
- ❌ 远程文件下载功能
- ❌ 钉钉文档自动同步（改为可选）

## 迁移指南 (v2.0 → v3.0)

### 对于现有用户

如果你之前使用的是 v2.0 版本：

1. **输入目录保持不变**
   ```bash
   # 继续使用 input_pdfs/ 目录
   cp your_papers/*.pdf input_pdfs/
   ```

2. **输出目录名称变更**
   ```bash
   # v2.0: output_distilled/
   # v3.0: distilled_papers/
   ```

3. **新增快捷模式**
   ```bash
   # 快速筛选文献时使用
   bash scripts/distill_batch.sh --quick
   ```

4. **不再支持的功能**
   - 知网 URL 直接处理 → 需先下载为 PDF
   - arXiv 链接处理 → 需先下载为 PDF

### 对于新用户

直接使用最新版本即可，无需考虑迁移问题。
