# 合同管辖约定审查规则

合同管辖条款审查的系统化指南，确保争议解决条款的合法有效性。

---

## 一、审查流程概述

管辖约定审查分为三个步骤：

1. **第一步**：识别合同是否约定了管辖机构
2. **第二步**：根据约定情况进行针对性询问和审查
3. **第三步**：深度审查管辖约定的有效性和合理性

---

## 二、第一步：识别管辖约定

### 审查要点

- [ ] 合同中是否存在争议解决条款
- [ ] 是否明确约定了管辖机构/仲裁机构
- [ ] 约定方式：仲裁、诉讼、还是未约定

### 识别结果分类

| 约定情况 | 说明 | 后续处理 |
|---------|------|---------|
| 未约定管辖 | 合同中无争议解决条款或未约定具体管辖机构 | 进入第二步-A |
| 约定法院管辖 | 明确约定由人民法院管辖 | 进入第二步-B |
| 约定仲裁管辖 | 明确约定由仲裁机构管辖 | 进入第二步-C |

---

## 三、第二步：针对性询问和初步审查

> **⚡ 短路规则（优先于下方 A/B/C 的询问）：** 本技能默认是**自动化合同审查**，不是交互式改约谈判。进入 A/B/C 的"是否需要更改管辖方式"询问前，**先做有效性判定**：
>
> - 若合同**已约定**管辖，且该约定**合法有效**（法院管辖：符合专属管辖规则，或落在《民诉法》第35条五个连接点内且唯一、明确、名称规范；仲裁管辖：机构唯一、名称准确、事项明确、无仲裁与诉讼并列），则**直接判定为"管辖条款合规、无需修改"**，在审查结论中一句话记录即可，**不得**再抛出"是否需要改为仲裁/法院"之类的开放式选择题打断用户。
> - 仅当出现以下情形才需要进一步询问或提示：① 未约定管辖；② 约定**无效或存疑**（命中 J101–J110 任一）；③ 约定虽有效但**明显不利于我方**且市场地位允许争取（此时以"建议"形式给出，而非强制选择题）。
> - 用户在阶段一提出的 `special_concerns` 若明确要求"评估/优化管辖条款"，则不受本短路规则限制，按 A/B/C 完整执行。

### A. 未约定管辖机构的处理

**风险提示**：
> 未约定管辖机构，可能导致争议发生时管辖不明确，影响维权效率和成本。

**询问用户**：
1. 是否需要增加管辖或争议解决约定？
2. 倾向于选择以下哪种方式？
   - 选项A：仲裁机构管辖（高效、专业、一裁终局）
   - 选项B：人民法院管辖（公信力强、可上诉）
   - 选项C：暂不约定（适用法定管辖规则）

**根据用户选择**：
- 选择A → 进入第三步-A（仲裁机构审查）
- 选择B → 进入第三步-B（法院管辖审查）
- 选择C → 提示法定管辖规则的不确定性

---

### B. 已约定法院管辖的处理

**询问用户**：
1. 当前合同约定由人民法院管辖，是否需要更改为仲裁机构管辖？
   - 选项A：保持法院管辖 → 进入第三步-B（法院管辖审查）
   - 选项B：更改为仲裁管辖 → 询问具体仲裁委员会名称，进入第三步-A

**仲裁优势提示**（如用户考虑更改）：
- 一裁终局，程序高效
- 专业仲裁员，熟悉商事争议
- 保密性强
- 可选择仲裁地点

---

### C. 已约定仲裁管辖的处理

**询问用户**：
1. 当前合同约定由仲裁机构管辖，是否需要更改为人民法院管辖？
   - 选项A：保持仲裁管辖 → 进入第三步-A（仲裁管辖审查）
   - 选项B：更改为法院管辖 → 进入第三步-B（法院管辖审查）

**法院诉讼优势提示**（如用户考虑更改）：
- 公信力强，国家强制力保障
- 可上诉，两审终审
- 管辖规则明确
- 执行便利

---

## 四、第三步：深度审查管辖约定

### A. 仲裁机构管辖审查

#### 1. 明确具体仲裁机构

**询问用户**（如未明确）：
- 请明确具体的仲裁委员会名称

**注意事项**：
- ⚠️ 必须使用仲裁机构的完整、准确名称
- ⚠️ 严禁编造、改编、缩写仲裁机构名称
- ⚠️ 避免使用"合同签订地仲裁委员会"等不明确表述

#### 2. 常见仲裁机构名称

| 仲裁机构类型 | 规范名称示例 |
|------------|------------|
| 全国性机构 | 中国国际经济贸易仲裁委员会<br>中国海事仲裁委员会 |
| 地方机构 | 北京仲裁委员会<br>上海仲裁委员会<br>深圳国际仲裁院 |

#### 3. 仲裁条款有效性审查

**必备要素检查**：
- [ ] 仲裁机构名称明确、准确、完整
- [ ] 仲裁事项明确（合同争议）
- [ ] 仲裁意思表示明确

**常见无效情形**（必须修改）：

| 无效情形 | 风险描述 | 法律依据 | 修改建议 |
|---------|---------|---------|---------|
| J101 | 仲裁机构不存在或名称错误 | 仲裁法 | 更正为准确的仲裁机构全称 |
| J102 | 约定多个仲裁机构 | 仲裁法 | 明确约定唯一仲裁机构 |
| J103 | 仲裁与诉讼并列约定 | 仲裁法 | 删除其中一种，保持争议解决方式唯一 |
| J104 | 仲裁事项不明确 | 仲裁法 | 明确仲裁事项为"因本合同引起的或与本合同有关的一切争议" |
| J105 | 约定不属管辖事项仲裁 | 民诉法 | 不属管辖事项不得约定仲裁，应改为法院管辖 |

#### 4. 标准仲裁条款模板

**推荐条款**：
```
因本合同引起的或与本合同有关的任何争议，均应提交〔仲裁机构全称〕，按照申请仲裁时该会现行有效的仲裁规则进行仲裁。仲裁裁决是终局的，对双方均有约束力。
```

**可选补充内容**：
- 仲裁地点：〔城市名称〕
- 仲裁语言：中文
- 仲裁员人数：三名/一名
- 仲裁费用承担：按仲裁规则确定/由败诉方承担

---

### B. 人民法院管辖审查

#### 1. 明确合同类型

**首先确认合同类型**（影响管辖规则）：

- 不动产纠纷相关合同（不动产买卖、租赁、毗邻等）
- 建设工程合同
- 运输合同（海事、航空、铁路）
- 知识产权侵权合同
- 其他合同类型

#### 2. 调用法规检索

**调用技能**：`lawding-regulation-retrieval`

**检索内容**：
- 搜索关键词："〔合同类型〕+ 管辖"、"专属管辖"、"协议管辖"
- 重点法条：
  - 《民事诉讼法》第34条（专属管辖）
  - 《民事诉讼法》第35条（协议管辖）
  - 相关司法解释

#### 3. 专属管辖情形判断

**专属管辖类型**（根据《民事诉讼法》第34条）：

| 条件类型 | 管辖法院 | 是否可协议约定 |
|---------|---------|--------------|
| 不动产纠纷 | 不动产所在地人民法院 | ✗ 不可约定其他法院 |
| 港口作业纠纷 | 港口所在地人民法院 | ✗ 不可约定其他法院 |
| 继承纠纷 | 被继承人死亡时住所地或主要遗产所在地人民法院 | ✗ 不可约定其他法院 |

**专属管辖审查流程**：

1. **判断是否属于专属管辖情形**
   - 是 → 检查约定是否与专属管辖规则一致
   - 否 → 进入协议管辖审查

2. **专属管辖一致性检查**
   - 约定法院与专属管辖法院一致 → 约定有效，无需修改
   - 约定法院与专属管辖法院不一致 → 约定无效，必须修改

3. **修改建议**（如不一致）
   ```
   【风险等级】：致命风险
   【问题描述】：当前约定〔约定的法院〕管辖，但根据《民事诉讼法》第34条规定，〔合同类型〕纠纷属于专属管辖，应由〔专属管辖法院〕管辖。
   【法律依据】：《民事诉讼法》第34条第X款
   【修改建议】：删除现有管辖约定，或修改为："因本合同引起的纠纷，由〔专属管辖法院〕管辖。"
   ```

#### 4. 协议管辖审查（非专属管辖情形）

**协议管辖的法定范围**（《民事诉讼法》第35条）：

可约定管辖的法院（五选一）：
- ✓ 被告住所地人民法院
- ✓ 合同履行地人民法院
- ✓ 合同签订地人民法院
- ✓ 原告住所地人民法院
- ✓ 标的物所在地人民法院

**协议管辖有效性检查**：

| 风险点 | 风险描述 | 法律依据 | 修改建议 |
|-------|---------|---------|---------|
| J106 | 约定的法院不在法定范围内 | 民诉法第35条 | 修改为五个连接点之一的法院 |
| J107 | 约定多个法院管辖 | 民诉法第35条 | 明确约定唯一法院 |
| J108 | 违反级别管辖规定 | 民诉法第18-21条 | 根据标的额约定相应级别法院 |
| J109 | 管辖法院约定不明确 | 民诉法第35条 | 明确具体法院名称 |
| J110 | 违反专属管辖规定 | 民诉法第34条 | 删除或修改为专属管辖法院 |

#### 5. 根据市场地位提供管辖建议

**强势方策略**（用户为强势一方）：

```
建议约定：由〔用户方住所地〕人民法院管辖

优势分析：
- ✓ 诉讼便利，降低维权成本
- ✓ 本地法院，人脉资源优势
- ✓ 对方起诉需到我方所在地，增加对方维权成本
- ✓ 提高合同威慑力

参考条款：
"因本合同引起的或与本合同有关的任何争议，由〔用户方住所地/合同履行地〕人民法院管辖。"
```

**平等地位策略**（合同地位相对平等或体现公平）：

```
建议约定：由原告住所地人民法院管辖

优势分析：
- ✓ 体现公平原则，双方地位平等
- ✓ 符合"原告就被告"的一般原则
- ✓ 降低争议解决阻力，维护合同履行
- ✓ 便于双方维权

参考条款：
"因本合同引起的或与本合同有关的任何争议，由原告住所地人民法院管辖。"
```

**弱势方策略**（用户为弱势一方）：

```
建议约定：由被告住所地人民法院管辖（法定一般原则）

或根据实际情况约定：
- 合同履行地（如对我方有利）
- 标的物所在地（如标的物在我方控制下）

条款示例：
"因本合同引起的或与本合同有关的任何争议，由被告住所地/合同履行地人民法院管辖。"
```

#### 6. 标准管辖条款模板

**基础模板**：
```
因本合同引起的或与本合同有关的任何争议，由〔具体法院名称〕人民法院管辖。
```

**精确到法院级别的模板**：
```
因本合同引起的或与本合同有关的任何争议，由〔被告住所地/原告住所地/合同履行地/合同签订地/标的物所在地〕有管辖权的人民法院管辖。
```

**注意事项**：
- ⚠️ 不得编造、改编、缩写法院名称
- ⚠️ 使用规范的法院全称，如"北京市朝阳区人民法院"
- ⚠️ 或使用连接点表述，如"被告住所地人民法院"
- ⚠️ 避免使用"就近法院"、"双方协商确定的法院"等不明确表述

## 五、管辖约定审查清单

### 仲裁条款检查清单

- [ ] 仲裁机构名称是否准确、完整
- [ ] 仲裁机构是否真实存在
- [ ] 是否只约定了唯一仲裁机构
- [ ] 仲裁事项是否明确
- [ ] 是否避免仲裁与诉讼并列约定
- [ ] 争议事项是否属于可仲裁范围（非专属管辖）
- [ ] 仲裁规则是否明确

### 法院管辖条款检查清单

- [ ] 合同类型是否明确
- [ ] 是否属于专属管辖情形
- [ ] （专属管辖）约定是否与专属管辖规则一致
- [ ] （协议管辖）约定的法院是否在法定五个连接点范围内
- [ ] 管辖法院是否明确、唯一
- [ ] 法院名称是否准确、规范
- [ ] 是否违反级别管辖规定
- [ ] 管辖约定是否符合用户市场地位和策略需求
