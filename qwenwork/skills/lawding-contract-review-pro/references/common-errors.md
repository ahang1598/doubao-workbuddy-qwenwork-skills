# 常见错误预防清单

> **用途：** 本文件列出了模型在执行合同审核技能时的高频错误，用于主动预防和规避。
> **使用方式：** 阶段三加载，阶段四审查时对照检查。

---

## 一、关键字提取错误

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 凭记忆复述 | 把"逾期付款的"写成"逾期付款" | 逐字复制原文，包括"的"、"了"等虚词 | 必须回到原文定位后复制 |
| 概括改写 | 把"每日按未付金额的0.5%"写成"日0.5%" | 保持原文表述，不做任何修改 | 对照原文逐字验证 |
| 跨段落复制 | old_text 包含多个段落的内容 | 每条 old_text 只包含单个段落 | 检查是否包含换行符 |
| 使用模糊定位 | keyword 为"付款条款"等泛指 | 使用条款编号 + 具体文字（如"9.1由乙方原因"） | 优先使用条款编号 |
| 遗漏条款编号 | keyword 仅复制内容，未包含条款编号 | 复制"第X条"+ 内容前几个字 | 条款编号是最可靠的定位符 |

**预防口诀：短、准、单**
- **短**：10-20字连续片段
- **准**：逐字复制原文
- **单**：单个段落，不含换行

### 二进制文件处理错误（模式 A 相关）

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 读取 docx 当文本 | 用 Read/cat 打开 `.docx`，把乱码填入 `old_text` | 只通过 `mode_a_annotator.py` 处理二进制 ZIP；JSON 里只放原文短片段 | 禁止 Read 用户合同 docx |
| 误用 docx skill 做模式 A | 用 docx skill 重建「批注版」导致正文变成 ZIP 乱码 | 模式 A 必须命令行调用 `mode_a_annotator.py` | 见 stage-5-output 工具分工 |

### PDF/扫描件提取错误（模式 B 相关）

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 关键字凭错序文本复制 | 多栏排版 PDF 提取后条款顺序错乱，仍照抄"提取文本"填 keyword | 以视觉上的原文条款为准，逐条人工核对定位；错序段落不可直接作为定位锚点 | 提取后先比对页面结构，标注"顺序可能错位" |
| 无提取方案硬闯 | Read 读 PDF 报 poppler 缺失即中断 | 按 stage-1 的正文提取优先级依次尝试（合合解析 / pymupdf / pdftotext / OCR） | 见 stage-1「合同正文提取」 |

## 二、风险等级误判

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 等级虚高 | 把"表述不规范"判为"致命风险" | 严格按风险模板的等级定义判定 | 对照风险模板判定表 |
| 等级虚低 | 把"违反强制性规定"判为"一般风险" | 违反法律强制性规定应为致命风险 | 检查是否涉及法律强制性规定 |
| 忽略市场地位 | 弱势方接受不利条款仍判为"一般风险" | 弱势方不利条款应提升风险等级 | 结合市场地位调整 |
| 忽略主体风险 | 相对方高风险但条款风险等级未调整 | 高风险主体的履约保障条款应提升等级 | 检查阶段1b产物 |

**风险等级判定速查表：**

| 风险等级 | 核心特征 | 典型情形 |
|---------|---------|---------|
| 致命风险 | 可能导致合同无效或无法履行 | 违反强制性规定、标的违法、主体不存在 |
| 重要风险 | 可能导致重大损失或争议 | 条款缺失、权利义务失衡、违约责任不明 |
| 一般风险 | 可能导致履行不便或小额损失 | 表述不规范、日期格式问题、金额格式问题 |
| 轻微瑕疵 | 不影响合同效力，仅形式问题 | 错别字、标点符号、格式不统一 |

## 三、批注格式错误

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 批注过长 | 一条批注超过 5 句话 | 控制在 1-3 句话，只说问题和建议 | 使用批注模板 |
| 批注过短 | 仅写"有问题"或"建议修改" | 说明问题是什么、依据什么、建议怎么改 | 使用批注模板 |
| 缺少法律依据 | 批注未引用法律条文 | 每条批注应引用相关法律依据 | 使用批注模板 |
| 措辞不规范 | 使用口语化表述（"给钱"、"送货"） | 使用法律术语（"支付价款"、"交付标的物"） | 对照语言规范 |

**批注标准格式：**

```
【风险等级】风险类型
【问题】具体问题描述
【依据】依据《XX法》第X条，法律规定要点
【建议】建议修改为："具体修改内容"
```

## 四、审查遗漏错误

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 缺失条款未记录 | checklist 中的"缺失"未记入 missing_clauses | 完整性核查必须逐项勾选，缺失项全部记录 | 使用完整性核查表格 |
| 占位符误判 | 把"[金额]"占位符当成风险 | 占位符不计入 findings，单独归集到 placeholders | 先执行占位符识别步骤 |
| 特殊关注点遗漏 | 未对用户特殊关注点做专项回应 | 每个关注点必须有对应的专项审查结论 | 检查 special_concern_responses |
| 四层审查不全 | 仅做了基础层审查，遗漏商业/法律/合规层 | 按顺序执行四层审查，每层都有检查表 | 使用四层审查检查表 |

## 五、类型判定错误

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 类型误判 | 把"设备采购+安装"判为单一买卖合同 | 识别为混合类型，加载两类模板 | 使用特征词表匹配 |
| 忽略排除词 | 含"技术开发"的合同被判为买卖合同 | 排除词出现则不匹配该类型 | 检查排除词 |
| 混合类型未识别 | 多种合同特征但仅加载一类模板 | 同时命中多类特征词时识别为混合类型 | 检查是否命中多类特征词 |

## 六、产物格式错误

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 字段缺失 | findings 缺少必要字段（如 keyword、level） | 每条 finding 必须包含所有必要字段 | 使用产物格式检查表 |
| 字段类型错误 | level 写成"高"而非"致命/重要/一般/轻微" | 使用规定的四个等级值 | 对照产物格式定义 |
| JSON 格式错误 | 产物不是有效 JSON | 确保产物可被 JSON 解析 | 使用 JSON 格式验证 |

**阶段三产物必要字段检查表：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| findings[].id | string | 是 | 风险编号，格式 R001、R002... |
| findings[].category | string | 是 | tc / comment_only / tc_insert |
| findings[].level | string | 是 | 致命 / 重要 / 一般 / 轻微 |
| findings[].layer | string | 是 | 基础层 / 商业层 / 法律层 / 合规层 |
| findings[].location | string | 是 | 条款位置 |
| findings[].keyword | string | 是 | 从原文逐字复制的定位关键字 |
| findings[].old_text | string | tc 类必填 | 从原文逐字复制的替换文本 |
| findings[].new_text | string | tc 类必填 | 建议替换的文本 |
| findings[].description | string | 是 | 风险描述 |
| findings[].legal_basis | string | 是 | 法律依据 |
| findings[].suggestion | string | 是 | 修改建议 |
| findings[].comment_text | string | 是 | 批注完整文本 |

## 七、执行顺序错误

| 错误类型 | 错误表现 | 正确做法 | 预防方法 |
|---------|---------|---------|---------|
| 跳过阶段 | 未完成阶段一确认直接开始审查 | 每个阶段必须满足退出条件才能进入下一阶段 | 检查阶段退出条件 |
| 顺序颠倒 | 先执行法律层审查再做基础层审查 | 按基础→商业→法律→合规顺序执行 | 按步骤编号顺序执行 |
| 跳过自检 | 未执行步骤 8 自检直接进入阶段四 | 必须完成自检并全部通过 | 使用自检检查表 |

## 执行前必读

在开始阶段三审查前，**快速浏览本清单**，确保：

1. ✅ 我知道关键字必须从原文逐字复制
2. ✅ 我知道风险等级必须对照风险模板判定
3. ✅ 我知道批注必须使用标准格式
4. ✅ 我知道占位符不计入风险
5. ✅ 我知道缺失条款必须记入 missing_clauses
6. ✅ 我知道四层审查必须全部执行
7. ✅ 我知道完成后必须自检
