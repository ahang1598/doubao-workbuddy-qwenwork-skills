# 商品房买卖合同 标准条款模板


#### 1. 商品房基本情况条款

**规范表述**
```
第X条 商品房基本情况
一、出卖人所售商品房坐落于【省/市/区/县】【街道/路】【号】，项目名称为
【  】（以下简称"该商品房"）。
二、该商品房所在土地使用权证号为【  】，土地用途为【住宅/商业/办公/综合】，
土地使用权取得方式为【出让/划拨】，土地使用权终止日期为【  年  月  日】。
三、该商品房的建设工程规划许可证号为【  】，建筑工程施工许可证号为
【  】，商品房预售许可证号/现售备案证明号为【  】。
四、该商品房为第【  】幢【  】单元【  】层【  】号，建筑面积共
【  】平方米，其中套内建筑面积【  】平方米，公共部位与公用房屋分摊
建筑面积【  】平方米。
五、该商品房用途为【住宅/商业/办公】，属【毛坯房/精装修房】交付，
房屋结构为【钢筋混凝土/砖混/框架/剪力墙】结构，层高为【  】米。
六、该商品房共用部位、共用设施设备的权属及使用范围详见本合同附件。
```

**专业术语**
- 建筑面积（而非"房子面积""总面积"）
- 套内建筑面积（而非"实际使用面积""实得面积"）
- 公共部位与公用房屋分摊建筑面积（而非"公摊面积""公摊"）
- 土地使用权出让（而非"买地""买地皮"）
- 建设工程规划许可证（而非"建房许可""盖楼审批"）
- 商品房预售许可证（而非"卖房资质""售楼许可"）
- 出卖人/买受人（而非"卖方/买方""开发商/业主"）

#### 2. 价款及支付条款

**规范表述**
```
第X条 商品房价款及支付方式
一、买受人与出卖人约定，该商品房按照下列第【  】种方式计价：
  （一）按建筑面积计算，单价为每平方米人民币【  】元（大写：【  】元整），
  总价款为人民币【  】元（大写：【  】元整）；
  （二）按套内建筑面积计算，单价为每平方米人民币【  】元
  （大写：【  】元整），总价款为人民币【  】元（大写：【  】元整）；
  （三）按套（单元）计算，总价款为人民币【  】元（大写：【  】元整）。
二、买受人采取下列第【  】种方式支付购房款：
  （一）一次性付款：买受人应于【  年  月  日】前一次性向出卖人支付
  全部购房款；
  （二）分期付款：买受人应于【  年  月  日】前支付首期房款人民币
  【  】元，占总价款的【  】%；余款人民币【  】元应于
  【  年  月  日】前付清；
  （三）贷款方式付款：买受人应于【  年  月  日】前支付首期房款人民币
  【  】元，占总价款的【  】%；余款人民币【  】元向【银行名称】
  申请【公积金/商业/组合】贷款支付。
三、买受人逾期付款的，每逾期一日按照已到期应付未付款项的万分之【  】
向出卖人支付违约金。逾期超过【  】日的，出卖人有权解除本合同，买受人
应按总价款的【  】%向出卖人支付违约金。
四、买受人以贷款方式付款的，因买受人自身原因未能在约定期限内取得贷款
批准的，双方同意按照下列第【  】种方式处理：
  （一）买受人在【  】日内以自有资金补足剩余房款；
  （二）双方协商解除本合同，出卖人在收到买受人书面解约通知之日起
  【  】日内退还已收房款（不计利息）。
```

**专业术语**
- 价款/购房款（而非"房价""买房钱"）
- 首期房款（而非"首付""首付款"）
- 逾期付款违约金（而非"逾期罚款""滞纳金"）
- 贷款批准/贷款审批（而非"贷款通过""贷款下来"）
- 以自有资金补足（而非"自己补钱""自己凑齐"）
- 计价方式（而非"算价方法""怎么算钱"）
- 解除本合同（而非"退房""取消合同"）

#### 3. 交付条款

**规范表述**
```
第X条 商品房交付
一、出卖人应于【  年  月  日】前将经验收合格的商品房交付买受人。交付时
该商品房应当符合下列条件：
  （一）取得建设工程竣工验收备案证明；
  （二）取得房屋实测面积报告；
  （三）满足本合同约定的交付使用条件及商品房交付使用通知书所载明的
  各项条件。
二、出卖人应在交付之日前【  】日书面通知买受人办理商品房交付手续。
交付时双方应共同对该商品房进行查验，填写《房屋交接书》，交接钥匙及相关
资料。
三、出卖人逾期交房的，每逾期一日按照买受人已付房款的万分之【  】向
买受人支付违约金。逾期超过【  】日的，买受人有权解除本合同。合同解除的，
出卖人应于解除通知到达之日起【  】日内退还买受人已付全部房款，并按照
已付房款的【  】%支付违约金。
四、因不可抗力导致出卖人未能按期交付商品房的，出卖人应于不可抗力事件
发生之日起【  】日内以书面形式告知买受人，并提供相关证明材料。交付期限
相应顺延，顺延期间出卖人不承担违约责任。
五、交付时出卖人应向买受人提供下列文件：
  （一）《住宅质量保证书》；
  （二）《住宅使用说明书》；
  （三）竣工验收备案证明（复印件）；
  （四）房屋实测面积报告。
```

**专业术语**
- 竣工验收备案证明（而非"验收证明""合格证"）
- 交付使用/交付（而非"交房""拿房""收楼"）
- 房屋交接书（而非"交房单""验房单"）
- 查验（而非"验房""看房"）
- 住宅质量保证书（而非"房屋保修书""质保卡"）
- 不可抗力（而非"天灾人祸""意外情况"）
- 实测面积报告（而非"实际测量面积""量房报告"）

#### 4. 产权登记条款

**规范表述**
```
第X条 产权登记
一、出卖人应于商品房交付使用之日起【  】日内，将办理不动产权属登记
所需由出卖人提供的全部资料报产权登记机关备案。
二、出卖人应于商品房交付使用之日起【  】日内协助买受人向不动产登记
机构申请办理不动产转移登记（即"不动产权属证书"），并提供必要的证明文件。
因出卖人原因导致买受人未能在商品房交付使用之日起【  】日内取得不动产
权属证书的，双方同意按照下列第【  】种方式处理：
  （一）买受人不退房的，出卖人按已付房款的【  】%向买受人支付违约金；
  （二）买受人退房的，出卖人应于买受人提出退房要求之日起【  】日内
  退还买受人已付全部房款，并按照银行同期贷款利率支付已付房款自交付之日起
  至退款到账之日止的利息，同时按已付房款的【  】%支付违约金。
三、买受人应及时提供办理不动产转移登记所需的身份证明、购房发票、契税
完税凭证等个人资料，并配合出卖人办理产权登记手续。因买受人原因延误办理
不动产权属登记的，出卖人不承担相应责任。
四、该商品房所占土地使用权依法随房屋所有权同时转让，由不动产登记机构
一并登记，记载于不动产权属证书。
```

**专业术语**
- 不动产权属证书（而非"房产证""产权证""红本"）
- 不动产转移登记（而非"过户""办证"）
- 不动产登记机构（而非"房管局""产权中心"）
- 契税完税凭证（而非"交税证明""税票"）
- 产权登记机关备案（而非"报备""登记备案"）
- 土地使用权随房屋所有权转让（而非"地随房走"）

#### 5. 面积差异处理条款

**规范表述**
```
第X条 面积差异处理
一、该商品房交付时实测建筑面积与合同约定建筑面积发生差异的，按照下列
方式处理：
  （一）面积误差比绝对值在3%以内（含3%）的，据实结算购房款，买受人
  不得以此为由解除本合同。实测面积大于合同约定面积的，面积误差比在3%
  以内（含3%）部分的房价款由买受人按约定单价补足；实测面积小于合同约定
  面积的，面积误差比在3%以内（含3%）部分的房价款由出卖人向买受人
  双倍返还。
  （二）面积误差比绝对值超过3%的，买受人有权解除本合同。买受人解除合同
  的，出卖人应于买受人提出解约要求之日起【  】日内退还买受人已付全部
  房款及利息。买受人不解除合同的，实测面积大于合同约定面积的，面积误差比
  超出3%的部分房价款由出卖人承担；实测面积小于合同约定面积的，面积误差比
  超出3%的部分房价款由出卖人双倍返还买受人。
二、面积误差比的计算公式为：
  面积误差比 =（实测面积 - 合同约定面积）÷ 合同约定面积 × 100%
三、本条所称建筑面积以具有测绘资质的房屋测绘机构出具的正式测绘报告
为准。
四、因出卖人规划设计变更导致商品房面积发生变化的，出卖人应于规划变更
确定之日起【  】日内书面通知买受人。买受人有权在收到通知之日起【  】日内
作出是否接受变更的书面答复。买受人不接受变更的，有权解除本合同。
```

**专业术语**
- 面积误差比（而非"面积差""面积偏差"）
- 据实结算（而非"按实际算""多退少补"）
- 双倍返还（而非"赔双倍""退两倍"）
- 测绘资质/房屋测绘机构（而非"测量单位""量房公司"）
- 规划设计变更（而非"改规划""改设计"）
- 绝对值（而非"不管多了还是少了"）

#### 6. 质量保证条款

**规范表述**
```
第X条 质量保证
一、出卖人交付的商品房质量应当符合国家现行工程质量验收标准和本合同约定
的质量标准。出卖人应向买受人交付《住宅质量保证书》和《住宅使用说明书》。
二、商品房保修期自商品房交付买受人之日起计算。保修期及保修范围按照国务院
《建设工程质量管理条例》及《住宅质量保证书》中载明的保修内容执行。
主要保修项目及最低保修期限如下：
  （一）地基基础工程和主体结构工程，为设计文件规定的该工程合理使用年限；
  （二）屋面防水工程、有防水要求的卫生间和外墙面的防渗漏，保修期为
  【  】年，且不少于5年；
  （三）供热与供冷系统，保修期为【  】个采暖期/供冷期；
  （四）电气管线、给排水管道、设备安装和装修工程，保修期为【  】年，
  且不少于2年。
三、在保修期内，因出卖人责任造成的质量缺陷，出卖人应当承担修复责任。
出卖人接到买受人书面保修通知后，应在【  】日内派员到场检查确认，并于
确认之日起【  】日内完成修复。修复期间造成买受人损失的，出卖人应予以赔偿。
四、商品房交付时存在下列严重质量问题的，买受人有权拒绝收房并解除本合同：
  （一）房屋主体结构质量不合格，经工程质量检测机构核验确认的；
  （二）房屋质量严重影响正常居住使用的。
  出卖人应于买受人提出解约要求之日起【  】日内退还买受人已付全部房款
  及利息，并按照合同总价款的【  】%支付违约金。
五、出卖人与买受人对房屋质量问题存在争议的，双方可以共同委托具备相应
资质的工程质量检测机构进行检测鉴定，鉴定费用由责任方承担。
```

**专业术语**
- 主体结构质量（而非"房子结构问题""承重墙有问题"）
- 保修期限/保修范围（而非"保修时间""保修内容"）
- 合理使用年限（而非"使用寿命""房子能住多久"）
- 工程质量检测机构（而非"检测公司""鉴定机构"）
- 防渗漏（而非"防漏水""防水"）
- 质量缺陷（而非"质量问题""房屋毛病"）
- 核验确认（而非"检查确认""验证"）
