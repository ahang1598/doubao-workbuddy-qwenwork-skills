# 合伙合同 标准条款模板


#### 1. 出资条款

**规范表述**
```
第X条 合伙人出资
一、各合伙人的出资方式、出资数额及出资期限如下：
  （一）合伙人【甲方姓名/名称】以【货币/实物/知识产权/土地使用权/劳务/
  其他财产权利】方式出资，出资数额为人民币【  】元（大写：【  】元整）
  或经全体合伙人一致认可的评估价值为人民币【  】元，占出资总额的【  】%，
  出资期限为【  年  月  日】前缴付完毕；
  （二）合伙人【乙方姓名/名称】以【货币/实物/知识产权/土地使用权/劳务/
  其他财产权利】方式出资，出资数额为人民币【  】元（大写：【  】元整）
  或经全体合伙人一致认可的评估价值为人民币【  】元，占出资总额的【  】%，
  出资期限为【  年  月  日】前缴付完毕；
  ……
二、合伙人以非货币财产出资的，依照法律规定或者全体合伙人协商确定的
合理价格折算为出资额。合伙人以劳务出资的，其评估办法由全体合伙人
协商一致确定。
三、合伙人的出资以及合伙经营积累的财产为合伙财产。合伙存续期间，
合伙人的出资及因合伙事务依法取得的收益，归全体合伙人共有。合伙期间，
合伙人不得请求分割合伙财产。
四、合伙人未按期足额缴纳出资的，应当向其他合伙人承担违约责任。
未按期出资的合伙人每逾期一日按照未缴出资额的万分之【  】向其他
合伙人支付违约金，并应在【  】日内补足出资。逾期【  】日仍未补足
出资的，经其他合伙人一致同意，可以将其除名。
五、合伙人出资后，由全体合伙人签署《出资确认书》，载明各合伙人的
出资方式、出资额及出资时间。
```

**专业术语**
- 出资/出资方式/出资数额（而非"投资""投入""入伙金"）
- 非货币财产出资（而非"拿东西入伙""实物投资"）
- 劳务出资（而非"出力""以劳动入伙"）
- 合伙财产（而非"合伙的钱""大家共有的财产"）
- 折算为出资额（而非"折算成钱""换算成出资"）
- 除名（而非"开除""踢出去"）
- 出资确认书（而非"出资证明""投资凭证"）

#### 2. 利润分配与亏损分担条款

**规范表述**
```
第X条 利润分配与亏损分担
一、合伙的利润分配与亏损分担，由全体合伙人协商确定，按照下列第【  】种
方式执行：
  （一）按照出资比例分配利润、分担亏损：合伙人【甲方】占【  】%，
  合伙人【乙方】占【  】%，……；
  （二）按照合伙协议约定的比例分配利润、分担亏损：合伙人【甲方】分配
  利润【  】%、分担亏损【  】%，合伙人【乙方】分配利润【  】%、
  分担亏损【  】%，……；
  （三）按照全体合伙人协商一致的其他方式确定。
二、合伙合同不得约定将全部利润分配给部分合伙人，或由部分合伙人承担
全部亏损。
三、利润分配及亏损分担的周期为【月/季度/半年/年】，每个分配周期届满后
【  】日内进行利润核算与分配。具体程序如下：
  （一）由执行合伙事务的合伙人或委托的会计人员编制利润分配方案；
  （二）利润分配方案经全体合伙人审议确认后执行；
  （三）合伙人对利润分配方案有异议的，应在收到方案后【  】日内书面
  提出，由全体合伙人协商解决。
四、合伙的亏损承担：
  （一）合伙经营亏损首先以合伙财产承担；
  （二）合伙财产不足以清偿债务的，由各合伙人按照本条约定的亏损分担比例
  以其个人财产承担无限连带责任；
  （三）已代偿超出自身应承担份额的合伙人，有权向其他合伙人追偿。
五、合伙存续期间的应纳税额，由各合伙人按照各自应分配的所得额分别缴纳。
```

**专业术语**
- 利润分配/亏损分担（而非"分钱""分红/赔钱"）
- 无限连带责任（而非"无限制赔偿""连带赔偿"）
- 追偿/追偿权（而非"追讨""要回多付的钱"）
- 出资比例（而非"投资比例""股份比例"）
- 利润核算（而非"算利润""结算"）
- 应纳税额（而非"要交的税""税款"）
- 合伙财产不足以清偿债务（而非"合伙的钱不够还债"）

#### 3. 合伙事务执行条款

**规范表述**
```
第X条 合伙事务执行
一、合伙事务的执行方式，经全体合伙人协商一致，按照下列第【  】种方式
确定：
  （一）由全体合伙人共同执行合伙事务；
  （二）委托合伙人【  】为执行事务合伙人，代表全体合伙人执行合伙事务。
二、执行事务合伙人的职权范围：
  （一）对外代表合伙组织，以合伙名义从事经营活动；
  （二）管理合伙日常经营事务，包括但不限于采购、销售、人员管理等；
  （三）管理和使用合伙财产，但单笔支出超过人民币【  】元的，须经
  全体合伙人一致同意或按本合同约定的表决机制作出决定；
  （四）签订标的额不超过人民币【  】元的合同。
三、下列事项须经全体合伙人一致同意方可执行：
  （一）处分合伙不动产；
  （二）变更合伙经营范围或主要经营场所；
  （三）对外提供担保；
  （四）单笔交易标的额超过人民币【  】元的合同签署；
  （五）以合伙名义对外借款或为他人提供担保；
  （六）其他涉及全体合伙人重大利益的事项。
四、执行事务合伙人应当定期向其他合伙人报告合伙事务执行情况，报告周期
为【月/季度】。不执行合伙事务的合伙人有权监督执行事务合伙人执行合伙事务
的情况，查阅合伙的会计账簿、财务报表等财务资料，并有权对执行事务提出异议。
五、执行事务合伙人超越权限或违反本合同约定执行合伙事务，给合伙或其他
合伙人造成损失的，应当承担赔偿责任。
六、合伙人分别执行合伙事务时，其他合伙人有权提出异议。提出异议时，
应当暂停该项事务的执行。该事务的执行是否继续，由全体合伙人共同决定。
```

**专业术语**
- 执行事务合伙人（而非"管理合伙人""负责人"）
- 执行合伙事务（而非"管理合伙事务""做决定"）
- 合伙财产（而非"公共资金""合伙的钱"）
- 处分不动产（而非"卖房子""处理房产"）
- 表决机制（而非"投票规则""决定方式"）
- 对外提供担保（而非"给别人做担保""替人担保"）
- 会计账簿/财务报表（而非"账本""财务报告"）
- 查阅权/监督权（而非"看账的权利""检查权"）

#### 4. 入伙与退伙条款

**规范表述**
```
第X条 入伙与退伙
一、入伙：
  （一）新合伙人入伙须经全体合伙人一致同意，并签订书面入伙协议。
  入伙协议应载明新合伙人的出资方式、出资数额、利润分配及亏损分担比例
  等内容。
  （二）新入伙的合伙人与原合伙人享有同等权利、承担同等义务。新合伙人
  对入伙前合伙的债务承担无限连带责任。
  （三）入伙协议另有约定的，从其约定，但不得对抗善意第三人。
二、自愿退伙：
  （一）合伙期限届满，合伙人不愿续伙的，有权退伙；
  （二）合伙协议约定的退伙事由出现时，退伙人有权退伙；
  （三）经全体合伙人一致同意，合伙人可以退伙；
  （四）发生合伙人难以继续参加合伙的事由时，合伙人可以退伙。
  合伙人自愿退伙的，应提前【  】日书面通知其他全体合伙人。
三、当然退伙：
  合伙人出现下列情形之一的，当然退伙：
  （一）合伙人死亡或被依法宣告死亡；
  （二）丧失民事行为能力；
  （三）个人丧失偿债能力；
  （四）法律规定或合伙协议约定的其他情形。
四、除名退伙：
  合伙人出现下列情形之一的，经其他合伙人一致同意，可以将其除名：
  （一）未履行出资义务的；
  （二）因故意或重大过失给合伙造成损失的；
  （三）执行合伙事务时有不正当行为的；
  （四）合伙协议约定的其他除名事由。
  对合伙人的除名决议应当书面通知被除名人。被除名人自收到除名通知之日起
  【  】日内，有权向人民法院提起诉讼。
五、退伙结算：
  （一）退伙人退伙时，应对退伙人的合伙财产份额进行结算。退伙财产份额
  的确定以退伙时合伙财产的状况为基础，参照合伙财产评估或审计结果确定。
  （二）合伙应于退伙人退伙之日起【  】日内向退伙人退还其财产份额。
  退还方式为【货币退还/实物退还/双方协商确定】。
  （三）退伙人对退伙前已发生的合伙债务，承担无限连带责任。
  （四）退伙时尚有未了结的合伙事务的，待该事务了结后进行结算。
```

**专业术语**
- 入伙/退伙（而非"加入合伙""退出合伙"）
- 当然退伙（而非"自动退伙""法定退伙"）
- 除名（而非"开除""踢出"）
- 合伙财产份额（而非"合伙股份""出资份额"）
- 无限连带责任（而非"一起承担""连带偿还"）
- 不正当行为（而非"违规行为""不当行为"）
- 善意第三人（而非"不知情的第三方""外人"）
- 民事行为能力（而非"行为能力""做事能力"）
- 了结/未了结（而非"结束/未结束""处理完"）

#### 5. 合伙解散条款

**规范表述**
```
第X条 合伙解散与清算
一、出现下列情形之一的，合伙解散：
  （一）合伙期限届满，合伙人不愿续伙的；
  （二）全体合伙人一致决定解散的；
  （三）合伙人仅剩一人且未在法定期限内补充合伙人的；
  （四）合伙协议约定的解散事由出现的；
  （五）依法被吊销营业执照、责令关闭或被撤销的；
  （六）法律、行政法规规定的其他情形。
二、合伙解散后，应当进行清算。清算人由全体合伙人共同担任或经全体合伙人
过半数同意指定【  】名合伙人担任，也可以委托第三方专业清算机构担任。
清算人自被确定之日起【  】日内开始清算。
三、清算人在清算期间执行下列事务：
  （一）清理合伙财产，编制资产负债表和财产清单；
  （二）通知和公告债权人，处理与清算有关的合伙未了结事务；
  （三）追收债权；
  （四）清缴所欠税款；
  （五）清理债权债务；
  （六）处理合伙清偿债务后的剩余财产。
四、合伙财产的清偿顺序如下：
  （一）支付清算费用；
  （二）支付合伙所欠职工工资、社会保险费用和法定补偿金；
  （三）缴纳所欠税款；
  （四）清偿合伙债务。
  清偿上述费用后的剩余财产，由全体合伙人按照利润分配比例进行分配。
  合伙财产不足以清偿前述费用和债务的，各合伙人应按照亏损分担比例以其
  个人财产承担无限连带清偿责任。
五、清算结束后，清算人应编制清算报告，经全体合伙人签署确认后，在【  】
日内向原登记机关办理注销登记。
六、清算期间，合伙人不得以任何方式处分合伙财产（清算必要行为除外），
不得开展与清算无关的经营活动。
七、合伙人在合伙解散后，对合伙存续期间的债务仍应承担无限连带责任，
但债权人在【  】年内未向合伙人主张权利的，该责任消灭（法律另有规定的
除外）。
```

**专业术语**
- 合伙解散（而非"散伙""合伙结束"）
- 清算/清算人（而非"算账/算账的人""结算"）
- 资产负债表/财产清单（而非"资产表""财产目录"）
- 债权人/债权（而非"债主/欠别人的钱"）
- 清偿顺序（而非"还债顺序""优先还谁"）
- 注销登记（而非"注销""销户"）
- 无限连带清偿责任（而非"一起还债""共同偿还"）
- 剩余财产分配（而非"分剩下的钱""分家产"）
- 法定补偿金（而非"赔偿""补偿款"）
