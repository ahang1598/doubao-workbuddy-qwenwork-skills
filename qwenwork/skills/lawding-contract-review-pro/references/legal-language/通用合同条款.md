# 通用合同条款 标准条款模板


> **适用场景：** 当合同无法匹配前述 17 类中的任何一种（无名合同/新型合同），或为混合类型合同时，使用本通用条款模板。

#### 1. 合同主体条款

```
甲方（全称）：【主体名称】
统一社会信用代码：【代码】
法定代表人/负责人：【姓名】
住所地：【地址】
联系方式：【电话/邮箱】

乙方（全称）：【主体名称】
统一社会信用代码/身份证号码：【代码/号码】
法定代表人/负责人：【姓名】
住所地：【地址】
联系方式：【电话/邮箱】
```

**专业术语**：
- 法定代表人（企业法人的代表人）
- 住所地（企业注册地址）
- 统一社会信用代码（企业唯一识别码）
- 合同当事人（合同权利义务的承受主体）
- 签约主体适格（具备签订合同的资格和能力）

#### 2. 标的与范围条款

```
第X条 合同标的

本合同项下的标的为【具体描述标的内容】。

甲方应按照本合同约定向乙方【提供/交付/完成】【标的具体内容】，具体包括但不限于：
（一）【具体事项一】；
（二）【具体事项二】；
（三）【具体事项三】。

上述标的的【规格/标准/范围】详见本合同附件【附件编号】。
```

**专业术语**：
- 合同标的（合同权利义务共同指向的对象）
- 标的物（具有实体形态的交易对象）
- 合同范围（合同约定的权利义务边界）
- 包括但不限于（非穷尽式列举）

#### 3. 价款与支付条款

```
第X条 合同价款

本合同总价款为人民币【大写金额】元（¥【小写金额】元），【含/不含】增值税。

第X条 支付方式

乙方应按照以下方式向甲方支付合同价款：
（一）本合同签订之日起【 】个工作日内，支付合同总价款的【 】%，即人民币【大写金额】元，作为【预付款/定金/首付款】；
（二）【触发条件/阶段节点】完成后【 】个工作日内，支付合同总价款的【 】%，即人民币【大写金额】元；
（三）【验收合格/全部履行完毕】后【 】个工作日内，支付剩余款项。

甲方应在收到款项后【 】个工作日内向乙方开具合法有效的增值税【专用/普通】发票。
```

**专业术语**：
- 合同价款（合同约定的对价总金额）
- 预付款（提前支付的合同款项，不适用定金罚则）
- 定金（具有担保性质的预付款项，适用定金罚则）
- 工作日（不含法定节假日和休息日的日期）
- 增值税专用发票/增值税普通发票（税务凭证类型）

#### 4. 违约责任条款

```
第X条 违约责任

一、任何一方未按照本合同约定履行义务的，构成违约，应当承担违约责任。

二、【甲方/乙方】有下列情形之一的，应当向对方支付合同总价款【 】%的违约金：
（一）未按约定【期限/方式/标准】履行义务的；
（二）未经对方书面同意，擅自【变更/转让/终止】合同的；
（三）违反本合同约定的保密义务的。

三、违约金不足以弥补守约方实际损失的，违约方应当赔偿超出违约金部分的损失。

四、一方迟延履行主要义务，经催告后在合理期限内仍未履行的，对方有权解除本合同，并要求违约方承担违约责任。
```

**专业术语**：
- 违约责任（违反合同义务应承担的法律责任）
- 违约金（合同约定的违约方应支付的金额）
- 损害赔偿（对守约方实际损失的补偿）
- 催告（书面通知对方履行义务）
- 合理期限（根据交易习惯和合同性质确定的适当期间）
- 迟延履行（超过约定期限履行义务）

#### 5. 解除与终止条款

```
第X条 合同解除

一、经双方协商一致，可以解除本合同。

二、有下列情形之一的，守约方有权书面通知违约方解除本合同：
（一）一方迟延履行主要债务，经催告后在【 】日内仍未履行的；
（二）一方明确表示或者以行为表明不履行合同主要义务的；
（三）因不可抗力致使不能实现合同目的的；
（四）【其他约定的解除条件】。

第X条 合同终止

本合同在下列情形下终止：
（一）合同义务全部履行完毕；
（二）双方协商一致解除；
（三）一方依法行使解除权；
（四）法律规定的其他终止情形。

第X条 解除/终止后果

合同解除或终止后，双方应在【 】日内进行清算和结算：
（一）已履行部分根据履行情况和合同性质，由当事人合理分担；
（二）尚未履行的部分终止履行；
（三）因违约导致合同解除的，违约方应当承担损害赔偿责任。
```

**专业术语**：
- 合同解除（提前终结合同关系）
- 约定解除（基于合同约定的解除条件）
- 法定解除（基于法律规定的解除权）
- 协商解除（经双方合意的解除）
- 合同终止（合同权利义务关系消灭）
- 清算结算（解除/终止后的债权债务处理）

#### 6. 不可抗力条款

```
第X条 不可抗力

一、本合同所称不可抗力，是指不能预见、不能避免且不能克服的客观情况，包括但不限于：自然灾害（地震、洪水、台风等）、社会事件（战争、暴乱、恐怖袭击等）、政府行为（法律法规变更、政策调整、行政命令等）、公共卫生事件（传染病疫情等）。

二、遭受不可抗力的一方应在不可抗力事件发生之日起【 】日内以书面形式通知对方，并在【 】日内提供不可抗力事件的证明材料。

三、因不可抗力导致不能履行或迟延履行合同义务的，根据不可抗力的影响，部分或者全部免除责任。但迟延履行后发生不可抗力的，不免除迟延履行方的责任。
```

**专业术语**：
- 不可抗力（不能预见、不能避免且不能克服的客观情况）
- 免责事由（免除违约责任的法定或约定事由）
- 通知义务（及时告知对方的法定义务）
- 证明义务（提供相关证明材料的义务）

#### 7. 保密条款

```
第X条 保密义务

一、本合同所称保密信息，是指一方向另一方披露的、与本合同有关的一切非公开信息，包括但不限于：商业秘密、技术资料、财务数据、客户信息、合同条款及其履行情况。

二、未经信息披露方书面同意，接收方不得向任何第三方披露、提供或允许第三方使用保密信息，亦不得将保密信息用于本合同约定以外的任何目的。

三、保密义务的存续期间为本合同有效期内及合同终止后【 】年。

四、违反保密义务的一方，应当赔偿因此给对方造成的全部损失。
```

**专业术语**：
- 保密信息（不向公众公开的非公知信息）
- 商业秘密（具有商业价值并经权利人采取保密措施的技术信息和经营信息）
- 保密期限（保密义务的存续期间）
- 披露（向第三方透露保密信息）

#### 8. 通知与送达条款

```
第X条 通知与送达

一、本合同项下的通知、函件等往来文件，应以下列方式之一送达：
（一）专人送达：以签收之日为送达日；
（二）邮寄送达：以挂号信或特快专递方式寄送，以寄出之日起第【 】日为送达日；
（三）电子送达：以电子邮件或双方确认的即时通讯工具发送，以发送成功之日为送达日。

二、各方确认的送达地址和联系方式如下：
甲方：【地址】，联系人：【姓名】，电话：【电话】，邮箱：【邮箱】
乙方：【地址】，联系人：【姓名】，电话：【电话】，邮箱：【邮箱】

三、任何一方变更送达地址或联系方式的，应在变更之日起【 】日内书面通知对方。未履行通知义务的，按原地址送达视为有效送达。
```

**专业术语**：
- 送达（将法律文书或通知交付给对方当事人）
- 挂号信/特快专递（具有送达凭证的邮寄方式）
- 视为送达（法律拟制的送达效力）
- 送达地址确认（当事人对接收文件地址的书面确认）
