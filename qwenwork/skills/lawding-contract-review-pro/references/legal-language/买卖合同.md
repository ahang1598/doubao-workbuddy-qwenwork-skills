# 买卖合同 标准条款模板


#### 1. 标的条款

**规范表述**
```
第X条 标的物
甲方向乙方出售的标的物为【具体名称】（以下简称"标的物"），
具体规格型号、数量、质量标准详见本合同附件《标的物清单》。

标的物的权属清晰，不存在权属纠纷、抵押、查封等权利瑕疵。
```

**专业术语**
- 标的物（而非"货物"）
- 出售（而非"卖"）
- 权属清晰（而非"所有权清楚"）
- 权利瑕疵（而非"权利问题"）

#### 2. 价款条款

**规范表述**
```
第X条 价款及支付方式
一、标的物价款为人民币【大写】元整（¥【小写】元），
上述价款为含税价格，增值税税率为【】%。

二、支付方式：
（一）合同签订后【】日内，乙方向甲方支付合同价款的【】%，
计人民币【大写】元整（¥【小写】元），作为预付款；
（二）标的物交付并经乙方验收合格后【】日内，乙方向甲方
支付合同价款的【】%，计人民币【大写】元整（¥【小写】元）；
（三）质保期满后【】日内，乙方向甲方支付剩余价款及质保金。

三、付款账户：
户名：【】
开户行：【】
账号：【】
```

**专业术语**
- 价款（而非"价格"、"钱"）
- 支付（而非"付"）
- 预付款（而非"定金"、"订金"，除非确实是定金）
- 质保金（而非"保证金"）

#### 3. 交付条款

**规范表述**
```
第X条 交付
一、交付时间：甲方应于【年月日】前完成标的物的交付。

二、交付地点：【具体地址】。

三、交付方式：甲方负责将标的物运输至交付地点，运输费用
由【甲方/乙方】承担。

四、风险转移：标的物毁损、灭失的风险，自标的物交付时起
转移至乙方。交付前的风险由甲方承担，交付后的风险由乙方承担。

五、交付凭证：标的物交付时，乙方应向甲方出具书面签收凭证，
作为完成交付的证明。
```

**专业术语**
- 交付（而非"交货"、"送货"）
- 风险转移（而非"责任转移"）
- 毁损、灭失（而非"损坏、丢失"）
- 签收凭证（而非"收据"）

#### 4. 验收条款

**规范表述**
```
第X条 验收
一、验收标准：标的物应符合国家标准【标准号】/行业标准【标准号】
/本合同约定的质量标准（详见附件）。

二、验收程序：
（一）甲方完成交付后，应书面通知乙方进行验收；
（二）乙方应在收到验收通知后【】日内完成验收；
（三）验收合格的，双方签署《验收合格证明》；
（四）验收不合格的，乙方应书面说明不合格的具体事项，
甲方应在【】日内予以修复或更换，修复或更换后重新验收。

三、视为验收合格：乙方在验收期限内未提出异议且未进行验收的，
视为验收合格。

四、验收争议：对验收结果有争议的，双方同意委托【检测机构名称】
进行检测，检测费用由责任方承担。
```

**专业术语**
- 验收标准（而非"验收要求"）
- 验收合格证明（而非"验收单"）
- 修复（而非"修理"）
- 视为验收合格（法定的拟制条款）

#### 5. 质量瑕疵担保条款

**规范表述**
```
第X条 质量瑕疵担保
一、质量保证期：自验收合格之日起【】个月/年。

二、质量瑕疵的通知：质量保证期内，标的物出现质量瑕疵的，
乙方应在发现瑕疵后【】日内书面通知甲方。

三、甲方的责任：
（一）因甲方原因导致标的物存在质量瑕疵的，甲方应在收到
通知后【】日内无偿予以修理、更换或退货；
（二）因质量瑕疵造成乙方损失的，甲方应承担赔偿责任。

四、乙方的义务：乙方应按照约定的用途和方式使用标的物，
因乙方使用、保管不当造成的质量问题，甲方不承担责任。
```

**专业术语**
- 质量瑕疵担保（而非"质量保证"）
- 质量瑕疵（而非"质量问题"）
- 无偿（而非"免费"）
- 修理、更换或退货（法定的三种救济方式）

#### 6. 违约责任条款

**规范表述**
```
第X条 违约责任
一、甲方违约责任：
（一）逾期交付：甲方未按约定时间交付标的物的，每逾期一日，
应按合同总价款的【】%向乙方支付违约金；逾期超过【】日的，
乙方有权解除合同，甲方除返还已收价款外，还应向乙方支付
合同总价款【】%的违约金。

（二）质量不符：标的物质量不符合约定，经修理或更换后仍不符合
约定的,乙方有权拒收，甲方应返还已收价款，并向乙方支付
合同总价款【】%的违约金。

（三）权利瑕疵：标的物存在权属争议、抵押、查封等权利瑕疵的，
乙方有权解除合同，甲方应返还已收价款，并向乙方支付
合同总价款【】%的违约金；造成乙方损失的，甲方应承担赔偿责任。

二、乙方违约责任：
（一）逾期付款：乙方未按约定时间支付价款的，每逾期一日，
应按逾期支付金额的【】%向甲方支付违约金；逾期超过【】日的，
甲方有权解除合同，乙方应向甲方支付合同总价款【】%的违约金。

（二）拒收：标的物符合约定，乙方无正当理由拒绝接收的，
应向甲方支付合同总价款【】%的违约金。

三、违约金调整：违约金不足以弥补守约方实际损失的，违约方应
赔偿守约方的实际损失；违约金过高的，违约方可请求人民法院或
仲裁机构予以适当减少。
```

**专业术语**
- 逾期（而非"延迟"、"推迟"）
- 支付违约金（而非"罚款"）
- 解除合同（而非"取消合同"）
- 返还（而非"退还"）
- 承担赔偿责任（而非"赔偿损失"）
- 实际损失（而非"全部损失"）
