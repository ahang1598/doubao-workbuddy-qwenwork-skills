# 担保合同 标准条款模板


#### 1. 担保方式条款

**规范表述**
```
第X条 担保方式
一、本合同项下担保方式为【保证/抵押/质押/留置/定金】。担保人自愿为债务人
【债务人名称】在主合同项下的债务向债权人【债权人名称】提供担保。
二、本合同项下保证方式为【一般保证/连带责任保证】。保证人承诺，当债务人
未履行到期债务或者发生当事人约定的情形时，依照本合同约定履行保证责任。
三、若本合同未明确约定保证方式或约定不明确的，依据《中华人民共和国民法典》
第六百八十六条之规定，保证人按照一般保证承担保证责任。
四、担保人声明并保证：其具有完全民事行为能力，有权签署本合同并提供本合同
项下之担保；提供担保已获得其内部有权机关的合法授权（附授权文件作为本合同
附件）。
五、本合同为主合同【主合同编号及名称】的从合同。主合同无效的，本担保合同
无效，但法律另有规定的除外。
```

**专业术语**
- 一般保证（而非"普通担保"）
- 连带责任保证（而非"共同担保"）
- 从合同（而非"附属合同""次要合同"）
- 保证人（而非"担保方""保人"）
- 有权机关（而非"领导""上级"）
- 民事行为能力（而非"法律资格"）

#### 2. 担保范围条款

**规范表述**
```
第X条 担保范围
一、本合同担保范围包括：主债权本金人民币（大写）【金额】元整
（¥【金额】）及利息（含罚息、复利）、违约金、损害赔偿金、实现债权的费用
（包括但不限于诉讼费、仲裁费、保全费、执行费、律师费、差旅费、评估费、
拍卖费等）以及所有其他应付费用。
二、主债权利息的计算方式、利率标准及计息期间，以主合同的约定为准。若主合同
约定的利率发生调整，担保范围内的利息相应调整，无需另行签署补充协议。
三、主合同项下债务人的债务每次变更（包括但不限于展期、金额变更），如未经
担保人书面同意，担保人对变更后的债务不承担担保责任；如经担保人书面同意，
则担保范围相应调整。
四、担保人与债权人对担保范围有特别约定的，从其约定。未约定或约定不明确的，
担保范围依据《中华人民共和国民法典》第六百九十一条之规定，包括主债权及其
利息、违约金、损害赔偿金和实现债权的费用。
```

**专业术语**
- 主债权（而非"主要欠款""原始借款"）
- 罚息（而非"罚款利息""惩罚利息"）
- 复利（而非"利滚利""利息的利息"）
- 损害赔偿金（而非"赔偿款""补偿费"）
- 实现债权的费用（而非"追债费用""要账成本"）
- 展期（而非"延期""推迟还款"）

#### 3. 担保期间条款

**规范表述**
```
第X条 担保期间
一、本合同保证期间为主债务履行期限届满之日起【六个月/两年/具体期限】。
二、在保证期间内，债权人未依法向保证人主张权利的，保证人免除保证责任。
具体而言：
  （一）一般保证的债权人未在保证期间内对债务人提起诉讼或者申请仲裁的，
  保证人不再承担保证责任；
  （二）连带责任保证的债权人未在保证期间内请求保证人承担保证责任的，
  保证人不再承担保证责任。
三、债权人与债务人对主债务履行期限没有约定或者约定不明确的，保证期间自
债权人请求债务人履行债务的宽限期届满之日起计算。
四、主合同项下分期履行债务的，保证期间自最后一期债务履行期限届满之日起
开始计算。
五、保证期间不因任何事由发生中断、中止或延长。
```

**专业术语**
- 保证期间（而非"担保期限""担保有效期"）
- 履行期限届满（而非"到期""期限到了"）
- 主张权利（而非"要求承担责任""追责"）
- 宽限期（而非"缓冲期""多给的时间"）
- 中断、中止（而非"暂停""停止计算"）
- 免除保证责任（而非"不用担保了""解除担保"）

#### 4. 反担保条款

**规范表述**
```
第X条 反担保
一、债务人或第三人【反担保人名称】自愿向担保人提供反担保。反担保方式为
【保证/抵押/质押】。
二、反担保的范围包括：担保人依本合同承担担保责任后有权向债务人追偿的全部
金额，包括担保人代为清偿的主债权本金、利息、违约金、损害赔偿金，以及担保人
因承担担保责任所支出的合理费用（包括但不限于诉讼费、律师费等）。
三、反担保人应在本合同签署之日起【  】个工作日内完成反担保的设立手续。
以不动产抵押为反担保方式的，应依法办理抵押登记；以动产或权利质押为反担保
方式的，应依法交付质押财产或办理出质登记。
四、担保人在承担保证责任后，有权在其承担担保责任的范围内向债务人追偿，
同时有权就反担保财产优先受偿。
五、未经担保人书面同意，反担保人不得处分反担保财产或以其他方式减损反担保
财产的价值。
```

**专业术语**
- 反担保（而非"反向担保""二次担保"）
- 追偿（而非"要回""索赔"）
- 代为清偿（而非"替人还款""代还"）
- 优先受偿（而非"优先拿钱""先拿"）
- 出质登记（而非"质押登记""质押备案"）
- 处分（而非"处理""卖掉"）

#### 5. 担保物处分条款

**规范表述**
```
第X条 担保物的处分
一、债务人不履行到期债务或者发生当事人约定的实现担保物权的情形，债权人
有权就担保财产依照法律规定的程序进行处分。
二、担保物的处分方式包括：
  （一）与担保人协议以担保财产折价；
  （二）就拍卖担保财产所得的价款优先受偿；
  （三）就变卖担保财产所得的价款优先受偿。
三、担保财产折价或者变卖的，应当参照市场价格。拍卖担保财产的，应当委托
具有相应资质的拍卖机构依法进行。
四、担保财产处分所得价款，按照下列顺序清偿：
  （一）实现担保物权的费用；
  （二）主债权的利息；
  （三）主债权。
五、担保财产处分后所得价款超过担保范围的部分归担保人所有，不足部分由
债务人继续清偿。
六、在担保物权存续期间，担保人未经债权人同意，不得转让担保财产，但受让人
代为清偿债务消灭担保物权的除外。
```

**专业术语**
- 担保物权（而非"担保权利""抵押权"）
- 折价（而非"打折处理""降价出售"）
- 拍卖（而非"竞卖""公开卖"）
- 变卖（而非"转卖""私下卖"）
- 优先受偿（而非"优先获得赔偿""先拿到钱"）
- 存续期间（而非"有效期内""持续期间"）
- 受让人（而非"买方""接手人"）
