# 劳动合同 标准条款模板


#### 1. 工作内容条款

**规范表述**
```
第X条 工作内容和工作地点
一、工作岗位：甲方安排乙方在【部门】从事【岗位】工作。

二、工作职责：乙方的工作职责为【具体职责】，
详见本合同附件《岗位说明书》。

三、工作地点：【省市区县街道门牌号】。

四、工作地点变更：
（一）因生产经营需要，甲方可调整乙方的工作地点；
（二）工作地点调整至【同一城市/不同城市】的，甲方应
提前【】日通知乙方，并征得乙方书面同意；
（三）乙方不同意工作地点调整的，双方协商解决；
协商不成的，按照本合同约定处理。
```

**专业术语**
- 工作岗位（而非"岗位"、"职位"）
- 工作职责（而非"工作内容"）
- 岗位说明书（标准文件名称）
- 工作地点（而非"上班地点"）
- 生产经营需要（调整的理由）
- 征得书面同意（明确同意方式）
- 协商解决（劳动合同变更的原则）

#### 2. 劳动报酬条款

**规范表述**
```
第X条 劳动报酬
一、工资构成：
乙方的工资由以下部分构成：
（一）基本工资：人民币【大写】元整（¥【小写】元）/月；
（二）岗位工资：人民币【大写】元整（¥【小写】元）/月；
（三）绩效工资：根据乙方的工作绩效确定；
（四）其他：【津贴、补贴等】。

二、工资总额：
乙方的月工资总额为人民币【大写】元整（¥【小写】元）
（税前工资，不包括绩效工资等浮动部分）。

三、工资支付：
（一）甲方以货币形式按月支付乙方工资；
（二）工资发放日期为每月【】日（遇法定节假日或休息日顺延）；
（三）甲方通过银行转账方式将工资支付至乙方指定账户。

四、工资调整：
甲方可根据公司经营状况、乙方工作表现及物价水平等因素，
适时调整乙方的工资。

五、最低工资：
乙方的工资不低于当地最低工资标准（目前为【】元/月）。
```

**专业术语**
- 劳动报酬（而非"工资"，虽然条款名可以叫工资）
- 工资构成（基本工资、岗位工资、绩效工资等）
- 基本工资（固定部分）
- 绩效工资（浮动部分）
- 津贴、补贴（工资的组成部分）
- 月工资总额（而非"月薪"）
- 税前工资（而非"工资"）
- 以货币形式（劳动法要求）
- 按月支付（支付周期）
- 法定节假日或休息日顺延（支付时间的调整）
- 银行转账（支付方式）
- 经营状况、工作表现、物价水平（调整因素）
- 适时调整（调整的时间）
- 当地最低工资标准（法定底线）

#### 3. 社会保险条款

**规范表述**
```
第X条 社会保险和福利待遇
一、社会保险：
（一）甲方依法为乙方缴纳基本养老保险、基本医疗保险、
失业保险、工伤保险、生育保险；
（二）甲方应自用工之日起三十日内为乙方办理社会保险登记；
（三）社会保险费由甲方和乙方按照国家规定的比例分别缴纳，
乙方应缴纳的部分由甲方从乙方工资中代扣代缴。

二、住房公积金：
甲方依法为乙方缴存住房公积金，缴存比例按照【】%执行。

三、福利待遇：
乙方享受甲方规定的福利待遇，具体内容详见甲方
《员工手册》/《福利制度》。
```

**专业术语**
- 社会保险（五险的总称）
- 基本养老保险、基本医疗保险、失业保险、工伤保险、
生育保险（五险的全称）
- 依法缴纳（强制性规定）
- 自用工之日起三十日内（法定期限）
- 社会保险登记（行政程序）
- 按照国家规定的比例（缴费比例）
- 代扣代缴（代缴义务）
- 住房公积金（而非"公积金"）
- 缴存（而非"缴纳"）
- 福利待遇（而非"福利"）
- 员工手册、福利制度（规章制度）

#### 4. 解除和终止条款

**规范表述**
```
第X条 劳动合同的解除和终止
一、协商解除：
经甲乙双方协商一致，可以解除本合同。

二、乙方单方解除：
（一）乙方提前三十日以书面形式通知甲方，可以解除本合同；
（二）乙方在试用期内提前三日通知甲方，可以解除本合同；
（三）甲方存在下列情形之一的，乙方可以随时通知甲方解除
本合同：
1. 未按照劳动合同约定提供劳动保护或者劳动条件的；
2. 未及时足额支付劳动报酬的；
3. 未依法为乙方缴纳社会保险费的；
4. 甲方的规章制度违反法律、法规的规定，损害乙方权益的；
5. 因甲方原因致使本合同无效的；
6. 法律、行政法规规定乙方可以解除劳动合同的其他情形。

（四）甲方以暴力、威胁或者非法限制人身自由的手段强迫乙方
劳动的，或者甲方违章指挥、强令冒险作业危及乙方人身安全的，
乙方可以立即解除劳动合同，不需事先告知甲方。

三、甲方单方解除：
（一）乙方存在下列情形之一的，甲方可以随时通知乙方解除
本合同：
1. 在试用期间被证明不符合录用条件的；
2. 严重违反甲方的规章制度的；
3. 严重失职，营私舞弊，给甲方造成重大损害的；
4. 乙方同时与其他用人单位建立劳动关系，对完成本单位的
工作任务造成严重影响，或者经甲方提出，拒不改正的；
5. 因欺诈、胁迫或者乘人之危致使本合同无效的；
6. 被依法追究刑事责任的。

（二）乙方存在下列情形之一的，甲方提前三十日以书面形式
通知乙方或者额外支付乙方一个月工资后，可以解除本合同：
1. 乙方患病或者非因工负伤，在规定的医疗期满后不能从事
原工作，也不能从事由甲方另行安排的工作的；
2. 乙方不能胜任工作，经过培训或者调整工作岗位，
仍不能胜任工作的；
3. 劳动合同订立时所依据的客观情况发生重大变化，
致使劳动合同无法履行，经甲乙双方协商，未能就变更劳动合同
内容达成协议的。

四、经济性裁员：
因生产经营发生严重困难等法定情形需要裁减人员的，甲方应
提前三十日向工会或者全体职工说明情况，听取工会或者职工的
意见后,裁减人员方案经向劳动行政部门报告，可以裁减人员。

五、劳动合同终止：
（一）劳动合同期满的；
（二）乙方开始依法享受基本养老保险待遇的；
（三）乙方死亡，或者被人民法院宣告死亡或者宣告失踪的；
（四）甲方被依法宣告破产的；
（五）甲方被吊销营业执照、责令关闭、撤销或者甲方决定
提前解散的；
（六）法律、行政法规规定的其他情形。

六、经济补偿：
（一）甲方依据本条第三款第（二）项、第四款解除本合同的，
或者依据本条第五款第（四）（五）项终止本合同的，
应向乙方支付经济补偿；
（二）经济补偿按乙方在本单位工作的年限，每满一年支付
一个月工资的标准向乙方支付；六个月以上不满一年的，
按一年计算；不满六个月的，向乙方支付半个月工资的经济补偿；
（三）经济补偿的月工资标准为乙方在劳动合同解除或者终止前
十二个月的平均工资；
（四）乙方月工资高于甲方所在地上年度职工月平均工资三倍的，
向其支付经济补偿的标准按职工月平均工资三倍的数额支付，
支付年限最高不超过十二年。

七、解除和终止手续：
（一）劳动合同解除或者终止的，甲方应在十五日内为乙方
办理档案和社会保险关系转移手续；
（二）甲方应在解除或者终止劳动合同时出具解除或者终止
劳动合同的证明；
（三）乙方应按照双方约定，办理工作交接；
（四）甲方依法应向乙方支付经济补偿的，在办结工作交接时
支付。
```

**专业术语**
- 劳动合同的解除和终止（两个并列的概念）
- 协商解除（合意解除）
- 单方解除（一方解除）
- 提前三十日以书面形式通知（预告解除期）
- 试用期内提前三日通知（试用期预告期）
- 随时通知解除（即时解除权）
- 劳动保护或者劳动条件（劳动者权益）
- 及时足额支付劳动报酬（工资支付义务）
- 依法缴纳社会保险费（社保缴纳义务）
- 规章制度违反法律法规（无效情形）
- 致使本合同无效（无效后果）
- 立即解除（紧急情况下的解除）
- 不需事先告知（无需预告）
- 在试用期间被证明不符合录用条件（试用期解除条件）
- 严重违反规章制度（过失性解除条件）
- 严重失职，营私舞弊，给甲方造成重大损害（严重过错）
- 同时建立劳动关系（双重劳动关系）
- 被依法追究刑事责任（犯罪）
- 患病或者非因工负伤（疾病）
- 规定的医疗期（法定医疗期）
- 不能胜任工作（能力不足）
- 经过培训或者调整工作岗位（补救措施）
- 客观情况发生重大变化（情势变更）
- 经济性裁员（批量解雇）
- 生产经营发生严重困难（裁员理由）
- 向工会或者全体职工说明情况（民主程序）
- 向劳动行政部门报告（行政程序）
- 劳动合同期满（定期合同终止）
- 开始依法享受基本养老保险待遇（退休）
- 被人民法院宣告死亡或者宣告失踪（法律拟制）
- 被依法宣告破产（破产终止）
- 被吊销营业执照、责令关闭、撤销（行政处罚）
- 经济补偿（解除或终止的补偿）
- 每满一年支付一个月工资（补偿标准）
- 十二个月的平均工资（工资基数）
- 职工月平均工资三倍（封顶标准）
- 支付年限最高不超过十二年（年限封顶）
- 档案和社会保险关系转移（离职手续）
- 出具解除或者终止劳动合同的证明（离职证明）
- 办理工作交接（交接义务）
- 办结工作交接时支付（支付时间）
