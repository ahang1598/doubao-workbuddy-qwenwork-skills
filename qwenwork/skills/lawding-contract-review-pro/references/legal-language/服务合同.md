# 服务合同 标准条款模板


#### 1. 服务内容条款

**规范表述**
```
第X条 服务内容
一、服务方（以下简称"乙方"）应按照本合同约定向委托方（以下简称"甲方"）
提供以下服务：
  （一）【具体服务项目一】；
  （二）【具体服务项目二】；
  （三）【具体服务项目三】。
二、服务的具体内容、技术要求、工作量及交付成果详见本合同附件《服务工作说明
书》（SOW），该附件构成本合同不可分割的组成部分。
三、乙方应按照甲方合理要求提供服务，但甲方不得要求乙方提供超出本合同
约定范围的服务。如需变更或增加服务内容，双方应另行协商并签署书面补充协议。
四、乙方在提供服务过程中形成的工作成果（包括但不限于报告、方案、数据、
软件等），其知识产权归属由本合同第【  】条约定。
五、乙方在履行本合同过程中知悉的甲方商业秘密及技术秘密，乙方负有保密
义务，未经甲方书面同意不得向任何第三方披露或用于本合同以外的目的。
```

**专业术语**
- 服务工作说明书（而非"服务清单""任务表"）
- 补充协议（而非"补充合同""追加协议"）
- 知识产权（而非"版权""创作权"）
- 商业秘密（而非"商业机密""公司秘密"）
- 书面同意（而非"同意""口头允许"）
- 交付成果（而非"成果""工作结果"）

#### 2. 服务标准条款

**规范表述**
```
第X条 服务标准
一、乙方提供的服务应符合以下标准：
  （一）符合国家及行业现行有效的法律法规、技术标准及规范要求；
  （二）符合本合同及附件《服务工作说明书》约定的质量标准和技术要求；
  （三）达到同行业同类服务的通常专业水准；
  （四）符合甲方合理期待的服务质量。
二、乙方应指派具备相应专业资质和能力的人员提供服务。乙方指派的主要
服务人员名单详见附件，未经甲方书面同意，乙方不得擅自更换主要服务人员。
三、甲方有权对乙方的服务质量进行检查和评估。乙方应配合甲方的检查工作，
并按甲方合理要求提供相关工作记录和文件资料。
四、乙方提供的服务不符合约定标准的，甲方有权要求乙方在合理期限内重新
提供服务或采取补救措施。乙方逾期未改正的，甲方有权依据本合同第【  】条
追究乙方违约责任。
五、服务验收标准及程序：
  （一）乙方完成阶段性服务或全部服务后，应向甲方提交书面的服务成果
  及验收申请；
  （二）甲方应在收到验收申请之日起【  】个工作日内完成验收并出具
  书面验收意见；
  （三）甲方逾期未出具验收意见且未提出书面异议的，视为验收合格。
```

**专业术语**
- 专业资质（而非"专业证书""从业资格"）
- 补救措施（而非"弥补办法""修复方案"）
- 验收（而非"检查通过""确认完成"）
- 逾期（而非"超过期限""过期"）
- 阶段性服务（而非"分步骤服务""部分服务"）
- 视为验收合格（而非"默认通过""自动合格"）

#### 3. 服务费用条款

**规范表述**
```
第X条 服务费用及支付
一、本合同服务费用总额为人民币（大写）【金额】元整（¥【金额】），
该费用为【含税/不含税】价格。如为不含税价格，增值税税率为【  】%，
税额为人民币（大写）【金额】元整。
二、服务费用的计算方式为【固定总价/按实际工作量结算/按阶段分期结算】。
具体如下：
  （一）【阶段一/第一期】：人民币【金额】元，于【支付条件】时支付；
  （二）【阶段二/第二期】：人民币【金额】元，于【支付条件】时支付；
  （三）【尾款/质保金】：人民币【金额】元，于【支付条件】时支付。
三、甲方应在约定的付款条件成就后【  】个工作日内，向乙方支付相应款项。
支付方式为银行转账，乙方收款账户信息如下：
  户  名：【  】
  开户行：【  】
  账  号：【  】
四、乙方应在收到服务费用后【  】个工作日内，向甲方开具合法有效的
增值税【专用/普通】发票。
五、甲方逾期支付服务费用的，每逾期一日，应按未付金额的【  】‰向乙方
支付逾期付款违约金。
六、因不可归责于乙方的原因导致服务内容变更、工作量增加的，双方应就
增加的费用另行协商确定。
```

**专业术语**
- 增值税专用发票（而非"发票""税票"）
- 逾期付款违约金（而非"滞纳金""罚金"）
- 质保金（而非"押金""保证金"）
- 付款条件成就（而非"满足付款条件""达到付款要求"）
- 不可归责于（而非"不怪""不是……的责任"）
- 银行转账（而非"打款""转钱"）

#### 4. 服务期限条款

**规范表述**
```
第X条 服务期限
一、本合同服务期限自【起始日期】起至【终止日期】止，共计【  】个
【日历日/工作日/月】。
二、服务的具体时间安排如下：
  （一）【阶段一】：自【  】至【  】，乙方应完成【工作内容】；
  （二）【阶段二】：自【  】至【  】，乙方应完成【工作内容】；
  （三）【阶段三】：自【  】至【  】，乙方应完成【工作内容】。
三、如因甲方原因导致服务期限需要延长，乙方应在合理范围内予以配合，
由此产生的额外费用由甲方承担。延长期限超过原合同服务期限【  】%的，
双方应另行协商并签署补充协议。
四、如因乙方原因导致服务进度滞后，乙方应及时书面通知甲方并提出赶工方案。
因乙方延误造成甲方损失的，乙方应承担相应的违约责任。
五、本合同服务期限届满前【  】日，任何一方如不同意续约，应书面通知
对方。双方同意续约的，应在服务期限届满前另行签署新的服务合同或续约协议。
六、有下列情形之一的，本合同服务期限提前终止：
  （一）双方协商一致解除本合同的；
  （二）因不可抗力导致合同目的不能实现的；
  （三）一方严重违约，经催告后在合理期限内仍未履行的。
```

**专业术语**
- 日历日（而非"天""自然日"）
- 合同目的不能实现（而非"合同没法执行""做不下去了"）
- 催告（而非"催促""通知"）
- 续约（而非"续签""延期合同"）
- 不可抗力（而非"天灾人祸""意外情况"）
- 赶工方案（而非"加急方案""追赶计划"）

#### 5. 违约责任条款

**规范表述**
```
第X条 违约责任
一、乙方有下列情形之一的，构成违约，应承担相应的违约责任：
  （一）未按合同约定的时间提供服务或交付成果的，每逾期一日，应按合同
  总价款的【  】‰向甲方支付违约金；逾期超过【  】日的，甲方有权
  解除本合同；
  （二）提供的服务不符合约定标准，经甲方书面通知后【  】日内仍未
  改正的，甲方有权要求乙方减少服务费用或解除本合同；
  （三）违反保密义务的，应向甲方支付合同总价款【  】%的违约金，
  违约金不足以弥补甲方损失的，乙方还应赔偿甲方的实际损失；
  （四）擅自将服务转委托第三方的，甲方有权解除本合同并要求乙方支付
  合同总价款【  】%的违约金。
二、甲方有下列情形之一的，构成违约，应承担相应的违约责任：
  （一）未按合同约定支付服务费用的，按本合同第【  】条约定支付逾期
  付款违约金；
  （二）未按约定提供必要的协助和工作条件，导致乙方无法正常提供服务的，
  服务期限相应顺延，甲方不得追究乙方的延期责任。
三、违约方支付的违约金不足以弥补守约方实际损失的，违约方还应就不足部分
予以赔偿。
四、双方均违约的，各自承担相应的违约责任。
五、因不可抗力致使不能履行本合同的，根据不可抗力的影响，部分或者全部
免除责任，但法律另有规定的除外。受不可抗力影响的一方应在不可抗力事件
发生后【  】日内书面通知对方，并在【  】日内提供有关证明文件。
```

**专业术语**
- 违约金（而非"罚款""赔偿金"）
- 守约方（而非"没违约的一方""遵守合同的一方"）
- 转委托（而非"转包""外包"）
- 实际损失（而非"真实损失""直接损失"）
- 顺延（而非"推迟""延后"）
- 免除责任（而非"不负责任""不用担责"）
