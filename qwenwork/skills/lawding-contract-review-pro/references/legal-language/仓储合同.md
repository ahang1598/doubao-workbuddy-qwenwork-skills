# 仓储合同 标准条款模板


#### 1. 仓储物条款

**规范表述**
```
第X条 仓储物
一、存货人存储的仓储物基本信息：
  （一）仓储物名称：【名称】；
  （二）仓储物品种：【品种】；
  （三）仓储物规格：【规格型号】；
  （四）仓储物数量：【数量】【计量单位】；
  （五）仓储物质量：符合【国家标准/行业标准/约定标准】；
  （六）仓储物包装：【包装方式及要求】；
  （七）仓储物价值：人民币【大写金额】元整（¥【数字金额】元）。
二、仓储物的性质说明：
  （一）仓储物属于【普通货物/特殊货物】；
  （二）仓储物是否属于易燃、易爆、有毒、有腐蚀性、有放射性等危险物品
  或者易变质物品：【是/否】；
  （三）存货人存储危险物品或者易变质物品的，应当说明该物品的性质，提供
  有关资料，并应当符合法律、行政法规以及国家有关主管部门的规定。
三、仓储物权利状况：
  （一）存货人保证对仓储物享有合法的处分权，仓储物不存在权利瑕疵；
  （二）仓储物不涉及第三方权利主张、司法查封、扣押或者其他权利限制；
  （三）因存货人未如实说明仓储物权利状况而给保管人造成损失的，存货人
  应当承担赔偿责任。
四、保管人验收仓储物时，发现入库仓储物与约定不符的，应当及时通知存货人。
```

**专业术语**
- 仓储物（而非"货物""存放的东西"）
- 存货人（而非"客户""存货方""货主"）
- 保管人（而非"仓库方""仓储方""仓库公司"）
- 权利瑕疵（而非"产权问题""所有权纠纷"）
- 处分权（而非"处理权""所有权"）
- 危险物品（而非"危险品""有害物品"）

#### 2. 储存条件条款

**规范表述**
```
第X条 储存条件
一、仓储场所及设施：
  （一）仓储场所地址：【详细地址】；
  （二）仓库编号：【编号】；
  （三）仓储面积：【  】平方米；
  （四）仓库类型：【常温库/恒温库/冷藏库/冷冻库/危险品仓库/
  其他专用仓库】。
二、储存环境要求：
  （一）温度要求：【  】℃至【  】℃；
  （二）湿度要求：【  】%至【  】%RH；
  （三）通风要求：【自然通风/机械通风/密封储存】；
  （四）光照要求：【避光储存/无特殊要求】；
  （五）其他特殊储存条件：【具体要求】。
三、保管人应当按照约定的储存条件储存仓储物，并履行以下义务：
  （一）配备符合标准的仓储设施设备，保持仓库及设施设备的完好与
  正常运行；
  （二）定期检查、监测储存环境，确保温度、湿度等指标符合约定标准；
  （三）做好防火、防盗、防潮、防鼠、防虫等安全防护措施；
  （四）建立仓储物日常巡查制度，发现仓储物有变质或者其他损坏的，
  应当及时通知存货人并采取必要的救济措施。
四、保管人变更储存场所或者储存条件的，应当事先征得存货人的书面同意。
五、因保管人保管不善造成仓储物毁损、灭失的，保管人应当承担赔偿责任。
```

**专业术语**
- 储存条件（而非"存放条件""保存环境"）
- 毁损灭失（而非"损坏丢失""弄坏弄丢"）
- 保管不善（而非"管理不当""没保管好"）
- 救济措施（而非"补救措施""抢救措施"）
- 仓储设施设备（而非"仓库设备""存储设施"）

#### 3. 仓储费条款

**规范表述**
```
第X条 仓储费
一、仓储费的计算标准：
  （一）计费方式：【按面积计费/按重量计费/按体积计费/按件计费/
  综合计费】；
  （二）计费单价：每【计量单位】每【日/月】人民币【  】元；
  （三）计费起始日：自仓储物验收入库之日起计算；
  （四）最低计费期限：【  】【日/月】。
二、仓储费包含的服务内容：
  （一）仓储物的保管及日常维护；
  （二）仓储场所的安全防范管理；
  （三）储存环境的维护与监控；
  （四）【其他包含的服务内容】。
三、下列费用不包含在仓储费内，由存货人另行支付：
  （一）仓储物的装卸搬运费用；
  （二）仓储物的保险费用；
  （三）特殊包装或者加固处理费用；
  （四）超出约定储存条件的特殊要求产生的额外费用；
  （五）【其他另行收取的费用项目及标准】。
四、仓储费的支付：
  （一）支付周期：【月付/季付/半年付/年付/一次性支付】；
  （二）支付时间：每个支付周期届满后【  】个工作日内；
  （三）支付方式：【银行转账/其他】；
  （四）保管人收款账户信息：
    开户行：【银行名称】
    户  名：【账户名称】
    账  号：【银行账号】
五、存货人逾期支付仓储费的，每逾期一日应当按照未付金额的【  】‰向
保管人支付违约金。
六、保管人对入库仓储物享有留置权。存货人逾期未支付仓储费的，保管人可以
依法对仓储物行使留置权，但当事人另有约定的除外。
```

**专业术语**
- 仓储费（而非"仓租""保管费""存货费"）
- 留置权（而非"扣押权""扣货权"）
- 装卸搬运（而非"上货卸货""搬货"）
- 验收入库（而非"进仓""货物进来"）
- 计费起始日（而非"开始算钱的日子""收费起始"）

#### 4. 出入库条款

**规范表述**
```
第X条 仓储物出入库
一、入库：
  （一）存货人交付仓储物时，保管人应当按照约定对仓储物进行验收，验收
  内容包括：
    1. 仓储物的名称、品种、规格与本合同约定是否一致；
    2. 仓储物的数量、重量是否与交付凭证相符；
    3. 仓储物的外包装是否完好；
    4. 仓储物的质量外观是否存在明显瑕疵。
  （二）验收期限：保管人应当在仓储物到达仓库之日起【  】个工作日内
  完成验收；
  （三）验收合格后，保管人应当向存货人出具仓单或者入库单作为入库凭证；
  （四）验收中发现仓储物与约定不符的，保管人应当及时书面通知存货人，
  由存货人在【  】个工作日内处理。
二、仓单：
  （一）保管人应当在仓储物验收入库后，按照存货人的要求签发仓单；
  （二）仓单应当载明法定事项，包括：存货人的姓名或者名称和住所、仓储物
  的品种和数量等基本信息、储存场所、储存期限、仓储费、保险情况、
  填发人及填发日期等；
  （三）仓单是提取仓储物的凭证，存货人或者仓单持有人凭仓单提取仓储物。
三、出库：
  （一）存货人或者仓单持有人提取仓储物时，应当凭仓单或者出库凭证向
  保管人提取；
  （二）保管人应当按照仓单或者出库凭证的记载交付仓储物，并对出库仓储物
  进行复核；
  （三）提货时间：【工作日】的【  】时至【  】时；
  （四）出库交付地点：仓储场所的【具体交付地点】。
四、存货人或者仓单持有人在仓单或者出库凭证上签字或者盖章，保管人的交付
义务即告完成。
五、仓储物的堆码苫垫、检查盘点以及出入库作业中产生的正常损耗，按照
【国家标准/行业惯例/双方约定】的合理损耗率【  】‰以内由保管人自行承担，
超出部分由责任方承担。
```

**专业术语**
- 仓单（而非"仓库单据""仓库收据""提货单"）
- 入库凭证（而非"入库单""入库证明"）
- 出库凭证（而非"出库单""提货凭证"）
- 堆码苫垫（而非"堆放垫底""码放"）
- 正常损耗（而非"自然损耗""正常损失"）
- 仓单持有人（而非"持单人""拿单子的人"）

#### 5. 损害赔偿条款

**规范表述**
```
第X条 损害赔偿
一、保管人的赔偿责任：
  （一）保管人验收时未对仓储物的数量、毁损提出异议的，推定仓储物与
  仓单记载一致；
  （二）储存期内因保管人保管不善造成仓储物毁损、灭失的，保管人应当
  承担赔偿责任；
  （三）因仓储物本身的自然性质、包装不符合约定或者超过有效储存期造成
  仓储物变质、损坏的，保管人不承担赔偿责任；
  （四）因不可抗力造成仓储物毁损、灭失的，保管人不承担赔偿责任，但
  保管人未采取必要救济措施致使损失扩大的，应当就扩大部分承担赔偿责任。
二、赔偿范围与标准：
  （一）仓储物全部毁损或者灭失的，按照仓储物入库时双方确认的价值赔偿；
  未确认价值的，按照交付时的市场价格计算赔偿金额；
  （二）仓储物部分毁损的，按照毁损程度和仓储物价值的相应比例计算
  赔偿金额；
  （三）因仓储物毁损、灭失给存货人造成的其他合理损失，包括但不限于
  停产损失、利润损失等间接损失的赔偿，以人民币【大写金额】元整
  （¥【数字金额】元）为上限；
  （四）保管人的赔偿总额不超过仓储物入库时确认价值的【  】%。
三、存货人的赔偿责任：
  （一）存货人未按照约定对仓储物进行包装或者包装不符合约定，造成仓储物
  损坏的，由存货人自行承担损失；
  （二）存货人存储危险物品或者易变质物品未履行如实告知义务，造成保管人
  损失的，存货人应当承担赔偿责任；
  （三）因仓储物本身的缺陷造成保管人或者第三人财产损害、人身伤害的，
  存货人应当依法承担赔偿责任。
四、仓储物的保险：
  （一）存货人应当自行为仓储物投保【财产一切险/仓储物综合险/其他险种】，
  保险金额不低于仓储物价值的【  】%；
  （二）保管人应当为仓库及仓储经营活动投保相应的责任保险；
  （三）发生保险事故的，理赔所得优先用于弥补仓储物损失。
五、损害赔偿的通知与索赔期限：
  （一）任何一方发现仓储物发生毁损、灭失的，应当在发现之日起【  】
  小时内书面通知对方；
  （二）索赔方应当在知道或者应当知道仓储物毁损、灭失之日起【  】日内
  向对方提出书面索赔，并提供损失证明材料；
  （三）超过上述索赔期限未提出书面索赔的，视为放弃索赔权利，但法律
  另有规定的除外。
```

**专业术语**
- 毁损灭失（而非"损坏丢失""弄坏弄没"）
- 不可抗力（而非"天灾人祸""意外情况"）
- 保管不善（而非"看管不力""管理不当"）
- 有效储存期（而非"保质期""存放期限"）
