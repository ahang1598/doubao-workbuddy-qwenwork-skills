# 委托合同 标准条款模板


#### 1. 委托事务条款

**规范表述**
```
第X条 委托事务
一、委托人（以下简称"甲方"）委托受托人（以下简称"乙方"）处理以下事务：
  （一）事务名称：【  】；
  （二）事务内容：【具体委托事项的详细描述】；
  （三）事务目的：【  】；
  （四）事务要求：【完成标准、时限要求等】。
二、乙方应当按照甲方的指示处理委托事务。需要变更甲方指示的，乙方应当
经甲方同意；因情况紧急，难以和甲方取得联系的，乙方应当妥善处理委托事务，
但事后应当将该情况及时报告甲方。
三、乙方应当亲自处理委托事务。经甲方同意，乙方可以转委托。转委托经甲方
同意或者追认的，甲方可以就委托事务直接指示转委托的第三人，乙方仅就第三人
的选任及其对第三人的指示承担责任。转委托未经甲方同意或者追认的，乙方应当
对转委托的第三人的行为承担责任。
四、乙方处理委托事务取得的财产，应当转交给甲方。
五、乙方应当按照甲方要求，定期或不定期地报告委托事务的处理情况。
委托事务完成后，乙方应当向甲方报告委托事务的处理结果并提交必要的文件
资料。具体报告周期为每【  】日/周/月提交一次书面报告。
```

**专业术语**
- 委托人（而非"委托方""托付方"）
- 受托人（而非"受委托方""被托付方""代理方"）
- 转委托（而非"再委托""二次委托""分包"）
- 选任（而非"挑选""选择"）
- 追认（而非"事后同意""补认"）
- 指示（而非"要求""吩咐""安排"）

#### 2. 委托权限条款

**规范表述**
```
第X条 委托权限
一、甲方授予乙方的委托权限为【一般委托/特别委托】。
二、一般委托权限范围：乙方有权就委托事务实施一般性管理行为和保存行为，
包括但不限于：
  （一）【具体权限事项一】；
  （二）【具体权限事项二】；
  （三）【具体权限事项三】。
三、特别委托权限（如适用）：经甲方特别授权，乙方有权就委托事务实施以下
处分行为：
  （一）【如：代为签署合同】；
  （二）【如：代为收取或支付款项】；
  （三）【如：代为提起诉讼或申请仲裁】。
四、乙方超越委托权限处理事务的，未经甲方追认，对甲方不发生效力，由此
给甲方造成损失的，乙方应承担赔偿责任。但第三人有理由相信乙方有代理权的，
该代理行为有效，甲方可以就由此受到的损失向乙方追偿。
五、甲方可以根据需要调整乙方的委托权限，但应及时书面通知乙方。甲方缩小
委托权限的通知到达乙方之前，乙方在原权限范围内所实施的行为对甲方仍然
有效。
六、委托事务涉及以甲方名义与第三人进行法律行为的，甲方应向乙方出具
授权委托书，载明代理事项、权限及期间。
```

**专业术语**
- 一般委托（而非"普通委托""通常授权"）
- 特别委托（而非"特殊委托""特别授权"）
- 处分行为（而非"处理行为""重要事项"）
- 表见代理（而非"看起来有权代理""第三人以为有权"）
- 授权委托书（而非"委托书""授权书""授权函"）
- 不发生效力（而非"无效""不算数""不管用"）

#### 3. 报酬条款

**规范表述**
```
第X条 报酬
一、本合同为【有偿/无偿】委托合同。
二、有偿委托的，甲方应向乙方支付委托报酬人民币（大写）【金额】元整
（¥【金额】）。报酬的计算方式为【固定金额/按委托事务处理结果的一定
比例计算/按实际工时计算】。
三、报酬支付时间及方式：
  （一）甲方应于【委托事务完成后/每月  日/每季度末】向乙方支付报酬；
  （二）支付方式为银行转账，转入乙方指定账户；
  （三）乙方应在收到报酬后【  】个工作日内开具合法有效的发票。
四、因不可归责于乙方的事由，委托合同解除或者委托事务不能完成的，
甲方应当向乙方支付相应的报酬。当事人另有约定的，按照其约定。
五、乙方违反委托合同约定义务，导致委托事务未能完成或处理结果不符合
约定的，甲方有权相应减少或拒绝支付报酬。因乙方过错给甲方造成损失的，
甲方有权从应付报酬中抵扣相应的损失赔偿额。
六、无偿委托的，乙方因处理委托事务所受到的损失，除因乙方自身故意或
重大过失造成的以外，甲方应予以赔偿。
```

**专业术语**
- 有偿委托（而非"收费委托""付费委托"）
- 无偿委托（而非"免费委托""义务委托"）
- 不可归责于（而非"不怨""不能怪"）
- 重大过失（而非"严重失误""重大错误"）
- 抵扣（而非"扣除""扣减""减掉"）
- 相应的报酬（而非"部分报酬""应得的钱"）

#### 4. 费用承担条款

**规范表述**
```
第X条 费用承担
一、乙方处理委托事务所支出的必要费用由甲方承担。必要费用包括但不限于：
  （一）交通费及差旅费；
  （二）通讯费及邮寄费；
  （三）资料查询费及复印费；
  （四）为处理委托事务而依法缴纳的税费、规费；
  （五）其他经甲方事先书面同意的合理费用。
二、费用的预付与结算：
  （一）甲方应在本合同签订后【  】个工作日内，向乙方预付费用人民币
  【金额】元，用于委托事务处理的日常开支；
  （二）乙方应如实记录费用支出情况，并保留相关票据和凭证；
  （三）委托事务完成或本合同终止后【  】个工作日内，乙方应向甲方
  提交费用结算清单及相应票据凭证，双方进行费用清算；
  （四）预付费用不足的，甲方应在收到乙方书面通知后【  】个工作日内
  补足；预付费用有剩余的，乙方应在费用清算后【  】个工作日内退还甲方。
三、下列费用不属于必要费用，由乙方自行承担：
  （一）因乙方过错导致的额外支出；
  （二）未经甲方事先同意的超标准支出；
  （三）乙方的日常经营管理费用。
四、乙方为处理委托事务垫付必要费用的，有权请求甲方偿还该费用并支付
自垫付之日起的利息，利率按照同期全国银行间同业拆借中心公布的贷款市场
报价利率（LPR）执行。
```

**专业术语**
- 必要费用（而非"需要的费用""必须花的钱"）
- 预付（而非"先付""提前支付"）
- 费用清算（而非"费用结算""对账""算账"）
- 垫付（而非"先垫""代付"）
- 规费（而非"政府费用""行政收费"）
- 贷款市场报价利率（LPR）（而非"银行利率""基准利率"）

#### 5. 委托终止条款

**规范表述**
```
第X条 委托的终止
一、有下列情形之一的，委托合同终止：
  （一）委托事务已经完成；
  （二）委托期限届满；
  （三）甲方撤销委托；
  （四）乙方辞去委托；
  （五）甲方或乙方死亡、丧失民事行为能力或被宣告破产；
  （六）双方协商一致解除本合同；
  （七）法律规定的其他情形。
二、甲方撤销委托的：
  （一）甲方可以随时撤销委托。有偿委托的，因甲方撤销委托给乙方造成
  损失的，除不可归责于甲方的事由外，甲方应当赔偿乙方的直接损失及合理
  的预期利益损失；
  （二）甲方撤销委托应提前【  】日书面通知乙方，以便乙方妥善处理
  未竟事务。
三、乙方辞去委托的：
  （一）乙方可以随时辞去委托。有偿委托的，因乙方辞去委托给甲方造成
  损失的，除不可归责于乙方的事由外，乙方应当赔偿甲方的损失；
  （二）乙方辞去委托应提前【  】日书面通知甲方。
四、委托终止后的事务处理：
  （一）乙方应在委托终止后【  】个工作日内向甲方移交委托事务的
  全部文件资料、财产及处理成果；
  （二）甲方应在收到移交材料后【  】个工作日内完成费用结算及报酬
  支付（如适用）；
  （三）因委托合同终止给对方造成损失的，除不可归责于该当事人的事由
  外，应当赔偿损失。
五、因甲方死亡或者丧失民事行为能力导致委托终止的，乙方在甲方的继承人、
遗产管理人或者监护人承受委托事务之前，应当继续处理委托事务以维护甲方
及其继承人的利益。
```

**专业术语**
- 撤销委托（而非"取消委托""撤回委托"）
- 辞去委托（而非"不干了""退出委托""拒绝继续"）
- 未竟事务（而非"没完成的事""剩余事项"）
- 移交（而非"交接""交还"）
- 遗产管理人（而非"遗产继承人""管遗产的人"）
- 监护人（而非"法定代理人""监管人""照顾人"）
