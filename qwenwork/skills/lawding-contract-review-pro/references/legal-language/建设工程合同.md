# 建设工程合同 标准条款模板


#### 1. 工程范围条款

**规范表述**
```
第X条 工程概况
一、工程名称：【】。

二、工程地点：【具体地址】。

三、工程内容：【工程内容简述】，详见本合同附件《工程量清单》
和《施工图纸》。

四、承包范围：【包工包料/包工不包料/包料不包工】。

五、承包方式：【总承包/专业分包】。

六、工程规模：
（一）建筑面积：【】平方米；
（二）建筑层数：地上【】层，地下【】层；
（三）建筑高度：【】米；
（四）结构形式：【】。
```

**专业术语**
- 工程概况（而非"工程情况"）
- 工程地点（而非"施工地点"）
- 承包范围（明确承包的工作内容）
- 承包方式（总承包、分包的法定分类）
- 包工包料（建设工程术语）
- 工程量清单（标准文件名称）
- 施工图纸（而非"图纸"）
- 建筑面积（专业术语）
- 结构形式（钢筋混凝土/钢结构等）

#### 2. 工期条款

**规范表述**
```
第X条 工期
一、开工日期：【年月日】。承包人应在开工日期前做好开工准备，
并于开工当日进场施工。

二、竣工日期：【年月日】。承包人应在竣工日期前完成全部工程，
并达到竣工验收条件。

三、工期总日历天数：【】天（自开工之日起计算）。

四、工期顺延：
因下列原因导致工期延误的，经发包人确认后，工期相应顺延：
（一）发包人未按约定提供施工条件、施工场地、图纸、资金等，
造成停工或窝工的；
（二）工程量发生重大变更，导致工期延长的；
（三）不可抗力导致施工中断的；
（四）发包人要求暂停施工的；
（五）其他非承包人原因造成的工期延误。

五、顺延程序：
（一）发生工期顺延事由后，承包人应在【】日内书面通知发包人，
并提交顺延工期的申请；
（二)发包人应在收到申请后【】日内予以确认或提出异议；
（三）发包人逾期未确认也未提出异议的，视为同意工期顺延。
```

**专业术语**
- 开工日期、竣工日期（而非"开始时间"、"结束时间"）
- 工期总日历天数（而非"工期"，明确计算方式）
- 工期顺延（而非"工期延长"）
- 停工、窝工（建设工程术语）
- 工程量变更（而非"工程变化"）
- 不可抗力（法定免责事由）
- 工期顺延事由（导致顺延的原因）

#### 3. 工程价款条款

**规范表述**
```
第X条 工程价款及支付
一、价款构成：
（一）工程总价款为人民币【大写】元整（¥【小写】元）；
（二）价款构成：
1. 直接费：人民币【】元；
2. 间接费：人民币【】元；
3. 利润：人民币【】元；
4. 税金：人民币【】元（税率为【】%）。

二、计价方式：【固定总价/固定单价/可调价格】。

三、价款调整：
（一）固定总价合同，合同价款不予调整，但下列情况除外：
1. 发包人要求变更工程设计、施工方案的；
2. 工程量发生重大变化的（增减超过【】%）；
3. 国家法律法规、政策调整导致成本重大变化的。

（二）价款调整程序：
1. 承包人应在价款调整事由发生后【】日内提出调整申请；
2. 发包人应在收到申请后【】日内予以确认；
3. 双方协商确定调整金额，签订补充协议。

四、支付方式：
（一）预付款：合同签订后【】日内，发包人向承包人支付工程
总价款的【】%作为预付款，计人民币【大写】元整（¥【小写】元）；

（二）进度款：
1. 承包人每月【】日前向发包人提交当月完成的工程量及
《工程进度款支付申请》；
2. 发包人收到申请后【】日内审核确认；
3. 发包人应在确认后【】日内向承包人支付进度款；
4. 进度款支付比例为当期完成工程量对应价款的【】%；
5. 预付款在进度款中按比例扣回。

（三）竣工结算款：
1. 工程竣工验收合格后【】日内，承包人向发包人提交
《工程竣工结算书》；
2. 发包人应在收到结算书后【】日内完成审核并与承包人
办理竣工结算；
3. 竣工结算完成后【】日内，发包人向承包人支付至结算
总价款的【】%；
4. 剩余【】%作为质量保证金。

（四）质量保证金：
1. 质保期满且无质量问题的，发包人应在质保期满后【】日内
向承包人退还质量保证金；
2. 质保期内发生质量问题的，承包人应在【】日内负责维修；
维修费用从质量保证金中扣除；
3. 质量保证金不计利息。

五、支付账户：
户名：【】
开户行：【】
账号：【】
```

**专业术语**
- 工程价款（而非"工程款"）
- 价款构成（直接费、间接费、利润、税金）
- 计价方式（固定总价、固定单价、可调价格）
- 价款调整（而非"价格变更"）
- 预付款（而非"定金"）
- 进度款（按进度支付的价款）
- 工程量（而非"工作量"）
- 工程进度款支付申请（规范文件名称）
- 竣工结算（而非"工程结算"）
- 工程竣工结算书（规范文件名称）
- 质量保证金/质保金（而非"保证金"）
- 质保期（质量保证期的简称）

#### 4. 竣工验收条款

**规范表述**
```
第X条 竣工验收
一、竣工验收条件：
承包人完成全部工程内容，并满足以下条件的，具备竣工验收条件：
（一）完成合同约定的全部工程内容；
（二）工程质量符合国家和行业标准以及合同约定；
（三）有完整的工程技术档案和施工管理资料；
（四）有工程使用的主要建筑材料、建筑构配件和设备的进场
试验报告；
（五）有设计、勘察、施工、监理等单位分别签署的质量合格文件。

二、竣工验收程序：
（一）承包人自检合格后，向发包人提交《工程竣工验收报告》；
（二）发包人应在收到报告后【】日内组织竣工验收；
（三）发包人组织设计、勘察、施工、监理等单位进行验收；
（四）验收合格的，参与验收的单位签署《工程竣工验收备案表》；
（五）发包人应在竣工验收合格后【】日内办理竣工验收备案手续。

三、竣工验收不合格：
（一）工程竣工验收不合格的，承包人应在【】日内进行整改，
整改完成后重新申请验收；
（二）因承包人原因导致验收不合格的，整改费用由承包人承担，
工期不予顺延。

四、竣工日期：
（一）工程经竣工验收合格的，以竣工验收合格之日为竣工日期；
（二）承包人已提交竣工验收报告，发包人无正当理由逾期不组织
验收的，以承包人提交验收报告之日为竣工日期；
（三）工程未经竣工验收，发包人擅自使用的，以转移占有工程之日
为竣工日期。
```

**专业术语**
- 竣工验收（而非"完工验收"）
- 竣工验收条件（法定和约定的验收前提）
- 工程技术档案（而非"施工资料"）
- 建筑材料、建筑构配件（专业术语）
- 进场试验报告（质量控制文件）
- 质量合格文件（验收必备文件）
- 工程竣工验收报告（规范文件名称）
- 工程竣工验收备案表（法定文件）
- 竣工验收备案（行政管理程序）
- 竣工日期（而非"完工日期"）
- 转移占有（法律术语，表示实际控制）

#### 5. 质量保证条款

**规范表述**
```
第X条 工程质量及质量保证
一、质量标准：
（一）工程质量应符合国家标准【标准号】、行业标准【标准号】
以及合同约定；
（二）工程质量等级为【合格/优良/优质】。

二、质量保证期：
（一）基础设施工程、房屋建筑的地基基础工程和主体结构工程，
质量保证期为设计文件规定的该工程的合理使用年限；
（二）屋面防水工程、有防水要求的卫生间、房间和外墙面的防渗漏，
质量保证期为【】年；
（三）供热与供冷系统，质量保证期为【】个采暖期、供冷期；
（四）电气管线、给排水管道、设备安装和装修工程，
质量保证期为【】年；
（五）其他工程的质量保证期由双方约定为【】年。

三、质量保证责任：
（一）质量保证期内，工程出现质量缺陷的，承包人应在接到通知后
【】日内进行维修；
（二)因承包人原因造成的质量缺陷，维修费用由承包人承担；
（三）因发包人使用不当造成的质量缺陷，维修费用由发包人承担；
（四）因第三人原因或不可抗力造成的质量缺陷，维修费用由
责任方承担。

四、质量争议：
（一）对工程质量发生争议的，双方同意委托【检测机构名称】
进行检测；
（二）检测结果证明工程质量不符合约定的，检测费用由承包人承担；
（三）检测结果证明工程质量符合约定的，检测费用由发包人承担。
```

**专业术语**
- 工程质量（而非"施工质量"）
- 质量标准（国家标准、行业标准）
- 质量等级（合格、优良、优质）
- 质量保证期（而非"保修期"，虽然实务中常混用）
- 基础设施工程（专业分类）
- 地基基础工程和主体结构工程（关键部位）
- 合理使用年限（设计年限）
- 屋面防水工程（专业术语）
- 防渗漏（而非"防漏水"）
- 采暖期、供冷期（特殊工程的时间单位）
- 电气管线、给排水管道（专业术语）
- 质量缺陷（而非"质量问题"）
