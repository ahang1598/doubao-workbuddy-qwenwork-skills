# 中介合同 标准条款模板


#### 1. 中介服务条款

**规范表述**
```
第X条 中介服务内容与方式
一、中介人应当按照本合同约定，为委托人提供以下中介服务：
  （一）向委托人报告订立合同的机会；
  （二）为委托人与第三人订立【合同类型】合同提供媒介服务；
  （三）就交易事项向委托人如实提供相关信息，包括但不限于：
    1. 交易标的的权属状况、现状及瑕疵情况；
    2. 交易对方的基本信息及资信状况；
    3. 市场行情及交易价格参考依据。
二、中介服务的期限自【起始日期】起至【终止日期】止。中介人应当在上述
期限内完成中介服务事项。
三、中介人提供中介服务时，应当遵循诚实信用原则，不得隐瞒与订立合同有关
的重要事实或者提供虚假情况，损害委托人利益。
四、委托人应当按照中介人的合理要求，提供与中介事项有关的真实、完整信息
及必要的协助。
```

**专业术语**
- 中介人（而非"中间人""介绍人"）
- 委托人（而非"客户""甲方"）
- 媒介服务（而非"牵线搭桥""撮合"）
- 报告订立合同的机会（而非"介绍生意""推荐买家"）
- 资信状况（而非"信用情况""靠不靠谱"）
- 权属状况（而非"归谁所有""产权情况"）

#### 2. 报酬条款

**规范表述**
```
第X条 中介报酬
一、中介人促成合同成立的，委托人应当按照下列标准支付中介报酬：
  （一）报酬计算方式：【固定金额/按交易金额的百分比计算】；
  （二）报酬金额或比例：【具体金额】元/交易金额的【  】%；
  （三）报酬总额上限为人民币【大写金额】元整（¥【数字金额】元）。
二、中介报酬的支付时间与方式：
  （一）委托人应当在合同促成之日起【  】个工作日内支付中介报酬；
  （二）支付方式为【银行转账/现金/其他】，中介人收款账户信息如下：
    开户行：【银行名称】
    户  名：【账户名称】
    账  号：【银行账号】
三、因中介人提供订立合同的媒介服务而促成合同成立的，由该合同的当事人
平均负担中介报酬，但当事人另有约定的除外。
四、中介人未促成合同成立的，不得请求支付中介报酬。但委托人为故意阻碍
中介人的中介活动而直接与第三人订立合同的，应当向中介人支付中介报酬。
五、中介人违反诚实信用原则，损害委托人利益的，不得请求支付中介报酬并
应当承担赔偿责任。
```

**专业术语**
- 中介报酬（而非"中介费""佣金""提成"）
- 促成合同成立（而非"谈成了""交易完成"）
- 媒介服务（而非"介绍服务""中间服务"）
- 请求支付（而非"要求给钱""收取"）
- 故意阻碍中介活动（而非"跳单""飞单"）

#### 3. 费用条款

**规范表述**
```
第X条 中介活动费用
一、中介人从事中介活动支出的必要费用包括但不限于：
  （一）信息查询及调查核实费用；
  （二）交通、通讯等直接费用；
  （三）广告宣传及推介费用；
  （四）其他为完成中介服务所产生的合理费用。
二、中介人促成合同成立的，中介活动的费用由中介人自行负担，但当事人另有
约定的除外。
三、中介人未促成合同成立的，可以请求委托人支付从事中介活动支出的合理
费用，具体约定如下：
  （一）费用结算方式：【据实结算/包干制/上限制】；
  （二）费用上限为人民币【大写金额】元整（¥【数字金额】元）；
  （三）中介人应当在请求支付费用时，提供相应的费用明细及票据凭证。
四、委托人应当在收到中介人费用结算单据之日起【  】个工作日内完成费用
支付。
```

**专业术语**
- 必要费用（而非"成本""开销"）
- 据实结算（而非"花多少算多少""实报实销"）
- 票据凭证（而非"发票收据""报销单"）
- 费用负担（而非"谁出钱""费用承担"）

#### 4. 中介人义务条款

**规范表述**
```
第X条 中介人义务
一、如实报告义务：中介人应当就有关订立合同的事项向委托人如实报告，不得
故意隐瞒与订立合同有关的重要事实或者提供虚假情况。如实报告的事项包括但
不限于：
  （一）交易标的的真实状况、权利瑕疵及法律风险；
  （二）交易相对方的主体资格、履约能力及信用状况；
  （三）与交易有关的市场信息及政策法规变化。
二、忠实义务：中介人应当忠实于委托人利益，不得利用中介活动损害委托人
利益，不得在同一中介事项中为双方当事人提供相互冲突的中介服务。
三、保密义务：中介人对在中介活动中知悉的委托人商业秘密、个人信息及其他
不愿公开的信息，负有保密义务。保密期限自本合同终止之日起【  】年。
四、勤勉义务：中介人应当以合理的技能和注意，积极寻找交易机会，尽力促成
交易达成。
五、中介人违反上述义务，给委托人造成损失的，应当依法承担赔偿责任，并
无权请求支付中介报酬。
```

**专业术语**
- 如实报告义务（而非"说实话的义务""告知义务"）
- 权利瑕疵（而非"产权问题""权利有毛病"）
- 忠实义务（而非"忠诚义务""不能害客户"）
- 勤勉义务（而非"认真干活""尽心尽力"）
- 商业秘密（而非"商业机密""公司秘密"）
- 主体资格（而非"是否合法""有没有资质"）
