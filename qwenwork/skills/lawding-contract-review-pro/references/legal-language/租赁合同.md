# 租赁合同 标准条款模板


#### 1. 租赁物条款

**规范表述**
```
第X条 租赁物
一、租赁物坐落：【省市区县街道门牌号】。

二、租赁面积：建筑面积【】平方米（以房产证记载为准）。

三、房屋权属：该房屋的所有权人为甲方，甲方已取得该房屋的
房地产权证，证号为【】，有权出租该房屋。

四、房屋现状：租赁物现状为【毛坯/简装/精装】，
附属设施设备详见本合同附件《房屋及附属设施设备清单》。
```

**专业术语**
- 租赁物（而非"出租房"、"房子"）
- 坐落（而非"位置"、"地址"）
- 所有权人（而非"房主"、"业主"）
- 有权出租（明确出租权）

#### 2. 租赁期限条款

**规范表述**
```
第X条 租赁期限
一、租赁期限自【年月日】起至【年月日】止，共计【】年【】个月。

二、租赁期限届满，本合同终止。甲方收回租赁物，乙方应返还
租赁物。

三、续租：租赁期限届满前【】日，乙方如需继续租赁，
应书面通知甲方，双方协商一致后续签租赁合同。在同等条件下，
乙方享有优先承租权。
```

**专业术语**
- 租赁期限（而非"租期"）
- 租赁期限届满（而非"到期"）
- 合同终止（而非"合同结束"）
- 收回租赁物（而非"收回房子"）
- 返还租赁物（而非"归还房子"）
- 优先承租权（法定权利）

#### 3. 租金条款

**规范表述**
```
第X条 租金及支付方式
一、租金标准：
（一）月租金为人民币【大写】元整（¥【小写】元）；
（二）年租金为人民币【大写】元整（¥【小写】元）。

二、支付方式：
（一）乙方应于每【月/季度/年】【首日/末日】前支付租金；
（二）首期租金应于本合同签订后【】日内支付。

三、租金调整：
（一）租赁期内前【】年租金保持不变；
（二）自第【】年起，租金按照【固定金额/固定比例/市场价格】
调整，调整后的租金由双方协商确定。

四、支付账户：
户名：【】
开户行：【】
账号：【】
```

**专业术语**
- 租金（而非"房租"）
- 租金标准（而非"租金价格"）
- 支付方式（明确时间、地点、方式）
- 租金调整（而非"涨租"）

#### 4. 用途条款

**规范表述**
```
第X条 租赁物用途
一、租赁用途：乙方租赁该房屋用于【住宅/办公/商业/仓储等】，
未经甲方书面同意，乙方不得擅自改变租赁用途。

二、禁止事项：乙方不得利用租赁物从事违法犯罪活动或者
违背公序良俗的活动。

三、违反后果：乙方擅自改变租赁用途或者从事禁止事项的，
甲方有权解除合同，乙方应承担违约责任。
```

**专业术语**
- 租赁用途（而非"用途"）
- 擅自改变（强调未经许可）
- 违背公序良俗（法律术语）

#### 5. 维修义务条款

**规范表述**
```
第X条 维修义务
一、甲方维修义务：
（一）租赁物的主体结构、外墙、屋顶、承重墙等部位发生损坏的，
由甲方负责维修；
（二）因租赁物自身质量原因或自然老化导致的设施设备损坏，
由甲方负责维修。

二、乙方维修义务：
（一）因乙方使用不当或保管不善造成租赁物及设施设备损坏的，
由乙方负责维修或承担赔偿责任；
（二）租赁物及设施设备的日常维护保养由乙方负责。

三、维修通知：需要维修时，一方应及时通知另一方；
需要对方维修的，对方应在收到通知后【】日内进行维修。

四、紧急维修：发生危及租赁物安全的紧急情况，乙方可先行维修，
维修费用由甲方承担，但乙方应及时通知甲方。
```

**专业术语**
- 维修义务（而非"维修责任"）
- 主体结构（建筑术语）
- 使用不当或保管不善（过错表述）
- 承担赔偿责任（而非"赔偿"）
- 先行维修（紧急情况的特殊规定）

#### 6. 转租条款

**规范表述**
```
第X条 转租
一、转租限制：
（一）未经甲方书面同意，乙方不得将租赁物全部或部分转租、
转借给第三人使用；
（二）乙方将租赁物转租给第三人的，应当在转租前征得甲方的
书面同意，转租期限不得超过本合同剩余期限。

二、转租合同：
（一）转租合同的内容应当符合本合同的约定；
（二）第三人对租赁物造成损失的，乙方应承担赔偿责任。

三、擅自转租：乙方未经甲方同意擅自转租的，甲方有权解除合同，
乙方应承担违约责任。
```

**专业术语**
- 转租（而非"转租出去"）
- 转借（与转租并列的另一概念）
- 第三人（而非"其他人"、"别人"）
- 剩余期限（而非"剩下的时间"）
- 擅自转租（强调未经许可）

- 自然性质（而非"物品本身特性""货物自身原因"）
- 间接损失（而非"连带损失""额外损失"）
- 索赔（而非"要求赔偿""讨要赔偿"）
- 如实告知义务（而非"说明义务""如实说明的责任"）
