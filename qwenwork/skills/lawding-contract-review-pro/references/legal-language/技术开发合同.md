# 技术开发合同 标准条款模板


#### 1. 技术开发内容条款

**规范表述**
```
第X条 技术开发内容与要求
一、本合同所称技术开发，系指当事人之间就新技术、新产品、新工艺、新品种
或者新材料及其系统的研究开发所订立的合同。本合同属于【委托开发/合作开发】
合同。
二、技术开发项目名称：【项目名称】。
三、技术开发的具体内容与范围：
  （一）开发目标：【具体描述技术开发所要达到的目标】；
  （二）开发内容：【具体描述需要完成的技术研发工作】；
  （三）技术指标与参数要求：
    1. 【技术指标一】：【具体参数要求】；
    2. 【技术指标二】：【具体参数要求】；
    3. 【技术指标三】：【具体参数要求】。
四、技术开发计划及进度安排：
  （一）第一阶段：自【起始日期】至【终止日期】，完成【阶段目标】；
  （二）第二阶段：自【起始日期】至【终止日期】，完成【阶段目标】；
  （三）第三阶段：自【起始日期】至【终止日期】，完成【阶段目标】。
五、技术成果的验收标准与方式：
  （一）验收标准：符合本条第三款约定的全部技术指标与参数要求；
  （二）验收方式：【委托人单方验收/双方共同验收/委托第三方检测机构验收】；
  （三）验收期限：开发方提交技术成果之日起【  】个工作日内完成验收。
六、技术成果的交付形式：【技术文档/源代码/样品/样机/其他】。
```

**专业术语**
- 技术开发（而非"研发""开发项目"）
- 委托开发（而非"外包开发""找人开发"）
- 合作开发（而非"一起研发""共同做项目"）
- 技术指标与参数（而非"技术要求""性能标准"）
- 验收标准（而非"交货标准""合格标准"）
- 技术成果（而非"开发成果""研发结果"）

#### 2. 技术成果归属条款

**规范表述**
```
第X条 技术成果权利归属
一、委托开发完成的发明创造及相关知识产权，按照以下约定确定归属：
  （一）申请专利的权利归属于【委托人/开发人/双方共有】；
  （二）技术秘密成果的使用权、转让权归属于【委托人/开发人/双方共有】。
二、合作开发完成的发明创造及相关知识产权，按照以下约定确定归属：
  （一）申请专利的权利属于合作开发的当事人共有，但当事人另有约定的，
  按照其约定；
  （二）合作开发的当事人一方不同意申请专利的，另一方不得申请专利；
  （三）合作开发当事人一方声明放弃其共有的专利申请权的，除当事人另有
  约定外，可以由另一方单独申请或者由其他各方共同申请。
三、技术成果中涉及的著作权归属：
  （一）技术开发过程中形成的技术文档、设计图纸、源代码等作品的著作权
  归属于【委托人/开发人/双方共有】；
  （二）一方许可第三人使用的，所取得的收益按照【  】%：【  】%的
  比例分配。
四、利用本合同技术成果所获得的后续改进技术成果的分享办法：【具体约定】。
五、任何一方未经对方书面同意，不得向第三方转让本合同约定归其享有的
技术成果权利。
```

**专业术语**
- 发明创造（而非"发明成果""技术发明"）
- 申请专利的权利（而非"专利权""专利申请权"）
- 技术秘密成果（而非"保密技术""核心技术"）
- 后续改进技术成果（而非"升级版本""改良技术"）
- 知识产权（而非"知识版权""智力成果权"）

#### 3. 开发费用条款

**规范表述**
```
第X条 技术开发费用与报酬
一、委托开发合同的研究开发经费和报酬：
  （一）研究开发经费总额为人民币【大写金额】元整（¥【数字金额】元），
  包括：
    1. 研究开发人员的人工费用；
    2. 设备购置及使用费用；
    3. 原材料及消耗品费用；
    4. 试验验证费用；
    5. 其他必要的技术开发支出。
  （二）开发报酬为人民币【大写金额】元整（¥【数字金额】元）。
  （三）研究开发经费和报酬的支付方式与时间：
    1. 本合同签订之日起【  】个工作日内，支付人民币【金额】元，
    作为首期款项；
    2. 第【  】阶段验收通过后【  】个工作日内，支付人民币【金额】元；
    3. 全部技术成果验收合格后【  】个工作日内，支付尾款人民币【金额】元。
二、合作开发合同的费用分担：
  （一）【甲方】承担以下开发费用：【具体费用项目及金额】；
  （二）【乙方】承担以下开发费用：【具体费用项目及金额】。
三、研究开发经费的使用应当符合本合同约定的用途，开发方应当按照委托方
要求提供经费使用明细。
四、因不可归责于当事人的事由致使技术开发费用增加的，增加部分的负担由
双方协商解决。
```

**专业术语**
- 研究开发经费（而非"开发费用""项目经费"）
- 开发报酬（而非"开发费""劳务费"）
- 不可归责于当事人的事由（而非"不是谁的错""不怪任何人"）
- 经费使用明细（而非"费用报告""花销明细"）

#### 4. 技术保密条款

**规范表述**
```
第X条 技术保密
一、保密信息的范围：本合同所称保密信息，包括但不限于：
  （一）技术开发过程中产生的全部技术资料、数据、图纸、源代码、算法、
  工艺流程等技术信息；
  （二）与本项目相关的商业计划、客户信息、市场分析、定价策略等经营信息；
  （三）本合同的存在及其具体条款内容；
  （四）任何一方以书面形式明确标注为"保密"的其他信息。
二、保密义务：
  （一）各方应当对保密信息严格保密，未经信息提供方书面同意，不得向任何
  第三方披露、公开或者允许任何第三方使用保密信息；
  （二）各方应当将保密信息的知悉范围限于因履行本合同而必须知悉的本方
  工作人员，并确保该等人员承担同等保密义务；
  （三）各方不得将保密信息用于本合同约定目的以外的任何用途。
三、下列信息不属于保密信息：
  （一）在披露前已为接收方合法持有的信息；
  （二）非因接收方违反保密义务而成为公知信息的；
  （三）接收方从有权披露的第三方合法获得的信息；
  （四）接收方独立开发取得的信息。
四、保密期限：自本合同签订之日起至【  】年届满之日止。合同终止或解除
不影响保密义务的效力。
五、违约责任：任何一方违反本条保密义务的，应当向守约方支付违约金人民币
【大写金额】元整（¥【数字金额】元），违约金不足以弥补守约方实际损失的，
违约方应当补足差额。
```

**专业术语**
- 保密信息（而非"秘密""机密内容"）
- 公知信息（而非"公开信息""众所周知的"）
- 知悉范围（而非"知道的范围""谁能看"）
- 书面同意（而非"同意""允许"）
- 独立开发（而非"自己做的""自主研发"）
- 合法持有（而非"已经知道的""本来就有的"）

#### 5. 风险负担条款

**规范表述**
```
第X条 技术开发风险负担
一、技术开发合同履行过程中，因出现无法克服的技术困难，导致研究开发失败
或者部分失败的，该风险按照以下约定负担：
  （一）委托开发合同的风险负担：
    1. 因技术开发的固有风险导致研究开发失败或者部分失败的，风险责任由
    【委托人承担/开发人承担/双方按照【  】%：【  】%的比例合理分担】；
    2. 研究开发经费的返还：【全部返还/部分返还/不予返还】；
    3. 开发报酬的支付：【全额支付/按完成比例支付/不予支付】。
  （二）合作开发合同的风险负担：
    1. 研究开发失败的风险由合作各方按照【投资比例/约定比例/平均】
    合理分担；
    2. 各方已投入的研究开发经费按照【具体处理方式】处理。
二、判定研究开发失败或者部分失败的标准：
  （一）技术开发项目在现有技术水平条件下已无法继续实施；
  （二）经【  】以上有资质的专业技术评估机构评估，确认技术目标
  不可实现；
  （三）双方协商一致确认研究开发失败。
三、风险负担的通知与举证：
  （一）一方发现可能导致研究开发失败或者部分失败的情形时，应当在
  【  】个工作日内书面通知对方，并提供相应的技术分析报告及证明材料；
  （二）未及时通知致使损失扩大的，应当就扩大的损失承担责任。
四、因一方或者各方违约导致研究开发失败的，不适用本条关于风险负担的约定，
违约方应当依照本合同违约责任条款承担违约责任。
```

**专业术语**
- 技术风险（而非"开发风险""失败风险"）
- 无法克服的技术困难（而非"做不出来""技术难题"）
- 风险负担（而非"风险分担""谁来承担风险"）
- 固有风险（而非"本身的风险""天然风险"）
- 举证（而非"提供证据""证明"）
- 专业技术评估机构（而非"鉴定机构""评估公司"）
