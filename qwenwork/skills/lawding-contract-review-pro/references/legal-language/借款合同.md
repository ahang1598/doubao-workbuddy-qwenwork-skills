# 借款合同 标准条款模板


#### 1. 借款金额和用途条款

**规范表述**
```
第X条 借款金额及用途
一、借款金额：甲方向乙方出借人民币【大写】元整
（¥【小写】元）（以下简称"借款"）。

二、出借方式：甲方通过银行转账方式将借款划入乙方指定账户。
账户信息如下：
户名：【】
开户行：【】
账号：【】

三、借款用途：乙方承诺将借款用于【具体用途】，不得挪作他用。
甲方有权监督借款的使用情况。

四、借款交付：借款本金以实际到账金额为准，甲方不得预先扣除
利息、违约金、管理费等费用。
```

**专业术语**
- 出借（而非"借给"）
- 借款（而非"贷款"，民间借贷不用"贷款"）
- 挪作他用（成语，表示改变用途）
- 借款交付（而非"打款"）
- 实际到账金额（强调本金认定标准）
- 预先扣除（禁止砍头息的表述）

#### 2. 借款利息条款

**规范表述**
```
第X条 借款利息
一、利率：借款年利率为【】%（以实际出借本金为基数计算）。

二、利息计算：
（一）利息自借款实际交付之日起计算；
（二）利息按【月/季/年】计算，计算公式为：
利息 = 借款本金 × 年利率 ÷ 365 × 实际天数；
（三）先息后本/等额本息/一次性还本付息。

三、利息支付：
（一）乙方应于每【月/季/年】【首日/末日】前支付当期利息；
（二）首期利息应于【年月日】前支付。

四、逾期利息：乙方逾期支付利息的，应按照逾期金额的
年利率【】%向甲方支付逾期利息。

五、法律限制：本合同约定的利率不超过法律保护的上限
（合同成立时一年期贷款市场报价利率的四倍）。
```

**专业术语**
- 年利率（而非"利息"）
- 实际出借本金（计息基数）
- 借款实际交付之日（起算点）
- 逾期利息（而非"罚息"）
- 一年期贷款市场报价利率的四倍（LPR的4倍，法定上限）

#### 3. 还款条款

**规范表述**
```
第X条 还款
一、还款期限：乙方应于【年月日】前偿还全部借款本金及利息。

二、还款方式：
方式一（一次性还本付息）：
乙方应于还款期限届满之日一次性偿还全部借款本金及利息。

方式二（分期还款）：
（一）借款本金分【】期偿还，每期偿还金额为人民币【大写】元整
（¥【小写】元）；
（二）第一期还款应于【年月日】前支付，
其后各期还款时间为每【月/季】的【】日；
（三）各期应还本金、利息详见本合同附件《还款计划表》。

三、提前还款：
（一）乙方有权提前偿还全部或部分借款；
（二）提前还款的，乙方应提前【】日书面通知甲方；
（三）提前还款的利息计算至实际还款之日。

四、还款账户：
户名：【】
开户行：【】
账号：【】

五、清偿顺序：乙方偿还的款项不足以清偿全部债务的，按照
实现债权的有关费用、利息、本金的顺序清偿。
```

**专业术语**
- 偿还（而非"还"）
- 还款期限届满之日（明确时间节点）
- 提前偿还（而非"提前还款"）
- 清偿（比"偿还"更正式的法律术语）
- 清偿顺序（法定的清偿次序）
- 实现债权的有关费用（包括诉讼费、律师费等）

#### 4. 担保条款

**规范表述**
```
第X条 担保
一、担保方式：本合同项下的借款由【丙方/担保物】提供
【保证/抵押/质押】担保。

保证担保：
（一）保证人：【丙方全称】；
（二）保证方式：连带责任保证；
（三）保证范围：借款本金、利息、违约金、损害赔偿金以及
实现债权的费用（包括但不限于诉讼费、律师费、保全费等）；
（四）保证期间：自本合同约定的还款期限届满之日起二年。

抵押担保：
（一）抵押物：【抵押物名称及基本情况】；
（二）抵押物权属：抵押物的所有权人为【】，
有权设定抵押；
（三）抵押登记：双方应于本合同签订后【】日内共同到
【登记机关】办理抵押登记手续；
（四）担保范围：同上；
（五）抵押物处分：乙方未按约定偿还借款的，甲方有权依法
处分抵押物，以处分所得价款优先受偿。

二、担保合同：甲方与担保人/抵押人另行签订【保证合同/抵押合同】，
作为本合同的附件。

三、担保责任：【丙方/抵押人】对本合同项下乙方的债务承担
【连带保证责任/抵押担保责任】。
```

**专业术语**
- 担保方式（保证、抵押、质押的统称）
- 保证人（而非"担保人"，虽然口语可以混用）
- 连带责任保证（与一般保证相对）
- 保证范围（明确担保的债务范围）
- 实现债权的费用（包括各类实现担保权的成本）
- 保证期间（而非"保证期限"）
- 抵押物（而非"抵押品"）
- 有权设定抵押（明确抵押权人）
- 抵押登记（物权公示方式）
- 处分抵押物（行使抵押权）
- 优先受偿（抵押权的效力）
