# 股权转让合同 标准条款模板


#### 1. 标的股权条款

**规范表述**
```
第X条 标的股权
一、目标公司：【公司全称】（以下简称"目标公司"）。

二、目标公司基本情况：
（一）注册资本：人民币【大写】元整（¥【小写】元）；
（二）实缴资本：人民币【大写】元整（¥【小写】元）；
（三）公司类型：【有限责任公司/股份有限公司】；
（四）统一社会信用代码：【】；
（五）住所：【】。

三、转让股权：
（一）甲方持有目标公司【】%的股权，对应出资额为
人民币【大写】元整（¥【小写】元）（以下简称"标的股权"）；
（二）标的股权的权属清晰，不存在权属争议、质押、查封、
冻结等权利限制；
（三）甲方有权依法转让标的股权。

四、其他股东优先购买权：
（一）目标公司其他股东已放弃对标的股权的优先购买权，
放弃声明详见本合同附件《优先购买权放弃声明》；
（二）股东会已通过股权转让决议，决议详见本合同附件
《股东会决议》。
```

**专业术语**
- 标的股权（而非"股份"、"股权"）
- 目标公司（股权转让标的所在的公司）
- 注册资本（而非"注册资金"）
- 实缴资本（与认缴资本相对）
- 有限责任公司、股份有限公司（公司类型）
- 统一社会信用代码（而非"营业执照号"）
- 住所（公司法定术语，而非"地址"）
- 权属清晰（而非"所有权清楚"）
- 权属争议、质押、查封、冻结（各类权利瑕疵）
- 权利限制（而非"权利问题"）
- 有权依法转让（明确转让权）
- 优先购买权（其他股东的法定权利）
- 优先购买权放弃声明（必备文件）
- 股东会决议（必备文件）

#### 2. 转让价款条款

**规范表述**
```
第X条 转让价款及支付方式
一、定价依据：
标的股权的转让价格以【评估价值/净资产/双方协商】为依据确定。

二、转让价款：
标的股权的转让价款为人民币【大写】元整（¥【小写】元）。

三、支付方式：
（一）本合同签订后【】日内，乙方向甲方支付转让价款的【】%，
计人民币【大写】元整（¥【小写】元），作为首期价款；

（二）工商变更登记完成后【】日内，乙方向甲方支付转让价款的
【】%，计人民币【大写】元整（¥【小写】元）；

（三）【交割日/股权交割完成后】【】日内，乙方向甲方支付
剩余转让价款。

四、支付账户：
户名：【】
开户行：【】
账号：【】
```

**专业术语**
- 转让价款（而非"转让价格"、"转让款"）
- 定价依据（评估价值、净资产、协商）
- 首期价款（而非"首付款"）
- 工商变更登记（股权变更的公示方式）
- 交割日（权利义务转移的时间节点）
- 股权交割（权利义务的实际转移）

#### 3. 股权交割条款

**规范表述**
```
第X条 股权交割
一、交割日：
双方同意以【年月日】/【工商变更登记完成之日】/
【转让价款全部支付完毕之日】为交割日（以下简称"交割日"）。

二、交割前提条件：
（一）本合同已生效；
（二）目标公司股东会已通过股权转让决议；
（三）其他股东已放弃优先购买权；
（四）乙方已按约定支付【首期/全部】转让价款；
（五）【其他约定条件】。

三、交割安排：
（一）甲方应在交割日前完成以下事项：
1. 向目标公司提交书面通知，要求目标公司将标的股权的
股东登记变更至乙方名下；
2. 配合乙方办理工商变更登记手续；
3. 向乙方移交目标公司的营业执照、公章、财务章、
合同章、财务账册、重要合同等资料；
4. 向乙方移交目标公司实际控制权。

（二）乙方应在交割日前完成以下事项：
1. 按约定支付转让价款；
2. 准备工商变更登记所需的全部文件。

（三）双方应在交割日共同到目标公司住所地工商行政管理部门
办理股权变更登记手续。

四、交割完成标志：
目标公司向乙方签发出资证明书，并在股东名册上记载乙方为
目标公司股东，视为股权交割完成。
```

**专业术语**
- 股权交割（而非"股权转让完成"）
- 交割日（明确的时间节点）
- 交割前提条件（交割的先决条件）
- 交割安排（交割的具体事项）
- 股东登记（公司内部的股权登记）
- 工商变更登记（外部公示的股权变更）
- 营业执照、公章、财务章、合同章（公司证照）
- 财务账册（公司财务资料）
- 实际控制权（公司控制权）
- 出资证明书（股东身份证明）
- 股东名册（记载股东的簿册）
- 记载为股东（股权变更的内部公示）

#### 4. 陈述与保证条款

**规范表述**
```
第X条 陈述与保证
一、甲方陈述与保证：
甲方向乙方作出如下陈述与保证，保证其真实、准确、完整：

（一）关于标的股权：
1. 甲方是标的股权的合法所有权人，有权依法转让标的股权；
2. 标的股权权属清晰，不存在权属争议、质押、查封、
冻结等权利限制；
3. 标的股权不存在代持、信托等权益安排；
4. 除本合同约定外,标的股权不存在任何第三方权利；
5. 其他股东已放弃优先购买权，股东会已通过股权转让决议。

（二）关于目标公司：
1. 目标公司依法设立并有效存续，不存在解散、清算、
破产等终止事由；
2. 目标公司已依法办理工商登记、税务登记等手续，
证照齐全有效；
3. 目标公司的公司章程、股东名册、出资证明书等文件
真实有效；
4. 目标公司的注册资本已足额缴纳，不存在虚假出资、
抽逃出资等情形。

（三）关于财务状况：
1. 甲方已向乙方提供的目标公司财务报表真实、准确、完整；
2. 目标公司不存在账外负债、或有负债；
3. 目标公司已依法纳税，不存在欠税、偷税、漏税等情形。

（四）关于诉讼仲裁：
1. 目标公司及甲方不存在尚未了结的或可预见的诉讼、
仲裁、行政处罚等事项；
2. 目标公司的资产不存在被查封、扣押、冻结等情形。

（五）关于重大合同：
1. 甲方已向乙方披露目标公司的全部重大合同；
2. 目标公司签署的重大合同合法有效，不存在重大违约情形。

（六）关于知识产权：
1. 目标公司合法拥有其经营所需的全部知识产权；
2. 目标公司的知识产权不存在侵权、权属争议等情形。

二、乙方陈述与保证：
乙方向甲方作出如下陈述与保证：
（一）乙方具有完全民事行为能力/依法设立并有效存续，
有权签署并履行本合同；
（二）乙方签署并履行本合同已获得必要的授权和批准；
（三）乙方具有支付转让价款的能力。

三、陈述保证的效力：
（一）上述陈述与保证在本合同签订日及交割日均真实、
准确、完整；
（二）任何陈述与保证被证明不实的，违反方应承担违约责任；
（三）因陈述与保证不实给守约方造成损失的，违反方应
承担赔偿责任。
```

**专业术语**
- 陈述与保证（representations and warranties，并列的两个概念）
- 真实、准确、完整（三位一体的表述标准）
- 合法所有权人（强调权利的合法性）
- 有权依法转让（明确转让权）
- 权利限制（各类权利瑕疵的总称）
- 代持、信托（隐名出资的方式）
- 权益安排（权利的特殊安排）
- 第三方权利（他人权利）
- 依法设立并有效存续（主体适格的标准表述）
- 解散、清算、破产（公司终止事由）
- 证照齐全有效（证书执照的状态）
- 注册资本已足额缴纳（实缴到位）
- 虚假出资、抽逃出资（违法出资行为）
- 财务报表（而非"财务报告"）
- 账外负债、或有负债（隐性负债）
- 欠税、偷税、漏税（违法纳税行为）
- 尚未了结的或可预见的（诉讼范围）
- 被查封、扣押、冻结（财产保全措施）
- 全部重大合同（重要合同的范围）
- 重大违约（严重的违约行为）
- 合法拥有（而非"拥有"）
- 知识产权侵权、权属争议（知识产权瑕疵）
- 完全民事行为能力（自然人的行为能力）
- 依法设立并有效存续（法人的主体资格）
- 必要的授权和批准（内部决策程序）
- 在本合同签订日及交割日均真实（持续保证）
- 被证明不实（陈述保证违反）
- 承担违约责任（违约的后果）
- 承担赔偿责任（损害赔偿的后果）
