# 承揽合同 标准条款模板


#### 1. 承揽内容条款

**规范表述**
```
第X条 承揽内容
一、定作人（以下简称"甲方"）委托承揽人（以下简称"乙方"）完成以下工作：
  （一）工作名称：【  】；
  （二）工作内容及范围：【具体承揽事项描述】；
  （三）工作形式：【加工/定作/修理/复制/测试/检验】；
  （四）技术要求及质量标准：【执行标准编号或详见附件《技术规格书》】。
二、乙方应以自己的设备、技术和劳力完成主要工作。乙方将其承揽的主要工作
交由第三人完成的，应当就该第三人完成的工作成果向甲方负责，并经甲方事先
书面同意。
三、承揽工作的具体规格、数量、图纸及样品等详见本合同附件，该附件构成
本合同不可分割的组成部分。如合同附件与合同正文不一致的，以合同正文为准。
四、甲方对承揽工作有特殊要求的，应在本合同签订时明确告知乙方，并在附件
中予以载明。合同签订后甲方变更工作要求的，应当及时通知乙方，由此增加的
费用及造成的损失由甲方承担。
五、乙方发现甲方提供的图纸或者技术要求不合理的，应当及时通知甲方。
甲方因此变更工作要求的，按本条第四款执行。
```

**专业术语**
- 定作人（而非"客户""委托方""订货方"）
- 承揽人（而非"加工方""制作方""做活的"）
- 定作（而非"定制""订做"）
- 工作成果（而非"产品""成品""做出来的东西"）
- 技术规格书（而非"技术要求""参数表"）
- 交由第三人完成（而非"转包""外包给别人"）

#### 2. 材料提供条款

**规范表述**
```
第X条 材料提供
一、完成承揽工作所需材料的提供方式为【甲方提供全部材料/乙方提供全部
材料/甲方提供主要材料、乙方提供辅助材料】。
二、由甲方提供材料的：
  （一）甲方应按照合同约定的时间、地点向乙方交付材料，并提供相应的
  材料质量证明文件。材料名称、规格、数量、质量标准及交付时间详见附件
  《材料清单》；
  （二）乙方应对甲方提供的材料及时进行检验，发现材料不符合约定的，
  应当及时通知甲方更换、补齐或者采取其他补救措施；
  （三）乙方不得擅自更换甲方提供的材料，不得更换不需要修理的零部件；
  （四）乙方应当妥善保管甲方提供的材料以及完成的工作成果，因保管不善
  造成毁损、灭失的，应当承担赔偿责任。
三、由乙方提供材料的：
  （一）乙方应按照合同约定提供材料，并接受甲方检验；
  （二）乙方对其提供材料的质量负责。材料质量不符合约定，导致工作成果
  不符合质量要求的，乙方应承担相应责任。
四、甲方未按约定时间提供材料的，交付工作成果的期限相应顺延；由此造成
乙方停工损失的，甲方应予赔偿。
```

**专业术语**
- 材料（而非"原料""东西""物料"）
- 毁损、灭失（而非"损坏、丢失""弄坏、弄丢"）
- 检验（而非"验收""检查"）
- 零部件（而非"零件""配件"）
- 质量证明文件（而非"质检报告""合格证明"）
- 停工损失（而非"停工费""等待费用"）

#### 3. 工作成果交付条款

**规范表述**
```
第X条 工作成果的交付与验收
一、乙方应于【具体日期/签订本合同之日起第  日】前将工作成果交付甲方。
交付地点为【  】，交付方式为【  】。
二、工作成果的风险负担：
  （一）交付之前，工作成果毁损、灭失的风险由乙方承担；
  （二）交付之后，工作成果毁损、灭失的风险由甲方承担；
  （三）甲方逾期不领取工作成果的，自逾期之日起风险由甲方承担。
三、验收程序：
  （一）乙方交付工作成果时，应同时提供必要的技术资料、合格证明、
  使用说明等随附文件；
  （二）甲方应在收到工作成果之日起【  】个工作日内完成验收，并出具
  书面验收意见；
  （三）甲方逾期未提出质量异议的，视为验收合格。
四、工作成果不符合质量要求的，甲方有权要求乙方承担以下责任：
  （一）修理；
  （二）重作；
  （三）减少报酬；
  （四）赔偿损失。
五、乙方应就工作成果承担质量保证责任，质量保证期为交付验收合格之日起
【  】个月。质量保证期内，非因甲方使用不当导致的质量缺陷，由乙方免费
修理或重作。
```

**专业术语**
- 工作成果（而非"产品""成品""货物"）
- 毁损、灭失（而非"损坏""丢失"）
- 风险负担（而非"责任归谁""谁来承担风险"）
- 重作（而非"重新做""返工"）
- 随附文件（而非"附带文件""配套资料"）
- 质量保证期（而非"保修期""保质期"）

#### 4. 报酬条款

**规范表述**
```
第X条 报酬及支付
一、本合同承揽报酬总额为人民币（大写）【金额】元整（¥【金额】），
该报酬为【含税/不含税】价格。具体构成如下：
  （一）加工费/制作费：人民币【金额】元；
  （二）材料费（如适用）：人民币【金额】元；
  （三）其他费用（如适用）：人民币【金额】元。
二、报酬支付方式及时间：
  （一）预付款：合同签订后【  】个工作日内，甲方向乙方支付合同总价的
  【  】%，即人民币【金额】元；
  （二）进度款：乙方完成【节点描述】后，甲方于【  】个工作日内支付
  合同总价的【  】%，即人民币【金额】元；
  （三）验收款：工作成果验收合格后【  】个工作日内，甲方支付剩余
  款项人民币【金额】元。
三、乙方对完成的工作成果享有留置权。甲方未按照约定支付报酬的，乙方
可以依据《中华人民共和国民法典》第七百八十三条之规定，留置该工作成果，
并催告甲方在合理期限内支付。甲方逾期仍不支付的，乙方可以依法就留置的
工作成果优先受偿。
四、甲方在乙方交付工作成果前，可以随时解除本合同，但应当赔偿乙方因此
造成的损失，包括乙方已完成工作部分的报酬及合理预期利益损失。
```

**专业术语**
- 报酬（而非"费用""加工费""工钱"）
- 留置权（而非"扣押权""不给的权利"）
- 留置（而非"扣留""扣押""不给"）
- 合理预期利益（而非"预计利润""应得收入"）
- 预付款（而非"定金""预付费""先付的钱"）
- 优先受偿（而非"先拿钱""优先获赔"）

#### 5. 风险负担条款

**规范表述**
```
第X条 风险负担
一、工作成果交付前的风险负担：
  （一）因乙方原因导致工作成果毁损、灭失的，乙方应重新完成工作或赔偿
  甲方损失，交付期限不予顺延；
  （二）因甲方提供的材料或指示不当导致工作成果毁损、灭失的，乙方不承担
  责任，甲方应支付乙方已完成工作部分的相应报酬；
  （三）因不可抗力导致工作成果毁损、灭失的，乙方的损失由乙方承担，
  甲方提供的材料损失由甲方承担，双方另有约定的除外。
二、工作成果交付后的风险负担：
  （一）交付后工作成果的毁损、灭失风险由甲方承担；
  （二）但因工作成果存在质量缺陷导致毁损、灭失的，乙方应在质量保证
  期内承担相应责任。
三、甲方提供材料的风险负担：
  （一）甲方提供的材料在乙方占有期间，因乙方保管不善毁损、灭失的，
  乙方应承担赔偿责任；
  （二）因材料自身缺陷或自然损耗导致的毁损、灭失，乙方不承担责任。
四、乙方应对工作过程中的安全生产承担责任，因承揽工作造成乙方自身人员
伤亡或财产损失的，甲方不承担责任，但甲方的指示或提供的材料存在缺陷的
除外。
五、双方应各自为其可保利益投保相应的保险。乙方应为其工作人员投保工伤
保险或商业意外伤害保险。
```

**专业术语**
- 风险负担（而非"风险承担""风险分担"）
- 自然损耗（而非"自然损失""正常消耗"）
- 可保利益（而非"可以保的利益""保险利益"）
- 安全生产（而非"生产安全""施工安全"）
- 占有期间（而非"持有期间""保管期间"）
- 工伤保险（而非"工伤赔偿保险""上班保险"）
