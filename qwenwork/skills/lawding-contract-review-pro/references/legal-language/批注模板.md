# 批注模板与示例

> **用途：** 本文件定义批注的标准格式和示例，确保批注风格统一、内容完整。
> **使用方式：** 阶段三加载，阶段四整理 findings 时使用。

---

## 一、批注标准格式

### 致命风险批注格式

```
【致命风险】[风险类型]
【问题】[具体问题描述]
【依据】依据《[法律名称]》第[条款]条，[法律规定要点]
【后果】[可能导致的不利后果]
【建议】必须修改。建议修改为："[具体修改内容]"
```

### 重要风险批注格式

```
【重要风险】[风险类型]
【问题】[具体问题描述]
【依据】依据《[法律名称]》第[条款]条，[法律规定要点]
【建议】建议修改为："[具体修改内容]"
```

### 一般风险批注格式

```
【一般风险】[风险类型]
【问题】[具体问题描述]
【建议】建议修改为："[具体修改内容]"
```

### 轻微瑕疵批注格式

```
【轻微瑕疵】[问题类型]
【问题】[具体问题描述]
【建议】建议修改为："[具体修改内容]"
```

### 缺失条款批注格式

```
【缺失条款】[条款名称]
【问题】合同缺少[条款名称]，可能导致[风险]
【依据】依据《[法律名称]》第[条款]条，[法律规定要点]
【建议】建议补充："[条款全文]"
```

## 二、批注示例

### 示例 1：致命风险 - 标的物违法

**原文：** "甲方同意向乙方出售其持有的XX公司股权。"

**批注：**
```
【致命风险】标的条款
【问题】合同未核实标的股权是否存在质押、冻结等权利限制，可能导致无法过户
【依据】依据《民法典》第597条，出卖人应当履行向买受人交付标的物并转移标的物所有权的义务
【后果】可能无法取得标的股权，合同目的落空，已支付款项难以追回
【建议】必须修改。建议补充：甲方保证标的股权不存在任何质押、冻结或其他权利限制，并承诺在交割日前完成解押解冻手续。
```

### 示例 2：重要风险 - 付款时间不明确

**原文：** "乙方应及时付款。"

**批注：**
```
【重要风险】价款条款
【问题】付款时间约定不明确，"及时"属于模糊表述，不具有可执行性
【依据】依据《民法典》第511条，履行期限不明确的，债务人可以随时履行，债权人也可以随时请求履行，但应当给对方必要的准备时间
【建议】建议修改为："乙方应于收到甲方开具的增值税专用发票后十五（15）日内，将价款支付至甲方指定账户。"
```

### 示例 3：重要风险 - 违约金过高

**原文：** "逾期付款的，每日按未付金额的1%支付违约金。"

**批注：**
```
【重要风险】违约责任条款
【问题】违约金费率明显偏高，可能被认定为过分高于造成的损失并被法院或仲裁机构调减
【依据】依据《民法典》第585条，约定的违约金过分高于造成的损失的，人民法院可以根据当事人的请求予以适当减少
【建议】建议修改为："逾期付款的，每日按未付金额的万分之五（0.05%）支付违约金。"
```

### 示例 4：一般风险 - 金额格式不规范

**原文：** "合同总价为100万元。"

**批注：**
```
【一般风险】价款条款
【问题】金额仅有阿拉伯数字，无大写，存在被篡改风险
【建议】建议修改为："合同总价为人民币壹佰万元整（¥1,000,000.00）。"
```

### 示例 5：一般风险 - 期限表述不规范

**原文：** "乙方应在收到通知后10天内付款。"

**批注：**
```
【一般风险】履行条款
【问题】期限表述不规范，"10天"应为"十（10）日"
【建议】建议修改为："乙方应在收到通知后十（10）日内付款。"
```

### 示例 6：缺失条款 - 不可抗力

**原文：** （合同中无不可抗力条款）

**批注：**
```
【缺失条款】不可抗力条款
【问题】合同缺少不可抗力条款，发生不可抗力事件时双方权利义务不明确
【依据】依据《民法典》第590条，因不可抗力不能履行合同的，根据不可抗力的影响，部分或者全部免除责任
【建议】建议补充："第X条 不可抗力。一、本合同所称不可抗力，是指不能预见、不能避免并不能克服的客观情况，包括但不限于地震、台风、洪水、战争、政府行为等。二、因不可抗力导致合同不能履行或不能完全履行的，根据不可抗力的影响，部分或全部免除违约责任。三、遭受不可抗力的一方应在事件发生后三（3）日内通知对方，并在十五（15）日内提供证明文件。"
```

### 示例 7：缺失条款 - 争议解决

**原文：** （合同中无争议解决条款）

**批注：**
```
【缺失条款】争议解决条款
【问题】合同缺少争议解决条款，发生争议时管辖法院不明确，可能增加诉讼成本
【依据】依据《民法典》第470条，合同的内容由当事人约定，包括解决争议的方法
【建议】建议补充："第X条 争议解决。因本合同引起的或与本合同有关的任何争议，双方应友好协商解决；协商不成的，任何一方均可向甲方所在地有管辖权的人民法院提起诉讼。"
```

## 三、批注用语规范

### 问题表述用语

| 用途 | 规范表述 |
|------|---------|
| 条款缺失 | 合同缺少[条款名称] |
| 约定不明 | [事项]约定不明确 |
| 表述模糊 | "[原文表述]"属于模糊表述 |
| 违反法律 | 违反《[法律名称]》第[条款]条关于[内容]的规定 |
| 权利义务失衡 | 我方[义务/责任]明显重于对方 |

### 依据表述用语

| 用途 | 规范表述 |
|------|---------|
| 引用法律 | 依据《[法律名称]》第[条款]条 |
| 引用原则 | 依据[法律原则] |
| 引用后果 | 可能导致[具体后果] |

### 建议表述用语

| 风险等级 | 规范表述 |
|---------|---------|
| 致命风险 | 必须修改。建议修改为："[修改内容]" |
| 重要风险 | 建议修改为："[修改内容]" |
| 一般风险 | 建议修改为："[修改内容]" |
| 轻微瑕疵 | 建议修改为："[修改内容]" |
| 缺失条款 | 建议补充："[条款全文]" |

## 四、批注长度控制

| 风险等级 | 建议句数 | 建议字数 |
|---------|---------|---------|
| 致命风险 | 3-5句 | 100-200字 |
| 重要风险 | 2-4句 | 80-150字 |
| 一般风险 | 1-3句 | 50-100字 |
| 轻微瑕疵 | 1-2句 | 30-50字 |
| 缺失条款 | 2-4句 | 80-150字 |

**原则：** 说清楚问题和建议即可，不要展开论述。

| 批注长度是否在建议范围内？ | □ |
| 措辞是否使用法律术语？ | □ |
