# 法律语言规范库

专业合同起草的法律语言表达规范和标准条款表述库。

---

## 一、法律语言表达规范

### 1. 基本原则

**准确性原则**
- 使用法定术语，避免模糊表述
- 区分相似概念（定金vs订金、违约金vs赔偿金）
- 数字、日期、金额采用大小写一致的规范表述

**规范性原则**
- 遵循法律法规的用语习惯
- 采用合同起草的标准格式
- 保持条款表述的一致性

**严谨性原则**
- 权利义务表述完整清晰
- 避免歧义和漏洞
- 逻辑关系明确

### 2. 常见术语正误对照

| 错误表述 | 正确表述 | 说明 |
|---------|---------|------|
| 订金 | 定金 | 定金具有担保作用，适用定金罚则 |
| 赔偿金 | 违约金 | 违约金是预先约定的违约责任；赔偿金是实际损失 |
| 交货 | 交付 | 交付是法律术语，包括实物交付和权利转移 |
| 付款 | 支付价款 | 支付价款更规范，明确支付的性质 |
| 双方同意 | 双方协商一致 | 协商一致体现合同自愿原则 |
| 出现问题 | 发生违约/产生争议 | 明确指出法律后果 |
| 负责 | 承担责任 | 承担责任是规范表述 |
| 不能 | 不得/无权 | 不得表示禁止性规定，无权表示无权利 |
| 可以 | 有权 | 有权更明确权利性质 |
| 及时 | 于……日内/立即 | 明确具体时限 |
| 合理 | 符合……标准/不超过……范围 | 具体化标准 |
| 适当 | 按照……方式/不少于…… | 明确具体要求 |
| 尽快 | 于收到通知后……日内 | 明确时间节点 |
| 必须 | 应当 | 在法律法规规范性表述中，应当代表必须 |

### 3. 数字和金额表述规范

**数字表述**
```
错误：10天、三个月
正确：十（10）日、三（3）个月
```

**金额表述**
```
错误：100万元、1000000元
正确：人民币壹佰万元整（¥1,000,000.00）
或：人民币100万元（大写：壹佰万元整）
```

**百分比表述**
```
错误：10%
正确：百分之十（10%）
或：10%（百分之十）
```

### 4. 日期和期限表述规范

**日期表述**
```
错误：2024年1月1日
正确：2024年1月1日（或：二〇二四年一月一日）
```

**期限表述**
```
错误：合同签订后30天
正确：自本合同签订之日起三十（30）日内
```

**起算规范**
```
错误：从交付开始
正确：自标的物交付之日起
```

## 三、合同审查中的法律语言规范

### 1. 提出修改建议的标准表述

**权利义务条款修改**
```
原条款：【原条款内容】
问题：【法律问题描述】
修改建议：
建议修改为："【规范条款表述】"

理由：
1. 【法律依据】
2. 【风险说明】
3. 【修改必要性】
```

**示例**
```
原条款："乙方应及时付款"
问题：付款时间约定不明确，"及时"属于模糊表述，
不具有可执行性。
修改建议：
建议修改为："乙方应于收到甲方开具的增值税专用发票后
十五（15）日内，将价款支付至甲方指定账户。"

理由：
1. 依据《民法典》第五百一十一条，履行期限不明确的，
债权人可以随时请求履行，可能引发争议；
2. 明确具体的付款时间节点，有利于合同的顺利履行和
争议解决；
3. 采用"日"而非"天"，符合法律用语习惯；
数字采用汉字加阿拉伯数字的规范表述。
```

### 2. 风险提示的标准表述

**致命风险提示**
```
【风险等级】致命风险
【风险条款】第X条第X款
【风险描述】【具体风险】可能导致合同无效/无法履行。
【法律依据】依据《【法律名称】》第【条款】规定，【法律规定内容】。
【法律后果】【可能的不利后果】
【修改建议】必须修改。建议：【具体修改方案】
```

**重要风险提示**
```
【风险等级】重要风险
【风险条款】第X条第X款
【风险描述】【具体风险】可能导致重大损失或争议。
【法律依据】依据《【法律名称】》第【条款】规定，【法律规定内容】。
【法律后果】【可能的不利后果】
【修改建议】建议修改。建议：【具体修改方案】
```

### 3. 批注用语规范

**指出问题**
```
【问题】本条款约定不明确/存在法律风险/违反法律规定
```

**提出建议**
```
【建议】建议修改为/建议增加/建议删除
```

**说明理由**
```
【理由】依据《【法律名称】》第【条款】规定/
基于【法律原则】/为避免【风险】
```

**提醒注意**
```
【注意】本条款涉及/需要关注/应当注意
```

### 4. 法律文书中的衔接用语

| 用途 | 规范表述 | 说明 |
|------|---------|------|
| 并列关系 | 以及、与、和 | "和"较口语化 |
| 递进关系 | 并且、同时、且 | 强调递进 |
| 转折关系 | 但是、但、然而 | "但"更正式 |
| 因果关系 | 因此、故、由此 | 表示结论 |
| 条件关系 | 如果……则/如……则 | 表示假设 |
| 时间关系 | 自……之日起、于……前、在……时 | 明确时间 |
| 假设关系 | 若、如、倘若 | 表示假设 |
| 目的关系 | 为了、以便、用以 | 表示目的 |
| 引用关系 | 依据、根据、按照 | 引用依据 |

## 四、使用说明

1. **审核合同时**：参照本规范库中对应合同类型的标准条款表述，
确保修改建议使用规范的法律语言。

2. **起草合同时**：直接采用本规范库中的标准条款模板，
根据具体情况填写相关内容。

3. **修改条款时**：对照法律语言表达规范，避免使用口语化、
模糊或不准确的表述。

4. **撰写审核意见时**：采用本规范库中的标准提示用语和
批注用语，保持专业性和规范性。

5. **持续更新**：根据法律法规的变化和实务经验的积累，
持续更新和完善本规范库。
