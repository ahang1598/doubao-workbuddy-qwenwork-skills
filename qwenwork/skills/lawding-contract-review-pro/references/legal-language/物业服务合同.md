# 物业服务合同 标准条款模板


#### 1. 物业服务内容条款

**规范表述**
```
第X条 物业服务内容与标准
一、物业服务人应当按照本合同约定和物业的使用性质，对以下物业管理区域
提供物业服务：
  （一）物业项目名称：【项目名称】；
  （二）物业坐落位置：【详细地址】；
  （三）物业管理区域范围：【具体范围描述】；
  （四）物业类型：【住宅/商业/办公/工业/综合体】；
  （五）建筑面积：【  】平方米。
二、物业服务人提供的物业服务内容包括：
  （一）物业共用部位的维修、养护和管理；
  （二）物业共用设施设备的运行、维修、养护和管理；
  （三）物业管理区域内的环境卫生维护与绿化养护；
  （四）物业管理区域内的秩序维护与安全防范；
  （五）物业服务档案和物业档案的建立与管理；
  （六）【其他约定的物业服务事项】。
三、物业服务等级标准：本合同项下物业服务按照【国家/地方】物业服务等级
标准中的【  】级标准执行，具体服务标准详见本合同附件《物业服务等级
标准明细》。
四、物业服务人应当按照约定和物业的使用性质，妥善维修、养护、清洁、绿化
和经营管理物业服务区域内的业主共有部分，维护物业服务区域内的基本秩序，
采取合理措施保护业主的人身、财产安全。
```

**专业术语**
- 物业服务人（而非"物业公司""物业"）
- 业主（而非"住户""居民""房东"）
- 共用部位（而非"公共区域""公共部分"）
- 共用设施设备（而非"公共设施""公用设备"）
- 物业管理区域（而非"小区范围""管理范围"）
- 秩序维护（而非"保安服务""安保"）

#### 2. 物业费条款

**规范表述**
```
第X条 物业服务费用
一、物业服务费的计费方式：本合同采用【包干制/酬金制】计费方式。
  （一）包干制：物业服务费用由业主按照约定的物业服务费标准向物业服务人
  支付，盈余或者亏损均由物业服务人享有或者承担；
  （二）酬金制：在预收的物业服务资金中按约定比例或者约定数额提取酬金
  支付给物业服务人，其余全部用于物业服务合同约定的支出，结余或者不足
  均由业主享有或者承担。
二、物业服务费标准：
  （一）住宅物业：每月每平方米建筑面积人民币【  】元；
  （二）非住宅物业：每月每平方米建筑面积人民币【  】元；
  （三）物业服务费按照房屋的建筑面积计算。
三、物业服务费的交纳：
  （一）业主应当按照【月/季/半年/年】为周期交纳物业服务费；
  （二）交纳期限为每个交费周期的前【  】日内；
  （三）交纳方式：【银行转账/物业服务中心现场缴费/线上支付平台】。
四、物业服务费的调整：
  （一）物业服务费标准的调整须经业主大会或者业主委员会同意；
  （二）因政府指导价调整或者物业服务成本发生重大变化的，双方可以协商
  调整物业服务费标准。
五、已竣工但尚未出售或者尚未交给物业买受人的物业，物业服务费由建设单位
交纳。
六、业主逾期未交纳物业服务费的，物业服务人可以催告其在合理期限内支付；
逾期仍不支付的，物业服务人可以依法提起诉讼或者申请仲裁。
```

**专业术语**
- 物业服务费（而非"物业费""管理费"）
- 包干制（而非"全包制""一口价"）
- 酬金制（而非"提成制""按比例收费"）
- 业主大会（而非"业主开会""居民大会"）
- 业主委员会（而非"业委会""居民委员会"）
- 建设单位（而非"开发商""地产公司"）
- 物业买受人（而非"购房者""买房人"）

#### 3. 维修养护条款

**规范表述**
```
第X条 维修养护
一、物业共用部位、共用设施设备的维修养护责任：
  （一）物业服务人负责物业共用部位、共用设施设备的日常维修和养护，
  包括但不限于：
    1. 房屋本体共用部位（屋面、外墙面、楼梯间、走廊通道、门厅等）；
    2. 共用设施设备（电梯、水泵、供配电系统、消防设施、监控系统、
    路灯照明等）；
    3. 市政公用设施（道路、排水系统、化粪池等）。
  （二）物业服务人应当制定年度维修养护计划，并报业主委员会备案。
二、日常维修的响应时间与标准：
  （一）紧急维修事项（包括水管爆裂、电梯困人、消防设施故障等）：接到
  报修后【  】分钟内到达现场，【  】小时内完成应急处理；
  （二）一般维修事项：接到报修后【  】小时内到达现场，【  】个工作日内
  完成维修；
  （三）维修记录应当及时归档保存，保存期限不少于【  】年。
三、住宅专项维修资金的使用：
  （一）物业共用部位、共用设施设备的维修和更新、改造费用，依法从住宅
  专项维修资金中列支；
  （二）住宅专项维修资金的使用须经法定程序审批；
  （三）紧急情况下需要使用住宅专项维修资金的，物业服务人可以依法申请
  应急使用。
四、因物业服务人未履行或者未适当履行维修养护义务，造成业主人身、财产
损害的，物业服务人应当依法承担赔偿责任。
```

**专业术语**
- 共用部位（而非"公共部位""公摊面积"）
- 共用设施设备（而非"公共设施""公用设备"）
- 住宅专项维修资金（而非"维修基金""大修基金""公共维修基金"）
- 日常维修（而非"日常维护""小修小补"）
- 更新改造（而非"翻新""大修"）
- 应急使用（而非"紧急动用""临时使用"）

#### 4. 安全管理条款

**规范表述**
```
第X条 安全防范管理
一、物业服务人应当在物业管理区域内建立健全安全防范管理制度，采取合理措施
维护物业服务区域内的基本秩序，保护业主的人身、财产安全。
二、安全防范管理的具体内容：
  （一）秩序维护：
    1. 物业管理区域实行【封闭式/半封闭式/开放式】管理；
    2. 物业管理区域设置【  】个出入口，配备秩序维护人员【  】名，
    实行【24小时/定时】值班制度；
    3. 对进出物业管理区域的人员、车辆实施必要的查验和登记管理。
  （二）技防设施：
    1. 在物业管理区域主要出入口、公共通道、电梯轿厢等重点部位安装
    视频监控设备；
    2. 监控录像资料保存期限不少于【  】日；
    3. 定期检查、维护安全技术防范设施设备，确保正常运行。
  （三）消防管理：
    1. 建立消防安全管理制度，定期组织消防安全检查和消防演练；
    2. 确保消防通道畅通、消防设施设备完好有效；
    3. 发现消防安全隐患及时排除，不能及时排除的应当向相关行政主管部门
    报告。
三、突发事件处置：
  （一）物业服务人应当制定突发事件应急预案，包括自然灾害、公共卫生事件、
  安全事故等；
  （二）突发事件发生时，物业服务人应当立即采取应急措施，并及时向有关
  行政主管部门报告。
四、安全防范的合理限度：物业服务人的安全防范义务不替代业主自身的安全
注意义务，亦不免除侵权人依法应当承担的侵权责任。
```

**专业术语**
- 安全防范（而非"安保""安全保卫"）
- 秩序维护人员（而非"保安""门卫"）
- 技防设施（而非"监控设备""安防系统"）
- 突发事件应急预案（而非"紧急预案""应急方案"）
- 消防安全隐患（而非"消防问题""着火隐患"）
- 行政主管部门（而非"有关部门""政府部门"）

#### 5. 合同终止条款

**规范表述**
```
第X条 合同期限与终止
一、本合同期限自【起始日期】起至【终止日期】止，期限为【  】年。
二、合同期限届满前【  】个月，双方应就合同续订事宜进行协商。合同期限
届满，双方未续订的，本合同终止。
三、业主依法共同决定解聘物业服务人的，可以解除物业服务合同，但应当提前
【六十】日书面通知物业服务人。
四、物业服务人提前终止合同的，应当提前【六十】日书面通知业主委员会或者
全体业主，并须经业主大会同意。
五、合同终止或解除后的交接：
  （一）物业服务人应当在约定期限或者合理期限内退出物业服务区域，并将
  下列资料和财物移交给业主委员会、决定自行管理的业主或者其委托的人：
    1. 物业服务用房及物业共用部位；
    2. 物业共用设施设备及相关技术资料；
    3. 物业服务档案和物业档案；
    4. 物业管理区域内的公共财物；
    5. 利用物业共用部位、共用设施设备经营产生的收益中业主应得部分。
  （二）物业服务人应当在交接期间继续维持正常的物业服务秩序。
六、物业服务人不得以业主欠交物业服务费、对业主共同决定有异议等为由，
拒绝办理交接。
七、物业服务合同终止后，原物业服务人拒不退出物业服务区域的，业主委员会
可以依法请求其退出，并承担由此造成的损失赔偿责任。
```

**专业术语**
- 解聘（而非"辞退""开除""炒掉"）
- 物业服务用房（而非"物业办公室""物业用房"）
- 交接（而非"移交""交接手续"）
- 物业服务档案（而非"物业资料""服务记录"）
- 共同决定（而非"投票决定""业主表决"）
- 退出物业服务区域（而非"搬走""撤出"）
