# 土地承包合同 标准条款模板


#### 1. 承包土地条款

**规范表述**
```
第X条 承包土地基本情况
一、发包方将位于【省/市/区/县】【乡/镇】【村/组】的下列农村土地发包给
承包方经营：
  （一）土地坐落：【  】；
  （二）土地面积：共计【  】亩（以实测面积为准），四至范围为东至【  】、
  南至【  】、西至【  】、北至【  】；
  （三）土地类型：【耕地/林地/草地/其他农用地】；
  （四）土地质量等级：【  】。
二、上述承包土地已依法确权登记，土地承包经营权证书编号为【  】，并在
农村土地承包经营权登记簿中予以记载。
三、承包土地的现状为【  】（含地上附着物、基础设施等现有状况描述），
双方签订本合同时应共同进行实地勘验，并以书面形式确认承包土地的现状及
附属设施清单，作为本合同附件。
四、发包方保证对发包土地享有合法的发包权，该土地不存在权属争议、未被
征收征用、未设定抵押或其他限制流转的情形。如因发包方原因导致承包方无法
正常经营使用承包土地的，发包方应承担相应的违约责任。
```

**专业术语**
- 发包方/承包方（而非"出租方/租户""村里/农户"）
- 农村土地承包经营权（而非"承包权""使用权"）
- 四至范围（而非"四周边界""周围到哪里"）
- 确权登记（而非"确认登记""登记确认"）
- 地上附着物（而非"地上东西""地面建筑"）
- 征收征用（而非"国家征地""政府收地"）
- 土地质量等级（而非"地好不好""土地等级"）

#### 2. 承包期限条款

**规范表述**
```
第X条 承包期限
一、本合同承包期限为【  】年，自【  年  月  日】起至
【  年  月  日】止。承包期限应符合《中华人民共和国农村土地承包法》
的规定：
  （一）耕地的承包期为三十年；
  （二）草地的承包期为三十年至五十年；
  （三）林地的承包期为三十年至七十年。
  前述承包期届满后，依法相应延长。
二、承包期内，发包方不得随意调整或收回承包地。因自然灾害严重毁损承包地
等特殊情形需对个别农户之间的承包地进行适当调整的，须经本集体经济组织
成员的村民会议三分之二以上成员或三分之二以上村民代表同意，并报乡（镇）
人民政府和县级人民政府农业农村主管部门批准。
三、承包期内，承包方全家迁入城镇落户的，应依照承包方的意愿，保留其土地
承包经营权或允许其依法自愿有偿退出。不得以退出土地承包经营权作为农户
进城落户的条件。
四、承包期届满前【  】个月，双方可协商续订承包合同。在同等条件下，
原承包方享有优先承包权。
```

**专业术语**
- 承包期限/承包期（而非"租期""合同期限"）
- 集体经济组织成员（而非"村民""村里的人"）
- 村民会议（而非"村民大会""开会"）
- 土地承包经营权（而非"包地权利""种地权"）
- 有偿退出（而非"拿钱不种了""退地拿补偿"）
- 优先承包权（而非"优先续约权""优先续租权"）
- 调整承包地（而非"换地""调地"）

#### 3. 土地用途条款

**规范表述**
```
第X条 土地用途
一、承包方应当依照法律法规及本合同约定的用途合理利用和保护土地，承包
土地的用途为【粮食种植/经济作物种植/林果业/畜牧养殖/渔业养殖/其他
农业经营】。未经依法批准，承包方不得将承包地用于非农建设。
二、承包方在承包土地上从事农业生产经营活动，应当遵守下列规定：
  （一）不得改变土地的农业用途，不得用于非农建设；
  （二）耕地应优先用于粮食和其他农产品生产，不得闲置、荒芜耕地；
  （三）不得在承包地上建造永久性建筑物、构筑物，确需建设农业设施的，
  应当符合农业设施用地管理规定并依法办理相关手续；
  （四）不得从事掠夺性经营，不得给土地造成永久性损害。
三、承包方确需改变土地用途的，应当事先取得发包方书面同意，并依法报经
相关行政主管部门审批。未经批准擅自改变土地用途的，发包方有权要求承包方
限期恢复原状，逾期未恢复的，发包方有权解除本合同，并要求承包方赔偿由此
造成的全部损失。
四、国家实施土地用途管制制度，因国家政策调整导致承包土地用途受到限制的，
双方应协商解决，合理分担由此产生的损失。
```

**专业术语**
- 非农建设（而非"盖房子""建工厂"）
- 农业用途（而非"种地用""农业用"）
- 永久性建筑物、构筑物（而非"永久建筑""固定建筑"）
- 农业设施用地（而非"农业建设用地""设施用地"）
- 掠夺性经营（而非"过度使用""不合理耕种"）
- 闲置、荒芜耕地（而非"撂荒""不种地"）
- 土地用途管制制度（而非"土地管理规定""用地限制"）

#### 4. 承包费条款

**规范表述**
```
第X条 承包费
一、承包方应向发包方缴纳承包费。承包费的标准、支付方式及支付时间约定
如下：
  （一）承包费标准：每年每亩人民币【  】元（大写：【  】元整），
  年承包费总计人民币【  】元（大写：【  】元整）；
  （二）支付方式：承包方以【现金/银行转账】方式向发包方指定账户支付；
  （三）支付时间：承包方应于每年【  月  日】前缴纳当年度承包费。
二、承包费的调整：
  （一）承包期内，承包费原则上保持稳定，非因法定事由或双方协商一致，
  发包方不得单方提高承包费；
  （二）双方约定每【  】年可依据当地农村土地经营权流转指导价格对承包费
  进行一次调整，调整幅度不超过现行承包费的【  】%；
  （三）因自然灾害等不可抗力导致承包方经营严重受损的，承包方有权请求
  减免当年度承包费，具体减免金额由双方协商确定。
三、承包方逾期缴纳承包费的，每逾期一日按照应缴承包费的万分之【  】向
发包方支付违约金。逾期超过【  】日仍未缴纳的，发包方有权书面催告承包方
在合理期限内支付；经催告后在合理期限内仍不支付的，发包方有权解除本合同。
四、承包期内，发包方不得以任何名义向承包方收取承包费以外的费用。国家
依法规定的税费由承包方依法承担。
```

**专业术语**
- 承包费（而非"租金""地租""土地租金"）
- 流转指导价格（而非"市场价""指导价"）
- 减免承包费（而非"减租""免租"）
- 经催告后在合理期限内（而非"催了以后过了一段时间"）
- 不可抗力（而非"天灾""意外"）
- 法定事由（而非"法律允许的原因"）

#### 5. 土地经营权流转条款

**规范表述**
```
第X条 土地经营权流转
一、承包方有权依法采取出租（转包）、入股或其他方式向他人流转土地经营权，
并向发包方报备。流转期限不得超过承包期的剩余期限。
二、土地经营权流转应遵循下列原则：
  （一）依法、自愿、有偿原则，任何组织和个人不得强迫或阻碍土地经营权
  流转；
  （二）流转的土地不得改变农业用途，不得用于非农建设；
  （三）流转应在公开、公正的条件下进行，同等条件下本集体经济组织成员
  享有优先权。
三、承包方流转土地经营权的，应当与受让方签订书面流转合同，明确下列主要
内容：
  （一）双方当事人基本信息；
  （二）流转土地的坐落、面积、四至、质量等级；
  （三）流转期限和起止日期；
  （四）流转方式；
  （五）流转价款及支付方式；
  （六）流转土地的用途；
  （七）双方的权利和义务；
  （八）违约责任。
四、承包方将土地经营权流转给他人的，其与发包方之间的承包关系不变，
承包方的土地承包经营权不受影响。
五、承包方通过招标、拍卖、公开协商等方式承包取得的"四荒"（荒山、荒沟、
荒丘、荒滩）土地经营权，经依法登记取得权属证书的，可以依法采取转让、
出租、入股、抵押等方式进行流转。
六、土地经营权流转后，受让方擅自改变土地用途、弃耕抛荒连续两年以上、
给土地造成严重损害或者严重破坏土地生态环境的，发包方有权要求承包方终止
土地经营权流转合同。
```

**专业术语**
- 土地经营权流转（而非"转包""转租土地"）
- 受让方（而非"接手方""下家"）
- 出租（转包）（而非"租出去""包出去"）
- 入股（而非"拿地入股""以地换股"）
- 报备（而非"汇报""通知"）
- 弃耕抛荒（而非"不种地""荒废"）
- "四荒"土地（而非"荒地""没人管的地"）
- 抵押（而非"拿地抵押""抵押贷款"）

#### 6. 土地保护条款

**规范表述**
```
第X条 土地保护
一、承包方在承包经营期间负有保护和合理利用土地的义务，应当依据科学合理
的方式从事农业生产经营，防止土地质量下降。
二、承包方应当遵守下列土地保护义务：
  （一）合理使用化肥、农药等农业投入品，推广使用有机肥料和生物防治技术，
  防止土壤污染和地力下降；
  （二）采取必要的水土保持措施，防止水土流失；
  （三）不得进行掠夺性经营，不得超负荷使用土地；
  （四）禁止在承包地上倾倒、堆放固体废物或排放有毒有害物质；
  （五）维护承包地上的农田水利设施、道路等基础设施，不得擅自毁损或拆除。
三、承包期满或合同终止时，承包方应将承包土地恢复至不低于承包时的土地
质量状况。双方应共同对土地现状进行查验并签署《土地交还确认书》。承包方
因经营行为导致土地质量下降的，应当承担恢复治理费用；造成永久性损害的，
应当赔偿损失。
四、因承包方违反土地保护义务造成生态环境损害的，承包方应当依法承担
生态环境损害修复责任。修复费用由承包方承担。
五、发包方有权对承包方的土地保护情况进行监督检查，但不得妨碍承包方
正常的生产经营活动。发现承包方存在违反本条规定情形的，有权书面通知
承包方限期整改。
六、国家或地方人民政府实施耕地保护、基本农田保护、退耕还林还草等政策
措施，双方均应遵照执行，由此给承包方造成经营损失的，承包方有权依法获得
相应补偿。
```

**专业术语**
- 农业投入品（而非"化肥农药""农业用品"）
- 水土保持措施（而非"防水土流失措施""保水保土"）
- 地力（而非"土地肥力""地劲"）
- 掠夺性经营（而非"竭泽而渔""过度耕种"）
- 生态环境损害修复责任（而非"修复环境""恢复生态"）
- 基本农田保护（而非"保护耕地""保护农田"）
- 退耕还林还草（而非"不种地改种树""退耕"）
- 土地交还确认书（而非"交地手续""还地证明"）
