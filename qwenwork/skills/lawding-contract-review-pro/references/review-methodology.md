# 合同审核方法论

基于《合同起草审查指南：三观四步法》的专业审核方法论。

---

## 一、四层审核体系

### 1. 基础层审核

**目标**：确保合同基本要素完整、表述准确

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 当事人身份 | 合同当事人身份清晰，具备签约资格 | 致命风险 |
| 标的基本信息 | 合同标的基本信息明确（名称、规格、数量、质量） | 重要风险 |
| 履行条款 | 履行期限、地点、方式具体明确 | 重要风险 |
| 违约责任条款 | 违约责任条款完整（违约金、赔偿金、救济方法） | 重要风险 |

### 2. 商业层审核

**目标**：评估商业风险和交易结构合理性

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 权利义务分配 | 权利义务分配合理（符合商业目的） | 重要风险 |
| 交易结构 | 交易结构设计合理（税务、合规、风险分配） | 重要风险 |
| 标的物/服务交付 | 标的物/服务交付条件清晰 | 重要风险 |
| 支付条款 | 支付条款设计合理（节奏、条件、保障） | 重要风险 |

### 3. 法律层审核

**目标**：确保合同合法有效、风险可控

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 法律法规符合性 | 符合相关法律法规强制性规定 | 致命风险 |
| 公序良俗 | 不违反公序良俗，合同效力稳定 | 致命风险 |
| 担保安排 | 担保安排符合法律规定（如有） | 重要风险 |
| 争议解决 | 争议解决条款有效（管辖约定明确） | 重要风险 |

### 4. 合规层审核

**目标**：确保符合内外部合规要求

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 内部审批流程 | 履行内部审批流程（如有） | 一般风险 |
| 国资/上市公司合规 | 涉及国资、上市公司的合规性（如有） | 重要风险 |
| 行业特定要求 | 行业特定要求符合（如有） | 重要风险 |
| 备案登记要求 | 合同备案、登记要求（如有） | 一般风险 |

## 二、三观分析法

### 宏观视角（交易层面）

从交易整体角度审查：

**交易类型**
- 合同类型选择是否正确
- 是否符合物权法定原则
- 是否存在违法交易模式

**交易主体**
- 主体是否存在
- 主体是否适格
- 是否具备履约能力
- 信用状况是否良好

**交易程序**
- 内部决策程序是否完备
- 是否需要行政审批
- 是否需要登记/备案

**交易时序**
- 时序安排是否合理
- 关键节点是否明确
- 是否有先决条件

### 中观视角（条款层面）

从条款结构角度审查：

**合同类型**
- 有名合同 vs 无名合同
- 单一合同 vs 混合合同

**合同体例**
- 结构是否完整
- 逻辑是否清晰

**核心条款**
- 标的是否明确
- 数量/质量是否明确
- 价款是否明确
- 履行条款是否明确

**风控条款**
- 违约责任是否明确
- 解除终止条款是否明确
- 担保保险条款是否明确
- 保密/知识产权条款是否明确

**程序条款**
- 通知与送达条款
- 争议解决条款
- 法律适用条款

### 微观视角（表达层面）

从文字表述角度审查：

**语言表达**
- 用词是否精准
- 法律术语是否准确
- 数字/日期是否准确

**逻辑结构**
- 时间是否一致
- 金额是否一致
- 引用是否准确
- 权利义务是否对应

**形式规范**
- 格式是否规范
- 签署是否规范
- 附件是否规范

## 三、审核深度配置

### 快速审核

**适用场景**：应急场景、初步审查、只需判断是否存在影响签署决策的核心风险

**审核范围**：
- 风险等级：致命风险、重要风险
- 条款类型：标的、价款、违约责任、解除条款

**详细程度**：简略。除非用户特别要求，快速审核不展开错别字、语病、格式统一等文本质量问题。

### 标准审核

**适用场景**：常规审核、日常法务工作、默认推荐给大多数用户的交付深度

**审核范围**：
- 风险等级：致命风险、重要风险、一般风险
- 条款类型：标的、数量质量、价款、履行、违约责任、解除终止、不可抗力、担保保险、争议解决
- 通用增强：文本质量、首尾附件、关键逻辑一致性

**详细程度**：标准。应覆盖错别字、语句不通、金额日期冲突、条款引用错误、主体简称混用、正文与附件冲突等影响理解、履行、证据或专业度的问题。轻微文字问题以原文批注为主，审核意见书只作汇总。

### 深度审核

**适用场景**：重要合同、复杂交易

**审核范围**：
- 风险等级：致命风险、重要风险、一般风险、轻微瑕疵
- 条款类型：所有条款
- 通用增强：标准审核全部内容，并展开格式统一、表达精修、轻微瑕疵全量批注

**详细程度**：详细

## 四、检查清单

### 宏观检查清单

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 合同类型选择 | 根据交易实质选择正确的合同类型 | 重要风险 |
| 物权法定原则 | 物权类合同需符合物权法定原则 | 致命风险 |
| 主体存在性 | 查验营业执照、存续状态 | 致命风险 |
| 主体适格性 | 是否具备相应资质、许可 | 致命风险 |
| 履约能力 | 资金、技术、业绩、信用状况 | 重要风险 |
| 内部决策程序 | 董事会决议、股东会决议、上级审批 | 重要风险 |
| 行政审批 | 谁审批、审批条件 | 致命风险 |
| 登记备案 | 登记是生效要件还是对抗要件 | 重要风险 |

### 中观检查清单

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 标的明确 | 具体、唯一、可履行 | 致命风险 |
| 数量明确 | 数量、计量单位 | 重要风险 |
| 质量标准 | 国标、行标、样品 | 重要风险 |
| 价款明确 | 金额、货币、含税、付款方式 | 重要风险 |
| 履行条款 | 时间、地点、方式 | 重要风险 |
| 违约责任 | 违约情形、违约责任、计算方式 | 重要风险 |
| 解除终止 | 解除情形、程序、后果 | 重要风险 |
| 争议解决 | 方式、机构/法院 | 重要风险 |

### 微观检查清单

| 检查项 | 说明 | 风险等级 |
|-------|------|---------|
| 用词精准 | 避免模糊词汇 | 一般风险 |
| 法律术语准确 | 定金vs订金、违约金vs赔偿金等 | 重要风险 |
| 数字准确 | 金额大小写一致 | 重要风险 |
| 日期准确 | 格式统一、起算明确 | 重要风险 |
| 签署规范 | 签字、盖章、日期、骑缝章 | 重要风险 |
