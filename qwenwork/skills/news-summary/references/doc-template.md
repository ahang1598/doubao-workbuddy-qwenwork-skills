## 分类框架

6 个固定分类，按以下规则归类：

| 分类 | 归类标准 | 典型来源 |
|------|---------|---------|
| 官方发布 & 重大更新 | 第一手官方公告、版本发布、政策变更 | 官方博客、新闻稿、监管机构公告 |
| 产品 & 技术 | 新产品发布、功能更新、技术突破 | 产品页面、技术博客、评测媒体 |
| 研究 & 论文 | 学术成果、基准测试、技术报告 | arXiv、Nature、学术会议 |
| 开源 & 工具 | 开源项目发布、开发者工具、SDK 更新 | GitHub、开发者博客 |
| 行业 & 市场 | 投融资、并购、合作、市场数据 | 财经媒体、行业报告 |
| 观点 & 分析 | 专家观点、深度分析、趋势预测 | 分析师报告、专栏文章 |

### 分类规则

- 每条新闻归入最匹配的 1 个分类
- 某分类无条目时，该分类在报告中省略
- 若某分类条目过多（>5条），保留最重要的 5 条，其余简要列出标题和链接

---

## 写入规则

### 分块策略

按以下顺序分块写入，每块 ≤1500 字符：

1. 第一块：核心要点（Callout 格式）
2. 第二块起：逐个分类写入（每个分类 1-2 块）
3. 倒数第二块：本期重点关注
4. 最后一块：附录统计表

### 格式要求

- markdown 禁止以 `#` 一级标题开头（`dws doc create --name` 已设置文档标题）
- 使用 `##` 二级标题作为分类标题
- 使用 `###` 三级标题作为新闻条目标题
- Callout 使用 `>` 引用格式
- 链接使用 `[文字](URL)` 格式
- 换行使用真实换行符，禁止字面量 `\n`

### 内容质量

- 简介：1-2 句，概述核心信息，不超过 50 字
- 详情：2-4 句，包含核心内容、关键数据、影响/意义
- 禁止复制粘贴原文大段内容，必须提炼总结
- 每条新闻的链接必须指向实际可访问的原文页面

## Few-shot 示例：从原始检索到最终写入

以下演示一条新闻从 `WebSearch` 结果到最终写入文档的完整流程。

### 第 1 步 — WebSearch 原始结果

```
WebSearch("OpenAI official announcement March 2026")
→ 返回结果中包含：
  标题: "Introducing GPT-5: A New Frontier in AI Reasoning"
  摘要: "Today we're releasing GPT-5, our most capable model..."
  URL: https://openai.com/blog/gpt-5
  搜索引擎时间标注: 2 days ago
```

### 第 2 步 — fetch 获取全文并提取时间

```
fetch("https://openai.com/blog/gpt-5")
→ 页面内容中找到：
  <time datetime="2026-03-24T09:00:00-07:00">March 24, 2026</time>
  核心内容：GPT-5 支持原生多模态推理，上下文窗口 1M tokens，
  推理基准 GPQA 得分 78.2%（GPT-4o 为 53.6%），
  API 定价 $15/1M input tokens...
```

### 第 3 步 — 时间核验

```
时间窗口：2026-03-23 ~ 2026-03-26 (UTC+8)
页面时间：2026-03-24（步骤 1 命中，<time> 标签）
判定：✅ 在窗口内，时间来源=页面
```

### 第 4 步 — 去重检查

```
已有候选列表中是否有同一事件？
→ 36氪 "GPT-5 正式发布" (2026-03-24) — 同一事件
→ 少数派 "GPT-5 来了！测评" (2026-03-25) — 同一事件
判定：3 条聚为一组，保留 OpenAI 官方博客（官方来源优先级最高）
被淘汰来源在详情中提及
```

### 第 5 步 — 最终写入格式

以下是实际传给 `dws doc update --markdown` 的内容：

```markdown
### [OpenAI] GPT-5 正式发布：原生多模态推理与百万级上下文
- **发布时间**: 2026-03-24
- **简介**: OpenAI 发布 GPT-5，支持原生多模态推理，上下文窗口扩展至 1M tokens
- **详情**: GPT-5 在推理基准 GPQA 上得分 78.2%，较 GPT-4o（53.6%）大幅提升。新模型支持图像、音频、视频的原生理解和生成，API 定价 $15/1M input tokens。本消息亦被 36氪、少数派等媒体报道
- **链接**: [Introducing GPT-5](https://openai.com/blog/gpt-5)
```

## 质量检查清单

每条新闻写入前逐项确认：

| # | 检查项 | 通过标准 |
|---|--------|---------|
| 1 | 发布时间已核验 | 有明确的时间来源（页面/URL/meta），且在窗口内 |
| 2 | 来源可信 | 指向实际可访问的原文页面，非二手转载 |
| 3 | 简介精炼 | ≤50 字，概述核心信息，无废话 |
| 4 | 详情有实质 | 包含关键数据或具体影响，非空泛描述 |
| 5 | 链接有效 | URL 来自 `WebSearch`/`fetch` 的真实返回，非编造 |
| 6 | 未重复收录 | 与已有条目不构成同一事件 |
| 7 | 分类正确 | 归入最匹配的 1 个分类 |

若任一项不通过，该条目不写入报告，在统计中计入对应剔除原因。
