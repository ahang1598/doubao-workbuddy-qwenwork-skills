# 格式与语体规范

用于格式审校、语体润色，以及 GB/T 9704-2012 相关基础规范判断。若用户模板或单位内部格式另有要求，优先执行用户模板和单位格式。

## 版面基础

用户要求正式公文格式或 `.docx` 输出时，可按以下默认值处理；模板另有规定时以模板为准：

- 纸张：A4。
- 页边距：上约 37 毫米，下约 35 毫米，左约 28 毫米，右约 26 毫米。
- 正文：优先仿宋_GB2312 或仿宋，常用三号。
- 正文行距：常见固定值 28-30 磅，或按模板保持一致。
- 段落：首行缩进 2 个汉字。
- 标题：可用方正小标宋_GBK 或相近字体，居中，常用二号。
- 版头、主体、版记等要素按模板或正式公文习惯处理。

若输出格式无法保留字体和版式，不要声称已经完全符合排版标准。

## 公文要素

正式公文或格式审校任务中，按用户材料和模板检查以下要素；材料未提供时不得补造：

- 版头：份号、密级和保密期限、紧急程度、发文机关标志、发文字号、签发人。
- 主体：标题、主送机关、正文、附件说明、发文机关署名、成文日期、印章、附注、附件。
- 版记：抄送机关、印发机关、印发日期、页码。
- 联合行文、上行文、带附件或涉密文件，应额外核对发文机关署名、签发人、附件顺序和密级期限。

## 层级序号

常用层级：

1. `一、`
2. `（一）`
3. `1.`
4. `（1）`

正式正文中避免混用相近层级、跳级编号或使用装饰性项目符号。用户模板层级稳定且不同于上述规则时，保留模板层级。

## 标题与主送机关

标题通常应包含发文机关、事由和文种，避免 `关于有关工作的通知` 这类空泛标题。

上行文主送有管辖权的上级机关；下行文主送相关下级机关或执行对象；函应对应不相隶属的来往单位。

## 日期与数字

- 中文机关文稿日期通常写作 `2026年5月27日`。
- 日期必须与用户材料一致；缺失日期不得自动使用当天日期，除非用户明确要求。
- 统计数量、百分比、文号、序号等通常使用阿拉伯数字；模板使用中文数字且口径一致时可保留。
- 单位要完整、明确，例如 `万元`、`人次`、`个工作日`。

## 标点

- 中文句子使用中文全角标点。
- 法律法规、规划方案、正式文件标题使用 `《》`。
- 避免过多括号；括号内容若是必要条件，应写入正文。
- 分号只用于并列分句较长且内部已有逗号的场景。

## 机关语体

可使用：

- `为深入贯彻落实...`
- `现就有关事项通知如下：`
- `经研究，现批复如下：`
- `请结合实际认真贯彻执行。`
- `以上请示妥否，请批示。`

应避免：

- `史无前例`、`全面领先`、`极大成功` 等无事实支撑的绝对化表述。
- `搞一下`、`尽快弄完`、`大家注意` 等口语化表达。
- 没有行动内容的空泛口号。
- 在责任主体明确时仍写 `有关部门要加强重视` 这类模糊要求。

## 常用结构

### 下行部署

目的依据 -> 总体要求 -> 重点任务 -> 时间安排 -> 责任分工 -> 保障措施。

### 上行请示

背景依据 -> 必要性 -> 拟请事项 -> 可行性或风险说明 -> 请批语。

### 情况报告

基本情况 -> 主要工作 -> 工作成效 -> 存在问题 -> 下一步安排。

### 会议纪要

会议概况 -> 议定事项 -> 责任分工 -> 跟进要求。

## 润色规则

- 减少长串抽象名词。
- 一个句子尽量只承载一个核心要求。
- 在事实允许时，把模糊目标改成可观察、可落实的动作。
- 同级标题保持语法结构一致。
- 政策文件名称和规范表述保持稳定，不随意改写。
