## 云栖大会概况

### 大会定位

"云栖大会"源于2009年的阿里云开发者大会，2015更名为"云栖大会"。杭州·云栖大会已连续举办11年，长期汇聚科技企业、开发者与产业实践者，已成为观察中国云计算与人工智能发展的重要窗口，也是面向全球的科技交流平台，累计吸引来自70个国家和地区的80万人参与，近5年来发布超1600项重要技术与产业成果。

2025年杭州云栖大会上宣布了阿里云全栈人工智能服务商的定位，2026云栖大会延续这一主题，以年度最具科技与产业意义的 Agentic AI 为锚点，立体呈现整个行业在技术、产品、落地案例等方面的产业实践。

### 大会主题

**智以致用 · Intelligence Goes Beyond**

### 时间地点

- **时间：** 2026年9月22日 - 9月24日
- **地点：** 中国 · 杭州国际博览中心

## 签到入场



### 入场时间

9月22日 - 9月24日 08:00 - 17:00

### 签到处

大会期间，设置一期、二期两个签到处入口，方便您从不同方向进入会场。

### 入场流程

**普通嘉宾：**

1. 核验门票凭证（电子门票 / 短信通知）
2. 由【畅享票通道】入场
3. 闸机刷身份证人脸识别核验
4. 安检合格入场

**持护照、港澳通行证、台胞证嘉宾：**

1. 核验门票凭证（电子门票 / 邮件通知）
2. 由【畅享票通道】入场
3. 由人工通道核验后刷闸机
4. 安检合格入场

> 带儿童或身份证件遗失，请到票务咨询台处理。

## 智能化参会服务



### 大会小程序

为参会嘉宾提供参会观展的一站直达服务，便捷获取电子票、日程安排、展览信息及参会指南。

**使用方法：** 支付宝搜索"云栖大会"或现场扫描二维码打开小程序。

### 大会 Skill

把整场大会"装进"你的 Agent。让 Agent 推荐论坛、查找展台、订阅感兴趣场次，并在论坛结束后3小时自动领取摘要。

**使用方法：** 在大会官网获取 Skill 的安装命令，在电脑端打开你的任意 Agent（推荐千问办公、Qoder），安装 Skill。

### 千仔陪你逛云栖

跟随虚拟吉祥物"千仔"，边逛展、边提问、边完成趣味任务领取奖品，还有机会偶遇行业大咖。

**使用方法：** 扫描现场二维码进入即可使用。

### 睿译宝同声传译

提供中、英、日多语言翻译，让海内外嘉宾沟通无界、便利参会。

**使用方法：** 扫描各会场专属二维码，选择需要的语言，即可享受专业、实时的同声传译服务。

## 参会 FAQ



### Q1：大会时间、参加方式及地点？

大会于9月22日至9月24日举办，地点设在杭州国际博览中心一期和二期。参会者需通过云栖大会官网注册门票方可现场参会。

### Q2：门票种类及定价？

设有三类门票：


| 门票类型       | 价格      |
| ---------- | ------- |
| 云栖精选 - 全通票 | 4999元/张 |
| 云栖精选 - 优享票 | 1099元/张 |
| 云栖畅享票      | 免费注册    |




### Q3：门票包含的权益？

- **全通票：** 享有开幕式、各主论坛、三日展览、商务午餐、专属通道及精选礼包等权益。
- **优享票：** 不包含开幕式，其余权益与全通票基本一致。
- **畅享票：** 需选择参会日期，包含技术主论坛及所选日期的展览与专题论坛。
- 所有专题论坛座位"先到先得"。闭门会议仅限受邀者。



### Q4：报名渠道？

官方唯一指定注册渠道：**云栖大会官网**。

### Q5：为什么要提交身份证信息？

依据相关部门对大型活动的安全要求实行实名登记。入场需持注册时填写一致的身份证件原件进行人脸核验，非本人无法入场。

### Q6：如何开具发票？

支持申请电子普票或专票。购票者可在9月28日后登录官网门票页面申请，开票链接通过短信发送。发票基于订单开具且信息不可修改，提交申请后将在3-7个工作日发送到申请邮箱。

### Q7：退票政策是什么？

仅支持官网购票用户退票，截止时间为9月15日24时。需发送退票申请至官方邮箱，三个工作日内处理，款项会在七个工作日内退还原支付账户。

### Q8：能否更换或转赠用票人？

一人一票，不可转让。

### Q9：一人能否持多张票？

每人仅能持有一张门票。同一个手机号和同一个身份证件号仅限注册一张门票。

### Q10：如何查看门票？

注册成功后可通过注册或购票链接查看，也可登录官网在"门票"页面查看门票状态。

### Q11：签到进场方式？

注册成功后会收到短信通知。参会当天需携带注册时使用的身份证件原件现场核验。全通票和优享票嘉宾可使用现场专属通道入场。

### Q12：入场时间安排？

开放时间为9月22日 - 9月24日 8:00 - 18:00。每日17:00后停止入场，需提前规划行程。

### Q13：参会人年龄限制？

18周岁以下用户需注册门票，且须由法定监护人全程陪同，并在现场签署《未成年人承诺书》。
