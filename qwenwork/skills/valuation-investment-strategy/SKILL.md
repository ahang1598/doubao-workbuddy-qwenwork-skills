# 估值投资策略

在事实基础（战略、业务、财务、行业、风险）完成后，构建情景化估值分析。

## 不可违背的原则

- 公开证据缺失时，不得凭空捏造输入数据
- 每个关键假设必须关联公开来源或明确标注为分析性估计
- 使用情景分析替代虚假精度（如单一精确目标价）
- 事实与主观判断、交易计划严格分离
- 所有中间输出和最终输出默认使用简体中文

## 适用时机

- 已完成公司全景分析（战略、业务、财务、行业、风险），需要进入估值框架
- 公司处于转型期，简单PE估值不足以反映真实价值
- 报告需要明确列出熊市、基准、牛市三种情景及各自假设

---

## 估值方法选择指南

根据商业模式和数据质量选择合适的估值方法。

| 方法 | 最适用场景 | 注意事项 |
| --- | --- | --- |
| **PE（市盈率）** | 盈利稳定的业务 | 转型期亏损或一次性损益会扭曲估值结果 |
| **EV/EBITDA** | 重资产及基础设施类资产 | EBITDA可能忽略资本开支负担，需结合资本回报率判断 |
| **PB（市净率）** | 资产驱动或周期性资产负债故事 | 账面价值可能滞后于真实经济价值 |
| **SOTP（分部估值）** | 混合商业模式或业务转型故事 | 需要仔细界定各分部边界，避免重复计算 |
| **DCF（现金流折现）** | 现金流路径清晰可见的业务 | 现金流不稳定时容易产生虚假精度 |
| **资产基础法** | 房地产、数据中心、资源类资产 | 需要合理的使用率假设和折价调整 |

**转型类公司的建议**：优先使用SOTP或基于情景的EV/EBITDA，并辅以资产负债表检查。

**填写要求**：
- 收入假设：明确增长率或绝对金额，说明驱动因素（量/价）
- 利润率假设：毛利率或净利率水平，说明成本结构变化
- 现金流假设：资本开支强度、营运资金变化、自由现金流转化率
- 估值倍数/方法：选择上述指南中最适合的方法，说明倍数选取依据
- 隐含价值：计算得出的每股或整体估值区间
- 主要来源：标注每个假设的公开数据来源（财报、研报、行业数据等）

## 工作流程

1. **汇总前期分析输出**：提取战略、业务、财务、行业、风险五个维度的核心结论
2. **选择估值方法**：根据商业模式和数据质量，从六种方法中选择最适合的一种或组合
3. **定义情景表**：围绕收入、利润率、资本开支、使用率、资产负债表等维度设定三种情景
4. **关联假设与来源**：每个关键假设必须关联支撑性来源或标注为分析性估计
5. **输出价值区间与决策点**：得出估值区间、投资论点检查点和失效触发条件

---

## 投资计划输出要求

在估值分析完成后，必须输出具体的投资行动计划，包含以下三要素：

### 建仓条件
- 明确在什么价格区间或估值水平下开始建仓
- 说明触发建仓的具体事件或催化剂（如业绩拐点、政策落地、资产注入等）

### 止损条件
- 明确在什么情况下止损离场（如价格跌破某阈值、基本面逻辑被证伪等）
- 设定具体的失效触发条件（如利润率持续下滑、负债率突破警戒线等）

### 投资论点确认里程碑
- 列出未来需要验证的关键节点（如季度财报、产能爬坡进度、合同签署等）
- 说明每个里程碑如何确认或否定投资论点

## IDC/AI算力转型估值叠加指南

当标的为IDC运营商或正在向AI算力转型的公司时，需在基础估值流程上叠加以下专项分析。

### 数据来源映射

| 来源类型 | 支撑内容 | 查询入口 |
| --- | --- | --- |
| 公司年报及中期报告 | 资产基础、资本开支、债务结构、业务分部、已披露使用率 | https://www.cninfo.com.cn |
| 融资公告 | 资金假设、项目经济性、稀释路径 | https://www.cninfo.com.cn |
| 同业交易所披露 | 可比公司估值倍数及商业模式对比 | https://www.cninfo.com.cn |
| 工信部/发改委政策 | 影响行业叙事和区域节点布局逻辑的政策支撑 | https://www.miit.gov.cn |

### 方法选择提示

- **SOTP**：当公司仍持有传统工程或制造业资产，同时拥有新建IDC资产时，优先使用SOTP分部估值
- **EV/EBITDA**：需谨慎使用，因为重资本开支可能导致EBITDA看起来比真实股东回报更好
- **资产基础法/重置成本法**：仅在有现实路径实现资产变现和电力接入的情况下使用
- **DCF**：仅在使用率、爬坡进度和融资假设已明确披露或可合理设定时使用

### 必须强制检查的输入项

- 资产装载或使用率提升路径是否清晰
- 业务结构：一次性交付与持续性运营的比例
- 债务成本及到期结构
- 达到稳态运营前还需投入的额外资本开支
- 项目延期、合同修订或爬坡放缓的概率评估

### 输出要求

明确区分以下三类估值上行驱动因素：
- **依赖执行的估值上行**：需要公司完成具体项目或达成运营目标
- **依赖融资缓解的估值上行**：需要债务重组、股权融资或利率环境改善
- **依赖真实经常性变现的估值上行**：需要客户留存、合同续签和收入结构优化

---

## 标准输出结构

最终报告必须包含以下五个板块：

1. **事实**：与估值相关的事实，包括可比公司集合、资产基础、融资约束条件
2. **解读**：最适合的估值方法及其选择理由
3. **待验证问题**：缺失的使用率、利润率、资本开支或资产处置假设
4. **情景表**：熊市、基准、牛市三种情景，每个假设均关联来源
5. **投资计划**：建仓条件、止损条件、投资论点确认里程碑

## 边界约束

- 不得从零重建公司原始事实库（应基于前期分析输出）
- 不得展示无支撑的虚假精度（如精确目标价而不给区间）
- 不得忽略风险和资产负债表约束
