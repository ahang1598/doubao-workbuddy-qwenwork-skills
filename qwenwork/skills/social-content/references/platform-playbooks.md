# 平台打法详细指南

本文件为 social-content 技能的平台适配参考。AI 在生成内容时必须读取本文件，按目标平台的规则适配内容。

> 注意：平台规则会随时间变化，建议定期更新本文件。标注日期的数据以标注时间为准。

---

## 小红书

### 基本规范

| 项目 | 规则 |
|------|------|
| 标题字数 | ≤ 20 字（含 emoji） |
| 正文字数 | ≤ 1000 字（建议 500-800 字效果最佳） |
| 封面图 | 3:4 竖版图最佳，首图决定点击率 |
| Hashtag | 3-8 个，混合热门标签和精准长尾标签 |
| 内容类型 | 图文笔记、视频笔记 |

### 内容结构模板

```
标题: [数字/情绪词] + [核心利益点]
例: "3 个被低估的效率神器，第 2 个我天天在用"

正文结构:
1. 钩子开头（1-2 句，制造好奇或共鸣）
2. 正文分点（用 emoji 作为每段标记，3-5 个要点）
3. 产品/方案植入（自然融入，不硬广）
4. 互动引导（提问 + 收藏引导 + 关注引导）

尾部固定格式:
- "觉得有用的话记得 ⭐ 收藏，下次找得到～"
- "关注我，持续分享 XX 干货"
```

### 算法偏好

- 完读率 > 互动率 > 点击率，内容要让人看完
- 首图点击率是第一道门槛
- 发布后 1 小时内的互动数据决定初始流量池
- 评论区互动（回复评论）可以二次激活流量
- 收藏率高的内容更容易被长期推荐

### 标题公式

| 公式 | 示例 |
|------|------|
| 数字 + 结果 | "5 个习惯让我效率翻倍" |
| 身份 + 痛点 | "打工人必看！这个工具救了我的周报" |
| 反常识 | "别再用 XX 了，试试这个方法" |
| 对比 | "用了这个之后，再也回不去了" |
| 情绪 + 干货 | "后悔没早知道的 3 个职场真相" |

### 避坑事项

- 不要在标题中出现"最好""第一""绝对"等绝对化用语
- 不要直接放外部链接（小红书不支持正文外链）
- 避免纯文字无分段，必须用 emoji 或序号分段
- 避免过度营销语气，小红书用户对硬广敏感

### 最佳发布时间

- 工作日: 12:00-13:00, 18:00-20:00, 21:00-23:00
- 周末: 10:00-12:00, 14:00-16:00, 20:00-22:00

## 微信公众号

### 基本规范

| 项目 | 规则 |
|------|------|
| 标题字数 | ≤ 64 字（建议 15-25 字，朋友圈分享只显示部分） |
| 正文字数 | 建议 1500-2500 字（本技能处理范围），>3000 字路由到长文技能 |
| 封面图 | 头条 2.35:1，次条 1:1 |
| 摘要 | ≤ 120 字，出现在分享卡片中 |
| 内容类型 | 图文、图片消息 |

### 内容结构模板

```
标题: [强信息密度，说清核心价值]
例: "为什么你的 AI 工具用了等于没用？问题出在这 3 步"

摘要: 概括文章核心价值，制造点击欲望

正文结构:
1. 开头（前 3 行定生死，要么制造共鸣要么抛出悬念）
2. 小标题分段（每段 300-500 字，配小标题便于扫读）
3. 核心论点 + 案例/数据支撑
4. 总结与行动建议
5. 引导关注 + 转发 + 留言互动

固定尾部:
- "如果觉得有帮助，欢迎转发给需要的朋友"
- "你怎么看？评论区聊聊"
```

### 算法偏好

- 打开率取决于标题和封面，朋友圈分享是主要传播渠道
- 完读率影响后续推荐（公众号推荐流）
- "在看"和转发是最重要的互动指标
- 发布后 2 小时内的阅读增长曲线影响推荐权重

### 避坑事项

- 标题不要做标题党，打开后内容不匹配会被取关
- 正文不要大段无分段，必须用小标题切分
- 不要依赖纯文字，适当插入配图提升阅读体验
- 避免诱导分享的话术（"不转不是中国人"之类），会被限流

### 最佳发布时间

- 工作日: 7:30-8:30（通勤）, 12:00-13:00（午休）, 20:00-22:00（晚间）
- 周末: 9:00-10:00, 15:00-17:00

## 微博

### 基本规范

| 项目 | 规则 |
|------|------|
| 正文字数 | ≤ 2000 字（建议 ≤ 300 字效果最佳，超 140 字需点击展开） |
| 话题标签 | #话题名# 格式，1-3 个 |
| @功能 | 可 @相关账号提升互动 |
| 内容类型 | 短文、图文、视频、头条文章 |

### 内容结构模板

```
短微博（≤ 140 字，不折叠）:
[首句即观点/钩子] + [1-2 句展开] + [CTA 或互动提问]
+ #话题标签# @相关账号

中长微博（140-300 字）:
[钩子] + [核心内容 2-3 段] + [结论/CTA]
+ #话题标签#

示例:
"AI 不会取代你，但会用 AI 的人会。
上周用 AI 工具帮团队把周报时间从 2 小时缩到 15 分钟，
关键不是工具多牛，而是你怎么拆解任务给它。
分享 3 个我验证过的用法 ↓↓↓
#AI效率# #职场干货#"
```

### 算法偏好

- 转发和评论权重最高
- 热搜话题带来公域流量，蹭热点要快但要有自己的观点
- 首条评论可以补充信息或放链接
- 互动（回复评论）能延长内容生命周期

### 避坑事项

- 超过 140 字会折叠，核心信息必须在前 140 字说完
- 不要在正文放长链接（影响阅读体验），放评论区
- 不要同时带太多话题标签，1-3 个最佳
- 避免搬运其他平台内容不做适配

### 最佳发布时间

- 工作日: 8:00-9:00, 12:00-14:00, 21:00-23:00
- 热点类内容: 越快越好，不受时间限制

## 抖音

### 基本规范

| 项目 | 规则 |
|------|------|
| 视频时长 | 15 秒 / 60 秒 / 3 分钟 / 15 分钟（建议 30-60 秒） |
| 标题字数 | ≤ 55 字 |
| Hashtag | 2-5 个 |
| 内容类型 | 短视频（口播、情景、教程、Vlog） |

### 脚本结构模板

```
前 3 秒（定生死）:
[冲突/反常识/结果前置/痛点提问]
例: "你知道为什么你的方案总被打回吗？"

中间段（15-45 秒）:
[分点讲解 / 故事推进 / 操作演示]
每 5-8 秒一个信息点，保持节奏

结尾（5-10 秒）:
[总结 + CTA]
例: "学会了吗？关注我，下期教你 XX"

脚本格式:
| 时间 | 画面描述 | 口播文字 | 字幕/特效 |
|------|---------|---------|----------|
| 0-3s | 面对镜头，表情夸张 | "你还在用 XX 方法？难怪效率上不去" | 大字幕强调 |
| 3-15s | 切换到屏幕录制 | "今天教你一个方法..." | 步骤编号 |
| ... | ... | ... | ... |
```

### 算法偏好

- 完播率 > 互动率 > 关注转化率
- 前 3 秒跳出率是最关键指标
- 评论区互动能触发二次推荐
- 发布后 1 小时是黄金流量窗口
- 同一时段频繁发布会互相抢流量

### 避坑事项

- 前 3 秒不要铺垫，直接给冲突或结果
- 不要节奏太慢（信息密度不够会被划走）
- 不要出现其他平台水印（限流）
- 不要使用违禁词、绝对化用语

### 最佳发布时间

- 工作日: 7:00-8:00, 12:00-13:00, 18:00-19:00, 21:00-23:00
- 周末: 10:00-12:00, 15:00-17:00, 20:00-22:00

## 视频号

### 基本规范

| 项目 | 规则 |
|------|------|
| 视频时长 | 建议 1-3 分钟（比抖音可以更长更深入） |
| 标题/描述 | ≤ 1000 字 |
| Hashtag | 3-5 个，#话题 格式 |
| 内容类型 | 短视频、直播 |

### 内容特点

视频号与抖音的核心区别在于分发逻辑——视频号依赖社交推荐（朋友点赞你能看到），所以内容要有"值得分享"的属性。

```
适合的内容方向:
- 知识分享/行业洞察（让人觉得"转发显得我专业"）
- 品牌故事/幕后花絮（让人觉得"这公司挺有意思"）
- 实用教程（让人觉得"收藏下次用得上"）

脚本节奏:
- 比抖音稍慢，可以多一些解释和铺垫
- 但开头仍然需要钩子，不能做流水账
- 重点在传递价值，而非娱乐性
```

### 避坑事项

- 不要照搬抖音内容，视频号受众偏成熟、偏职场
- 不要纯娱乐内容，知识/价值类内容在视频号表现更好
- 标题要清晰传递价值，不要纯标题党

## 微信朋友圈

### 基本规范

| 项目 | 规则 |
|------|------|
| 可见字数 | 前 6 行（约 120 字）不折叠，超出需点击"全文" |
| 图片 | 1/3/6/9 张，建议 3 或 9 张排版最整齐 |
| 链接 | 可分享公众号文章或小程序 |
| 内容类型 | 文字 + 图片 / 文字 + 链接 |

### 内容结构模板

```
朋友圈文案（≤ 6 行，确保不折叠时信息完整）:

人设型:
"今天团队用 AI 工具把 3 天的方案缩到半天搞定，
有时候效率的提升不是靠加班，是靠选对工具。
分享给同样在找效率突破口的朋友。"

产品软植入型:
"最近被问最多的一个问题：XX 怎么用？
整理了 3 个最实用的场景 ↓
（配图放操作截图或效果对比图）"

日常分享型:
"周五下班前的小确幸——
这周的 OKR 全绿，还提前交了两个方案。
秘密武器就是 XX，真的谁用谁知道。"
```

### 关键规则

- 前 6 行必须完整表达核心信息，不要把重点放在折叠区
- 口语化、真实感，避免官方广告腔
- 配图要真实有质感，不要用明显的素材图
- 发圈频率不宜过高，每天 1-2 条为佳
- 适合做品牌人设、软植入和社交信任建设，不适合硬广

## LinkedIn

### 基本规范

| 项目 | 规则 |
|------|------|
| 正文字数 | ≤ 3000 字符（建议 800-1300 字符效果最佳） |
| 链接 | 正文内放链接会降低分发，建议放评论区 |
| Hashtag | 3-5 个 |
| 内容类型 | 文字帖、图片帖、文章（Article）、轮播文档 |

### 内容结构模板

```
钩子（首句，≤ 15 词，独占一行）
↓
空行
↓
观点展开（2-3 段，每段 2-4 行）
↓
关键洞察/数据（如有）
↓
行动建议或 CTA
↓
Hashtag

示例:
"Most AI tools fail — not because of the tech.

It's because teams skip one critical step: defining what 'good output' looks like.

Last month our team ran an experiment:
→ Group A: gave AI raw prompts
→ Group B: gave AI structured briefs with examples

Result? Group B's output quality was 3x higher.

The lesson: AI is only as good as your input framework.

What's your experience? Drop a comment below 👇

#AI #Productivity #Leadership"
```

### 算法偏好

- 前 90 分钟的互动决定推荐量级
- 评论 > 转发 > 点赞（评论权重最高）
- 长评论（>15 词）比短评论权重更高
- 自己主动回复评论能触发二次分发
- 轮播文档（PDF）的完读率和停留时间表现突出

### 避坑事项

- 正文内不要放外部链接，会被降权
- 不要纯分享链接不加个人观点
- 不要用太多 emoji（LinkedIn 语境偏专业）
- 不要照搬公众号长文，需要改写为 LinkedIn 口吻

### 最佳发布时间（UTC+8 参考）

- 工作日: 8:00-10:00, 17:00-18:00
- 周二至周四效果最佳

## X (Twitter)

### 基本规范

| 项目 | 规则 |
|------|------|
| 单条字数 | ≤ 280 字符（中文约 140 字） |
| Thread | 多条串联，适合深度内容 |
| Hashtag | 1-2 个（过多降低互动） |
| 内容类型 | 推文、Thread、图片、视频、投票 |

### 内容结构模板

```
单条推文:
[强观点/钩子] + [1 句展开] + [CTA 或提问]

Thread 结构:
1/ [钩子 + 预告: "分享 X 个关于 XX 的经验 🧵"]
2/ [第 1 个要点]
3/ [第 2 个要点]
...
N/ [总结 + CTA: "如果有用，RT 让更多人看到"]

示例:
"Hot take: Most 'productivity tips' make you busier, not better.

Here's the only framework that actually works 🧵"
```

### 算法偏好

- 回复和引用转推权重最高
- 发布后 30 分钟的互动决定分发
- Thread 的展开率（有多少人点开看完）是关键
- 带图/视频的推文曝光量高于纯文字

### 避坑事项

- 不要把长文硬塞进 280 字符，用 Thread
- Hashtag 不要超过 2 个，太多显得不专业
- 不要连续发推不间隔，建议间隔 1-2 小时

## Instagram

### 基本规范

| 项目 | 规则 |
|------|------|
| 文案字数 | ≤ 2200 字符（建议 ≤ 500 字符） |
| Hashtag | 5-15 个（放正文末尾或首条评论） |
| 内容类型 | 帖子（图片/轮播）、Reels（短视频）、Stories（24h 限时） |
| 图片比例 | 方形 1:1，竖版 4:5，横版 1.91:1 |

### 内容结构模板

```
图文帖:
[1 句钩子] + [2-3 句正文] + [CTA]
↓
Hashtag 块（首条评论或正文末尾）

Reels 脚本:
- 同抖音脚本结构，但可稍偏生活方式/美学风格
- 配乐选择很重要，使用热门音频能增加曝光

轮播帖（Carousel）:
- 第 1 页: 标题/钩子（让人想划下一页）
- 中间页: 每页 1 个要点
- 最后页: CTA + 关注引导
```

### 避坑事项

- Instagram 是视觉优先平台，配图质量决定一切
- 不要发低分辨率图片
- Hashtag 不要全用超热门标签（竞争太大），混合使用

## Facebook

### 基本规范

| 项目 | 规则 |
|------|------|
| 正文字数 | ≤ 63206 字符（建议 ≤ 500 字符） |
| 内容类型 | 帖子、图片/视频、直播、活动、群组帖 |
| 链接 | 可放正文，但纯链接帖互动低 |

### 内容结构模板

```
[提问或故事开头] + [核心内容] + [CTA/互动引导]

示例:
"Quick question for founders:

What's the ONE tool you couldn't run your business without?

For us, it's been [tool name] — saved our team ~10 hours/week on reporting.

Drop yours in the comments 👇"
```

### 关键规则

- 提问式开头能显著提升评论量
- 视频内容（特别是直播）在 Facebook 有流量加权
- 群组（Group）帖子的互动率远高于主页帖
- 适合本地化业务、社区运营、活动推广
