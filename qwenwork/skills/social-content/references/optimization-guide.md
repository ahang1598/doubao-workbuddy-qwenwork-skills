# 互动优化指南

本文件为 social-content 技能的内容优化参考。AI 在用户要求"优化互动""内容没人看""数据不好"时必须读取本文件。

---

## 内容诊断框架

当用户反馈"内容效果不好"时，按以下顺序逐项排查：

### 第 1 步：检查钩子

| 问题 | 症状 | 修复方向 |
|------|------|---------|
| 钩子太弱 | 曝光量尚可但点击/完读率低 | 换用更强的钩子公式（参见 hook-formulas.md） |
| 钩子与正文脱节 | 点击率高但跳出率也高 | 钩子承诺的内容正文必须兑现 |
| 钩子信息太密 | 用户看不懂就划走 | 首句只做一件事：让人想继续看 |

### 第 2 步：检查平台适配

| 问题 | 症状 | 修复方向 |
|------|------|---------|
| 内容格式不匹配 | 比如在小红书发纯文字无 emoji | 按平台规则重新排版（参见 platform-playbooks.md） |
| 字数超出最佳范围 | 微博超 140 字被折叠，关键信息看不到 | 缩减到平台最佳字数范围 |
| 语气不匹配 | 在小红书用 LinkedIn 的正式口吻 | 按平台受众调整语气 |
| 搬运不改写 | 多平台版本雷同，哪个平台都不突出 | 必须从母稿独立改写每个平台版本 |

### 第 3 步：检查 CTA

| 问题 | 症状 | 修复方向 |
|------|------|---------|
| 无 CTA | 用户看完不知道干什么 | 补充明确的行动引导 |
| CTA 太多 | 又要关注又要收藏又要转发又要点链接 | 每条内容只保留 1 个核心 CTA |
| CTA 太模糊 | "欢迎交流" 不如 "评论区告诉我你的做法" | 用具体动作替代泛化表达 |

### 第 4 步：检查发布时间

| 问题 | 症状 | 修复方向 |
|------|------|---------|
| 发在非活跃时段 | 内容质量不差但曝光量低 | 参考各平台最佳发布时间（见 platform-playbooks.md） |
| 多条同时发 | 内容互相抢流量 | 间隔 2-4 小时发布 |

### 第 5 步：检查内容本身

| 问题 | 症状 | 修复方向 |
|------|------|---------|
| 选题太泛 | "如何提升效率"太空洞 | 收窄到具体场景："用 AI 把周报时间缩到 15 分钟" |
| 缺乏差异化 | 内容和竞品同质化 | 加入独特视角、个人经历或独家数据 |
| 无事实支撑 | 内容空泛像广告 | 补充具体案例、数据、截图 |
| 信息密度低 | 读完没有获得感 | 增加信息密度，删除废话 |

## 各平台核心指标与优化重点

### 小红书

| 核心指标 | 优化方向 |
|---------|---------|
| 封面点击率 | 封面图设计：大字标题、对比图、数字、清晰的利益点 |
| 完读率 | 内容分段清晰、每段有信息增量、emoji 辅助阅读节奏 |
| 收藏率 | 内容有"以后用得上"的属性：清单、教程、模板、对比 |
| 互动率（评论） | 末尾引导提问："你们平时用什么方法？评论区聊聊" |

**快速优化清单：**
- 封面有没有大字标题？
- 标题有没有数字或情绪词？
- 正文有没有用 emoji 分段？
- 末尾有没有互动引导？
- Hashtag 是不是混合了热门 + 长尾？

### 微信公众号

| 核心指标 | 优化方向 |
|---------|---------|
| 打开率 | 标题优化：信息密度高、制造好奇、与读者相关 |
| 完读率 | 小标题分段、每段 300-500 字、重点加粗 |
| 分享/在看 | 内容有"转发价值"：让转发者显得专业/有品位/关心他人 |
| 留言数 | 文末抛出开放性问题 |

**快速优化清单：**
- 标题是否在 25 字以内说清了核心价值？
- 前 3 行是否制造了继续看的理由？
- 是否有小标题方便扫读？
- 末尾是否有转发和留言引导？

### 微博

| 核心指标 | 优化方向 |
|---------|---------|
| 转发量 | 内容有观点或情绪，让人想"说两句" |
| 评论量 | 用提问句结尾，降低评论门槛 |
| 热搜关联 | 关联当日热搜话题，但要有自己的角度 |

**快速优化清单：**
- 核心信息是否在 140 字内（不折叠区域）说完？
- 是否带了 1-3 个相关话题标签？
- 首句是否足够有力？

### 抖音

| 核心指标 | 优化方向 |
|---------|---------|
| 完播率 | 前 3 秒定生死：冲突/结果/痛点，中间保持节奏 |
| 互动率 | 视频结尾引导评论："你觉得哪个方法最好用？打在评论区" |
| 关注转化 | 展示持续价值："关注我，每天分享一个 XX 技巧" |
| 分享率 | 内容有"帮别人解决问题"的属性 |

**快速优化清单：**
- 前 3 秒是否直接给冲突/结果/收益？
- 节奏是否紧凑？（每 5-8 秒一个信息点）
- 是否有字幕和视觉强调？
- 结尾是否有 CTA？

### LinkedIn

| 核心指标 | 优化方向 |
|---------|---------|
| 评论数 | LinkedIn 评论权重最高；用洞察/观点引发讨论 |
| Dwell time | 内容让人停下来读完；轮播 PDF 效果突出 |
| 个人回复 | 主动回复每条评论，触发二次分发 |

**快速优化清单：**
- 首句是否独占一行形成视觉钩子？
- 是否有具体数据或案例支撑观点？
- 链接是否放在评论区而非正文？
- 是否在发布后 90 分钟内回复了评论？

### X (Twitter)

| 核心指标 | 优化方向 |
|---------|---------|
| 回复和引用转推 | 有态度的观点更容易引发讨论 |
| Thread 展开率 | 第 1 条推文决定有多少人展开看完 |
| 30 分钟互动 | 发布后 30 分钟的互动决定分发量 |

**快速优化清单：**
- 是否在 280 字符内说完了核心信息？
- Thread 首条是否有足够的钩子？
- Hashtag 是否控制在 1-2 个？

## A/B 变体策略

当用户对效果不确定时，建议生成 2-3 个变体：

| 变体维度 | 说明 | 示例 |
|---------|------|------|
| 角度变体 | 同一主题用不同切入角度 | 角度 A: 效率提升 / 角度 B: 成本节约 / 角度 C: 个人故事 |
| 钩子变体 | 同一内容换不同开头 | 钩子 A: 数字型 / 钩子 B: 反常识型 / 钩子 C: 提问型 |
| 语气变体 | 同一内容换不同语气 | 语气 A: 专业严谨 / 语气 B: 轻松亲切 / 语气 C: 犀利直接 |
| CTA 变体 | 同一内容换不同行动号召 | CTA A: 引导评论 / CTA B: 引导收藏 / CTA C: 引导点击 |

建议做法：
1. 给用户展示 2-3 个变体的首段和 CTA
2. 用户选择偏好的版本
3. 基于选定版本完善全文

## 常见问题诊断表

| 用户说 | 可能原因 | 优化方向 |
|--------|---------|---------|
| "发了没人看" | 钩子弱 / 发布时间不对 / 选题太泛 | 先查钩子和发布时间，再查选题 |
| "阅读量还行但没互动" | CTA 缺失或模糊 / 内容缺乏讨论性 | 强化 CTA，增加开放式提问 |
| "粉丝不涨" | 内容没有关注动机 / 缺少持续价值承诺 | 增加系列感，展示后续内容预告 |
| "内容像广告" | 太硬 / 缺乏价值 / 没有人设感 | 先提供价值再植入，增加个人视角 |
| "数据时好时坏" | 内容质量不稳定 / 缺乏规划 | 建立内容支柱和排期，保持稳定输出 |
| "不知道写什么" | 缺少内容支柱和选题框架 | 先定义 3-5 个内容支柱，再从中选题 |
