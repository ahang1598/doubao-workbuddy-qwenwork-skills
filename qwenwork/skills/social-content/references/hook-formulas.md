# 钩子公式与模板

本文件为 social-content 技能的开头钩子参考。AI 生成内容时，必须根据平台和内容类型选择合适的钩子公式。

> 原则：钩子只承担"让人继续看"的职责，不要在首句塞满信息。钩子后 1-2 句必须快速交代收益或场景。

---

## 通用钩子公式

适用于所有平台，按平台语气调整表达方式。

### 1. 数字型

用具体数字制造"值得看"的预期。

| 公式 | 示例 |
|------|------|
| {数字} + {结果/方法} | "5 个习惯让我效率翻倍" |
| {数字} + {时间} + {结果} | "3 个月从 0 到 10 万粉，我只做对了这一件事" |
| {百分比} + {变化} | "用了这个方法，方案通过率提升了 80%" |
| 只需 {数字} 步 | "只需 3 步，用 AI 自动生成周报" |

### 2. 好奇型

制造信息缺口，让人必须继续看。

| 公式 | 示例 |
|------|------|
| 我以前一直误解了 {X} | "我以前一直误解了远程办公的核心问题" |
| {X} 的真相，和你想的不一样 | "效率工具的真相，和你想的不一样" |
| 很少有人知道的 {X} | "很少有人知道的 Excel 隐藏功能" |
| 99% 的人都搞错了 {X} | "99% 的人都搞错了复盘的第一步" |

### 3. 反常识型

打破认知惯性，制造"怎么可能"的反应。

| 公式 | 示例 |
|------|------|
| 别再 {常见做法} 了 | "别再用 to-do list 管理时间了" |
| {常见做法} 正在拖垮你 | "每天写日报正在拖垮你的效率" |
| {A} 不如 {B} | "加班 3 小时不如学会这个方法" |
| 这个 {X} 其实是错的 | "你以为的高效沟通，其实是在浪费时间" |

### 4. 结果前置型

先说结果，再说方法，让人好奇"怎么做到的"。

| 公式 | 示例 |
|------|------|
| 我用 {方法} 实现了 {结果} | "我用 1 个 AI 工具，把周报时间从 2 小时缩到 15 分钟" |
| {结果}，只因为做对了 {一件事} | "团队效率翻倍，只因为做对了一件事" |
| 从 {A} 到 {B} 的关键 | "从月薪 8k 到年薪 50w，转折点在这" |

### 5. 痛点共鸣型

直击目标受众的日常痛点。

| 公式 | 示例 |
|------|------|
| 如果你也 {痛点} | "如果你也每周为写周报头疼" |
| {痛点场景}，看完这篇就够了 | "方案总被打回？看完这篇就够了" |
| {人群} 最怕的就是 {痛点} | "运营人最怕的就是月底交不出数据" |

### 6. 故事型

用叙事开头，激发好奇心。

| 公式 | 示例 |
|------|------|
| 上周发生了一件事 | "上周团队复盘时，我发现了一个被忽略的问题" |
| {时间}前，我还在 {困境} | "半年前，我还在每天加班到 11 点" |
| 一个客户跟我说 {X} | "一个客户跟我说：你们这个功能救了我的命" |

### 7. 提问型

用问题直接卷入读者。

| 公式 | 示例 |
|------|------|
| 你有没有想过 {X}？ | "你有没有想过，为什么同样的工具别人用得好你用不好？" |
| 为什么 {现象}？ | "为什么 90% 的内容发了没人看？" |
| {场景}，你会怎么选？ | "老板让你 1 天出 3 版方案，你会怎么办？" |

## 平台专属钩子策略

### 小红书

小红书钩子侧重"人设感"和"干货承诺"，语气亲切、真实。

| 适合的钩子类型 | 示例 |
|-------------|------|
| 身份 + 经验 | "做了 3 年运营，这些弯路你别再走了" |
| 后悔体 | "后悔没早知道！这 5 个工具真的绝了" |
| 分享体 | "姐妹们！这个宝藏工具我不允许你不知道" |
| 对比体 | "用之前 vs 用之后，效率差距也太大了" |
| 合集体 | "我的 2024 效率工具清单（自用分享）" |

### 微信公众号

公众号钩子要在前 3 行（朋友圈可见的部分）说清价值。

| 适合的钩子类型 | 示例 |
|-------------|------|
| 现象洞察 | "你有没有发现，越来越多的公司开始砍掉周报了？" |
| 观点开门 | "我始终认为，AI 不是来取代人的，是来放大人的" |
| 数据开门 | "据统计，职场人每天花在无效会议上的时间超过 2.5 小时" |
| 悬念开门 | "今天这篇文章，我想跟你聊一个大多数管理者不愿承认的问题" |

### 微博

微博钩子必须在 140 字（不折叠区域）内完成信息传递。

| 适合的钩子类型 | 示例 |
|-------------|------|
| 热点借势 | "看完今天的热搜，说点不一样的观点——" |
| 短句观点 | "AI 不会取代你，但会用 AI 的人会。" |
| 吐槽共鸣 | "打工人的周一，永远从"今天加班吗"开始" |

### 抖音/视频号

视频钩子要在前 3 秒说完，语速快、信息密度高。

| 适合的钩子类型 | 示例 |
|-------------|------|
| 冲突型 | "你还在用 XX 方法？难怪效率上不去" |
| 结果型 | "用了这个工具之后，我再也没加过班" |
| 反问型 | "你知道为什么你的方案总被打回吗？" |
| 恐惧型 | "如果你不知道这个功能，你可能白忙了一个月" |

### LinkedIn

LinkedIn 钩子偏专业、洞察型，首句独占一行形成视觉钩子。

| 适合的钩子类型 | 示例 |
|-------------|------|
| 洞察型 | "Most AI tools fail — not because of the tech." |
| 经验型 | "After managing 50+ product launches, here's what I learned:" |
| 反常识型 | "Unpopular opinion: Daily standups are killing productivity." |
| 数据型 | "Teams that replaced weekly reports with async updates saw 30% more output." |

### X (Twitter)

X 钩子要极短、极锐、有态度。

| 适合的钩子类型 | 示例 |
|-------------|------|
| Hot take | "Hot take: Most 'productivity tips' make you busier, not better." |
| 极简洞察 | "The best content strategy is consistency, not virality." |
| Thread 预告 | "I've spent 5 years building audience on X. Here's everything I know 🧵" |

## 钩子质量检查清单

生成钩子后用以下标准自检：

| 检查项 | 通过标准 |
|--------|---------|
| 是否在 1-2 句内制造继续看的理由 | 读完首句有"然后呢？"的感觉 |
| 是否与目标受众相关 | 受众能在 1 秒内判断"这和我有关" |
| 是否与后续内容匹配 | 钩子承诺的内容正文有兑现 |
| 是否符合平台语气 | LinkedIn 不用"姐妹们"，小红书不用"Unpopular opinion" |
| 是否避免标题党 | 钩子夸张但不欺骗 |
