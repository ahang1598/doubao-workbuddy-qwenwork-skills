# 要素式民事起诉状格式规范

> 本文件仅在以下场景被读取：(a) 用户在 Step 1.5 选择「要素式」或「两种都要」；(b) Step 2 案由命中《通知》11 类白名单且触发合规提示。**不要在其他场景开局预读**。

## 一、规范依据

最高人民法院《关于印发部分案件民事起诉状、答辩状示范文本（试行）的通知》（以下简称《通知》）发布了 11 类高频民事案件的要素式起诉状示范文本。对于这些案件，**人民法院可能要求当事人按要素式提交起诉状**，部分立案窗口已将要素式作为立案受理的形式要件之一。

## 二、《通知》明确覆盖的 11 类案由白名单

下列 11 类案由属于《通知》示范文本范围，本技能必须在 Step 2 案由识别后**主动重点提示**用户考虑使用要素式：

## 三、本技能附加覆盖的模板（非《通知》白名单但常用）

为最大化「严格按模板输出」的覆盖率，`references/templates/element-based/` 目录另附下列模板，用户主动要求要素式时同样按模板填充：

- **保险类**：人身保险合同纠纷、财产损失保险合同纠纷、责任保险合同纠纷
- **房屋类**：房屋买卖合同纠纷、房屋租赁合同纠纷
- **建工类**：建设工程施工合同纠纷
- **海事类**：海事 人损、海事 船员劳务合同纠纷、海事 船舶碰撞损害责任纠纷、海事 货运代理
- **知识产权**：不正当竞争、侵害发明专利权、侵害商业秘密、侵害商标权、侵害外观设计专利权、侵害植物新品种权、侵害著作权及邻接权、垄断、技术合同（共 9 项）
- **环境类**：环境污染公益诉讼、生态环境损害赔偿诉讼、生态破坏公益诉讼

## 四、生成路由规则（脚本调用方决策）

```
案由名 → 在 references/templates/element-based/ 中匹配模板文件？
├── 命中（11 类或附加覆盖）→ 「严格按模板填充」模式
│   └── 用 python-docx 打开模板 docx，按要素项 key 替换占位（保留表格、复选框、字体）
└── 未命中 → 「通用要素式」模式
    └── 按下方「通用要素式骨架」生成 Word
    └── 文档开头必须加注释：
        "⚠ 本案由不在最高人民法院《关于印发部分案件民事起诉状、答辩状
         示范文本（试行）的通知》要素式示范文本覆盖范围，本文按通用要
         素式结构输出，仅供参考。建议立案前向受理法院核实是否接受。"
```

## 六、11 类案由核心要素项清单

下列要素清单用于「严格按模板填充」模式时构造 JSON 输入。每类列出**诉讼请求要素**与**事实要素**。

### 1. 金融借款合同纠纷
- 诉讼请求要素：本金 / 利息 / 复利 / 罚息 / 提前还款或解除合同 / 担保权利（抵押权、质权、保证）/ 实现债权的合理费用（律师费、保全费等）
- 事实要素：合同签订情况（时间、文本编号） / 贷款人与借款人主体身份 / 借款金额 / 借款期限 / 借款利率 / 借款发放时间 / 还款情况 / 担保情况 / 催收情况

### 2. 银行信用卡纠纷
- 诉讼请求要素：透支本金 / 利息（含分期手续费、滞纳金、违约金）/ 实现债权费用
- 事实要素：领卡及合同签订 / 透支金额与时间 / 还款记录 / 催收情况

### 3. 民间借贷纠纷
- 诉讼请求要素：本金 / 利息（不超过 LPR 4 倍）/ 提前还款或解除合同 / 担保权利 / 实现债权费用
- 事实要素：合同签订情况 / 出借人与借款人身份 / 借款金额 / 借款期限 / 借款利率 / 款项交付时间与方式 / 还款方式 / 还款情况 / 催收情况

### 4. 保证保险合同纠纷
- 诉讼请求要素：保险金赔付 / 代位求偿 / 解除合同 / 担保权利 / 实现债权费用
- 事实要素：保险合同签订情况 / 保险标的 / 保险事故发生 / 理赔申请与拒赔情况

### 5. 买卖合同纠纷
- 诉讼请求要素：支付货款 / 迟延利息或违约金 / 卖方违约损失赔偿 / 标的物瑕疵责任 / 继续履行或解除合同 / 担保权利 / 实现债权费用
- 事实要素：合同签订情况 / 买卖双方身份 / 标的物信息（名称、规格、数量、单价）/ 价款与付款方式 / 交付时间与地点 / 履行情况 / 验收情况

### 6. 物业服务合同纠纷
- 诉讼请求要素：物业费 / 滞纳金或违约金 / 解除合同 / 恢复服务 / 实现债权费用
- 事实要素：物业服务合同签订 / 房屋情况 / 物业服务期间 / 收费标准 / 业主缴费情况 / 物业履约情况

### 7. 融资租赁合同纠纷
- 诉讼请求要素：支付全部未付租金（含留购价款）/ 违约金、滞纳金、损害赔偿金 / 租赁物所有权确认 / 解除合同 / 返还租赁物及损害赔偿 / 担保权利 / 实现债权费用
- 事实要素：合同签订情况 / 出租人与承租人身份 / 租赁物信息 / 租金及支付方式 / 履行情况 / 留购或返还约定

### 8. 证券虚假陈述责任纠纷
- 诉讼请求要素：赔偿投资差额损失 / 佣金损失 / 印花税损失 / 连带责任主体认定 / 实现债权费用
- 事实要素：被告虚假陈述行为情况 / 监管部门认定或处罚 / 原告交易记录（买入卖出时间与价格）/ 虚假陈述重大性 / 因果关系分析 / 原告损失计算

### 9. 机动车交通事故责任纠纷
- 诉讼请求要素：医疗费 / 护理费 / 营养费 / 住院伙食补助费 / 误工费 / 交通费 / 残疾赔偿金 / 残疾辅助器具费 / 死亡赔偿金 / 丧葬费 / 精神损害抚慰金 / 财产损失
- 事实要素：交通事故发生情况（时间、地点、经过）/ 交通事故责任认定（事故认定书编号、责任划分）/ 机动车投保情况（交强险、商业三者险）/ 损失情况 / 救治与鉴定情况

### 10. 劳动争议纠纷
- 诉讼请求要素：拖欠工资 / 未签书面合同二倍工资 / 加班费 / 未休年休假工资 / 未缴社保损失 / 解除经济补偿 / 违法解除赔偿金 / 工伤待遇
- 事实要素：劳动合同签订情况 / 劳动合同履行情况（岗位、工资、工作时间）/ 解除或终止劳动关系情况 / 工伤情况 / 劳动仲裁前置情况（裁决书编号、裁决结果）/ 其他特殊情况

### 11. 离婚纠纷
- 诉讼请求要素：解除婚姻关系 / 夫妻共同财产分割（房屋、汽车、存款、股权、基金等明细）/ 共同债务承担 / 子女直接抚养 / 子女抚养费 / 探望权 / 离婚损害赔偿或经济补偿
- 事实要素：婚姻关系基本情况（登记时间、登记机关）/ 生育子女情况（姓名、性别、出生年月日）/ 双方生活情况 / 离婚事由（感情破裂的具体事实）/ 财产情况（婚前 / 婚后）/ 债务情况 / 子女抚养现状

## 七、与传统起诉状的关键差异

| 维度 | 传统起诉状 | 要素式起诉状 |
|---|---|---|
| 诉讼请求 | 自由叙述式 | 按要素勾选 + 分项填空 |
| 事实和理由 | 连贯段落叙述 | 按编号要素逐项填写 |
| 当事人信息 | 段落式列出 | 表格化字段 |
| 证据组织 | 文中"详见在案证据"指引 | 与事实要素一一对应 |
| 立案审查 | 形式审查灵活 | 便于法院自动化数据提取 |
| 适用范围 | 通用 | 案件类型专门化 |

## 八、编号与符号约定

- 一级序号：`1.` `2.` `3.`
- 二级序号：`(1)` `(2)` `(3)`
- 三级序号：`①` `②` `③`
- 多选 / 单选框：`☐`（未选）/ `☑`（已选）—— 文本表达为 `是☐ 否☐`，填充时仅修改对应框
- 填空线：`______`，填充时直接替换为内容文本
- 无内容的要素：填「无」或「/」，**严禁留空**
