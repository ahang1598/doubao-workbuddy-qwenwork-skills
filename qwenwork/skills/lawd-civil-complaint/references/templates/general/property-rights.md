# 物权类纠纷专项规则（property-rights.md）

> **前置加载**：本文件须在读取 `general-general.md` 后使用。  
> 涵盖：物权确认、返还原物、排除妨害、消除危险、相邻关系、共有分割、业主权益。

> ⚠ **注意**：返还原物和排除妨害有独立的深度专项文件（基于大量案例总结），如案件属于侵权大案由，优先使用 `../tort/return-property.md` 和 `../tort/exclusion-obstruction.md`。本文件适用于物权确认、共有分割、相邻关系等非侵权路径的物权纠纷。

---

## 一、物权类常见请求权基础

| 子案由 | 主要法条 | 主要主张 |
|-------|---------|---------| 
| 物权确认 | 民法典 §234 | 确认所有权 / 用益物权 / 担保物权 |
| 返还原物 | 民法典 §235 | 物在被告处占有，请求返还 |
| 排除妨害 | 民法典 §236 | 停止侵害行为、清除占用 |
| 消除危险 | 民法典 §236 | 消除已经形成的危险状态 |
| 修理重作更换恢复 | 民法典 §237 | 物受损害的恢复请求 |
| 相邻关系 | 民法典 §288–§296 | 通行、采光、通风、排水、噪音等 |
| 共有 | 民法典 §297–§310 | 分割共有物、行使共有权 |
| 业主权益 | 民法典 §271、§278、§280 | 业主大会决议、撤销权 |

## 二、诉讼请求范例

### 1. 物权确认
```
1. 判令确认位于 ___ 的 ___（不动产 / 动产，描述）归原告所有（或：原告享有 ___% 的份额）；
2. 本案诉讼费由被告承担。
```

### 2. 共有物分割
```
1. 判令依法分割原告与被告共同所有的 ___（财产名称、坐落 / 标识）：
   方案一：原物分割 → 原告分得 ___，被告分得 ___;
   方案二：变价分割 → 公开拍卖该财产，所得价款由原告与被告按 ___ 比例分配；
   方案三：折价补偿 → 该财产归原告所有，由原告向被告支付折价款 ___ 元；
2. 本案诉讼费由原被告共同承担。
```

### 3. 相邻关系（通行 / 采光）
```
1. 判令被告停止 ___（具体妨害行为），恢复 ___（通行 / 采光 / 排水）正常状态；
2. 判令被告赔偿原告损失人民币 ___ 元；
3. 本案诉讼费由被告承担。
```

## 三、特别注意事项

### 1. 物权类
- **专属管辖**：不动产纠纷由不动产所在地法院管辖（民诉法 §35），相邻关系、共有不动产、确权等均适用
- **诉讼时效**：返还原物请求权不适用诉讼时效（民法典 §196 第二项；动产为善意取得制度调整）
- **物权确认 + 返还原物**可合并起诉，形成"先确认 + 后给付"诉讼结构

### 2. 共有物分割
- 按份共有人有权随时请求分割（民法典 §305），共同共有人在共有关系终止时分割（§307）
- 分割方式选择顺序：原物分割优先 → 变价分割 → 折价补偿
- 不动产分割须注明：取得房屋所有权一方须向其他共有人支付"折价补偿款"

### 3. 相邻关系
- 相邻关系纠纷属不动产纠纷，专属管辖于不动产所在地法院
- 须具体描述妨害行为，法院通常要求现场勘验
- 迟延履行金须在诉讼请求中明确写入

## 四、事实理由结构（物权类通用）

```
[第1段] 原告权利基础
    不动产权证书/土地使用权证/购买合同+付款凭证（见证据×）

[第2段] 被告侵权/妨害事实
    具体行为+时间+位置（见证据×）
    催告记录（见证据×）

[第3段] 损害后果
    财产损失/使用权损失/占用费（见证据×）

[第4段] 请求权基础
    援引顺序：民法典§234（确认）/§235（返还）/§236（排除妨害/消除危险）/
    §297–§310（共有）/§288–§296（相邻关系）→民诉法§35（专属管辖）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```
