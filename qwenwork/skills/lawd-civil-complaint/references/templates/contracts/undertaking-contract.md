# 承揽合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「承揽合同纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年334件案例，261件胜诉（含部分胜诉），系统提炼裁判规律。

---

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 支付承揽报酬 | 民法典 §770（承揽合同定义）、§783（报酬支付）、§781（验收义务） |
| 逾期付款利息 | 民法典 §577、§579 |
| 修理重作/减少报酬 | 民法典 §781（工作成果不符合质量要求） |
| 赔偿损失 | 民法典 §577、§584 |
| 解除合同 | 民法典 §787（定作人任意解除权）、§563（法定解除权） |

## 二、诉讼请求标准表述（按胜诉频率排序）

### 第一项：支付承揽报酬（72案，最核心请求）

```
判令被告向原告支付承揽报酬人民币×元×角×分
（含：合同约定报酬×元；增项工作报酬×元；扣除已付款×元）；
```

**专业术语规则**：
- **民法典施行后（2021年1月1日起）统一使用「承揽报酬」**，禁止使用「劳务费」「工程费」「服务费」等非规范表述
- 加工合同可用「加工款」，定作合同可用「定作款」，均属承揽报酬的具体形态
- 金额须**精确到分**（元角分均须写明），不得取整
- 须同时列明大写金额

### 第二项：赔偿逾期付款利息损失/资金占用损失（255案，最高频附属请求）

**表述一（LPR基准，无约定时）**：
```
以人民币×元为基数，按照全国银行间同业拆借中心公布的
一年期贷款市场报价利率（LPR），
自×年×月×日起计算至实际清偿之日止，
作为逾期付款利息损失；
```

**表述二（LPR倍数，合同约定利率时）**：
```
以人民币×元为基数，按照全国银行间同业拆借中心公布的
一年期贷款市场报价利率（LPR）的1.5倍，
自×年×月×日起至实际付清之日止；
```

**表述三（合同约定利率）**：
```
以人民币×元为基数，按合同约定年利率×%计算，
自×年×月×日起至实际清偿之日止；
```

**专业术语规则**：
- 区分「逾期付款利息损失」（损失赔偿性质）与「违约金」（惩罚性质）：**二者不能同时主张**（民法典§577，不得重复计算）
- 起算日：有合同约定付款日的，从约定日次日起算；无约定的，从催告之日次日起算，或从诉状送达之日次日起算

### 第三项：违约金（59案，须与利息请求择一主张）

```
判令被告支付违约金人民币×元（按合同第×条约定，
以承揽报酬×元为基数，按日/月×%计算，
自×年×月×日起暂计至起诉日×年×月×日止）；
```

**注意**：违约金与逾期利息损失不得同时主张，择高选择。

### 第四项：赔偿损失（材料损失/停工损失）

```
判令被告赔偿原告损失人民币×元，具体包括：
①材料损失×元（见证据×：采购凭证/入库单）；
②人工窝工损失×元（见证据×：用工记录）；
③其他直接损失×元；
合计×元；
```

## 三、事实与理由结构（承揽合同专版）

```
[第1段] 合同签订
    ×年×月×日，原告（承揽人）与被告（定作人）签订《×××合同》
    （合同编号：×××），约定：
    承揽内容：[加工/定作/修理/复制/测试/检验]×××；
    合同价款：人民币×元；
    完工期限：×年×月×日前；
    付款方式：[预付款×元，完工验收后付清余款/按进度付款]；
    验收标准：[合同约定标准/行业标准/国家标准]（见证据1）。

[第2段] 原告履约情况（守约方身份确立）
    合同签订后，原告按约组织实施，于×年×月×日完成全部工作
    并向被告提交工作成果（见证据×：交付记录/验收单）。
    被告于×年×月×日[验收合格/实际接收使用]
    （见证据×：验收报告/接收确认）。
    [增项工作：在原合同基础上，经被告书面/口头确认，
    原告另完成增项工作，增加费用×元（见证据×：变更确认单）。]

[第3段] 被告违约
    合同约定被告应于×年×月×日前支付承揽报酬×元，
    然而被告仅支付×元，尚欠承揽报酬×元（含增项×元）
    至今未付（见证据×：付款记录/银行流水）。

[第4段] 催告过程
    原告曾于×年×月×日以书面方式向被告催告，
    要求其于×日内支付欠付报酬，被告至今未予回应
    （见证据×：催告函及送达凭证）。

[第5段] 损失量化
    被告拒不支付承揽报酬，给原告造成以下损失：
    ①欠付承揽报酬×元；
    ②逾期付款利息损失×元（以×元为基数，按LPR，
      自×年×月×日起暂计至×年×月×日止）；
    合计×元。

[第6段] 法律依据
    综上，被告拒不支付承揽报酬的行为已严重违反双方合同约定
    及《中华人民共和国民法典》第七百七十条至第七百八十七条之规定。
    为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 四、承揽合同纠纷特殊注意事项

### 4.1 验收规则（高频争议）
- 被告拒绝验收时：须证明工作成果已交付（交付记录、快递凭证、微信确认）
- 被告实际使用工作成果的：法院通常认定为默认验收合格（民法典§782）
- 无书面验收的：可主张被告未在合理期限内提出异议视为验收合格

### 4.2 法条引用顺序规范
```
请求权基础援引顺序（必须遵守）：
① 先援引承揽合同专章（民法典§770—§787）
② 再援引违约责任通则（§577—§585）
③ 最后援引诉讼法依据（民诉法§122）
禁止仅笼统引用「民法典相关规定」
```

### 4.3 数字精确性要求（承揽合同专属严格标准）
- 金额精确到分（角分均须写明），如「×元×角×分」或「×.××元」
- 日期精确到日，不得写「×月底」或「×月份」
- 计算期间须写明起止日期及天数，如「自2023年3月15日起至2024年5月20日止，共431日」

### 4.4 条款引用精确性要求
- 合同条款须引用至「第×条第×款第×项」，不得笼统引用
- 法律条文须引用至具体条文，如「《民法典》第782条第2款」

## 五、承揽合同纠纷自检清单

- ☐ 承揽合同（含变更/补充协议）已列入证据清单
- ☐ 工作成果交付记录/验收单已列入证据清单
- ☐ 已付款凭证已列入证据清单
- ☐ 增项工作确认单（如有增项）已列入证据清单
- ☐ 催告函及送达凭证已列入证据清单
- ☐ 承揽报酬金额精确到分（含大写）
- ☐ 逾期利息与违约金未同时主张（择一主张）
- ☐ 法条引用顺序：承揽专章 → 违约责任通则 → 诉讼法
- ☐ 守约方身份确立：原告履约陈述先于被告违约陈述
- ☐ 证据前置：每一关键事实均括注「见证据×」
