# 劳务合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「劳务合同纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **重要区分**：劳务合同纠纷（民事）≠ 劳动合同纠纷（劳动仲裁前置）。本文件适用于平等民事主体之间的劳务关系，不适用于劳动法调整的劳动关系。
> **数据来源**：近五年337件案例，原告胜诉率约85.8%（含部分胜诉）。

---

## 一、劳务合同 vs 劳动合同的关键区分（首要判断）

| 维度 | 劳务合同（民事） | 劳动合同（劳动法） |
|------|---------------|----------------|
| 主体关系 | 平等民事主体 | 从属性（人身+经济双重从属） |
| 典型主体 | 退休返聘人员、个人承包者、自由职业者、劳务派遣工 | 在职员工 |
| 争议解决 | 直接向法院起诉（无需仲裁前置） | 须先经劳动仲裁 |
| 适用法律 | 民法典合同编 | 劳动法、劳动合同法 |

**被告常见抗辩**：主张双方系劳动关系，要求法院移送劳动仲裁。须在事实中明确陈述劳务合同的平等主体性质，并附上书面劳务合同作为证据。

---

## 二、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 支付劳务报酬 | 民法典 §509（全面履行）、§577（违约责任）、§579（金钱债务） |
| 逾期付款利息 | 民法典 §577；利率按LPR |
| 违约金 | 民法典 §585；合同约定 |
| 连带责任（建筑施工） | 《保障农民工工资支付条例》§30（总承包单位连带责任） |
| 赔偿损失 | 民法典 §577、§584 |

## 三、诉讼请求标准表述（按胜诉频率排序）

### 第一项：支付劳务报酬（最核心请求）

```
判令被告向原告支付劳务报酬人民币×元
（合同约定报酬×元，已付×元，欠付×元）；
```

**专业术语规则**：
- 使用「劳务报酬」，**禁止**使用「工资」「薪酬」「劳动报酬」（劳动法用语）
- 金额精确到分，须同时列明大写

### 第二项：支付逾期付款利息/资金占用损失

```
以欠付劳务报酬×元为基数，自×年×月×日
（合同约定付款日次日/催告之日次日）起至实际清偿之日止，
按照全国银行间同业拆借中心公布的贷款市场报价利率（LPR）
计算资金占用损失；
```

### 第三项：建筑施工总承包单位连带责任（28.5%案件涉及，胜诉率极高）

```
判令被告[总承包单位全称]对上述第一项劳务报酬
人民币×元及利息承担连带清偿责任；
```

**依据**：《保障农民工工资支付条例》第30条：建筑施工总承包单位对拖欠农民工工资承担连带清偿责任。

**须在事实中明确陈述**：
```
被告[总承包单位]系案涉工程的建筑施工总承包单位，
原告系[分包单位/劳务班组]的劳务人员，
依据《保障农民工工资支付条例》第30条之规定，
被告[总承包单位]应对拖欠原告劳务报酬承担连带清偿责任。
```

### 第四项：支付违约金（22%案件涉及，须双轨准备）

```
判令被告支付违约金人民币×元（按合同第×条约定，
以欠付劳务报酬×元为基数，按×%计算，
自×年×月×日起暂计至起诉日止）；
```

## 四、事实与理由结构（劳务合同专版）

```
[第1段] 合同签订（明确平等主体关系）
    ×年×月×日，原告（劳务提供方）与被告（劳务接受方）
    以平等民事主体身份签订《×××劳务合同》
    （合同编号：×××），约定：
    劳务内容：[具体劳务内容]；
    劳务期限：×年×月×日至×年×月×日；
    劳务报酬：人民币×元（[总价/月×元/按完成工作量计算]）；
    付款方式：[按月支付/完工后一次性支付]（见证据1）。

[第2段] 原告履约情况（守约方身份确立）
    合同签订后，原告按约提供劳务，于×年×月×日完成
    全部/约定阶段性劳务工作（见证据×：工作完成记录/
    被告确认单/考勤记录）。

[第3段] 被告违约
    合同约定被告应于×年×月×日前支付劳务报酬×元，
    然而被告仅支付×元，尚欠劳务报酬×元至今未付
    （见证据×：付款记录/银行流水/欠条）。

[第4段] 催告过程
    原告曾于×年×月×日以[书面/微信]方式催告被告支付，
    被告[未予回应/承诺但未履行/明确拒绝]
    （见证据×：催告记录）。

[第5段] 建筑施工连带责任（如涉及多层分包）
    被告[总承包单位]系案涉工程的建筑施工总承包单位，
    依据《保障农民工工资支付条例》第30条，
    应对拖欠原告劳务报酬承担连带清偿责任。

[第6段] 法律依据
    综上，被告拒不支付劳务报酬的行为已严重违反双方合同约定
    及《中华人民共和国民法典》第五百七十七条之规定。
    为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 五、证据证明力排序（欠付金额认定）

| 证据类型 | 证明力 | 说明 |
|---------|--------|------|
| 欠条/对账确认书（被告签字） | **最强** | 被告书面确认债务，几乎必然全额支持 |
| 微信转账记录+聊天记录 | **强** | 结合工作内容能形成完整证明链 |
| 工资结算单/工资明细表 | **强** | 用人单位自制文件，对其不利时直接采信 |
| 银行流水+考勤表 | **中** | 须结合其他证据综合认定 |
| 证人证言 | **弱** | 单独使用时法院通常要求补强证据 |

## 六、劳务合同纠纷自检清单

- ☐ 劳务合同（书面合同/微信记录）已列入证据清单
- ☐ 劳务完成证明（工作记录/考勤/被告确认单）已列入证据清单
- ☐ 已付款凭证已列入证据清单
- ☐ 欠条/对账确认书（如有）已列入证据清单
- ☐ 催告记录已列入证据清单
- ☐ 建筑施工：总承包单位身份证明（营业执照/施工许可证）已列入证据清单
- ☐ 劳务报酬使用规范术语（非「工资」「劳动报酬」）
- ☐ 劳务关系 vs 劳动关系：已在事实中明确平等主体性质，防止被告抗辩移送仲裁
- ☐ 违约金双轨：主位（约定）+ 备位（防调减）
