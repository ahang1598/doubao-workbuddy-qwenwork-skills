# 租赁合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「租赁合同纠纷」（含房屋租赁、设备租赁、融资租赁）时读取。须先读取 `contract-general.md`，再读取本文件。

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 支付租金 | 民法典 §703（租赁合同定义）、§722（承租人支付租金义务） |
| 返还租赁物 | 民法典 §735（返还租赁物） |
| 解除合同 | 民法典 §722（逾期付租金解除）、§563（法定解除权） |
| 赔偿损失 | 民法典 §577、§584 |
| 支付违约金 | 民法典 §585；合同约定 |
| 支付逾期利息 | 民法典 §577、§579 |

## 二、诉讼请求标准表述

### 出租人作为原告（追讨租金/要求返还租赁物）

**第一项：支付欠付租金**
```
判令被告向原告支付欠付租金人民币×元
（×年×月×日至×年×月×日，共×期，
每期租金×元，已付×元，欠付×元）；
```

**第二项：支付逾期付租金违约金/资金占用损失**
```
以欠付租金×元为基数，自×年×月×日（付租期限届满次日）起
至实际清偿之日止，按照全国银行间同业拆借中心公布的
贷款市场报价利率（LPR）计算资金占用损失；
```

**第三项：解除合同（逾期付租金达一定期限时）**
```
判令解除原、被告于×年×月×日签订的《×××租赁合同》；
```
依据：民法典 §722（承租人无正当理由未支付或迟延支付租金，
出租人催告后合理期限内仍未支付的，出租人可以解除合同）

**第四项：返还租赁物**
```
判令被告于本判决生效后×日内将位于[地址]的[租赁物描述]
返还给原告，并恢复至正常使用状态；
```

**第五项：赔偿损失（租赁物损毁/逾期占用）**
```
判令被告赔偿原告因[租赁物损毁/逾期占用]造成的损失
人民币×元，具体包括：
①修缮费×元（见证据×：维修报价/发票）；
②逾期占用期间的占用费×元（自×至×，按月×元计算）；
合计×元；
```

### 承租人作为原告（要求返还押金/赔偿损失）

**第一项：返还押金/保证金**
```
判令被告向原告返还押金（保证金）人民币×元；
```

**第二项：赔偿损失（出租人违约未能提供合格租赁物）**
```
判令被告赔偿原告因[出租人违约行为]造成的损失
人民币×元，包括：
①已付租金损失×元；
②搬迁费×元；
③重新租房差价损失×元；
合计×元；
```

## 三、事实与理由结构（租赁合同专版）

### 出租人追讨租金版本：

```
[第1段] 合同签订
    ×年×月×日，原告（出租人）与被告（承租人）签订
    《×××租赁合同》（合同编号：×××），约定：
    租赁物：[房屋地址/设备名称]；
    租赁期限：×年×月×日至×年×月×日；
    月租金：人民币×元，每月×日前支付；
    押金：人民币×元；
    违约责任：[合同约定违约金条款]（见证据1）。

[第2段] 原告履约（交付租赁物）
    合同签订后，原告于×年×月×日将[租赁物]
    交付被告使用，被告已实际接收并使用至今
    （见证据×：交接记录/入住确认）。

[第3段] 被告违约（拒付租金）
    合同履行过程中，被告自×年×月×日起未按约定支付租金，
    截至×年×月×日，被告累计欠付租金人民币×元
    （×期，每期×元，已付×元）（见证据×：付款记录）。

[第4段] 催告过程
    原告曾于×年×月×日向被告发出《催租通知》，
    要求其于×日内补缴欠付租金，被告至今未予支付
    （见证据×：催告函及送达凭证）。

[第5段] 损失量化
    被告欠付租金给原告造成损失：
    ①欠付租金×元；
    ②资金占用损失×元（以×元为基数，按LPR，
      自×年×月×日起暂计至起诉日止）；
    合计×元。

[第6段] 法律依据
    综上，被告拒不支付租金的行为已严重违反双方租赁合同约定
    及《中华人民共和国民法典》第七百零三条至第七百三十四条之规定。
    为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 四、租赁合同纠纷特殊注意事项

### 4.1 解除合同的前提条件（民法典§722）
出租人以欠租为由解除合同，须满足：
1. 承租人无正当理由未支付或迟延支付租金
2. 出租人已催告
3. 催告后合理期限内仍未支付

**表述规范**：须在事实中明确催告时间、方式及催告后未支付的事实。

### 4.2 押金/保证金返还规则
- 押金性质：担保性质，非违约金；租赁期满后无违约情形应全额返还
- 可扣减项：合同约定的损毁赔偿、欠付租金；须有明确约定和证据
- **禁止**：未经合同约定擅自没收押金

### 4.3 逾期占用费计算
租赁合同解除后承租人仍占用租赁物的，出租人可主张：
- 按原租金标准计算逾期占用费（最常见）
- 或按市场价格计算（须有评估报告）

### 4.4 房屋租赁合同特殊规则（《民法典》§725）
- 「买卖不破租赁」：租赁物所有权转移不影响租赁合同效力
- 承租人优先购买权（§726）：出租人出售租赁物须提前通知承租人
- 不定期租赁（§730）：双方均可随时解除，但须给对方合理准备期

## 五、租赁合同纠纷自检清单

- ☐ 租赁合同（含补充协议）已列入证据清单
- ☐ 租赁物交付记录已列入证据清单
- ☐ 已付租金凭证已列入证据清单
- ☐ 催告函及送达凭证已列入证据清单
- ☐ 欠付租金金额计算：期数 × 月租金 - 已付 = 欠付
- ☐ 逾期利息起算日：约定付租日次日
- ☐ 解除合同（如主张）：已催告且合理期限内仍未支付
- ☐ 返还租赁物请求（如主张）：明确返还期限
- ☐ 损毁赔偿（如主张）：有维修报价/发票支撑
