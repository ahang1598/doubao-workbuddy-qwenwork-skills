## 一、合同纠纷请求权基础分析框架（Anspruchsmethode）

所有合同纠纷起诉状的请求权基础分析须按以下顺序展开：

```
① 合同是否有效成立？（民法典 §465、§502、§143）
② 原告义务是否已履行（或已提出履行）？
③ 被告是否存在违约行为？（民法典 §577）
④ 原告主张的救济方式是什么？（继续履行 / 损害赔偿 / 违约金 / 解除）
⑤ 是否有担保（保证 / 抵押 / 质押）？
```

## 二、合同条款强制阅读规则（合同纠纷必须执行）

> **核心要求**：凡涉及合同纠纷，**必须充分、全面阅读合同全文**，重点核查以下四类条款，并据此分析诉讼请求策略。未执行本节的，视为起草前置工作不完整。

### 2.1 双方权利义务条款

- 逐条识别原告的合同义务（交货/付款/提供服务/完成工作等）及已履行情况
- 逐条识别被告的合同义务及违约情况
- **目的**：确立"原告守约、被告违约"的基本叙事框架，为事实与理由第1—3段提供素材

### 2.2 违约责任条款

- 提取违约金约定（金额/比例/计算方式/起算日）
- 识别违约金是否同时覆盖逾期付款损失（判断违约金与利息能否并存，见§九）
- 识别是否有律师费、鉴定费等维权费用约定（见§十）
- 识别定金条款（有则判断是否触发定金罚则）
- **目的**：确定可主张的违约责任类型和金额上下限

### 2.3 合同解除条款

- 识别约定解除权条款（合同约定的解除情形）
- 对照民法典第563条识别法定解除权是否成就
- 判断解除通知是否已发出（决定用"确认解除"还是"判令解除"，见§五）
- 识别解除后的清算安排（已付款项返还、损失赔偿等）
- **目的**：确定解除路径和解除后的救济请求

### 2.4 争议解决条款（⚠ 仲裁管辖强制检查）

> **这是最高优先级检查项**，必须在起草任何内容之前完成。

- **仲裁条款识别**：检查合同是否约定"仲裁"或"提交仲裁委员会仲裁"
- **有效仲裁条款的认定要件**（仲裁法§16）：
  1. 约定仲裁的意思表示明确
  2. 约定了具体仲裁机构名称（如"中国国际经济贸易仲裁委员会""北京仲裁委员会"等）
  3. 约定了仲裁事项
- **无效仲裁条款情形**（此时法院有管辖权）：
  - 仅约定"可仲裁也可诉讼"（选择性条款，通常认定无效）
  - 约定的仲裁机构不存在或名称错误无法确定
  - 仅约定"友好协商解决"（不构成仲裁协议）
- **处理规则**：
  - 识别到**疑似有效仲裁条款** → **立即停止起草，执行§十一仲裁管辖提示流程**
  - 确认仲裁条款无效或不存在 → 继续正常起草流程

## 三、合同纠纷诉讼请求通用排列顺序

```
一、[合同主给付请求]（支付价款/返还款项/继续履行等）
二、[逾期利息/资金占用损失]（附属于主给付，四要素必备）
三、[违约金]（主位+备位双轨，防止法院调减后无据可依）
四、[损害赔偿]（逐项列明，含可预见性论证）
五、[合同解除确认]（如有，区分"确认解除"与"判令解除"）
六、[担保责任]（保证/抵押/质押，有则必加）
七、[律师费]（合同有明确约定时主张）
八、[诉讼费、保全费由被告承担]
```

## 四、利息/资金占用损失四要素规范（所有合同纠纷必须遵守）

**四要素缺一不可**：基数 + 起算日（具体日期）+ 利率标准 + 暂计截止日及暂计金额

### 4.1 利率基准统一规则
- **2019年8月20日起**：统一使用「全国银行间同业拆借中心公布的贷款市场报价利率（LPR）」，禁止使用「中国人民银行同期贷款基准利率」
- **跨越节点的合同**：分段计算
- **民间借贷上限**：LPR的四倍
- **金融借款**：不适用民间借贷利率上限

### 4.2 起算日规范（必须写明具体日期）

| 情形 | 起算日 | 如何确定 |
|------|--------|---------|
| 合同有约定付款期限 | 约定付款日次日 | 从合同条款中提取 |
| 无约定，已书面催告 | 催告之日次日 | 从催告函/律师函中提取 |
| 无约定，未催告 | 起诉状副本送达之日次日 | 如实表述 |
| 建设工程（竣工验收后） | 竣工验收合格之日次日 | 从竣工验收报告中提取 |
| 承揽合同（完工后） | 工作成果交付之日次日 | 从交付凭证中提取 |

### 4.3 暂计截止日及暂计金额（必填）

```
暂计至 [YYYY年MM月DD日（起诉日）] 止，共计人民币 [金额] 元。
```

### 4.4 标准表述模板
```
以人民币×元为基数，自×年×月×日起至实际清偿之日止，
按照全国银行间同业拆借中心公布的贷款市场报价利率（LPR）计算资金占用损失，
暂计至×年×月×日止为人民币×元。
```

## 五、合同解除的两种写法（必须区分）

### 5.1 确认解除（已发送解除通知且通知已到达对方）
```
一、请求确认原、被告于×年×月×日签订的《×××合同》（合同编号：×××）
    已于×年×月×日（解除通知到达被告之日）解除；
```
依据：民法典第565条

### 5.2 判令解除（尚未发出解除通知）
```
一、请求判令解除原、被告于×年×月×日签订的《×××合同》；
```
依据：民法典第563条

## 六、事实与理由标准六段式结构

```
[第1段] 合同签订情况
    ×年×月×日，原告与被告签订《×××合同》（合同编号：×××），
    约定：[核心合同条款摘要，引用条款编号]。

[第2段] 原告履约情况（守约方身份确立——必须先于被告违约陈述）
    合同签订后，原告严格按照合同约定履行了全部/主要义务：
    [具体履约行为 + 时间节点 + 金额/数量 + 证据编号]

[第3段] 被告违约行为
    然而，被告未按合同第×条约定于×年×月×日前[履行义务内容]，
    截至起诉之日，[违约事实描述，引用合同条款编号]（见证据×）。

[第4段] 催告与协商过程
    原告曾于×年×月×日以[书面/微信/电话]方式向被告催告，
    要求其于×日内履行，被告[未予回应/拒绝/推诿]（见证据×）。

[第5段] 损失量化与计算依据
    被告的违约行为给原告造成损失共计人民币×元，具体包括：
    ①[损失项目一]×元（计算依据：……）；
    ②[逾期利息损失]×元（以×元为基数，按LPR，自×至×，暂计）；
    ③[其他损失项目]×元。

[第6段] 法律依据与诉请收束
    综上，被告[违约行为概括]的行为已严重违反《×××合同》的约定
    及《中华人民共和国民法典》合同编的相关规定。
    为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 七、通用专业术语规范

| 规范术语 | 禁止使用 | 说明 |
|---------|---------|------|
| 贷款市场报价利率（LPR）全称 | 银行同期贷款利率、基准利率 | 2019年8月20日后必须用全称 |
| 资金占用损失 | 利息（合同欠款场景） | 借贷关系才用"利息" |
| 确认解除 | 撤销合同 | 解除≠撤销 |
| 判令解除 | 宣布解除 | 须经法院判决 |
| 连带清偿责任 | 连带赔偿责任 | 保证责任的规范表述 |
| 合同约定付款期限届满之次日 | 到期后 | 起算日须精确到日 |
| 人民币×元（大写×万×千×百×拾×元整） | 约×万元 | 金额须精确到分 |
| 民法典第×条第×款第×项 | 民法典相关规定 | 法条须引用至具体条款 |
| 承揽报酬 | 劳务费、工程费（承揽合同） | 民法典施行后统一用"承揽报酬" |

## 八、通用自检清单（生成起诉状前必须逐项确认）

- ☐ **合同条款已全面阅读**：权利义务、违约责任、合同解除、争议解决四类条款均已核查（见§二）
- ☐ **仲裁条款已检查**：确认无有效仲裁条款，或已执行仲裁提示流程（见§十一）
- ☐ 当事人信息完整：自然人（姓名、身份证号、住址）；法人（全称、USCC、法定代表人、住所含街道级）
- ☐ 企业主体已通过「企业主体定位 + 工商登记信息查询」两段能力补全信息（探测→匹配→定位→取字段，见 `parties-format.md` §9.2）；连接器不可用 / 调用失败 / 字段不全时，**已按 `parties-format.md` §9.4（唯一真源）的三个出口处理**，未编造任何企业登记信息
- ☐ 核验状态标注位置正确：「用户自报，待核验」「待补全街道」等标注**只写在交付说明/质量自检报告**，起诉状正文仅出现真实值或中性占位「（待补充）」
- ☐ 管辖依据明确：合同约定管辖 / 被告住所地 / 合同履行地
- ☐ 诉讼标的额已计算：本金 + 利息（含暂计截止日及暂计金额）+ 违约金（同左）+ 其他损失
- ☐ 利息/违约金**四要素**齐备：基数 + 起算日（具体日期）+ 利率标准（LPR全称）+ 暂计截止日及暂计金额
- ☐ 违约金与资金占用利息已按§九判断是否可并存
- ☐ 维权费用（律师费等）已按§十核查合同约定及实际支出
- ☐ 违约金双轨：主位（约定）+ 备位（防调减）
- ☐ 解除合同写法正确：确认解除（已通知）vs 判令解除（未通知）
- ☐ 担保责任已列入（如有）
- ☐ 事实与理由中原告履约先于被告违约陈述；无小标题、无"上述事实有…证据为证"结尾语
- ☐ 每项关键事实均有证据编号对应
- ☐ 法条引用至具体条款，无"相关规定"笼统引用

## 九、违约金与资金占用利息能否并存——逐案判断规则

### 9.1 基本框架

| 请求组合 | 能否并存 | 适用条件 |
|---------|---------|---------| 
| 约定**逾期付款违约金（日千分之N等）** + **资金占用利息（LPR）** | **通常不能并存**（实质重叠） | 两者均以迟延付款为对象，保护同一损失 |
| 约定**违约金** + **实际损失赔偿** | 可并存，但以实际损失为上限 | 违约金不足以覆盖实际损失时，差额另行主张 |
| 建设工程**欠付工程款利息** + **逾期竣工违约金** | **可以并存** | 两者指向不同违约行为 |
| 合同**无违约金条款**，仅有逾期利率约定 | 主张约定利率利息 | 可另行主张超出利息部分的其他损失 |

### 9.2 判断步骤（每案必须执行）

1. **检索合同违约金条款原文**，识别违约金"保护的法益"：
   - 「逾期付款的，每日按千分之X支付违约金」→ 与 LPR 资金占用损失高度重叠，**不宜并存**
   - 「违约方须支付合同总价X%作为违约金」→ 综合约定，可另行主张利息损失

2. **判断两项请求是否实质重叠**：同一损失不得双重计算

3. **确定起诉策略**（日常逾期付款纠纷推荐）：
   - **主位**：约定违约金（含暂计金额）
   - **备位**：若贵院认为约定违约金过高，请求以LPR×130%确定，不低于×元
   - **禁止**：将逾期违约金与LPR利息同时列为独立并列请求

### 9.3 标准表述

**场景A：合同约定日千分之五逾期违约金**
```
判令被告支付逾期付款违约金（以人民币[基数]元为基数，自[起算日]起按日千分之五
计算至实际清偿之日止，暂计至[暂计日]为人民币[暂计金额]元）；
若贵院认为约定违约金过高应予调减，请求按全国银行间同业拆借中心公布的贷款
市场报价利率（LPR）的一点三倍确定，不低于人民币[LPR×130%金额]元。
```

**场景B：合同无违约金条款，主张LPR资金占用损失**
```
判令被告支付逾期付款的资金占用损失（以人民币[基数]元为基数，自[起算日]起按
全国银行间同业拆借中心公布的贷款市场报价利率（LPR）计算至实际清偿之日止，
暂计至[暂计日]为人民币[暂计金额]元）；
```

## 十、维权费用（律师费等）主张规则

### 10.1 律师费可主张的情形

| 情形 | 依据 | 审查重点 |
|------|------|---------|
| **合同明确约定**违约方承担律师费 | 民法典§577 | 条款须明确写明"律师费"；"维权费用"较模糊 |
| **司法解释直接规定**（知识产权等） | 相关特别法及司法解释 | 按具体规定执行 |
| 无约定，违约行为存在**故意或重大过失** | 民法典§584 | 支持概率较低，须充分论证 |

### 10.2 操作规则

1. **检索合同"违约责任"章节**，找到含"律师费"的条款
2. **确认原告是否已实际签订并支付律师费**（立案前须备齐律师费发票）
3. **诉讼请求标准表述**：
```
判令被告承担原告为本案支出的律师费人民币[金额]元
（依据：合同第X条约定，有律师委托合同及发票为证）；
```

### 10.3 自检提示
- ☐ 原告是否持有已签订的律师委托合同 + 律师费发票（缺一不可）
- ☐ 合同中是否有律师费条款（有则主张，无则评估风险后决策）
- ☐ 律师费金额是否在当地律师收费标准合理范围内

## 十一、仲裁管辖提示流程（⚠ 识别到有效仲裁条款时强制执行）

> **触发条件**：执行§二第2.4节检查时，发现合同争议解决条款约定了仲裁且疑似构成有效仲裁协议。

### 11.1 提示话术（标准格式）

向用户输出以下提示，**不得省略任何要点**：

```
⚠️ 【管辖权重要提示】

经审查，您提供的《[合同名称]》第[条款编号]条约定：
"[争议解决条款原文]"

该条款疑似构成有效仲裁约定（具体仲裁机构：[×××仲裁委员会]），
符合《中华人民共和国仲裁法》第十六条关于仲裁协议有效要件的规定。

如该仲裁约定有效，本案争议应通过仲裁解决，而非向人民法院起诉。
向法院起诉后，被告可依据《民事诉讼法》第一百二十七条申请驳回起诉，
导致诉讼费损失及时间延误。

建议您考虑：
① 向约定的仲裁机构申请仲裁（可协助起草仲裁申请书）；
② 如您认为仲裁条款无效，可在起诉状中专门论证并申请法院确认仲裁协议无效；
③ 如双方能就管辖达成新的书面协议，可约定由法院管辖。

请问您希望如何处理？
A. 继续起草民事起诉状（将在起诉状中增加仲裁条款无效论证段落）
B. 改为起草仲裁申请书
C. 等待您进一步确认
```

**用户选 B 时**：直接调用生成脚本的仲裁模式，无需手工改 XML——`python3 scripts/generate_complaint.py --mode arbitration`。JSON 键不变（仍用 `plaintiffs` / `defendants`），脚本自动渲染为仲裁文书：标题"仲裁申请书"、当事人称谓"申请人/被申请人"、请求标题"仲裁请求"、落款"申请人（签字/盖章）"；`court` 字段填仲裁委员会名称（如"杭州仲裁委员会"）。文书措辞按仲裁口径调整（"请求裁决"替代"请求判令"等）。

### 11.2 用户坚持起诉时的处理

在起诉状"事实与理由"正文最后（收尾语之前）增加：

```
关于管辖，原、被告于《×××合同》第×条约定了争议解决方式。
原告认为，该约定[理由一：仲裁机构名称不明确，无法确定具体仲裁机构；
理由二：属于选择性条款，依法无效；理由三：……]，
依据《中华人民共和国仲裁法》第十七条第[X]项之规定，
该仲裁协议无效，本案争议依法应由人民法院管辖。
```

### 11.3 仲裁条款无效常见情形

| 情形 | 依据 | 说明 |
|------|------|------|
| 约定的仲裁机构不存在 | 仲裁法§17(3) | 如"提交中国仲裁委员会仲裁"（该机构不存在） |
| 仲裁机构名称有歧义 | 仲裁法§17(3) | 如"提交北京仲裁"（可能指多个机构） |
| 选择性条款（仲裁或诉讼二选一） | 仲裁法§4 | 如"可仲裁，也可向法院起诉" |
| 仅约定协商解决 | 仲裁法§16 | 不构成仲裁协议 |
| 约定仲裁但未约定机构且未约定仲裁地 | 仲裁法§16 | 缺乏有效要件 |

## 十三、合同纠纷常见抗辩与预先消解

> 起草时须在事实与理由中**自然融入**化解，不要写"针对被告可能的抗辩"字样，避免提示对手。

| 被告可能的抗辩 | 预先化解写法 |
|-------------|------------|
| 合同未成立 / 未生效 | 陈述合同签订经过、双方盖章/签字、已开始履行的事实 |
| 标的物质量不符 | 强调被告已签收验收合格、未在合理期间提出异议（民法典§621） |
| 诉讼时效已过 | 列出最近一次催告/还款承诺时间证明时效中断 |
| 主体资格异议 | 强调原告是适格的合同当事人 / 受让债权人 |
| 管辖异议 | 引用合同中的管辖条款或合同履行地认定规则 |
| 不可抗力免责 | 区分不可抗力与商业风险，强调被告未及时通知（民法典§590） |
| 情势变更 | 强调被告未在合理期间内请求变更合同，不能事后援引 |
| 对方违约在先 | 陈述原告已完整履行义务的事实，或原告违约系被告拒绝受领所致 |

## 十四、买卖合同纠纷专项实务规则（100案例总结）

> 原 contract.md §六内容，合并至此。

### 14.1 高频诉讼请求类型（按出现频次）

1. **货款追索**（最高频）：本金 + 逾期违约金/利息 + 律师费（合同约定时）
2. **解除合同 + 返还货款**：需证明法定/约定解除事由成就
3. **继续履行 + 交付货物**：卖方违约时，买方可主张继续履行
4. **质量瑕疵赔偿**：须有检验报告或鉴定报告支撑
5. **定金双倍返还**：须证明对方违约且定金条款有效成立

### 14.2 诉讼请求互斥规则（买卖合同）

| 互斥组合 | 原因 | 处理方式 |
|---------|------|---------|
| 继续履行 + 解除合同 | 两者目的相反，不可并存 | 择一主张，或设主位/备位 |
| 定金双倍返还 + 违约金 | 民法典§588：定金与违约金不可并用，择高适用 | 选择较高者主张，备位保留另一种 |
| 违约损害赔偿 + 违约金（超出损失部分） | 民法典§585：违约金不超过实际损失的130% | 主张违约金，备位主张实际损失 |

### 14.3 五段式事实结构

```
[第1段] 合同建立（时间/双方/标的/总金额/付款方式/违约条款编号）
[第2段] 原告履约（发货时间/数量/被告签收/开具发票）
[第3段] 被告违约（对账确认金额/已付金额/欠付金额/违约起始时间）
[第4段] 催收过程（催款函/微信记录/律师函+时间节点）
[第5段] 法律依据（民法典§577+§626+司法解释§18→诉请收束）
```

### 14.4 五大陈述规律

1. **时间轴清晰**：发货时间 → 签收时间 → 付款期限 → 违约时间 → 催告时间 → 起诉时间
2. **金额三明治**：总合同金额 → 已付金额 → 欠付金额（计算公式明确）
3. **证据编号对应**：每一关键事实括注"见证据×"
4. **违约金双轨**：主位（约定）+ 备位（防调减）
5. **主体一致性**：合同相对方与被告主体必须一致（含公章核查）

## 十五、委托合同纠纷专项实务规则（271条诉请总结）

> 原 contract.md §七内容，合并至此。

### 15.1 高频诉讼请求类型

1. **追索委托报酬**（最高频）：已完成委托事项，委托人拒付报酬
2. **损害赔偿**：受托人擅自处分委托财产、越权转委托、怠于履行
3. **任意解除权行使后的损失赔偿**（民法典§933）：委托人任意解除，须赔偿受托人损失
4. **不当得利返还**：受托人以委托人名义取得的财产拒不转交
5. **确认委托合同无效**：代理权限争议

### 15.2 诉讼请求互斥规则（委托合同）

| 互斥组合 | 原因 | 处理方式 |
|---------|------|---------|
| 继续履行委托 + 解除委托合同 | 两者目的相反 | 择一主张 |
| 委托报酬 + 解除合同后损失赔偿 | 解除后报酬请求基础消灭 | 若已完成部分工作，主张比例报酬 |
| 任意解除权损失赔偿 + 违约金 | 任意解除不构成违约，不适用违约金条款 | 主张损失赔偿，不主张违约金 |

### 15.3 六段式事实结构

```
[第1段] 合同建立（时间/双方/委托事项/委托期限/报酬约定）
[第2段] 委托权限与约定（权限边界/转委托权限/引用合同条款编号）
[第3段] 原告履约（已支付费用/已配合提供材料/已交付委托标的）
[第4段] 被告违约行为（援引合同第×条+具体违约事实）
[第5段] 损失与因果关系（致使/造成/导致原告损失×元+计算依据+催告记录）
[第6段] 法律依据与诉请收束（民法典§922/§929/§933→收尾固定语）
```

### 15.4 专项自检要点

- ☐ 合同性质是否明确点明为"委托合同"（避免与居间、行纪、代理混淆）
- ☐ 委托事项范围是否具体（附件编号、工作量、地域、再委托权限）
- ☐ 被告违约行为是否引用合同条款编号
- ☐ 损失金额是否有计算依据（合同约定 / 发票 / 评估）
- ☐ 催告/协商过程是否在事实中陈述（主张违约金时必备）
- ☐ 任意解除权（§933）情形下损失赔偿范围是否合理（一般限于直接损失）
