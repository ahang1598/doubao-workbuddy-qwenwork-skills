# 民间借贷纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「民间借贷纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年（2021—2025）266件案例，132件胜诉，系统提炼裁判规律。

---

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 返还借款本金 | 民法典 §667（借款合同定义）、§679（自然人借款成立时间）、§675（按期返还义务） |
| 支付利息 | 民法典 §676（逾期利息）、§680（禁止高利贷，LPR四倍上限）；民间借贷规定 §25、§26 |
| 担保责任 | 民法典 §688（连带保证）、§394（抵押权）、§425（质押权） |
| 优先受偿权 | 民法典 §394（抵押权定义及效力） |

## 二、诉讼请求标准表述（按胜诉频率排序）

### 第一项：返还借款本金（100%必备）

```
判令被告[姓名/公司全称]向原告偿还借款本金人民币×元（大写：×万×千×百×拾×元整）；
```

**专业术语规则**：
- 动词用「偿还」或「返还」，**禁止**用「赔偿」（赔偿是侵权用语）
- 多笔借款可合并一项，在事实与理由中分列明细（借款日期、金额、凭证编号）
- 金额精确到「分」，不写「约」字

### 第二项：支付利息（100%必备）

**2020年8月20日后签订的合同**：
```
判令被告向原告支付以借款本金×元为基数，自×年×月×日起至实际清偿之日止，
按照全国银行间同业拆借中心公布的一年期贷款市场报价利率（LPR）的四倍
计算的利息；
```

**跨越2020年8月20日节点的合同**：
```
判令被告向原告支付利息：以本金×元为基数，
自×年×月×日至2020年8月19日止，按年利率24%计算；
自2020年8月20日起至实际清偿之日止，
按照一年期贷款市场报价利率（LPR）的四倍计算；
```

**辅助表述**（方便法院计算，可附加）：
```
暂计至起诉日（×年×月×日）为人民币×元，之后按前述标准计至还清之日止。
```

**专业术语规则**：
- 利率上限：LPR的**四倍**（民间借贷，不适用金融机构利率规则）
- 起算日：约定还款日次日；无约定则为出借之日次日（如合同明确约定）或催告之日次日
- 截止日：一律「至实际清偿之日止」，不写具体日期

### 第三项：连带/担保责任（有担保时必加，43.9%案件涉及）

**连带保证**：
```
判令被告[保证人姓名/公司全称]对上述第一、二项债务承担连带清偿责任；
```

**一般保证**：
```
判令被告[保证人]在原告不能从主债务人处获得清偿的范围内承担保证责任；
```

**抵押担保**：
```
判令原告对被告[抵押人]名下位于[地址]的[不动产/动产]（抵押权登记编号：×××）
在人民币×元及利息范围内享有优先受偿权；
```

### 第四项：律师费（36.4%案件涉及，合同有约定时主张）

```
判令被告承担原告为本案支出的律师代理费人民币×元；
```

### 第五项：财产保全费（31.1%案件涉及）

```
判令被告承担本案财产保全申请费人民币×元；
```

## 三、事实与理由六段式结构（民间借贷专版）

```
[第1段] 借贷关系成立
    ×年×月×日，被告因[用途，如：资金周转/购房/经营]向原告借款，
    原告与被告签订《借款合同》（合同编号：×××），约定：
    借款金额×元，借款期限自×年×月×日至×年×月×日，
    借款利率为[年利率×%/月利率×%/不超过LPR四倍]，
    还款方式为[一次性还本付息/分期还款]（见证据1：借款合同）。
    [如有担保：×年×月×日，被告[担保人]与原告签订《保证合同》，
    约定对上述借款承担[连带/一般]保证责任（见证据×）。]

[第2段] 出借行为（原告履约）
    合同签订后，原告于×年×月×日通过[银行转账/支付宝/微信]
    向被告[账户/账号]转款人民币×元，被告已实际收到上述款项
    （见证据×：银行转账凭证/收款确认）。
    [多笔借款分列：
    第一笔：×年×月×日转款×元（见证据×）；
    第二笔：×年×月×日转款×元（见证据×）；
    合计：×元。]

[第3段] 被告违约
    借款期限届满后，被告未按合同约定偿还借款本金及利息。
    截至×年×月×日，被告尚欠原告借款本金人民币×元，
    逾期利息人民币×元（以×元为基数，按LPR×倍，自×至×计算），
    合计人民币×元（见证据×：还款记录/流水）。

[第4段] 催告过程
    原告曾于×年×月×日以[书面函件/微信/电话]方式多次催告被告还款，
    被告[未予回应/承诺还款但未履行/明确拒绝]（见证据×：催告记录）。

[第5段] 损失量化
    被告的违约行为给原告造成以下损失：
    ①借款本金人民币×元；
    ②逾期利息损失人民币×元（以×元为基数，按LPR×倍，
      自×年×月×日起暂计至×年×月×日止）；
    ③律师代理费人民币×元（见证据×：委托代理合同及付款凭证）；
    合计人民币×元。

[第6段] 法律依据
    综上，被告拒不偿还借款的行为已严重违反双方借款合同的约定
    及《中华人民共和国民法典》关于借款合同的相关规定。
    为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 四、民间借贷纠纷特殊注意事项

### 4.1 借贷关系真实性举证规则
- **最强证明链**：书面借款合同 + 银行转账凭证 + 被告确认回执
- **仅有转账凭证**：须在事实中说明转账原因，排除其他法律关系（如劳务报酬、货款等）；被告须就借贷关系不存在承担举证责任（民间借贷规定 §16）
- **现金交付**：须有收条或其他辅助证据（微信聊天记录、证人证言），单纯主张现金交付胜诉率极低

### 4.2 职业放贷人风险
若被告可能以原告系「职业放贷人」为由抗辩，须在事实与理由中说明：
- 出借资金来源合法（非银行贷款转贷）
- 非以营利为目的向不特定多数人出借

### 4.3 利率节点处理规则
| 借款时间 | 适用利率上限 | 表述规范 |
|---------|------------|---------|
| 2020年8月20日后 | LPR四倍 | 「按一年期LPR的四倍」 |
| 2020年8月20日前 | 年利率24%（保护线）/ 36%（无效线） | 分段计算，节点前按24%，节点后按LPR四倍 |
| 跨越节点的合同 | 分段适用 | 必须在诉请中明确分段，防止全部按旧标准被驳回 |

### 4.4 保证期间严格审查
- 连带保证：债务履行期届满之日起**6个月**内须向保证人主张（合同有约定则从约定）
- 一般保证：债务履行期届满之日起**6个月**内须提起诉讼或申请仲裁
- **风险提示**：起诉状中须明确主张保证人责任，并在事实中说明保证期间未届满

## 五、民间借贷纠纷自检清单

- ☐ 借款合同/借条/欠条原件已列入证据清单
- ☐ 转账凭证（银行流水/支付宝/微信）已列入证据清单
- ☐ 利率不超过LPR四倍（超出部分须在诉请中主动降至上限）
- ☐ 利息起算日明确（约定还款日次日 / 催告之日次日）
- ☐ 有担保的：保证合同/抵押登记证明已列入证据清单，且保证期间未届满
- ☐ 多笔借款已分列明细，合计金额与诉请一致
- ☐ 辅助表述「暂计至起诉日为×元」已填写
- ☐ 职业放贷人风险已评估
