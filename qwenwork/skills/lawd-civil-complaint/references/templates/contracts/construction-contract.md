# 建设工程施工合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「建设工程施工合同纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年（2021—2025）200件案例，62%部分支持，系统提炼裁判规律。

---

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 支付工程款 | 民法典 §793（无效合同工程款处理）、§807（工程款优先受偿权） |
| 逾期付款利息 | 民法典 §577、§579；《建工司法解释（一）》§27 |
| 建设工程价款优先受偿权 | 民法典 §807；《建工司法解释（一）》§38-§41 |
| 违约金 | 民法典 §585；合同约定 |
| 解除合同 | 民法典 §563（法定解除）、§565（解除通知） |
| 赔偿损失（停工损失/窝工费） | 民法典 §577、§584 |
| 增减工程款 | 《建工司法解释（一）》§19、§20 |

## 二、诉讼请求标准表述（按胜诉频率排序）

### 第一项：支付工程款（63%案件，最核心请求）

```
判令被告向原告支付欠付工程合同价款人民币×元
（含：竣工结算工程款×元；增项工程款×元；扣除已付款×元）；
```

**专业术语规则**：
- 使用「工程合同价款」或「欠付工程款」，**禁止**使用「拖欠款项」「未付费用」等非规范表述
- 金额须精确到分，须同时列明大写
- 须注明金额构成：竣工结算金额 - 已付款 = 欠付金额
- 付款条件已成就时，使用「应付未付工程款」；付款条件争议时，使用「到期应付工程款」

### 第二项：支付逾期付款利息/资金占用费（71%案件，最高频附属请求）

**情形一：合同约定利率**：
```
判令被告支付原告逾期付款利息，以欠付工程款×元为基数，
按合同约定的日/月×%（年化×%）计算，
自×年×月×日起至实际清偿之日止；
```

**情形二：按LPR计算（无约定或约定不明）**：
```
判令被告支付原告逾期付款资金占用损失，以欠付工程款×元为基数，
自×年×月×日起至实际清偿之日止，
按照全国银行间同业拆借中心公布的贷款市场报价利率（LPR）计算；
```

**利率标准统一规范**：使用「LPR」，**禁止**使用「同期贷款基准利率」（2020年后已废止）

**起算日规则**（重要）：
| 情形 | 起算日 |
|------|--------|
| 合同约定付款期限 | 约定付款日次日 |
| 竣工验收后付款（无具体约定） | 竣工验收合格之日次日 |
| 工程已交付使用但未办竣工验收 | 法院通常认定「以竣工验收合格日」起算，须在事实中明确该日期 |
| 结算文件确认后 | 结算文件确认之日次日 |

### 第三项：建设工程价款优先受偿权（13%案件，有必要时主张）

```
请求确认原告对被告位于×市×区×路×号、建筑面积约×平方米的
×工程（以下简称「案涉工程」）折价或拍卖所得价款
在欠付工程款人民币×元及利息范围内享有建设工程价款优先受偿权；
```

**专业术语规则**：
- 须明确指向「折价或拍卖、变卖所得价款」，不得笼统表述为「工程」
- 须明确优先受偿的具体金额范围（「在×元及利息范围内」）
- **行使期限**：自发包方应当给付建设工程价款之日起**18个月**内（《建工司法解释（一）》§41，2021年修订后由6个月延长为18个月）
- 须在事实与理由中明确起算时间，证明18个月期限未届满

### 第四项：支付违约金（11%案件）

```
判令被告支付违约金人民币×元（按合同第×条约定，
以欠付工程款×元为基数，按日/月×%计算，
自×年×月×日起暂计至×年×月×日止）；
```

### 第五项：赔偿停工/窝工损失（发包方原因停工时）

```
判令被告赔偿原告因[发包方原因]停工/窝工损失人民币×元，
具体包括：①人工窝工费×元；②机械停滞费×元；③材料损失×元；
合计×元（见证据×：停工记录/监理确认/明细清单）；
```

## 三、事实与理由结构（建设工程专版）

```
[第1段] 合同签订
    ×年×月×日，原告（承包人）与被告（发包人）签订
    《建设工程施工合同》（合同编号：×××），约定：
    工程名称：×××；工程地点：×市×区×路×号；
    承包范围：[土建/装饰/安装/总承包]；
    合同价款：人民币×元（[固定总价/固定单价/可调价]）；
    工期：×年×月×日至×年×月×日；
    付款方式：[按进度节点付款/竣工验收后付款]；
    质保金：合同价款的×%，缺陷责任期届满后退还（见证据1）。

[第2段] 原告施工履约情况
    合同签订后，原告按约组织施工，于×年×月×日完成全部施工工程。
    ×年×月×日，发包人[组织/委托]竣工验收，验收合格
    （见证据×：竣工验收报告/竣工验收备案证明）。
    [或：工程已于×年×月×日交付发包人实际使用（见证据×：交付记录）。]

[第3段] 结算情况
    竣工验收后，原告于×年×月×日向被告提交结算报告，
    审定工程总价为人民币×元（见证据×：结算书/审定报告）。
    [或：因被告拒绝结算，原告申请司法鉴定，鉴定结论为×元（见证据×：鉴定报告）。]
    被告已累计支付工程款×元，尚欠工程款×元。

[第4段] 催告违约
    原告曾于×年×月×日向被告发出《催款函》，
    要求被告于×日内支付欠付工程款，被告至今未予支付
    （见证据×：催款函及送达凭证）。

[第5段] 优先受偿权（如主张）
    依据《中华人民共和国民法典》第八百零七条及
    《最高人民法院关于审理建设工程施工合同纠纷案件适用法律问题的解释（一）》
    第三十八条至第四十一条之规定，原告对案涉工程折价或拍卖所得价款
    享有建设工程价款优先受偿权。
    自被告应当给付工程价款之日（×年×月×日）起，至今未超过18个月，
    原告依法在本案中一并主张优先受偿权。

[第6段] 法律依据
    综上，被告拒不支付工程款的行为已严重违反双方建设工程施工合同的约定
    及《中华人民共和国民法典》合同编的相关规定。
    为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 四、建设工程施工合同纠纷特殊注意事项

### 4.1 结算依据优先级
1. **竣工结算文件**（双方签字确认）：最强，法院直接采用
2. **审计报告/造价鉴定**：有争议时委托司法鉴定
3. **合同约定单价×实际工程量**：须有监理确认的工程量清单

### 4.2 工程款金额表述规范
- 须同时列明：合同总价 + 增项工程款 + 扣减项 - 已付款 = 欠付金额
- 金额须精确到分，须同时列明大写
- 使用「欠付工程款」而非「拖欠款项」或「工程费」

### 4.3 优先受偿权的18个月期限
- 起算点：发包方「应当给付」工程款之日（即付款条件成就之日）
- **2021年修订后**：由6个月延长为18个月（《建工司法解释（一）》§41）
- 若案涉合同签订于2021年1月1日前，需注意时效节点适用新旧解释的衔接
- 须在事实中明确起算日期，并说明18个月期限未届满

### 4.4 实际施工人资格认定（高频争议）
若存在多层分包，须明确原告身份：
- **总承包人**：直接向发包人主张
- **分包人**：向总承包人主张；特殊情形下可突破合同相对性向发包人主张（《建工司法解释（一）》§43）
- **实际施工人**（挂靠/借用资质）：须在事实中说明挂靠关系及实际施工事实

### 4.5 工程质量与价款关联
被告可能以工程质量问题作为抗辩，须预先准备：
- 竣工验收报告（证明验收合格）
- 或：工程已交付使用（法院通常认定为默认验收合格）
- 对于质量争议，建议在诉请中预留：「若法院认定存在质量问题，请求在鉴定确认的修复费用范围内相应扣减」

## 五、建设工程施工合同纠纷自检清单

- ☐ 建设工程施工合同（含补充协议）已列入证据清单
- ☐ 竣工验收报告或交付使用证明已列入证据清单
- ☐ 竣工结算书（双方确认版）或司法鉴定报告已列入证据清单
- ☐ 已付款凭证（银行流水）已列入证据清单
- ☐ 催款函及送达凭证已列入证据清单
- ☐ 工程款金额计算：合同总价 + 增项 - 扣减 - 已付 = 欠付
- ☐ 逾期利息起算日已确认（竣工验收合格日次日 / 合同约定付款日次日）
- ☐ 优先受偿权（如主张）：18个月期限未届满，已明确起算日
- ☐ 实际施工人身份（如涉及多层分包）：已明确原告与发包人/总包人的法律关系
- ☐ 质量争议风险已评估，必要时预留扣减口径
