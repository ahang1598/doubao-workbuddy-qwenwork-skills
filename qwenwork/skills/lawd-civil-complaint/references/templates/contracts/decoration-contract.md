# 装饰装修合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「装饰装修合同纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年296件案例，原告整体胜诉率约63%（含部分胜诉）。
> **法律定性**：装饰装修合同属于**承揽合同**（民法典§770），同时可参照适用建设工程相关规定。

---

## 一、原告身份二分（决定诉请结构）

| 原告身份 | 典型场景 | 核心诉请 | 胜诉关键 |
|---------|---------|---------|---------|
| 施工方（装修公司/工人） | 追索装修款/工程款 | 支付装修款+逾期利息 | 证明工程已完工或已完成阶段性工作 |
| 业主/发包方 | 要求返款/修复/赔偿 | 解除合同+返还已付款+赔偿损失 | 鉴定报告（质量问题）或书面催告记录（工期违约） |

---

## 二、诉讼请求标准表述

### 施工方作为原告（追索装修款）

**第一项：支付装修工程款**
```
判令被告向原告支付装修工程款人民币×元
（合同总价×元，已付×元，欠付×元）；
```

**第二项：支付逾期付款利息/资金占用损失**
```
以欠付装修款×元为基数，自×年×月×日
（竣工验收合格之日次日/合同约定付款日次日）起至实际清偿之日止，
按照全国银行间同业拆借中心公布的贷款市场报价利率（LPR）
计算资金占用损失；
```

**第三项：支付质保金（质保期届满后）**
```
判令被告于本判决生效后×日内向原告返还质保金人民币×元；
```

### 业主/发包方作为原告（要求返款/赔偿）

**第一项：解除合同**
```
判令解除原、被告于×年×月×日签订的《×××装饰装修合同》；
```
（或：确认合同已于×年×月×日解除）

**第二项：返还已付款**
```
判令被告向原告返还已收取的装修款人民币×元
（扣除已完工部分合理费用×元后，应返还×元）；
```

**第三项：赔偿质量瑕疵修复费用**
```
判令被告赔偿原告因工程质量不合格造成的修复费用
人民币×元（见证据×：司法鉴定报告/维修报价单）；
```

**第四项：支付工期违约金**
```
判令被告支付工期违约金人民币×元
（按合同第×条约定，逾期×天，每天×元，合计×元）；
```

**第五项：赔偿其他损失**
```
判令被告赔偿原告因装修延误造成的租房损失/搬迁费损失
人民币×元；
```

## 三、事实与理由结构

### 施工方追索装修款版本：

```
[第1段] 合同签订
    ×年×月×日，原告（施工方）与被告（业主）签订
    《×××装饰装修合同》（合同编号：×××），约定：
    装修地址：×市×区×路×号×室；
    合同总价：人民币×元（[固定总价/按实结算]）；
    工期：×年×月×日至×年×月×日；
    付款方式：[首付×元，完工验收后付清余款]；
    质保金：合同总价的×%，质保期×年（见证据1）。

[第2段] 施工履约情况
    合同签订后，原告按约组织施工，于×年×月×日完成全部
    装修工程，并通知被告验收（见证据×：完工通知）。
    被告于×年×月×日[验收合格/实际入住使用]
    （见证据×：验收单/入住记录）。

[第3段] 被告违约
    工程完工验收后，被告仅支付装修款×元，
    尚欠装修款×元（含质保金×元）至今未付
    （见证据×：付款记录）。

[第4段] 催告过程
    原告曾于×年×月×日向被告发出《催款函》，
    被告至今未予支付（见证据×：催告函及送达凭证）。

[第5段] 法律依据
    综上，依照《中华人民共和国民法典》第七百七十条、
    第七百八十三条及《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 四、装饰装修合同纠纷特殊注意事项

### 4.1 验收规则（最高频争议）
- **有书面验收单**：最强证明，法院直接采用
- **被告已入住使用**：法院通常认定为默认验收合格（民法典§782）
- **被告拒绝验收**：须证明工程已完工并通知验收；被告无正当理由拒绝验收的，视为验收合格

### 4.2 质量瑕疵赔偿（业主胜诉关键）
- **无鉴定报告**：仅凭照片或证人证言难以支持修复费用（法院普遍要求鉴定）
- **有鉴定报告**：胜诉率大幅提升，建议在起诉前申请司法鉴定或委托专业机构出具评估报告
- **鉴定报告须写明**：鉴定机构名称、鉴定日期、鉴定结论摘要

### 4.3 违约金调减规律
约定违约金超出实际损失30%以上时，法院几乎必然酌减。
调减后通常以「实际损失的1.1—1.3倍」或「LPR的1.5—2倍」为基准。
**必须准备违约金双轨（主位+备位）请求**。

### 4.4 合同解除时间节点
- 129件涉及解除，核心争议是解除时间节点
- **催告通知送达之日**或**起诉状副本送达之日**为法院常认定的解除时间节点
- 须在事实中明确催告时间、方式和送达情况

### 4.5 已付款返还范围
合同解除后，返还范围 = 已付款 - 已完工部分合理费用。
须在事实中说明已完工比例及对应金额，防止被告抗辩已完工部分的费用。

## 五、装饰装修合同纠纷自检清单

- ☐ 装饰装修合同（含预算书/变更单）已列入证据清单
- ☐ 验收单/入住记录已列入证据清单（无书面验收时，需入住使用证明）
- ☐ 已付款凭证已列入证据清单
- ☐ 质量问题：司法鉴定报告或专业评估报告已准备（无此证据时赔偿请求风险极高）
- ☐ 工期违约：书面催告记录已列入证据清单
- ☐ 违约金双轨：主位（约定）+ 备位（防调减）
- ☐ 合同解除写法正确：确认解除（已通知）vs 判令解除（未通知）
- ☐ 返还款项计算：已付款 - 已完工部分合理费用
