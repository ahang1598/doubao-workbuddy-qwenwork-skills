# 买卖合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「买卖合同纠纷」（含普通货物买卖、商品房买卖、网络购物、分期付款买卖等）时读取。须先读取 `contract-general.md`，再读取本文件。

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 支付货款/价款 | 民法典 §595（买卖合同定义）、§626（买受人支付价款义务） |
| 交付货物/标的物 | 民法典 §598（出卖人交付义务）、§603（交付方式） |
| 逾期付款利息 | 民法典 §577、§579 |
| 违约金 | 民法典 §585；合同约定 |
| 损害赔偿 | 民法典 §577、§584 |
| 解除合同 | 民法典 §563（法定解除）、§565 |
| 商品房买卖特殊请求 | 商品房买卖司法解释 §7（双倍返还定金）、§11（赔偿损失） |

## 二、诉讼请求标准表述

### 出卖人作为原告（追讨货款）

**第一项：支付货款**
```
判令被告向原告支付货款人民币×元；
```

**第二项：支付逾期付款利息**
```
以货款×元为基数，自×年×月×日（约定付款日次日）起
至实际清偿之日止，按照全国银行间同业拆借中心公布的
贷款市场报价利率（LPR）计算资金占用损失；
```

**第三项：支付违约金（双轨）**
```
主位：判令被告支付违约金×元（按合同第×条约定，
以货款×元为基数，按×%计算，自×至×暂计）；
备位：若贵院认为过高，请求依据实际损失×元的130%确定，不低于×元；
```

### 买受人作为原告（要求交货/退款）

**第一项：交付货物（继续履行）**
```
判令被告于本判决生效后×日内向原告交付[货物名称/规格/数量]；
```

**第二项：解除合同+返还货款**
```
一、判令解除原、被告于×年×月×日签订的《买卖合同》；
二、判令被告向原告返还货款人民币×元；
```

**第三项：赔偿损失**
```
判令被告赔偿原告因[迟延交货/货物质量不合格]造成的损失
人民币×元（包括：差价损失×元；仓储费×元；其他损失×元）；
```

## 三、买卖合同纠纷事实与理由结构

```
[第1段] 合同签订
    ×年×月×日，原告（出卖人/买受人）与被告签订
    《×××买卖合同》（合同编号：×××），约定：
    货物名称/规格/数量：×；
    合同总价：人民币×元；
    交货时间：×年×月×日前；
    付款方式：[预付×元，验货后付清余款]；
    违约责任：[约定条款]（见证据1）。

[第2段] 原告履约情况
    合同签订后，原告[按约交付货物×（见证据×：发货记录/签收单）/
    按约支付货款×元（见证据×：付款凭证）]。

[第3段] 被告违约
    然而，被告[未按约定于×年×月×日前支付货款/
    未按约定交付货物]，截至起诉日，被告尚欠货款×元
    （见证据×：对账记录/欠款确认）。

[第4段] 催告过程
    原告曾于×年×月×日催告被告履行，被告至今未履行
    （见证据×：催告记录）。

[第5段] 法律依据
    综上，依照《中华人民共和国民法典》第五百九十五条、
    第六百二十六条及《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 四、买卖合同纠纷特殊注意事项

### 4.1 商品房买卖特殊规则
- **双倍返还定金**（商品房买卖司法解释§7）：出卖人违约不交房，买受人可主张双倍返还定金（须有定金合同）
- **赔偿损失**（商品房买卖司法解释§11）：开发商迟延交房，赔偿范围包括差价损失、租金损失等
- **逾期办证**：开发商逾期办理产权登记，赔偿按日计算损失（须合同有约定）

### 4.2 货物质量争议
- 买受人以质量不合格为由拒付货款时，须在事实中明确：
  - 质量标准（合同约定/国家标准/行业标准）
  - 质量瑕疵的具体表现（有鉴定报告最佳）
  - 已通知出卖人的时间（超过合理异议期则视为接受）

### 4.3 货款金额计算
- 须列明：合同总价 + 增量货款 - 已付款 - 合理扣减 = 欠付货款
- 有对账单/欠款确认书的，直接采用；无书面确认的，须提供送货记录+签收单

## 五、买卖合同纠纷自检清单

- ☐ 买卖合同（含订单/补充协议）已列入证据清单
- ☐ 交货记录/签收单（出卖人追货款时）已列入证据清单
- ☐ 付款凭证（买受人追货物时）已列入证据清单
- ☐ 对账单/欠款确认书（如有）已列入证据清单
- ☐ 货款金额计算：合同总价 - 已付款 = 欠付
- ☐ 逾期利息起算日：约定付款日次日
- ☐ 违约金双轨：主位（约定）+ 备位（防调减）
- ☐ 商品房买卖：定金合同+付款凭证已列入证据清单
