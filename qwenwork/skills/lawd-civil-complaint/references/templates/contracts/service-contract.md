# 服务合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「服务合同纠纷」（含咨询服务、技术服务、物业服务、广告服务、中介服务、出国中介、教育培训等）时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年311件案例，系统提炼裁判规律。

---

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 支付服务报酬 | 民法典 §577、§579；服务合同专章 |
| 资金占用损失 | 民法典 §577、§584 |
| 违约金 | 民法典 §585；合同约定 |
| 返还预付款/服务费 | 民法典 §566（合同解除后恢复原状）、§985（不当得利） |
| 赔偿损失 | 民法典 §577、§584（可预见性规则） |
| 确认/判令解除合同 | 民法典 §563、§565 |

## 二、诉讼请求标准表述（按胜诉频率排序）

### 第一项：支付服务报酬（231案，最高频核心请求）

```
判令被告向原告支付《×××服务合同》项下服务报酬
人民币×元，并自×年×月×日（付款期限届满之次日）起
至实际清偿之日止，按照全国银行间同业拆借中心公布的
贷款市场报价利率（LPR）计算资金占用损失；
```

**专业术语规则**：
- 民法典施行后（2021年1月1日起）统一使用「服务报酬」或依合同名称使用「咨询费」「技术服务费」「物业费」「劳务费」等
- **禁止**使用「劳动报酬」（劳动法范畴，与本案由混淆）
- 使用「资金占用损失」而非「利息」（后者为借贷关系用语）

### 第二项：支付资金占用损失（282案，最高频附属请求）

**LPR基准（无约定）**：
```
以×元为基数，按照全国银行间同业拆借中心公布的
贷款市场报价利率（LPR），
自×年×月×日起至实际清偿之日止计算资金占用损失；
```

**分段计算（跨2019年8月20日节点）**：
```
以×元为基数，2019年8月20日前按中国人民银行同期贷款基准利率，
2019年8月20日起按贷款市场报价利率（LPR），
自×年×月×日起至实际清偿之日止计算资金占用损失；
```

**起算日选择**：
1. 合同约定付款日之次日（优先）
2. 原告催告之次日
3. 起诉之日（最保守兜底）

### 第三项：支付违约金（77案，须与资金占用损失双轨准备）

**主位请求（按合同约定）**：
```
判令被告向原告支付违约金×元（按合同第×条约定，
以服务报酬×元为基数，按×%的标准计算，
自×年×月×日起至实际清偿之日止）；
```

**备位请求（防止调减后无据可依）**：
```
若贵院认为约定违约金过高，请求依据原告实际损失×元的130%
确定违约金，不低于×元；
```

**年化15.4%（LPR×1.5倍）是当前法院普遍接受的合理上限**。

### 第四项：返还预付款/服务费（34案，服务接受方作为原告时）

```
判令被告向原告返还[预付服务费/咨询费/定金/保证金]
人民币×元，并自×年×月×日起至实际返还之日止，
按照贷款市场报价利率（LPR）计算资金占用损失；
```

**专业术语规则**：
- 区分「返还」（不当得利/合同解除后恢复原状，民法典§566）与「赔偿」（违约损害赔偿，民法典§577），两者请求权基础不同
- 定金双倍返还须援引民法典§587，**不得与违约金并用**（「定金罚则与违约金不得并用」）
- 保证金/押金若无约定没收条款，原则上应全额返还

### 第五项：赔偿损失（41案）

```
判令被告赔偿原告因[违约行为描述]所造成的损失共计×元，
具体包括：
①[损失项目一]×元（见证据×：计算依据）；
②[损失项目二]×元；
③[损失项目三]×元；
合计×元；
```

### 第六项：确认/判令解除合同（与返还、赔偿并列）

**已发出解除通知**：
```
一、请求确认原、被告于×年×月×日签订的《×××服务合同》
    （合同编号：×××）已于×年×月×日（解除通知到达之日）解除；
二、请求判令被告返还…（恢复原状）；
三、请求判令被告赔偿…（损害赔偿）；
```

**未发出解除通知**：
```
一、请求判令解除原、被告于×年×月×日签订的《×××服务合同》；
```

## 三、诉讼请求标准排列顺序

```
一、确认解除合同（如有）
二、返还预付款/服务费（如有）
三、支付欠付服务报酬（含资金占用损失）
四、支付违约金（主位+备位双轨）
五、赔偿各项损失（逐项列明）
六、支付律师代理费（须有合同约定）
七、本案诉讼费由被告承担
```

## 四、服务合同纠纷特殊注意事项

### 4.1 服务已完成的证明（高频争议）
- **最强证明**：服务完成确认书（对方签字）
- **替代证明**：服务报告/成果文件 + 对方未在合理期限内提出异议
- **电子证据**：邮件往来、微信聊天记录（须截图并公证）

### 4.2 损失的可预见性（民法典§584）
须在事实与理由中论证：
- 损失是在订约时可合理预见的
- 区分「直接损失」（已发生的实际损失）与「可得利益损失」（合同履行后可获得的利益）

### 4.3 继续履行请求的特殊性
服务合同中继续履行请求极少被支持（因服务具有人身专属性），通常转为赔偿损失请求。

## 五、关键术语对照表

| 规范术语 | 禁止使用 | 说明 |
|---------|---------|------|
| 服务报酬 | 劳动报酬 | 民法典服务合同专章用语 |
| 贷款市场报价利率（LPR） | 银行同期贷款利率 | 2019年8月20日后统一用LPR |
| 资金占用损失 | 利息 | 服务合同欠付款的利息性质 |
| 确认解除 | 撤销合同 | 解除≠撤销 |
| 恢复原状 | 退款 | 合同解除后的法律后果用语 |

## 六、服务合同纠纷自检清单

- ☐ 服务合同（含补充协议）已列入证据清单
- ☐ 服务完成证明（确认书/成果文件）已列入证据清单
- ☐ 已付款凭证已列入证据清单
- ☐ 催告函及送达凭证已列入证据清单
- ☐ 违约金双轨：主位（约定）+ 备位（防调减）
- ☐ 资金占用损失与违约金未重复计算
- ☐ 定金罚则与违约金未并用
- ☐ 损失逐项列明，每项有计算依据和证据支撑
- ☐ 解除合同写法正确：确认解除（已通知）vs 判令解除（未通知）
