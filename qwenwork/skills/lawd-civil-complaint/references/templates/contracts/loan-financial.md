# 金融借款合同纠纷起诉状专项规则

> **加载时机**：Step 3 案由锁定为「金融借款合同纠纷」或「银行信用卡纠纷」时读取。须先读取 `contract-general.md`，再读取本文件。
> **数据来源**：近五年（2021—2026）365件案例，原告（金融机构）胜诉率约72%。

---

## 一、请求权基础

| 请求类型 | 主要法条 |
|---------|---------|
| 偿还贷款本金 | 民法典 §667、§675 |
| 支付合同利息 | 民法典 §674、§676 |
| 支付罚息/复利 | 民法典 §577；《最高院关于进一步加强金融审判工作的若干意见》 |
| 担保责任 | 民法典 §394（抵押）、§688（连带保证） |
| 提前到期 | 借款合同约定的加速到期条款（法院普遍认可） |

---

## 二、诉讼请求标准表述

### 第一项：偿还贷款本金（必备）

```
判令被告[借款人全称]向原告偿还贷款本金人民币×元；
```

### 第二项：支付合同利息（必备）

```
判令被告向原告支付贷款利息，以本金×元为基数，
按合同约定年利率×%（月利率×‰）计算，
自×年×月×日起至实际清偿之日止；
```

**逾期罚息（合同有约定时）**：
```
判令被告向原告支付逾期罚息，以逾期本金×元为基数，
按合同约定罚息利率（年利率×%，即正常利率上浮×%）计算，
自×年×月×日（逾期之日）起至实际清偿之日止；
```

**复利（合同有约定时）**：
```
判令被告向原告支付复利，以应付未付利息×元为基数，
按合同约定复利利率计算，自×年×月×日起至实际清偿之日止；
```

### 第三项：担保责任（有担保时必加）

**抵押担保**：
```
判令原告对被告[抵押人]名下[抵押物描述]（抵押权登记编号：×××）
在本金×元及利息、罚息、复利范围内享有优先受偿权；
```

**连带保证**：
```
判令被告[保证人全称]对上述第一、二项债务承担连带清偿责任；
```

### 第四项：律师费（合同约定且金额合理时主张）

```
判令被告承担原告为本案支出的律师代理费人民币×元；
```

## 三、金融借款合同纠纷特殊规则

### 3.1 利率规则（区别于民间借贷）
- 金融机构贷款**不适用**民间借贷LPR四倍上限（《最高院关于新民间借贷司法解释适用范围问题的批复》明确）
- 合同利率 + 罚息 + 复利均受保护，但明显畸高（如年化超过36%）的罚息/复利仍受司法调整
- 标准罚息：正常利率上浮50%（年化约为正常利率×1.5倍）
- 复利：以应付未付利息为基数，按罚息利率计算

### 3.2 提前到期条款（加速到期，31.5%案件涉及，全部获支持）
借款人逾期还款达合同约定期限，或出现其他约定违约事件时，须在事实与理由中明确陈述：
```
根据《借款合同》第×条约定，被告逾期还款超过×日，
原告有权宣布全部贷款提前到期。
×年×月×日，原告向被告发出《贷款提前到期通知书》，
宣布全部贷款人民币×元提前到期，要求被告立即偿还
（见证据×：提前到期通知书及送达凭证）。
```

### 3.3 电子合同效力
若借款合同系通过网络平台/APP签订，须在事实中说明：
```
上述借款合同系原、被告通过[平台名称]在线签订，
被告使用本人[手机号/身份证号]注册账户并以电子签名方式确认，
符合《中华人民共和国电子签名法》第三条规定，具有与手写签名同等法律效力
（见证据×：电子合同及签约记录）。
```

### 3.4 保证期间（中频争议，须严格审查）
- 连带保证：主债务履行期届满后**6个月**（或合同约定期间）内须向保证人主张
- 起诉状中须明确陈述：「×年×月×日，原告向被告[保证人]发出《催收通知书》，
  在保证期间内主张了保证责任」（见证据×）

## 四、事实与理由结构（金融借款专版）

```
[第1段] 合同签订
    ×年×月×日，原告与被告[借款人]签订《[贷款/借款]合同》
    （合同编号：×××），约定：贷款金额×元，贷款期限×年，
    贷款利率为年利率×%（月利率×‰），还款方式为[等额本息/到期一次性还本付息]，
    逾期罚息利率为正常贷款利率上浮×%（见证据1）。
    [如有担保：同日，被告[担保人]与原告签订《[保证/抵押]合同》，
    约定对上述贷款承担[连带/一般]保证责任/以[抵押物]设立抵押（见证据×）。]

[第2段] 放款情况（原告履约）
    合同签订后，原告于×年×月×日依约向被告账户（账号：×××）
    发放贷款人民币×元（见证据×：放款凭证/银行转账记录）。

[第3段] 被告违约
    贷款到期后/[提前到期后]，被告未按约定偿还贷款本息。
    截至×年×月×日，被告尚欠原告贷款本金×元、
    合同利息×元、逾期罚息×元、复利×元，合计×元
    （见证据×：贷款账户明细）。

[第4段] 催收过程（如有提前到期，在此说明）
    原告曾多次向被告发出催收通知，要求其偿还到期贷款，
    被告均未予回应（见证据×：催收记录）。
    [如有提前到期：×年×月×日，原告依据合同第×条宣布贷款提前到期，
    向被告发出《贷款提前到期通知书》（见证据×）。]

[第5段] 担保人催告（有担保时必备）
    在保证期间内，原告于×年×月×日向被告[保证人]发出《担保催收通知书》，
    要求其承担保证责任（见证据×）。

[第6段] 法律依据
    综上，为维护原告合法权益，特依照《中华人民共和国民事诉讼法》
    第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。
```

## 五、金融借款纠纷自检清单

- ☐ 借款合同（含电子合同签约记录）已列入证据清单
- ☐ 放款凭证（银行转账记录）已列入证据清单
- ☐ 贷款账户明细（本金/利息/罚息/复利分列）已列入证据清单
- ☐ 提前到期通知书及送达凭证（如有）已列入证据清单
- ☐ 担保合同/抵押登记证明（如有）已列入证据清单
- ☐ 催收记录（保证期间内）已列入证据清单
- ☐ 利率计算核实：合同利率 + 罚息利率 + 复利是否符合合同约定
- ☐ 保证期间已核实（主债务到期日起6个月内已向保证人主张）
- ☐ 诉讼标的额 = 本金 + 利息 + 罚息 + 复利（暂计至起诉日）
