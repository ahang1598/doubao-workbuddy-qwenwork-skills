# 名誉权纠纷专项规则（reputation-right.md）

> **案由识别**：被告实施侮辱、诽谤等行为，损害原告名誉，原告主张停止侵害、赔礼道歉、赔偿损失。  
> 适用民法典第1024—1000条（人格权编）。

---

## 一、裁判规律（基于190条样本，2021—2025年）

| 裁判结果 | 案件数 | 占比 |
|----------|--------|------|
| 部分支持（最典型） | 125件 | 65.8% |
| 部分驳回/部分支持 | 34件 | 17.9% |
| 全部驳回 | 19件 | 10.0% |
| 全部支持 | 12件 | 6.3% |

> **核心规律**：  
> - 「赔礼道歉+停止侵害」支持率约72%（最容易获支持的请求）  
> - 精神损害赔偿中位数仅2000元，最高30000元——须充分举证才能突破  
> - 律师费支持率约40%（须有合同+发票，且2023年后支持率上升）

---

## 二、名誉侵权四要素（全部满足方可立案）

| 要素 | 内容 | 举证方向 |
|------|------|----------|
| 行为违法 | 被告实施了侮辱、诽谤等违法行为 | 截图/录音/公证固化 |
| 名誉受损 | 原告社会评价客观降低 | 证人证词/职场影响证明 |
| 因果关系 | 损害系被告行为直接导致 | 时间线对应 |
| 主观过错 | 被告故意或过失 | 行为本身即可推定 |

---

## 三、诉讼请求结构

### 模板A：标准名誉权侵权（个人对个人）

```
一、请求判令被告立即停止对原告名誉权的侵害行为，
    删除在×（平台/渠道）发布的侵权内容；
二、请求判令被告在×（对应平台/渠道）公开向原告赔礼道歉，
    道歉内容须经原告认可，持续时间不少于×天；
    若被告拒不履行上述赔礼道歉义务，原告申请由人民法院在相关媒体
    （含网络媒体、纸质媒体）刊登本判决书的主要内容，
    刊登费用由被告负担；
三、请求判令被告赔偿原告精神损害抚慰金×元；
四、请求判令被告赔偿原告律师费×元；
五、本案诉讼费由被告承担。
```

### 模板B：网络平台侵权（含平台连带责任）

```
一、请求判令被告一（侵权人）立即停止侵权，
    删除在×平台发布的全部侵权内容；
二、请求判令被告二（平台方）在收到本判决书之日起×日内
    删除前述侵权内容，逾期承担连带责任；
三、请求判令被告一在×平台同一账号公开向原告赔礼道歉，
    持续时间不少于×天；
    若被告拒不履行，由法院在相关媒体刊登判决主要内容，费用由被告承担；
四、请求判令被告一赔偿原告精神损害抚慰金×元；
五、请求判令被告一赔偿原告律师费×元；
六、本案诉讼费由被告承担。
```

## 四、赔礼道歉请求的「影响范围相当」原则

民法典第1000条要求道歉渠道须与侵权行为影响范围相当：

| 侵权渠道 | 对应道歉请求渠道 | 胜诉率 |
|----------|------------------|--------|
| 抖音/快手账号公开发布 | 同一账号公开发布致歉声明 | ≈85% |
| 微信朋友圈/微信群 | 对应朋友圈/群发布道歉 | ≈80% |
| 村/社区口头传播 | 村委会公告栏书面公告 | ≈75% |
| 网络媒体报道 | 在同媒体发表声明 | ≈70% |
| 多渠道混合侵权 | 逐一对应各渠道 | ≈65% |

**逾期替代执行条款（必须内嵌，否则被告拒履行时执行无据）**：
> 「若被告拒不履行上述赔礼道歉义务，原告申请由人民法院在相关媒体
> （含网络媒体、纸质媒体）刊登本判决书的主要内容，刊登费用由被告负担。」

## 五、精神损害赔偿的举证增强策略

突破2000元中位数天花板须在起诉前完成以下证据固化：

1. **传播量量化证据**：播放量/转发量截图（公证固化优先）
2. **社会评价降低直接证据**：证人证词、好友反馈截图、职场影响证明
3. **精神损害医疗证据**：心理咨询记录、医院就诊记录
4. **原告社会身份证明**：职称证书、社会任职证明（身份越高影响越大）

**金额梯度参考**：

| 证据充分程度 | 参考赔偿区间 |
|--------------|--------------|
| 仅有截图，无传播量证明 | 500—2000元 |
| 有传播量证明（万级以上） | 2000—10000元 |
| 有职场/社会影响证明 | 5000—20000元 |
| 有医疗证据+高社会身份 | 10000—30000元 |

## 六、「言论自由」抗辩的应对

被告常以「正当监督评论」「言论自由」抗辩，应对策略：

- **侮辱型**（谩骂、人身攻击）：无论内容是否真实，侮辱性语言本身违法
- **诽谤型**（虚假事实）：被告须举证内容真实；原告只需证明内容虚假且造成损害
- **混合型**（部分真实+夸大）：法院区分真实部分（免责）与虚假部分（担责）

---

## 七、证据固化优先级

| 证据类型 | 固化方式 | 重要性 |
|----------|----------|--------|
| 网络侵权内容截图 | 公证处公证固化（最优） | ★★★★★ |
| 视频/音频记录 | 原始文件+MD5校验 | ★★★★ |
| 传播数据（播放量/转发量） | 截图+时间戳 | ★★★★ |
| 证人证词 | 书面证词+身份证明 | ★★★ |
| 医疗记录 | 医院原件 | ★★★ |

---

## 八、核心法条援引顺序

1. 民法典第1024条（名誉权保护——首要依据）
2. 民法典第1000条（赔礼道歉影响范围相当原则）
3. 民法典第1194—1197条（网络侵权连带责任——如涉及平台）
4. 民法典第1183条（精神损害赔偿）
5. 民法典第179条（停止侵害、赔礼道歉等责任方式）
