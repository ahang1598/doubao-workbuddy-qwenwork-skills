## 一、侵权类常见请求权基础

| 子案由 | 主要法条 | 责任类型 |
|-------|---------|---------| 
| 一般侵权 | 民法典 §1165、§1182、§1183 | 过错责任，需证明过错 |
| 机动车交通事故 | 民法典 §1208–§1217；《道交损司法解释》 | 过错+无过错混合，对行人采无过错 |
| 医疗损害 | 民法典 §1218、§1222、§1223 | 过错责任，特殊情形过错推定 |
| 产品责任 | 民法典 §1202–§1207；产品质量法 | 严格责任，生产者无过错责任 |
| 教育机构责任 | 民法典 §1199（无民事行为能力）、§1200（限制民事行为能力） | 过错推定 / 过错责任 |
| 饲养动物 | 民法典 §1245–§1251 | 严格责任为主，禁养动物加重 |
| 高空抛物 / 建筑物 | 民法典 §1253–§1257 | 严格责任 / 过错推定 |
| 环境污染、生态破坏 | 民法典 §1229；环境保护法 | 严格责任，因果关系举证倒置 |
| 网络侵权 | 民法典 §1194–§1197 | 网络用户过错 + 网络服务提供者通知规则 |
| 人格权（名誉/肖像/隐私） | 民法典 §995、§1024、§1032 | 过错责任 |
| 排除妨害 | 民法典 §235、§236 | 物权请求权，不适用诉讼时效 |
| 返还原物 | 民法典 §235 | 物权请求权，不适用诉讼时效 |
| 财产损害赔偿 | 民法典 §1184、§1165 | 过错责任 |

## 二、损害赔偿范围（必查）

### 人身损害（《民法典》§1179）
- **直接损失**：医疗费、护理费、交通费、营养费、住院伙食补助费、误工费、住宿费、康复费
- **后续损失**（造成残疾的）：残疾赔偿金、残疾辅助器具费、被扶养人生活费
- **死亡情形**：死亡赔偿金、丧葬费、被扶养人生活费
- **精神损害抚慰金**：根据后果严重程度酌定（一般 1–10 万元，重大伤残或死亡可至 5–20 万元）

> 计算口径详见各地《人身损害赔偿计算标准》及当年度统计公报，具体数字需要根据**事故发生地或受诉法院所在地**的城镇/农村人均可支配收入计算。**不要凭空填数字，需要案件办理时实际查询**。

### 财产损害（《民法典》§1184）
- **修复费用**或**重置成本**
- **替代品使用费**（如车损案件中的代步费）
- **可得利益损失**（生产经营性财产）

## 三、事实理由结构骨架

```
[第 1 段] 当事人关系与权利基础
    原被告之间的关系、原告所受的合法权益（生命健康、财产、人格权）

[第 2 段] 侵权事实
    时间、地点、被告的具体行为
    损害后果（详细描述受伤情况、财产损毁情况、精神损害情况）
    因果关系（被告行为与损害后果之间的因果链条）

[第 3 段] 法律分析与责任
    援引《民法典》第 ___ 条
    被告主观过错（过错责任案件）/ 法定无过错责任（产品、环境等）
    具体损害项目计算依据
    保险公司的责任限额（交通事故案件）
    综上恳请贵院判如所请
```

## 四、常见抗辩与预先消解

| 被告可能抗辩 | 预先消解方法 |
|------------|------------|
| 「我没有过错」 | 详细描述被告行为违反的注意义务标准（§1165 一般注意义务、行业规范、法律法规明确义务） |
| 「损害不是我造成的（无因果关系）」 | 时间空间衔接 + 鉴定意见 + 排除其他可能原因 |
| 「原告自身有过错（过错相抵）」 | 描述己方完全无过错的事实（如行人在斑马线内、严格按指示） |
| 「不可抗力 / 第三人原因」 | 强调被告行为是损害发生的直接原因，第三人因素不能完全免除责任 |
| 「损害已经赔偿（保险已赔）」 | 区分交强险、商业险、侵权人自行赔偿，扣除已赔金额仍有差额 |
| 「主体错误」 | 核实被告身份、车辆所有人、雇佣关系等 |

## 五、特别注意事项（侵权类通用）

### 1. 道交事故的特别要求
- 必备文件：交通事故责任认定书、医疗票据、伤残鉴定报告、车损评估
- 列被告：驾驶人 + 车辆所有人 + 保险公司（必要共同诉讼）
- 责任主体：实际驾驶人、车主（出借/出租/买卖未过户、挂靠关系）、雇主
- 受诉法院：事故发生地法院最便利（鉴定、查档、保险机构所在）

### 2. 医疗损害的特别要求
- 应申请医疗损害鉴定（医疗事故鉴定 / 司法鉴定）
- 病历完整性是关键：起诉前应完成病历复印
- 注意特殊过错推定情形（民法典 §1222）：违反法律法规、隐匿病历、伪造篡改

### 3. 产品责任的特别要求
- 销售者无过错责任（先行赔付，再向生产者追偿）
- 缺陷产品包括：制造缺陷、设计缺陷、警示缺陷
- 食品、药品、医疗器械：可主张惩罚性赔偿（食品安全法 §148 价款 10 倍 / 损失 3 倍；最低 1000 元）

### 4. 高空抛物
- 公安机关应当依法及时调查（民法典 §1254 第三款）— 起诉前应有报警 + 调查记录
- 物业管理人未尽安全保障义务的，应承担相应责任

### 5. 网络侵权
- 必须先尽通知义务（"避风港"原则）
- 公证保全证据（侵权页面、传播范围、阅读量、评论）
- 案件管辖：被侵权人住所地法院（信息侵权扩展规则）

### 6. 精神损害抚慰金
- 一般侵权：限于"造成严重精神损害"
- 特殊侵权（具有人身意义的特定物受损）：可主张
- 数额酌定参考：地方法院指导意见

## 六、收尾段范例

> 综上，被告 [核心侵权行为概括] 的行为已构成对原告 [权利类型] 的侵害，依法应当承担侵权责任。原告与被告的纠纷属于贵院管辖范围。**为维护原告合法权益，特依照《中华人民共和国民事诉讼法》第一百二十二条之规定，向贵院提起诉讼，恳请依法判如所请。**
