# 股东出资纠纷专项规则（shareholder-contribution.md）

> **前置加载**：本文件须在读取 `company-general.md` 后使用。  
> 数据来源：296条近五年案例总结。

---

## 一、高频请求类型

1. **补足出资**（最高频）：本金 + LPR利息 + 其他股东/董事连带责任
2. **返还抽逃出资**：抽逃金额 + LPR利息 + 协助抽逃的连带责任人
3. **认缴出资加速到期**（债权人追索）：须论证公司不能清偿到期债务

---

## 二、互斥规则

| 互斥组合 | 处理方式 |
|---------|---------| 
| 补足出资 + 赔偿损失（同一欠缺出资） | 通常不并存；补足出资本身即救济 |
| 抽逃出资返还 + 损害公司利益赔偿 | 可并存；抽逃返还是物权请求，赔偿是损害赔偿 |

---

## 三、诉讼请求标准表述

**补足出资（公司/债权人追索）：**
```
一、请求判令被告×××（股东）向[第三人/原告]××公司补足出资
    人民币×元（被告认缴×元，已实缴×元，未缴纳×元）；
二、请求判令被告支付资金占用利息（以×元为基数，按LPR计算，
    自×年×月×日起至实际缴纳之日止）；
三、请求判令被告×××（设立时其他股东/董事）对上述未出资部分
    承担连带责任（公司法§50）；
四、本案诉讼费由被告承担。
```

**返还抽逃出资：**
```
一、请求判令被告×××向[第三人/原告]××公司返还抽逃出资
    人民币×元；
二、请求判令被告支付资金占用利息（以×元为基数，按LPR计算，
    自×年×月×日起至实际返还之日止）；
三、请求判令协助抽逃的被告×××承担连带责任（公司法§54）；
四、本案诉讼费由被告承担。
```

**债权人追索加速到期：**
```
一、请求判令被告×××（未届出资期限的股东）在其认缴但未实缴的
    出资范围内（即人民币×元），对原告债权人民币×元承担补充赔偿责任；
二、本案诉讼费由被告承担。
```

## 四、专项术语规则

- "补足出资"（规范）；禁用"补交注册资本""补缴股本"
- "抽逃出资"（规范）；禁用"转走公司钱""挪用资金"
- "认缴出资加速到期"（规范）；禁用"提前到期""出资期限提前"
- 连带责任人须在被告栏明确列明，不可仅在事实理由中提及

---

## 五、事实理由四段式结构

```
[第1段] 公司设立/增资情况
    公司名称+设立时间+注册资本+被告认缴金额+认缴期限（见证据×）

[第2段] 被告出资履行情况
    实缴金额（见验资报告/银行流水）（见证据×）
    抽逃行为（时间+金额+方式，见银行流水/会计账簿）（见证据×）
    催告记录（见证据×）

[第3段] 违约/侵权行为
    欠付金额计算：认缴-实缴=欠付
    连带责任人的参与行为（其他股东/董事/实际控制人）

[第4段] 请求权基础
    援引顺序：公司法§49（出资义务）→§50（连带责任）→
    §51（董事催缴义务）→§53（抽逃出资禁止）→§54（抽逃连带）→
    民法典§577（违约责任）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 六、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 出资期限未届满（认缴制抗辩） | 债权人须论证公司已不能清偿到期债务（提供法院生效判决/执行裁定/资产负债表） |
| 抽逃出资证据不足 | 申请法院调取公司会计账簿；申请司法审计 |
| 连带责任人举证困难 | 提供公司章程+工商登记+银行流水，证明其他股东/董事知情并参与 |
| 新公司法5年实缴制影响 | 2024年7月1日后设立的公司，5年内须实缴；旧公司须核查过渡期规定 |
