# 合伙企业纠纷专项规则（partnership.md）

> **前置加载**：本文件须在读取 `company-general.md` 后使用。  
> 数据来源：356条近五年案例总结。

---

## 一、核心裁判规律

- **整体胜诉率66%**（含部分支持），但差异显著：
  - 知情权/账目查阅类：胜诉率>85%
  - 利润分配/退伙财产分配类："全部支持"率仅约30%
- **私募基金型有限合伙纠纷占比约38%**，集中于上海、广东、浙江
- **GP连带责任认定宽松化**：有限合伙企业欠付LP投资款，法院普遍对GP判令承担无限连带责任
- **引用规律"双轨制"**：合伙企业法专章条文（基础层）+ 民法典合同编（补充层）+ 民诉法第264条（执行保障层）

## 二、诉讼请求类型与互斥规则

| 请求类型 | 胜诉率 | 互斥/并列规则 |
|---------|--------|-------------|
| 退伙财产分配（清算后） | ~30%全额支持 | **与利润分配（同一时段）互斥**：退伙时须清算，利润已计入净资产，不得重复主张 |
| 利润分配 | ~40%部分支持 | 须有账目支撑；无账目时申请司法鉴定 |
| 知情权/账目查阅 | >85% | 可与利润分配并列（先查阅确认利润，再主张分红） |
| 确认合伙协议无效+不当得利返还 | 可并列 | 无效则以不当得利处理已履行部分 |
| 除名决议无效+恢复合伙人身份 | 可并列 | 确认无效是恢复身份的前提，不互斥 |
| **确认合伙协议无效 + 继续履行** | **互斥** | 无效则无履行基础 |

## 三、诉讼请求标准表述

**退伙财产分配：**
```
一、请求判令被告向原告支付退伙结算款人民币×元
    （以×年×月×日为退伙时间节点，依据合伙协议第×条及合伙企业法第45条
    确定原告对应合伙企业净资产份额，司法鉴定报告确认为×元）；
二、请求判令被告支付逾期付款利息（以×元为基数，自×年×月×日起按LPR计算）；
三、本案诉讼费由被告承担。
```

**GP连带责任（有限合伙基金）：**
```
一、请求判令被告××有限合伙企业向原告支付投资款本金×元及收益×元；
二、请求判令被告××公司（普通合伙人/基金管理人）对上述款项承担连带清偿责任；
三、本案诉讼费由被告承担。
```

## 四、核心法律依据（合伙企业法专章）

| 条文 | 内容 | 援引场景 |
|------|------|---------| 
| 合伙企业法§33 | 利润分配与亏损分担（约定优先，无约定按出资比例） | 利润分配纠纷 |
| 合伙企业法§43 | 合伙份额转让须其他合伙人一致同意 | 份额转让效力争议 |
| 合伙企业法§45 | 退伙结算（退伙时企业财产净值中对应份额） | 退伙财产分配 |
| 合伙企业法§49 | 合伙人除名程序要件 | 除名决议效力争议 |
| 合伙企业法§51 | 合伙企业解散事由 | 解散清算纠纷 |

## 五、专项术语规则

- "退伙结算款"（规范）；禁用"退股款""退伙金"
- "合伙份额"（规范）；禁用"合伙股权"
- "普通合伙人（GP）""有限合伙人（LP）"（规范）；须在首次出现时注明全称
- 合伙协议名称照录书面协议标题，不得自行简化

## 六、事实理由四段式结构

```
[第1段] 合伙关系建立
    合伙协议名称+签订时间+各方身份（GP/LP）+出资金额+利润分配约定（见证据×）

[第2段] 原告履约
    实际出资金额+时间（见银行流水）（见证据×）
    知情权行使记录（如并列主张）（见证据×）

[第3段] 被告违约/侵权行为
    退伙通知时间+退伙依据（见证据×）
    被告拒绝结算/拒绝分配的事实（见证据×）
    GP连带责任基础（有限合伙企业欠付LP款项）

[第4段] 请求权基础
    援引顺序：合伙企业法§33（利润分配）或§45（退伙结算）→
    合伙企业法§49（除名，如涉及）→
    民法典合同编（补充层）→民诉法§264（执行保障）→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 七、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 退伙财产分配无账目支撑 | 先行申请司法鉴定（合伙企业净资产评估），鉴定报告是胜诉关键 |
| 利润分配无账目依据 | 先提起知情权诉讼查阅账目，再主张利润分配 |
| GP连带责任举证 | 提供有限合伙协议+工商登记（GP身份）+GP实际管理行为证据 |
| 退伙时间节点争议 | 明确退伙通知送达时间，以书面通知送达日为退伙生效日 |
