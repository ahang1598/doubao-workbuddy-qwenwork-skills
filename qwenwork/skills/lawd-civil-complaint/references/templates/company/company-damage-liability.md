# 损害公司/股东/债权人利益纠纷专项规则（company-damage-liability.md）

> **前置加载**：本文件须在读取 `company-general.md` 后使用。

---

## 一、三类案由对照

| 案由 | 原告 | 被告 | 第三人 | 请求权基础 |
|------|------|------|--------|----------|
| 损害公司利益 | 股东（派生诉讼） | 董监高/关联人 | 公司 | 公司法§188、§189 |
| 损害股东利益 | 股东（直接诉讼） | 公司/控股股东/董监高 | — | 公司法§189 |
| 损害债权人利益 | 债权人 | 股东（抽逃出资/虚假出资） | 公司 | 公司法§49、§54 |

**关键互斥规则**：
- 损害公司利益之诉（派生诉讼）：赔偿金归属**公司**，不归股东个人
- 损害股东利益之诉（直接诉讼）：赔偿金归属**股东个人**
- 两者不可混同，须根据损失归属选择正确路径

## 二、诉讼请求标准表述

**损害公司利益（派生诉讼）：**
```
原告（股东）：……
被告（董事/高管/控股股东）：……
第三人（公司）：……

诉讼请求：
一、请求判令被告向第三人××公司赔偿损失人民币×元；
二、请求判令被告向第三人××公司返还其侵占公司财产×××；
三、本案诉讼费由被告承担。
```

**损害股东利益（直接诉讼）：**
```
一、请求判令被告（公司/控股股东/董监高）赔偿原告股东损失
    人民币×元；
二、本案诉讼费由被告承担。
```

**损害债权人利益：**
```
一、请求判令被告（虚假出资/抽逃出资股东）在虚假出资/抽逃出资
    范围内（即人民币×元）对原告债权承担补充赔偿责任；
二、本案诉讼费由被告承担。
```

---

## 三、派生诉讼前置程序（损害公司利益必须）

1. 原告资格：有限公司任何股东 / 股份公司连续180日单独或合计1%以上股东
2. 前置请求：先书面请求监事会（监事会成员侵害时请求董事会）于30日内起诉
3. 紧急情形：可不经前置直接起诉（情况紧急、不立即起诉将使公司利益受难以弥补的损害）
4. 公司列为第三人：公司**不能列为被告**，列为第三人

---

## 四、专项术语规则

- 派生诉讼赔偿金"归公司"须在诉请中写明（"向第三人××公司赔偿"）
- 直接诉讼赔偿金"归股东"（"向原告赔偿"）
- "董事、监事、高级管理人员"（规范全称）；可简称"董监高"
- "控股股东、实际控制人"须区分，不可混用

---

## 五、事实理由四段式结构

```
[第1段] 原告身份 + 被告侵权主体资格
    股东持股比例（派生诉讼须满足法定资格）（见证据×）
    被告担任的职务/控股地位（见工商登记/章程）（见证据×）

[第2段] 侵权行为事实
    具体侵权行为（关联交易/挪用资产/侵占财产/违规担保）
    时间+金额+方式（见证据×）
    前置程序（派生诉讼）：书面请求监事会/董事会的时间+内容+结果（见证据×）

[第3段] 损害后果
    公司损失/股东损失金额（见司法审计报告/财务报告）（见证据×）
    因果关系（被告行为→损害后果）

[第4段] 请求权基础
    损害公司利益：公司法§188（董监高忠实勤勉义务）→§189（派生诉讼）→民诉法§122
    损害股东利益：公司法§189（直接诉讼）→民诉法§122
    损害债权人利益：公司法§49→§54→民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 六、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 派生诉讼未经前置程序 | 起诉前必须有书面请求监事会/董事会的记录，或有紧急情形的说明 |
| 损失归属错误（混淆派生与直接） | 明确：公司损失→派生诉讼；股东个人损失→直接诉讼 |
| 损失金额无依据 | 申请司法审计；提交公司财务报告；委托资产评估 |
| 关联交易未经批准 | 核查：关联交易须经股东会/董事会批准，未批准的认定违规 |
