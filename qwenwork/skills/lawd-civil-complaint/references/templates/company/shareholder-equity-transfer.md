## 一、高频请求类型与互斥规则

| 请求类型 | 出现频次 | 互斥/并列规则 |
|---------|---------|-------------|
| 支付股权转让款+LPR利息 | 最高频（39次） | 可并列；利息起算日=约定支付日次日或催告函送达日次日 |
| 继续履行+办理工商变更登记 | 11次 | 可并列；公司须列为第三人 |
| 解除协议+返还转让款 | 11次 | **与继续履行互斥**，须择一主张或设主位/备位 |
| 确认协议无效+恢复原状 | 高频 | 无效须同时主张恢复原状，否则无法实现救济 |

## 二、诉讼请求标准表述

**支付股权转让款：**
```
请求判令被告某某于本判决生效之日起×日内向原告支付股权转让款
人民币×元，并自×年×月×日起至实际清偿之日止，按照中国人民银行
公布的同期贷款市场报价利率（LPR）计算利息。
```

**继续履行+办理变更登记：**
```
一、请求判令被告某某继续履行双方于×年×月×日签订的《股权转让协议》；
二、请求判令被告某某及第三人××公司协助将被告持有的××公司×%股权
    变更登记至原告名下；
三、如被告拒不履行，请求判令被告赔偿原告损失人民币×元。
```

**解除协议+返还转让款（主位/备位）：**
```
主位请求：
一、请求判令解除原告与被告于×年×月×日签订的《股权转让协议》；
二、请求判令被告返还原告已支付的股权转让款人民币×元，
    并自×年×月×日起按LPR计算利息至实际返还之日止；
备位请求（如主位不获支持）：
一、请求判令被告于×日内继续履行《股权转让协议》……
```

## 三、专项术语规则

- "股权转让款"（规范）；禁用"股权款""转让费"
- "标的股权"（规范）；禁用"目标股权""所购股权"
- 逾期利息须与违约金区分，不可重叠主张
- "协助办理工商变更登记"须将公司列为第三人

## 四、事实理由四段式结构

```
[第1段] 合同建立
    签订时间/双方/标的股权（公司名称+股权比例+出资额）/
    转让价款/付款节点/过户时间/生效条件

[第2段] 原告履约
    已支付转让款金额及时间（见证据×）
    催告记录（时间+方式+对方回应）（见证据×）

[第3段] 被告违约
    欠付金额三项列明：总价-已付=欠付
    违约性质：迟延履行/拒绝过户/拒绝履行
    优先购买权瑕疵（如有）：其他股东是否放弃优先购买权

[第4段] 请求权基础
    援引顺序：公司法§84（优先购买权，如涉及）→
    公司法§88（股权转让限制）→
    民法典§577（违约责任）→§585（违约金/损害赔偿）→
    民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 五、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 优先购买权瑕疵 | 起诉前核查：其他股东是否已书面放弃优先购买权（公司法§84） |
| 协议效力争议 | 审查章程限制性条款；股权转让须符合公司章程约定 |
| 逾期利息与违约金重叠 | 择一主张：有违约金条款时主张违约金；无违约金条款时主张LPR利息 |
| 公司未列为第三人 | 涉及工商变更登记的请求，必须将公司列为第三人 |
