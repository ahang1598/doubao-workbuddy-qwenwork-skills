---

## 一、三类决议效力及请求权基础

| 类型 | 适用情形 | 请求权基础 |
|------|---------|----------|
| 决议无效 | 内容违反法律法规强制性规定 | 公司法§26 |
| 决议可撤销 | 召集程序/表决方式违规，或违反公司章程 | 公司法§27 |
| 决议不成立 | 未召开会议、签字虚假、表决未达法定比例 | 公司法§27（新增类型） |

**撤销之诉时效**：自决议作出之日起**60日内**提起（公司法§27），逾期不予支持。

---

## 二、互斥规则

| 互斥组合 | 处理方式 |
|---------|---------| 
| 确认决议无效 + 撤销决议 | 通常择一；有绝对无效事由时主张无效；仅程序瑕疵时主张撤销 |
| 撤销决议 + 要求公司执行该决议 | **互斥**，不可并存 |

## 三、诉讼请求标准表述

**决议无效：**
```
一、请求判令确认被告××公司于×年×月×日作出的《×××决议》无效
    （理由：内容违反法律行政法规强制性规定）；
二、请求判令被告承担因决议无效给原告造成的损失人民币×元；
三、本案诉讼费由被告承担。
```

**决议撤销：**
```
一、请求判令撤销被告××公司于×年×月×日作出的《×××决议》
    （理由：召集程序/表决方式违反法律法规或公司章程，
    或决议内容违反公司章程）；
二、本案诉讼费由被告承担。
```

**决议不成立：**
```
一、请求判令确认被告××公司于×年×月×日作出的《×××决议》不成立
    （理由：未实际召开会议/签字系伪造/表决票数未达法定比例）；
二、本案诉讼费由被告承担。
```

**变更公司登记纠纷（附带）：**
```
一、请求判令撤销/确认无效前述决议；
二、请求判令被告××公司向公司登记机关申请撤销/变更依据前述决议
    办理的工商登记（登记事项：×××，登记时间：×年×月×日）；
三、本案诉讼费由被告承担。
```

## 四、专项术语规则

- 三类效力须精确区分，不得混用"无效"和"撤销"
- "决议不成立"是新公司法新增类型，旧案（2024年7月1日前）须注意适用问题
- 撤销之诉须在60日内提起，起诉状须写明决议作出日期
- 损害赔偿须附损失计算依据，不可笼统主张

## 五、事实理由四段式结构

```
[第1段] 原告股东身份 + 决议基本情况
    原告持股比例（见证据×）
    决议名称+作出时间+主要内容摘要

[第2段] 决议效力瑕疵事实
    无效：违反的法律法规强制性规定+具体条文
    撤销：召集程序违规（通知时间不足/未通知/通知对象遗漏）
          或表决方式违规（表决比例未达章程要求/关联股东未回避）
          或内容违反公司章程（具体条款）
    不成立：未实际召开会议的证据/签字伪造的鉴定/票数不足的统计

[第3段] 损害后果（如主张损害赔偿）
    决议执行导致的具体损失（见证据×）

[第4段] 请求权基础
    援引顺序：公司法§26（无效）或§27（撤销/不成立）→
    民法典§155（无效民事法律行为自始无效，如需）→
    民诉法§122
    收尾固定语：特提起诉讼，请求贵院依法支持原告的全部诉讼请求。
```

## 六、常见败诉风险预警

| 风险点 | 预防措施 |
|--------|---------| 
| 撤销之诉超过60日 | 收到决议通知后立即审查，超期只能主张无效或不成立 |
| 无效/撤销/不成立混淆 | 起诉前明确瑕疵类型：内容违法→无效；程序违规→撤销；未开会/伪签→不成立 |
| 损害赔偿无据 | 附司法审计报告或资产评估报告，量化损失 |
