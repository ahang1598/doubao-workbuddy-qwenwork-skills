# 离婚纠纷专项规则（divorce.md）

> **前置加载**：使用本文件前必须先读 `family/family-general.md`。  
> 本文件只写离婚纠纷的**差异化规则**，通识规范见 `family-general.md`。

---

## 一、案由适用条件

- 当事人请求**解除婚姻关系**（含同时主张财产分割、子女抚养权、损害赔偿）
- 诉讼离婚（区别于协议离婚，协议离婚在民政局办理，不适用本模板）
- **注意**：离婚后财产纠纷（双方已离婚，仅主张财产）→加载 `divorce-property.md`

---

## 二、诉讼请求结构（五段式）

### 模板A：标准离婚请求（含子女抚养+财产分割）

```
一、请求判令原、被告离婚；
二、请求判令婚生子（女）×××由原告直接抚养，被告每月支付抚养费×元，
    自本判决生效之日起于每月×日前支付，至×××年满十八周岁时止；
三、请求依法分割夫妻共同财产：
    （一）位于×市×区×路×号×室房屋（建筑面积×㎡，不动产权证号：×）
          归原告所有，原告向被告支付折价补偿款×元；
    （二）被告名下×银行账户（账号：×）存款×元由原告获得×元、
          被告获得×元；
四、本案诉讼费由被告承担。
```

### 模板B：仅请求离婚+子女抚养（无财产争议）

```
一、请求判令原、被告离婚；
二、请求判令婚生子（女）×××由原告直接抚养，被告每月支付抚养费×元，
    自本判决生效之日起于每月×日前支付，至×××年满十八周岁时止；
三、本案诉讼费由被告承担。
```

### 模板C：含损害赔偿（过错方离婚）

```
一、请求判令原、被告离婚；
二、请求判令婚生子（女）×××由原告直接抚养，被告每月支付抚养费×元；
三、请求依法分割夫妻共同财产（详见第三项）；
四、请求判令被告赔偿原告离婚损害赔偿金×元；
五、本案诉讼费由被告承担。
```

## 三、感情破裂的法定情形（民法典第1079条第三款）

以下情形法院支持率高，须在事实与理由中重点论证：

| 情形 | 举证方向 | 支持率参考 |
|------|----------|------------|
| 实施家庭暴力 | 报警记录/出警证明/伤情鉴定/医院诊断 | 约85% |
| 重婚/与他人同居 | 同居证据（酒店记录/照片/通话记录） | 约80% |
| 遗弃、虐待家庭成员 | 民政、警察、证人证词 | 约75% |
| 赌博、吸毒劣迹 | 行政处罚决定书/银行流水 | 约65% |
| 分居满二年 | 居住证明/通讯记录/证人证词 | 约60% |
| 感情不和（无特定事由） | 仅凭主观陈述，首次起诉驳回率约70% | 约30% |

> **实务提示**：首次起诉离婚被驳回后，六个月后再诉，法院通常认定感情已破裂。

## 四、子女抚养权归属论证结构

**四段论式写法**（对应民法典第1084条"子女最大利益"标准）：

1. **基本情况**：子女年龄×岁，现随原告共同生活（事实居住状态）
2. **原告优势**：原告收入稳定/居住环境良好/时间更充裕/主要照料者
3. **子女意愿**（满8岁时必写）：经征询，子女明确表示愿随原告生活
4. **结论**：综上，由原告直接抚养更有利于子女健康成长

## 五、夫妻共同财产分割要点

### 5.1 房产分割（最高频争议）

- **婚后共同购置**：通常各半分割或折价补偿；结合还贷情况确定补偿额
- **父母全额出资（赠与一方）**：属被告/原告婚前个人财产，另一方无权分割（民法典第1063条第（三）项）
- **父母部分出资**：出资部分属赠与一方的个人财产，婚后共同还贷部分属共同财产
- **婚前一方购置**：属个人财产，但婚后共同还贷的增值部分须另行计算

### 5.2 股权分割

- 须通过司法审计确定股权价值
- 代持股权须穿透审查实际出资人
- 请求内须明确：「对被告名下×公司×%股权中属于夫妻共同财产的部分依法予以分割」

### 5.3 隐匿转移财产（民法典第1092条）

- 须举证：账户大额异常转账+被告无法提供合理解释（仅有转账记录不足够）
- 「520」「1314」等特殊金额转账可作强力证据
- 请求写法：「被告恶意转移夫妻共同财产×元，请求判令被告少分或不分×项财产，原告多分相应份额」

## 六、损害赔偿请求（民法典第1091条）

适用情形：重婚、与他人同居、家庭暴力、遗弃虐待。

请求写法：
> 请求判令被告赔偿原告**离婚损害赔偿金**×元（含精神损害抚慰金×元）。

> **注意**：须写「离婚损害赔偿金」而非「精神损害赔偿金」（适用第1091条而非侵权责任编）。

---

## 七、核心法条援引顺序

1. 民法典第1079条（法定离婚情形）
2. 民法典第1084条（子女抚养权）
3. 民法典第1085条（抚养费标准）
4. 民法典第1062-1063条（夫妻财产）
5. 民法典第1087条（夫妻共同财产分割原则）
6. 民法典第1091条（损害赔偿，如有）
7. 婚姻家庭编解释（一）第56条（变更抚养，如附带请求）
