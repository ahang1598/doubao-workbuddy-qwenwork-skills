# 输出质检清单

输出前快速过一遍，任何一项不通过都要修改后再输出。

---

## 通用检查（所有操作）

- [ ] **核心信息完整**：原文的主要论点、关键数据、核心结论都出现在输出中
- [ ] **无引入性错误**：没有加入原文没有的事实、数据或观点
- [ ] **专有名词准确**：人名、产品名、术语、数字与原文一致，未被替换或改写
- [ ] **立场一致**：输出的立场和结论方向与原文一致

---

## 改写专项

- [ ] 篇幅与原文相近（±20%以内），除非用户另有要求
- [ ] 表达方式确实发生了变化（不是原文的复制粘贴）
- [ ] 段落逻辑顺序与原文基本一致，或调整后更清晰

---

## 扩写专项

- [ ] 原文每个核心段落都有对应的扩展内容
- [ ] 新增内容有具体锚点，不是空泛的套话
- [ ] 扩写后篇幅达到目标量级
- [ ] 没有重复原文意思（堆字数）

---

## 缩写专项

- [ ] 篇幅达到目标量级
- [ ] 用户标注"必须保留"的内容都在
- [ ] 每个核心论点至少保留一句
- [ ] 缩写后文本可以独立阅读，不依赖原文才能理解

---

## 风格迁移专项

- [ ] 目标风格特征明显体现（词汇、句式、语气都有变化）
- [ ] 原文的信息内容没有因风格迁移而丢失
- [ ] 没有因为追求风格而引入原文没有的观点
- [ ] 如有无法迁移的内容（如专业术语），已在输出后说明
