# 迟延履行金计算明细表模板

独立附表，随强制执行申请书一并提交法院。Word 表格格式。

---

## 表头信息

```
迟延履行期间债务利息计算明细表

案号：（XX）XX号
申请执行人：XXX
被执行人：XXX
执行依据：[执行依据名称及案号]
生效日期：YYYY年MM月DD日
履行期限届满日：YYYY年MM月DD日
暂计至：YYYY年MM月DD日（申请日）
```

---

## 表格结构

### 一、一般债务利息

| 序号 | 计算项目 | 本金(元) | 年利率 | 起算日 | 截止日 | 天数 | 利息金额(元) |
|------|----------|---------|--------|--------|--------|------|-------------|
| 1 | [第一段] | XXX | X% | YYYY/MM/DD | YYYY/MM/DD | XX | XXX |
| 2 | [第二段（如有部分履行）] | XXX | X% | YYYY/MM/DD | YYYY/MM/DD | XX | XXX |
| | **小计** | | | | | | **XXX** |

计算公式：利息 = 本金 × 年利率 ÷ 365 × 天数

### 二、加倍部分债务利息

| 序号 | 计算项目 | 未履行本金(元) | 日利率 | 起算日 | 截止日 | 天数 | 利息金额(元) |
|------|----------|--------------|--------|--------|--------|------|-------------|
| 1 | [第一段] | XXX | 0.0175% | YYYY/MM/DD | YYYY/MM/DD | XX | XXX |
| 2 | [第二段（如有部分履行）] | XXX | 0.0175% | YYYY/MM/DD | YYYY/MM/DD | XX | XXX |
| | **小计** | | | | | | **XXX** |

计算公式：利息 = 未履行本金 × 日万分之一点七五 × 天数

### 三、其他费用

| 序号 | 项目 | 金额(元) |
|------|------|---------|
| 1 | 案件受理费（被执行人负担部分） | XXX |
| 2 | 保全费（被执行人负担部分，如有） | XXX |
| | **小计** | **XXX** |

### 四、汇总

| 项目 | 金额(元) |
|------|---------|
| 本金 | XXX |
| 一般债务利息 | XXX |
| 加倍部分债务利息 | XXX |
| 案件受理费等 | XXX |
| **执行标的合计** | **XXX** |

---

## 表尾说明

```
注：
1. 以上金额暂计至YYYY年MM月DD日，此后至实际清偿之日止的一般债务利息和加倍部分债务利息另行计算。
2. 一般债务利息按判决主文确定的利率计算。
3. 加倍部分债务利息依据《民事诉讼法》第264条及法释〔2014〕8号司法解释，按日万分之一点七五计算。
4. [如有部分履行] 被执行人于YYYY年MM月DD日已支付XXX元，按先息后本规则抵充后，剩余本金为XXX元。

                              计算人：[律师姓名]
                              日期：YYYY年MM月DD日
```

## 多项给付义务时

判决含多项金钱给付义务时，每项单独列表计算，最后汇总：

```
一、第一项给付义务（货款）
  [一般利息表格]
  [加倍利息表格]

二、第二项给付义务（违约金）
  [一般利息表格]
  [加倍利息表格]

三、其他费用
  [费用表格]

四、总汇总
  [全部项目汇总表]
```
