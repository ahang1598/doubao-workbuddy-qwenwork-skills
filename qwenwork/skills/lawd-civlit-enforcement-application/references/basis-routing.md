# 执行依据路由规则

启动技能后必须首先判定执行依据类型，路由结果影响：管辖法院、附件清单、文书称谓、生效日期计算。

---

## 依据类型判定

### 场景标签格式

```yaml
basis_type: judgment | ruling | mediation | arbitration_award | notarized_document | payment_order
case_no: "（2024）浙01民初xxx号"
court_or_institution: "杭州市中级人民法院"
effective_date: "2024-06-15"
applicant_role: "申请执行人"
respondent_role: "被执行人"
```

## 六类路由对照表

### 一、法院判决书

| 项目 | 规则 |
|------|------|
| 管辖法院 | 一审法院执行局 |
| 生效日期 | 送达双方当事人后 + 上诉期（15日）届满次日；二审判决作出即生效 |
| 附件要求 | 判决书副本 + 生效证明（一审法院出具） |
| 文书称谓 | "依据（XX）XX号民事判决书" |
| 时效 | 判决生效之日起2年内申请执行（民诉法第250条） |

### 二、法院裁定书

| 项目 | 规则 |
|------|------|
| 管辖法院 | 一审法院执行局 |
| 生效日期 | 送达后 + 上诉期（10日）届满次日；不可上诉的裁定送达即生效 |
| 附件要求 | 裁定书副本 + 生效证明 |
| 文书称谓 | "依据（XX）XX号民事裁定书" |
| 时效 | 裁定生效之日起2年内 |

### 三、法院调解书

| 项目 | 规则 |
|------|------|
| 管辖法院 | 一审法院执行局 |
| 生效日期 | 双方当事人签收之日即生效（无上诉期） |
| 附件要求 | 调解书副本（无需生效证明） |
| 文书称谓 | "依据（XX）XX号民事调解书" |
| 时效 | 调解书生效之日起2年内 |
| 特殊注意 | 调解书内容通常为自愿履行条款，注意区分给付义务与非给付义务 |

### 四、仲裁裁决书

| 项目 | 规则 |
|------|------|
| 管辖法院 | 被执行人住所地 或 财产所在地的中级人民法院 |
| 生效日期 | 裁决书作出之日即生效（一裁终局） |
| 附件要求 | 仲裁裁决书副本 + 仲裁协议 + 送达证明（证明裁决已送达被执行人） |
| 文书称谓 | "依据XX仲裁委员会（XX）XX号裁决书" |
| 时效 | 裁决书作出之日起2年内 |
| 特殊注意 | 需确认是否已被法院裁定撤销或不予执行；涉外仲裁适用《纽约公约》 |

### 五、公证债权文书

| 项目 | 规则 |
|------|------|
| 管辖法院 | 被执行人住所地 或 财产所在地的人民法院 |
| 生效日期 | 公证书生效日（通常为出具日） |
| 附件要求 | 公证债权文书副本 + 执行证书（公证机构出具，必须有） |
| 文书称谓 | "依据XX公证处（XX）XX号执行证书" |
| 时效 | 执行证书载明的履行期限届满之日起2年内 |
| 特殊注意 | 必须持有公证机构出具的「执行证书」方可申请执行，仅有公证书不够 |

### 六、支付令

| 项目 | 规则 |
|------|------|
| 管辖法院 | 签发支付令的人民法院 |
| 生效日期 | 送达被申请人后15日异议期满次日 |
| 附件要求 | 支付令副本 + 生效证明 |
| 文书称谓 | "依据XX人民法院（XX）XX号支付令" |
| 时效 | 支付令生效之日起2年内 |
| 特殊注意 | 如被申请人在异议期内提出异议则支付令失效，不可申请执行 |

---

## 管辖法院选择规则

| 依据类型 | 管辖法院 | 级别 |
|----------|----------|------|
| 法院判决/裁定/调解书 | **一审法院** | 与一审同级别 |
| 仲裁裁决 | 被执行人住所地/财产所在地 | **中级人民法院** |
| 公证债权文书 | 被执行人住所地/财产所在地 | 按标的额确定级别 |
| 支付令 | 签发法院 | 与签发法院同级别 |

被执行人住所地与财产所在地不一致时，两地法院均有管辖权，申请执行人可择一申请。

## 生效日期计算辅助

| 依据类型 | 计算公式 | 示例 |
|----------|----------|------|
| 一审判决 | 最后送达日 + 15天 + 1天 | 2024-06-01 送达 → 2024-06-17 生效 |
| 一审裁定 | 最后送达日 + 10天 + 1天 | 2024-06-01 送达 → 2024-06-12 生效 |
| 二审判决/裁定 | 作出之日 | 2024-06-01 作出 → 2024-06-01 生效 |
| 调解书 | 双方签收日（以较晚者为准） | 原告 6/1 签、被告 6/3 签 → 2024-06-03 生效 |
| 仲裁裁决 | 作出之日 | 2024-06-01 作出 → 2024-06-01 生效 |
| 公证债权文书 | 公证书载明的生效日 | 视公证书内容 |
| 支付令 | 送达日 + 15天 + 1天 | 2024-06-01 送达 → 2024-06-17 生效 |

注：上诉期/异议期遇法定节假日顺延，需以日历实际计算。用户无法提供精确送达日时，标注"待律师确认"。

---

## 时效计算

申请执行时效 = 2年（民诉法第250条）

起算日 = 法律文书规定履行期间的最后一日；未规定履行期间的，从法律文书生效之日起计算。

⚠️ 时效警示规则：
- 距到期 ≤ 30天：「⚠️ 申请执行时效即将届满，请尽快提交」
- 已超期：「⚠️ 申请执行时效已超过2年（超出XX天），法院仍可受理但被执行人可提出时效抗辩」
