# OpenYida 宜搭应用搭建

把自然语言需求转换为可用的宜搭应用。支持从零搭建应用，也支持修改已有表单、流程、页面、报表、连接器、权限和数据功能。

## 支持的任务

- 搭建客户管理、项目管理、活动报名、工单、审批等完整应用。
- 创建或调整表单、字段、审批流程和业务规则。
- 开发并发布自定义页面、工作台、看板和报表。
- 配置连接器、权限和数据管理功能。
- 根据现有宜搭应用链接继续修改和完善应用。

## 执行流程

### 1. 保留用户需求

记录触发本技能的完整用户需求。运行准备完成后继续执行这项需求，不要求用户重新描述。

### 2. 确认 OpenYida 能力

执行 `openyida --version`，并检查当前宿主用户级 Skills 目录中的 `yida-skills/SKILL.md`。

常见位置：

- 千问办公：`~/.qwenworkcn/skills/yida-skills/SKILL.md`
- Codex：`~/.codex/skills/yida-skills/SKILL.md`
- Claude Code：`~/.claude/skills/yida-skills/SKILL.md`
- 通用 Agent：`~/.agents/skills/yida-skills/SKILL.md`

CLI 和根技能均可用时，直接进入第 4 步。

根技能存在后，本技能不再自行规划宜搭业务操作；后续意图路由和执行规范全部以根技能为准。

### 3. 准备运行环境

CLI 或根技能缺失时，向用户说明需要准备或更新 OpenYida 能力。用户已经明确要求安装时可直接执行，否则先取得同意。

```bash
npm install -g openyida
```

安装时不使用 `sudo`，不修改 npm 目录权限。安装完成后再次检查版本号和根技能文件；失败时返回原始错误和处理建议。

### 4. 加载应用搭建规范

直接完整读取 `yida-skills/SKILL.md`，再按其中的意图路由读取所需子技能。完整应用搭建必须读取 `skills/yida-app/SKILL.md`。

把已读取的 OpenYida 文档作为当前任务的执行规范。

### 5. 继续原始任务

在当前会话继续第 1 步保存的用户需求。安装或环境检查只是准备步骤，不是任务终点。

登录、工作目录、资源定位、子技能选择和宜搭业务操作全部按 OpenYida Skills 执行。

### 6. 处理宿主未刷新

根技能文件已经落盘但宿主尚未刷新技能清单时，仍然直接读取文件并继续任务。

当前运行环境无法读取新文件时，先让用户在当前会话回复“继续”。下一轮仍无法发现或读取时，再提示重启宿主。新建会话不是默认步骤。

## 完成标准

- OpenYida 根技能和所需子技能已读取。
- Agent 已继续用户最初提出的宜搭需求。
- 只有原始需求已完成，或 OpenYida Skills 明确要求等待用户操作时，才停止执行。

## 相关文件

- OpenYida 根技能：`yida-skills/SKILL.md`
- 完整应用编排：`yida-skills/skills/yida-app/SKILL.md`
