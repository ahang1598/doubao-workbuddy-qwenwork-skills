# 抖音文案生成子技能

## 平台规范

| 元素 | 规范 | 说明 |
|------|------|------|
| 视频标题 / 文案 | ≤ 55 字最佳（上限 300 字） | 搜索权重高，影响推荐分发 |
| 话题标签 | 2-5 个 | 混合热门 + 垂直话题 |
| 评论区引导 | 1-2 句 | 置顶评论，提升互动率 |
| 封面文案 | ≤ 15 字 | 清晰可读，决定划走还是点开 |
| 封面尺寸 | 1080×1920px | 9:16 竖版 |

---

## 完播率核心原则

**前 3 秒决定完播率**，文案必须在前 3 秒制造"不得不看"的理由：

| 钩子类型 | 示例 | 效果 |
|---------|------|------|
| 悬念钩子 | "你绝对想不到这条裤子多少钱" | 好奇心驱动 |
| 痛点钩子 | "小个子女生看过来！" | 精准召唤目标用户 |
| 反常识钩子 | "穿搭博主不会告诉你的秘密" | 颠覆认知 |
| 数字钩子 | "3秒教你显高10cm" | 具体利益点 |
| 情绪钩子 | "天呐！这条裤子也太绝了吧！" | 情绪感染 |

## 内容类型

### 类型一：短视频标题文案
配合视频内容，兼顾搜索关键词和点击吸引力。

```
标题公式：[关键词] + [核心利益点] + [情绪词]

示例：
"小个子穿搭｜显高10cm的秘密，学会了直接封神🔥"
"梨形身材穿搭｜这5条裤子穿上直接显瘦，姐妹们冲！"
```

### 类型二：评论区置顶引导
发布后第一时间**单独置顶**，引导互动和转化。

> ⚠️ **格式约束**：评论区引导语必须作为**独立的置顶评论**输出，禁止将其附在正文结尾。在输出模板中，评论区置顶话术与视频正文是两个独立区块，不可合并。

```
评论区置顶公式：[补充信息] + [行动引导]

示例：
"链接在主页橱窗～想要哪件评论区告诉我！"
"姐妹们！这套的详细穿搭公式在评论区，记得收藏📌"
"想要同款的扣1，我来整理链接给大家！"
```

### 类型三：直播带货话术 ⭐
适合直播间产品介绍、逼单、互动环节。

**直播话术结构**：
```
开场白（30秒）
  → "欢迎来到直播间！今天给大家带来..."

产品介绍（60-90秒）
  → 卖点 + 场景 + 价格锚点

互动引导（持续）
  → "想要的扣1" / "点个关注不迷路"

逼单话术（限时）
  → "库存只剩最后XX件" / "这个价格只有今天"

结尾留存
  → "关注我，每天分享穿搭技巧"
```

## 搜索关键词策略

抖音搜索权重越来越高，标题需要包含**搜索关键词**：

| 关键词类型 | 示例 | 布局位置 |
|---------|------|---------|
| 人群词 | 小个子、梨形身材、显瘦 | 标题前半段 |
| 场景词 | 约会穿搭、上班穿搭、秋冬穿搭 | 标题中段 |
| 效果词 | 显高、显瘦、气质、高级感 | 标题后半段 |
| 品类词 | 阔腿裤、风衣、针织衫 | 话题标签 |

## 分批生成流程

### 第一批：标题变体（5-8 条）
覆盖不同钩子类型，标注字数和关键词布局。

```
## 抖音标题变体

### 悬念钩子
1. "你绝对想不到这条裤子多少钱！小个子穿搭神器🔥"（24字）✅

### 痛点钩子
2. "小个子女生看过来！这5套穿搭直接显高10cm"（22字）✅

### 数字钩子
3. "3秒学会梨形身材穿搭公式，显瘦显高不踩雷"（22字）✅
```

### 第二批：评论区置顶话术（2-3 条）
配合选定标题，设计评论区引导。

### 第三批：封面文案建议
简短有力，≤ 15 字，清晰可读。

### 第四批（可选）：直播话术
如需直播带货，生成完整直播脚本框架。

---

## 输出模板

> ⚠️ **评论区置顶话术必须作为独立区块输出**，与视频正文严格分离，不可将引导语附在正文结尾。

```
## 抖音文案

### 视频标题（XX字）
[标题内容]

### 话题标签
#话题1 #话题2 #话题3

### 封面文案（≤15字）
[封面文字]

---

### 📌 评论区置顶话术（独立置顶，勿放正文）
[置顶内容]

---

### 发布建议
- 时间：18:00-21:00（黄金时段）
- 前3秒：[视频开场建议]
```

---

## 合规检查

生成后**逐条强制检查**，不通过则必须修改后重新输出：

- ✅ 标题 ≤ 55 字
- ✅ 话题标签 2-5 个
- ✅ 包含搜索关键词（人群词 + 场景词）
- ✅ **评论区置顶话术独立输出（强制）**：必须作为独立区块呈现，禁止附在正文结尾
- ✅ 无极限词（广告法合规）
- ✅ 直播话术中的库存/价格信息需确保真实
