# 微信公众号文案生成子技能

## 平台规范

| 元素 | 规范 | 说明 |
|------|------|------|
| 标题 | **≤ 22 字（强制硬限制）** | 朋友圈分享时超过 22 字会被截断，**必须严格遵守，不可超出** |
| 摘要 | **≤ 54 字（必填字段）** | 显示在消息列表，影响打开率，**每次生成必须提供摘要** |
| 正文 | 1500-3000 字（软文） | 故事化、场景化，避免硬广感 |
| 封面图 | 900×383px，2.35:1 横版 | 决定消息列表点击率 |
| 文内图 | 1080px 宽 | 不限高度 |

---

## 软文写作结构

**标准软文结构（5段式）**：
```
一、开头（故事 / 场景 / 痛点切入，150-200字）
    → 目标：前3段留住读者，不能有广告感

二、痛点分析（引发共鸣，200-300字）
    → 目标：让读者觉得"说的就是我"

三、解决方案（产品植入，300-500字）
    → 目标：自然过渡，产品是"顺带提到"的

四、使用体验（真实感受 + 数据，200-300字）
    → 目标：消除顾虑，建立信任

五、结尾（互动引导 + 福利，100-200字）
    → 目标：引导留言、转发、关注
```

## 标题公式

**高打开率标题公式**：

| 公式 | 示例 |
|------|------|
| 数字 + 干货 | "3个穿搭技巧，让你显高10cm" |
| 故事 + 悬念 | "我花了3年，终于找到了小个子的穿搭密码" |
| 痛点 + 解决 | "总觉得穿什么都不好看？可能是这个问题" |
| 反常识 | "为什么越贵的衣服，反而越难搭？" |
| 身份认同 | "真正懂穿搭的人，从不买这类衣服" |

**禁用词（广告法）**：最、第一、绝对、最好、顶级、极致、完美、史上最

## 分批生成流程

### 第一批：标题 + 摘要（3-5 组）
每组**必须同时包含标题和摘要**，供用户选择。摘要为**强制必填项**，不可省略。

> ⚠️ **标题硬性约束**：生成前必须数字数，超过 22 字的标题**禁止输出**，必须精简后再输出。

```
## 标题方案

### 方案一（故事切入）
标题：3年才找到的小个子穿搭密码（15字）✅
摘要：不靠大牌也能穿出高级感，这篇穿搭指南帮你省下一个亿。（26字）✅

### 方案二（痛点切入）
标题：总觉得穿什么都不好看？看这里（16字）✅
摘要：90%的穿搭问题，都出在这里。（15字）✅
```

### 第二批：正文结构确认
输出正文大纲，用户确认结构后再展开全文。

### 第三批：完整正文
按确认的结构生成完整软文，含小标题、段落分隔。

### 第四批：配套元素
- 封面图文案建议
- 文末互动引导话术
- 投票 / 留言话题设计

## 合规检查

生成后**逐条强制检查**，不通过则必须修改后重新输出：

- ✅ **标题 ≤ 22 字（强制）**：超出则必须精简，禁止以"最佳"或"建议"等措辞绕过此限制
- ✅ **摘要已提供（强制）**：摘要为必填字段，每次生成必须输出，不可省略或标注"如有"
- ✅ **摘要 ≤ 54 字（强制）**：超出则必须精简
- ✅ 无广告法极限词
- ✅ 产品植入自然，无硬广感
- ✅ 结尾有互动引导
