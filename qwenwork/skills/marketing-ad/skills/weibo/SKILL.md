# 微博文案生成子技能

## 平台规范

| 元素 | 规范 | 说明 |
|------|------|------|
| 正文 | **≤ 140 字（强制硬限制）** | 精炼为主，超过折叠，**必须严格遵守，含话题标签在内的全部文字均计入字数** |
| 话题标签 | 1-3 个，用 #话题# 格式 | 放开头或结尾 |
| 配图 | 1 / 3 / 6 / 9 张 | 长图文可用长图 |
| 超话 | 可选 | 垂直领域流量入口 |
| 配图尺寸 | 1080×1080px 或长图 | 1:1 或自定义 |

---

## 内容类型

### 类型一：话题种草文案
结合热门话题，自然植入产品，适合日常运营。

```
#今日穿搭# 秋天的第一件风衣安排上了
全身搭配不到800块，但质感拉满！
姐妹们觉得这套怎么样？
评论区选出你最喜欢的搭配👇

#穿搭分享 #秋冬穿搭指南
```

### 类型二：转发抽奖文案
适合新品发布、活动推广，快速涨粉。

```
[产品名]新品上线🎉
为了感谢大家的支持，这次抽3位送[奖品]！

参与方式：
1️⃣ 关注本账号
2️⃣ 转发本条微博
3️⃣ 评论区留言你最想要的[产品类型]

截止时间：[日期] 20:00
```

### 类型三：热点蹭热文案
结合当日热搜，快速产出相关内容，适合时效性强的营销。

**蹭热点原则**：
- 快（热点出现后 2 小时内发布）
- 巧（品牌与热点有自然关联，不强行蹭）
- 稳（避免争议性话题，不踩雷）

## 话题标签策略

| 类型 | 示例 | 作用 |
|------|------|------|
| 大话题（流量池） | #穿搭分享# #今日穿搭# | 获取泛流量 |
| 垂直话题（精准） | #小个子穿搭# #梨形身材穿搭# | 触达精准用户 |
| 品牌话题 | #品牌名# | 积累品牌声量 |
| 活动话题 | #活动名# | 聚合活动内容 |

**话题放置位置**：
- 开头放 1 个大话题（获取流量入口）
- 结尾放 1-2 个精准话题（触达目标用户）

## 分批生成流程

> ⚠️ **核心约束**：
> 1. **字数强制限制**：每条微博文案（含话题标签在内的全部文字）**必须 ≤ 140 字**，生成前必须计算字数，超出则必须精简后再输出。
> 2. **禁止附加非必需内容**：交付物只包含可直接发布的文案正文，**严禁**在文案后附加"文案亮点说明"、"创作思路"、"数据预测"等分析性内容。

### 第一批：文案主体（3-5 条变体）
覆盖不同类型（种草 / 抽奖 / 互动），标注字数，每条文案**直接可发布**。

```
## 微博文案变体

### 变体一（话题种草）
#今日穿搭# 秋天的第一件风衣安排上了
全身搭配不到800块，但质感拉满！
姐妹们觉得这套怎么样？评论区选出你最喜欢的搭配👇
#穿搭分享# #秋冬穿搭指南#
（约80字）✅

### 变体二（转发抽奖）
[文案内容]
（约120字）✅
```

### 第二批：话题标签组合
推荐 3 套话题标签组合，覆盖不同流量策略。

### 第三批：互动引导设计
- 评论区置顶话术
- 转发抽奖规则
- 超话签到引导

## 输出模板

```
## 微博文案

### 正文（约XX字）
[话题标签（开头）]
[正文内容]
[互动引导]
[话题标签（结尾）]

### 话题标签方案
- 方案A（泛流量）：#大话题1# #大话题2#
- 方案B（精准）：#垂直话题1# #垂直话题2#
- 方案C（混合）：#大话题# #垂直话题#

### 配图建议
[配图数量和内容建议]

### 发布建议
- 时间：工作日 12:00 / 18:00 / 21:00
- 互动：发布后 30 分钟内回复前 10 条评论
```

## 合规检查

生成后**逐条强制检查**，不通过则必须修改后重新输出：

- ✅ **正文 ≤ 140 字（强制）**：含话题标签在内的全部文字均计入字数，超出则必须精简，禁止以任何理由超出此限制
- ✅ **仅输出可发布文案（强制）**：禁止在文案后附加"文案亮点说明"、"创作思路"、"数据预测"等非发布内容
- ✅ 话题标签格式正确（#话题#）
- ✅ 话题数量 1-3 个
- ✅ 无极限词（广告法合规）
- ✅ 抽奖文案包含完整参与规则和截止时间
