# 小红书文案生成子技能

## 平台规范

| 元素 | 规范 | 说明 |
|------|------|------|
| 标题 | ≤ 20 字 | 带 emoji、数字更吸睛 |
| 正文 | 300-800 字（上限 1000 字） | 分段 + emoji，口语化 |
| 话题标签 | **严格 3-5 个**，禁止超过 5 个 | 混合大话题 + 精准长尾话题，宁少勿多 |
| 配图 | 6-9 张，3:4 竖版 | 首图决定点击率 |
| 配图尺寸 | 1080×1440px | 3:4 竖版 |

---

## 爆款公式

**标题钩子公式**：数字 + 痛点/结果 + 情绪词

```
示例：
✅ "小个子穿搭｜这5套闭眼抄，显高10cm"
✅ "月薪3000也能穿出万元质感！这套公式太绝了"
✅ "被问了800遍的裤子终于到货了🔥"
```

**正文结构公式**：
```
开头 3 行（黄金钩子）
  ↓
痛点共鸣（引发认同）
  ↓
解决方案 / 产品植入（自然过渡）
  ↓
使用体验 / 效果展示（真实感）
  ↓
结尾互动引导（评论 / 收藏 / 关注）
  ↓
话题标签（严格 3-5 个，禁止超过 5 个）
```

## 分批生成流程

### 第一批：标题（5-10 条）
覆盖 3-5 个不同角度，每个角度 1-2 条变体，标注字数。

```
## 小红书标题变体

### 角度一：痛点共鸣
1. "每天出门纠结穿啥？这5套闭眼抄"（16字）✅
2. "衣柜满了却没衣服穿？试试这个公式"（17字）✅

### 角度二：效果展示
3. "穿上它直接显瘦10斤🔥梨形身材救星"（17字）✅
...
```

### 第二批：正文（基于选定标题）
用户选定标题后，生成对应完整正文，含 emoji 分段和话题标签。

### 第三批：配套元素
- 话题标签推荐（大话题 + 长尾话题组合）
- 配图建议（首图 / 内容图 / 末图引导图）
- 评论区置顶话术
- 最佳发布时间（工作日 12:00-13:00 / 20:00-22:00）

## 合规检查

生成后自动检查：
- ✅ 标题 ≤ 20 字
- ✅ 正文 300-1000 字
- ✅ 无极限词（最、第一、绝对、最好）
- ✅ 话题标签 **3-5 个**（严格不超过 5 个）
- ✅ 无虚假数据（如确保"回购5次"属实）
