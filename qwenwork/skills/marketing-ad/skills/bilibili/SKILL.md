# B站文案生成子技能

## 平台规范

| 元素 | 规范 | 说明 |
|------|------|------|
| 视频标题 | **≤ 30 字（强制硬限制）** | 信息量要足，影响搜索推荐，**必须严格遵守，不可超出** |
| 视频简介 | ≤ 2000 字（250 字内最佳） | 补充视频信息，含时间轴 |
| 动态文案 | ≤ 500 字 | 图文动态，互动性强 |
| 标签 | 3-5 个 | 影响推荐分发权重 |
| 封面尺寸 | 1146×717px | 16:10 横版 |

---

## B站内容特点

B站用户对内容质量要求高，文案风格需要：
- **有信息量**：标题要让人知道能学到什么
- **真诚不浮夸**：B站用户对过度营销敏感，种草要自然
- **专业感**：适当展示专业知识，建立信任
- **互动感**：引导三连（点赞、投币、收藏）和评论

---

## 内容类型

### 类型一：视频标题
兼顾搜索关键词和点击吸引力，信息量充足。

```
标题公式：[核心关键词] + [内容亮点] + [受众定位]

示例：
"小个子穿搭指南｜5套显高10cm的公式，155cm也能穿出大长腿"
"平价穿搭测评｜300元以内的秋冬穿搭，到底能穿出多少质感？"
"穿搭避坑指南｜这5类衣服买了就后悔，踩过坑的来看看"
```

### 类型二：视频简介
补充视频信息，含时间轴、相关链接、互动引导。

```
简介结构：
[视频核心内容简述（1-2句）]

⏱ 时间轴：
00:00 开场
01:30 [章节一]
03:00 [章节二]
...

📌 视频中提到的：
- [产品/工具名]：[简短说明]

💬 欢迎在评论区告诉我你的[相关问题]！
👍 觉得有用的话，三连支持一下～
```

### 类型三：动态文案
适合新视频预告、日常互动、活动发布。

```
动态公式：[话题引入] + [内容预告/分享] + [互动引导]

示例：
"最近整理了一下衣柜，发现了一些被遗忘的宝藏单品🤩
下期视频会详细分享如何用这些基础款搭出高级感
你们最想看哪种风格？评论区告诉我！"
```

## 标签策略

| 标签类型 | 示例 | 作用 |
|---------|------|------|
| 内容分区标签 | 穿搭、时尚、生活 | 进入对应分区推荐池 |
| 人群标签 | 小个子、学生党、职场 | 精准触达目标用户 |

## 分批生成流程

> ⚠️ **核心约束**：
> 1. **单条输出原则**：用户要求生成一条文案时，**只输出一条**，禁止未经要求自行生成多条不同风格的变体。如需多条变体，须用户明确要求。
> 2. **标题强制要求**：每条文案必须包含**明确的标题（≤ 30 字）**，不可仅以正文形式呈现。
> 3. **标签格式强制要求**：标签必须使用 `#标签名#` 格式（首尾均有 #），数量 3-5 个，禁止使用 `#标签名` 或其他格式。

### 第一批：标题变体（3-5 条）
覆盖不同切入角度，标注字数和关键词。

```
## B站标题变体

### 干货教程型
1. "小个子穿搭指南｜5套显高10cm的公式，155cm也能穿出大长腿"（30字）✅

### 测评对比型
2. "平价穿搭测评｜300元以内的秋冬穿搭，到底能穿出多少质感？"（29字）✅

### 避坑指南型
3. "穿搭避坑指南｜这5类衣服买了就后悔，踩过坑的来看看"（26字）✅
```

### 第二批：视频简介
基于选定标题，生成完整简介，含时间轴框架。

### 第三批：标签推荐
推荐 3-5 个标签，覆盖分区 + 人群 + 场景。

### 第四批（可选）：动态文案
新视频发布时配套的动态预告文案。

## 输出模板

> ⚠️ **标签格式说明**：必须使用 `#标签名#` 格式（首尾均有 #），如 `#穿搭# #小个子# #秋冬穿搭#`，数量 3-5 个。

```

- 封面：横版 1146×717px，文字清晰可读
```

## 合规检查

生成后**逐条强制检查**，不通过则必须修改后重新输出：

- ✅ **标题 ≤ 30 字（强制）**：超出则必须精简，每条文案必须包含明确标题，不可仅以正文形式呈现
- ✅ **单条输出（强制）**：用户要求一条时只输出一条，未经要求禁止自行生成多条变体
- ✅ **标签格式正确（强制）**：必须使用 `#标签名#` 格式，数量 3-5 个
- ✅ 简介包含时间轴和互动引导
- ✅ 无极限词（广告法合规）
- ✅ 种草内容自然，无硬广感
