# 朋友圈文案生成子技能

## 平台规范

| 元素 | 规范 | 说明 |
|------|------|------|
| 文案长度 | **≤ 6 行（强制硬限制），约 140 字以内** | 超过显示"全文"，点击率下降，**必须严格遵守，不可超出** |
| 配图数量 | 1 / 3 / 6 / 9 张 | 九宫格视觉冲击力最强 |
| 图片比例 | 1:1 正方形最佳 | 保证缩略图美观完整 |
| 配图尺寸 | 1080×1080px | 正方形标准尺寸 |
| 发布频率 | 每天 ≤ 1-2 条营销内容 | 避免刷屏导致被屏蔽 |

## 黄金位置原则

```
┌─────────────────────────────────┐
│  第1行 ← 黄金位置，必须抓眼球    │
│  第2行 ← 黄金位置，留住读者      │
│  第3行                           │
│  第4行                           │
│  第5行                           │
│  第6行 ← 行动号召 / 引导私聊     │
└─────────────────────────────────┘
```

**核心原则**：
- 前两行是"黄金位置"，必须有钩子（悬念 / 数字 / 反差）
- 降低广告感：加入生活感、真实感，像朋友分享而非推销
- 结尾留悬念或引导私聊，不要直接贴链接

## 文案公式

**九宫格带货公式**：
```
[生活场景 / 情绪共鸣]（1-2行）
[产品亮点 / 反差信息]（1-2行）
[价格锚点 / 稀缺感]（1行）
[行动引导]（1行）
```

**示例**：
```
闺蜜问我最近怎么变好看了
其实就是学会穿搭了而已
这套全身不到500
但看起来像5000
想要同款的姐妹评论区举手🙋
```

## 分批生成流程

> ⚠️ **核心约束**：朋友圈文案必须是**可直接复制发布的精简文案**，禁止输出文案策划方案、排版建议、分析说明等非发布内容。每条文案严格控制在 **6 行以内**，生成前必须数行数，超出则必须精简后再输出。

### 第一批：文案主体（3-5 条变体）
覆盖不同情绪基调（生活感 / 惊喜感 / 悬念感），每条文案**直接可发布**，标注行数。

```
## 朋友圈文案变体

### 变体一（生活感）
闺蜜问我最近怎么变好看了
其实就是学会穿搭了而已
这套全身不到500
但看起来像5000
想要同款的姐妹评论区举手🙋
（5行，约80字）✅

### 变体二（悬念感）
今天这套也太绝了吧
姐妹们猜猜全身多少钱？
答案：不到300
显瘦显高还不挑人
想要链接的扣1👇
（5行，约65字）✅
```

### 第二批：九宫格配图规划
根据选定文案，输出九宫格每张图的内容建议。

### 第三批：发布策略建议
- 最佳发布时间（早 8:00 / 午 12:00 / 晚 21:00）
- 本周发布频率建议
- 评论区互动话术

## 合规检查

生成后**逐条强制检查**，不通过则必须修改后重新输出：

- ✅ **文案 ≤ 6 行（强制）**：超出则必须精简，禁止以任何理由超出此限制
- ✅ **输出形式为可直接发布的文案（强制）**：禁止输出文案策划方案、排版建议、亮点说明、分析内容等非发布内容；每条变体必须是用户可直接复制到朋友圈发布的完整文案
- ✅ 无极限词（广告法合规）
- ✅ 有生活感，广告感低
- ✅ 结尾有明确行动引导
- ✅ 九宫格图片数量为 1/3/6/9 张
