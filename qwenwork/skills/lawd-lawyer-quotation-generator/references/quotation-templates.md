# 法律服务报价方案模板参考

> 本文件基于律师事务所的实际报价方案整理，提供五种不同类型的报价模板结构。

---

## 一、模板一：仅报价

### 适用场景
- 案件简单明确，客户已了解律所和律师
- 老客户续委托，无需重复介绍服务内容和团队
- 案件类型明确，标准化程度高

### 文档结构

```
1. 律所名称 + 文档标题（封面）
2. 正式称谓
3. 委托事项描述（简述案件背景）
4. 报价表格
   - 法律事务列
   - 付费时间/条件列
   - 律师费用标准列
5. 脚注说明（解释特殊条款）
6. 结尾语 + 律所署名 + 日期
```

### 报价表格结构

| 法律事务 | 付费时间/条件 | 律师费用标准（人民币） |
|---------|-------------|---------------------|
| {诉讼事项名称}（一审、二审） | 委托合同签订之日起5日内 | {X}万元 |
| {非诉讼事项}基础服务费 | 委托合同签订之日起5日内 | {X}万元（含{N}小时） |
| 风险代理费 | 收到给付款项之日起5日内 | 收回财产的{X}% |


**多方案对比报价表格（纵向归类式）：**

适用于：同一案件提供多种收费模式供客户选择（如固定收费 vs 风险代理）

**方案一：基础服务费用+风险代理费**

| 项目 | 付费时间/条件 | 律师费金额（万元） |
|-----|-------------|-------------------|
| 基础服务费用 | 委托代理合同签署完毕之日起5日内 | 20 |
| 基础服务费用 | 开庭（包括庭前会议）之日起5日内 | 10 |
| 风险代理费 | 收到仲裁裁决，或达成调解、和解，或以其他方式确认减损结果之日起5日内 | 减损金额的2% |

**方案二：按阶段固定收费**

| 项目 | 付费时间/条件 | 律师费金额（万元） |
|-----|-------------|-------------------|
| 委托合同签订阶段 | 委托代理合同签署完毕之日起5日内 | 60 |
| 开庭阶段 | 开庭（包括庭前会议）之日起5日内 | 20 |
| 结案阶段 | 收到仲裁裁决，或达成调解、和解，或以其他方式结案之日起5日内 | 20 |

### 脚注要素
- 基础服务费包含的小时数及超时费率
- 在途时间折半计算规则
- 复杂程度超预期的协商条款

### 参考范例要点
- 股东知情权诉讼：一审二审合计15万元
- 关联商业谈判非诉服务：基础10万元（含50小时），超时2000元/小时
- 风险代理费：收回财产的3%

## 二、模板二：报价+服务内容

### 适用场景
- 需要明确服务范围的标准诉讼案件
- 客户需要了解律师具体做哪些工作
- 中等复杂度案件

### 文档结构

```
1. 律所名称 + 文档标题（封面）
2. 正式称谓
3. 委托事项描述
4. 报价表格（分阶段）
   - 基础法律服务费（按阶段细分）
   - 风险代理费（按结果区分）
5. 服务内容清单
6. 衍生事项说明
7. 结尾语 + 律所署名 + 日期
```

### 报价表格结构（分阶段式）

| 阶段 | 付费时间/条件 | 律师费金额（万元） |
|-----|-------------|-------------------|
| **基础法律服务费** | | |
| 一审阶段 | 委托合同签订之日起5日内 | {X} |
| | 递交立案材料进入诉前调解之日起5日内 | {X} |
| | （如有）开庭前5日 | {X} |
| 二审阶段（如有） | 决定提起上诉或对方上诉之日起5日内 | {X} |
| **风险代理费** | | |
| 调解/和解达成目的 | 调解/和解协议生效之日起5日内 | {X} |
| 判决胜诉 | 判决生效之日起5日内 | {X} |
| 实际取得款项 | 收到给付款项或其他财产之日起5日内 | 收回财产的{X}% |

### 服务内容清单（标准4项）
1. 法律分析、风险研判、法律建议，协助制定诉讼策略
2. 协助搜集/调取必要证据
3. 介入案件相关谈判，出具相关协议（和解、调解等）
4. 参与诉讼全过程（诉前调解、一审、二审），起草各类法律文书

### 衍生事项条款
> 如案件涉及其他衍生诉讼、或其他专项等委托的，需另行协商收费及签订补充合同或新的委托代理合同。

## 三、模板三：标准+费用

### 适用场景
- 需要引用法规标准增强报价合理性
- 标的金额较大，需展示收费合规性
- 客户对收费标准有疑虑时

### 文档结构

```
1. 律所名称 + 文档标题
2. 正式称谓 + 致谢
3. 委托事项描述
4. 第一部分：律师法律服务收费标准性规定
   - 国家层面法规引用
   - 地方层面法规引用
   - 参考计算示例
5. 第二部分：具体收费方案
   - 收费模式说明
   - 收费方案表格
   - 脚注说明
6. 结尾语 + 律所署名 + 日期
```

### 法规引用模块

引用的核心法规：
1. **司法部等三部门**：《关于进一步规范律师服务收费的意见》（司发通〔2021〕87号）
   - 风险代理各环节收费上限（按标的额分段）
2. **地方规定**：如北京市全面放开律师收费通知（市场调节价）
3. **地方指导价**：如《北京市律师诉讼代理服务收费政府指导价标准》
   - 参考标准计算示例

### 收费方案表格结构

| 收费模式 | 金额（万元）/标准 | 支付时间 |
|---------|-----------------|---------|
| **基础服务费用+风险代理费** | 二者合计不超过{X}万元 | |
| 基础服务费用 | {X} | 委托代理合同签署之日起5日内 |
| 风险代理费 | 减损金额的{X}% | 确认减损结果之日起5日内 |

### 脚注体系
- 脚注①：方案覆盖范围（如仲裁阶段、执行阶段）
- 脚注②：费用上限说明
- 脚注③：专业术语定义（如"减损金额"）
- 脚注④：执行阶段结果纳入计算
- 脚注⑤：弹性协商条款

## 四、模板四：服务内容+团队+价格

### 适用场景
- 高端/复杂案件，需全面展示律所实力
- 首次合作的重要客户
- 需要综合非诉+诉讼服务的案件
- 投融资、资本市场等专业领域案件

### 文档结构

```
1. 律所名称 + 文档标题（封面）
2. 正式称谓 + 致谢
3. 委托事项描述
4. 第一部分：法律服务内容
   - （一）非诉讼法律服务（6项）
   - （二）诉讼/仲裁法律服务（7项）
5. 第二部分：法律服务团队介绍
   - 团队概述
   - 各律师详细简历
   - 代表性业绩
6. 第三部分：法律服务费用
   - 法规依据
   - （一）非诉讼法律服务费用（多方案）
   - （二）诉讼法律服务费用
7. 结尾语 + 律所署名 + 日期
```

### 非诉讼服务内容（完整6项）
1. 法律咨询、法律建议
2. 法律风险研判，提供法律分析及建议
3. 制定非诉谈判策略；搜集、汇总、梳理证据，为可能的诉讼/仲裁做取证准备
4. 参加或协助与相关主体磋商、谈判
5. 向相关主体发送律师函
6. 协助起草、审核、修改相关法律文书

### 诉讼/仲裁服务内容（完整7项）
1. 案件法律分析与风险研判，协助制定诉讼策略
2. 依法调查取证（公安户籍、工商内档、财产信息等），必要时申请调查令
3. 代为向法院申请财产保全
4. 代表参与案件诉讼/仲裁全流程（提起诉讼、调查取证、调解/和解、庭审、辩论等）
5. 庭审后跟踪案件进展，向承办法官/仲裁员提供法律依据及类案参考
6. 必要时介入相关谈判，提供法律建议，协助确定谈判策略
7. 协助起草诉讼过程中所涉及的各类法律文书

### 律师简历格式

```markdown
**{姓名} 律师**

{律所全称}{职位}

| 项目 | 内容 |
|-----|------|
| 专长领域 | {领域1}、{领域2}、{领域3} |
| 执业证号 | {证号} |
| 执业年限 | {X}年 |

**简介**：{一段话描述律师专业背景和主要业绩}
```

### 代表性业绩格式
按领域分类，列出具体案例：
- 案件类型描述
- 案涉金额
- 案件结果（胜诉/调解/收回款项等）

### 非诉讼费用表格（多方案对比）

| | 基础固定费用（万元） | 包含基础时长及超时费率（元/小时） | 有效服务时长 | 风险代理费 |
|-----|----------|-------------|---------|---------|
| 方案一 | {X} | {N}小时内，超时按{Y}元/小时 | {Z}个月内 | 协商 |
| 方案二 | {X} | {N}小时内，超时按{Y}元/小时 | {Z}个月内 | 协商 |

### 风险代理费说明
> 若本所在向贵方提供法律服务的过程之中创造了较大价值的，如指导/促成双方达成协议化解后期诉讼/仲裁法律风险、对方增加担保等增信保障措施、律师介入促成谈判、律师介入收回部分投资损失等较大成果，双方可友好协商确定风险代理费用。

## 五、模板五：团队+费用

### 适用场景
- 再审案件、疑难案件
- 需要突出律师团队专业性和经验
- 案件已经经过一审二审，客户需要信心保证

### 文档结构

```
1. 律所名称 + 文档标题（如"民事再审诉讼法律服务报价方案"）
2. 正式称谓
3. 案件背景描述（包含一审二审情况）
4. 第一部分：法律服务团队介绍
   - 团队成员简表
   - 核心律师详细简历（附后）
5. 第二部分：法律服务费用报价
   - 报价表格（阶段式 + 风险代理费）
   - 费用包含说明
   - 差旅费说明
6. 结尾语 + 律所署名 + 日期
7. 附录：核心律师详细个人介绍
```

### 团队简表格式

| 姓名 | 执业年限 | 业务专长 | 所内任职 |
|-----|---------|---------|---------|
| {姓名1} | {X}年 | {专长} | {主任/合伙人/律师} |
| {姓名2} | {X}年 | {专长} | {职位} |

### 报价表格结构（阶段+成果式）

| | 签订委托代理合同之日起5日内 | {关键节点}之日起5日内 | 风险代理费 |
|-----|----------|----------|----------|
| 律师费金额 | {X}万元 | {X}万元 | {触发条件}，应于结果确定之日起5日内支付{X}万元 |

### 费用包含说明
> 以上报价包括本所提供法律服务所需的通讯费、复印费、管理费和税金、律师执业保险以及律师报酬。如存在异地差旅费的，实报实销。

- {职务1}

## 六、通用要素汇总

### 开场白模板

**简洁版：**
> 关于贵司与{相对方}（以下称"相对方"）{案件类型}一案之法律服务（以下称"委托事项"），根据贵司的具体诉求及服务内容，现向贵司提供本法律服务报价方案。

**礼貌版：**
> 感谢贵方的信任。就{案件描述}之法律服务（以下称"本事务"），基于贵我双方的友好沟通，本所现向贵方提供法律服务收费方案如下：

### 结尾语模板

**简洁版：**
> 以上法律服务方案，供贵司参考。如有任何疑问，可随时与本所律师联系。
> 顺祝商祺。

**标准版：**
> 以上法律服务报价方案供贵方参酌。
> 如有任何疑问，可随时与服务律师联系。
> 顺祝商祺！

### 日期格式
- 使用中文格式：`二〇二五年X月X日`
- 如未确定具体日期：`二〇二五年X月`

### 付费条件标准表述
- `委托合同签订之日起5日内`
- `向人民法院递交立案材料并经人民法院审查通过进入诉前调解阶段之日起5日内`
- `（如有）开庭前5日`
- `贵司决定提起上诉或对方提起上诉之日起5日内`
- `收到仲裁裁决/判决之日起5日内`
- `达成调解/和解之日起5日内`
- `收到给付款项或其他财产之日起5日内`
- `结果确定之日起5日内`
