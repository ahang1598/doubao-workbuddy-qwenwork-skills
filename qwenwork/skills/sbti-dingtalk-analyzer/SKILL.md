# 钉钉言行风格 × SBTI 人格自动分析

从你的钉钉聊天记录出发，提炼言行风格画像与工作氛围侧写，自动模拟完成 SBTI 32 题，输出专属人格报告与结果海报。全程无需手动答题。

## 禁止事项

- 禁止直接引用聊天原文：输出画像时只做极短引用，人名/群名/业务名尽量模糊化
- 禁止以 Base64 或 `data:image/...;base64,...` 形式输出结果海报，只能通过本地文件路径引用
- 禁止改写 intro/desc 原文：`final.intro` 与 `final.desc` 必须一字不漏逐字输出，不得扩写、压缩或二次创作
- 禁止随机噪声盖过画像主趋势：扰动幅度只能在主方向周围微调，不得让最终人格偏离画像结论

## 强制要求

- 执行前必须向用户发送固定提示语：**"正在读取并分析您的近期言行记录..."**
- 分支题逻辑必须严格执行：`drink_gate_q1 == 3`（饮酒）才继续模拟 `drink_gate_q2`，否则跳过
- 答题扰动必须可复现：使用 `seed = hash(用户身份标识 + 当天日期)` 驱动伪随机，保证同一用户同一天结果基本稳定
- 最终回复必须附上结果海报图片，严禁只输出文字而遗漏图片

## Phase 2 — 拉取当前用户发送的消息

**目标：** 拉取当前用户本人发送的消息，不限时间范围，满足以下两个条件后停止：
- 累计有效消息 **≥ 50 条**
- 每条消息正文长度 **≥ 5 个字符**（过短的消息如"嗯""好的""收到"不计入有效条数）

**执行方式：**

```bash
dws chat message list-all \
  --limit 50 \
  --cursor "0" \
  --format json
```

**循环拉取规则：**

1. 每次拉取后，从结果中过滤出 `sender == 当前用户` 且 `正文长度 ≥ 5` 的消息，累加到有效消息池
2. 若有效消息池 **< 50 条** 且 `hasMore=true`，继续用 `nextCursor` 翻页
3. 重复直到有效消息池 **≥ 50 条** 或 `hasMore=false`（消息耗尽）
4. 无上限页数约束——以满足 50 条有效消息为唯一终止条件

**会话上下文保留：**

拉取过程中，同步保留每条有效消息所在会话的上下文（前后各 2～3 条他人消息），作为 Phase 2.5 工作氛围分析的佐证材料，不计入有效消息数。

**消息池最终用途：**

- **有效消息（用户本人发送，≥5字符）** → 用于 Phase 3 言行风格画像 + Phase 4 模拟答题
- **会话上下文（他人消息）** → 仅用于 Phase 2.5 工作氛围分析，不参与性格推断

---

## Phase 2.5 — 工作氛围分析

基于 Phase 2 拉取的**全部消息**（用户本人 + 会话上下文），判断当前用户所处的工作氛围与职能背景。

**分析维度：**

| 维度 | 判断依据 |
|------|---------|
| **职能倾向** | 消息中出现的专业词汇、讨论议题、决策方式 |
| **协作模式** | 对话对象的角色（研发/设计/业务/管理层），群聊名称与话题 |
| **工作节奏** | 消息密度、响应速度、是否有 deadline/上线/发版等关键词 |
| **语言风格** | 技术性表达（代码/架构/接口）vs 业务性表达（GMV/转化/DAU/策略）|

**输出结构（供 Phase 3 画像使用）：**

```
工作氛围标签：<主标签> + <副标签（可选）>
  - 主标签候选：技术研发 / 产品设计 / 业务运营 / 团队管理 / 设计创意 / 综合职能
  - 副标签候选：偏前线执行 / 偏决策管理 / 偏跨团队协作 / 偏独立深度工作

佐证摘要（2～4条）：
  - 从会话上下文中提炼，说明判断依据，不直接引用原文
```

**注意：** 工作氛围标签是画像的背景底色，不影响 SBTI 人格计算，但会体现在最终报告的"你的工作底色"一节。

---

## Phase 3 — 生成言行风格画像

基于 Phase 2 有效消息池，融合 Phase 2.5 工作氛围背景，输出结构化画像（供后续模拟答题使用，不要过长）：

| 维度 | 关注点 |
|------|--------|
| 沟通风格 | 直接/委婉、理性/感性、幽默/严肃 |
| 情绪基调 | 稳定/波动、容易焦虑/更松弛 |
| 关系模式 | 黏人/独立、信任/多疑、边界感强/弱 |
| 行事风格 | 计划性强/随性、规则导向/灵活变通 |
| 自我认知 | 自信/自卑、目标感强/迷茫 |

画像结论中可适当融入工作氛围背景，例如"在技术氛围下表现出强执行导向"，但不得因工作背景而扭曲性格推断主方向。

---

## Phase 4 — 模拟 32 题作答

**两步生成策略：**

1. **主导版**：纯粹基于画像推理每道题答案，确保整体人格趋势与画像高度一致
2. **扰动版**：对约 **15%** 的题目施加 `±1` 微调（在 `[1,3]` 区间裁剪），使用 `seed = hash(用户身份 + 当天日期)` 保证可复现性

**答案数组格式（固定 32 位）：**

```json
[1,2,3,1,2,3, ... 共32个数字]
```

| 位置 | 对应题目 | 取值 |
|------|---------|------|
| `[0]~[29]` | `q1~q30` | `1 / 2 / 3` |
| `[30]` | `drink_gate_q1` | `1`=吃喝拉撒 `2`=艺术爱好 `3`=饮酒（触发分支） |
| `[31]` | `drink_gate_q2` | `drink_gate_q1==3` 时取 `1` 或 `2`；否则填 `1` 占位 |

---

## Phase 5 — 人格计算

**转换 answers_dict：**

- `q1..q30` 取数组前 30 位
- `drink_gate_q1` 取第 31 位
- 仅当 `drink_gate_q1 == 3` 时，加入 `drink_gate_q2 = answers_array[31]`

**调用计算脚本：**

```bash
python3 scripts/compute_sbti_result.py --answers '<answers_dict JSON>'
```

**解析输出字段：**

| 字段 | 含义 |
|------|------|
| `final.code` | 人格 code |
| `final.cn` | 人格中文名 |
| `final.intro` | 简介（必须原文直出） |
| `final.desc` | 详细描述（必须原文直出） |
| `final.image.relative_path` | 海报图相对路径 |

---

## Phase 6 — 输出报告与结果海报

按以下结构输出，保持可读性：

1. **人格标题**：`你的结果是：<code> — <中文名>`
2. **你的工作底色**：输出 Phase 2.5 工作氛围标签（主标签 + 副标签）及 2～3 条佐证摘要
3. **言行画像摘要**：3～6 条要点（基于 Phase 3 画像提炼，可融入工作背景）
4. **intro**：逐字输出 `final.intro` 原文，不得改写
5. **desc**：逐字输出 `final.desc` 全部原文，按自然段落换行，不得增删
6. **结果海报**：

```markdown
![结果海报](assets/images/<图片文件名>)
```

> 海报图片必须发出来，可尝试多种方式，最终确保图片正确展示。

## 意图映射

| 用户说 | 对应操作 |
|--------|---------|
| "帮我测一下 SBTI" / "我想知道我的人格类型" | 完整执行 Phase 1~6 |
| "我的聊天记录能看出什么性格" | 执行 Phase 2~3，只输出画像，不做答题计算 |
| "重新测一次" / "再来一次" | 重新执行全流程（扰动 seed 含日期，同天结果基本稳定） |
| "我想看海报" / "图片没出来" | 仅重新执行 Phase 6，用已有 `final.image.relative_path` 重新渲染 |
| "我的工作氛围是什么" / "看看我是哪个方向的" | 执行 Phase 2~2.5，只输出工作氛围分析，不做性格测试 |

## 易混淆场景

| 场景 | 正确处理 |
|------|---------|
| 有效消息不足 50 条（消息已耗尽） | 拉取至 `hasMore=false` 后停止，基于现有样本继续分析，在报告中注明"样本共 N 条，结果仅供参考" |
| 有效消息不足 50 条（仍有更多页） | 继续翻页，直到满足 50 条或 `hasMore=false` |
| `drink_gate_q1` 模拟为 3 但未继续模拟 `drink_gate_q2` | 必须继续模拟第 32 题，取值只能为 `1` 或 `2` |
| 脚本输出 `final.intro` 为 null | 说明该人格 code 在题库中无对应文案，直接输出 code 和中文名即可，跳过 intro/desc |
| 工作氛围无法判断（消息太少或内容太泛） | 输出"工作底色：信息不足，暂无法判断"，不影响性格分析继续进行 |

## 错误处理

| 错误类型 | 处理方式 |
|---------|---------|
| `dws chat message list-all` 返回空列表 | 提示用户"消息记录为空，无法完成分析"，终止流程 |
| 循环翻页超过 20 页仍未满足 50 条 | 以当前已拉取内容继续分析，在报告中注明样本数量 |
| `compute_sbti_result.py` 执行报错 | 检查 answers_dict 格式，确认所有 q1~q30 均有值，重试一次 |
| 海报图片文件不存在 | 输出文字报告，说明"海报图暂时无法显示"，不阻断文字结果 |
| 匹配度 < 60%（触发 HHHH 兜底） | 正常输出 HHHH 人格结果，无需额外说明 |
