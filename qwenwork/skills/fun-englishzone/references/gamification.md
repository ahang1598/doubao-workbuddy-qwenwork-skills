# 游戏化机制参考资料

## 核心游戏化元素

### 1. 积分系统

#### 积分类型
| 类型 | 分值 | 获得条件 | 设计目的 |
|------|------|----------|----------|
| 学习积分 | 5分 | 学习一个新单词 | 鼓励日常学习 |
| 练习积分 | 10分 | 完成一套练习 | 奖励主动练习 |
| 挑战积分 | 20分 | 完成每日挑战 | 维持学习动力 |
| 连胜积分 | 基础分×1.5 | 连续学习3天以上 | 培养学习习惯 |
| 成就积分 | 50-200分 | 解锁成就 | 鼓励探索精神 |
| 帮助积分 | 3分 | 使用提示后正确 | 鼓励自主学习 |

#### 积分计算示例
```
基础场景：
- 学习10个新单词：10 × 5 = 50分
- 完成1套练习：10分
- 总计：60分

进阶场景：
- 连续学习第5天：基础分 × 1.5
- 完成3套练习：30 × 1.5 = 45分
- 解锁成就：额外100分
- 总计：145分
```

### 5. 挑战模式

#### 每日挑战
- **单词挑战**：每天学习/复习指定数量单词
- **语法挑战**：完成指定数量的语法题
- **阅读挑战**：阅读一篇短文并答题
- **听力挑战**：完成一段听力练习

#### 限时挑战
- **闪电战**：1分钟内尽可能多答题
- **速记王**：限时记忆单词
- **翻译大赛**：限时翻译句子

#### Boss战
- **综合测验**：涵盖多项技能的复杂测验
- **写作挑战**：限时完成一篇作文
- **口语挑战**：完成一段口语表达

### 6. 反馈系统

#### 即时反馈

**正确反馈**
- ✅ 绿色对勾
- 🎉 庆祝动画
- 📈 积分增加
- 💬 鼓励语句
  - "Great job!"
  - "Excellent!"
  - "Well done!"
  - "You're amazing!"

**错误反馈**
- ❌ 红色提示
- 💡 显示正确答案
- 📚 相关知识点链接
- 💬 鼓励语句
  - "Keep trying!"
  - "Almost there!"
  - "You can do it!"
  - "Practice makes perfect!"

### 7. 社交元素

#### 排行榜
- **全球排行**：所有学习者排名
- **好友排行**：好友间排名
- **周排行**：本周积分排名
- **主题排行**：特定主题排名

#### 学习小组
- 创建或加入学习小组
- 小组内互相监督
- 小组挑战赛
- 分享学习心得

### 8. 奖励机制

#### 每日奖励
| 连续天数 | 奖励 |
|----------|------|
| 1天 | 10积分 |
| 3天 | 30积分 + 1个提示卡 |
| 7天 | 100积分 + 3个提示卡 |
| 30天 | 500积分 + 专属徽章 |

#### 里程碑奖励
- **词汇量突破**：每500词奖励
- **等级提升**：解锁新功能
- **成就解锁**：专属徽章

### 9. 视觉设计规范

#### 颜色编码
| 颜色 | 含义 | 应用场景 |
|------|------|----------|
| 绿色 | 正确/成功 | 正确答案、完成状态 |
| 红色 | 错误/警告 | 错误答案、重要提示 |
| 蓝色 | 信息/中性 | 普通信息、说明 |
| 黄色 | 提示/注意 | 提示信息、警告 |
| 紫色 | 特殊/成就 | 徽章、特殊成就 |
| 金色 | 高级/奖励 | 高分、稀有成就 |

#### 动画效果
- **正确动画**：缩放 + 闪光（0.5秒）
- **错误动画**：左右震动（0.3秒）
- **得分动画**：数字滚动（1秒）
- **徽章解锁**：放大 + 发光 + 粒子（2秒）
- **升级动画**：全屏庆祝效果（3秒）
