| 前缀 | 含义 | 例词 |
|------|------|------|
| un- | 不、非 | unhappy, unable |
| re- | 再、重新 | rewrite, return |
| pre- | 前、预先 | preview, predict |
| dis- | 不、分离 | disagree, disappear |
| mis- | 错误 | mistake, misunderstand |
| over- | 过度 | overwork, overeat |
| under- | 不足 | underestimate, underpay |
| inter- | 之间 | international, internet |
| trans- | 跨越 | transport, translate |
| auto- | 自己 | automatic, automobile |

| -ness | 状态、性质 | happiness, kindness |
| -ity | 性质、状态 | ability, reality |

## 记忆技巧

### 1. 联想记忆法
- 将新词与已知词或图像联系起来
- 例：ambulance (救护车) → "俺不能死"

### 2. 词根词缀法
- 分析单词结构，理解含义
- 例：un + happy = unhappy (不快乐)

### 3. 情境记忆法
- 将单词放入句子或场景中记忆
- 例：在餐厅场景中学习点餐词汇

### 4. 间隔重复法
- 使用艾宾浩斯遗忘曲线进行复习
- 复习间隔：1天、3天、7天、15天、30天

### 5. 卡片记忆法
- 正面写英文，背面写中文和例句
- 利用碎片时间翻看复习
