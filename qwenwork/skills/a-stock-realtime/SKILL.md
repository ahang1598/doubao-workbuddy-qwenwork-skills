# A股实时行情与分时量能分析

通过新浪财经免费接口获取沪深A股实时数据，支持实时行情查询、分时量能分析、主力信号识别和持仓盈亏管理。

## 禁止事项

- 禁止在非交易时段声称获取的是"实时"数据——非交易时段返回的是最近收盘数据，必须告知用户
- 禁止对主力信号做投资建议——仅呈现量能分布数据和异常信号，不推荐买卖操作
- 禁止未经用户明确指令修改持仓数据——仅在用户说"添加/更新/删除"时才变更持仓
- 禁止捏造股票代码——不确定代码时要求用户确认6位数字
- 禁止将本技能用于港股、美股、基金、期货等非A股品种

## 强制要求

- 执行脚本前必须确认股票代码为6位数字格式（沪市6开头、深市0/3开头、北交所8/4开头）
- 分时量能分析（`--minute`）仅在交易日有意义，非交易日应提醒用户
- 批量查询时优先使用单次命令传入多个代码（减少请求次数）
- 向用户展示结果时必须包含数据获取时间
- 持仓操作后向用户确认变更结果

## 能力清单

| 能力 | 安全等级 | 说明 |
|------|---------|------|
| 实时行情查询 | 只读 | 获取股票现价、涨跌幅、成交量等基础数据 |
| 分时量能分析 | 只读 | 分析当日分钟级成交分布，识别早盘/尾盘放量 |
| 主力信号识别 | 只读 | 根据量能分布判断抢筹/出货/封板等信号 |
| 持仓添加 | 写入 | 向持仓文件添加新的股票持仓记录 |
| 持仓更新 | 写入 | 修改已有持仓的成本价或数量 |
| 持仓删除 | 写入 | 从持仓文件中移除股票记录 |
| 持仓盈亏分析 | 只读 | 获取所有持仓实时行情并计算盈亏比例 |

## Phase 1 — 实时行情查询

查询一只或多只A股的实时行情数据。

**执行命令：**

```bash
# 单只股票
uv run {baseDir}/scripts/analyze.py 600789

# 多只股票（批量）
uv run {baseDir}/scripts/analyze.py 600789 002446 002342

# JSON格式输出（便于后续处理）
uv run {baseDir}/scripts/analyze.py 600789 --json
```

**输出字段：** 股票名称、现价、今开、昨收、最高、最低、涨跌幅、成交量（万手）、成交额（亿元）。

**股票代码格式：** 直接使用6位数字，系统自动识别市场：

- 沪市：6开头（如 600789）
- 深市：0或3开头（如 002446、300001）
- 北交所：8或4开头

## Phase 2 — 分时量能分析

在实时行情基础上，加载当日分钟K线数据，分析成交量分布和主力信号。

**执行命令：**

```bash
uv run {baseDir}/scripts/analyze.py 600789 --minute
```

**成交分布时段：**

| 时段 | 时间范围 | 信号含义 |
|------|---------|---------|
| 早盘30分 | 9:30-10:00 | 占比 >30% 为主力抢筹，>40% 为强势介入 |
| 上午中段 | 10:00-11:30 | 正常交易期 |
| 下午中段 | 13:00-14:30 | 正常交易期 |
| 尾盘30分 | 14:30-15:00 | 占比 >15% 为尾盘放量，>25% 为异动信号 |

**放量时段 TOP 10：** 当日成交量最大的10个分钟，用于识别主力建仓/出货时机、重大消息时点、涨停封板/开板时刻。

## Phase 3 — 持仓管理

管理本地持仓记录。持仓数据存储在 `~/.clawdbot/skills/a-stock-analysis/portfolio.json`。

**操作命令：**

```bash
# 查看所有持仓
uv run {baseDir}/scripts/portfolio.py show

# 添加持仓（需指定成本价和数量）
uv run {baseDir}/scripts/portfolio.py add 600789 --cost 10.416 --qty 3400

# 更新成本价或数量
uv run {baseDir}/scripts/portfolio.py update 600789 --cost 10.2

# 删除持仓
uv run {baseDir}/scripts/portfolio.py remove 600789
```

## Phase 4 — 持仓盈亏分析

对所有持仓股票执行实时行情 + 分时量能分析，计算每只股票及整体盈亏。

**执行命令：**

```bash
uv run {baseDir}/scripts/portfolio.py analyze
```

**输出包含：** 每只持仓的实时行情、分时量能信号、成本市值、当前市值、盈亏金额和比例，以及全部持仓汇总。

## 使用示例

### 示例 1：快速查看行情

**用户说**："600789 现在什么价？"

**执行**：`uv run {baseDir}/scripts/analyze.py 600789`

**回复要点**：展示现价、涨跌幅、成交量，注明数据时间

### 示例 2：分时量能分析

**用户说**："帮我看看鲁抗医药今天主力有没有动作"

**执行**：确认代码为 600789 → `uv run {baseDir}/scripts/analyze.py 600789 --minute`

**回复要点**：展示成交分布比例、异常信号（如"早盘主力抢筹明显"）、放量时段 TOP 10

### 示例 3：持仓盈亏总览

**用户说**："看看我持仓现在整体盈亏"

**执行**：`uv run {baseDir}/scripts/portfolio.py analyze`

**回复要点**：逐只展示行情 + 盈亏，最后汇总总成本、总市值、总盈亏比例

### 示例 4：批量对比

**用户说**："帮我同时看下 600789、002446、300001 的行情"

**执行**：`uv run {baseDir}/scripts/analyze.py 600789 002446 300001`

**回复要点**：依次展示每只股票行情，可做简单对比总结

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 股票代码无效（非6位数字） | 提示用户提供正确的6位数字代码 |
| 接口超时或返回空数据 | 告知用户网络异常，建议稍后重试 |
| 非交易时段查询分时数据 | 告知获取的是最近交易日数据，非实时 |
| 持仓文件不存在 | 自动创建空持仓文件，提示用户先添加持仓 |
| 持仓中已存在相同代码 | 提示使用 update 命令更新，不重复添加 |
| 用户提供股票名称而非代码 | 要求用户确认6位数字代码（本技能不支持名称搜索） |
| uv 命令不可用 | 改用 `python3 {baseDir}/scripts/analyze.py` 执行（脚本无外部依赖） |

## 数据源

统一使用新浪财经接口（免费、无需 token）：

| 数据 | 接口 | 延迟 |
|------|------|------|
| 实时行情 | `hq.sinajs.cn` | ~3秒 |
| 分时K线 | `CN_MarketDataService.getKLineData` | ~1分钟 |

## 限制

- 仅支持A股（沪深北交所）
- 交易时段外获取的是收盘数据
- 分时数据最多250条（约1个交易日）
- 不支持股票名称搜索，需提供6位数字代码
- 不提供投资建议，仅呈现数据和信号
