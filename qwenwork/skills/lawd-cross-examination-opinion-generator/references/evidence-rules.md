# 民事质证相关证据规则

## 版本信息

- 核验日期：2026-08-04
- 适用范围：中华人民共和国境内民商事诉讼的一般证据分析
- 本文件用途：帮助定位规则，不替代个案法律检索

援引前应再次确认案件时点、案件类型、审级、地域特殊规则及法规现行状态。不得仅凭本摘要拼接法条原文。

## 一、《民事诉讼法》基础规则

| 条号 | 与质证相关的要点 |
|---|---|
| 第六十六条 | 规定当事人陈述、书证、物证、视听资料、电子数据、证人证言、鉴定意见、勘验笔录等证据种类；证据须经查证属实才能作为认定事实的根据。 |
| 第六十七条 | 当事人对自己提出的主张负有举证责任；特定情况下由人民法院调查收集。 |
| 第六十八条 | 当事人应及时提供证据；举证期限、延期及逾期举证后果由该条规定。个案期限必须以法院通知和案件程序核验。 |
| 第七十一条 | 证据应在法庭上出示并由当事人互相质证；涉及国家秘密、商业秘密和个人隐私的证据适用保密及非公开出示要求。 |
| 第七十二条 | 经法定程序公证证明的法律事实和文书原则上作为认定事实的根据，但存在足以推翻的相反证据时除外。 |
| 第七十三条 | 书证原则上提交原件、物证原则上提交原物；确有困难时可提交相应替代材料，外文书证应附中文译本。 |

提示：不要继续使用旧版本中“证据种类为第六十三条”“举证责任为第六十四条”等旧条号。

## 二、《民事诉讼证据规定》常用规则

### 原件、原物和电子数据

| 条号 | 要点 |
|---|---|
| 第十一条 | 提供证据原则上应提交原件或原物；确有困难时可提交经法院核对无异的复制件或复制品。 |
| 第十五条 | 视听资料应提供原始载体；电子数据应提供原件。与原件一致的副本或直接来源于电子数据、可显示识别的输出介质，可按该条视为电子数据原件。 |
| 第六十一条 | 质证书证、物证、视听资料时原则上出示原件或原物；存在该条规定的困难或灭失并能证明一致等情形时存在例外。 |

因此，“只有复印件/截图”应先分析能否核对、来源和其他印证，不能机械得出“一律无效”。

### 质证程序

| 条号 | 要点 |
|---|---|
| 第六十条 | 审理前准备、调查或询问过程中已经发表质证意见的证据，可视为已经质证；书面质证意见是否准许由法院依规则处理。 |
| 第六十二条 | 规定不同提交主体出示证据时的一般质证顺序，以及法院调查收集证据时的质证或听取意见方式。 |
| 第六十八条 | 证人原则上应出庭并接受询问；无正当理由未出庭的证人以书面等方式提供的证言，适用该条规定的后果。 |
| 第八十一条 | 鉴定人拒不出庭作证时，鉴定意见的使用及相关处理适用该条。 |

### 审核认定与证明力

| 条号 | 要点 |
|---|---|
| 第八十五条 | 法院以证据能够证明的案件事实为根据裁判，并依法全面、客观审核证据、判断证明力。 |
| 第八十七条 | 单一证据可从原件或原物、与案件事实的相关性、形式和来源、内容真实性、提供者利害关系等方面审核。 |
| 第八十八条 | 全部证据应结合各证据与案件事实的关联程度及证据之间联系综合判断。 |
| 第八十九条 | 当事人在诉讼中认可证据的法律效果及反悔处理适用该条及所引用规则。 |
| 第九十条 | 当事人陈述、特定证人证言、存疑视听资料或电子数据、无法核对的复制件或复制品等，在该条列明情形下不能单独作为认定案件事实的根据。 |
| 第九十二条 | 私文书证真实性的举证、签名盖章捺印推定及涂改等瑕疵的证明力判断适用该条。 |

“不能单独作为认定依据”不等于“绝对不得采纳”，应结合其他证据和全案情况表述。

### 电子数据

| 条号 | 要点 |
|---|---|
| 第九十三条 | 电子数据真实性应综合考察系统环境、运行状态、防错机制、保存传输提取的完整可靠性、正常业务形成情况、相关主体等因素。 |
| 第九十四条 | 特定来源和保管情形下，法院可以确认电子数据真实性，但存在足以反驳的相反证据时除外；公证电子数据也存在该条规定的反证空间。 |
| 第九十五条 | 一方控制证据并无正当理由拒不提交时，法院可在符合该条条件下作出不利认定。 |

不要把区块链存证、公证、第三方平台记录表述为“绝对真实”或“当然采信”；仍须核对适用条件和反证。

## 三、引用纪律

1. 使用法规全称、现行条号和与个案直接相关的规则；
2. 优先链接官方全文，不引用搜索摘要或非官方转载作为唯一依据；
3. 不大段复制法条，用准确摘要说明其与具体证据的关系；
4. 旧裁判或旧模板中的条号应回到现行文本复核；
5. 对域外证据、电子数据、鉴定、举证期限等易变或案件依赖问题进行专项检索；
6. 无法核验时标记“法律依据待核验”，不得猜测。
