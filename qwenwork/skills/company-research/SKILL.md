# 公司调研

面向指定公司进行**全维度、多来源**的系统性调研，覆盖基本面、业务产品、竞争格局、经营财务、风险动态等关键维度，最终输出一份可直接交付的钉钉在线文档公司调研报告。

---

## 禁止事项

- 禁止以对话文本替代钉钉在线文档作为最终交付物
- 禁止编造事实、链接或来源；所有数据必须有明确出处
- 禁止使用过期数据（旧数据需标注年份）
- 禁止做无依据的主观判断；推测性内容必须明确标注
- 禁止多来源数据冲突时不作说明（必须注明差异原因）
- 禁止财务数据缺少来源和对应年份/季度

## 强制要求

- 本技能触发即代表用户期望生成**钉钉在线文档**，主 Agent 无需询问确认
- 内部知识库查询必须在外部检索之前或同步进行，确保内部视角不遗漏
- 数据收集完成后，直接调用 `dws doc create --name --markdown` 创建钉钉在线文档
- 每个数据步骤完成后立即写入草稿：`/home/workspace/draft_company-research_{YYYYMMDD_HHMMSS}.md`
- 多来源数据冲突时，优先采信公司官方披露，其次权威第三方，并在报告中注明差异

## 能力清单

| 工具 | 用途 | 说明 |
|------|------|------|
| `WebSearch` | 公司新闻、财报数据、行业排名、融资动态 | 多角度覆盖，时效优先 |
| `WebFetch` | 公司官网、招股书、年报、深度报道全文 | 全文返回后 Agent 自行提取 |
| `dws doc search --keyword` | 检索内部已有公司研究、分析报告 | 补充内部视角 |
| `dws doc read --node` | 读取具体文档内容 | 深度提取 |
| `knowledge` | 内部对目标公司的分析、合作记录、竞品档案 | 内部视角不可遗漏 |
| `dws doc create --name --markdown` | 创建钉钉在线文档 | 最终交付 |
| `write_file` | 写入草稿文件（append 模式） | 每步完成后执行 |

## 触发方式

- "公司调研" / "公司画像" / "公司研究"
- "帮我研究XX公司" / "帮我调研一下XX公司"
- "做一份XX公司的调研报告"
- "XX公司怎么样？帮我全面分析一下"

## 输入

**必选：** 公司名称（含别名、英文名、股票代码等常见标识）

**可选：**
- 时间范围（默认：近 1-3 年数据，最新动态优先）
- 关注维度（默认全维度；可指定：基本面/业务/竞争/财务/风险）
- 对标公司（指定用于竞争对比的公司）
- 地理范围（全球/中国/特定区域）
- 研究深度（概览/标准/深度，默认标准）

## Phase 2 — 信息收集

### A1. 公司基本面

**WebSearch 查询：**
```
"{公司} 成立时间 总部 创始人 融资历程"
"{公司} 公司简介 企业概况 百科"
"{公司} 上市 股价 市值 股票代码"
"{公司} CEO 管理团队 核心高管"
```

**WebFetch 深度获取：**
```
WebFetch(url: "{公司官网}/about")
→ Agent 提取：公司简介、成立时间、总部地址、企业使命愿景、核心团队
WebFetch(url: "{招股书/年报链接}")
→ Agent 提取：发展历程、股权结构、主要股东、融资历程
```

**写入草稿：**
```markdown
## 一、公司概况

### 基本信息
| 维度 | 内容 |
|------|------|
| 公司全称 | {全称}（来源） |
| 成立时间 | {YYYY年MM月}（来源） |
| 总部地址 | {城市}（来源） |
| 创始人/CEO | {姓名}（来源） |
| 员工规模 | {约N人}（来源，截至YYYY年） |
| 上市情况 | {交易所/股票代码/上市时间} 或 未上市 |
| 最新估值/市值 | {金额}（来源，截至YYYY-MM-DD） |
| 主营业务 | {一句话描述} |

### 发展历程（时间倒序）
1. **YYYY年**：{里程碑事件}（来源）

| 时间 | 轮次 | 金额 | 投资方 | 投后估值 | 来源 |
|------|------|------|---------|---------|------|
```

## 意图映射

| 用户说 | 实际意图 | 处理方式 |
|--------|---------|---------|
| "帮我调研一下XX公司" | 标准全维度调研 | 触发全流程 |
| "帮我快速了解一下XX" | 概览模式 | 仅执行 A1+A2+A5，输出概览版 |
| "XX公司的财务情况怎么样" | 仅财务维度 | 仅执行 A4，输出财务分析 |
| "XX公司和YY公司哪个更好" | 对比调研 | 分别执行全流程，最后做横向对比 |

## 易混淆场景

| 场景 | 判断依据 | 处理方式 |
|------|---------|---------|
| 公司名称有歧义（如"字节"） | 名称不唯一 | 先确认完整公司名称和主体 |
| 非上市公司财务数据缺失 | 无公开财报 | 标注"财务数据非公开"，用融资信息和行业估算替代 |
| 用户给了内部文档 | 有附件 | 优先读取内部文档，外部调研作补充 |
| 目标公司是竞品 | 用户提到"我们的竞品" | 补充执行 A6 内部资料，获取内部竞品档案 |

---

## 错误处理

| 错误 | 原因 | 修复方法 |
|------|------|---------|
| 财务数据缺失 | 非上市公司无公开财报 | 用融资信息、行业估算替代，明确标注数据来源和可信度 |
| 多来源数据冲突 | 不同来源口径不同 | 优先采信官方披露，在报告中注明差异原因 |
| 公司信息过时 | WebSearch 返回旧内容 | 在查询中加入年份关键词，优先选用最新来源 |
| 内部资料为空 | knowledge 无相关记录 | 标注"内部暂无相关记录"，不影响外部调研结果 |
| 竞争格局信息不全 | 行业信息分散 | 补充行业研究报告，用 WebFetch 深读权威来源 |
