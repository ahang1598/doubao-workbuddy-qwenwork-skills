# 门店运营海报Skill

:::
**适用对象及目标：**帮助没有设计能力的门店商家，快速生成一个接近可用的海报图片

**实现效果：**拍摄主体 →  识图生成文案（AI）→ 直接生成海报  → 线上分享 / 或使用 AI印 打印并邮寄
:::

### 用户痛点

大部分门店商家：

**能力上：不具备**

并不具备设计的相关能力，也不具备相关的运营思路和想法

成本上：**较高**

自行设计需要单独投入专门的“人”

外包，又需要额外支付成本

效率上：**低下**

想要跟进所有的节日、活动，需要投入大量的人力，而门店经营本身就已经让人疲惫不堪，实在没有额外的精力去处理

### 生成海报提示词句式模板：

将画面拆解为以下六个模块进行描述：

*   画面结构与主视觉（定基调）
    
*   背景细节（定质感）
    
*   主体形象（上/中/下 分区叙事）
    
*   动势与层次（引导视线）
    
*   文字排版（留白策略）
    
*   风格总结（最终渲染）
    

### 用户需要输入的内容

1.  主题和使用场景
    
2.  标题
    
3.  副标题 / 描述文案 / 辅助文字（可选）
    
4.  主体形象（可上传图片或文字描述）
    
5.  风格描述（如极简干净、热烈欢快、自然清新、商务科技、尊贵臻选、3D酷炫等）

## 核心功能与交互流程

### 用户使用链路

1.  用户上传商品照片 (手机拍摄)
    
2.  AI自动抠图提取商品主体，并适当P图（饱和度、对比度、亮度调整）
    
3.  AI分析商品类型并智能匹配营销文案
    
4.  用户确认和修改文案、海报风格 (现代简约/优雅精致/活力缤纷/极简留白等)
    
5.  调用Nano Banana Pro 模型 / 盒马MCP结合商品主体、文案、风格生成高质量海报
    
6.  用户可以调整海报细节 (位置、大小、颜色等)
    
7.  满意后下载海报或联动钉钉AI印下单打印

### 流程说明

1.  图片上传阶段 用户通过手机拍摄或从相册选择商品照片 系统进行照片质量检查，确保清晰度符合要求
    
2.  AI处理阶段 AI抠图：自动识别并抠出商品主体，去除背景 商品分析：识别商品类型、特征和适用场景 文案匹配：根据商品属性自动生成营销文案
    
3.  用户确认阶段 用户可以查看并修改AI生成的文案 选择喜欢的海报风格（简约、时尚、促销风等） 确认所有参数后进入生成环节
    
4.  海报生成阶段 调用 Nano Banana Pro 模型 结合主流新潮样式和模版 融合商品主体、文案和风格生成高质量海报
    
5.  调整与输出阶段 用户可调整海报细节（颜色、布局、文字位置等） 满意后可选择： 下载保存：将海报保存到本地相册 钉钉AI印：直接下单打印实体海报
    

技术要点     抠图算法：高精度AI图像分割     文案生成：基于商品类型的智能文案推荐     海报生成：Nano Banana Pro 模型 + 潮流模版库     打印集成：钉钉AI印 API 对接
