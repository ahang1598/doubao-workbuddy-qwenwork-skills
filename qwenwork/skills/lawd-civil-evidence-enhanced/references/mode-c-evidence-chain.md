# 模式C ｜ 证据链构建与举证要点映射：详细工作流

> ⛔ 本文件是 SKILL.md 第 3.3 节模式C「证据链构建与举证要点映射」的详细工作流细则（适用场景、输入参数、五层证明链条、缺口识别、论证节点预检、六步操作模板、硬性要求），自 SKILL.md 原样外移。执行模式C 前必须完整读取本文件，并严格按其流程执行。
>
> 文中「第四节（法规检索）」等节号均指 SKILL.md 中的章节。

#### 适用场景

当需要把一堆零散证据有序组织起来，回答以下问题时使用：
- 我的哪些主张有足够证据支撑？
- 哪些主张还缺证据？缺什么？
- 每个证据的证明力如何？
- 如果对方攻击某个证据，我的主张会不会倒？

#### 输入参数

1. **案件基本信息**：案由、管辖法院、诉讼阶段
2. **主张清单**：列出希望证明的全部法律主张（按优先级排序）
3. **证据清单**：列出已掌握的全部证据（编号、名称、来源、形成时间）
4. **证据类型**：书证 / 物证 / 电子数据 / 证人证言 / 鉴定意见 / 当事人陈述
5. **对方可能持有的证据**（如有预判）

#### 核心方法论：五层证明链条

从法律主张到具体证据，建立逐层对应的五层结构：

```
第一层：法律主张（你要证明什么？）
    ↓
第二层：法律要件（法律规定需要满足哪些条件？）
    ↓
第三层：案件事实（哪些事实能对应这些要件？）
    ↓
第四层：证据材料（哪些证据能证明这些事实？）
    ↓
第五层：证明力评估（每个证据能证明到什么程度？）
```

#### 五层映射表

对每个主张，逐一填写以下映射表：

| 层级 | 内容 | 说明 |
|---|---|---|
| 主张 | [具体法律主张] | 如"被告违约，应承担违约责任" |
| 对应要件 | [法条规定的构成要件] | 如"存在有效合同 + 被告未履行 + 无免责事由" |
| 对应事实 | [能证明要件满足的事实] | 如"双方签署了书面合同 + 被告逾期未付款" |
| 支撑证据 | [证明事实的证据编号] | 如"证据1《买卖合同》 + 证据3 催款函" |
| 证明力 | 强 / 中 / 弱 | 评估该证据对事实的证明力度 |

#### 证据缺口识别

完成映射后，逐行检查以下情况并标记：

| 缺口类型 | 表现 | 风险等级 |
|---|---|---|
| 要件缺失 | 某个法律要件找不到对应事实 | 🔴 致命 |
| 事实无证据 | 有事实陈述但无证据支撑 | 🔴 致命 |
| 证据链断裂 | 证据只能证明部分事实，关键事实无证据 | 🟡 严重 |
| 证明力不足 | 有证据但证明力弱（如单一证人证言） | 🟡 严重 |
| 证据瑕疵 | 证据真实性/合法性/关联性可能被质疑 | 🟠 中等 |
| 冗余证据 | 多个证据证明同一事实，可以精简 | ⚪ 轻微 |

#### 论证节点预检（缺口关联评估）

当识别到证据缺口时，需要预判该缺口是否构成论证的致命弱点：

**预检步骤：**

1. **缺口性质判断**：该缺口对应的是核心要件还是辅助要件？
   - 核心要件缺口 → 主张可能完全不成立
   - 辅助要件缺口 → 主张可能成立但证明力打折

2. **可补救性评估**：能否通过补充取证来弥补？
   - 可补救（如可调取银行流水、申请证人出庭）→ 列入补证计划
   - 不可补救（如关键书证已灭失、关键证人无法联系）→ 需要调整主张策略

3. **替代路径搜索**：是否可以通过其他证据或间接事实来间接证明？
   - 有替代路径 → 降低缺口等级，标记替代方案
   - 无替代路径 → 维持原缺口等级，准备应对对方攻击

#### 操作模板（六步）

**Step 1：主张拆解**

将每个法律主张拆解为具体的法律要件。例如：
- 主张"被告违约" → 要件：①合同有效 ②被告有履行义务 ③被告未履行
- 主张"赔偿损失" → 要件：①存在损失 ②损失与被告行为有因果关系 ③损失金额可计算

要件拆解须以法条为依据，法条来源见第四节（法规检索）。

**Step 2：事实匹配**

为每个要件匹配对应的案件事实。事实应具体、可验证：
- "双方于 2024年3月15日签署了编号为 HT-2024-0089 的《设备采购合同》"
- "合同约定被告应于 2024年6月30日前支付货款 50 万元"
- "截至起诉日，被告仅支付 10 万元，尚欠 40 万元"

**Step 3：证据挂靠**

为每个事实找到支撑证据，填入映射表：
- 事实"双方签署了合同" → 证据1《设备采购合同》原件（证明力：强）
- 事实"被告已付 10 万元" → 证据2 银行入账记录（证明力：强）
- 事实"被告催款后仍未付" → 证据3 催款函及送达回证（证明力：中）

**Step 4：证明力评估**

对每个证据的证明力进行评估，考虑以下因素：

| 评估维度 | 强 | 中 | 弱 |
|---|---|---|---|
| 证据来源 | 公文书证/鉴定意见 | 第三方书证 | 当事人自述 |
| 证据形式 | 原件 | 复印件 | 照片/截图 |
| 关联性 | 直接证明关键事实 | 间接证明 | 仅能佐证 |
| 完整性 | 证据链完整 | 部分缺失 | 孤证 |
| 可反驳性 | 难以反驳 | 可能被质疑 | 容易推翻 |

**Step 5：缺口标注**

对每个识别到的缺口，标注类型、风险等级和补救建议，并完成论证节点预检。

**Step 6：全链条审视**

从整体视角审视证据链：
- 哪些主张的证明链条完整？
- 哪些主张链条断裂？
- 是否存在"一个证据支撑多个主张"的情况（风险集中）？
- 如果对方反驳最弱的那个证据，哪个主张会倒塌？

#### 硬性要求

- **不得有悬空主张**：主张清单中的每一项都必须出现在映射表中并有对应证据或明确标注为缺口，不允许只列主张不做映射。
- **证据编号连续无重复**。
