# 民事诉讼举证责任分配规则

本文档系统阐述民事诉讼中举证责任的基本原则、特殊分配规则、证明标准，是证明责任分析专章的方法依据。

---

## 一、举证责任的基本原则

### 1.1 谁主张谁举证

**法律依据**：《民事诉讼法》（2023年修正）第67条第1款
> "当事人对自己提出的主张，有责任提供证据。"

**法律依据**：《最高人民法院关于民事诉讼证据的若干规定》（法释〔2019〕19号，以下简称《证据规定》）第90条

**核心要义**：
- 主张权利的一方，对权利发生事实承担举证责任
- 主张权利妨碍、消灭、阻碍的一方，对相应事实承担举证责任
- 主张事实的一方，对该事实承担举证责任

### 1.2 当事人无法举证时由法院调取

**法律依据**：《民事诉讼法》第67条第2款
> "当事人及其诉讼代理人因客观原因不能自行收集的证据，或者人民法院认为审理案件需要的证据，人民法院应当调查收集。"

**法律依据**：《证据规定》第20条

### 1.3 举证责任的实质内涵

举证责任包含两个层面：
- **行为意义上的举证责任**（提出证据的责任）：当事人为支持自己的主张应当向法庭提供证据
- **结果意义上的举证责任**（说服责任）：在事实真伪不明时由谁承担不利后果

## 二、举证责任分配的一般规则

### 2.1 法律要件分类说

按照法律要件性质分配举证责任：

| 要件类型 | 举证责任方 | 典型情形 |
|---------|----------|---------|
| 权利发生要件 | 主张权利的一方 | 主张合同权利，应证明合同成立、生效、对方义务 |
| 权利妨碍要件 | 主张妨碍的一方 | 主张合同无效，应证明无效事由 |
| 权利消灭要件 | 主张消灭的一方 | 主张已履行，应证明履行事实 |
| 权利阻碍要件 | 主张阻碍的一方 | 主张时效届满，应证明时效起算与届满 |

### 2.2 不同诉讼请求的举证责任分配

#### A. 合同纠纷类

| 待证事实 | 举证责任方 | 法律依据 |
|---------|----------|---------|
| 合同成立 | 主张合同存在的一方 | 《证据规定》第90条 |
| 合同生效 | 主张合同有效的一方 | 《民法典》第143条 |
| 合同无效/可撤销 | 主张无效/撤销的一方 | 《民法典》第153-157条 |
| 合同条款内容 | 主张特定条款内容的一方 | 《证据规定》第90条 |
| 标的物已交付 | 主张已交付的一方 | 《民法典》第595条 |
| 付款事实 | 主张已付款的一方 | 《证据规定》第90条 |
| 标的物质量不符 | 主张质量瑕疵的一方 | 《民法典》第615-617条 |
| 履行期限届满 | 主张请求权的一方 | 《证据规定》第90条 |
| 已合法行使撤销权 | 主张已撤销的一方 | 《民法典》第152条 |
| 合同解除 | 主张已解除的一方 | 《民法典》第565条 |

#### B. 侵权纠纷类

| 待证事实 | 举证责任方 |
|---------|----------|
| 侵权行为 | 受害人 |
| 损害结果 | 受害人 |
| 因果关系 | 受害人 |
| 过错（一般侵权） | 受害人 |
| 不存在过错（特殊侵权-过错推定） | 加害人 |
| 不存在因果关系（特殊侵权-举证倒置） | 加害人（如医疗、环境） |
| 损失金额 | 受害人 |

#### C. 借贷纠纷类

| 待证事实 | 举证责任方 |
|---------|----------|
| 借款事实（借款合同关系成立） | 出借人 |
| 款项实际交付 | 出借人（大额现金交付需补强证据） |
| 借款已偿还 | 借款人 |
| 利息约定 | 主张利息的一方 |
| 利息超过法定保护范围 | 借款人 |
| 借款用途违法 | 主张违法用途的一方 |

#### D. 公司纠纷类

| 待证事实 | 举证责任方 |
|---------|----------|
| 股东资格 | 主张股东资格的一方 |
| 出资到位 | 公司/股东（如出资到位） |
| 股东会决议有效 | 主张决议有效的一方 |
| 决议程序违法 | 主张决议无效/撤销的一方 |
| 公司决议损害股东利益 | 受损股东 |

## 三、举证责任倒置

### 3.1 一般规则

举证责任倒置是法律规定，由通常情况下不承担举证责任的一方承担举证责任，以平衡双方信息不对称。

### 3.2 法定举证责任倒置情形

#### A. 高度危险作业致害责任

**法律依据**：《民法典》第1236-1244条
- 高度危险作业人需证明：受害人故意或者不可抗力造成损害
- 受害人仅需证明：损害事实、与高度危险作业之间的关联

#### B. 环境污染、生态破坏责任

**法律依据**：《民法典》第1229-1235条；《证据规定》第90条
- 污染者需证明：法定不承担责任或减轻责任的情形；行为与损害之间不存在因果关系
- 受害人仅需证明：损害事实、污染行为存在、关联可能性

#### C. 产品责任

**法律依据**：《民法典》第1202-1204条
- 生产者需证明：免责事由（如产品投入流通时科技水平不能发现缺陷）
- 受害人需证明：产品存在缺陷、损害事实、缺陷与损害之间的因果关系

#### D. 医疗损害责任

**法律依据**：《民法典》第1218-1228条
- 医疗机构需证明：医疗行为符合诊疗规范；不存在过错
- 患者需证明：医疗关系存在、损害事实

#### E. 饲养动物致害责任

**法律依据**：《民法典》第1245-1251条
- 动物饲养人需证明：受害人故意或重大过失（仅限部分情形）

#### F. 物件致害责任

**法律依据**：《民法典》第1252-1258条
- 物件所有人/管理人需证明：自己没有过错（建筑物、构筑物、堆放物致害等）

#### G. 共同危险行为

**法律依据**：《民法典》第1170条
- 数个加害人需各自证明：自己的行为与损害之间不存在因果关系

#### H. 劳动争议中部分事项

**法律依据**：《最高人民法院关于审理劳动争议案件适用法律若干问题的解释（一）》第44条
- 用人单位需举证：因用人单位作出的开除、除名、辞退、解除劳动合同、减少劳动报酬、计算劳动者工作年限等决定而发生劳动争议的

## 四、举证责任的转移

### 4.1 表见举证（表见证明）

主张事实的一方提供初步证据后，举证责任转移给对方。

**典型情形**：
- 票据持有人持有票据，无需证明取得票据的对价（除非对方提出反证）
- 不动产登记权利人无需证明其权利存在（除非对方提出反证）
- 持有借条主张借款的，无需逐项证明借款交付细节（小额借款）

### 4.2 经验法则与生活常理

法庭依据经验法则推定的事实，主张相反事实的一方承担举证责任。

**典型情形**：
- 当事人长期共同生活，共同财产应当分割（主张不分割的一方需举证）
- 邮件已发送至对方，推定送达（主张未收到的一方需举证）
- 银行流水显示款项已转入，推定已支付（主张未收到的一方需举证）

### 4.3 当事人自认导致的转移

**法律依据**：《证据规定》第3、4、7-9条

| 自认情形 | 法律后果 |
|---------|---------|
| 一方陈述事实，对方明确承认 | 该事实无需举证 |
| 一方陈述事实，对方既不承认也不否认 | 经询问后仍不明确表态的，视为自认 |
| 一方限定情形下的自认（如部分自认） | 仅在该限定范围内免证 |
| 委托代理人自认 | 视为当事人自认，除当事人明确否认 |
| 共同诉讼人中部分自认 | 不必然及于全体（视情况） |

## 五、证明标准

### 5.1 三种证明标准

| 证明标准 | 含义 | 适用情形 |
|---------|------|---------|
| 高度盖然性 | 待证事实存在的可能性明显大于不存在的可能性 | 一般民事诉讼 |
| 排除合理怀疑 | 待证事实存在没有合理的怀疑 | 涉及刑事犯罪事实的认定、欺诈、胁迫、恶意串通、口头遗嘱、赠与等 |
| 较大可能性 | 待证事实存在的可能性较大 | 程序事项 |

**法律依据**：《证据规定》第85-86条、第108-110条

### 5.2 不同证明对象的证明标准

| 证明对象 | 证明标准 | 法律依据 |
|---------|---------|---------|
| 一般民事案件事实 | 高度盖然性 | 《证据规定》第108条 |
| 涉及欺诈、胁迫、恶意串通 | 排除合理怀疑 | 《证据规定》第109条 |
| 涉及口头遗嘱、赠与 | 排除合理怀疑 | 《证据规定》第109条 |
| 程序事项（如管辖、保全） | 较大可能性 | 《证据规定》第110条 |
| 涉及法律行为效力 | 高度盖然性 | 《证据规定》第85条 |
| 一方主张已偿还借款 | 高度盖然性 | 《证据规定》第90条 |

## 六、举证不能的后果

### 6.1 不利后果原则

**法律依据**：《证据规定》第90条
> "当事人对自己提出的诉讼请求所依据的事实或者反驳对方诉讼请求所依据的事实，应当提供证据加以证明，但法律另有规定的除外。在作出判决前，当事人未能提供证据或者证据不足以证明其事实主张的，由负有举证证明责任的当事人承担不利后果。"

### 6.2 具体不利后果

| 情形 | 不利后果 |
|------|---------|
| 原告未尽举证责任 | 驳回诉讼请求 |
| 被告未尽抗辩举证责任 | 抗辩不成立 |
| 未尽部分举证责任 | 该部分主张不能成立 |
| 妨碍举证（如毁损证据） | 推定对方主张成立 |
| 拒绝出示证据 | 推定该证据不利于自己 |

## 七、举证期限

### 7.1 举证期限的确定

**法律依据**：《民事诉讼法》第68条；《证据规定》第50-53条

| 程序类型 | 举证期限 |
|---------|---------|
| 一审普通程序 | 不少于15日 |
| 一审简易程序 | 不超过15日 |
| 二审 | 不少于10日 |
| 当事人协商一致 | 经法院准许 |

### 7.2 逾期举证的后果

**法律依据**：《证据规定》第59条

| 逾期情形 | 法律后果 |
|---------|---------|
| 故意或重大过失逾期 | 不予采纳；除非与基本事实有关 |
| 非因故意或重大过失逾期 | 训诫或罚款；可采纳 |
| 与案件基本事实有关的逾期证据 | 应当采纳，但当事人因举证不能受到损失的，由逾期举证方赔偿 |
| 经对方同意 | 可采纳 |

### 7.3 新证据的特别规则

**法律依据**：《证据规定》第41-43条

新证据包括：
- 一审中提供的新证据：①新发现的证据；②举证期限届满前申请延期举证未获准许的证据
- 二审中提供的新证据：①一审庭审结束后新发现的证据；②一审中申请调取未获准许，二审申请调取的证据；③对一审依职权调取的证据，当事人反驳的新证据
