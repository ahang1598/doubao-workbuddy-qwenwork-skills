# 证据分析材料收集指南

本文档定义启动证据分析前必须收集的材料清单、最低启动条件，以及材料收集的具体要求。

---

## 一、完整材料清单

### A. 基础诉讼文书（必需）

| 文书类型 | 收集要点 | 关注信息 |
|---------|---------|---------|
| 起诉状/仲裁申请书 | 原件或当事人留存件 | 诉讼请求、事实理由、证据清单 |
| 答辩状 | 对方提交的完整版本 | 抗辩理由、反诉请求、对方主张事实 |
| 反诉状（如有） | 完整版本 | 反诉请求、反诉证据 |
| 上诉状（二审/再审） | 完整版本 | 上诉请求与理由 |
| 代理词（如有） | 双方提交的代理意见 | 双方法律观点、援引法条 |

### B. 证据材料（必需）

| 证据类别 | 收集要求 | 注意事项 |
|---------|---------|---------|
| 己方证据清单 | 与卷宗一致的完整清单 | 编号、名称、页码、证明目的 |
| 己方证据材料 | 提供给法院/仲裁庭的版本 | 原件状态、复印件标注 |
| 对方证据清单 | 法院/仲裁庭送达的版本 | 编号、名称、页码、证明目的 |
| 对方证据材料 | 经法院/仲裁庭转交的完整版本 | 是否完整、是否清晰 |
| 法院调取证据 | 法院依职权或申请调取的证据 | 调取主体、调取时间 |
| 第三人提交的证据 | 如有第三人参与诉讼 | 第三人与争议的关联 |

### C. 程序性文书（必需）

| 文书类型 | 关键信息 |
|---------|---------|
| 举证通知书 | 举证期限、举证范围、逾期后果 |
| 开庭传票 | 开庭日期、地点、案件信息 |
| 庭前会议通知书（如有） | 庭前会议安排 |
| 证据交换笔录（如有） | 证据交换日期、双方质证意见 |
| 鉴定/评估通知书（如有） | 鉴定机构、鉴定事项、鉴定期限 |
| 调查令（如有） | 调查范围、对象、有效期 |

### D. 辅助材料（推荐）

| 材料类型 | 用途 |
|---------|------|
| 当事人陈述书 | 补充事实细节 |
| 律师调查笔录 | 自行调查取得的材料 |
| 类案判决书 | 已检索的类案材料 |
| 法律法规打印件 | 已检索的法规材料 |
| 鉴定意见书 | 已委托的鉴定结论 |

## 二、最低启动条件

至少需具备以下材料，否则无法进行有效分析：

### 最低条件（缺一不可）
1. ✅ 起诉状/仲裁申请书（或能说明案件基本事实的材料）
2. ✅ 己方证据清单及材料（至少部分核心证据）
3. ✅ 举证期限信息

**低于此条件**：明确告知用户无法分析并说明原因，请其补充材料后再启动。

### 基础齐备条件（推荐）
在最低条件基础上，再具备：
4. ✅ 答辩状（如已提交）
5. ✅ 对方证据清单及材料（如已交换）
6. ✅ 开庭日期

**达到此条件**：可进行较为完整的证据分析。

### 完整齐备条件（最佳）
在基础齐备条件基础上，再具备：
7. ✅ 程序性文书完整
8. ✅ 双方代理词
9. ✅ 庭前会议笔录（如有）

**达到此条件**：可进行最深入完整的证据分析。

## 三、材料齐备性核对清单

启动分析前，对照以下清单逐项核对：

```
□ 起诉状/仲裁申请书（核对：诉讼请求、事实理由是否清晰？证据清单是否随附？）
□ 答辩状（核对：是否提交？抗辩理由是否明确？反诉是否提出？）
□ 己方证据清单（核对：编号是否连续？是否标注证明目的？）
□ 己方证据材料（核对：原件/复印件状态？页码是否清晰？是否完整？）
□ 对方证据清单（核对：编号是否完整？是否标注证明目的？）
□ 对方证据材料（核对：是否经法院送达？是否完整清晰？）
□ 举证通知书（核对：举证期限？是否已届满？）
□ 开庭传票（核对：开庭日期？剩余天数？）
□ 庭前会议通知书（核对：是否有庭前会议？是否已进行？）
□ 鉴定通知书（核对：是否涉及鉴定？是否已完成？）
□ 法院调取证据（核对：是否有调查令？是否已执行？）
```

## 四、材料缺失时的引导方式

### 缺失基础诉讼文书

```
缺失：答辩状

引导提问：
- 对方是否已提交答辩状？提交时间？
- 对方主要抗辩理由有哪些？请简述。
- 对方是否提出反诉？反诉请求是什么？
```

### 缺失证据材料

```
缺失：对方证据清单及材料

引导提问：
- 双方是否已进行证据交换？时间？
- 对方提交了哪些证据？请提供清单或描述。
- 您是否拿到对方证据的复印件？
```

### 缺失程序性文书

```
缺失：举证通知书

引导提问：
- 举证期限的截止日期是什么时候？
- 是否还有时间补充举证？
- 是否已超过举证期？逾期举证情形如何？
```

## 五、材料处理特殊规则

### 1. 证据原件管理
- 原件应妥善保管，不得遗失
- 电子证据应保留原始载体
- 庭审时按要求出示原件并核对

### 2. 复印件标注
- 复印件应在每份首页标注"与原件核对一致"并由当事人签字
- 双面文件应完整复印两面
- 模糊不清的部分应注明"原件即如此"或申请说明

### 3. 翻译件要求
- 外文证据需附中文翻译件
- 翻译件应由具有资质的翻译机构出具
- 重要外文证据建议公证

### 4. 域外证据
- 在我国领域外形成的证据，应当履行公证认证手续
- 港澳台地区形成的证据，按相关规定办理
- 加入海牙取消认证公约的国家，按公约规定办理

### 5. 涉密证据
- 涉及国家秘密、商业秘密、个人隐私的证据，应申请不公开质证
- 注意《民事诉讼法》第137条相关规定

## 六、材料基本齐备但有缺失时的处理

材料基本齐备但有缺失时：
- 可进行基础分析，但须在报告中明确注明局限性
- 提示用户补充缺失材料后再做最终决策
- 在报告"风险提示"章节中标注因材料缺失导致的分析局限

示例提示语：
```
【报告局限性说明】
本报告基于现有材料分析，因以下材料缺失，相关分析存在局限：
- 对方代理词未提交，无法准确预判对方法律观点
- 庭前会议笔录缺失，无法获知对方质证态度
- 建议补充上述材料后再进行最终决策
```
