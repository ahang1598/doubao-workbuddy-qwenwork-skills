# 中国大陆遗嘱核心规则开发基线

## 1. 法源基准

规则包 `cn-will-core@0.2.0` 于 2026-08-11 按以下官方原文核验：

- 《中华人民共和国民法典》，中华人民共和国主席令第四十五号，2021-01-01 施行：<https://wb.flk.npc.gov.cn/flfg/PDF/bd53dd912c1048f2aecbaa229238334b.pdf>
- 《最高人民法院关于适用〈中华人民共和国民法典〉继承编的解释（一）》，法释〔2020〕23号，2021-01-01 施行：<https://www.court.gov.cn/fabu/xiangqing/282091.html>
- 《中华人民共和国保险法》（2015年修正），第42条：<https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_4c715a53f3d4402c89f62ae77809f638.html>

规则包处于 `development`。法源已经核验，但每条规则仍需一名继承领域律师起草或确认、另一名律师独立复核，完成后才能将状态改为 `approved`。

## 2. 首批可执行规则

| 规则 | 法源 | 确定性检查 | 不由系统自动判断的部分 |
|---|---|---|---|
| 个人合法财产 | 民法典第1122、1133条 | 遗嘱人是否被记录为权属人、份额是否明确 | 实际权属争议、夫妻/家庭共有析分 |
| 能力与真实意思 | 第1143条 | 明确疑点时阻断；未知时转审查 | 医学、司法或律师对行为能力与胁迫的最终评价 |
| 遗嘱形式 | 第1134—1139条 | 根据自书、代书、打印、录音录像、口头、公证形式检查结构化要件 | 个案证据证明力、签署过程真实性 |
| 见证人资格 | 第1140条 | 数量、能力、是否继承人/受遗赠人、是否有利害关系 | 复杂或间接利害关系的最终认定 |
| 必要份额 | 第1141条 | 是否完成候选人排查、已报告候选人是否处理 | “缺乏劳动能力”“没有生活来源”和具体必要份额的个案判断 |
| 撤回与多份遗嘱 | 第1142条 | 有旧遗嘱时要求完成日期、冲突和撤回审查 | 内容抵触范围和行为撤回的具体法律评价 |
| 遗赠扶养协议冲突 | 继承编解释（一）第3条 | 有协议时要求核对冲突，已确认冲突则阻断 | 协议效力和冲突范围 |
| 未处分财产 | 民法典第1154条 | 比对全部已知财产与处分意愿映射 | 是否采用剩余财产条款及条款设计 |
| 继承人范围、胎儿份额、丧失继承权 | 第1125、1155条 | 核对完整性、胎儿份额处理状态和异常事实复核状态 | 亲属关系、代位继承、宽恕和证据评价 |
| 共有财产析产 | 第1153条 | 识别多人共有并检查是否先核对可处分份额 | 夫妻共同财产、家庭共有和隐名权属争议 |
| 遗赠接受、附义务与兜底 | 第1124、1144、1154条 | 检查期限提示、附义务复核、替补和剩余财产状态 | 通知证据、义务可执行性和具体条款设计 |
| 遗产管理 | 第1145、1147、1149条 | 检查管理人意愿、职责权限和费用报酬安排 | 适格管理人选任、紧急处分和责任承担 |
| 税款债务与复杂资产 | 第1159、1161—1163条及保险法第42条 | 检查盘点、专项复核和专业分流状态 | 税务、公司、境外、数字资产和保险合同个案结论 |

## 3. 遗嘱形式检查矩阵

- 自书：遗嘱人亲笔书写、签名并注明年、月、日；当前数据只记录执行计划，无法证明实际亲笔过程。
- 代书：两名以上见证人在场见证，由其中一人代书，遗嘱人、代书人和其他见证人签名并注明年、月、日。
- 打印：两名以上见证人在场见证，遗嘱人和见证人在遗嘱每一页签名并注明年、月、日。
- 录音录像：两名以上见证人在场见证，遗嘱人和见证人应在记录中留下姓名或肖像以及年、月、日。
- 口头：仅在危急情况下适用，并需要两名以上见证人在场；危急情况消除后能够采用书面或录音录像形式的，原口头遗嘱无效。
- 公证：由遗嘱人经公证机构办理。

执行计划的机器检查只记录结构化安排，不证明任何实际行为已经依法完成，也不授权签署。生成后的操作指引必须把所选形式对应的准备动作逐项写明，并提示律师人工复核。

## 4. 规则结果

- `PASS`：输入数据满足当前机器可判断条件，不等于法律结论最终成立。
- `WARN`：存在不阻断的注意事项。
- `REVIEW_REQUIRED`：可继续整理和生成明确标注的草案，但必须在须知中列出专业判断或补证任务。
- `BLOCKED`：不得生成遗嘱正文 DOCX；先补充、纠正或由专业人员决定后续处理。

## 5. 暂不覆盖

规则包只对税费、保险、公司、境外和数字资产等事项做识别与分流，不自动给出专项结论；仍不自动处理涉外冲突规范、遗嘱信托、复杂公司治理、具体税负测算、农村集体权益、数字资产平台规则、诉讼时效、证据真实性鉴定或争议裁判结果。这些问题由实时检索和专业审核处理，并以简明事项和下一步动作进入执行指引。
