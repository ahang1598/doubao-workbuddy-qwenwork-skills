# A股个股技术诊断

通过免费接口获取个股行情和60日K线数据，由 Agent 进行趋势、量价、均线、支撑压力等多维分析，输出结构化 Markdown 诊断报告。无需任何 API Key。

## 禁止事项

- 禁止给出明确的买入/卖出建议——只输出分析和信号，末尾必须附免责声明
- 禁止编造数据——所有数字必须来自脚本采集结果，数据获取失败时如实告知
- 禁止分析港股/美股/基金/期货——仅支持A股沪深北交所
- 禁止在数据不完整时强行分析——K线不足20日时标注"数据不足，分析仅供参考"
- 禁止省略免责声明

## 强制要求

- 执行分析前必须先运行数据采集脚本获取最新数据
- 股票代码必须为6位数字，执行前验证格式
- 分析报告必须包含数据获取时间
- 多只股票分析时逐只出报告，最后附总结对比
- 分析结论必须基于脚本返回的实际数据，不得凭空推断

## 能力清单

| 能力 | 安全等级 | 说明 |
|------|---------|------|
| 数据采集 | 只读 | 运行脚本获取实时行情 + 60日K线 + 技术指标 |
| 趋势分析 | 只读 | 基于均线排列和K线走势判断趋势方向 |
| 量价分析 | 只读 | 对比成交量与均量，识别放量/缩量信号 |
| 支撑压力 | 只读 | 基于60日高低点和均线计算关键价位 |
| 风险评估 | 只读 | 综合技术信号给出风险等级 |
| 多股对比 | 只读 | 多只股票并行分析后横向对比 |

## Phase 1 — 数据采集

运行数据采集脚本获取个股全部数据：

```bash
# 单只股票
uv run {baseDir}/scripts/fetch_data.py 600519

# 多只股票
uv run {baseDir}/scripts/fetch_data.py 600519 000858 300750
```

脚本输出 JSON，包含：
- `realtime`：实时行情（现价、涨跌幅、成交量）
- `klines_60d`：近60个交易日K线数据
- `technicals`：技术指标（MA5/10/20/60、量比、区间位置等）

## Phase 2 — 数据解读

Agent 读取 Phase 1 输出的 JSON 数据，提取关键信息：

1. **行情概览**：现价、涨跌幅、成交量/额
2. **均线数据**：MA5、MA10、MA20、MA60 及与现价关系
3. **区间位置**：当前价格在60日高低点区间中的位置
4. **量能变化**：当日成交量与5日均量对比
5. **近期涨跌**：5日涨跌幅、20日涨跌幅

## Phase 3 — 多维分析

基于 Phase 2 数据，Agent 从以下维度分析：

**趋势判断：**
- MA5 > MA10 > MA20 > MA60 → 多头排列（上升趋势）
- MA5 < MA10 < MA20 < MA60 → 空头排列（下降趋势）
- 均线交叉缠绕 → 震荡整理

**量价关系：**
- 价涨量增 → 健康上涨
- 价涨量缩 → 上涨动力不足
- 价跌量增 → 恐慌抛售
- 价跌量缩 → 下跌趋缓

**支撑与压力：**
- 支撑位：MA20、MA60、60日最低点
- 压力位：近期高点、MA60（空头时）、60日最高点

**风险信号：**
- 60日区间位置 >80% → 高位风险
- 60日区间位置 <20% → 超跌区域
- 成交量突增 >2倍均量 → 异动信号
- 5日跌幅 >10% → 短期超跌

按以下模板输出分析报告：


## 使用示例

### 示例 1：单股分析

**用户说**："帮我分析下600519"

**执行**：`uv run {baseDir}/scripts/fetch_data.py 600519` → 读取 JSON → 多维分析 → 输出报告

### 示例 2：多股对比

**用户说**："帮我对比下600519和000858"

**执行**：`uv run {baseDir}/scripts/fetch_data.py 600519 000858` → 逐只分析 → 输出对比表

### 示例 3：需确认代码

**用户说**："分析下宁德时代"

**执行**：提示用户"宁德时代代码为300750，确认分析？" → 确认后执行完整流程

### 示例 4：数据不足

**用户说**："分析下次新股 xxx"

**执行**：采集数据 → 发现K线不足20日 → 输出报告但标注"上市时间较短，数据不足，分析仅供参考"

## 错误处理

| 错误场景 | 处理方式 |
|---------|---------|
| 股票代码无效（非6位数字） | 提示用户提供正确的6位数字代码 |
| 新浪接口超时 | 告知用户网络异常，建议稍后重试 |
| K线接口获取失败 | 仅基于实时行情做简要分析，标注"K线数据暂不可用" |
| K线数据不足60日 | 正常分析但标注数据天数，部分指标标注"不适用" |
| 非交易时段 | 正常执行，标注"当前为非交易时段，数据为最近收盘价" |
| 用户提供股票名称而非代码 | 要求用户确认6位数字代码 |
| uv 命令不可用 | 改用 `python3 {baseDir}/scripts/fetch_data.py` 执行 |

统一使用免费公开接口，无需任何 API Key：

| 数据 | 接口 | 说明 |
|------|------|------|

## 限制

- 仅支持A股（沪深北交所）
- 技术分析基于60日K线，不做更长周期分析
- 不支持股票名称搜索，需提供6位数字代码
- 不提供买卖建议，仅呈现分析和信号
- 不做量化回测或策略编写
