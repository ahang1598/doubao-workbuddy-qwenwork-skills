# 证券虚假陈述责任纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对赔偿因虚假陈述导致的损失 | 无异议 / 有异议 |
| 2 | 对主张连带责任 | 无异议 / 有异议 |
| 3 | 对实现债权的费用 | 无异议 / 有异议 |
| 4 | 对其他请求 | 无异议 / 有异议 |
| 5 | 对标的总额 | 无异议 / 有异议 |
| 6 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实与理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对存在虚假陈述行为的情况 | 无异议 / 有异议 |
| 2 | 对有无监管部门的认定、处罚 | 无异议 / 有异议 |
| 3 | 对原告交易情况 | 无异议 / 有异议 |
| 4 | 对虚假陈述的重大性 | 无异议 / 有异议 |
| 5 | 对虚假陈述与原告交易行为之间的因果关系 | 无异议 / 有异议 |
| 6 | 对虚假陈述与原告损失之间的因果关系 | 无异议 / 有异议 |
| 7 | 对原告损失情况 | 无异议 / 有异议 |
| 8 | 对原告请求发行人的控股股东、实际控制人、董监高、相关责任人员承担连带责任的情况 | 无异议 / 有异议 |
| 9 | 对原告请求保荐机构、承销机构、律师事务所、会计师事务所等其他机构及其相关责任人员承担连带责任的情况 | 无异议 / 有异议 |
| 10 | 有无其他免责/减责事由 | 无 / 有 |
| 11 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《中华人民共和国证券法》第八十五条（虚假陈述民事赔偿）
- 《中华人民共和国证券法》第一百六十三条（中介机构连带责任）
- 《最高人民法院关于审理证券市场虚假陈述侵权民事赔偿案件的若干规定》
- 《中华人民共和国民法典》第一千一百六十五条（过错责任）
