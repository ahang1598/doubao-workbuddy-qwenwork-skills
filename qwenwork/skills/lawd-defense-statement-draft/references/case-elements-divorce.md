# 离婚纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对解除婚姻关系 | 确认 / 异议 |
| 2 | 对夫妻共同财产诉请 | 确认 / 异议 |
| 3 | 对夫妻共同债务诉请 | 确认 / 异议 |
| 4 | 对子女直接抚养诉请 | 确认 / 异议 |
| 5 | 对子女抚养费诉请 | 确认 / 异议 |
| 6 | 对子女探望权诉请 | 确认 / 异议 |
| 7 | 对赔偿/补偿/经济帮助 | 确认 / 异议 |
| 8 | 其他事由 | 自由填写 |
| 9 | 答辩的依据 | 法律及司法解释的规定（写明具体条文） |

## 二、特殊说明

离婚纠纷的答辩状模板与劳动争议类似，将"答辩事项"和"事实和理由"合并为一张表。每项诉请直接选择"确认/异议"并附事由。

## 三、常用法律依据

- 《中华人民共和国民法典》第一千零七十九条（离婚条件）
- 《中华人民共和国民法典》第一千零八十四条（子女抚养）
- 《中华人民共和国民法典》第一千零八十五条（抚养费）
- 《中华人民共和国民法典》第一千零八十六条（探望权）
- 《中华人民共和国民法典》第一千零八十七条（共同财产分割）
- 《中华人民共和国民法典》第一千零八十八条（经济补偿）
- 《中华人民共和国民法典》第一千零九十一条（离婚损害赔偿）
- 《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释（一）》
