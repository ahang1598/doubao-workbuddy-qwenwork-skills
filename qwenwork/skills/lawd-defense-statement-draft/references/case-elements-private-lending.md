# 民间借贷纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对本金 | 无异议 / 有异议 |
| 2 | 对利息 | 无异议 / 有异议 |
| 3 | 对提前还款或解除合同 | 无异议 / 有异议 |
| 4 | 对担保权利诉请 | 无异议 / 有异议 |
| 5 | 对实现债权的费用 | 无异议 / 有异议 |
| 6 | 对其他请求 | 无异议 / 有异议 |
| 7 | 对标的总额 | 无异议 / 有异议 |
| 8 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实和理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对合同签订情况（名称、编号、签订时间、地点等） | 无异议 / 有异议 |
| 2 | 对签订主体 | 无异议 / 有异议 |
| 3 | 对借款金额 | 无异议 / 有异议 |
| 4 | 对借款期限 | 无异议 / 有异议 |
| 5 | 对借款利率 | 无异议 / 有异议 |
| 6 | 对借款提供时间 | 无异议 / 有异议 |
| 7 | 对还款方式 | 无异议 / 有异议 |
| 8 | 对还款情况 | 无异议 / 有异议 |
| 9 | 对是否逾期还款 | 无异议 / 有异议 |
| 10 | 对是否签订物的担保合同 | 无异议 / 有异议 |
| 11 | 对担保人、担保物 | 无异议 / 有异议 |
| 12 | 对最高额抵押担保 | 无异议 / 有异议 |
| 13 | 对是否办理抵押/质押登记 | 无异议 / 有异议 |
| 14 | 对是否签订保证合同 | 无异议 / 有异议 |
| 15 | 对保证方式 | 无异议 / 有异议 |
| 16 | 对其他担保方式 | 无异议 / 有异议 |
| 17 | 有无其他免责/减责事由 | 无 / 有 |
| 18 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《中华人民共和国民法典》第六百六十七条至第六百八十条（借款合同）
- 《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》
- 《中华人民共和国民法典》第六百八十一条至第七百零二条（保证合同）
