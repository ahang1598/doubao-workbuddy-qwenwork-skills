# 融资租赁合同纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对支付全部未付租金的诉请 | 无异议 / 有异议 |
| 2 | 对违约金、滞纳金、损害赔偿金 | 无异议 / 有异议 |
| 3 | 对确认租赁物归原告所有 | 无异议 / 有异议 |
| 4 | 对解除合同 | 无异议 / 有异议 |
| 5 | 对返还租赁物，并赔偿因解除合同而受到的损失 | 无异议 / 有异议 |
| 6 | 对担保权利的诉请 | 无异议 / 有异议 |
| 7 | 对实现债权的费用 | 无异议 / 有异议 |
| 8 | 对其他请求 | 无异议 / 有异议 |
| 9 | 对标的总额 | 无异议 / 有异议 |
| 10 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实与理由（对起诉状事实与理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对合同签订情况（名称、编号、签订时间、地点） | 无异议 / 有异议 |
| 2 | 对签订主体 | 无异议 / 有异议 |
| 3 | 对租赁物情况 | 无异议 / 有异议 |
| 4 | 对合同约定的租金及支付方式 | 无异议 / 有异议 |
| 5 | 对合同约定的租赁期限、费用 | 无异议 / 有异议 |
| 6 | 对到期后租赁物归属 | 无异议 / 有异议 |
| 7 | 对合同约定的违约责任 | 无异议 / 有异议 |
| 8 | 对是否约定加速到期条款 | 无异议 / 有异议 |
| 9 | 对是否约定回收租赁物条件 | 无异议 / 有异议 |
| 10 | 对是否约定解除合同条件 | 无异议 / 有异议 |
| 11 | 对租赁物交付时间 | 无异议 / 有异议 |
| 12 | 对租赁物情况 | 无异议 / 有异议 |
| 13 | 对租金支付情况 | 无异议 / 有异议 |
| 14 | 对逾期未付租金情况 | 无异议 / 有异议 |
| 15 | 对是否签订物的担保合同 | 无异议 / 有异议 |
| 16 | 对担保人、担保物 | 无异议 / 有异议 |
| 17 | 对最高额抵押担保 | 无异议 / 有异议 |
| 18 | 对是否办理抵押/质押登记 | 无异议 / 有异议 |
| 19 | 对是否签订保证合同 | 无异议 / 有异议 |
| 20 | 对保证方式 | 无异议 / 有异议 |
| 21 | 对其他担保方式 | 无异议 / 有异议 |
| 22 | 有无其他免责/减责事由 | 无 / 有 |
| 23 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《中华人民共和国民法典》第七百三十五条至第七百六十条（融资租赁合同）
- 《最高人民法院关于审理融资租赁合同纠纷案件适用法律问题的解释》
- 《中华人民共和国民法典》第六百八十一条至第七百零二条（保证合同）
