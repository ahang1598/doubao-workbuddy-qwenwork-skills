# 示例输入：买卖合同纠纷

## 用户输入

```
帮我写一份买卖合同纠纷的答辩状。

案件情况：
- 案号：(2023)沪0X民初XX号
- 原告：上海XX混凝土有限公司
- 被告（我方）：上海XX集团建筑工程有限公司
- 合同：《南通XX项目商品混凝土买卖合同》

原告诉请：
1. 支付全部货款2,054,220元
2. 支付逾期付款利息（按年利率6%计算）
3. 支付律师费100,000元

我方情况：
- 已支付货款1,527,578.98元（占总额74.36%）
- 剩余未付526,641.02元，愿意支付
- 工程尚未结束，合同约定工程结束后付清尾款
- 合同约定逾期付款利息按中国人民银行同期活期存款利率计算，不是年利率6%
- 原告未提交律师费支付凭证
```
