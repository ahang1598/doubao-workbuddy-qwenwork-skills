# 保证保险合同纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对理赔款 | 无异议 / 有异议 |
| 2 | 对保险费、违约金等 | 无异议 / 有异议 |
| 3 | 对实现债权的费用 | 无异议 / 有异议 |
| 4 | 对其他请求 | 无异议 / 有异议 |
| 5 | 对标的总额 | 无异议 / 有异议 |
| 6 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实与理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对保证保险合同的签订情况 | 无异议 / 有异议 |
| 2 | 对保证保险合同的主要约定 | 无异议 / 有异议 |
| 3 | 对原告对被告就保证保险合同主要条款进行提示注意、说明的情况 | 无异议 / 有异议 |
| 4 | 对被告借款合同的主要约定 | 无异议 / 有异议 |
| 5 | 对被告逾期未还款情况 | 无异议 / 有异议 |
| 6 | 对保证保险合同的履行情况 | 无异议 / 有异议 |
| 7 | 对追索情况 | 无异议 / 有异议 |
| 8 | 有无其他免责/减责事由 | 无 / 有 |
| 9 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《中华人民共和国保险法》
- 《中华人民共和国民法典》第六百六十七条至第六百八十条（借款合同）
- 《中华人民共和国民法典》第四百九十六条（格式条款）
- 《最高人民法院关于适用〈中华人民共和国保险法〉若干问题的解释》
