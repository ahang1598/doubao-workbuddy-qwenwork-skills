# 买卖合同纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对给付价款的诉请 | 无异议 / 有异议 |
| 2 | 对迟延给付价款的利息（违约金） | 无异议 / 有异议 |
| 3 | 对要求继续履行或是解除合同 | 无异议 / 有异议 |
| 4 | 对赔偿因违约所受的损失 | 无异议 / 有异议 |
| 5 | 对就标的物的瑕疵承担责任 | 无异议 / 有异议 |
| 6 | 对担保权利的诉请 | 无异议 / 有异议 |
| 7 | 对实现债权的费用 | 无异议 / 有异议 |
| 8 | 对其他请求 | 无异议 / 有异议 |
| 9 | 对标的总额 | 无异议 / 有异议 |
| 10 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实与理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对合同签订情况（名称、编号、签订时间、地点） | 无异议 / 有异议 |
| 2 | 对签订主体 | 无异议 / 有异议 |
| 3 | 对标的物情况 | 无异议 / 有异议 |
| 4 | 对合同约定的价格及支付方式 | 无异议 / 有异议 |
| 5 | 对合同约定的交货时间、地点、方式、风险承担、安装、调试、验收 | 无异议 / 有异议 |
| 6 | 对合同约定的质量标准及检验方式、质量异议期限 | 无异议 / 有异议 |
| 7 | 对合同约定的违约金（定金） | 无异议 / 有异议 |
| 8 | 对价款支付及标的物交付情况 | 无异议 / 有异议 |
| 9 | 对是否存在迟延履行 | 无异议 / 有异议 |
| 10 | 对是否催促过履行 | 无异议 / 有异议 |
| 11 | 对买卖合同标的物有无质量争议 | 无异议 / 有异议 |
| 12 | 对标的物质量规格或履行方式是否存在不符合约定的情况 | 无异议 / 有异议 |
| 13 | 对是否曾就标的物质量问题进行协商 | 无异议 / 有异议 |
| 14 | 对应当支付的利息、违约金、赔偿金 | 无异议 / 有异议 |
| 15 | 对是否签订物的担保合同 | 无异议 / 有异议 |
| 16 | 对担保人、担保物 | 无异议 / 有异议 |
| 17 | 对最高额抵押担保 | 无异议 / 有异议 |
| 18 | 对是否办理抵押/质押登记 | 无异议 / 有异议 |
| 19 | 对是否签订保证合同 | 无异议 / 有异议 |
| 20 | 对保证方式 | 无异议 / 有异议 |
| 21 | 对其他担保方式 | 无异议 / 有异议 |
| 22 | 有无其他免责/减责事由 | 无 / 有 |
| 23 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

- 《中华人民共和国民法典》第五百九十五条至第六百四十六条（买卖合同）
- 《中华人民共和国民法典》第五百七十七条至第五百九十四条（违约责任）
- 《中华人民共和国民法典》第六百八十一条至第七百零二条（保证合同）
