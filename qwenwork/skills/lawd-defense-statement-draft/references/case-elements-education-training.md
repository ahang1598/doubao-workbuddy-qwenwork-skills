# 教育培训合同纠纷 — 要素清单

## 一、答辩事项（对原告诉讼请求的确认或者异议）

| 序号 | 答辩事项 | 态度选项 |
|------|----------|----------|
| 1 | 对退还培训费/学费的诉请 | 无异议 / 有异议 |
| 2 | 对利息/违约金的诉请 | 无异议 / 有异议 |
| 3 | 对解除合同或确认合同无效的诉请 | 无异议 / 有异议 |
| 4 | 对赔偿损失的诉请 | 无异议 / 有异议 |
| 5 | 对共同承担责任（如个人与公司共同被告）的诉请 | 无异议 / 有异议 |
| 6 | 对实现债权的费用（律师费、保全费等） | 无异议 / 有异议 |
| 7 | 对其他请求 | 无异议 / 有异议 |
| 8 | 对标的总额 | 无异议 / 有异议 |
| 9 | 答辩依据 | 合同约定 + 法律规定 |

## 二、事实和理由（对起诉状事实与理由的确认或者异议）

| 序号 | 事实要素 | 态度选项 |
|------|----------|----------|
| 1 | 对合同签订情况（合同名称、签订时间、签约主体） | 无异议 / 有异议 |
| 2 | 对合同性质与效力（是否教育培训服务合同、有无无效事由） | 无异议 / 有异议 |
| 3 | 对培训服务内容、课程安排与课时总量的约定 | 无异议 / 有异议 |
| 4 | 对培训费用的构成与支付方式（一次性/分期、优惠折算方式） | 无异议 / 有异议 |
| 5 | 对已提供培训服务的情况（已上课时、已消耗课时价值） | 无异议 / 有异议 |
| 6 | 对教学结果有无承诺（是否承诺包过、保分、就业等效果） | 无承诺 / 有承诺 |
| 7 | 对学员/消费者自身因素（缺课、中途放弃、未按时上课） | 无 / 有 |
| 8 | 对退费/和解协商情况（是否已协商退费、已退金额、和解协议） | 无 / 有 |
| 9 | 对收款主体与费用流向（收款方是否为答辩人、是否存在代收代付） | 无异议 / 有异议 |
| 10 | 对是否存在虚假宣传、欺诈（宣传内容与合同/实际是否一致） | 无 / 有 |
| 11 | 对合同解除/终止的原因与责任归属 | 无异议 / 有异议 |
| 12 | 对退费条款的约定（退费条件、扣除标准、违约金） | 无异议 / 有异议 |
| 13 | 有无其他免责/减责事由（不可抗力、情势变更、政策变化） | 无 / 有 |
| 14 | 其他需要说明的内容 | 自由填写 |

## 三、常用法律依据

> ⚠️ 以下法条为定位提示，引用时须核验现行性或标注"（待核验）"。

- 《中华人民共和国民法典》第四百六十五条（合同相对性）
- 《中华人民共和国民法典》第五百零九条（全面履行）
- 《中华人民共和国民法典》第五百六十三条（合同法定解除）
- 《中华人民共和国民法典》第五百六十六条（解除后果与结算清理）
- 《中华人民共和国民法典》第五百七十七条（违约责任）
- 《中华人民共和国消费者权益保护法》第五十三条（预付款退还）
