# 商业计划书

覆盖从市场规模验证（TAM/SAM/SOM）、竞品对比矩阵、商业模式画布到财务预测与融资需求的**全链路**分析，输出结构化的钉钉在线文档商业计划书，可直接用于投资人评审。

---

## 禁止事项

- 禁止以对话文本替代钉钉在线文档作为最终交付物
- 禁止编造数据、链接或来源；所有数据必须有可追溯出处
- 禁止使用过期数据（用户指定时间范围时，必须严格筛选）
- 禁止财务数据缺少来源、年份和口径说明
- 禁止市场规模仅有单一来源（至少 2 个独立来源交叉验证）
- 禁止直接构造 API 请求绕过钉钉工具

## 强制要求

- 本技能触发即代表用户期望生成**钉钉在线文档**，主 Agent 无需询问确认
- 数据收集完成后，直接调用 `dws doc create --name --markdown` 创建钉钉在线文档
- 每个数据收集步骤完成后立即写入草稿文件：`/home/workspace/draft_business-plan_{YYYYMMDD_HHMMSS}.md`
- 并列项 ≥ 3 时使用列表或表格；单段 > 150 字必须拆分；财务数据必须使用表格

## Phase 3 — 结构化分析

### B1. TAM/SAM/SOM 市场验证

采用「自上而下 + 自下而上」双向估算，交叉验证市场规模：

**自上而下：** 行业总市场规模 × 目标细分占比 × 地理渗透率
**自下而上：** 目标客户数 × 平均客单价 × 预期渗透率

两种方式差异 ≤ 20% 方可采信；差异过大需说明原因。

### B2. 竞品对比矩阵（加权评分）

对每个竞品在以下维度打分（1-5分），权重可按用户需求调整：

| 评估维度 | 权重 | 我方 | 竞品 A | 竞品 B | 竞品 C |
|---------|------|------|--------|--------|--------|
| AI/技术能力 | 25% | | | | |
| 产品完整度 | 20% | | | | |
| 部署灵活性 | 15% | | | | |
| 客单价竞争力 | 20% | | | | |
| 实施效率 | 10% | | | | |
| 客户口碑 | 10% | | | | |
| **加权总分** | 100% | | | | |

## 易混淆场景

| 场景 | 判断依据 | 处理方式 |
|------|---------|---------|
| 用户提供了大量内部资料 | 有内部数据支撑 | 优先使用内部数据，外部调研作补充验证 |

| 用户给了 PDF 附件 | 有参考材料 | 用 WebFetch 或 合合文件解析 MCP 的 `parse_pdf_to_markdown`（或对图片/PDF 直接用多模态 Read 读取）提取内容作为内部资料 |

## 错误处理

| 错误 | 原因 | 修复方法 |
|------|------|---------|
| 市场规模缺乏说服力 | 仅单一来源或无 SOM 拆解 | 补充至少 2 个来源，完成 TAM/SAM/SOM 三级拆解 |
| 竞品分析浮于表面 | 仅列名称，缺乏定量对比 | 建立加权评分矩阵，用 WebFetch 深读竞品官网 |
| 财务预测不可信 | 增速假设激进，缺乏依据 | 对标行业 benchmark，增速逐年递减符合 S 曲线 |
| 团队信息单薄 | 仅列姓名职位 | 补充核心背景（前公司+职级+关键成就） |
| 风险章节走过场 | 对策空洞 | 风险矩阵必须含影响程度+概率+具体可执行对策 |
| dws doc create 失败 | 内容过长或格式问题 | 分章节创建，或检查 markdown 格式 |
