y = 1x² + 0x + 0
a (开口方向和大小) 1
b (左右平移和倾斜) 0
c (上下平移) 0

顶点坐标

(0, 0)

x = 0

根 (x截距)

x = 0

判别式 Δ

0

📚 学习要点

  • a > 0：抛物线开口向上，有最小值
  • a < 0：抛物线开口向下，有最大值
  • |a| 越大：抛物线越窄，开口越小
  • |a| 越小：抛物线越宽，开口越大
  • b 影响：对称轴位置 x = -b/(2a)
  • c 影响：y轴截距，即 x=0 时的函数值
  • Δ > 0：两个不同的实根
  • Δ = 0：一个实根（重根）
  • Δ < 0：无实根（有复根）
