# 基础数学参考资料

## 算术基础

### 加法
- **概念**：将两个或多个数合并成一个总数
- **性质**：
  - 交换律：a + b = b + a
  - 结合律：(a + b) + c = a + (b + c)
  - 零元素：a + 0 = a

### 减法
- **概念**：从一个数中移除另一个数
- **性质**：减法是加法的逆运算
- **关系**：a - b = c 等价于 a = b + c

### 乘法
- **概念**：重复的加法
- **性质**：
  - 交换律：a × b = b × a
  - 结合律：(a × b) × c = a × (b × c)
  - 分配律：a × (b + c) = a × b + a × c
  - 单位元：a × 1 = a
  - 零元素：a × 0 = 0

### 除法
- **概念**：将一个数分成相等的部分
- **关系**：a ÷ b = c 等价于 a = b × c
- **术语**：被除数 ÷ 除数 = 商 ... 余数

## 分数

### 基本概念
- **分子**：分数线上方的数，表示部分的数量
- **分母**：分数线下方的数，表示整体被分成的份数
- **真分数**：分子 < 分母（如 3/4）
- **假分数**：分子 ≥ 分母（如 5/4）
- **带分数**：整数 + 真分数（如 1 1/4）

### 分数运算

#### 加法/减法
1. 找到公分母
2. 将分数转换为相同分母
3. 分子相加/减，分母不变
4. 化简结果

#### 乘法
1. 分子相乘得到新分子
2. 分母相乘得到新分母
3. 化简结果

#### 除法
1. 将除数取倒数
2. 转换为乘法
3. 按乘法规则计算

### 等值分数
- **概念**：值相同但形式不同的分数
- **生成**：分子分母同时乘以或除以相同非零数
- **示例**：1/2 = 2/4 = 3/6 = 4/8

## 小数

### 位值系统
- 个位 . 十分位 百分位 千分位
- 示例：3.141 表示 3 + 1/10 + 4/100 + 1/1000

### 小数运算
- **加减法**：对齐小数点
- **乘法**：先按整数计算，再确定小数位数
- **除法**：将除数转为整数，被除数相应调整

### 分数与小数转换
- 分数 → 小数：分子 ÷ 分母
- 小数 → 分数：根据位值写成分数后化简

## 百分数

### 基本概念
- **定义**：表示"每一百"的数
- **符号**：%
- **关系**：p% = p/100 = p × 0.01

### 常见转换
| 分数 | 小数 | 百分数 |
|------|------|--------|
| 1/2 | 0.5 | 50% |
| 1/4 | 0.25 | 25% |
| 3/4 | 0.75 | 75% |
| 1/5 | 0.2 | 20% |
| 1/10 | 0.1 | 10% |

### 百分数应用
- **求百分比**：部分 ÷ 整体 × 100%
- **求部分**：整体 × 百分比
- **求整体**：部分 ÷ 百分比

## 基础几何

### 基本形状

#### 三角形
- **内角和**：180°
- **分类**：
  - 按边：等边、等腰、不等边
  - 按角：锐角、直角、钝角
- **面积**：A = 1/2 × 底 × 高

#### 四边形
- **正方形**：四边相等，四角90°
- **长方形**：对边相等，四角90°
- **平行四边形**：对边平行且相等
- **梯形**：只有一组对边平行

#### 圆
- **半径**（r）：圆心到圆周的线段
- **直径**（d）：通过圆心的弦，d = 2r
- **周长**：C = 2πr = πd
- **面积**：A = πr²

### 周长与面积

#### 周长公式
- 正方形：P = 4s
- 长方形：P = 2(l + w)
- 三角形：P = a + b + c
- 圆：C = 2πr

#### 面积公式
- 正方形：A = s²
- 长方形：A = l × w
- 三角形：A = 1/2 × b × h
- 圆：A = πr²
- 梯形：A = 1/2 × (a + b) × h

## 模式与序列

### 数列类型

#### 等差数列
- **定义**：相邻项的差相等
- **通项**：aₙ = a₁ + (n-1)d
- **求和**：Sₙ = n/2 × (a₁ + aₙ)
- **示例**：2, 5, 8, 11, 14...（公差 d = 3）

#### 等比数列
- **定义**：相邻项的比相等
- **通项**：aₙ = a₁ × r^(n-1)
- **求和**：Sₙ = a₁ × (1 - rⁿ)/(1 - r) （r ≠ 1）
- **示例**：3, 6, 12, 24, 48...（公比 r = 2）

### 常见数列
- **平方数**：1, 4, 9, 16, 25, 36...
- **立方数**：1, 8, 27, 64, 125...
- **斐波那契**：1, 1, 2, 3, 5, 8, 13...（Fₙ = Fₙ₋₁ + Fₙ₋₂）
- **三角形数**：1, 3, 6, 10, 15, 21...

## 时间与金钱

### 时间
- **读钟**：时针（短针）、分针（长针）、秒针
- **换算**：
  - 1小时 = 60分钟
  - 1分钟 = 60秒
  - 1天 = 24小时
  - 1周 = 7天

### 货币计算
- **基本单位**：元、角、分
- **换算**：1元 = 10角 = 100分
- **计算**：加法对齐小数点，减法注意借位

## 测量

### 长度单位
- **公制**：毫米(mm)、厘米(cm)、米(m)、千米(km)
- **换算**：1 km = 1000 m = 100,000 cm = 1,000,000 mm

### 重量单位
- **公制**：毫克(mg)、克(g)、千克(kg)、吨(t)
- **换算**：1 t = 1000 kg = 1,000,000 g

### 容量单位
- **公制**：毫升(mL)、升(L)
- **换算**：1 L = 1000 mL
