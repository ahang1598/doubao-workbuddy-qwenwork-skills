# 几何参考资料

## 基础几何概念

### 点、线、面
- **点**：没有大小，只有位置
- **线**：由无数点组成，向两端无限延伸
- **线段**：线的一部分，有两个端点
- **射线**：有一个端点，向一端无限延伸
- **平面**：向四面八方无限延展的平坦表面

### 角
- **定义**：两条射线从同一点出发形成的图形
- **顶点**：角的公共端点
- **边**：组成角的两条射线
- **度量单位**：度（°）或弧度（rad）

#### 角的分类
| 类型 | 度数范围 | 示例 |
|------|----------|------|
| 锐角 | 0° < θ < 90° | 45° |
| 直角 | θ = 90° | 90° |
| 钝角 | 90° < θ < 180° | 120° |
| 平角 | θ = 180° | 180° |
| 周角 | θ = 360° | 360° |

#### 角的关系
- **余角**：两角之和为 90°
- **补角**：两角之和为 180°
- **对顶角**：两直线相交，相对的角相等
- **邻补角**：相邻且互补的角

### 平行线与横截线
当一条横截线与两条平行线相交时：
- **同位角相等**
- **内错角相等**
- **同旁内角互补**

## 三角形

### 基本性质
- **内角和**：180°
- **外角定理**：外角等于不相邻两内角之和
- **两边之和大于第三边**

### 三角形分类

#### 按边分类
- **等边三角形**：三边相等，三角均为 60°
- **等腰三角形**：两边相等，两底角相等
- **不等边三角形**：三边都不相等

#### 按角分类
- **锐角三角形**：三个角都是锐角
- **直角三角形**：有一个直角（90°）
- **钝角三角形**：有一个钝角

### 特殊线段
- **高**：从顶点向对边所作的垂线
- **中线**：连接顶点与对边中点的线段
- **角平分线**：平分内角的线段
- **垂直平分线**：垂直且平分边的直线

### 面积公式
- **基础公式**：A = 1/2 × 底 × 高
- **海伦公式**：A = √[s(s-a)(s-b)(s-c)]，其中 s = (a+b+c)/2
- **两边夹角**：A = 1/2 × ab × sin(C)

### 直角三角形

#### 勾股定理
- **定理**：a² + b² = c²（c 为斜边）
- **逆定理**：若 a² + b² = c²，则三角形为直角三角形
- **常见勾股数**：(3,4,5), (5,12,13), (8,15,17), (7,24,25)

#### 特殊直角三角形
- **45-45-90 三角形**：两直角边相等，斜边 = 直角边 × √2
- **30-60-90 三角形**：
  - 短直角边（对 30°）= x
  - 长直角边（对 60°）= x√3
  - 斜边 = 2x

### 全等三角形

#### 判定定理
- **SSS**：三边对应相等
- **SAS**：两边及其夹角对应相等
- **ASA**：两角及其夹边对应相等
- **AAS**：两角及其中一角的对边对应相等
- **HL**（直角三角形）：斜边和一条直角边对应相等

### 相似三角形

#### 判定定理
- **AA**：两角对应相等
- **SAS**：两边成比例且夹角相等
- **SSS**：三边成比例

#### 性质
- 对应角相等
- 对应边成比例
- 面积比 = 边长比的平方

## 四边形

### 分类与性质

#### 平行四边形
- **性质**：
  - 对边平行且相等
  - 对角相等
  - 对角线互相平分
- **面积**：A = 底 × 高

#### 矩形
- **性质**（继承平行四边形）：
  - 四个角都是直角
  - 对角线相等
- **面积**：A = 长 × 宽
- **周长**：P = 2(长 + 宽)

#### 菱形
- **性质**（继承平行四边形）：
  - 四边相等
  - 对角线互相垂直
  - 对角线平分对角
- **面积**：A = 1/2 × d₁ × d₂（对角线乘积的一半）

#### 正方形
- **性质**（继承矩形和菱形）：
  - 四边相等，四角为直角
  - 对角线相等且垂直
- **面积**：A = s²
- **周长**：P = 4s

#### 梯形
- **定义**：只有一组对边平行的四边形
- **面积**：A = 1/2 × (上底 + 下底) × 高
- **等腰梯形**：两腰相等，底角相等

## 多边形

### 正多边形
- **定义**：各边相等、各角相等的多边形
- **内角和**：(n-2) × 180°
- **每个内角**：(n-2) × 180° / n
- **外角和**：360°
- **每个外角**：360° / n

### 常见正多边形
| 边数 | 名称 | 内角 | 外角 |
|------|------|------|------|
| 3 | 正三角形 | 60° | 120° |
| 4 | 正方形 | 90° | 90° |
| 5 | 正五边形 | 108° | 72° |
| 6 | 正六边形 | 120° | 60° |
| 8 | 正八边形 | 135° | 45° |

## 圆

### 基本术语
- **圆心**：圆的中心点
- **半径**（r）：圆心到圆周的线段
- **直径**（d）：通过圆心的弦，d = 2r
- **弦**：连接圆周上两点的线段
- **弧**：圆周的一部分
- **扇形**：由两条半径和一段弧围成的区域
- **弓形**：由弦和弧围成的区域

### 周长与面积
- **周长（圆周）**：C = 2πr = πd
- **面积**：A = πr²

### 弧长与扇形面积
- **弧长**：L = (θ/360°) × 2πr = rθ（θ 为弧度）
- **扇形面积**：A = (θ/360°) × πr² = 1/2 × r²θ

### 圆的性质
- **切线性质**：切线垂直于过切点的半径
- **弦的性质**：
  - 垂直于弦的直径平分弦
  - 等弦到圆心距离相等
- **圆周角定理**：圆周角等于所对圆心角的一半
- **圆内接四边形**：对角互补

## 立体几何

### 棱柱
- **定义**：两个全等多边形底面，侧面为矩形
- **体积**：V = 底面积 × 高
- **表面积**：S = 2 × 底面积 + 侧面积

### 棱锥
- **定义**：一个多边形底面，侧面为三角形
- **体积**：V = 1/3 × 底面积 × 高

### 圆柱
- **体积**：V = πr²h
- **表面积**：S = 2πr² + 2πrh

### 圆锥
- **体积**：V = 1/3 × πr²h
- **表面积**：S = πr² + πrl（l 为母线长）

### 球
- **体积**：V = 4/3 × πr³
- **表面积**：S = 4πr²

## 坐标几何

### 距离公式
两点 A(x₁, y₁) 和 B(x₂, y₂) 之间的距离：
```
d = √[(x₂-x₁)² + (y₂-y₁)²]
```

### 中点公式
线段 AB 的中点 M：
```
M = ((x₁+x₂)/2, (y₁+y₂)/2)
```

### 斜率
- **公式**：m = (y₂-y₁) / (x₂-x₁)
- **平行线**：斜率相等
- **垂直线**：斜率乘积为 -1

### 直线方程
- **斜截式**：y = mx + b
- **点斜式**：y - y₁ = m(x - x₁)
- **一般式**：Ax + By + C = 0

### 圆的方程
- **标准式**：(x-h)² + (y-k)² = r²（圆心 (h,k)，半径 r）
- **一般式**：x² + y² + Dx + Ey + F = 0
