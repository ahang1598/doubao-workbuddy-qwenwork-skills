# 统计与概率参考资料

## 描述统计

### 数据类型
- **定性数据（分类数据）**：性别、颜色、类别
- **定量数据（数值数据）**：
  - 离散型：计数数据（如人数）
  - 连续型：测量数据（如身高、体重）

### 集中趋势度量

#### 平均数（Mean）
- **算术平均数**：x̄ = (Σxᵢ) / n
- **加权平均数**：x̄ = (Σwᵢxᵢ) / (Σwᵢ)
- **几何平均数**：G = ⁿ√(x₁ × x₂ × ... × xₙ)

#### 中位数（Median）
- **定义**：将数据排序后位于中间位置的值
- **奇数个**：第 (n+1)/2 个数
- **偶数个**：中间两个数的平均值

#### 众数（Mode）
- **定义**：数据中出现频率最高的值
- **特点**：可以不存在，也可以有多个

#### 比较
| 度量 | 优点 | 缺点 |
|------|------|------|
| 平均数 | 利用所有数据 | 受极端值影响 |
| 中位数 | 不受极端值影响 | 未利用所有数据 |
| 众数 | 适用于分类数据 | 可能不存在或不唯一 |

### 离散程度度量

#### 极差（Range）
- **定义**：最大值 - 最小值
- **特点**：简单但受极端值影响大

#### 四分位数
- **Q1（第一四分位数）**：25%分位数
- **Q2（中位数）**：50%分位数
- **Q3（第三四分位数）**：75%分位数
- **四分位距（IQR）**：Q3 - Q1

#### 方差（Variance）
- **总体方差**：σ² = Σ(xᵢ - μ)² / N
- **样本方差**：s² = Σ(xᵢ - x̄)² / (n-1)

#### 标准差（Standard Deviation）
- **总体**：σ = √σ²
- **样本**：s = √s²

#### 变异系数
- **定义**：CV = (标准差 / 平均数) × 100%
- **用途**：比较不同单位或量级数据的离散程度

### 分布形态度量

#### 偏度（Skewness）
- **对称分布**：偏度 ≈ 0
- **右偏（正偏）**：偏度 > 0，长尾在右
- **左偏（负偏）**：偏度 < 0，长尾在左

#### 峰度（Kurtosis）
- **正态分布**：峰度 ≈ 3（或超额峰度 ≈ 0）
- **尖峰**：峰度 > 3，数据更集中于中心
- **平峰**：峰度 < 3，数据更分散

## 概率基础

### 基本概念
- **随机试验**：结果不确定的实验
- **样本空间（S）**：所有可能结果的集合
- **事件**：样本空间的子集
- **概率**：P(A) = 事件A发生的可能性

### 概率公理
1. **非负性**：P(A) ≥ 0
2. **规范性**：P(S) = 1
3. **可加性**：互斥事件的并的概率等于概率之和

### 概率类型
- **理论概率**：P(A) = 有利结果数 / 所有可能结果数
- **经验概率**：基于实验数据的频率
- **主观概率**：基于个人判断

### 概率运算

#### 加法公式
- **互斥事件**：P(A ∪ B) = P(A) + P(B)
- **一般情况**：P(A ∪ B) = P(A) + P(B) - P(A ∩ B)

#### 乘法公式
- **独立事件**：P(A ∩ B) = P(A) × P(B)
- **一般情况**：P(A ∩ B) = P(A) × P(B|A)

#### 条件概率
```
P(A|B) = P(A ∩ B) / P(B) （P(B) > 0）
```

#### 全概率公式
若 B₁, B₂, ..., Bₙ 构成样本空间的划分：
```
P(A) = Σ P(A|Bᵢ) × P(Bᵢ)
```

#### 贝叶斯定理
```
P(Bᵢ|A) = P(A|Bᵢ) × P(Bᵢ) / P(A)
```

### 独立性
- **定义**：P(A ∩ B) = P(A) × P(B)
- **等价条件**：P(A|B) = P(A)

## 随机变量

### 离散型随机变量

#### 概率质量函数（PMF）
- P(X = xᵢ) = pᵢ
- 性质：pᵢ ≥ 0，Σpᵢ = 1

#### 期望值
```
E(X) = Σ xᵢ × pᵢ
```

#### 方差
```
Var(X) = E[(X - μ)²] = E(X²) - [E(X)]²
```

### 连续型随机变量

#### 概率密度函数（PDF）
- f(x) ≥ 0
- ∫(-∞ to ∞) f(x)dx = 1
- P(a ≤ X ≤ b) = ∫[a,b] f(x)dx

#### 累积分布函数（CDF）
```
F(x) = P(X ≤ x) = ∫(-∞ to x) f(t)dt
```

#### 期望值
```
E(X) = ∫(-∞ to ∞) x·f(x)dx
```

#### 方差
```
Var(X) = ∫(-∞ to ∞) (x-μ)²·f(x)dx
```

### 常见分布

#### 离散分布

**1. 伯努利分布**
- 单次试验，成功概率 p
- P(X=1) = p, P(X=0) = 1-p
- E(X) = p, Var(X) = p(1-p)

**2. 二项分布 B(n,p)**
- n 次独立伯努利试验的成功次数
- P(X=k) = C(n,k) × pᵏ × (1-p)ⁿ⁻ᵏ
- E(X) = np, Var(X) = np(1-p)

**3. 几何分布**
- 首次成功所需的试验次数
- P(X=k) = (1-p)ᵏ⁻¹ × p
- E(X) = 1/p, Var(X) = (1-p)/p²

**4. 泊松分布 P(λ)**
- 单位时间或单位面积内随机事件发生次数
- P(X=k) = λᵏ × e⁻ˡ / k!
- E(X) = Var(X) = λ

#### 连续分布

**1. 均匀分布 U(a,b)**
- f(x) = 1/(b-a), a ≤ x ≤ b
- E(X) = (a+b)/2, Var(X) = (b-a)²/12

**2. 正态分布 N(μ,σ²)**
- f(x) = 1/(σ√(2π)) × e^(-(x-μ)²/(2σ²))
- E(X) = μ, Var(X) = σ²
- **标准正态**：Z = (X-μ)/σ ~ N(0,1)

**3. 指数分布**
- f(x) = λe⁻ˡˣ, x ≥ 0
- E(X) = 1/λ, Var(X) = 1/λ²
- 无记忆性

**4. t分布**
- 小样本均值推断
- 自由度 n → ∞ 时趋近标准正态

**5. 卡方分布 χ²**
- 方差分析和拟合优度检验
- 若 Z₁, ..., Zₖ ~ N(0,1) 独立，则 ΣZᵢ² ~ χ²(k)

**6. F分布**
- 方差比检验
- 两个独立卡方变量除以各自自由度的比值

## 统计推断

### 抽样分布

#### 样本均值分布
- 若总体 ~ N(μ,σ²)，则 x̄ ~ N(μ, σ²/n)
- **中心极限定理**：n 足够大时，x̄ 近似正态分布

#### 样本方差分布
- (n-1)s²/σ² ~ χ²(n-1)

### 参数估计

#### 点估计
- **矩估计法**：用样本矩估计总体矩
- **最大似然估计**：使似然函数最大化的参数值

#### 区间估计
- **置信区间**：以一定置信水平包含真值的区间
- **常用区间**：
  - 均值（σ已知）：x̄ ± z_(α/2) × σ/√n
  - 均值（σ未知）：x̄ ± t_(α/2) × s/√n
  - 比例：p̂ ± z_(α/2) × √(p̂(1-p̂)/n)

### 假设检验

#### 基本步骤
1. 建立原假设 H₀ 和备择假设 H₁
2. 选择显著性水平 α
3. 计算检验统计量
4. 确定拒绝域或计算 p 值
5. 做出决策

#### 常见检验

**1. 均值检验**
- Z检验（σ已知或大样本）
- t检验（σ未知，小样本）

**2. 比例检验**
- Z检验

**3. 方差检验**
- 卡方检验

**4. 两样本检验**
- 独立样本 t 检验
- 配对样本 t 检验
- 两比例 Z 检验
- F 检验（方差比）

### 回归分析

#### 简单线性回归
- **模型**：Y = β₀ + β₁X + ε
- **最小二乘法**：最小化残差平方和
- **估计**：
  - β̂₁ = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
  - β̂₀ = ȳ - β̂₁x̄

#### 模型评估
- **R²**：决定系数，解释变量比例
- **标准误差**：估计的标准差
- **t检验**：系数显著性

#### 多元回归
- **模型**：Y = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ + ε
- **矩阵形式**：Y = Xβ + ε

## 数据可视化

### 图表类型

#### 单变量
- **直方图**：连续数据分布
- **条形图**：分类数据频数
- **饼图**：比例构成
- **箱线图**：五数概括（最小值、Q1、中位数、Q3、最大值）

#### 双变量
- **散点图**：两连续变量关系
- **折线图**：时间序列
- **热力图**：相关性矩阵

### 选择指南
| 数据类型 | 推荐图表 |
|----------|----------|
| 分类数据 | 条形图、饼图 |
| 连续数据 | 直方图、箱线图 |
| 时间序列 | 折线图 |
| 相关性 | 散点图、热力图 |
