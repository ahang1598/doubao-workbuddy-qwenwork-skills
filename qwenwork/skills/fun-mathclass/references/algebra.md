# 代数参考资料

## 基础代数

### 变量与表达式
- **变量**：表示未知数的符号（通常用 x, y, z）
- **常数**：固定不变的数值
- **系数**：变量前面的数值因子
- **代数表达式**：由变量、常数和运算符组成的式子

### 代数术语
| 术语 | 定义 | 示例 |
|------|------|------|
| 项 | 由加减号分隔的部分 | 3x, -5y, 7 |
| 同类项 | 变量部分相同的项 | 3x 和 5x |
| 多项式 | 多个项的和 | 3x² + 2x - 7 |
| 次数 | 变量的最高指数 | x³ + 2x 的次数是 3 |

### 运算规则

#### 合并同类项
- 只合并变量部分完全相同的项
- 系数相加，变量部分不变
- 示例：3x + 5x = 8x，但 3x + 5y 不能合并

#### 分配律
- a(b + c) = ab + ac
- a(b - c) = ab - ac
- 示例：3(x + 4) = 3x + 12

## 方程

### 一元一次方程
- **标准形式**：ax + b = c
- **解法步骤**：
  1. 去括号（如有）
  2. 移项（将含x的项放一边，常数项放另一边）
  3. 合并同类项
  4. 系数化为1

**示例**：
```
3x + 7 = 22
3x = 22 - 7
3x = 15
x = 5
```

### 一元二次方程
- **标准形式**：ax² + bx + c = 0 （a ≠ 0）
- **求根公式**：x = [-b ± √(b² - 4ac)] / 2a
- **判别式**：Δ = b² - 4ac
  - Δ > 0：两个不同实根
  - Δ = 0：一个实根（重根）
  - Δ < 0：无实根（有复根）

### 因式分解法
- **原理**：若 ab = 0，则 a = 0 或 b = 0
- **常见形式**：
  - x² - a² = (x + a)(x - a) （平方差）
  - x² + 2ax + a² = (x + a)² （完全平方）
  - x² + (a+b)x + ab = (x + a)(x + b)

### 方程组

#### 二元一次方程组
- **代入法**：从一个方程解出一个变量，代入另一个方程
- **消元法**：通过加减消去一个变量

**示例（消元法）**：
```
2x + 3y = 13  ...①
4x - y = 5    ...②

② × 3: 12x - 3y = 15 ...③
① + ③: 14x = 28
x = 2
代入②: 8 - y = 5
y = 3
```

## 不等式

### 基本性质
- 两边加减相同数，不等号方向不变
- 两边乘除正数，不等号方向不变
- 两边乘除负数，不等号方向改变

### 一元一次不等式
- **解法**：类似方程，但注意乘除负数时要变号
- **解集表示**：数轴表示，实心点表示包含，空心点表示不包含

### 不等式组
- **解集**：各不等式解集的交集
- **数轴法**：在数轴上找出所有不等式都满足的区域

## 函数

### 函数基础
- **定义**：每个输入对应唯一输出的关系
- **表示法**：f(x) = ...
- **定义域**：所有有效输入值的集合
- **值域**：所有可能输出值的集合

### 一次函数
- **形式**：f(x) = mx + b
- **图像**：直线
- **斜率**（m）：表示倾斜程度和方向
  - m > 0：向上倾斜
  - m < 0：向下倾斜
  - m = 0：水平线
- **截距**（b）：y轴截距

### 二次函数
- **形式**：f(x) = ax² + bx + c
- **图像**：抛物线
- **开口方向**：
  - a > 0：向上开口，有最小值
  - a < 0：向下开口，有最大值
- **顶点**：(-b/2a, f(-b/2a))
- **对称轴**：x = -b/2a

### 函数变换
- **平移**：
  - f(x) + k：向上平移k个单位
  - f(x) - k：向下平移k个单位
  - f(x + h)：向左平移h个单位
  - f(x - h)：向右平移h个单位
- **伸缩**：
  - a·f(x)：垂直伸缩（|a| > 1 拉伸，0 < |a| < 1 压缩）
  - f(b·x)：水平伸缩
- **反射**：
  - -f(x)：关于x轴反射
  - f(-x)：关于y轴反射

## 指数与对数

### 指数法则
| 法则 | 公式 | 示例 |
|------|------|------|
| 乘法 | a^m × a^n = a^(m+n) | 2³ × 2² = 2⁵ = 32 |
| 除法 | a^m ÷ a^n = a^(m-n) | 2⁵ ÷ 2² = 2³ = 8 |
| 幂的幂 | (a^m)^n = a^(mn) | (2³)² = 2⁶ = 64 |
| 积的幂 | (ab)^n = a^n × b^n | (2×3)² = 4×9 = 36 |
| 零指数 | a⁰ = 1 (a ≠ 0) | 5⁰ = 1 |
| 负指数 | a^(-n) = 1/a^n | 2^(-3) = 1/8 |

### 对数基础
- **定义**：若 a^x = b，则 logₐ(b) = x
- **常用对数**：
  - 常用对数：log₁₀ 或简写为 log
  - 自然对数：logₑ 或 ln
- **定义域**：真数必须为正数

### 对数法则
| 法则 | 公式 | 示例 |
|------|------|------|
| 乘法 | logₐ(MN) = logₐM + logₐN | log(6) = log(2) + log(3) |
| 除法 | logₐ(M/N) = logₐM - logₐN | log(6/2) = log(6) - log(2) |
| 幂 | logₐ(M^n) = n·logₐM | log(2³) = 3·log(2) |
| 换底 | logₐb = logₙb / logₙa | log₂5 = log₁₀5 / log₁₀2 |

## 多项式

### 多项式运算

#### 加法/减法
- 合并同类项
- 示例：(3x² + 2x - 5) + (x² - 3x + 7) = 4x² - x + 2

#### 乘法
- 使用分配律
- 示例：(x + 2)(x + 3) = x² + 3x + 2x + 6 = x² + 5x + 6

#### 除法
- **长除法**：类似数字的长除法
- **综合除法**：适用于除式为 (x - c) 的情况

### 因式分解技巧

#### 提取公因式
- 找出所有项的最大公因式
- 示例：6x² + 9x = 3x(2x + 3)

#### 分组分解
- 将多项式分组后分别提取公因式
- 示例：ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)

#### 二次三项式
- 形式：x² + bx + c
- 找两个数，乘积为c，和为b
- 示例：x² + 5x + 6 = (x + 2)(x + 3)

## 有理表达式

### 定义
- 分子分母都是多项式的分式
- 分母不能为零

### 运算
- **化简**：因式分解后约去公因式
- **乘除**：先因式分解，再约分，最后相乘
- **加减**：先找公分母，再相加减

## 根式

### 性质
- **定义**：ⁿ√a = b 表示 bⁿ = a
- **化简**：√(ab) = √a × √b，√(a/b) = √a / √b
- **有理化**：消除分母中的根号

### 运算
- 只有同类根式（根指数和被开方数相同）才能相加减
- 乘法使用分配律
