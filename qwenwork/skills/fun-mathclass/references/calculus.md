# 微积分参考资料

## 极限

### 极限的定义
函数 f(x) 在 x 趋近于 a 时的极限为 L，记作：
```
lim(x→a) f(x) = L
```

### 极限的性质
- **唯一性**：若极限存在，则唯一
- **局部有界性**：若极限存在，则函数在该点附近有界
- **保号性**：若极限为正，则函数在该点附近为正

### 极限运算法则
若 lim(x→a) f(x) = L，lim(x→a) g(x) = M，则：
- **和差**：lim(x→a) [f(x) ± g(x)] = L ± M
- **乘积**：lim(x→a) [f(x) × g(x)] = L × M
- **商**：lim(x→a) [f(x) / g(x)] = L / M （M ≠ 0）

### 重要极限
- **基本极限**：lim(x→0) sin(x)/x = 1
- **自然常数**：lim(n→∞) (1 + 1/n)ⁿ = e
- **指数极限**：lim(x→0) (eˣ - 1)/x = 1
- **对数极限**：lim(x→0) ln(1+x)/x = 1

### 无穷小与无穷大
- **无穷小**：极限为 0 的变量
- **无穷大**：绝对值无限增大的变量
- **比较**：高阶、同阶、等价无穷小

### 连续性
- **定义**：lim(x→a) f(x) = f(a)
- **间断点分类**：
  - 可去间断点
  - 跳跃间断点
  - 无穷间断点

## 导数

### 导数的定义
函数 f(x) 在点 x 处的导数：
```
f'(x) = lim(h→0) [f(x+h) - f(x)] / h
```

几何意义：**切线的斜率**

### 导数记号
- **拉格朗日记号**：f'(x), y'
- **莱布尼茨记号**：dy/dx, df/dx
- **其他**：ẏ（对时间求导）

### 基本求导公式

| 函数 | 导数 | 示例 |
|------|------|------|
| 常数 c | 0 | d(5)/dx = 0 |
| xⁿ | nxⁿ⁻¹ | d(x³)/dx = 3x² |
| eˣ | eˣ | d(eˣ)/dx = eˣ |
| aˣ | aˣ·ln(a) | d(2ˣ)/dx = 2ˣ·ln(2) |
| ln(x) | 1/x | d(ln x)/dx = 1/x |
| logₐ(x) | 1/(x·ln a) | d(log₂x)/dx = 1/(x·ln 2) |
| sin(x) | cos(x) | d(sin x)/dx = cos x |
| cos(x) | -sin(x) | d(cos x)/dx = -sin x |
| tan(x) | sec²(x) | d(tan x)/dx = sec²x |

### 求导法则

#### 和差法则
```
(f ± g)' = f' ± g'
```

#### 乘法法则（积法则）
```
(fg)' = f'g + fg'
```

#### 除法法则（商法则）
```
(f/g)' = (f'g - fg') / g²
```

#### 链式法则（复合函数）
```
[f(g(x))]' = f'(g(x)) × g'(x)
或 dy/dx = dy/du × du/dx
```

### 高阶导数
- **二阶导数**：f''(x) 或 d²y/dx²
- **n 阶导数**：f⁽ⁿ⁾(x) 或 dⁿy/dxⁿ

### 隐函数求导
对方程 F(x,y) = 0 两边对 x 求导，将 y 视为 x 的函数。

### 参数方程求导
若 x = x(t), y = y(t)，则：
```
dy/dx = (dy/dt) / (dx/dt)
```

### 导数的应用

#### 切线与法线
- **切线方程**：y - f(a) = f'(a)(x - a)
- **法线方程**：y - f(a) = -1/f'(a) × (x - a) （f'(a) ≠ 0）

#### 函数的单调性
- f'(x) > 0：函数单调递增
- f'(x) < 0：函数单调递减
- f'(x) = 0：临界点（可能为极值点）

#### 极值
- **必要条件**：f'(x) = 0 或 f'(x) 不存在
- **第一充分条件**：导数变号
- **第二充分条件**：f''(x) > 0（极小），f''(x) < 0（极大）

#### 凹凸性与拐点
- **凹函数**（向上凹）：f''(x) > 0
- **凸函数**（向下凹）：f''(x) < 0
- **拐点**：凹凸性改变的点，f''(x) = 0 且变号

#### 最优化问题
1. 建立目标函数
2. 求导找临界点
3. 判断极值类型
4. 比较端点和临界点值

#### 相关变化率
1. 建立变量间关系式
2. 对时间 t 求导
3. 代入已知变化率求解

## 积分

### 不定积分

#### 定义
若 F'(x) = f(x)，则 ∫f(x)dx = F(x) + C

#### 基本积分公式

| 被积函数 | 积分结果 | 备注 |
|----------|----------|------|
| xⁿ (n≠-1) | xⁿ⁺¹/(n+1) + C | |
| 1/x | ln\|x\| + C | |
| eˣ | eˣ + C | |
| aˣ | aˣ/ln(a) + C | |
| sin(x) | -cos(x) + C | |
| cos(x) | sin(x) + C | |
| sec²(x) | tan(x) + C | |
| 1/(1+x²) | arctan(x) + C | |
| 1/√(1-x²) | arcsin(x) + C | |

#### 积分方法

**1. 换元法（第一类）**
```
∫f(g(x))g'(x)dx = ∫f(u)du = F(u) + C = F(g(x)) + C
```

**2. 换元法（第二类）**
令 x = g(t)，则 dx = g'(t)dt

**3. 分部积分法**
```
∫u dv = uv - ∫v du
```
选择 u 的顺序（LIATE法则）：对数、反三角、代数、三角、指数

**4. 有理函数积分**
- 部分分式分解
- 分项积分

**5. 三角函数积分**
- 三角恒等变换
- 万能代换 t = tan(x/2)

### 定积分

#### 定义（黎曼和）
```
∫[a,b] f(x)dx = lim(n→∞) Σ(i=1 to n) f(xᵢ)Δx
```

#### 几何意义
曲线 y = f(x) 与 x 轴在 [a,b] 上围成的有向面积

#### 微积分基本定理
**第一基本定理**：
若 F(x) = ∫[a,x] f(t)dt，则 F'(x) = f(x)

**第二基本定理**：
∫[a,b] f(x)dx = F(b) - F(a) = F(x)|[a,b]

#### 定积分性质
- **线性性**：∫(αf + βg) = α∫f + β∫g
- **区间可加性**：∫[a,b] + ∫[b,c] = ∫[a,c]
- **对称性**：∫[a,b] = -∫[b,a]
- **零长度**：∫[a,a] = 0

#### 定积分应用

**1. 面积计算**
- 曲线与 x 轴：A = ∫[a,b] |f(x)|dx
- 两曲线之间：A = ∫[a,b] |f(x) - g(x)|dx

**2. 体积计算**
- **圆盘法**：V = π∫[a,b] [f(x)]²dx
- **壳层法**：V = 2π∫[a,b] x·f(x)dx

**3. 弧长**
```
L = ∫[a,b] √(1 + [f'(x)]²) dx
```

**4. 旋转曲面面积**
```
S = 2π∫[a,b] f(x)√(1 + [f'(x)]²) dx
```

**5. 物理应用**
- 功：W = ∫F(x)dx
- 质心：x̄ = (∫x·f(x)dx) / (∫f(x)dx)
- 转动惯量

### 反常积分

#### 无穷区间
```
∫[a,∞] f(x)dx = lim(b→∞) ∫[a,b] f(x)dx
```

#### 无界函数
```
∫[a,b] f(x)dx = lim(ε→0⁺) ∫[a+ε,b] f(x)dx
（若 f 在 a 处无界）
```

#### 收敛判别
- **比较判别法**
- **p-积分**：∫[1,∞] 1/xᵖ dx，p > 1 收敛
- **绝对收敛与条件收敛**

## 微分方程基础

### 基本概念
- **阶**：方程中出现的最高阶导数的阶数
- **度**：最高阶导数的幂次
- **解**：满足方程的函数
- **通解**：含任意常数的解
- **特解**：给定初始条件的特定解

### 一阶微分方程

#### 可分离变量
```
dy/dx = f(x)g(y) → dy/g(y) = f(x)dx
```

#### 齐次方程
```
dy/dx = f(y/x)，令 u = y/x
```

#### 一阶线性方程
```
dy/dx + P(x)y = Q(x)
```
解法：积分因子 μ(x) = e^(∫P(x)dx)

### 二阶线性微分方程

#### 常系数齐次方程
```
ay'' + by' + cy = 0
```
特征方程：ar² + br + c = 0
- 两不同实根：y = C₁e^(r₁x) + C₂e^(r₂x)
- 重根：y = (C₁ + C₂x)e^(rx)
- 共轭复根：y = e^(αx)(C₁cos βx + C₂sin βx)

## 级数

### 数项级数

#### 基本概念
- **级数**：Σ(n=1 to ∞) aₙ = a₁ + a₂ + a₃ + ...
- **部分和**：Sₙ = a₁ + a₂ + ... + aₙ
- **收敛**：lim(n→∞) Sₙ = S 存在

#### 收敛判别法
- **必要条件**：若收敛，则 lim aₙ = 0
- **比较判别法**
- **比值判别法**（达朗贝尔）
- **根值判别法**（柯西）
- **积分判别法**
- **交错级数判别法**（莱布尼茨）

#### 重要级数
- **几何级数**：Σrⁿ，|r| < 1 时收敛于 1/(1-r)
- **p-级数**：Σ1/nᵖ，p > 1 时收敛
- **调和级数**：Σ1/n，发散

### 幂级数

#### 定义
```
Σ(n=0 to ∞) aₙ(x-c)ⁿ
```

#### 收敛半径
- **比值法**：R = lim |aₙ/aₙ₊₁|
- **根值法**：R = 1/lim sup |aₙ|^(1/n)

#### 泰勒级数
```
f(x) = Σ(n=0 to ∞) f⁽ⁿ⁾(c)/n! × (x-c)ⁿ
```

#### 麦克劳林级数（c = 0）
常见展开：
- eˣ = 1 + x + x²/2! + x³/3! + ...
- sin(x) = x - x³/3! + x⁵/5! - ...
- cos(x) = 1 - x²/2! + x⁴/4! - ...
- ln(1+x) = x - x²/2 + x³/3 - ... （|x| < 1）
- 1/(1-x) = 1 + x + x² + x³ + ... （|x| < 1）

#### 傅里叶级数
周期函数的三角级数展开：
```
f(x) = a₀/2 + Σ(aₙcos(nx) + bₙsin(nx))
```
