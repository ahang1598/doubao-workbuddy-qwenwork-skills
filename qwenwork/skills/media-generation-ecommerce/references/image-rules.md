# 图片任务规则

模型选择见 `model-routing.md`，选区编辑见 `mask-edit.md`。

## 1. 文字渲染判定与可见文字语言锁定

满足任一条件时，按文字渲染处理，当前可优先尝试 `open-image-2`；最终仍需检查文字效果与所需规格：

- 业务词：功能图、卖点图、营销海报、详情页文案、标注、说明图、产品说明。
- 用户给出了画面中应出现的具体中文，如“价格 ¥99”“夏日特惠”“全屋净化”。
- 用户提到中国大陆电商平台（淘宝、天猫、拼多多、京东、抖音、小红书），且任务涉及文字。

**不算文字渲染**：去文字、去字、不要文字、擦除水印、去掉字幕。这些是删除图中已有的文字，不要因此改用 open-image-2；同时命中选区编辑或用户点名模型时，按对应规则处理。

`banana-image-2` 也能生成画内文字（含中文），具体效果应以当前结果为准。当前可用模型中它更适合所需比例、用户点名或选择它时，照样把文字写进 prompt。默认让图片模型在同一次生成中写出画内文字；用户明确要求本地后期排版时，按其工作流处理。

命中文字渲染后，还要锁定可见文字的语言和文案来源：

1. **默认简体中文**：用户原文或调用技能的任务含中文卖点、中文尺码字段、中文洗护说明、国内平台，或调用技能要求可见文字为简体中文时，新增的说明性文字默认使用简体中文。自行编写 prompt 时写明：「新增的说明性文字使用简体中文；品牌名、型号及用户指定文案保持原样，避免英文模板词、乱码和不可读字符」。调用技能提供完整 prompt 时按第 3 节保留正文；若它与用户最新文案或语言要求冲突，先核实再提交，不擅自改写。
2. **保留指定语言**：用户或调用技能指定的英文、多语言文案，以及品牌名、型号和商标，按原文保留。Amazon listing、跨境、SHEIN、Temu、独立站等场景的可见文字语言以具体平台和用户要求为准。
3. **可见文字清单优先**：调用技能传入了可见文字清单时，逐字使用其中的标题、卖点、尺码字段、数据、洗护条目，不翻译、不摘要、不替换近义词。
4. **禁止英文模板词泄漏**：中文场景下，不得把 `SIZE CHART`、`CARE INSTRUCTION`、`STYLING SUGGESTIONS`、`Garment Length`、`Machine Wash Cold`、`label`、`text labels`、`typography-ready`、`space for text` 等英文说明词写成画面中的可见文字，改用“尺码参考”“洗护说明”“搭配建议”“衣长”等中文。
5. **禁止英文占位图**：用户已给数据，或说「数据可以直接填入」时，直接生成带用户给定数据的图片，不要生成留白、等后期填字的图。用户明确要求无字、留白或后期自己加字时，可以留白，并在 prompt 中写「画面中不要出现任何文字」。

这些规则只约束可见文字的语言和文案，不要求 OCR 校验。生成后肉眼发现明显的英文混入、乱码或文字不可读时，按第 6 节处理。

## 2. 在底图上叠加文字

用户说“图片 N 上方文字内容：……”“在图片 N 上方加文字”“在图片 N 顶部添加标题”“给图片 N 加封面字”“在图片 N 侧边加字”等时，含义是以图片 N 为底图、在原图内部安全区叠加文字，不是单独生成文字标题卡，也不是把图片 N 当作风格参考。

- **底图**：被点名的图片 N 就是底图，放在 `images` 第一位；其他图按用户指定的文字风格、排版、装饰、商品或 Logo 等角色放在后面，不擅自换底图。
- **参数**：优先考虑 `open-image-2` 的 `edit`，按 `model-routing.md` 的规则构造自定义尺寸；3:4 等比例可直接使用合法尺寸。未锁定模型、而所需比例或像素规模超出该模型边界时，可改用能满足要求的模型（本表可考虑 `banana-image-2` 的 `edit`），并说明选择原因。不要把任务改成没有底图的文生图。
- **prompt 约束**：用户只要求在原图内部加字、没有指定底色或扩画布时，写明「以图片 N 为底图，在原图内部安全区域叠加文字『……』；尽量保留原图背景、人物／商品、光线、构图、比例和主体位置；不额外新增底色、标题卡或画布」。用户指定底色、白边或其他版式时，按其要求调整；生成后检查底图内容是否仍符合请求。
- **多图时**：如果用户说“参考图片 1 的文字风格，在图片 2 上方加文字”，图片 2 是底图，图片 1 是风格参考；成品必须仍能看到图片 2 的原图内容。
- **不要预先扩画布**：不要先在本地把原图贴进更大的画布，再交给模型整图回写。这样常导致未授权的纯色背景条、主体被挤压、原图比例和构图被改写。只有用户明确要求加白底文字条、加宽边留白、在原图外补画布时，才允许预先补边。

这条规则是把用户明确的编辑意图完整交给模型，优先于第 3 节“不主动追加约束”的通用要求。

## 3. prompt 的传递

- **内容来源**：内容语义来自用户当前有效的意图。不擅自改写、翻译、追加或增强，只允许补充模型执行所需的功能性、结构性约束。文字渲染按第 1 节处理；选区编辑按 `mask-edit.md` 的结构白名单处理。缺少必要的生成目标时先确认，不自行补全。
- **调用技能交来的 prompt**：非选区任务原样提交，不压缩、概括、删段、翻译、截断，也不把调用技能逐项写清的版型、体积、材质光泽、结构、五金描述改写成品类、风格或评价词。任务单缺少必填参数时补参数，不动 prompt 正文。选区任务的内容语义同样只能来自用户意图，见 `mask-edit.md`。
- **删除、去除类诉求**：照抄用户对删除对象和范围的表达，不把“水印”扩大成“文字”，不把局部扩大成全图；含义不明确时先确认。
- **不为扩写 prompt 而看图**：不为了丰富画面属性去分析图片。选区格式、极性、对齐和覆盖验收所需的检查不受此限，但观察结果不得写成新的 prompt 属性。

## 4. 参数继承

有输入图、且用户没有指定比例、分辨率或尺寸时，以底图或第一张主参考图的比例和像素规模为参考，在当前模型支持的取值内选择：

- 先按这个比例选模型：`open-image-2` 可用合法自定义尺寸覆盖 1:3–3:1 内的比例，包括 3:4。未锁定模型、而所需比例或像素规模超出首选模型边界时，可选能满足要求的模型，文字场景也一样；不要先出近似尺寸再裁切。
- banana-image-2：比例取最接近的可用比例；分辨率优先取不低于输入像素的最近一档。没有满足条件的档位时，说明当前输出上限，不承诺保持原像素规模。
- open-image-2：底图尺寸符合自定义规则时可原样传 `size`；否则在合法的 16 倍数尺寸中尽量接近底图比例和像素规模。无法保持时说明差异，不把旧预设当成唯一可选值。

没有可参考的输入比例、且用户也未指定平台或比例时，非「微小修改、重试、一键默认」的任务先一次性确认：目标平台或使用场景、比例、是否带文字（中文、英文或多语言）。

## 5. 样张确认后批量处理：只继承规格，不继承主体

用户先做 1 张、确认后说「其他也这样」「全部处理」「按这个效果继续」，或一次给一组图要求各出一张时，默认用样张锁定处理方法和输出规格；除非用户明确要求复用样张主体，不自动把它的主体套到其他图片。

- **可以继承**：背景、尺寸、比例、格式、画质、构图、光照、处理方法。
- **默认不继承的主体事实**：颜色、款式、材质、图案、Logo、文字、结构、人物身份、物体类别；逐图处理时以当前输入图为准，用户另有明确要求时遵照其要求。

逐图处理时，每张图单独提交一个任务，以当前输入图为主体参考。prompt 表达「保留本图主体、套用样张规格」，不要未经用户要求把样张的主体描述复制到别的图上。提交前自查：每个任务的输入图、prompt 所指主体和产物名一致；输入图不同却用了相同的主体描述时，先暂停复核。

## 6. 成功判定与失败处理

- **成功的必要条件**：任务成功，且结果里有可用的图片文件。任务显示成功但没有图片、文件为空，都按失败处理；不要把原始输入图当作生成结果交付。
- **服务失败**：同一模型、同一参数最多重试一次。不要静默切换模型：用户点名的模型、已确认的方案需要换模型时，先说明原模型失败的原因，再按用户意见执行。
- **内容审核拦截**：说明该张未通过审核及上游给出的原因；可以把换用另一个兼容模型作为选项交给用户，用户选择后再换。不要为了绕过审核擅自改写 prompt。批量任务中某张失败只影响该张，其他照常推进。
- **产物自检**：交付前把实际结果和本次声明的规格、提交参数、平台规范逐项对照；服务端回落成默认值时主动说明，并修复或建议重试。

## 7. 先出计划还是直接执行

被其他技能调用时，执行调用技能的计划，不重复出计划。本技能直接承接用户请求时：

- **直接执行**：用户说清楚了要生成或编辑什么、参考哪张图、改或保留哪些区域，只有一条明确路径；多张图只是同一操作的批量（统一改色、去水印、换白底、同一样式套到多张图）；用户只要单张、直接生成、重试或微调，且素材角色清楚。
- **先整理方案，必要时确认**：用户只给期望结果、尚未明确画面结构或实现路径；多张产物的职责、参考图角色、多个商品的位置或多阶段顺序还存在会影响结果的未决选择时，先整理关键方案。用户已给出明确方案或要求直接执行、且素材角色清楚时，沿用其意图，不重复索取确认。

方案可简要写明生成目标、素材角色、输出结构、执行步骤和关键自检；只有关键选择仍缺失时再请用户确认。只是缺少比例、分辨率等参数时，按第 4 节补齐即可。
