# 视频提示词指南

数值约束见 `video-constraints.md`，参考素材筛选见 `video-rules.md` 护栏 D。

> **语言**：中文电商请求的描述性 prompt 默认用中文，便于用户核对；用户或调用技能指定其他语言时按其要求。画面文字、口播、字幕，以及品牌名、产品型号和商标均保留用户指定的原文。不要仅因为猜测模型偏好而翻译已确认的内容。

把视频 prompt 拆成 4 层来写：**主体**、**动作/事件**、**画面与风格**、**视听控制**。绝大多数视频任务都可以先用这套公式起稿，再按是否有参考素材补充约束。

## 一、基础公式

```text
主体 + 动作/事件 + 场景/风格 + 镜头/节奏 + 声音/文字 + 质量/约束
```

最小可用版：

```text
谁/什么，在什么场景里，做什么，镜头怎么拍，整体什么氛围。
```

推荐写法：

```text
一只银色保温杯放在暖调家居餐桌上，镜头从中景缓慢推近到近景，一只手自然拿起杯子并轻微旋转展示杯身，光线柔和，背景干净，质感真实，节奏平稳。
```

## 二、六个核心维度

### 1. 主体

先说清楚谁是主角，避免模型误判关注点。

- 人物：年龄、性别、造型、服装、身份、情绪
- 商品：品类、材质、颜色、结构特征、摆放方式
- 场景主体：建筑、车辆、动物、道具、品牌元素

示例：

```text
一个穿白色西装的短发女性
一台银黑色复古相机
一匹金色骏马
```

### 2. 动作与事件

动作决定视频感。优先写连续动作，而不是静态名词堆砌。

- 单一动作：走、跑、转身、抬手、拿起、靠近、回头
- 连续动作：先 A，再 B，最后 C
- 互动关系：谁对谁做什么，谁回应什么
- 变化过程：从白天到夜晚、从静止到爆发、从近到远

示例：

```text
女孩拿起杯子看向镜头，轻轻微笑，然后转身离开窗边。
镜头先展示相机正面，再环绕到侧面和背面。
```

### 3. 场景、光线与风格

这部分决定“看起来像什么”。没有明确风格时，至少写清场景、时间和光线。

- 场景：办公室、街头、咖啡馆、草原、未来都市、纯白棚拍
- 光线：柔和自然光、逆光、霓虹、清晨薄雾、电影感低照度
- 风格：写实、广告片、手绘漫画、3D 动画、赛博朋克、复古胶片
- 色调：暖色、冷色、高饱和、低饱和、黑金、奶油色

示例：

```text
背景是霓虹闪烁的未来都市空中廊道，整体为 3D 赛博朋克动画风格。
暖调居家场景，柔和自然光，真实广告片质感。
```

### 4. 镜头与节奏

视频 prompt 和图片 prompt 的关键差异在这里。镜头语言越明确，结果越稳定。

- 景别：大全景、中景、近景、特写
- 运镜：推近、拉远、平移、环绕、俯冲、跟拍、横摇、定格
- 节奏：缓慢、平稳、迅速、逐渐、突然、连续切换
- 结构：开场画面、过程变化、结尾定格/淡出/虚化

示例：

```text
镜头以特写开场，缓慢推近，最后定格在产品 logo 上。
第一视角俯冲进入园区，随后平稳抬升，展示整体空间结构。
```

### 5. 声音与文字

需要声音或上屏文字时，直接写进 prompt，不要只写“加点音乐”。

- 旁白：谁说、说什么、语气如何
- 对白：角色 A 说什么，角色 B 如何回应
- 背景音：轻爵士、城市环境音、风声、激烈鼓点
- 上屏文字：字幕、广告语、气泡台词、logo 出现方式

示例：

```text
一个平静的男声旁白说：“在宏大的宇宙中，我们的世界不过是一个短暂的瞬间。”
画面底部同步出现中文字幕。
后画面逐渐模糊，画面中部显示文字“快乐尽在每一天”。
```

### 6. 质量与硬约束

最后补“不能丢”的约束，避免模型自由发挥过头。

- 主体特征一致，不要改变服装/颜色/结构
- 背景简洁干净，不要出现杂物
- 动作自然，不要夸张变形
- 运镜平稳，不要频繁跳切
- 其他内容保持不变

示例：

```text
保持人物五官与发型一致。
保持图 1 中商品的颜色、材质和 logo 不变，背景中不出现其他商品。
```

## 三、参考图怎么写

使用参考图时，prompt 里必须明确“参考什么”。只上传图片不指代，控制力会明显下降。

常见用途：锁定主体形象、商品结构、服装、logo、分镜构图、场景氛围。

推荐模板：

```text
参考图片 1 中的主体/构图/服装/场景，生成……，保持……一致。
```

**商品/服装/包装保真写法**：

当参考图片用于锁定商品、服装、配饰或包装的颜色和细节时，先写商品锚点，再写动作、场景和镜头。商品锚点只写用户明示或视觉分析真实支持的事实；不要根据品类常识、模特图、场景光线或脚本摘要补出颜色和结构。看不准时不要猜，要求模型沿用图 N 中可见的商品事实，并在交付前检查结果。

```text
商品锚点：以图 N 中的<商品/服装>为依据，保持真实颜色、材质、版型、开合状态和可见细节；不要主动改变拉链/纽扣/口袋/拼接/五金、logo/印花/文字等商品事实。
```

错误写法：源图未确认颜色时写“黑色外套 / 白色包装 / 灰色鞋面”等猜测词。即使后面再写“保持颜色不变”，前面的错误颜色也会覆盖源图事实。

**只锁身份不借姿态（护栏 D 多姿态筛选时用，身份图与镜头姿态不符但保留时套用）**：

```text
参考图片 N 中主体的五官/发型/服装/造型形象，**不要参考其姿态/动作**，生成……
```

示例：

```text
参考图片 1 中的女孩形象，生成她在咖啡店吃蛋糕的画面，保持发型和五官一致。
参考图片 1 中的 logo，在结尾淡入显示于画面右下角。
参考图片 1 的分镜构图，按顺序依次出现每个镜头。
```

## 四、按任务类型写 prompt

### 1. 文生视频

适合没有参考素材、主要靠描述生成。

模板：

```text
主体 + 动作 + 场景 + 运镜 + 光线风格 + 声音/文字 + 约束
```

示例：

```text
夜晚的东京街头，雨水落在地面形成倒影，镜头缓慢前移穿过人群，霓虹灯不断闪烁，整体电影感写实风格，无对白，只有城市环境音。
```

### 2. 图生视频

适合先锁定主视觉，再让画面动起来。

当用户说「live 图 / live 动效 / 图片动起来 / 约 3s」时，优先理解为类似 Live Photo 的轻微图生视频：以原始图片为首帧和主视觉锚点，只让人物表情、头发、衣摆、光影或环境元素产生小幅自然运动。prompt 写清希望沿用的主体身份、真人／商品质感、画风、构图、文字、背景和比例；若用户只要轻微动效，不写成大幅动作或全新剧情。约 3 秒是时长意图，实际取值先核对当前模型约束，不静默改时长。

模板：

```text
参考图片 1 中的主体，生成……，保持主体特征一致；镜头……；整体……。
```

示例：

```text
参考图片 1 中的产品，产品位于画面中央，镜头缓慢环绕展示产品全貌，光线柔和自然，背景简洁干净，突出材质细节。
```

想从已有片段的结尾画面起步时，可抽取上一段末帧作为首帧，在 prompt 中写清后续动作以及希望沿用的主体、光线和运镜方向；生成后检查实际衔接效果。

### 3. 多图参考

适合把人物、服装、场景、logo 拆开控制。

模板：

```text
图片 1 中的人物穿着图片 2 中的服装，出现在图片 3 中的场景里，图片 4 中的 logo 始终显示在右下角。
```

写法原则：

- 写清每张图的主要用途；一张图同时承担身份、服装等多项职责时，在 prompt 中分别说明，不必为每项职责再添一张图
- 先说主次关系，再说组合方式
- 有顺序要求时，明确写“按顺序”
- 商品/服装/配饰/包装源图承担保真职责时，先把该图的商品锚点放在 prompt 前部；商品颜色、材质、版型和局部结构不得从其它人物图、场景图或风格图继承。
- **同主体多姿态不等于多个独立元素**：多张姿态图可能包含重复的身份信息。通常先选清晰的身份图，必要时增加互补角度；其余图片按镜头起始或关键动作、用户指定角色及输入上限筛选。明显冲突但用户要求使用的图应先说明取舍，详见 `video-rules.md` 护栏 D 与本文第九节。
- **张数按信息需要和输入上限确定**：一张图可承担多项职责，同一职责也可能需要少量互补图；上传数量本身不是目标。
- 以已有视频为基础重新生成时，从视频抽出的关键帧也是参考图：按它在 `reference_images` 中的位置写“图 N”，不写“视频 1”；源视频的动作、运镜和节奏用文字写进 prompt。

### 4. 文字上屏

适合广告片、解说片、带字幕视频。

常见模板：

```text
画面中部/底部出现文字“……”，在……时机出现，以……方式出现。
角色说：“……”，画面底部同步出现字幕。
角色说话时周围出现气泡，气泡中写着对应台词。
```

## 五、实用技巧

### 1. 先主体，后风格，最后约束

顺序建议：先确定「谁在做什么」，再补「看起来像什么」，最后补「不要变什么」，通常更便于核对。

### 2. 连续动作比抽象气质更有效

与其写“画面很高级、很有张力”，不如写“镜头从近景推到特写，人物转头看向窗外，停顿一秒后继续前行”。

### 3. 参考素材一定要点名用途

不要只写“参考图片 1”。要写“参考图片 1 中的构图”或“参考图片 1 中的人物形象”。

### 4. 基于已有画面改写时说明保留项

以原图为首帧，或以原片关键帧为参考重新生成时，写清希望沿用的主体、背景和镜头要素；生成后仍要检查，不能假定局部之外保持原样。

### 5. 文字需求要写清内容、位置、时机、风格

只写“加字幕”通常不够，最好补上是否同步音频、出现在底部还是中部、是否需要气泡或 slogan。

### 6. 复杂任务先拆成镜头语言

如果需求很长，先按“开场 - 过程 - 结尾”写成 2 到 4 个连续片段，再串成一个 prompt。

## 六、常见问题

### 1. 生成结果主体不稳定

补主体特征和一致性约束；有参考图时明确写“保持主体特征一致”。

### 2. 动作不明显或不像视频

补连续动作、镜头运动和节奏词，少写静态形容词。

### 3. 多参考素材混乱

写清每张参考图的主要职责；同一张图同时承载人物和服装等信息时，可分别点名其用途。

### 4. 修改任务改动过大

写清希望沿用的内容和只想替换的元素；参考生成的动作、运镜和其他画面仍需检查。

### 5. 文字上屏效果不理想

先补充文字出现的位置、时机和方式。文案未锁定时，可建议使用更常见的字词；用户或任务单已指定文案时，不改词，先按原文重试或说明生成模型的文字局限。

## 七、一个通用起稿模板

```text
参考图片 1 中的主体，生成一段……视频。主体位于……，先……，再……，最后……。场景为……，光线……，整体风格……。镜头……，节奏……。声音/旁白/字幕……。尽量沿用……等已确认的画面要素。
```

这份指南用于**把需求写清楚**。真正执行时，仍需结合当前模型的参数能力、输入上限和素材引用规则；数值约束以 `video-constraints.md` 为准，提交示例见 SKILL.md。

## 八、有声视频处理（要旁白／配音／音效／BGM 时必读）

要「有声 / 旁白 / 配音 / 音效 / BGM」时，若模型未锁定、且当前接口支持原生音轨，可优先使用 `seedance-2.0` + `generate_audio: true`，并把声音要求写进 prompt（谁说、说什么、语气、背景音氛围、是否希望音画同步）。用户锁定的模型不支持音轨时，先说明限制，不静默换模型。

- 普通视频旁白和音效优先考虑原生有声，避免未经核对就叠加独立声轨。如果用户明确要「语音合成 / 配音文件」，应说明需要独立音频或后期链路。用户指定独立配乐并接受合成时，可按当前执行层能力完成合成，核对原声、时长和音量；用户只要单独配乐时，可提交音乐任务。
- 声音要求写进 prompt 结尾的"视听控制"段，例：
  - 旁白：`音频/旁白描述：成熟知性女声普通话画外音，语速沉稳，念出："……"，伴随空灵的现代都市电子乐，音画同步。`
  - 音效：`音频/特效描述：快切的史诗运动配乐，伴有风声、踩雪与碎石飞溅的原生自然音效。`
- 本包所述 `happy-horse-1.0` 工具没有音轨控制；需要有声、且模型未锁定时可考虑 `seedance-2.0`。用户锁定 Happy Horse 时，先说明声音无法在当前工具中控制，再按用户选择处理。

## 九、多素材点名（与字段顺序严格对应）

**先筛后点名（`video-rules.md` 护栏 D）**：点名对象 = **实际传进 `reference_images` 的图（筛选后剩余的）**，不是用户原始上传的全部。流程：① 先按本镜头意图列视觉职责清单；② 按用户最新要求、身份锚定需要和当前输入上限筛选候选图；③ 把留下的图按出现顺序放入 `reference_images`；④ 就该列表逐张编号点名职责。未提交的图不在 prompt 中占编号；编号按最终数组顺序确定。

`reference_images` 里的「图 N」**按列表出现顺序一一对应**，prompt 里必须逐张点名职责（"图 1 的主体 / 图 2 的服装 / 图 3 的动作"）；禁止"参考这些素材生成好看视频"这类含糊指令——编号错位导致素材错配。

### 反例：5 张同主体图全塞当 identity（典型坑）

用户上传 5 张同一女孩的不同姿态图（图 1 正面倚沙发 / 图 2 侧面 / 图 3 背影漫步 / 图 4 坐姿托腮 / 图 5 站立微笑），本镜头 prompt 是「女孩坐在沙发上托腮 → 起身 → 走向白墙触摸光斑 → 仰头感受阳光」（复合动作链，全程正面/侧面）。

**容易出问题的做法**：5 张全塞 `reference_images`，prompt 写「参考图 1 至图 5，女孩形象完全一致……」——背影漫步（图 3）、站立微笑（图 5）的肢体信号可能与「坐 → 触摸光影」的镜头意图冲突，增加姿态污染和身份漂移的风险。

**本例的一种选法**（用户未要求全部使用，且输入上限允许）：
- 职责清单：① 身份（女孩形象）② 坐沙发托腮起始姿态 ③ 起身走向白墙 + 侧身触摸光斑的侧身/手部动作
- 图 1（正面倚沙发，五官发型服装信息最全）→ 可作身份锚定图
- 图 2（侧面，承担「侧身触摸光斑」的侧身／手部动作）→ 可作关键动作参考
- 图 4（坐姿托腮，匹配镜头起始姿态）→ 可作起始姿态参考
- 图 3（背影漫步，与镜头全段正面／侧脸要求不符，身份信息与图 1 重复）→ 本例暂不提交
- 图 5（站立静态微笑，与本镜头起始和转折动作都不匹配，身份信息重复）→ 本例暂不提交

本例最终提交 3 张时，prompt 只点名这 3 张：「图 1 的女孩（仅参考其五官／发型／服装形象，不借用倚靠姿态）像图 3 那样坐在沙发上托腮，起身像图 2 那样侧身走向白墙，伸手触摸墙上光斑，仰头感受阳光……」。编号按最终数组顺序确定（图 1＝正面倚沙发，图 2＝侧面，图 3＝坐姿托腮）。若用户明确要求使用原图 3 或图 5，先说明它们可能带来的姿态干扰，再按最新要求和输入上限处理。
