# 视频约束

下表记录随包发布时的视频模型取值和素材约束。字段和数值是否可用，以当前视频工具的 Schema 及服务端实际校验为准。

## 1. 输出参数

### 1.1 seedance-2.0

| 参数 | 取值 |
| --- | --- |
| 模式 | `text_to_video`、`image_to_video`、`first_last_frame_to_video`、`reference_images_to_video` |
| `duration_seconds` | 4–15 的整数；没有自动时长；省略时为 5 |
| `resolution` | `480p`、`720p`、`1080p`、小写 `4k` |
| `aspect_ratio` | `1:1`、`4:3`、`3:4`、`16:9`、`9:16`、`21:9`；无法可靠映射原比例时内部可用 `adaptive`；不能传空字符串 |
| `generate_audio` | 支持；默认开启 |
| `seed` | -1 到 4294967295 |
| 水印、联网检索、固定机位 | 不提供；prompt 中写“机位固定”只能引导，不能承诺 |

标准 Seedance 2.0 的 `4k` 输出为 10-bit H.265 MP4。交付原始文件，不为预览而静默转码或降分辨率；预览无法播放时说明播放器兼容性。`4k` 档位不保证固定的像素宽高，以实际文件为准。

### 1.2 happy-horse-1.0

| 参数 | 取值 |
| --- | --- |
| 模式 | `text_to_video`、`image_to_video` |
| `duration_seconds` | 4–15 的整数；省略时为 5 |
| `resolution` | `720p`、`1080p` |
| `aspect_ratio`、`generate_audio` | 不支持，传了会被拒绝 |
| `seed` | -1 到 4294967295 |

## 2. 输入素材（seedance-2.0）

| 素材 | 约束 |
| --- | --- |
| 图片 | 本地绝对路径（须在当前工作区或已授权目录内）、HTTPS 地址或图片 data URL；jpeg、png、webp、bmp、tiff、gif（本表不含 heic、heif）；宽高比 0.4–2.5；**每边 300–6000 px**（按本包输入检查，见 `video-rules.md` 第 4 节）；单图小于 30 MB |
| 图片张数 | 参考图 1–9 张；首帧 1 张；首尾帧 2 张 |
| 首尾帧 | 有尾帧必须有首帧；本包记录比例不一致时按首帧处理，提交前应核对画面裁切风险并说明取舍 |
| 参考视频、参考音频 | 本表对应的工具 Schema 未提供参考字段；若当前 Schema 仍无，先用媒体理解解析已有素材，再按需抽取关键帧作为参考图或首帧，见 `video-rules.md` 第 4 节 |
| 人脸 | 不接受未经授权的真人人脸，可能被审核拦截；被拦截时按失败处理并告知用户，可请用户换一张已获授权的人像 |

## 3. 输入素材（happy-horse-1.0）

- `image_to_video` 需要 1 张首帧图，格式和尺寸以当前工具 Schema 为准。
- 不支持参考图、尾帧。
