# 子 Agent 翻译提示词模板

两部分：
1. **`prompt.md`** —— 共享上下文（保存到输出目录）。包含背景、术语表、难点和原则，**不含**任务级指令。
2. **子 Agent 启动提示词** —— 启动每个子 Agent 时传入的任务指令。每 chunk 一个子 Agent（不分块时为整份源文一个子 Agent）。

主 Agent 读取 `analysis.md`（如有），把所有相关上下文内联到 `prompt.md`，再并行启动子 Agent，让任务指令引用该文件。

请把 `{占位符}` 替换为实际值。带 "若分析存在" 标记的小节在快翻模式下省略。

---

## Part 1：`prompt.md`（共享上下文，落盘文件）

```markdown
你是一位专业译者。任务：把 markdown 内容从 {source_lang} 翻译为 {target_lang}。

## 目标读者与风格

**读者**：{读者描述}

**目标风格**：{风格描述——例如 "storytelling：叙事流畅、过渡顺滑、措辞鲜活"，或用户自定义风格}

**原文声音**（来自分析，若存在）：{简述原作者的声音——正式 / 口语、是否幽默、语域、句式节奏等}

## 内容背景

{若 analysis.md 存在，从中内联：内容摘要、核心论点、作者背景、写作语境}

## 术语表

请前后一致地使用以下译法。首次出现时附原文括注。

{合并后的术语表——一行一条：英文 → 译文}

## 翻译难点

{若 analysis.md 存在，从其 §1.4 内联。理解断点、修辞、结构难点及建议处理方式：}

- **{术语 / 段落}**：{难点类型} → {建议方法}

## 翻译原则

把内容用自然、有吸引力的 {target_lang} **重写**——而不是直译。每一句都应当像本族语母语作者从零创作。

- **准确为先**：事实、数据、逻辑必须与原文严格一致
- **自然流畅**：使用 {target_lang} 地道的语序。把过长的源句拆成自然的短句。隐喻和习语按意译处理，不逐字直译
- **术语**：按术语表前后一致地使用译法。专业术语首次出现时附原文括注
- **保留格式**：保留所有 markdown 格式（标题、加粗、斜体、图片、链接、代码块）
- **主动解释**：对目标读者可能缺乏背景的术语 / 概念，用 **加粗括号** 加简短解释 `（**解释**）`。批注宁少勿多，仅在确实影响理解时使用
```

## Part 2：子 Agent 启动提示词（作为 Agent 工具的 prompt）

### 分块模式（每 chunk 一个子 Agent，全部并行）

```
请先读取翻译指令：{output_dir}/prompt.md

你正在翻译第 {NN} 块 / 共 {total_chunks} 块。
位置：{该 chunk 的内容简介及其在整体论证中的位置}

翻译步骤：
1. 读取 `{output_dir}/chunks/chunk-{NN}.md`
2. 按 prompt.md 中的指令翻译
3. 保存译文到 `{output_dir}/chunks/chunk-{NN}-draft.md`
```

### 不分块模式

```
请先读取翻译指令：{output_dir}/prompt.md

翻译并保存：
1. 读取 `{source_file_path}`
2. 保存译文到 `{output_path}`
```
