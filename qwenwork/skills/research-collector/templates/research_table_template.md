# 调研表格模板

## 标准表格格式

```markdown
# 技术调研表：[研究方向]

**调研日期**: YYYY-MM-DD
**数据来源**: [来源列表]
**总条目数**: N

---

## 调研明细

| 序号 | 文章/项目名称 | 来源类型 | 发布/更新时间 | 机构/作者 | 核心技术 | 应用场景 | 开源状态 | 引用量/Star | 局限性 | 链接 |
|------|-------------|---------|-------------|----------|---------|---------|---------|-----------|--------|------|
| 1 | | | | | | | | | | |
| 2 | | | | | | | | | | |
```

## 来源类型枚举

- 学术论文
- 百家号
- 微信公众号
- 知乎
- GitHub
- CSDN
- 掘金
- 其他

## 开源状态枚举

- 已开源（附链接）
- 未开源
- 部分开源
- 商业产品

## 统计摘要（追加到表格底部）

```markdown
---

## 统计摘要

- **来源分布**: [各来源数量统计]
- **时间分布**: [各年份/月份数量统计]
- **开源状态**: [各开源状态数量统计]
```
