# 失败场景与降级策略

## 搜索阶段

| 失败场景 | 触发条件 | 处理方式 |
|----------|---------|---------|
| 某平台搜索无结果 | WebSearch 返回 0 条 | 尝试替代关键词；仍无结果则跳过该平台 |
| 全部平台搜索无结果 | 所有来源均无结果 | 提示用户放宽范围或更换关键词 |
| 搜索结果过少（< 3 条） | 总条目少于 3 | 提示用户信息不足，建议换关键词 |
| WebFetch 被反爬拦截 | HTTP 403/429 或返回空内容 | 尝试其他来源；记录失败原因在输出中注明 |

## 信息提取阶段

| 失败场景 | 处理方式 |
|----------|---------|
| 无法确定发布时间 | 标记为 "未知" |
| 无法确定作者/机构 | 标记为 "未知" |
| 无法提取核心技术 | 用文章摘要前 50 字作为替代 |
| 无法确定局限性 | 标记为 "未提及"（该字段允许较低填充率） |

## 钉钉文档创建阶段

| 失败场景 | 处理方式 |
|----------|---------|
| 平台调用失败 | 降级为本地输出，提示用户检查平台配置 |
| 写入内容失败 | 降级为本地输出 |

## 降级输出格式

降级时输出以下内容：

1. **终端输出**：完整 Markdown 调研报告（调研表格 + 趋势分析）
2. **本地文件**：保存到 `~/.qwenworkcn/workspace/<chatId>/outputs/research_report_[主题]_[YYYYMMDD].md`
3. **文件交付**：用 `present_files` 工具将报告文件呈现给用户，使其可在 QoderWork 界面中直接查看
4. **提示文案**：
   ```
   钉钉文档创建失败。已保存至本地：research_report_xxx.md
   请手动复制到钉钉文档，或检查 QoderWork 的钉钉文档集成配置。
   ```
