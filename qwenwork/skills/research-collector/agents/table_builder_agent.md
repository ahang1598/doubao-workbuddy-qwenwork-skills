# Table Builder Agent

## 职责

接收 `search_collector_agent` 输出的结构化文章信息列表，生成调研明细表格和学术趋势分析，合并为完整报告并强制调用 dws 创建钉钉在线文档。

## 执行步骤

### Step 1: 表格生成

将文章信息填充为 Markdown 表格：

```markdown
# 技术调研报告：[研究方向]

**调研日期**: YYYY-MM-DD
**数据来源**: arXiv / Semantic Scholar / GitHub / 百家号 / 微信公众号 / 知乎
**总条目数**: N

## 一、调研明细

| 序号 | 文章/项目名称 | 来源类型 | 发布/更新时间 | 机构/作者 | 核心技术 | 应用场景 | 开源状态 | 引用量/Star | 局限性 | 链接 |
|------|-------------|---------|-------------|----------|---------|---------|---------|-----------|--------|------|
| 1 | ... | ... | YYYY-MM-DD | ... | ... | ... | ... | ... | ... | [链接](url) |
```

### Step 2: 趋势分析（固定输出，不可省略）

在调研表格之后追加：

```markdown
## 二、学术趋势分析

### 2.1 时间趋势
[按季度统计 + 趋势描述]

### 2.2 技术热点
[高频关键词统计]

### 2.3 来源分布
[各来源占比统计]

### 2.4 代表性推荐
1. **[论文/项目名称]** — [推荐理由]
2. **[论文/项目名称]** — [推荐理由]
3. **[论文/项目名称]** — [推荐理由]
```

### Step 3: 合并为完整报告

将 Step 1（调研明细表格）和 Step 2（学术趋势分析）合并为一份完整的 Markdown 报告。

### Step 4: 后续弹窗

使用 `AskUserQuestion` 工具向用户提问（**4 个选项**）：

- **question**: "调研已完成，接下来你想做什么？"
- **header**: "后续操作"
- **options**:
  1. `1. 收集相关文献并速读` — 基于调研报告中的文献列表，快速阅读摘要和核心结论
  2. `2. 对文献原件进行深度分析` — 对单篇或多篇论文进行深度精读、方法论剖析
  3. `3. 对文献进行引文追溯` — 追溯关键论文的引用关系，发现源头研究和后续演进
  4. `4. 暂不需要，生成基础报告即可` — 不触发下游 Skill，仅输出当前调研报告

### Step 5: ⚠️ 强制调用 dws 创建钉钉在线文档

**禁止输出本地 .md 文件。必须强制调用 dws 创建钉钉在线文档。**

1. **根据 Step 4 选择结果确定文档名称**：
   - 选项 1/2/3 → `技术调研报告：[研究方向] - [日期]（科研工作流输出）`
   - 选项 4 → `技术调研报告：[研究方向] - [日期]（通用输出）`
2. **调用 dws 创建文档**，将完整报告内容写入
3. **返回文档链接**给用户

**所有最终产物必须是钉钉在线文档，不可降级为本地文件。**

### Step 6: 返回结果

```
调研完成！

已创建钉钉文档：[技术调研报告：RAG 技术 - 20260508（通用输出）](https://alidocs.dingtalk.com/...)

报告包含：
- 调研明细：15 条
- 时间趋势：[简述]
- 技术热点：[Top 3 关键词]
- 来源分布：[简述]
- 代表推荐：3 篇
```
