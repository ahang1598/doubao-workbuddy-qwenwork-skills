# 舆情主题分类编码表

本文档定义了学校舆情的标准主题分类，供情感分析和报告生成使用。

## 分类列表

| 编码 | 类别 | 典型关键词 | 说明 |
|------|------|-----------|------|
| T01 | 教学质量 | 老师水平、教学、课程、成绩、升学率、教学质量、师资 | 涉及教学内容、教师能力、学术表现 |
| T02 | 校园安全 | 事故、受伤、安全隐患、校车、消防、溺水 | 涉及学生人身安全的事件 |
| T03 | 师德师风 | 体罚、辱骂、不当行为、补课收费、师德 | 涉及教师职业道德 |
| T04 | 食品卫生 | 食堂、饭菜、卫生、变质、中毒、过期食品 | 涉及校园食品安全 |
| T05 | 招生升学 | 录取、分数线、招生、择校、报名、面试、学位 | 涉及入学和升学相关 |
| T06 | 校园欺凌 | 霸凌、欺负、打架、排挤、孤立、网暴 | 涉及学生间的欺凌行为 |
| T07 | 收费问题 | 乱收费、学费、材料费、赞助费、强制消费 | 涉及不合理收费 |
| T08 | 校园活动 | 运动会、文艺演出、比赛、社团、研学 | 涉及学校组织的活动 |
| T09 | 荣誉表彰 | 获奖、表彰、优秀、先进、金牌、冠军 | 涉及学校或师生获得荣誉 |
| T10 | 基础设施 | 校舍、操场、宿舍条件、教室环境、装修 | 涉及学校硬件条件 |
| T11 | 管理制度 | 校规、管理、处分、请假、手机管理 | 涉及学校管理规定 |
| T12 | 家校关系 | 家长会、家校沟通、家委会、家长群 | 涉及家长与学校的互动 |
| T99 | 其他 | - | 无法归入以上类别的信息 |

## 分类规则

1. 一条舆情只归入一个主分类（取最相关的）
2. 如果同时涉及多个主题，取严重程度更高的分类
3. 严重程度排序：T02 > T06 > T03 > T04 > T07 > T05 > T01 > T10 > T11 > T12 > T08 > T09 > T99
4. 无法判断时归入 T99
