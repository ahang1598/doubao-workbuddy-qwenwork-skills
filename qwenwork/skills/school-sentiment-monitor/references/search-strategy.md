# 搜索策略

## 平台优先级与执行顺序

❗ **强制要求：必须严格按以下优先级顺序逐个平台执行，禁止跳过任何平台，禁止调整顺序：**

| 顺序 | 平台     | 搜索方式          | 说明                   |
| ---- | -------- | ----------------- | ---------------------- |
| 1    | 微博     | 「我的浏览器」连接器 | 舆情覆盖最广、传播最快 |
| 2    | 抖音     | 「我的浏览器」连接器 | 视频平台舆情影响力大   |
| 3    | 快手     | 「我的浏览器」连接器 | 视频平台下沉市场覆盖   |
| 4    | 今日头条 | WebSearch         | 新闻资讯类             |
| 5    | 知乎     | WebSearch         | 深度讨论类             |
| 6    | 百度贴吧 | WebSearch         | 本地化讨论类           |

## 搜索时间范围映射

WebSearch 的 `time_range` 参数映射：

- 24h → `OneDay`
- 3d / 7d → `OneWeek`
- 30d → `OneMonth`

## 覆盖要求

- **每个别名必须在全部 6 个平台执行搜索，不可跳过**
- 每个平台搜索完成后才进入下一个平台
- 某平台搜索失败时记录失败原因，继续执行下一平台，不终止整个流程

## 增量搜索

对比上次执行时间，仅关注新增内容

## 微博/抖音/快手强制定向搜索

- **必须执行**：使用 QoderWork 浏览器连接器「我的浏览器」进行定向搜索以获取更多舆情信息
- **执行顺序**：微博(第1) → 抖音(第2) → 快手(第3)，完成后才执行今日头条/知乎/百度贴吧
- **连接器说明**：「我的浏览器」是 QoderWork 浏览器连接器（builtin_browser MCP），直接驱动用户本机 Chrome 中带 QW 图标的标签页；支持的操作能力包括：打开/导航到 URL、在输入框中输入关键词、点击元素、滚动页面、截图、读取渲染后的页面内容（DOM/文本）
- **操作方式**：
  - 打开页面：通过「我的浏览器」打开/导航到 `<搜索URL>`
  - 检测状态：通过「我的浏览器」读取渲染后的页面内容
  - 交互操作：通过「我的浏览器」点击 / 输入 / 滚动
- **连接前置校验**：操作前必须确认用户 Chrome 已安装 QoderWork 浏览器扩展、「我的浏览器」连接器已启用、活动标签页显示 QW 图标；未连接则停止并用 AskUserQuestion 请用户先连接
- 未登录时暂停流程，使用 AskUserQuestion 请用户在其 Chrome 中带 QW 图标的标签页完成登录
- 禁止仅依赖通用搜索引擎的公开索引结果替代
- 禁止跳过此策略

## 搜索 URL 模板

### 微博

`https://s.weibo.com/weibo?q={URL编码别名}&typeall=1&suball=1&timescope=custom:{起始日期}:{结束日期}`

### 抖音

`https://www.douyin.com/search/{URL编码别名}?type=video`

### 快手

`https://www.kuaishou.com/search/video?searchKey={URL编码别名}`
