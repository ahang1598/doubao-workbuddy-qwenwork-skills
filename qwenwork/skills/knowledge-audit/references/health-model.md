# 文档健康度评分模型

> 被 SKILL.md Module A 引用。基于 `doc info` 返回的元数据（及深度模式下的正文摘要）对每篇文档打分。

---

## 评分维度

| 维度 | 权重 | 评分规则 |
|------|------|---------|
| 新鲜度 | 40% | ≤ 3 月: 100 / 3-6 月: 70 / 6-12 月: 40 / > 12 月: 10 |
| 标题规范性 | 20% | 有意义标题: 100 / 含日期但可辨识: 70 / "未命名"等: 10 |
| 归属清晰度 | 20% | 在分类目录中: 100 / 在根目录: 50 / 孤立: 10 |
| 内容可读性 | 20% | 有实质内容: 100 / 仅标题无正文: 30 / 空文档: 0 |

> 轻量模式下"内容可读性"维度仅基于 doc info 推断（有正文标记 vs 无），深度模式下基于 doc read 实际内容判断。

## 综合等级

| 等级 | 分数区间 | 含义 |
|------|---------|------|
| A | ≥ 80 | 健康，无需处理 |
| B | 60-79 | 基本健康，建议关注 |
| C | 40-59 | 需改善（陈旧/标题不清/归属不明） |
| D | < 40 | 亟待处理（疑似过期/空文档/孤立） |

## 标记规则

| 条件 | 标记 |
|------|------|
| 距今 > 6 月未更新 | 陈旧 |
| 距今 > 12 月未更新 | 疑似过期 |
| 无所属文件夹或在根目录散落 | 孤立文档 |
| 标题为"未命名""测试""111"等 | 标题待规范 |
| 正文为空或仅含标题（深度模式可确认） | 空文档 |

## 两种审计模式对比

| 环节 | 轻量级审计 | 深度审计 |
|------|----------|---------|
| A1 扫描 | 相同：递归 doc list | 相同：递归 doc list |
| A2 元数据 | 相同：逐篇 doc info | 相同：逐篇 doc info |
| A3 正文读取 | 跳过 | 逐篇 doc read + AI 生成 ≤ 100 字摘要 |
| A4 健康度 | 基于元数据推断 | 基于元数据 + 正文内容判断 |
| A5 分类 | 按标题 + 类型分类 | 按摘要内容主题分类 |
| A6 去重 | 标题重合度 > 80% | 摘要内容相似度（语义判断） |
| 适用文档数 | 不限（大规模友好） | ≤ 100 篇（> 100 建议轻量或缩小范围） |

## 问题识别规则

### 轻量模式

| 问题类型 | 判定条件 | 建议操作 |
|---------|---------|---------|
| 疑似重复 | 两篇文档标题重合度 > 80% | 列入待处理清单，人工确认 |
| 版本混乱 | 同一主题多个版本（如"XX方案""XX方案v2"） | 保留最新版，旧版归档 |
| 归属模糊 | 标题关键词匹配多个分类 | 标注"建议人工确认分类" |

### 深度模式（基于摘要）

| 问题类型 | 判定条件 | 建议操作 |
|---------|---------|---------|
| 内容重复 | 两篇文档摘要核心主题和关键实体高度相似 | 对比摘要展示给用户，建议合并 |
| 版本混乱 | 摘要显示同一内容但数据/日期不同 | 标注版本差异，建议保留最新 |
| 归属模糊 | 摘要内容跨多个主题 | 基于摘要主题权重分配主分类 |
| 内容空洞 | 正文仅含标题/目录无实质内容 | 标记"内容待补充"或"建议归档" |
| 内容过时 | 正文中的数据/引用明显过时 | 标记"内容需更新" |

## 分批策略

### 轻量模式

| 文档数量 | 策略 |
|---------|------|
| ≤ 50 篇 | 全量 doc info |
| 51-200 篇 | 分批 doc info，每批 20 篇 |
| > 200 篇 | 分批 doc info，按标题粗分后汇总 |

### 深度模式

| 文档数量 | 策略 |
|---------|------|
| ≤ 30 篇 | 全量 doc read + 摘要 |
| 31-100 篇 | 分批 doc read，每批 10 篇 |
| > 100 篇 | 提醒用户文档较多，建议缩小范围或切换轻量模式 |
