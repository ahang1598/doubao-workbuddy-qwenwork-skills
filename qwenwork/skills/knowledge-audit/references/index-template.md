# 知识地图索引文档模板

> 被 SKILL.md Module C 引用。创建索引文档后按此结构分块写入。

---

## 推荐文档结构

索引文档通过 `dws doc create --name "{知识库名称}审计报告与知识地图 {YYYY-MM}"` 创建后，按以下章节顺序用 `doc update --mode append` 分块写入。每块 ≤ 1500 字符。

### 第 1 块：审计概览

```markdown
## 审计概览

- 审计范围：{知识库/文件夹名称}
- 审计日期：{YYYY-MM-DD}
- 文档总数：{N} 篇
- 健康度分布：A 级 {n} 篇 / B 级 {n} 篇 / C 级 {n} 篇 / D 级 {n} 篇
- 核心发现：
  - {发现 1}
  - {发现 2}
  - {发现 3}
```

### 第 2 块：目录规划

```markdown
## 目录规划

### 目录树

- {分类 1}/ — {定义和归入规则}
- {分类 2}/ — {定义和归入规则}
- {分类 3}/ — {定义和归入规则}
- 历史归档/ — 超过 12 个月未更新且不再活跃的文档
```

### 第 3 块：分类清单

```markdown
## 分类清单

| 文档名 | 当前位置 | 目标分类 | 健康等级 | 分类依据 |
|--------|---------|---------|---------|---------|
| {文档1} | {位置} | {分类} | {A/B/C/D} | {依据} |
```

### 第 4 块：待迁移清单

```markdown
## 待迁移清单

> 以下文档建议迁移到对应目录，需人工操作。

| 文档名 | 当前位置 | 建议目标目录 | 迁移原因 | 备注 |
|--------|---------|------------|---------|------|
| {文档} | {当前} | {目标} | {原因} | {备注} |
```

### 第 5 块：待处理清单

```markdown
## 待处理清单

> 以下文档存在质量问题，建议按优先级处理。

| 文档名 | 问题类型 | 建议操作 | 优先级 |
|--------|---------|---------|-------|
| {文档} | 疑似过期 | 更新或归档 | 高 |
| {文档} | 疑似重复 | 人工确认后合并 | 中 |
| {文档} | 标题待规范 | 重命名 | 低 |
```

## 写入注意事项

1. markdown 内容禁止以 `#` 一级标题开头（`doc create --name` 已设置文档标题）
2. markdown 中的换行必须使用真实换行符（U+000A），不能使用字面量 `\n`
3. 每块控制在 1500 字符以内，超过则拆分
4. 分类清单和迁移清单文档较多时，按分类分块写入
5. 默认使用 `--mode append`，除非用户明确确认否则不使用 overwrite
