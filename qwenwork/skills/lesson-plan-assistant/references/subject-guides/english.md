# 英语学科教学指南

## 学科特点

英语是国际交流的重要工具，教学应注重语言运用能力培养，体现工具性与人文性统一。

## 教学重点

### 听说教学

- 创设真实语境
- 注重语音语调
- 培养交际策略

### 阅读教学

- 培养阅读策略
- 提升理解能力
- 拓展文化视野

### 写作教学

- 从控制到自由
- 重视过程指导
- 鼓励创意表达

## 课标要点（2022年版）

### 核心素养

1. 语言能力
2. 文化意识
3. 思维品质
4. 学习能力

### 学段要求

- **一级（3-4年级）**：简单对话、基础词汇
- **二级（5-6年级）**：日常交际、简单阅读
- **三级（7-9年级）**：综合运用、跨文化交际

## 常见课型设计

### 听说课

热身导入 → 听力输入 → 口语操练 → 交际运用 → 总结评价

### 阅读课

读前激活 → 读中理解 → 读后拓展 → 语言聚焦 → 技能训练

### 写作课

范文分析 → 构思指导 → 起草写作 → 修改润色 → 展示评价

### 语法课

情境呈现 → 观察发现 → 归纳规则 → 操练运用 → 巩固拓展
