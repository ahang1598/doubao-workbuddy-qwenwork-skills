# 语文学科教学指南

## 学科特点

语文是工具性与人文性统一的学科，注重语言文字运用能力和文化素养培养。

## 教学重点

### 阅读教学

- 整体感知与局部品味结合
- 注重朗读指导和语感培养
- 引导学生与文本对话

### 写作教学

- 从仿写到创作循序渐进
- 重视修改环节
- 结合生活实际激发写作兴趣

### 口语交际

- 创设真实交际情境
- 培养倾听和表达能力
- 注重交际礼仪

## 课标要点（2022年版）

### 核心素养

1. 文化自信
2. 语言运用
3. 思维能力
4. 审美创造

### 学段要求

- **第一学段（1-2年级）**：识字写字、阅读浅近故事
- **第二学段（3-4年级）**：理解词句、初步把握内容
- **第三学段（5-6年级）**：体会情感、领悟表达方法
- **第四学段（7-9年级）**：鉴赏评价、创意表达

## 常见课型设计

### 古诗文教学

- 诵读感知 → 理解大意 → 品味语言 → 体会情感 → 拓展积累

### 现代文教学

- 导入激趣 → 整体感知 → 深入研读 → 拓展延伸 → 总结提升

### 作文指导课

- 明确要求 → 例文引路 → 构思指导 → 动笔写作 → 交流评改
