# 评价量表设计参考

## 任务评价量表模板

### 通用评价量表

| 评价维度   | 优秀（4-5分）              | 良好（3分）        | 需改进（1-2分）  |
| ---------- | -------------------------- | ------------------ | ---------------- |
| 任务完成度 | 完全达成任务目标，超出预期 | 基本达成任务目标   | 部分达成或未达成 |
| 知识掌握   | 准确理解并能灵活运用知识   | 基本理解知识要点   | 理解存在偏差     |
| 思维能力   | 展现出优秀的分析和创新能力 | 具备一定的分析能力 | 思维较为单一     |
| 协作表现   | 积极参与，贡献突出         | 能够配合团队       | 参与度较低       |
| 表达展示   | 表达清晰，逻辑严谨         | 表达基本清楚       | 表达不够清晰     |

### 小组合作评价量表

| 评价指标 | 权重 | 优秀               | 良好         | 合格         |
| -------- | ---- | ------------------ | ------------ | ------------ |
| 参与度   | 20%  | 主动参与，积极发言 | 能够参与讨论 | 偶尔参与     |
| 贡献度   | 30%  | 提出有价值的观点   | 能够补充完善 | 跟随他人意见 |
| 协作性   | 25%  | 善于倾听，尊重他人 | 能够配合团队 | 偶有冲突     |
| 成果质量 | 25%  | 成果优秀，创新性强 | 成果符合要求 | 成果基本合格 |

## 整节课学习评价

### 评价方式权重

- **过程性评价**（60%）
  - 课堂参与度（20%）
  - 任务完成质量（30%）
  - 小组合作表现（10%）

- **结果性评价**（40%）
  - 课堂练习正确率（20%）
  - 作业完成质量（20%）

### 等级标准

| 等级   | 分数范围 | 标准描述                             |
| ------ | -------- | ------------------------------------ |
| 优秀   | 90-100分 | 积极参与所有活动，高质量完成所有任务 |
| 良好   | 75-89分  | 较好参与活动，基本完成所有任务       |
| 合格   | 60-74分  | 参与主要活动，完成基本任务           |
| 需改进 | 60分以下 | 参与度低，任务完成不理想             |

## 学科特色评价量表

### 语文课堂评价

- 朗读表现（语音、语调、情感）
- 阅读理解（把握主旨、分析人物）
- 写作表达（结构、语言、创意）
- 口语交际（倾听、表达、应对）

### 数学课堂评价

- 概念理解（定义、性质、应用）
- 运算能力（准确、熟练、灵活）
- 问题解决（分析、建模、验证）
- 数学思维（逻辑、抽象、推理）

### 英语课堂评价

- 听说能力（发音、流利度、理解）
- 阅读能力（词汇、语法、理解）
- 写作能力（结构、语法、表达）
- 文化意识（跨文化理解、交际）
