# 教案写作助手技能

基于教学评一致性原则，生成符合《义务教育课程标准（2022年版）》的专业教案。

## 功能介绍

本技能帮助中小学教师快速生成结构完整、内容专业的教学设计文档，严格遵循教学评一致性原则，确保教学目标、教学过程、教学评价三者有机统一。

### 核心能力

- **完整教案生成**：根据课题、学科、年级自动生成八模块完整教案
- **教案模板输出**：提供可编辑的空白教案框架
- **评价量表设计**：生成任务评价量表和学习评价方案
- **板书结构设计**：生成可视化板书布局图示

## 使用方式

### 生成完整教案

```
请帮我生成《咏鹅》语文课程的教案
```

### 获取教案模板

```
给我一个数学教案模板
```

### 生成评价量表

```
为小组合作学习任务设计评价量表
```

## 输出说明

所有输出均为标准的 Microsoft Word 文档（.docx）：

- 专业排版，适合打印
- 老师可直接编辑修改
- 支持表格、图片等复杂格式
- 兼容主流办公软件（Word、WPS等）

## 支持范围

- **学科**：语文、数学、英语、科学、物理、化学、生物、历史、地理、道德与法治
- **学段**：小学（1-6年级）、初中（7-9年级）、高中（10-12年级）
- **课型**：新授课、复习课、练习课、实验课
