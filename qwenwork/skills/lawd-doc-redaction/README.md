# 超安全文件脱敏（lawd-doc-redaction）

给律师法务的**纯浏览器本地脱敏工具**：合同、判决书、证据、表格里的敏感信息（公司名/人名/证件号/账号/手机号/地址…）在你自己的浏览器里识别并替换成代号，**不经大模型、文件不离开本机、断网可用**。

## 为什么是它

- **真脱敏**：替换式脱敏（原文从文档里删除）+ PDF 栅格化（脱敏页转图片），不是"盖黑块"的假涂黑
- **零泄露**：识别、替换、预览、确认全程本地，发送给 AI 的永远是脱敏版
- **你说了算**：每一处脱敏都过你的眼睛——逐条勾选、逐条撤销、框选补漏、涂抹

## 使用

1. 用浏览器打开 `assets/redaction-studio.html`（双击即可，无需联网）
2. 拖入文件（PDF/Word/Excel/图片）或直接粘贴文本
3. 逐条确认脱敏项 → 导出脱敏版 → 放心交给 AI 或对外发送

详细操作见 `references/操作指南.md`；agent 侧流程与隐私红线见 `SKILL.md`。

## 效果示例

> 原文：甲方深圳市云图科技有限公司向乙方北京智算信息技术有限公司采购设备，合同总额人民币 2,580,000 元，付款至乙方账户 6222 0210 0110 1234 5678。
>
> 脱敏：甲方某公司A向乙方某公司B采购设备，合同总额【金额已脱敏】，付款至乙方账户【账户已脱敏】。
