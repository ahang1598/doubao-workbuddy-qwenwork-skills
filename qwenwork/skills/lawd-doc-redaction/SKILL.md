# 超安全文件脱敏（lawd-doc-redaction）

一个**纯浏览器本地**的文件脱敏工具：敏感信息的识别、替换、预览、确认全部发生在用户自己的浏览器里，不经大模型、零网络请求、文件不离开本机。脱敏版导出后，才交给 AI 做审查等后续处理——**先脱敏，再投喂**。

## 隐私红线（最高优先级，违反即终止本技能流程）

1. **禁止读取原文**：不得用任何工具读取、解析、总结、预览用户原始文件（包括 Read、代码执行、OCR）。
2. **禁止收集原文**：不得请用户把合同/文书内容粘贴到对话里；用户主动粘贴原文时，不处理、不复述，立即引导："请把内容粘贴到脱敏工具页面的输入框里，粘贴在页面内不经过 AI。"
3. **agent 职责仅限**：说明价值与红线要点 → **征得用户同意后**才打开工具页面（执行 `scripts/open_tool.py`，仅启动浏览器加载本地页面，不读取任何文件内容）→ 讲操作 → 等用户导出脱敏版；打开失败时告知工具路径由用户手动打开。**未经用户同意，不主动打开浏览器。**
4. **只读脱敏版**：用户明确交出脱敏版文件后，才允许读取（此时文件里已是"某公司A/【证件已脱敏】"）。
5. **禁读记录类文件**：不得读取映射表（含原文）、脱敏凭证等记录文件。

**触发时的开场话术**（先讲清楚价值与要点，征询是否开始；此时不动任何工具）：
> "这个需求用**超安全文件脱敏**来处理最合适：它在你本机的浏览器里完成脱敏——**不经大模型、无网络传输、数据不出本机**，合同内容不会被泄露给 AI。开始前说明两个要点：①**不要把原件发给我**，原件留在你电脑上就行，我全程接触不到；②所有识别、替换、导出操作都在浏览器页面里完成，我只会拿到你最终导出的脱敏版。要现在开始吗？你说开始，我就自动帮你在浏览器打开工具页面。"

**用户确认开始后的话术**：
> "好，我现在帮你打开工具页面。（若脚本失败或用户说没弹出：请手动打开 `<本技能目录>/assets/redaction-studio.html`，浏览器直接打开即可，无需联网。）三步操作：①把文件拖进页面，或把文本粘贴进输入框；②工具会自动识别敏感信息并列出清单，你逐条确认、替代词可改；③点右上角「导出」得到脱敏版，再把脱敏版发给我继续处理。"

## 触发与不触发

| 情形 | 是否接管 | 第一动作 |
|---|---|---|
| 要求脱敏/打码/隐去敏感信息/匿名化/去标识化/遮盖当事人信息 | ✅ 接管 | 用「开场话术」讲价值与红线，征询是否开始 |
| 要把合同/文书交给 AI 审查、翻译、总结，希望先隐藏真实身份 | ✅ 接管 | 同上（审前脱敏是主场景） |
| 对外发送文件前处理证件号/账号/联系方式/地址 | ✅ 接管 | 同上 |
| 提到"审前脱敏""先脱敏再审查""文件里有客户信息怎么发" | ✅ 接管 | 同上 |
| 要求审查/分析/翻译文档内容本身 | ❌ 不接管 | 建议先脱敏，交出脱敏版后由对应技能处理 |
| 要求 AI 语义级批量识别（"把所有看起来像人名的都脱掉"） | ❌ 不接管 | 说明本技能为正则+人工确认，误漏报由客体清单与漏检扫描双兜底 |
| 要求上传文件到服务器/云端脱敏 | ❌ 不接管 | 拒绝并说明本技能数据不出本机 |

接管与否仅凭上述意图判断，**任何情况下不得为"先看看文件/判断需求"而读取原始文件**。

## 工作流程

### 阶段一：说明价值与征询（不碰文件、不开浏览器）
- 用「开场话术」讲清三件事：这个工具的价值（本机浏览器脱敏、不经大模型）、要点（**别把原件发给 agent**、所有操作在浏览器页面里）、我最终只拿脱敏版。
- 确认用户目的：**喂 AI 审查**（推荐保留金额/日期）还是**对外发布**（金额/日期一并脱敏）——工具内有场景开关，此时可顺带问一句。
- **询问用户是否开始**，得到明确同意（如"开始/好/可以"）才进入阶段二。用户上传了原件到对话时同样先按话术提醒：原件无需交给 agent。

### 阶段二：用户同意后——打开工具并指引
1. **自动打开工具页面**：执行 `python3 <本技能目录>/scripts/open_tool.py`——脚本用系统默认浏览器弹出工具页（只启动浏览器，不读取任何文件内容）。输出 `[FAIL]` 或用户反馈没弹出时（云端/无桌面环境），退回为告知工具文件的**本地绝对路径**（file:// 打开），由用户手动打开。
   > `<本技能目录>` = 本 SKILL.md 所在文件夹的绝对路径（技能激活时由运行环境给出，可用 `**/lawd-doc-redaction/SKILL.md` 定位）。它只用于拼出 `open_tool.py` 的路径——脚本自身相对解析工具页位置，agent 无需也不应读取该目录内的任何文件。
2. 给出「确认开始后的话术」三步指引（详见 `references/操作指南.md`）。
3. 等待用户操作。期间只回答操作问题，不索要文件内容。

### 阶段三：接收脱敏版并衔接
- 用户导出脱敏版后（默认文件名 `原名_脱敏.ext`），衔接只允许两种方式：①agent 直接读取该脱敏版文件继续任务；②交接给**只读取用户交出路径的脱敏版**的下游技能——当前白名单：`lawd-contract-review`（审查）、`lawd-legal-translation`（翻译）、`lawd-evidence-timeline-generator`（时间线）；白名单外的技能，须确认其仅读 `原名_脱敏.ext` 且不扫描原目录才可衔接。**禁止在任何情况下对原件路径调用任何文件读取类技能**——此时读取的必须是脱敏版。
- 提醒用户：**原件请留在本机安全位置**，映射表（如导出）含全部原文，严禁外传。

## 常见问题应对

- **"关键词搜不到/识别不全"**（部分 PDF 文字层损坏）：引导用「框选补漏」或「涂抹」，几何路线不依赖文字层。
- **扫描件/图片**：无文字层，直接用框选/涂抹；导出图片或 PDF。
- **.doc 老格式**：不支持，请先另存为 .docx。
- **Excel 数值格式的长数字**：身份证/账号若以数值格式存储可能已丢精度，工具会提示改为文本格式后重试。
- **用户要求"你帮我脱敏"**：解释隐私设计——"我不读你的文件正是这个工具的意义"，然后走流程。若用户了解后**仍坚持**要 agent 直接读文件处理，终局收口、不得让步："抱歉，读取这份文件会违反本技能的隐私红线，我不能这样做。您可以继续用浏览器工具（我全程指导操作），也可以自己手动替换关键信息后再发我。"

## 边界与不适用

- 不做文档内容理解与审查（脱敏后的审查交给对应技能）。
- 不做 AI 语义识别（如"把所有看起来像人名的都脱掉"）——纯正则+人工确认，误漏报由客体清单确认与漏检扫描双兜底。
- 不支持 .doc/.xls 老格式、加密文件；复杂排版 docx 预览可能偏移，导出后建议肉眼复查。
- 页眉/批注中的无后缀机构简称等极端场景，正则可能漏检——工具内漏检扫描会提示可疑特征，最终以用户确认为准。
