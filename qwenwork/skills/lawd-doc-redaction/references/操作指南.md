# 操作指南：超安全文件脱敏

> 一页看懂。全程在你的浏览器里完成，**不需要联网，文件不会离开你的电脑，AI 全程接触不到原文**。

## 开始之前（可选的自证）

- 本工具**断网也能完整使用**——你可以开飞行模式试一遍。
- 进阶验证：浏览器菜单打开「开发者工具 → Network（网络）」面板，操作全程请求数为 0。
- 进入页面就能看到入口下方的三枚徽章：**不经大模型 · 无网络传输 · 数据不出本机**。

## 三步搞定

### 第 1 步：载入

- 通常 agent 已经帮你在浏览器里**自动打开**了工具页；如果没弹出，双击 `redaction-studio.html`（或从对话里 agent 给的路径打开）。
- 把文件**拖进页面**，或点「选择文件」；也可以展开「或直接粘贴文本」把文字粘贴进去。
- 支持：PDF、Word（.docx）、Excel（.xlsx）、文本（.txt/.md）、图片（.png/.jpg）。

### 第 2 步：确认（每一处脱敏都过你的眼睛）

- 工具自动识别敏感信息，左侧按类别列出清单：**原文摘录 → 替代为什么**。
- 先选**脱敏场景**：喂 AI 审查（保留金额/日期）／对外发布（金额/日期一并脱敏）。
- 不想脱敏某条？**取消勾选**。想改替代词？直接在框里改（如"某公司A"改成"客户甲"）。
- 预览区实时显示脱敏后效果；点击任何脱敏块会浮出「**撤销**」按钮，**逐条恢复**。
- 识别漏了？切到「**框选补漏**」或「**涂抹**」，在文件上直接操作，一笔一笔补。
- 预览区上方的「**敏感信息复查**」会自动提示可疑残留，按提示复核即可。

### 第 3 步：导出（右上角按钮）

| 你需要 | 导出 | 说明 |
|---|---|---|
| 给 AI 审查 | 脱敏全文 .txt / 脱敏 Word | 原文已从文件中**删除**，AI 看到的是"某公司A" |
| 对外发送 | 脱敏 Word / Excel / **涂黑版 PDF** | 涂黑处已转成图片，任何人都还原不了 |
| 留痕 | 脱敏统计（自动） | 只有统计数字，**不含原文**，可存档 |

- 导出按钮在页面**右上角**（悬停可看说明）；旁边两个小图标分别是「保存脱敏统计」和「保存原文对照表」。
- 想换一份文件？点顶栏「**重新发起脱敏**」回到入口。
- 导出文件名自动带 `_脱敏`，**原件一个字节都不会被改动**。
- 「保存原文对照表」会把原文对照存到本地——**仅限你自己保管，严禁发给 AI 或任何人**。

## 常见问题

| 问题 | 办法 |
|---|---|
| PDF 里有的内容没识别到 | 该页可能是扫描件/文字层损坏 → 用「框选补漏」或「涂抹」，不受影响 |
| .doc / .xls 打不开 | 另存为 .docx / .xlsx 再来 |
| Excel 提示"数值格式长数字" | 身份证/账号列在 Excel 里是数值格式会丢精度 → 该列改为"文本"格式后重新保存再处理 |
| Word 预览排版有点歪 | 复杂排版仅供参考，以导出文件在 Office 里打开为准 |
| 想恢复某条脱敏 | 点击预览里那个黑块/高亮 → 浮出「撤销」；或在左侧清单重新勾选 |
