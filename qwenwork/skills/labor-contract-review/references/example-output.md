### 2. 按合同条款顺序的风险问题

#### 1. 工作内容和工作地点（规则编号：LCR004）

| 项目 | 内容 |
| --- | --- |
| 风险等级 | 🔴 高风险 |
| 风险类型 | 调动边界不清风险 |
| 原文位置及摘要 | 岗位与地点条款：甲方安排乙方从事运营相关工作，具体岗位可根据甲方经营需要随时调整。乙方工作地点为全国范围内甲方指定地点，甲方可根据项目需要安排乙方长期驻外，无需另行协商。 |
| 风险说明 | 工作地点范围过宽，且未约定调动条件、通知程序和合理安排，容易被认定为赋予用人单位过度单方调整权。 |
| 修改建议 | 将工作地点限定到明确城市或可合理预期区域；如需异地调动，补充启动条件、通知期限、驻外期限、员工确认方式，并明确相关支持安排按制度执行或另行协商确定。 |
| 修改后文本示例 | 乙方工作地点为杭州市。因项目需要安排跨市驻场的，甲方应提前七日通知乙方，并明确驻场期限、工作安排、员工确认方式；相关支持安排按甲方依法制定并公示的制度执行，或由双方另行协商确定。 |

#### 2. 社会保险（规则编号：LCR003）

| 项目 | 内容 |
| --- | --- |
| 风险等级 | 🔴 高风险 |
| 风险类型 | 法定义务转嫁风险 |
| 原文位置及摘要 | 社会保险条款：甲乙双方同意，社会保险由乙方自行缴纳，甲方按月向乙方支付社保补贴。 |
| 风险说明 | 社会保险缴纳义务原则上由用人单位依法办理并代扣代缴个人承担部分。将法定参保义务整体转给劳动者，争议时通常难以得到支持。 |
| 修改建议 | 改为甲方依法为乙方办理并缴纳各项社会保险，乙方个人承担部分由甲方依法代扣代缴。 |
| 修改后文本示例 | 甲方依法为乙方办理养老、医疗、工伤、失业、生育等社会保险，并按法律规定承担单位缴费部分；乙方个人承担部分由甲方在支付工资时代扣代缴。 |

#### 3. 违反劳动合同责任（规则编号：LCR010）

| 项目 | 内容 |
| --- | --- |
| 风险等级 | 🟡 中风险 |
| 风险类型 | 工资扣罚风险 |
| 原文位置及摘要 | 违约责任条款：乙方如违反公司制度，甲方可视情况予以罚款，或直接从乙方工资中扣除相应金额。 |
| 风险说明 | 若未说明损失赔偿依据、规章制度基础和程序保障，罚款或直接扣工资安排容易被认定为无正当依据克扣工资。 |
| 修改建议 | 删除一般性罚款表述；如需追偿损失，应以合法制度、实际损失和法定程序为基础另行约定。 |
| 修改后文本示例 | 乙方因故意或重大过失给甲方造成实际损失的，甲方可依据依法制定并已公示的规章制度，在核实损失、听取乙方说明后，依法另行主张赔偿责任。 |

#### 4. 规章制度效力（规则编号：HFR003）

| 项目 | 内容 |
| --- | --- |
| 风险等级 | 🔴 高风险 |
| 风险类型 | 规章制度效力风险 |
| 原文位置及摘要 | 规章制度条款：甲方依法制定的规章制度，无论乙方是否主动查阅学习，均对乙方具有约束力。 |
| 风险说明 | 直接写成无论劳动者是否查阅均有效，会弱化用人单位公示告知义务。后续依据制度处分或解除时，容易因告知留痕不足被否定。 |
| 修改建议 | 改为仅依法经民主程序制定并已向乙方公示或告知的制度，对乙方具有约束力，并补充与劳动合同冲突时的处理口径。 |
| 修改后文本示例 | 甲方依法经民主程序制定并已向乙方公示或告知的规章制度，对乙方具有约束力；乙方确认已收到或可查阅相关制度文本。规章制度与本合同不一致的，按法律规定及有效约定处理。 |

#### 5. 离职交接赔偿（规则编号：HFR007）

| 项目 | 内容 |
| --- | --- |
| 风险等级 | 🔴 高风险 |
| 风险类型 | 变相违约金风险 |
| 原文位置及摘要 | 离职交接条款：乙方未办理离职交接或交接不完整造成损失不能确定的，赔偿标准至少为月平均劳动报酬之2倍。 |
| 风险说明 | 损失不能确定时直接约定固定倍数赔偿，可能被认定为惩罚性赔偿或变相违约金。劳动者赔偿通常应以实际损失、过错和因果关系为基础。 |
| 修改建议 | 删除固定倍数赔偿，改为约定交接义务、资料返还、账号权限移交和实际损失赔偿边界。 |
| 修改后文本示例 | 乙方应按约办理工作交接，归还资料、设备、账号权限和载有甲方信息的载体；因乙方未依法办理交接给甲方造成实际损失的，乙方在其过错范围内承担赔偿责任。 |

#### 6. 工资异议期限（规则编号：HFR010）

| 项目 | 内容 |
| --- | --- |
| 风险等级 | 🟡 中风险 |
| 风险类型 | 工资追索权限制风险 |
| 原文位置及摘要 | 工资结算条款：乙方收到工资后7个工作日内未书面提出异议的，视为认可当月工资、加班费、提成等全部结算。 |
| 风险说明 | 工资异议期限可以作为内部核对流程，但不能让劳动者逾期即丧失依法追索工资、加班费或提成差额的权利。 |
| 修改建议 | 明确 7 个工作日仅为内部核对期限，不影响乙方依法主张劳动报酬差额。 |
| 修改后文本示例 | 乙方如对工资明细有异议，可在收到工资后7个工作日内向甲方提出核对申请；该期限仅为内部核对期限，不影响乙方依法主张劳动报酬差额的权利。 |

## 五、其他合规提示

1. 如采用综合计算工时制或不定时工作制，需结合合同履行地进一步核查当地审批和执行口径。
2. 甲方复用模板时，建议按普通员工、项目制员工、核心技术/管理人员分别匹配合同期限、岗位地点和竞业限制条款。
3. 如附件包含《员工手册》等制度文件，建议同步完成签收确认并保留送达记录。
4. 如合同后续补充培训、服务期或竞业限制安排，应另行核查其独立效力、启动通知、解除机制和补偿条件。
