# 示例输入

以下内容为模拟劳动合同节选，仅用于回归验证 Skill 输出结构，不代表正式法律意见。

## 合同基本信息

- 合同名称：劳动合同书
- 甲方：杭州某科技有限公司
- 乙方：张三

## 合同节选

甲方安排乙方从事运营相关工作，具体岗位可根据甲方经营需要随时调整。乙方工作地点为全国范围内甲方指定地点，甲方可根据项目需要安排乙方长期驻外，无需另行协商。

乙方实行综合计算工时工作制，具体排班及休息方式按照公司制度执行。

乙方月工资按公司薪酬制度发放，绩效奖金根据考核情况确定。甲方有权根据经营情况调整工资标准。加班工资已包含在月工资中，甲方不再另行支付。

甲乙双方同意，社会保险由乙方自行缴纳，甲方按月向乙方支付社保补贴。

乙方如违反公司制度，甲方可视情况予以罚款，或直接从乙方工资中扣除相应金额。

甲方依法制定的规章制度，无论乙方是否主动查阅学习，均对乙方具有约束力。

乙方未办理离职交接或交接不完整造成损失不能确定的，赔偿标准至少为月平均劳动报酬之2倍。

乙方收到工资后7个工作日内未书面提出异议的，视为认可当月工资、加班费、提成等全部结算。

双方发生劳动争议的，可向杭州市高新开发区（滨江）劳动人事争议调解委员会申请仲裁。

本合同附件包括《员工手册》《保密协议》等文件。

## 预期命中方向

- `LCR003`：社会保险责任转嫁给劳动者
- `LCR004`：工作地点过宽且异地调动边界不清
- `LCR005`：综合工时仅笼统写“按制度执行”，缺行政许可与排班细节
- `LCR006`：工资结构和加班工资约定不清，且存在“加班费包含在工资中”风险
- `LCR010`：罚款、直接扣工资条款
- `LCR017`：附件仅笼统提及，未明确效力与签收确认
- `HFR003`：规章制度未公示告知仍当然有效
- `HFR007`：离职交接固定倍数赔偿
- `HFR010`：工资异议逾期视为认可
- `HFR011`：劳动争议解决机构或程序表述错误
