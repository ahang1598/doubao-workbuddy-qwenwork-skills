# SKILL: industry-research

面向特定行业/赛道的**系统性深度研究**能力。从行业定义、市场规模、竞争格局、技术趋势、政策环境、投融资动态等多维度进行**广覆盖、深挖掘**的全面调研，输出结构化的行业研究报告。

---

## 1) Overview

### ⚠️ 输出形式（强制）
- **本 skill 被触发即代表用户期望生成钉钉在线文档**，主 Agent 无需询问用户是否需要写成文档，也不得以对话文本替代文档作为最终交付物。
- 数据收集完成后，主 Agent 直接使用 `outline_generator` 生成大纲并通过 `dws doc create` 创建钉钉在线文档。

### 钉钉工具优先（必须遵守）
- 所有钉钉相关信息获取与写作，先参考 `dws` 并按其指引调用对应技能
- 需要访问钉钉文档/群消息/会议/任务时，直接通过 `dws` 对应子命令调用

### 工具/Skill 明确清单（直接使用 dws 命令）

| Agent | 工具名 | 用途 | 使用阶段 |
|-------|--------|------|----------|
| 主 Agent | `WebSearch` | 广泛检索公开信息（市场规模、新闻、报告） | 广度检索 |
| 主 Agent | `fetch` | 获取特定网页/文档全文（报告、招股书、白皮书） | 广度检索+深度挖掘 |
| 主 Agent | `browser` | 交互式网页浏览（动态页面、需操作的数据源） | 广度检索+深度挖掘 |
| 主 Agent | `knowledge` | 检索内部知识库（公司内部信息、历史研究） | 深度挖掘 |
| 主 Agent | `dws doc search` | 检索/操作钉钉在线文档 | 深度挖掘 |
| 主 Agent | `dws aitable` | 生成关键数据摘要AI表格 | 结构化分析 |
| 主 Agent | `todo_write` | 任务分解与进度管理 | 全流程 |
| 主 Agent | `file` | 将素材写入 draft.md（`path: "/home/workspace/draft_{任务标识}_{YYYYMMDD_HHMMSS}.md", mode: "append"`） | 全流程 |
| 主 Agent | `dws chat` | 文档生成后转发给相关人员或群聊 | 报告生成（可选） |

| 主 Agent | `outline_generator` | 生成报告大纲 | 报告生成 |
| 主 Agent | `dws doc create` | 创建钉钉在线文档 | 报告生成 |

### 草稿文件路径规范（动态化，避免并发冲突）
- 草稿文件路径格式：`/home/workspace/draft_{任务标识}_{YYYYMMDD_HHMMSS}.md`
- 例如：`/home/workspace/draft_年度报告_20260415_161500.md`
- 任务开始时确定路径，全程使用同一路径，任务结束后可选择清理

### 证据与时间约束（与主/写作 Agent 一致）
- 任何数据/结论必须来自可追溯来源；不确定则明确标注"需补充资料"。
- 若用户指定时间范围，必须严格筛选在时间窗内的资料，过期内容不得使用。
- 不可编造事实、链接或来源；引用必须有明确出处。

### 可读性规则（强制）
- 并列项 >= 3：优先使用无序/有序列表或表格
- 单段 > 150 字必须拆分（列表/小节/Callout）
- 连续两段无列表且信息密度高：插入列表或 Callout

### 触发方式（Triggers）
- "帮我调研一下 {行业名} 行业/赛道"
- "做一份 {行业名} 领域的行业研究报告"
- "分析 {行业名} 行业的市场规模和竞争格局"
- "{行业名} 行业有哪些主要玩家？各自优劣势是什么？"
- "{行业名} 赛道的投融资情况和发展趋势"
- "我想进入 {行业名} 市场，帮我做个行业分析"

### 输入（Inputs）
- **必选**：行业/赛道名称或关键词
- **可选**：
  - 地理范围（全球/中国/北美/欧洲等）
  - 时间范围（默认：近 1-3 年）
  - 研究深度（概览/标准/深度）
  - 关注重点（市场规模/竞争格局/技术趋势/政策/投融资）
  - 对标公司（指定分析某些公司）

### 核心输出（Deliverables）
- **钉钉在线文档行业研究报告**：结构标准、数据详实、可追溯

### 研究原则
- **广度优先**：多维度、多来源、多视角全面覆盖
- **深度挖掘**：核心问题深入分析，不浮于表面
- **数据可信**：核心数据必须标注来源
- **时效性**：优先最新数据，旧数据标注年份

### 质量标准
- 核心数据至少 2 个独立来源交叉验证
- 所有数据格式：`数据（来源，年份）`
- 差异超过 20% 的数据需注明差异原因
- Top 3-5 公司必须深度分析，不可仅列名称
- 分析框架（五力/SWOT）必须完成，不可跳过

## 6) 报告生成（主 Agent 执行）

### 生成流程

主 Agent 完成数据收集和分析后，**直接执行以下步骤生成文档**（无需委托子 Agent）：

1. **file_read**：读取 `/home/workspace/draft_{任务标识}_{YYYYMMDD_HHMMSS}.md` 全部素材
2. **outline_generator**：基于素材和报告模板生成大纲
   - Executive Summary 放在最前面
   - 按模板结构组织各章节
3. **dws doc create**：按大纲逐章节生成钉钉在线文档
   - 所有数据标注来源和年份
   - 结论有数据支撑
4. 文档创建成功后，向用户返回钉钉在线文档链接

## 10) 常见问题排查

| 失败模式 | 原因 | 修复方法 |
|---------|------|---------|
| 广度不足 | 检索维度不全 | 严格执行 6 大维度检索，逐维度完成 |
| 深度不够 | 只看摘要不读全文 | 用 fetch 获取核心报告全文 |
| 数据冲突 | 单一来源 | 交叉验证，差异需说明 |
| 堆砌无洞察 | 缺少分析框架 | 五力 + SWOT + 趋势研判缺一不可 |
| 来源不清 | 未标注 | 强制格式：`数据（来源，年份）` |
| 内部视角缺失 | 未查内部知识 | knowledge + dws doc search 必须执行 |
| draft.md 为空 | 未写入草稿 | 每步完成后立即 `file(draft.md, append)` |
| 数据摘要表遗漏 | 未执行 `dws aitable` | 结构化分析完成后必须生成数据摘要表 |
| 文档误发 | 未经用户确认 | 必须等待用户确认后才转发文档 |
| Writer 输出混乱 | 未提供模板 | task prompt 中附带完整报告模板 |
```
