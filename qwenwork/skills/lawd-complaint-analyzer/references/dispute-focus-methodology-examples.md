# 争议焦点分析方法示例

本文档包含争议焦点分析各方法的详细应用示例，供分析时参考。

---

## 案由匹配法示例

```
案由：买卖合同纠纷（出卖人要求支付价款）
参考知识库：references/typical-disputes-by-case-type.md § 买卖合同纠纷

典型焦点适配情况：
✓ 焦点1：合同效力（本案存在效力争议）
✓ 焦点2：标的物是否已交付（本案有争议）
✓ 焦点3：标的物质量是否符合约定（本案核心争议）
✓ 焦点4：付款期限是否届满（无争议）
✓ 焦点5：买受人是否已付款（有部分付款争议）
✗ 焦点6：合同解除（本案不涉及）

特殊焦点：
+ 本案涉及代理人签约效力问题（需单独分析）
```

## 请求权基础分析法示例

```
请求权基础：价款支付请求权（买卖合同）
参考知识库：references/legal-elements-checklist.md § 价款支付请求权

构成要件核对：
✓ 要件1：买卖合同有效成立（已满足）
✓ 要件2：标的物已交付（有送货单，但对方质疑签收人无权签收）→ 争议焦点
✗ 要件3：标的物质量是否符合约定（对方主张质量不合格）→ 核心争议焦点
✓ 要件4：付款期限已届满（已满足）
✗ 要件5：买受人未付款（对方主张已部分付款）→ 争议焦点

识别出的争议焦点：
焦点1：标的物是否已有效交付？（签收人是否有权代收）
焦点2：标的物质量是否符合约定？（核心焦点）
焦点3：买受人已付款金额？还欠付多少？
```

## 证据审查法示例

```
焦点：标的物质量是否符合约定
参考知识库：references/evidence-checklist-by-focus.md § 证明标的物质量

我方证据审查：
✓ 核心证据：第三方质量检测报告（★★★★★ 证明力强）
✓ 补强证据：质量异议函（在异议期内发出，有送达证明）
✓ 补强证据：质量问题照片、视频
✗ 证据缺口：未申请司法鉴定（对方可能不认可第三方检测报告）

对方证据预判：
- 对方可能提供：出厂合格证、我方验收无异议的证据
- 对方可能抗辩：我方超过质量异议期才提出异议
- 应对策略：强调质量问题属于隐蔽瑕疵，不受异议期限制
```
