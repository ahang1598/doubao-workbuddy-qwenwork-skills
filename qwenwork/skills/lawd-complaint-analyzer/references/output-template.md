# 律师版输出模板

## 输出结构

本 Skill 输出一份完整的起诉状深度解析报告，包含以下七个部分：

| 部分 | 名称 | 内容概要 |
|------|------|----------|
| 一 | 案件基本信息 | 结构化的案件要素 |
| 二 | 诉讼请求拆解与风险评级总表 | 全部诉请概览 + 风险色块 |
| 三 | 逐项诉请深度分析 | 每项诉请的要件分析、风险评分、防御方向 |
| 四 | 事实与理由分析 | 时间线、逻辑链审查、可争议事实 |
| 五 | 证据脆弱性分析 | 三性评估、证据链完整性、攻击建议（如有证据清单） |
| 六 | 防御行动清单 | 紧急事项、证据收集、法律研究、程序策略 |
| 七 | 后续建议 | 下游功能推荐 |

---

## 填写规则

1. **每项诉请必须独立分析** — 不合并、不遗漏
2. **风险评分必须有依据** — 每个维度的分值须附一句话说明
3. **引用必须溯源** — 起诉状事实引用标注 `[起诉状第X段]`
4. **缺失信息不编造** — 统一标注"起诉状未载明"或"待补充"
5. **证据分析有条件** — 无证据清单时须在第五部分开头说明
6. **后续建议基于分析** — 不无条件推荐所有功能，仅推荐与分析结果相关的
7. **合规声明不可省略** — 报告末尾必须包含声明
