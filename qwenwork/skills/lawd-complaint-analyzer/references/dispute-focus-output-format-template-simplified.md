# 争议焦点分析报告（简易版）输出模板

本文件定义简易版争议焦点分析报告的输出格式。简易版侧重争点梳理与可读性摘要，不含攻防推演、类案法条完整引用及表格化深度分析。

---

## 适用场景

- 用户明确要求「简易版」「简要版」「精简」「快速梳理」「只要焦点」
- `report_profile = simplified`
- 被整合调用且上游指定简易版输出

---

## 报告结构概览

```
争议焦点分析报告（简易版）

案件案号：
审理法院：

一、案件基本情况
二、本案核心争议焦点
三、简要结论
```

---

## 详细输出格式

```
争议焦点分析报告（简易版）

案件案号：{案号，未知则留空或写「待补充」}
审理法院：{法院/仲裁机构名称}

一、案件基本情况

{第 1 段：案件背景与关键事实，200 字以内，按时间线或法律关系叙述}

{第 2 段：原告/申请人核心诉请与主张，忠实于起诉状/申请书}

{第 3 段：被告/被申请人主要抗辩理由，忠实于答辩状；无答辩状时基于材料合理归纳并标注「基于现有材料推断」}

二、本案核心争议焦点

争议焦点一：{焦点名称}

{第 1 段：法庭需查明的核心问题，1–2 句}

{第 2 段：双方主张的叙述性对比；关键事实可 inline 标注证据来源，如「见证据三」「见起诉状第 X 页」，不使用表格}

{第 3 段（可选）：该焦点对案件结果的影响，如是否构成抗辩、是否影响责任范围或金额}

争议焦点二：{焦点名称}

（同上结构，每个焦点 150–400 字）

争议焦点三：...

（按法律逻辑层级 + 内部分析优先级排序；正文不展示 ★ 星级，但焦点顺序须与内部分析一致）

三、简要结论

本案核心争议可概括为：
• {焦点一一句话概括}
• {焦点二一句话概括}
• ...

本案关键在于：{一句话点明胜负要点或法庭审查重心}
```

---

## 格式约束

1. **叙述体**：全文 prose 叙述，禁止大段表格、禁止「焦点体系图」树状结构
2. **篇幅**：全文建议 1500–3000 字；单焦点 150–400 字
3. **焦点数量**：不少于 2 个；常见案件 3–6 个
4. **证据锚定**：关键事实须 inline 标注来源（证据编号/文书名称），不必单独建证据评估表
5. **不展开的内容**（与完整版区分）：
   - 不含「法庭辩论推演与应对」章节
   - 不含类案/法条完整引用块（检索仅用于内部分析校验，不写入报告正文）
   - 不含「焦点攻防路线图」「专业检索指引」独立章节
   - 不含 ★★★★★ 优先级符号（内部分析仍标注，输出时按重要性排序即可）
6. **客观中立**：原被告双方主张均须呈现，不得只写单方
7. **材料不足**：inline 标注「材料待补充」或「分析受限」，不编造焦点

## 生成前确认
