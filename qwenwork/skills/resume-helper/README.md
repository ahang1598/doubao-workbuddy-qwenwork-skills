# 简历与面试辅助助手 (resume-helper)

## 概述

这是一个帮助用户完成简历创作、优化和面试准备的AI技能。它支持三大核心功能：

1. **简历创作** - 从零开始构建专业简历
2. **简历优化** - 改进现有简历的内容、结构和表达
3. **面试准备** - 基于简历生成知识点清单和模拟面试题

## 触发条件

### 会触发的场景

- "帮我写一份简历"
- "优化我的简历"
- "根据简历生成面试题"
- "模拟面试"
- "面试准备"
- "面试官可能会问什么"

### 不会触发的场景

- 求职信写作
- 薪资谈判策略
- 公司背景调研
- 职业规划咨询
- 面试礼仪建议

## 使用方法

### 模式A：创作简历

```
用户：我想找一份前端开发工程师的工作，帮我写一份简历

助手：好的，我需要了解一些基本信息：
1. 你的姓名和联系方式？
2. 教育背景（学校、专业、毕业时间）？
3. 工作或实习经历？
4. 掌握的技术栈？
5. 项目经验？

请提供这些信息，我会为你生成专业简历。
```

### 模式B：优化简历

```
用户：这是我的简历，帮我优化一下

[粘贴简历内容]

助手：我分析了你的简历，发现以下问题：
1. 工作经历缺乏量化成果
2. 技能清单没有分类
3. 项目经验缺少技术栈说明

优化建议：
[具体建议]

优化后的版本：
[完整简历]
```

### 模式C：面试准备

```
用户：根据我的简历生成面试题

[粘贴简历]

助手：基于你的简历，我整理了：

一、技术知识点清单
- React相关（必会）
  - 生命周期
  - Hooks原理
  - ...

二、模拟面试题
1. 基础题：...
2. 实践题：...
3. 情景题：...

三、行为面试题
1. ...

[完整面试准备文档]
```

## 质量标准

### 简历质量检查

- ✅ 联系方式完整
- ✅ 求职意向明确
- ✅ 成就描述量化
- ✅ 动词开头
- ✅ 无语法错误
- ✅ 格式统一
- ✅ 长度适中（1-2页）

### 面试题质量检查

- ✅ 覆盖核心技术
- ✅ 难度梯度合理
- ✅ 包含基础和进阶
- ✅ 答案准确有深度
- ✅ 符合STAR法则

## 注意事项

1. **真实性**：所有内容必须基于用户真实经历
2. **个性化**：根据目标岗位调整重点
3. **保密**：提醒用户注意个人信息安全
4. **迭代**：鼓励持续优化和改进
