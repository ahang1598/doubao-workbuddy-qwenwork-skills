# 简历写作规范

## STAR 法则

所有工作经历和项目经验描述应遵循 STAR 法则：

| 缩写  | 含义              | 说明             | 示例                                 |
| ----- | ----------------- | ---------------- | ------------------------------------ |
| **S** | Situation（情境） | 项目/任务的背景  | "在电商平台首页重构项目中"           |
| **T** | Task（任务）      | 面临的挑战或目标 | "需要将首屏加载时间从3秒降至1秒"     |
| **A** | Action（行动）    | 采取的具体措施   | "引入懒加载、CDN 加速、代码分割"     |
| **R** | Result（结果）    | 量化的成果       | "首屏加载时间降低65%，跳出率减少25%" |

**简历中的精简写法**：将 STAR 浓缩为一行，以动词开头：

```
- 优化电商平台首页性能，引入懒加载和CDN加速，首屏加载时间降低65%
```

## 成就描述动词清单

按功能分类的强力动词：

| 类别     | 推荐动词                           |
| -------- | ---------------------------------- |
| 开发构建 | 设计、开发、构建、实现、搭建、部署 |
| 优化改进 | 优化、改进、重构、升级、加速、降低 |
| 管理领导 | 领导、管理、主导、协调、推动、组织 |
| 分析解决 | 分析、排查、解决、定位、修复、诊断 |
| 创新突破 | 创新、研发、首创、引入、开拓、探索 |

## 量化成果指南

| 类型     | 示例                         |
| -------- | ---------------------------- |
| 性能提升 | 响应时间从500ms降至150ms     |
| 效率提升 | 开发效率提升30%              |
| 规模数据 | 管理10人团队 / 日活100万用户 |
| 成本节约 | 服务器成本降低40%            |
| 质量改善 | Bug率降低60%                 |
| 业务增长 | 转化率提升25%                |

## 禁用表达

| 禁用            | 原因       | 替代                   |
| --------------- | ---------- | ---------------------- |
| "负责..."       | 过于被动   | "主导..." / "推动..."  |
| "参与了..."     | 不明确贡献 | "设计并实现了..."      |
| "优秀的/热情的" | 主观无依据 | 用量化事实替代         |
| "熟悉XXX"       | 过于模糊   | 分层级：精通/熟练/了解 |
| " etc."         | 不专业     | 完整列出或用"等"       |

## ATS 优化要点

1. **关键词匹配** — 根据目标岗位JD调整关键词
2. **标准标题** — 使用"工作经历"而非"我的旅程"
3. **日期格式统一** — 如 "2022.06 - 2024.03"
4. **避免图片/图表** — ATS 无法解析
5. **常用文件名** — 姓名*岗位*简历.pdf

## 简历长度标准

| 经验阶段 | 建议页数 | 重点                 |
| -------- | -------- | -------------------- |
| 应届生   | 1页      | 教育背景、项目、实习 |
| 1-3年    | 1页      | 工作经历、项目       |
| 3-5年    | 1-2页    | 核心项目、技术深度   |
| 5年以上  | 2页      | 管理经验、技术架构   |

## 敏感信息处理

简历中**禁止**包含：

- 身份证号
- 家庭住址
- 银行卡号
- 个人私密邮箱（建议使用专业邮箱）

## 质量检查清单

- [ ] 联系方式完整且正确
- [ ] 求职意向明确
- [ ] 教育背景清晰
- [ ] 工作经历使用动词开头且量化
- [ ] 项目经验突出个人贡献
- [ ] 技能清单与目标岗位匹配
- [ ] 无语法错误和拼写错误
- [ ] 格式统一、层次清晰
