# 面试准备框架

## 知识点分级标准

| 等级 | 标记   | 定义                               | 示例（React）                             |
| ---- | ------ | ---------------------------------- | ----------------------------------------- |
| 必会 | ⭐⭐⭐ | 该技术基础核心概念，答不出直接淘汰 | 组件生命周期、Props/State、Hooks基础      |
| 进阶 | ⭐⭐   | 常见面试考点，区分候选人水平       | 虚拟DOM原理、性能优化、状态管理方案对比   |
| 深入 | ⭐     | 高级主题或源码级理解，加分项       | Fiber架构、Concurrent Mode、Hooks源码实现 |

## 面试题三大类型

### A. 基础概念题

**目标**：考察对技术的理解深度

**模板**：

```
**问题**: [技术概念]是什么？/ 请解释[技术概念]的原理
**考察点**: [面试官想验证什么]
**参考要点**:
  1. [核心定义]
  2. [工作原理]
  3. [应用场景]
**常见误区**:
  - ❌ [错误理解1]
  - ❌ [错误理解2]
**难度**: ⭐~⭐⭐⭐
```

**示例**：

> **问题**: 请解释React的虚拟DOM是如何工作的？
> **考察点**: 对虚拟DOM机制的理解深度
> **参考要点**: 1. 虚拟DOM是JS对象 2. Diff算法比较差异 3. 批量更新最小化DOM操作
> **常见误区**: ❌ 认为虚拟DOM一定比直接操作DOM快 ❌ 不了解Diff算法的key机制

### B. 实践应用题

**目标**：考察实际项目经验和解决问题的能力

**模板**：

```
**问题**: 在你的[某项目]中，如何解决[某技术问题]？
**考察点**: 实际项目经验、方案选择能力
**回答框架**:
  1. 背景 — 项目情况和面临的问题
  2. 方案选择 — 为什么选这个方案，对比过哪些
  3. 实施过程 — 具体如何实施
  4. 结果 — 量化效果
  5. 反思 — 如果重来如何改进
**难度**: ⭐⭐~⭐⭐⭐
```

### C. 情景分析题

**目标**：考察系统性思维和应急处理能力

**模板**：

```
**问题**: 如果[出现某线上问题]，你会如何处理？
**考察点**: 问题排查能力、系统性思维
**回答要点**:
  1. 快速止损 — 先恢复服务
  2. 信息收集 — 日志、监控、报警
  3. 定位问题 — 从最近变更、依赖服务排查
  4. 解决方案 — 根据根因采取措施
  5. 复盘预防 — 建立预防机制
**难度**: ⭐⭐~⭐⭐⭐
```

## 行为面试题（STAR法则）

### 问题生成方向

基于简历中的经历，生成以下维度的行为面试题：

| 维度     | 典型问题                               | 从简历中提取线索 |
| -------- | -------------------------------------- | ---------------- |
| 问题解决 | "分享一个你解决的最复杂的技术难题"     | 项目中的技术挑战 |
| 团队协作 | "描述一次你和团队成员意见分歧的经历"   | 跨团队项目       |
| 主动性   | "讲一个你主动优化流程或提升效率的例子" | 流程改进类成就   |
| 领导力   | "你如何带领团队完成困难目标"           | 管理类经历       |
| 适应力   | "分享一次你需要快速学习新技术的经历"   | 新技术栈项目     |

### STAR回答框架

每个行为面试题必须引导用户按STAR结构回答：

- **S（Situation）**：简述项目背景和面临的问题
- **T（Task）**：你的具体任务和目标
- **A（Action）**：你采取的行动，这是重点，要详细
- **R（Result）**：量化的成果和影响

**优秀回答特征**：

- 用"我"而非"我们"，突出个人贡献
- Action占比最大（60%以上）
- Result必须量化
- 控制在2分钟内

## 常见面试问题清单

### 自我介绍

- 结构：姓名+身份 → 2-3个核心亮点 → 求职动机
- 准备多个版本：1分钟 / 2分钟 / 3分钟

### 优缺点

- 优点：选与岗位相关的，用例子证明
- 缺点：真实的非致命缺点 + 正在如何改进

### 离职原因

- 保持积极正面，聚焦职业发展

### 职业规划

- 短期（1-2年）：技能深耕
- 中期（3-5年）：承担更多责任
- 与公司发展契合

## 反问面试官建议

**推荐方向**：

- 团队规模和技术分工
- 技术栈构成和演进计划
- 新人培养机制
- 岗位业务线发展重点

**避免**：

- ❌ 薪资福利（留到HR阶段）
- ❌ 加班情况（换种方式问工作节奏）
- ❌ 网上能查到的基本信息
