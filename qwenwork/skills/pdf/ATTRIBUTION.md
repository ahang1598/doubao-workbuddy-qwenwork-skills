# Attribution

This skill references the following public standards and specifications:

## PDF Specifications
- **ISO 32000-2:2020** — PDF 2.0 specification (Adobe / ISO)
  - AcroForm interactive form specification
  - Encryption and security handler standards
  - XObject and image embedding model

## OCR Standards
- **Tesseract OCR** — Open-source OCR engine (Apache License 2.0)
  - Language model and page segmentation mode documentation

## Typesetting
- **Tectonic** — Modern TeX/LaTeX engine (MIT License)
  - Command-line interface and compilation model

## Web Standards
- **W3C CSS Paged Media Module Level 3** — Print CSS specification
  - Page break, margin, and @page rule behavior

## Security
- **OWASP PDF Security Cheat Sheet** — Input handling and content sanitization guidelines
