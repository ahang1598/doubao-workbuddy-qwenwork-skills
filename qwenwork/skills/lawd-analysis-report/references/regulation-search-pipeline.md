# 法规检索连接器管道

本文档定义使用「法规检索」连接器能力进行法条检索的完整管道流程。
本环节按 SKILL 连接器写法三铁律执行：只写能力语义、三段式探测、分级降级，**不写死任何供应商/工具名**。

---

## Step 0：能力探测与匹配

本管道需要**「法规检索」**能力：输入检索 query/关键词，返回法规/法条清单（法规名称、条号、条文原文、时效性、效力级别）。

1. **探测**：调用 `qwenwork_mcp_tool_list`，keyword 逐个尝试：
   `法规 / 法条 / fatiao / law / article / pkulaw / fabao / yuandian / flfg / 法智`
2. **匹配**：在返回工具中，按工具名或 description 含「法规检索」「法条检索」「statute/law search」「article」等语义判定候选；不确定时用 `qwenwork_mcp_tool_get` 查看 schema，确认返回含法规名称、条号、条文原文、时效性字段。
3. 多家可用时按探测命中顺序依次尝试，首选调用失败切下一家。

## Step 1：Query 改写

使用 [regulation-query-rewrite-prompt.md](regulation-query-rewrite-prompt.md) 将法律关系转化为法条检索语句：
- **query**：控制在 **8-15 字**，使用空格分词，使用法律专业术语（如"七日"而非"七天"，"解除合同"而非"取消合同"）
- **keywords**：提取 3-5 个关键词，若工具要求逗号分隔的关键词字符串则**必须使用英文逗号分隔**

示例：
```json
{
  "query": "劳动合同期满 经济补偿",
  "keywords": "劳动合同,期满终止,经济补偿"
}
```

## Step 2：执行检索

用 `qwenwork_mcp_tool_call` 调用匹配到的「法规检索」工具，实际入参名以该工具 schema 为准。`lawName` 优先映射到工具独立的「法规名称过滤 / 法规名+条号精确取条」入参，不支持时并入查询文本。示意（入参语义级）：

```text
qwenwork_mcp_tool_call(
  tool: <匹配到的「法规检索」工具>,
  args: {
    <查询文本>: "<改写后的法条检索 Query>",
    <辅助关键词>: "<关键词1>,<关键词2>,<关键词3>",   // 若为逗号分隔字符串，用英文逗号
    <法规名称过滤>: "<lawName，可选>",                 // 工具不支持时并入查询文本
    <返回条数>: 10
  }
)
```

将连接器返回结果保存为 JSON（如 `/tmp/lawding_analysis_regulations.json`）以备后续核对与门禁校验。

## Step 3：处理返回结果

不同连接器返回结构各异，先归一化为 [regulation-data-structure.md](regulation-data-structure.md) 描述的统一契约。重点关注字段：
- `lawDomain.lawName` — 法规名称
- `lawDomain.lawOrder` — 条款编号
- `lawDomain.lawTitle` — 条款标题
- `lawDomain.lawSourceContent` — 条款原文
- `lawDomain.timeliness` — 时效性（现行有效/已废止/尚未生效）
- `similarity` — 匹配相似度

## 关键注意事项

1. 若工具需要逗号分隔的关键词字符串，分隔符**必须是英文逗号**（`,`），中文逗号会导致检索返回空结果
2. Query 长度严格控制在 8-15 字以内，过长会导致匹配度下降
3. 使用法律专业术语（"七日"而非"七天"）
4. 对已废止的法规必须标注"已废止"
5. 优先引用现行有效法律，禁止引用已废止的《合同法》《担保法》《婚姻法》等旧法

## 空结果重试策略

1. 第一次重试：缩短 query 至 8 字以内，减少 keywords 至 2-3 个
2. 第二次重试：替换同义词（如"退货"→"退款"，"网购"→"网络交易"）
3. 仍无结果：按下方降级策略处理

## 降级策略（A 档：权威法条拒绝降级）

探测不到任何「法规检索」连接器、或全部连接器调用失败时：
- **停止该环节**，告知用户："本技能的法条引用需要「法规检索」能力，请前往千问办公 设置 → 连接器 安装法规检索类连接器后重试。"
- **严禁**用 WebSearch 或**模型内置知识罗列法条**替代权威检索结果（法条属权威引用，模型记忆可能条号/版本错误，会导致律师引用不存在的法律依据）；
- 未取得检索结果时，报告中不得出现具体法条条号与条文原文，相关分析只写法理层面判断并标注"待连接器检索后补充法律依据"。
