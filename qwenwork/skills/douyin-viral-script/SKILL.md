# 抖音爆款口播文案生成器

根据任意话题或书籍，快速生成符合抖音爆款逻辑的口播文案（约 600 字），覆盖钩子设计、节奏把控、情绪调动、价值输出全流程。

## 环境前置：连接器依赖

本技能的版本 B（拍摄参考版）写入钉钉在线文档，依赖 **DingTalk（dws）连接器**：

- 连接器已开启并认证 → `dws doc create` + `dws doc update` 可用，版本 B 完整交付。
- 连接器未开启或认证失败 → 跳过钉钉文档写入，仍保证版本 A（对话内提词器版）+ `.md` 文件输出，报告错误。
- 开启方式：QoderWork 设置 → 连接器 → 启用 DingTalk 并完成 OAuth 授权；或让 agent 执行 `qw_action install/enable/connect` on `qwenwork.settings.connector.builtin.dws`。

版本 A（提词器版）不依赖任何连接器，始终可用。

## 核心规则

**禁止：**
- 超过 800 字（口播节奏拖沓）
- 书面语和长难句（必须口语化）
- 钩子承诺与正文不符（说"3 个技巧"就必须讲 3 个）
- 全篇钩子堆砌无干货（钩子必须搭配价值输出）
- 虚假夸大（如"看完月入百万"）
- 钩子类型单一重复（必须多样化）
- 无引导动作的结尾

**强制：**
- 开头 50-80 字内有黄金 3 秒强钩子
- 中间每 40-60 字插入钩子，全文 7-12 个
- 情绪曲线有起伏：共鸣 → 焦虑 → 希望 → 行动
- 价值输出具体（方法论、数据、案例）
- 结尾有评论区互动 + 关注引导
- 总字数 500-700 字

## 输出格式

Phase 1-4 为内部思考步骤，**不输出给用户**。包括但不限于：话题拆解、钩子设计、钩子类型标注、情绪触发点分析、**节奏验收表格、钩子数量统计、质量自检清单**。这些是 AI 内部生成逻辑，博主不需要看。

默认双版本交付：

### 版本 A：提词器版（对话内输出）

纯文本，用于直接复制到提词器：
1. 一句话概述（字数 + 预估时长）
2. 完整文案（纯文本，无标注、无 emoji、无格式标记）
3. 互动提示

### 版本 B：拍摄参考版（md 文件 + 钉钉文档）

富文本 Markdown，用于拍摄参考和团队协作。生成 `.md` 文件并保存到工作目录，同时通过 `dws doc create` + `dws doc update` 写入钉钉在线文档。包含：
- 一级标题：`# 抖音口播 — {核心主题}`
- 元信息引用块（核心概念 / 目标人群 / 预估时长 / 文案基调 / 情绪曲线 / 核心关键词）
- 分区块结构（🪝 开场 Hook → 📖 核心概念 → 💡 案例/场景 → 🎯 金句+CTA）
- 关键金句 **加粗**（2-4 处）
- 每段末尾拍摄提示引用块

**完整格式参考 [references/viral-examples.md](references/viral-examples.md) 中的「金标案例」。**

### 以下内容仅在用户主动要求时输出（默认不输出）

- 钩子分布图（表格：位置 / 钩子类型 / 内容）
- 时长预估表（分段字数 + 时长）
- 质量自检清单
- 文案结构分析

用户说"帮我分析一下"/"看看钩子分布"时才输出，**其他情况一律不输出**。

### 交付说明

- 文档命名：`抖音口播 — {2-6字关键词}`，禁止长句/日期/版本号
- 用户说"不要存文档"/"只要文案" → 仅版本 A，跳过 Phase 5 的步骤 2-4
- 用户说"不需要拍摄提示" → 版本 B 去掉拍摄引用块

## 工作流

```
用户输入 → Phase 1 话题拆解（内部）
         → Phase 2 钩子设计（内部）
         → Phase 3 文案生成（内部）
         → Phase 4 节奏验收（内部）
         → Phase 5 双版本交付
```

## Phase 1 — 话题拆解

1. 识别输入类型：话题类 / 书籍类
2. 提炼 1-3 个核心观点（共鸣或认知冲突优先）
3. 识别痛点和情绪触发点
4. 确定文案基调：知识科普 / 技能教学 / 情感共鸣 / 好物推荐
5. 提取元信息（核心概念 / 目标人群 / 预估时长 / 情绪曲线 / 关键词）

## Phase 2 — 钩子设计

从 6 种钩子类型中组合（详见 [references/hook-techniques.md](references/hook-techniques.md)）：

| 类型 | 原理 | 位置 |
|-----|------|-----|
| 疑问式 | 用问题激发好奇 | 开头/中间 |
| 反常识 | 打破常规认知 | 开头 |
| 数字冲击 | 具体数字制造冲击 | 开头/中间 |
| 痛点戳中 | 直击用户痛点 | 开头/中间 |
| 利益诱惑 | 直接展示价值 | 中间/结尾 |
| 悬念制造 | 设置悬念引导继续 | 中间 |

分布：开头 1-2 个强钩子 → 中间每 40-60 字 1 个（共 5-8 个）→ 结尾 1-2 个引导钩子

## Phase 3 — 文案生成

### 开头（50-80 字）
黄金 3 秒强钩子，快速切入主题，不拖泥带水。

### 中间（300-400 字）
- 钩子 + 价值交替分布
- 故事化表达：案例、对比、场景代入
- 核心观点用"第一个……""第二个……""第三个……"串联

**情绪句式参考：**
- 共鸣："你是不是也……""你有没有过这种经历……"
- 焦虑："别再……了""真相是……""99%的人都在犯……"
- 希望："第一个方法……""其实很简单……""记住这3点……"
- 行动："记住，……""从今天开始……"

### 结尾（100-150 字）
- 金句点题，总结升华
- 评论区互动（扣关键词、分享经历）
- 关注引导（给理由：送资料、持续分享）

## Phase 4 — 节奏验收

| 检查项 | 标准 | 未达标 |
|--------|-----|--------|
| 总字数 | 500-700 字 | 调整密度 |
| 钩子总数 | >= 7 个 | 补充钩子 |
| 开头钩子 | 前 50 字内 | 重写开头 |
| 钩子间距 | 不超 80 字无钩子 | 插入钩子 |
| 情绪曲线 | >= 2 次切换 | 增加段落 |
| 口语化 | 无书面语长难句 | 拆句替词 |
| 结尾引导 | 评论 + 关注 | 补充 |
| 钩子兑现 | 承诺全覆盖 | 补充遗漏 |

## Phase 5 — 交付

Phase 4 验收通过后，**按顺序执行以下 4 步**：

1. **对话输出版本 A**：在对话中输出提词器版纯文本（一句话概述 + 完整文案 + 互动提示）
2. **生成 md 文件**：生成版本 B 的 `.md` 文件并保存到工作目录（按金标案例格式）
3. **写入钉钉文档**：调用 `dws doc create` 创建文档 + `dws doc update` 写入内容，文档名按命名规则
4. **返回链接**：在对话中附上 md 文件和钉钉文档链接

迭代修改后 → `dws doc update --mode overwrite` 覆盖同一文档（记录 `nodeId`），不创建新文档。
文档写入失败 → 保证对话输出 + md 文件，报告错误。

## 迭代修改

| 用户请求 | 行为 |
|---------|-----|
| "换个开头" | 换钩子类型，正文不变 |
| "再激烈一点" | 加强情绪词 + 反常识/数字冲击钩子 |
| "太长了" | 压缩中间，保留钩子密度 |
| "太短了" | 补充案例或观点 |
| "语气太夸张" | 换温和钩子（疑问式/利益诱惑） |

每次修改输出**完整文案**，不输出 diff。修改后自动覆盖钉钉文档。

## 意图映射

| 用户意图 | 行为 |

## 易混淆场景（不要用本 Skill）

- 小红书文案 → 小红书文案技能
- 长视频脚本（5分钟+）→ 长视频脚本技能
- 广告投放文案 → 广告文案技能
- 图文内容 → 图文内容技能
- 分析爆款视频（非创作）→ 内容分析技能

## 错误处理

| 错误 | 处理 |
|------|-----|
| 未提供话题 | 询问话题 |
| 话题过泛（如"人生"） | 缩小范围，提供 2-3 方向 |
| 敏感/违规内容 | 拒绝，说明原因 |
| 字数超标（>800） | 压缩到 600 字 |
| 钩子验收未过 | 返回 Phase 2 |
| 非口播格式 | 路由到对应技能 |
| 钉钉文档写入失败 | 保证对话输出 + md 文件 |
