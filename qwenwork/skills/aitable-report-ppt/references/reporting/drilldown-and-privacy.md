# 下钻、原始记录与隐私规范

## 下钻的目标

下钻不是装饰性交互，而是回答“这个数字由哪些记录组成”。每次点击都应增加信息，并保持与当前图表筛选条件一致。

## 标准链路

```text
总体指标或图表类别
→ 经过同一筛选条件得到的记录集合
→ 单条业务详情
→ 钉钉 AI 表格原始记录
```

用户从总体结论到原始证据最多三次点击。

主题预览阶段不设计、展示或验证下钻。用户选定主题、内容蓝图获批后，才进入正式报告的下钻设计。

正式报告共享的是**数据成员规则和交互语义**，不是一套僵硬的页面模板：不同主题可以改变弹窗尺寸、留白、栅格、视觉层级、字体、色彩和过渡动效，也可以在居中弹窗与全屏主从视图之间做适配；但不能改变同一个触发点所对应的记录集合、列表 → 单条详情 → 原始记录的层级、返回与关闭语义。推荐从 `assets/components/standard-drilldown.css` 和 `assets/components/standard-drilldown.js` 起步，再通过主题 class 或 CSS 变量适配视觉。

统一交互为：

1. 居中的记录集合弹窗，包含过滤条件、数量、搜索和有限业务列；
2. 从列表进入单条记录详情；
3. 有真实链接时在同一详情层直接加载钉钉原始记录；
4. 只有确认 iframe 加载失败时，才出现“新窗口打开”的降级入口；
5. 没有真实链接时在相同详情层显示本地快照和明确的降级提示，不改造成另一种页面。

## 记录链接

优先使用 DWS 批量取得的真实记录分享 URL，不手工拼接随机 rowId。存储时将 `recordId` 与 URL 绑定，生成页面前验证：

- URL 的 Base、table、view 与当前来源一致；
- URL 中的行 ID 对应当前记录；
- 至少抽样打开一条；
- 用户没有权限时显示权限提示，不回退到其他人的数据。

钉钉页面可能拒绝被第三方 iframe 嵌入。因此详情层采用：

1. 优先尝试受控 iframe；
2. iframe 正常加载时不重复显示来源按钮、记录说明或“打开钉钉原始记录”工具条；
3. 只有 `error`、明确超时或人工验收确认无法嵌入时，才显示“新窗口打开”；
4. iframe 失败时不重做一个看起来像钉钉的假页面。

只有 `record_id_fidelity=real`、`record_id_coverage=1.0` 和 `record_link_coverage=1.0` 时，`drilldowns[].mode` 才能设为 `full`。导出文件中的行号只能作为 `local_row_key`，不能参与钉钉 URL 拼接。

## 能力分级与降级

| `drilldowns[].mode` | 数据条件 | 允许行为 |
|---|---|---|
| `full` | 真实 ID 和真实链接均为 100% | 记录列表 → 单条详情 → 钉钉原始记录 |
| `local_only` | 有业务记录，但没有完整真实链接 | 记录列表 → 本地详情；明确说明不能打开原始记录 |
| `aggregate_only` | 公开报告或禁止嵌入明细 | 只展示聚合，不包含行级信息 |

从 `full` 降为 `local_only` 必须在内容蓝图中说明，并在 `content-approval.json.approved_degradations` 中记录 `no_original_record_links`。不得静默降级。

## 图表到记录的成员一致性

每个非聚合下钻都必须保存可复现的成员规则，不限于图表。触发点可以是 KPI、图表类别、文本结论或表格行；成员规则来自 `report-spec.json` 的 `membership.filter_ast`，不能用页面显示文字做模糊搜索，也不能把某个示例任务中的月份、部门、状态等字段写死为通用规则。

验证：

```text
触发点显示数量 = 使用规格过滤快照得到的记录数 = 下钻列表实际行数
```

并列排名、零值类别、未分类和多选字段需单独设计成员规则。

## 明细弹窗

列表层应包含：

- 当前过滤条件；
- 结果数量；
- 搜索；
- 业务需要的有限列；
- 默认排序；
- 点击查看单条记录；
- 空结果与无权限状态。

单条详情层顶部只保留：返回、当前记录标题和关闭。不要重复完整报告标题、来源说明、“共 N 条记录”元信息或常驻的来源按钮。原始记录能嵌入时让钉钉页面本身成为正文；无法嵌入时再显示清晰、克制的降级说明和新窗口入口。

组件根节点必须直接挂载到 `<body>`，放在固定 1920×1080 舞台之外，避免随舞台缩放或被裁切。弹窗打开时暂停方向键、空格、PageUp/PageDown 等翻页操作；返回列表时保留搜索和筛选状态；关闭后恢复原页面、原筛选、原页码和键盘焦点。

## 隐私等级

### internal

- 可以保留用户授权范围内的姓名和业务字段；
- HTML 必须放在受控位置；
- 行级 URL 继承钉钉权限；
- 页面源码仍会包含嵌入数据，交付时提示风险。

### external_masked

- 姓名、工号、手机号、邮箱、身份证、自由文本评价等按规则脱敏；
- 默认禁用真实行级链接；
- 只嵌入展示所需字段；
- 小样本人群需考虑重识别风险。

### public

- 只保留聚合数据；
- 不嵌入原始记录、链接、附件或人员自由文本；
- 输出前扫描敏感字段名和值；
- 发布前再次取得用户确认。

## 数据最小化

不要因为已经读到字段就全部嵌入 HTML。报告规格必须分别列出：

- 聚合计算字段；
- 明细展示字段；
- 仅用于筛选但不展示的字段；
- 禁止离开 AI 表格的字段。

## 版本与撤回

公开或外发报告应记录数据快照时间和报告版本。数据更新后重新生成，不在旧页面上局部修改数字。发布渠道必须支持更新或撤回；skill 只在用户授权后执行部署。
