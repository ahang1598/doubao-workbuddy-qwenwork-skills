# 质量红线

本文件是 `aitable-report-ppt` 全流程的底线约束。任何阶段违反以下规则的产出都不能交付。

## 数据真实性

- 不把模拟、补齐或估算值标成真实数据。
- 不因字段名相似就默认 JOIN；关联键必须来自字段配置或用户确认。
- 不用姓名作为默认跨表键；优先稳定 ID/工号/业务编号。
- 不把职位名称解释成职级关系，不把相关性解释成原因。
- 不静默漏掉零值类别、未分类记录或缺失目标。
- 不把本地行号、Excel 序号或模拟 ID 当成钉钉 `recordId`。

## 交互真实性

- 不在下钻弹窗里重新伪造钉钉原始页面；能嵌入就嵌入，不能嵌入就新窗口打开。
- 不在主题预览中加入下钻弹窗、明细记录、原始记录 iframe 或不可操作的交互示意；预览只解决主题选择。
- 图表数据的下钻触发点必须挂在图表本身（trigger `type: chart`，按需带 `category`）；不得把页外抽查条、末页 chip 当作图表下钻的唯一入口——验收辅助触发点不能替代用户真实交互。验证器支持 drills 用例的 `slide` 字段先翻页再点击，"触发点必须在末页才能被验收"不再成立。
- **下钻全覆盖（硬性）**：每个展示数据分组的图表（有 `group_by`）、热力图，以及每个统计数字（`data_fact` / `rule_calculation` 指标）都必须可下钻到其口径对应的记录。这是 `validate_report_spec.py` 的硬性覆盖校验——漏一个则 spec 不通过，不能靠事后抽查补。确有不该下钻的项（纯目标趋势线、占位、无行级来源的合成值）用 `drilldown_required: false` + `drilldown_opt_out_reason` 显式豁免。**推荐一图一下钻模板**：一个图表声明一个不含固定 `filter_ast` 的 chart-trigger 下钻，runtime 按点击的类别用 `group_by` 字段自动筛选，一个声明覆盖该图全部类别；热力图用双字段 `filter_ast`（区域 × 月份）逐格声明或模板化——避免逐类别手动枚举导致遗漏。

## 确认门禁

- 不在内容或主题尚未确认时生成并交付正式版。
- 不用普通说明文字冒充确认，不在结构化确认尚未返回时继续执行后续阶段。
- 当轮确认卡答案优先于一切历史记忆与既有偏好；未被选中的推荐项即本次明确拒绝，不得事后复活。用户选了一套主题就只交付一套；多套交付必须来自用户当轮明确选择（`selection_mode: all_versions`）。

## 输出形态

- 不把 `reading-first` 内容密度包装成独立阅读模式，也不默认生成用户没有要求的连续长页。
- 默认只生成固定 16:9 演示稿；连续阅读长页只有用户明确要求时才启用。
- **不靠缩小规避溢出。**内容装不下时拆成更多页或改用更紧凑的版式，不得缩小字号或压低图表高度硬塞。溢出与"太小、太空"是同等级的失败，判定标准见 `validation.md` 第 5.1 节。
- **不写死主图高度。**主图用 `flex:1` 或显式的大高度（两栏 ≥360px、单栏 ≥420px，1920 画布尺寸）。固定小高度会让面板撑满而图表干瘪，是覆盖率骗过门禁的典型手法。
- **`reading-first` 的主题必须装得下数据。**候选主题的 `supported_density_modes` 须含 `reading-first`。主题默认视觉稀疏不构成排除理由，但其稀疏构图只能用于封面、章节和金句页——**不得把封面式构图套到每一页**。
- **刻意小的文字要申报。**用 `data-text-role="chrome"` 标注，不申报即按正文字号下限判定。豁免靠声明，不靠验证器猜类名。

## 运行时与验收

- 不在页面里重写聚合、filter_ast、舞台缩放等 runtime 已提供逻辑的第二份实现。
- runtime 不给自己打分：`verificationSnapshot()` 只报告观察值，不得包含 `passed`、expected 值或任何自我比较结论；判定只发生在页面外的验收脚本。
- 验收指纹（快照/规格哈希、语义与合同版本）任何一项不一致必须硬失败，不降级为 warning。
- `member-keymap.json` 是内部构建产物，永不进入交付目录。

## 底线

- 不让漂亮页面掩盖数据验证失败。
