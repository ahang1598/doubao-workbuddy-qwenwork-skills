# Provenance

The authoring, editing, themes, visual components, rendering guidance, and
design QA baseline was refreshed from MuleRun's
`src/super-agent-sandbox/packages/mule-skill-pptx/opt/agent-skills/pptx`
package at `origin/main` commit `53a3b3765de75a9b0246aecdd73f48092e996650`
on 2026-08-10. The baseline content was introduced by MuleRun commit
`08f319bf58070b226e05343f544f6c279de74b99`.

This repository retains the stronger standalone clone/prune and OOXML package
audit modules, and adds cloud-preferred semantic routing, local parity
adapters, Python 3.9/cross-platform adjustments, tests, and deterministic
packaging. Windows PowerPoint COM code was not copied; it remains owned by the
Desktop host.
