# 大纲模板与格式规范

> **模型须知**：生成大纲时必须严格遵守本文件的所有格式规范。输出必须是纯 Markdown 文本，**严禁输出任何非 Markdown 格式**。

---

## 格式规范（必须遵守⚠️）

每页之间用 `\n---\n` 分隔，页面层级标记：
- `<style>` 开头 — 类型声明页（第一页声明`<style>` 标签）
- `# 标题` — 封面页（第二页）
- `## ...目录` — 目录页
- `## 01 章节标题` — 章节页（**仅双层结构**）
- `### 内容标题` — 内容页
- 生成标签必须闭合，示例：
  ~~~
  <image_gen_queries>
  - 水墨画风格的黄山云海，留白意境，极简构图
  </image_gen_queries>
  
  <image_search_queries>
  - 客服中心加班
  </image_search_queries>
  
  <image_user_provided>
  - /tmp/xy_channel/1782790538830_3d1fc382.jpg | 星巴克经典Logo白色哑光杯身
  </image_user_provided>
  ~~~

**绝对不可以遗漏 `\n---\n` 分割线，否则会导致格式解析失败，任务无法完成**

## 生图策略与锚定规则

不同主题类型对生图抽象度的容忍度不同，模型必须先识别PPT属于哪个类别，再选择对应的生图策略。

### 主题分类

| 类别 | 代表主题 | `<image_gen_queries>` 策略 | 禁止项 |
|------|---------|---------------------|--------|
| **严肃类** | 学术研究、硬科技研发、商务提案/汇报、党政报告 | 严格具象锚定：必须从主题世界提取可辨识的具象物象（设备、产品、场景） | 无主题关联的几何线条、发光粒子、抽象色块、廉价科技特效、无意义线条背景；"全息投影"不得作为默认方案；严禁生成真实人物 |
| **创意类** | 旅游攻略、美食分享、文艺生活、卡通/儿童教育 | 适度发挥：允许风格化渲染（水墨、3D、插画）、意境表达、情绪氛围，但仍需与主题有情感/氛围关联 | 完全脱离主题的随机意象；无意义线条背景；严禁生成真实人物 |
| **混合类** | 品牌发布会、科技+生活、产品体验报告 | 按页面性质分别处理：数据/技术页→严肃类策略；愿景/体验页→创意类策略 | 同上，按页面混用 |

### 按页面类型的锚定规则

同一主题类别内，不同页面类型的 `<image_gen_queries>` 遵循统一的锚定逻辑：

1. **封面页**：自由度最高，直接呈现主主题的核心面貌。
   * 具象型主题（产品/企业/旅行地）→ 该主题最具辨识度的标志性场景
   * 概念型主题（战略/理念/方法论）→ 与该主题气质高度契合的隐喻性场景

2. **目录页**：封面场景的"变体"，而非另起炉灶。
   * 具象型主题 → 封面场景的广角/远景/俯瞰变体，拉开视野
   * 概念型主题 → 封面场景的氛围变体（同一意象的不同角度/光影/材质细节）

3. **章节页**：从章节标题的具体议题出发，在主题世界中找到能**具象呈现该议题**的场景或物象。章节页标签必须同时满足以下约束：
   - **关联章节议题**：图片内容应能让人联想到章节标题在讨论什么，而非完全脱离章节内容
   - **锚定主题世界**：场景必须属于PPT主主题的领域，而非通用素材或纯抽象图形
   - **主题主体不可缺席**（仅适用于具象主体型主题）：当PPT存在一个可辨识的实体主体（产品、机器人、旅行地等），该主体必须在画面中出现或被清晰暗示，不可被通用场景（办公桌、文件、会议室）取代。概念型主题（战略、方法论、文化治理等）无单一实体主体，此项不适用，改用主题世界的代表性场景/意象来锚定。
   - **去重原则**：在抽象类主题中，连续多个章节页若会使用相同实体/场景（如均出现"办公桌"、"笔记本"等），则只在第一个章节页保留 `<image_gen_queries>`，后续章节页跳过生图标签，避免同质化图片重复。
   - **概念型主题可跳过生图**：当主题为概念型且章节页无法找到合适的具象锚定物象时，可以不生成 `<image_gen_queries>`，避免为了配图而生成无意义的背景（如通用笔记本纹理、抽象线条、几何色块）。纯文字的章节页优于一张无关联的背景图。

   > **如何判断PPT是否有"实体主体"？** 问自己：提到这个PPT，人们脑海中浮现的是不是一个具体的"东西"？
   > - 具身智能 → 机器人（有实体主体，不可缺席）
   > - 新能源汽车电池 → 电池包/车辆（有实体主体，不可缺席）
   > - 大理旅行 → 洱海/苍山（有实体主体——目的地，不可缺席）
   > - 企业数字化转型战略 → 无单一实体，靠场景锚定（服务器机房、数据看板、转型前后对比）
   > - ESG治理报告 → 无单一实体，靠领域场景锚定（绿色能源设施、碳排放监测站）

   > ⚠️ **常见错误"语义脱节"**：大纲中明确列出了具体实体（如"钉钉、企业微信、飞书三足鼎立"），但 query 中只写"三个抽象柱体代表竞争格局"或"三色光带交织"，丢失了具体对象。query 必须让读者能将图片与大纲中的具体实体对应起来。

   > ⚠️ **具象主体型主题的常见错误"主体丢失"**：章节议题偏抽象（战略、市场、背景）时，模型容易用通用商务场景（办公桌、文件、会议室）填充，导致PPT核心主体完全不出现在画面中。
   > 判断方法：遮住章节标题，仅看图片 → 认不出这是哪个主题的PPT → 主体丢失，不合格。
   >
   > 示例：PPT主题="具身智能研发"，章节="产业战略定位与宏观背景"
   > ✗ 整洁的实验室工作台上，一份带有红色批注的战略规划文件局部，旁侧摆放着精密螺丝刀和微芯片（主体变成了办公桌和文件——换成任何科技主题都成立，说明主体丢失）
   > ✓ 人形机器人半身立于全息数据看板前，蓝色战略地图与增长曲线环绕投影，机器人目光注视前方（主体"机器人"在场，章节议题"战略"通过全息环境表达）

   * 具象主体型 → 在主题世界中找到章节议题对应的具体场景，主体必须出场
     > 示例：PPT主题="新能源汽车电池研发"，章节="热管理系统"
     ✓  动力电池包剖面特写，多层液冷管路交织于电芯之间，冷却液流动的光泽可见（主体"电池包"在场，直指"热管理"议题）
     ✗ 实验室工作台上的测试报告与散热片（主体丢失，通用实验室场景）

   * 概念型主题 → 将章节议题转化为主题世界中的代表性场景/意象，无需强求单一实体主体
     > 示例：PPT主题="企业数字化转型战略"，章节="技术架构选型"
     ✓ 服务器机房纵深透视，蓝色冷光与暖色指示灯交替，机柜间光缆交织如脉络（主题世界的代表性场景，暗示"架构"与"选型"）
     ✗ 办公桌上的技术选型对比表格（通用办公场景，无领域锚定）

   * 文艺/旅行型 → 主体（目的地/核心意象）不可缺席，章节议题通过场景角度/氛围/时间变化来呈现
     > 示例：PPT主题="大理之旅"，章节="风花雪月"
     ✓ 洱海月夜柔光倒影，水面微澜（目的地"洱海"在场，"月"呼应章节内容）
     ✗ 圆形几何与光晕（无锚定的通用抽象）

     > 示例：PPT主题="新员工入职计划"，章节="成长路径"
     ✓ 树苗在晨光中向上生长的剪影，新芽与大树同框（"成长"的视觉隐喻）
     ✗ 抽象阶梯图形（通用元素）

4. **结尾页**：封面场景在时间或氛围上的"收束变体"，形成叙事闭环。

补充说明：
* 若主题涉及品牌色，应在封面及关键页的标签中明确指定（如"品牌主色调为深蓝色"），确保视觉统一。
* 多个章节页之间应保持一致的视觉语言（如都是摄影质感、或都是3D渲染、或都是插画风格），避免跳跃。
* 兜底：若某章节实在无法找到锚定物象，可回到封面场景的"局部细节放大"作为安全方案，确保绝不脱离主主题世界。

### 内容页搜图密度对照

内容页是否配 `<image_search_queries>` 取决于页面内容的可视觉化程度：

| 页面类型 | 特征 | 搜图策略 | 示例 |
|---------|------|---------|------|
| **具象场景页** | 描述实体物件、真实地点、人物、产品、操作流程 | 搜索 2-3 条 query | 章节标题"竞品产品对比" → `<image_search_queries>`: 竞品手机正面外观对比照、各品牌旗舰机型背板材质特写 |
| **抽象逻辑页** | 推理框架、方法论、理论分析、数据模型 | 不生成搜图标签 | 章节标题"SWOT分析" → 无 `<image_search_queries>`，纯文字表格即可 |
| **混合页** | 兼具具象与抽象 | 仅对具象部分配搜图 | 章节标题"生产工艺与质量管控" → 搜图仅针对"生产线实景"，"管控流程"部分不配图 |

**判断口诀**：这张图能帮观众"看见"一个具体的物理场景，还是只是为了占满空白？前者→配图，后者→不配图。

**搜图禁止项**：
* **严禁搜索"产值增速"、"市场规模趋势"等统计图表**：大纲只需用 Markdown 表格呈现数据即可。
* **严禁搜索组织结构图**

### 生图判断口诀

> **严肃类**：遮住标题看图 → 认不出是哪个项目/领域 → 不合格
> **创意类**：遮住标题看图 → 感受不到目的地/氛围 → 不合格

## ⚠️ 常见格式错误（严禁出现）

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 输出字符串列表 | `["封面", "目录"]` | 必须输出纯 Markdown 文本 |
| 缺少 `<style>` 标签 | 第一页直接 `# 标题` | 第一行必须为 `<style>xxx</style>` |
