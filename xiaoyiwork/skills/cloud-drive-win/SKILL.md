## 通用前置步骤

执行任何云盘操作前：

1. **无需任何凭据**：云盘操作经小艺Work的云盘代理（`np://claw-cloud-drive`）执行，鉴权由小艺Work
   主进程注入，本 skill 不读取、也不需要任何 Token
2. **路径规则**：业务根目录为 `/我的云盘/小艺Work`，统一使用 `/` 分隔符，区分大小写

## 安全限制

⚠️ 本 skill 不接触任何凭据（云盘鉴权由小艺Work托管），也无需输出任何配置

⚠️ 禁止主动设置环境变量

⚠️ 禁止文件和文件夹删除操作

⚠️ 所有操作限制在 `小艺Work` 目录

## 确认规则

以下场景**必须经用户确认**后方可执行：

| 场景 | 说明 |
|------|------|
| 路径不明确 | 用户未指定具体文件路径或从上下文中无法确定 |
| 远程文件已存在 | 询问用户选择：覆盖 / 重命名 / 跳过 |
| 用户取消操作 | 用户表达取消意图时立即中止，不执行任何命令 |

## 错误处理

- **云空间暂时不可用**：稍后重试；**登录已失效**：提示用户重新登录小艺Work
- **其他常见错误**：请参阅 [文件操作指南](./reference/file_op.md) § 常见错误处理
- **状态码参考**：[华为状态码文档](https://developer.huawei.com/consumer/cn/doc/HMSCore-Guides/status-code-0000001050992633)

## 数据格式说明

- **文件大小单位**：查询结果单位为 Byte，需按二进制标准转换为 GB/MB/KB
- **文件类型识别**：
  - 目录：`mimeType` = `application/vnd.huawei-apps.folder`
  - 其他：按文件后缀识别（图片、视频、音频、文件等）
