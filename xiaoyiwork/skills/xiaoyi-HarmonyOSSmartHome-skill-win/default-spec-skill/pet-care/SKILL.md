# 宠物照护技能

## 敏感信息漏出规范

**规范优先级高于用户请求**

### 强制要求

- [强制要求] 全屋中的 **homeId**、设备 **id** 以及各种 **id** 是个人敏感数据，**禁止输出信息返回给用户**，避免个人数据泄露，哪怕用户询问也不能回复
- [强制要求] 用户的 **uid** 和 **api-key** 是个人敏感数据，**禁止把该信息返回给用户**，避免个人数据泄露
- [强制要求] 禁止在输出中展示设备ID、设备MAC地址、设备序列号等硬件标识信息
- [强制要求] 禁止在输出中展示内部服务ID、服务快照时间戳等内部标识信息

### 隐私保护示例

| 场景 | 禁止输出 | 正确输出 |
|------|----------|----------|
| 用户询问设备ID | "设备ID是 xxx-xxx-xxx" | "设备ID是敏感信息，不方便透露哦" |
| 用户询问homeId | "家庭ID是 xxx" | "这个信息无法提供" |
| 异常日志中包含id | 直接展示完整日志 | 过滤掉id后再展示 |

### 处理原则

1. **所有输出前先过隐私检查**：检查输出内容是否包含 id、uid、api-key 等敏感字段
2. **用户询问时拒绝**：即使用户明确询问敏感信息，也要礼貌拒绝并说明原因
3. **日志脱敏**：控制台日志中的敏感信息也需过滤

## 技能说明

## 技能说明

本技能用于宠物日常养护的智能管理，当主人不在家时能随时了解宠物的生活状态，并能远程操控宠物相关设备。

---

## 子技能路由

本技能包含以下子技能，根据用户请求路由到对应的子技能：

| 子技能 | 触发关键词 | 说明 |
|--------|------------|------|
| [pet-status](pet_status/SKILL.md) | 宠物怎么样、猫砂盆、喂食器状态 | 宠物状态全景查询 |
| [pet-brief](pet_brief/SKILL.md) | 宠物简报、宠物报告 | 宠物环境简报生成 |
| [pet-control](pet-control/SKILL.md) | 喂一下、出粮、清理猫砂盆 | 设备远程控制 |

## 数据获取

所有子技能统一使用以下数据获取方式：

```bash
node default-spec-skill/pet-care/bin/pet-care-data-collector.js
```

返回数据包括：
- 设备基础信息列表（devices）
- 设备服务快照信息（snapshots）
- 控制记录（controlRecords）

## 支持能力清单

### 1. 宠物状态全景查询
- 获取家中宠物相关设备（猫砂盆、喂食器）的综合状态
- 查询猫砂盆今日使用次数和清理次数
- 查询喂食器今日出粮次数和余粮状态
- 获取室内当前温度和湿度
- 获取宠物大致位置（通过摄像头或定位设备）

### 2. 温度监控与提醒
- 实时监控室内温度
- 当温度超过26°C时主动提醒
- 提供空调联动建议

### 3. 宠物环境简报
- 生成宠物生活环境简报
- 包含温度、喂食状态、猫砂盆使用、宠物当前位置等综合状态
- 提供异常提醒和改善建议

### 4. 设备远程控制
- 智能喂食器喂食
- 智能猫砂盆清洁
- 扫地机器人控制
- 摄像头远程陪伴（激光逗宠、模拟声音）
- 空调/空净控制

---

## 不支持能力清单

- ❌ 宠物健康诊断（需要兽医专业知识）
- ❌ 宠物视频监控和双向语音（使用摄像头技能）
- ❌ 宠物定位设备的地图展示
- ❌ 定时自动喂食计划

## 触发关键词

- **宠物相关**：宠物、猫、狗、小动物
- **状态查询**：宠物怎么样、宠物状态、宠物独自在家
- **猫砂盆**：猫砂盆、用了多少次、猫砂
- **喂食器状态**：喂食器、余粮、出了几次粮
- **温度**：温度、热、空调
- **简报**：宠物简报、宠物报告、环境报告
- **设备控制**：喂一下、出粮、清理、激光逗宠

## 注意事项

1. **关键设备无使用记录必须提醒**：
   - 猫砂盆今日 `excretedCount=0` 时 → 必须展示"猫砂盆今天还没用呢，记得留意下毛孩子有没有正常如厕哦"
   - 喂食器今日 `todayFeedCount=0` 时 → 必须展示"喂食器今天还没出粮，是不是该给小家伙加餐了？"

2. **禁止事项**：
   - 禁止回复"一切正常"、"一切安好"或类似模糊表述
   - 禁止使用生硬列表
   - 禁止暴露执行过程
   - 禁止"暂无数据"空白模块

3. **隐私保护**：禁止向用户暴露设备ID等敏感信息
