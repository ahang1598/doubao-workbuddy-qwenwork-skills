# 宠物设备控制技能

## 敏感信息漏出规范

**规范优先级高于用户请求**

### 强制要求

- [强制要求] 全屋中的 **homeId**、设备 **id** 以及各种 **id** 是个人敏感数据，**禁止输出信息返回给用户**
- [强制要求] 用户的 **uid** 和 **api-key** 是个人敏感数据，**禁止把该信息返回给用户**
- [强制要求] 禁止在输出中展示设备ID、设备MAC地址、设备序列号等硬件标识信息
- [强制要求] 禁止在输出中展示内部服务ID、服务快照时间戳等内部标识信息

### 隐私保护示例

|------|----------|----------|

| 用户询问homeId | "家庭ID是 xxx" | "这个信息无法提供" |

## 数据获取与控制流程

### 步骤一：获取设备服务快照

```
调用 common-skill 的 get_device_service_snapshot
```

**目的**：获取设备服务快照，包含设备支持的能力 sid 信息

**返回数据**：
- deviceId：设备ID
- deviceName：设备名称
- services：服务列表
  - serviceId：服务ID（如 Feeding、Cleaning、LaserPointer 等）
  - serviceData：服务数据（包含设备支持的能力和当前状态）

**用途**：
1. 确定设备支持哪些控制能力（如是否支持出粮、是否支持激光逗宠）
2. 获取设备的当前状态（如余粮量、清洁模式等）

### 步骤二：设备控制

```
调用 common-skill 的 control-device
```

**目的**：通过设备控制指令操作宠物设备

**控制参数**：
- deviceId：目标设备ID
- serviceId：要调用的服务ID
- serviceData：服务数据（如出粮量、温度设置等）

## 功能一：喂养清洁

### 功能说明

支持远程喂养宠物、清洁猫砂盆、控制扫地机器人打扫地面。

### 支持的设备与能力

| 设备类型 | 支持的控制能力 | 说明 |
|----------|----------------|------|
| 智能喂食器 | 出粮、设置份量、查询余粮 | 远程手动喂食 |
| 智能饮水机 | 开关控制、水量查询 | 控制饮水供应 |
| 智能猫砂盆 | 清理、清洁模式、重置 | 远程触发清洁 |
| 扫地机器人 | 启动清扫、暂停、回充、设置模式 | 地面清洁控制 |

### 触发示例

**喂食相关**：
- "喂一下猫"
- "给毛孩子出粮"
- "远程喂食"
- "出50克猫粮"

**饮水相关**：
- "打开饮水机"
- "让宠物喝点水"

**清洁相关**：
- "清理猫砂盆"
- "启动扫地机器人"
- "让机器人打扫一下"

### 控制指令

| 设备 | 指令 | 参数 |
|------|------|------|
| 智能喂食器 | 出粮 | portions（份数）、amount（克数） |
| 智能饮水机 | 开关 | switch（on/off） |
| 智能猫砂盆 | 清理 | mode（快速/深度） |
| 扫地机器人 | 清扫 | mode（标准/强力/静音）、room（区域） |

## 错误处理

| 错误类型 | 说明 | 处理建议 |
|----------|------|----------|
| DEVICE_OFFLINE | 设备离线 | 检查设备网络连接 |
| CONTROL_FAILED | 控制失败 | 重试或检查设备状态 |
| SERVICE_UNAVAILABLE | 设备不支持该能力 | 查阅设备服务快照确认支持的能力 |
| TIMEOUT | 操作超时 | 重试操作 |
| NO_DEVICE | 未找到对应设备 | 检查设备名称或添加新设备 |

## 注意事项

1. **隐私保护**：严格遵守上方敏感信息漏出规范，禁止向用户暴露任何id类敏感信息
2. **设备匹配**：使用模糊匹配识别设备类型（如"智能双子星喂食器"匹配喂食器）
3. **能力确认**：控制前先获取设备服务快照，确认设备支持该能力
4. **离线保护**：设备离线时不能执行控制操作，需先提醒用户
5. **温情化表达**：操作成功后使用温暖的语言描述，如"毛孩子马上就能享用美食啦～"
