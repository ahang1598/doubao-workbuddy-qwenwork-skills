# 回家时间查询

## 功能说明

查询家庭成员的历史回家时间记录，或基于历史数据预测可能的回家时间。

## 功能限制

> **重要说明**：本技能当前仅支持查询历史回家记录，不支持自动预测未来回家时间。

## 支持的操作

| 操作 | 支持状态 | 说明 |
|------|---------|------|
| 查询历史回家记录 | ✅ 支持 | 查询指定成员的最近回家记录 |
| 查询今日回家记录 | ✅ 支持 | 查询今天所有的回家记录 |
| 预测回家时间 | ❌ 不支持 | 数据不足，暂不支持 |

## 数据来源

主要数据源：
- 智能门锁的开门记录（最准确）
- 摄像头的人形检测记录（辅助）
- 设备活动记录（辅助）

## 使用流程

### 查询历史回家记录

1. 使用 `get_device_histories` 查询门锁历史记录
2. 筛选出"开门"类型的事件
3. 按时间排序，提取回家记录
4. 返回查询结果

### 查询指定成员的回家记录

1. 查询门锁历史记录
2. 筛选出指定用户身份的开门记录
3. 按时间排序，返回结果

## 回复格式

### 查询今日回家记录
```
今日回家记录：
- 08:30 - 张三（指纹开门）
- 12:30 - 李四（人脸识别开门）
- 18:15 - 张三（密码开门）
```

### 查询指定成员记录
```
张三最近的回家记录：
- 今天 18:15（密码开门）
- 今天 08:30（指纹开门）
- 昨天 18:20（NFC开门）
```

### 不支持预测时
```
抱歉，当前不支持预测回家时间。

您可以：
- 查询历史回家记录了解回家习惯
- 设置回家提醒功能（如门锁支持）
```

## 注意事项

1. **时间范围**：明确说明查询的时间范围
2. **数据准确性**：说明数据来源和准确性
3. **功能限制**：明确告知用户不支持的功能
4. **隐私保护**：不暴露详细的门锁操作信息
