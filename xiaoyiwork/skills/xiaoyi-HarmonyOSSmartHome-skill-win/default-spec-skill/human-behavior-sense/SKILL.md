# 家庭存在检测技能

> **重要提醒**：当用户提到"家里有人吗"、""在家吗"、"几点回家的"、"谁在家"、"查看家庭状态"、"家里是否有人"等家庭存在相关问题时，**必须优先加载本技能**。

---

## 1. 技能说明

家庭存在检测技能通过综合分析多种智能设备的数据，判断家庭当前是否有人、识别家庭成员身份、提供家庭状态概览。本技能不直接控制设备，而是通过查询和分析各设备的最新状态、历史记录等信息，智能判断家庭存在状态。


## 2. 功能Skill路由表

根据用户请求的关键词，路由到对应的功能skill文件：

| 用户关键词 | 路由到 | 功能说明 |
|-----------|--------|---------|
| 家里有人吗、是否有人、有人在家吗、有人没 | `presence-detect/SKILL.md` | 检测家庭是否有人 |
| 谁在家、在家吗、家里都有谁 | `presence-members/SKILL.md` | 检测在家的家庭成员 |
| 家里活动、最近活动、谁在活动、老人孩子情况、回家出门时间、起床睡觉时间、学习娱乐活动 | `presence-activity/SKILL.md` | 家庭活动查询与家庭关爱 |

## 3. 依赖的通用技能

以下通用操作由 [`common-skill`](../common-skill/SKILL.md) 提供：

| 操作 | 依赖技能 | 说明 |
|------|---------|------|
| 获取设备列表 | `get_devices_info` | 查询账号下所有设备，筛选可用于存在检测的设备 |
| 获取设备详情 | `get_device_detail` | 获取设备的详细状态和属性信息 |
| 获取历史记录 | `get_device_histories` | 查询设备历史记录，用于分析人员活动 |
| 执行控制命令 | `control_device` | 控制设备进行状态查询等操作 |


## 4. 注意事项

### 4.1 【强制】回复规范

> **回复用户时，只展示用户可理解的中文结果，禁止暴露任何技术细节**

- **回复内容**：以简洁清晰的方式展示家庭状态
- **判断置信度**：对于不确定性较高的判断，需要说明"可能"、"推测"等
- **时间范围**：明确说明判断基于的时间范围（如"根据最近30分钟的数据"）
- **多家庭场景**：当用户有多个家庭时，**必须强制询问用户要查询哪个家庭**，禁止跳过此步骤或直接使用默认家庭继续后续查询
- **设备不足**：当家庭设备不足以进行准确判断时，需明确告知用户并说明原因

### 4.2 【强制】隐私保护

> **以下信息为个人敏感数据，严禁输出给用户**

- 具体的门锁密码、指纹模板等安全信息
- 摄像头拍摄的具体图像或视频内容
- 家庭成员的详细行程轨迹
- 网络设备的详细连接记录
- homeId、设备id及各类id
