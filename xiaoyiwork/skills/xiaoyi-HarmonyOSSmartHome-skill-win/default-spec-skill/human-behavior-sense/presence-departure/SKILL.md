# 出门时间查询

## 功能说明

查询家庭成员的历史出门时间记录，了解家庭成员的出门习惯。

## 数据来源

主要数据源：
- 智能门锁的关门记录（需配合开门记录判断）
- 智能门锁的从内开门记录（表示出门）
- 摄像头的人形消失记录（辅助）
- 设备停止活动记录（辅助）

## 判断逻辑

### 门锁判断出门

1. **从内开门**：门锁记录显示"从内开门"，直接判断为出门
2. **开门后关门**：先有开门记录，随后有关门记录，且之后长时间无门锁操作，判断为出门
3. **关门未再开门**：有关门记录，且之后30分钟内无新的开门记录，判断为出门

### 时间窗口

- 分析最近24小时的出门记录
- 或分析指定日期的出门记录

## 使用流程

1. 使用 `get_device_histories` 查询门锁历史记录
2. 筛选出"从内开门"或"关门"类型的事件
3. 结合开门记录进行关联分析
4. 提取出门记录和对应人员
5. 返回查询结果

## 回复格式

### 查询今日出门记录
```
今日出门记录：
- 08:15 - 张三（从内开门）
- 12:20 - 李四（关门，推测出门）
- 18:10 - 张三（从内开门）
```

### 查询指定成员记录
```
张三最近的出门记录：
- 今天 18:10（从内开门）
- 今天 08:15（从内开门）
- 昨天 18:05（从内开门）
```

### 数据不足时
```
根据现有数据，无法准确查询出门时间。

原因：
- 门锁记录未包含操作方向信息
- 缺少关门记录

建议：
- 确认门锁是否支持记录操作方向
```

## 注意事项

1. **判断准确性**：说明出门判断的准确性（"确认出门"或"推测出门"）
2. **数据完整性**：当数据不完整时，明确告知用户
3. **时间范围**：明确说明查询的时间范围
4. **隐私保护**：不暴露详细的门锁操作信息
