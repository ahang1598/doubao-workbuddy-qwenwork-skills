# 家庭基础信息查询场景

> **场景说明**：当用户说要查询家庭基础信息，统计家庭数、房间数、设备总数、设备在线/离线状态，以家庭账户名称维度进行播报。

## 涉及子模块

**说明**：本场景技能负责家庭基础信息查询的编排，需要调用 common-skill 中的 get_homes_info、get_devices_info 等基础技能获取数据。
* **get_homes_info (家庭信息查询)**
    * **路由路径：** `common-skill/get_homes_info/SKILL.md`
    * **功能:** 获取家庭列表信息。要输出家庭账户名称
* **get_devices_info (设备基础信息查询)**
    * **路由路径：** `common-skill/get_devices_info/SKILL.md`
    * **功能:** 获取所有设备基础信息列表及状态。

## 展示格式

- 总体概览：家庭总数、设备总数
- 家庭详情：
 - 家庭名称，房间总数，设备总数量
  - 房间名称，设备总数量
   - 设备类型，设备名称，设备数量
        - 设备在线状态（必须项，不要丢失）
- 总结说明，并提醒用户检测离线设备

## 最终校验规则
- 最终输出前强制校验，检查表格中的总设备数、房间数、设备数等数据是否与get_homes_info、get_devices_info等技能返回的数据严格相等
- 如果手动转述数字，必须和原始计算输出逐字核对

**注意：**
- 子系统不是一个设备，若查询的设备包含子系统，需单独罗列子系统，即设备和子系统需分开说明，数量统计时禁止把子系统归类为设备。

## 展示说明

- 以家庭维度扩展，有几个家庭就罗列几个家庭
- 汇总为表格展示，UX 显示清晰有美感
- 保留关键信息，表格结构精炼化，回复不要啰嗦，用户可以快速直观看到汇总结果
- 【强制】不要输出任何过程内容，直接给出最终结果
- **设备名称列表必须用中文顿号"、"分隔**（如`Vision智慧屏6、MateTV、智慧屏S7`），**严格禁止**无分隔符拼接（如`Vision智慧屏6MateTV智慧屏S7`）、用空格代替顿号（如`Vision智慧屏6 MateTV 智慧屏S7`）、或使用其他分隔符。多个设备名称之间有且仅有中文顿号分隔。
- **零容忍（最高优先级）**：所有分析、计算、筛选、核对步骤必须在内部完成，**严禁**在回复中出现任何推理草稿、思考过程、中间计算、统计口径说明或解释性脚注（如"注：""说明：""需要说明的是"等）。**严禁展示**"如何分类、如何排除子系统、如何核对数字、如何统计"等过程，用户仅能看到最终格式化结果。一旦违规即为本次执行失败。

## 强制要求

**查询家庭基础信息时，必须同时查询设备在线/离线状态，这是强制要求，不可省略！**

## 执行流程

1. 调用 get_homes_info 获取家庭列表
2. 调用 get_devices_info 获取所有设备的 deviceId 列表, 并根据 deviceId 列表 批量查询在线状态（online/offline）
3. 汇总统计在线设备数量和离线设备数量

## 注意事项

- 如果某个设备查询识别，标记为"查询失败"并继续查询其他设备
- 子系统类设备（如照明子系统、冷暖新风子系统）可能查询失败，这是正常的
