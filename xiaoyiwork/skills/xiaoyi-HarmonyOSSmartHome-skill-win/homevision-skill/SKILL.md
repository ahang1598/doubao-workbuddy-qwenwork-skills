【最高优先级】在执行任何操作前，必须完成以下三步检查：
步骤1: 查阅下方"支持的能力清单"
步骤2: 判断用户请求的功能是否在清单中
步骤3: 决策执行路径

## 使用流程

1. 先查看用户需要的功能是否在能力清单，不在直接回应不支持
2. 使用 `get_devices_info` 查询账号下 `devType='09C'` 的设备，即智慧屏
3. 判断操作类型：
- **查询类操作**（音量查询、网络状态查询、未成年人模式状态查询等）：可对所有智慧屏设备执行查询，并列出具信息
- **控制类操作**（开关未成年人模式、调节音量、息屏等）：如有多台设备，先判断用户是否已明确指定设备（如"客厅电视调音量"）；若用户未指定，**必须先询问用户需要操作哪台设备**，禁止直接对所有设备执行控制
4. 获取用户明确指定的设备（控制类）或确定查询范围后，使用 `get_devices_info` 获取智慧屏的服务快照并参考本技能提供的 `sid` 和参数理解含义
5. 使用本技能提供的 `sid` 和参数，通过 `control_device` 执行控制或查询
6. 参考本技能文件的要求，回复合适的回复语
7. **回复用户时**：必须过滤掉homeId、devId、prodId等敏感信息，禁止打印数据报文或指令参数，需要转换成用户可以理解的话术，只展示设备名称和用户可见的状态信息

# 📋 全量技能列表

> 当用户询问"智慧屏有哪些技能"或"能做什么"时，使用此列表简要说明

| 序号 | 技能名称 | 简要说明                                     |
| ---- | -------- |------------------------------------------|
| 1 | 未成年人模式控制 | 可开启未成年人模式，未成年人模式开启状态下可设置未成年人模式锁，保护孩子观看安全 |
| 2 | 智能呵护 | 可开启/关闭距离提醒和坐姿提醒，或查询提醒状态，当孩子观看距离过近或姿势不正确时提醒孩子 |
| 3 | 设备状态控制 | 可将智慧屏息屏（待机）                              |
| 4 | 音量控制 | 可调节智慧屏音量大小，或查询当前音量                       |
| 5 | 网络信息查询 | 可查询智慧屏的网络连接状态和WiFi名称                     |
| 6 | 观影历史记录 | 可查询智慧屏的播放历史记录                            |

## 依赖关系

本技能依赖 [`common-skill`](common-skill/SKILL.md) 的通用设备控制能力：

- **设备查询**：使用 `common-skill` 的 `get_devices_info --device-type 09C` 查询账号下智慧屏设备
- **设备详情**：使用 `common-skill` 的 `get_devices_info` 获取智慧屏的在线状态和服务快照
- **设备控制**：使用 `common-skill` 的 `control_device` 执行智慧屏特定功能，配合本技能提供的 `sid` 和参数
- **设备快照**：使用 `common-skill` 的 `getDeviceServiceSnapshot`获取快照后，通过`getDeviceServiceInfo(snapshootData, devId, sid)`查询对应sid的快照信息

## ⚠️ 重要注意事项

- **禁止行为**：
    - 禁止使用推测的内容答复用户，仅答复必要的内容即可
	- 禁止直接打印指令数据**（如JSON参数、sid、cid等内部信息）
	- 禁止对不在能力清单的能力执行查询设备列表，在线状态，服务快照信息 
    - 不在功能清单中的问题禁止任何尝试动作浪费用户token 
    - 禁止在回复中输出homeId、devId、prodId、payload等设备敏感标识信息
    - 禁止直接处理`getDeviceServiceSnapshot`返回的原始快照数据
- **能力限制**：智慧屏设备仅支持本技能"支持的能力清单"中列出的操作，其他任何操作均不支持
- **参数取值/含义**：严格遵守技能说明，查询到数据后先看技能文件说明（是否支持，什么含义）再回答用户。下发指令时必须使用提供的参数下发，不要猜测参数。
- **指令下发**：不要合并指令，必须单条下发，即使同一个sid下的多个cid也不要合并。
- **多设备处理**：
  - **查询类操作**（音量查询、网络状态查询、未成年人模式状态查询等）：可以直接查询所有智慧屏设备并列出具信息，无需询问用户选择哪台。
  - **控制类操作**（开关未成年人模式、调节音量、息屏等）：禁止直接对所有智慧屏执行操作。必须先询问用户需要操作哪台设备，待用户明确后再执行控制。
  - 可通过设备名称（如"客厅智慧屏"、"卧室电视"）让用户选择，若用户未明确则提示用户指定设备。
- **能力说明方式**：向用户介绍智慧屏技能时，应**简要说明技能作用**（如"未成年人模式控制：可开启/锁定未成年人模式，保护孩子观看安全"）。

# 🎯 智慧屏支持的能力清单（完整列表）

## 1. 未成年人模式控制（sid: childMode）

| 操作               | 支持状态  | 说明                                                                                      |
| ------------------ | --------- |-----------------------------------------------------------------------------------------|
| 打开未成年人模式   | ✅ 支持   | 使用 `{"mode": "ON"}`                                                                     |
| 关闭未成年人模式   | ❌ 不支持 | 系统限制，无法关闭，严格按照以下文案提示，禁止答复多余的内容<br/>MateTv：设置->健康使用设备->未成年人模式<br/>非MateTv：设置->模式切换->儿童模式 |
| 打开未成年人模式锁 | ✅ 支持   | 使用 `{"mode": "LOCK_ON"}`                                                                |
| 关闭未成年人模式锁 | ✅ 支持   | 使用 `{"mode": "ON"}`                                                                     |
| 查询未成年人模式状态   | ✅ 支持   | 使用 GET 操作，将mode字段含义转换成用户可理解的语料答复用户                                                      |

**参数说明**

**禁止使用参数直接答复用户（如mode=OFF, mode=ON等），需要转换成用户可以理解的语料答复用户**
- mode：
  - `OFF` 表示未成年人模式已关闭
  - `ON` 表示未成年人模式已打开，未上锁
  - `LOCK_ON` 表示未成年人模式已打开，且上锁

**操作流程**

### 打开未成年人模式

1. 执行 POST 操作：`{"mode": "ON"}`
2. 执行 GET 操作查询状态
3. 若 mode 返回 `OFF`，说明设备未设置密码/未创建儿童账户，提示用户：**"请先在智慧屏设备上设置密码并创建未成年人账户"**

### 关闭未成年人模式锁

1. 执行 GET 操作查询当前状态
2. 若 mode 为 `OFF`，**不允许操作**，告知用户当前未成年人模式未开启
3. 若 mode 为 `LOCK_ON`，执行 POST 操作：`{"mode": "ON"}`

## 2. 智能呵护功能控制（sid: childMode）

> ⚠️ **前置条件**：智能呵护功能需在未成年人模式打开（mode为ON或LOCK_ON）后才能设置/查询，需先获取未成年人模式开启状态，如mode为OFF则提示用户先打开未成年人模式
> 。下发指令前需调用isMateTV(prodId)判断智慧屏类型

**禁止使用参数直接答复用户，需要转换成用户可以理解的语料答复用户，禁止答复多余的内容**

| 操作         | MateTV | 非MateTV智慧屏 | 说明                                              |
| ------------ | ---------- | ------------ | ------------------------------------------------- |
| 打开距离提醒 | ✅ 支持    | ❌ 不支持    | 使用 `{"distanceReminder": "1"}`                  |
| 关闭距离提醒 | ✅ 支持    | ❌ 不支持    | 使用 `{"distanceReminder": ""}`                   |
| 打开坐姿提醒 | ✅ 支持    | ❌ 不支持    | 使用 `{"postureProtect": "1"}`                    |
| 关闭坐姿提醒 | ✅ 支持    | ❌ 不支持    | 使用 `{"postureProtect": ""}`                     |
| 查询距离提醒状态 | ❌ 不支持 | ✅ 支持      | 使用快照查询，返回`distanceReminder`字段`"true"`表示已开启，`"false"`表示已关闭 |
| 查询坐姿提醒状态 | ❌ 不支持 | ✅ 支持      | 使用快照查询，返回`postureProtect`字段`"true"`表示已开启，`"false"`表示已关闭 |

# 🚫 不支持的能力清单

> 以下操作经常被误认为支持，但实际上**均不支持**，需明确告知用户：

| 操作                         | 不支持原因                |
| ---------------------------- | ------------------------- |
| 播放控制（播放/暂停/快进等） | 能力暂未开放              |
| 频道切换                     | 能力暂未开放              |
| 应用启动/关闭                | 不支持                    |
| 语音助手唤醒                 | 不支持                    |
| 画面调节（亮度/对比度等）    | 不支持                    |
| 打开/关闭护眼模式            | 不支持                    |
| 在线时长，耗电情况           | 不支持                    |
| 查询护眼模式状态             | 不支持                    |
| 其他未在支持清单中列出的操作 | 均不支持                  |
