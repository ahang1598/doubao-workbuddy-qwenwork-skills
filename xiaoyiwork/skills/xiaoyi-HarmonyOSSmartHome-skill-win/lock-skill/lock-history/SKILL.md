# 门锁历史记录查询技能

> 本技能用于**查询**门锁的历史记录，**不支持控制操作**。

---

## 2. 触发关键词

当用户提到以下关键词时，应加载本技能：
- 开门记录、关门记录
- 逗留抓拍、门铃响铃
- 上锁、开锁记录
- 操作记录、历史记录
- 谁开门了、回家记录
- 添加用户、添加密码/指纹/掌静脉/人脸

## 3. 查询命令

### 近 24 小时（默认）

```bash
node common-skill/bin/smarthome-claw.js get_device_histories \
  --dev-id "xxx" \
  --sid "eventData" \
  --verbose
```

### 今天

```bash
node common-skill/bin/smarthome-claw.js get_device_histories \
  --dev-id "xxx" \
  --sid "eventData" \
  --date today
```

### 昨天

```bash
node common-skill/bin/smarthome-claw.js get_device_histories \
  --dev-id "xxx" \
  --sid "eventData" \
  --date yesterday
```

### 最近 7 天

```bash
node common-skill/bin/smarthome-claw.js get_device_histories \
  --dev-id "xxx" \
  --sid "eventData" \
  --last-days 7
```

### 最近 30 天

```bash
node common-skill/bin/smarthome-claw.js get_device_histories \
  --dev-id "xxx" \
  --sid "eventData" \
  --last-days 30
```

## 4. 显示内容

开头固定：`当前您家门锁记录如下：`
固定以表格形式展示：时间、事件、操作人

### 4.1 若用户有明确要求，则根据`type`、`up`、`das`字段，筛选特定类型的记录后仅显示对应类型的门锁记录
- "仅显示开关门记录"
- "仅显示告警"
- "仅显示用户管理相关操作"

### 4.2 若用户无明确要求，则不进行分类，直接按时间顺序倒序展示所有记录
**强制规则：禁止对记录做任何形式的分类/分组/分段展示**

### 4.3 强制规则：按时间倒序显示相关记录

### 4.4 显示时间时严格按照`et`字段显示，禁止将时间进行估算，如160356显示为16点4分，必须显示为16点3分

---

## 5. 注意事项

### ⚠️ 强制说明

**`et`字段的时间戳格式为IO8601（末尾带Z），但实际值已经是北京时间，无需再做时区转换（UTC+8）。直接展示即可**

### 其他说明

- 本技能仅支持查询，不支持控制操作
- 记录类型通过 `up` 和 `das` 字段进行区分
