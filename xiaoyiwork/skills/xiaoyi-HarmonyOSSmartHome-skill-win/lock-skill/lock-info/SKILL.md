# 门锁基本信息查询功能Skill

## 1. 必读项

本技能用于**查询**门锁的基本信息，包括门锁状态、门锁配置、用户信息等。**不支持控制操作**。

查询时注意以下特殊参数的含义：
- faceSleepTime：回头防误开时长
- palmSleepTime：关门静默时长
- doorOpenSwitch：门未关告警开关
- vid：留言id，查询留言时通过id值区分回家和出门。回家取值：1，2，3，4，5，当前回家留言最多5条；出门取值：51，52，53，出门留言最多3条
- doorOpenSwitch：门未关告警开关
- takeSnapshotSwitch：检测模式，**用户不感知，不要展示，不支持控制**
- lockStatus.status (门锁状态) ： 2-已开锁、3-已上锁、4-已关门、5-门虚掩、6-已反锁、7-门未关好 ⚠️注意：status=2是已开锁，不是已上锁

## 2. 触发关键字

当用户提到以下关键词时，应加载本技能：
- 门锁状态、门锁电量、在线状态
- wifi状态、wifi配置
- 设备信息、门锁信息
- 用户信息、录入人数
- 人脸录入、掌静脉录入
- 门锁配置、人脸配置、猫眼配置

## 5. 强制说明【最高优先级】

### ⚠️ 执行流程（必须严格按顺序执行）

#### 步骤1：路由检查
- 确认已加载本 skill（lock-info/SKILL.md）
- ❌ **严禁直接调用 common-skill 的 get_device_detail**

#### 步骤2：获取设备信息
```bash
# 获取设备列表
node common-skill/bin/smarthome-claw.js get_devices_info

# 获取设备详情（包含能力集）
node common-skill/bin/smarthome-claw.js get_device_detail --dev-id "xxx"
```

#### 步骤3：能力集过滤
- 从 `privacyPolicy` 中提取能力集
- 根据能力集对照表判断设备支持的功能
- ❌ **严禁输出能力集中标记为不支持的功能**

#### 步骤4：查询历史记录（必须执行）
```bash
# 查询今日历史记录
node common-skill/bin/smarthome-claw.js get_device_histories \
  --dev-id "xxx" \
  --sid "eventData" \
  --date today
```
- ❌ **严禁跳过此步骤，否则无法展示今日记录**

#### 步骤5：按格式输出
- 严格按照下方"精简版"格式输出
- ❌ **严禁输出格式之外的信息**

### ⚠️ 输出规范

#### ✅ 必须展示的信息（精简版）
```
门锁名称：xxx
门锁位置：xxx
开关门状态：已上锁/未上锁
电池电量：xx%
今日记录：
- xx:xx 开门记录
- xx:xx 告警记录
- xx:xx 门铃记录
用户录入情况：
- 用户A（已录入人脸、指纹）
- 用户B（已录入掌静脉）
```

#### ❌ 禁止展示的信息
- **技术参数**（如 status:2、uid:1、devId、homeId、api-key等你认为是技术参数的信息）
- **能力集不支持的配置**（如设备不支持人脸，却展示了人脸配置）

#### ❌ 在整体状态查询时禁止主动展示以下信息
- **在线状态**（如"在线"、"离线"）
- **WiFi 信息**（如信号强度、SSID、IP 地址）
- **设备版本**（如固件版本、软件版本）
- **蓝牙网关状态**

**【例外】当用户明确查询上面某项禁止主动展示的信息时，可以展示该项具体信息**  
例如：用户问
- "WiFi信号怎么样？"->可以展示WiFi信息  
- "我的门锁是什么版本？"->可以展示软件版本信息  

**但上面禁止展示的信息无论在什么状态下都禁止展示**  

#### ⚠️ 强制说明1：查看信息时，务必要对照能力集，不要输出能力集不支持的云侧配置，重点检查人脸、掌静脉、猫眼、灵犀钥匙、留言等领域，配置项可能冗余，实际版本并不支持

##### ⚠️ 强制说明2：给用户展示信息时要精简，严格按照上面的精简版进行展示，只有用户继续追问时才展示详细版

##### ⚠️ 强制说明3：严格按照上面的格式进行展示，除此之外不要展示任何信息，如设备版本、wifi连接、WiFi信号、**在线状态**、**蓝牙网关状态**等

##### ⚠️ 强制说明4：禁止给用户展示你读到的参数，如已上锁(status:2)、用户1(uid:1)

##### ⚠️ 强制说明5：禁止给用户说明你不支持什么能力
