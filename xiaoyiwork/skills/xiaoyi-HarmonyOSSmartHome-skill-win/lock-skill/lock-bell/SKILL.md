# 门锁铃声设置技能

> 本技能用于**查询和设置**门锁的门铃，包括默认铃声、创意铃声、文字铃声，**当前暂不支持设置录音铃声**。

---

## 1. 铃声类型

通过 `lockCommonSetting` 的 `bellType` 字段进行区分：

| 类型 | bellType值 | 说明 |
|------|------------|------|
| 默认铃声 | 0 | 按门铃时播放叮咚声 |
| 创意铃声 | 20 | 按门铃时播放固定语料，语料从云端获取 |
| 文字铃声 | 10 | 使用文字转语音，vid固定为110 |
| 录音铃声 | 11 | 当前不支持 |

### 创意铃声获取

创意铃声列表实时更新，需从云端查询：
```
https://smartlife-sandbox-drcn.things.dbankcloud.cn:8443/device/guide/smartlock/bell/mp3/config.json
```
获取后仅显示 `name` 字段给用户选择。

---

## 2. 文字铃声音色选项

文字铃声支持5种音色，通过 `homeGreeting` 的 `tb` 字段控制：

| tb值 | 音色 |
|------|------|
| 0 | 小艺女声（成熟女性声音） |
| 1 | 小艺少女（年轻女性声音） |
| 2 | 保留（暂不可用） |
| 3 | 小艺男声（男性声音） |
| 4 | 小艺童声（儿童声音） |

**强制要求**：设置文字铃声前，必须先询问用户选择音色。

---

## 3. 触发关键词

当用户提到以下关键词时，应加载本技能：
- 门铃、铃声
- 创意门铃、创意铃声
- 默认门铃、默认铃声
- 文字门铃、文字铃声
- 自定义门铃、自定义铃声

---

## 4. 查询命令

### 查询门铃状态

1. 调用 `get_device_detail` 获取设备详细信息
2. 根据 `bellType` 判断当前铃声种类
3. 向用户展示：
   - 默认铃声：`"您当前的铃声为默认铃声"`
   - 创意门铃：`"您当前的铃声为创意门铃，铃声为[bellName]"`
   - 文字铃声：`"您当前的铃声为文字铃声，铃声为[ve]"`
   - 录音铃声：`"您当前的铃声为录音铃声"`

## 5. 控制命令

### 5.1 设置默认铃声

```bash
node common-skill/bin/smarthome-claw.js control_device \
  --dev-id "xxx" \
  --prod-id "xxx" \
  --operation "POST" \
  --sid "lockCommonSetting" \
  --data '{"devCfg":[{"bellType":0,"ts":"20260427T162906Z713"}]}' \
  --verbose
```

### 5.2 设置创意门铃

当用户选择某个创意门铃后（如"访客提醒-1"）：

```bash
node common-skill/bin/smarthome-claw.js control_device \
  --dev-id "xxx" \
  --prod-id "xxx" \
  --operation "POST" \
  --sid "lockCommonSetting" \
  --data '{"devCfg":[{"bellType":20,"bellName":"访客提醒-1","bellFileName":"fktx1_1231.mp3","ts":"20260427T162932Z105"}]}' \
  --verbose
```

### 5.3 设置文字铃声

**步骤1**：判断是否需要设置文字铃声
当用户输入的文字与创意门铃列表都不匹配时，询问用户是否设置文字铃声。

**步骤2**：强制询问音色选择
必须向用户展示音色选项并等待明确选择，不能擅自决定。

**步骤3**：查询现有配置
```bash
node common-skill/bin/smarthome-claw.js get_device_detail --dev-id "xxx"
```
从返回结果中提取 `vid=110` 的配置，保留 `rpt`、`rd` 等参数不变。

**步骤4**：设置文字内容
```bash
node common-skill/bin/smarthome-claw.js control_device \
  --dev-id "xxx" \
  --prod-id "xxx" \
  --operation "POST" \
  --sid "homeGreeting" \
  --data '{"cfg":[{"vid":110,"fid":"","uid":"all","st":"00:00","rd":"1,2,3,4,5,6,7","act":2,"rpt":0,"type":1,"tb":用户选择的音色,"switch":1,"et":"24:00","ve":"用户输入的文字"}],"ts":"20260427T163147Z862"}' \
  --verbose
```

**步骤5**：设置文字铃声模式
```bash
node common-skill/bin/smarthome-claw.js control_device \
  --dev-id "xxx" \
  --prod-id "xxx" \
  --operation "POST" \
  --sid "lockCommonSetting" \
  --data '{"devCfg":[{"bellType":10,"ts":"20260427T163148Z004"}]}' \
  --verbose
```

**步骤6**：验证设置结果
设置完成后，重新查询设备状态确认：
- `homeGreeting` 的 `ve` 字段是否已更新
- `homeGreeting` 的 `tb` 字段是否为用户选择的音色
- `lockCommonSetting` 的 `bellType` 是否为10

### 5.4 设置录音铃声

**当前不支持设置录音铃声**，提醒用户在智慧生活APP上进行操作。

## 6. 注意事项

### 6.1 创意门铃优先原则
当用户想要设置铃声时，先判断创意门铃中是否存在对应文字，若存在则设置创意门铃，若不存在则设置文字铃声。

### 6.2 文字铃声音色选择（强制）
- 设置文字铃声前，必须询问用户选择音色
- 不能擅自决定音色，必须等待用户明确选择
- 必须向用户展示所有可选音色及其特点

### 6.3 保持配置一致性
- 修改配置时，除要修改的字段外，其他参数应保持与原有配置一致
- 特别是 `rpt`、`rd` 等控制参数，不要随意更改

### 6.4 设置后验证
- 每次设置完成后，必须重新查询设备状态验证修改是否成功
- 向用户确认最终设置的文字内容和音色

## 7. 常见错误示例

### ❌ 错误做法
```
用户："把门铃改成有客人来啦"
→ 直接设置文字铃声，使用默认音色tb=0
→ 没有询问用户音色选择
```

### ✅ 正确做法
```
用户："把门铃改成有客人来啦"
→ 查询创意门铃列表，确认不存在该文字
→ 询问用户："请选择音色：0-小艺女声，1-小艺少女，3-小艺男声，4-小艺童声"
→ 用户选择："用小艺少女吧"
→ 查询现有配置，保持其他参数不变
→ 设置文字内容，使用tb=1
→ 设置铃声模式为文字铃声
→ 验证设置结果
→ 告知用户："已成功设置门铃为'有客人来啦'，音色为小艺少女"
```
