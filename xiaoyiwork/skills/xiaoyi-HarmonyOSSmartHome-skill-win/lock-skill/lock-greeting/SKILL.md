# 门锁出门/回家留言设置功能Skill

## 1. 必读项

本技能用于**控制**门锁的出门/回家留言设置，包括添加、删除、修改留言等操作。**不支持查询操作，查询操作请参考lock-info**。

### 服务ID（sid）
- **sid**: `homeGreeting`

### 核心参数速查

| 参数 | 含义 | 取值说明 |
|------|------|----------|
| `act` | 操作类型 | 0=增加, 1=删除, 2=修改 |
| `vid` | 留言ID | 回家:1-5, 出门:51-53 |
| `uid` | 用户ID | 回家:用户ID/"all"/"1,3,5", 出门:空字符串"" |
| `rpt` | 重复类型 | 0=仅一次, 1=每天, 2=每周, 3=每月, 4=每年, 5=指定日期 |
| `rd` | 周期 | 与rpt配合：每天=""，按周="1,2,3,4,5,6,7"，每月="21"，每年="1,2" |
| `ve` | 留言内容 | 自定义文本 |
| `tb` | 音色 | 0=小艺女声, 1=小艺少女, 3=小艺童声, 4=小艺男声 |
| `st/et` | 时间范围 | 格式HH:mm，24小时制 |
| `type` | 语料类型 | 1=文字留言, 2=录音留言 |
| `switch` | 播放开关 | 0=关闭, 1=开启 |

### 重要说明
- 回家留言和出门留言是不同的功能，执行时注意根据用户要求区分
- 留言的音量大小可以在音量设置-留言/天气提醒音量中进行设置
- 修改留言后，会在下次【门锁在线】时生效，以下任一情况会让【门锁在线】：
  1. 开关门
  2. 产生逗留录像或图片
  3. 有人按门铃
  4. 开启实时视频

### VID说明
| 类型 | VID范围 | 最大数量 |
|------|---------|----------|
| 回家留言 | 1, 2, 3, 4, 5 | 5条 |
| 出门留言 | 51, 52, 53 | 3条 |

### 用户说明
- 用户开门时，门锁可以区分回家的用户，因此可以针对用户设置回家留言
- 用户出门时，门锁无法区分离家的用户，因此出门留言的用户均设置为所有用户（uid=""空字符串）

## 2. 触发关键字

当用户提到以下关键词时，应加载本技能：
- 出门留言、回家留言
- 留言设置、添加留言、删除留言、修改留言
- 门锁语音提醒、对家人说、对XX说
- 提醒孩子、提醒家人

## 3. 操作流程

### 3.1 添加留言流程 (act=0)

```
1. 确定留言类型 → 回家(vid 1-5) 或 出门(vid 51-53)
2. 查找可用VID → 从小到大遍历未占用的VID
3. 确定目标用户 → 回家可指定用户/全部，出门的uid必为空
4. 确定重复规则 → rpt + rd 参数组合
5. 选择音色 → tb参数（默认0小艺女声）
6. 构造data发送 → 无需用户确认直接执行
```

### 3.2 删除留言流程 (act=1)

```
1. 查询现有留言 → 确定要删除的vid（参考lock-info）
2. 获取用户确认 → 删除操作有破坏性，必须确认
3. 构造删除命令 → 只需vid+act，其他字段可省略
4. 发送执行 → 以vid唯一标识删除
```

### 3.3 修改留言流程 (act=2)

```
1. 查询现有留言 → 确定要修改的vid
2. 获取用户确认 → 修改操作需用户确认
3. 确定变更内容 → 内容/用户/时间/音色等
4. 构造修改命令 → 完整保留原vid，修改目标字段
5. 发送执行
```

## 4. 命令格式

```bash
node common-skill/bin/smarthome-claw.js control_device \
  --dev-id "设备ID" \
  --prod-id "产品ID" \
  --operation "POST" \
  --sid "homeGreeting" \
  --data '{"cfg":[{留言配置}],"ts":"时间戳"}' \
  --verbose
```

## 6. 核心规范 (Critical Rules)

1. **增量更新原则**：`cfg`数组**仅包含**本次操作的留言配置，**严禁**携带其他留言数据
2. **VID唯一性**：已占用的VID不能重复使用，若满额需先删除再添加
3. **用户确认要求**：
   - 添加留言 → 空位充足时无需确认
   - 修改/删除留言 → **必须用户确认**
4. **uid格式**：
   - 回家-指定用户：`"3"`
   - 回家-全部用户：`"all"`
   - 回家-部分用户：`"1,4,5"`
   - 出门留言 → **固定空字符串 `""`**
5. **删除命令特点**：系统仅依据vid识别删除目标，其他字段可任意值

## 7. 注意事项

- 本技能仅支持控制操作，**不支持查询**
- **删除/修改留言必须用户确认**后执行
- 门锁最多存在5条回家留言(vid 1-5)，3条出门留言(vid 51-53)
- 留言生效需门锁在线（开关门/逗留录像/按门铃/开启实时视频）
