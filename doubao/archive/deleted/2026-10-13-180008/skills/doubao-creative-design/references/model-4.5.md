# 4.5 模型改写规则

## 用途
- 选择4.5模型进行生图时读取，明确生图prompt的改写和推演规则
- 需搭配各产物 reference 的平台特征、风格调性、尺寸、安全区、品类结构、视觉风格和合规红线共同完成改写。
- 只规定 Prompt 改写方式，不新增模型参数，不改变 `image_gen`、`image_edit`、`prompt`、`ratio` 和参考图入参。
- 最终 SP 是一段精简自然语言。`ratio` 单独作为工具参数传入。

## 接力前提

- 不得脱离产物 / 场景特征 reference 单独使用。
- 先完成产物路由；命中具体产物时，先读取对应产物 reference，提取产物结构、风格调性、平台画幅与安全区、信息层级、系列图、核心资产和合规要求，未命中具体产物时，使用主 `SKILL.md` 的通用产物规则作为底稿。
- 再用本文件完成 4.5 改写。

## 通用原则

- 根据用户输入长度做核心提炼或合理扩充，品牌名、产品名、活动名、人名等专有信息必须逐字保留。
- 每张图分别形成独立、完整、可视觉化的中文 Prompt，不使用“同上”“其余一致”“若干元素”等省略表达。
- 最终传入图片工具的 Prompt 必须合并为一段连贯中文，不保留内部小标题、规划字段或工具字段。
- 平面设计只描述目标平面载体；除非目标是样机或空间展示，不添加无关现实背景。
- 先读取目标产物 reference，再将其中的平台特征、画幅、安全区、品类结构和红线合入本规则。

## T2I 文生图改写

### 固定结构

按“总览句 → 分区扫描主段落 → 条件收束 → 画幅确认”完成内部方案，再整理成一段连续 Prompt。

1. **总览句**：先说明横版、竖版或方形方向，再前置核心风格、色彩影调和画面类型；首句不写具体比例数字。
2. **分区扫描**：占主体篇幅。按从上到下、从左到右、从外到内或从背景到主体的物理空间顺序逐区展开。
3. **条件收束**：元素较少且存在统一视觉特征时，用 1–2 句收束整体配色、排版、光影和氛围；复杂画面可省略。
4. **画幅确认**：内部方案确认目标比例；工具调用时通过 `ratio` 单独传入，不把比例字段或像素尺寸写进最终 Prompt。

### 三层推演

先确定载体骨架，再确定场景语义，最后完成实例填充：

- **载体骨架**：画面类型、物理分区、阅读顺序、主体位置和信息层级。
- **场景语义**：用户目标、平台阅读场景、传播语气、品类特征和视觉方向。
- **实例填充**：把每个可见元素、文字、图形、材质、光影和关系写成可直接生成的具体内容。

### 基础 9 维

分区内的每个重要元素必须覆盖以下维度；具体枚举和平台化写法以目标产物 reference 为准：

1. **绝对位置**：使用明确方位、占比、对齐和空间关系，避免“旁边”“附近”“大概”。
2. **元素类型**：写明主体、标题、标签、卡片、图标、道具、背景或装饰的具体类型。
3. **形态细节**：说明轮廓、组成、姿态、角度、材质和可见结构，不只写功能名称。
4. **内容描述**：图片写清主体、场景和状态；文字逐字写出真实文案。
5. **文字视觉样式**：写清字体气质、字号层级、字重、字色、底色、边框、描边和必要特效。
6. **状态信息**：说明人物表情、物体状态、界面状态、动势或变化状态。
7. **关联关系**：说明元素之间的对齐、层叠、遮挡、指向、比例、主次和阅读顺序。当需要图文并茂时，必须合理安排文字和图片各自的体积占比，避免单一方过度挤压画面空间。
8. **风格特征**：从目标产物 reference 选择与任务匹配的明确视觉风格，不使用空泛的“高级”“好看”。
9. **视觉处理工艺**：写清光线、阴影、颗粒、印刷、拼贴（设计时必须是复杂、分层的编辑日志拼贴，具有原始、个人化的叙事感，严禁简单的平铺拼贴）、描边、辉光、纹理或渲染处理。

### 平台增强维度

- 命中媒体、电商、品牌、知识教育等专门产物时，在基础 9 维后补入对应 reference 规定的平台强调维度。
- 媒体类现有规则中的第 10/11/12 维必须保留，用于约束点击钩子、平台识别、信息密度、主体占比、UI 安全区或该平台特有的视觉结构。
- 平台增强维度必须转译成画面结构、阅读场景和视觉语言；最终 Prompt 不直接写平台名或内部路由名称。

### 描述密度

- 简洁平面设计的设计方案不少于约 600 字符。
- 中等信息量的营销海报、社媒封面或界面不少于约 1200 字符。
- 多人、多区域或复杂界面场景不少于约 2000 字符。
- 每个独立元素都应被覆盖；重复元素写明数量及实例差异。
- 所有可见文字必须逐字写出；每个独立元素至少包含一个明确颜色词。
- 长描述持续使用绝对方位词和空间衔接词，保证分区关系可以复现。

## I2I 图生图改写

### 固定结构

按“编辑目标 → 保留项 → 编辑项 → 空间线性描述”完成内部方案，最终合并成一段连续 Prompt。

1. **编辑目标**：直接说明来源图片、编辑对象、目标状态和作用范围。
2. **保留项**：明确主体身份、产品或包装结构、构图关系、位置比例、透视角度、光影方向、材质细节、文字样式和层级关系中不能改变的内容。
3. **编辑项**：逐项写明删除、替换、新增、背景替换、文字改写、比例改版、属性修正、局部重绘或结构重排。
4. **空间线性描述**：按物理空间顺序串联每个编辑区域的位置、原图内容、保留内容、修改动作、目标结果和融合约束。

### 参考图规则

- 多张输入图按工具传入顺序使用 `[img0]`、`[img1]`、`[img2]` 标明作用，不得混用。
- 少复述旧图，多描述目标图。新载体或新场景应让目标画面占主要篇幅；品牌、包装等现有 reference 明确要求时，目标图描述不少于 Prompt 的 70%。
- 只提取任务需要继承的主体、结构、品牌识别、配色比例、字体气质、纹样、材质、光影或版式锚点。
- 旧背景、旧裁切、偶然道具、噪声和无关文字不作为锚点，除非用户明确要求保留。
- 不得只写“参考原图”“保持不变”“其他不变”；保留项和修改项必须具体。
- 文字替换必须逐条写明原文案、目标文案、位置以及需要保持的字体、字号、字重、颜色和对齐方式。

## 平台尺寸与画幅适配

- 用户明确比例或尺寸时优先遵从；否则使用目标产物 reference 的默认比例和安全区。
- 多平台、多比例或多尺寸任务按用途分别生成，每张图独立确定 `ratio` 和构图，不把不同正式产物合并到同一画布。
- 比例变化不是机械裁切。必须重新安排主体占比、留白、标题位置、信息密度、CTA 和安全区。
- 工具只支持 `width/height` 时，由既定 `ratio` 推导；不在 Prompt 中加入像素尺寸、比例字段或画幅参数。

## 系列图与前图参考

- 用户要求系列图、套图、连续页或延展前图时，先规划每张图的角色、信息任务、排版分组和依赖关系。
- 一旦存在上传图、用户指定前图或已确认核心资产，后续一致性延展必须使用 `image_edit`，并把对应图片加入参考图列表；不得仅凭文字用 `image_gen` 重画近似版本。
- 系列一致性分为两层：跨全套统一品牌层锚点，同角色分组统一排版、图文比例和信息密度等角色层锚点。
- 首张或核心图负责建立全局锚点；新角色分组的第一张以上传前图或核心图为参考，同组后续图可同时引用全局锚点和同组前图。
- 不机械地让每张图只参考上一张。根据用户指代、核心资产、角色分组和主体匹配度选择参考图。
- 用户明确说“基于上一张”“延展这张”时，必须把被指向的前图作为参考，并在 Prompt 中写清 `[imgX]` 的保留作用和修改范围。
- 同一组多图保持参考图顺序和锁定变量一致；每张图仍需独立完整描述，不得使用“同上”。
- 系列图共享核心资产和视觉语言，但每张图必须承担不同功能，并在构图、场景、信息层级、镜头、背景或物料角色中形成真实差异。

## 文字与事实纪律

- 中文待渲染文字使用中文双引号，例如：`“中文文案”`；英文待渲染文字使用英文双引号，例如：`"English copy"`。
- 中文与英文混排时分别使用对应引号；不得用中文引号包裹纯英文文案。
- 禁止使用 `XX`、`某某`、`标题文案`、`待补充文字`、`相关说明`、`若干文字`、`同上`、`占位符` 等让模型自由补字的表达。
- 高密度信息物料先建立可见文字清单；最终 Prompt 只渲染清单中的文字，并把文字与对应容器、位置和层级绑定。
- 价格、日期、折扣、销量、功效百分比、排名、评分、认证编号和监管声明只能来自用户或已确认资产。
- 不直接使用第三方受保护 IP 或在世艺术家姓名作为风格锚点，改写为通用视觉语言。
- 不使用 HEX、模型名、seed、文件路径、URL、内部 skill 名称或工具字段描述画面。

## 生成前后检查

生成前检查：

- 是否选对 `image_gen` 或 `image_edit`。
- 是否锁定核心资产并传入正确参考图。
- 是否为每张图写了独立完整的 Prompt 和 `ratio`。
- T2I 是否完整覆盖所有维度，完整描述所有画面内容；I2I 是否写清保留项、修改项和目标画面。
- 平台比例、安全区、文字纪律和事实信息是否符合目标产物 reference。
