# 小红书视觉营销配图与文案生成器

## 主 Skill 路由适配

本 ref 只提供小红书平台媒体创意的产物规则。被 `doubao-creative-design` 路由调用时，工具协议、澄清轮次、核心资产记录、张数策略、prompt 总规则和关键实体信息红线以主 `SKILL.md` 为准；本文件只补充小红书平台视觉特征、9 大赛道核心、笔记封面/配图结构、长图强制规则、传播文字规则与平台禁忌。

本 ref 不强行限制媒体物料张数。用户明确要求多页笔记、套图轮播、长图文或不分页长图时，按内容结构规划足够页数；用户未指定张数时，先按完成传播目标所需的最小张数规划，避免为了凑数量生成重复图。

**⚠️长图生成强制规则**：当用户明确要求"生成一张长图"、"不要分多页"或"合并在一张图里"时，**必须严格遵守指令，仅输出一张包含所有核心信息的长图（如比例使用 9:16 或更长）**，严禁擅自将内容拆分为多页分屏展示。在长图排版时，需采用垂直瀑布流，通过清晰的区块分割保证阅读体验。

## 概述
用于生成符合小红书视觉规范的营销配图（笔记封面、笔记配图、长图文、单图、多图轮播等）及配套发布文案，帮助用户快速创建高种草率的小红书视觉内容。
核心原则：以真实照片主导、价值快速可见、个人经验可感知为平台视觉基础；根据内容选择单图摄影、图文分区、编辑网格、照片序列或拼贴语法，保持自然生活场域、明确主次、真实情绪和多图系列感，同时遵循文字渲染规范与平台合规红线。

## 使用场景
**何时触发该 skill：**
- 用户的任务描述中包含"小红书"、"笔记"、"种草"、"OOTD"、"探店"、"穿搭分享"、"美妆测评"、"手账"、"日系胶片"、"孟菲斯拼贴"、"Y2K"、"霓虹"、"打工人干货"、"避坑"等相关关键词。
- 用户明确要求生成具有小红书平台风格的笔记封面或多图轮播内容。
- 在多轮对话中，当前轮次为上述小红书配图任务的延续、修改或补充说明时（即使未显式提及上述关键词）。

**何时不触发该 skill：**
- 纯文字翻译、纯代码编写等与社媒配图/视觉营销/发布文案完全无关的任务。
- 明确目标投放在 B 站/抖音/快手/朋友圈/公众号等其他平台时，应路由到对应平台 ref。

## 输入
- **发布主题**：一句话说明"你想让读者看完得到什么"。用户未明确时，根据已给主体、用途、参考图和平台语境内部推断；只有主题缺失到无法确定画面核心时，按主 `SKILL.md` 只问一个关键问题。用户说"你自己定/随便定"时，直接选择最贴近上下文的主题并执行。
- **关键实体信息确认与保留（如需）**：
  - 当用户的主题或需求暗示了必须出现具体的活动日期、具体的人名、活动地点、商品价格等关键实体信息时，按主 `SKILL.md` 的澄清规则处理。禁止使用"xx"、"某某"等指代词；用户未提供且无法确认时，不编造真实日期、价格、地点、人名、认证编号或监管声明，可改用非具体表达或不在画面中渲染该信息。
  - **⚠️专有名词保留约束**：如果用户的 prompt 中已经提供了具体的品牌名、活动名、产品全称等关键实体信息（如"怡宝矿泉水"），**绝对禁止在推演和撰写提示词时对其进行省略或概括**（如省略为"矿泉水"），必须原封不动地保留并应用到画面主体描述或文字渲染方案中。
- **参考图**：根据用户上传/提供的图片进行意图推断（如品牌素材、产品展示、人物姿态、场景氛围、构图、光影、色彩、风格等，详见参考文件中的 [附表2：参考图推演与高级审美风格提升规则](#附表2参考图推演与高级审美风格提升规则)）。
  - *注：若是"随手拍"低质产品图，需主动提升质感；不确定参考意图时需向用户提问确认。*
- **生成张数**：
  - 未指定时，文生图通常规划 **1-4 张**，图生图通常规划 **1 张**；若主题天然需要封面、铺垫、核心要点、收获、CTA 等连续阅读，可增加页数，不设置机械硬上限。
  - 用户未指定生成单张长图，但明确要求生成多图（如"完整的多页图文"、"全套配图"）时，默认采用**分页多图**形式。根据用户的意图自行判断用多少张图能表达清楚主题，一般遵循"主题能展开说的信息越多，所需的张数越多"的规律；页数必须服务内容结构，不能重复凑数。
  - 用户明确要求生成多张或特定张数的图时（如"3 张分集封面"），严格按用户要求规划/生成张数。
  - **️长图推演要求**：必须按照用户需求产出对应的整张长图，不要进行分页。但在设计方案推演时，要保证整张图的信息密度与逻辑连贯性和分页保持一致，长图各板块（通常是从上至下垂直排布，引导向下滑动阅读）必须有序衔接，自然过渡，文案详实具体。

## 核心流程
**Step 1: 需求分析与提示词处理**
- 确认或内部推断用户发布主题；只有无法确定传播核心时才按主 `SKILL.md` 澄清。
- 根据用户 prompt 长短进行**核心提炼**或**合理扩充**。
- 必须将需求收束为以下 7 项分析结果：
  1. **内容类型**：从小红书 9 大赛道中定 1-2 个主类型。
  2. **钩子潜力**：识别钩子类型（数字/痛点/好奇/利益/身份），给出 1 个更强的标题钩子备选。
  3. **受众**：主要受众 + 次要受众 + 他们最在意的 1 句话。
  4. **互动信号**：点赞/收藏/评论/关注（各 1 条）。
  5. **视觉表现**：把内容元素映射到视觉载体（数据→大数字；对比→左右分屏；步骤→1→2→3 流程；清单→列表卡片；情绪→表情/场景）。照片型内容同时规划主镜头、环境或动作镜头、细节证据与可选过渡氛围，并让不同照片具备景别、视角或时刻变化。
  6. **滑动流**：封面 → 铺垫 → 核心（每页 1-2 要点） → 收获 → 结尾 CTA。
  7. **发布文案规划**：规划发布文案的正文内容（包括标题、正文开头、正文主体、正文结尾、话题标签）等。

**Step 2: 匹配平台视觉特征与赛道核心**
必须根据小红书平台共性与赛道应用视觉（详见 [附表1：小红书视觉特征与赛道核心](#附表1小红书视觉特征与赛道核心)）。

**Step 3: 推演设计方案**
遵循三层推演流程：明确骨架 -> 场景语义推演 -> 实例填充。
- **⚠️平台全局修饰词**：所有发布在小红书上的生图需求，无论是何种赛道或风格，在最终组装 Prompt 时都必须加上“杂志”这一形容词，以强化画面的编辑感和高级感。
- **特定场景产物声明**：如果主题内容符合活动专题宣传页的调性，推荐在 Prompt 的开头明确点明产物类型为“活动专题页封面”。
- **⚠️色彩反刻板原则**：在推演配色方案时，**绝对禁止对季节、特定概念进行低级的视觉刻板映射**（例如：春天/护肤必用大面积绿色、秋天必用黄色、科技必用深蓝色）。当参考图中包含高饱和度的产品/主体色时（如绿色的瓶子），在设计背景与全局主色调时，必须**主动采用与主体色形成明显对比的中性色或低饱和辅助色进行视觉中和**，严禁直接提取主体高亮色作为大面积背景色，坚决避免造成"绿上加绿"等色彩泛滥与审美疲劳。
- **⚠️色彩多元化原则**：必须根据具体的主题调性，从以下四大色谱中动态选择主色调，且**单次生成任务中背景色与辅助色的对比度必须明显**：
  - **治愈松弛系（生活/Vlog/种草）**：清透冷白、低饱和浅灰、雾蓝、灰粉与柔和自然色。
  - **千禧潮酷系（活动宣发/大字报/Y2K）**：半透明冰蓝色、香芋淡紫、酸性极光渐变、银河灰调叠加强烈霓虹对比色。
  - **复古质感系（穿搭/经验干货/美妆）**：牛皮纸原色、胶片噪点墨绿、中古红棕、水洗丹宁蓝。
  - **现代克制系（专业干货/商业招商）**：微水泥冷灰、临床纯白、极简大留白叠单点高饱和克莱因蓝或无机绿。
- **暖浅中性色显式解锁**：在 5.0 Pro 轨中，米白、奶油白、暖白、燕麦色、奶咖浅底和米黄默认不由系统主动选作大面积背景；用户在当前请求中明确指定该色系、明确要求继承参考图的该色系，或品牌与核心资产固有色需要保真时，在当前连续创作任务中按用户意图使用。新的独立任务重新采用默认配色选择。
- **⚠️文字渲染强制规则**：中文待渲染文字用中文双引号`“”`框定，英文待渲染文字用英文双引号`""`框定。非生成文字内容不能使用这两类引号表示强调。
- **多图串行推演**：如果生成多图，必须继承前一张的视觉资产，确保系列感一致。
- **Prompt 改写接力**：先应用本文件的平台与产物硬约束，再按主 `SKILL.md` 读取且只读取一个模型 reference 完成 Prompt 改写；模型轨取值不得替代或跳过本文件。
- **封面构图锚点**：没有参考版式时，先确定一个第一焦点与一条清晰阅读动线，再根据内容选择单图摄影、分栏版式、主图卫星、编辑式非对称网格、胶片接触印样、电影分镜条、满版场景细节窗、物件标本板、对比联图或叙事拼贴。主标题、人物或商品围绕同一焦点组织，安全边距与留白随构图自然分配。
- **照片角色与叙事**：Plog/Vlog、穿搭与美妆的照片型封面优先从主镜头、环境建立、人物或动作、结果展示、细节证据、第一视角、过渡氛围中选择 3–5 种角色；主镜头承担第一焦点，辅助照片补充场景、动作或证据，共同形成一个可感知的故事。
- **组件与文字**：同类信息保持一致的文字与容器语言。照片主导型封面可使用主标题与少量日期、地点或细节注释；信息型封面可增加内容钩子和说明层级。当现有文字不足以支撑画面时，在 Prompt 中加入“根据画面自动扩写合适的文案”，说明主题、受众、语气与需要补充的文案角色，引导 PE 自然完成。
- **灵动与材质**：一张封面优先围绕一种主要材质语言和一处轻量人工痕迹展开，让照片、标题、边缘、投影与注释共享同一光线和空间关系。材质服务照片内容与主题语义，叠压关系帮助阅读动线从主图进入细节。
- **字体与杂志质感**：主标题使用与主题匹配的创意字体，具体字形与字图关系由 PE 判断；摄影、穿搭、美妆、旅行和设计分享封面可引导 PE 从编辑式裁切、跨栏图片、印刷颗粒、页码、导视细线、栏目小字或大面积留白中选择最适合画面的少量锚点。

**Step 4: 红线与禁忌审查**
- 检查是否存在版权 IP、敏感词、不良视觉元素、违反公序良俗的内容（详见 [附表6：小红书硬性红线与禁忌项](#附表6小红书硬性红线与禁忌项)）。
- 检查是否存在占位符（如`[文案]`，必须写出完整明文）、站外引流、明显水印、违规医疗/功效宣传、极限词等违规元素。
- **⚠️平台隔离原则**：设计方案中**绝对禁止出现平台名称**（如"小红书风"、"RED"、"红薯"），也不要出现"种草"、"爆文"、"上首页"等平台强相关的运营词汇，需将这些概念转化为对应的纯视觉描述。
- 检查设计方案中是否包含了未与用户澄清的编造事实信息（如自己编造的日期、地点、人名、价格、认证等），若有，必须移除、改为非具体表达或按主 `SKILL.md` 的澄清规则处理，绝不允许出现占位符。

**Step 5: 调用工具生图与审查**
- **照片拼贴模式选择**：
  - **快速模式**：普通单张封面或已有高质量完整参考图时，在一次最终生成中写清照片角色、景别变化、主辅尺度、叙事动线和材质光影，由 PE 完成自然整合。
  - **高级拼贴模式**：用户明确要求高级拼贴，或穿搭、美妆任务需要多张照片共同呈现造型、妆效、产品与细节时，默认采用“先素材、后拼贴”的两阶段路径。
    1. **素材阶段**：先规划 2–4 张有效素材，包括一张主镜头，以及环境或动作、细节证据、可选结果或过渡氛围；用户已提供足够素材时直接使用。需要新建素材时，先用 `image_gen` 生成主镜头并将其作为当前核心资产，再用 `image_edit` 参考主镜头发展不同景别、角度或时刻的辅助素材。
    2. **素材一致性**：人物、服装、妆效、产品和场景保持当前任务的核心识别，辅助镜头继承主镜头的身份、造型、产品、光线与调色，并通过远近、角度或时刻变化形成互补，共同建立同一次拍摄或同一篇内容的连续感。
    3. **拼贴阶段**：使用 `image_edit` 传入已确认素材，明确 `[img0]` 为主镜头，其余图片分别承担环境、动作或细节角色；从主图卫星、编辑式非对称网格、胶片接触印样、电影分镜条、满版场景细节窗、物件标本板、对比联图或叙事拼贴中选择一个构图原型。
    4. **最终整合**：引导 PE 让照片尺度、裁切、投影、叠压、文字与留白自然协同，保留一个稳定第一焦点，并让辅助图帮助讲清内容。
- **⚠️多图生成与串联执行规则**：不管要求生成几张图，对每一张图都必须独立进行完整的方案规划。在调用生图工具时，**必须多次调用，每次调用只生成一张图**。
  - **⚠️系列图规划与参考图分层选择硬规则**：系列图/套图的一致性不是靠"每张都传前一张"这种机械做法实现的。必须**先规划、再分层锚定、再选参考图**。
    1. **规划先行**：生图前必须先输出一份"图片角色矩阵"，为每张图明确：
       - **角色定位**（封面 / 内页正文 / 干货步骤页 / 场景铺垫页 / 尾页 CTA / 分享卡等）
       - **信息任务**（是否出现产品/主体本身、是否承载教程/成分/证言/情绪金句/使用场景）
       - **排版逻辑归组**（哪些图属于同一排版分组、共享同一栅格与信息密度）
    2. **一致性分两层锚定**：
       - **品牌层锚点（跨所有图统一）**：主色调、字体规范、拼贴材质库、装饰元素基调、整体风格调性 → 由系列首图（通常是封面）锁定。
       - **角色层锚点（同角色分组内统一）**：排版栅格、文字容器样式、图文比例、信息密度 → 每个角色分组内部独立锁定。
    3. **产品/主体不必每张都出现**：套图里不同图承担不同信息任务（封面出现产品核心印象，内页可以只出现使用场景 / 成分卡 / 教程步骤 / 用户证言，尾页只有 CTA / 落款）。**参考图的目的是"保持视觉一致性"，不是"保持产品必现"**——不要因为要展示产品就强制每张图都使用产品图作为参考。
    4. **工具与参考图选择路径**：
       - **系列首图（第 1 张，通常是封面）**：调用 `image_gen`（文生图），生成后作为**品牌层锚点**，锁定主色调 / 字体 / 拼贴材质 / 装饰基调。
       - **每个新角色分组的第 1 张**：调用 `image_edit`（图生图），传入品牌层锚点（封面）URL，prompt 显式声明"参考 [img0] 的主色调 / 字体规范 / 拼贴材质 / 装饰基调，重新推演符合本角色（如内页 / 尾页）排版逻辑的画面"。
       - **同角色分组内第 N 张（N≥2）**：调用 `image_edit`，传入**该角色分组的上一张**（如生成第 3 张内页时以第 2 张内页为参考），显式声明"参考 [img0] 的排版栅格 / 文字容器 / 图文比例 / 信息密度，保持内页一致性"。
       - **必要时传多张参考图**：`image_reference_url_list` 支持数组，可传多张图，如`[img0]` = 品牌层锚点（封面，锁色调字体）+ `[img1]` = 角色层锚点（同角色分组上一张，锁排版），prompt 中显式区分两张 img 的用途和参考点，避免 AI 混用。
    5. **跨角色参考图选择偏好**：**不建议把"封面"作为"内页"的排版参考图**（封面的破框大标题 / 大留白会污染内页的信息平铺栅格），也不建议把"内页"作为"尾页 CTA"的排版参考图。跨角色优先只继承品牌层锚点（色调 / 字体 / 装饰基调），角色层锚点（排版 / 容器 / 密度）由本角色分组独立确立。
    6. **不建议仅凭文字描述用 `image_gen` 重画后续图**——纯文字复述容易出现色调漂移、字体跳变、拼贴材质不统一，一致性衍生更推荐走 `image_edit` 上传参考图进行生图。
- 必须多次调用生图工具，每次只生成一张图。
- **合格生成图要求**：
  - 用户生图需求中要求的图片、文字/产品/任意元素已正确生成，不存在物体/文字结构崩坏。
  - 画面文字与方案中列出的"文案内容"完全一致，无变形、无乱码、无裁切、无重复生成。
  - 画幅比例正确，无平台水印或违规元素。


**Step 6: 输出与交付**
- **交付图片**：按顺序编号展示最终生成的图片，说明其对应用途（如"小红书笔记封面"、"小红书多图轮播 P2"、"小红书 9:16 长图"）及与文案的对应关系。
- **发布文案（按需输出）**：仅当用户明确要求生成文案时输出。小红书文案需强闺蜜分享感、真人第一人称、Emoji 与话题标签自然分布，严禁套用其他平台调性。
- **细节反馈引导**：
  - 若本次任务仅生成了配图，主动追问用户："是否需要为您生成适配该平台的发布文案？"
  - 提供 1-3 个维度的效果延展、形式变化或多平台分发建议（例如："当前 3:4 笔记封面可调整为 4:5 用于轮播 P1，是否需要为您生成？"）。保持简短，无明确增量时不展开。

### 附表3：小红书可视化文案要求
小红书配图的可视化文案主要分为以下三类基础组件。

1. **情绪钩子(主标题)**：带有主观情绪、悬念或痛点直击。示例：`"被问爆了"` / `"千万别买错"` / `"姐妹们冲！"`。
2. **细节特征(副标/便签)**：指向具体卖点/特征的短语。示例：`"水润质地"` / `"日常通勤"` / `"压箱底干货"`。
3. **逻辑结构(序号/盘点)**：数字序号或提纲结构。示例：`"Step 1"` / `"Top 3 推荐"` / `"避坑 Tips"`。

**小红书文案组合规则与偏好**：以真实细节和明确内容价值为核心。照片主导型封面可由主标题配合少量日期、地点或细节注释；教程、测评和信息型封面可加入内容钩子、细节特征与逻辑结构。现有文字不足以支撑画面时，加入 `根据画面自动扩写合适的文案，围绕“{主题}”面向{受众}采用{语气}表达，可发展{当前画面需要的文案角色}，并自然融入当前构图层级。` 引导 PE 完成适量补充。

**可选文字载体**：根据主题和构图选择最合适的少量载体，保持同类信息一致：
- **场景光影文字**：文字与主体物或场景中的真实明暗关系结合，形成自然空间层次。
- **编辑栏目文字**：页码、日期、地点、导视细线或栏目小字沿网格和留白组织。
- **照片边缘备注**：文字落在胶片、接触印样、照片留边或空白区域，形成真实记录感。
- **主题化标签**：穿搭可使用面料标签、色样或单品注释；美妆可使用色号、质地或步骤注释；潮流主题可使用金属、镭射或立体字作为单点焦点。
