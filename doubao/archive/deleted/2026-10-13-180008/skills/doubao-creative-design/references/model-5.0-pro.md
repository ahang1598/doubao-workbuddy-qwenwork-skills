# 5.0 Pro 模型轻改写规则

## 用途

- 选择5.0 Pro模型进行生图时读取，明确生图prompt的改写和组装规则。
- 需搭配各产物 reference 的平台特征、风格调性、尺寸、安全区、品类结构、视觉风格和合规红线共同完成改写和组装。
- 只规定 Prompt 改写方式，不新增模型参数，不改变 `image_gen`、`image_edit`、`prompt`、`ratio` 和参考图入参。
- 最终 SP 是一段精简自然语言。`ratio` 单独作为工具参数传入。

## 接力前提

- 不得脱离产物 / 场景特征 reference 单独使用。
- 先完成产物路由；命中具体产物时，先读取对应产物 reference，提取产物结构、风格调性、平台画幅与安全区、信息层级、系列图、核心资产和合规要求，未命中具体产物时，使用主 `SKILL.md` 的通用产物规则作为底稿。
- 再用本文件完成 5.0 Pro 改写。

## prompt 模板

**生成目标 → 构图决策与结构型主视觉 → 主体和信息层级 → 核心事实文字 → 组件与材质系统 → PE 文案与视觉扩写 → 画面完成度。**

- 产物特征 ref 中提取并回填当前画面适用的四类信息：比例、安全区与内容结构；2–3 个品类视觉特征或平台视觉指纹；核心资产与系列一致性；合规要求。

## T2I / I2I 模板

### T2I

```text
生成一张[产物与主题]。[构图原型、结构型主视觉、主体位置、视觉动势、第一/第二/最终阅读层与留白作用]。核心文字为[逐项列出品牌、标题、日期、数字、价格、地点和专名]。[一种主风格 + 背景色/主体色/强调色 + 标题材质/主体材质/信息容器材质 + 主标题创意字体 + 组件家族]。[若传播型任务存在文案缺口，写入：根据画面自动扩写合适的文案，围绕“[主题]”面向[受众]采用[语气]表达，可发展[当前画面需要的文案角色]，并沿[构图动线或版面区域]自然融入主视觉；文案角色已完整或用户要求少字、无字时删除本句]。[按需加入一处轻量人工痕迹和至少一组明确前后或叠压关系]。引导PE围绕[主题]自然发展[结构型视觉母题、一个构图亮点、组件细节、材质光影与空间节奏]，形成完整设计。[按场景加入画面完成度描述]
```

### I2I

每张待生成图的编辑方案必须按以下要求进行组织，不可缺段。
若任务包含多张输入图，应依次使用 `[img0]`、`[img1]`、`[img2]`……进行引用；每张图的编辑方案必须独立描述，不得用 同上/其余图片一样处理等方式进行概括。

**结构**：编辑目标 + 保留项 + 编辑项 + 空间线性描述（最终输出为一段连贯的话）

##### 编辑目标

- 直接说明当前图像需要执行的编辑任务。
- 必须明确编辑对象的来源图片、目标状态和作用范围。
- 推荐句式：
  - `保持 [imgX] 中【核心主体/构图/元素】不变，将【编辑对象】调整为【目标状态】。`
  - `对 [imgX] 进行【删除/替换/新增/背景替换/比例调整/属性修正】，使画面呈现【目标结果】。`
- 说明：
  - `[imgX]` 代表当前正在处理的参考图片编号，例如 `[img0]`、`[img1]`、`[img2]`。

##### 保留项

- 明确参考图中不能改变的内容。不重复描述原图已有特征。
- 必须写清：主体身份、产品结构、构图关系、位置比例、透视角度、光影方向、材质细节、文字样式、层级关系等。
- 推荐句式：
  - `保留 [imgX] 中【主体对象】的【颜色/材质/结构/位置/比例/透视/光影】不变。`
  - `保留 [imgX] 中【区域/元素】的【样式/排版/阴影/边缘/层级关系】不变。`
- 禁止只写：
  - `保持不变`
  - `其他不变`
  - `参考原图`

##### 编辑项

- 明确当前图片中所有需要修改的对象和对应动作，并进行编辑后的空间线性描述。
- 多图任务中，每张图都必须独立完成空间线性推演，不得只描述第一张图。
- 编辑动作包括：删除、替换、新增、背景替换、文字改写、比例改版、属性修正、局部重绘、结构内重排等。
- 推荐句式：
  - `删除 [imgX] 中【位置】的【对象】。`
  - `将 [imgX] 中【位置】的【原元素】替换为【目标元素】。`
  - `在 [imgX] 的【位置】新增【元素】。`
  - `将 [imgX] 的【原背景】替换为【目标背景】。`
- 如同一张图包含多个编辑动作，必须逐项列出，不得合并成模糊描述。

**空间线性描述**
必须按物理空间顺序描述当前图片的编辑逻辑。
- 推荐顺序：从上到下/从左到右/从背景到主体/从主体到局部/从主要编辑区域到次要编辑区域
- 每个编辑区域必须写清：
  - 位置
  - 原图内容
  - 保留项
  - 编辑动作
  - 目标结果
  - 视觉约束
- 推荐句式：
  - `保留[imgX]的【保留内容】不变；对[imgX]的【修改对象】进行【删除/替换/新增/修正/重绘/重排】；呈现为【详尽的目标结果】，并保持[imgX]的【颜色/材质/光影/透视/边缘/对齐】一致。`

##### 最终输出样式说明
将上述的编辑目标、保留项、编辑项和空间线性描述**合并串联成一段连贯的话**直接输出，避免使用"编辑目标："、"保留项："等小标题分点拆分。
- **推荐输出格式**：
  `保留[imgX]的【保留内容】不变；对[imgX]的【修改对象】进行【删除/替换/新增/修正/重绘/重排】；呈现为【按照空间线性描述逻辑的详尽的目标结果】，并保持[imgX]的【颜色/材质/光影/透视/边缘/对齐】一致。`
- 说明：如同一张图包含多个编辑动作（删除、替换、新增、文字改写等），请按空间位置顺序依次在段落中写清，不要拆分成多个小点。

**文字与文案约束**
- 如当前图片涉及文字改写、翻译、加字、删字，必须逐条写清原文案与目标文案。
- 若多张图均涉及文字处理，必须分别写清 `[img0]`、`[img1]`、`[img2]` 中各自的文字替换规则。
- 所有文字必须以中文双引号""框定，包括：状态栏时间/电量、按钮文字、弹幕内容、价格标签、地址信息等。
- 禁止只用概括性描述进行文案指代。
- 推荐格式:
  - `将 [imgX] 中【位置】的原"【原文案】"替换为"【目标文案】"，保持原有【字体样式/字号/字重/颜色/背景框/位置/对齐方式】不变。`
  - `[imgX] 中【位置】的文字"【保留文案】"保持原有样式与位置不变。`
- 禁止只写：
  - `把文字换成英文`
  - `文字改一下`
  - `翻译成中文`
  - `文字保持一致`

**风格与质量约束**
写清当前图片需要保持或达到的整体风格、光线、色调、材质、阴影、真实度和融合要求。
- 推荐句式：
  - `[imgX] 整体保持【风格类型】，使用【光线类型】、【色调】、【材质处理】和【阴影方式】，使修改区域与原图自然融合。`
- 禁止只写或模糊描述：高级、自然、好看、更真实、有质感等。
- 风格约束必须与当前图片的原始内容和编辑目标一致。### I2I

```text
参考[img0]作为[核心资产 / 风格参考 / 版式参考]，延续[普通参考 3–6 项核心识别；核心资产或系统延展 6–8 项，并包含整体色调、字体气质、组件家族和装饰语言]。本次将[用户改动]，[延续原骨架或依据明确要求重构布局，合理安排图文体积占比]。核心文字为[逐项列出保持或更新的事实文字]。[结构型主视觉、美学延续与新增区域的融合方式]。[若传播型任务存在文案缺口，写入：根据画面自动扩写合适的文案，围绕“[主题]”面向[受众]采用[语气]表达，可发展[当前画面需要的文案角色]，并沿[构图动线或版面区域]自然融入主视觉；文案角色已完整或用户要求少字、无字时删除本句]。[按需加入一处轻量人工痕迹和至少一组明确前后或叠压关系]。引导PE自然细化[组件一致性、文案层级、克制且多样的装饰点缀、对象材质、光影过渡、局部层次和版面衔接]。[按场景加入画面完成度描述]
```

装配后删除方括号、字段说明和空槽，合并为一个自然段。多图使用 `[img0]`、`[img1]` 标明作用。

### 实行文案引导

- 把“用户只提供主题或主标题，且场景对应的画面仍需要副标题、短标签、说明、栏目名或行动收束中的任一角色”判定为存在文案缺口。
- 存在文案缺口时，最终 SP 必须保留一整句以“根据画面自动扩写合适的文案”开头的开放引导；不要只在内部规划中记录，也不要自行补充具体的非事实文案内容。
- 引导句写清主题、受众、语气、允许发展的文案角色（包括但不限于“副标题”、“说明”、“体验描述”等），具体文案内容由 PE 自然补全。
- 包装、品牌应用和联名概念可开放人格短句、系列标签、主题短词、体验描述和行动引导；商品名、口味、规格、价格、日期、功效、认证和监管信息继续使用已确认事实。
- 用户已提供完整文案信息、用户要求画面极简、用户需求场景为纯视觉表达或明确要求无文字时，不触发文案引导。

## 构图决策器

每张图选择一个主构图原型、一个灵动动作，并写清第一焦点、第二阅读层和最终收束位置。

| 构图原型 | 适合场景 | 核心骨架 | PE 发展方向 |
|---|---|---|---|
| 非对称主视觉 | 商品、人物、IP、品牌海报 | 主体偏轴放大，文字在对侧平衡视觉重量 | 陪衬元素、局部光影、边缘节奏 |
| 字图咬合 | KV、封面、潮流海报 | 标题与主体穿插、环绕、承托或局部叠压 | 字形变化、字图连接、层次关系 |
| 对角线动势 | 活动、运动、年轻化传播 | 主体和信息沿斜向路径推进 | 飞溅、轨迹、飘带、速度细节 |
| 环形围合 | IP、节庆、活动主视觉 | 主体居中，信息和装饰沿弧线围合 | 节点、图标、环绕节奏 |
| 叙事拼贴 | 小红书、旅行、时尚、手账 | 主图与不同景别的辅助照片共同讲述一个场景，形成大小跳跃和层叠 | 照片角色、尺度节奏、语义连接、适量材质（设计时必须是复杂、分层的编辑日志拼贴，具有原始、个人化的叙事感，严禁简单的平铺拼贴） |
| 主图卫星 | 穿搭、美妆、人物 Plog | 一张主图承担第一焦点，2–4 张细节图围绕主图形成证据与补充 | 主辅尺度、细节选择、视线回环 |
| 编辑式非对称网格 | 时尚、设计、城市生活 | 隐形网格组织照片与文字，局部跨栏或越格形成节奏 | 裁切、跨栏、留白、栏目小字 |
| 胶片接触印样 | Plog、旅行、日常记录 | 连续小格以时间、地点或动作变化串联，保留一个重点格 | 镜头顺序、编号、选片标记、胶片节奏 |
| 电影分镜条 | Vlog、探店、教程 | 远景、中景、特写或动作、反应依次展开 | 景别变化、时间推进、转场与收束 |
| 满版场景细节窗 | 松弛日常、旅行、探店 | 一张真实场景铺满画面，局部细节窗补充人物、物件或动作 | 场景氛围、窗口位置、局部呼应 |
| 物件标本板 | 穿搭拆解、美妆产品、清单 | 核心物件与配件、色样、质地或注释形成有序陈列 | 物件关系、色样、细节标注、呼吸感 |
| 对比联图 | 测评、教程、造型变化 | 双联或三联并置前后、不同方案或不同妆效 | 对齐关系、差异焦点、简明说明 |
| 字体主视觉 | 金句、品牌态度、大字报 | 标题成为最大主体，图像承担气氛和语义 | 字体表现、色块、小型信息层级 |
| 编辑网格 | 专题页、宣传页、详情页 | 网格组织模块，重点元素局部越格 | 卡片内容、栏目、间距和阅读节奏 |
| 路径叙事 | 地图、攻略、教程、活动玩法 | 路线或编号串联多个信息节点 | 节点名称、路标、说明、互动细节 |
| 电影纵深 | 摄影、人像、场景、3D | 前景引导、中景主体、背景环境形成纵深 | 镜头、景深、光影、环境叙事 |
| 分栏版式 | 封面、介绍页、图文传播 | 上下或左右建立图文主区，以一处跨栏元素连接 | 分区比例、跨栏关系、标题与主体呼应 |
| 向心爆发 | 大促、赛事、强活动传播 | 主标题或商品位于中心，信息和图形沿放射方向展开 | 爆发节奏、价格或卖点层级、中心聚焦 |
| 满版阵列 | 多 SKU、IP 群像、系列陈列 | 重复元素铺满版面，以一处尺度、颜色或朝向变化建立焦点 | 阵列密度、特异点、标签与边缘节奏 |
| 压角留白 | 书封、文创、艺术与展览海报 | 主体或文字重量集中于一角，其余区域形成连续留白 | 角部重心、留白中的小型信息和克制动线 |
| 框架画中画 | 摄影、场景 KV、空间海报 | 门窗、植物、手或前景物形成天然画框，主体位于框内 | 框内外明暗、窥视感、前景虚实和视线聚焦 |

### 选择规则

1. I2I 默认延续参考图空间骨架、主体位置和主次关系；用户有创作、重排、改版或重构需求时更新布局。
2. 单一核心主体优先选非对称主视觉、字图咬合、环形围合或电影纵深；多模块信息优先选编辑网格；流程、地图和教程优先选路径叙事。
3. 百分比分区用于专题页、详情页、规则页及产物 ref 已给出物理版式锚点的标准传播物料；艺术海报、纯摄影和实验封面使用主体关系、尺度对比和视觉动线表达。
4. 社媒封面的大标题位于首屏强阅读区，并具备手机缩略图识别度；摄影和 3D 场景按需加入景别、视角与前中后景。
5. 主原型需要增强内容特征时，叠加一个微型结构：长场景用 S 形路径引导，单主体用三分焦点承接留白，空间场景用门窗、植物或前景物形成框景，多商品或重复元素用一处尺度、颜色或朝向变化建立记忆点。
6. 产物 ref 已给出明确构图惯例时优先沿用；小红书照片型内容先根据照片角色和叙事目标，从主图卫星、编辑式非对称网格、胶片接触印样、电影分镜条、满版场景细节窗、物件标本板、对比联图或叙事拼贴中选择；单商品电商图优先非对称主视觉，多商品优先满版阵列，地图和教程优先路径叙事，书封与展览海报可选压角留白，场景摄影可选框架画中画，大促活动按内容选择向心爆发或对角线动势。

### 灵动动作

每张图选一个：超大标题、偏轴主体、局部越格、字图叠压、尺度突变、弧形路径、大片留白、非核心装饰出画。通过一个高密度区对应一个呼吸区、一组大中小尺度差和一个明确动势形成设计节奏。

装饰从主题语义提取：玩水发展水流轨迹与折射泡泡，登岛发展路线与印章，科技发展光带与界面节点。PE 围绕主题发展一个最适合当前画面的构图亮点，使画面具有辨识度和稳定重心。除非是 UI、网页设计等需要高度统一视觉语言的场景（此时要保证容器和装饰的统一性），其余情况装饰仅作为点缀时必须克制使用，并在一张图中保证其形态的多样性，严禁机械重复同质化的装饰符号（如满屏的同款气泡、同款贴纸或光斑），根据平台和赛道合理安排画面的留白与呼吸感，拒绝无意义的元素堆砌。

为减弱机械模板感，每张图按风格选择一处轻量人工痕迹：手账与拼贴使用微旋、折边、贴纸翘角或不等距排列；印刷与波普使用套色偏差、网点或印章轻微错位；摄影使用颗粒、轻微漏光或前景虚化；手绘使用线条轻颤、描边变化或色块毛边。核心文字、品牌和主体保持清晰稳定。**注意：轻量人工痕迹仅作为局部点缀，绝不允许导致画面布满密集的同质化便签或贴纸。**

每张图至少写清一组具体前后或叠压关系，明确哪个元素在前、哪个元素在后以及它如何连接阅读动线；拼贴、字图咬合和电影纵深可使用两组，极简、Logo 与纯产品主图保持一组即可。

### 结构型主视觉与组件家族

- 引导 PE 将主题母题发展成一个组织画面的结构，可承担主体舞台、视觉路径、信息容器或前后空间中的一种或多种功能。例如泡沫堆承载人物和信息卡，岛屿路线串联地图节点，建筑透视引导标题排布。
- 同类信息形成组件家族：相同角色在底层逻辑上保持一致，但具体容器间相互可以有颜色、形态、材质或倾斜角度的差异，保持画面的灵活与呼吸感（注意：绝不能机械地将所有小字说明全装进同质化、等比例的半透明底板或便签中）；主标题、节点标签、说明卡和行动信息彼此有明确层级差异。
- 引导 PE 让材质与对象自然对应，优先写清最影响画面识别的标题、主体或信息容器材质，并用一致的光影和空间气氛完成衔接。

## 文字与信息补全

### 默认路由

- **按需扩写文字**：海报、KV、小红书封面、专题页、落地页、宣传页、活动页、电商传播图、信息图、品牌应用及其他传播型平面设计，根据内容目标、画面信息量和用户已提供文案决定扩写程度。
- **纯视觉表达**：纯插画、壁纸、头像、场景图、概念视觉、无字产品图，以及用户明确要求纯画面或无字的任务。
- **I2I**：先延续参考图已确认的核心文字，再根据目标产物执行对应路由。

传播型任务先保留用户提供的核心文字，再按画面需要选择以下信息层级；当现有文案不足以支撑画面时，必须把开放引导写入最终 SP，交给 PE 自然补全：

| 产物 | 文案角色链 |
|---|---|
| 海报 / KV | 品牌或栏目 → 主标题 → 副标题 → 内容亮点 → 活动信息 → 参与引导 |
| 小红书封面 | 主标题 → 可选内容钩子 → 可选主题或细节注释 |
| 专题页 / 落地页 | Hero 标题 → 价值说明 → 栏目标题 → 模块标签 → 行动按钮 → 底部收束 |
| 宣传页 / 活动页 | 活动标题 → 主题说明 → 玩法栏目 → 规则摘要 → 活动信息 → 参与引导 |
| 电商传播图 | 活动主题 → 商品价值 → 核心卖点 → 优惠事实 → 行动引导 |

通用引导句：`根据画面自动扩写合适的文案，围绕“{主题}”面向{受众}采用{语气}表达，可发展{当前画面需要的文案角色}，并沿{构图动线或版面区域}自然融入主视觉。`

### 场景自适应文案

| 产物 | PE 文案预算 |
|---|---|
| 普通海报 / KV | 1 个副标题、2–4 个短标签、1–2 条说明、1 个行动引导 |
| 社媒封面 | 0–1 个内容钩子、0–2 个主题或细节注释；信息型封面可按画面需要增加层级，小红书注重杂志感 |
| 地图 / 攻略 | 每个已确认节点 1 个短标签，另配 1–2 个说明卡 |
| 教程 / 步骤图 | 每一步 1 个编号与步骤标题，另配 1 条总结 |
| 专题页 / 详情页 | 每个模块 1 个栏目标题与 1 条说明 |
| 电商传播图 | 2–4 个真实卖点、用户提供的优惠事实、1 个行动引导 |

中文副标题约 8–16 字，短标签约 2–8 字，单条说明约 10–24 字；节点、步骤和模块数量由真实内容结构决定。PE 扩写完成后，把所有可见文案转成带引号的真实可渲染文字，不把“副标题”“标签”“说明”等角色名称交给生图模型。

### 信息块与物理落点

- Skill 为每组信息确定内容角色、相对位置、视觉重量、字体类别及其与主视觉的关系，PE 在该关系内完成具体文案和排版细化。当需要图文并茂时，必须合理安排文字和图片各自的体积占比，避免单一方过度挤压画面空间。
- 日期与时间、地点、利益信息、玩法说明、行动引导分别形成语义块；同组信息紧密关联，组间以更大的间距、色块或方向变化建立层级。
- 核心文字采用清晰可读的主标题与正文系统；PE 可将非事实性的主题短词、编号或符号发展为小型图形文字，用于节奏、路径和边缘细节。当存在多个标签或说明时，**严禁机械地为每一条文字套上同质化的“半透明矩形底框”、“拼贴便签”或“气泡框”**。除非是 UI 界面、网页设计等需要高度统一视觉语言的场景（此时应保证使用统一的容器），其余情况文字排版应优先依靠字号对比、字重变化或极简分割线来划分层级。若必须使用容器底板作为画面点缀，必须克制使用，并在一张图中保证其形态的多样性与大小错落（容器间相互可以有颜色、形态、材质、倾斜角度等明显差异），**彻底杜绝满屏皆是同等体量、密密麻麻的半透明矩形框或便签碎片的现象（如几十张同款手写便签贴满屏幕）**。
- 主标题统一使用与主题匹配的创意字体；具体字形、字重、描边、立体感及字图关系由 PE 根据风格和构图自行规划，辅助文字保持清晰可读。
- 主标题是最大文字，通常占画面宽度约 45%–75%；副标题紧邻或承托主标题，字号约为主标题的 35%–55%；小型图形文字使用 1–3 处，字号约为主标题的 15%–25%。
- 非对称主视觉让标题与主体分居主轴两侧，次级信息在标题同侧下方；分栏版式让主副标题同组落在文字主区，CTA 在底部收束；字体主视觉让标题占主要画面高度，其他文字在边角或底部收束。
- 向心爆发让标题或利益点位于中心，卖点沿放射方向分层，日期与落款置于外围；错落拼贴与满版阵列让信息围绕主标题成组，保持一个稳定阅读起点。
- 路径叙事与编辑网格让节点、栏目按路径或网格依次展开，说明卡落在路径终点或独立信息区；压角留白让次级信息沿角部重心展开；框架画中画与电影纵深让文字落在框外或清晰景深层。

### 杂志质感叠加

杂志质感可叠加到摄影、人物、商品、拼贴和品牌传播任务，不等同于固定网格模板。可引导 PE 根据画面内容从摄影裁切、跨栏图像、印刷颗粒、纸面触感、页码、导视细线、栏目小字或大面积留白中选择少量有效锚点，并让它们与主风格、结构型主视觉和信息组件自然统一。

### 事实与文字边界

- 品牌、主标题、日期、数字、价格、地点、专名、型号和活动名称逐字取自用户或已确认资产，并用对应语言的引号标记。
- 日期、价格、折扣、销量、功效、认证、排名和监管信息只使用核心事实锚点；PE 扩写副标题、栏目名、主题短句、卖点表达、规则摘要、标签和行动引导。
- 文案扩写只发展表达形式，不扩展事实内容；缺少事实数据时，以非事实性的主题表达、体验描述和行动引导完成层级。
- 任务类型、平台名、用途说明、风格名称和主体描述作为设计指令；用户明确指定为可见文案时纳入核心事实。
- 纯视觉任务以图形、色彩、材质和空间关系承载信息。

### 色彩规则

- 写清背景色、主体色、1–2 个强调色及整体冷暖；用户色、品牌色和核心资产固有色优先。
- **暖浅中性色显式解锁**：米白、奶油白、暖白、燕麦色、奶咖浅底和米黄默认不由系统选作背景、大面积表面或扩展配色。用户在当前请求中明确指定该色系、明确要求继承参考图的该色系，或品牌与核心资产固有色命中且需要保真时，在当前连续创作任务中按用户意图使用；新的独立任务恢复默认状态。
- 未触发显式解锁时，从纯白、冷白、中性灰、深色、品牌色或明确主题色中选择；触发后让暖浅中性色与主体、强调色和材质共同形成清晰层级。
- 背景色、主体色和强调色承担不同信息角色；中性色保持清透，强调色集中用于焦点、路径或行动信息。

字体写气质、字重对比和标题表现；材质写最关键的 1–2 类；光影写主光方向、软硬、主体明暗与空间层次。

## 画面完成度

- **基础**：`关键主体与画面信息完整置于安全边界内，四周边距均衡，背景自然铺满画布。`
- **传播型文字**：`画面文字形成清晰可读的主标题、辅助信息和行动层级。`
- **纯视觉**：`画面采用纯视觉表达，以图形、色彩、材质和空间关系承载信息。`
- **人物**：`人物五官结构自然，可见手部结构完整、五指关系自然，肢体比例协调。`

## 最终检查

- 串行读取、工具路径与 T2I / I2I 模板正确。
- 一个构图原型、一个灵动动作、三层阅读顺序明确。
- 按需使用一个微型结构、一处轻量人工痕迹和一组前后或叠压关系。
- 传播型任务先判断文案缺口；存在缺口时，最终 SP 必须出现以“根据画面自动扩写合适的文案”开头的完整开放引导，文案完整或用户要求少字、无字时不加入；纯视觉任务保持纯画面。
- 信息按语义成组并落在数量、长度和版面范围内，核心文字与图形文字角色清楚，主标题使用与主题匹配的创意字体。
- 核心事实、参考资产、美学系统和色彩规则落实。
- PE 引导与当前画面需要匹配，能够自然发展主题文案、视觉母题、构图亮点或空间节奏，不为完成清单堆叠元素。
- 最终 SP 连贯精简，内部字段与空槽已清理。
