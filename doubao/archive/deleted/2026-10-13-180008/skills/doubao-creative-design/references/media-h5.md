# H5 移动端互动长页视觉营销配图与文案生成器

## 主 Skill 路由适配

本 ref 只提供 H5 移动端互动长页媒体创意的产物规则。被 `doubao-creative-design` 路由调用时，工具协议、澄清轮次、核心资产记录、张数策略、prompt 总规则和关键实体信息红线以主 `SKILL.md` 为准；本文件只补充 H5 视觉特征、5 大子类核心、分页内容策略、传播文字规则与平台禁忌。

本 ref 不强行限制媒体物料张数。H5 通常需要多页分发（首屏/序言/正文篇章/尾屏 等），用户明确要求多页、单页长图流或不同主题分集时，按内容结构规划足够页数；用户未指定张数时，先按完成传播目标所需的最小张数规划，避免为了凑数量生成重复图。

## 概述
用于生成符合 H5 移动端互动长页视觉规范的营销配图（高级叙事长页、游戏化互动、活动邀请函、品牌故事/年度账单、产品发布等）及配套发布文案，帮助用户快速创建高沉浸感的 H5 视觉内容。
核心原则：严格遵守 H5 独家视觉指纹（极强的沉浸感与连续性阅读体验、强制分页多图、各页之间高度一致的视觉系统 主色调/字体规范/背景质感、明确的交互引导符号 向上滑动箭头/闪烁点击按钮、手机全屏视觉纵深 重要信息不贴边），保证 5 大子类的核心策略与系列感，同时强制遵循文字渲染规范与平台合规红线。

## 使用场景
**何时触发该 skill：**
- 用户的任务描述中包含"H5"、"长页 H5"、"移动端长页"、"互动长页"、"邀请函 H5"、"品牌故事 H5"、"年度账单 H5"、"产品发布 H5"、"游戏化营销 H5"、"抽奖 H5"、"裂变活动 H5"等相关关键词。
- 用户明确要求生成多页连续可拼接的移动端 9:16 长页视觉内容。
- 在多轮对话中，当前轮次为上述 H5 长页任务的延续、修改或补充说明时（即使未显式提及上述关键词）。

**何时不触发该 skill：**
- 纯文字翻译、纯代码编写等与社媒配图/视觉营销/发布文案完全无关的任务。
- 明确目标产物为竖版独立海报/横向 Banner/平台特定笔记封面/视频封面时，应路由到对应 ref（media-poster / media-banner / media-xiaohongshu / media-douyin 等）。

## 输入
- **发布主题**：一句话说明"你想让读者看完得到什么"。用户未明确时，根据已给主体、用途、参考图和投放场景内部推断；只有主题缺失到无法确定画面核心时，按主 `SKILL.md` 只问一个关键问题。用户说"你自己定/随便定"时，直接选择最贴近上下文的主题并执行。
- **关键实体信息确认与保留（如需）**：
  - 当用户的主题或需求暗示了必须出现具体的活动日期、具体的人名、活动地点、商品价格等关键实体信息时，按主 `SKILL.md` 的澄清规则处理。禁止使用"xx"、"某某"等指代词；用户未提供且无法确认时，不编造真实日期、价格、地点、人名、认证编号或监管声明，可改用非具体表达或不在画面中渲染该信息。
  - **⚠️专有名词保留约束**：如果用户的 prompt 中已经提供了具体的品牌名、活动名、产品全称等关键实体信息（如"怡宝矿泉水"），**绝对禁止在推演和撰写提示词时对其进行省略或概括**（如省略为"矿泉水"），必须原封不动地保留并应用到画面主体描述或文字渲染方案中。
- **参考图**：根据用户上传/提供的图片进行意图推断（如品牌素材、产品展示、人物姿态、场景氛围、构图、光影、色彩、风格等，详见参考文件中的 [附表2：参考图推演与高级审美风格提升规则](#附表2参考图推演与高级审美风格提升规则)）。
  - *注：若是"随手拍"低质产品图，需主动提升质感；不确定参考意图时需向用户提问确认。*
- **生成张数**：
  - 未指定时，文生图通常规划 **3-6 张分页**（首屏/序言/正文篇章 1-2 页/尾屏），图生图通常规划 **1 张**；若主题天然需要更长的篇章结构或单页长图流，可增加页数，不设置机械硬上限。
  - 用户明确要求生成多张或特定张数的图时（如"6 页 H5"），严格按用户要求规划/生成张数。

## 核心流程
**Step 1: 需求分析与提示词处理**
- 确认或内部推断用户发布主题；只有无法确定传播核心时才按主 `SKILL.md` 澄清。
- 根据用户 prompt 长短进行**核心提炼**或**合理扩充**。
- 必须将需求收束为以下 7 项分析结果：
  1. **内容类型**：从 H5 5 大子类中定 1-2 个主类型。
  2. **钩子潜力**：识别钩子类型（数字/痛点/好奇/利益/身份），给出 1 个更强的标题钩子备选。
  3. **受众**：主要受众 + 次要受众 + 他们最在意的 1 句话。
  4. **互动信号**：滑动查看/点击参与/分享裂变（各 1 条）。
  5. **视觉表现**：把内容元素映射到视觉载体（数据→大数字；对比→左右分屏；步骤→1→2→3 流程；清单→列表卡片；情绪→表情/场景）。
  6. **滑动流（分页流）**：首屏 → 序言 → 正文篇章（每页 1-2 要点） → 尾屏 CTA。
  7. **发布文案规划**：规划发布文案的正文内容（包括标题、序言金句、正文篇章标题、CTA 文案、品牌落款）等。

**Step 2: 匹配平台视觉特征与赛道核心**
必须根据 H5 平台共性与 5 大子类视觉（详见 [附表1：H5 视觉特征与子类核心](#附表1h5-视觉特征与子类核心)）。

**Step 3: 推演设计方案**
遵循三层推演流程：明确骨架 -> 场景语义推演 -> 实例填充。
- **⚠️色彩反刻板原则**：在推演配色方案时，**绝对禁止对季节、特定概念进行低级的视觉刻板映射**（例如：春天/护肤必用大面积绿色、秋天必用黄色、科技必用深蓝色）。当参考图中包含高饱和度的产品/主体色时（如绿色的瓶子），在设计背景与全局主色调时，必须**主动采用中性色（如临床白、冷白、高级灰、莫兰迪冷色）或低饱和辅助色进行视觉中和**，严禁直接提取主体高亮色作为大面积背景色，坚决避免造成"绿上加绿"等色彩泛滥与审美疲劳。
- **⚠️文字渲染强制规则**：中文待渲染文字用中文双引号`“”`框定，英文待渲染文字用英文双引号`""`框定。非生成文字内容不能使用这两类引号表示强调。
- **多图串行推演**：如果生成多图，必须继承前一张的视觉资产，确保系列感一致。H5 多页之间必须保持**高度一致的视觉系统**（主色调、字体规范、背景质感、装饰元素），任何一页都不能突兀脱离整体调性。
- **Prompt 改写接力**：先应用本文件的平台与产物硬约束，再按主 `SKILL.md` 读取且只读取一个模型 reference 完成 Prompt 改写；模型轨取值不得替代或跳过本文件。

**Step 4: 红线与禁忌审查**
- 检查是否存在版权 IP、敏感词、不良视觉元素、违反公序良俗的内容（详见 [附表6：H5 硬性红线与禁忌项](#附表6h5-硬性红线与禁忌项)）。
- 检查是否存在占位符（如`[文案]`，必须写出完整明文）、站外引流、明显水印、违规医疗/功效宣传、极限词等违规元素。
- **⚠️平台隔离原则**：设计方案中**绝对禁止出现平台名称**（如"微信 H5"、"小程序风格"），也不要出现"刷屏"、"病毒裂变"等平台强相关的运营词汇，需将这些概念转化为对应的纯视觉描述。
- 检查设计方案中是否包含了未与用户澄清的编造事实信息（如自己编造的日期、地点、人名、价格、认证等），若有，必须移除、改为非具体表达或按主 `SKILL.md` 的澄清规则处理，绝不允许出现占位符。

**Step 5: 调用工具生图与审查**
- **⚠️多图生成与串联执行规则**：不管要求生成几张图，对每一张图都必须独立进行完整的方案规划。在调用生图工具时，**必须多次调用，每次调用只生成一张图**。
  - **⚠️系列图规划与参考图分层选择硬规则**：H5 多页一致性不是靠"每页都传上一页"这种机械做法实现的。必须**先规划、再分层锚定、再选参考图**。
    1. **规划先行（角色矩阵先行）**：生图前必须先输出一份"页面角色矩阵"，为每一页明确：
       - **角色定位**（首屏 / 序言金句页 / 正文篇章页 / 数据可视化页 / 互动交互页 / 尾屏 CTA / 分享卡等）
       - **信息任务**（是否出现主视觉主体、是否承载章节标题 / 数据 / 情感金句 / CTA 按钮 / 分享引导）
       - **排版逻辑归组**（哪些页属于同一排版分组、共享同一栅格与信息密度，如"所有正文篇章页"共享一组、"首屏 + 尾屏"另分一组）
    2. **一致性分两层锚定**：
       - **品牌层锚点（跨所有页统一）**：主色调、字体规范、背景质感、装饰花纹、章节编号排版规则、CTA 按钮基调 → 由首屏锁定。
       - **角色层锚点（同角色分组内统一）**：排版栅格、文字容器样式、图文比例、信息密度、卡片圆角 / 描边样式 → 每个角色分组内部独立锁定。
    3. **主体不必每页都出现**：H5 多页承担不同信息任务（首屏出现艺术主标 + 主视觉，序言只是金句，正文篇章可以只有数据 / 章节 / 图表，尾屏只有 CTA / 品牌落款）。**参考图的目的是"保持视觉系统一致性"，不是"保持主体必现"**。
    4. **工具与参考图选择路径**：
       - **首屏（第 1 页）**：调用 `image_gen`（文生图），生成后作为**品牌层锚点**，锁定主色调 / 字体 / 背景质感 / 装饰花纹。
       - **每个新角色分组的第 1 页**（如序言金句页、正文篇章页首页、尾屏 CTA）：调用 `image_edit`（图生图），传入首屏 URL，prompt 显式声明"参考 [img0] 的主色调 / 字体规范 / 背景质感 / 装饰花纹，重新推演符合本角色（如序言 / 正文 / 尾屏）排版逻辑的画面"。
       - **同角色分组内第 N 页（N≥2）**：调用 `image_edit`，传入**该角色分组的上一页**（如生成正文篇章第 3 页时以正文篇章第 2 页为参考），显式声明"参考 [img0] 的排版栅格 / 文字容器 / 图文比例 / 信息密度，保持本篇章一致性"。
       - **必要时传多张参考图**：`image_reference_url_list` 支持数组，可传 `[img0]` = 品牌层锚点（首屏）+ `[img1]` = 角色层锚点（同角色分组上一页），prompt 中显式区分两张 img 的用途。
    5. **跨角色参考图选择偏好**：**不建议把"首屏"作为"正文篇章页"的排版参考图**（首屏的沉浸式全屏主视觉 + 大标题会污染正文的信息卡片栅格），也不建议把"正文页"作为"尾屏 CTA 页"的参考图。跨角色优先只继承品牌层锚点（色调 / 字体 / 装饰花纹），角色层锚点（排版 / 容器 / 密度）由本角色分组独立确立。
    6. **不建议仅凭文字描述用 `image_gen` 重画后续页**——纯文字复述容易导致主色调漂移、装饰花纹跳变、CTA 样式不统一，更推荐走 `image_edit` 参考图路径。
- 必须多次调用生图工具，每次只生成一张图。
- **合格生成图要求**：
  - 用户生图需求中要求的图片、文字/任意元素已正确生成，不存在物体/文字结构崩坏。
  - 画面文字与方案中列出的"文案内容"完全一致，无变形、无乱码、无裁切、无重复生成。
  - 画幅比例正确，无平台水印或违规元素。


**Step 6: 输出与交付**
- **交付图片**：按顺序编号展示最终生成的图片，说明其对应用途（如"H5 首屏"、"H5 序言"、"H5 正文篇章 01"、"H5 尾屏 CTA"）及与文案的对应关系。
- **发布文案（按需输出）**：仅当用户明确要求生成文案时输出。H5 文案需主标艺术化、序言金句化、正文篇章信息分层、尾屏 CTA 强引导，严禁套用其他平台调性。
- **细节反馈引导**：
  - 若本次任务仅生成了配图，主动追问用户："是否需要为您生成适配该 H5 的发布文案与分享卡片文案？"
  - 提供 1-3 个维度的效果延展、形式变化或多平台分发建议（例如："当前 9:16 H5 首屏可调整为 3:4 用于竖版海报，是否需要为您生成？"）。保持简短，无明确增量时不展开。

## 参考附表

### 附表1：H5 视觉特征与子类核心
**默认画幅：9:16，长度可自定义加长**

- **平台共性**：极强的沉浸感与连续性阅读体验，强制要求分页多图设计，各页之间必须保持高度一致的视觉系统（主色调、字体规范、背景质感）。必须包含明确的交互引导符号（如底部的"向上滑动"箭头、闪烁的点击按钮）。排版需遵循手机全屏的视觉纵深，避免重要信息贴边。
- **核心子类**：
  - **高级叙事/特刊长页 (Premium Narrative)**：适用于周年回顾、人物专访、深度故事等。
    - **配色与风格**：根据主题情绪灵活选择基调，呈现电影级/高级杂志质感。
      - *深色基调（神秘/高级）*：沉浸式深色基底（如深邃森林绿、暗夜蓝）+ 暖色/金属色点缀（如香槟金光斑、萤火虫光效）。
      - *浅色基调（通透/治愈）*：呼吸感浅色基底（如冷白、晨雾灰、淡冰蓝）+ 同色系深色或金属质感文字点缀（如玫瑰金细线、银色字体），可辅以自然光影（如丁达尔光斑、树影斑驳）。
    - **字体与排版策略**：
      - *字体选择*：标题与数字使用优雅的衬线体/花体（可倾斜），正文使用清晰的无衬线细体，形成极强的字号与字重对比。
      - *位置与对齐*：强制使用**中轴线对称构图**，所有大标题、数字编号、金句引言必须**绝对居中对齐**，确保视觉重心稳定。长段落正文可放在居中的半透明卡片内，做左对齐处理。严禁版面重心偏移或杂乱无章的散点排布。
    - **核心元素**：半透明毛玻璃卡片、极细优雅线框、胶囊形状标签、悬浮发光粒子、极简括号 `[ ]` 或 `{ }` 装饰。
    - **分页内容策略（多页流）**：
      1. **首屏**：全屏沉浸式背景 + 居中超大艺术主标 + 诗意副标 + 氛围光斑。
      2. **序言**：居中排版的引言/金句，用细线或括号包裹，奠定情绪基调。
      3. **正文篇章**：使用巨大的半透明数字（01, 02...）作为视觉分割。内容装载于细边框的半透明卡片中，段落间用胶囊标签进行信息分层。
      4. **尾屏**：居中的胶囊形行动号召按钮（CTA）、品牌 Logo 阵列与克制的落款文字。
  - **游戏化互动/营销活动**：适用于抽奖、闯关、大促裂变、会员签到等强营销导向的 H5 页面。
    - **配色与风格**：高明度、高饱和的糖果色/多巴胺配色（如明黄、粉红、草绿），整体呈现 3D 卡通、圆润膨胀的盲盒/潮玩质感，视觉氛围热闹、欢乐、强吸引力。

### 附表3：H5 可视化文案要求
H5 配图的可视化文案主要分为以下三类基础组件。

1. **情绪钩子(主标题/篇章标)**：带有主观情绪、悬念或痛点直击。示例：`"致漫长岁月"` / `"100% 中奖"` / `"邀你共赴盛宴"`。
2. **细节特征(序言/正文金句)**：指向具体卖点/篇章核心的金句或段落。示例：`"愿你被世界温柔以待"` / `"满 100 立减 50"` / `"6 月 28 日 北京"`。
3. **逻辑结构(序号/篇章/CTA)**：数字序号或提纲结构。示例：`"01"` / `"Chapter 02"` / `"立即开始冒险"` / `"向上滑动"`。

**H5 文案组合规则与偏好**：
- **Premium Narrative（高级叙事）**：主标艺术化 + 序言金句化 + 正文使用巨大半透明数字（"01"/"02"）分章 + 尾屏胶囊形 CTA（"了解更多"）。
- **游戏化营销**：超大 3D 气泡主标（"100% 中奖"）+ 极度放大的利益点（金额/奖品名）+ 强引导 CTA（"立即开始冒险"）。
- **活动邀请函**：首页大字报主题 + 时间地点嘉宾流程（"6 月 28 日 19:00 / 北京国贸大酒店 / 主咖：嘉宾姓名"）+ 末页表单或报名按钮。
- **品牌故事/年度账单**：大号数据加粗高亮（"陪伴 365 天"）+ 极简走心文案（"你看过 12 部电影"）。
- **产品发布/测试**：每页一个核心卖点关键词（"性能"/"续航"/"外观"）+ 数据化背书（"提升 45%"）。

### 附表4：H5 硬性红线与禁忌项
- **通用强制**：必须文案明文，严禁 `[文案]` 占位符；严禁虚假标题党；金融/医疗需合规标注风险提示；严禁未成年人商业化；严禁极限词("最"/"绝对")。
- **UI 安全区**：H5 9:16 顶部 8%（状态栏）、底部 12%（Home 指示条/系统导航）禁放关键信息；左右边缘 5% 禁放关键信息。
- **平台独家红线**：严禁伪原生系统 UI（假微信通知/假支付弹窗/假短信）；游戏化 H5 严禁诱导分享文案（"不分享不能继续"）与虚假中奖承诺；活动邀请函严禁编造未与用户澄清的具体时间/地点/嘉宾信息；品牌故事/年度账单严禁编造虚假数据；产品发布 H5 严禁夸大功效宣传与未经验证的性能参数；H5 多页之间严禁出现视觉系统脱节（主色调/字体规范/背景质感）的页面。
