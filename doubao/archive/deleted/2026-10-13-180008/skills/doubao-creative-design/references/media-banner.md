# 横向 Banner / 焦点图视觉营销配图与文案生成器

## 主 Skill 路由适配

本 ref 只提供横向 Banner / 焦点图媒体创意的产物规则。被 `doubao-creative-design` 路由调用时，工具协议、澄清轮次、核心资产记录、张数策略、prompt 总规则和关键实体信息红线以主 `SKILL.md` 为准；本文件只补充横向 Banner 平台视觉特征、赛道核心、焦点图结构、传播文字规则与平台禁忌。

本 ref 不强行限制媒体物料张数。用户明确要求多张焦点图轮播、不同投放位适配或系列分发时，按内容结构规划足够页数；用户未指定张数时，先按完成传播目标所需的最小张数规划，避免为了凑数量生成重复图。

## 概述
用于生成符合横向 Banner 视觉规范的营销配图（横向 Banner、电商焦点图、信息流轮播图、活动通栏、视频封面横版等）及配套发布文案，帮助用户快速创建高点击率的横向焦点视觉内容。
核心原则：严格遵守横向 Banner 独家视觉指纹（极度压缩的垂直空间、信息高度精炼、左右分栏或居中对称构图、强视觉冲击力），保证赛道特征与系列感，同时强制遵循文字渲染规范与各平台合规红线。

## 使用场景
**何时触发该 skill：**
- 用户的任务描述中包含"Banner"、"横向焦点图"、"焦点图"、"轮播图"、"首页横版"、"通栏"、"店招"、"信息流横版封面"、"促销 Banner"、"活动 Banner"等相关关键词。
- 用户明确要求生成横向极宽比例（如 2.35:1 / 16:9 / 3:1）的焦点图或营销横版内容。
- 在多轮对话中，当前轮次为上述横向焦点图任务的延续、修改或补充说明时（即使未显式提及上述关键词）。

**何时不触发该 skill：**
- 纯文字翻译、纯代码编写等与社媒配图/视觉营销/发布文案完全无关的任务。
- 明确目标产物为竖版海报/笔记封面/H5 长页/视频竖版封面时，应路由到对应 ref（media-poster / media-h5 / media-xiaohongshu / media-douyin 等）。

## 输入
- **发布主题**：一句话说明"你想让读者看完得到什么"。用户未明确时，根据已给主体、用途、参考图和投放场景内部推断；只有主题缺失到无法确定画面核心时，按主 `SKILL.md` 只问一个关键问题。用户说"你自己定/随便定"时，直接选择最贴近上下文的主题并执行。
- **关键实体信息确认与保留（如需）**：
  - 当用户的主题或需求暗示了必须出现具体的活动日期、具体的人名、活动地点、商品价格等关键实体信息时，按主 `SKILL.md` 的澄清规则处理。禁止使用"xx"、"某某"等指代词；用户未提供且无法确认时，不编造真实日期、价格、地点、人名、认证编号或监管声明，可改用非具体表达或不在画面中渲染该信息。
  - **⚠️专有名词保留约束**：如果用户的 prompt 中已经提供了具体的品牌名、活动名、产品全称等关键实体信息（如"怡宝矿泉水"），**绝对禁止在推演和撰写提示词时对其进行省略或概括**（如省略为"矿泉水"），必须原封不动地保留并应用到画面主体描述或文字渲染方案中。
- **参考图**：根据用户上传/提供的图片进行意图推断（如品牌素材、产品展示、人物姿态、场景氛围、构图、光影、色彩、风格等，详见参考文件中的 [附表2：参考图推演与高级审美风格提升规则](#附表2参考图推演与高级审美风格提升规则)）。
  - *注：若是"随手拍"低质产品图，需主动提升质感；不确定参考意图时需向用户提问确认。*
- **生成张数**：
  - 未指定时，文生图通常规划 **1-4 张**，图生图通常规划 **1 张**；若主题天然需要焦点图轮播、多投放位适配或系列分发，可增加页数，不设置机械硬上限。
  - 用户明确要求生成多张或特定张数的图时（如"3 张轮播焦点图"），严格按用户要求规划/生成张数。

## 核心流程
**Step 1: 需求分析与提示词处理**
- 确认或内部推断用户发布主题；只有无法确定传播核心时才按主 `SKILL.md` 澄清。
- 根据用户 prompt 长短进行**核心提炼**或**合理扩充**。
- 必须将需求收束为以下 7 项分析结果：
  1. **内容类型**：从横向 Banner 赛道中定 1-2 个主类型。
  2. **钩子潜力**：识别钩子类型（数字/痛点/好奇/利益/身份），给出 1 个更强的标题钩子备选。
  3. **受众**：主要受众 + 次要受众 + 他们最在意的 1 句话。
  4. **互动信号**：点击/立即购买/参与活动（各 1 条）。
  5. **视觉表现**：把内容元素映射到视觉载体（数据→大数字；对比→左右分屏；步骤→1→2→3 流程；清单→列表卡片；情绪→表情/场景）。
  6. **焦点流**：左侧主体 → 中间核心信息 → 右侧 CTA（或居中对称分布）。
  7. **发布文案规划**：规划发布文案的正文内容（包括标题、副标、利益点、行动号召、品牌落款）等。

**Step 2: 匹配平台视觉特征与赛道核心**
必须根据横向 Banner 平台共性与赛道应用视觉（详见 [附表1：横向 Banner 视觉特征与赛道核心](#附表1横向-banner-视觉特征与赛道核心)）。

**Step 3: 推演设计方案**
遵循三层推演流程：明确骨架 -> 场景语义推演 -> 实例填充。
- **⚠️色彩反刻板原则**：在推演配色方案时，**绝对禁止对季节、特定概念进行视觉刻板映射**（例如：春天/护肤必用大面积绿色、秋天必用黄色、科技必用深蓝色）。当参考图中包含高饱和度的产品/主体色时（如绿色的瓶子），在设计背景与全局主色调时，必须**主动采用中性色（如冷白、高级灰、莫兰迪冷色）和低饱和辅助色进行视觉中和**，严禁直接提取主体高亮色作为大面积背景色，坚决避免造成"绿上加绿"等色彩泛滥与审美疲劳。
- **⚠️文字渲染强制规则**：中文待渲染文字用中文双引号`“”`框定，英文待渲染文字用英文双引号`""`框定。非生成文字内容不能使用这两类引号表示强调。
- **多图串行推演**：如果生成多图，必须继承前一张的视觉资产，确保系列感一致。
- **Prompt 改写接力**：先应用本文件的平台与产物硬约束，再按主 `SKILL.md` 读取且只读取一个模型 reference 完成 Prompt 改写；模型轨取值不得替代或跳过本文件。

**Step 4: 红线与禁忌审查**
- 检查是否存在版权 IP、敏感词、不良视觉元素、违反公序良俗的内容（详见 [附表6：横向 Banner 硬性红线与禁忌项](#附表6横向-banner-硬性红线与禁忌项)）。
- 检查是否存在占位符（如`[文案]`，必须写出完整明文）、站外引流、明显水印、违规医疗/功效宣传、极限词等违规元素。
- **⚠️平台隔离原则**：设计方案中**绝对禁止出现平台名称**（如"淘宝风"、"京东风"），也不要出现"爆款"、"上首页"等平台强相关的运营词汇，需将这些概念转化为对应的纯视觉描述。
- 检查设计方案中是否包含了未与用户澄清的编造事实信息（如自己编造的日期、地点、人名、价格、认证等），若有，必须移除、改为非具体表达或按主 `SKILL.md` 的澄清规则处理，绝不允许出现占位符。

**Step 5: 调用工具生图与审查**
- **⚠️多图生成与串联执行规则**：不管要求生成几张图，对每一张图都必须独立进行完整的方案规划。在调用生图工具时，**必须多次调用，每次调用只生成一张图**。
  - **⚠️系列图规划与参考图分层选择硬规则**：Banner 系列一致性不是靠"每张都传前一张"这种机械做法实现的。必须**先规划、再分层锚定、再选参考图**。
    1. **规划先行（角色矩阵先行）**：生图前必须先输出一份"Banner 角色矩阵"，为每张 Banner 明确：
       - **角色定位**（主 KV 首图 / 品类聚合位 / 子活动导流位 / 优惠券膨胀位 / 尾部收口位 / 多尺寸适配版本等）
       - **信息任务**（是否出现主体产品/主视觉、是否承载利益点/CTA/倒计时/子活动分流入口）
       - **排版逻辑归组**（哪些属于同一排版分组、共享同一栅格与信息密度，如"所有子活动导流位"共享一组、"多尺寸适配版本"另分一组）
    2. **一致性分两层锚定**：
       - **品牌层锚点（跨所有图统一）**：主色调、主标字体、CTA 按钮基调、几何视觉元素、主体产品/人物形象 → 由主 KV 首图锁定。
       - **角色层锚点（同角色分组内统一）**：排版栅格、图文比例、信息密度、CTA 位置与体量 → 每个角色分组内部独立锁定。
    3. **主体不必每张都出现**：Banner 矩阵不同位承担不同信息任务（主 KV 出现主体产品与核心利益，子活动导流位可以只有小图标 + 分流文案，尾部收口位只有 CTA / 品牌落款）。**参考图的目的是"保持视觉系统一致性"，不是"保持产品必现"**。
    4. **工具与参考图选择路径**：
       - **主 KV 首图（第 1 张）**：调用 `image_gen`（文生图），生成后作为**品牌层锚点**，锁定主色调 / 主标字体 / CTA 基调 / 主体形象。
       - **每个新角色分组的第 1 张**（如子活动导流位、多尺寸适配首张）：调用 `image_edit`（图生图），传入主 KV URL，prompt 显式声明"参考 [img0] 的主色调 / 字体规范 / CTA 基调，重新推演符合本角色（如子活动 / 多尺寸）排版逻辑的画面"。
       - **同角色分组内第 N 张（N≥2）**：调用 `image_edit`，传入**该角色分组的上一张**（如生成第 3 个子活动导流位时以第 2 个子活动导流位为参考），显式声明"参考 [img0] 的排版栅格 / 图文比例 / CTA 位置，保持本角色一致性"。
       - **必要时传多张参考图**：`image_reference_url_list` 支持数组，可传 `[img0]` = 品牌层锚点（主 KV）+ `[img1]` = 角色层锚点（同角色分组上一张），prompt 中显式区分两张 img 的用途。
    5. **跨角色参考图选择偏好**：**不建议把"主 KV 首图"作为"子活动导流位"的排版参考图**（主 KV 的破框主体 + 大标题会污染子活动位的信息平铺栅格），也不建议把"子活动位"作为"多尺寸适配版本"的参考图。跨角色优先只继承品牌层锚点（色调 / 字体 / CTA 基调），角色层锚点（排版 / 图文比例 / 密度）由本角色分组独立确立。
    6. **不建议仅凭文字描述用 `image_gen` 重画后续图**——纯文字复述容易导致主色调漂移、CTA 样式跳变、主体形象不统一，更推荐走 `image_edit` 参考图路径。
- 必须多次调用生图工具，每次只生成一张图。
- **合格生成图要求**：
  - 用户生图需求中要求的图片、文字/任意元素已正确生成，不存在物体/文字结构崩坏。
  - 画面文字与方案中列出的"文案内容"完全一致，无变形、无乱码、无裁切、无重复生成。
  - 画幅比例正确，无平台水印或违规元素。


**Step 6: 输出与交付**
- **交付图片**：按顺序编号展示最终生成的图片，说明其对应用途（如"首页 2.35:1 焦点图"、"店招通栏 3:1"、"信息流 16:9 横版封面"）及与文案的对应关系。
- **发布文案（按需输出）**：仅当用户明确要求生成文案时输出。横向 Banner 文案需极致精炼，利益点明确，呼吁行动直接，严禁套用其他平台调性。
- **细节反馈引导**：
  - 若本次任务仅生成了配图，主动追问用户："是否需要为您生成适配该投放位的发布文案？"
  - 提供 1-3 个维度的效果延展、形式变化或多平台分发建议（例如："当前 2.35:1 焦点图可调整为 3:4 用于竖版海报，是否需要为您生成？"）。保持简短，无明确增量时不展开。

## 参考附表

### 附表1：横向 Banner 视觉特征与赛道核心
**默认画幅：2.35:1（按投放位可更宽）**

- **平台共性**：极度压缩的垂直空间，要求信息必须高度精炼。常规横向 Banner 最常见推荐 2.35:1；视频封面、横版内容封面使用 16:9；窄条广告、店招或顶部通栏可使用 3:1。通常采用左右分栏或居中对称构图，视觉冲击力强。
- **核心赛道**：
  - **电商促销**：利益点极大，产品在左/右侧破框，使用红金或高对比色彩，配有行动号召(CTA)按钮。
  - **品牌形象**：极简大留白，高级质感，居中单主体+简短品牌 Slogan，中性或品牌色调。
  - **活动预告**：强烈的节日/活动主题氛围，大字报+时间地点，辅以气氛点缀（光效、彩带）。

#### 美学风格扩展（按需叠加）
- **电商促销**：可叠加 Hyperpop 超流行视觉 / 套印错位 Misregistration / 美式复古波普艺术 / 80s 孟菲斯 / 千禧复古风 / 网点印刷 Halftone。
- **品牌形象**：可叠加瑞士国际主义平面设计 / 包豪斯几何 / 极少主义 Minimalism / 北欧极简主义 / 东方侘寂风 / Art Deco 装饰艺术 / 大画幅胶片 / Helmut Newton 黑白人像 / 法式复古浪漫。
- **活动预告**：可叠加 Art Deco 装饰艺术 / Art Nouveau 新艺术运动 / 民国月份牌复古海报 / 中国工笔重彩 / 敦煌壁画 / 青绿山水 / 浮世绘 Ukiyo-e / 韦斯·安德森对称构图。
