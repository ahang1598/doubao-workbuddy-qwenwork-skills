# 论文写作指南

- **路由条件**：适用于根据实验、调查、数据、文献、大纲等研究材料撰写论文，以及对已有论文进行修改、规范和Word排版。可用于课程论文、期刊论文、会议论文及其他学术论文。


## 一、总原则

### （一）工作主线

**明确目标 → 核实材料 → 组织论证 → 按本指南及目标规范完成格式校验、内容回读和逐页渲染  → 交付完整论文**

先明确论文的提交对象、写作任务和评价要求，完整读取并核实用户提供的所有材料或者用户明确要求搜集的所有资料；在材料能提供够支持的范围内组织研究问题、论点和证据；最后按照目标期刊、课程或学校的规范完成内容与Word格式交付。

### （二）核心指导

1. **根据提交目标确定写作标准**：明确论文用于课程提交、期刊投稿、会议交流还是其他场景，据此确定内容重点、篇幅、专业深度和表达方式。具体篇章结构应结合用户要求、学科惯例、研究类型和现有材料确定，不强制所有论文套用同一模板。

2. **以研究问题统领全文**：从用户要求和研究材料中确定论文需要回答的核心问题，并围绕该问题筛选内容、建立论点和安排篇章。。各部分应承担相互衔接的论证任务，不得按照材料来源简单堆砌内容。

3. **使论点、证据和推理相互对应**：重要观点必须有文献、数据、实验、调查、案例或理论分析支持，并说明证据如何导向结论。区分已有研究结论、用户研究发现、分析解释和待验证推测，不得超出材料能力作出判断。

4. **保证学术表达准确克制**：核心概念、术语、数据、单位、时间和统计口径应前后一致；结论应说明适用范围和必要限制。不得以复杂表达、空泛评价或固定学术套话代替实质分析，也不得无依据地声称“首次发现”“填补空白”或“具有重大意义”。

5. **完整交付与篇幅要求**：用户要求完整论文时，应交付内容完整、引用规范、排版完成且可以直接使用的Word文档，不得只提供提纲、片段、示例或待用户继续加工的模板。论文篇幅应符合用户及目标规范要求，并足以完整展开研究问题、证据、分析和结论，不得为缩短写作过程而过度压缩内容。

### （三）真实材料使用

用户附件不能只在任务开始时被概括或摘要。开始写作前，必须回到原始附件核对将要采用的细节，避免因早期压缩理解而遗漏限定条件、数据口径、图表信息、例外情况或原文措辞。

1. **完整读取**：DOCX、PDF、图片和表格均须读取其文字与视觉信息；图、表、公式、扫描页、批注和嵌入对象中的相关内容不得因初步提取而遗漏。

2. **明确附件角色**：多附件时，先明确每份材料的用途。模板只决定结构和格式；上下文材料用于理解任务背景；素材和事实材料用于支持具体内容；示例只用于学习结构、粒度或表达。

3. **按问题整合**：不要按附件顺序分别摘要或写作。应围绕同一对象、时间、事项或结论，将分散在不同附件中的相关信息匹配、补全和整合。

4. **用户数据保真**：将用户图片或图表用于论文时，应保持清晰度和宽高比例，不得裁掉或修改会影响理解的数据、坐标轴、图例、单位、注释和来源。必要的重绘、标注或图像处理应说明，并与原始材料核对。

5. **处理冲突**：附件信息不一致时，先区分其对象、时间、地区、口径和角色；不能确认时明确保留差异或待确认，不得自行拼接、混算或选择性采用。

6. **写作前复核**：每项关键表述均应能回到原始附件确认依据；附件中的细节不足以支持时，不得依靠初步摘要或模型记忆补全。

7. **限制结论范围**：研究结论不得超出材料或实际分析所能支持的范围。材料只能支持描述性结论时，不得扩展为因果、机制或其他更强的结论。

8. **外部文献信息使用**：在用户没有明确限制或范围规定时，可以检索真实文献补充研究背景、理论、方法和讨论，但必须核验可靠的原始出处及其实际观点。不得使用外部信息替代用户未提供或未完成的实验、调查、访谈、数据分析或研究发现。

9. **保证分析可复核**：重新计算指标、制图或进行统计分析时，应保持变量、样本、公式和统计口径一致；正文、图表和附录中的结果必须相互一致。

### （四）格式识别与应用

#### 格式依据

1. 论文格式按以下优先级确定：
- 用户在指令中明确提出的格式要求；
- 用户提供的格式模板、投稿要求、课程要求或评分标准；
- 目标期刊、学校、课程或会议正式发布的格式要求；
- 用户指定的参考论文或样稿；
- 中文学术论文通用格式：GB/T 7713.2—2022《学术论文编写规则》
2. 不同依据发生冲突时，执行优先级较高的要求；高优先级依据未规定的内容，可以用低优先级依据补充，但不得与其冲突。
3. 用户仅指定目标期刊、学校、课程或会议时，应查找其正式要求；无法确认时应明确说明，不得凭经验或参考论文推断。
4. 学术论文在没有用户、模板、学校、期刊或会议格式依据时，以 GB/T 7713.2—2022《学术论文编写规则》及本指南规定为兜底；仅普通课程论文且课程未提供格式要求时，未明确的 Word 排版项目可参照 [`writing-taxonomy.md`](writing-taxonomy.md) 中“## 一般Word排版格式要求”。
5. 交付时应说明最终采用了哪些格式依据，以及发生冲突时如何取舍。

#### 目标格式读取

1. 必须完整读取用户提供的投稿须知、评分要求、DOCX模板、PDF样稿和参考论文的内容、结构和完整的排版格式，不得只提取其中的文字内容。

2. 应识别并记录以下要求：篇幅、文件类型、必要组成部分及排列顺序、标题层级、字体字号、段落和行距、页边距、分栏、编号体系、页眉页脚、页码、摘要和关键词、作者及机构信息、基金和作者简介、匿名审稿、脚注和尾注、引文和参考文献、图表和公式、附录及文件命名。

3. 用户指定参考论文时，只学习其稳定的结构和版式特征，不得复制其研究内容、表达或数据。

4. 正式编辑前应先形成格式检查清单，再将要求应用到全文。不得只修改正文的字体字号，就声称已经完成目标格式适配。

#### Word格式编辑

1. 使用Word原生标题样式建立标题层级；需要目录时，使用标题样式生成并更新原生目录，不得手工输入目录或页码。

2. 使用统一的段落样式控制字体、字号、行距、缩进、段前段后和分页，不得依靠连续空格、空行或手工换行调整版面。

3. 图、表和公式应连续编号，在正文中有对应引用；图题、表题、单位、来源和注释应完整，并使用题注或交叉引用功能保持编号一致。

4. 脚注和尾注必须使用Word原生脚注或尾注功能，不得手工输入上标编号或在正文、页尾模拟注释。除用户或目标规范另有要求外，注释使用阿拉伯数字连续编号。编辑完成后应检查编号顺序、正文标记与注释内容的对应关系，以及增删内容后编号是否自动更新。

5. 排版完成后必须渲染并逐页检查，重点核验目录和页码、标题分页、孤行孤句、图表跨页、公式截断、图文遮挡、脚注位置、参考文献悬挂缩进及页面大面积空白。

#### 篇幅长度
1. 论文篇幅依次以用户明确要求、用户提供的模板或评分标准、目标期刊或会议正式要求为准。  
2. 没有明确篇幅要求时，应根据论文类型、研究问题和材料量确定合理篇幅。完整论文不得写成简要提纲或内容摘要，各必要部分应有充分、实质性的论述。
3. **一般参考**：未提供任何篇幅要求且需要生成完整论文时，可参考以下范围：
   - 期刊研究论文：中文一般6000—12000字，英文一般5000—8000词；
   - 会议论文：优先按照会议模板规定的页数执行；确无要求时，根据长论文、短论文或摘要等类型确定，不统一设置字数；
   - 课程论文：中文一般3000—5000字，英文一般1500—3000词。
4. **内容质量优先**：篇幅应与研究问题、材料数量和论证需要相匹配。材料不足时不得通过重复表述、空泛背景或编造内容凑足字数；内容需要充分展开时，也不得为了机械控制篇幅而删除必要的方法、证据和分析。

### （五）明确禁止

1. **禁止编造研究事实**：不得虚构或补写实验、调查、访谈、样本、数据、分析过程和研究结果。

2. **禁止编造或误用文献**：不得生成不存在的作者、题名、期刊、年份、页码、DOI和链接；不得只根据题名、摘要或二手转述概括原文关键结论。

3. **禁止越界修改**：用户仅要求排版时，不得擅自重写内容；用户要求内容修改时，不得改变研究事实和原始结果以增强论文完整性或创新性。

4. **禁止交付未完成模板**：用户要求完整论文时，完整论文中不得保留“请补充参考文献”“请填写基金项目”、XXX、虚构示例文献等模板提示或者只留下参考文献占位而不是真实搜索参考文献并填入的内容。能够通过用户材料或可靠来源完成的内容应直接完成；确实缺少作者身份、基金编号等无法推断的信息时，不得编造，应明确标记缺失项并在交付说明中告知用户，不得声称文档已经完全定稿。


### （六）交付检查
交付前先核验本指南及目标规范规定的样式要求，再按 [`writing-taxonomy.md`](writing-taxonomy.md) 中“## 交付前回读与校验”完成通用检查。


## 二、任务模式

根据用户提供材料的完成程度和核心任务选择主要模式：

| 用户提供的内容与需求 | 主要模式 |
| --- | --- |
| 只有论文题目，需要从头完成论文 | 命题成文 |
| 已有大纲或部分正文，需要补充扩展 | 大纲扩写 |
| 已有实验、调查、数据、文献、图片或图表等研究材料，需要整合成文 | 材料成文 |
| 已有完整或基本完整的论文，需要修改、润色或排版 | 成稿整理 |

任务模式可能交叉，应根据用户的核心目标确定主要模式，并同时执行其他相关模式的适用要求。无论采用哪种模式，均须遵守本指南的材料真实性、证据边界和格式优先级等共同原则。


### （一）命题成文：只有题目，主要依靠搜索真实外部资料
* **核心目标与节奏**：根据用户给出的论文题目，明确研究对象、范围和核心问题，检索并核实必要资料，形成结构完整、论证连贯的论文。

* **内容逻辑思路**：先判断适合写作文献综述、理论分析、案例研究还是实证论文，再围绕研究问题组织论点、证据和结构。不得仅根据题目套用固定提纲或堆砌通用内容。

* **资料处理要求**：论文中的事实、观点和引文应来自可核实的真实来源。需要引用文献时，必须检索权威学术网站，并且在引用文献后按照格式要求进行标注引用。

* **格式要求**：按照本指南的格式优先级确定排版依据；没有明确要求时，采用中文学术论文通用格式。

### （二）大纲扩写：已有大纲或部分正文，需要补充为完整论文

* **核心目标与节奏**：在保留用户既定主题、结构和写作方向的基础上，补充缺失内容和必要衔接，将大纲或部分正文扩展为结构完整、论证连贯的论文。大纲只是写作框架，不是最终交付内容。用户要求完整论文时，应对全部章节进行实质性扩写和统一改写，形成结构完整、论证充分、语言正式且可以直接交付的论文，不得只在原有内容后补充少量文字。

* **内容逻辑思路**：先检查论文应有部分和各章节的论证任务，再将大纲中的标题、编号、要点、短句和提示语转化为相互衔接的正式论文内容。各部分应包含必要的观点、证据、分析和过渡，不得保留未经展开的提纲式表达；编号或分点仅在符合论文结构和内容逻辑时保留。不得机械填充篇幅，也不得擅自改变用户确定的研究方向。

* **资料处理要求**：大纲只用于确定结构和写作方向，不能作为研究事实或证据。新增的事实、观点和引文必须来自用户材料或可核实的真实来源；不得编造用户未提供的实验数据等信息；不得将计划开不展的研究或预期结果写成已经完成的研究。

* **交付要求**：应完成目标格式要求的全部必要部分，并统一检查内容完整性、章节衔接、论证深度、引文、图表和格式。不得交付只完成局部扩写、仍呈现明显大纲形态或需要用户继续补写整合的文稿。

* **格式要求**：按照本指南的格式优先级确定排版依据；没有明确要求时，采用中文学术论文通用格式。

### （三）材料成文：用户已有研究材料，需要整合成论文

* **核心目标与节奏**：将用户提供的实验、调查、数据、文献、图片、图表、大纲及其他研究材料整合为围绕明确研究问题展开的完整论文。先完整读取和核实材料，再组织论证、形成结论并完成格式交付。

* **内容逻辑思路**：先判断现有材料能够回答什么问题，再建立核心论点并安排各部分的论证任务。文字、数据、图片和图表应共同服务于研究问题，不得按照附件类型或提供顺序分别堆砌。

* **资料处理要求**：
- 写作前对材料进行完整盘点，识别已经完成的研究过程、已有结果、待补信息和外部文献需求。重要数据、结论和引文应能够追溯到具体材料；无法核实的信息不得进入定稿。
- **充分利用用户提供的实验数据和图片**：在用户提供素材中有符合论文规范可以直接用户论文中呈现时，应从附件中直接提取并使用原始图片文件，不得通过截图、复制粘贴、OCR重建或重新绘制代替原图。插入论文时只允许保持宽高比例缩放，不得裁剪、压缩、重采样、转换格式或调整颜色、清晰度和图中内容。交付前应提取成稿中的嵌入图片，与附件原图进行文件哈希或像素级比对，并渲染检查，确认图片内容没有发生变化。

* **格式要求**：优先读取目标期刊、课程、学校或会议的正式规范，并在内容框架确定后按照相应格式完成Word文档。没有明确目标格式时，采用本指南的中文学术论文通用兜底格式。

### （四）成稿整理：已有完整或基本完整的论文，需要修改和排版

* **核心目标与节奏**：在不改变研究事实和证据边界的基础上，使已有论文符合用户指定的内容、语言和格式要求。先识别论文现状与目标规范之间的差异，再完成必要修改和Word排版，最后逐项检查。

* **内容逻辑思路**：用户只要求排版时，仅处理格式，不主动重构论文。

* **资料处理要求**：以用户原稿为唯一的研究事实基础。需要补充文献、背景或规范性表达时，明确区分新增内容与原稿内容。

* **格式要求**：完整提取目标要求或参考论文的格式特征，建立检查清单后应用到全文。排版完成后更新目录、题注、交叉引用和页码，并通过逐页渲染确认实际呈现效果。
