# 管理报告

**路由条件**：运营 / 财务 / 董事会汇报（季度年度汇报、预算评审、投资决议、并购提案）；业务经营回顾（零售 / 制造 / 消费 / 供应链的品类 / 区域 / 渠道对比与走势）；互联网 / 科技 / 增长月报（漏斗、留存、A/B 实验、MRR / ARR / Churn、迭代进展）；人力 / 行政 / 政务汇报（组织盘点、绩效回顾、行政后勤、政务专项工作总结）。

**对标参考**：麦肯锡、BCG、贝恩的高管汇报模板；德勤、普华永道、安永的审计与运营诊断报告；高盛、摩根士丹利的董事会与投行提案；伯克希尔·哈撒韦、亚马逊等公司的年度股东信；以及一流企业内部使用的经营分析、季度回顾与月度经营例会材料。

## 全局叙事原则

- **翻标题就能读懂业绩**：每一页的标题都要陈述一个状态或结论——写「Q3 毛利率降 3.2 pct，主因原料涨价」，不写「业务绩效报告」这种板块标签。管理者只翻各页标题也应能读懂本期表现、原因、诉求。
- **封面定调，第二页给全貌**：封面承担气质与调性，做到高端大气、贴合品牌——大留白 + 品牌主色 + logo + 报告标题 + 期次 / 汇报人 / 日期，不塞业绩数据。真正的全貌放在第二页——用数字、图表与极细线段的组合做一张"仪表盘式总览"，让管理者翻到第二页就能看清本期表现、缺口和状态，用户的指令优先于这个组合。
- **数字不夸大也不裁剪**：用户给的数字和事实原样呈现；素材里的基准值必须与结果一并展示；素材里没有的东西不得替用户臆造；灵活用数字、图表、表格呈现关键信息。
- **措辞专业、贴合身份**：不用外行话，也不上放之四海皆准的空泛套话（"赋能""抓手""打法""闭环""协同联动""多措并举"这一类一律回避）。
- **关系图形化**：进展、数据、职责、风险与依赖是管理报告的核心关系——从内容里提炼关系并用结构图 / 框架表达，而非文字堆砌。

## 全局视觉纪律

顶级质感不是靠装饰堆出来的，是靠一套贯穿始终的纪律。

- **信息定位固定**：结论 / 标题在固定的标题位；证据（图表、编号卡、照片）落在右栏或下半部固定区域；度量口径、来源、脚注放固定角落的小号文字。全篇位置不动，翻页不跳动。
- **字体分家族**：展示字体与正文字体分工明确（同一无衬线家族的不同字重，或无衬线体标题 + 另一家族的正文）；层级靠字号与字重的比例建立；编号、标签、脚注这类功能性文字统一用小号大写字母加大字间距；字号随内容体量伸缩，但层级比例不变。字体与配色互相参照，一并设计。
- **圆角与质感统一**：全篇所有矩形组件（卡片、面板、照片、柱形顶部）共用同一套圆角规格，不得混用；保持扁平，无投影、无 3D、无渐变文字；颗粒感 / 光晕等氛围图层若使用，须低强度、位置固定，且置于内容之下。
- **视觉母题贯穿**：确立 1–2 个视觉母题（编号徽章、连接虚线、装饰形状等），在各类页面上复用它们的变体；某一页缺视觉锚点时，优先复用已有母题，不引入新元素。
- **目录决定观感**：目录页不能小字堆叠。参考样式：主题色编号 + 章节标题 22pt + 一行 12pt 浅灰说明，三者左对齐；章节间加 0.5pt 浅灰细横线；超过五章时用左右对称布局并合理缩小字号。
- **区域填满**：任何内容必须填满其规划区域——不是"文本框填满"，而是"从截图上看到的实际文字撑满区域"。留白不足是最严重的粗糙。

## 用户附件模板参考

**用户给的 pptx 是最高优先级视觉指导**。用户要求"参考"其风格或用它作模板时，不是逐页复用，先按以下步骤处理再套用本文件的设计原则：

1. **先看渲染效果，别止步于抠文字**：打开样本截图看真实视觉；只跑 xml 提出一堆文字不算看懂模板。
2. **提炼一份精简的参考要点，不逐页照搬**，分三类记录可迁移的部分：
  - **版式手法**：网格骨架、配色规则、步骤式导航、证据分区等结构性设计。
  - **风格基调**：克制、亲和、严谨，或活动现场感、公务通传感。
  - **图形语法**：并列模块、时间轴路径、嵌套层级、取景框等表达手法。
3. **不能改的东西**：主要字体、背景图（尺寸与 ppt 一致的视为背景）、模板自带品牌标识、真实人物 / 照片、原始文案、专属色值、装饰纹样——这些要保留，但可以在其基础上灵活设计。
4. **判断内容属于模板中的哪一类页面再用**，不把局部经验放大成整套通用规则。
5. 没有能直接复用的页面时，回落到下面的设计系统自行搭建。

## 配色总原则

**第一原则——品牌主色优先**：用户提到公司 / 机构 / 组织名称，或提供了 logo 时，**必须先搜索确认其品牌主色**，把主色定为全篇主题色，围绕它构建整套配色；封面建议直接放品牌 logo 呼应。用户明确给出 VI 色值时直接用。**这条优先级高于下面各分场景的参考色板**——只要能确认到品牌色，就不再挑色板。

**气质要求**：拒绝套路化配色（Office 默认蓝、科技蓝紫渐变、大促季红金配、灰蓝模板色等）。背景色向稳重克制方向靠拢（暖白 #F7F3E8、浅石灰 #ECEAE4、雾灰 #E9E7E2）；章节页与强调页可用深墨蓝 #16283C 或墨黑 #1A1A2E。强调色仅用于关键指标、达成状态、章节色带，正文页面积 3%–8%，绝不用于装饰。

**图表色系**：同一份材料所有图表用同一色系的深浅，不引入第二色族；饼图等多类别图表在同色系内保证图例明显可辨；数据标签只保留关键点或移至文字栏；关键指标用大数字直接标注；图表区与解读文字严格分区，不叠印、不交错。

## 分场景参考

### 运营 / 财务 / 董事会汇报

**气质**：机构级正式感——克制、精确、去装饰化；配色深沉稳重，正文密度适中，章节页与结论页大面积深色以体现权重。

**决策焦点**：达成率、缺口归因、资金与资源诉求；数字与结论必须一眼看到。

**参考配色**（无品牌色时二选一）：

- 主题色深蓝 #0D1B2A + 辅助蓝灰 #64748B / 琥珀金 #C9A66B + 背景雾白 #F7F7F8 + 标题深蓝 #0D1B2A + 正文蓝灰 #465667
- 主题色珊瑚红 #C24C57 + 辅助炭黑 #333333 / 银灰 #9B9B9B + 背景纯白 #FFFFFF + 标题墨黑 #1A1A1A + 正文板岩灰 #5C5C5C
- 主题色钴蓝 #2F54EB + 辅助雾蓝 #ADC6FF / 银灰 #D9D9D9 + 背景雪白 #F8F9FA + 标题墨黑 #141414 + 正文板岩灰 #595959

**字体**：中文黑体家族；数字与英文可搭配等宽或半衬线数字字体以突出精度。封面标题 56–72pt，页面标题 32–40pt，正文 16–19pt，脚注 9–11pt。

**布局**：十二列网格；固定标题基线与右下角来源位；封面与章节页允许非对称大色块。

**图表与表格**：

- KPI 大数字优先：达成率、缺口值以 60–96pt 呈现，附极简小标签与同比。
- 柱形 / 线形图去坐标轴与网格，只保留关键数据点标签。
- 表格用三线表；异常行用极窄色带或色点标记，禁止整行高饱和填色。

**页面语法**：封面（品牌调性优先——大留白 + 品牌主色 + logo + 报告标题 + 期次 / 汇报人 / 日期，不塞业绩数据）→ 总览页（第二页给全貌，用大数字 KPI + 迷你趋势图 + 极细线段组合的仪表盘式布局，一眼看清达成率、缺口、状态）→ 摘要页（3–5 条陈述式结论，每条附指标与缺口）→ 指标页（一个巨大数字 + 同比环比 + 一句归因，下方留一条细分图）→ 归因页（瀑布图或贡献分解 + 结论文字紧贴图右侧）→ 诉求页（所提资源 / 预算 / 决议明列，附影响预测与替代方案）。

**视觉母题**：金属色细线 · 章节编号徽章 · 固定页码 · 三线表 · 极简 KPI 大数字。

**场景禁止**：蓝白商务风与 Office 默认配色；圆角信息卡片堆叠；3D 柱形 / 渐变柱 / 投影；巨型公司徽标水印；「工作汇报」「总结展望」这类空洞板块标题。

### 业务经营回顾（零售 / 制造 / 消费 / 供应链）

**气质**：产业感与务实感——暖色调打底，密集的表格与柱线组合，异常项一眼可辨；不追求艺术化装饰，追求信息密度与决策效率。

**决策焦点**：品类 / 区域 / 渠道的对比与走势；表格与柱线组合，突出异常项。

**参考配色**（无品牌色时二选一）：

- 主题色焦糖棕 #A05A2C + 辅助琥珀 #C9986A / 沙驼 #E2CDB8 + 背景象牙白 #F6F1EC + 标题深栗 #2A1F14
- 主题色朱砂橙 #E24C3D + 辅助深墨绿 #0F2A23 / 沙棕 #CBAA8D + 背景米白 #F5EDE1 + 标题深墨绿 #0F2A23 + 正文炭灰 #333333
- 主题色深蓝灰 #1F3240 + 辅助浅钢灰 #C3CCD4 / 琥珀黄 #FCAD0C + 背景浅钢灰 #C3CCD4 + 标题正文深墨蓝灰 #1F3240

强调色只用于标记异常项、超标项、需重点关注项，不做装饰。

**字体**：中文思源宋体；数字与表格使用等宽数字（Tabular Figures）保证纵向对齐。封面标题 48–64pt，页面标题 28–36pt，正文 15–18pt，表格 12–14pt，脚注 9–11pt。

**布局**：以表格与图表混排为主的密集网格；顶部固定导航（品类 / 区域 / 渠道切换）；底部固定指标口径说明。

**图表与表格**：

- 多维度对比优先用横向条形图与折线图；柱形图仅用于时间序列。
- 表格必须有明确表头分组、水平分隔线、异常行标记；负数用括号或专用色，不用负号加红字。

**页面语法**：封面（品牌调性优先——大留白 + 品牌主色 + logo + 报告标题 + 期次 / 汇报单位，不塞业绩数字）→ 总览页（第二页给全貌，核心业绩数字 + 迷你趋势图 + 极细线段组合的仪表盘）→ 全景页（多维度矩阵表：品类×区域 或 渠道×品类，异常单元格高亮）→ 单维度分析页（一张主图 + 3–5 条结论，结论紧贴图右侧或下方）→ 归因页（瀑布图或贡献分解 + 分因子说明）→ 动作页（本期已完成 / 下期承诺 / 需要支持三分区，各带责任人与时点）。

**视觉母题**：三线表 · 异常色点 · 等宽数字对齐 · 期次徽章 · 品类色系。

**场景禁止**：彩虹柱形图、多色饼图；整行高饱和背景色标状态；3D 柱形 / 圆柱 / 锥形图；灰蓝模板色与 Office 默认蓝；装饰性图标堆叠在数据周围；表格不对齐、数字未使用等宽字体。

### 互联网 / 科技 / 增长月报

**气质**：现代、克制、数据驱动——冷色打底或深色打底，指标以大数字与迷你图组合呈现，节奏感强；不用互联网大厂惯用的彩色卡片墙。

**决策焦点**：漏斗、留存、迭代节奏；漏斗图、趋势线与关键事件时间轴构成骨架。

**参考配色**（无品牌色时三选一）：

- 主题色荧光黄绿 #D4E92C + 辅助橄榄绿 #7A8B2C / 烟灰 #6B7280 + 背景墨黑 #1A1A1E + 标题雪白 #FFFFFF + 正文银灰 #B8BCC2
- 主题色铁锈橙 #C24E2A + 辅助钢灰 #7D8085 / 浅钢灰 #C9CBCE + 背景冷白 #F2F2F0 + 标题炭黑 #17191C + 正文铁灰 #555A60
- 主题色青瓷绿 #3FA68C + 背景墨黑 #101418 + 标题正文冷白 #F4F7F6

用深色主题色时正文用冷白 / 浅灰，禁止小字号置于高饱和色上。

**字体**：中文黑体 + 英文 / 数字用几何无衬线体（Inter、IBM Plex Sans）。封面标题 48–64pt，页面标题 28–36pt，正文 15–18pt，指标大数字 60–96pt，脚注 9–11pt。

**布局**：允许密度较高的仪表盘式布局，但仍以固定网格切分；顶部固定期次与指标口径，右侧固定筛选 / 维度说明。

**图表与图形**：

- 迷你图（Sparkline）跟在指标数字旁展示趋势。
- 漏斗图、留存曲线、队列（Cohort）表是常见主图；每张主图只回答一个业务问题。
- A/B 实验结果必须标注样本量、置信区间、显著性，不得只报相对提升百分比。

**页面语法**：封面（品牌调性优先——大留白 + 品牌主色 + logo + 报告标题 + 期次 / 团队 / 日期，不塞指标数字）→ 指标总览页（第二页给全貌，4–8 个 KPI 大数字 + 对应迷你图 + 极细线段分隔，不用圆角卡片）→ 漏斗 / 留存页（一张主图 + 关键节点数字标注 + 结论文字）→ 实验汇报页（实验假设 + 变体对照 + 结果表 + 结论与后续动作）→ 迭代进展页（时间轴 + 已上线 / 进行中 / 待启动分层展示）。

**视觉母题**：迷你图 · 指标数字 + 同比标签组合 · 时间轴刻度 · 显著性星标 · 期次标签。

**场景禁止**：蓝紫渐变、青紫霓虹、彩虹光晕；玻璃拟态卡片、发光边框、荧光色描边；3D 数据可视化、球体图、雷达图（除非确有语义需要）；只报相对提升不报绝对值与样本量；大厂惯用的多色圆角卡片墙。

### 人力 / 行政 / 政务汇报

**气质**：庄重、条理分明、有仪式感——暖色或纸调打底，衬线体，表格与流程图承担主要信息量；不追求视觉冲击，追求条目清晰、责任到人、时点明确。

**决策焦点**：合规性、覆盖率、时序节点；表格、地图与流程图承担主要信息。

**参考配色**（品牌主色优先；无品牌色时三选一）：

- 主题色翡翠绿 #2E8B47 + 辅助松柏绿 #143D30 / 青柠绿 #7CB342 + 背景云灰白 #F2F3F5 + 标题墨绿 #1A2E23 + 正文板岩灰 #4A5568
- 背景纸白 #F7F3E8 + 主题与正文松绿 #284F2C + 强调杏黄 #E8B54A
- 党政汇报：主题色勃艮第红 + 米白 + 炭黑

强调色用于标记完成状态、逾期项、重点事项；禁止整段红色警告字。

**字体**：中文标题可用现代宋体；编号与档案参考号用等宽字体。封面标题 48–64pt，页面标题 30–38pt，正文 16–19pt，表格 13–15pt，脚注 9–11pt。

**布局**：稳重的对称或近对称布局；顶部固定机构标识（如有）与页眉；底部固定页码与文件编号；章节页可整页强调色。

**图表与表格**：

- 优先使用清晰的表格与流程图；柱形与饼图仅在必要时使用。
- 组织结构、流程节点、责任分工用结构图呈现，每条连接线都要有方向与含义。
- 覆盖率、达标率等百分比指标用条形进度图或环形图，不用 3D 饼。

**页面语法**：封面（庄重仪式感优先——报告标题 + 期次 + 汇报单位 / 汇报人 + 机构标识，不塞结论）→ 总览页（第二页给全貌，关键指标表 + 覆盖率 / 达标率进度条 + 极细线段组合，一眼看清整体推进情况）→ 总体情况页（3–5 条陈述式结论 + 关键指标表）→ 分项工作页（每项工作单独一页，含目标、进展、责任人、时点、下一步）→ 数据分析页（主表 + 主图 + 简短解读，数据口径与来源固定在页脚）→ 下一步页（按优先级或时点排列的行动清单，每条附责任人与完成时限）。

**视觉母题**：机构色细线 · 章节编号 · 责任人标签 · 时点节点 · 三线表 · 完成状态图标。

**场景禁止**：大红大绿大金的节庆感配色；卡通图标、装饰花边、剪贴画；3D 饼图、爆炸饼图、彩虹柱；空泛套话（"赋能""抓手""打法""闭环""协同联动""多措并举"）；章节页用巨型徽标水印代替内容；表格边框粗黑、行高不一致、数字未对齐。
