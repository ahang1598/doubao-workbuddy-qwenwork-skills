# 教育与培训

**路由条件**：课件、职业技能培训、操作指南、教师素材、学习手册、公共教育、入职培训、能力建设与知识普及。

**核心立场**：教育课件的骨骼是「**问题 → 思考 → 判断 → 小结**」。学习者是被问题拉着走的，不是被信息推着走的。每一页必须能回答"这页在教哪一次思考"——写不出来的页面判为内容空洞，必须补内容或删页。页面形态是弹性工具，视觉服从教学。

---

## A. 硬性禁令（贯穿全篇）

- 严禁卡片构建层级——改用线段、留白、字号/字重差异
- 严禁均分构图：三等分、四等分、2×2矩阵、「标题+三并列块+结论」套路
- 严禁平庸配色：蓝白搭配、蓝紫渐变、青紫霓虹、彩虹光晕、玻璃拟态、发光边框
- 严禁风格冲突：锐利风中混用圆角；简约系统中混用拟物纹理
- 严禁SmartArt原始样式、彩虹配色、粗黑表格边框——必须重做
- 严禁用装饰填补内容不足：缺定义补定义，缺示例补示例，不得用图形、留白掩盖空洞
- 严禁图形连线穿越文字
- **正文字号不低于 15px**，保障投影展示
- 课件内带文字图片禁止截图处理，排版适应图片比例即可
- 页面不能信息过载，学习者一眼看到核心对象和核心问题，如果本页提出了问题最好不要在同页给出答案

## B. 执行流水线（严格按序）

### 1. 明确学习任务 + 搭建问题树

在动手前，先在脑子里想清楚：**学习者是谁、现在不会什么、学完能做什么、会在哪个真实场景用到**。不需要写成清单，但这四件事必须都想到。

然后搭建问题树（这是骨架，缺此步不得往下）：

- **课件级驱动问题**：全篇回答的一个大问题（写成完整问句）
- **章级子问题**：3–7个，每个对应一章
- **页级问题**：每章再拆2–5个，一个对应一页正文；每页都要想清楚"学习者在这里会卡在哪里"

> **警示**：如果问题树写出来的"问题"其实是"XX背景""XX概览""XX介绍"，说明还没搞清楚要教什么——回头重想，不要硬闯下一步。



### 2. 逐页大纲

每页必须写出：**章节 / 页型 / 本页问题或本页判断 / 标题 / 主展示物 / 解释或任务 / 来源**

关键字段说明：

- **本页问题**：完整问句，直接对应问题树中的页级问题；不得用板块名冒充
- **本页判断**：看完这页学习者能复述的一句话；不得用"了解XX""掌握XX"等不可观察动词，如果在上一页提出问题结论可以放在下一页，不要直接给出答案
- **标题**：先想清楚问题和判断，再起标题。"背景""概述""相关内容"视为内容匮乏，必须重写
- **来源**：外部事实、数据必须标注来源；示意数据须标注「示意素材」

写不出「本页问题」或「本页判断」的页面直接判为内容空洞——**要么补内容，要么删页或并入邻页**。

### 3. 提取参考样例（如有）

从参考样例中只提取：可借用的功能性布局（网格/色彩编码/步骤导航）、气质（克制/亲和/严谨）、图形语法。**不可继承**：品牌标识、照片、人物、具体文案、专有色值。每份素材最多提取2–3个彼此兼容的特征。

### 4. 视觉简报

必须覆盖：受众与使用环境 / 主网格+5–6种页型 / 字体层级 / 颜色语义分工与对比度 / 图形语法 / 固定坐标（页眉、页脚、页码、来源）

### 5. 逐页生成 + 生成前校验

**生成每页**：写收获标题 → 确定唯一主展示物 → 补全定义/边界/标签/任务/来源 → 应用网格和层级 → 删去不承担教学功能的装饰 → 先查内容完整性，再做视觉微调。

**生成前校验**：参照主SKILL执行飞书Slides XML产物校验。

## C. 规则库



### 教学闭环

完整学习弧线：**建立动机 → 构建认知 → 观察过程 → 主动尝试 → 获得反馈 → 迁移应用**。短素材不必每环节单独设页，但凡缺失必须说明是主动决策，而非放不下。


| 环节   | 页面上必须出现的内容                          |
| ---- | ----------------------------------- |
| 建立动机 | 学这个带来什么能力、不学错过什么；用真实处境而非口号          |
| 构建认知 | 先给可复述定义，再补边界/构成/反例；新术语不得仅出现在图注里     |
| 观察过程 | 呈现判断推进过程而非仅结论；关键岔路、取舍理由、高频误区在同一阅读路径 |
| 主动尝试 | 写明输入/操作/完成标准；虚构场景标注「练习场景」           |
| 获得反馈 | 答案为何对、错在哪里、下次如何自查；答案页与题目页视觉上一眼可分    |
| 迁移应用 | 用清单/模板/行动卡连接真实场景；不以口号代替可操作行动        |




### 页型目录

每页最小完整单元：标题 + 主展示物 + 支撑层 + 行动/检查 + 来源。单页只承担一种主要学习行动。


| 页型        | 学习行动            | 骨架内容                                   |
| --------- | --------------- | -------------------------------------- |
| 学习目录     | 知道从哪来、要去哪       | 学习问题 + 章节顺序                            |
| **章节引题页** | 产生一个具体的、卡住自己的问题 | 驱动问题（第一视觉落点）+ 困惑锚点                     |
| 概念页       | 说出「它是什么、边界在哪里」  | 一个定义 + 边界/构成 + 直觉示例或结构图                |
| 方法地图页     | 知道当前位置与后续预告     | 整体框架 + 当前位置标记 + 后续预告                   |
| 方法页       | 知道何时选用、如何决策     | 判断标准 + 适用条件 + 决策路径                     |
| 流程页       | 知道先做什么再做什么、怎么验收 | 步骤顺序 + 每步动作 + 验收标准                     |
| 演示页       | 看到判断如何推进        | 输入素材 + 中间判断 + 取舍依据 + 结论；易错岔路同路径        |
| 案例—证据页    | 学到可迁移判断         | 角色标签 + 事实素材 + 解读 + 可迁移判断 + 来源          |
| 对比/易错页    | 区分两种做法或状态       | 同骨架并排两种做法 + 判断标准 + 高频错误                |
| 练习页       | 动手操作或做出选择       | 任务说明 + 输入/场景 + 作答区 + 完成标准；答案不得同页       |
| 反馈页       | 纠正错误并提炼原理       | 参考做法 + 原因 + 错误所在 + 下次如何自查              |
| **章节小结页** | 收束本章判断、回答驱动问题   | 一字不差回到引题、本章判断一句话、2–4条支柱判断、迁移边界；不复述所有标题 |
| 迁移页       | 离开课件后知道怎么用      | 清单/模板/参考卡/资源链接与下一步                     |


**章节引题页/小结页开合判据**


| 出现条件            | 引题页                        | 小结页                                  |
| --------------- | -------------------------- | ------------------------------------ |
| **开的条件（满足任一）**  | 本章≥4页；或需要卡住的驱动问题；或引入≥3个新概念 | 已开引题页（必须闭合）；或跨≥3页的复杂判断需收拢；或结论被后续反复引用 |
| **不开的条件（满足任一）** | 全课件≤6页；或本章仅1–2页；或纯迁移/清单型章节 | 结论已在最后一页标题里说清楚；或本章仅过渡性铺垫             |


**强制一致性**：引题页与小结页要么成对出现，要么都不出现。

### 密度规则

密度设定为「适满」——学习者一眼看到核心对象，同一页也能找到理解所需支撑。

- 正文页三层：学习问题/结论标题 → 主展示物 → 解释/任务/检查/来源
- 主内容区至少60%面积由有效学习内容填满；留白是引导视线的工具，不是产品
- 除封面/章节页/结尾页外，不得连续出现「一行文字+大片空白」
- 密度越高越要强化分组标签；密度越低越要补定义/示例/检查题，而非添加图形

**图形语法**：顺序用流程，层级用树形/嵌套，对比用并列区域，因果用单向链，有循环才用环形。每张结构图只表达一种主要关系；删去装饰性箭头和无意义节点。

### 视觉底线

**网格与层级**：先锁定主内容区/标题锚点/内容对齐轴/页码来源位置，再决定页面变体。每页只有一个第一视觉落点。标题/正文/图注/来源使用清晰双字族（文科：思源宋体+楷体；理科：思源宋体+黑体）。**正文字号 13-15 px**，与背景对比度不低于4.5:1，不以阴影描边打补丁。

**色彩**：有品牌/学校信息时使用logo主色。无品牌规范时根据主题/受众自行调整——深色底用高对比度浅色正文，浅色底用近黑色正文，小字号绝不置于高饱和色之上。

**组件**：圆角/直角/描边/阴影/胶囊选定后全篇一致。阴影/纹理/渐变/装饰图标仅在服务层级或情境时出现，删去后不影响理解的一律删去。

**图片与图表**：每张图片说明「看什么、为什么在这里」。图表呈现关系，旁注解释如何读取与下一步行动。保留必要单位/时间范围/图例/来源，删去非必要网格线和装饰。无可靠数据时使用示意性结构——**不得生成外观可信的精确数值**。

### 用户附件内有要求参考的ppt模板

**用户要求"参考"其风格或者用这个模板做ppt时并不是把它当整套模板逐页复用，一旦附件内有pptx并且用户意图是用这个pptx作为模板做ppt时先按以下方法处理后再路由对应的style参考设计原则**：

1. **先看渲染效果，别止步于抠文字**：实际打开样本，截图看清页面真实呈现的视觉效果；只跑xml提取拿到一堆文字不算看懂模板。
2. **提炼一份精简的参考要点，不逐页照搬**，按三类记录可迁移的东西：
  - **可迁移的版式手法**：如模板的网格骨架、配色规则、步骤式导航、证据分区等结构性设计。
  - **可迁移的风格**：如克制、亲和、严谨，或活动现场感、公务通传感等基调倾向。
  - **可迁移的图形语法**：如并列模块、时间轴路径、嵌套层级、取景框等表达手法。
3. **不能修改的东西**：主要字体、背景图片（尺寸跟ppt一样大的视为背景）、模板自带的品牌标识、真实人物/照片、原始文案、专属色值、装饰纹样——这些必须在新设计内保留，但是可以灵活的进行设计。
4. **设计时对应页面类型**：判断内容表达更适配里的哪一类，不要把这点局部经验放大成整套页面的通用规则。
5. 没有合适的可以直接使用的页面时按照当前设计系统的指导搭建。

## D. 参考方向

以下是快速定位设计选择的方向，不是固定配色表或页面模板。主题不符合任一方向时，建立新方向，先写清楚「它帮助学习者完成什么」。



- **A. 课堂教学**——根据学段路由到对应两种子风格：



#### A-1.1 小学及以下——MBE 风

**核心气质**：亲切、有趣、低认知负担，要配图片，对于可抠图呈现的卡通元素，优先生图，不优先使用 shape 构造实体；对于人物、物品、设备、场景等具体实体，优先使用真实图片或真实感图片，不用抽象 shape 代替，以保证视觉质量和信息传达效率。

**字体使用**：使用圆体字体，例如寒蝉团圆体 圆体、霞鹜 975 圆体

**MBE 风格规则**：

- **粗描边**：所有图形/插画使用 3–5px 统一黑色描边，端点为圆头
- **圆角全开**：矩形、标签、按钮、容器一律使用圆角（半径 ≥ 12px）；全篇圆角风格，不混用任何直角
- **图标/插图**：使用 MBE 风格插画（描边+填色+阴影偏移色块）；人物/动物/物件都可使用，保持同一描边粗细和调色盘
- **抠图使用规则**：白底照片/图片可以抠图去背景
- **文字**：圆体或幼圆字族；字号偏大（正文 16px+）；重点词用色块衬底或加描边标签突出
- **布局**：中轴对称或左图右文；图形占比 40%–60%；每页信息点不超过 3 个；留白充裕
- **禁止**：尖锐直角、深色底、高密度文字、任何"成人课件"的克制风格混入
- **用户要求配色优先，以下为参考**
- #E2883E 橘黄 + #3D547A 深蓝 + #6BBFEA 浅蓝 + #F7D752 亮黄  -- #DC6872 玫粉+ #FAE47A 奶油黄 + #7D7AB7 薰衣草紫 + #EBA59A 浅粉
- #62B4A5 薄荷绿 | #C6A163 浅棕 | #FAE452 柠檬黄 | #A2D2D2 浅青 |
- #4583BD 正蓝 | #C2AE9F 灰棕 | #D77653 橘红 | #B7D6E9 浅蓝 
- #60AB70 草绿 | #F8E653 蛋黄色 | #EA9B46 橘橙 | #AECC73 浅绿
- #DB714F 珊瑚红 | #6DBA9C 薄荷绿 | #FCF08F 奶油黄 | #EBA17E 浅橘 |
- 底色建议 #FFFDF5（暖白）或 #FFFFFF。每组中深色（色1/色2）用于描边和标题，浅色（色3/色4）用于色块填充和背景分区。



#### A-1.2 小学及以下——手绘涂鸦风

- 画风：简笔手绘涂鸦、粗黑线轮廓、扁平 2D 卡通、童趣手账风，配一些卡通图片，不要画抽象shape
- 色彩：高饱和明亮撞色，柔和马卡龙 
- 装饰：零散小贴纸元素（云朵、星星、小花、简笔小人、气泡对话框），边角点缀，不抢文字 
- 版式：圆角卡片分区，模块化布局，清晰文本框，简报 / 年度通讯版式 
- 氛围：轻松活泼、年轻化、非正式，课堂作业 / 小组汇报友好，不商务严肃

---

#### A-2 初中 / 高中——问题牵引风

**核心气质**：清晰、有逻辑、带着学生走——每一页是一次思考任务，不是一堆知识点。

**问题牵引规则**：

- **每页标题必须是问句或判断句**——「为什么勾股定理成立？」「氧化反应的本质是什么？」；板块名（「勾股定理」「氧化还原反应」）视为空洞，必须改写
- **引题页强制使用**：每章开头用完整问句作为第一视觉落点，配「这个问题会让你卡在哪里」的困惑锚点，困惑和答案不能在同一页
- **判断句结尾**：每章/每节末尾用一句可以脱离页面独立成立的判断句收束（「面积不变，周长可以变化」）
- **视觉服务于思维路径**：图形、公式、表格的摆放顺序必须还原推理步骤——先条件，再过程，再结论；不允许直接贴出结论图
- **风格**：中性底色（浅灰白/暖白）+ 一个学科主色作为问题/强调色；直角为主，允许小圆角标签；必要时要插入适当的插图展示信息。
- **字体**：文科——思源宋体+楷体；理科——思源黑体/黑体；公式用专业公式字体
- **密度**：中密度，关键推导步骤宁可多页也不压缩

**配色参考**：

- 理科：深靛蓝 #1A2E4B + 冷灰底 #F0F2F5 + 强调橙 #E8720C
- 文科：深墨 #2B2B2B + 暖白底 #FAF7F2 + 强调赭石 #9C5C38
- 生物/地理：深绿 #2F4A3B + 浅草底 #F3F7F0 + 强调土黄 #C8A44A
- 党政相关：白色 rgb(245,240,235) + 勃垦第红 + 炭黑

---



#### A-3 大学 / 职业教育——问题牵引·专业版

**核心气质**：严谨、可验证、有学术质感——在问题牵引的基础上，内容密度更高，来源/边界/反例不可省略，视觉克制而精准，使用思源宋体，先搜索学校或机构logo使用主色而不是直接用指导配色。

**在 A-2 基础上的差异规则**：

- **问题更深**：课件级驱动问题必须包含条件边界（「在什么假设下……才成立」）；页级问题必须区分定义/机制/应用三类
- **来源不可省**：所有外部事实、数据、引用必须标注来源/作者/年份；「示意数据」须显式标注
- **密度升级**：允许中高密度页面；演示页/案例页可包含多步推导；但仍然一页只回答一个问题
- **文字与图形分工严格**：文字承担定义/边界/判断依据；图形承担关系/结构/流程——不互相替代
- **风格**：深色章节页 + 浅底正文页交替；字体层级更多（标题/正文/引注/来源/图注 五层）；允许使用细线框表格和数据图表作为主展示物
- **代码/公式**：等宽字体；代码块背景加浅底色与正文明确区隔；公式编号右对齐
- **禁止**：「了解」「掌握」「熟悉」等不可观察动词；无来源的数据；口号式结语
