# 学信网当前有效学籍核验

本流程是学生优惠申请的内嵌子流程，不是独立 Skill。仅在主流程首次命中 `STUDENT_AUTH_REQUIRED` 时执行一次；完成、失败、取消或中断后都返回主流程，不独立决定优惠资格。

## 目标与返回边界

只核验学信网官方页面是否明确存在当前有效学籍，并返回主流程允许使用的最小结果。不要为学生优惠申请提取、展示或保存姓名、身份证号、学生 ID/学号、账号、密码、短信验证码、人脸信息、在线验证码、报告编号、验证链接或二维码内容。

将结果归一为：

```json
{
  "resultType": "NO_RESULT",
  "hasCurrentValidEnrollment": "unknown",
  "enrollmentStatus": null,
  "enrollmentEvidence": null,
  "institutionName": null,
  "majorName": null,
  "educationLevel": null,
  "reportValidUntil": null
}
```

映射必须固定：

- `unknown` → `NO_RESULT`
- `true` → `VALID_RESULT`
- `false` → `INVALID_RESULT`

`true` 和 `false` 使用 JSON 布尔值；只有无法判断时使用字符串 `"unknown"`。未取得的字段返回 `null`，不要猜测或补造。只向主流程返回这组字段，不把结果写入 `student_discount_run_application_step` 的参数。

## 执行流程

### 1. 打开官方页面

使用可用的浏览器自动化能力打开 `https://www.chsi.com.cn/`，进入“学信档案”；也可直接打开 `https://my.chsi.com.cn/archive/index.jsp`。仅在 `chsi.com.cn` 及其官方子域中操作。若出现付费或可疑第三方页面，停止并返回 `NO_RESULT`。

### 2. 将登录与敏感操作交给用户

到达登录页后，将浏览器控制权交给用户，并提示：

> 请在浏览器中亲自完成学信网登录。不要在对话中发送账号、密码、短信验证码、身份证号或人脸信息；登录完成后请告诉我继续。

等待用户明确确认。不要自动填写、读取或复述登录凭据；若页面要求实名认证、人脸识别或其他敏感操作，也必须由用户亲自完成。用户取消或无法登录时返回 `NO_RESULT`。

### 3. 查找学籍或在线验证报告

用户确认登录后，验证页面已进入学信档案个人中心，然后按以下顺序查找：

1. 优先查看“学籍信息”中的官方学籍状态。
2. 需要进一步核验时，进入“在线验证报告”，优先选择“教育部学籍在线验证报告”。
3. 已有有效报告时直接查看。
4. 没有有效报告但允许免费申请或延长时，在实际提交申请或延长前征得用户确认；用户不确认则基于已见信息判断，证据不足时返回 `NO_RESULT`。
5. 不为本流程申请“学历证书电子注册备案表”，除非它仅用于确认没有学籍信息；只有学历信息仍不能证明当前有效学籍。

常见入口文字包括“学籍信息”“在线验证报告”“申请”“查看”“延长有效期”。页面布局变化时以可见语义定位，不依赖固定 DOM id。

### 4. 提取最小必要信息

只读取并保留：

- 学籍状态原文；
- 院校、专业、学历层次；
- 报告有效期；
- 足以支持判断且已经脱敏的简短页面依据。

页面即使显示其他个人信息，也不要纳入返回结果或面向用户的回复。若下载 PDF 才能看到状态，只在浏览器能力允许且用户同意时下载，并仍遵守相同的数据最小化边界。

### 5. 判断当前有效学籍

- 官方学籍信息明确显示至少一条当前“在籍”或“注册学籍”记录：返回 `true`。
- 页面明确提示没有当前学籍，或所有可见记录均明确为“毕业”“结业”“肄业”“注销”等非当前在籍状态：返回 `false`。
- 无法进入页面、登录或浏览器失败、未取得学籍状态、报告过期且无法更新、状态含义不明确，或只有学历信息：返回 `unknown`。
- 多条记录中只要一条明确为当前在籍，即返回 `true`。
- 不把“有学历”“显示学校名称”“预计毕业日期未到”或用户口述当作当前有效学籍的充分证据。
- 只有全部可见记录均有明确非在籍结论时才返回 `false`；证据不完整时返回 `unknown`。

### 6. 返回主流程

先生成上述最小结果，再立即回到主 Skill 的 `finally` 流程。不要把 `false` 或 `unknown` 表述为学生优惠资格不通过；最终资格只由后续 `student_discount_run_application_step({})` 的可见返回决定。

## 异常处理

- 找不到入口：依次检查“学籍信息”“学历信息”“在线验证报告”，或打开 `https://my.chsi.com.cn/archive/bgysq/bgysq-index.action`；仍找不到则返回 `NO_RESULT`。
- 页面明确无学籍信息：在证据覆盖当前账号全部可见记录时返回 `INVALID_RESULT`，否则返回 `NO_RESULT`。
- 报告过期：征得用户确认后尝试免费延长或重新申请；无法处理时返回 `NO_RESULT`。
- 无法读取状态：可刷新一次或在用户同意后查看报告 PDF；仍无法读取则返回 `NO_RESULT`。
- 浏览器、登录、下载或页面加载失败：不要猜测，返回 `NO_RESULT`。
- 无论何种异常，都不要跳过主 Skill 要求的强制续调。
