# Worked Example：三国时期图解

这是按三个章节拆分的多图示例，普通回答默认不超过两个可视化模块；示例工具字段须按当前 schema 适配。为演示流程，假定下列事实已由用户资料提供；实际任务仍按事实核验规则处理。

## 1. 正文拆分

```yaml
article_sections:
- 第1段｜三国鼎立格局：曹魏、蜀汉、东吴并存，形成相互牵制的格局；三方实力并不相等。
- 第2段｜汉末至三国的时间脉络：184年黄巾起义后，汉末政局持续动荡；200年官渡之战、208年赤壁之战改变力量格局；220年至229年三国先后建立；263年蜀汉灭亡，280年西晋灭吴、完成统一。
- 第3段｜三场关键战役：官渡之战为曹操统一北方奠定基础；赤壁之战奠定三分局面的基础；夷陵之战使蜀汉遭受重创。
```

第2段的时间节点先整理如下；共5个节点，时段的两个端点均已明确。

```yaml
time_facts:
- 时间: '184'
  事件: 黄巾起义
  含义: 汉末动荡的重要节点
- 时间: '200'
  事件: 官渡之战
  含义: 曹操取得北方争霸优势
- 时间: '208'
  事件: 赤壁之战
  含义: 三分局面形成的重要基础
- 时间: 220—229
  事件: 三国建立
  含义: 曹魏、蜀汉、东吴先后建国
- 时间: 263—280
  事件: 三国走向统一
  含义: 从蜀汉灭亡到西晋灭吴、完成统一
```

## 3. 视觉策略

统一视觉系统：

- 风格：博物馆历史知识图解；
- 配色：古籍米白、朱砂红、墨黑、青铜绿；
- 材质：古籍纸张、青铜器纹理、印章；
- 标题：同一书法印刷字体气质；
- 图形：三方关系示意、时代长卷、战役场景；
- 禁止：游戏 UI、廉价古风边框、等大卡片、密集小字。

三张图构图必须不同：

- 格局图：横向三角制衡；
- 时间线：横向时代长卷；
- 战役图：中心关系结构加三个战役场景。

## 5. 生成后检查

- 三张图是否使用了三种不同构图；
- 时间线是否为横图；
- 格局图是否能一眼看到三方制衡；
- 战役图是否有中心关系结构，而非三张卡片；
- 逐张对照 `visible_text_list` 核对标题、标签和短句，是否有缺失、错字或新增文案；
- 年份、国名、战役影响是否与对应段落及 `time_facts` 一致；
- 若当前业务要求固定模型，是否已根据工具 schema 使用正确的顶层 `model_version`；否则是否避免提交未知字段。
