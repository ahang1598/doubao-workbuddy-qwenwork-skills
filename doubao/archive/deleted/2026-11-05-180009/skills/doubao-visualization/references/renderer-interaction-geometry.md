# 交互、联动与几何专项

仅在 HTML/SVG 已确定为交互模式，且需要拖拽、播放、几何约束、DOM/ECharts 联动时读取。通用脚本安全规则见 `renderer-stability-math.md`。

## 交互契约

- 操作必须揭示新的状态、因果、过程或参数关系。
- 初始状态已表达主结论；交互不是唯一入口。
- 操作后即时更新图形，并同步显示文字或数值反馈。
- 控件少而明确，点击区域不小于 44×44px，支持 click/tap。
- hover 只能增强，不能承载必要信息。
- 动画必须提供暂停和重置，停止后不继续高频刷新。
- 控件、提示和图例不得覆盖核心画布。

## 交互形态

| 需求 | 首选控件 | 必需反馈 |
| --- | --- | --- |
| 连续参数 | range | 当前值、单位、图形变化 |
| 离散状态 | segmented buttons/select | 当前模式与差异 |
| 算法步骤 | 上一步/下一步/播放 | 当前步骤、状态和队列 |
| 几何变换 | SVG/Canvas 拖拽点 | 约束状态与关键量 |
| 动画过程 | 播放/暂停/重置 | 进度与当前状态 |
| 多视图比较 | 切换或同步高亮 | 联动方向与共同尺度 |

输入必须校验范围和非法值；键盘可操作时提供清晰焦点状态。

## Renderer 内嵌 ECharts

仅当图表必须与 DOM 控件、用户原图或其他视图联动时使用。普通数据图返回原生 `echarts` option。

- 图表容器设置明确局部高度，直接父元素设置 `min-width:0`。
- `window.resize` 时调用 `chart.resize()`。
- tooltip `confine:true`，长内容允许换行。
- 直角坐标图设置 `grid.containLabel:true`。
- 密集标签使用 `labelLayout.hideOverlap`、缩写、采样或 tooltip。
- 数值统一精度和单位，避免浮点尾数与不合常理量级。
- 外部库加载失败时显示静态说明，不能空白。
- 禁止地图、`geo`、`map` 和地图注册数据。

## 几何与约束

- 点、线、角、长度和变量名与证明文字一一对应。
- 垂直、平行、相切、中点、共线、共圆等关系必须由计算保证，不能只靠视觉近似。
- 拖拽只能改变自由变量；每帧根据约束重新求解派生点。
- 拖拽范围限制在有效域，退化状态应阻止或明确提示。
- 角度、长度和不变量按统一精度更新。
- 图示不得暗示尚未证明的结论。
- 无法稳定维持约束时改用静态 SVG。

## 防重叠

- 标签与锚点分离，必要时按象限偏移或使用 leader line。
- 同一直线上的密集标签交错排布。
- 长文本设置宽度、换行和行高。
- 节点多于可读容量时隐藏次要标签，通过点击或正文补充。
- 初始、拖拽边界、播放终点和窗口缩放后都要检查包围盒。

## 交付检查

- 每个控件是否改变了有意义的信息？
- 所有交互是否支持移动端？
- 暂停、重置和错误状态是否可用？
- 几何约束在边界状态下是否仍成立？
- 联动图表和正文是否使用同一数据与单位？
