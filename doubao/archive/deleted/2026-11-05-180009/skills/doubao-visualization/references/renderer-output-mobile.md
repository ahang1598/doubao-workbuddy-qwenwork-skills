# HTML/SVG 移动端专项

仅在系统或用户明确移动端，且存在复杂分栏、长文本、密集控件或高信息密度时读取。普通响应式规则已包含在 `mode-html-svg.md`。

## 布局

- 按宿主内容宽度设计，不按整机屏幕高度推算。
- 根容器 `width:100%;box-sizing:border-box;height:auto`，禁用 `100vh`、`height:100%` 和根固定高度。
- 优先单列；多列只能使用 Flex 换行或 Grid `auto-fit/minmax`。
- SVG 和图片保持比例并限制 `max-width:100%`。
- 标题、图例、控件位于主体上方或下方，不挤在侧边。

## 文字与控件

- 正文不低于 14px，辅助文字不低于 12px。
- 点击区域不小于 44×44px；核心操作支持 tap，不能只依赖 hover。
- 长文本允许换行；标签过密时缩短、编号、折叠或拆分。
- 控件不能覆盖图形、标签或反馈区；空间不足时上下堆叠。

## 密度与性能

- 首屏只保留主结论、关键节点和必要图例。
- 复杂关系拆成连续模块，不横向压缩为不可读小图。
- 避免大规模粒子、复杂 3D 和持续高频动画。
- 动画必须可暂停、可重置，并尊重 `prefers-reduced-motion`。

## 检查

- 320-430px 宽度下是否无横向溢出？
- 最长标题、标签和按钮文字是否完整可读？
- 初始、展开和交互状态是否均无重叠、裁切？
- 手指操作是否不会遮住唯一反馈？
