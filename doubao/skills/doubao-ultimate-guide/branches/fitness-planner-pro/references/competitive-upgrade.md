本文件合并了开源训练系统能力抽象和开源资源接入说明。**用途**：把开源训练平台里有价值的结构抽象成健身攻略能力，让攻略变成“可开始训练、可记录每组、可中途替换、可复盘进阶”的训练系统。**不要在用户文档里暴露项目名、仓库名、许可证或内部字段**；用户只看到更专业、可执行、可记录、可调整的攻略。

## 使用场景

当用户提到动作库、训练模板、训练记录、PR、训练容量、RIR、渐进超负荷、替代动作、训练历史、食物日志、体重追踪、开源健身项目、wger、workout-cli，或需要完整高质量计划时读取本文件。

## 接入原则

- 先查真实性和许可证，再借鉴结构。不要把未经核验的仓库内容当成权威训练标准。
- AGPL 项目（如 wger）**不能**把代码、大段 fixture、图片或文案复制进闭源交付物；只借鉴结构。
- 开源动作库不是医学权威；动作安全仍优先用 `training-standards.md`、`exercise-technique-library.md` 和权威资料核验。
- 不要声称某开源项目有某功能，除非已打开仓库或文档核验。
- 不要把动作库中的文字原样大段复制到最终回答；要转成适合用户的动作卡和自检语言。
- 不要把姿态识别输出包装成确定诊断。

## 候选资源与可借鉴点

| 来源 | 可借鉴的抽象能力 | 放进攻略的表现 | 注意 |
|---|---|---|---|
| wger | 动作分类、器械、肌群、训练日、组次/重量/RIR/休息配置、训练日志、营养和体重记录 | 动作卡、训练模板、打卡表、营养/体重追踪字段 | AGPL，只借鉴结构，不复制代码/fixture/图片/文案 |
| workout-cli | 快速记录、模板训练、RIR、相对加重、swap/add/skip、训练摘要、PR、容量分析 | 可填训练日志、替代矩阵、2–4 周复盘仪表盘 | MIT，但仍避免照搬完整代码和动作库 |
| workout-db / free-workout-plans / bodyweight-fitness | 动作字段抽取、计划样例、自重进阶 | 动作卡字段、计划结构 | 核验维护状态与免责声明 |
| FitTrackee / HomeWorkout | 训练记录和应用逻辑 | 打卡与日志字段 | 借鉴交互，不复制 |

姿态数据集或姿态模型仅在用户明确要做视觉动作识别时评估；Skill 只能提供产品流程、动作要点和安全提示，实时纠错应由专门模型或应用实现。

## 攻略里的最小数据模型

### 动作字段（完整计划中关键动作至少体现 6 项）

| 字段 | 写给用户的表达 |
|---|---|
| 动作名 | 中文名，必要时加英文名方便搜视频 |
| 动作模式 | 蹲、髋铰链、推、拉、核心抗伸展/抗旋、单腿稳定、心肺 |
| 目标肌群 | 主练肌群 + 辅助肌群 |
| 器械 | 自重、哑铃、弹力带、杠铃、器械、绳索、跑步机等 |
| 类型 | 复合 / 孤立 / 热身 / 有氧 / 活动度 / 核心 |
| 难度 | 新手可做、需要基础、进阶动作 |
| 处方 | 组数、次数/时长、强度、休息 |
| 自检 | 1 句判断动作是否对 |
| 替代 | 无器械、器械被占、不适时的替代 |
| 进阶 | 加重量、加次数、加组数、放慢离心、缩短休息或升级动作 |

肌群大类：手臂、腿、腹、胸、背、肩、小腿、心肺。常用器械：杠铃、EZ/SZ 杆、哑铃、垫子、瑞士球、引体杠、自重、平板凳、上斜凳、壶铃、弹力带、绳索、固定器械。常用肌群：胸、背阔、斜方、竖脊肌、肩前/中/后束、肱二、肱三、前臂、腹直肌、腹斜肌、臀、股四、腘绳肌、小腿。

### 训练模板字段（每个训练日尽量包含）

| 字段 | 说明 |
|---|---|
| 训练日名称 | 例如全身 A、肩背核心、下肢臀腿、跑走结合 |
| 训练目的 | 这天解决什么问题 |
| 热身 | 3–8 分钟，含活动度和轻量激活 |
| 主训练 | 2–5 个核心动作 |
| 辅助/补弱 | 1–3 个目标肌群或稳定性动作 |
| 有氧/步数 | 按目标加入，不要硬塞 |
| 收操 | 拉伸、呼吸或低强度走路 |
| 强度 | 大白话 + 括号标 RIR/RPE/心率（如"有挑战还能做2-3次 RIR2-3"） |
| 进阶规则 | 下次如何加量或降级 |

### 当次训练记录字段

只要生成周期训练或打卡计划，就给可记录表（按场景选字段）：

| 字段 | 训练型 |
|---|---|
| 日期 | 训练发生日 |
| 模板 | 今天按哪个训练日练 |
| 动作 | 实际完成动作 |
| 目标 | 计划组数 x 次数/时长 |
| 实际 | 实际重量、次数、组数或时长 |
| RIR/RPE | 还剩几次余力或主观强度 |
| 休息 | 组间休息 |
| 疼痛 | 0–10，超过 3 要调整 |
| 备注 | 动作感觉、器械替换、睡眠压力 |

饮食或体重管理场景加：7 日均重、腰围、照片、步数、蛋白达标、含糖饮料次数、外卖执行率、睡眠。食堂/外卖场景重点记“少油少酱是否做到、每餐蛋白是否有、饮料是否无糖、夜宵零食次数”。

## 替代与中途调整逻辑

任何完整训练计划都应让用户知道“练不了怎么办”：

| 情况 | 处理 |
|---|---|
| 器械被占 | 换同动作模式、相近肌群、相近强度的替代动作 |
| 时间不够 | 保留热身 + 主动作 + 1 个补弱；删掉泵感和可选有氧 |
| 动作疼痛 | 立即降阶或换低风险动作；疼痛 >3/10 停止该动作 |
| 太轻松 | 先加次数到上限，再小幅加重量或升级动作 |
| 太累/睡眠差 | 降 1–2 个 RPE、少做 1–2 组或改技术练习/快走 |
| 漏练 | 不惩罚性补课；回到下一次计划或做 20 分钟最小训练 |

替代动作匹配动作模式：蹲（椅子深蹲→高脚杯深蹲→腿举→深蹲）；髋铰链（臀桥→靠墙髋铰链→哑铃 RDL→壶铃/杠铃硬拉）；水平推（墙面俯卧撑→上斜俯卧撑→器械推胸→哑铃卧推）；水平拉（弹力带划船→坐姿划船→胸托划船→杠铃划船）；垂直拉（弹力带下拉→高位下拉→辅助引体→引体向上）；核心（死虫→平板→侧桥→Pallof press→负重抗旋）。

## 进阶与分析要求

完整周期计划要提供复盘规则，不只给一次性安排：

- 双进阶：在目标次数区间内，所有组达上限且仍有 1–2 次余力，下次加 2.5–5% 重量或换更难版本。
- PR：不只看 1RM。可记录同重量更多次数、同次数更大重量、更标准动作、更少疼痛、更稳定完成率。
- 容量：力量训练粗略看 `重量 x 次数 x 组数`；自重看总次数、总时长、动作难度。
- 肌群平衡：每 2–4 周检查推/拉、上/下肢、核心、心肺是否偏科。
- 疲劳管理：连续 2 次表现下降、睡眠变差、关节不适或主观疲劳高，下一周降载 30–50% 训练量。

## 飞书文档转化方式

把这些能力变成用户看得懂的文档组件（按场景挑，不全部塞）：

- 动作库卡片：动作名、目标肌群、器械、动作模式、要点、替代、视频。
- 训练模板表：训练日、目的、动作、组次、强度、休息、进阶。
- 当次训练日志表：目标 vs 实际、RIR/RPE、疼痛、备注。
- 替代矩阵：器械被占、疼痛、时间不够时怎么换。
- 复盘仪表盘：完成率、训练容量、PR、围度/体重、睡眠、疼痛。
- 饮食日志表：餐次、蛋白、蔬菜、主食、饮料、外卖执行率。

力量/增肌/长期计划优先训练日志和 PR；减脂饮食优先饮食日志和体重趋势；动作教学优先动作卡、替代和视频；新手入门优先第一练、动作降阶和打卡。

## 开源资源核验清单

接入任何开源资源前检查：仓库是否可访问 / 最近维护状态 / LICENSE 类型 / 是否有训练或医学免责声明 / 数据字段是否结构化 / 是否包含明显不安全、极端或过时建议 / 是否需要保留 attribution。
