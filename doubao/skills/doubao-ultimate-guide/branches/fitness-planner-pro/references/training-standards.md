## 计划组成

每份完整训练计划至少包含：

- 目标路径：这份计划主要靠什么产生效果，训练、饮食、步数/有氧、恢复各自承担什么角色。
- 周频率：每周几练、休息日如何安排。
- 周期长度：按目标和人群选择；新手泛需求可默认 8 周，减脂/增肌常用 8-12 周，动作教学可只做单次。
- 单次结构：热身、主训练、辅助训练、有氧或收操。
- 动作处方：动作名、组数、次数或时长、强度、休息时间。
- 进阶规则：何时加重量、加次数、加组数或提高难度。
- 替代动作：每个关键动作至少 1 个替代。
- 复盘指标：体重、围度、训练重量、主观疲劳、睡眠、步数等。
- 执行阻力处理：时间不够、器械被占、漏练、没动力、疼痛/酸痛、饮食吃超时怎么回到计划。

## 训练模板与日志标准

完整攻略不要只给“动作菜单”。训练计划应像可执行模板，让用户能照着练、照着记、照着调整。

### 训练模板最小字段

| 字段 | 要求 |
|---|---|
| 训练日 | 写清是全身、上肢、下肢、肩背核心、跑步辅助等 |
| 目的 | 说明这天服务哪个目标 |
| 动作 | 中文名，必要时加英文名方便找视频 |
| 动作模式 | 蹲、髋铰链、推、拉、核心、单腿稳定、心肺等 |
| 目标肌群 | 主练肌群 + 重要辅助肌群 |
| 器械 | 居家/健身房/自重/哑铃/弹力带/杠铃/器械 |
| 组次 | 组数 x 次数或时长 |
| 强度 | RIR/RPE/心率区间 |
| 休息 | 组间休息或动作间休息 |
| 自检 | 1 句动作质量标准 |
| 进阶 | 达到什么条件后加重量、次数、组数或难度 |
| 替代 | 器械被占、不适或太难时换什么 |

### 核心动作卡最小字段

核心动作不能只写进表格。每个影响目标或安全的核心动作至少补一张“动作卡”或等价段落：

| 字段 | 要求 |
|---|---|
| 适合原因 | 为什么这个动作服务当前目标 |
| 起始姿势 | 脚/手/躯干/器械位置 |
| 执行路径 | 从开始到结束怎么移动 |
| 发力感觉 | 应该主要感到哪里在发力 |
| 常见错误 | 至少 2 个错误 + 对应修正 |
| 降阶/进阶 | 太难/太轻/器械不合适时怎么变 |
| 停止条件 | 疼痛、麻木、头晕、动作失控时怎么处理 |

辅助动作可以只给 1 句自检，但不能所有动作都只有动作名。

### 当次训练日志字段

周期训练、新手入门、增肌、力量、减脂打卡和平台期调整必须提供日志入口：

| 日期 | 模板 | 动作 | 目标 | 实际 | RIR/RPE | 休息 | 疼痛 | 备注 |
|---|---|---|---|---|---|---|---|---|

说明：

- 负重动作记录重量 x 次数 x 组数；自重动作记录总次数、难度或动作高度；有氧记录时长、配速/距离、RPE 或心率。
- 疼痛用 0-10 评分，但给用户要解释清楚：0=完全不痛，10=痛到受不了。**3 分是"有明显疼痛、已经让你想停下来"的界限**——超过这个、麻木、刺痛、锐痛或次日明显恶化时，停止该动作换低风险版本。给用户写"疼痛明显到让你想停就别硬撑（超过 3/10）"，不要只甩"3/10"。
- 备注记录睡眠、压力、器械替换、动作感觉和是否达成目标。

### 中途调整规则

| 情况 | 调整 |
|---|---|
| 器械被占 | 换同动作模式和相近肌群的动作，不为了等器械打乱全场训练 |
| 时间只剩 20 分钟 | 保留热身、1-2 个主动作和 1 个核心/收操；删掉可选泵感动作 |
| 动作不舒服 | 先降阶、减重、缩短幅度；疼痛超过 3/10 直接换动作 |
| 睡眠差或疲劳高 | 保留动作模式，训练量减少 30-50%，强度降 1-2 个 RPE |
| 漏练 | 不补惩罚性训练，下一次回到计划；本周只看核心训练是否完成 |
| 没动力 | 做最低完成版：热身 + 1 个主动作 + 1 个收操；完成后不加罚 |
| 饮食吃超 | 下一餐回到蛋白+蔬菜+正常主食，不用断食或加练惩罚 |
| 平台期 | 先看 2 周完成率、睡眠、步数和饮食，再决定加量或调整缺口 |

### 进步分析

给长期计划时必须说明 2-4 周如何判断有效：

- PR：同重量更多次数、同次数更大重量、更稳定动作、更少疼痛或更高完成率都算进步。
- 训练容量：负重动作看 `重量 x 次数 x 组数` 的趋势；自重动作看总次数、难度、标准程度和总时长。
- 肌群覆盖：减脂和新手看全身动作模式是否覆盖；增肌看每肌群周有效组数；塑形看目标肌群每周是否 2-3 次刺激。
- 恢复：睡眠、疲劳、酸痛、关节不适和表现下降决定是否降载。

## 先定周指南针

训练计划不要像菜单堆动作。先定本周最重要的 1-2 个目标，再安排训练。

- 减脂：力量保肌肉 + 步数/低冲击有氧 + 饮食缺口。
- 增肌：训练量 + 渐进超负荷 + 热量盈余和睡眠。
- 心肺：低强度有氧打底，少量间歇点缀。
- 体态：高频低强度活动度 + 稳定性 + 基础力量。
- 力量：主项技术和强度，辅助动作服务主项。

如果用户时间、睡眠或恢复不稳定，给“周指南针”比固定死日程更实用：本周至少完成 2-3 次力量、1-2 次有氧或步数、2 次活动度；漏练不叠加惩罚性补课。

## 新手默认方案

当用户没有训练基础时，优先使用：

- 每周 3 次全身力量训练，另加 2-4 天轻松有氧或日常步数。
- 每次 45-60 分钟。
- 每个动作保留 2-4 次余力，避免力竭。俯卧撑、深蹲等自重动作也不要默认写“做到力竭”。
- 先学深蹲/髋铰链/推/拉/核心/负重行走六类模式。
- 减脂可加每周 2-4 次低冲击有氧或日均步数目标。
- 第一个月不默认安排杠铃硬拉。需要髋铰链时，先用靠墙髋铰链、臀桥、轻哑铃罗马尼亚硬拉或壶铃硬拉替代。
- 成人健康锚点：多数成年人可把长期目标设为每周 150 分钟左右中等强度活动，加至少 2 天覆盖主要肌群的力量训练；新手可以从更低量开始逐步接近。

## 新手周期示例

| 周期 | 目标 | 训练安排 | 重点 |
|---|---|---|---|
| 第 1-2 周 | 启动 | 每周 3 次全身 + 2 次轻松活动 | 动作学习、不过度酸痛 |
| 第 3-4 周 | 稳定 | 维持 3 练，记录次数和 RPE | 动作稳定、建立节奏 |
| 第 5-6 周 | 提升 | 小幅加次数、组数或重量 | 渐进超负荷 |
| 第 7-8 周 | 巩固 | 保持训练量，做复盘 | 决定下一阶段目标 |

## 目标周期选择

- 新手泛攻略：8 周，重点是动作学习和习惯。
- 减脂：8-12 周，重点是力量训练、步数、有氧和饮食缺口。
- 增肌：8-12 周，重点是训练量、渐进超负荷和恢复。
- 力量提升：6-12 周，重点是主动作强度、技术和降载。
- 跑步/心肺：4-12 周，根据当前跑量和目标递进。
- 体态/久坐：4-8 周，高频低强度纠偏。

## 训练量与强度

- 新手：每个大肌群每周 6-10 组起步。
- 有经验训练者：每个大肌群每周 10-20 组，结合恢复调整。
- 力量目标：主动作 3-6 次为主，休息 2-4 分钟。
- 增肌目标：多数动作 6-15 次，部分孤立动作 12-20 次，休息 60-150 秒。
- 减脂目标：力量训练保肌肉，有氧和日常活动制造能量消耗。
- 心肺目标：低强度有氧为底，高强度间歇少量点缀。

强度表达：

强度内部用 RPE/RIR/心率校准，但**呈现给用户时必须用大白话解释**，让普通用户看懂，括号里再标专业数值。用户看不懂的纯术语（如只写"RPE 7-8"）不行。

- 力量训练强度（给用户的说法 + 括号标数值）：
  - "轻松，还能做好几次"（RPE 5-6 / RIR 4-5）：新手学动作、恢复日。
  - "有挑战，但动作不变形，还能再做 2-3 次"（RPE 7-8 / RIR 2-3）：大多数增肌和力量训练。
  - "很吃力，接近做不动"（RPE 9-10 / RIR 0-1）：普通攻略少用；新手、睡眠差、疼痛用户避免。
- 心肺强度（给用户的说法 + 括号标数值）：
  - "慢跑时能连续说完整句子，呼吸平稳"（RPE 3-4）：低强度打底。
  - "能说短句，但说长句会喘"（RPE 5-6）：中等强度。
  - "只能说几个字，喘得厉害"（RPE 7-9）：高强度，新手只少量用。
- 用户提供年龄时可用粗略最大心率 `220 - 年龄` 算心率区间；没有年龄就用上面的大白话描述。
- 训练日志里记 RPE/RIR（给复盘用），正文给用户时用大白话为主、括号标数值。

## 渐进超负荷

推荐双进阶规则：

1. 设定次数区间，例如 8-12 次。
2. 当所有工作组都能以标准动作做到上限，且仍有 1-2 次余力，下次小幅加重量。
3. 加重量后回到区间下限继续推进。

居家自重训练可用：

- 增加次数。
- 增加组数。
- 放慢离心。
- 缩短休息。
- 提高动作难度。
- 使用背包、弹力带或单侧变式。

## 周期与降载

- 4-8 周作为一个小周期。
- 连续 2 周表现下降、睡眠变差、关节不适或主观疲劳高时，安排 1 周降载。
- 降载方式：训练量减少 30-50%，强度降低 5-10%，保留动作模式。

恢复信号：

- 睡眠差、压力大、连续疲劳：当天降强度或改技术/低强度有氧。
- 连续 2 次同动作表现下降：减少训练量或安排降载。
- 关节疼、麻、刺痛：停止该动作，换低风险替代，不要“顶着练”。
- 两次高强度训练间至少隔 48 小时；短时训练也不能天天冲强度。

## 常见目标方向

### 减脂

- 每周 3 次力量训练。
- 每周 2-4 次 20-40 分钟低冲击有氧。
- 日均步数从当前水平增加 2000-3000 步。
- 饮食使用轻度热量缺口。
- 对上班族和外卖用户，NEAT/步数通常比额外 HIIT 更容易坚持。优先把日均步数从当前水平提高 2000 步，而不是直接每天高强度。

### 增肌

- 每周 3-5 次力量训练。
- 每个肌群每周训练 2 次左右。
- 主动作追踪重量和次数。
- 饮食使用轻度热量盈余和足量蛋白。
- 偏瘦新手先每周 3-4 练，全身或上下肢优先；有半年以上基础再考虑每周 5 练分化。
- 大量有氧会挤占恢复和热量盈余。偏瘦增肌用户保留轻松散步即可，不安排消耗型跑跳计划。

### 居家无器械

- 深蹲/弓步/臀桥。
- 俯卧撑/跪姿俯卧撑。
- 上斜俯卧撑优先于标准俯卧撑；能稳定完成后再降高度。
- 弹力带划船优先；桌边划船仅在桌子稳定且用户理解安全风险时使用。
- 平板支撑、死虫、侧桥。
- 新手有氧优先快走、骑车、椭圆机等低冲击方式。跳绳、开合跳等高冲击动作只在膝踝耐受良好时使用。

### 短时高效

用户每次只有 20-30 分钟时：

- 不要塞完整长训练。保留 1 个主目标。
- 结构：3-5 分钟热身，15-20 分钟主训练，2-5 分钟收操。
- 每周多次训练时，高强度日和恢复/体态日交替。
- 短时训练也要有动作质量和停止条件，不要默认 HIIT。

### 跑步入门

- 从跑走结合开始，例如跑 1 分钟 + 走 2 分钟，重复 6-10 组。
- 每周 3 次，隔天跑；先增加总时长，再增加连续跑时间。
- 搭配每周 2 次基础力量：臀桥、分腿蹲、提踵、死虫、侧桥、髋铰链。
- 疼痛逐次加重、胸痛、头晕、异常气短时停止。
