# 易混路由边界

已命中 `SKILL.md` 第 1.2 节“单一数据域遍历”的请求，应直接使用对应的 `lark-xxx`；本表仅处理未命中该规则，且第 1.4 节仍不足以判断具体对象类型的易混边界。

| 对象类型 | 使用 `lark-xxx` / 对应 OpenAPI | 使用 `enterprise_agentic_search` | 其他路径 |
|---|---|---|---|
| 文档 | 已给出明确文档、文件或 Wiki URL，需要打开、读取、总结、提取字段/名单/正文、编辑或导出对象本体 | 读取后对象内容不足，或需要围绕主题、项目或文档名查询背景、讨论、反馈、风险、结论、决策依据、后续进展 | — |
| 群聊 / 消息 | 发送、回复、点赞、批量发送、@我、私聊、未回复、未读、群成员/人数/列表查询，按消息 ID、链接或时间点定位明确消息；仅需按人员、时间、主题或关键词等条件筛选、枚举、计数匹配消息；以及“问下/跟某人确认/找某人确认”等消息操作 | 需要基于消息内容追溯背景或过程，或归纳已有发言、讨论、观点、反馈和结论 | — |
| 会议 | 读取单个明确会议及其直接产物，如妙记纪要、录音、转写和复盘文档 | 按时间段、主题、项目或多场会议复盘讨论、结论、待办、风险和进展 | — |
| 日程 | 查询日程对象状态或执行日程操作 | 基于一段时间的日程或会议进行复盘、主题归纳和协作分析 | — |
| 项目 / 任务 / 工作内容 | 操作明确的 Meego、飞书项目、工作项、视图、节点、MQL、项目空间、飞书任务或任务清单，包括状态、流转、创建、更新和完成 | 按时间段、团队、主题或个人视角查询或总结需求安排、工作内容、未完成事项、跟进项、风险、阻塞和历史进展 | — |
| 联系人 / 人员 / ID / UID / 账号 | 查询飞书/Lark 通讯录中的姓名、部门、职位、组织关系、团队归属、邮箱、员工 ID、用户标识或收件人信息 | 查询企业豆包 UID、产品 UID、平台账号、业务系统 ID，或从非结构化内部资料判断实际职责、业务归属、项目参与、历史协作、观点贡献和发言内容 | — |
| 公司制度与职能 | 查询个人实时记录、审批流、审批模板、审批单等审批对象或明确对象状态 | 查询制度、政策、流程、口径、申请方法和历史说明 | — |
| 公司 / 办公语境下的生活服务 | — | 查询内部食堂、园区福利、公司班车、内部活动和员工专属渠道等依赖内部资料的信息 | 公司楼下餐饮、附近商圈、公开餐饮推荐和外部商业信息使用公开搜索或直接回答 |
| 品牌文创 / 周边 / 内部活动 | — | 查询公司特色、员工内购、内部活动、品牌物料、设计思路、单品清单及领取或购买渠道 | 明确要求官网、电商平台、公开售卖页或公开媒体信息时使用公开搜索 |
