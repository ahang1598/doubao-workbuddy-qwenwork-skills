# 课堂转写清洗

清洗课堂录音转写、本地 ASR、字幕或复制来的授课文本时读取本参考。

## 清洗目标

- 保留原意、事实、教学顺序、定义、推理、例子、纠错、任务和强调内容。
- 删除无意义口头语、重复片段、设备噪声、破碎标点和明显转写卡顿。
- 保持不确定性可见；不把同音词猜测改成确定事实。

## 工作流

1. **规范说话人**：说话人有助于理解问答时保留；身份不明时使用“教师/学生/发言者待确认”，不猜姓名。
2. **清理口语噪声**：删除填充词、重复起句和无意义打断；教学反问、纠错和有解释作用的玩笑应保留。
3. **修复段落**：按主题拆分长段落，添加简洁小标题；默认保留课堂时间顺序。
4. **核对术语**：仅当课件、板书或上下文足以确认时修正术语；否则保留候选并标 `[待核对]`。
5. **保留定位**：原稿有时间戳时沿用；没有时禁止虚构时间戳。
6. **提取锚点**：另列定义、例题、反例、教师强调、学生疑问、作业和 DDL，供最终笔记重组。

## 不得执行

- 不概括掉后续笔记需要的推理、条件和例证。
- 不删除决定教师回答含义的学生问题。
- 不编造缺失课件、日期、指标、URL、来源或课堂后半段。
- 不覆盖原始转写。

## 清洗稿最小结构

```markdown
# 清洗稿｜<课程或主题>｜<日期>

## 一句话概览

## 主题一

### 关键讲解

### 课堂案例/问答

### 教师强调与任务

## 待核对

- [ ] 术语/数字：
- [ ] 对应时间戳或课件位置：
```

清洗稿可以保留课堂顺序和说话人；最终学习笔记必须改写为学习者可直接复习的知识结构。
