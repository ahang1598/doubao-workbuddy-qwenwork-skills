输入含课堂照片、截图、扫描 PDF、板书或手写笔记时读取本参考。目标是生成可回看原图的识别稿，而不是制造看似流畅但无法核验的文本。

## 支持边界

| 内容 | 默认处理 | 强制复核 |
|---|---|---|
| 清晰印刷文字 | OCR/视觉识别后按段落重建 | 页码、标题、数字、DDL |
| 普通手写文字 | 整页理解后分区转写 | 专名、数字、否定词、缩写 |
| 公式与符号 | 按视觉结构转写 | 上下标、正负号、括号、条件、单位 |
| 图表与板书关系 | 描述节点、箭头、圈框、坐标和颜色 | 方向、图例、坐标轴、连接关系 |
| 化学结构/复杂示意图 | 先描述可见结构，再谨慎转写 | 键型、取代位置、标注、反应条件 |
| 模糊、遮挡或裁切区域 | 标记位置和问题 | 禁止猜写 |

只做文本识别、无学习笔记需求时，不使用本 Skill。

## 处理流程

### 1. 页面预检

1. 记录文件名、页码/图片编号、方向、裁切、阴影、反光、透视和清晰度。
2. 检查扫描 PDF 是否已有可信文本层；文本层乱码或缺失时按图片处理。
3. 必要时旋转或逐页查看，但禁止覆盖原图。
4. 将页面分为标题区、正文区、边注区、公式区、图表区和任务区；用 `R1`、`R2` 等编号。

**门禁：**未完成整页预检和区域编号前，不得直接输出连续全文。

### 2. 分层识别

按以下顺序处理每页：

1. **整页语境**：判断课程主题、页面结构和阅读顺序。
2. **印刷文字**：优先使用宿主视觉能力；有本地 OCR 时可用于初稿，但不得把 OCR 结果视为权威来源。
3. **手写文字**：逐区域识别，保留删除线、星号、问号、框选和边注的学习含义。
4. **公式/图表/代码**：单独读取，不与自然语言 OCR 混跑；代码必须保留缩进。
5. **版式关系**：用“R1 → R3”“R2 圈出 R4”“红色批注修正蓝色公式”等中性描述记录空间关系。

若宿主没有可用视觉能力，停止视觉识别分支并请求用户提供更清晰图片或人工转写；不要假装已读取图片。

### 3. 置信度与字符策略

- `[已确认]`：图像清晰，或有另一清晰课程来源交叉支持。
- `[待核对]`：可提出一个候选，但字符、数字、符号或关系仍不稳定。
- `[无法辨认]`：不能可靠提出候选；写明页码/区域和不可读原因。
- 不确定字符使用 `□`，不根据学科常识自动补齐。
- 不确定候选最多给 2 个，并说明区分它们需要查看什么。
- 课件或教材可用于核对，但不得把未出现在图片中的内容补写成图片原文。

### 4. 二次复核清单

以下内容必须回看原图：

- 日期、时间、分数、页码、题号、任务和截止日期。
- 公式中的上下标、根号范围、分式线、积分上下限、正负号和括号。
- 物理量单位、化学式/结构式、生物专名和代码缩进。
- 坐标轴、箭头方向、图例、颜色含义、圈框包含关系。
- 否定词、条件词和例外词，例如“不”“仅当”“除外”。

## 视觉识别稿模板

```markdown
# 视觉识别稿｜<课程或主题>

## 材料与页面

| 标签 | 文件/页码 | 类型 | 可读性 | 问题 |
|---|---|---|---|---|

## 分区转写

### [手写笔记 1-R1]

[已确认] ...

### [手写笔记 1-R2]

[待核对] 候选 A / 候选 B；需核对...

## 公式、图表与版式

- [截图 2-R3] ...

## 待核对

| 区域 | 可见内容/候选 | 不确定原因 | 建议核对方式 |
|---|---|---|---|

## 识别审计

- 已复核的数字/公式/任务：
- 无法辨认的区域：
- 使用的交叉来源：
```

## 准出条件

- 每页有标签，每个关键区域可定位。
- 手写内容没有被无依据“润色”为印刷体结论。
- 公式、数字、DDL 和空间关系完成二次复核。
- 模糊内容显式标记；视觉识别稿与原图均保留。
