# 可选协作文档写回

仅当用户明确要求把清洗稿、预习卡或学习笔记写入飞书/Lark 或其他协作文档时读取本参考。远程写回是可选交付方式，不是整理笔记的硬依赖。

## 门禁

1. 必须确认当前环境有对应的官方连接器或已安装工具，并且用户有目标文档权限。
2. 默认新建文档；只有用户明确指定目标并要求更新时才编辑已有文档。
3. 禁止覆盖原始逐字稿、课件或教师文档。
4. 连接器不可用、鉴权失败或权限不足时停止远程分支，保留本地 Markdown 并说明限制。

## 写入顺序

1. 先生成并验证本地 Markdown 权威版本。
2. 创建远程文档骨架，再按章节分块写入长内容。
3. 对 Mermaid、白板、表格和公式使用目标平台支持的格式；不留下空白图示或占位符。
4. 写入后重新读取标题层级、关键章节和文档 URL，确认内容完整。
5. 报告远程文档地址、本地权威文件、源文件是否保持不变和验证结果。

## 隐私

- 不在远程文档中写入与学习无关的姓名、学号、联系方式、成绩、私密链接或凭据。
- 未经用户明确授权，不把本地课堂图片、录音或手写材料上传到第三方服务。
