# 上课笔记整理

## 概述

把分散、重复、含噪声的课堂材料整理成可复习、可追溯、可继续补充的课程笔记。优先忠实于用户提供的材料；保留定义、例题、条件、数字、任务和不确定信息，禁止用流畅措辞掩盖证据缺口。

## 使用场景

使用本 Skill：

- 整理课堂录音转写、课件、PDF、课堂截图、扫描页、板书、手写笔记或零散文本。
- 对图片或扫描 PDF 做 OCR，对手写内容做分区识别，并与课件或转写交叉核对。
- 合并多种课程材料，修复同音词、重复、缺标点或来源混乱的课堂转写。
- 根据课表、课程大纲、教材范围或下一讲主题生成课前预习卡。
- 把已有课堂笔记重组为复习版，同时保留来源和待核对项。

不要使用本 Skill：

- 会议、访谈或工作讨论的纪要整理。
- 只把音频逐字转写，不需要学习笔记。
- 从零撰写论文、课程报告、演讲稿或完整教材。
- 代答作业、代写实验结果或完成应由用户独立完成的考核。
- 只做通用知识问答，且没有课堂材料或课程笔记目标。

## 模式选择

1. **课后整理**：已有课堂材料时使用。默认模式。
2. **视觉识别**：输入含照片、截图、扫描 PDF、板书或手写笔记时，先生成视觉识别稿，再进入课后整理。
3. **课前预习**：已有课程大纲、教材范围、课表或下一讲主题时使用。
4. **完整学习闭环**：同时要求课前准备、课后整理和复习任务时使用。
5. **笔记修复**：已有结构化笔记但存在缺页、噪声、重复、术语错误或来源混乱时使用。
6. **可选写回**：用户明确要求写入协作文档时使用；仅在对应连接器可用且用户有权限时执行。

若用户没有指定模式，根据输入选择最小可完成模式，不为模式选择额外追问。

## 核心流程

### 1. 接收并保护输入

1. 列出材料、格式、可读状态、课程/日期和可用定位信息。
2. 禁止覆盖、改写或删除原始文件；所有结果必须另存。
3. 省略或匿名化与学习任务无关的姓名、学号、联系方式、签到和成绩。
4. 读取 `references/input-handling.md`，按来源优先级和冲突规则处理材料。
5. 输入含录音转写时，读取 `references/transcript-cleaning.md`。

**门禁：**仅当至少有一份可读取的课程材料，或有明确课程名称与预习范围时，才允许继续。否则停止并说明所需输入。

### 2. 处理图片、扫描件和手写内容

仅当输入含视觉材料时执行本阶段，并必须读取 `references/vision-ocr.md`。

1. 先检查整页方向、裁切、清晰度、页码和页面类型，再分区识别。
2. 区分印刷文字、手写文字、公式、图表、代码、箭头/圈框和装饰内容。
3. 为每页、每图和关键区域分配稳定标签；保留版式关系，不把图示强行线性化。
4. 对公式、化学结构、坐标图、代码缩进、数字和 DDL 做第二次视觉复核。
5. 用 `[已确认]`、`[待核对]`、`[无法辨认]` 标记识别状态；禁止猜写模糊字符。
6. 宿主有本地 OCR 时可先预提取印刷文字，但最终必须回看原图；禁止默认上传到未获授权的第三方 OCR 服务。

**门禁：**必须先生成带页面/区域定位和识别审计的视觉识别稿，才允许把图片内容写入最终笔记。

### 3. 建立来源映射

1. 使用稳定标签：`[课件 p.12]`、`[录音 00:18:42]`、`[截图 2-R3]`、`[手写笔记 3-R1]`、`[用户补充]`、`[外部补充]`、`[推断]`、`[待核对]`。
2. 区分材料原文、用户补充、模型推断和外部资料。
3. 同一事实存在冲突时并列保留，不擅自选择看起来更合理的一项。
4. 核心概念、公式、例题、任务和截止日期必须能够回溯，或显式标为推断/待核对。

### 4. 提取并重组学习信息

1. 提取主题、学习目标、定义、联系、因果、步骤、条件、边界和结论。
2. 保留教师强调、典型例题、反例、例外、易错点、单位、数字和课堂任务。
3. 清理口头语、重复和明显转写噪声，但不得删掉推理、例证或任务信息。
4. 不确定的术语、公式、数据和人名不得凭常识补全。
5. 需要学科定制时读取 `references/subject-adaptations.md`。

**门禁：**完成“概念—证据—例子—任务—疑问”内部清单并检查遗漏后，才允许写最终笔记。

### 5. 生成课前预习卡

仅在课前预习或完整学习闭环模式执行，并必须读取 `references/preclass-preview.md`。

1. 先判定材料充分度：A（有大纲/课件范围）、B（有章节或明确主题）、C（只有课程名/课表）。
2. 区分“课程材料已确认”“外部资料补充”和“根据主题推断”。
3. 生成学习目标、前置知识、概念地图、重点/难点、带着上课的问题和 15 分钟计划。
4. 只在用户允许或任务明确需要时检索外部资料；外部资料必须单独标记并附来源。
5. C 级输入只生成低置信度通用框架，不得声称教师一定会讲某个知识点。

### 6. 生成课后笔记与复习闭环

1. 写作前必须读取 `references/output-contract.md`。
2. 以 UTF-8 Markdown 作为权威内容版本；Word、PDF 或其他格式从 Markdown 派生。
3. 使用学生可直接复习的知识结构，不按录音顺序机械复述。
4. 每个详细小节至少给出一个适用的来源标记；无法定位时明确说明。
5. 对受版权保护的课件或教材以概括为主，仅保留必要短语、公式或术语。
6. 生成 3–8 道主动回忆题，答案要点与问题分开。
7. 给出 10–20 分钟复习清单；只把材料明确指定的内容写入“课堂任务与 DDL”。
8. 当课程超过三个模块或用户要求导图时，在“知识结构”中生成简洁 Mermaid flowchart；长解释留在正文。

若用户明确要求写回飞书/Lark 或其他协作文档，读取 `references/remote-writeback.md`。连接器不可用时交付本地 Markdown，不把远程写回设为完成主任务的前提。

### 7. 验证并交付

1. 读取 `references/quality-rubric.md` 并逐项检查。
2. 按产物类型运行：

   ```bash
   python3 scripts/validate_notes.py --artifact postclass --note /path/to/notes.md --strict
   python3 scripts/validate_notes.py --artifact preclass --note /path/to/preview.md --strict
   python3 scripts/validate_notes.py --artifact visual --note /path/to/ocr.md --strict
   ```

3. 返回 1 时必须修复后重跑；返回 2 表示输入或命令错误，禁止忽略。
4. 修改校验器或测试契约后，运行离线回归测试：

   ```bash
   python3 scripts/test_validate_notes.py
   ```

   该脚本覆盖 postclass、preclass、visual 的正例、缺标题、占位符、来源标记、预习等级和
   视觉审计边界；不处理用户材料。
6. 需要重跑全部 fixture、路由题、隐私面和结构检查时运行：

   ```bash
   python3 tests/run_regression.py
   ```

   该脚本输出 JSON，保存 command、stdout、stderr、return code、assertion、Judge rubric
   和 metrics；退出码 0 才表示本地回归通过。
7. 交付时说明使用材料、视觉识别限制、待核对项、缺失页和验证结果。

**准出条件：**结构完整、来源可追溯、不确定性可见、视觉内容经过复核、任务信息未虚构、复习问题可回答。未满足任一条件时不得声称完成。

## 失败处理

- **音频不可访问或无转写工具**：说明限制并请求转写文本；其他材料可先整理。
- **图片方向错误、严重裁切或分辨率不足**：指出具体页/区域，请求重拍；继续处理可读部分。
- **手写内容无法辨认**：保留区域位置并标 `[无法辨认]`，禁止猜测。
- **复杂公式或图表 OCR 不稳定**：转为视觉逐项复核；仍不确定则标 `[待核对]`。
- **课件与录音冲突**：并列记录两个版本及来源。
- **只有课表或课程名**：只生成 C 级低置信度预习框架。
- **材料过长**：先建立目录和批次计划；每批沿用同一来源标签和术语表。
- **用户要求补造缺失内容或作业结果**：拒绝补造，改列缺口和核对方法。

## 输出形式

- 默认权威文件：结构化 Markdown。
- 中间产物：视觉识别稿、清洗稿、来源映射表。
- 最终产物：课前预习卡、课后课程笔记、复习清单和主动回忆题。
- 可选展示文件：Word、PDF、知识图或抽认卡数据；不得与权威文件冲突。
