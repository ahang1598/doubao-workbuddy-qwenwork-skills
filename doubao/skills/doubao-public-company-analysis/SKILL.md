# 上市公司分析

围绕决策问题研究目标公司：开篇亮明核心判断、决定性依据与最关键未知项，随后展开机制拆解、可复算财务核验与条件化情景推理。

## 分析深度与任务边界

- **快速判断**：直面具体疑问，给出核心定性与关键定量证据，明确前提真伪与主要风险边界。
- **聚焦分析**：针对指定业务、会计、资本运作、市场表现或财务质量问题深挖，厘清对估值与长期逻辑的影响路径。
- **完整研究**：系统剖析商业模式、成本结构、行业位置、盈利与现金流质量、可复算估值及重大下行风险。

交付形态按任务需要、用户要求和宿主可用能力选择，对话回复、本地文件或飞书文档均可；未作指定时可在对话中直接给出完整自包含的研究结论。

**不适用与邻近任务**：多股批量筛选、市场热点事件传导、非上市一级市场项目评估、个人资产配置属于邻近任务；若宿主存在对应的已注册 Skill 可按需转交。无对应承接或与单股问题混合出现时，直接利用本任务框架完成现有条件下可核查的部分，不因边界路由而拒答。本 Skill 不提供交易执行、个性化仓位、止损或收益承诺。

## 核心研究与核算原则

1. **时间截点与最新报告期**：存在 `as_of` 研究截点时，行情、财务、公告与结语均不越过截止时刻；未指定历史截点时，先确认截至当前已披露的最近完整财年和最近一期定期报告。
2. **前提核验与主体边界**：将提问中的经营现状、传闻、估值印象或资本运作说法视为待证命题，回到原始披露核验原值与交易实质（是否涉及股权稀释、资金承接主体及权益或负债属性）。简称或代码有歧义时先澄清，用户未指定目标公司时不自行选择，不用同名或同类公司替代；公司已退市、被收购或更名时核实并说明。没查到不等于公司未披露，约数不写成精确数。用户要求匿名时，同步隐去关联实体、项目等可反向识别信息。
3. **口径对齐与科目边界**：比率与增速的分子分母须期间等长、截点一致、合并范围相同；不混用存量与流量、不同利润层级、单体法人与合并/分部口径、累计口径与当期口径。
4. **现金流桥接与正常化原则**：经营现金流桥接以合并净利润为起点，表内加总与披露值的差额诚实单列为残差；评估分红、回购等股东现金回报覆盖时使用实际现金口径。对比公司自定义指标与常规算式时，先厘清差异来源与方向再定性；构造正常化调整时，核对一次性事项是否已计入当期报表及其现金方向、税前税后口径，保持调整方向与税基一致。
5. **可复算估值与隐含预期**：估值保持从经营假设到现金流再到价值的完整推导与情景自洽，不重复计价或凭空设定单点目标价；多地或多类股份按各自股本、价格及同期汇率分别计算后加总。讨论估值高低时，可由当前市值反推隐含经营预期并指出敏感变量；缺少关键输入时给出条件式关系与待补参数。
6. **商业模式特征匹配**：按收入生成方式、成本习性及资本结构选择核心追踪指标与估值方法（例如区分固定成本杠杆与随用量同步变动的成本、轻资产模式与以资产负债表为核心生产资料的主体）；结合周期位置、业务占比与实质约束判断短期波动或产业链关联强度。银行、保险、券商、REIT、控股与资源类主体不套用普通制造业的毛利率与 DCF 框架，具体口径见商业模式与估值两份参考。
7. **事实分层与纯净表达**：清晰区隔一手披露、外部共识与分析推演，核心论断紧随商业含义与可证伪观察点。正文只面向读者呈现研究内容，不混入后台过程或内部标记。

## 表达、引用与合规边界

重要事实、财务数字、外部共识与公告动态在对应语句处说明可追溯来源，文字方向与数值保持一致；交付形态按任务需要、用户要求和宿主可用能力选择，对话回复、本地文件或飞书文档均可。

**建议边界**：所有结论均为基于公开信息的研究观点，不构成投资建议，不承诺或保证收益，不给出买卖指令、个性化仓位或止损安排。
