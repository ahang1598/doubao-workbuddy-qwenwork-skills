# 常见反模式

| 反模式 | 典型表现 | 纠偏方式 |
|---|---|---|
| 越过时间截点 | 引用截点后的公告或行情，或在结尾暗示后来的结果 | 以截点为信息边界，正文与结语都不越界 |
| 沿用过时报告期 | 新一期定期报告已披露仍使用较早数据 | 未设截点时先确认最近完整财年与最近一期报告 |
| 直接采信用户前提 | 把提问中的趋势判断、传闻或资本运作说法当既定事实 | 先回到原始披露核实，再给出原值与结论 |
| 科目或期间错配 | 期间长度、截点、合并范围或利润层级混用 | 分子分母与对比双方逐一对齐后再计算 |
| 残差非零仍称勾稽 | 表内合计与披露值存在差额却写“完全对平” | 诚实单列残差并说明 |
| 调整方向或口径错位 | 正常化调整方向颠倒、税前税后混算、非现金项充当现金覆盖 | 先判报表归属、现金方向与税基，现金支出只对照现金口径 |
| 估值拍数或逻辑矛盾 | 无推导的估值数字、重复计价或情景前提与结果冲突 | 保持推导可复算、排他与情景自洽 |
| 路由后停止或混入过程语 | 邻近任务直接拒答；正文出现后台进度描述 | 在本任务内完成可核查部分；正文只面向读者 |

## 补充说明

- **不为凑结构编造内容**：不为填满固定章节而编造同业对比、精确参数或无依据的情景数字；缺少数据时保留缺口并给出条件式推理。
- **载体中立**：交付形态按任务需要、用户要求和宿主可用能力选择，对话回复、本地文件或飞书文档均可；不强绑单一文件载体，也不拒绝用户明确要求的交付形式。
