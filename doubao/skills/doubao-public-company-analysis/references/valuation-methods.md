# 估值方法

| 方法 | 适用 | 关键风险 |
|---|---|---|
| DCF | 现金流稳定、预测可解释 | 终值和折现率占比过高 |
| 可比公司 | 存在可比商业模式和口径 | 周期、增长和会计差异 |
| SOTP | 多分部或控股公司 | 分部边界、净债务和折价 |
| NAV/资产价值 | REIT、资源、控股 | 资产时点和流动性 |
| P/B-ROE | 银行、保险等金融机构 | 资本质量和周期信用成本 |
| 概率调整 | 生物科技、里程碑业务 | 成功概率和融资稀释 |

## 时点一致性

给精确估值或倍数前先确认 `valuation_as_of`。价格、汇率、股本、净债务、分母和外部预期需处于合理一致的时点；使用财报期末净债务与当前价格时说明两者时间差，不静默称为同一时点。

只在用户问题和输入支持时输出估值区间、关键假设或敏感性。缺少可靠预测、实时价格、股本或资本结构时，说明方法、关键变量和需要补充的输入；不混用日期生成精确倍数或目标价。
