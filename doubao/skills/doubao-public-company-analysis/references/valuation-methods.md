# 估值方法

| 方法 | 适用 | 关键风险 |
|---|---|---|
| DCF | 现金流稳定、预测可解释 | 终值和折现率占比过高 |
| 可比公司 | 存在可比商业模式和口径 | 周期、增长和会计差异 |
| SOTP | 多分部或控股公司 | 分部边界、净债务和折价 |
| NAV/资产价值 | REIT、资源、控股 | 资产时点和流动性 |
| P/B-ROE | 银行、保险等金融机构 | 资本质量和周期信用成本 |
| 概率调整 | 生物科技、里程碑业务 | 成功概率和融资稀释 |

## 时点一致性

先冻结 `valuation_as_of`。价格、汇率、基本/稀释股本、净债务、估值分母和外部预期逐项记录日期；`full` 只接受同一收盘日或明确属于同一披露批次的输入。财报期末净债务与当前价格组合时，必须说明滚动调整，不能静默称为同一时点。

输出估值区间、关键假设和敏感性。缺少可靠预测、实时价格、股本或资本结构时降为 `degraded`，只给方法、变量关系、具名可比口径和恢复所需输入；不得混用日期生成精确倍数或目标价。
