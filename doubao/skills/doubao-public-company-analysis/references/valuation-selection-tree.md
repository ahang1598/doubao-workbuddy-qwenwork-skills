# 估值方法选择树

先判断业务形态，再选择方法：

1. 稳定经营、可预测现金流：简化 DCF + 可比公司。
2. 多分部且驱动差异明显：SOTP。
3. 银行与保险：P/B-ROE、P/EV 等行业方法。
4. 资产型公司：NAV 或重估资产价值。
5. 亏损或未商业化：收入、用户、产能等阶段指标，只给情景和数据需求。

输入门禁：

- 当前价格、股本、币种和 as-of；
- 历史财务与预测期间；
- 净债务、租赁、少数股东和非经营资产；
- 估值方法所需的业务特异输入。

缺任一关键输入时 `can_value=false`。公司分析可以提供方法、公式和敏感变量，但完整三表工作簿和独立 DCF 模型应路由到专项 Skill。
