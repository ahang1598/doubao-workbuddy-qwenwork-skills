# 线上执行说明

根据当前问题使用宿主提供的搜索或金融数据工具，不假定包内 Python 脚本一定能运行。没有运行的脚本不要声称已执行；脚本不可用不妨碍直接回答有证据支持的问题。

正式财务、公司指引、证券和监管状态优先查看能直接支持主张的披露；标准金融字段可使用口径清楚的可靠数据库。重要数字保留期间、单位、币种和来源。数据库新闻摘要不自动等于公司原文；管理层说法和外部预测分别表达。只查询会影响当前判断的事实，不设固定工具顺序、搜索次数、补查轮数或每条 Claim 的机器状态。

不同期间、公司、分部或指标定义不可静默合并。经营现金流、资本开支、公司调整后 FCF 与估值输入的具体处理见财务和估值文档。某项资料缺失只影响依赖它的判断；已知事实与商业机制仍可交付。

报告先写清判断，再写决定性依据和真正重要的不确定性。内部工具轨迹、证据等级、脚本状态和逐条计算记录不进入主文。完整结构化记录与脚本验证仅在用户要求可复核模型或复杂计算确实需要时使用。
