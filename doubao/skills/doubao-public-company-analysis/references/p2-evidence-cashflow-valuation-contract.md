# 财报、现金流与估值口径

讨论具体报告期的业绩时，查看对应财报及必要附注；“最新”须与分析截止日对应。只有涉及现金流质量或 FCF 时才要求现金流量表，不为回答其他问题强制完成一套年报、季报与现金流清单。

FCF 分析从财报经营现金流和实际现金资本开支出发。净利润到经营现金流的桥用于解释现金转化，不能把经营利润加非现金项目再减资本开支当作法定 FCF。公司调整后 FCF 保留原名和定义；其调整若影响判断，解释主要项目及其现金属性，无法核对的差额保持未知。

精确估值比较需要价格、汇率、股本、净债务和估值分母处于合理一致的时点，历史时点也应统一。缺实时价格或关键预测时可讨论业务质量、估值方法与条件，但不拼出看似精确的实时倍数或单点目标价。

内容或平台业务分析版权成本时，先区分按收入或使用量分成、最低保底和固定投入。不要未经合同或披露支持就把可变版权费写成随规模固定摊薄。
