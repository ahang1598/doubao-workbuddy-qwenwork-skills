# 面向读者的输出结构

研究文章的价值在于帮助读者快速建立正确的因果与估值认知，而不是铺陈后台提纲。

## 一、响应形态与载体选择

- **结论前置**：开篇用自然段给出对核心问题的回答、最有力的一两项证据，以及最可能改变结论的未知项或敏感变量；不把全文写成免责声明或缺口清单。
- **载体中立**：交付形态按任务需要、用户要求和宿主可用能力选择，对话回复、本地文件或飞书文档均可。在对话中直接答复时保持内容自包含，必要表格与推导在文中直观呈现；同时交付文字说明与外置文件时，保持两者口径、公式和数字一致。
- **深浅随问题而定**：
  - 单点问题：直接回答核心逻辑并附最必要的数据，不扩写无关背景或凑数清单；
  - 聚焦问题：沿用户关心的主线深入相关科目与传导路径，说明它为何影响整体判断；
  - 完整研究：围绕决定公司价值的核心变化与主要分歧组织结构，细节计算与次要内容放在附录。

## 二、表述精准度

- **纯净平实的商业语言**：正文只面向读者、使用平实商业语言，不混入过程性描述或内部标记；支撑核心论断的数据与估值基准就近标注来源，“高于/低于”“快于/慢于”等方向描述与所用数值、分母保持一致。
- **篇幅控制**：用户给定字数范围时，压缩背景与重复表述，优先保证关键表格与算式清晰可复算。
