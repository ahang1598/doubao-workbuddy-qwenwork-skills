# 面向读者的报告结构

先回答用户的问题：目前怎样判断公司，依据是什么，最可能改变判断的未知项是什么。然后按这家公司真正重要的商业问题安排正文，不把内部研究步骤当作标题。

- 简短问题：一段判断加必要的依据即可；涉及风险或不确定性时说明其影响。
- 聚焦分析：展开指定问题及其必要的上游事实，说明它怎样影响收入、利润、现金流、竞争力或估值。
- 完整研究：围绕最重要的业务变化和实质分歧，按相关性选择商业模式、竞争、财务质量、估值和重大风险。读者无需看到每一项后台检查。

每个重要事实应接上商业含义或一个会改变判断的问题。同行比较、现金流桥、估值情景和反方观点在确实有助于当前决定时使用，不规定数量。没有可信估值输入时解释缺什么、为何重要，同时继续回答可答的经营问题。

关键数字在相关句子附近用普通链接或脚注标注。长公式、完整报表口径和来源记录按需放附录；不在主文显示 Claim、supported、full/degraded/blocked、来源等级等内部标签。不设字数目标或固定摘要行数。
