# 研究执行边界

确认用户讨论的公司、证券与时间。当前证券状态、最新业绩或管理层指引对结论重要时，以正式披露或口径清楚的数据库核实。资料足够时停止查询，不建立固定数量的证据槽。

按公司类型选择指标：零售可看同店和会员，制造可看产能与订单，平台可看交易、抽成和履约，金融机构可看资本与资产质量。只用本题相关的指标；没有相关资料时说明影响，不逐项填 `blocked`。

区分经营判断、竞争判断和估值判断。缺实时价格或同行不妨碍商业和财务分析；要给精确估值时则需要一致的价格、股本、债务、分母和时点。增速、利润率与倍数在需要复核时记录输入和公式，不在正文贴 calculation id。

交付内容随用户问题变化。同行、财务桥、估值和反方观点可帮助解释判断，但不要求每次全部出现，也不要求固定数量的“证伪信号”。
