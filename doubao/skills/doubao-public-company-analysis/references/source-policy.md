# 公司分析 来源与证据规则

## 来源层级

| 优先级 | 来源 |
|---|---|
| 1 | 交易所/监管披露、定期报告和公司公告 |
| 2 | 公司 IR、业绩会和审计财务 |
| 3 | 字段完整、对象/期间/单位清楚的权威金融数据库 |
| 4 | 用户提供的模型、研究资料和内部笔记 |
| 5 | 行业协会、竞争对手披露和可靠第三方数据 |
| 6 | 市场价格、一致预期和估值数据 |
| 7 | 媒体与网页仅用于背景和交叉验证 |

## 证据类型

| 类型 | 定义 | 正文措辞 |
|---|---|---|
| fact | 一手来源或用户确认事实 | 可直接陈述，并标来源与日期 |
| estimate | 外部预测、模型或派生计算 | “估计/测算/一致预期”，暴露输入 |
| inference | 多项事实支持的分析结论 | “指向/可能意味着”，给证伪条件 |
| assumption | 为继续分析采用的透明假设 | 明确写“假设”并可修改 |
| management_claim | 公司/管理层陈述 | 写“公司表示”，不得当独立事实 |
| data_gap | 缺失、过期、冲突或不可访问 | 说明影响与下一步 |

## 新鲜度

- 价格、估值、预期、事件状态：必须标 as_of。
- 定期报告：标报告期和发布日期。
- 用户材料：标文件名、版本或提供日期。
- 旧资料若仍使用，说明为何仍适用。

## 数字纪律

- 数字必须有期间、单位、币种和来源。
- 派生数字引用输入 claim，并记录 calculation。
- 不同会计口径、财年和币种不能静默混用。
- 无法核验时宁可省略或写 data gap，不从记忆补数。

## 工具降级

可调用私有数据源时优先使用用户授权数据；不可用时转公开一手来源；仍不可用时输出方法、数据需求和局限，不伪造完整结果。

降级按证据槽位和 claim 局部执行。公司 IR、监管或交易所一手材料可访问时，必须先完成最近年报、最新中报/季报、现金流量表及拟引用公司自定义指标的核心槽位；不得因实时价格、同行、外部预期或另一个渠道缺失而把整份研究降级。

## Search 与引用规则

1. 每个问题最多 3 轮搜索；标准化金融字段可先用权威数据库，公司特异事实先找一手来源，再补二手解释。
2. 数字主张必须在同一段落给出来源 URL 或权威数据库provider/reference；文末堆链接不算完成引用。
3. 搜不到一手证据时，不用普通二手文章拼出精确数字；满足字段契约的权威金融数据库标准字段除外。
4. 只有低质量来源时，结论降为“待核验线索”，不得进入估值、排名、概率或行动建议。
5. 澄清题、边界题和负例不为满足“必须搜索”而扩写无关案例。

## 无精确事实时的最低分析

删除无法核验的数值和合同断言，但仍说明业务/成本/现金流机制、具名可比口径或比较阻断、最强反方和可观察证伪。不得用记忆中的实体事实补位。
