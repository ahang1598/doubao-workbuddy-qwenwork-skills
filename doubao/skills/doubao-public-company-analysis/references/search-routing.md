# 查询资料

先确认公司、证券和用户所问的时间。用户资料足够、问题只涉及方法或封闭材料时可直接回答；当前公开事实影响判断且材料不足时查询。优先找对应财报、公告、交易所、监管或公司 IR；标准价格与财务字段可借助可靠金融数据库。工具选择由事实类型决定，不要求固定先后顺序或两个工具都调用。

查询围绕当前结论最重要的事实。找到足够支持判断的资料就停止，不设固定调用次数、原子查询格式或补查轮数。来源冲突时保留差异；暂时查不到时只降低受影响的判断，不用记忆补数，也不把空结果写成公司未披露。

用户资料中的私有信息不能靠搜索到的同名公司、外部估计或相邻业务代替。完整查询日志只在需要审计或复核时制作，不进入报告主文。
