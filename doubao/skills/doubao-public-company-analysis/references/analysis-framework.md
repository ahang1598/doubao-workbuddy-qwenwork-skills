# 公司分析 分析框架

## 核心分析

- 商业模式：客户、产品、收费、成本、资本与增长约束。
- 行业位置：市场边界、竞争结构、议价能力、替代和份额证据。
- 财务质量：增长、利润、现金流、资本效率和资产负债表是否一致；重大扩产、研发、并购或股东回报是否改善长期收益。
- 估值：方法适配、假设、敏感性和结果区间。
- 观点：决定性变化、不同解释、可能的商业后果，以及会改变判断的关键事实。

## 从变化到判断

投资逻辑不能只是业绩、公告或产品发布的摘要。抓住当前问题最重要的变化，解释需求、供给、客户、价格或成本为什么变，公司能获得多少收益，以及收益可能体现在哪项财务指标上。若讨论投资价值，再问这些变化是否已反映在市场预期中；没有可靠的预期依据，就只讨论经营含义。

分析竞争优势时，区分长期结构性优势与阶段性机会。说明相对哪个对手更强，优势怎样转化为价格、单位成本、客户留存或现金流；证据只支持阶段性领先时，不写成持久护城河。

## 解释深度

1. 定位：发生了什么、哪个指标或条件变化。
2. 归因：什么业务活动、市场变量或事件驱动。
3. 约束：为什么主体不能轻易消解，或为什么机会可能持续。
4. 前瞻：结构性还是暂时性，什么信号会验证或证伪。

核心论点解释清楚原因及商业后果；证据不足时降低结论强度。分析层级用于思考，不作为主文固定栏目。

## 竞争性假设

关键现象有合理的其他解释时，说明双方依据及最值得核实的区别；不为凑数量罗列反方。调研问题应具体到能改变判断的变量，例如新增订单的交付与毛利，而不是泛泛写“关注订单”。无法区分时不把其中一种解释写成确定结论。

## 判断强度

让读者分得清已披露事实、公司说法、外部预测、分析推断和情景假设即可，不在正文输出内部证据等级。

## 信息增量

成稿前回答：读者相比原始材料多知道了什么？如果只有数字复述、格式整理或常识，退回分析计划。
