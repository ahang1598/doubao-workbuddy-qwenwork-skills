# 分析框架

## 一、核心推演路径：定位—归因—约束—前瞻

个股研究围绕“变化如何最终影响现金流与市场定价”展开，避免退化为公告流水账：

1. **事实定位**：明确发生实质变化的经营、财务或市场维度，找出核心矛盾。
2. **经济归因**：拆分变化来自外部周期与价格因素，还是来自产品、渠道、份额等公司自身因素；尽量量化价、量、成本、费用各自的贡献。
3. **优势与约束**：检验优势是否可持续、竞争对手跟进门槛多高。证据只支持阶段性领先时，不写成长期壁垒。
4. **前瞻与可证伪**：说明当前逻辑成立的条件，并给出未来报告期内可通过公开数据验证或推翻的观察点。

## 二、常见延展问题的处理方式

### 1. 题材或产业链关联核验

评估公司与某题材或下游需求的关联强度时：
- 以公司正式披露的相关业务收入占比及实际商业化进度判断实质贡献；
- 评估产品在下游环节的价值量、技术门槛与可替代程度；
- 核实市场预期依赖的前提是否已经兑现，判断关联溢价的支撑边界。

### 2. 短期市场表现问题

在不给出交易指令的前提下分析短期走势时：
- 结合较长周期的价格位置、成交变化、同期业绩或公告反应以及股本供给变化交叉判断；
- 给出上行与下行两侧的确认条件，并对照估值与基本面支撑程度。

### 3. 邻近任务的降级承接

请求偏向主题筛选、事件传导或未商业化业务时：若宿主存在已注册的对应 Skill 则转交；无承接或问题混合时，在本任务内采用“明确口径 + 逐项核验 + 说明偏差”的方式交付可核查结果，不因路由而停止。

## 三、竞争性假设与观察信号

多空存在实质分歧时，并列提炼双方最强的论据，指出分歧落在哪些具体假设或参数上。跟踪信号应指向具体科目或经营指标、方向阈值与对应的披露窗口，避免空泛表述。
