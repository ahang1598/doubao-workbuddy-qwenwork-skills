# Trigger Boundaries

## Should Trigger
- 下周要讲一篇论文，帮我做 12 分钟课程汇报 PPT 大纲和讲稿。
- 我们小组调研大学生消费，帮我整理成汇报结构。
- 这些课堂笔记很散，帮我变成 8 页展示。
- 用户要求交付：PPT 大纲、逐页文案、演讲稿、答辩问题
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我做一张社团招新海报。
- 帮我查实习岗位。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 只有标题没有材料。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
