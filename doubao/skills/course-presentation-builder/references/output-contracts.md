# Output Contracts

## Required Artifact Fields
- PPT 结构
- 逐页标题与正文
- 演讲稿
- 答辩问题
- 素材缺口清单
- 初稿诊断（用户提供初稿时）
- 实际 PPT/飞书幻灯片或可导入页表（用户要可展示成品时）

## Minimum Quality Bar
- The result must match the user's context and audience.
- The result must include concrete wording, table rows, schedule, or checklist items when applicable.
- The result must not be only a framework unless the user explicitly asks for a framework.
- The result must label unknown facts and assumptions.
- Each slide row must include module, time allocation, visual suggestion, and where hard requirements are satisfied.
- Comparison matrices must expand to the scenario: literature reviews may need research question, method, sample, variables, evidence strength, inference boundary, limitation, and future research dimensions.

## Final Review Checklist
- Trigger matched: yes/no.
- Required inputs complete or visibly marked.
- Deliverables present.
- Tone fits the audience.
- No fabricated fact.
- No unsafe or non-compliant instruction.
- User can take a next action immediately.
- If an actual PPT was requested, either generated it or provided an explicit handoff table ready for slide creation.
- If a draft was provided, diagnosed its main problems before rewriting.
