# 图片创作工作流

> 定位：图片从方案的策略、核心信息与传播内容里长出来，服务于表达而非装饰。本文件只负责图片的创意与素材方法论。

## 一、交付基线（硬性）

1. 视觉统一：整组图片统一比例、色调、字体气质、版式语言，像同一套物料；同组图共享一张轻量视觉卡：主色/点缀色、字体气质、背景质感、构图网格、关键词高亮方式、去 AI 味要求。
2. 尺寸：竖版基准 1080×1440px（3:4，产品定位图、竖版海报、社媒竖图）；横版基准 1920×1080px（16:9，banner、横版海报、汇报封面）；明确涉及具体社媒平台时遵循该平台图片规范，覆盖默认基准。尺寸、比例、分辨率只作生成工具参数，不写进画面文案。

## 二、图片配置判断标准

### （一）必须配图的场景

核心判断标准：建立视觉调性+承接真实观感。凡需要让读者一眼建立认知、降低理解成本，或需呈现产品/品牌/场景真实观感的内容，须配图。典型场景：

1. 产品定位：可视化产品在用户心中的定位、卖点或产品矩阵。
2. 传播主画面/封面首图：需要一个主视觉统领整场传播，或文档出现「封面与首图建议」时，必须提供实际主视觉参考图。
3. 活动预热节奏：活动战役需要制造倒计时期待时，用系列倒计时视觉承接传播节奏。
4. 场景化种草/氛围传播：需呈现真实使用场景、人物或情绪时，用场景图、KV 延展或氛围海报承接。
5. 产品证据页：当产品优势需要靠外观、质地、包装、材质、套装关系、前后对比或细节特写建立可信度时，必须配图。

## 三、输入基准

出图前先对齐五类输入，避免图片脱离方案乱长：

1. 用户指令：主题、品类、品牌/产品、目标人群、指定风格、指定数量、是否真人出镜、指定平台。
2. 方案标题/主标题：提炼封面主钩子；封面文案可比总标题更短，但承诺必须一致。
3. 策略与核心信息：图片主画面承接方案核心信息与定位，视觉承诺必须与方案主张一致。   
4. 传播内容：从渠道/内容策划里拆出配图分镜，每张图只承接一个要点。
5. 事实素材：产品参数、价格、品牌视觉、官方素材、截图证据、官方/电商产品图。可核验信息先核实，图片不得凭空造证据；涉及真实品牌与真实产品时，先锁定产品名、系列、SKU、瓶身/包装形态、logo 位置、颜色材质、容量规格，再进入视觉创作。

信息缺口处理：只有当缺口会直接影响真实性、产品识别或交付安全时再追问；其余默认按照同品类高质量视觉与方案场景合理补齐。

## 四、商业/非商业判断

1. 商业图（有明确品牌、产品、门店、服务）：服从品牌真实视觉体系。先检索品牌官方视觉（主色辅色、标准字体、logo 规范、包装、官方海报版式）和真实产品图；logo、品牌名、产品名、型号、卖点、价格、门店名、地址等**关键信息零容错**；产品外观、瓶身/包装形态、logo 位置、套装组合、门店实景必须使用真实素材或官方/授权电商商品图，不用 AI 捏造证据图；字体与版式随品牌走。
2. 非商业图（理念传达、情绪表达、氛围营造、无品牌诉求）：从内容角色定调，提炼情绪、信息密度与视觉钩子；仍优先检索同品类高质量视觉对标，避免一眼 AI。

### 品牌真实产品图检索与净化（强制）

涉及真实品牌或用户明确给出品牌/产品时，按以下顺序找图和验图：

1. 官方优先：品牌官网、官方商城、官方社媒、官方新闻稿 / Lookbook、品牌天猫 / 京东 / 抖音 / 小红书店铺等官方账号素材优先。
2. 电商补充：官方素材不足时，检索天猫、京东、抖音电商、小红书店铺、得物、丝芙兰 / Sephora、品牌授权经销商等电商平台，获取商品主图、详情页产品图、套装图。只取产品本体、包装、材质和组合关系，不采纳促销贴片、价格角标、满减券、销量话术、平台水印。
3. 产品验真：落图前核对品牌 logo、产品名称、瓶身/盒型/颜色、系列组合、容量规格、男女款或品类属性；任一项不符即弃用，不得用相似产品替代真实产品。
4. 净化处理：电商图如含促销信息、价格、优惠券、直播贴片、平台角标、用户头像、二维码、销量标签，先裁切/重排/去除后再入方案；无法净化则不用。
5. 方法边界：本节只处理真实产品图与素材真实性，不把素材联网混同为热点借势。

## 五、分镜清单与整组视觉系统

### （一）分镜清单格式

先把整组图写成统一分镜清单：

`序号 → 图片任务 → 主文案/主体 → 素材来源 → 设计方法`

示例理解：
- 1 → 封面主视觉 → 主标题/主产品/主人物 → 官方 KV/电商产品图/实拍素材 → 广告拼贴型
- 2 → 产品定位图 → 一句话卖点/产品主图/包装特写 → 官方产品图 → 产品质感型   
- 3 → 传播场景图 → 使用场景/情绪主角 → 实拍参考/AI 场景延展 → 场景实拍型

### （二）整组视觉系统

1. 先定整组，再做单张：先明确每张图承担的任务，再做单张执行，避免封面和内页彼此割裂。
2. 先封面定调：主视觉决定整组点击气质。先定封面/主视觉，再决定产品证据页、场景页、结构页用什么方法承接。
3. 建立统一视觉卡：至少明确主色/点缀色、背景质感、构图网格、字体气质、关键词强调方式、去 AI 味要求。  
4. 主次关系清楚：同组图只允许一个主气质，不要一张广告拼贴、一张极简观点卡、一张手绘便签、一张赛博科幻同时出现。

## 六、视觉基准：七维拆解、质检底线与设计原子

### （一）七维拆解

对标图与生成图都用七维拆：

1. 主题文案：主标题醒目、辅文简洁、层级清楚，一眼抓住核心钩子。
2. 视觉主体：核心图（产品/人物/场景）占绝对重心，与文案讲同一件事。
3. 色彩搭配：固定一套主色/点缀色，有主次，不乱用高饱和。
4. 排版布局：留白合理、阅读路径顺畅、焦点明确。
5. 字体规范：字体服务内容气质，标题与主体关系紧密，字数少、力度集中。
6. 辅助元素：logo、边框、贴纸、手写注解、图标只作点缀，不抢主角。
7. 关键信息：时间、地点、人群、产品名、系列、卖点等信息完整、准确、可读。

### （二）视觉质检底线

- 文字层级清楚：标题/副标题/信息点一眼可分。
- 字体服务内容气质：快消可更活泼，年轻化可更轻快，高奢/严肃场景需更克制。
- 只强调少数关键词：不能每句话都高亮，避免平均用力。
- 色彩有主次：主色、辅助色、点缀色关系明确，不做彩虹盘。
- 真实信息用真实载体：真实品牌、产品、价格、SKU、店铺信息不用 AI 伪造。
- 画面干净高清：无脏边、无锯齿、无乱码、无水印、无假 UI、无低清拉伸。

### （三）设计原子

按传播目的组合 1–2 个原子形成画面方法：

- 利益结果原子：把用户能得到的好处视觉化。
- 痛点反差原子：把前后变化、旧问题与新解决方案做成反差。
- 产品证据原子：用包装、材质、细节、组合、对比建立可信度。
- 场景代入原子：让目标人群一眼看到自己。
- 节点符号原子：节日、季节、城市、倒计时等符号变成记忆锚点。
- 品牌资产原子：品牌色、口号、核心图形、版式语言形成连续识别度。

## 七、主视觉创意方法论

### （一）0.3 秒法则

封面 / 主视觉只争取 0.3 秒注意力：远看先被截停，近看再愿意读字。先解决“停不停”，再解决“点不点、信不信”。

### （二）封面/主视觉八项原则

1. 尺寸合规：先确认横竖版比例和平台文档展示场景。
2. 视觉抓眼：远看先看到主体或大字，不能一眼糊成背景。
3. 信息极简：封面只讲一个核心钩子，不把全部卖点塞上去。
4. 构图聚焦：主角只有一个，次要元素服务主角，不抢戏。
5. 图文同源：封面文案与正文标题、方案主张一致，不另起炉灶。
6. 证据真实：真实品牌、真实产品、真实价格与真实场景必须可核验。
7. 风格成组：封面决定整组气质，内页围绕封面延展，而不是各画各的。
8. 品牌适配：高奢、快消、功能型产品、年轻化品牌的视觉语气不能混用。

### （三）四步创意推导

1. 定传播命题：把方案核心信息压成一句可被转述的话——谁在什么场景下，因为哪个利益点而行动。
2. 找视觉钩子：从产品差异、用户痛点、情绪反差、场景冲突、节点符号、利益结果中只选一个最强钩子。
3. 转成画面关系：把钩子翻译成主体/动作/对比/结果/证据的画面关系。
4. 选表现手法：最后再选封面类型与具体版式方法，不反过来让风格决定创意。

### （四）封面/主视觉文案写法

- 主标题只讲一个核心钩子：不要一张图塞多个信息中心。
- 主标题尽量 ≤14 字：越短越有截停力。
- 与正文标题呼应：可以更口语、更画面化，但承诺必须一致。
- 优先选择用户能立刻感知的钩子：利益、痛点、结果、身份、节点、反差、情绪。
- 零容错信息少放封面：价格、参数、成分、SKU 等如无真实载体支撑，优先放内页证据图或后期排字页。

### （五）14 种高频封面/主视觉类型

按传播命题选一种主类型，不要同时堆多个类型：

1. 真实人大字截停型：人物表情/姿态+大字钩子，适合 ToC、年轻化传播、达人视角。
2. 纯文字大字报型：靠大字结论与强观点截停，适合观点型主张、节点营销、快闪海报。
3. 纸卡便签型：便签、纸卡、手写批注形成亲近感，适合轻咨询、种草、清单感表达。
4. 极简观点卡型：少字、留白、强观点，适合高认知表达、品牌主张、单点结论。
5. 插画情绪型：插画氛围、拟人元素、场景感受，适合节日、情绪价值、年轻化品牌。
6. 广告拼贴型：实物大图 + 品牌色块 + 卖点标签，适合主视觉、新品促销、功能传播。
7. 图表结构化型：清单、矩阵、对比、步骤感强，适合机制解释、产品矩阵、结构化信息页。
8. 产品质感型：产品在干净材质背景上有序陈列，靠光影、材质与工艺感取胜。
9. 证据对比型：前后对比、成分/功效/质地证据，适合功能型产品与产品优势页。
10. 场景实拍型：真实生活场景、人物代入和使用时刻，适合种草、氛围传播、生活方式表达。
11. 节点倒计时型：倒计时数字 + 单一信息，适合活动预热与节点节奏页。
12. 套装/矩阵拼贴型：多产品/多 SKU组合展示，适合礼盒、产品矩阵、组合装推荐。
13. 窑图/证据载体型：引用真实界面、证书、评论、榜单、报道等证据，适合建立可信度。
14. 海报大片型：视觉大片、光影强、品牌感重，适合高势能发布、品牌传播、重要节点主视觉。

## 八、画面风格方法、去 AI 味与 Prompt 转换

### （一）去 AI 味具体方法

1. 真实图片摄影感：要求自然光影、真实景深、材质反射合理、镜头语言统一，避免塑料感磨皮和悬浮无影。
2. 实拍质感要求：保留真实表面纹理、纸张褶皱、桌面痕迹、轻微环境变化，让画面像真实拍摄而不是全新 CG。
3. 手绘注解层叠加：在不破坏品牌调性的前提下，可叠加少量手写箭头、圈注、便签、框线，增强“被人处理过”的真实感。
4. 不要把所有元素做满：允许留白、允许背景不完全对称、允许次级元素弱一点，避免 AI 的平均用力。
5. 真实信息优先真载体：真实品牌产品、证书、榜单、参数、评论截图，用真实载体，不让 AI 重画。

### （二）九要素填槽框架

把图片任务转成 prompt 时，依次填九项：

1. 主视觉标题：这张图最重要的一句标题。
2. 次级说明：补充信息或副标题，没有可留空。
3. 行动引导：需要用户采取什么动作，或本页要强化什么认知。
4. 品牌标识：品牌名、logo、口号、系列名、关键视觉资产。
5. 视觉载体：人物、产品、场景、截图、插画、纸卡、便签、大片等。
6. 色彩系统：主色、点缀色、背景色、色彩气质。
7. 版式构图：大字居中、左文右图、拼贴、留白、矩阵、对比等。
8. 字体规范：粗体 / 细体、现代 / 手写、克制 / 活泼。
9. 细节辅助：箭头、贴纸、纸张质感、光斑、阴影、边框、图标等。

### （三）Prompt 生成顺序

先写传播命题，再写画面关系，再补九要素；不要上来就堆风格词。优先写清：

`图片任务 → 主标题 → 主体 → 真实素材约束 → 画面方法 → 色彩 → 构图 → 字体 → 细节辅助 → 去 AI 味要求`

### （四）常用 Prompt 模板（按主视觉类型套填）

#### 1. 广告拼贴 / 产品质感型

`以<产品/系列>为主体，突出<核心卖点/利益点>，使用<品牌主色>与<点缀色>，画面为<产品特写/包装陈列/材质细节>，构图采用<居中大图/左文右图/对角构图>，标题为“<主标题>”，整体风格高级、干净、真实，有商业海报质感，保留真实 logo 与包装结构，避免 AI 改形。`

#### 2. 真人大字 / 场景实拍型

`以<目标人物/使用场景>为主体，传达<情绪/身份/痛点反差>，标题为“<主标题>”，保留自然光影与真实生活痕迹，人物表情和动作服务<传播命题>，配色遵循<品牌调性>，画面有真实摄影感，避免磨皮、塑料皮肤和假笑。`

#### 3. 极简观点卡 / 纯文字大字报型

`以“<主标题>”为唯一核心信息，版式极简，留白充足，主色为<颜色>，次级说明极少或不出现，字体服务内容气质，突出一个关键词，不使用多余装饰，不把多个卖点塞进同一张图。`

#### 4. 结构化 / 矩阵信息型

`围绕<一个结构化主题>，用<清单/对比/步骤/矩阵>方式组织画面，标题为“<主标题>”，信息层级清楚，主次分明，色彩克制，适合解释<产品矩阵/护理步骤/功能对比/机制说明>。`

#### 5. 节点倒计时型

`以<节点/活动/发售日>为核心，突出倒计时数字与一个单一信息，使用<品牌主色>，版式统一、强识别、适合系列延展，每一张只改变数字与当日重点，不重复堆砌其他信息。`

#### 6. 套装 / 矩阵拼贴型

`以<套装/组合产品>为主体，明确展示每个产品的真实外观、包装与组合关系，标题为“<主标题>”，画面采用<拼贴/矩阵/组合陈列>方式，适合礼盒、系列推荐、组合装说明，避免把不同 SKU 生成成同一外形。`

## 九、图片创意与素材自检

输出前按四类质检统一过关，再交由文档写入规范落位：

1. 创意质量：由本文件负责，检查传播命题、视觉钩子、画面关系、风格统一、图文同源和组图延展性。
2. 产品真实性：由本文件负责，检查品牌 logo、产品名、系列、SKU、瓶身/包装形态、颜色材质、容量规格与官方 / 授权电商产品图一致。

逐张检查创意与素材质量：

- 数量与成组性：整套必须成双数（4、6、8 张），至少 4 张；主题、比例、色调和视觉语言成组统一。
- 真实产品一致性：涉及真实品牌时，产品形态、logo、包装、系列组合、容量规格与官方 / 授权电商产品图一致；不得出现错 logo、错瓶型、错品类、泛化替代品或 AI 编造套装。
