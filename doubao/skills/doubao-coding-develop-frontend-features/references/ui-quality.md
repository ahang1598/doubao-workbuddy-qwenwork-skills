# 界面质量

## 有视觉依据

1. 在与依据一致的数据、权限、状态和尺寸下运行目标界面。
2. 直接比较实现与依据，先处理内容顺序、结构和任务完成，再处理排版、间距、颜色、素材和控件状态。
3. 每轮回到相同条件复验；依据未覆盖的状态沿用相邻产品行为，不臆造新能力。

## 没有视觉依据

1. 从足以确认稳定模式的相邻界面提取组件、颜色角色、字体层级和间距尺度。
2. 根据内容对象、主要用户和核心任务建立信息层级，再用真实文案与数据完成画面。
3. 不引入缺少需求或现有产品语言依据的容器、装饰和交互。

## 跨状态与输入验证

- 在需求涉及的尺寸、内容极值、系统字号和输入方式下检查阅读顺序、滚动、溢出与操作可达性；空间不足时按任务优先级重组，而非等比缩小。
- 为控件提供真实语义、可理解名称和非颜色信息；保持合理键盘顺序、可见焦点和浮层关闭后的焦点恢复。
- 触控操作不得依赖悬停或精确点选；自定义手势应有可发现的等价操作。
- 只用动效解释状态、空间关系或反馈；快速重复、取消和上下文切换不得锁住操作或掩盖最终状态，并验证项目已有的 reduced-motion 路径。
