# 场景差异模块与条款槽位

模块只补充下列统一槽位，不能单独生成完整合同或重复主机制。

| 模块 | 触发 | 贡献槽位 | 关键点 |
|---|---|---|---|
| 运维 | 驻场、支持、故障处理 | 履行、验收、终止 | 人员、响应恢复、报告、交接 |
| 数据处理 | 处理个人/业务数据 | 数据合规、终止 | 指令、最小权限、审计、事件、删除 |
| AI模型 | 模型训练、推理、私有部署 | 范围、IP、数据、责任 | 训练限制、模型成果、评估、输出责任 |
| 开源软件 | 使用开源组件 | IP、合规、交付 | 清单、许可证、传染性风险 |
| 内容/KOL | 艺人、主播、内容制作 | 范围、IP、违约 | 授权链、审核、劣迹、下架 |
| 施工现场 | 现场施工或改造 | 履行、质量、责任 | 安全、设施保护、第三方损害 |
| 楼层/屋面/空中花园施工 | 二楼、屋顶、屋面、露台、空中花园 | 履行、质量、责任、验收 | 承重核验、堆载限制、防水排水测试、渗漏修复、临边防坠、消防及运输路线 |
| 苗木养护 | 园林绿化 | 验收、质量、终止 | 苗木质量、养护、更换、代履行 |
| 竞业/排他 | 竞争对手或排他要求 | 范围、违约、终止 | 名单、实质相同、隔离、例外 |
| 论文发表 | 高校/科研合作 | IP、保密 | 审阅、专利、商业秘密、延迟公开 |
