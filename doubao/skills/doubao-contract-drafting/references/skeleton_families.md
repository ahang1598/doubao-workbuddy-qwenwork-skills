# 主骨架族

骨架只确定主交易逻辑和条款槽位，不提供固定金额或具体交易事实。付款比例、相对期限、验收期、质保/维护期等可控参数按 `default-commercial-parameters.md` 预填。所有骨架均由以下槽位组成：主体背景、交易范围、履行与验收、费用结算、权利/数据/保密合规、违约终止、争议签署。

| 骨架族 | 主交易逻辑 | 必须重点处理 |
|---|---|---|
| 货物买卖/采购 | 交付货物 | 规格数量、运输、风险转移、质保、售后 |
| 服务采购 | 采购服务成果 | 服务边界、人员、分包、成果、验收 |
| 营销推广 | 投放/效果服务 | 商业模式、KPI、归因、反作弊、素材审核 |
| 工程施工与空间改造 | 施工/装修/绿化 | 现场安全、材料、变更、质量、返修、代履行 |
| 软件许可/SaaS采购 | 授权和云服务 | 授权边界、开通、SLA、数据导出、停服 |
| 委托开发/技术服务 | 开发并交付成果 | 需求、里程碑、源码、变更、验收、技术失败 |
| 合作开发/联合研发 | 共同投入和成果 | 投入、阶段成果、成果分类、发表、退出 |
| 知识产权许可 | 许可既有权利 | 权属、范围、独占、既有许可、提成 |
| 知识产权转让 | 转移既有权利 | 权利负担、过户、失败退款、回授 |
| 租赁 | 占有使用标的 | 权属、交付、租金、维修、返还 |
| 数据处理/数据共享 | 数据处理或传输 | 角色、目的、再委托、出境、删除 |
| 保密协议 | 独立保密安排 | 用途、例外、返还销毁、禁令救济 |

复合交易选择最能决定价款、验收、权属和终止后处理的骨架族；其他法律关系以模块贡献条款，不得拼接第二份完整骨架。未收录或混合场景使用 `skeleton_00_generic.md`。
