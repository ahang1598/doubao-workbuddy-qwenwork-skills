# 通用兜底骨架

仅用于未收录、新型或无法可靠归入既有主骨架族的交易。不得因场景未收录而拒绝起草；也不得为了方便将其硬套入不匹配的专用骨架。

## 使用步骤

1. 先用“交易目的、对价方式、主要履行行为、交付/验收、权属、终止后处理、监管角色”识别主法律关系。
2. 形成临时风险标签：标的与范围、履行与验收、费用与结算、权利/数据/合规、责任/解除/终止后安排。必要时从风险地图借用相近场景的风险点。
3. 按以下结构起草，并只展开本案需要的部分：

```text
主体、背景与定义
交易范围、边界与前提条件
履行、交付、验收、变更与记录
费用、付款、对账、审计与结算
知识产权、数据、保密、合规及第三方权利
双方权利义务、风险承担与保险（按需）
违约、暂停、解除、终止后交接与存续义务
通知、争议解决、附件与签署
```

4. 对未提供的交易事实保留可填写空白；按起草方标准政策填入可默认的风险分配。
5. 在交付说明中标明“未预置场景，已按临时风险标签起草”，并列出建议补充的信息。

## 兜底禁令

- 不得假设不存在监管、审批、资质、数据、知识产权或第三方权利风险。
- 不得把待核查事项写为已完成。
- 不得出现第二套付款、验收、知识产权、解除或签署机制。
