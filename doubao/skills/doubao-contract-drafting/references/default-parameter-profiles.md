# 默认参数覆盖项

本文件规定单项合同必须记录并写入正文的参数。用户或附件已经明确的，标记为 `confirmed`；未明确的，按 `default-commercial-parameters.md` 标记为 `standard_parameter`。`parameter_profile.required` 不得删减；交易确实不适用的项目仅可移入 `parameter_profile.not_applicable`，逐项说明理由并在交付说明中列示。

## 全部单项合同

- 争议解决
- 验收期及书面验收规则（不适用验收的合同除外）
- 逾期履行违约金
- 普通责任上限及其例外
- 合同期限

## 按主骨架族追加

| 主骨架族 | 必填覆盖项 |
|---|---|
| 货物买卖/采购 | 交付期、付款节点、付款期限、质保/维护期 |
| 服务采购、营销推广 | 履行/启动期、付款节点、付款期限、质保/维护期 |
| 工程施工与空间改造 | 工期或相对竣工期、付款节点、付款期限、质保/养护期、工程质量与安全责任例外 |
| 软件许可/SaaS采购 | 开通/交付期、付款节点、付款期限、服务期、SLA/支持响应（有服务等级时） |
| 委托开发/技术服务 | 交付期、付款节点、付款期限、验收期、质保/维护期、逾期履行违约金 |
| 知识产权许可/转让 | 交付期、付款节点、付款期限、权利保证期限 |
| 租赁 | 交付期、租期、付款周期、保证金处理（约定保证金时） |
| 数据处理/数据共享 | 配置/启动期、服务期、事件通知时限（有数据安全风险时） |
| 合作开发/联合研发 | 项目计划期、验收期、合同期限；经费及成果比例仅在有明确事实时写入 |

## 角色例外

起草方为收款方、供应方或服务方时，付款节点、付款期限、暂停履行和解除权应改按起草方收款立场预填；不得沿用“起草方为付款方”的付款比例。其他覆盖项仍应完整记录。
