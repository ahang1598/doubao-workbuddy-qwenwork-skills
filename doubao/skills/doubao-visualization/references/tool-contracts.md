# 工具契约与能力检查

## 原则

本 Skill 只使用当前环境明确提供的事实核验、原图读取、ECharts 和 renderer 能力。调用前查看工具与参数，只提交明确支持的字段。

## 搜索与事实核验

当任务涉及可能变化的信息、真实数据、年份、人物、事件顺序或专业细节时，使用当前可用的官方搜索、链接访问或数据工具核验。

- 搜索查询聚焦当前图所需事实，避免把整篇搜索结果塞进图中。
- 无法获得可靠结果时，不绘制伪造的真实图表、时间线、关系或架构；提供模板、空态、取数方案或结构化文字。

## 图片搜索与原图

图片搜索只用于用户明确需要真实素材或核验实体外形的场景，不用于寻找抽象概念图冒充权威机制图。

- 用户原图是证据时，保持其像素内容、对象位置和比例。
- 只有 renderer 能访问本题原图真实 URL 时才输出叠加层。
- 根据原图观察自绘结构时，只使用直接可见特征，并明确标注“示意”。

## ECharts

普通精确数据图使用原生 `echarts` option，不套 HTML。只有自定义交互确实需要 DOM 或多视图联动时，才在 renderer 中嵌入图表库。

## renderer

HTML renderer 是回复内嵌展示能力，不是附件生成工具。若当前端不支持 renderer，按以下顺序降级：

1. 交互 HTML/SVG 改为静态 HTML/SVG。
2. 外部库改为纯 HTML/SVG/Canvas。
3. renderer 整体不可用时改为结构化文字或原图说明。

## 失败处理

- 工具不存在或无权限：说明限制，不猜测私有 API、不绕过鉴权。
- 外部库失败：显示静态替代或可读提示。
- 原图 URL 不可访问：不输出空白叠加层。
- 数据或事实不足：不通过视觉形式伪装确定性。
