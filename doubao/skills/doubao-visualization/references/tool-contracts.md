# 工具契约与能力检查

## 原则

本 Skill 描述能力，不假设每个运行环境都暴露相同工具名或 schema。调用前查看当前可用工具与参数，只提交明确支持的字段。

## 搜索与事实核验

当任务涉及可能变化的信息、真实数据、年份、人物、事件顺序或专业细节时，使用当前可用的官方搜索、链接访问或数据工具核验。

- 搜索查询聚焦当前图所需事实，避免把整篇搜索结果塞进 Prompt。
- 无法获得可靠结果时，不生成伪造真实图表；提供模板、空态或取数方案。

## 图片搜索

只用于真实实体的外形参考或用户明确需要真实图片的场景。不要搜索抽象概念图来冒充权威机制图。

- 用于校准生成时，只提炼可观察特征。
- 是否能将搜索图直接作为参考输入，取决于图片生成工具 schema 和素材授权。

## 图片生成

调用前确认：

- 是否支持单图或批量请求；
- 是否支持每图独立宽高；
- 是否支持参考图输入；
- 当前模型版本字段和可用值；
- 返回结果是否可供视觉复查。

不得因为旧文档曾支持某字段，就向当前 schema 强行提交未知参数。若业务环境明确提供额外兼容参数，应以当前工具验证结果为准。

## renderer

HTML renderer 是回复内嵌展示能力，不是附件生成工具。若当前端不支持 renderer，应降级为文字、原图说明或其他已支持形式。

## 失败处理

- 工具不存在或无权限：说明限制，不猜测私有 API、不绕过鉴权。
- 部分图片失败：只重试失败项。
- 外部库失败：显示静态替代或可读提示。
- 原图 URL 不可访问：不输出空白叠加层。
