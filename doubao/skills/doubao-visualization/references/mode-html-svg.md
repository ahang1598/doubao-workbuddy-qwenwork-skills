## 适用范围

用于确定性表达：

- 流程、机制、因果和反馈回路。
- 系统架构、层级、组件关系和数据流。
- 人物、组织、角色和知识关系。
- 时间线、阶段演进、生命周期和状态机。
- 对比、选型、分类和层级。
- 算法步骤、证明过程、参数变化、物理过程和动态几何。
- 基于用户原图的点击讲解、逐步高亮或部件切换。

不用于海报、头像、壁纸、写实图片或艺术插画创作。结构无法可靠确定时回退文字。

## 静态与交互选择

### `static`：默认

以下内容优先静态 HTML/SVG：

- 阅读方向固定的流程和时间线。
- 节点与连线可一次呈现的关系和架构。
- 不需要改变参数的机制、因果和比较。
- 初始画面即可完整理解的状态结构。

### `interactive`：必须有理解增益

只有以下情况选择交互：

- 点击节点会显示不同但必要的说明。
- 拖动参数会改变曲线、轨迹、几何或状态。
- 播放步骤能揭示算法、证明或物理过程。
- 切换视图能帮助比较不同模型或状态。
- 原图上的点击、逐步高亮或联动能定位证据。

如果交互只是展开静态文字、装饰动画或 hover 高亮，改用静态。

## 常用信息图形态

| 内容 | 推荐形态 |
| --- | --- |
| 流程、pipeline | 带方向的步骤流、泳道、阶段门 |
| 因果、机制 | 因果链、反馈回路、输入—处理—输出 |
| 架构、分层 | 水平分层、模块连接、数据流箭头 |
| 人物、角色 | 分组关系网、层级树、关系矩阵 |
| 时间、演进 | 时间轴、阶段带、转折节点 |
| 状态机 | 状态节点、条件标签、迁移箭头 |
| 对比、选型 | 双栏对比、矩阵、二维定位 |
| 分类、构成 | 树状层级、嵌套分区、分组列表 |
| 算法、证明 | 分步画布、当前步骤高亮、前后状态 |
| 参数、物理 | 滑块、实时数值、轨迹或曲线联动 |

不要把“标题 + 若干等大卡片”当成默认信息图。每个节点和连线都应有信息意义。

## 素材形态

- `none`：用 HTML/SVG/Canvas 自绘抽象结构。
- `text_context` / `verified_sources`：只使用已确认事实构图。
- `structured_data`：可用于数值反馈；标准统计图优先 ECharts。
- `user_image + preserve`：将原图作为 `<img>` 底图，叠加 SVG/DOM；不得改变原图。
- `user_image + observe_for_schematic`：提取可直接观察的结构特征，自绘并明确标注“示意”。

## 输出约束

- 使用 `html type="renderer"`。
- 首块外层为 `<html style="margin:0;padding:0;">` 和透明 div。
- 不使用 DOCTYPE、head、body、TEXT；CSS 全部内联。
- 根容器自然撑高；禁止 `100vh`、`height:100%` 和根固定大高度。
- 优先 HTML/SVG；Canvas 只用于 SVG 难以稳定表达的连续动态绘制。
- 脚本使用 IIFE、try/catch 和 DOM 判空，不监听 `DOMContentLoaded`。
- 地图库和地图组件一律禁止。

## 静态信息图要求

- 不操作即可读懂主结论。
- 流程和时间线有明确阅读方向。
- 节点分组、连线含义和图例清晰。
- 可见文字准确简短，不把正文全文塞进图中。
- 复杂关系通过分层、分组或拆图降低交叉。
- 示意结构显式标注“示意”，不暗示精确测量或官方结构。

## 交互要求

- 控件不小于 44×44px，同时支持 click/tap。
- hover 只作桌面增强，不承担核心答案。
- 动画可暂停、可重置，不持续高频空转。
- 操作后提供即时视觉变化和文字或数值反馈。
- 初始静态状态即可理解主结论。
- JavaScript 失败时至少显示文字说明、底图或静态主结构。

## 降级

1. 复杂交互失败 → 静态 HTML/SVG。
2. 外部库失败 → 纯 HTML/SVG/Canvas。
3. 结构或事实不足 → 结构化文字。

不得输出空白 renderer，也不得用不可复核内容替代缺失事实。
