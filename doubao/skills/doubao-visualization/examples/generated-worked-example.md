# Worked Example：三国时期图解

## 1. 正文拆分

```text
article_sections:
1. 三国鼎立格局：魏、蜀、吴的地理位置、实力和制衡关系
2. 六十年时间脉络：从黄巾起义到三国归晋
3. 三场关键战役：官渡、赤壁、夷陵分别改变了什么
```

## 3. 视觉策略

统一视觉系统：

- 风格：博物馆历史知识图解；
- 配色：古籍米白、朱砂红、墨黑、青铜绿；
- 材质：古籍纸张、青铜器纹理、印章；
- 标题：同一书法印刷字体气质；
- 图形：地图沙盘、时代长卷、战役场景；
- 禁止：游戏 UI、廉价古风边框、等大卡片、密集小字。

三张图构图必须不同：

- 格局图：横向三角制衡；
- 时间线：横向时代长卷；
- 战役图：中心沙盘加三处战场。

## 5. 生成后检查

- 三张图是否使用了三种不同构图；
- 时间线是否为横图；
- 格局图是否能一眼看到三方制衡；
- 战役图是否有中心沙盘，而非三张卡片；
- 图片中的年份、国名和战役名是否正确；
- 若当前业务要求固定模型，是否已根据工具 schema 使用正确的顶层 `model_version`；否则是否避免提交未知字段。
