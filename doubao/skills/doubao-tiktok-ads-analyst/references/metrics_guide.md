## 一、核心指标体系

### 1.1 漏斗指标（从上到下）

| 层级 | 指标 | 计算公式 | 意义 | 健康参考值 |
|------|------|----------|------|------------|
| 曝光层 | 曝光量 (Impressions) | - | 广告被展示的次数 | 视预算而定 |
| 曝光层 | 触达人数 (Reach) | - | 看到广告的独立用户数 | 视预算而定 |
| 曝光层 | 曝光频次 (Frequency) | 曝光量 / 触达人数 | 平均每人看到广告的次数 | 1.5-3.0（过高=疲劳） |
| 曝光层 | CPM | 花费 / 曝光量 × 1000 | 千次曝光成本 | 行业差异大，$5-20 |
| 点击层 | 点击量 (Clicks) | - | 广告被点击的次数 | - |
| 点击层 | CTR | 点击量 / 曝光量 × 100% | 点击率 | 1.5%-3%（低于1%需优化） |
| 点击层 | CPC | 花费 / 点击量 | 单次点击成本 | 行业差异大，$0.3-1.5 |
| 转化层 | 转化量 (Conversions) | - | 完成目标行为的次数 | - |
| 转化层 | CVR | 转化量 / 点击量 × 100% | 点击转化率 | 2%-5%（电商） |
| 转化层 | CPA | 花费 / 转化量 | 单次转化成本 | 视目标而定 |
| 转化层 | ROAS | 转化价值 / 花费 | 广告支出回报率 | 电商≥2.5为优 |

### 1.2 视频专属指标

| 指标 | 说明 | 健康参考 |
|------|------|----------|
| 2秒播放率 | video_watched_2s / impressions | ≥30% |
| 6秒播放率 | video_watched_6s / impressions | ≥15% |
| 完播率 (VTR) | video_views_p100 / video_views | ≥15%（15秒内视频） |
| 平均播放时长 | average_video_play | 视频时长的40%以上 |
| 25%/50%/75%完播 | 各阶段完播人数 | 递减但不断崖式下跌 |

**视频指标分析要点**:
- 2秒播放率低 → 前3秒钩子不够吸引人
- 6秒播放率低但2秒高 → 开头还行但内容留不住人
- 完播率低 → 视频中段或结尾有问题
- 播放时长分布断崖式下跌 → 对应时间点的内容需要优化

### 1.3 互动指标

| 指标 | 说明 | 用途 |
|------|------|------|
| 点赞数 (Likes) | 用户点赞次数 | 内容受欢迎程度 |
| 评论数 (Comments) | 用户评论次数 | 内容引发讨论程度 |
| 分享数 (Shares) | 用户分享次数 | 内容传播潜力 |
| 关注数 (Follows) | 新增关注数 | 品牌吸引力 |
| 主页访问 (Profile Visits) | 访问主页次数 | 品牌兴趣度 |
| 互动率 | (点赞+评论+分享) / 曝光 | 内容整体互动表现 |

## 二、分析维度详解

### 2.1 时间维度分析

**分析方法**:
- **日趋势分析**: 观察每日数据变化，识别增长/下降趋势
- **周内分布**: 分析周几效果最好，优化投放时段
- **小时分布**: 分析一天中哪些时段效果好，设置分时出价
- **环比/同比**: 与上周期/去年同期对比，评估增长

**常见异常识别**:
- 突然下跌 → 检查账户状态、素材审核、预算耗尽
- 周末波动 → 正常现象，结合行业特点判断
- 持续下滑 → 素材疲劳、受众饱和，需要更新

### 2.2 结构维度分析

**广告系列层级**:
- 各系列预算占比 vs 转化贡献占比
- 识别高ROI系列和低效系列
- 优化预算分配

**广告组层级**:
- 各广告组表现排名
- 定向策略效果对比（宽定向 vs 窄定向）
- 出价策略效果对比

**广告层级**:
- Top 10表现最好的广告（总结成功经验）
- Bottom 10表现最差的广告（分析失败原因）
- 素材生命周期分析（新广告 vs 老广告）

**分析方法**:
- 帕累托分析：80%的转化来自20%的广告
- 贡献度分析：各部分对整体的贡献
- 集中度分析：是否过度依赖少数广告

### 2.3 受众维度分析

**人口统计学维度**:
- **年龄**: 18-24 / 25-34 / 35-44 / 45-54 / 55+
  - 分析各年龄段的转化效率
  - 识别高价值年龄段，加大投放
  - 排除低效年龄段，节省预算
  
- **性别**: 男性 / 女性 / 未知
  - 对比不同性别的表现差异
  - 针对性优化素材和文案

- **地域**: 国家 / 州省 / 城市
  - 各国/地区的CPA/ROAS对比
  - 识别高潜力市场
  - 调整地域出价

**设备维度**:
- **操作系统**: iOS vs Android
  - iOS通常CPA更高但转化价值也高
  - Android通常量大但质量稍低
  - 根据ROI调整预算分配
  
- **设备型号**: 高端机 vs 中低端机
  - 高端机用户消费能力更强
  - 可用于电商、游戏等行业

**兴趣/行为维度**:
- 兴趣标签效果对比
- 行为定向效果（视频互动者、购物行为等）
- 自定义受众 vs 泛受众对比

### 2.4 素材维度分析

**素材形式**:
- 视频 vs 图片
- 长视频 vs 短视频
- 真人出镜 vs 产品展示
- UGC风格 vs 专业制作

**素材元素**:
- 开头钩子类型对比
- 文案风格对比
- BGM效果对比
- CTA形式对比

**分析方法**:
- A/B测试结果分析
- 素材衰减曲线（上线后效果随时间变化）
- 素材生命周期管理（什么时候该换新素材）

### 2.5 版位维度分析

**TikTok版位**:
- TikTok信息流（主流量）
- TikTok搜索广告
- TikTok故事广告

**其他版位**:
- Pangle（穿山甲）
- 其他联盟流量

**分析要点**:
- 各版位的流量质量对比
- 版位间的转化差异
- 版位优化建议（是否只投TikTok）

## 三、优化策略库

### 3.1 预算优化

**问题诊断**:
- 预算花不出去 → 定向太窄、出价太低、素材太少
- 预算花太快 → 定向太宽、出价太高、预算太小
- 预算消耗不均 → 部分广告组抢量严重

**优化方法**:
1. **预算分配优化**
   - 向高ROI广告组倾斜预算
   - 逐步增加（每次20%-30%），避免大幅调整
   - 低效广告组降预算或暂停

2. **预算节奏控制**
   - 学习期预算：建议日预算≥目标CPA的20倍
   - 稳定期预算：根据ROI目标调整
   - 避免单日多次调整预算（≤2次）

### 3.2 出价优化

**出价策略选择**:
- **最低成本**: 追求最大转化量，成本可能波动
- **成本上限**: 控制成本不超过目标，可能拿不到量
- **出价上限**: 手动出价，控制力强但需要经验

**优化方法**:
1. **出价调整幅度**
   - 每次调整幅度≤20%
   - 调整后观察24-48小时
   - 学习期不建议频繁调价

2. **分时出价**
   - 高峰时段提高出价
   - 低峰时段降低出价
   - 根据小时数据制定出价策略

### 3.3 受众优化

**定向策略演进路径**:
1. **冷启动期** → 较宽定向，让系统探索
2. **成长期** → 基于数据逐步叠加兴趣/行为标签
3. **稳定期** → 精准定向 + 再营销 + 相似受众

**优化方法**:
1. **受众分层**
   - 核心受众（高转化）→ 重点投放
   - 潜力受众（有点击无转化）→ 再营销
   - 低效受众 → 排除或减少预算

2. **相似受众 (Lookalike)**
   - 种子人群：高价值用户（购买、注册等）
   - 规模：1%-5%（越小越精准，越大覆盖越广）
   - 更新：定期更新种子人群

3. **再营销**
   - 网站访客再营销
   - 视频观看者再营销
   - 加购未购买再营销
   - 老客户唤醒

### 3.4 素材优化

**素材迭代策略**:
1. **保持上新频率**
   - 每周上新3-5组素材
   - 测试不同创意方向
   - 及时淘汰低效素材

2. **爆款素材复制**
   - 分析Top素材的成功要素
   - 基于成功要素做变体
   - 换演员、换场景、换文案

3. **素材生命周期管理**
   - 新素材：学习期（前3天）
   - 成长期：效果上升期（3-7天）
   - 稳定期：效果平稳（7-14天）
   - 衰退期：效果下降（14天后）→ 准备替换

**常见问题与优化**:
| 问题 | 可能原因 | 优化方向 |
|------|----------|----------|
| CTR低 | 素材不吸引人、定向不准 | 优化前3秒、调整定向 |
| CVR低 | 落地页差、产品吸引力不够 | 优化落地页、调整出价目标 |
| CPA高 | 出价高、转化少 | 降低出价、优化素材提升转化 |
| 素材衰减快 | 受众饱和、创意单一 | 扩大受众、增加素材多样性 |

### 3.5 账户结构优化

**最佳实践**:
1. **广告系列划分**
   - 按目标划分（转化、曝光、点击等）
   - 按产品/产品线划分
   - 按地区/市场划分

2. **广告组划分**
   - 按定向策略划分
   - 按素材类型划分
   - 避免广告组之间互相抢量

3. **广告数量**
   - 每个广告组3-5个广告
   - 太多会导致学习数据分散
   - 太少无法测试优化

## 四、分析框架模板

### 4.1 账户健康度评分

| 维度 | 权重 | 评分标准 |
|------|------|----------|
| CTR表现 | 20% | ≥2%=优 / 1-2%=良 / 0.5-1%=中 / <0.5%=差 |
| CPA达成率 | 30% | ≤目标=优 / 目标×1.2=良 / 目标×1.5=中 / >目标×1.5=差 |
| ROAS表现 | 25% | ≥3=优 / 2-3=良 / 1.5-2=中 / <1.5=差 |
| 素材健康度 | 15% | 上新频率+衰减速度 |
| 预算利用率 | 10% | 80%-100%=优 / 60-80%=良 / 40-60%=中 / <40%=差 |

### 4.2 问题诊断树

```
效果下降
├── 曝光下降
│   ├── 预算问题（预算耗尽、预算太低）
│   ├── 出价问题（出价太低、竞争力下降）
│   ├── 定向问题（定向太窄、受众饱和）
│   ├── 素材问题（素材疲劳、审核不通过）
│   └── 账户问题（账户受限、余额不足）
├── CTR下降
│   ├── 素材问题（创意老化、吸引力下降）
│   ├── 定向问题（受众不精准）
│   ├── 竞争问题（竞争对手增加）
│   └── 版位问题（流量质量变化）
└── CVR下降
    ├── 落地页问题（页面加载慢、体验差）
    ├── 产品问题（价格、库存、评价）
    ├── 受众问题（流量质量下降）
    └── 竞争问题（竞品促销）
```

### 4.3 优化优先级矩阵

```
        影响大
          ↑
          |
   快速见效 ●────● 长期投入
          |      |
          |      |
   立即执行 ●────● 暂缓考虑
          |
          +──────→ 实施难度
                难度低
```

**优化行动分类**:
- 🔴 立即执行（影响大、难度低）：暂停低效广告、调整预算分配
- 🟡 中期优化（影响大、难度中）：素材迭代、受众优化
- 🟢 长期策略（影响大、难度高）：账户结构重构、数据积累
- ⚪ 暂缓考虑（影响小、难度高）：复杂的定制化开发

## 六、分析报告结构建议

每次分析建议遵循以下结构：

1. **执行摘要**（3-5句话总结核心发现和建议）
2. **核心指标概览**（关键数据表格 + 环比变化）
3. **趋势分析**（时间维度变化）
4. **结构分析**（各广告组/广告表现对比）
5. **受众分析**（人群画像与转化效率）
6. **素材分析**（创意表现与优化方向）
7. **问题诊断**（发现的问题与原因分析）
8. **优化建议**（分优先级的具体行动项）
9. **下一步计划**（后续工作安排）
