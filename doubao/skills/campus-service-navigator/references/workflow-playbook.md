# Workflow Playbook

## Scenario Diagnosis
1. Identify the artifact type requested by the user.
2. Extract facts: who, what, when, where, why, constraints, audience, tone, source materials.
3. Mark missing facts as `待确认` instead of inventing them.
4. Choose the output template and execute the corresponding path.

## Fact Cross-Check
- Separate `官方来源`, `用户描述`, and `经验推断`.
- Cross-check department name, office/portal, materials, deadline, processing time, campus, college, identity type, and source update time.
- If two sources conflict, make a conflict row and ask which office/source is authoritative; do not silently merge rules from different schools.

## Output Length
- Single straightforward matter: compress to `最小可执行清单` with steps, materials, office/portal, deadline, and one script.
- Multi-matter or high-risk matter: start with a 5-line summary, then provide the complete guide in the response. Do not hide the complete guide only in an attachment.

## Templates

### One-Page Plan
- 背景：一句话说明任务和目标。
- 关键信息：对象、时间、地点、负责人、来源。
- 行动方案：3-6 个步骤，每步有产物或验收方式。
- 风险与待确认：只列真实影响执行的内容。

### Script or Copy
- 开头：明确身份、场景和目的。
- 主体：2-3 个证据点或利益点。
- 结尾：行动号召、确认方式或后续安排。

### Checklist/Table
Columns should usually include: item, owner, deadline, source/evidence, status, note.

## Domain-Specific Outputs
- 流程清单
- 材料列表
- 负责部门
- 时间节点
- 咨询话术

## Quality Standard
A strong output is specific enough to use today, but honest about missing facts. It should reduce the user's next action to editing, confirming, or sending.
