# Trigger Boundaries

## Should Trigger
- 学生证丢了，怎么补办，需要准备什么？
- 我要办成绩证明，帮我整理步骤。
- 宿舍漏水，帮我写报修说明和催办话术。
- 用户要求交付：办事流程清单、所需材料列表、联系人/部门清单、时间节点提醒、咨询话术模板
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我绕过请假审批。
- 帮我做海报封面。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 用户未说明学校。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
