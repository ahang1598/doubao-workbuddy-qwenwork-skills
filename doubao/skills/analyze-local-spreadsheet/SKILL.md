# Analyze Local Spreadsheet

按“先读结构—再定口径—后计算—再验算—最后交付”处理本地工作簿。未确认范围、拆分规则或指标口径前，不给最终数值。

## 1. 定位文件与范围

1. 从用户给出的本地路径读取附件，列出文件名、版本、全部 sheet、可见/隐藏状态和实际使用区域；本地读取失败后再说明阻塞，不以同名网络文件替代。
2. 明确统计期间及其归属字段。批量月表若日期写在文件名中，就从文件名取日期，不改用文件修改时间；异常文件名和缺失日期单列。
3. 把用户边界原样写入口径。例如租赁重述只纳入 `2026-03-31` 前投入使用的 `9` 个仓库，并按 `2023`、`2024`、`2025` 全年核算；取消该截止日或仓库范围会改变面积、费用和调整额。
4. 若证据未规定日期窗口开闭、时区或拆分方式，先询问，不自行假设自然日或左闭右开。

## 2. 识别工作簿结构

1. 逐 sheet 检查表头层级、数据起始行、合并单元格、隐藏行列、空行、合计行、公式列、样式列和浮动对象；样式或说明不等于数据。
2. 不套用统一起始行：证据中的 `订单表` 实际明细从第 `3` 行开始，`O2` 单独放下单日期；若仍从第 `2` 行读取，会把日期或表头当明细。
3. 遇到 `主表` 时核对 `采购订单号`、`物料编码`、`订单数量` 等真实表头，不仅依赖列字母；证据中它们曾位于 B、D、F 列，但列位必须以当前文件为准。
4. 图片是浮动对象时检查锚点、合并格和行高；合并格同一位置可能有多张图片，不能只读取单元格值。
5. 合并月表时识别并跳过空行与合计行，同时记录跳过数；多级表头、空列和重复行模式不得并入明细。

## 3. 锁定事实源与统计口径

1. 以明细 sheet 重算事实，已有 `summary` 或首页汇总只作交叉校验；两者不一致时报告差异并回查明细。证据明确指出后加的 `summary` 可能存在数据或计算逻辑错误。
2. 租赁场景从各仓明细的 `原费用`、`折旧`、`利息`、`资本化`、`摊销` 重算：新口径将全部租金总额在租赁期内系统分摊，并将建设期租金资本化，而不是按实际付款期直接计费；这会改变 `2023`—`2025` 各年费用和利润。
3. 将 `免租期资本化` 与 `租金平摊方式变更` 分年量化为差额成因，不把免租期简单记为零成本。
4. 若只发现 `单据状态` 字段却没有状态值定义，或没有可靠日期区间规则，向用户或数据字典确认；不得编造“有效”“已完成”等过滤值。

## 4. 建立字段映射与计算关系

1. 先写出来源 sheet、目标 sheet、匹配键、展开粒度、过滤条件和去重键，再计算；一对多关系必须保留。
2. 物料场景按 `主表.物料编码 = 机型清单大全汇总表.物料号` 搜索全部工作表，不能只查 `散单` 或当前 sheet。一个 `物料号` 可对应多个 `图号`、`描述`、`数量`、`材质`、`规格`、`是否激光下料`、`重量`、`面积`、`长宽`、`颜色`，不得用单值映射覆盖后项。
3. `订单表.数量 = 机型清单大全汇总表.数量 × 主表.订单数量`；例如每套 `2` 个且下单 `2` 套，结果为 `4`，不能直接复制任一来源数量。
4. 多 `图号` 展开时只在第一行显示 `采购订单编码` 和 `物料编码`。`主表.物料编码` 重复时需合并 `采购订单号`，但合并顺序、是否去重及分隔符须先确认。
5. 若用户要求月均，沿用其 `跑外卖总金额 ÷ 跑外卖月数` 口径，不改除以记录行数、工作天数或固定 `12`；“有数据月份”还是自然跨度未定义时先确认月数判定。

## 5. 执行重算、映射或合并

1. 保留来源引用链；首页汇总以公式引用各仓明细，杜绝手工加总。写入公式后使用 Excel、LibreOffice 或 WPS 兼容引擎重算，不能把公式文本或旧缓存值当结果。
2. 对证据中的 `订单表`，在 `O2` 写运行当天日期、从第 `3` 行写匹配结果，并按 `需求日期 = 当天 + 5天` 生成日期；仅在当前模板仍有这些字段和位置时采用。
3. 每个物料只复制其匹配到的图片集合一次；同一锚点有多图则全部保留，但不得把上一物料的图片累加到下一物料。图片位置应与对应结果行一致。
4. 保持目标模板的行高、框线和列结构；订单模板中除 `图片`、`图号` 外其他列居中，并覆盖 `备注`、`激光`、`折弯`、`机加`、`焊接`、`打磨`、`喷涂` 的边框。
5. 批量合并必须保留来源文件和来源 sheet 字段；企业名匹配分别记录已匹配、未匹配和多匹配。证据只确认需处理后缀及“市”字差异，未给完整标准化词表时不得扩写删除规则。

## 6. 做勾稽校验

1. 至少验证：明细合计 = 首页汇总、各仓小计之和 = `9` 仓总计、`调整后结果 - 调整前结果 = 差额`、差额 = `免租期资本化 + 租金平摊方式变更` 等已确认成因。
2. 分年任务同时验证 `2023`、`2024`、`2025` 结果之和与总调整影响一致；不能只抽查总计而跳过年度列。
3. 订单展开后，逐样本复核 `订单表.数量 = BOM数量 × 主表.订单数量`，并检查多个 `图号`、图片和采购订单没有丢失或重复累加。
4. 批量合并报告 `输入行数 - 跳过空行 - 跳过合计行 - 去除重复 + 按规则新增/展开行 = 最终行数`，并另报缺失数；任一等式不平即回查。
5. 公式文件必须在表格引擎重算后复读关键单元格，避免仅用 openpyxl 等库写入公式却读取旧缓存。

## 7. 异常回查与复验

1. 出现汇总不平、结果为空、多个图号无图片、第三个及后续物料重复累加、异常文件名或缺失日期时，停止交付最终结论。
2. 按固定顺序回查：源 sheet 与实际数据区 → 表头映射 → 匹配键 → 一对多展开粒度 → 筛选与去重 → 公式 → 图片锚点 → 汇总勾稽。
3. 若 `summary` 与各仓 `原费用`、`折旧`、`利息`、`资本化`、`摊销` 明细不一致，以重算明细为准并列示差异；不要通过改汇总常数把差额抹平。
4. 修正图片逻辑后，核对 `5` 个物料号可能匹配 `11` 张图片这类一对多结果，区分合理多图与跨物料累加；再全量重算并重复第 6 节所有等式。

## 8. 结构化交付

1. 交付物注明文件版本、使用的 sheet、实际明细区域、时间范围、字段映射、过滤/去重/展开规则、公式重算引擎及异常处理。
2. 同时提供结果、公式或处理方案，以及已匹配、未匹配、多匹配、重复、缺失、跳过空行和跳过合计行的数量；明细与汇总有差异时附差额和成因。
3. 用户要求“原 Excel 表格形式”时保留模板结构，并说明首页汇总如何公式链接到各仓明细；不要只给聊天中的数值摘要。
4. 输出可追溯定位，例如 `文件名 → sheet → 原始行/单元格 → 目标行/公式`。不得把某次任务算出的结果常数写成通用口径。

## 边界与禁止事项

- 范围、月份定义、日期边界、状态值、拆分规则或重复键不明确时先确认，不猜测。
- 不忽略 sheet 差异、表头偏移、合并格、隐藏行列、浮动图片、空行和合计行。
- 不把样式列、说明列、公式缓存或后加 `summary` 当明细事实。
- 不把 `物料号` 到多个 `图号` 的一对多关系压成单值，也不自行决定 `采购订单号` 合并分隔符。
- 发现差额异常或口径冲突必须回查源数据、修正并复验。

## 工具使用

- 用工作簿解析库盘点 sheet、单元格、公式、合并区、隐藏状态与图片锚点；读取公式时同时区分公式文本和缓存值。
- 用数据处理工具按已确认的字段、过滤、去重和展开规则计算；保留来源文件、sheet、原始行号。
- 用 Excel、LibreOffice 或 WPS 兼容引擎重算公式并复读关键结果；批量处理后再做全量行数守恒和勾稽。
- 不需要为不同模板强套固定脚本；字段名或位置与 `订单表`、`主表` 等证据模板不一致时重新盘点。

## 示例

用户要求把 `主表` 订单映射到 `订单表` 时：先确认 `订单表` 第 `3` 行为明细起点、`O2` 为下单日期；再以 `主表.物料编码 = 机型清单大全汇总表.物料号` 搜索全部工作表，按一对多展开 `图号`，计算 `订单表.数量 = BOM数量 × 主表.订单数量`，每个物料复制图片集合一次；最后核对展开数量、图片数、重复采购订单和 `需求日期 = 当天 + 5天`，交付映射与异常清单。
