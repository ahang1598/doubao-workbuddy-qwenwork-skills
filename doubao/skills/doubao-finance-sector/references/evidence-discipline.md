# 证据、截止与反证补充

复杂历史截止、排名、置信度、风险或情景任务先声明决定性 claim，再形成最终使用。普通短答和零工具请求在会话内做同样的最小检查，不为修辞句建立台账。

结构化状态为 `supported|unverified|contradicted|conditional`。缺失、未知时间或没有新数据属于 `unverified`，不属于反证。`contradicted` 需要在截止时合资格、直接指向本命题的决定性反证。未来条件使用 `conditional`；截止后的具体事实只能隔离，不能改写成假设后影响当前结论。

所有参与当前支持状态的决定性依赖都必须同时满足 `observed_at <= as_of` 和 `available_at <= as_of`。未知时点保持未知。相同观察时点会因可获得时点不同而改变资格。摘要、正文、表格、排名、置信度、风险和情景使用均复用同一 canonical claim；必须显式声明最终决定性使用集合完整。

`unique|necessary` 需要完整范围、完整覆盖以及完整声明并逐项直接反驳的竞争解释。研究优先级不是市场必经顺序。不同累计窗口不能证明连续时段加速；该推断只接受同一日历中两个相邻的单一 session。

价格、成交、换手、席位名称或估算流量不能单独证明身份、意图或实际净资本。排除渠道需要直接证据。缺口、反证和情景作用只降级受影响 claim，不连带推翻其他已有支持的结论。

外部检索仍服从托管的 `financial-search-policy.md`。文件复现的哈希只证明字节完整；干净重建只证明声明的确定性装配路径。两者都不证明来源真实、语义支持、因果正确或决定性清单完整。
