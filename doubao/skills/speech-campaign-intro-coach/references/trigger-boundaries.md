# Trigger Boundaries

## Should Trigger
- 明天班委竞选，帮我写 2 分钟竞选演讲。
- 社团面试问为什么加入，我该怎么回答？
- 新生自我介绍想自然一点，别太尬。
- 用户要求交付：自我介绍稿、竞选演讲稿、社团面试回答、答辩Q&A、表达优化建议
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我编一个国家级获奖经历。
- 帮我查补办学生证流程。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 只有一句“写自我介绍”。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
