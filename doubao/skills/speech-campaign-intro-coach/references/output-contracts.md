# Output Contracts

## Required Artifact Fields
- 自我介绍稿
- 竞选演讲稿
- 面试回答
- 答辩 Q&A
- 表达优化建议
- 对话内完整稿件或核心段落
- 字数、时长、停顿、删减点、练习提示
- 合规替代表述表

## Minimum Quality Bar
- The result must match the user's context and audience.
- The result must include concrete wording, table rows, schedule, or checklist items when applicable.
- The result must not be only a framework unless the user explicitly asks for a framework.
- The result must label unknown facts and assumptions.
- Do not provide only a summary or attachment reference. Include the full speech, answer, or at least the core paragraphs directly in the response.
- Every稿件 must state approximate word count, target duration, pause marks, optional cuts, and practice tips.
- Scenario tools must match the occasion: defense uses qualification/evidence/compliance table; pitch uses story arc, data limitation, team contribution; campaign uses controllable promises; interview uses identity positioning and high-pressure Q&A.
- Compliance replacement table must cover fabricated achievements, uncontrollable promises, labeling/sob-story framing, opponent attacks, and privacy exposure when relevant.

## Final Review Checklist
- Trigger matched: yes/no.
- Required inputs complete or visibly marked.
- Deliverables present.
- Tone fits the audience.
- No fabricated fact.
- No unsafe or non-compliant instruction.
- User can take a next action immediately.
- Full/core稿件, timing marks, and compliant replacements are present.
