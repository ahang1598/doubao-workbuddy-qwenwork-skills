# 三市场公告分类体系

本文件是三个市场的公告分类"字典"，用于第二步"定位公告类型"。分类颗粒度已与需求方确认，后续如有新增/调整公告类型，直接在对应市场表格里增补，不要另开新文件。

## 一、A股（沪深北交易所）

制度依据：《上市公司公告电子化规范》JR/T 0021.1-8—2023（临时公告电子化分类标准）+ 上交所/深交所《股票上市规则》（2026年修订）+ 深交所公开公告类别列表。

| 大类 | 细分公告类型（示例） | 投资者关注视角 |
|---|---|---|
| 定期报告 | 年度报告、半年度报告、一季度报告、三季度报告 | 业绩增长/景气度、扣非口径、是否符合此前预告与一致预期 |
| 交易类临时公告 | 收购/出售资产、关联交易、对外担保、对外投资、签订重大合同/战略协议 | 交易对价与规模、是否影响主业、关联方利益输送风险 |
| 公司治理类 | 董事会/监事会/股东会决议、董监高变动、审计/评级等中介机构报告 | 管理层稳定性、治理结构变化信号 |
| 权益变动类 | 股东增减持、股份协议转让、限售股解禁、收购报告书、权益分派（分红/转增） | 大股东/管理层对公司价值的真实判断、股权结构变化 |
| 股权激励类 | 股票期权激励计划、限制性股票激励计划、员工持股计划（草案/股东大会审议/授予登记/调整/解锁行使/终止注销） | 授予价格相对市价的折让幅度、业绩考核指标是否宽松、对股本的摊薄程度、管理层与核心员工的利益绑定力度 |
| 监管问询类 | 交易所问询函/关注函/监管工作函，及公司随后发布的《关于问询函的回复公告》 | 监管主动质疑的具体事项是什么（业绩异常/重组合规性/股价异动/关联交易/商誉减值等）、回复是正面回应还是打太极、后续是否会影响事项本身的进展（如重组被暂停/终止） |
| 融资类 | 首次公开发行、配股、增发（定增）、可转债、权证、其它融资 | 摊薄效应、募资用途、发行价格与条款 |
| 其他临时公告 | 业绩预告/快报、股价异动说明、诉讼仲裁、澄清风险提示、补充更正 | 是否证实/证伪此前市场传闻，业绩是否超预期 |
| 停复牌公告 | 独立停牌/复牌申请及理由 | 停牌原因（重组/重大事项/风险提示）、复牌后走向 |
| 上市/退市公告 | 新股上市、退市风险警示、其他风险警示（ST）、终止上市 | 是否触及财务类/交易类退市红线 |

**监管问询类和"其他临时公告"里的澄清风险提示不是一回事**：澄清公告是公司主动针对市场传闻做澄清；问询函是交易所主动发函要求说明，公司必须在规定时间内回复，不回复或回复不到位有监管后果，交易所主动发函这个动作本身就是一个独立于回复内容的信号。另外，问询函是一个"元类型"——问询的具体内容可以是任何事项（业绩、重组、股价异动、关联交易……），解读时既要看这一层"监管问询"本身的信号（详见 `playbooks/tier2-inquiry-letter.md`），也要回头识别问询的是哪类具体事项，联动到对应的其它 playbook 一起看（联动规则见 `linked-signals.md`）。

## 二、港股（HKEX）

制度依据：HKEX《Headline Categories》标签指引 + 《主板/GEM 上市规则》第 14/14A 章（须予公布的交易/关连交易）+ 《证券及期货条例》第 XV 部披露权益（DI）制度。

| 大类 | 细分公告类型（示例） | 投资者关注视角 |
|---|---|---|
| 财务业绩 | 中期/年度业绩公告、盈利预警（Profit Warning）、盈喜（Positive Profit Alert） | 是否符合预期，盈警/盈喜作为提前信号的价值 |
| 须予公布的交易 | 须予披露交易/主要交易/非常重大交易（Ch.14）、关连交易（Ch.14A） | 交易规模占比（资产/收入/代价比率测试）、是否需股东批准 |
| 股份发行与集资 | 配售（Placing）、供股（Rights Issue）、可换股债券、股份计划（期权/奖励） | 折让率、摊薄比例、资金用途 |
| 股份回购与增减持 | 每日回购公告、股东/董事增持或减持 | 回购力度、大股东真金白银表态 |
| 股权披露（DI 通知） | 大股东（5%+）、董事/最高行政人员权益变动通知（Form 1/2/3A-3D，经 DION 系统） | 是否为控制权变化前兆 |
| 董事与管治变动 | 董事/公司秘书变更、企业管治守则合规情况 | 管理层稳定性信号 |
| 股东大会 | AGM/EGM 通知及表决结果 | 重大决议（私有化、资产重组等）的通过情况 |
| 停牌复牌与内幕消息 | 停牌原因说明、内幕消息（Inside Information）披露 | 停牌原因的重大性（私有化/业绩延迟/监管调查） |

港股公告须从 HKEX 官方 Headline Categories 里选标签，正文解读时优先使用公告本身选用的标签体系定位大类；DI 通知是独立于普通公告的另一套申报系统（DION），检索时要分别处理。

## 三、美股（SEC EDGAR）

制度依据：《证券交易法》1934 + EDGAR 电子化申报表单体系；中概股/红筹架构公司常用 20-F/6-K 替代 10-K/8-K。

| 大类 | 细分公告类型（示例） | 投资者关注视角 |
|---|---|---|
| 定期报告 | 10-K（年报）、10-Q（季报）、20-F（外国私人发行人年报，中概股常用） | MD&A 管理层讨论、风险因素变化 |
| 当期重大事项 | 8-K（或中概股 6-K）：Item 1.01 签订重大协议、2.01 完成收购处置、2.02 经营业绩、5.02 董监高变动、7.01 自愿披露、8.01 兜底重大事项 | 4 个工作日强制披露窗口内，33 类法定事项中触发了哪一类 |
| 注册与发行 | S-1/F-1（IPO）、S-3（增发/再融资） | 发行规模、募资用途、承销商 |
| 持股与内部人交易 | Schedule 13D（积极投资者）/13G（被动，5%+ 持股）、Form 3/4/5（董监高及 10% 股东买卖） | 机构建仓/清仓信号，管理层买卖节奏 |
| 股东大会材料 | DEF 14A（委托投票说明书） | 高管薪酬、董事选举、股东提案 |
| 要约收购/私有化 | SC TO-T、SC 14D9 | 收购价格与条件、董事会意见 |
| 摘牌/合规风险 | Item 3.01 摘牌通知、Item 4.02 财报重述（Non-Reliance） | 是否触及纳斯达克/纽交所持续上市门槛 |

**中概股/外国私人发行人对照**：20-F 对应 10-K（年报，但披露时限和内容要求不同于纯美国公司）；6-K 用于向 SEC 提交按注册地或上市地规则须披露的信息（不像 8-K 有强制 4 个工作日窗口和固定 33 类事项），实际使用上常涵盖业绩、重大协议等内容，但**不能直接套用 8-K 的强制时限规则去判断"是否迟延披露"**。

## 四、三市场共性维度对照

同一类投资者关注点在三市场里对应不同制度名称，解读时按下表把"陌生市场的术语"映射到共性维度，选择对应的解读框架（`references/playbooks/`）。

| 共性维度 | A股对应制度 | 港股对应制度 | 美股对应制度 | 共性关注点 | 对应 Playbook |
|---|---|---|---|---|---|
| 业绩披露 | 定期报告 + 业绩预告/快报 | 中期/年报 + 盈警/盈喜 | 10-K/10-Q/20-F + 8-K Item 2.02 | 是否超预期、指引是否上调/下修 | `playbooks/tier1-earnings.md` |
| 重大合同/并购 | 交易类临时公告 | 须予公布的交易（Ch.14/14A） | 8-K Item 1.01 / 2.01 | 交易规模占比、对主业的影响 | `playbooks/tier1-material-contracts-ma.md` |
| 股权变动 | 权益变动类（增减持/转让） | DI 通知 + 每日回购公告 | 13D/13G + Form 4 + 回购披露 | 大股东/内部人的真实态度 | `playbooks/tier1-equity-changes-buyback.md` |
| 停牌/退市风险 | 停复牌公告 + 上市/退市公告 | 停牌复牌 + 内幕消息 | Item 3.01 摘牌 + 持续上市门槛测试 | 是否触发红线、后续路径 | `playbooks/tier2-halt-delisting-risk.md` |
| 股权激励 | 股权激励类（期权/限制性股票/员工持股计划） | 股份计划（期权/奖励），归在"股份发行与集资"大类下，未单列 | 暂缺——通常体现在 DEF 14A（股东会材料审议激励计划）或 S-8（员工福利计划注册），本轮暂未纳入分类表，后续补充 | 授予折让、业绩考核松紧、摊薄程度、利益绑定力度 | `playbooks/tier2-equity-incentive.md` |
| 监管问询 | 监管问询类（问询函/关注函/监管工作函及回复） | 暂缺——港股交易所也会私下问询，但通常不强制公开发布逐份问询函，常以公司主动澄清公告或内幕消息公告呈现，本轮暂未单列，后续补充 | 暂缺——SEC 对应机制为 comment letter（通过 EDGAR 的 UPLOAD/CORRESP 表单公开，但披露及时性和覆盖面与 A 股不同），本轮暂未纳入分类表，后续补充 | 监管主动质疑的具体事项、回复质量（正面回应还是打太极）、后续对事项本身进展的影响 | `playbooks/tier2-inquiry-letter.md` |
| 融资类 | 融资类临时公告 | 股份发行与集资 | 注册与发行（S-1/S-3） | 摊薄效应、募资用途 | `playbooks/tier3-skeleton.md` |
| 治理变动 | 董监高变动 + 股东会决议 | 董事变动 + AGM/EGM | Item 5.02 + DEF 14A | 管理层稳定性信号 | `playbooks/tier3-skeleton.md` |
| 要约收购/私有化 | （通常走收购报告书/权益变动） | （通常走须予公布交易/私有化安排） | SC TO-T / SC 14D9 | 收购价格/条件、少数股东权益 | `playbooks/tier3-skeleton.md` |

## 五、维护规则

- 新增公告类型时，先判断属于哪个市场的哪个大类，追加到对应表格行；如果是一个全新的大类，先看能否归入现有共性维度，不能归入时才在第四节新增一行。
- 分类颗粒度以此文件为准，不要在其它 playbook 文件里重复定义或使用不一致的分类名称。
