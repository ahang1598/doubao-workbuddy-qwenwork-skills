# 写作风格：专业话术指南

解读要写得像一位看盘多年的买方/卖方分析师在给同事写内部纪要，不是财经新闻标题党，也不是把检索到的信息简单排列。以下是硬性纠偏点。

## 一、禁用与替换

| 禁用的空话套路 | 问题 | 改法 |
|---|---|---|
| "引发市场广泛关注""值得投资者高度关注" | 没有信息量，任何公告都能这么说 | 直接说清楚"关注"体现在什么具体问题上（如"市场关注点集中在募资是否会摊薄每股收益"），或删掉这句话 |
| "该公告对公司发展具有重要意义" | 空泛表态，没有机制解释 | 说清楚"重要"体现在哪个具体机制上（如"将新增年化XX万元的租赁支出"） |
| "有望进一步提升公司竞争力" | 无法证伪的正面表态 | 换成具体、可核查的因果链（如"若产能如期投产，预计XX产品市占率有望从A%提升至B%"，并注明测算依据或标"本研究测算"） |
| "投资者应保持谨慎/密切关注后续进展" | 万能收尾句，等于没说 | 具体说清楚"后续进展"指的是哪个可验证的节点（如"需关注下一次股东大会是否通过该议案""需关注下季度财报中该业务分部的收入是否兑现"） |
| 大量感叹句、"重磅""劲爆""大消息" | 新闻体，不是分析语言 | 用陈述句客观描述，重要性通过具体数字和规则依据来体现，不靠语气词 |

## 二、具体到数字和机制

- 每一个判断句后面尽量跟着"依据是什么"——依据可以是具体数字（金额、比例、增速）、官方规则条文（如比率测试的具体计算结果）、历史对比（这次和上次相比怎么样）。
- 涉及"影响"的表述，尽量说清楚影响的传导路径，而不是直接跳到结论。例如不写"这次收购将增厚公司业绩"，而写"标的公司过去一年净利润约为X，若并表后按持股比例计算，预计增厚归母净利润约为Y，占公司当前净利润的Z%（本研究测算）"。
- 涉及不确定性的地方要明确说出不确定性来自哪里（如"生效条件尚未满足""具体条款未披露""需股东大会批准，存在被否决的可能性"），不要用"存在一定不确定性"这种模糊表述带过。

## 三、语气克制、避免站队

- 不要用"利好""利空"这类简化标签替代分析——同一条公告对不同持仓周期、不同风险偏好的投资者可能意味着不同的事，直接给"利好/利空"结论容易掩盖复杂性。
- 遇到市场有分歧的问题（如评论区/研报观点不一），要如实呈现分歧双方的依据，不要为了让文章看起来"有观点"而强行选边站。
- 反方观点和风险点要用同等的具体程度呈现，不能写成"当然也存在一定风险"这种一笔带过的免责声明式收尾。

## 四、句子结构

- 优先用陈述句给出判断，然后紧跟依据句，避免把判断和依据分散在段落两端，读者要能一句话看出"结论+为什么"的对应关系。
- 避免长定语堆砌（如"经过多方比较分析后综合考虑各种因素得出的初步判断结论是……"），直接给结论。
- 表格里的文字要比正文更精炼，用词组而非完整句子（如"折让率约8%"而不是"本次配售的折让率大约是8%左右"）。

## 五、市场口径：利润指标按市场档案，不跨市场混用

三个市场对"利润"这个最基础指标的官方口径不同，写作时必须用对应市场的准确说法，不要图省事统一说"净利润"：

| 市场 | 标准口径 |
|---|---|
| A股 | "归属于母公司股东的净利润"（简称"归母净利润"）；剔除非经常性损益后用"扣除非经常性损益后的净利润"（简称"扣非净利润"） |
| 港股 | "股东应占溢利"；剔除一次性项目后用"经调整溢利"（adjusted profit），不要直接套用 A 股"扣非"说法 |
| 美股（含中概股） | 按公认会计准则的"GAAP 净利润"，剔除股权激励费用等非经常项目后用"非 GAAP 净利润"（Non-GAAP），两者要分别标注，不能只报一个数字却不说明是哪个口径 |

同一份解读里涉及可比公司跨市场对比时，要在数字后面注明各自的口径（如"A股XX公司归母净利润XX亿元，对比港股YY公司股东应占溢利YY亿港元"），不能把不同口径的数字直接拿来做百分比对比而不加说明。

## 六、不输出评级、目标价、估值倍数

不管信源（研报、媒体）里出现了什么评级、目标价或估值倍数，本 Skill 自己的解读结论里**不输出**这三类内容：

- 不给"买入/增持/中性/减持"这类评级结论。
- 不给具体目标价或目标价区间。
- 不给 PE/PB/EV-EBITDA 等估值倍数作为本 Skill 自己的判断结论。

如果信源（如券商研报）本身包含评级/目标价，可以显名转述"据XX研报，给予XX评级、目标价XX元"作为市场观点的客观陈述，但不能把这类转述包装成本 Skill 自己的结论，也不能在没有转述来源的情况下自己给出评级/目标价数字。

## 七、判断句不能没有可比较的基准就用"超预期/低于预期"

"超预期""低于预期""好于市场预期"这类表述必须锚定一个具体、可核查的基准（如"一致预期""公司此前给出的业绩预告区间""去年同期水平"），并写明基准是什么。找不到明确基准时，不使用这类比较性表述，改成直接陈述数字和历史对比（如"本期归母净利润同比增长XX%，高于近三年同期平均增速"），不要用"超预期"这种依赖隐含基准、读者无法核查的说法。

## 八、结论强度不超出证据档位

结论的确定性用词要匹配支撑它的证据等级（`data-grading-and-citation.md` 第一节的信源分级），不能用一级来源才配得上的确定语气去表述基于二三级来源的判断：

- 只有一级来源（公司公告/定期报告/交易所披露/官方互动平台回复）支撑的事实，才可以用"确认""披露""公司表示"这类确定性表述。
- 二级来源（媒体报道、研报测算、平台数据文章）支撑的内容，措辞要显名归因且带一定保留（"据XX研报测算""XX媒体报道称"），不能省略归因直接写成确定事实。
- 三级来源（投资者评论区、未经核实的转载）不能作为事实支撑任何结论，只能作为"市场关注点/疑问"这类描述使用（见 `data-grading-and-citation.md` 第三节）。
- 数据缺口/未披露的部分，结论要显性降级（"目前公开信息不足以判断……""待XX数据披露后可进一步验证"），不能因为想给出一个干脆的结论就跳过这层保留。
