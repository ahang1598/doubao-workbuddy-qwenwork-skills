# Playbook：Tier 3 骨架 — 融资类 / 治理变动类 / 要约收购与私有化类

这三类出现频率较低，或解读逻辑与 Tier 1 高度复用，先给出骨架框架，后续如需深挖再补充独立 playbook（补充时在 `markets-taxonomy.md` 第四节把对应行的 Playbook 链接指向新文件）。

## 一、融资类

对应：A股融资类临时公告（IPO/配股/增发/可转债/权证）；港股股份发行与集资（配售/供股/可换股债券/股份计划）；美股注册与发行（S-1/F-1/S-3）。

核心问题：融资规模相对现有股本/市值的摊薄比例；发行价格相对市价的折让/溢价；募资用途是否具体（偿债、补流、新项目）；发行对象是特定投资者还是公开市场（影响后续解禁/减持压力）。

## 二、治理变动类

对应：A股董监高变动 + 股东会决议；港股董事变动 + AGM/EGM；美股 Item 5.02 + DEF 14A。

核心问题：变动的是核心管理层（CEO/CFO）还是普通董事；是主动辞任还是被更换；接任者背景是否释放战略调整信号；股东大会决议中是否有非例行性的重大议案（如修改公司章程、罢免董事、重大薪酬方案）被否决或高比例反对票。

## 三、要约收购/私有化类

对应：A股通常走收购报告书/权益变动路径；港股通常走须予公布的交易或专门的私有化安排（Scheme of Arrangement / General Offer）；美股 SC TO-T（要约收购方申报）/ SC 14D9（目标公司董事会意见）。

核心问题：收购价格相对市价的溢价水平；收购条件是否包含最低接纳比例等生效条件；目标公司董事会/独立财务顾问的意见是建议接纳还是不建议；少数股东后续的选择空间（是否有强制挤出条款）。

## 四、后续扩展方式
