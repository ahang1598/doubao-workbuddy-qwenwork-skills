# Playbook：业绩披露类（Tier 1）

对应：A股定期报告 + 业绩预告/快报；港股中期/年报 + 盈警/盈喜；美股 10-K/10-Q/20-F + 8-K Item 2.02。

## 一、先分清公告的性质

三个市场里，"业绩相关公告"其实分两种性质，解读方式不同：

- **正式定期报告**（年报/半年报/季报/10-K/10-Q/20-F）：内容完整，包含财务报表全貌、管理层讨论（MD&A）、风险因素，解读要覆盖收入利润的结构性变化，不能只看总量增速。
- **业绩预告/快报类**（A股业绩预告/快报、港股盈警/盈喜、美股 8-K Item 2.02）：抢先于正式报告披露关键数字，通常只有净利润/营收区间，解读重点是"这个数字相对预期意味着什么"，而不是财务结构分析（因为详细数据还没披露）。

## 二、核心解读问题

1. **是否符合/超出预期**：对照此前的一致预期（`seed_finance_search` 可取一致预期数据）、公司此前给出的业绩指引、同期基数，判断是超预期、符合预期还是不及预期，并给出具体幅度而不是笼统的"好/差"。
2. **增长/下滑的驱动因素**：公告本身通常会给一句归因（如"主要因为XX产品放量""主要因为XX业务费率提升"），要判断这个归因是否可信、是否可持续，不要照抄公告的归因原话当作分析。
3. **结构 vs 总量**：正式报告要看分部收入、毛利率、费用率的变化，不能只看营收/净利润总量；预告类公告如果只给了净利润区间，要明确说明"结构性信息暂缺，需等正式报告"。
4. **指引变化**（如涉及）：管理层是否上调/维持/下调了未来指引或展望，这通常比当期数字本身更影响市场预期。
5. **和历史节奏的对比**：这次的增速/降速是延续此前趋势还是转折点，需要拉近几期数据做对比（`seed_finance_search` 取历史财务），用表格列出近 4~8 期的营收/净利润/增速，趋势明显时配一张折线图（见 `output-rendering.md`）。

## 三、联动检查（必做）

业绩类公告的联动信号排查，按 `linked-signals.md` 的规则表执行，业绩类公告最常见、最值得核对的联动方向是**股权变动类**：

- **业绩连续向好** → 检查同期是否有管理层/大股东增持、公司回购。如果有同步的真金白银动作，是"内部人用行动确认业绩趋势可持续"的加强信号；如果业绩向好但同期反而出现减持，要在正文里正面指出这个背离，不要回避。
- **业绩连续下修/不及预期** → 检查同期是否有股东减持、董监高离职、质押/平仓风险类公告，判断是否存在"业绩恶化 + 股东提前离场"的组合信号。
- 联动检索没有发现任何同期股权变动动作时，也要写明"未发现同期股权变动联动信号"，不要略过不提。
- 检索资讯流/研报动态，看是否已有券商对本次业绩发布点评（尤其是否已调整盈利预测/评级），可引用其测算作为参考视角；检索同花顺/东方财富该业绩公告下的投资者评论，找出市场最集中的质疑点（如"增速主要靠非经常性损益，是否可持续"），并在解读里正面回应。

## 四、市场特有注意点

- **A股**：业绩预告/快报和正式年报之间可能存在数字调整（如商誉减值在快报后补充），解读预告类公告时要提示"最终数字以正式报告为准"。
- **港股**：盈警（Profit Warning）和盈喜（Positive Profit Alert）是强制披露事项（预期业绩较去年同期有重大变动时），要指出这是监管强制要求的提前预警，本身就是一个信号，不只是数字。
- **美股/中概股**：8-K Item 2.02 通常和财报发布会同步或紧随其后，正文里的具体数字要以随附的财报文件（Exhibit 99.1）为准；中概股用 20-F 的披露时限比美国本土公司的 10-K 更宽松，比较同业时要留意披露节奏本身的差异，不要误判为"披露滞后"。
