# Playbook：停牌/退市风险类（Tier 2）

对应：A股停复牌公告 + 上市/退市公告（风险警示 ST、终止上市）；港股停牌复牌 + 内幕消息；美股 Item 3.01 摘牌通知 + 持续上市门槛测试。

## 一、核心解读问题

1. **停牌的官方理由是什么**：公告通常会给出停牌类型/原因（如"因重大事项""因股价异常波动""等待刊发内幕消息"）——不同理由对应的后续走向和复牌时间预期差异很大（重组类停牌可能持续数月，风险提示类停牌往往当日或次日复牌）。
2. **是否是监管强制触发，还是公司主动申请**：主动申请停牌（如筹划重大事项）和被交易所强制停牌（如触及异常交易监控指标）性质不同，后者往往伴随更严重的问题。
3. **是否触及退市/摘牌的具体红线**：这类判断必须引用官方的量化指标，不能凭感觉：
   - A股退市新规常见触发线：财务类（如连续亏损、净资产为负、营收低于门槛）、交易类（如股价连续低于面值、成交量/市值过低）、规范类（如信息披露违规、财务造假）、重大违法类。
   - 港股：长期停牌（通常超过一定期限）本身会触发除牌程序，需关注联交所是否已启动除牌程序及公司是否满足复牌指引。
   - 美股：纳斯达克/纽交所的持续上市门槛（如最低股价、最低市值、最低股东权益）——跌破门槛通常先收到交易所警示信、有整改期，不是立即摘牌；Item 3.01 是"被通知不符合上市标准"的强制披露事项。
4. **复牌/整改的路径和时间表**：公告或后续公告是否给出了明确的整改计划、复牌条件、时间表；如果只是笼统表态没有具体路径，要在解读里指出这一点。

## 二、市场特有注意点

- **A股**：ST/*ST 标识本身是一个持续状态（不是一次性事件），解读时要说明公司当前处于哪个风险警示阶段，以及本次公告相对此前状态是升级还是有改善迹象。
- **港股**：内幕消息（Inside Information）披露和停牌常常同时发生——上市公司在内幕消息尚未能保密或已泄露时，有法定义务尽快披露，解读要留意"是先停牌后公告"还是"边停牌边补充公告细节"这个时间线。
- **美股**：跌破持续上市门槛后通常有几个月的整改期（Compliance Period），期间公司可以通过多种方式补救（如反向拆股拉高股价），解读时要说明当前处于整改期的哪个阶段，避免直接判断为"即将摘牌"。
