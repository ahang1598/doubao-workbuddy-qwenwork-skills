# Playbook：股权激励类（Tier 2）

对应：A股股权激励类公告（股票期权激励计划、限制性股票激励计划、员工持股计划的草案/股东大会审议/授予登记/调整/解锁行使/终止注销）。制度依据：《上市公司股权激励管理办法》（证监会）+ 交易所信息披露业务备忘录/自律监管指引中的股权激励相关规定。

> 港股/美股的对应制度和披露颗粒度与 A 股差异较大（港股散落在"股份计划"里，美股主要靠 DEF 14A/S-8），目前本 playbook 以 A 股为主，港股/美股待后续补充深度。

## 一、先分清计划类型

三种常见工具的机制和信号强度不同，解读前先判断这次公告属于哪一种：

- **股票期权激励计划**：授予对象获得以约定行使价买入股票的权利，行权价通常不低于草案公布前一定期限的市场均价（没有直接折让），激励对象要先看股价涨到行权价以上才有实际收益——本质上更接近"押注未来股价上涨"，管理层承担的下行风险相对小。
- **限制性股票激励计划**：授予对象以折价（常见五折左右，具体折让幅度需核实公告原文）直接获得股票，即便股价不涨也已经锁定了折价收益——激励力度通常被认为强于期权，但也意味着即使公司经营一般，激励对象依然有既得利益，解读时不能简单等同于"管理层信心"。
- **员工持股计划**：一般通过资管产品/信托等载体，员工出资认购，覆盖面通常比前两种更广（可能包含核心员工而非仅董监高），出资方式（自筹 vs 公司借款/担保）本身也是一个关注点。

## 二、核心解读问题

1. **覆盖范围与集中度**：激励对象是否包含董监高、覆盖的核心技术/业务人员范围有多大，授予额度在管理层与普通员工之间的分布是否集中（集中度过高时，"团队激励"实质上更接近"管理层自利"）。
2. **授予价格/折让幅度**：限制性股票的授予价格相对市价的折让有多大（折让越大，员工的既得收益越确定，但也意味着摊薄对老股东更不利）；期权的行权价是否设置了显著低于市价的情况（不常见，出现时要重点核查是否合规）。
3. **业绩考核指标的松紧程度**：这是全篇最关键的一步——解锁/行使条件设定的业绩指标（营收增速、净利润增速、ROE、市值等）相对公司历史增速、同业平均水平是宽松还是有挑战性。具体做法：把考核目标数字和该公司过去几年的实际增速摆在一起比（见联动检索），如果考核目标明显低于历史平均增速，基本可以判断这次计划的"激励"成分弱、"发福利"成分强。
4. **摊薄影响**：新增股份的来源（定向发行新股 vs 从二级市场回购再授予）、涉及股份数量占当前总股本的比例，直接影响每股收益摊薄程度，需要给出具体比例数字，不能只说"存在摊薄"。
5. **解锁/行使节奏**：分几期解锁、每期比例、首次可解锁的时间点距离草案公告的时间——节奏过于集中在短期或考核期过短，都会削弱"长期激励"的实际效果。
6. **员工持股计划的出资方式**（如涉及）：员工自筹资金 vs 公司提供借款/担保认购，后者实质上降低了员工的真实风险承担，解读时要指出这一点，不能简单等同于"员工真金白银投票"。

## 三、联动检查（必做）

按 `linked-signals.md` 的规则执行，股权激励类最值得核对的联动方向：

- **业绩考核完成情况**：检索该公司历史上推出的股权激励计划，其业绩考核目标最终是否达标、达标方式是否"精准擦线"——反复出现"刚好达标"的公司，本次计划的考核指标可信度要打折扣。
- **同期股价走势**：核查计划推出时点是否恰好在股价阶段性低点（业绩承压/股价低迷时更容易以低折让授予，变相让激励对象低价接盘），需要把授予价格和公告前后的实际股价走势放在一起看。
- **董监高是否同步增减持**：如果股权激励计划推出前后，同一批董监高有其它增减持动作，需要交叉核查是否存在提前布局或套现嫌疑。
- 联动检索没有发现任何异常，也要在正文里写明"未发现同期联动异常"。

## 四、市场特有注意点

- **A股**：《上市公司股权激励管理办法》对激励对象范围、有效期、单个对象获授比例上限等有强制性规定，解读时如涉及是否合规的判断，要引用具体条款而非主观感觉；草案公布后通常还有独立财务顾问意见、监事会/独立董事意见等配套文件，可以交叉参考。
- **港股**：股份计划相关信息披露相对分散，年报/中期报告里会披露期权/奖励计划的持仓变动情况，较少像 A 股一样单独发一份"计划草案"深度公告，检索时要注意补充年报里的相关章节。
- **美股**：主要通过 DEF 14A（股东会材料，涉及计划的股东批准）或 S-8（员工福利计划注册声明）披露，信息颗粒度和披露节奏与 A 股不同，本轮暂未深入，遇到具体案例需要额外确认披露路径和文件类型。
