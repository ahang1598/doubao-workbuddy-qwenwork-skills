# Playbook：监管问询类（Tier 2）

对应：交易所（上交所/深交所/北交所）针对定期报告数据异常、重大事项披露不充分、股价异常波动、关联交易、商誉减值等具体事项，向上市公司发出的问询函/关注函/监管工作函，以及公司随后发布的《关于问询函的回复公告》。目前以 A 股为主，港股/美股的对应机制暂未纳入分类表（见 `markets-taxonomy.md` 第四节）。

> 这是一个**"元类型"**：问询函本身是一层独立的监管信号（交易所主动发函施压，本身就说明存在疑点），但问询的具体内容可以是任何事项（业绩、重组、股价异动、关联交易、商誉减值……）。解读时必须**两层都做**，不能只做其中一层。

## 一、先做元类型路由（必做，第一步）

在展开这层"监管问询"信号之前，先识别问询函问的到底是哪类具体事项，回头对照 `markets-taxonomy.md` 找到对应的具体公告类型，联动到对应的其它 playbook 一起看这条实质内容：

- 问的是业绩/财务数据异常 → 联动 `tier1-earnings.md`
- 问的是重大合同/并购/重组 → 联动 `tier1-material-contracts-ma.md`
- 问的是股价异常波动、股东增减持相关 → 联动 `tier1-equity-changes-buyback.md`
- 问的是停牌/复牌/退市风险相关 → 联动 `tier2-halt-delisting-risk.md`
- 问的是股权激励方案相关 → 联动 `tier2-equity-incentive.md`
- 问的是其它事项（关联交易、商誉减值、内控问题等），目前没有专门 playbook 的，按 `tier3-skeleton.md` 的核心问题框架处理，如实标注"深度框架待补充"

**如果一份问询函同时问了好几类事项**（常见，尤其是重组预案问询函），要逐项拆开列明，每一项分别对照联动到对应 playbook，不要合并成一个笼统结论。

## 二、核心解读问题（监管信号本身这一层）

1. **发函主体与紧迫程度**：是普通问询函、关注函，还是措辞更严厉的监管工作函/警示函；有没有要求限期回复（通常 5～10 个交易日），限期本身反映交易所对这件事的紧迫程度判断。
2. **问询函提问的角度**：交易所问的是"事实性核实"（如要求补充披露某个数字的计算过程），还是"合理性质疑"（如要求说明某笔交易定价是否公允、某项安排是否损害中小股东利益）——后者的信号强度明显高于前者，是监管在直接表达不信任。
3. **回复质量评估**：这是全篇最关键的一步——回复是正面给出具体数据/依据，还是用"公司将持续关注""不存在损害投资者利益的情形"这类空泛套话搪塞？逐条对照问询函提出的问题，检查回复是否真的回答了，还是答非所问、避重就轻。**回复的质量本身就是一个独立于被问询事项的信号**：越是关键的问题被打太极，越值得警惕。
4. **回复中是否有主动"自曝"的实质信息**：有些回复会在解释问题的过程中，被动披露了此前没有充分说明的风险点（如标的公司实际技术能力、财务杠杆水平、尚未签订的关键协议条款）——这类"顺带暴露"的信息往往比问询函本身更有解读价值，要重点提取。
5. **后续监管路径**：问询函本身是否会实质性影响事项进展（如导致重组被暂停/要求重新提交方案/需要延期回复），公司是否在回复里主动提示了相关风险（如"可能因涉嫌内幕交易被暂停、终止或取消"）。
6. **是否有历史监管记录叠加**：这次问询是孤立事件，还是该公司近期已有多次被问询/警示的记录（见第三节联动检查）——叠加出现时，反映的是持续性的治理/信息披露质量问题，不是单次事件。

## 三、联动检查（必做）

除第一节的元类型路由（联动到具体事项类型的 playbook）外，还要按 `linked-signals.md` 的规则执行：

- **历史同类检索**：该公司过去是否曾收到过问询函/关注函/监管工作函，历史回复的质量（是正面回应还是同样打太极）——反复出现"回复质量差"的公司，本次回复的可信度也要打折扣。同时检索该公司是否有过其它监管处分记录（警示函、监管关注等），判断是孤立事件还是持续性问题。
- **股价阶段表现检查（几乎总是需要做）**：问询函本身通常是股价异常波动或重大事项预案发布后的直接结果，按 `linked-signals.md` 第四节的量化标准检查停牌前/复牌后/回复公告发布前后的价格走势，这类公告触发"值得展开"判断的概率明显高于其它类型——如果触发，整理关联动态时间线时，问询函的下发时间和回复时间本身就是时间线上的关键节点。
- **被问询事项本身的联动**：按第一节路由到的具体事项类型，执行该类型 playbook 里规定的联动检索（如问的是重组，就要按 `tier1-material-contracts-ma.md` 检索交易对手方历史记录）。

## 四、市场特有注意点

- **A股**：问询函/关注函/监管工作函三者措辞严厉程度递增，交易所官网和巨潮资讯网通常会同步公开问询函原文和回复公告，两份文件都要找到并逐条对照读，不能只读回复公告而不看问询函原文问的到底是什么。
- **港股**：交易所也会私下问询，但通常不强制公开发布逐份问询函原文，更多以公司主动发布的澄清公告、内幕消息公告呈现监管压力的结果，检索时要注意区分"公司主动澄清"和"监管要求说明"两种性质不同的信号（本轮暂未深入，遇到具体案例需要额外确认披露路径）。
- **美股**：SEC 的对应机制是 comment letter，通过 EDGAR 的 UPLOAD（SEC 发出）和 CORRESP（公司回复）表单公开，但通常有滞后期（SEC 政策是问询往来完成后才公开，不是实时同步），检索时要注意这个时间差，本轮暂未纳入分类表深入展开。
