# 联动检索规则：历史同类公告 + 关联公告

单看一条公告容易漏掉真正的信号——同类公告的历史节奏、和这条公告"联动"的其它类型公告，往往才是解读的关键切入点。**这一步是必做步骤，不是可选项**：无论是单条深度解读还是批量监控摘要，定位完公告类型后，都要先跑一遍本文件的联动检索，再进入 playbook 的深度分析。

## 一、历史同类公告检索（纵向）

对于任意一条公告，先检索该公司过去若干次同类型公告，建立时间序列基准：

- **业绩类**：拉近 4~8 个报告期/预告的数字（营收、净利润、增速），判断这次是延续趋势、拐点，还是节奏突变。只看单期数字容易误判"好"或"差"。
- **股权变动类**：拉近该股东/董监高过去 6~12 个月的增减持记录，判断这次操作是"新动作"还是"既有计划的延续执行"；连续多次同方向操作（如连续增持）比单次操作的信号强度更高。
- **重大合同/并购类**：检索该公司是否有同类型交易的历史（如是否经常签署类似的战略合作协议但少有落地），用于判断这次协议的"可信度基准"——如果历史上同类协议大多没有后续执行细节，这次也要留一份保留。
- **停牌/退市风险类**：检索该公司此前是否有过同类风险警示或停牌记录，判断这是初次出现还是反复出现的问题。
- **股权激励类**：检索该公司历史上推出过的股权激励计划（授予价格折让幅度、业绩考核指标的松紧程度、最终解锁比例是否达标），判断这次计划的考核门槛相比历史是更严格还是更宽松——历史上考核指标经常"精准达标"或"擦线通过"的公司，本次计划的可信度要打折扣。
- **监管问询类**：检索该公司历史上是否收到过问询函/关注函/监管工作函，以及历史回复的质量（正面回应还是打太极）、是否有其它监管处分记录（警示函等）——反复出现"回复质量差"或多次被问询/警示的公司，本次回复的可信度也要打折扣，且要在解读里指出这是孤立事件还是持续性的治理/披露质量问题。

## 二、关联公告检索（横向）——联动分析规则表

同一时间段内，某类公告出现时，习惯性地同步检索下表里列出的关联类型，因为它们经常互相印证或互相解释：

| 触发公告类型 | 应同步检索的关联公告类型 | 联动逻辑 |
|---|---|---|
| 业绩类（尤其连续向好/连续下修） | 股权变动类（增减持、回购）、董监高变动 | 业绩趋势是否有管理层/大股东的真金白银动作同步印证（如业绩向好时管理层是否在增持/回购，业绩下修时是否有股东减持或高管离职） |
| 重大合同/并购类 | 该交易对手方过往关联交易记录、后续是否有股权变动（如战略投资方借道增持） | 判断交易是否为独立商业行为还是伴随资本运作（如战略合作常伴随后续入股） |
| 股权变动类（大股东/董监高减持） | 近期业绩类公告、诉讼仲裁/风险提示类公告 | 减持是否发生在利空信息前后，是否有"提前知情"的时间线疑点 |
| 停牌/退市风险类 | 停牌前的重大合同/并购类公告、股权变动类公告 | 停牌原因是否与近期已披露事项相关，还是全新事项 |
| 融资类（定增/可转债） | 同期股权变动类（是否有认购方后续增减持）、业绩类（募资项目是否已有业绩兑现迹象） | 判断融资资金投向是否已经开始体现在经营数据里 |
| 治理变动类（董监高变动） | 近期业绩/风险提示类公告、股权变动类 | 变动是否发生在业绩下修或风险事件前后，判断是主动战略调整还是被动应对 |
| 股权激励类 | 近期业绩类公告（尤其业绩考核期的实际完成情况）、同期股价走势、董监高是否同步增减持 | 业绩考核指标是否卡在"刚好能达标"的水平；计划是否恰好在股价低点推出（关注授予价格相对当时市价的折让是否明显偏高） |
| 监管问询类（问询函/关注函及回复） | 问询函问的具体事项对应的实质类型公告（业绩/重组/股权变动/停牌退市/股权激励等，见 `playbooks/tier2-inquiry-letter.md` 的元类型路由）、同期股价走势、该公司历史问询/处分记录 | 问询函本身是监管主动施压的独立信号；回复质量（正面回应还是打太极）往往比问询函内容本身更值得解读；历史多次被问询/警示反映的是持续性问题 |

## 三、联动检索的产出方式

- 联动检索的结果不需要单独成篇，而是作为解读正文里"与已知信息的关系""多视角分析"部分的支撑证据（对应 `output-formats.md` 里单条深度解读的第 4、5 项）。
- 如果联动检索没有发现关联信号（如查了股权变动记录但近期没有相关操作），也要在正文里明确说"未发现同期联动动作"，而不是略过不提——"没有联动信号"本身也是一个有信息量的结论。
- 批量监控摘要模式下，联动检索主要用于决定"哪条摘要需要在 `重点标注` 里加长"（见 `output-formats.md` 第二节第 3 项）。

## 四、股价阶段表现检查与关联动态时间线（条件触发）

这是一个**通用能力**，适用于所有 Tier 1/2 类型的公告（不局限于某一类 playbook），检查这条公告发布前后股价是否有异常反应，如果有，就把"这条公告 + 联动公告 + 公司互动平台回复 + 股价走势"整合成一张时间线图，帮助判断股价异动到底是被哪个具体信息驱动的。

### 4.1 先判断，再决定是否展开（不要跳过判断本身）

用 `seed_finance_search` 拉取该股票公告发布日前后的价格和成交量数据，按以下任一标准判断是否"明显偏离常态"：

- **单日涨跌幅异常**：公告发布当日或次日涨跌幅达到或接近涨跌停限制（A 股主板 ±10%、创业板/科创板 ±20%）；港股/美股无涨跌停限制的，用"当日涨跌幅是否超过近 3 个月日均波动率的 2～3 倍"判断。
- **累计涨跌幅异常**：公告发布后 5 个交易日内累计涨跌幅超过 ±8%~10%。
- **成交量/成交额异常**：公告发布当日或次日成交量相对近 20 个交易日均值放大超过 2 倍。

三条只要满足一条，就判定为"值得展开"；都不满足，说明股价反应平淡，**不需要**做后面的时间线整合，正常按第一到第三节的联动检索结果直接写解读即可——不要为了"显得全面"而不管股价反应如何都强行画一张图。

### 4.2 触发后：整合关联动态时间线

判定为"值得展开"后，整理一张按时间顺序叠加以下四类信息的时间线：

1. **本条公告**本身的发布日期。
2. **联动公告**：按本文件第二节联动规则表检索到的关联类型公告，各自的发布日期。
3. **公司投资者互动平台回复**：上证e互动/深证互动易等平台上，公司就相关事项的回复日期（如果检索到有影响力的回复）。
4. **股价走势**：覆盖从最早一个相关事件到当前的价格序列（不要只画公告当天一个点，要能看出走势的前因后果）。

把这四类信息按时间顺序整合后，用于回答一个具体问题：**这次股价异动，是被这条公告本身驱动的，还是被同期的其它信息（联动公告、互动平台回复）驱动的，还是几个因素叠加的结果？** 不要笼统归因于"这条公告"，如果时间线显示异动主要发生在另一个事件之后，要如实说明。

呈现方式：这张时间线图用 `scripts/render_charts.py` 的 `event_timeline` 图表类型生成（价格曲线 + 分类着色的事件标注），具体规范见 `output-rendering.md`。
