# 证据与口径

## 资料是否适用于当前判断

读取关键结论所依赖的原文及其上下文，保留主体、事项或指标、期间、单位、公开时间和可定位的出处。公开时间决定历史时点能否使用，报告期间或事项发生时间不能代替公开时间。来源只给日期而任务精确到时刻时，保留可用性的边界。

按本题要求选择来源。封闭材料题不因附件含网址就扩大检索；允许检索时优先正式披露，二手资料注明性质。交易所互动平台、公司认证社交账号代表公司口径但不是正式披露，与公告冲突时以公告为准并指出不一致；评论区和自媒体只用来发现市场在质疑什么，不作为事实，也不量化成“多少投资者认为”。材料未收到、读取受阻、尚未完成检索和原文未披露是不同情况，不能互相替代。

## 条款和状态如何连接

两份公告说法不同时，先辨明它们各自的生效范围。一份已生效的替代方案以新文本为准；如果只是局部修订，沿用仍然适用的条款。不能确定哪份有效时，列出冲突出处，说明它会改变哪项判断。

金额与比例必须对应同一主体、权利义务和适用范围。计算前明确所用报表、交易或合同定义；不同定义的数值不能仅改标签后直接比较。需要转换口径时，说明原始输入、转换关系和适用前提，无法可靠转换时保留差异。

## 证据能支持多强的结论

将披露事实、公司解释、自算和假设分别说明。公司对影响的概括不代替研究推理，推断也不能改写成公司已确认的事实。未找到证据不证明事项不存在；相反，有关联或可能性也不足以证明已经实现。

说明每个重要结论由哪些事实支持、还有哪些必要条件，以及现有材料是否足以作出判断。不编造来源、数据或执行记录，不用无依据的精确数字掩盖不确定性。
