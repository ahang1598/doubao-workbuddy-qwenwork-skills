# Output Contract

## Expected Deliverable

私域营销与用户运营方案，包含目标与合法基础、生命周期分层、标签和触发信号、用户旅程、内容与权益、社群 SOP、自动化规则、指标口径、实验、风险门禁和复盘动作。

## Required Sections

- 目标与合法基础
- 生命周期分层
- 标签与事件 Schema
- 旅程与触发
- 内容与权益
- 频控与抑制
- 指标与实验
- 社群定位与规则
- 成员旅程
- 内容节奏
- 活动执行表
- 服务话术
- 风险升级
- 复盘指标
- 数据与授权审计
- 流程诊断
- 旅程表现
- 疲劳与投诉
- 修复优先级
- 实验设计
- 监控与回滚

## Completion Rule

Deliver every applicable section, label unknown information, and end with concrete next steps. Do not claim an artifact, source check, calculation, or tool execution that did not occur.
