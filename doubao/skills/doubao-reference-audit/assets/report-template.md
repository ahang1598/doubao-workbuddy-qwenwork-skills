# 《论文标题》学术引用审查书

> **审查结论：** 用一至两句话说明引用体系的总体情况、最重要风险以及投稿前建议。结论明确但不过度承诺。

| 审查对象 | 信息 |
|---|---|
| 论文标题 | 《论文标题》 |
| 稿件类型 | 期刊论文 / 会议论文 / 学位论文 / 研究报告 |
| 审查重点 | 真实性、题录、文内—文后对应、主张—证据匹配、版本与来源风险 |
| 审查日期 | YYYY-MM-DD |

---

## 一、执行摘要

用简洁、专业的语言概括：

- 引用体系的整体可靠性；
- 最值得作者关注的实质性问题；
- 是否存在影响核心论证、研究归属、复现性或投稿可信度的风险；
- 建议作者优先完成的修改。

本节面向希望快速理解结果的作者、导师或项目负责人。避免罗列检索过程和大量正常项。

## 二、投稿前优先行动

### 优先行动｜行动标题

说明需要修改什么、为什么优先，以及最直接的处理方式。根据实际发现保留最有价值的行动，不固定数量。

## 三、核心发现

### 发现｜能够准确概括问题的标题

**稿件位置**

章节、页码、段落、句子或引用编号。

**稿件原文**

> 摘录能够识别问题的最小必要原文。

**专家判断**

清楚说明这是错引、部分支持、过度推断、范围扩大、二手转引、版本问题，还是其他实质性风险。

**来源实际表明**

给出能够回答当前问题的最小充分证据。必要时说明研究对象、方法、样本、实验条件、结论方向或适用范围。

**为什么重要**

说明它会怎样影响论文的论证强度、研究归属、结果解释、可复现性或投稿判断。

**建议修改**

给出作者可以直接执行的方案，例如收窄措辞、拆分句子、更换来源、补引原始研究、修正题录或补充限定条件。

**核验来源**

- [权威来源名称](https://example.com)

---

重要问题可以充分展开，轻微问题可以简洁表达。不要为了统一篇幅牺牲判断质量。

## 四、题录、版本与来源问题

集中说明不需要展开成完整核心发现、但仍值得作者修正的问题。

| 引用 | 问题 | 建议 |
|---|---|---|
| [编号或作者—年份] | 年份、作者、题名、载体、卷期页、DOI、版本或来源问题 | 直接可执行的修正方式 |

没有相关问题时删除本节，不生成空表。

## 五、引用结构观察

根据论文实际情况，概括具有整体意义的现象，例如：

- 文内引用与文后条目的对应情况；
- 组合引用是否清晰；
- 是否过度依赖综述、网页或非权威来源；
- 数据集、软件和方法来源是否规范；
- 是否存在未使用、重复或位置不清的参考文献；
- 不同章节的引用密度和证据质量是否失衡。

只写具有解释价值的观察，不把扫描结果逐条倾倒给用户。

## 六、已确认可靠的代表性引用

如有必要，可选择少量对核心论证重要且经过深入核查的引用，说明其为什么能够支持论文表述。这一节不是为了列出所有正常文献，没有必要时删除。

## 七、总体修改建议

从全文层面归纳作者下一步应如何改善引用体系，例如：

1. 哪类强主张需要降低措辞或补充直接证据；
2. 哪些二手来源应回到原始研究；
3. 哪些组合引用需要拆分；
4. 哪些版本、数据集或软件信息需要统一；
5. 哪些题录错误可以批量修正。

## 八、审查范围与证据边界

简要说明：

- 本次审查使用了哪些论文材料；
- 审查覆盖了哪些类型的问题；
- 判断主要使用了哪些层级的证据；
- 哪些来源因公开访问、授权或材料完整性限制而无法充分判断；
- 本报告不替代对实验数据真实性、统计分析或研究伦理的专项审计。

> 工作流程完成不等于论文自动“通过审计”。未发现明显问题，也不代表不存在任何引用风险。

---

## 模板使用说明

- 本模板用于组织最终报告，不是必须逐项填满的表单。
- 可根据论文类型、用户关注点和真实发现调整标题、合并章节或删除空章节。
- 核心发现优先展示具有明确证据和修改价值的问题。
- Markdown 是飞书文档的内容底稿；转为飞书后保持信息层级、来源链接和重点结论一致。
- 不展示内部检索日志、状态字段、工作流编号或为了体现工作量而生成的大量正常项。
