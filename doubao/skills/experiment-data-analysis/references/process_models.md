# PROCESS 模型选择与解读指南

## 模型选择决策树

```
有中介变量 M？
├─ 无 → 直接做 ANOVA/回归
└─ 有
   ├─ 有调节变量 W？
   │  ├─ 无 → Model 4（简单中介）
   │  └─ 有
   │     ├─ W 调节哪条路径？
   │     │  ├─ 只调节 a 路径 (X→M) → Model 7
   │     │  ├─ 只调节 b 路径 (M→Y) → Model 14
   │     │  ├─ 调节 a 和 c' 路径 → Model 8
   │     │  ├─ 调节 b 和 c' 路径 → Model 15
   │     │  └─ 调节 a 和 b 路径 → Model 9
   │     └─ 有两个调节变量 W, Z？
   │        ├─ 都调节 a 和 c' → Model 12
   │        ├─ W 调节 a, Z 调节 b → Model 11
   │        └─ W/Z 调节 a/b/c' 的不同组合 → Model 13/17/18/19/20/21
   └─ 有多个中介？
      ├─ 并行中介 → Model 4（多M）
      └─ 链式中介 → Model 6
```

## 本脚本支持的模型

| 配置 | W | Z | 对应模型 |
|---|---|---|---|
| mediation.W=null, Z=null | — | — | Model 4 简单中介 |
| mediation.W=X2, Z=null | 1个 | — | Model 8（W调节a和c'） |
| mediation.W=X2, Z=X3 | 2个 | | Model 12（W/Z调节a和c'） |

## 三层递进检验（被调节的中介）

### Step 1: 交互项显著性

在预测 M 的回归中，检验 X×W（及 X×Z、X×W×Z）系数是否显著。
- p < .05 → 调节效应初步成立，继续 Step 2
- p > .05 → 调节不成立，应退回 Model 4 简单中介

### Step 2: Index of Moderated Mediation（终极判决书）

- Index = a_交互 × b（交互项的a路径系数 × b路径系数）
- 必须看 Bootstrap 5000 次的 95% CI
- CI 不含 0 → 被调节的中介整体成立
- CI 含 0 → 被调节的中介不成立，即使个别条件间接效应显著也不能宣称调节

### Step 3: 条件间接效应

在调节变量的不同水平（通常0和1）下，分别报告间接效应 a×b 的 Bootstrap CI：
- CI 不含 0 → 该条件下中介效应显著
- CI 含 0 → 该条件下中介效应不显著

## 注意事项

1. **Index 不显著但个别条件间接效应显著**：只能作为探索性发现，不能写"被调节的中介成立"
2. **分类自变量必须编码为0/1**：系数解释为"从参照组到实验组的变化"
3. **多因素设计（2×2×2）**：以理论核心变量为 X，其余为 W/Z；可轮流以每个变量为 X 各跑一遍
4. **Bootstrap 次数**：正式报告至少5000次，建议10000次
5. **b 路径不随调节变量变化**：Model 7/8/12 假设 b 路径固定（M→Y 不受 W 调节）；若理论认为 b 也被调节，需用 Model 14/15
