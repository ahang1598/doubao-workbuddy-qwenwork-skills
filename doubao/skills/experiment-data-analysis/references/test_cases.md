## 执行规则

1. 每题至少记录输入、预期路由、实际路由、能力声明、实际输出、判定和 badcase。
2. 触发一致性题至少独立运行三次；未运行前保持 `PENDING`。
3. 涉及脚本的题保存命令、依赖版本、随机种子、完整 stdout、stderr、退出码和产物校验值。
4. 至少五题做 no-skill 同题基线，不用主观描述代替原始输出。
5. 参与者数据必须有授权、脱敏和最小化记录；不能提供真实数据时使用可公开生成且固定种子的合成数据。
6. 本次返修不执行 `scripts/exp_analysis.py`，下列结果均不得预填为通过。
