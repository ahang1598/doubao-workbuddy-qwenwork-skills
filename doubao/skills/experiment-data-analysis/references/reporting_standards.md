# 结果报告规范（APA 风格）

## 信度

- 报告格式：`Cronbach's α = .XX`
- 评价标准：≥.90 优秀；≥.80 良好；≥.70 可接受；≥.60 偏低需说明；<.60 不可接受
- 多题项量表必须报告α；单题项不需要

## 操纵检验

- 独立样本 t 检验：`t(df) = X.XX, p = .XXX, d = 0.XX`
- 操纵检验不通过时必须在报告中明确说明，并讨论其对结果解释的影响
- 间接操纵检验（如能动性归因）可作为补充证据，但不能替代直接操纵检验

## ANOVA

- 报告格式：`F(df_between, df_within) = X.XX, p = .XXX, η²p = .XX`
- 主效应：`A的主效应显著，F(1, 296) = 5.23, p = .023, η²p = .018，实验组(M=4.50)高于控制组(M=4.10)`
- 交互效应：`A×B交互显著，F(1, 296) = 4.12, p = .043, η²p = .014。简单效应分析显示……`
- 不显著：`p = .234`（不要写 p = ns，给具体值）
- 边缘显著：标注 † 并写 `p = .076`

## 简单效应

- 2×2：`在B1条件下，A的效应显著，t(148) = 2.34, p = .021, d = 0.38；在B2条件下不显著，t(152) = 0.45, p = .653`
- 必须使用 Bonferroni 校正（多组比较时）或在脚注说明

## 中介分析

- b路径：`拟人化感知显著正向预测满意度，B = 0.63, SE = 0.05, t = 11.69, p < .001`
- 间接效应：`间接效应 = -0.20, 95% CI [-0.33, -0.03]，CI不含0，中介效应显著`
- Index of Moderated Mediation：`Index = 0.14, 95% CI [-0.28, 0.54]，CI含0，被调节的中介不成立`
- 条件间接效应：`在W=1条件下，间接效应 = 0.33, 95% CI [0.02, 0.67]，显著；在W=0条件下不显著`
- **间接效应只报告Bootstrap CI，不报告p值**

## 显著性标记

| 标记 | 含义 |
|---|---|
| *** | p < .001 |
| ** | p < .01 |
| * | p < .05 |
| † | p < .10（边缘显著） |

## 均值与标准差

- 格式：`M = 4.31, SD = 0.99`
- 表格中同时报告 n
- 7点量表均值保留2位小数

## 报告结构建议

1. 信度分析
2. 操纵检验
3. 描述统计（各单元M/SD/n）
4. 主分析（ANOVA决策树 + 简单效应 + 交互图）
5. 中介分析（三层递进）
6. 简要结论
