# 操纵检验（Manipulation Check）分析路径

## 三种情境与对应方法

### 情境1：基础单因素（1个IV，2个或多个水平）

#### 2个水平（实验组 vs. 控制组）
- **方法**：独立样本 t 检验
- **成功标准**：p < .05，且两组均值方向符合预期
- **方向检验**：不能只看p值，必须确认实验组的感知得分确实高于/低于控制组
- **配置**：`"expected_direction": "high"`（iv=1组应更高）或 `"low"`

#### 3个及以上水平（低/中/高）
- **方法**：单因素 ANOVA + Tukey HSD 事后检验
- **成功标准**：整体 p < .05，且事后检验证明相邻组别差异显著
- **注意**：如果"高 vs 中"不显著但"高 vs 低"显著，说明操纵不够精细，需讨论

### 情境2：复杂多因素（2×2 / 2×2×2 设计）

对**每一个**操纵检验变量分别跑一次全因素 ANOVA。

#### 三条成功标准（极其重要）

1. **主效应精准命中**：A的操纵检验得分只能被A显著影响；B的操纵检验得分只能被B显著影响
2. **无交叉污染**：A不能显著影响B的检验得分，反之亦然（p > .05）
3. **无交互作用**：A×B在操纵检验上不应显著（p > .05），否则说明两个操纵在心理机制上"串味"了

#### 解读
- 如果A的检验题被B显著影响 → 操纵不干净，被试可能通过B的条件推断出了A
- 如果A×B交互显著 → 两个操纵的效果相互依赖，需要重新审视实验材料
- 间接操纵检验（如能动性归因）可作为补充，但不能替代直接检验

### 情境3：分类变量检验（Categorical Check）

- **方法**：卡方检验（χ²）+ 各组正确率
- **成功标准**：绝大多数被试（≥80%，严格标准≥90%）正确识别其所在组别的特征
- **适用场景**：客观事实检查（"你看到的广告背景是红色还是蓝色？"）、注意力检查
- **配置**：`"type": "categorical"`, `"correct_values": {"0": 0, "1": 1}`, `"correct_threshold": 0.80`

## 配置示例

```json
"manipulation_checks": [
  {
    "iv": "X1",
    "check_var": "thinkingprocess1",
    "label": "机器人呈现了思考过程",
    "type": "continuous",
    "expected_direction": "high"
  },
  {
    "iv": "X2",
    "check_var": "task1",
    "label": "任务是机械工具性任务",
    "type": "continuous",
    "expected_direction": "low"
  },
  {
    "iv": "X1",
    "check_var": "color_recall",
    "label": "广告背景颜色识别",
    "type": "categorical",
    "correct_values": {"0": "red", "1": "blue"},
    "correct_threshold": 0.90
  }
]
```

## 操纵检验失败时的处理

1. **如实报告**：在论文中明确说明哪些操纵检验未通过
2. **讨论影响**：操纵检验不通过意味着自变量效应可能被低估（回归均值），解释结果时需谨慎
3. **检查原因**：天花板/地板效应（均值接近量表端点）、操纵太弱、检验题不敏感
4. **间接指标**：如有间接操纵检验（如本研究中的能动性归因），可作为补充证据报告
5. **不应**：操纵检验失败但仍按预期解释结果，或删除失败的检验题不报
