# ANOVA 决策树与简单效应分析

## 决策树（必须严格按此顺序执行）

```
Step 1: 看最高阶交互效应
│
├─ 显著 (p < .05)
│  └─ 🔴 停止解释所有主效应和低阶交互！
│     执行简单效应分析（Simple Effects）
│     ├─ 2×2设计：在B的每个水平下检验A，在A的每个水平下检验B
│     ├─ 2×2×2设计：在B×C的每个水平组合下检验A（简单简单效应）
│     └─ 绘制交互作用图
│
├─ 边缘显著 (.05 ≤ p < .10)
│  └─ 按探索性处理，可做简单效应但需明确标注"边缘显著"
│
└─ 不显著 (p ≥ .05)
   └─ 忽略该交互，降级检查下一阶交互
      │
      ├─ 低阶交互显著 → 对该交互做简单效应分析
      └─ 所有交互不显著 → Step 2: 检查主效应
```

## Step 2: 主效应解读

| 变量水平数 | 主效应显著 | 主效应不显著 |
|---|---|---|
| 2个水平 | 直接比较两组均值，得出谁高谁低 | 该自变量对DV无显著影响 |
| 3+个水平 | 必须做事后检验（Tukey HSD / Bonferroni） | 该自变量对DV无显著影响 |

## 效应量报告标准

| 指标 | 用途 | 报告位置 |
|---|---|---|
| η²p (partial eta squared) | ANOVA 各效应 | ANOVA 表 |
| Cohen's d | t 检验/两组比较 | 简单效应、操纵检验 |
| R² | 回归模型整体 | 中介分析 |
| Bootstrap 95% CI | 间接效应 | 中介分析（不报p值） |

## 交互作用图绘制规范

- X轴：一个自变量（通常是核心IV）
- 不同线条/颜色：另一个自变量
- 面板(facet)：第三个自变量（2×2×2设计）
- 误差棒：95% CI 或 ±1 SE
- 线条交叉 = 交互存在；线条平行 = 无交互

## 常见错误

1. ❌ 交互显著时仍解释主效应（"A的主效应显著，说明……"）
2. ❌ 三因素交互不显著时直接解释二因素交互而不先检验二因素交互
3. ❌ 2水平变量显著后还做事后检验（不需要，只有两组）
4. ❌ 3+水平变量显著后不做事后检验（不知道哪两组有差异）
5. ❌ 只报p值不报效应量
6. ❌ 边缘显著(p=.07)当作显著报告而不标注
