# Output Contract

## Expected Deliverable

可实施的提示词或工作流设计稿，包含目标与成功标准、假设和证据、输入输出契约、提示词或步骤定义、状态与异常处理、评测矩阵、上线验证和迭代计划。

## Required Sections

- 目标与成功标准
- 假设与失败模式
- 最终提示词
- 输入输出契约
- 测试集与判定规则
- 使用与迭代说明
- 流程概览
- 步骤与状态定义
- 能力接口与 Schema
- 证据和检查点
- 异常与恢复
- 验证与上线计划
- 现状与证据
- 问题清单
- 优先级
- 修订方案
- 验证矩阵
- 回滚条件

## Completion Rule

Deliver every applicable section, label unknown information, and end with concrete next steps. Do not claim an artifact, source check, calculation, or tool execution that did not occur.
