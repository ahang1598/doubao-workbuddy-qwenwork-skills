# M07 向其他处理者提供个人信息

## 法律依据

### 本模块涉及的主要法律条款

**《中华人民共和国个人信息保护法》**

**第二十三条【向其他处理者提供个人信息】**
> 个人信息处理者向其他个人信息处理者提供其处理的个人信息的，应当向个人告知接收方的名称或者姓名、联系方式、处理目的、处理方式和个人信息的种类，并取得个人的单独同意。接收方应当在上述处理目的、处理方式和个人信息的种类等范围内处理个人信息。接收方变更原先的处理目的、处理方式的，应当依照本法规定重新取得个人同意。

**第五十五条【个人信息保护影响评估的情形】**
> 有下列情形之一的，个人信息处理者应当事前进行个人信息保护影响评估，并对处理情况进行记录：
> （一）处理敏感个人信息；
> （二）利用个人信息进行自动化决策；
> （三）委托处理个人信息、向其他个人信息处理者提供个人信息、公开个人信息；
> （四）向境外提供个人信息；
> （五）其他对个人权益有重大影响的个人信息处理活动。

---

## 模块概述

审查个人信息处理者向其他处理者提供其处理的个人信息时，是否取得单独同意、履行告知义务并开展影响评估。

## 审计内容与方法

### 7.1 个人信息对外提供情形下的单独同意

**审计内容**：
基于个人同意处理个人信息的，是否取得个人的单独同意。

**审计方法**：
1. 查阅向其他个人信息处理者提供其处理的个人信息的情况说明，验证存在哪些向其他个人信息处理者提供其处理的个人信息的情形；
2. 查验个人信息处理规则，是否告知向其他个人信息处理者提供其处理的个人信息的内容；
3. 查验征得个人同意的机制，是否符合取得个人单独同意的要求；
4. 抽查征得个人同意的实例记录，是否取得个人单独同意。

**审计证据参考**：
- 向其他个人信息处理者提供其处理的个人信息的情况说明
- 个人信息处理规则
- 征得个人同意的机制
- 征得个人同意的实例记录等

### 7.2 个人信息对外提供前的告知

**审计内容**：
是否向个人告知接收方的名称或者姓名、联系方式、处理目的、处理方式和个人信息的种类，法律、行政法规规定应保密或者不需要告知的除外。

**审计方法**：
1. 查验个人信息处理规则，是否包含向其他个人信息处理者提供其处理的个人信息的内容；
2. 查验向其他个人信息处理者提供其处理的个人信息时，是否向个人告知接收方的名称或者姓名、联系方式、处理目的、处理方式和个人信息的种类。

**审计证据参考**：
- 向其他个人信息处理者提供其处理的个人信息的情况说明
- 个人信息处理规则
- 告知机制
- 告知文案等

### 7.3 个人信息对外提供前的个人信息保护影响评估

**审计内容**：
是否事前进行个人信息保护影响评估。

**审计方法**：
1. 查阅向其他个人信息处理者提供其处理的个人信息的情况说明，验证存在哪些向其他个人信息处理者提供其处理的个人信息的情形；
2. 查验个人信息保护影响评估报告，是否对向其他个人信息处理者提供其处理的个人信息情形开展个人信息保护影响评估。

**审计证据参考**：
- 向其他个人信息处理者提供其处理的个人信息的情况说明
- 个人信息保护影响评估报告等

## 判定方法指引

### 数据来源单位义务的全链路追溯

在审计"向其他处理者提供个人信息"时，仅审查直接提供行为是不够的。当被审计方从第三方获取个人信息后再行处理或对外提供时，需追溯数据全链路中各环节主体的义务履行情况：

**追溯分析框架**：

```
数据来源方（A）→ 被审计方（B）→ 数据接收方（C）
     ↓                  ↓                  ↓
A的义务：              B的义务：            C的义务：
- 是否合法收集         - 取得数据时是否      - 接收后处理
- 是否有权提供           审核A的合法性         是否在约定
- 向个人告知了         - 再次提供给C时         范围内
  提供给B的事实         是否取得单独同意
                      - 是否向个人告知
                        接收方C的信息
```

**审计判断要点**：

1. **授权书/委托书审计**：当审计材料中包含个人信息处理授权书时，应审查授权书载明的个人信息来源和流转路径，判断上游（授权方/来源方）是否已合法取得个人信息、是否有权对外提供
2. **告知义务的链式传导**：个人信息每次流转至新的处理者，告知义务不因中间环节传递而消灭——最终处理者有义务确保个人知悉其信息被提供给了谁
3. **单独同意的适用判断**：向第三方提供（非委托处理）原则上需取得个人的"单独同意"（《个保法》第23条），但需区分：
   - 委托处理不需要单独同意（由M05覆盖）
   - 法定情形下的提供可豁免同意
   - 为订立或履行合同所必需的提供可能豁免

**与M04/M05的边界**：
- 若流转关系中双方共同决定处理目的 → 转入M04分析
- 若流转关系中一方仅按指令处理 → 转入M05分析
- 若一方独立决定目的、另一方提供数据 → 适用M07
