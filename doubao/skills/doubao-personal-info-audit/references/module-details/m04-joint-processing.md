# M04 与其他处理者共同处理个人信息

## 法律依据

### 本模块涉及的主要法律条款

**《中华人民共和国个人信息保护法》**

**第二十条【共同处理个人信息】**
> 两个以上的个人信息处理者共同决定个人信息的处理目的和处理方式的，应当约定各自的权利和义务。但是，该约定不影响个人向其中任何一个个人信息处理者要求行使本法规定的权利。
> 个人信息处理者共同处理个人信息，侵害个人信息权益造成损害的，应当依法承担连带责任。

---

## 模块概述

审查个人信息处理者与其他处理者共同处理个人信息时，是否明确约定权利义务、建立权益保护机制和安全事件报告机制。

## 审计内容与方法

### 4.1 各自权利义务的约定

**审计内容**：
是否约定各自的权利义务。

**审计方法**：
1. 查验共同处理个人信息情况说明，验证有哪些共同处理者；
2. 查验双方的个人信息共同处理合同、协议或相关条款，是否约定各自的权利义务；
3. 约定内容是否影响个人向其中任何一个个人信息处理者要求行使个人信息主体权利。

**审计证据参考**：
- 共同处理个人信息情况说明
- 个人信息共同处理合同
- 协议或相关条款等

### 4.2 个人信息权益保护机制

**审计内容**：
个人信息权益保护机制。

**审计方法**：
1. 查验共同处理个人信息情况说明，验证有哪些共同处理者；
2. 查验双方的个人信息共同处理合同、协议或相关条款，是否约定个人信息权益保护机制；
3. 查阅个人信息保护管理制度，验证是否明确针对共同处理个人信息的个人信息权益保护机制；
4. 抽查个人信息权益保护机制，通过穿行测试等方式验证是否有效。

**审计证据参考**：
- 共同处理个人信息情况说明
- 个人信息共同处理合同
- 协议或相关条款
- 个人信息保护管理制度等

### 4.3 个人信息安全事件报告机制

**审计内容**：
个人信息安全事件报告机制。

**审计方法**：
1. 查验共同处理个人信息情况说明，验证有哪些共同处理者；
2. 查验双方的个人信息共同处理合同或协议，是否约定个人信息安全事件报告机制；
3. 查阅个人信息保护管理制度，验证是否明确针对共同处理个人信息的个人信息安全事件报告机制；
4. 抽查个人信息安全事件报告机制，通过穿行测试等方式验证是否有效。

**审计证据参考**：
- 共同处理个人信息情况说明
- 个人信息共同处理合同或协议
- 个人信息保护管理制度等

## 判定方法指引

### "不涉及"判定路径

M04 模块仅在被审计方存在"共同决定处理目的和处理方式"的情形时适用。以下情形不构成"共同处理"，应判定为"不涉及"：

1. **纯委托处理关系**：被审计方将数据交由服务商处理，但处理目的和方式完全由被审计方单方决定，服务商无权自主决定处理目的→ 属于 M05（委托处理），非 M04。
2. **单向数据提供**：被审计方向第三方提供数据，第三方独立决定后续处理目的和方式→ 属于 M07（向他人提供），非 M04。
3. **技术集成但无共同决策**：被审计方集成第三方 SDK 或 API，但处理目的由各方独立决定、不共同协商→ 需进一步分析是否构成"共同决定"，不能仅因技术集成即认定共同处理。

### 区分"共同处理"与"委托处理"的分析要素

| 分析维度 | 共同处理（M04适用） | 委托处理（M05适用） |
|---------|-------------------|-------------------|
| 处理目的决定权 | 双方/多方共同决定 | 委托方单方决定 |
| 处理方式决定权 | 双方/多方共同协商 | 委托方指定，受托方执行 |
| 对外责任 | 连带责任 | 委托方承担主要责任 |
| 典型场景 | 联合运营、数据合作分析 | 云服务商代存储、外包客服 |

**关键判断原则**：判断的核心在于"谁决定了处理目的"——如果多方共同决定了为什么要处理这些数据以及如何处理，即构成共同处理；如果一方仅按另一方指令执行，则为委托处理。
