# 学术研究

**视觉参考**：可参考顶尖高校学术模板、成熟 Beamer 主题、权威科研期刊图版和高水平学术会议演示的共通特征，但不要机械模仿具体模板；应提炼其背后的视觉原则，理性、克制、清晰、可信，强调严谨的信息层级、充足留白、稳定网格、低饱和配色和高质量图表整合能力
**用户上传ppt附件原则**：用户附件内有要求参考的pptx模板没有合适的可以直接使用的页面时按照当前设计系统的指导搭建，并参考 `workflow/template-editing.md`工作流。


## 目标

### 叙事：第一分钟就抓住价值；进度始终可见
遵循「研究背景、证据缺口、研究问题、实验假设、核心证据、结论、贡献」的叙事逻辑——让评委/导师在第一分钟内就把握到价值所在。

通过合理的章节规划、在关键位置增加过渡页、把导航栏内建进正文骨架等方法，让评委/导师随时了解演示文稿的进度。

### 视觉：简约而不廉价
学术场景下的演示文稿往往朴素，但朴素不等于简陋，更不等于廉价。使用恰当、精致的颜色——在精神气质上意料之中，在具体选择上意料之外——搭配精心的排版，营造高级感。
1. **保持极简风格**：装饰元素与装饰图片只允许用于封面页、章节过渡页、结尾页、页面背景图等区域；严禁用装饰图片来填充正文区域。图标也不是填补留白的万能药——只有当添加图标能带来明确收益时才使用。
2. **高级感来自精细的细节设计**：统一的页面骨架、标注数据来源与参考文献的脚注标记、图与表的图注、恰当的页码、精心设计的字号层级与字体……
3. **反常规高端配色**：
  - 当用户精确提到某个学校/机构/组织名称/会议名称/期刊名称时，必须下载官方 logo，用 logo 的主色作为主色，并在合理位置插入 logo。若无法获取 logo，则不要使用 logo 的主色，以免出现偏差。
  - 拒绝本场景中最常见的配色：不能使用医院蓝、医疗绿、环保绿、海洋蓝等颜色
  - 除非用户明确要求，否则不要使用粗糙、简陋的黑、白或浅蓝背景；向更精致的背景靠拢，例如钛灰 #E7E8E5、档案纸 #F1E9DA 或象牙纸 #F7F3E8。
4. **大字号下的高密度**
  - 学术演示文稿应在恰当字号下保持高密度，同时保留一些呼吸空间。不同于行业研究与金融的小字号与单倍行距，学术研究的正文应使用更大的字号（10 以上）与合适的行距（1.3 左右），除非交付物是学术海报之类的阅读型产物。同时，它应具备行业研究与金融那样的「饱满感」：区域之间留出一些呼吸空间，但每个区域内部要填满。
  - 严禁出现规划了 100px 的区域最终只放下 70px 内容的情况。
5. **严谨精细的排版**：禁止卡片布局，需要使用视觉密度合适的排版，用线段、留白以及字体/字号差异展示信息差异。长段文字之后应该空一行，再写下一段，不要大段的堆砌。


### 从研究领域出发；考虑视觉焦点
不同研究领域的学术演示文稿各有侧重：思考该领域真正重要的是什么，并决定每一页应聚焦于什么。
- 基础研究与理论推导：公式、定义、命题与证明步骤是焦点；严谨、完整的推理过程占据大面积区域。
- 计算机科学与工程：系统图、代码、运行轨迹、消融实验与性能曲线构成页面骨架。
- 实验研究：研究图、图像与表格是焦点。属于同一研究结论的公式、图表、表格与图像应尽可能紧凑。
- 实证分析：本质上也是实验研究，但社会科学的工作应比理工科的工作更具叙事性。
- 人文/建筑/艺术：档案、地图、手稿、图像细节、时间线索与文本证据……除了学术严谨性之外，还应有品牌级别的精致——必须读一遍 `brand-storytelling.md`。
- 使用形状、线条与箭头作为标注，来强调或解释图表与图像的内容，但是注意禁止任何文字穿线现象，线条应该止于节点边缘
- 使用图片必须是能够辅助当页信息表达，优先使用附件内的真实图片，准确传达信息

## 禁止项

1. **默认禁止使用卡片**：除非用户明确要求，否则严禁使用圆角矩形或矩形卡片来构建层级或对齐：线段、留白以及字体/字号差异是更好的解决方案。
2. **禁止均分构图**：除非没有其他可用布局，否则不要默认采用三等分、四等分或 2×2 矩阵——包括「三栏 + 标题 + 结论」这类三段式套路。
3. **禁止平庸、常见或典型 AI 味的配色**：严禁任何蓝白搭配、蓝紫渐变、青紫霓虹、彩虹光晕、玻璃拟态卡片或发光边框——除非用户明确要求。
4. **禁止过小的字号**：除非用户要求，或交付物是阅读型产物（海报等），否则正文不得使用小字号。
5. **区域内禁止留白不足**：严禁出现任何内容无法填满其规划区域的情况。文本框填满还不够——从截图中看到的实际文本内容必须填满区域。填不满是最严重的一种粗糙，会让人感觉排版完全没有用心。
6. **禁止用默认图表设置**：严禁使用软件默认的坐标轴、网格线、图例框、彩虹配色、粗黑表格边框、3D 柱形、渐变填充、投影——必须全部重做；同一份演示文稿中所有图表使用同一色系深浅，不引入第二色族，但在饼图等多类别图表中，各图例颜色需明显可区分，优先保证识别性，避免颜色过近；
7. **禁止不合理截图**：附件素材内图表必须原汁原味使用，不得进行图片切割，应该让排版适应图片而不是图片适应排版。
8. **禁止不规范用图**：学术论文内的图片除了用于信息展示或者机构院 logo 之外不得重复使用，用图需要严谨，且避免信息被裁切。

## 视觉参考


### 自然科学与工程实验研究

**路由条件**：理工科实验研究（生命科学、物理、化学、材料科学、工程系统）；结果驱动、数据图表密集；会议海报或研究成果展示。

**核心特点**：实验室海报的秩序与张力——严格网格、巨大结论、大面积纯色色块与出血研究图像，比例强烈，安静但不保守。

**配色**：优先从研究领域或机构标识中提取一至两个主色，如果没有才能走下面的参考配色；色块使用大面积纯色，拒绝多彩；背景遵循通用配色规则（钛灰/档案纸/象牙纸）。

**参考配色**：
- 主题色苏木精紫 #684765 、辅助色伊红粉 #C9828B 或
- 主题色：暖棕灰（#7A6A58）；辅助色：灰褐（#6B6B67）和 暖灰（#B5B1A8）；背景色：米白（#EDEBE6）；标题文字色：深灰（#1A1A1A）；正文字色：中灰（#5B5A55）
- 主题色：深蓝（#0D1B2A）；辅助色：蓝灰（#64748B）和 琥珀金（#C9A66B）；背景色：雾白（#F7F7F8）；标题文字色：深蓝（#0D1B2A）；正文字色：蓝灰（#465667）。
- 灰蓝白（清冷学术）：主色 #3A506B，辅色 #5F7A94，点缀色 #B8C6D1，背景色 #FFFFFF，标题色 #3A506B，正文色 炭灰
- 石板绿（清冷学术）：主色 #4A5E4A，辅色 #7A8F7A，点缀色 #C4CFC0，背景色 #F2F4EF，标题色 #4A5E4A，正文色 炭灰
- 酒红 + 米灰（优雅红棕）：主色 #6B2C3E，辅色 #A85A6B，点缀色 #D4B8A8，背景色 #F0E8E0，标题色 #6B2C3E，正文色炭灰
- 深灰 + 金（深色底）：主色 #E8E4D9，辅色 #3A3A3A，点缀色 #C9A961，背景色 #1E1E1E，标题色 #E8E4D9，正文色 #E8E4D9（60% 透明度）


**字体**：无衬线体（黑体）；封面标题 64–88 pt，页面标题 36–48 pt，正文 16–19 pt，来源 9–11 pt。

**布局**：十二列网格；明显不对称比例，常见 3:9、4:8 或整页主图。

**研究图规则**：
- 主图占页面 60%–75%，完整保留坐标轴、误差棒、图例与来源。
- 摄影、显微图像与遥感图像可出血布局；标题置于不透明色块内，不直接压在图像上。
- 每页只突出一个结果。

**页面语法**：
1. 封面：出血研究场景图 + 主色纯色色块，图片要与色块之间蒙层过度，柔和高级的展示。
2. 目录：主题色编号 + 章节标题 22pt+ 一行说明 12pt 浅灰,三者左对齐，章节间加 0.5pt 浅灰细横线分隔，如果超过五个可以采用左右对称布局，合理缩小字体大小
3. 内容页：有节奏的展示研究图+内容，没有图不应加，两页间除非在讲同一个内容不要用一种排版方式。
4. 结果页：左侧巨大结论，右侧完整主图；下一页左右互换。
5. 局限性页：一条粗色线切分「已证实」与「尚未确定」。
6. 结尾页：回到封面色块比例，逐一回答研究问题。

**视觉母题**：不对称纯色色块 · 章节编号 · 页码 · 注记 · 参考文献脚注标记 · 页面边缘细刻度线

**禁止项**：
- 卡片、居中标题、柔和阴影
- 蓝白商务风
- 多彩图表配色
- 机构徽标放大为巨型水印

### 理工科院系答辩与正式学术报告

**路由条件**：学位论文答辩（硕士/博士）；课程汇报与研究报告；会议论文口头报告；需要展示机构标识（校徽/院系 logo）的正式学术演讲。

**核心特点**：正式院系答辩的秩序感——校色与徽标只做最小化身份识别，其余退居内容之后；公式、图与论证始终占据视觉中心。

**配色**：
- 有机构标识：从官方徽标提取主色，绝不凭记忆硬编；正文页校色面积 3%–8%，章节页可满铺。
- 无机构标识：从下面的配色选一个
1. 主题色：深炭灰（#2A2D30）；辅助色：森林绿（#4C7A5A）和 浅青绿（#DCE6D6）；背景色：象牙白（#F4F6F1）；标题文字色：深炭灰（#2A2D30）；正文字色：灰绿（#4D5A53）
2. 主题色：深蓝（#002FA7）；辅助色：浅灰（#B7B7B7）和暖灰白（#E8E4DC）；背景色：暖白（#F5F3EE）；标题文字色：黑色（#111111）；正文字色：深灰（#383838）。
3. 主题色：酒红（#7B2532）；辅助色：玫瑰棕（#A34450）和暖砂（#D4A59A）；背景色：雪白（#FFFFFF）；标题文字色：酒红（#7B2532）；正文字色：炭黑（#2D2D2D）。

**字体**：中文思源宋体；英文与公式可搭配学术衬线体或数学字体。封面标题 48–64 pt，页面标题 32–40 pt，正文 17–21 pt，图注与来源 9–11 pt；标题、正文、图注、脚注各保持固定基线。

**布局**：正文页设一条极细页眉/页脚横线，固定放置短标题、章节名与页码（或章节导航）。

**公式与表格规则**：
- 公式保留编号、条件与符号说明；关键推导可逐步呈现，但每页必须构成完整的局部论证。
- 表格优先采用三线表，只突出与结论直接相关的行与列。

**页面语法**：
1. 封面：小尺寸校徽/院系徽标 + 标题 + 作者/导师/院系/日期；一条校色细线建立身份识别，不用巨型水印。
2. 目录：主题色编号 + 章节标题 22pt+ 一行说明 12pt 浅灰,三者左对齐，章节间加 0.5pt 浅灰细横线分隔，如果超过五个可以采用左右对称布局，合理缩小字体大小
3. 章节页：整页校色或精致背景色，放章节编号、标题与一个研究问题；可搭配低调纹样装饰图。
4. 总结页：按研究问题逐条作答，每条后标注对应证据或章节编号。
5. 参考文献页：略小于正文但大于脚注的字号，按官方引用格式分栏或单栏排列。
6. 结尾页：保留校色与徽标，只呈现「Questions」或最终结论。

**视觉母题**：校色短线 · 固定标题基线 · 章节名 · 页码 · 图注 · 参考文献脚注标记

**禁止项**：
- 凭记忆伪造校色
- 徽标放大填留白、半透明徽标水印
- 蓝色渐变页眉、每页重复大面积色带
- 圆角信息卡片
- 无图注的图
- 为传统而挤压正文与图

### 人文社科与档案研究

**路由条件**：历史学、社会学、人类学、语言学、文学、艺术史、建筑史、考古学；以档案扫描件、手稿、地图、访谈录音或统计调查为核心证据材料。

**核心特征**：当代版式排印的档案研究特刊——暖色纸调、衬线体、页边批注与细分隔线构建骨架；图片作为证据呈现，不作为填充装饰。

**配色参考**：
- 主题色：深炭灰（#2A2D30）；辅助色：森林绿（#4C7A5A）和 浅青绿（#DCE6D6）；背景色：象牙白（#F4F6F1）；标题文字色：深炭灰（#2A2D30）；正文字色：灰绿（#4D5A53）
- 主题色：砖红（#C62828）；辅助色：银灰（#9B9B97）和近黑（#111111）；背景色：米白（#F5F4F0）；标题文字色：近黑（#111111）；正文字色：深灰（#373735）
- 主题色：深蓝（#002FA7）；辅助色：浅灰（#B7B7B7）和暖灰白（#E8E4DC）；背景色：暖白（#F5F3EE）；标题文字色：黑色（#111111）；正文字色：深灰（#383838）。

**字体**：中文标题与正文优先使用现代宋体（衬线体），引用原文字体使用楷体；编号、来源可用无衬线体或等宽字体。封面标题 48–68 pt，页面标题 34–44 pt，正文 17–20 pt，长引文 21–28 pt，图注与脚注 9–11 pt；行距 1.3–1.45。

**布局**：4:8 或 5:7 不等宽布局；窄边距放置日期、关键词、文献编号或批注；依靠留白与细线组织内容，不用卡片，不用复古花边框。

**规则**：
- 引用图注意不要裁剪，保留完整；强调时用细框、引导线与放大细节指出证据。
- 每张图标注作者、标题、日期、来源；每段访谈摘录标注受访者编号、时间与地点。
- 统计图表保持现代清晰，不叠加做旧质感；只用强调色突出与论证直接相关的数据系列。
- 长引文只摘录支撑论证的段落，旁附解释与出处；不整页堆砌原文，引文字体可以使用楷体。

**页面语法**：
1. 封面：学术专著扉页式标题 + 占 35%–50% 的档案/地图/艺术品细节图；附作者、机构、日期与卷/期式元信息。
2. 研究问题页：三到五行摘要式引言，页边列出地点、日期、对象与材料范围。
3. 文献综述页：沿时间或观点分歧组织文献，用细线连接学者、论点与回应关系——不堆砌作者卡片墙。
4. 档案证据页：左侧放大原件，右侧呈现转录/翻译/释读/出处；相同编号连接原件与分析。
5. 实证分析页：主图或主表占三分之二，另一侧放结论、变量说明与局限性。
6. 地图与时间页：一张主地图或一条主时间线；强调色只标记与论证相关的地点与事件。
7. 论证页：顶部一句判断句，其下依次铺陈文本证据、视觉证据与研究者释读。
8. 结论页：连续编号短段落回答研究问题，每段附对应的档案编号、图号或章节编号。

**视觉母题**：书页式页码 · 细脚注横线 · 书眉 · 档案参考编号 · 章节页签 · 统一图注格式

**禁止项**：
- 随意倾斜的剪贴画
- 低对比度正文
- 档案材料当作背景纹理
- 无来源的历史照片
- 卡片
