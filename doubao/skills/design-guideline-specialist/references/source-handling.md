# 来源读取规范

在读取品牌依据或待审资产时使用本参考。

## 通用原则

- 优先使用当前环境中最适合该来源的文件、文档、图片、网页或飞书读取能力。
- 保留文件名、相对路径、页码、章节、幻灯片、文档区块、记录 ID 和附件字段等定位信息。
- 布局、色彩、Logo 几何、安全距离或位置类规则必须进行视觉检查。
- 文本抽取、OCR 和视觉观察是互补证据，不得用其中一项无条件取代其他项。
- 只读到标题、摘要、缩略图或部分页面时，明确标记为“部分读取”。

## Logo 与标准图像

### 位图

- 使用原始分辨率检查。
- 记录画布尺寸、透明背景（如适用）、可见组合、文字与色彩。
- 单个 Logo 样图只能证明该样式存在，不能证明其他变体被允许。

### 矢量文件

- 尽量读取原始矢量信息或渲染为无损预览。
- 保留比例和透明度，不得在渲染时拉伸。
- 如果无法读取原始色值，不得从色彩管理不明的预览中声称得到了精确生产色值。

## 文档类来源

### PDF、Word 和 PPT

- 同时提取文本并渲染相关页面/幻灯片。
- 检查图片示例、标注、表格、例外和 Do/Don't 对比。
- 引用规则时保留页码、章节或幻灯片编号。

### Markdown 和纯文本

- 解析标题层级、强制性措辞、例外和链接的视觉示例。
- 必要视觉示例缺失或无法访问时，将相关规则标记为不完整。

## 本地文件和文件夹

- 审计前先建立清单。
- 只在用户要求或语境明确时递归读取子文件夹。
- 记录隐藏文件、不支持文件、重复文件和无法读取文件。
- 如果当前环境无权读取用户本地路径，请用户上传文件、打包文件夹或提供可访问链接。

## 飞书文档与知识库

- 读取文档区块、标题层级、表格、内嵌图片、附件和相关子内容。
- 规则依赖图像示例时，必须获取或渲染图像，不得只使用图片占位符。
- 审计文档内物料时，确认范围是内嵌原图、文档渲染页面，还是两者。位置和排版规则需检查渲染页面。
- 保留文档标题、章节或区块定位。

## 飞书多维表格

审计前确认：

- 多维表格、数据表和视图；
- 记录过滤条件；
- 需要检查的图片或附件字段；
- 是否检查同一记录中的所有附件。

保留记录 ID、主字段、字段名、附件名和版本信息（如有）。同一资产存在于多条记录时，可去重检查，但不得丢失记录引用关系。

## 网页与权限失败

- 优先读取用户指定的官方来源。
- 需要登录或权限时，使用可用的已授权能力；仍无法读取时，请用户授权、导出或上传。
- 说明具体哪些内容无法访问，以及哪些结论因此无法作出。
- 不得用搜索结果或非官方来源重建无法访问的官方规则。
