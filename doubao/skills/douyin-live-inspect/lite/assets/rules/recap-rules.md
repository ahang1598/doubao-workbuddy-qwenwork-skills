# 直播复盘规则

## 评价边界

复盘帮助主播和商家回看这场怎么卖、哪些地方讲得好、观众关心什么，以及下一场可以怎么讲。复盘不重新判定违规，只引用已完成的质检结论；表达不完整不等于违规，讲得流畅也不等于合规。

讲解评价基于本次字幕、已查看可引用画面和质检结果；观众评论另用于需求观察与行动建议。发现须有内容与时间依据，不补造缺失部分。抽检总结仅代表已提供窗口。

评论按合同总结观众需求，人数仅描述同期采样现象，不单独成立亮点。人数变化不作话术归因，不推断成交、转化或留人效果；缺失为未知。仅凭字幕不评价音色、音量、情绪感染力或视觉效果。

## 互动洞察与下一场行动

“复盘洞察与建议”必须同时查看整体讲解与可用互动，不把评论只放在独立统计模块。没有可用评论时说明范围，不编造需求。

当前仅提供评论总结，不执行评论与主播回答匹配，不评价已回答、部分回应、未回答或漏答率。

- **商品需求**：识别求上链接、求补货、希望售卖某款产品等表达，不因没有问号而忽略；区分想买哪款、规格诉求和普通提及。建议运营核对选品、补货或预告安排，不承诺实际上架。
- **集中疑问**：按同一商品及条件归纳常问的成分、规格、适用人群、价格权益、使用方式等；区分评论条数与提问人数。多条同一人的刷屏不称“很多人”，无法确定频次或仅有抽样时不称“全场最关注”。
- **情绪**：只分析已采集评论明确表达的认可、期待、疑惑或不满，用一句话概括主要倾向及触发原因；没有倾向性证据时写无法判断，不把普通提问当负面、不把未投诉当满意，也不从文字推断心理状态。排除已知主播/助播宣传与重复刷屏，不以少量评论外推全体观众。
- **购买意向**：用一句话归纳明确求购或上链接意愿、观望条件及购买顾虑；询价、点赞、人数和情绪积极不直接代表想买，“已买”只算评论自述，不当作真实订单或转化。尽量点明商品和可见阻碍；证据不足写无法判断，不编造意向比例或成交预测。
- **讲解与需求的差距**：从评论提炼高频疑问与购买顾虑，建议下一场前置说明、配贴片或置顶；不匹配回答，不推断主播忽略观众。
- **改进建议**：在 recommendations 中写主播下一次可以直接做的动作。帮助观众理解时，点出容易混淆的信息，再说明怎样用对比、实物或一句解释讲清；帮助购买决策时，把有依据的需求对应到可选规格、套餐、条件或购买入口。可引用同商品的观众原话；没有评论时也可依据讲解原文给建议。

示例（仅说明写法，次数和商品必须来自本任务）：观众多次询问某款是否补货 → 说明已采集的提及次数/人数及评论原文 → 建议核对补货计划并统一预告；某款“是否加糖”反复被问 → 建议在配料说明时前置回答，配合置顶说明。评论只证明观众表达了需求或疑问，不证明产品事实、需求规模、销量、转化或收益。

## 讲解质量维度

收到 clarifications 时，复盘还需核对原表述与现场纠正是否对应、在首页结论中点明仍待澄清或待核实的具体话题，在下一场建议中写清应补充的条件或依据。结论尽量一句话，有纠正证据的不得继续描述为完全未处理；ASR 疑点、采集缺口与明确问题分开，不自动撤销原风险，不由缺少记录推断没有纠错机制，不宣称系统已满足三年留存。

以下维度用于寻找有证据的优势与改进点，不逐项凑问题。是否适用取决于本段实际讲解对象和目的。

| 维度 | 讲得好的依据 | 值得改进的依据 |
|---|---|---|
| 话术结构与逻辑 | 引入需求、解释核心信息、说明条件、给出下一步，衔接自然 | 同一主题中前后跳跃、逻辑矛盾，或讲解结束仍未说明重点 |
| 产品/服务卖点表达 | 说明具体特点、用途、适用人群及限制，举例与对象相关 | 只有空泛形容和催促，关键特点含糊或不同版本混讲 |
| 促销与行动理由 | 优惠内容、参与条件和行动理由交代清楚 | 反复催促却不说明权益或条件；只评价表达，真实库存和优惠不靠口播自证 |
| 互动引导 | 提问具体，并在可见话术中围绕问题作出清楚回答 | 话术内明确提出的问题未得到回应，或回答偏离问题；没有评论数据不推断忽略观众 |
| 合规性 | 引用已有质检结论和证据 | 不另作合规判定；未命中不等于承诺真实，证据不足不等于违规 |
| 话术节奏与专业度 | 内容衔接清楚，术语解释易懂，重复用于强调或补充信息 | 连续重复没有新增信息，术语前后矛盾或表达难以理解；不把识别错误直接归咎于主播 |
| 售后/保障说明 | 适用的退款、质保、价保、运费或服务边界说清楚 | 在完整相关主题中提出保障承诺，却没有解释影响理解的适用条件 |
| 价格/优惠清晰度 | 价格、规格或套餐、优惠条件相互对应 | 同一对象价格前后不一致，优惠条件含糊，难以判断实际应付金额 |
| 行动指令清晰度 | 明确下一步做什么、到哪里操作，符合当前讲解目的 | 有行动要求但入口、步骤或对象不清楚 |

“缺失”必须限定证据范围：一个短片段没提到售后，不能推断全场没讲；非销售内容不强求报价和催单。上下文不完整时说明无法评价，不把缺少证据写成主播缺点。

## 类目适配

- 服装/鞋帽：关注面料、版型及适用参数；尺码与身高体重参照；适用的售后政策和发货时效。没有画面不评价上身展示。
- 软件/SaaS/数码会员/3C：关注功能与使用边界、版本或套餐差异、适用人群、试用退款及续费条件；没有产品依据不判断功能宣称真实。
- 食品：关注成分、配料、过敏原、保质期、储存和食用方法，以及适用的售后条件；功效是否违规引用质检结果。
- 美妆/护肤：关注成分与功效表达、适用肤质、使用步骤、注意事项及售后条件；不自行验证功效或认定医疗宣称违规。
- 金融：关注概念解释、费用期限、适用条件、限制及风险提示；不把刺激交易或收益承诺当作高光，合规风险引用质检结果。
- 汽车：关注车型配置、使用场景、价格权益条件、交付范围、质保及用车成本，试驾或咨询步骤是否清楚。
- 其他内容：按真实主题评价信息完整、逻辑清楚和表达价值，不强套商品或成交维度。

以下为表达示例，仅有完整主题改进依据时使用，不要求每段讲齐。括号内容来自已有资料，未知标明待核实；合规仍引用质检结果。

| 类目 | 可改进的表达 | 改写示例 |
|---|---|---|
| 服装/鞋帽 | 反复说“好穿，照着买”，已讲出的面料和尺码参照却散落难懂 | “这款面料是〔已知面料〕，版型为〔已知版型〕；我的身高、体重和试穿码数是〔实际参照〕，选码还需结合〔已有尺码表及适用条件〕。” |
| 软件/会员 | 功能、版本和购买条件混讲，难以分辨当前套餐 | “当前讲的是〔版本〕，支持〔功能〕；操作先〔必要步骤〕，再〔后续步骤〕。试用、退款及续费分别按〔已核实条件〕执行。” |
| 食品 | 已介绍配料和食用方法，但前后跳跃、注意事项不清 | “配料是〔包装已知内容〕；按〔食用说明〕食用，储存方式和注意事项是〔已有说明〕。” |
| 美妆/护肤 | 使用顺序和已有注意事项交叉重复，听众难以跟随 | “说明中的适用肤质是〔已知范围〕；先〔步骤一〕，再〔步骤二〕，使用时注意〔已有注意事项〕。” |

## 高光判定

判定前必读[高光统一判定](../../../references/highlight-selection.md)（本次主 Skill 根目录 `references/highlight-selection.md`），按统一门槛、实际场景和本场目标筛选，沿既有 highlights、引用和高光段（labels 含2）填写。已读规则只有在当前上下文完整保留时才复用；证据层次、入选理由及二创候选均按共享标准，不另设数量下限。

## 问题判定

从现场能核实的问题写起，例如同款两个规格的价格混讲。已证实的经营问题按影响理解、购买决策、咨询效率或售后预期的程度排序。涉及库存、履约或成交表现时，需要对应经营记录；仅有观众留言时，写清谁反映了什么，有必要再建议商家核对。同类合并，不逐句挑错或凑数；写实际表达、影响、改法及验证点。标明推测，不混淆关联与因果，不编造业务事实。

已确认违规全部纳入明细，不挤占经营建议；有时间证据进问题时刻，否则只留质检摘要，不编造定位。总览按经营影响归纳，欺骗、人身安全或重大损失风险可优先。未判定、证据不足不作违规或表达缺点。

同主题相邻同类违规可合并展示，保留各次时间、证据；相隔较远分别定位、总结归类。合并不改变事件和计数，不以代表片段替代其余违规。

## 分段与总结

通读全部质检摘要、风险及缺口后按完整主题分段；无摘要时通读证据。评分、发现及矛盾核对相关原文；重复或缺失须核对完整主题，不能用代表句替代。不照搬采集切片，常规段1–3分钟，短主题可更短，单段不超3分钟；有序覆盖有效内容，不重叠、不跨录制缺口、不补字幕空白。

同段可兼有高光和问题，但须针对不同事实说明保留与改进点。有可靠句级时间可拆分，否则不强拆、不抹去优势，不表扬同一违规表达。

首页 conclusion 用一句话概括本场讲解表现。highlights 和一般内容 problems 各精选最多两条，已确认违规另行全部保留。各条写明主播实际怎么讲、讲清或缺失了哪项信息，时间与证据放在对应时刻。非销售场按实际主题总结。

summary 归纳主要发现和本次覆盖范围。recommended_structure 写推荐的话术顺序，recommendations 写具体改法。观众原话可补充说明关注点，重复提问本身不能证明主播漏答或讲错。无依据的一项省略。只有取得同场、同口径的交易数据，才描述实际销售结果；评价高低还需可比基准。口播报单、评论“已买”和在线人数均不能代替订单或转化数据。

事实、时间、依据与改法放对应时刻，总览归类引用，不复述。普通段写主题与要点；风险段保留全部事实及各次证据。话术顺序写组织顺序，建议写行动；统一分析后分栏，不重复分析整场。提交前核对覆盖、全部风险及引用，不因去重遗漏独立事件。

对主播说明合规情况时，写已确认的问题及对应改法；已判定范围零命中写“已检测范围内未发现违规”。只有待核实线索时说明尚未确认，完全缺乏有效判断时写无法判断。评分门槛、覆盖统计及封顶计算留在评分流程。
