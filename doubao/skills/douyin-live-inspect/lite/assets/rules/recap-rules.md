# 直播复盘规则

## 评价边界

复盘回答“主播讲得好不好、怎样改进”。质检回答“是否符合合规规则”。复盘不重新判定违规，只引用本任务已完成的质检结论；表达不完整不自动等于违规，讲得流畅也不等于合规。

只分析本次提供的字幕、已查看且可引用的画面，以及已完成的质检结果。每项发现必须有真实内容和时间依据，不补写未采集、未识别或未判定的部分。抽检任务的总结只代表已提供的抽检窗口。

缺少评论、观众、流量、点击及成交数据时，不判断互动效果、停留或转化提升；仅有字幕时，不评价音色、音量、情绪感染力和视觉展示效果。不生成维度分、综合分或基于违规数量的扣分。

## 讲解质量维度

以下维度用于寻找有证据的优势与改进点，不逐项凑问题。是否适用取决于本段实际讲解对象和目的。

| 维度 | 讲得好的依据 | 值得改进的依据 |
|---|---|---|
| 话术结构与逻辑 | 引入需求、解释核心信息、说明条件、给出下一步，衔接自然 | 同一主题中前后跳跃、逻辑矛盾，或讲解结束仍未说明重点 |
| 产品/服务卖点表达 | 说明具体特点、用途、适用人群及限制，举例与对象相关 | 只有空泛形容和催促，关键特点含糊或不同版本混讲 |
| 促销与行动理由 | 优惠内容、参与条件和行动理由交代清楚 | 反复催促却不说明权益或条件；只评价表达，真实库存和优惠不靠口播自证 |
| 互动引导 | 提问具体，并在可见话术中围绕问题作出清楚回答 | 话术内明确提出的问题未得到回应，或回答偏离问题；没有评论数据不推断忽略观众 |
| 合规性 | 引用已有质检结论和证据 | 不另作合规判定；未命中不等于承诺真实，证据不足不等于违规 |
| 话术节奏与专业度 | 内容衔接清楚，术语解释易懂，重复用于强调或补充信息 | 连续重复没有新增信息，术语前后矛盾或表达难以理解；不把识别错误直接归咎于主播 |
| 售后/保障说明 | 适用的退款、质保、价保、运费或服务边界说清楚 | 在完整相关主题中提出保障承诺，却没有解释影响理解的适用条件 |
| 价格/优惠清晰度 | 价格、规格或套餐、优惠条件相互对应 | 同一对象价格前后不一致，优惠条件含糊，难以判断实际应付金额 |
| 行动指令清晰度 | 明确下一步做什么、到哪里操作，符合当前讲解目的 | 有行动要求但入口、步骤或对象不清楚 |

“缺失”必须限定证据范围：一个短片段没提到售后，不能推断全场没讲；非销售内容不强求报价和催单。上下文不完整时说明无法评价，不把缺少证据写成主播缺点。

## 类目适配

- 服装/鞋帽：关注面料、版型及适用参数；尺码与身高体重参照；适用的售后政策和发货时效。没有画面不评价上身展示。
- 软件/SaaS/数码会员/3C：关注功能与使用边界、版本或套餐差异、适用人群、试用退款及续费条件；没有产品依据不判断功能宣称真实。
- 食品：关注成分、配料、过敏原、保质期、储存和食用方法，以及适用的售后条件；功效是否违规引用质检结果。
- 美妆/护肤：关注成分与功效表达、适用肤质、使用步骤、注意事项及售后条件；不自行验证功效或认定医疗宣称违规。
- 金融：关注概念解释、费用期限、适用条件、限制及风险提示；不把刺激交易或收益承诺当作高光，合规风险引用质检结果。
- 汽车：关注车型配置、使用场景、价格权益条件、交付范围、质保及用车成本，试驾或咨询步骤是否清楚。
- 其他内容：按真实主题评价信息完整、逻辑清楚和表达价值，不强套商品或成交维度。

## 高光判定

单场高光最多 2 个，只选最具体、可复用且有完整证据的话术。说明对应维度、主播怎样讲清楚了，以及值得复用的方法，不用“效果很好”“促进成交”等无数据结论。

同类优势优先合并；没有突出证据可以为零。已确认违规的表达不能同时被表扬为高光，也不能因表达流畅抵消风险。

## 问题判定

单场一般内容问题最多 2 个，优先选择最影响理解或决策的信息问题。同类问题合并，不逐句挑错，不为凑数输出空泛建议。每项说明实际表达、具体不足和可执行改法；示范改写不得补造价格、资质、权益或参数。

已确认违规全部纳入，不占一般问题名额。带有可定位时间证据的违规全部进入问题时刻；没有时间证据的保留在质检结论摘要，不编造定位。未判定和证据不足不能写成确认违规。

同主题、相邻连续的同类违规可合并展示，详情保留每次出现的时间及证据；相隔较远的事件分别定位，在总结中归为同类。合并不改变原始风险事件和计数，不用一个代表片段替代其余违规。

## 分段与总结

通读全部可用证据后按完整主题划分，不直接照搬采集切片。常规段落以 1–3 分钟为宜，短主题可以更短，单段不超过 3 分钟；按时间顺序覆盖全部有效内容，不重叠、不跨录制缺口，不补写字幕空白。

同一段不同时标为高光和问题；可按真实时间拆开时分别定位，无法可靠拆开时问题优先。

全场亮点和一般问题各最多 2 条，违规另外按类型全部归纳。全场总结不重复堆砌时间片段；具体时间、依据及改法放在对应时刻。给出一句话结论、主要发现、建议话术顺序和可执行改进，同时说明证据范围。证据不足时保留空项，不编造发现。
