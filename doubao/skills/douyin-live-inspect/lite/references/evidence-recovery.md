# 证据与凭证恢复

本文件仅在 ASR 或凭证异常时读取；命令工作目录仍为 Lite 根目录。

### ASR 区间恢复与证据不足

以下恢复仅适用于仍在采集且未冻结的任务。media_frozen=true 后停止所有恢复与媒体重启，已有文字继续判定和双报告；部分缺口不能阻塞，全程无有效文字才返回失败终态。

新任务默认 remote_first，远端失败、超时或运行时确认存在语音缺口时，本地已就绪模型最多补识别一次，保留成功字幕及原时间轴；静音不补识别。本地兜底后由运行时冷却60秒，仅允许一个新片段试跑远端，成功恢复远端优先，失败重新冷却，认证拒绝待凭证变化。Agent 不重置次数、不等待模型下载、不自行切换或重试。显式 local_first/local_only 和历史模式沿用任务设置，不新增上传权限。新任务整段模式与旧逐句模式不互迁。检测到语音但无文字须披露语音缺口；已终结证据不承诺自动恢复。

`submission_unknown` 保留提交记录，不重传；已知远端ID沿原协议查询。接管或区间已结束后拒绝迟到云端结果。两端失败只结束该区间语音尝试，记录 `asr_status=failed` 与缺口，画面仍须判定。静音且未检测到语音是正常无语音；没有音轨保留 `no_audio`。前后成功字幕不因中间一句失败被删除。

收到 `ASR_EVIDENCE_MISSING` 时读取最新证据，依赖缺失语音的规则提交 `insufficient`，禁止空字幕直接 `no_hit`。失败区间不阻塞后续就绪单元。旧任务历史 `SEGMENT_SKIPPED` / `ASR_RETRY_EXHAUSTED` 继续按返回结果披露跳过范围。

## 凭证与未知提交

- 宿主认证恢复后执行 `refresh-credentials`，只从当次宿主环境读取并保存私有凭证，不输出值，然后 resume 原任务。凭证缺失不能用空字幕冒充识别成功。已标记 CLOUD_ASR_AUTH_UNAVAILABLE 且没有远端任务 ID 的失败片段属于未提交，可在凭证更新后重新排队，或在本地备用模型可用时恢复处理；已封存任务不改写已封存报告。上传地址响应缺少 result 本身不证明凭证失效，不据此阻断整场任务；未知提交在本地备用完成前保持待恢复，不重复上传。
- ASR 提交异常先读取 `status` 的 `pipeline.asr`：`cli_failed` 只表示未分类的 CLI 错误，限流、网络错误或超时也不能证明远端未建任务。不得仅凭稍后手动成功断言服务端故障或“同一环境”；后台使用任务目录的凭证快照。`resume` 不重放未知提交，`refresh-credentials` 不会重新排队 `cli_failed` 片段；只在认证确实需要恢复时刷新，不循环刷新或重试上传。
- 已从可信任务记录核实某个远端 ASR ID 确实对应本片段原音频时，可执行 `asr-reconcile --task-dir <原目录>`，stdin 为 `{"task_id":"本地任务ID","segment_id":20,"remote_task_id":"已核实的远端任务ID","confirmed_same_audio":true}`。仅处理已记录提交失败诊断的未知提交；没有诊断的预提交标记可能仍在执行，不允许关联。该确认字段表达已完成的音频归属核验，不能根据 ID 格式、字幕相似或查询成功推断，不能自行重传音频以获取新 ID。命令只查询已有任务，不上传、不重新提交；completed 后写回原片段并使旧判定失效，继续 review-next 和报告/复盘流程。remote_pending 时保留原状态，稍后可再次核对；query_failed 时按安全诊断处理。远端 ID 未知或归属无法核实则不猜测 ID、不修改数据库；remote_first 或 local_first 的云端处理可由 worker 本地接管。已接管片段返回 local_takeover，不导入远端结果。已封存的本地直播返回 inspection_finished，不能用此命令修改已封存报告。
