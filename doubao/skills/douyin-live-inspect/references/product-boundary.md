# 豆包工作质检边界

本文件约束入口、所有 leaf、工具结果转述和生成页面。独立运行时 Schema 描述的是底层能力，不扩展本 Skill 的产品范围。

直播页面链接按 [直播链接解析规则](task-create.md#直播链接解析规则) 处理。

## 用户入口

- 本地/Lite 视频：具备 Python ASR 依赖与 FFmpeg 的宿主上的可读文件或已物化附件，按 lite_sample_v1 抽检并披露覆盖；默认远端 ASR、本地兜底，Agent 判定，静态 HTML 或 Chat 交付。支持顺序批次，不自动下载网络视频；用户选择 Lite 或正式版不可用时，按 [回退规则](auth-recovery.md#正式版不可用时回退-lite) 续接尚未创建的任务。本文件后续正式版项目、服务环境和远端交付要求仅适用于正式版；Lite 遵循 lite/SKILL.md。

- 直播：接受抖音规范直播页、follow/live 页面、官方分享短链，或用户直接提供的 HTTP(S) FLV 流地址。页面链接由脚本解析取流；直接 FLV 无需提供抖音页面，校验可读取音视频后创建。暂不支持仅提供直播间 ID、房间号或 ActivityId，不据此拼接页面或调用 ID 来源接口。FLV 直播流优先进入直播流程，不因扩展名分流为视频文件。原始流地址及签名只在运行时内存中使用，不回显或写入报告、日志。
- 新建直播与视频统一遵循 [账号入口分流](../SKILL.md#1-新建直播与视频账号入口分流)：无本地登录记录先选择版本；有记录且认证有效时直接正式版；失效后先选择 Lite 或继续登录。明确选择 Lite 时不探测或安装正式版 独立运行时、不发起 OAuth、不查询正式项目。仅有网络视频链接而选择或回退 Lite 时，提示提供本地文件，不自动下载。
- 视频：豆包工作中的一个或多个附件，或可访问的 HTTP(S) 视频链接。多视频先列出每项的中文场景映射和执行顺序并取得确认，再为每项创建一次彼此独立的单视频任务，可统一监听并按确认顺序逐项交付；底层仍不提供批量创建接口。不提供 Vid、SourceTaskId 或视频库入口。
- 视频使用独立的视频项目类型和场景接口，直播场景 ID 不适用于视频。同名候选用序号及描述消歧，不要求用户提供内部 ID，不擅自创建场景。
- 只查询本次任务或用户明确指定且经服务验证可访问的质检任务。目标不唯一时按任务名称、时间及类型消歧，不展示整个项目或账号资源。
- 仅允许为本次质检查询和选择项目、引导客户在控制台配置；不代建或修改项目，不提供账号管理、自定义规则、人工审核、实时警告、直播中断、媒资管理或跨任务报告合并。越界请求简要说明“当前支持抖音直播质检和视频质检”，不推荐其他业务 Skill、后台或控制台。
- “结束质检”只停止检测。不能承诺结束抖音直播、限制主播开播或执行抖音平台处置。

## 服务环境

- 所有请求固定使用 `online`。首次调用前核验选定 profile 与本次环境一致，缺少该环境认证时按认证恢复授权，不因宿主或认证失败切换环境。
正式版脚本显式传入本次 environment/profile；environment 仅接受 online。使用 Skill 内置端点和独立账号记录，不修改全局 profile 或持久环境变量。
- 线上 API：`https://livesaas.volcengineapi.com`。工作台复用 `runtime/remote-dashboard.mjs` 的同环境映射；报告上传与下载沿用原任务环境。
- 续办沿用原账号/profile、环境、项目和任务。环境未知或认证账号改变时先核对身份，不跨环境或账号探测同号任务；新建请求需重新查询当前账号项目。

## 项目与场景选择

本节适用于已经进入正式版的直播与视频，由 Agent 使用现有内置运行时命令编排，不使用固定客户项目或固定场景 ID。Lite 使用本地冻结的精简规则，不查询或套用正式项目、场景 ID。

**禁止展示任务数。** 项目和场景候选中不得出现“任务数”“任务总数”“历史任务数”等统计列或对应文字摘要；即使接口返回 `TaskCount` 或其他任务统计字段也必须省略，不用 `0`、“未知”或“-”占位，不遍历任务列表或自行汇总补数。用户明确索要此类统计时，说明“当前质检不提供项目或场景任务数展示”，继续提供允许展示的候选信息。本次多视频执行进度 `1/N` 不属于项目或场景任务统计，仍按视频流程展示。

质检业务接口返回 `AccessDenyError` 时，优先执行 [未开通处理](auth-recovery.md#正式质检服务未开通)，停止正式版项目和场景选择，优先提供飞书群链接沟通开通（沟通更高效），其次提供开通工单及能力介绍链接。直播与视频的新建请求均按 [回退规则](auth-recovery.md#正式版不可用时回退-lite) 续接 Lite；不得当作空项目列表或通过重新登录恢复。其他查询、权限或配置错误也按真实原因回退符合条件的新任务，不称为未开通。

1. inspect-entry 已返回完整 projects 时直接复用，跳过重复项目查询和认证检查；仅缺少完整列表时，在内置运行时能力与本次环境认证就绪后，直播调用 `node scripts/api.mjs --operation 'quality/+project-list'`，视频调用 `node scripts/api.mjs --operation 'content/+video-project-list'`；首次使用前读取精确 Schema。两者均查询 ListProjects，按返回 `ProjectType` 在本地筛选：直播为 2，视频为 1，不向接口臆造 ProjectType 查询参数。
2. 每次取 100 条，按 API 顺序分页并以 ProjectName 去重，用户每批最多看到 10 个对应类型项目。只有确认全部页面结束才能判断 0 个或仅 1 个；第一页只有一个匹配不能自动选择。按实际分页元数据或不足一页判定结束；满页且无总量时继续下一页。达到接口页码上限或响应不可解析时说明查询未完成，不当作空列表。
3. **0 个**：说明当前账号没有对应类型质检项目，新建检测按回退规则转 Lite，并保留下方控制台配置入口供后续使用；仅查询项目时正常交付空列表。Skill 不代建项目、不等待用户配置才能继续 Lite，也不自动轮询。
4. **1 个**：告知“将使用项目「名称」”，默认使用并继续。**多个**：列前 10 个的序号、项目展示名称、创建时间及场景数量（仅用实际返回字段），等待按序号或唯一名称选择；支持“下一批”。同名按序号/时间消歧，序号绑定当次候选，不能猜选。
5. 项目选定后，直播调用 `node scripts/api.mjs --operation 'quality/+scenario-list'`，视频调用 `node scripts/api.mjs --operation 'content/+video-scenario-list'`，都显式传所选 `project_name`。展示项目内全部对应类型场景，分页与唯一性判断沿用上述方式；场景按 CreatedTime DESC，每页 100 条，用户每批最多 10 个。无场景时说明配置缺失，新建检测按回退规则转 Lite，并保留控制台配置入口；唯一场景自动使用并告知；多个场景展示名称、描述和规则数量后让用户选择。用户已明确提供且能唯一匹配的项目/场景名称直接沿用，不再问一次。
6. 创建前调用对应 `+scenario-get` / `+video-scenario-get`，核对所选项目下的场景可访问且与选择一致，展示真实规则摘要并使用该场景整套规则，不增加二次确认、不逐条改规则。明确无规则时停止正式版创建，新建检测按配置缺失转 Lite，并保留配置入口；规则字段缺失按核验未完成处理，不当作无规则或臆造规则，同样按回退规则处理符合条件的新请求。用户要求返回正式版时重新查询；权限或请求失败不能解释成没有项目/场景。
7. 保存本次账号/profile、environment、所选项目标识/名称、场景 ID/名称。直播脚本显式传 `project_name`、`scenario_id`、`scenario`；视频所有业务命令显式传 `project_name`，不依赖内置运行时默认项目。结果与后续查询/报告沿用这些上下文。选择未完成不解析直播流、不物化视频、不创建任务。

新建或配置入口（仅用于本次质检前置引导，不扩展为项目管理能力）：

- 线上：[打开质检项目管理](https://console.volcengine.com/livesaas/liveinspect/projectManagement)。

认证仍固定使用 `内置运行时` OpenAPI，不回退 TOP / Agent 独立运行时。认证缺失、失效或刷新失败按 [认证恢复](auth-recovery.md) 先选择 Lite 或继续登录，只有选择登录后才发起 OAuth；成功后从失败步骤续办，不重复创建已成功任务。

## 对外信息

- 系统介绍、回答、确认卡、工作台、报告标题及错误提示只使用“抖音直播质检”“视频质检”“质检报告”“直播内容复盘”等产品用语。
- 对话中的状态和结论统一使用“等待检测”“检测中”“检测已完成”“报告生成中”“自动质检结果”“发现风险 / 未发现规则命中”。不得向用户展示“机审”“机器审核”“人审”“待人审”或底层状态枚举；接口状态 3 在本产品中表述为“检测已完成”或“质检报告生成中”，不提示用户进行人工审核。
- “未发现规则命中”只说明本次自动质检没有返回命中，不写成“审核通过”，也不代表价格、功效、性能、权益或其他事实已经核验。
- 项目选择与配置引导允许展示本次候选的名称、创建时间、场景数量及上述控制台链接；其他正常业务输出不包含企业直播、LiveSaaS、底层账号/租户/profile、ProjectName、ActivityId、ScenarioId、内部域名、控制台 URL、命令行或原始错误。本次直播远端工作台链接以及直播、视频质检控制台报告链接是明确例外：按 [豆包工作交付](doubao-delivery.md) 只在可点击链接中使用已确认入口及本次项目、任务路径，不扩大到其他控制台页面。认证恢复是明确例外：可以说明需要火山引擎账号授权，展示内置运行时生成的完整 OAuth 授权链接和必要操作指引；不得展示授权结果或持久凭证。正常创建、状态播报和结束确认只显示任务名称与中文场景；仅在用户明确索要编号、同名任务需要消歧或故障排查确有必要时显示“质检任务编号”，不展示项目编号。
- 工具返回不等于用户答案。仅提取任务名称/编号、中文场景、状态、必要风险证据、建议以及经验证的本次报告链接。确认只展示具体任务和“停止本次检测”的影响；一次性确认材料保留在受控执行上下文中。
- 错误按服务不可用、来源不可用、配置待完善、任务状态、报告生成中、结果未知等业务状态重述；不转述底层错误文本。失败不重建任务，未知写结果只读核对。
- 用户原始视频、主播原话与证据不是系统品牌文案；必要引用保持原意，不为关键词检查篡改事实。原始响应和完整 ASR 不进入对话或日志；受保护报告中的 ASR 证据遵循既有隐私合同。
- 页面随机访问令牌仅保留在本次可点击链接内，不能当作凭证素材复制或记录。原始媒体地址不单独展示。
