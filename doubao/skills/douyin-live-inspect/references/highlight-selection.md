# 高光统一判定

标准版本：`highlight-v1`。正式版与 Lite 共用判定门槛，证据来源及提交字段仍遵循当前复盘合同；本标准不授权补采数据或改变评分公式。

## 场景与本场目标

先确定实际内容场景和本场目标，再用同一口径评价全场。目标优先取用户明确要求或已有任务资料；未提供时写“目标未提供，按实际内容场景评价”，不猜清库存、拉新或成交目标。场景不明时按通用内容价值评价；混合直播按真实主题切换侧重点，不能为某个候选临时降低门槛。

| 场景 | 优先寻找的可复用做法 |
| --- | --- |
| 商品带货 | 讲清具体差异、适用条件，演示使用方法，化解选型或购买顾虑 |
| 知识讲解 | 解释难点、纠正常见误解，给出能照做的方法及适用边界 |
| 娱乐互动 | 完整的铺垫与回应、包袱或反转、具体互动设计；现场效果须有视听或互动证据 |
| 商家服务 | 解答预约、核销、使用、售后问题，说明下一步及服务边界 |

行业细则只调整侧重点：服装看选码和试穿参照；食品看食用与储存；美妆看肤质、步骤和注意事项；软件/3C 看功能、版本及使用限制；汽车看车型配置、用车场景与价格权益条件；金融看概念、费用、期限、适用条件与风险解释，不以刺激交易或收益承诺为优点。

## 统一入选门槛

每个候选均须满足以下条件，再按本场目标、具体价值和代表性精选，同类合并、不凑数量；可以零条，不设必须产出的名额。仅为“本场相对最好”而未达门槛的内容保留为普通片段。

1. **可核对**：实际核对原文或已查看画面，能定位时间和同一商品/主题，包含支撑结论所需的上下文。ASR 歧义影响含义、对象不明、铺垫或关键条件缺失时仅列为待回看，不确认高光。
2. **有具体价值**：指出帮助谁解决了什么问题，或提供了什么明确看点；普通报价、常规产品介绍、流畅表达、情绪激动、促销词多本身不足以入选。
3. **有可复用方法**：说明值得保留的解释顺序、对比、演示、回应或互动方法，以及复用条件。不能只写“专业”“有感染力”“促进转化”。
4. **结论不超过证据**：区分表达清楚与商品事实真实，不把未命中质检当成承诺已获证实。已确认违规表达不作为高光；“价格条件讲得清楚”可评价表达方法，“确实最低价”“保证有效”“保障更优”则需要相应事实依据。缺少依据时不表扬承诺本身，复用前注明核实条件，也不据此改判违规。

同段另有问题不抹去有证据的优势，也不能用优势抵消风险。分别指明事实，按当前合同允许的标签及分段方式呈现；不表扬同一违规表达。

## 证据层次

这三层说明结论支持到哪里，不是加分档位；有价值的内容不必等到成交数据齐全才能入选。

| 层次 | 所需证据 | 可以表达的结论 |
| --- | --- | --- |
| 内容价值 | 达到上述门槛的原话或画面 | 具体做法值得复用；效果待验证 |
| 互动反馈 | 内容证据之外，还有可核对、确与该话题相关的观众回应 | 在所采集范围内观察到具体反馈；不外推全体观众或成交 |
| 经营数据关联 | 当前合同提供可引用的点击、加购、成交或真实留存数据，且对象、时段和统计口径对应 | 与指标变化同期相关；仅凭前后变化不能证明因果 |

**当前数据边界**：正式版只有 ASR 与质检结论，高光只能落在内容价值层。Lite 高光仍须引用本次主播字幕或已查看且可引用的画面；评论、问答和人数只作补充上下文，不能作为话术高光的引用证据或据此升级证据层次。已核对的主播回答原文可以支持“答疑清楚”，观众反馈另在互动洞察中说明。当前两版均无支持经营效果归因的数据，不输出“已验证转化/留人/减少退货”。

评论接收时间可能滞后，不以时间相邻强配回应；重复刷屏、助播宣传、泛泛好评及人数波动不证明某句有效。只有文字时不评价声音、语气、笑声；稀疏抽帧不证明连续动作、节奏或音效。

## 输出与复核

在已有 summary 或数据范围说明中简记标准版本、场景、本场目标及来源；没有新增字段。每条入选理由交代“解决的问题或看点—具体做法—证据层次及局限”，复用条件放已有 reason 或 suggestion。时间和引用沿原合同放在对应片段，汇总与片段标签一致；不大段抄写原话，不把所有讲解都标成高光。

正式版沿用 highlights[].reason 与 segments[].momentData；Lite 沿用 highlights[].reason、evidence_ids 与 segments[].moment_detail。总览归纳方法，片段提供定位和依据。高光数量不直接加分，评分仍按原九维度规则。

搞笑、高能、整活等二创候选也须过门槛：说明具体看点及须保留的铺垫、回应、条件，引用覆盖完整内容；在 highlights 标题以“二创候选：”开头，与讲解亮点区分。依赖缺失视听证据时只建议回看，不确认高光；精确剪点需回看时注明，不宣称已剪辑、爆款或传播效果。没有二创候选不扣分。

## 边界示例

- “太划算了，赶紧拍”：只有催促，没有具体价值或方法，不命中。
- 完整演示地漏内口测量、说明选型条件：可入选内容价值层，复用的是测量和解释方法；不能据此声称降低退货率。
- 只有字幕“大家笑死了”或人数突然上涨：不能证明娱乐高光，缺少关键证据则待回看。
- 清楚讲解后出现“明白了”的评论：可在互动洞察记录这条反馈；按当前合同，高光仍基于讲解原文，不升级为转化高光。
- 一场都是泛泛介绍：即使其中一段更流畅，也可以没有高光。
