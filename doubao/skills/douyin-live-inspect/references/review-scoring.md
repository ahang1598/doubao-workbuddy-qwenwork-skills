# 复盘评分

每次新复盘在同一次分析中填写 `scoring`，不另跑整场分析。读取同目录 `review-scoring.json` 的九维度、权重和五档标准。每项在对应档位中取整数分：满足该档全部描述取高值，部分满足取低值；0–2 档按无有效表达、极少信息、已有少量信息取 0、1、2。程序计算总分、等级和封顶，不填写这些派生字段。

输入：使用运行时提供的 `scoring_context`。输出：原样保留 `version` 与 `evidence_version`（上下文提供的证据版本）、九项 `dimensions`（id、status、score、reason、evidence_ids）、`risks`（issue_id、level、reason）。每条风险必须与上下文 issue 一一对应，不能新增或省略。状态为 scored/not_applicable/insufficient；后两种 score=null，reason 解释原因，evidence_ids 可为空。scored 必须引用本次上下文真实证据；合规至少引用一条 quality，其他项至少引用一条语音或已查看画面，不能只凭质检摘要评价内容。不要引用其他任务或正文片段编号代替证据 ID。

- 评价对象是本次采集片段的表达质量，不是整场直播表现或经营效果。三分钟、未录到开场本身不是拒绝评分条件；有可辨认的连续字幕即可按可观察维度评分。只有缺少对应内容、转写严重不可读或无法定位依据时才填 insufficient。
- 有内容但表达薄弱应按档位给低分：反复催单却少讲产品，可评价促销与卖点；不能把“讲得不够好”写成“证据不足”。未采集部分不推断为缺失，引用片段范围说明观察边界。
- 互动评提问、指令及主播可见回应，不要求评论或成交数据；价格、售后评口播是否讲清价格、条件与保障，不要求商品卡或政策库来验证真实性；行动指令不要求完整操作演示。节奏与专业度评内容衔接和术语，不以发货承诺能否核实代替评价。真实性核验仍沿用已有质检，不能由表达评分新增违规结论。
- 按类目解释维度，不增加计分项：教学的卖点是讲解内容与操作步骤，才艺是节目内容表达；非交易内容的价格、促销、售后可不适用。不能把未录到开场、缺评论或缺画面当作低分。
- 至少一个内容维度（合规性以外）可评即可计算总分，按全部可评项的权重归一化；结构逻辑或节奏专业度缺失不阻断其他项。只有合规分、或全部内容维度不可评时，不给内容总分。只凭字幕评价内容衔接与术语，不评音色、音量或感染力；无评论不推断互动效果，无成交数据不评转化效果。
- 合规只使用已有质检结果，风险分级仅为评分服务，不等于违法等级。high：已有结论确认严重误导、无依据承诺、危险指导等实质风险；medium：已确认且有明确影响但不属于严重风险；low：已确认的轻微问题；缺少逐条原话、影响或证据不足以分级用 unknown，不把整改 P0/P1/P2 直接当高/中/低风险。
- 同规则、相同原话的重复问题必须使用相同等级；程序去重计分，保留全部位置和次数。没有逐条证据不能将汇总次数拆成多个问题。`compliance_complete=false` 或有 unknown 时合规项填 insufficient，其他有证据项仍评分，总分标暂定。
- 合规证据完整时：无风险 9–10、仅低风险 7–8、有中风险 5–6、1–2项高风险 3–4、3项以上高风险 0–2。没有命中只代表已检查范围，不能称承诺已核实。
- 内容证据不足也提交九项状态及原因，顶部隐藏总分，下方分项评分说明缺口，不编分数。每项理由一句话，证据中保留原话和可用时间。
- Lite 摘要的评分依据以完整 scoring_context.evidence 为准；旧摘要仅含 quality 时从 evidence_file 补读，不能把省略当成无证据。已有语音或画面却全部内容维度不可评时，须在相应 insufficient 项引用核对过的内容并说明具体缺口；原本没有内容证据时仍可留空。
