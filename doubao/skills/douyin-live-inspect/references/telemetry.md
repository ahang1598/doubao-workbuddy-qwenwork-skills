# 入口与任务沿用

Lite 回执要求刷新宿主凭证时，在新的宿主工具调用中沿原任务目录执行 `refresh-credentials`，然后按回执继续；不另建任务、不重放未知提交。重新导入不代表云端已恢复，不读取或粘贴凭证内容。

- 新的真实业务请求通过 `inspect-entry` 进入；仅阅读文档不执行入口。来源未明确时可省略 `--kind`，按回执澄清；版本未确定时等待选择，不提前探测账号。明确选择 Lite 且尚无入口目录时，执行 `node scripts/inspect-entry.mjs --mode lite --task-state not_created`。
- 首次入口在用户当前选择的执行电脑运行。`execution_env` 是命令环境变量，不是切换电脑指令；不能根据任务路径推断云电脑或擅自切换宿主。当前电脑无法访问原目录时先说明环境不一致，不重建任务，也不自动切回云电脑。
- 同一请求的登录、创建、查询、授权续办及重试，复用入口目录并继承 `data.execution_env`（包括 `INSPECT_USAGE_CONTEXT_DIR`）；批次沿用 batch_dir，不为每个子项重建入口。不手工修改本地上下文或设备缓存。
- Lite 启动校验失败时按回执修正字段，沿原目录重试；环境配置或内置规则故障先修复对应环境。不静默删除字段、转换类型或改来源与识别策略，不手工补报。
- Windows 私有目录权限失败时，保留原任务与缓存，按回执排查当前宿主；不自动提权、放宽权限或清空重建。升级后仍须沿原目录核对结果，不直接宣称旧目录已修复。
- 报告回执提示证据版本变化时，沿原任务重新读取报告并使用最新回执合同；不得改写版本或跳过实际交付。
- 重复启动返回 `TASK_ALREADY_EXISTS` 时执行回执中的原任务 `status`，按实际状态继续判定、收尾或报告交付；不重试 start、不覆盖已有任务，也不把新输入当作已生效。
- Lite 续办显式传入原 task_dir / batch_dir，避免沿用其他请求的环境目录；已有证据就绪时按 review-next 领取并提交，再处理剩余媒体恢复。
- 本次已选择正式版且回执已含授权链接时先交付，`login_required` 时直接进入登录恢复，等待授权期间沿用正式版、原入口目录和执行环境，授权启动失败按入口最终阻塞回执处理，认证或业务受阻时保留正式版，只有用户明确选择 Lite 才启动 Lite。
- 正式版登录完成后，沿原目录再次执行正式版入口检查，再继续创建或查询；不因授权续办新建目录，不把其他账号的已有任务接到当前请求。
- 优先用宿主命令工具的环境参数传递环境。POSIX shell 可用 `INSPECT_USAGE_CONTEXT_DIR="<入口返回目录>" node scripts/login.mjs ...`；Windows 按实际 shell 设置。
- 用户对已有任务发起新的查询或停止请求时，执行 `node scripts/inspect-entry.mjs --mode lite|formal --task-state existing --new-request --task-dir "<原目录>"`，批次改用 `--batch-dir`，随后继承返回环境执行原业务，不重新选版本或创建任务。正式任务沿用最初目录与服务端身份，不按设备或时间猜关联。
- **Lite 停止例外**：已知 task_dir 时先执行 Lite 普通 stop，再用原目录开始本次请求并继续收尾，不为入口延迟停止或重复 stop。
- 以业务回执核对结果，Lite 新直播等待时长选择时沿用入口任务，采集到期沿原任务收尾。等待选择、授权或报告时说明待办；没有明确证据时不推断失败、用户放弃或停播。用户禁止上报时设置 `BYTEDLIVE_TELEMETRY_DISABLED=1` 或 `true`，让后续子进程继承。
- 直播结束且未取得内容时，沿原任务核对来源状态并完成双报告收尾，按 [停播与零内容处理](../lite/references/live-review.md#停播与零内容处理) 区分已确认停播与未知中断；平台确认停播或原任务明确停止后，迟到的补流按原目录收尾；补流超时只说明交接未完成。正常业务命令自动记录结果，不另建任务或手工补报。
- 视频以已保存的窗口判定和实际报告交付核对完成状态；零有效判定如实保留检测缺口；已生成报告和实际交付分别沿原回执确认，不因判定数为零否定报告成功，不重建入口或手工补写状态。

- 入口与既有业务命令已统一接入；复核提交、请求重试及后台恢复继续使用原任务目录，结果未知时沿原 request-id 核对。复核提交超时会先自动核对；已领取的下一批沿用回执，部分保存时使用返回的新 retry_command_argv 处理剩余片段。正常操作不要另行调用 `skill-start` 或 `version-selected` 补记；这两个兼容脚本每次显式调用都会记录一次，以免重复观察。

新视频质检交付后继续完成复盘与评分，按各自回执确认；沿原任务续办，不另建直播复盘入口或手工补报。
视频任务按实际已判定范围记录进度与完成结果；新建视频连续检测至片尾，失败或停止造成的缺口不能记作全片完成。历史抽检任务继续沿用原策略，勿重算历史结果或手工补报。
全视频采集结束后仍可继续远端抽帧；不因任务无收尾期限而误记远端失败，单次远端请求仍受自身超时约束。

ASR 备用能力准备失败时，沿原任务查询状态并按[证据恢复](../lite/references/evidence-recovery.md#本地备用识别不可用)处理具体原因；没有原因就说明未知，不另建任务或手工补报。Windows 目录权限故障时，沿原任务回执核对状态；回执明确系统 PowerShell 不可用时，修复系统组件后沿原任务重试。其他权限失败保留目录，不循环修改权限或自动提权；不要仅凭上传地址失败要求重新授权，也不要为恢复另建任务。

本地推理依赖由后台独立环境准备；准备中不当作失败，准备失败后沿原任务回执处理，不手工补报或反复安装。

直播上传失败时展示回执中的安全原因，继续其他可用内容和报告收尾；不因单段异常循环重试、等待模型准备或暂停已有报告，不手工补报。

直播采集结束后媒体处理进程退出，仍沿原任务回执恢复已有内容；不能把进程退出当作整项质检完成。恢复或收尾结果由原业务命令记录，不重开采集、不手工补报。

复盘输入报错时保留原任务和草稿，按回执行列定点修复后重新提交；不要全局替换引号，不用超时或页面生成中判断最终失败。正常提交与状态观察自动记录诊断，不手工补报。

直播最终无字幕且关闭画面检测的未领取片段可由运行时记录为未检测；不手工补写成功判定。后台监看退出不代表双报告已交付，仍按回执完成实际交付。

小红书直播沿用原入口和任务目录；浏览器补充取流及候选刷新不另建任务、不手工补报。按回执区分明确停播、来源受阻与恢复超时，不因浏览器能播放而声称质检成功。

小红书浏览器补流交接超时使用 `BROWSER_SOURCE_TIMEOUT`，终态任务拒绝候选使用 `BROWSER_SOURCE_TASK_CLOSED`；二者不归为网络错误或候选不可读。沿用现有任务身份和事件，交接等待从首次请求补流起固定180秒，不随轮询续期。期限届满时，已接收候选的校验或探测失败保留实际错误及安全诊断，不改记为交接超时。

B 站浏览器确认同房间 live_status=0 时，原任务按 offline / not_live 收尾。小红书本房间播放器明确显示停播时，已有 Lite 任务通过 resume 交回停播观察，worker 核验房间和时效后以 offline 收尾，新请求不产生检测启动或结束事件。小红书浏览器观察准备脚本不发独立事件，交接和检测仍归原任务；只返回固定状态，不记录资源列表或完整 FLV URL。

采集回执报告本地存储异常时，保留原任务和已采集证据，说明检测中断、未确认停播；报告生成不消除采集失败提示，不手工补报成功。

判定领取、提交沿用原直播或视频任务类型，不把未知任务当作直播；判定和远端识别查询结果由运行时自动观察，不手工补报；命令成功、识别提交成功和实际交付分别核验。进度无待处理片段不代表已完成双报告。依赖回执指出 NumPy 或 sherpa-onnx 导入/加载失败时，按原任务安全原因恢复环境，不发送原始异常、凭证或路径。

FFmpeg 安装失败时按回执中的实际阶段、操作和系统错误码定位，沿原任务修复后重试；下载完成不代表安装成功，旧回执只有权限类错误时不推断为 ACL 或文件占用，不手工补报。

Mac 依赖由运行时自动准备，失败后沿原任务显式重试，不另建任务或手工补报。小红书 dynpath 分享链接沿用同一直播入口，分享参数不贴入诊断或报告。

浏览器候选交接成功不代表采集恢复或质检成功；按原任务回执执行补流和 status，不手工补报成功，不因等待补流推断停播。

Mac FFmpeg 从国内 CDN 自动准备，旧内置下载地址由运行时迁移，不手动改 PATH 或转向 GitHub；下载失败沿原任务回执恢复或重新导出，运行时自行记录实际准备结果。

小红书启动前先观测浏览器候选；提取到地址不代表采集或质检成功，仍以原任务媒体和检测回执为准，不单独补报。

Mac ARM64 内置 FFmpeg 在依赖准备时升级至 8.0.1，沿原任务自动准备；不另建任务、不手工补报。

- Lite 直播的 H.265 FLV 由运行时选择直采或兼容路线，不因编码名称手工安装依赖；发生媒体路线切换时沿原 task_dir 继续；按回执处理准备失败或覆盖缺口，不重建任务或反复运行依赖准备。远端结果未知时不重新提交同一片段。

- Lite 语音结果有缺口时仍使用已保存字幕，并按回执披露缺口；不把部分识别失败说成整段静音，也不因升级版本手工改写历史任务结果。

- 当前 Lite 直播积压时继续处理原队列，不手工标记跳过或补报成功；已知远端任务 ID 沿原任务续查，不重新提交。历史已跳过片段与数据库损坏如实披露，不因升级改写历史结果。

抖音、B 站和小红书首次取源失败或断流，自动重连沿用原任务；等待期间继续处理已有内容，恢复后接续录制。仅收到 FLV 文件头时仍按首次取流处理。FLV 采集失败按原任务安全诊断说明原因；重试耗尽只表示没有新增片段，不等于页面解析失败或停播，不因诊断改进重开历史任务。

宿主代理由运行时沿用；不手动取消代理、修改网络配置或复制浏览器认证材料。取流失败仍按原任务诊断排查，浏览器可播放和代理可连通都不能代替实际采集确认。

云电脑返回采集网络错误时沿原任务诊断；宿主托管出网由运行时适配，不手工修改 DNS、代理或关闭证书校验。终态任务不因修复重开，新检测继续按正常入口执行。

云电脑采集/判定命令不再按累计次数自动停止；旧任务计数不作为执行额度耗尽的证据。Agent 工具调用也不按固定步数触发停止；宿主实际提示额度不足时按 Lite 提前收尾流程执行，不把停止采集表述为直播下播。

正式工作台沿原身份取得远端链接；本地工作台已退役，旧入口在遥测启动前被拒绝，不重建任务、不补报成功。开发观察工具不属于 Skill 业务步骤，不为质检启动观察服务。

停止采集后若运行时仍在等待本地语音备份，继续沿原任务回执收尾；不要提前宣告失败、另建任务或手工重开已结束报告。

B 站直播沿用原入口和任务目录；匿名取流、浏览器补流及断流恢复不另建任务或手工补报。明确未开播、轮播不支持、来源受阻分别按原回执处理；只取得 FLV 或本机可读不代表云端检测、报告交付成功。

纯语音片段本地确认静音后可正常收尾，沿原任务继续；个别片段语音证据缺失或备用环境未就绪时，保留该段缺口，继续处理其他片段。

复盘内容退回按回执提示修正原草稿；领取遇到权限或存储错误时，沿原任务核对请求状态。

小红书正式版交付本场流地址后，以服务端检测结果确认开始质检，取得候选不代表已产生检测内容。
