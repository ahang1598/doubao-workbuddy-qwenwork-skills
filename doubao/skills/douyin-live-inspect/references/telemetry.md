# 入口与任务沿用

- 新的真实业务请求通过 `inspect-entry` 进入；仅阅读文档不执行入口。来源未明确时可省略 `--kind`，按回执澄清；版本未确定时等待选择，不提前探测账号。明确选择 Lite 且尚无入口目录时，执行 `node scripts/inspect-entry.mjs --mode lite --task-state not_created`。
- 同一请求的登录、创建、查询、授权续办及重试，复用入口目录并继承 `data.execution_env`（包括 `INSPECT_USAGE_CONTEXT_DIR`）；批次沿用 batch_dir，不为每个子项重建入口。不手工修改本地上下文或设备缓存。
- Lite 启动校验失败时按回执修正字段，沿原目录重试；环境配置或内置规则故障先修复对应环境。不静默删除字段、转换类型或改来源与识别策略，不手工补报。
- Lite 续办显式传入原 task_dir / batch_dir，避免沿用其他请求的环境目录；已有证据就绪时按 review-next 领取并提交，再处理剩余媒体恢复。
- 正式版登录完成后，沿原目录再次执行正式版入口检查，再继续创建或查询；不因授权续办新建目录，不把其他账号的已有任务接到当前请求。
- 优先用宿主命令工具的环境参数传递环境。POSIX shell 可用 `INSPECT_USAGE_CONTEXT_DIR="<入口返回目录>" node scripts/login.mjs ...`；Windows 按实际 shell 设置。
- 用户对已有任务发起新的查询或停止请求时，执行 `node scripts/inspect-entry.mjs --mode lite|formal --task-state existing --new-request --task-dir "<原目录>"`，批次改用 `--batch-dir`，随后继承返回环境执行原业务，不重新选版本或创建任务。正式任务沿用最初目录与服务端身份，不按设备或时间猜关联。
- **Lite 停止例外**：已知 task_dir 时先执行 Lite 普通 stop，再用原目录开始本次请求并继续收尾，不为入口延迟停止或重复 stop。
- 以业务回执核对结果，等待选择、授权或报告时说明待办；没有明确证据时不推断失败、用户放弃或停播。用户禁止上报时设置 `BYTEDLIVE_TELEMETRY_DISABLED=1` 或 `true`，让后续子进程继承。
- 直播结束且未取得内容时，沿原任务核对来源状态并完成双报告收尾，按 [停播与零内容处理](../lite/references/live-review.md#停播与零内容处理) 区分已确认停播与未知中断；正常业务命令自动记录结果，不另建任务或手工补报。
- 视频以已保存的窗口判定和实际报告交付核对完成状态；零有效判定如实保留检测缺口；已生成报告和实际交付分别沿原回执确认，不因判定数为零否定报告成功，不重建入口或手工补写状态。

- 入口与既有业务命令已统一接入；复核提交、请求重试及后台恢复继续使用原任务目录，重试沿用原 request-id。正常操作不要另行调用 `skill-start` 或 `version-selected` 补记；这两个兼容脚本每次显式调用都会记录一次，以免重复观察。

视频任务按实际已判定范围记录进度与完成结果；新建视频连续检测至片尾，失败或停止造成的缺口不能记作全片完成。历史抽检任务继续沿用原策略，勿重算历史结果或手工补报。
全视频采集结束后仍可继续远端抽帧；不因任务无收尾期限而误记远端失败，单次远端请求仍受自身超时约束。

ASR 备用能力准备失败时，沿原任务查询状态并按[证据恢复](../lite/references/evidence-recovery.md#本地备用识别不可用)处理具体原因；没有原因就说明未知，不另建任务或手工补报。Windows 目录权限故障时，沿原任务回执核对状态；回执明确系统 PowerShell 不可用时，修复系统组件后沿原任务重试。其他权限失败保留目录，不循环修改权限或自动提权；不要仅凭上传地址失败要求重新授权，也不要为恢复另建任务。

复盘输入报错时保留原任务和草稿，按回执行列定点修复后重新提交；不要全局替换引号，不用超时或页面生成中判断最终失败。正常提交与状态观察自动记录诊断，不手工补报。

直播最终无字幕且关闭画面检测的未领取片段可由运行时记录为未检测；不手工补写成功判定。后台监看退出不代表双报告已交付，仍按回执完成实际交付。

小红书直播沿用原入口和任务目录；浏览器补充取流及候选刷新不另建任务、不手工补报。按回执区分明确停播、来源受阻与恢复超时，不因浏览器能播放而声称质检成功。

小红书浏览器补流交接超时使用 `BROWSER_SOURCE_TIMEOUT`，终态任务拒绝候选使用 `BROWSER_SOURCE_TASK_CLOSED`；二者不归为网络错误或候选不可读。沿用现有任务身份和事件，交接等待从首次请求补流起固定180秒，不随轮询续期。期限届满时，已接收候选的校验或探测失败保留实际错误及安全诊断，不改记为交接超时。

小红书浏览器观察准备脚本不发独立事件，交接和检测仍归原任务；只返回固定状态，不记录资源列表或完整 FLV URL。
