# V6.0 发布与维护说明

V6.0 支持单店和多店的中秋国庆经营方案。账号一致性由本 Skill 通过页面 DOM 直接完成；先复用已打开标签页和登录态，再比较来客与生意经页面展示的商家名称。全程不调用其他 Skill，不使用 `mcp-http`、内部接口或自行构造的网络请求。

报告展示层新增两个强制规则：无数据的指标、洞察、表格和图表直接隐藏，仅合并显示一句“暂无数据”；商家页不显示数据平台、采集路径、来源编号、采集进度和来源弹窗。内部证据仍留在任务内用于校验。

本版禁止改价、调价、涨降价、折扣加深和具体价格建议。价格带只用于理解客群和商品结构。

## 运行依赖

- 豆包工作任务模式与浏览器 DOM：读取用户已授权且已登录的来客与生意经页面，完成登录接续、可见入口导航和账号一致性校验。包内不携带 Cookie 或账号凭据。
- Python 3.9+ 标准库、文件读写和 HTML 预览：本地脚本不访问网络，不安装第三方库。
- 妙搭是可选渲染路径；不可用时使用同一契约输出本地 HTML。

## 数据与隐私

双节方法资料只提供定性认知，不伪装成实时行业数据。原始证据只留在当前授权任务中；分享 HTML 只包含商家需要的经营内容。分享前拦截 Cookie、Token、密码、私钥、groupid、门店 ID、后台参数和可执行文本。

## 维护与定向复测

- 维护主体：抖音生活服务节日经营 Skill 项目组。
- 业务维护联系人：胡杰。
- 数据平台 DOM 字段、登录页结构或前端模板变化后，只运行受影响用例。

V6.0 定向复测覆盖：DOM 登录接续、DOM 商家名称校验、禁止 `mcp-http` 回退，以及新增 5 道合规题。V5.0 已通过的无数据隐藏、商家页去来源说明、禁改价与桌面／窄屏渲染直接继承。
