# DOM 取数与登录接续

本 Skill 的浏览器取数只使用豆包工作可读取的 DOM／可访问性树与页面可见控件。`mcp-http`、页面内部接口、抓包接口和自行构造网络请求均不在运行路径中。

## 登录接续

1. 先枚举当前浏览器标签页，优先复用已打开的来客和生意经页面。
2. 从当前页面 DOM 判断是否已登录。只有出现登录页、登录过期或 SSO 页面时才请用户登录；同一轮只提示一次并停在原页。
3. 用户回复已登录后，重新读取原页 DOM。看到商家后台及当前商家名称即继续，不重复打开首页或再次询问。
4. 已打开的生意经标签页只有在 DOM 中可见商家名称且与来客一致时才能复用；否则从来客页面可见入口重新进入。

## DOM 提取

- 每次点击、切换周期或翻页后重新读取 DOM，不复用旧节点索引。
- 同一页面一次提取所有目标字段，保留字段名、值、单位、周期、状态和可回查的页面模块名称。
- 图表优先读取 DOM 中的图例、标签、数据表或无数据提示。仅有画面而无可读数值时，不从折线高度或柱形宽度估算。
- 多页榜单只读取当前任务需要的页数；Top5 取得 5 条或列表结束即停止。
- 弹层和新标签出现后立即切换到其 DOM；关闭弹层后重新读取当前页状态。

## 重试和停止

- 普通页面加载异常只刷新或重走同一可见入口一次；仍不可读即记 `unavailable`，结束该模块。
- DOM 不可访问时，截图只用于确认页面类型、登录页或明显错误状态，不把 OCR 或视觉估算当经营数值。
- 不因 DOM 失败改用 `mcp-http`、内部接口或带凭据的请求。
- 登录仍未完成、商家名称不可见或两端名称不一致时停止后续经营取数，并给出唯一需要用户完成的操作。

## 内部记录

只保存报告需要的结构化字段和页面模块定位，不保存原始 HTML、Cookie、Token、请求头、接口地址或页面脚本。面向商家的 HTML 不显示采集方式和内部证据。
