# 论文草稿评审与修改

## 基本信息

- 版本：v1.1.0
- 适用领域：传播学、心理学、管理学、营销学、健康传播、科学传播等社会科学领域

## 目标

从目标期刊审稿人视角诊断论文草稿，把期刊标准转化为有证据的逐节评价、范例比对和可执行修改清单。评审必须区分文稿事实、外部检索事实与推断，不能用记忆补齐期刊指标、文献或统计结果。

## 触发边界

### 应触发

出现以下任一意图时主动使用：

- 投稿前评审完整论文或部分章节
- 从审稿人视角诊断标题、摘要、引言、理论、方法、结果或讨论
- 对论文逐节打分并给出 P0/P1/P2 修改清单
- 匹配目标期刊、制定顺序投稿策略或评估投稿难度
- 检索目标期刊的相似已发表论文并对标写法
- 预测审稿问题，或在论文评审基础上准备 cover letter 要点

典型请求包括“帮我评审这篇论文”“从审稿人角度看投稿前还要改什么”“给这篇社科论文逐章评分并推荐期刊”“对照目标期刊文章找出差距”。即使用户没有说出 Skill 名，只要核心任务是论文草稿的投稿前诊断，也应触发。

### 不应触发

- 仅做拼写、语法、翻译或语言润色
- 针对已有审稿意见撰写 response to reviewers / rebuttal letter
- 仅撰写研究计划、proposal 或普通文献综述，尚无可评审草稿
- 执行统计分析、清洗实验数据或生成统计结果
- 制作 PPT、新闻稿、博客或商业报告
- 仅查询某本期刊的一个指标，且不涉及论文匹配或投稿诊断

### 复合请求

若请求同时包含论文评审与润色、统计分析或 rebuttal，只执行论文评审部分，并明确标出超出范围的子任务；需要其他能力时，声明应使用对应 Skill，不穿透调用其脚本或工具。

## 输入与边界处理

优先获取：

- 论文草稿：全文或指定章节，可为文档、PDF、Word 或粘贴文本
- 研究领域、研究问题、理论框架和方法
- 目标期刊或期刊层级偏好（可选）
- 字数限制、投稿时间等特殊要求（可选）

边界输入按以下方式处理：

- **未附文稿**：请求补充全文或目标章节；不评分、不假设论文内容。
- **仅有部分章节**：只评审已提供部分；其余标记“未提供”，不给虚构分数。
- **超长文稿**：先建立章节清单与研究画像，再分批评审；保持统一问题台账和评分口径。
- **扫描件、乱码或无法读取的文件**：说明不可读范围，请求可检索文本或更清晰文件。
- **研究信息前后矛盾**：列出冲突位置并请求确认；确认前不替作者选择版本。
- **敏感或未公开材料**：只处理任务所需内容；输出示例时去除姓名、单位、邮箱、伦理编号等不必要标识。

## 核心流程

### 1. 判定评审模式

- **全文评审**：输出研究画像、期刊匹配、范例检索、逐节评审、总评和投稿策略。
- **部分评审**：只评价已提供章节，明确范围与缺失项。
- **期刊匹配**：聚焦研究画像、候选期刊和证据化匹配，不生成虚假的逐节评分。
- **单节聚焦**：只加载该章节所需标准，避免生成完整报告。

### 2. 加载必要资源

任何评审先读 [评审核心原则](references/core-principles.md)。按任务选择：

| 需求 | 资源 |
|---|---|
| 期刊匹配、IF、分区、审稿周期 | [期刊匹配与事实核验](references/journal-matching.md) |
| 逐节检查与评分 | [章节检查清单](references/section-checklist.md) |
| 完整报告 | [报告输出模板](references/output-template.md) |
| 具体改写示例 | [写作问题与范例](references/writing-issues.md) |
| 精准诊断表述 | [诊断话术库](references/diagnostic-phrases.md) |

这些资源是规则与模板，不是外部事实证据；期刊指标和范例文章仍需在本次任务中检索。

### 3. 建立研究画像

通读可用内容，提取研究问题、理论、样本、设计、分析、主要发现、贡献声明和章节完整度。所有结论都要能定位到原文；缺失信息使用 `[INPUT NEEDED]`，待补文献使用 `[CITATION NEEDED]`，待补数据使用 `[DATA NEEDED]`。

### 4. 检索并核验期刊与范例

需要期刊推荐或范例比对时，执行实际检索：

1. 用期刊官网的 Aims & Scope、投稿指南和近年目录核验主题、方法、格式及文章类型。
2. 用 Clarivate Journal Citation Reports 核验 JIF 与 JCR 分区；用中国科学院文献情报中心期刊分区表核验中科院分区。两个体系分列，不能混写。
3. 用期刊官网或出版社官方 metrics 页面核验首轮决定、同行评审或投稿至接收时间，并准确保留其统计口径（平均值/中位数、是否包含 desk reject）。
4. 用 DOI、出版社落地页、Crossref、PubMed、Web of Science 等核验范例文章的题名、作者、年份、期刊和 DOI/PMID。
5. 每项外部事实记录“数值或结论、指标年份/统计口径、来源 URL、查询日期”。来源之间冲突时并列呈现，不取平均，也不擅自判断谁正确。

无法访问权威来源或无法确认时，统一写 `[待核验]`，说明已尝试的来源和受阻原因；不得使用搜索摘要、聚合站、论坛经验或模型记忆填入确定数值。未核验的 IF、分区、审稿周期和录用率不得参与最终排序。

### 5. 逐节评审

按标题、摘要、引言、理论框架、方法、结果、讨论的顺序评审：

1. 引用 draft 的具体位置或原句。
2. 给出精准问题类型及其对审稿判断的影响。
3. 对照已核验范例的具体写法；没有合适范例时明确说“未找到可比范例”，不强行类比。
4. 给出保留项、扣分项和可执行修改方案。
5. 改写示例保持作者原意，不新增研究发现、统计量或文献。

评分采用 10 分制。未提供的章节不评分；每个分数必须同时说明加分点和扣分点。可指出研究设计或分析中的致命局限，但不能伪造补救数据，也不能把需要重新收集数据的方案表述为已完成修改。

### 6. 汇总与优先级

- P0：可能导致拒稿、结论不成立或研究不可核验的问题
- P1：显著削弱理论、方法或叙事质量的问题
- P2：表达、格式和呈现层面的优化

完整稿总分按标题 5%、摘要 15%、引言 20%、理论框架 15%、方法 15%、结果 10%、讨论 15%、其他 5% 计算。部分稿只报告已评章节分数，不外推全文总分。

## 输出要求

默认用中文和结构化表格。完整评审依次包含：

1. Draft 概览与研究画像
2. 潜在目标期刊匹配
3. 目标期刊类似文章检索
4. 逐部分比对与评审
5. 总体评分与 P0/P1/P2 修改清单
6. 投稿策略建议

期刊匹配表至少包含：期刊、匹配证据、IF、JCR 分区、中科院分区、审稿周期、指标年份/口径、来源 URL、查询日期、核验状态。任何无法确认的单元格写 `[待核验]`。

## 产出前门禁

- [ ] 评审模式和范围已声明
- [ ] 文稿缺失部分没有被评分或补写为事实
- [ ] 期刊信息逐项带来源、指标年份/口径和查询日期
- [ ] 无法核验的外部信息已标 `[待核验]`
- [ ] 范例文章已核验题名、作者、年份和 DOI/PMID（如有）
- [ ] 每个批评都能定位原文，并解释为什么影响审稿
- [ ] 每个分数都有加分点、扣分点和修改建议
- [ ] 改写没有引入原稿不存在的数据、发现或引用
- [ ] 总分已按适用权重实际计算
- [ ] P0/P1/P2 定义一致，未用优先级制造夸张结论

## 失败降级

- **外部检索不可用或付费墙阻挡**：保留候选期刊，但相关 IF、分区、审稿周期、录用率均标 `[待核验]`；不基于这些字段排序。
- **只能找到非官方来源**：可作为检索线索，不作为最终证据；继续寻找官方来源，找不到则标 `[待核验]`。
- **找不到高度相似范例**：报告检索式和筛选范围，改用主题、理论或方法最接近的真实文章，并降低匹配度。
- **无法解析文稿**：说明具体失败文件或页码，请求替代格式；不输出貌似完整的评审。
- **证据冲突**：并列来源、日期与口径，标记“来源冲突”；不合并成单一数值。
- **信息不足以评分**：输出诊断清单和待补材料，不给猜测性分数。
