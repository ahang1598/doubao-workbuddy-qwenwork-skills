# 各部分评审检查清单与打分标准

> **文件定位**：本文件提供论文各部分的评审检查清单、常见问题诊断和10分制打分标准，用于确保评审的一致性和可操作性。
> **何时加载**：逐部分打分评审时必读；单节聚焦模式下仅需加载对应部分。
> **使用方式**：评审每个部分时，先按"检查项"逐项核查，再对照"常见问题"定位问题类型，最后按"打分参考"给出分数并说明扣分点/加分点。

## 打分标准总则

| 分数段 | 含义 | 描述 | 审稿人对应判断 |
|-------|------|------|-------------|
| 9–10 | 优秀 | 达到顶刊发表水平，无需修改或仅需微调 | 接受（Accept） |
| 7–8 | 良好 | 基本达标，有少量可改进之处 | 小修（Minor Revision） |
| 5–6 | 及格 | 存在明显不足，需要较大修改 | 大修（Major Revision） |
| 3–4 | 较差 | 问题严重，需要重写 | 拒稿但鼓励重投（Reject & Resubmit） |
| 1–2 | 很差 | 完全不符合学术规范，需要从头写 | 直接拒稿（Reject） |
| 0 | 缺失 | 该部分未写或完全不可用 | 不适用 |

**打分时必须同时说明**：
- **扣分点**：具体哪里不好、为什么扣分、扣了多少分
- **加分点**：哪里做得好、值得保留
- **修改建议**：具体怎么改，最好有改写示例

## 一、标题评审清单

### 检查项
- [ ] 标题是否准确反映研究内容（不夸大、不模糊）？
- [ ] 标题是否包含核心理论/方法/变量标识？
- [ ] 标题长度是否符合期刊要求（通常10-20个英文单词）？
- [ ] 标题是否有吸引力（能引起目标读者兴趣）？
- [ ] 标题是否避免了缩写、行话和无意义的修饰词？
- [ ] 标题是否与期刊已发表文章的标题风格一致？

### 常见问题
- **过于宽泛**：如"社交媒体与健康"——没有具体变量和关系，审稿人无法判断研究内容
- **过于冗长**：超过25个单词，包含不必要的修饰（如"一项关于...的探索性研究"）
- **方法缺失**：实验研究不在标题中体现"实验"，审稿人无法快速判断研究类型
- **误导性**：标题暗示的发现与实际研究不符（如标题说"影响"但实际是横截面相关）
- **缺乏区分度**：与已有文章标题过于相似，无法体现本研究的独特性

### 打分参考
- 9–10分：精准、简洁、有信息量，包含核心变量和方法标识，与期刊风格一致
- 7–8分：基本准确，可优化措辞或增加方法/理论标识
- 5–6分：过于宽泛或模糊，缺少核心要素，需要重写
- 3–4分：严重不准确、冗长或误导性

## 二、摘要评审清单

### 检查项（标准结构化摘要）
- [ ] 背景/问题：1-2句说明研究背景和缺口
- [ ] 方法：1句说明研究设计、样本、关键操纵/测量
- [ ] 结果：2-3句说明核心发现（含效应方向和关键统计）
- [ ] 贡献/启示：1句说明理论或实践贡献
- [ ] 关键词：4-6个，覆盖主题、方法、理论
- [ ] 字数是否符合期刊要求（通常150-250英文词）？
- [ ] 是否避免了引用文献和缩写（或首次出现时解释）？

### 常见问题
- **背景过长**：用3-4句讲背景，挤占结果空间，信息密度倒置
- **方法模糊**：只说"通过实验研究"，不说明具体设计、样本量和关键操纵
- **结果空洞**：只说"发现了显著效应"，不说明具体效应、方向和统计量
- **贡献缺失**：没有说明研究的理论或实践价值，摘要戛然而止
- **关键词不当**：用太泛（如"社交媒体"）或太偏的词，影响检索和定位

### 打分参考
- 9–10分：结构完整、信息密度高、每句都有实质内容、结果含统计量
- 7–8分：结构完整，部分句子可优化（如方法可更具体、结果可加统计量）
- 5–6分：结构有缺失或信息密度低，需要较大修改（如结果空洞、贡献缺失）
- 3–4分：结构混乱或关键信息缺失（如没有方法或结果）

## 三、Introduction评审清单

### 检查项
- [ ] 开篇是否有有效的hook（现象、数据、矛盾、故事）？
- [ ] 是否逐步缩小到具体研究问题（从宽到窄的漏斗结构）？
- [ ] 文献综述是否批判性而非罗列式（概念驱动而非作者驱动）？
- [ ] 是否清晰定位了research gap（现有研究缺什么、为什么重要）？
- [ ] 研究问题/假设是否明确陈述？
- [ ] 是否预告了理论贡献（本文如何填补gap）？
- [ ] 是否有文章路线图（roadmap paragraph）？
- [ ] 段落之间是否有逻辑衔接（每段结尾引出下一段）？
- [ ] 是否避免了"本文首次研究"等无法证实的表述？
- [ ] Introduction长度是否合理（通常占全文15-20%）？

### 常见问题
- **漏斗倒置**：开头太窄（直接讲具体变量），无法展开研究背景和意义
- **文献罗列**："A发现了X，B发现了Y，C发现了Z"——没有综合和批判，是作者驱动而非概念驱动
- **gap不明确**：只说"研究较少"，不说明具体缺什么维度、什么机制、什么样本、什么方法，以及为什么这个缺口重要
- **贡献夸大**：声称"首次"但实际已有类似研究，或声称"重要贡献"但不说明具体是什么
- **缺少路线图**：读者不知道后面每节讲什么，文章结构不清晰
- **逻辑跳跃**：段落之间没有过渡，读起来碎片化，从背景直接跳到假设

### 打分参考
- 9–10分：漏斗结构清晰、gap定位精准（problematization而非gap-spotting）、贡献有说服力、逻辑流畅
- 7–8分：结构完整，gap或贡献部分可加强，文献综述可更批判性
- 5–6分：gap不清晰或文献综述罗列，需要重构组织方式
- 3–4分：结构混乱或缺少核心要素（如没有gap或研究问题）

## 四、理论框架与假设评审清单

### 检查项
- [ ] 理论是否被正确引入和概述（不是只提名字，而是说明核心命题）？
- [ ] 假设推导是否有理论依据（不是凭直觉，而是理论→推理→假设的链条）？
- [ ] 每个假设是否有明确的因果方向？
- [ ] 假设之间是否有逻辑递进关系？
- [ ] 是否有变量关系图（概念模型图）？
- [ ] 假设表述是否规范（"X正向影响Y"而非"X与Y相关"）？
- [ ] 是否区分了主效应、中介效应、调节效应？
- [ ] 中介/调节假设是否有充分的理论推导？

### 常见问题
- **理论装饰化**：提了理论名字但没有用理论的核心命题推导假设，理论和假设脱节
- **假设跳跃**：从理论直接跳到假设，缺少中间推理步骤（如预测了A→C但未建立A→B和B→C的逻辑链）
- **假设表述模糊**："X可能影响Y"——没有方向和机制，无法检验
- **中介调节混淆**：把中介当调节或反之，变量关系不清晰
- **缺少模型图**：变量关系不直观，审稿人难以快速理解研究框架
- **假设无独立推导**：多个假设挤在一段，每个假设没有独立的文献和理论推导段落

### 打分参考
- 9–10分：理论运用深入（用核心命题推导假设）、假设推导严密、模型清晰、表述规范
- 7–8分：理论运用基本到位，部分假设推导可加强（如增加中间推理步骤）
- 5–6分：理论运用表面化（装饰化）或假设推导薄弱，需要重构推导逻辑
- 3–4分：理论与假设脱节或假设不规范（模糊、无方向）

## 五、研究方法评审清单

### 检查项
- [ ] 研究设计是否清晰说明（实验设计类型、被试间/被试内、混合设计）？
- [ ] 样本是否充分描述（来源、人口学特征、样本量依据）？
- [ ] 操纵是否详细描述（材料、程序、操纵检验）？
- [ ] 测量工具是否说明（量表来源、题项数、信度）？
- [ ] 分析策略是否明确（用什么统计方法、为什么）？
- [ ] 是否报告了伦理审查和知情同意？
- [ ] 是否有预注册（如适用）？
- [ ] 方法部分是否足够详细，可被重复？
- [ ] 是否报告了排除标准和排除率？
- [ ] 是否有a priori power analysis？

### 常见问题
- **样本量无依据**：不说明为什么用这么多样本，没有power analysis
- **操纵描述模糊**：不说明具体操纵材料和程序，只说"通过情景材料操纵"
- **测量工具不透明**：不说量表来源、题项数和信度，无法判断测量质量
- **分析方法不匹配**：用了错误的统计方法（如用t检验分析三因素交互）
- **缺少操纵检验**：实验研究不报告操纵检验，无法确认操纵有效
- **伦理缺失**：不说明IRB审批和知情同意，顶刊通常要求
- **排除标准不明**：不说明排除了哪些被试、为什么排除、排除率多少
- **可重复性不足**：方法描述不够详细，其他研究者无法重复

### 打分参考
- 9–10分：方法描述详尽、可重复、有power analysis、符合顶刊标准
- 7–8分：方法基本完整，部分细节可补充（如操纵检验、排除标准）
- 5–6分：关键信息缺失（如样本量无依据、操纵模糊）或方法有瑕疵
- 3–4分：方法描述严重不足或有致命缺陷（如分析方法错误）

## 六、结果评审清单

### 检查项
- [ ] 结果是否按假设顺序呈现？
- [ ] 统计报告是否规范（F/t/χ²值、df、p值、效应量、置信区间）？
- [ ] 操纵检验是否在主分析之前报告？
- [ ] 图表是否清晰、标注完整、符合期刊格式？
- [ ] 结果是否只陈述发现，不做过度解读（解读留到讨论）？
- [ ] 中介/调节效应是否用正确方法检验（Bootstrap、简单斜率）？
- [ ] 是否报告了所有假设的检验结果（包括不显著的）？
- [ ] 是否有补充分析（稳健性检验）？
- [ ] p值是否精确报告（p>.001报具体值，p<.001报p<.001）？

### 常见问题
- **只报显著结果**：隐瞒不显著的假设检验，选择性报告（学术不端风险）
- **统计报告不规范**：缺效应量或置信区间，或p值只报p<.05不报具体值
- **图表质量差**：坐标轴无标注、图例不清、颜色不可打印（黑白印刷时无法区分）
- **结果与讨论混淆**：在结果部分做理论解读（"这一结果说明..."），应留到讨论
- **顺序混乱**：不按假设顺序呈现，或操纵检验在主分析之后才报告
- **中介报告不完整**：不报告PROCESS model number、bootstraps次数、置信区间
- **非显著结果被spin**：把不显著结果描述为"边缘显著""趋势显著"，误导读者

### 打分参考
- 9–10分：结果呈现规范、完整（含不显著结果）、统计报告标准、图表专业
- 7–8分：结果基本完整，统计报告或图表可优化（如补充效应量）
- 5–6分：结果有遗漏（如不报告不显著假设）或统计报告不规范
- 3–4分：结果严重不完整或统计错误（如选择性报告、分析方法错误）

## 七、讨论评审清单

### 检查项
- [ ] 是否回顾了核心发现（不是重复结果，而是提炼关键模式）？
- [ ] 理论贡献是否充分论证（不是只说"有理论贡献"，而是具体说明贡献了什么）？
- [ ] 是否与前人研究对话（一致/不一致/扩展了什么）？
- [ ] 实践启示是否具体可行（不是空泛的"有实践意义"）？
- [ ] 局限是否诚实且有深度（不是只说"样本不具代表性"）？
- [ ] 未来研究方向是否具体（不是"未来可进一步研究"）？
- [ ] 结论是否简洁有力（不引入新数据）？
- [ ] 讨论长度是否合理（通常占全文20-25%）？
- [ ] 理论贡献是否编号（First/Second/Third），每个贡献对应一个发现？

### 常见问题
- **贡献空泛**："本研究有重要理论贡献"——不说明具体是什么贡献、拓展了什么理论
- **不与文献对话**：不说明结果与前人研究的关系（一致/不一致/扩展），讨论变成自言自语
- **实践启示敷衍**："建议从业者注意"——没有具体建议，无法落地
- **局限套路化**："样本量小、横截面、自报告"——每个研究都这么写，没有针对本研究的具体局限
- **未来方向空泛**："未来可探讨更多变量"——没有具体方向和研究设计建议
- **讨论过长**：重复结果或引入无关内容，挤占贡献论证空间
- **贡献与发现不对应**：声称有三个贡献但只有两个发现支撑，贡献无依据

### 打分参考
- 9–10分：贡献论证充分（编号式、具体）、与文献深度对话、启示具体、局限深刻且配对未来方向
- 7–8分：讨论结构完整，贡献或启示部分可深化（如贡献可更具体）
- 5–6分：贡献空泛或局限套路化，需要重写部分内容（如贡献论证、局限性）
- 3–4分：讨论严重不足或结构混乱（如没有贡献论证、不与文献对话）

## 八、其他部分评审清单

### 参考文献
- [ ] 格式是否符合期刊要求（APA/MLA/Chicago等）？
- [ ] 引用是否完整（正文引用的文献都在列表中，反之亦然）？
- [ ] 是否优先引用了高质量期刊和近年文献？
- [ ] 是否有自引过多或引用低质量文献的问题？
- [ ] 文献信息是否准确（作者名、年份、期刊名、卷期页码）？

### 图表
- [ ] 图表是否在正文中被引用（按顺序引用Figure 1, Table 1等）？
- [ ] 图表标题和注释是否完整（独立可读，不依赖正文）？
- [ ] 图表是否独立可读（不依赖正文也能理解）？
- [ ] 图表数量是否合理（不冗余，每个图表都有实质信息）？
- [ ] 图表分辨率是否符合期刊要求（通常300dpi以上）？

### 语言与格式
- [ ] 是否有语法错误、拼写错误？
- [ ] 学术语气是否一致（不口语化、不用 contractions）？
- [ ] 术语使用是否一致（全文统一变量名称和术语）？
- [ ] 行距、字体、页边距是否符合期刊要求？
- [ ] 统计符号是否斜体（F, t, b, SE, p, η², β, χ²）？
- [ ] 时态是否正确（文献/理论用现在时，方法/结果用过去时，讨论解释用现在时）？
