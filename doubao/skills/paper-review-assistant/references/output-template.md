# 6部分评审报告输出模板

> 本文件提供全文评审报告的完整输出结构模板。生成完整评审报告时必须严格按此结构输出，默认使用中文，尽量使用表格。部分评审模式可仅输出相关部分，但必须在开头标注评审范围。

## 第1部分：Draft 概览与研究画像

### 1.1 研究画像表

| 维度 | 内容 |
|-----|------|
| 研究主题 | （用一句话概括核心研究问题和对象） |
| 理论框架 | （核心理论、中介/调节机制） |
| 研究方法 | （实验/问卷/质性/混合，样本量，设计类型） |
| 核心发现 | （2-3个最关键的实证发现，含效应方向） |
| 论文结构 | （已完成哪些部分，哪些缺失/不完整） |
| 目标读者领域 | （传播学/心理学/管理学/健康传播等） |

### 1.2 研究概括

用2-3句话概括这篇论文"做了什么、怎么做的、发现了什么、贡献是什么"。

**示例格式**：本研究以[理论框架]为基础，通过[研究方法]检验了[核心关系/机制]。结果发现[核心发现1]，且[核心发现2]。研究贡献在于[理论/实践贡献的具体表述]。

### 2.2 各期刊补充说明

对每本期刊补充以下信息（至少覆盖首选期刊）：

- **偏好的研究类型和理论视角**：该期刊倾向发表什么类型的研究？偏好什么理论传统？
- **近期类似主题文章趋势**：近3年该期刊是否发表过类似主题？趋势如何？
- **投稿策略定位**：首选/备选/保底，以及理由

### 2.3 推荐投稿顺序

明确标注：首选期刊→备选期刊→保底期刊，并说明排序逻辑。

## 部分评审模式的输出调整

如用户仅提供部分章节，输出时做以下调整：

1. **开头标注**："本次评审范围：[已提供的部分]。[未提供的部分]未提供，不纳入评审。"
2. **第1部分**：研究画像中标注哪些部分未提供
3. **第2-3部分**：如用户未要求期刊匹配，可省略或简化
4. **第4部分**：仅评审已提供的部分，未提供部分标注"未提供"并给出写作建议框架，不打分
5. **第5部分**：总体评分仅计算已评审部分，标注"基于已提供部分的评分，全文评分可能不同"
6. **第6部分**：如未做期刊匹配，投稿策略部分可省略
