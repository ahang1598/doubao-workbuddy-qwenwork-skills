# PDF 获取：最短可靠路径

目标是取得可核对的原文，不是默认逐页 OCR。

## 路由

1. **先按来源类型选工具**：本地附件和本地路径使用 `Read` 或等价本地读取工具；只有 `http/https` 远程地址才用 `web.fetch`。`web.fetch` 不支持 `/Users/...`、相对路径或 `file://`，不得尝试后再当作来源失败。
2. **直接全文获取成功且结构清楚**：使用一次全文结果。
3. **文字可取但顺序可疑**（双栏、复杂表格、脚注、跨页图注）：只定点读取或渲染可疑页并修正受影响区域。
4. **部分页面是扫描件**：仅对这些页 OCR，并保留页码。
5. **全文获取失败**：使用可用 PDF 工具提取；仍失败时说明实际可读页码和缺口。

不得把搜索摘要当全文。不得因存在 PDF 就固定逐页截图。

## 范围与长文处理

- 用户明确只翻译指定页、章节或片段时，只处理该范围，不自动扩展为全文。
- 全文或长范围可按章节或连续页做内部处理分段，再依原文顺序合并并统一核对跨页句、编号和术语。
- 内部处理分段不等于分批交付；确有读取、OCR、来源或工具缺口时，在最终回复中如实说明。
- 飞书任务必须先完成用户要求的全部范围，生成并校验一份完整 `translation.xml`，默认整篇一次创建；只有整篇创建明确因载荷、长度或服务限制失败且没有留下可用文档时，才按 `output-and-qa.md` 在同一最终文档内使用最多 3 个连续大段兜底。
- 聊天任务若一次回复无法完整承载，可按原文顺序在后续回复继续，并明确每次回复的实际范围；不得改成摘要。若本轮因文件过长仍未完成用户要求的范围，必须列出已译和未译的具体来源页码，并询问“是否需要我继续翻译第 X—Y 页？”；来源没有稳定页码时才使用连续章节或段落范围。

## 最小表图清单

来源含 Table、Figure 或 Supplement 时，从 `assets/coverage-ledger-template.json` 复制生成 `coverage-ledger.json`。编号明确时每项只登记来源编号 `id`，例如 `Fig. 1`、`Table 1`；校验器自动匹配译文中的常见中英文图表标签。只有无法由编号识别的项目才增加 `target_marker`。不要写入题名、期刊、翻译方向、范围、参考文献策略、交付模式、译文全文或长图注。没有表图/补充材料时不创建清单。章节、首中尾、页码、范围、缺口和参考文献策略均不进入机器清单。

全文结果没有提取出已登记的表格、图注、图片文字、尾部声明或参考文献边界时，只定点获取对应页；不要重新逐页读取整篇。表格必须保留全部可读列、行、脚注和注册号，不得以摘要性文字替代，也不得在已知可能不完整时凭“基本信息”或记忆重建。图片无法嵌入时也必须翻译题注和图中可读文字，并把图片缺失登记为交付缺口。

“全文翻译”完成前必须核验首页、至少一个正文中段、每个表图所在页和末页。双栏 PDF 重点核对阅读顺序；扫描 PDF 重点核对 OCR 的小数点、负号、希腊字母和上下标。

## 交付判定

- 门槛 A 只检查本地 `translation.xml` 非空、XML 良构、`<sup>`、已登记表图/补充材料文字锚点和真实表格块数量。
- 门槛 B 只检查飞书 create/update 的返回状态、document ID 和 revision，不 fetch 或检查飞书正文。
- 用户只说“全文翻译”时，参考文献列表默认不翻译、不保留，也不写入飞书；这不构成缺口。只有用户明确要求纳入时，参考文献占位句、终止编号或文献数量说明才不能证明条目已纳入。
- 聊天直译不额外复述文章内容；飞书论文通过门槛 A/B 后的外部回执按 `output-and-qa.md` 提供已核验基本信息和来源内内容概括，不得概括未读页或扩展成论文解读。
