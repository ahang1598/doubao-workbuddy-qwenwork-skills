# 不同医学文本的翻译规则

只加载与当前来源匹配的一节。

## 论文、摘要、系统综述与指南

- 保持 IMRaD、推荐条目和证据等级结构。
- effect estimate、95% CI、P 值、异质性、非劣效界值等不得弱化或强化。
- guideline recommendation 中的 recommend/suggest/may/should/should not 保持力度差异。
- 作者姓名按原文保留，不翻译、不音译、不转写拼音、不调整姓名顺序；机构、科室、地址和作者角色正常翻译。
- 中译英时，本研究已经完成的方法和观察结果通常用过去时；所有时间关系以来源为准，用户明确提供的体例只在不改变语义时应用。
- 中文长定语可拆为英文分句，省略主语可在上下文唯一支持时补出；不得借此补造行为主体、逻辑关系或研究结论。

## 病历、出院记录和病例报告

- 保留时间线、主诉、现病史、既往史、查体、检查、评估和计划的层级。
- “denies”“no evidence of”“cannot exclude”不可互换。
- 诊断名称、疑似/待排/既往状态不能混写。

## 影像、病理和检验报告

- 保留部位、侧别、尺寸、数量、强化特征、切缘、分级、免疫组化阳性/阴性和参考范围。
- impression/diagnosis 与 findings 分开。
- 不补 TNM 分期、病理分型或临床意义，除非原文明确给出。

## 临床试验和药品资料

- 保留随机、盲法、分层、方案版本、访视窗口、入排标准和终点定义。
- 药名、剂型、剂量、途径、频次、疗程、减量/停药条件逐项绑定。
- adverse event、serious adverse event、adverse reaction 不随意互换。

## 手术和操作材料

- 保留体位、入路、解剖标志、器械动作、关键步骤、术中发现、并发症和术后处理。
- 技术名称首次出现可给中英对照，后续保持统一。

## 患者版

- 句子可更短，首次出现术语可加括注。
- 不删除风险、限制、复查要求或不确定性。
- 不把“可能”写成“确定”，不新增安慰或治疗建议。
