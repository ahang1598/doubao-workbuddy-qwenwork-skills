# 医学学术中译英

本文件仅用于中文医学论文、摘要、指南、研究报告等学术材料译成英文。目标是得到符合常见学术表达的英文，同时保持来源命题、证据强度和不确定性不变。

## 先建立命题映射

逐句识别并绑定：

- 研究对象、样本和亚组；
- 干预、暴露、对照和结局；
- 时间、条件、范围和比较关系；
- 数字、单位、效应量、置信区间和 P 值；
- 否定、可能性、相关性、因果性和限制条件。

可以拆句、合句、调整主语或改变信息顺序，但重构后每个来源命题都必须仍可定位，不能新增或删除科学含义。

## 三遍生成

1. **语义成册**：先提取事实、限定词和高风险绑定，不沿中文词序逐词替换。
2. **英文成句**：使用清楚的主谓结构和本领域常见搭配；只有来源唯一支持时才补出中文省略的逻辑连接。
3. **双语回核**：从英文反向复述命题，逐项比较对象、动作、条件、方向、强度和范围。

歧义存在多种合理解释时，不替作者选择。采用最贴近原文的保守译法，并把问题写入译文之外的“待确认项”。

## 学术英语要求

- 优先准确、清楚、克制的科学表达，不追求华丽、宣传性或刻意复杂的措辞。
- 避免中文式长定语、连续名词堆叠和无必要的抽象名词；可用动词或分句提高可读性。
- 只使用论证所必需的连接词，不补造因果、递进、转折或作者立场。
- 术语、缩写、大小写、连字符、统计符号和单位在全文保持一致；缩写无据不得擅自展开。
- 中文或其他语言的作者姓名保持来源原样，不转写拼音、不翻译、不调整姓名顺序；作者机构、科室、地址和角色说明正常译成英文。
- Methods 和已经完成的研究操作通常使用过去时；Results 中本研究观察结果通常使用过去时。所有时间关系以来源为准；用户明确提供的体例只在不改变语义时应用。
- 主动或被动语态按句意和学科惯例选择，不为追求某一语态改变责任主体。
- 指南中的“建议、推荐、可以、不应”等力度必须在英文中保持区分。

## 不可越过的语义边界

- 不新增数据、阈值、引用、方法细节、机制解释、创新性声明或临床建议。
- 不把相关关系写成因果关系，不把探索性结果写成确证性结论。
- 不删除 `可能`、`提示`、`尚不能确定`、`不能排除`、样本限制或适用条件。
- 不把“不显著”写成“无效”，不把“非劣效”写成“等效”。
- 不擅自添加 `first`、`only`、`best`、`superior`、`prove`、`definitively` 等更强表述。
- 若来源本身明确包含强结论或创新性声明，忠实翻译，并在译文之外提示作者核验证据；不得静默弱化或强化。
- OCR、公式、表头或缩写不清时标记待确认，不能根据常识猜补。

## 与学术润色的边界

中译英可以为形成自然英文而重构句法，但不能替作者：

- 重组论文论证或章节；
- 改写研究结论；
- 补充证据、引用或机制；
- 扩写讨论、创新点或临床意义；
- 对已经是英文的稿件做独立语言润色。

用户的主任务是来源内翻译、双语对照或术语核对时，仍由本 Skill 完成，即使目标是规范学术英语。主任务是投稿级润色、去 AI 腔、按期刊风格改写或重组论证时，路由到 `doubao-academic-polish`；不能只依据输入语言分流。

## 交付前检查

中译英学术材料至少完成：

1. 来源—译文命题逐项对齐；
2. 医学实体与数字、结局、时间和比较组绑定核对；
3. 否定、模态、相关/因果和结论力度核对；
4. 术语一致性与章节时态核对；
5. 作者姓名与原文逐字核对，未翻译、音译、转写拼音或调整顺序；
6. 英文语法、搭配、标点和可读性核对；
7. 不可辨内容和歧义已进入译文之外的待确认项。

可运行确定性检查：

```bash
python scripts/validate_translation_fidelity.py \
  translation.xml \
  --autofix \
  --report fidelity-report.json
```

来源含表图/补充材料时再传入最小表图清单。该脚本只检查 XML、已登记表图、真实表格块和 `<sup>`，不判断中译英方向、范围、参考文献策略、数字/单位、语义强度、中文残留、基金措辞或一般学术表达。命题对齐、医学语义、专名保留和学术英语质量必须直接按本文件在翻译与逐段审读中核对。
