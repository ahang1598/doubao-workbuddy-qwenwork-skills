# 翻译质量核对

本文件对应门槛 A。检查未全部完成或校验器非零退出时，不得进入飞书写入和成功交付。

## 高风险绑定

逐项确认原文实体仍与正确结果绑定：

- 药物 ↔ 剂量/途径/频次；
- 人群/亚组 ↔ 样本量/效应量；
- 结局 ↔ 时间点/比较组/置信区间；
- 解剖部位 ↔ 侧别/尺寸/阳性阴性；
- 事件 ↔ 发生时间/严重性/因果判断。

## 易错语义

- `not significant` 不是“无效”。
- `noninferior` 不是“等效”。
- `associated with` 不是“导致”。
- `may/could` 不得译为确定结论。
- `no evidence of` 不等于绝对不存在。
- `rule out` 依据语境区分“排除”与“待排除”。

## 一致性

建立小型术语表，只收录：

- 有多个常见译法但本文需统一的术语；
- 容易与相邻概念混淆的缩写；
- 用户要求保留英文的术语。

不要把普通词汇堆成大词表。

作者姓名不进入术语翻译表。无论英译中还是中译英，署名、通讯作者、作者贡献、致谢具名人员、表图署名及显式纳入的参考文献作者均须与原文逐字核对，保留原始拼写、缩写、连字符、变音符号和姓名顺序；不翻译、不音译、不转写拼音，也不猜测权威外文名。机构、科室、地址、作者角色和说明文字正常翻译。

术语表是质量约束，不是翻译引擎。不得使用术语表、正则表达式、逐词/逐短语 `replace` 或搜索替换批量生成最终译文，也不得把未命中的原文片段保留在目标语言句子中。每个段落、列表项、表格单元格、图题和图注都要先按完整语义翻译，再用术语表检查一致性；脚本只能报告潜在不一致，不能代替句法重构和双语审读。

## 中译英学术质量

中文论文、摘要、指南或研究材料译成英文时，必须先完整读取 `zh-en-academic.md`。除上述医学高风险绑定外，还要检查：

- 来源命题在英文中逐项可定位，句法重构没有改变研究对象、条件或结果；
- `相关` 未升级为因果，`提示/可能/尚不能确定` 未变成确定结论；
- 没有新增创新性、优越性、机制、引用或临床意义；
- 术语、缩写、大小写、连字符、统计符号和单位一致；
- 时态、语态和表达符合相应章节的常见学术英语，但不覆盖来源时间语义；
- 英文清楚、克制、可读，没有明显中文残留或中文全角标点。

学术自然度检查是翻译与逐段双语审读的一部分，不是独立润色任务；来源忠实度始终优先。来源明确要求保留中文专名时，只保留来源实际出现的原词，并在术语表或待确认项说明；结构校验器不判断中文残留。

## 不确定性

来源歧义、OCR 可疑、缩写无法唯一展开、表格列头缺失时：

1. 保留最贴近原文的译法；
2. 标注原文；
3. 写入“待确认项”；
4. 不静默猜测。

## 全文翻译过程检查

本节只用于目标范围已经全部完成、准备交付的任务。长文内部可以分段处理，但飞书写入前必须先合并为完整 `translation.xml`。

最终全文交付还必须逐项确认：

- PDF 的目标范围均已可靠读取；
- 目标范围内的一级章节及二、三级小节均已按原文顺序逐项翻译和复核；
- 每张表以不同的实际 `<table>` 块进入译文；全部可读列、行、单元格和脚注仍须逐项翻译并回到原文核对，但不建立逐行机器锚点；
- 所有图题、图注和图中可读文字均进入译文；
- 作者姓名已按原文保留，未翻译、音译、转写拼音或调整顺序；
- 基金、致谢、作者贡献、利益冲突等尾部内容按原文翻译；这些常规措辞由本检查引导，不建立逐词机器硬门槛；
- 参考文献处理与用户要求一致：默认排除；显式纳入时逐条保留原文或逐条翻译；
- 显式纳入参考文献时，译文没有“详见原 PDF”“共若干篇”“未收录”等占位式替代；
- 译文没有 `<sup>`，固定上下标使用 Unicode。

如果模型已判断某张表“可能不完整”，必须回到表格所在页继续读取和逐行核对；不得根据表题、若干示例行或记忆补成一张更短的新表。无法取得全部单元格时只能登记缺口并降级，不能继续声称全文。

运行：

```bash
python scripts/validate_translation_fidelity.py \
  translation.xml \
  --autofix \
  --report fidelity-report.json
```

有表图/补充材料时增加 `--coverage-ledger coverage-ledger.json`。退出码为 0 且逐段双语高风险绑定复核完成，门槛 A 才通过。脚本通过只证明其声明的最小格式与表图检查，不替代逐段双语核对。

中译英不增加额外机器参数。门槛 A 只硬拦截空译文/无效 XML、缺少登记表格的真实 `<table>` 块、缺少已登记表图/补充材料文字锚点和未修复的 `<sup>`；其他内容均由可靠读取、逐段双语医学复核和学术英语审读完成。
