# 短视频分镜脚本编导

使用本 skill 时，把选题、文案、产品 brief、口播稿或已有脚本，转成能直接拍摄和剪辑的短视频分镜。重点是让执行人员清楚知道：拍什么、拍几秒、镜头怎么看、谁说什么、剪辑节奏是什么。

## 文件路由

按任务需要读取对应参考文件，不要一次性加载全部内容：

| 需求 | 读取 |
| --- | --- |
| 新写分镜、重写、大幅优化、增强钩子或创意质感 | `references/creative-playbook.md`（创作类任务必读） |
| 确认表格字段、交付结构、文档输出、修改格式 | `references/output-format.md`（默认丰富交付必读） |
| 默认丰富交付、分镜图、封面图、视觉一致性或图片状态清单 | `references/visual-storyboard.md`（默认丰富交付必读） |
| 指定抖音、快手、B站、视频号、小红书视频、TikTok、信息流广告，或要求平台适配、发布建议、运营打法、平台语感差异 | `references/platform-operations.md` |
| 涉及最新趋势、平台规则、竞品案例、热点、合规敏感信息 | `references/research-workflow.md` |

只使用相对路径，不依赖本地绝对路径。

## 适用场景

用户要求以下内容时使用：

- 短视频分镜脚本、拍摄脚本、逐镜头脚本、镜头表、storyboard、可执行视频脚本。
- 把已有口播稿、文案、产品信息、营销卖点、活动 brief 或选题转成分镜表。
- 评估、优化或重写已有分镜脚本。
- 增加景别、机位、时长、画面动作、台词、音效、花字、道具清单、场景清单、剪辑提示。

以下情况不要强行使用：

- 只要选题、账号定位、标题、评论区话术、直播话术或纯文案。
- 只要普通口播稿/讲稿，不需要画面和镜头拆解。
- 只做热点盘点、竞品分析、平台趋势总结，但不产出分镜脚本。
- 只要求「标题 / 文案 / 小红书文案 / 公众号标题 / 评论区互动」等内容。
- 要求小红书图文笔记、公众号文章、论文/学术写作、翻译、润色、摘要、标题库、账号定位、直播话术、评论区话术或平台运营报告，且没有要求产出可拍摄分镜。

## 边界判定与回复策略

先判断任务是否需要“可拍摄、可剪辑、含镜头拆解的短视频分镜脚本”。**显式要求使用本 Skill 不是覆盖边界的理由**：用户说“使用这个 Skill / 使用我上传的 Skill / 按这个 Skill 来”时，仍必须先检查任务是否属于短视频分镜脚本。

### 不适用时的固定回复

遇到不适用请求，不创建在线文档，不输出分镜表，只做简短边界说明：

| 不适用任务 | 示例 | 回复策略 |
| --- | --- | --- |
| 小红书图文 | “帮我写一篇小红书笔记，主题是早睡” | 说明这是小红书图文文案，不属于短视频分镜脚本；如需使用本 Skill，请明确要小红书视频脚本、镜头、台词和剪辑建议。 |
| 公众号文章 | “帮我写一篇公众号文章” | 说明这是公众号长文写作，不属于短视频分镜脚本；本 Skill 只生成可拍摄的视频分镜和执行方案。 |
| 论文/学术写作 | “使用这个 Skill，帮我写一篇论文，关于抖音达人生态” | 说明这是论文/学术写作，不属于短视频分镜脚本；如需使用本 Skill，可提供研究材料并要求改成科普视频分镜。 |
| 翻译 | “帮我把这段英文翻译成中文” | 说明这是翻译任务，不属于短视频分镜脚本。 |
| 润色/改写 | “帮我润色这段文案” | 说明这是普通文案润色，不属于短视频分镜脚本；如要使用本 Skill，请说明要改成可拍摄视频分镜。 |
| 摘要/总结 | “帮我总结这篇文章” | 说明这是摘要总结任务，不属于短视频分镜脚本。 |
| 标题/选题 | “帮我写 20 个抖音标题” | 说明这是标题或选题生成，不属于短视频分镜脚本。 |
| 账号定位/运营报告 | “帮我做一个抖音账号定位/短视频运营方案” | 说明这是账号或运营策略任务，不属于分镜脚本；除非用户要求产出具体可拍摄脚本。 |
| 直播/评论话术 | “帮我写直播成交话术/评论区回复” | 说明这是直播或评论运营话术，不属于预制短视频分镜脚本。 |

可直接使用的边界回复模板：

> 这个请求不属于“短视频分镜脚本”范围。本 Skill 只适用于生成可拍摄、可剪辑、包含镜号/时长/景别/机位/画面/台词/音效花字的短视频脚本。如果要使用本 Skill，请补充或改成“把这些内容做成短视频分镜脚本”。

### 模糊输入处理

- 用户只说“写个脚本”，但没有出现“短视频 / 拍摄 / 分镜 / 镜头 / 景别 / 画面 / 机位 / 剪辑 / storyboard”等信号时，只追问一次：`你需要普通口播稿，还是可拍摄的短视频分镜表？`
- “抖音文案 / 快手文案 / 视频号文案”默认不触发；只有用户要求视频脚本、镜头拆解、拍摄执行或剪辑建议时才触发。
- “小红书视频脚本”触发；“小红书笔记 / 小红书图文”不触发。
- “把论文/文章/报告做成视频”触发，把原材料当素材生成短视频分镜；不要生成论文或长文正文。
- “分析爆款短视频/平台趋势”默认不触发；如果用户要求“基于分析生成分镜脚本”，分析只作为辅助，最终必须输出分镜。
- 复合任务只执行本 Skill 范围内的部分：例如“分镜 + 发布排期 / 直播话术 / 账号定位”，只生成分镜脚本，并说明其他部分需作为后续任务处理。

## 默认输出方式

默认必须做在线文档交付，采用 **MD 中转策略**：先将完整交付内容写入本地 `.md`（或 `.xmlmd`、`.xml`）文件，再通过飞书文档导入功能转为在线文档。不直接调用飞书文档 API 创建文档。用户明确说“只要文字/只要表格/不要文档/直接在聊天里给”时，才降级为轻量聊天输出。

用户明确说“不要图片”时，只跳过封面图和关键分镜图生成，仍按丰富在线文档交付；不要因此降级为轻量聊天输出。

- 丰富模式优先：交付物必须包含项目概览、创意策略、完整 7 列分镜表、封面方案区、视觉参考区（关键分镜图）、拍摄执行包、剪辑提示、平台适配和合规提醒。
- 视觉参考区（关键分镜图）默认生成：默认选取关键分镜，目标生成 3 张关键分镜图，最多 5 张；并额外给 1-3 个封面方案或封面图；不需要用户额外明确要求。
- 本地文档格式：优先使用 `.md`；若飞书导入支持 `.xmlmd` 或 `.xml` 格式且效果更好，可选用。
- 视觉参考区（关键分镜图）状态必须原位回填：图片生成成功时，替换或填充视觉参考区对应镜号；图片失败时，在原位写 `待生成 + 图片生成提示词`。
- 禁止在文档末尾追加“分镜图预览”来绕过视觉参考区；封面图必须进入封面方案区，关键分镜图必须进入视觉参考区。
- 轻量模式：只有用户明确要求轻量输出，或当前环境无法创建交付物时，才在聊天里输出简短说明和标准 7 列分镜表。

## 标准流程

1. 识别任务信息：对象、内容类型、受众、平台、目标时长、必含信息、语气、场景限制和合规风险。信息缺失但不影响执行时，做合理默认并继续。
2. 设计钩子和结构。新写、重写或大幅优化时，读取 `references/creative-playbook.md`，内部确定钩子、叙事结构、情绪弧线和可拍动作。若用户指定目标平台，或需要平台适配 / 发布建议 / 运营打法，读取 `references/platform-operations.md`，将平台差异落实到钩子、分镜节奏、台词、花字、CTA、剪辑提示和平台适配模块中。
3. 生成标准 7 列分镜表。固定列顺序：

| 镜号 | 时长 | 景别 | 机位 | 画面内容 | 台词 | 音效/花字 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |

4. 创建交付内容。默认读取 `references/output-format.md`，先将完整内容写入本地 `.md`（或 `.xmlmd`、`.xml`）文件，再通过飞书文档导入功能转为在线文档；无论在线文档还是用户明确要求的聊天文本，都必须包含完整标准 7 列分镜表。
5. 补充视觉支持。默认读取 `references/visual-storyboard.md`；图片工具可用时优先生成封面图，再生成关键分镜图；图片失败时在原位写 `待生成 + 图片生成提示词`。
6. 交付前自检：总时长、镜头数、钩子位置、画面具象度、台词口语度、景别变化、剪辑可行性、道具/场景可实现性、合规风险。

## 质量规则

- 前 2-5 秒必须有观看理由：视觉钩子、冲突、问题、声音、反差或具体动作。
- 把抽象卖点翻译成可拍动作。例如“保湿”可以写成“下午三点用纸巾轻按鼻翼，妆面没有明显卡粉”。
- 台词要短、顺，能在对应镜头时长里自然说完；无台词写 `（无台词）`。
- 避免“赋能”“助力”“打造闭环”“震撼”“炸裂”等 AI 腔或营销腔，除非用户明确要求。
- 避免连续 3 个以上镜头使用相同景别，除非是刻意的固定机位口播风格。
- 默认用容易拍的日常场景和道具。
- 平台适配不能只写在说明里；指定平台时，分镜表中的镜头密度、台词长度、花字强度、CTA 和剪辑提示必须体现平台差异。
- 用户提供的事实要保留；用户没有提供时，不编造数字、背书、认证、价格、排名或功效结果。

## 联网/调研规则

只有信息会影响准确性、安全性或创意适配时才调研：最新、最近、当下、热门、BGM、挑战、热梗、平台规则、竞品、热点借势、真实事件或高风险合规表达。

如果最终答案包含来自外部来源的事实性信息，需要按宿主环境能力标注来源。

## 最终回复

- 丰富模式：给交付物链接/路径，并简要说明包含哪些内容。
- 轻量模式：直接给分镜脚本，并说明这是轻量文本版。
- 只有当假设会影响拍摄执行时，才说明关键默认假设。
- 不展示隐藏推理过程或内部自检清单。
