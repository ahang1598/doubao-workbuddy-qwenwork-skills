# 输出格式

默认丰富交付时必读。本文件定义在线文档交付结构和分镜表硬性要求。

## 丰富交付模式（默认）

默认必须做在线文档交付，采用 **MD 中转策略**：先将完整交付内容写入本地 `.md`（或 `.xmlmd`、`.xml`）文件，再通过飞书文档导入功能转为在线文档。不直接调用飞书文档 API 创建文档。用户明确说“只要文字”“只要表格”“不要文档”“直接在聊天里给”时，才使用轻量聊天模式。

用户明确说“不要图片”时，只跳过封面图和关键分镜图生成，仍按丰富在线文档交付；不要因此降级为轻量聊天模式。

默认交付物必须包含：

1. 项目概览。
2. 创意策略。
3. 完整标准 7 列分镜表。
4. 封面方案区：默认 1-3 个封面方案；图片工具可用时生成封面图。
5. 视觉参考区（关键分镜图）：默认目标 3 张关键分镜图，最多 5 张；图片失败时保留原位占位和图片生成提示词。
6. 拍摄执行包：道具、场景、演员/表演、现场风险。
7. 剪辑提示。
8. 平台适配：指定平台时必须包含平台节奏、字幕/花字、CTA、发布注意点；多平台时说明主平台与可迁移改法。
9. 合规与风险提醒。

分镜表是必备内容，不因生成了分镜图或在线文档而省略。

## 文档交付规则

采用 **MD 中转策略**：先将完整交付内容写入本地 `.md`（或 `.xmlmd`、`.xml`）文件，再通过飞书文档导入功能转为在线文档。不直接调用飞书文档 API 创建文档。

若飞书文档导入功能不可用，应明确说明无法完成默认在线文档交付，并询问用户是否接受聊天版 7 列分镜表。

文档交付必须：

- 标题清楚，能一眼看出主题、平台和时长。
- 结构完整，包含定位、钩子、完整分镜表、封面方案、视觉参考区（关键分镜图）、拍摄清单、剪辑建议、CTA 和合规检查。
- 分镜表放在正文核心位置，不要只放图片或只放口播稿。
- 视觉参考区（关键分镜图）和封面方案区分开。
- 图片生成成功时，必须把图片原位插入或替换到对应区域：封面图放入封面方案区，关键分镜图放入视觉参考区对应镜号。
- 禁止在文档末尾追加“分镜图预览”或“图片预览”作为替代；不要让前文保留 `待生成`，后文又出现实际图片。
- 最终回复只给文档链接/路径和简要说明，不重复粘贴整篇文档。

## 标准 7 列分镜表

| 镜号 | 时长 | 景别 | 机位 | 画面内容 | 台词 | 音效/花字 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 01 | 2s | 特写 | 俯拍固定 | 可拍摄的客观画面 | 自然口语台词 / `（无台词）` | BGM / 音效 / 花字 |

字段规则：

- 镜号：两位数字，从 `01` 开始。
- 时长：`Ns`，如 `2s`、`3s`、`5s`。
- 景别：远景 / 全景 / 中景 / 近景 / 特写 / 大特写。
- 机位：角度和运动，如平视固定、平视轻推、俯拍固定、跟拍移动、POV、屏幕录制、分屏。
- 画面内容：只写能被镜头拍到的客观动作，不写抽象评价，不塞台词。
- 台词：短、顺、口语化；无台词写 `（无台词）`。
- 音效/花字：BGM 情绪、音效节点、关键词花字、节奏提示；无音效/花字写 `（无）`，不要留空。

## 轻量聊天模式

仅在用户明确要求轻量输出，或在线文档工具不可用且用户接受聊天版时使用。

输出内容：

1. 一句简短说明，概括创意切入点。
2. 标准 7 列分镜表。
3. 按需补充少量说明：默认假设、道具、场景、剪辑节奏或合规提醒。

## 交付前检查

- 任务确实属于短视频分镜脚本；不是小红书图文、公众号文章、论文/学术写作、翻译、润色、摘要、标题库、账号定位、直播话术、评论区话术或纯平台运营报告。
- 交付物包含完整分镜表，且表格严格为标准 7 列。
- 封面方案区已提供 1-3 个方案；图片工具可用时封面图已原位插入封面方案区。
- 视觉参考区（关键分镜图）已原位插入图片；未生成成功时已写 `待生成 + 图片生成提示词`。
- 文档末尾没有额外追加的“分镜图预览/图片预览”章节。
- 画面具体可拍，台词能自然说出口。
- 没有无依据承诺或绝对化广告词。
