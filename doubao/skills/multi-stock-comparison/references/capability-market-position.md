# 行业位置、产品与客户

## 回答什么

比较行业需求与周期处于什么位置，各公司服务谁、解决什么需求、产品位于供应链/价值链哪个环节，以及行业结构如何影响份额、定价权和盈利空间。

## 何时选择

用户问市场地位、产品、客户、份额、产业链/供应链位置、竞争格局或竞品差异时选择；宽泛比较默认选择。涉及近期中断、国际事件或监管时，同时读取 `capability-supply-chain-news-regulation.md`。

## 分析动作

涉及外部行业规模、份额或产业链财务数据时，先按金融数据检索能力调用 `/seed_finance_search`；结果仍需统一市场边界、地区和时间范围。

1. 统一市场边界、地区、客户群、产品层级和时间范围。
2. 判断行业需求、库存、产能、价格、成本和资本开支所处周期阶段。
3. 横向比较客户需求、产品定位、价格带、渠道、区域和使用场景。
4. 比较份额、竞争者、替代方案、客户集中度和转换成本。
5. 按 `上游原料/设备/技术 → 核心部件/制造 → 公司产品/服务 → 渠道/客户 → 终端需求` 定位各公司，写明业务层级、地区和关键依赖。
6. 判断各公司掌握的控制点、议价权、替代周期和交付责任，以及利润池可能向哪里迁移。
7. 建立 `行业/供应链变量 → 公司份额/价格/销量/成本 → 收入/毛利/现金流` 传导链。
8. 给出定位判断的反例、边界和下一验证指标；未披露供应商/客户名称或份额不得补造。

## 完成标准

产出逐维度的行业角色、供应链位置、产品客户差异、控制点、竞争位置和基本面含义。企业名单和产品清单不算比较。
