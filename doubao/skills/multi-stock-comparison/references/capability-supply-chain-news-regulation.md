# 供应链、重要新闻与监管

## 回答什么

比较企业位于供应链的哪个环节、依赖哪些关键投入与下游需求，近期公司新闻、供应链/国际事件和监管变化如何影响各公司的收入、成本、交付、现金流、预期与估值。

## 何时选择

用户问产业链、上下游、供应商、客户、地缘政治、贸易限制、公司近期新闻、政策、监管、调查、处罚或事件驱动时选择。全面比较和投资二选一至少做相关性扫描；只有重大或差异化事项才写入正文。

## 供应链地图

1. 统一产品与业务层级，按 `上游原料/设备/技术 → 核心部件/制造 → 公司产品与服务 → 渠道/客户 → 终端需求` 定位每家公司。
2. 记录关键节点的地区、供应商/客户集中度、单一来源、替代周期、库存缓冲、合同与定价权；未正式披露的名称或份额标为待验证。
3. 比较各公司在价值链中的控制点、利润池、议价权、转换成本和交付责任，不能只贴“上游/中游/下游”标签。
4. 对中断、制裁、关税、出口管制、物流、能源、汇率或自然灾害建立 `事件 → 节点 → 公司暴露 → 数量/价格/成本/现金流 → 预期与估值` 传导链。
5. 识别替代来源、认证周期、在途库存、保险与合同保护；把毛风险和缓释后的净风险分开。

## 新闻筛选与时间线

“近期”默认取截至日向前 90 个自然日，并覆盖最近一次财报以来的重大事项；用户给定窗口时遵从。每条候选新闻必须记录：

- 事件发生时间、首次发布时间、来源更新时间和目标市场可交易时间；
- 影响的公司、业务、地区和供应链节点；
- 事实、公司/监管表述、媒体报道与作者推断的分类；
- 对盈利、预期、估值或风险的影响路径，以及尚未确认的环节。

只保留满足至少一项的新闻：改变经营或财务预测；改变关键假设或相对排序；形成可验证催化剂/证伪条件；解释显著价格反应。多家媒体转述同一原始事件只算一项，不按报道数量提高置信度。

两项以上重大事件存在清晰的先后、阶段或可交易时点差异时，读取 `advanced-lark-visuals.md`，优先用 `timeline` SVG；事件只是精确字段集合时用表格。供应链节点与多家公司暴露形成分叉传导时可用自定义 SVG whiteboard；若只有一条线性关系，用一句机制段落即可。

## 监管与国际事件

- 监管信息优先使用监管机构、政府、法院和交易所原文，区分征求意见、草案、正式通过、生效、执法/处罚和司法救济阶段。
- 写清管辖区、适用主体、开始日期、过渡期、量化门槛和执行不确定性；政策标题不能代替条款分析。
- 国际新闻只有映射到公司的市场、客户、供应商、技术、航线、资本或合规义务时才纳入。
- 未落地政策使用情景与条件表达，不把可能性写成已发生事实；监管调查不等同于违法结论。

## 来源优先级

监管/政府/法院/交易所原文 → 公司公告与法定披露 → 海关、行业机构或可靠数据库 → 具名权威媒体。社交媒体和产业链传闻仅用于提出待验证线索，不进入确定性结论。

## 完成标准

产出可复核的供应链位置图或表、按重要性排序的事件时间线、公司间暴露差异、净风险、监管阶段和下一验证点。图形只有在压缩节点、时序或分叉关系时才保留；新闻清单、媒体摘要或无传导链的国际新闻不算完成。
