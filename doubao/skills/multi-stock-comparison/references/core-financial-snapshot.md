# 默认核心财务金融数据底座

多股票分析默认先建立全部比较对象的紧凑同口径数据快照。它是读者理解公司规模、增长、盈利、财务承受力和市场定价的底座，不是可有可无的“财务章节”。

## 默认覆盖

在同一张横向表中选择 5–12 个最能解释当前比较的指标，并至少覆盖：

- `market_data`：同一估值日的价格、市值或企业价值；
- `valuation`：至少一个适合该行业和盈利阶段的估值指标；
- 下列经营财务类别中的至少两个：`financial_scale`、`growth`、`profitability`、`cash_flow`、`balance_sheet`、`capital_efficiency`。

常规非金融企业优先考虑：收入及增长、毛利率/经营利润率、EPS 或净利润、经营现金流/FCF、净现金/净债务、ROIC，以及 PE、EV/EBITDA、EV/Sales 或 FCF yield 中真正适用的指标。不要机械把全部字段塞进表格。

按商业类型替换指标：

| 类型 | 核心指标示例 |
|---|---|
| 银行/保险/券商 | 资产或贷款/AUM、收入与 EPS 增长、NIM/ROE、信用成本/NPL/CET1 或偿付能力、P/B/PE |
| REIT/地产运营 | NOI、FFO/AFFO、同店增长、出租率、杠杆、分派收益率、P/AFFO |
| 亏损生物科技/早期成长 | 现金与净现金、季度/年度现金消耗、现金跑道、研发投入、关键里程碑、EV/现金；不强行展示无意义 PE |
| 资源/周期制造 | 产销量、实现价格、单位成本、EBITDA/FCF、净债务、周期中枢估值 |
| 平台/订阅软件 | 收入/ARR、增长、毛利率、经营利润率、FCF margin、留存/获客效率及适用估值 |

## 口径与表达

- 全部公司使用相同指标、共同 TTM/自然年或明确标注的最近完整期；错期时不做伪排名。
- 流量、时点、估值和行情分别写明期间或日期；列名包含币种、单位和法定/调整后口径。
- 缺失值标为未披露/不可比，不补造，不为填满表格换用定义不同的替代值。
- 表格放在核心结论之后、详细分析之前。它只承担全局定位，正文不逐格复述。
- 默认只用一张紧凑富表格，不为这组数据额外生成多个章节或图表。只有时间路径、二维矩阵或桥接关系本身改变判断时，才按 `advanced-lark-visuals.md` 另选图形。

## 可审计的不相关条件

只有确认附加财务金融数据不会帮助回答当前问题时，才把 `core_financial_snapshot.status` 设为 `not_relevant`：

| `reason_code` | 适用边界 |
|---|---|
| `single_fact_query` | 只核对一个明确事实、定义或同口径单项指标，短文本即可无损回答 |
| `narrow_nonfinancial_scope` | 问题严格限定为与规模、盈利、现金、风险承受力和估值无关的非财务关系 |
| `user_explicitly_excluded` | 用户明确要求不展示财务金融数据 |
| `other_material_reason` | 其他能具体证明这些数据不会影响答案的重大理由 |

数据难找、篇幅有限、已有定性结论、制作成本或部分字段缺失都不是“不相关”。遇到缺失时仍保留可得的核心数据并明确覆盖边界。

## 完成标准

质量清单默认使用 `status=included`，记录全部公司、指标、类别和证据。最终确认估值日、期间、币种、单位、缺失值与来源；若设为 `not_relevant`，记录标准原因代码和它为何不会改变当前答案。
