# 多股比较领域要点

以下情况读本文件：涉及行业口径、跨上市地、配对与组合、供应链与监管，或需要跟踪相对论点时。表中内容是起点，不是限制；偏离时说明理由。

## 1 取数与口径
- **同批同源**。行情、估值、标准财务、一致预期等结构化字段，尽量一次查询覆盖全部对象，写明代码、指标、期间、口径、币种、单位和估值日。
  - 无结果时，按顺序回到法定披露、监管文件、公司正式材料、其他可靠数据库。
  - 换了来源，就不再称"同源可比"。
  - 数据库值与披露值冲突时，先查币种、单位、期间、重述、会计口径和业务层级；仍解释不了，就把两者并列，并缩小结论范围。
- **回附注核验**。遇到重述、并购或处置、终止经营、财年变更、一次性项目，回到附注和调整桥核验。数据库返回的客户名、独家供应、未披露订单，不因为"查到了"就成为事实。
- **期间对齐**。优先级为：共同 TTM → 共同自然年或连续 12 个月 → 各自最新完整财年。
  - 期间错位的数据只能看方向，不排名。
  - 报告名称里写着同一年，不等于同一期间。
  - 集团数据不能替代分部数据。分部利润未披露时，不能用收入占比去推利润占比。
- **一致预期**。要说"上修""下修"或"beat/miss"，必须是同一供应商、两个快照日、同一指标、同一财年，并写出覆盖机构数。
  - 区分以下几种预测：一致预期、单家预测、管理层目标、价格隐含的假设、自建模型。单家券商的预测不能称作一致预期。
  - 预测发生变化时，先排除基数效应和滚动财年效应。
- **时间**。
  - 行情要注明交易所、时区，以及是收盘价还是盘中价。
  - 不同时区的市场不写成"同时反应"。目标市场收盘后才出的新闻，标注"尚未经交易验证"。
  - 用户没有指定"近期"时，取截至日前 90 个自然日，并覆盖最近一次财报以来的事项。
  - 多家媒体转述同一事件，只算一项证据。
- **来源优先级**。监管、法院、交易所原文 → 公司法定披露 → 海关、协会或可靠数据库 → 具名权威媒体。社交媒体和产业链传闻只作待验证线索。来源要写到具体材料；研报写明机构、标题和日期。
- **核心快照**。建议在结论后放一张横向表：同一估值日、共同期间，列 5–12 个指标，至少包括市场数据、一个适用的估值指标和两类经营财务指标。缺失的标"未披露"或"不可比"，不拿定义不同的值顶替。表头写明期间（FY/CY/TTM）、币种、单位、法定还是调整后口径、是否复权。

## 2 行业指标与估值口径

| 类型 | 核心指标 | 估值口径 |
|---|---|---|
| 银行、保险、券商 | 资产或贷款/AUM、收入与 EPS 增长、NIM、ROE、信用成本/NPL、CET1 或偿付能力 | P/B、PE；保险可用 P/EV |
| REIT、地产运营 | NOI、FFO/AFFO、同店增长、出租率、杠杆、分派收益率 | P/AFFO |
| 资源、周期制造 | 产销量、实现价格、单位成本、EBITDA/FCF、净债务 | 周期中枢估值 |
| 平台、订阅软件 | 收入/ARR、增长、毛利率、经营利润率、FCF margin、留存与获客效率 | 按盈利阶段选择适用倍数 |
| 亏损生物科技、早期公司 | 现金与净现金、现金消耗、现金跑道、研发、关键里程碑 | EV/现金；不展示无意义的 PE |
| 常规非金融企业 | 收入及增长、毛利率/经营利润率、EPS、经营现金流/FCF、净现金/净债务、ROIC | PE、EV/EBITDA、EV/Sales、FCF yield 中选适用的 |

- 周期行业先判断需求、库存、产能、价格、成本、资本开支分别处在周期的哪个阶段。
- 多业务公司按分部估值，并说明集团折价、协同效应和资本结构。

## 3 分维度要点
- **商业模式**：用"客户 → 价值 → 产品 → 收费 → 成本 → 现金流"这条链来写；护城河要落到可持续的回报上，不用"平台型""生态型"这类空标签。
- **行业位置**：按"上游 → 核心部件或制造 → 产品 → 渠道或客户 → 终端"定位，比较控制点、议价权、替代周期，以及利润池向哪里迁移。
- **经营**：数据可得时，看三年加最近八个季度。用"量 × 价 × 结构 → 收入 → 毛利 → 费用 → 经营利润"做驱动拆解。没有披露前的预期快照，就不判断 beat 或 miss。
- **财务质量**：核心经营利润要和股权激励费用、摊销、投资收益、公允价值变动、补贴、处置收益、减值、税项、少数股东损益分开看。比较净现金、债务到期、稀释、表外项目；看 ROIC、增量资本回报和资本配置去向。
- **成长**：拆成行业扩张、份额、价格、结构、新品类、新区域、并购。TAM 不等于可服务市场。给出 4–8 个季度的领先指标和失效条件。"团队更强"不能单独作为证据。
- **估值**：
  - 统一估值日、稀释股本、净现金或净债务、少数股东权益、租赁负债、预测期和币种。
  - 建立"经营变量 → 盈利或现金流 → 估值"的价值桥。从 EV 推到股权价值时，扣除少数股东权益。
  - 每家只设一个基准情景。
  - 反推隐含增长时，WACC 要大于 g，终值 ROIC 要大于 g。没有可复算的输入，就只给方向或区间。
- **价格**：先剥离大盘、板块、汇率与利率、海外同业的影响，再谈公司自身事件。归因分四级：已验证、有证据、可能、无法确认。不分配没有依据的百分比。
- **市场、板块与海外**：
  - 区分交易所正式分类、可核验的主题指数和媒体的"概念"标签。把公司归入某个概念，需要收入、产品、客户或资本开支方面的证据。
  - 海外市场（如美股、日韩同业）只在能写出"外围变量 → 板块或供应链 → 公司盈利或估值"这条链时纳入，并压缩到 1–3 个变量。相关不等于因果。
- **供应链与监管**：
  - 供应链：记录关键节点的集中度、是否单一来源、替代或认证周期、库存缓冲；区分毛风险和缓释后的净风险。
  - 监管：区分征求意见、草案、通过、生效、执法或处罚、司法救济等阶段，写清管辖、主体、门槛和过渡期。调查不等于违法。
- **因果主线**：用"行业角色 → 商业模式与利润池 → 经营与财务 → 增长约束与预期 → 估值 → 风险与催化剂"解释至少三项差异。一条主线掩盖了反例时，用两条。
- **宽泛问题的默认维度**：
  - 全面对比：位置、模式、经营、财务质量、成长、预期、估值、风险。
  - 估值比较：经营、财务质量、预期、估值，不只比孤立的倍数。
  - 财报比较：经营、财务质量、预期；问到市场反应时再加价格。
  - 近期表现：市场、板块与海外，新闻与监管，价格，预期。
  - 产业链或地缘：位置、供应链与监管、风险。

## 4 跨上市地与 A/H
- **先核对证券权利**：股份类别、每股对应的权益单位、分红和投票权、公司行动。区分 A/H、H/ADR、双重主要上市、二次上市和可互换的存托凭证。典型的 A/H 不能自由互换，价差本身不是无风险套利。
- **价格与汇率**：价格和汇率的时间戳要同步。计算历史分位时，用同一公式和当日汇率，不用今天的汇率重算历史。
- **称"可执行"之前，逐项验证**：
  - 转换或交割的路径与时长
  - 两条腿的交易资格、互联互通资格与额度、资本流动限制
  - 借券的可得性、成本和召回风险
  - 交易时段、涨跌幅限制、休市安排、T+n、汇率
  - 印花税、佣金、托管或转换费、融资成本、股息税与预提税
  - 盘口深度与冲击成本

  能给出成本假设时，同时给出扣除成本后的指示性价差。
- **价差成因**：投资者结构、流动性、借券、资本管制、指数资金、汇率、税负、分红、治理。
- **收敛或扩张的催化剂**：互联互通调整、指数纳入、股息、回购、增发、转换安排、监管与资金流向。

## 5 组合适配与配对（分析，不是执行）
- 区分标的自身质量和它对现有组合的边际贡献。没有组合数据时，只比较标的本身的风险属性。
- 先确认共同风险因子和独立 Alpha，再选择金额中性、Beta 中性或因子中性。
- 检查交叉持股、供销关系、共同客户、跨市场制度风险。历史相关性不是永久关系；同行业或负相关，都不能证明是好配对。
- 动作用 if/then 的条件式表达。

## 6 相对论点跟踪
- 冻结初始基线，不用后见之明改写。
- 维护 3–5 个决定性指标，口径保持不变。
- 状态用以下几种描述：优势扩大、不变、收窄、反转、需重建、无法判断。
- 设黄灯、红灯阈值和下一次复核日期。历史记录只追加，不修改。

## 7 呈现（按需选用，载体不限）
- 推荐顺序：比较元信息 → 结论 → 核心快照 → 3–5 个胜负驱动因素 → 增量对比 → 机制 → 最强反例与翻转条件 → 验证点 → 来源。
- 如果画 K 线：只用完整的 OHLC 数据（最高价不低于开盘、收盘、最低价，日期严格升序），各股用同一窗口、频率和复权口径。只有收盘价时改画折线，不补造开盘、最高、最低价。A 股和港股常用红涨绿跌，海外常用绿涨红跌，图例要写明。
- 象限图的轴和阈值必须可解释，不用未经说明的综合分数，也不把某个象限等同于"买入"。
