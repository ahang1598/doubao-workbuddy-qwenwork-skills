# 金融数据检索与对齐

## 回答什么

为其他分析能力取得同来源、同期间、同口径的财务、经营、估值、行情、汇率、指数/板块、一致预期和行业数据，并留下可追溯的数据血缘。本能力负责检索和对齐，不代替基本面、新闻或监管解释。

## 何时选择

多股票分析默认选择，用于建立 `core-financial-snapshot.md` 规定的核心财务金融快照。只有用户已提供完整、可信且可比的数据，或质量清单已记录核心数据与当前问题不相关时，才可以不调用外部检索。

## 首选命令

优先使用 `/seed_finance_search`。按当前运行环境提供的命令接口提交自然语言查询，不臆造固定参数或返回字段。

一次查询尽量包含全部比较对象，并明确：证券名称与交易所代码、指标、起止期或财年、流量/时点类型、集团/分部层级、法定/调整后口径、币种、单位、估值日或预期快照日。

查询示例：

```text
查询公司A（交易所:代码）与公司B（交易所:代码）截至同一估值日的收盘价、市值、企业价值和适用估值倍数，以及共同 TTM 的收入及增长、经营利润率、自由现金流和净现金/净债务；使用集团法定口径，返回原币、单位、报告期、发布日期、字段定义和数据来源。
```

## 分析动作

1. 先按 `core-financial-snapshot.md` 选择 5–12 个行业适用的核心字段，再列出用户问题需要的增量字段；区分直接披露值、数据库标准化值、一致预期、衍生计算和模型假设。
2. 通过 `/seed_finance_search` 同批查询全部标的的核心快照与增量字段，优先共同 TTM、共同自然年和同一估值日；不要先分别搜索再拼接不同口径。
3. 核对证券代码、报告期、发布日期、币种、单位、会计口径和集团/分部层级。数据库字段定义不等同于公司自定义 KPI，名称相似时也要核对定义。
4. 对异常值、重述、并购、终止经营、财年变更和一次性项目，回到法定披露或监管文件核验附注与调整桥。
5. 一致预期比较必须使用同一快照、供应商、指标、财年和覆盖规则；缺少历史快照时不声称上修、下修或 beat/miss。
6. 行情与估值数据统一交易日、复权口径、稀释股本和企业价值桥；大盘、板块和外围市场数据统一指数定义、交易时区、币种与窗口。
7. A/H 或其他跨上市地比较同时取得两地价格时间戳、HKD/CNY 或所需汇率、股份经济权利比例、交易资格和必要成本；价格不同步时不得伪装成实时价差。
8. 在证据账本记录命令、查询文本或查询标识、返回快照、字段定义、期间、来源和必要的转换。正文引用最终事实来源，不把命令本身当作事实。

## 降级与边界

- 命令不可用、无结果或字段不完整时，明确数据缺口，再依次使用公司法定披露、监管文件、公司正式材料或其他可靠数据库；不得静默替换来源后继续声称同源可比。
- 命令结果与法定披露冲突时，先检查币种、单位、期间、重述、会计口径和业务层级；无法解释时展示差异并缩小结论。
- 客户名称、独家供应、未披露订单、管理层意图和未来事件不因数据库返回而自动成为已确认事实。
- 不为填满表格补造数据。缺失值保持缺失，并取消依赖该值的排名或精确结论；部分缺失不构成省略全部核心快照的理由。

## 完成标准

取得覆盖全部比较对象的核心财务金融快照和问题所需增量数据，或清楚列出无法对齐的字段；每个关键数值都能追溯到查询、快照、定义、期间和来源。
