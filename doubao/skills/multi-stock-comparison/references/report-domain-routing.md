# 报告领域路由

“扫描”表示研究规划时判断相关性，不表示正文必须出现。九领域扫描在 `core-financial-snapshot.md` 规定的默认核心财务金融快照之后执行；核心快照不是第十个可选领域。领域通过本文件的相关性筛选后，仍须通过 `writing-quality.md` 的内容准入门禁。只有用户明确要求、能解释公司间差异、会改变盈利/预期/估值/股价/风险，或形成可验证催化剂与证伪条件，且证据质量足够时才写入。不要创建九个固定章节，也不要用“暂无影响”填充版面。

## 九领域路由

| 领域 | 必须扫描的体裁 | 正文出现条件 | 首选表达 |
|---|---|---|---|
| 大盘 | 全面比较、投资二选一、近期表现、事件复盘、组合/配对 | 风格、流动性、利率、汇率或市场 Beta 会改变相对结论 | 市场状态短表、相对收益 HTML 图 |
| 概念/板块 | 全面比较、竞品、近期表现、事件复盘 | 有可核验分类/主题指数，且板块需求或资金解释差异 | 板块比较表、热力图；概念定义放注释 |
| 企业供应链位置 | 全面比较、竞品、产业链/地缘、投资二选一 | 价值链环节、控制点、客户/供应商依赖影响盈利或风险 | 供应链 whiteboard + 精确数据表 |
| 企业近期重要新闻 | 全面比较、一页纸、事件复盘、近期表现、论点跟踪 | 事项改变预测、假设、排序、催化剂或证伪条件 | 重要性排序表或时间线，不做新闻摘要合集 |
| 供应链风险/国际新闻 | 产业链/地缘、全面比较、事件驱动、风险情景 | 国际事件能映射到具体地区、节点、数量/价格/成本和公司暴露 | 事件—节点—公司传导图、净风险表 |
| 图表 | 所有 `LARK_DOC` 体裁 | 股价分析默认使用 K 线；其他图形仅在明显优于段落/表格、带来新信息且输入可核验时出现 | 路径/矩阵用 HTML，桥接/阶段/因果/位置用 SVG，查值用富表格 |
| 监管新闻 | 全面比较、事件驱动、强监管行业、风险/催化剂 | 规则、调查、处罚或审批直接适用，且阶段与影响可验证 | 阶段时间线、公司暴露与情景表 |
| 外围美股/日韩 | 跨市场行业、近期表现、事件复盘、供应链/地缘、配对 | 可写出外围变量到板块/供应链/公司的传导链 | 跨市场短表、时区对齐曲线或传导图 |
| H 股套利机会 | A/H 双重上市、跨上市地、相对价值、配对交易 | 同步折溢价显著或制度差异影响选择；执行条件可核验 | A/H 同步价差表、历史折溢价 HTML、执行门禁表 |

## 按体裁扫描

- **全面股票比较/投资二选一**：扫描全部九项；正文通常只保留 3–6 个真正改变判断的领域。
- **一页纸/会前准备**：扫描全部九项；只保留最重要的市场背景、供应链位置和 1–3 个重大事件，图表至多一个主视觉家族；股价分析的成组 K 线按一个视觉家族计算。
- **近期表现/事件复盘**：大盘、板块、公司新闻、监管、外围市场和图表为必扫；默认用同窗口、同频率、同复权 K 线展示决策相关标的，只有可审计的不适用理由才能省略；供应链/国际新闻按事件传导加入。
- **竞品/业务能力比较**：板块、供应链位置和公司新闻为必扫；大盘与外围通常只在影响需求、成本或估值时出现。
- **供应链/地缘研究**：供应链位置、供应链/国际新闻、监管和外围市场为必扫；用传导图而不是新闻列表。
- **组合适配/配对交易**：大盘、板块、外围、公司事件、监管和共同供应链暴露为必扫；同一发行人的跨上市地组合增加 A/H 能力。
- **A/H 或 H 股相对价值**：九项全部扫描，但正文重点是同步价差、制度/成本、市场与资金环境、公司/监管催化剂和执行障碍。

## 规划记录

在内部工作记录中为九项标记 `include`、`omit` 或 `not_applicable`，并为 `include` 写一句传导理由。随后把候选内容写入质量清单；任何候选图表同时进入 `visual_plan`，按 `advanced-lark-visuals.md` 完成格式选择、预算和去重。正文只展示同时通过领域相关性和内容质量门禁的内容。
