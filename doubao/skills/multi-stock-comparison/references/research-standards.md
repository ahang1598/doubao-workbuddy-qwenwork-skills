## 比较前提

开始前锁定：比较对象、用户要做的判断、信息截止日期与时刻、流量指标期间、时点指标日期、新闻窗口、市场交易时区、币种、单位、会计口径、集团/分部/产品层级及估值日。用户前提错误时先纠正。

## 默认核心财务金融锚点

按 `core-financial-snapshot.md` 为全部比较对象建立同一横向快照。市场价格、市值/企业价值和估值使用同一估值日；收入、盈利和现金流优先共同 TTM；资产负债表使用接近的报告期末。指标因商业类型调整，但必须同时覆盖市场定价与至少两个经营财务维度。

核心表格是比较口径锚点，不是数据倾倒：只保留 5–12 个高价值指标，精确标明日期、期间、币种、单位和口径。缺失或错期时显式标记并缩小结论，不能因此跳过整张表。

## 证据类型

明确区分：

- **公司披露**：年报、季报、公告、演示和官方产品资料；
- **标准化金融数据**：通过 `/seed_finance_search` 返回的财务、经营、估值、行情、一致预期或行业数据；
- **第三方事实**：监管、协会或可靠数据库；
- **监管事实**：政府、监管机构、法院或交易所的规则、决定与执法原文；
- **新闻事件**：有明确发生时间、首次发布时间、来源和可交易时间的公司、供应链或国际事件；
- **一致预期**：同一供应商、同一快照日和统一口径的多机构汇总；
- **单家机构预测**：不能称为一致预期；
- **衍生计算**：由已引用外部输入按明确公式得到；
- **模型假设**：研究者设置的情景参数；
- **推断**：证据支持但未直接披露的判断；
- **待验证**：证据不足或只有二手说法。

标准化横向数据优先通过 `/seed_finance_search` 同批检索；公司法定披露和监管文件用于核验会计定义、附注、重述、非标准 KPI 与异常值。定性事实的来源优先级为监管/政府/法院/交易所原文、公司法定披露与正式材料、标准化数据库和行业协会、具名研究或权威媒体。未正式披露的产业链名称、独供、订单和份额只用于提出待验证假设。

脚本、模型、工作簿和作者计算属于方法，不是来源。衍生计算必须记录公式、单位和外部输入，正文引用回到这些输入。

使用 `/seed_finance_search` 时保留查询文本或查询标识、返回快照、证券代码、字段定义、报告期、发布日期、币种、单位和数据来源。命令是检索入口，不是事实来源；最终证据归类仍以返回结果标明的原始来源和数据类型为准。

## 可比性矩阵

| 项目 | 可直接比较 | 无法统一时 |
|---|---|---|
| 时间 | 流量指标同起止期，时点指标日期接近 | 标记错期，只作方向观察，不排名 |
| 财年 | 共同 TTM、自然年或连续 12 个月 | 不因报告名称含同一年就视为同期 |
| 会计口径 | 法定/调整后定义一致 | 分列，不混算利润率或增速 |
| 币种与单位 | 统一汇率日和单位 | 保留原币或取消绝对金额排名 |
| 业务层级 | 集团对集团、分部对分部、产品对产品 | 改用同层级或取消排名 |
| 一次性项目 | 处置、减值、补贴和投资收益已识别 | 同列报告值与调整值或限定结论 |
| 估值时点 | 市值日期一致且分母匹配 | 统一估值日和预测期 |

集团指标不得替代单一业务。分部利润未披露时不能用收入占比推断利润占比。客户名称、份额、独供和订单规模需要正式来源，否则降级为待验证。

## 市场、新闻与监管时间

- 大盘、板块、外围市场和公司行情必须记录交易所、交易日、时区、收盘/盘中状态、币种和复权口径；异步市场不能写成同时反应。
- “近期”未指定时取截至日向前 90 个自然日并覆盖最近一次财报以来的重大事项；明确写出窗口。
- 每条新闻区分事件发生时间、首次发布时间、后续更新时间和目标市场可交易时间；重复转述回溯到原始事件。
- 监管事项区分征求意见、草案、通过、生效、执法/处罚和司法救济，写明管辖区、适用主体、门槛和过渡期。
- 国际或外围新闻只有建立到比较对象的需求、供应、技术、物流、汇率、利率、商品、资本或合规传导链时才能进入结论。

## 跨上市地与 A/H

- 先核验证券类别、每股经济权利、转换/交割机制和公司行动，再计算折溢价。
- 价格、汇率和复权口径必须同步或明确错位；历史序列使用一致公式，不能混用收盘与盘中价格。
- 折溢价、成本后价差和历史极值都不是套利证明。只有股份可交割、两腿可交易、借券、法律路径、交收、汇率和成本均已验证时，才可讨论可执行性。
- 互联互通资格、卖空、税费、结算和资本流动规则可能变化，必须以分析时官方来源为准并注明截止日。

## 一致预期

声称上修、下修或排名时必须同时具备：同一供应商、两个明确快照日、相同指标和财年、覆盖机构数及陈旧预测处理。实际同比增长、单家券商调整、管理层目标和不同来源的最新预测都不能单独证明一致预期变化。

## 计算与判断

- 每个计算记录公式、输入、单位和符号方向；
- 比率分子、分母、期间和业务层级必须匹配；
- 敏感性只有一个明确基准，零变动格与基准一致；
- 百分比变化和百分点变化分开；
- 分母接近零或为负时，不用简单比率排名；
- 数据不足时缩小结论或取消排名，不补伪精确数字；
- 组织能力只从迭代、交付、产能、周转、扩张、研发成果和费用率等可观察结果谨慎推断。

## 证据账本

复杂比较使用：

```json
{
  "as_of": "2026-07-22",
  "observations": [
    {
      "id": "a-revenue-ttm",
      "company": "公司A",
      "metric": "revenue",
      "value": 100.0,
      "period": "TTM ended 2026-06-30",
      "metric_type": "flow",
      "currency": "CNY",
      "unit": "bn",
      "layer": "group",
      "evidence": "company_disclosure",
      "retrieval": "seed_finance_search",
      "query_id": "保留实际查询标识；没有则记录查询文本",
      "source": "https://example.com/filing",
      "source_date": "2026-07-15"
    }
  ],
  "comparisons": [
    {
      "id": "revenue-rank",
      "observation_ids": ["a-revenue-ttm", "b-revenue-ttm"],
      "normalized_currency": "CNY",
      "allow_mismatch": false,
      "rationale": ""
    }
  ]
}
```

`metric_type` 使用 `flow`、`stock`、`ratio` 或 `other`；`layer` 使用 `group`、`segment` 或 `product`。计算项使用 `calculation`，并增加 `formula` 与指向外部输入的非空 `input_ids`。
