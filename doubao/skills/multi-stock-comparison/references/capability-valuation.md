# 估值与隐含假设

## 回答什么

比较估值差异是否由增长、质量、资本结构和风险合理解释，以及当前价格要求各公司实现什么。

## 何时选择

用户问估值、贵不贵、可比倍数、SOTP、DCF、隐含增长、目标区间或投资选择时选择；宽泛比较默认选择。

## 分析动作

涉及外部估值、股本、净债务或预测数据时，先按金融数据检索能力调用 `/seed_finance_search`，统一全部公司的估值日和预测期。

1. 统一估值日、稀释股本、净现金/净债务、少数股东、预测期和币种。
2. 根据业务选择 PE、EV/EBITDA、EV/Sales、FCF yield、SOTP 或 DCF，不机械使用同一倍数。
3. 比较历史区间、同业和基本面情景，并解释可比性差异。
4. 建立 `经营变量 → 盈利/现金流 → 估值` 价值桥，判断溢价或折价是否有基本面支撑。
5. 多业务公司按分部估值，明确集团折价、协同和资本结构处理。
6. 需要反推当前价格隐含的增长或利润率时，分别运行 `scripts/reverse_dcf.py`；保持企业价值桥、变量定义和估值时点一致。
7. 做基准、乐观、悲观及关键变量敏感性，保持每家公司唯一基准价值。
8. 比较隐含假设时结合各自历史兑现、行业容量和资本效率，不把相同参数强加给不同商业模式。
9. 没有可复算输入时只给方向或范围，不输出伪精确目标价。

二维敏感性矩阵有足够可复算网格时，读取 `advanced-lark-visuals.md`，使用 `heatmap` HTML 并同时标出基准格；估值吸引力与盈利确定性等双维定位可用 `quadrant` SVG，轴与阈值必须透明。若仅有少数情景或单一倍数排名，使用表格，不为了视觉效果生成热力图或象限图。

## 完成标准

产出估值方法、可比性调整、隐含假设、溢价/折价机制、敏感变量和边界。孤立倍数排名不算估值比较。
