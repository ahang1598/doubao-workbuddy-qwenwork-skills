# 报告审阅循环

报告生成后，用户可通过文档评论或会话反馈提出修改意见。

## 连接器模式

仅在用户指定且已授权的文档连接器支持评论读取、回复和正文修改时使用：

1. 拉取未解决评论及其锚定原文；
2. 根据评论 ID、时间和最后回复人识别本轮新增意见，避免重复处理；
3. 按评论真实语义定位目标，锚点与意见冲突时先向用户澄清；
4. 将评论分为：
   - 直接修改；
   - 检索后修改；
   - 需专业人员确认；
   - 需要用户澄清；
   - 经核验无需修改；
5. 修改后在对应评论下说明处理结果；
6. 未经用户明确要求，不自动关闭或删除评论。

## 无连接器模式

使用意见处理表：

| 编号 | 原文位置 | 用户意见 | 处理类型 | 修改内容/回复 | 状态 |
|---|---|---|---|---|---|

用户可继续回复编号，重复处理直至确认定稿。

## 法律内容边界

- 风险等级只在新事实、新依据或用户确认后调整；
- 要求补充法律依据时重新执行真实检索；
- 判断性意见无法可靠处理时进入待专业确认事项；
- 不删除原结论，除非用户明确要求；
- 所有修改同步到底稿和风险与建议汇总。

## 定稿

用户明确确认定稿后：

1. 检查所有意见均已处理或标明待确认；
2. 检查来源、时效和风险与建议汇总与正文一致；
3. 记录定稿日期、确认人和未解决事项；
4. 不自动向第三人发送报告。
