# 风险分级

风险等级必须由法律规则、业务事实和法律后果共同推出，不得凭领域名称或公开文章直接定级。

## 1. `【禁止或重大风险】`

适用于：

- 命中现行有效的强制性禁止规则；
- 缺少开展业务所必需的许可或前置批准；
- 可能构成犯罪或存在可靠的同类重大执法、裁判依据；
- 继续实施可能造成重大且难以补救的法律后果。

要求：必须提供直接法律依据，说明禁止或重大风险的适用要件、当前事实和整改条件。

## 2. `【可整改风险】`

适用于：

- 法律允许在满足条件后开展；
- 现有告知、同意、协议、流程、技术或记录存在缺口；
- 风险程度取决于规模、实现方式、概率或补救措施。

要求：说明具体缺口、整改动作、整改后的剩余风险和责任角色。

## 3. `【需专业人员确认】`

适用于：

- 适用法域、主体地位或法律解释存在争议；
- 关键业务或技术事实缺失；
- 来源时效、效力或真实性无法核验；
- 只有公开专业文章而无直接法律依据；
- 涉及复杂经济分析、物项分类、当地法或其他专业判断。

要求：写明不确定原因、所需事实和建议确认的专业角色。

## 定级规则

1. 确定性结论必须有可核验依据。
2. 只有网络搜索摘要或非官方来源时，不直接定重大风险或放行。
3. 组织政策可以提高内部控制等级，不得降低法定风险。
4. 不得承诺“零风险”或“完全合规”。
5. 同一事项可同时记录法律风险等级和业务关注优先级，两者不得混淆。
