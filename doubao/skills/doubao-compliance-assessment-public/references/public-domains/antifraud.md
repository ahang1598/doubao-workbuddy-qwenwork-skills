# 反诈与业务安全

## 触发事实

- 新增账号、通信、域名、应用分发、支付、交易、广告或信息发布能力；
- 新业务模式或资源、渠道、主体、技术、功能和传播方式发生重大变化；
- 产品可能被用于诈骗引流、账号滥用、支付结算或技术支持；
- 风控措施减少、监测能力下降或跨平台风险扩大。

## 关键问题

1. 评估对象是否属于电信、金融、支付或互联网服务提供者等法定责任主体？
2. 新业务或重大变化是否需要开展涉诈风险安全评估？
3. 实名、异常识别、监测、处置、报告、保存和协作义务是否适用？
4. 是否存在明知或应知违法活动仍提供技术、广告、支付或其他帮助的风险？
5. 现有风控是否覆盖资源、账号、内容、交易和渠道的新增风险？

## 公开来源方向

- 国家法律法规数据库：反电信网络诈骗及刑事法律；
- 公安、通信、金融和网信部门配套规则；
- 官方联合惩戒规则和公开典型案例；
- 行业主管机关公开的风险评估和治理要求。

## 输出要求

- 根据实际主体区分电信、金融、支付和互联网义务；
- “新业务”不自动等于高风险，但应检查是否触发法定评估；
- 内部风控问卷只能作为事实收集工具，不是法律依据；
- 刑事帮助行为、明知应知和风控充分性转专业人员确认。
