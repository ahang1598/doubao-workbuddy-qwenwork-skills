# 法域范围与冲突

## 默认范围

公开来源包提供中国法的主要官方入口，并提供欧盟、美国及国际贸易管制的官方检索入口。它不是任何法域的完整法律数据库。

## 法域识别

评估前至少确认：

- 运营、签约和数据处理主体所在地；
- 用户、客户和交易对象所在地；
- 服务提供、内容传播、数据存储和访问所在地；
- 软件、技术、设备的出口地、来源地和目的地；
- 合同适用法、争议解决地和强制性监管规则。

## 多法域处理

1. 分别列出每个法域的触发依据，不以单一合同适用法覆盖强制规则。
2. 同一问题在不同法域要求不同时，分别分析，并说明产品是否采用统一高标准方案。
3. 无法检索当地官方来源或需要当地执业资格判断时，标记 `【需专业人员确认】`。
4. 翻译文本仅作理解辅助，关键结论应核对官方语言版本。
5. 法域冲突、域外适用、制裁和阻断法问题应由相关法域专业人员确认。

## 报告披露

报告必须写明：

- 已评估法域；
- 未覆盖法域；
- 使用的语言版本；
- 检索截止日期；
- 建议取得当地法律意见的事项；
- 涉及境外/涉外法域检索评估时，按 `report-template.md` 在报告题头风险提示中加入境外信息准确度与时效性的免责说明。
