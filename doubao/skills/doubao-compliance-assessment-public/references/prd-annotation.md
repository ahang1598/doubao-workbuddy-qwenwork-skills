# PRD 合规审阅

## 适用范围

用户要求对 PRD、需求文档或设计方案标注法律风险时使用。批注是审阅意见，不替代完整法律报告。

## 操作步骤

1. 确认评估法域、版本和可访问范围。
2. 读取带段落或区块定位信息的正文。
3. 用 `dimensions.md` 做风险排查，必要时加载公开领域包。
4. 高风险或会改变方案设计的问题优先批注。
5. 需要法律依据时执行真实检索，不凭记忆填写条号。

## 单条意见格式

```text
【风险等级】
风险：……
原因：……
建议：……
待确认事实：……
依据：名称、条款、URL、检索日期
```

## 权限和降级

- 只使用用户已授权的文档连接器。
- 无权访问时，请用户上传或导出；不主动申请资源权限。
- 无局部评论能力时输出：

| 原文位置/摘录 | 风险等级 | 审阅意见 | 修改建议 | 依据 |
|---|---|---|---|---|

- 除非用户明确要求，不直接修改正文或删除内容。
- 不自动通知第三人或把材料发送到其他系统。
