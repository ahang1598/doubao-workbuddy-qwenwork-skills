# 通用责任角色

外部版只标责任角色，不预置组织名称、部门缩写或个人。

| 触发事项 | 建议角色 |
|---|---|
| 法律定性、重大风险、许可和合同 | 法务或外部律师 |
| 产品功能、交互和上线计划 | 产品负责人 |
| 数据字段、系统架构和技术措施 | 研发、架构或信息安全 |
| 隐私告知、个人权利和数据跨境 | 隐私或数据保护负责人 |
| 内容审核、账号和用户治理 | 内容安全或信任与安全 |
| 广告、营销、价格和消费者 | 营销合规、运营和消费者事务 |
| 贸易管制、制裁和跨境交付 | 贸易合规及目标法域专业律师 |
| 品牌、版权、专利和开源 | 知识产权或开源合规 |
| 舆情和外部沟通 | 公共关系或公共事务 |
| 整改排期和资源决策 | 业务负责人或管理层 |

## 使用规则

1. 每条建议明确主责角色和协作角色。
2. 不自动查询联系人、组织架构或发送消息。
3. 仅在用户提供具体人员并要求写入时记录姓名。
4. “转专业人员”应说明所需专业领域和待确认问题。
5. 路由不替代责任主体本身的法定义务。
