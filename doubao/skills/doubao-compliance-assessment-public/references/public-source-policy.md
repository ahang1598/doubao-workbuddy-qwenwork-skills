# 公开来源使用规则

## 来源等级

### A 级：正式法律依据

- 立法机关公布的法律；
- 国务院、监管机关公布的行政法规、规章和规范性文件；
- 法院官网、人民法院案例库或官方裁判文书；
- 目标法域官方公报和监管数据库。

关键定性和重大风险原则上需要 A 级来源。

### B 级：官方实施资料

- 监管机关答记者问、办事指南、申报指南和公开执法案例；
- 强制性标准及正式发布的推荐性标准；
- 官方技术委员会发布的实践指南。

B 级来源可解释落地方式，但不得改变上位法。

### C 级：公开专业参考

- 行业协会资料；
- 许可证发布机构和标准组织资料；
- 律所、学者及可信专业机构文章。

C 级只作线索和实践参考，不单独支持禁止、重大风险或确定性放行。

### D 级：低可靠来源

- 无署名文章、自媒体、营销材料和无法追溯的二手转载。

原则上不引用；只能用于发现检索关键词。

## 时效核验（防旧法闸门）

通用网络检索会大量返回已废止或修正前的旧版法条，`seed_legal_search` 的法规库也可能滞后于近期新规；引用任何法规前必须核验其现行有效版本，这是所有领域通用的强制要求：

1. **以官方权威来源为准**：法条文本和条号以 `seed_legal_search` 返回结果、国家法律法规数据库（flk.npc.gov.cn）等官方数据库的现行有效版本为准；搜索引擎结果、新闻报道、律所文章、百科等只用于发现线索和检索关键词，不得直接作为法条文本、条号或效力状态的来源。
2. **强制标注版本与效力**：每次引用法规都要确认并记录其最新版本年份（制定或最近一次修正/修订的年份）与效力状态，报告正文引用时一并标注（如“《广告法》（2021年修正，现行有效）”），使版本一目了然，防止误用旧版。
3. **高频修正法律主动核验最新版**：对广告法、反不正当竞争法、反垄断法、消费者权益保护法、个人信息保护法配套规则等经常修正的法律，不得停留在第一个检索结果，必须主动核对是否已有更新的修正/修订版本，不沿用旧版条号或旧表述；`seed_legal_search` 结果与近期新规不一致时，以官方数据库现行有效版本为准。
4. 征求意见稿、草案、暂未施行的文件不得作为现行依据；如需引用，明确标注状态并只作趋势提示。
5. 无法确认时效或只能查到二手转述的，标记“待核验”，不作确定性结论的支撑依据。

## 检索与引用

1. 优先检索目标法域官方来源，避免以新闻报道替代原文。
2. `seed_legal_search` 仅用于法律、法规、规章等规范性文件的检索，不用于案例；司法裁判、行政处罚决定等案例一律走官方裁判文书库、人民法院案例库或监管机关官网，不依赖 `seed_legal_search`。其返回的法条仍须按上文核验版本与效力，通用搜索引擎、新闻和二手文章只用于发现新规、案例线索和检索关键词，不得替代官方原文。
3. 每条来源记录名称、发布机关、发布日期、生效日期、效力状态、URL 和检索日期。
4. 法规引用到具体条款；案例记录案号、法院、裁判日期和裁判要旨。
5. 同一结论通常保留不超过三条最直接依据。
6. 无法访问原文、无法确认时效或只找到摘要时，标记“待核验”。
7. 法律修订、官方解释和新规冲突时，核对新旧文件衔接条款，不自行推定。

## 动态来源

以下信息不得长期固化为静态结论：

- 制裁、出口管制和受限主体名单；
- 数据跨境门槛和申报指南；
- AI、算法和内容标识规则；
- 许可目录、行业资质目录和监管政策；
- 平台、应用商店或标准组织规则。

对动态来源必须记录“最后核验日期”，生成报告时重新查询。

## 法域边界

1. 公开来源包主要提供中国法官方入口，并提供部分跨境监管入口。
2. 涉及其他法域时，应加载该法域官方来源或由当地专业人员确认。
3. 不因合同适用法约定而忽略经营地、用户所在地、数据所在地或制裁规则的强制适用。

## 组织政策

组织政策单独列示来源和版本，不进入法律依据等级。政策严于法律时可以作为内部控制建议；政策宽于法律时不得据此放行。
