# Output Contract

## Expected Deliverable

投标包，包含需求追踪、胜标主题、方案、交付、成本假设、证据、例外、审批和提交清单。

## Required Sections

- 合规矩阵
- 客户理解
- 解决方案
- 交付治理
- 报价假设
- 审查提交

## Completion Rule

Deliver every applicable section, label unknown information, and end with concrete next steps. Do not claim an artifact, source check, calculation, or tool execution that did not occur.
