# 艺术指导与参考使用

在用户要求“更好看、更有质感、更有艺术感”或提供作品网站时使用。以下是设计判断方法，不是必须套用的样式库；不把艺术感等同于暗色、极简、奢侈品、三维或英文排版。保持宣传内容可读和品牌辨识。

## 从参考中提取可迁移的手法

有清楚的用户参考便先用现有材料。需要扩展时，挑少量与当前品牌、内容、静态尺寸相容的作品，通常 2–3 个足够；看实际视觉，不凭站名、奖项或分类猜审美。每个参考用一句话记下“观察到的手法 → 对本图的用途”，并保留来源链接。

区分三类依据：品牌资产约束、用户要保留的风格、可借鉴的艺术处理。网站中的别家 Logo、文案、独创插画不自动成为可直接置入的素材。不要混合所有参考的配色和材质；一个主方向，加少量相容细节即可。网页里的悬停、视频和滚动叙事，需要转成静态图中成立的焦点、层次和阅读顺序；无法成立就不借用。

可按需从 [站酷](https://www.zcool.com.cn/)、[Godly](https://godly.website/)、[Siteinspire](https://www.siteinspire.com/websites) 或 [CSS Design Awards](https://www.cssdesignawards.com/) 寻找作品。这些只是可选的参考入口，不是指定风格或品牌规范；遇到跳转，记录当次实际目的页，不把旧站名视为当前来源。需要采用具体作品时，查看当次实际可见的画面并记录作品级来源；直接置入图片/字体等资产时核实允许用途，不能把页面可达当成授权。不把过往访问记录当成当前已看过的依据。网站不可访问时继续用用户提供的参考与本地设计原则。

## 先决定画面为何值得看

针对同一个核心信息，在工作笔记中比较两种简短视觉想法，选更贴合品牌且一眼能理解的一种；不必额外生成两张、不必等用户选。每张只需一个明确创意，产品直观展示本身也可以是创意，不强迫做隐喻。

例：宣传“资料梳理”，可以选择文件的精美编辑展示，也可以选择纸页由散到聚的视觉关系。前者靠字体秩序与纸张细节成立，后者靠组织变化表达价值；都不必加入圆台、放大镜、箭头、云和多套小图标。

## 按内容选择构图与表现

| 内容目的 | 可选设计手法 | 执行要点 |
| --- | --- | --- |
| 突出一个成果 | 主体近景或局部大幅裁切 | 表面和边缘值得近看，标题沿主体轮廓或网格组织，必要内容不被裁掉 |
| 表达变化或过程 | 同一视觉对象的状态变化 | 利用方向、排列、明暗表达逻辑，不默认三张等距卡片加箭头 |
| 传递观点或品牌主张 | 字体主导的编辑排版 | 用一处显著字号/字重对比与精确行长建立记忆点；中文语义完整，不用装饰英文充数 |
| 展示场景或情绪 | 摄影、插画或受控拼贴 | 明确取景和色调，主视觉与标题形成关系；选择一个叙事，不堆所有功能 |
| 展示专业工具 | 经设计的产物/界面局部 | 只露出帮助理解的内容，完整页面可适度裁切；不把低保真骨架当精致产品成果 |

版式多样时改变视觉逻辑：例如同一批分别使用成果近景、字体与主体嵌合、状态变化、场景取景。五张仍共享字体体系、色彩角色和图形/光影语言；不能为差异把摄影、卡通、金属三维随机混成一组。

## 质感与字体的具体选择

- 先决定哪些区域是亮、暗、纯色、纹理。品牌色可以集中在关键形状或文字上，不必把所有物体都染成同一种荧光色。底色、强调色与中性色分工清楚，数量由品牌决定。
- 三维材质选主要表面与少量对比：如哑光纸与局部透明亚克力；写清纸页厚度、亚克力边缘折射、单一柔和侧光与接触阴影。别让所有边缘同时发光，也别把任何材质都渲染成充气塑料。
- 平面画面可以靠精确色块、线条粗细、裁切和叠印关系获得质感；纹理只在主题需要时使用，强度不能破坏文字和 Logo。
- 字体设定应描述气质和关系：清晰有力的标题、较轻辅助文字、明确基线和段间距。广告需要响亮时可用粗体，但不用“整图所有文字都巨大超粗”代替层级设计。
- 留白围绕焦点形成形状。过空先查内容尺度和定位；过满先移除重复说明与装饰；不能把扩大元素当唯一解法。

## 将方向写入提示词

只写已选方向，使用如下顺序组织自然语言，无需生成 JSON：

1. 核心信息和一句视觉创意。
2. 参考角色，以及必须保留的品牌身份。
3. 主体、取景、图文关系和刻意安静的区域。
4. 字形气质、标题/辅助层级、配色角色、材质或笔触的具体处理。
5. 准确文案与本张真正相关的限制。

示例方向（仅在本次参考支持纸张材质时使用，不是默认风格）：

> 表达“让研究更清晰”：一组白色纸页由散开转为整齐的扇形，形成一个明确视线方向，本次选定的强调色只用于关键边缘与标题强调。纸张保持哑光、可见薄边，左上柔和侧光，接触阴影干净。标题与纸页共用对齐轴，较轻辅助文字贴近标题组，保留一块安静底色衬托主体。只保留用户文案和品牌 Logo，不额外添加功能卡片、圆台或发光描边。

审图后指出具体差距并定向修正。若核心仍是无关摆件配一句口号，应重构主视觉；若只是纸页边缘或文字间距有问题，保留方向作局部修正。不要把“整齐”“清晰”“输出成功”当成审美通过的全部理由。
