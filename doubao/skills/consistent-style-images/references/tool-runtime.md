# 工具适配与异常处理

生图前确认当前工具的真实能力；失败或输入超限时查阅相应行。保持技能通用，不预设供应商、模型、鉴权或参数名称。

## 能力与输入输出

| 任务 | 必要能力 | 输入语义 | 输出与验证 |
| --- | --- | --- | --- |
| 自然语言方向的宣传图 | 生成位图 | 本张内容、已选风格、构图、准确文案、尺寸意图 | 可查看的单张图片；核对实际尺寸与文字 |
| 参考图或系列扩展 | 工具能实际接收图像 | 可读取的风格参考、合格样张，分别标明用途 | 逐张查看是否延续样张；文字中写“同上一张”不等于传图 |
| 局部修正 | 编辑图像或重新生成 | 待改图片、具体修改点、保留项 | 检查改动区域及原有内容，保留原版本 |
| 精确本地排版 | 用户选择且宿主允许的本地合成 | 已准备底图、授权字体/Logo、layout 配置 | PNG 与待审记录；不是生图能力的替代品 |

语义示例：输入“2 张横版茶饮海报，采用用户参考的版画线条，文字分别为‘春茶上新’和‘一口回春’”；先传参考生成第一张，自检后把参考和第一张作为第二张的实际图像输入。输出为两个独立文件，报告实测尺寸。将这些语义映射到当前工具 schema，不能把示例当成某供应商的固定字段，也不假定工具具有 seed、字体加载、保存路径或精确尺寸参数。

有图像工具但不支持参考图时，无法保证按实际图像锚定系列；说明缺口，提出支持参考输入的可用路径。仅用户接受描述式近似后才改为该方式。需要读取远程资料时使用可用且已授权的访问方式，不能绕过登录或换用未经授权的服务。

## 失败与边界

| 情况 | 执行动作 |
| --- | --- |
| 没有主题，也没有可用参考/描述 | 只追问影响结果的主题或方向；不从历史补品牌。缺数量/尺寸按主文件的合理默认处理 |
| 参考文件不存在、损坏或不可访问 | 明确哪些文件未读到，先使用其余已读资料做独立准备；关键参考缺失时请用户补回，不猜测内容 |
| 参考数量超工具上限 | 按角色选择最相关参考和合格样张；必须保留的身份/资产无法同时传入时说明限制，不能悄悄舍弃 |
| 超长定稿与小画幅冲突 | 先尝试语义完整的重排；仍不可读时给出具体分图或精简方案，再就改变原文/数量取得用户意见。不默默删字或缩成不可读文字 |
| 工具不支持目标比例/精确尺寸 | 优先选择支持该要求的已授权路径；需要改规格时说明可得尺寸与差异，不把近似尺寸标成精确。后期按宿主规则及用户选择执行，不拉伸主体 |
| 超时或结果状态不明 | 先查已有任务状态和输出，避免重复请求；确认失败后，瞬时错误最多再试 1 次，仍失败则报告并保留已完成图 |
| 参数错误或能力不支持 | 依据真实 schema 修正参数；不对同一不支持的能力反复重试 |
| 无可用工具、权限不足或服务拒绝 | 如实说明缺口；不以纯色脚本夹具当成成品，不绕过限制，不静默启用另一个计费/外传路径 |
| 批次部分完成 | 保留合格图片、实际文案和必要恢复信息；报告完成数/目标数及剩余原因，恢复只处理未完成或受影响项目 |

这些是运行失败处理；画面质量修正仍遵守主文件每张最多两轮的约定。失败不改变用户授权范围。

## 平台验证边界

迁移到目标平台时检查上述能力及实际绑定；有元信息或已成功调用才记录“可用”。本机成功不等于目标平台已注册或有权限。平台验证只在部署/审核任务中进行，不给普通生图增加表单或确认步骤。
