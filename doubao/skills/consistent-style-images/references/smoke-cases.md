# 触发与运行测试

修改或发布本技能时使用，不是普通生图的前置流程。按可观察行为记录结果；写下预期不等于已经执行模型路由或生图测试。

## 自然语言用例

| 类型 | 输入 | 预期行为 |
| --- | --- | --- |
| 应触发 | 参考这张海报，做三张同风格的咖啡活动横版图，文案自拟 | 先读参考，样张自检后传入后续调用，总量 3 张，不复制参考活动权益 |
| 应触发 | 五张黑白木刻风公益宣传画，不要 Logo，排版有变化 | 依据描述制作，图形语言统一，不要求品牌资料包 |
| 应触发 | 把这组课程海报统一成温暖手绘风，保留全部文案 | 保留文字并逐张检查，按系列重排 |
| 不启动生图 | 只审核这个生图 Skill 的代码和触发描述 | 使用审核流程，不调用图像生成工具 |
| 不触发 | 把现有 SVG 图标的描边从 2px 改成 3px | 编辑矢量文件，不启动宣传图流程 |
| 相邻边界 | 给这张普通证件照去掉背景 | 交给一般图像编辑能力，不套系列宣传工作流 |
| 专用边界 | 已显式指定本技能，另一个品牌技能也匹配名称 | 使用本次指定工作流，只按用户明确适用的规范加入资产要求，不并行跑两套流程 |
| 输入不足 | 做几张图（无主题/参考/方向） | 集中追问核心主题或方向，不补历史品牌 |
| 内容冲突 | 800 字原文全部放入小横幅，一个字不许改 | 先给具体排版方案，不能静默删字或新增图片数 |
| 运行故障 | 第二张超时，第一张已完成 | 检查状态避免重复生成；确认失败最多重试 1 次，保留第一张并报告进度 |
| 参考失效 | 必须参照的图片文件不存在 | 明确未读到，要求补回，不声称已参考 |
| 尺寸受限 | 精确 1600×900，但工具不能提供 | 选择支持路径或说明差异；不把实际 1672×941 标成精确尺寸 |

## 本地脚本回归

从技能根目录执行（使用当前可用 Python；只在临时目录产生技术测试图片，不调用生图服务）：

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

[测试代码](../tests/test_local_workflow.py) 验证无品牌/无字计划、坏 JSON、无效尺寸、指纹变化、重复输出、最小排版、防覆盖和已审文件变化后的拒绝行为。示例及测试图只是脚本夹具，不是设计作品。

当前测试环境：Python 3.9.6、Pillow 11.3.0；测试不代表未测版本均兼容。自然语言用例需另在目标宿主执行，记录工具调用、产物和限制；不能用脚本通过替代该证据。
