# 风格统一宣传图生成

交付有明确视觉创意、品牌一致、图文协调的广告成品。**信息清楚、构图饱满是基础，还要有独特的视觉焦点、精细的字体关系和可信的材质或图形表现。** 用户只要求评估、方案或修改技能时，不启动生图。

本技能负责宣传图的风格与系列设计；普通照片修补、背景移除或已有 SVG 的局部编辑由对应图像/矢量能力处理。用户显式选择本技能时依本次参考工作；另有品牌专用技能时，只在用户选择该技能或明确要求其专属资产/规范且适用范围一致时采用其规则，不因提到品牌名就叠加两套制作流程。宿主的图像工具说明负责调用方式，本技能负责设计与检查；不隐式依赖另一个技能才能执行。

## 理解需求后直接推进

从对话与材料提取视觉方向、宣传内容、数量和尺寸。参考图或自然语言都可以开工，不要求品牌战略、资料表或逐步确认。只追问实质影响结果且无法推断的缺口；缺数量和尺寸可先做一张适合用途的图片并简短说明规格。

本技能不内置或默认选择任何品牌。品牌、产品事实、Logo、字体和视觉规范均从本次任务适用的用户资料获取；只有明确要求延续同一项目时才复用已选材料，不能因为历史对话出现过某个品牌就自动沿用。仅作风格参考的图片不授权复制其中的品牌标识、产品文案或活动权益。

品牌名称、Logo 和文字均为可选项。未要求品牌标识时不补 Logo；已要求特定 Logo 但缺少素材时，先检查用户指定资料，再仅追问必要缺口。缺少正式配色或字体规范时，可依据本次参考作设计选择，并区分设计建议与官方标准。

用户定稿文案保持原文；授权代拟时，用一个主信息和必要辅助内容表达价值，不把功能清单全部放上画面。不编造产品能力、价格或活动权益，不为了填空擅加卖点和 CTA。允许无文字或纯字体海报。

## 1. 读懂参考，确定艺术方向

先看实际参考图，区分品牌标识、风格依据、内容素材与需要直接使用的官方资产。提取色彩关系、字体气质、构图节奏、摄影/插画/图形表现、光线与表面质感；只看配色不算完成参考分析。只有自然语言时直接转成这些设计选择，不必补找参考图。

用户要求接近原图时保留其关键视觉特征；用户要求在原风格上更有质感时，保留品牌识别和主色关系，改进信息密度、字重、材质与布局，不把旧图里的粗糙处理继续当标准。参考冲突且无选择依据时集中问一次。多品牌不串用字体、Logo 或规则。

每批制作前用几句工作笔记确定：**核心信息 → 视觉创意 → 字体与色彩 → 材质/表现方式 → 构图与留白。** 这由 Agent 完成，不增加用户确认步骤。不要只写“高级、艺术、精致、获奖级”；要落实成看得见的选择。风格由本次参考与主题决定，蓝白、纸雕、科技、摄影、插画等都只是可选方向，不设默认配色、材质或行业。

普通任务使用下述原则即可。用户强调设计感、艺术感、质感或提供设计作品网站时，读取 [艺术指导与参考使用](references/art-direction.md)，选择与品牌相容的手法。网站只作按需灵感来源，不要求每次遍历。把网页的视觉关系转译成一张静态广告，不照搬导航、滚动长页或互动效果。

用户提供正式规范时，只采用与本次任务有关的规则；用户本次明确要求优先。需要长期复用时按 [资料接入说明](references/brand-profiles.md) 将资料保存在用户指定的项目目录，技能包本身保持通用。

## 2. 设计画面，而非堆齐元素

- **一个视觉创意：** 从本张主题选择一个有记忆点的主体或图文关系，图片与文案共同表达同一个意思。产品、场景或成果可以直接展示，或采用有依据的视觉隐喻；不用固定的一套图标或摆件替代主题表达。
- **构图有主次和节奏：** 先确定第一眼焦点，再安排阅读路径。用尺度反差、裁切、局部叠压、偏心平衡或网格中的重点变化形成张力；根据内容选择，不同时堆满所有手法。让标题与主体互相呼应，不机械地各占半张。
- **饱满而有呼吸：** 饱满指视觉重心稳定、空间有目的。去除内容过小、散落造成的无效空白，同时保留衬托焦点、分隔信息的留白；不要靠把所有文字放到最大、铺满卡片或增加装饰来填充。局部密集配合局部安静，不能每个区域都在争抢注意力。
- **字体是设计的一部分：** 根据品牌选字形与字重，用字号、行长、行距和对齐建立秩序；细调中文断行、标点、字间距与中西文基线。标题有力度但不默认超粗、倾斜或描边；不能为造型拆断语义、拉伸字形或牺牲可读性。辅助文字保持实际展示尺寸可读。
- **质感来自具体表现：** 选择适合主题的主要材质或图形语言，控制背景与主体的明度、边缘和细节。三维画面明确光源方向、表面粗糙度、厚度与接触阴影；平面/插画通过线条、色块、印刷感或笔触获得质感，不必加入三维。没有参考依据时，不默认玻璃、金属、霓虹、颗粒或发光边框。
- **适度克制：** 装饰应强化主题、品牌或视线引导。删掉可有可无的小图标、圆台、光环和重复口号。不要用灰色短线/假字占满画面冒充精美产物；需要演示内容时，设计少量可读的真实示例，图形示意与真实产品截图明确区分。

用户要求版式多样时，先为每张确定不同的视觉组织方式；仅交换左右位置不够。可以改变主次关系、取景远近、图文嵌合或疏密节奏，同时保持同一批的色彩逻辑、字形、光线/材质语言和品牌标识规范。无需每张强行不同，也不能变成五个互不相关的风格。多尺寸需重排，不拉伸主体或裁掉必要内容。

## 3. 制作、审美检查与修正

默认用当前可用的图像生成/编辑工具。提示词先说明主题和视觉创意，再写构图、字体、色彩及具体质感选择，最后提供准确文字与必须保留项。只放与该图有关的约束，不能把旧提示词中“巨大黑体、玻璃卡片、发光底座、填满全画面”整套继续复用。网站链接不能替代工具真正可见的参考图。不要以代码占位图代替视觉创作。

调用前从实际工具说明确认参考图输入、生成/编辑能力与结果读取方式；只传当前工具支持的字段。无可用工具、失败、参考或尺寸受限时，按 [工具适配与异常处理](references/tool-runtime.md) 处理，不声称已完成未产出的图片。

批量先完成一张，自行检查创意与工艺后再扩展，这张计入总量。用户要求先确认样张时才等待。只把检查合格的样张作为后续参考；有本地路径时按工具规则实际传入，同时保留品牌参考，不能仅在文字里声称“与上一张一致”。每张独立输出，不以拼图代替多张成品。

精确字体与原始 Logo 的置入按需求及工具规则处理，普通任务不强制拆分底图与后期。图像生成复现不等同于原资产精确置入，交付时如实区分。

查看实际成图，按下面四项判断，不以提示词、哈希或脚本成功证明美感：

1. **品牌与主题：** 是否贴合用户参考和本张信息？主视觉是否有具体表达，换一个标题就能用于任何产品的通用摆件是否过多？
2. **整体设计：** 缩小看能否记住一个焦点？标题和主体是否互相呼应？留白有用途，既没有松散空洞，也没有满屏喊话、卡片等大等距的僵硬排布？
3. **细节质感：** 实际尺寸看文字正确、间距细致、边缘干净；材质与光影可信或图形语言自洽，没有塑料泛光、杂乱投影、糊字和无意义纹理？
4. **系列与交付：** 并排看属于同一系列，要求多样时确有不同视觉组织；数量、尺寸、格式与必要内容完整？

若构图整齐但视觉仍通用、质感粗糙或每张都像同一张模板，不判通过。先指出具体原因，再修最关键问题：创意弱则改视觉关系；排版僵则改尺度/行长/阅读路径；廉价泛光则改光源/表面/边缘；过满则删次要内容。不要只追加“更高级”或更多特效。修改后重看。默认每张最多两轮修正，仍不合格则如实说明，不无限重试。

交付图片预览、文件链接和必要的数量/尺寸说明；有未解决项直说。按用户指定目录保存，否则使用独立的 `output/brand-campaign/<批次名>/`，避免覆盖已有成果。

## 按需高级资源

普通生图不以填写配置与记录作为开工或交付前提：

- 长期复用规范和资产：[品牌资料包](references/brand-profiles.md)，使用 `scripts/profile_utils.py` 加载资料并计算指纹。
- 可追溯批次、结构化审核或任务恢复：[批次记录](references/batch-workflow.md)、[审核记录](references/quality-review.md)，使用 `scripts/check_batch.py` 校验批次配置与交付记录。
- 用户选择精确本地排版且工具规则允许：[参数化排版](references/composition.md)，使用 `scripts/compose_poster.py` 合成底图、授权字体与原始 Logo。技术夹具不是广告构图模板。
- 工具适配、失败和输入边界：[运行约定](references/tool-runtime.md)。
- 发布或修改技能后的复核：[触发与运行测试](references/smoke-cases.md)；包含本地测试命令，普通生图无需执行。
- 平台接口配置：`agents/openai.yaml` 为 OpenAI Agents SDK 平台的接口声明，包含显示名称、简介与默认提示词，仅在该平台加载时生效。
