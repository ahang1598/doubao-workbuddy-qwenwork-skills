# 商品图片生图参考：文字红线与生成后检查

## 文字红线

- 画面中不要出现无法证明的“第一”“最强”“100%”“治愈”“永久”“官方授权”“销量第一”。
- 不要生成假评价截图、假检测报告、假认证章、假平台 UI。
- 不要把场景道具、另购配件或赠品画成默认包含物。
- 不要误导尺寸、数量、规格或适用范围。
- Amazon A+ 和跨境详情图避免价格、折扣、购买按钮、联系方式和夸张促销语。

## Prompt 密度要求

好的商品图片 prompt 需要足够具体，但不要堆无关形容词。至少覆盖：

- 画面类型：商品主图、场景主图、首屏、卖点拆解、材质细节、步骤、参数、包装、信任说明。
- 画幅方向：竖版、方图、横幅、A+ 模块等。
- 商品主体：位置、大小、角度、保留项。
- 背景：颜色、材质、光线、场景或留白。
- 文案：主标题、支撑点、参数、标签，逐字写出。
- 版式：分栏、卡片、局部放大、步骤、尺寸线、表格等。
- 证据：哪些能写；缺证据的信息不进入画面，放到交付备注。
- 禁止项：不能出现的 claim、图标、配件、价格或第三方标识。
- 画面比例：方图、竖图、横幅或平台模块尺寸；不确定时写成比例而不是随意给像素。

避免低质量 prompt：

- “做得高级一点”“突出卖点”“生成详情页图”这类过短描述。
- “若干卖点”“相关文字”“产品说明”等让模型自由补字的表达。
- 只写风格，不写画面结构。
- 只写文案，不写商品、背景、构图和光影。
- 一条 prompt 同时要求生成主图和完整长详情页的所有屏。

## 简洁高密度写法

可以不用写成特别长的说明书，但每句话都要承担一个画面任务：

```text
这是一张竖版产品步骤说明图，浅灰白背景、柔和影棚光。画面顶部居中写黑色粗体标题“3步完成日常使用”，中央从左到右排列三张白色圆角步骤卡：第一张展示手持商品打开盖子，文字“1 打开瓶盖”；第二张展示按压/取用动作，文字“2 取适量使用”；第三张展示商品放回收纳区，文字“3 清洁后收纳”。底部放置商品完整主体和包装清单小图，保持商品颜色、包装文字和比例真实。整体文字清晰、留白充足，不出现功效保证、销量、认证章和价格。画幅：3:4。
```

## 生成后检查

生成真实图片后检查：

- 商品主体是否保持真实：颜色、结构、包装、Logo、比例是否被误改。
- 多张图片中的商品主体是否一致：包装、颜色、结构、配件数量和比例是否前后一致。
- 每张图片是否继承同一主参考图：不能出现不同型号、不同 SKU、不同包装、不同配件数量或商品从一款变成另一款。
- 文字是否可读、无乱码、无裁切、无重复。
- 中文、英文和数字是否逐字正确，字体是否支持字符集，是否存在方块字、问号、错别字、异常大小写或标点错误。
- 文字是否完成电商版式化：标题、副标题、价格、标签、注释是否有层级、对齐、容器、安全区和留白。
- 文字是否遮挡商品主体、Logo、包装文字、口红膏体、瓶身高光、尺寸线或局部放大窗。
- 如果使用后期文字兜底，是否接近模型原生版式质感；若明显像手工贴字，应退回强文字模型重生或重新做局部修字。
- 图文是否一致：卖点和画面是否互相支撑。
- 平台位置是否适配：详情页、A+、信息型副图不要混用规则。
- 是否出现未经证实的认证、销量、评价、价格、功效。
- 多张图是否保持统一色彩、字体、光影和商品识别。

如结果偏离，只修正导致偏差的关键 prompt：参考图、保留项、文字、版式、比例或禁用项。

交付给用户时：

- 生成成功：展示带最终文字的成品图片，并用一句话说明每张图的用途。
- 飞书文档交付成功：文档内必须展示主体参考图、全部主图成品和全部详情图成品；若图片多，按 D1-D5、D6-D10、D11-D15 分组做图文展示或正文图片块，不能省略 D5-D10 等后段详情图。
- 只能生成无字底图但无法完成文字合成：不算生成成功，必须继续用真实字体叠字或说明具体阻断原因。
- 无法生图：交付每屏 prompt / brief，说明可直接给设计师或生图工具执行，并明确这是降级交付。
- 部分信息缺失：不要把缺失内容写进画面，放到“建议补充信息/需补充证据”里。
- 未提供真实商品图：结尾提醒用户上传商品图，用于替换概念主体并保持主图、详情图一致。
