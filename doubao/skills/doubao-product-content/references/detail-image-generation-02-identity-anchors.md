# 商品图片生图参考：素材读取与主体一致性

## 素材读取与视觉锚点

用户提供商品图、包装图、场景参考或前轮生成图时，先提取可复用锚点，再写商品主图和详情图 brief / prompt：

- 商品识别锚点：外形轮廓、颜色、材质、Logo、包装文字、型号、接口、瓶盖、扣件、鞋底、纹理、配件数量。
- 拍摄/生成锚点：视角、透视、主光方向、阴影位置、反光强度、背景色、台面材质、商品占画面比例。
- 版式锚点：主色、辅助色、字体气质、标题位置、卡片圆角、线条粗细、图标风格、留白比例。
- 不可迁移项：参考图里的道具、其他品牌元素、平台 UI、评价截图、认证章、价格、活动信息，除非用户明确提供并要求使用。
- 用户实拍图的原背景默认也属于不可迁移项。只把商品轮廓、颜色、材质、Logo/包装、真实配件和比例写入主体保留清单；把拍摄环境写入 `不应出现`，例如杂乱桌面、墙面、数据线、非售卖道具、房间背景。

多张商品图片要维护同一套商品识别锚点，但不要复制同一构图。必须在“主图全貌 -> 交互 -> 局部 -> 场景 -> 平铺 -> 参数”的视角之间切换，让整套图统一但不呆板；飞书文档中要展示主参考图本身，便于用户核对主体是否被后续图片继承。

## 多图主体一致性流程

用于主图、详情图、场景图、套装图和 A+ / PDP 多模块图片。公开工作流里的共识是：主体一致性不能靠每张文生图 prompt 重复描述保证，必须使用同一张参考图、同一套结构约束或同一个专属商品模型来约束生成。

默认顺序：

1. 确定主参考图：优先使用用户上传的真实商品图；没有真实商品图时，先生成或搜索确定一张概念主参考图，再用它作为后续图片的临时主体基准。
2. 给主参考图编号，如 `REF-1`，并建立主体保留清单：颜色、外形轮廓、材质、Logo、包装文字、型号、接口/瓶盖/扣件、配件数量、SKU 数量、比例、关键纹理和正反面差异。
3. 先生成商品主图或标准展示图，确认主体成立后再生成详情图；不要在多屏详情图里各自重新文生图。
4. 生成详情图前先分配资产类型和视角，保证整套图包含整体/全貌、局部细节、使用或场景、规格/参数/包装/步骤中的多种类型。
5. 后续图片优先走图生图、参考图条件、局部重绘或商品抠图合成，只改变背景、角度、手部动作、局部放大、版式和光影；用户实拍图必须先隔离商品主体，再替换为干净影棚、真实使用场景或信息图背景。
6. 每生成一张图，先做主体一致性检查，再做文字合成；主体不一致时先修主体，不要用文字层掩盖商品变形。

工具路线选择：

- 真实商品图充足：使用图生图/参考图模式；主商品区域尽量保留，主要改背景、光影、构图和信息图元素。
- 需要严格保留轮廓、姿态、尺寸线或包装位置：使用 ControlNet 类结构控制（边缘、深度、轮廓、姿态/布局）或等效结构参考。
- 需要跨场景保持同一商品外观：使用 IP-Adapter / reference-only / image prompt 等参考图适配路线，把同一商品参考图传入每张图。
- 只需换背景或加道具：优先商品抠图合成或局部重绘背景，不重绘商品主体。
- 用户实拍背景污染明显：先商品分割/抠图得到干净主体，再合成到影棚或商业场景；如果必须图生图，prompt 明确“保留商品主体，不保留原拍摄背景和周边杂物”。
- 需要统一很多张、很多角度或长期复用同一商品：考虑基于商品照片训练 LoRA / DreamBooth / Textual Inversion 等专属主体模型；训练前需要多角度清晰图片，且要保留真实包装和 SKU 差异。
- 商品主体已在某张图里正确，局部有问题：用 inpainting/局部重绘，只修背景、手部、阴影、局部细节或错误区域，不整张重生。

禁止流程：

- 不要让多屏详情图分别用纯文生图生成同一商品。
- 不要只在 prompt 里反复写“保持一致”却不提供参考图或结构约束。
- 不要把一张图里随机生成的商品外观，当成另一张图的商品事实，除非用户确认它就是主参考图。
- 不要为了场景好看而改变商品颜色、包装、Logo、配件数量、规格或 SKU。
- 不要把参考图里的灵感商品替换成用户商品；灵感图只参考版式、配色和视觉节奏。

主体锁定 brief 必须写清：

- 主参考图：用户图 / 已确认主图 / 概念主参考图 / 公开信息待确认；飞书文档中必须插入该图并标为 `REF-1` 或等效编号。
- 必须一致：颜色、结构、包装、Logo、文字、比例、配件和 SKU。
- 可以变化：背景、光影、角度、裁切、手部动作、版式、局部放大、文字层。
- 不能变化：商品类别、型号、颜色、关键结构、Logo/包装主视觉、数量和赠品关系。

主体一致性检查：

- 颜色是否一致：主色、透明/金属/织物质感、包装底色不应漂移。
- 结构是否一致：瓶盖、接口、按钮、鞋底、包带、扣件、风扇叶片、屏幕边框等不能变形或增减。
- 包装是否一致：Logo、型号、图案位置、瓶身/盒身文字不能换品牌或乱造。
- 数量是否一致：单品、套装、配件、赠品、规格数量不能多画或少画。
- 比例是否一致：商品高宽比、厚薄、容量视觉比例不能明显变成另一款。
- 多图是否一致：把所有成品缩略图并排看，买家应能判断是同一件商品的不同角度/场景。

如果用户有商品图但没有版式/风格参考，且平台品类特征不足以锚定视觉组织方式，可搜索或读取 1 张灵感参考作为版式/配色/视觉节奏锚点。灵感参考只用于组织方式，不能替代或改变商品主体；生成或 brief 中必须说明商品外观以用户商品图为准。

如果用户没有商品图：

- 有明确商品名时先联网搜索商品名称或品类常见外观，提取常见形态、包装样式、结构比例和主流使用场景，再输出可执行 brief 或概念图。
- 没有明确商品名但有品类时，只能按品类常见外观生成概念方向。
- 文生图只能生成“商品概念图/商品图片方向”，不能假装已经还原了真实商品包装。
- 涉及包装文字、Logo、型号、专利结构、认证标识时，必须使用占位风险说明，不把它们画成事实。
- 交付末尾必须提醒：上传真实商品图可显著提高商品主体一致性，避免生成图和实物不一致。
