# 原子输出契约：标题与详情文案方法

## 标题写作方法

- 关键词挖掘：先列产品词，再列属性词、场景词、人群词、证据/信任词。
- 核心词：品类大词或用户真正会搜索的商品词，例如“保温杯”“防晒衣”“蓝牙耳机”。
- 属性词：材质、规格、功能、颜色、容量、型号、适配范围等。
- 场景/人群词：使用场景和购买对象，例如“通勤”“户外”“学生”“宝妈”“送礼”。
- 标题结构：产品词 + 核心卖点/属性词 + 场景/人群词 + 必要补充词；品牌词只有用户提供或确认可用时加入。
- 黄金位置：标题前段优先放产品词和最大购买理由，避免前半句被空泛形容词占掉。
- 可读性：关键词自然嵌入，不为了覆盖词而牺牲可读性。
- 违禁词检查：检查极限词、虚假宣传、未经授权品牌/IP、无依据功效和平台敏感表达。

好标题：

- 买家立刻识别商品是什么、适合谁、核心差异是什么。
- 产品词准确，属性词具体，场景词和人群词服务真实搜索意图。
- 关键词自然嵌入，可读性强。
- 核心卖点前置，但不牺牲商品识别。
- 没有无法证明的销量、排名、认证、价格和功效承诺。

差标题：

- 只有“爆款、热卖、高级、好用”等空泛词。
- 关键词重复堆叠，像词库拼接。
- 用错类目词或把不确定属性写成事实。
- 为吸引点击写夸大承诺，详情页和证据无法承接。
- 跨境标题直译中文电商黑话。

## 详情页文案方法

- 基础顺序：购买阻力 -> 核心卖点 -> 证据/细节 -> 使用场景 -> 选择与安心。
- 痛点引入：用买家真实顾虑切入，不制造焦虑，不夸大问题。
- 卖点展示：每个卖点按“特征 -> 作用 -> 买家好处”展开。
- 信任背书：只使用用户提供的检测、认证、评价、质保、物流、授权、数据。
- 使用场景：让买家知道什么时候、谁、怎么用，而不是只写抽象体验。
- 促单表达：优惠、限时、库存、赠品只在用户提供时出现；没有依据时用规格、适配、售后边界和选择建议降低决策成本。
- 人群差异：不同人群版本要改变关注点，而不是只换称呼。

好详情页文案：

- 先回应买家最关心的购买阻力，再展开卖点和证据。
- 每个卖点都能追溯到商品事实。
- 用具体场景、具体参数、具体触感或具体步骤替代抽象夸奖。
- 文案层级清楚，图文可以互相支撑。

差详情页文案：

- 通篇“高端、舒适、精选、品质好”，没有具体证据或场景。
- 只罗列参数，不解释这些参数对买家有什么用。
- 先讲品牌口号或宏大理念，迟迟不回答商品能解决什么问题。
- 虚构评价、认证、销量、前后对比或促销紧迫感。

## 标题与详情页文案协同

- 关键词一致：标题中的核心产品词、属性词和场景词，应在详情页文案中自然出现并解释。
- 卖点呼应：标题突出的核心卖点，详情页要重点展开。
- 人群匹配：标题吸引的人群，详情页语气、场景和顾虑要对应。
- 证据闭环：标题里出现的强 claim，详情页必须有证据承接；没有证据就降低标题表达强度。
- 详情图承接：详情页文案中的核心模块要能转成详情图画面。
