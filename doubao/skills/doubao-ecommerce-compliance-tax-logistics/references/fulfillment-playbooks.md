# Fulfillment Playbooks

## Fulfillment Options

| Route | Best for | Key fields | Main risks |
|---|---|---|---|
| Domestic self-fulfillment / cross-border direct mail | Lightweight, low inventory, test orders, low service-level promise | Weight, dimensions, value, carrier, destination, tracking, return address | Long delivery, customs delay, DDU surprise, return cost |
| FBA / WFS / platform warehouse | Amazon/Walmart/platform speed and conversion, Prime-like promise | SKU, ASIN/item, dangerous goods status, IPI/capacity, inbound lead time, package size | Hazmat review, capacity, aged inventory, stranded inventory, storage fees |
| Overseas warehouse / 3PL | Multi-platform, local delivery, returns, larger SKU portfolio | Warehouse country, SKU volume, outbound fee, storage fee, return processing | Inventory lockup, compliance labels, local tax nexus |
| Express DDP | High-value or urgent orders | HS, COO, declared value, carrier account, recipient phone | Cost, wrong classification, brokerage fees |
| Postal / economical DDU | Low-value lightweight goods | Destination, value, package size, tracking requirement | Slow clearance, customer refusal, lost parcel |

## FBA / Platform Warehouse Checks

| Check | Evidence path |
|---|---|
| Dangerous goods / hazmat | Seller Center dangerous goods classification, SDS/exemption sheet |
| Inventory capacity | IPI, capacity dashboard, product type capacity |
| Stranded inventory | Fix Stranded Inventory, listing status, suppression notice |
| Storage / aged inventory | Inventory age, monthly storage fee, aged inventory surcharge |
| Restock timing | Sales velocity, manufacturing lead time, freight lead time, check-in time |

## Landed Cost Fields

| Cost bucket | Examples |
|---|---|
| Product cost | Unit cost, packaging, inspection |
| Export / origin | Domestic freight, export declaration, pickup |
| International freight | Air/sea/rail/truck, fuel surcharge, insurance |
| Customs | Duty, import VAT/GST, brokerage, disbursement |
| Platform/warehouse | Inbound, placement, storage, fulfillment, removal, disposal |
| Returns/loss | Return shipping, refusal, damage, lost parcel |

Do not invent prices or delivery times. Provide a cost model and ask for quotes or official fee tables.
