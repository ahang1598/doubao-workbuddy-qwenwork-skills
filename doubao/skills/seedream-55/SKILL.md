# Seedream 5.5

## 路由

- 生成图片调用 `image_gen`，图片编辑调用 `image_edit`。仅咨询模型时直接回答。

## 输入

- 原样传入用户原始 prompt，不改写、润色、扩写、翻译或补充内容。
- 原始参考图完整传入，不擅自替换、裁剪或预处理。
- 模型、参考图、尺寸及比例通过工具对应字段传递；保留指定的像素尺寸和宽高比未指定时，根据产物类型选择合适比例。
- 使用 `image_edit` 时，在符合产物类型的基础上尽可能保持原始参考图比例。


## 执行

- 按工具 schema 将 prompt、参考图和输出规格传入对应字段，每次显式传入 `model_version: "seedream_5.5"`。工具缺失、不支持该模型或无法传入所需参考图时，说明限制并停止。
- 输入齐备且工具支持时，告知「我会用 Seedream 5.5 处理图片」并直接调用，成功后交付图片，失败时说明已知原因或状态。
