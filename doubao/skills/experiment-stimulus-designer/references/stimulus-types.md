<a id="type-a"></a>
## 类型A：情境阅读法（Vignettes / Scenarios）

最常用的刺激形式，通过让被试阅读一段故事、新闻报道或对话来代入情境。

### 适用研究场景
- 态度改变 / 说服效果
- 刻板印象与偏见
- 领导风格 / 组织行为
- 道德判断
- 风险感知
- 人际信任
- 健康传播

### 设计步骤

1. **基线先行**：先写出中立的控制组故事骨架，包含所有背景信息（人物、场景、时间、事件起因）
2. **关键词替换**：在骨架上仅替换核心操纵部分，其余一字不改
3. **避免情绪溢出**：除非研究情绪本身，否则描述保持客观中立，避免强烈情感形容词
4. **字数对齐**：不同条件版本字数差异控制在5%以内

### 结构模板

```
[共用背景段]（所有条件完全一致）
交代人物身份、场景设定、事件背景，让被试代入角色。

[操纵段]（仅替换核心句）
通过人物的具体行为、语言或决策来体现自变量水平。
注意：用“做了什么/说了什么”来体现，不要直接写“他是一个XX的人”。

[收尾段]（所有条件完全一致）
提出需要被试回应的情境或问题，自然衔接到因变量测量。
```

### 关键注意事项
- 人物姓名、性别、年龄等信息在各组保持一致（除非这些本身是操纵变量）
- 操纵段的句式结构在各组保持对齐（如都用直接引语、都用间接描述）
- 避免在某一条件中加入额外的背景细节或论据
- 新闻类Vignette要模仿真实媒体格式（标题、日期、消息来源）

### 示例
参见 [领导风格案例](leadership-style-example.md) 和 [低碳饮食案例](low-carb-diet-example.md)。

<a id="type-b"></a>
## 类型B：视觉/多媒体刺激（Visuals / UI / Ads）

通过图片、网页截图、短视频、UI界面等视觉材料进行操纵。

### 适用研究场景
- 营销广告效果
- 人机交互（头像、界面、反馈方式）
- 品牌印象
- 视觉刻板印象
- 产品包装与购买意愿
- 社交媒体内容效果

### 设计规范

1. **基础参数完全一致**：
   - 图片尺寸、分辨率、文件格式
   - 色彩饱和度、亮度、对比度
   - 构图方式、留白比例
2. **操纵元素控制**：
   - 操纵的元素（如环保标签、头像性别、按钮颜色）处于视觉中心或易察觉位置
   - 操纵元素要自然融入，不能突兀到像P上去的假图
   - 非操纵元素（背景、其他文字、装饰）完全一致
3. **人物照片控制**：
   - 如使用人脸照片，需控制吸引力、表情、姿势、光线
   - 最好使用同一张照片做局部修改，或使用经过预测试的标准化照片库
4. **视频刺激控制**：
   - 时长精确一致（误差<0.5秒）
   - 背景音乐、音量、旁白音色保持一致
   - 镜头节奏、剪辑方式保持一致
   - 仅替换需要操纵的画面/台词

### 关键注意事项
- 制作完成后做“肉眼盲测”：并列快速扫视不同条件，记录除操纵点外的其他显眼差异
- 图片中的文字内容也遵循最小差异原则
- 考虑不同设备的显示效果，尽量使用通用格式并在目标设备预测试
- 不能直接制作媒体成品时，输出参数表和验收标准，不声称文件已经生成或检查通过

<a id="type-c"></a>
## 类型C：回忆与行为唤起（Recall / Behavioral Tasks）

不给现成材料，让被试从记忆中提取或完成特定任务，从而唤起某种心理状态。

### 适用研究场景
- 权力感（高/低权力）
- 社会排斥 / 归属感
- 死亡焦虑 / 恐惧管理
- 情绪唤起（积极/消极情绪）
- 自我肯定
- 怀旧感
- 控制感

### 设计规范

1. **指导语给出明确的字数或时间要求**：
   - 例：“请回忆并写下一次你拥有权力并控制他人的经历，请至少写出50个字，详细描述你当时的感受和发生的事情。”
   - 字数要求用于促进投入，但不能替代注意力和理解检查
2. **控制组做消耗同等认知资源的中性任务**：
   - 错误：控制组什么都不写，直接进入下一步
   - 正确：控制组写中性事件，例如昨天去超市购物的流程
   - 中性任务的字数要求、写作时长与实验组一致
3. **指导语格式对齐**：
   - 两组指导语的字数、句式、要求格式保持一致
   - 仅替换核心的“回忆什么”部分

### 常见操纵参考

| 自变量 | 实验组任务 | 控制组中性任务 |
|--------|-----------|--------------|
| 权力感 | 回忆控制他人的经历 | 回忆昨天的日常活动 |
| 社会排斥 | 回忆被排斥的经历 | 回忆昨天吃了什么 |
| 死亡焦虑 | 想象自己死亡的过程 | 想象看牙医的过程 |
| 积极情绪 | 回忆开心的事情 | 回忆中性的日常事件 |
| 自我肯定 | 写下自己最重要的价值观 | 写下中性物品的特征 |

### 关键注意事项
- 写作任务后加入与目标状态对应的操纵检验
- 回忆任务的效果可能随时间消退，因变量测量时序应在设计中明确
- 负面情绪、排斥、死亡或创伤主题采用最低必要强度，并配置跳过、退出、事后安抚和支持资源
- 涉及脆弱群体或高风险主题时先走机构伦理审查，不能用本指南替代审批
