# 01 · 知识库与信息时效

> 通用层 reference，几乎每个案例都需读取。负责：说明商家知识库的重要性与建议结构、知识库状态规则、知识冲突处理、动态信息时效、联网检索边界与来源优先级。

## 一、知识库的定位

Skill 应明确建议商家提供自己的知识库。知识库不是普通补充材料，而是：

> 生成准确策略、贴合品牌回复、正确权限判断和动态客服规则的**主要依据**。

## 二、建议的商家知识库结构

| 分类 | 建议包含 |
|---|---|
| 品牌信息 | 品牌定位、客服称呼、品牌语气、推荐用词、禁用词、道歉与承诺规则 |
| 商品信息 | 名称、型号、规格、尺寸、颜色、材质、成分、功能、使用方法、包装清单、配件 |
| 适用与限制 | 适用/不适用人群、使用/不适用场景、兼容型号、注意事项、禁忌、常见误用 |
| 证明材料 | 商品详情页、参数表、说明书、检测报告、认证信息、可公开引用的事实 |
| 交易信息 | 库存、预售、发货时效、价格、活动、优惠券、叠加规则 |
| 售后信息 | 退换货条件、运费承担、质量问题认定、补发规则、退款规则、补偿权限、升级权限 |
| 客服经验 | 高频问题、标准答案、历史投诉、易误解的商品描述、已确认统一口径 |
| 维护信息 | 适用平台、适用店铺、负责人、更新时间、版本号、有效期 |

## 三、知识库状态规则（核心）

### 完整
- 直接使用真实商品、品牌、规则、权限信息；
- 输出**无占位符、可直接发送**的完整内容；
- **不得再次询问使用者已经提供的信息**；
- 不得退化为泛泛模板话术。

### 部分缺失
- 已确认内容直接写入；
- **只对确实缺失的字段**使用占位符；
- 明确说明缺失项会影响什么判断。

### 完全缺失
- 允许使用占位符；
- 但仍需给出**安全初稿 + 通用策略 + 待补充清单**；
- 不能只给一个空模板。

### 冲突
- 明确展示冲突；
- 不得自行选择对商家更有利的信息；
- 提供临时承接回复；
- 列出需要核实什么；
- 核实前不得作确定承诺。

### 过期风险
库存、价格、活动、发货时效等动态信息，任一项缺少更新时间、有效期、适用平台、适用商品/SKU 或规则版本时，标为过期风险，按待核实处理。

## 四、统一占位符格式

```
【商品名称】【商品型号】【客户关注点】【已确认参数】【适用场景】
【限制条件】【优惠信息】【处理时限】【客服权限】
```

**禁止混用**：XXX、下划线、小括号、随意符号。占位符必须使用上述【】格式，便于使用者一眼识别待补项。

## 五、知识冲突处理

知识库内容冲突时：
- **明确指出冲突**；
- **不得自行选择对商家更有利的信息**；
- 提供临时承接回复；
- 说明需要核实什么；
- 核实前不得作确定承诺。

## 六、动态信息时效检查

库存、价格、活动、发货时效等动态信息，使用前必须检查：
- 更新时间
- 有效期
- 适用平台
- 适用商品或 SKU
- 规则版本

任一项过期或不明 → 标为"过期风险"，按"待核实"处理，给临时回复，不做确定承诺。

## 七、联网检索边界

### 必须联网检索
- 最新平台规则；
- 现行法律法规与监管要求；
- 用户明确提到的网络舆情事件；
- 品牌或平台的最新正式说明；
- 可能已发生变化的政策或规则。

### 禁止用网络搜索替代（只能来自使用者/知识库/内部系统）
- 店铺实时库存；
- 真实订单状态；
- 店内价格权限；
- 商家赔偿额度；
- 未公开的品牌统一口径；
- 客服实际审批权限。

> 外部自媒体或网络传言**不能**作为品牌统一口径。

## 八、来源优先级（统一）

1. 使用者本轮明确提供的最新信息
2. 商家当前有效知识库与统一口径
3. 订单、库存、物流等内部系统记录
4. 平台官方最新规则
5. 官方法律法规或监管资料
6. 权威行业资料
7. 通用客服实践
