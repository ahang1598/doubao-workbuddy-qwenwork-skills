## 一、使用方法

先确定一个主类型，再选择最多一个辅助类型。日历以主类型的内容支柱为骨架，辅助类型只增加角度，不把账号做成“什么都发”。

## 二、十类账号策略

### 1. 新闻资讯与热点评论

- 核心需求：发生了什么、为什么重要、接下来怎样。
- 支柱：事实进展、时间线、机制解释、影响人群、后续追踪。
- 重点节点：两会、重要政策窗口、重大公共议题、年度数据发布、国际事件。
- 适合形式：快讯、事实卡、问答、深度复盘、年度回看。
- 标题重点：新进展 + 影响；避免“刚刚”“炸了”替代事实。
- 禁区：抢跑、传谣、用问号定罪、消费灾难。

### 2. 知识科普与专业解读

- 核心需求：把复杂问题讲明白并能使用。
- 支柱：概念、机制、误区、方法、案例、趋势。
- 重点节点：专业主题日、重要报告、行业大会、季节性问题。
- 适合形式：图解、FAQ、实验、清单、案例拆解。
- 标题重点：具体问题 + 可验证收益。
- 禁区：伪权威、把相关性写成因果、万能结论。

### 3. 职场商业与财经

- 核心需求：决策、效率、职业发展、行业判断。
- 支柱：求职、沟通、管理、工具、商业案例、数据趋势。
- 重点节点：招聘季、毕业季、财报季、预算季、年中/年终复盘、劳动节。
- 适合形式：决策框架、模板、案例、趋势报告。
- 标题重点：人群 + 场景 + 代价/收益。
- 禁区：保证升职发财、虚构内幕、无资质投资建议。

### 4. 文化读书与人文历史

- 核心需求：理解作品、人物、时代与当下。
- 支柱：书影解读、人物、历史节点、文化现象、阅读方法。
- 重点节点：世界读书日、文化遗产日、作者诞辰/忌辰、开学季、年度书单季。
- 适合形式：书单、文本细读、人物小传、主题策展。
- 标题重点：熟悉作品 + 新问题/新细节。
- 禁区：伪造引语、杜撰史实、只有鸡汤没有文本。

### 5. 情感成长与心理

- 核心需求：被理解、看见关系模式、获得可行改变。
- 支柱：自我、亲密关系、家庭、友谊、情绪、人生阶段。
- 重点节点：情人节、妇女节、母亲节、父亲节、毕业季、七夕、春节返乡、世界精神卫生日。
- 适合形式：场景文章、读者来信、心理机制、练习清单。
- 标题重点：精准命名情绪，不替读者下诊断。
- 禁区：廉价安慰、性别对立、把心理疾病当标签。

### 6. 生活方式与消费

- 核心需求：把日常生活过得更高效、舒适、有审美。
- 支柱：居住、穿搭、饮食、旅行、整理、消费决策。
- 重点节点：换季、长假、618、双11、开学、春节、梅雨/高温/供暖季。
- 适合形式：实测、对比、清单、路线、改造前后。
- 标题重点：真实场景 + 具体改善。
- 禁区：伪测评、隐性广告、制造消费焦虑。

### 7. 教育亲子与青年成长

- 核心需求：学习、陪伴、升学与发展选择。
- 支柱：学习方法、家庭沟通、校园适应、考试、职业启蒙。
- 重点节点：寒暑假、开学季、中高考、儿童节、教师节、毕业季。
- 适合形式：年龄分层指南、对话示范、案例、工具表。
- 标题重点：阶段 + 问题 + 可执行动作。
- 禁区：贩卖升学焦虑、绝对化育儿、泄露未成年人隐私。

### 8. 健康运动与医疗科普

- 核心需求：识别风险、建立习惯、理解就医信息。
- 支柱：症状边界、预防、运动、睡眠、营养、就医流程。
- 重点节点：世界睡眠日、世界卫生日、全民健身日、季节性疾病窗口、体检季。
- 适合形式：风险分层、问答、流程、专家核查。
- 标题重点：人群和条件明确，区分科普与诊断。
- 禁区：恐吓、替代诊疗、夸大疗效、无来源医学数字。

### 9. 品牌机构与企业文化

- 核心需求：理解品牌价值、产品背后的人与方法、机构可信度。
- 支柱：品牌故事、用户案例、专业能力、团队、社会责任、行业洞察。
- 重点节点：品牌周年、产品发布、行业日、招聘季、公益节点、客户场景旺季。
- 适合形式：幕后、案例、人物、方法论、年度报告。
- 标题重点：用户价值优先于品牌自夸。
- 禁区：假用户、假数据、借公共悲剧营销、把广告伪装成新闻。

### 10. 本地生活与城市文化

- 核心需求：在本地吃住行游、理解城市变化、建立归属感。
- 支柱：服务信息、路线、人物、街区、城市史、公共议题。
- 重点节点：本地节庆、花期/汛期/高温、交通变化、文旅旺季、城市纪念日。
- 适合形式：地图、清单、实地探访、口述史、服务指南。
- 标题重点：城市名 + 时间窗口 + 明确用途。
- 禁区：过期信息、未经核实的店铺状态、地域优越感或歧视。

## 三、复合账号处理

常见组合：

- 新闻 + 专业：热点说明发生了什么，专业能力解释为什么；
- 文化 + 情感：作品提供文本，情感提供当下连接；
- 职场 + 心理：场景问题为主，心理机制为辅；
- 本地 + 生活：服务价值为主，城市文化增加辨识度；
- 品牌 + 专业：用户问题为主，品牌案例只作证据。

复合后仍需保持一个稳定承诺。若某选题无法落入主账号的任一内容支柱，即使节点很热也应放弃。
