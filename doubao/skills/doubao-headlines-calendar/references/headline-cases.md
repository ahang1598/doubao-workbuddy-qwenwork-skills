## 一、经典标题案例

下面整理了一些过往的新媒体爆款标题。重点学习这些标题的技巧和表达优势，不机械照抄。

### 1. `她没有被确诊，却被判了死刑`

- 技法：医学词语跨域 + 生死反差 + 被动命运。
- 亮点：“没有/却”瞬间造出不公感。
- 迁移：`他没有做错什么，却失去了最后一次机会`
- 注意：原文必须支撑这种强烈命运判断。

### 2. `“决定离婚那晚，她发了1条朋友圈，收到29个未接来电”`

- 技法：关键时刻 + 私密动作 + 精确数字。
- 亮点：像电影预告，读者会追问朋友圈写了什么。
- 迁移：把抽象关系问题压成“那一晚的一件事”。

### 3. `半夜撞见老公上厕所，我泣不成声`

- 技法：日常动作与极端情绪反差。
- 亮点：常识无法解释，信息缺口极强。
- 风险：正文若只是普通温情故事，会有刻意煽情感。

### 4. `我33岁，凑够房子首付当天，住进了ICU`

- 技法：年龄 + 人生目标 + 当天反转 + 重大代价。
- 亮点：把赚钱与健康冲突推到峰值。
- 迁移：用“终于得到/立刻失去”的结构。

### 5. `果然，这对夫妻的恩爱，是假的……`

- 技法：情绪前置 + 价值反转 + 身份隐藏。
- 亮点：“果然”让读者自动脑补已有怀疑；短标题视觉强。
- 可替换词：终于、偏偏、难怪、可惜、原来。

### 6. `隐婚有娃，这个女明星骗了所有人！`

- 技法：两个高信息词并列 + 身份 + 强情绪动词。
- 亮点：人物知名度不足时，用身份和秘密撑点击。
- 当下改法：若“骗”不准确，可改为“瞒了这么多年”。

### 7. `谷爱凌的父母到底什么来头？`

- 技法：热点人物 + 家庭背景 + 直接问句。
- 亮点：从正面故事转向“背后的生成机制”。
- 迁移：热门人物被写遍后，挖父母、老师、搭档、转折点。

### 8. `果然，谷爱凌被美国人骂了……`

- 技法：热点 + 对立情绪 + 事件后续。
- 亮点：比重复成长史更有新角度。
- 风险：“美国人”范围过大；当下应尽量限定具体舆论来源。

### 9. `唐嫣：我为什么嫁给罗晋？`

- 技法：结果改写为选择逻辑 + 第一人称。
- 亮点：同样的婚讯内容，角度从“发生”变为“为什么”。
- 风险：不是本人自述时不要伪装第一人称，可改为“唐嫣为什么选择罗晋？”

### 10. `恭喜佟丽娅女士离婚`

- 技法：极短标题 + 价值反转 + 明确站队。
- 亮点：用庆祝词挑战“离婚等于失败”的默认叙事。
- 迁移：传统负面结果在具体处境中成为新开始。

### 11. `他被确诊，全网都在心疼！`

- 技法：结果前置 + 群体情绪 + 人物隐藏。
- 亮点：短、重、第一眼抓住同情。
- 当下改法：“全网”容易空泛，可用人物最痛的真实细节替代。

### 12. `雷佳音，好窝囊一男的！`

- 技法：人物 + 口语化人设判断 + 强烈语气。
- 亮点：“窝囊”比“没出息”更具体，更有角色画面。
- 核心：由轻到重不是找更大的词，而是找更贴人物的狠词。

### 13. `今晚，聊一聊孟晚舟和张艺谋`

- 技法：由繁到简 + 两个高识别人物并置。
- 亮点：比隐喻式原标题更直白，降低理解门槛。
- 风险：两个人必须都在正文承担重要功能。

### 14. `王力宏很渣！李靓蕾呢？`

- 技法：由隐到显 + 判断 + 反问。
- 亮点：直接给出人物与争议中心。
- 风险：涉及现实人物争议时需基于已证实事实，避免标题代替裁决。

### 15. `“在我的婚礼上，我是一个局外人”`

- 技法：第一人称 + 身份与处境错位。
- 亮点：婚礼主角却成局外人，反差天然成立。
- 迁移：找“本应属于我，却与我无关”的时刻。

### 16. `我在情感电台，见过10000种悲惨人生`

- 技法：职业身份 + 数字夸张 + 人生窥探。
- 亮点：建立权威和故事密度。
- 当下改法：数字若非真实统计，可写“见过太多种”。

### 17. `“养了13年的狗，我亲手把它送进火化炉”`

- 技法：时间积累 + 第一人称动作 + 告别终点。
- 亮点：不说“悲痛”，细节已经足够悲痛。
- 迁移：克制催泪优于“看哭所有人”。

### 18. `孟晚舟背后的男人，牛！`

- 技法：热点人物 + 关系人物 + 单字态度。
- 亮点：极短，痒点和爽点同时存在。
- 风险：“背后的男人/枕边人”已被滥用，需换成更具体关系或行动。

### 19. `4天39例，河北疫情蔓延，这个教训你千万要记住！`

- 技法：时间数字 + 事件进展 + 读者利益。
- 亮点：信息、风险、行动三段齐全。
- 风险：公共卫生内容必须以权威信息为准，不能为点击放大恐慌。

### 20. `吴孟达生前最后一条朋友圈曝光：人这辈子，最该明白这3个道理`

- 技法：名人离世 + 最后一次 + 私密信息 + 人生收益。
- 亮点：缅怀与普遍价值结合。
- 风险：容易消费逝者；引用和“最后一条”必须确证。

### 21. `我不敢看山西人的朋友圈`

- 技法：第一人称情绪 + 地域人群 + 朋友圈入口。
- 亮点：不直接讲灾情，用“不敢看”留出画面。
- 风险：灾难语境中正文必须有事实和帮助，不只煽情。

### 22. `李云迪的悲剧，从18岁那年就注定了`

- 技法：热点事件 + 人生回溯 + 宿命感。
- 亮点：避开事件表层，从成长史切入。
- 当下改法：`李云迪18岁之后，人生怎样一步步偏离高光时刻？`，减少武断因果。

## 二、当下高传播标题趋势与案例

当下的变化不是“标题不再刺激”，而是读者更能识别旧套路。有效方向是更具体的情绪、更像真人的口语、更强的反套路和更贴身的数据。

### 1. 具体情绪代替宏大鸡汤

弱：`愿你成为更好的自己`

强：`下班后连消息都不想回的人，不是冷漠，是今天已经用完了自己`

核心：把“成长、治愈、焦虑”落到一个当下动作。

### 2. 幽默解构焦虑

弱：`年轻人的职场压力有多大`

强：`班是上完了，人也差不多用完了`

核心：用轻口语承载重处境，读者更愿意转发自我表达。

### 3. 反套路自曝

弱：`我是如何做到自律的`

强：`我终于不自律了，生活反而开始正常`

核心：先推翻内容赛道里的标准答案，再给新解释。

### 4. 数据人格化

弱：`我的年度消费总结`

强：`外卖软件替我记住了这一年：我有73顿饭是在晚上10点后吃的`

核心：把用户数据变成个人故事，兼具具体、隐私感和分享欲。

### 5. AI时代的人味反差

弱：`AI对写作行业的影响`

强：`AI一天能写100篇文章，我却开始珍惜一句有毛边的话`

核心：技术效率与人的稀缺价值并置。

### 6. “没用但真实”的反绩效叙事

弱：`如何提高休息效率`

强：`这个周末，我决定做一点完全没用的事`

核心：反抗万事都要有产出的疲惫，适合生活与情绪内容。

### 7. 具体身份 + 具体困境

弱：`中年人的失业焦虑`

强：`被裁第42天，我最怕的不是没工作，是每天假装去上班`

核心：身份、时间、动作和隐秘心理同时出现。

### 8. 小事升级为时代切片

弱：`年轻人为什么不爱逛商场了`

强：`周末的商场挤满了人，年轻人却只在里面吹空调`

核心：一帧现场 + 一个反常行为，正文再解释消费变化。

### 9. 强口语判断

弱：`过度精致生活值得反思`

强：`家可以乱一点，人别先累坏了`

核心：像朋友一锤定音，不像论文下定义。

### 10. 新鲜概念命名

弱：`为什么休假后仍然疲惫`

强：`你休的可能不是假，是“换个地方继续待命”`

核心：为熟悉痛苦起一个新名字，让读者获得表达工具。

### 11. 低粉爆款反向研究

不只盯大号。低粉账号突然出现高互动内容，通常更能说明选题、标题或情绪确实击中了人。建立每周样本：原标题、粉丝量级、互动倍数、机制、可迁移角度。

### 12. 推荐流标题的前半句竞争

在信息流卡片里，前12—16字承担大部分识别任务。把人物、冲突或痛点前置，不把“真正的原因是”藏到截断之后。

## 三、改题实战

### 1. 由轻到重

- 原：`为什么我总觉得工作很累？`
- 改：`班还没上完，我已经被工作榨干了`
- 再改：`班是上完了，人也差不多用完了`

第三版更口语、更意外，也更适合转发。

### 2. 由泛到细

- 原：`成年人的友情越来越淡`
- 改：`我们没有绝交，只是半年没再点开彼此的对话框`

用一个动作替代大判断。

### 3. 由繁到简

- 原：`在快速变化的时代背景下，我们应该如何重新理解稳定的意义`
- 改：`所谓稳定，可能只是风险还没轮到你`

从论文句改成可争论的判断。

### 4. 由隐到显

- 原：`这件事，终于瞒不住了`
- 改：`年轻人开始集体关掉朋友圈，原因不只是隐私`

交代主题，保留原因。

### 5. 由大到小

- 原：`数字时代的老年人困境`
- 改：`父亲第一次独自挂号，在机器前站了17分钟`

细节自动带出时代问题。

### 6. 由正确到惊喜

- 原：`要学会接受不完美的自己`
- 改：`我不想变得更好了，我想先变得像个人`

允许强态度，只要正文能承接。

### 7. 由知识到损失

- 原：`如何正确准备面试`
- 改：`面试前背熟答案的人，最容易死在第一个追问里`

把方法题变成风险题，点击更强。

### 8. 由热点复述到角度翻新

- 原：`某热门人物夺冠背后的成长故事`
- 改：`所有人都在谈她的天赋，我更想知道她输掉的那几年`

别人写高光，就写低谷；别人写主角，就写幕后。

### 9. 由节日祝福到刺痛问题

- 原：`母亲节，感谢伟大的母亲`
- 改：`做了母亲以后，她为什么越来越少说“我想要”？`

节日不是祝福模板，而是观察入口。

### 10. 由品牌自夸到用户利益

- 原：`我们推出了全新的会员体系`
- 改：`会员规则终于能看懂了：这次我们砍掉了17个选项`

用变化和减法展示品牌价值。

## 四、同题多写

素材：一位工作五年的年轻人决定从大厂离职，回到小城开修理铺。

### 信息型

`离开大厂回县城后，他开了一家只修旧东西的店`

### 数字型

`月薪3万到一天3单，他说自己终于敢睡整觉了`

### 反差型

`他从大厂“逃”回县城，却第一次觉得人生没有掉队`

### 痛点型

`高薪工作最贵的成本，他辞职后才算明白`

### 爽点型

`辞掉所有人羡慕的工作，他终于不用证明自己了`

### 细节型

`离职那天，他把工牌放进抽屉，买了一张回县城的票`

### 强观点型

`真正的上岸，不是进大厂，是不再害怕重新开始`

### 口语型

`钱少了一半，他反而活得像个人了`

### 短标题

`我从大厂逃回县城`

同一素材至少写出五个方向，再决定账号最适合哪一刀。

## 五、案例迁移规则

1. 抄结构，不抄名词；学“年龄反差”，不是每篇都写“27岁/35岁”。
2. 抄情绪机制，不抄情绪词；找到素材自己的“心疼、荒诞或痛快”。
3. 爆款标题换人名后仍成立，说明套路太重；加入独有细节后才属于这篇文章。
4. 每个标题只选一个最大爆点，别把热点、数字、反转、清单、金句全部挤在一起。
5. 先大胆写到120分，再把事实风险修回100分；不要从60分的“正确标题”开始自缚手脚。
6. 允许口语、断句、感叹号、引号和省略号，但标点必须制造节奏，不负责制造内容。
7. 经典案例随时间折旧。每月补充近30天同赛道高传播标题，淘汰读者已免疫的陈词。
