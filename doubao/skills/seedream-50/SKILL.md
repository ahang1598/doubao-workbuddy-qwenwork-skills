## 用途

- 选择5.0_flash模型进行生图时读取，明确生图prompt的改写和组装规则。
- 需搭配各产物 reference 的平台特征、风格调性、尺寸、安全区、品类结构、视觉风格和合规红线共同完成改写和组装。
- 除规定 Prompt 改写方式外，还强制规定 5.0_flash 的模型参数与 Skill 接力：完成本 Skill 后必须调用 `doubao-creative-design` Skill，再由它调用实际图片工具；保留 `image_gen`、`image_edit`、`prompt`、`ratio` 和参考图入参，并在每次实际工具调用中额外显式传入 `modelversion: "seedream_5.0_flashpro"`。
- 最终 SP 是一段精简自然语言。`ratio` 单独作为工具参数传入。

## 接力前提

- 不得脱离产物 / 场景特征 reference 单独使用。
- 先完成产物路由；命中具体产物时，先读取对应产物 reference，提取产物结构、风格调性、平台画幅与安全区、信息层级、系列图、核心资产和合规要求，未命中具体产物时，使用主 `SKILL.md` 的通用产物规则作为底稿。


## 强制调用策略

1. 使用本 5.0_flash Skill ，必须把任务交接给 `doubao-creative-design` Skill；由该 Skill 调用实际图片工具时，显式传入精确参数 `modelversion: "seedream_5.0_flashpro"`，不得省略、改写、降级或依赖宿主默认值。
2. `modelversion` 是独立工具参数，不得写入最终 SP 或 Prompt。
3.必须继续调用 `doubao-creative-design` Skill；不得只返回 Prompt、规划或参数草案后结束。
4. `doubao-creative-design` 是后续 Skill，不是生图工具。向该 Skill 传递最终 Prompt、`ratio`、参考图信息以及固定的 `modelversion` 要求，由它按实际 T2I / I2I 路径完成图片工具调用。
5. 若无法调用 `doubao-creative-design` Skill，或实际图片工具的参数结构无法传入 `modelversion`，立即说明能力缺口；不得跳过 Skill 接力、省略参数、切换其他模型或声称已经执行。

### 选择规则

1. I2I 默认延续参考图空间骨架、主体位置和主次关系；用户有创作、重排、改版或重构需求时更新布局。
2. 单一核心主体优先选非对称主视觉、字图咬合、环形围合或电影纵深；多模块信息优先选编辑网格；流程、地图和教程优先选路径叙事。
3. 百分比分区用于专题页、详情页、规则页及产物 ref 已给出物理版式锚点的标准传播物料；艺术海报、纯摄影和实验封面使用主体关系、尺度对比和视觉动线表达。
4. 社媒封面的大标题位于首屏强阅读区，并具备手机缩略图识别度；摄影和 3D 场景按需加入景别、视角与前中后景。
5. 主原型需要增强内容特征时，叠加一个微型结构：长场景用 S 形路径引导，单主体用三分焦点承接留白，空间场景用门窗、植物或前景物形成框景，多商品或重复元素用一处尺度、颜色或朝向变化建立记忆点。
6. 产物 ref 已给出明确构图惯例时优先沿用；小红书照片型内容先根据照片角色和叙事目标，从主图卫星、编辑式非对称网格、胶片接触印样、电影分镜条、满版场景细节窗、物件标本板、对比联图或叙事拼贴中选择；单商品电商图优先非对称主视觉，多商品优先满版阵列，地图和教程优先路径叙事，书封与展览海报可选压角留白，场景摄影可选框架画中画，大促活动按内容选择向心爆发或对角线动势。

### 灵动动作

每张图选一个：超大标题、偏轴主体、局部越格、字图叠压、尺度突变、弧形路径、大片留白、非核心装饰出画。通过一个高密度区对应一个呼吸区、一组大中小尺度差和一个明确动势形成设计节奏。

装饰从主题语义提取：玩水发展水流轨迹与折射泡泡，登岛发展路线与印章，科技发展光带与界面节点。PE 围绕主题发展一个最适合当前画面的构图亮点，使画面具有辨识度和稳定重心。除非是 UI、网页设计等需要高度统一视觉语言的场景（此时要保证容器和装饰的统一性），其余情况装饰仅作为点缀时必须克制使用，并在一张图中保证其形态的多样性，严禁机械重复同质化的装饰符号（如满屏的同款气泡、同款贴纸或光斑），根据平台和赛道合理安排画面的留白与呼吸感，拒绝无意义的元素堆砌。

为减弱机械模板感，每张图按风格选择一处轻量人工痕迹：手账与拼贴使用微旋、折边、贴纸翘角或不等距排列；印刷与波普使用套色偏差、网点或印章轻微错位；摄影使用颗粒、轻微漏光或前景虚化；手绘使用线条轻颤、描边变化或色块毛边。核心文字、品牌和主体保持清晰稳定。**注意：轻量人工痕迹仅作为局部点缀，绝不允许导致画面布满密集的同质化便签或贴纸。**

每张图至少写清一组具体前后或叠压关系，明确哪个元素在前、哪个元素在后以及它如何连接阅读动线；拼贴、字图咬合和电影纵深可使用两组，极简、Logo 与纯产品主图保持一组即可。

### 结构型主视觉与组件家族

- 引导 PE 将主题母题发展成一个组织画面的结构，可承担主体舞台、视觉路径、信息容器或前后空间中的一种或多种功能。例如泡沫堆承载人物和信息卡，岛屿路线串联地图节点，建筑透视引导标题排布。
- 同类信息形成组件家族：相同角色在底层逻辑上保持一致，但具体容器间相互可以有颜色、形态、材质或倾斜角度的差异，保持画面的灵活与呼吸感（注意：绝不能机械地将所有小字说明全装进同质化、等比例的半透明底板或便签中）；主标题、节点标签、说明卡和行动信息彼此有明确层级差异。
- 引导 PE 让材质与对象自然对应，优先写清最影响画面识别的标题、主体或信息容器材质，并用一致的光影和空间气氛完成衔接。

## 文字与信息补全

### 默认路由

- **按需扩写文字**：海报、KV、小红书封面、专题页、落地页、宣传页、活动页、电商传播图、信息图、品牌应用及其他传播型平面设计，根据内容目标、画面信息量和用户已提供文案决定扩写程度。
- **纯视觉表达**：纯插画、壁纸、头像、场景图、概念视觉、无字产品图，以及用户明确要求纯画面或无字的任务。
- **I2I**：先延续参考图已确认的核心文字，再根据目标产物执行对应路由。

传播型任务先保留用户提供的核心文字，再按画面需要选择以下信息层级；当现有文案不足以支撑画面时，必须把开放引导写入最终 SP，交给 PE 自然补全：

| 产物 | 文案角色链 |
|---|---|
| 海报 / KV | 品牌或栏目 → 主标题 → 副标题 → 内容亮点 → 活动信息 → 参与引导 |
| 小红书封面 | 主标题 → 可选内容钩子 → 可选主题或细节注释 |
| 专题页 / 落地页 | Hero 标题 → 价值说明 → 栏目标题 → 模块标签 → 行动按钮 → 底部收束 |
| 宣传页 / 活动页 | 活动标题 → 主题说明 → 玩法栏目 → 规则摘要 → 活动信息 → 参与引导 |
| 电商传播图 | 活动主题 → 商品价值 → 核心卖点 → 优惠事实 → 行动引导 |

通用引导句：`根据画面自动扩写合适的文案，围绕“{主题}”面向{受众}采用{语气}表达，可发展{当前画面需要的文案角色}，并沿{构图动线或版面区域}自然融入主视觉。`

### 场景自适应文案

| 产物 | PE 文案预算 |
|---|---|
| 普通海报 / KV | 1 个副标题、2–4 个短标签、1–2 条说明、1 个行动引导 |
| 社媒封面 | 0–1 个内容钩子、0–2 个主题或细节注释；信息型封面可按画面需要增加层级，小红书注重杂志感 |
| 地图 / 攻略 | 每个已确认节点 1 个短标签，另配 1–2 个说明卡 |
| 教程 / 步骤图 | 每一步 1 个编号与步骤标题，另配 1 条总结 |
| 专题页 / 详情页 | 每个模块 1 个栏目标题与 1 条说明 |
| 电商传播图 | 2–4 个真实卖点、用户提供的优惠事实、1 个行动引导 |

中文副标题约 8–16 字，短标签约 2–8 字，单条说明约 10–24 字；节点、步骤和模块数量由真实内容结构决定。PE 扩写完成后，把所有可见文案转成带引号的真实可渲染文字，不把“副标题”“标签”“说明”等角色名称交给生图模型。

### 信息块与物理落点

- Skill 为每组信息确定内容角色、相对位置、视觉重量、字体类别及其与主视觉的关系，PE 在该关系内完成具体文案和排版细化。当需要图文并茂时，必须合理安排文字和图片各自的体积占比，避免单一方过度挤压画面空间。
- 日期与时间、地点、利益信息、玩法说明、行动引导分别形成语义块；同组信息紧密关联，组间以更大的间距、色块或方向变化建立层级。
- 核心文字采用清晰可读的主标题与正文系统；PE 可将非事实性的主题短词、编号或符号发展为小型图形文字，用于节奏、路径和边缘细节。当存在多个标签或说明时，**严禁机械地为每一条文字套上同质化的“半透明矩形底框”、“拼贴便签”或“气泡框”**。除非是 UI 界面、网页设计等需要高度统一视觉语言的场景（此时应保证使用统一的容器），其余情况文字排版应优先依靠字号对比、字重变化或极简分割线来划分层级。若必须使用容器底板作为画面点缀，必须克制使用，并在一张图中保证其形态的多样性与大小错落（容器间相互可以有颜色、形态、材质、倾斜角度等明显差异），**彻底杜绝满屏皆是同等体量、密密麻麻的半透明矩形框或便签碎片的现象（如几十张同款手写便签贴满屏幕）**。
- 主标题统一使用与主题匹配的创意字体；具体字形、字重、描边、立体感及字图关系由 PE 根据风格和构图自行规划，辅助文字保持清晰可读。
- 主标题是最大文字，通常占画面宽度约 45%–75%；副标题紧邻或承托主标题，字号约为主标题的 35%–55%；小型图形文字使用 1–3 处，字号约为主标题的 15%–25%。
- 非对称主视觉让标题与主体分居主轴两侧，次级信息在标题同侧下方；分栏版式让主副标题同组落在文字主区，CTA 在底部收束；字体主视觉让标题占主要画面高度，其他文字在边角或底部收束。
- 向心爆发让标题或利益点位于中心，卖点沿放射方向分层，日期与落款置于外围；错落拼贴与满版阵列让信息围绕主标题成组，保持一个稳定阅读起点。
- 路径叙事与编辑网格让节点、栏目按路径或网格依次展开，说明卡落在路径终点或独立信息区；压角留白让次级信息沿角部重心展开；框架画中画与电影纵深让文字落在框外或清晰景深层。

### 杂志质感叠加

杂志质感可叠加到摄影、人物、商品、拼贴和品牌传播任务，不等同于固定网格模板。可引导 PE 根据画面内容从摄影裁切、跨栏图像、印刷颗粒、纸面触感、页码、导视细线、栏目小字或大面积留白中选择少量有效锚点，并让它们与主风格、结构型主视觉和信息组件自然统一。

### 事实与文字边界

- 品牌、主标题、日期、数字、价格、地点、专名、型号和活动名称逐字取自用户或已确认资产，并用对应语言的引号标记。
- 日期、价格、折扣、销量、功效、认证、排名和监管信息只使用核心事实锚点；PE 扩写副标题、栏目名、主题短句、卖点表达、规则摘要、标签和行动引导。
- 文案扩写只发展表达形式，不扩展事实内容；缺少事实数据时，以非事实性的主题表达、体验描述和行动引导完成层级。
- 任务类型、平台名、用途说明、风格名称和主体描述作为设计指令；用户明确指定为可见文案时纳入核心事实。
- 纯视觉任务以图形、色彩、材质和空间关系承载信息。


## 画面完成度
