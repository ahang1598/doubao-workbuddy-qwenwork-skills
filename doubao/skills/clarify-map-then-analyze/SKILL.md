# Clarify, Map, Then Analyze

先冻结交付目标和计算口径，再定位可追溯来源、建立字段映射并执行分析。未通过前置闸门时只交付问题清单或带假设的预览，不给确定性最终结论。

## 流程

### 1. 冻结交付目标

1. 确认目的、受众、输出载体、表头、粒度、时间范围和是否需要可复算明细。
2. 把用户点名的对象原样写入交付契约。例如配方排名只纳入 `成型收缩率/%`、`拉伸强度/MPa`、`弯曲强度/MPa`、`弯曲模量/MPa`、`冲击强度/(kJ/m²)` 时，不得自行恢复课程文件中的 `热处理尺寸变化率` 或 `翘曲率`。
3. 对产线定额表，先确认是否按 `冲压`、`胀管`、`产线（8条）`、`包装线`、`装加热丝线` 五段交付；不要把“产线”误当成全部五段的统称。

### 2. 锁定口径、权重与边界

1. 建立口径表：指标方向、公式、单位、权重、过滤条件、分组键、时间字段和例外；缺项标为“待确认”或“假设”，不可暗补。
2. 配方评分中，`成型收缩率` 是成本型，使用 `(Xmax-X)/(Xmax-Xmin)`；`拉伸强度`、`弯曲强度`、`弯曲模量`、`冲击强度` 是效益型，使用 `(X-Xmin)/(Xmax-Xmin)`。`Xmax`、`Xmin` 必须取同一批 25 个配方，而不是外部历史范围；五项权重未给定时先列待确认，不默认等权。
3. 长度方向成型收缩率按 `(模具型腔长度-放置12 h后样条长度)/模具型腔长度×100%`，标准弯曲样条的模具型腔长度取 `80 mm`；不得用“初始样条长度”替代 `80 mm`。
4. 正交极差分析以各水平的指标均值为 `K1/K2/K3`，`R=max(K)-min(K)`；成本型指标取均值最小的水平，效益型取均值最大的水平。若 `B压力` 与 `C冷却` 在试验表中同步变化，应报告二者混杂，不能把相同 `R` 解释成独立效应。

### 3. 定位权威来源与版本

1. 为每个目标字段记录来源文件、工作表或图片、版本日期、读取时间与选用理由；本地附件可读时先读本地文件，在线协作文档则在每次使用前重读当前修订。
2. 五段定额的冲压、胀管明细应回到 `26.3.25批量产品定额.xls` 的 18 个 Sheet；`batch_5seg.json` 是已解析中间结果，必须与原始 Sheet 的 `工段`、`生产工序`、`单班工序定员`、`10小时单班执行产量`、`生产工序节拍（秒/台）` 抽样回查后使用。
3. 多版本冲突时按“用户明确指定版本 > 当前协作文档修订 > 可追溯的最新时间戳”选择，并列出被排除版本。伺服数据配对按 CSV 时间戳寻找最近的参数 `xls`，同时输出时间差；“最近”不等于“正确”，超出用户确认窗口时保留为待确认匹配。
4. 计算口径以原始明细为准；已有汇总结果仅作交叉校验。两者不一致时重算明细并报告差异及可能滞后原因。

### 4. 建立目标字段到来源字段的映射

1. 输出映射表：`目标字段 | 来源文件/Sheet | 来源字段 | 转换/单位 | 匹配键 | 缺口 | 置信度`，先解决一对多、多对一和单位换算，再批处理。
2. BOM 合并以规格兼容为前提：相同物料合并时累加 `用量`、合并 `位号`，已有 `料号` 原样保留；不能仅凭名称相似合并。电解电容至少核对 `容量`、`误差`、`封装`、`耐压值`，其中 `D8xL10.5mm` 与其他尺寸不是同一封装，`10V` 与 `16V` 的差异必须显式列出。
3. 对 `3.17.05.0018`，来源库规格为 `贴片电解电容,1000uF,±20%,D8xL10.5mm,10V`；若客户 BOM 写 `16V`，只能标为冲突并请求确认是否接受降额，不能因为料号存在就宣称完全匹配，也不能同时写“复用该料号”和“需新建16V料号”。
4. 生产履历映射要把 `ArriveLot`、`MountExpand` 等事件别名先归一到进出站语义；空设备的 `TrackOut` 必须依据前后事件补全且保留补全标记。设备、批次和事件时间不足以唯一配对时，不强行全量匹配。

### 5. 批量读取、清洗并执行分析

1. 先检查工作表数、表头行、单位、类型、空值、重复键、异常值、版本时间与公式单元格，再运行抽取、比对、归一化、排序或统计。
2. 配方表的 25 行须用实验编号保持唯一；评分前报告五项指标的非空数，遇到 `Xmax=Xmin` 时停止该指标归一化并请求规则，禁止用除零结果或私设满分。综合分仅在权重和指标方向已锁定后计算，排序应保留原始值、单项分、权重、总分与并列规则。
3. 五段工序分类按证据规则执行：`冲片/打片` 归 `冲压`；`下料/折U/胀管摆片` 归 `胀管`；`折弯、水试漏、氩弧焊` 归 `产线`；`钝化、包装、测压装箱` 归 `包装`；`装加热丝` 归 `加热丝`。未命中的 `生产工序` 单列，不猜分类。
4. BOM 差异比对至少输出 `客户BOM值`、`料号库值`、`候选匹配值` 和 `结论`；任何容量、阻值、封装或耐压差异都进入差异项，而不是被文本相似度覆盖。

### 6. 复核并形成可追溯交付

1. 对计算结果做独立回算：随机抽取至少 3 行核对来源值、转换和公式；排名核对总分降序及并列处理；合并核对合并前后 `用量` 总和不变、`位号` 不丢失不重复。
2. 输出分为“事实、推断、建议、待确认”四块。事实必须带来源和版本；推断写依据与置信度；建议写适用条件；缺失的权重、工况或专业规则进入待确认项。
3. 极差表应保留 `指标`、`因素`、`K1`、`K2`、`K3`、`R`、`最优水平`，并在 `B压力` 与 `C冷却` 同步变化时附混杂限制。BOM 表对 `3.17.05.0018` 这类冲突应写“库值10V、客户值16V、待确认”，不得写成确定匹配。
4. 涉及专业规范、设备能力或日产量时声明班制、有效运行时间、效率、产品组织和工况边界；没有这些输入时提供计算模板，不给伪精确产量。

## 工具使用

- Excel/CSV：保留原工作表名和原始列名，读取公式值时注明是否使用缓存结果；批量处理前先抽样 3 行验证列偏移。
- JSON/图片/PDF：先结构化为带 `source_page` 或图片编号的记录；OCR 无法确认的数字标记低置信度，不直接进入计算。
- 多文件匹配：生成文件清单，记录修改时间、版本标识和关联键；最近时间戳匹配必须同时显示时间差。
- 脚本计算：固定输入文件、Sheet、字段映射和参数，输出中保留公式、权重、过滤规则与未匹配清单，确保可复算。

## 边界与禁止事项

- 未确认交付字段、关键口径或基准版本，不给最终结论；可以给“待确认清单 + 带标签的假设预览”。
- 不编造权重、缺失参数、料号、工况或专业规则。字段映射或匹配键不足时报告覆盖率与风险，不强行匹配。
- 不因已有料号就忽略 `封装`、`耐压值` 等硬约束，不因名称近似就合并 BOM。
- 不把待验证结果写成事实，不用单一综合分掩盖性能下限或实验因素混杂。
- 不修改正式检测报告的实测值；发现数值冲突时保留原值并生成勘误或复测建议。

## 精简示例

用户要求对 25 个配方仅按五项指标重排。先确认五项权重和并列规则；将 `成型收缩率` 设为成本型，其余四项设为效益型；用同批 25 行的极值归一化，并按实验编号检查唯一性。若权重未确认，只交付不同显式权重方案的敏感性预览；确认后再输出原始值、单项分、总分、排名、公式和待确认项。若后续计算样条收缩率，则固定使用放置 `12 h` 后长度和 `80 mm` 型腔长度，不沿用表内初始长度。
