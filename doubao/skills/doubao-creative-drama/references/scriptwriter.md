# 剧本创作 Ref

本文件是剧本阶段的主指南：承接已确认输入，教模型构思人物、事件、叙事与表达，一次完成当前范围的创作；完整模式写出正文后提取现有制作合同，轻量模式按下表交付正文或衔接主表。具体类型、题材、呈现类别、发动机和专项技巧按问题查阅 `剧作方法与类型库.md`；检索判断以 `planning.md` 为准，时间与镜头预算以 `pacing.md` 为准。目录、机器索引和状态分别以 `manifests.md`、`control-contracts.md` 为准，镜头与 Prompt 属于后续阶段。

## 阅读与执行顺序

先沿用规划已确定的制作模式和项目规模，明确本次要完成什么，再执行“输入门禁”和下面的共用构思顺序。模式只按视频交互 Ref 第 10 节确定；若影响全剧组织的集数仍无答案且用户未授权模型建议，先回该节澄清，不默认单条后动笔。两条路径共用下文适用的剧作、人物、叙事和人声方法，不能因轻量减少必要事件、人物应对或台词往来。已有合格正文按原采用范围继承，局部任务只深化缺口；已落实的模式与规模不重问，此处不增加确认。

| 已确认路径 | 本次构思与正文范围 | 完成后怎样衔接 |
|---|---|---|
| 轻量单条 | 想通完整事件、人声与结尾；剧本目标写唯一正文，分镜或含视频调用的目标直接落实到十五列主表 | 到目标即停止；只有含视频调用的目标按 `planning.md` 展示概览及本批完整人声，再取得生成授权，不提取完整模式配套合同 |
| 完整单篇/单集 | 一次写全唯一完整剧本，必要故事与设定放在同一文件 | 项目故事和本集执行复用该正文；继续制作时提取既有数据与合同，同一实际回复记录项目级、本集级作用域，只确认一次；纯剧本终点交付即结束 |
| 完整多集 | 项目级先写全局设定、完整故事走向与全部分集推进；获准细化当前集后，只写当前集详细正文 | 先确认总纲及数据卡基线，再逐集提取本集合同、确认本集；未来集不提前写详细对白 |

构思时读取本节、输入与已确认边界、“创作目标与选择”及共用策略第一至八节；所选类型与表达方法按具体路由补读。“从作品与生活材料迁移方法”和完整成稿示例只在缺少相应写法时查阅；正文格式在落笔前读，完整模式的数据卡与机器合同在正文完成后读，轻量模式跳过这两节。“剧本修改影响评估”只在用户提出修改时执行。下列步骤说明可相互校准的构思关系，不是先锁死情节、最后包装叙事；方法选择不变成新的交付物或确认门。

1. **承接输入与材料**：读取已确认规划、用户原文、来源边界；复用规划已有研究与受众结论。按 `planning.md` 的“创作检索策略”只补仍影响写作的实际缺口，不重新启动方向竞选。
2. **一起构思人物、关键场面与讲法**：用下文“创作目标与选择”把整片的关键决定连起来，再按对应方法深化。把主题变成具体处境，想清人物要做什么、观众为何在意、跟随谁、观众先知道什么、最值得看的场面和当前结果；同时判断这些内容能否装入已确认篇幅。沿用已选类型、题材和呈现类别，按工具库的“按已选方向主动调用方法”带回适用写法。
3. **推演连续应对与观看进展**：按第四节及系列要求，安排人物办法、其他人的回应、环境条件和后果；每次应对同时考虑观众此刻看见、听见和期待什么。写到交接、识破或回扣时，从正文上一状态接着推演谁持有什么、谁已接触哪条信息，不能从片头设定或预想结尾直接取用。前一结果改变下一步，不以增加背景、换场或支线代替丰富。
4. **贯通场面、声音与时间**：按第五至七节及工具库的[表达路径](剧作方法与类型库.md#先选表达路径再按题材与场景落笔)，继承短剧或微电影／短片的已定意图，结合已选题材、场景与载体构思整段交谈和声画关系。把信息关系、对白、行为、OS、VO、主观段落落实到前面的行动链；用实际语言和必要动作判断能否完成，省去重复解释与无效过渡。发现容量不合适时，在动笔前收拢未锁定的事件规模，不靠写完后统一加速。
5. **一次完成本次创作**：完整多集的项目级一次写全总纲，当前集获准细化后再一次写全该集；完整单集直接一次写全唯一正文，场次、动作、人声和结尾均完整。轻量完成相同的事件与人声构思；剧本目标保存唯一正文，分镜或含视频调用的目标不再复制剧本。均不安排初稿、试写、诊断报告或多轮改写。
6. **成稿与衔接**：把下文具体写法直接用于正文，交代影响理解的前提、保持人物状态和容量自洽，不以填字段替代创作。完整模式从正文提取稳定身份、状态、人声与必要合同，按原作用域展示确认；轻量模式回到上表的内部衔接，不套用完整模式产物或确认门。

此顺序是构思与交付的工作顺序，不要求正文线性叙事，也不要求把每一步写成表格。独立短片完成主要事件；连续剧同时处理本集所得与跨集后果，具体见“系列连续性与一次成稿”。

## 输入门禁

以下确认输入用于完整模式继续制作与轻量生成授权后的执行。轻量纯剧本/分镜目标可从明确要求与采用规划直接完成交付，不等待规划确认；视频目标展示前即可想清故事并写主表，取得真实 generate 后才执行视频。不运行独立规划校验。

- `00_制作控制/drama_plan.json` 内容完整，且 `制作状态.json.phases.planning == confirmed`。
- `00_制作控制/project_manifest.json`、`source_manifest.json` 及其中当前单集条目 已按 `manifests.md` 建立。
- `用户确认记录.jsonl` 存在当前 `drama_plan.json.revision` 的规划确认记录。参数确认正文已按 `planning.md` 在当前对话中直接展示，不依赖 Markdown 文件。

剧本继承规划中已经确定的目标、事实、创作选择、规模和风险，不得自行更换受众、平台、画幅、模型、故事发动机或创意主路径；轻量共用决定从 `drama_plan.json` 按 `planning.md` 继承，具体人物行动与人声写入本次唯一正文或主表，不为本节补齐完整模式字段。规划存在 `pending` 且会改变剧情意义、权限、成本或交付规模时返回规划阶段，不得直接补写。

输入是剧情大纲时，继承当前采用范围内的主线、关键事件、关系、因果与结局，不将局部任务扩为全剧创作；大纲本身不等于已经写好或确认了全部场面与台词。依据已定单条/多集范围，把省略的行动、应对、对白与声画过程具体展开，不因轻量只复述梗概，也不重新追问集数。独立故事兑现本片主要期待；开放结尾可以保留余味，但不能擅自删掉已给结局或改成连载预告。当前范围或锁定容量确实冲突时，沿规划既有变更规则处理，不通过跳过关键因果来适配时长。

完整模式继续制作所需的规划确认按 `planning.md` 执行；轻量纯创作不套用上述确认前置，实际生成授权边界不变。

### 已确认承诺与可深化空间

先区分“用户明确限定或已经确认的内容”和“尚待模型创作的内容”。人物身份与关系、事件、关键回应、结果、原台词、类型、时长、形态等，只要已明确确认，就不能以“提升质量”为由自行替换；规划中提出并获确认的内容同样有效，不只保护用户最初写的要求。

**尚未确认的简短剧情创意，应主动补成完整故事。** 例如用户只给“两个室友抢最后一把伞”，锁定的是两人、同住关系和争伞事件，不等于锁定“只拉扯一次、没有各自理由、没有台词、没有后果”。可在原意和已定规模内创作双方各自的急事、争取办法、相互发现、选择与结果；先让这些补充形成同一件事的连续发展。按既有适用流程展示采用内容，不另开一轮创意问卷，不把尚未完成的故事提前当作已确认基线。

补充时遵守以下界限：

- 用户未给动机、具体交锋或结局，且现有采用内容也未将其确定时，模型在当前阶段允许的创作范围内选择相容写法；不能把“未说明”一律解释为“不得添加”，也不能把自己的设想说成用户指定。已经确认的概览不等于每项具体行动和每句台词均已确定，但概览明确采用的事件、关键回应和结果仍须保留。
- 新增配角、物件和背景须在本场产生作用并适合篇幅；能用现有人物与资源产生丰富往来时优先使用，不为增加名词而扩建世界观。
- 用户已限定“只拍取伞动作”“无对白”“忠实复现”等，就在这些要求内丰富表演、观察、声音和可见过程，不擅自改成争夺故事。日常、温柔、喜剧、动作和悬疑各按自身乐趣展开，不统一增加恶人、伤害或身世秘密。
- 按已确认内容的实际范围深化：完整模式在规划确认后、正式剧本确认前，仍须沿采用故事写全尚未确定的具体场面、人物应对和台词；这不是替换已确认的主线、关键事件或结果，也不提前制作正式分镜或视频 Prompt。正式剧本已确认后，分镜只展开其动作过程、表演、镜头与声音呈现，不能补造缺失的重要剧情或新台词。轻量视频目标在生成确认前完成采用故事与本批人声，生成确认后只作原规则允许的呈现深化。纯剧本或纯分镜目标按原终点规则完成交付，不额外等待确认。改变关键事件或生成方案仍按原变更规则，不能借补充细节绕过。

轻量视频目标的预览展示采用故事的完整走向与结果；当前授权批次的全部发声原文按 `planning.md` 展示，未来批次的人声此时可只说明安排，轮到对应批次确认时再展示采用原文。纯剧本目标写完整正文，纯分镜或视频目标写完整十五列主表，面向用户的概览可以简洁。已经明确采用的事件、关键回应、结果及本批原句不能因概览简短而被另造或替换；具体深化仍按上一条的阶段与范围处理。

## 边界

承接短篇短剧、微电影、剧情短片、动画短片、单条剧情短视频，以及具备完整"目标→阻力→策略→反馈→变化"因果链的剧情宣传片、剧情预告片和广告剧情；纯商品转化广告、品牌价值观 TVC、企业宣传或真人对镜口播不属于本 Skill。也可承接多单元、几十集和跨集主线的长篇完整剧本。常规多集短剧单集通常为 1-3 分钟，极短集支持 15-60 秒；微电影可长可短，按完整事件确定篇幅。最终时长必须结合用户指令与剧本容量确定；超过 10 集时须声明长篇漂移风险，先锁全局故事、全部分集推进和结局，再逐集写详细剧本并复核。

## 创作目标与选择

故事应让观众清楚谁在争取什么、为什么困难，并持续产生值得关注的行动、发现、关系变化或情绪回应。开场不限定异常或悬疑，过程不限定受辱翻盘，微电影不默认缓慢，结尾不强制金句、反转、牺牲或和解。

沿用 `drama_plan.json.type_strategy` 中的呈现类别、题材路由与必要子路由，并继承主类型、项目签名和亮点职责。共用方法用于把这些选择落实到具体事件，不能暗中更换已确认主线、结局或创作方向。

动笔前把下面的决定放进同一部作品里推演：人物的办法如何形成剧情，剧情怎样让观众产生期待，台词和声画如何推进它，结果又怎样回应开头。它是既有策略的集中入口，不是新增交付表；不逐格填答案，也不要求所有故事采用相同技巧。已确认的受众、形态、题材与来源结论直接继承，有实际材料缺口才按规划策略补查。

| 需要一起想清的事情 | 动笔前落到本片的决定 | 具体方法 |
|---|---|---|
| 核心事件、表达与观看理由 | 谁正在争取什么，为何对他重要；观众想看哪种交锋、相处、操作或发现，什么具体细节使它属于这些人物；不止有主题或一个结尾点子 | 第一节及第三节 |
| 人物、关系与行动理由 | 主要人物各自想保住什么、知道什么、能用什么办法；对方为何接招，变化凭什么发生；稳定人物也可有丰富应对，不强制创伤或成长 | 第二节 |
| 连续剧情、场面与起伏 | 前一结果怎样改变下一次办法；每场进入哪项未解决的行动，结束时观众拿到什么进展、趣味或感受；不靠换场、碎操作或新增支线充数 | 第三、四节及第七节 |
| 叙事、设定与信息顺序 | 跟随谁，人物与观众各知什么、期待什么；哪些规则和事实必须让观众实际看见或听见，发现后又怎样影响行动 | 第五节及“因果、事实与表达边界” |
| 台词、心理与叙述声音 | 此人为何在此刻对这个人这样说，对方怎样理解并继续；需要的内在活动采用行为、对白、OS、VO或主观段落中的哪种表达；整段有何起伏与所得 | 第六、七节及工具库的短剧／短片表达路径 |
| 类型乐趣与声画呈现 | 本片要兑现的好笑、紧张、心动、机智、奇观或其他体验，具体落在哪段可见可听的往来；已有呈现载体怎样使它成立，不用抽象情绪标签代替场面 | 第一、三节及工具库的已选类型、题材、呈现与场景路径 |
| 全片节奏、容量与可拍性 | 从开头到结尾，何处进入事件、何处已产生有效反馈、何处兑现主要期待；动作、理解、说话与反应怎样占时，不能前面准备过久、后面一次赶完 | 第三节的容量方法、第七节及 `pacing.md` |
| 结尾、系列承接与连续性 | 当前问题和关系走到哪一步，在哪里结束最有分量；跨集保留什么结果、能力和后果；关键回收来自既有条件，不临时补万能答案 | 第三、五、八节 |

上述决定互相影响：一句话需要对方改变决定，就要留出听懂与回应的空间；一个规则负责解题，就要安排观众理解它的机会；一段准备占了篇幅，就应同时产生本片所选的观看乐趣。先把这些关系想通，再一次写全正文，不先凑齐栏目、最后才寻找戏。

## 共用写作策略

下列方法帮助完成一个具体故事。先把当前故事真正需要的关键选择想清楚，再连续写出正文；选择过程不另产出卡片、分析报告或确认轮次。先抓住本片主要观看乐趣，用适用方法把它做实；不要让人物依次表演所有技巧。已选类型需要的方法在构思时主动调用；其他专项工具只在实际用到时读取，不通读全部候选。

### 使用方式

- 一次完成当前授权范围的完整成稿。动笔前把下列关键选择想清楚，直接写入人物行动、场次、对白与结尾，不安排“初稿—诊断—改写”、七轮改稿或逐轮报告。
- 方法是帮助作出选择的工具，不是要在正文显示的栏目。不新增创作卡、心理表、观众期待表或评分文件；必要信息随正文和现有合同保存。
- 沿用既有五类呈现方式、十一题材路由、十四类型家族和场景四维度；允许采用相应规则下的自定义写法。结构、节拍和独白都不规定统一数量或频率。
- 任何策略只用于用户未锁定的空间。已确认主线、结局、时长和形态不因调用方法库而被更换；真实冲突按 `planning.md` 和 `control-contracts.md` 处理。

### 一、先确定为什么值得看

先在脑中把想法落成具体处境：谁正要完成哪件事，什么阻力迫使他改变办法，失败会失去什么；再明确观众最想看到的结果，以及这个结果为何不容易得到。欲望可以很小，但对这个人必须重要。

让观众关心，靠眼前可感知的投入：人物为一件喜爱的事认真准备、展露一项本领、笨拙地争取回应、冒着丢脸风险主动接近，或在具体处境里受到不公平对待。按本片选择即可，不要求主角先受辱、讨喜或自述苦难。小愿望也要有此人的分量：错过这次机会具体意味着什么，他已经为它做了什么；背景很大却无人真正想做事，同样难以吸引人。

选事件时也辨认它能提供的体验：比试和操作可以好看，相互欣赏、调情和默契可以好看，危险中的机智、荒诞的麻烦、欲望失控与艰难取舍也可以好看。把所选观看机制放进主要往来，想出它怎样改变人物的判断、办法及对方回应，或改变观众对同一行动的理解与期待；再试着拿掉这一机制，若主要往来与观看体验仍相同，就检查它是否只剩开头噱头或题材装饰。在确认前让主要场面真正兑现这个机制，不只增加一段设定介绍。生活感不是把所有故事都收成修东西、填表、分工与讲道理；这些事务只有带来本片所选的趣味或情感时才值得展开。题材允许的冒险、欲望、浪漫、荒诞与强烈对抗应当真正进入场面，不因追求稳妥而一律缩成礼貌协商。

不要满足于“讲亲情”“女主逆袭”“口吃的人找到自信”。把抽象主题落实到当下事件：一次必须参加的见面、一项必须共同完成的任务、一笔双方都不愿让出的支出。事件可以让人物擅长的办法碰到不愿面对的弱点，也可以让不同本领形成配合、相同愿望发生竞争，或一次大胆尝试得到意外回应；不把克服弱点设为所有故事的必经主线。

选择故事时同时考虑三种吸引力，可按作品侧重其中一种或组合：

| 吸引来源 | 开写前如何决定 | 正文怎样让人愿意看 |
|---|---|---|
| 结果期待 | 明确观众希望谁得到什么，以及哪项阻力会让结果难料 | 让人物争取，给进展和挫折，使结果真的有可能改变 |
| 人物与关系 | 选一组相互需要又难以满足对方的人，写清各自不能轻易让步的理由 | 同一事件中出现不同策略，让观众看到他们独特的反应与相处趣味 |
| 情境与发现 | 选一个能产生行动后果的异常、规则或观察角度 | 尽早展示规则如何生效，让人物验证、利用或承担它的后果 |

题材常见仍可写出新意。按 `planning.md` 的“创作检索策略”补足必要材料，再从中找到任务、人物办法和行动限制。生活细节先有当前需要、人物习惯或交往用意，再从中展示能力与关系；不为贴上“专业”“默契”等标签，安排没有来由的操作。细节要参与决定，不只装饰地点、服装和道具。

把材料变成事件时，顺着下面的问题构思，不把答案另存成表：

1. **抓住真实的不便或愿望**：当事人原本打算做什么，哪一步最费劲、最难开口或最容易被误解？例如“父女不善沟通”仍太泛；“女儿替父亲填一张报名表，却把他的参赛项目改成自己认为安全的项目”已经有可演的事。
2. **给双方不同的解决办法**：不是先给人贴“控制狂”“叛逆”标签，而是明确各自想保住什么、会做什么。她要替父亲避险，他要保住自己决定的项目；改表、核对、提交会使分歧落地。
3. **选会迫使回应的碰撞时刻**：表正在核对或准备提交时进入，避免先演长段家庭背景。谁发现改动、能否撤回、谁决定提交，用可信流程约束行动，不凭空加死亡或最后一分钟倒计时。
4. **让结果回应原问题**：可以共同重填，也可以父亲自行提交、女儿只帮录入；关键是决定权和帮助方式发生了什么。不要临时加身世秘密替代眼前分歧。

上述为原创构思示意，不是固定亲情模板。别的材料可以发展成竞争、协作、闹剧或探索；若用户已锁定事件，只在其允许的切入、办法和表达中深化。涉及专业流程仍需核实，不把示意中的程序当现实事实。

在已授权创作空间内，如果一个处境只能产生介绍和气氛，就继续把事件想具体再动笔。用户锁定方向时，通过切入时刻、人物应对和信息顺序增加吸引力，不替用户另选故事。

核心事件要能持续提供所选乐趣。动笔前想清：人物第一次会用什么办法，对方为何不会轻易照办，反馈留下什么可继续利用的条件，最值得看的往来如何当场发生。若主题是机智，正文要让观众看到办法与接招；若是爱情，要看到靠近、误读或回应如何改变相处；若是喜剧，要看到预期、偏差与补救。只在开头宣称题材、结尾宣布结果，中间处理普通手续，不算兑现。不要为增加轮次故意让人物忽视已有的直接办法；直接办法可行时，就让它产生真正值得展开的结果。

#### 把普通设想变成当前人物独有的事件

用户给出的是主题、关系或一个动作时，先沿下列关系构思，把采用结果直接写入正文或主表，不另建表单或分析文件。用户已提供或确认的答案直接继承，只补未锁定部分。

| 当前缺口 | 模型应补出的具体内容 | 如何实际进入剧情 |
|---|---|---|
| 只有动作，没有目的 | 这个人当下要得到什么、为何此刻要做 | “拿伞”可以是要护住面试材料；观众从保护材料的行为理解急迫，不先听履历 |
| 只有单方愿望 | 另一人也有自己要保住的事，或环境有已建立的限制 | 抢伞者也要送一盒不能淋雨的蛋糕，争执有双方立场，不只是坏人阻挡 |
| 只有冲突标签 | 第一次具体办法和有作用的回应 | 先到者按住伞不让取，对方拿出自己的急事；回应改变对方的拉扯力度或做法 |
| 中段只有“争执、努力” | 一次尝试留下什么新信息、机会或代价，下一步怎样利用 | 看见对方护住蛋糕的动作后，原先只顾自己的角色开始改办法，不能仍重复同一句“给我” |
| 只有结果宣告 | 人物在可选办法之间作出的选择，以及它怎样生效 | 一人把伞让出，另一人回身提出同行，两人真实调整持伞和携物方式，而非旁白说“他们懂得分享” |
| 人物只有标签 | 具体能力、习惯、关注点或话语选择 | 嘴上争先的人始终把伞向对方倾斜，让行为提供话语之外的信息；不再追加点题解释 |

这些是同一因果链的可用构思方向，不要求每段新增一项设定。新增内容先有与当前目标的关系，再进入画面、声音或台词；一段时间只需让观众抓住当前关键进展。不要一边介绍新人、一边揭示新规则、一边要求看清另一处证据。

把表层情绪推进到实际取舍：嫉妒者具体阻止什么、害怕者仍愿意做什么、关心者让出什么、想保全面子的人怎样改变说法。取舍可以轻巧、有趣或强烈，不必总有惨重代价。人物的结果应来自这些选择和已有条件，而不是突然出现的消息、能力或救场者。

#### 让过程本身值得看

构思时先想见一段观众会想亲眼看完的交锋、操作、相处或发现：谁具体做什么，对方怎样接招，观众原先预期什么，实际回应有什么趣味或分量。把这段放回完整因果中，决定开头怎样让人关心、过程怎样接近它、兑现后留下什么结果。只会描述“最后感动、反转、成功”，却想不出中间值得看的互动时，继续深化未锁定的事件，不急着确认方向。

熟悉的题材先顺推最容易想到的展开，再从当前人物已有的资源、习惯、利益或场景条件里找另一种可信办法。例如“争最后一个排练时段”可以双方竞价、互相试音、协商合练，分别产生竞争、喜剧或亲近；选哪种取决于人物和观看乐趣。新鲜感应改变互动与后果，不靠临时秘密、猎奇伤害或增加设定。

按所选类型让过程交付实际乐趣：喜剧让认真采用的办法引出可见偏差与补救；悬疑让观众能提出猜测、看见验证并修正理解；关系戏让吸引、较量、体贴或边界通过往来成立；动作让已知空间和资源产生观众看得懂的巧用。只选本片实际采用的路径，不把所有作品写成解谜或成长。具体类型方法仍读工具库。

需要选择进入故事的具体时刻时，查工具库的[开场入口](剧作方法与类型库.md#开场从什么行动进入)。

### 二、人物与关系先有自己的理由

对主要人物，想清楚“当下想得到什么、害怕暴露什么、惯用什么办法、能动用什么资源、什么情况下愿意改变”。这些选择用行为和语言体现，不要求每人都有创伤、秘密、错误信念和完整成长弧。

需要人物层次时，找同一时刻相互牵扯的愿望，并让它影响办法：想被欣赏又不肯显得刻意，想赢又珍惜搭档，愿意帮忙却舍不得出让自己的机会。不是列两项相反标签，而是在当前行动中看见顾此失彼、折中或选择其一。矛盾也能带来喜剧、吸引力和惊喜，不必诊断成人格缺陷；单纯、稳定、坦率的人物同样可以成立。

给人物安排办法时，区分“想要的结果”和“此刻用的手段”。每个关键应对从行动者自己的所知与诉求推演：他认为出了什么问题，为什么觉得这个办法有用？不能只因编剧需要下一次误会，就让人无故绕开自己已知的直接做法。人物可以固执、装傻或采用笨办法，让观众从眼前行为读出他相信什么、在维护什么，不另加一段背景替行为找借口。同样想留住搭档，有人谈条件、有人展示不可替代的能力、有人假装不在乎；不能所有角色都轮流质问和解释。遇到反馈后，根据他实际知道的信息与资源调整办法，不能为方便下一场突然改性格。

对核心关系，先找相互牵制之处：一方需要另一方的什么；双方对同一件事的诉求哪里相同、哪里冲突；谁有决定权、谁知道更多、谁更在乎。权力、信息和情感位置都可用自然语言记录，不强制打分或独立关系矩阵文件。

- 两个人都有道理时，让他们对同一件具体事采取不兼容的办法，别把其中一人临时写坏来方便收场。
- 明确善恶对抗时，反派可以恶，但应有目标、利益、资源和自保能力，不能只等主角揭底或突然犯蠢。
- 配角根据自身诉求帮助、阻挠、交换或退出，不只负责讲背景、递线索和惊呼。
- 感情变化要有足够分量的触发：对方做了原来不会做的事、承担了风险、尊重了边界，或暴露了难以接受的事实。随后写出新的相处行为，不能从一次对视直接跳到信任或原谅。
- 人物可以不成长，也可以作出错误选择；结尾应让这种坚持或失败产生可理解的后果。

人物遇到不利反馈时，先按他当时的利益和惯性继续应对：可以辩解、试探、退让一部分、交换条件，也可以直接认错。选择必须承接他的所知与刚发生的事，不能因为快到结尾就突然接受作者的道理。构思交锋时，替对方作一次当前所知与能力范围内的合理自保：他会收起证据、核实说法、保住资源还是退出？再判断主角已有的办法为何仍有机会奏效。证据取得需要可信的接触条件，不让对手为配合揭晓，把原件、账号和全部目的留在主角眼前。对方也有权拒绝、附条件或只接受眼前合作；配角不必按主角成长进度给予原谅。

**新事实不会自动使人照办。** 揭穿一种说法以后，继续从对方仍想保住的东西推演：他为何愿意交回、配合、退出或换条件，主角又凭什么取得眼前结果。可以是继续掩饰的代价变大、原办法已行不通、换取保全面子，或真心接受新的提议；把有作用的原因放进实际行为与回应。没有相应控制权时，一句“你不能走”“现在必须给我”只是人物的要求，不是已经生效的结果。故事可以以保住物品、拒绝逼迫或完成合作结束，不顺带宣布尚未获得的追责、原谅或彻底胜利。

交换、交接或权限转移本身就是关键场面时，顺着实际先后想清：每一步谁已拿到什么、还控制什么、为何愿意继续。如果一方仍能拿走所需而扣住另一方应得，原来的保障问题就没有解决；不能仅写“同时交换”“互相制约”便宣布安全成交。也可让人物有根据地承担风险，但须分清是信任选择，还是办法确实消除了风险。

分别想清“眼前任务完成了什么”“人物这次改变了什么做法”“关系恢复到哪一步”。一次合作可以只证明双方还能做事，一次公开更正可以修复署名而尚未恢复信任。篇幅不足以支撑彻底转变时，让这次回应小而可信；轻松和解、稳定人物与无成长喜剧仍可成立，不强添裂痕。

需要展开双方的具体相处方式时，查[人物关系路径](剧作方法与类型库.md#人物关系怎样产生张力与趣味)；需要落成话语时查[对白写法](剧作方法与类型库.md#对白与可传播台词)。

### 三、动笔前定好关键场面和结果

先确定最值得观众看到的场面：它可以是有效反击、艰难选择、规则妙用、情感靠近、笑点回扣或真相得到验证。把场面想成正在发生的往来：人物用什么办法争取，对方或环境给出什么反馈，人物如何利用这个反馈得到结果；不要只想结果发生后的解释、认错和处理手续。此处是构思，不另写试稿或示范草稿。

**把代表场面想成可以亲眼经历的过程。** 先建立观众能理解的目标与条件，再让人物的方法与这些条件相遇：重要物件放在哪里、谁能接触或看见、双方如何利用刚收到的反馈，突破发生在什么行动上。使结果来自已建立条件的有趣使用；观众可以预感方向而仍期待具体怎样做到。高潮的规模按本片选择，可以是身体行动、公开回应、关系靠近、一次操作或喜剧回扣；不能一律加灾难、围观者、倒计时和胜负。

按当前题材选真正有效的组织方式：悬疑把两种解释放到同一次可读验证中，人物须承担验证后的行动；动作让已知路径、资源和对方应对不断改变可用办法；爱情让靠近、回避或主动回应实际改变两人的相处；喜剧先建立认真坚持的行为规律，再让补救改变偏差；家庭短片让同一件日常事承载双方不同的关心方式，新的回应改变旧习惯。是从已定事件深化过程，不强求所有场面都反转、遇险或感动。

在剧本中想清关键时刻画面和声音分别贡献什么：画面证明行动，声音可提供距离、尚未看见的回应、期待或主观体验，台词改变一次决定。它们可同向强化，也可各自补足另一层信息；不要求每场都声画反差。具体镜头与配乐执行留给分镜，已确认故事中的关键事实不能由后来随意新增的音效或旁白补救。短篇集中兑现适合自身容量的亮点，全篇仍要有主次与连接，不能只剩一个漂亮高潮。

从关键场面往前安排必要条件：人物此前要经历什么，观众要知道什么，哪项能力、规则、道具或关系需要先出现；再从开端顺推行动链，确保结尾能由这些条件自然得到。删去只为遮掩答案而存在的拖延。

**按整片的发展分配场面，不把任务步骤直接当故事段落。** 先想开头的愿望怎样被实际争取，中途哪次发展改变办法、期待或理解，主要场面又兑现了什么。把等待确认、搬运物件、准备工具等条件放到人物真正要做的事中；它们只有带来本片特有的交锋、趣味、发现或情绪时才展开。可以全片围绕一件事，也可以有多条相遇的行动；丰富度来自经历的差别与相互影响，不来自把同一次安排依次拍成准备、同意、摆放、再确认。

片中最有分量的变化需要有足够过程，连接处则带着它造成的新条件往前走。例如一次合作已成功，后段可以因此敢于争取更难的事、暴露先前没显出的分歧、共同享受成果，或承受它引来的后果；不自动接一段证明“我们终于会合作了”。短剧与微电影都按所选体验安排主次，完整模式增加全篇组织，轻量也保留这些决定。规模与当前内容确实不匹配时，先在未锁定空间深化，已锁定时按原变更规则处理；不硬填时长或集数。

故事的意思落在“人物原来怎样应对、这件事迫使他怎样选择、结果说明了什么”之间。可以始终坚持同一信念，也可以改变或失败，不必由旁白宣布道理。让主要事件与结尾回应同一个问题：开头争取自主，结尾就通过一次实际决定呈现自主；不要中途换成揭露身世而把原问题丢下。

- 独立短片：回答主要行动问题或呈现明确结果，保留人物反应；主题可以留有分歧。开放结尾可保留未来，但要让观众清楚眼前发生了什么、人物选择了什么。
- 连续短剧：本集先交付实质进展或阶段结果，再由该结果的后果建立下一集行动理由。案件可跨集，不能每集只加谜团而没有发现和变化。
- 喜剧：回收已建立的执念、误判、规则或行为，最大笑点应与人物此前的做法有关；不要求转成煽情结尾。
- 情感与生活流：用一次具体回应、关系边界或生活方式的变化收束，可以克制，不强制大和解、死亡或不可逆牺牲。

需要增强关键兑现时，查[爽感与阶段回报](剧作方法与类型库.md#爽感与阶段回报怎样成立)及[亮点维度库](剧作方法与类型库.md#亮点维度库)。

#### 从“能讲通”走到“值得看”

不要用“局势有变化”直接代替精彩。先在脑中看见主要场面的实际往来：观众刚形成什么期待，人物怎样争取，对方为什么这样回应，这次回应又让人想看什么。递出文件、交代背景、取得线索可以推进手续，却未必提供观看乐趣；把需要展开的部分写成有办法、有反应的现场，其他部分压缩。

按本片欠缺的东西作具体选择，不把下面各项依次套进每场戏：

| 场面目前停在哪里 | 继续构思什么 | 怎样让过程值得看 |
|---|---|---|
| 只知道最后赢了、感动了、揭晓了 | 从结果回到兑现发生前：当时谁还不肯、不能或没有察觉？人物凭什么让事情发生？ | 展开最有趣的争取、配合或发现；准备条件可以在这一过程中建立，不先集中讲解 |
| 人物一开口就拿到想要的回应 | 站到听者立场，找他真正愿给的东西及不愿让出的部分，再推演一次合理回应 | 主角从反馈中找到新办法；也可意外得到善意，但善意应有此人的理由，随后产生具体互动 |
| 办法受阻之后仍原样重复 | 让前一步留下可用的经验、暴露的弱点、已经答应的话或改变的关系 | 后一步利用或承受这个结果；不是换一个新麻烦后从头再来 |
| 全程一眼能猜到相同的应答 | 在已有性格、共同经历、场景资源中，找对方另一种有根据的反应 | 例如认真接住一次玩笑、拒绝好意却提出真正想要的帮助；改变交往，不必新增身份秘密 |
| 人物作了选择，下一步仍像没选过 | 让承诺被执行、资源被使用、另一人据此回应，或让人物承担选择留下的影响 | 结果改变后续可能性；影响可以是更亲近、更尴尬、更自由，不必都是损失或惩罚 |

**把张力放在此人不能轻易兼得的东西上。** 想赢又不愿暴露底牌，想被留下又不肯接受怜悯，想开玩笑却发现对方当了真，都能让一次简单行动产生层次。挑选本场真实存在的牵扯，使人物在应对中显出偏好；没有这种牵扯的合作、观察和纯粹喜悦，也可凭熟练配合、发现过程或形式趣味成立，不人为补苦难。

**起伏不只靠失败加码。** 可让好办法先奏效，使对方换条件；也可先有默契，再发现两人对同一句承诺理解不同；或让观众先知道隐瞒，期待它在日常互动中露馅。选哪条，取决于既有类型与人物。关键是前一发展改变下一次的期待和应对，而非按“受辱—反击—再受辱”轮换音量。大反转之前，中途同样要交付本片承诺的机智、心动、紧张、好笑或其他体验。

#### 揭晓之后，收束还是继续发生

先认清观众等的是“弄清发生了什么”，还是“看人物怎样解决、怎样相处”。若发现本身已回答主要问题，让答案回收线索，再给必要反应和眼前结果即可。构思结尾时，找到观众既看清结果、又拿到本片主要乐趣的落点：最后留下哪次行动、哪句话或哪种反应？在这里结束，不默认继续演到人物全部离场、场所恢复原状、每件道具都安置好。回扣本身就是主要乐趣时，为它留出完整往来；已经完成的结果则不再逐项展示角色“终于明白”，也不要求行动后再接对白、旁白和表情各总结一次。构思尚未锁定时，把篇幅用于兑现所需的条件和互动；已确认时长内保留必要的理解和情感回应，不把它们一概当作拖沓。

若答案出现后主要目标仍未完成，就从新事实中找出**现在实际卡住的事**：谁仍控制所需资源，谁还要保住另一项利益，什么已发生的结果不能靠一句解释撤回。接着选择符合本片的一种推进方式；不统一要求反派抵赖、连续反转或额外牺牲。

| 此刻还要完成什么 | 把场面具体想下去 | 结果怎样由行动得到 |
|---|---|---|
| 争取对方尚不肯给的东西 | 双方各自拿得出什么、愿意让到哪里；一方提出能执行的条件，另一方接受、换条件或退出 | 条件改变实际安排；不是主角指出道理，对方随即照办 |
| 让事实或能力得到验证 | 找一个在当前条件下能区分不同说法的动作；人物决定是否参与、如何应付，验证带来可见差异 | 观众看见判断如何成立；有现成简单办法时就使用，不故意绕路找多份同义证据 |
| 共同完成眼前任务 | 把已知能力和限制变成实际分工：谁先做、谁接手、怎样根据对方反馈配合 | 关键操作本身好看，贡献看得清；无需先互相认错或突然消除分歧 |
| 作一个无法两全的选择 | 只用已经建立且人物确实在意的两项需要，让他落实选择，另一人按自己的立场回应 | 观众看清保住了什么、放下了什么；不临时制造灾难逼出高尚表态 |
| 兑现一次关系回应或笑点 | 让人物把刚知道的事用于下一次试探、邀请、补救或玩笑；对方可以接住、改造或拒绝 | 往来带来新的亲近、边界或偏差；直接答应也可以精彩，不强造第二轮阻力 |

本文件的例二先用完整语音改变片段录音的解释，经理质疑手机材料后，林夏利用开头已出现的纸角要求核对现场原件；最后把“认清经手”用于区分领取与接收保管，逼签被打断，核对记录实际落到经理面前。这里原有施压与责任混淆仍在，所以继续接招；若本片所等的事情已经兑现，就应收束。例六在开头就揭明独占署名，观众等的是小夏怎样争取、阿行会怎样选：小夏交出操绳，使他不能继续隐形借力；他试图索取最后一次暗助，她提出公开署名与操作的条件；他放弃单人评奖，双方再用实际配合完成节目。差异在于观众等待的场面，不在于哪篇多加一次反转。

上述方法服务当前期待。动笔前顺着人物的办法把关键往来想通，直接写入完整正文；不用在成稿里补一轮轮质问、解释或反对来凑“交锋”。

#### 构思关键场面时就判断容量

关键场面、前置条件和结果一起估量：已确认时长内，观众需要看清哪些动作、听懂哪些话、认出多少人物与规则？先抓住真正改变判断的差异，把同一事实的多份证明、多个界面状态收拢到必要的信息链。关键文字需要发现、阅读与理解的时间，不能靠观众暂停逐字读完；动作也要让人认出目标、看懂办法、看清结果。画面能同时出现，不代表观众能同时理解。

按实际观看顺序推演整段往来：一人完成动作，另一人察觉、作判断再回应，通常有先后依赖；同镜发生或标在同一时间段里，不会自动变成并行。先按自然表演估量主要兑现与必要反应，再向前安排条件和交锋。比较各段的实际负担：如果尾段要认出更多新情况、换更多次办法、完成更复杂的操作，却比前面仅作准备的段落更短，不能凭时间标签认定装得下。先收拢未锁定的准备、同义证明和次要回扣，重新安排实际往来；不把最复杂的一段留给剩余几秒。

判断收束还需发生多少事。一句反应就能成立的包袱可以短促；若还要出现新问题、认出问题、换办法、执行并得到回应，它就是仍待完成的一段戏，不能当作结果后的顺手附赠。它若是主要乐趣，就给它完整空间，并让合适的条件此前进入实际交锋；若只是次要回扣，优先选择能随主要结果一起成立的收束，或舍去。关键结果可以最后才出现，中途则通过实际试用、接招、发现与相处交付所得，不把所有验证和回报留到尾声；不平均分配高潮，不套固定秒点。

把必须先后发生的动作、理解和完整台词连起来，按预定人物语气与正常动作速度推演一遍，再分配全片篇幅；可实际朗读时用完整人声估时，无试读或试演条件时只作保守粗估，不声称已有实测。若一段只有省掉人物看清、接招或执行，才能塞进预留时间，就在确认前取舍事件，不把“动画可以快”或“后续分镜解决”当作容纳依据。优先让一次行动兼顾能力展示、性格与推进，利用同一组已知条件形成多次反馈，不把每个节拍扩成另一个完整问题和解决过程。保住主要往来的理解与反应空间，舍去次要操作或回扣，比把全部想法演快更能保持利落。

前置条件随实际使用建立，真正可重叠的声音与行动按 `pacing.md` 预算；不因句子短忽略朗读，也不因“同时”“很快”省略交接、看清和改口。此处判断整体容量，分镜阶段再落实逐镜时间，不提前制作镜头表。以上调整只在未锁定空间进行，涉及已确认内容仍按原变更规则处理。

规划预览分配时间时，先按正常表演估量必要动作和关键往来，再安排整片篇幅。不要先给几个简单任务分好长时间槽，再由正文补擦拭、收放、核对等微步骤撑满；这些细节只有在产生新反馈、笑点、人物意味或观众仍在等待的结果时才展开。未锁定事件不足以支撑目标篇幅时，在确认前深化实际互动；已确认后仍保护原事件与时长，不靠擅自改剧情或自动放慢来补空。

短篇优先选能反复产生有效反馈的具体事件，保留主角的有效尝试和必要兑现；背景通过当前任务所用的物件、声音或回应进入。不要为省时直接删掉人物如何得出结论，也不要为了丰富塞入未铺垫的反派、设定与支线。若先决条件本身就需要长段讲解，在未锁定空间换更直观的条件或收拢事件；涉及已确认内容则按原变更规则处理。

同时判断制作表达：关键能力能否由清楚动作体现，多人互动能否分清行动者，空间和重要物件是否容易识别。推演相互作用时，把前一动作的结束状态作为下一动作的起点：人物与物件在哪里、朝哪边、谁与什么接触，以及哪些手、支承或通路仍被占用。围绕当前办法真正依赖的限制推演；办法改变了物件或位置，就按变化后的状态判断能否继续，不沿用变化前“装得下、够得着、看得见”的结论。方向、可达范围和必要的换手、解脱、支承变化要前后一致，不能让正文动作违背已写明的设定。依赖遮挡、偷看或误认的办法，还要想清双方此刻实际能看见什么，让观众能读懂藏与露的差别。把必要条件写进当下可见动作，不另列调度表，不展开无关原理，也不把普通流程逐步写满。让声音覆盖实际行动可以保住戏剧内容；模型难度不是自动改成站着解释、延长停顿或更换模型的理由。

### 四、用行动与后果丰富剧情

按“当前目标 → 采取办法 → 人或环境反馈 → 局势改变 → 下一步决定”构思。它是因果关系，不是要求每场、每镜机械展示五个栏目；一场可有多次应对，短场也可以只完成因果链中的重要一环。

丰富已有事件时，选择真正适合当前故事的方向：

| 需要的内容 | 具体写法 | 后续必须承接 |
|---|---|---|
| 策略变化 | 人物原来的办法受到具体反制，改用另一项资源或承担新风险 | 新办法改变成功条件，不能只是重复请求 |
| 利益牵连 | 解决眼前问题同时影响另一个人的目标、尊严或责任 | 对方依据自身立场回应，关系随之变化 |
| 信息重释 | 同一证据出现新语境，旧解释不再充分 | 人物根据新理解改变行动，而非只惊讶 |
| 能力与限制 | 让人物先展示能力，再遇到该能力不能直接解决的情形 | 高潮靠应用、组合或放弃已建立的办法 |
| 情绪反差 | 一个实际结果改变人物原有期待，快乐中出现顾虑或失败中出现支持 | 反应改变互动或决定，避免只有情绪形容词 |
| 一事多用 | 让同一行动既解决任务，又暴露性格、改变关系或回收伏笔 | 每种意义来自同一事件，不另加解释段逐项总结 |

副线只在篇幅容纳、且会改变主线筹码、人物判断或关系结果时加入。极短篇可以围绕一件事多次应对：“一件事”不是一个动作拖满时长，同一任务内仍可有试探、执行、受阻、换办法和兑现；每一步有新所得，不重复相同状态。不为“丰富”增加多条支线、多个反派和世界观名词。

把一场戏写活，先决定它从哪个尚未解决的行动进入，谁先采取办法，对方的回应使哪种办法继续有效或失效，再把场面推进到一个不同于开场的局面。变化可以是许可被拿到、玩笑被当真、合作分工形成、误判被纠正，不必每次增加灾难。

例如，两位同事都想交付演示，却分别坚持“先把功能做全”和“先让演示能跑”。只让他们争论速度与质量会空转；让一次实际试跑暴露缺陷，一人提出删功能、一人用已有工具修复，随后决定谁向客户说明范围，任务与关系就在同一场里推进。这是虚构方法示意，不代替真实行业流程。

场面进行中，注意对手和环境也有行动能力：对方会拒绝、换条件、验证、合作或退出，不是等主角说完观点。每次新动作都承接刚获得的反馈；转折来自已存在的条件被使用或被重新理解。写“她终于明白了”之后，还要让她作出与原来不同的决定，观众才看到理解的后果。

场面之间连接的应是条件变化。不要只用“然后去了另一个地方”；如果后场无需前场也完全成立，应在构思时明确其独立职责或合并。日常、关系、喜剧与任务都可推进，不强制每次反馈都是失败或更大危机。

当一件事需要连续几次应对，先决定前一次留下了什么，再用它构思后一次，而不是轮番安排新障碍。第一次试用可以显露限制，局部奏效可以引来对方调整，已经学会的办法可以在新条件下主动运用。变化可落在目标、方法、资源、信息、关系或人物的主动程度上，按事件选择；不要求依次用全。重复动作也可好看：观众已经认得其规律，接下来期待人物怎样提前应对、故意利用或反过来承受；每次都毫无所得地从头再来才会空转。

例如两名街头乐手第一次合奏互相抢拍，第二次一人听懂对方在借街边施工声打节奏，改用旋律接进去；施工骤停时，对方接住空拍，两人才形成自己的合奏。看点在听、试、接住和共同创造，既有进展也有关系趣味，不必额外安排恶人、比赛或身世。这是原创构思示意，不要求音乐题材都写成这一轨迹。

为避免剧情简单却被拆成很多动作，沿同一事件深化三件事：人物怎样利用已有条件争取；另一方怎样保护自己的利益或按自身意图回应；这次结果怎样改变接下来的办法或关系。配角的回应要实际起作用，不能每次只惊讶或认错。局部成功可以引来对方换条件，也可以使双方敢于更进一步；新的困难应来自已发生的事或已建立的条件，不临时增加事故。

默认有效变化的时间安排见 `pacing.md`。剧本不必按秒写段落，但应把“说了什么、正在做什么、收到什么反馈、因此改变什么”连续写出来。几个细节后仍没有新的办法、关系或结果时，改进事件本身，不把走路、拿物、转头和反复试探拆成更多段落。

#### 多样性来自不同的因果和表达

选取当前故事适用的办法，不把下列路径全装进一个短篇：

- **让相同目标遇到不同办法**：同想完成小组任务，一人靠流程、一人靠人情；一次行动的结果迫使双方借用对方方法。适用于校园、职场，也能迁移到冒险协作。
- **改变规则的使用者**：先由某人用规则约束别人，再让自己面临同样限制；喜剧可在重复中回扣，严肃故事可迫使人物重新判断公平。
- **让善意造成具体阻碍**：帮忙者提前替别人决定，导致一项任务受阻；被帮助者清楚提出自己的办法。不要把每次善意都藏成惊天秘密。
- **让胜利改变关系**：主角赢得比赛却发现搭档被排除；在结尾行动中处理新后果，不靠一句“友谊更重要”自动解决。
- **换叙述声音与信息顺序**：主观自辩配合相反事实、同一事件的有限双视角、先结果后追溯，都要产生具体理解差异；线性顺叙同样可以精彩。
- **让一个细节承担多种职责**：泳帽既证明母亲认真准备，也触发女儿询问，最后支持母亲自己的选择；比额外添加不相关支线更适合短片。

不要求每部都有反转、创伤、牺牲、恶人、秘密或成长。重复人物行为可以成为喜剧签名或关系母题，前提是情境、反馈或意义发生变化。借鉴作品时迁移机制，重新设计当前人物的诉求、资源、选择和结果，不复制桥段。研究迁移示例见本文件“九、从作品与生活材料迁移方法”。

需要组织不同乐趣的推进时，查[剧情节拍](剧作方法与类型库.md#剧情节拍按事件推导)；发现相同状态反复出现时查[避免空转](剧作方法与类型库.md#写作时怎样避免空转)。

### 五、叙事视角、信息与观众期待

构思事件时就一起选择视角与信息关系。同一个“归还物件”的任务，观众先看见送错可产生期待与尴尬，随人物一起辨认可形成探索，听人物自信判断再看到反证可形成主观喜剧；这些讲法会改变谁先做什么、哪里需要验证及关键场面如何发生。不能先写一条通用情节，最后只加几句 OS 或把场次倒过来就当作叙事设计。

先选主要跟随的人，再决定关键节点观众知道多少：

| 信息关系 | 适合的观看乐趣 | 执行方式 |
|---|---|---|
| 观众与人物同时发现 | 调查、探索、主观困境 | 给双方同样可读的线索，让人物提出判断并用行动检验 |
| 观众先知道 | 悬念、喜剧、危险逼近 | 先展示危险或误会来源，再看人物如何接近、错过或化解；不必把一切藏成谜底 |
| 人物比观众多知道 | 策略、人物秘密、事后重释 | 先给可观察的异常行为和足够线索，揭示时解释其因果；不靠独白故意否认人物明知的事实 |
| 不同人物各知一部分 | 谈判、群像、关系错位 | 只交替呈现会影响当前决定的部分；交会时让信息碰撞产生实际后果 |

在故事推进中，让观众当前关心的问题得到进展：一个假设被验证，一次争取有了结果，一段关系出现回应。得到回应后，下一期待应由新局势产生。不要每个片段另抛一个无关谜团，也不要求每场都以悬念结束。

把开头提出的观看理由带进中段：开头靠人物敢做吸引人，中段就要看见他实际试、有人接招；开头建立暧昧，就让相处有试探、误读或回应；开头呈现特殊规则，就看人物如何运用并受到反馈。不能钩子之后退回长篇背景，直到结尾才恢复本片乐趣。剧情变化可以快，观众对“接下来在等什么”的把握仍应连续；前一期待得到满足、受挫或被重释后，再自然转向下一期待。

先决定重要信息在何时产生什么作用，再选顺叙、倒叙、交叉或主观讲述。想让观众担心，就把足以担心的条件提前给他；想让观众参与判断，就让区分解释的迹象可见；想在结尾重看前事，就让前面的行为当时也能成立。揭晓不只是把答案念出来：它应改变已经在进行的行动，或改变观众对此前付出、选择与关系的感受。若提前知道答案，过程只剩等揭晓，应深化实际互动，而不是再藏一个答案。

把人物情绪与观众体验分别想清：人物自信，观众可能已看出破绽而替他担心；人物仍在掩饰，观众可能已察觉双方有意而期待谁先开口；人物掌握了办法，观众可以带着期待看他漂亮地完成。需要这种参与时，先给足判断条件，再让行动接近一个可预期却未必如愿的结果。吸引力可以来自“知道可能发生什么，想看他怎么应对”，不只来自藏住答案。

情绪起伏来自刚发生的事如何改变期待：以为被拒绝，实际得到一种更懂自己的回应；以为赢了，才看清这次胜利的具体影响。反应要体现此人如何理解，接着影响他说话或做事。喜悦夹着不安、尴尬中生出亲近、失望后仍有好笑的补救都可成立，不按固定悲喜顺序排情绪，也不靠配乐标签、突然重病或长篇牺牲史制造分量。

先让观众看懂当前人物关系、正在做的事和眼前阻力，再保留值得追问的未知。悬念可以隐去真正动机，不能连谁在向谁提要求都不清楚。新人物、专有名词与规则在影响行动时引入；需要前情时只给理解当前决定所需的部分，后续再补，不用开场介绍整部设定。

背景进入场面时，让它成为当前争取、试探、纠正或执行的一部分：有人把规则用于拒绝，另一人实际尝试后才知道限制；熟人用共同经历反驳此刻的误解。片头设定、预览摘要、人物心理注释和 Prompt 的目标层供制作理解，不等于观众已经看过；决定行为是否合理的物件来历、人物约定、当前目标及办法为何有效，必须落到正文实际可见、可听的依据中。用正在发生的交接、尝试或有意图的话语交代必要条件，不把这些条件只放在幕后说明中。先选观众需要理解的那项条件，让一次执行、受阻、明确标识或针对眼前要求的回答把它讲清，再让人物利用；只出现一个物件或标记，不自动等于交代了它的使用条件。无需演示全部世界规则，也可在揭晓时回收先前依据，不为解释增添整段教学。双方本来都知道的事，不为观众互讲履历；观众必须知道的条件，也不能仅靠人物心照不宣。切换场景、时间或视角时，保留能认清“谁、何时、为何到这里”的必要依据，情绪承接可以省去路程，不能省掉改变决定的关键事件。

倒叙先给值得追问的结果，再按因果补足过程；多视角的每次重看要提供新事实或新理解；回忆在当下事件触发并影响当下选择时使用。顺叙完全可以精彩，复杂结构不自动代表叙事更好。

公平性来自事实可复盘：人物所知与观众所见可以不同，但关键能力、证据、时空关系和世界规则不能在收尾时临时出现。能力名称相同不代表用途已经建立：会移动物件，不自动证明能改变人体；拿到一次许可，不自动获得另一项权限。将决定成败的适用范围、接触途径或限制，通过此前实际使用、受阻或必要话语让人看懂；可以提前交代，也可由人物作有根据但仍可能失败的尝试，不要求所有能力先做一次教学演示。作者已定的真相不等于人物已经知道；首次遇到的异常，要区分他实际观察到什么、据此猜什么、凭什么采用这个判断。需要辨认真假的关键发现，给能区分其他合理解释的具体反馈，不能只写“测出规则”便让人物知道整套机制；已知世界可用简洁的使用情境交代，不要求逐条实验。悬疑答案要解释主要线索；主观表达允许误判，不能把明确的虚假客观画面当唯一遮蔽手段。

构思抢答、回扣、试探或识破时，先找到被利用的信息实际出现在哪里、谁确实接触过，再写由它引出的回应。人物可以猜中，不能因说中了常见想法就自动证明他掌握秘密。回忆、多视角或时间重来按既定规则保留或改变记忆；未呈现、未交代来源的经历不能充当前一轮已经说过的话，也不能让没保留记忆的人知道被抹去的事情。无需另建信息表，沿实际叙述顺序连通这些依据即可。

用身体、道具、能力或装置解困时，按本片已定的物理或奇幻规则分清接触、支撑、牵引、固定各自改变了什么，以及触发位置、作用范围和保留状态；方法必须实际改变造成困难的条件，“托住、挡住、锁定、稳住”等结果词本身不提供作用依据。沿原规则再想一次，原来的阻力或对方办法是否仍会生效。若只是离开按钮、改变说法或换个位置，须确认它实际切断了哪项条件，不把未规定的限制临时当作胜负依据。只推演眼前有依据的应对，不穷举无关漏洞，也不为堵漏洞新增世界规则。

决定要改变观众哪一种理解时，查[认知变化的职责](剧作方法与类型库.md#认知变化先选择叙事职责)；确定使用重释后，再查[转折构造](剧作方法与类型库.md#转折与认知重释怎样有依据)。两者分别解决目的与构造问题。

高密度叙事时，先维持一条观众能跟住的当前行动，再让新信息改变它：给出可辨的条件，让人物据此判断，展示尝试及反馈，随后引向下一步。每项关键发现都需要观众看得见或听得见的依据；人物知道更多时，可以隐藏办法，但先让其异常行动可观察，揭晓时回到已有依据。不要连续抛新名词、身份和时间线，要求观众事后补全眼前正在发生什么。讲清一个转折不必重述整个前情，只补足让它成立的那一项差别。

### 六、把内在活动转成有职责的表达

人物心理要参与判断和选择。先想清楚“他怎样理解刚发生的事、想隐藏什么、准备怎么做”，再选择适合的表达。不是所有心理都要念出来，也不因画面能表达就排除内心独白。

| 表达方式 | 何时选择 | 如何落成正文 |
|---|---|---|
| 行为与表演 | 观众能从行动读出顾虑、欲望或态度 | 写他碰了什么、避开谁、改变了什么动作；必要时用简短表演提示说明矛盾，不用“眼神复杂”承担全部意义 |
| 对白与潜台词 | 人物正在影响另一个人 | 先确定试探、安慰、拒绝、交换或坦白的目的；对方根据听到的话作出回应，直白表达也可以有力量 |
| 内心独白 OS | 需要主观亲近感、策略理解、情绪反差、自我欺骗、喜剧节奏或独特语言 | 写当下具体判断、欲望或自我辩解，并让后续画面补充、验证或反驳它；可从开场采用，也可作为全片稳定视角 |
| 旁白/画外音 VO | 需要讲述、回顾、跨时空压缩、评论，或场外人物发声 | 明确是谁、在何时讲；区分讲述者判断、角色当下想法与场内实际可听声音 |
| 主观画面、想象与记忆 | 想法本身有视觉、声音或时空体验 | 明确主观段落的进入与返回，区分真实行动和心理预演；主观段落应改变对当下行动的理解 |
| 沉默与环境声 | 不说本身体现关系、决定或感受 | 让等待中有可追踪的选择或互动；到观众已经理解时结束，不以固定停顿秒数填满片长 |

OS 的可选用法：

- **表里反差**：表面镇定，心里计算退路；动作泄露紧张。不要把潜台词全部翻译一遍。
- **策略思考**：先作判断、执行、遇到反馈再修正；避免在行动前讲完所有步骤。
- **主观误判**：相信某个解释，遇到新事实后改变理解；独白是角色观点，不是客观保证。
- **喜剧自我评价**：心里把表现评价得很高，画面呈现其实际效果；后果继续推动场面。
- **情感自我防御**：人物给自己的行为找理由，行为显露真正愿望；也允许直接说出真心，避免所有人都嘴硬。
- **当下重释**：刚看到的行为推翻原有理解，用当下心声呈现判断变化；跨时空回顾改用明确的 VO，不在结尾补讲正文遗漏的关键因果。

声音与画面可以补充、反差、提前或延续。画面显示人物找钥匙，OS 可以交代“我得赶在他回来前离开”，而不只是“钥匙在哪”。直接重述画面只在需要节奏、强调或喜剧回扣时使用。内心话不必都短促或碎片化；长度服从人物语气、叙事价值和实际时长。

上表只定义表达职责，具体写法按作品分流：短剧读取[一段场面的对话与人声](剧作方法与类型库.md#短剧怎样写出一段有起伏的对话与人声)，把清楚的诉求、连续应对、情绪落点与实际兑现连起来；微电影／短片读取[对白与声音的整体组织](剧作方法与类型库.md#微电影与短片怎样让对白和声音构成完整体验)，按已选路径把主观体验、人物交流和实际事件相互组织。再取[已选题材与场景](剧作方法与类型库.md#按已选题材和场景调整说法)的适配写法。不根据时长或画幅重选类别，不把短剧都写成对怼，也不把微电影都写成沉默加旁白。

### 七、起伏、节奏与人物声音

先把重要节点想成具体变化：快成功时条件改变、失败后得到有效支持、外部胜利却暴露关系裂痕、一个小进展让人物敢于尝试。变化要使人物或观众重新判断接下来会怎样，而不只是把“平静、紧张、感动”换着标注。允许一次办法暂时有效、另一人物争回主动、合作带来新分歧；选择符合题材的变化路径，不强制低谷、翻盘、大反转全部齐备。

- 开头直接进入有意义的当下：正在争取的事、反常应对、鲜明人物行为、引人注意的讲述都可以；不限定异常、犯罪和倒计时开场。
- 从动作仍有必要的地方开始，从它产生结果的地方离开。省略已理解的准备、进门、坐下和同义解释；保留会改变判断的过程与反应。
- 构思对白时，按[对白与可传播台词](剧作方法与类型库.md#对白与可传播台词)确定当下说话条件、连续回应和人物口吻，并在整段场面中运用已选表达路径与题材场景写法。双方可以争取、回避、交换、拒绝或重新定义问题，也可共同解决困难；听懂之后如何继续、这段交谈有什么起伏和实际所得，需要一起想清，不能只保证每句接得上，最后仍像普通问答。
- 情感可以直接说，但要决定这句话正在争取什么、给对方什么此前没有的回应。行动已经清楚表明在意时，不再让双方轮流说明主题；结尾已有明确邀约、交接或告别后，后续细节应带来新的感受，不反复确认相同结果。余味也可来自不同时的反应或仍在继续的生活，不统一补一段点题独白。
- 人声、行动、听者反应可以并行；OS 不要求人物停住，VO 不要求画面改成空镜。按实际朗读与动作预算构思，不靠加速或静止填时。
- 人物口吻来自他注意什么、用什么词、习惯如何争取，而非给每人一个口头禅。金句由情境和人物自然产生，不要求每集凑一句传播文案。
- 具体时长、镜头与声音预算执行 `pacing.md`；本文件不另设统一秒点、反转数、独白占比或剧情评分。

一段对白的具体写法：先确定此刻要让对方答应、相信、暴露或改变什么；写出第一句话与同时进行的行动；让听者抓住刚出现的条件作出符合自身利益的回应；说话者据此换说法、换条件、行动验证或作出选择。最后让一次回应真正生效。可以有意回避、玩笑或沉默，但观众应看懂它在保护什么、试探什么或改变什么。不要为了每 1–2 秒有变化而强行打断自然句子。

例如同是“新人要求主管归还署名”，平直写法是“这是我的方案”“你别乱说”“你不能抢我的功劳”，三句只重复归属争执。若采用故事已经让投屏页面保留新人的署名，可以写：新人按住翻页器：“这页先别翻，右下角还有我的名字。”主管：“会后再处理。”新人看向同场参会者：“那就现在，大家都在。”具体物证、主管的拖延和新人把问题留在公开场合的办法，使下一句有了不同作用；随后必须演出署名是否被保留或更正，不能一句话便宣布全面胜利。人物说法可机敏、强硬、直白或柔和，但要符合其立场。短句负责接招，较长一句完成必要解释或袒露；不因追求锋利而把所有人写成连续抛金句，也不靠粗暴辱骂代替筹码与行动。

起伏要在正文中看见：某个办法暂时奏效，使观众期待成功；对方的有效回应或已有条件改变预期；人物利用已获得的信息继续争取；当前结果兑现本片乐趣。此关系可表现为胜负、亲疏、误判或笑点，不规定每场都走同一顺序。至少把本场选用的变化实际演出来，不只在说明中标“紧张、感动、高潮”。

### 八、系列连续性与一次成稿

多集构思先确定能变化的事件单元、长期欲望、持续对立资源，以及跨集关系或秘密。按每集实际展开的争取、发现、遭遇或关系阶段分配内容，再让它的结果改变下一集条件。一个任务可以跨集，各集也可以完成相互影响的独立事件；不能仅按准备、取用资源、实施的办事顺序划集，靠还没轮到主要场面拖住观众。筹备本身确有竞争、关系变化或过程趣味时可以展开。单元可以成功、失败、暂时搁置或改变目标，但本集要有可感知的所得，未来期待也须有本片相应分量；一项尚未执行的普通决定不会自动产生悬念，它需要在既有处境中影响人物真正重视的东西。

在总纲中先让各集的核心经历与连续影响成立，再逐集写正文；主线的完整发展不能只靠每集局部接话保证。已承诺的集数保留，在允许空间中深化真正不同的进展；确需改变规模按原确认规则处理，不自动缩集，也不靠让对手反复变笨、人物失忆或重复同一种误会撑集数。这里不增加分集卡、打分或逐集质检。

跨集变化要留得住：已经得到的技能、许可、线索、承诺与关系回应，应改变之后的选择；对手也会依据已经知道的结果应对。下一集的新任务可以放大原办法的用途，也可以碰到它的边界，不能靠失忆、无故撤销成果或同一种误会重置来续集。角色稳定的习惯与固定场所可以提供系列辨识度，事件的作用和相处结果仍需有变化。

写当前集前，只读取全局总纲、上一集实际结果与当前会用到的状态和伏笔。根据已经发生的事实落笔，不把未来设想当成现实；人物不能使用尚未获得的信息、能力、道具和信任。重要回收用前文已建立的条件完成。

一次写出当前授权范围内的全部场次、动作、人声和结尾。构思与写作中贯通人物所知、行动原因、时间空间、声音职责、承诺兑现与篇幅；用户另提修改时按原版本与确认规则办理。

通读时也看作品实际给了什么：最值得看的往来能否从正文具体指出；即使知道结局，其中的办法、人物反应或体验是否仍有吸引力；关键话语是否有此人的经验、明确对象与后果；重要段落之间是否持续推进期待，视听意图是否服务同一事件。只写“有张力、很感人、视觉震撼”不算正文证据。发现真实缺陷就修正受影响内容，不例行制造低质量初稿，也不靠再加一套字段证明优秀。

需要衔接下一集时，查[集间钩子](剧作方法与类型库.md#集间钩子设计方法)，先兑现本集，再建立下一行动理由。

### 九、从作品与生活材料迁移方法

是否检索、怎样选来源与何时停止，以 `planning.md` 的“创作检索策略”为准。短篇小说、剧本与电影可用来学习具体写法：找出人物追求、可见线索、第一次尝试、对方回应、选择和后果，再换成当前作品自己的人物、条件与事件。小说里的心理判断要转为可见行为、推动行动或显露人物意图的对白或已采用的主观声音，不能只把内心形容词搬进视频 Prompt。学习伏笔时，明确早先哪项细节在后面起作用；学习转折时，明确它为何由此前行动造成。可以借鉴同一物件前后用途变化、双方各有隐瞒、局部成功带来新条件等方法，不照搬人物、桥段与台词，也不规定每片都有大反转。下面是按问题选用的迁移示例，不是统一配方。资料区分访谈、作者自述、官方介绍与可读原剧本；访谈和简介不等于逐场分析，已读剧本不等于已观看成片，不把作品热度解释为单个技巧的功劳。

| 当前写作问题 | 资料中的创作经验 | 在本片怎样重新落实，何时不适用 |
|---|---|---|
| 开场只会吵架，关系只有敌友标签 | 《二十九》编剧访谈谈到事件开场，以及由对立关系转向暂时合作的构思 | 让一件正在发生的事要求双方回应；若选暂时结盟，明确共同任务和不同的成功标准，由协作选择产生亲近与分歧。不照搬原作关系或把所有女性故事都写成结盟 |
| 情节多但像多场拼贴，人物只为冲突服务 | 《再婚》主创强调人物逻辑，谈到能在一场完成的事件不必分散到多场 | 在同一事务里同时推动任务、性格和关系，下一应对来自刚才反馈；需要空间转换和时间跨度时仍可分场，不把“合并”写成一场长解释 |
| 职业、地方与人物缺少具体性 | 梨花颜创作自述从地方生活经验与人物细节谈故事 | 选择会改变应对的习惯、技能和资源差异；地方经验要核实并重新构思，不能照抄原例或只添加地名方言 |
| 配角像工具，剧本都长一个样 | 《执笔》编剧访谈谈到配角生命力、个人表达与制作条件 | 让配角按自己的任务回应主角，允许帮助有条件、拒绝有理由；故事选适合自己的乐趣，不从成功作品推导可复制公式 |
| 感情变化缺乏理由 | 《虚颜》《招惹》导演访谈谈到关系前史及相认场面的铺垫 | 倒推本次信任需要什么经历，让前文行动建立它并在后文回收；极短片无法建立长前史时，缩小关系变化幅度，不照搬救命相认 |
| 只有议题或段子 | 《大妈的世界》主创把日常行为、代际表达与具体冲突联系起来，也谈到借不同语域呈现说不出口的关心、让短暂失落回到喜剧行动 | 让同一行为或说法在不同关系中产生具体趣味，先让表层事件成立，再让意义显现；热梗要有此人此刻使用的理由，情绪变化要有新的回应。不要求喜剧最终催泪，也不据此让所有家人都反着说话 |
| 家庭人物只有标签 | 《家里家外》主创从共同生活与具体经验谈创作 | 找彼此需要却在钱、分工、照护或决定权上不同的人，让一件事务触发他们的办法；不把所有家庭都安排成先决裂再和解 |
| 微电影只有感伤回忆 | 《Stutterer》编导谈到首次线下见面的邀请打破主角安全距离 | 给内在困境一个当下要回应的事件，外部行动与主观声音一起推进；不照搬人物障碍、见面桥段或结局 |
| 动画只有外形变化 | 《Purl》官方资料呈现毛线角色与融入群体的故事 | 让身体或媒介特性参与资源、限制和选择；若变形与故事无关，就不因动画形态强加变形 |
| 台词前后不接，各自介绍信息 | 郑榕访谈强调由对方话语引起反应与说话愿望；John August 讨论谈话流动、信息传递及人物是否真正倾听 | 在写下一句时，确定此人听见什么、怎样理解、为何这样回应；通过回应调整行动或理解。不把生活闲谈原样照录，也不迁移舞台发声要求或作者的多稿流程 |
| 所有人像作者，换场景仍说同一种话 | 袁子弹谈人物话风区分与行动、语言合乎人物逻辑；张永新谈文白用语随场合和人物使用 | 根据经验、关注点、关系及公私场合选词和组织句子；不按职业身份机械分配腔调，不从戏剧化表达推导史实可以失真 |
| 不是直白点题，就是含蓄到听不懂 | Dee Rees 在 BAFTA 讲座中从说话后果与自我保护解释回避表达 | 想清人物为何不敢直说，用可理解的表层话题、动作和听者反应承载真实愿望；无需回避时就直说。不采用固定退让次数，不把含蓄规定为好对白的唯一标准 |

对白与叙述声音按两条路径分别取材。下表是对主创自述的迁移，不是完整作品分析；工具库中具体的场面组织、题材和场景写法是本 Skill 的创作推导，不把个别作品处理提升为行业通则。

| 表达路径与资料 | 采用的具体经验 | 在本片的落法与限制 |
|---|---|---|
| 短剧：梨花颜创作自述 | 短篇幅使主要人物、核心冲突、情绪与信息表达需要集中；人物差异来自具体生活细节 | 交谈尽早进入当前诉求，用与人物有关的细节承载有分量的回应；不移植固定亮点间隔、人物数量或台词字数，也不把所有短剧都写成冲突升级 |
| 短剧：《虚颜》《念念无明》《别跟姐姐撒野》制片人杜浩访谈 | 不同作品选择不同的关系模式、场面基调与台词风格；开场进入主线，背景在需要时补足 | 按本片要兑现的关系乐趣选择机敏、真挚、紧张或其他表达，当前事件让人物状态可见；不把“短剧”自动翻译为沙雕、互怼或古风甜宠 |
| 短剧：《悄悄地喜欢你》制片人访谈 | 从未必会公开的青春恋爱内在表达中寻找共鸣，并让角色作出观众想做而未做的行动 | OS 可让观众进入期待、自我防御与社交预演，实际交流和行动再给反馈；这是爱情项目的一种选择，不据此规定校园都恋爱、所有人物都要内心吐槽 |
| 微电影／短片：《Stutterer》编导 Benjamin Cleary 访谈 | 外在表达困难与流畅内在声音并置，线下邀请使原有安全距离面临改变 | 让主观声音有独特语感，并与当前要应对的事件相遇；不复制人物障碍或约会故事，不规定独白必须反差，更不采用访谈中的多轮修改流程 |
| 微电影／短片：《Bad Timing》导演 Pavel Kling 访谈 | 叙述者先建立对行动的预告规律，人物后来偏离它，使旁白与行动的关系本身参与叙事 | 若选此形式，先使讲述规律可辨，再让真实行动改变它；其他项目可用同向、补充或时间压缩，不强制不可靠叙述、声音反转或冷静旁白 |
| 微电影／短片：《Raspberry》导演 Julian Doan 的 Sundance 访谈 | 在写作中考虑速度与可见反应；同一事件里家人的感受与从业者办事话语形成复杂反差 | 从关系与当下职责区分说法，让情绪由具体碰撞显现；不套用死亡题材、悲喜调性或该片对白占时，不从“短片”推导慢与少言 |

下面的补充资料用于深化事件、人物应对和整段交谈。先按实际问题选用，不要求每次写作重新读取所有来源。表中“本片落法”是本 Skill 的迁移判断，不冒充主创原话。

| 具体缺口与资料性质 | 资料实际提供什么 | 本片怎样采用，哪些不照搬 |
|---|---|---|
| 构思只有题材和结尾：[Tony Gilroy 的 BAFTA 编剧讲座记录](https://www.bafta.org/stories/tony-gilroy-screenwriters-lecture/)，2013，主创讲座摘要 | 从具体人物、时刻或处境发展故事，强调对人物行为的理解及研究 | 从具体核心推演人物办法与反馈，代表场面需有实际过程；只借鉴创作原则，不套其长片结构、写作习惯或固定候选/改稿流程 |
| 生活细节只作装饰：[《家里家外》总制片人完整问答](https://www.jiemian.com/article/12537904.html)，2025-03，主创访谈 | 采访亲历者取得有行动过程的生活事件，并按家庭表达决定哪些过程详写、哪些作为背景 | 从材料里取人物可用的办法、接触条件和关系反馈；按本片主要乐趣取舍。该剧弱化创业过程不代表职业故事也应省去专业操作；年代、方言与权限另核实 |
| 主角只有受苦与被救：[《引她入室》编剧张静思访谈](https://k.sina.cn/article_6105713761_16bedcc6102001c94m.html)，2024-09，主创访谈 | 以人物的胆识和对亲近者的具体了解作为解困资源，尝试绕开外援与隐藏身份的惯例 | 把已建立的经验转成能被对手回应的办法，呈现如何奏效；不复制婚姻复仇桥段，不采用访谈中容忍逻辑瑕疵的主张，也不据此强制金句或多重反转 |
| 把复杂当悬疑：[《背刺》总制片人石小琳访谈](https://www.thepaper.cn/newsDetail_forward_30051901)，2025-01，主创访谈 | 明确谈到极短单集的理解成本，以及简明关系中亲情、欲望与占有的碰撞 | 悬念留在值得验证的事实或动机上，眼前谁在争什么保持清楚；人物可以有复杂愿望，不靠新增关系名词增加难度。不采用“第一部”等宣传判断，不据访谈声称读过全剧 |
| 喜剧都依赖末尾翻转：[陈翔接受界面新闻采访](https://www.jiemian.com/article/782210.html)，2016，主创访谈 | 讨论从素材中寻找创意点，也承认反转呈现趋同，需要尝试其他表现方法 | 从日常观察找可发展的情境，重建独立的人物、行动与结果；可用执念、配合、语域错位或熟悉规律的变化，不搬运段子，不采用旧平台数据与更新频次要求 |
| 对白能接上却不深入：[《The Event》公开拍摄稿](https://assets.scriptslug.com/live/pdf/scripts/the-event-2022.pdf?v=1729115014)，Hugo De Sousa，PDF 12 页含封面，原剧本阅读 | 请求逐步显露更深的回应需要；听者不断换理由，旁人的反应又改变局面；结尾把先前的说法回落到新的行为 | 借鉴“说出的请求、真正想确认的事、听者愿给的回应可能不同”，让试探与拒绝产生新后果；不复制食物比喻、人物关系与结尾，不按其对白长度推定本片时长 |
| 动作重复像填时：[《Storm》公开拍摄稿](https://assets.scriptslug.com/live/pdf/scripts/storm-2019.pdf?v=1742491405)，Will Kindrick，PDF 17 页含封面，原剧本阅读 | 重复经过的空间先是被动遭遇，后来成为人物带着目的、利用既有经验重走的过程；观众因识得规律产生期待 | 同一行动再次出现时，改变人物的知识、主动程度与运用方法；不复制水中穿越设定，不把反复回访、长设定开场或最后巧遇当必需结构。只采用该局部机制，不为其全部因果背书 |
| 谈话只交换表面信息：[《The Phone Call》Mat Kirkby 访谈](https://londonist.com/2015/02/london-shorts-qa-oscar-nominated-director-mat-kirkby)，2015-02，主创访谈 | 从热线志愿者经历中得到灵感，让倾听者逐步理解来电者最初未说清的需要 | 对方根据回答中真实出现的缺口与反应追问，交谈逐步改变理解和办法；不把所有人写成隐藏真相，不把剧情处理当专业热线程序，也不迁移其制作周期 |
| 高概念压住人物说话：[《Everyone Does It》Craig Ainsley 问答](https://filmshortage.com/shorts/everyone-does-it/)，主创访谈 | 把科幻放进熟悉的日常处境，以有限视角和有共同历史的朋友交流形成悬念与喜剧 | 让读者先懂眼前相处，再随人物发现异常；朋友的接话可熟稔、抢话、误补，仍各有理解和行动。不照搬设定，不要求即兴、长镜头、重叠说话或保留同一种谜底 |

公开拍摄稿中的停顿、镜头指令、修改版本和外文 OS／VO 用法是原作品文本的一部分，不自动成为本 Skill 的流程、节奏或标记规范。阅读原剧本用于观察完整前后关系，不能从一句台词抽出通用金句公式。上述几分钟至十余分钟作品中的机制，只能按本片容量重新构思，不把整条故事压缩搬进十五秒或三十秒。

## 因果、事实与表达边界

场次或场景序列应体现人物目标、采取的办法、外部反馈和局势变化；短场可以只承担其中一环。反应、余味、观察和心理也可有叙事价值，只要改变观众理解、人物关系或后续行动，不强制每场都争吵、失败或逆转。

关键身份、能力、指控、秘密和世界规则要有来源、铺垫或验证。角色可以撒谎和误判，OS 可以带偏见；正文需区分角色所信与故事事实，不能在结尾临时补万能能力或让对手无理由认输。情感不强制用物证证明，心理变化可以通过有分量的行为、交流和主观表达成立。

让人物利用规则解困时，把影响成败的使用条件保持一致：谁能操作、需要接触哪里、停电或隔离后哪些功能仍有效，按当前行动需要写清即可。情境改变后沿用仍成立的条件，不让设备或能力在下一步无说明地换一种用法；差别若决定胜负，应先让观众能辨认。普通道具不必解释原理，魔术也不必揭底；只交代理解当下办法与结果所必需的条件，不借此增加操作说明或新的设定文件。

涉及真实品牌、人物、历史、专业流程或时效事实，沿用已核实来源，未知内容不冒充事实。题材与受众策略读取相应参考库，不根据人口标签机械决定人物、节奏和结局。

## 按项目规模合并剧本文件

完整模式的用户可读剧本按以下结构保存。合并的是文档，不取消项目级故事确认、当前集剧本确认或逐集顺序；单集同一正文只问一次，按同一实际回复记录两个作用域。

| 项目 | 用户可读正文 | 内容职责 |
|---|---|---|
| 单篇或单集 | `episodes/ep_1/01_剧本/剧本_完整剧本_ep_1.md` 一份 | 片头写必要的故事与设定，正文一次写完整；同一文件同时承担项目故事和本集执行依据 |
| 多集项目级 | `01_剧本/剧本_全局设定与分集总纲.md` 一份 | 覆盖全剧主线、人物与关系、规则、主要伏笔、全部分集推进和最终结局；不提前批量写各集详细对白 |
| 多集当前集 | `episodes/ep_N/01_剧本/剧本_完整剧本_ep_N.md` 每集一份 | 写全当前集场次、动作、全部人声与结果，必要承接说明放在同一文件内 |

多集总纲保留“全局故事圣经”“分集推进总纲”两个一级章节。全局故事圣经包含足以读懂开端、发展、关键转折、高潮与结局的连贯故事走向，不再另写一份同内容的全剧剧本。分集推进写每集要完成的事、策略与结果，以及前后承接；不能只有标题或一句话题材简介。

单集不另建总纲、项目设定卡、项目事实文档、梗概、人物状态、关系矩阵或场景清单文件。多集也不另建上述重复文件。必要人物关系、场景、声音主体和初始状态写入正文中的“故事与设定”或总纲的相应段落，不把旧五份文件完整搬成五张长表。用户原文、事实状态与来源沿用规划的 `source_lock` 和 `source_manifest.json`；新增有效事实按原事实锁规则更新，不建立第二套原始要求。

机器侧仅保留下游确实使用的 `01_剧本/project_script_manifest.json`、`00_制作控制/project_data_card.json` 和当前集 `script_contract_ep_N.json`。它们从正文和已确认事实提取执行信息，不复制完整叙事，不扩展创作评分字段。单集的项目索引和分集合同引用同一个正文文件；具体路径、哈希与字段见 `manifests.md`。

### 项目确认与逐集细化

- 多集先完成并确认全局总纲与数据卡基线，再按 `ep_1 → ep_2 → …` 逐集一次完成当前集成稿；不提前写未来集详细剧本。当前集到达用户指定的交付终点并交付后即可进入下一集；若还要继续本集下游制作，则先取得必要创作确认，不为纯剧本终点另问收尾认可。
- 单集一次完成唯一完整剧本及本集合同，向用户展示一次；用户对同一版本明确认可后，项目级与 `ep_1.script` 两个作用域记录同一实际回复并一起生效，不再展示相同正文问第二遍。修订了内容则按实际变更确认。
- 项目级和分集级都交付完整内容，不出现“略、待补、后续依此展开”等占位。没有完整写出的场次和人声，不能交给分镜补剧情。
- 轻量剧本目标一次写全唯一正文，不补完整模式合同或数据卡；分镜/视频目标把完整场面、动作和全部人声直接写入十五列主表，不再复制独立剧本。预览概括完整事件、关键回应与结尾，人声展示按 `planning.md`；当前批次授权后忠实编译已展示内容，未来批次到其确认时展示采用原文，不把八行概览当作全部人声载体。没有视频目标不编 Prompt 或询问视频生成。

## 分场正文格式

剧本头写标题、已确认呈现类别/题材、篇幅与必要基调。单集正文前只放影响理解和制作的“故事与设定”；多集本集只补开场承接与实际新增项。视觉方向沿用已确认文字合同，不强制大师风格、三幕式或钩子结构。

- **集号与场次**：`第1集`；表头如 `1-1 旧公寓客厅 日 内`。地点与对应 SCN 名称一致；创作空间内确需的场景统一纳入正文与数据卡。超出已确认地点、规模或剧情边界时按原变更规则处理。
- **人物**：列出实际出现者及必要场外声音主体。
- **动作**：以 `△` 开头，写可见行动、必要空间、物件和结果。普通流程可概括为“二人封好最后一箱”；手指如何压胶带、物件怎样逐一收回，只在其带来新反馈、性格意味或叙事结果时展开。可拍不等于写全每个微步骤。镜头、焦段与运镜留到分镜；不把“他感到复杂”当作已经呈现心理。
- **表演提示**：可用简短括号说明动作或话语的心理意图，不发声；观众必须理解的心理需进一步选择行为、台词、OS 或主观画面表达。
- **对白**：`角色名：完整台词`。标点表达阅读语气，人物间有实际回应，关键指代能从上下文辨认；必要的动作和听者反应写在相应位置，不用旁注替两句无关的话补逻辑。坦白、安慰和共同解题均可，不强制句句攻防。
- **内心独白**：`角色名OS：完整文本`。按叙事价值主动选择，可建立人物声音、策略理解、情绪反差、主观误判或喜剧节奏，不限于“画面无法表达”时才用。
- **旁白/画外音**：`角色名VO：完整文本`，明确是叙述、回顾还是场外实际发声；与 OS 的时态、信息范围和可听对象分清。
- **主观段落**：明确标“想象”“回忆”或“主观听觉”及返回当下的位置，防止分镜误编为客观事件。
- **声音执行**：全部应发声文本实际写全；OS/VO 绑定主体、情绪、覆盖动作或场次，画面人物不做对应口型。合同中的 `speech_lines.type` 使用现有枚举，不把表演提示编成人声。
- **上屏文字**：只在故事确需时写清准确内容；不自动添加逐句字幕、BGM、黑屏和章节牌。

### 用户台词与人声闭环

台词三层文本的来源与转换统一执行 `delivery.md`；用户原文始终按 `source_lock` 与 `source_manifest.json` 保留。未获改写许可时，采用文本须逐字、按原顺序保留用户原句；获准精简后，完整展示采用稿，再按视频交互 Ref 取得生成确认。不得为节奏擅自改写；固定时长与全文无法兼容时，按该 Ref 明示取舍。

每条人声从正文提取至现有合同，绑定 `voice_id`、类型、原文和逐句表演意图。画面与声音可补充或反差，不要求只讲画面不能表达的信息；去掉没有作用的复述。朗读与动作预算见 `pacing.md`。

## 原创完整成稿示例

下列均为本 Skill 的虚构原创示范，非引用作品原剧本。展示不同的观看机制和完整结果；时长是写作预算，未宣称已完成生成验证。只读适合当前任务的例子，正式项目不得照搬人名、情节或台词。示例省略项目 JSON，仅展示完整剧本文字。

规则喜剧看例一，证据验证看例二，关系与心理回应看例三，主观讲述看例四，连续动作与协作看例五，有代价的关系选择看例六。按当前问题选读，不把六例的结构或结局拼成统一模板。

### 例一：30 秒动画喜剧《诚实门》

呈现：动画/卡通短剧；题材：搞笑，家庭关系为辅助。故事与设定：父亲买了“说真话才开门、一次过一人”的智能门，想知道儿子周末去哪。门只判说出的话，不读取想法。人物：阿团、父亲；场景：家门口。

第1集

1-1 家门口 日 内/外

人物：阿团、父亲、门禁VO

△阿团背起包。父亲按下门上的验证键，门亮起红灯。

门禁VO：说真话开门，一次一人。

父亲：去哪？

阿团：图书馆。

△门不动。阿团把包挡在胸前，父亲抱起胳膊。

阿团：……见小美。

△门亮绿灯。阿团跨出去，门随即合上。

△父亲立刻拿起外套，按住开门键。

父亲：我就下楼倒垃圾。

△红灯亮起。阿团回头，看看父亲空着的双手。

阿团：垃圾呢？

父亲：我……想跟着看看。

△门亮绿灯。父亲迈出半步，阿团把门边垃圾袋递到他手里。

阿团：这回顺路了。

△父亲低头拎好袋子，跟着阿团出门，不再偷偷躲在门后。

创作选择：先示范规则，再让监督者受同一规则约束；儿子把父亲的隐瞒改成公开同行，结尾回收“倒垃圾”。不依赖身份反转、秘密反派或煽情总结。

### 例二：60 秒职场悬疑《后半句》

呈现：AI 真人/数字人短剧；题材：校园职场中的职场，悬疑提供信息机制。故事与设定：林夏领取备用金后转交李经理，交接时拍过签收单，并发语音确认；负责人主持本次款项核对。场景：会议室。正文让完整语音、原件和保管责任依次起作用；不是司法或劳动处理示范。

第1集

1-1 会议室 日 内

人物：林夏、李经理、负责人

△手机里传出林夏的声音：“钱是我拿的。”李经理把离职书推到她面前。文件夹下露出黄色签收单的一角。

李经理：签字，这段就不交了。

△林夏伸手去拿黄色单据。李经理用离职书盖住它，把笔放进她手里。

林夏：你让我认钱，为什么给离职书？

李经理：不签，就按这段报。

△林夏放下笔，打开交接当天的聊天语音。

林夏VO（完整语音）：钱是我拿的，按你要求全交给你了。签收单我拍了照，你确认一下。

△负责人伸向离职书的手停下，转向李经理。

负责人：后半句呢？

李经理：她手机里的，谁知道改过没有。

△林夏打开紧随语音发送的照片：黄色签收单，李经理的签名。她把手机放到露出的黄色纸角旁。

林夏：那就看你手里的原件。

△李经理合上文件夹往回收。负责人按住文件夹的远端。

负责人：今天就是核交接。留下对。

李经理：我只是暂时保管。她经手的钱，让她先认，有什么错？

△林夏抽出被压住的离职书，放到一旁，把笔推向文件夹。

林夏：我认领取。你认不认接收？

△负责人摊开原件，核对照片上的日期、金额和签名。李经理的手压在签名旁，挡不住其余两人正在看的内容。他松开手。

负责人：领取、接收分开记。林夏领取，李经理接收保管。后续往下查。

△他将原件留在核对材料中，在本次核对记录的接收保管一栏写下李经理姓名，把笔递给李经理。

△李经理看向离职书。林夏将它推回他面前，自己的手机仍放在签收单旁。

林夏：你说的，先把经手的认清。

△负责人等着记录确认。李经理接过笔，落在接收保管一栏。

创作选择：逼签时遮住的纸角建立原件位置；完整语音使原指控失去单一解释；经理质疑手机材料，反而引出现场原件；收回文件夹暴露其不愿核对，负责人依据已建立的核对职责留住材料；主角不接受“领取等于一直保管”，把对方要求认清经手的说法用于区分责任。当前回报是停止这次逼签并实际记录接收保管人，不宣布经理已经侵占款项或获得法律结论。人声、取放与听者回应并行，时间容量遵循 `pacing.md`，不靠异常加速或逐句停顿。

### 例三：75 秒家庭微电影《联系人》

呈现：微电影/短片；题材：家庭现实。故事与设定：女儿小岚刚搬走，曾因母亲过度干预争吵。母亲独自到社区报名初学者游泳课，正在填写紧急联系人。人物：母亲、小岚、报名员；场景：社区报名处、女儿租屋。

第1集

## 写作时贯通叙事与可拍性

下列方法直接用于构思和一次成稿，不另安排剧本阶段检查、打分或诊断改写。按观众实际获得的声画顺序组织正文，不把片头设定和内部说明当成已播放内容。

- **整片讲什么、为何值得看**：当前人物、所争之事和主要观看期待是否可懂；除结尾创意外，中间是否已有具体的交锋、相处、操作或发现，符合本片选择的类型乐趣；结果是否回应同一件事。
- **人物为何继续、局势怎样推进**：关键行动是否符合此人所知、诉求和资源，对方是否有自己的理由；前一结果是否改变后一步，关系与情感变化是否有实际经历支持。换地点、换物件、提高音量不能自行证明剧情丰富。
- **观众能否跟上**：解题所需的条件是否实际进入正文，人物如何获得信息，指代和时空转换是否可辨；位置、方向、接触、持物与能力状态是否承接。保留有价值的未知，不省掉理解眼前行动的前提。
- **话语和心理是否属于此人此刻**：对白是否适合关系与场合，接住刚才的言行；关键接招、识破与回扣能否回到正文中的实际信息来源，整段是否有实际所得与起伏；OS／VO的主体、时点和可听范围是否清楚，主观表达是否与事件相互作用，而非替作者总结。
- **全片是否利落、关键处能否读清**：沿实际动作与台词推演开头、中段和结尾，区分真实并行与先后依赖；是否用准备、重复问答或反应拖长前面，再把解题、兑现和多个回扣挤到尾段。快慢执行 `pacing.md`，不能用字数少、镜头多或写了时间标签代替观看容量。
- **结果、承接与交付是否完整**：主要期待是否兑现，当下结果和必要反应是否清楚，结尾是否仍在重复完成同一职责；跨集所得能否保留，后续问题是否来自已有后果；现有合同是否忠实提取正文并遵守用户事实与已确认范围。

AI 生成边界应影响表达方式，不应把所有内容改成静止、纯对白或慢动作：复杂动作可拆成空间清楚的短链；多人场面明确主行动者和各自反馈；关键信息用足够可读的行为、声音或道具承接；对白、OS 与反应并行时标清声音覆盖。风险无法在已确认边界内处理时按原流程返回对应上游，不擅自换模型或新增付费重生。

不新增阶段结构检查、代码审美评分或自填 passed。用户要求修改时，执行下节，不影响一次成稿的默认方式。

## 稳定设定与数据卡

本节仅适用于完整模式。轻量模式不创建项目数据卡，内部构思仍保持人物、空间、物件与声音一致，随后进入内部十五列分镜。

完整模式正文完成后，按 `manifests.md` 提取角色、SCN 场景、关键/复现 PROP 道具和 VOICE 声音主体，并形成 `project_data_card.json`。数据卡承接可供下游引用的身份和状态，正文负责剧情意义。

- 人物：年龄阶段、类型、可辨身份、体型、固定音色；服装、伤痕、伪装等变化标明起止场次与剧情原因。不同人物不必都具备创伤和成长弧。
- 场景：实际使用的空间及影响行动的门窗、通路、固定物件；需要共享布局参考的场景按 `assets.md` 处理。不先凑场景数或预制所有昼夜版本。
- 道具：固定外观、尺度、持有者、位置与关键状态；一次性物件是否升级为 PROP 按资产规则决定，不扩大资产范围。
- 声音：同一角色的出镜对白、场外发声与 OS 沿用其固定音色；独立叙述者另设声音主体。锚点不统一锁慢语速或长停顿。
- 关系与信息：本集合同只提取正文确实出现的关系变化、角色所知和伏笔回收。无关关系不填长表，不虚构未发生的变化。

后续分集只引用稳定身份和当前状态，补实际变化。设定与正文有冲突时先厘清事实及影响范围，再同步源文件、数据卡和合同；不允许两套剧情分别演化，也不假定未来资产已生成或 approved。

## 机器合同与阶段输出

本节的剧本索引、数据卡、分集合同和两级剧本确认仅适用于完整模式。轻量按本文件开头的目标分支和 `control-contracts.md` 衔接，不进入下面的完整模式状态流。

路径和 schema 见 `manifests.md`；提取时只读统一目录、`project_script_manifest.json`、`project_data_card.json`、项目索引的当前单集条目、`script_contract_ep_N.json`，以及实际用到的来源、日志、确认与状态条目。亮点的现有字段说明见[亮点策略合同](剧作方法与类型库.md#亮点策略合同)，直接写入现有项目规划与分集合同，不另建亮点文档。先写正文，再提取数据卡与合同，现有 JSON 只承担下游执行和追溯；不再独立交付梗概、状态表、关系矩阵和场景清单。

完整模式多集先展示全局正文并取得项目级确认，随后才开始当前集详细剧本；若还需下游制作，本集正文与合同就绪后展示并取得本集确认。单集继续制作时同时完成唯一正文与本集合同，只展示并确认一次，同一真实回复分别记录项目级和本集作用域；纯剧本终点交付正文即结束，不为收尾等待认可。不得伪造确认或因合同晚提取而再问相同正文。阶段不运行独立 lint。

聊天只给必要的故事摘要、亮点与结尾说明，提供对应正文入口；不展示内部 JSON、哈希、校验统计和路径堆，不重复粘贴整篇剧本。阶段确认、逐集顺序、视频批次、强制委派与媒体交付仍执行原控制合同。
