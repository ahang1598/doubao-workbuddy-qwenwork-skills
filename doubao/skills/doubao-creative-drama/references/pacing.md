# 短剧事件与节奏合同

本文件是默认节奏、事件密度、镜头数量基线和对白预算的唯一权威。规划、剧本、分镜与 Prompt 撰写共用；这些要求不新增用户确认门；模型、方案选择与批次授权读取 `interaction-ask-video-clarification-ref.md`，委派、依赖调度与交付读取 `delegation.md`。

## 默认与例外

普通短剧默认利落推进。快的是人物应对与信息变化，不是所有动作都加速。对白可以快速攻防，悬疑等待期间也要增加线索、风险或误判；不能因为归为“对白情感”或“微电影”就自动放慢。

默认采用剪辑叙事。只有用户明确要求慢叙事、长留白或刻意舒缓节奏时，才采用对应节奏；只有用户明确要求一镜到底时，才采用真正一镜到底。“微电影”、导演名字、台词多或模型执行困难都不改变这些默认选择。普通镜头可以连续数秒，通过人物行动、对方回应和信息变化推进；一个数秒的连续镜头不等于整段或整片一镜到底。一镜到底与慢叙事是两项独立选择：用户只要求一镜到底时，仍按利落推进组织内容。

沿用清单的记录方式：默认 `pacing_profile=brisk`；用户要求慢叙事时为 `deliberate`，例外依据在规划和相关 SEG 的 `pacing_exception` 保存用户原话与理由。`density_profile` 只描述内容机制，不提供密度豁免；记录必须反映真实判断，不能靠改标签绕过要求。

## 先事件，后秒数和镜头

1. 先列因果节拍：当前局势 → 人物采取策略 → 对手/环境反馈 → 证据、关系、风险或选择改变 → 下一步被迫行动。一个核心冲突应产生多次有效推进；单一核心转折不等于整段只做一个动作。
2. 开头从正在发生的具体事件进入，默认首个 1–2 秒让观众辨认一次争取、阻碍、关系错位、异常或有趣行动；接着立即给人物的应对及其反馈。不先铺人物履历或连续气氛镜头，也不要求两秒内讲完背景或完成一次反转。用户已指定开场时，在该开场内落实可理解的行动与期待。
3. 默认尽量每 1–2 秒出现一次有效变化。有效变化指与当前事件有作用关系的行动、反馈、信息或情感发展：人物提出可回应的条件、尝试有依据的办法，对方接受、拒绝或附条件，观众看见影响判断的差别，或人物的反应使关系与下一步选择更清楚。这些变化可以逐步完成同一次交锋，不要求每次都推翻判断、转移主动权或改变结果。几个相连的变化共同推进办法、风险、关系或当前结果；若连续几个变化后仍在重复同一种争取、观众仍只知道同一件事，就深化事件，不继续拆动作。1–2 秒是默认内容安排目标，不是逐秒配额、切镜间隔、反转频率或生成精度承诺；必要辨认、表演和留白按下文展开，不为补足间隔添加事件。
4. 拿起、转头、走近、皱眉、呼吸、焦点移动和摄影机推拉本身不算有效变化；必须说明它对当前行动、判断、关系或体验有什么作用。例如转头发现门外来人，使正在谈判的人改口，才是发展；只换角度重复同一表情不是。一个动作可以由多镜共同呈现，一个镜头也可以连续发生多次变化，不按动作步骤或镜数计算剧情丰富度。
5. 删除同义解释、重复试探、重复反应和观众已理解的动作准备。证据、反应和结果可以由多个镜头共同完成一条因果链，单镜不必从头演到尾。
6. 给每镜一个主要观察职责，再分配时长；动作、对白和听者反应可以并行，声音可以跨镜。需要延长时，应有尚未完成的行动、辨认、情绪或环境体验需要呈现；按实际内容展开，不要求同时增加危机、反转或新事件。必要观看完成后及时离开，不靠重复动作和停顿凑满时长。

例如，“她看门 → 犹豫 → 伸手 → 停住 → 推门”仍然只是在完成一次开门，换五个景别也没有丰富剧情。“门内有动静 → 她谎称离开 → 对方开门暴露 → 物证推翻她的判断 → 她合门反制”才让前一件事推动后一件事。关系喜剧也可快速推进：两人都把最后一块蛋糕让给对方 → 同时收手后才发现都想吃 → 一人提议平分却切得偏 → 对方拿走小块，把大块留下当作明天请客的条件。这是相处与意图不断变化，不需要危机或揭密；具体写法由当前人物决定。

内容少时，在适用确认前先补故事，不把用户一句话当作整片全部事件。沿当前目标补出有用的尝试、回应及后果：刚得到的信息使人物换办法，刚作出的选择改变另一人的行动，已经露面的资源在后面被使用。每次变化接住前一步，不靠不断引入陌生人、规则和秘密增加数量。已经确认的内容只能在允许范围内展开，关键剧情不足仍返回相应阶段，不能在视频 Prompt 临时重写。

信息丰富度可以来自同一时刻的互补内容：人物继续争取一把伞时，保护简历或蛋糕的动作同时显露其理由；看见这个动作的对方调整做法，下一次推进自然产生。当前关键发现保持一个，另一层内容要容易辨认、为当前行动服务；不要让无关小动作抢注意，也不要求每个镜头同时塞满多层信息。

写出来仍然慢时，若目标未出现，就从正在争取的行动进入；若人物一直等解释，就让尝试和回应发生；若事实已说明，就推进它的影响；若结果已落定，就结束或进入真正的新局面。把这些选择用于写作当下，不新增节奏检查。镜数增加、台词变短和语速变快不能替代事件发展。

对白戏也用同一判断：例如“提出分手 → 对方拿出早已签好的协议 → 她发现日期在自己失业之前 → 她收回解释，要求先分清债务”。台词改变筹码和决定，不是两个人轮流解释同一个情绪；不要把悬疑示例当成所有题材的固定结构。

## 变化怎样相连并让观众看懂

在构思和分配时长时，沿实际观看顺序处理下列关系，直接写进正文及已有分镜，不新增逐秒表、评分或确认步骤：

1. **先确定当前问题**：本场谁要得到什么、眼前什么在阻止他。让首个行动交代这些关系；背景在影响下一步选择时再引入。观众可以不知道真实动机，但应知道人物眼下在做什么。
2. **从反馈接下一步**：人物提出要求后，对方接受、拒绝、附条件或转移；人物利用刚听见或看见的内容继续。也可先给观众一项人物尚不知道的事实，但它必须即将影响当前行动。不得为达到时间目标突然增加无前因的人物、危险、规则或秘密。
3. **每次突出一项主要理解内容**：需要辨认物证时，不同时介绍新人物、解释新规则并播另一段关键对白。先让观众找到对象和差别，再看人物如何利用它。声音可以跨镜，台词可以覆盖操作；并行内容应互相补充，不能争夺注意。
4. **把变化积累成后果**：一次试探暴露限制，下一次利用限制；一次让步换来合作，也带来新条件。主要期待需要在中途得到实际进展、趣味或回报，不能把所有精彩集中在最后一次揭晓。成功、亲近和默契同样可以推进，不必每轮失败。
5. **过载时先减负**：先删同义解释，省略观众已知的准备，减少同时出现的陌生对象，或用当前行动说明条件。必要信息仍来不及辨认时，给它足够时间；不以异常加速、无依据省略或继续加镜解决。

### 局部展开、环境镜头与留白

关键证据辨认、从听见到作出选择的表演、笑点识别、空间定位及有价值的环境体验，可以超过 2 秒。安排时想清观众需要看见或感受什么，理解或体验完成后及时离开；不要求为了保住间隔再插入一件事。环境镜头可以让逼近的脚步、逐渐被遮住的光线、人物离开后的空间关系继续发展，也可作短暂的审美停留或段落间缓冲；不要每次换场都重新铺气氛，或用环境小动作掩盖整场没有内容。

局部展开不自动改变整片利落推进的默认。用户要求舒缓时可扩大停留与展开；用户要求一镜到底时可在连续行动中迁移观察重点。二者仍需因果和可理解内容，不用变化数量衡量其质量。

## 开头、中段和结尾怎样保持推进

- **开头直接入事**：从递到一半却被拦下的物件、正在失败的尝试、答非所问的接招、已发生的规则异常等当前事件中选真实入口；构思或剧本阶段从当前采用且符合用户限定的剧情选择，分镜与视频阶段继承已有采用依据，不为开场硬添危机或绕过原有确认。所需空间关系随行动建立，不能先慢推场景、再慢推人物、最后才开始做事。第一个问题被看见后，立即接人物采取什么办法及其反馈，避免钩子之后重新介绍背景。
- **中段连续接招**：沿“这一步造成什么 → 人物因此怎样改做 → 又改变了什么”推进。相同意图的第二次展示只在加码、失败方式或判断确有变化时保留。人物可以边做边说，听者可以在话语中途作出选择；不让每句话之后都依次停顿、反应、转头再开始下一步。
- **结尾兑现后及时离开**：先让决定性办法、结果及必要反应看得清，再在选择生效、关系改变、笑点落定或具体悬念成立处切出。结果与反应可以同框、重叠或跨镜接续，不默认逐项另加时间。不自动追加凝视、慢拉远、空景、总结旁白或固定时长的稳定尾帧；悬念也要先完成当前一轮变化，不能靠停在未发生的动作前拖住。
- **查找空耗时间**：逐镜说清这一段时间内何时发生了行动、反馈、辨认或决定。尤其在设计持续约 3 秒及以上的单镜时：若只能写“保持表情、缓慢推近、等待下一句”，就压缩、与有效行动并行或重新分配覆盖；不能只换角度把同一空耗拆成几镜。固定机位中连续交锋、关键操作或逐渐变化的反应可以保留，依据是具体发展，不是摄影机是否移动。此项是时间分配方法，不是所有镜头的时长上限。

## 有效覆盖与切镜选择

节奏还要有注意与能量的变化。围绕主要兑现，判断哪些往来需要连续接招、哪些过程可以省略、哪项证据或反应必须给观众辨认时间；在既定默认推进速度内形成压缩、展开和落点。不要把所有镜头、台词与音乐都安排成同等强度，也不自动用空镜或慢动作制造起伏。连接段可以同时建立下一次期待或人物关系，不要求每镜都成为高潮。

重要瞬间的停留由仍在发生的行动、理解或情感变化支撑，观众已读懂且没有新体验时就离开。分别组织事件推进、信息到达、表演和切镜：人物不断换办法可以在同镜内很紧；频繁反打同一表情也可能很慢。动作高密度时保持路径和结果可读，安静场面也让人物应对或观众理解继续发展；音乐速度不能代替剧情进展。

分配单镜时间时，同时考虑观众找到重点、辨认证据/文字、理解行动与感到反应所需的时间；画面越陌生、关注区域跳得越远、同步发生的事情越多，越不能只把镜头缩短。先通过简化同镜注意对象、把人声覆盖到必要行动、压缩已知过程来腾出时间，再在关键证据或情绪变化上展开。需要的不是每镜等长，也不是每句台词后都停一拍；连续接招可以紧，决定性变化要看得见。具体覆盖与切点方法见 `storyboard.md` 的“场面怎样转成镜头”。

镜头数量由必要观察与可读容量推导，不按片长换算固定镜数，也不把每次有效变化都拆成一镜：语言攻防在说者、听者和起作用的证据之间切换；动作围绕目标、路径、接触和局势改变；喜剧保住观众识别规律与偏差的时机；关系戏保留选择如何改变相处。镜内发展足够就连续拍，关键东西看不见就补覆盖，不均分镜长或异常加速。用户明确要求的镜数仍须遵守；代码不以镜数推断节奏质量。

增加片内镜头时，优先把已确认场面中被略写的行动方法、关键接触、对方的有效回应、证据差别、选择生效和后果拍出来；同一次交锋可以从共同关系切到决定性细节，再回到改变后的关系，不必每镜重演整轮动作。用这些实际内容填充镜头，不增加无因果的小动作、无关支线或重复表情。若上游只有一个简单动作，先指出剧情容量不足并返回相应阶段，不能声称多切几镜就已丰富剧情；改变已确认剧情仍按原流程处理。

每镜必须有独立信息、行动或关系职责；数字裁切、重复角度和重复反应不能凑数。内容不足时深化事件链或重新组织观察位置，不靠改分类把空耗合理化。`deliberate` 仍须用户慢叙事依据；`true_one_take` 只登记一镜，写清持续行动中哪些反馈改变下一步、观察重点如何迁移以及最终落点，不规定事件节点配额。若只能描述一次简单动作加长停顿，先解决内容不足，不能以连续镜头掩盖。

片段是工具调用容器，镜头是片内观看单位。模型可生成 30 秒不表示要用满 30 秒，也不表示一段只能有几个镜头。先确定剧情与镜头节拍，再按模型上限和自然切点装入 SEG；上限不作为首选时长。整片和各集的发展先按 `scriptwriter.md` 组织，不能仅因各 SEG 都有动作就认定全篇紧凑。规划确认后不得擅自更改总时长、模型或已确认预览。

## 人声与并行时间预算

- 声音身份锚点只锁年龄感、音高、音色、语言/口音和稳定发声特征，不锁每句的语速、停顿与情绪。逐句用 `delivery_intent`、`pause_plan`、`emotion`、`emphasis_words` 表达变化；默认自然利落，不统一慢读。
- 估时按实际朗读、动作及反应的重叠关系计算：镜头占用时间是并行轨道的包络，加上确有必要的独占动作/停顿，而不是把所有项目串行相加。避免在朗读已含停顿时重复加算。
- 朗读占比和汉字/秒仅用于发现拥挤风险，不设置统一 55%/70% 占比、4/5 字每秒硬门或最低语速。写作时按目标表演与实际动作先后安排可理解容量；不另开朗读/试音质检或生成后试听，不能用异常加速掩盖超载。
- 上述预算用于内容规划和执行检查，不用于决定是否增加前置询问。用户台词明显过长的前置判断只按 `interaction-ask-video-clarification-ref.md` 作定性判断，不逐字计数、套阈值、编造精确用时或额外调用计时/TTS 工具。
- 模型自写或用户已授权改写的文案超载时，在授权内删重复、拆短句，或用画外音覆盖行动、调整镜头分配；用户提供且未授权改写的台词不得自动删改。用户锁定台词和时长确实无法同时满足时，按确认 Ref 明示精简或延长的取舍；换模型、分段或异常加速不能解决同一固定时长内的容量矛盾。涉及已确认内容、时长或批次的实质改变仍按原确认流程处理。

## 成稿与镜头预算的衔接

完整分场范例读取 [scriptwriter.md 的原创成稿示例](scriptwriter.md#原创完整成稿示例)：动画喜剧、职场悬疑、家庭微电影、原创口播分别展示规则回扣、证据重释、关系选择和主观讲述。它们都写到当前结果，不以新谜团代替结尾；示例时长只作创作预算，实际安排按上文“人声与并行时间预算”处理，不另开朗读或排演验证。

先完成完整故事和全部人声，再把事件转为镜头与时间。开门、对视、回忆或一段独白都只是表达单位，不能因拆成多镜便声称剧情丰富。OS/VO 可以覆盖行动和听者反应，不默认要求人物静止、慢推或空镜；主观思考也可以通过判断与行动的变化推进。
