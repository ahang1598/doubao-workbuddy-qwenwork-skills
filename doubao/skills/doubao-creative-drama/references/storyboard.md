# 分镜阶段 Ref

完整模式在项目级故事包、`current_episode` 详细剧本取得用户确认、且当前集资产已有有效采用依据后读取本文件；同范围已批准复用按控制合同承接。本文件是镜头规划、运镜阈值和 planned SEAM 的唯一权威。本阶段只处理当前集；不得在当前集达到目标前提前制作后续集分镜。轻量分镜或含视频调用的目标从采用故事、全部人声与真实素材直接写同标准的十五列主表，再从主表提取简洁预览；不从八行摘要反推整部故事。仅 `video|final` 目标继续编译 Prompt、取得生成授权。

## 本 Ref 关键要求

- 分镜只规划镜头、片段、连续性、已确认资产编排，不生成视频或最终 Prompt；仅要求分镜的任务到此交付，不编视频执行包。
- 正式分镜必须覆盖当前确认范围内全部剧情，不能只给样例、摘要或局部镜头。
- 用户可见阅读稿按本集提要、章节、SEG 和片内镜头组织；内容分类仅描述叙事机制，默认节奏、有效覆盖及慢叙事例外统一执行 [pacing.md](pacing.md)。
- 每个 SEG 必须存在 `reference_input_plan` 数组：有真实图片输入时逐张规划连续接缝所需的上一段真实尾帧、主体、角色状态、场景、道具、风格和连续性抽帧的职责、来源、采用/剥离边界；没有任何真实图片输入时可写空数组，并在片段路由理由中说明 `text_to_video` 的成立条件。非首段只有 planned `SEAM=elliptical` 且不需要媒体锚点时才可为空；不得伪造图片项。视频阶段不得无理由重排或漏传，真实上传顺序变化时必须同步更新图片标记和记录。
- planned SEAM 是生成前目标；真实尾帧只为实际后续输入提取，生成后不记录 observed seam 或审片选切点。

## 目标

把 `current_episode` 已确认的完整剧本和当前集采用资产逐场转换为可直接指导视频生成与后续必要尾帧输入准备的分镜交付包。正式交付必须覆盖当前集全部剧情，不得只提供样例、部分镜头、简略提纲或夹带后续集镜头。

本阶段只规划镜头、片段、连续性、已确认资产编排，不生成角色图、场景图、道具图、音色或视频。必须引用 approved 人物/状态、场景、道具和音色，继承已确认文字视觉合同；规划视频必需图片职责和仅供后续调用所需的真实尾帧提取职责。

每集唯一导演总控卡锁表达策略并解释“为什么这样看、如何剪、如何连续”，分镜主表写“观众看到什么”；最终视频 Prompt 只在 `video.md` 编译。分镜阶段不得写伪最终 Prompt。

本文件先读工作顺序，再按当前问题读“场面怎样转成镜头”“表演指导合同”“声音设计方案”和连续性方法，最后填写对应产物。上述创作方法同时适用于完整与轻量模式；导演总控卡、JSON、账本等文件要求仅适用于完整模式。轻量共用决定从 `drama_plan.json` 按 `planning.md` 继承，逐镜动作、人声、视听选择及局部变化落实到十五列；原位置按实际信息量展开，不省略创作判断，也不补建完整模式文件。

分镜继承已有采用视觉锚点，不自行更换已确认风格。完整模式的 `style_contract` 缺少可执行机制时，返回 `planning.md` 补齐并按受影响范围更新 revision、确认；轻量从已有规划的实际共用决定深化镜头，不因缺少完整风格字段停工或增加确认门，涉及用户锁定方向的实质变更仍按原变更规则。已确认风格存在但需要诊断漂移时，才读取 `电影大师风格库.md`，且只用于解释和校准原有光线、色彩、构图、材质和节奏机制。镜头职责、动态数量、主运镜和切点合同以本文件为准。

写具体分镜时，先执行本文件、`scriptwriter.md`、`assets.md`、`manifests.md` 和 `control-contracts.md`。创作参考只读取与当前分镜问题直接相关的部分：用 `scriptwriter.md` 的共用方法核对已确认场景功能、人物应对、信息释放和必要场面；用 `剧作方法与类型库.md` 的对应工具校准开场钩子、反转、爽点/泪点、传播句和片段节拍；用 `题材受众库.md` 校准观看焦点、情绪回报、平台观看场景和表达禁区；用 `电影大师风格库.md` 校准光线、色彩、构图、材质、声音和节奏机制。不得因分镜阶段读取候选库而改写已确认剧情、结局、人物身份、受众定位、风格合同或资产版本。

## 输入条件

必须具备：

- 已确认的项目级与当前集剧本（单集同一正文共用一次确认）：单集复用唯一完整剧本，多集读取全局总纲与当前集完整剧本；具体正文路径由 `project_script_manifest.json` 解析。另需本集 `script_contract_ep_N.json`；关系变化和场景状态从正文、现有合同及数据卡读取，不要求独立关系矩阵、梗概或场景清单文件。
- 已确认的 `00_制作控制/project_data_card.json`；本集所有出场角色、角色当前状态、需要建立 SCN 的主要场景、已升级为 PROP 的关键/复现道具及声音主体均能解析到稳定 ID 与 approved 当前版本。一次性物件只进入分镜和 Prompt，不要求建立 PROP 资产。
- 已确认且已向用户展示或明确标注复用的当前集人物、场景、道具和音色资产及文字视觉合同；资产必须来自当前集新增项、共享 approved 库或已完成分集的 approved 复用项，不得引用尚未生成的未来集资产。
- 已确认的项目固定画幅。
- 已确定且已经按 `planning.md` 完成参数确认表的视频模型、片段时长上限和会员模型提示；本阶段只继承，不自主切换。
- 用户原始指令、后续修改、原台词、必须出现项和禁用项。

剧本存在未写出的剧情、场次或台词时，返回剧本阶段补齐，不得由分镜阶段猜测剧情。

上列输入条件只适用于完整模式。轻量模式读取采用故事与人声、用户原始指令和真实可用素材，直接形成主表再派生预览；用户要求在生成确认前先审分镜时，使用当前待确认参数与预览完成审阅，不伪记为已取得生成授权；然后创建 `episodes/ep_1/02_分镜/分镜_完整分镜表_ep_1.md`。十五列逐镜要求与完整模式完全一致，不能删列、空列或用五列预览代替；扩充只能补足镜头、动作过程、表演、声音、连续性和素材职责，不得改变已确认的故事方向、动作结果、台词、模型、时长、画幅或素材边界。轻量模式不创建项目数据卡、分镜 JSON、导演总控卡、分段执行索引、独立连续性账本、独立参考输入计划。纯分镜目标将段序、镜号范围、计划首尾、连续/省略转场、不变量、声音桥与参考职责写入同一主表的分段说明，未来真实尾帧只写依赖，不伪造文件；不创建视频 manifest。视频目标再从该主表提取分段计划与依赖到视频 manifest，最终请求和真实输入按视频阶段就绪规则落实。默认不新增用户确认门；用户明确要求先审分镜时，按 `interaction-ask-video-clarification-ref.md` 在视频生成确认前完成该审阅。

## 分镜产物分层

完整模式内部以十五列逐镜主表为唯一逐镜内容源，导演总控卡维护全局/场面策略和必要专项，分镜 JSON 的 segments/seams 统一维护分组、边界、首尾状态与连续性依赖，不另存 SEG Markdown；面向用户按需展示主表派生的阅读稿与简要镜头方案，不点名内部制作支撑物、哈希、路径或检查过程。轻量视频目标的主表用于内部执行；纯分镜目标交付主表，用户要求先看时也展示。两种模式都不得用五列预览代替详细分镜。

各文档职责：

- **导演总控卡**：拆镜前唯一的导演决策中心，统一锁定本集视觉叙事、核心意象、场面调度、节奏波形、表演、声音与风格系统；不得另建导演阐述卡或强风格系统卡。
- **完整分镜表**：一行一镜，固定十五列，包含镜头职责、画面、声音、运镜、连续性和抽帧承接。
- **分段执行索引**：完整模式写入 `storyboard_ep_N.json.segments[]/seams[]`，记录调用容器、主表镜号引用、切镜触发、首尾状态、承接、参考职责和生成风险；轻量纯分镜保留同一主表的分段说明，进入视频制作时再提取到视频 manifest，不另存 SEG 表。
- **连续性记录**：跨镜事实写在逐镜主表，跨段不变量、变化、轴线和声音承接写入同一分镜 JSON 的 segments/seams，不另建账本。下文“连续性账本”均指这一职责。

## 完整模式工作顺序

1. **读出场面进程**：从已确认正文取实际首态、人物行动与台词顺序、关键变化和尾态；钩子、欲望、阻力、策略变化、权力转折、代价、信息差和兑现只标本场实际承担的部分，不强迫每场具备全套。
2. **确定观众怎样经历**：按“场面怎样转成镜头”选择观看立场、信息先后与主要体验；先推演人物和物件在空间内怎样往来，再选观察位置，不先按 15 秒切故事。
3. **落实导演总控卡**：把已作出的视觉、调度、节奏、表演、声音与风格判断写入唯一总控卡；按剧本组织章节与事件链，不另产候选方案或一套导演文档。
4. **推导覆盖与时长**：选择各节拍需要看见的行动、证据、听者或共同关系，再按 `pacing.md` 分配时长并落实有效覆盖。关键动作、对白、反应、读字和观看范围共享真实时间，不能只用总秒数相加代替容量判断。
5. **写完整分镜表**：先取对应剧本段落的实际首态与动作、台词先后，再逐镜展开；每镜承接上一镜已经形成的末态，不凭梗概重新编一遍场面。机位变化可改变看见的部分，不能改变谁已起身、物件已到哪里或某句话发生在动作前后。一行是一段未经剪切的连续画面；镜内移动、重构图、移焦或景别变化不自动拆镜，实际剪切、视点断开或时空跳跃才另起镜号。同一 SEG 内各镜头首尾相接，总和等于该片段时长。
6. **切视频片段**：先圈出必须连着证明的关键操作、复杂接触与发声窗口，优先完整放进同一生成片段，再按模型上限和自然切点安排周边镜头；不是每到上限就截开。边界必须落在镜头切换点。若原分配把复杂手部/物件状态卡在接缝，先用人声覆盖行动、合并重复观察或重配周边时长腾出位置，不删决定性操作；仍放不下时记录具体容量或承接风险，涉及已确认内容、时长或生成数量的调整仍按原授权边界处理。
7. **补连续性和导演控制**：在唯一导演总控卡内明确轴线、视线、动作方向、道具状态、光位、声音桥、动作桥和每个切点的动机。
8. **规划输入图和抽帧需求**：把已确认人物、角色状态、场景、道具、音色与文字视觉合同绑定到镜头；列出视频阶段必须传入的图片职责、实际传入顺序建议、采用/剥离边界，仅在下一次调用确实需要时规划真实尾帧；不为归档或质检抽取首中尾、状态帧全套。

轻量模式沿同样的场面、视听与容量推导，只把结果写入十五列；核对实际覆盖、连续性、声音与时间后交给 `video.md` 编译 Prompt。不得因此创建上述完整模式配套文件。

除“完整分镜表”及其十五列填写规则外，本文件后续关于导演总控卡、结构化分镜索引、分段执行索引、参考输入计划、表演谱、色彩脚本、连续性账本、SEAM 和阶段确认的文件要求均只适用于完整模式。

## 节奏与镜头推导

执行 [pacing.md](pacing.md) 的事件链、有效覆盖与容量方法。`density_profile` 只记录内容机制，`pacing_profile` 记录 brisk 或 deliberate；只有 deliberate 的用户慢叙事依据写入 `pacing_exception`。默认采用剪辑叙事；只有用户明确要求时采用真正一镜到底，连续镜头不自动降速。先事件、后观察职责、再时长与片段，不能用改分类合理化空耗。

开场首先让观众看到具体异常、冲突或迫切行动。不同内容都要有持续推进；悬疑不提前泄底，但等待中必须增加证据或风险。

## 场面怎样转成镜头

先在脑中走完同一采用方案，再一次写完整分镜。下面是作出取舍的方法，不是新增表格、候选数量或例行多稿流程；只把采用结果写进现有总控卡和十五列。上游事实不足以支撑关键行动时返回对应阶段，已有事实充分时直接完成镜头表达，不把每次取景选择都变成新确认。

### 先安排观众注意，再选择摄影机

对当前节拍确定三件事：观众先在意什么、目前知道什么、这次观看后怎样改变理解或感受。由此决定看行动者、听者、证据还是共同空间。镜头职责可以是一次可感的迟疑、亲近、笑意或尺度体验，不只限于新增事实；但要说出此时具体看见或听见什么在发展。

- **共同经历**：观众与人物同时发现，把关键证据放在其观察能够到达的位置，随后看判断如何改变，不提前用特写泄底。
- **观众先知**：先让观众辨认危险、误差或善意，再看不知情者怎样行动。悬念来自即将相撞的两条事实，不靠一直不让人看清。
- **重新理解**：已确认剧本需要认知重释时，先保留真实而不完整的观察，后面补足决定性范围或背景；不能把原本就在角色眼前、足以结束问题的事实无理由藏掉。

一次场面可按触发改变立场，不必全片绑定同一角色。每次切换让观众能判断谁在看、看向哪里；不把所有主观体验都拍成第一人称 POV。回忆、想象、内心独白继承剧本已定的真实/主观边界，用明确的进入和返回线索区分，不临时发明回忆来补因果。

### 把连续变化安排进镜头

变化间隔与局部展开以 `pacing.md` 为准。先把本场相连的行动、反馈、辨认与选择放到观看顺序中，再判断哪里需要切镜，不从等长镜头格子倒填剧情。

- 同一构图里能看清人物采取办法、对方回应和条件改变时，保留镜内发展。例如一人递钥匙，另一人看见钥匙上的旧挂件而收回手，递出者改口说明来历；不必每两秒分别切手、脸、钥匙。
- 观众需要看清原画面无法辨认的差别，或知道另一个位置正在发生的事时，切到对应对象。切后尽快呈现该项内容，不先空等人物再启动。
- 一次变化横跨两镜时，后镜接同一次行动和发声进度；不重说台词或重新起手。一次镜头包含几个变化时，逐步引导注意，不让多个角落同时发生不同的关键发现。
- 按剧本已定的信息顺序安排证据出现。观众需要凭该证据理解当前行动时，给足辨认时间，再让人物的利用与反馈可读；剧本有意保留底牌时，先呈现足以跟住行动的异常或线索，在既定揭晓处补足依据，不提前泄露。不能靠闪过复杂文字、遮掉本应被理解的差别来制造悬念。信息过多时减少同时呈现的对象、压缩已知准备，把时间留给当前应被理解的关键内容。
- 运镜应改变能看到的范围、距离或前后关系。例如侧移使被挡住的手露出，移焦让门外来者进入注意，跟拍保住追逐双方的位置。若运动结束后没有新的观察或体验，就保持固定或删掉运动；不要用推近代替人物得到证据。

以约 24 秒的局部场景说明时间怎样压缩与展开；以下时间仅是这场戏的创作预算，不作为其他故事的分配模板，也不承诺生成精确到这些秒点：

| 时间预算 | 镜头中的行动、声音与变化 | 为什么保留或切换 |
|---|---|---|
| 0–3 秒 | 固定近景里，门把手从外面被压下；女子扣内锁，问“谁？” | 同镜内先出现试门，再有防御与询问，不为两次变化分别切镜 |
| 3–5 秒 | 切门外中景，对方提工具箱说“物业，楼下漏水” | 给出对方提供的身份与开门理由，工具箱只能支持其说法看似可信，不能证明身份 |
| 5–9 秒 | 切室内侧面，女子走向对讲机说“我问值班室”；门外声音立即接“别打，线路坏了”；她仍按下呼叫键 | 在同镜内完成验证意图、阻止和坚持，动作与人声并行 |
| 9–12.5 秒 | 切到能同时看见对讲机与她侧脸的近景。对讲机回应“值班室”；她看回门口，原本靠近内锁的手收回 | 给观众辨认理由被推翻、人物因此改变判断的时间；话语结束后保留这次反应，不再塞另一条线索 |
| 12.5–14 秒 | 切门把手，再次猛压；门外声音由“开门”开始跨入下一镜 | 回到刚才已建立的威胁，施压是验证之后的回应，不重新介绍门外是谁 |
| 14–20 秒 | 切女子中景，接住同一声“开门”的尾音。她退离门边，对对讲机说“三楼，有人试门”；回应“别开门，保安上楼了” | 保留完整求助与回应；不为一句话跨过两秒就切断或加速 |
| 20–24 秒 | 切回门外，对方听见隔门传出的回应，收手提箱离开；走廊短暂留空，远去的脚步声接续 | 先看见求助的后果，再用短暂环境停留感受刚结束的逼迫；不另加人物或新危险填满留白 |

这七镜围绕试门、解释、验证、破绽、施压与求助后果展开。切点由需要观察的对象改变而来，不由 1–2 秒间隔触发；辨认、完整发声与留白可以超过这个间隔。结尾只说明当前试门被打断，不宣布身份已查明或危险已全部解除。

### 从人物往来推导覆盖

先按固定空间推演这次交锋或配合：人物要对谁做什么，谁占有可用空间或物件，哪次行动迫使对方调整。走位来自递取、避让、试探、合作或冲突等实际意图；如果人物坐着就能完成，不为“有调度”强迫起身绕行。

再选择能把关键关系拍清的覆盖方式，以下按需组合，不是每场全套：

| 需要观众经历的内容 | 观察与切换办法 |
|---|---|
| 两人持续接招、彼此试探 | 双人或多人同框保留距离、抢话与共同动作；切近是在某人开始隐瞒、辨认、改口或决定时，不是每换说话人就切 |
| 一句话改变了听者 | 可以提前到听者，看到其原状态、听见触发和改变；也可让说话声跨镜延续。后续说话者重新入画时接真实进度，不重说该句 |
| 物证、操作、身体接触决定成败 | 看清谁接触哪里、凭什么起作用，以及结果由什么条件维持；先让决定成败的路径、支承或可达关系可见，再用细节放大差别。交接以后谁仍能控制、移动以后能否停稳，要承接剧本已有条件；缺条件回到未锁定空间深化，不由运镜暗中补出。无关准备可压缩 |
| 误差与笑点同时发生 | 选择同框让观众比角色早发现，或有意延后一个反应/结果再切；包袱仍由人物行为产生，不用音效和惊讶头像代演笑点 |
| 重要选择需要连续感受 | 保留从听见、承受至选择的必要变化，不切走后突然把状态从平静变成落泪；反应完成后及时离开，不机械追加第二个相同反应 |

建立空间不必每场先放一个空全景：在首个有效行动中让所需双方、出入口或物件关系可读即可。细节镜头回到人物时，要接上同一事件的新进度。特写、远景、反应镜与共同画面各有职责，不按“全景—中景—特写”的顺序跑一遍。

### 构图、动作和切点一起设计

每镜先确定主要注意对象及它与环境的关系，再安排景别、清晰区域、明暗和运动。关键证据不能同时被背光、手部、画缘或过浅景深遮掉；需要同时看清双方接触时，保留二者及接触点，而非分别拍两张无法连起来的近脸。

快速切换时，让前镜的注意落点能引导下一镜：可保留主要区域、沿运动方向接力，或用视线/声音先提示新的区域。改变观看重心有戏剧作用时可以跳到另一侧，但须留足辨认时间。横竖画幅按已确认比例组织同框、纵深与出入画，不默认将宽画幅关系裁成单人头像，也不把所有竖屏都拍成大特写。

剪切可以落在动作进行中，不必等人物走完、话说完、转头结束。切入下一镜后延续同一相位和声音进度，不能重启；关键结果或情绪变化需要被见证时保留其有效阶段。无戏剧作用的拿起、走过、收好可在明确省略中压缩，但不能把“压缩”写成物件换手或人物瞬移。跨 SEG 的真实生成首尾仍按下文 SEAM 合同执行。

转场先回答“观众为什么此刻要去看下一处”，再选择已有转场方法。把以下采用关系写进原有切点与承接说明：

| 前镜正在产生的需要 | 后镜应立即提供什么 | 连接方法与限制 |
|---|---|---|
| 人物看见或听见画外对象 | 其视线或声源实际对应的对象，以及对象正在做什么 | 用视线或声音引导；明确方位，不能切到无关漂亮空景 |
| 动作尚未结束，结果在另一个角度才可读 | 同一动作接下来的接触、位移或结果 | 在有效动作中切，方向与进度接续，不重做起手 |
| 一句话正在改变对方 | 听者从承受到作决定的实际变化 | 同一完整句子跨镜只说一次；不按轮到谁说就机械反打 |
| 此段已完成，下一处要承担其后果 | 新时空与刚才结果之间的联系 | 用已出现物件、动作、声音或明确的新起点连接；省略有边界，不藏掉必要因果 |
| 两条已建立行动即将相遇 | 另一方的实际进度以及距相遇还有什么条件 | 交替观察须有共同问题，不能随意插一条陌生支线 |

不同镜头可通过上述不同需要产生变化，不要求每次特效转场。新镜头的首个有效内容就回应前镜留下的期待；没有新职责就保持镜内发展。甩镜、遮挡和形状匹配只在既定事件提供实际锚点时采用，不为每 1–2 秒造切口；必要辨认与留白照常保留。声音桥及跨 SEG 的实际处理能力仍按原合同，不以文字设计声称已经实现。

### 按既有呈现类别与场景适配

沿 `剧作方法与类型库.md` 的五类呈现语法和场景四维度选用镜头办法，不新增作品分类，也不因题材免除节奏基线：

- **AI 真人/数字人短剧**：让对白攻防与动作反应相互承接；短剧的直接表达、打脸或身份揭示仍需听者与证据可读，不能只靠连续口播和配乐宣告。复杂接触拆成少量明确阶段，不因此删除已确认的关键动作。
- **动画/卡通短剧**：起势、关键姿态、路径和结果形成可读轮廓；夸张的挤压、延迟和反弹沿既定世界规则。先让观众辨认动作，再给反差与回收，不把每个动作都延长成预备姿势。
- **漫剧**：按关键姿态、画格关系与揭示组织变化；切格、局部运动和声音各承担真实事件。局部推拉只引导读图，不把一张图持续放大算成多次推进。
- **口播解说短剧**：把讲述与对应行动、物证、反差排在同一时间线上；关键原声需要独占可懂窗口，解说让位。画面可提供讲述者没承认的信息，不用无关素材垫时；已有原片只用有权限且来源可核的部分。
- **微电影/短片**：让共同动作、环境与声音承担人物体验；选择持续观察还是切到细节取决于变化发生在哪里。余韵落在已发生事件的结果或关系，不用抒情空镜替代结局，也不默认全片降速、无对白。

封闭空间用深度、出入口、桌面和视线改变关系；开放空间先交代路线、目标和危险所在。陌生空间只建立当前动作需要的规则。高压段看清资源、接触与结果，低压段看清意图、细小偏差与回应；循环压缩观众已知部分，碎片叙事保留可辨的视点和时间锚点。

### 在安排镜头时完成时间取舍

按实际行动、人声与注意转移安排每镜：当前要看清什么，哪一反馈使下一镜有必要，切点会不会错过决定性动作。多人同时动作、辨认文字、走位与发声会争用注意时，先减少无关任务，让同一事实用更清楚的观察呈现；必要证据、完整句子与反应保留可理解的时间，不能按 1–2 秒机械切断。

这些取舍直接写进已有分镜，不另开写完后的朗读、排演、播放、打分或固定复查轮次，不要求为未播放写一份说明。剧情或时长确实需要实质变更时仍走原确认；本节不改变生成后的立即交付、必要依赖抽帧或问题触发排障规则。

方法来源与取用边界：本节迁移 [Hitchcock 在 BFI 的导演自述](https://www.bfi.org.uk/sight-and-sound/features/alfred-hitchcock-my-own-methods)中用物件、反应和声画错位引导注意的方法；参考 [Susan Shipton 的 CCE 访谈](https://cceditors.ca/2020/11/episode-035-behind-the-cut-with-susan-shipton/)对听者、情绪转变、双人画面及切点的取舍；[Disney Animation 的 Story 流程](https://disneyanimation.com/process/story/)说明分镜共同考虑表达、时间、调度和构图。这里不照搬长片时长、多稿习惯或特定拍法。快速剪辑的注意接力另参考 [ASC 对 John Seale《疯狂的麦克斯：狂暴之路》取景方法的介绍](https://theasc.com/video/john-seale-asc-acs-framing-mad-max-fury-road/)，只迁移便于观众快速找到重点的原则，不规定全片居中构图。

## 每集导演总控卡

详细拆镜前只生成一份 `episodes/ep_N/02_分镜/导演总控卡_ep_N.md`，同时承担导演阐述、控制与风格系统职责；具体内容统一按下文“导演总控卡字段合同”填写，声音、表演和色彩按对应小节落实，不再重复列一套总纲。每项判断绑定场次、镜号范围或剧情触发点，结构化索引保存现有文件指针。

### 亮点绑定

分镜前读取本集 `script_contract.highlight_ledger`，按 `manifests.md` 的 schema 在 `storyboard_ep_N.json.highlight_bindings` 中逐项绑定。每个 `role=primary` 的亮点必须有兑现、有效反馈及后果的可观察证据；同一 SHOT 可同时承担多个职责并复用镜号，不要求另加三个镜头或依次留出三段时间。后果可在兑现当下显现、与下一步行动并行，或按剧本延后回收，不为凑“高潮后余震”追加凝视、空镜或新剧情。绑定必须填写视觉、表演、声音和视频编译说明，某一维度不适用时写清理由，不能统一填写“加强氛围”。任何剧本主要亮点找不到镜头，先返回剧本调整或重拆分镜，不得直接删除。

每个主要亮点按“触发 -> 变化 -> 反馈 -> 结果”推导，不从“需要一个高光画面”倒推装饰性镜头：

1. **触发**：读取 `setup_evidence` 和当前场次前态，选择真正迫使人物或局势改变的台词、证据、动作或规则事件，并绑定观众可见/可听的镜头。
2. **变化**：写清触发后谁采取了什么不可忽略的策略，人物位置、道具控制权、信息归属、关系或危险如何发生可见变化；只写情绪形容词不成立。
3. **反馈**：给出对手、听者、环境或规则的即时回应，让观众确认变化被世界接住。反馈必须改变下一拍策略或认知，不能只补一个无后果惊讶特写。
4. **结果**：写清本场或后续场次留下的代价、权力重排、选择后果或余震。结果可延迟到后续集，用 `deferred_aftereffect_ref` 指向已确认全局总纲中的承诺与目标集；尚未制作目标集时不要求其详细剧本、HL 或 SHOT 已存在，目标集开始制作时再绑定实际兑现。

四步按顺序写入该亮点的 `causal_chain` 并绑定 SHOT；再把变化/兑现镜头映射到 `payoff_shot_ids`，反馈镜头映射到 `reaction_shot_ids`，结果或余震映射到 `aftereffect_shot_ids` 或跨集引用。同一 SHOT 可以承担多步，反馈和结果可与行动重叠，但必须分别写出可观察证据及因果关系；若缺触发、反馈或结果，返回剧本补因果，不得用慢动作、强音乐、发光或群众惊叹替代。

### 受众执行

分镜只能继承已确认 `drama_plan.json.audience_plan`，不得重新选择受众、平台或地域。在 `storyboard_ep_N.json.audience_execution` 中按 `manifests.md` 分别登记观看焦点、情绪回报、平台观看场景和表达禁区的执行合同，并把每项绑定到真实场次或镜头。四项都必须可追溯；仅写“符合受众”“适合平台”或重新引用受众库标签不算落地。

## 导演总控卡字段合同

> 本节规定每集正式拆分镜前必须完成的唯一导演判断，以及这些判断如何进入逐镜表和视频 Prompt。不得另建第二份导演控制包或强风格系统卡，也不把整张总控卡塞进每个 Prompt。

### 职责边界

- `导演总控卡_ep_N.md`：每集唯一整体创作判断，先于逐镜表完成，并用场次/SEG/镜号引用把判断落实到唯一逐镜主表，不再逐 SHOT 重写动作、表演、声音和剪辑合同。
- `storyboard_ep_N.json`：保存总控卡文件指针和可执行字段，不复制长篇说明。
- `video.md`：只编译已确认导演总控卡和分镜，不重新发明导演方案。

### 每集导演总控卡

固定文件：`episodes/ep_N/02_分镜/导演总控卡_ep_N.md`。至少包含：

- **视觉叙事策略**：回答观众如何被安排去看，包括主要观察距离、主客观视角、空间压力、运动与静止分工、何时拒绝特写、何时让环境压过人物。禁止只写“电影感、压迫感、高级感”。
- **开场承诺与情绪曲线**：继承 `script_contract.opening_contract`，写清首个叙事节拍如何被看见、谁先反应、什么动作或信息使其升级、在哪个场次兑现或延续；再把项目级 `emotion_design` 细化为关键角色的入场状态、压力来源、转折触发、可见证据、关系后果和尾态。
- **核心意象**：当已确认剧情中存在反复出现且意义变化的对象，或需要通过呼应完成表达时，选用道具、动作、空间、色彩或声音母题，通常聚焦 1-2 个。按实际剧情记录首次含义及发生的变奏、重释或回收，不要求每片凑齐四阶段；直接冲突、动作兑现等不需要母题的作品可注明不采用及原因，不增造镜头。每次复现应增加信息或改变意义，无变化的装饰不算核心意象。
- **场面调度总纲**：继承人物关系张力表，说明权力差、信息差和情感差如何通过距离、屏幕位置、纵深、遮挡、出入口和道具控制权变化。允许反讽调度，不能机械套“强者站高、弱者站低”。
- **节奏设计**：标记需要快切、连续表演、停顿、长镜或突然中断的段落及戏剧原因。快切用于信息压缩或失控，长镜用于让选择和反应无法逃避；不得用速度掩盖场景没有转折。
- **节奏波形推导**：依次记录不可移动内容节点、每个节点的信息密度/动作强度/阅读时间、唯一主重拍、切镜或镜内连续选择、动作与核心证明优先后的时长分配，以及 `1-5` 强度序列。可选“快起 -> 稳证 -> 快收”“逐级加速 -> 高光 -> 短停”“快慢交替 -> 汇聚”“连续推进 -> 节点变速”“结果前置 -> 倒推线索 -> 原因揭示”“稳态建立 -> 突然打断 -> 连续应对 -> 新稳定”“单点触发 -> 层层扩散 -> 整体响应 -> 回收”“两线交替 -> 节奏对齐 -> 汇合”“问题脉冲 -> 回答脉冲 -> 证据停留”“克制积累 -> 局部释放 -> 完整爆发 -> 余韵”“建立规则 -> 两次变奏 -> 打破规则 -> 新规则收束”“起点 -> 偏离 -> 回归 -> 无缝 Loop”或自定义波形；不得固定切成 `0-3 / 3-7 / 7-11.5 / 11.5-14 / 14-15`。
- **视觉风格系统**：媒介形态、构图骨架、光线方向、色彩关系、材质、镜头质感、字体/版式、明确剥离项。它是总控卡的一部分，不单独维护风格系统卡。
- **亮点转译**：逐项读取本集 `script_contract.highlight_ledger`，写清观众先看到什么、哪个动作兑现、表演如何泄露真实意图、声音何时进出、哪个镜头保留余震。信息重释重证据和反应，关系攻防重距离/遮挡/道具控制权，专业能力重流程和策略修正，母题重重复变奏，表演瞬间重表面策略与泄露动作，情绪余震重高潮后的结果镜头。

### 总控卡逐字段推导方法

按下列顺序从上游事实推导，不允许先写形容词再找镜头佐证：

1. **建立输入表**：读取 `creative_proposition`、`opening_contract`、`highlight_ledger`、正文与合同中的人物关系、场次 entry/exit state、`emotion_design`、`rhythm_design`、`style_contract`、数据卡空间/状态和用户镜头禁令。每条输入标记来源场次；互相冲突时回到最早权威阶段，不在总控卡中私自折中。
2. **推导观察者立场**：先问观众应比谁知道得多、与谁同处压力、何时需要看清证据。由答案决定主客观视角、主要观察距离、环境与人物的画面占比，再绑定场次范围；这形成“视觉叙事策略”。
3. **推导核心意象**：先判断本片是否需要重复、对照或呼应来改变观众理解；需要时按上面的适用条件选对象，只绑定剧本中实际成立的复现与意义变化，不需要时注明不采用。已有母题策略保留，但不能为了完整填四阶段额外安排剧情或延长结尾。
4. **推导场面调度**：把每个关系节点的权力差、信息差、情感差翻译成世界坐标中的距离、纵深、遮挡、出入口、视线和道具控制权；先写 T0，再只记录触发后的 T1/T2 变化。机位随后服务调度，不允许为了构图暗中移动人物或房间。
5. **推导节奏与表演**：从不可移动节点和主重拍分配快切、连续表演、停顿和静默；再对承担转折的角色写“表面策略 -> 内在压力 -> 泄露动作 -> 对方反馈 -> 尾态”。没有因果触发的表情、呼吸或停顿删除。
6. **推导声音**：从本片主要体验与关键行动确定声音主轴，按“声音设计方案”共同设计环境、动作、对白、主观听觉与音乐的发展；音乐的作用在构思场面时就决定，入退点再随实际动作落实。若多层声音争夺注意，明确此刻主听对象，再安排其他层避让或接力。
7. **推导色彩和风格**：逐项继承 `style_contract`，先写基础光源、主辅色、材质和构图骨架，再只在有世界内原因或剧情触发时写变化。无法指出光源、时间、天气、实景灯、服装或空间原因的自动变色删除。
8. **绑定执行范围**：每项决策必须落到场次、SEG、SHOT 范围或明确触发点，实际首尾状态引用主表或分段执行索引，导演卡只写共用决策与必要专项调度。若一项无法绑定任何镜头，它不是本集执行决策，应删除或返回上游补依据。
9. **统一设计依据**：写作时逐项明确“它服务哪个剧情问题、在哪一镜可见、变化由什么触发、视频 Prompt 需要继承哪部分”。四问任一无答案时重写；不同字段要求互斥动作、光线、声音或观看立场时，以核心证明和用户锁定项为先，不能同时保留。

### 把视觉选择组织成同一部片

先继承项目签名与已确认代表场面，选择适合本片的观察原则，再确定它在何种事件触发下变化。视觉既要使事情可读，也要让观众亲历本片的紧张、亲近、滑稽、压迫或惊奇。先想这个场面最值得亲眼看到的差别，再安排摄影机；不能只把正文逐句换成一张脸、一件道具和一个情绪特写。写入现有视觉叙事策略与镜头，不新增风格文件。下表为可选方法，不要求全用，也不将构图直接等同于人物道德或地位。

| 主要体验 | 怎样建立并发展画面关系 |
|---|---|
| 亲近或疏离 | 让任务中的空间关系先成立：谁替谁安排位置，谁躲开同一张桌，谁愿意把手边空间让给对方。人物的选择使距离、遮挡或共同区域变化，再决定保留同框还是切近；不能只用一组近脸宣布关系变化 |
| 悬念或发现 | 按已定信息关系组织看见的时机：观众先看见人物背后的动静，会期待他何时察觉；跟随人物发现时，则保留观察、判断和验证的可读联系。揭示由视线或实际行动打开，不靠拍不清藏答案；不是每个发现都先拍遮挡再慢推 |
| 动作或奇观 | 选择本场独有的空间条件与视觉规律，例如随重量倾斜的平台、只有倒影暴露的路径；仅使用剧本已建立或已获准深化的规则。先让观众认得它如何影响人，再拍利用、失误或突破。以尺度参照、路径、接触与环境反馈形成体量，不能只写巨物、闪光、爆炸和“史诗感” |
| 喜剧或群体互动 | 先决定观众比谁早明白笑点：同框看见一人认真遮掩、另一人已在身后，可以比连续惊讶特写更有效。按行为规律安排暴露与反应，给足辨认时间；不同笑点可延后结果或利用画外声音，不固定一种包袱切法 |
| 生活质感或人物体验 | 让空间和物件带着使用痕迹与此人的选择：同样一把椅子，替人预留、被撤走、终于自己搬过去，会有不同分量。选对当前人物重要的细节并使它参与事件；光线与材质有层次，不靠无关空镜填“质感” |

**让画面之间发生关系。** 例如剧本已写“合奏时一人总抢着报拍，后来决定跟随”，分镜可以先让报拍者占据前景、另一人不断被遮；两人重新试奏时，把谱架纳入共同画面，看见前者等待对方起拍并真正接住。随后有值得辨认的手部或听者变化，再切近。变化来自已经发生的相处，不是台词结束后另补一个靠近镜头。也可全程同框，让表演内部完成，按本场观看需要选择。

视觉辨识度从本片特有的场景资源、人物习惯或规则中取一个主要依据，再让构图、美术、运动和声音共同发展它。可以鲜明夸张，也可以朴素克制；不要求每片都有象征物或固定色板。音乐的进入、发展和退出按下文“声音设计方案”响应具体事件，不能从头铺满同一种情绪来补剧情强度。轻量模式也执行这些创作选择，直接写进现有逐镜主表；不补完整模式总控卡。

回扣物件与画面时，使用此前已经具备的特征，让人物的动作、所在关系或观察位置产生新意味；临到结尾才让普通物件自行发光、转动或出现新用途，会把抒情写成新的故事事实。确有这种设定时沿用原依据；否则从已发生的选择中找落点，不为“有余味”额外补一串物件、空景与反应。

光影和美术一起服务重点：先确定实际光源、主体与背景的分离，再决定哪里保留暗部、反射、色彩或材质细节；关键动作、身份和证据仍须可读。明暗、色彩与画幅中的秩序可以鲜明或朴素，不能全部项目统一成逆光、浅景深、冷暖对撞。角色移动、灯光开关或空间转换引起变化时保持世界内依据，纯剪辑对比也须遵守既有色彩合同与时空事实。

可迁移的主创依据：[ASC 对 Roger Deakins《银翼杀手2049》摄影交流的记录](https://theasc.com/article/deakins-blade-runner-2049/)说明其从人物与情感出发，让布景与光线共同形成画面。这里采用协作与取舍方法，不复制该片色板、规模、摄影节奏或实拍设备要求。

### 表演指导合同

AI 表演使用可观察层次，不依赖抽象形容词或只有微表情。每个关键镜头至少写清：镜号、角色、表面策略、内在压力、可见情绪层次、主要脸部/目光/肢体/呼吸变化、触发点、尾态和禁止表演。

先把角色此刻要对别人做的事说成可行动的意图，如套出答案、把东西留住、装作没听懂或给对方台阶；再从对方实际回应推导其改用什么办法。让选中的目光、手或身体变化承担这次调整，不同时指定眉、唇、手、肩、呼吸全部变化。低头、抿嘴、偷看、偏头和呼吸变化可以与台词、行动或听者反应同时发生，不因其细微就删除，也不将每项拆成等待拍；只突出此刻最有作用的变化。表演强弱按人物与呈现类别选择，卡通和风格化表演可以鲜明夸张；避免的是没有触发、角色全都一样的夸张。

听者可以忍住不接、继续手上的事或故意保持礼貌；这些行为须在本场上下文中可理解，不必每句都点头、惊讶或起身。关键变化发生前给出可辨基准，听见触发后才改变；若镜头看不到脸，用仍可读的动作、声音或距离承接，不为填写微表情强加特写。短镜只承载一项足够读懂的转变，不能同时要求复杂情绪过山车。

- 表面策略决定人物在做什么；内在压力解释动作为什么泄露。
- 微表情只作增强，关键信息同时由动作、距离、道具、声音或结果承担。
- 一镜最多突出一个主要表演转变，复杂变化拆成可观察节拍。
- 有听者时单独写听者反应及尾态，不能只细化说话者。
- 禁止“夸张震惊、持续流泪、机械点头、全员同一表情”等默认失控表演。
- 关键表演直接写主表画面与声音；需要细化时参考下文同镜内表演示例，AU 只作辅助强度标尺，不替代自然语言动作因果。

### 声音设计方案

每集先确定整体声音如何组织注意，再按实际需要从下列声层选用；某层不适用就不添加：

- **基础环境声**：房间底噪、空调、电流、远处车流等，用于空间和连续性，不抢对白。
- **叙事性环境声**：钟声、雨声、脚步、门锁、机器停转等，每次出现必须改变信息或预期。
- **情绪性主观声**：心跳、耳鸣、闷化、呼吸放大等，只在人物感知被触发时短暂进入，并写退出点。

BGM 不得只靠全程同一层音乐填补情绪，也不得只写“低频 BGM”“紧张音乐”“悬疑感音乐”。音乐主导的段落可以连续，但须有清楚的发展、主次与对白避让。每条 BGM 写清入点、退点、乐器/音色、速度或节奏、音量、质地、情绪职责和对白避让；跨 SEG 延续时，下一段复用上一段已确认 BGM 描述或 `bgm_descriptor`。

**从声音怎样发展出体验来选择配乐。** 先确定本场主要由语言、音乐还是现场声音组织注意，以及哪些时刻需要交接。音色与节奏来自本片世界、人物体验和表达意图，不按题材自动分配“悬疑低频、爱情钢琴、大片铜管”。可采用下列路径或自定义，不要求每片有旋律母题，更不强制使用音乐：

- **音乐推动行动**：以可辨的节奏或短动机建立期待，人物办法奏效、受阻或兑现时，让节奏密度、配器或句子完成度有相应发展；提速可由节奏细分和动作关系形成，不只把 BPM 调快。动作不必每次都落重拍，重要落点保持主次。
- **声音形成发现或亲近**：先让一种现场声、声源距离或人物关注的声音可辨；后续改变它的来源、空间、可听范围或与行动的关系，让观众获得新理解。需要音乐时再进入或变奏，不用配乐提前替人物宣布唯一情绪。
- **音乐承载情绪发展**：在足够篇幅中让可辨动机从未完成、不同音色或稀疏配置发展到另一种呈现；变化须对应真实经历。极短片可只用一个有分量的进入、退出或完成点，不硬塞完整起承转合。歌曲与人声音乐仍受原有歌词、语言和人声权限约束。

关键节点选清主听对象：重要一句话、独特动作声或音乐可分别占据前景，其他层让出理解空间，再按事件接回。静默、删层与强弱反差按本片需要使用，不能每次高潮都统一“骤停—重击”。音乐关闭时保留必要环境与叙事声，不偷偷增加 BGM。

逐镜先把实际人声窗口连起来，再叠声音事件和音乐：人物暂时离开画面不代表台词结束，也不改变其既定声音身份；同一发声跨镜时明确起止和接续文字，只发生一次。可让下一幅画面的声源先被听到，或让前一句延续到听者/结果画面，前提是来源和时空清楚；跨独立 SEG 不把未完成台词当作可自动拼好的尾音。

声音距离跟随世界位置和观察方式：画外门响先建立方向，靠近后变化，关闭或离开后按实际阻隔衰减；主观闷化须有进入与退出原因，不随每次换景别重启。声音可以早于画面暴露风险，也可以在画面揭示后改变含义，选择须服从剧本的信息先后，不能提前泄底。

音乐的进入、发展和退出绑定事件，而非每切一镜重新开始；速度可以不变，通过稀密、音区、音色或乐句关系改变能量。音效选择决定理解或触感的接触、摩擦、距离与环境反应，避免每个手势都加提示音。说清哪个动作需要同步即可，未经实际音频和工具验证，不承诺逐帧卡点或独立生成间自动同曲。短剧优先让有效对白和适合场景的人声参与冲突与推进，但根据已确认剧本分配到实际场面，不逐 SEG 凑句数，也不要求一直说话。分镜核对谁对谁说、为何此刻说、听后怎样改变行动；行动、证据或笑点需要无台词窗口时保留，必要环境声和动作声照常存在。微电影/短片可让语言、行动或主观听觉承担主轴，不能套短剧对白密度。无对白方案不为“默认人声”增写台词；若上游短剧确实缺少必要语言交锋，返回剧本补其因果与台词，而非临时添加解释旁白。

相同 BGM 描述只代表延续意图，不能保证独立生成的片段得到同一旋律、相位或精确卡点。精确同曲延续、混音和同步应核对已有真实音频及当前已授权工具能力，沿既有制作与委派边界处理；能力不足时说明具体缺口，不虚称已经对齐，不自动增加音乐生成、重生或编辑调用。

主创参考：[《沙丘》混录师 Ron Bartlett、Doug Hemphill 访谈](https://www.asoundeffect.com/dune-film-sound/)讨论音乐与音效如何交出前景、共同保持叙事重点。本节的方法是对其取舍原则的迁移，不照搬该片声音、全景声规格或多轮混录流程。

- 静默写明移除哪些声音、保留哪些身体或空间声、持续范围、人物感知和结束触发。
- 完全静默只在世界逻辑或主观听觉成立时使用；通常保留呼吸、布料、空间反射更可信。
- 声音桥登记来源镜头、目标镜头、声音主体、跨越时长、叙事作用和淡入淡出。优先使用环境声、拟音、动作声或非语义人声尾音；音乐桥只在剧情确实需要时使用。台词尾音只写声尾、气口或混响状态，不复制完整台词，不得写“自然衔接”。

### 色彩叙事合同

色彩首先是项目已确认风格的子系统，其次才承担本集变化。禁止把冷蓝、暖橙、红色等机械等同于固定情绪。

色彩脚本写清基础主色、辅色、禁用色/冲突色、人物色彩归属、变化触发、光影路径和高潮状态。色彩变化必须能在光源、时间、天气、实景灯、服装、人物移动或空间转换中解释；认知改变不等于画面自动变色。关键段记录基准主辅色、色温/对比、肤色与主体分离、可见触发、跨镜继承或允许偏移，不要求固定色值。

### Prompt 编译

- 视频 Prompt 不照抄十五列分镜表；以唯一十五列逐镜主表为内容源，阅读稿仅由主表整理供审阅，抽取景别、机位、运镜、时长、声音、动作桥、连续性和抽帧承接等硬信息，结合 `reference_input_plan` 的真实图片职责，改写为 `video.md` 的项目语言五层。每个镜头恰好编译一次。本表保留集内绝对时间与容量预算；工具侧的时间坐标和顺序/时间轴写法统一按 `video.md`“时间预算与模型适配”转换，不把整集时间戳原样塞进单段请求，也不因改用顺序表达而删镜或放宽预算。
- 每个 SEG 只采用与该段直接相关的导演总控卡内容：视觉策略、节奏原则、色彩基线、人物色彩归属、场景光源、核心意象、道具状态、表演节拍、已采用声层、适用的 BGM 入退点、静默、声音桥、禁止表演、禁止色彩跳变和尾态。
- 阅读稿和 JSON 都由十五列主表派生，修正派生遗漏不另建创作源；涉及改变用户已确认剧情或镜头方案时才回对应阶段修订。

## 场次、片段与镜头

“场次、视频片段、镜头”不得混为一层：

- **场次**：连续戏剧空间或连续戏剧行动，使用 `E{集号}S{场号}`，例如 `E01S01`。
- **视频片段**：一次视频模型调用容器，使用 `SEG001`、`SEG002`；它可以包含一个或多个完整镜头。
- **镜头**：一段未经剪切的连续画面，使用 `E01S01-SHOT001`；其中可有连续移动、移焦和重构图，单个镜头不得跨两个视频片段。

模型时长只决定提交方式，不反向决定剧情节奏。不得为了填满模型上限把无关镜头塞进同一片段，也不得把重复裁切、数字推拉或无信息变化的构图算作新镜头。

## 片段与时长

- 交付规模按用户意图伸缩：单条剧情短片通常为 15-60 秒；常规多集短剧单集通常为 1-3 分钟，极短集支持 15-60 秒；微电影通常为 5-10 分钟。具体时长结合用户指令、剧本事件量、对白预算和自然切点确定，并在规划阶段以准确秒数确认。
- 分镜沿用前置规划已确定的模型和制作路径；默认模型、必要方案选择、能力上下限及会员提示只读 `interaction-ask-video-clarification-ref.md`。按剧情节拍、实际时长上下限和自然切点分组，不优先填满上限；尾段过短时重新分配，不能擅自延长成片或换模型。
- 所有镜头使用绝对时间戳，首尾相接，总和等于本集确认时长。
- 已确认模型上限只约束提交容器，不决定镜头节奏；不为填满时长增加停顿。确认后改变时长或内容仍执行原确认规则。
- 片段边界优先落在可剪切拍点且必须同时是镜头切换点：连续动作优先在动作进程 `30%-70%`、遮挡最充分或甩镜运动模糊最强处切出，让下一段从同相位或略微推进的位置接入；只有动作单元真正结束、策略变化、信息揭示、角色反应、场景切换或声音过门时才落在完成态。
- 不在无法接续的台词、动作或关键反应中间强行切开生成容器。片内可在话语、动作进行中切镜；跨 SEG 只有动作相位与接触能可靠承接时采用动作中切，台词完整发声窗口与决定性反应优先留在同一 SEG。
- 按本段在整场戏中的职责记录真实可观察进展，例如“发现线索 -> 误判”“施压 -> 反击”“动作接触 -> 结果反应”；不按生成容器规定状态变化配额。已确认的单一证据、反应或短过渡只承担其真实职责，时长与有效覆盖仍按 `pacing.md`，不能用单一职责之名把常规剧情段拉长。
- 开场与持续事件推进统一按 `pacing.md` 组织，不因类型或片长豁免。
- 中间 SEG 默认使用 `continuous_motion` 或 `cuttable_completion` 尾态，让下一段从动作相位、视线、声音或状态继续，不强制停住。最终 SEG 通常以 `cuttable_completion` 在结果可读、必要反应成立时结束，不额外留固定稳定尾帧。只有剧情确需停顿时才使用 `stable_hold` 并写理由；无缝 Loop 或已确认的未完成动作结尾按真实切点处理。
- `viewer_takeaway` 说明观众从本 SEG 实际获得的行动、证据、反应或必要空间信息，并说明它怎样接住前文、推动下一步；不要求每段独立讲完一轮冲突或另造钩子。开头承诺、持续推进、重要转折与结尾回报按整片叙事位置组织，不能因 SEG 边界重复设置。不能把 10-15 秒片段写成单一慢镜、无信息凝视、纯氛围空镜或只有“情绪很难过”的镜头集合；抒情段也必须让观众看见具体选择、证据、回避、失去或关系变化。
- 人声和动作并行，逐句估时与预算遵循 `pacing.md`。是否无台词取决于已确认剧情，不把台词句数当事件密度。
- `seedance 2.5` 的 `25-30 秒`片段必须在同一场景/动作链/对话轮次能够稳定持续时使用；跨场景过多、复杂动作过载或尾态无法承接时，改用更短片段并说明原因。
- 默认剪辑叙事允许某个片段只包含一个普通镜头，例如短证据、反应、过渡，或镜内已能清楚完成的往来。是否切镜由观看需要决定，不因一个镜头恰好覆盖一个片段就额外切镜或采用 `true_one_take`。只有用户明确要求整段或整片连续拍摄、禁止剪切时，才采用真正一镜到底：从头到尾必须是同一次连续拍摄，禁止硬切、隐藏切、遮挡伪切、匹配剪辑和时间跳跃。可以连续跟拍、平移、推拉、升降、环绕或穿越空间，按实际事件安排连续摄影机路线、主体行动、观察重点迁移与落点，节点数量随叙事职责和时长确定，不设固定配额。单纯缓慢推镜、发光、凝视或无作用的小动作不能代替连续发展的内容。

### 尾态选择算法

在定稿每个 SEG 的末镜前执行：

1. 先判断是否为最终 SEG、无缝 Loop，或后续仍需承接同一动作/视线/声音/状态。
2. 后段必须接同一动作且完成态会失去动势时，选 `continuous_motion`，把尾点放在动作进程 `30%-70%` 的清晰相位，并写方向、速度、接触状态和下一段从何相位继续。
3. 当前动作已经完整，下一段可从结果、反应、视线、物件位置或声音尾音接入，或全片已到有效落点时，选 `cuttable_completion`；结果必须可读，但不额外停住等待。
4. 只有已确认剧情确需停顿，或停顿期间仍产生具体信息、压力或关系变化时选 `stable_hold`；在选择理由中写清观众还需看见什么及所需时长。最终 SEG 身份本身不是停住的理由，不预留固定秒数；中间 SEG 仍须填写 `tail_hold_reason`。
5. 只有首尾画面与动作能形成真实无缝循环时选 `loop_continuation`，同时写明末态如何回到首态；“画面相似”但动作、道具、光线或声音状态不闭合时不得使用。
6. 将所选模式写入末镜动作、声音、SEAM 出段 cue 和下一段入段 pickup。若下一段无法从该尾态自然开始，先改尾点或转场；不得在 Prompt 中同时要求“稳定停住”和“持续高速运动”。

### 真正一镜到底的场面调度算法

只有用户明确要求一镜到底时，才使用 `shot_mode: true_one_take`；默认采用剪辑叙事。用户只要求一镜到底而未要求慢叙事时，不改变 brisk 节奏，连续时间仍须承担叙事价值：

1. **画路线而非列镜头**：先确定（复杂空间用导演卡内的 `blocking_map` 展开）摄影机起点、终点、可通行路径、角色 T0/T1/T2 位置、出入口、遮挡物、光源和必须看清的证据；全段只登记一个 SHOT。
2. **安排有因果的连续节点**：节点必须依次改变空间、关系、信息或动作结果，例如“跟随进入 -> 绕到对峙双方之间 -> 后退揭示门外证人”。每个节点写触发、摄影机路径、主体行动、新信息和进入下一节点的自然动力。
3. **让主体动作驱动摄影机**：角色靠近、回避、抢夺、开门、转身或视线发现决定摄影机何时跟、停、绕、升降或转焦；不得让摄影机无原因游走，也不得只靠持续慢推撑满时长。
4. **维持连续世界**：逐节点核对轴线、屏幕方向、角色速度、道具接触、光位、声音距离和背景锚点。遮挡可以作为真实空间经过，但不得借遮挡伪造切换、换时空、换演员或重置动作。
5. **分配时间与可生成性**：为每个节点保留完整动作和反应时间；复杂多人同步、跨楼层、不可连续通过的空间或需要时间跳跃时判为不可执行。用户要求的一镜到底无法成立时，停止并说明具体冲突，返回调整动作或空间，不能偷偷使用隐藏切。
6. **编译与检查**：Prompt 只写一条连续摄影机路线，节点之间使用“摄影机继续/转向/绕行/停下后再跟随”等连续语言，不写“切到、转场、匹配剪辑、蒙太奇”。检查任一时间点是否都能从前一位置物理到达；无法回答时重做路线。

## 高密度剧情与运镜

分镜阶段要把镜头机制写成叙事功能，不把紧凑误解为机械碎切。连续微动作可以组织成剧情动作组：明确主体动作、对手/环境/道具反馈与结果，再按实际切点分行；一个连续画面可以承载多个微动作，一个动作组也可以跨镜完成。不能只写“快速打斗”“连续躲避”“镜头跟随”，也不能把发生剪切的动作组塞进同一镜来凑数。

动作、追逐、对峙、技能、商业攻防或家庭冲突的高密度段，可从实际轮次选择以下职责；不是每段跑完五步，所列拍法也不是固定配对：

- **起势/亮招**：用近景、特写、低机位、推镜或固定等待建立威胁和行动意图，画面必须让观众知道谁先掌握主动权。
- **接触/碰撞**：用动作切、POV、过肩、横移、甩镜或快推表现第一次交锋，并让道具、身体、空间或声音出现可见反馈。
- **躲避/格挡/误判**：用俯拍、侧跟、后拉、慢动作或短暂停顿展示角色处境，让观众看清危险差一点发生在哪里。
- **反制/策略变化**：先看清证据、技能、道具或选择怎样改变局势，再选择保留同框、转向听者、移焦或移动机位；不能用一次环绕代替反制原因。
- **结果/留白/钩子**：在实际结果、代价或新危机上安排收束或期待。结果细节、共同空间或声音变化都可成立；闪白、遮挡等仅在已有风格和事件需要时使用，不把每轮结尾都做成转场特效。

机位表现人物怎样使用空间，而非给强弱贴固定角度：占优者可以被环境包围，劣势者也可以占据前景；先让实际行动与对方回应证明关系，再决定是否改变景别、焦点、机位或画面占比。局势翻转也可以留在同一构图中，让人物自己改变画面。观众可先看见角色未看见的威胁、证据或伏笔，但要在既定剧情中形成发现、误判、利用或结果，不能让信息差悬空。

## 动态镜头数量

镜头密度从事件及观察职责推导，默认数量基线与例外只见 [pacing.md](pacing.md)。每镜承担一个主要职责；反应、证据或结果镜头可以共同完成事件链，不能重复演完整过程。

- 镜头必须足以清楚表达当前片段实际承担的钩子、目标、阻力、策略变化、高潮或反转、反应和收束。
- 两个以上关键职责只能靠一句台词或静止画面带过时，应增加镜头或镜内变化。
- 删除后不损失具体行动、关系、信息、情感体验或观看节奏的镜头应合并；有作用的环境、共同画面或反应不因没有新事实自动删除。
- 不为镜头数量碎切，不用慢动作、重复反应或无意义空镜填时长。
- 一镜到底只能登记一个镜头，且必须满足真实连续拍摄定义；镜内仍须包含连续变化的摄影机路线、主体行动、关系、空间或信息节点。
- 每个镜头只指定一个主运镜；片段内允许并鼓励切镜，但每个切点必须由动作、视线、遮挡、声音、反应、空间或信息变化触发。
- 人声只继承已确认剧本或轻量预览：出镜对白、旁白、画外音和内心独白各按既定职责覆盖画面，不因拆镜再添一句解释；已确认无人声时保持无人声。每句可跨相邻镜头连续，但不能靠拖长停顿填时长，也不能靠加速语速塞进过短镜头。字幕生成、样式和烧录只继承 `delivery.md`；视频模型阶段仍禁止画面字幕和自动转写。
- 所有时长、所有内容分类执行统一节奏基线；不得用重复反应、推拉或数字裁切凑数。

## 动作桥与观看关系

每个跨镜动作和每个切点都按以下链条设计：

```text
前镜状态
-> 动作发起
-> 运动路径
-> 合理切点或镜内调度
-> 后镜续接
-> 接触/反馈
-> 结果
```

每次切镜回答“为什么现在切”“用什么承接前一镜”“切后观众获得什么”。锚点来自动作、方向、主体位置、视线、形状、光色、声音、文字、遮挡或道具状态的实际事实。一般交接可沿“拿取 -> 移向目标 -> 接触 -> 归位结果”设计；关键接触、验证或方法决定成败时不可省略。观众已知且不影响判断的准备和移动可以用明确省略压缩，下一镜以足够位置、持有者和时间线索建立新状态，不把缺少路径的突变冒充连续动作。

以下方法适用于片内每一对相邻镜头，也适用于跨 SEG 的观看关系；片内直接写进现有画面动作、运镜和声音列，不新增逐切点衔接卡：

| 当前切换 | 前镜送出、后镜接住什么 | 避免的断裂 |
|---|---|---|
| 同一动作换观察位置 | 切在仍在进行的动作上；后镜接同一或略推进的相位，保持移动方向、用手、持有者和接触关系 | 重新起手、物件瞬间换手、尚未接触却已出现结果 |
| 对话、视线或听者反应 | 前镜的提问、目光或动作给出目标；后镜看到对应对象及被触发的回应，维持人物方位和视线关系；同一句声音连续而不重说 | 反应先于触发、对空看、每换镜就重启一句台词 |
| 证据细节回到人物/共同空间 | 前镜细节来自已建立位置；后镜保留刚才的道具状态并呈现辨认后的选择或关系变化 | 特写像另一个物件、回全景后证据复原、只换角度重复已知事实 |
| 省略过程或转换时空 | 出点先建立去向、意图或对照；入点用可辨的地点、人物/物件状态、光线或已有时间线索说明到了哪里及什么变了 | 无提示换场、用相似构图把不同时间冒充连续行动 |

每次切后先让主要对象可辨，并尽快带来新进度；不为了“接顺”先冻结后启动，也不重复上一镜最后一段动作。跨轴或改变屏幕方向时，先由可见走位、共同画面或明确观察位置变化交代新关系。硬切能讲清时直接硬切，闪白、叠化和甩镜不能补救缺少因果与空间关系；相邻两镜各自漂亮并不表示接得上。

## 镜头组因果与单镜职责检查

镜头组形成目标、策略、反馈与结果的完整因果。每镜检查新增观察、情感体验和对事件链的作用；证据镜头、反应镜头无需各自重演起势到结果。删除没有具体观看收益的重复镜头，保留让变化可感的必要阶段。跨镜动作须可理解，允许在自然拍点切换观察位置或作有依据的省略。

## 运镜与镜头差异化

每个镜头先选择观众需要看见的人物、关系、证据或结果，再决定景别、机位和运动；不把推近、拉远、环绕作为默认填写方式。移动镜头的运镜列写清“起点 -> 路径 -> 终点 -> 新看见的内容或正在变化的关系”；固定镜头写清观察位置、取景对象和收益。人物的靠近、回避、绕行、阻挡或追随，先来自其实际意图，再利用前后景、出入口和遮挡使交锋可读，不为展示运镜而让人物绕圈。

按当前观看需要选择具体办法，写进原有画面、运镜和切点列，不新增字段：

| 当前要拍清什么 | 可执行的观察或运动选择 | 应当看见的内容 |
|---|---|---|
| 两人争取同一物件 | 侧向双人中景同时保留双方手部与物件；必要时切接触细节 | 谁在施力、谁在退让，以及退让是被迫还是主动；不能只交替拍两张脸 |
| 前景行动掩着后景回应 | 固定或短距离侧移，前景人物不凭空换位，后景回应在可辨位置出现 | 观众看见另一人藏起、递出、拒绝或准备使用什么；不是无关背景忙碌 |
| 人物边移动边改变办法 | 从其侧后方跟随至实际目标，转到能看清阻挡或选择的位置停住 | 路线为何被改变、人物接着做什么；不能只拍走路到达再重新开场 |
| 一处遮挡影响判断 | 向明确一侧移动，使门框、肩膀或物件逐渐让开关键区域 | 原先看不见的手、出口或物件在合理位置出现，随后影响行动；不因揭示自动追加惊叫 |
| 说者的话真正改变了听者 | 切到听者或保留同框，让原句跨镜连续，看到听者开始行动 | 收回物件、改变条件、主动靠近等回应，而不只是重复皱眉 |
| 已有物件在新局势里改变意义 | 在剧本规定时点给必要细节，再回到人物怎样使用它 | 同一证据从“看见”走到“利用”，不能只有特写加配乐宣告反转 |
| 场面需要尺度、速度或失衡体验 | 用有明确目的的升降、横移、手持贴跟或环绕，沿已知空间落到结果 | 新显露的距离、阻碍或人物关系；没有这些收益时改用更简单的观察 |

这些选择可以组合成不同镜头，不要求逐项采用。固定画面中连续接招、同框关系改变和纵深行动都能丰富视频；单纯把同一张脸推近、拉远、绕一圈仍只提供同一信息。

每镜“运镜”列写主摄影方式及与事件有关的参数：有移动才写方向与速度，有移焦才写焦点从什么转到什么。固定镜头可以写“门口侧面的双人中景，同时看清两人的手和伞柄”，比泛写“固定、电影感”更可执行。推近用于确需逐步排除周边、进入决定性细节或表演的时刻；拉远用于确需显露新范围和处境；环绕用于确需改变前后关系或显露原先被遮住的内容。三者都不能替代人物应对与结果。进入和结束状态归画面动作列，不跨列反复抄写。追逐保持屏幕方向，关系变化保留可读过程；不按题材自动套一条固定运镜串。

常用运镜必须按剧情职责选择，不是凑变化：

| 运镜 | 适合用途 | 执行写法要点 |
|---|---|---|
| 固定 | 对话、压迫停顿、喜剧反应、情绪积累 | 写清谁被困在画内，稳定被什么动作、台词或沉默打破 |
| 推近 | 逼近压力、强调线索、进入人物情绪 | 从哪个景别推到哪里，最终压到脸、手、道具还是威胁物 |
| 拉远 | 揭示环境、关系疏离、结尾余韵 | 从谁或什么物件拉开，新增什么空间、孤立或危险信息 |
| 横摇/竖摇 | 跟随视线、揭示新主体、展示高度 | 从什么主体摇到什么主体，新出现的信息是什么；无信息增量不得空扫 |
| 横移/侧移 | 展示人物与物体关系、制造遮挡切、延展空间 | 平行于谁移动，前景/背景依次揭示什么关系或障碍 |
| 跟拍 | 行走、追逐、行动目标推进、陪伴视角 | 从前跟、后跟还是侧跟，保持什么距离，人物奔向或逃离什么 |
| 手持 | 紧张、失控、冲突临场感 | 跟随哪个动作产生可控晃动，晃动如何服务危险或混乱 |
| 环绕 | 揭示空间关系、主体亮相或关系变化 | 绕谁、绕多少角度，新看见什么关系；不得用运动本身宣告主动权翻转 |
| 升降 | 空间揭示、地位变化、规模感 | 从什么高度到什么高度，揭示什么空间层级或危险位置 |
| 焦点转移 | 线索揭示、信息差、视线关系 | 焦点从前景转向后景或反向，前后景对象和距离必须明确 |
| 变焦/希区柯克变焦 | 惊觉、眩晕、认知翻转 | 只用于单一明确高潮，说明主体尺寸和背景压缩/拉伸关系 |
| 甩镜 | 突发反应、注意转移、动作接力 | 写摄影机实际甩动和落点；若连接另一镜，另按真实切点拆镜，不用模糊掩盖断裂 |
| 匹配剪辑/快切蒙太奇（剪辑方法） | 形态或动作接力、时间压缩、准备过程、连续打击 | 每个实际剪切后的短镜头分别编号，各写主摄影方式；不能把一组剪辑登记成一个未剪切镜头 |

下列是可拆用的覆盖示例，不是整套必用顺序；从实际观察需要选择、删减或保持同框：

| 剧情职责 | 可用组合 | 注意 |
|---|---|---|
| 快速钩子 | 异常细节特写 -> 主角反应 -> 危险或关系揭示 | 依次回答发生什么、谁受影响、矛盾在哪 |
| 对话交锋 | 同框看双方接招，必要时转听者或关键物件，再回到已变化的关系 | 每次切镜对应具体观看需要，不做机械正反打，不按强弱固定配机位 |
| 身份揭示/掉马 | 证据特写或焦点转移 -> 围观反应 -> 主角推近或半环绕 | 先展示证据，再展示认知和权力变化 |
| 悬疑发现 | 遮挡侧移 -> POV 看线索 -> 快推或变焦到反应 | 公平线索先出现，惊觉运镜只用一次 |
| 追逐/逃离 | 侧跟 -> 遮挡切 -> 低位冲刺跟拍 -> 拉升交代位置 | 保持屏幕方向，动作每段改变位置或优势 |
| 打斗/抢夺 | 全景建位 -> 手持起势 -> 接触特写 -> 反应中景 -> 结果全景 | 起势、接触、受力、结果分开，复杂连招拆镜 |
| 情感选择 | 同框保留行动与回应；决定发生在手上或目光时，选择必要细节 | 保留体验转变的过程，不用轻推、拉远和手部特写代替选择 |
| 信息压缩 | 道具/动作结果/时间变化快切 -> 匹配剪辑收束 | 每个短镜头必须给新信息，不用慢动作填充 |

主运镜沿现有家族记录：`static`、`axial`、`pan_tilt`、`lateral`、`tracking`、`orbit`、`vertical`、`handheld`、`optical_focus`、`montage`。家族用于描述与比较计划/实际执行，不设最少家族数或单家族占比配额；固定镜头为主、少量集中运动都可成立。重复拍法是否有问题，要看是否持续提供不同观察和体验，而非是否凑足种类。已有 `camera_variety_exception_reason` 可按需说明取舍，不要求为正常固定覆盖编造例外。

`montage` 是既有记录中的剪辑描述，不是新的摄影机运动；实际分镜仍按每个连续画面编号，分别写固定、跟拍等方式，不能以一个 montage SHOT 绕过镜数、时间轴或真实一镜到底定义。

差异可以来自动作、距离、遮挡、关系、观察对象和构图，不必每镜换运镜。应改变观察而没有改变，或所有镜头都只用推拉放大同一信息时，回到覆盖方案调整；不额外插入一镜运动来“达标”。每镜只选择一个主运镜；简单辅助运动必须先后清楚且不争夺控制权。复杂组合优先拆成相邻镜头序列，如“侧跟 -> 遮挡切 -> 半环绕正面”，避免短镜同时堆叠推、拉、摇、移、环绕。

采用 POV 第一人称时，写明所属角色、眼睛高度、视线方向，以及可见的手部、衣袖、伤痕或手持道具；POV 内不得出现该角色完整正脸，也不得混写为自拍、监控或过肩镜头。运镜词库只是决策候选，不是必选清单；生成前把必要观察与运动路径写清。

## 对白时长预算

人声身份、逐句表演与并行估时统一见 [pacing.md](pacing.md)。每句先估完整朗读窗口，避免动作、台词、反应全部串行相加；字数/秒和朗读占比只作风险预警，实际以清楚、完整和自然表演为准。

## 用户可见分镜阅读稿

按需从唯一主表组织提要、实际章节、SEG 与镜头阅读展示，不另建 `分镜_阅读稿_ep_N.md`；不展示内部 JSON、哈希或校验结果。下面仅示范展示方式，逐镜内容始终取自主表，不维护另一份正文：

```markdown
## 第X集：[可读标题]

### 本集故事提要
[用一段话说明本集主线、冲突、高潮和结尾钩子/落点]

### [实际章节名]（本章实际起止时间与时长）
> 本章叙事功能：[世界观铺陈 / 冲突升级 / 反转兑现 / 高潮落点等]

#### [实际片段名]：[绝对起止时间]（剪辑型或已采用的一镜到底；本段实际镜数）
- **镜头[本场连续编号] ([绝对起止时间])**：[景别｜视角｜主运镜｜机位/角度] 本镜可见行动、证据、关系或反应；完整人声与声音；切入和切出怎样承接。
```

- 章节按照剧本的章节与场次映射排列，不能只写“第一章、第二章”的空标题。
- 按事件链与可剪切拍点组织片段，时长只受已确认参数和模型上限约束；填写真实起止时间，不因模型支持 15 秒或 30 秒就填满上限。
- 每个片段按 `pacing.md` 列全承担实际叙事职责的分镜，镜头时间首尾相接并覆盖完整片段。
- 每个镜头行必须包含：镜头编号、绝对时间、景别、视角、主运镜、机位/角度、画面动作、声音、人声文本或“无”、切入/切出方式。
- 听得见的人声一律写成 `说话人：{原文}`，例如 `旁白：{门已经开了}`；音效用 `<具体声音>`；BGM 用 `()` 或 `（）`；标题、品牌字、时间地点等画面文字用中文引号 `“”`。字幕源使用 `【】`，只在用户明确要求字幕时登记，并明确不由视频模型渲染。
- 阅读展示按需从主表组织自然语言章名、片段名与故事提要，可直接展示主表；用户要求逐镜阅读时即时呈现对应行，不另存第二份完整镜头正文。参数确认表的剧情预览不能替代正式分镜。

## 完整分镜表

内部详细分镜固定使用以下十五列。每一个镜头必须填写；无对白、旁白、音效或抽帧/承接要求时明确写“无”，不得留空。该表与参数确认表中按内容形态选择的五列分镜预览表/剧情节奏预览表职责不同，不得互相改写格式。

| 场次 | 视频片段 | 镜号 | 镜头职责 | 时长 | 画面描述 | 景别 | 机位/角度 | 光影氛围 | 对白·旁白 | 音效 | 运镜 | 切入/切出动机 | 连续性要点 | 抽帧/承接要求 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| E01S01（1-1） | SEG001（分镜01） | E01S01-SHOT001（镜1） | 钩子/证据/反应/反转/压迫/收束等具体职责 | 00:00-00:04（4s） | 写本镜承担的行动、证据或反应及与相邻镜头关系；完整因果由镜头组承载 | 特写/近景/中景/全景等 | 眼平/低机位/高机位/过肩/POV/俯拍等，可写焦段感 | 时间、内外景、主光方向、色温、明暗、材质和情绪 | 说话人：`{完整台词}`；无则写“无” | `<具体环境声/拟音>`；BGM 写 `(具体音乐)`；无则写“无” | 固定观察位置与对象；有移动或移焦时写必要路径与起落 | 动作切/视线切/遮挡切/声音先行/反应切等 | 轴线、视线、动作方向、道具状态、光位和声音接点 | 首帧检查/场景锚点/尾帧承接及目标时间 |

### 各列要求

- **场次**：稳定 ID 使用 `E{集号}S{场号}`，并保留剧本中的人读编号。
- **视频片段**：稳定 ID 使用 `SEG001`、`SEG002`；同一片段内镜头总时长不得超过所选模型上限。
- **镜号**：稳定 ID 使用 `E01S01-SHOT001`，末尾序号在当前场内连续、不重复、不跳号。
- **镜头职责**：写可验证的剪辑职责，不得写“推进剧情”“增强氛围”等空泛词。
- **时长**：写绝对起止时间和本镜持续秒数，与台词、动作、停顿和切点匹配。
- **画面描述**：写清本镜实际承担的行动、证据或反应与必要空间、朝向、轨迹；因果起点、反馈和结果可由相邻镜头共同完成，不要求每镜重复演完整动作。
- **景别**：明确大特写、特写、近景、中景、全景、远景、大远景、过肩或 POV。
- **机位/角度**：明确摄影机高度、观察方向、主客观视角和镜头感。
- **光影氛围**：继承场景日夜、内外景与光源基线，写影响本镜重点的方向、软硬、明暗、反射或天气；未变化时简短指明沿用，不每镜重设计布光或自动变色。
- **对白·旁白**：写明说话人、声音类型和完整文本；用户文本逐字按原顺序保留。
- **音效**：环境声和拟音使用 `<具体声音>`，BGM 使用 `(具体音乐)`，写清进入、持续、淡出或承接时机。
- **运镜**：固定镜写观察位置与清晰对象；移动镜写主运镜、必要方向/速度和路径，移焦才写起落；切点与结束状态各归对应列，不要求不存在的运动。
- **切入/切出动机**：由动作、视线、遮挡、物件、声音、反应、空间或信息变化驱动。
- **连续性要点**：记录屏幕位置、视线、轴线、动作方向、道具状态、光位、环境声和台词尾音。
- **承接输入要求**：说明分镜初始状态、片段承接关系和后段真正需要的输入；仅连续续段确需真实尾帧时安排提取与来源记录，不预设首帧、中间帧或生成后抽帧复核。

## 分段执行索引与按需阅读

分段设计是分镜和视频生成之间的桥：完整模式只在 `storyboard_ep_N.json.segments[]/seams[]` 维护，轻量写视频 manifest。必要字段包括实际时间范围、时长、镜号、片段职责、首尾状态、计划接缝、参考职责与生成风险；动作和全部人声仍引用唯一主表。下表只用于按需展示，不生成独立 SEG Markdown，也不将逐镜时间轴抄写一遍。

| 视频片段 | 时间范围 | 实际时长 | 包含镜头 | 镜头数量与模式 | density_profile / tail_mode | 片段职责 | 逐镜主表引用 | 首状态 | 尾状态 | 与上一片段衔接方法 | 预计输入素材类型 | 生成风险 |
|---|---|---:|---|---:|---|---|---|---|---|---|---|---|
| SEG001（分镜01） | 00:00-00:15 | 15s | E01S01-SHOT001 至 E01S01-SHOT008 | 8；`edited` | `high_density_short` / `cuttable_completion` | 完成钩子、误判和第一轮压力 | 仅引用主表 SHOT001-SHOT008；动作、表演、声音、切点不再抄写 | 主角低头看手机，房间冷光 | 主角抬头看向门口，手机仍在手中 | 起始片段；下一段连续承接时提取真实尾帧 | 按真实输入路由：出场 CHR + 当前 SCN/PROP 必需图片；需新生成人声时必须加入对应已批准 VOICE 并走 `media_to_video`，缺音色参考能力时暂停该调用；后续片段按 seam_mode 决定是否加入真实 tail FRM，默认不传上一段视频 | 近景口型、手机文字、冷光稳定 |

每个非首段在“与上一片段衔接方法”中写入入段承接；每个非尾段在该片段尾状态和逐镜主表的末镜切出落点中写入出段转场。二者必须来自同一个 `SEAMxxx`，不能各自发明转场。

### 视频参考输入计划

每个 `SEGxxx` 必须在 `storyboard_ep_N.json.segments[].reference_input_plan` 中写入视频阶段的图片输入计划数组。它不是最终 Prompt，也不是已传图证据；它用于提前规定“要传哪些图、按什么职责传、开头如何定位、哪些内容必须剥离”。数组可以为空，但只表示当前片段没有任何真实图片输入：首段可据此走 `text_to_video`；非首段仅当 planned `SEAM=elliptical`，且当前新起点不需要任何媒体锚点时才可为空。`continuous` 非首段必须规划上一段真实 tail FRM。视频阶段真实调用时仍以 `video_manifest_ep_N.json.reference_inputs` 和工具 schema 为准，但不得无理由删除分镜已列为必需的输入职责。

每条计划至少写：

```json
{
  "order": 1,
  "role": "previous_tail_as_start_frame|previous_scene_anchor_reference|previous_character_state_reference|previous_prop_state_reference|identity_reference|character_state_reference|scene_layout|prop_structure|prop_state_reference|style_reference",
  "planned_source": "上一段 SEG001 的实际 tail（生成后绑定）|已存在的真实 FRM003|CHR001_v01|SCN001_v01|PROP001_v01|用户素材 SRC001",
  "opening_binding": "[project-language binding for localized marker <图片1>/<IMG1> and its reference duty]",
  "adopt": "[project-language adopted subject, state, space, material, light, or style facts]",
  "exclude": "[project-language excluded subtitles, QR codes, watermarks, UI text, unrelated background, or unrelated people]",
  "required": true
}
```

- `order` 是计划顺序；视频阶段若工具实际上传顺序调整，必须同步改写最终 Prompt 的图片编号标记和 `reference_inputs[].order`，不能照搬旧编号。
- 第一段从已批准资产和文字动作合同启动；无需为事实记录额外提取 start FRM。
- 非首段先读取对应 `SEAMxxx.seam_mode`。分镜阶段的 `continuous` 在 `planned_source` 写“上一段 SEGxxx 的实际 tail（生成后绑定）”，规划 `previous_tail_as_start_frame` 的输入职责、采用事实与首镜衔接；上一段尚未生成时不要求真实 FRM ID、路径或哈希，不因此阻断整集分镜，也不伪造编号。若尾帧已经存在，可引用已登记真实来源。视频阶段再抽取、保存并登记实际尾帧，绑定到 `video_manifest.reference_inputs` 后编译下一段；此时缺真实尾帧才停止该段编译，不得用上一段视频或其他帧冒充。该 role 的状态参考/固定首帧用法按 `video.md`，在现有 `opening_binding/adopt/exclude` 写清。`elliptical` 按已确认新起点选择必要参考，不强制上一段 tail。
- 当前角色状态与已升级为 PROP 的复现道具状态须解析到数据卡 `state_id` 及足够的 approved 图片依据；查找共享库、本集状态绑定与已批准跨集复用项。状态记录与补图判断执行 `assets.md`：已有图已覆盖的归属、方向等变化可明确绑定复用，另写接触与动作；新服装、新破损或内容未被既有图说明时补状态图。按实际职责用 `character_state_reference`/`prop_state_reference` 或适用主 role，不能伪造新图，也不能省掉必要视觉依据。一次性物件不升级 PROP。
- 场景参考只锁空间、灯光、陈设和布局；风格参考只锁色彩、材质、光线、构图、景深和颗粒/线条语言，不承载剧情人物或道具；道具参考只锁结构、尺寸、材质、当前状态和可见面；不得把不同职责的图片混写成同一个主体。
- 任何用户或外部图片都必须写 `adopt/exclude`。图片中的字幕、二维码、水印、平台界面、无关人物、镜面文字和背景杂物默认剥离，除非用户明确要求保留且权限、剧情和平台风险均已确认。
### 唯一逐镜主表的执行要求

不再逐 SEG 另建第二份十五列镜头执行表。把前后状态、动作发起/路径/接触/结果、切入触发/切出落点、观察收益、表演与声音分别落实在主表现有对应列；SEG 只引用镜号范围。集内绝对时间只维护一份，编译时换算片段内时间；以下方法直接用于写主表，不另做阶段检查。

- 每个时间段首尾相接，总和严格等于该片段实际时长。
- 每个镜头都有切入触发和切出落点。
- 每个镜头的主运镜、景别、角度或焦点职责至少有一项与相邻镜头形成叙事差异。
- 每个片段呈现它在整场戏中实际承担的行动、信息、反应或过渡，不规定独立剧情变化的数量；相邻片段可以共同完成一轮推进。短证据、反应或过渡片段不另加事件，普通单镜片段不按一镜到底处理；常规剧情段仍按 `pacing.md` 组织连续有效变化，不以过渡为名拖长无内容的镜头。
- 片段边界必须落在镜头结束处，下一片段从新镜头开始，不重复上一片段已完成动作。
- 主运镜不能只填“镜头移动”。移动镜写清运动家族、路径、必要方向/速度和停止点，例如“侧向跟拍；摄影机在角色右侧平行向门口移动；中速；角色触锁时停在近景”；有实际移焦才补焦点变化。固定镜说明位置和观察收益即可。

## 导演总控卡与主表的分工

导演总控卡只维护本集和场景共用的观看立场、构图/光源/声音基准及实际需要的专项调度。十五列主表维护逐镜行动、台词、切点、表演与变化；分段执行索引维护容器边界、首尾状态和依赖；SEAM 引用同一边界事实。导演卡不再另做逐 SEG 首尾状态、声音交接或戏剧目标表。各处引用同一镜号或场景基准，不抄写整段事实。

下列 `blocking_map`、`lighting_plan`、表演/声音/色彩合同及 `action_ledger` 的导演卡写入位置用于完整模式。轻量同样采用这些推演方法：共用空间、动作不变量及人物信息边界写入已有规划的 `handoff.script_must_inherit`，共用光色与声音机制归 `style_contract`；各节点的站位、接触、持有者、动作相位、视点和结果展开到主表“画面描述”“机位/角度”“运镜”“连续性要点”，光声变化写相应列。跨段边界归原视频 manifest。只记录场面实际需要的内容，保持事件顺序和引用对应，不另建导演卡、账本或第二套逐镜表，也不把复杂动作直接简化为一句“完成打斗/交换”。

- **叙事节拍与片段理解**：在现有镜头职责/画面列和 SEG 片段职责中写清本场实际承担的进展、观众所得与段尾落点；钩子、欲望、阻力、策略变化、代价、信息差等只取实际适用项，不另填一套节拍清单。已有 JSON 的 `viewer_takeaway`、`hook_landing` 可从对应主表位置提取简述，不新增剧情。
- **台词证据链**：把关键身份、指控、承诺、能力、秘密和判断绑定到前置来源、可见证据镜头及其剧情后果；角色撒谎或误判时明确标记。
- **场面调度**：普通对坐、简单转身或单次递物直接在主表写位置、方向和接触；多人交叉走位、遮挡、连续传递、追逐或打斗确需空间推演时，在导演卡建立 `blocking_map`，记录实际节点的人物、道具、摄影机和轴线。
- **布光**：普通场景在导演卡写光源基准，主表只写实际变化；多光源交互、昼夜切换或剧情驱动的照明变化需要推演时才展开 `lighting_plan`，保留来源、方向、色温、照亮区域和连续性。跨 SEG 本身不触发另填一张表。
- **表演指导**：从导演总控卡继承本集表演总纲，落实承担选择、攻防或情绪变化的角色；同镜多名关键角色分别写清，普通共同在场者不为凑行数逐人设计微表情。各表演维度按本镜实际可见和主要变化填写，不要求脸、手、身体与呼吸全套变化。

表演直接写入十五列主表的画面/动作与声音列，不另维护第二张逐镜表演表。写法示例：林远试图结束谈话以掩饰仍在等待；回答时下颌短暂收紧、攥住衣角，呼吸与递还钥匙和台词并行；避免嚎哭和持续瞪眼。只选择本镜可见且改变攻防的维度，不套齐整组微表情。

逐镜声音回指导演总控卡中实际采用的声层及适用的 BGM 入退/发展节点，不要求三层环境声齐全，也不要求配乐；未采用的层不另造声音或曲线。静默或声音抽离有叙事作用时，写清移除/保留哪些声音、持续到什么事件、怎样恢复，不把无台词误写成全静音。逐镜色彩与光线必须回指色彩叙事合同的基准色或触发节点，不得只写“冷色高级感”。
- **动作账本**：简单动作在主表交代路径、接触和结果；涉及复杂接触、连续抢夺或多人同步且单镜描述不足时，在导演卡展开 `action_ledger`，按“起势 -> 位移 -> 接触/落空 -> 反应 -> 结果”拆拍；超出生成稳定性时拆镜或改用反应、遮挡、声音暗示。
- **剪辑动机**：每个切点必须由动作、视线、遮挡、物件、声音、反应、空间或信息变化驱动；“为了丰富镜头”不是动机。
- **逐镜主表引用**：所有 SEG 只引用同一份十五列主表，不再重写时间轴；编译时每镜恰好一次，不遗漏、不重复，也不合并成无节点长镜头。

### 叙事节拍与证据链

完整模式现有 JSON 的节拍索引可按实际需要引用下列字段；不要求每场或每段填齐，不另存节拍文件，也不在导演卡复写。没有实际变化的字段留空或省略：

```json
{
  "scene_id": "E01S01",
  "source_form": "script|outline|sketch|oral",
  "assumptions": [],
  "hook": "",
  "want": "",
  "obstacle": "",
  "strategy_shift": "",
  "power_turn": "",
  "cost": "",
  "information_gap": "",
  "entry_state": "",
  "exit_state": "",
  "cliffhanger_or_payoff": "",
  "evidence_shots": [],
  "dialogue_evidence_map": []
}
```

字段对应画面、动作、台词或声音的可观察事实；某场或 SEG 没有承担权力翻转、代价或悬念时，按现有字段写明本段无此职责，不为填全空格改剧情。关键身份、指控、承诺、能力和结论继承 `scriptwriter.md` 的证据链，再绑定实际揭示镜头及后果；不得只写“反转很强”“推进剧情”。

### 场面调度合同

仅在上述复杂空间调度确有需要时使用 `blocking_map`；以下是字段示例，不是普通双人戏必填表：

```json
{
  "blocking_map_id": "BM_E01S01",
  "orientation": "screen-left-to-right",
  "space_anchors": {"left": "", "center": "", "right": "", "foreground": "", "background": ""},
  "axis": {"a": "", "b": "", "camera_side": ""},
  "beats": [
    {
      "id": "T0",
      "actors": [{"asset_id": "CHR001", "position": "", "depth": "", "facing": "", "eyeline": "", "occlusion": ""}],
      "props": [{"asset_id": "PROP001", "holder": "", "position": "", "visible_side": ""}],
      "camera": {"position": "", "heading": "", "shot_size": "", "movement": ""}
    },
    {"id": "T1", "changes": []}
  ]
}
```

调度先于机位。换机位后按固定世界坐标重新计算屏幕左右、纵深、视线、遮挡和出入画，不得为保持画面左右而暗中移动人物或房间。

### 布光合同

复杂照明推演按需使用 `lighting_plan`；同一光源基准跨段复用，不因段数另建表：

```json
{
  "lighting_plan_id": "LP_E01S01",
  "narrative_purpose": "",
  "key": {"source": "", "direction": "", "kelvin": "", "target": ""},
  "fill": {"source": "", "ratio": "", "target": ""},
  "rim_or_background": {"source": "", "direction": "", "target": ""},
  "darkness_purpose": "",
  "continuity": {"T0": "", "T2": ""},
  "bans": ["无来源泛光", "关键动作不可读"]
}
```

资产图使用可读性优先的标准光；剧情镜使用有画内或世界来源的叙事光。暗部必须有叙事目的，不能用死黑或滤镜替代布光。

### 动作账本

需要拆清复杂接触与反馈时使用 `action_ledger`；简单动作直接写主表，不建立独立账本文件：

```json
{
  "action_ledger_id": "AL_E01S01_镜03",
  "feasibility": {"causal_beats": 2, "actor_count": 2, "camera_motion": "", "decision": "keep|split|offscreen"},
  "beats": [
    {
      "id": "A1",
      "seconds": "0-1.2",
      "initiator": "CHR001",
      "start": "",
      "path": "",
      "contact_or_miss": "",
      "end": "",
      "reaction": "",
      "screen_direction": "",
      "bans": []
    }
  ],
  "tail_state": ""
}
```

动作按“起势 → 位移 → 接触或落空 → 受力反应 → 结果”拆分。动作密度结合因果环节、人物数量、持续时间和摄影机运动判断；超出模型稳定能力时拆镜，或改用反应、遮挡和画外声音。

### 风格在分镜中的落实

场景共用风格基准写入唯一导演总控卡；逐镜的色彩、光影、构图、运动和变化写主表对应列并引用基准，不另建逐段风格表或第十六列。只采用服务剧情的风格机制，不规定每集固定出现多少大师元素，也不能用统一慢推或死黑代替风格。

| 创作维度 | 写入分镜的具体决定 |
|---|---|
| 色彩 | 场景主辅色与变化原因符合已确认风格 |
| 光影 | 光源有来源，方向、软硬和明暗层次明确 |
| 构图与景别 | 服务镜头职责，不机械重复同类特写 |
| 镜头运动 | 方向、速度和停止点符合风格与剧情 |
| 标志机制 | 有叙事作用才采用，不按固定数量凑元素 |
| 跨镜一致 | 用文字合同、采用资产与真实输入提前约束，不安排生成后锚点帧复核 |

## 开场、转场与角色表演控制

### 开场镜头合同

每集第一个可观看节拍必须把 `script_contract.opening_contract` 转译为镜头，而非只在台词或旁白中声明。第 1 集必须直接兑现规划 `OPEN001`；后续集可采用剧本中已解释的变体，但仍要在首镜建立与项目承诺的关系。开场类型只确定观众首先被什么抓住，仍必须服务人物目标、阻力和后续兑现：

| 主开场机制 | 首个可观察承诺 | 镜头设计重点 | 禁止替代 |
|---|---|---|---|
| 悬疑问题 | 可被看见的异常、缺口或未解问题 | 线索可读、视点克制、人物对异常作出行动或错误判断 | 用模糊滤镜、惊吓音效代替线索 |
| 世界观震撼 | 规则、尺度或秩序与人物处境的碰撞 | 奇观必须落到人物目标、代价或行动 | 只有空镜和设定说明 |
| 人物塑造 | 人物独有策略、习惯或失控裂缝 | 先让人物做选择，再解释背景 | 靠旁白贴标签 |
| 视觉奇观 | 一个无法被普通画面替代的视觉事件 | 构图、尺度、反应和后果连续出现 | 只展示漂亮场景 |
| 冲突驱动 | 双方目标立刻相撞 | 明确谁要什么、谁阻止、第一轮反馈是什么 | 无来源的争吵或突发事件 |

每个开场至少登记：首个时间范围、第一可见承诺、人物或世界的即时反应、升级触发，以及本集兑现或悬念延续的场次。把这些内容同步写入导演总控卡的 `opening_proof`：`opening_scene_id` 必须等于剧本合同的场次，`first_shot_id` 必须是该场次第一个承担开场职责的镜头，其余三项写明实际画面证据。入口时机与后续接招按 `pacing.md`；短片也不先用一个完整铺垫节拍等剧情开始。

开头在首个有效节拍建立异常、目标或压力，并尽快给出行动和反馈；执行 `pacing.md`，不再按内容分类或恰好 15 秒设置特殊节奏豁免。最终结尾完成结果、反应和落点；除已规划无缝 Loop 外，不只是回到与开头相似的画面。

### 转场设计合同

转场是两个镜头或两个 SEG 之间的叙事动作，不是后期遮掩错误。每个 `SEAMxxx` 选一个主转场，必要时可附声音桥，但不能把多种无关技巧堆在同一切点。跨 SEG 转场必须采用“双锚单主导”：上一段尾部负责把画面送到可剪切状态，下一段开头负责从该状态迅速接入。由于相邻 SEG 实际上是分开独立生成，双侧 cue 都必须自洽写清画面、方向、速度、遮挡、动作相位和落点，不得写“同上”“相同”“保持上一段”“自然接上”等需要读取另一段 Prompt 才能理解的省略词。

分镜阶段先逐个边界设计 SEAM，再定稿分段执行索引：判断 `continuous` 或 `elliptical`，选唯一主锚点，写清出入点的动作相位。此时使用计划首尾态；连续边界选可继承的动作、视线、接触、方向或遮挡，省略边界选相似构图、物件、声音或明确叙事动机；简单的有动机硬切也可成立，不为每段制造炫技转场。

| 转场类型 | 出点与入点必须匹配的锚点 | 适用场景 |
|---|---|---|
| 动作匹配 `action_match` | 同一动作相位、方向、速度或受力结果 | 连续行动、交接、反击 |
| 遮挡切 `occlusion_cut` | 前景遮挡物的方向、面积和解除时机 | 过门、掠物、人物交错 |
| 相似构图 `graphic_match` | 画面形状、主体位置、视觉重心或色块关系 | 时空跳跃、意义对照 |
| 甩镜同向 `whip_pan_match` | 同向运动、模糊强度和入画落点 | 失控、追逐、能量转移 |
| 视线/物件匹配 `eyeline_match|object_match` | 视线目标或道具形态、位置、接触关系 | 对话、线索、联想 |
| 声音桥 `sound_bridge` | 声音来源、进入/退出点和画面关系；台词尾音只写声尾性质，不复制完整台词；BGM 必须写可复用的乐器/节奏/音量/情绪职责 | 时间/空间转换、余韵；默认只辅助视觉转场 |
| 有动机硬切/叠化 `motivated_hard_cut|dissolve` | 明确的策略、信息或时间关系 | 不应伪装连续性的转场 |

衔接卡必须先选 `seam_mode`：`continuous` 用于同一行动、空间或无跳跃的时间推进，`elliptical` 用于明确的时间/空间/认知跳跃。再填写 `transition_anchor`、`outgoing_prompt_cue`、`incoming_prompt_pickup`、`required_invariants`、`permitted_deltas`、`proof_requirement`：分别说明匹配什么、上一段末镜如何把动作/运镜/声音送出、下一段 0 秒如何接住同一锚点、无论切法如何都不能变化的事实、计划允许变化的维度、生成前须落实的具体连续性依据。`permitted_deltas` 记录叙事时间、空间或事实状态的省略跳跃，不用它禁止正常切镜；`continuous` 不省略这些事实，故该数组为空，但允许已规划的景别、机位和构图切换，写在 `outgoing_prompt_cue/incoming_prompt_pickup` 及逐镜表中，保持空间、动作相位和视线关系可解释。换观察方向时明确对应的屏幕投影，不能借切镜移动人物或道具。`elliptical` 至少登记一项允许的叙事跳跃，仍在生成前落实不变量与计划变化。连续动作优先动作匹配、遮挡切或甩镜同向；跨时空优先相似构图、物件/声音匹配或有动机硬切。无法满足锚点时回到分镜；若视频已生成，则只记录返修建议，等待用户明确确认后再重生或编辑，不能让声音桥掩盖未允许的身份、动作相位或光位错误。

`outgoing_prompt_cue` 与 `incoming_prompt_pickup` 必须成对但不重复：前者写上一段末镜实际怎样通过出画、遮挡、视线、物件接触或声音送出锚点；后者写下一段 0 秒从哪个主体位置、动作相位、观察对象或声音进度接入，并立即发展新信息。匹配窗口取自已规划事件的有效时间，不额外预留“转场专用”的停顿、重复动作或慢推；硬切也不强制添运镜。衔接卡必须把摄影机运动方向转译成屏幕入画方向：例如上一段“向右甩镜至运动模糊，把门框遮满画面”，下一段应写“迅速从画面左边运动模糊和门框遮挡中接入，遮挡解除后停到新主体”，而不是只写“同向甩镜接上”。

方向必须拆开写清：摄影机运动方向、画面中模糊或遮挡物的流动方向、主体从哪一侧入画或出画、停在哪个景别和位置。不得只写“同向运动”。具体左右、上下、前后按该接缝实际画面设计填写，不套固定方向；若方向无法稳定判断，改用遮挡切、物件匹配、视线匹配或有动机硬切。

常见双锚写法：

| 主转场 | `outgoing_prompt_cue` 写什么 | `incoming_prompt_pickup` 写什么 |
|---|---|---|
| 动作匹配 | 动作切到未完成相位、方向、速度、受力点 | 从略微推进的相位开始，完成结果，不重做起势 |
| 遮挡切 | 哪个前景从哪侧进入、遮挡面积、遮满时机 | 从哪侧遮挡中开场，遮挡如何迅速解除并露出新主体 |
| 甩镜同向 | 摄影机甩动方向、模糊强度、切出前画面被什么吞没 | 从对应方向的运动模糊进入，短时间内停到新景别和新信息 |
| 相似构图 | 形状、主体位置、色块或视觉重心如何占满尾帧 | 以对应形状/色块/重心开场，并立刻揭示新时空或新意义 |
| 视线/物件匹配 | 视线目标或物件接触点在尾帧的位置 | 从目标物/接触点开场，说明看见者或持有者如何变化 |
| 声音桥 | 台词尾音、环境声、拟音或 BGM 的出点；台词尾音只写尾音性质和结束时机；BGM 只在剧情需要时写可复用的具体描述 | 声音从 0 秒继续，但只写非语义尾音、呼吸、环境声或拟音；BGM 逐字复用上一段描述，不把上一段完整台词再写一遍；画面动作仍要有具体入点 |
| 有动机硬切 | 上一段以明确结果、反应或信息落点收住 | 下一段快速建立新时空和变化原因，不伪装为连续动作 |

高风险边界先调整切点、观察位置或采用剧本允许的明确省略；仍需桥接时，在已确认时长和剧情范围内安排有叙事作用的桥接镜头或独立 `bridge SEG`，不自动增加总时长、生成数量或调用。角色过多、连续动作无法稳定接续、光位跨度大、尾帧无法传入或工具不支持叠化时，说明具体缺口并沿原变更/授权规则处理。真正重叠两侧画面的转场会消耗两侧有效帧，叠加类光效或声音桥不改变主时间轴；在 `duration_s` 和接缝卡中算清。桥接可选手部接触、前景遮挡、关键道具、视线目标或声音尾音，必须承担信息或情绪作用，不能只是空转场。

### 角色表演谱与情绪曲线

复杂表演可用下表理解同镜内怎样连续变化；实际内容仍直接写十五列主表的画面与声音，不新增 `performance_scores`、`performance_coverage`、情绪曲线表或导演逐段表。微表情、肢体动作与台词在同一时间窗并行，不按表格各列依次演完；停顿只服务真实判断和回应。用“触发 -> 当前状态 -> 人物办法与可见变化 -> 听者回应 -> 结果”组织关键变化，不给普通镜头补全套栏目或毫秒时间谱。台词只出现于其实际发声处，听者反应可同时发生。

| 时间段 | 发生原因/策略 | 基准状态 | 情绪状态与变化 | 可见脸部动作 | 目光与身体 | 声音/呼吸/停顿 | 台词触发 | 听者反应 | 结束状态 |
|---|---|---|---|---|---|---|---|---|---|
| 0-1.5 秒 | 林远看见门口自己的行李，想用归还钥匙结束关系 | 林远握着钥匙站在台边 | 假装利落，仍在意对方是否挽留 | 眉心短暂收紧，与推钥匙和说话同步 | 低头将钥匙推到对方面前 | 自然连贯说完，呼吸与推钥匙并行 | 林远边推钥匙边说“钥匙还你。” | 对方伸手接住钥匙，未将它收走 | 钥匙在对方手下，林远手指刚要离开 |
| 1.5-3 秒 | 对方将钥匙推回，以明日安排挽留 | 钥匙在对方手下，林远手指刚要离开 | 林远从决意离开转为重新考虑 | 林远嘴角微松，与收回钥匙同步 | 林远偷看对方，收回钥匙，将身体转回桌边 | 对方自然接话，不拖音；林远的呼吸随动作变化 | 对方边推回钥匙边说“明早你开门。” | 林远接住推回的钥匙，以转回身体回应，不加解释台词 | 钥匙回到林远手里，两人重新相对 |

- 变化来自台词、动作、道具、信息或对方反应；从观众已经看到的状态开始，前一动作结果成为后一变化的起点，不重置手势、持物和位置。
- 关键听者的有意义选择需被看见，可通过行动、回话或有意不回应表达；普通共同在场者不逐句抢反应。独白与不适用的场面不填听者字段或编造反应。
- 先写能看见的脸部、目光、手势、姿势和呼吸。确有需要才用 `AUxx + 1-5 强度 + 时机` 辅助校准，且面部须清晰可辨；非人、遮脸或远景不伪造 AU 精度。AU 不替代自然语言，也不新增记录文件。
- 同一时刻突出主要变化，复杂情绪按实际触发连续展开；角色压力、选择与关系后果写在场景和镜头中，不用 BGM 或色调替代。说话准备与正在发生的行动重叠，不自动追加开口前和句末停留。

## 连续性与片段衔接

连续性计划统一保存在 `storyboard_ep_N.json.segments[]/seams[]`，不另建分段表、账本、衔接卡文件或第二份逐镜记录。每个边界用唯一 `SEAMxxx` 关联相邻 SEG，保留主锚点、出入动作相位、不变量、允许变化与参考依赖。轻量模式直接把同样的必要边界信息写在视频 manifest。

连续边界写清上一段计划尾态、下一段首态、人物位置朝向/视线、道具持有及接触、轴线、主光和空间锚点、动作趋势；这些是生成设计，不是生成后比对结果。采用有动机硬切、动作/视线/物件匹配、遮挡或声音桥时，写明唯一主转场、锚点、允许变化及声音入退。出段 `outgoing_prompt_cue` 与入段 `incoming_prompt_pickup` 共用同一锚点，避免双转场、反向运动及动作重做。

`continuous` 仅在后续调用确实需要时提取并绑定前段真实尾帧，首镜说明状态参考/固定首帧与机位变化；`elliptical` 写清时间、空间或认知跳跃及新起点，不硬传前段尾帧。分镜阶段允许引用尚待生成的尾帧职责，不伪造 FRM 或路径。

在设计时想清普通拼接是否可读，存在跳变就提前选择桥接、遮挡、换机位或明确省略。默认用完整生成片段；确有已授权裁剪方案则记录计划切点与声音处理。不安排生成后接缝帧窗口、观察对比、审片选切点或新确认。

## 参考资料与参考视频

分镜阶段接收用户图片、视频、脚本或风格参考时，先按 `manifests.md` 的 `source_manifest.json` 分类并写明采用什么、不采用什么；跨阶段冲突优先级仍按 `control-contracts.md`。

针对 Seedance 运镜模板类资料：

- 采用：逐镜“景别 + 机位 + 运镜 + 动作”的结构、跟拍/环绕/升降/手持/焦点转移/甩镜/匹配剪辑等候选，以及动作匹配切镜和接缝重复帧排查思路。
- 不采用：默认 `4K/60fps`、固定三秒定格、所有动作都缓慢、每句最多两种运镜等与当前工具 schema 或剧情职责冲突的模板；最终参数以实际工具能力和项目节奏为准。
- 组合名称不能直接复制成模糊 Prompt。必须拆为相邻镜头，或在模型已验证、路径简单时拆成同镜先后两段运动。

参考视频必须拆成六项可迁移导演信息：

```text
reference_structure：段落结构、信息顺序、切点逻辑
reference_pov：机位、景别、视角和观察者身份
reference_motion：主体动作、摄影机轨迹、速度和节奏
reference_emotion_arc：情绪起点、升级、翻转和回报
reference_audio_logic：台词、环境声、拟音、音乐和声音桥关系
reference_risk：需剥离的品牌、人物身份、字幕、口号、水印、平台 UI 和未授权内容
```

只迁移已声明的结构、视角、运动、情绪或声音机制，不复刻原人物、场景、品牌和文字。

## 与视频阶段的边界

分镜阶段不写最终视频 Prompt，只提供视频可编译的事实：

- 稳定场次、镜头和片段 ID。
- 每镜画面、职责、时长、景别、机位、光影、对白、音效、运镜、切点动机、连续性和抽帧/承接要求。
- 每个 `SEGxxx` 的主表镜号引用、首尾状态、衔接方法、必需图片职责和预计输入素材类型。
- 人物、角色状态、主要场景、音色、道具状态、文字视觉合同及 FRM 抽帧计划；每个需引用的状态绑定真实 approved 依据，注明复用或确需补图的范围，未补齐项不得声称可执行。

视频阶段把分镜和资产编译成项目语言时间轴 Prompt。每个 SEG 必须具备可传入的当前角色/状态、场景、必要风格及复现 PROP 依据，可来自共享、本集或 approved 跨集复用项。新外观需要状态图时列出实际文件；仅关系/方向改变且旧图已充分说明时列出同一 approved 来源及本段动作，不因状态名不同增加图片。一次性道具状态只写动作与 Prompt；跨段承接按 planned SEAM 消费真实 FRM。人声写明主体、音色锚点、类型、逐字文本和发声窗口；出镜对白在人物可见的发声时段要求对应口型；旁白、画外音和内心独白不驱动画面人物对该句做口型，不禁止另有已确认对白。跨镜发声、叠话与主次按 `video.md` 的人声合同转写。

### 创作时落实的镜头与视听方法

下表用于直接设计分镜，不是额外阶段质检或打勾流程。

| 评估维度 | 达标标准 |
|---|---|
| 镜头职责 | 有明确行动、关系、信息、情感体验或节奏作用；重复同一体验且无发展才合并 |
| 开场承诺 | 第一个叙事节拍实际呈现开场问题、人物、奇观或冲突，并已绑定后续兑现 |
| 观察与运动 | 固定或运动均服务具体观看收益；区别来自事件与观察关系，不凑家族数量或占比 |
| 运镜执行 | 现有家族统计只描述计划与实际偏差，不以种类多代替质量 |
| 切点动机 | 每个切点都有动作、视线、遮挡、声音、反应、空间或信息触发 |
| 连续性 | 轴线、视线、动作、道具、光位和场景拓扑无冲突 |
| 信息密度 | 持续产生行动、反馈、关系、线索或情绪变化，不按固定秒数打点 |
| 风格落地 | 能指出色彩、光影、构图、材质和运镜的证据镜号；文字风格合同不引入额外人物或道具 |
| 表演层次 | 关键角色的基准、触发、采取的办法与尾态可读；只突出所需脸部、目光、肢体或声音变化，听者不机械抢反应 |
| 情绪曲线 | 关键角色的触发、可见表演变化、关系后果和尾态与场景攻防一致 |
| 转场策略 | 每个 SEG 接缝的主转场、锚点、允许变化与声音交接明确 |
| 声音叙事 | 实际采用的环境声、主观声、BGM、静默和声音桥有职责与入退点，不为齐全强加声层；人声跨镜不重复 |
| 色彩叙事 | 主辅色、色温/对比、主体分离和色调偏移有触发节点，并与人物认知或关系变化一致 |
| 可生成性 | 复杂动作、多人同框和长镜有拆镜或降级方案 |
| 抽帧承接 | 只有后续调用确需尾帧时安排真实尾帧；状态依据优先复用采用资产，转场合同提前可执行，不安排生成后窗口核验 |

写作时直接解决覆盖、因果、连续性和容量；保留具体策略，不新增诊断报告、阶段 lint 或质检确认。

## 存储与阶段确认

本阶段产物统一进入当前 `ep_N` 的分镜目录；路径、命名和 `storyboard_ep_N.json` schema 只读取 `manifests.md`。

完整模式保存十五列主表、导演场面策略及统一 JSON 的 SEG/SEAM 边界与必要索引；阅读稿按需从主表展示，不另维护副本。主表覆盖采用剧本的全部场次、动作和人声；专项调度/布光/动作只在实际需要时写入现有导演卡并用镜号引用，不重写逐镜内容。索引顶层与引用按 `manifests.md`，未来真实尾帧待就绪才绑定。

完整模式继续制作时，保存后展示可审查的阅读稿与简要镜头方案，取得认可再进入视频参数确认；纯分镜目标展示并交付即结束。不运行独立阶段检查，不展示内部执行文件、机器字段或报告。轻量纯分镜目标只交付十五列主表，不创建视频 manifest 或 Prompt；轻量视频目标保留主表和视频 manifest 内的分段依赖，再编译 Prompt，除用户明确要求先看之外不另设分镜确认。

收到修改意见时只修订分镜。改变镜头职责、时间轴、轴线、接缝或大范围执行合同的重大修改重新提供完整受影响文件；局部文字或单镜微调只提供修改文件、修改前后和影响范围。继续视频制作时，完整模式保留适用的分镜创作确认；轻量模式把修改纳入同次生成展示，不另设分镜确认，用户明确要求先审时按其要求等待。目标只到分镜则交付即结束。实际生成仍须取得覆盖当前版本和范围的视频授权，方案变化的授权失效按视频交互 Ref 处理。
