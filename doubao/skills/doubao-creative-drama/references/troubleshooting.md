# 全流程排障 Ref

当任一阶段出现错误、结果不符合预期、状态与文件不一致，或不知道应返回哪个阶段时读取本文件。本文件是重试预算、责任阶段和恢复路径的唯一权威。

## 本 Ref 关键要求

- 先读当前实际文件和状态，不凭聊天记忆判断。
- 返回最早出错层级；上游合同正确但模型执行漂移时留在当前生成阶段处理。
- 同一缺陷最多自动定向重试 1 次；但视频生成、重生或编辑不适用自动重试，且视频工具已返回可播放/可渲染结果后不得因自检问题自动返修或主动说明问题。第二轮仍失败则停止并升级给用户或返回责任阶段。
- 修复只补失败项和必要上游，不覆盖最后一个已确认版本。

## 排障原则

1. 先读 `drama_plan.json`、`制作状态.json`、`操作日志.jsonl` 和当前实际文件，不凭聊天记忆判断。
2. 区分“工具调用失败”“文件结构错误”“内容错误”“实际媒体质量错误”，不能只看接口是否成功。
3. 返回最早出错层级：规划错回规划，剧情错回剧本，镜头合同错回分镜，已批准 CHR/PROP 设定或确认采用的 VOICE 修复资产本身错误回资产，生成片段中的身份、场景、道具、原生声线、口型或运动执行漂移回视频，拼接/混音/字幕错回成片。
4. 保留最后一个已确认版本，只创建新版本，不覆盖。
5. 外部调用按部分成功处理：先盘点真实产物，只补失败项。
6. 同一缺陷最多自动定向重试 `1` 次：初始失败为第 1 轮，修改明确变量后的自动重试为第 2 轮；第 2 轮仍存在同一缺陷时停止，不再自动生成，按最早责任层级升级。视频生成、重生或编辑的结果检查不触发自动重试；视频工具已返回可播放/可渲染结果后，模型意外生成的字幕、随机文字、水印或平台 UI 按既定字幕策略执行非视频生成类清理，其他质量、连续性、口型或身份问题只内部记录缺陷和建议，仍按原交付文案展示，不主动说明问题。只有用户明确提出修改、返修、重生、新视频或继续视频任务，并重新完成视频参数确认后，才可提交新的 `media_to_video`、`image_to_video` 或 `video_edit` 调用。
7. 每次修复记录问题证据、归属层级、修复动作、版本和复验结果。

## 缺陷编号

| 前缀 | 类别 | 典型问题 |
|---|---|---|
| `V` | 视觉 | 身份漂移、复制主体、道具/场景/光线漂移、随机文字或水印 |
| `A` | 音频 | 静音或漏说、错人、声线漂移、口型错位、截断、噪声或响度突变 |
| `F` | 衔接 | 构图位置跳变、动作回弹/重复、光色跳变、声音桥断裂、未经检查的文件边界直拼 |
| `S` | 镜头执行 | 镜头遗漏、单动作拖时、运镜同质化、动作复杂度超限、计划与实际不符 |
| `N` | 叙事 | 动机或因果断裂、钩子未兑现、高潮依赖巧合、台词缺少证据 |

每个缺陷记录首次时间码、证据、责任阶段、修改变量、修复版本和复验结果。上游合同正确但模型执行仍漂移时留在当前生成阶段，改用拆分片段、更换已确认兼容模型或如实声明能力限制，不得无依据使上游失效。

## 快速定位

| 症状 | 首查阶段 | 证据 | 首选修复 |
|---|---|---|---|
| 受众、平台、风格或规模反复变化 | 规划 | `drama_plan.json` revision、开放问题和确认状态 | 返回规划，重新确认并使下游失效 |
| 剧情平、人物被动、反转无铺垫 | 剧本 | 场次因果、信息差账本、台词证据链 | 重写最早失效场次 |
| 片段只有一个慢动作、运镜重复或全是推拉 | 分镜 | 十五列详细分镜、片段执行表、shot_plan、运镜家族统计和切点 | 增加状态变化；把无职责推拉改为跟拍、横移、环绕、升降、手持、焦点转移、遮挡切或匹配剪辑 |
| 结构化台词存在但视频无声 | 视频 | 检查实际提交的 `compiled_prompt_file` 是否逐句包含 `{spoken_text}`、说话人和发声方式 | 缺失则重新编译 Prompt；已包含但仍无声时核对原生音频能力和实际音轨，不得直接归因于字幕 |
| 视频近似静止或像幻灯片 | 视频/关键帧 | 检查 `observable_state_changes`、逐镜 `subject_action/state_change`、实际 Prompt，以及是否无差别传入过多静态关键帧 | 补足动作起点、过程、反馈和结果；关键帧只保留高光时刻，按工具能力作为参考使用 |
| 已批准角色或道具设定本身错误 | 资产 | CHR/PROP 版本、需求来源和验收记录 | 建立正确的新资产版本，不覆盖旧版 |
| 生成片段中的角色、服装/装具、道具或场景漂移 | 视频 | 已批准 CHR/PROP、上一段场景锚点帧和尾帧、文字承接 | 内部记录强化文字锚点和可选重生范围；不伪造参考图输入，用户主动要求修改前不调用视频工具 |
| 计划人声静音、漏说、类型或口型职责错误 | 视频 | `speech_mode`、speech type、逐字文本、时间窗、原生音轨和嘴部 | 内部记录原生发声 Prompt 修正建议；旁白/画外音/内心独白明确画面人物不开口，用户主动要求修改前不调用视频工具 |
| 每个片段边界明显跳一次 | 分镜/视频/成片 | SEAM 合同、前段末 12 帧、后段首 12 帧、动作相位、摄影机运动、光位和声音桥 | 不按文件边界直拼；从窗口选切点，失败则内部记录可选重生后段或重设分镜边界，用户主动要求修改前不调用视频工具 |
| 画面中残留模型硬字幕、随机文字或旧字幕 | 视频/成片 | 视频生成参数、片段抽帧、字幕擦除结果和擦除后抽帧 | 先确认生成阶段已禁用字幕；片段正式交付前使用非视频生成类媒体能力擦除并验证，仍残留则停止该片段交付并说明客观处理能力缺口，不自动调用视频工具 |
| 字幕错位、越界、遮脸或遮道具 | 成片 | 最终音轨、SRT、宿主字幕预设、渲染抽帧和安全区 | 重新 ASR 或人工对轨并调整字幕预设或断句后烧录 |
| 工具返回成功但看不到内容 | 当前执行阶段 | 返回 ID、文件大小、实际播放/查看结果 | 不更新状态，重新取证或修复失败项 |
| 状态显示完成但文件缺失 | 控制层 | `制作状态.json`、产物清单和磁盘 | 回退状态并补齐产物 |

## 第 0 阶段：规划

| 问题 | 诊断 | 修复 |
|---|---|---|
| 一句话卖点与剧情目标无关 | 比较 `creative_proposition` 和用户目标 | 重写卖点、戏剧问题和成功定义 |
| 受众画像像刻板印象 | 检查来源状态和检索证据 | 改为待验证假设，删除人口标签推断 |
| 类型、情绪和风格互相冲突 | 检查主路径、辅助路径和排除项 | 保留一个主路径，明确辅助职责 |
| 风格只有“电影感”“高级感” | 检查 `style_contract` | 改写为光线、色彩、构图、材质和节奏机制 |
| 模型、时长或视频确认轮次不兼容 | 对照当前工具 schema 和已确认模型 | 停止调用并返回规划重新确认；用户未指定时仍固定 seedance 2.0 fast、单 SEG 不超过 15 秒，不得自动切换 2.5 |
| 风险只有名称没有处理方式 | 检查 `risk_plan.mitigations` | 为每项风险补缓解、确认或接受理由 |

## 剧本阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 主角被动等待 | 逐场找改变局势的选择 | 给主角目标、时限、策略和代价 |
| 场景删掉也不影响剧情 | 做删除测试 | 合并或重写该场 |
| 反转突然出现 | 反查公平线索和前置规则 | 补铺垫或删除反转 |
| 台词只解释画面 | 标记每句策略和结果 | 改为试探、逼迫、回避、反击或行动 |
| 关键声明没有证据 | 查台词证据链 | 增加可见动作、道具、结果或标记主观判断 |
| 台词在时长内说不完 | 朗读估时 | 调整场次、动作或时长，不改用户原文 |

## 分镜阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 分镜多但生成仍是长镜头 | 对照片段执行表和 Prompt 第三、四段 | 为每镜补动作桥、切入原因、主运镜、新增信息、承接锚点和切出落点 |
| 运镜统一推近/拉远或统一固定 | 对照 `storyboard.md` 的运镜分布检查、例外理由和实际画面 | 按信息、权力、速度和空间变化重选摄影机路径 |
| 镜头碎切 | 做删除测试 | 合并没有独立职责的镜头 |
| 长镜头没有内容 | 对照 `storyboard.md` 的真实一镜到底定义和尾态要求 | 增加连续摄影机路线、主体行动、空间变化、有效调度、焦点、信息与结果，或拆镜；不得补隐藏切点 |
| 跳轴、换手、瞬移 | 查 blocking_map、轴线和动作桥 | 按“前镜状态 -> 动作发起 -> 运动路径 -> 切点/镜内调度 -> 后镜续接 -> 接触/反馈 -> 结果”修正 |
| 开头不抓人 | 先检查 `density_profile` 和首个完整叙事节拍 | `high_density_short` 的 15 秒视频补足前 3 秒至少 3 个可见信息事件及一次观看关系变化；其他类型强化首节拍中的问题、目标、关系或悬念，不机械碎切 |
| 高光只有发光或慢推 | 检查高光因果链 | 补齐“触发 -> 变化 -> 反馈 -> 结果”，并让结果改变人物、产品、道具、关系、信息或场景状态 |
| 结尾只是回到相似画面 | 检查结果、反应与落点 | 补完整结果和落点；只有已规划无缝 Loop 才允许回到起点构图 |
| 台词、动作在片段边界被截断 | 查绝对时间轴 | 把边界移动到真实切镜点 |

## 资产阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 三视图生成多个角色 | 查防复制声明和头部身份锚点 | 明确同一角色多个角度，只出现一个主体 |
| 三视图带笑、怒、惊讶、卖萌或异常修饰 | 查中性表情与类型分支 | 恢复无情绪状态，并按真人、动漫、卡通或动物分支定向重生 |
| 真人脸部畸变或动画/动物结构异常 | 对照 `representation_type` 查看头部特写及侧面 | 真人按正常人脸、动画按原设计、动物按物种头骨与器官结构重生 |
| 动漫、卡通或动物被错误真人化 | 核对类型策略、画风合同和资产说明 | 锁定角色类型、轮廓、颜色纹理及物种特征后重生 |
| 角色换装或毛发状态变化后身份漂移 | 查状态版本来源 | 基于已批准身份资产生成新三视图 |
| 同一 SEG 内服装或发型突然变化 | 查 `project_data_card.json` 状态时间线和分镜变化镜头 | 无变化镜头则内部记录该 SEG 可选重生范围；确有剧情变化则补状态记录与对应镜头 |
| 不同集角色面部、身高体型或音色漂移 | 对照 CHR/VOICE 共享基准、数据卡身份锁和本集 3-5 张代表帧 | 保留共享基准，内部记录漂移 SEG 可选重生范围；不得为本集另造角色或音色 |
| 主要场景跨集布局变化 | 对照 SCN 布局参考、数据卡场景状态和实际 FRM | 无剧情原因则内部记录可选重生范围；确有改造或时间变化则先更新状态时间线 |
| 道具结构变形、部件错位或比例失调 | 对照道具结构、部件数量、连接方式和尺寸比例 | 强化结构描述后定向重生；局部问题可限定区域做 `image_edit` |
| 道具材质塑料化或颜色漂移 | 检查材质、光泽、纹理、主辅色和棚拍高光 | 写具体可见材质特征并重生，不用“高级质感”等空词 |
| 道具开合、破损、发光或内容物状态错误 | 核对当前 `PROPxxx` 状态版本与连续性账本 | 为互斥状态建立独立版本，只修复错误状态 |
| 三视图结构不一致或内部细节不可见 | 比较正面/侧面/背面并检查细节卡需求 | 重生三视图；内部结构、刻字或机关另生成细节卡 |

| 静音、漏说、串角色、类型错误或口型错位 | `A-*` | 播放原生音轨，核对声音主体、type、逐字文本、时间窗和嘴部职责 | 内部记录 `speech_mode`、`speech_lines` 与发声描述修正建议，用户主动要求修改前不调用视频工具 |
| 构图跳变、动作回弹、声音桥断 | `F-*` | 对比 SEAM 双侧 12 帧窗口、动作向量、摄影机运动、光位和音频 | 调整实际剪切点；内部记录动作/遮挡/甩镜匹配或声音桥修正建议，用户主动要求修改前不调用视频工具 |
| FRM 与 KF 核心状态偏离 | `V-*` / `F-*` | 对比相关高光 KF 与实际 FRM，定位身份、构图、状态或动作相位差异 | 核心因果或连续性受损时内部记录 SEG 可选重生范围；仅审美轻微差异可记录 accepted，用户主动要求修改前不调用视频工具 |
| 镜头遗漏、单动作拖时、运镜同质 | `S-*` | 对照 shot_plan 逐镜检查计划/实际运镜家族 | 修 Prompt；实际仍退化为推拉时返回分镜重分配路径 |
| 因果断裂、钩子未兑现 | `N-*` | 对照规划、剧本和分镜 | 返回最早叙事错误层级 |

## 成片阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 接缝硬跳 | 正常速度与 0.25x 慢放 SEAM 双侧帧窗口 | 不直接拼文件边界；优先调整切出/切入帧、动作匹配、遮挡切或甩镜同向接入；仍不理想时只内部记录可选责任片段，用户主动要求修改前不调用视频工具 |
| 音量忽大忽小 | 探测人声、环境声和 BGM 响度 | 分轨混音与响度归一 |
| 宿主媒体任务来源缺失或不匹配 | 检查任务 ID、状态和输出路径 | 继续查询真实任务到完成或重新调用对应宿主能力；不得手写任务结果或复用其他任务 ID |
| 宿主命令返回但任务仍在运行 | 单次轮询未等到完成 | 使用同一 task_id 再次轮询；不得当作失败、不得重复提交 |
| 基础检查为 blocked | 查看检查摘要中的具体错误 | 按错误修复媒体或 SRT，重新播放和检查 |
| ASR 对齐存在疑似错字 | 查看 alignment 的时间范围、expected_text、asr_text 和 differences | 定向试听；字幕正文仍取 spoken_text，确认是否需要修改 |
| ASR 对齐出现整句缺失或无效时码 | 对照 script_contract、ASR 原始信封和最终音轨 | 重新 ASR 或人工复核；若确认源音轨缺失，只内部记录可选视频返修范围，用户主动要求修改前不调用视频工具 |
| 字幕与发声不同步 | 比较最终音轨、ASR 时间戳和 SRT | 对最终音轨重新 ASR 对齐 |
| 字幕越界或遮挡 | 渲染首/中/尾帧检查字幕安全区 | 优先调整宿主位置预设或断句并重新烧录 |
| 修完局部又出现新问题 | 检查客观交付文件是否可播放 | 只要文件存在、可解码、可播放并完成当前环境交付，就不因主观内容问题延迟交付；内容问题记录为用户主动修改时的线索 |

## 工具、状态与部分成功

- 工具不存在：停止当前阶段，只说明对可见产物的影响和需要用户选择的替代方案；不报告内部工具名、能力字段或已落盘内部产物。
- 内部结构缺口、校验缺口或运行配置差异可自动修复或降级时：直接处理并继续，不向用户解释具体字段、机器可读结构、内部文件名、检查机制、运行配置或代码要求；确需用户补充时，只说缺少可理解的素材、授权、剧情选择、模型选择或确认信息。
- 工具路由错误：先逐张盘点真实媒体输入；当前目标没有任何有效视觉参考维度时才用 `image_gen`，存在需要视觉输入锁定的身份、结构、空间、构图、媒介或画风维度时用 `image_edit`；视频片段按实际输入路由，存在视频或音频输入时用 `media_to_video`，只有图片输入时用 `image_to_video`，没有媒体输入时用 `text_to_video`。`continuous` 非首段必须传入上一段真实 tail FRM；`elliptical` 非首段按新起点实际需要选择输入。已批准 VOICE 在实际 schema 支持音频输入时传入；不支持时保留同一 `voice_anchor` 文字锚点，不得为强行使用 `media_to_video` 伪造音频输入。修改已有视频才用 `video_edit`，且只能输入一个视频，并在 Prompt 中保留原视频人声、原音色和原口型关系。凡是重新调用视频生成或编辑工具，都必须先按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- `video_edit` 输出时长或比例变化：判定编辑失败，保留源视频并标记需重新编辑；确需改变时长或比例时返回分镜/成片建立新版本，不放宽编辑合同。重新编辑前必须按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- 旧项目只有旧版计划文件：保留原文件备查，将其内容迁移并补全为 `drama_plan.json`，在当前对话中重新直接输出完整参数确认表并完成 planning 确认；不得只改文件名或用附件代替对话确认。
- 参数 schema 不确定：读取实际 schema，不从其他工具类比参数。
- 模型不兼容或生成失败：不得以提高质量、延长片段或节省重试为由自主换模型；`seedance 2.5` 与 `seedream 5.0 pro` 必须先展示 `（会员模型并且消耗最多的额度）` 并取得明确确认。
- 调用超时：先检查返回 ID、任务状态和文件，不立即重复调用。
- 部分成功：保存成功项及版本，只补失败项；涉及视频生成、重生或编辑的失败项只记录返修范围，重新调用前必须按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- 本地大改：先写同目录临时文件，验证后原子替换，成功再清理。
- 状态更新：产物实际验证通过后才递增 revision 和提交阶段状态。

## 排障结束条件

只有同时满足以下条件才结束排障：

- 根因归属到明确阶段和稳定 ID。
- 修复动作已落盘为新版本。
- 自动结构检查通过。
- 图片已目视、音频可试听、视频具备可渲染/可播放资源；视频内容问题只内部记录，不作为交付前阻断。
- 缺陷记录包含证据和复验结论。
- 受影响下游已经重新生成或明确失效。
