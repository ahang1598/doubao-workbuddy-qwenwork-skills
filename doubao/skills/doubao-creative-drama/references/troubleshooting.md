# 全流程排障 Ref

仅在真实工具错误、已知输入/记录问题，或用户主动要求定位/修改结果时读取本文件；不为寻找问题而自动检查生成结果。下表是问题触发后的可选定位方法，不是常规质检、固定截图或播放流程。本文件是重试预算、责任阶段和恢复路径的唯一权威。

## 本 Ref 关键要求

- 先读当前实际文件和状态，不凭聊天记忆判断。
- 返回最早出错层级；上游合同正确但模型执行漂移时留在当前生成阶段处理。
- 非视频工具失败最多定向重试 1 次；不主动质检媒体或自动内容重生，视频调用始终重新取得生成授权。
- 修复只补失败项和必要上游，不覆盖最后一个已确认版本。

## 排障原则

1. 先读 `drama_plan.json`、`制作状态.json`、`操作日志.jsonl` 和当前实际文件，不凭聊天记忆判断。
2. 区分“工具调用失败”“文件结构错误”“内容错误”“实际媒体质量错误”，不能只看接口是否成功。
3. 返回最早出错层级：规划错回规划，剧情错回剧本，镜头合同错回分镜，已批准 CHR/PROP 设定或确认采用的 VOICE 修复资产本身错误回资产，生成片段中的身份、场景、道具、原生声线、口型或运动执行漂移回视频，拼接/混音/字幕错回成片。
4. 保留最后一个已确认版本，只创建新版本，不覆盖。
5. 外部调用按部分成功处理：先盘点真实产物，只补失败项。
6. 非视频工具失败最多定向重试一次；不主动检查媒体触发内容返修。任何新增视频调用仍须重新取得生成授权，不因用户抱怨或执行者发现问题自动提交；不自动清理生成结果中的意外文字。用户明确要求定位问题时才用对应方法，修复只作用于受影响项。
7. 每次修复记录问题证据、归属层级、修复动作、版本和复验结果。

## 缺陷编号

| 前缀 | 类别 | 典型问题 |
|---|---|---|
| `V` | 视觉 | 身份漂移、复制主体、道具/场景/光线漂移、随机文字或水印 |
| `A` | 音频 | 静音或漏说、错人、声线漂移、口型错位、截断、噪声或响度突变 |
| `F` | 衔接 | 构图位置跳变、动作回弹/重复、光色跳变、声音桥断裂、未设计好边界导致突兀拼接 |
| `S` | 镜头执行 | 镜头遗漏、单动作拖时、运镜同质化、动作复杂度超限、计划与实际不符 |
| `N` | 叙事 | 动机或因果断裂、钩子未兑现、高潮依赖巧合、台词缺少证据 |

每个缺陷记录首次时间码、证据、责任阶段、修改变量、修复版本和复验结果。上游合同正确但模型执行仍漂移时留在当前生成阶段，改用拆分片段、更换已确认兼容模型或如实声明能力限制，不得无依据使上游失效。

## 快速定位

| 症状 | 首查阶段 | 证据 | 首选修复 |
|---|---|---|---|
| 受众、平台、风格或规模反复变化 | 规划 | `drama_plan.json` revision、开放问题和确认状态 | 返回规划，重新确认并使下游失效 |
| 剧情平、人物被动、反转无铺垫 | 剧本 | 场次因果、信息差账本、台词证据链 | 重写最早失效场次 |
| 片段只有一个慢动作、运镜重复或全是推拉 | 分镜 | 十五列详细分镜、分段执行索引、shot_plan、运镜家族统计和切点 | 先找缺失的行动/信息/回应职责，按 `storyboard.md` 重选观察位置与切点；确需运动时再选路径，不能只换运镜名称 |
| 结构化台词存在但视频无声 | 视频 | 检查实际请求快照中的 Prompt 原文（旧项目可读 compiled_prompt_file） 是否逐句包含 `{spoken_text}`、说话人和发声方式 | 缺失则重新编译 Prompt；已包含但仍无声时核对原生音频能力和实际音轨，不得直接归因于字幕 |
| 视频近似静止或像幻灯片 | 视频 | 检查 `observable_state_changes`、逐镜 `subject_action/state_change`、实际 Prompt，以及是否无差别传入过多静态参考图 | 按 `video.md` 区分行动、证据、反应与空间观察；关键动作链可跨镜拍清，固定证据/漫剧持格不为运动凑动作；参考图按实际职责使用 |
| 逐镜时间写得很细但模型乱切、漏镜或拖时 | 分镜/视频 | 对照当前模型的时间控制能力、计划容量、实际切点与事件顺序，不只比较总时长 | 按 `video.md` 区分预算与模型表达，保留镜号、顺序和关键事件，以动作/信息到达约束切点；过载返回分镜，不擅自删镜、放慢或换模型 |
| 动作都写了却看不懂，或全员同时抢戏 | 分镜/视频 | 看最终观察机位的轮廓、遮挡、接触及注意转移，核对是否被光效/次要动作盖住 | 保住当前主动作与接触结果，让非重点动作降幅或自然静止；缺观察覆盖返回分镜，不另添等待或无关特写 |
| 人物被复制、沿用白底站姿或把宫格逐格重演 | 视频 | 核对多视图是否被误解为多个主体，参考职责是否混入姿态、版式或强制首帧 | 按 `video.md` 选最小充分参考并明确采用/剥离维度；必要多视图保留，不能靠删除身份依据解决 |
| 参考图片合法存在但 role 校验失败 | 视频 | 对照 `reference_inputs` 合法枚举与本次用途，区分图片职责、来源和真正视频输入 | 使用已支持的主职责，来源另记 `source_id`、附带维度写 `adopt`；不自造枚举，也不为配合错误文档扩大代码白名单 |
| 已批准角色或道具设定本身错误 | 资产 | CHR/PROP 版本、需求来源和验收记录 | 建立正确的新资产版本，不覆盖旧版 |
| 生成片段中的角色、服装/装具、道具或场景漂移 | 视频 | 已批准 CHR/PROP、上一段场景锚点帧和尾帧、文字承接 | 内部记录强化文字锚点和可选重生范围；不伪造参考图输入，用户主动要求修改前不调用视频工具 |
| 计划人声静音、漏说、类型或口型职责错误 | 视频 | `speech_mode`、speech type、逐字文本、时间窗、原生音轨和嘴部 | 内部记录原生发声 Prompt 修正建议；旁白/画外音/内心独白不驱动画面人物对该句做口型，另有已确认对白时按 `video.md` 分配声音主次，用户主动要求修改前不调用视频工具 |
| 每个片段边界明显跳一次 | 分镜/视频/成片 | 用户指出位置、既定 SEAM 合同、必要的局部画面/声音与输入记录 | 用户要求修接缝时按具体问题调整计划切点或重设边界，默认不做窗口审查，用户主动要求修改前不调用视频工具 |
| 画面中残留模型硬字幕、随机文字或旧字幕 | 视频/成片 | 视频生成参数、片段抽帧、字幕擦除结果和擦除后抽帧 | 先确认生成阶段已禁用字幕；不主动检测或擦除；只有用户明确要求清理时才执行可用的非生成类处理，失败如实说明，不自动调用视频工具 |
| 字幕错位、越界、遮脸或遮道具 | 成片 | 最终音轨、SRT、宿主字幕预设、渲染抽帧和安全区 | 重新 ASR 或人工对轨并调整字幕预设或断句后烧录 |
| 工具返回成功但看不到内容 | 当前执行阶段 | 返回 ID、文件大小、实际播放/查看结果 | 不更新状态，重新取证或修复失败项 |
| 状态显示完成但文件缺失 | 控制层 | `制作状态.json`、产物清单和磁盘 | 回退状态并补齐产物 |

## 第 0 阶段：规划

| 问题 | 诊断 | 修复 |
|---|---|---|
| 一句话卖点与剧情目标无关 | 比较 `creative_proposition` 和用户目标 | 重写卖点、戏剧问题和成功定义 |
| 受众画像像刻板印象 | 检查来源状态和检索证据 | 改为待验证假设，删除人口标签推断 |
| 类型、情绪和风格互相冲突 | 检查主路径、辅助路径和排除项 | 保留一个主路径，明确辅助职责 |
| 风格只有“电影感”“高级感” | 检查 `style_contract` | 改写为光线、色彩、构图、材质和节奏机制 |
| 模型、时长或视频确认轮次不兼容 | 对照当前工具 schema 和已确认模型 | 停止调用并返回规划重新确认；模型选择和能力按 `interaction-ask-video-clarification-ref.md`，不得因时长或素材自动换模型 |
| 风险只有名称没有处理方式 | 检查 `risk_plan.mitigations` | 为每项风险补缓解、确认或接受理由 |

## 剧本阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 主角被动等待 | 逐场找改变局势的选择 | 给主角目标、时限、策略和代价 |
| 场景删掉也不影响剧情 | 做删除测试 | 合并或重写该场 |
| 反转突然出现 | 反查公平线索和前置规则 | 补铺垫或删除反转 |
| 台词只解释画面 | 标记每句策略和结果 | 改为试探、逼迫、回避、反击或行动 |
| 关键声明没有证据 | 查台词证据链 | 增加可见动作、道具、结果或标记主观判断 |
| 台词在时长内说不完 | 规划后核对自然朗读与动作覆盖；前置询问只按确认 Ref 定性判断 | 自写或已授权改写的台词在授权内修正；用户原文未获改写许可时保留，锁定时长与全文冲突则按 `interaction-ask-video-clarification-ref.md` 明示取舍，不擅自删改、延长或换模型 |

## 分镜阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 分镜多但生成仍是长镜头 | 对照分段执行索引和 Prompt 第三、四段 | 为每镜补动作桥、切入原因、主运镜、新增信息、承接锚点和切出落点 |
| 运镜统一推近/拉远或统一固定 | 对照 `storyboard.md` 的运镜分布检查、例外理由和实际画面 | 按信息、权力、速度和空间变化重选摄影机路径 |
| 镜头碎切 | 做删除测试 | 合并没有独立职责的镜头 |
| 长镜头没有内容 | 对照 `storyboard.md` 的真实一镜到底定义和尾态要求 | 增加连续摄影机路线、主体行动、空间变化、有效调度、焦点、信息与结果，或拆镜；不得补隐藏切点 |
| 跳轴、换手、瞬移 | 查 blocking_map、轴线和动作桥 | 按“前镜状态 -> 动作发起 -> 运动路径 -> 切点/镜内调度 -> 后镜续接 -> 接触/反馈 -> 结果”修正 |
| 开头不抓人 | 对照事件链与首个有效节拍 | 按 `pacing.md` 尽早给出具体冲突，所有内容类型均检查；不靠任意碎切凑三事件 |
| 高光只有发光或慢推 | 检查高光因果链 | 补齐“触发 -> 变化 -> 反馈 -> 结果”，并让结果改变人物、产品、道具、关系、信息或场景状态 |
| 结尾只是回到相似画面 | 检查结果、反应与落点 | 补完整结果和落点；只有已规划无缝 Loop 才允许回到起点构图 |
| 台词、动作在片段边界被截断 | 查绝对时间轴 | 把边界移动到真实切镜点 |

## 资产阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 三视图生成多个角色 | 查防复制声明和头部身份锚点 | 明确同一角色多个角度，只出现一个主体 |
| 三视图带笑、怒、惊讶、卖萌或异常修饰 | 查中性表情与类型分支 | 恢复无情绪状态，并按真人、动漫、卡通或动物分支定向重生 |
| 头面出现非设定畸变或器官结构错误 | 对照 `representation_type`、已确认个体设定及实际特写/侧面，区分生成错误与固有特征 | 按本角色结构定向修正，保持已确认的疤痕、缺失、器官数量和自然状态；不能为“正常化”改写身份 |
| 动漫、卡通或动物被错误真人化 | 核对类型策略、画风合同和资产说明 | 锁定角色类型、轮廓、颜色纹理及物种特征后重生 |
| 角色换装或毛发状态变化后身份漂移 | 查状态版本来源与变化范围 | 基于 approved 身份定向编辑，只改错误状态；按 `assets.md` 选状态主视图、细节或三视图，不一律重做整板 |
| 同一 SEG 内持续外观无依据改变 | 查 `project_data_card.json` 状态时间线、已确认剧情与分镜过程/明确省略；表情和姿态自然变化不属于此错误 | 无剧情依据则内部记录该 SEG 可选重生范围；确有换装、受伤、弄湿等变化则补外观状态与承接，是否补图按 `assets.md`；不自动重生视频 |
| 不同集角色面部、身高体型或音色漂移 | 对照 CHR/VOICE 共享基准、数据卡身份锁和本集 3-5 张代表帧 | 保留共享基准，内部记录漂移 SEG 可选重生范围；不得为本集另造角色或音色 |
| 主要场景跨集布局变化 | 对照 SCN 布局参考、数据卡场景状态和实际 FRM | 无剧情原因则内部记录可选重生范围；确有改造或时间变化则先更新状态时间线 |
| 道具结构变形、部件错位或比例失调 | 对照道具结构、部件数量、连接方式和尺寸比例 | 强化结构描述后定向重生；局部问题可限定区域做 `image_edit` |
| 道具材质塑料化或颜色漂移 | 检查材质、光泽、纹理、主辅色和棚拍高光 | 写具体可见材质特征并重生，不用“高级质感”等空词 |
| 道具开合、破损、发光或内容物状态错误 | 核对数据卡、本集状态绑定和实际图；分镜后再对照连续性账本 | 现有图不能说明新结构/内容时只补错误状态；已有可见依据时修绑定，不为不同状态名复制相同图片 |
| 多视图结构不一致或内部细节不可见 | 对照实际所需视图和关键结构 | 修不一致视图；主图不足以说明剧情关键内部结构、刻字或机关时才补细节，已有可读依据直接复用 |

## 视频阶段

| 缺陷 | 编号 | 诊断 | 修复 |
|---|---|---|---|
| 下一段开场与上一段实际尾帧跳变 | `F-*` | 先按衔接卡区分正常切镜与事实漂移，检查 previous tail FRM、本段真实 start FRM、状态参考/固定首帧职责和真实输入记录；正常反打或特写不要求复刻旧构图 | 事实、空间或动作关系确实不兼容时，补齐必要真实帧与身份/状态依据，再内部记录分镜修正或下一段可选重生范围；用户主动要求修改前不调用视频工具 |
| 人物服装、妆发、伤痕或随身装具跨片段不一致 | `V-*` / `F-*` | 核对当前角色状态资产、上一段 character_state FRM、previous_tail_as_start_frame 和真实 reference_inputs | 缺状态资产先返回资产阶段补齐；缺上一段状态帧则抽取并登记；输入齐全仍漂移时内部记录后段可选重生范围，用户主动要求修改前不调用视频工具 |
| 复现道具形状、归属、可见面或开合破损状态跳变 | `V-*` / `F-*` | 区分新外观缺依据，还是既有图上的方向、归属、接触未承接；核对实际 PROP/FRM 与接缝 | 新外观缺图才补对应资产；只有易主/移位则沿用原图、修状态绑定与接触关系，不重画相同道具；缺真实状态帧先抽取登记。记录责任片段可选重生范围，用户主动要求修改前不调用视频工具 |
| 输入素材过多、模型随机取舍 | `V-*` | 查参考素材预算和必需图片优先级 | `continuous` 接缝保留上一段 tail FRM；`elliptical` 从新起点资产开始。再按当前角色状态、当前场景、关键/复现道具和风格选最小充分集；仍超限则拆段或确认降级 |
| 未经本次视频参数确认就准备生成，或用户只是抱怨/纠正却触发生成 | `C-*` | 查最近用户意图、按 `interaction-ask-video-clarification-ref.md` 展示的完整参数、`interaction.ask` 执行确认结果、`generation_confirmation_id` 与工具调用时间 | 立即停止调用；若已有任务在生成中，等待结果并如实说明；只有用户明确提出创作/修改需求后，按确认 ref 重新列完整视频参数并通过 `interaction.ask` 取得执行确认 |
| 上一个视频仍在生成中又准备提交新视频 | `C-*` | 查目标是否为原视频的修改、独立新任务或已授权依赖任务，以及真实状态和授权范围 | 同一视频修改不变更在途任务、不另起修改生成、不自动排队；独立新任务按原交互合同重新确认，已授权且有真实依赖的任务等待输入。主 Agent 按 delegation.md 回应状态及承接要求，不因催促或评价重复提交 |
| 确认采用的 VOICE 修复音频声线变化 | `A-*` | 查 VOICE ID、版本和修复范围 | 局部修复始终复用同一已批准 VOICE 资产，不替换合格原生人声 |
| 身份漂移、复制人、随机文字 | `V-*` | 片段内部记录、抽帧、已批准 CHR/PROP 与文字锚点 | 设定正确时内部记录文字锚点强化和可选重生范围；设定本身错误才返回资产，用户主动要求修改前不调用视频工具 |
| 原生声线跨片段变化 | `A-*` | 仅在本文件的问题触发条件成立后，核对受影响主体的已批准 VOICE 版本、采用依据及相关片段的真实音频输入映射；确需听辨用户指出的差别时，只试听相关位置，不遍历全部片段 | 记录缺失或错误的音色绑定及可选重生范围。若需重新生成该主体人声，首段和续段、轻量和完整模式都必须复用对应已批准音色版本，将真实音频传入该次 `media_to_video` 请求并在 Prompt 绑定对应音频；VOICE ID、文字音色描述、历史调用和尾帧均不能代替本次音频输入。缺音色、批准依据或音频参考能力时按原规则暂停受影响调用，不以文字兜底；用户主动要求修改前不调用视频工具，实际重生仍按原规则取得对应生成授权 |
| 静音、漏说、串角色、类型错误或口型错位 | `A-*` | 播放原生音轨，核对声音主体、type、逐字文本、时间窗和嘴部职责 | 内部记录 `speech_mode`、`speech_lines` 与发声描述修正建议，用户主动要求修改前不调用视频工具 |
| 构图跳变、动作回弹、声音桥断 | `F-*` | 仅按用户指定问题查看必要位置及对应输入/转场计划 | 调整实际剪切点；内部记录动作/遮挡/甩镜匹配或声音桥修正建议，用户主动要求修改前不调用视频工具 |
| FRM 与分镜核心状态偏离 | `V-*` / `F-*` | 对比分镜状态与实际 FRM，定位身份、构图、状态或动作相位差异 | 核心因果或连续性受损时内部记录 SEG 可选重生范围；仅审美轻微差异可记录 accepted，用户主动要求修改前不调用视频工具 |
| 镜头遗漏、单动作拖时、运镜同质 | `S-*` | 对照 shot_plan 逐镜检查计划/实际运镜家族 | 修 Prompt；实际仍退化为推拉时返回分镜重分配路径 |
| 因果断裂、钩子未兑现 | `N-*` | 对照规划、剧本和分镜 | 返回最早叙事错误层级 |

## 成片阶段

| 问题 | 诊断 | 修复 |
|---|---|---|
| 接缝硬跳 | 用户明确要求修接缝时查看所指位置，不规定慢放或双侧窗口 | 默认已规划普通拼接直接交付；用户要求修改时调整切出/切入点、动作匹配、遮挡切或甩镜同向接入；仍不理想时记录并说明影响理解的接缝及责任片段，用户主动要求修改前不调用视频工具 |
| 音量忽大忽小 | 核实独立声轨还是混合原生音轨，试听接点与对白/关键声响 | 按 `delivery.md` 在真实音轨能力内处理明显响度突变；有独立轨才分轨混音，不假设可无损分离 |
| 宿主媒体任务来源缺失或不匹配 | 检查任务 ID、状态和输出路径 | 继续查询真实任务到完成或重新调用对应宿主能力；不得手写任务结果或复用其他任务 ID |
| 宿主命令返回但任务仍在运行 | 单次轮询未等到完成 | 使用同一 task_id 再次轮询；不得当作失败、不得重复提交 |
| 工具实际失败或缺输出 | 读取真实任务错误和所需输入 | 只修失败项；新增视频调用重新授权，正常返回结果直接交付 |
| ASR 对齐存在疑似错字 | 查看 alignment 的时间范围、expected_text、asr_text 和 differences | 定向试听；字幕正文仍取 spoken_text，确认是否需要修改 |
| ASR 对齐出现整句缺失或无效时码 | 对照 script_contract、ASR 原始信封和最终音轨 | 重新 ASR 或人工复核；若确认源音轨缺失，记录并说明缺失台词及最小返修范围，用户主动要求修改前不调用视频工具 |
| 字幕与发声不同步 | 比较最终音轨、ASR 时间戳和 SRT | 对最终音轨重新 ASR 对齐 |
| 字幕越界或遮挡 | 渲染首/中/尾帧检查字幕安全区 | 优先调整宿主位置预设或断句并重新烧录 |
| 修完局部又出现新问题 | 仅定位用户指出或工具已明确报出的受影响项 | 按 `media-delivery.md` 直交当前实际版本，不另设播放复检；已知内容问题如实说明，归档失败单独恢复目录操作，不重复交付或重生媒体 |

## 工具、状态与部分成功

- 工具不存在：停止当前阶段，只说明对可见产物的影响和需要用户选择的替代方案；不报告内部工具名、能力字段或已落盘内部产物。
- 内部结构缺口、校验缺口或运行配置差异可自动修复或降级时：直接处理并继续，不向用户解释具体字段、机器可读结构、内部文件名、检查机制、运行配置或代码要求；确需用户补充时，只说缺少可理解的素材、授权、剧情选择、模型选择或确认信息。
- 工具路由错误：先逐张盘点真实媒体输入；当前目标没有任何有效视觉参考维度时才用 `image_gen`，存在需要视觉输入锁定的身份、结构、空间、构图、媒介或画风维度时用 `image_edit`；视频片段按 `video.md` 的输入与用途路由；续段仅图片输入时使用 image_to_video，有视频或音频参考时使用 media_to_video，传真实尾帧、本段必要参考图及所需音频，不自动上传上一段视频或其裁剪副本。仅图片生成使用 `image_to_video`，没有媒体输入时用 `text_to_video`。`continuous` 非首段必须传入上一段真实 tail FRM；`elliptical` 非首段按新起点实际需要选择输入。需新生成人声时必须实际传入对应已批准 VOICE 并走 `media_to_video`；缺少音色、批准依据或所需音色参考能力时暂停该调用，按现有规则补齐或由用户选择可执行方案，不以文字音色降级，不伪造音频输入。修改已有视频时先按 `video.md` 的目标、输入、规格和累计成功次数判断；只允许符合合同的具体画面编辑，不处理音频或整体风格等禁用目标。凡是重新调用视频生成或编辑工具，都必须先按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- 已明确得知 `video_edit` 输出规格偏离：先区分 `video.md` 允许的不足 4 秒输入对应 4 秒工具输出，及真正的规格偏差；不为查找偏差启动生成后探测。已完成的编辑仍消耗该最终成片任务唯一一次成功编辑机会，不因用户不满意或交付失败重置；真实失败未完成不计成功。保留源和实际结果，由 mainagent 说明；后续修改按原始输入重新生成或原合同允许的非生成处理，不直接再调编辑。新增生成仍取得本批授权。
- 旧项目只有旧版计划文件：保留原文件备查，将其内容迁移并补全为 `drama_plan.json`，在当前对话中重新直接输出完整参数确认表并完成 planning 确认；不得只改文件名或用附件代替对话确认。
- 参数 schema 不确定：读取实际 schema，不从其他工具类比参数。
- 模型不兼容或生成失败：不得以提高质量、延长片段或节省重试为由自主换模型；视频模型的选择、会员提醒与生成确认只读 `interaction-ask-video-clarification-ref.md`；`seedream 5.0 pro` 必须先展示 `（会员模型并且消耗最多的额度）` 并取得明确确认。
- 调用超时：先检查返回 ID、任务状态和文件，不立即重复调用。
- 部分成功：保存成功项及版本，只补失败项；涉及视频生成、重生或编辑的失败项只记录返修范围，重新调用前必须按 `interaction-ask-video-clarification-ref.md` 重新完成视频参数确认。
- 本地大改：先写同目录临时文件，验证后原子替换，成功再清理。
- 状态更新：产物实际验证通过后才递增 revision 和提交阶段状态。

## 排障结束条件

只有同时满足以下条件才结束排障：

- 根因归属到明确阶段和稳定 ID。
- 修复动作已落盘为新版本。
- 必要输入/记录问题已修正；不因此安排生成后结构质检。
- 图片／视频按 `media-delivery.md` 完成 RichMediaCard 直交，音频仍用宿主文件工具；不以排障收口安排额外看图、试听或播放检查，不以完成冒充内容质量已验证，目录未完成独立记录。
- 缺陷记录包含证据和复验结论。
- 受影响下游已经重新生成或明确失效。
