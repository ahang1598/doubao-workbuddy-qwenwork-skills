# 行业与主题分类

用本文件保持行业逻辑和主题概念逻辑分开。

## 行业

行业分类基于公司的主营业务和经济活动，主要用于：

- 行业配置；
- 行业内筛选；
- 同行业财务比较；
- 估值基准；
- 行业轮动和景气研究。

A 股任务可优先使用申万等标准行业层级。港股和美股任务按当前数据源可用的行业分类体系处理，并标注所用体系。

## A 股行业层级

A 股行业锚定任务优先按以下层级解析：

1. **标准行业层级：** 申万一级、申万二级、申万三级等当前工具可返回的标准行业分类。
2. **交易平台行业板块：** 东方财富、同花顺等平台行业板块，可用于股票池召回，但需说明口径。
3. **风格板块：** 周期、科技 TMT、消费、医药、先进制造、金融地产等宽口径归类，只能作为范围收敛入口，不能替代标准行业分类。
4. **用户自定义行业：** 用户给出的业务口径，例如“AI 服务器液冷”“半导体材料”“机器人零部件”，应判断更接近主题、产业链还是行业子板块。

同一请求中出现多种口径时，应先说明采用的主口径，再说明辅助口径。例如“半导体行业里的先进封装概念股”应以半导体行业为行业池，再用先进封装概念/产业链环节二次筛选。

## 风格板块映射

风格板块用于自然语言解析，不是严格行业分类。可按当前数据源支持情况映射：

| 风格板块 | 常见行业范围 |
|---|---|
| 周期 | 煤炭、钢铁、石油石化、基础化工、有色金属、建材、建筑、交运、公用事业等 |
| 科技/TMT | 电子、通信、计算机、传媒等 |
| 消费 | 农林牧渔、食品饮料、纺织服饰、家电、轻工、商贸零售、社会服务等 |
| 医药 | 医药生物及其细分，如化学制药、中药、生物制品、医疗器械、医疗服务、医药商业等 |
| 先进制造 | 电力设备、国防军工、机械设备、汽车、环保等 |
| 金融地产 | 银行、非银金融、房地产等 |

风格映射有歧义时，应把它写成假设，并在数据来源中标注分类体系。

## 常见别名和归一

常见自然语言别名应归一到标准行业、概念或产业链口径：

| 用户说法 | 优先归一 | 说明 |
|---|---|---|
| 芯片、集成电路 | 半导体 | 可进一步区分设计、制造、设备、材料、封测 |
| 算力、AI 算力 | 算力概念/AI 服务器/数据中心/光模块等 | 通常更接近主题或产业链，不等同于单一行业 |
| AI、人工智能 | 人工智能概念 | 通常跨计算机、传媒、电子、通信等 |
| 新能源车、电动车 | 汽车/电池/新能源汽车概念 | 需判断整车、零部件、电池或材料 |
| 光伏、太阳能 | 光伏设备/电力设备/新能源主题 | 可进一步区分硅料、硅片、电池片、组件、逆变器 |
| 锂电池 | 电池/锂电产业链 | 可进一步区分正负极、隔膜、电解液、设备 |
| 军工、国防 | 国防军工 | 可进一步区分航空、航天、船舶、电子等 |
| 大金融 | 银行、非银金融 | 房地产只有用户明确提及时纳入 |
| CXO、创新药 | 医药生物/医疗服务/化学制药/生物制品 | CXO 更偏产业链服务，创新药更偏产品主题 |

归一不是结论。归一后仍需用 `seed_finance_search` 获取实际股票池，并用公司证据验证核心候选。

## 行业和概念的布尔组合

用户可能同时给出行业、概念、策略和排除条件，应按布尔逻辑处理：

- **AND：** “电子行业里的华为概念股” = 电子行业 AND 华为概念。
- **OR：** “半导体或消费电子” = 半导体 OR 消费电子。
- **NOT：** “科技股排除传媒” = 科技/TMT NOT 传媒。
- **范围 + 策略：** “新能源里市值超 500 亿且北向加仓” = 新能源相关股票池 AND 市值条件 AND 资金条件。
- **行业 + 产业链：** “半导体制造原料” = 半导体行业/产业链上游材料环节，应优先走产业链环节筛选。

组合条件应输出为透明筛选口径，避免把多个条件隐含进不可解释排名。

## 主题或概念

主题概念基于政策、技术、事件、产业趋势或市场叙事，通常横跨多个行业。主要用于：

- 新兴机会发现；
- 跨行业候选召回；
- 产业链受益映射；
- 催化剂和交易状态分析。

平台概念标签只用于召回候选，不能证明公司是核心受益标的。

## 路由边界

- 用户说“某行业里选股”，走行业锚定筛选。
- 用户说“某概念股”“某政策受益股”“某技术主题”，走主题概念筛选。
- 用户说“某产业链/某环节/某材料/某设备/某零部件/某供应链”，走产业链环节筛选。
- 用户没有给行业，只说“现在看什么方向”，走行业发现。
- 用户指定行业后又给策略，例如“半导体里低估值成长股”，先走行业锚定，再叠加策略因子。

## 主题相关性所需证据

可用证据包括：

- 产品或服务披露；
- 相关收入或利润；
- 订单、合同或客户证据；
- 量产或商业化状态；
- 产能、市占率或交付数据；
- 公司公告、财报、投资者关系记录；
- 官方政策、行业协会或权威研究。

## 主题相关性分组

使用事实状态分组，不使用“主题纯度分”：

- 已披露相关收入；
- 已披露订单；
- 产品已商业化或量产；
- 客户验证或送样阶段；
- 研发阶段；
- 战略布局；
- 参股或资本关联；
- 一般合作；
- 仅平台标签相关；
- 尚未找到正式业务证据。
