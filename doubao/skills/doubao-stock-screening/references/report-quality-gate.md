# 正式报告质量门槛

本文件是所有正式股票筛选报告的交付前验收规则。它不是建议项；除非用户明确要求极简回答、只要名单、不要图表或不要研报，否则正式报告在输出前必须逐项自检。任何关键项缺失时，先回到 `references/formal-report-execution-contract.md` 继续补写或降级说明；但检索必须遵守 `references/retrieval-budget-and-stop-rules.md`，不得因为质量门槛触发无限搜索。

质量门槛不能替代内容生成。若报告因为缺少范围背景、券商研报、交易/资金状态、重点公司深度或可视化而被拦截，不要只在风险段落补一句说明；必须回到对应研究包，补足正文、候选表、重点公司或图表。若已达到检索预算或搜索结果重复，则不再继续检索，改为受限交付并说明缺口。

## 适用范围

适用于以下正式任务：

- 主题/概念股票筛选；
- 行业/板块股票筛选；
- 产业链/供应链/细分环节股票筛选；
- 策略风格筛选；
- 龙头识别；
- 指定股票比较；
- 用户说“优质股”“核心标的”“龙头股”“有哪些值得关注”“帮我看下”等开放式股票筛选请求。

用户明确要求“一句话”“只要表格”“不要图表”“不要研报”“不要生成文档”时，可压缩对应模块，但仍必须保留数据截止时点、主要来源、核心风险和免责声明。

## 最低通过标准

正式报告必须同时满足以下要求：

1. **范围背景不是科普。** 必须说明当前状态、关键变化、景气/政策/供需/估值/资金/交易热度中的相关变量，并明确这些变量如何影响后续选股。
2. **主线和辅助维度分层清楚。** 用户锚点是概念、行业、产业链、策略还是指定股票，必须作为主线；财务、估值、资金、股价和风险作为辅助体检，除非用户把它们指定为主筛选条件。
3. **股票池来源明确。** 每个候选至少说明来自结构化股票池、行业/概念成分、用户指定名单、公告/研报线索、媒体线索或产业链映射中的哪一类。
4. **候选表不能只列名称和口号。** 候选全景表必须包含候选角色、主线证据、财务/估值、交易/资金、研报或媒体增量观点、风险/缺口、数据日期或报告期。
5. **重点公司不能只写“核心优势”。** 重点公司必须按“业务介绍 -> 主线相关性和真实度 -> 后续发展 -> 业绩牵引 -> 基本面 -> 估值和交易状态 -> 资金/最新价/日涨跌/5 日/20 日/年初至今表现 -> 同行对比 -> 券商/媒体观点 -> 风险和验证点”展开。
6. **券商研报必须有落点。** 正式主题、行业、产业链、策略、龙头和重点公司分析必须尝试检索券商研报或分析师观点；输出中至少写出行业/背景研报观点、重点公司研报观点或明确说明公开可用研报覆盖不足。
7. **股价、资金和交易状态必须处理。** 正式多股报告必须有独立“行情与估值对比表”，至少包含收盘价/最新价、总市值、PE(TTM)、日涨跌、5 日涨跌、20 日涨跌、年初至今、成交额、换手率。不能只给最近一个交易日涨跌幅，不能因为工具未返回、表格过宽或排版原因删除 5 日/20 日/年初至今列；缺失时必须按 `references/market-data-completeness-rules.md` 做字段别名、二次查询、历史价派生和缺失原因分类。若一张表放不下，拆成基础行情表和阶段涨跌表，不得删列。
8. **可视化不能只有普通表格。** 正式主题、行业、产业链、龙头和策略筛选，除候选全景表外，至少还要有一个传导/流程/关系类组件，以及一个数值对比类组件；数据不足时用证据矩阵、事件时间线或明确的降级说明替代。
9. **数据来源必须可追溯。** 不得只写“同花顺、券商研报、公开报道”。关键数字和关键观点要能对应到来源名称、日期或报告期、字段用途；券商研报应尽量列底层机构、报告标题和发布日期。正文和表格中只能出现 `[n]` 来源标记，URL 只能出现在文末数据来源索引表；正文表格出现裸链接、链接数组或原始检索字段即不通过。
10. **反向证据必须影响结论。** 收入占比低、订单未确认、认证早期、估值过高、股价拥挤、资金噪声、财务质量弱、数据缺口等不能只放在风险段落，要影响分组或结论强度。
11. **飞书文档交付必须处理。** 正式报告默认创建飞书在线文档；若平台没有可用能力或创建失败，最终回复必须明确说明，并仍交付完整 display markdown。不得没有飞书文档也不说明。

## 深度自检

输出前逐项检查：

| 检查项 | 通过标准 | 未通过时的动作 |
|---|---|---|
| 范围背景 | 有当前状态、核心变量、传导到选股的逻辑 | 补充背景检索或压缩为受限背景并说明缺口 |
| 主线筛选 | 有证据门槛、候选来源、分组依据 | 回到用户锚点重写筛选逻辑 |
| 候选总表 | 有业务证据、财务摘要、交易/资金摘要、研报/媒体、风险/缺口 | 二次检索；仍缺失时写明原因并降级 |
| 行情与估值表 | 有收盘价/最新价、总市值、PE、日涨跌、5 日、20 日、年初至今、成交额、换手率；若表格过宽可拆表但不得删列；缺失字段有明确原因 | 按 `market-data-completeness-rules.md` 做别名合并、单股二次查询、历史价派生；仍缺失时保留列并写明原因，不得删除列或写裸 `-` |
| 重点公司 | 每家公司覆盖业务、真实度、发展、业绩、基本面、估值交易、资金股价、同行、研报、风险 | 使用 `templates/key-company-card.md` 重写 |
| 券商研报 | 背景或重点公司至少有明确券商观点/预测/分歧或研报覆盖不足说明 | 使用 `references/broker-research-usage.md` 重新检索 |
| 可视化 | 不止普通表格；有关系/流程/传导组件和数值对比组件 | 按 `references/visualization-rules.md` 补充；数据不足则写降级原因 |
| 来源 | 正文/表格用 `[n]` 标记，文末来源表有编号、来源名称、类型、日期/报告期、用途、链接/出处 | 补来源索引；删除正文裸链接和链接数组；不能追溯的数字降级或删除 |
| 风险 | 风险与分组或结论强度联动 | 调整分组、风险标记或验证清单 |
| 飞书文档 | 已创建并附上文档，或明确说明当前未能创建 | 按 `references/delivery-workflow.md` 交付；不能假装已创建 |

## 不得通过的典型输出

以下形式不得作为正式报告交付：

- 只有产业链/主题介绍和公司清单，没有重点公司深度分析；
- 重点公司只写“业务结构、核心优势、业绩牵引、风险”四段；
- 没有独立行情与估值对比表；
- 行情与估值表只有最近一个交易日涨跌幅，没有 5 日、20 日、年初至今等多窗口行情列，也没有说明工具未返回；
- 行情与估值表为了排版删除 5 日、20 日、年初至今列，而不是拆成基础行情表和阶段涨跌表；
- 行情与估值表出现裸 `-`、`--`、空白或“暂无”，没有写“工具未返回/上市未满窗口/停牌或无交易/口径不可比/指标不适用”等原因；
- 阶段涨跌幅工具未直接返回，但没有尝试历史收盘价派生计算，也没有说明为何无法计算；
- 候选表没有成交额、换手率、资金或相对板块表现，也没有说明工具未返回；
- 只列“券商研报、公开报道”但没有任何券商观点、预测、假设或分歧；
- 数据来源只有平台名，没有来源日期、报告期或字段用途；
- 正文表格中直接展示 URL、链接数组、`["https://..."]` 或检索结果原始字段，而不是 `[n]` 来源标记；
- 可视化全部是普通表格，没有传导图、流程图、时间线、柱状图、条形图、折线图、散点图、矩阵等更清晰表达；
- 大量使用 `--`、空白、“暂无”，但仍输出强结论；
- 用交易热度、涨幅或市值直接证明产业地位；
- 把券商预测、媒体转述或模型估算写成已确认事实。
- 没有生成飞书文档，也没有说明平台当前无法创建或创建失败。

## 降级交付

若工具不可用或数据不足，仍可交付受限报告，但必须：

- 明确写出哪些数据未返回或未检索到；
- 不生成依赖缺失数据的强图表或强排名；
- 将受影响候选降级到观察名单、风险标记或受限结论；
- 在数据来源或信息缺口中列出后续应补充的公告、研报、资金流、行情、财报或行业数据。
