# 范围背景与当前状态规则

本文件规定正式股票筛选报告的前置背景模块。任何行业、主题、概念、产业链、板块、市场、策略或指标锚定的筛选，都必须先解释“这个范围当前是什么状态”，再进入股票池和个股筛选。

## 适用范围

适用于：

- 概念/主题筛选，例如算力、机器人、低空经济、国产替代；
- 行业/板块筛选，例如银行、半导体、医药、消费、港股互联网；
- 产业链/供应链筛选，例如半导体制造原料、光模块、减速器、锂电设备；
- 市场范围筛选，例如 A 股、港股、美股、科创板、北交所；
- 策略/指标筛选，例如高股息、低 PE、高 ROE、成长、资金流入、困境反转。

用户明确要求“一句话”“只要名单”“不要背景”时可压缩，但仍应保留一句范围假设和数据截止时点。

## 背景模块目标

背景模块至少回答：

1. **范围是什么。** 定义用户锚点，说明纳入和排除边界。
2. **当前发生了什么。** 说明景气、政策、需求、供给、价格、资本开支、估值、资金或交易状态。
3. **为什么影响选股。** 说明背景变量如何传导到收入、订单、利润、估值、分红、资金关注或风险。
4. **筛选主线是什么。** 从背景中提炼本次股票筛选的主线和辅助维度。

背景不能写成独立行业报告。每个背景判断都要服务于后续股票筛选。

## 检索计划

### `seed_finance_search`

用于背景中的结构化金融和市场数据：

- 行业/板块/概念指数或成分股；
- 板块市值、成交额、涨跌幅、换手率、估值分位、资金流；
- 行业内成分股财务分布、盈利增速、ROE、毛利率、股息率；
- 指标分布，例如 PE、PB、PS、ROE、股息率、营收/利润增速；
- 指数或板块历史表现、相对市场表现、阶段回撤；
- 分析师一致预期、机构预测、公告/F10 中可得的背景字段。

### `general_search`

用于背景中的产业、政策、事件和权威观点：

- 政府、监管、交易所、行业协会、官方统计、白皮书；
- 公司公告、定期报告、投资者关系记录、互动平台回复；
- 券商行业研报、公司研报和分析师报告；
- 权威财经/行业媒体、央媒国媒、业内人士访谈；
- 产业链结构、市场空间、渗透率、国产化率、供需、价格、资本开支、客户认证、技术迭代。

## 背景可视化

正式报告默认至少选择一种背景可视化或准可视化表达：

- **市场/板块状态：** 指数最近交易日/5 日/20 日/年初至今表现、成交额、估值分位、板块市值、资金流对比；
- **行业景气：** 市场规模/增速、产销量、价格、库存、资本开支、订单、渗透率；
- **主题/概念：** 主题催化时间线、受益路径图、政策/事件链条；
- **产业链：** 上中下游链条图、细分环节优先级矩阵、价值量/国产化率/认证壁垒表；
- **策略/指标：** 指标分布、筛选漏斗、条件命中矩阵、估值-成长散点图；
- **固定股票比较：** 对比口径表、业务角色矩阵、财务/估值/交易状态并列表。

若数据不足以生成数值图，使用环节表、证据矩阵、时间线或分组表替代，并说明缺失原因。

## 不同锚点的背景重点

| 锚点 | 背景重点 | 常用可视化或表格 |
|---|---|---|
| 概念/主题 | 催化来源、兑现阶段、受益路径、分歧和风险 | 主题传导图、事件时间线、候选角色分布 |
| 行业/板块 | 规模增速、景气周期、估值位置、资金状态、竞争格局 | 行业状态表、估值/盈利/涨跌幅对比 |
| 产业链 | 环节划分、价值量、国产化率、认证壁垒、供需传导 | 产业链图、细分环节优先级矩阵 |
| 市场范围 | 市场表现、流动性、估值分布、风格偏好、制度约束 | 市场状态表、行业/风格分布 |
| 策略指标 | 指标定义、适用行业、当前分布、失效条件 | 筛选漏斗、指标分布、条件命中矩阵 |
| 指定股票比较 | 比较问题背景、行业/主题上下文、口径边界 | 对比口径表、业务角色矩阵 |

## 衔接筛选

背景模块之后必须明确写出筛选主线，例如：

- “因此本次优先看客户认证和量产收入，而不是只看概念标签。”
- “因此高股息筛选不能只看股息率，还要看现金流和派息率。”
- “因此半导体材料优先比较国产化率低、认证壁垒高且上市公司有真实收入/订单的环节。”

随后再进入主线维度筛选、辅助多维筛选、公司基本面、估值交易状态、风险和验证清单。

## 禁止事项

- 直接跳到公司名单，缺少范围背景和当前状态；
- 背景只写概念定义，不写当前景气、市场、政策、估值或交易状态；
- 背景图表没有数据日期、报告期或来源；
- 背景分析和后续筛选逻辑断裂；
- 用背景热度替代公司层面业务证据。
