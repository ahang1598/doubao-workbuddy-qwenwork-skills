# 行业口径与筛选经验

本文件是参考，不是门槛。用户条件、题目定义和原文口径优先。表中指标只说明"该看什么"，不构成合格线、公式或名单。用到某条时，说明它为什么适用于本题对象；对象的业务模式和行业典型不同时，按实际经济特征选指标。

## 1. 先分清范围类型
- 行业：按主营业务归类。A 股常用申万分类；平台的行业板块可以用来召回，但要注明口径。"周期""科技""消费"这类风格词只作入口，映射有歧义时写成假设。
- 主题或概念：通常跨行业。平台概念标签只用来召回，不能证明公司受益。例如"电子行业里的华为概念股"，应理解为电子行业池，再叠加有业务证据的华为链公司。
- 产业链：说明公司处在哪个环节、对谁供货。
- 口语别名先归一：
  - 芯片：归为半导体，再分设计、制造、设备、材料、封测。
  - 算力、AI：更接近主题或产业链。
  - 大金融：默认指银行和非银，地产要用户明说才纳入。
  - CXO 偏产业链服务，创新药偏产品主题。

## 2. 业务证据阶梯
证据从强到弱依次为：
1. 披露了相关收入或利润
2. 订单、中标或合同
3. 量产或商业化
4. 客户验证或送样
5. 研发阶段
6. 战略布局
7. 参股或资本关联
8. 一般合作或框架协议
9. 只有平台标签
10. 没有正式证据

对应的结论口径：
- 收入、订单、量产级别的证据可以支持"核心"。
- 有产品或认证、但收入未披露的，写"重要参与者"或"观察"。
- 只有标签或资本关联的，写"待验证"。
- 公司已澄清不涉及的，降级或排除。

其他规则：
- 收入占比未披露时，说明业绩牵引不可量化，不做推断。
- 不混淆客户、供应商、竞争对手和参股方。参股和框架协议都不等于订单。
- 证据优先取自公告、定期报告、投资者关系记录，以及交易所互动平台的回复（上证 e 互动、深交所互动易等）。研报和媒体只作观点或线索。

## 3. 产业链环节比较
用户问一条产业链，或问"某类原料、材料、零部件"时，先拆成环节，再比较公司；只问一个环节时，不扩写成全链。

逐项比较以下维度，不打分：
- 价值量
- 国产化程度与替代空间
- 技术、认证壁垒和认证周期
- 上市公司映射是否清晰
- 盈利兑现阶段
- 估值与交易拥挤度（例如板块估值是否已明显跑在基本面之前）
- 主要风险

相邻环节默认放入观察，不混入核心结论。

## 4. "龙头"要拆类型
用户未指定时，分类型说明，不合成单一排名：
- 产业龙头：看份额、产能、技术地位、客户覆盖。
- 业务龙头：看与主题直接相关的收入、订单或客户。
- 市值龙头：看总市值或流通市值，注明日期。
- 交易龙头：至少同时看日、5 日、20 日涨跌，以及成交额和换手率，并注明窗口。不能只看单日成交。
- 预期龙头：看盈利预测或订单指引，并标明是预测。

只有概念标签或股价表现时，不称"产业龙头"或"业务龙头"。找不到权威份额数据时，只写"候选"。

## 5. 估值方法适配
- PE：适用于盈利为正且相对稳定的公司。负 PE 是亏损的结果，既不是缺失，也不是低估；平台不显示 PE 时写"不适用"，改用替代口径。
- PB：银行、保险、地产、周期资源和资产重估类更常用，要结合资产质量；净资产为负时不适用。
- PS：适用于亏损或利润波动大的软件、互联网、硬科技、创新药，要结合毛利率和增长看。
- EV/EBITDA：适用于资本结构差异大、折旧摊销重的行业。
- PEG：只在增长可持续时使用；不适用于强周期高点和低基数跳升。
- 不跨行业按绝对 PE 排序。用户没给阈值时，优先用同行或历史分位；跨行业的绝对阈值只用来粗筛，并说明这一点。
- 遇到低 PE，先排查是否处于周期高点、是否有一次性利润、是否有风险折价。高估值不必然排除，但要写清需要什么兑现来支撑。

## 6. 行业常用口径（候选清单）
| 类型 | 优先查看 |
|---|---|
| 银行 | 净息差、不良率、拨备覆盖率、核心一级资本充足率、ROE、PB、股息率 |
| 保险 | 新业务价值、保费增速、投资收益率、偿付能力、EV/PEV |
| 地产 | 销售额、土储、现金短债比、负债率、交付与融资风险 |
| 周期资源 | 产品价格、库存、产能、成本曲线、供需缺口、PB、EV/EBITDA、现金流；单期高增不代表长期成长 |
| 软件/互联网 | 收入增速、ARR/订阅、毛利率、费用率、现金流、PS |
| 生物医药 | 管线阶段、临床进展、首付款与已确认里程碑（潜在总额不等于落袋现金）、研发投入、现金储备 |
| 半导体/硬科技 | 产品环节、客户验证、国产替代、订单与产能、研发投入；PE、PS、PB 按盈利阶段选用 |
| 消费 | 品牌、渠道、销量或同店、毛利率、费用率、现金流、分红 |
| 高股息行业（资源、公用事业、银行、电信） | 叠加看政策与价格机制、资产质量、资本约束 |

## 7. 质量检查
- 成长：区分内生增长、并购并表、低基数、价格上涨、汇兑、周期修复和一次性收益。用应收、存货、合同负债和经营现金流检查增长质量。
- 盈利质量：把 ROE 拆成杠杆、利润率和周转；高杠杆推高的 ROE 不等于高质量。经营现金流长期弱于利润时，标为风险。
- 股息：
  - 股息率上升可能只是股价下跌造成的。
  - 派息率过高、现金流覆盖不足、资本开支压力大或盈利下滑时，标"分红可持续性"风险。
  - 营收和利润同时下滑的公司如果仍然入选，要说明理由。
- 负值、极端值和一次性项目单独解释，不机械参与排序。
- 分析师覆盖数量只说明信息是否容易获得，不代表公司质量。资金流和短期涨跌只说明交易状态，引用时注明统计窗口。

## 8. 策略的典型陷阱
| 策略 | 必看补充 | 典型陷阱 |
|---|---|---|
| 低估值 | 盈利为正、ROE、现金流、负债 | 周期高点的低 PE、一次性利润、资产减值 |
| 高股息 | 派息率、自由现金流、分红连续性 | 股价下跌推高股息率、一次性分红 |
| 成长 | 分业务增长、订单与产能、现金流 | 低基数、应收高增、费用资本化、估值透支 |
| 趋势/动量 | 明确窗口、成交与换手、催化因素 | 涨幅透支、交易拥挤、异动问询 |
| 超跌 | 基本面拐点、流动性 | 基本面继续恶化、退市或债务风险 |
| 事件驱动 | 事件日期、金额、传导路径、后续兑现 | 只是框架协议、金额未披露、审批不确定 |
| 困境反转 | 亏损收窄、毛利率与现金流改善、反转触发点 | 只停留在预期、持续经营存在不确定性 |

多个策略叠加时，先用范围限定股票池，再执行必要条件，最后用辅助指标解释。输出每只股票对各条件的命中情况，不合成总分。

## 9. 风险的处理动作
风险不默认等于排除。每个重要风险选一个处理动作，并说明对结论的影响：排除、条件排除、保留并标记、移入观察、降级结论。

以下情形默认不进入稳健候选；但在困境反转、事件驱动或高风险偏好的任务中，可以保留并显著标记：
- ST、*ST 或退市风险警示
- 非标准审计意见，或持续经营存在重大不确定性
- 长期停牌，或流动性明显不足
- 连续亏损，且现金流或融资能力不足
- 债务违约、重整、立案调查或重大诉讼
- 高比例质押或资金占用
- 商誉、存货、应收存在重大减值风险
- 密集减持或解禁压力

其他规则：
- 公司已澄清不涉及目标业务，或公开事实与纳入理由直接冲突时，排除。
- 风险要写成可核查的事实，不写"注意风险"这类空话。
- 风险（已经发生的事实）和信息缺口（缺少的证据）分开写。

## 10. 来源、时效与冲突
- 事实来源的层级，从高到低：
  1. 交易所、监管机构或公司的正式公告
  2. 经审计的定期报告
  3. 官方统计
  4. 结构化数据库字段
  5. 公司官网或投资者关系页面
  6. 行业协会与第三方统计
  7. 券商观点
  8. 权威媒体
  9. 一般网页

  判断层级时看底层的原始来源，不看取数工具的名字。引用聚合页时，写出底层机构、标题和日期。
- 最新股价、成分股、概念标签、政策状态、市占率和分析师预测，在运行时获取并注明截止时点。只拿到旧数据时，只作背景使用。
- 跨市场时，交易日按交易所本地时间解释；财年不同时，按自然季度或 TTM 对齐；注意港股的报告币种可能不同于交易币种。
- 数据冲突时：
  - 先核对时间、定义、合并范围、调整口径、币种、预测与实际、分类体系。
  - 不对不可比的数值取平均，不挑对结论有利的值。
  - 平台标签不能覆盖公司澄清，预测不能覆盖已披露的实际值。
  - 冲突影响入选资格又无法解决时，该对象降为待定或观察。
- 券商研报和媒体：写成"某机构观点、预测或测算"，注明机构、日期和预测期。多家预测取一致预期或给区间，不挑最有利的单一数值。与公司披露冲突时，以公司披露为准。

## 11. 历史热门概念核查（用户问到或影响当前结论时）
同时满足以下四个条件，才写成历史事件：
- 存在一个不同于当前主题的历史热门概念；
- 公司对这个概念有公开的关联表述；
- 相近窗口内股价或成交明显异动；
- 三者在时间上能对应。

写法：按日期列出公司表述、问询或澄清、行情表现和后续兑现情况。只陈述事实，不判断动机，不用"蹭概念"这类标签。历史事件不机械否定已有业务证据支持的当前候选。
