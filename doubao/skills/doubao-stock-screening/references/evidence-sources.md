# 信源体系

重要结论应优先使用更高层级证据。

## 信源层级

| 等级 | 信源类型 | 主要用途 |
|---|---|---|
| S1 | 交易所、监管机构、公司公告、年报、半年报、季报、正式公告、投资者关系记录、政府部门 | 确认财务、订单、客户、产能、政策和风险事实 |
| S2 | 结构化金融数据工具，当前对应 `seed_finance_search` | 行情、估值、财务指标、成分股、分析师一致预期、资金流 |
| S3 | 行业协会、官方统计、权威白皮书、咨询报告 | 行业空间、渗透率、市占率、产业链 |
| S4 | 券商研报和分析师报告 | 行业框架、测算、估值假设、催化剂和风险观点 |
| S5 | 权威财经媒体或行业媒体 | 事件背景和行业语境 |
| S6 | 一般媒体、访谈、市场传闻 | 只作为线索，需要降权验证 |
| S7 | 模型计算或推断 | 派生比较，必须说明输入和公式 |

## 工具与底层来源

工具名称不是永久的证据等级。判断优先级时看底层原始来源：

- `general_search` 检索到的交易所原始公告，高于普通数据库摘要。
- `seed_finance_search` 返回的标准财务字段，通常高于普通媒体转述。
- 两个工具都可能返回公司公告、券商观点或媒体内容，输出前应识别其底层来源。

## 一手证据优先

公司业务相关性优先使用 S1。行业空间和市占率优先使用官方或行业来源。预测类信息必须标注为分析师预测或模型假设。

## 背景概况信源

范围背景和当前状态分析应尽量覆盖多类信源：

- **结构化市场数据：** 行业/板块/概念指数、涨跌幅、成交额、换手率、估值分位、资金流、成分股市值和财务分布，优先使用 `seed_finance_search`。
- **官方和行业数据：** 政府部门、交易所、监管机构、行业协会、官方统计、白皮书，用于市场规模、增速、渗透率、国产化率、供需和政策状态。
- **券商行业研报：** 用于景气判断、市场空间、产业链利润分布、盈利预测、估值假设、催化剂和风险分歧。
- **权威媒体和业内采访：** 用于事件背景、产业变化、订单节奏、价格变化、政策落地和市场分歧。
- **公司披露聚合：** 多家公司公告、年报、投资者关系记录和互动回复，用于验证背景变量是否已传导到订单、收入或资本开支。

背景概况不能只依赖单一概念标签或单篇媒体报道。

## 禁止事项

- 不把券商测算当成公司事实。
- 不把媒体摘要当成正式公告。
- 不把平台概念标签当成核心受益证明。
- 不对定义不同的数据简单平均。
