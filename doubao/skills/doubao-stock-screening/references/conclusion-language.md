# 结论语言

结论应有证据、有限定、可追溯。

## 可以使用

- “满足本次筛选的明确条件。”
- “相比之下，已披露收入/订单证据更充分。”
- “在本主题下可放入核心候选组，依据是……”
- “当前证据不足以认定为核心受益公司。”
- “估值比较受限，因为其中一家公司仍处于亏损状态。”
- “这是券商观点，不是公司已确认事实。”

## 避免使用

- “必买”“一定上涨”“确定受益”；
- “主题纯度 98%”；
- “五星推荐”；
- 无来源和范围限定的“低风险”；
- “蹭概念”等主观动机判断，应改用时间线和公开披露事实表达。

## 风险与信息缺口

- **风险：** 已发生或可确认的公司/市场事实，可能影响筛选逻辑。
- **信息缺口：** 缺少确认或否定结论所需的证据。

不要用泛化市场风险模板代替具体风险事实。
