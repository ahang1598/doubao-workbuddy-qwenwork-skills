# 行情数据完整性规则

本文件用于正式股票筛选报告中的行情、估值、交易活跃度和阶段涨跌幅取数。遇到行情表字段缺失、字段名不一致或表格出现 `-`、`--`、空白时，先读本文件再写正文。

## 核心原则

- 行情表是字段级取数，不是整表取数。某只股票某个字段缺失，不代表该股票所有行情数据都不可用。
- 正式多股报告必须先尝试补齐，再允许缺失。不能因为第一轮工具没有返回，就直接写 `-` 或删除列。
- `日涨跌`、`5日涨跌`、`20日涨跌`、`年初至今` 是固定窗口列。若用户要求中长期股价波动，再追加 `60日涨跌`、`120日涨跌` 或 `近一年涨跌`。
- 可以使用工具返回的原始窗口涨跌幅，也可以在历史收盘价可得时自行计算，但必须在来源或备注中标明“模型计算，基于历史收盘价”。
- 正文和表格来源列只写 `[n]`。原始链接、链接数组、工具 JSON 和 URL 只能放在文末“数据来源”表。

## 字段别名

检索或读取工具结果时，先按以下别名合并，不要只匹配一个固定字段名：

| 报告字段 | 可接受别名 |
|---|---|
| 收盘价/最新价 | 最新价、收盘价、现价、昨收/今收、last price、close、last_close |
| 日涨跌 | 涨跌幅、日涨跌幅、当日涨跌幅、最近交易日涨跌幅、pct_chg、change_pct |
| 5日涨跌 | 5日涨跌幅、近5日涨跌幅、5个交易日涨跌、weekly return、return_5d |
| 20日涨跌 | 20日涨跌幅、近20日涨跌幅、20个交易日涨跌、monthly return、return_20d |
| 年初至今 | 年初至今涨跌幅、今年以来、年内涨跌幅、YTD、ytd_return |
| 成交额 | 成交额、成交金额、amount、turnover_amount |
| 换手率 | 换手率、turnover rate、turnover_rate |
| 总市值 | 总市值、市值、market cap、total_market_cap |
| PE(TTM) | 市盈率TTM、滚动市盈率、PE TTM、pe_ttm |
| PB | 市净率、PB(LF)、PB(MRQ)、pb、pb_lf |
| 资金流 | 主力净流入、主力资金、北向资金、融资余额、fund flow、main net inflow |

## 回填顺序

对核心候选和正式行情表中的每个证券，按字段逐项执行，但受 `references/retrieval-budget-and-stop-rules.md` 限制：

1. **批量取数。** 先用 `seed_finance_search` 获取候选池的行情、估值、成交、换手、阶段涨跌幅和交易状态。
2. **字段别名合并。** 若目标字段为空，先检查工具结果里是否以别名返回，不要直接判定缺失。
3. **单股二次查询。** 对核心候选、重点公司和表格中缺失较多的证券，使用 `seed_finance_search` 按代码单独查询行情、估值、历史股价、成交、换手、资金和风险事件。默认最多 1 轮补查；不要为观察名单逐只补齐所有字段。
4. **历史价派生。** 如果 5日、20日、年初至今、60日、120日或近一年涨跌幅没有直接返回，但对应历史收盘价可得，应按 `(最新收盘价 / 窗口起点收盘价 - 1) * 100%` 计算。窗口起点使用对应交易日前后的最近可交易日；年初至今使用本年度首个可交易日收盘价。
5. **公开信息补查。** 若结构化工具缺失最新价、市值、PE/PB、成交额、换手率等基础字段，可用 `general_search` 检索权威金融页面、交易所行情页、公司公告或公开金融数据页，但要说明口径可能不完全统一。同一字段最多补查 1 次；仍无结果就分类缺失。
6. **缺失分类。** 仍无法补齐时，才允许在单元格写缺失原因；不得写裸 `-`、`--`、空白或“暂无”。

## 缺失原因写法

表格单元格可使用短标签，信息缺口或备注中解释：

| 场景 | 单元格写法 |
|---|---|
| 工具没有返回该字段，二次查询也无结果 | 工具未返回 |
| 权威公开检索未找到可核验字段 | 未检索到 |
| 股票上市时间不足以计算窗口收益 | 上市未满窗口 |
| 当日停牌或窗口内无有效交易价 | 停牌/无交易 |
| 指标因亏损、负净资产、会计口径或市场规则不适用 | 指标不适用 |
| 不同来源定义差异过大，不能并列表达 | 口径不可比 |
| 公司或来源未披露该业务/财务字段 | 未披露 |

负 PE 不是缺失。利润为负时可显示负 PE，同时在重点公司或风险中说明盈利亏损导致 PE 解释力弱；若平台把亏损公司 PE 置空，则写“指标不适用”，并使用 PB、PS、市值/收入、订单或同环节估值作为替代。

PB 缺失不等于公司没有资产价值。先检查 `PB(LF)`、`PB(MRQ)` 等别名；仍缺失时写“工具未返回”或在净资产为负、口径不适用时写“指标不适用”。

换手率和成交额缺失时，先检查交易状态和是否停牌；若正常交易但字段未返回，写“工具未返回”，不要用日涨跌替代交易活跃度。

## 表格输出要求

- 行情与估值表必须保留固定列。缺失字段写原因，不能删列。
- 若候选过多或列过宽，拆成两张表：
  - `行情与估值基础表`：股票、代码、收盘价/最新价、总市值、PE、PB、成交额、换手率、来源；
  - `阶段涨跌对比表`：股票、代码、日涨跌、5日涨跌、20日涨跌、年初至今、可选 60日/120日/近一年、来源。
- 如果某个字段全列缺失，仍保留列，并在表下注明该字段的缺失原因和已尝试的回填方式。
- 若某只核心候选缺失超过 3 个行情/估值关键字段，不能直接放入“核心优质”结论；应降级为“数据受限核心候选”或“观察名单”，除非主线业务证据极强且明确说明交易体检受限。

## 解释数据缺失

用户追问为什么有数据拉不下来时，优先按以下框架解释：

1. 字段覆盖差异：工具可能返回价格、市值、PE，但不返回 PB、换手或某些窗口涨跌。
2. 窗口收益限制：新股、上市未满窗口、停牌或历史价格窗口不完整时，年初至今、20日或近一年无法直接计算。
3. 指标适用性：亏损公司 PE、负净资产公司 PB、不同市场/不同口径的成交和换手可能不可比。
4. 字段名不一致：同一数据可能以“今年以来”“YTD”“年内涨跌幅”等形式返回，需做别名合并。
5. 输出兜底不足：即使真实缺失，也不应显示裸 `-`，而要写出缺失原因和对结论的影响。
