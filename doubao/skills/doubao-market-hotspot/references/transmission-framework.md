# 事件结构拆解与传导分析框架

沿着“事件条款或冲击 → 核心商业变量 → 企业或市场主体行为 → 业务指标与财务报表 → 估值或风险溢价”拆解因果链。按用户问题停在恰当层级：问经营影响就落到订单、成本与利润；问市场表现再延伸至预期差与定价。

## 第一步：拆清事件内部结构与生效节奏

- **存量基线与本次增量**：先剥离事件前已实施的规则或条件，识别本次真正新增、扩围、放宽或暂停的部分；涉及补充或延期文件时，核对关联文件的实际覆盖范围，避免遗漏或重复计算。
- **复合政策双向拆解**：一项新规可能同时包含放宽项与收紧项，分别评估两者对不同类型主体的影响，避免用单一的利好或利空概括结构分化。
- **条款方向与生效窗口**：逐条核实条款是加强、减弱还是维持，数量或价格条件属于上限还是下限，程序要求适用于哪些主体。把各条款的实际生效日对应到短期、中期与远期窗口，不把远期才生效的规则放进近期冲击测算。

## 第二步：区分合同状态、经营模式与传导弹性

- **既有合同与新签合同分离**：成本或规则变化时，价格已锁定的存量合同通常由履约方承担冲击；新签或可重新议价的合同能否转嫁，取决于需求弹性、行业供需、客户切换成本与替代周期。
- **按业务模式区分暴露**：比较多个受影响主体时，按实际业务环节、产能布局与收入结构逐层区分暴露方向与缓冲能力，不因同属一个概念板块就默认同向受影响。
- **额度与实际落地分离**：政策额度、工具规模或获批上限只代表可用空间，实际拉动取决于使用意愿、资金成本与执行节奏；没有执行细则时，不断言影响体现的精确时间。

## 第三步：准确映射会计科目并锚定业务权重

- **财务科目与合并边界不混用**：区分并表控股与非并表参股等不同会计核算边界，按实际持股比例和损益归属评估影响；区分经营性损益、非经营性估值变动与现金流指标，区分收入金额变化与收款周期变化。
- **业务权重与外部约束**：判断事件能否改变公司整体盈亏或板块定价时，先核实受影响业务占公司收入、毛利或利润的比重，并对照决定板块整体表现的主导变量。局部改善不足以抵消主业压力或外部强约束时，如实说明弹性边界。
