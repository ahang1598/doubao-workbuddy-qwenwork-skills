# 常见写作问题

| 问题 | 改法 |
|---|---|
| 一上来展示研究流程和来源等级 | 先回答事件会怎样影响业务或市场，重要事实在相关段落给出处 |
| 罗列数字却没有判断 | 说明数字改变了哪项成本、收入、需求或预期 |
| 把某一种解释写成定论 | 有实质性的其他解释时，说清区分它们需要什么信息 |
| 资料不全仍给精确概率或收益 | 说明目前能判断的方向，以及估算还缺什么输入 |
| 每个段落都重复“未证”“不外推” | 只在限定会改变结论时写入正文，其余口径放在必要的附录 |
| 把内部标签、工具状态和验证过程交给读者 | 用自然商业语言写结果；结构化记录只在用户需要复核时提供 |
| 为凑齐栏目扩写情景、公司清单或监控表 | 只保留当前问题真正需要的内容 |

没有持仓、投资目标和授权时，不把研究判断写成交易指令。政策、价格或公司事件尚未确认时，用条件式说明影响。
