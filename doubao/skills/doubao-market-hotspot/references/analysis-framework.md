# 事件影响的思考框架

先确认事件状态和真正新增的信息，再找出它首先改变的业务或市场变量。沿着“事件 → 变量 → 客户或企业行为 → 财务或市场结果”解释主要影响。只展开有依据且对本题重要的间接路径。

讨论受益或受损时，看实际暴露、转嫁能力和时间差；产业链总价值不自动等于目标公司的利润。讨论市场是否已经反映事件时，需要事前价格或预期基线。

关键结论有合理的其他解释时，说明哪条证据能区分它们；不为满足数量罗列反方。结论强度依证据而定，预测和假设应让读者辨认，但不必在正文加内部等级标签。

比较多个受影响对象时，内部按实际暴露、影响方向与幅度、出现时间、证据把握和传导的直接程度排序。只对有可比证据的对象下排序结论；这些维度不必变成正文表格。

成稿前自问：读者比直接阅读事件原文多理解了什么？如果只有事实复述，补上关键传导或真正会改变判断的未知项。
