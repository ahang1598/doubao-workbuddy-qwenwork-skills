# Seedance 2.5 参数说明

本 Skill 只负责说明模型参数及生成前路由，不独立执行内容策划、澄清确认或视频生成。

## 模型参数

| 参数 | 说明 |
|---|---|
| 模型 `model_version` | 固定为 `seedance_2.5`，不得因默认策略、速度、成本或其他偏好切换模型。 |
| 时长 | `5–30` 秒，整数秒；具体工具的输入要求与硬限制由 `doubao-creative-video` 对应工具策略校验。 |
| 比例 | 支持 `16:9`、`4:3`、`1:1`、`3:4`、`9:16`、`21:9` 六个精确值。 |

用户已指定的合法参数应保留。缺失参数、不支持的规格以及工具能力限制，交由 `doubao-creative-video` 按其策略处理，不在本 Skill 中另设默认值或确认流程。若实际工具不支持 `seedance_2.5`，停止生成并告知用户，不降级或替换模型。

## 必须告知用户

介绍本模型或处理使用本模型的生成请求时，必须明确向用户告知以下两点，不得省略或仅保留在内部交接信息中：

1. Seedance 2.5 是会员专属模型。
2. Seedance 2.5 生成消耗较大。

可合并表述为：`Seedance 2.5 是会员专属模型，生成消耗较大。`

实际生成前必须确保用户已看到以上说明；将两项告知要求随模型约束一并交给 `doubao-creative-video`，由其纳入生成前方案说明，不另设确认流程。

## 生成前必须路由

- 用户仅询问模型参数或支持范围时，直接依据上述参数说明回答，不进入视频生成流程。
- 用户要求实际生成或编辑视频时，必须先读取并调用 `doubao-creative-video` Skill，再由其识别素材与工具路由、整理生成内容、执行澄清和确认并生成；不得绕过该 Skill 直接调用视频工具。
- 交接时传递用户原始需求、已有上下文与参考素材、用户指定参数，以及固定模型约束 `model_version: seedance_2.5`。该模型约束不得被下游默认模型覆盖。
- 生成方案、文本澄清、额度提示、生成确认和结果交付均遵守 `doubao-creative-video` 的当前策略，本 Skill 不重复维护相关规则。
- 若无法读取或调用 `doubao-creative-video`，说明路由不可用并停止生成，不自行补建生成流程。
