# 参考素材提示词迭代

## 概述
维护素材角色、硬约束和时间轴的一致性，输出可复制的提示词与变化记录；最终生成由对应创意 Skill 执行。

## 使用场景
### 应使用
- 参考图/视频驱动的提示词优化。
- 角色一致性、镜头续接、时长压缩或多轮修改。
- 需要比较前后版本的约束变化。

### 不应使用
- 无参考素材的从零创作。
- 音乐或音色生成。
- 直接调用生成工具制作最终图片/视频。

## 核心流程
### 1. 建立素材映射
编号主体、风格、场景和参数来源。

### 2. 冻结硬约束
记录身份、结构、数量、文字、时长、比例和禁止项。

### 3. 按时间轴/画面拆解
图像按画面层级，视频按镜头时间段生成提示词。

### 4. 迭代差异
每轮只改用户反馈相关项，保留未点名约束并记录版本差异。

### 5. 转交生成
图片转 doubao-creative-design，视频转 doubao-creative-video/drama；工具参数以当前 schema 为准。

## 工具与协作
- 需要先拆参考图时可加载 reference-image-briefing。
- 不在本 Skill 中写死 Seedance 版本、会员、配额或时长上限。

## 安全边界
- 只陈述已读取、已执行或有来源支持的结果；未验证项必须明确标注。
- 涉及删除、覆盖、发布、系统设置、生产数据或不可逆操作时，先展示目标、影响、回滚方式并取得明确确认。
- 不得记录或输出密钥、Cookie、访问令牌、身份证号、银行卡号等敏感信息；示例使用脱敏占位符。

## 输出与验收
- 素材映射
- 正向/负向提示词
- 镜头或关键帧计划
- 版本差异与待确认项

## 冒烟用例
### Should trigger
- 根据参考视频和反馈迭代 4 个镜头提示词
- 保持角色一致性，把时长从 15 秒压到 10 秒

### Should not trigger
- 没有参考图，帮我直接生成海报
- 参考这段声音克隆真人音色

### 边界输入
- 用户反馈与原始角色/产品硬约束冲突
