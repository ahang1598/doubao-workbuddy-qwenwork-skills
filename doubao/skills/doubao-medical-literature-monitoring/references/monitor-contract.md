# 监控状态

监控优先保留：

- `subscription`：用户确认的关注主题领域、重点标注话题、更新频率、来源范围偏好；
- `previous_report_doc`：上一期飞书进展报告；
- `last_success_at`：上一次完成主检索与必要兜底并成功回读新报告的时间；
- `seen_source_keys`（可选）：已呈现来源的紧凑去重提示，优先使用稳定标识，没有时使用 canonical URL。

订阅设置、上一期报告和最新成功时间保存在定时任务 query 中；去重键在方便取得时一并保存。`previous_report_doc` 用于恢复配置和帮助减少重复。上一期文档或去重键缺失、过长、不可读时，不阻塞本期报告或任务更新。

执行时区沿用用户或账号时区；无重要更新时仍创建并发送简短报告。这两项是执行默认值，不向用户提问，也不放入订阅设置表。

来源范围偏好只用于检索加权、补充和排序，不是硬准入或逐站覆盖清单。

每个订阅只维护一个定时任务。每期完成检索和筛选后只写一次最终 `report-data.json`，不生成证据台账或逐批文件。报告写作和飞书回读规则统一读取 `references/output-and-qa.md`，不在这里重复定义。创建新报告后更新原任务的上一期链接和最新成功时间；`seen_source_keys` 能方便生成时再更新。不得因为跨期去重不完整创建第二个任务、重复试建文档或阻塞交付。
