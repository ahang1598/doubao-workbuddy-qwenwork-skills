# 视频生成失败分流

只依据当前工具回执，不保存固定模型、会员、配额或参数上限。

| 回执类型 | 首动作 | 禁止行为 |
|---|---|---|
| 内容安全硬拒/明确禁止重试 | 停止同类重试，向用户说明并给合规替代方向 | 换词反复撞审核 |
| 权限、模型或额度不足 | 原样说明可选路径，等待用户选择 | 静默换模型或缩短规格 |
| 素材 URL/格式不可访问 | 重新上传或更换可访问素材，保持创意参数不变 | 误改 prompt |
| 参数 schema 不合法 | 读取当前工具 schema，修正单一参数后重试 | 使用旧文档猜枚举 |
| 服务临时失败 | 按回执建议有限重试并记录次数 | 无限重试 |

每次失败都记录工具、时间、请求规格、回执摘要、是否重试和下一步。
