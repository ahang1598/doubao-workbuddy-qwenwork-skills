# 市场、竞品与商业环境

只在市场结构、替代方案或商业约束会改变当前决定时读取。不要为了让 PRD 显得完整而机械添加行业规模和竞品表。

## 1. 先明确分析要支持什么决定

可能的决定包括：是否进入、优先哪个细分人群、差异化放在哪里、做自研还是合作、如何定价或选择渠道。决定不同，需要的证据也不同。

## 2. 市场判断

按以下顺序分析：

1. 用户完成什么任务，当前用什么替代方式；
2. 哪类用户的问题更急、更频繁或替代成本更高；
3. 购买者、使用者、审批者和受益者是否为同一角色；
4. 获客、交付、服务、合规、生态或迁移成本是否会限制增长；
5. 本产品凭什么获得并持续获得价值。

市场规模必须说明时间、地域、口径、来源和计算关系。没有可靠输入时，提供估算公式、所需输入和上下界来源，不生成精确 TAM、SAM、SOM。

## 3. 竞品不是功能清单

比较对象包括直接竞品、间接替代、人工流程、内部自建和“不处理”。围绕用户决策比较：

| 维度 | 要回答的问题 |
|---|---|
| 目标用户与场景 | 它真正为谁解决什么任务 |
| 核心路径 | 用户从触发到获得结果经历什么 |
| 价值与代价 | 为什么采用，付出什么成本 |
| 能力与边界 | 什么做得到，什么明确做不到 |
| 商业与交付 | 定价、渠道、服务方式及迁移约束 |
| 证据 | 官网、真实体验、当前版本或可信第三方来源 |

把“官网声称”“本地实测”“用户反馈”和“推断”分开。版本、价格、功能、政策等易变化信息必须回源并标日期。

## 4. 从比较走向产品动作

每个差异都回答：它对目标用户是否重要、是否可持续、是否值得本阶段投入。最终只保留会改变定位、范围、顺序或验证方式的洞察。

避免：

- 看到竞品有就自动跟进；
- 用总功能数、主观星级或无依据权重制造排名；
- 把不同国家、行业或商业模式的做法直接迁移；
- 把媒体观点或营销文案当作产品事实。

输出至少包括推荐判断、关键证据、替代解释、对方案的具体影响和仍待确认的商业约束。
