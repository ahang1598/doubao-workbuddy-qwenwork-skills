# 估值与隐含假设

## 回答什么

判断当前定价需要公司实现什么、价值由哪些业务和变量构成，以及结论对关键假设有多敏感。

## 何时选择

用户问估值、目标区间、贵不贵、SOTP、DCF、反向 DCF、隐含增长、利润率或情景价值时选择。

## 数据获取

使用 `/seed_finance_search` 获取同一时点的股价、股本、市值、净债务、历史及同业估值、一致预期和分部输入；少数股东、非经营资产及特殊调整回到财报附注核验。

## 所需输入

- 同一时点的股价、稀释股本、市值、净债务/净现金、少数股东和非经营资产；
- 投资组合、联营公司、可出售资产、控股公司负债、潜在税费及各项资产的可实现性；
- 历史与可比公司估值及可比性差异；
- 收入、利润率、税率、资本强度、WACC 和终值假设；
- 多业务公司的分部经营与估值输入。

## 分析动作

1. 闭合 equity value 到 enterprise value，统一币种、日期和股本口径。
2. 先把持续经营盈利与投资公允价值、资产处置等非经营收益分开，确保估值分子与分母匹配。
3. 根据业务选择历史估值、同业、SOTP、DCF、反向 DCF 或扣资产后估值，至少提供两个有意义参照。
4. 将价值连接到经营变量，不给脱离基本面的倍数或目标值。
5. 多业务或资产型公司建立 `投资组合 + 联营/非经营资产 + 净现金 - 控股负债/税费 + 主营业务价值` 价值桥。折价按流动性、控制权、税费、披露透明度和可实现性逐项说明并做敏感性；没有依据时不得对全部资产使用同一折价。
6. 反向 DCF 使用 `scripts/reverse_dcf.py`，透明披露 WACC、预测期和终值假设，反推当前价格隐含的增长、利润率、ROIC 或资本强度；它用于还原市场要求，不用于倒推预设目标价。
7. 做关键变量敏感性和基准/乐观/悲观情景，保持唯一基准价值。
8. 与历史兑现、行业容量、公司能力和市场预期比较，判断隐含要求是否合理。

## 完成标准

产出价值桥、方法、关键输入、估值区间或隐含假设、敏感变量和边界；涉及投资资产时单列资产调整与折价依据。没有可复算输入时不给精确目标价。
