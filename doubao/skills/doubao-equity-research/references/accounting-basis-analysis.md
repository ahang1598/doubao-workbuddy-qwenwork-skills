## 基本原则

1. 以法定口径作为事实锚点。IFRS、US GAAP 或当地法定口径来自经审计/审阅财务报表；Non-IFRS、Non-GAAP 或 adjusted 指标属于管理层定义的替代绩效指标，跨公司、跨期不天然可比。
2. 不把“调整后”写成“更真实”。先说明管理层为何调整，再分析调节项是否持续、是否涉及现金、是否构成股东经济成本、是否受管理层判断影响。
3. 同一张表、同一句增长比较和同一估值计算只比较同口径指标。无法统一时并列展示，不计算误导性的同比、差额百分比或排名。
4. 指标首次出现时写全称与口径；后文可用缩写，但表头、图题和估值分母仍保留 `IFRS`、`Non-IFRS`、`GAAP`、`Non-GAAP`、`reported` 或 `adjusted` 标签。
5. 数据源只提供其中一种口径时明确缺口。不得根据差额猜测具体调节项，也不得把公司未披露的调节项当作事实。

## 口径登记

取数后、比较前，为每个关键指标建立内部口径登记。至少记录：

| 字段 | 要求 |
|---|---|
| 指标名称 | 收入、经营利润、归母净利润、基本/摊薄 EPS、FCF 等 |
| 会计口径 | IFRS、Non-IFRS、GAAP、Non-GAAP、reported、adjusted |
| 期间 | FY/CY/TTM，季度/累计，报告期起止日 |
| 合并范围 | 集团/分部，持续经营/全部业务，归母/含少数股东 |
| 币种与单位 | 报告币种、换算时点、元/千/百万/十亿 |
| 每股基础 | 基本/摊薄，加权平均/期末股本，ADR/普通股换算 |
| 定义与调节项 | 公司原始定义、是否重述、主要剔除项目 |
| 来源与时点 | 文件、页码/表名、发布日期、数据查询截止日 |

任何字段不同都先视为不可直接比较，直到完成统一或清楚标注差异。

## 差异桥与专业分析

公司披露完整调节表时，优先运行：

```bash
python3 "$EQUITY_RESEARCH_SKILL_DIR/scripts/accounting_basis_bridge.py" \
  accounting-basis.json --output accounting-basis-output.json
```

输入模板位于 `assets/accounting-basis-bridge.template.json`。脚本采用：

`调整后口径 = 法定/报告口径 + 各调节项`

调节项的正负号必须表示从法定/报告口径走向调整后口径的影响。脚本验证桥接是否平衡，并计算：

- 绝对差额及在分母有意义时的相对差额；
- 两种口径是否发生盈亏方向切换；
- 调整后利润对调节项的依赖程度；
- 已识别非现金调节项占比；
- 经常或可能经常发生的调节项占比；
- 可直接交给 `lark_charts.py waterfall` 的单期瀑布图输入。

逐项分析至少回答以下问题：

1. **持续性**：该项是否真正一次性，还是随招聘、并购、重组、营销或融资活动反复出现？
2. **现金性**：非现金不等于没有经济成本。股份支付会稀释股东；摊销可能对应真实收购成本；公允价值变动可能反映风险暴露。
3. **可控性**：调节是否高度依赖管理层定义、估值模型或分类选择？定义是否跨期变化？
4. **税与少数股东**：调节桥是否同时处理税效应、非控股权益和可转换证券？税前项目不能直接加到税后归母利润。
5. **趋势**：口径差额占收入、IFRS 利润或 Non-IFRS 利润的比例是否扩大？扩大来自业务扩张还是调整依赖上升？
6. **现金验证**：调整后利润增长是否被经营现金流、FCF 和营运资本支持？
7. **同业与估值**：可比公司是否剔除同类项目？价格、盈利预测和估值倍数的分母是否使用同一口径？

以下情形不使用百分比“改善”：

- IFRS/GAAP 数值接近零；
- 两种口径一盈一亏；
- 分母为负且百分比会掩盖方向；
- 两期定义、合并范围或股本基础不同。

改用绝对差额、利润率差、每股差额和调节桥，并解释方向。

## 相似口径清单

报告中遇到下列组合时执行同样的登记与统一：

| 容易混淆的组合 | 必查差异 |
|---|---|
| IFRS vs Non-IFRS；GAAP vs Non-GAAP | 剔除项、税效应、少数股东、每股基础、定义变化 |
| reported vs adjusted；underlying vs headline | 调整清单、是否反复发生、是否由管理层自行定义 |
| 归母净利润 vs 集团净利润 | 非控股权益、优先股和其他权益归属 |
| 基本 EPS vs 摊薄 EPS | 期权、限制性股票、可转债、反摊薄处理 |
| 单季 vs 年初至今累计 | 期间长度、季节性、去年同期基数 |
| FY vs CY vs TTM | 财年结束月份、滚动期、预测期 |
| 实际汇率 vs 固定汇率 | 汇率基期、换算方法、交易与折算影响 |
| reported growth vs organic growth | 并购、处置、汇率和产品/区域范围 |
| gross revenue vs net revenue | 主责/代理判断、平台流水与确认收入 |
| EBITDA vs adjusted EBITDA | 折旧摊销之外的额外剔除项 |
| CFO vs FCF vs adjusted FCF | 资本开支、租赁、营运资本和一次性现金项 |
| EV/EBITDA vs P/E | 企业价值/股权价值分子与对应盈利分母 |

不要仅凭名称判断定义相同；回到公司定义或数据供应商字段说明。

## 表格图表与文字表达

- 表头写成 `归母净利润（IFRS，百万元）` 与 `归母净利润（Non-IFRS，百万元）`，不要只写两个相邻的“净利润”。
- 执行摘要若引用调整后指标，同一句或相邻一句给出法定口径及差异驱动；不能让读者到附录才发现口径变化。
- 同一趋势图不混接 IFRS 历史值和 Non-IFRS 预测值。确需并列时使用两条明确命名的序列，并在口径切换点加注。
- 单期差异来源适合瀑布图；跨期口径差适合双序列表或趋势图。没有完整调节项时不生成伪造的瀑布桥。
- 估值表在倍数或目标价旁明确写 `基于 IFRS EPS`、`基于 Non-IFRS EPS` 等；同业倍数必须尽可能统一分母口径。
- 结论采用“法定结果 → 调整项 → 调整后结果 → 经济含义 → 估值/风险影响”顺序。

## 完成检查

交付前确认：

1. 所有关键盈利、利润率、EPS、现金流和估值字段都有清楚口径；
2. 同比、环比、预期差和同业比较均为可比口径；
3. IFRS/Non-IFRS 或同类差异已调节、并列或明确标为无法调节；
4. 没有把经常发生、股东承担或现金流相关的调节项笼统称为“一次性”；
5. 估值分母与报告正文使用的盈利口径一致；
6. 执行摘要已披露会实质改变判断的口径差异；
7. 口径不明、桥接不平或定义变化均作为限制与下一验证项保留。
