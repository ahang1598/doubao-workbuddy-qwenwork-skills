# 默认核心金融与财务数据

股票研究默认先建立分析对象的紧凑金融与财务快照。它用于锚定规模、经营质量、财务承受力和市场定价，不是可有可无的背景章节。只有确信这些数据不会改变答案时才可省略，并在交付清单记录具体理由。

## 选择原则

- 正文通常保留 4–10 个最能支持当前判断的字段；调查可以更宽，但不把数据库字段整页倾倒进报告。
- 快照位于核心结论之后、详细分析之前，优先用一张紧凑表格表达；正文不逐格复述，也不在后文重复同一组数字。
- 每个数字写清证券/对象、日期或期间、币种、单位、FY/CY/TTM、法定或调整后口径及来源。
- IFRS/Non-IFRS、GAAP/Non-GAAP、reported/adjusted 指标不得共用模糊表头；按 `accounting-basis-analysis.md` 明确标签，必要时并列法定值、调整后值与差异。
- 指标必须适合商业模式与盈利阶段。亏损公司不强行展示无意义的 P/E，金融企业不机械套用工业企业净债务口径。
- 数据不全时保留可得且可比的核心字段，用 `included_with_gaps` 明确缺口；不补造、不混用不可比口径，也不因为缺失部分字段而整体省略。

## 按研究对象选择

### 单一上市公司或证券

从下列类别选择能解释当前问题的 4–10 项：

- **市场锚点**：价格与估值日、总市值、企业价值；成交额/换手率只在流动性、异动或可执行性相关时加入。
- **规模与增长**：最新收入、收入增速及最能代表业务规模的行业 KPI。
- **盈利质量**：营业利润、净利润或 EPS，毛利率/营业利润率/净利率及其变化。
- **口径差异**：当调整后盈利被用于核心结论或估值时，同时保留对应法定盈利及关键调节差异；口径差显著时优先展示差异，而不是再增加一个次要 KPI。
- **现金与财务承受力**：经营现金流或 FCF、净现金/净债务、利息覆盖或其他适用指标。
- **资本效率**：ROIC、ROE 或与商业模式适配的回报指标。
- **市场定价**：P/E、EV/EBITDA、P/B、FCF yield 等真正适用的当前或前瞻估值；涉及预期时注明一致预期快照日。

按行业替换：

| 类型 | 更合适的核心字段示例 |
|---|---|
| 银行/保险/券商 | 贷款/资产/AUM、NIM、信用成本、NPL、CET1、ROE、NBV、偿付能力、P/B、P/E |
| REIT/地产运营 | NOI、FFO/AFFO、出租率、同店增长、净负债率、分派收益率、P/AFFO |
| 资源/周期制造 | 产销量、实现价格、单位成本、EBITDA/FCF、净债务、周期中枢估值 |
| 平台/订阅软件 | 用户/ARR、ARPU 或 take rate、增长、毛利率、经营利润率、FCF margin、留存/获客效率 |
| 亏损生物科技/早期成长 | 现金与净现金、现金消耗、现金跑道、研发投入、关键里程碑、EV/现金 |

### 行业、概念或板块

至少用指数/板块表现与估值锚定市场状态，再按问题选择成交/广度、汇总收入或盈利增速、利润率、资本开支、库存或核心景气指标，并说明龙头权重与样本口径。

### 股价与事件归因

除价格、区间收益、相对收益和流动性外，至少加入能约束叙事的盈利或估值锚点，例如盈利预期修正、最新利润增速、前瞻估值或事件前后估值变化，避免只用新闻解释价格。

### A/H 或跨上市地相对价值

同时列出两地价格、汇率、同权益口径折溢价、对应估值和必要的市值/股息信息；融券、转换、税费与结算约束单列，不能只展示静态价差。

### 组合或股票池

按任务选择净值/权重、集中度、流动性、行业/因子/币种暴露，以及能解释候选质量的统一财务与估值字段。缺失值不得当作零风险或中性值。

## 可省略边界

仅在下列情形之一成立，且补充金融数据不会改变答案时，设置 `core_financial_data_status=not_relevant`：

- 只核对一个明确日期、证券身份、定义或单一历史事实；
- 纯方法、口径或操作说明，不分析具体证券、公司、板块或组合；
- 用户把范围明确限制在与规模、盈利、现金、财务风险和市场定价均无关的问题；
- 其他可具体说明的重大理由。

“篇幅有限”“文档结构复杂”“数据获取较慢”“已有定性结论”或“部分字段缺失”都不是不相关理由。简单文本问题也不自动豁免：若核心金融数据会改变答案，就应升级交付方式并提供数据。

## 交付清单状态

- 计划态：使用 `planned` 并列出预计采用的字段，或使用 `not_relevant` 并写理由。
- 完成态：使用 `included`；若存在实质缺口，使用 `included_with_gaps` 并列出缺口；只有满足上节边界时使用 `not_relevant`。
- `core_financial_data_fields` 记录正文实际保留的字段名称，不记录调查阶段所有候选字段。
