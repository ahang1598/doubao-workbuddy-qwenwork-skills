# 报告领域覆盖矩阵

本矩阵仅用于内部防遗漏，不是正文目录，也不要求每篇报告出现全部领域。先按体裁检查触发项；候选信息还必须通过 `writing-quality.md` 的五项准入门槛才可进入正文。其他项只在工作记录中标为“不适用”“无重大影响”或“证据不足”，不要在报告中逐项声明已检查。

| 领域 | 默认触发体裁 | 正文最低要求 | 可省略条件 |
|---|---|---|---|
| 核心金融与财务快照 | 具体上市证券、公司、板块、股票池、组合、股价、估值及 A/H 分析 | 按对象选择 4–10 个决策相关字段，覆盖价格/规模、经营或盈利、现金流或财务承受力、适用估值；注明日期/期间、币种、单位、口径和来源 | 纯方法/定义/操作说明，或单一事实问题且这些数据确定不会改变答案；必须在交付清单说明 |
| 大盘 | 市场复盘、股价归因、组合风险、完整公司/行业研究 | 本地核心指数、风格/广度/成交及与目标资产的传导；利率、汇率、商品只在相关时加入 | 单一历史事实或纯会计口径问题 |
| 概念/板块 | 行业研究、公司研究、异动归因、筛选 | 定义分类，给板块表现/景气，并用收入、订单、资本开支或利润暴露核验“概念纯度” | 与公司和问题无经济联系 |
| 企业供应链位置 | 公司、行业、风险、事件驱动研究 | 上/中/下游或平台节点、关键投入与客户、议价权、利润池、替代来源和瓶颈 | 纯证券技术口径且不涉及经营 |
| 企业近期重要新闻 | 公司快照、会前准备、财报、完整研究、股价归因 | 覆盖与体裁匹配的窗口，按价值影响排序；列事实、日期、来源、传导和市场已知程度 | 用户只问单一历史期财务事实 |
| 供应链风险/国际新闻 | 行业、公司、催化剂风险、组合、事件驱动研究 | 制裁/出口管制/关税/航运/地缘事件的暴露节点、替代性、库存缓冲、财务传导和时间窗 | 无直接或二阶可解释暴露 |
| 图表 | 单股股价分析、时间序列、比较、情景、产业链、复杂事件、组合分析 | 单股股价分析优先脚本生成 K 线，只有可靠收盘价/分时价时脚本生成股价 HTML；其他场景按趋势、瀑布、热力图、时间线、象限或传导链 HTML 一图一问。标注日期、单位、币种、口径和来源 | K 线仅按明确例外省略；其他图在段落/小表更清楚、与已有图重复或数据不足时省略 |
| 监管新闻 | 受监管行业、公司新闻、风险、事件驱动、完整研究 | 发布机构、文件状态、适用对象、生效日、执行机制、财务传导；草案不得写成已生效 | 无适用性或不改变判断 |
| 外围：美股/日韩 | 市场晨报/复盘、跨市场归因、全球供应链、外需敏感行业 | 对齐时区与可交易时刻，覆盖相关指数/期货/汇率/同业；必须说明到本地资产的传导 | 仅存在时间上同时发生、无机制或异常反应 |
| H 股相对价值 | A/H 双重上市、H 股定价、跨市场价差、所谓套利 | 同币种同权益口径折溢价、历史位置、股息税费/汇率/交易日、融券与转换/交割约束、催化剂和止损条件 | 非双重上市且无可比跨上市地证券 |

## 体裁组合

- **完整公司研究/一页纸**：核心金融与财务快照 + 近期重大新闻 + 行业/概念 + 供应链位置为基础；大盘、监管、国际和外围按实质性加入。
- **市场晨报/收盘复盘/周报**：大盘 + 领涨跌板块 + 关键监管/国际事件 + 相关美股/日韩；不罗列无传导的全球新闻。
- **股价归因/事件驱动**：核心金融与财务快照 + 脚本生成 K 线或股价图 + 大盘 + 板块 + 公司新闻 + 必要外围；按信息可得时刻和异常收益判断证据强弱。K 线不适用时只在工作记录保留例外。
- **行业/供应链研究**：板块景气 + 价值链位置 + 供应链/国际风险 + 监管；用公司映射落地。
- **财报分析**：核心金融与财务快照 + 财报事实与预期为主，近期新闻只保留解释指引、预期或财报后交易的事项。
- **A/H 或 H 股相对价值**：核心金融与财务快照 + 价差与历史位置 + 可执行性约束 + 催化剂/风险；默认称“相对价值”，不自动称“套利”。
