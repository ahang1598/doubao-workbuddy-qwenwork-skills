# Task Playbook — 经营财务解读

## 口径冻结

- 默认币种：用户声明，否则索要；不默认虚构 FX。
- 毛利：仅直接/成本可变项（COGS、项目直接人工与直接费用）；不摊销间接开销除非用户明确要求「贡献后利润」并分列。
- 有利/不利：收入类实际>预算为有利；费用类实际>预算为不利。全文统一。
- 每个关键数字：数值 + 期间 + 来源标签（文件名或「用户粘贴」）。

## 模式工作流

### variance

1. 对齐科目：实际与预算同一树；无法对齐的进「未映射」并 degraded。
2. 显著性：金额阈值与比例阈值由用户给定；若皆无，用相对排序取绝对值Top项，并标注「未设组织重要性阈值」。
3. 分解优先级：
   - 收入：量差、价差，必要时结构差
   - 人员成本：人数、人均费率、结构/时点
   - 费用：编制驱动 / 量驱动 / 酌量 / 合约固定 / 一次性 / 时点
4. 运行 `variance_decomp.py`（价量）或汇总表；瀑布勾稽：起点 + 驱动之和 = 终点。
5. Narrative 结构：科目 | 有利不利 | 金额与比例 | 主因一句 | 持续性 | 动作。

### margin

1. 建产品/服务线清单：收入、直接成本、销量（可空）。
2. 运行 `margin_calc.py`。
3. 除负毛利这一算术状态外，不内置健康/偏薄/溢价阈值；用户未提供政策时输出 `UNASSESSED_NO_POLICY`。
4. 目标价、销量变化与弹性只接受用户政策或显式情景，不预设涨价幅度。
5. 不给出「保证提价无损量」断言。
6. 盈亏平衡必须披露固定/变动/半变动成本分类和产品组合假设；客户盈利的间接费用只按用户选择的分摊驱动列示。
7. 集中度可计算客户份额、Top-N 与 HHI，但风险线只来自用户政策；同时分列收入集中和利润集中。

### cash_runway

1. 期初余额与「截至日」必填。
2. 分周流入流出；区分 confirmed vs expected。
3. 运行 `cash_runway.py`：周表、用户给定最低现金额或固定成本周数、发薪状态；无缓冲政策则该门禁为 unknown。
4. 发薪：CLEARED / TIGHT / SHORTFALL —— SHORTFALL/TIGHT 置顶。
5. 缺口动作只建议（加速回款、延期非关键、动用授信、递延分红），不执行催收/支付。
6. 经常性/可变、confirmed/expected 分列；置信度只陈述数据覆盖，不内置风险颜色阈值。

### 经营风险与轻量报告

- 季节性优先使用至少两个完整年度；仅一年时标 `observational_only`，并列一次性事项和待解释驱动。
- 经常性成本输出供应商/合同/金额/周期/年化成本/使用状态；交易规律不能证明使用状态，动作恒为人工复核。
- 企业月度/年度 digest 只压缩已通过门禁的指标、异常、行动和局限；银行流水汇总不等于权责发生制或法定报表。

### cfo_brief

1. 抽取 KPI：收入、毛利、营业费用、净利润/亏损、现金、burn、runway（可算则算）。
2. 按数据可用性嵌入 variance/margin/cash 小节。
3. 异常：符号突变、单科目占比陡升、连续亏损且 runway 缩短——描述事实不贴身体疾病隐喻。
4. 行动项 ≤ 7 条，按紧急与现金影响排序。

## 场景假设

- 所有假设表列：名称、参数、来源（用户/推演）、影响指标。
- 禁止把假设写成已发生事实。

## 与相邻任务边界

- 需要律师函/诉讼：routed。
- 需要报税数字法定核定：routed；可列「待会计师确认材料清单」不影响主简报。
- 月结凭证级对账失败且用户只要结账清单：可 degraded 列出断点，不作审计结论。

## 脚本失败

- stderr/status=error → 不得填充假表；stopped 或 intake 修正输入。
