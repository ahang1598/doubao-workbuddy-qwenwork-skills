# 研究与证据规范

在报告需要外部事实、内部材料、用户证据、竞品结论或量化判断时使用本文件。

## 目录

- 决策主张与证据底稿
- 来源选择
- 状态、时效与冲突
- 用户证据与竞品实测
- 数字和市场规模
- 逐条回源审计
- 停止研究

## 1. 先研究会改变决策的证据

按“决策影响 × 当前不确定性”排列研究问题：

1. 会让总判断反转的证据；
2. 会改变目标细分、价值主张或进入方式的证据；
3. 会改变核心机制、能力依赖或主要风险的证据；
4. 只增加背景、不改变动作的材料。

先写待验证主张，再找证据。不要从搜索结果堆出章节，也不要在报告完成后用一组来源标题反向装饰结论。

可使用最小证据底稿：

| ID | 原子事实或决策主张 | 状态 | 直接来源标题、发布者与链接 | 发布时间/访问时间 | 版本、地区、套餐与口径 | 置信度及理由 | 支持的结论 |
|---|---|---|---|---|---|---|---|

置信度使用高、中、低并说明理由。多个来源可能转述同一原始材料，来源数量不等于独立证据。

“原子事实”应能被一个来源直接支持。将“支持多平台、速度最快且采用某模型”拆成平台、速度、模型归属三条事实，分别核验。为事实分配 `[F1]`、`[F2]` 等 ID，并在执行摘要、对比表、图表说明与建议依据中紧邻标注。

## 2. 选择最接近事实的来源

| 研究对象 | 优先来源 | 主要局限 |
|---|---|---|
| 用户问题 | 行为数据、工单、流失、可追溯访谈、任务观察 | 样本偏差，口述与行为不一致 |
| 产品机制 | 实际产品、本地实测、官方帮助与发布说明 | 营销材料常省略失败和边界 |
| 价格与包装 | 官方定价、合同、采购或账单事实 | 地区、套餐、促销和时间差 |
| 市场规模 | 政府或监管数据、原始研究、公司披露、方法透明的研究 | 定义、预测模型和商业偏差 |
| 竞争与战略动作 | 官方公告、财报、产品发布、招聘与生态动作 | 投入不等于采用、需求或成功 |
| 政策与标准 | 原始法规、监管机构、标准组织 | 生效时间、适用地区和解释差异 |

第三方媒体、评论、社区和搜索趋势适合发现线索、反例与用户语言，不单独证明普遍需求。搜索摘要只用于定位原文，不作为最终证据。官方首页的营销描述也只能支持它实际写出的范围，不能据此补全底层模型、失败边界或未披露指标。

涉及医疗服务、政府报销或公共资金、金融权益、法律合规等高风险路径时，只有当前权威来源明确支持适用性，且业务方确认可进入本期，才能写入 P0、对外卖点、价格承诺或确定路线图；否则保留为条件机会或待确认路径。

## 3. 标注状态、时效与冲突

在证据底稿和报告中区分：

- `已证实事实`：一手公开资料、正式数据或已确认内部事实；
- `用户提供`：用户给出的文档、数据或口述，保留其原始确定性；
- `本地实测`：记录产品、版本、套餐、环境、步骤和结果；
- `推断`：从事实推导，写明推导链和可能的替代解释；
- `待验证假设`：当前证据不足，附验证方法；
- `产品建议`：基于目标与约束作出的取舍。

为易变化事实标注 `as of` 时间，并记录地区、平台、版本、套餐和适用范围。用户要求“最新”时回到当前一手来源。

来源冲突时：

1. 并列展示各来源的定义、数值、样本与日期；
2. 判断差异来自口径、版本、地区、套餐还是时间；
3. 说明采用哪一口径及原因；
4. 无法解决时保留冲突并降低置信度，不求平均值。

引用紧邻关键数字、功能边界、用户结论、竞品动作和市场判断。文末来源需具体到可定位的标题或材料、发布者或提供者、日期、链接或文件、访问时间和支持的事实 ID。

来源清单只有标题、产品名或网站名时不算完成。每条关键事实应满足双向可追溯：从报告能找到来源，从来源表也能找到它支持的事实和结论。

## 4. 处理用户证据

将反馈绑定到真实任务与行为，至少记录：角色、触发场景、当前替代、实际步骤、失败点、后果和已付出的成本。

样本不足时使用“在当前样本中出现”，不要写“多数用户”或“用户普遍”。引语必须可回溯且不改变原意；无法确认原文时使用转述。

为高优问题主动寻找反证：谁没有这个问题，何时替代方案已经足够，用户为何不迁移，购买者为何不批准。

## 5. 进行竞品实测

关键流程至少记录：

- 产品、版本、套餐、平台、地区和测试日期；
- 前置条件、输入、步骤、输出和错误；
- 截图、录屏或文件证据；
- 本次观察能证明什么、不能证明什么。

单次测试不能证明稳定性，也不能外推到所有版本。官方说明与本地实测冲突时并列呈现，说明测试边界并安排复测。

帮助文档没有提到某功能只是弱信号，不能直接判定“不支持”。公开路线图、更新频率和招聘可以说明投入方向，但不自动证明用户需要或商业成功。

## 6. 使用数字和市场规模

每个关键数字记录：定义、值或区间、单位或币种、地区、时间、实际或预测、样本或分母、来源和计算方式。跨来源比较前先确认定义可比。

让数字精度不超过证据精度：

- 来源给区间，就保留区间；
- 来源只支持方向，就写方向；
- 定性证据不转换为精确百分比；
- 没有基线、渠道能力或时间窗口，不计算 SOM 或 ROI；
- 不使用无依据的固定权重、行业基准或“拿到 1%”式份额。
- 竞品数字缺少同口径测试条件时不参与横向评分或排名。

估算 TAM、SAM、SOM 时优先使用可解释的自下而上模型，列出公式、假设、地区、时间和数据来源。数据不足时说明现有证据能证明什么、不能证明什么，以及最值得补充的数据和获取方式。

对明显反常的数字先检查单位、口径、翻译、样本和时间。无法复核时移入待验证区，不把它写成确定事实。

产品路线图中的准确率、延迟、留存、客户数、收入和市场份额同样属于事实性承诺。只有存在定义、基线、样本、测量窗口、数据来源、资源或技术评估时才可给出；否则写成需要建立的验证门，不自行填数。

用户明确要求量化矩阵时，缺少可核实数值的单元格写“搜索未找到”“不可比”或“待补”，并说明已尝试的来源；不得用“高、中、低”冒充市场规模、商户数等事实，也不得为填满矩阵制造数字。高、中、低只可用于有判定依据的产品优先级或风险判断。

## 7. 完成逐条回源审计

成稿前单独检查执行摘要、对比矩阵、定位图、路线图和推荐理由：

1. 标出所有可被外部核验的事实；
2. 确认每条事实都有相邻 ID；
3. 打开对应原始来源并核对完整措辞；
4. 检查来源是否仍为当前版本，以及时间、地区、平台和套餐是否匹配；
5. 删除来源无法直接支持的修饰词、比较级和因果关系；
6. 确认待验证项没有进入评分、产品定位或指标承诺。

任一高影响事实无法回源时，报告只能标为研究草稿，不能标为正式决策稿。

## 8. 停止研究

出现以下情况即可停止扩搜：

- 关键主张已有相互独立的证据支持；
- 新来源只重复现有内容；
- 剩余不确定性更适合通过低成本实验验证；
- 继续搜索不会改变当前选择或风险等级。

停止研究不等于消除不确定性。将未解决项转成验证计划、证据门或重审条件。
