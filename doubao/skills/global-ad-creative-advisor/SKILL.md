# 出海广告公开情报探查（P1 同类型产品数据 / P2 广告透明库 / P3 原生热点 · 只做查询分析）

## 职责与交付物

以**广告主**身份，基于公开可查信息，为「产品 × 地区」端到端完成**公开情报查询、采集与结构化分析**。**主线投放平台固定四个：Google Ads、Meta、TikTok Ads、Apple Search Ads（ASA）；媒体热点平台固定四个：YouTube、TikTok、Facebook、Instagram。**

分析与交付顺序**固定为三段，不可颠倒、不可跳段**：

1. **P1 地区同类型产品数据扫描（前置）**：锁定 Top3 同类型产品，只交付**数据**——产品信息、市占/量级、活跃（DAU/MAU）代理指标、核心媒体平台广告在投概览；**本阶段不展示任何素材本体、截图与文案拆解**。
2. **P2 核心媒体平台付费素材查询**：GG/Meta/TT/ASA 先按平台建 Top10 采集池，**报告按同类型产品分组、每个同类型产品列 Top5 素材物料并附零登录实采的真实在投封面 + 可点击原内容链接**，另出搜索词包；统一字段落表、九维拆解、跨平台模式聚类。
3. **P3 原生内容平台地区热点查询**：YouTube/TikTok/Facebook/Instagram **近 7 天原生内容**（非广告口径）+ 搜索需求风向，**每个内容平台列 Top3 近期热点物料并附真实封面 + 原内容链接**，产出热点×卖点相关性标注。

P2/P3 完成后**汇总输出探查报告**（数据、素材、热点、模式分析、词包、缺口与来源口径）。用户只问其中某一段（如"只查这几家的广告""只看本周热点"）时从对应阶段切入，不强制走全流程，但结论口径仍受本文件全局约束。

**能力边界（本 Skill 不做什么）**：只做公开信息的**查询、采集、记录、结构化拆解与模式分析**；**不产出**广告创意方向、逐镜分镜脚本、开头钩子、双语文案、CTA 方案、A/B 测试方案、creative brief，也不产出成片视频/图片——这些需求按"适用边界"转交创意制作类能力。

## 适用边界（何时使用 / 何时转交）

- **适用**：零登录公开信息可完成的事——同类型产品数据扫描、广告透明库素材查询、原生热点探查、搜索词整理、素材/热点的结构化拆解与模式分析。
- **不适用，转交到对应能力**：
  - 需要广告创意概念、分镜脚本、广告文案、creative brief 等创作产出 → 转创意策划/短视频脚本类能力，本 Skill 只提供素材与模式分析输入。
  - 需要登录广告主账户、读取账户内花费/出价/人群数据，或执行广告搭建、改预算、调价、上下架等账户操作 → 转投放执行/盯盘类能力（如 tiktok-ads、meta-ads-mcp、google-ads-mcp、oceanengine 相关能力），本 Skill 不连接任何账户。
  - 需要直接产出成片视频/图片 → 转创意视频/创意设计类能力。
  - 电商自有账号的内容日历、直播/带货脚本、达人内容复用运营 → 转 doubao-cross-border-growth-content；本 Skill 只处理付费广告侧同类型产品公开情报查询。
  - 要求原样复刻/搬运同类型产品视频、素材或 BGM → 拒绝，本 Skill 只做模式分析。
  - 国内投放（非出海）、非公开/付费后台数据 → 不在本 Skill 范围。

## 全局硬性约束（优先级最高，不可违反）

1. **零登录、零 MCP、零接管、零绕过**：只使用**官方开放平台公开页面、官方公开库/公开接口与全网通用搜索**（来源开放性判定见 `references/05`）；**不连接任何广告 MCP，不登录任何账号，不要求用户扫码/输密码/接管浏览器，不自动注册虚拟身份账号，也不通过关闭登录弹窗、绕过人机/同意页、第三方镜像等方式取得未直接公开的内容**。页面未登录直接公开渲染才采集；遇到注册墙/登录墙/人机验证或被遮挡：换官方公开替代入口，仍取不到则**过滤不展示并在"覆盖缺口"登记**，绝不以记忆或付费后台数据顶替。
2. **顺序硬约束**：P1 未完成（Top3 与检索计划未明确）不进入 P2；P2/P3 可并行，两者都完成后才汇总输出探查报告。
3. **P1/P2 物料隔离**：P1 只出现"在投状态、版位分布、开投时间、素材数量级"这类**概览数据**，素材本体、文案、截图一律留到 P2。
4. **数据可得性分级（A/B/C/D，详见 `references/02`）**：A=官方公开精确值；B=官方公开库页面显示值；C=第三方免费层/模型估算；D=开放渠道不可得（必须改用代理指标并标注）。**不编数字**：商业广告无精确曝光/花费/出价/ROI；估算值只看量级与相对趋势，跨平台不比较数值大小，只归纳模式共性。
5. **不搬素材**：同类型产品广告与他人原生内容仅用于模式分析与内部展示；每条素材标注来源链接与采集日期；禁止下载搬运、对外发布或作为投放素材。
6. **不做刻板印象定论**：地区创意偏好只是先验假设，必须用本次采集结果验证或修正。
7. **合规前置**：金融、健康、博彩、减重、未成年人等敏感品类及 GDPR/DSA、中东禁忌等，在素材/热点的合规标注与风险提示中逐条标明；不蹭政治、灾难、悲剧与争议社会热点。
8. **素材必须真实可见、可回溯（硬要求）**：
   - **真实封面**：P2 每个同类型产品 Top5、P3 每个内容平台 Top3 的每条物料都要配**本次零登录实地截取或官方接口拉取的真实封面图**；**严禁占位图、AI 生成图、记忆图或网图冒充真实在投素材**。采不满配额（如某同类型产品免登录仅见 4 条、IG 登录墙无封面）就按实际数量全列并显式标注"已全列 N 条/无公开封面"，同时登记覆盖缺口，绝不凑数。
   - **原内容链接**：每条物料附可点击链接（`target="_blank" rel="noopener"`）。有单条公开固定链接的给**直链并核验有效**——YouTube 提取 11 位 videoId 组 `watch?v=` 后用 oEmbed 核验频道/标题一致；App Store/ASA 用 iTunes Search API 返回的 `trackViewUrl`。平台不提供单条免登录固定链接的（Meta Ad Library、GG 透明度、TT），**精确定位到该素材所在的检索结果页/广告主域名页/话题页**（带国家、在投、排序等完整参数，由脚本生成），并在报告注明"单条无公开固定链接，定位到该批素材列表页"；FB/IG 只使用已知公开主页或单条内容的固定直链，不做 Watch/标签/Explore 主动搜索。**禁止伪造 videoId / 广告 id / 帖子 id。**
   - **封面加工链**：浏览器零登录截图落盘 `creatives/<平台>/` → 裁剪压缩成 web 用图 → 拼联系表（contact sheet）自查封面与物料一致 → 报告相对路径引用（图片路径静态写在 `<img src>`，不要经 JS 拼接，否则内嵌会裂图）。**交付前必须做到单文件可离线打开**：装有 html skill 的环境（如云电脑）优先用其 `scripts/embed.py <报告.html>` 把封面 Base64 内嵌、交付它产出的 `<名>_embed.html`；无 html skill 时用环境内其他内嵌能力，或将 `creatives/` 与 HTML 同目录打包并在报告注明。随后做桌面宽屏 + 移动窄屏双端自检：有 html skill 时跑其 `scripts/shot.py <html>`（默认双端截图+lint，优先处理 consoleErrors，脚本本身失败可跳过改人工）；无该脚本时按"无控制台/资源报错、封面不裁字、窄屏网格正常堆叠、含 viewport meta"逐项人工自检，不得跳过。
9. **第三方商标、版权与数据使用边界（合规底线）**：
   - **商标**：Google、Meta、TikTok、Apple/ASA、YouTube、Facebook、Instagram 等均为各自权利人的商标/品牌，本 Skill 仅为指明研究对象而作**指示性合理使用（nominative use）**，不构成与任何平台的官方关联、授权、认证或背书；Skill 自身名称、产出物与对外物料不得嵌入第三方商标或冒充官方。
   - **版权与外发分级**：同类型产品广告与他人原生内容的截图、文案**仅限内部同类型产品分析**，且全程留痕（来源链接 + 采集日期 + 权利人）。**内部版**报告可含截图；**对客户/对外版**必须先过版权与合规审核，或改用文字描述/取得授权；严禁把同类型产品素材直接用于对外投放素材（细则见 `references/04` 版权分级节）。
   - **零第三方商业数据依赖（硬约束）**：P1–P3 的数据与素材**只来自官方开放源（官方商店/榜单、官方公开接口、官方广告透明库、官网/SEC 等官方披露、官方公开报告）与全网公开搜索**，以及 YouTube/TikTok 等平台的公开原生内容。**不使用 Similarweb、Sensor Tower/data.ai、Crunchbase、Owler、BuiltWith、Wappalyzer、ASO.dev、Social Blade、Newzoo、Statista、AppMagic 等任何第三方商业数据/估算平台**（不登录其面板、不引用其模型估算、脚本也不生成其入口）；这些平台原本提供的下载/收入估算、Web 月访问、技术栈等，开放渠道拿不到时一律按 D 级走官方代理指标（榜单位次/商店评论速率/官方账号互动/Google Trends），不找第三方补。公开口碑社区（应用商店自带评论、以及全网公开可检索的公开讨论）按全网公开搜索口径短引用、不成段搬运。

## Step P0：需求建档（一次问清，附默认值）

用户已提供的不重复问；能公开查到的先自查；只把真正影响结论的问题**一次性**抛出（不超过 5 个）。

| 信息项 | 缺失时的默认值 |
|---|---|
| 产品名、品类、端（iOS/Android/Web）、官网/商店链接 | 无链接时请用户一句话描述核心功能 |
| 目标地区（可多市场） | P1 分析后推荐 3 个优先级市场并说明理由 |
| 核心媒体平台范围 | 默认 GG + Meta + TT + ASA 全量；纯 Android/Web 产品自动跳过 ASA 并注明 |
| 查询目标 | 默认转化侧（安装/注册/订阅/购买）相关素材与词 |
| 素材语言 | 英语 + 各目标市场本地语言 |
| 采集配额（锁定值） | **每地区 Top3 同类型产品；核心媒体平台先按平台建 Top10 采集池，报告按同类型产品分组、每个同类型产品展示 Top5 真实素材（带封面+原内容链接）；原生内容平台每个展示 Top3 近期热点物料（带封面+链接）；热点窗固定近 7 天；不足配额按实采数量全列并登记缺口** |
| 交付形态 | **默认自包含 HTML 探查报告**（单文件可直接浏览器离线打开、封面内嵌不丢图），同时保留 Markdown 工作底稿与采集 TSV；用户另有指定从其指定 |

建档同时按 `references/01` 完成：JTBD、卖点矩阵、人群场景、**五类关键词矩阵初稿**（品类/功能/痛点场景/同类品牌/本地俚语，英文+本地语），供 P1/P2/P3 检索使用。

## P1：地区同类型产品数据扫描（只出数据，不出物料）

读取并遵循 `references/02-market-competitors.md`，要点：

1. 同类型产品识别覆盖四层 + 本地生态替代（直接/替代/跨品类/新锐 + 本地生态），用商店榜单、评论区、广告库粗扫、本地语原生搜索实地识别，**收敛到 Top3**做深。
2. 逐家建**数据型档案**：产品信息（定位/端/定价/上线/版本/评分评论量）、市占与量级（商店分类榜名次与变化趋势、官网/SEC/官方公开报告披露，**不用第三方下载/收入估算与 Web 月访问**）、活跃代理指标（精确 DAU 属 D 级不可得时，用榜单位次/商店评论速率/官方账号互动/Google Trends 等**五条官方开放代理**并标级）、**核心媒体平台广告在投概览**（仅在投状态/版位/最早开投时间/素材数量级，不展示素材）。
3. 一张含我方的**数据型对比矩阵**（同一把尺子）+ 当地用户选择逻辑 + **3–5 个差异化空白与"不打什么"**（作为同类型产品分析结论与后续 P2 采集重点，不在本 Skill 内展开为创意方案）。
4. 产出 P2/P3 检索计划：核心媒体平台同类型产品检索词/域名/Page 名清单 + 原生内容平台本地语关键词/话题清单。
5. **阶段闸门**：P1 报告中不得出现素材截图、广告文案、视频拆解。

## P2：核心媒体平台付费素材查询（Top10 采集池 / 每个同类型产品展示 Top5 + 搜索词）

读取并遵循 `references/03-meta-adlibrary-playbook.md`：

- **Meta**：Meta Ad Library，链接必须由 `scripts/build_adlibrary_url.py` 生成，默认 active + total_impressions 降序，视频优先。
- **Google Ads**：Ads Transparency Center，按 P1 同类型产品域名查 Search/YouTube/Display/Shopping 广告。
- **TikTok**：主源 Creative Center **Top Ads 免登录公开部分**（免登录仅展示前若干张卡片，能采多少采多少）；欧盟/英国/瑞士市场用官方 **Commercial Content Library** 按广告主补全；另以站内搜索中带"赞助/Sponsored"标记内容补充；缺口登记。
- **ASA**：欧盟市场用官方 **Apple Ad Repository**（adrepository.apple.com，免登录，查 App/开发者在欧盟的版位/素材/投放期）；**非欧盟无公开广告库**，改用 App Store 逐搜索词巡查顶部广告位（谁投该词、其 listing 素材）+ iTunes Search API + 商店元数据采集；不支持的场景过滤不展示。
- **搜索词包**：GG 走 Google Trends/搜索下拉相关搜索/透明度中心文案反推；ASA 走 App Store 联想词、iTunes 公开接口；TT 走话题/趋势词；Meta 由广告文案反推。
- **采集池与展示**：每平台先建 Top10 采集池、统一 schema、截图留证、每条写"为什么是优势素材（相对信号）"；**报告呈现按同类型产品分组，每个同类型产品列 Top5 物料，每条带真实在投封面 + 可点击原内容链接**（链接策略见全局约束 8），不足 5 条按实采数量全列并标注；随后按 `references/04` 九维拆解并聚类为 3–5 张跨平台模式卡（只归纳模式，不写创意方案）。

## P3：原生内容平台地区热点（近 7 天，与 P2 并行）

读取并遵循 `references/06-tt-yt-weekly-trends.md`。**只采平台原生内容、非广告口径、全程免登录**：

- **YouTube**：本周+按播放量搜索（脚本已内置确定性筛选参数）、Trending、Shorts、Google Trends×YouTube。
- **TikTok**：站内搜索/话题页，按卡片日期人工筛近 7 天，用本地语言词锁定地区。
- **Facebook（弱开放，仅直链）**：只用 P1/用户已给出的**公开主页视频/Reels 固定直链，未登录能直接渲染才采**；不做 Watch 主动搜索、不关闭登录弹窗；无公开热榜，缺的部分以 TT/YT 外溢与全网公开搜索补，取不到登记缺口。

## 工具路由

- **其余开放平台入口**：`scripts/build_openintel_urls.py`——覆盖官方广告透明库（GG 透明度中心、TT 热门广告/商业内容库、Apple 法定库）、官方商店与 iTunes 公开接口、FB/IG 公开固定直链；脚本只拼接公开 URL、不发请求，**且只含官方开放源、不含任何第三方商业数据平台入口**；`--plan` 按 P1 清单批量导出 TSV，自带 selftest（含"零第三方"反向断言）。
- **原生内容平台热点链接**：`scripts/build_trend_urls.py`（`--plan` 一键生成，复用同一套市场代码表，自带 selftest）；脚本只开放 TT/YT 开放发现与 FB/IG 已知公开固定直链（fb-page/ig-profile/ig-reel），**不提供 fb-watch、ig-tag 等主动探查入口**，与 P3 红线一致。
