# 用户需求与产品多维分析框架（P0 建档 / P1 前置）

> 何时读取：执行 P0 需求建档与 P1 同类型产品扫描前。目标：先从"用户要完成什么任务（JTBD）"出发，把用户一句"我是一个 xxx 客户/产品"转成可用于找同类型产品、找素材、建搜索词包的结构化输入，并产出关键词矩阵。
>
> 顺序要求：先理解**用户需求/场景/痛点**，再盘点产品能力去匹配；产品"有什么功能"从属于"用户拿它解决什么"。本步只做产品侧结构化，不采集素材。

1. 产品建档

## 1. 产品建档（先补齐事实）

用下表建档；能从官网、应用商店页、公开资料查到的用浏览器/搜索自行补齐，查不到的标"待用户确认"，不编造：

| 字段 | 内容 |
|---|---|
| 产品名 / 公司 | |
| 品类（一级/二级） | 如：效率工具 / AI 对话助手 |
| 端与形态 | iOS / Android / Web / 桌面 / 小程序（**决定 ASA 是否适用：无 iOS 端则 P2 跳过 ASA 并注明**） |
| 上线阶段 | 冷启动 / 增长期 / 成熟期 / 衰退防守 |
| 变现模式 | IAP 内购 / IAA 广告 / 订阅 / 电商 GMV / 线索 Lead / 免费引流 |
| 价格与付费点 | 定价、免费额度、首单/试用策略 |
| 当前市场现状 | 已上线地区、榜单/量级（用户提供或公开可查部分，按 02 手册 A–D 级标注） |
| 官网/商店链接 | 根域名（GG 透明度中心用）、App Store/Google Play 链接（ASA/iTunes 接口用）、Meta Page 名、TT 账号名 |

## 2. 行业与买量环境

- **赛道定位**：一级/二级行业与细分品类，边界划清（决定同类型产品范围）。
- **生命周期判断**（决定素材观察重点）：
  - 新兴品类 → 重点观察"教育市场、解释是什么、制造好奇"类素材
  - 成长品类 → 重点观察"差异化、为什么选我、对比教育"类素材
  - 成熟品类 → 重点观察"抢同类型产品用户、促销、社会证明、场景唤醒"类素材
- **核心媒体平台买量大盘特征**：该品类在 GG（搜索意图承接/YouTube）、Meta（社交信息流）、TT（原生短视频）、ASA（App Store 搜索收口）各自的主流素材形式与竞争强度。
- **合规基线**：记录该品类宣称禁区（健康疗效、金融收益、博彩、减重、AI 生成内容标识、DSA/GDPR、中东禁忌等），采集与分析时对相关素材逐条标注规避点。

## 3. 卖点矩阵（本框架的核心产出）

把产品能力逐条拆成三列，并打两个分，筛出"低可视化难度 + 高差异度"的卖点优先推进广告：

| 功能事实（产品有什么） | 用户利益（so what，对用户意味着什么） | 可视化证据（画面能拍到/录到什么） | 差异度 高/中/低 | 可视化难度 高/中/低 |
|---|---|---|---|---|
| 例：一键 AI 消除路人 | 旅行照不用再等没人的瞬间 | 前后对比录屏，3 秒出效果 | 高 | 低 |

要求：
- 功能事实至少列 5 条，覆盖核心功能、辅助功能、服务/价格优势。
- "用户利益"必须具体到场景结果，禁止停留在"高效/便捷/智能"等空词。
- 可视化证据要具体到镜头能呈现的动作或画面对比。
- 该矩阵同时是 P3「热点×卖点相关性标注矩阵」的卖点列来源。

## 4. 用户需求、人群与场景（先需求后功能）

- **用户任务（JTBD，先写）**：用一句话写"当我处于【场景】时，我想【完成什么】，以便【获得什么结果/情绪】"；这是后续人群场景与卖点分析的根。
- **人群画像**：人口属性、消费力与设备档位（影响 ASA/GG 与素材机型表达）、心理特征与内容偏好。
- **高频使用场景**：列 3–5 个，每个写清「什么时间 + 什么地点 + 遇到什么任务/情绪 + 产品如何解决」——素材采集时的场景匹配参照。
- **痛点与决策动机**：理性动机（省钱/省时/效果确定）与感性动机（身份认同/焦虑缓解/社交货币）分开列；痛点要能在 P1 与同类型产品差评、P3 与原生内容互相印证。
- **反人群**：明确谁不会被打动，避免方向发散。

## 5. 漏斗与广告目标（对齐核心媒体平台分工）

| 漏斗层 | 素材任务 | 典型素材 | 主投平台参考 | 本次是否为主 |
|---|---|---|---|---|
| 认知 Awareness | 让人记住是什么、制造兴趣 | 新奇演示、痛点共鸣、品牌故事 | TT/YT/Meta 信息流 | |
| 考虑 Consideration | 证明"为什么是我" | 对比、教程、证言、深度演示 | GG(YouTube/搜索)、Meta | |

## 6. 必交付：关键词矩阵（供 P1/P2/P3 使用）

五类检索词，**每类都要给英文 + 重点目标市场语言**（西/葡/日/韩/印尼/阿语等，可借助翻译但需回译检查语义），并标注主要消费平台：

| 词类 | 含义与写法 | 主要消费环节 |
|---|---|---|
| 1. 品类词 | 用户怎么称呼这类产品（AI chatbot / video editor） | P1 识别同类型产品；P2 GG 搜索词、ASA 词、TT 话题；P3 原生搜索 |
| 2. 功能词 | 核心能力的搜索表达（summarize PDF / remove background） | GG/ASA 词包主力；P2 素材检索 |
| 3. 痛点/场景词 | 问题句式优先（how to fix blurry photo / X alternative） | GG 长尾、TT 原生内容、PAS 钩子来源 |
| 4. 同类品牌词 | P1 补全的 Top3 及主要替代品名称 | Meta Ad Library/TT Top Ads/GG 透明度中心按品牌检索；ASA 同类型产品词 |
| 5. 本地化俚语/人群词 | 本地用户口语化说法、平台流行表达 | P3 锁定本地原生内容；本地化检索词 |

词矩阵同时派生：Meta 检索词、GG 透明度中心域名/广告主名、ASA 搜索巡查词表、TT/YT/FB/IG 原生搜索词与话题。

## 7. 输出示例（AI 陪伴 App，片段）

- 生命周期：成长品类 → 素材观察重点：差异化对比、情感共鸣类表达。
- 卖点矩阵首行：角色自定义语音通话 → 孤独时随时有人回应情绪 → 差异度高 / 可视化难度低（P2 采集时重点观察该卖点在真实素材中的呈现形式）。
- 关键词矩阵（节选，英文）：品类词 `AI companion`、`AI friend`；功能词 `AI character chat`、`talk to AI`；痛点词 `feeling lonely app`、`AI friend like Replika`；同类型产品词 `Replika`、`Character.AI`；本地语词（印尼）`teman AI`、`mengobrol dengan AI`。
- 平台采集重点：ASA 观察 `AI companion` 等明确搜索词的广告位与 listing；TT 观察痛点场景原生短视频；Meta 观察证言类素材；GG 观察 `X alternative` 对比词与 YouTube 教程侧广告。
