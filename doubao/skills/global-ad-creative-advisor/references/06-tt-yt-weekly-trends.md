# P3 原生内容平台近 7 天热点探查手册（YouTube / TikTok / Facebook / Instagram · 免登录 · 非广告口径）

> 何时读取：P1 明确目标地区与同类型产品后立即执行，与 P2 并行。固定时间窗「近 7 天」，目标是看目标市场用户这一周在**刷什么原生内容、搜什么**，结构化记录并标注与产品卖点的相关性；素材方向开发不在本 Skill。

## 0. 口径底线（先读）

1. **只看平台原生内容，不走广告口径**：一律来自平台站内搜索/话题/公开主页/Trending 与 Google Trends；同类型产品**付费**素材在 P2（核心媒体平台手册）处理，两类证据分开记录、分开表述，**不跨源比较数值**。
2. **全程零登录、零接管、零绕过**：不登录任何账号、不要求用户接管、不使用第三方镜像/搬运站，**也不通过关闭登录弹窗、绕同意页等方式取得未直接公开的内容**。只采未登录直接公开渲染的内容；被登录弹窗/同意页遮挡时，可换官方公开入口或稍后重试一次，仍遮挡即停并在"覆盖缺口"登记，不用广告后台或记忆顶替。
3. 所有链接由脚本生成：TT/YT/FB/IG/Trends 用 `scripts/build_trend_urls.py`；脚本只拼公开 URL、不发请求；只采未登录直接可见内容，不绕验证、不抓非公开数据、不下载搬运他人视频/音乐。
4. **来源仅限官方开放平台与全网公开搜索**。YT/TT 具备免登录公开发现能力，作为主力；**FB/IG 对未登录不提供开放发现（无公开热榜、搜索/Explore 关闭），只接受 P1/用户已给出的公开主页或单条固定直链——直接打开能渲染才采，不做主动搜索/标签探查、不绕行、不用镜像，打不开就整项登记缺口、不硬凑条数**。
5. **开放可及的内容平台各展示 Top3 近期热点物料，每条必须带零登录实采的真实封面 + 可点击原内容链接**：YouTube 为核验过的单条视频直链；TT 无单条免登录固定链接时定位到公开话题页；FB/IG 仅采可直接打开的固定直链；取不到封面就只登记缺口、**绝不放占位图/生成图/第三方镜像图**。

## 1. 探查线与原生内容平台分工

| 探查线 | 回答的问题 | 平台/入口（均免登录） | 时间窗 |
|---|---|---|---|
| A. 平台原生热门内容 | 本周在刷什么题材/形式/梗/BGM/钩子 | YT 搜索·Trending·Shorts；TT 搜索·话题（主力，开放发现）；FB/IG 仅已知公开固定直链（无开放发现） | 近 7 天 |
| B. 搜索需求风向 | 品类/同类型产品相关搜索在升还是降、冒出什么新词 | Google Trends（web + youtube 两个 gprop） | 近 7 天，辅以近 12 个月大盘 |
| C.（对照）同类型产品付费动作 | 同类型产品付费侧在投什么，与原生风向是否一致 | 引用 P2 结论（Meta/GG/TT/ASA），不在本手册重复采集 | 近 7 天 |

一次性生成某市场全部侦察链接：

```bash
python3 scripts/build_trend_urls.py --plan --markets ID \
  --keyword "lagu AI" --keyword "AI cover" \
  --hashtag fyp --hashtag laguai \
  --fb-account <同类型产品/本地达人FB主页slug> --ig-account <公开IG账号slug> \
  --domain suno.com --format tsv --out weekly_trend_plan.tsv
```

关键词来自 01 词矩阵与 P1：每市场 ≥1 品类词 +1 本地语言词 +1 同类品牌词；FB/IG 因无公开搜索热榜，需要 P1 先列出"已知本地达人/同类型产品/品类账号清单"作为直链输入。

## 2. YouTube：本周搜索 + Trending + Shorts + Trends

### 2.1 关键词搜索（A 线主力，已内置"本周+按播放量"）
- `--source yt-search --market <地区> --keyword <词>` → 脚本已确定性内置「本周上传 + 按播放量排序」参数，**打开即为本周高播放结果，无需手点筛选**；Shorts 在页内点「Shorts」Tab。
- 记录：标题句式、频道类型（个人/达人/媒体/品牌）、播放量量级、发布天数、时长、封面套路、前 3 秒、内容形式（教程/评测/对比/Vlog/Shorts）。
- 结果顶部标"赞助商"的广告计入 P2 对照，不计入原生统计。
- **原内容直链（必做）**：从搜索结果页解析每条入选视频的 11 位 `videoId`，组 `https://www.youtube.com/watch?v=<id>` 作为可点击直链；**写入报告前用官方 oEmbed 核验**——请求 `https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=<id>&format=json`，确认返回的 `author_name`/`title` 与记录一致，防止错链；核验失败则退回该关键词的搜索结果页链接并注明。封面取该视频缩略图或结果页实截，须与标题对应。
- **"本周+播放量"筛选参数（sp）失效重取 SOP**：脚本用常量 `YT_SP_WEEK_VIEWS`（`scripts/build_trend_urls.py`，当前值 `CAMSBAgDEAE=`）确定性生成"本周上传+按播放量排序"。YouTube 会不定期更换该编码，若打开结果不是"本周/按播放量"（如变成不限时间或相关度排序），按下列步骤重取，不要硬猜：①浏览器打开 YouTube 搜索任意品类词 → ②点「筛选/Filters」→ 上传日期选「本周/This week」、排序选「播放次数/View count」→ ③复制结果页最终 URL 里的 `sp=` 参数值（URL 编码形态）→ ④替换脚本常量 `YT_SP_WEEK_VIEWS`（解码后形态）→ ⑤重跑 `python3 build_trend_urls.py --selftest` 确认生成 URL 带上新 sp 且页面筛选正确。

### 2.2 Trending 地区热门榜（A 线）
- `--source yt-trending --market <地区>`：记录 Now/Music/Gaming 等分类前 10–20 的题材、标题句式、封面、时长、频道类型，提炼"该市场用户本周愿意看完的内容结构"。
- 已知坑：个别会话被同意页重定向（w/h=0 或 400），不纠缠，改用 2.1 的 yt-search 补齐并登记。

### 2.3 Google Trends × YouTube（B 线）
- `--source gtrends-yt --market <地区> --keyword 词1 --keyword 词2`：看近 7 天兴趣走势（升/降/脉冲）与 **Related queries 的 Rising 上升词**，直接转广告选题与词包补充；最多对比 5 个词；脚本直连可能 429，用浏览器打开即可。

## 3. TikTok：站内搜索 + 话题页（A 线主力）

### 3.1 站内搜索
- `--source tt-search --keyword <词>` → `tiktok.com/search?q=<词>`；页内切「视频」Tab，排序先选「获赞最多/Most liked」找高互动原生内容，再切「最新」看本周新冒头形式。
- **按卡片日期（M-D 或"X 天前"）人工筛近 7 天**——TT 网页端没有"本周"筛选，此步必做。
- 记录：配文、作者类型（素人/达人/品牌/媒体）、点赞量级、发布日期、话题标签、形式（口播/教程/剧情/反差/合拍/录屏）、前 3 秒、BGM 类型与卡点、系列化套路。
- **地区口径**：TT 搜索 URL 不带地区参数，**用本地语言关键词、本地人名/地名/曲风词锁定目标市场**，逐条标注"是否本地创作者/本地语言"，不把英文全球热门误当本地风向。

### 3.2 话题页
- `--source tt-tag --hashtag <话题>`：记录话题总播放量量级、近 7 天高赞视频的共同形式与 BGM、话题所处阶段（上升/爆发/平稳/衰退，对比"最新"与"获赞最多"两栏密度判断）。
- 本地大流量泛话题看形式，品类垂直话题看与产品相关的真实表达。
- **兜底与链接**：TT 站内搜索接口在部分云环境持续服务器报错时，不硬撞，改用 `tt-tag` 话题页（仍可拿到高赞视频流）；单条视频的 `/@user/video/id` 永久链接在免登录列表页通常不暴露、**不伪造 id**，报告统一链到该批素材所在的话题页 `tiktok.com/tag/<话题>`（listing），并注明"单条无免登录固定链接，定位到话题页"。

## 4. Facebook：仅公开主页/Reels 固定直链（弱开放，不做主动发现）

FB 无公开热榜，Watch/站内搜索对未登录不稳定且弹登录窗。按"零绕过"原则，**不做 Watch 主动搜索、不关闭登录弹窗**，只走下列开放路径：

1. **公开主页/Reels 固定直链（唯一采集通道）**：用 P1/用户已给出的主页 slug（`--source fb-page --account <slug>`）打开公开主页「视频/Reels」栏，**未登录直接渲染**的近 7 天内容才记录（题材、形式、播放/点赞量级、本地化表达）；被登录墙遮挡即停，不反复尝试、不关弹窗。
2. **跨平台外溢**：TT/YT 本周爆发的本地原生形式，看同一创作者是否在其 FB 公开主页同步分发（走公开直链），判断该形式在 FB 的适配度。
3. **全网公开搜索补证**：用全网通用搜索查该市场本周 FB 上传播较广的公开视频/话题报道（标为二手来源），不登录 FB 做站内主动检索。
4. 记录时标注"FB 无开放发现、仅直链样本"，取不到整项进覆盖缺口表，不硬凑条数。

## 5. Instagram：仅公开账号/单条 Reel 固定直链（弱开放，不做主动发现、不用镜像）

IG 未登录时 Explore/搜索/标签/热榜基本关闭，按"零绕过"只接受已知公开固定直链：

1. **公开账号主页直链**：用 P1/用户给出的账号 slug（`--source ig-profile --account <slug>`），未登录直接渲染才记录近 7 天 Reels 的题材、封面、点赞量级、字幕风格；页面要求登录即停止，不反复尝试。
2. **单条 Reel/帖子直链**：`--source ig-reel --reel <公开 Reel 链接或 shortcode>`（CLI 参数为 `--reel`，不是 `--url`；链接来自 P1 已知材料或创作者在其他开放平台的公开简介），未登录可直接渲染才采。
3. **明确不做**：不做 Explore/搜索/标签主动探查，不做 `site:instagram.com` 式绕行抓取，**不使用 Picuki、Imginn、Dumpor 等第三方镜像/匿名查看站**，不注册、不登录、不关闭登录遮挡。
4. 打不开或被登录墙遮挡即整项登记缺口；IG 缺口不影响 TT/YT 主结论成立。

## 6. 采集 SOP、替代顺序、schema 与缺口登记

**SOP**：脚本 `--plan` 生成 TSV → 浏览器逐条打开（不登录）→ 核对近 7 天 → 滚动采集 → 截图（命名 `平台_市场_对象_日期.png`）→ 落表去重。**展示侧每个内容平台精选 Top3：整页截图落 `creatives/<平台>/raw/` → 裁剪单条封面、压缩到 `creatives/web/` → 拼联系表逐张核对封面与标题一致 → HTML 静态引用；交付前内嵌成单文件（有 html skill 跑其 `embed.py` 交付 `_embed.html`，无则其他内嵌工具或 creatives 同目录打包），并做桌面+移动双端自检（有 html skill 跑其 `shot.py`，无则按清单人工自检）。**

**被遮挡时的替代顺序（不发起登录、不绕遮挡）**：①只在开放入口间换（TT 搜索↔话题；YT Trending↔搜索↔Shorts；FB/IG 只换另一条已知公开固定直链，不做搜索/标签/Explore 探查）；②在开放平台内换本地语同义词/相关话题；③用全网公开搜索找公开报道作二手辅证；④仍取不到则进覆盖缺口表，不用任何后台数据/记忆顶替，也不关闭弹窗硬取。

**三类记录行**：

- **原生内容行（原生内容平台统一）**：platform、market、surface、query_or_topic、rank、title、creator、creator_type、views_or_likes_level、posted_days、content_form、hook_0_3s、music_or_pacing、trend_direction（上升/爆发/平稳/衰退）、is_local、**cover_image（真实封面相对路径，无则填"无公开封面"）、source_link（报告可点击链接）、link_type（direct=YT 核验过的 watch 直链或 FB/IG 可直接打开的固定直链 / listing=TT 公开话题页）**、url、note
- **搜索趋势行（Google Trends）**：market、keyword、gprop(web/youtube)、7d_direction、rising_related_queries、note
- **付费对照行（引用 P2）**：platform、advertiser、format、hook、cta、variants、url、note（注明"付费，引自 P2"）

**覆盖缺口表**：平台 | 市场 | 缺失内容 | 原因（登录墙/无热榜/地区不支持）| 已用替代 | 对结论影响。

## 7. 原生热点的结构化标注（查询分析，不产出创意方案）

本 Skill 只对热点做客观拆解与相关性标注，作为后续创意环节（不在本 Skill）的输入：

1. **形式层拆解标签**：逐条标注开头钩子类型、叙事结构、镜头节奏、字幕花字、BGM 卡点方式、标题/封面句式——只记录"是什么"，不做翻拍、不写改编脚本、不用别人的 BGM/画面。
2. **热点 × 卖点相关性标注矩阵**：行=本周原生热点（话题/形式/上升词，标注来源平台），列=01 卖点矩阵的高优先卖点，逐格标注相关性（高/中/低）与合规风险（高/中/低）；每市场挑 3–5 个"高相关 × 低合规风险"组合**列出即可，不展开为创意方向**；是否采用、何时上线由后续创意环节决定。
3. **原生内容平台表达差异（标注口径参照）**：
   - **TikTok**：9:16、强达人/UGC 感、前 3 秒无品牌片头、15–30s、卡点、口语字幕、像普通用户发的；
   - **YouTube**：Shorts 走竖屏原生感；长视频/前贴广告前 5 秒出钩子且核心前置（可跳过）；搜索侧需求明确，教程/评测/对比类内容承接更明显；
   - **Facebook**：偏中年与熟人语境，字幕信息更完整、节奏可稍缓，"实用/情感/共鸣"题材更稳；
   - **Instagram**：视觉质感与封面美学要求更高，Reels 偏精致生活方式，字幕/封面排版讲究，弱口播硬推销。
4. **同类型产品空白对照（分析结论）**：把原生正在爆的形式与 P1 同类型产品档案、P2 付费素材对照，标注"用户在看但同类型产品付费侧少见"的形式缺口，作为探查结论呈现，不做创意立项与制作安排。
5. **时效声明**：每条热点标采集日期；热点窗口短，统一标注"采集时点近 7 天，时效性有限"，可每周复扫（需要时创建定时任务）。

## 8. 口径局限与红线

- TT 点赞、YT/FB/IG 播放或互动均为**页面显示值**，只在同一平台内分"量级档位"（万级/十万级/百万级），不抄精确个位；Google Trends 是 0–100 相对指数非搜索量；**跨平台、跨源不比较数值大小，只归纳模式共性**。
- TT 网页端无"本周"筛选、无地区 URL 参数，靠人工按日期筛 + 本地语锁地区；YT Trending 被重定向时用 yt-search 补；FB 无公开热榜、IG 登录墙频繁，按第 4/5 节替代链执行并登记缺口。
- 不依赖、不要求任何登录；用户主动提供其账号内截图时另列为"用户提供"，不作为免登录结论。
- 不蹭政治、灾难、悲剧、争议社会热点；未成年人、健康、金融等敏感品类按 04 手册合规备注逐条审。
- 不下载搬运他人视频/音乐对外发布；热门 BGM 商用走正版曲库，记录只写风格与节奏参考。
