# 字节UG自动化投放Agent-巨量引擎盯盘与数据分析

这是默认只读版。调用用户已授权、已绑定的巨量官方 Remote MCP，完成 R0 查询和分析；不读取本机 MAPI 凭证，不使用浏览器代写，也不修改广告账户。它不依赖 macOS Keychain 或 Windows Credential Manager：在支持官方 Remote MCP 的 macOS、Windows 桌面端及兼容的网页端均按平台能力使用。

## 使用场景

| 应使用 | 不应使用 |
|---|---|
| “看看今天巨量账户消耗和深层成本” | “暂停消耗高的计划” → 引导 `$bytedance-ug-oceanengine-local-autopilot` |
| “近 7 天哪些计划在空跑或成为长尾” | “新建 10 条广告计划” → 引导高级版 |
| “诊断广告组 CPA 偏高的原因，低样本先观察” | “把预算调到某金额” → 引导高级版 |

## 输入与输出

最少输入为精确广告账户、统计窗口和分析目标；成本是否达标还需要浅层/深层 KPI、目标值、容忍度、样本门槛和创建保护期。只问当前任务缺失的字段；可使用 [只读分析请求模板](assets/read-only-request-template.md)。

输出必须包含：数据窗口、层级、指标值、归因/回传成熟度、样本量、数据来源、缺失字段，以及 `keep`、`observe` 或 `suggest_pause`。`suggest_pause` 只是建议，绝不调用暂停工具。

## 首次调用与能力检查

1. 读取 [官方 MCP 接入与回查](references/official-mcp-onboarding.md)。确认当前会话存在已绑定的 `oceanengine-official-remote` MCP；若平台登记的实际 ID 不同，先同步 `agents/openai.yaml` 后上传。
2. 先调用工具列表或能力查询，确认已授权账户和支持的报表维度。未绑定、无账户权限或不支持请求指标时返回 `setup_required` / `blocked`，不猜测结果。
3. 只请求当前所需账户、窗口、层级和指标；不得要求用户提供 MCP 凭证、Token、Cookie、App Secret 或授权码。

## 工作流

1. 识别为账户概览、小时盯盘、计划/广告诊断、长尾候选、基建趋势或跑出率。
2. 读取 [指标与诊断规则](references/metrics-and-diagnosis.md)，收集最少缺失项。未提供考核目标时只给中性观察，不给“成本超标”结论。
3. 通过官方 MCP 读取数据；标明窗口、归因口径、来源、缺失字段、样本量及成熟度。
4. 用户提出任何写入需求时，说明本 Skill 不具备写能力，路由到高级版；不得代为执行。

## 数据展示与安全边界

- 默认掩码展示账户和对象标识，例如 `ADV_****1234`；只有用户已在当前会话指定精确对象且完成任务确有必要时，才回显最小范围的对象标识。
- 不展示或记录 Secret、Token、Cookie、授权码、手机号、联系人、落地页隐私参数和原始 OAuth 响应。
- 低样本、创建保护期、未完成小时、归因不明和回传未成熟对象一律 `observe`。
- 默认阈值仅作可修改参考；以用户 KPI、容忍度和样本要求为准。
- API 读取不可用时，只可导入用户从官方后台导出的文件；不得改用浏览器操作账户。
