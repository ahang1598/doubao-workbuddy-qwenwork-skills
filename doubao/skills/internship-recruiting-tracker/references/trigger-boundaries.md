# Trigger Boundaries

## Should Trigger
- 我是大三计科，想找上海后端实习，帮我做投递计划。
- 根据这个 JD 帮我改简历项目描述。
- 下周有产品经理面试，帮我准备题目和复盘表。
- 用户要求交付：岗位周报、投递计划、简历修改建议、面试题
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我保证拿到字节 offer。
- 帮我写班级活动通知。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 岗位链接已过期。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
