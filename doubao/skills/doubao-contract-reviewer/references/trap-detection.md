# 合同陷阱检测清单

> 本文档整理自合同审查技能的标准化陷阱检测模式，共收录 **47 项**通用检测 + **按合同类型的特殊检查项**，
> 覆盖形式审查（F-01 ~ F-10）、逻辑一致性（L-01 ~ L-12）、实质风险（S-01 ~ S-25）三大维度。
>
> **改进**：所有涉及权利义务方向的规则均增加"触发前提"列，严格区分"约束我方"还是"约束对方"。
>
> **去重说明**：标注 `⚙RL-X` 的规则表示与 risk-library 规则 X 完全/高度重叠，执行时以 risk-library 为准，本表中该规则**跳过不重复扫描**。仅当 risk-library 对应规则未被执行时（如被意外跳过），本规则作为兜底触发。

---

## 使用指南

1. **逐项扫描**：按编号从 F-01 到 S-25 依次检查。
2. **三层递进**：形式→逻辑→实质。
3. **遵守触发前提**：每条规则先读触发前提，不满足则跳过，不生成批注。
4. **去重优先**：标注 `⚙RL-X` 的规则已在 risk-library 中执行，直接跳过。
5. **标记命中项**：记录编号、命中位置、具体表现和优先级。
6. **结合合同类型**：完成通用47项后，补充对应的特殊检查项（见文末）。
