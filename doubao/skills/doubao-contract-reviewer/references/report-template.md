# 合同审查报告输出模板

本文件是 `doubao-contract-reviewer` 的伴随参考，对应 SKILL.md 第 8 节「输出模板」。在组织最终三层报告输出时按此结构生成。

下面是报告骨架（照此层级填充，实际输出即为报告正文）：

```markdown
# 合同审查报告

## 一、审查前提

- 我方立场：
- 合同类型/交易实质：
- 命中交易模块：
- 是否包含附件/补充文件：
- 总体签署建议：可签 / 修改后可签 / 不建议直接签 / 需补充信息后判断

## 二、风险总览

- 必改风险：X 项
- 可争取优化项：X 项
- 形式完善项：X 项
- 最高风险集中在：付款 / 交付验收 / 责任赔偿 / 解除终止 / 保密 / IP / 数据 / 其他

## 三、必改风险

按重要性排序。每条使用：

1. **位置**：
   **问题**：
   **风险等级**：高/中/低
   **为什么影响我方**：
   **建议动作**：替换/新增/删除/谈判确认
   **建议文本**：

## 四、可争取优化项

按谈判价值排序。每条使用同一结构。

## 五、形式完善项

同类问题合并输出，避免刷屏。

## 六、跨条款/跨附件复查

- 金额/付款：一致 / 不一致 / 未发现
- 期限/生效终止：一致 / 不一致 / 未发现
- 责任/赔偿上限：一致 / 不一致 / 未发现
- 附件义务是否加重：是 / 否 / 未发现
- 需要特别同步修改的位置：

## 七、签署建议

给一句清晰结论：

- 如果存在高风险必改项：建议修改后再签。
- 如果只有可争取项：可结合谈判地位争取优化。
- 如果只有形式项：补全后可签。
```
