## 附录 A：常见法律术语对照表

| 易混淆术语 | 区别 | 使用场景 |
|------------|------|----------|
| 定金 vs 订金 | 定金：受定金罚则约束（《民法典》587条）；订金：仅为预付款性质 | 合同担保条款 |
| 违约金 vs 赔偿金 | 违约金：预先约定的固定金额/比例；赔偿金：实际损失为基础 | 违约责任条款 |
| 解除 vs 终止 | 解除：合同关系溯及消灭或向后消灭；终止：合同关系向后消灭 | 合同效力条款 |
| 保证 vs 担保 | 保证：仅指人的担保；担保：包括保证、抵押、质押、留置、定金 | 担保条款 |
| 不可抗力 vs 情势变更 | 不可抗力：不能预见、不能避免、不能克服；情势变更：可预见但不公平 | 免责条款 |
| 连带责任 vs 按份责任 | 连带：债权人可向任一债务人要求全部履行；按份：各自承担份额 | 责任承担条款 |
| 法定代表人 vs 法人 | 法定代表人：自然人；法人：组织 | 签署主体 |
| 效力性强制 vs 管理性强制 | 效力性：违反则合同无效；管理性：违反受处罚但合同有效 | 合规审查 |
| 善意 vs 恶意 | 善意：不知道且不应知道；恶意：知道或应当知道 | 善意取得等 |
| 诉讼时效 vs 除斥期间 | 诉讼时效：可中止、中断、延长；除斥期间：不变期间 | 权利行使期限 |

## 附录 C：常见错别字检查库

| 错误写法 | 正确写法 | 说明 |
|----------|----------|------|
| 签定 | 签订 | 最常见的合同错别字 |
| 帐户 | 账户 | "帐"用于帐篷；"账"用于账户 |
| 权力 | 权利 | 权力指公权力；权利指民事权利 |
| 以至于 | 以致 | 表因果关系用"以致" |
| 制定/制订 | 视语境 | 制定：政策、法规；制订：计划、方案 |
| 做出/作出 | 视语境 | 法律文本多用"作出" |
| 其它 | 其他 | 规范书面语用"其他" |
| 份 | 分 | 视语境判断 |
| 必须/必需 | 视语境 | 必须：一定要（动词前）；必需：不可缺少（名词前） |
| 决议/决意 | 视语境 | 决议：集体决定；决意：个人决心 |
| 预定/预订 | 视语境 | 预定：预先确定；预订：预先订购 |
| 申明/声明 | 视语境 | 申明：申述说明；声明：公开宣告 |
| 受权/授权 | 视语境 | 受权：接受权力；授权：给予权力 |
| 义务/意务 | 义务 | "意务"为笔误 |
| 甲方/假方 | 甲方 | "假方"为笔误 |
| 利益/利意 | 利益 | "利意"为笔误 |

## 附录 F： vs  变更日志

| 项目 |  |  | 改进说明 |
|------|-----|-----|----------|
| 审查方法论 | 三层审查（基础→进阶→专业） | 五步专业工作流 | 更系统、更专业、更一致 |
| 知识库 | 外部链接获取 | 嵌入式本地文件（本地优先） | 默认本地读取，速度提升 50%+；需要时仍可联网 |
| 修改方式 | 逐条修改（1条/脚本调用） | 批量修改（5-10条/脚本调用） | 脚本调用次数减少 80% |
| 验证方式 | 每批验证 | 一次最终验证 | 减少冗余验证 |
| 立场管理 | 默认甲方，无严格检查 | 显式立场确认 + 每条修改立场检查 | 消除立场混淆问题 |
| 谈判地位 | 不支持 | 三级策略适配 | 更精准的修改建议 |
| 形式审查 | 基本缺失 | 独立 Step 5 + 10类检查 | 形式审查覆盖率大幅提升 |

| 批注格式 | 自由格式 | 结构化格式（问题/原因/后果/建议） | 更专业、更可操作 |

| 陷阱检测 | 基础检查 | 40+ 种陷阱，5类合同特殊检查 | 覆盖率大幅提升 |

| 并行加载 | 串行 | 文件下载 + skill加载并行 | 启动速度翻倍 |
