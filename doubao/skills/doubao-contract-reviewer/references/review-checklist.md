# 补充验证清单

本清单用于**最终验证阶段**，专注于主流程（Step 2-3）可能遗漏的边缘检查项。主流程已覆盖的常规检查项不再重复列出。

> **优先级说明**：P0 = 必须修改 / P1 = 强烈建议修改 / P2 = 建议修改

---

## 一、交付物质量验证

### 1.1 Track Changes 完整性
- [ ] 所有建议修改均已标记为 Track Changes
- [ ] 每处 Track Change 有对应批注说明理由
- [ ] 批注使用了【风险等级】+【风险分析】+【修改建议】三段式格式，且字数符合上限（风险分析 P0≤60/P1≤60/P2≤35，修改建议 P0≤60/P1≤60/P2≤35）；风险分析点明后果、稍带法言法语；定位一律用条款号/性质词，禁用 clean_text 段号

### 1.2 立场一致性复核
- [ ] 抽检全部修改，确认无违反我方立场的建议
- [ ] 代表甲方时未建议增加甲方不利条款
- [ ] 代表乙方时未建议降低对方违约责任

### 1.3 数量与排序
- [ ] 审查意见总数 ≤ 15 条
- [ ] 按 P0 > P1 > P2 排序

### 1.4 文件完整性
- [ ] .docx 文件可正常打开
- [ ] 风险等级视觉编码已正确设置（批注人统一为「合同审查助手」，风险图标 🔴/🟡/🔵 出现在批注正文的【风险等级】标签处）

---

## 二、交叉引用核验覆盖率（⭐  核心验证项）

### 2.1 索引表完整性
- [ ] 条款编号-标题索引表已构建，覆盖所有层级（含子条款）
- [ ] 索引表中编号连续，无遗漏

### 2.2 交叉引用提取完整性
- [ ] 全文所有"第X条""见第X条""依据第X条""定义见第X条"等引用均已提取
- [ ] 包含非标准格式引用（"上述第X条""违反第X条""适用第X条"等）

### 2.3 三层核验执行完整性
- [ ] 每个交叉引用均已完成编号存在性核验
- [ ] 每个交叉引用均已完成内容相关性核验
- [ ] 所有"定义见第X条"类引用均已完成定义匹配性核验
- [ ] 批量引用（"依据第X条、第Y条和第Z条"）已逐一拆分核验

### 2.4 核验结果统计
- [ ] 审查摘要中包含交叉引用核验统计（总数/通过/编号不存在/内容不匹配/定义不匹配）

---

## 三、易遗漏边缘项

以下检查项在主流程中容易被快速略过，此处做二次确认：

### 3.1 合同过期与倒签
- [ ] 合同结束日期是否已早于当前日期（已过期 → P0）
- [ ] 合同开始日期是否早于当前日期（倒签风险 → P1）
- **常见障碍**: 合同约定"有效期至2024年12月31日"但当前已过期

### 3.2 多层引用链
- [ ] 多层引用链（A引B，B引C）是否全部有效
- [ ] 引用条款的实际内容是否与引用语境匹配
- **常见障碍**: "违反第8条保密义务"但第8条实际是付款条款

### 3.3 附件与正文一致性
- [ ] 正文中提及的所有附件是否实际存在
- [ ] 附件内容是否与正文约定一致
- [ ] 目录中的附件与实际附件是否一致

### 3.4 自动续约陷阱
- [ ] 续约时长是否超过 1 年
- [ ] 续约次数是否超过 1 次
- [ ] 是否有"无异议即自动续约"无任何限制
- **常见障碍**: "乙方无异议即自动续约"无限制

### 3.5 先款后票风险
- [ ] 是否要求先收到发票再付款
- [ ] 付款期限是否至少为收到发票后 10 个工作日

### 3.6 审计权
- [ ] 对方是否有权对我方审计（如有，提示风险）

### 3.7 间接损失
- [ ] 我方违约责任是否包括间接损失/预期利润赔偿
- [ ] 赔偿总额是否有上限

### 3.8 验收后质量异议权
- [ ] 验收通过是否免除对方质量责任
- **常见障碍**: "验收后不得对产品质量持有异议"（隐蔽瑕疵无救济）

### 3.9 定金条款
- [ ] 定金比例是否 ≤ 20%（《民法典》第586条）
- [ ] "定金"与"订金"是否区分使用
