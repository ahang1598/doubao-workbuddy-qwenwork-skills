> 本文件仅包含通用规则（risk-library 40 条 + trap-detection 16 条独有规则）**未覆盖**的版权/授权合同特有风险。
> 识别为版权合同时由 SKILL.md Step 0 条件加载，非版权合同不加载本文件。

## 规则详情

### CR-01 授权作品定义不明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🟡 P1 |
| **触发前提**| **始终触发**。授权标的不清是版权合同的根本性风险 |
| **风险描述**| 合同未对授权作品进行精确定义（作品名称、类型、版本、编号等），可能导致授权范围理解不一致，或被授权方使用了授权范围外的作品 |
| **检测方法**| 检查合同是否明确定义授权作品：①作品名称/标题；②作品类型（文字/音乐/美术/视听等）；③版本/版次（如有）；④是否含附属作品（续集/衍生作品等） |
| **修改建议**| 在合同中增加"授权作品"的精确定义，建议采用附件清单形式逐一列明，并注明"未列入清单的作品不在本合同授权范围内" |

### CR-02 授权类型（独占/排他/普通）未明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🟡 P1 |
| **触发前提**| **始终触发**。《著作权法》第 26 条规定许可使用合同应当明确许可使用的权利种类和许可类型 |
| **风险描述**| 合同未明确授权类型（独占许可/排他许可/普通许可），依《著作权法》默认为普通许可，可能不符合被授权方的商业预期 |
| **检测方法**| 检查合同是否明确使用"独占许可""排他许可""普通许可"等法定表述，或用等效描述明确授权排他性 |
| **修改建议**| 明确约定授权类型，例如："授权方将授权作品以{独占/排他/普通}许可方式授权被授权方使用" |

### CR-03 授权范围（地域/媒介/用途）不完整

| 字段 | 内容 |
|------|------|
| **优先级**| 🟡 P1 |
| **触发前提**| **始终触发**。授权范围三要素（地域、媒介、用途）任一不明确均构成重大风险 |
| **风险描述**| 合同未完整约定授权的地域范围（全球/中国大陆/特定地区）、使用媒介（线上/线下/纸质/电子等）和使用用途（商业推广/内部使用/再创作等），导致被授权方使用时可能超出授权边界 |
| **检测方法**| 检查合同是否同时约定：①授权地域；②授权媒介/渠道；③授权用途。任一缺失即触发 |
| **修改建议**| 完整约定授权三要素："授权地域为{范围}，授权媒介为{渠道}，授权用途为{具体用途}。超出上述范围使用需另行取得书面授权" |

### CR-04 二次授权/转授权条款缺失

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**被授权方**时触发。我方为授权方→不触发（未约定转授权时默认被授权方不得转授权，对授权方有利） |
| **风险描述**| 合同未约定被授权方是否有权将授权转授给第三方使用，被授权方在商业合作中需要分授权时将受限 |
| **检测方法**| 检查合同是否约定转授权/二次授权条款：①是否允许；②如允许，是否需授权方同意；③转授权的范围限制 |
| **修改建议**| 增加条款："被授权方{经授权方书面同意后/有权}将授权作品转授权给第三方使用，转授权范围不得超过本合同授权范围" |

### CR-05 改编权与衍生作品权利归属未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**被授权方**时触发。我方为授权方→不触发（未约定时改编权默认保留在授权方，对授权方有利） |
| **风险描述**| 合同未约定被授权方是否有权对作品进行改编、翻译、汇编等二次创作，以及二次创作产生的衍生作品的权利归属 |
| **检测方法**| 检查合同是否约定：①改编/翻译/汇编等权利是否授予；②衍生作品的著作权归属（授权方/被授权方/共有）；③衍生作品的使用限制 |
| **修改建议**| 增加条款明确改编权和衍生作品归属："被授权方有权对授权作品进行改编，改编产生的衍生作品的著作权归{归属方}所有，但被授权方使用衍生作品应注明原作品出处" |

### CR-06 原始素材/源文件交付义务未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🔵 P2 |
| **触发前提**| 我方为**被授权方**时触发。我方为授权方→不触发 |
| **风险描述**| 合同仅约定授权使用但未约定授权方需交付原始素材/源文件（如设计源文件、高清母带、文字原稿等），被授权方实际使用时可能因素材质量不足影响使用效果 |
| **检测方法**| 检查合同是否约定：①授权方应交付的素材清单和格式要求；②交付时间；③素材质量标准 |
| **修改建议**| 增加条款："授权方应在合同签订后 X 日内向被授权方交付授权作品的{原始素材/源文件/高清版本}，格式为{要求格式}，且素材质量应满足被授权方的正常使用需要" |

### CR-07 著作人身权处理不当

| 字段 | 内容 |
|------|------|
| **优先级**| 🟡 P1 |
| **触发前提**| **始终触发**。中国《著作权法》规定著作人身权（署名权、修改权、保护作品完整权）不可转让，约定转让将导致条款无效 |
| **风险描述**| 合同约定"转让全部著作权"或包含放弃署名权/修改权的条款，违反法律强制性规定导致相关条款无效 |
| **检测方法**| 检查合同是否有以下表述：①"转让全部著作权"（应区分人身权和财产权）；②"放弃署名权"；③"不得行使修改权"；④"放弃保护作品完整权" |
| **修改建议**| 修改为"转让/许可著作财产权"，对署名权的处理改为"署名方式由双方另行约定"而非"放弃署名" |

### CR-08 权利瑕疵担保缺失

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**被授权方**时触发。我方为授权方→不触发（无权利担保对授权方有利） |
| **风险描述**| 合同未约定授权方对作品权属的担保义务，若授权作品存在权利瑕疵（如侵犯第三方著作权），被授权方面临侵权诉讼风险且无法向授权方追偿 |
| **检测方法**| 检查合同是否有授权方的权利担保条款：①保证享有合法著作权或有权授权；②保证不侵犯第三方权利；③权利瑕疵时的赔偿责任 |
| **修改建议**| 增加条款："授权方保证其为授权作品的合法著作权人或已获得合法授权，保证授权作品不侵犯任何第三方的知识产权。因权利瑕疵导致被授权方遭受第三方索赔的，授权方应承担全部赔偿责任" |

### CR-09 侵权处理机制和责任分担未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| **始终触发**。版权侵权纠纷高发，需明确双方的维权分工 |
| **风险描述**| 合同未约定发现第三方侵权时的处理机制（谁来维权、费用谁出、赔偿如何分配），以及一方被第三方主张侵权时的配合义务和责任分担 |
| **检测方法**| 检查合同是否约定：①第三方侵权时的通知义务；②维权主体和维权费用承担；③赔偿分配；④被第三方主张侵权时的配合义务 |
| **修改建议**| 增加条款："任一方发现第三方侵犯授权作品权利的，应及时通知对方。维权行动由{主体}发起，维权费用由{承担方}承担，获得的赔偿按{比例/方式}分配" |
