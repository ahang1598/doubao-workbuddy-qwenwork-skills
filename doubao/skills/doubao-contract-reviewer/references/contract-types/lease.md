# 租赁合同专项审查规则

> 本文件仅包含通用规则（risk-library 40 条 + trap-detection 16 条独有规则）**未覆盖**的租赁合同特有风险。
> 识别为租赁合同时由 SKILL.md Step 0 条件加载，非租赁合同不加载本文件。
>
> **编号规则**：LS = Lease，编号 LS-01 ~ LS-09。
> **方向化**：所有规则均标注触发前提，严格区分"约束我方"还是"约束对方"。

## 规则详情

### LS-01 出租权权属承诺缺失

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**承租方**时触发。我方为出租方→不触发（出租方无需自我承诺权属） |
| **风险描述**| 出租方未在合同中承诺其对租赁物享有合法出租权（所有权或转租授权），一旦真实权利人主张权利，承租方面临被迫搬离且无法追偿的风险 |
| **检测方法**| 搜索合同中是否有出租方关于"享有合法出租权""拥有所有权或合法授权""保证有权出租"等承诺条款 |
| **修改建议**| 增加条款："出租方承诺其对租赁物享有合法出租权利，因权属争议导致承租方无法正常使用的，出租方应承担全部损失赔偿责任" |

### LS-02 租期超过 20 年法定上限

| 字段 | 内容 |
|------|------|
| **优先级**| 🔴 P0 |
| **触发前提**| **始终触发**。无论我方持方为哪一方，超出法定上限的部分均无效 |
| **风险描述**| 《民法典》第 705 条规定租赁期限不得超过 20 年，超过部分无效。如合同约定的租期（含续租后累计）超过 20 年，超出部分不受法律保护 |
| **检测方法**| 提取租赁期限（起止日期或约定年限），计算实际租期；同时检查续租条款中是否存在"自动续约"使累计租期可能超过 20 年 |
| **修改建议**| 将租期调整为≤20 年，或增加条款："租赁期限（含续租）累计不超过 20 年" |

### LS-03 押金条款不完整

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**支付押金方**（通常为承租方）时触发。我方为收取押金方→不触发（条款不完整对收取方更有利） |
| **风险描述**| 押金条款仅约定金额但未明确退还条件、退还时间、可扣除情形，导致租期届满后出租方以各种理由拖延或拒绝退还押金 |
| **检测方法**| 检查押金条款是否同时包含：①押金金额；②退还时间（如"租期届满后 X 日内"）；③退还条件（如"租赁物验收合格后"）；④可扣除情形及标准 |
| **修改建议**| 完善押金条款，明确"租期届满且租赁物验收合格后 X 个工作日内，出租方应将押金无息退还承租方；出租方有权从押金中扣除承租方未付租金及应承担的维修费用，扣除金额应提供明细" |

### LS-04 维修责任未明确划分

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| **始终触发**。《民法典》第 712 条（出租人维修义务）和第 714 条（承租人妥善保管义务）提供默认规则，但合同未明确时容易产生争议 |
| **风险描述**| 合同未区分大修（结构性/设备老化）和日常维护（使用损耗）的责任划分，容易在实际履行中产生推诿 |
| **检测方法**| 检查合同是否明确约定：①出租方维修范围（通常为结构性/设施设备老化）；②承租方维修范围（通常为日常使用损耗）；③报修响应时间；④维修费用承担规则 |
| **修改建议**| 增加维修责任条款："租赁物的结构性维修及设施设备自然老化的维修由出租方负责，承租方使用不当造成的损坏由承租方负责维修。出租方应在收到报修通知后 X 个工作日内响应" |

### LS-05 转租条款缺失或方向不利

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**承租方**时触发。我方为出租方→不触发（缺少转租条款时依《民法典》第 716 条，承租方未经同意不得转租，对出租方有利） |
| **风险描述**| 合同未约定转租条款，或明确禁止转租但无合理例外。承租方经营调整时（如分租部分面积）将无法灵活处理，可能构成违约 |
| **检测方法**| 检查合同是否有转租条款；如有，是否仅允许"经出租方书面同意"但未约定"不得无故拒绝"或合理的审批时限 |
| **修改建议**| 增加或完善转租条款："承租方经出租方书面同意后可将租赁物部分或全部转租。出租方应在收到转租申请后 X 个工作日内答复，逾期未答复视为同意" |

### LS-06 装修改造权利和费用承担未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🔵 P2 |
| **触发前提**| 我方为**承租方**时触发。我方为出租方→不触发（未约定则承租方自行承担风险，对出租方无不利） |
| **风险描述**| 承租方实际使用中经常需要进行装修改造以适应经营需要，合同未约定装修权限和费用归属，容易在退租时因装修残值产生纠纷 |
| **检测方法**| 检查合同是否约定：①承租方是否有权装修/改造（及审批流程）；②装修费用承担；③租期届满时装修物的处理（恢复原状/归出租方/折价补偿） |
| **修改建议**| 增加条款："承租方有权对租赁物进行合理装修改造，重大改造需经出租方书面同意。租期届满时，双方协商装修物的处理方式；如需恢复原状，合理磨损除外" |

### LS-07 租赁物返还条件未明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🔵 P2 |
| **触发前提**| **始终触发**。返还条件不明对双方都可能产生风险 |
| **风险描述**| 合同未约定退租时租赁物的验收标准和返还流程，容易在退租时因"正常磨损"与"损坏"的界定产生争议 |
| **检测方法**| 检查合同是否约定：①返还时的验收标准；②"正常磨损"的定义或排除；③返还流程（验收→交接→结算） |
| **修改建议**| 增加条款："租期届满时，承租方应将租赁物按正常使用后的状态返还，正常磨损除外。双方应在 X 个工作日内共同验收并签署交接确认书" |

### LS-08 租赁登记/备案要求未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🔵 P2 |
| **触发前提**| 租赁物为**不动产**（房屋、办公场所、商铺、仓库等）时触发。动产租赁→不触发 |
| **风险描述**| 不动产租赁未办理备案登记可能影响承租方对抗第三人的效力（"买卖不破租赁"的前提是登记对抗），且部分地区要求强制备案 |
| **检测方法**| 判断租赁物是否为不动产；如是，检查合同是否约定备案登记的义务方、时限和费用承担 |
| **修改建议**| 增加条款："双方应在合同签订后 X 日内共同办理租赁备案登记手续，费用由{出租方/双方}承担。任一方不配合的，应承担由此产生的法律后果" |

### LS-09 附加费用承担未明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🔵 P2 |
| **触发前提**| **始终触发**。附加费用约定不明是租赁纠纷高频争议点 |
| **风险描述**| 合同仅约定租金但未明确物业管理费、水电费、燃气费、停车费、网络费等附加费用的承担方和结算方式，容易在履行中产生争议 |
| **检测方法**| 检查合同是否在租金条款外单独约定附加费用：①列明的费用项目；②各项费用的承担方；③结算方式（实报实销/包含在租金中/按面积分摊） |
| **修改建议**| 增加条款明确各项附加费用的承担方和结算方式，例如："物业管理费由{承担方}承担，水电费按实际使用量由承租方承担并按{月/季}结算" |

## 执行说明

1. **加载条件**：当 §2.1 交易本质解构识别出"物使用权让渡"模块时加载本文件（可与其他类型文件并行加载）
2. **执行顺序**：本文件的 9 条规则与通用规则（risk-library + trap-detection）合并为统一规则集，按 P0→P1→P2 统一排序后一起执行（不再单独置于通用规则之后），重要风险自然前置
3. **去重保障**：本文件所有规则均已与 risk-library（40 条）和 trap-detection（16 条独有）完成去重，不存在重叠
4. **融入清单**：LS 规则命中项与通用规则命中项合并排序（P0 > P1 > P2），共同受 15 条上限约束
