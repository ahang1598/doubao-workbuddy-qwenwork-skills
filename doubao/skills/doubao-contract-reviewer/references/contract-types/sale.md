# 买卖合同专项审查规则

> 本文件仅包含通用规则（risk-library 40 条 + trap-detection 16 条独有规则）**未覆盖**的买卖合同特有风险。
> 识别为买卖合同时由 SKILL.md Step 0 条件加载，非买卖合同不加载本文件。
>
> **编号规则**：SP = Sale-Purchase，编号 SP-01 ~ SP-08。
> **方向化**：所有规则均标注触发前提，严格区分"约束我方"还是"约束对方"。

## 规则详情

### SP-01 货物名称/规格/型号描述不完整

| 字段 | 内容 |
|------|------|
| **优先级**| 🟡 P1 |
| **触发前提**| **始终触发**。货物描述不完整是买卖合同纠纷的首要原因 |
| **风险描述**| 合同未明确货物的名称、规格、型号、数量或计量方式，导致交付标的不确定，双方对"交什么"产生争议 |
| **检测方法**| 检查合同是否明确约定：①货物名称；②规格/型号；③数量；④计量单位/方式。任一缺失即触发 |
| **修改建议**| 在合同标的条款中补充完整的货物描述，建议采用表格形式列明"名称、规格型号、数量、单位、单价" |

### SP-02 质量标准未明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🟡 P1 |
| **触发前提**| **始终触发**。《民法典》第 610 条规定质量要求不明确时按国标/行标/通常标准履行，但实践中极易产生争议 |
| **风险描述**| 合同未约定质量标准（国标/行标/企标/样品标准/封样标准），导致验收时无客观依据，产生质量争议 |
| **检测方法**| 检查合同是否明确引用质量标准文件编号，或约定以样品/封样为准（附样品确认书） |
| **修改建议**| 增加条款："货物质量应符合{国标编号/行标编号/双方确认的样品标准}，供方应提供质量合格证明文件" |

### SP-03 交货地点（风险转移点）未明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| **始终触发**。《民法典》第 604 条规定风险自交付时转移，交货地点决定风险转移节点 |
| **风险描述**| 合同未明确交货地点或交货方式（送货上门/自提/第三方物流），导致运输途中货损风险归属不明 |
| **检测方法**| 检查合同是否明确约定：①交货地点；②交货方式；③运输费用承担方；④运输途中风险承担方 |
| **修改建议**| 明确约定交货地点和方式，例如："卖方负责将货物运至{具体地址}，运输费用由{承担方}承担，货物在{交付节点}前的毁损灭失风险由卖方承担" |

### SP-04 检验期和质量异议期未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**买方**时触发。我方为卖方→不触发（未约定检验期时，依《民法典》第 621 条买方应在合理期间内通知，对卖方更有利） |
| **风险描述**| 合同未约定检验期限和质量异议期，买方可能因超过"合理期间"未提异议而丧失索赔权 |
| **检测方法**| 检查合同是否明确约定：①到货检验期限（如"到货后 X 日内"）；②质量异议提出期限；③异议提出方式（书面/邮件） |
| **修改建议**| 增加条款："买方应在收到货物后 X 个工作日内完成检验，发现质量问题应在检验期内以书面方式通知卖方；质量保证期内发现的隐蔽瑕疵，买方有权在发现后 X 日内提出" |

### SP-05 包装要求未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🔵 P2 |
| **触发前提**| 我方为**买方**时触发。我方为卖方→不触发（包装要求不明确时，卖方有更大自主权） |
| **风险描述**| 合同未约定包装标准和方式，因包装不当导致货物运输途中损坏时责任归属不清 |
| **检测方法**| 检查合同是否约定包装方式、包装标准或包装费用承担 |
| **修改建议**| 增加条款："卖方应按{国标/行业惯例/双方约定}对货物进行包装，确保货物在正常运输条件下不受损坏。因包装不当导致的货损由卖方承担" |

### SP-06 退换货条件未明确

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 我方为**买方**时触发。我方为卖方→不触发（退换货条件不明确时，买方难以主张退换，对卖方有利） |
| **风险描述**| 合同未约定退换货的触发条件、流程和费用承担，买方发现货物不符合要求时无法有效行使退换权 |
| **检测方法**| 检查合同是否约定：①退换货的触发条件（质量不合格/与样品不符等）；②退换货流程和时限；③退换货运费和相关费用承担 |
| **修改建议**| 增加条款："货物经检验不符合质量标准的，买方有权在 X 日内要求退货或换货，退换货运费及相关费用由卖方承担" |

### SP-07 所有权保留条款合规性

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| 合同含有**所有权保留条款**时触发。无所有权保留条款→不触发 |
| **风险描述**| 《民法典》第 641-643 条规定所有权保留需满足特定条件，约定不当可能导致条款无效或无法对抗善意第三人 |
| **检测方法**| 检查所有权保留条款是否明确：①保留条件（如"全款付清前"）；②是否约定了登记（动产需登记才能对抗善意第三人）；③取回权行使条件 |
| **修改建议**| 完善所有权保留条款，明确保留条件和期限，并建议办理所有权保留登记以对抗善意第三人 |

### SP-08 产品责任（缺陷产品致第三方损害）未约定

| 字段 | 内容 |
|------|------|
| **优先级**| 🟠 P1 |
| **触发前提**| **始终触发**。《产品质量法》规定生产者和销售者均承担产品责任，合同约定内部追偿机制可降低风险 |
| **风险描述**| 合同未约定因产品缺陷导致第三方人身/财产损害时的责任分担和追偿机制，一旦发生产品责任事故，双方相互推诿 |
| **检测方法**| 检查合同是否约定：①产品质量担保；②缺陷产品召回责任；③第三方损害的责任分担和追偿 |
| **修改建议**| 增加条款："因货物缺陷导致第三方损害的，由{责任方}承担赔偿责任；一方先行赔付后有权向责任方追偿" |

## 执行说明

1. **加载条件**：当 §2.1 交易本质解构识别出"货物所有权转移"模块时加载本文件（可与其他类型文件并行加载）
2. **执行顺序**：本文件的 8 条规则与通用规则（risk-library + trap-detection）合并为统一规则集，按 P0→P1→P2 统一排序后一起执行（不再单独置于通用规则之后），重要风险自然前置
3. **去重保障**：本文件所有规则均已与 risk-library（40 条）和 trap-detection（16 条独有）完成去重，不存在重叠
4. **融入清单**：SP 规则命中项与通用规则命中项合并排序（P0 > P1 > P2），共同受 15 条上限约束
