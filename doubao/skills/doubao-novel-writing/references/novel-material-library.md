## 使用原则

1. 用户已有明确设定时，以用户设定为主，素材库只做补强。
2. 用户要求“更抓人”“更爆”“更狗血”“更爽”“更下沉”“更有新意”时，可从本素材库抽取变量重组。
3. 不要机械照搬条目；应把题材、人物、关系、冲突、情绪和反转重新组合成适合用户任务的方案或正文。
4. 正文类任务不要把素材分析堆在正文前，正文必须尽早出现在飞书文档中。
5. 本文件不能覆盖 `SKILL.md` 中的飞书文档交付规则、图片规则和正文优先规则。

# 第三部分｜小说素材库扩容版

# 网文小说元素素材库｜男频女频通用扩容版

> 用途：供“网文小说创作 Skill”在生成长篇连载、短篇投稿、开篇、大纲、人设、世界观、金手指、冲突、爽点、情感线、剧情桥段时调用。  
> 核心原则：**先穷举素材，不急着创新；最后再通过组合方式，把常见元素变成新奇、有趣、能服务剧情的故事发动机。**

---

## 0｜使用原则

### 0.1 先穷举，再组合

素材库分两层：

1. **素材层**：人物性格、人物身份、世界观、金手指、冲突、关系、场景、桥段、爽点、虐点、悬念点、男频 / 女频常见题材元素。
2. **组合层**：最后再思考如何把这些元素组合成有反差、有梗、有剧情推动力的设定。

素材层不追求“看起来很怪”，而追求**覆盖面足够全**。创新不发生在罗列阶段，而发生在最后的组合阶段。

### 0.2 什么是有效组合

一个好组合必须能回答：

- 这个设定能不能引发剧情？
- 这个身份能不能反复使用？
- 这个金手指能不能制造误解、反差、打脸或悬念？
- 这个世界观能不能带来持续冲突？
- 这个人物设定能不能推动关系变化？
- 这个梗能不能在前 10 章至少变体出现 3 次？

# 10｜最后一步：组合创新方法

> 前面的所有内容只是“原料”。真正的新奇有趣，发生在组合阶段。

## 10.1 有效组合公式

**题材入口 + 常见身份 + 反差规则 + 稳定误判 + 反复应验 + 持续梗 + 主线用途**

例如：

- 题材入口：豪门
- 常见身份：玄学大师真千金
- 反差规则：豪门全家不信玄学，但她每次预警都应验
- 稳定误判：所有人以为她是乡下骗子
- 反复应验：她说老宅不能住，当晚祠堂出事
- 持续梗：嘴硬长辈每次都躲她身后
- 主线用途：通过玄学事件揭开豪门借命旧案

## 10.2 参考例：玄学大师女主

素材本身并不复杂：玄学大师、豪门、被看不起、风水、鬼怪、家族旧案。关键在于使用方式：

- 一群人瞧不起女主。
- 女主提前判断危险。
- 众人不信，甚至嘲笑。
- 下一秒事情应验。
- 看不起她的人被吓到。
- 家族长辈嘴硬但身体很诚实，躲到女主身后。
- 每次玄学事件都推动豪门旧案、家族秘密或男女主关系。

这个组合的核心是：**身份被剧情反复使用，而不是只在简介里出现。**

## 10.3 参考例：修仙摆烂系统

素材本身也很常见：修仙、系统、摆烂、宗门、废柴、打脸。关键在于把传统逻辑反过来：

- 传统修仙：勤奋修炼，升级打怪。
- 反向规则：越不修炼、越放弃资质，奖励越多。
- 外界误判：所有人以为女主烂泥扶不上墙。
- 持续梗：师尊、师兄师姐都想救她，给她送丹药、剑谱、修炼资源。
- 结果反转：有人看不起她要欺负她，所有爱她的人都替她捏把汗，她轻轻一掌把人打飞。

这个组合的核心是：**全世界都想让她努力，只有她必须不努力；所有人都以为她废，结果她每次都强得离谱。**

# 10.6｜市场调查拆解模板

市场调查不是简单罗列热门作品，而是把公开可核验的参考样本转化为原创写作指导。执行时根据任务复杂度选择快速、标准或深度调查，并优先选择与用户题材、读者情绪和商业目标相近的样本。

### 参考样本拆解维度

- 作品及题材标签
- 公开市场表现或讨论度依据
- 核心卖点与一句话定位
- 开篇冲突和首章钩子
- 主角身份、目标与困境
- 人物关系和关系推进方式
- 爽点、甜点、虐点、燃点、悬念的排列
- 前三章的小闭环
- 前十章的升级或变体机制
- 中长篇连载的故事发动机
- 与同类作品相比的差异化处理
- 可借鉴的写作机制
- 应规避的具体重复风险
- 对当前用户作品的适配建议

### 市场调查输出原则

1. 只能依据公开资料进行分析；“爆款”“热门”“高热度”等判断必须说明来源或改称“公开讨论度较高的参考样本”。
2. 外部事实和引用内容使用 `[[标题]](URL)` 格式在对应句子的句号前引用；没有真实标题和 URL 时不编造来源。
3. 只学习结构、节奏、情绪机制、卖点组织和题材规律，不复制正文、对白、独特人物设定或完整情节。
4. 参考样本必须服务用户的原创方案，最终转化为题材定位、开篇策略、前三章/前十章规划、差异化方向和同质化规避建议。
5. 不能声称模型因为一次检索而永久学习或记住某部作品；本次分析仅基于当前任务检索到的公开资料。

### 不同调查深度

- **快速调查**：1 个相似题材方向、3 条市场启示、3 条可执行建议。
- **标准调查**：1—2 个参考样本、写法拆解、差异化建议、编辑判断、前三章或前十章规划。
- **深度调查**：3—5 个参考样本、来源和时间说明、题材趋势、竞品对比、读者期待、同质化风险、差异化定位、编辑审稿风险和长线连载规划。

# 10.7｜编辑视角分析模板

编辑视角用于模拟网文编辑对商业潜力、投稿表现和连载能力的审阅，不只给泛泛评价，必须尽量落到原文、设定或章节规划，并给出修改动作。

### 编辑重点关注要素

- 题材和市场标签是否清晰
- 目标读者是否明确
- 一句话卖点是否成立
- 核心设定是否能够持续制造剧情
- 前 100 字、前 500 字和第一章是否尽快出现人物、事件、冲突和继续阅读理由
- 主角是否有明确目标、具体困境、主动行为和可识别人格
- 爽点、甜点、虐点、燃点、悬念是否及时
- 情绪回报是否与铺垫匹配
- 人物关系是否有张力
- 感情线、事业线、复仇线或升级线是否互相推动
- 前三章是否形成小闭环
- 前十章是否能够持续升级或产生有效变体
- 长篇是否具备连载扩展性
- 作品与同类相比的真正差异点是什么
- 哪个卖点应放入简介、导语和开篇
- 是否存在读者流失、编辑退稿或中段疲软风险

### 编辑视角输出要求

- 先给出编辑第一判断：题材定位、市场潜力和最大问题。
- 再分别分析题材、卖点、开篇、人物、关系、节奏、连载和差异化。
- 每个问题都尽量对应具体文本或设定，并说明为什么影响阅读或投稿。
- 每条意见都配一个可执行的修改方向，必要时给出原创示例思路。
- 最后给出“这篇作品想脱颖而出，应优先强化的 3—5 个动作”。

# 11｜组合自检清单

主 Skill 每次生成设定时，最后必须检查：

1. 这个设定是否只停留在简介里？
2. 这个身份能不能反复制造剧情？
3. 有没有稳定误判？
4. 有没有反复应验？
5. 有没有持续梗？
6. 有没有推动主线？
7. 有没有明确爽点、甜点、虐点、燃点或悬念点？
8. 这个组合是否服务人物关系变化？
9. 男频是否有升级、资源、势力、战斗、格局扩张？
10. 女频是否有情绪、关系、身份、处境、选择变化？
11. 是否避免了“硬凹怪概念”？
12. 是否做到“常见元素，新鲜用法”？

# 12｜一句话原则

**素材阶段要尽量全，组合阶段才追求巧。**

不要为了创新而创造奇怪概念，而是从市面常见人物、身份、金手指、世界观、冲突和桥段中选料，再通过“反差规则、稳定误判、反复应验、持续梗、主线用途”组合成真正能开篇、能连载、能制造追读的网文设定。
