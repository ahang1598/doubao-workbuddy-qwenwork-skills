# C / C++ 适配

- 从构建配置、语言标准、测试 target、头文件关系和邻近测试确认框架与注册方式。
- 把测试注册到现有 target；通过公开行为验证实现，并只在已有接口边界使用替身。
- 从契约选择空指针、空容器、整数边界、错误码、异常和所有权转移；终止契约才使用 death test。
- 指针、buffer 或输出参数先放入可识别值，再断言失败时保持、清零或写入的约定。
- 契约要求同一异常对象时，不得用类型、值或 `what()` 代替身份。捕获实际异常对象、记录地址并裸重抛，再在调用方比较地址：

```cpp
const void* thrown = nullptr;
try {
  call([&] { try { throw Sentinel{}; }
    catch (const Sentinel& e) { thrown = &e; throw; } });
} catch (const Sentinel& e) { CHECK(&e == thrown); }
```

- 身份探针编译失败或崩溃时修复见证器和生命周期，不得降级成消息断言；将裸重抛替换为同类型、同消息的新异常时，该探针必须 RED。
- 使用 RAII 管理文件、句柄、内存和线程；每个用例恢复 fixture，并在结束前 join 或释放资源。
- 资源生命周期用一次调用的 trace 取证：在成功轨迹内同时断言结果、顺序和清理次数，在失败轨迹内同时断言异常身份、顺序和清理次数；不要把同一调用的“恰好清理一次”另拆成重复用例。
- 反例保持在已定义行为内；sanitizer 只沿用项目配置或用户要求。
- 在仓库外构建，先运行最小 target，再运行相关 suite，并确认测试已注册且执行数非零。
