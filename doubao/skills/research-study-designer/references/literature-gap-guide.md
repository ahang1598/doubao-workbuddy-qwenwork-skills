## 1. 从研究问题到检索概念

先把问题拆成检索块：

| 检索块 | 内容 | 示例形式 |
|---|---|---|
| 核心构念 | IV、DV、中介、调节 | 正式术语 + 常见同义词 |
| 理论 | 理论名称、关键机制 | 全称 + 缩写 + 发源作者 |
| 总体 | 年龄、职业、组织或用户群 | population 词 |
| 情境 | 国家、平台、组织、事件 | context 词 |
| 方法 | experiment、survey、meta-analysis | 用于定向补检 |

不要一开始把所有词用 AND 串联，以免过度收窄。先用核心构念建立基线，再逐步加入理论、总体和情境。

### 1.1 同义词表

为每个核心构念记录：

- 英文规范名称；
- 中文名称；
- 缩写；
- 邻近但不等价的概念；
- 排除词；
- 领域特定表达。

邻近概念不能无说明地混为同一构念。若构念定义存在争议，将定义差异本身纳入文献矩阵。

### 1.2 查询式结构

通用结构：

```text
("X term" OR synonym*) AND ("Y term" OR synonym*)
```

机制补检：

```text
("X term") AND ("mechanism term" OR mediation) AND ("Y term")
```

理论补检：

```text
("theory full name" OR abbreviation) AND (construct OR context)
```

证据层级补检：

```text
(constructs) AND (meta-analysis OR systematic review OR experiment)
```

记录实际运行的查询式、数据库/搜索工具、日期、过滤条件与返回范围。

## 2. 检索与筛选

### 2.1 检索顺序

1. 查找高相关综述或元分析，建立术语和关键作者图谱。
2. 追溯理论发源或构念定义文献。
3. 查找直接检验核心关系的原始研究。
4. 查找近年更新、冲突结果、不同情境和不同方法。
5. 对关键文献执行前向/后向追踪。

“高被引”与“近年”是筛选信号，不是绝对质量保证。优先级取决于与研究问题的直接相关性、方法透明度和证据功能。

### 2.2 纳入/排除标准

在筛选前写明：

- 主题相关性；
- 研究总体与情境；
- 文献类型；
- 年份与语言范围；
- 方法要求；
- 是否需要同行评议；
- 重复样本或重复报告处理方式。

排除时记录主要理由，例如概念不匹配、仅评论文章、无目标关系、样本重复或元数据不可核验。

### 2.3 目标数量

默认目标是 10 篇高相关核心文献，而不是只返回搜索前十条。若直接证据不足：

- 扩展同义词和上位/下位概念；
- 减少过窄情境限制；
- 加入理论、机制或方法词；
- 查引用链；
- 报告真实数量和不足原因。

不得用低相关文献凑满十篇。

### 2.4 元数据核验

至少从可访问来源核对作者、年份、题名、出版源和 DOI/链接。不同来源冲突时，优先出版方或 DOI 注册元数据，并标记冲突。不要根据 URL 或搜索摘要猜测缺失字段。

## 3. 文献证据矩阵

每篇文献建议记录：

| 字段 | 说明 |
|---|---|
| ID | L01、L02…… |
| 完整引用 | 作者、年份、题名、出版源 |
| DOI/链接 | 可访问定位 |
| 可得状态 | 全文/摘要/仅元数据 |
| 研究问题 | 作者实际研究的问题 |
| 理论 | 使用或检验的理论 |
| 样本/情境 | 人群、地区、平台、时间 |
| 方法 | 设计、测量、识别策略 |
| 主要发现 | 仅写来源可见内容 |
| 作者自述贡献 | 与自己的推断分开 |
| 作者自述局限 | 标注所在章节/页码（如可得） |
| 相关性 | 对当前问题的证据功能 |

只有摘要时，不填写需要正文才能确认的操作化细节、作者局限或稳健性分析。

### 3.1 横向综合表

按以下维度比较：

- 结论方向是否一致；
- 构念定义和操作化是否一致；
- 总体与情境是否集中；
- 设计是否普遍为横断面或自陈；
- 机制和边界是否被直接检验；
- 统计识别和测量质量是否限制结论；
- 哪些证据是重复，哪些是互补。

综合不只是十条摘要拼接，应明确共识、冲突和证据薄弱点。

## 4. 深度理论分析

当用户指定理论或 gap 涉及理论扩展时，执行四步：

### 4.1 理论发源

定位理论的原始提出、核心构念、作用机制、边界假设和适用层级。区分后续研究的常见简化与原始主张。

### 4.2 高质量实证

查找直接检验核心命题的研究，比较样本、情境、设计和结果。优先能区分竞争解释的证据。

### 4.3 综述与元分析

查找系统综述/元分析对平均效应、异质性、发表偏倚和调节因素的评价。没有元分析时明确说明，不自行生成“元分析结论”。

### 4.4 三方对应

| 理论主张 | 原始实证结果 | 综述/元分析结论 | 未解释差异 | 可检验扩展 |
|---|---|---|---|---|
| 命题与边界 | 样本、方法、方向 | 平均效应与异质性 | 机制/情境/测量 | 新假设与设计 |

理论扩展必须改变解释力、边界或机制，不能只是把旧模型换到新样本。

## 5. 七类 Gap

### 5.1 未检验命题

理论明确提出命题，但现有实证未直接检验。需要证明“理论提出了什么”和“检索范围内哪些研究未检验”，不能只因自己没看到就断言。

### 5.2 结果矛盾

不同研究结果方向、大小或显著性不同。先检查构念、样本、设计和统计功效差异，再提出能解释异质性的边界或机制。

### 5.3 边界条件

效应可能因人群、情境、时间、文化或变量水平而变化。边界变量需要理论理由，不能仅做任意分组探索。

### 5.4 机制缺失

已知 X 与 Y 相关，但中间过程未被直接测量或操纵。机制研究应区分中介的时间顺序和竞争机制。

### 5.5 情境局限

证据集中于狭窄情境。新情境只有在可能改变理论过程、效应边界或实践含义时才构成贡献。

### 5.6 方法局限

共同方法偏差、横断面设计、自陈测量、样本选择、操纵弱或识别不足限制结论。新方法应直接修补该限制。

### 5.7 理论扩展

引入新机制、边界或层级，使理论解释新的可观察现象。仅增加变量或复制关系不自动构成理论贡献。

## 6. Gap 论证模板

对每个候选 gap 填写：

| 项目 | 内容 |
|---|---|
| Gap 类型 | 七类之一 |
| 已知证据 | 文献 ID 与可核验结论 |
| 缺失内容 | 具体机制/总体/情境/方法/命题 |
| 为什么重要 | 理论或实践后果 |
| 排除替代解释 | 为什么不是检索遗漏或概念差异 |
| 可检验问题 | 可操作化的研究问题/假设 |
| 所需设计 | 能真正填补 gap 的方法 |
| 证据强度 | 高/中/低及理由 |

推荐句式：

> 现有证据在【范围】中较一致地支持【已知结论】（L01、L03），但由于【具体方法/总体/机制限制】，尚不能判断【明确未决问题】。因此，本研究将通过【设计特征】检验【可检验命题】。

证据不足时改写：

> 本次检索发现一个候选 gap，但仍需用【数据库/查询式/全文】验证，当前不作为确定贡献声明。

## 7. 常见错误

- 以“尚无研究”“首次”作绝对声明，却没有系统检索证据。
- 把论文未提及某变量直接当成理论 gap。
- 把新国家、新平台或新人群自动当成贡献。
- 从摘要推断作者未报告的局限或分析。
- 用影响因子、分区或引用量替代相关性与方法质量。
- 混淆“未显著”和“无效应”。
- 把相关研究当作因果证据。
- 只列十篇文献，不做横向综合。
- Gap 与后续设计不对应。

## 8. 阶段交付与门禁

交付物：

1. 研究问题确认表；
2. 中英文概念表与实际查询式；
3. 纳入/排除标准；
4. 可核验文献表；
5. 逐篇证据矩阵；
6. 横向综合；
7. Gap—证据映射；
8. 候选 gap 的证据强度与待核验项。

进入方法选择前检查：

- [ ] 所有引用均可定位。
- [ ] 全文与摘要分析已区分。
- [ ] 作者陈述与综合推断已区分。
- [ ] 每个 gap 至少绑定具体文献证据。
- [ ] Gap 被转化为可检验问题。
- [ ] 未使用绝对“首次/无人研究”而无系统依据。
- [ ] 不足十篇时已说明真实数量与扩展检索过程。
