# 影像指导：图从哪来、怎么下单、怎么进稿

低质稿的图片问题**在生图之前就发生了**。Step 4 备料前读完本文，然后一次把全稿的图单列出来。

---

## 一、图源优先级（按**这张图要证明什么**分流，不按工具分档）

**先问这张图承担什么，再决定它从哪来。** 三档，从上往下取第一个成立的。

**第 1 档 · 身份证据**——真实品牌标志、真实产品、真实空间/门店、真人、真实包装与设备。
> **用户附件 / 官方素材 > 检索到的真实对象图**。用户给的**不许裁切**（可缩放适配版面）。
> **生成图不能替**：它画出来的是"像那一类东西"，不是那一个东西。
> 对象被点名却 0 张真图进稿时，**交付语里说明原因**——不许拿更漂亮的生成图冒充真实对象。

**第 2 档 · 氛围 / 概念 / 封面主视觉 / 没有身份的场景**——这一档**生图与"电影海报级"检索图同级**，
谁的质量高用谁；有真实素材可用时优先用真实素材，没有就生。
> **"电影海报级"是可判的**：单一光源方向明确、主体与背景分得开、有景深或有戏剧性、
> 没有图库均值感（居中摆拍＋平光＋万能虚化）、没有可读文字与水印、没有拼贴边缘。
> 达不到这条线的检索结果**不算第 2 档**，落到第 3 档。

**第 3 档 · 兜底检索**——前两档都不成立时才用，且要在交付语里说明这一张是兜底来的。

**任何图片进稿的三个门槛**（检索、生成、用户附件里截下来的都一样）：分辨率 ≥ 图窗有效像素的 2 倍、
画面里没有资料文字、源图/图窗比例差 ≤10%。否则只当调研材料；anchor 只选边，不豁免幅度。
附件整页截图尤其要查页眉、图注、气泡和拼接边；它是资料，不是满版画面。满版图会由每页 `check --slide`
自动分诊，再由宿主截图的 LOOK-24 核对边缘与画内文字。

✗ **不许用矩形／线拼出"图片该在的位置"**——那是线框图不是画面。
没有合格的图时**换承载**（信息图形／原生图表／巨字／清单，`page-craft.md` §二），不要拿形状冒充画面。

## 二、两种失败模式（认得出来才躲得开）

**失败一 · 内容描述式 prompt**：没有镜头、光线方向、色彩世界、构图留白，模型只能回吐图库均值。
> ✗ 「四款奶茶并排展示，透明杯，木质桌面，自然光线，清新风格，高品质商业摄影」

**失败二 · 统一后缀退化成同一张照片**（更隐蔽、更致命）：写了统一后缀并逐字追加到每条 prompt，
结果整组图全是「产品居中摆木桌上、暖光左上斜射、浅景深虚化」——后缀统一了，但每条只换了主体名词。

> **统一后缀负责"看起来是一个世界"，变量矩阵负责"每张都是新的一眼"。缺一半都出不了编辑级。**

尤其**不要把打光写死进统一后缀**：低饱和＋低对比＋平光三连会把全稿拉平成寡淡的一张脸。

---

## 三、先立影像世界（一次，全稿共享）

生成第一张图之前，把这几件事冻结下来（写在思考里即可）：

**主体关系 · 材料 · 光线 · 镜头语言 · 色彩与后期质感**。

按设计系统家族挑打光与色调，别用同一套：

| 家族气质 | 光位与质感 | prompt 里怎么写 |
| --- | --- | --- |
| 东方 / 文化 / 器物 | 侧窗漫射 ＋ 晨雾 ＋ 大留白 | `soft diffused window light from the side`、`morning haze`、`low saturation ink tones` |
| 硬科技 / 装备 / 运动 | 暗场 ＋ 单一方向硬光 ＋ 轮廓光 | `single hard light from <方向>`、`rim light traces the subject edge`、`background falls to near-black`、`volumetric haze` |
| 暖土 / 食物 / 手作 | 顶侧暖光 ＋ 蒸汽颗粒 ＋ 暗调静物 | `warm top-side light`、`steam and fine grain`、`dark moody still life` |
| 商务 / 平台 / 现代零售 | 明亮通透自然光 ＋ 干净景深 | `bright airy daylight`、`clean shallow depth of field`、`real workspace` |
| 时尚 / 潮流 / IP | 直闪硬光 ＋ 高对比 ＋ 动作瞬间 | `direct on-camera flash`、`high contrast`、`caught mid-action`、`saturated backdrop` |

## 四、五段式 prompt（每条都写满这五段）

```text
① 主体：是什么、什么状态、什么动作（具体到可画）
② 场域与关系：在哪、和什么发生关系、周围有什么
③ 镜头：景别（特写/中景/全景）＋ 机位（平视/俯 15°/仰 10°）＋ 焦段感（50mm/85mm/广角）
④ 光与色：光位方向、光质、色温、后期质感（＝影像世界那一套）
⑤ 画面纪律：留白位置、构图要求、禁令
```

**第 ⑤ 段的固定禁令**（逐字带上）：
`no text, no numbers, no logos, no watermarks, no captions`。
生图工具画不出可读的正确文字，写了就是一堆假字母压在画面上（「PPT 套 PPT」）——
**屏幕、店招、包装面上要有内容时，写「面上是什么材质/什么图形」，不要写要显示什么字**。

## 五、变量矩阵（组图时逐张换，至少换两项）

| 维度 | 可选值 |
| --- | --- |
| 景别 | 特写 / 中近景 / 中景 / 全景 / 大远景 |
| 机位 | 平视 / 略俯 15° / 俯拍 / 略仰 10° / 低角度 |
| 主体占高 | 30% / 45% / 62% / 80% |
| 被摄关系 | 单主体 / 主体＋环境 / 手部动作 / 群像 / 空景 |
| 光位 | 侧窗 / 逆光 / 顶光 / 单点暗调 / 阴天均匀 |

同一组图里**不许两张的景别＋机位完全一样**。

**第六个维度 · 同一主题的复现**：同一主题可以再拍，同一主体画面默认只承担一页；纹理／氛围底板按角色另计。用户明确要求复用时，每个使用页都写同一个 `reuse=user:<用户要求>`。复现时——

| 换什么 | 可选值 |
| --- | --- |
| 画幅 | 满版 / 半版贴边 / 窄条带 / 缩略 |
| 裁切锚点 | 仅在源图/图窗比例差 ≤10% 时用 `top/bottom/left/right` 选择保哪侧 |
| 它这一页承担什么 | 主视觉 / 佐证 / 材质 / 节奏换气 |

**换画幅＝按新比例重生/重检索同题材**，不是硬裁同一资产；这样仍有编辑连续性。
✗ 但相邻两页都只靠这一张图、同侧贴边且画幅近似，即使宽度略变也仍是同一主视觉重复。

## 六、画幅：图窗尺寸决定下单的那两个数

**下单尺寸不是随手写的，是图窗几何换算出来的。** 画布 960×540，换算规则：

```text
目标比 = 图窗宽 / 图窗高
短边取 1024–1536，长边 = 短边 × 比例，两个数都取 8 的倍数
```

| 图窗形态 | 常用下单尺寸 |
| --- | --- |
| 满版 / 满宽横图（960×540、960×300） | `width=2048 height=1152`（16:9）／`width=2048 height=640`（超宽） |
| 半版竖图贴边（约 440×540） | `width=1248 height=1536`／`width=1536 height=2048` |
| 竖条切片（约 170×400） | `width=1024 height=2048` |
| 方形（图形符号、材质、头像） | `width=1536 height=1536` |
| 卡片内横图（约 420×240） | `width=1792 height=1024` |

**画幅配比**：单一画幅占比 >70% 是「排版重复」的直接成因。目标 横 30% / 竖 25% / 方 20% / 超宽 9%，其余按需。
全是横图就组不成拼贴、做不了竖条带、无法满版出血，全稿退化成「一页一图、张张同比例」。

**画幅不对不要靠裁切救**：源图/图窗比例差 >10% 就不得进稿。重写 prompt、带新画幅重新生成或重新检索——尤其有人物时（脸和肢体切了就废了）。

---

## 七、融地：让图和页面地色长在一起

**地是设计实色时**（`page-craft.md` §一 里 L0 的第 1 种），每条生图 prompt 末尾加一句：

```text
background is a seamless <地色描述> backdrop, subject floats on it, edge-to-edge uniform color
```

这样图放上页面时**看不出图框边界**，整页像一张连续的画——顶级参考稿的「满版感」正是这么来的，
它们一张 slide 级底图都没用，靠的全是选图/生图时就让图底＝页地。

**检索图**同理：优先挑背景色接近页地的那张；挑不到就走去底（§九）或给它一个正当的相纸边框（page-craft D4/D11）。

---

## 八、地的订单工艺（按 `page-craft.md` §一 L0 的方案分小节）

「地」是哪一种由设计系统卡定，这一节只管**每一种怎么下单**。
七种方案里，A（设计实色地）不生图（见 §七 融地），E（色域拼接）由版面切分决定、
影像部分按 C/D 下单；下面写要生图的那几种。

### 八·1 满版影像地（C，有主体）／满版氛围底图（D，无主体）

**两种常见下法，下单时就要选定并写死：**

**①a 靠画面自身承文（参考稿七成走这条）**
> prompt 里写：`the <左/右/上/下> portion of the frame is a naturally quiet surface (plain wall / sky / ground / out-of-focus depth), evenly lit`
> **同时写死禁令**：`no cards, no panels, no frames, no overlay, no darkened patch —— the whole image is a clean continuous photograph`
> 那片安静区的坐标只有图知道 → 落盘后跑 `deck.py ground --image <图>` 量出来再排字。
> 图单同时记 `空面=<左/右/上/下>`；这是 E-b（满版图再盖一侧）成立的前提，没下过这条订单就改用 E-a 侧图窗。

**①b 图里铺一片承文面**（全稿最多 1–2 页，通常是首页/末页）
> prompt 里写：`a large calm color field occupies the <位置> of the frame, its four edges inset from the picture edge, no perspective distortion`
> 文字整叠放进那块形里，**零形状，不要在它上面再叠东西**。
> 那片形要**占住一侧**（占一整边，文字整叠落进去）——这时它与画面之间那条边是**设计**，不是缺陷。
> ✗ 不要在画面**中间**横切一条通宽带、两侧都放内容：读者不知道该看哪边。

**①c 满版承文（不留任何空面）**
> 整张图从头到尾都是画面，文字落进**它自己的暗部或虚化景深**；
> 需要时再叠一层覆盖**整页**的通幅调性层（方案 F，`page-craft.md` §一 L0）。
> prompt 里写：`the <位置> of the frame falls into deep shadow / soft out-of-focus depth`，
> 不写"留一片干净平面"。参照库里全稿 100% 满版的那两份走的就是这一条。

**三种都不是**「留一片纯净平面」——那生出来是一片死白。

> **①a 是有代价的**：prompt 里写死"某一侧三分之一是干净承文面"，
> **这张图从生出来那一刻就只能当半版图用**，满版铺上去会有一大块空。
> **一稿里 ①a 最多用 2–3 页**；整组图都这么写，全稿会长成同一张脸。

**两种都不成立时**（画面从头到尾都是内容，量不出安静区）：**不要硬排**，
按 `page-craft.md` §四 承文阶梯往下走——第 3 档是**重新生成这一页的底图**
（prompt 写明"给文字留一片低细节区/暗部，画面上无任何覆盖物"），
再往下才是通幅渐变、整页压暗罩（方案 F）、贴页缘小压字带。
**重做优先于叠东西**：它多花一次生图，省下一个永远修不好的页面。

**氛围底图（D）同样可以跨页复用，而且它比纹理更能定气质。**
一张**无主体、有光位、有纵深**的底图铺 6–10 页是成文做法（参照库里有一份 19 页的稿这么做，
其中一张铺了 10 页，全稿的深场气质就是它给的）。下单时写：
> `an empty <场域> with a single directional light raking across it, depth and falloff, no subject,
> the <位置> half falls into shadow`，加常规禁令。
落盘后跑**不带 `--as-texture`** 的 `ground --image <图>`，它会直接说这张图适合当哪一种地。

**纹理地与氛围底图的分界**（下单前就要选定，两支的合格线不一样）：

| | 纹理地（B） | 氛围底图（D） |
| --- | --- | --- |
| 图里有什么 | 只有质感：纤维、织纹、格纹、点阵、微噪 | 有光位、有纵深、有空间，但**没有主体** |
| 安静区 | **≥85%**（近纯色），`--as-texture` 判 | **40–85% 就成立**，不带 flag 的 `ground` 判 |
| 字往哪落 | 任何位置 | 落进它自己的低信息区（`ground` 会给坐标） |
| 它给这一稿什么 | 一层统一的底，不抢内容 | **整稿的明度带与气质** |
| 走错的代价 | 拿氛围底图去跑 `--as-texture` 会被判不合格——**那不是它的门**，去掉 flag 重跑 | 拿纹理当氛围底图，全稿会寡淡 |

### 八·2 纹理／材质地（B）

跨页复用一张就能撑起全稿，所以一张不合格会把整稿一起拖下去。**它与满版底图是两件事：**

| | 满版影像/氛围地 | 纹理地 |
| --- | --- | --- |
| 它是什么 | 这一页的**画面**：有主体或有场域、有景深 | 一层**近纯色**的底，没有主体、没有焦点 |
| 下单要写 | 主体、场域、镜头、光色、留白位置 | **只写材质与颜色**，写死「极浅」「中间不许有缝」 |
| 承文 | 按承文阶梯（`page-craft` §四） | 字可以落在**任何位置**——这正是它存在的理由 |
| 中间有分界线 | **不判**：占住一侧的承文面是成文做法 | **不合格**：它要复用到很多页，一条缝会把每一页都框死 |

三条硬要求，逐字写进订单：

1. 纹理只做质感，不做图案主角。**图案本身不禁**——点阵、格纹、笔触、纤维都成立，
   禁的是「重」：**同一个图案，配色浅一档就从不合格变合格**。
   判据是落盘后 `--as-texture` 的那两个数，不是图案的名字：
   安静区要覆盖几乎整张图，局部明度极差中位压到个位数到十几
   （真稿的纹理地 4–10；浅色点阵实测 17 合格，中调 33、高对比 152 不合格）。
   要材质就写材质：`fine paper fibre`、`woven linen`、`brushed matte surface`、`soft plaster`；
   要图案就写**浅**：`barely visible <图案> in a tone one step from the base colour`。
   ✗ 纹理地里不许出现能被认出来的东西（具体物件、文字、标志）。
2. `no seam, no fold, no split, no colour break across the middle of the frame — one continuous surface`
   ——**管的是中间**。贴着画幅四周的细边框、压边、暗角**是允许的**（它们不切版面）；
   中间的一条缝会把每一页的排版都框死。
3. 常规禁令 `no text, no numbers, no logos, no watermarks, no captions`。

**落盘后必须验，不合格就重新生成**：

```
python3 "$SKILL_ROOT/scripts/deck.py" ground --image assets/<纹理>.jpg --as-texture
```

**通过之前不许用在任何一页上。** 纹理地要和这一档的世界同源——
亮色档的浅点阵/格纹、纸感档的纤维、深场档的微噪都成立；
**照搬别档的纸纹是不同题材的稿子长成同一张脸的来源之一**。

### 八·3 整页预合成图（G）

底纹层 ＋ 主体 ＋ 图形件（笔触/色带/纸片）**在生图那一刻合成为一张图**——
宿主产不出透明底 PNG，叠层只能这样做，不是事后贴三张图上去。
prompt 逐字带上底纹的材质与颜色、主体的位置与占比、图形件的形状与走向，
并写死 `one continuous illustration, no separate layers, no cut-out edges`。

## 九、主体与底的物理关系（宿主的硬事实）

**这条产线产不出透明底 PNG，「贴」这个动作不存在。** 因此：

1. **主体要出场就一体生成**：主体＋底纹＋装置合成一张无字底图，prompt 逐字带
   `subject integrated naturally with the background`。
2. **图像件要么满版/出血，要么落在实色托底上**：不贴页边、面积又小、又没有底色卡片的图像件，
   渲染出来就是一块悬空矩形。
3. **符号、角标、母题小件用原生 `<shape>`／文字块**，不要用图片做。

**落地效果页的图从哪来**（物料／门店／界面／包装／产品这一类：对象是真的，画面还不存在）：

| 情况 | 走哪条 |
| --- | --- |
| 这件东西已经存在（在售产品、已开的店、已印的物料） | **检索真实照片**，按 §一 的三个门槛筛 |
| 这件东西还不存在（新设计的物料、未开的店、概念界面） | **按真实视觉基因生成高保真样机图**：材质、光线、场景一体生成，画幅按 §六 换算 |
| 页面讲的是**规范本身**（组件结构、网格、间距、色彩用法） | 原生 `<shape>` 画的图解成立——那时矩形证明的正是「规则长这样」 |

✗ **不要用矩形拼出「东西的样子」当画面**：无字矩形摞出的手机框／名片／招牌是**线框图**，
它只能证明「这里大概会有一个界面」。判据一句话：**把页面上所有文字删掉之后，
读者还能看出这是哪个对象的什么东西吗？** 看不出来就换真实素材或高保真图。
生成样机时仍守第 ④⑤ 段：面上写**什么材质、什么图形**，不写要显示什么字，末尾带无文字禁令。

**去底**：检索来的图带纯色底（黑白灰底必抠）→ 用 Python PIL 的 `ImageDraw.floodfill()` 抠掉，
结果另存新 PNG（不覆盖原图、不存 JPG）。渐变底和复杂背景**不硬抠**。抠完逐张看：
背景真透明了吗？主体边缘有没有残留色块？主体内部有没有被误抠？**抠坏就回退用原图。**
