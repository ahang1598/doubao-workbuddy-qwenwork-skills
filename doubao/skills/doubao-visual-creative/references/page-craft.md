# 构页工艺：一页是怎么长出来的

本文是**设计语言**，不是模板：给你构页的层、可选的装置、六条纪律；
**具体几何、具体内容、每页选哪个装置由你决定**。Step 3 策划前读完，写页时随取随用。
画布恒为 **960×540**（16:9），下文坐标与尺寸都按这个画布说。

---

## 一、五层构页法（每页自下而上想一遍，缺层就是平庸的来源）

| 层 | 是什么 | 判据 |
| --- | --- | --- |
| **L0 地** | 这一页的底：见下面的**地的方案库**（七种，可叠） | 全稿的地要成套。**纯平色地必须靠巨字或大画幅影像撑住** |
| **L1 图形层** | 幽灵巨字（120–400pt，6–12% 不透明度）、放大出血的符号、整块色域分割 | 不是每页都有；章节页与视觉页的主武器 |
| **L2 影像层** | 本页的 1–6 张图 | 每张说得出「服务本页哪一句」。多图时**主图 ≥ 最小图的 2.5 倍**，共享对齐轴，间距 12–20px。主体画面默认只用一页；纹理／氛围底板与 `reuse=user:` 另计（§3.3） |
| **L3 文字层** | 标题（定字号与断行）、正文（定栏宽与行距）、双语配对、竖排 | 竖排写成「窄栏 + 每行一个汉字」，不依赖宿主竖排 |
| **L4 家具层** | 全稿固定 3–5 件微装饰 | 每件**固定位置、固定字号、全稿一致**。缺失或逐页漂移＝「生成的」而不是「设计过的」 |

### L0 · 地的方案库（先定这一稿用哪几种，再逐页填）

**这一稿用哪几种地，由 Step 2 的坐标定**；这里给的是方案空间与代价。
一稿通常只用 **1–3 种**，靠轮换换气——不是每页各来一种，也不是全稿只有一种。

| 方案 | 是什么 | 什么时候成立 | 代价／注意 |
| --- | --- | --- | --- |
| **A 设计实色地** | 1–2 块设计色承全稿，两色交替换气 | 编辑体例、观点稿、规范稿；地就是品牌 | **纯平色地必须靠巨字或大画幅影像撑住**，否则就是空。图要「融地」（`image-direction.md` §七） |
| **B 纹理／材质地** | 近纯色 ＋ 一层质感（纤维、织纹、格纹、点阵、微噪） | 要一层统一的底又不想纯平 | **纹理一重小字就读不清**；复用前必须单独验。✗ 照搬别档的纸纹＝不同题材长成同一张脸 |
| **C 满版影像地（有主体）** | 整页一张图，有清晰的主体与焦点 | 封面、末页、要读者「进到场景里」的页 | 承文按 §四 阶梯——**不假设它一定有安静区**，量不到就重做底图 |
| **D 满版氛围底图（无主体）** | 整页一张图，只有光、材质与空间，没有主角 | 深场、精密、克制；要纵深又不想让画面抢内容 | **和纹理地一样能一张铺 6–10 页**，且比纹理更能定气质；字落在哪里同样要量 |
| **E 色域拼接／对开** | 切成 2–3 个大色域 | 章节页、对照页、封面 | **E-a（默认）**：页地 `fillColor`，图收成贴一侧三边的窗，**图窗多宽就按多宽下单**。**E-b**：满版图＋实色盖一侧，只在下单已写死空面、主体完整落在露出侧时成立；页头写 `cover=<被盖侧是什么空面>`。✗ 先按满版下单再盖掉一半，等于**扔掉一半画幅预算** |
| **F 满版影像 ＋ 通幅调性层** | 一层覆盖**整页**的半透明色，把画面压成能承文的地 | 画面从头到尾都是内容、找不出安静区 | **整页一层**，不是局部板（局部板会切一刀，§四） |
| **G 整页预合成图** | 底纹＋主体＋图形件在**生图那一刻**合成为一张 | 主体要贯穿版面、与巨字咬合的封面与章节页 | 宿主产不出透明底，**叠层只能在生图时完成** |

> **B / C / D / G 在 XML 上是同一行代码**：`<slide><style><fill><fillImg src="…"/></fill></style>`（`slides-xml.md` §二 第③条）。
> **差别只在那张图里装的是什么**——一层纸纹、一个有主体的场景、一片有光有纵深的空场、还是一张预合成图。
> 满版画面不比纹理地贵，别因为"以为要另铺一张 `<img>`"就退回纹理。

> **E-a 与 E-b 的差别不在几何，在图是否为那条缝生的。** E-a 图 100% 可见；E-b 被盖侧不可见，只适合那里本来就是空墙／天空／虚化地的订单。主体居中或横贯画幅时，板会切主体；这件事只有图单知道，不能靠面积阈值猜。具体选择按本页实际画面调整。

> **地可以是一层，也可以是叠出来的。** 封面、章节页、氛围页最值得叠成 2–3 层：
> **底纹层**（最淡）＋**场景/面板层**＋**光影层**——上表的 G 就是这件事落到宿主上的做法。

**七种是下限。** 常用配法：一主一副（统一底＋3–5 页满版换气）／两实色交替（靠巨字与留白撑）／满版到底（光影即纹理）。**最高频的地就是这一稿的脸**。

**满版底图（C/D/F/G）落盘后要量一次**：`deck.py ground --image <图>` 给出安静区、结构线禁区、主体区，
**以及这张图适合当哪一种地**；`check --slide` 排完字之后复核。**没量过就不要在满版图上排字**。
字往哪儿落见 **§四 承文阶梯**。

**纹理地盖住的地方仍然是空的**；也不要给地设全局配比——参照库从 100% 图地到过半纯平色都成立。

### L4 家具四件套（编辑级出品的分水岭，一稿定一套、页页复现）

- **眉行**：`NN — 全大写宽字距标签`＋一条短强调色线；对侧放 `页码 NN/NN`。
- **页脚轨**：一条发丝线 ＋ 跨页口号/卷号 ＋ **资料来源行**（涉及外部数据的页必写来源）。
- **图注**：每张内容图贴底沿一行小字：内容＋出处（例 `FIG.04 — 立面细部 · 摄于午后`）。
- **母题小件**：一稿一件（方块／三连圆点／胶带条／印章块／角标），页页同位复现。

## 二、版式装置库（每页选一个；同章可共用，跨章要换）

**画面主导**

| 装置 | 构图机制 |
| --- | --- |
| **D1 满版影像＋巨字** | 整页一张图，标题落图自身安静区，零形状。封面/章节页/换气页的主力 |
| **D2 半版竖图贴边** | 图占 40–56% 贴一侧三边（不留缝），另一半是地色，**该页压在图上的填充形状＝0** |
| **D3 上图带＋下多栏** | 上 50–60% 满宽图，下半是地色上的 3–4 栏编号词条，栏间竖发丝线 |
| **D4 多图编辑拼贴** | 3–6 张不同裁切比例（竖条/方/横幅）错落，1–2 张贴边出血，共享对齐轴 |
| **D5 竖条切片带** | 3–6 条等高竖图并排（材质/细节/原料），条间 8–14px，每条配 9–11pt 条目名。**同一张图裁成几条也成立** |
| **D6 组图带语义顶线** | 并排图各配一条 2px 强调色顶线，线的颜色承担语义（分类/阶段/色域） |

**文字主导**

| 装置 | 构图机制 |
| --- | --- |
| **D7 巨号章节页** | 超大编号（120–220pt）＋章节名＋一张代表图或整块色域；各章节页共享骨架、轮换图与明暗 |
| **D8 宣言页** | 一句 ≤20 字的话占据版心，四周成片留白；高密度页之后用它换气 |
| **D9 幽灵巨字压内容** | 单字/单词 150–400pt、6–12% 不透明度置底层，实内容压其上；每 4–6 页一次 |
| **D10 竖排文字带** | 页面一侧 8–14% 宽窄带，竖排短标题（每行一个汉字）＋极小拉丁字 |
| **D11 左图右词条卡** | 图通高占 40–45%，右侧＝眉行＋标签＋大标＋一行英文＋短线＋正文＋2–3 组「标签: 值」 |
| **D12 对开双栏** | 版心分左右两栏，中缝一条发丝线；两栏内容并置对照（问题/对策、前/后） |

**信息图形主导**（内容能做成图形时永远优先于「一段字」）

| 装置 | 构图机制 |
| --- | --- |
| **D13 数据卡组** | 2–6 组「大数字＋单位小字＋一行口径」；数字超大字号细字重，单位退到 10–12pt |
| **D14 大板拼贴（bento）** | 3–6 块**不等宽**大色板马赛克，块内饱满（数字＋标签＋小注），统一圆角与沟宽；用品牌色不用灰卡 |
| **D15 时间线** | 一条轴串起 4–8 个节点，年份用大字重，事件说明退到小字 |
| **D16 对比块** | 左右或上下两组对照，中间放一个「→ / VS / ＝」锚点 |
| **D17 色卡与字体样张** | 品牌设计稿必备：色块＋色值＋色名＋用法；字体样张要真的把字打出来看 |
| **D18 原生图表** | ≥3 个可比数值或时间序列就用原生 `<chart>`（**骨架见 `slides-xml.md` §五**）。**无网格线、值直标在柱/线端、只用墨色＋灰＋强调色** |
| **D19 原生表格** | 参数、规格、对照——用宿主原生 `<table>`（骨架同上），不用矩形拼 |
| **D20 时序/流程图** | 顶部一排角色框，各自向下引一条生命线，横向箭头带序号；返回用虚线；右上角图例 |
| **D21 分层架构图** | 3–5 条横向泳道，层内放模块框，层间标依赖方向 |
| **D22 点线清单** | 等宽字体的 `键 ..... 值` 档案式清单；关键词用强调色起头 |

**装置不是限制**：想到更好的构图就用你自己的——22 个是下限，不是天花板。

## 三、六条纪律

### 3.1 配色：材料色而不是屏幕色

- 全稿色板 ＝ **1 主色 ＋ 一条近黑近白的中性轴 ＋ 至多 1 个强调色**。超过就是失控。
- 主色要说得出它来自主题世界的哪种材料（茶汤、木、石、陶、织物、金属、漆面……）；
  **饱和度由 Step 2 的彩度带定**——低饱和不是普适纪律，参照库里有一份稿的饱和中位是 0.66。
- 中性轴禁用纯黑纯白：正文炭黑 `#2A2A2A–#3A3A3A`；浅底用暖白/米白/纸灰；深底用 `#101216–#1E1B18` 一档。
- **强调色面积 <5%**，只做视线锚点，语义固定（眉标/关键词/数字/母题件都用它）。
- 标题不套彩色：只用炭黑、暖白（深底时）或主色的深化版。
- 硬禁：蓝白商务、蓝紫渐变、青紫霓虹、彩虹光晕、玻璃拟态、发光描边、Material/Flat UI 默认色。

### 3.2 字体：display 与正文必须异质

- **字阶（16:9 编辑级）**：封面 80–130pt；章节巨字 90–200pt；页标题 28–44pt；导语 18–22pt；正文 14–16pt；注释 9–12pt。
  **相邻层级至少 1.8 倍尺度差**。**例外**：整稿走密排数据体例时，最大字号可以只有 20pt——那时靠网格与线撑。
- **中文主字 × 拉丁 display 配对**是编辑感标配：中文大字旁配一行 8–11pt 拉丁全大写、字距 200–300 的微标签。**英文必须有真实语义。**
- **数字与单位分层**：大数字超大字号细字重，单位与口径退到 10–12pt。
- 中文按语义断行，不留孤字；标题不超过 3 行。竖排只承担短标题、索引、年代。
- **字距**：只加宽不压缩。负字距会让字面压叠，宿主原样执行。

### 3.3 图像：图像是主角，而且不止一张

- **并排的几张图要成组**：同宽同高同比例、**共用顶线与底线**、间距相等（12–20px）。
  宽高各不相同的两张小图并排＝"临时贴上去的"，不是一组证据。
  只有要用宽度表达主次时才许不等宽；多图时**主图面积 ≥ 最小图的 2.5 倍**。
- **画面块默认切到页缘。** 参照库里 ≥12% 版面的画面块有 **94%** 至少切到一条页缘（11 份里 8 份是 100%）。
  四边都留白的内嵌矩形是 6% 的做法，只在「这块图本身是一件被展示的物件」（样张、色卡、单件产品图）时成立。
  ✗ 一整稿的图都四边留白 → 每页都退化成「白边里浮着一块内容」，题材再不同也是同一张脸。
- **图不是装饰**：每张图要么大到能承担画面，要么和别的图成组。**孤立的小图删掉比留着好**——
  四周空着、与任何块都不对齐、说不出服务哪一句话的小图，是填空不是设计。
- **左右并排时图与旁边那列内容之间至少留 24px 天沟**：`内容列 x = 图右沿 + 24`。
  ✗ 不许让整列文字的 x 对齐到图的边沿上——那不是"挨得近"，是没有天沟。修时**整列一起挪**。
  （出血图与半版色域共用一条缝是成文构图，不在此列。）
- **正文点名了几个对象（IP／产品／方案／场景），配图就要逐个对应**：一张图配一串名字＝图文不符。
- 顶级参考稿**单页图像面积中位 55%–75%，每页 2–5 张图**；全稿图像面积中位 <45% 先补图再写页。
- 单图页用满版或 ≥50% 版面的大画幅；多图页按 D4。**一排小图配一排小字＝电商详情页，判废。**
- 全稿共享同一个**影像世界**：统一的光线、色温、镜头语言、后期质感；**图自带的负空间就是标题的家**。
- **同一主题可以复现，同一主体画面默认只用一页**：下一页按新画幅重生/重检索；比例差 ≤10% 才用锚点。
  纹理／氛围底板可按角色跨页；用户明确要求同图复用时，每个使用页写同一个 `reuse=user:<用户要求>`。
  ✗ 不用“首尾呼应、连续场景、换了文字位置”自行豁免主体图；需要连续性就复现同题材的新画面。
- **图不为填框硬裁**：人物要完整肢体、产品要材质、空间要入口与动线。画幅不对就按新画幅重生，不要反复裁。

### 3.4 对齐：版心只有一条轴

- 全稿**一条左轴、一条右界**：每页的眉标、标题、正文、页脚都从左轴起或从右界收，不开第三根。
- **差几个像素只会被读成没对齐**：块的 x 与轴只差几像素时，直接对齐到轴上。
- 居中的元素要与**页面中心**同轴（或与它所居中的那块同轴），不要"看起来差不多居中"。
- 家具件（页码/眉标/刻线/角标）**逐页同坐标复用**，一个数都不要改——
  换页时变的是内容与密度，不是家具的位置。

### 3.5 密度：色块与文字块的分寸

- **实心色块不是主角**：参照稿每页只有 0–2 个实心图形。「一个大色块里塞五行字」是模板感的头号来源；
  **色卡、对比块、数据卡、章节底不在此列**——它们承担内容（§二 D13–D22），不是给文字当垫子。
- **文字块要拆开**：参照稿每页 8–19 个文字块、单块 3–22 字，靠**对位与字号跳跃**建立层级。
  一个块塞 40+ 字再套个框，对齐轴只剩 2–3 条，版面立刻散掉。
- **没有字的半透明罩就是多余的**：罩只为承文而存在，上面没有字就是忘了删。

### 3.6 构图：做极致的选择

- 巨字、巨图、强留白、高密多栏、鲜明色彩或粗线条都可成立，**宁可极致，不要平庸**。
- 封面、观点、数据、图片页各有构图；一致性靠配色、字阶、家具和网格，不靠同一骨架。
- 视觉语言来自主题、品牌、行业、时代或材质，并帮助理解内容；连续两页至少改变构图轴、图像占比、锚点、密度、明暗中的两项。

## 四、承文阶梯：文字落在图上怎么办（按这个顺序试，能停在前面就不要往后走）

> **加一层膜永远是次优解**——正解是把文字直接放进画面自己的那块安静面。

1. **落进图自身的安静区，零形状**（首选，参考稿七成的满版页这么做）——坐标不要估：
   `check --slide <本页>` 会印出这张图的安静区（`GRD-001`），更细的结构线与主体区跑 `ground --image`。
2. **图里本来就画了承文面**（订单写了「铺一片承文面」的那种）→ 文字整叠放进那块形，**零形状，不再叠任何东西**。
3. **图没有安静区 → 重新生成这一页的底图**，prompt 写明「给文字留一片低细节区/暗部，画面上无任何覆盖物」。
   **重做优先于叠东西**——多花一次生图，省下一个永远修不好的页面。
4. **两端压、中间透的通幅渐变**（前三条都不成立才用）：满画布 `rect x0 y0 w960 h540`，写成
   `linear-gradient(<角度>, rgba(R,G,B,0.72) 0%, rgba(R,G,B,0) 35%, rgba(R,G,B,0) 55%, rgba(R,G,B,0.72) 100%)`。
   **中段必须回到 α0**：单边 `α 0% / α 70% / 0 100%` 会压掉 83% 的画面，整张图洗成灰的。
5. **整页均匀压暗罩**（最后一档）：`rect x0 y0 w960 h540` 填 α0.35–0.50，**一块就够**。
6. **贴页缘的小压字带**（≤15% 版面，颜色跟地走）——只在带子底下那片画面本来就安静时成立。

**✗ 画面关系上的失败**：只为让字能读，就给每一块字各垫**等透明度的实色片**（板边会切一刀）；在**有内容的那一侧**
盖单边大渐变（那是「背景被截断」的来源）；给每一块字各垫一小片色片（画面上留一排补丁）。
**✓ 地不是图时**（实色地、纸色地），托片、色块、卡片都是正当手段——上面这些只针对**压在画面上**。

**画面上叠信息板的关系顺序（设计指导，不是门）**：先问板是**辅助承载**，还是这一页故意要看的**视觉主角**。
板只承载数据、说明或产品名时，先试：① 无板直排；② 从背景主色取同色相，做一层低透明板，让原画的光影与纵深
继续穿过去；深色画面也可先加同色相轻罩（约 α0.20–0.35）统一调子，再放近乎透明的板（约 α0.08–0.18）。
近乎不透明、又与背景反向明度的卡会把连续画面切成贴片；只有卡本身就是视觉主角、强对比确实服务本页判断时再用。
这三种关系都合法，数值只是起手位，必须结合本页内容与截图调整；`check` 不会按色相或透明度把设计判死。

## 五、空与满：两种失败长得不一样

- **空口袋 vs 开放边距**：**被内容两面围住**的那片空是**口袋**——两个方向围起来又不用它，
  读起来就是"这里还没放东西"；只有一面挨着内容的是**开放边距**，海报留白的常态，成立。
- **间距不均也算空**，最常见的是**列顶挤成一团、列底空一截**：① 行距拉到 1.8–2.0 ＋ 段间距铺满整列；
  ② 邻块或图窗放大接住让出的地；③ 铺不满就改双列或换版式重做。**不许保持原样。**
- **空**：大片没人用的纯色空白。**最常见的形状是「底纹或实色地 ＋ 几张悬浮的图 ＋ 一大片空」**——
  图既不贴边出血、也没有托底或相纸边框。三条出路：① 图撑满上下贴边；② 给图加托底/相纸边框＋图注；
  ③ 把空交给内容（装饰带、编号列、图注行、结构件）。`check` 会把这个形状连同空的坐标印出来。
  判法＝**遮挡测试**：挡住那片空白再看整页，构图还完整吗？这片空里有没有事发生（巨字的呼吸位、轴线的延伸、海报式静场）？
  两问都答不上就是「还没放东西」——**重新分布内容**，排不进就换版式重做。
  ✗ 不要加一块空色板占位；✗ 不要铺一层底纹了事。
  **合法的留白是成片负空间**：≥30% 连成一片、标题四周留得开——不是被内容切碎的几处空当。
- **满**：文字堆到装不下、块与块之间没有呼吸。修法是**删、拆、换结构**，不是缩字号。

**文字预算**（不含家具层）：章节页 ≤40 字；视觉主导页 ≤120 字；论证页 ≤180 字；全稿中位 ≤160 字。>220 字先删改或拆页。

## 六、写页时的自检七问（写完一页，回答不了就改）

1. 这一页的读者任务是什么？读者看完知道/相信/决定了什么？
2. 地是什么？和上一页的地是同一套系统吗？
3. 主视觉是什么？它服务本页哪一句话？**它是不是全稿里已经出现过的那张图换了个画幅？**
4. 文字落在什么上面？走的是承文阶梯第几档？为什么不是更前面那一档？
5. 家具四件套在不在？位置和上一页一样吗？
6. 这一页和前一页至少有哪两个维度不同？
7. 把文字全删掉，剩下的还是一张能看的画吗？（有图页）／还是一块干净有秩序的版面吗？（无图页）
