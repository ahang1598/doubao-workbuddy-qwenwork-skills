# Canvas 关闭文件流程

仅接受 [`canvas-doc.md`](canvas-doc.md#路由总表唯一判定入口) 已选出的 `close_file`。进入后不再调用 `+local-*` 或 `+ooxml-*`；打开态通道不可用不能自动降级到本流程。

> 使用前须完整读取本页；未见末行「全文完」时，继续读取至该标记。

- **读取/问答**：用 `scripts/read.py` 只读宿主提供的 `<path>`。
- **编辑前**：确认 `<path>` 仍是同一份可读写文件，记录 size/mtime/hash；在同目录创建时间戳备份并核对哈希。失败即停止。
- **编辑**：备份为只读 SOURCE，原 `<path>` 为唯一 TARGET，按 [`docx-editing.md`](docx-editing.md) 的路径策略例外原地增量编辑。修复也在同一 TARGET 增量完成；不执行其默认的副本创建、重新生成和末尾整份写回。若本轮已有已验收 Canvas 写入，必须先确认磁盘版本已包含，否则停止文件写入。
- **并发保护**：每次保存前核对磁盘文件仍匹配最近一次读取或自己成功保存后的 size/mtime/hash，保存后推进基线。首次写入前发生外部变化，只允许重新备份、读取和规划一次；再次漂移，或写入后发现外部变化，立即停止。该检查不是宿主写锁，要求原子隔离时不得进入本流程。
- **目录与验收**：先 audit 与结构回读；目录维护、失败披露和后处理后的重验统一按 [`docx-editing.md` 的验收步骤](docx-editing.md#第-4-步--验收)，不因无关目录的刷新能力缺失阻断已验收内容。摘要漂移或文件损坏时停止交付。命中视觉条件时只探测一次 LibreOffice 并查看受影响页及相邻页。
- **交付**：说明原路径和最终备份路径；渲染不可用只披露实际未验证范围。宿主要求显式交付时交付已验收的原路径文件，不套用本地打开流程的“不交付”规则。

不得把此前 CLI XML、OOXML 候选或历史上下文覆盖到 `<path>`，也不得把 token 拼成 URL。
