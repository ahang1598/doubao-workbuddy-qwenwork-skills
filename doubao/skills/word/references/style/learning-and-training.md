# 教学培训与学习写作指南


## 适用范围与核心要求

本指南指导教学、培训与学习场景的内容写作和 Word 排版。适用范围按 [writing-taxonomy.md](writing-taxonomy.md) 判断，文件处理遵守 [SKILL.md](../../SKILL.md)。
**内容服务实际任务**：按场景的常规用途组织内容，落实用户要求，并配齐使用所需的材料。

## Roadmap: Agent 执行路径

明确需求与依据 → 按场景设计并写作 → 排成可用的 Word → 回读交付。
完整读完本指南后，步骤2只执行本次相关场景，其余步骤共同适用。内容规划要说明本次材料如何支持理解、运用或反思，并将相应的内容安排写入主流程已有的 `outline.md`。

## 写作哲学

教学、培训与学习写作的核心，是帮助人形成理解、掌握方法，并逐步具备独立判断和运用的能力。

面向学习者的教学材料，应帮助其理解知识为什么成立、方法在什么条件下适用，以及面对具体问题时如何作出判断。学习者撰写的计划与总结，应帮助自己梳理已有认识、发现尚未解决的问题，并明确继续学习和改进的方向。

内容完整、事实准确和排版清晰是基础；更高的要求，是通过内容的选择与组织，为教与学带来实质性的启发。**Agent 必须结合具体任务，将这一追求贯穿内容规划、写作与成品检查。这是核心质量要求，不要求成品复述本段或增加固定栏目。

## 步骤1：明确需求与内容依据

### 1.1 从三个并列维度理解需求

- **使用者**：材料由学生还是老师编写、给谁使用？沿用该场景的常规体例，结合上下文确认学习者的基础，据此选择内容深度与表达方式。需要保持一致的写作者视角，不可混淆教师和学生视角。
- **任务目标**：用户要完成什么具体的教、学或评价任务？确定主题范围与预期结果，选择步骤2对应场景。
- **交付要求**：交付完整成品还是指定片段？落实篇幅与模板要求。

### 1.2 从材料用途走到可用依据

- **判断用途**：按主流程读透材料，分别识别它提供的内容依据与格式约束，用于正文或版式设计；同一材料可兼有两种用途。
- **提取依据**：采用具体信息时回到原件定位核对；关于既有学情、经历与效果的表述，须有用户陈述或真实记录支持。
- **不得编造信息**：必要的学情假设使用占位符应说明或标注说明，并提供验证办法；不为了内容丰富编造信息。

### 1.3 先匹配版本，再核对内容

涉及教材或课程、考试规定时，**必须在内容设计前搜索校验**。核验围绕三个相继动作展开：
- **定位版本**：从要求和用户提供附件或link中提取以区分版本的标识，如出版社、册次与版次；必要时核对起点和学制。用户使用旧版就匹配旧版，不能默认用最新版本或年份不同的版次。
- **核对内容**：搜索出版方或主管部门原始资料，与附件的具体内容相互印证。目录核位置，正文核知识范围与教学深度；在大纲留下原件定位或原始链接。
- **禁止依赖模型内置知识体裁教材核验**：用户只提供了教材名称时，必须根据线索搜索获得准确的内容；未核实前，不冒称匹配指定教材。

## 步骤2：按场景确定体例与内容

以下体例要素是完整成品至少应包含的内容，可按模板合并栏目；局部任务只采用相关要素。

### 2.1 教学设计

- **一般体例要素**：课题信息（课题、教学对象、课时）；教材与学情分析；教学目标；教学重难点；教学过程；学习评价。板书设计、课后任务与课后反思按课程或模板要求补充。
- **写作要点**：从教学内容和学习基础推导目标，写清学生学完后能够独立完成什么；活动之间应有承接，并提供突破难点的材料与教师支持。重点是最需要学会的内容，难点是最可能学不会的环节。评价写明用什么表现判断学会、未达标时怎样调整；单元设计还须说明各课与单元目标的关系。

### 2.2 教案

- **一般体例要素**：课题信息（课题、教学对象、课时）；教学目标；教学重难点；教学准备；教学过程（各环节的师生活动，最好能够提供板书设计）。有练习或课后任务时，附具体题目及参考答案或评价要点；板书按需提供。
- **写作要点**：按课堂顺序写到教师能直接使用，给出关键提问、转场及遇到困难时的处理办法。所需材料应实际提供或准确指向用户已有材料；将操作与等待计入课时，按教案试走确认可完成。与教学设计合写时，把设计理由融入对应环节。

### 2.3 讲义

- **一般体例要素**：学习主题与目标；知识讲解与示例；练习任务；参考答案或评价要点。课堂讲义保留必要作答区，教师说明另作分区。
- **写作要点**：围绕学生需要理解的问题展开，解释、示例与练习应有承接，答案须能帮助核对并纠正关键错误。自学讲义补足无人讲解时需要的步骤和提示，使学生能够独立继续学习。

### 2.4 试卷

- **一般体例要素**：学生卷包含考试信息（范围、时长、总分）、作答说明、题目及分值；教师部分包含参考答案和评分标准，过程题给出分步评分。正式组卷附简明细目表，听力题附读稿或音频。随堂练习至少包含题目和参考答案；用户明确不要答案时从其要求。
- **写作要点**：先确定考查范围和能力要求，再安排题型与分值。正式组卷用“内容 × 能力”细目检查覆盖；少量随堂练习无需完整细目表。难度配比注明统计口径，默认按分值；按目标学生水平估计用时，调整题量并留出检查时间。
- **核验要求**：逐题重新作答后确定答案与评分；核对题量及题号与解析对应，设有分值时用脚本复算总分，不得口算。

### 2.5 学习计划

- **一般体例要素**：学习基础与目标（总体roadmap）；任务日程（学习内容、所用材料、用时）；阶段成果与检查标准；未达标时的调整办法。
- **写作要点**：按能力依赖安排先后顺序，每次任务写清做到什么算完成。练习、核对与复习均计入可用时间，预留补漏空间；未达标时减少新任务或增加支持，用实际表现判断掌握程度。

### 2.6 培训讲稿

- **一般体例要素**：标题；开场导入；主体讲述；结尾收束。有演示或互动时附对应操作提示；依据 PPT 写稿时，在每页讲解前标“PPT 第N页｜页题”。
- **写作要点**：围绕听众需要解决的问题展开，正文写成可直接讲述的话，包含关键示例与转场；用户只要提纲时按提纲交付。
- **时长核验**：先预留互动与演示时间，再按中文180–200字/分钟估算实际讲述篇幅。

### 2.7 学习总结与教学反思

- **一般体例要素**：学习总结包含学习经历、主要收获、问题与后续计划；教学反思包含教学实施情况、效果与原因分析、改进安排。
- **写作要点**：用真实记录串起“经历—认识—行动”，改进安排应有复查办法；短心得按篇幅取舍。学习总结保持学习者视角，教学反思围绕自己的教学选择。

## 步骤3：从使用方式落到 Word 版面

按“组织页面内容 → 设置样式 → 处理页面与对象”推进；排版选择应帮助读者查找、理解或操作。

### 3.1 组织内容：先排顺序，再分区，再选形式

- **安排阅读顺序**：教案沿课堂进程排列，讲义让解释与示例相邻，学习计划让当前任务和完成标准相邻；按实际使用顺序组织正文。
- **划分使用区域**：学生内容与教师说明分区。正式试卷的教师答案另起页，随堂练习按用户要求同页分区或另附；作答与记录区按预期填写量留空间。
- **选择表现形式**：连续解释用段落，需对照的信息用表格，难以用文字说清的关系用图示。例题推导、板书设计需要与正文区分时，优先采用3.4的内容块。教案可用短流程表配正文，长讲述放表外；计划选择周历或清单呈现同一套日程。

### 3.2 设置样式：先确定依据，再统一应用

用户明确要求优先，其次继承模板或原稿需保留的格式；无模板时采用下表，覆盖 taxonomy 同项默认值，其余遵守通用规则。这些是编辑默认值。

| 角色 | 字体与字号 | 段落与用途 |
|---|---|---|
| Title | 黑体 / Times New Roman，18 pt，加粗黑色 | 居中，段后12 pt，无标题线 |
| Subtitle / 课时信息 | 宋体 / Times New Roman，10.5 pt，黑色 | 居中、单倍，段后8 pt，零缩进 |
| Heading 1 | 黑体 / Times New Roman，14 pt，加粗黑色 | 顶格，段前10 pt、段后5 pt，与下段同页 |
| Heading 2 | 黑体 / Times New Roman，12 pt，加粗黑色 | 顶格，段前8 pt、段后4 pt，与下段同页 |
| Normal | 宋体 / Times New Roman，12 pt，黑色 | 1.5倍，段后4 pt；论述首行2字符、两端对齐 |
| Task / 话术 / 题干 | 宋体 / Times New Roman，12 pt，黑色 | 左对齐、零缩进，1.5倍，段后4 pt |
| Table Text | 宋体 / Times New Roman，10.5 pt，黑色 | 单倍，段后3 pt，所有缩进为0 |
| Caption / 来源注 | 宋体 / Times New Roman，10.5 pt，黑色 | 单倍，段前后4 pt、零缩进；题注居中，来源左对齐 |

- **统一应用**：使用真实 Word 样式；中文设 `eastAsia`，西文设 `ascii/hAnsi`。默认两级标题，可不编号；长手册按需用三级，短环节用加粗标签。
- **按阅读需要调整**：低龄材料正文默认14 pt，并同步增大作答空间。颜色只用于标识信息角色，同类信息保持一致；计划可用一个低饱和强调色，打印试卷保持黑白可辨。

### 3.3 设置页面与对象，再检查衔接

- **设置页面**：A4、四边2.5 cm，默认无封面和页眉；两页及以上正文设页脚居中的 `PAGE` 域。未要求时不加目录，覆盖 taxonomy 的长文自动目录规则；需要时用真实 Heading 驱动 TOC 并刷新，目录不显示页码、正文从1开始。
- **设置对象**：表格不超版心，固定列宽、表内零缩进；所有表头都需要设置重复表头的属性；文字列水平左对齐、数值列水平右对齐、短分类列及表头水平居中。默认浅灰表头、白底，外框1 pt/内框0.5 pt，左右内边距0.19 cm；**所有表格单元格必须垂直居中，包括表头与正文单元格。** 题号用自动编号，公式优先用可编辑 Word 公式，图片等比嵌入；必要来源用邻近的真实超链接。
- **检查衔接**：标题与后文同页，题干与短选项同页；图题在图下、表题在表上，并与对象首部同页。表头设 `tblHeader`、行设 `cantSplit`，长表在行间续页；不靠空段撑页或缩小字号挤页。

### 3.4 例题与板书内容块

- **用途与组织**：将一个例题的题目与推导、或一组板书集中呈现，用“【例题】”“【板书设计】”等标签标明用途；同类内容块全文保持一致。
- **视觉样式**：默认浅蓝底纹 `#F0F5FA`、蓝色 `#4A90D9` 的0.5 pt边框，四边内边距0.3 cm；标签用深蓝 `#003366` 加粗，块内字体与字号沿用本次文档的正文设置，水平左对齐、零缩进。
- **实现与分页**：可用单列表格承载，所有单元格必须垂直居中；内容块采用本节的底纹、边框、内边距和文字样式，覆盖普通表格对应默认值，无需表头或表题。文字和公式保持可编辑；块高随内容变化，过长时按例题或推导阶段拆块，标签与后续内容同页。

## 步骤4：检查内容与文件后交付

- **实际可用**：按具体场景回读，检查内容关系是否成立、必备材料是否齐全；对照开篇的写作哲学，从成品的具体内容判断是否为理解、运用或反思提供了实际支持。有不足就调整内容，栏目齐全不等于质量达成；篇幅是否合理。
- **局部修改一致**：仅同步授权范围内的关联内容。用户要求“其余不变”时，先使当前片段兼容原文；无法兼容则说明具体冲突，不擅改其他部分。
- **遵守主流程**：完整运行 `audit.py`，用 `read.py` 回读实际生效格式，如不通过需要修改。
