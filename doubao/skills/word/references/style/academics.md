# 学术文稿写作与编辑指南

## 适用范围与核心要求

用于论文、综述、开题及研究方案的写作、修改和 Word 排版。

## 写作哲学

**内容有据**：基于真实文献和研究材料立论，不编造、套用文献。让读者看清问题、证据与推理，能够判断结论为何成立、适用于哪里。
**排版严谨**：严格执行选定的学术规范。逐项落实完整排版系统，核验实际格式与页面效果。
这两项是核心质量要求。具体内容、结构和修改范围由用户任务决定。

## Roadmap: Agent 执行路径

明确需求与依据 → 写作或整理 → 应用排版要求 → 检查交付。
文件处理沿用 [SKILL.md](../../SKILL.md)。本指南明确项覆盖 [writing-taxonomy.md](writing-taxonomy.md) 的同项默认值。

## 步骤1：明确需求与依据

从三个维度确认需求
- **任务目标**：要写什么或改什么，完成到什么程度。
- **内容依据**：按需读取用户材料、检索文献，区分内容来源与格式参考。修改已有文稿以原文为准。
- **交付要求**：落实篇幅、结构、语言和目标规范，明确修改及保留范围。

沿用已确认要求，保留采用信息的出处。必填但缺失的作者、基金等信息标待补。

## 步骤2：内容规划与校验

**注意**：要交付完整产物，除非是需要用户补充的数据实验信息等，否则不可以留下任何待补占位，尤其是公开搜索可获得的参考文献；润色、翻译和压缩保留原意、数据、引语及结论强度；仅排版或套模板时，直接进入步骤3。

### 2.1 检索与核验文献

- **检索**：按问题确定关键词和时间范围，记录检索式、日期及取舍理由。优先适题的高质量原始研究。中文优先万方、维普和期刊官网；英文生物医学用 PubMed/PMC，其他学科用相应数据库、出版社或机构知识库。
- **核身份**：逐篇核验出版页或数据库原始记录。核作者、题名、年份、刊名、卷期及页码/文章号。有 DOI 则解析并比对出版页面。
- **核内容**：将实际读到的内容与正文表述逐项对应。书目信息只证明文献身份；引用的表达需要是摘要支持其直接载明的内容。取得全文后核关键结果、图表及限制。在工作底稿记录链接、阅读范围、原文定位和引用位置。
- **绝对禁止编造参考文献**：所有参考文献列表的文献必须真实，并且需要是原文引用所表达的含义，不可编造，不可张冠李戴。
- **不验证则不使用**：原文不可得时换可核来源，不可轻易引用转引的说法。

### 2.2 组织论证

- **明确问题**：比较已有研究的对象、方法与结论，确定本次要补充或澄清什么。新写且研究方式未指定时，按可得材料选择写法。指定实证任务缺数据时说明缺口。
- **完成分析**：选择材料和方法，完成比较、计算或推导。检验其他解释及相反证据，按证据确定结论强度。数据与计算应可复核；系统综述保留可复现的检索筛选过程。研究方案写清拟采集什么、怎样分析和判断，以及可行性与必要伦理安排。
- **展开正文**：各节承担明确的论证任务，连接观点、证据和解释。定义、方法及过渡段按各自作用安排。扩写在指定范围内形成完整论述；压缩优先删重复，保留必要方法、证据与限制。

### 2.3 确定体例要素与篇幅

下文依次提供**完整中文学术论文**和**研究生开题报告**两种常见体裁的体例要素。
体例、篇幅及统计口径按用户与目标规范确定，执行硬性上下限。已有文稿和局部任务按本次范围保留、扩写或压缩。
未列出的类型，用户未说明要求时，须主动检索权威规范。
优先目标期刊、会议或学校/院系官网，再查适用的国家标准及学科权威指南。核对适用范围与现行版本后，确定组成、篇幅及排版要求。
章节篇幅和文献数量由论证需要决定。无统计口径时计摘要及正文（含标题、表内文字、题注），排除目录、页眉页脚、参考文献、脚注及附录；成品核对字数。

**完整中文学术论文**：以下为组成参考。
新写完整论文且无要求时，仅作规划参考：中文期刊6000～12000字、课程3000～5000字；英文分别5000～8000词、1500～3000词。会议按长短文及模板页数，学位按本校要求。

| 组成 | 内容与要求 |
|---|---|
| 题名（必备） | 准确、简明、可检索。用标准术语、学名全称及药物化学品通用名，不用泛词夸张词。一般不宜超过25字，宜有外文题名。必要时用副题名说明范围或分期成果，各处题名一致 |
| 作者（必备） | 列实际贡献责任者及姓名、单位、通信邮箱。宜置题名下并有对应外文信息。集体成果不宜只列课题组名，署名顺序按已确认贡献；通信作者信息可置文末 |
| 姓名写法 | 中国姓名拼音姓前名后，不加短横线、不缩名。外国姓名遵从原拼写 |
| 摘要（必备） | 独立自明，不加注释评论。通常写目的、方法、结果、结论，所述结果有正文支持。宜报道性，可结构式，也可报道/指示性或指示性；中文分别约400/300/150字，随成果量调整 |
| 摘要位置 | 宜置作者后，宜有对应外文摘要。外文可含更多信息，可置中文摘要后或正文部分后 |
| 摘要符号 | 可含图表、数学式、化学式，但不应含这些对象及参考文献的编号。不宜用非公知符号术语；首次出现的非公知简称/缩略语应给全称、翻译或解释 |
| 关键词（必备） | 宜3～8个，宜置摘要后并提供对应外文。宜从主题词/专业词表选，可用未收录的新术语及地区、人物、产品名。不用“方法、理论、分析”等泛词 |
| 其他前置项 | 基金产出应标基金名称与编号。宜标收稿日期，可标修回日期，亦可置文末。可标本文引用格式、增强出版元素及相关声明。真实填写，按目标要求匿名 |
| 引言（必备） | 交代背景、目的、理由和预期意义。客观评介既有研究，如实介绍本研究，聚焦研究缺口与问题 |
| 主体（必备） | 占主要篇幅。完整说明涉及的理论、方法、假设、技术工艺、程序、参数、设备材料或研究对象，使同行可重复研究。呈现过程、步骤、结果及必要图表、公式和数据，并解释讨论。理论、方法、结果、讨论等宜按逻辑独立成章 |
| 结论 | 有则必备，应编章编号。提炼回答而非重复摘要或小结；无法推导结论时可写结束语，讨论建议与待研究问题 |
| 致谢 | 可选，真实、恰当。置结论/结束语后，一般不编章编号，可用不同字体 |
| 参考文献 | 必备，与主题密切相关。仅列实际引用的来源 |
| 附录 | 有则必备，一般不设。需要时收影响正文紧凑性的重要原始数据、推导、程序及设备技术细节，置论文末尾 |

**研究生开题报告**：按目标模板填写题名及基本信息，正文通常包含以下要素。

| 组成 | 内容与要求 |
|---|---|
| 选题依据 | 交代课题来源、背景及研究意义 |
| 文献综述 | 比较国内外代表性研究的观点、方法与发现，评述不足并引出研究问题。按学校要求独立成节、合入选题依据；需另交综述报告时单独成文 |
| 研究目标与内容 | 明确研究目标、主要内容及拟解决的关键问题 |
| 研究方案 | 写清材料或对象、方法与技术路线，以及拟如何采集、分析和判断 |
| 研究基础与可行性 | 说明已有工作、所需条件、困难及应对。经费、设备和伦理安排按需列明 |
| 创新与预期成果 | 说明可能的创新及预期成果形式，区分已有成果与拟完成工作 |
| 进度安排 | 按阶段列任务、时间节点及预期产出 |
| 参考文献 | 列实际阅读并引用的文献，按2.1核验 |

## 步骤3：严格执行排版规范

选定规范 → 对照 [3.1](#31-选定规范列全要求全文统一) 列全要求 → 设置格式 → 核验交付。3.1 表中的全部要素都须考虑，分别确定需要设置、保持原状或不适用。以下细则供对应项目执行时查阅。

### 3.1 选定规范，列全要求，全文统一

- **选依据**：用户明确要求优先，其次为有效模板/投稿要求、目标机构正式规范、指定样稿、指定期刊。按本次范围查齐适用版本与要求。学位论文另查学校、院系及学位论文规范。
- **用默认**：无特殊要求时，执行下方中文方案。已确认目标规范未规定的项目，用兼容的默认值补齐；暂未查到的要求标待核。
  方案基于 **GB/T 7713.2—2022** 《学术论文编写规则》 与 **GB/T 7714—2025** 《信息与文献 参考文献著录规则》 。保留“应、宜、可”的区别。页边距、行距和三线表等由本指南补齐。
- **定范围**：默认值仅用于本次需要设置的项目。定位到真实章节、段落或对象，页码仅作线索。改共用样式前检查其全部使用位置。局部调整用局部属性或专用样式，范围外保持原状。
- **选定排版系统后，必须全文统一，不得变换。**

| 排版系统 | 必须考虑的要素 |
|---|---|
| 页面与分节 | 尺寸、方向、页边距、装订线、分栏、分节与分页 |
| 文字与段落 | 中西文字体、字号、粗斜体、上下标、颜色、对齐、缩进、行距、段距、同页控制 |
| 结构与导航 | 封面、声明及其他前置项；标题层级与编号；目录/图表目录；页眉页脚、页码起点与续接；附录、匿名信息 |
| 引用与文献 | 文内制度、标记位置、定位页码、脚注/尾注、文末排序、书目字段及段落格式 |
| 图表与公式 | 图尺寸、环绕、题注及图注；表列宽、边框、底纹、对齐、单位、表注及续页；公式编号、变量、符号与单位 |


### 3.2 字体与页面默认值

字号换算：小二18 pt、四号14 pt、小四12 pt、五号10.5 pt、小五9 pt。

先应用表中 Word 样式，再设置字体字号。章节标题使用原生 Heading 1–4，并关联多级编号。
自定义标题样式继承对应 Heading 和大纲级别。目录收录范围、无编号标题按目标规范确定。

| 文字角色 | 字号与字体 | Word 样式／结构 |
|---|---|---|
| 中文题名 | 小二黑体 | 标题（Title），正文大纲级别 |
| 中文作者姓名 | 小四楷体 | “作者”段落样式，正文大纲级别 |
| 中文工作单位及通信方式 | 小五宋体 | “作者单位”段落样式，正文大纲级别 |
| 中文摘要、关键词引题 | 小五黑体 | 段内标签用专用字符样式 |
| 中文摘要、关键词内容 | 小五仿宋 | 分别用“摘要”“关键词”段落样式，正文大纲级别 |
| 英文题名 | 四号黑体 | 基于 Title 的“英文题名”样式，正文大纲级别 |
| 英文作者姓名 | 五号宋体 | “英文作者”段落样式，正文大纲级别 |
| 英文单位及通信方式 | 小五宋体 | “英文作者单位”段落样式，正文大纲级别 |
| 英文摘要、关键词引题 | 小五黑体 | 段内标签用专用字符样式 |
| 英文摘要、关键词内容 | 小五宋体 | 分别用“英文摘要”“英文关键词”段落样式，正文大纲级别 |
| 其他前置项目 | 小五宋体 | 按角色设专用段落样式，正文大纲级别 |
| 章编号及标题（引言、主体、结论） | 小四黑体 | 标题1（Heading 1），大纲1级 |
| 二级节编号及标题 | 五号黑体 | 标题2（Heading 2），大纲2级 |
| 三级节编号及标题 | 五号黑体 | 标题3（Heading 3），大纲3级 |
| 四级节编号及标题 | 五号黑体 | 标题4（Heading 4），大纲4级（如有） |
| 正文 | 五号宋体 | 正文（Body Text），正文大纲级别 |
| 图编号及图题 | 小五黑体 | 题注（Caption），图号用 SEQ 域 |
| 表编号及表题 | 小五黑体 | 题注（Caption），表号用独立的 SEQ 序列 |
| 表内文字 | 小五宋体 | “表格正文”段落样式，正文大纲级别 |
| 表注、图注 | 小五宋体 | “图表注”段落样式，正文大纲级别 |
| 致谢引题 | 五号黑体 | 基于 Heading 1 的“致谢标题”，默认无章编号 |
| 致谢内容 | 五号楷体 | “致谢正文”段落样式，正文大纲级别 |
| 参考文献引题及章编号 | 小四黑体 | 基于 Heading 1 的“参考文献标题”，章编号按目标要求 |

| 附录内容 | 五号宋体 | “附录正文”段落样式，正文大纲级别 |

- **文字与段落**：西文默认 Times New Roman，字号随角色。文字黑色，标题边框无。正文两端对齐，1.5倍行距，首行2字符，段前后0。章/节标题段前12/6 pt、段后6/3 pt，与下段同页，连续编排。
- **页面与导航**：A4单栏，四边2.5 cm，装订线0。期刊/会议从题名、作者、摘要到正文、参考文献连续编排。封面、目录、页眉按目标要求设置；课程长文按用户要求或导航需要加目录，学位按学校规范。
  页脚居中用阿拉伯页码，正文从1起；独立封面隐藏页码，独立前置页与正文分节。如需目录用 Heading 驱动的动态TOC，层数按内容及目标规范。
- **表格与图片**：白底三线表、无竖线，顶底线1 pt，表头下线0.5 pt，辅助线便于理解。表宽≤版心，列宽显式。表头居中，数据列按语义统一对齐；缩进0，单倍行距。表行保持完整，长表行间跨页并处理续表。
  图片嵌入型居中，等比缩放至版心内，保留原始信息。题注与对象同页；图表注及脚注9 pt、单倍行距；参考文献悬挂2字符、单倍行距。


### 3.3 引用、注释与参考文献

- **引用位置**：一般放在句号前面。在借用的观点、数据、方法、定义或原话旁标来源。直接引语应用双引号，逐字核对并给页码；无页码用真实章节/段落定位。转述同样标来源。
- **默认顺序编码**：按首次引用连续编号，重复引用沿用原号。多篇如 `[1,4,7]`、`[1-3]`；作者入句如“张三等[2]认为”。
  引文标记默认上标。文末按编号列参考文献。
- **注释**：解释性注释宜采用原生脚注，文中编号、置当页底部，图注、表注随对象。
- 文末参考文献为独立书目表，可编为一级标题；规定使用[1]、[2]的参考文献，易用交叉引用REF格式；规定脚注时用 footnote。
- 以下为默认论文参考文献的结构示例，尖括号内用核实字段替换。按资源原类型及载体著录。在线版本按类型加 `/OL`，补真实获取路径及该类型要求的日期。有 DOI 时优先保留 `DOI:〈标识符〉`。

| 类型 | 格式示例 |
|---|---|
| 中文期刊 | `[1] 〈作者〉. 〈篇名〉[J]. 〈刊名〉, 〈年〉, 〈卷〉(〈期〉): 〈起止页码或文章号〉.` |
| 英文期刊 | `[2] 〈Surname A〉, 〈Surname B C〉. 〈Article title〉[J]. 〈Journal〉, 〈year〉, 〈volume〉(〈issue〉): 〈pages/article number〉.` |
| 图书 | `[3] 〈作者〉. 〈书名〉[M]. 〈译者〉, 译. 〈版次〉. 〈出版地〉: 〈出版者〉, 〈年〉: 〈引文页码〉.`；无译者省译者项，首版省版次 |
| 网页 | `[4] 〈责任者〉. 〈网页题名〉[EB/OL]. (〈创建或修改日期〉)[〈实际引用日期〉]. 〈URL〉.`；未载创建/修改日期时省略该项 |
| 学位论文 | `[5] 〈作者〉. 〈题名〉[D]. 〈城市〉: 〈学位授予单位〉, 〈授予年〉: 〈引文页码〉.` |
| 会议析出论文 | `[6] 〈作者〉. 〈篇名〉[C]//〈编者〉. 〈会议录名〉. 〈出版地〉: 〈出版者〉, 〈年〉: 〈页码〉.` |
| 标准/报告 | `[7] 〈标准编号〉 〈标准名称〉[S].`；`[8] 〈责任者〉. 〈报告题名〉: 〈报告编号〉[R]. 〈发布日期〉: 〈引文页码〉.` |

### 3.4 章节与图表

- **标题层级**：一般不宜超过4级，并且需要使用原生的`Heading`。章应有标题，节宜有标题；同章/节中同层有无标题统一，标题一般不宜超过15字。
- **编号**：宜用 `1`、`2.1`、`3.2.1`，末位无点。顶格，编号后空1字符接标题，末无标点，正文另行。传统编号可按统一层级结合汉字与阿拉伯数字。
- **列项**：全文统一。宜用 `1）`、`（1）`、`a）`、`（a）`，也可符号。公式已用 `（1）` 时列项不宜重用。图、表、公式用阿拉伯数字分别连续编号，一般按出现顺序全文统一。单图、单表也编号；附录依序用“附录A、附录B”。
- **插图**：自明、简明、科学、清晰，大小适当。图号后空1汉字接图题，居中置图下。宜紧随首次提及，先文后图。必要图例、图注和说明完整。
- **图类型**：坐标标目置轴外、一般居中。横标从左到右，纵标自下而上“顶左底右”，右纵轴同左。量与单位写“量符号或名称/单位符号”。照片轮廓鲜明、反差适中，缩放后清晰，应有目的物尺寸标度。构造/装配图共用单位宜在左下或右下注“单位：××”。地图准确并符合公开地图表示规范。
- **表格**：自明、简明、规范、逻辑清晰。表号后空1汉字接表题，置顶线上方、宜居中；必要表注在表下。表头正确齐全，禁止斜线。宜项目横排、数据竖排；相邻重复内容重写或通栏，不能用“同上/同左”。可选三线表、或普通表格，一般不设表头以外的背景色。
- **表内数据**：空白表示无此项或未测，“—”表示测过未发现，“0”表示实测零。“—”与阴性混淆时可用“⋯”，不得混写。量与单位用“量符号或名称/单位符号”，复合单位加括号。全表单位相同宜置右上方。
- **图表注**：说明符号、代码等事项。多条需编号时，宜用数字加后半圆括号或圈码，标在被注对象右上；注末加句号。
- **续表**：表宜紧随首次正文引用。所有表格均需要在首行设置重复表头，跨页后在接排表上方写“表×（续）”或“续表”，并重复表头。

### 3.4 量、单位、数字、公式与术语

- **量名与符号**：量符号通常为单个拉丁/希腊字母，特征数可两字母；用斜体，pH除外。按含义区分上下标、大小写及正斜体。
- **单位**：用法定单位。量值用正体国际单位符号，与数值留0.5字符间隙。
- **词头**：宜用SI词头，不独立、不重叠。平面角°、′、″及时间d、h、min不加SI词头，°C允许。
- **量值**：相乘各量重复单位，如 `40 m × 60 m`。同单位范围前单位宜省略，但 `20%～30%` 保留前百分号。一组同单位数可只在末值写单位。
- **数字**：简明清晰时宜阿拉伯数字。计量计数、编号、公历世纪年代年月日时刻及定型阿拉伯数字名称应使用阿拉伯数字。定型词/惯用语中的汉字数字、两数连用、非公历纪年应使用汉字数字。日期时间采用规范表示。
- **数值表达**：按规则修约和判定极限值，保留全部有效数字。分组无重叠、无遗漏，如 `[0,5)`、`[5,10]`。大于999的整数及超过3位的小数宜三位分节。除万、亿中文符号外，阿拉伯数字不与汉字数词混拼。起止时间用一字线，如 `2020-09-01—12-01`。
- **公式语义**：按数学符号规范区分变量、变动附标、函数、已知函数、常数、算子、集合、向量/矩阵及说明字符的大小写、正斜黑白体。区分量关系式与数值关系式，宜用前者。变量随式解释，同符号不能兼指量与数值；不用量的中文名或多字母缩略术语代替量符号。
- **公式位置**：一般串文排。后文引用的编号公式及繁分式、积分、连乘、求和、矩阵等大式应另行居中。编号置本行或转行末行最右，可按语法加末尾标点。宜避免行文公式多于1行、上下标嵌套超过1层、式内表示形式多于2行。
- **术语**：首选全国科学技术名词审定委员会规范名词。全称/简称可用，少用又称，不宜俗称/曾称。不同机构定名可择用，同机构跨学科定名宜选本学科用语。未审定词宜单义，贴近内涵或行业习惯。少用字母词；未经审定的首次括注中文译名，必要时补外文全称。全文一致。


## 4. 交付检查

- 禁止引用未经检验的文献、虚构文献、研究条件、已完成的研究过程或结果。

- 禁止用同义扩写、堆砌文献替代论证，或只列方法名称代替可执行的研究方案。
