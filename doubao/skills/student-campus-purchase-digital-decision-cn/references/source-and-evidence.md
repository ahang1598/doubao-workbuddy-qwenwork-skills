# 来源与证据

## 运行时 Tool 状态

每次任务都重新记录联网搜索/页面读取能力，不复用上一次任务状态，也不从平台名称或 Skill ZIP 推断：

- `available_authorized`：Tool 实际可用，且当前任务已获准使用。
- `available_authorization_pending`：Tool 可用，但授权范围未确认。
- `unavailable`：当前任务没有该 Tool 或调用失败。
- `not_used`：本次没有使用联网 Tool。

授权待确认不等于已授权。只有 `available_authorized` 能与已授权的联网来源一起支持“已核验”。

## 逐来源授权记录

每个会改变购买结论的来源至少记录：

- `source_id`、标题、主体、发布日期、链接和适用范围；
- `access_method`：`user_provided`、`public_web` 或 `offline`；
- `authorization_status`：`authorized`、`pending`、`restricted` 或 `not_applicable`；
- `retrieved_at`：实际联网打开正文时的带时区 ISO 8601 时间；未打开则为 `null`。

用户提供或离线材料使用 `not_applicable + null`，只能标为“用户材料”或“离线材料”。`public_web + authorized` 必须同时满足 Tool 为 `available_authorized` 且存在带时区获取时间，才可标为“已核验”。`pending/restricted` 来源不得访问或支持推荐。公开可访问不自动等于允许自动获取、持久存储或再分发；需要登录、验证码、付费墙或条款限制时停止访问。

## A 级：官方一手

学校/学院/宿舍管理通知、厂商规格/支持页、用户提供的正式课程软件要求。用于规则、规格、兼容和官方支持。

## B 级：正规销售与高质量评测

用于当前价格区间和真实使用体验。不得覆盖 A 级硬规则。

## C 级：论坛/社区/短视频

仅用于发现坑点和生成待核验问题，不能单独证明学校政策、当前官方规格或确定适配。

## 动态信息

在售型号、价格、促销、库存、保修、学校规则、校园网络、软件版本与兼容要求都需尽量核验并标时间。

软件兼容性随版本、操作系统与处理器架构变化。模型记忆、“听说”或基于专业名称推测的软件清单均标为未核验，不能支持具名兼容表、具体配置门槛或购买结论。

## 历史官方信息

旧年度、旧校区、旧版本或适用对象不明的官方通知标为“历史官方信息”，不能自动继承为现行规则。没有找到新通知不等于旧通知仍有效，也不等于第三方说法为真。购买决策可暂按历史限制中的更保守方案降低损失，但结论必须写“当前规则未核验”，并给出现行宿管、学生手册、迎新通知或校方书面答复等核验路径。

## 工具可用性

先检查当前环境是否实际提供网页搜索、页面读取或附件读取工具，不假设固定工具名。只有满足上面的 Tool 与逐来源授权契约、成功打开来源并核对页面主体、日期、适用对象和关键内容后，才能标记“已核验”。工具不存在、调用失败、授权待确认、页面受限或只看到搜索摘要时均保持“未核验”，并说明替代路径。

## 冲突

- 学校规则：最新 + 官方 + 对当前校区/年级适用
- 产品规格：当前厂商官方型号页/支持页
- 价格：保留渠道、配置和时间
- 体验：作为偏好风险，不裁定为客观事实

无法核验时必须列“未核验内容、替代证据、是否影响购买结论”。
