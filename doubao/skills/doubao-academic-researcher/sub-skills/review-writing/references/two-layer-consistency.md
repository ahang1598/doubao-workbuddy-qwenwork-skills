# 双层一致性核查

综述最终对外交付两层：**文献调研结果层**（结论先行、分主题、带脚手架）和**成稿参考层**（连续成文、去脚手架）。两层同源，必须判断一致、形态互补。这份核查专门防止两层脱节。

成稿写完后过一遍下面几组检查；发现问题就地修正，若发现的是分析本身的问题（判断站不住、引用缺失），退回 research-synthesis，不在成稿层打补丁。

## 零、输入边界检查

先确认成稿正文只来自上游材料。

- 正文中的核心判断是否都能对应到上游“核心结论、主题分析、争议与开放问题、局限性”之一？
- 正文中的引用标识是否全部来自上游已有作者-年份引用？
- 正文是否新增了上游没有出现过的作者、年份、方法、数据集、实验结果、政策事实或具体数字？
- 正文是否把上游的开放问题改写成了作者自己的研究贡献？

发现新增事实或新增引用 → 删除；不能删除但确实需要表达 → 标 `[证据不足]`；如果核心论证链连续缺证据，回退上游。

## 一、判断一致性

两层的核心判断必须是同一套，不能一层说强、一层说弱。

- 调研结果层的每条"核心结论"，在成稿里是否都有对应表达？没有遗漏关键判断？
- 有没有某个判断在调研层用了强措辞（"多项研究证实"），到成稿里悄悄软化成"可能"，或反过来？
- 争议在两层是否都如实呈现，没有在成稿里被抹平成"存在讨论"？
- 措辞强度两层都要服从同一套分寸（见 `../../../references/hedge-calibration.md`），不能各写各的。

发现不一致 → 以证据为准统一，二者向同一强度收敛。

## 二、脚手架清除

调研结果层为"帮读者看地图"带的辅助件，成稿里必须全部拿掉：

- 范围说明
- 研究视角导航段
- 每节"本节文献 [x][y]"索引
- `> **小结**：` 分点标记
- 分点编号、"综上/首先/其次"这类分析口吻的连接词（改成自然过渡）
- 对比表和条目清单（除非用户明确要求保留）
- 可研究方向的题目、方法思路、选题建议

成稿里只要出现上述任何一种，就是脚手架残留 → 删除或改写为连续散文。

## 三、成稿边界

成稿最容易越界成"论文引言"。逐条排查：

- 是否被写成“摘要 / 引言 / 方法 / 结果 / 讨论 / 结论 / 总结”的整篇论文结构？
- 是否出现 `一、二、三`、`1. 2. 3.`、`第X章` 这类编号标题？
- 是否仍是 3-6 个自然段、2000 字左右，而不是一篇长论文或提纲？
- 有没有写出"本文/本研究/our work"或等价的第一人称定位句？
- 有没有偷偷替用户发明贡献点、方案或"我们提出"？
- 结尾是停在文献层面的未解问题，还是滑进了"为解决上述问题，本文……"？
- 综述稿是否自始至终保持"综述"身份，而不是变成某篇具体论文的引言？

发现越界 → 直接删改，不做软化处理。参考稿只描述"文献做到哪里、还差什么"，不承诺"谁来解决"。

## 四、证据不足处理

`[证据不足]` 不是常规写作标记，只在低文献量或关键证据缺口时保留。

处理顺序：

1. 如果只是证据强度不够，把“证实、表明、确立”降为“提示、可能、现有证据倾向于”。
2. 如果上游有判断但无明确引用编号，且该判断必须保留，句末标 `[证据不足]`。
3. 如果文献数量明显偏少（如只有十几条且覆盖多个主题），可交付草稿，但保留必要的 `[证据不足]`。
4. 如果核心段落连续依赖 `[证据不足]`，说明成稿阶段无法修复，应回退上游补充文献或综合。

不得为了交付完整正文、飞书云文档或其他外部格式，删除必要的 `[证据不足]` 标记。

## 五、AI 痕迹与汇报腔检查

成稿参考层必须像论文中的文献综述正文，而不是 AI 总结、科研汇报或 PPT 讲稿。输出前逐条检查：

- 是否仍有“第一、第二、第三”“首先、其次、最后”这类分点式组织。
- 是否用“近年来……受到广泛关注”“具有重要意义”“提供理论基础”“具有参考价值”等空泛句承担开头或结尾。
- 是否每段长度和句式过于整齐，呈现“四句一段、每句同长”的模板感。
- 是否只是在更换连接词后拼接上游材料，而没有形成连续论证链。
- 是否把文献关系写成“某研究提出 X，某研究提出 Y，某研究提出 Z”的论文清单。
- 是否把本应自然过渡的关系写成汇报口吻，如“下面从三个方面展开”“本节主要介绍”“综上所述”。
- 是否为了显得正式而堆叠抽象名词，却没有说明对象、机制、条件或边界。

处理方式：

- 出现分点式或汇报式组织时，改写为连续段落。
- 出现空泛开头或结尾时，改为具体对象、研究分歧、条件边界或未解问题。
- 出现逐篇摘要时，重写为“主题判断 + 文献关系 + 条件差异”。
- 出现句式过齐时，调整为长短句交替：复杂机制用长句，判断收束用短句。

## 快速自检清单

- [ ] 调研层每条核心结论在成稿里都有对应，无遗漏
- [ ] 同一判断在两层的措辞强度一致
- [ ] 争议两层都呈现，未被抹平
- [ ] 成稿无范围说明 / 导航段 / 本节文献索引 / 小结标记
- [ ] 成稿无表格、清单、可研究方向题目等调研层脚手架
- [ ] 成稿为 3-6 个自然段、2000 字左右，无拟题/摘要/引言/结论/总结/编号标题
- [ ] 成稿无"本文/本研究/our work"
- [ ] 成稿未替用户发明贡献点
- [ ] 结尾停在文献层面的未解问题
- [ ] 没有新增上游不存在的事实、作者、年份、方法、数据或引用编号
- [ ] 必要的 `[证据不足]` 没有被删除或粉饰
- [ ] 成稿不像 AI 总结、科研汇报或 PPT 讲稿
- [ ] 成稿没有空泛开头、口号式结尾、逐篇摘要和句式均质化问题

全部通过 → 双层交付合格。任一未过 → 就地修正或退回上游。
