# 缺口分析：争议、开放问题、可研究的方向

综述的后三个内容节——争议与开放问题、可研究的方向——**同源**：都是对综合过程中暴露的缺口做提炼。前面的主题章节回答"已经知道了什么"，这三节回答"哪里还不确定、哪里还没人做、你能做什么"。它们不是收尾套话，往往是读者查文献的真正目的（找选题、找切入点）。

方法在本文件，最终排版格式见 `../../../references/output-structure.md`。

## 三者的关系与分工

```
矛盾/分歧 ──→ 争议          （已有工作互相打架的地方）
taxonomy 空格 / 视角遗漏 ──→ 开放问题   （没人做、但应该有人做的地方）
争议 + 开放问题 ──→ 可研究的方向   （把上面两者翻译成可下手的选题）
```

- **争议**：证据层面的冲突——两篇及以上工作给出不一致的结论。
- **开放问题**：证据层面的空白——某个格子没有工作，或某视角被系统性忽略。
- **可研究的方向**：把争议和开放问题转成"读者明天能开始做"的具体选题。前两节是诊断，这节是处方。

**不要三节内容互相重复。** 争议讲冲突本身，开放问题讲空白本身，可研究方向讲"因此可以做 X"。同一个缺口在三节里出现时，视角要递进，不是复制粘贴。

## 一、争议：呈现冲突，不平均掉

A 说 X 有效、B 说 X 无效时：
1. **摆出双方发现**（A 具体说了什么、B 具体说了什么，各自引文献）。
2. **分析条件差异**（数据集？指标？样本量？时间窗口？识别策略？）。
3. **能判断就给倾向**："在 Z 条件下，B 的证据更有说服力"。
4. **不能判断就如实说**："目前证据不足以判断，需在 W 条件下验证"。

**禁止**：写一句"存在争议"就跳过；把矛盾平均成"结论不一"；只引支持一方的文献。争议是综述最有价值的部分之一，因为它指向尚未解决的问题——也就是选题的富矿。

### 矛盾排查要可核查：两条正交轴

散文式地写矛盾，容易漏、也容易糊。动笔前先在内部过一遍**被评估的论文对清单**（内部工具，不打印），让"排查了哪些对、各自判定如何"可核查，而不是让读者只能相信一段笼统叙述。每个论文对标两个**互不替代的轴**：

- **冲突性质**（这对到底有没有、有什么冲突）：
  - `矛盾`——同一问题上结论直接对立
  - `条件差异`——结论不同但可由语境/方法差异解释，不算真对立
  - `无实质冲突`——看似相关实则不冲突
  - `重叠不足`——两篇没有足够共同问题可比
- **消解状态**（这对处理到哪一步）：
  - `已消解`——在综述里给出了倾向或条件性结论
  - `标记未解`——是真冲突但当前证据判不了，如实挂着
  - `不适用`——本就无可消解

**两轴正交，不许合并成一个标签。** 一对可以是"条件差异 + 已消解"，也可以是"矛盾 + 标记未解"。

**合法组合有约束**：真冲突（`矛盾` / `条件差异`）只能配 `已消解` 或 `标记未解`，**绝不能标 `不适用`**——把真冲突标成"无可消解"等于把它悄悄埋掉。非冲突（`无实质冲突` / `重叠不足`）只能配 `不适用`。

**召回受限，不许声称穷尽**：你不需要枚举所有论文对（组合爆炸）。挑候选对来查——共享子问题、共享构念/指标、方向相反、或互相引用的。但两篇真矛盾的论文可能分处不同主题簇而没被配到一起。所以**永远不要写"已覆盖所有矛盾"**，如实说这是有限召回的排查。真冲突宁可标 `标记未解` 也不要漏报。

## 二、开放问题：让空白显形，并证明它是真空白

开放问题来自三个系统性来源，逐一扫描：

1. **taxonomy 空格**：MECE 分类表里哪个格子没有文献？"尚无工作把方法 A 用于场景 B"本身就是 finding。
2. **被遗漏的视角**：学科、地域、语种、方法、时间——哪一类被系统性忽略了？（如"某结论只在单一语种/单一国家样本上验证过"。）
3. **只在单一条件下成立的结论**：某个 claim 是否只在一种数据/一种设定下被检验过，外部有效性未知？

**每条开放问题都要有证据支撑**——"缺乏研究"也是一种需要论证的判断。区分**真空白**（搜过、确实没有）和**没搜到**（关键词没覆盖到）：真空白才写进开放问题，可疑的先回 literature-scout 补搜再定。

## 三、可研究的方向：把缺口翻译成可下手的选题

这一节回答读者最实际的诉求：**"那我能做什么？"** 每条选题必须由上文的争议或开放问题长出来，不凭空发散。

### 每条的三要素

1. **参考题目**：具体到能直接当研究标题。不是"可以研究 X 方向"这种泛指，而是"在 Y 条件下用 Z 方法检验 X"这种能立刻立项的表述。
2. **缺口依据**：回指上文——对应哪个 taxonomy 空格、哪处争议、哪个只在单一条件下验证过的结论。让读者看到这个选题不是拍脑袋，而是有据可循。
3. **方法思路**：不只给一个方法名，而是用一两句话说清这题大概**怎么做、涉及哪些方面**——让读者拿到就有下手感。至少覆盖：
   - **数据/材料**：用什么数据源、样本、语料或实验对象。
   - **做法/路径**：用什么识别策略、模型、实验设计或分析框架，关键步骤是什么。
   - **要处理的方面/难点**：这题绕不开的变量、对照、稳健性或边界条件（如"需控制 A、区分 B 与 C、在 D 上做稳健性检验"）。
   一两句话即可，不展开成方案；目的是让读者知道"从哪下手、要注意什么"，而非写完整研究设计。

**示意**（不同学科形态不同，仅供参考）：
> **题目**：《在低资源语种上检验 X 方法的跨语言迁移能力》。**缺口**：现有结论只在英文语料上验证过（第二节表 1 的空格）。**方法思路**：可用公开的多语种平行语料，以英文为源、若干低资源语种为目标做零样本迁移，比较 X 与基线的差距；需控制语种间数据规模差异，并在形态丰富度不同的语种上分别报告，避免用单一语种代表整体。

不同学科的"方法思路"落点不同：实证社科侧重识别策略与数据（IV/DID/面板）、CS 侧重数据集与基线对比、生医侧重试验设计与样本量、理论工作侧重建模假设与推导路径。按学科切换，但都要落到"具体怎么做+要注意什么"。

### 筛选标准：落在"少有人做 × 做得动"的交集

- 只新颖、但没有数据/方法能支撑的 → 不是好选题（无法推进）。
- 能做、但已经被做烂的 → 不是好选题（无增量）。
- **两者的交集**才是：当前研究较少涉及，且现有条件（数据、方法、工具）足以推进。
- 明确不要"正确但空洞"的建议（如"未来应加强跨学科研究"这类谁都会说的话）。

### 数量与排序

- **3-5 条**，按可行性或潜在价值排序。
- 可标注难度或所需资源（如"需要面板数据""需要一次小规模实验""可用公开数据集直接做"），帮读者判断投入产出。
- 措辞受分寸约束（见 `../../../references/hedge-calibration.md`）：没把握的方向用"可探索"，有明确抓手的用"值得优先推进"，不要每条都说成"极具前景"。

## 自检

- 三节内容是否递进而非重复？（争议讲冲突、开放问题讲空白、方向讲处方）
- 每条开放问题背后是真空白还是没搜到？可疑的补搜了吗？
- 每条可研究方向是否三要素齐全（题目+依据+方法），且能落在"少有人做×做得动"的交集？
- 有没有混进"正确但空洞"的万能建议？有就删。
