# 检索策略细则

## 关键词构造

关键词不是想到什么搜什么。按以下模式系统构造：

**模式 0：原始主题词 / 精确短语直搜（最先做，不许跳过）**
- **用简报的原词直搜，不要先替换成自己归纳的流派名或术语。** 归纳的框架未必是业内的叫法，一上来就换词会把标题里正好写着该主题的最相关文献整批漏掉。
  - 例："经济结构差异 出口贸易" 直搜，而不是先拆成 "要素禀赋理论""需求相似理论"
  - 例："protein language model drug discovery" 直搜，而不是先拆成 "ESM""AlphaFold"
- **加引号搜可能的标题短语**，看有没有论文标题正好就是这个主题（综述、benchmark 常这样命名）。
- **覆盖该领域实际发表的语言**：默认至少"提问语言 + 英文"各一轮；若该方向的文献明显集中在某语言（如中文政策、日文材料学），补该语言一轮。不预设任何单一语言，也不假设只搜英文就够。
- 直搜的作用有二：① 命中的高相关文献直接进核验；② 从这些文献的标题、关键词、被引里**归纳**出下一步的检索视角与模式 1-5 的关键词——**先搜再拆，不要先拆再搜。**

**模式 1：核心方法 × 应用领域**
- "retrieval augmented generation" + "question answering"
- "CRISPR base editing" + "clinical trial"

**模式 2：核心机制 × 目标任务**
- "chain of thought" + "scientific reasoning"
- "碱基编辑" + "遗传病治疗"

**模式 3：领域 + survey/benchmark/meta-analysis**
- "LLM agent survey 2024 2025"
- "social media adolescent mental health meta-analysis"

**模式 4：关键人名 × 方向**（当研究简报提到具体研究者时）
- "Haidt social media adolescent"
- "Orben screen time well-being"

**模式 5：已知论文的引用网络**
- 从已找到的核心论文的标题中提取关键术语，搜其被引/引用

每个模式至少试一轮。在多视角检索中，每个视角用 1-2 种模式构造关键词，3-5 个视角 × 每视角 2 轮 = 若干轮 `scholar_search` 调用。具体次数不设上限，以覆盖充分为准。

## 盲区发现

第二轮检索后做一次盲区检查：

1. **覆盖检查**：研究简报的每个子方向是否有 ≥3 篇文献？
2. **流派检查**：有没有明显的方法流派完全缺席？
3. **引用链检查**：已找到的论文引用的高频工作是否在列表里？
4. **弃置检查**（STORM moderator trick）："搜到了但没打算用"的结果是否指向未覆盖的子方向？不要扔掉它们——它们是盲区的线索。
5. **时间检查**：近 1 年有没有重要工作？全是老论文说明可能漏了新进展。

## 纵深：引用网络回溯与前向追踪

关键词检索会漏掉两类文献：一类是**大家默认知道、标题里不再写全称的奠基作**，另一类是**引用了奠基作的最新推进**。这两类要靠引用网络捞，不靠换关键词。对核心子方向（尤其争议大的）做这一步：

- **引用回溯（backward）**：翻已找到的核心论文的参考文献，捞出被多篇核心论文**共同引用的更早工作**。被 ≥3 篇核心论文共引的，基本是该方向的奠基作，**按"必纳入"处理**——漏掉奠基作是 Coverage 门禁的硬伤。
- **前向追踪（forward）**：用"被引检索"（Google Scholar / Semantic Scholar 的 Cited by）找**引用了奠基作的后续工作**，优先近 3 年。奠基作近 3 年零被引，可能该方向已冷或已被取代，标注存疑。
- **语义近邻**：用语义相似检索（Semantic Scholar、Connected Papers 等）找关键词没覆盖到的相关工作，特别留意**跨学科的相邻文献**。若语义检索结果与已有清单**重叠 >80%**，是覆盖趋于饱和的信号（见下）。

引用网络回溯同样受多语种约束：某语种的奠基作常只被同语种文献引用，只回溯英文引用网络会系统性漏掉它。

## 何时停：饱和判据

检索不是"搜够 N 篇就停"，也不是"无限搜下去"。用以下 5 条判据判断某个方向是否已覆盖充分，**满足 ≥3 条即可停止该方向的检索**：

1. **覆盖达标**：研究简报的每个子方向都有足够文献支撑交叉对比（每方向 ≥3 篇）。
2. **新增衰减**：最近一轮检索新增的有效文献 < 已有总量的 10%——再搜边际收益很低。
3. **主题饱和**：预期的主题/流派都已有文献落位，没有明显的空类别。
4. **引用闭环**：引用回溯不再发现清单外的高频共引工作——奠基层已捞干净。
5. **时间跨度覆盖**：既有奠基作，也有近 3 年的最新进展，时间轴没有断层。

**5 条都不满足、但同一方向已搜满 4 轮**：如实记一笔"检索局限：该方向未达饱和，可能存在未覆盖文献"，然后继续后续流程，不要无限循环。饱和判据是给"够了没有"一个可核查的答案，避免"搜一轮写一篇"的草率，也避免"永远差一篇"的空转。

## 按学科调整检索

不同学科的文献分布不同：

- **CS/AI**：arXiv 预印本为主，更新极快，近 6 个月的工作可能关键。搜 arXiv 关键词。
- **生物医学**：NEJM/Lancet/Nature Medicine 的临床论文，搜 "clinical trial" + 疾病名。
- **社科**：AER/QJE（经济学）、Nature Human Behaviour（心理学），搜效应量和方法（RCT/DID/IV）。
- **跨学科**：分别搜每个相关学科，再合并。不要只搜一个学科的关键词。

## 多语种文献与浏览器抓取

不同语种的学术库分布不同，只搜单一语言会漏掉相当一部分文献。按话题实际的语言分布并检：

- **通用/英文库**：Google Scholar、Semantic Scholar、arXiv、PubMed、RePEc/IDEAS、NBER、期刊官网。
- **其他语种库**：按方向选择，如中文的知网/万方/维普及各学科顶刊、日文的 J-STAGE、德法等语种的国家级库。用该语种的原词搜，不要只用英译术语。
- **拿题录/摘要**：`scholar_search` 之外，可用浏览器工具打开上述站点的检索结果页或文章页，抓取标题、作者、年份、摘要、关键词。付费库抓不到全文时**只在元数据层引述**，判 PAYWALL，不编造数字与方法细节。
- **跨语种并集**：各语种的命中先合并去重，再做盲区检查——某个子方向若只有一种语言有文献，要明确标出，这本身可能是 finding（如"该机制在某语种学界研究充分、其他语种罕见"）。

## 权威性与高引优先

检索不是"搜到就行"，而是"搜到该方向真正立得住的工作"。同一个话题的候选里，要主动向权威、高引、顶刊倾斜——它们既更可信，也是判断该方向脉络的锚点。

### 三条优先线

1. **奠基作 + 高引经典**：一个成熟方向总有被反复引用的少数几篇奠基/里程碑工作。识别信号：在多篇后续论文的引言/相关工作里被反复引用、被引数量显著高于同侪、常被冠以"seminal""classic"。这些必须进清单——漏掉奠基作是 Coverage 门禁的硬伤。
2. **顶刊 / 顶会**：优先来自该领域公认高影响力出口的文献（下方按学科给参考）。同一发现有顶刊版和预印本/普通刊版时，引顶刊版。
3. **权威综述 / meta-analysis**：一篇高质量综述或 meta 分析能一次性锚定该方向的主要工作与共识，且自带一份高质量参考文献网络，是发现更多高引文献的跳板。

### 怎么操作

- **看被引信号**：`scholar_search` 或浏览器打开 Google Scholar / Semantic Scholar，读"被引次数"排序；注意结合年份判断——近 2 年的新作被引低是正常的，不能只按绝对被引砍新工作（否则会系统性漏掉最新进展）。
- **顺引用网络上溯**：从已找到的高引论文的参考文献里，捞出被它们共同引用的更早工作（多半是奠基作）；再从"引用了它的后续工作"里捞该方向的最新推进。
- **顶刊定向搜**：在关键词后加期刊/会议名或用站点检索，直接定向到顶刊出口。

### 各学科权威出口参考（非穷举，按方向调整）

- **经济/金融**：AER、QJE、JPE、Econometrica、REStud、JIE；中文：《经济研究》《世界经济》《管理世界》《金融研究》《数量经济技术经济研究》。
- **CS/AI**：NeurIPS、ICML、ICLR、ACL、CVPR、TPAMI；预印本 arXiv 需结合被引与录用信息判断分量。
- **生物医学**：NEJM、Lancet、Nature/Science 系、Cell；看临床试验分期与样本量。
- **综合性顶刊**：Nature、Science、PNAS 常有跨学科重磅。
- **中文通用**：优先 CSSCI/北大核心/中文顶刊，警惕预印/学位论文/未经同行评议的网络文档（可作线索，不作权威引用）。

### 与权威性相关的红线

- **不因为"高引"就免核验**：被引高也可能被后续工作推翻，引述仍要核对原文；高引 ≠ 结论正确。
- **不为凑权威牺牲覆盖**：顶刊优先是"同等相关下优先"，不是只收顶刊——批评方、相邻领域、最新预印可能不在顶刊但恰恰是盲区所在。
- **权威性写进呈现**：综述里可通过"已被多项高引研究证实 / 某顶刊 meta 分析显示"传达证据分量，但仍受措辞分寸约束（见 `../../../references/hedge-calibration.md`）。
