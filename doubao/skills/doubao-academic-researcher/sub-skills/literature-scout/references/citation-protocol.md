# 引用核验协议

## 核验流程

对每条文献按两步核验：

**第一步：存在性核验**
用 `scholar_search` 搜论文完整标题（或关键片段 + 第一作者姓氏）。中文、英文及其他语种文献一律同标准核验；英文期刊/会议不能因为看起来像 SCI/SSCI、顶会或英文标题就免核验。
- 搜到、标题作者匹配 → 存在性通过
- 搜到但标题/作者有出入 → 标记，核实是否同一篇
- 搜不到 → 不等于不存在，但使用时必须标注"[未经核验]"

**第二步：引述准确性**
正文中引述的发现是否和论文标题/摘要一致。只有元数据可用时，不编造方法细节或具体数字。

**第三步：权威性核验**
每条核心文献都要核验其 `authority_signal` 和 `quality_basis`。中文文献可用 CSSCI、北大核心、中文顶刊等凭据；英文文献同样必须给出 SCI/SSCI/A&HCI/EI、JCR/中科院分区、影响因子、被引数、顶刊/顶会录用、经典奠基地位或官方/权威机构来源等凭据。不能只写“英文期刊”“SCI/SSCI期刊”这种空泛标签。

## 怎么算"匹配"：核验强度细则

"搜到了"不等于"核验通过"。判断一条命中是否算数，用以下标准，从强到弱：

- **标题相似度**：把候选结果的标题和你要核验的标题逐字比对。**高度吻合（仅大小写、标点、副标题截断的差异）才算命中**；只是主题相近、关键词重合但标题明显不同，不算——那是"另一篇相关论文"，不是你要找的这篇。年份需一致（±1 年容差，预印本转正刊常跨年）。
- **DOI 优先**：有 DOI 时先用 DOI 反查。DOI 是唯一标识，比标题搜更硬。
- **DOI 能解析、但标题对不上 = 幻觉信号**：如果一个 DOI 能解析，但它指向的论文标题和你要核验的标题**明显不是同一篇**，这不是"核验通过"，而是一个**已知的幻觉模式**（编造引用时凑了一个真实存在但不相关的 DOI）。判 MAJOR 或 UNVERIFIABLE，不能因为"DOI 真的能打开"就放行。
- **多源交叉**：单一检索源查不到 ≠ 不存在（尤其新预印本、非英文、灰文献常只被部分索引收录）。**换一到两个独立学术源再查**——多个独立源都查不到，编造嫌疑显著上升；某个源有、别的没有，可能只是收录差异，按存在处理但记录来源。
- **低等级源优先核验**：预印本、会议短文、灰文献、非顶刊来源更值得逐条核验；高引顶刊也不免核验（见"编造引用的零容忍"），但抽检可倾斜到低等级源。

**判断原则**：这些标准是给"这条到底算不算核验通过"一个可核查的答案，替代"搜一下感觉有就行"。拿不准的落回下面的灰区原则——不使用。

## 5 级判定

| 判定 | 含义 | 允许使用 |
|---|---|---|
| VERIFIED | 存在，引述一致 | ✓ |
| MINOR | 存在，措辞微偏差 | ✓ 修正后 |
| MAJOR | 存在，引述不符 | ✗ 修正或删 |
| UNVERIFIABLE | 无法确认存在 | ✗ |
| PAYWALL | 存在但元数据不足 | △ 限于元数据层 |

## 灰区 = 不使用

无法确认的引用不进综述。"好像有一篇论文做过 X"但搜不到 → 不引用，用 `[该方向可能有相关工作但未检索到]` 占位。

## 来源质量分级（强制）

不是所有核验通过的文献都能当核心证据。每条文献必须按来源质量分级，决定它能进入综述的哪一层论证。

### A/B/C 三级

| 等级 | 标准 | 允许用途 |
|---|---|---|
| **A** | 本学科权威期刊/顶会、权威出版社专著、高引经典（被引 > 同类均值 3 倍以上）、权威综述/meta-analysis、正式一手材料/档案 | 核心证据、概念定义、机制解释、反证 |
| **B** | 普通核心期刊（如 CSSCI/北大核心/SCI/SSCI 非顶刊）、正式学术期刊、可靠会议论文、正式馆藏图录、可靠学术专著 | 核心证据、概念定义、机制解释、反证 |
| **C** | 一般期刊、质量一般但可查的补充文献、非正式出版物 | 只能作背景补充、线索或次要支撑，不能单独支撑核心判断 |
| **grey** | 网页、新闻、博客、非正式报告、未同行评议的预印本 | 只能作背景线索或案例说明，不能作为正式学术引用 |

**核心论证铁律**：支撑核心判断、概念定义、机制解释、反证的文献，必须是 A 或 B 级。C 和 grey 级文献即使核验通过、内容相关，也只能作背景线索，不能放进核心论证链。

### authority_signal（必标）

每条 A/B 级文献必须标注 `authority_signal`，说明它凭什么可信：

| 信号 | 含义 | 典型场景 |
|---|---|---|
| `top_journal` | 发表在学科公认顶刊/顶会 | Nature/Science/学科顶刊/CCF-A |
| `high_citation` | 被引显著高于同类 | 该方向奠基作或广泛引用的方法论文 |
| `classic` | 学科内公认经典 | 教材级、必引文献、长期被引 |
| `official` | 官方/权威机构发布 | 指南、专家共识、政策文件、国家标准 |
| `core_journal` | 正规核心期刊但非顶刊 | CSSCI/北大核心/SCI 非顶刊 |
| `not_established` | 来源可信度未建立 | 只能标 C 或 grey，不能作核心证据 |

不要只在正文里口头说"这篇很权威"——必须落在 `authority_signal` 字段里。没有 `authority_signal` 的文献，默认不能进入核心论证。

### 正向质量凭据（替代黑名单）

核心证据不能靠“不在垃圾刊名单里”放行，而必须靠**正向凭据**证明它为什么可信。不要使用刊名子串黑名单做一刀切判断——这会误伤一些领域的正当期刊或专业来源。判断一篇文献能否作为核心证据，优先看它是否能提供以下凭据之一：

- **核心/权威收录**：中文文献看 CSSCI、北大核心、中文顶刊等；英文文献看 SCI/SSCI/A&HCI、EI、权威出版社、正式馆藏等。
- **影响力指标**：影响因子、JCR/中科院分区、显著高被引、Google Scholar/Semantic Scholar 被引明显高于同类。英文期刊必须尽量给出 JCR/中科院分区、IF 或被引等可核查凭据。
- **领域出口**：学科公认顶刊/顶会（如 AER/QJE/《经济研究》、NeurIPS/ICML/ACL、NEJM/Lancet 等，按学科调整）。
- **经典/奠基地位**：被多篇后续核心文献共同引用，常被称为 seminal/classic/foundational。
- **官方/共识来源**：权威机构、指南、专家共识、国家标准、一手材料/档案。

**红线**：如果一篇文献无法给出具体 `quality_basis`（如 CSSCI、IF=8.2、被引 1200+、ACL 主会、领域奠基作、官方指南等），它不能作为核心证据。可查、相关、标题很像，都不等于可作为核心证据。

### url 要求

每条正式参考文献必须记录 `url`（原文/DOI/期刊页/学术入口链接）。url 有两个用途：
1. 供文末参考文献逐条附可点击链接，读者可直接核验。
2. 供内部核验时通过 DOI 反查确认标题匹配。

正文不放 url。所有文献链接集中到文末参考文献。

### read_status 约束

| 状态 | 含义 | 允许用途 |
|---|---|---|
| `full_text` | 已读全文 | 可写精确数字、方法细节、样本量 |
| `abstract` | 只读了摘要/题录 | 只能写摘要层概括，不得编造具体数字和方法细节 |
| `metadata_only` | 只有题录元数据 | **不能支撑核心判断、概念定义、机制解释或反证**；只能作背景线索 |

进入核心论证的文献，`read_status` 不能是 `metadata_only`。

## 正文引用格式（作者-年份夹注制）

正文引用一律用**作者-年份夹注制**（对应 GB/T 7714 著者-出版年制），不用 `[1]` 数字编号。按作者人数分写，**最易错的是两位作者——两位必须写全两个姓氏，只有三位及以上才用"等/et al."**：

| 作者数 | 叙述式 | 括注式（句尾） |
|---|---|---|
| 1 位 | `张三（2021）` / `Smith（2020）` | `（张三，2021）` / `（Smith，2020）` |
| 2 位 | `张三和李四（2021）` / `Smith and Jones（2020）` | `（张三和李四，2021）` / `（Smith & Jones，2020）` |
| ≥3 位 | `张三等（2021）` / `Smith et al.（2020）` | `（张三等，2021）` / `（Smith et al.，2020）` |

- 两位作者写成"张三等（2021）"是**错的**；"等/et al."只用于三位及以上。
- 中文语境用全角括号，括注式内作者与年份间用中文逗号"，"，多篇间用分号"；"。
- 文末参考文献条目仍列全部作者（或 GB/T 7714 前 3 名 + 等/et al.），此人数简写只用于正文夹注。完整示例见 `references/output-structure.md` 的"正文引用格式（作者-年份夹注制）"。

## 引用簇限制

正文引用必须克制，不能用引用堆替代分析。

- **同一处引用最多 3-4 篇**。一个括号或同一句最多放 4 条作者-年份引用；优先 1-3 条。
- 如果需要引用 5 篇以上才能支撑一个判断，说明这个判断应该**拆成多个子判断**，或者这些文献之间的关系需要被解释（收敛/冲突/互补/阶段推进），而不是堆在一起当背景。
- **禁止引用堆砌**：出现 `（张三等，2021；李四，2020；王五，2019；……）` 一长串、但正文没有说明这些文献之间关系的，属于引用堆砌，必须重写。
- 如果删掉引用后该段只剩"某某认为、某某指出"的堆叠，说明文献解释失败。

## 编造引用的零容忍

编造引用是红线。检测信号：
- 标题太完美匹配你想引用的观点
- 作者+标题+年份+期刊组合完全搜不到
- 同一作者在列表中出现过多次但你只搜到过一次
- DOI 能解析但指向的论文标题与引述标题明显不是同一篇

发现编造 → 立刻删除 + 检查依赖该引用的所有判断是否还站得住。
