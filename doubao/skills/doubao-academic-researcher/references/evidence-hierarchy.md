# 证据分级：金字塔与双轴定级

综述里每条判断的分量，取决于它靠什么证据支撑。给证据定级不是打分游戏，是为了让措辞分寸（见 `hedge-calibration.md`）和矛盾消解（比证据等级）有一个可核查的依据。

这份分级由 literature-scout 定级、research-synthesis 在建文献矩阵和消解矛盾时使用。

## 7 级证据金字塔

按研究设计的因果推断强度从高到低：

| 等级 | 证据类型 | 分量 |
|---|---|---|
| **I** | 系统综述 / meta-analysis（预注册、多库检索、含质量评估） | 最高 |
| **II** | 随机对照试验（RCT） | 很高 |
| **III** | 非随机对照研究（准实验：DID、PSM、断点回归等） | 高 |
| **IV** | 队列 / 病例对照研究（观察性、纵向或回顾） | 中高 |
| **V** | 描述性 / 质性研究的系统综述 | 中 |
| **VI** | 单个描述性 / 质性研究（案例、民族志、调查） | 中低 |
| **VII** | 专家意见 / 委员会报告 / 社论 | 最低 |

金字塔顶层控制混杂、能支撑因果断言；底层富于语境但难以外推。**"权威" ≠ "证据"**：一篇顶刊社论仍是 VII 级。

## 双轴定级：设计层级 ≠ 学科内适配度

只用金字塔会犯一个系统性错误：**把人文和质性工作一律压成低级**，无论它在自己传统里多出色。定级要分两个正交的轴：

- **研究设计层级**（绝对、跨学科中性）：这项研究的设计落在"实验—描述"阶梯的哪一层。一个单一质性案例研究是 VI 级，不管它出现在医学还是历史学。
- **学科内适配度**（相对、看学科规范）：对**它要支撑的那个断言**，这个源是否达到**其所在学科的黄金标准**。一手档案史料是 VI 级设计证据，但同时可能是史学解释性断言所能拿到的最强证据。

**关键规则**：判断一个源"够不够强"，看的是**适配度**，不是原始设计层级。当一个源的设计层级达到或超过**其所在学科的黄金标准**（见下表），它对该断言就是强证据——哪怕它只是 VI 级。所以人文领域的 VI 级一手文献，在 VI 级正是该学科黄金标准时，是强证据。

### 各学科黄金标准参照

| 学科 | 黄金标准 | 常见层级 | 说明 |
|---|---|---|---|
| 医学 / 健康 | I–II（RCT、meta 分析） | I–III | 循证医学传统 |
| 教育 | III–IV（准实验） | IV–VI | 随机化常不可行 |
| 社会科学 | III–V | IV–VI | 混合方法常见 |
| 政策 | IV–V + VII（专家panel） | V–VII | 语境依赖，专家意见有价值 |
| 人文 | VI（一手文献） | VI–VII | 认识论不同，"证据"含义不同 |
| 技术 / 工程 | III + 行业报告 | V–VII | 领域快，同行评议滞后于实践 |

一个源用错轴评就会误判：拿 RCT 的标准去要求一篇史学论文，或拿"顶刊"去给一篇一手档案降级，都是把双轴压成单轴的错误。

## 时效轴：与断言相关，不是一刀切

时效是**独立的第三个考量**，而且**与断言相关**——不是越新越好：

| 领域速度 | 可接受时效 | 例子 |
|---|---|---|
| 快 | 2–3 年 | AI/ML、社交媒体 |
| 中 | 5–7 年 | 教育政策、组织行为 |
| 慢 | 10–15 年 | 历史分析、经典理论 |
| 奠基性 | 无限制 | 里程碑 / 奠基工作 |

**断言相关**的意思是：当断言就是关于某个源本身或它所处时代时，不因其"老"而扣分（一手史料、奠基作）；只有当断言依赖时效（如"该领域当前最新水平"这类实证性判断）时，才套用上面的年限。这与 literature-scout"时间筛选是为抓新进展，不是误杀经典"的纪律一致。

## 掠夺性 / 幻觉信号（一票否决，与层级无关）

无论落在哪一级，出现以下信号先解决再谈定级：

- **掠夺性期刊**：未被 Scopus/WoS/DOAJ 收录、出版商非 COPE 成员、超短审稿周期、编委不可考、期刊范围大得离谱。
- **利益冲突**：作者评估自己机构的项目、产业资助方向性研究——如实标出让读者判断，不必然排除。
- **幻觉引用信号**（核验层面，见 `../sub-skills/literature-scout/references/citation-protocol.md`）：标题"太完美匹配"观点、作者+标题+年份+期刊组合完全搜不到。

这三类不是"低一级"的问题，是"能不能用"的问题：掠夺性和幻觉信号触发核验流程，证实不存在的一律不用。
