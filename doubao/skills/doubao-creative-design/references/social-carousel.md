# 社媒套图与轮播

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物按[主入口](../SKILL.md)执行适用的数量门禁，不做其他成品检查；长图段图和拼接成品生成后立即交付，不做生成后计数或质量检查。

**目标**：以逐页独立阅读和有序翻页推进同一传播任务，保持信息完整、系列统一与正常尺度可读。

**适用**：社媒轮播、知识套图、活动套图及其他按页阅读的独立系列图片。连续长图不能机械切片当作套图，单张封面不等于整套任务。

**核心流程**：明确产物与阅读条件 → 组织内容与页序 → 设计系列与各页 → 核对阅读与翻页关系 → 交付完整套图。

## 1. 明确产物与要求

- 保持整套同宽高，遵守用户指定的尺寸、页数和顺序。把单页作为完整发布单位，不靠增高锁定画布、隐藏溢出、整版缩小或拼成长图容纳正文。
- 区分缩略图与正常阅读：缩略图用于识别主题、主体和必要吸引点；正常尺度用于阅读正文、条件及来源。放大清楚不能替代正常尺度可读。
- 区分轮播套图、独立头图与九宫格组合。独立头图由[主入口](../SKILL.md)另选对应题材；九宫格兼顾单图裁切边和组合切线，不用头图比例覆盖轮播内页。
- 路线、批准与编辑范围见 [主入口](../SKILL.md) 和 [edit](edit.md)；事实、身份及需求记录见 [common](common.md)。纯图顺序见 [produce-image](produce-image.md)，可编辑套图封面前置见 [produce-hybrid](produce-hybrid.md)。

### 按实际轮播版位选择画幅

以下画幅、安全区及避让规则见 [platforms](platforms.md)，均为未经外部核验的内部历史参考，不代表现行官方标准。先核对真实版位，不把平台内容气质当作投放依据。

| 采用条件 | 画幅参考与具体动作 |
|---|---|
| 小红书图文轮播 | 默认3:4，适合时用4:5；分别采用对应避让区，突出真实内容价值，不仿平台UI；卡片、大字报、人物及点缀遵守平台专项 |
| 抖音／快手图文轮播 | 参考9:16；抖音突出强焦点与动势，快手突出真实场景、动作及实物细节，不强制红黄大字报 |
| B站实际横向图文版位 | 参考16:9；保证主体与标题缩略可识，按实际版位避让右下角标，不自动加侵权IP、假弹幕或伪分区 |
| 朋友圈独立系列图片 | 默认1:1，明确用途可用3:4；保持单图完整，不仿红包、点赞或播放条 |
| 未指定平台 | 按真实用途从4:5、3:4、1:1、9:16或16:9选择，保留四周安全边界，不引入连续长页高度 |

平台互动、价格、承诺和信任背书须有依据。

## 2. 内容链与页面职责

### 先组织完整信息，再分配页面

先判断读者需要答案、方法、规则还是人物事件认同。每页围绕一个主结论，可兼一个辅助职责；让证据支持主张，条件与例外完整，行动由前文导出。不让每页都变成口号，不为悬念推迟必要答案，不删除支撑直接跳到奖励或CTA。

| 页面采用条件 | 文字组织动作 | 图像组织动作 |
|---|---|---|
| 需要建立第一阅读入口 | 封面回答“是什么、为什么继续看”；用短说明承担第二阅读层，不塞全部规则 | 让标题与具体主体形成第一视觉；除明确大字报或纯文字命题外，保留可识别的人物、商品、物件、场景、插画或图形主体 |
| 需要说明问题 | 呈现处境、冲突及待解决问题 | 对应相关对象、场景或动作，不用无关情绪图代替问题 |
| 需要解释知识 | 组织定义、解释和示例 | 解释概念、结构或差异，让图注逐一对应 |
| 需要指导操作 | 交代动作、顺序和完成状态 | 保留手、操作接触点及结果，不只列步骤名 |
| 需要支持结论 | 让来源、条件邻接结论 | 使用真实记录或有依据的图表，不以生成图冒充证据 |
| 需要查找规则 | 分组呈现条件、例外和入口 | 用必要分组及标注辅助扫描，不强制新增内容图 |
| 需要收束 | 总结行动或价值，不新增未经解释的承诺 | 强化真实入口或主题收束；联系方式和短总结不强制配图 |

### 按任务选择内容链

| 采用条件 | 内容组织动作 |
|---|---|
| 活动传播 | 串联价值 → 参与方式 → 参与方向 → 权益 → 行动 |
| 教程说明 | 串联问题 → 结论 → 方法 → 示范 → 误区 |
| 攻略检索 | 按场景分类 → 对应用法 → 条件与提醒组织 |
| 人物与品牌叙事 | 串联背景 → 事件 → 转折 → 真实细节 |
| 产品介绍 | 串联场景 → 功能 → 证据 → 使用 |
| 公益倡议 | 串联事实影响 → 误区 → 方法 → 行动 |
| 招聘传播 | 串联业务 → 岗位 → 职责资格 → 福利成长 → 投递 |
| 专题展开 | 串联背景 → 展开 → 关键节点 → 回看 |

- 按需取舍、合页，不要求每个环节单占一页。轻量传播可参考3–4页，一般解释可参考5–7页；复杂教程、多案例、完整规则或专题确有需要时再考虑8–10页，不凑页，不改变用户锁定数量。
- 相邻页的结论、素材和动作高度重复时，优先检查能否合并；页数锁定时，在授权内容范围内重新分工。内容不足可补必要解释及明确示例，不制造事实。
- 保持每页独立主题及必要上下文。完整标题、步骤、证据和必要信息不跨页切断；让准确文案进入成品，排除规划说明。
- 按内容选择照片：主镜头突出人物状态或核心对象，环境与动作交代使用过程，特写补充细节证据。空镜、光影或第一视角用于转场，数量随内容确定。
- 保持真实商品、人物及品牌身份，保护包装标签和Logo；版式参考不授权复制其中身份与文字。比较页保持同尺度、同视角、同条件，不通过裁切造差异，不为统一调色使肤色、食物或证据原色失真。

### 按内容选择照片组合

| 内容 | 选图与组织 |
|---|---|
| 穿搭与造型 | 用完整造型建立重点，搭配半身、侧背面、面料或鞋包细节；拆解搭配时，将单品与造型图对应排列。 |
| 美妆与测评 | 用妆效或商品主图配质地、色样和使用细节；比较效果时并置同条件照片，让说明对应可见差异。 |
| 探店与日常记录 | 用场所、人物动作和物件细节交代经历；按时间或体验顺序排列，短注说明地点、行为或感受。 |
| 教程与操作 | 展示关键动作、操作部位和完成状态；连续步骤保持观察方向，难点用局部放大说明。 |

## 3. 系列机制与页面重组

### 按页面职责匹配模板与资源

1. **初选方法。** 根据第2章的页面职责、文案容量、图像数量与画幅，从下方布局、风格表初选方法；已有有效方案只处理新增或获准替换部分。可编辑套图的内页选型在当前封面获批后进行，此前只规划内容、容量与素材需求；纯图任务沿入口路线执行。
2. **按范围取词。** 构图查询“社媒套图”及“通用”；容器、点缀、材质和特效分别查询通用对应组。取下表中的单个词查询，不把不同方法串成必选条件，真正同义词才用 `|` 合并。表中风格词是名称关键词，工具的 `--style` 标签另以 [templates](templates.md) 的词表为准。
3. **读取后适配。** 按 `match → describe → read` 完整读取候选和必要依赖，用真实文案、图片比例和目标画幅判断整页或局部采用。区域母版连同布局与页面读取；通用长页只借适合单页的局部关系。无合适候选时沿已选方法设计。
4. **逐页落实。** 在同一 Brief 记录选型与调整，保持系列字体、配色和边缘语言，按各页职责重组布局。同类步骤或证据可复用结构，不用模板槽位倒推内容；制作后逐页检查，并排和按序核对系列关系。

### 明确文字与图像分工

- 完整纯图各页承载准确文案；可编辑作品保留指定文字的独立编辑能力，包括封面。独立艺术标题的适用条件按[混合制作](produce-hybrid.md)执行，不因标题标签批量转成图片。
- 先确定字形、字重、断行与层级，再添加字效；数字、单位、条件和来源就近成组。照片、插画说明具体内容，不重复叠加图内已有文字、容器或光效。

### 固定机制，不固定封面坐标

优先遵守用户锁定、品牌规范和明确参考；局部改材质不授权重做整套。把媒介、感受与排除项落实为可见关系，不用“高级”等标签代替设计。

| 采用维度 | 具体动作 |
|---|---|
| 构图 | 明确主体重心、阅读方向、对齐、疏密及图文关系；按页职责重组入口与收束 |
| 字体层级 | 固定标题与正文字体职责，控制字形、字重、尺度、断行和强调方式 |
| 颜色职责 | 区分主色、辅助色、重点色及事实信息用色；跨页保持语义一致 |
| 形状边缘 | 统一几何或自由轮廓、圆角、切角、撕边、描边与裁切语言 |
| 材质 | 统一表面特征、纹理尺度与制作效果，避免各页像来自不同媒介 |
| 图像处理 | 统一摄影或插画方式、光向、调色和边缘处理；按内容改变景别与取景 |

从当前真实封面及适用的分层实现提取系列机制，不从Prompt假称提取。内页按自身职责、容量和画幅选择结构，不机械移植封面巨字、破框、主体数量、容器与留白。适用路线的视觉家族比例、辅助母题及空间关系硬条件见 [produce-image](produce-image.md) 和 [produce-hybrid](produce-hybrid.md)。

### 选择单页布局

以下为社媒套图的布局候选。按真实页面职责选择，区域母版的示例页数、尺寸和槽位不作为当前任务要求。

| 内容与页面采用条件 | 具体组织方法 | 可检索词 |
|---|---|---|
| 封面或收束页需要单一焦点、明确秩序 | 大留白用于结论完整的低密页面；居中对称用于稳定焦点，不为对称添加无关主体 | 构图·社媒套图：`大留白聚焦式`、`居中对称式` |
| 封面或内容页需要主对象与周边解释 | 中轴包围用于围绕主轴组织信息；环绕散点用于关联项；四角框定用于边缘辅助信息，均保护正文净空与安全区 | 构图·社媒套图：`中轴包围式`、`环绕散点式`、`四角框定式` |
| 封面需要动势，内容页需要层次或前后关系 | 对角穿插借方向关系；叠层错位借前后关系，不遮挡事实与身份，不用于扭曲平行比较 | 构图·社媒套图：`对角穿插式`、`叠层错位式` |
| 内容页需要图文分工，或比较页需要并置 | 左右分栏、上下分区按画幅及文案容量选择；比较双方保持同尺度、同视角、同条件 | 构图·社媒套图：`左右分栏式`、`上下分区式` |
| 内容页需要扫描多个同类项目或证据 | 网格矩阵用于同类项对齐；横向分带用于分组或阶段分层，不预设项目数量 | 构图·社媒套图：`网格矩阵式`、`横向分带式` |
| 步骤页需要明确顺序或路径 | 阶梯递进用于阶段推进；曲线动线用于有方向的操作或导览，保留完整动作、顺序与完成状态，不把必要步骤切断 | 构图·社媒套图：`阶梯递进式`、`曲线动线式` |
| 规则、专题或叙事内容需要导读与多层信息 | 侧栏导读用于索引与正文分工；杂志跨栏用于标题、正文与图像的编辑关系，不借跨栏拆断完整信息 | 构图·社媒套图：`侧栏导读式`、`杂志跨栏式` |

照片为主时，按下表组织画面；这些是设计方法，不代表模板库已有同名模板。

| 照片构图 | 适用内容与做法 |
|---|---|
| 主图配辅助图 | 穿搭、美妆或人物介绍：放大完整造型或核心对象，旁侧用小图补充动作、环境和细节。 |
| 非对称编辑网格 | 时尚、城市生活或设计分享：让主图跨栏，辅助照片与短注沿共同轴线排列，以大小差区分主次。 |
| 连续照片与分镜条 | 日常记录按时间、地点或动作排列小幅照片，并突出关键瞬间；教程按动作与结果排列，保留清楚顺序。 |
| 满版场景配细节窗 | 探店、旅行或体验：用场景交代环境，局部小图补充难以看清的细节，文字放在低干扰区域。 |
| 物件标本板与对比联图 | 搭配拆解用物件、色样与短注一一对应；测评将比较对象并置，保持同尺度和同条件。 |
| 叙事拼贴 | 照片日记或活动记录：主图配不同景别的辅助照片，以尺度差、局部叠压和纸边建立层次，保留关键画面完整。 |

### 选择视觉风格与表现方法

以下风格从通用构图查找，借用相关图文、色彩与媒介关系，再适配为独立单页。它们不是社媒套图专属模板，不沿用样例的内容与长页结构。

| 内容采用条件 | 具体表现方法 | 可检索词 |
|---|---|---|
| 知识、规则或证据需要理性信息层级 | 用清楚字级、对齐网格和图注组织结论与证据，不把科研视觉当作真实科研背书 | 构图·通用：`理性信息风`、`证据信息网格` |
| 人物、文化或专题叙事需要出版感 | 用大小图、长短文字栏和栏目细线建立出版感，插画对应具体内容，保持单页阅读完整 | 构图·通用：`人文出版`、`时尚杂志` |
| 记录、活动或资料组织适合纸本拼贴 | 主纸面承载正文，照片与票据补充记录；用纸边、接触阴影和局部叠压区分层次 | 构图·通用：`纸本拼贴`、`纸感编辑`、`票据档案` |
| 内容适合鲜明、活跃的波普表达 | 用高对比色块、粗标题和主体剪影形成焦点，局部错位、网点或涂鸦加强动势 | 构图·通用：`波普拼贴` |
| 文化、品牌或生活主题适合当代东方／新中式表达 | 以器物轮廓、笔势或纹样组织图文，用疏密和留白突出主题，颜色从内容与参考中选择 | 构图·通用：`当代东方`、`新中式风`、`传统纹样` |
| 知识解释或亲切表达适合涂鸦手作 | 用手绘线条标注重点，插画解释对象或动作，编号与短注说明顺序 | 构图·通用：`涂鸦手作` |
| 自然、生活或材料主题适合质朴表达 | 用木、纸或织物的自然纹理配稳定墨色，保留材料触感与疏朗图文，不照搬模板题材 | 构图·通用：`侘寂质朴` |
| 技术、产品或界面主题需要清晰分层 | 用面板分组和强调色标明信息层级；透明层表现透底与边缘，金属层表现反射与结构 | 构图·通用：`清透光感` |
| 主标题与影像共同建立视觉入口 | 让标题断行贴合主体轮廓或画面留白，建立字与图的前后关系；内页按内容密度调整字级 | 构图·通用：`字体潮流` |

#### 单页组合示例

示例说明标题、主体与信息面如何共同成像，可按内容借用，不增加候选轮次或固定槽位；系列继承可见机制，各页仍按自身职责重组。

| 适用内容 | 组合关系 | 内页如何展开 |
|---|---|---|
| 人物故事／活动记录 | 人物与大标题共同聚焦，文字沿轮廓或动作留白组织，影像色与强调色呼应。避免普通页眉与人物各占一块。 | 转入事件、动作或细节，短注邻接对应照片；保留字形与影像语言，不复制封面姿态和巨字位置。 |
| 攻略／手账计划 | 主纸面承载完整信息组，照片或主题物从边缘切入，便签补充；纸色、墨色与索引色分工，避免一句一卡。 | 按分类、步骤或提醒调整纸面分区，边缘与接触阴影一致，不为手账感堆无关票据。 |
| 知识／测评解释 | 主对象与结论邻接，局部放大或可比图支持说明，颜色与标注对应同一部位或类别。避免背景装饰掩盖解释关系。 | 根据问题选择全貌、结构或同条件对比，维持编码与说明轴，不将所有页做成相同放射标注。 |

### 组织背景、容器与层次

| 采用条件 | 具体动作 |
|---|---|
| 多页共享同一视觉空间 | 区分全局底面、组级背景和局部覆盖；光向、透视、尺度、净空与材质相容时共享底面或同源变体，真正换章再改变 |
| 主题需要材质或空间表达 | 选择有职责的纹理、肌理、渐变或场景关系，控制尺度与疏密；阅读区保持低干扰。背景及纯色适用边界见 [produce-image](produce-image.md)，不在本题材另设强制纹理配额 |
| 内容需要独立扫描、比较或承托 | 先确定容器的内容、边界、主次、留白和遮挡，再选择轮廓与材质，不给每句话套框 |
| 对齐和段距已足够组织信息 | 采用开放排版，用对齐、段距和分隔建立结构，不强加卡片或嵌套 |
| 采用文件夹、票券、对话框或信纸 | 让载体对应真实信息关系；文件夹呈现可见页签，不靠名称宣称实现 |
| 采用中性矩形卡片 | 用于明确分组，不无差别铺满整页；按信息权重安排主辅，不预设卡片数量或面积倍率 |
| 内容需要突出主次或方向 | 按需选择错位、倾斜、叠压、非对称、堆叠、路径或自由轮廓，不为变化扭曲平行比较 |

按上述职责选择局部资源，外框、图片承托与表面分别查询。

| 局部用途 | 设计动作 | 可检索词 |
|---|---|---|
| 资料分类与纸面载体 | 页签对应栏目，纸面与内容分层；开放排版足够时不加外壳 | 容器·通用：`文件夹轮廓`、`绕线档案袋`、`卷纸与垂挂公告面` |
| 票券、提示与角色对话 | 凭证或场次采用票券；对话尾部指向发言主体 | 容器·通用：`票券与缺口`、`侧尾对话框` |
| 照片与手作拼贴 | 纸边承托图片，短观点可用撕纸；证据图保持平直可读 | 点缀·通用：`照片衬纸与胶带`；容器·通用：`不规则撕纸边` |
| 章节入口与中式图窗 | 按章节或文化主题选拱顶、花瓣窗；取景保留主体识别部位 | 容器·通用：`拱顶章节面板`、`拱形图片窗`、`中式花瓣窗框` |
| 必要功能分组 | 按主辅安排边界与留白，不把每句话装卡 | 容器·通用：`圆角矩形细描边`、`直角矩形无描边` |
| 纸面与印刷 | 纹理随纸面，套印只作用于适合的装饰或图形区域 | 材质·通用：`纤维纸张`；特效·通用：`轻纸纹`、`套色网印与错版颗粒` |
| 柔和色场与织物 | 按已选媒介使用；控制纹理尺度，文字区域降低干扰 | 特效·通用：`细颗粒柔雾色场`、`织物手作`、`格纹布与经纬细纹` |
| 透明承托层 | 结合后景表现透光和磨砂，仍保持文字对比 | 材质·通用：`半透明塑料`、`磨砂玻璃` |

不生产完全遮挡且无其他职责的底图。文字净空、临时灰黑底板／雾带／压暗横带限制和接缝保护见 [common](common.md)；不以素材失败为由偷换已定背景。

### 让变化服务内容推进

- 保持标题／正文字体职责、主色职责、素材边缘、背景语言、品牌识别与页码样式稳定，以整体识别而非变化项数判断系列成立。
- 当结论、动作或阅读任务改变时，按需调整主体位置、尺度、图文比例、镜头、容器或密度。只换标题与底色不能代替内容推进，也不要求相邻页固定改变若干项。
- 比较页、同类证据和连续步骤可复用主布局，以同尺度、同口径支持判断，不为避免重复而强行变版。内容不同却只机械替字时，再调整结构。
- 叠压用于建立前后关系，不按固定面积百分比执行。保护脸、操作接触点、商品识别面、Logo、二维码、数字单位与行动入口。
- 巨字被主体遮挡时，确保每个语义关键词仍能直接辨识，首尾字符不得同时遮挡，事实文字保持完整；不以字面保留比例替代实际识读。

## 4. 容量、字体与正常阅读

### 用真实内容试排

用真实文案、选定字体和主素材比例判断容量。存在不同可行关系时再比较兼容布局，不要求固定试排数量；字体选型与加载见 [fonts](fonts.md)。

| 实际问题 | 调整动作 |
|---|---|
| 内容较少但结论完整 | 保留有意留白，或以有语义的图像承接，不用口号与装饰强填 |
| 信息组拥挤 | 重分组、扩展文字容器、调整图文比例，减少不承担语义的留白和装饰，保留必要间距 |
| 规则、条件或案例密集 | 采用清楚的栏目、分组标题、对齐与高密布局，让条件邻接结论，不只缩小正文 |
| 图片占用过多但细节不重要 | 调整景别或图窗比例，仍保留定位、身份与必要上下文 |
| 原布局无法支持正常阅读 | 更换适合该职责的结构；页数可调整时拆成独立完整单页，补齐入口与承接 |
| 页数、尺寸锁定且仍无法容纳 | 在原范围内重排；仍不足时请求内容取舍，不擅删事实、锁定文案或改变页数尺寸 |

不把字数估算、模板容量比或无溢出当作可读性证明；不使用固定压缩百分比决定是否合格。

### 保留实际阅读尺度基准

以下 **516×696** 为内部排版基准，不是平台官方标准。其他画布按短边比例换算，再依据适用安全区和实际阅读结果收紧。

| 适用项目 | 基准与动作 |
|---|---|
| 主标题／模块标题 | 主标题最多2行、≥34px；模块标题≥18px，检查断行与第一阅读层 |
| 正文／辅助文字 | 正文≥13px、行高≥1.4；辅助文字≥10px，在正常阅读尺度确认条件和来源可读 |
| 边界净距 | 左右安全区≥31px；上下关键净距≥28px，同时满足实际版位避让 |
| 内容间距 | 模块距≥14px；正文内边距≥18px，防止相邻信息串组 |

原生实现核对真实字号和几何，位图核对对应阅读效果，不从文件像素反推CSS字号。有效字号、导出采样和字体回退后的测量见 [produce-code](produce-code.md) 与 [quality](quality.md)。

## 5. 翻页关系与专项可用性

### 建立可理解的页间衔接

按内容安排密度，低 → 中 → 高 → 中／低仅作起点，不强凑高密度重点页，也不连续安排空洞大字页。优先让每个页间关系围绕一条清楚的主线，说明对象、方向和位置如何承接；尾页只收束。

| 采用条件 | 翻页动作 |
|---|---|
| 需要定位进度 | 固定页码位置与样式，明确当前阶段 |
| 使用色块或纸层延续 | 延续边缘与方向，同时保持各页独立阅读 |
| 主体具有动作方向 | 用视线、手势或运动方向引导下一页，不截断关键动作 |
| 从全貌进入细节 | 保留对象定位，以新结论推进，不重复同一图与同一结论 |
| 内容进入新章节 | 在稳定色彩职责内调整重点色，按章节需要使用，不随机换色或限定变化次数 |
| 前页提出问题 | 及时给出答案，不把完整必要信息拆成悬念 |

连续场景须有同母图、连续裁切或可验证共享背景依据；不得把两张独立完整主图用渐变、蒙版或混合模式融合成假连续空间。

## 6. 必要交付组织

| 产物条件 | 交付动作 |
|---|---|
| 完整图片套图 | 按约定数量和既定页序逐张展示、交付独立完整图片；封面、内页和尾页依任务成立，不强行补页凑数 |
| HTML套图 | 保留每页独立完整HTML源及同版本、同尺寸真实预览，一一对应；不以截图、代码片段或一份长页源替代 |
| 用户明确需要总览 | 仅用于并排查看，不计成品页数，不替代逐页展示与交付 |

独立图与套图保持各自独立，非用户要求不拼成长图，不自动附加其他产物或承诺后台发布。主体图、背景、独立标题等模块素材不计入成品页数，也不作为必须附交的成品附件。保存、展示、回读及宿主出口见 [quality](quality.md)。全部已授权页完成并逐页交付后才称整套完成；仅完成封面或部分内页时，明确已完成页及未完成范围。

### 可编辑套图的制作前提

封面前置按[主入口](../SKILL.md)与[混合制作](produce-hybrid.md)执行。当前封面获批前，内页只规划内容、容量、事实缺口及预计素材；不得冻结具体布局、卡片、坐标、比例或槽位，不得借复用生产本套定制内页资产，也不得提前写入内页。
