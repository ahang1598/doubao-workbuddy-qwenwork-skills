# 参考观察、继承与重建

## 1. 概述

将可见参考转成可执行、可验收的视觉依据，用于参考新建、同款延伸、图片重建及参考驱动修改；图像与代码生产共用视觉规则。生产裁决归 [SKILL.md](../SKILL.md)。

通用规则各归其主文件，本文件只补充参考专项：

- [common.md](common.md)：事实、需求记录、身份。
- [edit.md](edit.md)：授权、编辑基线及局部／整体边界。观察不产生复用权，重建不扩大授权。
- [quality.md](quality.md)：状态、QA、修复、禁止自主 AI 重生及交付。
- [produce-image.md](produce-image.md)：通用图像输入、记录及可见文字语法。
- [templates.md](templates.md)：实际模板库的正文、依赖读取与采用。

## 2. 使用场景

出现“参考排版、结构、风格”“同款换内容”“严格复刻”，或指定继承字体、配色、肌理、卡片、渐变、蒙版等维度时，在视觉选型、字体选择、KV 或正式素材生产前观察。

| 类别 | 用途或继承边界 |
|---|---|
| 身份来源／内容证据 | 前者保护商品、人物、品牌身份，不自动提供版式；后者提供内容依据，不自动成为目标文案 |
| 整体设计／局部效果参考 | 前者确定整体阅读关系；后者只影响指定效果，不覆盖主参考 |
| 一模一样、位置不动、严格复刻 | 在已授权维度尽量保持具体关系 |
| 参考结构和风格、同款换内容 | 迁移结构与视觉机制，适配新主题 |
| 只参考配色、字体或某效果 | 仅继承指定维度，其余由当前题材规则补足，不扩读其他题材 |

- 多图按维度确定主次，不平均混合；保留用户指定用途。
- 有完整可编辑源的局改，只观察受影响区域及必要邻居；只有图片时，不假定存在可编辑源。
- 仅在原图缺失、关键要求冲突或完整文案无法容纳于锁定结构时澄清，不为填满分析增加确认。

## 3. 核心流程

### 素材地址解析

- 区分原始资产 ID、附件引用、云盘文件页、媒体 URL 与本地文件。资产 ID 或附件引用通过当前环境实际支持的资产详情／附件解析接口取得原图；保留原始标识及对应关系，不猜接口、拼域名或删前缀构造地址。
- 资产详情中的 `resource_url` 是云盘文件页，不能直接当媒体下载地址；采用接口契约明确的媒体字段，并实际验证能否读取。已提供可访问原图或本地文件时直接使用，不重复解析或上传。
- 解析失败、权限不足或仅有缩略图时记录限制，只暂停依赖原图的部分；不凭链接标题推断图像内容、不拿缩略图冒充身份母版。故障重试沿用入口上限。仅取素材时执行本节，不额外触发完整参考风格分析。

### 取得可信底稿

1. 查看可访问的原尺寸参考，识别作品画幅；拼图、并排长图、多页截图须分清页面及阅读顺序，无法恢复的隐藏区域保持未知。
2. 水印、截图 UI、工具栏、平台按钮、黑边、账号名、AI 角标、演示外框等非作品内容只记“已过滤”，不进入设计计划；真实作品内的品牌内容不可因形似界面文字误删。
3. 关键判断注明来源图及区域，区分直接观察、可复核测量、合理推断、未解决项。低清、裁切、模糊或透视图不支持精确取色、确定字体名或像素测量。OCR 只辅助转写，可辨文字逐字看图，不可辨内容不猜。
4. 依次形成视觉底稿、逐块绑定、同源机制和目标方案。观察、目标适配、最终结果分别保留，不把实现偏差反写为参考目标，不以源码自洽证明继承成功。

### 十一项观察语义，合并为五组

只分析继承范围；范围内没有的现象简记“未出现”，范围外不凑项新增效果。可写自然段，不强制填表。

| 观察组 | 内容 |
|---|---|
| 版式、构图、关系 | 栅格、分栏、模块、留白、对齐；主体位置、尺度、朝向、重心、纵深、阅读路径；主体与陪体、文字、背景的接触、穿插、遮挡或孤立 |
| 文案、字体、信息 | 可辨原文、语种、语气、修辞、商业作用；层级、标注、图例、卡片、栏目、编号、数据关系；字族、字阶、字重、横竖排、倾斜、错落，以及字色、描边、阴影、发光、纹理、立体、破损。字形相似不等于识别具体字体 |
| 色彩、光影材质 | 主辅及点缀色职责，明度、饱和度、冷暖，高对比、互补、邻近、单色加点缀等机制；观察色不自动成为目标色。光影用方向、强弱、颜色倾向、自然光／棚拍光／环境光、高光阴影落位及纹理描述，不用 K、RGB、HEX 或光比数字 |
| 风格、人像 | 画种、流派、媒介、笔触、颗粒、网点；摄影的焦段感、机位、景深、对比度、影调，有依据才写胶片型号，否则用明确调色语言。人像看姿态、表情、发型、服装廓形及材质，底妆、腮红、眼妆、唇妆、修容、高光、妆感流派；不可辨细节保持未知，无人像记“未出现” |
| 商业与可迁移规律 | 卖点、痛点、CTA、品牌语气，以及焦点、层级、关联、节奏怎样使画面成立；不以“高级感、氛围感”代替原因 |

### 逐块绑定与同源机制

分栏、四宫格、时间轴、步骤图、对比卡、卡片流，按真实阅读顺序逐块说明：主体及构图、姿态／朝向、材质／成像方法、色彩职责及相邻差异、可辨原文、文字层级与语义、图文对应原因、如何进入下一块。

不得写“其余同理”、压成“一张主图加多段文字”，或只数容器而漏掉主题差异。A／B／C 三项内容不等于必须三栏，应按阅读路径与语义权重分配。

提炼七类机制，解释怎样成立、怎样迁移，不重抄观察：①构图公式；②配色思路；③文字层数与字号相对比例；④文案语气与修辞；⑤图文层叠／穿插／咬合／并置／环绕／遮挡；⑥主体与其他元素关联强弱；⑦美术成像手法。

同款延伸默认继承配色、构图和图文关系，适配获准变化的品牌、文案、主题对象；用户限定范围时从其限定。创意改编可在授权范围重组机制。

### 六步形成目标方案

局部编辑只应用于获准范围，依次进行：

1. 满足用户明确要求及锁定项，不用参考偏好覆盖。
2. 按范围保留配色；创意改编可随新主题调整色相及配色关系，但用户锁定色、真实资产固有色、适用的证件照规范背景不变。
3. 替换不适用的主视觉、配图、道具、装饰及图形族，保留仍适用的继承项；新配图须真正表达新主题。
4. 默认完整对齐文字模块数、层级、字号相对比。非事实性文案可在授权内补齐，只有用户明示精简才主动降低密度。
5. 按范围保留或调整焦点、主体尺度／姿态／朝向、标题与主视觉关系、模块分组、阅读路径、装饰分布，说明变化及内容依据。
6. 保留 **1 个主亮点和 1–2 个辅助亮点**，其余降级；简约图保持克制。需要创意差异时，优先改变主视觉轮廓、位置关系或阅读路径。

最终文案按语义和商业作用映射到文字模块；标题、副标、叙事、过渡、视觉创意及基于已有事实的卖点表达可主动设计扩写。

锁定内容存在证据冲突时，保留原文与冲突记录，暂停依赖部分，不改写为已核实；独立且已授权的工作继续。

## 4. 不同产物/策略展开

### 容量适配

- 超出参考容量，先凝练获准调整的重复表达，不损失事实、不改锁定原文。
- 仍超载且授权允许时，沿原叙事语法增加屏、页或章节，保持同源构图家族、图文比例、密度节奏。
- 锁定结构或编辑范围不允许扩展时，提出具体冲突并取得所需确认。
- 禁止靠全页缩字、压行距、删除必要配图、连续堆满高密度模块维持原屏数。

### 承托、遮挡与纹理

- 区分整页／章节背景、卡片表面、照片内部场景、展示外底；展示衬底不自动成为成品背景。共享色场和连续场景注明范围，不按文字段落强拆；无卡片直说无卡片，不强加卡片或纹理。
- 文字绑定具体卡片、产品或场景，说明父子／并列、对齐轴、净空、前后层级、允许穿插及阅读顺序。连续长图的产品左右错落，分别记录产品、标题、卖点位置，不改成等宽左右卡或机械镜像。
- 字形、卡面、背景、主体成像的纹理分别绑定承担者与范围，说明颗粒尺度、密度／强度、渐变方向、淡出边界。细纸纹、大片斑驳、暗纹插画、摄影柔焦不能用同一种噪点替代；图片已有的效果不重复覆盖。
- 效果区分“已有实现及依赖”“已绑定当前素材或节点”“当前渲染已核验”；配方写过不等于兑现，库示例不证明宿主具备交付能力。含正文的共同根节点不得整体模糊或降低透明度。

### 三类安全区

- **页面安全区**：文字与关键内容距画幅边缘的区域、章节留白、接缝保护；装饰出血另记。距离依据目标画幅、阅读尺度、参考证据，不套统一百分比。
- **容器安全区**：真实可见内表面扣除边框、折角、夹子、缺口、遮挡及旋转后不可用部分，不以外接矩形充当内容框；卡片与内容共同变换后仍检查最终位置。
- **素材语义保护区**：保护人脸、Logo、产品轮廓、标签、关键证据，识别可放文字的低干扰净空；淡出、纹理、前景装饰均须避让，区分源坐标与目标显示坐标。

判断绑定来源区域及目标消费者；范围、比例、数值须说明基准与证据等级。允许叠压须明确哪层可遮哪层、什么必须完整，不只写层级数值。裁切与保护区沿用原素材记录，节点、几何、层级、蒙版留给实现。无参考新建只建立目标关系，不编造原图证据。

### 真实承载与可编辑保护

关键决定须落到真实对象：布局与阅读路径到章节／组件，主体关系到素材及裁切遮挡，文案到可见文字，配色与效果到消费者，多块语义到对应图文，商业主次到焦点及 CTA。

不得将参考截图铺成整页背景再覆盖新字冒充分层重建，也不得用截图覆盖原本可编辑的内容；位图文字不能声称为独立可编辑层。

## 5. 输出形式

简单纯图将参考用途、需保留的视觉关系及获准改动直接落实到提示词。复杂任务在同一 Brief 补充来源、视觉分析、图文对应、目标方案及必要的验收重点；不另建参考分析文件或平行 Brief。

- 逐字列出最终可见文案，与设计说明分开；观察到的参考文字不自动成为目标文字。
- 说明颜色机制与职责，不要求坐标、色值表、模板编号或参数校验结果。用户锁定的尺寸、颜色数值及其他原始约束原样保留，不能借“自然语言”删除。
- 新增精确色值、透明度、几何、层级及代码属性在执行阶段落实。方案确定后再转译，不声称存在自动解析 Brief 的编译器，也不反向索要机器字段。
