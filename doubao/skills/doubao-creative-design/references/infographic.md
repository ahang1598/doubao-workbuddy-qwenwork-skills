# 信息图与图解规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

目标：准确解释对象的形态、组成、变化，以及节点之间的分类、条件、依赖和协作关系。

**共用流程**：明确解释目标与阅读条件 → 组织内容与依据 → 选择表达结构与视觉方法 → 试排与适配 → 集中检查 → 按授权形式交付。

按内容选择相关章节：对象说明读第1.1、2.3、3.2节；关系与流程读第1.2、2.4–2.7、3.3–3.4节；文字、布局、试排和交付共用其余条款。同一作品可组合两种表达，各模块采用相应约束，不重复执行整套流程。

生产路线由[主入口](../SKILL.md)决定。用户未指定生成图片或其他制作方式时，新建且确定性关系结构为主体默认走 pure-coding，用 HTML、CSS、SVG 或 Mermaid 构建节点、文字、连线与图例，不调用生图生成整图或底图；对象说明按入口选择路线。已有源编辑保留原路线，独立位图局改不强制转代码；功能冲突只处理具体冲突。

制作与事实依据执行 [common.md](common.md)，参考执行 [reference.md](reference.md)，编辑先按 [edit.md](edit.md) 核验完整源、目标与范围，沿用有效方案，只修改授权内容及必要关联部分。检查轮次、保存和交付状态统一执行 [quality.md](quality.md)。完整结构设计、复杂任务及代码制作在同一 Brief 记录内容、关系和来源，各视图共用；简单位图局改直接编写编辑提示词，不补建 Brief。不要求用户提供内部 ID、JSON 或 RDF。

## 1. 明确目标与选择表达

明确用途、受众、核心问题和实际阅读端，保留已有文案、数据、尺寸、数量、来源、参考及修改范围；确认全量或总览、静态或交互，只补影响本次工作的缺失信息。先确定主解释目标，再选择必要主图、局部和辅助图表，不为覆盖图种增加内容。

### 1.1 对象与数据说明

适用于微观结构、解剖剖面、设备分解、工程空间、时间与地理、操作与形态演变，以及科普长图、知识海报、知识卡片和数据说明。UI、手机界面和卡片可作为内部载体或解释对象，不据此扩展为通用界面题材。

| 类别 |图种 | 适用场景 | 设计重点 |
|---|---|---|---|
| 结构与原理 | 微观结构图 | 细胞结构、分子模型、原子晶格 | 明确观察尺度与重复单元，区分整体和放大部位，标注真实位置 |
| 结构与原理 | 解剖／剖面图 | 器官内部、机械结构、建筑内部 | 说明切面位置与观察方向，保留内外轮廓和部件对应 |
| 结构与原理 | 分解图 | 零件装配、产品拆解、系统组成 | 保留整体参照，沿清楚方向分离部件，用编号或引线对应装配位置 |
| 图表统计 | 比较图与趋势图 | 已知数量比较、随时间变化 | 柱图便于比较数值，折线呈现时间变化；统一口径、单位与尺度 |
| 图表统计 | 构成图、流量图、多维图、分布图 | 整体占比、来源去向、多维特征、数值分布 | 分别选饼／环图、桑基图、雷达图或适用分布图；矩形树图用于层级数值，不与分类树混用 |
| 图表统计 | 信息报告 | 综合数据与结论说明 | 按问题组织图表、解释和来源，保持口径可比，避免图表堆砌 |
| 工程设计 | 平面／规划图、建筑与户型图 | 空间布局、室内分区、场地与路线说明 | 标清边界、出入口、方向及已有尺寸；平面位置与实际空间对应 |
| 工程设计 | 蓝图式说明 | 产品、建筑或机械的技术外观展示 | 按目的选择正投影、顶视或轴测，保留可辨标注；蓝底白线是可选外观，不代表施工或生产已验证 |
| 时空演化 | 时间轴、编年图 | 历史事件、发展过程 | 设置清楚主轴与关键节点，区分按时间比例排列和非比例事件编排 |
| 时空演化 | 甘特图 | 任务起止、持续时间与进度说明 | 共用时间轴，对齐任务时段和里程碑；真实依赖单独表达 |
| 时空演化 | 地理可视化 | 气候分布、地形地貌、人口空间分布 | 地点、区域和数值编码对应，标清图例；地形形态不与统计颜色混为一义 |
| 时空演化 | 路径／轨迹图 | 洋流、台风、迁徙路线 | 对应真实位置、方向和时段；箭头不同时暗示未经给定的速度或流量 |
| 时空演化 | 形态演变图、对象循环图 | 胚胎发育、恒星演化、种子萌芽、生命周期 | 按真实阶段表现变化，保持视角和尺度可比；循环须有真实回返关系 |
| 科普示意 | 科普长图 | 需要连续展开的主题讲解 | 用主图、章节与跨段线索串联解释，保护完整信息组 |
| 科普示意 | 知识海报 | 快速识别主题并理解重点 | 集中一个主焦点，再安排必要说明、图例和来源 |
| 科普示意 | 知识卡片 | 单个知识点、概念或短步骤 | 对象、解释和必要条件成组，脱离系列仍能理解 |

### 1.2 关系与流程说明

适用于节点、集合、层级、条件及连接。一个视图明确一个主图种，辅助视图分别标明职责；不按单张、多张或长图决定关系模型，不混用含义不清的关系线。

| 产物或阅读模式 |适用条件 | 必要组成 | 规格或专属要求 |
|---|---|---|---|
| 思维导图 | 单根分类、知识梳理、项目拆解 | 根主题、分类依据、主父子关系、必要解释与跨分支联系 | 主层级单根、无环、从根可达；包含不等于执行顺序 |
| 概念关联图 | 多中心、跨主题联系与关联探索 | 概念名称、关系名称、端点、方向及依据 | 允许多入边和有意义的循环；其中层级关系仍无环 |
| 流程图 | 步骤、条件、执行循环、交接或状态流转 | 起止或持续运行边界、活动、判断、路径条件、责任、合流与异常 | 判断分支互斥且覆盖；可终止执行流程的循环须有出口并按第2.5节处理；持续性关系循环按第2.7节说明边界，不虚构终点；泳道对应真实责任 |
| 知识图谱 | 可命名、可追溯的实体事实查询 | 实体与类型、谓词、来源、时间、状态、查询视图 | 先消歧；多元事实用事件或关系实体；筛选状态可见 |
| 模块／依赖／数据流框图 | 系统或模型架构、模块协作与接口连接 | 模块名称与边界、依赖端点、输入输出、数据流方向及含义 | 复用第2.2节共同节点关系和第3.4节连线要求；区分包含、依赖、调用与数据流，不把依赖误作执行顺序，不强套流程或图谱模型 |
| 分类树 | 生物分类、文件目录等父子归属 | 分类依据、根、父子节点及必要解释 | 单根、主父唯一、无环且可达；分类树不是以矩形面积编码数值的矩形树图 |
| 组织结构图 | 公司架构、职责与汇报关系 | 组织或岗位、层级、汇报端点、关系类型 | 单一主汇报层级可用树；多汇报关系分别保留并标明，不强压为单树 |
| 韦恩图 | 集合包含、交集与差异比较 | 集合名称、归属条件、交集及必要全集边界 | 相交和包含须有依据；未给定面积比例时不表达数量占比 |
| 时序依赖图 | 以任务、事件或阶段间的依赖和约束为主要解释内容 | 节点、真实依赖、必要日期或时段及时间基准 | 时间与依赖分别编码，先后不自动表示因果；以历史叙事、持续区间或对象阶段变化为主的时间轴、编年及甘特说明采用对象说明方法，第2.7节的时间编码策略仅用于本类中的必要时间信息 |
| 工程拓扑示意 | 电路、液压、网络等连接原理解释 | 元件或模块、端口、连接、方向及符号说明 | 专业符号采用明确的符号规范，参数和尺寸来自确认资料；不以示意图承诺生产施工可用 |
| 总览与局部阅读 | 内容较多，需要先定位再展开 | 展示范围、折叠范围、局部上下文、返回定位 | 全量任务所有内容实际出现；总览可折叠但须说明范围与展开方式 |
| 静态与交互阅读 | 固定查看或确需搜索、筛选、展开 | 静态索引或实际功能及其可见状态 | 静态不画伪按钮；交互在目标端验证，并提供完整静态内容 |

时间轴、编年和甘特以历史叙事、持续区间或对象变化为主时采用对象说明方法，以依赖和约束为主时采用关系方法；辅助依赖线不改变主解释目标。PDCA表达逻辑循环，生命周期按实际形态变化表达；细胞器协作网与细胞剖面分别采用关系和对象方法。蓝图配色、立体外观不决定题材。主要任务为筛选、比较、趋势或多图表分析时仍按入口的分析职责处理，不因本文件合并改变路线。

## 2. 组织内容与依据

### 2.1 按输入成熟度展开

| 输入模式 | 采用条件 | 具体动作与边界 |
|---|---|---|
| 视觉模板 | 只要求材质、构图、图表形态或装饰，未要求填充知识 | 明确主视觉、节点、容器、留白、图形制式和可填写标签区；不补业务数据，不把空白槽位当作事实依据 |
| 完整内容 | 已提供文字、数据、分类或关系 | 逐项分配标题、模块、插画、图表、图例和标签；覆盖事实、分类、关系及长尾项目，保留限制、警示、例外和来源，不用“其余类似”省略 |
| 主题科普 | 只给主题，但明确要求讲解、机制、原理或知识叙事 | 形成标题、导语、核心主图、解释模块与必要总结；各模块明确正文、对象、标签及关系；扩写依据可核验知识，不补无依据参数或定量说明 |

保留给定数字、百分比、坐标、统计结论、引用、署名、日期、时间点、版本、技术参数、公式、单位和专业数值的原值，不擅改、重算或补造。按给定值表达图形比例，不由此生成新统计结论。

事实缺失或矛盾时，仅暂停依赖它的图表、标签或结论，按共用规则记录；保留锁定原文，不为画面完整强行编码，不先补数字再用“约”“示意”放行。科学机制与现实主张须有依据；自拟标题、导语和过渡不冒充参考图、论文或权威来源原文。

### 2.2 整理节点、关系与视图范围

1. 明确来源、版本、页段或时间范围、整理权限和排除项；保留锁定原文及必要上下文。
2. 写清节点名称、解释、关系端点、名称、方向和依据。摘要保留对象、条件、否定、时间范围与观点主体，不把“建议尝试”改成“已经决定”。
3. 区分来源明确、整理推断和开放提案；后两类在成品中可见。事实、价格、参数和数据不得编造；允许创意扩写时可补充想法或示例，不把它们写成事实，也不默认把材料扩成完整知识体系。
4. 列明各视图展示、折叠及外部连接范围；缺口沿共用待补记录维护，仅暂停依赖部分。结构正确不证明知识正确，不以“待核实”掩盖无依据事实。

### 2.3 对象说明的内容结构

围绕对象与说明目标，区分并列、对比、时序、因果、部件归属和对应关系。

| 内容类型 | 采用条件 | 具体动作 |
|---|---|---|
| 多模块科普 | 知识点并列或递进 | 并列用稳定网格；递进明确阅读次序；每模块文字、插画、图表一一对应 |
| 说明型图表 | 已知数据用于比较、趋势或构成解释 | 比较用柱图，时间趋势用折线，构成可用饼或环，面积编码须有数据依据；明确类别、原值、单位、排序及颜色映射 |
| 信息海报 | 先识别主题，再阅读解释 | 建立标题、核心图形和说明区的主次；主图表达对象或机制，不以装饰替代信息组织 |
| 地图与空间说明 | 地点、区域或路线需要空间定位 | 以地理空间组织内容，逐项对应区域、路线、地点标签和颜色编码；地点说明按需要展开特色、看点或使用信息，与对应位置就近成组，不机械交替摆在两侧 |
| 放射式说明 | 围绕中心对象解释部位或特征 | 明确中心、层级圈、扇区与向外阅读方向；装饰圆环不冒充数据比例 |
| 时间线或历程 | 说明对象或事件随时间变化 | 正序或倒序贯穿主轴及左右交错节点，保留日期，不为等距布局改写时间。同年不同事件明确区分，同一事件不为对称重复；关键节点按依据补充具体变化或与主题的关系，不把先后写成因果；锁定原文按共用规则处理 |
| 结构解析或解剖 | 需要辨认形态与组成 | 先整体，再部件与局部；保留空间对应，使标记点、引线和标签逐项匹配 |
| 属性对照或分组 | 比较特征或按属性归组 | 明确分组依据与共同比较标准，同组对齐、逐项对应；父子分类树采用第2.4节的树约束 |
| 操作或形态演示 | 操作画面、形态变化或对象内流向承担解释 | 按真实顺序安排，标清起止及适用的流向、循环；编号和箭头对应画面，并列项不画成因果 |
| 原理与机制示意 | 依托对象或场景解释作用原理 | 明确作用对象、位置、变化及关键机制；区分部件引线、运动方向和因果关系，不套用无依据机制 |

以下为按解释需要选用的具体策略，可与上表合并使用，不要求全部采用。

| 图种或难点 | 具体策略与边界 |
|---|---|
| 微观结构 | 细胞、分子与晶格明确观察层级、重复单元和局部位置；不同尺度分区并标明放大关系，不把示意粒子大小当真实比例 |
| 解剖／剖面 | 标明切面位置、观察方向、切口与内外边界；器官、机械、建筑部件保持真实空间对应。肌肉收缩等变化按机制呈现，不为动感编造形态 |
| 分解与装配 | 保留整体参照，沿可辨方向分离部件，标明原位置与装配对应；分解间距不表示实物间隙，分解箭头不自动表示操作顺序 |
| 对象循环 | 生态循环、生命周期等先判断解释对象；以对象状态为主时对应各阶段形态、流向及回到起点的真实条件，不为闭环补造阶段或因果；PDCA等逻辑循环按第2.7节处理 |
| 数值图表与报告 | 已知数据说明按比较、趋势、构成、流量、多维或分布分别选型；分类树不等于数值矩形树图。综合信息报告保留各模块的数据口径、单位、时间与来源，不因排版整齐混用尺度；具体编码见第3.8节 |
| 工程空间与视图 | 平面／规划、建筑与户型说明先定位边界、空间、出入口和用户给定路线。正投影用于沿相应投影方向表达形状，顶视是从上方观察的视图；轴测以平行投影呈现多个面和空间关系，不等于顶视，也不是近大远小的透视图。按解释目的选择，不混标视图 |
| 工程依据 | 电路、液压、网络图保留用户给定专业符号与正确拓扑，不用装饰图标代替专业含义；尺寸、尺寸箭头、单位及技术标注以用户资料为依据，缺依据仅暂停依赖项。蓝图外观不证明设计满足生产、施工或逃生安全要求 |
| 时间轴与甘特 | 历史、编年按真实日期和阶段组织主轴与关键节点；甘特以起止时间、持续区间对齐时间轴，依赖不靠邻近暗示。等距事件编排须与按时长编码区分，不让间距虚示持续时间 |
| 地理与轨迹 | 气候、地形、人口说明区分区域属性、地形形态与数据编码；洋流、台风、迁徙对应真实位置、方向和时段。路径箭头表示运动方向，不自行兼作速度或流量；比例尺与距离须有依据，非等比例示意明确说明。标注密集处可用局部放大或独立说明区，并保留位置对应；按地图范围与说明量安排版面，不拉伸地图迁就画布 |
| 形态演变 | 胚胎、恒星、萌芽等按真实阶段安排；统一视角、方向及可比基准，突出实际变化。跨阶段尺度改变须明示，不因统一画面大小暗示对象尺寸不变 |
| 长图、海报与卡片 | 长图用章节接续与跨段线索维持解释连续；海报集中主题焦点，再展开说明；知识卡片围绕一个知识点配对象、解释及必要条件，脱离组图仍能理解，不以删限制换短小 |

### 2.4 思维导图与概念关联图

- 树状层级只有一个根，其他节点各有一个主父节点，主层级无循环且从根可达；跨分支联系另列，不能偷偷增加主父节点。
- 概念网络可多中心、多入边及有意义的循环，其中层级关系仍不得循环；不按树强行删边。
- 同名不同概念增加语境，不因名称相近合并。“相关、包含、支持、依赖、导致”不可互换；原文同时出现两个词不证明二者相互作用。
- 节点长短和分支数量由内容决定，不为对称补节点，不为减少交叉删关键联系。

| 策略 | 采用条件 | 具体做法 |
|---|---|---|
| 分类与解释 | 知识梳理 | 写明分类依据，保留理解分类所需的定义与解释；主题示意仅按需使用 |
| 工作拆解 | 项目规划 | 区分目标、工作、交付物和责任；包含关系不画成执行顺序 |
| 观点归属 | 阅读或会议整理 | 分开讨论、决定、待确认项，保留发言或观点主体；证据截图保留出处 |
| 发散分层 | 用户允许创意探索 | 将开放想法、示例与已选方向分开标记，不将灵感图当事实依据 |
| 共同维度比较 | 决策要素或对象对照 | 只按真实共同维度比较，显示差异和缺项，不强凑一一对应 |

### 2.5 流程图

以下用于有起止条件的执行流程；持续性关系循环按第2.7节说明。

1. 确定起点、终点、参与者与责任边界；逐节点记录名称、必要类型、责任主体、前置条件、输出和来源。
2. 逐线明确端点、方向、条件和正常／异常属性。只使用必要的开始／结束、活动、判断、子流程、数据／文档和注释类型，未要求时不强套完整 BPMN。
3. 每条判断出线写明条件，有默认路径时显式标注。条件须在来源允许范围内互斥且覆盖；无法证明时标待确认，暂停依赖路径定稿，不自行补齐业务规则。
4. 共同后续流程设置独立合流点；循环写明进入、回路及退出条件，每个开始均能到达明确结束或已说明的外部出口。
5. 逐项检查来源中适用的失败、超时、取消、回退、人工介入、子流程与跨图入口出口。异常不可因低频而隐藏；定稿前处理孤立节点、悬空端点、无标签判断线和责任错位。

泳道只表示真实责任主体，节点归属须一致，跨泳道线表示真实交接。位置邻近不表示审批权、先后或因果。

### 2.6 知识图谱

1. 先写核心查询和资料范围，定义实体类型及边界，再整理规范名称、别名、来源和状态。同名先消歧，别名指向同一规范实体，不因名称相近或视觉邻近自动合并。
2. 定义关系名称、方向、含义及适用端点类型。事实按“主体—关系—客体”记录；仅主题相近而无明确谓词时不建边。多元关系通过事件或关系实体表达，不压成含糊二元边。
3. 每条事实分别保留来源、时间有效区间、置信或状态；区分已证实、推断、提案和矛盾。推断说明规则或依据，不包装为来源结论。
4. 按查询选择总览、实体邻域、关系路径、时间切片或冲突视图，不默认全量力导向铺图。各视图只筛选同一事实集，不改实体身份、类型、方向或状态。

环路和多中心须有明确语义；保留孤立实体时说明查询价值或资料缺口。不得存在重复实体、悬空关系、空谓词、无来源却标已证实的事实。对称或无向关系按定义表达，不伪造单向关系。

高连接实体先做密度试排，超出本任务可读容量时按类型、来源、时间、状态或查询范围筛选；显示筛选状态和省略数量，不编造通用节点阈值。全量任务仍须在获准的总览或局部中展示全部内容，不能以过滤数量代替。

### 2.7 集合、组织、时序与工程示意

| 策略 | 采用条件 | 具体做法 |

### 2.8 确定单图、系列与阶段

用户指定张数和形式优先。编辑未指定数量时，默认一个完整方案；多张先区分备选方向与共同叙事，不只组织第一张。

- **单图**：一张讲清主题，配齐标题、主图、必要模块、标签与来源；密集时先重排，不自动增页。
- **备选方案**：每个候选信息完整，通过构图、解释视角、风格或编排区分，不改事实与锁定文字。
- **同组系列**：各页有完整主题，共享图例与视觉语言，共同覆盖全题；按页序交付，不自动拼成长图。
- **图文分步**：阶段名、连续编号、说明与阶段图逐项对应，按真实状态或操作顺序组织。
- **连续长图**：章节与跨段关系完整，交付连续成品，不用分页预览替代；生产分段不改变成品数量。

步骤1，保留已锁定数量与形式；数量未定时，判断一张能否在实际阅读尺度下完整解释。

步骤2，按对象状态变化、操作边界、解释跨度与阅读容量选择单图、系列或分步。“图文交替”“一篇图文”等只作阅读意图线索，不直接决定多图；静态解析、并列知识和静态数据不强拆。

步骤3，采用分步时，按真实知识或操作边界命名阶段，从1连续编号。数量与形式未锁定时，同图可清楚解释的状态可放在单图中分区呈现；确定采用图文分步后，每阶段对应一张完整阶段图，并配齐阶段名、编号和说明。按真实变化划分阶段，不为凑张数拆分或合并，不以第一阶段代替其余阶段。

## 3. 设计视觉与布局

按解释结构、主图职责、节点层级、关系与标签密度、图例、连续性和目标画幅选择布局；模板执行 [templates.md](templates.md)，读取所选正文及依赖，用真实内容试排，只调整新增或授权替换部分。无适用候选时按已定内容原生实现，不为套模板改变事实、关系或数量；下列策略不代表模板库已有对应 CSS。

沿用已定风格和构图；需要新选时依据受众、内容和参考确定主方向，总览与局部保持一致。网络或架构先安排核心节点与模块，再安排分组、外围节点及关系。

### 3.1 从整体到局部安排画面

- 先定画幅、阅读方向和核心信息面积，再安排标题、主图、模块、标签、图例与来源。未锁定画幅时按内容选横、竖或方形；编辑默认维持原比例和方向。
- 横向从左到右，纵向从上到下，放射从中心向外；对象解析先整体再局部，阶段演示按变化顺序。用面积、字号、位置和对比度建立主次。
- 命名顶部、中央、左右栏、底部等区域，明确区域内对象及对应锚点，不用“附近”“旁边”替代空间关系。不限制真实知识层级；以标签可追踪、引线不歧义判断定位是否清楚。
- 密集内容用网格、分栏或分层；为密集连线预留通道，不穿过文字与关键图形。重复元素保持共同格式，突出真正差异。
- **按有效解释分配面积。** 解释型信息图不只列名称、年份或口号；制作前按核心问题补足有依据的必要解释。偏空时合并可整理的重复表达，收紧模块和无职责空区，减少装饰占位；仅未锁定高度时可缩短画布。不设最低字数、节点数或配图数量，不编造事实，保留明确的极简要求与有意留白。纯图将这些要求落实到提示词，不增加生成后检查或自主重生。

### 3.2 对象说明的视觉方法

| 方法 | 采用条件 | 具体动作 |
|---|---|---|
| 主图配解释模块 | 对象、场景或机制比纯文字易理解 | 用主插画、剖面或阶段画面表达核心内容，模块围绕主图分配；插画与图标直接对应知识点 |
| 整体与局部配对 | 部件或微观过程难以辨认 | 保留整体对象，增加必要放大、剖面或微观图；标记原位置，以引线和标签对应同一部件 |
| 整体现象与组成对照 | 需区分表面感知与实际组成 | 用共享基准的左右或上下结构展示整体与拆解，连接对应元素，简述组合关系 |
| 归属与对应编码 | 类别或部件需反复辨认 | 用颜色、形状、图例、引线或邻近关系表达归属；主图、模块与图例逐项同义 |
| 阶段变化与总结 | 同一对象持续变化，末尾需归纳 | 保留可比部分，突出阶段变化；总结仅呈现已解释关系，不把先后变化冒充因果 |
| 风格内材质处理 | 已选扁平、写实或立体风格 | 扁平以线条和色块为主；写实或立体按需补充可信材质、光照；统一边框、图标、编号和箭头处理，装饰不抢信息 |
| 科学形态与材质 | 需辨认生物组织或机械部件 | 依据真实对象表现纹理、硬度和状态；科学配色优先遵守给定惯例或图例，示意色不冒充真实颜色 |
| 可选表面与光效 | 参考或表达目的确需风格强化 | 磨砂、渐变、拟态玻璃、全息、亚克力、塑料以及体积光、边缘光、轮廓光均为可选；不遮标签、切口或边界，不附加未经定义的数量和关系含义 |
| 工程线绘外观 | 需要突出空间、轮廓与技术标注 | 可选蓝底白线或黑底白线，也可采用浅底线绘；保持线型、标注和部件清楚，不以漂亮蓝图冒充可施工图纸 |
| 科普表现与阅读方向 | 需适配受众与解释跨度 | 卡通、写实、矢量或立体按目的选择，不为科普强制3D；主轴可水平、垂直或对角安排，但时间、空间方向和标签须清楚，数值图表不加扭曲编码的透视 |

### 3.3 关系图风格策略

| 策略 | 采用条件 | 具体做法 |
|---|---|---|
| 瑞士网格、清晰知识编辑 | 需要快速总览与检索 | 以清楚主干、稳定字级、有限分类色组织内容，将来源置于低干扰区域 |
| 手绘笔记、白描线绘 | 需要亲近、记忆或复习感 | 使用圈注、手绘轮廓和少量主题图；装饰线与真实关系线明显分开 |
| 编辑档案、文献索引 | 需要追溯资料与观点 | 用非对称分组、注释和来源索引形成检索关系；编号必须对应真实出处或索引 |
| 有机枝条、自然插画 | 适合生长或分类比喻 | 用分枝节奏与柔性轮廓组织层次，不强画树，不暗示额外生物因果 |
| 地图式主题探索 | 多区域需要定位与回溯 | 设置分类区域和地标式主题，保留返回定位；空间路径不暗示执行顺序 |
| 包豪斯、孟菲斯、积木图形 | 教学、轻快表达或形态辨认 | 少量几何形体对应明确角色，保持形状含义稳定，不用随机装饰干扰连线 |
| 像素模块、数字系统 | 主题或参考适合数字语汇 | 统一颗粒尺度和端点处理，正文用可读字体，不将全部准确文字改为像素字 |
| 纸艺、等距微缩、艺术拼贴 | 需要材料或空间表达 | 将辅助对象放在低密度主题区，节点与关系独立准确；使用原生可实现效果或核验的已有资产，不因此生图 |

辅助手法只处理局部，不逐分支换画风；只换底色不算完成手绘、档案或空间表现。材质、光效与立体表现按需采用，不为科普或工程主题强制3D；不以透视扭曲图表数值。背景按第3.7节处理。

| 可选策略 | 采用条件 | 具体做法 |
|---|---|---|
| 几何节点与矢量表达 | 逻辑、流程或拓扑需要清晰辨认 | 以稳定形状、网格或水平主轴组织节点；标签贴近对应节点或边，方向与关系优先于装饰 |
| 磨砂、渐变与拟态玻璃 | 已定风格适合少量表面层次 | 仅处理节点或辅助表面，保证文字、关系标签和端点清晰，不用透明叠层制造假交集 |
| 蓝底白线或黑底白线 | 工程解释确需相应视觉语汇 | 保留符号、文字与线型的可辨性；配色不替代标准、尺寸依据或专业验证，不暗示施工批准 |

### 3.4 整体布局与连线

以下六类主要用于思维导图与概念关联图，选择服从已建模型，不为命中布局改内容。

| 策略 | 采用条件 | 具体做法 |
|---|---|---|
| 中心放射、左右分枝 | 单根、短分支、较宽画幅 | 主次沿分枝展开，保持左侧文字正常阅读，不旋转长文或为对称补节点 |
| 单向树、上下层级 | 层级深或标题长 | 固定层级方向、同级对齐，用树线、缩进或嵌套表达真实父子关系；给长节点留宽，不机械缩小深层文字，不暗示时间顺序 |
| 分区集群 | 多主题、会议整理或检索 | 分区对应真实分类，区内外关系仍明确画出，不以邻近代替关系 |
| 对照双区 | 确有共同维度的比较 | 两区按共同维度对齐，保留各自差异、缺项与非对应内容，不凑等量 |
| 概念网络 | 多中心、交叉联系 | 优先保护关系标签、端点和方向，疏解高连接局部，不按树删边 |
| 总览加局部展开 | 内容多、关系密集 | 总览定位，局部保留祖先路径或实体上下文、入口出口和返回位置；不自动新增页数 |

思维导图的主层级与跨主题关系以线型、位置、粗细和标签区分。流程图默认单一主轴，节点类型形状稳定；正常、异常、超时和取消用标签与线型共同区分，异常可降视觉权重但不能隐藏。避免反向长线与反复交叉；跨区使用具名连接点，长流程保留子流程入口、出口和返回位置。

知识图谱的类型用形状、边框或分区稳定编码，关系显示谓词及定义要求的方向。来源、时间和状态用标签、线型或侧栏表达，不只靠颜色。节点距离、面积和线宽不得暗示未定义的相似度、重要度或置信度。

使用节点与连线的图种须明确实际端点；连线交叉不代表相连，汇合须有明确节点。集合区域图的相交、包含和互斥按集合定义表达，不套用节点连线的交叉规则。图例只解释实际使用项，装饰不得新增分类、因果或权重。

### 3.5 容器与开放排版

用对齐、间距和关系线即可组织信息时，采用开放排版；需要明确分组时再选容器。

| 策略 | 采用条件 | 具体做法 |
|---|---|---|
| 中性圆角容器 | 稳定的普通节点、定义或解释 | 按层级调整边框或表面，不强制等大，不把全部节点做成同款白卡 |
| 文件夹轮廓 | 主题组、资料集、分类簇 | 页签对应真实分类，不用于无分类职责的单个普通概念 |
| 侧尾对话框 | 注释、提问、观点、待确认项 | 尾部指向明确对象，与真实关系线分开 |
| 阶梯面板 | 中心主题、结论、阶段边界 | 仅强调关键层级，避免所有节点都用重框 |
| 胶囊与徽章 | 状态、关系类型、编号、图例 | 只放短标签，长概念回到正文节点 |
| 圆角磨砂玻璃 | 网络或抽象空间的少量主节点 | 控制透明和模糊，确保文字与连线对比，端点不被透明层叠乱 |

容器按真实文案定尺寸，明确文字排列、留白、连线出入口和与底图的关系。轮廓、表面、边缘及层次按 [templates.md](templates.md) 设置，共用效果只写一次。核对实际材质、对比和遮挡，不因容器造型改变层级或方向。

### 3.6 局部排版策略

| 策略 | 采用条件 | 具体做法 |
|---|---|---|
| 紧凑内容 | 同组短字段或密集可扫描信息 | 压缩留白与组距，不压到不可读，不把无关内容塞同框 |
| 宽松内容 | 单一主张、少量重点 | 留白服务焦点和阅读停顿，不用空白凑高度 |
| 规整对齐 | 可比较条目、证据或稳定栏目 | 明确列组、共同基线和主次，网格不自动变卡片墙 |
| 疏朗留白 | 长解释或编辑阅读栏 | 固定行宽、文字轴、图片归属和段间节奏，不把所有内容挤窄 |
| 错落平衡 | 短标题接力或不等权分组 | 写明错位方向及共同对齐依据，不随机散放正文 |
| 聚焦主场 | 真实对象或证据图需先被识别 | 保持主体尺度、取景和文字静区，说明图文前后关系 |
| 连续流动 | 已授权连续视图或系列阅读 | 明确前段出口、后段入口及共享背景或接续对象，不据此新增长图 |
| 叠层拼贴 | 多张资料、照片或纸片需叠放 | 区分主副片、角度、遮挡和保护区，不遮证据与节点 |
| S 形导览线 | 真实流程、路线或概念节点需曲线推进 | 明确起止、真实节点和绕行保护区，无关系节点时不用装饰曲线 |
| 横向卡片列 | 同类短条目或短阶段 | 统一共同尺度并保留差异，不挤入长正文或复杂证据 |
| 章节眉线 | 局部标题、编号或换区提示 | 对应真实层级和接续对象，不让分隔线抢占主内容 |
| 带引导线的图像标注 | 部件、结构、地图或证据解释 | 指向真实细节，明确文字归属，避免交叉遮挡 |

可组合相容策略，但保持主要关系清楚。

### 3.7 底图与辅助资产

- 关系类 HTML/CSS 每个视图的整体底图至少采用一种与主题相关的纹理、肌理或渐变；用代码或已核验资产实现，不因此调用生图。密集区降低纹理频率、对比和密度，可局部留纯色，保持背景连续。
- 配图用于主题识别、记忆或真实证据，不要求每节点一图。明确主体尺度、取景和低干扰阅读区。
- 证据截图保留出处和必要上下文，等比缩放，说明文字独立排布；核对图片归属、裁切和保护范围。已有真实短链保留，缺失注明待补，不编造地址。
- 装饰不模拟证据，参考中的人物、品牌和科学关系不自动继承；修改背景不改节点事实。

对象说明的背景与视觉家族按适用路线执行 [produce-image.md](produce-image.md)、[produce-hybrid.md](produce-hybrid.md)，不套用关系类禁止新增生图的路线约束。

### 3.8 文字、连线与图表

- 保留用户指定或原图语言，不自动翻译。明确字符串逐字保留大小写、数字、标点和单位；清晰参考文字准确转写。
- 不猜写不可辨文字。仅要求原样保留时，维持原位置的视觉形态与排版，不提交臆测转录；需要准确重排而缺依据时，暂停依赖部分。替换、删除和新增仅作用于授权范围。
- 先按目标阅读宽度确定正文和关键标注，再安排标题、主图与辅助信息的面积；按 [fonts.md](fonts.md) 的“信息图、关系与流程图”字号要求换算与验收，不把母版上的字号当实际阅读字号。部件解释、步骤和必要条件按正文处理，不能因放在图旁或底部而缩为小字。深底文字保持清楚对比，不以低透明度和细字重区分长段正文。
- 每条连线明确起点、终点、方向、线型及颜色含义；无方向关系不加箭头。区分部件引线、运动方向和因果箭头，颜色与线型承担明确语义。
- 每项图表明确类型、编码、轴线、刻度、标签、图例与已有数据。使柱长、折线趋势、面积或扇区比例、颜色映射、标注数值与结论一致，不用视觉夸张改变数据关系。按下表选择适用编码，不把流量、构成、多维比较统称统计分布；不使用透视或立体厚度扭曲数值。

| 图表类型 | 编码要求 |
|---|---|
| 柱图／折线 | 柱长表达数值，时间趋势按真实时间顺序组织折线；明确坐标、单位与刻度，比较使用可比口径，非等间隔时间不得伪装成等间隔 |
| 饼图／环图 | 表达同一整体的构成，保留整体口径与已有比例；不将不相容类别拼成整体，不擅自补足缺项或重算给定值 |
| 数值矩形树图 | 矩形面积编码给定数值，嵌套表达真实层级；与只表达父子分类的分类树区分，无数值依据不编码面积 |
| 桑基图 | 带宽编码流量，明确来源、去向、单位与适用时段；差额、损耗或存量变化仅按资料说明，不擅补流量以求视觉守恒 |
| 雷达图 | 各轴对应明确维度，显示尺度、方向和单位；不同量纲不能直接冒充同尺度比较，归一化仅采用给定规则，不从轮廓面积生成综合结论 |
| 分布图 | 依据实际数据选择适用的分组、区间与频数／密度编码；明确区间和单位，不把分类层级或流量图当分布图 |
| 集合关系辅助图 | 韦恩图以区域表达集合及交集，只有给定数量依据且明确采用面积编码时才表达数量比例；否则不由圆面积或交叠面积推断数量 |

- 编号只表达阶段、时间或索引，并与读图方向一致；不把并列知识默认编号成先后流程。

### 3.9 系列视觉与参考融合

稳定字体族与字体角色、色彩语义、图标制式、编号、箭头、图例和共同定位，使同一颜色、形状或线型跨页同义。保留对象的可比特征，系列不作为差异化风格备选。

一般系列按章节、密度和局部放大需要调整主体版式、背景分区、面积及同级字号，保持层级与系列识别，不要求所有背景色值完全相同。锁定模板或明确要求严格一致时，保持约定的背景色值、明度、质感或渐变方向、字体族、同级字号和模板位置；进度变化仅用小面积强调，不改变锁定配色。

- 按内容、布局、风格、配色或局部素材的既定用途取用参考。重复信息保留有依据的权威版本，矛盾信息按用户取舍，不擅自融合。
- 形成连贯信息图，不机械并排截图；借用风格不继承身份、署名或事实。
- 对齐比例、透视、边缘、遮挡、光影、材质、色彩与清晰度，保留锁定构图。删除后整理空缺；新增明确位置、层级及关联，局改不扩成重设计。

## 4. 试排与适配

1. **先测最困难内容。** 用最密对象标注、最长节点、最深路径、最密关系、高连接实体、真实条件、泳道、图例、来源、公式和多语种文案试排，再扩至全部视图。
2. **先定阅读字号，再定容量。** 按 [fonts.md](fonts.md) 的“信息图、关系与流程图”要求，以实际显示宽度换算节点、解释、关系标签及来源字号，再安排主图、解释区、节点和连线空间。用户尺寸优先；仅未指定尺寸的横向思维导图总览，可先以 **1600 × 1200 px** 为设计假设，不作为阅读宽度或全部关系图的默认规格。手机须按实际显示尺寸重排，不能只缩小总览；打印按实际纸张和阅读尺度检查。
3. **处理密度与范围。** 优先调整图文面积、栏宽、节点宽度、间距、路径和已授权视图内的分区；未锁定高度按内容调整；仍过密时按授权安排局部展开或确认范围，不靠缩字、隐藏关系、无依据聚类或自动增页求整洁。
4. **字体稳定后重测。** 字体选型、加载和回退引用 [fonts.md](fonts.md)。主题、分支、节点、解释、关系标签、状态与来源有明确字级，不每深一层机械缩字。装饰字体仅用于短标题，不用于节点、步骤、条件、关系、来源或密集图例。字体加载与实际命中核验按 fonts 执行；采用最终字体后，重新检查节点尺寸、换行、连线端点、箭头与标签位置，排除遮挡和溢出，不沿用加载前的排版结果。
5. **验证总览与局部。** 局部保留祖先路径或实体上下文和返回定位，重要外部线标明另一端去向。全量任务的全部内容须实际出现；仅总览任务允许明确折叠。缺图降级保留节点和关系，不以装饰缺失删事实。
6. **验证真实交互。** 仅实现授权的展开、收起、搜索、定位、筛选、返回总览及来源查看；收起同步隐藏附属线，展开保留来源。静态使用页名、区域名或索引，不假装可点击。手机阅读适配不等于变更宿主或允许改变锁定画布。

## 6. 组织交付

- 单图交完整信息图；备选按授权数量分别交完整候选；系列按页序交完整组图，不自动拼成长图。
- 图文分步按阶段交说明与对应图；连续长图交完整连续成品，不以分页预览替代。
- 纯图长页分段条件执行 [produce-image.md](produce-image.md)。适用分段生产时，段图与完整长图分别在生成后立即交付。
- 可编辑作品保留完整源及同版本、同尺寸预览，使指定文字与确定性结构保持可编辑。说明与提示词不默认混入成品附件。

- 关系图交付实际渲染成品；可编辑时保留原生节点、文字与关系，代码文本或截图不能替代对应成品。按授权交付总览与局部，保留页名或区域索引、来源、祖先路径或实体上下文及跨图定位，不自动新增页数、长图或附件。
- 交互作品说明已验证功能、筛选范围和未验证项；完整静态内容、降级交付及保存、展示状态按 [quality.md](quality.md) 执行。源、预览和成品保持同一版本。

### 适用生图路线时的说明格式

本题材生图提示词跟随请求语言，每份完整画面写成一段连续自然语言，多份以空行分隔，不加标题、编号或列表；分步图可保留阶段编号与名称。只描述最终画面，各区及各阶段完整，局改写清变化与保留项。此格式不规定阶段数、成品数或调用数，也不限制用户说明；图内语言按第3.8节，输入与调用按[图像制作](produce-image.md)执行。
