# 混合生产：先准出素材，再组装可编辑作品

## 1. 概述

- 本文件只执行 [SKILL](../SKILL.md) 已裁定的 image-coding，负责 KV、可编辑社媒套图封面门禁、素材登记与组装、视觉机制及独立艺术标题；不另判路线、宿主或批准权限。
- 图像承担摄影、场景、插画、复杂材质及获准图内文字；准确文字、数据、规则图形与指定可编辑区域由原生层承担。完整固定画布 HTML5 为可编辑实现源，不以整页压平替代指定编辑范围，也不将局部编辑要求扩大为全图。
- 唯一 Brief、事实、扩写、身份母版与创意依据归 [common](common.md)；状态、展示、准出、修复及交付归 [quality](quality.md)。参考传入、Prompt、背景与抠图执行归 [produce-image](produce-image.md)；全部 HTML 及通用图像适配计算归 [produce-code](produce-code.md)。

## 2. 使用场景

- 用于入口已指定的混合新建、整体重做及已有 HTML 编辑；既有源保护与授权见 [edit](edit.md)，不因导出图片而改路线。
- 混合新建／整体重做须有承担实际视觉职责并绑定成品的生成或编辑素材。入口允许的通知、公告、邀请、喜报／捷报／成果战报、节庆贺图可直接复用合适真实底图；局部改字、间距不生成无关图。其余路线例外及图像能力冲突仍由入口裁决。
- 混合 KV 仅用于新建或整体重做电商详情页、社媒长图；纯图、纯代码、其他题材、局部替换及不改变视觉路线的小改不触发，不因成本高增加批准。
- 封面门禁仅用于可编辑社媒套图；不扩至商品轮播、普通画册、其他多页物料、单张封面或纯图套图。

## 3. 核心流程

### 素材尺寸与规格

- 按 [common](common.md) 更新同一 Brief，由页／段职责、准确文案及图文关系确定素材组合：共同解释整组的画面可合成完整场景，需分别邻接说明的对象按对应关系安排，需独立移动或跨层的主体保留可分离边界。完整背景、透明主体或复用由用途决定，不默认一章一张横图，也不逐条强配图。事实、身份与编辑范围沿用原记录，规划说明不进入成品。
- 用真实文案、选定字体及拟用构图验证容量与图文对应，再冻结素材数量、比例、取景和文字安全区；不因素材先定成矩形场景而把文字全部挤到图前或图后。可进行不加载未就绪素材的非交付文字容量／比例测量，不提前组装正式作品，不另建几何文件；套图确认前测量只服务整套内容容量与封面。
- 字体选型、加载及阅读尺度见 [fonts](fonts.md)。真实内容明确后、Brief 冻结前按 [templates](templates.md) 比较模板；只消费自包含发布 manifest、所选正文及必要依赖，不凭摘要、类名或缺失维护源实现。

### KV 生成与确认

KV 用于确认主视觉、字体与图文关系，并指导后续制作。适用范围见第 2 章，批准与修复按 [主入口](../SKILL.md)。

#### 1. 设计

- **先定完整方向。** 在同一候选 Brief 明确主题、真实主体、第一焦点、尺度与视角、场景光材、配色及参考锁定项；只提取本张必要内容。电商表现商品、标题与连续场景；社媒表现首段并露出下一章节入口。
- **标题参与构图。** 默认包含准确主标题，来源依次为用户提供／确认、核验事实提炼、授权创意扩写；记录来源与改写权限，不加无关英文或虚构卖点。按 [fonts](fonts.md) 明确字形、粗细宽窄、姿态、字距断行、颜色及必要材质，并确定相对主体的尺度、位置、对齐或穿插关系。副标题按需从属，不默认立体、描边或发光。仅背景、商品或文字空位不算完整 KV；用户明确无字时记录未确认字体方向。
- **辅助内容有职责。** 电商可无卡片、使用同场景主题装饰，或使用一张承担归属／比较／阅读隔离的卡片；不放空壳、伪参数，不缩小商品给样本腾位。
- **候选有实际差异。** 优先两个、最多两个，共享事实、身份与锁定项，至少一个维度有显著可见差异；微调或改名不算新方向。用户只要一个、整体方向已锁定或确无有效差异时生成一个并记原因；仅锁品牌色不等于锁整体方向。

#### 2. 生成

- 图像工具直接生成／编辑 **1920×1080、16:9 横版完整 KV**，不以 HTML、情绪板或散图拼装替代。核对请求与返回像素；能力不足如实记录，不拉伸或静默改尺寸判合格。候选阶段不建正式素材清单。
- Prompt 落实上述主体、场景、字体、图文关系与保护项，真实参考按 [produce-image](produce-image.md) 传入。所有待渲染文字逐项用中文双引号界定，排版说明放在引号外，保留源文案原有引号。正式 Hero 的无新增文字规则不套用于候选 KV。

#### 3. 验收与确认

- **每张候选返回即展示，再按混合路线检查。** 核对身份、全部文案、焦点、场景、尺寸、版本和候选差异；标题须出现、准确、可读，字形符合方向，层级、断行与对比清楚，不挤压主体。未通过标记未准出，不进入可选方向，不自主修图或追加生成；实际仅为同方向变体时说明并推荐。
- **确认当前唯一方向。** 锁定方向仍须展示获批；普通参考、现成素材、“直接开始”或旧版批准不替代当前确认。合并方向须更新 Brief、生成并重新展示获批，图像变化使旧确认失效。续做仅复用设计、版本、范围与确认依据均匹配的结果。
- **保留可核验记录。** 真实输入、完整 Prompt、请求／输出尺寸、结果引用、版本／哈希、展示证据、用户原话与时间、批准范围及复用关系留在既有记录，不另建视觉 Brief 或合同。获批后回读 KV，将唯一方向写回同一 Brief 并冻结，再登记正式素材。

#### 4. 后续使用

| 对象 | 使用规则 |
|---|---|
| 整页与后续章节 | 继承字体气质、文字层级、配色、媒介、光材与边缘语言；按内容调整景别、图文比例、密度和接续，不复制每屏构图 |
| 正式文字 | HTML 按 fonts 选用并核验真实字体，准入艺术标题按本文件制作。KV 图内字不证明精确 family、可编辑性，也不扩大正式文字栅格化权限 |
| 正式首屏 | 按目标比例、容量、文字安全区及编辑范围重新构图、分工生产；横版 KV 不决定竖向段高，不以裁窄、缩主体或补白代替适配 |
| KV 整图 | 默认仅作参考，不声称可拆字层。仅题材允许一体化 Hero，且身份、全部图内文案、正式比例、有效像素、编辑范围及接续均通过时可复用；社媒另验第二屏衔接，否则重新制作 |

复用素材须登记、准出并按 [produce-code](produce-code.md) 核验适配；独立已有资产另验来源、权限和消费者。最终渲染检查方向落实、文字可读及章节接续，不能只凭沿用色板或引用 KV 判通过。

### 封面确认与内页制作

- 可编辑社媒套图不另生 KV。先在同一 Brief 规划整套页链、文案、编辑范围、容量和共享目标；一期只冻结封面，只登记、生产、展示及准出封面素材，再完成真实封面 HTML、渲染、展示，等待当前封面明确批准。
- 封面素材准出不依赖尚未生成的 HTML 或用户批准。批准前不得冻结、登记定制内页资产，也不得执行内页专属图像调用、编辑、后处理、HTML 组装、渲染或交付；内容规划、工具成功、素材展示及内部 QA 均不替代批准。
- 获批后从真实封面提取构图、字体角色、色彩职责、边缘、材质和图像处理等系列机制，写回原 Brief；补齐内页视觉，再增补清单、逐页生产。不机械复制封面坐标、对象数或容器。封面版本变化或确认依据不可核验时回展确认；已有 HTML 不压平。

### 素材登记、检查与组装

- 首次正式图像调用前建立轻量 `asset-manifest.json`，**KV 是唯一前置登记例外**。只登记当前获准范围，关联页／段与用途，记录生产方法、真实参考及顺序、身份母版与保护项、完整 Prompt、目标比例／尺寸、安全区、消费者、计划后处理、准出标准及阻断项。
- 同一结果重复摆放共用一条，列出全部 `consumers`；每项一个 `output`，不同采用结果分项。维护 `asset_id`、`reference_inputs`、`postprocess`；DOM ID、坐标、字号、色值及 CSS 留在 HTML。
- 调用前实际查看参考，身份与变体依赖按 [common](common.md)；真实参考传入、输入顺序及 Prompt 编译按 [produce-image](produce-image.md)。未传入的图片不称工具参考，不预填未来句柄；必要输入无法满足时暂停依赖。
- 返回后原条目回填真实 URI／句柄、实际尺寸、版本及状态；处理结果追加父子关系、范围、参数、Alpha 与采用版本，不覆盖原图或凭旧 Prompt、记忆、预览地址猜采用版本。来源分类与身份继承按 [common](common.md)。
- 组装前实际看图，核验源质量、身份、图内文字及计划用途；记录保留背景、已有有效透明或需去底的理由，具体处理执行 [produce-image](produce-image.md)。源图到就绪文件的方向、比例、裁切及有效像素检查执行 [produce-code](produce-code.md)，不等待尚未构建的 HTML 才准出。
- 当前获准页面的必需素材已展示、准出并回填后，才组装完整 HTML；套图一期只要求封面素材，不等待内页。只绑定最终就绪且真实可加载的地址；同图各位置独立定位，不因 URL 相同擅自全部换源。
- 一体化 Hero 已烘焙的文字、容器、主体和效果不再叠加；只组装生成前明确拆出且已留空的内容，不以原生覆字修补图内错误。完整渲染后再核验实际图文关系、各消费者、接缝及阅读尺度；各实例适配与有效像素均按 [produce-code](produce-code.md) 检查。

## 4. 不同产物/策略展开

### 首屏文字的制作方式

- 电商正式 Hero 默认商品／环境主图与原生标题、文案分离；明确选择且符合编辑边界的一体化方案，只允许主标题与必要短辅助文字入图，价格、日期、条件、参数和正文仍原生实现。
- 社媒一体化 Hero 按题材已分配的文字整体生产；简历、三折页全部标题保持原生。图中字标、包装文字、实物标签按 [common](common.md) 保护，不因普通配图不新增文案而擦除；不伪造证书、评论、账号、播放量、平台界面或真实案例截图。

### 系列视觉一致性

- 创作型混合作品至少 **70%** 画面保持同一视觉家族，最多一种次级母题；单个 Prompt 一种主风格，色板通常 **2–4 色**，明确主辅职责，不覆盖锁定品牌色。
- 背景、容器与标题至少共享色板、轮廓、材质、网格中的 **三项**；分层独立主体与背景通过光向、透视、接触、遮挡、路径或材质至少 **两项** 建立空间关系，不以同色冒充融合。规则信息区可用稳定网格，不为变化改造事实。
- 背景分工、光效授权、连续来源及相邻素材试排执行 [produce-image](produce-image.md)；文字净空见 [common](common.md)。组装须兑现已定背景与图文职责，不以小卡片、纯色或弱化效果偷换，不用融合遮盖结构断口。

### 独立艺术标题的使用条件

- 仅题材允许且未要求逐字可编辑的首屏／首图主标题，或每个独立图片唯一最高优先级大标题可用；同一独立图片默认最多一个，无唯一第一标题则不用。普通 H1、章节标题、正文、参数、标签、日期、价格、单位、免责声明及 CTA 均用真实字体与 DOM。
- “全部替换艺术字”不扩大准入；一体化 Hero 不进入独立字图流程，电商默认原生标题，简历／三折页不放宽。普通黑体、宋体、圆体及常规展示字体直接使用 [fonts](fonts.md)，不生成字体截图。
**按情形选择制作方法。** 下表区分原生标题与独立字图，不扩大上述字图使用范围。已有合适素材先复用；要求逐字可编辑时使用原生文字。其余按效果、背景与透明需求选择。

| 适用情形 | 制作方法 | HTML 接入与检查 |
|---|---|---|
| 需要逐字可编辑，或字体配合渐变、描边、阴影等即可实现 | 字体＋CSS／SVG 文字 | 使用 DOM 或 SVG `text`，不将文字转路径后声称逐字可编辑；字体与实现分别按 [fonts](fonts.md)、[produce-code](produce-code.md) |
| 已有符合文字、样式与使用条件的透明 PNG／SVG 字标 | 直接复用素材 | 核对来源、字形、透明背景及清晰度后接入；PNG 内文字不可编辑，SVG 路径可编辑不等于文字可重新输入 |
| HTML 背景已知且稳定，混合后字色与效果符合要求 | 纯色底字图＋混合模式 | 深色字配纯白底，用 `multiply`；浅色字配纯黑底，用 `screen`。仅作用于字图节点，不作用于父容器或整页；不声称具有真实 Alpha |
| 已有字图仅需去底 | 纯色底字图＋抠图工具 | 保留完整字形，对已有图执行抠图；优先 `byted-mediakit-image`，按 [抠图与背景保留](produce-image.md#抠图与背景保留) 调用，得到透明 PNG 后接入 |
| 直接生成透明底字图，且工具支持对应透明输出 | 直接透明输出 | 按 [抠图与背景保留](produce-image.md#抠图与背景保留) 选择图像工具并设置透明输出；核验 Alpha 后直接接入，不重复抠图 |

透明导出、跨背景复用、背景未知或严格保色时，使用通过检查的透明素材，不附混合模式。混合模式所用底色必须为纯白或纯黑，不使用渐变、纹理或近似纯色。下面的字形、材质、生成规格与像素要求用于新制作的独立字图，不强加于原生文字。

- Brief 留准确源文字与准入原因；素材记录留所属产物、唯一断行、视觉职责、KV 字形参考或已定参数、消费者及显示尺寸。先定骨架，再定平面／浅浮雕／挤压／充气／雕塑形态，再定一种主材质及最多一种局部工艺；须有真实字形改造、笔画语言或材质表达，立体不默认。
- 骨架只用中粗、粗或特粗；连接不细成发丝，不加无职责长横线或编辑批注线。明确具体字符与部位的切角、连笔、延伸、断笔，以及字面比例、笔画节奏、正侧面材质、粗糙度、纹理尺度、唯一表面处理、边缘、色彩职责、单一主光与自阴影。
- 一般正视或约 **12°以内**轻偏转；挤压模块水平偏转不超过 **8°**，厚度通常为主笔画宽 **0.3–0.8 倍**；石材／陶土起伏小于主笔画宽 **10%**。不生成环境、地面、底座或外部投影；装饰仅在 Brief 明确属于标题本体时采用。
- 七类骨架按主题选择：**融合黑体**保清晰及指定局部改造；**童趣手绘**保粗重、受控歪斜，立体仅低浮雕纸浆／软陶；**书法**保真实运笔，采用平面墨迹或克制压印；**风动行草**保厚实连接与完整拖尾，不用厚重挤压；**签名体**不加伪英文、随机缩写或污染字形的外发光；**复古手写**旧化限字内，不堆无关道具；**狂草**仅用于确有张力需求，关键字根及最细连接仍可读。
- 系列共用骨架、空间、材质、光向、边缘与色板，按语义长度受控变化。最终文件有效字面像素的宽、高均至少为对应显示尺寸 **2 倍**，插值不计；显示实例测量方法见 [produce-code](produce-code.md)。
- 优先 **2048×2048** 方图，尺寸按实际模型能力设置；不支持时采用其最高分辨率方形或近方形能力，不假定模型可用。字面包围盒建议占源图宽高 **65%–80%**，四周建议留 **8%–12%** 安全边距。超宽标题仅在文案与断行权限允许时预先规划分行／短语，不因失败自主拆词重生。
- 逐字对照断行、镂空、粘连与裁边，在最终尺寸及 **200%** 视图核验，OCR 仅辅助；材质关闭后轮廓仍须成立，不靠辉光或贴纸边才可识别。错字、缺笔、低有效像素或接入失败均未准出，不用锐化、DOM 覆字或拼错字补救。

## 5. 输出形式

- 保留同一 Brief、轻量素材清单、真实素材及完整固定画布 HTML；整体决定不重复写，几何实现不另建副本。不另建生产合同。
