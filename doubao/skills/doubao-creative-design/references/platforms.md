# 平台、版位与安全区

## 1. 概述

- 本文提供平台／版位画幅、安全区及内部内容、视觉限制，不决定题材、页数、生产方式、模型、工具或交付流程。唯一生产裁决在 [SKILL.md](../SKILL.md)；平台、比例或参考风格不改变锁定路线，同一版位不按生产方式分设规范。
- **全部画幅、安全区均为未经外部核验的内部历史参考，不代表现行官方标准；内容与视觉限制也不冒称平台现行审核条文。**

## 2. 使用场景

- 用于实际目标版位的布局、适配与检查；内容像某平台不等于投放该平台，通用海报不自动叠加所有社媒禁区。
- 多比例适配逐版位检查；已有源适配不自动授权删改内容、改变身份、重做整图或压平可编辑源。

## 3. 核心流程

1. **确定依据。** 用户实际尺寸、裁切框和遮挡要求优先，不为默认比例改动锁定尺寸。比例不代替像素，也不能推断上传容量、分辨率上限或压缩标准。未列版位不补造规格，标明待核实项，继续不依赖它的已授权工作。
2. **保护事实与身份。** 需求记录、事实缺口、文案扩写、锁定原文／专名、身份及真实行动入口，统一按 [common.md](common.md) 的相应规则执行。原文、品牌名、活动名、产品全称、人物身份和参考用途须保留；姿态、构图、光影、色彩参考不授权替换身份、包装或品牌资产。用户品牌素材保持原貌，不随意改形、改色、改比例。
3. **安排可见区域。** 有实际遮挡示意时按真实可见区检验。表中左右按画布宽、上下按画布高计算；范围缺少细节时可取较大避让值，仅为保守设计选择。背景、纹理、非关键装饰可延伸到边缘；标题、金额、专名、必要条件、身份标识及主要行动信息不得依赖遮挡部分才能理解。
4. **处理文案边界。** 非锁定且非必需的缺失事实可不呈现，或改用不增加现实主张的表达；不把“xx”“某某”“[文案]”渲染为成品。平台名可用于投放说明，但“某平台风”“爆款”“上热门”“刷屏”等运营标签不能替代具体设计要求。不得据此删除锁定的合法平台名或原文；与内部限制冲突时记录并交入口裁决。

## 4. 不同产物/策略展开

- **长页**：单屏导航风险与整图外边距分开处理；不得将 H5 顶部 8%、底部 12% 机械施加于每段，也不得按超长画布高度计算导航遮挡。视口未知则记录，不虚构设备适配结果。
- **多比例与九宫格**：母版完整不证明衍生版合格。九宫格兼查单格可读性和跨格切线，组合预览完整不允许文字跨危险裁切线。
- **海报收束区**：仅任务确需时放二维码或落款；电影、艺术、情绪海报不强塞 CTA 或二维码。真实扫码目标与禁假码按上述行动入口规则；平台禁站外导流时，不借通用海报规则绕过。

### 共用营销限制

- 所有版位禁止虚假标题党、未经证实的医疗／功效宣传、虚构权威背书、未授权品牌资产；内部营销限制包括禁止未成年人商业化及“最”“绝对”等极限宣传表达。
- 金融、医疗必要风险提示不能漏，也不能为虚假事实放行。以下平台视觉策略适用于对应营销配图与指定版位，不外推为所有题材的统一审美。

### 分平台策略

**小红书**

- **界面与导流**：禁止仿原生UI、假点赞数、假关注按钮、假评论气泡，以及微信号、电话、二维码等站外导流标识。
- **文字与照片封面**：文字大字报须通过容器、网格、纸张肌理或主题装饰建立信息层级，不只平铺文字在纯色底板上；照片主导封面可仅用主标题与少量注释，不强制装饰。
- **容器组织**：不把全部文字塞入同质半透明卡片或同款便签墙；多个容器在颜色、形态、材质或大小上形成职责差异，不用无职责四宫格组织信息。
- **人物与点缀**：严肃主题禁幼态点缀，生活叙事人物禁棚拍精修悬浮感；描边须符合手工、涂鸦、撕纸或主题材质逻辑，禁机械纯色矢量轮廓线。

**其他平台与版位**

- **B 站**：禁止侵权 IP；二创标识不替代授权、不使侵权合法化。有二创属性且需标识时须真实，不冒充原创、官方合作或权利人许可。参数对决、跑分、首测、排行榜均为可核验主张，不为冲击力补造。
- **抖音与快手**：禁止站外引流标识、微信号、虚假划线价及虚假承诺；直播预告的时间、价格、福利、库存须有依据。快手源头好货、工厂直营、产地直发、现挖现摘等不能仅凭实景风格成立；生成农田、车间或手部特写不是真实溯源证据。
- **朋友圈**：禁止假红包、假播放条、假点赞等伪原生 UI，禁止满版大字报、价格爆炸贴、促销轰炸及诱导转发。原生生活分享禁夸张情绪钩子和官方营销腔，不得编造第一人称购买、使用、到访或体验经历。
- **公众号**：禁止假系统通知、假对话气泡、假订阅号消息条等微信 UI 仿造；禁止电商主图式促销贴纸、高饱和满版撞色、夸张大字报及情绪营销轰炸。专业医疗、金融内容不得用花哨效果削弱必要信息；数据提炼不虚构数值，“附 PDF”等表述须与实际提供内容相符。
- **横向 Banner**：电商位禁虚假划线价、虚假优惠承诺及假“已购买”“已领取”状态。静态 CTA 须明确为视觉引导／装饰，不伪装成已发生交易或领取的系统反馈。品牌形象位禁过量促销贴纸破坏已选定的克制表达。
- **H5**：禁止假微信通知、假支付弹窗、假短信等伪系统 UI，禁止“不分享不能继续”等诱导分享及虚假中奖承诺。邀请函不编造时间、地点、嘉宾；年度账单不编造个人记录或统计；产品发布不夸大功效、不补造未验证性能参数。静态按钮、进度条、抽奖格、表单、滑动符号不是实际功能，不声称可点击、提交、抽奖或动态闪烁。连续页主色、字体规范、背景质感不得无理由脱节。
- **通用竖版海报**：日期、地点、主办方、演职员、奖项、上映信息须有依据；倒计时须有真实时间基础，不滥用“最后机会”“绝对错过”等宣传语。真实公众人物肖像须有授权依据，名人语录不得断章取义；禁止系统通知仿造。

## 5. 输出形式

- 将版位、尺寸、裁切和安全区用于实际构图与调用。已有 Brief 时只补充对应依据、差异和待补项，不重复抄写整体事实与身份决定。
- 平台适配不新增首图、KV 或批准环节。批准与生产顺序归 `SKILL.md`，可编辑社媒套图当前真实封面获批后再做内页的门禁归 [produce-hybrid.md](produce-hybrid.md)；纯图套图不增加 KV 或封面批准。
- 执行状态、真实展示、准出、集中初检、最多两轮确定性修复及禁止自主 AI 质量重生统一按 [quality.md](quality.md)，不扩大编辑授权。
