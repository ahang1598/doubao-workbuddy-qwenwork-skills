# 模型适配

## 1. 概述

- 本文件用于已确定题材、生产方式和实际模型的图像调用，覆盖完整位图与混合素材，将已知方案编译为工具输入，只调整表达密度与组装方式。生产裁决归 [SKILL.md](../SKILL.md)，不重选题材、内容结构、平台策略或路由，仅按需读取对应适配段。
- “4.5”“5.0 Flash”“5.0 Pro”“5.5”是内部未核验标签，不代表厂商型号、接口版本、性能排名或官方最佳实践，也不保证文字、身份或复杂编辑效果。仅使用实际部署能力，不猜测映射、不伪造成功、不自行切换生产方式；能力缺失仅暂停受阻部分。旧平台基准不视为现行官方标准。

## 2. 使用场景

- 已定方案的新图、参考延展或当前成品编辑；仅要求方案、提示或审查时，不自行生成。
- 沿用用户要求、已确定的方案及有效规则，只编写本次图像输入；已有 Brief 时直接采用其中的决定。缺少必要依据时，按主入口补读对应文件，不重新读取无关规范或另建模型专用 Brief。
- 用户锁定的数量、文案、尺寸、身份和编辑范围优先于适配默认值。

## 3. 核心流程

1. 明确本图目标、题材约束、锁定内容、参考用途及编辑范围；已有 Brief 时直接沿用，不为模型适配新建文档。
2. 按主入口确定图像工具；透明背景是输出要求。已有图片仅需去底时使用专用抠图工具。
3. 编译每图独立、完整的自然语言段落，清除规划字段、空槽和内部小标题，不用“同上”“其他一致”替代内容，内部说明不充当画面文字。指定图内数量时，保留主入口要求的逐对象 `<point>`、坐标约定与类别绑定；任何改写均不得删减、合并标签或将其画入成品。
4. 映射真实工具输入：画幅按实际协议传入，保留用户或题材方案确定的尺寸，不凭模型标签新增 `ratio`、seed 等字段。`[img0]`、`[img1]` 仅在工具支持时使用，否则映射为支持的参考输入；编号须对应真实图像。

所有待渲染文字（含英文、数字和混排）统一用中文双引号 `“”` 标记，保留原文及自带引号；标记用的引号不画入成品，字体、颜色、排版和断行说明写在引号外。不以“标题文案”“若干文字”“XX”代替实文。平台名、路径、内部路由和工具字段不充当视觉描述，但用户要求显示的真实网址、型号等不得误删。

## 4. 改写档位

默认映射：**4.5、5.0 Flash → 重改写；5.0 Pro、5.5 → 轻改写。** 重／轻仅指提示词的展开程度，不代表原图修改幅度；两档均保留锁定内容与授权范围，不新增事实。实际模型未明确或未列出时，仅执行共用输入规则，不猜测档位或切换模型。

### 重改写：显式空间描述

- **按条件采用风格。** 用户要求拼贴，或确需两张及以上图片共同叙事时采用拼贴；用户要求手账、日记、笔记本或文具拟物时采用手账结构；用户要求报纸、复古印刷、版画、油印或印刷工艺时采用对应印刷表现。局部纸纹、颗粒或手工痕迹不自动改成拼贴构图。

- **组装。** 按“方向与总览 → 空间扫描 → 必要收束 → 画幅核对”展开，最终合成一段中文提示。首句写横版、竖版或方形、主风格、影调与载体类型，不写具体比例。扫描选择从上到下、从左到右或从背景到主体等一种可复现顺序，不跨区跳跃。
- **实例化。** 先载体骨架与阅读顺序，再结合题材场景语义，落实主体、文字、材质及关系。重要元素覆盖适用的九类信息：位置、类型、形态、实际内容、文字样式、状态、关联关系、风格、视觉工艺；不补无意义元素。题材已有平台增强仍须落实；旧媒体第 10／11／12 维仅命中原用途时转译为阅读结构、安全区、信息密度或主体关系，不写编号和平台路由。
- **内部密度。** 简洁平面约 **600 字符**；中等信息量营销海报、社媒封面或界面约 **1200 字符**；多人、多区域或复杂界面约 **2000 字符**。这是重改写档的内部展开参考，不是最终提示词的字数下限；不为凑字增加内容，可去重，但不删主体、锁定文字、编辑范围或空间关系。
- **元素表达。** 每个独立元素至少一个颜色词，服从用户精确色值、锁定品牌色、参考资产与题材规则，不擅自改色。重复元素写数量与实例差异，长描述持续明确方位与衔接。高密度文字按既有清单绑定位置、容器和层级，不借描述扩充事实。
- **收束。** 信息较少且确有统一特征时，可用 **1–2 句**收束配色、排版和氛围；复杂画面可省略。只描述目标载体，不把平面成品自动扩展为现实空间样机。
- **编辑。** 按“编辑目标 → 具体保留项 → 具体修改项 → 空间线性描述”组织。每区交代来源图、位置、原内容、动作、目标状态和融合约束；身份、产品结构、位置比例、透视、材质、文字层级等锁定项须具体。文字替换写原文、目标文、位置与保留样式。
- **目标优先。** 少复述旧图；新载体或新场景以目标画面为主。仅品牌、包装等题材确有对应要求时，目标图描述不少于提示的 **70%**，不推广到全部局部编辑。旧背景、裁切、偶然道具和噪声不自动继承，用户锁定除外；改比例须重组空间，不等于机械裁切。

### 轻改写：结构约束与受限细化

- **5.0 Pro 底色偏好。** 不无依据地默认采用米白、奶油白、暖白、燕麦色、奶咖或米黄作为大面积背景。用户指定、明确继承参考配色，或品牌与核心资产保真需要时沿用；否则根据主题选择纯白、冷白、中性灰、深色或品牌色。此项仅用于 5.0 Pro，不扩展到 5.5，也不改动已确认的题材配色方案。

- **组装。** 不套用重改写档的密度参考，按“生成目标 → 已选构图与结构型主视觉 → 主体和阅读层级 → 核心文字 → 组件与材质 → 允许细化范围 → 完成度约束”成段。回填适用比例、安全区、内容结构、核心资产、系列一致性及合规边界，不杜撰工具字段。
- **聚焦。** 保留既定的 **一个主构图原型、一个明确动势**，写清第一焦点、第二阅读层、最终收束位置。一个主风格配 **2–3 个**最强有效视觉锚点，优先写关键 **1–2 类**材质，以及背景色、主体色、**1–2 个**强调色的角色；数量用于控制焦点，不为凑数增加颜色、装饰或材质。
- **空间。** 有空间层次时至少一组前后或叠压关系；拼贴、字图咬合、电影纵深可用两组，极简、Logo、纯产品主图保持一组即可。纯平面 Logo 可写图形与背景关系，不强加阴影、立体化或遮挡。轻量人工痕迹仅在原风格及题材允许时局部使用，不损害清晰度或锁定资产。
- **条件性补文案。** 传播任务需要副标题、短标签、栏目名、过渡或行动收束，且现有表达不足时，可设计非事实文案，或使用实际存在的提示细化能力；不强制交给“PE”，未部署不假装接力。开放细化须给出主题、受众、语气、允许的文案角色、长度或版面范围及“不得新增事实主张”边界；可改进既有事实的卖点表达，体验描述和行动引导也不能暗含未经证实的承诺。
- **不触发条件。** 完整文案、少字／无字要求或纯视觉任务不补写。局部编辑仅在授权区域细化，不顺带换标题、加标签或重排整图。细化后须确定实际文字，不把角色名留给渲染；只有单次生成能力时，由助手调用前定稿，不虚构生成后审定再提交的环节。
- **参考识别。** 普通参考明确 **3–6 项**核心识别，核心资产或系统延展明确 **6–8 项**，包含实际存在的整体色调、字体气质、组件家族、装饰语言；无字或无组件资产不杜撰缺项，全部用户锁定项即使超数也须保留。
- **继承与编辑。** 轻改写仍完整写出目标、保留项、编辑项和空间线性描述。默认延续空间骨架、主体位置与主次关系，仅获准创作、重排、改版或重构时更新布局。每图说明参考用途与变化，逐条绑定原文和目标文，不只说“翻译成英文”或“文字保持一致”。保留项具体而不长篇复述旧图；新增区域写清与原有颜色、材质、光影、透视、边缘和对齐的融合关系。

## 5. 输出形式

- 每张图一段可直接提交的完整提示，以及实际协议要求的参考与参数映射；沿用既有调用记录，不另建模型专用 Brief。
- 适配完成仅表示表达就绪，不表示生成、展示、当前版本批准或准出完成。
