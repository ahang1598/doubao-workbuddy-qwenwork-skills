# 创意概念生成系统

> 本 Reference 将主题转化为可看见、可延展、可生成、可 Coding 的创意机制。它解决“直接从主题跳到风格词”“只换配色和构图就称为多个方案”“装饰很多但没有核心想法”等问题。场景 Ref 决定说什么，本文决定用什么核心视觉命题让内容被记住，视觉系统 Ref 再决定字体、配色、排版和材质如何稳定执行。

## 适用范围

以下任务必须读取本文：

- 用户要求创意设计、新视觉概念、主视觉、品牌／活动／营销图片、海报、信息长图、电商详情页、三折页或其他需要形成视觉记忆的产物；
- 用户提供主题和内容，但未锁定具体画面机制；
- 用户说“更有创意、不要模板感、不要太板正、视觉冲击强、想法再大胆些”；
- 需要把抽象价值、利益、情绪、数据或故事转化成主画面；
- 需要 AI 生图资产与 Coding 排版共同服务一个视觉概念。

以下任务不强制发散：

- 用户要求严格复刻、只做尺寸适配、修字、替换素材或小范围调整；此时只在不破坏参考结构的范围内使用“受限创意模式”。
- 纯协议转换、纯数据校验或已锁定视觉系统的机械批量生产。
- 用户已确认唯一概念时，不重新让用户选择；只检查它是否已经明确到具体事物、可见关系与后期手法。

创意系统不得覆盖事实、品牌、平台、商品真实性、无障碍、印刷、HTML 或交付协议。创意越强，准确文字、证据和商品结构越要保持独立可编辑。

## 创意工作顺序

固定顺序为：

```text
锁定载体与事实
→ 完成场景／L3／品类内容路由
→ 提炼主题核心与受众变化
→ 找到一个创意张力
→ 生成至少 3 个机制不同的内部候选
→ 选择一个主创意命题
→ 翻译为构图、影像、文字、色彩、材质和空间规则
→ 进入对应字体／配色／排版系统
→ 编写资产 Prompt 与 Coding／HTML 映射
```

不得先选择“赛博、酸性、极简、高级、国潮、毛玻璃、3D”等风格，再反推主题。风格是概念的执行语言，不是概念本身。

只有用户确实需要选择方向时才向用户展示候选。需求已经清楚时，Agent 在内部完成发散、评分与收敛，直接执行最佳方向，不把流程负担转交用户。

## 第一步：提炼主题核心

### 1. 建立主题三层

分别写出：

1. **事实层**：画面必须准确传达什么对象、事件、功能、数据或商品事实。
2. **意义层**：这些事实为什么与目标受众有关，解决什么问题、满足什么欲望或代表什么价值。
3. **感受层**：受众看完应产生什么具体感受与行动倾向，例如“原来这很简单”“我也能参与”“它比想象中可靠”“我想停下来仔细看”。

禁止只写“年轻、活力、高级、科技、温暖”。感受必须能描述用户的认知变化。

### 2. 写出受众变化

用一个完整句子固定：

```text
让【具体受众】从【当前认知／情绪】转变为【目标认知／情绪】，并愿意【具体行动】。
```

如果无法写出变化，说明任务仍停留在内容罗列，不能进入视觉创意。

### 3. 建立语义原料库

从用户材料中提取四类词，不凭空添加无关母题：

| 类型 | 提取内容 | 用途 |
|---|---|---|
| 对象名词 | 商品、人物、地点、器物、结构、自然物、界面 | 决定可见主体 |
| 动作动词 | 打开、连接、生长、穿越、聚合、释放、折叠、守护 | 决定画面发生什么 |
| 关系词 | 内外、远近、前后、轻重、快慢、个体与群体、旧与新 | 产生构图与叙事张力 |
| 感官词 | 透明、柔软、锋利、温热、潮湿、颗粒、回声、速度 | 决定材质、光影和镜头 |

优先使用用户已有对象和动作。只有能解释主题时才引入新隐喻；不能因为某种视觉好看就强行添加宇宙、液体、花、粒子、玻璃、金属或门户。

## 第二步：寻找创意张力

创意通常不是“增加元素”，而是在两个真实语义之间建立意外但合理的关系。至少寻找以下一种张力：

| 张力类型 | 思考问题 | 可转化的视觉关系 |
|---|---|---|
| 现状 vs 目标 | 用户现在卡在哪里，完成后发生什么？ | 前后状态、打开、跨越、释放、展开 |
| 微小 vs 巨大 | 哪个细节实际影响很大？ | 尺度反转、巨物化、微观世界 |
| 外观 vs 内在 | 表面看不到的价值是什么？ | 剖面、透视、窗口、层层揭示 |
| 个体 vs 群体 | 一个行动如何汇聚成更大结果？ | 聚合、编织、阵列、扩散、接力 |
| 秩序 vs 失控 | 什么需要被整理、稳定或打破？ | 网格与破格、轨道、容器、溢出 |
| 熟悉 vs 陌生 | 哪个日常对象可以被重新理解？ | 语义替换、材质置换、场景错位 |
| 静止 vs 变化 | 主题真正重要的是状态还是过程？ | 冻结瞬间、轨迹、变形、连续章节 |
| 理性 vs 情绪 | 数据和体验怎样同时成立？ | 数据实体化、人物与图形共同构图 |

张力必须来自主题与受众，不得只为视觉奇观。最终只保留一个主张力，最多一个辅助张力。

## 第三步：生成不同机制的候选

本步骤是创意系统的核心。目标是得到至少 3 个机制不同、已经能被画面执行的候选。这里的“落地”不是提前完成坐标、资产管理和工程验证，而是把抽象意图翻译成具体物象、物象关系与后期手法。

### 1. 候选生成方法

每个候选固定沿以下链路生成：

```text
要表现的意义
→ 选择能代表该意义的具体事物
→ 让事物发生一个可见动作／关系
→ 选择强化该关系的构图与后期手法
→ 描述观众最终会看到的画面
```

逐步回答：

1. **要表现什么**：不用“高级、年轻、科技、温暖”等风格词，而写“透明可验证”“多人协作形成更大结果”“旧事物进入新循环”等具体意义。
2. **用什么事物表现**：必须点名可见物象，例如透明容器、织线、拉链、口袋、门、镜片、年轮、轨道、接力的手、商品剖面。不能只写“抽象元素”“科技元素”“自然元素”。
3. **事物如何发生关系**：点明变形、穿过、包围、接力、放大、剖开、折叠、溢出、编织、投影、缺失或重复等动作。只有“人物／商品摆在背景前”不算机制。
4. **用什么后期手法强化**：明确写出抠图叠层、双重曝光、蒙版融合、透视合成、尺度错置、位移变形、液化、色彩分离、网点、扫描纹理、长曝光轨迹、运动模糊、重复序列、阴影造型或负空间切割等手法。
5. **最后看到什么**：用一帧画面描述具体结果，包括第一眼对象、动作、空间和文字大致落位，不停在概念名称。

候选生成公式：

```text
【意义】通过【具体事物】的【动作／关系】，
配合【构图】和【后期手法】，形成【最终可见画面】。
```

例：“表现协作”不能只写多人合影。可以写：“用不同颜色的真实织线从多只手中进入画面，在中央编织成同一个稳定结点；通过抠图叠层、局部遮罩和线条由散到密的合成，形成视线从个体汇聚到共同成果的画面。”

### 2. 生成至少 3 个机制不同的候选

三个候选共享同一主题、受众、事实和载体，只改变表达机制。建议分别从以下不同方向取材：

- **对象变化**：物体变形、材质置换、符号凝练；
- **空间变化**：尺度反转、内外门户、负空间、剖面；
- **动作／关系变化**：接力、聚合、碰撞、连续过程、人物互动；
- **信息变化**：文字成为画面、真实数据实体化；
- **世界规则变化**：让多个章节或模块属于同一套空间规则。

每次至少跨两个方向。例如 A 用对象变形，B 用空间反转，C 用人物接力；不能 A/B/C 都是同一商品居中，只分别换成金属、玻璃和液体材质。

### 3. 候选表达卡

每个候选只需填写以下字段，但必须具体：

```text
candidate_name:
meaning_to_express: 要表现的具体意义
concrete_objects: 使用哪些可见事物
visual_mechanism: 事物发生什么动作／关系
composition: 主体位置、尺度关系、观看视角和文字净空
post_processing: 使用哪些明确后期手法，以及各自作用
final_frame: 观众最终看到的一帧画面
why_it_works: 物象与主题为什么有关
extension: 长图／系列／折页如何延展；单图写 none
avoid: 最容易退化成什么俗套表现
```

如果 `concrete_objects` 仍是“抽象图形／科技元素／氛围素材”，或 `post_processing` 仍是“增强质感／做得高级／加点特效”，候选不合格。

### 4. 后期手法与表达目的

后期手法必须为创意关系服务，不是任意叠加滤镜：

| 要强化的意义 | 可使用的具体事物 | 合适后期手法 | 可见结果 |
|---|---|---|---|
| 两种身份／状态并存 | 人物侧脸、商品外壳与内部结构、城市与自然 | 双重曝光、蒙版融合、局部透明叠加 | 两个语义共享同一轮廓，而非两张图并排 |
| 转变／进化 | 织物、纸张、路径、植物、零件 | 位移变形、形态渐变、液化、逐帧序列 | 一个对象保留识别特征并逐步变成另一个对象 |
| 影响巨大 | 微小零件、种子、水滴、按钮、数据点 | 尺度错置、透视合成、景深匹配、接触影重建 | 小物成为环境，人物／商品进入其尺度世界 |
| 聚合／协作 | 手、线、模块、碎片、点阵 | 抠图叠层、路径汇聚、重复阵列、遮罩穿插 | 分散对象在同一节点编织、拼合或接力 |
| 速度／释放 | 人物动作、产品轨迹、光、液体、布料 | 运动模糊、长曝光轨迹、方向性拉伸、残影序列 | 动作方向明确，静态画面具有前后过程 |
| 可验证／看见内部 | 透明容器、剖面、镜片、窗口、包装结构 | 局部去背、X-ray 式蒙版、剖面合成、轮廓高光 | 外观与内部证据同时可见 |
| 缺失／问题 | 空椅、断开的路径、被挖去的轮廓、影子 | 负空间切割、反相蒙版、阴影造型、局部消隐 | 缺失本身形成主符号 |
| 复古／档案／传播痕迹 | 照片、票据、纸张、印刷字、时间编号 | 扫描纹理、复印噪点、网点、套印偏移、撕边遮罩 | 形成真实媒介感，不只是泛黄滤镜 |
| 强观点／冲突 | 两个对立对象、标题、边界、颜色轴 | 硬切拼贴、色彩分离、阈值化、高反差遮罩 | 冲突在接触边界发生，不是左右各放一张图 |
| 梦境／记忆 | 人物、场所、旧物、光斑 | 多重曝光、柔焦边缘、局部拖影、颗粒与色偏 | 现实主体可辨认，记忆层只局部侵入 |

同一候选通常只选 1 个主后期手法和最多 1 个辅助处理。若去掉后期效果后物象之间没有意义关系，说明手法在冒充创意，应重写机制。

### 5. 创意机制库

每次从与主题最相关的不同机制中生成至少三个内部候选。候选之间必须改变“画面为什么成立”，不能只换颜色、字体、主体位置或材质。

#### CE01｜符号凝练

把主题压缩为一个能在缩略图中识别的主符号，由真实对象的轮廓、动作或关系组成。适合海报、封面、首屏和强传播主题。禁止使用与品牌无关的万能图标。

#### CE02｜尺度反转

把关键细节放大为环境，或把人物／商品缩小进入其内部，以尺度差表现重要性、精密度、沉浸或影响范围。必须保持主体可识别和透视可信。

#### CE03｜语义变形

让一个对象在保持识别特征的同时逐步变成另一个相关对象，例如路径变成线缆、织物变成地形、数据柱变成城市。转变必须能用一句话解释，不做随机混合物。

#### CE04｜材质隐喻

用主题相关材质表达抽象价值，例如透明表现可验证，编织表现协作，层压表现积累，弹性表现适应。材质必须与对象、行业或感受有关，不能套用流行玻璃、金属与液体。

#### CE05｜空间悖论／门户

通过门、窗、屏幕、容器、切面、镜片或折页让两个语义空间发生关系。适合内外变化、探索、产品生态和章节转场。门户内部必须承接主题，不能只是放另一张图。

#### CE06｜并置碰撞

把两个通常不同时出现但语义相关的对象放进同一画面，通过比例、接触、影子或功能关系产生新理解。并置要形成第三层意义，而非简单拼贴。

#### CE07｜叙事瞬间

选择故事中变化即将发生或刚刚发生的瞬间，让动作、视线、痕迹和环境留下前因后果。适合人物、活动、公益、品牌故事和使用场景；避免摆拍式“人物拿产品看镜头”。

#### CE08｜系统世界化

把一组规则、功能、角色或模块设计成同一世界中的场所、轨道、生态或集合。适合长图、系列、产品生态和多模块叙事。必须有一个主世界规则，不能每个章节换宇宙。

#### CE09｜文字成为画面

让短标题的字形、间隙或尺度参与主题表达。分图层 AI + Coding 中，仅首屏／首图或单图唯一最重要主标题可按宿主策略生成艺术字图片；其余标题无论层级均从字体库选择并使用可编辑 HTML DOM 文字。

#### CE10｜数据实体化

把真实数字、比例、路径或比较关系转化为空间、物体、光带、阵列或尺度，但数据映射必须可解释、可还原。适合信息图、报告与证据模块，禁止伪数据装饰。

#### CE11｜动作／过程可视化

围绕一个动词设计轨迹、连续状态、拆解、折叠、组装或前后因果。适合教程、电商功能、工艺和流程；每个状态必须增加信息，不重复同一主体。

#### CE12｜缺席与负空间

通过被拿走的部分、轮廓空缺、阴影、痕迹或有方向的留白表达问题与价值。适合克制、高端、公益和强命题设计；空白必须承担语义，不是内容不足。

### 6. 候选概念句

每个候选必须写成：

```text
因为【主题事实／矛盾】，把【核心对象】表现为【视觉机制】，让受众先看到【第一锚点】，再理解【意义】，最终产生【认知／行动变化】。
```

如果概念句只能写成“使用某色、某字体、某风格营造氛围”，它不是创意候选，应淘汰。

### 7. 差异门禁

三个候选至少满足以下两项不同：

- 核心隐喻或主符号不同；
- 主动作不同；
- 空间规则不同；
- 观看视角或尺度关系不同；
- 信息被揭示的顺序不同；
- 强化意义的主要后期手法不同。

只换配色、字体、镜头远近、卡片圆角、背景纹理或“高级／活泼”语气，不算不同创意。

三个最终候选填写一张简洁差异矩阵：

| 维度 | 候选 A | 候选 B | 候选 C |
|---|---|---|---|
| 要表现的意义 |  |  |  |
| 具体事物 |  |  |  |
| 主动作／关系 |  |  |  |
| CE 机制 |  |  |  |
| 构图与观看方式 |  |  |  |
| 主后期手法 |  |  |  |
| 最终可见画面 |  |  |  |

若任意两列只有颜色、字体、材质强弱或主体位置不同，则两案同构；保留较强者，并从另一个机制方向重新生成。

### 8. 示例：旧衣循环主题

共同意图：表现“旧衣不是终点，而是可以进入下一段循环”。三个候选必须用不同事物关系和后期手法表达：

#### 候选 A｜衣摆变成循环路径

- **具体事物**：一件真实旧外套、衣摆纱线、三个回收节点。
- **视觉机制**：衣摆的纱线逐渐解开并延伸成一条贯穿画面的回收路线。
- **构图**：外套偏右放大，标题位于左上净空，纱线路径从右中向左下延伸。
- **后期手法**：外套抠图；用蒙版让衣摆边缘逐步消散；用位移／液化把纤维拉成长线；用 Coding 线条补充路径、节点和准确文字。
- **最终画面**：观众先看到真实外套，再发现衣摆正在变成“下一站”的路线。

#### 候选 B｜口袋里的下一站

- **具体事物**：被放大的衣物口袋、叠好的旧衣、口袋内部的分类空间。
- **视觉机制**：口袋成为一个可进入的门户，内部展示旧衣被分类后的下一站。
- **构图**：微距口袋占画面主体，手部从右下把衣物放入口袋，标题在左上。
- **后期手法**：透视合成口袋内部空间；用遮罩处理口袋前后遮挡；重建接触影和景深；内部标签与流程文字由 Coding 完成。
- **最终画面**：观众看到的不是普通口袋，而是一个真实物件通向回收流程的入口。

#### 候选 C｜旧衣接力

- **具体事物**：同一件旧衣、三双来自不同方向的手、贯穿动作的轨迹。
- **视觉机制**：同一件衣服正在三双手之间接力，表现个人行动如何进入共同流程。
- **构图**：三组手和衣服沿左下至右上的对角线排列，右上保留结论文字。
- **后期手法**：分别抠出手与衣服；用遮罩重建前后穿插；统一色温与光向；使用轻微运动模糊和残影连接动作，Coding 绘制编号与步骤。
- **最终画面**：观众先看到接力动作，再理解回收不是“丢掉”，而是把衣物交给下一环。

三案分别使用“对象变形、空间门户、人物接力”，并分别以“位移变形、透视遮罩、动作残影”强化，因此不是同一创意的三种配色。

## 第四步：筛选主创意

### 1. 评分矩阵

内部以 1–5 分评分。候选没有点明具体事物、可见关系和后期手法时，直接退回第三步，不用高分风格描述补救：

| 维度 | 权重 | 判断 |
|---|---:|---|
| 主题相关性 | 25% | 不看说明能否与主题建立关系 |
| 物象与机制具体度 | 20% | 是否明确用什么事物、发生什么动作／关系 |
| 独特记忆点 | 15% | 是否区别于该品类的默认模板 |
| 后期手法有效性 | 15% | 手法是否强化语义，而不是只加滤镜 |
| 视觉即时性 | 10% | 缩略图和首屏能否形成第一锚点 |
| 内容延展性 | 5% | 长图、系列或折页是否能自然延展；单图按画面完整性判断 |
| 信息可读性 | 10% | 概念是否为准确文字和证据保留空间 |
| 品牌／平台适配 | 5% | 是否符合品牌和载体限制 |

### 2. 硬否决项

出现任一项即淘汰：

- 改变商品、人物、数据、功效、认证、事件或品牌事实；
- 必须依赖一大段解释才能看懂；
- 第一眼只能看到风格，无法识别对象或传播任务；
- 只能生成一张漂亮背景，无法承载真实文字和后续模块；
- 需要 AI 准确生成大量正文、参数、Logo 或界面文字；
- 与用户参考、品牌或平台边界明显冲突；
- 换成任何品牌／商品仍然成立，说明概念过于通用。

### 3. 收敛原则

选择一个主创意引擎，最多借用一个辅助机制。主机制控制 70%–90% 的视觉语言；辅助机制只解决局部信息或过渡。不得把三个候选折中叠加成一张画面。

## 第五步：把概念翻译为视觉系统

选定概念后，必须完成以下翻译，不得只保留一句口号：

| 维度 | 必答问题 | 输出 |
|---|---|---|
| 第一锚点 | 用户第一眼看到什么具体对象或关系？ | 主体、尺度、位置、占比 |
| 空间规则 | 画面是舞台、切面、门户、路径、档案、生态还是其他？ | 前中后景、透视、边界 |
| 主动作 | 画面正在发生什么？ | 动作方向、冻结时刻、轨迹 |
| 构图 | 视觉张力靠偏心、对角、包围、穿越、层叠还是负空间？ | 主轴、阅读线、文字净空 |
| 影像 | 需要完整场景、独立主体、微距、人物还是证据图？ | 镜头、裁切、资产边界 |
| 文字 | 标题如何参与而不破坏准确性？ | Coding 字级、对齐、可选艺术标题 |
| 色彩 | 哪个颜色承担语义，而非只营造气氛？ | 色彩职责、面积、变化条件 |
| 材质与光 | 什么材质和光能证明概念？ | 材质来源、主光、接触影、颗粒 |
| 重复与变化 | 哪些锚点跨屏／跨页保持，哪些按章节变化？ | 连续机制、换挡规则 |
| 反模板机制 | 本方向最容易退化成什么默认模板？ | 明确排除项 |

### 创意浓度

一张画面遵循“一个主创意 + 两个支撑机制 + 功能性信息”的层级：

- **主创意**：唯一可复述的视觉命题，控制第一印象。
- **支撑机制**：最多两个，例如材质接力、尺度参照、路径或章节编号。
- **功能性信息**：标题、正文、参数、证据、CTA、图注，服从阅读与准确性，不争夺创意主角。

创意不足时先强化主对象、动作、尺度或空间关系，不先增加贴纸、气泡、英文、粒子、渐变、玻璃卡片和随机装饰。

## 第六步：将选中概念交给生产

本节只在主创意选定后执行，用于衔接 AI 生图、Coding 与 HTML 生产，不属于候选创意“落地性”的定义。候选阶段只要求把意义说成具体事物、可见动作／关系、构图和明确后期手法，不要求提前填写坐标、资产清单、风险等级或降级方案。

### 1. 先拆资产，不生成整屏替代设计

把概念拆为：

- 用户必须提供或必须继承的真实主体；
- AI 生图生成的背景、环境、人物、复杂物件、材质、独立主体或经准入的艺术标题；
- HTML DOM／CSS／内嵌 SVG 生成的准确文字、色块、简单几何、线条、路径、图表、价格、参数、日期、标签和 CTA；
- 需要抠图、遮罩或前后景穿插的独立资产；
- 只用于预览、不得进入最终交付的临时参考。

AI + Coding 项目必须在此处完成“生图资产 vs Coding 元素”的第一轮生产规划。Brief 用自然语言说明每个概念元素由图片、可编辑文字、DOM/CSS 还是内嵌 SVG 承担；需要正式图片的项目再把图片生产信息写入轻量素材清单。没有完成职责拆分时不得开始素材生产或 HTML 组装。Coding 不是用来先搭一张页面再寻找生图位置，生图也不是用来替代已经规划好的准确文字、数据和规则结构。

AI 生图必须服务已选概念，Prompt 写出主体、动作、空间、镜头、光影、材质、负空间、画幅和排除项；不得只写风格形容词。除通过准入的独立艺术标题外，图片 Prompt 不包含传播文字。

### 2. 概念到 最终 HTML

每个核心机制必须在 Brief 中说明语义职责、可见行为、生产方式、所在页面／区域、与相邻内容的关系、可编辑要求和降级边界。需要图片时，其用途、生产方式、参考来源、Prompt、比例、目标尺寸、安全区、消费者和准出标准进入素材清单；DOM 坐标、字号、层级与 CSS/SVG 参数留到 HTML 实现。

如果概念只能停留在抽象形容词，无法说明由什么可见对象、图片或可编辑元素承载，也无法给出人类可理解的成品证据，则概念尚未完成。

### 3. 生图与 Coding 的共同构图

- 生图资产必须预留真实文字净空和叠压边界；不得生成后才在角落寻找放字位置。
- 背景元素应能进入主体前后，建立景深与空间关系；不能把所有素材并排摆在同一平面。
- 独立主体按最终遮挡和破框需求生成／抠图；完整场景保留有意矩形边界。
- Coding 不是后贴字幕。标题、数字、线条和图形必须参与主轴、尺度与节奏。

## 不同载体的创意尺度

| 载体 | 核心创意单位 | 适合的创意强度 | 必须保留 |
|---|---|---|---|
| 单张海报／封面 | 一个视觉句子 | 第一锚点最强，机制最凝练 | 三秒识别、一个主行动 |
| 信息／社媒长图 | 一个世界规则 + 章节变化 | 主概念贯穿，章节通过 X/TR/F/IL 换挡 | L3、阅读链、移动端可读 |
| 电商详情页 | 商品真实主体 + 利益可视化 | 创意服务识别与转化，不替代证据 | 商品结构、参数、证据、规格 |
| 三折页 | 一个概念跨正反六面展开 | 利用折叠、展开、遮挡和揭示 | 物理面板映射、折线安全、满幅布局 |
| 信息图／数据图 | 一个解释框架 | 让关系更直观，不把数据装饰化 | 口径、比例、图例、来源 |
| 系列图／套图 | 一个系列母题 + 单页变量 | 统一识别与有效变化并存 | 系列锚点、单页独立可读 |
| AI 原生最终图 | 一个场景或瞬间 | 画面完成度优先，不强制分层 | 用户主体、用途、画幅和事实边界 |

### 受限创意模式

用户要求复刻、严格参考或已锁定视觉时：

- 保留参考的构图机制、密度、材质、光线和字体关系；
- 只在主题替换必需的对象、动作、隐喻和资产上做创意适配；
- 不新增与参考冲突的世界观、转场和装饰；
- 仍要确保新主题与视觉机制之间存在真实关系，不能只换文案。

## 创意验收与反模式

### 六项快速测试

1. **无标题测试**：暂时隐藏标题，主画面是否仍能表达主题方向；若完全失效，视觉概念过弱。
2. **缩略图测试**：缩到 25%，是否仍有唯一第一锚点和清楚轮廓。
3. **替换测试**：把品牌、商品或活动名换成其他对象是否仍完全成立；若是，概念过于通用。
4. **删装饰测试**：删除粒子、贴纸、英文、光效和边框后，核心关系是否仍成立；若否，装饰在冒充创意。
5. **延展测试**：长图、系列或折页的第二、第三章节是否能产生新信息，而非重复主视觉。
6. **具体化测试**：是否能直接指出“什么事物通过什么动作和后期手法形成什么画面”；若仍只能说风格词，返回候选生成阶段。

### 反模式

- **主题直译**：环保必用叶子、科技必用蓝紫光、女性必用粉色、国潮必用祥云，未建立具体关系。
- **风格冒充创意**：只写“酸性、赛博、极简、高级、3D、毛玻璃”。
- **装饰堆叠**：随机加入英文、贴纸、光斑、粒子、渐变、箭头和气泡。
- **概念过载**：同时使用门户、巨物、拼贴、液体、数据世界和艺术字，无法复述主命题。
- **素材先行**：先生成一张漂亮图，再反向编造它与主题的关系。
- **只做版式变化**：三个候选只是居中、左右和上下构图，没有不同视觉机制。
- **创意损害事实**：为了好看改变商品、人物、数据、比例、包装、功能或证据。
- **创意停在文案**：概念句很巧，但构图、具体事物、动作关系和后期手法与普通模板无差异。
- **每屏一个创意**：长图或系列没有共同世界规则，像多个无关海报拼接。
- **卡片默认化**：还未判断信息关系，就把所有内容放入等大的圆角矩形。

## CREATIVE_READY 门禁

创作型图片任务在视觉系统选择、生图与 Coding 前必须形成以下唯一值：

```text
theme_fact:
theme_meaning:
audience_shift:
semantic_materials:
creative_tension:
candidate_engines: 至少 3 个机制不同的内部候选
candidate_cards: 每案的意义、具体事物、动作／关系、构图、后期手法与最终画面
candidate_difference_matrix: 三案在事物、动作、机制、观看方式和后期手法上的差异
selected_engine: 一个主 CE + 最多一个辅助机制
concept_sentence:
first_visual_anchor:
spatial_rule:
main_action:
composition_mechanism:
image_and_material_language:
typography_role:
color_semantics:
continuity_or_variation:
anti_generic_rule:
validation_results:
```

通过条件：

- 概念可用一句话复述，第一锚点、主动作和空间规则均为具体可见关系；
- 内部候选的差异来自创意机制，不是配色与排版变体；
- 三个候选均明确写出“用什么具体事物，通过什么动作／关系和后期手法，最终形成什么画面”；
- 差异矩阵证明三个候选在具体事物、主动作、空间／观看方式或后期手法中至少两项不同；
- 已选方向通过主题相关性、替换测试、缩略图测试和具体化测试；
- 创意没有越过事实、商品、品牌、平台、文字准确性和协议边界。

未达到 `CREATIVE_READY` 时，不得用风格词代替概念，不得开始正式生图、坐标布局或当前路由的源文件实现。
