# Explicit Style Terms｜显性风格词典

本文件统一跨品类使用的明确审美词、别名和最低视觉指纹。它不决定品类信息结构、载体、字体字号、色值或生产方式；只有品类 Spec／视觉系统明确列入的词才可用于该品类，未列入的词不进入候选，也不需要输出“不建议”清单。

## 使用合同

用户明确说出风格词或别名时，先到当前品类的“显性风格词适配”确认该词可用，再输出：

```yaml
style_term: STxx 标准风格词 | custom
style_alias_hit: 用户原词
style_fingerprint: 该词在当前品类展开后的构图、字体、配色、成像、表面与边缘机制
```

编号只用于名称一致性和追踪。Prompt、最终 HTML、HTML 或最终图片必须消费展开后的 `style_fingerprint` 与品类实际值，不能只拿到 ST 编号。用户未给显性风格词时不强制选择；由品类自身视觉系统完成常规选型。

## 标准词义

| 标准风格词 | 常见说法 | 最低视觉指纹 |
| --- | --- | --- |
| `ST01 白描线绘` | 白描、东方线描、墨线稿 | 单色墨线以起收、转折和疏密塑形，少填色、大留白，不使用西式体积排线冒充白描 |
| `ST02 经典波普` | 波普艺术、漫画波普、Pop Art | 原色或高饱和有限色、大尺度广告字、粗黑轮廓、漫画网点与对象重复 |
| `ST03 拼贴波普` | 波普拼贴、Pop Collage | 照片剪片、撕纸色块、漫画网点、粗字跨层、黑边与轻错版形成单一冲撞动线 |
| `ST04 新艺术装饰` | 新艺术运动、Art Nouveau | 植物鞭线、花叶纹样、拱形框饰和有机分区共同组织主体与文字 |
| `ST05 穆夏式人物海报` | 穆夏风、Mucha-inspired | 中心人物、发丝与花卉光环、纵向装饰边框和窄幅标题共同围合；不复制具体作品 |
| `ST06 印象派光色` | 印象派、印象主义 | 可见短笔触与互补色在观看距离中混合，轮廓松动，空气和自然光主导 |
| `ST07 浮世绘版画` | 浮世绘、日式木版画 | 平涂色面、明确墨线、主动裁切、层叠云水纹和有限套色 |
| `ST08 包豪斯几何` | 包豪斯、Bauhaus | 圆方三角承担功能分区，红黄蓝黑建立面积秩序，无衬线字与网格共轴 |
| `ST09 瑞士国际主义` | 瑞士风、Swiss Style | 严格模数网格、无衬线层级、左对齐、非对称留白、客观影像与一个信号色 |
| `ST10 构成主义` | 俄国构成主义、Constructivism | 红黑米白、锐角斜线、几何裁切和粗窄字形成强方向 |
| `ST11 孟菲斯` | Memphis、80 年代几何 | 高明度底、弧线、锯齿、点阵和不对称几何形成受控轻快节奏 |
| `ST12 粗野主义排版` | 粗野主义、Brutalist、反设计 | 极端字级、硬边分隔、裸露网格、黑白高反差和少量信号色 |
| `ST13 达达拼贴` | 达达主义、Dada Collage | 异质纸片、报刊字、照片切片和尺度跳变形成反逻辑张力，同时保留事实阅读轴 |
| `ST14 极简主义` | 极简、Minimal | 单一锚点、宽留白、有限字级和一种强调关系，删除无信息责任的材质与容器 |
| `ST15 超现实主义` | 超现实、梦境拼接 | 一个可解释的不可能尺度、材质或空间关系成为第一锚点，光向统一 |
| `ST16 像素艺术` | Pixel Art、8-bit、16-bit | 固定像素倍率、有限色板、硬边无抗锯齿、统一正投影或等距视角 |
| `ST17 Y2K 数字怀旧` | Y2K、千禧风、早期互联网 | 银色塑料、半透明界面、泡泡字、星芒和早期数码 UI 构成轻未来怀旧 |
| `ST18 赛博朋克夜景` | Cyberpunk、霓虹未来都市 | 潮湿夜景、深纵深城市、冷暖霓虹反射与人物或产品剪影主导 |
| `ST19 复古未来主义` | Retro-futurism、太空时代 | 流线外壳、太空海报色、模拟仪表和有限印刷颗粒表达旧时代的未来想象 |
| `ST20 3D 软质黏土` | 软陶 3D、黏土风、Clay 3D | 圆润体块、哑光微颗粒、柔和接触阴影和低锐度高光 |
| `ST21 3D 玻璃金属` | 科技 3D、玻璃拟态、液态金属 | 一个透明或金属主物件、统一环境反射、明确接地和结构标注 |
| `ST22 3D 等距微缩` | Isometric 3D、微缩世界 | 统一等距轴、比例、光向和投影，以路径或空间邻接连接场景节点 |
| `ST23 低多边形 3D` | Low Poly、低模 3D | 可见多边形切面、有限材质、统一面光和清楚剪影 |
| `ST24 纸艺定格` | 剪纸、纸雕、Paper Cut | 纸层厚度、切边纤维、逐层接触阴影和有限色纸构成景深 |
| `ST25 街头涂鸦` | Graffiti、喷漆风 | 统一喷笔或马克笔笔触、粗轮廓、动作箭头和局部墙面肌理 |
| `ST26 赛璐璐动画` | Cel Animation、平涂动画 | 平涂角色、两档明暗、清楚描线、电影式裁切和动作叙事 |

## 通用消歧

- 只说“波普”：对象重复、漫画格和广告字主导时选 ST02；照片剪片、纸层和异质材料主导时选 ST03。
- 只说“新艺术”：没有中心人物、花卉光环和纵向人物海报结构时选 ST04，不自动写 ST05。
- 只说“3D”：必须根据材质和空间任务解析为 ST20–ST23 之一，不能把“3D”原词直接当最终风格。
- “印象派”必须落实为光色和笔触成像；只有柔焦、颗粒或低饱和不成立。
