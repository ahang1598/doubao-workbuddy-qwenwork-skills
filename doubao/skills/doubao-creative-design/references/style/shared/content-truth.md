# 内容创作与事实边界

适用于全部路线。品类 ref 决定内容结构，不扩大真实事实的生成权限；下游“合理补齐／继续执行／按版面补数据”等宽泛表述受本规则约束。

- 用户未要求极简或原文原样呈现时，按主题与阅读需要主动完善标题、副标、过渡文案、栏目名、解释和 CTA 等非事实表达；新增内容须提供不同的信息价值。虚构故事与设计概念按用户授权创作。将本次确定的准确可见文案逐字写入 Brief，并注明由图片还是可编辑 DOM 承载；准确生成不等于必须由用户逐字撰写。
- 真实身份、业务承诺、价格、日期、认证、奖项、功效与数据等采用用户提供或可核验资料。真实招聘的职责、资格、福利、流程可拟待确认草稿，不能冒充企业已发布事实；防暑等健康建议和定量内容须有可靠依据，不能因填版面而编造。
- 缺失事实时可继续不依赖它的结构与视觉规划，必要事实影响最终用途时说明缺口。二维码、联系方式、报名或投递链接缺失时，按用途处理：
  - 用户明确要求可扫描、拨打、联系或跳转：询问补充真实入口，不受影响的内容可继续制作。
  - 草稿、示意、演示、效果或设计展示，且未明确要求入口可用、未用于正式发布：允许使用明确标注的占位框、示意或说明文字，如“二维码待补”“报名入口待补”，交付时说明待补项。
  - 正式发布且入口影响使用：补齐真实入口后再作为正式成品交付，即使用户未强调“可用”。
  占位须在对应位置清楚标注，不伪造可用号码、链接或二维码；改变报名、投递等行动方式须经用户确认。
- 明确虚构／演示任务可创作并清楚标识示例内容，但不能伪装为真实证据、有效联系入口或真实机构承诺。底部统一免责声明不能使虚构事实成为可正式发布的信息。
- 保留用户已确认原文、名称、片名、数量和单位。修改文案仅在授权范围内；字号／间距不足不能成为擅自删事实的理由。
