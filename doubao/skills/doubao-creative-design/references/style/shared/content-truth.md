# 内容创作与事实边界

适用于全部路线。品类 ref 决定内容结构；事实补充与披露方式统一由本文确定，下游不另设逐屏重复声明。

- 可以按授权创作标题、副标、文艺小字、过渡文案、栏目名、CTA、虚构故事及明确的设计概念。将本次确定的准确可见文案逐字写入 Brief，并注明由图片还是可编辑 DOM 承载；准确生成不等于必须由用户逐字撰写。
- 作为真实信息呈现的身份、业务承诺、价格、日期、认证、奖项、功效与数据等采用用户提供或可核验资料；概念设定按下文处理。真实招聘的职责、资格、福利、流程可拟待确认草稿，不能冒充企业已发布事实；防暑等健康建议和定量内容须有可靠依据，不能因填版面而编造。
- 缺失事实时可继续不依赖它的结构与视觉规划，必要事实影响最终用途时说明缺口。真实二维码、邮箱、联系方式或投递链接不得猜造，也不能默默替换成普通 CTA。
- 明确虚构／演示任务可创作并清楚标识示例内容，但不能伪装为真实证据、有效联系入口或真实机构承诺。底部统一免责声明不能使虚构事实成为可正式发布的信息。
- 保留用户已确认原文、名称、片名、数量和单位。修改文案仅在授权范围内；字号／间距不足不能成为擅自删事实的理由。

## 资料缺失时的概念补充

- 用户未提供事实资料时，可根据品类常识和设计目标补充名称、规格、材质、价格、功能等合理、自洽的示例设定，完成内容与视觉设计；不把设定称为已核实事实。
- 用户提供部分资料时，保留已有信息，仅对缺失部分作概念补充，不覆盖已知事实或擅自增强承诺。在同一 Brief 区分用户资料、可核验来源与补充设定，不把内部校验记录逐项搬入成品。
- 使用概念补充的作品统一说明一次，例如“概念设计，产品信息为示例设定”或“部分信息为概念设定”；放在易找到、清晰可读且不抢占主信息的位置，不逐屏、逐段重复。独立交付的作品各自保留必要上下文；纯创意文案不因由模型撰写而增加声明。
- 只有省略后会误导理解的局部条件或示意性质才就近简短说明。不得虚构真实检测、认证、奖项、用户评价、机构背书或有效联系方式，也不得用概念说明包装无依据的医疗、金融等高风险结论。
- 作为真实商品或业务信息发布前须确认或替换补充设定；概念作品展示不受此限制。影响实际使用的必要信息仍缺失时说明缺口，不以统一声明替代事实确认。
