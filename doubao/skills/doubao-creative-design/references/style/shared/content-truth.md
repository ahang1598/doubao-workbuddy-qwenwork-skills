# 内容创作与事实边界

适用于全部路线。品类 ref 决定内容结构，不扩大真实事实的生成权限；下游“合理补齐／继续执行／按版面补数据”等宽泛表述受本规则约束。

- 可以按授权创作标题、副标、文艺小字、过渡文案、栏目名、CTA、虚构故事及明确的设计概念。将本次确定的准确可见文案逐字写入 Brief，并注明由图片还是可编辑 DOM 承载；准确生成不等于必须由用户逐字撰写。
- 真实身份、业务承诺、价格、日期、认证、奖项、功效与数据等采用用户提供或可核验资料。真实招聘的职责、资格、福利、流程可拟待确认草稿，不能冒充企业已发布事实；防暑等健康建议和定量内容须有可靠依据，不能因填版面而编造。
- 缺失事实时可继续不依赖它的结构与视觉规划，必要事实影响最终用途时说明缺口。真实二维码、邮箱、联系方式或投递链接不得猜造，也不能默默替换成普通 CTA。
- 明确虚构／演示任务可创作并清楚标识示例内容，但不能伪装为真实证据、有效联系入口或真实机构承诺。底部统一免责声明不能使虚构事实成为可正式发布的信息。
- 保留用户已确认原文、名称、片名、数量和单位。修改文案仅在授权范围内；字号／间距不足不能成为擅自删事实的理由。
