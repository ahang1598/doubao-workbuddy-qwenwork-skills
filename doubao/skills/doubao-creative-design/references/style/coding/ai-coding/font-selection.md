# 字体视觉选型与搭配

<a id="font-visual-selection"></a>

本文件共享字形、视觉重量、姿态、搭配与实际文案适配判断。[共享候选 JSON](../../../../assets/fonts/font-curated-pool.json) 通过 `scripts/runtime/select_fonts.py` 召回组合、主题、语种及角色候选，不直接决定本次选型；用户锁定字形、参考证据、组合字体角色与真实阅读任务优先。实际使用字体排版时按 [字体资源文档](../../../rendering/font-family-library.md) 解析与核验；pure-image 只按需借用视觉参考，不强制安装、DOM 或独立字体契约，不保证精确 family，也不继承可编辑设计的艺术标题准入限制。生产载体、HTML、交付和截图仍由原有规范决定。

## 信息角色与选择依据

先根据文案语种、信息优先级、长度和阅读尺度确定文字角色，再结合参考与组合判断字形。用户/参考约束优先，然后按组合、主题及同角色字形标签补充；所有阶段共同遵守语种、形态与排除项。主题只补未限定维度；“科技／高级／亲民”不能直接映射到固定字体。实际字体排版中，CDN 或本地资源状态只在字形适配的候选之间作为选择条件，不是目标环境可用批准；纯图视觉参考不以安装状态作为前置门槛。

主标题承担第一焦点；栏目与章节标题组织阅读；正文承担连续说明；辅助文字处理次要注释和页码。日期、价格、数字按信息重要性分配角色：停水时间、促销价格和核心数据可以是主要信息，不能因字段名就统一降为小字。默认以一个展示家族和一个阅读家族建立层级；参考或跨语种确有需要时再增加，不为每个模块另换字体。

## 沐瑶软笔的候选准入

沐瑶 `muyao` 保留真实标签与资源，但默认不进入推荐候选。仅用户明确要求可爱软笔气质时，用 `--shape 毛笔 --tag 可爱` 或 `--shape 软笔 --tag 可爱` 放行，仍排在其他合格候选之后；此准入条件共同作用于组合、主题和全库标签扩展。单独“国风／山野／书法／毛笔／软笔／可爱／手写”，或童趣场景许可，都不能自动推导为可爱软笔诉求。明确点名沐瑶按原精确字体解析路径执行，排除项、真实字形覆盖与资源核验继续有效；不为实现点名而虚构风格标签。字体取舍是当前偏好，不是客观质量评级。

选择器只接收已判断的参数，不解析原始 query。以用户原文为依据区分明确诉求与模型自选装饰；例如“元气熊＋山野美食菜单”不等于可爱软笔，“非遗＋毛笔书法标题”保留合适毛笔候选但不自动放行沐瑶。Brief 原字体说明记录选型理由；`selection_policy.muyao_cute_brush_intent` 记录是否满足准入。若严格条件下无候选，保留缺口，不删除条件、提高返回数量或绕过选择器从字体表任取沐瑶。

## 字形维度与表达任务

| 维度 | 需要判断的可见特征 | 决策边界 |
|---|---|---|
| 形态 | 黑体、宋／明体、圆体、手写、书法、装饰展示体 | 黑体不等于粗体，宋体不等于细体；手写的自然随意与书法的笔势／章法分别判断 |
| 视觉重量 | 细、常规、中粗、粗、超粗；字腔是否仍开放 | 以目标字号下的笔画与墨色判断，CSS weight 只描述该字体文件／轴位置，不能跨家族等同视觉重量 |
| 姿态 | 直立、原生 italic、原生 oblique、字形内置倾斜 | italic 常伴随字形变化，不等于把直体斜切；字体已带斜势时不再叠 skew／旋转冒充原生样式 |
| 字面与笔画 | 宽／窄、字面大小、疏密、粗细反差、圆角／尖角、笔端特征 | 相同字号不保证等大，窄字不等于速度，圆角不等于童趣；不得水平压缩字体来凑列宽 |
| 语种与信息 | 中文字腔、拉丁大小写、数字及单位、标点、连续阅读长度 | 分别检查覆盖与气质；拉丁手写不能代表中文也有手写字形，不以同家族名代替混排验证 |

先在既有 Brief 字体说明中写出需要保留的关键形态及作用，例如“直立中粗黑体、开放字腔，标题可信有力；正文同系常规”。实际字体排版再筛精确字体，pure-image 将这些可见特征用于原 Prompt；不以“高级字体／创意字体”作为可执行选择。强参考保留其关键特征，模糊参考只记录看得到的部分。

| 表达与阅读任务 | 优先试排的类型 | 不应自动推导 |
|---|---|---|
| 专业、清晰、数据比较 | 直立常规至中粗黑体，数字轮廓稳定 | 科技不必用斜窄体；重要数字可加重，但单位保持完整 |
| 典雅、书卷、仪式感 | 有合适笔画反差的宋／明体或衬线体，重量按背景和阅读尺度选 | 高端不必细体，通知日期也可以用清楚的宋体 |
| 轻盈、安静、大字留白 | 细或常规字面，足够字号与对比 | 小字、复杂底纹、发光背景不因“精致”强用细体 |
| 力量、促销、醒目 | 真实粗／超粗字重，笔画坚实且字腔不堵 | 粗黑不自动加描边、投影或斜切 |
| 速度、运动、向前动作 | 原生倾斜／紧凑展示字形，限需动态的标题 | 同页正文、数据和章节题不必跟着倾斜 |
| 亲切、手作、个人语气 | 适度圆润字形或自然手写，按稚拙／成熟程度筛选 | 趣味不必手写；圆体不自动适合所有亲子与女性主题 |
| 东方笔意、书写仪式 | 笔势与内容相符的书法／楷意字形，短标题为主 | 新中式不必毛笔；书法不能承担密集规则 |
| 潮流、实验、独特识别 | 与参考一致的宽窄、切角、几何、像素或其他展示机制 | “创意”不是一种固定字体，不能统一回到得意黑或涂鸦 |

## 字形、效果与搭配

先看可见字形的笔画粗细、字腔和中英文视觉重量，再选择描边或投影；不能只按“科技／趣味／波普”套效果。细体、细窄字及高反差衬线的细笔画采用清晰实色，禁用描边叠投影、多层套边或错位重影。需要厚重效果时选择中粗／粗且字腔充足的字形，不以描边冒充加粗；实际字体排版须有对应真实字重，纯图则以成图笔画与字腔判断，不冒称已加载某个 face。

展示标题每次选一个主要强调机制：字形／尺度反差、实色或渐变填充、单一外轮廓、受控立体偏移等；不默认把粗描边、多色偏移、黑影和发光叠在一起。粗体也不能豁免：边缘不得侵蚀字腔、并拢相邻笔画或压住下一行。多色套印仅在参考明确需要且主字轮廓仍清楚时采用，不把“趣味”自动翻译成彩色重影。正文、参数和小标签不继承标题特效。

主标题可以有个性，章节标题按其职责选择同系稳定字形或与之相容的阅读字体，正文保持中性；不要让所有章节都继承细窄斜体与立体效果。搭配先确定谁主谁次，再用重量、尺寸或形态形成有依据的差别，避免两种强展示体争抢焦点。中英按实际字高、墨色、字距和基线协调，不机械套相同字号／weight；辅助英文不抢中文信息，主视觉本就由英文承担时保留其主次。

用最终文案在 100% 和目标阅读尺寸检查，手机产物另查实际手机阅读宽度：不放大也能辨字，字腔未堵、重影不被读成新笔画、背景不吞细线、行间不碰撞。需要修改时，先去掉描边／投影，再调整重量、字形或字号，不再加一圈边或阴影补救；实际字体排版须使用真实字重。Brief 只记录可见效果目标；仅 HTML 路线将效果参数写入最终 HTML 的行内样式并按既有流程验收，字体加载与覆盖通过不等于可读性通过。pure-image 在原 Prompt 中描述效果意图，按原流程检查成图，是否修改或重生仍服从该路线，不增加 HTML 参数、截图或自动重生步骤。

## 书法、毛笔、手写与创意字的分类召回

先拆开字形类别、风格气质和使用角色，再筛选精确字体；“软笔手写体（主标题）”描述的是形态与角色，不是精确 family，也不意味着狂放。“书法字”“书法体”统一到 calligraphy，“毛笔字”“笔刷”到 brush，“软笔”到 soft-brush，“手写字／手写体”到 handwritten，“创意字／艺术字”到 creative。书法大类包含已明确的毛笔与楷意书写，但普通硬笔手写、墨感黑体不因此自动成为毛笔；同一字体可同时属于多个类别。

| 查询类别 | 范围与区分 | 可继续限定的气质 |
|---|---|---|
| 书法 calligraphy | 中文书法、楷意书写；西文连写单独遵守语种，不替代中文 | 狂放、端正、清新、文艺、优雅、仪式感 |
| 毛笔 brush／软笔 soft-brush | 具有已确认毛笔或软笔形态的子类；不能从粗、墨感或名字推定 | 狂放、可爱、清新分别有依据才召回 |
| 手写 handwritten | 自然笔迹、硬笔、软笔、手绘字形；可爱与清新并非同义 | 可爱、清新、松弛、温暖、俏皮、文艺 |
| 创意 creative | 展示宋黑、装饰、几何实验、像素等特殊展示机制；不是所有普通黑宋圆体 | 可爱、科技、运动、力量、复古、街头、实验、优雅等 |

风格标签按明确需求取交集，不把表内全部气质一起传入。例如 `--role hero --shape 书法字 --tag 清新`、`--role hero --shape 手写字 --tag 可爱`、`--role hero --shape 创意字 --tag 科技`；西文另传 `--language en`。类别相同不代表气质相同，“创意”也不能统一回到可爱、涂鸦或得意黑。用户只说大类时比较适合本案的不同分支；明确“狂放且可爱”却没有交集时保留缺口并澄清，不静默删标签。组合与主题只排序符合约束的候选，不绕过形态、气质、语种和角色。

`tags` 维护唯一正向分类，`style_classification` 只说明依据：editorial_metadata 为已有字形、标签与设计说明的整理，visual_sample 为指定 face 和样句的真实字样审核，pending 为描述或字样不足。它不是第二套标签，也不是资源可用状态；未审核不得凭名称补风格。清松各版本、点阵各变体分别判断；拉丁字样不证明中文字形，繁体字样不证明简体覆盖。新审核的展示字体先限主标题，不根据大字样直接开放正文。

保留毛笔字样结论：沐瑶软笔以可爱、温暖手作为主，不进入狂放候选；流江草体支持狂放；马善政楷书支持端正传统；莫大毛笔的狂放／可爱／清新仍待审核。书法或手写大类可以有清新候选，不代表当前毛笔子类已有清新候选。`reviewed_brush_moods` 只记录已检查的毛笔气质范围，缺少正向标签表示本轮依据不足，不是永久禁用。查询 `trait_diagnostics` 区分未知标签、已知零候选及毛笔气质待审，不代表其他类别已完成字样审核。

Brief 在原字体说明中记录“类别＋气质＋角色”、选型理由及已有证据；HTML 再落实精确 family／face 与真实文案试排。补充风格须有明确描述或相同文案、字号、无附加特效的字样依据；更新原字体池，不另建候选表。若新证据与旧标签冲突，先复核再修正，不能仅因某字体已有 CDN 或列在组合中就保留错误匹配。字体资源协议、严格报错与真实覆盖验证仍按下文执行。

## 精确字体与替代边界

实际使用字体排版时，核对精确 family、实际 face、真实 weight 与 normal／italic／oblique 组合及当前文案覆盖；可变字体核对轴范围与选中实例。仅明确引用 [平台字体表](../../../items/fonts.md) 的 Canvas Item 字段受其 family 和注册字重限制，不泛指所有 XML。HTML Item 内的 DOM 按 [HTML 协议](../../../html/coding-rendering.md) 验证目标环境实际加载，不因未列平台表而拒绝；远程字体必须按 [Web 字体契约](../../../rendering/web-font-contract.md) 输出唯一受控字体声明块，其他视觉 CSS 保持行内，本地资源或推荐不能替代加载证据。分别列出的 weights 和 styles 不证明任意组合都存在，视觉粗细也不能直接换算成 CSS 字重。缺少粗体或斜体时重新选 face／候选，不依赖伪粗、伪斜或横向压缩。pure-image 的候选名称只是视觉参考，不据此声称实际 face 或逐字覆盖已验证。

得意黑仅在所需形态确为倾斜、窄长、尖锐笔势时作为候选，不能成为科技、极简、趣味或商业题材的默认标题。库内 Smiley Sans 的字形记录为 400 Oblique，平台表以 400 italic 注册；二者是字体姿态和平台枚举的不同证据，不能互相改写。受该表约束的 Item 字段按实际协议提交；HTML 使用目标环境核验的真实 face 与样式，不直接照搬 Item 枚举。不推断 700／900，也不自动承担正文、数字单位及所有章节。实际字体排版中的其他字体同样以当前实际文件与目标环境为准，既有核验不能代替本次核对；纯图借用其字形特征不等于使用了该 face。

先保留关键形态、重量和姿态，在同角色适配字体中选择替代；其次选择同形态较中性的候选并记录差异。没有形态相符资源时记录缺口，依既有授权处理；用户锁定字形不静默替换。思源黑体可用于中性黑体任务，不作为宋体、手写和书法的通用视觉回退。中文、拉丁、韩文、日文以及数字、币种和单位分别检查；推荐语种不等于逐字覆盖。字体家族同名不证明各语言字形均可用，避免静默混排。

用户禁用的胡敬礼毛笔行书及 `HuJingLi-Mao`、`胡敬礼毛笔行书简.TTF` 等别名不得作为候选或回退；只有用户明确解除才恢复。旧案例的飞波正点体也只是该案选择，不是所有手写场景的默认答案，不据此删除或卸载任何系统字体。

## 用真实文案判断适配

实际字体排版的关键展示文字、混排或不确定候选先比较无特效字样。通常用 2–3 个真正不同且适配的候选；明确命中时不凑数量。先在同字号、同背景下辨别形态，再按预计字级、栏宽和行数放回标题、正文、数字与单位组合，观察字腔、细线、墨色、基线、换行和主次。

实际字体排版按已锁定协议记录选中 family、实际 face、weight、style、字距与行高；HTML 的实现参数仅保存在最终 HTML，既有 Brief 字体说明记录视觉选择理由、替代损失和试排结果，不新增固定字段结构。声明了某字体或本地安装成功不等于目标环境实际使用了它；沿既有验证能力记录证据，不虚构实际 face，无法观察时保留未验证状态。pure-image 只在原 Brief／Prompt 与产物记录中保留字形意图和可见结果，不填报未经证实的 family／face。两者均不改变库内配方的可用状态，也不新增截图或交付步骤。


新中式、杂志编辑与自然生活的字形分支按 [主题策略](../../../rendering/font-theme-strategy.md#新中式杂志编辑与自然生活的分支) 查询同一候选池。古籍字形与书写姿态不互相代替；同系列不同字包不是独立风格，日语标题候选不代表中文覆盖。新增主题沿用本文件的字重、连续阅读与排除项检查。

## 与主题策略和平台资源共同验收

先按主题策略中的 VI／三折页／混排情景查询，选型时只判断字形、重量和实际阅读任务。实际字体排版默认试排无特效文字，再放回真实素材与目标尺寸；pure-image 结合已有参考与成图判断，不为试排另行生成样张；强展示标题不自动传给所有章节，正文不为丰富候选而使用装饰字体。

实际字体排版分别核对查询结果中的 `catalog_resolution`、`resource_status`、`platform_status`、`registered_faces` 和 `coverage_status`，这些查询状态不替代目标环境验证；pure-image 查候选时只借用视觉信息，不默认串行进入资源执行。候选更多只扩大选择空间，不改变适用的 Item 字段白名单、已锁定产物格式、HTML 字体加载限制或交付协议。`shortfall` 是保留约束后的真实缺口，不能用错误语种、伪粗体或默认 Sans 填满。
