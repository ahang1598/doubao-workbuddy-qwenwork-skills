# 思维导图与概念关联图内容 Brief

在当前任务已有设计 Brief 中填写“思维导图内容结构”；没有时根据当前对话创建，同任务不另建副本。先确定概念、层级、关系与依据，再交给 Visual 决定布局和视觉编码。

## 底图结果约束

凡本品类进入 HTML/CSS 设计，作品级底图必须包含与主题和视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整张画布。节点与关系密集区域可以局部降为纯色或低纹理以保证阅读，但仍须属于同一底图系统。Spec 只记录这项结果门禁和底图职责；具体材质、色场、变化方向、生成方式与 Prompt 由对应 Visual 决定。

## Brief 结构

```markdown
## 思维导图内容结构

- 主题与受众：
- 用途：知识梳理、项目拆解、阅读／会议整理、创意发散或概念关联
- 内容来源与范围：原始资料、章节／页段、需保留内容和明确排除项
- 整理权限：提炼摘要、保留原文、允许扩写的想法或待确认解释
- 结构：树状层级或概念网络，主题入口与分类依据
- 节点内容：准确名称、必要说明、来源和状态
- 关系清单：哪两个节点、什么关系、有无方向、原文依据或推断说明
- 阅读方式：总览到细节、分区检索、对照比较或关联探索
- 视图计划：总览、局部展开、折叠范围及返回定位
- 配图计划：主题图、节点辅助插画或真实证据图的数量、真实 URL 短链、直接使用／编辑／借鉴方式和用途；无需配图时说明
- 载体与尺寸：静态／交互、宽 × 高及单位、语种与目标阅读环境

### 每个视图
- 职责与展示范围：
- 节点与关系：引用同一内容，不另写一套结论
- 可见文案与状态说明：
- 配图与来源：
- 折叠或外部关联：隐藏什么、到哪里展开或查找
```

节点和关系在内容中记录一次，视图引用其名称；同名不同概念增加语境说明，不为省事合并。无需让用户填写内部 ID、JSON 或机器 Schema。

## 用途与常用配图

| 用途 | 内容组织 | 配图与用途 |
| --- | --- | --- |
| 知识梳理 | 分类依据、层级与必要解释 | 少量主题插画或概念示意辅助记忆，不要求每节点一图 |
| 项目拆解 | 目标、工作、交付物与责任范围 | 真实产品或项目截图帮助识别；包含关系不自动等于执行先后 |
| 阅读／会议整理 | 观点归属、讨论、决定与待确认 | 材料截图或原图作证据，保留出处与上下文 |
| 创意发散 | 开放想法、方向与已选结论分开 | 灵感图或主题母题辅助联想，不能把生成想法写成事实 |
| 决策要素梳理 | 选项、维度、差异与缺项 | 对象真实图或示意按需，不强配不存在的对应关系 |
| 概念关联 | 跨主题关系名称、方向与局部集群 | 相关对象或证据图；装饰不能暗示额外因果 |

主要表达连续条件判断时应采用流程结构，主要表达作用反馈时应采用机制结构，主要表达数值比例时应采用统计图，不硬塞为知识分类。混合材料可以分模块保持各自语义。

有可用参考图时，在对应配图或节点条目记录真实 URL 短链和具体用途。已有短链不得省略；未取得时写“短链待补”，不得编造 URL 或用本地路径代替。

## 层级、关联与依据

- 树状层级有一个根，每个其他节点只有一个主父节点，主层级无循环并能从根到达。跨分支联系单独写，不偷偷增加主父节点。
- 概念网络允许多中心、多入边及有意义的循环；若含层级关系，该部分仍无循环，不把网络按树强行删边。
- “相关”“包含”“支持”“依赖”“导致”不同，关系名称和方向以材料为准；原文出现两个词不等于确认它们相互作用。
- 关系依据分为原文明确、整理推断、开放提案；非明确关系在成品中有可见说明，不能只留在规划记录。
- 摘要保留对象、条件、否定、时间范围与观点主体，不能把“建议尝试”改成“已经决定”。
- 节点长短与分支数量由内容决定，不为对称补造节点，不为少交叉删掉关键联系。

## 总览、局部与媒介

总览帮助定位，复杂分支可另页展开。每个视图列明展示的节点、关系及折叠内容，局部页保留祖先路径与返回定位。重要外部连线说明另一端去向，不悬空。

要求全量展示时，所有范围内内容须在总览或局部页实际出现，不能用“还有若干项”替代。仅要总览时可折叠，但隐藏范围与展开方式要明确。

用户尺寸优先；未指定的横向总览可先用 1600 × 1200 px 作为设计假设，再以最长节点与最密集关系试排。手机不能只缩小大画布，必要时拆局部视图；印刷按实际纸张核对。

静态图用页名、区域名或索引导航，不假装可点击展开。交互要求单独列出展开、收起、搜索、定位、返回总览与来源查看，后续必须实际验证。

## 内容补写与核对

材料整理不默认补成“完整知识体系”。用户允许发散时可生成明确标注的想法或示例，不将推断冒充来源结论；真实业务、健康、身份和科学关系缺口标待核实。开放想法、争议与待确认状态可以是完整创意图的一部分，但不能隐藏影响理解的缺口。

保存前核对节点覆盖、准确关系与方向、依据状态、折叠与跨视图定位。图结构正确不证明知识正确，未核实专业内容如实标记。

## 写回 Brief 的内容结构规范

- **内容结构生产规范**：按本 Spec 把主题范围、节点、主层级、跨分支关系、方向与依据、视图职责、折叠范围、准确文案、素材来源和待核实项写入同一 Brief。
- **内容结构验收规范**：核对节点覆盖、根与父子关系、循环边界、连线端点和方向、依据状态、总览／局部定位及交互范围，确认没有为对称补节点、误造因果或把整理推断冒充原文。
