# 个人名片与会员卡内容 Brief

在当前任务已有设计 Brief 中填写“个人卡片内容结构”；没有时根据当前对话创建，同任务不另建副本。本文件确定内容、正反面职责与使用条件，风格与排版交给 Visual。

## 底图结果约束

凡本品类进入 HTML/CSS 设计，作品级底图必须包含与主题和视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整张画布。联系方式、权益和条件区域可以局部降为纯色或低纹理以保证阅读，但仍须属于同一底图系统。Spec 只记录这项结果门禁和底图职责；具体材质、色场、变化方向、生成方式与 Prompt 由对应 Visual 决定。

## Brief 结构

```markdown
## 个人卡片内容结构

- 卡种与用途：名片、品牌联系卡、会员卡、集点卡、礼品卡、储值卡或体验卡
- 主体与记忆点：卡片属于谁／哪个品牌，希望第一眼记住什么
- 内容：准确姓名／品牌、身份／服务、联系方式，适用的权益、金额、期限与条件
- 信息链：第一眼识别什么、进一步了解什么、最后怎样联系或使用
- 载体与尺寸：实体／数字，宽 × 高及单位，单面／双面，语种
- 卡片／版本数：按真实人员、等级、面额或状态统计，不额外增加等级
- 配图计划：背景主题与用途；Logo、作品、照片或插画的数量、真实 URL 短链与使用方式
- 系列内容：哪些内容共用、每张变体分别属于谁，哪些字段随版本变化
- 制作约束：印刷、圆角、出血、刀模、可写区、盖章区或数字状态的已知要求

### 正面
- 职责：
- 上屏文案：写全准确内容
- 配图与来源：

### 背面（仅双面卡）
- 职责：
- 上屏文案：写全准确内容与必要限制
- 配图与来源：
```

数字卡按实际状态写条目，不强制正反面。单张只填一次；系列共用结构，逐张补不同姓名、卡号、等级、面额和规则，不能复制后遗留上一张信息。

## 常见卡种与配图

| 卡种 | 内容与阅读重点 | 常用配图与用法 |
| --- | --- | --- |
| 个人／商务名片 | 姓名 → 职业或服务 → 主要联系入口 | 可用个人作品、本人照片或与服务有关的主题背景；照片、Logo 与二维码并非必选 |
| 工作室／品牌联系卡 | 品牌 → 做什么 → 怎样联系 | 现有 Logo、代表作品或品牌物件帮助识别，作品必须有真实来源 |
| 会员卡 | 品牌归属 → 身份／等级 → 使用识别与权益入口 | 品牌纹样、标识或 IP 建立归属；等级差异不能只靠颜色 |
| 集点卡 | 参与规则 → 完成点数 → 奖励与兑换条件 | 主题插画辅助参与感；实际点位数量由规则确定，装饰点不能被误认成已完成印章 |
| 礼品卡 | 赠送内容／面额 → 兑换方式 → 期限与范围 | 与礼赠有关的物件、插画或品牌背景；实物照片不能暗示额外赠品 |
| 储值卡 | 卡身份 → 查询与使用 → 金额含义 | 品牌资产为主；面值、初始储值和实时余额分开，不把静态金额写成实时状态 |
| 优惠／体验卡 | 权益 → 条件 → 使用入口 | 服务或产品真实图帮助理解体验，不虚构折扣、次数与适用范围 |

这是配图候选，不是卡种对应风格。选中的图写入配图计划，背景主题元素不必拆成多张。待生成装饰标明“待生成”；有可用参考图时记录真实 URL 短链、直接使用／编辑／借鉴方式和具体用途。已有短链不得省略；未取得时写“短链待补”，不得编造 URL 或用本地路径代替。

## 正反面、系列与规格

- 内容可按“识别／联系”“礼遇／规则”“展示／盖章”分配；不要求两面同等密度。默认让一面承担识别、一面承担解释或操作，避免两面都塞满。
- 个人／商务名片常用密度：正面保留姓名／品牌、身份和 1 个主要识别元素，共 2–4 组信息；背面放 2–4 个联系入口或一段 2–3 行服务说明。若只有姓名与电话可做单面，不为双面补内容。
- 工作室／品牌联系卡常用密度：正面为品牌、业务短句和主图，背面为 3–5 个联系／服务信息组；代表作品只选 1 个主视觉或 1–3 个有明确归属的缩略内容。
- 会员／储值／礼品／体验卡常用密度：正面为品牌、卡种／等级、持有人或面额等 2–4 组识别信息；背面为 3–6 条核心规则、期限、查询／兑换入口。规则更多时使用短句分组或另附规则页，不缩成无法阅读的小字。
- 集点卡常用密度：一面保留品牌、奖励与简短规则，另一面以实际点位为主；常见 6–12 个点位，具体数量严格服从真实兑换规则，点位之间保留可盖章或标记的实际操作空间。
- 二维码、条码、签名、盖章和手写区都按真实操作尺寸占位，计入卡面密度；它们不能被当作可压缩装饰。Visual 可调整比例和留白，但不得改变上述内容职责或把次要信息提升为同等焦点。
- 用户尺寸优先；未指定时名片可先用 90 × 54 mm，标准会员卡可先用 85.6 × 54 mm，均标为设计假设，不代表供应商已确认。数字卡记录实际目标显示尺寸，不照搬毫米规格。
- 出血、刀模、圆角、烫印、压凹、透明材料和套准依据供应商条件；不知道就记待确认，不编造可生产结论。
- 手写、盖章区域按真实工具与材料预留；二维码／条码使用实际来源并验证目标，不生成虚假凭证。
- 数字卡明确有效、过期、可用、已用等状态及数据来源。视觉稿不等于已实现开户、支付、核销或余额更新。
- 每个卡面提供独立清洁稿；桌面、纸堆和透视 Mockup 只作展示，不替代卡面。

## 内容补写与核对

身份、电话、账号、卡号、金额、权益、期限与兑换规则以用户或核实来源为准；可润色服务表达，不扩大资格或权益。草稿缺内容时可显示明确占位，并就近注明“**注：**以下内容由模型根据经验生成，非真实事实，正式使用前请替换为已核实内容”。不制造能被误用为有效凭证的编码；正式使用前完成核实与替换。

保存前核对每张卡的持有人、正反面归属、权益条件、系列变量及来源；不适用项省略，不要求内部机器 Schema。

## 写回 Brief 的内容结构规范

- **内容结构生产规范**：按本 Spec 把卡种、主体、准确身份与联系内容、正反面职责、权益条件、系列变量、尺寸、操作区、配图来源和待确认项写入同一 Brief。
- **内容结构验收规范**：逐卡核对持有人、号码／金额／期限／权益、正反面归属、扫码／盖章／手写区、系列差异和来源，确认静态稿没有冒充有效凭证、实时余额或核销能力。
