# Logo 内容与系统 Brief

在当前任务已有设计 Brief 中填写“Logo 内容与结构”；没有时根据当前对话创建，同任务不另建副本。确定品牌事实、生成范围、参考资产、交付状态和提案职责，不在 Spec 挑具体造型或配色。

从零设计 Logo 默认使用生图工具先生成干净的平面彩色主标，再把确认后的主标作为唯一参考图，用图片编辑工具依次生成单色、反白、图形标和组合标等状态。Coding 只负责准确说明文字、状态标签、对齐和提案展示排版，不默认用代码绘制 Logo 图标。

## Logo 入口与确认门禁

- **已知品牌名必须进入标准 Logo**：只要已经明确品牌名称，每个首轮候选和平面彩色主标都必须以准确品牌名形成字标或图文组合标，禁止只输出独立图形、角色头像、物件符号、首字母图标或抽象符号。品牌名必须是 Logo 本体的主要识别层，不能缩成角落小字、图片说明或可有可无的副标题。独立图形标只能在含品牌名的组合主标被确认后，作为同一响应式家族的附属变体派生。
- **品牌名未知时先澄清**：不得用占位名称、随机英文、通用首字母或纯图形方案绕过名称缺失；取得准确名称、大小写、空格、标点和中外文关系后再生成正式候选。
- **用户已提供 Logo**：核对准确品牌名、文件、版本、授权、允许修改范围和目标用途；用户确认后直接登记为唯一身份母版，不额外生成竞争 Logo，也不把参考风格图、历史候选或应用 Mockup 当作第二母版。
- **用户未提供 Logo**：先冻结准确文字、核心概念、使用环境和禁用项，再生成多个在核心概念、造型路线与视觉气质上真正不同的 Logo 候选，逐一完成交付并说明差异，等待用户明确选择。换色、换字体、轻微变形、改变排版或更换 Mockup 不算不同方向。
- **确认后唯一母版**：用户明确确认一个候选后，该版本成为后续单色、反白、透明底、组合标、紧凑标和小尺寸状态的唯一视觉锚点；所有派生必须以该母版调用 `image_edit`，禁止只凭文字重生或把未确认候选混入正式家族。

候选交付前，每个方向都要记录一句核心概念、主造型机制、黑白识别方式、适合的品牌气质、目标场景、小尺寸风险与主要禁用项，让用户比较真实设计差异，而不是只比较颜色和效果图。

## 底图结果约束

凡本品类进入 HTML/CSS 提案或系统展示，作品级底图必须包含与品牌和视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整张画布。Logo 单色、反白、灰阶和最小尺寸测试所需的纯白／纯黑功能色块属于局部测试载体，不代替作品级底图。Spec 只记录这项结果门禁和底图职责；具体材质、色场、变化方向、生成方式与 Prompt 由对应 Visual 决定。

## Brief 结构

```markdown
## Logo 内容与结构

- 品牌与受众：品牌做什么、面向谁、希望形成什么认知
- 准确名称：中文、英文、缩写、大小写、标点及已确认描述语
- 任务范围：从零生成主标、已有标志编辑、响应式延展或完整 Logo 交付
- 参考资产：已有 Logo、品牌／产品／风格参考图的真实 URL 短链、参考角色与允许借鉴内容
- 候选与确认状态：用户是否提供 Logo；未提供时各候选的核心概念、主造型机制、黑白识别、小尺寸风险与选择状态；确认后的唯一母版 ID／短链
- 必须保留与允许修改：轮廓、字形、颜色、组合、符号与文化禁区
- 标志范围：已知品牌名时，标准主标固定为含准确品牌名的字标或图文组合标；图形标、首字母标、角色标、紧凑副标或徽章只作为确认后的附属家族成员；已有要求与待设计项分开
- 图文锁定关系：横向并列、上下堆叠、嵌合／咬合或字标主导＋图形陪衬；角色／图形与品牌名共享的描边、圆角、色块、负形、基线或比例语言；中外文与描述语的准确层级
- 创意概念与风格：品牌性格／消费体验、一句话趣味概念、主体与产品的关系、视觉风格分支；不得把“XX 产品 Logo”自动理解为“画产品外形＋品牌名”。先按 [Logo 创意与风格参考](../../shared/logo-ip-wordmark-background-reference.md) 区分内容机制与表现语言，再进入生成。
- 线条风格：线重、端点、转角／曲率、闭合与开口、黑白节奏、表面完整度，以及角色、字标和身份容器共享的至少两项线条语言；不得只写“可爱”“手绘”或“有线条感”
- Logo 配色上限：默认 `1–3` 个印刷色角色，常规最多 `4` 个且第四个必须是有固定对象的小面积强调色；黑、白、奶油色、灰、正式描边、影边和身份容器填色均计入。超过上限必须记录用户已有资产或不可替代语义依据，并规划低色数、单色和反白降级版
- 使用场景：头像、导航、印刷、标牌等，实际最小使用尺寸与单位
- 交付状态：平面彩色主标、黑色单色、白色反白、透明底、图形标、横版／竖版组合、小尺寸及用户指定变体
- 生成依赖：第一张主标如何生成／编辑，后续每个状态分别引用哪张确认图
- 提案范围与信息链：主标 → 单色／反白 → 图形与组合标 → 小尺寸 → 展示与应用验证
- 配图计划：真实母版与应用资产；材质、环境或 Mockup 的数量、来源、用途
- 画板与交付：尺寸、画板数、母版／预览／规范／导出范围和可编辑要求
- 权利与缺口：授权、字体许可、近似风险及待核实信息

### 每个变体／提案画板
- 名称、使用场景与职责：
- 需要表达的内容与准确文案：
- 对应母版、素材与来源：
- 需要验证的条件：
```

标志类型与系统范围分开：一个图形标可以有多个响应式版本；响应式不是一种标志类型。普通放置既有 Logo 不扩展为完整品牌设计。

有可用参考图时必须在对应条目写入真实 URL 短链，并说明它是身份母版、内容参考还是风格参考，以及用于直接编辑还是借鉴。已有短链不得省略；未取得时写“短链待补”，不得编造 URL 或用本地路径代替。

涉及 IP 角色 Logo、角色／物件与品牌名组合、字标描边、贴纸边、投影边、身份容器或图片背景处理时，完整读取并应用 [Logo IP 角色、字标描边与背景处理参考](../../shared/logo-ip-wordmark-background-reference.md)。参考图只提供机制证据，不把其中的角色、字形、容器或品牌事实写入本品牌。

## 默认交付内容与顺序

用户只说“做一个 Logo”且未限制交付时，默认完成以下内容；用户明确只要单张主标时可缩减：

1. **平面彩色主标**：第一张干净主图，使用生图工具生成；已有 Logo 时以真实短链作为图1编辑，不另造身份。品牌名称已知时，主图必须包含准确品牌名并形成字标或图文组合标，不得只显示图形。
2. **黑色单色版**：将确认主标作为参考图编辑为白底黑标，保持轮廓、负形、字形和比例。
3. **白色反白版**：继续以确认主标为参考图编辑为黑底白标，保持同一结构。
4. **透明底资产**：从确认的平面标志确定性抠图／去底，保留完整边缘和内部孔洞，不重新生成近似图。
5. **图形标与组合标**：需要字标时，以确认图形标为图1，按准确品牌名生成横版组合和竖版组合；两种组合分别输出，不在一张主图中拼多个候选。
6. **小尺寸状态**：按头像、图标或 favicon 的实际尺寸检查；必要时以主标为参考编辑简化细节，而不是直接缩小到糊。
7. **Logo 展示版**：使用以上真实状态进行组版，至少展示主标、单色、反白和组合关系；说明文字由 Coding 完成。
8. **应用预览（按需）**：只选能验证实际使用的 1–2 个场景，必须继续引用确认主标，不把 Mockup 当母版。

完整 Logo 交付通常包含上述 1–7；轻量任务至少交付平面主标、单色和反白。每个衍生状态都记录所引用的主标真实短链，不能只凭文字重新生成。

## 内容与应用范围

| 范围 | 内容重点 | 常用配图与用途 |
| --- | --- | --- |
| 母版生成／授权修改 | 从零生图主标，或基于已有身份编辑 | 新建主标使用生图工具；已有 Logo 使用真实母版编辑，不为展示重画相似 Logo |
| 组合系统 | 图形与字标、横竖与紧凑使用场景 | 同源组合、准确源文字、光学间距说明，构造图由真实几何生成 |
| 响应式系统 | 大尺寸到小尺寸的保留与删减 | 主标、紧凑版、小尺寸版与头像测试，同一母版派生 |
| 规范提案 | 识别、结构、单色、反白、安全区与最小尺寸 | 平面母版与真实测试图，不能全靠材质 Mockup |
| 应用验证 | 数字、实物或环境中的实际适配 | 与品牌业务有关的场景与载体，生成场景作为示意，不冒充落地案例 |

提案按需求安排，不为固定页数凑杯子、袋子或招牌。完整 Logo 交付需要覆盖平面主标、单色、反白、透明底、所需组合、小尺寸和展示版；完整品牌手册仍需用户明确要求。

## 母版、变体与来源

- 从零创建时，先用生图工具获得含准确品牌名的平面彩色主标，经选择／确认后登记为唯一身份母版；后续状态全部通过图片编辑引用它。独立图形标只从确认后的组合主标派生。已有 Logo 时，用户指定或已确认资产直接成为唯一母版。
- 生图候选在确认前只是方向稿；确认后不能再绕过母版另生成竞争标志。Coding 消费各状态成图完成规范文字与展示排版，不替代母版生成。
- 紧凑版、小尺寸版可按确认范围简化细节、扩大负形或调整细线，但保留主轮廓、核心手势和字形关系；记录适用尺寸，不写模糊的“自动缩放”。
- 保留准确品牌文字源。字体派生字标核实字体来源和商标使用许可；完全自绘与生成位图如实注明来源，不虚构字体文件。
- 位图母版是可替换图片，不等于原生矢量；HTML 内嵌 SVG 只有具备真实路径时才称路径可编辑。外部专业源必须确实存在。
- 品牌名称、法律主体、历史、注册类别与权利状态不推测；设计图形可以创作，品牌事实不能编造。

## 尺寸、文案与核对

用户指定尺寸优先；规范画板可先以 1600 × 1200 px 作为设计假设，Logo 本体尺寸由使用场景决定。头像需看圆形／圆角裁切，小尺寸可按实际场景测试 16–48 px；印刷按所需毫米尺寸验证，不把像素值当成印制规格。

说明文案只描述真实构造与实际验证，不编造黄金比例、历史渊源或“保证可注册”。视觉近似初筛不等于商标检索。缺失名称、母版或授权范围列待补；虚构品牌演示须明确标示。

保存前确认：名称准确，母版来源唯一，变体和提案职责与实际需求相符，应用素材有来源，未验证规格与法律结论未被写成事实。

## 写回 Brief 的内容结构规范

- **内容结构生产规范**：按本 Spec 把品牌事实、准确名称、任务范围、唯一母版、标志与组合状态、使用场景、画板职责、来源、授权和待确认项写入同一 Brief。
- **内容结构验收规范**：核对名称、母版、候选确认、变体、组合、单色／反白／小尺寸职责、应用来源与权利边界。品牌名已知时，确认每个首轮候选和标准主标均包含准确、清晰且作为 Logo 本体主要识别层的品牌名，没有用独立图形或角落小字冒充完整 Logo；品牌名未知时，确认已先澄清而非使用占位名称。用户未提供 Logo 时，确认已交付多个在概念、结构与气质上真正不同的候选且用户明确选定唯一母版；用户已提供 Logo 时，确认没有误触发竞争候选。确认没有用 Mockup 代替母版、用位图冒充矢量、用换色或轻微改版冒充多个方向，或把未验证法律结论写成事实。
