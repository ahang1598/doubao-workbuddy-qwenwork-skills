# 菜单视觉参考库（按需读取）

本库保存参考图提取的十种视觉思路，供需要灵感或指定类似风格时选读。不是固定模板清单，不要求逐套阅读或必须从中选择。

日常设计先读 [菜单 Spec](menu-spec.md)；风格、布局、配色、图片生成和 CSS 实现入口见 [菜单设计方法](menu-spec.md#menu-visual-css-routing)。本库补充案例细节，不重复定义生产与验收流程。

## MN-S01｜奶油纸感·饮品图鉴（参考 1）

**风格词**：温润、手绘写实、图鉴、纸感、克制、精品咖啡。

**视觉公式**：浅奶油纸底＋独立杯型图像＋松弛的图鉴排列＋每杯下方准确名称与价格。顶部标题与细规则线建立入口，底部集中品牌和联系信息。杯子本身是视觉主体，信息随杯子成组，不用大面积卡片壳。

**配图与构图**：统一视角与光线，保留玻璃、咖啡分层、奶泡与装饰物的区别；不同杯型按视觉重量平衡，不把高脚杯压扁以凑同高。图像与对应文字保持近邻，透明或干净背景有利于融入纸底。

**适配**：适合特色咖啡、茶饮、鸡尾酒和少至中等品项图鉴；列数、行数随实际尺寸改变，手机可改为少列或逐组展示。

**Prompt 槽位**：单杯［准确饮品外观］，［实际杯型与已确认配料］，温暖柔光，细腻写实插画或统一实拍语言，独立干净背景，无文字、价格和标识。

**验收与避免**：一眼能辨认不同杯型，文字不会成为大图下不可读的小点。不要把此风格改成只有纸纹和饮品名单的无图菜单。

## MN-S02｜山野自然·主视觉与密集分类（参考 2）

**风格词**：山野、苔绿、自然、原木、食材感、质朴丰盛。

**视觉公式**：一块强食物场景主视觉＋浅色分类信息场＋重点菜图与高密度列表交替。苔绿与米白连接环境摄影和点单信息，主视觉承担记忆，分类区承担检索。

**配图与构图**：食物与木器、树枝或低调自然材质形成统一环境，但食物应比布景更明确。大图、小图和无图条目有主从；上下或正反页沿用分类标题、线条和价格规则。

**适配**：烧烤、山野餐饮、菌菇、自然主题餐厅。山野气质不代表可以新增野生、原产地或有机等商品承诺。

**Prompt 槽位**：［已确认菜品］置于［指定器皿］，克制原木／自然材质环境，柔和定向光突出真实食材质地，保留信息区，无文字与推荐章。

**验收与避免**：密集页面仍有足够的代表菜视觉，分类清楚；不把背景绿纹理当作图文并茂，不为森林气氛遮住菜品。

## MN-S03｜玄黑精致·料理纵向陈列（参考 3）

**风格词**：深黑、精致、矿石、仪式、克制金色、日式料理。

**视觉公式**：低亮度有质感底面＋一条纵向料理陈列＋侧边安静菜序文字＋底部套餐价格。明亮食材在深底上形成连续视觉节奏，金色只点出标题、品牌或价格。

**配图与构图**：料理位置形成可追踪的纵向轴，保留鱼肉光泽、纹理与米饭轮廓；图像可以占较大画面，文字拥有独立暗部留白。确为套餐内容时逐项对应，装饰陈列不能暗示未包含的菜品或数量。

**适配**：品鉴菜单、精选套餐、少品项寿司或甜点陈列。数量和排列长度来自实际内容，不固定十件或指定套餐价。

**Prompt 槽位**：［确认料理集合］在深色石质或布面上沿纵向有节奏排列，定向光突出食材细节，左侧干净暗部供排版，禁止文字和随机增加料理。

**验收与避免**：高级感来自食物与光线，不是单纯黑底金字。正文与金色小字需按实际显示尺度提高对比。

## MN-S04｜浅金留白·海鲜套餐（参考 4）

**风格词**：浅金、洁净、海鲜、宴席、留白、轻盈。

**视觉公式**：顶部／侧边海鲜主体＋浅纸底和有方向的边缘过渡＋主题标题＋中部套餐说明与价格＋底部真实菜品小图带。

**配图与构图**：主体从边缘进入，留出标题与套餐信息的干净区域；小图补充套餐细节，不仅重复同一食材。纵排标题只用于适合的主题字，金额和使用条件仍易读。

**适配**：海鲜套餐、宴席、分享餐。可使用清楚主体边界或轻刷痕过渡，不要求生硬套用水墨笔刷。

**Prompt 槽位**：［已确认海鲜主体］与清洁冰面或浅色环境，突出真实形态，预留［标题方位］留白，无酒店 Logo 和文字。

**验收与避免**：完整点单菜单需要套餐包含项或明确入口；不能只有食材大图和宴席价却无法理解买到什么。

## MN-S05｜秋色编辑·多盘斜向场景（参考 5）

**风格词**：秋色、陶土、奶油、柔光、编辑感、季节餐桌。

**视觉公式**：两块斜向或非对称色域＋错落菜盘＋一侧主题标题＋另一处安静说明。盘子穿过背景分界，让图像和底面有整体关系。

**配图与构图**：不同器皿形成大小节奏，菜盘与阴影方向一致；不把菜品分别塞进互不相关的白色小卡。已有摆盘保持真实，合理裁切外围器皿但不隐藏关键份量。

**适配**：季节新品、菜单封面、精选菜介绍页。若要完整菜单，沿用色域和摄影语言建立后续菜品价格页，不能只交一张活动宣传图。

**Prompt 槽位**：［已确认多盘菜］置于陶土暖色与奶油浅色组成的统一桌面，斜向空间关系、柔和自然阴影，［方位］预留文字，无品牌或日期。

**验收与避免**：图像是主体，文案可读；参考中的活动时间、地址和品牌不迁移到新任务。

## MN-S06｜朱红招牌·丰盛实拍菜单（参考 6）

**风格词**：朱红、热闹、招牌、丰盛、传统餐馆、清楚点单。

**视觉公式**：招牌大图与红色识别区＋米白底图文菜组＋稳定菜名价格条＋必要分类标题。首个单元建立招牌，后续单元按品类形成可浏览的食物阵列。

**配图与构图**：主菜图显著强于普通条目图；普通菜图可同类重复版式，但大小不必全相同。餐具、拍摄角度和光线相容，避免主体被密集印章遮挡。

**适配**：中餐、海鲜家常菜、招牌菜丰富的餐厅。非遗、传承、销量、获奖等章印文字属于事实，不从参考复制或自行生成。

**Prompt 槽位**：［真实菜品］盛于［实际器皿］，暖调餐桌摄影，突出油润质感和真实配料，主体完整，环境低干扰，无印章、价格和文字。

**验收与避免**：同一行图、菜名和价格明确对应，红色不压住菜品；不把整本菜单做成只有一张封面图与其余文字列表。

## MN-S07｜暗调季节·食材微距（参考 7）

**风格词**：暗调、季节、浓郁、微距、黑金、沉浸。

**视觉公式**：上部或中上部强食材近景＋自然向下变暗的文字承托区＋局部主题字＋下方季节与使用说明。

**配图与构图**：以真实食物光泽和近景尺度建立食欲，焦点明确，背景逐渐安静。文字不能随意压在反光食材上；自然暗部优于给全部图像盖厚黑蒙版。

**适配**：季节食材推广、菜单封面、专题页。若用户要点单菜单，应补充菜品清单与价格或后续内页；这张参考本身主要是推广页。

**Prompt 槽位**：［确认食材／料理］近景，深色餐桌与侧光，突出［实际质地］，画面下部干净低亮度区域，无促销文案、酒店标识和日期。

**验收与避免**：主视觉保留质地而非死黑，规则文字有足够可读性；不把季节主题变成未经提供的时令供应承诺。

## MN-S08｜烹饪瞬间·动态服务场景（参考 8）

**风格词**：动态、浇汁、匠心、瞬间、深色、餐桌服务。

**视觉公式**：上方动作起点＋中间液滴／动作路径＋下方斜向菜盘＋路径旁侧的安静信息区。动作将画面连接成整体，同时突出料理而非道具。

**配图与构图**：动作、容器、落点和菜品关系可信；只表现菜品实际存在或获准示意的烹饪／服务动作。液滴路径不能穿过准确正文造成干扰。

**适配**：特色料理介绍、冬季或主题菜单封面、招牌动作菜。全菜单内页保留相同光线与器皿语汇，转为便于点单的图文结构。

**Prompt 槽位**：［已确认料理］与［已确认酱汁或服务动作］，斜向器皿、深调环境、动作凝固瞬间，［方位］低纹理文字区，无文字和虚构配料。

**验收与避免**：动作增强食欲且不会把普通菜夸大为不存在的制作工艺；不把参考广告信息直接当成菜单数据。

## MN-S09｜焦糖烘焙·共享台面陈列（参考 9）

**风格词**：焦糖、麦香、温暖、手作、酥脆、橱窗陈列。

**视觉公式**：暖棕统一场域＋有大小变化的面包甜点陈列＋贴近产品的双语名称与价格＋底部组合餐信息。图片融入共享底面，不是每张图都有独立矩形背景。

**配图与构图**：切面、酥皮和果实等细节帮助区分品项；前后陈列与阴影相容，文案分别归属对应产品。主标题可有烘焙气质，价格与描述保持清楚。

**适配**：烘焙、甜点、下午茶、零售食品。组合价和第二件优惠必须来自实际规则；没有优惠时直接省略，不按参考补促销。

**Prompt 槽位**：［确认烘焙产品］置于统一焦糖色台面，温暖侧光突出酥皮／切面，干净接触阴影，预留邻近标注区域，无品牌纸牌和文字。

**验收与避免**：食品、文字与底面有足够对比，不能照搬参考的小字或低对比；图片对应实际份量和口味。

## MN-S10｜韩式暖木·器皿陈列与分类货架（参考 10）

**风格词**：暖木、米白、烟火气、韩式餐馆、分类陈列、丰富。

**视觉公式**：一侧招牌场景＋另一侧分类图文陈列＋后续满幅品类单元。锅碗可用透明背景独立展示，也可在统一桌面场景中展示；分类标题和细线维持阅读秩序。

**配图与构图**：有“货架式”水平承托，也有主菜放大和局部小图矩阵，形成稳定而不单调的节奏。器皿保留真实形状，长柄锅等不能为统一边框被错误裁断。

**适配**：韩餐、锅物、拌饭、小吃和品项较多的餐厅。装饰语言可替换为品牌自有语汇，不复制参考韩文、招牌章和来源承诺。

**Prompt 槽位**：［确认锅物／主食］置于［指定真实器皿］，暖木或干净浅色底，统一斜俯视角与温暖自然光，主体完整，无招牌文字和推荐贴纸。

**验收与避免**：点单信息易检索，分类视觉各有代表菜；不将密集照片机械挤成全部等权卡片。
