# 画册与多页册子

适用于画册、产品目录、宣传册和多页作品集；三折页使用折页规则，完整 VI 保持自己的单一 HTML 交付。内容与交付安排写入同一 Brief。

## 内容与页面

- 明确用途、读者、成品尺寸、页数、阅读方向、装订方式和印刷需求；缺失的生产条件列待确认。
- 按阅读顺序组织封面、目录、章节、正文与封底，记录每页职责、准确文案、图片来源和跨页关系；页数随内容确定，不用空页凑数。
- 可以按跨页设计，标题、关键文字及主体避开装订遮挡。页码、字体角色和版心保持一致，章节与重点页允许改变节奏。

## 交付文件

- 默认一页一个完整 HTML，按阅读顺序上画布，并逐页提供同尺寸渲染图；另交一个按阅读顺序排列的多页 PDF，每个 PDF 页面对应一个设计单页。
- 跨页预览用于展示相邻页关系，不代替单页文件。印刷拼版按生产方要求处理，不自行打乱阅读顺序。
- 含书脊的封面、特殊折页或生产方明确要求的跨页稿，按确认的展开结构另行组织。
- 导出后核对页数、顺序、尺寸、字体和跨页衔接。Mobile 沿用其现有出口；无法提供约定的画布或文件时，生产前确认替代方案。

## 视觉安排

应用 [创意机制](../../shared/creative-concept-system.md) 与 [构图规则](../../shared/composition-principles.md)，在同一 Brief 中确定视觉主张、字体、色彩、图文比例及页面节奏；以整套预览核对连续阅读关系。
