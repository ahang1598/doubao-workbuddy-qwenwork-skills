# 三折页视觉表现规划

在 Spec 保存的同一份 Brief 上补充视觉，不另建脱离内容的视觉 Brief。整体风格和共同语言只写一次，逐面表现追加到对应物理面与图片条目中。Brief 使用自然语言描述可见结果，不输出模板参数、代码或工具流程；把“高级、自然、活泼”等抽象词转换成字体、主体、材料、色彩和构图关系。本文件中的编号、真实 CSS ID 与链接仅用于候选定位和后续实现，不要求按编号选择，也不把编号写成视觉目标。小效果只在服务主题和信息时选用，不要求把候选全部堆入成品。

## 底图与 Prompt 强制规则

内外侧展开面的作品级底图都必须包含与主题和已选视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整个展开面。折线坐标与安全区必须保留在规划、布局和验收中；它们是内容避让约束，不是底图需要画出的视觉对象。平面展开清洁稿不添加模拟物理折叠的亮带、暗带、投影或透视，该边界同时适用于图片内烘焙效果和 HTML／CSS 叠加层；折线与制作标记保存在可独立关闭的辅助层，默认不进入清洁稿导出。折叠样机另行展示，不回写进展开母版；纸纹、插画自身明暗及有意图的纸片层次可按设计职责保留，不能把装饰折痕当成实际物理折线。对应区域可以降低纹理频率、对比和密度，或使用局部纯色承托，但仍须与对应侧底图连续且同源。

每次写出内侧、外侧或局部跨面背景的具体 Prompt 前，必须先读取并遵循 [背景图 Prompt](../ai-coding/asset-prompt-guide.md#5-背景图-prompt)，按其中的背景职责、纹理选择模型和完整 Prompt 编译语法描述材质、色场、变化方向、尺度、低纹理区、区域避让与连续关系。折线和安全区在 Prompt 编译前转换为左／中／右区域的位置、净空与密度约束；最终生成素材的 Prompt 不出现折线、折痕、压痕、折叠纸面或制作标记等会被模型视觉化的表述。该路由适用于新生成和编辑既有底图；直接复用真实背景时不强造 Prompt，但必须记录使用方式并检查本节结果门禁。

## 读取入口

读取 [三折页 Spec](../scenarios/tri-fold-spec.md) 保存的同一 Brief 中“三折页内容结构”。缺少内容或完整面板映射时返回 Spec，不创建副本、不自行改折法或文案顺序。Z 折／包心折按 6 面，门折按 8 面读取。主场景、事实内容、折法、面板职责与印刷规格由 Spec 决定，本文件不以其他品类视觉系统代替。

先继承用户锁定的调性与参考，再依据传播目标、真实文案、素材和折法形成可调整的方向，并用一句话说明该方向怎样帮助主题被理解和记住。方向有歧义时比较少量视觉签名真正不同的候选；参考已明确时，不为凑数量另选无关风格。信息密度只影响适配，不独立决定采用编辑、摄影或艺术方向。

选一个主方向，约 70%–90% 的主视觉判断由它承担，这是识别与组织关系的占比，不是纹理像素覆盖率；从属技法不与主方向争夺识别。各面可改变强弱和密度，但须共享字体角色、颜色职责、图像后期、材料或边缘语言，不能成为互不关联的海报。网点、叠色与缺墨可共同构成一种印刷成像，不必拆成多个主风格。

先建立展开态秩序，再验证闭合与半展开的入口、揭示和接力。视觉风格与 Spec 的阅读机制联合判断，无固定编号映射；索引可用粉彩，连续轨迹也不必用弥散。遇到事实、尺寸、折线或工艺冲突，先调整作用区域和实现方式，仍不成立才说明冲突并比较替代方向，不静默舍弃用户参考。

## 风格与艺术表现手法

保留以下原有风格分类，在相关分类内细分候选；TV 编号仅便于定位，不再并列另一套家族目录。依据表达意图、品牌个性、读者与参考选择，不因机构类就限定冷静，也不因文旅就必用水墨。风格与跨面表现一起决定，不先套编号再拼效果。

“精致”可来自出版排字、真实棚拍或柔和色域；“自然”可来自现场摄影、地方图形或颜料笔触；“先锋”可由扫描、透叠或弥散分别承担。先辨别第一锚点，不以单个形容词自动路由。事实区密集时优先控制纹理、对比与分组，不整册静默改成编辑模板。

以下 TT、TC、TI、TA 的角色定义分别见文字配色与素材章节；配方是可比较的搭配，不要求全套照抄。

字级、栏线、编号与图像尺度形成阅读秩序；密度高不等于必须选此类，也不能用网格抹平手作、插画或摄影的主要识别。

| TV1.2 人文出版编辑 | 衬线标题、段落首字、页边家具、章节引语与克制摄影；折入页像序言，内侧像有节奏的短文章 | TT02＋TC02／TC05；图文分区／长文阅读；TI02；TA02 | 把杂志切成六块，折后标题和图注失去上下文 |

| TV2.2 两色套印海报册 | 两主印色及其叠色，粗图形或跨折形体建立展开锚点；丝印用墨边／覆盖不匀，Riso 用网点／缺墨／轻错版。可开放排字或整体纸页，闭合仍有完整锚点 | TT03＋TC04／TC07；跨列标题／视觉分区；TI05；TA03／TA04 | 均匀噪点冒充印刷、颜色失控、整卡移位冒充色版错位、事实错版或跨折不可读 |

### 木刻印记、手作纸本

**TV2.3 手作纸本与印记**：按参考选择纸纤维、形内刮擦、木刻缺墨、章印或手工边缘为主工艺，纸色不限暖黄。连续纸纹按展开尺寸规划，一张纸面可包裹多个内容组，文字各自避折；有资料收纳、长文卷纸或档案语义时才使用相应纸面容器，不为每条信息加便签。

配方可比较 **TT05＋TC02／TC05＋长文阅读／连续场景＋TI06＋TA04**。形内制作痕迹须真实可见，不只是铺底噪点；胶带、印章不能随机散落。图像压印是视觉模拟，真实压印、烫印或刀模必须有已确认工艺。

### 编辑线描、粗线民艺

绘制对象、图解和地方性符号帮助理解时采用；准确标签、比例尺、路线距离和地图事实仍由真实资料与原生内容承担。

| 子风格 | 可执行签名 | 配方候选 | 避免退化 |
|---|---|---|---|
| TV3.1 编辑线描图解 | 统一线宽、局部色块、对象注释与纸面负空间；对象和说明形成真实解释链 | TT01／TT05＋TC01／TC05；步骤导览／地图路线；TI03；TA01 | 图标风格不一、插画只在段落旁装饰 |
| TV3.3 粗线民艺图形 | 粗轮廓、有限色、重复纹样和有地方依据的对象群；以轮廓、负形和节奏跨面接力 | TT03／TT05＋TC04／TC08；跨列标题／视觉分区；TI05；TA03／TA04 | 无关民族纹样、符号来源不明、装饰冒充路线或压过内容 |

### 绘本世界、粉彩颗粒

适合连续世界、角色、探索感或手绘情绪成为第一锚点，不限亲子、教育或轻松内容。信息表面与主体保持同源，不能以满面高噪点代表艺术表达。

| 子风格 | 可执行签名与折叠关系 | 配方候选 | 避免退化 |
|---|---|---|---|

| TV3.4 粉彩颗粒绘制 | 粉末颗粒、颜料柔边与手绘明暗属于主体和色面；可柔和也可高饱和撞色。展开以连续插画／色块引导，闭合保留可辨主体，正文区减弱颗粒 | TT02／TT03／TT05＋TC08／TC09；图文分区／视觉分区／连续场景；TI13；TA04 或无艺术标题 | 只有背景加噪点、主体光滑、自动变软体 3D、抠图丢粉末边缘、关键主体被折线切断 |

### 纪实目的地、品牌棚拍

地点、产品或人物作为主要证据时，用统一镜头组、景别、光线和尺度建立场域，文字置于真实负空间。其他风格也可局部用证据照片；不同图库不能仅靠同一滤镜统一场域。

**TV5.1 包豪斯超图形**：几何主轴、大色面、方向性圆／线与跨折比例变化形成记忆，一个主形体随面板旋转、缩放或组合，闭合后仍保留完整局部焦点。配方可比较 **TT01／TT03＋TC03／TC07＋跨列标题／视觉分区＋TI01＋TA03**。

## 展开布局与 CSS 组合选择

在最终 Brief 冻结前，以完整展开面比较组合，判断真实内容怎样形成视觉重心、尺度反差和开合节奏，再确定栏数、图窗与局部效果。用户锁定的风格、事实和物理折法优先；“更有设计感”落实为有意图的图文关系，不以装饰数量衡量。用户明确要求的框型、跨面或揭示效果进入选型条件，未要求的效果按内容选择，不强制每册使用同一套技法。

按参考、传播目标、画幅、文案容量与素材条件，用 `describe ID...` 读候选摘要；结构不清时用 `get ID --prose` 读设计正文。比较候选怎样组织图像与文字、连接相邻折面，以及展开后形成什么新的整体关系，不能只按色调或风格名匹配。约 70% 的组合适配指核心层级、图文关系和字体／材质职责能够保留，不是效果数量或配色相似度；只借局部结构时明确采用范围。

将选中结构作为本次构图依据，写入原 Brief：由哪些真实内容参与、位于哪些折面、如何组合，以及开合时的可见变化。例如图窗跨过深浅分区并与题注共轴，或同一形体在半展开时露出局部、全展开后连接两组信息。采用框型时说明轮廓、取景与图文的关系；采用开放排版时说明对齐、尺度与留白如何组织阅读。这些关系指导素材制作与排版，并用于最终验收；模板名称和泛化风格词不能代替它们。

候选不足才通过 [CSS 检索入口](../../../../assets/templates/css/README.md#按风格读取) 限量补查，不遍历无关组合，不读取未选候选的代码与依赖。无适用组合时可自主构图，仍按同样方式明确图文和开合关系。

### 通用展开骨架与局部关系

每个展开面保留一个主骨架，不叠加互相冲突的整页网格。组合不适配而采用独立布局时，不必再读取来源组合。

- [视觉分区与跨区内容／layout.brochure-visual-zones](../../../../assets/templates/css/layouts/brochure-and-booklet-layouts.md#layout.brochure-visual-zones)：多栏图文、独立色区、跨面超图形或中央证据；背景分界与物理折线不必同界。

地图／路线和步骤导览保留独立方向：按真实节点组织地图、摄影、图例与索引，必要时借 [导览路径](../../../../assets/templates/css/layouts/continuous-flow.md#layout.route-flow)。装饰曲线不能代替真实路线，也不能声称上述四种骨架已覆盖全部导览关系。

### 冻结后的实现与折线复核

确认组合及必要局部补充后，把最终可见结果、采用区域和必须保留的关系写回原 Brief。冻结后用 `get <ID> --dependencies` 读取所选实现及必要依赖；真实引用、参数、覆盖范围和消费者落实到最终 HTML，图片生产输入进入原素材清单。分别绑定文字角色、背景、图窗和承托面，不只复制配色或类名。

用真实字体、完整文案与最终素材核对标题层级、阅读密度、主体净空和闭合入口，按 [Spec 的面板构图与跨面约束](../scenarios/tri-fold-spec.md#panel-composition)复核面序与折线。在固定纸幅与既定折法内，内容偏少时保持各面职责、面序和必要的跨面关系，可重组面内内容编排，调整栏宽、模块尺寸、间距与可读字级，不锁定所选组合的模块形态与比例。确需补充信息时，可展开已有事实，或加入有来源且服务该面职责的图片与图标，不为填空添加素材；内容已足以完成该面职责时，收紧内容区，保留用于分组、阅读停顿或折线避让的留白，不将卡片或图窗拉高补空。图片保持比例、主体完整及折线安全；无组合可复用时，原子组装也须明确纵向空间分配。固定纸面超量先在所选结构内调整容量，仍冲突再评估内容组织和区域分配，涉及文案或面序变更返回 Spec；不拉高纸面、不隐藏正文、不靠过度缩字解决。实际测高与溢出检查遵循当前 HTML/CSS 契约。无法保留核心关系时明确改为局部采用或自主布局，不声称完整采用；按 [公共 CSS 绑定复核](../../../workflow/html-assembly.md#css-recipe-binding)核对读取、绑定与视觉兑现。

## 容器与开放排版视觉决策

在整幅组合比较后，Visual 必须在原 Brief 每个物理面板条目中输出“容器与开放排版视觉决策”，并说明跨面容器在展开与折叠时的关系。先判断是否需要边界，再按 [容器视觉语法](../composition-layout.md#容器视觉语法开放排版优先语义容器按需)选择容器家族，不能只写内外侧全局风格或留到 HTML 阶段决定。

- 逐个说明容器名称、承载内容、位置与主次；同面多个容器分别描述，共用效果可引用，但须写本面差异。
- 写清轮廓与圆角／切角、表面材质、填充配色及纹理／渐变、边框与边缘、阴影与厚度、透明度／模糊，以及内部留白、图文排列、与底图和折线的关系。未使用的效果写“无”，不默认全部叠加。
- Brief 写可见效果和短采用记录，不写 CSS 参数、色值表或槽位契约。选中 CSS／SVG 能可靠表达的容器、独立规则边框和表面交给 HTML／CSS／SVG，不因票券、撕纸或拟物等名称转交生图。连续场景中已烘焙的边框不重复构建；复杂材质、插画或无法可靠原生表达的拟物壳体按 [素材使用规范](../ai-coding/asset-prompt-guide.md)准备，准确文字保持独立。
- 无需容器时写“开放排版、无容器”，说明如何用对齐、段距或分隔线组织信息；不能为填字段强加卡片或嵌套。
- 普通白色圆角矩形只用于稳定功能区，不能在六面／八面重复铺满。有真实语义时，让折页结构与文件夹、卷纸、档案页、票券、撕纸、切角牌或照片衬纸发生关系，用跨面背页、折痕、袋口、页签与纸层建立层次；没有收纳、纸媒或票券语义时保持开放排版。
- 将本面效果写入验收重点，检查实际边缘、材质、对比、文字容量与折线避让，不凭“高级容器”等名称判为完成。

### 已有布局 CSS 能力表

下表是本品类常用能力，不是模板库完整覆盖表。只补充已选整幅关系未覆盖或需替换的局部；当前能力由分类入口与限量查询核实，不沿用过期“暂无”结论。Brief 使用能力名称及实际图文关系，不输出 ID、路径、类名或参数。

|---|---|

## 写回内容结构 Brief

整体只写一次，逐面视觉直接追加到原面板条目，不新建视觉 Brief，也不恢复独立参数规划或机器 schema。

- 风格：具体名称、视觉特征、调性／参考证据，以及对主题、品牌、受众和传播目标的帮助。
- 决策优先级：用户锁定、印制／折法、品牌规范、参考继承／排除、品类规则与可裁量项。
- 视觉命题与注意力路径：闭合第一印象、展开入口、半展开线索、跨面推进与封底收束。
- 艺术手法与不变量：绘制、摄影、材料、图形如何共同构成内外侧；明确必须保留的非色彩机制，如图窗跨界、共同题注、文字轴或折叠揭示。
- 配色与文字：颜色来源及职责，各文字角色的字体、字重、层级和可读边界。
- 跨面关系：同一图形、场景、轴线或图像序列如何随折叠揭示；所选组合的采用区域与保留关系。
- 内外侧背景：分别写主题、材料、低干扰区、连续关系与制作比例。
- 逐面相对构图：焦点、主体区域、图片层级、文字位置、图文占比、密度、留白、容器／开放排版、裁切、遮挡、折线和安全区。
- 素材生产意图：用途、画面目标、处理方式、参考短链、继承／排除、保护和禁用项；正式 Prompt 在素材清单中编译。
- 载体适配与降级：展开、闭合、半展开、印刷误差、数字预览和素材缺失时保留、重排或降级什么，哪些工艺待确认。
- 生产与验收：三种折叠状态的焦点、图文比例、主体保护、背景连续、阅读顺序及未兑现对象。
- 逐面交接：主组、辅助组和阅读先后；跨面对象从哪里出现、在哪里继续、折后露出什么。
- 逐图画面描述：图片名称、所属面板、内容用途、完整可见画面，以及与折线、文字静区和相邻素材的关系。

|---|---|---|
| 图文栏目接力 | 全景、局部、事实形成节奏 | 封面完整，折入页不是第二张封面 |
| 连续场景揭示 | 一幅景观或插画跨多个面 | 每个状态有局部中心，不切断脸部和关键产品 |
| 几何母题变化 | 同一形体随面板旋转、缩放、组合 | 关键标识完整，不随机撒几何 |

| 索引与导览 | 分类或路线与图片共同导航 | 当前区域可识别，线条不冒充未确认地理关系 |

| 连续轨迹推进 | 有依据的路线、视线、枝叶或重心随展开延伸 | 不把装饰线伪装成路线或事实关系 |

先在完整展开面安排主次、图像尺度、框型或开放空间，再按物理面序检查闭合与半展开。折线约束关键文字与主体位置，不强制视觉对象封闭于单面；图窗、场景、形体或阅读轴可跨面，单面入口和必要信息仍须完整。内外侧共享视觉语言，构图职责可不同。

按 Brief 的选中关系将文字、照片和背景一起试排。只选对本次内容有用的方法，避免把表中方法逐项堆满。可选的设计关系包括：

- 框型：通过轮廓、裁切、层叠或开口组织内容。
- 跨面对象：明确出现、延续和揭示的位置。
- 图像序列：通过全貌、细节及题注建立联系。

低干扰区随图文布局确定，素材变化时同步调整相邻图文，保留结构意图，不把回退素材直接塞进旧版面。

## 逐面视觉补充

- 封面明确唯一主要视觉锚点、标题姿态、主图尺度和打开动机。
- 折入页用局部图、短引语或轻索引承接封面，不成为第二张封面；封底让联系与行动区易于找到，并以共同母题局部收束。
- 内页语境用疏朗文字、场景或引导图建立理解；内页核心放大关键主体并形成最明确的图文关系；内页证据确保每张图片与说明对应。
- 同面多个内容组须说明主组、辅助组和阅读先后。跨面对象写明起点、延续位置、折线处理，以及闭合和半展开时的可见部分。门折按 Spec 的八面职责逐面补充，不套六面默认语义。

## 文字、配色与安全区

全部文案和艺术标题由 HTML/CSS 实现，封面不使用电商 Hero 整图生字例外。建立封面标题、章节标题、正文与辅助信息四类稳定文字角色；艺术处理集中在最重要的短标题，章节标题适度呼应，正文、地址、价格、日期与多语言长文优先清楚辨认。用大小、粗细、宽窄、位置和段距共同建立层级，不只靠变色。

### 字体角色候选

下表只规定字体角色与搭配起点，不替代具体字体选型，也不把示例名称当作资源已就绪结论。实际候选先从 [字体推荐入口](../../../rendering/font-recommendation-list.md) 按语种、角色、形态和气质形成，并用封面标题、章节标题、正文、地址、价格、日期、联系方式及多语言长文试排；精选清单不是封闭白名单，查询脚本只提供候选、缺口和诊断。折叠与展开状态都须保持同级内容的层级连续和可识别的字体家族关系，但不要求每面机械使用同一款式；正文、小字和联系方式必须避开折线影响区，并在实际阅读尺寸清楚可辨。视觉候选确定后，正式 HTML 再按 [字体资源与执行契约](../../../rendering/font-family-library.md) 核验实际 family、face、weight／style、许可、目标字形覆盖和 Web 加载，写入真实 DOM；Canvas 分支用 `shot.py`、其他分支用对应目标端预览，同时验收闭合、半展开和完全展开状态，不能只凭放大的展开稿判定通过。本地安装记录不能替代目标端验证；用户锁定精确字体时，门禁失败必须请求确认，不得静默替换。

## 底图与素材制作

保持三折页当前 ai-coding 父路线及原生／图像分工，不另建生产路由。先依据原 Brief 中选定的图文关系，确定底图、局部图窗与独立主体的职责，再决定素材数量、比例、取景和文字净空；不得先固定为内外两张满幅背景，再迁就素材简化版式。内外侧底图仍须连续，但不要求把所有配图合成到底图。图像承担连续场景、复杂插画、真实材质及 Brief 明确分配到一体底图的视觉结构；独立规则色面、普通渐变、容器和边框沿选中组合使用 HTML／CSS／SVG，不按名称强制生图。HTML 同时负责全部文字、尺寸、裁切与分层组装。已烘焙在连续底图中的纸纹、渐变、框线或窗口不重复构建，也不用零碎色块替换主视觉。

- 用户 Logo、产品、人物、IP、准确地图与证据使用真实素材或获准的身份保持编辑；地图、图表的事实关系不能交给图像模型猜绘。
- 同一连续底图按实际展开比例生成或扩图，面板切片共用坐标，不各自拉伸，不以互不关联的小背景拼成展开面。
- 只有确需前后遮挡、替换或独立移动时才拆图；图内纸面不能同时声称可独立移动。独立壳体和抠图检查 Alpha、粉末柔边与细节。
- 人物面部、品牌标识、关键产品和准确路线不被纹理、折线或裁切盖住；真实身份不得被统一滤镜抹掉。
- 复杂纸层、半色调、套印、粉彩落实到对应素材；CSS／SVG 能可靠表达的轮廓、色版、颗粒或表面可原生实现，以实际能力与选中方案为准。物理透纸、压印、烫印和裁切能力不能凭屏幕图确认。
- 背景保护区只限制局部复杂度，不压制整张创意；没有强光需求时不机械加舞台效果，也不照搬公告专属光线禁项。

| TI14 | 弥散色域组 | CSS／SVG 能可靠表达的线性／径向渐变、颗粒、多重混合及规则变形原生实现；复杂液态成像或真实材质才用图片。记录色域流向、色标、柔边、颗粒尺度与跨面连续性 |

配图可直接属于连续场景，可将去底主体融入同一光线、色温和绘制质感，也可保留有意图的照片边界。主图尺度按可见主体而非源文件周围留白决定；全貌与局部细节须说明关联，不把所有照片做成同样大小的小相框。底图已有纸片、框线或窗口时，不再机械套第二层衬纸。

矩形背景与连续插画按展开目标比例规划，独立面板资产按面板目标比例规划。直接贴合且不裁切的图片与 DOM 显示框比例误差不超过 1%；采用等比 cover／contain 或裁切时，以实际取景、主体保护、文字安全区及有效像素是否满足最终显示尺寸验收，不因源图与框比例不同直接判失败。禁止非等比拉伸，不能把单面正方形图变形为跨三面横幅。清晰度按最终显示和输出尺寸检查，不以源文件尺寸或比例命中代替有效像素检查。

图窗、出血、纸片轻叠、跨区题注和边缘揭示须写明服务对象与归属。人物视线、枝叶方向或重心可导向下一内容，关键主体仍须避开折线与裁切。必要的安静承托只用于有职责的内容，不把整册变成白卡墙；复杂素材缺失时须指出未兑现对象与降级，不静默退回光滑渐变或普通白卡。

## 形成每项素材生产意图并编译 Prompt

按 Spec 的内外侧或独立配图逐项写用途、画面目标、参考职责、主体与背景关系、保护和禁用项。每张图先记录名称、所属面板与内容用途，再用自然语言描述具体风格、主体与辅助对象、空间关系、配色职责、材质／笔触／光线、主次、文字静区，以及安全区和折线对构图的约束；连续底图还要写相邻区域怎样连接，局部图要写与母图怎样继承。这些规划约束不能原样复制进生成 Prompt。

冻结 Brief 后，在原素材清单中补生产方式、目标比例、尺寸、安全区、消费者与准出标准，并编译完整 Prompt；风格放在首位，再写主体、辅助元素、配色、材料、构图、视角、尺度、明暗、低纹理区与裁切保护。

Prompt 只描述最终需要生成的画面，不写上屏文案或文字排版，也不写“无文字／无字／no text”等否定词。安全区与折线坐标在规划中保留并预先计算；编译时只转成左／中／右区域的主体位置、净空、纹理密度和连续关系，最终 Prompt 不提折线、折痕、压痕、折叠纸面或制作标记。本文案与艺术标题始终由原生文字后置。

参考图按图1、图2逐项记录真实短链和借鉴内容；Prompt 只用图序号，URL、路径和工具参数另行传递。缺短链标待补，不调用依赖该图的参考生成。原图编辑明确保护身份与允许变化范围，不把品牌重画成另一个标志。

## 视觉验收

从同一展开母版查看内外侧清洁稿、闭合正反面和半展开预览，分别判断设计关系与技术可用性。清洁稿核对图片、CSS 渐变、阴影和伪元素，确认不存在为模拟折叠而附加的光影；样机效果与辅助标记不得混入清洁稿。技术检查通过不能代替设计判断，屏幕预览也不能代替实体打样。

- **结构是否成立**：对照 Brief 的选中关系，在实际预览中指出参与对象、所在折面与可见效果。框型是否组织了取景与图文，跨面构图是否形成连接或揭示，图像与题注是否相互解释；共同配色、连续底图或装饰描边本身不足以证明这些关系。开放排版则检查其对齐、尺度和留白是否形成明确的阅读秩序，不为验收额外添加未选效果。
- **开合是否有节奏**：闭合有清楚的识别焦点，半展开有可理解的承接，完全展开形成整体构图；逐面有主次和密度变化。检查上下空置、重复主图和等权分栏，保留服务焦点或阅读停顿的留白，调整缺少内容职责的空间。
- **内容与折法是否准确**：面数、正反对应、宽度、方向和阅读顺序符合 Spec；原文、事实、标识与产品身份准确，关键文字与主体避开折线及裁切带。字体真实加载、字形覆盖、字重、换行和实际尺寸可读，内容不被隐藏或截断。
- **素材与成像是否合格**：检查有效分辨率、取景、Alpha 边缘、暗部对比、材质尺度与拼接连续；连续场景共用坐标，图片不拉伸。框型与容器的边缘、容量及遮挡符合布局，已烘焙的结构不重复叠加。纹理、套色与透明效果按成品尺度查看，不把屏幕模拟当成已确认的印刷工艺。
- **交付状态是否如实**：清洁稿与制作标注分开；记录尚未核实的纸材、工艺和印制条件，未打样不声明印刷通过。交付与失败处理遵循当前门禁。

选中关系未兑现时，返回对应的素材或布局修正。确因内容、折法或可用素材改变方案时，说明原关系为何不再适用，更新同一 Brief 中的替代构图，再检查上述状态；不能仅改称“局部采用”就通过。原图回退也按新取景与相邻图文重验。将实际兑现的关系及未解决项写回原 Brief 的 **视觉效果验收规范**，不重复建立检查文档。
