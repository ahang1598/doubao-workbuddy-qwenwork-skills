# Logo 视觉与应用规划

## 底图与 Prompt 强制规则

Logo 提案和系统展示的作品级底图必须包含与品牌和已选视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整张画布。单色、反白、灰阶和最小尺寸测试所需的纯白／纯黑功能色块可以局部保留，但不能代替提案页的作品级底图。

每次写出具体提案底图、材质背景或应用背景 Prompt 前，必须先读取并遵循 [背景图 Prompt](../ai-coding/asset-prompt-guide.md#5-背景图-prompt)，按其中的背景职责、纹理选择模型和完整 Prompt 编译语法描述材质、色场、变化方向、尺度、低纹理区与连续关系。该路由适用于新生成和编辑既有底图；直接复用真实背景时不强造 Prompt，但必须记录使用方式并检查本节结果门禁。

## 读取入口

读取 [Logo Spec](../scenarios/logo-spec.md) 保存的同一 Brief 中“Logo 内容与结构”。缺少准确名称、参考短链、生成范围或授权边界时返回 Spec，不创建第二份 Brief。从零任务先规划生图主标；已有 Logo 任务先确认身份母版。

凡涉及角色／物件 Logo、角色与品牌名锁定、定制字标描边、贴纸／周边状态、Logo 身份容器、纯白／纯黑底或透明背景处理，必须同时完整读取 [Logo IP 角色、字标描边与背景处理参考](../../shared/logo-ip-wordmark-background-reference.md)。本 Visual 负责把其中规则转成当前品牌的可见决策，不复制参考样本。

描述“这种线条感”时优先使用共享参考中的可观察术语，例如“粗圆等线卡通＋受控稚拙”“胶管式连续曲线”“粗轮廓＋大留白”“黑白块面卡通”或“干净骨架＋轻微丝网油墨颗粒”；同时写清线重、端点、曲率、开口、黑白节奏和边缘质感。只写“可爱、手绘、复古、卡通”不构成可执行视觉决策。

## 容器与开放排版视觉决策

Visual 阶段必须在原 Brief 每个提案画板、状态展示页与应用页的对应条目中输出“容器与开放排版视觉决策”，先判断展示内容是否需要承托，再按 [容器视觉语法](../composition-layout.md#容器视觉语法开放排版优先语义容器按需) 选择容器家族；不能只写全局风格或留到 HTML 阶段决定。这里只规划展示承托，不擅自改变 Logo 母版。

- 逐个说明容器名称、承载内容、位置与主次；同屏多个容器分别描述，共用效果可明确引用，但须写本屏差异。
- 写清轮廓与圆角／切角、表面材质、填充配色及纹理／渐变、边框与边缘、阴影与厚度、透明度／模糊，以及内部留白、图文排列、与底图和标志的关系。未使用的效果明确写“无”；纯色测试载体不能被材质或阴影干扰。
- 只写可见效果的自然语言，不输出 CSS 参数、色值表或槽位契约；来源 ID 仅写入短采用记录；规则容器交给 HTML/CSS，复杂壳体按 [素材使用规范](../ai-coding/asset-prompt-guide.md) 准备。
- 无需容器时明确写“开放排版、无容器”，并说明如何用对齐、段距或分隔线组织信息；不能为填字段强加卡片或卡片嵌套。
- 普通白色圆角矩形只用于中性测试区，不能把母版、变体和应用全部装成同款卡。提案展示可用档案页、文件夹、切角铭牌、材料样本、照片衬纸或分层窗口建立结构，但标准稿与色彩测试必须保持干净、无遮挡。
- 将本屏效果写入视觉验收重点，检查实际边缘、材质、对比、安全区与遮挡；不得仅凭“高级容器”等名称判为完成。

### 品类常用容器表

下表是提案与系统展示的常用容器候选，不作为 Logo 造型来源；先判断展示任务，任何容器都不得改变母版轮廓与安全区。

| 常用容器类型 | 常见用途 | 视觉选择与边界 |
|---|---|---|
| 中性圆角容器（非默认） | 组合标、尺寸、禁用示例与说明区 | 只在中性测试分组成立时采用克制薄边或实色面，不能让容器比 Logo 更抢眼 |
| 阶梯面板 | 主标展示、构造与比例说明 | 细框用于建立基准和仪式感，不裁切安全区 |
| 拱形图片窗 | 品牌应用摄影或场景 Mockup | 只作用于应用图片，不套在标准 Logo 测试底上 |
| 照片衬纸与胶带 | 手作、编辑或档案式应用照片 | 仅当品牌语言支持纸本拼贴时使用，不伪造历史档案 |
| 圆角磨砂玻璃 | 数字品牌、科技应用与透明介质展示 | 作为应用承托，不把玻璃高光烘焙进平面母版 |
| 胶囊与徽章 | 版本标签、状态名与短尺寸标记 | 与 Logo 本身的徽章结构区分，只承载短标签 |

### 已有布局 CSS 能力表

下表完整覆盖当前模板库已有的布局能力。Visual 根据内容职责选择，不按顺序轮用，也不要求每屏使用一种；写回 Brief 时使用表内能力名称和实际图文关系，便于后续自然语言匹配。名称用于能力对应，不输出 ID、路径、类名或参数。

| 布局能力 | 适用关系 | 写入 Brief 的边界 |
|---|---|---|
| 紧凑内容 | 同组事实、短字段、密集但可扫描的信息 | 写明压缩的是留白与组距，不缩小到不可读，也不把无关内容塞进同框 |
| 宽松内容 | 单一主张、少量重点、需要呼吸感的组件 | 写明留白服务的焦点与阅读停顿，不用空白凑画布高度 |
| 规整对齐（方格／网格排版） | 参数、证据、规格、并列比较和稳定栏目 | 写明列组、共同基线与主次；方格只组织可比较内容，不自动生成卡片墙 |
| 疏朗留白 | 长文、说明、编辑阅读栏与安静叙事 | 写明行宽、文字轴、图片归属与段间节奏，不等于所有内容缩成窄列 |
| 错落平衡 | 短标题接力、偏轴构图、左右不等权信息 | 写明错位对象、方向和共同对齐依据，不随机散放正文 |
| 聚焦主场 | 商品、人物、作品或场景作为第一视觉焦点 | 写明主体尺度、取景、文字静区和图文前后关系，不把主图缩成卡片配图 |
| 连续流动（串页／长页排版） | 长图章节、连续叙事、上下屏衔接和系列阅读 | 写明上一段出口、下一段入口、共享背景或接力对象，不只写“向下阅读” |
| 叠层拼贴 | 多张照片、纸片、证据或装饰需要错位叠压 | 写明主片、副片、角度、遮挡与保护区，不用随机旋转制造丰富 |
| S 形导览线 | 流程、路线、时间或概念节点需要曲线推进 | 写明真实节点、起止点和绕行保护区；没有关系节点时不用装饰曲线 |
| 横向卡片列 | 同类短条目、阶段、步骤或可横向扫描的内容组 | 写明条目共同尺度与差异；长正文、价格条件或复杂证据不挤入窄卡 |
| 章节眉线 | 章节编号、标题、短导语与换章提示 | 写明眉线承担的层级与接续对象，不把分隔线当主视觉 |
| 带引导线的图像标注 | 产品部件、成分、结构、地图或证据图解释 | 写明标注对象、端点和文字归属；引导线必须指向真实细节且不交叉遮挡 |

同一屏可组合兼容能力，例如“聚焦主场＋带引导线的图像标注”或“连续流动＋章节眉线”；组合后仍须形成一个明确主关系。没有适用能力时保留自定义关系并描述可见结果，不为命中模板改写内容。

### CSS 原子能力校验

完成视觉方向草案后、最终 Brief 冻结前，将本品类已选效果拆成下列自然语言能力词并执行公共限量查询。这里选中 ID、源路径与版本进入 Brief 短采用记录，不复制代码或参数；查询只验证能力与边界，不能反向新增视觉决定。

| 决策维度 | 交给查询的自然语言能力词 | Brief 保留内容 |
|---|---|---|
| 布局 | 阅读轴、主图关系、网格、错位、叠层、连续流动等实际关系 | 本屏图文主次、阅读路径与开放／分组方式 |
| 字形 | 填字、描边、发光、浮雕、路径排字等可见效果及文字角色 | 哪组文字采用何种效果、作用和可读边界 |
| 形状 | 当前选定的容器、图窗、票券、纸边、徽章或其他轮廓 | 轮廓服务的真实内容与本屏差异 |
| 表面 | 纸张、玻璃、塑料、织物、金属、柔焦等材质及承载对象 | 材质落在背景、卡片、图片还是文字，正文如何保持清晰 |
| 配色与背景 | 色彩职责、渐变／弥散方向、纹理类型及覆盖范围 | 可见色彩关系、背景变化、静区和保护范围 |
| 作用对象与边界 | 字体、卡片、背景、局部装饰；需要素材承担的复杂部分 | HTML 与图片的分工、必要降级及验收重点 |

候选摘要证明确实可实现后，把最终可见结果写回原 Brief；没有适用候选时保留已选方向，说明由素材或原生实现承担。真实引用、依赖、参数和消费者只进入后续 最终 HTML。

## 写回内容结构 Brief

- 风格与依据：具体视觉语言、品牌认知与参考依据
- 决策优先级：用户锁定、名称准确、母版身份、授权范围、参考继承／排除、应用要求与 Agent 可裁量项
- 品牌视觉命题与注意力路径：首先识别什么轮廓／字标，随后理解什么品牌特征，提案页如何收束到可用母版
- 造型与艺术手法：轮廓、负形、字形、比例或材料怎样形成识别
- 保留与变化：继承母版的特征、授权修改项与各变体的简化方式
- 字标与提案文字：字形、字距、组合关系，说明文字的字体与层级
- 配色：主色、单色、反白、灰阶与不同背景的用途
- 逐画板相对构图与图文占比：母版、结构、测试和场景的主次、相对面积、留白、对齐轴与允许遮挡
- 配图层级与背景：真实 Logo 如何独立放置，环境、材质与应用素材怎样配合，前后景、裁切／遮罩和身份保护
- 跨尺寸／背景固定与变化：横竖组合、单色、反白、小尺寸和复杂背景下保留、简化或重排什么
- 素材生产意图：每项用途、画面目标、来源、参考职责、处理方式、保护与禁用项；正式 Prompt 在素材清单中编译
- 视觉效果生产与验收：第一识别、轮廓、字标、图文比例、最小尺寸、单色、背景与应用身份核对

整体写一次，变体与画板差异补在原条目中，不重复内容规划。从零主标、单色、反白和组合标均使用生图／图片编辑工具；Coding 负责准确说明文字、对齐、规范线和展示组版。未授权改造已有母版时，风格只作用于提案和应用。

## Logo 结构、风格与家族方法

本节消费 Spec 已冻结的准确品牌名、核心概念、形式职责、语气和使用环境，不复制参考 Logo 的具体品牌名、角色、字形、轮廓、负形或组合关系。造型风格与提案背景分开：材质、渐变和 Mockup 只能验证应用，不能掩盖标志本体的问题。

### 最高优先级：已知品牌名不得只做图形

只要品牌名称已经明确，每个 Logo 候选与最终标准主标都必须包含准确品牌名，并把名称设计成可识别的字标或与图形／角色／物件共同构成组合标。不得只生成独立图形、头像、角色、物件、抽象符号、首字母图标或无名称徽记；也不得把品牌名缩成角落注释、细小副标题或与主图无关的普通排字。独立图形标、角色标和缩写标只能在含品牌名的主标确认后，从同一母版派生为特定场景的附属版本。

品牌名称尚未明确时返回 Spec 澄清准确名称、大小写、空格、标点、重音符号和中外文关系；禁止用 `Brand`、`Logo`、随机英文、占位文字或纯图形先行生产正式候选。

### 黑白优先与核心轮廓

Logo 先在纯黑／纯白条件下成立，再进入品牌色、材质和应用。第一轮正式比较必须查看黑标白底与白标黑底，检查整体剪影、视觉重心、主负形、字腔、笔画连续性和远距离识别。

- 单色状态保留核心概念和主要识别关系；去色后不能只剩普通文字或无法辨认的图形。
- 轮廓在缩略图中形成独特外形；内部细节只服务概念和识别，不用微孔、发丝线、碎片或小装饰制造复杂度。
- 负形具有明确语义或结构职责，并在正负反转、小尺寸和不同输出方式中保持；不强塞多个隐喻。
- 基础几何必须经过比例、切口、连接、负形或节奏上的品牌化处理，不能停留在通用模板符号。

### 造型路线

每个候选只保留一个核心概念和一套主要造型操作。候选之间必须在语义压缩、结构机制和视觉气质上真正不同；品牌名已知时，每条路线都必须把同一准确名称纳入 Logo 本体，不能让某个方向退化为纯图形候选。

| 造型路线 | 核心要求 | 常见失败 |
| --- | --- | --- |
| 定制字标 | 从准确品牌名的字符、音节、重复字形或发音节奏建立独有轮廓；统一笔画、字腔、圆角／切角和基线 | 直接套现成粗体、随意挤压、为了造型破坏拼写 |
| 几何图形标／字母标 | 用有限形体、切口、连接和负形形成稳定剪影；字母含义可追溯 | 通用圆圈加首字母、随机几何堆叠、依赖说明才看懂 |
| 图文一体标 | 图形与字标在笔画、基线、负形或轮廓上互相生成，拆分后仍有明确职责 | 图标放在文字旁却声称融合、图形遮挡关键字符 |
| 角色／物件标 | 用最少轮廓和表情保留角色或产品记忆点，并与字标共享线条性格 | 细节过多、小尺寸糊合、角色与字标像两套设计 |
| 有机粗体／实验字形 | 通过受控膨胀、压缩、连笔、错位或不规则建立个性，同时保持准确字符识别 | 所有字同样扭曲、字腔堵塞、只剩潮流字体效果 |

### 参考样本提炼的风格母题库

母题只用于建立候选差异和质量标准。每个候选以一个主母题为核心，最多加入一个有明确职责的辅助母题，禁止拼成风格杂烩。

| 风格母题 | 可见风格特征 | 具体构造方法 | 适合的品牌气质 | 必须避免 |
| --- | --- | --- | --- | --- |
| 几何负形符号 | 黑白高对比、稳定外轮廓、基础形中藏有字母、对象或方向关系 | 从一个基础形出发，通过切除、嵌合、镜像、旋转和共享边形成单一主负形 | 理性、创新、设计、科技、空间、专业服务 | 通用圆圈加首字母、隐喻过多、只有解释后才能辨认、细缝在小尺寸消失 |
| 模块构成字标 | 字母被压缩、堆叠、拆分或重组成紧凑色块，字符之间形成共同轮廓 | 统一笔画重量与模块尺度，用重复形、共享竖画、切角和负形建立节奏 | 文化、潮流、创意机构、音乐、数字品牌 | 牺牲读音和字序、机械拉伸现成字体、每个字符使用不同规则 |
| 有机膨胀粗字 | 粗重、圆润、柔软、略带手工不规则，字腔小但清晰，整体像连续形体 | 对字干做受控膨胀、局部压缩、连笔和基线跳动；保持一致圆角、黑量和内部留白 | 餐饮、生活方式、年轻消费、亲和社交品牌 | 软塌无骨架、字腔堵死、所有字同样扭曲、直接套用复古泡泡字体 |
| 复古角色徽记 | 简化角色头像或物件与粗体字标组成强记忆组合，低色数、线面明确 | 角色只保留身份轮廓、表情和标志部位；字标与角色共享笔画、圆角、色块或时代语汇 | 餐饮、零售、社区、亲和型消费品牌 | 角色细节过多、卡通与字标像两套系统、用滤镜代替原创结构、无依据添加年份或城市 |
| 物件／角色融合标 | 产品、动物或人物动作参与字母、容器或负形，图形和名称互相生成 | 选取与业务强相关的物件或行为，将其轮廓嵌入首字母、字腔、基线或外框 | 咖啡、餐饮、宠物、娱乐、体验型服务 | 图标只摆在文字旁、物件喧宾夺主、使用通用杯子／笑脸／动物剪影 |
| 动势轨道与开放环 | 弧线、箭头、开放圆环、倾斜或连续路径带来速度、循环、连接和方向感 | 用单一运动路径控制字标或符号，使开口、终点和重心与品牌行为一致 | 运动、音乐、出行、连接型产品、实验文化 | 随意加箭头、旋转后失去阅读方向、动势与业务无关、线条过细 |
| 极简物件字标组合 | 高度简化的物件／角色符号配合紧凑粗字标，低色数、留白明确、远距离识别强 | 将物件压缩为少量大轮廓和一个关键动作；用基线、重心或轮廓咬合建立整体 | 门店、餐饮、个人品牌、轻松但需要商业清晰度的品牌 | 插画细节多于标志、符号与名称等权分离、只在大尺寸成立、缩小时表情消失 |
| 角色主标＋定制字标锁定 | 角色／物件与完整品牌名共同构成一个不可误拆的主标；常见为左图右字、上图下字或角色压住／托起字标 | 先确定角色最大识别轮廓和品牌名准确字形，再用共同描边、笔画粗细、圆角、色块、基线或遮挡建立锁定关系；角色与字标分别清晰，合起来形成唯一重心 | 音乐、餐饮、潮流、娱乐、宠物、社群和人物型品牌 | 只画角色不写品牌名、角色像插画而字标像后贴、角色遮挡关键字符、依赖复杂场景才成立 |
| 复古人物肖像＋脚本字标 | 单色或低色数人物头像配合有时代感的粗脚本／衬线字标，主次明确、亲和且有手作招牌感 | 压缩肖像为稳定面部剪影与一两个标志特征；字标使用宽笔画、清楚字腔和受控连笔，必要品类词置于弱层级 | 餐饮、甜品、手作、理发、地方零售、个人品牌 | 肖像过度写实、脚本字不可读、虚构创始年份／产地／人物故事、品类词抢过品牌名 |
| 双语／双层名称锁定 | 主品牌名承担最大识别，第二语言或合法短描述形成稳定次层；整体可横向或上下堆叠 | 固定主次比例、共同对齐轴和唯一断行；第二语言只翻译或补足已确认信息，不重复争抢重心 | 跨语言品牌、本地门店、文化消费、国际化产品 | 随机翻译、两种语言等权竞争、把副语言缩到不可读、为填空新增口号或品类词 |
| 响应式排布家族 | 同一字形和图形在拱形、横向、纵向、组合和纯字标格式中保持身份连续 | 先确认唯一母版，再只改变排布、比例和从属信息；核心字形、角色、负形和颜色职责不变 | 需要包装、招牌、头像、社媒和多尺寸载体的品牌 | 把不同候选混称家族、每种格式重画核心字形、用应用变化掩盖主标不成立 |

共同质量标准是：优先用黑白检验结构；采用少量粗壮形体而不是碎细节；让字形、图形与负形共同承担识别；允许亲和、幽默和复古，但保持商业可读性；从一开始考虑横向、纵向、紧凑标和小尺寸状态。

### 新参考补充：角色／图形与品牌名的组合关系

新参考进一步证明，角色或图形的价值不是独自成为一张插画，而是与准确品牌名建立稳定锁定。每个候选先选择一种主组合，不在同一标准主标里同时堆叠多种关系：

- **横向并列**：角色／图形在左、品牌名在右，二者共享视觉中线或文字基线；适合招牌、页眉和横向包装。图形高度与字标重量平衡，不能像社媒头像旁临时加字。
- **上下堆叠**：角色／图形位于品牌名上方或嵌入上部，品牌名形成下方稳定承托；适合方形主标、包装正面和门店标牌。顶部形象不能过大到把名称压成脚注。
- **嵌合／咬合**：角色局部、物件轮廓或动作进入首字母、字腔、基线或字标外轮廓；必须保留完整拼写，不得遮挡关键字符或制造误读。
- **字标主导＋图形陪衬**：品牌名称是最大视觉主体，角色或图形作为可识别引子与字标共享描边、色块或节奏；适合名称本身记忆性强的品牌。陪衬不能退化为随机贴纸。

同一组合内至少统一两项：笔画／描边重量、圆角逻辑、主色角色、负形语言、基线节奏或外轮廓倾向。粗描边、贴纸式白边、投影边和高饱和底色只在品牌气质需要时使用，不能作为掩盖角色与字标不统一的补救。场景照片上的 Logo 属于应用验证，不作为标准母版；标准母版仍要单独在干净深浅底上查看。

若存在中英文、主名与品类描述或双层名称，只能使用用户提供或确认的准确文字。主品牌名先读，第二语言／描述语后读；两者共享对齐轴和字形气质，但通过字重、字号与间距拉开层级。禁止模型自由添加域名、口号、品类词、年份、注册符号或社媒账号。

角色＋名称组合至少验证一次单色正版和反白版：角色表情、关键轮廓、名称字腔和图文锁定关系在两种状态下都必须完整；不能让彩色填充、白色描边或场景背景成为唯一可识别条件。

### 多风格候选与确认

用户未提供 Logo 时，从母题库选择若干真正适配且彼此差异明显的路线。候选至少在“身份来源”和“形态结构”两个维度同时不同；每个方向都要给出核心概念、主母题、造型操作、黑白识别方式、适用场景、小尺寸风险和主要禁用项。用户明确确认一个方向前，不建立正式家族；确认后所有派生只使用该唯一母版。用户已提供并确认 Logo 时跳过候选生成。

### 字标同源与光学校正

字标不是普通字体加图标。定制字标必须明确被重绘、连接、切开、旋转、嵌合或形成负形的字符，并统一笔画重量、字腔尺度、圆角／切角、端点、倾斜和视觉节奏。图形标或角色标与字标至少共享两项可观察特征；若刻意对比，也要由共同基线、负形、色块或比例维持整体。

逐字检查品牌名；禁止错字、缺字、多字、形近字替换、不可辨认连字和未经确认的大小写变化。对字符间距、图文间距、内外留白、视觉中心、同权笔画粗细、圆弧外扩、尖角越界、横竖补偿、交接黑量和封闭字腔进行光学校正，不能用机械居中和默认 kerning 代替。

字标描边按共享参考区分为无描边母版、单层对比描边、贴纸式白边、双层轮廓、偏移投影边和手绘粗糙边。先保证无描边字形准确可读，再让描边承担清楚职责；描边后必须复查字腔、相邻字符、反白和真实最小尺寸。描边与容器属于已确认变体时才能进入家族，禁止在 HTML 或 Mockup 中临时给母版加边制造“另一版”。

### 响应式家族、底色与应用测试

确认主方向后，只从同一母版建立真实需要的主标、横向／纵向组合、独立字标、独立图形标／角色标、紧凑副标／缩写标、单色／反白和小尺寸简化。标准主标必须保留准确品牌名；独立图形标／角色标只服务头像、favicon、封签等受限场景，不能取代标准主标。每个成员记录用途、最小空间、保留项和删除项；小尺寸只删除次要纹理、从属文字或内部细节，不改核心剪影、主要负形和识别笔画。

- 纯白底 Logo 保持均匀纯白背景，在 HTML 中仅对 Logo 图片节点使用 `mix-blend-mode: multiply`。
- 纯黑底 Logo 保持均匀纯黑背景，在 HTML 中仅对 Logo 图片节点使用 `mix-blend-mode: screen`。
- 已有可靠 Alpha 的 PNG 或无底 SVG 直接按透明资产使用，不补底、不机械套混合模式。

底色使用前先区分母版测试背景、身份容器／底板、应用承托底和材质／摄影背景。只有底板真实参与名称轮廓、负形或品牌语义并能在单色与小尺寸中继承时，才属于 Logo 本体；否则作为应用状态登记，不得烘焙进母版。进入 VI 作为独立图片层时，改按 VI 专项规则先用 MediaKit 去底并验边，禁止沿用本节混合模式。

至少在大尺寸标准稿、中等组合应用和小尺寸图标／标签三个尺度，检查黑标白底、白标黑底、品牌色、低对比背景、屏幕、普通印刷和本任务真实载体。Mockup 只能验证场景适配，不能反向成为标准稿。

### 禁止项

- 禁止直接复刻参考 Logo 的具体字形、角色、构图、负形或组合关系。
- 禁止无依据增加 `TM`、`®`、`©`、成立年份、城市、口号、品类词或虚构外文。
- 禁止用通用图库图标、默认字体加外框、随机首字母组合或无语义几何拼贴冒充原创 Logo。
- 禁止把多个候选混成正式家族，或用颜色、渐变、阴影、立体材质和 Mockup 掩盖黑白结构、拼写与间距问题。
- 禁止把位图预览声称为可编辑矢量母版，或把模型生成的近似重复声称为精确几何变体。

## 主标生成与状态派生

按以下顺序生产，不把单色、反白理解成 Coding 滤镜，也不在没有母版时直接做规范页：

1. **平面彩色主标**：从零任务用生图工具生成一张干净主标；已有 Logo 用图1编辑。品牌名已知时，主标必须把准确品牌名作为字标或组合标的主要识别层，禁止只输出图形。画面只呈现一个标志状态，轮廓与负形清楚，不用纸张、墙面、金属压印或场景掩盖结构。确认后记录真实短链，成为后续唯一图1。
2. **黑色单色版**：以确认主标为图1调用图片编辑工具。Prompt 示例：

   `把图1的背景换成纯白色，把完整 Logo 图标和字标统一换成纯黑色。严格保持图1的轮廓、内部负形、字形、比例、间距和组合位置，不增删细节，不添加阴影、渐变、描边或材质。`

3. **白色反白版**：仍以确认主标为图1调用图片编辑工具。Prompt 示例：

   `把图1的背景换成纯黑色，把完整 Logo 图标和字标统一换成纯白色。严格保持图1的轮廓、内部负形、字形、比例、间距和组合位置，不增删细节，不添加阴影、渐变、描边或材质。`
4. **透明底版**：优先对平面主标确定性去底／抠图；检查外轮廓、内部孔洞和半透明边缘，不通过重新生图获得近似透明 Logo。
5. **图形标**：组合主标已有独立图形时，可从图1裁取或编辑分离；没有独立图形时不得擅自删除字标制造一个新符号。
6. **横版／竖版组合标**：以已确认图形标或主标为图1，通过图片编辑生成。Prompt 逐字写明品牌名称、图形与字标的相对位置、比例和间距；先横版后竖版，分别输出。不得只凭文字重画图形。
7. **小尺寸版**：先按真实尺寸缩放测试；仅当细节糊合时，以图1编辑简化细节、扩大开口或加粗细线，并写清保留的核心轮廓。小尺寸版不能变成另一枚 Logo。
8. **拟物／材质版**：只能在平面主标确认后以图1做应用编辑，保持标志结构；金属、玻璃、黏土、毛毡、陶瓷或浮雕只是表现状态，不替代平面、单色与反白交付。

字标源与名称逐字对应。生成组合标时 Logo 文字属于图像内容，可以写入 Prompt，但必须逐字核验；提案页标签和说明文字仍由 Coding 实现。字体来源、许可和改造范围真实可查，生成位图不宣称存在字体文件或矢量路径。

## 组合标与展示构图

组合标先确定图形与字标的主次，再选择形式：

| 组合形式 | 适用场景 | 构图要求 |
| --- | --- | --- |
| 横版组合 | 网站导航、横向标牌、页眉 | 图形在左、字标在右；按视觉重心校正，不以边界框机械等距 |
| 竖版组合 | 包装正面、海报落款、竖向空间 | 图形在上、字标在下；控制整体高度，避免字标比图形更抢 |
| 徽章／包围组合 | 贴章、印章或圆形载体 | 名称沿真实容器组织，单色下保持开口，不额外加入无依据年份 |
| 图形标独立 | 头像、App 图标、favicon | 保留核心轮廓并检查圆形／圆角裁切，不把横版组合硬塞进方形 |

获得主标、单色、反白和组合标后，再选择 Logo 展示版构图：

| 展示构图 | 适合表达 | 排版方法 |
| --- | --- | --- |
| 中央主标＋底部状态带 | 一页先建立主标识别，再展示状态 | 主标占上部主要面积；下方同尺度排列单色、反白与图形标 |
| 左侧主标＋右侧系统列 | 需要解释组合和使用关系 | 左侧大主标，右侧纵向排横版、竖版、小尺寸；说明与标签由 Coding 对齐 |
| 2×2 状态矩阵 | 比较彩色、黑色、反白、透明／浅深背景 | 四格同尺度、同安全区，不用不同 Mockup 干扰比较 |
| 图形标＋组合标递进 | 展示从符号到完整名称 | 从左到右为图形标、横版、竖版，保持同一视觉高度与清楚间距 |
| 主标＋小尺寸递减带 | 验证响应式状态 | 主标为焦点，下方按真实像素递减，必要时并列简化版 |
| 主标＋结构局部放大 | 说明负形、笔画或关键转角 | 主标完整显示，局部放大只指向真实几何，不编造黄金比例 |
| 深浅背景横向分带 | 检查彩色、单色与反白 | 上下或左右两条连续背景带，同位置展示对应版本 |
| 应用主图＋平面证据 | 表达材质或业务场景 | 应用图占主要区域，旁边必须保留平面主标与对应状态，Mockup 不独占整页 |

展示版不是把所有版本塞满画布。每页解决一个问题，Logo 之间保持统一尺度基准和足够安全区；准确标签、色值与说明由 Coding 排版，生成图只作为母版或应用素材。

## 提案、颜色与应用

提案可采用母版独占、左标右释、同尺度对照、递减尺寸带、真实构造序列或应用主图配平面证据。每张解决一个主要问题，规则色样可以矩阵，但不把每项说明套进同款卡片。

记录主色、必要辅助色和中性色；标准主标默认采用 `1–3` 个印刷色角色，常规不得超过 `4` 个。黑、白、奶油色、灰、正式描边、影边和身份容器填色均计入；第四个颜色只能是有固定对象的小面积强调色。角色、字标和容器共享同一色组，不为每个字符、五官、服装或道具分别配色。

单色、反白、灰阶分别检查。渐变默认不进入标准母版；确有品牌语义或已有资产依据时，必须同时保留可独立成立的低色数平面版、单色版和反白版。超过四个颜色只接受用户已确认多色母版或颜色序列具有不可替代含义的例外，并在 Brief 记录固定色序、对象、背景及降级方案；“活泼、丰富、年轻”不足以构成例外。背景上的对比靠选用合适版本，不随意给母版加厚描边或发光，不编造 Pantone、CMYK 或工艺色。

选择与品牌业务相关的应用：数字端可检验头像、导航与圆角裁切；实物可检验标牌、包装、压印或丝印限制。每个场景说明使用哪一变体、为什么合适，不为凑展示机械加周边。

复杂材质只作用于应用示意；清洁母版独立保留。AI 场景在 Coding 说明中标为效果示意，不假称真实门店、已上市产品或已完成制作。

## 形成每项素材生产意图并编译 Prompt

Brief 先为从零平面 Logo 主标，以及基于确认母版派生的单色、反白、组合、小尺寸、材质和应用状态逐项记录生产意图。冻结后在素材清单中每图编译一条完整 Prompt，先写具体风格与可见特征，再写图形概念、核心轮廓、负形、字标、配色、构图、安全区及必须保持项；比例和目标尺寸保留在素材清单参数中。生成顺序与参考依赖严格遵循“主标生成与状态派生”。

Logo 主标与组合标是普通素材规则的例外：品牌名称属于 Logo 本体时，Prompt 必须逐字写出准确文字、字体特征、字色、字重、字形风格、图形与文字层级、相对位置和断行，并在结果中逐字核对。提案标题、版本标签、解释段落和色值不进入 Logo 生图 Prompt，由 Coding 完成；Prompt 也不写“无文字／无字／no text”等否定词。

每张参考记录真实短链、来源和借鉴内容；Prompt 只用图1、图2，工具同序传参考参数，不放 URL 或路径。缺链标待补，不调用依赖它的编辑。只借鉴风格时不继承第三方轮廓、字标和专属符号。

## 视觉验收

- 准确字标、主轮廓、负形与获准母版相符，各变体同源。
- 品牌名已知时，每个首轮候选和最终标准主标都清晰包含准确品牌名；独立图形只作为确认后且有明确用途的附属变体，不冒充完整标准 Logo。
- 实际小尺寸、单色、反白、灰阶与深浅背景经过检查，未测试条件明确列出。
- 网格、安全区和构造标注对应真实几何，不伪造比例依据。
- 应用中标识未拉伸、变色、漂移；清洁母版与展示效果分开。
- 位图、可编辑路径、外部专业源和预览的能力如实说明；近似检查不宣称法律注册结论。

将本任务采用的做法写入 **视觉效果生产规范**，覆盖母版保护、造型与字标关系、配色、逐画板构图、背景、变体派生、素材职责和降级；将上述实际检查写入 **视觉效果验收规范**，不得只引用本文件或用 Mockup 数量代替母版与变体验证。
