# 电商详情页视觉表现规划

本文件把 [`ecommerce-detail-page-spec.md`](../scenarios/ecommerce-detail-page-spec.md) 输出并保存的内容结构 Brief，补充为同时包含内容规划与具体视觉表现的完整 Brief。

内容结构 Brief 提供屏数、叙事、每屏功能和文案；Visual 补充整图风格、艺术表现手法、配色、背景、图文组合、逐屏构图、文字排版和图片排版，并与 Spec 联合完善同一 Brief。商品事实与用户锁定的文案、顺序、职责及其他明确要求必须保留；完整方案确认前，模型自拟文案、段数、分组、顺序、配图与构图可联动推演，但不得丢失必要购买信息职责或改变商品事实。准确文案要求最终文字正确呈现，不将模型草稿永久冻结。联动结果同步回写同一 Brief 的内容与视觉条目，包括实际配图数量、覆盖范围及试排尺寸依据；确认与冻结仍沿原 KV／冻结流程，冻结后的改案按既有变更确认流程处理。正式电商 Hero 默认采用无字主图＋独立 HTML 原生标题与文案（商品与环境共同构图，保留原包装文字与 Logo）；主图不新增上屏文字，保留商品原有包装文字与 Logo。按 Brief 明确选择一体生成且符合文字编辑边界时，才将商品、环境、主标题及必要短辅助文字共同成图，以下 DIT 专节仅约束该所选模式，不用于候选视觉 KV。价格、日期、条件、参数和正文始终由 HTML DOM 承担；其余屏的准确文案也由 HTML DOM 承担，素材负责场景、材质、商品、人物和非事实装饰。

视觉选择不得改变商品颜色、比例、结构、Logo、包装文字和其他事实。有参考图时记录真实 URL 短链并说明借鉴内容；没有短链时写“短链待补”，不得编造。

## 底图与 Prompt 强制规则

整条详情页的作品级底面系统必须包含与商品、主题和已选视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整张长页。事实与正文安全区可以降低纹理频率、对比和密度，或使用局部纯色承托，但仍须与所属背景组连续；不同背景组按屏间衔接决定接续。作品级底面系统不等于必须生产一张覆盖全页的图片。

每次写出完整底图或按覆盖范围确定的背景组 Prompt 前，必须先读取并遵循 [背景图 Prompt](../ai-coding/asset-prompt-guide.md#5-背景图-prompt)，按其中的背景职责、纹理选择模型和完整 Prompt 编译语法描述材质、色场、变化方向、尺度、低纹理区与连续关系。该路由适用于新生成和编辑既有底图；直接复用真实底图时不强造 Prompt，但必须记录使用方式并保持本节的设计约束。

## 读取入口

进入本文件后，先按 `SKILL.md` 的画布资产读取与树状存储规则，在当前画布项目中查找以当前主题和品类命名的设计 Brief；不得只依赖对话记忆，也不得另建一份同主题 Brief。

找到设计 Brief 后，读取其中已经保存的“内容结构 Brief”板块，确认其中已有叙事节奏、说服链、总屏数，以及逐屏的屏幕类型、功能、配图要求和文案要求，再开始视觉规划。

如果没有找到对应设计 Brief，立即路由到 [`ecommerce-detail-page-spec.md`](../scenarios/ecommerce-detail-page-spec.md)，由 Spec 按当前对话上下文和已完成的澄清在对应位置创建 Brief，先填写主题、商品及其他已知信息，再完成内容结构规划；保存后返回本文件。如果已有 Brief 但没有完整“内容结构 Brief”板块，同样路由到 Spec 在原 Brief 中补齐。Visual 不得创建 Brief、猜测缺失屏幕或绕过 Spec 补写内容规划；已有完整内容结构时，按首段边界与 Spec 联合完善。

## 先按商品品类确定风格方向

购买动机只决定信息表达倾向，商品子品类、品牌定位、受众和真实材质共同决定具体视觉风格；以下是开放式优先项，不是封闭范围。

- **功能标品**：优先理性商务风、未来科技风；设计型硬件可用先锋实验风，金属、玻璃、织物和制造工艺突出时可用材质肌理风。
- **颜值感官**：优先杂志编辑风、自然质朴风、感官生活风、抽象光感风、奢雅精致风或材质肌理风；香氛花艺可用诗性浪漫风，东方茶饮与护理可用新中式风，潮流服饰可用都市潮流风。
- **高信任门槛**：优先理性商务风、自然质朴风或奢雅精致风；高端护理体验可用感官生活风，包装、膏体和原料质感可用材质肌理风，有真实东方文化依据时可用新中式风。
- **高频快消**：优先复古商业风、波普撞色风、趣味创意风或国潮装饰风；食品、饮品和洗护的食欲或触感可用感官生活风，多口味、联名和开箱叙事可用手账拼贴风。
- **B 端采购**：优先理性商务风或未来科技风；材料、加工精度和制造工艺可用材质肌理风，先锋实验风仅用于品牌形象段，不能破坏规格、资质和流程阅读。
- **轻奢高客单**：优先奢雅精致风、杂志编辑风、诗性浪漫风、新中式风、抽象光感风或材质肌理风；材质肌理风可直接作为主风格，以纸张、织物、皮革、金属、石材、玻璃和漆面的微距、压印、层叠与光泽控制建立价值感，不能把黑金配色简单等同于高奢。
- **虚拟服务**：优先理性商务风、未来科技风、都市潮流风、波普撞色风或先锋实验风；知识课程和文化内容可用杂志编辑风，亲子课程可用趣味创意风，旅行、活动和会员回顾可用手账拼贴风。

### 具体表现候选

以下配方归入上表相关大类，编号仅用于查找；同一手法可因品牌与内容跨类借用，不新增并行分类，也不要求每类均采用。

#### 理性商务风：证据与工程编辑

用于参数、规格与证据主导的商品：以网格、事实层级与标注组织购买判断；香气、口感或触感是核心时，不以参数面板替代感官说服。

**EV1.1｜实验室说明编辑**

- **签名**：冷静留白、编号、局部放大、细标注线和单一验证色。
- **影像**：真实商品棚拍或结构切片；不生成伪检测图、伪仪器读数和伪证书。
- **推荐**：ET01/ET04 + EC01/EC06 + EL01/EL04 + EI01；EA01 或 none。
- **退化**：深蓝渐变、发光线和任意百分比堆叠成“科技感”。

**EV1.2｜临床洁净证据**

- **签名**：高明度洁净底、精细线框、同口径对照和充分条件说明。
- **影像**：成分、肤感或器械使用只表达已证实事实；人物与肌肤保持自然纹理。
- **推荐**：ET01/ET02 + EC01/EC02 + EL02/EL05 + EI02；EA01。
- **退化**：过度磨皮、无来源的分子图、十字图标和医疗背书暗示。

**EV1.3｜工程规格图册**

- **签名**：模块化规格、尺寸基线、真实部件图与工程式图例。
- **影像**：准确结构使用真实资产或 Coding 示意；AI 只做无事实含义的环境和材质氛围。
- **推荐**：ET04 + EC03/EC06 + EL04/EL06 + EI03；EA02 或 none。
- **退化**：假爆炸图、不可追溯内部结构或装饰性网格挤压正文。

#### 感官生活风：商品微距与材质

以真实微距、反光、颗粒、液体或热气表现食品、护肤与材料质地；没有真实商品或稳定身份资产时，不把生成画面伪装成实拍证据。

**EV2.1｜食欲微距**

- **签名**：可见水汽、油脂、气泡、断面和真实食物色；近景焦点明确。
- **影像**：优先真实食品摄影；补景时保持产品形态、份量和食材事实。
- **推荐**：ET02/ET03 + EC04/EC05 + EL02/EL07 + EI04；EA02。
- **退化**：全屏橙红滤镜、塑料质感、过量酱汁和无法证明的配料。

**EV2.2｜流体护肤材质**

- **签名**：半透明凝胶、乳霜推抹、液滴边缘和克制高光形成空间。
- **影像**：包装必须来自真实资产；生成流体只作为独立材质层或背景机制。
- **推荐**：ET02 + EC02/EC07 + EL03/EL05 + EI05；EA03 或 none。
- **退化**：任意玻璃球、无关花瓣与包装共同压成不可编辑整图。

#### 材质肌理风：纤维与手作触感

**EV2.3｜纤维与手作触感**

- **签名**：织纹、纸纤维、木纹、陶土或手工边缘，以侧光显示真实触感。
- **影像**：材质不得覆盖规格、洗护条件和成分；局部纹理只在职责区域出现。
- **推荐**：ET02/ET05 + EC05 + EL03/EL08 + EI06；EA03。
- **退化**：仿古纸纹覆盖所有页面，导致商品色和文字对比失真。

#### 复古商业风：商业套色

促销、上新与节日零售可用大字级、利益标签与印刷节奏；高监管、证据密集或奢侈品叙事不默认采用高噪声促销语言。

**EV3.1｜复古商业套色**

- **签名**：暖纸、有限套色、粗字、错版边和商品剪影。
- **推荐**：ET03/ET05 + EC04 + EL01/EL07 + EI07；EA02/EA04。
- **退化**：滤镜做旧但没有套色纪律、版面轴线或真实商品焦点。

#### 波普撞色风：平面促销

**EV3.2｜高对比平面促销**

- **签名**：纯色块、大利益数字、商品破框和一个强行动色。
- **推荐**：ET03 + EC03/EC08 + EL01/EL06 + EI01；EA02。
- **退化**：所有信息都放进同权圆角卡片，价格与条件失去主从。

#### 手账拼贴风：上新拼贴

**EV3.3｜上新拼贴发布**

- **签名**：真实商品切片、票签/贴纸、可控倾斜与新品序列形成发布感。
- **推荐**：ET03/ET05 + EC08 + EL07/EL08 + EI07；EA04。
- **退化**：异质装饰多于商品，SKU、卖点和行动路径被剪贴层遮挡。

#### 自然质朴风：日常纪实

家居、服装、母婴、户外、文旅与服务可通过真实人物、空间、动作和光线表达使用状态；保持商品身份，场景不能替代必要的证据与参数说明。

**EV4.1｜自然日常纪实**

- **签名**：自然窗光、真实动作、不过度摆拍、可供文字进入的环境负空间。
- **推荐**：ET01/ET02 + EC05 + EL02/EL03 + EI08；EA01 或 none。
- **退化**：空泛“幸福家庭”图库感、人物与产品没有真实交互。

#### 奢雅精致风：棚拍静物

**EV4.2｜高端棚拍静物**

- **签名**：受控光位、准确轮廓、材质台面与少量道具建立价值感。
- **推荐**：ET02 + EC02/EC07 + EL03/EL05 + EI02；EA03。
- **退化**：黑金渐变、镜面台座和无关粒子替代真实材质表现。

#### 杂志编辑风：空间陈列

**EV4.3｜空间陈列叙事**

- **签名**：房间、门窗、台面或货架成为跨屏坐标；商品通过视线和路径被发现。
- **推荐**：ET01/ET02 + EC05/EC06 + EL08 + EI08；EA01。
- **退化**：每屏换空间与光向，长图只剩互不相干的场景图。

#### 未来科技风：结构与光场

面向设备、运动装备、结构创新或数字服务，受控 CG 与光场仅辅助解释；准确参数和标签由原生文字承担，不以生成的内部结构、能量路径或结果图伪装商品事实。

**EV5.1｜结构分解与路径**

- **签名**：真实部件或明确示意件按轴线分层，路径、编号、箭头可编辑。
- **推荐**：ET04 + EC06 + EL04/EL06 + EI03；EA02。
- **退化**：未经证实的爆炸图和装饰发光线被当作性能证据。

**EV5.2｜清透光场科技**

- **签名**：冷白到低饱和蓝紫的透明光层、清晰商品边缘和低噪声空间。
- **推荐**：ET01/ET04 + EC06/EC07 + EL03/EL05 + EI05；EA03。
- **退化**：霓虹、玻璃、金属、网格和粒子同时出现，文字落在高频背景上。

**EV5.3｜柔性 3D 机制**

- **签名**：圆润 CG 对象、作用界面、明确方向和少量材质对比，用于解释使用步骤、服务流程，或有可追溯依据且确有解释必要的递送、吸收、屏障、过滤、散热等机制；路径、数值与条件不烘焙进图片。
- **推荐**：ET01 + EC02/EC08 + EL06/EL08 + EI09；EA01。
- **退化**：无关 3D 图标墙、用抽象物件替代真实商品、无依据描绘功效路径，或把成分／部件机理扩大为成品效果。

## 整页 CSS 组合选择

以必要购买职责和可调整的视觉假设比较整页组合，再补局部原子；宽泛需求可先探索少量摘要帮助形成方向；保留用户锁定项，不先锁死模型自选的配色、栏数或图窗再排除候选。适配依据为信息主次、主体尺度、图文关系、阅读节奏及背景连接，不按参考章节数或内容相似比例评分。商品、文案、章节名可替换，槽位可按真实内容删减、重排、重复；核心视觉关系仍成立算组合适配，仅余网格、间距等零散能力算局部复用。

通过 [公共 CSS 组合入口](../../../../assets/templates/css/README.md#brief-combination-match) 限量检索，已知候选用 `describe`，拟采用的组合或布局用 `get <ID> --prose` 阅读设计正文，核对摄影主场、章节关系、素材要求与可调整范围，再联动完善同一 Brief。摘要只支持初筛，不能代替采用依据；确认采用结构后，在冻结时实际读取 `follow_ups` 指定变体的 HTML 模板、布局、皮肤及必要依赖，不以已读组合 dependencies 代替。Brief 的视觉方案用自然语言描述；所选 CSS 的 ID、源路径与版本、范围和内容映射沿用既有短采用记录，不另建记录。下列不是封闭清单；无适用组合才转独立布局及原子组装，只借局部不声称整页复用。

## 详情页反模板构图门禁

先读取 Spec 的“视觉证据节奏合同”，再决定风格、图片与容器。以下是完成 Visual 前必须写入同一 Brief 的构图约束：

1. **Hero 主体门禁**：正式电商首屏默认采用不新增上屏文字的连贯主图＋独立 HTML 原生标题与文案，并保留商品原有包装文字与 Logo。两种制作模式均由已选主导关系中的核心影像承担第一视觉焦点，商品身份须清楚可辨，完整商品不必总是最大对象；微距主导时，用可识别的全貌或定位上下文说明细节归属。标题、定位图与辅助信息服务主场，不得把核心影像缩成居中小图、顶部缩略图或普通段落配图。仅在 Brief 明确选择一体生成且符合文字编辑边界时，将商品、环境、主标题及必要短辅助文字共同编译；不用 HTML 覆盖、拆分或重排图内文字，价格、日期、条件、参数和正文仍由 HTML 原生文字承担。
2. **视觉高点门禁**：按商品与购买信息确定必要的主场和主图，不规定主场数量；有主辅关系时必须有明确的尺度与职责差，局部、背面、颜色、细节和搭配图不能全部等宽、等高、等圆角、等权并列，同条件比较可保持同尺度同权，不为满足数量或变化配额增加主场或强制造型差异。透气段不因独立成段、使用大图或包含完整主体而自动成为主场；Hero 后短过渡默认从属首屏，若实际已形成独立视觉高点，应复核其体验、价值或证据职责并返回 Spec 确认分类，不能以“透气屏”命名规避主场要求，也不能只因画面醒目便新增购买主张。
3. **证据形态门禁**：每屏写“整体轮廓／场景或上身／材质微距／结构标注／动作性能／规格决策／信任服务／收束”之一；相邻屏是否调整形态、商品尺度、图文位置或信息密度，由内容职责、证据关系与阅读需要决定，不为制造差异设置逐屏变化配额。同一连续场景可延续空间关系与构图语法，由镜头、焦点或信息推进；叙事阶段、证据责任或阅读节奏确有变化时，再选择必要的变化维度。连续对照允许重复形态，并写明对照维度。
4. **构图与辅图门禁**：跨栏、出画、局部放大、环绕、叠压和连续跨段均由内容增量决定，不设动作配额。辅图只有补充细节、定位、过程或比较时才增加，无新增信息可只保留主图；同条件证据允许同尺寸图窗，不为变化强行穿插。内容段高度、背景覆盖范围和交付切片分别落实：表格、FAQ、参数及规格段按真实行列、断行与间距定高，不继承 Hero 或整图背景高度；共享背景可跨段，切片不反向制造换景或段内空白。
5. **信息与情绪门禁**：高密度参数、尺码、服务、认证或 FAQ 按阅读负荷决定是否需要换挡，不要求逐段前后配置情绪图或空白屏。需要停顿时由商品、场景、材质或有职责的留白承担。信息屏可开放排版、表格或一组语义容器，但不能变成整页小字资料墙。
6. **决策模块门禁**：参数、尺码和 FAQ 必须说明帮助用户做出的选择、保留的关键条件以及阅读优先级；表格采用可扫描的列轴、行距和强调行，不可把所有事实压成细小后台表格。

遇到与这些约束冲突的构图时，先回写 Brief 的视觉证据节奏、图片层级或构图关系，再改 HTML；不得仅加渐变、装饰、卡片或阴影掩盖层级问题。

### 视觉丰富度与表达策略

先判断商品的主要说服方式，再分配图片、文字、材质、空间与容器的权重。整体应有鲜明调性、可感知的图片层级和阅读节奏；不以背景种类、卡片数量或装饰数量替代设计。以下策略与 EV/ET/EC/EL/EI/EA 组合使用，不改变生产轨道。

| 策略 | 图像如何说服 | 文字与卡片 | 丰富度应体现在哪里 |
|---|---|---|---|
| `technical-product` 技术卖点 | 产品大角度、真实部件、结构层次与使用证据 | 标题先给利益结论，数据和条件从属；内容平行时允许规则矩形与连续同轴模块 | 模块内部的主体尺度、透视、局部光场、结构细节与图文主次，不能只在旁边贴一张小产品图 |
| `sensory-commercial` 感官商业 | 食物／质地微距、原料、包装和场景相互承托 | 有性格的大字与清晰说明；色块、圆角或破框由品牌和内容决定 | 质感、景别、大小图、色彩和文字共同建立食欲与吸睛点，保留事实可读性 |
| `brand-editorial` 品牌编辑 | 克制棚拍、材质、意象与细节形成连贯的品牌世界 | 字体对比、疏密、对齐与偏心关系主导；无边界分组和少量有职责图片窗 | 取舍、比例、摄影质量和留白节奏；不能用缩小所有文字、黑金配色或图表装饰冒充精致 |

可结合诉求，但需明确一个主策略和局部辅助手法，视觉命题以贯穿作品的图文关系定义，而非只列风格词。高级感也可以由大图表达；规则卡片也可以承载完整视觉。先结合真实标题、正文和商品轮廓，在 Brief 中说明各段相对高度、图文关系和镜头职责，再在素材清单记录图片目标比例与文字安全区；素材就绪后在完整 HTML 中试排，直接落实实际段高、图片框、主体可见范围和文字组位置；图片应为这个版面预留文字净空，不能把自带边框、台座和完整构图的独立海报缩小后逐屏贴入。

采用系统化节奏时，在同一自然语言 Brief 的“视觉证据节奏”中说明依据、图片／文字层级、容器逻辑、重复原因，以及哪些屏承担焦点或呼吸职责。节奏与数量约束按当前 Spec 执行，不减免事实、图文归属、安全间距或逐屏图文关系要求。QA 对照同一 Brief 与最终 HTML，检查说明是否完整、逐屏关系是否落实，以及实际渲染是否呈现所述效果；不新增机器规划字段、旧合同或平行参数文件。

纯色不作为默认推荐。优先让影像、材质、光影和空间承担品牌表达；只有当前视觉系统确实需要安静、稳定的底面，且额外纹理会损害层级或商品表现时，才依据当前 Spec 的局部纯色适用要求采用纯色。在同一自然语言 Brief 中限定区域、说明取舍及其与产品影像、字体层级和留白的关系，并对照最终 HTML 检查实际效果，不要求另建纯色合同；“高级”“省时”“缺素材”或“更容易排字”均不是理由。纯色区域由产品影像、字体层级与留白关系承担丰富度，不得演变为整页纯色底加小图卡片的默认模板。

## 视觉主场表现手法

每个主场必须写成一个完整的画面方案，不可只写“商品放大”或“突出主体”。在 Brief 的“视觉焦点”“相对构图与图文占比”“图片层级与背景关系”中，至少交代以下六项：**主场类型、主体处理、背景或承托、文字关系、辅助证据、向下一屏的接力**。一个主场只选择一种主关系，辅助手法不得与主关系争夺注意力。

| 主场类型 | 主体如何表现 | 背景、文字与辅助证据如何配合 | 禁止退化 |
|---|---|---|---|
| 完整商品雕塑化陈列 | 商品以完整轮廓占据画面主要重量，可正置、偏心、悬挂、倾斜或跨出画面边界；通过台座、布面、纸面、金属台或连续色场承托，保留 Logo、接口、开合和关键结构 | 标题进入商品轮廓之外的安静区域；短卖点可沿商品边缘形成一条阅读轴；最多用一张局部图或一两个短标签补证据 | 商品缩成居中小图，四周围满等权卖点卡；商品和背景没有接触关系 |
| 人物上身／真实使用场景 | 人物动作、视线或姿态把商品带入真实尺度，商品处于可识别位置并保留人与商品的接触点；人物或商品至少一个跨越画面主要区域 | 文字跟随人物留白、墙面、地面或景深静区；可用一张裁切更紧的局部图衔接到材质或结构屏；环境色温与商品色形成关系 | 模特图缩成规则缩略图，或多张上身照等宽排成证件照式阵列 |
| 材质／工艺极端微距 | 单一材料、缝线、肌理、五金、织物褶皱、液体、膏体或表面细节放大到能直接感知触感，同时保留少量定位上下文 | 背景延续同一材质或让微距延展成整面色场；标题贴近被说明的细节；用一张小型全貌图标明微距来自哪里 | 微距只是一枚小方图；把不同材质随意拼成样品墙，无法知道它们属于商品何处 |
| 结构拆解／环绕标注 | 完整商品保持中心或偏心主位，真实部件、层次、开合或剖面围绕主体展开；标注端点精确指向实际结构 | 文字为短结论，沿清晰的环绕路径分布；背景保持克制，使连线、结构和商品轮廓可读；下一屏可承接其中一个被标注局部做微距 | 用无指向的装饰线和泛泛卖点围绕商品；商品被标注遮住或连线交叉 |
| 动作／性能瞬间 | 用手、人物、液体、光照变化、前后状态或真实使用过程表现一个动作的关键时刻，商品和结果在同一画面建立因果关系 | 结论文字放在动作前方或结果静区；必要时用一张连续帧或同尺度对照补足过程；背景保留动作方向的延伸 | 只把商品放在场景中却没有动作或结果；用装饰特效代替真实功能证据 |
| 编辑式大小图叙事 | 一张大图承担情绪或整体，少量小图以不同景别补充细节、环境或背面，形成错位、叠压、衬纸、边框或纸片层次 | 文字沿统一编辑网格穿插于大小图之间；小图可露出、压边或形成跨屏入口，但不和主图等权；适合品牌、服饰与生活方式内容 | 规则九宫格、三等分图片列，或每张图都用同样矩形、圆角与说明 |
| 连续场景跨屏 | 商品、人物、道具、色场、材质或一条路径从上一屏进入下一屏，在不同段落切换焦点、景别或信息密度 | 文字静区随场景移动；中段可从全景切到局部、再切到使用或规格，使同一世界内有节奏变化 | 每屏重新换无关背景；在屏界硬切商品、人物关节、Logo 或关键结构 |

### 按商品选择主场，不按页面套版

- **服饰鞋包**：按真实内容从“完整廓形”“上身姿态”“面料／五金微距”中选择所需主场；只有版型、上身与材质分别承担独立证据时才组合多个。完整廓形可让衣服悬挂、平铺成有张力的褶皱、搭在真实材质上或与模特形成尺度对照；上身屏优先展示版型、动作和搭配，不把正侧背三张图平均排开；材质屏把领口、缝线、面料、五金或内里放大成视觉表面，再以小型全貌图定位。
- **功能产品／家电**：按购买问题从“完整商品雕塑化陈列”“结构拆解／环绕标注”“动作／性能瞬间”中选择；需要多个主场时，由不同证据职责推动变化。技术感由结构、尺度、真实使用和受控光影建立，不能只用深色背景、蓝光和参数卡替代主场。
- **美妆、护理、香氛**：用“包装／器皿陈列”“质地或原料微距”“使用动作或感官场景”形成主场。膏体、液体、凝露、粉体、花材或玻璃折射应与真实包装存在物理接触或视觉呼应，不让瓶子漂在无关渐变上。
- **食品、生鲜与饮品**：用“完整食物／包装主角”“切面或质地微距”“制作或食用瞬间”推进。热气、冰感、酱汁、器皿和食材只在能解释口感、温度或新鲜度时出现，不能把所有产品缩在菜单式小图中。
- **家居、母婴与日用**：用“真实空间尺度”“人与物的使用动作”“结构或接触材质”递进。主场要说明它如何进入空间、解决什么使用动作或接触感受，而不是独立白底商品图。
- **高客单材质商品**：优先让一种真实材料成为整屏的承托面，例如皮革、木材、石材、金属、纸张或织物；商品与承托面形成压住、悬挂、嵌入、倚靠、反射或投影关系，价值感由触感、尺度和克制留白建立，不由黑金色块或小商品居中建立。

### 主场写回 Brief 的句式

每个主场可按以下自然语言完整表达，不填写技术参数：

> 本屏为“材质／工艺极端微距”主场。深色丹宁的领口、缝线和金属扣被放大为贯穿画面的触感表面，右下角以一张小型完整夹克图定位细节来源；标题沿缝线外侧的安静区域排布，短说明指向扣具与布料交界。深色织物从上一屏完整廓形延续到本屏，并在下一屏过渡为模特上身的衣领局部。无规则卡片，无等宽局部图列。

这类描述必须落入每个主场对应屏，而不是只写在整页风格字段中。

### Hero 冲击力构图：主体与场景方案

Hero 不允许只写“商品居中、背景高级、标题在上”。在以下方案中选择一个作为首屏主关系，并在 Brief 中逐项落实：**画面切入、主体尺度、空间承托、文字区、辅助元素、动势／对比、保护区域**。首屏文字与商品共同规划构图，不因文字由 HTML 独立实现就成为后加说明；默认模式的图片 Prompt 落实完整商品／环境与文字净空，文字排版由 HTML 实现；明确选择一体化 DIT 时，才把获准入图的主标题及必要短辅助文字一并编译。

| Hero 构图方案 | 如何形成冲击力 | 文字与辅助元素 | 适用与禁用 |
|---|---|---|---|
| 近距离压迫式主体 | 商品或人物以极近景从画面下方、侧边或前景切入，完整识别部位与被放大的材质／结构同时存在；主体压住大部分视觉重量，背景只保留少量可辨空间 | 标题贴近主体边缘的安静负空间，短副标题沿主体方向排布；只保留一条关键卖点或材质标记 | 适合服饰、鞋包、材质、器物；不能把关键 Logo、开合、穿着廓形或人体关节硬切掉 |
| 斜向动态穿透 | 商品、人物姿态、道具、布料、液体、路径或光影沿对角线贯穿画面，形成从首屏入口到段尾出口的方向 | 标题与副标题沿对角线的反侧或停顿区排布；小元素顺着动势递减，不能反向堆成卡片 | 适合上身、运动、功能动作、食品和高频快消；没有真实动作或方向关系时不用装饰斜线假造动势 |
| 材质舞台对抗 | 商品与一种大面积真实承托材质建立压住、悬挂、嵌入、倚靠、反射、褶皱或投影关系；材质尺度大到像一个舞台而非小纹理 | 标题落在材质较平整的静区；材质名称或短卖点可像压印、标签或铭牌融入画面 | 适合丹宁、皮革、金属、玻璃、纸张、木石、香氛和高客单商品；禁用无关渐变和悬空小商品 |
| 人物与商品同尺度场景 | 人物以动作、视线、手部接触或身体姿态把商品带进真实使用场景，商品在画面中有清晰可识别的尺度与作用 | 标题落在墙面、地面、景深、窗光或人物朝向留出的区域；辅助文案不覆盖脸、手和商品接触点 | 适合服饰、家居、母婴、日用和功能产品；禁用多张小模特照并列代替一个完整场景 |
| 局部极端放大与全貌定位 | 一种核心结构／材质占据大部分画面，另一角保留较小完整商品或人物轮廓，让用户同时感知触感和整体身份 | 标题沿放大细节的低干扰边缘；完整商品只承担定位，不与微距争夺主场 | 适合面料、五金、膏体、食品切面、接口和工艺；禁用无来源的小方细节图 |
| 物件破框与跨页入口 | 商品、人物或关键道具越过首屏边缘，部分轮廓进入下一屏；首屏显示完整身份，段尾留下可被后续材质／结构／上身屏承接的局部 | 标题与商品错开，避免把主体封进框内；段尾只留下一个明确接力对象，不叠加多种装饰 | 适合长图详情页、系列叙事和具有强轮廓的商品；禁用在屏界切断 Logo、人物关节或功能结构 |

正式电商 Hero 的画面方案需按以下顺序组织为完整构图，而不是孤立列出“背景、商品、标题”；默认模式将画面与净空编译为图片 Prompt、文字关系落实为 HTML，明确选择一体化 DIT 时才将获准入图文字一并编译：

1. 先写主场类型与画面切入方式，例如“斜向动态穿透的深色丹宁夹克 Hero，夹克从右下向左上穿过画面”。
2. 写商品／人物的可见尺度、姿态、完整保留部分、允许进入画外的部分，以及与台面、布料、环境或人物的真实接触关系。
3. 写背景的空间、材质、色温和明暗，并指出一块为标题保留的平整静区，而不是泛写“高级背景”。
4. 在 Brief 中按阅读顺序逐项写首屏准确文字，并分别写信息层级、字形气质、字色、字重、特效、行数、对齐和与主体的避让关系；默认全部由 HTML 原生文字实现，不传入图片 Prompt。明确选择一体化 DIT 时，只将获准入图的主标题及必要短辅助文字写入 Prompt；价格、日期、条件、参数和正文仍原生排字。
5. 最后写只服务主场的辅助元素、必须保留的商品身份、禁止出现的无关卡片／缩略图／装饰，以及段尾如何把一个局部交给下一屏。

例如服饰 Hero 不应是“黑色夹克居中白底，标题在上”。应写成：深色丹宁夹克以近距离压迫式主体从右下切入，肩线、皮领和前袋形成大尺度前景，夹克下摆保留完整识别轮廓；粗粝深灰织物从左上向下延展为承托面，左上平整暗区承载品牌、商品名与一句利益点；一枚低调金属扣的局部反光作为唯一辅助；段尾保留衣领与缝线局部，下一屏从此进入材质微距。默认将夹克、背景和金属扣作为完整连贯主图，保留原包装文字与 Logo，不新增上屏文字，标题与文案由 HTML 原生实现；明确选择一体化 DIT 时才将主标题及必要短辅助文字共同入图，价格、日期、条件、参数和正文仍原生排字。

## 容器与开放排版视觉决策

Visual 先确定信息之间是并列、递进、对照、指向主体还是共同说明，再判断这些关系是否需要可见边界。信息分组、网格对齐和内容分段都不自动意味着加底板、边框或圆角；先在已确定的共享背景上安排主体和文字，用对齐、字级、留白、编号或必要的线条表达关系。按照 [容器视觉语法](../composition-layout.md#容器视觉语法开放排版优先语义容器按需) 决定是否增加容器，并将结果写回同一 Brief。

可见容器应承担开放排版尚不能充分表达的职责：隔离复杂背景以保证阅读、区分独立比较单元、形成明确的标签或凭证，或实现已选参考中的收纳、纸页和框景关系。只写“有多条卖点”“科技感”“需要分组”不足以决定卡片；先说明边界增加了什么作用。已有背景静区、图窗或载体能承担该职责时直接利用，不再逐条套框。

### 按内容关系选择组织方式

| 内容关系 | 先考虑的组织方式 | 何时需要可见容器 |
|---|---|---|
| 几条短卖点共同解释一个主张 | 同一文字组内对齐、编号、分隔或主次排字 | 各项需要独立识别、局部承托或明确分隔时；共同承托可覆盖整组，不默认一项一卡 |
| 信息解释同一产品、结构或场景 | 将说明安排在对应主体附近，按实际关系使用引线、标号或环绕排字 | 标注在真实背景上难以阅读，或需要明确标签时；不为容器腾位而把主场缩成段落插图 |
| 同条件规格、方案或选项比较 | 共享列头、基线、表格或开放网格 | 独立选项边界有助于识别或对应真实交互时，可采用稳定卡片；不把所有参数拆为孤立小块 |
| 步骤、时间或因果链 | 顺序排布、路径和有依据的连接 | 步骤内含需整体阅读的独立图文，或边界能帮助区分阶段时；不能用等权卡片抹平顺序与因果 |
| 照片、截图和局部证据 | 保留必要图窗及就近图注，主图与局部图分工 | 需要框景、衬纸或来源区分时；完整场景不默认加相框，图内已有边界不重复构造 |
| 凭证、权益、档案或收纳关系 | 按真实语义组织完整信息组 | 可采用票券、文件夹、纸页等结构；材料名称本身不决定内容应装进哪种容器 |
| 背景纹理复杂的必要正文 | 优先利用稳定净空、调整文字位置或适配取景 | 仍无法清楚阅读时，使用范围适当的承托面；不是先为每段生成复杂背景，再统一盖卡片 |

### 有容器时再决定外观

确定职责和覆盖内容后，说明位置与主次、内部留白及与主图和共享背景的关系，再选择需要的轮廓、材质、边缘和层级。色调或商品类别不直接决定容器：科技不等于磨砂玻璃，原料不等于纸卡，重要结论也不必改成铭牌。中性矩形、开放栏线或有语义的结构容器都可采用，以实际阅读和选定视觉为依据，不用复杂外形替代合理组织。

只描述采用的效果，不为每组内容枚举一套材质、阴影和模糊参数。复用同一组织方式时引用共用决定并说明必要差异；无需容器的区域写清开放组织关系即可。相邻段可沿用相同排版，不为避免重复强制换框；真正需要区分的是内容层级与职责。

规则容器交给 HTML/CSS；复杂壳体按 [素材使用规范](../ai-coding/asset-prompt-guide.md) 准备。正式电商 Hero 的容器或标注若被采用，两种模式均须与商品和文字共同构图；仅明确选择一体化 DIT 时，获准入图的主标题及必要短辅助文字随完整画面生产。价格、日期、条件、参数、正文及其余准确文字保持原生可编辑。

验收依据是关系是否清楚、边界是否有作用、主图尺度与正文可读性是否保留，并按通用容器策略检查容量和净距。多张等权卡片若削弱共同主张、主体关联或连续阅读，应回到信息组织重排；独立比较单元采用统一卡片则可以成立。不得以卡片数量少、轮廓复杂或已经命中 CSS 作为通过依据。

在纸媒或公告语义成立时，可选择 [卷纸与垂挂纸面 / shape.scroll-sheet](../../../../assets/templates/css/shapes/notes-and-paper.md#shape.scroll-sheet) 承托说明，或以 [不规则档案纸与报纸面 / shape.archival-sheet](../../../../assets/templates/css/shapes/notes-and-paper.md#shape.archival-sheet) 表现复古档案。它们是局部原子，不能替代整页组合；卷边、折痕和纸边不得压住准确文字，不为填空额外添加纸卡。

### 已有布局 CSS 能力表

下表提供本品类常用布局能力，实际可用范围按当前库查询。Visual 根据内容职责选择，不按顺序轮用，也不要求每屏使用一种；写回 Brief 时使用表内能力名称和实际图文关系，便于后续自然语言匹配。名称用于描述视觉关系；选中的 CSS 来源与范围沿用 Brief 中的既有短采用记录，类名和参数只进入 HTML 实现。

| 布局能力 | 适用关系 | 写入 Brief 的边界 |
|---|---|---|
| 紧凑内容 | 同组事实、短字段、密集但可扫描的信息 | 写明压缩的是留白与组距，不缩小到不可读，也不把无关内容塞进同框 |
| 宽松内容 | 单一主张、少量重点、需要呼吸感的组件 | 写明留白服务的焦点与阅读停顿，不用空白凑画布高度 |
| 规整对齐（方格／网格排版） | 参数、证据、规格、并列比较和稳定栏目 | 写明列组、共同基线与主次；方格只组织可比较内容，不自动生成卡片墙 |
| 疏朗留白 | 长文、说明、编辑阅读栏与安静叙事 | 写明行宽、文字轴、图片归属与段间节奏，不等于所有内容缩成窄列 |
| 错落平衡 | 短标题接力、偏轴构图、左右不等权信息 | 写明错位对象、方向和共同对齐依据，不随机散放正文 |
| 聚焦主场 | 商品、人物、作品或场景作为第一视觉焦点 | 写明主体尺度、取景、文字静区和图文前后关系，不把主图缩成卡片配图 |
| 连续流动（串页／长页排版） | 长图章节、连续叙事、上下屏衔接和系列阅读 | 写明上一段出口、下一段入口、共享背景或接力对象，不只写“向下阅读” |
| 叠层拼贴 | 多张照片、纸片、证据或装饰需要错位叠压 | 写明主片、副片、角度、遮挡与保护区，不用随机旋转制造丰富 |
| S 形导览线 | 流程、路线、时间或概念节点需要曲线推进 | 写明真实节点、起止点和绕行保护区；没有关系节点时不用装饰曲线 |
| 横向卡片列 | 已确认需要独立边界的比较项或可扫描单元 | 先确认卡片职责，再说明共同尺度与差异；只需并列文字时采用开放对齐，长正文和复杂条件不挤入窄卡 |
| 章节眉线 | 章节编号、标题、短导语与换章提示 | 写明眉线承担的层级与接续对象，不把分隔线当主视觉 |
| 带引导线的图像标注 | 产品部件、成分、结构、地图或证据图解释 | 写明标注对象、端点和文字归属；引导线必须指向真实细节且不交叉遮挡 |

同一屏可组合兼容能力，例如“聚焦主场＋带引导线的图像标注”或“连续流动＋章节眉线”；组合后仍须形成一个明确主关系。没有适用能力时保留自定义关系并描述可见结果，不为命中模板改写内容。

### CSS 原子能力校验

最终 Brief 冻结前，随方向假设与候选比较，按整页关系查询组合，按下列能力词查询布局、字形、形状、表面与背景原子，不把所有查询限制为 combination。组合负责整体关系，原子补局部能力；Brief 记录选中 ID、源路径与版本、范围和映射，不复制代码或参数，候选可启发新的图文关系与素材方案，并回写改善模型草案；采用理由须落在商品表达、购买理解或阅读体验上，不因效果现成而堆入装饰。

| 决策维度 | 交给查询的自然语言能力词 | Brief 保留内容 |
|---|---|---|
| 布局 | 阅读轴、主图关系、网格、错位、叠层、连续流动等实际关系 | 本屏图文主次、阅读路径与开放／分组方式 |
| 字形 | 填字、描边、发光、浮雕、路径排字等可见效果及文字角色 | 哪组文字采用何种效果、作用和可读边界 |
| 形状 | 当前选定的容器、图窗、票券、纸边、徽章或其他轮廓 | 轮廓服务的真实内容与本屏差异 |
| 表面 | 纸张、玻璃、塑料、织物、金属、柔焦等材质及承载对象 | 材质落在背景、卡片、图片还是文字，正文如何保持清晰 |
| 配色与背景 | 色彩职责、渐变／弥散方向、纹理类型及覆盖范围 | 可见色彩关系、背景变化、静区和保护范围 |

摘要只支持候选判断，不证明效果已实现；采用时读取对应正文、模板与必要依赖，把可见目标写回原 Brief，最终以真实渲染验收。没有适用候选时保留方向，说明素材或原生实现分工；只借原子不声称采用完整组合。真实引用、依赖、参数和消费者只进入后续最终 HTML。

## 决定艺术表现手法

艺术表现手法必须能直接进入生图 Prompt，不能只写“高级、清新、科技、治愈”等情绪词。每个方案从对应品类中选择一至三种与卖点有关的手法，并用自然语言写清“背景如何处理，主体如何处理，辅助元素如何处理，由此烘托什么调性”；首屏必须重点写，后续屏减弱、变奏或用同一线索延续。

- **功能标品**：用深浅渐变、体积光、精密网格或克制雾场建立技术空间，将商品悬浮、轴测、拆解、局部剖开或与人物形成夸张尺度对照，以细线、光轨、几何色面和真实结构标记组织信息，烘托精确、可靠、先进；可用局部破框与极端放大强化核心结构，不得加入虚假仪表与参数。
- **颜值感官**：用柔焦渐变、半透明介质、织物或自然材质铺成背景，将主体做微距放大、局部虚化、薄雾包裹、逆光剪影、透明容器封存或原料透光薄片化，以花叶、水纹、凝露、折射、重影和流动色影衔接；也可用色味转译，让口味、香气和温度对应整页单色、材质与光线，烘托细腻、松弛、可触摸的感官想象。
- **高信任门槛**：用高明度洁净空间、透明层叠、受控实验环境或真实原料档案弱化杂讯，将商品稳定正置、剖面分层、透明容器封存或与原料并置，以微观纹理、柔和光晕、折射边缘和清晰证据区辅助，烘托洁净、专业、温和可信；可用过程转化展示使用顺序，但艺术处理不能伪造机理与效果。
- **高频快消**：用高饱和同色场、冰感透明空间或强对比色块制造即时刺激，将商品与食材做水中浸没、飞溅、气泡附着、冷凝微距、冰块封存、重复阵列、冻结运动或大小尺度错置，以碎冰、果肉、液滴、透明器皿和包装节奏强化爽点；也可用糖浆沙漏、绒布果味等材质隐喻把慢熬、浓郁、清甜与冰爽变成物理形态，烘托新鲜、丰盛、轻快和购买冲动。
- **B 端采购**：用真实厂房、金属工作台、深色工业空间或工程蓝图底面建立环境，将主体正交陈列、结构拆解、截面放大或连续工序展开，以硬侧光、材料纹理、尺度参照、过程转化和模块化分区辅助，烘托耐用、规范、可验证的制造能力。
- **轻奢高客单**：用纸张、织物、皮革、金属、石材、玻璃或漆面形成大面积材质场，将主体雕塑化陈列、极端微距裁切、悬浮、尺度错置或与异质材质超现实并置，以掠射光、柔影、压印、褶皱和少量手工痕迹突出触感；可用银盘、餐具、透明台座和礼盒搭成静物舞台，以丝线、枝梗或光带跨屏延续，烘托克制、稀缺、静谧且有收藏感的价值，不以黑金套色替代材质表达。
- **虚拟服务**：用抽象渐变、流动光带、空间网格、档案拼贴或编辑式拼贴构成无实体背景，将真实界面、课程内容或权益载体做透视层叠、窗口悬浮、路径串联或连续过程转化，以光点、连线、纸张切片、照片票据和动态残影提示流程，烘托清晰、连接、成长或前沿；不能虚构界面与服务能力。

当商品具有亲子、宠物、礼赠或潮玩属性时，可跨品类使用角色化与微缩叙事：把商品拟人化或与品牌角色结伴，利用表情化结构、心形等主题部件、微型生活场景和连续动作建立亲近感；角色不得遮挡商品身份，也不能虚构功能。跨屏可选择一条梗、丝线、液流、枝叶、光带或重复道具作为连续视觉线索；按每屏新增内容决定保持或调整其位置、尺度或状态，连续关系成立时允许稳定重复，不能用无职责复制代替内容推进。

## 决定配色

- 奶油白、米白等暖浅中性色，仅在用户、确认参考或品牌／商品本身有明确依据时才作为大面积底色，不因品类或“柔和、高级”等气质词自动选用。
- 先保护商品、包装、Logo、肤色、食品和材料的真实颜色，再依次从商品主体色、品牌识别色、核心原料或材质色、可信参考图的主色中选择一个主色；只有这些来源都不足时，才根据品类情绪另选颜色。Brief 写明取色来源，不能只写颜色名称。
- 当商品本身已有强识别色时，优先将它作为主色或让背景使用其同类色、邻近色，使商品自然融入；当品牌色具有强制识别要求时，以品牌色为主色，并让商品色在画面中保持真实，不为统一色调而改色。
- 选定主色后，追求统一、柔和或高级时，从同类色的深浅变化或色相相邻的颜色中选择辅助色；需要突出购买按钮、关键数字或爽点时，才选择主色的互补色或分裂互补色作为强调色。黑、白、灰和低饱和材质本色负责承接文字与留白，不与主色争夺焦点。
- 整页默认只出现两个有彩色系：一个主色系和一个辅助色系；确有强调需求时增加一个强调色系，最多三个有彩色系。一个色相的深浅、明暗和饱和度变化仍算同一色系，黑白灰等中性色及商品不可改变的固有颜色不计入，但新增背景、文字和装饰色必须受该数量约束。
- 主色覆盖主要背景与核心视觉，辅助色用于分区、层次和跨屏过渡，强调色只少量出现在真正需要聚焦的位置；不同屏可以改变三者占比和明度，不能引入新色系或每屏更换色板。切换明暗分支时，正文、次要文字及标签色随背景成对调整，保持可读对比。摄影素材颜色较多时，通过共同色温、综合色调和降低无关颜色存在感，让它仍归属于整页色系。
- 概念说明的范围与频次遵循 [内容创作与事实边界](../../shared/content-truth.md)，保持清晰可读，不抢占主信息。

## 决定整页背景及跨段覆盖范围

先按购买信息与参考确定图文关系，再决定容器和素材生产单元。商品与环境共同承担体验或说服时，优先评估满幅场景覆盖对应内容段，将 HTML 原生标题、说明、标注与图形安排在同一构图中；满幅指覆盖该段画布宽度，段高由内容决定，不等于固定视口或整页只用一张图。该判断适用于正文中的使用场景、感官和材质表达，不仅限于 Hero；需要独立移动商品或跨层穿插时采用透明主体与开放排字；细节证据、并列比较或明确取景边界需要独立观看时采用局部图窗。再据此确定背景组覆盖范围和局部配图，不从现成容器反推主体尺度。完整商品／环境场景可同时承担背景和主图职责，无须另生空背景或把主体重新装入图片卡片；图片覆盖范围与文字归属分别决定，可编辑文案不要求拆散完整场景。背景组可以跨越多个内容屏；共享背景指同一可辨空间或连续底面的延展，须能说明跨段的材质尺度、光向、空间深度或色场走势如何接续；颜色相近、使用同一风格或同类纹理，均不足以判定共享。相邻段仍在同一空间或连续说明中时，优先改变主体、景别与信息组织，不随屏号重置背景。章节变化只提示复核，不自动换景；确有场景、证据表达或阅读需要时可另起背景组。在 Brief 的“背景连续性与衔接”中补全各组起止段、连续依据、换景理由、交界关系与必要的融合约束；独立图窗单列，不冒充共享底图，也不强制整页只有一个背景。
- 有参考时记录 URL 短链与借鉴职责，按用户指定范围保留连续场景、跨段覆盖和过渡方向；不能把参考的一片连续底面拆成逐屏重新起算的渐变或重复纹理。未指定精确复刻时依内容调整，但仍先确定覆盖关系；不复制未获授权的商品、品牌或人物身份。
- 首屏、证据段与结尾通过主体尺度、图文密度和局部取景形成节奏；写清首屏出口、下段入口及接力对象，换景须说明边界和依据。结尾先通过既有背景、开放式主体或文字／服务关系完成收束；独立图窗须补充新的商品、礼赠、场景或服务信息，并说明为何不能由现有关系承担，不能因留白较多或模板存在图片槽而默认插入。正式电商 Hero 默认保留完整连贯的商品／环境主图并独立原生排字；明确选择一体化 DIT 时保留其完整成图、不拆解获准入图文字。两种模式均提前规划衔接，不把整条长图交给一次整图生成。
- 按共享范围准备背景素材或 CSS 色场，内容段共同消费，渐变和纹理不按段重启。连续性以最终可见图层为准：根 CSS 渐变被不透明图片遮盖不算兑现，须检查上层图片边缘、色场、光向或材质的实际接力；有意独立的图窗不强制融合。段高变化后复核共享取景、主体净空和过渡位置；同时验收整图及交界，不用白雾掩盖空间错位，共同父层与坐标沿用现有 HTML 组装协议。

## 决定整图图文组合关系

从下列关系中选择一种主关系贯穿整图，可以按叙事在局部变化，但要说明变化规律：

- **图像主导、文字嵌入留白**：大面积场景或商品图建立情绪，文字进入真实低干扰区域，适合颜值感官与轻奢商品。
- **商品主导、文字环绕说明**：完整商品作为中心或轴线，标题、卖点与细节围绕商品展开，适合功能标品和新品介绍。
- **图文左右交替推进**：图片与文字在连续长页中交替换边，形成稳定阅读节奏，适合多卖点和生活方式商品。
- **编辑式大小图穿插**：大图建立章节，小图补充细节与证据，文字沿统一网格组织，适合杂志编辑、品牌故事和材质商品。
- **证据网格与视觉高点衔接**：参数、步骤和比较使用理性网格；需要降低连续阅读负荷时，先在原内容段内调整商品尺度、景别、密度或留白，独立透气段只承接 Spec 已确认的职责。
- **连续场景承载多屏内容**：商品与环境沿同一空间跨屏延续，文字在不同区域出现，适合生活方式、未来科技和抽象光感方向。
- **商业海报与信息区交替**：强标题、商品和色块形成促销高点，随后用清晰信息区解释规格与条件，适合高频快消。

## 决定各屏图文关系

结合整页背景覆盖关系，各内容段按首段边界联动完善内容结构 Brief 的功能、证据职责、文案和尺寸要求，再从下列关系中选择并写明。原有配图意图不等于逐段独立生产背景；需要调整资产数量或合并共享范围时回写同一 Brief；图文关系必须解释它如何服务购买信息职责，不能另造无依据的内容主张。素材未兑现预期时调整受影响素材／版面，不将临时避让固化为默认构图。视觉试排使真实字体、素材比例或构图需要调整段高时，只回写同一 Brief 的尺寸策略与段高依据；具体高度、后续屏位置、完整背景使用、图片消费区域、接缝和切片在最终 HTML 中同步调整并由真实 DOM 测量，不另建平行尺寸计划：

- **文字压在图像净空区**：适合单一主张与大图，必须先确认背景低干扰且文字对比清楚。
- **文字与图片左右分区**：适合解释功能、场景和卖点，文字与图片可换边但保持统一轴线。
- **文字在上、图片在下**：适合先读结论再看商品或步骤，标题区不能挤压主体。
- **图片在上、文字在下**：适合先产生感官吸引，再补充名称、参数和说明。
- **中央商品、四周说明**：适合结构、接口、材料和局部卖点，标注不得交叉或遮挡商品。
- **大图带小图证据**：主图负责整体，小图负责局部、前后、步骤或对比；小图必须与文字归属清楚。
- **文字模块与图片模块交错**：适合多段说明和多场景内容，模块之间用共同网格和背景连接，不能变成卡片堆砌。
- **纯图透气或纯文字宣言**：只用于内容结构 Brief 已确定的透气屏，不承担参数、优惠和复杂功能解释。

### 单模块文字

- **标题与短说明上下排列**：标题先给结论，说明补原因或条件，适合大多数卖点屏。
- **大标题独立占区**：标题成为视觉锚点，正文放在相邻安静区域，适合开场、章节和透气屏。
- **标题贴近商品局部**：标题与被说明结构形成明确对应，适合细节和材质屏。
- **短句沿边缘或轴线排列**：适合编辑式、潮流和实验风格，但必须保持自然阅读顺序。

### 多模块文字

- **同轴纵向分组**：多个卖点沿同一左轴或右轴排列，适合参数、步骤和功能解释。
- **主结论加并列要点**：一个大标题统领多个短模块，模块等权且间距一致。
- **对照双栏**：左右分别表达两种规格、场景或差异，标题、单位和条件必须同口径对齐。
- **步骤序列**：按真实操作顺序连续排列，每步由短标题、动作说明和对应图片组成。
- **中心结论加环绕说明**：适合商品结构与多细节解释，环绕模块数量受空间限制，不能让连线交叉。

正式电商 Hero 默认标题与文案全部保持 HTML 原生可编辑，禁止生成独立标题字图；只有 Brief 或用户明确选择一体化 DIT 且不与文字独立可编辑要求冲突时，主标题及必要短辅助文字可与商品／环境共同成图，按下方 Hero Prompt 规则编译。价格、日期、条件、参数、正文及其余分层文案始终保持原生可编辑。主标题、卖点标题、正文、参数和注释形成清楚层级；文字排版必须覆盖原屏“文案类型”中的全部信息与来源，模块多少由内容决定，不用缩小字号强塞。

| --- | --- | --- |
| 适合商品身份、外观和核心利益 | **完整商品居中或偏心陈列** | 偏心位置为文字或细节留出空间。 |
| 适合材质、接口和工艺 | **局部细节放大** | 必须保留足够上下文说明细节位置。 |
| 适合连续叙事和强视觉高点 | **商品破框进入下一屏** | 不能切断关键结构或文字。 |

### 多图组合

| --- | --- | --- |

图片裁切、参考图短链和事实保护继续服从内容结构 Brief。多图不是越多越丰富，只有承担不同信息责任时才并列出现。

### 影像与材质候选

所有矩形生成资产按最终槽位的目标比例规划。直接贴合且不裁切的资产，就绪像素比例与图片显示框比例误差不超过 1%；比例差本身不等于实际拉伸。采用等比 cover／contain 或裁切时，以实际取景、主体与文字安全区保护、有效像素是否满足最终显示尺寸验收，不因源图与显示框比例不同直接判失败。禁止运行时非等比拉伸。图片后处理的职责、范围和回退写入原素材清单；cover／contain、蒙版、渐变与描边等显示实现直接落实到最终 HTML，不新增 `postprocess_plan` 机器合同。

## 按背景覆盖范围与独立配图编译素材意图

先为已确定的共享背景逐项写生产意图，再为独立主体、图窗与细节图逐项编写；一项共享资产列明所有消费内容段，各段不重复生成它。逐项说明用途、参考来源、覆盖范围或取景、主体与辅助元素关系及目标调性，核对各段要求均有素材承接。独立多图分别说明职责与差异，不能共用一句模糊 Prompt；共享背景也不能因覆盖多段而复制成多张仅风格相近的图。冻结同一 Brief 后，素材清单按这些实际生产单元编译 Prompt 和尺寸，沿用既有事实保护与准出流程。


普通配图 Prompt 只描述画面，不写上屏文案、文字排版或“无文字／no text”等否定词；留白只描述位置与空间。正式电商 Hero 默认同样只编译完整连贯的商品／环境画面与原生文字净空，主图不含新增上屏文案。按 Brief 明确选择一体生成且符合文字编辑边界时，商品、环境、主标题及必要短辅助文字才共同进入一条 DIT Prompt；价格、日期、条件、参数和正文仍由 HTML 原生文字承担。商品本身的包装文字与 Logo 属于身份保护要求，不得因此删除或改写。

风格是画面描述的首要信息：每条 Prompt 开头写明 Brief 已确定的具体风格及其视觉特征，再围绕它描述主体、动作、数量、背景、辅助元素、艺术手法、配色、材质、构图、视角、明暗及裁切保护。比例与像素尺寸只放工具参数，不进入 Prompt 正文。不能只列物件或用“高级感”代替具体风格；Hero 的文字表现也必须服从同一风格。

每条 Prompt 先写清画面部分：

- 具体风格及可见特征，后续的图形处理、色彩、材质与空间关系如何共同服务这一风格。
- 这张图服务哪一屏、承担什么作用，是商品主图、场景图、细节图、步骤图、对比图、材质图还是透气图。
- 参考哪张图（如图1/2/n），具体继承商品身份、人物、场景、构图、光影、材质或风格中的哪些内容。Prompt 本身只用图序号指代参考图，不写 URL、本地路径或工具参数；真实 URL 短链按相同顺序传入生图工具的参考图参数，并在对应屏的“屏内配图”中记录。没有短链时写“短链待补”，不得调用参考生图。
- 画面主体是什么，商品的颜色、比例、Logo、包装文字、接口和关键结构必须保持什么；是基于原图编辑时明确说明不得重绘成另一款商品。
- 环境、人物、动作、道具和非事实装饰是什么，它们如何服务本屏功能，哪些内容不能新增或虚构。
- 构图、景别、视角、主体位置、前后景和低纹理留白区域是什么；目标比例与尺寸单独传工具参数。正式电商 Hero 默认在 Prompt 中落实完整画面与真实净空，各组文字的位置关系由 Brief 与 HTML 落实；仅明确选择一体化 DIT 时，将获准入图的主标题及必要短辅助文字编译到对应区域。
- 光线的方向、强弱、软硬、色温与氛围，色彩和材质如何服从整页风格、艺术表现手法、配色及全屏背景。
- 裁切与保护要求，以及错误 Logo、畸变、额外肢体、结构变化、无依据功能和不一致商品等画面问题；普通配图不额外加入文字相关否定词。

示例：把图1的商品放在图2的背景中，做一张密封结构场景图，画面为中近景，图1中的杯子直立，位于画面偏右，一只手握住杯盖，完成真实旋紧动作，左侧保留约三分之一连续低纹理区域，材质反光自然清晰。光线从图2左侧窗户柔和照入，浅灰背景。

纯背景、材质或氛围图片也必须写 Prompt。正式电商首屏遵循 Spec 的模式选择：默认生产不新增上屏文字的完整商品／环境主图，保留原包装文字与 Logo，标题与文案独立原生排字；按 Brief 明确选择一体生成且符合文字编辑边界时，才将主标题及必要短辅助文字共同入图。价格、日期、条件、参数和正文始终原生排字；其余屏不得要求图片模型生成最终准确标题、参数、优惠和说明文字。已有真实商品图能直接使用或确定性裁切时，不为凑 Prompt 重复生成，只在对应屏的视觉字段中写明直接使用方式。

### 正式电商 Hero：按需一体生成（候选 KV 不使用本节）

本节仅在 Brief 或用户明确选择正式电商 Hero 一体化 DIT 且不与文字独立可编辑要求冲突时适用，不用于候选视觉 KV。商品、环境、主标题及必要短辅助文字在同一张 DIT 图中生成或编辑，不由 HTML 覆盖或重排图内文字；价格、日期、条件、参数和正文始终由 HTML 原生文字承担。除画面描述外，必须在同一条完整 Prompt 中逐项写出获准入图文字的以下要求，不能只写“加上标题和卖点”或引用 Brief 让模型自行取文案。构图主关系先遵循上方“Hero 冲击力构图”确定，再填写文字。

- **准确文字**：按阅读顺序逐项引用获准入图的主标题及必要短辅助文字，逐字保留大小写、标点及必要断行；商品名等仅在属于必要短辅助文字且不要求独立编辑时入图，没有的信息不为凑层级添加。价格、日期、条件、参数、规格、正文、来源与概念说明不进入 DIT Prompt，保留在 Brief 中由 HTML 原生排字。Brief 只有文案大意时，先返回 Spec 在同一 Brief 补齐准确文案及图内／原生归属，再写 Prompt。
- **信息层级**：每项获准入图文字标明主标题或必要短辅助文字的角色，说明阅读先后和相对大小，并在 Brief 中与原生信息层级衔接，不让所有文字同等突出。
- **字体特征与风格**：每项写清衬线／无衬线／手写等字形类型、笔画与字面特征，以及几何、圆润、书卷、复古、实验等具体气质；不能只写“高级字体”或只给字体名称。
- **字色与字重**：每项指定颜色名称与必要色值，以及细体、常规、中等、粗体等字重；可附数值作为视觉参照，不将生图字形宣称为准确调用了某个字体文件。
- **特效**：每项明确描边、投影、压印、金属、渐变、发光等是否使用及具体强度；不需要时写“无特效”，不能由模型为所有字添加立体或发光效果。
- **位置与关系**：每项获准入图文字写明位置、对齐、行数、字号或相对尺度、行距及与商品的避让关系；画面为原生信息保留真实净空。必要说明由 HTML 原生文字呈现；统一概念说明与局部条件按事实边界分别安排，不重复铺设。

多项文字样式相同时可先定义公共样式，再逐项明确引用与差异，但准确文案不能合并成“其余同 Brief”。参考图只提供已指定的视觉关系，上屏文案以本次逐项清单为准；不复制参考中的无关口号、价格或品牌。

### 正式电商 Hero 已选择一体化 DIT 模式专用 Prompt 示例（非默认模式，非候选视觉 KV）

以下仅示范 Brief 或用户已明确选择正式电商 Hero 一体化 DIT 且不与文字独立可编辑要求冲突的情况，不是候选视觉 KV 示例。假设 Spec 已确定仅有三组获准入图文案：“随行杯”“把日常装进随行”和“随手一握，轻松出发”，图1为已提供的商品图；示例不代表可擅自为实际商品新增文案或事实。真实任务的价格、日期、条件、参数、正文、来源与概念说明须在 Brief 中逐项写全并由 HTML 原生文字承担，不加入此 DIT Prompt。

工具参数：比例 `5:9`；图1为实际商品参考输入。

> 现代编辑风格的竖版商品 Hero，商品、背景、装饰与以下三组文字共同生成在同一张成图中。以图1为商品身份来源，保持杯子的颜色、比例、结构、Logo 与包装细节，杯子完整位于中下部偏右；背景为浅灰纸面，少量青绿色几何色面形成层次，柔和漫射光呈现杯体材质。左上至中上部组织文字，与杯体轮廓保持间隔。
>
> 第一组准确写“随行杯”，作为商品名与第二信息层级，位于左上方。使用简洁几何无衬线字形，笔画均匀、字面舒展，现代克制风格；字色深灰 #303634，中等字重约 500，字号约为主标题的三分之一，单行左对齐，无特效。
>
> 第二组准确写“把日常装进随行”，作为主标题与第一信息层级，位于商品名下方，分两行：“把日常”与“装进随行”。使用宽字面、略圆转角的无衬线粗体，亲切有力的现代风格；字色深绿 #174C3C，字重约 800，两行同字号、左对齐，紧凑但不挤压的行距。添加极轻的同色系浅投影，不描边、不发光，整体占据左上至中上区域，不遮挡杯体。
>
> 第三组准确写“随手一握，轻松出发”，作为辅助说明与第三信息层级，位于主标题下方。使用笔画清晰、常规宽度的人文无衬线字形，轻松自然风格；字色深灰 #454B48，常规字重约 400，字号约为主标题的四分之一，单行左对齐，无特效。仅呈现以上指定的三组文案，不增写口号、价格或功效。

所选一体化 DIT Hero 的图内文字出现漏字、错字或包装身份变化时，按用户后续要求编辑整图或重生成；不使用 HTML 覆字掩盖图内文字。两种模式的原生文案错误均在 HTML 中修正，商品原有包装文字与 Logo 始终按身份源核验。

## 决定屏间视觉节奏

屏间节奏服从同一 Brief 联合完善后的说服链，不因换背景新增内容屏。逐对按以下顺序判断：

1. **内容交接**：写清上屏交出什么、本屏如何接住；语义接力不证明空间连续。
2. **叙事关系**：连续场景须有同一母图、连续裁切或可验证的共享背景生产单元依据，优先延展同一母图、连续裁切或重组为同屏；同章推进使用有内容职责的结构化分隔；章节、地点、时段或证据类型发生切换时使用切屏。切屏不是纯图默认，关系由说服链决定。
3. **载体边界**：两张独立完整主图不得以 Alpha、渐变或混合模式直接融合；纯色、纹理和图片背景层确需连续时，才把端点、保色、材质与保护要求交给公共 HTML 过渡路由，已有连续光场不重复加效果。
4. **接缝记录**：只在后一屏记录一次关系、承载对象、上段收束、本屏入口与选择理由；结构化分隔须承担标题、留白、品牌识别或阅读换挡职责，不为制造过渡额外增加空屏。

## 视觉效果生产与验收规范

- **视觉效果生产规范**：在同一 Brief 写明整页与逐屏的风格、视觉命题、商品主场、图文关系、字体角色、颜色职责、连续底图、容器／开放排版、素材生产意图、跨屏接力和必要降级；正式电商 Hero 默认采用不新增上屏文字的完整商品／环境主图＋独立原生标题与文案，仅 Brief 或用户明确选择且不与文字独立可编辑要求冲突时采用一体化 DIT。必须明确所选模式与逐屏文字归属；一体化仅含商品、环境、主标题及必要短辅助文字，价格、日期、条件、参数和正文仍原生排字，原包装文字与 Logo 始终保留。
- **视觉效果验收规范**：先看完整长图缩略图，再按正常阅读尺度核对正文。满幅场景须实际覆盖计划范围，原生文字与图形须参与同一画面；不能只让 Hero 满幅、后续体验段一律退成“标题＋图窗＋说明”。连续图窗有同条件比较、证据或参考依据时可以保留；否则返回图文关系重排，不以换框形或加纹理代替。素材净空、比例或模板槽位不适配时调整取景、素材或排版并遵守既有变更权限，不静默缩小场景；不设满幅占比或数量门槛。对照真实渲染检查 Hero 主体与准确文字、由商品与购买信息确定的视觉高点、商品身份、逐屏证据形态、主辅图尺度、文字可读性、背景实际覆盖范围及交界连续性（不能只核对色系一致）、容器职责、段间节奏、素材用途和载体适配。不得用模板命中、字段齐全、图片存在或单一首屏效果代替整页通过；将概念设定冒充已核实事实、图内错字、身份漂移和未兑现主场均须明确标为未通过。
