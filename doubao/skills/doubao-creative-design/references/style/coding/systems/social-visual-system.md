# 社媒长图与套图视觉表现规划

本文件将 [长图 Spec](../scenarios/social-long-image-spec.md) 或 [套图 Spec](../scenarios/social-carousel-spec.md) 已保存的内容结构 Brief，补充为包含决策优先级、视觉命题、风格、艺术手法、配色、背景、图文组合、逐屏／逐页排版与素材生产意图的完整 Brief。Spec 决定说什么、顺序、数量与配图职责；Visual 把这些内容转成具体画面，不改写事实或另造内容链。正式 Prompt 在冻结 Brief 后编译到素材清单。

本文件只消费已锁定的 coding／编辑父路线，不重新裁定制作方式。社媒套图默认 pure-image，使用现有 pure-image 平台 Ref 与 pure-image-sequence，不读取本文件或 Coding 套图 Spec；用户要求可编辑设计或文字时才进入 AI + Coding，封面与内页均以图片素材＋HTML 原生文字制作。指定可编辑区域必须原生排字，封面不例外；局部编辑的非目标区域可沿既有艺术标题准入规则，真实照片内标签无需重画。长图默认 AI + Coding。用户明确要求长图全部由图像模型生成且不要 HTML 排版时，由主入口锁定 pure-image，执行纯图长页与拼接流程，不进入本文件的 HTML 生产要求。电商详情页、三折页和简历分别读取各自的 `ecommerce-visual-system.md`、`tri-fold-visual-system.md`、`resume-visual-system.md`。

## 底图与 Prompt 强制规则

承担可见背景职责的全局底面、连续内容组背景或独立页背景，应包含与主题和已选视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满画布。文字安全区可以降低纹理频率、对比和密度，或使用局部纯色承托；没有可见范围、连续职责或露底需求时，不强制生成额外底图。

每次为全局底面、连续内容组或局部背景编写图片 Prompt 前，必须先读取并遵循 [背景图 Prompt](../ai-coding/asset-prompt-guide.md#5-背景图-prompt)，按其中的背景职责、纹理选择模型和完整 Prompt 编译语法描述材质、色场、变化方向、尺度、低纹理区与连续关系。该路由适用于新生成和编辑既有背景；直接复用真实背景时不强造 Prompt，但必须记录使用方式并检查本节结果门禁。

## 读取入口

先按主 `SKILL.md` 在当前画布项目查找当前主题的设计 Brief，读取“内容结构 Brief”，核对叙事节奏、信息链、屏数／页数及各条目的功能、尺寸、配图、文案与参考短链。缺少 Brief 或内容不完整时回到对应 Spec，在原位置补齐后再继续；不只凭对话记忆猜内容，也不另建视觉 Brief。

长图按屏追加视觉，可编辑套图按页追加视觉。套图执行 [首页与内页生产](../scenarios/social-carousel-spec.md#首页与内页生产)：封面与内页均按正常素材生产和 HTML 原生文字组装，封面职责见 [可编辑封面职责](../scenarios/social-carousel-spec.md#可编辑封面职责)，不设完整终图例外。直接把字体、配色、材质、布局与继承关系展开为自然语言效果，不从首页采样参数，不建立系列机器合同或资产矩阵，也不将其转移到 HTML。既有源编辑保留完整 HTML，只调整授权范围。

## 容器与开放排版视觉决策

Visual 阶段必须在原 Brief 每一屏／页的对应条目中输出“容器与开放排版视觉决策”，覆盖首页、内页与尾页；先判断是否需要边界，再按 [容器视觉语法](../composition-layout.md#容器视觉语法开放排版优先语义容器按需) 选择有内容语义的容器家族，不能只写全局风格或留到 HTML 阶段决定。

- 逐个说明容器名称、承载内容、位置与主次；同屏多个容器分别描述，共用效果可明确引用，但须写本屏差异。
- 写清轮廓与圆角／切角、表面材质、填充配色及纹理／渐变、边框与边缘、阴影与厚度、透明度／模糊，以及内部留白、图文排列、与底图和主体的遮挡关系。未使用的效果明确写“无”，不默认全部叠加。
- 只写可见效果的自然语言，不输出 CSS 参数、色值表或槽位契约；来源 ID 仅写入短采用记录。能由 CSS／SVG 可靠表达的规则容器、轮廓和表面交给原生实现，不因“纸壳、设备、手工边缘”等名称强制生图；只有所需复杂材质、真实成像或壳体细节不能可靠表达时，才按 [素材使用规范](../ai-coding/asset-prompt-guide.md) 准备对应图片。长图一体化 Hero 内的容器效果进入该单元的整图 Prompt；可编辑套图封面与内页均按正常素材与原生图层分工，不以完整终图绕过指定文字的可编辑要求。
- 无需容器时明确写“开放排版、无容器”，并说明如何用对齐、段距或分隔线组织信息；不能为填字段强加卡片或卡片嵌套，已有容器准入与系列关系仍须遵守。
- 普通白色圆角矩形只用于中性功能分组，不能铺满整页。需要视觉承托时优先通过文件夹／口袋、卷纸／档案页、撕纸／涂刷边、切角牌、票券、相框／衬纸等语义轮廓，加背页、页签、袋口、卷边、折痕、胶带或夹具，并用一致材质与接触阴影形成平面拟物。
- 将本屏效果写入视觉验收重点，检查实际边缘、材质、对比、文字容量与遮挡；不得仅凭“毛玻璃卡片”“高级容器”等名称判为完成。

### 品类常用容器表

下表覆盖社媒长图与套图的高频容器候选；先由内容关系和已选风格决定。同一套图可共享容器家族，但相邻页需按职责改变主次、尺度或数量。

| 常用容器类型 | 常见用途 | 视觉选择与边界 |
|---|---|---|
| 中性圆角容器（非默认） | 结论、步骤、清单、比较与事实摘要 | 只适用于稳定功能分组，不把每段正文做成同尺寸白卡 |
| 文件夹轮廓 | 岗位、档案、分类、资料与专题索引 | 页签对应真实栏目，无分类语义时不用文件夹 |
| 不规则撕纸边 | 拼贴标题、关键数字与短观点 | 只包短内容，系列内控制数量和角度，不能满页碎纸 |
| 票券与缺口 | 场次、路线、票据与活动栏目 | 承担真实信息职责，不生成无意义编号或凭证 |
| 照片衬纸与胶带 | 人物、生活、证据与产品照片 | 纸边和投影方向统一，证据图保持平直可读 |
| 侧尾对话框 | 对话、提示、角色发言与问题 | 尾部指向明确主体，不把普通说明都做成气泡 |
| 圆角磨砂玻璃 | 科技、光感、数字界面中的必要信息面 | 只局部使用并依赖合适后景，不能全套统一透明白卡 |
| 拱顶章节面板 | 章节开场、传统／人文主题与主题门户 | 用于章节转换，不逐屏重复同一拱顶造成模板化 |

### 已有布局 CSS 能力表

下表完整覆盖当前模板库已有的布局能力。Visual 根据内容职责选择，不按顺序轮用，也不要求每屏使用一种；写回视觉字段时使用表内能力名称和实际图文关系，不夹带实现标识或参数。选中候选的 ID、源路径与版本仅写入短采用记录。

| 布局能力 | 适用关系 | 写入 Brief 的边界 |
|---|---|---|
| 紧凑内容 | 同组事实、短字段、密集但可扫描的信息 | 写明压缩的是留白与组距，不缩小到不可读，也不把无关内容塞进同框 |
| 宽松内容 | 单一主张、少量重点、需要呼吸感的组件 | 写明留白服务的焦点与阅读停顿，不用空白凑画布高度 |
| 规整对齐（方格／网格排版） | 参数、证据、规格、并列比较和稳定栏目 | 写明列组、共同基线与主次；方格只组织可比较内容，不自动生成卡片墙 |
| 疏朗留白 | 长文、说明、编辑阅读栏与安静叙事 | 写明行宽、文字轴、图片归属与段间节奏，不等于所有内容缩成窄列 |
| 错落平衡 | 短标题接力、偏轴构图、左右不等权信息 | 写明错位对象、方向和共同对齐依据，不随机散放正文 |
| 聚焦主场 | 商品、人物、作品或场景作为第一视觉焦点 | 写明主体尺度、取景、文字静区和图文前后关系，不把主图缩成卡片配图 |
| 连续流动（串页／长页排版） | 长图章节、连续叙事、上下屏衔接和系列阅读 | 写明上一段出口、下一段入口、共享背景或接力对象，不只写“向下阅读” |
| 叠层拼贴 | 多张照片、纸片、证据或装饰需要错位叠压 | 写明主片、副片、角度、遮挡与保护区，不用随机旋转制造丰富 |
| S 形导览线 | 流程、路线、时间或概念节点需要曲线推进 | 写明真实节点、起止点和绕行保护区；没有关系节点时不用装饰曲线 |
| 横向卡片列 | 同类短条目、阶段、步骤或可横向扫描的内容组 | 写明条目共同尺度与差异；长正文、价格条件或复杂证据不挤入窄卡 |
| 章节眉线 | 章节编号、标题、短导语与换章提示 | 写明眉线承担的层级与接续对象，不把分隔线当主视觉 |
| 带引导线的图像标注 | 产品部件、成分、结构、地图或证据图解释 | 写明标注对象、端点和文字归属；引导线必须指向真实细节且不交叉遮挡 |

同一屏可组合兼容能力，例如“聚焦主场＋带引导线的图像标注”或“连续流动＋章节眉线”；组合后仍须形成一个明确主关系。没有适用能力时保留自定义关系并描述可见结果，不为命中模板改写内容。

### CSS 原子能力校验

完成内容骨架与可调整的视觉方向草案后、最终 Brief 冻结前，先按 [组合参考筛选](../../../../assets/templates/css/README.md#brief-combination-match) 比较同品类、同作用范围组合的整体层级、图文关系与视觉语言，沿约 70% 的适配原则判断；摘要不足先补读设计正文。用户锁定项与事实不变，模型自选的栏数、容器和照片位置可随比较调整。组合未覆盖或需替换的局部，再拆成下列自然语言能力词执行限量原子查询；确无适用组合才转原子组装或自主实现。这里选中 ID、源路径与版本进入 Brief 短采用记录，不复制代码或参数，也不因库中存在效果新增无职责装饰。

| 决策维度 | 交给查询的自然语言能力词 | Brief 保留内容 |
|---|---|---|
| 布局 | 阅读轴、主图关系、网格、错位、叠层、连续流动等实际关系 | 本屏图文主次、阅读路径与开放／分组方式 |
| 字形 | 填字、描边、发光、浮雕、路径排字等可见效果及文字角色 | 哪组文字采用何种效果、作用和可读边界 |
| 形状 | 当前选定的容器、图窗、票券、纸边、徽章或其他轮廓 | 轮廓服务的真实内容与本屏差异 |
| 表面 | 纸张、玻璃、塑料、织物、金属、柔焦等材质及承载对象 | 材质落在背景、卡片、图片还是文字，正文如何保持清晰 |
| 配色与背景 | 色彩职责、渐变／弥散方向、纹理类型及覆盖范围 | 可见色彩关系、背景变化、静区和保护范围 |
| 作用对象与边界 | 字体、卡片、背景、局部装饰；需要素材承担的复杂部分 | HTML 与图片的分工、必要降级及验收重点 |

候选摘要证明确实可实现后，把最终可见结果写回原 Brief；没有适用候选时保留已选方向，说明由素材或原生实现承担。真实引用、依赖、参数和消费者只进入后续 最终 HTML。

### 套图共同效果的自然语言写法

整体字段写共同效果，逐页条目写本页变化。例如：

> 整套采用明快纸本拼贴风，深蓝用于主标题与细线，珊瑚色突出动作，暖白纸面承托正文。标题宽厚紧凑，正文笔画清楚；主体有手工剪边和轻接触阴影。首页用大主体与标题形成主组，步骤页沿斜向路径展开，证据页改成一大两小的照片关系。内页都保留同样的标题气质、剪边与纸面，通过主体位置、尺度和信息密度变化。

这段直接指导图片与 Coding，不翻译为品牌参数、角色矩阵或系列 DNA。参考图有真实短链时记录其用途；生成后的首页仅用来核对这些效果是否成立，差异写成观察与必要调整，不假称规划值是实测值。

## 选择风格方向与具体风格

### 从用户的话进入

1. **先锁明确依据**：用户指定的品牌规范、参考及继承范围优先。区分参考整体风格、布局，还是只借某个卡片、颜色或质感；身份图和证据图不自动成为风格参考。
2. **拆开需求维度**：整体媒介／风格、期望感受、字体、形状、表面、颜色及明确排除项。只提“科技”“高级”“年轻”时，结合受众、阅读目的和真实素材补全；不直接映射为企业蓝、黑金或萌系插画。
3. **选择整体或局部入口**：整体描述明确时查下表的 17 类入口；第 10 节组合作为按需展开的关系示例；只提局部效果时直接查第 9 节与对应 C／I，保留当前整体方向。一个毛玻璃文件夹不要求整页改成 3D 科技展台。
4. **匹配后再展开**：先读本节 17 类索引，只展开命中类别、分支差异及实际需要的成像机制或 CSS 原子。清楚的要求直接采用；有实质歧义时比较少量不同机制的候选，按用户需求、素材可得性和可读性取舍，不机械生成两个方向。
5. **把选择变成可见关系**：说明要保留的识别特征及落点，再与 Spec 的内容关系一起确定构图。标签和编号不是结果，不先冻结布局再硬套风格。

以下 17 类是用户需求入口，可跨行业使用；内容用途只作辅助召回。明确参考和用户指定优先，其次看媒介、期望感受与素材，行业名称不能直接决定风格。类别可以组合，选定主要识别与有职责的辅助机制，不要求风格占比。

#### 材质肌理风

**何时选**：用户要求整张作品像由某种材料或工艺制作，材质参与标题、主体、信息面和章节组织时进入本类。仅要求局部纸纹、毛玻璃卡片或金属边缘时直接读第 9 节原子，保留整体风格。可与新中式、杂志编辑等组合，确定主要材质语言，不堆满所有工艺。

| 分支与选择线索 | 标题、配图与容器如何共同成像 | 色彩与跨段关系 |
|---|---|---|
| 纸墨版画：纸本、刻印、古雅、复古肌理 | 标题取粗印或刻痕，插画用刀刻轮廓、有限色面与墨边；纸页、帆面、拱门等有主题依据时可承载内容 | 按主题选纸白、灰蓝、橄榄等底与有限套色，不默认泛黄；以纸面、墨色或主题载体接力 |
| 颗粒印刷：清透颗粒、彩色印刷、轻肌理 | 标题与色面保持鲜明，背景细颗粒、信息面较轻；真实照片保持自身细节，不能统一撒点 | 青绿与青柠等清亮搭配或其他主题套色均可；沿色域和纸面延续，允许清楚分区，不必怀旧 |
| 织物纤维：布面、刺绣、编织、毛毡 | 编织方向、缝线与边缘厚度共同建立材料感；短标题可有织绣特征，正文清楚；布标／口袋仅在分组语义成立时用 | 染色与纱线色呼应；接缝、织带或布面方向连接章节，避免真实织纹被规则网格冒充 |
| 陶土手作：黏土、软雕塑、手捏、哑光 | 主体有厚度、指压与接触关系；字形或少量容器可共享圆润边缘，正文不立体化 | 使用相容或对比的材料色，局部阴影表现接触；物件动作与轮廓接力，不每段添加漂浮气球 |
| 金属压印：拉丝、压纹、蚀刻、珐琅 | 材料反射与凹凸对应真实结构；展示字、标牌或主体局部使用，信息阅读面控制反光 | 银灰、铜色或主题涂层均可；反射方向与压纹语言连续，不自动黑金、镜面或满页炫光 |
| 透明薄膜：半透明塑料、磨砂、叠色、膜感 | 透底、边缘厚度、叠色和折射分工；标题保持清晰，容器只在需要时采用透明材料 | 背景色域支撑透叠，跨段延续色场或膜边；不把正文一起降低透明度，也不默认可见光柱 |

**按对象分配材质**：背景决定基底与观看尺度，标题和插画决定墨迹／笔触，容器通过边缘与表面承接；共享材料语言不等于叠同一张纹理。正文、真实证据与照片保护可读性和原貌，局部光滑或无纹理也可成立。纹理既不只留在背景，也不平均覆盖全画面。

**实现路由**：纸墨先读 [复古印刷机制](#v13复古商业印刷)／[刻印插画](#v36纸本刻印插画)，局部纸面与颗粒读 [纸张印刷](../../../../assets/templates/css/surfaces/paper-and-print.md)；规则点阵不能代替主体半色调。织物读 [织物手作](../../../../assets/templates/css/surfaces/textile-and-craft.md)，金属局部近似读 [浮雕与反光](../../../../assets/templates/css/surfaces/metal-and-relief.md)，透明材料读 [材质共用层](../../../../assets/templates/css/surfaces/materials.md#surfaces.parameters)及所选塑料／玻璃覆盖。库内近似不等于真实纤维、复杂压印或曲面折射；陶土与未覆盖的具体成像沿 [素材 Prompt](../ai-coding/asset-prompt-guide.md) 使用图像，不虚构 CSS 配方。参数只在库内维护，HTML 绑定本次选值。

Brief 写材料气质、图文权重、各对象如何共享或区别，以及章节怎么接；不复述整张分支表。验收看实际字面、主体、容器与背景是否共同形成所选关系，不能仅凭“有颗粒”判为材质风。

### 整体配方与局部效果可以组合

例如“清爽科技招聘，青绿弥散、透明文件夹卡片，不要企业宣传味”：Spec 仍规划团队样貌、岗位与投递；Visual 可采用 V5.2 的轻透空间，叠加青绿自定义配色、弥散底和局部毛玻璃文件夹。岗位同类项保持稳定排布，团队图片展示真实工作内容。不能因“招聘”套 R09，也不能因“玻璃”强加芯片、金属台座或无关 3D 物件。

“把现有卡片改成毛玻璃”只调整表面及必要的背景层次；“做成商业波普”先选 S10 对应分支，再按需调用 V2.7 + C14 + I17，连同字物关系、纸边与投影一起适配。用户指定青绿色时保留颜色职责，自定义 C 不必硬改成 C13 的默认色组。

## 决定艺术表现手法

以已选风格为主线，写清背景、主体和辅助元素分别如何处理，以及由此形成什么可见调性。可以通过镜头、尺度反差、剪形、纸层、笔触、印刷、材质或光影表达内容，但不只写“高级、年轻、有冲击力”。

长图说明首屏如何建立视觉语言、展开段如何变奏、密集区如何保持清晰；套图说明首页与内页共享哪些可见特征及本页怎样变化。下列机制按需读，不要求把每个参数、风格编号或候选菜单抄进 Brief。

### V｜整体视觉机制

V1–V5 是底层成像与排版机制库，不承担用户风格分类。按风格选择节选中类别后查询所需机制，明确谁承担主要识别、谁承担辅助作用。套图同时执行后文一致性与差异性硬门禁；70% 是系列视觉统一要求，不是要求把风格标签或像素面积伪装成测量结果。

各风格分支的比例与数量是试排起点，按实际文案、参考、素材和目标显示尺度调整；套图后文单独列出的统一、相邻页变化、布局轮换与主辅容器配额仍是硬门禁，二者须同时满足。T/C/L/I/A 推荐与 R 组合用于快速展开，不限制自定义搭配。

### V1｜编辑排版家族

- **家族签名**：字体、网格、栏线、留白和编辑家具构成主要识别，影像服从版式而非独立成景。

#### V1.1｜现代几何编辑

- **视觉签名**：单轴/不对称网格、超大无衬线词组与 `2–4` 个几何对象受控穿插。 占宽 `65%–95%` 的标题或概念字，事实说明回到稳定轴线。
- **背景与空间**：带受控渐变或低对比纹理的主色基底、规则网格或大色块分区；保留 `18%–32%` 低信息区。
- **影像与素材**：影像可无；若有，只用一个剪影、符号或局部主体，不形成完整摄影场景。
- **字体与图形**：T01/T03；800–900 展示字与 400–550 正文；圆、矩形、箭头不超过三类。
- **色彩与材质**：C03/C05；一个高明度点色，不叠加纸纹、玻璃和霓虹三套材质。
- **推荐系统**：L03/L04；I05/none；A01/A02。
- **排除/退化**：居中标题加均匀圆点、孟菲斯散点或普通卡片墙。

#### V1.2｜高端衬线编辑

- **视觉签名**：克制衬线展示字、细线、页缘家具、有任务的留白与少量高质量影像。 标题与留白的尺度关系；主体通常占 `35%–65%`，不靠装饰制造高级感。
- **背景与空间**：象牙白、暖灰、深棕或单一低饱和底；留白 `20%–40%`。
- **影像与素材**：单品、人物或建筑图像最多一主两辅，裁切主动且共享同一光向。
- **字体与图形**：T02；衬线负责标题，Sans 负责日期、价格和说明；只用细线和少量括号/页码家具。
- **色彩与材质**：C04/C05；哑光纸、轻颗粒或无材质，强调色面积低于 `12%`。
- **推荐系统**：L01/L03/L06；I01/I02；A01。
- **排除/退化**：把高级感等同于小产品居中、金色描边、平均留白或装饰衬线全文。

#### V1.3｜复古商业印刷

- **视觉签名**：有限色版、图文尺度反差与油墨边缘形成平面印刷感；暖纸与焦糖是可选配方，不是准入条件。 粗字、主体或色版之间存在明确裁切、遮挡或叠印关系；仅有纸纹背景不成立。
- **背景与空间**：纸白、暖纸或主印色底；信息区根据墨色对比留出阅读位置。蓝橙、红蓝、黑白及其他有限套色均可，不按食品题材强制黄褐化。
- **成像选择**：半色调以网点疏密或点径表达主体明暗；丝印感以有限色面、墨边与局部覆盖不匀表达；Riso 以有限色版、叠色、缺墨和轻错版共同表达。选择与参考一致的一种主工艺，不能用均匀噪点替代全部工艺。
- **影像与素材**：主体轮廓、身份和明暗结构可辨；既有人物／品牌素材只在获准范围内转译，纪实证据保留原貌。网点尺度、墨色、叠印位置和边缘在目标显示尺寸下确定。
- **字体与表面**：T01/T02/T03/T05 或明确的 custom；事实文字干净可读。方正色面、纸页包裹或无卡片均可，具体关系按第 9 节选择，不默认票券和撕边。
- **推荐系统**：C02/C11；L02/L03/L07/L13；I02/I06/I11/I14；A01/A05 或 none。
- **排除/退化**：整图黄化、人物上均匀铺点、每处都做脏污，或只有背景有肌理而主体／信息面失去同源关系。

#### V1.4｜证据与信息编辑

- **视觉签名**：结论、证据数字、规则网格和对象舞台构成可扫描的论证关系。 一个结论与 `2–3` 组真实证据同屏邻接，科研符号只做从属家具。
- **背景与空间**：冷白、银蓝或单一深色轴，证据区保持低纹理高对比。
- **影像与素材**：产品、结构图、局部放大或真实图表；不生成伪数据和伪实验装置。
- **字体与图形**：T01/T06；数字 700–900，正文 400–500；网格、标尺和连接线有对应关系。
- **色彩与材质**：C05；允许单一玻璃/金属实验材质作 `10%–25%` 次级修饰。
- **推荐系统**：L04/L07/L08；I05；A01。
- **排除/退化**：随机分子式、过量光环、无证据的医疗权威暗示或数字装饰化。

#### V1.5｜电影票券编辑

- **视觉签名**：暗场、宽银幕裁切、票券/场次/价目模块、窄体标题与胶片家具构成叙事节奏。 电影式标题或票券结构，而非单张夜景照片；信息沿场次、章节或菜单顺序推进。
- **背景与空间**：黑、深棕、暗紫或橙红光场，允许硬切章节带和局部颗粒。
- **影像与素材**：剧照、舞台、胶片帧、门票和价签；每个票券承担真实栏目，不填无意义编号。
- **字体与图形**：T03/T07；压缩 Sans、Mono 编号与稳定正文三档并置。
- **色彩与材质**：C03/C08；暗底加一组暖光，颗粒、划痕和发光最多选两种。
- **推荐系统**：L02/L04/L10；I01/I07；A01/A02。
- **排除/退化**：有黑底橙字就判电影风，或票券只做装饰、不承载场次/价格/章节。

### V2｜拼贴家族

- **家族签名**：纸层、照片、切片、标签或数字界面形成可见层级，阅读顺序由重叠、轴线、路径和编号建立。

#### V2.1｜档案索引拼贴

- **视觉签名**：索引、编号、地图/资料切片和微型元数据沿路径或轴线形成资料页秩序。 资料层分别承担栏目、索引、注释或叙事责任，形成明确主次。
- **背景与空间**：扫描纸、地图底、资料板或低对比纸面，保留连续阅读轴。
- **影像与素材**：按题材选择照片、地图、票据、资料卡和当代生活素材；档案编辑语言是一种视觉表达方式。
- **字体与图形**：T05；Serif/Mono/Sans 分责；编号、图钉、邮戳和路径必须可解释。
- **色彩与材质**：C01；低饱和纸轴加一个索引色，仿旧不超过两种工艺。
- **推荐系统**：L04/L09；I06；A04/A05。
- **排除/退化**：随机票据、无意义英文、平均散落；事实素材被当真实凭证时另行核验来源。

#### V2.2｜票据邮票拼贴

- **视觉签名**：一个主纸面与 `2–5` 个票据、邮票、标签或照片切片受控碰撞。 主纸面占 `45%–70%`，标题、事实和票据家具形成三档视觉重量。
- **背景与空间**：旧纸、牛皮纸、信封或低对比桌面；保留 `15%–30%` 安静留白。
- **影像与素材**：票据、邮票、标签、旅行照片和包装切片按题材选择，每项承担日期/地点/栏目/引导。
- **字体与图形**：T07；粗细、字类、`-8°–8°` 旋转和裁切制造乱中有序。
- **色彩与材质**：C08；一个中性纸轴与一个点色，统一磨损、阴影方向和印刷颗粒。
- **推荐系统**：L10；I07；A03/A04/A05。
- **排除/退化**：十余个小物平均散落、伪造可扫描条码/真实凭证，或票据不承担信息责任。

#### V2.3｜相册摄影拼贴

- **视觉签名**：真实照片是主要叙事材料，拍立得、相册框、文件夹和短说明组织先后关系。 照片合计占 `45%–70%`，可采用主图＋辅图或同级记录，数量按内容确定。
- **背景与空间**：草地柔光、季节场景、桌面或低纹理纸面，预留标题和相框负空间。
- **影像与素材**：人物、门店、旅行、活动或产品照片共享曝光、白平衡与颗粒。
- **字体与图形**：T08；标题柔和，地点/日期紧邻对应照片；相框、回形针和贴纸只负责组织。
- **色彩与材质**：C09；统一季节色温，纸框与接触阴影方向一致。
- **推荐系统**：L11；I08；A01/A03。
- **排除/退化**：无主次九宫格、不同季节色温混用，或生成事件冒充真实记录。

#### V2.4｜生活手账信息拼贴

- **视觉签名**：笔记本/信息主板承载主要内容，便签、日历、清单和少量生活物件形成可扫描高密秩序。 主板占 `55%–78%`，内容拆为 `3–5` 个有标题的信息组。
- **背景与空间**：奶白笔记纸、方格纸、软木板、浅木桌或摊开的本子。
- **影像与素材**：人物/产品主题物与 `2–3` 类生活小物，主题物跨主板边缘 `5%–15%`。
- **字体与图形**：T09；手写标题与稳定 Sans 正文分责；日历格、清单和便签共享纸张语言。
- **色彩与材质**：C10；暖纸底加 `1–2` 个清亮点色，避免厚重怀旧滤镜。
- **推荐系统**：L12；I09；A01/A03/A04。
- **排除/退化**：每句话一个便签、涂鸦填满留白，或手写字承担价格、日期和 CTA。

#### V2.5｜涂鸦剪贴拼贴

- **视觉签名**：手绘笔迹、剪纸块、贴纸轮廓和少量照片切片共同形成有方向的手作冲突。 剪贴层与涂鸦路径共同主导构图；若角色插画占主导则改选 V3.2。
- **背景与空间**：纯纸面或单色底，保留一条清晰阅读轴与 `18%–30%` 呼吸区。
- **影像与素材**：`1–3` 张照片/产品切片、`2–4` 个剪纸块和一组统一笔触；素材必须对应主题动作。
- **字体与图形**：T04/T09；准确事实用 Sans，涂鸦仅承担短标题、箭头与情绪注释。
- **色彩与材质**：C06/C10；主色不超过三组，剪纸边缘与笔刷粗细统一。
- **推荐系统**：L02/L09/L12；I04/I09；A03/A04。
- **排除/退化**：无任务涂鸦、十余张贴纸堆积，或角色已成第一锚点仍误判拼贴。

#### V2.6｜数字界面拼贴

- **视觉签名**：社媒帖子、屏幕、弹窗、照片流或 UI 框架作为可见媒介层，组织真实内容序列。 两个以上数字界面层发生缩放、叠压或流动关系，而不是普通卡片墙。
- **背景与空间**：品牌光场、深色舞台或连续渐变底；界面外保留统一环境光与阅读方向。
- **影像与素材**：内容帖、视频帧、手机/屏幕、头像和评论切片；准确平台文字用 CODING 重建。
- **字体与图形**：T01/T06；界面层共享圆角/硬边、描边和阴影规则，不混用多套平台皮肤。
- **色彩与材质**：C05/C07；品牌色为主，界面表面与背景至少有 `4.5:1` 文字对比。
- **推荐系统**：L04/L05/L09；I01/I05；A01。

##### V3.1 变体｜粗描边贴纸风插画

- **影像与素材**：产品、镜片、芯片、设备或抽象技术符号；同页只保留一组主材质。
- **字体与图形**：T06/T01；规格、证据和连接线对齐真实结构。
- **色彩与材质**：C05/C07；银、蓝、黑或品牌色，透明度与反射方向统一。
- **推荐系统**：L04/L07/L08；I05；A01/A02。
- **排除/退化**：随机玻璃球、伪芯片纹理、无依据数据和多材质 3D 堆叠。

#### V5.4｜等距场景与路线

- **视觉签名**：等距建筑、摊位、角色和一条连续路径构成可探索的信息世界。 路径连接 `3–7` 个场景节点，并承担章节/步骤/地点顺序。
- **背景与空间**：单色或低纹理地面，等距透视和投影角度全图一致。
- **影像与素材**：建筑、展台、人物、交通或产品节点共享比例和材质。
- **字体与图形**：T01/T06；节点编号与路径邻接，说明不漂浮到无关位置。
- **色彩与材质**：C06/C07；有限品牌色，避免所有节点同等高饱和。
- **推荐系统**：L05/L09；I05；A01。
- **排除/退化**：路径成为装饰、节点无先后关系，或场景比例与光向不一致。

#### V5.5｜超现实材质场

- **视觉签名**：单一超现实尺度、漂浮关系或陌生材质构成概念场景，主体仍保持主题识别。 一个不可能但可解释的材质/空间机制占 `35%–65%`。
- **背景与空间**：连续环境、明确主光和低纹理事实区；不做素材拼盘。
- **影像与素材**：巨物、液态、织物、软体、透明体或空间折叠只选一种主机制。
- **字体与图形**：T03/T01；标题与材质发生一次穿插，正文回到平面信息层。
- **色彩与材质**：C03/C05；主材质决定色温与高光，辅助材质不超过一种。
- **推荐系统**：L02/L03/L06；I03；A01/A02。
- **排除/退化**：无主题的奇观、多个生成物堆叠，或准确文字被烘焙进背景。

#### V5.6｜颗粒弥散色域

- **视觉签名**：多中心柔边色域与连续颗粒形成平面情绪空间；不依赖玻璃球、镜片、台座或科技卡片。 色域的尺度、明暗与标题／主体之间的留白关系；色团需有方向和聚散，不能随机散布。
- **成像选择**：柔边色团、连续流动色带或液态变形色域择一作为主机制；胶片柔焦摄影仍归 V4，以摄影后期描述，不误归抽象渐变。
- **字体与表面**：T01/T02/T03；清楚字形与柔边背景对照。优先开放信息场，需要分组时用有意的纸面、色面或窄带；不默认毛玻璃。
- **推荐系统**：C13；L01/L03/L04/L06；I16；A01/none。轻细衬线由真实字体 DOM 文字实现，不因使用弥散就必须生成粗艺术字。
- **适用与延续**：艺术专题、音乐、文化活动、情绪与生活方式内容；长图沿方向、色阶和颗粒尺度接力，信息段降低局部起伏，不退回无关白卡。
- **排除/退化**：普通蓝紫渐变、均匀模糊全图、噪点吞字、色域无构图职责或所有章节重复同一彩球。

### I｜影像与材质系统

图片中的主体、动作、环境、必要细节和证据职责来自内容 Spec；本节只规定怎样拍、怎样画、怎样处理材质。统一后期不意味着每段复用相同姿势或同一张图。

I01–I13 提供成像方向，I14–I17 补充具体材质参数。素材来源和主体内容沿 Spec，生产方式按第 9 节与 workflow 选择；Hero 一体化与其余章节分层的边界不因 I 配方改变。

| 编号 | 成像方向 | 需要保持的视觉关系 |
| --- | --- | --- |
| I01 满版真实摄影 | 明确景别、主光、色温与景深 | 真实负空间承担文字，不通过模糊全部照片掩盖拥挤 |
| I02 微距主体／透明单品 | 材质细节清楚，保留识别轮廓；透明资产可破框 | 近景与说明关联，抠图边缘、接地光影与背景一致 |
| I03 高能材质场 | 柔光域、液态膜或异空间网格等主机制 | 标题与材质有尺度或层叠关系，事实区安静 |
| I04 手绘角色与道具 | 统一比例、轮廓、笔触与有限色板 | 动作服务主题，图形与文字共享绘制气质而不损害可读性 |

| I12 像素游戏场景资产组 | 固定像素网格、有限色板、描边倍率与投影体系 | 场景／状态对应真实任务顺序；真实奖品仍能识别，文字保持清楚 |
| I13 主题展陈资产组 | 明确透视、环境光、接地阴影与主从对象尺度 | 展台服务主题而非补空；扁平、3D 或实物陈列按需求选择，身份资产保真 |

### I14｜有限色版成像

- **输入与范围**：指定主体／图形、源资产及允许风格化的区域；区分主体转网点、色版叠印和仅在背景施加纸纹。
- **执行参数**：记录目标显示尺寸下网点间距／点径范围、方向、明暗映射、主印色；丝印或 Riso 另写墨边、缺墨区域、错位方向／幅度和叠色结果。只启用所选工艺需要的参数。
- **生产**：复杂网点、油墨覆盖和叠色作为生成／编辑或预处理后的图片资产；独立图形检查 Alpha 与内部孔洞。规则色面可用 HTML 容器与行内 CSS，均匀点阵不代替主体半色调。
- **准出**：缩小后仍能识别主体与工艺；文字与身份细节不被破坏，网点无明显干扰纹。参数是生成目标，必须对实际资产复核，不能把 Prompt 当测量结果。

### I15｜纸本绘制与刻印素材

- **输入与范围**：选择粉彩绘制或纸本刻印，写明纸底、主体、信息壳体哪些共用画法；没有材质作用的事实层明确保持清楚。
- **执行参数**：粉彩记录粉末尺度／密度、色面露纸、柔边范围和明暗；刻印记录剪形、刮擦方向／尺度、形内缺墨和墨边。只保留一套与参考相符的主成像机制。
- **生产**：主体绘制及 CSS／SVG 无法可靠表达的复杂纸壳、手工边缘使用图片；可可靠表达的纸页轮廓、规则容器和表面保留原生实现，不按名称强制生图。矩形纸底可作为连续背景，需要独立叠压的图片纸壳按既有抠图流程准出。形内刮擦限制在对应对象内部，不能用跨全图白线覆盖。
- **准出**：最终尺寸下质感仍可见，Alpha 不误删粉末边缘或内部留白；正文、规则与来源有独立安全区，颗粒不只存在于底图。

### I16｜弥散与颗粒色域素材

- **输入与范围**：记录色域形态、流向、中心／范围、基底色、文字静区和章节出口；连续长图按实际生产单元继承色阶和颗粒尺度。
- **执行参数**：柔边范围、色标／主色关系、颗粒尺度／密度及局部对比；液态变形还写流向和变形范围，不把镜头柔焦与抽象色域混为一个效果。
- **实现**：HTML 可使用行内多重渐变、装饰层模糊和独立颗粒纹理；复杂液态变形或无法达到所选质感时使用图片。按第 9 节落实，不把 CSS 模糊施加到文字。
- **准出**：文字静区与实际 DOM 文字位置一致，色域形成构图，章节接缝无色阶与颗粒尺度突变；没有可用复杂素材时先说明缺口，不静默换成光滑渐变。

### I17｜波普贴纸与印刷物件

- **输入与参数**：绑定主题物件／参考局部，分别写对象颗粒的尺度、密度和对比，字面墨纹、纸边厚度、道具排线、阴影方向／偏移／模糊与遮挡顺序；并非每个对象都需全部效果。颗粒强度由参考与最终观看尺寸确定，不默认“极轻”。
- **生产**：一体化 Hero 内按已确定的文案分工联合生成字、物件和叠压；其他章节中可由 CSS／SVG 可靠表达的纸壳、纹理与阴影使用原生实现，只有复杂真实成像部分使用图片，准确内容用可编辑 DOM 文字。独立标题的外部投影按组装职责另行实现，不误套独立字图的禁投影规则到整个 Hero。
- **准出**：手机尺度下主组、纸边和材质差异仍可辨，细看颗粒不破坏文字；纹理跟随对应物件而非覆盖整图。长图接续同时继承实测色阶与纸墨尺度，只有底色一致不算材质连续。

## 决定配色

本节提供可执行起点，不替代品牌色或参考证据。规划 Brief 只写背景、表面、文字、主辅色和强调色分别承担什么，以及冷暖、明暗与跨页关系；不要求填写 HEX 或从首页提取色值。选定配方或有依据的自定义关系后，实现阶段在最终 HTML 中落实唯一 HEX、色标位置与混合参数。以下色值只作实现候选，不整表抄进 Brief，不从多个配方任意抽色而省略统一职责。

- **C10-A 明快生活页**：`背景 #F5E9D3` · `表面 #FFF8EA` · `文字色 #312820` · `主色 #35A8E0` · `辅色 #FFE36A` · `强调色 #EF6C56`。

- 纸张中性轴占 `60%–78%`，主色和辅色合计 `15%–28%`，强调色 `3%–7%`。适用于 V2.4/V2.5；同一信息组只用一种编码色，正文保持文字色。

### C11｜有限色版

- 先锁定纸色和实际参与的 1–3 个印色，再记录叠色区域与文字反色；叠色是这些色版的结果，不是额外随机配色。
- 起点示例：纸白 `#FFF9EC`、钴蓝 `#2863E8`、暖橙 `#F6B65B`；或纸白、朱红 `#EF493E`、深墨 `#252525`。只能选一套或形成完整 custom，面积由主体、信息面和留白决定。
- 适配 V1.3/V3.6；有限色版可用现代撞色，不自动等于焦糖复古。屏幕模拟色不声明为已核验的实体专色或印刷工艺。

### C12｜颜料撞色

- 由背景颜料色、主体色、局部明暗色和清楚文字色构成；同一主体允许有色相变化的粉彩明暗，不要求每个物体只有一个纯色。
- 高饱和起点：群青 `#3158F5`、朱红 `#F44E3D`、黄绿 `#CBE83F`、纸白 `#FFF6E5`；柔和起点可选暖白、珊瑚、淡紫和青绿，但只在最终 HTML 中落实全套 HEX，Brief 只写颜色职责。
- 适配 V3.5；颗粒露出的纸色与背景色区分记录，不把高饱和主色直接用作低对比正文。

### C13｜连续弥散色域

- 明确基底、2–4 个主要色域、每个色域的中心／范围与明暗职责，再确定文字色和文字所在的稳定对比区域。数量是选型起点，不为凑色添加无职责色团。
- 起点示例：暖白 `#F5EFDF`、洋红 `#ED4A9E`、紫 `#794DE1`、青绿 `#5DBFB9`，局部暖橙 `#F89C55` 仅在有聚焦需要时加入。
- 适配 V5.6；普通 linear/radial 写实际 stops，颗粒／变形／多重混合交给 I16。AI 成像的混色只能记录为资产特征，不声称是可精确复算的原生渐变。

### C14｜商业波普撞色

- 起点示例：高饱和蓝 `#245DF2` 承载主物件／主色面，朱红 `#F02D16` 承担巨字或焦点，亮黄 `#FFE600` 承担短标签；纸白 `#F7F6ED` 分隔，近黑 `#141414` 用于字与局部边界。这些是可改的设计起点，非参考图实测色。
- 按参考指定主色面、焦点色与信息强调色，面积服务主次；可依据主题少量加入绿等物件色，不把所有高饱和色平均分配。黑字配黄标签、红字配纸白边等关系须在最终尺寸检查，不机械套用亲和色板。

## 决定长图与套图背景

- 根据连续内容组和实际可见职责划分全局底面、组级背景与局部覆盖；屏或页不是自动生产边界。
- 从场景关系、光向与透视、主体尺度、文字安全区和色场／纹理判断相邻内容是否相容。相容时优先共享底面或延续同一基底，避免重复生产近似背景。
- 不相容时先判断局部图窗或覆盖层能否自然承接；无法合理承接，或叙事阶段、视觉命题和信息负荷确需换挡时，可以建立新背景，并记录覆盖范围、换挡依据与接缝。局部方案不是换底前的强制步骤。
- 不同内容组可以共享背景，同一内容组也可以按视觉兼容性使用多个背景生产单元；背景变化不得改变 Spec 已确定的内容顺序和职责。
- Visual 决定使用 CSS／SVG、图片或组合。规则色面与普通渐变优先原生实现，真实场景、复杂材质或成像细节使用图片；没有可见、露底或跨段连续职责的底面不生产。
- 参考背景附真实短链与借鉴范围，不默认复制其品牌、人物、口号或全部构图。具体表面和 CSS 能力沿下一节选择，不另建模板索引。

### 从内容关系选择可用方案

社媒长图在[内容骨架与视觉草案形成后、冻结前](../scenarios/social-long-image-spec.md#下一步路由)按内容、风格与参考主动选择容器、材质和字效，不等用户点名。先判断开放排字或独立承托，再选轮廓；不默认圆角卡，也不因避免卡片过量而排除有意义的文件夹。

容器用途见下表；内容产生候选，参考、可读性和整体风格决定采用，不要求逐段换形。用户指定容器须落实，冲突时说明处理，不静默改成方卡。

本表是入口，不是封闭清单。沿 [CSS 组合筛选](../../../../assets/templates/css/README.md#brief-combination-match)查询当前 catalog：先用 `describe ID...` 比较摘要，缺设计依据时用 `get ID --prose` 补读；选定后再读实现与依赖并在 HTML 绑定。候选不足时按内容关系＋轮廓／表面检索，核对产物、粒度、style_tags 与 candidate_contexts；通用原子参与，不全文读库。通知／邀请函整张布局不作社媒长图模板，局部借用须区分轮廓、材质与完整结构的适用范围。

L 提供局部视觉关系，不代替 Spec 的分组与顺序；章节骨架 IL 见上文。先满足内容关系，再借用偏轴、叠层、满版影像等表现；同一长图可混合兼容关系，不设布局种数配额。具体坐标、段高与安全区由 [布局规则](../composition-layout.md) 和 HTML 落实。

### L10｜编辑碰撞拼贴

- 一个主纸面占 `45%–70%`，`2–5` 个票据/照片/标签从边缘切入；只保留一个主阅读轴，允许 `-8°–8°` 旋转和 `8%–20%` 局部遮挡。
- 标题可跨越两个纸层，但事实文字必须完整落在单一高对比表面；右上、左下或页缘保留一个家具密集区，其余区域留白。

### L11｜相册照片叙事

- 照片区占 `45%–70%`，按内容采用主图＋辅图或同级记录；拍立得边框宽度统一，重叠不超过照片短边的 `15%`。
- 标题位于背景负空间或独立相册封面，地点/日期紧邻对应照片；CTA 与活动规则不得压在摄影细节上。

### L12｜手账信息主板

- 主板占 `55%–78%`，内部按单一左轴或轻微错落轴划分 `3–5` 个内容组；一个人物、产品或照片跨越主板边缘 `5%–15%` 成为第一锚点。
- 便签只用于关键结论、时间或福利，不把每个段落都装进卡片；底部保留连续 CTA/品牌收束区。

- **核心关系**：一个主题对象、角色群或产品组合占画面 `42%–72%`，落在明确底座、文件夹、橱窗、奖章墙或概念舞台中；标题与主体邻接或轻叠一次，事实说明集中在一处低纹理信息面。
- **适用载体**：单张海报的主视觉、长图首屏/章节高潮、套图首页/奖励页；适合角色议题、产品功能、奖项展示、主题活动和需要“一眼进入世界观”的内容。
- **推荐视觉分支**：V3.1 扁平角色插画、V5.3 玻璃金属科技、V5.5 超现实材质场；复古实物陈列可用 V1.3，第一锚点仍按实际媒介裁决。
- **生产方式**：用于社媒长图 Hero 时，按品类 Spec 将舞台、主体、主标题及适合入图小字联合构图为完整图片，图内已有文字、容器与物件不重复叠加；用户明确要求独立编辑的对应文字排除出图并预留位置。用于品类允许分层的其他区域时，舞台环境与跨层物件使用图片；只有该图唯一最重要主标题可按既有准入使用艺术字图片，其余文字使用经本文件字体流程选定并通过资源门禁的可编辑 DOM 文字。
- **排除/退化**：主体缩成角落贴纸，展台只剩普通圆角卡；同页混入互不相干的 3D、摄影和手绘材质；图内文案错误，或把用户明确要求独立编辑的内容烘焙进图；用本原子的分层示例覆盖品类 Hero 默认。

### L14｜地图路线叙事

- **核心关系**：地图、区域轮廓或连续路线占画面 `50%–78%`，连接 `3–7` 个地点、菜品、步骤或场景节点；每个节点只保留一个名称和一条关键信息，标题、路线与行动出口形成可追踪方向。
- **适用载体**：城市/美食海报、旅行或活动长图章节、攻略/导览套图页面；既可表达真实地理路线，也可表达被明确标注为概念关系的主题地图。
- **推荐视觉分支**：V2.1 档案索引拼贴、V3.3 编辑线描插画、V4.1 纪实场景摄影、V5.4 等距场景与路线。
- **生产拆分**：真实地图底图与照片使用有来源素材；概念地图背景可用图片；区域轮廓、路线、节点、编号和准确地名使用 DOM／CSS／内嵌 SVG，主题食物、建筑、人物或交通工具使用独立图片。
- **排除/退化**：路线只是无意义虚线，节点与路径没有先后或地理关系；地图被切成普通卡片墙；用生成画面伪装成精确地图、地址或导航依据。

### L15｜统一摄影场域

- **核心关系**：一张满版环境照或同一地点/时段的连续摄影占画面 `60%–100%`，文字进入天空、草地、墙面、夜色或独立纸面负空间；辅助照片、手写线条和信息岛只能强化同一场域。
- **适用载体**：目的地/品牌纪实海报、长图的连续情绪章节、旅行/公益/人物套图；需要真实性、季节、地点或生活氛围先于信息容器时优先。
- **推荐视觉分支**：V4.1 纪实场景摄影、V4.4 生活直闪摄影、V4.5 电影夜景摄影；照片序列成为多层相册时改选 V2.3。
- **生产方式**：真实人物、活动、地点和产品优先使用用户上传或有来源的照片，在授权范围内编辑并保持身份与场景证据；只在虚构概念场景中从零生成摄影。用于社媒长图 Hero 时，按品类 Spec 将同一摄影场域、主标题及适合入图小字联合生成或编辑为完整图片，不重复叠加图内文字；用户明确要求独立编辑的对应文字排除出图并预留位置。用于品类允许分层的其他区域时，只有该图唯一最重要主标题可按既有准入使用艺术字图片，其他标题、日期、路线、图注和 CTA 使用经本文件字体流程选定并通过资源门禁的可编辑 DOM 文字；不把整张长图压平。
- **排除/退化**：每页换地点、色温和镜头语言却声称统一；文字压住主焦点；照片退化为模糊背景，前景重新堆满无关卡片。

### L16｜任务关卡界面

- **核心关系**：一个可识别的任务世界、像素场景、记分牌或设备界面统领画面，`2–5` 个任务/规则/奖励节点依照关卡、路径或状态推进；界面外壳本身必须解释主题，而不是通用 UI 皮肤。
- **适用载体**：活动招募海报、互动机制长图章节、玩法/规则/奖励套图页面；适合体育、城市探索、数字文化、挑战赛和产品任务流程。
- **推荐视觉分支**：V2.6 数字界面拼贴、V5.4 等距场景与路线；信息论证比世界观更重要时可用 V1.4 作为主分支。
- **生产拆分**：场景、角色、机器、道具和奖品可使用图片；准确规则、比分、日期、金额、按钮文字、页签与状态使用 DOM／CSS／内嵌 SVG。像素风必须统一像素网格、描边倍率和投影方向。
- **排除/退化**：普通白卡加游戏图标；每个节点视觉等权且没有关卡顺序；生成不可读的伪按钮、伪规则或可被误认成真实平台截图的界面。

## 决定各屏与各页文字排版

### 单模块文字

短标题与说明上下组织、主结论独占一块区域、图注邻接对应细节，或短句沿阅读轴排列。先让读者读到结论，再看必要原因与条件；不靠大段装饰英文补版。

### 多模块文字

按内容选择同轴分组、主结论加并列要点、同口径双栏比较或连续步骤；同类单元共用字级和间距，重点来自真实信息。多组图注、来源与限制条件分别绑定其对象，不能统一缩到页尾。

### 字体与字级

所有准确事实优先使用可稳定加载的 Coding 字体。艺术标题只承担短语，不承载日期、价格、薪资、规则、联系方式、Logo 或二维码。

先设母版短边为 `W`、预期展示短边为 `V`、缩放系数 `s=V/W`，按实际显示字号反推正文基准 `B`。例如 1080 px 母版展示为 360 px 宽，长图正文若从显示 `16–20px` 起测，母版应为 `48–60px`。这是试排起点，最终按真实字形、内容密度和观看方式检查；不要因母版数字看起来大就认定手机上可读。

#### 社媒长图显示字号底线

本段仅约束 AI + Coding 社媒长图；可编辑套图按目标平台与对应 Spec 单独验收。字号按最终展示尺寸的 CSS 逻辑像素计，母版字号按显示比例反推；同一交付物若还执行品牌 VI 字号规则，取两者中更严格者。

- 正文为 `16–20px`，图注与来源为 `14–16px`；所有有效信息不得低于 `14px`。
- 必须在平台压缩后的手机默认显示及完整长图预览中，无需放大仍可读；复杂背景、细字重或弱对比不能仅凭数值达标判定通过。
- 不可读时优先增大字号、提高对比或字重并重组信息，其次拆页或拆段，禁止继续缩字。

| 文字角色 | 相对 B 起点 | 典型字重 | 断行与职责 |
| --- | --- | --- | --- |
| Display / 第一标题 | `3.2–6×` | 700–900 或艺术字视觉重量 | 1–3 行；只承担一个识别命题，可有一次极端尺度 |
| Secondary / 传播钩子 | `1.6–2.6×` | 600–800 | 1–3 行；补充价值或情绪，不复述标题 |
| Key fact / 核心事实 | `1.15–1.65×` | 600–900 | 日期、价格、薪资、结论和 CTA；条件与单位保持邻接 |
| Body / 说明 | `1×` | 400–550 | 每行约 14–24 个中文字符；高密区用组间距而非缩字解决 |
| Caption / 标签 | `0.82–0.95×` | 450–650 | 1–2 行；对应主体、证据或栏目，不作无意义填空 |
| Micro / 家具 | `0.68–0.82×` | 400–600 | 仅非关键索引、期次和短英文；不能承担 CTA 或必要联系方式 |

相邻层级接近时，用字重、字类、位置与留白拉开。具体字体、字号、行宽与行数由 HTML 记录；用真实文案和目标展示宽度检验，不在 Brief 重复记录全部几何。字体先从 [字体推荐入口](../../../rendering/font-recommendation-list.md) 按语种、角色、形态和气质形成候选，并用各屏真实文案试排；精选清单不是封闭白名单，查询脚本只提供候选、缺口和诊断。长图应保持封面、章节标题、正文和辅助信息之间可识别的家族关系与跨屏层级连续，但不要求所有屏机械使用同一款字体。视觉候选确定后，正式 HTML 再按 [字体资源与执行契约](../../../rendering/font-family-library.md) 核验实际 family、face、weight／style、许可、目标字形覆盖和 Web 加载，写入真实 DOM，并在完整长图中检查跨屏一致性、换行、基线、伪粗体和裁切；用户锁定精确字体时，门禁失败必须请求确认，不得静默替换。

### T01｜中性无衬线层级

- **展示字体栈**：中文 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / Microsoft YaHei / sans-serif`；主标题 `800–900`，传播钩子 `600–800`。
- **正文字体栈**：中文沿用同一 Sans 栈；核心事实 `600–800`，正文 `400–500`，标签 `500–600`。
- **英数/家具字体栈**：`Inter / Helvetica Neue / Arial / sans-serif`；数字 `700–900`，英文栏目与家具 `500–700`。
- **控制**：适合通用、科研和活动；主要依靠尺度与字重分层，不同时引入第二套展示字体。主标题通常为正文 `3.2–5×`。

### T02｜高对比衬线＋Sans

- **展示字体栈**：中文 `思源宋体 / Source Han Serif SC / Noto Serif CJK SC / Songti SC / SimSun / serif`；英文 `Bodoni 72 / Didot / Georgia / serif`；主标题 `500–700`，传播钩子 `500–600`。
- **正文字体栈**：中文 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif`；核心事实 `600–700`，正文 `400–500`，标签 `500–600`。
- **英数/家具字体栈**：英文可沿用展示 Serif，准确数字使用 `Inter / Helvetica Neue / Arial / sans-serif`；价格与日期 `700–800`，家具 `400–600`。
- **控制**：适合高端编辑、食品和文化；衬线负责品类气质，Sans 负责准确事实。主标题为正文 `3.2–5.5×`，禁止全篇装饰衬线。

### T03｜实验展示字＋中性事实字

- **展示字体栈**：中文 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif`；英文 `Arial Narrow / Roboto Condensed / Inter Tight / Arial / sans-serif`；主标题 `800–900`，传播钩子 `700–800`。
- **正文字体栈**：中文使用稳定 Sans 栈；岗位、日期和核心事实 `600–800`，正文 `400–500`，标签 `500–600`。
- **英数/家具字体栈**：`Inter / Roboto Mono / SFMono-Regular / Courier New / monospace`；薪资与编号 `800–900`，英文家具 `500–700`。
- **控制**：适合酸性和潮流；倾斜、压缩、拉伸或错位只作用于短标题，事实层保持正常字面。主标题为正文 `3.5–6×`。

### T04｜手绘展示字＋圆润 Sans

- **展示字体栈**：普通可编辑标题使用 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif`；授权手写字体或艺术字图片仅用于短标题；主标题视觉重量 `700–900`，传播钩子 `600–800`。
- **正文字体栈**：中文使用上述 Sans 栈；岗位与核心事实 `600–800`，正文 `400–500`，标签 `500–600`。
- **英数/家具字体栈**：`Arial Rounded MT Bold / Nunito / Inter / Arial / sans-serif`；数字 `700–900`，英文家具 `500–700`。
- **控制**：适合年轻手绘；手写不承担价格、日期、岗位、联系方式和 CTA。主标题为正文 `3–4.8×`，正文保持稳定基线。

### T05｜档案 Serif＋Mono

- **展示字体栈**：中文 `思源宋体 / Source Han Serif SC / Noto Serif CJK SC / Songti SC / SimSun / serif`；主标题 `500–700`，章节钩子 `600–700`。
- **正文字体栈**：中文可使用同源 Serif 或 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif`；核心事实 `600–700`，正文 `400–500`，标签 `500–600`。
- **英数/家具字体栈**：`Roboto Mono / SFMono-Regular / Courier New / monospace`；编号与日期 `500–700`，索引家具 `400–600`。
- **控制**：适合档案拼贴；等宽字只承担索引、期次和元数据，每组微字必须有真实语义。主标题为正文 `3–4.8×`。

### T06｜企业几何 Sans

- **展示字体栈**：中文 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / Microsoft YaHei / sans-serif`；英文 `Inter / Helvetica Neue / Arial / sans-serif`；主标题 `800–900`，传播钩子 `600–800`。
- **正文字体栈**：中文沿用稳定 Sans 栈；岗位或模块标题 `700–900`，核心事实 `600–800`，正文 `400–500`。
- **英数/家具字体栈**：`Inter / Helvetica Neue / Arial / sans-serif`；薪资和关键数字 `800–900`，英文栏目与家具 `600–800`。
- **控制**：适合商务、招聘和科研；数字与单位保持邻接，正文不使用伪技术等宽字。主标题为正文 `3.2–5×`。

### T07｜票据编辑碰撞字组

- **展示字体栈**：中文 `思源宋体 / Source Han Serif SC / Noto Serif CJK SC / Songti SC / serif` 与 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif` 二选一为主；主标题 `700–900`，传播钩子 `600–800`。
- **正文字体栈**：中文使用稳定 Sans 栈；核心事实 `600–800`，正文 `400–500`，票据标签 `500–700`。
- **英数/家具字体栈**：`Roboto Mono / SFMono-Regular / Courier New / monospace`；编号与日期 `500–700`，英文家具 `400–600`。
- **控制**：一页最多组合两种主字类与一种 Mono；碰撞来自尺度、旋转和基线，不靠五种字体。主标题为正文 `3.5–6×`，准确文字保持 `400–800` 的稳定 Coding 字重。

### T08｜相册手写＋人文 Sans

- **展示字体栈**：普通标题使用 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif`；授权手写字体或 A03 只用于短情绪句；主标题视觉重量 `600–800`，传播钩子 `500–700`。
- **正文字体栈**：中文使用上述人文 Sans 栈；地点与日期 `600–700`，正文 `400–500`，图片说明 `400–600`。
- **英数/家具字体栈**：`Inter / Avenir Next / Helvetica Neue / Arial / sans-serif`；日期与编号 `500–700`，英文家具 `400–600`。
- **控制**：照片说明必须比主标题低两级，单张照片只配一个说明组。主标题为正文 `2.8–4.5×`；手写不得承载核心事实。

### T09｜手账粗题＋结构化 Sans

- **展示字体栈**：中文 `思源黑体 / Source Han Sans SC / Noto Sans CJK SC / PingFang SC / sans-serif`；艺术手写标题可使用 A03；主标题 `800–900`，栏目钩子 `600–800`。
- **正文字体栈**：中文使用同一 Sans 栈；组标题 `700–800`，核心事实 `600–800`，正文 `400–500`，标签 `500–600`。
- **英数/家具字体栈**：`Inter / Arial Rounded MT Bold / Arial / sans-serif`；关键数字 `700–900`，英文家具 `500–700`。
- **控制**：标题可跳动，内容必须齐轴；组标题与正文至少形成 `1.3×` 尺度差。主标题为正文 `3–5×`，高密时增加组间距而非缩小正文。

字级按阅读角色落成，不以编号替代数值。事实正文不得为了保留装饰而压到目标平台不可读；字体栈中的首选字体不可用时必须使用同类别回退，并重新测量。

### 长图字体与配色适配

- 统一展示、正文与英数的字体职责，局部可改变尺度和字重；按目标手机宽度检查，文字过密先改信息组织、行宽或段高。
- 母版字号只是起点，缩放后仍须清楚。真实文字试排后记录实际字体和断行，字体未加载或字形明显偏离时不能声称已命中对应 T。
- 共享配色职责，章节可切换明暗、表面和强调面积。数据、单位、条件与来源邻接；纹理、照片和渐变上的正文检查实际合成对比。
- 参考或照片取色区分目标色与实测色，肤色、食物和证据影像不为统一调色而失真。

## 决定各屏与各页图片排版

### 单图组合

- 全幅场景保留实际空间与主体，文字进入可读净空；不为了排字把照片全部模糊。
- 完整对象居中或偏轴，配相邻说明；局部特写保留辨认部位所需的上下文。
- 独立主体可与标题、路径或边界穿插；脸、操作接触点、商品身份和证据不得被遮挡。
- 长图可以让同一主体或场景跨段；套图每页须独立成立，仅通过动作、边缘或镜头关系接力。

### 多图组合

- 主图加细节：主图交代整体，辅图补动作、材质或证据，图注逐一对应。
- 同级并列：分类、比较或步骤使用一致的尺度与必要视角，不通过裁切制造假差异。
- 编辑式拼贴：照片、纸层与说明形成清楚前后关系，最大图承担主结论，不平均散落。
- 连续镜头：全貌、行动、细节按内容推进；同一主体保持身份，改变镜头必须带来新信息。
- 系列图鉴：按实际分类组织对象，边缘与标注统一，不能把不同对象变成同一身份。

数量和内容用途沿 Spec；为破框、遮挡或替换而拆分已有图片时，将拆分理由和对应关系补在原配图条目下，不新增内容性配图。直接使用的参考图写裁切、位置和保护范围，不为凑生成任务重绘。

## 形成各屏与各页素材生产意图并编译 Prompt

在对应屏／页的配图条目写每张待生成或编辑图片的人类可读生产意图；冻结 Brief 后，再在素材清单中编译完整自然语言 Prompt。编译顺序为：具体风格及可见特征 → 参考图分工 → 主体、动作、数量 → 背景与辅助元素 → 艺术手法、色彩、材质与明暗 → 构图、景别和裁切保护。比例与像素尺寸只放素材清单和工具参数，不写入 Prompt 正文；构图中的主体占比和相对位置可以描述。

普通配图不写上屏文案、文字排版，也不写“无文字／无字／no text”；留白描述位置与低纹理空间，不写标题用途。原商品包装、Logo 等身份保护要求不因此删除。长图一体化 Hero 与准入的独立艺术标题是文字例外，必须逐项描述本次分配到图内的准确文案和字形。可编辑套图封面没有整图文字例外；明确要求可编辑的文字必须为 HTML 原生文本，局部编辑的非目标区域可沿既有艺术标题准入规则，真实照片内标签无需重画。

### 逐图填写

```markdown
- 图片：所属屏／页、名称、用途与目标画幅
- 来源与方式：直接使用／裁切／编辑／生成
- 参考图：
  - 图1：参考对象；提供什么；必须保留什么
  - 图2：参考对象；仅借鉴什么；不继承什么
- 排版与裁切：使用位置、主体范围、与其他图文的关系
- 生产意图：本次画面目标、主体与背景关系、参考职责、保护项和禁用项
```

建立素材清单时，写入参考图真实短链和顺序，编号与传给工具的参考数组一致；Prompt 正文只用图1、图2等序号，不写 URL、本地路径或工具参数。没有短链则在素材记录标记待补，暂不调用依赖该参考的生成。参考只控制明确指定的维度，不把风格参考中的人物、品牌或数据视为本次事实。

尺寸、Alpha、抠图、素材准出与工具参数仍执行 [素材 Prompt 指南](../ai-coding/asset-prompt-guide.md)。上方是 Brief 的生产意图写法，完整 Prompt 与工具参数只进入素材清单。

### 长图 Hero：按既定分工描述文字

先读取同一 Brief 的 Hero 制作方式，只描述已确定入图的文案，不将独立可编辑文字重新烘焙入图。入图文字逐项写出准确内容、信息层级、字形特征、字体风格、字色、字重、特效、位置与断行；正文只写大意时返回 Spec 补齐。相同样式可以复用，准确文案不能用“其余同 Brief”省略。

假设一个虚构编辑专题仅确定入图主标题“把周末交给街角”，其余信息由独立文字层承担：

> 人文杂志编辑风，用街角建筑的几何线条、自然摄影与清楚展示字形成阅读入口。竖版画幅按当前 Hero 槽位生成，街道从中部向下延伸，建筑轮廓集中右侧，左上墙面平整，底部保留可接续的路面。主标题准确写“把周末交给街角”，分两行“把周末”“交给街角”，位于左上，是第一信息层级；采用宽字面人文无衬线、粗体约 800，深墨色，平面实色无特效，左对齐，两行间距紧凑但不相碰，与右侧建筑留有间隔。

真实任务按全部入图文案写全，画幅只放工具参数，逐字核对生成结果。出现图内文字问题先按原门禁交付，记录并等待用户要求，不自动编辑、重生或用 Coding 覆字。

### 长图 Hero：完整首屏视觉衔接

长图 Hero 把背景、主体、装饰和按 Spec 分配的全部入图文字写在同一条 Prompt 中。每组文字逐字引用，写明字体特征、风格、字色、字重、特效、信息层级、位置、对齐与断行；包括实际采用的来源或占位声明，不能只写“其余同 Brief”。生成后作为完整 Hero 图片进入长图组装，不另生透明艺术字替代。

假设本次首页仅有以下两组已确定的创意文案，工具参数为比例 `3:4`：

> 明快纸本杂志拼贴风，暖白纤维纸面与深蓝剪纸块形成清楚主次，珊瑚色小箭头引向右下。中央偏右是一组有手工剪边的街角建筑插画，少量侧影与细接触阴影建立纸层，左上保留开阔区域。主标题准确写“周末走进街角”，断为“周末走进”“街角”两行，位于左上，第一信息层级；宽体人文无衬线、特粗字重，深蓝实色、无特效，紧凑左对齐，不遮挡建筑轮廓。副标题准确写“发现身边的小店”，位于主标题下方，第二信息层级；清楚的常规无衬线、中等字重、深灰色、无特效，与主标题留出明显间距。整体用标题、建筑和小箭头形成向右下推进的阅读关系。

## 决定屏间与翻页视觉节奏

叙事顺序沿 Spec，不因为想展示更多布局而增删内容。长图看连续阅读与实际接缝，套图看每页独立性、翻页理由及系列继承；不要把两种载体的过渡混用。

### 段高、比例与衔接

按真实文字、图片信息和主次估算段高，“屏”不等于统一高度。重点段展开，短规则收紧，同类例图保持稳定比例。手机尺度读不清时调整信息组织、行宽或段高，不通过缩字和非等比拉伸图片解决。源图与容器的比例差不等于实际拉伸：分别核对源图比例、容器比例及最终横纵缩放。cover／contain 保持等比时，以实际取景、主体与文字保护、裁切后有效像素和目标尺寸清晰度验收；cover 不得裁掉保护对象，contain 的露底须符合既定背景关系，不能仅凭比例不同判失败。

主次与疏密直接写入 Brief 的屏间视觉节奏：哪些段展开、哪些紧凑，哪些同类段共享结构及原因；具体几何只在公共 HTML 维护。长图不为凑布局种数制造变化；套图则以内容为依据试排，同时满足下文独立列出的差异性与一致性配额。

先判断相邻段属于连续场景、同章推进还是章节切换，再选择表现：连续场景须有同一母图、连续裁切或可验证的共享背景生产单元依据，优先延展同一母图、连续裁切或重组为同屏；同章推进使用标题、留白、纸层、路径、色块或品牌识别等有职责的结构化分隔；章节、地点、时段或媒介发生切换时使用切屏。常规顺接不强加转场，切屏也不是纯图默认。

两张独立完整主图不使用渐变、蒙版、透明度或混合模式直接融合。背景按已确定的生产单元覆盖对应内容范围；相容的相邻屏延续同一基底，只有纯色、纹理或图片背景层确需连续时才提出色场、材质或退场要求，具体实现交给公共 HTML 路由。相邻背景与实际露底区的接缝须复核，不保留完全被遮挡且无其他职责的底图。

### 上下段的交接关系

先决定上段交出什么、下段为什么继续，再确定画面如何接住。在同一 Brief 中相邻两段各自的“与前后屏／页的衔接”条目内，用自然语言记录并核对交接对象、出口方向、入口接收位置和保护区；末段记录收束，不虚构下一屏。具体共享图像、端点、蒙版和接缝几何落实到最终 HTML，不恢复旧过渡机器字段。

| 交接方式 | 上段 → 下段的具体推进 |
|---|---|
| 全貌 → 细节 | 从完整主体进入同一主体的局部放大，说明放大的位置与要解释的内容 |
| 场景 → 行动／证据 | 上段呈现处境，下段用动作、作品或真实证据兑现首屏承诺 |
| 对象／路径延续 | 同一对象轮廓或有真实顺序的路径穿越边界，下一段接收后进入解释 |
| 连续空间 | 同一环境内改变信息密度或景别，先联合规划文字净空和主体位置 |
| 对比换挡 | 同一比较维度发生状态切换，保留可比较对象；撞色服务差异 |
| 章节停顿 | 内容确实换章时允许明确切换，用标题、留白或媒介变化标识，不强行融合不相容场景 |

Visual 决定连续色域、上下弥散、撞色、纸层或线条的具体表现；Spec 不以“都是同色”“有一条渐变”代替内容接力。组装时的共享图像、扩图、蒙版和结构错位处理统一读 [跨段组装](../../../workflow/html-assembly.md#4-素材合成与实际测量)。

### P｜翻页连续原子

P 仅作离散页面翻页连续性的内部参考，不决定整套内容链，也不替代单页 L 构图。每个页缝最多采用一种主要接力机制；在同一 Brief 的“与前后屏／页的衔接”条目中，核对上一页出口与下一页入口描述的机制、交接对象、方向、接收位置和保护区一致。最终 HTML 落实各页实际接力关系，不要求输出 P 编号或恢复系列机器字段。

### P01｜页码递进

- **机制**：编号、进度、章节名或阶段词持续推进；
- **适用**：教程、规则、榜单、活动流程、专题章节；
- **实现**：页码和章节轴使用真实文本与容器 DOM，位置和字重固定；
- **退化**：页码只表示顺序，没有内容阶段；每页页码位置随机。

### P02｜边缘接力

- **机制**：色块、边框、线条、路径或纸层从上一页出口延续到下一页入口；
- **适用**：编辑排版、票券、拼贴、路线、运动和活动套图；
- **实现**：共享颜色、线宽、方向和接触位置，分别在两页建立可编辑端点；
- **退化**：两页只是颜色相近；线条没有接触内容或指向。

### P03｜主体动作接力

- **机制**：人物视线、手势、运动方向、产品朝向或角色动作指向下一页；
- **适用**：人物故事、手绘角色、运动、公益、产品场景和品牌活动；
- **实现**：主体为独立图片 DOM；下一页承接动作结果或视线对象；
- **退化**：重复同一姿态；动作朝向与翻页方向冲突。

### P04｜裁切回声

- **机制**：上一页的局部图像、形状或标题片段在下一页以新尺度、新镜头或新职责回应；
- **适用**：摄影、产品、拼贴、地图、食物和作品展示；
- **实现**：保留同一素材身份，但改变裁切责任；内页标题沿本文件字体流程更新，确需准入艺术主标题时按其源文案生产；已有图内文字问题等待用户要求，不因翻页自动重生；
- **退化**：同图复制；只缩放而没有新结论。

### P05｜色彩章节推进

- **机制**：保持颜色职责不变，通过背景色阶、明暗或主辅色交换标记阶段；
- **适用**：活动阶段、知识分类、情绪叙事、昼夜和多场景内容；
- **实现**：颜色仍来自同一 C 系统，最多一次显著高潮换挡；
- **退化**：每页随机换色；正文对比度随色阶下降。

### P06｜问题—回答翻页

- **机制**：上一页留下明确问题、悬念或未完成句，下一页首要信息立即回答；
- **适用**：科普、攻略、功能介绍、公益议题、品牌故事和 FAQ；
- **实现**：问题和答案分别成为两页 P0/P1 信息；视觉锚点保持一致；
- **退化**：制造空洞悬念；下一页没有直接回应。

P 的选择必须服务页面语义。箭头、页码、胶带、括号和装饰线本身不是翻页系统。

### 套图布局轮换与视觉节奏

同一套图通常选择 `2–4` 种兼容 L 轮换，而不是每页一种新风格。建议至少包含：

1. 首页主视觉页：大标题与主素材共同占据主要重心；
2. 建立页：解释主题、活动价值或问题；
3. 展开页：步骤、分类、案例、规则或证据；
4. 高潮页：最强案例、奖励、核心功能或关键结论；
5. 尾页：行动、参与、收藏、投递或价值余韵。

密度通常采用 `low → medium → high → medium/low`，但由内容决定。避免所有页面都是高密说明，也避免首页之后连续空洞大字页。

以上是有内容依据的试排建议；下面的配额用于保证内页差异性和系列一致性，不因试排建议而豁免，也不能用机械换版损害内容和可读性。

### 套图一致性与差异性硬门禁

- **整体统一**：至少 70% 的视觉判断服从同一套已写明的视觉语言，最多借用一个次级母题。全套固定主视觉家族、标题／正文字体职责、主色职责、素材边缘、背景材质、品牌锚点和页码语法。
- **相邻变化**：每对相邻内页至少改变两项主体动作、位置、尺度、图文比例、镜头、信息容器或密度，同时保留至少三个可观察的系列锚点。短转场也需满足，不只换标题和背景颜色。
- **布局轮换**：连续三页不得使用相同主布局；再次使用同一主布局时，至少改变主体位置、尺度、图文比例、信息容器或密度中的两项。按实际成图判断，不靠更换布局名称通过。
- **容器准入**：只在有独立扫描、比较、承托或媒介隐喻的多组信息时启用卡片；默认一个主容器，最多两个辅助容器。普通段落、分隔线、底色和单一主图不计为卡片。
- **主辅差异**：多卡片页主卡面积至少为最小辅助卡的 1.5 倍，禁止全部卡片等宽、等高、等亮、等圆角、等阴影；至少采用一种错位、倾斜、叠压、非对称、堆叠、路径或自由轮廓关系，并改变至少两项形态、尺度、位置、角度、层级或密度。
- **关系保护**：叠压时以 10%–30% 实际面积重叠试排并记录前后关系，倾斜明确方向；不能遮挡关键信息、脸、产品识别面、Logo、二维码、数字单位和行动入口。

平行比较需要相同尺度时，让比较对象在一个主信息组内保持可比，页面其他位置承担层级与变化；不要扭曲证据或任意放大比较对象来满足卡片配额。所有数值检查结合最终几何与渲染，Brief 用自然语言写主次、保持项、变化项及内容依据，不新增机器计划。

| 排版与引导 | 文字／素材的视觉权重与落点、阅读主轴、引导线连接对象、标题错列、穿插与保护范围 | 路径端点、线宽、层序、文字净距 |
| 素材风格 | 媒介、镜头、笔触、材质、光照、逐图生产意图；沿用 Spec 的对象、动作和参考关系 | 素材清单中的完整 Prompt、目标信息与实际资产，以及 HTML 中的裁切 |
| 卡片与容器 | 开放排字或容器，轮廓、表面和边界；适用信息组 | CSS 组合／原子、内容框、透明度、边缘与投影 |
| 全篇延续 | Hero、展开段、密集事实段与收尾如何保持识别、发生变化 | 共享样式与章节差异、接缝关系 |

例如“清爽科技＋青绿弥散”：Brief 可选深青为正文，浅青与浅蓝构成上下连续色域，青柠仅突出关键数字；主标题约正文 4 倍，章节题约 2 倍，关键短语下沿高亮。Hero 右下色域接入第二段左上，细线连接图中实际部件与解释；信息优先开放，平行比较再用薄边半透明容器。该例是试排策略，具体色值与字号由 HTML 确定，不推广为其他风格默认。

“文字占约七成视觉权重、插画在左下角点缀”描述本段主次，需同时说明标题位置与图文关系；不解释成每个文字框面积的硬指标。相反，摄影主导段可让图像成为第一锚点、标题短而清楚，不能全篇套同一比例。

Visual 阶段先由内容、参考与视觉判断形成可调整的效果、对象、范围和可见关系草案，再按本文件的“CSS 组合优先与原子能力校验”先比较同品类、同范围组合，适配整体关系后补充或替换局部原子；不能先锁死模型自选几何再排除组合。用户事实与锁定项不变，不因库中存在某种卡片强加效果。最终 Brief 只记录适配后的自然语言可见结果；冻结后由 HTML 按 `ref_key` 读取选中正文及依赖并绑定参数。库未覆盖的成像按实际表达能力分配给图像或必要原生实现，不虚构已有组件。

所选机制逐项落入 [Brief → 素材清单 → HTML](../scenarios/social-long-image-spec.md#brief--素材清单--html)。Brief 逐图记录生产意图，素材清单按 [素材 Prompt](../ai-coding/asset-prompt-guide.md) 编译并唯一维护完整 Prompt、工具参数与素材准出；不另建同图的平行 Prompt 事实源。

验收看实际结果：

1. 用户明确要求的风格与局部效果是否出现；“清爽科技”是否被误做成深色企业模板，“毛玻璃”是否只有透明白卡。
2. 标题、主体、信息表面是否共同形成所选关系；去掉风格名后仍能指出可见机制。
3. 图片的镜头、笔触、边缘与光线是否统一且服务内容；真实证据有没有被后期损坏。
4. 正文与关键信息在目标显示尺寸下是否清楚，叠压、纹理、渐变与透明度有没有干扰阅读。
5. 全图是否有基于内容的主次和重复，局部变化有没有破坏整体语言。

效果检查与套图配额都必须通过，不能相互代替。生成目标、实际资产观察与最终渲染分别记录；未观察到的效果不宣称验证通过，也不以填写字段数冒充完成。AI 图内文字问题交付后记录并等待用户，不自动重生；Coding 文字照常修正。

将当前长图或套图实际采用的主风格、注意力路径、逐屏／逐页构图、字体与配色、背景系统与生产单元、容器／开放排版、图像系统、连续与差异机制、素材职责和降级写入 **视觉效果生产规范**；将本节实际效果检查、目标尺寸可读性、长图接缝或套图一致性／差异性配额写入 **视觉效果验收规范**，不得只引用风格编号、配额名称或模板结果。

## 复古长图：按承载机制选型

规划阶段先分清档案剪报、冷银Y2K和酒馆陈列，不把三者统一成棕色纸纹。下表为已入库局部组合，整页入口见本节末尾。整页的Hero、连续章节及收尾仍按社媒长图Spec规划；示例素材的外观近似按各组合采用边界处理。

| 内容与视觉条件 | 原子选择 | 组合选择与不变量 |
|---|---|---|

| 冷银促销、优惠券、商品陈列 | [冷银墨黑青蓝](../../../../assets/templates/css/colors/calm-and-rational.md#palette.silver-cyan-mono)保持银底/墨字/白券/青蓝行动；[单对腰孔](../../../../assets/templates/css/shapes/tickets-and-notches.md#shape.paired-waist-ticket)不是四边邮票孔；[金属包边](../../../../assets/templates/css/shapes/cards-and-panels.md#shape.beveled-metal-frame)保留外斜面、内凹槽和独立内容窗 | [银底优惠票阵](../../../../assets/templates/css/combinations/recipes.md#combination.silver-coupon-grid)：标题、星饰和券阵归属同一银底；宽幅3列、窄幅2列；商品摄影放入金属框槽；复杂充气星和链条保留真实材质素材职责 |
| 街区探店、酒馆图录、纸本领取说明 | [红棕赭纸亮橙](../../../../assets/templates/css/colors/rich-and-retro.md#palette.tavern-umber-orange)区分柜底/纸/文字/招牌；[搁板截面](../../../../assets/templates/css/shapes/cards-and-panels.md#shape.shelf-profile)负责承托厚度；[内凹出纸槽](../../../../assets/templates/css/shapes/cards-and-panels.md#shape.recessed-paper-slot)负责槽与前唇 | [搁板摄影目录](../../../../assets/templates/css/combinations/recipes.md#combination.tavern-shelf-directory)：照片保留原色、图签压照片下缘、整排落板；[出纸槽垂纸说明组](../../../../assets/templates/css/combinations/recipes.md#combination.tavern-paper-dispenser)：橙牌在装置外，纸从槽后穿出、前唇遮纸顶，补充便笺叠在长纸前 |

字体按角色匹配：档案艺术刊头可使用独立艺术标识素材，不用普通Georgia冒充原艺术字；促销标题选择真实粗紧展示字，示例思源黑体900仅用于该标题，正文400；酒馆便笺可试寒蝉高黑体Medium，橙牌可试抖音美好体Bold的真实face。解析具体字体资源后核对同字字形和实际字重，示例别名不等于已加载字体，不把本例字重推广给其他风格。

纹理与渐变分别落点：底面颗粒低对比单色，照片不统一滤色；橙牌横纹保持低明暗差，螺钉与文字分层；金属框反光在框带内，不能把整张照片涂银。掉墨SVG按资源协议内联，不能因file页面遮罩未显示就宣称机制成立。票面门槛增行时复核腰孔与分区线，夹持与出纸组合复核长文案安全区；整页背景场不拆成多个局部背景图卡。

### 数码活动的通用形状入口

先按对象职责选形状，再由组合绑定配色、质感、布局与素材；这些形状不限定数码风格。

- [斜台面与独立前沿](../../../../assets/templates/css/shapes/cards-and-panels.md#shape.sloped-deck)：只含台面轮廓与独立前沿；前沿高度独立于内容与投影。颜色、颗粒、按钮与内部网格由组合绑定。
- [薄侧边立体按键](../../../../assets/templates/css/shapes/cards-and-panels.md#shape.thin-sided-key)：键面、薄侧边与承托分离；主体可换圆滑SVG轮廓。原图组合保留已校准的圆滑路径作为覆盖。不是带行为的按钮组件。
- [连续圆弧缺口票根](../../../../assets/templates/css/shapes/tickets-and-notches.md#shape.arc-notched-stub)：使用同一闭合路径绘制底色与描边，底边8个圆弧缺口。此预设随viewBox缩放，不宣称孔径与数量可直接通过CSS独立改变；需要不同孔数时重新构造路径并验证。无名单、条码或上部票面语义。
- [双层胶囊指示器](../../../../assets/templates/css/shapes/capsules-and-badges.md#shape.capsule-indicator)：外壳和内芯各自居中，border-box使内芯边框计入高度；外层相对标题条居中由组合负责。本原子为装饰指示器，不宣称开关交互或实时状态。

## 下一步路由

完整 Brief 保存后，可编辑套图的封面、内页及长图分层部分执行上文“候选试排 → 资源门禁 → 真实 DOM → 完整长图渲染验收”的字体流程，按 [布局规则](../composition-layout.md) 细化实际几何，按背景职责准备 CSS／SVG、图片或组合及其余素材，再按正常流程组装 HTML 并检查真实 DOM。套图指定可编辑文字包括封面必须原生实现，不生成完整封面终图，不插入参数提取阶段，也不读取 pure-image 路线文件；默认纯图套图不进入本文件。CSS／SVG 依赖继续按第 9、10 节绑定和展开。

实现读取 [HTML/CSS 编码与渲染契约](../../../html/coding-rendering.md) 及 [HTML 组装](../../../workflow/html-assembly.md)，实际渲染后分别检查长图接缝、套图单页与全套缩略图。内容或主构图改变回写原 Brief，单纯测量修正留在同一 HTML。

### 摄影分章候选

多组摄影与单品介绍交替的品牌／穿搭长图，可复用 [摄影分章长页](../../../../assets/templates/css/layouts/continuous-flow.md#layout.editorial-lookbook-longpage)，可选 [奶油复古穿搭组合](../../../../assets/templates/css/combinations/recipes.md#combination.cream-sport-editorial-longpage)。布局不绑定配色；按本品类 Hero、准确文字及固定画布规则组装，不把详情页规格栏目强加给活动长图。

### 食品饮料感官章节

茶饮／水果主题需要透光原料、微距与双材质对照时，可选 [植萃绿金感官组合](../../../../assets/templates/css/combinations/recipes.md#combination.botanical-green-gold) 内“清透微距感官长图”变体。它采用微距叙事长图：单画布连续排布，只有双材质局部两列；不输出左右两个独立图，不强加详情页包装参数。Hero与图内文字职责仍遵循本品类规则，摄影策略读取组合正文。
