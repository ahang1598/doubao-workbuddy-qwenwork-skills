# 个人名片与会员卡视觉表现规划

## 底图与 Prompt 强制规则

每个卡面的作品级底图必须包含与本人、品牌和已选视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整个卡面。姓名、联系方式、权益和条件区域可以降低纹理频率、对比和密度，或使用局部纯色承托，但仍须与整体底图连续且同源。

每次写出具体卡面底图或材质背景 Prompt 前，必须先读取并遵循 [背景图 Prompt](../ai-coding/asset-prompt-guide.md#5-背景图-prompt)，按其中的背景职责、纹理选择模型和完整 Prompt 编译语法描述材质、色场、变化方向、尺度、低纹理区与连续关系。该路由适用于新生成和编辑既有底图；直接复用真实背景时不强造 Prompt，但必须记录使用方式并检查本节结果门禁。

## 读取入口

读取 [个人卡片 Spec](../scenarios/personal-card-spec.md) 保存的同一 Brief 中“个人卡片内容结构”。没有 Brief 或缺少必要内容时返回 Spec；Visual 不创建副本，不猜测身份、权益、卡号或卡面职责。

## 容器与开放排版视觉决策

Visual 阶段必须在原 Brief 每个正反卡面及各版本的对应条目中输出“容器与开放排版视觉决策”，先判断卡内信息是否还需要边界，再按 [容器视觉语法](../composition-layout.md#容器视觉语法开放排版优先语义容器按需) 选择容器家族；不能只写全局风格或留到 HTML 阶段决定。区分实体卡面本身与卡面内的信息容器，不把整张卡再包进装饰卡片。

- 逐个说明容器名称、承载联系／权益信息、位置与主次；同屏多个容器分别描述，共用效果可明确引用，但须写本面差异。
- 写清轮廓与圆角／切角、表面材质、填充配色及纹理／渐变、边框与边缘、阴影与厚度、透明度／模糊，以及内部留白、图文排列、与卡面底图和主体的关系。未使用的效果明确写“无”，不默认全部叠加。
- 只写可见效果的自然语言，不输出 CSS 参数、色值表或槽位契约；来源 ID 仅写入短采用记录；规则容器交给 HTML/CSS，复杂壳体按 [素材使用规范](../ai-coding/asset-prompt-guide.md) 准备，不将视觉材质冒充已验证印刷工艺。
- 无需容器时明确写“开放排版、无容器”，并说明如何用对齐、段距或分隔线组织信息；不能为填字段强加卡片或卡片嵌套。
- 普通白色圆角矩形只用于稳定权益或联系分组，不能把姓名、身份、二维码和条件分别装成同款卡。可按真实语义采用票券、切角铭牌、纸张插袋、标签牌、材料样本或照片衬纸，但二维码与小字区域保持平整、无遮挡。
- 将本面效果写入视觉验收重点，检查实际边缘、材质、对比、联系方式容量与二维码净空；不得仅凭“高级容器”等名称判为完成。

### 品类常用容器表

下表区分实体卡面与卡内信息容器；类型只作为视觉候选，不能把整张名片／会员卡再次包装成装饰卡片。

| 常用容器类型 | 常见用途 | 视觉选择与边界 |
|---|---|---|
| 中性圆角容器（非默认） | 联系方式、会员信息、权益摘要 | 只在确需稳定分组时使用；内部容器服从实体卡面，不重复同等强度圆角和投影 |
| 阶梯面板 | 姓名主区、品牌标志与高等级权益 | 适合精细边框和正式层级，不能侵占裁切与安全边距 |
| 圆角磨砂玻璃 | 数字会员卡、科技或透明材质主题 | 检查背景透叠和文字对比，不把屏幕效果宣称为实体工艺 |
| 圆角纤维纸张 | 手作品牌、自然职业与纸本会员卡 | 纸纹尺度适配小卡，二维码与小字区域保持平整 |
| 票券与缺口 | 权益券、入场卡与可核验凭证分区 | 仅在真实兑换／凭证语义成立时使用，不伪造编码 |
| 胶囊与徽章 | 会员等级、状态与短权益标签 | 只放短字，避免与 Logo 徽章或主标混淆 |

### 已有布局 CSS 能力表

下表完整覆盖当前模板库已有的布局能力。Visual 根据内容职责选择，不按顺序轮用，也不要求每屏使用一种；写回 Brief 时使用表内能力名称和实际图文关系，便于后续自然语言匹配。名称用于能力对应，不输出 ID、路径、类名或参数。

| 布局能力 | 适用关系 | 写入 Brief 的边界 |
|---|---|---|
| 紧凑内容 | 同组事实、短字段、密集但可扫描的信息 | 写明压缩的是留白与组距，不缩小到不可读，也不把无关内容塞进同框 |
| 宽松内容 | 单一主张、少量重点、需要呼吸感的组件 | 写明留白服务的焦点与阅读停顿，不用空白凑画布高度 |
| 规整对齐（方格／网格排版） | 参数、证据、规格、并列比较和稳定栏目 | 写明列组、共同基线与主次；方格只组织可比较内容，不自动生成卡片墙 |
| 疏朗留白 | 长文、说明、编辑阅读栏与安静叙事 | 写明行宽、文字轴、图片归属与段间节奏，不等于所有内容缩成窄列 |
| 错落平衡 | 短标题接力、偏轴构图、左右不等权信息 | 写明错位对象、方向和共同对齐依据，不随机散放正文 |
| 聚焦主场 | 商品、人物、作品或场景作为第一视觉焦点 | 写明主体尺度、取景、文字静区和图文前后关系，不把主图缩成卡片配图 |
| 连续流动（串页／长页排版） | 长图章节、连续叙事、上下屏衔接和系列阅读 | 写明上一段出口、下一段入口、共享背景或接力对象，不只写“向下阅读” |
| 叠层拼贴 | 多张照片、纸片、证据或装饰需要错位叠压 | 写明主片、副片、角度、遮挡与保护区，不用随机旋转制造丰富 |
| S 形导览线 | 流程、路线、时间或概念节点需要曲线推进 | 写明真实节点、起止点和绕行保护区；没有关系节点时不用装饰曲线 |
| 横向卡片列 | 同类短条目、阶段、步骤或可横向扫描的内容组 | 写明条目共同尺度与差异；长正文、价格条件或复杂证据不挤入窄卡 |
| 章节眉线 | 章节编号、标题、短导语与换章提示 | 写明眉线承担的层级与接续对象，不把分隔线当主视觉 |
| 带引导线的图像标注 | 产品部件、成分、结构、地图或证据图解释 | 写明标注对象、端点和文字归属；引导线必须指向真实细节且不交叉遮挡 |

同一屏可组合兼容能力，例如“聚焦主场＋带引导线的图像标注”或“连续流动＋章节眉线”；组合后仍须形成一个明确主关系。没有适用能力时保留自定义关系并描述可见结果，不为命中模板改写内容。

### CSS 原子能力校验

完成视觉方向草案后、最终 Brief 冻结前，将本品类已选效果拆成下列自然语言能力词并执行公共限量查询。这里选中 ID、源路径与版本进入 Brief 短采用记录，不复制代码或参数；查询只验证能力与边界，不能反向新增视觉决定。

| 决策维度 | 交给查询的自然语言能力词 | Brief 保留内容 |
|---|---|---|
| 布局 | 阅读轴、主图关系、网格、错位、叠层、连续流动等实际关系 | 本屏图文主次、阅读路径与开放／分组方式 |
| 字形 | 填字、描边、发光、浮雕、路径排字等可见效果及文字角色 | 哪组文字采用何种效果、作用和可读边界 |
| 形状 | 当前选定的容器、图窗、票券、纸边、徽章或其他轮廓 | 轮廓服务的真实内容与本屏差异 |
| 表面 | 纸张、玻璃、塑料、织物、金属、柔焦等材质及承载对象 | 材质落在背景、卡片、图片还是文字，正文如何保持清晰 |
| 配色与背景 | 色彩职责、渐变／弥散方向、纹理类型及覆盖范围 | 可见色彩关系、背景变化、静区和保护范围 |
| 作用对象与边界 | 字体、卡片、背景、局部装饰；需要素材承担的复杂部分 | HTML 与图片的分工、必要降级及验收重点 |

候选摘要证明确实可实现后，把最终可见结果写回原 Brief；没有适用候选时保留已选方向，说明由素材或原生实现承担。真实引用、依赖、参数和消费者只进入后续 最终 HTML。

## 写回内容结构 Brief

保留原字段，整体追加一次；正反面与版本的差异写进原卡面条目，不重抄一份视觉 Brief。

- 风格：具体名称、可见特征及选择理由
- 决策优先级：用户锁定、本人／品牌身份、权益事实、扫码与工艺约束、参考继承／排除及 Agent 可裁量项
- 视觉命题与注意力路径：第一识别、身份／等级、联系／权益、扫码或条件收束
- 艺术表现手法：主体、背景和辅助元素怎样共同表达本人或品牌
- 配色：来源、主辅色、强调色与各自用途
- 文字排版：姓名、身份、联系、等级、金额与条件的字体、字重、层级、位置和断行
- 相对构图与图文占比：主焦点、主体区域、信息轴、图片／文字面积、密度、留白、允许遮挡和正反面呼应
- 图片层级与背景：比例、主辅尺度、裁切／遮罩、前后景、材料联动、身份保护与安全区
- 系列视觉：固定关系、可变关系，以及每张变体的具体差异
- 素材生产意图：逐图用途、画面目标、处理方式、参考职责、保护与禁用项；正式 Prompt 在素材清单中编译
- 尺寸适配、状态与降级：正反面、小尺寸、数字／印刷、扫码、不同人员／等级状态和素材缺失时保留／重排什么
- 视觉效果生产与验收：第一焦点、小幅面阅读、身份、扫码、图文比例、背景关系、材质与双面关系

## 选择风格与艺术手法

从希望留下的印象、品牌个性、卡片用途、已有作品和参考出发，不按职业、性别或会员等级套风格。选择一个主方向，必要时加相容的局部手法；材质是表达方法，不是工艺承诺。

| 风格候选 | 选择线索 | 具体处理 |
| --- | --- | --- |
| 瑞士平面、现代编辑 | 清晰、精密、有秩序 | 光学对齐、字重对照、宽窄信息区与细规则线，避免把小字当精致 |
| 人文出版、编辑档案 | 文化、私人叙述、作品感 | 衬线与无衬线对比，作品局部与注释成组，正反面可局部／全貌呼应 |
| 自然线描、手作纸本 | 温润、亲近、手工感 | 枝叶、器物笔触、纤维纸面与有机边缘，不能只叠纸纹 |
| 复古商业、活版票券 | 怀旧、凭证感、地方性 | 边饰、色版叠印、横向分段，装饰编号不伪装成兑换码 |
| 装饰艺术、精细材料 | 仪式、礼赠、精致 | 细致纹样、压印感与安静标识；不默认黑金或巨大 VIP |
| 实验字体、街头印刷 | 鲜明、先锋、个性 | 巨字局部裁切、字形穿插、错位与局部撞色，完整姓名另保持可读 |
| 像素插画、涂鸦、黏土拟物 | 俏皮、轻松、有参与感 | 主题物件与边缘或点位区互动，不让装饰点混入实际集点 |
| 抽象雕塑、透明层叠 | 艺术、空间、未来感 | 局部放大、负形、反射或透光构成，不淹没联系信息 |

例如“植物线描沿右边缘生长，正面只露局部，背面揭示全貌”，比“自然高级名片”更能落实。不要把职业统一画成工具图标，也不要求所有卡都含隐喻。

## 构图、文字与正反面

- 姓名／品牌主导：以字形和留白建立识别，联系信息沿稳定轴线组织。
- 图像主导：作品、插画或照片承担记忆，信息落在真实低干扰区，不套同款小相框。
- 编辑分区：身份与联系分开，但邮箱、电话、职业不能跨栏错配。
- 礼遇／规则配对：正面标识与主题，背面完整权益和条件；两面可以密度不同。
- 展示／操作配对：图像与点位、手写或兑换区分工，操作区由真实尺寸决定。
- 同轴、反相、实形／负形、局部／全貌都可形成呼应，不机械要求每面换构图。

所有文案与文字效果用 HTML/CSS，姓名、职位、邮箱、电话号码、地址、会员号、金额、有效期、权益和条件保持准确且可编辑。先试排最长姓名、最长头衔、多语种与最多规则的版本，再定文字尺度。竖排或实验字只用于适合的展示角色，不整卡旋转；同一等级同时有明确名称，不能仅用颜色辨认。Logo 与二维码保持独立、可替换对象，不由字体或装饰文字代替。

字体候选先从 [字体推荐入口](../../../rendering/font-recommendation-list.md) 按语种、角色、形态和气质形成，并用上述真实身份、联系、会员与权益字段试排；精选清单不是封闭白名单，查询脚本只提供候选、缺口和诊断。展示字体只承担姓名、品牌或短等级标题，不承载电话、邮箱、地址、会员号、有效期、价格、条件或密集权益。视觉候选确定后，正式 HTML 再按 [字体资源与执行契约](../../../rendering/font-family-library.md) 核验实际 family、face、weight／style、许可、目标字形覆盖和 Web 加载，写入真实 DOM，并在实体尺寸或数字目标宽度检查姓名—身份、联系方式、会员号—有效期、权益—价格—条件的配对，以及数字、符号、混排基线、换行、伪粗体、裁切和二维码净空。用户锁定精确字体时，门禁失败必须请求确认，不得静默替换。

密度先服从 Spec 的卡种惯例：识别面只保留一个主焦点，解释／操作面再承载联系、规则或点位。若单面超过 5 个信息组，先合并同类联系项、缩短说明或移至背面；若规则超过 6 条，优先分组并提供规则入口，不通过降低字号塞入。二维码、签名、盖章与点位按操作区域计算，不能与正文争抢同一空间。

## 图片、材料与制作

主视觉可由一张底图或独立主体承担，不因已有底图再重复生成主体。真实人像、作品、Logo 与二维码分别保留来源和替换入口；不生成虚构作品冒充持卡人作品。

纸纹、金属、压印、透明、珠光只描述可见效果；工艺能力、刀模、套准、透卡双面干扰由实际制作验证。清洁卡面不带卡片外投影；展示 Mockup 的投影应整洁，不应大面积扩散。符合实际接触或悬浮关系及光向，避免大范围暗晕，展示环境不计入卡面设计。

选色来自本人偏好、作品或品牌，写明主色、信息色、强调色的用途。透明、反光与纹理区域必须检查联系方式的对比；印刷色与屏幕色分别验证。

## 形成每张配图生产意图并编译 Prompt

每张待生成或编辑图先在 Brief 写用途、画面目标、来源、参考职责、主体与背景关系、保护和禁用项，保留 Spec 的数量与职责。冻结 Brief 后，在素材清单中补生产方式、比例、尺寸、安全区、消费者与准出标准并编译完整 Prompt；先写具体风格及视觉特征，再写主体、动作、数量、配色、材质、构图、视角、明暗、留白与裁切保护。直接使用或裁切的素材只写使用说明。

Prompt 只描述画面，不写文案、字体排版，也不写“无文字／无字／no text”等文字否定词。低干扰区域只描述位置，不说明用于姓名或联系方式。

有参考图时，逐项记录图1、图2的真实短链与职责，区别主体来源、风格参考和待编辑原图。Prompt 只用图序号，不放 URL、路径或工具参数；工具按同序接收短链。短链待补时不调用依赖该图的参考生成。真实品牌标记只继承获准母版，不因普通配图规则删除资产自身的标识。

### 无参考背景示例

> 采用自然线描与纤维纸本风格，制作宽高比 5:3 的横向背景。细墨线植物从右下方沿右边缘展开，少量叶片形成疏密变化，主体纸白、植物深绿，轻微纸纤维可见。左侧大部分保持连续低纹理空间，枝条在边缘自然出画，均匀柔和明暗，不增加其他物件。

## 视觉验收

- 按实体尺寸或数字目标宽度检查全部变体，姓名、号码、条件不截断。

- 手写、盖章、扫码区域实际可用；未做实测则注明，不以画面好看替代验证。
- 真实素材没有身份漂移，图像与信息有主次；清洁卡面独立成立且无外投影，展示投影轻淡并符合实际空间关系。
