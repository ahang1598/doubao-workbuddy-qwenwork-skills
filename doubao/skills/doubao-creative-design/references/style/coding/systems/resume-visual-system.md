# 简历视觉表现规划

## 底图与 Prompt 强制规则

每页简历的作品级底图必须包含与职业定位和已选视觉系统相关的纹理、肌理或渐变中的至少一项，不得以无变化纯色铺满整页。优先采用极弱纸纹、低对比肌理或克制渐变；正文区域可以局部纯色承托，但不得损害打印、ATS 辅助阅读和文字对比。

每次写出具体纸材底图、插画背景或环境背景 Prompt 前，必须先读取并遵循 [背景图 Prompt](../ai-coding/asset-prompt-guide.md#5-背景图-prompt)，按其中的背景职责、纹理选择模型和完整 Prompt 编译语法描述材质、色场、变化方向、尺度、低纹理区与连续关系。该路由适用于新生成和编辑既有底图；直接复用真实背景时不强造 Prompt，但必须记录使用方式并检查本节结果门禁。

## 读取入口

读取 [简历 Spec](../scenarios/resume-spec.md) 保存的同一 Brief 中“简历内容结构”。缺少内容、阅读模式或默认一页的内容安排时返回 Spec；不创建第二份 Brief，不改写学历、经历、指标或人像身份。Visual 不能为了解决排版拥挤自行增加页数，应先返回 Spec 按一页规则精简或展开文案。

## 按用户风格比较整页关系，再细化局部

新建或整体重做时，依据内容容量、阅读模式、用户锁定项和参考形成可调整的视觉草案。用户以风格描述需求时，先召回适配该风格的整页布局，再比较其关联组合；用户明确指定完整组合时直接比较该组合。不要先选局部形状或装饰再寻找整页，也不要把模型自选栏数、照片位置锁成硬约束。

使用带查询词的公共限量搜索：`python3 scripts/runtime/query-css-library.py search "简历 <用户风格与结构词>" --kind layout --artifact 简历 --layout-scope 整张单屏 --limit 5`，例如“手账 贴纸”或“极简 窄侧栏”。读取 `style_matches` 的适配程度、命中词与结构依据，对相关布局及其 `related_combinations` 使用 `describe` 比较整页关系。强适配表示现有结构支持该风格，可适配表示仍需所述调整，都不等于已通过视觉、容量或 ATS 验证。仅命中“简历”的弱候选不能声称满足风格；补查用户实际效果词或说明覆盖不足，不以颜色推导风格。

布局适配标签及关联组合统一维护在 [CSS 目录](../../../../assets/templates/css/catalog.json)，不在本 Visual 复制标签表。RV 是设计方向提示，查询时转成用户可见的风格与结构词，不直接把 RV 编号当标签。对关联组合按约 70% 的组合适配原则评估内容容量、阅读路径和整体关系；关联关系用于定位，不能代替比较。需要扩大整页候选时，再以同样效果词查询 `--kind combination`，包含通用原子组装的完整页面。

用户事实、锁定项、ATS／打印与一页 A4 约束优先。颜色、字体家族、照片风格或可替换影像的差异不能单独成为拒绝组合的理由；先判断结构是否可复用、换肤后是否仍适配。不能为了采用组合改写事实，也不能先锁死模型自选布局再排除可适配组合。存在真实冲突且无适用候选时可采用自定义关系，说明冲突和可见结果，不为命中模板改内容。

组合比较后决定采用范围：

- **完整组合（full_combination）**：采用适配的整体关系，实际复用组合的布局依赖与视觉样式，再补足或替换必要局部原子；不能只借颜色或名称却声称采用组合。共享主结构只插入一次。
- **独立布局（layout_only）**：只继承布局主结构和布局 CSS，另选字体、配色及质感；保留分区、图文位置、内容顺序、字级约束和安全区。比较关联组合后确认仅结构适用时采用；用户已明确锁定布局时可直接评估其内容适配。
- **自定义关系**：候选与事实、阅读模式或用户约束冲突时保留自定义实现，不把局部参考冒充整页匹配。

整页采用关系确定后，才选择局部容器并校验原子能力。Brief 用自然语言说明用户风格如何体现在所选结构中、保留哪些图文关系、如何调整颜色与素材；沿现有短 CSS 采用记录保存选中 ID、来源版本、采用范围与内容映射，不新增参数规划文件或额外确认轮次。局部编辑不重选整页。最终 Brief 冻结后才获取选中实现的代码、依赖及所需模板；真实参数和作用对象进入 HTML，图片生产参数进入素材清单。

## 阅读模式与视觉方向

风格依据个人特点、目标受众与参考选择，不按职业固定套蓝色或黑金。阅读模式限制排版自由度，不规定人格与审美；事实完整、可复制和可检索优先。以下 RV、RT、RC、RL、RI、RA 仅是查阅配方的简称，不是新的 Brief 字段或机器契约。

| 阅读模式 | 风格范围 | 可用图像 | 版式与标题边界 |
|---|---|---|---|
| ATS-first | 克制编辑、专业系统；作品证据仅单列变体 | 无附加图或规范证件照，遵循 Spec 的人像安排 | 单列优先，线性 DOM，事实不靠颜色或图标独立表达；标题克制，姓名为原生文字 |
| human-first | 克制编辑、专业系统、作品证据、人物编辑 | 证件照、克制职业场景或证据图 | 可用明确双区与证据图形，十秒主线稳定；标题不能吞并事实 |
| portfolio-hybrid | 可选全部五个风格家族 | 人像、作品图、案例缩略图、受控纹理 | 可用编辑式非对称；事实仍有线性阅读路径，所有标题保持原生 HTML |

视觉强度可仅体现为排版与颜色差异，也可加入受控影像、图形和一个记忆点；实验构图或复杂视觉资产仅适合 portfolio-hybrid，不得降低事实读取。图片和装饰不是每份简历的必需内容。多页及跨页配方只有在 Brief 记录用户明确要求多页时才启用，不能覆盖默认一页要求。

## 整页风格配方

### 克制编辑家族（RV1）

以清晰字级、充分留白、少量栏线和精确节奏建立记忆，适合通用专业岗位、跨行业投递及中高信息量；兼顾 ATS 与人工阅读。作品本身是核心证据时，不把所有案例压成纯文字。

| 方向 | 可见特征 | 参考搭配 | 避免退化 |
|---|---|---|---|
| RV1.1 现代单栏编辑 | 单一阅读轴，姓名—定位—核心优势—经历连续向下，右侧只放短元数据 | RT01；RC01/RC03；RL01；RI01 或无附加图；RA01 | 大面积空白挤压经历、条目同字重、职责与成果不分 |
| RV1.2 人文出版简历 | 克制衬线姓名、无衬线事实、小型页缘家具与舒展段落节奏 | RT02；RC02/RC04；RL01/RL03；RI01；RA01/RA02 | 细衬线小字、自述过长、把专业信息做成杂志散文 |
| RV1.3 紧凑双区编辑 | 主经历区与窄元数据区，轴线、间距、标题基线稳定 | RT01；RC01/RC03；RL02；RI01；RA01 | 左右阅读顺序不清、窄栏塞长句、联系与技能等权堆叠 |

### 专业系统家族（RV2）

以时间线、指标、能力矩阵或项目证据形成理性秩序，颜色只标角色和结果。适合商务、产品、技术、数据、运营、咨询、金融、工程、研究和管理等证据密集内容；不能制造不存在的量化比较，图标不替代可搜索事实标签。

| 方向 | 可见特征 | 参考搭配 | 避免退化 |
|---|---|---|---|
| RV2.1 企业治理网格 | 中性字、稳定分区、项目／职责／结果三层结构、低噪声边界 | RT01/RT04；RC01/RC05；RL02/RL04；RI02；RA01 | 默认蓝侧栏、技能进度条、所有经历同款圆角卡 |
| RV2.2 工程与数据履历 | 明确时间轴、等宽英数、技术栈标签、结果数字对齐 | RT04；RC03/RC05；RL01/RL04；RI03；RA01 | 伪代码背景、满页标签、关键词大于项目结果 |
| RV2.3 研究与学术文档 | 长文献友好字级、清晰层级与编号、出版／研究信息；获准多页时使用连续页眉 | RT02/RT05；RC01/RC02；RL03/RL05；RI01；无艺术标题 | 为美化删减作者、期刊、日期、DOI 或研究条件 |

### 作品证据家族（RV3）

以案例缩略图、项目编号、角色／约束／结果和作品索引为第一锚点。适合设计、交互、产品、内容、摄影、建筑等作品导向内容；缩略图必须绑定本人角色与事实证据，作品不能吞掉履历。

| 方向 | 可见特征 | 参考搭配 | 避免退化 |
|---|---|---|---|
| RV3.1 案例索引网格 | 1–3 个代表案例统一比例，旁列角色、时间、职责和结果 | RT01/RT03；RC01/RC03；RL04；RI04；RA01/RA02 | 作品墙过密、比例随机、案例无法回到事实 |
| RV3.2 编辑式作品叙事 | 一张主案例图、受控破格标题、线性事实区；获准后续页继承索引 | RT02/RT03；RC02/RC06；RL05/RL06；RI04；RA02/RA03 | 首屏像海报，姓名、岗位、联系和近期经历不可扫描 |
| RV3.3 产品／内容证据板 | 流程、界面、内容样例或成果截图与准确说明共轴 | RT01/RT04；RC01/RC05；RL04/RL06；RI05；RA01 | 伪造界面、虚构指标、截图业务文字无法核验 |

### 人物编辑家族（RV4）

真实人像、职业姿态与简洁版面共同建立个人识别，适合顾问、管理、讲师、服务、公共事务、创意总监及明确要求人像的人工阅读简历。ATS-first 不使用大幅艺术照；人像不能遮挡经历或替代能力证据。

| 方向 | 可见特征 | 参考搭配 | 避免退化 |
|---|---|---|---|
| RV4.1 规范职业肖像 | 3:4 证件照或克制半身照、自然肤色、稳定背景、明确身份区 | RT01/RT02；RC01/RC02；RL02；RI02；RA01 | 过度磨皮、AI 改脸、夸张商务背景、头像大于价值摘要 |
| RV4.2 编辑环境人像 | 真实职业环境、人像负空间与姓名／定位共轴 | RT02/RT03；RC02/RC04；RL05；RI06；RA02 | 道具暗示不存在的身份、风格化使本人不可识别 |
| RV4.3 领导力档案 | 克制人物图、关键影响范围、精选履历、治理型数据结构 | RT02/RT04；RC01/RC05；RL03/RL05；RI02；RA01 | 豪华黑金、空泛名言、头衔先于可验证业绩 |

### 创意表达家族（RV5）

以印刷、拼贴、插画、超图形或实验媒介为记忆点，同时保留独立事实层，适合艺术、时尚、品牌、音乐、文化、插画等 portfolio-hybrid。ATS-first 不使用；没有原生 HTML 降级或事实顺序不清时不采用。

| 方向 | 可见特征 | 参考搭配 | 避免退化 |
|---|---|---|---|
| RV5.1 平面印刷履历 | 有限套色、粗标题、网点／套印与清晰事实栏并置 | RT03；RC03/RC06；RL05/RL06；RI07；RA03 | 错版覆盖正文、成为活动海报而非简历 |
| RV5.2 档案拼贴履历 | 真实作品切片、票签、索引、扫描纹与项目编号 | RT03/RT05；RC02/RC06；RL04/RL06；RI08；RA02/RA03 | 胶带贴纸多于经历、虚构票据、来源不清 |
| RV5.3 插画个人系统 | 统一线条、角色或符号形成个人表达，事实区维持规则 | RT03/RT05；RC04/RC06；RL05；RI09；RA03 | 通用头像插画、随机涂鸦、技能被图标替代 |

用户明确希望互动或游戏语言时，可采用局部像素、窗口语汇和索引形成复古数字界面；窗口不得相互遮挡，不作为默认 ATS 结构。

## 字体、标题与配色

### 字体角色配方

RT 只规定字体角色与搭配起点，不把示例名称当作资源已就绪结论。实际候选先从 [字体推荐入口](../../../rendering/font-recommendation-list.md) 按语种、角色、形态和气质形成，并用真实姓名、职位、公司、时间、项目、技能、链接及中英混排试排；精选清单不是封闭白名单，查询脚本只提供候选、缺口和诊断。快速扫描、连续阅读、文本可选择／复制／搜索和 DOM 阅读顺序优先，不能以视觉效果破坏 ATS 可读性。视觉候选确定后，正式 HTML 再按 [字体资源与执行契约](../../../rendering/font-family-library.md) 核验实际 family、face、weight／style、许可、目标字形覆盖和 Web 加载，写入真实 DOM，并用 `shot.py` 检查缺字、非预期回退、混排基线、换行、伪粗体和裁切；本地安装记录不能替代目标端验证。用户锁定精确字体时，门禁失败必须请求确认，不得静默替换。

| 配方 | 角色结构 | 适用与边界 |
|---|---|---|
| RT01 中性无衬线履历 | 姓名粗体、标题中粗、正文常规、等宽数字 | 通用、ATS、企业；字级差与行距支持扫描 |
| RT02 人文衬线＋无衬线 | 姓名／章节衬线，事实无衬线 | 文化、管理、学术、人文；小字与链接不用细衬线 |
| RT03 展示字＋中性事实字 | 有性格的姓名／作品标题，无衬线事实 | 创意、作品型；展示字不进入公司、日期、链接和结果 |
| RT04 工程无衬线＋等宽字 | 几何标题、等宽英数／技术标签、无衬线正文 | 技术、数据、产品；等宽字不承载中文长段落 |
| RT05 学术衬线＋清晰无衬线 | 长文衬线或无衬线正文、稳定编号 | 研究、教育及获准多页 CV；引文／出版格式不因美化删改 |

### 原生艺术标题

| 配方 | 形式 | 使用边界 |
|---|---|---|
| RA01 克制粗黑姓名艺术字 | 中粗至特粗字形、字距和轴线建立识别 | 真实 DOM 文字，以字体、字重、字距与 CSS 实现，逐字、复制与搜索核验 |
| RA02 图文融合一级标题 | 中粗至特粗字形与人像或主作品形成受控遮挡／共轴 | human-first 或 portfolio-hybrid；文字准确、完整可读，不吞并事实 |
| RA03 粗印刷／粗笔手绘标题 | 套色、木刻、粗笔手绘或拼贴字形 | 仅 portfolio-hybrid 一级标题，以真实字体和 CSS 实现，逐字与缩放核验 |

所有姓名、正文和标题，包括 RA01–RA03，均使用真实 HTML 文字与 CSS，不生成标题图片，不把文字转图片或路径。此处“艺术标题配方”只表示可由真实字体、字重、字距、套色和可靠 CSS 实现的视觉强化；姓名即使是唯一焦点也仍须保持可选择、可复制、可搜索的 DOM 文字。装饰可另用内嵌 SVG，但不能代替文字；其他标题包括普通 H1 同样执行上文字体流程。ATS-first 保持线性阅读、复制和搜索。

### 色彩职责配方

颜色至少区分纸面／画布、正文墨色、次级文字、主色和强调色的职责；任何颜色都不能成为事实的唯一编码。

| 配方 | 色彩关系与用途 | 风险 |
|---|---|---|
| RC01 黑白灰＋单一定位色 | 兼容、事实优先；ATS、通用、学术 | 过浅灰导致打印不可读 |
| RC02 暖白＋深棕／墨蓝 | 出版感与自然人像；人文、管理、文化 | 低对比米色模板化 |
| RC03 黑白＋高对比强调 | 作品、技术、现代编辑，强调姓名或结果数字 | 强调面积过大像海报 |
| RC04 克制自然色 | 教育、公益、服务、手作，亲和与真实人像 | 柔和色压低事实层级 |
| RC05 企业深色＋清晰浅底 | 管理、金融、咨询、技术，稳定区分章节 | 大面积深底影响打印与阅读 |
| RC06 有限套色／品牌色 | 创意、作品、个人品牌，形成记忆 | 彩虹化、每页换主色 |

### 字级与分页约束

- 姓名是身份锚点而非海报标题；职业定位与最近／最相关证据在首屏可见。
- A4 可先试姓名 24–42 pt、定位 11–18 pt、章节 10.5–14 pt、正文 8.5–10.5 pt、日期 8–9.5 pt；正文不低于 8.5 pt，实际字形和打印可读性不足时提高，不靠压缩字宽塞入。
- 组织、职位、时间和成果对应清楚。技能以准确名称与证据表达，不用星级、进度条或百分比自评冒充测量结果。
- 颜色来自个人、作品或已有品牌偏好，强调只用于真正的定位信息；灰阶打印仍需读清层级，浅灰不能隐藏日期。
- 先以最长组织名称、长链接、最复杂项目和混合语种试排。章节尽量不单独留在页尾，经历跨页时有明确续接。
- 默认只排 1 页 A4。只有 Brief 记录用户明确要求多页时，后续页才继承字体、边距与索引；不重复巨大页眉，剩余几行应返回 Spec 重组文案，而不是填装饰。

## 页面关系与整页布局入口

RL 是页面关系策略，不替代 Spec 已确定的内容构图，也不代表必须采用某个模板。

| 配方 | 版面机制 | 适用与必须保留 |
|---|---|---|
| RL01 单轴线性履历 | 单列时间／内容轴向下推进 | ATS、通用、学术；DOM 与视觉顺序一致 |
| RL02 主经历＋窄元数据区 | 70/30 或 75/25 双区 | 人工阅读、企业；主区先读，窄区不放长句 |
| RL03 分章节出版页 | 页眉、章节、页码与长文节奏 | 管理、学术；获准多页时章节和日期连续 |
| RL04 证据矩阵 | 项目、角色、方法、结果按统一单元 | 产品、技术、设计；证据有优先级，不做同权卡片海 |
| RL05 人像／主作品＋事实轴 | 图片占一侧或上部，事实沿稳定轴 | 人工阅读、作品型；不挤压姓名、定位与经历主线 |
| RL06 编辑式跨页叙事 | 首页建立主张，后页按案例／经历接力 | 仅获准多页的 portfolio-hybrid；每页可独立识别并继承索引 |

下表仅提供现有实现的阅读入口；检索适配标签与关联组合以 CSS 目录为准。双区与实验布局不默认满足 ATS-first 的线性读取要求；不固定按职业或颜色套用。

通过 `search` 返回的 `related_combinations` 定位关联组合；完整布局正文见 [简历整页布局](../../../../assets/templates/css/layouts/resume-full-page.md)。编号 14–16 的完整组合由通用原子组装，没有独立的简历布局条目，需要时通过整页组合查询比较。

配色、字体家族、背景纹理和可选装饰可更换；列宽、图窗、回转形状、跨区关系和事实顺序不因换肤暗改。所采用结构应在实现中真实复用；若真实内容试排表明其不适配，可调整采用范围或返回候选比较并说明理由，不能只借配色或名称声称采用。填入真实文案、换字体后按 [简历模板共用约束](../../../../assets/templates/css/layouts/resume-full-page.md#resume-layout-contract) 在固定 A4 内试排。内容偏少时，可调整所选结构的栏宽、模块编排和图窗比例；若仍需靠空壳维持版面，则返回候选比较或改为自定义关系，不为保留原结构撑高卡片、栏目或图窗。确需补充信息时，仅依据已提供的事实，展开与目标岗位相关的职责、行动、成果或技能证据，不为填空添加无关模块；信息已充分呈现时，保留用于分组、焦点或阅读停顿的留白，不强制填满整页。无组合可复用时按同一容量与视觉重心要求组织原子；自然增高不能当作单页 A4 通过。纹理绑定背景／载体，清晰文字不继承模糊或根层透明。13 套布局的名称与源码由 CSS 布局库维护，本文只保留入口与映射，不另存 CSS。

## 容器与开放排版视觉决策

整页采用关系确定后，Visual 阶段必须在原 Brief 每页简历的对应条目中输出“容器与开放排版视觉决策”，先判断证据是否需要边界，再按 [容器视觉语法](../composition-layout.md#容器视觉语法开放排版优先语义容器按需) 选择容器家族；不能只写全局风格或留到 HTML 阶段决定，也不因此改变默认页数。

- 逐个说明容器名称、承载经历／项目、位置与主次；同页多个容器分别描述，共用效果可明确引用，但须写本页差异。
- 写清轮廓与圆角／切角、表面材质、填充配色及纹理／渐变、边框与边缘、阴影与厚度、透明度／模糊，以及内部留白、正文日期排列、与底图和照片的关系。未使用的效果明确写“无”，优先克制且可打印的表现。
- 只写可见效果的自然语言，不输出 CSS 参数、色值表或槽位契约；来源 ID 仅写入短采用记录；规则容器交给 HTML/CSS，复杂壳体按 [素材使用规范](../ai-coding/asset-prompt-guide.md) 准备，不改变事实、线性阅读与文本可复制性。
- 无需容器时明确写“开放排版、无容器”，并说明如何用对齐、段距或分隔线组织信息；不能为填字段强加卡片或卡片嵌套。
- 普通白色圆角矩形只用于确需独立分组的摘要或作品证据，不能把经历、项目、技能全部拆成同款卡。创意简历可使用档案页、文件夹／口袋、报纸分栏、撕纸衬底、照片相框或切角铭牌，但须保留文本复制顺序、灰阶打印与 ATS 辅助阅读。
- 将本页效果写入视觉验收重点，检查实际边缘、材质、对比、长经历容量和灰阶打印；不得仅凭“高级容器”等名称判为完成。

### 常用局部容器

简历默认优先开放阅读栏、对齐和分隔线，只有确有信息分组或作品展示需要时才使用容器。

| 常用容器类型 | 常见用途 | 视觉选择与边界 |
|---|---|---|
| 中性圆角容器（非默认） | 技能摘要、联系信息与单个重点项目 | 稳定分组成立时使用低圆角、薄边或浅色面；经历正文不拆成卡片墙 |
| 阶梯面板 | 姓名区、职业摘要与精选成果 | 细框克制，保证打印和灰阶对比，不制造证书感 |
| 圆角纤维纸张 | 创意简历的个人陈述或作品摘要 | 仅用极弱纸纹，ATS 辅助阅读与可复制文字优先 |
| 照片衬纸与胶带 | 头像、作品图与真实项目图片 | 只承托图片，不能把装饰纸片伪装成项目证据 |
| 胶囊与徽章 | 技能标签、语言等级与短状态 | 限少量短标签，不得成为密集胶囊云 |

### 局部布局补充能力

这些能力仅用于补足已选整页结构，不是完整模板库清单，也不替代整页组合比较。可按实际需要采用紧凑内容、宽松内容、规整对齐、疏朗留白、章节眉线或受控叠层：压缩组距而非可读字号，明确共同基线、正文轴与图片归属，叠层写清主副片及保护区。没有合适局部能力时保留自定义关系，不为命中原子改写内容。

### CSS 原子能力校验

整页采用关系和局部方向形成后、最终 Brief 冻结前，将已选效果拆成下列自然语言能力词并执行公共限量查询。这里只验证能力与边界，选定后将库 ID、源路径与版本写入短采用记录，不复制代码或参数，不能反向新增视觉决定或推翻整页结构。

| 决策维度 | 查询能力词 | Brief 保留内容 |
|---|---|---|
| 布局 | 阅读轴、主图关系、网格、错位、叠层等实际关系 | 图文主次、阅读路径与开放／分组方式 |
| 字形 | 填字、描边、浮雕等可见效果与文字角色 | 哪组原生文字采用何种效果、作用与可读边界 |
| 形状 | 已选容器、图窗、纸边、徽章或其他轮廓 | 轮廓服务的真实内容与本页差异 |
| 表面 | 纸张、玻璃、塑料、织物、金属、柔焦等已选材质 | 材质承载对象，正文如何保持清晰 |
| 配色与背景 | 色彩职责、渐变／弥散方向、纹理与覆盖范围 | 色彩关系、背景变化、静区与保护范围 |
| 作用对象与边界 | 字体、卡片、背景、局部装饰及复杂素材部分 | HTML 与图片分工、必要降级及验收重点 |

候选摘要证明确实可实现后，把最终可见结果写回原 Brief；没有适用候选时保留已选方向，说明由素材或原生实现承担。真实引用、依赖、参数和消费者只进入后续最终 HTML。

### 人像与作品处理

按 Spec 使用与当前候选人对应的人像参考图及其真实短链，不由 Visual 擅自换人或取消。合格本人照片直接确定性裁切为 3:4；需要编辑时把该图作为图1传入图片编辑工具，保持头顶、下巴、肩部、面部结构和自然肤色，照片尺寸不能压缩证据正文。

获准编辑时只调整背景、曝光或非身份干扰；不改变五官、年龄、肤色、体型、发型和服装身份，不生成不存在的职业环境冒充任职经历。发生漂移回用原图，缺照片返回 Spec 记录待补。

作品截图不得重画成更高级的项目；裁切保留说明当前成果所需上下文，隐私处理按用户授权。环境人像只在已规划时作附加，不替代规定的证件照。

创意背景、插画、扫描纸片仅承担视觉，不得看起来像真实奖状、证书、客户项目或成绩。简单分区、规则线和数据图形直接 Coding，无需为了调用工具增加图。

## 形成每项素材生产意图并编译 Prompt

每项待生成或编辑图先在 Brief 记录用途、目标页、画面目标、处理方式、来源、参考职责、主体与背景关系、保护和禁用项。冻结 Brief 后，在素材清单中补比例、尺寸、安全区、消费者与准出标准并编译完整 Prompt；风格是首要信息，先写具体风格与特征，再写主体、数量、背景、材料、构图、视角、明暗、留白与保护范围。

普通 Prompt 只描述画面，不写姓名、经历等文案、字体排版，也不写“无文字／无字／no text”等文字否定词。简历不存在整图生字例外；直接使用照片或项目截图只写使用说明。

参考图用图1、图2标明主体来源、风格参考或待编辑原图；真实短链在 Brief 对应图片条目中记录并同序传给工具。Prompt 不写 URL、路径或工具参数，短链待补时不调用依赖该图的编辑。证件照的图1必须是当前简历人员本人，不能使用相似职业人物或通用头像。

## 视觉验收

- 按目标纸张和屏幕宽度核对每页，重点经历完整、没有溢出或过小字；同时检查实际内容是否集中靠上、页尾是否存在无职责的大块空白，以及卡片增高后内部是否仍挤在顶部。发现问题先在所选结构内调整尺寸与间距并复验，不以无溢出代表排版完成；默认一页 A4 不以自然增高通过。
- 从导出文件复制文本，核对姓名、联系、组织、职位和日期顺序；搜索实际关键词，检查字体与链接。
- ATS 未在真实渠道验证时如实写明，不能把一次文本抽取等同于所有系统兼容。
- 照片身份准确、作品归属真实；移除装饰后仍保留完整履历。
- 日期、结果、证书与原材料一致，全部标题及正文为可编辑原生文字，不用压平图片伪装成可搜索简历。
- 核对实际采用的整页结构与说明一致，不能只换配色却声称复用了组合。

将本任务的阅读模式、字体层级、页面网格、证据主次、人像／作品处理、跨页连续、打印／ATS 适配、素材职责和降级写入 **视觉效果生产规范**；将上述实际纸张／屏幕可读性、复制搜索、身份事实、页间完整性和能力边界检查写入 **视觉效果验收规范**。
