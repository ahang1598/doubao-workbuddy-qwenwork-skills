# 4.5 模型改写规则

> 适用范围：仅供已选 `pure-image` 的任务读取。品类／平台规则在前，模型改写在后，见 [纯生图读取路由](../../../workflow/creation/pure-image.md#品类-ref-路由) 与 [指令合同及模型接力](../prompt-guide.md#14-产物知识与模型改写接力)。本 ref 不决定生产轨道、工具字段、Workspace、串并行或交付；这些全部服从宿主原 workflow 与 [交付门禁](../../../workflow/image-generation-delivery-gate.md)。用户指定数量、原文、参考身份和编辑范围优先于默认建议。


## 用途
- 选择4.5模型进行生图时读取，明确生图prompt的改写和推演规则
- 需搭配各产物 reference 的平台特征、风格调性、尺寸、安全区、品类结构、视觉风格和合规红线共同完成改写。
- 只规定 Prompt 改写方式，不新增模型参数，不改变宿主实际生成／编辑工具、提示词、画幅和参考图入参。
- 最终 SP 是一段精简自然语言。画幅按宿主已有参数传入，不新增 ratio 字段。

## 接力前提

- 不得脱离产物 / 场景特征 reference 单独使用。
- 先完成产物路由；命中具体产物时，先读取对应产物 reference，提取产物结构、风格调性、平台画幅与安全区、信息层级、系列图、核心资产和合规要求，未命中具体产物时，使用宿主纯 AI 成品图指令指南中的完整成品 Brief 作为底稿。
- 再用本文件完成 4.5 改写。

## 通用原则

- 根据用户输入长度做核心提炼或合理扩充，品牌名、产品名、活动名、人名等专有信息必须逐字保留。
- 每张图分别形成独立、完整、可视觉化的中文 Prompt，不使用“同上”“其余一致”“若干元素”等省略表达。
- 最终传入图片工具的 Prompt 必须合并为一段连贯中文，不保留内部小标题、规划字段或工具字段。
- 平面设计只描述目标平面载体；除非目标是样机或空间展示，不添加无关现实背景。
- 先读取目标产物 reference，再将其中的平台特征、画幅、安全区、品类结构和红线合入本规则。

## 关键词使用规则

关键词只用于补充 4.5 的分维度描述，不能替代视觉载体决策。必须先判断画面是“图片主导型”“图文平衡型”还是“文字主导型”，再从下表选择与该模式匹配的词。默认优先图片主导型或图文平衡型；只有用户明确要求大字报、纯文字海报、报价单、规则页、信息图或文字排版时，才允许采用文字主导型。

构图词与照明词必须分开解释：“放射构图／向心爆发”只表示平面对象、实色线条、纹样或信息单元围绕焦点排列，不等于放射性光线，也不得自动扩写成顶部聚光、光束、太阳芒／耶稣光、舞台追光、体积光、闪电／雷霆光纹或镜头光晕。庆典、隆重、红金、金色、丝绸／绸缎同样不构成光效授权；仅用户明确要求具体光效或明确保留参考中的该光效时才能加入。

**拼贴不是默认风格**：只有用户明确提到拼贴、手账拼贴、照片墙、剪贴簿、叙事拼贴，或任务确实需要 2 张及以上图片共同讲述内容时，才选择“拼贴 / 贴纸 / 自然层叠 / 局部遮挡”等词。单张产品、人物、场景、文章封面和普通社媒配图默认使用单一连贯主视觉，不自动加入拼贴、照片墙、便签堆叠或多张配图。

### 视觉载体决策与图文比例

在完成总览句前，内部必须先锁定以下模式，并将模式转译成最终 Prompt 中的明确结构：

| 模式 | 适用条件 | 图片 / 主视觉面积 | 文字面积 | 必须写清 |
|---|---|---:|---:|---|
| **图片主导型** | 人物、产品、食品、场景、穿搭、美妆、生活方式、封面、普通社媒配图 | 65%–80% | 10%–20% | 1 个完整主视觉主体；标题只作辅助，不得占据主体区域 |
| **图文平衡型** | 教程、测评、经验分享、品牌内容卡、图文说明 | 50%–65% | 20%–30% | 至少 1 个清晰主视觉，文字与图片形成对应关系 |
| **文字主导型** | 用户明确要求大字报、金句海报、规则页、信息图或数据图表 | 25%–45% | 40%–60% | 文字主标题、信息模块和至少 1 个图形/插画/图表载体；不能只有文字铺满背景 |

- 除非用户明确要求无图或纯文字，最终 Prompt 必须写出至少一个可识别的图片、插画、产品、人物、场景、物件或图表主体，并说明其位置、大小和状态。
- “配图”必须写成实际可生成的视觉对象，例如“右侧占画面约 40% 的咖啡杯与蒸汽微距照片”，不能只写“配一张图”“加入相关配图”或“图文结合”。
- 文字主导型也必须保留视觉锚点。若没有用户提供事实数据或具体内容，不得用虚构小图表、密集说明文字或无意义装饰填充。
- 面积比例是初始结构约束，不是把画面切成机械矩形；应通过主体尺度、留白、叠压、跨栏和阅读动线实现。除非用户明确要求规整网格，图片与文字不要平均切半。
- 最终 Prompt 中必须出现一组明确关系，例如“主视觉位于右侧并占主要面积，标题位于左上留白区”“产品照片压住纸张边缘，短注释沿照片底边排列”。不能只罗列图片和文字清单。

| 维度 | 无序可选关键词 |
|---|---|
| 风格 | 手绘、摄影、复古、插画、杂志编辑感、涂鸦、扁平、极简、3D/C4D、胶片、电影感、水彩、半调网点、现代主义、瑞士编辑、实验字体、Y2K、丝网印刷、黏土、国潮 |
| 构图 | 居中、特写、留白、俯拍、近景、正面平视、网格、九宫格、三段式、分区、对称、卡片式、非对称网格、半身、仰拍、俯视、广角、低机位、斜角、竖版长图 |
| 排版 | 手写字体、标签、标注、衬线体、无衬线体、描边、字幕条、箭头、大标题、高亮块、字号层级、字重层级、标题块、信息条、随性排版 |
| 色彩与背景 | 渐变、荧光点缀、黑白强对比、焦糖暖色、暖光、撞色、高饱和、柔光、低饱和、逆光、高级灰、冷调、霓虹、品牌主色底、真实生活场景、深色背景、纯白背景、彩色纸张、纹理纸、中性灰背景 |
| 质感与氛围 | 纹理、肌理、颗粒、纸张压痕、胶片颗粒、哑光、光晕、水雾、手工感、生活感、松弛感、纪实感、自然光、真实环境 |
| 随性与非商业化 | 非商业化、低广告感、素人抓拍、原生发布感、日常记录感、纪实快照、自然留白、轻微瑕疵、轻修图、手写注记、编辑部草稿感、克制装饰、单点点缀、拒绝堆砌 |

**条件词库（仅在触发对应结构时使用）**：

- **拼贴条件词**：拼贴、照片拼贴、剪贴簿、照片墙、叙事拼贴、贴纸感、便签、自然层叠、局部遮挡、不规则错落。触发条件是用户明确要求拼贴类视觉，或任务确实需要 2 张及以上图片共同叙事。
- **手账条件词**：手账、线圈本、纸胶带、撕裂纸张、荧光笔涂痕、手写注记、纸张压痕。触发条件是用户明确要求手账、日记、笔记本或文具拟物骨架。
- **印刷条件词**：剪纸、活字印刷、套印错位、油墨晕染、印章压痕、网点印刷。触发条件是用户明确要求报纸、复古印刷、版画、油印或印刷工艺。
- 未触发条件时，最终 Prompt 不得从条件词库中选词；纸张纹理、颗粒或轻微手工痕迹可以作为局部材质，但不得升级为拼贴构图。

## T2I 文生图改写

### 固定结构

按“总览句 → 分区扫描主段落 → 条件收束 → 画幅确认”完成内部方案，再整理成一段连续 Prompt。

1. **总览句**：先说明横版、竖版或方形方向，再前置核心风格、色彩影调和画面类型；首句不写具体比例数字。
2. **分区扫描**：占主体篇幅。按从上到下、从左到右、从外到内或从背景到主体的物理空间顺序逐区展开。
3. **条件收束**：元素较少且存在统一视觉特征时，用 1–2 句收束整体配色、排版、光影和氛围；复杂画面可省略。
4. **画幅确认**：内部方案确认目标比例；工具调用时按已有画幅参数传入，不把比例字段或像素尺寸写进最终 Prompt。

### 三层推演

先确定载体骨架，再确定场景语义，最后完成实例填充：

- **载体骨架**：画面类型、物理分区、阅读顺序、主体位置和信息层级。
- **场景语义**：用户目标、平台阅读场景、传播语气、品类特征和视觉方向。
- **实例填充**：把每个可见元素、文字、图形、材质、光影和关系写成可直接生成的具体内容。

### 基础 9 维

分区内的每个重要元素必须覆盖以下维度；具体枚举和平台化写法以目标产物 reference 为准：

1. **绝对位置**：使用明确方位、占比、对齐和空间关系，避免“旁边”“附近”“大概”。
2. **元素类型**：写明主体、标题、标签、卡片、图标、道具、背景或装饰的具体类型。
3. **形态细节**：说明轮廓、组成、姿态、角度、材质和可见结构，不只写功能名称。
4. **内容描述**：图片写清主体、场景和状态；文字逐字写出真实文案。
5. **文字视觉样式**：写清字体气质、字号层级、字重、字色、底色、边框、描边和必要特效。
6. **状态信息**：说明人物表情、物体状态、界面状态、动势或变化状态。
7. **关联关系**：说明元素之间的对齐、层叠、遮挡、指向、比例、主次和阅读顺序。必须先写明图片主导型、图文平衡型或文字主导型，再写图片与文字的面积比例、对应关系和阅读动线；不能只写“图文并茂”。
8. **风格特征**：从目标产物 reference 选择与任务匹配的明确视觉风格，不使用空泛的“高级”“好看”。
9. **视觉处理工艺**：写清光线、阴影、颗粒、印刷、拼贴（设计时必须是复杂、分层的编辑日志拼贴，具有原始、个人化的叙事感，严禁简单的平铺拼贴）、描边、辉光、纹理或渲染处理。

### 图片与配图强制规则

- **先有主体，后配文字**：图片主导型和图文平衡型必须先确定主视觉主体、景别、视角、位置和面积，再安排标题、标签与说明；不得先铺满文字再在空隙里塞一张小图。
- **单主体默认单图**：没有明确拼贴信号时，默认只生成一个完整、连续、可识别的主视觉主体；不添加随机人物、随机产品、多张小照片、照片墙、贴纸阵列或无关插画。
- **多图必须有角色差异**：只有确需多图时，逐一写明主图、环境图、动作图、细节图或对比图的角色、数量、景别和位置；每张辅助图都必须解释它补充了什么信息。
- **配图必须可见且有体积**：图片、插画、产品或图表不能只作为角落图标或极小装饰出现；图片主导型的主视觉不得小于画面约 55%，图文平衡型的主视觉不得小于画面约 35%。
- **文字不能吞没图片**：除文字主导型外，主标题、标签和说明合计不得占据画面主体区域；当文字数量增加时，应减少文案或拆分页面，而不是压缩主视觉。
- **禁止空泛的图文指令**：最终 Prompt 不得只出现“图文结合”“搭配配图”“加入插画”“丰富画面”等抽象表述，必须替换成对象、位置、面积、关系和内容。
- **拼贴触发条件**：未满足拼贴触发条件时，最终 Prompt 不得使用“拼贴、照片拼贴、剪贴簿、照片墙、贴纸堆叠、便签堆叠”等词。手撕边缘、胶带、纸张纹理也只能作为局部材质，不得自动改变为拼贴构图。

### 平台增强维度

- 命中媒体、电商、品牌、知识教育等专门产物时，在基础 9 维后补入对应 reference 规定的平台强调维度。
- 媒体类现有规则中的第 10/11/12 维必须保留，用于约束点击钩子、平台识别、信息密度、主体占比、UI 安全区或该平台特有的视觉结构。
- 平台增强维度必须转译成画面结构、阅读场景和视觉语言；最终 Prompt 不直接写平台名或内部路由名称。

### 描述密度

- 简洁平面设计的设计方案不少于约 600 字符。
- 中等信息量的营销海报、社媒封面或界面不少于约 1200 字符。
- 多人、多区域或复杂界面场景不少于约 2000 字符。
- 每个独立元素都应被覆盖；重复元素写明数量及实例差异。
- 所有可见文字必须逐字写出；每个独立元素至少包含一个明确颜色词。
- 长描述持续使用绝对方位词和空间衔接词，保证分区关系可以复现。

## I2I 图生图改写

### 固定结构

按“编辑目标 → 保留项 → 编辑项 → 空间线性描述”完成内部方案，最终合并成一段连续 Prompt。

1. **编辑目标**：直接说明来源图片、编辑对象、目标状态和作用范围。
2. **保留项**：明确主体身份、产品或包装结构、构图关系、位置比例、透视角度、光影方向、材质细节、文字样式和层级关系中不能改变的内容。
3. **编辑项**：逐项写明删除、替换、新增、背景替换、文字改写、比例改版、属性修正、局部重绘或结构重排。
4. **空间线性描述**：按物理空间顺序串联每个编辑区域的位置、原图内容、保留内容、修改动作、目标结果和融合约束。

### 参考图规则

- 多张输入图按工具传入顺序使用 `[img0]`、`[img1]`、`[img2]` 标明作用，不得混用。
- 少复述旧图，多描述目标图。新载体或新场景应让目标画面占主要篇幅；品牌、包装等现有 reference 明确要求时，目标图描述不少于 Prompt 的 70%。
- 只提取任务需要继承的主体、结构、品牌识别、配色比例、字体气质、纹样、材质、光影或版式锚点。
- 旧背景、旧裁切、偶然道具、噪声和无关文字不作为锚点，除非用户明确要求保留。
- 不得只写“参考原图”“保持不变”“其他不变”；保留项和修改项必须具体。
- 文字替换必须逐条写明原文案、目标文案、位置以及需要保持的字体、字号、字重、颜色和对齐方式。

## 平台尺寸与画幅适配

- 用户明确比例或尺寸时优先遵从；否则使用目标产物 reference 的默认比例和安全区。
- 多平台、多比例或多尺寸任务按用途分别生成，每张图独立确定 `ratio` 和构图，不把不同正式产物合并到同一画布。
- 比例变化不是机械裁切。必须重新安排主体占比、留白、标题位置、信息密度、CTA 和安全区。
- 工具字段按宿主现有协议使用，不在 ref 中推导或新增参数；不在 Prompt 中加入像素尺寸、比例字段或画幅参数。

## 系列图与前图参考

- 用户要求系列图、套图、连续页或延展前图时，先规划每张图的角色、信息任务、排版分组和依赖关系。
- 一旦存在上传图、用户指定前图或已确认核心资产，后续一致性延展必须使用 `image_edit`，并把对应图片加入参考图列表；不得仅凭文字用 `image_gen` 重画近似版本。
- 系列一致性分为两层：跨全套统一品牌层锚点，同角色分组统一排版、图文比例和信息密度等角色层锚点。
- 首张或核心图负责建立全局锚点；新角色分组的第一张以上传前图或核心图为参考，同组后续图可同时引用全局锚点和同组前图。
- 不机械地让每张图只参考上一张。根据用户指代、核心资产、角色分组和主体匹配度选择参考图。
- 用户明确说“基于上一张”“延展这张”时，必须把被指向的前图作为参考，并在 Prompt 中写清 `[imgX]` 的保留作用和修改范围。
- 同一组多图保持参考图顺序和锁定变量一致；每张图仍需独立完整描述，不得使用“同上”。
- 系列图共享核心资产和视觉语言，但每张图必须承担不同功能，并在构图、场景、信息层级、镜头、背景或物料角色中形成真实差异。

## 文字与事实纪律

- 中文待渲染文字使用中文双引号，例如：`“中文文案”`；英文待渲染文字使用英文双引号，例如：`"English copy"`。
- 中文与英文混排时分别使用对应引号；不得用中文引号包裹纯英文文案。
- 禁止使用 `XX`、`某某`、`标题文案`、`待补充文字`、`相关说明`、`若干文字`、`同上`、`占位符` 等让模型自由补字的表达。
- 高密度信息物料先建立可见文字清单；最终 Prompt 只渲染清单中的文字，并把文字与对应容器、位置和层级绑定。
