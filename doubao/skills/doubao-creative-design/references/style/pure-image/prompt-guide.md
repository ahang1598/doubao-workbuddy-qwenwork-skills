# 纯 AI 成品图生成与编辑指令指南

本文件只服务于 [纯生图创建](../../workflow/creation/pure-image.md) 与 [纯生图编辑](../../workflow/editing/pure-image.md)：图像工具输出本身就是最终交付图片，不再进入 Coding/HTML 覆字或组装。它负责把已经确认的用户意图和轻量 Brief 编译成清楚、可执行、可核验的 `image_generate`／`image_edit` 指令；比例、核心资产身份与画质继续遵循 [图像质量指南](../shared/image-quality-guide.md)，持久化与交付服从宿主 workflow。

## 1. 编译原则

### 1.1 先写指令合同

调用图像工具前，先从用户原话、参考图和已确认 Brief 写出：

```yaml
operation: image_generate | image_edit
deliverable: 成品类型与使用场景
canvas: 最终宽高、比例、方向
content_goal: 观众第一眼看到什么、随后理解什么
source_inputs: 参考图、编辑目标、核心资产；无则写 none
must_keep: 编辑时不可改变的主体、文字、构图或区域
must_change: 本轮唯一改动集合
visual_thesis: 一句话说明核心画面机制
composition: 主体区域、占比、景别、视角、动线、负空间与裁切
visual_language: 媒介、形态、时代／文化语汇、色彩、光线、材质与边缘
visible_text: 允许进入画面的准确文字；无则写 none
must_not_include: 与当前任务相关的禁止项
quality_target: 结构、清晰度、材质、边缘和目标尺寸要求
```

合同缺少画幅、核心主体、构图或编辑范围时先补 Brief，不用“自由发挥”“合理调整”“更高级”代替决定成品身份的约束。

### 1.2 用可观察描述代替标签堆叠

- 把“高级”写成留白比例、低饱和色域、单一光向、材质和对比层级。
- 把“电影感”写成镜头距离、机位、焦点、景深、光比、色温与颗粒。
- 把“有冲击力”写成主体占比、越界、透视、明暗冲突、动线和视觉焦点。
- 把“可爱”写成轮廓圆润度、比例、表情、色彩明度、材质和细节密度。

每项形容词至少对应一种可在结果中指出位置的视觉事实。不要堆艺术家名、平台热词、渲染器名和互相冲突的风格词；使用一个主视觉语言，最多一个辅助母题。

构图与照明是两类独立决定。“放射构图／向心爆发”只表示平面对象、实色线条、纹样或信息单元围绕焦点排列，不等于放射性光线；庆典、隆重、红金、金色、丝绸／绸缎也不自动产生光源。只有用户明确要求某项光效，或明确要求保留参考图中的该项光效时，才可加入顶部聚光、放射光束、太阳芒／耶稣光、舞台追光、体积光、闪电／雷霆光纹或镜头光晕。

### 1.3 按观看顺序写，不按关键词清单写

生成指令采用“整图目的 → 主体 → 画面区域 → 空间关系 → 风格与光材质 → 质量 → 禁止项”的顺序。编辑指令采用“编辑目标 → 必须保留 → 指定区域改动 → 新旧融合 → 输出要求”的顺序。最终写成连贯自然语言，让每句都能改变画面或约束错误。

### 1.4 产物知识与模型改写接力

先读取命中的品类与平台 ref，把结构、视觉特征、安全区、核心资产和合规边界写入同一份自然语言指令合同；再读取已选模型 ref 做轻量改写。模型 ref 不得另建 Brief JSON、参数计划或平行事实源，也不得改写用户锁定的数量、原文、参考身份和编辑范围。最终调用与交付继续服从宿主 workflow。

## 2. `image_generate` 指令

生成完整成品图时按以下结构编译：

1. **产物与画幅**：说明成品类型、使用场景、方向、比例和最终像素尺寸。
2. **传播目标**：说明第一视觉、第二阅读信息和期望情绪，不写泛化营销口号。
3. **核心主体**：明确数量、身份、动作、表情、朝向、景别、视角、轮廓和不可缺少的特征。
4. **构图扫描**：按上→下、左→右或前→后描述区域；给出主体占比、焦点位置、视觉动线、负空间和安全边缘。
5. **元素关系**：说明人物／产品／场景／标题区如何承托、遮挡、穿插、呼应或共同指向焦点，避免“左图右字”式互不作用。
6. **视觉语言**：明确媒介、形态、色彩职责、光源方向、材质、边缘、颗粒和空间层次。
7. **文字**：只写允许出现的准确源文字、位置与层级，并要求除它之外不生成任何字符。
8. **质量与禁止项**：加入与主体结构、身份、裁切、杂物、文字、水印和目标清晰度有关的少量关键约束。

Prompt 必须说明完整成品，而不是只描述一个孤立主体。人物、产品或物体存在时，同时写清它与环境、前景、光影和留白的关系；场景存在时说明前中后景或平面层级。不得用“丰富背景”“加入一些装饰”授权模型随机填充。

### 2.1 参考图使用

- **内容参考**：只继承指定主体、物件、姿态或场景事实。
- **风格参考**：只继承构图机制、色彩职责、光线、材质、形态或边缘语言，不复制参考图中的人物身份、文字、Logo 和偶发细节。
- **同款／复刻**：先列出必须对应的构图、比例、层级、视觉机制与允许替换内容，再生成；不得只写“按参考图风格”。
- **核心商品、品牌或 Logo**：不得靠文字描述重绘，必须改走 `image_edit` 并绑定已确认母版。

## 3. `image_edit` 指令

编辑指令默认最小改动。用户没有点名的主体身份、构图、视角、光向、比例、文字和清晰区域全部列入 `must_keep`；不得为了“统一风格”顺带重画整张图。

按以下结构编译：

1. **编辑目标**：第一句直接说明本轮只改什么，以及成品仍用于什么场景。
2. **保留项**：逐项写出主体身份、五官／商品结构、Logo、已有准确文字、姿态、镜头、画幅和不编辑区域。
3. **改动区域**：使用可定位的区域、对象或边界描述，说明删除、新增、替换、重绘、换色、换材质或扩图的具体结果。
4. **几何与遮挡**：说明新增元素的大小、方向、前后层级、接触点、投影和不得遮挡的部位。
5. **融合约束**：新内容必须匹配原图的透视、焦距、景深、光向、色温、噪点、材质、边缘锐度和颗粒。
6. **输出约束**：明确最终尺寸、比例、是否扩画幅，以及除指定改动外保持像素级稳定的要求。

不要把原图从头复述成新的生成 Prompt。编辑区域很小时，用“保留整图，仅在……”开头；替换背景时仍明确保留主体边缘、接触阴影和身份结构；删除物体时要求根据周边空间连续补全纹理、光影和遮挡关系，不留下复制纹、空洞或模糊块。

### 3.1 常见编辑类型

- **局部删除**：指明对象及边界，要求恢复被遮挡的背景结构和纹理。
- **局部新增**：指明位置、尺寸、朝向、层级、接触关系和匹配的光影。
- **替换环境**：锁定主体身份与轮廓，描述新场景的透视、地面、光向和反射如何承接主体。
- **改色／改材质**：限定对象与区域，保留明暗结构、纹理尺度、接缝、印刷和 Logo。
- **扩图**：先写最终画布尺寸与扩展方向，锁定原图位置和尺寸，只在新增区域延续空间；禁止拉伸原图。
- **文字修改**：只替换指定字符串，保留文字框位置、字形风格、层级和其他像素；结果仍须逐字核验。

## 4. 文字与身份边界

- 生产路线已由主 SKILL 的品类与意图确定，本文件不因姓名、日期、价格、正文或 Logo 重新分流。图内文字必须有准确来源并逐字核验；二维码等功能内容使用已提供的真实输入并核验实际可用性，不凭外观声称可用。无法满足明确的功能／逐层编辑要求时报告具体冲突，由主流程处理，不私自切换路线。
- 允许生成文字时，Prompt 使用引号列出唯一 `source_text`，明确字数、断行、区域、视觉层级，并禁止额外文字、乱码、伪 Logo 和水印。生成后必须逐字核验，不凭“看起来像”判通过。
- 用户上传的人物、商品、包装、品牌或 Logo 是身份锚点。承载该身份的任务使用 `image_edit`；指令列出轮廓、比例、结构、颜色、标记和不可改区域，不用“类似”“同款”替代身份保持。
- 不把参考图中未经用户授权的商标、人物身份、签名、水印或可识别作品细节带入新图。

## 5. 调用前自检

调用前逐项确认：

- 指令第一句能否回答生成什么成品，或只编辑什么；
- 最终尺寸、比例、方向与 Brief 是否一致；
- 是否只有一个明确第一视觉，且主体数量、位置、占比、视角和安全边缘可执行；
- 是否描述了主体与环境、文字区和其他元素的空间关系；
- 风格是否落实为色彩、光线、材质、形态和边缘，而非标签堆叠；
- `image_edit` 是否同时包含明确 `must_keep` 与 `must_change`，且未授权区域不会漂移；
- 核心身份是否绑定真实图像输入，而非纯文本重绘；
- 可见文字是否来自唯一准确源，禁止项是否针对当前任务；
- 指令是否存在互相冲突的机位、光线、媒介、时间或材质要求；
- 每句话是否能在结果图中被观察和核验。

任何一项为否，先改指令再调用工具。生成后按 [图像质量指南](../shared/image-quality-guide.md) 和纯生图 workflow 核对尺寸、结构、身份、文字、边缘、未授权变化及交付状态；AI 图中文字问题遵循宿主规则，只如实披露并等待用户明确要求，不自动重生。

## 6. 示例

### 6.1 完整生成

```text
生成一张 1080×1440、3:4 竖版生活方式封面，主题是雨后清晨的城市骑行。第一眼看到一名穿浅灰防风衣的年轻骑行者从画面左下驶向右上，人物与自行车占画面高度约 58%，低机位中景，车轮、手脚和车架结构完整；随后看到湿润街道反光形成的对角动线和右上方开阔晨光。顶部 18% 保留低纹理浅雾负空间，人物头部不进入该区；近景有一小片虚化树叶，中景为骑行者，远景建筑柔和但保持垂直透视。采用清透纪实摄影结合克制编辑色彩，冷灰蓝为主，晨光暖黄只出现在道路反射和轮廓边缘；光源来自右上方，地面接触阴影与反射方向一致，颗粒轻微。
```
