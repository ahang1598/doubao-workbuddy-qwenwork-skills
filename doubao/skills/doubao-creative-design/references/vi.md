# VI 题材规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

目标：依据获准范围与确认身份，建立可识别、可复用、有差异且适应真实载体的品牌视觉系统。用准确规则说明怎样使用，用真实尺寸平稿和相关场景证明怎样落地，不以 Logo、色块和随机样机代替完整 VI。

适用产物： VI Lite、VI Core、VI Full、已有 VI 整理、局部应用及整体重做。按授权范围形成身份总览、使用规范、应用平稿、场景与完整展示。

**核心流程**：了解品牌与确定范围 → 确认 Logo 与使用方式 → 建立基础视觉规范 → 设计应用物料 → 编排 VI 展示 → 核对与交付。

共用事实与唯一 Brief 引用[共用规范](common.md)；生产、授权与批准遵循[主入口](../SKILL.md)；状态、两轮确定性修复及宿主交付引用[质量规范](quality.md)。将品牌事实、视觉规则、应用与交付说明写在同一 Brief 中，不另建平行资料。

## 1 了解品牌与确定范围

### 步骤1：核实品牌与任务

核实准确名称、业务、受众、实际价值、使用环境、语种、文案、资产来源、真实尺寸、材料和制作资料。说明受众需要查找什么、判断什么、完成什么，不用泛化品牌故事填补事实缺口。

区分用户事实、参考信息和设计提案。参考只借鉴已说明的构图、风格、材料或应用方法，不移入参考品牌的名称、历史、客户、承诺或身份。

| 任务入口 | 确认内容 | 范围限制 |
| --- | --- | --- |
| 新建 VI | 品牌事实、Logo 状态、核心触点、所需系统与交付形式 | 先确认身份，再开展依赖身份的视觉设计 |
| 整理已有 VI | 已锁定的 Logo、字体、颜色、图像及可调整部分 | 保留来源与版本，不把整理变成全面重设计 |
| 局部应用或续改 | 指定物料、修改对象、原稿尺寸和受影响内容 | 不自动扩成完整系统，不因此重生首屏 |
| 整体重做 | 可保留、可延展和可重设计的具体对象 | 不用“整体优化”模糊授权范围 |

成品文案与规划说明分开。核实价格、参数、日期、认证、联系方式、员工身份及权限；缺少事实时按共用规范处理，不把生成场景当作真实门店、人物或落地案例。

### 步骤2：选择范围等级

按任务深度、真实触点和需要验证的载体选择范围，不单凭公司大小分级。Brand Board、连续长板和分页是展示形式，不是范围等级。

| 范围 | 适用场景 | 具体组成 | 应用要求 |
| --- | --- | --- | --- |
| VI Lite | 聚焦少量核心接触场景、快速建立基础识别，或需要紧凑展示 | 已确认 Logo 及必要家族、颜色职责、字体角色、至少一类真实核心资产或应用证据、紧凑 Identity Kit | 选择最相关的 **3–5个连续核心触点**。体现真实使用链，不扩成完整手册 |
| VI Core | 需要多个相关载体保持一致，并说明系统怎样变化 | Lite 内容，加图像语言、固定与可变方法、主要深浅背景状态及跨应用关系 | 通常覆盖**至少两类相关应用**，展示母版、真实平稿与场景的对应；不以物料数量代替规则 |
| VI Full | 需要覆盖完整业务中的身份使用、跨载体适配与后续扩展 | 完整身份系统、必要家族、字体与颜色、图像及按需启用的 IP／数字规则、变化方法、小尺寸与复杂介质适配、制作和交付边界 | 按真实业务覆盖必要数字、实物或环境触点；说明不适用类别，不凑类别，不把视觉提案称为已验证生产手册 |

“连续核心触点”指用户接触品牌的几个相关环节。例如咖啡店：看到门头 → 查看菜单 → 拿到外带杯、包装袋及其他咖啡包装。一个触点可对应多件物料，触点数量不等于物料数量或展示屏数。

| 范围 | 建议展示屏数 | 内容安排 |
| --- | --- | --- |
| VI Lite | **3–4屏** | 品牌封面、基础视觉规范、核心应用；内容较少时合并相关规范，应用按实际需要分配 |
| VI Core | **4–6屏** | 品牌封面、基础视觉规范、图像与变化方法、多类应用；相关内容可同屏并列 |
| VI Full | 按系统与应用范围分章 | 展开必要使用规范、跨载体应用与适配方法，不设统一屏数上限 |

“一屏”指一个完整展示章节；分页时对应一页，连续长板中各章节不要求等高。以上为设计建议，用户指定数量优先。按真实内容调整，不为凑屏重复物料，也不为压屏删减必要规范或缩小文字。紧凑 Brand Board 可将所选范围整合为一张总览，不机械套用屏数。

完整门店型／消费型 VI 默认包含四类应用：**至少一项店铺关键场景、一项灯牌或导视、一项员工穿戴，以及一组周边或交易物料**。确实不适用时，说明业务原因。具有门店、线下服务、员工接触或周边传播场景的品牌，应逐类评估第4章应用矩阵。

沿“发现 → 选择／购买 → 使用 → 携带／传播 → 复购／分享”选择相关触点，不机械覆盖五阶段。为每个入选触点写清使用人、场合、准确内容、来源、尺寸、阅读距离、材料，以及它与其他触点不同的验证重点。

### 步骤3：确定展示形式和尺寸

先确认最终发布位置和用户锁定尺寸，再安排板内内容。应用物料的方向不决定展示板的宽窄。

| 展示形式 | 适用条件 | 尺寸与编排要求 |
| --- | --- | --- |
| 宽幅模块化长板 | 未指定最终展示尺寸的 VI 提案、作品集、系统与应用总览 | 默认宽 **1600px**，主要章节按 **1600×900px、16:9** 横向视域组织；各章节独立 HTML，高度服从内容关系；导出图可按顺序拼成长板，不把全部内容塞进一张横屏 |
| 独立分页 | 明确要求演示文稿、提案页、手册或逐页播放 | 用户尺寸优先；未指定时每页 **1600×900px**。每页保存独立完整 HTML，保持单页边界与固定尺寸；展示和预览按下述分页要求执行 |
| 手机长图／竖向长卷 | 明确要求手机长图或竖向连续阅读 | 默认宽 **750px**，按完整章节分屏，各屏独立 HTML、高度按内容确定；导出图按阅读顺序拼接 |
| 紧凑 Brand Board（品牌总览板） | 明确要求将基础视觉与核心应用集中展示 | 默认 **1200×1600px**，以主标、颜色、字体和代表应用组成一张总览；内容超出容量时调整展示形式，不靠缩字硬塞 |
| 已锁定的窄幅展示 | 明确沿用竖向参考总览、既有窄幅源或不可变窄发布位 | 沿用已确认尺寸与比例；参考未给像素尺寸时，连续长图按750px宽、单张总览按1200×1600px起稿，保留指定比例 |
| 真实应用平稿 | 包装、海报、界面、导视等实际设计 | 使用真实载体尺寸，不套展示板尺寸；进入展示板后作为对象呈现 |

**独立分页的展示与预览**：

1. 先按单页尺寸设计，各页保留完整内容、页序和边界。
2. 每页一个完整 HTML，分别渲染和检查；PC Web 按页序交付独立画布对象，Mobile 仅交预览并在任务目录保留源文件。最终预览图可由同版本逐页导出图拼接，保留全部单页 HTML，拼接图不替代源文件。
3. 按页核对文字、图片及边界，再核对完整预览的页数、顺序和版本。需要逐页播放时，先核验宿主是否支持；不支持则说明差异并确认展示方式，不声称静态总览已实现播放。
4. 独立分页保留各页底部安全区；仅连续长板的非末屏可按 produce-code 声明实际下一屏并省略接缝留白，末屏仍保留安全区。整套核对下一屏存在、顺序与背景接续，不因制作总览而取消独立页面留白。

以上尺寸为设计默认值，不是平台固定规范；用户尺寸和实际发布要求优先。物料竖向、内容多、素材偏竖或需要滚动，不单独构成将宽幅 VI 改成窄幅的理由。

内容增加时先横向重组、去重、分组或拆章。长板整体仍过长时，可拆成多张宽幅板，仍保持同一完整作品，不缩窄板宽或持续堆成单列。

## 2 确认 Logo 与使用方式

### 步骤1：确认唯一母版

| Logo 状态 | 处理方法 |
| --- | --- |
| 已提供 Logo | 核对准确名称、文件、版本、授权、锁定组合、可用背景状态及本次确认情况；确定唯一母版，不另造近似标志，不重新生成候选 |
| 未提供 Logo | 按[主入口](../SKILL.md)指定的 Logo 前置阶段完成设计与确认，再进入本规范的系统设计。候选应在核心概念和结构上真正不同，不以换色、换样机冒充方向 |
| 已有多个冲突版本 | 查明来源和确认状态，确定本次采用版本；未确定前不把候选或旧稿混成正式家族 |
| 仅有低质量预览 | 说明可用范围和缺口，索取可靠源；不将近似重绘称为原母版 |

新制主标及候选在名称已知时须包含准确名称；名称未知时先澄清。此要求不用于重画获准的既有图形标。

逐字保护大小写、空格、连字符、重音、语种关系和锁定断行。不得无依据增加注册符号、年份、城市、域名或身份附文。将宣传语与母版附文分开，不把普通宣传文案并入锁定 Logo。

唯一母版确认前，只规划内容、章节和应用职责，不开展依赖身份的配色、字体、IP、摄影与应用视觉。正式设计前的规划告知与制作条件集中按第6章执行。

### 步骤2：选择需要的 Logo 版本

先检查新制身份在黑标白底、白标黑底上的剪影、字腔、负形、笔画连续性和视觉重心。既有身份发现问题时标明风险，不越权修形。

保留确认主标，根据实际应用选择所需版本。下表全部是同一 Logo 的组合或使用状态，**是可选用法，不是全部生产清单**。已有可用版本直接沿用，只从同一确认母版补充有实际需要且获准的版本。

为选用版本标明名称、用途、来源、保留项、删减项和不可替代的场景。例如横向门头与深底名片，可按需选择主标、横向组合和反白版本；没有小尺寸应用时，不额外制作紧凑标或简化版。各版本可在同一规范屏对照，不要求各占一屏。

| Logo 版本 | 使用场景 | 保留与调整方法 |
| --- | --- | --- |
| 主标 | 默认品牌署名、首次接触、需要完整身份的信息面 | 保留完整字形、图文关系、比例和必要附文 |
| 横向组合 | 横招、页眉、狭长包装面等横向空间 | 采用获准横向关系；不压扁主标，不临时改变图文间距 |
| 纵向组合 | 竖向标牌、较窄正面或上下组织的信息面 | 采用获准上下关系，保留名称主次和锁定断行 |
| 独立字标 | 以名称识别为主、不需要图形的场景 | 保留母版字形，不用相似字体重新输入替代 |
| 独立图形标／角色标 | 已具备独立识别条件的头像、产品签名或小面积标识 | 保留核心轮廓；首次接触仍需完整名称时，不以图形替代主标 |
| 紧凑标／缩写标 | 小标签、封签、头像或狭窄空间 | 只使用获准紧凑版本，不另造第二概念或临时缩写 |
| 单色状态 | 单色印刷、刻印及颜色受限的材料 | 使用确认的单色结构，检查字腔和负形，不擅自加描边补救 |
| 反白状态 | 深色或品牌主色背景 | 使用确认的反白版本，保护浅色身份部位，不把所有内部区域一律填白 |
| 小尺寸简化 | 细节无法稳定呈现的小图标、标签或粗糙介质 | 仅采用获准简化，减少次要纹理、从属文字或细节，保留核心剪影、负形和识别笔画 |

### 步骤3：说明净空、最小尺寸与背景用法

| 规范项目 | 具体方法 | 记录内容 |
| --- | --- | --- |
| 净空 | 已有规范优先。无既有数值时，从母版选取稳定、可重复测量的部位作为尺度参照，在代表性应用中测试周围文字、边缘和图像的干扰；以测试结果确定净空 | 标出测量起点、参照部位及确认后的关系。区分 Logo 净空、物料裁切安全区和安装边界，不编统一倍数 |
| 最小尺寸 | 至少观察大标准稿、中等应用、小图标／标签三个尺度；逐步缩小，检查字腔、负形、细线、名称与必要附文，再在实际介质和阅读距离复核 | 按屏幕、印刷及特殊材料分别记录可用尺寸与状态。未实测时注明待验证，不编统一最小值 |
| 浅色背景 | 优先使用获准正色或深色单色状态；检查浅色笔画和细节是否消失 | 展示标准状态与实际应用，注明不适用的低对比背景 |
| 深色背景 | 优先使用获准反白或深底专用状态；检查孔洞、负形和浅色身份部位 | 不以投影、发光或临时描边代替正确状态 |
| 摄影与复杂背景 | 先选择已有的安静区域，或调整照片裁切和版面落位；必要时使用有明确承托职责的干净信息面 | 不让复杂纹理穿过关键字符，不把应用承托底误记为 Logo 身份容器 |
| 受限材料 | 按单色印刷、织物、刻印、发光等条件测试；细节被吞时先换获准家族或增大尺寸 | 不擅自加粗、拉伸或改造锁定标志；制作能力不足时说明限制 |

不得拉伸、换字、改变核心轮廓和负形、混用候选、任意交换关键颜色，或在场景中另造字形。场景只能验证应用，不能反向成为标准母版。

## 3 建立基础视觉规范

### 步骤1：确定品牌视觉风格

根据品牌定位、受众、Logo、参考和业务场景选择风格。说明如何通过形态、颜色、字体、材料和布局表现品牌特点，不只列“可靠、亲和、活跃”等形容词。

Logo 字形、展示字、获准 IP、产品图像与摄影处理至少共享两项可观察特征，例如笔画粗细、圆角、开口、色彩面积或材料表现，使各部分属于同一品牌。

从确认母版观察宽窄、线重、端点、转角、开口、黑白节奏与轮廓。区分身份结构和表面效果，不把颗粒误当字形骨架。

选定一个主要风格方向，同时确定字体、颜色、图像、材料和布局。在阅读任务不同的相关触点试排，检查不同应用的字体、配色和图像是否一致，不只检查封面。

本 VI 不新增独立辅助图形、Pattern、装饰 Icon 或纹样系统，不拆解、重复 Logo 形成装饰。视觉变化使用确认 Logo／字标的真实状态、品牌色面积、字体层级、获准 IP、产品、摄影、材料、裁切和真实内容。真实数字产品所需功能图标不登记为品牌辅助图形。

### 风格方向：选择整套设计的方法

以下八种方向用于判断怎样组织设计，不作为行业套式。已有方向时直接适配，不为凑数量另换风格。

| 风格方向 | 适用重点 | 具体设计方法 |
| --- | --- | --- |
| 瑞士模块、几何现代主义 | 精确与组织 | 从母版比例和转角建立网格与字级；用稳定编号、对齐和分组组织信息。颜色区分身份面与信息面，图像按栏目裁切，材料保持边缘清楚；在空间和小卡片上复用比例关系，不照搬网格尺寸 |
| 人文编辑、出版档案 | 叙述与内容 | 用图片裁切、标题节奏、边注和栏目关系串联阅读。展示字表达气质，正文保证连续阅读；以克制纸色承托长文，材料效果只落在有依据的对象表面，不伪造年代 |
| 手作纸本、印刷工艺 | 制作动作与触感 | 以真实工具、制作过程和材料近景承担内容；让展示字力度、摄影颗粒及纸面纤维保持相近粗细尺度。控制低色数和局部套印，准确文字与标准色不做磨损 |
| 数字动态、透明层叠 | 状态、连接或流动 | 用真实内容的聚合、伸展、路径和叠层解释变化；字体在状态切换时保留稳定位置，颜色区分层级。透明度与光场服务前后关系，不以蓝紫渐变代替逻辑；静态稿不宣称动态已实现 |
| 角色插画、趣味拟物 | 获准 IP 沟通 | 以轮廓、动作、表情和行为组织叙事；展示字呼应线重或圆角，主色延续角色颜色职责。按真实场合改变动作和尺度，不每页贴同一姿态，不新增角色填页 |
| 纪实摄影、生活方式摄影 | 产品、人物或空间认知 | 以全貌、使用过程和细节建立证据；固定镜头距离范围、光向和主体尺度，字体让位于图像但保留阅读轴。材料由真实表面呈现，不靠统一滤镜制造一致 |
| 空间导视、工程图形 | 方向、尺度与环境 | 由远近阅读层级决定字重、信息量和标识面积；把安装边界、路径和环境材料对应到平稿。颜色承担识别或方向职责，必要示意依据真实结构，不另造装饰工程线 |
| 实验拼贴、受控极繁 | 获准强表达与视觉实验 | 用一个内容母题控制裁切、叠压和材料碰撞；设置唯一主焦点，再组织次级密度。字体和颜色保留稳定关系，准确说明进入干净区域，不混装无关风格或制造新纹样 |

### 风格组合配方

以下配方用于把各部分连成一套，不是模板编号。一次采用一套主要关系；自定组合时，应写到同等具体程度。

| 配方 | 适用条件 | 联动方法 | 使用边界 |
| --- | --- | --- | --- |
| 高饱和角色识别 | IP有明确品牌职责，且已有确认角色母版 | 用单一强主色建立识别面，浅中性色形成反差，少量暖色调节节奏；展示字选粗重、圆润或受控稚拙字形，呼应角色线条。以角色动作和产品安排紧凑大模块，颗粒只作局部印刷表面 | 保持商业可读，不滑向儿童绘本，不重复同一角色姿态 |
| 手作编辑式品牌 | 有真实制作、工具和材料依据 | 用双色或低色数控制版面，材料色支撑；展示字与身份共享手写力度、圆角或不规则程度，正文保持清晰。用真实工具、产品和制作摄影，以不对称栏目、段距和轻套印连接 | 手作线描使用产品、食材、工具或制作动作内容，不建立独立装饰系统，不全板叠噪点。 |
| 温暖产品生活方式 | 食品、饮品、美妆与生活方式品牌 | 用暖中性色承载大背景，主色建立身份，产品自身颜色作内容支撑；标题和正文友好且字腔清楚。由产品主图确定自然侧光、台面和环境对象，规范区收敛，应用区延续光色 | 不堆促销信息，不使用无依据的奢华材质 |

高密度依靠对齐和分组，不靠缩字；低密度依靠主次和有效净空，不靠空洞。局部颗粒、套印、透明或光场须说明承载对象与用途，不让每章同样热闹。

### 步骤2：确定字体与阅读尺度

Logo 字标不自动成为正文字体。根据 Logo 的宽窄、端点和黑白节奏搭配展示字；正文优先检查字腔、字符覆盖、长文阅读与实际输出。

| 阅读任务 | 字体与排版方法 |
| --- | --- |
| 短标题承担身份表达 | 选择较强字形性格，用字重、宽度和断行建立轮廓；效果集中在第一焦点，不把全部文字变成展示字 |
| 长文承担解释 | 选择结构清楚、字面稳定的正文；用行长、行距和段距分段，不以极细字重制造轻盈 |
| 菜单、价格、参数承担比较 | 固定项目列与数值列，检查数字宽度、小数点和单位；必要时使用适合对齐的数字形式，不将普通参数放大成主结论 |
| 多语种共同阅读 | 按实际主次调整字号、字重与基线，不按相同字号机械等权；保留确认译文和断行 |

用同一组最长标题、正文、数字和外文比较候选。先比较视觉重量、行长与断行，再调整字重、宽度和段距，最后微调字号。核实字体资源、许可、字重、缺字和回退。

下表以 **1600px宽展示板** 为基准，数值为源HTML的CSS px。默认优先采用区间中上段；其他母版宽度按“表内字号×母版宽度÷1600”换算，不将原数值直接套用所有画布。换算后仍按实际阅读尺寸检查；实体应用内部文字另按真实尺寸、阅读距离和材料验证。

| 文字角色 | 默认字号 | 建议行高 | 使用要求 |
| --- | ---: | ---: | --- |
| 首屏展示字／主命题 | 84–144px | 0.9–1.1 | 仅承担第一焦点；长标题先调整行宽和断行 |
| 章节标题 | 48–72px | 1.05–1.2 | 表达本章结论，与正文形成清楚级差 |
| 正文／规范说明 | 25–30px | 1.45–1.7 | 默认25–30px，基准母版不得低于20px；按实际显示尺寸验证 |
| 界面小字／辅助说明 | 16–20px | 1.3–1.5 | 只放短辅助信息；长内容改用正文角色 |
| 关键数字／核心参数 | 56–96px | 0.95–1.15 | 仅用于主结论，普通色值和尺寸随正文或标签 |
| 标签／章节眉标／状态文字 | 20–24px | 1.15–1.4 | 用字重、字距、颜色和位置共同区分 |
| 图注／应用名称／来源 | 16–20px | 1.3–1.5 | 与对象近邻；可低于20px，但须在最终预览中可读 |

正文、章节信息及主要说明在1600px宽基准母版上不得低于 **20px**；短辅助说明、图注、应用名称与来源不得低于 **16px**，长说明使用正文角色。其他母版宽度同步换算下限。章节标题相对正文可从约 **1.6×**、首屏展示字可从约 **3×** 的级差试排，不作为强制比例。提高采样倍率不能代替增大字号；缩略总览不用于阅读正文，实际阅读需逐页或逐章查看。达到换算下限仍难读时继续增大或重排，不以缩字换留白。Mockup或照片内因透视缩小的文字仅作场景表现，必要说明另用符合上述尺度的展示板文字呈现。

### 步骤3：确定配色与使用比例

先定主色、表面／纸色、墨色和强调色，再定数值。**2–4个主要角色**足够时不加无职责新色。Logo 默认 **1–3个印刷色角色，常规最多4个**，不塞入全部 VI 色板。

一次方向选一组；完整VI可按颜色职责扩展应用色板，不机械限定色数。以下 HEX 为规划近似值，精确继承须从用户原资产取色。

| 配色方向 | 色值 | 使用方法 |
| --- | --- | --- |
| 外向、远距强识别 | 主橙 #FF6508；墨黑 #111111；亮白 #F7F7F2 | 橙色铺识别面，黑白承担身份及信息；长文转浅底，避免细白字压橙底 |
| 自然、可靠、温和 | 深绿 #066447；奶油 #F4EFD5 | 建立两色正反关系；信息密集时扩大奶油面，不以冷白或新亮色打断温度 |
| 清爽、现代 | 钴蓝 #123FCB；暖奶油 #F0ECD8；深蓝 #16348C | 钴蓝作主识别，奶油承载文字和表面；深蓝仅按需补层级，避免蓝色层级过多 |
| 复古、乐观 | 蓝 #235E91；橙 #F47A18；奶油 #F5EFE1 | 每版蓝橙只选一个主导，另一色局部强调；奶油隔开高对比区，避免蓝橙等权 |
| 经典、热情 | 深红 #C70D27；奶油 #F6EBD0；暗红 #94101F | 深红连续成场，奶油承载标题与信息；暗红仅补层次，长说明移出高饱和底 |
| 成熟、克制 | 炭黑 #2D2D2F；象牙白 #F2EED5；深墨 #111111 | 炭黑作环境与大底，象牙白作文字或纸面，深墨用于浅底身份；不堆无差异黑层 |
| 手作、编辑 | 米白 #F3EBDD；番茄红 #C92B30；黑 #181311 | 米白作主要信息面，红集中在品牌与重点，黑承担正文；避免红黑同时大面积压迫 |
| 安静、社区 | 米白 #F2EEE2；橄榄绿 #58713D；黑 #171411 | 米白作主纸色，绿用于品牌强调和空间呼应，黑承担文字；不将全文染绿或叠泥色 |

首轮可按**主导色60–80%、表面色15–35%、墨色或强调色5–15%**试排。不同时取上限，不作固定公式。首屏可让主色占大面，规范区扩大信息纸色，应用按可见面调整；保留职责，允许正负反转，不任意交换主辅。

色板展示面积不代表实际使用比例。将色名、数值、用途和应用证据近邻放置；标准色样保持干净，材料照片不得充当标准色样。

检查彩色、灰阶、单色、反白、低清和深浅底。屏幕色、印刷色、专色与材料色分开记录，不由 HEX 虚构 Pantone、CMYK 或已打样材料色。

### 步骤4：确定摄影、插画、IP与材料

先说明全貌、过程和细节各自证明什么，再统一主光方向与软硬、色温、台面、景别范围、阴影、主体尺度、环境对象和后期。这些是整套共享的艺术指导，不是额外图像参考。

| 内容 | 具体方法 |
| --- | --- |
| 摄影 | 全貌说明对象，过程说明使用，细节说明材料或工艺；同组保持光向、台面与视觉尺度，按内容改变取景，不靠同一滤镜统一 |
| 插画 | 保留轮廓、笔触、负形、透视和对象关系；不额外建立装饰图标或纹样 |
| 材料 | 明确效果属于主体、背景还是局部表面，限定颗粒尺度、范围和强弱；已有照片的材质与阴影不重复覆盖 |
| IP | 按真实沟通需求启用，记录名称、职责、轮廓、头身、五官、标志部位、配色与行为；各角色分别保留来源和基准，不混作同一角色变体 |
| 媒介变化 | 纸艺、毛绒、像素和3D只改变媒介表现，不换身份；单张正面不证明全角度一致，实体须专业制作或打样 |
| 不启用 IP | 用产品、摄影序列或应用关系承担叙事，不新增吉祥物填页 |

角色图像的衍生与独立角色复用限制，统一按第6章执行。

## 4 设计应用物料

### 步骤1：选择物料，确定内容与设计重点

按第1章范围选择代表物，不要求所有品牌制作同一套样机。每件入选物料均明确准确尺寸、使用人、阅读距离、材料和交付状态；平稿与场景按授权范围形成。需要场景验证时，先完成真实尺寸平稿，再将同一设计用于相关场景。

| 类别 | 可选物料 | 优先呈现的内容 | 具体设计重点 |
| --- | --- | --- | --- |
| 店铺与空间场景 | 门头、橱窗、入口、收银台、吧台、菜单区、货架、墙面、桌面、等候区、快闪店、展台、活动空间 | 门头先呈现品牌名称；入口和店内说明位置、经营内容及必要营业信息。菜单按类别组织项目、价格和服务条件，用稳定列宽、基线和段距便于查找 | 远景验证发现与动线，中景验证入口和选择，近景验证材料与细节；让门头、入口、主色场和标识尺度形成连续关系，不用一张模糊室内图替代全部证据 |
| 灯牌与导视 | 发光字、灯箱、侧招、吊牌、霓虹／轮廓灯、楼层牌、方向牌、营业信息牌、门牌、价格／菜单灯牌 | 优先呈现品牌、方向、入口或目的地，减少次要说明；保留主标与方向信息的完整可见区 | 按安装高度、正侧面观看和距离调整尺度；检查昼夜、深浅背景和正色／反白。发光不得吞字腔或负形，缺供应商参数时仅示意效果 |
| 员工服装与穿戴 | T恤、Polo、卫衣、围裙、帽子、外套、袖章、工牌、胸牌、挂绳、员工证 | 服装呈现品牌及必要岗位标识；工牌优先呈现真实姓名、岗位和编号 | 按岗位、功能和动作选择胸、袖、背面等位置，避开折痕、头发、挂绳和手臂。工牌按姓名、岗位、编号等真实信息分层，不把完整 Logo 同样居中贴满衣物 |
| 品牌周边 | 帆布袋、贴纸、徽章／Pin、钥匙扣、杯具、笔记本、卡套、手机壳、伞、玩偶、礼盒、限定纪念物 | 突出品牌名称或确认标志，按收藏、赠送或传播用途补充内容；手持、折叠后仍能看到主要标识，延续字体和配色，不照搬同一布局 | 先建立主周边，再用相关物组成系列；按携带、收藏、赠送和传播用途调整尺度、材料与内容，不用 Pattern 铺满表面 |
| 交易与服务物料 | 包装袋、外带盒、杯／杯套、餐垫、托盘纸、价签、收据、优惠券、会员卡、感谢卡、配送包装 | 按用途呈现品类、项目、价格、服务条件、领取动作、编号与时间；操作信息清楚可见，品牌署名不抢主次。会员或优惠物料说明真实使用条件，不虚构权益 | 串联购买、使用、携带和复购；优先保证品类、价格、编号和服务信息可读。检查接缝、折线、手持露出区，不以随机贴标代替设计 |
| 数字与传播物料 | 社交头像、帖子模板、短视频封面、数字广告、官网／小程序入口、电子菜单、活动页；按需增加演示文稿和界面 | 按页面用途呈现主题、产品或服务及实际操作入口；会员、回访、分享或再次购买的信息采用真实业务内容，不虚构优惠、权限或承诺 | 检查小尺寸识别、长短内容变化、字级、间距、颜色和边界；按需展示长文本、空态、禁用和错误，操作含义不由情绪图像替代 |

### 步骤2：保持品牌一致，按物料调整设计

沿用确认的 Logo、字体、配色和图像规则，根据物料尺寸、形状、材料和阅读距离调整设计。共同规则写一次，各件物料只补充不同做法。

| 设计内容 | 沿用的品牌规则 | 按物料调整的方法 | 避免的问题 |
| --- | --- | --- | --- |
| Logo | 确认字形、轮廓、负形、比例、锁定组合与颜色职责 | 根据空间选用获准横向、纵向、紧凑、单色或反白状态；调整整体尺度和位置，并保留规定净空 | 拉伸、换字、临时改组合、拆解或重复成装饰 |
| 字体与信息 | 展示字、正文、数字和标签的角色及基本节奏 | 长标题先调行宽和断行；菜单固定项目列和价格列；不同载体调整字级与段距 | 每件物料换字体，或全部文字使用展示字 |
| 颜色 | 主色、纸色／表面色、墨色和强调色的职责 | 首屏扩大主色，规范区扩大信息底色；按可见面调整面积，允许有依据的正负反转 | 随意交换主辅，或将全部 VI 色板塞进 Logo |
| 摄影与产品 | 主光、色温、景别范围、材料响应和主体识别 | 按全貌、过程、细节改变对象、裁切和距离；保持同一光色关系 | 同图换字称系列，靠滤镜掩盖来源差异 |
| IP | 轮廓、头身、五官、标志部位、配色与行为逻辑 | 在授权内按欢迎、导览、使用等场合改变动作、表情、尺度和媒介 | 换脸型、删身份部位、无用途新增服装道具或角色 |
| 布局与材料 | 阅读层级、共同轴线、字体节奏和材料依据 | 按形状、阅读距离、折叠和手持区域重排；在真实表面表现纸纤维、织物或发光 | 所有载体同样居中贴标，以效果图证明工艺已验证 |

系列须改变真实内容、主体、裁切、局部色面积或用途，不把三套独立设计并排称为系统。可暂时遮去 Logo，检查字体、颜色、图像和材料是否仍有共同关系；仅作视觉自查，不冒充用户识别测试。

### 步骤3：先做真实平稿，再做场景

| 层级 | 应完成的内容 | 修改依据 |
| --- | --- | --- |
| 品牌母版 | 确认 Logo、字标、角色等身份及允许用法 | 引用同一获准来源；变更时说明影响哪些应用 |
| 真实尺寸应用平稿 | 在实际载体尺寸中排好 Logo、文字、图像、信息层级和安全区域 | 明确继承哪份母版，不靠场景图反推设计 |
| 应用场景 | 将同一平稿用于杯身、袋面、灯箱、服装或空间 | 保留平稿内容，处理透视、曲面、接缝、折痕、遮挡和材料响应，不另造字形 |
| VI 展示板 | 组织规则、平稿、对象、场景与说明 | 帮助理解系统，不替代前三层资产，不自动成为生产源文件 |

分别写清三种位置：

1. **图文在平稿内的位置**：说明 Logo、标题、正文、图像分别占据哪些区域，怎样对齐，哪些部位必须完整。
2. **设计在场景表面的落位**：说明平稿怎样贴合曲面、接缝、折痕、发光面或佩戴位置。
3. **物料在展示板上的位置**：说明主辅大小、相邻说明、阅读顺序和与其他证据的关系。

不要用一句“居中”代替三层说明。

### 步骤4：检查不同物料的使用效果

固定字体节奏、颜色职责和图像语言，根据形状与可见区域选择已确认家族；改变尺度、色面积、真实内容、裁切和景别，不把同图换字称为系列。

曲面、折叠和携带物料先确认杯身、袋面、接缝、折线与手持区域，再重排内容。保留关键轮廓、杯沿和袋柄证据；物体与台面应真实接触，不以旋转矩形冒充贴图。

小尺寸与粗糙材料优先选获准紧凑或单色状态，减少从属内容，增大关键字与净空。图片缺失时使用真实可用资产和原生排版，不用无关图片替代品牌对象。

场景已有袋杯组合时，不额外叠入同一物件。每张图补充不同距离、材料、动作或状态证据。无法证明精确继承时仅称概念示意；修改只更新受影响的平稿、场景与展示。

### 按展示对象与构图关系匹配品牌视觉模板

展示对象指画面呈现的内容或载体，构图关系指它们的排列、位置与层次。先在品牌视觉范围内交叉匹配这两类词，风格在读取后依据第3章已定方案判断，不作为本次名称匹配条件。

1. **按页面职责取词。** 从下表选择与实际内容相符的对象词和构图词；已有明确模板时也可用后文完整名称定位。表中词是现有名称的可检索片段，不是独立语义标签；不把一格内的所有词拼成必选条件，名称中的数量也不决定当前任务的资产数量。
2. **限定品牌视觉并取交集。** 使用下方查询方式，空格表示各词须同时命中名称，真正同义词可用 `|` 合并。`--category 品牌视觉` 会包含通用候选，因此同时用名称前缀“品牌视觉”限制结果，再核对返回项的 `category` 为“品牌视觉”。此处查询整页名称，不使用尚未登记的屏级用途、布局或风格条件。
3. **在原范围内处理缺词或零命中。** 先检查词是否出现在名称中、两类词是否有共同候选。名称没有明确对象，或需求尚未确定布局时，保留“品牌视觉”与已明确的一类词检索，再读正文补判；两类词没有交集时，按实际内容放宽其中一类，不自动改查其他题材或把通用结果算作品牌视觉命中。
4. **读取并适配。** 按 [templates.md](templates.md) 的 `match → describe → read` 完整读取候选及必要依赖，核对真实对象、空间关系、图文容量与画幅，再判断能否适配已定字体、配色、摄影和材料。明确整页、章节或局部采用范围；保留原确认与首项完整封面生产顺序，局改只处理受影响项，不因样例新增资产或拆改确认 Logo。

### 步骤2：选择首屏主结构

首屏只选一种主结构，最多附一项低权重辅助方法。不得新增独立辅助图形、图案或装饰纹样。

| 首屏策略 | 适用情况 | 具体构图 | 身份保护  可检索词与采用范围 |
| --- | --- | --- | ---  --- |
| **沉浸裁切型** | IP、产品或3D／摄影主体承担第一认知 | 放大获准主体，使其占据大部分高度或宽度；允许出血，用局部特写、前后遮挡和光色形成进入感。文字放在可控净空，Logo 可作次级签名 | 保留决定身份的脸部、轮廓、产品结构或标志部位；主体必须与品牌相关，不用无关漂亮大图，也不以整图重蒙版补救  构图·品牌视觉：`山景居中品牌`、`山景主视觉下置故事`、`半幅实景品牌留白`（借主视觉与文字关系，沉浸裁切另按主体适配） |
| **标志／角色整合型** | Logo、角色、物件或字标本身就是核心识别 | 让主标或品牌名统领中心关系，让获准角色或物件沿字腔、字肩、基线、轮廓或留白参与构图；可用同一确认标志的放大轮廓水印或单一辅助色块增强结构；不改变标志身份，不拆解成新的装饰图案或生成第二套标志 | 不改变锁定组合，不遮挡关键字符，不重画字腔或角色身份；整合发生在构图中，不临时改造母版  构图·品牌视觉：`左字样右吉祥物`、`大吉祥物侧置标语`、`巨字衬底角色出框`（并置与层级参考，不等同于标志融合） |
| **封套陈列型** | 品牌提案封面、作品集，或需先展示核心应用证据 | 以大品牌色场包围居中的封套、品牌板或应用画面；中心对象足够大，能看清 Logo 与核心设计，外围只留短标题和少量索引 | 不把对象缩成孤立缩略图，不让透视与裁切破坏名称；不新增外围图案，不以大量空白掩盖内容不足  构图·品牌视觉：`三袋错层陈列`、`斜置实物四角标识`（借陈列关系，按真实封套或品牌板重排） |
| **身份系统预告型** | VI Lite、Brand Board，或 Logo 家族是主要内容 | 主标保持绝对第一视觉，以少量真实组合标、核心色、获准 IP 动作、产品或应用切片预告后续内容，组成一个整体 | 不做等权候选墙、资产清单或目录；只展示确认资产，不制造变体或新增角色填充  构图·品牌视觉：`上单下双品牌展板`、`三联品牌展示`（重排主标与预告资产的主次） |

首屏同时满足以下要求：

- **唯一最大主体**：按真实可见对象计量，不把透明边或照片空背景算作占版。先放大主对象，再检查阅读、Logo 净空、安全区和裁切。
- **明确主色场**：优先使用一个占主导面积的品牌主色，配一个高反差中性色和最多一个辅助色；既有规范或明确多系列架构按获准颜色职责适配，不强行删减产品或场景的真实颜色。允许纯色承担完整背景，不为“高级”机械加入玻璃、渐变或噪点。
- **低文字密度**：原则上只保留准确品牌名／Logo、一个短命题或职责说明，以及极少量必要索引。长介绍、色值和清单后置。
- **进入第二章的连续线索**：以同一颜色、获准轮廓的实际使用、角色动作、主体裁切或应用切片接续。第二章展开 Identity Kit 或相关证据，不无关联硬切。
- **三秒识别**：在首屏单独视图和整板缩略图中，检查能否迅速认出品牌名或核心身份，主色是否明确，裁切是否保留身份。

准确标题和说明采用原生文字，完整首屏图像制作及透明 Logo 条件按第6章执行。

### 步骤3：选择宽幅章节构图

先确定内容关系，再选择版式。可用“主视觉加物料总览”“品牌规则加系列平稿”“物料陈列加场景证据”组织内容，再落到以下构图。不按固定模板凑页。

| 宽幅构图 | 适用内容 | 具体方法  可检索词与采用范围 |
| --- | --- | ---  --- |
| 主视觉＋说明侧栏 | 品牌命题、核心场景、开场 | 主视觉占主要宽度，说明集中于一侧；让文字与主体建立共同轴线，避免小主体配巨大空场  构图·品牌视觉：`半幅实景品牌留白`；构图·通用：`跨栏标题与单侧信息轴`（借图文分区与说明轴） |
| 规则区＋应用证据 | Logo、字体、颜色、图像规则 | 规则与对应应用左右近邻；标准稿保持干净，样机不反向充当规则来源  构图·品牌视觉：`样机原稿对照`、`品牌图形实拍对分`（准确规则与对应应用近邻） |
| 上部主对象＋下部横向系列 | 包装、海报、界面或 IP 状态 | 上部先建立主要对象尺度，下部可选 **3–5个同类状态**共享基线、视角和观察尺度，比较真实内容差异  构图·品牌视觉：`上单下双品牌展板`（借上主下辅关系，系列数量按内容调整） |
| 非对称矩阵 | 平稿、独立物件、场景和细节共同说明一个结论 | 可用一个大模块带动 **2–4个辅助模块**；辅助只补关键证据，不形成等权缩略图墙  构图·品牌视觉：`左侧分格右侧双瓶`、`四幅分栏品牌展示`（借分格与主次，按真实对象重排） |
| 左窄右宽／右窄左宽 | 短规范、色板、细节与大场景并置 | 窄区只放短说明，宽区承担主要视觉证据；两侧共享轴线或边界，长文另增宽度  构图·品牌视觉：`纵列大字与细节阵列`；构图·通用：`疏密交替的偏置内容组`（借标题、细节与疏密关系） |

3–5个同类状态、2–4个辅助模块为组织建议，不是数量硬要求。按内容是否互补决定保留数量。

每章保留一个主焦点、清楚顺序和结束点。以大图、大字、低无效空白为默认尺度策略，不以塞满为目标。内容过量先去重、横向重组、分组或拆章，不持续缩字和增高。

### 步骤4：统一背景与开放排版

先确定标题、正文和图注的共同对齐线，再按构图安排主图跨栏或出血。短说明可用窄侧栏，长说明增加宽度。叠压时写清哪两个对象、谁在前、遮挡目的与保护区域。

整套确定一个主背景方法和一个辅助方法：

| 背景方法 | 适用内容 | 使用要求 |
| --- | --- | --- |
| 连续品牌色域 | 首屏、章节过渡、品牌信息面 | 以颜色职责和面积变化形成连续关系，纯色须承担明确品牌或信息用途 |
| 真实摄影或主题场景 | 产品、人物、制作过程、生活方式 | 延续光向、色温和主体尺度，场景本身承担空间与材料证据 |
| 产品或材料近景 | 细节、材质、工艺说明 | 只使用有依据的表面，不把效果图当真实工艺证明 |
| 物料陈列场 | 多件应用共同展示 | 统一台面、接触、光线和阴影，避免物件漂浮 |
| 干净规范区＋图像窗 | Logo、字体、色板和规则说明 | 准确样本保持纯净，材料和情绪集中在相关图窗 |

首屏突出品牌形象，规范区保证样本和说明清楚，应用区展示物料、场景及材料细节；用一致的配色、光线或图片裁切衔接章节。不机械加噪点、玻璃、辉光或无关渐变，不在已有照片上重复叠纹理与阴影。

优先用近邻、轴线和段距组织开放排版。确有承托职责时再用容器，并说明边缘、表面、颜色、层次、内部留白和文字容量；未使用的效果不默认添加。白色圆角卡片不作默认品牌语言。

完整平稿、照片图窗和场景可保留有职责的背景，不一律去底；独立叠放身份资产按第6章处理。

## 6 交付

### 步骤2：执行专项制作条件

以下条件用于制作与交付，与前述设计方法配合执行。

#### 规划告知与模板使用

正式设计前，按主入口向用户告知品牌与受众理解、Logo 状态、方向理由、范围、拟建系统、应用触点、展示形式、制作顺序、确认事项和交付边界。未提供 Logo 时说明前置阶段；母版确认后更新规划。**不新增首屏批准环节。**

模板检索与风格适配按第5章执行，比较时机仍按主入口；名称命中不代表适配或制作已完成。

#### 首屏与衍生图像

新建或整体重做完整 HTML VI 时，确认母版并告知规划后，第一项正式图像必须是**匹配最终首屏画幅的完整封面效果**，以确认 Logo 为唯一真实参考进行图像编辑。

首屏结果应完成第5章所选主结构，不得用贴标、无 Logo 氛围图、模板或准确透明 Logo 加纯色背景冒充该生产项。缺少能力时按主入口报告，不绕过。

准确透明 Logo 与原生文字可用于组装，但不能替代首屏图像生产，也不得掩盖底图的错误身份。核对底图拼写、字形、轮廓、比例、负形与颜色职责；错误身份不得与正确覆盖层叠存。

新制衍生图像仅以确认 Logo 为实际参考编辑，不追加风格、产品、平稿、角色或既有衍生图。其他真实素材可直接复用或确定性放置；不能通过新制图像方式精确完成时，说明限制，不改用其他参考冒充继承。

**授权局改例外**：已有合成成品的局部修改，以当前成品为编辑目标，Logo 为必要身份参考，不套用新制单输入限制。

仅确认 Logo 内角色可由该 Logo 编辑衍生。独立角色母版仅直接复用或确定性放置；若编辑必须依赖 Logo 之外的角色参考，报告能力冲突，不绕过限制。

#### 原生文字与透明 Logo

准确文字、色样和规范示意采用原生文字／图形。首屏标题、短命题和说明保留可编辑文字；透视小字仅作场景效果，不承担展示板的准确说明。

独立层 Logo 必须为真实 Alpha 或无底 SVG。可靠透明源只核验；带底源按已部署能力去底，保留确认身份容器，仅移除外部图片背景，不重绘、不改字、不改变比例。

在浅底、深底和最终底色上检查细线、孔洞、负形、白边、色边、误删与残底。不得以混合模式、滤镜或同色矩形假装透明。透明结果未合格前停止该资产的排版使用，报告缺口。

#### 制作参数与代理能力

真实平稿使用实际尺寸。纸张、刀模、色彩模式、材料、安装、发光和制作精度采用供应商资料；缺参数或未打样时标明待确认，不由屏幕效果作生产承诺。

已部署代理工具时，将完整 HTML 生成／修改与渲染检查交子代理；主代理负责媒体、选稿及交付。缺少所需能力时按主入口报告，不新增工具或扩大代理职责。

### 步骤3：按实际能力交付

按授权范围拆分制作：分页 VI 每页、长板每个完整章节分别保存完整 HTML；单张 Brand Board 保留一个 HTML。每个文件独立检查，整套沿用同一 Brief 和视觉系统；PC Web 逐文件交付画布对象，Mobile 仅交预览并在任务目录保留源文件。最终预览图可按顺序拼接，核对页数、顺序、尺寸和版本；保留各页源文件。宿主交付按质量规范执行。

| 交付内容 | 应说明的实际能力 | 不得混称 |
| --- | --- | --- |
| 原生文字与布局 | 可直接修改文字、字号、位置、间距和版面 | 不把场景图片内文字称为独立可编辑文字 |
| 可替换位图 | 可整体替换图片，说明来源、版本和用途 | 不称为矢量、3D源或专业母版 |
| 专业母版与应用源稿 | 仅列实际存在、可打开和可修改的文件 | 不以预览或效果板代替源稿 |
| 应用平稿 | 说明真实尺寸、内容完整度和制作验证状态 | 不自动称为刀模、施工文件或已验证生产规范 |
| 场景与预览成图 | 说明概念、效果或实际素材状态 | 不称为真实门店、落地案例或可生产证明 |

交付前说明已完成项、可编辑项、可替换项和待核事项。保留母版、平稿、场景与展示的对应关系；未验证的印刷、实体、交互或法律结论如实说明，不以展示完成代替制作验证。
