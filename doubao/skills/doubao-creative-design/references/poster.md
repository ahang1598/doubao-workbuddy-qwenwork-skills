# 独立海报设计规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

**目的**：使独立传播画面主题清楚、事实完整、图文协调，适配指定版位与阅读尺度。

**适用**：以品牌表达、商品宣传、活动吸引、人物塑造或艺术情绪为主的独立海报，以及对应的系列、多尺寸版本、Banner和单张社媒封面。不含详情页、社媒连续长图、其他产物内部封面及未匹配产物的通用兜底。

**按主要任务分流**：事项告知、安排变更、公示、邀请、成果发布及节庆祝贺按[主入口的生产方式](../SKILL.md#选择生产方式)执行；解释知识或机制走[信息图与图解规范](infographic.md)。活动宣传以主题吸引和主视觉为中心，活动通知／邀请以安排和参加方式为中心；两者均保留已提供的必要事实。节日商品宣传仍属海报，节日祝福／放假通知属公告。Banner、封面和横竖比例是载体，不决定类别。混合内容按主任务选规范，涉及另一类时只补相应专项条款，不重复执行流程。

**核心流程**：明确产物与要求 → 组织内容 → 确定视觉方案 → 核对专项要求 → 交付各版位独立成稿

<a id="shared-intake"></a>

## 1. 明确产物与要求

- **识别交付职责。** 筛选、比较、趋势或多图表分析为主体的战报，优先按分析任务处理。路线、批准触发与生产顺序服从[主入口](../SKILL.md)，不因一张 PNG、图片格式或无需分层改道，不套用社媒套图封面批准或混合 KV 门禁。
- **锁定需求。** 明确用途、受众、阅读顺序、实际显示／打印尺度、数量、尺寸和可编辑范围。保留用户锁定原文、全名、身份及素材用途；已有源和局改按[edit](edit.md)保护完整基线，只改授权对象及必要依赖。低质参考不授权重画身份或自主重生。
- **取得真实输入。** 实际查看人物、商品、Logo、印章、二维码、证据与待编辑原图；按[reference](reference.md)区分身份、姿态、构图、配色、光影等参考职责。身份母版按[common](common.md)处理，参考中的人物、品牌、水印、文字、奖项与事件不自动继承。
- **核对生产条件。** 简单纯图直接编写提示词；系列或代码制作按[common](common.md)维护同一 Brief；仅建议或审查不启动生产。缺少传播核心、责任依据或不可替代身份输入时，只问解除阻塞的关键问题，其余已授权工作继续。
- **按路线读取配套。** 图像调用、Prompt 与素材字段按[produce-image](produce-image.md)；混合组装按[produce-hybrid](produce-hybrid.md)；所有 HTML 按[produce-code](produce-code.md)。不另抄工具、状态或参数记录。

### 画幅与数量

| 情形 | 规格与动作 |
|---|---|
| 用户已指定 | 保留实际像素、比例、数量与用途；冲突交入口处理 |
| 一般竖版海报 | 无其他依据时从 **3:4** 起排 |
| 手机全屏／方图／横屏 | 分别采用 **9:16／1:1／16:9** |
| 横向 Banner | 默认 **2.35:1**；视频／横版内容封面用 **16:9**；窄条广告、店招、顶部通栏可用 **3:1** |
| 印刷海报 | 按实际纸张及约定物理规格，不以屏幕比例替代 |
| 数量规划 | 文生图 **1–4 张**、图生图通常 **1 张**仅作规划参考，不扩张单张需求；未指定时取完成传播目标的最少张数，系列或多版位按真实需要安排，不设机械上限 |
| 同内容多尺寸 | 共用准确内容，每个版本完整表达主题和必要信息，不拼成连续长页 |

<a id="shared-content"></a>

## 2. 组织内容

- **集中一个命题。** 围绕同一传播目标组织内容；按用户目标选择扫码、报名或转发，艺术、电影、情绪海报可无 CTA。二维码仅用于确有扫码任务且有真实入口的情形。
- **核实事实。** 价格、参数、数据、日期、地点、认证、身份、联系方式、交易与成果按[common](common.md)核实；缺失只记待补，不在成品放“XX”“某某”或假数值，不以免责声明放行。
- **完善表达。** 可扩写未锁定的标题、副标、叙事、过渡、祝福及基于事实的卖点，不增加未经证实的功能、功效、权益或承诺。
- **保留准确名称。** 锁定标题、片名、品牌名、活动名、产品全称不得缩写或概括；只有允许改标题时才提供替代。演职员、奖项、上映信息须真实；人物金句不冒充真实引语或署名。
- **保留必要字段。** 不适用的时间、地点、行动可省略，适用事实不能为排版删去。发布文案只在用户要求时编写。

### 海报的图文职责

| 产物 | 组织动作 |
|---|---|
| 促销海报 | 突出有依据的利益，使商品、价格、条件与行动关系清楚，不用装饰掩盖限制条件 |
| 品牌形象海报 | 可只保留主体、短 Slogan 与落款，用主体和文字的空间关系表达品牌 |
| 活动宣传／预告 | 以主题吸引和活动性质建立主视觉，时间地点独立成组；主要用于告知安排或邀请参加时优先呈现时间、地点及参加方式 |
| 倒计时海报 | 巨大的倒计时数字作为主视觉，辅以紧迫感短语，背景可采用高对比渐变或质感纹理；严禁滥用“最后机会”“绝对错过”等极限表达 |
| 人物／角色海报 | 以 **1 个身份重点、1 句角色表达、最多 2 项有来源辅助信息**为内容重点 |
| 艺术／电影海报 | 围绕一个视觉命题组织主体、标题与文艺小字，不以虚构事实增强声势 |
| Banner | 精炼主体、利益与行动；品牌位可减为主体、短语和落款 |
| 单张社媒封面 | 单张独立说明主题，图像提供情境或对象，文字补充识别信息；不自动扩为套图或长图 |

## 3. 确定视觉方案

<a id="shared-composition"></a>

### 联合试排与主导关系

先用真实文案、选定字体、素材与目标画幅联合试排，再确定背景生产。不先做空海报后堆字。缩略图下能识别主题与核心信息；避免多个同权重焦点竞争。真实关系平等的参与者可等权并列，但须组成清楚的信息组。

| 主导关系 | 可选做法 |
|---|---|
| 事实主导 | 让事项、状态或日期先进入视线，再排说明与落款 |
| 字体主导 | 用字形、尺度、断行和留白构成主视觉，保留准确全文 |
| 人物／场景主导 | 以姿态、视线、景别和取景引导文字位置 |
| 主题图形主导 | 用主题轮廓、纹样或对象关系连接标题与信息 |
| 实体载体主导 | 用有语义的信笺、票券、文件夹或纸张承托内容 |
| 成果数字主导 | 放大关键数字，同时保留其完整解释信息 |

- 明确第一焦点、第二阅读层、收束点，以及相对位置、图文面积、密度、留白、对齐、遮挡、裁切、背景与前后景。竖版建立主视觉、标题、核心信息及适用落款层级；Banner 可左右分栏、居中或沿焦点流组织，不机械固定左图右字。
- 少内容不靠随机英文、重复口号填版；多内容先合并重复、调整列宽和分组，不删事实、不整体缩小字。标题通常 **1–2 行**，核心短标题建议 **4–14 个中文字符**，不是截断正式长名称的依据。
- 人物稿按身份、姿态和文案建立主次，可用姓名与轮廓穿插、引语沿姿态展开、裁切、尺度反差或不对称留白强化表达；编号仅用于真实系列或顺序。不规定层级或图文关系数量，主体与短标题已能成立时保持简洁。保护眼睛、嘴部、手部和身份特征；锁定原布局时不擅自改版。

### 构图与阅读动线

先确定主导对象，再按主体形态、文案量、阅读顺序和目标画幅选择构图；最后落实裁切、尺度、材质与文字关系。下表是可选方法，不要求逐项采用或按数量叠加。已有参考或锁定布局优先，模板选型按 [templates](templates.md) 执行。

| 构图 | 适用条件 | 组织方法与边界 |
|---|---|---|
| 中心／对称 | 单一标志性主体、仪式感或稳定表达 | 主体与标题围绕中心轴组织，用尺度、留白及轻重建立主次；不为变化强行打破有效对称 |
| 三分／偏置 | 主体需要环境、视线或文案空间 | 主体靠近三分位置或偏向一侧，另一侧承接文字与留白；按真实取景调整，不机械卡在三分线上 |
| 对角线 | 动作、速度感或有明确斜向形态的主体 | 主体、姿态或图文组沿斜向呼应，以另一侧留白平衡；正文保持正常可读，不把全部文字旋转或强加斜线 |
| Z 字形 | 少量信息需依次经过标题、主体和行动／落款 | 上方横向建立入口，斜向转入主视觉，下方横向完成收束；用位置与视觉权重引导，不必画 Z 线，不强套长正文或不适配的阅读方向 |
| 上下／左右分区 | 图文并重、对照或多组必要信息 | 按信息职责划分区域，建立共同对齐线；面积由主体和文案容量决定，不固定五五分、不切散完整信息组 |
| 框景 | 场景、窗口、门洞或实体载体能强化主题 | 用有意义的边缘围合焦点，文字置于框内静区或框外说明区；边框不遮主体身份与必要信息，不无故套重框 |
| 叠层拼贴 | 多张素材、不同尺度或前后关系共同表达主题 | 确定主片、副片和文字层，以遮挡、角度、尺度形成秩序；保护证据、面部和关键文字，不把无关素材堆成装饰 |

按预定入口、主体和收束顺序检查视线能否自然移动；构图名称不能代替实际图文关系，装饰动线不冒充流程或因果。

### 按封面内容安排图文

| 内容 | 图像与文字安排 |
|---|---|
| 测评与知识解读 | 将对象与关键结果、参数或局部细节并置；标题概括问题或结论，标注紧邻对应部位。 |
| 剧情与人物故事 | 选择冲突、动作或反应瞬间，用人物朝向和前后关系突出情节，标题放在动作之外的留白区。 |
| 美食与探店 | 放大食物质地、制作或食用动作，保留能说明场所的环境；短标题与主体错开，避免盖住关键细节。 |
| 生活分享与上新 | 用手持、桌面、开箱或使用场景建立体验感；轻量标题和短注沿物件边缘排列，保留自然光色。 |

<a id="shared-crop"></a>

### 区域、安全区与裁切

以下为内部设计参考，不冒称现行平台官方标准。实际遮挡或印刷裁切更严格时取更严格边界；指定投放位按[platforms](platforms.md)补充。

| 范围 | 参考与例外 |
|---|---|
| 标准竖版、无参考布局 | 品牌区顶部 **8%–12%**、标题区上部 **20%–35%**、主视觉中部 **40%–55%**、收束区底部 **15%–20%**、四周 **4%–8%**；可跨区、叠压、合并，不相加为硬配额 |
| 艺术、纯摄影、字体实验 | 按阅读动线组织，不强套上述分区 |
| 竖版营销海报 | 左右各 **5%** 内不放关键信息；有落款／二维码时保护底部 **8%** 的阅读，不放冲突元素，无此内容不强塞入口 |
| Banner | 左右各 **5%**、上下各 **8%** 内不放关键信息；**3:1** 窄通栏左右可各 **3%** |
| 局部配方样例 | **658 px** 画幅、**42 px** 安全距只作局部校准，不覆盖实际规格 |

摄影、插画和生成素材等比适配。**1%** 容差只用于真实横纵缩放差，不把图框比例不同直接判为拉伸；合法 `cover`／`contain` 按实际取景、主体保护与有效像素判断，无 fit 的直接填充和 `transform` 仍核真实缩放，容差不授权主动变形。

裁切保护面部、手部、接触点、Logo、证书标题和所说明场景。仅已规划的背景、装饰或展示大字可出血，不以隐藏溢出删掉事实。多尺寸可重排、断行、调整取景及装饰密度，不以拉伸或补白代替适配；保持核心信息优先级、事实组合、身份与主风格。

<a id="shared-style"></a>

### 风格、配色与容器

- 依据主体、受众、事项、品牌和参考选 **1 个主风格**，必要时加 **1 个相容辅助方向**。清晰不等于商务极简，品牌或参考已有配色优先。
- 未锁定视觉时，必须落实 **1–3 项**相容的材质、构图、印刷、镜头或图形方法，不只列风格词。下表为可选设计方法，服务已选构图与主导关系。

| 设计方法 | 可执行做法 |
|---|---|
| 透明反射与运动 | 用局部透明叠片、柔和材质反射、倾斜或错位表现层次与方向，避开事实文字，不默认加发光轨迹 |
| 图形纹样 | 提取主题轮廓，沿边缘、网格或非放射路径重复，连接标题与信息组 |
| 文字图像化 | 用准确字形的尺度、笔画、叠压或材质形成主体，仍遵守下述图内文字与原生文字的分工 |
| 实体结构 | 用信笺、票券、文件夹、折片或撕纸组织内容，按实际文长确定结构与留白。平面成品保持正视可读，倾斜样机仅用于展示效果 |
| 印刷材料 | 用纸纹、墨迹、压印或金属表面质感，控制纹理尺度；视觉模拟不宣称真实采用烫金、蚀刻等工艺 |
| 尺度虚实 | 用大小反差、前后遮挡、远近或清晰度差突出主题，事实清楚、身份不变形 |

- 先保护 Logo、肤色、服装、商品及证据原色。营销海报／Banner 主体高饱和且配色未锁定时，必须以中性色或低饱和辅助色中和，不直接以主体高亮色铺满背景。用户明确锁定或真实品牌规范要求同色大面积时保留，用明度、面积与材质区分。多版本共用主色逻辑。
- 逐张决定开放排版或具体容器。需容器时说明内容、主次、位置、轮廓、材质、色面、边缘、厚度／阴影、透明度、内部留白及遮挡；未用效果写无。先测文字容量再定外框，不给每个日期地址套胶囊、按钮或嵌套卡片。
- 普通白色圆角只作中性事实分组，不覆盖全部画面。信笺等载体须有语义；票券不伪造编号或兑换能力，文件夹页签须真实分类，撕纸短框不硬装长文，照片衬纸须确有照片。
- 平面分组默认无投影；实体阴影须有接触、叠压或悬空依据。紧凑／宽松、网格、错落、主图聚焦、拼贴、标注可组合，但须服务同一主关系，不以模板命中证明设计完成。

<a id="shared-background"></a>

### 背景与光影

背景从整张图文关系推导，可选完整影像环境、纸张与织物、商业印刷底面、主题插画、透明材料或连续色场，不是固定颜色模板。文字区可局部纯色或低纹理净空，保持同源连续。已选摄影、纸艺、花艺或复杂材质不得为省事换成普通渐变。连续背景优先共底或扩图，渐隐处理图像自身 Alpha，不铺短黑白渐变遮缝；有意分区可清晰分界。

海报按主视觉与参考选择光影，保持主体、材质和文字可辨。

<a id="shared-assets"></a>

### 图像、准确文字与真实身份分工

- 真实人物照片、Logo、印章、二维码与证据能直接使用时优先独立保留。装饰奖杯不冒充获奖证明，往届现场不冒充本届实况，拼贴不制造不存在的关系。
- HTML 的准确标题、正文、姓名、日期、地点、数字、单位、落款与行动用真实、可独立编辑的原生文字节点（DOM）排版。简单几何、规则容器及可可靠表达的卷边／折片用 CSS／SVG；复杂摄影、自然材质、不规则影像用图片。
- 仅符合[produce-hybrid](produce-hybrid.md)准入的唯一最高优先级艺术主标题可用独立字图，同一独立图片默认最多 **1 个**，逐字核验并按需去底。要求该文字或全部文字可编辑时禁用字图，其他标题不随之栅格化。
- Prompt 格式、准确文字编译、参考实传、素材字段及版本按[produce-image](produce-image.md)，不另建规则。
- 按展示标题、事实标题、正文、日期数字、落款分配字体；选型、真实加载、回退链、禁用字体及 HTML 逐字覆盖按[fonts](fonts.md)。正文不用难读书法，不压扁字形；“囍”和艺术字来自用户源、真实字体或核验过的独立资产。准确且必要的英文可主导视觉，装饰英文不压过事项，不编英文填版。

静态 CTA 只作可理解的行动提示，不冒充真实按钮、交互或已发生状态；禁止假系统通知、已购买、已领取状态及虚假标题、划线价、优惠、认证、医疗功效。实际版位营销限制按[platforms](platforms.md)，对未成年人商业化、极限营销和金融／医疗风险提示从严处理；不把“最／绝对”等字符脱离语义一概禁用。平台名不替代视觉特征，也不因此删除锁定的合法名称、投放信息或联系方式。

<a id="shared-series"></a>

### 系列与既有方案

在原 Brief 逐张记录角色、信息任务和版式分组。共同身份、色彩、字体、装饰与落款形成共同的品牌识别特征；同角色内固定栅格、图文比例、密度与行动位置。主体不必每张出现，跨角色只继承适用关系，不将主活动布局硬套倒计时或子活动位。

需要参考维持一致时使用真实可用的固定参考，明确用途，不机械传上一张，不虚称已批准；仅真实依赖串行。模板比较、采用范围、素材更新与正式组装按[templates](templates.md)及所选生产文件执行；样例不扩大事实、光效或确认授权，局部验证不证明全部素材、字体或尺寸通过。已有 Brief 时，仅设计意图改变才更新；超出锁定内容或尺寸按入口处理，不擅自删改。

<a id="shared-checks"></a>

## 5. 交付各版位独立成稿

| 产物 | 交付内容 |
|---|---|
| 单张纯图 | 指定尺寸的真实完整成图 |
| HTML 海报／Banner | 完整可编辑源及同尺寸完整预览，不以整页位图替代指定编辑区域 |
| 独立系列 | 各角色的独立完整稿，不默认拼成长图 |
| 同内容多尺寸 | 每个指定尺寸的完整稿；HTML 版本各有对应源与预览 |
| 约定印刷稿 | 按已约定规格提供相应文件；物理要求按[produce-code](produce-code.md)及[quality](quality.md)，未实际核验不宣称可直接投产 |

- **按清单交齐。** 遵循用户指定数量、版位及系列角色顺序，每个版本独立完整；单张不擅增，素材不代替成稿，发布文案、源素材及其他附件仅按需求提供。
- **保持版本对应。** 完整源与预览一一对应同一版本，源更新后不沿用旧预览；保存、展示及必要回读只按[quality](quality.md)执行。
- **说明完成范围。** 部分结果明确已交付、可编辑、未解决和未验证范围；诊断不称成稿，候选或本地测试不称已部署、已发布或已通过生产验证，不承诺后台发布。
