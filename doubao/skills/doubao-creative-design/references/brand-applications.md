# 品牌应用规范
目标：将已有或本轮确认的品牌资产转化为可用、美观、有识别特点的点名物料，不重新发明品牌身份。
适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

适用产物：线上传播图、页面视觉稿、宣传册、折页、空间与门店应用、小型印刷物、活动及办公物料等。
核心流程：明确物料与要求（第1节）→组织内容（第2节）→选择主体与构图（第3节）→确定字体、配色与材质（第4节）→按产物选择专属设计方法（第5或第6节）→核对与交付（第7节）。

线上页面与册页使用第5节，印刷物料与空间应用使用第6节；只处理本次要求的产物，不依次制作所有类别。

## 1. 明确物料与要求

以用户点名物料为首要产物。明确用途、受众、观看距离、使用动作、锁定内容及真实载体条件。不默认扩展完整 VI、配色规范页或全渠道全案。

共用事实与需求记录引用[共用规范](common.md)。独立纯图应用效果图直接编写提示词；成套物料及复杂页面维护同一 Brief。生产路线、专属题材路由及批准规则服从[主入口](../SKILL.md)，不互读其他题材全文。HTML 的品牌展示、样机与周边陈列查构图“品牌视觉”，可取 `品牌视觉 样机`、`品牌视觉 周边`、`品牌视觉 三联` 等名称片段；具体物料沿入口指定的题材选型。查询与完整读取按[模板选型](templates.md)执行，依据内容关系和容量采用，不以风格名称推定存在对应模板；纯图不因此查询 HTML，不改变制作路线。

区分身份继承项与应用可变项。继承已确认的品牌名、Logo、IP、包装结构、主色、字体气质、图形母题及传播语气。将参考分别用于身份、主体、空间或视觉方向，不将风格图当身份母版或现场资料。必要母版须实际输入，不以文字复写代替。正式延展已有用户图、历史图或识别参考时，使用实际可用的参考编辑能力；仅在没有可用参考且确需首个核心资产时从零建立。已有源的编辑方式服从入口，参考依赖无法落实时按 common 处理。

新建应用可在授权内重新安排载体、构图、信息层级与场景，不机械保留参考中的偶然道具和裁切。局部修改只调整指定区域；保留原文字、背景及未授权部分。不得为适配版面擅自改造 Logo、角色特征或包装形状。

实体应用按交付职责确定所需资料：图案平面稿或概念效果图依据已知比例、结构及场景设计，未确认条件不冒充生产参数；实景编辑须有对应现场资料。生产或施工文件才以真实尺寸、结构、材料及必要安装资料为前提，不将用户未要求的施工、打样或矢量生产交付扩大为默认范围。先区分设计平面、结构展示、实景效果与生产文件；效果图不能替代刀模或施工资料。

## 2. 组织内容

步骤 1：明确这件物料要介绍什么，读者主要需要了解或完成什么。对允许编辑的标题，写具体内容或行动，避免只堆叠形容词。锁定文案逐字保留，不按版式配额删改。

步骤 2：把已有内容拆为主信息、利益点、支持材料和行动。标题回答主题，利益点回答与受众的关系，证据解释为何可信，行动说明下一步。无依据的证明模块不填满；不编造销量、评分、认证、功效、联系方式或活动事实。

步骤 3：先判断内容关系，再选视觉容器。不要因版面已有圆环、徽章或卡片就补造对应内容。

| 条件 | 具体做法 |
|---|---|
| 表达真实进度 | 按已知总量、阶段或完成值绘制进度图，标明含义；只有阶段信息时用阶段标记，不虚构百分比 |
| 解释操作流程 | 将动作按实际先后拆为步骤，编号与连线共同表示路径；分支单独标识，不把并列利益点画成流程 |
| 比较产品、方案或前后变化 | 并排设置相同尺度的对象和同序比较项；保持拍摄角度、单位及观察条件可比，不用夸张比例暗示优势 |
| 展示材质与工艺 | 用局部细节图对应整体位置，展示织纹、折边、纸面或表面反光；说明可见差异，不用质感照片充当性能认证 |
| 说明分类或同级利益 | 用分组卡片、分栏或图标网格；同级信息采用相同容器，类别差异由标题、图形和图片共同承担 |
| 说明权益和参与条件 | 用票券或权益区承载已确认内容，将适用条件置于相邻阅读区；装饰徽章不得暗示未取得的资质 |
| 叙述时间变化 | 用时间轴连接真实节点，将事件和日期对应；无明确时间关系时改用章节或主题分组 |

高密度页面、册页、折页、信息图、背标及说明卡，在唯一 Brief 中列出完整文案，并分配到对应页面或区域。逐项明确实际标题、标签、正文和说明，不用模糊小字冒充完整内容。图标描述形态和职责，不只写功能名。

按主次排序后再处理密度。先移除无职责装饰，调整分栏与模块间距，再在允许范围内分页。明确要求单张长图时保留同一成品结构；超过真实画幅能力时说明限制，不擅自拆页。无正文时可补写创意文案，包括短标题、组织标签和必要说明；事实、价格、参数及数据须有依据，不得编造，不以固定文字数量反向生成内容。

## 3. 选择主体与构图

先选择最能支持主张的主体。产品用途用产品或使用场景说明，品牌识别用母题或标志性轮廓说明，材料优势用整体与细节对照说明。不要将所有已有资产同时放大。

步骤 1：依据实际轮廓放置主体。细长主体沿竖向展开，横向组合优先留出连续横幅，成组物件按高低与前后组织。以有效可见边界判断大小，不让透明留边造成主体显小。

步骤 2：确定第一眼焦点与第二阅读点。让主标题与主体形成支撑关系；将支持内容落入稳定信息区。先看缩略图是否能辨认主体，再看正文是否有独立阅读空间，不用统一面积比例决定所有载体。

步骤 3：依次处理裁切。先保护 Logo、面部、产品关键结构和必要文字，再裁去无职责环境、空白边缘与次要道具。局部放大可裁母题，但完整身份标识另设可读位置。展示产品结构时优先保留完整边缘，不把瓶体、提手或支架切掉。

| 条件 | 具体做法 |
|---|---|
| 母题有独特转折、轮廓或局部特征 | 在授权范围内截取并放大，作为封面、袋面或墙面的超级符号；试验不同裁切位置，保留足以识别的结构，不任意变形原标志 |
| 内衬、胶带、包装纸或连续背景需要节奏 | 将授权图形按固定单元重复，控制方向、间距和密度；接缝处检查连续性，文字区降低纹样密度或退出纹样 |
| 短标题配强主体 | 用上下标题带、偏轴锚点或满版构图；将文字放在负空间，必要时只对文字承载区调整对比，不给全图覆盖沉重蒙版 |
| 长文案配完整产品或服务图 | 用左右分区或非对称网格，按行长确定文字列宽；让图像跨栏形成节奏，避免所有对象同时错位 |
| 多物件展示系列或材料集合 | 先设主物，再按尺度和方向组织次物；形成疏密与空区，不均匀撒满，不让道具遮住主包装 |
| 需要动作或阅读引导 | 用斜向排列、Z 型阅读线或真实空间消失线连接焦点；箭头只指向实际行动或顺序 |
| 需要强调中心 | 可用平面放射图形组织对象，不将放射构图解释为光束；通知、公告、喜报、邀请函及节庆贺图默认不用，用户明确要求时再采用 |

三段式仅用于三段承担不同任务的情况，不等高切成三张卡片。几何异形用于裁切、引导或层级，不作无意义装饰。居中构图可服务对称结构、极简规范页或单标志展示；一般应用不以居中 Logo 加空背景替代载体设计。

系列保持同一身份锚点，同时从构图、信息层级、媒介结构、场景、材质或互动路径中选择用途相关的差异。可结合两三项共同变化，不以数量达标代替设计判断。落地页强调行动，册页强调阅读节奏，空间强调位置和尺度，小印品强调结构与触感。

## 4. 确定字体、配色与材质

继承品牌字体气质，再按中文笔画密度、字面宽度、行长和观看条件选择字重。短标题可形成紧凑块面；长标题按语义换行，不压扁字形，不孤立关键词。细笔画展示字用于足够大的位置，密集说明优先保证字腔、行距与背景稳定。

传播封面建立一个最高标题层级，副标退一档，同级标签保持同字号和对齐方式。正文靠行距与段距组织，不以大量字重和字体种类制造层级。价格、日期、单位及条件就近组合；远读内容与近读说明分区，不让说明挤占主标题。

先定义颜色职责，再决定面积。用品牌主色建立识别，表面色或纸色承载内容，墨色承担正文与轮廓，强调色提示关键行动。已有标准色不得被近似取色覆盖。两色已能完成任务时不新增无职责颜色。

| 条件 | 具体做法 |
|---|---|
| 封面需要快速识别 | 扩大主色或主图的连续面积，收拢标签用色；标题以明度对比脱离背景，避免主辅色等权争抢 |
| 册页、信纸或说明信息较多 | 扩大纸色与稳定信息底，主色集中于标题、章节和识别位置；正文使用可靠墨色，不将长文全部染成强调色 |
| 页面需要行动引导 | 将强调色集中用于主要按钮或关键标签；装饰降低对比，不让所有卡片都像按钮 |
| 照片或玻璃背景明暗复杂 | 移动文字到稳定区域，或增加局部承载色；按玻璃透光、反射和背景变化检查，不只看纯色稿 |
| 跨载体出现面积变化 | 保持颜色的语义职责；允许纸面扩大、主色缩小，不任意交换主辅身份。经授权的正反白版本按实际背景使用 |

不按行业机械规定低饱和、暖色或冷色。依据品牌认知、图像内容、阅读距离和材料判断。颜色近似值仅作规划参考；印刷、专色与材料色另依真实资料和打样，不由屏幕色反推虚构生产色值。

材质反差用于强调识别或触摸部位。粗织物与哑光纸可突出软硬差别，局部亮面与哑面可突出图形轮廓，金属与纸面可形成光泽层级。将工艺落在有意义的母题、边缘或触摸点，不把烫金、压纹、局部 UV 全部叠加。小字和细线需服从工艺可实现程度。

选择摄影、去背主体或扁平示意时，保持表现逻辑一致。摄影保留真实接触影、折边和材料尺度；去背玻璃保留半透明，不填入页面底色；扁平示意采用正面轮廓、平涂和真实孔洞关系，不混入无依据的立体高光。页面说明与实体印刷标识分清：前者保持阅读层级，后者随实体表面透视呈现。

## 5. 设计线上页面与册页

### 线上传播与页面

封面先让主题与主体成立，再放支持标签。短视频封面按快速扫读扩大主体和短标题；横向头图将标题与视觉焦点并置，减少碎片装饰；内容卡片每页解释一个重点，以同级容器承接信息。活动海报将主题与时间、地点、参与方式分层，保留已提供的完整活动信息。

平台名称仅用于判断画幅、密度和语气，不自动写入画面。不伪造平台界面，不自行添加账号入口、同款或引流词。锁定内容的适用处理交主入口，不扩大为所有品牌物料的禁词。

官网首屏保留导航、Hero、行动入口及下方内容露出。移动端长页按主张、价值、流程、证明和行动组织；缺少事实依据的模块不强补。沿同一栅格连续排布，利用色面、图片和模块间距区分章节，不把长页拼成一串独立海报。报名页优先回答何时何地、参加什么、如何参加。

宽窄适配时重新排序和分区。横版左右关系可转为竖版上下关系；保持主标题、主体与行动的优先级，不等比缩小整个页面。检查真实手机宽度下的正文、按钮和边界，不以大屏预览替代阅读验证。

### 宣传册与折页

宣传册先确定单页、封面、代表性跨页、概览或整本。按内容建立封面识别、导语、产品服务、优势证明及行动引导的阅读节奏，不为凑章节补事实。叙事跨页可用一侧场景、一侧说明；产品比较跨页改为并排对象和同序信息。让高密度页与视觉停顿页交替，保持页码、章节和说明位置稳定。

折页先按真实展开与折叠关系安排内容，再设计跨面构图。

步骤 1：依据已知比例和折法标出面板、折痕、封面及开启方向；生产文件依据确认尺寸、纸张和刀模落实。对折、三折、Z 折、四折分别核对实际折叠顺序，不从展示图比例推定生产尺寸。

步骤 2：按合拢、打开一层、完全展开的顺序分配内容。包心三折的外侧通常分配封面、封底和折入页，具体位置按开启方向及刀模确认；Z 折按交替折向确定封面、封底和各阶段可见面，不套用包心折的折入页关系。各折法均以实际折叠后的可见顺序核对印刷面序。

步骤 3：内侧可跨两至三面组织核心说明，以连续图形或背景建立整体感；标题、人物面部、小字及关键信息避开折痕。每个单面仍应具备可理解的信息入口。

步骤 4：核对折入余量和非等宽要求。包心折等结构可能需要收窄折入面，按实际生产资料落实，不默认等宽。正反上下展示时保持对应尺寸，明确为同一张纸的两面，不画成两套独立六面结构。

高密度多面印刷物不得仅凭画面描述进入纯图执行。概念展示不能替代真实刀模、面序或入口规定的制作路线。

## 6. 设计印刷物料与空间应用

### 小型印刷及办公物料

书签先避让孔位、圆角、丝带和撕线，再安排纵向主体。让母题沿细长版面形成上疏下密、连续延展或局部停顿的节奏；底部设置独立品牌短名或短句区，不将书签拉宽成卡片。短句按语义换行，保持细窄留白。

撕券式书签保持主体、副券、撕线和模切一体化。主图不依赖跨撕线才能完整识别；副券继承同一色彩与小图形，关键权益和条件在撕下后仍可独立阅读。孔位、撕线与工艺区不得互相挤占。

信封正面保持克制，将识别或边角纹样避开实际书写、地址及必要邮寄区域。封口可延续母题，内衬可用重复阵列；核对封舌闭合后的遮挡，不让关键信息消失在折叠内。小卡正面承担主视觉，背面承担信息、活动说明或行动；正反通过边距、色彩和图形对应，不重复塞入同一组信息。

办公信纸为实际书写和打印留足内容面，身份、姓名及联络信息按真实使用顺序分组。规范展示页用标签、样本、对齐轴和尺寸关系解释已确认规则，不套广告场景，不把尚未确认的应用选择写成品牌标准。

互动贴纸按回应、提示或情绪用途设计动作和表情。保持核心角色特征，在授权范围内变化姿态；缩小后仍辨认轮廓和短文字。透明底或白描边按使用背景选择，避免把内部浅色误删为透明。周边按帆布、亚克力、金属和纸卡分别处理线条、开孔及边缘，不只更换样机背景。

### 远读、陈列与空间

立牌将远处需要识别的主题和主体放在不易被遮挡的位置，近读说明下移；结合支架、底座和安全边距安排垂直构图。导视优先箭头、区域名与路径，方向依真实空间确定，不以装饰箭头代替指向。议程板按时间与事件配对，拍照背景避开人物站位对核心识别的遮挡。

门店、展位与陈列以观看距离、人体尺度、安装高度、动线、照明和真实结构确定元素大小。货架先保住包装正面识别，再用重复陈列建立节奏；高物后置、低物前置时保留关键边缘。材质细节用近景补充，整体场景负责验证可见度，不以特写代替空间落地。

实景编辑保留原有透视、采光、硬装及家具关系，只修改授权玻璃、墙面、门头、腰线或装饰区。沿窗框、门窗分割、墙角和柜台边缘展开图案。明确贴膜边缘、透光、反射与视线遮挡；兼顾室内外观察，不用风格图替代实景。多个视角分别保持自身比例和空间关系。

组合静物按真实尺寸摆放，统一桌面、光向和接触影。可通过前后高低形成文案留白，不能拉伸物件或虚构附件。冷光只在需要突出织纹、折边或冷静氛围时选用，不作为系列通用滤镜。

## 7. 验证、规格与交付

未指定画幅时，竖向传播默认 3:4，内容适合时采用 4:5；短视频封面默认 9:16，横向视频与首屏默认 16:9，宽头图默认约 2.35:1。以上为内部建议，不是平台官方标准。按实际入口、遮挡和展示用途适配。

实体尺寸优先采用用户与生产方资料。单页宣传单默认 A4（210×297 mm）；书签默认 50×150 mm，长款采用 50×180 mm。信封须含封舌及开合结构，小卡与配套物保持真实尺寸关系。包装、折页、空间不虚构毫米参数；出血、安全边距、装订、孔位和工艺余量依生产资料落实，未确认项不得声称可直接生产。

| 观察 | 问题 | 调整 |
|---|---|---|
| 缩略图与实际阅读尺寸 | 主体不明、标题争抢或正文糊成色块 | 收拢焦点，扩大有效主体，调整字重、换行及信息区；不删锁定内容 |

| 系列并置与不同触点 | 身份漂移或仅换背景 | 恢复母版特征，按用途重排构图、层级、结构和互动路径 |
| 折叠、撕取、手持与现场视角 | 面序错误、孔位冲突、遮挡关键内容 | 依据真实结构移动分区，核对独立阅读与安装关系 |
