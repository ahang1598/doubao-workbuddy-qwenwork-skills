# 画册与多页册子规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

目标：让整册内容顺序清楚、视觉连贯、单页可读，并交付完整且对应一致的逐页文件。

适用产物：品牌画册、产品目录／手册、业务宣传册和多页作品集；不扩为完整 VI 或三折页，孤立封面、代表性跨页和册页概览不能冒充整册。

**核心流程**：明确产物与要求 → 组织内容 → 确定视觉方案 → 处理跨页与装订 → 核对并交付逐页 HTML、渲染图与阅读 PDF。

## 1. 明确产物与要求

先按阅读用途确定整册职责，再单列尺寸和生产条件。已有有效内容、视觉及资源选型继续沿用，只补本次判断和授权变化；局部修改不重新设计整册。

| 产物 | 读者需要读懂什么 | 可利用的视觉机会 |
|---|---|---|
| 品牌画册 | 品牌理念、产品服务、实践与可信依据 | 用场景摄影、品牌符号和章节重点页形成叙事 |
| 产品目录／手册 | 产品分类、型号差异、适用场景；手册兼顾使用说明 | 统一产品取景与信息位置，安排同类对照、全貌与细节图 |
| 业务宣传册 | 服务对象、问题、方案、优势证据和行动入口 | 用场景引入、服务模块、案例及流程形成递进 |
| 多页作品集 | 项目背景、本人职责、设计过程和最终成果 | 用作品大图、连续图组、过程与结果对照突出重点 |

在 [common](common.md) 规定的唯一 Brief 中记录全册决定；逐页只补职责与差异，不另建分页或生产 Brief。

| 要求 | 记录与处理 |
|---|---|
| 用途与读者 | 明确阅读场景、信息深度、整册范围和约定交付物 |
| 尺寸 | 单列成品宽高、单位及数字／印刷用途；已有源继承锁定尺寸 |
| 方向 | 分别记录单页横竖方向和全册阅读方向，不把横版当作产品分类 |
| 页数 | 记录锁定页数或预计篇幅；说明封面、封底等是否计入 |
| 装订与印刷 | 记录装订方式、已确认出血、纸张及生产方要求；未知项不猜填 |
| 内容与素材 | 记录准确文案、图片来源、身份依据、参考用途及允许编辑范围 |

按 common 核对事实、价格、产品参数、数据、案例、资质及联系方式，不编造；其他创意内容可扩写，包括标题、导语、过渡和基于事实的卖点。缺失项注明所在页及影响，只暂停依赖部分。锁定文字不因拥挤而缩写；页数与内容无法兼容时说明具体冲突。

制作、既有源编辑和批准按 [入口](../SKILL.md) 裁定；普通画册不因多页而增加 KV 或封面审批。混合新建／整体重做按 [produce-hybrid](produce-hybrid.md) 完成实际素材生产，所有 HTML 按 [produce-code](produce-code.md) 实现。

## 2. 组织内容

### 2.1 建立阅读路径

1. 先确定整册主线，再按内容选择封面、导语、目录、章节、正文和封底。短册不必包含所有角色，目录和分隔页必须承担导航或转折职责，不用空页凑数。
2. 按确认的阅读方向落实逐页职责、准确文案、图片来源和相邻关系。目录重检索，宣传册重论点与证据递进，作品集重项目之间及项目内部的叙事。
3. 按内容轻重分配篇幅，不固定每页字数或图片数。锁定页数内先调整分组、图文比例和分页，不擅自增删页或删改原文。
4. 同步页码、目录引用和章节定位。调页后检查后续引用及跨页配对；不得为了叙事虚构案例背景、个人职责或成果。

### 2.2 按内容选择模块

以下策略按读者需要理解或判断的问题展开，可组合、合并或省略，不要求每册按同一顺序铺满。先写清解释及已有依据，再分配页数与图文空间；不把每个要点各拆一页，也不靠增加标签凑信息量。

| 内容策略 | 具体安排 | 适用判断 |
|---|---|---|
| 封面识别 | 品牌或作品名称、主标题、必要短副标题及主视觉 | 明确本册主题，不把整册卖点挤到封面 |
| 导语／品牌故事 | 一句核心理念配场景图或品牌符号，再用短段说明背景 | 先建立理解背景，避免堆口号 |
| 产品目录／手册 | 按类别解释用途、型号差异与适配条件，图片展示全貌或对应细节，保留准确型号、规格与单位；手册按需交代操作及注意事项 | 让读者按共同字段选择或正确使用，不只陈列产品图与标签 |
| 业务／服务说明 | 从读者问题展开服务内容、关键过程、交付内容与适用条件，已有案例就近解释对应做法 | 让读者理解如何解决问题，不将建议流程写成已承诺的服务 |
| 优势与证据 | 按已有材料选数据、资质、反馈、流程或对比；证据贴近所支持论点 | 不把装饰图或生成场景当作真实案例证明 |
| 项目叙事 | 背景与本人职责 → 关键难点与决策依据 → 过程及结果；过程图说明为何这样做，成果图展示完成了什么，细节支持具体判断 | 用于作品集；按真实材料展开，不编造被否决方案、个人贡献或量化成果 |
| 行动引导 | 使用真实电话、网址、地址或预约信息，配清楚的下一步提示 | 有行动目标时设置，不虚构入口 |

## 3. 确定视觉方案

### 3.1 统一字体、配色与页面布局

根据本册主题，明确要让读者理解的重点，选择能说明这一重点的对象、场景或关系，再确定图片、字体、配色、版心、图文比例、图片取景及页码位置。全册共用规则在同一 Brief 中写一次，各页补充内容与布局差异；实现参数留在最终源文件。

HTML 新建／整体重做及局改受影响项按 [templates](templates.md) 选择资源：画册构图查通用，按封面、目录、产品对照、项目叙事等页面用途选择，并检查长标题、参数列、图注和装订内侧空间；配色、容器、材质和背景查对应通用组；完整读取选中正文及依赖，沿用有效选型。含文字 HTML 试排前按 [fonts](fonts.md) 核验字体。

按内容与参考选择以下视觉方向；配色、字体和构图均为设计建议，用户已确定的方案优先。

| 编辑风格 | 配色与字体建议 | 构图与节奏建议 |
|---|---|---|
| 人文品牌叙事 | 暖白纸面、炭黑正文、少量品牌色；宋体标题配黑体正文 | 场景大图引入，窄栏短文承接；章节重点页放大图像，正文回到稳定版心 |
| 清晰产品目录 | 白或浅灰底、深灰文字、单一品牌强调色；黑体分级，用字重区分标题与参数 | 按分类建网格，产品图统一尺度；参数列对齐，重点产品可独占一页 |
| 专业业务宣传 | 米白或白底、深蓝／品牌深色标题、少量暖色提示行动；黑体标题与正文 | 场景页提出问题，图文对页解释方案，证据页紧凑，结尾行动页收束 |
| 图像主导作品集 | 中性底色、黑白文字、从作品中选一种索引色；克制黑体，不与作品字体争主次 | 项目首页用全貌图，后续穿插细节与过程；项目间用标题和留白换节奏 |

### 3.2 安排全册节奏

保持页码系统、字体角色、版心及图注规则一致；章节页、重点产品页和作品全图页可改变密度与构图，不机械复制模板，也不让正文入口漂移。

| 页面关系 | 选用条件与动作 |
|---|---|
| 跨页一景 | 场景需要宽阔空间时使用同源连续画面；装订处安排低信息区域 |
| 图文对页 | 一页主图、一页说明，适合故事或服务解释；图注与论点能准确对应 |
| 连续图组 | 按时间、步骤或视角推进；用统一边界和图注维持顺序，不任意堆图 |
| 同类对照 | 统一比例、视角、字段和单位；差异清楚可查，不靠图像大小暗示虚假优劣 |
| 局部／全貌 | 先交代对象整体，再展示关键细节；用图注说明对应部位，避免失去上下文 |

密集信息页之后可安排较疏的场景页或重点页，但留白要有导航、强调或换章职责。图片等比缩放，裁切保护产品关键部位、人物身份和用户锁定内容；文字冲突先调整布局与分页，不以遮挡、模糊或极端缩字解决。整套预览同时检查章节转折、相邻页密度和正常阅读尺度，不只看封面效果。

## 4. 处理跨页与装订

1. 在 Brief 标明共同观看的相邻页、连续图像及必须单页可理解的信息。背景可以跨页延续，标题、关键文字及主体必须避开装订遮挡。
2. 根据已确认装订条件处理内侧安全区；条件未知时记录影响范围，可先做不依赖该条件的内容与版式，不宣称已满足印刷生产。
3. 保持阅读顺序文件。阅读序不等于拼版序，印刷拼版仅按生产方明确要求处理，不凭经验添加空白页或改排页码。
4. 含书脊封面、特殊折页或生产方要求的跨页稿，按确认展开结构另交。未知书脊、出血、折线参数不能从普通单页尺寸推算；尺寸换算与采样按 produce-code。

跨页预览只展示相邻关系，不替代两个单页。特殊展开稿与普通正文分别标明用途，不混入阅读 PDF 充当普通设计单页。

## 5. 交付

### 5.2 交付完整单页与阅读文件



| 交付物 | 完整性要求 |
|---|---|
| 逐页 HTML | 默认一页一个完整 HTML，承载该页完整设计，按阅读顺序上画布；不以片段或跨页预览替代 |
| 逐页渲染图 | 每页提供与对应 HTML 同尺寸、同版本的完整渲染图；尺寸以确认的单页成品为准 |
| 多页 PDF | 按阅读顺序排列，每个 PDF 页面对应一个设计单页；不自动声称为可印刷拼版稿 |
| 跨页预览 | 按需补充相邻页关系展示，不替代任何单页文件 |
| 特殊展开稿 | 按确认结构另交含书脊封面、特殊折页或指定跨页稿，注明尺寸和用途 |

实际出口、主 Agent 交付、源保存及回读依 quality 执行。交付说明简述视觉主张、可编辑范围、实际文件和未解决事项；不以文件生成代替核验，不声称候选内容已部署或通过生产验证。
