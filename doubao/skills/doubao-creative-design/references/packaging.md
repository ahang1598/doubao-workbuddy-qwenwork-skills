# 包装设计规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

目标：围绕产品事实与使用场景，形成识别鲜明、阅读清楚、结构成立、可按用途延展的包装设计。
适用产物：包装本体效果图、平面展开、标签、纹样、包装纸、配件，以及约定的 SKU、开箱、货架和陈列展示。

核心流程：确认用途与要求 → 确定包装形体与主视觉 → 设计图文与材质 → 处理各面与系列 → 核对并交付约定产物。

核心流程按交付范围选用：本体新建按第2—4节设计主视觉、正面与跨面关系；独立标签、纹样、包装纸及配件直接围绕该产物组织版式，按需使用第3—5节的方法；已有源局改仅检查受影响项。三视图、打开状态与场景用于核对已有依据，只有约定交付时才制作，不为执行本流程新增产物。

## 1. 确认用途、事实与授权

共用事实与需求记录引用[共用规范](common.md)。独立纯图效果图直接编写提示词；包装结构、多面及系列方案维护同一 Brief。生产路线及批准条件引用[主入口](../SKILL.md)，以根入口为最高生产规则。状态、两轮确定性修复及宿主交付引用[质量规范](quality.md)。不另建包装审批或记录流程。

确认包装用于货架购买、线上识别、赠礼、携带、收藏还是运输。确认实际产品形态、容纳数量、保护需求、取用方式和主要观看方向。真实尺寸、刀模及生产资料属于设计成立条件；缺少时只推演比例和结构，不编精确尺寸。

按用户意图限定范围。“做一个包装设计”分别交付效果图与平面展开设计图；仅看效果时不增加展开。点名平面稿、展开稿或刀版图时，以平面为主；无真实刀模时标为设计示意。点名纹样、卡片或封签时优先完成该产物。仅说礼盒或套装，不自动增加完整开箱系统。系列任务优先解决 SKU 识别，陈列任务优先解决正面可见性。

保留用户锁定的品牌、Logo、IP、产品名、文字、结构、数量及编辑范围。新建包装时推演完整母版；已有资产延展时继承授权的身份和视觉变量。涉及图像生成或编辑的延展，应将已有母版或已完成的当前本体设计作为真实参考输入，明确各参考分别约束身份、结构或材质；不以文字复写冒充母版传递。参考传入能力及相关批准条件沿用入口与质量规范，不新增确认。局部修改时只改授权部分，保留其余文字、背景与区域。参考中的道具、光线和裁切不自动成为身份条件。

核对容量、配料、过敏原、营养、功效、产地、认证、许可证、执行标准、监管声明、批号、日期、条码、二维码及联系方式。环保、手作等现实主张也须有依据。概念稿可安排待补信息区，不生成貌似真实的编号、数值或认证图形。可创作非事实性主题词、短句及基于已有事实的卖点，不增加功能承诺。

制作前明确各面最终可见文字及层级，品牌、产品名、SKU、数字和监管信息按依据逐项落实，不让模型自行补字。包装多面信息排版按入口裁定路线，默认走混合路线，准确长文由原生文字层承载，不靠生图强塞密集小字。仅在概念布局范围内可使用清楚短标签与待补信息区；用户要求完整背标时，不得以信息区替代正文。内容或能力不足时保留要求、说明限制，暂停相应产物的可用成稿认定。

## 2. 确定包装形体与主视觉

### 根据装入、取用与开合方式确定形体

步骤 1：依据产品外形和取用动作，确定盒、袋、瓶、罐、软管或标签载体。先判断产品如何装入、固定、取出及重新关闭，再处理表面装饰。

步骤 2：确定主要展示面及开合方向。盒装区分盒盖、抽屉、封套和插口；袋装交代底部支撑、热封口及易撕位置；瓶罐区分容器、盖体、标签和防拆关系。礼盒的内托、隔板与产品间隙须服务承托和取用，不以装饰填满内部。

步骤 3：使轮廓与主题发生联系。需要轻巧便携时减少不必要的外套和突出部件；需要分次取用时考虑独立分装及可恢复的关闭关系；需要开盒仪式时，用外封、揭盖、内衬和卡片形成逐层显露。已有结构未经授权不重做。

### 选择与主题相关的图像、文字或符号

先明确包装要突出的产品特点。把“轻松”“精致”“有食欲”等描述落到可见形态：用疏密与错位形成轻松感，用轮廓、间距和触感建立精致感，用真实产品表面、断面或有依据的原料关系表现食欲。避免同时堆入多个无关故事。

步骤 1：从产品形态、结构线、使用动作、已有 Logo 或授权 IP 中选取可识别特征。

步骤 2：选择主要图像、文字或符号。可使用完整产品图像、局部裁切、抽象符号或产品名造型。先验证其与产品的关系，再补充装饰。

步骤 3：将选定的图像、文字或符号放入主要展示面。比较它与产品名的大小、位置和留白关系，并预判侧面延续、开窗或开合后的变化。

| 条件 | 具体做法 |
|---|---|
| 产品外观或质地直接影响购买 | 选择图像主导。展示有辨识度的外形或断面，将产品名放入稳定净区；减少无依据的配料与夸大体积表现 |
| 产品名、系列名是主要记忆点 | 选择文字主导。以名称建立版面骨架，用字形尺度、行长和空区形成特点；图像退为小型佐证 |
| 已有标志、IP 或母题足以识别 | 选择符号主导。放大一个特征轮廓，用边缘裁切制造张力，另设清楚的品类名称区 |
| 需要亲和但不幼稚 | 用圆角轮廓、自然曲线和适度错位表达轻松；保持产品名稳健、辅助字规整，减少无职责表情与装饰 |
| 需要克制而非空泛的高级感 | 减少竞争焦点，放大字距、纸面与局部触感的差异；保留必要产品信息，不以极小字或低对比代替精致 |

局部放大与阵列重复并列选用。局部放大时，截取仍可辨认的轮廓或细节，放大到正面边缘，作为单一主视觉或底纹。调整裁切位置，使关键特征不被产品名截断。已有 Logo、IP 的裁切、变形及重组须在授权范围内。

## 3. 完成正面母版的图文、字体与材质

### 建立购买阅读顺序

先使观看者判断是什么产品，再识别品牌和具体变体，最后读取卖点与规格。已有品牌具有强购买指向时，可先读品牌，但不得让产品类别隐入装饰。将品牌、产品名、SKU、主视觉、短卖点和净含量按任务排序，不把六类内容做成六个等权焦点。

步骤 1：划出主识别区、图形区和辅助信息区。依据盒面比例安排上下或左右关系，共用一条主要对齐轴。

步骤 2：确定第一焦点和第二锚点。主视觉较大时，用产品名形成第二锚点；产品名主导时，用小图像、色块或符号补足产品线索。

步骤 3：用字号、字重、明度和间距拉开层级。将同组内容靠近，不同任务之间留出明显间隔。避免每行文字都配边框或徽章。

步骤 4：在缩略图中检查品牌、产品类别和 SKU 的识别，在实际尺寸依据可用时另查小字阅读。两种检查不得互相替代。

| 条件 | 具体做法 |
|---|---|
| 图像与名称均需强识别 | 采用上下或左右分区。以约3:7或4:6作为起始关系，按文字长度调整，不强行等分 |
| 主视觉适合大幅裁切 | 让图像接近满版，在自身负空间或局部实色信息面放字；不用整面重蒙版压暗产品 |
| 正面狭长或信息较多 | 建立窄文字列与连续图形区。沿同一轴排品牌、名称和规格，避免多处零碎居中 |
| 需要偏轴张力 | 将母题移向边缘或角部，以名称平衡另一侧空区；只让少数关键元素越界 |
| 需要中心徽章或包围感 | 用轮廓、弧线或边框聚拢视线，保留出口；采用平面放射图形时，不将其解释为照明光束 |

### 选择字形并处理长短文字

依据主表达选择展示字。亲和方向可比较开口舒展、转角柔和的字形；理性方向可比较笔画稳定、结构清楚的字形；传统或精细方向可比较衬线与笔画对比。不要因品类名称直接套用固定字体。已有字标不得随正文换字。

用一套清楚的正文体系承接说明。小尺寸优先选择字腔开放、笔画不易粘连的字形，避免极细笔画、过窄字面和密集反白。展示字的个性集中在产品名或主题处，辅助信息靠字号、字重和间距分层，不靠不断换字体。

长产品名按语义换行，保留完整词组。先调整行数与区域宽度，再微调字号，不横向压扁文字。SKU 名在同一位置使用相近的视觉尺度；长短不一时调整行长和间距，不让长名称显得等级更低。中英文并置时校准视觉字高与基线，避免机械使用同字号。

### 分配颜色职责

从已有品牌资产、真实产品特征和主题中取色，不按行业机械套色。先指定主识别色、纸面或表面色、文字墨色、强调色及 SKU 辅助色，再决定面积。两色已能完成识别时，不增加无职责第三色。

让一个色系主导。可先以大面积主色、较小信息承载面和少量强调色起稿，再按可读性调整。跨载体可改变面积，不任意交换主辅职责。需要精确继承时以用户原始资产为依据；屏幕近似色不等于标准色，更不能反推已验证的印刷或材料色。

用明度差保障产品名与小字。两种鲜艳颜色相邻但明度接近时，插入纸色、墨色或净区。灰阶中层级消失时，先改面积与明度，不仅增加饱和度。SKU 区分同时使用名称和固定位置的色带、标签或小图标，避免只靠颜色识别。

### 让材料与工艺承担明确作用

先满足保护、开合、展示和贴附需求，再选择纸面粗细、透明度与反光。材质不能只作为“高级”标签。粗纹纸可承接质朴触感，但须检查细字与细线；哑面可缓和大色块反光；玻璃和透明窗可展示真实内容物，但须处理背后颜色干扰。

| 条件 | 具体做法 |
|---|---|
| 需要强调标志或可触摸细节 | 将烫印、击凸或压纹集中于标志、主母题或触摸位置；避免所有元素同时做特殊工艺 |
| 需要局部光泽对比 | 用局部 UV 与哑面形成范围清楚的差异，避开依赖稳定阅读的密集小字 |
| 透明瓶、透明标签或开窗 | 将关键文字移到稳定底色区域；需要白墨或遮蔽底层时按生产依据落实。检查内容物深浅变化后的对比 |
| 金属、亮膜或高反光表面 | 将小字避开强高光区域，比较实色标签、哑面信息区或更稳健的字重；不靠消除材料反射伪装可读 |
| 半透明内衬或硫酸纸 | 预判下层图形透出后的叠色与重影，减少重叠区域的细碎文字，使开盒前后均有清楚层级 |

## 4. 映射各面、展开与开合关系

步骤 1：以当前所需正面设计建立母版，不因此新增展示图或确认环节。固定本体比例、开合方式、主展示面、品牌位置、文字层级、色彩职责和材质逻辑。

步骤 2：分配各面内容。侧面承接使用方式、系列线索或故事；背面按成分、用法、警示、生产信息和编码区分组；顶底及封口处理批号、易撕口、挂孔与防拆关系。背标建立组标题、正文和组间距，不将全部内容排成一块密字。

步骤 3：展开同一本体。逐面对应正面、侧面、背面、顶底、粘口、封口与开窗。区分裁切、折线、安全区、出血区和工艺位置。跨面图案先定位共同边缘，再核对折叠后的方向，不把展开中的连续误认为闭合后的连续。

步骤 4：回到三视图及打开状态。核对正、侧、背的尺寸关系、接缝和文字方向。使盒盖、抽屉、内托、隔板、封套及产品摆放能够闭合、抽取和承托，避免内件穿出盒体或开启路径互相阻挡。

曲面标签先确定主展示面、环绕方向、接缝和背标区。将产品名集中在正常观看可见的弧段内，避免跨过侧转折而读不完整。环绕色带在接缝处接续；关键字、图形特征和编码区避开搭接。柔性袋考虑折边、鼓起和握持后的变形，将必要识别内容放在相对稳定区域。

跨面大图形可连续，也可有意在折线处结束。连续时核对轮廓和色块的接续；断开时让各面独立完整。不要把细小识别特征压在折线或粘口上。将开窗纳入图形构图，但不以开窗造型牺牲必要支撑。

平面展开、标签、纹样、包装纸和小配件默认正交俯视或正视。保留轮廓、孔位及面别边界，不加入桌面道具、透视和复杂摄影阴影。可示意纸张、丝印、压纹或烫印效果，不将平面稿渲染为空间场景。

按品类安排有依据的信息。食品饮品关注配料、过敏原、营养和净含量；酒、咖啡、茶关注容量、产地或风味、批次，酒精度须有来源；美妆与补剂关注成分、用法、警示及期限；玩具关注年龄、警示、系列和角色；服饰关注尺码、材质与洗护。这些分区不替代适用法规核验。

## 5. 延展纹样、配件、SKU 与展示

### 组织重复图案与包裹体验

从母版提取 Logo 局部、授权 IP、产品形态、品类符号或结构线。大母题承担识别，中母题组织节奏，小底纹填充空隙。不要因建立纹样而把每一处都铺满。

| 条件 | 具体做法 |
|---|---|
| 需要秩序和货架连续感 | 采用直排，固定单元间距与方向；让盒身或袋身形成稳定节拍 |
| 需要柔和、较少网格痕迹 | 采用半落或错列，错开相邻行主母题，避免形成意外粗条带 |
| 需要对称呼应 | 采用镜像排列，让相邻母题反向呼应；已有 Logo、IP 的镜像处理须在授权范围内 |
| 需要轻松群落 | 采用散点，以一个主点和少量次点组织方向与空区，不均匀撒满 |
| 需要保留大面积文字区 | 将图案收为边框、角花或腰封，让中心或一侧保持净区 |
| 需要醒目单图形 | 采用局部放大，保留可识别特征，调整裁切与疏密，避免名称遮断轮廓 |

检查重复单元四边衔接，扩大铺排后再看是否出现空洞、密结或意外条纹。包装纸同时考虑裁切、折包和封口方向；重要图形不要只在完整大纸上成立。内衬降低图案密度，避免与产品及说明卡争抢。封套和腰封交代环绕接续，预留封签与文字净区。

### 分配配件职责

配饰至少在两个维度与母版互通，可继承图形、纹样、主辅色关系、字体气质、材质工艺、封签形状或开箱顺序。按用途重排，不直接缩小主包装贴图，也不逐件另造风格。

卡片承载短句或信息；说明卡承载必要说明；封签负责开合与防拆提示；贴纸负责装饰或识别；吊牌承载品牌与产品信息。根据握持、粘贴和悬挂方向安排文字、孔位及模切轮廓。小配件减少装饰和无关副文，不因此删改用户锁定的长文。

### 建立同盒型 SKU 变化

保持结构、开合、正面比例、品牌位置、名称层级和主视觉母题不变。仅在授权范围改变辅助色、有依据的口味或香型名、局部材质、标签或小图标。

先确定固定的变体识别区，再把所有 SKU 并排比较。色带使用相近面积，名称保持相近视觉等级，图标保持相同笔画体系。相邻颜色过近时，拉开明度或辅以不同符号；不通过重做整盒构图制造差异。新增变体仍沿用同一规则。

### 组织陈列与开箱视角

| 条件 | 具体做法 |
|---|---|
| 本体与外盒组合展示 | 将较高物件置后、较矮物件置前，错开正面信息；保持同一接触面、光向与合理比例 |
| 需要表现开启与内托 | 使用开盒俯视或适度俯角，显露折页、内格、产品与卡片位置；闭合和打开状态沿用同一结构 |
| 需要核对平面图文 | 使用正面平视，避免透视缩短；扁平示意采用一致轮廓等级，不混入摄影高光 |
| 需要玻璃去背素材 | 保留玻璃透光、半透明边缘与折射，盒体和盖体保持实边；不得用页面底色填死透明区域 |
| 需要货架识别 | 以正常陈列方向排列同系列，减少前排遮挡；缩略查看品牌、类别与变体区，避免道具和光效抢占焦点 |

保持物件完整边界和真实落影，避免漂浮、拉伸或为凑画幅裁掉瓶盖与袋底。场景中的人物、服装和道具仅服务既定使用情境。相关视觉参考仅用于方法提取，不复制示例品牌、配色和角色。HTML 包装展示的陈列布局查构图“品牌视觉”，可取 `品牌视觉 包装`、`品牌视觉 三袋`、`品牌视觉 双瓶` 等名称片段，再按[模板选型](templates.md)完整读取候选。仅借用展示编排，不把陈列模板当作包装结构或刀版；纯图不因此查询 HTML，不改变制作路线。

## 6. 按观察结果调整设计

在授权范围内调整；超出局改边界的问题按[质量规范](quality.md)披露和处理。集中初检与最多两轮确定性修复沿用该规范，不另建循环。

| 观察 | 问题 | 调整 |
|---|---|---|
| 缩略查看正面与陈列 | 看见装饰，读不出产品 | 扩大类别或产品名，收减次要图形，增强信息净区 |
| 按实际尺寸依据查看文字 | 长名称拥挤，小字粘连 | 按语义换行，调整区域宽度、字重和行距，不删锁定内容 |
| 比较彩色、灰阶及深浅背景 | 焦点消失或 SKU 混淆 | 调整明度与色块面积，增加名称或符号的辅助区分 |
| 转动曲面、对照各面与展开 | 接缝断图、文字跨弧不可读 | 重定位主展示区，修正图形起止及搭接避让 |
| 对照闭合、打开与三视图 | 盒盖冲突、内托悬空或比例漂移 | 回查同一本体结构与承托位置，不用阴影掩盖矛盾 |
| 扩大铺排并模拟包裹 | 重复断边、封口切断主母题 | 修正单元边缘、裁切方向和局部留白 |
| 检查反光、透明与工艺区 | 高光吞字、底色干扰阅读 | 调整信息承载面与工艺范围，保留真实材料特征 |
| 对照母版与配件 | 缩小贴图或失去家族关系 | 按用途重排，恢复至少两个互通维度 |

对照制作前确定的各面文字与层级，核对全部事实、锁定原文及完整背标，检查是否有缺漏、错字或擅自补字。

## 7. 核对规格、生产依据与交付范围

图片画幅不等于包装尺寸。以下仅为未锁定画幅时的排版起点，按产物轮廓与内容调整。

| 产物 | 默认画幅参考 |
|---|---|
| 本体展示／正面版式 | 展示1:1或4:5；正面3:4或4:5 |
| 三视图、结构、展开 | 16:9或4:3 |
| 瓶标、罐标、腰封展开 | 3:1或2:1 |
| 重复单元／包装纸 | 单元1:1；包装纸可用1:1、4:3或3:2 |
| 卡片、配件套版、配套系统 | 4:3；竖卡3:4；方形组合1:1 |
| 货架、开箱、陈列 | 16:9或4:5 |

系列方案可参考轻量1–2张、标准3–4张、完整5–6张，不覆盖用户数量。结构任务优先结构与展开，平面延展优先纹样与配件，展示任务优先效果与场景。范围允许的多图系统从闭合、三视图、打开、展开、细节、SKU 或陈列中选择2–3类实际差异；单张和局改除外。合并仅换背景或轻微角度的重复展示。

用于生产时，取得真实刀模、尺寸和生产方要求。按依据落实刀线、折线、孔位、粘口和工艺层。出血、安全距离、色彩模式、纸张克重、专色、刀模线型及印后参数不得自行编定。核对实际结构并完成规格和文件检查后，才称为生产稿；仅有尺寸或逼真效果不代表生产验证完成。

分别交付约定的独立产物，不用总画布替代文件。用户要求的三视图、套版或色彩系统板可作为单件组合产物。说明文件属于效果展示、设计／结构示意还是生产稿，并保留未完成内容及限制。宿主存储、展示和交付按[质量规范](quality.md)执行，不声称未发生的归档或生产验证。
