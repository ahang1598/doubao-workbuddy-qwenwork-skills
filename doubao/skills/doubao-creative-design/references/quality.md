# 素材与交付

图像与素材检查仅适用于 `image-coding`；HTML 成品检查适用于 `pure-coding` 与 `image-coding`。纯图产物按主入口执行适用的数量门禁，不适用本文件的成品检查；长图段图和拼接成品生成后立即交付，不做生成后计数或质量检查。

### 图像与素材

- **核对用途及输入。** 区分完整终图、背景和独立素材；检查真实母版、当前编辑目标与保护项。包装文字、标签和Logo属于身份内容，不因“不新增文字”而擦除。
- **核对真实像素。** 检查输出宽高、裁切后有效像素、轮廓、比例、颜色、结构及系列一致性。插值不增加细节；合法cover/contain不因图框比例不同判为拉伸。每个使用位置分别检查，算法见生产规范。
- **按职责处理背景。** 完整场景、照片窗及一体Hero可保留背景；独立主体不为迁就白底改成卡片。裁切、蒙版、混合模式与抠图不能互相冒充。
- **验证真实透明。** 位图检查有效透明像素，SVG检查背景填充、引用图像及渲染；再在浅底、深底和实际背景检查孔洞、毛发、残底、色边与误删。PNG后缀、棋盘格或全不透明RGBA不证明透明；完整终图不强制Alpha。
- **限定混合模式。** 人物、商品及多色插画不以混合冒充透明。普通Logo展示仅按Logo专项例外使用节点级混合，VI独立Logo层不适用。艺术标题按 `produce-hybrid.md` 的稳定背景例外接入；透明导出、跨背景或严格保色使用真实透明结果，混合不作用于父容器或整页。
- **核对实际消费者。** 素材项保持一个 `output`，同结果多处共用，不同采用结果分项；维护 `asset_id`、`consumers`、`reference_inputs` 与 `postprocess`。检查img、srcset、CSS背景/蒙版、伪元素及SVG image实际引用，不因同URL而全部替换。

- **检查当前采用的素材。** 混合制作的正式素材生成前运行 [validate_asset_manifest.py](../scripts/validate_asset_manifest.py)；候选 KV 按入口先生成，不要求正式素材清单。用重复的 `--asset-id` 指定当前素材及全部依赖，编写或组装当前范围 HTML 前加 `--require-ready` 检查这些素材均为 ready／reused；不指定 ID 时检查整份清单。`unresolved_blockers` 中，文字条目表示整体阻断，局部阻断用 `{"asset_ids":["受影响素材ID"],"reason":"原因"}` 记录，不删除其他范围或历史记录来通过检查。仅改字或间距且不处理素材时，沿用未变资产，不补建整份历史清单。脚本通过不代替实际加载、展示与视觉核验。

### HTML 成品

全部计划页／屏完成后，统一渲染同版本完整 HTML：先看整页／整条结构，再按实际阅读尺寸检查文字与主体，集中修正。纯代码不建混合素材清单；脚本通过不等于视觉通过。已有源局改只检查授权范围及必要联动区域；封面批准等前置检查仍按主入口执行。

- **尺寸与资源。** 按 `produce-code.md` 同步画布属性及 html、body、作品根容器的行内宽高，运行 `shot.py` 修复尺寸、资源与溢出问题；核对裁切、页序、素材绑定和文字可编辑性，不绕过检查另行导出。
- **布局与连续性。** 检查双栏失衡、尾部空置、重复卡片、同组内容拆散及辅助图无依据独占大屏，按 `common.md` 重排。长图查看整条和相邻接缝：连续图片须有比较、步骤或叙事推进，说明须就近对应对象；先调分组、说明位置或图尺度，不补空话隔图。等宽、无缝不代表视觉连续；有意换章不判为断裂。
- **焦点与遮挡。** 首屏符合既定图文主次；文字、装饰、容器及接缝不遮挡关键五官、产品特征或证据。冲突先移字、调整取景或重排，素材仍不适配时按原路线和编辑权限处理。图片框与文字框相交不直接判错，脚本不代替图像语义检查。社媒混合首屏另查实际资产与文字实现，确认含字整图及明确的编辑例外，不能仅凭截图推断生产方式。
- **实际断行。** 查看标题、商品名、栏目名和短标签的孤字、拆词、标点悬挂；如“原色拼／接”“牛仔夹／克”须保持词组完整。按下述检测结果和预览修正，不只看有无告警。

### 孤字定位与修复

`shot.py` 在字体加载、布局稳定后检查 DOM 短文本的汉字单字行。发现可疑项返回 `TEXT_WRAP_REVIEW`，在 `textWrap.findings` 记录元素定位、实际分行、可疑行号与位置，并保留截图；脚本不改字、缩字或重排。

修复顺序：

1. 调整文字栏宽和图文占比。
2. 按完整词组断行，清除不合适的强制换行。
3. 仍放不下时，在题材字号规范和可读范围内调整字号、字距。

不压缩字形、隐藏文字或删改锁定文案；图内标题按原路线处理，不用 DOM 覆字修补或自主重生。确认有意单字强调时，仅在对应文本元素设置 `data-text-wrap-intent="single-character"` 和写明原因的 `data-text-wrap-reason`，不在整页或祖先容器批量豁免。

脚本不识别图片内文字，也不能判断全部语义断词。资源或布局未稳定时，`textWrap.status=not_ready`，需修复后重渲染。竖排、复杂混排、变换和超长文本等记入 `textWrap.skipped`，须看预览；有意单字强调不机械判错，无告警不代表全部正确。

### 修复后复验

独立页面只重渲染受影响页；连续长图修改后更新完整预览，复验聚焦修改区域。尺寸、背景或分组变化时，同时复查相邻接缝与整页节奏，确认未新增断行、遮挡或溢出；不重复细查未变内容。
