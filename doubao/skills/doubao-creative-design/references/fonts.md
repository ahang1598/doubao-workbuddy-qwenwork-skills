# 字体与排版

## 1. 概述

- 统一字体选型、资源核验、文字层级、阅读尺度与回退；路线、格式和批准由 [SKILL.md](../SKILL.md) 裁决。字体失败不构成改格式、重做 Logo 或栅格化普通可编辑文字的理由。
- 需求记录、事实缺口、锁定原文与身份保护归 [common.md](common.md)；执行状态、集中初检、最多两轮确定性修复、禁止自主 AI 质量重生及交付归 [quality.md](quality.md)，不另建检查链。
- **本文件的历史登记、旧平台集合及场景数值均为内部参考，不是已核验的现行官方标准；登记数量不代表当前安装或验证数量，试排线不代表低于即失败、高于即合格。**
- 分开记录**推荐适配、资源存在、字形覆盖、目标环境实际命中**。推荐、平台注册、本地安装、CDN 探测、FontFace 加载或截图正常，均不能单独证明其余项通过；不可观察的命中记未验证，不虚构能力或结果。

## 2. 使用场景

- **字体建议**：按语种、形态、角色与阅读状态选型，不强制制作或字体契约。
- **图像内文字**：借用字形、重量与搭配意图，不承诺精确 family，不强制安装、DOM、独立契约或另生成试排图。
- **实际字体排版**：核验许可、真实文件／face、文案覆盖与目标加载；可编辑文字沿既定分配保持原生。pure-coding 与 image-coding 的 HTML 实现归 [produce-code.md](produce-code.md)。
- **已有品牌或参考**：保留锁定形态、重量、姿态及关键字形；未知字体只描述可见笔画，不冒充识别结果。

## 3. 核心流程

### 确定条件与候选

- 明确尺寸、准确文案、语言、身份、品牌字体、关键字形、参考用途与阅读条件；简单纯图落实到提示词，复杂任务保留在同一 Brief，事实待补沿共用记录处理。
- 先看真实语种、信息优先级、长度和阅读尺度，再保留用户／参考要求。未限定维度依次由组合意图、主主题、同角色同语种候选补足；主题不等同字体，多主题取一个主主题、一个修饰意图，不叠两套语法。
- 通常比较 **2–3 个**适配候选，明确命中时不凑数。全部召回阶段同时执行语种、形态、标签与排除项，多标签取交集；不足保留 `shortfall`，不删条件、换语言或用不兼容字体补数。
- 默认两个协调家族，也可用单家族真实字重建立层级；多语种补充须有覆盖和搭配依据，不逐模块换字体。

### 查询与分类

- 候选、主题查询只消费 `assets/fonts/font-curated-pool.json`；`font_key` 不是 CSS family。完整资源按需读同组平铺的 `chinese.json`、`latin.json`、`multilingual.json`、`font-cdn-manifest.json`、`web-font-manifest.json`，不复制目录。
- 旧登记规模：中文／CJK 187、拉丁 874、多语种 500、推荐 157、平台 70 family。
- `scripts/select_fonts.py` 仅查询候选、缺口与诊断；`scripts/resolve_font.py` 按通道解析精确身份、face 与资源状态。仅用已部署能力，不假定脚本或参数存在。`local_paths` 是预期位置，缓存缺失不等于目录损坏；未解析 ID 不得编造文件、URL、face 或授权。
- 正向分类以候选池 `tags` 为准；`style_classification` 仅说明元数据整理、字样审核或证据不足，不是另一套标签或可用状态。补充判断须有明确描述，或相同文案、字号、无特效字样依据；新审核展示体先限主标题，不凭大字样开放正文。

### 许可与就绪状态

| 状态 | 证明范围与使用边界 |
|---|---|
| `editorial_candidate` | 仅代表视觉分类 |
| `registered_unclassified` | 不进入默认推荐 |
| `local_present` | 仅证明文件存在 |
| `cdn_listed_not_rechecked` | 仅证明历史收录 |
| `listed_not_runtime_verified` | 仅证明匹配平台表 |
| `not_installed`、`unresolved`、`invalid`、`blocked_by_license` | 不得作为正式可用资源 |
| `ready` | 本次目标环境的许可、正确family/face、真实字重、完整覆盖与加载均通过；查询不产生此状态 |
| `contract_ready=true` | 仅证明本地许可、family、覆盖通过；`target_environment_status=not_checked` 时目标端仍未验证 |

- 收录或 CDN 可达不等于许可通过。自动下载仅限明确开源且许可证为 **OFL、Apache 或 Ubuntu Font License**；非标、失效、不明或禁止再分发先核现有授权／替代。子集化、修改、收费服务、公开再分发另核许可。系统字体可记 `system` 来源，不复制进 Skill 或交付包。

### HTML 加载

- 用最终可见文案，按所需 family、weight、style 去重解析；参数、资源、环境未变的成功结果可复用，失败只处理对应项。消费 Resolver 的真实 face、`font_face_css`、`font_stack`，不猜身份、格式、路径或改写主 family。
- 选型优先使用 Web manifest 中已登记的真实字体地址与 face；未登记资源须有真实来源、许可及字重依据，不猜路径。资源准入由 [web-font-policy.json](../assets/fonts/web-font-policy.json) 配置，当前仅允许 `lf-flow-web-cdn.doubao.com` 的 `/obj/flow-doubao/doubao/infinite-canvas/fonts/v1/` 目录；示例中的其他 CDN 未自动启用。目录登记、地址合法和本次加载成功分别核验。
- 浏览器直接加载远端字体；禁止用 local()、相对路径、file://、data:／Base64 或 blob: 声明字体源，不为加载失败另找托管或重新上传字体。每个真实 weight/style 分别解析并避免冲突；声明可用普通样式块或可加载样式表，不限定块名、数量或与普通 CSS 分离，不强制字体 CSS 全部行内化。禁止本地绝对路径、`file://`、临时缓存路径。
- 预览、截图、导出前等待 `document.fonts.ready`，结合目标诊断、真实字形与截图检查实际命中、缺字、替换、基线、换行、伪粗及裁切。cmap 覆盖不证明浏览器命中，加载完成不证明全部字符命中目标 face。
- `coverage_status=not_checked` 不要求 HTML 自动转本地流程；仅离线或二进制核验确有需要时本地处理。工具输出按 UTF-8 保存，执行服从实际宿主。

### 字体失败处理

- **先查具体错误。** 分开记录资源声明不合规、网络／CORS／CSP 加载失败、字重不符和缺字；定位失败 URL、family、weight 与使用位置，不因一次失败判断整个 CDN 不可用。
- **有限修复。** 对已定位原因做一次针对性修复或重试；仍失败时，自选字体换同语种、同角色、符合字形要求的可用远端字体。用户锁定字体按下述回退规则处理；未解决时暂停依赖部分，不以重复渲染碰运气。
- **不扩展为托管任务。** 不默认查找写入凭证、测试多个托管平台或制作字体子集。确需离线／子集方案时另核授权、许可、编辑后字符覆盖及交付支持，不用内嵌字体绕过资源检查。

- **混合排版检查。** 核对实际字体加载结果、字重和文字覆盖。

### 本地／Canvas 文件

- 下载只用下载 manifest 内 `verified=true` 的完整 URL，下载 URL 集合须为 Web manifest URL 的子集。当前 CDN 为 `lf-flow-web-cdn.doubao.com`；仅使用清单完整 URL，不由根地址拼接路径，不沿用曾返回 404 的旧 packages 路径。旧验证对象思源黑体简体 VF、抖音美好体、优设得意黑仍须核本次可达性。
- 核对 catalog ID、实际路径、完整 URL、大小、MD5、Content-Type、验证日期；新增登记须实际探测与文件头验证。WOFF/WOFF2 解码需 FontTools 与 Brotli；缺依赖或二进制损坏记不支持／未就绪，不凭后缀判覆盖。
- 索引平铺不抹平外部包层级：保留包内相对路径，同名不同目录不覆盖。写前检查全部目标，同内容可重复登记，不同内容拒绝覆盖，越界链接拒绝登记；失败撤回本次新增项，晚到冲突保留原文件并报错。保持 URL 转义，不把 `%20` 变成 `%2520`。

### 受约束平台字段

- 仅明确引用平台表的 Canvas Item 字体字段受限：提交精确 family 及登记的 normal/italic 字重，不填显示名或 CSS 栈。`platform_fonts` 为登记镜像，扩充候选不扩大注册资格；有当前画布实际清单时以其为准。旧表未含 `Songti SC`、`Georgia`、`Inter`，不构成 HTML DOM 禁用名单。

| 精确 family | 登记字重／样式 |
|---|---|
| `Source Han Sans SC VF` | normal 250/300/350/400/500/700/900；正文可从400、标题700起排 |
| `寒蝉锦书宋Pro` | normal 400/700；italic 600 |
| `Source Han Serif CN` | 仅 normal 600，不填400 |
| `Montserrat` | normal/italic 均100–900，步长100 |
| `Alegreya` | normal 400/500/700/800/900，无italic |
| `PingFang SC`、`Arial`、`Helvetica Neue` | normal 400/500/600/700，依赖目标设备 |
| `S-Core Dream` | 仅 normal 300，不推断700 |

- 其他集合查精确登记，不凭范围外推；HTML 使用实测 face。

## 4. 不同产物/策略展开

### 角色、形态与效果

| 角色 | 职责 | 字重／相对正文大小试排起点 |
|---|---|---|
| hero | 唯一最高焦点、主标题、品牌名 | 600–900；3–6× |
| sub | 栏目、章节、卖点标题 | 500–700；1.5–2.5× |
| body | 连续说明、经历、规则、参数 | 400–500；1× |
| meta | 注释、编号、页码、辅助信息 | 400–600；0.75–0.95× |

- 范围不证明资源有对应实例。价格、核心日期、数据可升为 hero/sub，不因字段名固定小字，也不因重要而用难读展示体。body 禁用书法、像素、黑信体、强装饰字体；`dark_horror`、`street_y2k`、强手写限短标题，不进入简历正文、公告事实、参数、价格或 UI。
- 可编辑独立艺术标题的准入与品类例外见 [produce-hybrid.md](produce-hybrid.md)“独立艺术标题只服务唯一视觉入口”，须在 Brief 明确；一体化 Hero 沿既定分配。图像内文字只共享视觉角色，不继承该准入限制。
- 黑体不等于粗体，宋体不等于细体；自然手写与书法章法不同，圆角不自动童趣，窄字不自动速度。CSS weight 不跨家族等同视觉重量。分别核验 italic、oblique、内置倾斜，不用伪粗、伪斜、横向压缩或再次斜切冒充 face。
- 书法、毛笔／软笔、手写、创意分别按 calligraphy、brush／soft-brush、handwritten、creative 判断；普通硬笔、墨感黑体不凭名称归毛笔。气质按需求取交集，“狂放且可爱”无交集时不静默删标签。
- 关键展示字先看无特效字样，再放回真实背景。细体、细窄、高反差衬线细笔画用清晰实色，禁描边叠投影、多层套边、错位重影。标题每次一个主要强调机制；多色套印仅在参考明确需要且轮廓清晰时用。粗体不侵蚀字腔或压下一行，正文、参数、小标签不继承标题效果。问题先去描边／投影，再调真实重量、字形、字号，不追加套边补救。

### 字体禁用与条件准入

- `胡敬礼毛笔行书`、`HuJingLi-Mao`、`胡敬礼毛笔行书简.TTF` 及别名禁止候选、精确解析和回退，仅用户明确解除才恢复；不据此删除或卸载系统字体。
- 沐瑶软笔默认不推荐。仅用户明确同时要求“可爱＋毛笔／软笔”的短标题才准入，排在其他合格候选后；国风、山野、非遗、童趣、手写、可爱单独出现均不足。明确点名可精确解析，但不绕过禁用、许可、覆盖；已有 Brief 时记录选型理由，不新增字段表。
- 沐瑶支持可爱、温暖手作，不按狂放或清新毛笔召回；流江草体支持狂放，马善政楷书支持端正传统，莫大毛笔的狂放／可爱／清新证据不足。缺正向标签非永久禁用，也不证明其他类别已审核。
- 得意黑仅在需要倾斜、窄长、尖锐笔势时考虑，不作为通用标题。资源400 Oblique与平台400 italic为不同证据；HTML用实测face，受约束Item用协议枚举，不推断700／900，不叠伪斜。
- 清松第7款不等于第8／9款，第3款繁体样字不证简体覆盖。齐伋各包、CN／SC／TW／VF、轻量版、点阵变体分别核验，不合并实例；龙藏锁定具体版本。Zen Antique仅为日语标题候选，未证明等同“Zen 老式明朝”或覆盖中文。
- Oswald核验可变轴，不以同名ExtraLight冒充Bold；Playfair Display核验Regular实例，不挪用另一DEMO造型；阿里巴巴普惠体目录仅Regular，不推断粗体。寒蝉点阵体不用于正文、价格、事实；齐伋刻本、书法不进入密集正文。

### 主题与产物

- 烘焙／手作区分圆润产品形态与自然笔迹；茶饮／新中式先比宋、明、仿宋、楷与书写，不默认毛笔；时尚／杂志看反差、阅读距离、中英墨色；促销／运动用真实粗体，仅需动态才倾斜；旅行／自然生活不把整段改手写。新中式、杂志编辑、自然生活与原主题共存，不另建排名。
- 简历主题限 `business_pro`、`minimal_modern`、`luxury_elegant`、`retro_classic`、`literary_academic`、`japanese_fresh`。运营公告优先商务／极简，婚礼邀请优先典雅／东方，喜报优先商务／运动力量／东方，节庆按品牌选择。
- Logo字体仅是字标起点，不自动变成VI正文或UI字体；保留批准母版。可编辑VI角色进入既定Token、组件与应用，规范样张须用真实字体、字重，图像不冒充精确样张。
- 三折页在既定六面、折法、尺寸内试排，超量先调内容分配、栏宽、行距，不改纸幅或无限缩字。

### 阅读尺度与换算

- 用户、品牌、渠道、制作要求在其范围内执行。屏幕值为最终阅读状态的CSS逻辑像素，纸张pt为最终物理字号，不直接套任意HTML母版。
- 设母版CSS宽W、整张画布在阅读端的实际显示宽V（扣除宿主外侧边距，不扣画布内部留白或正文栏边距）、源字号F、无单位行高L：`s=V/W`，`有效字号=F×s`，`F=目标有效字号×W/V`，`最终行高=F×L×s`。
- 同构图W1→W2时，字体、固定行高、框、间距、坐标、画布高度均乘 `W2/W1`，无单位行高不再乘。改长宽比、仅加高度、改多栏属于重排，不机械缩放。
- 例如360宽16px对应同构图1080宽48px；1080宽仍用16px，缩回360仅5.33px。360不是统一验收宽度；电商详情页未指定手机阅读宽度时按390px检查，其他产物按各自阅读条件确定。
- 仅提高采样倍率／DPR不改CSS布局或字号。已知源且整图无额外裁切变形时：`有效字号=F×采样倍率×最终显示宽度/导出像素宽度`。预览缩放只计一次，局部transform另计；非等比字形拉伸须修复，不以根transform掩盖溢出。只有位图时看实际阅读效果，不猜源字号。
- 纸张成品宽M mm、字号P pt：`F=P×25.4/72×W/M`，`P=F×M/W×72/25.4`。M为对应整页宽，非正文栏宽，出血前后不混用。`1in=96px=72pt`；原生A4 CSS宽约793.70px，无额外缩放时12pt=16px。PDF／打印落实物理尺寸及打印缩放；A4比例或截图不能证明pt验收，也不能推断用户要印刷。

| 场景 | 默认字号与验收要求 |
|---|---|
| 社媒长图、屏幕连续说明 | 正文16–19px、低于16px复核；辅助14–16px、低于14px复核。旧网页正文／行高16/24px及19/25px、小字14／16px不混为统一要求；标题无28/20px通用硬下限 |
| 简历 | 定尺寸文档10–12pt，中文可从11–12pt起排；必要日期、联系方式沿正文尺度，低于10pt重点复核，不统一放行9pt。姓名不强制24–32pt或最低22pt；A4仅默认文档选择，英文行高1.2仅试排 |
| 菜单 | 手机菜名、价格、关键条件16–19px，辅助14–16px，分别低于16/14px复核；纸质近读12–14pt、低于12pt复核，暗环境或大字需求再增大。无11/10/9pt角色底线；墙面按实体字高、距离、视角、亮度实测 |
| 电商详情页 | 按最终阅读宽度计算：正文默认16–19px，辅助说明默认14–16px，所有内容文字不得低于13px。手机阅读宽度未指定时按390px检查；13px是下限，不是正文默认值 |
| 三折页 | 按实际成品尺寸：正文默认12pt、不得低于11pt；图注及短辅助说明默认11pt、不得低于10pt；日期、地址、联系方式、价格及使用条件按正文下限执行。数字专用且无物理尺寸时，正文默认16–19px、不得低于16px，辅助默认14–16px、不得低于14px，按实际阅读宽度换算 |
| VI展示板 | 以1600px宽母版为基准：正文默认25–30px，正文、章节信息及主要说明不得低于20px；短辅助说明、图注及来源默认16–20px，不得低于16px。其他母版宽度按W/1600换算，并在实际阅读尺寸检查；效果图内文字不承担展示板说明 |
| 信息图、关系与流程图（数字阅读） | 按实际显示宽度换算：解释正文、节点文字、步骤、关键部件及关系标注默认16–20px，不得低于16px；短图注、图例及来源默认14–16px，不得低于14px。关键条件、单位和必要解释不降为辅助小字。先明确阅读端与显示宽度；无依据时记录阅读假设，不以导出像素或放大查看代替验收。纸质版本按实际纸幅与阅读距离另定，不直接套屏幕px |
| 其他产物 | 画册定物理尺寸后可从12pt起排；名片、票券、包装无8/9pt统一底线，按各题材和制作要求执行 |

- 上述详情页、三折页、VI及数字信息图／关系与流程图下限为本skill的设计验收要求，不冒称平台或印刷行业标准。低于下限须增大字号或重排，不以“看起来可读”放行；达到下限但实际难读仍须修正。仅用户明确锁定字号或必须遵循的外部规范与此冲突时，保留其要求并说明冲突，不记为通过本项检查。纯图按目标阅读尺度规划字号，出图后按主入口规定交付，不增加文字质量检查。

- 中文连续正文从行高1.5试排，可比1.5–2；行间空白0.5–1倍不等于CSS line-height，短题、单行金额另测。长说明默认左轴，书刊式中文可两端齐，检查禁则、末行、孤字、中西间距，不拉满短末行或空格凑列。
- 不设统一每行14–24字、固定段距、菜单0.5–0.8／1–1.5倍间距门禁；按条目内、条目间、章节间递进分组。金额独立右轴对齐菜名首行，规格矩阵留列头；简历机构、正文、项目符号共左轴，日期统一右轴或邻接，长邮箱正常换行。
- 网页可访问性按实际交付目标检查用户覆盖行高1.5、段后2、字距0.12、词距0.16倍及文字200%放大适配，非作者默认值；图片文字等有适用例外，WCAG无统一最小字号。静态截图合格不证明网页无障碍合格。

### 回退

- 顺序：同语种、同角色、满足锁定形态的组合／主题候选 → 同条件其他候选 → 同形态中性字体并记差异 。系统字体只作备用，不替代远端首选字体声明。思源黑体仅适合中性黑体任务，非宋体、手写、书法、韩文通用回退。
- 用户指定字体失败先按原因恢复；仍失败且不破坏另行锁定的关键字形时可合格回退，复查并说明未生效目标与实际字体。锁定字形无解或许可不足先确认授权／替代，只暂停相关部分；模型自选字体可自行换合格字体，不静默用浏览器默认值。

## 5. 输出形式

- 需要 Brief 的任务在同一文档记录选型理由、条件准入、角色、阅读假设、`shortfall`及回退差异；实现值留最终HTML，结论入既有验收记录，不强制独立 `font-contract.json`。
- 仅既定workflow要求时提供字体契约：精确family、真实face／字重、来源、已存在绝对路径或system来源、覆盖、回退栈、hero/body等角色。角色不绑定对象类型或协议。
- `source=target_environment`、`availability=verified` 仅目标端实测后成立，下载记录不冒充就绪契约；字体加载、覆盖、视觉可读性分别记录。
