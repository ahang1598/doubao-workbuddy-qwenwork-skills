# 社媒连续长图

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做计数或质量检查；授权拼接的操作完整性核对及回退按主入口执行。

围绕一个主题组织连续信息，使读者逐段理解结论、找到依据，并在需要时行动。

适用：一张连续阅读的社媒长图，包括图片与可编辑文字组合的长页，以及入口授权的纯图长页；不按独立发布的套图组织。

**核心流程**：明确载体与约束 → 组织内容链 → 设计图文、背景并试排 → 核对与交付

## 1. 明确载体与约束

确定阅读条件、尺寸和编辑范围，保留用户已锁定的要求。

### 载体、尺寸与制作范围

- 明确发布载体、目标宽度、总高是否锁定及阅读方式；缺失信息影响制作时集中澄清。手机阅读尺寸不决定宿主。
- Brief、事实、身份、参考用途及设计变更按 [common.md](common.md) 记录；已有源按 [edit.md](edit.md) 保留完整基线，只改授权范围及必要联动区域。
- 路线、纯图例外与方向样图（KV）的确认要求由 [主入口](../SKILL.md) 决定；获准纯图长页的严格分段阈值、生成依赖及完整拼接按 [produce-image.md](produce-image.md) 执行。
- 发布尺寸、安全区与裁切约束按 [platforms.md](platforms.md) 的适用范围读取。
- 混合长图保留一个完整 HTML 文档及同版本、同尺寸的完整整图预览，不用段图替代，不因导出图片压平已有源；实现按 [produce-code.md](produce-code.md) 执行。

### 首屏规格与文字边界

- **首屏高度**：包括开场至下一章节入口的完整构图，一般采用 **H/W＝1.5–1.8**，向下段衔接时默认 **1.8**。用户明确尺寸，或完整采用且规定首屏高度的命名模板或样式方案，优先于默认值；仅借色或局部构图不构成例外。**1:1、3:4** 不作默认，方向 KV 的 **1920×1080** 不替代正式首屏比例。
- **过渡安全区**：计入首屏，避开主标题、主体与关键信息，不额外加高或用空白补比例。后续内容段按完整内容测量，不继承首屏高度。
- **混合首屏默认含字整图**：将背景、主体、主标题及适量辅助文案联合制作成完整图片并用于首屏，不能改为无字底图加原生主标题。只有用户明确要求某处文字独立可编辑，才将对应文字排除出图、预留位置并原生实现；风格或位置描述不等于编辑要求。
- **后续正文与真实资产**：后续正文保持原生可编辑，真实 Logo、二维码与证据保留原资产边界。首屏整图可替换不等于图片内文字可编辑，一体首屏不另拆艺术字图。

## 2. 组织内容链

先确定读者需要获得什么，再安排各段结论、解释、前后交接和配图。

### 选择阅读目的与内容链

按适用场景选择起点，允许合并、拆分或调整顺序，不将购买论证、管理进度或故事结构强加给所有主题。

| 内容场景 | 信息链与安排 |
| --- | --- |
| 活动与招募 | 活动价值→玩法或作品样貌→流程与条件→权益→参与入口；用具体亮点说明价值，时间、地点、资格、费用及限制紧邻相关玩法。 |
| 教程与科普 | 问题→结论→解释→步骤→误区；先给可理解的答案，再展示过程与结果判断，例外和常见错误紧邻对应步骤。 |
| 攻略与清单 | 场景→分类依据→选择或路线→注意事项；说明分类和推荐依据，相关项目成组并突出重点，同类内容统一比较口径，真实路线保留起止点与必要条件。 |
| 人物与品牌故事 | 处境→事件→转折→真实细节→呼应开头；以人物行动、作品、时间、场景和镜头推进，不用抽象赞语替代事件，不编造引语或经历。 |
| 产品种草与解决方案 | 使用处境→解决方式→功能或证据→使用方法→推荐理由；方案对应具体问题，用案例、结构或过程解释，保留限制与使用条件。 |
| 公益与公共信息 | 问题→依据→可执行步骤→帮助入口；用清楚动作说明如何参与或求助，保留来源与时效，不以煽情替代事实。 |
| 招聘与岗位介绍 | 团队或工作内容→岗位→资格与待遇→申请；展示真实工作关系，准确分组职责、条件、薪资口径与投递方式，不推测企业承诺。 |
| 实际管理与进度沟通 | 结论→依据→进度与责任→问题→下一步；仅用于真实管理内容，注明已知状态与依赖，不虚构责任人、完成时间或执行结果。 |
| 内容叙事与专题策划 | 开场命题→分章展开→关键节点→回看与收束；用章节题和导语建立主线，同类栏目保持稳定阅读习惯。 |

篇幅只作试排起点，先合并重复内容、补齐必要解释，不用停顿段、巨字段或装饰空白凑篇幅：

- **3–4 个内容段**：单一观点或短活动，补齐解释后按试排调整。
- **5–7 个内容段**：教程、攻略或一般专题，按步骤、分类与证据关系分段。
- **8–10 个内容段**：多案例、复杂规则或多章专题，按独立问题与阅读任务分组。

- **内容段与内容组**：内容段是一组相关图文，不按手机视口定高。相邻段共同回答同一问题，或存在全貌—细节、问题—解释、场景—行动／证据关系时，优先延续为同组；读者任务真正改变且下一段可独立进入时拆组。同色、视口边界、图高或标题变化不足以决定合拆。

### 明确组内层级与读者关系

- **先定一组回答的问题**：写清读者读完需要理解的结论或能采取的行动，再将解释、证据、方法与提醒归入对应位置。章节标题统领本组，条目标题说明具体方法，条件与补充从属于所支持的内容；不把这些角色都拆成同级模块。
- **让内容关系成为可见结构**：识别并列、先后、主辅及角色关系，将其落实到分组边界、阅读顺序、图文邻接和视觉权重，而非只记录章节顺序。保留原文不等于沿用原列表排法；调整组织时保留语义、条件与归属。编号只表达实际步骤或索引，不强造顺序或重点。
- **明确适用读者与条件**：同一主题中面向不同角色、阶段或情境的内容，标明适用对象并安排相应分组。另一角色的支持建议不直接混入当前读者的操作步骤；必要条件仍紧邻所属方法，不为分组移到远处。
- **区分重点与篇幅**：按理解或行动的重要性确定展开程度，关键解释可以展开，简短提醒可以收紧；不为统一条目数量、图片数量或段高补写内容。主次决定后再选择布局，不按模板槽位倒推内容。

### 写清结论与解释

先找读者读完仍会留下的问题，再补必要解释。关键段写透，辅助段写短；内容充分以能够理解、判断或行动为准，不以字数、屏数或统一句式衡量。

- **从结论到解释**：标题表达主题或判断，正文说明是什么、为何与读者有关，并补必要条件。问题交代处境与影响，价值或权益说明所得及获取条件；原因有依据时再写因果，不将联想写成确定结论。
- **从抽象到具体**：将“提升效率”“有设计感”等泛词展开为具体问题、使用情境、可观察变化或评价维度，不反复换词重述口号。
- **从建议到行动**：方法写清输入、动作、顺序与结果判断，规则保留对象、条件、限制和例外，必要条件紧邻所属内容；建议用法不改写为品牌承诺，编号不制造不存在的顺序。
- **从概念到例子**：难以理解的概念可补贴近主题的说明性例子，明确示意性质；不虚构真实客户、成绩或亲历故事。例子解释本段主张，不另起无关内容凑篇幅。
- **让证据邻接结论**：图注、来源、时间、适用范围与比较口径绑定所支持的主张；真实引语注明人物身份与来源，往期照片保留事件语境，示意画面不作证据。
- **按授权补足内容**：用户只提供主题或零散要点并要求策划、创作时，按上述方法展开；要求原文不变、仅排版或限定改写范围时，遵守边界。事实处理沿用 [common.md](common.md)，规划说明与上屏文案分开。

例如“海报设计、图片精修”可展开为“海报设计梳理主题与关键信息，让标题、主体和行动入口形成阅读顺序；商品图片精修关注边缘、色彩与细节的一致性”。这是服务类型的解释，不能自行补成“24 小时交付、无限修改、转化率翻倍”。

### 安排叙事推进、前后交接与收束

首屏交代主题、吸引点与继续阅读的价值，从下一内容段开始兑现。依据内容选择能解释顺序的叙事方法，不要求凑齐或轮换使用：

| 叙事方法 | 使用条件与推进方式 |
|---|---|
| 章节杂志流 | 专题包含多个相对独立视角，用章节题和导语维持主线，同类栏目保持稳定阅读习惯。 |
| 问题—答案推进 | 读者有连续疑问，先回答当前问题及必要解释，再引出下一个问题，不用悬念拖延已承诺的内容。 |
| 时间线／流程推进 | 顺序影响理解或执行，每个节点对应事件、动作或阶段结果，路径体现实际先后。 |
| 清单逐级展开 | 分类或建议可独立扫描，先给分类依据或重点，再展开相关项目，不平均放大所有条目。 |
| 场景—证据交替 | 需要兼顾感受与可信解释，场景呈现处境，邻近证据回应主张，不用气氛图冒充证明。 |
| 情绪曲线叙事 | 人物、品牌或议题有转折，由具体事件、行动、细节和镜头推进情绪，不只靠换色和口号。 |

先明确上段完成什么、下段为何继续，再选视觉接法：全貌进入细节，场景进入行动或证据，沿同一对象、路径展开，或在同一比较维度下切换状态；任务或叙事阶段真正改变时再换章。服务同一阅读任务的相容内容优先归组，重复内容合并，解释与例子服务本段主张，前文问题在后文得到回应。

末段回应前文，按任务给出总结、提醒、联系、参与入口或叙事余韵；需要行动时交代做什么、到哪里做及必要时限，不强加按钮。

### 分配配图职责

- **按信息需要配图**：展示具体对象、动作、结构、差异或证据；任务或情绪确实切换时，可用图像与短句交接。规则、短总结与联系方式可直接排字，不规定每段配图，也不将图片全部集中在首屏。
- **明确图文分工**：说明图展示对象、动作、结构或差异，正文补充原因、条件与操作要点；装饰图只承担主题识别、情绪或过渡，不计作解释与证据，也不按条目逐项配齐。相关信息并入已有 Brief 和素材记录，通用字段及调用记录沿用生产规范。
- **按对应关系组合图文**：一图解释整组时，围绕同一图解组织相关说明；多图分别解释不同方法时，各图与所属文字就近配对。只有需要先整体比较或浏览图像序列时，才集中排列图片并建立清楚对应；不默认“先一排插画，再一列说明”，也不将正文逐句另画一遍。
- **按解释取景**：先确定图片要回答的问题，再选景别：全貌交代对象与环境关系，动作说明过程，特写解释细节，比较支持判断。全貌保留识别面，特写保留上下文，动作保留手、工具、接触点与结果；机制可用剖面、分解或过程图，标注指向实际部件，比较保持必要的一致视角与尺度。
- **保留可靠关系**：真实地图、图表、节点、单位、路径和截图使用可靠来源及可核实表达；概念路线、说明性例子标明示意性质，不冒充导航、数据或真实记录。
- **按内容复用素材**：有用资产可直接复用；新增解释图或更换镜头，应让读者看见新的动作、情境、细节或证据，同一主体保持身份一致。重复裁切不等于新信息，不为版式变化增加近似图片；承担主题呼应或过渡的复用图按装饰职责处理。

## 3. 设计图文、背景并试排

将内容关系落实为可见构图，用真实文字、字体和素材验证连续阅读。

### 先定整页阅读结构与组内构图

1. **确定整页主线。** 按第 2 章安排开场、展开和收束，确定哪些组需要重点解释、哪些可简读，以及相邻组延续还是换章。由内容决定图文面积与密度：大图建立场景、突出重点或换章，小图补细节；密集解释与重点画面按理解需要交替，文字主导内容可沿稳定轴连续展开。不把每组排成等高、等量的独立小海报，也不为轮换插入无内容的停顿段。
2. **落实组内构图。** 用本组实际内容说明先看什么、哪些图文共同表达、补充信息从属于哪里，再确定字级、位置、尺度与间距；“标题—图片—正文”不足以说明这些关系。相同阅读任务可复用结构，不同关系须在布局中可辨，不为变化强行换版式。
3. **建立阅读动线。** 将入口焦点、图文阅读顺序和下一组入口对应到实际位置。动线可以由稳定文字轴、图文邻接、尺度变化、人物朝向或真实路径建立，不等于加箭头或贯穿曲线；跨组保留足以识别连续性的轴线、角色或色彩用途，真正换章时清楚切换。
4. **选择图像呈现与隔离范围。** 根据说明职责选择场景、开放主体、邻接标注或图窗，再判断哪些信息确需容器。先判断整组关系，再选择局部承托；不从“每条一图一框”开始排版。

将上述决定并入同一 Brief，再按下面步骤匹配资源；布局表提供实现方法，不要求逐组更换样式。

### 匹配模板与资源的步骤

1. **明确内容并初选方法。** 完成内容分组、整页阅读结构与组内构图后，依据内容与参考，从下方风格、布局表初选方法；先匹配整页或章节构图，再为确有隔离或媒介需要的局部匹配容器。HTML 新建或整体重做须在 Brief 冻结前比较候选；已有有效方案只查询新增或获准替换部分，纯图任务按入口路线执行。
2. **取词并按组查询。** 使用用户原词或已选方法的检索词，不同方法词分别查询，不把每格整串作为查询；真正同义词才用 `|`，同时需要的条件用空格表示 AND。风格与布局查构图组的社媒长图及通用范围；容器按表中标注查询：独立外框与部件查通用容器组，设备整体查对应构图组；配色、纹理、材质与渐变按各表标注查询对应通用资源组，不混查。无词或未命中时列出对应范围候选；无合适资源则沿已选方法执行，不为命中改换方向。
3. **读取并确定借用范围。** 按 [templates.md](templates.md) 的 `match → describe → read` 查看适用范围与真实内容，完整读取所选正文及必要依赖。明确采用完整方案、章节、局部或仅配色；完整采用命名方案时保留其字级、字重、面积关系与例外，局部借用只取相关部分。
4. **用真实内容适配与预排。** 比较模板能否承载已定的并列、先后或主辅关系，再核对容量与首屏画幅。用准确文案、字体和素材比例预排整组及相邻组，按需合并或移除无职责槽位、调整尺度与轴线；风格命中不能代替结构适配，无法保持内容关系时换选。首屏尺寸与文字边界按第 1 章执行，不按样例反推事实或段数。
5. **并入同一 Brief 后制作与复核。** 将选用方案及必要调整并入同一 Brief，按入口完成适用确认、冻结与素材生产；素材就绪后复核段高、接缝、阅读尺度及锁定条件。发现容量或锁定条件冲突时再调整选型。

规则轮廓、普通渐变、容器与边框优先原生实现，复杂影像和材质使用图片；制作与必要拆层按 [produce-hybrid.md](produce-hybrid.md)、[produce-code.md](produce-code.md) 执行，已合入图片的内容不重复叠加。素材不足时说明受影响对象及替代效果。

### 选择视觉风格与表现方法

从人物动作、对象形态、地点特征、材料和品牌识别提取依据，保留锁定调性及参考中的有效关系；身份图、证据图不自动成为风格参考。

- 按主题与参考确定主要识别方式，再安排标题、主体、信息面与背景如何共同成像：哪些共享字形、色彩或材料语言，哪些为清晰阅读保持克制。风格不能只落在背景或装饰上，也不要求每个对象使用同一效果；局部毛玻璃修改保留整体风格。
- 自然质朴可取植物细节、明亮日常、不规则表面或环境纵深，不默认米色纸纹；国潮可取民俗角色、精细重彩、真实纹样或字物碰撞，不泛化为红金庆典。
- 诗性浪漫用人物情境、枝叶空间、信纸关系或明确的超现实场景；奢雅精致用主体尺度、工艺、几何节律或人物姿态，不以黑金、小物居中和大面积空白代替设计。
- 用景别、图文面积、明暗、尺度与密度安排变化；肤色、食物及证据影像保留本色，允许局部光滑或低纹理区域。复杂素材缺失时说明具体缺口，不静默替换已选方法。

### 确定 Hero 的主导构图

从主题最有辨识度、最能建立阅读动机的内容选择第一焦点，再确定标题、主体与导语如何共同组织。制作方式、首屏高度和文字归属沿第 1 章执行，本节决定画面关系。

| 内容条件 | 主视觉关系与安排 |
|---|---|
| 主张短而有力，字形能表达情绪 | **文字主导**：用大字、断行和强调色建立识别，插画或图形从属，不强加大照片。 |
| 人物、产品或可信结果就是吸引点 | **主体与标题／关键数字共构**：通过尺度、邻接或受控穿插形成一个主组，真实身份与数字有来源。 |
| 地点、生活情境或活动现场影响理解 | **场景主导**：用全景或中景建立环境与动作，文字进入真实净空，主体与环境线索保持可辨。 |
| 多个对象共同代表主题 | **拼贴主视觉**：人物、建筑、器物或照片以共同基底、尺度差与遮挡形成主组，数量由内容决定。 |
| 图片重要，同时需要稳定的编辑秩序 | **图窗与标题共构**：用拱窗、椭圆或纸框等有依据的轮廓组织主图，标题、导语与图注构成入口，图窗不必满幅。 |
| 动作、招牌或主题物件能直接表达内容 | **动作／语义场景**：标题进入招牌、展板等有意义的载体，由人物动作和物件关系组织视线。 |
| 差异或问题能建立阅读动机 | **问题／对比开场**：突出可解释的差异或问题，保留比较条件，正文及时给出答案与证据。 |

用户锁定与明确参考优先；多种方式都成立时，选择最能表达核心内容且素材支持的一种主导关系，辅助手法服务它，不要求生成全部候选。Brief 写清焦点、图文权重、位置与阅读出口：图像主导不缩成小图，文字主导不为氛围硬塞场景。标题与图像共同主导时形成主视觉组，以尺度、裁切或色彩反差突出焦点；文字主导不另加主体，也不强制图文叠合。避免无依据的标题页眉化、主体沉底和中间空置。保留有意留白和文字净空，不用空白填足首屏比例。

首屏出口承接第 2 章确定的内容推进，再按本章背景规则选择空间延续、媒介转换、视觉呼应或明确换章；有边界不等于失败，同色也不自动连续。

### 选择图文布局方法

- **先定主导关系**：体验、氛围或空间叙事先评估满幅场景；对象解释可用邻接标注；主体移动、穿插可用开放排字；截图、比较、局部证据或明确框景参考可用图窗。用户锁定与明确参考优先，图像主导不缩成小图，文字主导不强塞大场景。
- **按信息增量配图**：场景开篇可用整幅图，对象介绍用主图配细节，过程用分镜条，差异用并置对比。后续配图须补充解释、证据或情境，不重复首屏主体作占位；无需配图的内容直接排文。避免不同内容连续套用“大图＋下方短文”；同类步骤和比较可保持一致布局。
- **组织正文轴线**：明确标题与主体组合、主辅图尺度和阅读顺序；偏轴主体可用朝向、视线或动作将阅读带回说明。长正文保持连续行宽，多组说明按同轴、并列比较或实际步骤组织；同类比较可同形、等大、对齐，确有主次或层叠关系时再错位、倾斜、重叠；拼贴、手绘风下，正文及正文容器保持水平，不倾斜或变形。
- **保护图文完整**：穿插、环绕与破框不损伤文字含义、人脸、商品身份、证据、数字单位或入口；同一处文案只由一个图层或元素显示。连续采用“标题＋图窗＋说明”须有截图、比较、证据或明确参考依据。

以下方法可组合或自主布局，不套用独立套图的相邻变化项数、三页轮换或主辅卡配额：

| 布局方法 | 适用内容 | 图文安排 | 可检索词（构图组） |
|---|---|---|---|
| **章节编辑与单轴信息场** | 结论与解释需要连续细读的内容。 | 将标题、结论、说明和必要行动沿共同轴展开，以段距、栏线、大小图和章节带分组；问答错列仍保持配对，文字主导段不强配图片。 | `章节纵向连续递进`、`同轴编辑`、`单侧信息轴` |

| **档案拼贴与手账主版面** | 资料切片、清单或叙述需要同版组织的内容。 | 主要事实排在主纸面，票据与照片从边缘切入，索引和标签只作必要标识或引导；手账用组标题与稳定轴线分组，便签强调必要信息，不把每句话放进独立纸片。 | `夹持剪报`、`档案长卷`、`手账` |

| **引语人物与章节停顿** | 人物观点或真实换章需要突出的内容。 | 将肖像、引语与署名绑定，以动作和细节补充处境；仅在任务或情绪确实切换时设置章节门，用图像与短句交接，不凑空白段。 | — |

### 选择容器与开放排版

先用对齐、间距、字级和必要栏线组织内容；以下情况再使用容器：需要保留截图或照片的独立观看边界、隔离易混淆的比较对象、突出可独立使用的信息单元，或兑现明确的媒介／框景参考。“有一条信息”或“需要分组”本身不构成逐条加框的依据。

同组标题、配图与说明优先共同组织；外层已有清楚边界时，内层仅在另有隔离职责时加框，不默认给章题、图片和每条正文分别描边。多个同级对象可以重复容器，但父子层级须由位置、尺度、字级或间距区分。先确定结构，再匹配颜色、纹理与光影；选毛玻璃不等于必须增加面板。

| 容器形式 | 用途与结构 | 可检索词与资源组 |
|---|---|---|
| 卡片 | 仅在隔离比较、独立扫描或使用时分卡；相关说明优先在同一内容组内开放排版，不逐条套同款白卡。文字容器不等于图窗，不能仅凭边框判断用途。采用粉色派对组合时，说明窗口的顶栏与正文面分层。 | 容器：`卡片与面板`、`圆角矩形无描边`、`圆角顶栏卡片` |
| 文件夹 | 用于承托主纸面和资料分组，显示页签与必要背页；材质服从已选结构。 | 容器：`文件夹轮廓`、`文件夹-半透明塑料`、`文件夹-磨砂玻璃`、`文件夹-纤维纸张` |
| 票券 | 用于票据信息与票根分区，区分齿孔、腰孔和票根，不以统一缺口替代不同结构。 | 容器：`缺口齿边票据`、`双侧单腰缺口票面`、`连续圆弧缺口票根` |

| 图签与照片 | 图签说明照片归属和先后，明确图签、照片与固定件的叠放关系。 | 容器：`手绘毛边纸签`、`窄白边照片`、`宽底白边相框`、`回形针纸板` |
| 游戏机／抽奖设备 | 屏幕承载任务、规则与结果，机身组织标题及主题装饰，控制区对应行动信息；明确机壳、屏幕、台面和按键的前后层次与厚度，按当前主题调整设备外形。采用蓝银演出组合时，按真实活动取舍设备，不强加抽奖，日期屏、奖品和按钮各有归属。 | 构图（长图）：`蓝银抽奖设备`（借设备结构）；容器：`斜台面与独立前沿`、`薄侧边立体按键` |

| 撕纸／短纸签 | 用于拼贴标题、关键数字与短观点，以纸片大小、叠压和轻微错位组织节奏；撕裂边缘避开文字，主纸片承载核心信息，辅纸签补充注释，折角与阴影交代层次。 | 容器：`不规则撕纸边`、`毛边纸条`、`折角便笺` |

- 纸边、折片、尾部和缺口不计入正文区域；纸形裁背景，不裁真实文字。
- 卷边、螺钉和夹持避开正文。
- 阴影依据接触与材料，不以厚外阴影代替结构。构图时预留低干扰文字区，空间不足先移字或重排，不随文字框临时添加灰黑底板、雾带或压暗横带。

### 确定背景范围与生成段

- **背景单元**：按场景、光向、透视、主体尺度、文字低干扰区及色场／纹理确定覆盖范围。相容时优先共享背景或延续同一基底，以景别、主次、图文比例和密度推进；不相容时按叙事换景、重新构图或使用有独立观看职责的图窗。不同内容组可共享背景，同组也可换景。
- **生成段**：按路线与素材依赖确定生产范围，不与内容段、内容组、背景单元一一对应，也不改变首屏定义。只制作实际可见、从内容间隙露出或需跨段连续的背景，避免近似背景重复生产及纹理、光场意外重启；生成与拼接按 [produce-image.md](produce-image.md) 执行。
- **可见背景**：全局及内容组背景须含主题相关的纹理、肌理或渐变至少一项，不用无变化纯色铺满整张长页。文字区可低纹理或局部纯色；照片自身的空间与表面变化也可满足要求，不强加纸纹，不为完全遮挡的底层另生图片。
- **相邻衔接**：明确衔接对象、离开上一段的方向、进入下一段的位置与保护区。连续空间核对透视、边缘、尺度和光向；场景转为相册、纸页、票据或信息版面时，让媒介变化可见；不共享物理空间时，可延续栏目轴、轮廓、颜色用途或角色，真正换章可明确切换。
- **连续来源**：场景须来自同母图、连续裁切，或共同制作且经核对能连成同一场景的素材。不将两张独立完整主图用渐变、蒙版、透明度或混合模式直接融合；单独检查接缝与实际露底，依据空间连续性判断衔接，保留有意的图像边界。

### 确定字体与文字层级

- 字体加载、字形覆盖、真实字重及同类别回退按 [fonts.md](fonts.md) 执行。固定 Bold 字体不能仅改声明字重冒称变细，字体不可用时重新测量。
- 展示标题突出主题，章节题标明章节，正文解释内容，英数、单位、图注与来源绑定对象；各段保持一致层级。
- 粗黑切角、窄宽变化、粗笔手写、纸张拼贴与复古粗印刷均可选，普通标题也可用实际字体。日期、价格、薪资、规则、联系方式、Logo 和二维码不承担艺术字效果。
- 背景大字逐词检查，每个关键词至少有 **65% 的字形可辨认**，首尾字符不得同时遮挡；必要事实不得借此许可遮挡。
- 混合路线允许区域的唯一主艺术标题、有效字面宽高 **2 倍**要求及检查按 [produce-hybrid.md](produce-hybrid.md) 执行；后续章节标题不逐项生图，一体首屏不拆入独立字图流程。

| 字体组合 | 适用依据与安排 |
| --- | --- |
| 中性无衬线与几何 Sans | 通用解释、活动、商务或技术内容，用真实粗细与尺度分层；中文选稳定 Sans，英数可配 Inter 类清晰字形，数字与单位邻接，正文不用伪技术等宽字。 |
| 高对比 Serif＋Sans | 人文、文化、器物或出版语境，用宋体或适当 Serif 展示，Sans 排准确事实与长说明，不全文使用装饰衬线。 |
| 实验展示字＋中性事实字 | 潮流、酸性或时代字形参与识别时，用窄体、切角、短标题错位或受控变形突出重点；事实保持正常字面，保护负形与整词识别。 |
| 手绘展示字＋圆润 Sans | 角色、涂鸦或手作语气，手绘字限短标题，正文保持稳定基线，不让手写承担核心事实或行动入口。 |
| 档案 Serif＋Mono | 索引、期次和资料元数据需区分时，Serif 或 Sans 排正文，Mono 用于真实编号、日期和短元数据，微字须有语义。 |
| 票据碰撞字组 | 票据、刊头和栏目需字级碰撞时，以一种主字类建立识别，按栏目辅以另一字类或短元数据 Mono；通过尺度、旋转与基线形成碰撞，不堆字体。 |
| 相册手写＋人文 Sans | 照片与短情绪句共同叙事时，手写限短情绪句，地点、日期、图注用清晰字形；图注从属于标题，每张照片归入一个说明组。 |
| 手账粗题＋结构化 Sans | 密集清单与分组笔记需扫描时，标题可跳动，内容保持齐轴；组标题与正文形成清楚级差，高密度时先调组间距与组织。 |

以正文 **B** 试排字级，下表为一般参考，不是强制级差；完整模板的适用规则见“匹配模板与资源的步骤”。

| 文字角色 | 相对 B 起点与安排 |
| --- | --- |
| 第一标题 | **3.2–6×**，通常 **1–3 行**，突出一个主题或核心判断。 |
| 引导语 | **1.6–2.6×**，通常 **1–3 行**，补充价值或情绪，不复述标题。 |
| 核心事实 | **1.15–1.65×**，单位、条件与必要解释邻接。 |
| 正文说明 | **1×**，按真实字体、行宽与内容试排，不硬套固定字数。 |
| 标签与图注 | **0.82–0.95×**，通常 **1–2 行**，绑定具体对象。 |
| 非关键信息标记 | **0.68–0.82×**，只用于非关键索引、期次与短英文，不用于入口或必要联系方式。 |

### 分配配色职责

- 分配底面、表面、文字、主辅色与强调色；品牌色、参考色和自主配色均可用，不将风格、构图与色板硬绑定，实际色值及混合参数留在实现源。
- 专业题材不默认深色背景；亲和活动、生活或创作者内容避免因深底被误读为会议或 B2B 产品。行动色只用于真实入口、重点数字或必要引导，不在无关段落反复抢焦点。
- 区分参考取色、照片本色、纸面底色和透明叠色，并落实到页面角色；资源配方读取实际色值，不将目估或旧面积示例当作实测数据和整页配额。

| 配色关系 | 适用依据与安排 |
| --- | --- |
| 档案纸＋原色定位 | 资料页需中性阅读面与索引时，以纸色和深墨为主，钴蓝、朱红择一主导，另一色从属，信号黄局部定位；纸斑低于正文对比，不默认纯黑或泛黄。 |
| 暖纸＋焦糖套色 | 暖色材料、食品或商业印刷，在琥珀食品与较克制的焦糖关系中选完整方向，以暖纸、棕墨、焦糖及少量暖红分工；采用此配方时不将冷色扩成大面积底。 |
| 黑白＋单一荧光 | 高反差编辑、潮流或实验，用黑白保证文字清晰；常规方案从荧光黄绿、酸粉、橙红中只选一种强调色，其余不用。线框空间方案可用薄荷绿、紫色辅助，荧光黄绿只强调一处行动入口或引导位置；荧光色不用作细小正文。 |
| 奶油中性＋自然主色 | 自然、生活或温和出版，用奶油、暖灰作底，森林绿或陶土择一作大面积主色，草木色辅助、暖黄局部强调，不让绿与陶土争主导。 |
| 冷白银蓝＋证据色 | 结构说明与证据定位，用冷白、银蓝、冷灰建立阅读面，按内容从紫、红、蓝、绿中选一种主要编码；颜色不证明功效，深紫变体同步调整文字反色。 |
| 亲和撞色 | 角色、活动和轻松叙事，可选天空蓝配黄与红，或暖粉配黄与绿；清楚墨色统一正文，强色分担主体、辅助与强调，不用彩色长文替代层级。 |
| 品牌高对比 | 品牌需明确色面时，可选钴蓝配白黄、浅冷蓝配品牌蓝，或黑白配黄绿；蓝底和黑面同步反白文字，紫色与柔金强调择一，不因专业题材默认金色。 |
| 克制票据色 | 票据与纸层需稳定中性轴时，在粉蓝旧纸、灰阶单点色、牛皮纸黑黄中选完整关系，不混成多套高饱和色；纸张、印字与索引分别上色。 |
| 季节相册色 | 照片季节与光线决定情绪时，春日用草绿与浅黄，冬旅用冰蓝与蓝紫，深蓝记忆用暗蓝与暖纸、柔粉；相册面衬托照片，不用滤镜改写事实影像。 |
| 生活手账纸色 | 主板和信息组需清楚归属时，可选暖纸配蓝黄、牛皮配黄蓝，或奶白配粉绿；同一信息组只用一种编码色，正文统一墨色，避免厚重怀旧滤镜。 |
| 有限色版 | 版画、丝印或 Riso 成像时，锁定纸色及本章所选印色，叠色来自实际色版关系，不另添随机颜色；蓝橙、红黑均可现代化使用。 |
| 颜料撞色 | 粉彩与绘制明暗共同成像时，分工背景颜料、主体、局部冷暖明暗与正文色；允许同一主体有色相变化，分别记录露出的纸色和背景色，不将高饱和主色用于低对比正文。 |
| 连续弥散色域 | 色域表达连续空间时，按本章色域起点明确中心、范围与明暗职责，可用暖白、洋红、紫、青绿组织，暖橙仅在需聚焦时加入；生成混色如实记录为资产特征，不冒称精确可复算渐变。 |
| 商业波普撞色 | 巨字与物件需强色碰撞时，可用高饱和蓝突出主物件、朱红突出焦点、亮黄用于短标签，以纸白和近黑分隔；物件色按主题补充，不平均分配强色，最终尺寸检查黑字黄签、红字白边等关系。 |

### 安排纹理、材质与渐变

纸面承托文字，墨纹作用于标题或印色，照片保留自身细节；容器通过边缘与表面表现材质，不用统一噪点覆盖整页。

| 处理类型 | 具体做法 | 可检索词与资源组 |
| --- | --- | --- |
| 纸纹 | 沿纸面铺纤维、纸斑与磨损，裁在对应纸片内；文字区减弱纹理，纸边与接触处保留厚度差异。 | 材质组`纤维纸张`；特效组`轻纸纹``揉皱纸折面`。 |
| 墨纹与网点 | 按目标尺寸记录网点间距或点径、明暗映射、墨边与错版；网点随明暗变化，缺墨与叠色留在所属印色内。 | 特效组`套色网印与错版颗粒``局部掉墨与擦损`。 |
| 粉彩与刻印 | 记录粉末尺度、柔边、露纸与形内刮擦；粉彩以粉末和明暗塑形，刻印区分墨面与纸底，刮擦不跨全文。 | 仅刻印的局部擦损可借特效组`局部掉墨与擦损`。 |
| 渐变 | 明确色域中心、流向、软边、颗粒与低干扰区；连续底面保持色阶和颗粒尺度衔接。 | 配色组`通用渐变与逐色标透明度`；特效组`弥散光晕``细颗粒柔雾色场`。 |
| 织物 | 顺布面安排格纹与经纬细纹，随裁片、折叠和接缝变化；文字承托区减少纹理干扰。 | 特效组`织物手作``格纹布与经纬细纹`。 |
| 金属 | 框带或壳体的反光沿结构起伏，以亮暗带表现表面，不把照片涂成金属色。 | 特效组`金属反光带近似`可作近似。 |
| 透明表面 | 表现透底、折射、边缘厚度与叠色；正文不随表面透明、模糊或发光。 | 材质组`半透明塑料``磨砂玻璃``球面玻璃近似`可作近似；特效组`压纹玻璃`。 |
| 场景表面 | 按需用于场景背景，斑驳跟随墙面范围，不侵入纸片、照片与正文。 | 背景组`斑驳墙面`。 |

在最终显示尺寸下检查纹理尺度、明暗和文字清晰度，按实际素材调整。

### 用真实内容试排段高与阅读尺度

- **完整测高**：以准确文案、真实字体、主图展示范围及必要留白试排，用 **H/W** 记录各段高度。标题、说明、图片、交接区与留白全部计入，不只测图片框；重点图解可展开，短规则可收紧，同类比较可等高。正式组装按入口及 [produce-hybrid.md](produce-hybrid.md) 执行。
- **试排字号**：正文 **16–19px**、辅助文字 **14–16px**、中文行高约 **1.5 倍**。低于 **16／14px** 时重点复核；最终以实际阅读宽度下的清晰度判断。
- **换算阅读字号**：有效字号＝母版字号×阅读宽／母版宽；导出采样倍率不重复计入，局部变换另核，标签与微字同样检查。只有位图时不猜 CSS 字号；阅读宽度未知时注明假设。
- **按内容收束高度**：内容讲清后，总高未锁定时按各段实际高度相加，不用大段空白撑长画布。尺寸已锁定时，先调整内容分组、栏宽、图片尺度和间距；字号遵守阅读规范与用户要求，不为容纳内容降到适用下限以下。仍无法容纳完整内容时，说明冲突并暂停依赖制作。不擅自改锁定尺寸或段数、删事实、隐藏或截断内容、拉伸图片或补装饰凑高。段高改变后同步下游位置、背景接缝与切片边界。
- **检查两种阅读状态**：整图缩略图检查主线、疏密、开场与结尾，约定阅读宽度检查正文、条件、图注及图内文字；信息流缩略图不要求展示全部正文。平台压缩未实测时标为未验证。
- **检查实际取景**：按 [produce-code.md](produce-code.md) 核对等比 `cover`／`contain`，不因图框比例不同自动失败；检查裁切保护、有效像素、露底与最终取景，不作非等比拉伸。按可见主体而非文件外围留白判断尺度，切片保护标题、数字单位、面部、操作接触点、关键证据与跨段路径。

在原 Brief 补充实际焦点、图文分工、轴线与阅读顺序、文字低干扰区、材质对象、背景范围、段高依据、裁切保护及上下衔接。整体决定写一次，各段只补实际差异，不用“后续同上”省略；坐标、字号、色值和接缝几何留在实现源。
