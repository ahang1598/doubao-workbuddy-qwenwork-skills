# 固定画布 DOM 测高

测高已集成到唯一入口 `scripts/runtime/shot.py`，不再要求 Agent 单独调用浏览器或另写测量脚本。调用与失败策略见 [HTML 预览](html-preview.md)。

脚本按声明宽度等待资源，在内存中临时解除 html、body 和作品根的高度限制，读取 `measurement.natural` 后恢复，使用 `measurement.final` 复核正式布局。源文件不会自动修改。用户未锁高时可根据自然内容与底部安全区调整四处高度后重跑；锁高时在原尺寸内重排。

声明尺寸、自然高度、正式内容底边和安全区分别核对；截图尺寸正确不证明内容完整。复杂布局、隐藏祖先、字体回退等自动检查未覆盖项，结合完整截图判断并保留未验证状态，不声称完整前端诊断。
