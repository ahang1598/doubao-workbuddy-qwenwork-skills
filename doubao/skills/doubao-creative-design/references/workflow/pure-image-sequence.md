# 纯图套图与长页拼接

> 先按主 SKILL 判断交付环境。system 明示 `Device platfrom: Mobile` 时遵循 [Mobile 直接交付](mobile-app-direct-delivery.md)：Brief／素材记录留在本地，跳过本文全部 Workspace、Canvas CLI、Item 与卡片步骤，媒体逐项直接交付、HTML 预览走 CDN＋Markdown。其他环境执行本文默认 Canvas 分支。生产与编辑顺序不变。

仅在主 SKILL 已经把当前产物路由为 pure-image 后读取，本文件不接受“用户想直接出图”作为改道依据，也不得覆盖主路由。社媒套图默认 pure-image，使用本文先规划共享系列，再逐页生成含封面在内的完整图片，并读取现有 pure-image 平台 Ref，不读取 Coding Spec／Visual。要求可编辑设计或文字的套图进入 ai-coding，指定可编辑区域必须原生排字，封面不例外。详情页与连续长图默认走 ai-coding；主 SKILL 在用户明确要求“全部由图像模型生成、不要 HTML 排版”时允许的纯图长页使用本文。既有 HTML 源编辑保持完整 HTML。

## 1. 轻量计划

复用 brief.md，必要时在其中增加页序／分段表，不另建参数规划文件。记录：最终交付是套图还是连续长图、总尺寸或比例、准确文案及来源、主体与品牌身份、共享配色／字形／光向／材质，以及每页或每段的序号、内容职责、文案、目标宽高、入口／出口和可复用资产。

先规划完整内容，再分配到页或段，不能先生成再补叙事。模型改写只消费该计划，不增删页数、事实或身份要求。

## 2. 套图：逐页成品

封面与内页都由 image 工具生成完整图片，文案随图生成，不拆艺术标题或叠加 HTML 正文。共享视觉语言，按页面职责改变景别、密度和构图；不要求每页复制封面版式。默认先生成正式封面，实际读图后记录可复用的色彩、标题关系、材质与主体特征，再生成内页；这是正式生产顺序，不额外增加 KV 提案或用户确认轮次。若页间不依赖生成结果，可在全套计划冻结后按原并行门禁生产。

身份母版与风格参照分别记录。使用参考图时按实际工具能力传入，不能只写 ID 或“同款”；不把封面衍生图升级为新的身份母版。每页完成双通道交付，最后核对页序和系列关系。除用户要求外不自动拼接套图。

## 3. 纯图长页：比例判断

- 使用目标整图宽 W、高 H，均为正整数。判定 `H * 9 > W * 16` 时进入分段生成与拼接；恰好 9:16 不因该门槛强制拆分。
- 门槛比较的是最终整图，不是每个素材槽位。未知高度先按明确内容与目标宽度估算并记录；用户锁定尺寸时沿用，不为了避开拼接缩短内容。
- 低于或等于门槛可以直接生成整张；若工具实际输出能力不足，仍可分段，不拉伸或虚报像素。
- 按章节和低信息接缝划分，单段目标原则上不高于同宽 9:16，并同时满足工具实际比例／分辨率限制。避免切开标题、商品识别面、表格行或证据；不为等高而拆坏内容。
- 统一各段目标宽度；段高之和等于整图高度。需要重叠接缝时，先明确保护区和裁切范围，合成高度扣除实际重叠，不能重复文案或主体。

## 4. 生成与拼接

逐段 Prompt 包含全图视觉约束、本段完整内容、准确文案、上缘／下缘的颜色材质与接续方式。需要前段真实边缘做依据时串行：前段完成交付并读图后再编辑／生成后段。段间无实际依赖才并行。

每段为含本段文字与视觉的完整位图；各段成功输出先按 [交付门禁](image-generation-delivery-gate.md) 完成双通道闭环，再进入合成。保存原始短链和本地合成输入的来源映射；为完成用户要求的合成可以读取／取得实际像素，不以本地副本替换原始段图的交付短链。

使用实际可用的图像拼接工具或 scripts 中的确定性脚本，将统一宽度、接缝已准备好的段图按序拼接。不得把拼接称为 HTML 排版，不拆字、不自动覆字，不拉伸主体。当前脚本 [stitch-images.py](../../scripts/runtime/stitch-images.py) 只做等宽纵向连接，遇到宽度不一致即失败；重叠裁切与接缝修复须在调用前用真实工具完成并核验。

```bash
python3 scripts/runtime/stitch-images.py --output /absolute/new/long-page.png /absolute/segment-01.png /absolute/segment-02.png
```

脚本需要 Pillow。环境缺少依赖时使用宿主已有图像合成工具，或说明具体阻塞；不伪造输出。拼接生成的新本地产物可以上传取得自己的短链，并作为独立 IMAGE 完成 CLI 写入／回读与单项 present_files；原始段图保持各自来源和版本。不能因段图已交付就跳过完整长图的最终交付。

维护时可用 [路由案例](../../SKILL.md) 检查套图、纯图长页、Logo 系统与已有源编辑边界。

## 5. 验收与编辑

核对实际总宽高、顺序、段数、接缝错位／色差／重复、主体比例和完整文案。检查 100% 局部与全图阅读节奏；字错照原门禁记录并等待用户要求修改，不用拼接或遮盖宣称修复。存在问题的完整版本如实标记，不能宣称验收通过。

修改既有纯图长页时优先复用原分段与未修改像素，只重做授权段及必要接缝，再输出新的完整拼接版本。只有扁平原图时先保存基线、定位区域并按实际工具能力拆段，不要求用户补不存在的参数规划文件，也不因高度触发全图重生。
