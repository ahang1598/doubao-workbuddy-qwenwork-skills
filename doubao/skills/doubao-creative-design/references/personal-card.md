# 名片、会员卡与票券规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

目标：让持卡人、品牌、权益与使用入口清楚可辨，卡面有记忆点，联系、扫码及实际操作区域可用。

适用产物：个人商务名片、工作室品牌联系卡、会员卡、集点卡、礼品卡、储值卡、优惠体验卡与票券，含已确定的单面、双面、数字状态及真实系列变体。

**核心流程**：明确产物与要求 → 组织内容 → 确定视觉方案 → 核对成品 → 分面交付清洁卡面、完整源与预览。

## 1. 明确产物与要求

沿用已有有效方案，只补本次产物、内容、版本或编辑范围的判断。单张纯图直接编写提示词；需统筹正反面、系列或代码制作时维护同一 Brief。事实与创意扩写按 [common](common.md)，已有源修改按 [edit](edit.md)，参考继承按 [reference](reference.md)。不另建逐卡 Brief，不新增 KV、封面审批或确认轮次。

### 1.1 产物类型、尺寸与内容

用户已有尺寸及明确的供应商规格优先。实体产物未指定尺寸时，按下表默认横版起稿；尺寸为宽 × 高、裁切后的成品尺寸，不含出血，竖版互换宽高。默认值用于设计起稿，不代替生产规格确认。数字产物记录目标显示像素，不照搬毫米规格。

| 产物类型 | 默认成品尺寸及调整条件 | 必要内容 |
|---|---|---|
| 个人商务名片 | 默认 90 × 54 mm | 准确姓名、身份或服务、主要联系入口 |
| 工作室品牌联系卡 | 默认 90 × 54 mm | 品牌名、业务短句、联系入口 |
| 会员卡 | 默认 85.6 × 54 mm | 品牌、真实等级、持有人或会员识别、权益入口；只列适用信息 |
| 集点卡 | 默认 85 × 55 mm；按真实点位与盖章空间试排，放不下时调整版型，不压缩操作区 | 参与规则、完成点数、奖励与兑换条件 |
| 礼品卡 | 默认 85.6 × 54 mm；礼券式长条版按实际内容另定 | 礼赠内容或面额、金额含义、兑换方式、期限与范围 |
| 储值卡 | 默认 85.6 × 54 mm；采用实体读卡设备时以匹配的卡材规格为准 | 卡身份、查询与使用方式、适用的金额说明 |
| 优惠体验卡 | 默认 90 × 54 mm；条件较多时按既定范围重新分配内容 | 折扣、次数、适用范围、限制及使用入口 |
| 票券 | 默认 210 × 99 mm；已有主副券时包含在整张尺寸内，撕线按实际版型确定 | 活动或服务、时间地点、适用场次／座位／票种、使用条件与核验入口 |

尺寸参考：[集点卡 85 × 55 mm](https://wttb.co.uk/products/business-cards/loyalty-cards)、[塑料礼品／储值卡 85.6 × 54 mm](https://print24.com/uk/printing-products/plastic-cards)、[票券 210 × 99 mm](https://www.welove2print.com/product/secure-event-ticket-printing/)。名片及优惠体验卡的 90 × 54 mm 沿用本规范的便携卡设计默认值。

### 1.2 确定面数与制作条件

- 写明实体或数字载体、宽 × 高及单位、语种。单面、双面沿用既定范围；数字载体按实际状态组织，不强制模拟正反面。数量按真实人员、等级、面额或状态统计，不自行增加背面、等级或规则页。
- 保留用户锁定原文、身份、尺寸与参考用途。身份、认证、联系方式、账号、卡号、价格、金额、权益、期限及规则只用用户资料或核实依据；缺失集中记待补，仅暂停依赖部分，不编造后附免责声明。
- 记录已知出血、刀模、圆角、材料、可写区、盖章区及数字状态要求。未知制作条件不猜填，效果模拟不作为可生产结论。

## 2. 组织内容

仅执行本次产物对应的内容步骤；共同要求如下。

- 在既定面数和授权范围内写全上屏文案，沿用已确定的正反面分工，不为对称补内容。
- 识别面只设一个主焦点，两面不求同等密度；内容少时围绕主焦点集中排布，以留白突出识别或保留操作空间，不把少量信息分散到四角，不为姓名和电话补出背面。仅已有且获准承接的背面可分流。
- 系列共用结构集中写，逐张补真实变量，覆盖完整系列；先试排最长姓名、头衔、多语种及最多规则版本，再统一尺度。
- 照片、Logo、二维码按需采用，背景主题可合为一张图。图片计划保留数量、用途、来源、真实 URL 短链及直接使用、编辑或借鉴方式；已有短链不省略，缺失写“短链待补”，待生成装饰明确标记。
- 二维码、条码、签名、手写、盖章和点位按实际操作区计容量，不作可压缩装饰。

### 2.1 名片与品牌联系卡

1. 个人名片突出姓名与身份；品牌联系卡突出品牌名与业务短句。先说明是谁、做什么，再安排联系信息。
2. 按用途归并联系项，明确主要联系入口；其他入口与服务说明按既定面数安排，仅在已有且获准的背面承接。
3. 配图与本人或业务对应：个人可用本人照片、真实作品或服务相关背景；品牌可用现有 Logo、品牌物件或代表作品。作品与归属说明成组，保留完整联系信息。

### 2.2 会员与权益卡

1. 品牌与卡身份成组，按用途突出等级、权益或金额。可用品牌标识、纹样或已确认 IP 建立归属。
2. 将权益或金额与对应范围、期限和限制成组，区分共同条件与专项条件。
3. 按“识别卡片 → 了解权益与条件 → 查询或使用”的顺序安排信息；已有规则面承接说明，入口与对应权益保持关联。

| 类型 | 组织差异 |
| --- | --- |
| 会员 | 等级与持有人识别相邻，权益说明接其后；等级用文字区分，不只靠颜色。 |
| 礼品 | 礼赠内容或面额与含义成组，期限、范围对应兑换说明；礼赠物件、插画或品牌背景突出赠送主题，实物图不暗示额外赠品。 |
| 储值 | 金额标签与数值紧邻，面值、初始储值、实时余额分组区分；查询入口靠近金额区，静态金额不冒充实时状态。 |
| 优惠体验 | 折扣或次数与对应限制成对对齐，服务图邻近适用项目，不扩大权益承诺。 |

### 2.3 集点卡

1. 参与规则放在点位区之前，计点动作与累计要求成组，便于先读规则再操作。
2. 按真实兑换规则排列点位，与盖章或记录说明相邻；采用主题插画时与操作区分开，装饰点不冒充完成印章。
3. 奖励接在累计点位之后，兑换条件与奖励相邻，兑换入口紧随条件，不挤占操作区。

### 2.4 票券

1. 活动或服务作首焦点，场次、时间地点按阅读顺序成组，座位或票种对齐其归属场次。
2. 按实际结构分主券与副券，各自信息保持完整对应；同属一面的主副券不拆成两面。
3. 核验入口靠近对应票券识别，使用条件与核验说明相邻，扫码或撕取区域不被装饰侵占。

### 2.5 共用试排与容量处理

以下数值仅为可选建议，不是硬标准，不覆盖真实内容或授权范围。

| 内容 | 建议 |
| --- | --- |
| 个人 | 正面 2–4 组，含姓名／品牌、身份及 1 个主要识别元素；已有背面可放 2–4 个联系入口或 2–3 行服务说明。 |
| 品牌 | 正面安排品牌、业务短句和主图；已有背面约 3–5 个联系／服务组；作品选 1 个主视觉或 1–3 个归属明确的缩略内容。 |
| 会员与权益 | 识别面约 2–4 组；规则面约 3–6 条核心规则，加期限及查询／兑换入口。 |
| 集点 | 6–12 个点位仅作版式参考，实际数量严格服从兑换规则。 |

- 单面超过 5 个信息组，先合并同类联系项、缩短未锁定说明，再由已有获准背面承接。
- 规则超过 6 条，先用短句分组，可使用真实且已纳入范围的规则入口或规则页；不自动增卡面或页，不靠缩小字号、删条件或隐藏内容塞满卡面。

## 3. 确定视觉方案

### 3.1 选择有辨识度的主方向

从本人或品牌希望留下的印象、已有作品和用途出发，选一个主方向，必要时搭配相容的局部手法。名片以姓名字形、作品取景、边缘主题或独特色彩关系建立辨识，不按职业、性别、等级套风格，不默认黑金、巨大 VIP 或统一工具图标。

下表给出可直接试排的方向；品牌色和锁定参考优先，字体须按 [fonts](fonts.md) 核验可用性。

| 风格候选 | 配色方向 | 字体与构图动作 |
| --- | --- | --- |
| 瑞士平面、现代编辑 | 暖白底、炭黑信息、钴蓝或朱红少量强调 | 无衬线字重对照；姓名放大，联系沿稳定轴线排布，用宽窄分区和细规则线组织 |
| 人文出版、编辑档案 | 米白、墨黑，赭红作注释强调 | 姓名用衬线，联系用清晰无衬线；作品局部与注释成组，正反面局部／全貌呼应 |
| 自然线描、手作纸本 | 纸白、深绿、低饱和土黄 | 温和衬线标题配简洁正文；枝叶或器物笔触沿边缘展开，纸纤维与有机轮廓共同表达，不只叠纸纹 |
| 复古商业、活版票券 | 奶油白、砖红、深海军蓝 | 展示字配易读正文；横向分段、边饰与轻微色版叠印，装饰编号不得伪装兑换码 |
| 装饰艺术、精细材料 | 深蓝、象牙白、少量哑金效果 | 精细衬线或几何无衬线标题；轴线对称、细纹样和安静标识，避免材料效果压过卡种信息 |
| 实验字体、街头印刷 | 黑白为底，荧光绿或亮橙局部撞色 | 粗展示字局部裁切、穿插或错位；另保留完整可读姓名，联系信息回到稳定网格 |
| 像素插画、涂鸦、黏土拟物 | 奶白、珊瑚红、天蓝分角色使用 | 短标题可用圆润或像素字，正文用清晰无衬线；主题物件与边缘互动，不侵占真实点位 |
| 抽象雕塑、透明层叠 | 冷灰、深紫、青蓝渐变 | 几何无衬线配大小对照；雕塑局部放大、负形与透光层叠，信息落在连续低干扰区 |

逐面明确主色、信息色、强调色、首焦点、图文主次、留白与裁切保护；全局风格写一次，版本只记录差异。

### 3.2 确定背景、构图与两面呼应

**进入 HTML/CSS 卡面设计时，每个卡面的作品级底图必须包含与本人、品牌及选定视觉系统相关的纹理、肌理或渐变至少一项，不得整面使用无变化纯色。** 姓名、联系、权益、条件和扫码区可降低纹理频率、对比及密度，或局部纯色承托，但应与整体连续同源。此条件不扩展到已有位图编辑等其他路线；入口允许直接复用背景时不强写 Prompt，仍检查上述底图要求。

| 构图策略 | 具体动作 |
| --- | --- |
| 姓名／品牌主导 | 用字形与留白建立识别，联系沿共同基线收束，不让每组事实争当标题 |
| 真实图像主导 | 让作品、照片或插画占据主要视觉区域，文字进入实际低干扰区，不默认套小相框 |
| 编辑分区 | 按身份、联系、权益分组；明确栏位归属，避免邮箱、电话、职业跨栏错配 |
| 票券主副分区 | 主券以主题、面额或票种及主题图形成视觉组，使用条件集中排列；副券按填写、核验、盖章的实际顺序安排。操作区保留足够空间，其余间距按信息关系收紧，不靠新增条款填空 |
| 同轴／反相 | 两面保持信息轴与关键位置，按职责交换明暗或主辅面积，不损害阅读对比 |
| 实形／负形 | 正面完整形体，背面用同源轮廓或负形承接，不把负形误作另一标志 |
| 局部／全貌 | 复用真实同源图像的局部与完整取景，保持方向、比例与身份，不改画作品 |

说明对象位置、主辅尺度、对齐与遮挡范围。系列统一信息轴、字体角色、材质尺度和边缘；小尺寸适配先保留身份、关键权益和操作区域，再简化装饰。

### 3.3 选择容器与安排文字

对齐、段距和分隔线足够时采用开放排版，不再套装饰卡片。需要容器时说明内容、位置、主次，以及采用的轮廓、材质、填充、边缘、厚度、透明和内部留白；只记录所选效果。

| 容器候选 | 使用条件 |
| --- | --- |
| 中性圆角分组 | 确需稳定联系或权益分组时使用，不把姓名、身份、二维码各装成同款卡 |
| 阶梯面板、切角铭牌 | 强调姓名或正式层级，不侵占裁切与安全边距 |
| 磨砂玻璃 | 数字卡或透明主题；检查透叠对比，不宣称实体工艺 |
| 纤维纸张、插袋、照片衬纸 | 服务纸本或作品语义，纹理尺度适配小卡 |
| 票券缺口、标签牌 | 有真实凭证或标签职责时采用，二维码及小字区保持平整无遮挡 |
| 胶囊、徽章 | 放短等级、状态或短权益标签，避免混淆 Logo |

展示字体只用于姓名、品牌或短等级标题，不承载电话、邮箱、地址、会员号、价格、有效期、条件及密集权益。竖排或实验字只用于适合的展示角色，不整卡旋转。Logo 与二维码保持独立可替换，不用装饰字代替。

HTML/CSS 交付的全部文案与文字效果由原生文字承担，关键字段准确可编辑；此要求不变成位图内部可编辑承诺。

### 3.4 选择资源并落实制作要求

制作与既有源编辑按 [入口](../SKILL.md) 裁定。混合新建／整体重做按 [produce-hybrid](produce-hybrid.md) 完成实际素材生产，HTML 实现按 [produce-code](produce-code.md) 执行；局部编辑只处理授权范围。

HTML 新建／整体重做及局改受影响项按 [templates](templates.md) 匹配：卡券整体构图查通用；需要参考以下局部布局时查“线下物料”，结果同时包含通用候选。票面轮廓查容器组，配色、文字特效和材质查对应通用组；完整读取选中正文及依赖，沿用有效选型。

| 需要参考的内容 | 查询范围 | 匹配词 |
|---|---|---|
| 品牌、姓名与标识的位置 | 构图／线下物料 | `标题与标识分列` |
| 联系方式、二维码与落款 | 构图／线下物料 | `二维码与落款联络区` |
| 权益、条件等信息分组 | 构图／线下物料 | `标签与事实说明分组` |
| 票面缺口与外轮廓 | 容器 | `票券`、`缺口` |

这些候选提供局部布局或轮廓，不是完整卡券模板；按实际卡面尺寸和文案重新组织，不直接套用长幅或邀请函整页。

- 逐图说明用途、来源、参考职责、允许编辑与保护范围；素材记录、参考实传及 Prompt 按 [produce-image](produce-image.md) 执行。HTML 底图不写卡面文案或字体排版；完整位图按其准确文案规则处理。
- 主视觉可由一张底图或独立主体承担，不因已有底图再重复生成主体；保留真实人像、作品、Logo、二维码的来源与替换入口。本人作品只作获准的缩放、裁切或局部复用，不擅自改画，不生成虚构作品冒充本人作品，不误删母版自带标记。
- 二维码、条码使用真实来源，核对目标与净空，不制造可能被误用的有效凭证编码。手写、盖章和点位按真实工具、材料与操作空间预留；未实测须标未验证。
- 出血、刀模、圆角、烫印、压凹、透明材料和套准只按真实供应商规格处理。纸纹、金属、珠光、压印仅代表可见效果；印刷色与屏幕色分别验证，透卡双面干扰以实际制作验证为准。
- 数字卡有效、过期、可用、已用等状态须有数据来源。静态稿不代表开户、支付、实时余额更新或核销能力。

## 5. 交付文件

单面交付一份清洁卡面；双面分别交付正面、背面两份清洁稿，标明对应关系及翻转方向。系列按真实人员、等级、面额或状态完整交付，数字状态按实际数量交付，不自动增加版本。

清洁稿不含桌面、纸堆、透视环境或卡外阴影。Mockup 仅作已纳入范围的展示，不替代正反面净稿；投影须符合接触或悬浮关系与光向，避免大面积暗晕，环境不计入卡面设计。
