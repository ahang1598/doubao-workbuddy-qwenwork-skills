# 电商详情页

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物按[主入口](../SKILL.md)执行适用的数量门禁，不做其他成品检查；长图段图和拼接成品生成后立即交付，不做生成后计数或质量检查。

准确展示商品，按购买问题组织内容，让商品、主张与证据逐段对应，保持整页视觉连续、实际阅读清楚。

适用：连续商品详情页；不适用于单张商品主图、商品套图或 Amazon A+ 模块。

**核心流程**：明确要求 → 安排购买内容与各屏职责 → 确定图文构图并试排定高 → 核对并交付独立屏，按诉求拼接完整长图

已有明确方案直接沿用，只补充本次任务所需内容。

## 1. 明确产物与要求

### 确认载体与输入

- **确认连续阅读产物。** 明确目标平台、地区、版位、发布宽度、总高限制、切片要求和实际阅读宽度。外文不自动等于 Amazon；未明确 Amazon 的连续详情按国内详情职责组织。A+ 按真实模块执行，不套本文件的段数、首屏比例或整页上传方式。上传前核实平台要求。
- **沿用要求与记录。** 保留已确定的商品、文案、数量、尺寸、参考和修改范围。事实、身份、授权、参考来源及唯一 Brief 按 [common.md](common.md) 执行，不为布局改写锁定信息。整页与逐屏设计统一补入同一 Brief，记录项见第 2 章，全页共同决定只写一次。
- **限制具体价格位置。** 国内详情绝大多数段不放具体价格；只有确有转化职责的规格段，才可使用用户明确提供或确认准确的价格，并完整展示条件。不因平台允许、文字可编辑或使用图片而扩大到整页。

### 确认制作与文字边界

- 路线与批准由 [主入口](../SKILL.md) 裁定。混合详情默认使用商品／环境首图与原生可编辑标题、文案；首图不新增上屏文字，保留商品原有包装文字与 Logo。
- Brief 或用户明确采用一体首屏，且不冲突文字独立编辑要求时，仅主标题和必要短辅助文字可入图。其余标题、价格、货号、规格、参数、单位、日期、正文、来源和条件保持原生文字；不生成独立标题图。一体首屏的组装与图内文字修复按 [produce-hybrid.md](produce-hybrid.md)。
- 混合详情中独立放置的 Logo、二维码和行动按钮保持可替换，并符合平台限制；商品原有包装文字与 Logo 按身份源保留。
- 仅入口授权时制作纯图详情，不要求图片内文字独立可编辑；制作及长页分段拼接按 [produce-image.md](produce-image.md) 执行。

### 确定宽度、总高与正式首屏

- **统一整页宽度。** 采用用户尺寸或实际发布要求，各内容段和最终切片等宽。本文的 750px 仅为计算示例，不是统一上传宽度；换宽时同比换算，再按阅读效果调整。
- **区分屏与视口。** 一“屏”是一组围绕主要购买问题展开的图文，不等于手机视口，不要求等高。后段不继承首屏比例，内容段、背景、素材与切片也不自动一一对应。
- **按优先级确定正式首屏。** 用户明确尺寸或比例 ＞ 完整采用的命名模板或样式方案规定的首屏高度 ＞ 默认 **5:9，H/W＝1.8**，例如 **750×1350px、1080×1944px**。仅借配色、字体或局部模块不改变默认高度；所选模板或样式方案未规定首屏高度时仍用默认值。
- **区分正式首屏与方向样图。** **1920×1080** 横版 KV、独立商品图和 A+ 模块比例均不决定长页首段比例。须按正式画幅重新安排主体、环境、文字空位和保护区。
- **保留锁定总高。** 总高锁定时，在既定首屏和总高内调整后段；仍放不下则说明冲突，仅暂停受影响部分，不擅改首屏或总高，不删事实、拉伸或裁断内容。未锁定高度按第 3 章试排确定。

## 2. 安排购买内容与各屏职责

### 按购买问题确定顺序与分工

- **判断先回答什么。** 结合购买动机、顾虑、决定性证据、决策成本与风险、购买时机安排先后。陌生新品先解释是什么；成熟品类突出真实差异；高风险或高客单商品前置信任依据、适用条件和风险。食品、护肤和材质商品可先建立感官吸引，再回到商品事实。
- **统一记录整页与逐屏设计。** 在同一 Brief 记录上述判断、证据、整页顺序及内容增减办法。每屏记录主问题、结论、准确文案及来源、配图职责、必要视角和定位上下文；第 3 章继续补入第一视觉对象、主体尺度、图文位置、保护区、背景分组、尺寸依据和接续方式，各屏只写差异。
- **先展开信息，再确定篇幅。** 先按下表核对已有资料能回答哪些购买问题，将特点展开为具体表现、使用价值及适用条件，并配上对应细节、动作或比较依据；同一主张可由多个相关要点共同解释，不把“一屏一个主问题”简化成“一句口号配一张图”。完成内容覆盖后，合并不独立的任务、去掉不适用项，再拆分无法在一段内讲清的复合任务。同一卖点的介绍与证据就近组织，篇幅由实际解释量决定；缺事实或证据登记待补，其余有依据的内容继续完善，不用重复文案、无职责图片或经验占位事实填高。

### 按品类安排顺序与资料

段数仅用于估量复杂度，不是配额；证书、测试、试用、退款、履约和服务等按实际资料选用。

| 购买品类 | 整页责任链 | 重点资料与篇幅参考 |
| --- | --- | --- |
| 功能标品 | 商品与使用问题 → 功能解决 → 结构、性能与同口径比较 → 适配、规格与质保 | 结构、性能条件、使用证据、兼容信息和质保范围；**6–9 段**。 |
| 颜值商品 | 风格与生活方式 → 场景搭配 → 材质工艺与体验 → 系列选择、适配与售后 | 全貌、实际使用、材质细节、颜色款式及保养资料；**7–11 段**。 |
| 高信任商品 | 商品与用户问题 → 信任依据、机理及同条件证据 → 适用限制 → 用法、试用与售后 | 检测、专利、机构或专家资料及适用范围，实际试用、退款条件；依据和限制紧邻主张，**7–10 段**。 |
| 高频快消 | 商品与体验 → 规格、组合和场景差异 → 履约与售后 → 选择收束 | 真实规格、感官体验、组合或赠品内容、发货时效和包赔条件；**4–6 段**。具体价格仍按第 1 章限制。 |
| B端采购 | 商品与标准 → 场景、测试及细节 → 参数和制造资料 → 采购与服务 | 标准、测试口径、工厂资料、客户案例，以及实际寄样、定制、起订量、开票和采购流程；宣传图不作能力证明，**5–8 段**。 |
| 轻奢高客单 | 商品与身份价值 → 材料、工艺及来源 → 佩戴或空间关系 → 证书、保养与服务 | 材料来源、真实触感、尺度、证书及服务范围；**5–7 段**。 |
| 虚拟服务 | 服务解决的问题 → 真实内容、界面或流程 → 权益与适用对象 → 交付及售后 | 内容、使用条件、有效期、交付方式与退款规则，不虚构界面或能力；**4–6 段**。 |

结合具体品类核对内容覆盖，再决定顺序和分屏。下表为展开维度，不是必做章节；按当前商品、购买问题和真实资料选用，多项可同屏，一项也可在确有解释需要时展开。只描述图片可观察的形态不能据此推断材质、工艺参数、性能或认证；功效、数据、授权及服务承诺须有依据。

| 商品品类 | 可展开的内容 | 如何解释与呈现 |
| --- | --- | --- |
| 服饰鞋包 | 风格款式、系列差异、材质、廓形比例、五金标识、功能结构、尺码、容量／穿着表现、颜色搭配、保养服务 | 全貌与上身图解释轮廓及比例，局部对应织纹、缝线、五金和开合；有资料时用尺寸、容量及搭配对照帮助选择，不把“质感好”作为全部解释。 |
| 美妆护肤 | 使用需求、方案、成分／技术、机理、功效依据、质地肤感、温和性资料、用法、人群适配、组合方式、规格及FAQ | 将主张与已有证据、适用范围就近组织；质地以真实涂抹或局部呈现，用步骤说明用量和顺序，款式或色号按同条件比较；成分机理不直接充当成品功效证明，前后对比须有来源。 |
| 数码家电 | 使用问题、核心场景、性能、关键部件、功能体验、操作交互、连接生态、兼容条件、结构细节、型号差异、包装与服务 | 先说明功能解决什么，再用部件定位、真实操作或同口径参数解释如何实现及适用条件；型号对照回答具体选择，保留接口、配件和环境限制，不用技术装饰代替说明。 |
| 食品／生鲜 | 品类品种、原料产区、等级、制作工艺、鲜度依据、切面层次、口味口感、营养资料、吃法场景、份量、包装、储存／冷链及售后 | 全貌与切面说明实际组成和口味差异，食用动作说明吃法，规格与包装解释份量和携带；产区、营养、温度及鲜度承诺只采用真实资料，感官图不充当检测证明。 |
| 日用家居 | 生活问题、结构、材质、功能分解、尺寸空间、容量效率、操作体验、安全耐用、多场景、款式规格及服务 | 用空间全景交代尺度，局部和操作说明结构如何解决问题；尺寸、容量和场景对照帮助适配，安全耐用说明匹配已有依据，不只重复不同背景下的全貌。 |
| 母婴 | 年龄阶段、亲子场景、结构、安全、人体工学、舒适环境、照护者操作、尺寸重量、空间适配、接触材质、多模式、清洁维护及认证服务 | 区分儿童体验与照护者操作，阶段／模式对应实际使用条件；结构定位、动作步骤和尺寸说明就近组织，认证注明适用对象与范围，不凭画面推断安全性。 |
| 时尚潮玩 | 角色与故事、系列阵容、单款角色、多角度比例、表情造型、工艺材质、玩法结构、互动、款式机制、包装清单及授权防伪服务 | 全貌建立身份，多角度展示姿态比例，局部解释表情、纹理及已知工艺；有玩法则用连续动作说明，有系列则比较实际差异；包装逐项对应数量，来源与授权不由角色外观推断。 |

- **套装先全貌、后单品。** 后段不反复放全家福；说明包装组成、颜色规格或同条件比较时可再次整体展示。名称、数量与图片逐项对应，不混入另售配件。
- **让资料帮助选择。** 参数、FAQ、尺码和对照表须解决具体判断，保留关键行列、单位、适配范围和条件，口径一致。资料多时调整分组与版位，不压成小字资料墙。
- **其他篇幅参考。** 其他品类 **8–14 段**、国内综合详情 **5–15 段**也不是配额；没有独立内容或必要过渡，不另起一段。

特定内容顺序可按商品采用：

- **性能递进长页：** 运动商品由性能主张进入局部结构、性能依据与使用条件，再以规格、适配及服务帮助选择。
- **暖烘焙食品长页：** 按原料、制作、食用场景、包装和资料分章，可用编号串联；不因参考存在某章而补造产地、温度或营养事实。

### 组织各屏图文

以下是可合并或省略的职责，不是必做屏型清单。

- **开场／识别。** 用商品全貌、使用场景或有定位上下文的核心细节建立身份，主副层级说明是什么、适合谁及核心利益。图像承担第一视觉焦点，文字与主体共同构图，不用一圈卖点卡代替首屏。
- **场景／需求。** 实用商品用实际动作和使用障碍说明需求；生活方式商品可展示理想场景。文字点明情境，图片保留商品在其中的作用，避免图文各讲一件事。
- **价值／证据。** 标题给出基于事实的结论，正文说明具体特点、使用价值及适用情境，按需补充原因、条件与限制；图片用结构、细节、步骤或同条件比较解释，不只配一句空泛赞语。来源紧邻主张，缺证据登记待补，不用氛围图或经验占位代替。
- **规格／使用／服务。** 将型号、尺码、操作、适配或服务条件组织成可扫描的信息组，图示承担定位、步骤或选项对照。表格保留决策所需行列，不为整齐压小关键条件。
- **过渡／收尾。** 过渡连接前段已回答与后段待解决的问题，优先在相邻段内改变景别、尺度和密度，确有独立转接任务时才另设。通常 **0–20 字**，可无字，不作硬门槛；首屏后简短且视觉从属，页中可用材质局部、环境细节或章节提示，不放复杂参数、优惠或规格，有新证据或购买结论则按内容段处理。收尾说明选择条件、服务或下一步行动；独立结尾图须补充商品、礼赠、场景或服务信息，现有背景与开放排版能承担时不另添图。

标题、栏目、过渡和基于事实的卖点可按 [common.md](common.md) 完善；锁定文案、事实、价格、参数与数据不擅改或编造。语义接续不等于共享空间，连续背景依据与过渡段高见第 3 章。

## 3. 确定图文构图并试排定高

### 确定整页图文安排

1. **先规划整页，再确定分屏。** 沿用第 2 章的内容顺序，先合并重复表达，安排重点展示、细节解释、比较与规格的主次，再确定主图尺度、图文位置及分屏边界。将标题、对应图片和说明作为完整信息组，相邻组一起试排图文顺序后再定屏；不因各屏独立选版式而拆散归属，也不按段落数、素材数或统一高度分屏。独立 HTML 是交付单位，不要求各屏都具有独立海报式的开头和收尾。
2. **选择贯穿整页的图文关系。** 可用大场景与留白文字、商品与邻接说明、左右图文交替、编辑式大小图穿插，或连续场景组织内容。选择适合当前商品的一种主要关系，局部按说明需要调整；字体、配色与对齐规则保持统一；不同说明任务分别安排图文，不因模板相同而全部沿用同一图框和文字带。具体构图方法见本章“安排主体、文字与配图”。
3. **逐对判断内容与画面是否推进。** 先明确上屏已经解释什么、本屏新增什么，再选择整体轮廓、使用场景、材质微距、结构标注、动作步骤、规格决策或服务说明等证据形态。说明任务已变化却仍只替换图片、标题或底色时，调整景别、主体尺度、图文位置或信息组织，让变化服务新增内容。真实同条件比较、连续步骤及同一场景叙事可复用布局，但须能指出比较维度、动作或焦点的推进；不规定逐屏变化数量，也不为变化换背景或添加无职责图片。

将整页安排写入现有 Brief，再匹配各屏模板。相邻屏共同确定交界处的背景、明暗、主体出口和下一屏入口，具体按本章“确定背景范围与表面”执行；模板适配不得重置整页视觉系统。文字与图片共同试排，文字落在实际背景上仍须清楚，不把素材剩余空位直接当文字区。

### 按屏标签匹配模板

根据各屏内容、配图需要与整页图文安排，按 [templates.md](templates.md#详情页按用途布局与整页风格选型) 检索；保留整页模板，通过屏级索引定位，不将整页名称当作屏用途。

| 层级 | 标签或记录 | 用法 |
|---|---|---|
| 整页 | 商品品类、整页风格 | 品类用于判断内容与商品是否适用，无依据标“通用”；风格用于统一全页，默认仅作为候选偏好，不给每屏另造风格 |
| 屏名称 | 如“主题收束与发售门店” | 说明该屏具体内容，便于定位和复核；不能代替用途与布局标签 |
| 屏用途 `purposes` | 主视觉、场景、卖点、细节、原理、效果、对比、选购、步骤、参数、信任、收尾等 | 回答“这一屏帮助用户理解或决定什么”；功效诉求转成有事实依据的效果、原理或对比任务 |
| 屏布局 `layouts` | 满幅场景、独立图窗、图文分栏、主图＋局部特写、图解标注等 | 回答“图文如何组织”；以当前 `catalog` 词表为准；按实际图层与裁切关系区分满幅场景和独立图窗，不因主体定位框或容器改变满幅判定 |

- **用途与布局共同匹配。** 首屏先匹配“主视觉”，需要满幅场景时再加“满幅场景”；仅命中满幅不代表适合首屏。细节说明可查“细节＋主图＋局部特写”，具体组合须按内容需要选择，两个条件必须在同一屏成立。
- **结构适配后参考风格。** 先核对图片数量、比例、文字容量与依赖，再参考整页风格和同源偏好；用户明确限定风格时才设硬条件。商品品类按现有 metadata 核对，不将品类或商品功效冒充已实现的检索参数。
- **命中后完整读取。** 对 `screen_ref` 先 `describe`，再完整 `read` 来源；同源正文读一次，各屏仍逐一核对实际区域、主体位置、文字安全区和 `required_sections`。无命中时检查标签与硬条件；人工定位须说明，不声称屏检索已命中。
- **采用后核对效果。** Brief 记录屏名称、用途、布局、来源屏引用及必要调整。保留标题、副标题、分屏小标签和完整主体；按显式屏标签、背景分区及内容关联判断边界，不等高切屏。跨模板统一字体、配色、边距与接续；检索命中不等于采用后效果合格。

### 选择商品表现方向

- 依据轮廓、包装识别、材料、使用动作、品牌规范和授权参考选择主方向，再安排光影、尺度、字形与阅读路径；辅助处理只补必要能力，不逐项叠加。
- 首屏可集中表现，后段按职责减弱效果、改变景别或延续线索，不要求所有后段都由大图主导。与事实、编辑或平台要求冲突时，先调整作用区域和实现方式；仍不兼容则说明替换手法及原因，不因缺素材擅换风格。
- 区分形象与证据：不伪造内部结构、检测图、仪器读数或证书。感官画面不能证明产地、营养或等级；机理图只表达有依据的关系，非实测结构就近标明“机理示意”，不把成分或部件机理扩大为成品功效。

| 视觉方向 | 适用依据 | 表现动作 |
| --- | --- | --- |
| 理性证据与工程编辑 | 参数、规格、验证条件决定选择 | 用稳定网格、编号、局部放大、细标注线和单一验证色；洁净证据用高明度底、同口径对照及充分条件，工程资料保留尺寸基线、真实部件和图例，人物与肌肤保留自然纹理。 |
| 食欲微距与流体质地 | 口感、肤感或液体状态需要解释 | 食品突出真实断面、水汽、油脂、气泡和食物色；护理突出凝胶透光、乳霜推抹、液滴边缘及受控高光。保护形态、份量和配料事实，流体须关联材质或商品，不用无关玻璃球、花瓣替代商品。 |
| 纤维与手作触感 | 织物、纸、木、陶土有辨识价值 | 用侧光显示织纹、纤维、木纹、陶土颗粒和手工边缘，将材料放大为承托面或定位细节；纹理限对应区域，不覆盖成分、规格和洗护说明，不统一套仿古滤镜。 |
| 复古商业套色 | 品牌或零售主题有年代、印刷依据 | 用有依据的暖纸、有限套色、粗字、商品剪影和受控错版边；网点、墨边、缺墨只作用于指定图层，不污染包装及照片颜色。 |
| 高对比平面促销 | 真实利益或行动是该段主要任务，且平台允许 | 用大色块、真实利益数字、商品破框和一个强行动色建立主次，条件独立可读，不把全部卖点排成同权卡片；具体价格仅按第 1 章例外使用。 |
| 上新与档案拼贴 | 新品序列、系列差异或资料需要并置 | 用真实商品切片、票签、贴纸、衬纸和受控倾斜组织序列，统一尺度与光向；纸片承载具体内容，不遮挡 SKU、卖点和行动路径。 |
| 自然日常纪实 | 使用动作和真实尺度是主要证据 | 用自然窗光、人物动作和环境负空间建立生活关系，保持人物、地点、时段与镜头连贯，不用没有商品交互的泛化家庭图库画面。 |
| 受控棚拍与材质静物 | 轮廓、材质和做工需要集中展示 | 统一光位、台面、镜头和少量道具，用掠射光、柔影、反射或褶皱表现触感；让商品与表面形成压住、倚靠、悬挂或投影关系，不用镜面台座和无关粒子代替材质。 |
| 空间陈列与编辑叙事 | 商品需要在房间、货架或生活空间中被理解 | 用门窗、台面和货架建立空间坐标，通过视线、路径与全景—局部变化发现商品，保留实际尺度；跨段使用同一空间时不随意换地点和光向。 |
| 结构路径、清透光场与柔性3D | 结构、流程或有依据的作用界面需要解释 | 真实部件沿轴线分层，路径、编号准确对应；光场用冷白至低饱和蓝紫透明层、清楚轮廓和低干扰区域；柔性3D用圆润对象、作用界面和少量材质对比表达定性关系，无机理依据时改用真实使用、结构、流程或材质。 |

局部方法按相关性选用，不作为真实状态或功效证据：

- **感官色味转译：** 将口味、香气或温度联想转成色场、材质与光线，保护商品本色，不暗示未经证实的成分或效果。
- **冷凝与封存：** 用冷凝微距、气泡、透明器皿或冰块封存形成冷感，不冒充真实储存状态、鲜度或性能。
- **冻结动作与尺度错置：** 定格相关食材、液滴或商品，或改变相对尺度形成概念对照；保持身份，不以夸张尺度证明份量、容量或效果。
- **角色化或微缩场景：** 让相关品牌角色与商品形成连续动作，不遮挡身份或虚构功能。
- **材质隐喻：** 将柔顺转为丝线的连续弧线、清新转为疏朗枝叶间隙、润泽转为包覆表面的薄液膜，以曲率、疏密、透明度和接触形态承载感受，不声称是实物状态或效果。

### 选择整页摄影与图文节奏

内容顺序沿用第 2 章，以下只决定观看方式，不替代必要销售资料。

| 视觉候选 | 适用情况 | 可见安排 |
| --- | --- | --- |
| 摄影分章长页 | 运动、服饰等有多组穿搭或使用摄影 | 交替使用大幅摄影、非对称图窗与单品细节，大图建立章节，小图补背面、环境或材料信息，文字沿共同网格组织，不以配色决定内容顺序。 |
| 烘焙沉浸摄影 | 以多口味切面、手掰和食用体验解释差异 | 大幅摄影、切面、手掰与相关细节连续推进，通过景别和尺度变化衔接章节。 |
| 清透微距感官长图 | 果茶等适合表现透光、气泡和质地 | 在整页中连续叙事，分屏后仍用清晰与虚化区域、共享背景和相邻边缘呼应衔接；有对读需要时才用两列，不默认拆成左右两图。不替代完整销售详情，不沿用示例事实、段数或总高。 |

采用模板时，按 [templates.md](templates.md) 根据真实内容容量、图文主次和连续关系选择，读取所选正文及必要资源后适配当前商品；局部借用不称整页套用。

### 安排主体、文字与配图

按本段任务选择呈现方式，不固定绑定屏型：

- **满幅场景：** 首屏及正文的使用场景、感官和材质表现，优先评估满幅场景与文字共同构图。场景覆盖该段画布宽度，兼任背景与主图，按主体、动作及文字净空安排位置；段高由实际内容确定。
- **透明主体与开放排字：** 需要独立移动、跨层或遮挡时，保留透明边缘、孔洞与自然阴影，以接触、投影连接承托面，文字沿主体外侧组织。
- **独立图窗：** 证据、比较或来源需要明确取景边界时，保留边界与就近图注；同条件比较统一尺度、视角与裁切，不机械缩小完整场景。

- **落实画面关系。** 按购买问题决定先看什么：需先理解结论时文先图后，需先感受外观或场景时图先文后；解释功能可图文分栏，结构说明可环绕标注，整体与细节可用大小图配对，多组相关说明可交错组织。对应说明就近组织，不跨另一商品图寻找归属。同商品全貌与细节共用明确说明时可连续展示；仅配色一致不算内容推进。前组图尾接后组图头时，须有明确的比较、步骤或叙事推进；否则移动说明、调整主辅图尺度或合并相容内容，不强制图文交替，不补空话隔图。再落实取景、承托、文字净空和保护区；不把全页统一成“标题＋矩形商品图＋一句说明”，也不因文字可编辑就全部排在图外。
- **保留首屏焦点。** 核心影像成为第一视觉焦点，商品身份清楚；完整商品不必总是最大对象，微距主导时保留全貌或部位定位。在既定首段高度内展开核心影像、环境与文字构图。
- **区分主辅。** 重点展示图与补充图用可见尺度和位置区分，局部、背面或搭配图作为辅助时，不与主图全部等宽、等高、等权；细节本身是核心卖点时可放大为主图。同类陈列与同条件比较可保持同尺度同权。辅助图须增加细节、定位、过程或比较信息；无新增信息不添图，普通信息段可无图。
- **先排信息再加框。** 优先使用对齐、字级、距离、编号、引线和图文对应；背景块或边框仅用于隔离复杂背景、划分比较单元、标识凭证标签或保留参考取景框。收拢不服务阅读、分组或保护的空白。

| 构图方法 | 适用内容 | 段内安排与后段连接 |
| --- | --- | --- |
| 完整陈列与近景切入 | 轮廓、身份或核心材料 | 完整陈列、偏心、悬挂或从前景切入，以台面、布面、纸面承托；标题放轮廓外低干扰区，短卖点沿一轴排列，保护识别部位，后段再放大局部。 |
| 斜向动作与性能瞬间 | 真实动作、方向或状态变化 | 人物、商品、布料或液体沿对角线推进，文字放另一侧或动作结果旁的安静区域；必要时补连续帧或同尺度对照，辅助元素顺势递减，不用斜线、光轨伪造动作和因果。 |
| 材质舞台与极端微距 | 触感、工艺、切面或局部结构 | 细节为主要证据时放大微距，以小全貌定位，解释贴近对应纹理、部位或层次；材料作为承托面时让商品压住、嵌入、倚靠或形成反射。后段可转入实际使用、制作或结构，不能只换另一张等大特写重复赞语。 |
| 人物使用与真实负空间 | 上身、操作或空间尺度 | 用动作、视线、手部接触建立人与物关系，让人物或商品跨越主要画面；文字沿墙面、地面、窗光或适合排字的浅景深区域排列，局部特写补材质，不以多张小模特照代替完整场景。 |
| 结构环绕与规格轴 | 部件、尺寸、适配 | 完整商品居主要位置，真实部件沿轴展开，短结论和标注围绕结构；单位、条件紧邻对象，连线不交叉遮挡，后段可放大已定位部位。 |
| 编辑式大小图与图文交错 | 品牌、服饰、生活方式、多卖点 | 大图建立整体或章节，小图补环境、背面、局部及其他必要证据，文字就近对应；多组解释沿共同网格交错推进，图数由信息增量决定，不全部等大并列或都挤在图下，不做无关拼贴。 |
| 同尺度对照与左右对读 | 颜色、型号、规格、效果或场景差异 | 图片保持可比尺度、视角、裁切及光线，名称、差异、单位与条件按对应轴对齐；可图文换边但归属不变，不用大小、明暗或无依据文案制造差异。 |
| 路径步骤与证据网格 | 使用、服务、工序、参数 | 步骤按真实动作连续排列，每步由动作说明与对应图示组成，人物、商品方向和环境保持连贯；参数按决策问题分组，稳定行列、单位及条件。密集处先调整组距、景别与密度，不机械插情绪屏或空白段。 |
| 错位商品阵列与重点展示 | SKU、口味、系列或允许的利益 | 统一基线、光向和裁切，区分主次，名称逐一对应图片；标题说明商品及真实利益，规整信息区解释规格和条件，不把不同型号混成装饰拼贴。 |
| 连续空间与跨框衔接 | 同一空间或对象贯穿多段 | 延续商品、人物、材质或路径，改变焦点、景别和信息密度，文字空位随场景移动；段尾只保留明确连接对象，接缝不切断 Logo、关节或功能结构。 |

### 确定背景范围与表面

- **分开内容组、背景组与素材组。** 按购买问题分段后确定背景覆盖范围，最后按交付要求切图。一个背景可跨段，一个内容段可使用多项素材，不要求一段一图或一张全页底图。
- **核实实际连续来源。** 同一空间使用同一母图、连续裁切，或共同制作且核对后能连成同一场景的素材；颜色近似、内容相关不等于同一空间。透视、尺度、纹理、光向、接触关系及前中后景须一致。
- **只在后一段记录接缝。** 写清延续什么、不再出现什么、哪里留给文字或主体，以及换景理由。渐变与纹理按背景组延续，不逐段重启。
- **按边界衔接。** 独立图窗保留边界，换章不自动加渐变；连续照片先满足空间关系，再在最终裁切后的安全空场衔接。背景色场、前景淡出和接缝遮罩分别处理，不用透明度或混合模式蒙两张独立完整 KV 造连续，不靠白雾、黑幕或纯色块遮掩断口。文字净空与接缝保护按 [common.md](common.md) 执行。
- **让表面实际可见。** 作品级长页至少实际可见一项与主题相关的纹理、肌理或渐变，不整页铺无变化纯色；被不透明上层遮住不算采用。正文可局部纯色或低纹理，但须属于同一背景系统。
- **统一同组摄影。** 棚拍保持光位、台面和镜头一致；生活场景保持人物、地点、时段与光向一致；微距保持商品颜色、色温和材质细节一致。白底商品图也须依据真实外观，不补造缺失部位。

表面须写清实际安排：

- **纤维、织纹、陶土：** 纹理尺度、方向和侧光，限于对应材料区域。
- **套印表面：** 色版、偏移、网点和缺墨区域，保护包装、照片及事实文字。
- **流体表面：** 透明度、边缘与高光，质地须与商品相关。
- **渐变色场：** 流向、色阶及低变化阅读区，不只记录效果名。

### 选择字体、文字轴线与标题表现

- **分清文字角色。** 主标题、解释、数据单位、来源和条件建立不同层级；数字、货币与单位清楚对应，展示字不排密集规格。
- **建立阅读轴。** 单组可上结论下说明、标题独占区域或贴近商品局部；多组可同轴分组、主结论带并列要点、双栏对照或按步骤排列。上下图文保持阅读先后，左右换边沿用共同网格，沿边或环绕标注仍须顺序自然、归属明确。
- **分别选择字体、效果与配色。** 不与视觉方向固定绑定；字体资源、加载与字形覆盖按 [fonts.md](fonts.md) 执行，用准确文案试排。

| 字体组合 | 适用内容与安排 |
| --- | --- |
| 中性信息 Sans | 标题用中粗至特粗，正文和表格数字保持中性，不让全文同粗细。 |
| 精致 Serif＋Sans | 衬线标题表达品牌语气，Sans 排事实与说明，稳定数字，不以细衬线排规格小字。 |
| 商业粗体＋条件 Sans | 区分利益、数字和条件层级，艺术处理不改变数值。 |
| 工程 Sans＋Mono | 用字级、编号和结构表达重点；Mono 限短参数和编号，连续说明用 Sans，不用伪代码装饰整页。 |
| 人文展示字＋Sans | 展示字表达品牌语气，正文保持稳定；手写或刻印字不进入规格、法务和行动按钮。 |

| 标题表现 | 使用条件与动作 |
| --- | --- |
| 克制粗黑 | 用中粗至特粗、受控字级和少量切角强化首屏最重要标题，不批量用于章节标题。 |
| 材质融合 | 一级品牌或概念短语与光影、液体、材料局部呼应，逐字核对并保留来源；编辑性遵守第 1 章。 |
| 紧凑商业排法 | 用粗字、窄字、有限套色或破框压紧构图，保持字形和数字可辨，不省略利益条件。 |
| 拼贴标签 | 中粗至特粗文字配有明确内容归属的纸签、撕边或贴纸壳，文字与装饰分工，不妨碍正文。 |

### 确定配色关系

- **保护固有颜色。** 保留商品、包装、Logo、肤色、食品和材料本色；依次从商品色、品牌色、原料材质和可信参考取色并记录来源，不足时才按主题另选，不统一调色改变商品。
- **确定主辅关系。** 强识别商品色优先作主色，或选同类、邻近背景；品牌硬性规范指定主色时以品牌色为主，保留商品真实颜色。辅助色可用同类深浅或邻近色；关键数字、利益或行动需要强调时，可用互补色或分裂互补色。
- **限制附加彩色家族。** 默认新增两系，确需强调才加第三系，最多三系；同色深浅算一系，中性色和不可改变的商品等固有色不计。新增背景、文字和装饰色均受约束。
- **分配职责并延续。** 主色组织画面，辅助色分层并连接相邻色块，强调色限必要位置；连续段可改面积和明度，不逐段换色板。摄影统一色温、弱化无关颜色，不改变固有色。
- **核实暖浅底依据。** 大面积奶油白、米白须有用户、确认参考、品牌或商品依据，不因“柔和、高级”自动采用。
- **记录用途。** Brief 说明画布、表面、正文、次要文字、强调和警示的用色，实际色值留在实现源。采用资源配色须读取完整参数，不将缩略图估色称为已读取参数。

| 配色关系 | 适用依据与安排 |
| --- | --- |
| 临床白＋冷灰＋验证蓝 | 白、冷灰安排洁净技术与事实，蓝标验证或关键证据，不覆盖肤色和商品色。 |
| 奶油中性＋材质本色 | 暖浅底有依据时采用；从商品提取强调色，用明度差分章，避免米色低对比和全页同明度。 |
| 黑白＋单一行动色 | 一个有彩色表示允许的利益或行动，不用荧光色排细正文。 |
| 暖纸＋两色套印 | 印刷方向及暖纸有依据时，纸色、主套色、定位色形成有限色版和叠色，错版不作用于包装、照片和事实文字。 |
| 自然低饱和 | 从商品、原料、纺织或环境中的植物、土壤、材料取色，配克制强调，不用泛化绿色暗示天然或安全证明。 |
| 冷白银蓝＋性能色 | 冷白、金属灰组织结构和设备空间，蓝或青标性能、状态，避免整页深蓝霓虹化。 |
| 深色底＋材质高光 | 暗场衬托光泽，以清楚浅字和单一金属或商品色分层，保持正文对比，不自动套黑金。 |
| 品牌撞色＋稳定事实底 | 品牌主色主导，辅助色有限参与；事实区使用稳定中性阅读面，不逐段换高饱和底色。 |

### 用真实内容试排并确定段高

用准确文案、选定字体、主素材比例和主体可见尺度试排，计入标题组、全部说明卡、正文、图片、必要留白与段尾出口，不只计算图片框。正式首屏服从第 1 章优先级；后续屏未被用户、发布规格或已确认方案锁定高度时，按内容定高。下表仅为起排参考，采用参考数值不等于锁定尺寸；确定后导出为固定尺寸 HTML。比例按“宽:高”书写。

| 模块用途 | 参考比例 | 750px 宽度示例 | 排版动作 |
| --- | --- | --- | --- |
| 简短卖点／服务说明 | 1:1 | 750×750px | 安排少量说明，不为填满画面重复卖点。 |
| 常规卖点 | 3:4 | 750×1000px | 作为常规模块起排参考，按文案、商品与证据调整高度。 |
| 细节／材质／少量步骤 | 2:3 | 750×1125px | 为局部图片、标注和说明留出阅读空间。 |
| 大商品／场景展示 | 3:5 | 750×1250px | 大图配底部说明，或沿阅读轴与文字空位排说明；保留真实尺度和接触关系。 |
| 首屏／完整场景／竖向标注 | 5:9 | 750×1350px | 默认长页首屏采用此比例；后续大图或场景按内容选用。 |
| 沉浸式大图／已指定比例的首屏 | 9:16 | 750×约1333px | 后续模块按取景选用；首屏须由用户指定，或由完整采用的命名模板、样式方案明确规定，不替换默认比例。像素取整后为近似比例。 |
| 复杂步骤／参数 | 1:2 或按内容定高 | 750×1500px 以内可作起排参考 | 不必用满，也不把 1500px 当上限；过密时拆分，合理增高时保留图文对应与可读性。 |

过渡职责按第 2 章执行，起排高度参考如下：

| 过渡段位置 | 高÷宽起排参考 |
| --- | --- |
| 首屏后 | 0.38–0.68 |
| 页面中段 | 0.45–0.90 |

- **按容量调整。** 先放入完整文案与配图，再确定未锁定的段高。画面空时先判断内容是否需要展开，再调整主图尺度、文字栏宽和间距；内容已充分且无必要留白时，缩短未锁定的段高，或合并没有独立内容的相邻段。内容拥挤时增高或拆分，不缩字、不补空白凑高、不按固定留白率计算。已确认的尺寸保持不变，在既定范围内调整图文；仍有冲突按第 1 章处理。过渡超出参考范围时说明段高依据并复核接缝，不把范围当最低高度或硬上限。
- **同步复核总高与背景。** 总高锁定时按第 1 章处理；段高变化后重查背景覆盖、图片取景、主体净空、接缝与切片。
- **按实际阅读宽度确定字号。** 手机阅读宽度未指定时按 **390px** 检查，多目标宽度分别检查。有效字号＝源 CSS 字号×整张画布显示宽度÷源画布宽度；正文默认 **16–19px**，辅助说明默认 **14–16px**，所有内容文字不得低于 **13px**。例如750px宽母版显示为390px时，16px正文对应源字号约31px，13px下限对应源字号25px。放不下先重排，不把13px当正文默认值，不直接沿用模板小字。位图按相同阅读尺寸检查，无法确认字号时记未验证，不猜源CSS值。HTML 实现见 [produce-code.md](produce-code.md)。

## 4. 交付

### 交付独立屏，按需拼接长图

- HTML 路线按已确认的屏边界制作，每屏一个完整 HTML，各自设置尺寸、检查并导出；屏按完整内容与视觉边界划分，不按手机视口等高切分，也不把每个段落自动当作一屏。
- HTML 路线在 PC Web 按屏序交付独立画布对象；Mobile 仅交预览并在任务目录保留分屏源文件。
- HTML 连续非末屏可按 produce-code 在根节点声明实际下一屏并省略底部空白；末屏仍保留安全区。核对下一屏存在、顺序正确，标题与主体不被切断，背景连续；四边越界仍须修正。
- 各屏按阅读顺序交付，保留标题、小标签和完整主体。用户需要完整长图时，将同版本、等宽的分屏导出图顺序拼接；不拉伸、不漏屏、不重复，核对背景、文字和主体在接缝处完整。
- 拼接长图不替代分屏 HTML，也不只交首屏。纯图路线交付独立屏图，并按诉求拼接长图，不增加 HTML 要求。

交付出口按 [主入口](../SKILL.md)，保存、展示与宿主执行细节按 [quality.md](quality.md)。
