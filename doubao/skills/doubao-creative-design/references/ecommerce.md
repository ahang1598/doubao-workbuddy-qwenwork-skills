# 电商图片与 Amazon A+ 规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物按[主入口](../SKILL.md)执行适用的数量门禁，不做其他成品检查；长图段图和拼接成品生成后立即交付，不做生成后计数或质量检查。

**目标：** 准确展示商品特征、卖点与活动条件，便于识别商品、理解差异和判断适用情况。

**适用产物：** 商品主图、副图及轮播图片，Amazon A+ 模块素材及约定的整页预览，Banner、店招、促销海报、直播背景、优惠券。连续商品详情页由[主入口](../SKILL.md)分流至 [ecommerce-detail.md](ecommerce-detail.md)，非商业社媒内容另行分流。

**核心流程：** 明确产物与要求 → 组织内容 → 确定视觉方案 → 核对专项要求 → 交付图片

已有明确方案直接沿用，只补充本次任务需要的判断。

## 1. 明确产物与要求

1. **确定产物。** 按平台、展示位置和用途选下表产物。仅说“Amazon 详情页”时，先区分轮播副图、A+ 或两者组合；不凭外文或促销风格推断平台和产物。
2. **查看商品资料。** 核对商品图与已有说明，整理外形、包装、标识、配件及已有卖点。区分实物与概念设计，不凭外观推断品牌、型号、材质、功能或功效；事实和身份要求按 [common.md](common.md)执行。
3. **明确使用要求。** 明确受众和观看条件，沿用已定数量、尺寸、展示顺序、原文与修改范围，不自行增图或增加模块。平台要求优先于品类风格，品类风格优先于通用视觉偏好。

### 产物与规格对照

| 产物 | 适用条件 | 必需内容与组成 | 规格及专属要求 |
|---|---|---|---|
| 国内主图／车图 | 国内商品首张展示 | 必需：完整清晰的商品全貌，商品为视觉中心。保持低密度：1个标题＋最多1–2个极短标签 | 通常1:1，服饰可3:4；居中或非对称摆放。可按需选横幅、角标或服务栏，文字放完整空区并留白 |
| 国内卖点图 | 解释单项特点或结构 | 必需：一个重点及对应部位；结构拆解有真实资料 | 1:1或3:4；可选局部、微距、有依据的透视图，配简洁引导线、核心卖点大字及短说明 |
| 国内场景图 | 展示实际使用环境 | 必需：商品可辨，环境、动作与用途一致 | 1:1或3:4；场景占主要画面，配较疏的描述性标题；可用情绪表达，不遮挡动作与商品细节 |
| Amazon 单品主图 | Amazon 单品首张展示 | 必需：商品全貌，RGB 255,255,255纯白底；保留商品及真实包装自带的Logo、型号、标签 | 通常1:1；商品居中、占画面约85%，边缘清晰无遮挡。不得附加文案、Logo、水印、徽章、营销角标、道具或装饰背景 |
| Amazon 套装主图 | Amazon 套装首张展示 | 必需：沿用单品主图背景及主体要求；主品、包装、配件按真实比例、数量组织 | 仅展示实际售卖内容；不混入另售配件，不用赠品或热卖标签解释套装 |
| Amazon 副图 | 解释卖点、用途、尺寸、清单或差异 | 必需：单张单主题，说明具体客观；信息型卖点图用机制、条件、参数、步骤或清单等具体内容支撑卖点，标题与说明分区安排，不只写口号 | 通常1:1；可选全貌、局部、场景、分组平铺、对齐对比。通常1个明确标题＋2–4条支持，场景可配2–3条说明；禁折扣、购买按钮、促销CTA、营销徽章、夸大承诺及限时、秒杀、立即购买等诱导文案 |
| Amazon A+ | 商品页下方的品牌、功能、场景与对比内容 | 必需：按所选模块配图片、后台标题、正文或原生数据；组成见下表 | 优先沿用已选模块；未指定时按内容及后台可用的Basic／Premium模块选择，不固定数量。禁价格、折扣、倒计时、联系方式、外链、购买按钮、夸大承诺及未经授权的评价 |
| Banner／店招 | 横向活动位、顶部店铺位 | 必需：分清商品区与信息区，主标题、副标、行动文案不超过三个文字层级 | 建议2.35:1；活动横图可16:9，窄条店招可3:1；窄条优先保留关键信息 |
| 促销海报 | 独立活动宣传 | 必需：活动主题、核心利益、商品组及必要条件 | 建议1:1或3:4；有依据的价格或折扣可作最大文字，时间条只写已确认日期 |
| 直播背景 | 直播人物后方展示 | 必需：人物活动净空，四周安排氛围、利益点和互动引导 | 9:16；中央约60%留作人物活动区，文字、漂浮物和图形避开该区并保留显示安全空间；实际平台遮挡另按版位核对 |
| 优惠券 | 展示真实优惠及规则 | 必需：优惠与门槛、规则对应 | 2:1或16:9；左右约60:40，左侧突出优惠，右侧列条件；可用虚线分隔或锯齿边表现券形 |

**规格依据：** 用户提供的实际版位、后台要求及 [platforms.md](platforms.md)。本表“必需”表示题材要求，“通常、约、可、建议”表示设计参考；未经外部核验的库内数值不称现行官方标准。

**共同内容限制：** 主副图均不放具体价格。国内主副图可保留有真实依据的促销氛围、利益标签与服务信息，不因此改列为活动海报。活动价格、折扣、时间及门槛仅在来源真实且平台、载体允许时使用；缺失价格不使用占位符。站外商业图片不必一律写价格或 CTA。

### A+ 模块组成与图文分工

图片比例仅为构图建议，实际尺寸、裁切和文字区域以任务提供的真实后台要求为准。

| 模块 | 模块组成 | 建议图片比例 | 图文分工 |
|---|---|---|---|
| Basic · Standard Company Logo | 品牌识别图 | 10:3 | Logo或品牌识别元素居中，周围留空，不混入活动信息 |
| Basic · Standard Image Header with Text | 大图＋标题与正文 | 97:60 | 图片展示商品整体或品牌环境，标题简短，较长说明放后台正文 |
| Basic · Standard Single Left／Right Image | 左图或右图＋另一侧文字 | 1:1 | 方图说明一个功能、材质或使用特点，客观段落解释同一内容 |
| Basic · Standard Single Image & Sidebar | 竖图＋侧栏说明 | 3:4 | 图片呈现商品或局部，侧栏分组整理补充信息 |
| Basic · Standard 3 Images／4 Images & Text | 3张或4张图片＋对应文字 | 每张1:1 | 各图说明不同重点，下方或旁侧配说明，次序一一对应 |
| Basic · Standard Comparison Table | 后台原生对比表 | 不适用 | 使用后台原生对比表，不制成图片；商品、参数项目、单位和条件准确对应 |
| Premium · Hero Image | 宽幅图及对应简短主张 | 61:25 | 展示商品或品牌场景，不用促销字效挤占主体 |
| Premium · Dual Image with Text | 两张并列图片＋对应说明 | 每张1:1 | 分别呈现细节或场景；状态、效果及条件有事实依据 |
| Premium · Navigation Carousel | 按已选内容组织的轮播项 | 61:25 | 各项分别说明步骤、场景或状态，不将全部步骤挤入一张小图 |

## 2. 组织内容

1. **确定整组分工。** 单张任务只处理当前主题；多张商品图先列读者需要辨认或判断的问题，再分配全貌识别、特点解释、使用场景、尺寸适配与包装清单等职责，按需求取舍，不要求各占一张。每张聚焦一个主题，新增图片应补充尚未讲清的信息；同款不同角度可解释结构，但仅换角度或口号不算新的卖点。沿用确认文案及已知资料，创意表达可在授权内完善，不编造事实、价格、参数与数据，不为补齐职责擅增张数；缺口和锁定项按 [common.md](common.md)处理。
2. **安排展示顺序。** 在平台与已定顺序内，先建立商品识别，再按用户判断需要展开特点、使用与适配信息，不套固定购买链。套装需解释组成时，先全套、后重点单品或局部，不改变售卖组合。远景交代环境、中景展示使用、近景说明细节，握持、按压、倾倒等动作符合真实用途；A+按实际模块及图文分工组织，不套用连续详情页的跨屏结构。
3. **对应图片与文字。** 标题指出本张要说明的问题，支持内容用短句、参数、步骤或清单解释；引导线落到对应部位，不以场景气氛代替功能证据。操作、时间或因果关系用编号，并列卖点不机械编号。

### 按内容选择说明方法

| 内容方法 | 适用条件 | 图文动作 |
|---|---|---|
| 卖点 | 说明一项已知特点 | 选全貌、局部、微距或有依据的结构图；文字解释实现方式、适用对象或条件，引导线指向实际部位 |
| 场景 | 需要解释用途或使用环境 | 商品、人物动作及环境围绕同一用途；在场景空区放标题，说明使用收益、对象或条件 |
| 尺寸参数 | 需要判断尺寸、容量或适配 | 用全貌或局部配尺寸线、比例参照及适配范围；数字、单位、测量部位准确，不从透视图估算参数 |
| 包装清单 | 需要辨明内含物 | 主品与配件平铺或分组，就近标名称、数量、规格或用途；逐项对应实物，不将道具、另售配件列入 |
| 客观对比 | 同系列款式或已知参数有差异 | 按相同项目、单位及条件对齐，图片对应差异文字；不贬低竞品，不虚构认证、评价、测试或其他证据 |

### 补齐 A+ 与活动关系

| 条件 | 内容安排 |
|---|---|
| A+含后台正文 | 图片呈现所讲内容，正文补充功能、使用条件或品牌信息；标题可含品牌短句，正文保持客观具体，不把全部段落压入图片 |
| A+含并列图、侧栏或轮播 | 每张图配对应标题与说明；轮播有操作关系时按步骤排序，无操作关系时按场景或状态分项 |
| 活动展示赠品 | 主品优先，真实赠品可缩小、围绕排布并标明赠送关系；版面大小不得误导真实尺寸，道具及装饰礼盒不得冒充赠品 |
| 活动需要行动引导 | 使用明确行动文案，并与真实活动条件对应；不为“完整成品”强加CTA，不增加虚假交互状态 |

## 3. 确定视觉方案

按第1章产物要求，从下表选择适用的构图、光色、字体和图像表现。保留已确认方向，不要求各表逐项选用，不将全部策略叠加。

### 构图与图文位置

| 构图 | 适用条件 | 可执行表现 |
|---|---|---|
| 左右分栏 | 单品独立图、信息副图、允许图文并置的模块 | 可用5:5或6:4，一侧商品、一侧文字，按主次分配空间，不强行填满 |
| 中心／放射组织 | 单一主品或套装需集中展示 | 商品居中，允许装饰时以线条或元素朝向向外展开；主图仍服从专属限制 |
| 悬浮透视 | 年轻、动感的独立图或模块图 | 可偏转15–45°，用倾斜姿态及合理投影表达；拆件、爆炸结构、运动效果符合真实结构与用途 |
| 阶梯陈列／矩阵 | 系列、套装、多件商品 | 前低后高或错落聚集，保留主品焦点，数量准确 |
| 90°俯拍平铺 | 装备、生活用品、食品组合、清单图 | 沿网格等距或直角排列，清楚区分售卖内容与装饰 |

A+ 后台正文用清晰的黑色或深灰，按模块左对齐或居中；图内短标题与后台说明各有用途，不重复堆叠。

按实际露出范围设计背景，保留已定纹理、材质或场景；纯白主图及已选极简方案按对应要求执行。预留低干扰文字区，结合字色、明暗、纹理与裁切安排位置，空间不足先移字或重排。正文不普遍套描边投影；短摄影标题、漫画大字可按风格使用。不随文字框临时添加灰黑底板、雾带或压暗横带，既定纸签、铭牌、票据仍可承载信息。

需要 CTA 的活动图，可在视线终点用高对比圆角色块及明确文案，按需配箭头或播放符号，只作视觉提示。

### 平台与品类表现

同组图片统一光向、主色、字号层级、标签及说明组件；跨平台先服从各自限制。主光、投影和环境反光相互一致，同时保护商品原色及材质；A+ 商品可用自然光或标准棚拍光。光效写明位置与方向，不因“高端”“动感”自动加光束。

| 平台方向 | 适用重点与表现 |
|---|---|
| 淘宝／京东／拼多多 | 需快速识别商品与利益时，可选棚拍光、较强明暗对比、暖色或高饱和强调；标题可用粗体、描边或立体字 |
| 商业小红书 | 内容化阅读可选低饱和复古色、冷白雾灰及手账排布；手写感文字保持清晰，生活化内容可选Ins或UGC方向 |
| 抖音／快手 | 快速观看场景可选直播灯感、强对比、撞色及大字号，商品与利益清楚分区 |
| 闲鱼 | 优先准确呈现商品状态，说明简明；减少精修及复杂商业排版，实拍可选UGC方向 |

| 商品方向 | 光色与图像动作 | 字体与说明动作 |
|---|---|---|
| 数码／家电 | 硬光、轮廓光突出边缘，深空灰或冷白；微距展示接口、按键、工艺，有结构依据才做透视 | 简洁无衬线或工业黑体，参数单位清楚，装饰不掩盖结构 |
| 美妆／香氛 | 柔和棚拍呈现真实水光、丝绒等质感；浅色低饱和或同色系浓色，按语境选水波、光斑、植物 | 标题与说明层级清楚，可选高端或极简；装饰不暗示不存在的成分、功效 |
| 食品／生鲜 | 暖色、食欲感高光，微距展示真实切面、酥脆或流心状态；飞溅、热气符合食用状态 | 可用活泼粗圆体，口味与规格准确 |
| 服饰／箱包 | 棚拍或街拍自然人像光，结合穿着与局部材质，色调服务衣料、皮面及配色 | 标题克制，尺码、材质清楚，不挡上身效果与工艺 |
| 母婴／亲子 | 柔和漫反射自然光，马卡龙或低饱和大地色，展示实际使用场景 | 可用圆润字体、圆角说明；温和视觉不代替安全、年龄段、材质依据 |
| 运动／户外 | 场景光、广角、高对比深色及荧光强调，展示动作和装备细节 | 力量感黑体、适度倾斜；环境与动作符合用途，不夸大性能 |

### 整体风格与促销方法

| 风格方向 | 适用条件与可执行表现 |
|---|---|
| 高端／高级 | 需克制展示质感时，可选单侧柔和轮廓光、背景适度压暗，深空灰、黑金或冷白；主配色可控制在两种以内，商品居中，允许时留约40%空区；简洁无衬线或明朝体，减少字效。两色和空区比例不是通用要求 |
| Ins／氛围感 | 生活化场景可选午后阳光或柔和漫反射，冷白、雾灰、低饱和冷色；按场景放咖啡、绿植等道具，可用手账拼贴、照片白边、打字机或手写感文字 |
| 大气／宏大 | 需表现空间和体量时，用广角、低角度、开阔远景或大型空间形成对比；可选宽体、窄体工业黑体或飞白标题，不改变商品真实比例 |
| 简约／极简 | 信息少或明确要求克制时，用白底加单色，或指定黑白灰；可用商品与一句核心文案构图，保留约定必需内容；几何无衬线、少装饰，无文案产物不补字 |
| 动感／速度感 | 运动、年轻化主题可用对角线、适度运动或径向模糊、符合情境的粒子；右倾粗体、锐利切角，图文有前后关系，不遮挡结构和字形 |
| UGC／手机实拍 | 需真实生活或商品状态表现时，用手机直拍质感、环境光与生活色温，保留原有使用痕迹；平台允许时可用对话框、弹幕，不虚构用户身份、经历或评价证词 |

需要促销表现时，前三项配色选一组，再按需搭配字效与装饰。数值仅为所选方法参考，不全部叠加；高饱和、景深或字效均须保留商品细节和条件文字。

| 促销方法 | 适用条件与动作 |
|---|---|
| 热烈配色 | 强烈活动氛围可用红橙为主、黑色拉开对比、金黄强调利益；高饱和覆盖可超过90%，不等于塞满物件 |
| 清浅配色 | 需要轻盈背景及集中强调时，用浅灰白或冷调渐变＋15–30%高饱和色；红色集中在文字、飘带或引导区 |
| 暗调配色 | 黑五、数码或高客单价活动可用超过75%的暗背景，黑、深蓝配金色或白字 |
| 利益数字与字效 | 核心数字视觉面积可为辅助文字3–4倍；可选超粗无衬线、右上倾斜5–15°、3D厚度与阴影，海外素材也可居中不倾斜；字形保持准确 |
| 活动装饰 | 按主题选节日元素、飘带、金币、礼盒或碎片，形成有用途的前后层次，避开商品结构及条件文字 |

### 试排与素材准备

1. **确定图文分工。** 按[主入口](../SKILL.md)已选路线落实：完整纯图不强制拆层；可编辑产物区分图片与原生文字。已有 HTML 沿完整源编辑，导出 PNG 不改变路线。输入与文字格式见 [produce-image.md](produce-image.md)，混合分工见 [produce-hybrid.md](produce-hybrid.md)；商品图、轮播与 A+ 不新增 KV 或社媒套图封面批准。
2. **匹配模板与 CSS。** HTML 新建或整体重做时，按商品数量、图文位置、模块比例和已定视觉方向选择对应模板；局部修改只核对受影响项。用实际商品和文案检查是否适合，不凭风格名称直接套用。查询、完整读取及依赖处理按 [templates.md](templates.md) 执行；纯图不因此查询 HTML 模板。
3. **试排完整文案。** 用实际字体、文案和素材比例，在最终观看尺寸下调整图文区域与留白。HTML 试排前读取 [fonts.md](fonts.md)，固定画布与容量按 [produce-code.md](produce-code.md)；放不下先重排，不删锁定文字、全局缩字或隐藏溢出。
4. **准备商品参考。** 真实商品派生须基于真实图编辑，原图杂乱或不适合复用时，可准备白底商品母版；保留原图，不用生成图补替缺失实物参考。明确的概念商品可从零创建母版。母版确认与实际传入按 [common.md](common.md)，不擦除真实包装文字和标识。

## 5. 交付独立图片与 A+ 模块素材

| 交付类别 | 内容与组织 |
|---|---|
| 商品主图、副图及轮播 | 按约定展示顺序交独立成品图片；每张完整可读，不以整套拼图或缩略预览替代 |
| Amazon A+ | 按模块顺序、模块内图片顺序交素材，配对应后台标题、正文；多图模块逐张提供，Navigation Carousel按轮播项提供，Comparison Table交原生数据 |
| Banner、店招、促销海报、直播背景、优惠券 | 按约定版位、尺寸和版本分别交成品，不以一张母图替代所有适配版本 |
| HTML及明确可编辑产物 | 保留完整HTML源及当前源同版本、同尺寸真实预览；指定可编辑文字保持原生节点，不以位图冒充可编辑源 |

1. **核齐数量与顺序。** 对照总数、各版位数量、A+ 模块数、每模块图片数、轮播项顺序及文字对应关系，不增减约定交付。
2. **区分预览与上传资产。** 仅在约定时附 A+ 整页预览；预览用于展示方案，不替代可上传的独立模块素材。未指定不加总览、不拼长图、不新增附件。
3. **保持版本一致。** 完整源、采用素材及真实预览对应同一版本；纯图不承诺位图内部图层可编辑。保存、展示及实际交付出口按 [quality.md](quality.md)执行。
4. **如实说明范围。** 区分已交付、未解决和未验证项；素材准备完成不等于后台上传，没有真实执行证据，不宣称已上传、发布或通过审核。
