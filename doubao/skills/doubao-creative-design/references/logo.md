# Logo 设计规范

适用范围：下文涉及产物检查、验收与修复的条款仅用于代码路线。`pure-image` 产物一返回即交付，段图和最终成品均不做检查。

目标：设计有辨识度、字形清楚、比例协调，并适应实际使用尺寸的 Logo。

适用产物：新建 Logo、授权修改、所需组合与规范页。仅放置已有 Logo 时，不扩展为重设计、完整 VI、IP 或品牌手册。

**核心流程：** 明确品牌与用途 → 提炼概念、选择形式 → 设计图形与字形 → 完善比例、配色与组合 → 验证识别与使用 → 制作交付。

需求与参考遵循[共用规范](common.md)，工具路线与确认遵循[主入口](../SKILL.md)，共用检查与实际交付遵循[质量规范](quality.md)。

## 1 明确品牌与用途

- 用简短信息明确：品牌提供什么、希望被怎样记住、首先用于哪里。优先确定最受限制的场景，如小头像、远视招牌或单色印制。
- 核对准确名称、大小写、空格、标点、重音及中外文关系。名称未知时先澄清，不用占位名或随机英文制作正式候选。
- 已知名称须进入每个候选和标准主标，形成可识别的字标或图文组合；不得缩为角落注释。第二语言、描述语和副标只用已确认文字，不自行增加翻译、年份、城市、域名或注册符号。
- 已有身份直接使用确认母版；仅在授权范围内修改，保护锁定文字、造型和未授权区域。缺少必需原稿时不凭描述重画，风格参考及应用图不作为身份母版。

## 2 提炼概念与选择标志形式

从名称特征、业务动作、产品体验或品牌人格中选一个主要依据，写成一句可画出的概念。将“专业、年轻”等形容词转为具体关系，如连接、包容、转向、聚合，再判断是否符合真实业务。每个候选采用一个主母题，必要时补一个作用明确的辅助母题。

| 标志形式 | 采用条件 | 设计重点 |
| --- | --- | --- |
| 字标 | 名称简短、读音或字符有记忆点；需要优先传播名称 | 从关键字符、重复笔画、字腔或音节节奏建立独特字形 |
| 图文组合 | 需要同时建立名称记忆与独立图形识别 | 图形表达一个核心关系，文字负责准确命名；统一重量和组合轴 |
| 角色／物件组合 | 人物、产品或品牌人格具有真实记忆价值 | 压缩为稳定剪影，与完整名称共同构成主标；角色不是必选项 |
| 徽记 | 强调归属、地域或传统感，主要载体允许较完整结构 | 用外轮廓组织名称与图形，避免靠环绕小字填满空间 |

形式回答“由什么组成”；几何、复古、有机回答“呈现何种气质”；负形、共形等回答“如何构造”。不要混为一张风格清单。

候选应在概念依据或形态结构上真正不同，不能只换色、字体、排版或场景。比较各方向如何压缩语义、形成轮廓和适应小尺寸，不为差异擅换既有身份。参考只提炼构造原则，不复制具体角色、字形、负形或组合。

## 3 设计图形与字形

按品牌气质选择一至两种主要方法，不要求全部叠加，也不要求每个标志都含隐藏图形。先以黑白推敲主体，再处理表面风格。

### 3.1 正负形

适用于两个含义能够自然嵌套，且主体可保留大块连续轮廓的概念。负形是背景留白形成的第二图形，不是两个实心轮廓相似就称为负形。

步骤 1：画出首先要被识别的实体图形，确定外轮廓和深色面积。

步骤 2：从内部或交界处切出留白，使背景形成第二图形；通过位置、开口和面积区分主次。

步骤 3：缩到实际使用尺寸，再做黑白反转。第二图形仍可辨认，主要图形保持完整。

例如，假设物流标志在连续块面间留出箭头空隙，可同时表达稳定与方向；该例不要求其他品牌采用箭头。

若必须解释才看见第二形，先简化其轮廓；若留白消失，扩大通道；若两形争抢注意力，减弱次形或放弃双义。只为透气设置的孔洞属于结构留白，不必赋予故事。

### 3.2 其他造型方法

| 方法 | 采用条件 | 具体做法与判断 |
| --- | --- | --- |
| 共形／共享轮廓 | 两个对象可共用边界、笔画或转折 | 找出相近的方向和曲率，共用一段轮廓，删去重复边，保留各自关键特征。连接处应自然，两种读法均成立；出现硬拼接或鼓包时调整连接位置。同一段轮廓须同时承担两种识别，仅相邻或连接不算共形；第二图形不一定由背景留白形成 |
| 几何归纳 | 需要稳定、简洁、便于缩放的形态 | 用少量圆弧、直线和块面概括对象，保留关键长宽、缺口和朝向；用局部切口、连接或比例形成差异。转折应顺畅，相似部位采用一致规则；若只剩通用品类图标，重新寻找对象特征，不继续堆几何 |
| 图文融合 | 名称的笔画或字腔可与业务动作、物件相接 | 选择一个关键字符，让图形参与笔画、基线、字腔或外轮廓，其余字符保持稳定。先保证完整拼写，再调连接点和图文重量；若造成误读，退回局部呼应，不强行嵌合 |
| 字形定制 | 名称具有记忆价值，现成字形不能充分表达性格 | 先定字骨架、宽窄和字重，再局部重绘、切开、连接或改变端点；统一字腔、圆角、倾斜和基线。主要变化集中于有意义的字符，其余字符帮助阅读；逐字检查错漏、形近替换和连字误读 |
| 模块重复与节奏 | 名称有重复结构，或概念涉及秩序、协作、连续变化 | 固定基础模块、笔画重量和间隔，通过重复、镜像、错位或共享笔画形成整体；设置一处有意义的变化作为记忆点。字序保持清楚；过于呆板时调整局部疏密，难读时恢复识别笔画 |
| 动势路径 | 概念包含运动、连接、循环或转向 | 确定一条主要路径的起点、方向、转弯和终点，再安排开口、弧度与倾斜；让重心跟随动作，保持阅读方向稳定。速度感不足时调整曲率和疏密；缩小断裂时加粗路径、减少回绕，不靠追加箭头补救 |
| 角色标志化 | 人物、产品或品牌角色具有明确记忆价值 | 先画主剪影，再保留一个关键身份部位、一个表情或动作，最后补最少细节。产品拟人先保留产品特征；缩小时先认出轮廓与名称，再读表情。删除无助识别的毛发、衣褶和道具，避免把插画细节塞入标志 |

### 3.3 按品牌气质完善造型

在选定方法上调整字形和线条，不重新叠加一套无关风格。

| 视觉方向 | 具体做法 |
| --- | --- |
| 理性、清晰 | 统一直曲关系、转角与开口，用局部切角、偏移或连接建立特征；保留可辨字腔，避免每个字符各用一套规则 |
| 柔软、有机 | 保留字骨架，对字干局部膨胀、压缩或连笔，适度改变基线；维持连续圆角和黑白疏密，防止字腔堵塞。集中调整关键字符，不把所有字等量扭曲 |
| 复古角色徽记 | 用胶管曲线、粗轮廓、大留白和少量块面简化角色；字标共享圆角、笔画或色块关系，以真实构造体现时代感，不靠旧化滤镜 |
| 肖像与脚本字 | 将人物压缩为稳定面部剪影与一两个特征，配宽笔画脚本或衬线字；控制连笔、交叉和回环，保留首尾字符辨认特征，减少写实毛发和皱褶 |

角色、图形与字标至少在两项可见特征上呼应，如线重、曲率、端点、倾斜或黑白节奏。刻意对比时，以共同对齐轴、比例或色块维持整体。应用插画保持母版五官与核心剪影，人物、年代和地域故事须有依据。

## 4 完善比例、线条、配色与组合

### 比例与光学校正

- 先看视觉重量，不按外框等高等宽。密实图形可适当缩小，细线图形可放大；名称被压成副标题时，减图形或增字面。
- 眯眼或缩小观察重心，再微调位置。圆弧和尖角可略越出齐线；动势形在目标尺寸下出现视觉偏移时，再调整位置或留白，不机械居中。
- 逐对调整字距，以阅读节奏和整体均衡为准，不追求数值或每处留白相等。斜边之间可收紧，直立密集笔画间可放松；同时平衡字腔与外部间隙。
- 检查横竖粗细与交接黑量。连接处发黑时减薄或挖开，圆字显小时适度外扩。构造线只说明真实几何，不编造黄金比例。

### 线条与描边

按气质选择等线、粗圆、轻线描、手绘或干刷，并统一端点、转角、开口与粗糙尺度。细线适合较大、清晰输出；高频小尺寸优先简洁块面。手绘偏差应有规律，不用锯齿或失真代替风格。

先保证无描边字形可读，再按分离底色、贴纸切边或复古层次的需要选边。轮廓描边最多两层；贴纸边围住完整组合，不逐字包边。描边、白边、影边合计重量不超过字面，已确认属于字标结构的外轮廓除外。描边须属于获准结构或应用变体，不在展示中临时添加。

### 配色选择

颜色依据情绪、差异化、对比和生产条件选择，不将暖色或蓝色机械对应行业。

| 选择 | 设计动作与判断 |
| --- | --- |
| 单色 | 用黑白面积与留白组织层次，适合结构优先、低成本印制或强识别需求 |
| 中性色＋强调色 | 中性色维持整体，小面积强调色标出固定身份部位；避免到处点色 |
| 双色关系 | 以明度差保证分离，以冷暖或邻近色关系调节活力；两色均分时检查重心是否分散 |
| 有限多色 | 按固定对象分配颜色，保持共同明度或饱和度秩序；角色、字标和容器共享色组 |

标准主标通常采用 1–3 色，常规最多 4 色；第四色只用于固定、可命名的小面积身份部位。黑、白、奶油、灰、正式描边、影边、身份容器填色及实际白墨均计色；透明和未施色材料本色不计。无墨透明切边只记应用结构；反白的白色计入该状态，载体底色另记。

渐变默认不进标准母版，可见色相仍计复杂度。超过 4 色仅用于已确认既有多色身份、用户明确保留多色身份，或不可替代的色序及真实类别、组织、文化含义；“活泼”不是理由。例外须明确对象、固定色序、背景和降级方式，验证不超过 3 色的平面简化版及单色、反白，并按约定交付。色值如实定义，不编造专色或未经打样的材料映射。

### 图文组合与背景

横向组合共享视觉中线或基线；上下组合以名称稳定承托；嵌合组合保留关键字符；名称记忆性强时以字标主导。调整图文距离，使二者形成整体，又不粘成难读块面。

双语或双层名称使用共同对齐轴和固定断行，以字号、字重和间距区分先后；次层仍须在目标尺寸可读，不能为等宽强行拉伸。横竖延展改变排布，不重画核心字形。

身份底板须参与轮廓、负形或明确品牌含义，并在单色、小尺寸中成立；否则只是应用承托。标准稿使用干净底色，黑白结构测试分别使用白底黑标、黑底白标，不添加干扰轮廓和负形的纹理。品牌系统展示按品牌气质和版式选择背景，可采用纹理、渐变或摄影；纯色用于突出标志或品牌色，不以标准稿的测试底色代替展示方案。展示背景不并入标准标志。

## 5 验证识别与实际使用

下表的结构调整适用于新建或明确授权的修改。已有 Logo 的适配只改授权部分，保留锁定图形与字形；发现范围外问题时说明，不借美化重做。

先比较黑标白底与白标黑底，再检查彩色、灰阶及实际背景。首轮须提供黑白结构证据；候选测试不等于正式变体。按原尺寸、约四分之一尺寸及真实最小尺寸观察，不能只放大检查。

| 观察项 | 常见问题 | 调整动作 |
| --- | --- | --- |
| 剪影与概念 | 去色后普通、主要对象不明 | 强化关键比例或动作，删除竞争形体 |
| 负形与字腔 | 缩小消失、反白粘连 | 扩大通道与开口，减轻连接黑量 |
| 名称与层级 | 错字、连字误读、名称太弱 | 恢复识别笔画，重排字距，降低图形或次层重量 |
| 描边与细节 | 字腔闭合、多层糊合 | 减层、减纹理、扩大留白；单色反白不依赖彩边或发光 |
| 色彩与背景 | 灰阶混同、复杂底吞没标志 | 调整明度关系，选获准深浅版本，不临时变色加光 |
| 载体适配 | 圆裁切断主体、印刷细线丢失 | 调整放置留白，按实际像素或毫米验证；印刷不以像素代替规格 |

按任务覆盖大标准稿、中等组合及小图标／标签，屏幕小尺寸可参考 16–48 px；同时观察远看识别及真实载体。无法实测的印制条件明确说明。材质 Mockup 只作效果示意，不冒称真实生产案例；多图可展示组合、尺度和应用差异，不强制换身份。

## 6 必要制作与交付

- 按主入口确认唯一母版后再制作正式变体。名称错误、缺失或未确认图形不得用于继续衍生。各正式变体以确认母版文件为实际输入，保持核心轮廓、字形、负形和颜色职责，不凭文字重建。
- 正式单色、反白以母版为实际输入作源图编辑，分别形成白底黑标、黑底白标，不以代码滤镜代替。透明版从确认平面母版确定性去底，不重新生成近似图；保留孔洞及身份底板。
- 横竖组合分别输出；独立图形、缩写标用于头像、封签等受限空间，不替代含名称标准主标。已有独立图形可裁取或编辑分离，没有时不擅删名称造新符号。小尺寸确有糊合才在授权内删次要纹理、从属信息或描边，保留核心剪影、主负形和识别笔画，并说明用途与删减项。
- 普通 Logo HTML 的均匀白底图仅在图片节点用 `multiply`，均匀黑底图仅在图片节点用 `screen`，不作用容器或整页。可靠 Alpha PNG／无底 SVG 直接使用；非均匀底或混合污染须取得透明源或确定性去底。进入 VI 的独立图片层须使用真实 Alpha 图片或无底 SVG，不用混合或同色背景伪装透明。
- 透明资产在白、黑、品牌色及高饱和异色底检查残边、孔洞误删、细线断裂和半透明污染；未通过不得用于后续制作，按[质量规范](quality.md)处理，不加阴影或描边遮盖。
- 核实所用原字体来源及商标使用许可；字体文件、专业源与路径须真实存在。位图不称矢量，自绘或生成位图如实说明；近似初筛不等于商标检索，不保证可注册。
- 按约定实际传递独立图片与文件，不以拼板、内部引用或预览代替。主图只放标志及确认身份文字；理念、色值、网格与标签放规范页。仅要一个主图时不追加系统或手册。

画幅优先服从用户尺寸与实际载体，以下仅为默认建议；候选数量按约定，不计最终文件数。

| 产物 | 默认画幅或范围 |
| --- | --- |
| 标准主标、头像、测试单图 | 1:1；通常含正常展示版与同标志透明 PNG |
| 横向／竖向组合 | 横向 3:1；竖向 4:5，修长排布可用 3:4 |
| 规范页／并列对照 | 1600×1200 px（4:3）；横向对照可用 16:9 |
| 小尺寸、应用展示 | 按真实载体；应用按需选少量业务场景 |
| 完整 Logo 系统 | 按约定包含彩色、单色、反白、透明、所需组合及小尺寸成员 |
