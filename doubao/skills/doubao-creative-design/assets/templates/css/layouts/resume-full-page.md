# 简历全页布局

这些条目只保存整张排版与内容结构；配色、具体字体、纹理和装饰由组合或另选视觉方案提供。每套只有一个布局源，组合引用该源，不复制结构。

选型顺序：用户风格与内容约束 → 检索整页布局的适配风格 → 比较布局及关联组合 → 确定采用范围并冻结 Brief。适配标签与组合关联仅在 [CSS 目录](../catalog.json) 维护，通过 `search`／`describe` 读取；下列“通用”表示结构不绑定固定视觉风格，不表示所有风格同等适配。

实现顺序：读取选中布局的结构和样式节点 → 填入真实内容并应用选定视觉层 → 验排。适配依据不能替代正文中的内容容量、阅读顺序和安全区约束。

- `layout_only`：只取布局的 `main` 与 `style[data-resume-layout]`，再添加选定字体、颜色和质感；中性预览不是正式视觉方案。
- `full_combination`：读取组合及其布局依赖，将布局样式、组合视觉样式、一次且仅一次的主结构组装到最终文档。视觉样式不能单独当整页HTML使用。
- 字号、行距、字距、宽高、列比和净空在布局中维护。主题不得隐式改动这些几何参数；确需适配时明确修改并验排。
- 保留主结构的 `lang`，更换语言时显式调整，避免宿主语言误触发字体变体。素材槽位仍需真实资产；SVG ID多实例复用时统一加前缀。
- 换肤可使用组合的 `--resume-paper/ink/accent/surface/strong/muted/rule/on-accent` 和 `--resume-body-font/serif-font/condensed-font/script-font` 覆盖入口。这些是视觉参数，不是布局默认配色；未覆盖时组合保持原参考值。复杂渐变与多色贴纸须按其对象另选视觉实现，不能认为单一accent覆盖了所有材质。
- 纹理、光晕等绑定明确背景或载体，不施加到事实文本；取消装饰只改变绘制，不移除占位或含事实的祖先节点。字体与素材变化后重新核对内容容量。

## 简历模板共用约束

下列布局的“必须保留”约束实际已有内容的归属与视觉关系，不锁定样本的人名、岗位、机构、年份、数量或文字。新建简历按真实资料增减槽位：没有来源的奖项、技能、百分比、照片或联系方式不从示例复制，也不为填满固定格数补造。用户明确复刻时保留已锁定的布局特征，仍以其真实事实决定内容。

模板是布局与视觉实现源，不是可直接交付的成品。800px 等尺寸仅供试排；正式产物按[当前 HTML 组装流程](../../../../references/workflow/html-assembly.md)落实行内样式、真实字体与素材，并满足现有底部安全区和同尺寸预览协议。本机 local 字体及示例字号不能作为目标环境已加载、可读或获得授权的证据。

统一底线，所有布局和引用它们的组合共用，不给每个组合另建一份：
- **空间有归属**：可变正文与其后续分区使用正常文档流／Grid；头像、曲线、徽章、纸边可以局部定位，但必须有独立占位，不能让正文增长后继续沿用整页固定坐标。新增或调整分区以同栏节间24px、文字与外来装饰12px净空为起点（800px基准等比换算），原有更大间距保留；标题与所属正文、图标与标签不机械套节间距。
- **先填再定稿**：匹配布局后先填全量真实内容并加载实际字体，检查最长姓名／机构、网址、完整技能名和最多条目区。文字、量条、图标、曲线文字与相邻纸张都检查，不能只凭scrollHeight或文字矩形没有重叠判定通过。
- **超量有顺序**：先允许换行和条目自然增高，再调整栏内分配、让下游内容及装饰随所属模块移动；保持原分区关系和可读字级。缩写图标格不直接塞完整名称，改用文字标签排法。不得裁切正文祖先、隐藏事实、整体缩字或只增加一个固定top值。
- **固定纸幅单独验**：未锁定高度时可自然增高；A4等固定尺寸必须按扣除页边距后的实际可用区试排，800px宽A4高约1131.43px。超出时按完整小节／条目移栏或分页，单条过长按段落拆分并标续；锁定页数仍放不下则说明容量冲突。页面变长不算单页A4通过，分页后逐页重验。
- **维护只测独立源**：布局入库或几何修改时跑原文案和长文案两个样本，长样本包含正文增长及新增条目；再对变动的高风险布局抽查长标签／不同字体。组合共享布局结果，只抽样换肤，不穷举所有组合。记录碰撞、越界和固定纸幅容量，发现具体问题才修改对应源规则。

## 信息双栏 · 左疏右密

风格标签：通用。

产物：简历／个人履历／作品集介绍页；范围：整张单屏。基准宽800px，高度沿源模板最小高度与内容适配，不是社媒长图布局。

必须保留：
- 双栏模式下左身份、右履历，共用纸张内容区顶线；基准两栏宽度与栏距合计690px，对应纸张扣除左右内边距后的宽度。
- 职业标题保持在身份信息之前；成果概览位于联系方式之后、肖像之前，不改变真实成果事实的对应关系，项目数量按资料调整。
- 成果概览保留首行左项、次行左右两项的空间组织；主题切换不得擅自重排。
- 肖像维持竖幅内容框并位于左栏下部；箭头是否可见不能改变肖像位置或引导留白的结构作用。
- 右栏分节顺序固定为关于我、工作、奖项、技能；各条机构或奖项名称与其日期、说明保持关联。
- 双栏内容未超出基准高度时，肖像和技能区接近各自栏底；内容增长时允许整体增高，不以重叠强行维持底部位置。
- 保留真实资料中已有的技能及其语义，样本槽位数量按资料调整；无事实的示例槽位应移除，不将已有事实误判为装饰。

内容适配：
- 正文增加时让条目、分区与纸张自然增高；保留最小高度而非锁死总高度，不截断描述、不省略日期，也不对事实容器使用display:none。
- 姓名、学校、邮箱或职业标题变长时，先验证现有折行，再调整可用栏宽和布局间距；长邮箱需允许安全断行，不能依靠溢出或裁切。
- 机构名或奖项名增长时保持与日期的归属；空间不足可将日期移至同一条目内下一行，避免不可换行日期挤压名称至不可读。
- 字体家族更换后重新测量中英文标题、数字和正文；字号、行高、字距属于独立布局参数，应显式调整并回归验证，不能作为主题切换的隐含变化。
- 窄画幅下先收敛纸张宽度和外侧留白，双栏不再可读时改为按DOM顺序的单栏；同步调整.photo-lead留白与.skills-section底部吸附策略，保留肖像和全部技能。
- 技能区不足以容纳实际技能图标时改为多行网格，保持真实技能顺序和对应槽位；肖像按竖幅比例适配，确保人物主体不被不合理裁切。
- 打印画幅或文案超过单页容量时允许分页，优先保持标题与后续内容、条目名称与说明相邻，不通过极端缩字或隐藏事实强塞单页。


三类净空：页面内边距、卡片／回转轮廓的文字可用区、图窗主体及相邻文字区域，均由源布局维护；替换内容、字体或图片后重新验排。装饰取消不改变内容归属和阅读顺序。

读取本条目的两个模板节点：`main`为唯一主结构，`style[data-resume-layout]`为布局CSS。填入内容并添加所选视觉层后才形成交付页面；不能把灰色占位或缺图状态称为组合成品。具体字体不由布局绑定，保留字号／行高／字距约束。

此条目不复制原配色、字体文件或参考人物；已有对应组合为 `combination.resume-01`，采用其完整视觉时由组合单向依赖本布局，避免循环读取。
