# Brochure & Booklet Layouts

用途：三折页、其他折页及画册的可复用布局。风格通用，视觉网格不等于物理折面；折法、面序、纸面尺寸与出血由品类 Spec 决定。每个展开采用一个整体骨架，局部模块嵌入对应区域；可交叉绑定字体、配色与材质，不机械继承示例主题。

按稳定布局 ID 经脚本读取所需段落。每节 CSS 与 HTML 配套，无必需外部 CSS；来源组合不作为读取布局的依赖。正式交付按现有协议展开行内样式，示例图片替换为就绪资产。固定印刷尺寸由外层锁定，内部自然排版后检查完整文字、图片与折线安全区；超量重新分配内容，不拉高纸面或隐藏正文。参数为试排起点，不保证任意文字量自动适配。图窗裁切只作用于图片，背景与正文不继承裁切或透明度。

## 跨区分栏布局

风格标签：通用。产物标签：三折页、折页、画册。布局范围：整张单屏。

替换已有实现。维持背景与内容分层，增加独立图像背景、共享嵌套场域和面内角色节点；普通网格本身无法表达不随正文列改变的背景矩形，但圆图、交替图文和封面左右区不需要另立原子。

参数：--bz-columns控制整体视觉列；--bz-gap、--bz-inset、--bz-space控制间距；子节点--bz-column、--bz-row控制真实网格占位；背景--bz-region控制矩形范围；--bz-field-columns控制共享场域主次；--bz-pair-columns控制局部图文比；--bz-image-height默认auto，--bz-image-ratio默认auto；--bz-fit、--bz-focus、--bz-clip、--bz-radius分别控制取景和仅图片裁切；--bz-cover-columns、--bz-cover-mode控制封面竖题与纵景；所有paint、ink由实例绑定。

约束：背景可绝对定位，文字不得绝对定位。区域图片依赖内容或外层尺寸获得高度；如需满高须依据实测画幅指定区域，不设置通用大高度。圆图只允许在已核验的非人脸区交叠。背景矩形按spec和实际文案校核；茶园产品节点需同时加载本输出的局部跨缘原子。 图片背景由独立区域容器承接inset，内部img填满该区域；不能把带inset偏移的img仍设为整页100%宽高。

## 错层图窗布局

风格标签：通用。产物标签：三折页、折页、画册。布局范围：整张单屏。

替换已有固定中栏实现。将跨界图窗做成完整展开内可迁移的列角色，以图窗真实高度减去cross确定背景分界，不通过位移图像再补假空白；共同题注和页脚始终属于展开根网格。

参数：--bw-columns控制三视觉列比例；--bw-cross-column和--bw-cross-cell控制同一跨界列，须一致；--bw-image-height控制跨界图窗高度；--bw-cross控制图窗越过背景分界的深度；--bw-caption-column、--bw-caption-row和--bw-footer-column控制共同信息行；--bw-body-row控制正文行；--bw-inset、--bw-gap控制净距；--bw-before、--bw-after控制分界两侧背景；图片--bw-clip、--bw-focus、--bw-fit可逐项覆盖。

约束：--bw-cross必须大于0且小于--bw-image-height；图片需同时跨越分界上下两侧。分界从跨界列实际顶部内容及图窗高度推导，不固定全文高度。独立列背景与共同题注颜色须配套。跨界列、相邻列及页脚不得重复占用同一内容单元。
