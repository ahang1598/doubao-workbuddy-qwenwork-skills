# 折页完整展开布局

当用户明确选用或候选比较后采用完整展开时，先读取该布局，再按需要取面；不以通用三栏替代已选核心关系。原创和仅借局部的任务仍按品类流程选择，不强制套用完整模板。配色、字体与质感在组合视觉层，图窗、分区、字级、行距、切角、叠压和节点位置在本布局源中维护。

- `full_combination`：组合主题 + 必需布局 CSS + 一次主结构；原配色下应与组合基准一致。
- `layout_only`：采用同一布局 CSS 和主结构，选择视觉参数。中性回退只用于排版检查，不是正式配色。
- 配色覆盖入口：`--fold-paper/ink/accent/tint/surface/muted`。组合的 `--fold-tone-*` 保留原色细分；未覆盖时保留参考值。字体入口 `--fold-font-*` 的具体 family 在组合主题中定义；字号、行距、字距不随主题隐式变化。
- 图像必须绑定 `data-asset-slot`；`data-fold-image` 区分同素材的不同图窗实例，不得按素材角色合并节点。参考裁片、人物、品牌及联系方式只用于验证，不随库分发，正式采用须换成获准素材与真实内容。
- 源坐标以900px展开为基准，图文槽位有固定容量。更换字体、长文案或图片后重查溢出、遮挡与完整语义。换印刷尺寸先按同一比例适配并核验，不能为了套默认折面而改变已选关系。
- 视觉分区不等于物理折面。四区展开为四视觉栏；竖题图文为六个独立面组。折法、面序、安全区和出血依品类Spec确认，不能据参考展示图自动认定。
- 原子提取验收：先对照原图确认组合关系，再核对提取前后像素与元素几何；只有新样张的可读性检查，不能证明参考还原。

## 共用采用边界

### 布局与内容解耦

布局只约束素材槽的边界、比例、裁切、文字净空、对齐、跨区与叠放关系，不限定山水、茶园、人物、商品等题材，也不固定行业文案、色相或书法字体。具体图像内容、字形、配色与材质由所选组合／本次Brief绑定。

- 满版背景槽：覆盖所属整面或连续跨面区域，保留安全裁切与文字净空；不能拆成多个独立图卡。背景可用任何符合取景和净空要求的素材。
- 局部图窗槽：保留原图窗边界、比例和取景保护；不能因“背景解耦”擅自扩大为满版。
- 前景主体槽：保留跨边方向与遮挡层级；主体题材可替换，素材需有适合叠放的边缘。
- 文字与信息组：只固定角色、位置和容量关系；样本的工艺、会议、产品、服务等内容不是必选模块。真实文案超量时调整分配并重验。

既有文件名、CSS类和data-asset-slot中tea/botanical/care等是定位标识，不是题材约束；不凭名称生成素材。模板内文字为参考试排内容，采用时整体绑定真实文案。保持原槽ID与几何，组合层才决定具体画什么。历史参考对照只说明原实例，不证明任意换图后仍合格。


本文件“验证通过”“像素差为 0”等描述是来源版本的历史记录，本次同步未重新渲染原参考对照，不能当作新任务验收。下列“必须保留”指已选方案的布局关系与用户锁定项，样本人名、品牌、活动、照片数量、联系方式和文字不作为新任务事实。按真实资料绑定槽位；来源不足不补造，局部改字不更新无关素材或整页。

布局和主题源是组装片段，正式交付沿用[当前组装协议](../../../../references/workflow/html-assembly.md)，落实真实字体／资产、行内样式、底部安全区和同尺寸预览。固定印刷纸幅、折法、物理面序与出血按品类规则，不能按展示坐标推断；内容超量时按授权重排或重新分配，不擅改事实、裁断字词或移动折线。仅取面时，裁切是明确的视图用途，不得掩盖被截断的标题或正文。

母版非900px宽时显式改`.fold-panel-canvas`宽度，并同步更新视窗坐标，不能只缩放文字。来源版本记录 26 个具名视图的节点几何与母版一致，本次未复跑该记录；裁切栅格化有少量色阶／抗锯齿差异；换内容、字体、面宽后重新检验字词完整性。
