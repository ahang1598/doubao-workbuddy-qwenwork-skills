# 材质、纹理与配色共用规则

类型：共用实现与参数；按稳定 ID 读取，非独立成品或风格预设。

- 来源：本地旧版 doubao-creative-design 1.0.43 的 materials.md、palettes.md、recipes.md；保留参数、CSS、JSON，仅调整发布路径与读取说明，不恢复旧目录或旧版全局执行约束。
- 采用边界：任务确定形状、准确内容与实际配色；恢复依赖不等于通过目标环境渲染和视觉验收。骨架见[文件夹轮廓](容器/容器-文件夹轮廓.html)、[圆角容器](容器/容器-圆角容器.md)。

## 表面参数与材质默认值

并列变量的默认值、范围按列内顺序对应。

| 参数 | 实现默认值 | 范围／用途 |
|---|---|---|
| `--vl-grain` | `.14` | [0, 0.85]；纹理强度，0 关闭 |
| `--vl-texture-size` | `192px` | ['96px', '384px']；平铺越大，颗粒越粗 |
| `--vl-alpha` / `--vl-blur` | `.72` / `8px` | [0, 1] 表面不透明度／非负 px 背景模糊 |
| `--vl-highlight` / `--vl-edge` / `--vl-shadow` | `.5` / `.88` / `0` | 均 [0, 1]；材质光照／亮边／外投影强度 |
| `--vl-texture-blend` | `soft-light` | ['soft-light', 'multiply']；随材质成组复制，非通用换肤开关 |
| `--vl-texture-size-x` / `--vl-texture-size-y` | `var(--vl-texture-size)` / `var(--vl-texture-size)` | 横／纵向平铺尺寸，默认跟随统一尺寸 |
| `--vl-texture-x` / `--vl-texture-y` | `0px` / `0px` | 纹理横／纵向偏移 |
| `--vl-light-angle` / `--vl-light-width` | `112deg` / `36%` | 塑料、玻璃主高光方向／宽度；宽度建议 12%–70% |
| `--vl-light-softness` | `0px` | 光层模糊半径 |
| `--vl-light-x` / `--vl-light-y` | `20%` / `10%` | 纸张径向光源横／纵向位置 |
| `--vl-shadow-x` / `--vl-shadow-y` | `0px` / `2px` | 外投影横／纵向偏移 |
| `--vl-shadow-blur` / `--vl-shadow-spread` | `5px` / `0px` | 同一外投影的模糊／扩散；前者非负，后者可负，与偏移共同控制 |

表面参数不降低正文不透明度，也不模糊文字。形状及纸张、塑料、玻璃均不自动启用外投影；仅真实叠纸接触或实体悬浮时，按光向、尺度、接触距离和背景设置，不以大面积黑色渐变作通用底影。纸纤维、印刷颗粒不意味着悬浮；厚度用的内高光／内阴影与外投影分控；图像已烘焙阴影时不重复投影。

| 材质 | alpha | blur | grain（轻／强） | texture-size | highlight | edge | shadow |
|---|---|---|---|---|---|---|---|
| 塑料 | .72 | 8px | .14／.36 | 192px | .60 | .96 | 0 |
| 玻璃 | .24 | 18px | .18／.48 | 176px | .40 | .95 | 0 |
| 纸张 | .97 | 0px | .36／.70 | 256px | .16 | .45 | 0 |

调整示例：玻璃减轻，在根节点设 `--vl-grain:.12; --vl-blur:12px`；细纹拉长，设 `--vl-texture-size-x:160px; --vl-texture-size-y:280px`。参数改变叠加强度、平铺尺度及纤维外观，不改变 SVG 纤维数量。

## 独立背景的共用纹理层

用于无文件夹或卡片骨架的页面／纸片背景。纸纤维与屏幕颗粒共用本层，仅覆盖纹理资源；grain、texture-size、texture-blend 沿用上表。

```css
.vl-texture-field { position:relative; isolation:isolate; background:var(--vl-tint,transparent); color:var(--vl-ink,#302a20); }
.vl-texture-field__texture { position:absolute; inset:0; z-index:-1; pointer-events:none; border-radius:inherit; background-image:var(--vl-texture,none); background-size:var(--vl-texture-size-x,var(--vl-texture-size,256px)) var(--vl-texture-size-y,var(--vl-texture-size,256px)); background-position:var(--vl-texture-x,0px) var(--vl-texture-y,0px); opacity:var(--vl-grain,.12); mix-blend-mode:var(--vl-texture-blend,multiply); }
```

```html
<section class="vl-texture-field" style="--vl-texture:url('asset:svg/paper-fiber.svg');--vl-grain:.12"><span class="vl-texture-field__texture" aria-hidden="true"></span><h2>正文保持清晰</h2></section>
```

纹理 span 与内容分层；同时使用 CSS 光场时另留光层节点，由 HTML 指定两层顺序。照片已有纹理时不重复覆盖。

纹理与底色独立：本层未传 `--vl-tint` 时透明，覆盖已规划的下层表面；不透明纸面须显式传入表面色及配套文字色。纸纤维、颗粒或纸张名称不自动指定米色。

## 配色角色参数

| 参数 | 实现默认值 | 角色／限制 |
|---|---|---|
| `--vl-hue` | `184` | 色相，通常 0–360 |
| `--vl-tint` | `hsl(var(--vl-hue) 87% 91%)` | 表面底色 |
| `--vl-ink` | `hsl(var(--vl-hue) 70% 19%)` | 正文色 |
| `--vl-accent` | `#ffdf53` | 主强调色；文件夹背页读取 |
| `--vl-accent-2` / `--vl-accent-3` | `var(--vl-accent)` / `var(--vl-accent)` | 第二／第三强调色；仅供显式绑定的色块、装饰，不自动添加色块 |
| `--vl-surface-end` | `hsl(var(--vl-hue) 82% 91%)` | 塑料、玻璃渐变末端；纸张仅用 tint |
| `--vl-muted-ink` | `var(--vl-ink)` | 次级正文色，与 body-opacity 共同决定结果 |
| `--vl-edge-color` / `--vl-light-color` | `#fff` / `#fff` | 亮边／主高光色；文件夹亮边渐变末端沿用色相 |
| `--vl-shadow-color` | `hsl(var(--vl-hue) 80% 25%)` | 底部环境投影色，不替代材质内部阴影 |
| `--vl-label-bg` / `--vl-label-ink` | `hsl(var(--vl-hue) 66% 48% / .82)` / `#fff` | 标签底色／文字色 |

默认色仅补齐组件角色，不是整页背景或风格推荐：先依用户参考、品牌、主体、主题确定色板；不得因“高级、自然、留白”自动选奶油／暖纸色作全页底色。背景空间、色场、纹理由视觉设定另定；材质预设纸色在本文件维护，纹理与滤镜在 surfaces 维护。
