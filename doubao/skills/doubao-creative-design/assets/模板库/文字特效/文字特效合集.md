# 特效-文字描边

类型：规则与配方。本条没有独立 HTML 成品。

稳定 ID：`text.outline`。

<a id="text.outline"></a>

## 特效-文字描边

风格标签：通用。

补齐活动粗字、球面徽章字面与彩色标题轮廓。描边、填字和挤出分别启用。

| 参数 | 默认值 | 作用与限制 |
|---|---|---|
| `--vl-text-stroke-width` | `1px` | 字形轮廓宽度，建议 .5–2px |
| `--vl-text-stroke-color` | `#c4f5ff` | 轮廓颜色 |

```css
.vl-text-outline { -webkit-text-stroke:var(--vl-text-stroke-width,1px) var(--vl-text-stroke-color,#c4f5ff); paint-order:stroke fill; }
```

```html
<h2 class="vl-text-outline" style="color:#1678c0;--vl-text-stroke-width:1px">轮廓清晰</h2>
```

薄描边保持字腔，小字号需要减小宽度。图中定制字形、弯曲变形不由描边自动产生；字体仍通过原字体规则选取。此实现使用目标浏览器的 text-stroke，不添加兼容分支。
# 特效-渐变与纹理填字

类型：规则与配方。本条没有独立 HTML 成品。

稳定 ID：`text.paint`。

<a id="text.paint"></a>

## 特效-渐变与纹理填字

风格标签：通用。

对应金色标题、蓝色活动标题与印刷字面；复用通用 paint 或纹理短引用，保留真实文字节点。

| 参数 | 默认值 | 作用与限制 |
|---|---|---|
| `--vl-text-fill` | `var(--vl-paint,none)` | 渐变、纹理 URL 或 CSS 多层背景列表；使用前必须提供有效 paint 或 fill |
| `--vl-text-fill-size` | `100% 100%` | 渐变通常 100% 100%；纸纹可设 192px 192px |
| `--vl-text-fill-position` | `50% 50%` | 填充图案位置 |

```css
.vl-text-paint { color:transparent; background-image:var(--vl-text-fill,var(--vl-paint,none)); background-size:var(--vl-text-fill-size,100% 100%); background-position:var(--vl-text-fill-position,50% 50%); background-clip:text; }
```

```html
<h2 class="vl-gradient--linear vl-text-paint" style="--vl-gradient-stops:#e0faff 0%,#4dc9ff 45%,#176bbe 100%">蓝色渐变标题</h2>
```

依赖 [通用渐变](../配色/配色-通用渐变与逐色标透明度.html)，或者显式提供短引用作为 text-fill。纸纹图片有透明区域时可在同一 fill 列表后叠加纯色渐变底层，防止文字主体变稀。SVG 内部纹理强度需要改资源，单个背景图层没有独立 CSS opacity；需要动态独立强度时使用两层同字节点并只调装饰层。不要直接把整块玻璃卡片样式加到文字上。
# 特效-网点与点阵字

类型：规则与配方。本条没有独立 HTML 成品。

稳定 ID：`surface.dot-pattern`。

<a id="surface.dot-pattern"></a>

## 特效-网点与点阵字

风格标签：通用。

参考演唱会战报的大字点阵。相同径向点阵可应用于装饰色块或文字裁切；字形仍由真实字体决定。

| 参数 | 默认值 | 作用与调整 |
|---|---|---|
| `--vl-dot-step` | `5px` | 点阵间距，建议 3–8px |
| `--vl-dot-radius` | `1.4px` | 点半径，应小于 step/2 |
| `--vl-dot-color` | `#e5ffff` | 点色 |
| `--vl-dot-alpha` | `1` | 点色透明度；背景印刷通常 .08–.25，点阵字通常 1 |

```css
.vl-dot-pattern { background-image:radial-gradient(circle,color-mix(in srgb,var(--vl-dot-color,#e5ffff) calc(var(--vl-dot-alpha,1) * 100%),transparent) var(--vl-dot-radius,1.4px),transparent calc(var(--vl-dot-radius,1.4px) + .3px)); background-size:var(--vl-dot-step,5px) var(--vl-dot-step,5px); }
.vl-dot-pattern--text { color:transparent; background-clip:text; }
```

```html
<h2 class="vl-dot-pattern vl-dot-pattern--text" style="font-size:96px;font-weight:900;--vl-dot-step:4px;--vl-dot-radius:1.4px">演出</h2>
```

点阵字只用于大字，正文不使用；最终字号小于约 48px 时优先保留完整字形。实体字的光晕由独立文字发光层或素材提供，不用阴影把点阵孔隙填平。背景网点放独立装饰层以免影响正文清晰度。
# 特效-贴布缝线字

类型：规则与配方。本条没有独立 HTML 成品。

稳定 ID：`surface.applique`。

<a id="surface.applique"></a>
## 特效-贴布缝线字

风格标签：通用。机制：织物编织；适用对象：text。

真实SVG文字轮廓描边＋虚线针脚＋粗糙外缘＋字形内侧微阴影（偏移0.8px、模糊0.55px、透明度0.22；600px画布）＋松线，非矩形缝线框。字符保持可编辑；粗绒、逐根毛线和精密刺绣为近似。

```bash
python3 scripts/make-craft-texture.py applique /任务目录/applique.svg --width 600 --height 360 --color '#87b2d0' --base '#f8f1df' --weight 700
```

HTML 绑定（文件在任务中复制／内嵌，路径按任务调整）：

此项为按参数生成的资源规则。先运行上述生成器取得实际 SVG，再内嵌到目标作品；不提供缺少实际效果的独立 HTML 示例。

检查：在最终输出尺寸观察字腔是否堵塞、针脚是否沿字形、字体是否实际加载。不存在引用图片即自动完成材质的判定。


## 布艺拼贴字体组合

以下为参考图启发的可用搭配，非原字形鉴定。拉丁字选 **Arial 700**（预览实际使用；轮廓较规整），中文选 **Source Han Sans 900**，任务中先验证字体文件加载。需要参考中摇摆、膨胀的字形时须单独调整字形，不能声称换色后已复刻。描边8px、针脚2px／3px虚线在600px示例画布上定义，随SVG等比缩放；标题建议最终不小于36px。投影仅保留字形内部窄边，不向下外扩；针脚层位于内阴影上方。四组共用applique与gingham，不复制纹理实现。
