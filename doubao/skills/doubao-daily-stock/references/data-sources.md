## 数据来源

- 用 `seed_finance_lookup` 获取证券身份、行情、财务、资金、板块、技术指标和一致预期等结构化数据。取数时核对证券代码、市场、日期/时间、单位和复权口径。
- 取数完成后按 [数据契约](data-contract.md) 记录字段、时间口径及可打开的来源链接。缺失、可疑或口径不明的字段留空，表格和指标卡写 `暂无`。
- 当前版本不获取 1 分钟级行情、30 个交易日日线 OHLCV 或 90 个交易日行情，也不生成 K 线图和 `window.RECAP_CHART_DATA`。

## 新闻、公告和研报来源

1. `seed_finance_search`：优先用于检索交易所公告、公司公告、官方 IR、监管披露、权威财经媒体、产业媒体和新闻原文；不可用时用 `general_search`。
2. 交易所、公司公告、官方 IR、监管披露。
3. 权威财经媒体与产业媒体：财新、彭博、路透、证券时报、上海证券报、中国证券报、证券日报、财联社、第一财经、21世纪经济报道、Reuters、Bloomberg、CNBC，以及对应产业的专业媒体/研究机构。
4. 不采用：雪球、股吧、贴吧、微信群截图、自媒体小作文，除非只作为“市场传闻”并明确不可核验，通常不要写入报告事实。
5. 证券时报数据宝、东方财富 Choice 等“成交额/大宗交易/资金流”类短讯只可作为第一部分交易结构素材，不得充当第四部分消息面主来源。

## A 股结构化数据

### 1. 股票识别

用 `seed_finance_lookup` 的证券识别或合约元数据确认股票名称、代码、交易所和币种。

### 2. 今日实时/收盘行情

使用 `seed_finance_lookup` 的实时行情或收盘快照。

需要字段：

- 最新价/收盘价、涨跌幅、开盘、最高、最低、成交量、成交额、总市值、PE TTM、换手率、量比。

如果接口只返回部分字段：

- 日内区间用最高/最低拼接。
- 成交额从接口直接取，无法取时用成交量和 VWAP 近似但必须在内部数据核验记录和口径说明中标注。
- PE TTM 缺失时用总市值/TTM归母净利润估算，缺 TTM 利润则表格或指标卡内写 `暂无`。

摘要指标核验：

- 当前价格/收盘价、涨跌幅、日内区间、总市值、市盈率 TTM、成交额、换手率、量比必须记录 `data_as_of`。
- 非交易日请求时，用最近有效交易日收盘数据；交易日盘中请求时，以请求时点之前可获得的最新快照数据为准。

### 3. 技术指标、量比和关键价位

- MA、MACD、RSI 和量比采用 `seed_finance_lookup` 返回值，记录来源链接和时间口径。
- 压力位、支撑位和震荡区间采用 `seed_finance_lookup` 返回值、明确引用的研报或公告观点，或按公式计算。自行计算须引用输入数据来源。
- 指标缺失时，表格单元格写 `暂无`，正文可简短说明数据缺口。

### 4. 资金流

A 股使用 `seed_finance_lookup` 的资金流或成交结构字段，包括主力资金、北向资金、大单资金或大单成交占比。

失败兜底：

- 主力资金无法取到时，资金流表格对应单元格写 `暂无`，或用可核验的大单成交占比/主动买卖盘替代。
- 不能随意编造净流入金额。

非 A 股处理：

- 港股、美股及其他非 A 股不生成 A 股资金流表，不硬套主力资金、北向资金、大单资金三行结构。
- 港股可用南向资金、成交额/成交量、换手、异常大宗交易等可核验交易线索。
- 美股可用成交量相对均量、盘前/盘后表现、期权成交/隐含波动率、ETF 流向、机构持仓变化等可核验交易线索。
- 非 A 股交易线索写入第一部分“价格与量能”文字分析；无可信来源时写“未见可核验的异常资金交易信号”。

### 5. 板块数据

使用 `seed_finance_lookup` 的行业和概念板块字段。

输出：

- 主行业涨跌幅。
- 核心概念板块涨跌幅。
- 板块上涨/下跌家数。
- 个股相对板块强弱。

### 6. 技术指标

使用 `seed_finance_lookup` 返回的技术指标：

- MA5/10/20/60：采用来源披露值；若来源未披露 MA60，表格内写 `暂无`。
- MACD：采用来源披露的 DIF/DEA/MACD 柱体或等价口径；来源必须说明参数或使用平台默认参数。
- RSI：优先 RSI14；若来源使用其他参数，必须说明。

## 消息和公告

优先：

- 巨潮资讯、上交所、深交所、港交所、SEC EDGAR、公司公告。
- 公司官网投资者关系。
- 财联社、证券时报、上海证券报、中国证券报、第一财经、财新、彭博、路透等权威媒体。
- 行业产业链用公司 IR、产业媒体和权威研究机构。

要求：

- 每条消息保留日期、来源、标题/摘要、原文链接、影响判断。
- 最近 3 日内的信息优先；太早的信息一般不进入每日复盘，除非用户明确追问或事件仍在发酵。
- 文末“信息来源”列出正文和表格实际引用的可打开原始外部来源，包括公告、新闻、产品、业绩、产业趋势、研报/一致预期，以及行情摘要、资金流、板块行情、技术指标、PE TTM、量比等数据来源。不得列内部核验记录、本地 txt、本地材料包或中间文件。

## 投行一致预期

用 `seed_finance_lookup` 查一致预期字段。研报原文用 `seed_finance_search` 检索，不可用时用 `general_search`。

计算兜底：

- PE = 当前价格 / EPS。
- EPS = 归母净利润 / 总股本。
- 营收缺失不可臆造，表格内写 `暂无`。

说明：

- 不要把 EPS 估算出的净利润伪装成数据库直接披露值。
- A 股或披露完整盈利预测的数据源，表格可使用 `年份 / 归母净利润 / 营业总收入 / 每股收益 / 市盈率`。
- 港股、美股或主要披露券商评级/目标价的数据源，表格改用 `机构名称 / 最新评级 / 目标价 / 日期`，展示最近约 5 家机构，优先选择日期最新且来源可打开的记录。
- 投行一致预期表格下方必须写简短口径说明，例如“口径说明：A 股一致预期采用 `seed_finance_lookup` 返回值，缺失字段写暂无。自行计算项列明公式与输入来源。”或“口径说明：港股/美股一致预期以近期可核验券商评级与目标价为主，展示最近约 5 家机构记录；目标价币种按原始来源列示。”
- 若没有可核验的机构覆盖、盈利预测、评级或目标价，不得输出全是 `暂无` / `未披露` 的投行一致预期表，也不得把公司公告、IR 或资讯聚合页伪装成投行覆盖。该节保留标题，正文说明暂无覆盖，并分析机会与风险：机会包括关注度低、预期发现、估值重估；风险包括外部跟踪不足、估值锚弱、信息透明度和流动性不确定。
- 不要把无法打开的接口地址作为“信息来源”来源行；必须尽量使用可打开的数据页、公告页、媒体原文、研报页或平台行情页。若只有接口且无法打开核验，该字段不得进入报告。

## 港股/美股差异

港股：

- 公告原文可引用港交所披露或公司公告。
- 北向资金不适用，可用南向资金。
- 币种通常为港币，市值和预测需要统一币种。

美股：

- 披露原文可引用交易所、SEC EDGAR 或公司 IR。
- 没有主力资金/北向资金口径时，不要硬套 A股资金流；可改为成交量、期权、机构持仓、ETF流向、盘前盘后表现。

## 本项目踩过的坑

- 数据抓错日期：先判断 `report_request_time` 和最近有效交易日，再取行情；周末、节假日、停牌时要向前推。
- 技术指标口径：记录 MA/MACD/RSI、量比的来源、时间、参数和复权方式。
- 数据无链接：缺少可打开来源链接的数值按缺失处理。
- 来源角标遗漏：当前价、PE TTM、量比、资金流、MA/MACD/RSI、投行一致预期等数据都必须在正文/表格中有角标，并在“信息来源”中有对应“打开原文”。
- 新闻不要用小作文：没有权威来源时宁可写“暂未检索到权威消息”，不要引用股吧/雪球传闻。
- 投行一致预期可能缺字段：可以计算 EPS/PE，但必须标注估算口径。
