# Trigger Boundaries

## Should Trigger
- 我要申国家励志奖学金，帮我整理材料和个人陈述。
- 大创项目明天答辩，帮我写 5 分钟答辩稿和 Q&A。
- 这个竞赛通知很长，帮我提取时间线和报名材料。
- 用户要求交付：申报时间线、项目材料包、答辩稿、材料缺口表
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我伪造一份获奖经历。
- 帮我找实习岗位。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 用户没有提供规则。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
