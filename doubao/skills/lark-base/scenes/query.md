# 查询与计算

## 任务导航与计算模式

| 任务 | 路径与边界 |
|---|---|
| 普通结构、记录查询 | 表与字段读对应模块；已知记录、原始记录筛选、排序、Top/Bottom N 交 [Record](record.md#读取与完整分页)，不用 SQL |
| 独立分析问答 | 接收 Analyze-data 的问题与口径，走 Context → SQL → 查询核验（计数、求和、均值、分组、聚合 TopN、趋势、对比、多表）；简单或数据少不是改用 DSL 或本地计算的理由 |
| 对象搭建、维护、写后辅助计算 | 原对象流程内按能力选 DSL、SQL 或允许的程序计算，不必先让 SQL 失败；已有图表按 Dashboard 实际配置和结果验收 |
| 混合任务 | 两类路径分别执行，共享指标一致；查询不授权写入或新建字段、表、View、Dashboard，不代替对象回读 |

“金额最大的 10 条订单”是记录排序，“销售额最高的 10 个客户”先按客户聚合再排名。独立分析未定口径先按 Analyze-data 定，已定则复用，不循环加载。取 Context、写 SQL 前读 [SQL 契约](../references/query-sql.md)，用 DSL 才读 [DSL 契约](../references/query-dsl.md#职责与前置条件)。

## 前置检查与结构准备

- 接收问题、范围、粒度、指标及实体键、分母、权重、精度；定义不足补业务依据，不靠换工具或回退解歧义；一次性分析默认只读。
- 按 [Base 定位](base.md#定位已有-base) 确认可信 Base 与身份；权限被拒处理授权，不换身份、工具或回退绕过。用户限定 SQL-only 等工具时覆盖取数、补查、关系/名称回查（用 SQL 补可读字段，不用 Record）、精度复算，做不到报告限制。
- 独立分析先读结构定相关表，再取或复用覆盖它们及关联表的 Context；表、字段、键以真实结构为准，样例不代表完整值域。缺字段或截断按 [补全协议](../references/query-sql.md#返回解读复用与截断) 分批定向补，不用近义字段、不漏表。
- 构造 DSL 前必须取得目标表真实 `+field-list` 核对字段名、类型、计算来源；同身份同表、结构未变的完整结果可复用。
- 指定 View 时读其实际范围与过滤并等价表达；未指定不依赖既有视图，除非已核实其 filter/sort/projection 符合问题；无法等价报告限制，不拿全表冒充。

## 共同查询约束

1. 字段绑定真实来源，投影含输出及解释、关联、回查用的键；别名只标结果列，不把近义字段改名冒充。见 [SQL 字段来源](../references/query-sql.md#字段来源与结果列)、[Record 行矩阵](../references/record-read.md#json行矩阵与字段映射)。
2. 筛选、排序、聚合、限制能云端表达就下推；原始记录 TopN 先对完整范围筛选排序再限制；默认页、本地 jq、自然语言预览不证明全局结论；本地计算仅限 [受控回退](#精度与受控回退)。
3. 要全量就覆盖完整范围，只要样例或 TopN 时写明边界；Context 样例、有限维度行、`has_more=true`、截断结果都非全量。Record 的筛选、排序、JSON/NDJSON 解析与分页按 [读取与完整分页](record.md#读取与完整分页)；普通日期条件用 [tuple 协议](../references/shared-filter-tuple.md)，不混用 SQL 或 DSL 运算符。
4. 指标、日期、范围、空值、分母、权重沿用调用方口径及 [共享统计规则](../references/shared-statistics-rules.md)；修语法、补精度、回退、复算都不静默剔异常、改样本或总体、漏候选、换指标或公式含义。
5. 数值来自确定性查询或程序，输入、公式、单位、分母/权重、精度、舍入可复核，不手工数行、累加、估算。只算所需结果，同范围、兼容粒度的指标与核验合并或复用；`SELECT *` 只用于需全部可见字段的探索；缺必需证据才定向补查，不固定追加 DSL 或重算。
6. Dashboard 视图组件记录默认继承视图配置，覆盖 filter/sort/projection 前读 [视图组件协议](../references/dashboard-view.md)，不因最小投影丢掉用户要的展示。
7. 按所选命令的 Reference 解析：SQL 读命名结果列，DSL 读 alias 的 CellValue，Record 按真实字段映射。DSL 日期窗口、分段计数、恢复未舍入均值按 [日期分段与均值核验](../references/query-dsl.md#dsl-日期分段与均值核验) 查边界与有效数值范围；诊断不扩大取数授权。
8. 操作涉及或可能涉及全表或完整筛选范围内的所有原始记录时，先取得该范围的行数：有明确筛选则统计筛选后的记录数，否则统计全表。使用后端计数或复用有效的同口径计数，不先拉明细数行；规模计数属于操作前辅助查询，可与目标统计合并获取，计数失败不能当成小表。
9. 原始记录数超过 **1000 行**时，不得拉全表到模型或本地逐行判断；使用后端统计，或带完整业务筛选条件的查询，将取回判断的原始记录控制在 **1000 行以内**。不能仅用 `LIMIT` 截断或分页拼回全表绕过，也不能遗漏用户要求处理的数据；无法完整处理时说明限制。此边界约束原始明细取数，**不约束后端聚合结果的行数与分页**；后者沿用对应查询协议。行数不超过阈值仍按既有选路处理，不自动授权本地计算。

## 实体粒度与多表连接

- 每个指标确认事实粒度、唯一业务键、连接基数，连接用元数据声明的关联记录 ID 或已验证业务键（同一标识体系），字段名含 ID/编号 不证明可连接。
- 只有名称时核验名称与实体一一对应，查未匹配和关联放大（事实侧同名多条可属同一实体）；无法消歧报告限制，不合并不同实体。
- 分组、去重、窗口分区按实体键，名称只展示（明确按名称或类别统计除外）；记录键不一定是实体键，名称加评级、地区也不默认唯一；实体 TopN 先按实体键聚合再排序，不合并同名实体后再补编号。
- 不同粒度先各自聚合到共同粒度或按明确的归属/分摊规则；粗粒度金额不随明细行重复求和，`SUM(DISTINCT 金额)` 不等于按事实键去重。证据不足查重复键、未匹配、连接前后对账；总额守恒不代替粒度核验。

## 精度与受控回退

独立分析正常用 SQL。只有能力明确不可用，或按 [有界恢复](#返回证据与有界恢复) 修正、重试后仍失败，才先说明原因再转 DSL 或其他受控计算；精度复算按下表独立触发。对象辅助计算不必先让 SQL 失败。两类都优先用同口径的云端计算，回退期间不因“复杂”跳回已失败的 SQL。

已返回数据完整覆盖所需范围与粒度时可用程序算派生值、排序、核验并留输入与公式，但不借此读原始记录，也恢复不了已丢精度。

另读原始记录本地复算仅限三类原因，各自独立判断，后两类在独立分析中须先过上述门槛：

| 原因 | 判定 |
|---|---|
| 精确十进制或已证实的精度问题 | 用户或可信业务规则要求精确十进制、十进制舍入、精确对账，或有证据表明浮点误差可能改变交付值、阈值、排名；不必先报错、返回 null 或试 DSL 聚合 |
| 云端不能表达 | 允许的云端路径表达不了按 key 保留最新/最高记录、跨表存在性等复合计算 |
| 字段聚合不兼容 | 按 [null measure 诊断](../references/query-dsl.md#聚合成功但-measure-为-null) 确认类型限制，且等价底层数值的云端计算也不行 |

数据少、SQL 复杂、指标是金额、只展示两位小数都不是导出原始记录的理由。200 行是本地处理的默认选路参考，超过先评估云端能力，满足上述条件且能完整、可复核处理时不禁止；Record 单页上限不是任务总量上限。

- 复算只读必需的业务键、关联/分组键、原始数值，完整分页并复用已有完整数据；浮点计算参与过候选筛选、排名或阈值时，覆盖可能改变入选结果的完整候选集。
- 从原始十进制输入按 [精确计算方法](../references/shared-statistics-rules.md#精确十进制复算方法) 计算；浮点聚合值转 Decimal、加 epsilon、改容差都不能恢复精度。
- 统计已有公式字段读其原始值，不重算公式、不换指标；原始返回已丢精度就说明限制。
- SQL-only 无法满足精度时报告限制，不用 Record 绕过；取不到完整范围时不声称精确的全局结果。
- 回退后优先用 DSL 下推可表达的过滤、分组、计数、聚合、排序。类型不兼容按其 Reference 诊断；只有语义等价才用底层 number 字段替代计算表达式，不把用户指定指标换成近似字段。
- 本地计算拆成可复核的中间集合，以最小投影完整读取[规模允许的候选集合](#共同查询约束)，复用键集合。例：跨表存在性比例先固定分母 key 集合，再取分子 key 集合，按组求交集；找差值最大的组时算完全部候选组再统一排序。

## 查询核验

SQL、DSL、程序计算都做适用检查，复用已有证据：

| 检查项 | 通过条件 |
|---|---|
| 执行与覆盖 | 调用与解析成功，分页结束、无未处理截断，条件覆盖原问题；`truncated=false` 不证明范围完整 |
| 来源与实体 | 输出值可追溯到真实表、字段和表达式，最小投影仍含必要键；分组或分区键对应预期实体，连接基数、未匹配项可解释 |
| 计数与空值 | 记录数、非空数、主体去重数各用对应聚合，分组字段空不等于该组无记录（DSL 见 [记录计数](../references/query-dsl.md#常用示例)）；行数、维度行数、页长不是业务计数；空集、无有效值、失败、真实 0 分开 |
| 周期比较 | 环比对真实上一周期、同比对上年同期，上一条有数据的不一定是基期；缺失基期不补 0，零基期不算增长率，见 [月趋势与环比](../references/query-sql.md#月趋势与环比) |

必需项不能确认时按恢复预算补证据或返回限制，只报已证明部分。通过后连同证据交回：独立分析交 [Analyze-data](analyze-data.md) 验证结论；对象辅助计算回原 Scene 验收，不加载 Analyze-data。

## 返回证据与有界恢复

返回证据：表字段、时间与筛选范围、实体粒度、指标及分母/权重、实际 SQL/DSL 或程序输入与公式、覆盖证明、精度舍入、回退来源、限制。恢复预算沿用 [主入口](../SKILL.md#异常恢复与停止条件)，本页不加重试：

| 原因 | 处理 |
|---|---|
| 字段、语法、算子、类型、完整性错误 | 依真实 Context 和错误定向修正一次；可识别的暂时性服务错误重试一次；不猜底层版本、不盲试 |
| 结果截断 | 改投影、聚合或完整分页；不缩小业务总体，不用任意 LIMIT、日期裁剪冒充完整 |
| 修正仍失败或能力不可用 | 按 [受控回退](#精度与受控回退) 选路；回退仍失败、范围无法证明或被拒时返回未完成项，继续不依赖它的子任务 |

### 关系查询与回查

聚合结果不是原始记录，不猜 `record_id`（[DSL 维度行身份](../references/query-dsl.md#维度行与记录身份)）。有记录 ID 直接读，有结构化业务 key 精确筛选，仅有展示文本才用关键词搜索；link 与多跳关系按 [Record 回查流程](record.md#关联记录与多跳回查) 取关联表真实展示字段。独立 SQL 分析不为回查另跑 DSL；定位与写入分别判断授权；回查后交回业务值和定位证据。
