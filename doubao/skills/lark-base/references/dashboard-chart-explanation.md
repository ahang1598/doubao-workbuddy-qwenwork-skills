# 图表结果的自然语言解释模板

输入是实际配置和已核验结果；模板只是推荐结构，不新增取数、写入或回退权限。

## 模板使用条件

- 占位符只填有证据的字段和数值；没有对应维度、比较或趋势数据时删去该句。必答项缺证据时说明限制，不编造，缺失不当 0。
- 指标含义、时间和筛选范围取自实际配置和返回，不凭图表名称或 alias 推断。合计、占比、组间比较和排名按 [统计口径](shared-statistics-rules.md#指标与统计总体) 填写；未核验的句子不能当结论。
- 增强回答按“指标与范围 → 核心结果 → 排名或差异 → 分组或周期比较 → 趋势或异常 → 结论”组织，只留适用层次。“明显差异”“持续增长”“同一梯队”要有证据；成因和主题归纳与事实分开写。
- 图表基础模板通用：`在 <范围> 内，按 <维度> 统计 <指标及单位>：<项1> 为 <值1>，<项2> 为 <值2>。` 分组图表的项写成“维度1值／维度2值”，词云的项是词。

## 普通二维图表

适用于单维度的柱、条形、饼、折线、面积图和排行榜。时间序列按时间顺序解释；排行榜保持服务端返回顺序，另算排名须说明范围和依据。

增强：`<Top1> 最高，为 <值1>；随后是 <Top2及值>、<Top3及值>。前 <N> 项合计 <合计值>，占 <明确总体> 的 <占比>；<完整范围内的低值项及值>。<已核验的趋势或峰谷>。结论：<结论>。`

只返回 Top N 时，只报告所示项目和可加指标的合计；无独立同口径总体证据时，不输出总体占比或全局最低值。非可加指标不用合计贡献句。

## 分组聚合图表

先把每个值绑定到正确维度组合。

增强：`在同一 <维度1值> 下，<组X> 为 <值X>，<组Y> 为 <值Y>，差额为 <已算差额>。按 <维度1> 汇总后，<已核验排名及汇总值>；组内 <经计算成立的强弱或并列>。结论：<结论>。`

只有可加指标能按维度1汇总。均值、比率、加权值、去重主体数须有目标粒度的重算证据，否则省略汇总句，只比较现有组合值。不合并不同范围或单位的组。

## 词云

词项值的含义由返回的 measure 决定，不默认等于原文出现次数；同一记录可属于多个词项，词项值之和不等于记录总数。

增强：`<词1> 最高，为 <值1>；<词2及值>、<词3及值> 随后。<有依据时的并列或梯队>。可归纳出 <主题线索>，并说明原文或业务成因尚未确认。`

只描述实际词项和已证实排序；没有主题需求或证据时省略主题句。不把词云当逐条原文，也不把词项热度解释为用户人数或业务原因。

## 指标卡

`main_data` 是主值，`comparison_data`、`trend_data` 可选；主值可能不同于当前比较周期值。含义和日期维度顺序见 [指标卡返回协议](dashboard-chart-result.md#三指标卡statistics)。

- 基础：`当前 <指标及单位> 为 <main_data值>。<当前周期> 为 <comparison_data[0]值>，<对比周期> 为 <comparison_data[1]值>。<简要走势>。`
- 增强：`按 <已确认的比较窗口>，当前周期 <当前值>，对比周期 <基期值>，<升／降／持平及差额>，<基期非零时的变化率>。<趋势范围> 内最高 <日期及峰值>，最低 <日期及低值>，整体 <有序序列支持的走势>。<结论与限制>。`

未返回比较或趋势时省略对应句。窗口未知时只说明返回值和窗口未知，不猜同比或环比。基期为 0 时不算常规增长率；日期稀疏或月份不连续时，不把相邻观测点当相邻周期，不补零，不宣称持续增长。
