# 统计口径与一致性规则

## 适用范围

各节按动作触发，读本页不改选路、不自动全量取数；回退与复算条件见 [Query](../scenes/query.md#精度与受控回退)。权限“以上/以下”按 [权限数值边界](../scenes/permission.md#355-数值边界与百分比还原)，不用统计语义覆盖。

## 任务口径与核对

含业务筛选、Top N、分组、比率或时间范围时，执行前在验收项填：`总体/结果实体 → 业务谓词与全部限定 → 分组 → 指标及分子/分母 → 业务日期与范围`。

例：“本月各部门任务完成率”——总体=本月符合定义的任务记录，分组=部门，分子=组内完成数，分母=同组符合定义总数，日期=任务发生日；按人数统计则按人员去重，不混用粒度。

- 执行后在实际查询表达式或保存配置中逐项找到上述内容再核对；标题、别名、说明文字不算证据。
- 原始记录 Top N 先限定候选集再排序截断，返回检验资格所需列，不先取全库前 N 再筛。
- 读过或打印过分类不证明计算用了它（售后含退货、换货、物流咨询时，“退换货”仍须写进计算）；先按业务谓词确认子类，再按目标实体关联、去重、计算。

## 指标与统计总体

- 指标绑定真实业务字段，注明来源、单位、粒度、时间与筛选范围、空值、分母、权重、舍入规则。问总时间/成本/投入且同一对象并列记录同单位互补环节时，默认取各分量之和并说明构成；只问某环节取单项；计划与实际、预估与实收等替代口径不相加。
- 区分记录数、非空字段数、主体去重数，各指标分别定总体；组内发生率以该组符合定义的全部主体为分母，不因别的指标只覆盖部分主体而缩小；贡献占比按题定总体定分母。
- `sum(分子) / sum(分母)`（总体加权）不同于 `avg(分子_i / 分母_i)`（等权平均）；零分母、缺失值、无有效数值不当零比率或零均值；粒度、分子、分母、权重、空值处理计算前固定，输出时不换。
- 去重主体数、比率、加权均值在目标粒度重算，不直接加总或平均；多组重复归属时组内去重不保证组间可加；核对分项和前确认互斥、覆盖总体、单位一致。
- 并列权重约定仅用于 [受控回退与对象辅助计算](#受控回退与对象辅助计算)。

## 自然语言条件与字段充分性

自然语言目标转成筛选或分析条件前：

1. 改写为可验证的**业务谓词**（如“待收余额 > 0”）；阶段状态、局部状态、流程中间值、语义相邻字段不证明最终业务状态。
2. 用 `+field-list` / `+field-get` 确认字段定义及完整选项；需补实际值域、组合关系或子类数量时，按 [Query 选路](../scenes/query.md#任务导航与计算模式) 使用云端去重／分组统计，只定向读取解释条件必需的明细，完整候选值域不要求导出全部原始行；独立分析改用 Context 和只读 SQL；写入须有授权。
3. 为完整值域建 `值 | Include / Exclude / Unknown | 字段证据` 对账，字段证据直接证明不满足才可 `Exclude`，否则 `Unknown`。
4. `Unknown` 不静默丢弃，不混入已确认命中数、分子或总体：用户明确业务关系且授权结构写入时建可复核的源/派生字段；只读任务保留未知范围、不自动加字段；关系未明确先澄清；补不齐则保留全部候选分组展示；指标依赖未知值时说明范围或先澄清，不给伪精确值。
5. 写入后分别复算 Include、Exclude、Unknown 子类数量，与持久视图、最终回答核对；任一子类遗漏或口径不一致不得交付。

**业务事件资格不能由相邻维度代替**：渠道、款式、客户、负责人等维度只表示归属；以“有效订单”“已成交”“出单”作统计总体须有订单号、成交状态、有效标记或用户给的等价定义，否则保留 `Unknown`，不把全部明细算进分子或排名。

Few-shot：“定金收一部分的和一分没付的都还没付清”，只有 `定金支付状态=已支付/未支付`。`已支付` 是**阶段状态**，不证明 `全款已结清`；应同时保留未付定金与已付定金待尾款（加“欠款类型/待收金额”字段在一个视图分组，或建两个互补视图），不得只筛 `定金支付状态=未支付`；比例、总额、尾款状态不明时先补总金额/已收金额/尾款状态或澄清，不猜待收金额。

**状态筛选**：按状态类单选 / 多选字段筛选（视图、仪表盘、工作流条件）前，先用 `+field-list` 列出该字段全部选项，逐个判断进行中还是已结束（结束不只成功，空值去留同按语义），按原话正向枚举保留项：“未完成 / 未处理 / 进行中”写 `["状态", "intersects", [全部未结束选项]]`，不得用 `!=` 或 `disjoint` 只排除一个终态。

## 时间范围与动态配置

一次性查询按本次操作时间与业务时区算固定边界并说明；以下用于长期保存的 Formula、View、Dashboard、Workflow 等；固定历史区间按用户指定，不改滚动。

- 锚定运行当天、随时间变化的相对时间词是数据范围，不是名称装饰。这类词包括本周、上周、本月、今年、本年度、年度、年底、近/超过 N 天或月、未来/接下来 N 天或月、即将到期。
- 出现这类词时，逐个检查本轮 Formula、View、Dashboard、Workflow、汇总表的保存后配置和最终回答：展示或参与 `SUM` / `AVERAGE` / `COUNT` / 排名的记录必须先按真实业务日期动态过滤，所有相关对象范围一致。
- 用户未要求固定历史区间时，不把运行当天换算成固定 `ExactDate` / 年月边界。全历史聚合后只命名为“本周/年度/本月”不得交付；样例数据恰好在范围内不算通过证据。
- **按周分组不等于本周筛选**：周度序列、按周汇总、周次维度用真实业务日期加稳定周分组（如 Dashboard `DATE_YEAR_WEEK`）或已验证的周次／周起始日字段；`CurrentWeek`／本周只限范围、不产生周维度；两者同时出现分别配置。

### 年度口径不是全历史聚合

“今年、本年度、年度、年底”约束参与计算的记录范围，不只是字段名或展示文案。年度评分、汇总、排名或状态判断必须：

1. 用真实业务日期字段确定记录所属年度。
2. 参与聚合的记录加 `YEAR([日期字段]) = YEAR(TODAY())` 或等价动态年度条件。
3. 下游 Lookup、Dashboard、汇总表、最终回答保持同一年度范围，不让公式聚合全历史、下游再声称“本年度”。
4. 创建或更新后核验保存表达式及代表记录。

没有可定年度的日期字段时，新建系统补业务日期字段，修改已有系统先澄清；不用语义相邻但不等价的日期，不聚合全历史后仅命名为“年度评分”。

## 口径保持与对照

- 主查询、修正、补查、复算、回答同一来源、范围、粒度、指标；极值、字段存在、业务习惯只触发复核，不自行排除记录、改分母、缩主指标；改口径须有用户要求、已核验的指定 View/任务范围、字段公式或可信业务定义；歧义会改变结论或与用户明确要求冲突时先澄清。
- 默认用全量符合条件数据，不静默剔除疑似异常或改样本；有业务含义的对照（如“剔除疑似异常”）单列并说明依据与差异；依据不足则保留原口径、报告疑点，对照不替换主结果。

## 查询、产物与回答一致性

- 同一指标的查询、持久对象实际数据、最终回答用相同数据源（source）、范围（range）、结果粒度（grain）、指标（measure，含聚合函数及分母/权重），调用方据查询计算证据与对象保存配置、实际结果逐项对账。
- View 过滤不证明以表为源的图表继承该范围，逐个核对下游数据源与保存条件；原始记录分组、排序、预览顺序不等于分组聚合结果；写入成功、配置名称、查询结果不等于产物生效。
- 任意两者不一致则该交付项未通过；不同口径的补充对照须标注，不混作同指标。

## 数值展示与精确计算

- 交付数字（含合计、差额、占比、解读性计数）来自确定性查询或可复核程序并保留输入与公式，不手工数行、累加、估算。
- 先按未舍入值排名、比较、判并列，再舍入展示（用户明确要求按舍入值比较时照办）。展示值相同不证明原值相等，精度不足不强判阈值或并列。
- 单位、展示精度、业务舍入规则一致；分项各自舍入后求和可能不等于总额舍入，展示时说明，不为凑总额改原值。
- 只要求“展示两位小数”不等于要求精确十进制复算；对已完整返回的结果做确定性核验，不授权另行导出原始记录。

### 精确十进制复算方法

SQL/DSL 数值能力见各自协议。满足 Query 复算条件时：

1. 用原始十进制文本构造 Decimal 或以十进制解析 JSON 数字（如 `json.loads(raw, parse_float=Decimal)`），不先转 float；确认业务单位与原值小数位后可用整数最小单位；显示两位不证明原值只有两位。
2. 设足够精度，按既定粒度、空值、分母、权重计算，最后显式舍入；十进制四舍五入用 `ROUND_HALF_UP`，不靠语言默认：`Decimal('43.135').quantize(Decimal('0.01'), rounding=ROUND_HALF_UP)` 得 `43.14`（浮点可能得 `43.13`）。
3. 不对已失真的聚合值转 Decimal、加 epsilon、调容差伪装修复；`ROUND` 和本地计算都恢复不了已丢的精度。
4. 输出复算结果并保留原始输入、公式、覆盖证据、精度、舍入规则，必要时解释与云端值差异；完整范围与候选集按 Query。

## 受控回退与对象辅助计算

仅用于已获准的受控回退与对象辅助计算，不含正常 SQL 成功路径；沿用 [口径保持与对照](#口径保持与对照)。

- 派生比率、单位值、加权均值输出标明口径；用户明确问这类指标且有多种合理权重，或开放式对比已在同一粒度把有明确业务含义的比率/单位值的分子分母都作主要维度时，默认并列给加权与等权结果。
- 用户表述、字段公式或已确认业务定义指定主口径时以其为主，另一口径仍有业务含义则标为敏感性对照；应并列或对照且实质影响数值或结论的口径不省略、不静默切换；只有数字字段而比率语义未确认时不自行派生。
