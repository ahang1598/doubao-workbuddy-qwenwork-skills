# 视图生命周期命令

## 适用范围

本页维护视图列表、详情、创建、重命名和删除的命令约定。任务选择、修改范围与业务验收见 [View Scene](../scenes/view.md#任务导航)。

## 生命周期命令

执行依赖目标表权限，参数以对应子命令的 `--help` 为准。

| 操作 | 命令 | 返回与用途 |
|---|---|---|
| 列出表内视图 | `+view-list` | `data.views`，用于定位或枚举目标表视图 |
| 读取视图详情 | `+view-get` | `data.view`，用于按真实 ID 核对名称与类型 |
| 创建 | `+view-create` | `data.views` 数组 |
| 重命名 | `+view-rename` | 仅更新名称；具体配置使用独立设置命令 |
| 删除 | `+view-delete` | 目标通过 `--view-id` 指定；沿用 CLI confirmation gate |

筛选、分组、排序、可见字段、卡片和时间轴的独立读取与设置入口见 [展示协议](view-display.md#配置命令索引)。

## 创建名称的传参约束

`+view-create` 的 `--json` 接受单个对象或对象数组，名称与类型放在 `name/type`（如 `{"name":"...","type":"grid"}`），不使用 `--name`、`--view-name` 或 `--view-type`。改名才用 `+view-rename --name`。

`type` 省略时默认 `grid`；支持 `grid`（表格）、`kanban`（看板）、`gallery`（画册）、`calendar`（日历）、`gantt`（甘特）。不要传 `form`，表单使用独立命令。

## 结果未知时的读取

- 创建结果未知时，先按已返回的 ID 读取；没有 ID 时列出目标表视图，结合名称、类型及调用前现状定位。未确认创建结果前不重复创建，候选不唯一时不能任选一个继续。
- 更新结果未知时，用 `+view-get` 或对应配置 get 检查已保存状态；名称与配置分别读取，不因一种读取成功推断另一种已更新。
- 删除后以成功读取的目标表完整视图列表确认目标 ID 是否仍存在；权限拒绝、网络错误或解析失败不能作为已删除的证据。
