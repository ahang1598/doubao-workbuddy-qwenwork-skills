# 普通列表 standard

必读 [列表协议](component-list.md)。type=list，sub-type省略或standard。默认容器宽×20，推荐W24～48、H≥16；显式宽fill，根组合决定高fill，不能auto，用户合法尺寸与模板优先。

创建/明确调整字段时，可展示业务字段≤8全部展示，>8选核心8项。按标识、状态、负责人、关键时间/金额的业务价值排序，系统与重复信息后置；用户点名字段优先。columns可用field或combined，但不重复字段。回读实际字段、顺序、密度、矩形与模式。

列宽默认按字段内容自适应，不低于原生最小列宽，单字段最大宽度不超过可视内容区20%。有效字段数≤5时优先均分剩余空间、避免右侧大片留白；>5时按内容定宽、允许横向滚动。约束冲突时原生最小宽优先，其次20%上限，均分/消除留白仅在两者满足时执行；例如4列各≤20%无法铺满整行，保留留白并报告约束缺口，不擅自放宽上限、缩字或删必需字段凑版。当前公开columns只确认字段/组合列配置，未确认独立列宽设置与回读协议；不能把组件外框宽当列宽，不能编column_width等键。没有列宽或页面渲染证据时，该项记未验证。
