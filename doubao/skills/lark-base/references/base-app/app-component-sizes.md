# App 组件原子尺寸索引

每个组件的默认宽高、推荐范围、模式与密度已在 [逐组件Skill](app-component-selection.md) 独立维护。本页保留旧入口，不再复制第二份尺寸表。

新建无覆盖时必须落实原子默认；用户合法尺寸、首页模板或组排版优先于原子默认。推荐范围不是用户尺寸硬阈值，容器宽/组均分/内容高不自动等于fill/auto。根级组合、高度填充和同行兼容只由 [页面布局](../../scenes/app-mode/layout.md) 判定。

尺寸最终以独立回读的layout_config.position与size_mode为证据，不能把CLI产品自动默认或规划值当成规则已落实。原子高度、透视表叶子密度、文本auto、AI独立模式均加载对应组件文件。
