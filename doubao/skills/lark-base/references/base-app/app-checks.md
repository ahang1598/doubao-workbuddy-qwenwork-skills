# App 回读与交付

独立读取实际保存结果，对照原话；名称/创建成功/请求回显不代替证据。只检查本次目标、直接依赖和保留项。

## 写前核对

- 新建按 [create](../../scenes/app-mode/create.md) 核Page/组、组件、口径、入口；骨架也补有效内容，指定树不扩，标题/占位不算完成。
- 修改先读原配置；新增按 [语义查重](../../scenes/app-mode/modify.md#添加组件先按业务语义查重) 记复用/补齐/创建及ID，涉及位置/尺寸/容器读完整structure和保留项。
- 读命中组件/范围/时间/指标协议，参数看精确help。

## 每步写后

| 操作 | 读取与判定 |
| --- | --- |
| App/页/组/导航 | app-get；page-tree-list完整分页核类型/数量/父级/顺序 |
| 组件 | 逐ID block-get核widget、type/subtype、源、字段、完整筛选、分组/聚合/排序/格式/动作 |
| 图表/指标 | 配置后block-get-data用真实chart_token+源Base，同口径对账，0合法 |
| 点名进度条 | progress+shape=bar，current/target来源/字段/聚合/资格/格式；完成率与条形实际展示分验，statistics不抵扣 |
| 列表/视图 | 显示字段、新增/详情开关；引用视图另核类型、筛选/排序/分组/日期 |
| “我的”（含自拟） | 逐源真实归属字段+动态访问者，列表/视图/指标均覆盖；页面可见/切片器不抵扣，记录权限另验 |
| 布局/容器 | 完整structure核坐标/模式/父级/顺序、同父无重叠/越界；按 [补洞](../../scenes/app-mode/layout.md#画布会向上补洞不能用空位占行) 与 [正例](../../scenes/app-mode/layout.md#消除留白的正向示例) 核每行含尾行满所属区域、无上挤串行；保留局部关系，最终排版另取页面证据 |
| 按钮/Form/Workflow | 真实URL/Page承载目标动作；Form题目/必填/题序/分享；Workflow条件/动作/人员/启用 |
| App角色 | role-list+逐role-get，按 [授权证据](../../scenes/app-permission.md#授权证据与两轴判定) 分验页面/表/记录/字段/复制权限，取数成功或普通Base角色不抵扣 |

## 页面与交互验收

完整新建/全局重设计逐页全部检查；简单按明确集合，局部只查目标/邻居/保留项，既有其它问题列出不顺带重做。

| 项 | 真实证据 |
| --- | --- |
| 首屏识别 | 标题/业务说明/核心字段/高频入口可识别用途，无通用空壳；名称/坐标不能证明 |
| 数据内容 | 列表/图表正常展示，无报错/数据无效/占位；0和符合条件的空结果合法，不造数/改口径 |
| 可读布局 | 无严重重叠/错位/断层/非预期大空白；正文、按钮、关键字段、分类/标签/轴/图例完整可读，不只看标题，不另设铺满一屏门禁 |
| 可见入口 | 逐个真实点击跳转/详情/录入能打开正确目标并承载动作；action/allowViewDetail/URL仅配置证据，不证明非死链/可提交 |
| 核心路径 | 按原话至少一条查看→详情→所需录入/编辑/处理；只读不开写，空目标/错承载记未完成，状态/提交结果另回读 |

有错误记未完成，缺页面/点击证据记未验证，不凭无证据推断正常。仅用公开能力/授权工具，副作用实测限原授权，不能测则缺口；用户指定异常链接/特殊效果按原话判定。

## 跨页面风格一致性

完整新建/全局重设计横向核全部页，同语义层级/角色样式一致；用户差异及业务风险强调保留，不机械统一所有组件。

| 维度 | 核对 |
| --- | --- |
| 主题/颜色 | 主题、背景、同类卡/图配色协调，无意外明暗/刺眼冲突；theme相同不证明组件一致 |
| 容器/卡片 | 同类圆角/描边/背景/阴影策略一致，不为不支持项编参数 |
| 字体/图标 | 同层级字号/字重、同类入口图标/有无/底色策略跨页一致，不只看同行 |
| 排版/操作 | 同职责对齐/间距/主次、主操作位置/样式稳定；不同用途不强制同集合/布局 |

先回读公开样式，再真实页核渲染；只theme-style不算整体通过。仅修授权不一致，局部不重设未点名主题/字体/配色/布局；能力不足或无渲染证据分别记未完成/未验证。

## 末次写后

1. 对原话和三行计划逐项核页/组、每个组件/字段、范围/周期/指标、录入/处理对象的真实证据；一个正确不抵扣漏项，标 `已验证 / 未完成 / 未验证`，不生成审查JSON/清单文件。
2. 修改的写入/回读/链接始终是原目标App，多资源分清角色，不以新副本代替；比较未点名源/样式/布局/权限/动作。新建先记录 [结构门禁](../../scenes/app-mode/create.md#交付前结构门禁)：默认≥3不同用途有效Page，组/表/空页不计，明确页数/闭合集合优先；逐对象核App内新增/详情/处理/Form入口及目标。
3. 逐谓词核报名/活跃/读完资格、自然周期双边界、计量实体/跨表条件、并列度量、Form/当前记录入口；适用首页跑 [T型自检](../../scenes/app-mode/layout.md#t-型自检交付前必跑)，不是只核存在。不符先修复重读，后续写入影响旧结果时重验。
4. 执行上方页面/交互/风格表，保留实际证据与用户覆盖，缺证据不勾通过。
5. 最终给真实可用App及必要页面/入口链接、完成内容和逐项缺口；配置保存、计算、动作实跑分报，未验不称全部通过。
