# App 对象图标候选

按 [布局与视觉](../../scenes/app-mode/layout.md) 的职责、范围与语义选图标；按钮按 [组件选型](app-component-selection.md) 选择图标或隐藏。不同对象的候选不能混用。以下是迁入的 Building Agent 首批资源合同；CLI 字符串参数不证明线上全量可用，写后独立回读，服务拒绝时保留失败，不猜替代名。

目录：
- App 图标
- Page 与 PageGroup 图标
- Button 图标
