# App 时间范围、趋势与周期

要求临期、逾期、时间窗口、走势或月/周聚合时必读本页；范围覆盖仍按 [范围合同](app-scope-contract.md)，图表参数按 [标准图表](component-charts.md)。不把本页示例当用户指定阈值或新增来源授权。

### 时间语义的最小操作配方

先写清时间谓词再建组件；状态、可见日期、日期排序或改名不产生时间范围。

本周为业务时区自然周，不换最近7天；本月不换最近30天。支持CurrentWeek就用它，不用LatestOneWeek改名。例仅源filter，真实日期/时间分组/资格另保留：

```json
{"filter":{"conjunction":"and","conditions":[{"field_name":"业务日期","operator":"is","value":"CurrentWeek"}]}}
```

独立回读并用区分日期核范围；不支持标签则已验等价自然周或blocked，不换滚动窗口。

- **临期**：复用真实阈值，无阈值且授权自主设计可选提前N天，交付记假设不称用户指定。剩余天数须按当前日期持续算且数值，`>=0 AND <=N`排过期/远期，续费/处理资格另AND不替边界；逾期用真实到期日/负天数。
- **公式证据**：field-get核表达式/公开元数据，未露输出类型unknown，Formula声明/名/表达式/Record渲染字符串不证明数值。读实际值验算，用公开筛选/聚合保存、独立回读、命中/排除/边界核能力；成功写入/未知不判通过。`IF(日期为空,"",剩余天数)`先核混合类型适配，授权内改数值计算并独立处理空日期、数字标量筛；或持续“临期是/否”文本标记+字符串精确筛。均排空日期/过期/远期，不手填状态。缺类型元数据仍可继续验证，公开路径失败/缺区分结果分别记失败/待验证。
- **值类型**：数字标量、公开日期表达，不套Record单元素数组；下例N=14，真实表/字段/阈值按口径：

```json
{"filter":{"conjunction":"and","conditions":[{"field_name":"剩余天数","operator":"isGreaterEqual","value":0},{"field_name":"剩余天数","operator":"isLessEqual","value":14}]}}
```

报错保留原口径/完整错误，查Formula/Lookup输出/实际值、标量、字段/协议重试。公开日期或真实视图等价动态双边界可替换并回读，不只状态/删边界/固定搭建日时间戳。仍失败原组件blocked；逐列表/视图/指标核时间/边界，正确卡不抵扣列表。

## 趋势图先准备时间事实

用户要求“走势/趋势/随时间变化”时，先准备真实时间数据，再创建组件：

1. **事实**：事件用发生日期/当次数值；健康/余额存量需对象+观测日+当时值。当前值+对象名非历史，合同到期/创建修改不自动为观测日。
2. **来源**：已有复用；授权从零建结构时缺历史指标补最小对象关联/观测日/数值源。触发 [Mock规则](../../scenes/mock-data.md#开工必读) 则准备区分时点、日期≤当前、关联/数值一致的明确样例，不因无历史跳过授权依赖。保真仅可核观测，不复制当前值到过去/造曲线；空/单点保留正确源，说明待积累。既有局部未授权新源则最小依赖+blocked。
月/周粒度另验，日字段不自动聚合周期；公开分组不足则授权内从真实业务日期派生周期字段并升序，月YYYY-MM按 [粒度配方](../dashboard-chart-config.md#时间粒度与范围辅助字段)，周保留年/业务周。升序/标题不代周期聚合。

3. **绑定**：主group_by真实观测/发生/周期字段升序，series当时值/聚合，不被当前主表覆盖；客户/人员仅必要第二维度。block-get核时间/序/值/筛选，对象名line/smooth不算走势。

用户只要求分类对比时仍按分类语义选型，不强制新增历史表。指标语义受阻时保留原图要求和真实缺口，不能改成“当前值对比”后勾掉走势需求。

### 空结果后的窗口保留

本月取0不判日期失败，查业务日期/时区/同范围记录，不换未来30天/删日期；原窗口交付或缺口。日期分组仅横轴、不自动过滤，最近/本月须在本趋势源/有效视图回读。
