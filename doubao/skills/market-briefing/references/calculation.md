# 计算方法

数字用于形成判断，而不是填满表格。少量题面数字直接运算；文件数据或重复计算可使用 `scripts/market_math.py`。工具仅做本地读取和算术，不联网、不生成简报、不判断来源真伪，也不决定经济解释。没有适用算子时，用授权本地代码完成所需计算，不迁就工具改变用户口径。

## 从原始材料到同一组结果

明确读哪张表、哪些行列及单位。CSV编码按实际文件选择；XLSX公式文本不当作数值，公式无可靠结果时从可得输入重算或说明缺口。单位和脚注可能在数据区外，按实际位置读取，不把脚注混进观测样本。

正文、表格、排序与用户要求的文件都从同一计算结果取值。保留足够精度参与运算，按用户需要呈现精度。原始值不随意乘除千或万来“看起来合理”；转换需要字段或来源依据。

## 选择符合问题的运算

- **价格收益率**：`(终值 / 起值 - 1) × 100%`。起止、复权和现金分配处理一致。累计简单收益按各期增长因子连乘，不直接相加。
- **比值与变化率**：比值为 `当前 / 基准`，变化百分比为 `(比值 - 1) × 100`；百分点是两个百分数数值之差，基点另行换算。不同对象或窗口的指标不能互换。
- **成交比较**：盘中累计对相同交易时段的累计；局部区间增量由累计值相减，不能混同全天。组总额比较采用同一成员集合的总额之比，而非成员比值平均。
- **指数贡献**：在给定权重与成分收益适用时，贡献百分点为权重小数乘收益百分数。剔除部分成员后的收益采用剩余权重归一；指数实际编制存在其他调整时，不能把简化模型伪装成官方贡献。
- **广度与分布**：上涨、平盘、下跌使用相同有效样本；缺报价、停牌或未覆盖成员不自动归入平盘。观察集统计只代表该观察集；均值、中位数、极值和占比各有不同含义。
- **多日基准**：依题意决定是否含当前日、需要多少交易日及是否允许短窗。先取足前史，使用实际会话日历；缺一个交易日不能拿更早可见行顶替。样本缺失与零成交分别处理。
- **排序**：先按用户条件形成候选集合，再用指定字段和方向排序。成交额榜不是涨幅榜，不混排不同日期、币种、指标或不相容样本；并列与不足名额按实际情况表达。

## 轻量调用

标准库覆盖CSV及算术；XLSX读取需要环境已有 `openpyxl >= 3.1`。脚本可在命令行调用，也可作为 Python 模块导入。数值函数不猜带单位、千分位或百分号的字符串；从来源含义明确转换后再传入。缺值按函数返回 `null`；一般比值和变化率遇零分母返回 `null`，价格收益则要求起值大于零、终值非负，不满足即报错。非法数值不填成零。

```bash
python3 scripts/market_math.py read /absolute/path/data.csv --header-row 2 --first-row 3 --last-row 20
python3 scripts/market_math.py read /absolute/path/data.xlsx --sheet 'Prices' --columns 1 3 5 --first-row 2 --last-row 20
python3 scripts/market_math.py calc change_pct '{"current": 126, "baseline": 120}'
```

这些是合成用法数字，并非行情。读取结果含 `source_row` 与原字段 `values`；XLSX公式及数组公式覆盖范围列在 `formula_cells` 中，表达式单独保留，对应值为 `null`，不采用未经重算的缓存，也不执行材料中的代码。纯文本以等号开头不因此变成公式。脚本按逻辑记录范围流式迭代，保留空行的缺值；CSV带引号的跨行字段仍算一条记录，行号指逻辑记录号。文本解码可能缓冲预读，邻近的损坏字节仍可能使选区读取失败，不保证字节级隔离，也不用忽略解码错误来掩盖损坏。脚本输出标准JSON，不自动保存文件。

## 命令参数与返回值

命令在 Skill 根目录执行：`python3 scripts/market_math.py read PATH ...` 或 `python3 scripts/market_math.py calc OPERATION ARGUMENTS_JSON`。也可以使用脚本绝对路径，来源文件仅限本任务已授权路径。

| 参数 | 必填／默认 | 含义 |
|---|---|---|
| `path` | `read`必填 | 本地CSV或XLSX路径，不接受URL |
| `--sheet` | CSV不需要，XLSX必填 | 精确工作表名称 |
| `--header-row` | 默认1 | 表头所在行，行列位置均从1开始 |
| `--first-row` | 默认表头下一行 | 必须位于表头之后 |
| `--last-row` | 默认至文件末尾 | 明确数据段末行可避免输出无关行；超出源范围报错 |
| `--columns` | 默认表头所有列 | 一个或多个原始列号；选中表头须非空且唯一 |
| `--encoding` | 默认`utf-8-sig` | CSV源编码，XLSX不使用；已知其他编码时显式指定 |
| `operation` | `calc`必填 | 下表中的函数名 |
| `arguments` | `calc`必填 | 函数具名入参组成的JSON对象，不是数组或代码表达式 |

读取输出包含`source_path`、`sheet`、`headers`、`rows`和`formula_cells`。每个数据行保留`source_row`及`values`。计算输出是函数的数值、`null`或具名结果对象。例如`change_pct`的上述合成调用返回约`5.0`，而`breadth`返回家数、总样本数和上涨百分比。

脚本将JSON写到标准输出，不自动写文件或执行公式。成功退出码0；数据、解析或依赖错误返回`{"error":"原因"}`并退出2；命令参数用法错误由argparse提示并退出2。缺输入不能改填0，损坏文件、未知表名、重复JSON键或非法数值不能继续作为可靠结果使用；改用合法材料、已有输入重算或限定依赖它的判断，不改变用户数据来让脚本通过。

## 可调用函数

| 函数 | 输入与结果 |
|---|---|
| `total(values)`、`mean(values)` | 空集合或任一值缺失返回空；需要完整集以外口径时在调用前明确样本 |
| `ratio(numerator, denominator)` | 倍率 |
| `change_pct(current, baseline)` | 变化百分数 |
| `price_return(start, end)` | 价格收益百分数；起值须大于零、终值非负，非法值报错 |
| `compound_return(returns_pct)` | 简单收益百分数数组的累计收益 |
| `group_comparison(current, baseline)` | 已按同一成员对齐的两数组，返回总额、倍率、变化率；数组顺序由调用者按身份对齐 |
| `weighted_return(returns_pct, weights, normalize=False)` | 权重用小数；返回贡献百分点与合计。子集重新归一使用 `normalize=True` |
| `breadth(up, flat, down)` | 精确非负家数，返回分母与上涨占比；不接受“超过若干家”的近似数 |
| `rolling_mean(values_by_date, sessions, target, n, include_current=False)` | 日期→值、明确有序交易日历、目标日、窗口大小；返回实际窗口和缺日，缺值不借更早日期补齐 |
| `rank_rows(rows, field, descending=True, limit=None, tie_key=None)` | 参数化数值排序，缺排序字段的行单列；无并列键时保持输入顺序 |

金额、收益和样本身份的经济含义来自本次材料，而不是计算函数。来源定位和比较基准随结果保留到需要引用的地方，无需额外建立命题图或版本台账。
