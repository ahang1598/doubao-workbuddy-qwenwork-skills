# 取数协议（Data Collection Protocol）

本文件规定本 Skill 的取数方式，配合工作流程第 2 步使用。来源分级与台账规则见 `data-grading-and-citation.md`。目标是避免"一遍搜完就写"，同时保住模型在套用固定结构之前先发现行业特定事实、矛盾与线索的能力。

## 一、数据合规与授权（红线，先读）

- **只用授权可用的工具**：按 SKILL.md 第2步的工具分工取数，或使用用户主动提供的文件；不得自行调用其它未授权的数据接口或数据源。
- **只取合法公开的内容**：仅使用合法、公开可访问的页面或官方/授权接口返回的信息；引用前确认来源公开可得。
- **严禁绕过任何访问控制**：不得绕过登录态、付费墙、验证码或反爬限制，不得抓取未授权数据，不得规避站点条款（robots/ToS）或访问受限的非公开数据。
- **缺数据如实暴露，不另寻隐藏来源**：可用工具及用户文件拿不到的字段，按缺口降级、如实标注，绝不切换到隐藏的第三方数据源、绝不补造。

## 二、工具选择

按 SKILL.md 第2步的工具分工执行。行情、财务类数字采用查询结果；公告、研报与其他公开信息优先追溯原文。

## 三、来源计划（动笔前先想清楚）

检索前明确问题类型、关键指标与合格来源，按信息类型选择相应工具。缺工具或缺字段时，只对受影响的内容降级、标明数据缺口，不补造。

## 四、检索轮次与覆盖度

不要"一遍搜完就写"。每一轮围绕一个取证目的，把该目的下相关的几条检索一次性成组发出、同步推进，而不是查一条等一条；用足够宽的覆盖面把这个证据问题快速答清。

按信息类型选择工具成组取证，无需先后遍历所有工具。

**以覆盖度而非轮数停机**。动笔写正文前，按研究问题覆盖下列核心维度：

1. 行业定义、边界与规模（多源对照 + 一条本研究测算）。
2. 增速 / CAGR、宏观敏感性、生命周期阶段。
3. 产业链结构与各环节价值分布（利润池）。
4. 竞争格局：集中度（CR3/CR5）、头部玩家与阵营。
5. 价格、产能利用率、库存与供需（如适用）。
6. 梳理影响行业判断的政策及其发布主体、时间、适用范围和影响。
7. 核心驱动力与制约因素（需求、技术、政策、成本、竞争五维）。
8. 盈利质量与估值（毛利率、ROE/ROIC、现金流、可比公司 PE/PB 区间与分位）。

覆盖到位、最重要的行业变量已清晰、剩余未知项已转为明确的"数据缺口"时，即可停机动笔。不为检索条数继续查找。

**优先处理**：竞争格局还没讲清谁拿走利润；核心判断还依赖一个未经核验的数字；只有正面的、公司/聚合站口径的来源；政策类事实还没取到官方一手源。

## 五、采集规则

1. **市场/行业数字**：按 SKILL.md 第2步工具分工取得，并满足来源级别要求；用户文件须注明出处；显名“本研究测算”须写清输入来源、公式与假设。

2. **来源分级与取数优先级**：同一事实优先引用级别更高的来源。三级可信度的完整定义见 `data-grading-and-citation.md`。概要：**一级**（可直接当事实）＝①金融数据库的市场/财务数据；②一手官方与权威机构原文（公司年报/季报/业绩快报/公告/招股书/交易所披露，统计局/部委/央行/海关的官方统计与政策原文，官方通讯社，券商研报原文）。**二级**（须显名归因、限定措辞）＝权威财经/行业媒体原创报道、行业协会与第三方研究机构数据（中汽协/光伏协会/IDC/Gartner/IEA/BNEF 等）、券商或机构对未披露口径的估算。**三级**（仅作线索）＝聚合站（前瞻/智研/中商/华经）、自媒体/UGC（雪球/股吧/公众号）、传闻与二手转载。政策类事实必须取自官方一手源；**三级不得作为任何展示数值或政策事实的唯一来源——必须顺藤摸到一级/二级原文核验后引用更高等级来源，核验不到就不展示**。

3. **行情/财务数字的来源红线**：必须经指定查询工具取得。正文/表格里每个具体数值都必须可追溯，严禁凭印象或估算给数，拿不到就按缺口降级。

4. **取数时点（数据基期）**：涉及行情/财务时点的数字写明基期——年报/统计年鉴等滞后数据标注其基期（YYYY 或 YYYYFY/YYYYQn），不因发布晚而失真；涉及行情时点的（如估值分位）统一写"数据截至 YYYY-MM-DD"；禁止用盘中实时价或来路不明的估算值充当口径数字。

5. **估值口径**：PE/PB/PS 须标注 TTM/静态/动态(LYR) 与时点。

6. **代表公司选取口径**：板块二"重点公司简析"的样本必须从该行业代表性上市公司中选取，优先权重靠前、有代表性的龙头与典型品种，每家写清其代表性（如"整机龙头""核心零部件标的"），且仅用法定信披来源（年报/公告/交易所披露）。

7. **同一指标多源差异 >30%**：并列展示并解释口径（出厂/零售、含税、销量/销售额、全球/中国、收入/出货/装机口径），不取平均、不只取单源。

## 六、缺通道时的降级

- **某条检索通道不可用**：按本文第二、三节降级——只有受影响板块已明确降级、数据缺口已如实标注时才交付；不得用其他工具顶替必需的行情/财务查询、绝不补造。
- **所需工具均不可用**：不强行产出含编造数字的报告；向用户说明数据缺口与限制。
- **缺数据本身是一个分析结论**，必须作为来源缺口如实暴露，绝不通过切换隐藏来源或补造来填补。

## 七、品牌、命名与示例数据纪律

- 本 Skill 名称含 `doubao` 前缀。该品牌词的对外使用须经内部合规/法务确认；正文中提及的任何第三方机构、平台或产品名称仅作中性、客观引用，不暗示授权、背书或合作关系。
- 模板、说明或示例中出现的任何示例链接、示例数字、占位机构名，仅用于演示格式，**不得作为真实来源或真实数据写入正式交付物**。
- 正式交付物（正文、表格来源行、参考文献）中的每个数据点都必须可追溯到授权工具或用户提供的文件；拿不到则按缺口如实标注、绝不补造。
