# 量表查找与测量设计

## 基本信息

- **版本**：v1.1.0
- **定位**：把已明确的构念转化为可核验、可实施的测量方案；不替研究者发明理论模型，也不把检索线索包装成已证实来源。

## 触发边界

### 触发

在研究变量或目标构念已经明确时，用于：

- 判断构念应使用自陈量表、他评、客观指标、行为日志或实验任务；
- 查找成熟量表、短版、中文版本或跨文化修订版；
- 为既定构念生成中英文检索式并比较候选量表；
- 整合问卷并规划预测试、信度、结构效度、收敛效度和区分效度检验；
- 核验用户提供的量表名称、作者、年份、题项数、版本或文献来源。

### 不触发

- 研究问题尚未收敛，无法说清核心构念、研究对象或情境；先帮助澄清问题，但不进入量表推荐。
- 用户需要完整理论建模、研究假设、实验操纵或系统综述，而量表仅是附带需求。
- 纯质性研究不需要标准化测量。
- 已有完整数据，只需统计分析或模型估计。
- 只需一般文献检索、论文润色或期刊投稿建议。
- 临床诊断、人员甄选或高风险决策要求直接给出结论；此类工具须由具备资质的专业人员依适用规范使用。

## 输入与首轮门禁

开始检索前，确认以下信息；一次只补问 1–2 个最关键缺口：

| 项目 | 最低要求 | 缺失时处理 |
|---|---|---|
| 目标构念 | 至少明确自变量和因变量，或明确单个待测构念 | 给 2–3 个相邻构念释义供选择，不替用户决定 |
| 操作化含义 | 说明要测“什么”、不测“什么” | 对相邻概念做边界对照 |
| 人群与情境 | 对象、语言、地区及使用场景 | 标记 `[INPUT NEEDED]` 并追问 |
| 测量目的 | 描述、预测、组间比较、纵向变化或筛查 | 目的不明时不承诺版本适用性 |
| 实施约束 | 时长、题量、授权预算、测量时点 | 约束不明时分别给标准版与短版检索方向 |

只有构念、人群和情境达到可操作化程度后，才进入候选量表检索。中介、调节和控制变量只在用户需要时给出候选，不把建议写成既定模型。

## 核心流程

按“确认 → 判断 → 检索核验 → 整合评估 → 交付复核”推进。用户只需要其中一段时，可停止在对应阶段，但不得跳过该阶段的真实性门禁。

### 阶段 1：确认构念与用途

1. 用一张记录表复述构念角色、操作化定义、人群、情境和测量目的。
2. 区分相邻构念，例如状态与特质、态度与意向、信任与依赖、满意与幸福感。
3. 请用户确认记录；未确认项标记 `[INPUT NEEDED]`。

**阶段输出**：构念确认记录，不擅自补全理论关系。

### 阶段 2：判断测量方式并建立检索地图

1. 逐个构念比较自陈、他评、行为、客观指标和任务测量的适配性。
2. 对适合量表的构念生成英文规范名、中文同义词、排除词和检索式。
3. 依据人群、时间框架、维度结构和用途确定筛选条件。
4. 读取[构念—量表检索地图](references/construct-scale-map.md)，将其中内容视为检索起点，不视为最终推荐。

| 构念 | 推荐方式 | 理由 | 英文检索词 | 中文检索词 | 排除条件 |
|---|---|---|---|---|---|
| `[INPUT NEEDED]` | 量表、行为或组合 | | | | |

**阶段门禁**：客观绩效、真实频次或系统行为优先考虑记录数据；需要主观体验时再用自陈。避免用单一共同来源替代本可获得的客观证据。

### 阶段 3：检索并核验具体量表

需要具体工具时，读取[量表数据库与检索指南](references/scale-databases.md)，至少完成以下证据链：

1. 找到原始开发或首次验证文献，而非只引用博客、题库聚合页或二手论文。
2. 用 DOI、题名、作者和年份交叉核对书目信息。
3. 从原文或正式数据库核对题项数、维度、计分、样本和测量属性；摘要未报告的字段写“原文待核”。
4. 中文版必须定位独立的翻译或跨文化验证来源；“有中文题项”不等于“有经过验证的中文版”。
5. 核对许可、版权、购买或联系作者要求；可检索不代表可自由复制。
6. 记录检索日期、查询式、数据库和稳定链接，使结论可复查。

每个候选量表使用以下证据表：

| 字段 | 要求 |
|---|---|
| 正式名称与版本 | 与来源原文一致；短版、修订版分开记录 |
| 开发者与年份 | 至少两项书目字段交叉核对 |
| 原始文献 | 完整题名、期刊、年份、DOI 或稳定链接 |
| 测量对象 | 人群、语言、文化和情境 |
| 结构与计分 | 题项数、维度、响应格式、反向题；未核实则标记 |
| 测量属性 | 只报告来源明确给出的指标和对应样本 |
| 中文证据 | 翻译流程、验证样本、结构及等值性证据 |
| 获取与许可 | 开放、订阅、购买、需授权或状态未核 |
| 证据强度 | 已核实、部分核实、仅线索 |

**真实性门禁**：

- 未打开原始来源时，不给出精确题项、信度数值、页码或版权结论。
- 搜索结果摘要只能作为线索；关键元数据回到论文、出版社或正式数据库确认。
- 同名量表、缩写冲突和版本演变分别建记录，禁止拼接不同版本信息。
- 找不到来源时明确写“未检索到可核验原始来源”，不得生成看似完整的引用。

### 阶段 4：比较候选并整合问卷

1. 按内容匹配、人群适配、语言证据、结构证据、负担、可获得性和许可比较 2–3 个候选；证据不足时不强行排序。
2. 保留原量表指导的题干、时间框架、响应格式和计分。未经依据不新增反向题，也不把删题版称为原版。
3. 安排知情说明、筛选题、核心量表、必要的注意力检查和人口学变量；是否随机化或分时测量由研究设计决定。
4. 预测试可理解性、完成时长、缺失模式和技术逻辑。
5. 读取[问卷与心理测量指南](references/survey-psychometrics-guide.md)，按研究目的制定分析计划。

**阶段输出**：候选比较表、问卷结构、计分说明、预测试方案和测量属性评估计划。

### 阶段 5：交付前复核

- [ ] 构念、人群、情境和测量目的已确认。
- [ ] 每个变量都说明为何采用量表或替代方式。
- [ ] 具体量表的名称、版本、作者、年份和来源已核验。
- [ ] 中文版不是由“存在中文题项”推断而来。
- [ ] 题项数、维度、计分和统计值均可回溯到具体来源与样本。
- [ ] 许可状态已说明；未核实处没有默认写成可免费使用。
- [ ] 改写、删题或翻译均标成研究者改编，不冒充原量表。
- [ ] 未通过项已标 `[INPUT NEEDED]`、`[SOURCE NEEDED]` 或“未核实”。

## 文献与量表真实性核验

采用三层证据：

1. **书目层**：Crossref、出版社页面或数据库记录核对 DOI、题名、作者和年份。
2. **内容层**：原文方法、附录或正式手册核对结构、题项和计分。
3. **适用层**：目标语言与人群中的验证研究核对结构、信效度和测量等值性。

冲突时并列记录各来源及版本，优先采用最接近原始出版物的证据，不自行“纠正”为单一答案。只有摘要可见时，输出“摘要可确认”和“全文待核”两栏。

## 期刊建议边界

仅在用户明确要求期刊方向时读取[期刊定位与核验指南](references/journals.md)。按 scope、文章类型和方法契合度给出检索策略；影响因子、分区、开放获取费用和收录状态会变化，必须以用户指定年份的官方来源复核，不写静态排名保证。

## 失败与降级

| 情况 | 降级处理 |
|---|---|
| 构念仍模糊 | 停在阶段 1，提供相邻构念辨析；不列具体量表 |
| 数据库不可访问或遇到付费墙 | 保存可核实书目与摘要，标记全文待核；建议通过机构馆藏、馆际互借或联系作者获取 |
| 原始文献找不到 | 扩展同义词并做引文追踪；仍无结果则只交付检索日志和候选线索 |
| 中文版证据不足 | 不声称存在成熟中文版；给出翻译、回译、认知访谈和目标样本验证计划 |
| 多来源元数据冲突 | 分版本列示，保留冲突字段与链接，不合并统计值 |
| 用户要求复制完整受限题项 | 先核对许可；无法确认授权时提供获取途径、结构摘要或自编题项开发方案 |
| 量表不适合研究目的 | 说明失配点，推荐行为、客观或混合测量；若用户坚持，明确局限 |
| 证据不足但用户要求确定结论 | 给证据等级与未决项，不用确定语气填补缺口 |

## 输出模板

1. **输入确认**：构念、角色、人群、情境、目的、约束。
2. **测量方式判断**：量表与替代方式对照。
3. **检索日志**：日期、数据库、查询式、筛选条件。
4. **候选量表证据表**：逐字段标注来源和核验状态。
5. **候选比较与建议**：说明推荐依据和不确定性。
6. **问卷整合与分析计划**：含计分、预测试和测量属性评估。
7. **来源清单**：优先 DOI、出版社、官方数据库或原始论文链接。
8. **待补信息**：集中列出 `[INPUT NEEDED]` 与 `[SOURCE NEEDED]`。

默认用简体中文和表格输出。不要把“推荐方向”表述成已找到的成熟量表。
