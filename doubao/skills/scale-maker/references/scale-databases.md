## 1. 数据库分工

| 资源 | 适合查什么 | 能确认什么 | 局限与注意 |
|---|---|---|---|
| [APA PsycTests](https://www.apa.org/pubs/databases/psyctests) | 心理测验、量表、问卷及工具记录 | 构念、开发与施测信息；来源有报告时可见信效度和因子信息 | 常需机构订阅；并非每条都有可下载全文或自由许可 |
| APA PsycInfo | 心理学开发、验证和应用论文 | 学科主题词、摘要、文献链 | 通常需订阅；工具全文需另找 |
| Web of Science | 跨学科引文追踪 | 被引关系、相关修订 | 订阅资源；被引量不等于质量或适配性 |
| Scopus | 跨学科文献与引文追踪 | 作者、机构、引文与主题 | 订阅资源；仍需回到原文核对工具细节 |
| PubMed | 医学、健康和临床相关量表 | PMID、摘要、部分全文链接 | 不覆盖所有社会科学工具 |
| [PubMed Central](https://pmc.ncbi.nlm.nih.gov/) | 可公开阅读的生物医学全文 | 方法、附录和参考文献 | 只覆盖入库全文 |
| [Crossref](https://search.crossref.org/) | DOI 与书目核对 | 题名、作者、期刊、年份、DOI | 不负责证明题项、结构或许可 |
| [OpenAlex](https://openalex.org/) | 开放书目与引文线索 | 作品、作者、概念和开放链接 | 元数据可能不完整，关键字段需二次核验 |
| Google Scholar | 广泛发现论文、学位论文与被引版本 | 线索和版本入口 | 元数据质量不一，不作为唯一真实性证据 |
| CNKI、万方、维普 | 中文编制、修订、应用研究 | 中文题名、作者、期刊及部分全文 | 访问权限各异；“应用”论文不等于翻译验证论文 |
| 机构知识库、作者主页 | 手稿、附录、补充材料 | 有时可取得正式稿或题项 | 核对版本，勿把未审稿件当最终出版版 |
| 出版社或期刊官网 | 原始文章与补充材料 | 最接近正式版本的书目信息 | 可能付费；摘要不足以核对所有字段 |

数据库名称、覆盖范围和访问方式可能变化。执行任务时记录实际访问日期与可见字段。

## 2. 检索顺序

### 第一步：发现候选

用构念规范名、同义词、目标人群和 `scale`, `instrument`, `questionnaire`, `measure` 组合检索。先广后窄，不在第一轮限定年份。

### 第二步：定位开发文献

加入 `development`, `construction`, `validation`, `psychometric`；查看候选文献如何引用工具来源，沿参考文献回溯到最早的开发或首次验证论文。

### 第三步：建立版本树

分别搜索：

- 正式全称和简称；
- `short form`, `brief`, `revised`, `version`；
- `translation`, `adaptation`, `cross-cultural validation`；
- 目标语言、人群、地区和场景。

### 第四步：追踪后续证据

正向引文追踪查结构复现、测量等值性、反应性和短版。高被引只能作为阅读优先级线索，不能代替质量评价。

### 第五步：核对获取与许可

在原文、手册、开发者或发行机构页面核对使用、改编、翻译和再分发条件。

## 3. 查询式设计

### 英文发现式

```text
("perceived stress" OR "stress appraisal")
AND (scale OR instrument OR questionnaire OR measure)
AND (development OR validation OR psychometric)
AND (student OR adult)
```

### 原始来源式

```text
"<exact scale name>" AND (development OR original OR validation)
"<scale acronym>" AND <first-author surname>
```

### 目标语言式

```text
("<exact scale name>" OR "<acronym>")
AND (Chinese OR Mandarin OR China)
AND (translation OR adaptation OR validation OR invariance)
```

```text
("<中文构念>" OR "<英文量表名>")
AND (中文版 OR 中文修订 OR 跨文化 OR 信效度 OR 测量等值性)
```

### 排除噪声

- 同名医学检查：增加 `questionnaire` 或目标学科。
- 只想找开发研究：增加题名字段限制或 `development`。
- 缩写冲突：同时加入全称、构念和作者。
- 应用论文过多：增加 `validation`, `factor structure`, `measurement invariance`。

不要机械排除学位论文：它们可提供线索，但最终推荐仍需评估同行评议来源和证据质量。

## 4. 原始量表定位

原始来源应满足尽可能多的特征：

- 明确提出或开发该工具；
- 描述条目生成、筛选、样本和验证过程；
- 给出正式名称、版本、结构或计分；
- 后续论文稳定回引该来源。

核验表：

| 字段 | 来源 A | 来源 B | 判定 |
|---|---|---|---|
| 题名 | 出版社或 DOI 记录 | 数据库记录 | 一致或冲突 |
| 作者 | 原文首页 | Crossref | |
| 年份 | 卷期页 | DOI 记录 | |
| 工具名称 | 原文方法 | 正式数据库 | |
| 题项数与结构 | 方法、附录或手册 | 后续验证 | |
| 计分 | 原文或手册 | 作者页面 | |
| 许可 | 版权页或发行方 | 作者说明 | |

“某篇论文使用该量表”不能自动证明它是原始开发论文。

## 5. 中文版与跨文化版本

中文版检索至少区分：

1. **正式翻译或跨文化适配研究**：有过程、样本和测量属性证据。
2. **论文自行翻译**：只服务该研究，未必形成通用版本。
3. **转载中文题项**：来源链和授权可能不明。
4. **简体、繁体及地区版本**：语言相同不代表文化和计分等价。

记录：译者、年份、翻译方法、样本、地区、语言变体、题项差异、结构、等值性和授权。

跨语言比较时，仅有各组 Cronbach's alpha 不足以证明分数可比；应寻找测量等值性或差异项功能等证据。

## 6. 元数据交叉核验

### 可直接从书目服务核对

- DOI、题名、作者、期刊、年份、卷期页；
- 是否有更正、撤稿或版本更新线索。

### 必须回到内容来源核对

- 题项数、删除题项、维度和载荷；
- 响应格式、时间框架、反向计分；
- 信度、效度及其样本；
- 许可、计分手册和解释界值。

任何统计值都应绑定“版本 + 样本 + 研究”。不要把原研究的 alpha 写成工具的永久属性。

### 引用输出

优先提供 DOI 形式的稳定链接。只有可核验的信息才进入 APA 引用；字段缺失时保留缺口，不猜页码、期号或作者名。

## 7. 获取与许可

把“能读论文”“能看到题项”“能使用”“能翻译或改编”“能再分发”视为不同权限。

核对顺序：

1. 原文版权和补充材料说明；
2. 工具手册、发行方或开发者页面；
3. 数据库记录中的使用限制；
4. 必要时联系作者或权利方。

许可未核实时写：`许可状态未核，使用前联系权利方或查正式手册`。不要因学术用途默认免费，也不要因付费墙推断工具本身收费。

## 8. 检索日志模板

| 字段 | 示例格式 |
|---|---|
| 检索日期 | YYYY-MM-DD |
| 数据库 | APA PsycTests、PsycInfo、CNKI 等 |
| 完整查询式 | 原样保存 |
| 筛选条件 | 语言、人群、年份、文献类型 |
| 命中与初筛数 | 如界面可见则记录 |
| 纳入候选 | 正式名称与来源链接 |
| 排除原因 | 构念不符、版本不明、仅二手引用等 |
| 全文状态 | 已读全文、仅摘要、无法访问 |
| 许可状态 | 已核、待核、需授权 |
| 未决字段 | 题项数、计分、中文版来源等 |

为每个最终候选保留至少一个原始开发来源和一个适用性来源；如果后者不存在，如实说明。

## 9. 常见失败与降级

| 失败 | 调整策略 | 最终表述 |
|---|---|---|
| 构念词过宽 | 加入操作化定义、理论术语和排除词 | 只交付检索方向 |
| 只有二手引用 | 沿参考文献和被引链回溯 | 标为“二手线索，原始来源待核” |
| DOI 与题名不一致 | 到出版社、Crossref 和原文首页比对 | 并列冲突，不拼接 |
| 付费墙 | 查机构馆藏、开放仓储或联系作者 | 标“全文未核” |
| 找不到中文版 | 搜索译者、地区和语言变体 | 不声称存在成熟中文版 |
| 只有自行翻译研究 | 评估翻译过程与样本 | 标“研究内翻译，不等同正式版本” |
| 许可不明 | 查手册、权利方或作者说明 | 不提供完整题项 |
| 版本太多 | 画版本树并绑定各自来源 | 分版本比较 |
