## 1. 从构念到问卷

先定义分数用途，再选择工具：

| 用途 | 关键证据 |
|---|---|
| 描述群体水平 | 内容覆盖、结构、分数分布、解释依据 |
| 预测结果 | 与结局关系、增量效度、过拟合控制 |
| 组间比较 | 跨组测量等值性、抽样与混杂控制 |
| 纵向变化 | 纵向等值性、测量误差、反应性 |
| 个体筛查 | 灵敏度、特异度、阈值来源及目标人群 |

不要因某工具“常用”就跳过用途匹配。筛查量表不能单独充当临床诊断；群体研究的相关结构也不能自动支持个体决策。

## 2. 翻译与文化适配

仅逐字翻译不足以证明文化等价。参考 International Test Commission 的测试翻译与适配框架，规划：

1. **前置条件**：确认构念在目标文化中的含义、原工具权限和适配必要性。
2. **多方翻译**：由语言与领域能力互补的人员独立或协作翻译。
3. **回译或等效审查**：用于发现意义偏移，不把文字一致当唯一标准。
4. **专家评审**：检查相关性、完整性、可理解性和文化适切性。
5. **认知访谈**：让目标受访者解释题意、回忆过程和作答依据。
6. **预测试与修订**：记录每次修改和理由。
7. **确认性证据**：在目标样本评估结构、可靠性和跨语言等值性。
8. **文档化**：保存译者角色、争议、版本和授权。

若无正式验证，只能称“研究者翻译版”或“初步适配版”，不能称“成熟中文版”。

## 3. 问卷编排

### 保持量表完整性

- 保留原说明、时间框架、响应选项和计分方向，除非改编有充分依据。
- 删题、改写、改变响应级数或把状态说明改成特质说明，都可能改变分数含义。
- 不为“平衡”而自行新增反向题；反向措辞可能引入方法因子和理解负担。
- 多个工具的响应格式不同可保留原格式，并在界面上清晰分块。

### 推荐结构

1. 知情说明与同意；
2. 必要的资格筛选；
3. 与研究目的直接相关的核心测量；
4. 次要构念或控制变量；
5. 合理且不侵犯参与者的质量检查；
6. 人口学项目与结束说明。

题序随机化、区块随机化和时间分离应由假设、操作需求和参与者体验决定，不是固定要求。敏感问题可后置，并允许“不愿回答”。

### 时长估计

不要用固定“每题几秒”替代实际预测试。报告目标样本的中位完成时长、分布和异常值规则；开放题、矩阵题、移动端显示和语言难度都会改变耗时。

## 4. 预测试

分两层：

### 可用性与理解

- 认知访谈检查题意、回忆期和选项映射；
- 检查跳转、必答、移动端、无障碍和错误提示；
- 记录完成时长、遗漏、直线作答和反馈；
- 不根据很小的便利样本过度解释信效度。

### 初步测量检查

- 分布、天花板或地板效应；
- 项目间关系和项目—总分关系；
- 反向题编码是否正确；
- 因子模型是否与版本理论一致；
- 任何删题决定都保留理论和统计依据，并计划独立样本复核。

## 5. 信度与测量误差

### 内部一致性

Cronbach's alpha 和 omega 反映特定假设下的内部一致性，不是量表质量的全部。内部一致性应在结构基本单维或各分量表结构有依据后解释。

报告：

- 版本、样本、分量表；
- 指标及区间估计；
- 使用的估计方法和缺失处理；
- 结构证据。

不要把 `alpha ≥ .70` 当普遍且充分的通过线。阈值取决于用途、研究阶段、项目数和决策风险；高 alpha 也可能来自项目冗余。

### 重测信度

间隔应足以减少记忆，又不能长到构念真实改变。对稳定构念可用 ICC 等指标；明确模型、类型、单次或平均测量及一致性或绝对一致定义。

### 测量误差

按设计报告标准测量误差、最小可检测变化或一致性界限。纵向解释需区分真实变化和误差。

## 6. 效度与因子结构

效度是对分数解释和用途的证据积累，不是工具一次性“拥有”的标签。

### 内容效度

检查项目对构念的：

- 相关性；
- 全面性；
- 可理解性。

证据来自目标人群和内容专家，而不只来自统计模型。COSMIN 方法把内容效度视为核心测量属性之一。

### 结构效度

- 探索性分析适合结构不确定或新开发阶段；
- 验证性因子分析用于检验先验模型；
- 有序分类题项需选择与数据性质相符的相关矩阵和估计方法；
- 报告载荷、残差、因子相关、拟合指标和模型修改依据。

不要机械套用单一拟合阈值。CFI、TLI、RMSEA、SRMR 和卡方受样本、模型、估计方法与误设影响，应结合理论、残差和替代模型解释。

### 收敛与区分证据

可使用预先定义的相关或组间差异假设。CR、AVE、Fornell–Larcker 或 HTMT 可作为特定模型下的补充指标，但不能替代内容和结构证据。

避免在未说明模型、估计方法和标准化方案时给出统一计算结论。

### 效标关系

只有存在合理效标时才谈效标效度。心理构念常无无误差金标准；相关高低必须结合时间、方法和样本解释。

## 7. 跨组与纵向可比性

当比较语言、性别、地区、年龄或时间点时，评估测量等值性或差异项功能。常见 CFA 路径依次考察构型、载荷、截距或阈值及残差约束，但是否需要达到哪一级取决于比较目的。

报告：

- 组别和样本；
- 基线模型；
- 约束顺序；
- 判定依据与敏感性分析；
- 部分等值时释放的参数及理论理由。

不同组各自 alpha 良好，不代表组间均值可比较。

## 8. 共同方法偏差

共同方法偏差应优先通过设计减轻：

- 清晰定义并分离预测与结果测量；
- 在可行时使用不同来源、时间点或方法；
- 保证匿名或保密，降低评价焦虑；
- 减少含混、双重或诱导题；
- 将量表和行为、日志或他评证据组合。

Harman 单因子检验不能单独证明不存在共同方法偏差。统计补充可包括标记变量或方法因子模型，但必须有理论和识别依据。

## 9. 报告模板

### 工具说明

| 字段 | 内容 |
|---|---|
| 构念与用途 | |
| 工具、版本与来源 | |
| 语言与适配来源 | |
| 题项数、维度、响应格式 | |
| 计分与缺失处理 | |
| 许可状态 | |
| 本研究改动 | 无或逐项列出 |

### 测量属性计划

| 属性 | 方法 | 先验假设或判定依据 | 报告项 |
|---|---|---|---|
| 内容效度 | 专家评审、认知访谈 | 相关、全面、可理解 | 样本、流程、修改 |
| 结构效度 | EFA、CFA、IRT 或 Rasch | 理论结构与数据类型 | 估计、载荷、拟合、残差 |
| 内部一致性 | alpha、omega 等 | 分量表结构有依据 | 点估计与区间 |
| 重测可靠性 | ICC 或其他 | 构念在间隔内稳定 | 间隔、模型、区间 |
| 假设检验 | 相关、已知组比较 | 预注册方向与幅度 | 支持比例与不确定性 |
| 跨组可比性 | 多组 CFA 或 DIF | 与比较目的匹配 | 约束、变化、部分等值 |

## 10. 常见误区

| 误区 | 修正 |
|---|---|
| alpha 高即量表有效 | 先确认结构，再综合内容和外部关系证据 |
| AVE 低就自动删题 | 同时审查理论覆盖、载荷、误差与版本完整性 |
| 每个量表都应加反向题 | 尊重原工具设计，不自行制造方法效应 |
| 短版一定更高效 | 比较内容覆盖、结构和目标人群证据 |
| 中文翻译即中文版验证 | 区分翻译、文化适配和心理测量验证 |
| Harman 检验通过即无偏差 | 设计控制优先，统计检验仅补充 |
| CFA 拟合达到固定线即正确 | 结合理论、估计方法、残差和替代模型 |
| 原论文信度可直接用于本样本 | 在当前样本重新估计并绑定版本和分量表 |
