## 1. 使用边界

期刊推荐必须建立在论文主题、研究对象、文章类型、方法和开放获取预算上。不要仅凭量表名称或影响因子推荐。

本文件只提供发现与核验流程，不保证投稿、送审或录用。期刊 scope、费用、收录和指标会变化，最终以投稿当日官方页面为准。

## 2. 先判断稿件类型

| 稿件类型 | 核心贡献 | 优先寻找的期刊特征 |
|---|---|---|
| 新量表开发 | 构念定义、条目生成、内容效度、结构与外部证据 | 明确接收测量、评估或方法论文 |
| 翻译与文化适配 | 文化等价、翻译过程、目标样本测量属性 | 接收跨文化或本地化验证，不把纯翻译视为充分创新 |
| 短版开发 | 降低负担且保持内容和结构 | 接收工具精简，并要求独立验证或信息保留证据 |
| 测量等值性 | 跨组或跨时分数可比 | 关注定量方法、跨文化或目标学科测量 |
| 量表应用 | 用成熟量表回答实质研究问题 | 主题学科期刊，而非专门测量期刊 |
| 系统综述 | 工具或测量属性证据综合 | 接收系统综述，并允许相应协议与报告规范 |

如果论文只是“在一个便利样本中再算一次 alpha”，多数期刊会认为贡献不足。先明确新增证据。

## 3. 期刊发现路径

1. 从最接近的 5–10 篇近期论文记录其发表期刊。
2. 查看原量表开发、重要修订和目标语言验证论文的期刊分布。
3. 在学科数据库按题名或主题检索 `scale development`, `validation`, `measurement invariance`。
4. 访问候选期刊官方 aims and scope、article types 和 author guidelines。
5. 检查近两年是否持续发表同类文章，而不是只看一篇旧文。
6. 建立 3–6 本分层候选，不给“保录期刊”。

不要把出版商自动推荐器输出直接当结论；它只用于生成候选。

## 4. 量表研究的 scope 匹配

对每本期刊回答：

- 主题是否覆盖目标构念和人群？
- 是否接受量表开发、翻译、验证或方法论文？
- 是否要求临床、教育、组织、传播或技术等特定场景？
- 是否接受纯验证研究，还是要求实质理论贡献？
- 方法要求是否与样本量、设计、结构验证和外部效度证据相匹配？
- 是否要求开放数据、材料、注册或特定报告清单？
- 字数、图表、补充材料和匿名审稿规则是否可满足？

### 匹配评分框架

| 维度 | 高匹配 | 中匹配 | 低匹配 |
|---|---|---|---|
| 主题 | 近期连续发表相同主题 | 相邻主题 | scope 不含或明确排除 |
| 文章类型 | 明确列出且有近年实例 | 未明确但有实例 | 明确不接收 |
| 方法 | 数据与证据满足常见要求 | 可补充 | 设计根本不符 |
| 受众 | 读者直接需要该工具 | 部分相关 | 工具对读者价值弱 |
| 实施 | 格式、费用、开放政策可接受 | 需权衡 | 无法满足 |

评分只是比较工具，不能替代编辑判断。

## 5. 官方信息核验

每本候选只从官方期刊或索引来源记录：

| 字段 | 首选来源 |
|---|---|
| Aims and scope | 期刊官网 |
| Article types | 期刊 author guidelines |
| 近期同类论文 | 期刊官网目录、学科数据库 |
| 审稿与伦理政策 | 期刊或出版商政策页 |
| 开放获取选项与费用 | 官方费用页，记录币种和访问日期 |
| Web of Science 收录 | Clarivate Master Journal List |
| Journal Impact Factor | Journal Citation Reports，记录年份 |
| Scopus 收录 | Scopus Sources |
| CiteScore | Scopus Sources，记录年份 |
| DOAJ 状态 | DOAJ 官方记录 |
| 国内分区或评价 | 对应评价体系官方当年版本 |

第三方“期刊查询”页面可作线索，不作为高风险动态字段的唯一来源。

## 6. 动态指标处理

影响因子、CiteScore、分区、费用和审稿周期都会变化。输出时必须写明：

- 指标名称，不把不同指标混称“影响因子”；
- 指标年份和查询日期；
- 官方来源链接；
- 无权限核验时标记“未核实”，不引用搜索摘要中的数字；
- 用户要求某年分区时，使用该年评价体系，不拿当前状态替代历史状态。

审稿周期若只来自投稿者论坛，应标为非官方经验，不写成承诺。

## 7. 风险检查

### 出版真实性

检查：

- 官网域名与出版商是否一致；
- ISSN、编辑委员会和联系方式是否可核；
- 是否在其声称的官方索引中真实存在；
- 费用、同行评议和撤稿政策是否透明；
- 冒用知名期刊名称、克隆网站或异常催缴费迹象。

### 投稿适配风险

- 目标期刊是否把翻译验证视为范围内贡献；
- 样本是否仅来自单一便利来源；
- 是否缺少内容效度、独立验证、外部关系或等值性证据；
- 是否未解决量表版权或翻译授权；
- 是否切分同一研究形成重复投稿或“香肠式发表”。

## 8. 输出模板

### 候选表

| 期刊 | 匹配理由 | 同类文章证据 | 文章类型 | 动态指标核验 | 费用核验 | 风险与缺口 |
|---|---|---|---|---|---|---|
| | | 标题、年份、链接 | | 指标、年份、来源 | 金额、币种、日期或未核 | |

### 推荐分层

- **首选**：scope 与稿件类型直接匹配，方法要求可满足。
- **稳健候选**：受众和主题匹配，但需要调整强调重点。
- **探索候选**：存在相关论文但 article type 或贡献门槛待向编辑确认。

每个推荐附“不确定性说明”，不使用“必中”“保录”或未经证实的录用率。

## 9. 失败降级

| 障碍 | 处理 |
|---|---|
| JCR、Scopus 或国内分区无访问权限 | 不报数字；提供官方入口并标待用户核验 |
| 期刊官网打不开 | 用 DOI 和索引确认期刊身份，但动态字段保留未核 |
| scope 表述含糊 | 查近期同类文章，必要时建议向编辑发送 presubmission inquiry |
| 找不到接受纯验证的期刊 | 重新评估研究贡献与证据，不用不可靠期刊填空 |
| 费用信息冲突 | 并列页面与日期，建议投稿前书面确认 |
| 收录状态冲突 | 以对应索引官方实时记录为准，并记录查询日期 |

## 10. 官方入口
