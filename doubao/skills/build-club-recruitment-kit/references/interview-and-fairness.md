# 社团招新面试与公平性

## 目录

1. 先确认是否需要选拔

## 1. 先确认是否需要选拔

不要把面试当作社团专业化的装饰。人数和资源允许时优先开放报名或体验期。只有岗位存在安全、
技能、场地、设备或培养容量限制时，才设计与限制直接相关的选拔。

确认实际形式：`open_enrollment`、`interview`、`audition`、`portfolio`、`written_test` 或
`mixed`。无法确认时保持 `placeholder`，不要把预测题说成往年真题或内部题。

## 2. 胜任力设计

每项胜任力必须连接到新人会承担的真实任务。建议选 3-5 项：

| 维度 | 可观察定义 | 不应替代为 |
| --- | --- | --- |
| 动机与理解 | 能说明对具体活动或任务的兴趣 | 对社团的夸奖程度 |
| 可靠性 | 能按约定完成、提前沟通风险 | 无条件服从或无限时间承诺 |
| 协作 | 能倾听、分工、处理分歧 | 外向、话多或“合群感” |
| 学习能力 | 能描述学习行动、反馈和调整 | 已有资源、昂贵设备或证书数量 |
| 岗位基础 | 展示与任务相关的作品或练习 | 专业、年级、家庭背景 |
| 安全意识 | 理解活动风险和操作边界 | 身体状况的泛化盘问 |

权重总和建议为 1。岗位基础只在任务确实需要时提高权重，并为零基础岗位提供可完成的小练习。

## 3. 问题结构

默认使用具体经历与情境组合：

```text
考察维度：协作
主问题：请讲一次你和同伴对做法有分歧的真实经历。你当时做了什么？
追问：你如何确认对方的关注点？结果没有达到预期时，你后来做了什么调整？
观察点：能否说明自己的行动、沟通过程和反思。
风险信号：只给抽象态度；把全部责任归给他人；编造无法追溯的结果。
```

允许课程、小组作业、兴趣练习、志愿活动、家庭事务或个人项目。没有社团经历不能直接扣分。
问题应给不同背景的报名者相同机会展示相关行为。

## 4. 评分锚点

默认 1-5 分，不使用“凭感觉”：

| 分数 | 通用锚点 |
| --- | --- |
| 1 | 没有回答问题，或内容与考察维度无关 |
| 2 | 有态度但缺少具体行动，追问后仍无法说明 |
| 3 | 有相关场景和行动，能说明基本结果或反思 |
| 4 | 行动具体，能解释权衡、反馈和调整 |
| 5 | 行动、结果、反思完整，并能迁移到该社团真实任务 |

未知、紧张、表达慢或需要澄清不能自动计为低分。必要时复述问题或给思考时间，但对所有报名者
保持一致。

## 5. 禁止问题

不得询问、推断或评价：

- 民族、宗教、政治观点或组织身份；
- 性取向、恋爱、婚姻、生育计划；
- 家庭收入、父母职业、家庭关系；
- 疾病、残障或不影响任务安全的健康信息；
- MBTI、星座、内向/外向等人格标签；
- 账号密码、身份证、宿舍、精确课表等无关个人信息。

确需确认时间时，只问“这些已公布的固定活动时段是否可参加”；确需确认安全或无障碍时，只说明
具体活动条件并询问需要何种合理支持，不索取诊断。

## 6. 面试执行

1. 所有面试官使用同一题库、顺序原则和评分锚点。
2. 开场说明时长、记录方式、问题数量和提问权利。
3. 每题先独立记录事实，再评分；不要在报名者面前讨论排名。
4. 至少两人评分时，先独立打分，再讨论超过 1 分的差异。
5. 记录只保存与考察维度相关的内容，限制访问和保存周期。
6. 结果通知不公开个人分数、失败原因或淘汰名单；需要反馈时只给一项可行动建议。
