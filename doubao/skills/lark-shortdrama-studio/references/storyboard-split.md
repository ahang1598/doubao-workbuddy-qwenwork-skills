# 分镜拆分规范

## 概述

分镜是连接剧本和视频的中间层。按场次→片段→镜头三级结构拆分，保证视频生成的质量和效率。

---

## 三级拆分结构

```
场次（Scene） → 片段（Clip） → 镜头（Shot）
```

### 场次（Scene）

一个完整的场景段落，通常对应剧本中的一场戏。

**命名方式**：Sc1, Sc2, Sc3...
**时长**：30秒 - 2分钟
**包含**：多个片段

**示例**：
- Sc1 - 周一早晨·牛排消失
- Sc2 - 一周蒙太奇·食物接连消失
- Sc3 - 周日夜晚·冰箱空了·爆发

### 片段（Clip）

一场内的情绪/动作段落，约15秒。是视频生成的基本单位。

**命名方式**：片段1, 片段2...
**时长**：约15秒（12-18秒）
**包含**：3-5个镜头

**为什么按15秒分段**：
- 视频生成工具的最佳时长区间
- 太短（<10秒）：内容太碎，效率低
- 太长（>20秒）：质量不稳定，容易崩坏
- 15秒：平衡质量和效率

**示例**：
- 片段一：发现（成薇打开冰箱→发现牛排不见→疑惑）
- 片段二：确认（问成磊→发微信→看到回复→表情变化）

### 镜头（Shot）

单个镜头，3-5秒。是分镜表的基本单位。

**命名方式**：S001, S002...
**时长**：3-5秒
**包含**：一个画面+一句台词（可选）

---

## 分镜表字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 场次 | Sc1, Sc2... | Sc1 |
| 片段 | 1, 2, 3... | 1 |
| 场景名 | 具体场景 | 成薇家厨房 |
| 画面描述 | 核心画面内容 | 成薇走进厨房，拉开冰箱门 |
| 时长(秒) | 单个镜头时长 | 5 |
| 景别 | 远景/全景/中景/近景/特写/主观视角 | 中景 |
| 运镜 | 固定/推/拉/摇/移/跟/升降 | 固定 |
| 台词 | 角色台词 | "你动那块牛排了？" |
| 音效 | 环境音/动作音 | 冰箱门打开声 |
| 关联资产 | 该镜头涉及的角色+场景+道具 | 成薇、厨房 |

## 拆分原则（从 Toonflow 继承）

### 1. 台词零删改

分镜师只设计画面，不做台词二次创作。
- 原文有什么台词就用什么台词
- 不增删、不改写、不润色
- 即使台词有问题，也只标注，不修改

### 2. 缺资产不审核

资产未确认前，不进入分镜审核阶段。
- 角色设定图未确认 → 不拆角色相关分镜
- 场景设定图未确认 → 不拆场景相关分镜
- 所有核心资产确认后 → 才开始拆分镜

### 3. 人物外观交给图片

分镜提示词不写服装/发型/长相，用参考图保证一致性。
- 不在画面描述里写"穿着白色衬衫的女子"
- 而是关联"成薇"角色资产，用参考图控制外观
- 提示词只写动作和情绪，不写外貌

### 4. 禁光影色调词

特殊光照效果走场景衍生资产，不在分镜提示词里写。
- 不写"夕阳的余晖洒在脸上"
- 不写"蓝色的冷光照亮房间"
- 这些应该通过不同时间/氛围的场景资产来实现

### 5. 音效禁配乐

仅环境音+动作音，配乐后期加。
- 环境音：风声、雨声、街道嘈杂声
- 动作音：开门声、脚步声、物品碰撞声
- 不加背景音乐描述（BGM 后期配）

### 6. 片段≤15秒

保证视频生成质量。
- 每个片段控制在15秒左右
- 超过15秒的内容拆成多个片段
- 宁可多拆几段，也不要一段太长

### 7. 长台词必须拆镜

每镜换视角/景别。
- 一句长台词不要用一个固定镜头到底
- 每句话或每个停顿换一个角度
- 可以在说话人、听话人、反应镜头之间切换

### 8. 在场人物不消失

连续性原则。
- 一个场景里出现的人物，后面的镜头里不能无故消失
- 如果人物离开，要有离开的动作镜头
- 保持空间逻辑一致

## 拆分流程

### 第一步：通读剧本，划分场次

1. 通读完整剧本
2. 按场景/时间/地点划分场次
3. 给每个场次命名（Sc1, Sc2...）
4. 估算每场时长

### 第二步：场次内划分片段

1. 按情绪/动作段落划分片段
2. 每个片段约15秒
3. 给每个片段命名（片段一：发现）
4. 估算每段时长

### 第三步：片段内拆分镜头

1. 按画面切换拆分镜头
2. 每个镜头3-5秒
3. 标注景别、运镜、台词、音效
4. 关联对应的资产（角色+场景）

### 第四步：写入分镜库

1. 批量创建分镜记录
2. 每条记录关联：所属项目、所属剧本、关联资产
3. 更新剧本库的"关联分镜"字段
4. 更新项目看板的"分镜数"

## 景别参考

| 景别 | 说明 | 适用场景 |
|------|------|---------|
| 远景 | 人物很小，环境为主 | 开场、转场、宏大场景 |
| 全景 | 人物全身，环境可见 | 人物入场、动作展示 |
| 中景 | 人物半身（膝盖以上） | 对话、日常动作 |
| 近景 | 人物胸部以上 | 表情、情绪反应 |
| 特写 | 局部（脸/手/物品） | 强调细节、情绪高潮 |
| 主观视角 | 角色的视角 | 代入感、发现线索 |

---

## 运镜参考

| 运镜 | 说明 | 适用场景 |
|------|------|---------|
| 固定 | 镜头不动 | 对话、静态场景 |
| 推 | 镜头向前推进 | 强调、聚焦、进入场景 |
| 拉 | 镜头向后拉开 | 展示环境、结束场景 |
| 摇 | 镜头左右/上下摇动 | 展示空间、跟随动作 |
| 移 | 镜头平行移动 | 跟随人物移动 |
| 跟 | 镜头跟随主体 | 动作场景、追逐 |
| 升降 | 镜头上下移动 | 展示高度、气势 |

---

## 最佳实践

1. **先分场次，再分片段，最后拆镜头**，从上到下逐步细化
2. **每个镜头只写一个核心动作**，不要堆太多内容
3. **台词和画面要匹配**，谁说话镜头给谁（或给反应）
4. **注意节奏变化**，不要全是中景对话，要有景别变化
5. **关联资产要准确**，每个镜头关联用到的角色和场景
6. **时长估算要合理**，不要太长或太短
7. **音效要具体**，写"冰箱门打开声"而不是"声音"
