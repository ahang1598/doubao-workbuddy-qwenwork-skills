# 多维表格结构设计

## 概述

每个短剧项目一个独立多维表格，包含四张核心表，两两双向关联。

```
项目看板 ←→ 剧本库 ←→ 分镜库 ←→ 资产库
```

---

## 表1：项目看板

### 用途
项目总览、进度追踪、多项目管理。

### 字段设计

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 项目编号 | 自动编号 | PRJ001 格式 |
| 项目名称 | 文本 | 项目全称 |
| 项目状态 | 单选 | 筹备中/制作中/审核中/已完成/已暂停 |
| 总进度(%) | 数字 | 0-100 |
| 题材 | 单选 | 修仙/都市/古装/现代/悬疑/甜宠/家庭/其他 |
| 剧本数 | 数字 | 关联剧本数量 |
| 分镜数 | 数字 | 关联分镜数量 |
| 资产数 | 数字 | 关联资产数量 |
| 视频数 | 数字 | 已生成视频数量 |
| 开始时间 | 日期 | 项目启动时间 |
| 预计完成时间 | 日期 | 预计交付时间 |
| 项目简介 | 文本 | 项目概述 |
| 备注 | 文本 | 其他说明 |
| 关联剧本 | 关联→剧本库 | 双向关联 |

### 进度参考节点

| 阶段 | 进度 | 产出 |
|------|------|------|
| 项目搭建 | 5% | 四表+关联 |
| 剧本入库 | 10% | 剧本记录+文档链接 |
| 资产完成 | 20% | 角色三视图+场景+道具 |
| 分镜完成 | 40% | 全部分镜表 |
| 视频50% | 60% | 一半场次的视频 |
| 视频全部完成 | 90% | 所有视频片段 |
| 审核修改完成 | 100% | 成片交付 |

## 表2：剧本库

### 用途
剧本管理、状态追踪、文档入口。

### 字段设计

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 剧本编号 | 自动编号 | P001 格式 |
| 剧本名称 | 文本 | 剧本全称 |
| 题材 | 单选 | 同项目看板 |
| 集数/章节 | 文本 | 如"三章"、"12集" |
| 字数 | 数字 | 估算字数 |
| 状态 | 单选 | 待拆分/拆分中/已拆分/制作中/已完成 |
| 飞书文档链接 | 文本 | 原文文档 URL |
| 简介 | 文本 | 剧情概要 |
| 备注 | 文本 | 其他说明 |
| 所属项目 | 关联→项目看板 | 双向关联 |
| 关联分镜 | 关联→分镜库 | 双向关联 |
| 关联资产 | 关联→资产库 | 双向关联 |

---

## 表3：分镜库

### 用途
分镜管理、视频生成任务、视频产出。

### 字段设计

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 镜号 | 自动编号 | S001 格式 |
| 场次 | 文本 | Sc1, Sc2, ... |
| 片段 | 数字 | 1, 2, 3, ...（同一场内分段） |
| 场景名 | 文本 | 具体场景名称 |
| 画面描述 | 文本 | 核心画面内容 |
| 时长(秒) | 数字 | 单个镜头时长 |
| 景别 | 单选 | 远景/全景/中景/近景/特写/主观视角 |
| 运镜 | 单选 | 固定/推/拉/摇/移/跟/升降 |
| 台词 | 文本 | 角色台词 |
| 音效 | 文本 | 环境音/动作音 |
| 视频状态 | 单选 | 待生成/生成中/已生成/失败 |
| 视频文件 | 附件 | 生成的视频文件 |
| 备注 | 文本 | 其他说明 |
| 所属项目 | 关联→项目看板 | 双向关联 |
| 所属剧本 | 关联→剧本库 | 双向关联 |
| 关联资产 | 关联→资产库 | 该镜头涉及的角色+场景+道具 |

### 三级拆分结构

```
场次（Scene） → 片段（Clip） → 镜头（Shot）
```

- **场次**：完整场景段落，如"Sc1 - 周一早晨·牛排消失"
- **片段**：情绪/动作段落，约15秒，如"片段一：发现"
- **镜头**：单个镜头，3-5秒

## 表4：资产库

### 用途
视觉资产管理、复用、一致性保障。

### 字段设计

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 资产编号 | 自动编号 | A001 格式 |
| 资产类型 | 单选 | 角色/场景/道具 |
| 资产名称 | 文本 | 资产名称 |
| 描述 | 文本 | 详细描述 |
| 参考图 | 附件 | 设定图 |
| 风格 | 单选 | 国风二次元/写实/3D/现代都市/其他 |
| 视图 | 单选 | 正面/侧面/背面/四分之三侧面/头像特写/全身立绘/全景 |
| 状态 | 单选 | 待生成/已生成/已确认/废弃 |
| 备注 | 文本 | 其他说明 |
| 所属项目 | 关联→项目看板 | 双向关联 |
| 关联剧本 | 关联→剧本库 | 双向关联 |
| 关联分镜 | 关联→分镜库 | 双向关联 |

### 资产分类

**角色资产**：
- 每个角色生成三视图（正面/侧面/背面）
- 主要角色和次要角色都要有设定图
- 角色之间必须有明显视觉区分

**场景资产**：
- 每个主要场景一张全景概念图
- 标注氛围、时间、光线

**道具资产**：
- 核心道具单独生成设定图
- 普通道具可在场景中体现

## 关联设置

四张表两两之间都要设置关联（双向）：

| 关联对 | 字段名 | 关联表 |
|--------|--------|--------|
| 项目→剧本 | 关联剧本 | 剧本库 |
| 剧本→项目 | 所属项目 | 项目看板 |
| 剧本→分镜 | 关联分镜 | 分镜库 |
| 分镜→剧本 | 所属剧本 | 剧本库 |
| 剧本→资产 | 关联资产 | 资产库 |
| 资产→剧本 | 关联剧本 | 剧本库 |
| 分镜→资产 | 关联资产 | 资产库 |
| 资产→分镜 | 关联分镜 | 分镜库 |
| 项目→分镜 | （通过剧本间接关联） | - |
| 项目→资产 | （通过剧本间接关联） | - |
| 分镜→项目 | 所属项目 | 项目看板 |
| 资产→项目 | 所属项目 | 项目看板 |

**注意**：飞书多维表格的 link 字段默认是单向的（bidirectional: false），不会自动生成反向关联。需要两边都手动创建关联字段并填充数据。

---

## 初始化流程

1. 新建 Base
   ```bash
   lark-cli base +base-create --name "项目名称"
   ```

2. 创建四张表（项目看板、剧本库、分镜库、资产库）

3. 为每张表创建字段（按上表设计）

4. 创建关联字段（两两双向）

5. 删除新建 Base 时自动创建的默认表

6. 录入项目信息到项目看板

7. 录入剧本信息到剧本库，关联到项目
