# 资产生成规范

## 概述

资产是短剧创作的视觉基础。先确认资产，再做分镜和视频，保证角色和场景的一致性。

**资产类型**：角色、场景、道具

---

## 角色资产

### 三视图规范

每个角色生成三张视图：
- **正面**：正脸全身立绘
- **侧面**：侧脸全身立绘
- **背面**：后背全身立绘

三张图保持服装、发型、体型完全一致，只改变视角。

### 提示词模板

```
[风格]风格，[题材]人物设定。一位[年龄]左右的[性别]，[角色名]，[身份]。
[外貌特征描述]。穿着[服装描述]。[气质描述]。
全身立绘，[视图]视角，纯白背景。[风格]风格。
```

### 风格选项

**国风二次元**（修仙、古装题材）：
- 飘逸的服饰
- 二次元画风
- 精致的五官
- 古风发型和饰品

**写实/现代都市**（家庭、都市题材）：
- 真实质感
- 现代服装
- 自然的五官比例
- 生活化的造型

### 差异化原则

角色之间必须有明显的视觉区分，避免"标准帅哥脸"/"标准美女脸"：

- **发型**：长度、颜色、样式要有差异
- **服装**：颜色、款式、风格要有差异
- **体型**：高矮胖瘦要有差异
- **气质**：眼神、表情、姿态要有差异
- **年龄**：不同年龄段的角色要有明显年龄感

### 生成步骤

1. 先生成正面视图，确认角色形象
2. 用户确认后，生成侧面和背面视图
3. 三视图全部入库，关联到剧本和项目
4. 更新项目资产统计

### 图片参数

- **尺寸**：1536 × 2048（3:4 全身立绘）
- **背景**：纯白背景，便于后期处理
- **视角**：全身立绘，正面/侧面/背面

---

## 场景资产

### 全景概念图

每个主要场景生成一张全景概念图，用于：
- 统一场景氛围
- 作为视频生成的参考图
- 保证场景一致性

### 提示词模板

```
[风格]风格，[题材]场景设定。[场景描述，包含布局、光线、氛围]。
全景视角，[风格]风格。
```

### 场景要素

描述场景时要包含：
- **空间布局**：房间结构、家具位置
- **光线氛围**：自然光/人工光、明亮/昏暗
- **时间感**：早晨/中午/傍晚/夜晚
- **情绪基调**：温馨/紧张/压抑/欢快

### 图片参数

- **尺寸**：2048 × 2048（1:1 全景）
- **视角**：全景视角

---

## 道具资产

### 核心道具

只有核心道具才需要单独生成设定图：
- 反复出现的重要道具
- 有特殊功能或象征意义的道具
- 需要特写镜头的道具

普通道具可以在场景图中体现，不需要单独生成。

### 提示词模板

```
[风格]风格，道具设定。[道具描述，包含外观、材质、细节]。
正面视角，纯白背景，细节清晰。[风格]风格。
```

### 图片参数

- **尺寸**：1024 × 1024（1:1 道具特写）
- **背景**：纯白背景

---

## 资产入库流程

1. **生成图片** → 下载到本地工作目录

2. **创建资产记录**
   ```bash
   lark-cli base +record-batch-create --base-token <base_token> --table-id <资产库table_id> --json '{
     "create_records": [{
       "资产类型": "角色",
       "资产名称": "角色名",
       "描述": "...",
       "风格": "...",
       "视图": "正面",
       "状态": "已生成",
       "所属项目": ["<项目record_id>"],
       "关联剧本": ["<剧本record_id>"]
     }]
   }'
   ```

3. **上传参考图**
   ```bash
   lark-cli base +record-upload-attachment --base-token <base_token> --table-id <资产库table_id> --record-id <record_id> --field-id "参考图" --file <本地文件路径>
   ```

4. **关联到剧本** → 更新剧本库的"关联资产"字段

5. **更新项目统计** → 更新项目看板的"资产数"

---

## 资产确认流程

1. 向用户展示所有资产设定图（角色+场景+道具）
2. 用户提出修改意见
3. 重新生成不满意的资产
4. 全部确认后，生成角色三视图（侧面+背面）
5. 三视图全部入库
6. 更新资产状态为"已确认"

---

## 最佳实践

1. **角色设定图要明确差异化特征**，否则容易生成"标准脸"
2. **三视图分别生成**，保持提示词一致，只改视图描述
3. **场景图要包含光线和氛围描述**，视频生成时参考效果更好
4. **道具不要太多**，只做核心道具，避免过度设计
5. **资产确认后再做分镜**，否则后期改资产会导致大量返工
6. **命名要规范**，角色名+视图，场景名+视角，道具名
