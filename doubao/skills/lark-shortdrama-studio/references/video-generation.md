# 视频生成规范

## 概述

按片段生成视频，每段约15秒。使用参考图保证角色和场景的一致性。

---

## 生成方式

### 按片段生成（推荐）

每个片段约15秒，作为一个视频输出。

**为什么不按单个镜头生成**：
- 太碎，效率低
- 每个镜头都要单独生成，耗时长
- 镜头之间的衔接不自然

**为什么不按整场生成**：
- 太长，质量不稳定
- 超过20秒后画面容易崩坏
- 角色容易漂移

**为什么15秒最合适**：
- 视频生成工具的最佳质量区间
- 足够展示一个完整的情绪/动作段落
- 质量稳定，效率高

---

## 工具选择

### image_to_video（推荐）

使用参考图生成视频，保证角色和场景一致性。

**适用场景**：
- 有角色设定图的场景
- 需要保证角色一致性的镜头
- 有场景设定图的场景

**优点**：
- 角色一致性好（用参考图控制）
- 场景还原度高
- 质量稳定

### text_to_video

纯文字生成视频，不需要参考图。

**适用场景**：
- 纯空镜（没有角色的场景）
- 抽象/概念性画面
- 没有对应资产的临时镜头

**优点**：
- 灵活，不需要参考图
- 适合创意性画面

**缺点**：
- 角色一致性差
- 形象容易漂移

---

## 参考图使用

### 参考图选择原则

每个片段的视频使用该片段涉及的角色+场景作为参考图。

**参考图数量**：2-3张
- 主要角色（1-2个）
- 场景（1个）

**不要传太多参考图**：
- 太多参考图会互相干扰
- 2-3张效果最好
- 最多不超过5张

### 参考图优先级

1. **角色正面图**：最常用，保证角色形象
2. **场景全景图**：保证场景环境
3. **角色侧面/背面图**：需要特定角度时用
4. **道具图**：有道具特写时用

## 提示词编写

### 提示词结构

```
[风格]风格，[题材]。[画面描述，把该片段的核心动作/情绪串起来]。
镜头[运镜描述]，氛围[情绪基调]。
```

### 编写要点

1. **风格开头**：明确风格（写实/国风二次元等）
2. **核心动作**：把片段的主要动作串起来
3. **情绪氛围**：描述整体情绪基调
4. **镜头运动**：描述运镜方式
5. **不写外貌**：角色外貌交给参考图，提示词只写动作和情绪

### 示例

**片段：发现**
```
写实风格，现代都市家庭剧。早晨的厨房，阳光从窗户照进来。
一位年轻女子走进厨房，走到冰箱前，伸手拉开冰箱门。
她在冰箱里翻找了一下，然后停住了，眉头微微皱起，眼神疑惑。
她转头看向画面外，开口说话。
镜头缓慢推进，氛围平静但带着一丝疑惑。
```

## 视频参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 比例 | 9:16 | 竖屏短剧标准 |
| 时长 | 15秒 | 每段时长 |
| 工具 | image_to_video | 带参考图 |
| 分辨率 | 720x1280 | 9:16 对应分辨率 |

### 其他比例选项

- **16:9**：横屏，适合 YouTube、B站
- **1:1**：方形，适合 Instagram 帖子
- **3:4**：竖版，适合小红书
- **21:9**：宽屏，电影感

## 生成流程

### 第一步：准备

1. 确认分镜已拆分完成
2. 确认对应资产已生成并入库
3. 按片段组织提示词和参考图

### 第二步：生成

1. 调用 image_to_video 生成
2. 每次最多生成 2 个视频
3. 等待生成完成

### 第三步：下载

1. 下载视频到本地工作目录
2. 命名规范：`项目名_场次_片段.mp4`
   - 示例：`family_sc1_clip1.mp4`

### 第四步：入库

1. 上传到分镜库（该片段的第一个镜头记录的"视频文件"字段）
2. 更新视频状态为"已生成"
3. 更新项目看板的"视频数"和"总进度"

### 第五步：确认

1. 向用户展示视频
2. 收集反馈
3. 不满意则调整提示词/参考图，重新生成

## 质量问题与调整

### 角色不一致

**问题**：视频里的角色和设定图不像

**调整方法**：
1. 确保传入了角色参考图
2. 参考图用正面图，效果最好
3. 提示词里不要描述角色外貌，交给参考图
4. 可以多传几张不同角度的角色图

### 场景不对

**问题**：视频里的场景和设定图不一样

**调整方法**：
1. 确保传入了场景参考图
2. 提示词里描述场景的关键特征
3. 可以把场景图作为主要参考图

### 动作不自然

**问题**：人物动作僵硬或不自然

**调整方法**：
1. 简化动作描述，不要太复杂
2. 减少同时发生的动作数量
3. 用更自然的动作描述
4. 缩短时长，降低复杂度

### 画面崩坏

**问题**：视频后半段画面崩坏

**调整方法**：
1. 缩短时长，从15秒降到10秒
2. 减少画面中的元素数量
3. 简化场景和动作
4. 拆成多个更短的片段

---

## 最佳实践

1. **一定要用参考图**，纯文字生成的角色一致性很差
2. **参考图2-3张最佳**，太多会互相干扰
3. **提示词只写动作和情绪**，外貌交给参考图
4. **15秒是黄金时长**，质量和效率的平衡点
5. **一次生成2个**，不要太多，避免超时
6. **生成后及时下载入库**，避免链接失效
7. **不满意就调整重生成**，不要将就用
8. **命名要规范**，方便后期查找和管理
