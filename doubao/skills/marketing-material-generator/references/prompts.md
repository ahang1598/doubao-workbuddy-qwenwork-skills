# 各环节提示词模板

## 图像精修师

**任务**：生成标准化产品正视图（白底精修）

**提示词模板**：
```
作为智能产品摄影棚的首席精修师，对这张{产品名称}图片进行高级精修处理：
1. 高精度识别{产品名称}主体，确保完美分离，移除任何非产品元素
2. 提取最能展现其全貌的标准正视图，如非正视则进行视角矫正
3. 将产品置于纯白色背景（HEX: #FFFFFF）上
4. 对产品进行专业级光影、色彩、清晰度优化，修复瑕疵，提升材质质感
5. 在产品下方生成符合物理逻辑的柔和自然投影，增强立体感
6. 保持品牌logo和关键细节清晰完整
7. 输出高分辨率、电商级专业产品图效果
```

**参考图**：原始产品图URL
**尺寸**：2048×2048

## 视觉设计师

**任务**：生成4张商品详情页核心图

**图组规划原则**：
从以下类型中选择最适合产品的4种：
- A. 功能原理图（技术/功效卖点）
- B. 材质放大特写图（触感/材质卖点）
- C. 感受/概念意象图（柔软/清凉/透气等感受）
- D. 成分/源头展示图（天然/原料卖点）
- E. 多场景使用图（适用场景展示）
- F. 尺寸/规格对比图

**设计原则**：
- 每张图只讲一个卖点
- 善用视觉比喻（柔软→云朵/羽毛，清凉→冰块/水流）
- 配色从产品本身提取，主色+白/灰/同色系
- 必须叠加简洁中文标题和小图标
- 4张图风格色调必须统一

**提示词模板**：
```
电商详情页{类型}图：{产品名称}居中，{视觉元素描述}，
采用{构图方式}，主色调为{颜色}，干净高级。
叠加醒目的中文标题"{标题文案}"，字体现代简约。
整体光影柔和，产品质感突出，电商详情页风格。
```

**参考图**：精修图URL
**尺寸**：2048×2048，共4张

## 场景搭建师

**任务**：生成2张高写实度场景融合图

**场景选择原则**：
根据产品定位选择1-2个最具代表性的生活场景：
- 居家/办公场景（桌面、书房、客厅）
- 户外/休闲场景（野餐、露营、运动）
- 通勤/出行场景（车内、地铁、街头）
- 礼品/节日场景（礼盒、节日氛围）

**提示词模板**：
```
高写实度{场景类型}场景图：将这只{产品名称}自然放置在{场景描述}，
旁边有{搭配元素}。{光线描述}，在{位置}形成柔和的光影。
整体色调{色调描述}，营造出{氛围描述}的氛围。
产品光影与环境光完美匹配，透视自然，照片级真实感，商业摄影风格。
```

## 动态视觉设计师

**任务**：生成Cinemagraph动态视频

**默认参数**：
- 时长：8秒
- 比例：1:1
- 模型：seedance_2.0_fast
- 基于场景图生成（优先居家/办公场景）

**提示词模板**：
```
高级感Cinemagraph动态照片：画面整体保持静止，只有微妙的动态效果。
{动态效果描述1}，{动态效果描述2}，{动态效果描述3}。
镜头以几乎察觉不到的速度极缓慢推进。
整体氛围{氛围描述}，动态效果极其克制自然，视频可以无缝循环播放。
电影级质感，4K高清，商业产品摄影风格。
```

**常用动态效果**：
- 阳光/光影缓慢移动
- 微风轻拂窗帘/植物
- 空气中微尘/水汽浮动
- 水面/金属表面微光闪烁
- 蒸汽/冷气缓慢流动
- 镜头极缓慢推拉
