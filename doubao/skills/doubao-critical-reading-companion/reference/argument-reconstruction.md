# 论证重建规范

## 目标

把散落的文本内容重建为可审查的论证链：结论 → 关键理由 → 证据 → 推理连接 → 隐藏前提 → 成立边界。重建的目的不是找错，而是让作者真正的说服路径变清楚。

## 核心论点卡

完整模式对影响总判断的核心论证逐条建立论点卡。每张卡必须包含：认识状态、结论、原文定位、理由、证据、证据类型、推理连接、隐藏前提和成立边界。原文没有提供的环节明确写“原文未提供”，不要替作者悄悄补齐后再评价其推理完整。

原文定位使用 PDF 页码、标题与段落，或 8—20 字可搜索原文短语。一个定位应让读者能够快速返回原文核对，不使用“文章前半部分”“作者提到”等模糊描述。关键引语与数据直接抽取精确页码和上下文短语，避免按章节推算错误页码。

## 识别对象

核心问题是文章试图回答的主要问题。核心结论是作者希望读者接受的判断、解释、预测或行动建议。关键理由是支撑核心结论的主要依据。推理连接说明理由为什么能够推出结论。隐藏前提是作者没有明说但论证成立所依赖的条件。成立边界说明结论适用的对象、时间、地点和条件。

## 证据分类

证据类型至少区分：一手数据、权威文件、原始记录、二手报道、专家判断、匿名转述、个案、作者观察、历史类比、预测，以及原文未提供。必要时补充更准确的类型。

“原文出现了某句话”只能证明作者或信源作出过该陈述，不等于陈述内容已被外部证实。作者自述、匿名企业家转述、经验观察、历史类比和预测可以参与论证，但评价时必须说明它们能支持什么、不能支持什么。只有经过独立外部来源核验的内容才能标为外部验证通过。

## 认识状态

“原文陈述”只用于作者直接说出的内容，并附原文定位。“合理重建”用于原文未完整说出但可由上下文推出的连接和前提。“分析评价”用于对证据和推理的判断。“增强建议”用于为强化论证额外提出的内容，不能冒充作者原意。“外部验证通过”只用于有可访问来源支撑且记录了来源信息的核查结果。

## 重建要求

先复述作者最强合理版本，再进入评价。不要只挑选作者最弱表达攻击。不要把作者未讨论的所有问题都视为缺陷；只有遗漏会实质影响核心结论时，才作为完整性问题呈现。

每项重要批评按“原文定位 → 具体推理断点 → 为什么影响结论 → 影响范围与置信度”的顺序展开。谬误名称只能作为最后的辅助标签，不能替代对推理断点的解释。

论证链可写成自然语言，也可写成结构式表达，例如：“因为 A 和 B，作者认为 C；从 A、B 到 C 依赖推理连接 R 和隐藏前提 P。如果 P 不成立，C 的适用范围将缩小到 S。”
