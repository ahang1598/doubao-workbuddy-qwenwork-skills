# 结论与讨论写作

## 核心原则：重新解释，不重复

讨论部分解释发现的理论含义、与既有研究的关系和适用边界。它不能用新的数据、虚构机制或无法核验的引用补救结果不足。

## 结构顺序

### 第一部分：开篇摘要

用一段话概括核心发现，不重复统计符号。每项发现都应能回溯到结果部分。

### 第二部分：依次讨论研究发现

按假设或研究问题顺序回答：

- 该发现与已有研究一致、矛盾还是构成拓展；
- 哪种理论机制可以解释，但要区分“结果直接支持”和“可能解释”；
- 意外结果有哪些替代解释，还需要什么证据区分。

引用既有研究时必须可核验；不确定时标记 `[CITATION NEEDED]`。

### 第三部分：研究贡献

编号呈现，每个贡献对应具体发现。

#### 理论贡献

1. **边界拓展**：说明理论在何种条件、情境或人群中适用。
2. **机制拆解**：说明研究实际检验并支持了什么机制。
3. **概念整合**：说明哪些原本分离的概念或理论被连接。

不得把未经检验的机制写成“揭示”，也不得把一般性重复检验写成重大理论创新。

#### 实证贡献

说明数据、测量、方法或识别策略相对于已有研究的可核验增量。

#### 实践贡献

指明具体利益相关者和可操作建议，并说明建议依赖的证据与适用范围。

### 第四部分：研究局限与未来研究

每条局限包含：

1. 承认具体弱点；
2. 说明它可能如何影响结论及哪些结论仍然成立；
3. 给出与局限直接对应的未来研究设计。

不要机械排除“样本量”“横截面因果”等局限。是否构成有效局限取决于研究声明、功效、设计与证据。

### 第五部分：凝练核心结论

回到核心困惑和观点，用一至两句话说明材料实际支持的结论。结尾避免煽情和超范围推广。

## 讨论写作要点

- 英文讨论通常用现在时解释含义，用过去时回顾本研究所做的工作。
- 讨论需要与可核验文献对话。
- 不引入未在结果或附录中报告的新数据和分析。
- 不重复结果部分的完整统计数字。
- 使用谨慎措辞区分相关、预测与因果。
- 截图或摘要中无法追溯的实证数字不得进入贡献与实践建议。

## 讨论自检清单

- [ ] 开篇是否准确概括结果？
- [ ] 是否按假设或问题顺序展开？
- [ ] 与既有研究的关系是否有可核验引用？
- [ ] 机制解释是否区分直接证据与推测？
- [ ] 每项贡献是否对应具体发现？
- [ ] 实践建议是否说明对象、证据和适用边界？
- [ ] 局限是否具体，并配对可执行的未来研究？
- [ ] 是否没有引入未报告数据或分析？
- [ ] 是否没有重复或虚构统计数字？
- [ ] 结论是否没有超出研究设计允许的推断？
