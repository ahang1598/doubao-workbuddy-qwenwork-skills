## 一、研究方法（Method）

### 核心原则：完全可审计

方法部分应使其他研究者能够理解并尽可能复现研究。每个操作决策有依据，每个变量可追溯。

### 结构顺序

1. **研究设计（Design）**
   - 实验：设计维度、被试间或被试内、招募平台与随机分配方式；
   - 准实验：DID、IV、RDD 等识别策略与识别假设；
   - 调查或面板：横截面或纵向、抽样方式与时间跨度。
2. **数据与样本（Data and Participants）**
   - 数据来源、抽样框、样本量；
   - 关键人口统计特征；
   - 排除标准与最终分析样本；
   - 实验的事前功效分析及其输入参数。
3. **变量测量（Measures）**
   - 自变量、因变量、中介与调节变量的操作化；
   - 量表来源、题项数、锚点、示例题项和信度；
   - 控制变量及其理论理由；
   - 操纵检查与测量质量。
4. **分析策略（Analytic Strategy）**
   - 模型、估计方法和软件版本；
   - 标准误处理或聚类层级；
   - 效应量与置信区间；
   - 稳健性和敏感性分析计划。

### 因果推断检查

无论设计类型，都检查：

- 是否存在同时影响自变量和因变量的混杂因素；
- 是否误控自变量和因变量的共同结果；
- 是否存在反向因果；
- 样本选择是否造成系统性偏差；
- 实验组在处理前是否具有可比性；
- DID 是否支持平行趋势并报告事件研究；
- IV 是否说明相关性与排他性，并报告第一阶段；
- RDD 是否检查阈值附近连续性、密度与带宽敏感性。

### 方法写作要点

- 英文方法通常使用过去时。
- 量表必须给出可核验来源；自编量表说明开发和验证过程。
- 方法部分不解释结果或展开理论讨论。
- 预注册研究仅在用户提供可核验注册信息时写入编号或链接。
- 若某项检查未执行，不得将“建议执行”写成“已经通过”。

## 二、研究结果（Results）

### 核心原则：按假设顺序，少解读

结果部分说明数据呈现的模式，不承担完整理论解释。按假设顺序汇报，并诚实区分显著、非显著和方向相反的结果。

### 结构顺序

1. 数据清洗与排除；
2. 随机化检查或描述统计；
3. 操纵检查；
4. 预分析和主效应；
5. 中介、调节或异质性分析；
6. 稳健性、敏感性与安慰剂检验。

### 三层汇报结构

每个结果段落依次说明：

1. 白话结论与假设支持情况；
2. 精确统计量，包括统计量名称、自由度、p 值、效应量和置信区间；
3. 具体方向，包括均值、标准差、系数或简单斜率。

**合成格式示例：以下数字仅展示报告格式，禁止作为任何真实研究结果使用。**

> H1 得到支持。处理组的 Y 高于对照组，*M* = `[RESULT NEEDED]`，*SD* = `[RESULT NEEDED]`，*t*(`[df]`) = `[RESULT NEEDED]`，*p* = `[RESULT NEEDED]`，效应量与 95% CI 均待填。

### 中介分析报告内容

在用户统计输出确实包含相应信息时，报告：

- 模型或估计方法；
- Bootstrap 次数；
- 变量编码方式；
- 协变量；
- 各路径系数；
- 间接效应点估计与置信区间。

**结构模板，不含默认数字：**

> 中介分析显示，X 通过 M 对 Y 的间接效应为 `[RESULT NEEDED]`，标准误为 `[RESULT NEEDED]`，95% CI 为 `[RESULT NEEDED]`。直接效应为 `[RESULT NEEDED]`。据此，`[仅按实际结果说明中介类型或不确定性]`。

### 结果写作要点

- 英文结果通常使用过去时。
- 统计符号按目标期刊要求设置斜体。
- p 值精确报告；极小值的表示方式服从目标期刊规范。
- 报告适合分析类型的效应量和置信区间。
- 非显著结果如实报告，不进行显著性包装或掩埋。
- 结果部分通常不引用理论文献，方法来源除外。
- 图表位置和格式服从目标期刊要求；未指定时可采用文先图表后的组织方式。

## 事实与数字约束

1. 逐项将样本量、均值、标准差、系数、检验统计量、自由度、p 值、效应量和置信区间映射到用户提供的表格或统计输出。
2. 换算百分比、边际效应或倍数时，记录原值、公式与舍入方式；无法复算时不写换算结果。
3. 只有截图而没有可读数值来源时，说明“截图中显示”，并请求原始输出；不得将截图中的数字标记为已验证。
4. 统计量之间明显不一致时暂停结论，指出冲突并请用户确认。
5. 缺失数字统一使用 `[RESULT NEEDED]`，不得填入常见值、示例值或推测值。
6. 不能从统计显著性直接推断因果、机制、实践重要性或普遍性。
7. 本文件中的所有结构模板均不是研究证据。

## 方法与结果自检清单

### 方法

- [ ] 研究设计、数据来源、样本和抽样方式是否完整？
- [ ] 排除规则是否预先说明或如实标明为事后决定？
- [ ] 每个变量的操作化和来源是否可追溯？
- [ ] 分析策略、模型和标准误处理是否明确？
- [ ] 识别假设及其关键检查是否被准确报告？
- [ ] 未执行的检查是否没有被写成已通过？
- [ ] 其他研究者能否理解并尽可能复现研究？

### 结果

- [ ] 是否按假设顺序汇报？
- [ ] 每个结果是否包含结论、统计量与方向？
- [ ] 每个数字是否能定位到用户材料或可验证来源？
- [ ] p 值、效应量和置信区间是否按目标规范报告？
- [ ] 中介或调节分析信息是否完整？
- [ ] 非显著与反向结果是否被诚实呈现？
- [ ] 稳健性检验是否只报告实际完成的项目？
- [ ] 是否避免在结果部分做超出数据的理论解释？
