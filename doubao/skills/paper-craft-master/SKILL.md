# 社科实证论文全流程写作

## 基本信息

- 版本：v1.1.0

## 适用范围

### 应触发

在用户需要以下任一能力时使用：

- 基于研究问题、论文草稿、数据分析结果或统计输出起草实证论文全文；
- 起草或修改标题、摘要、引言、文献综述、假设、方法、结果、讨论中的一个或多个章节；
- 诊断量化、实验或准实验论文的结构、论证和学术表达；
- 用户希望先通过问答梳理研究设计、核心困惑、结果和贡献；
- 在不改变数据、结论、引用和专业术语的前提下润色中英文实证论文。

### 不触发

以下请求不使用本 Skill：

- 纯理论论文、质性研究、元分析或非社科实证写作；
- 执行统计分析、清洗数据、估计模型、绘图或复算结果；
- 代查文献但不涉及论文写作，或制作 PPT、海报和教学课件；
- 仅需通用语法校对、翻译或格式转换，且不涉及实证论文结构；
- 用户要求编造数据、统计结果、研究发现或引用。

### 边界

- 本 Skill 负责写作、诊断和材料组织，不替代统计软件、文献数据库或事实核验工具。
- 仅根据用户提供的材料和可验证来源表述事实。不得把示例、截图、常识推断或格式模板当作研究证据。
- 不确定是否属于实证写作时，先确认研究类型、目标章节与现有材料，再决定是否进入工作流。
- 用户同时提出写作与统计计算时，只处理写作部分，并明确统计计算需要独立完成后提供结果。

## 事实与证据门禁

学术写作的可信度依赖可追溯证据，因此在起草、改写和终检时执行以下规则：

1. 不得虚构数据、样本、模型、统计量、结果、机制、引用、DOI、页码或期刊信息。
2. 每个实证数字必须来自用户材料或可验证来源。优先记录来源文件、表号、模型列、页码或链接；换算值还要说明换算依据。
3. 截图只能证明截图中出现过相应文字。截图里的数字若没有原始数据、统计输出或可核对引用，不得写成已验证事实。
4. reference 中的数字与引文示例仅用于展示格式，禁止复制为用户论文的真实结果或真实参考文献。
5. 线索不足时使用占位标记：事实或研究设计用 `[INPUT NEEDED]`，统计结果用 `[RESULT NEEDED]`，引用用 `[CITATION NEEDED]`。
6. 用户要求补全缺失数字或引用时，说明无法可靠补全，并列出需要的原始材料；不得生成“看起来合理”的内容。

## 任务路由

### 判断语言

| 语言 | 判断依据 | 规范 |
|---|---|---|
| 中文 | 用户指定中文、目标为中文期刊或中文学位论文 | 引用格式按用户或目标单位要求；表达润色参考中文规则 |
| 英文 | 用户指定英文或目标为英文期刊 | 引用与时态按目标期刊要求；未指定时参考 APA 7th 与实证写作惯例 |

### 判断任务类型

| 任务类型 | 处理方式 | 按需资源 |
|---|---|---|
| 全文起草 | 执行阶段 0 至 7 | 各章节资源按阶段加载 |
| 单节起草 | 只加载目标章节资源 | 对应章节指南 |
| 开篇写作 | 提炼核心困惑与观点后写标题、摘要或引言 | [opening-craft.md](references/opening-craft.md) |
| 修改诊断 | 对照目标章节清单诊断并改写 | 对应章节指南 |
| 交互式诊断 | 分轮收集信息，输出论文信息卡 | [interactive-diagnosis.md](references/interactive-diagnosis.md) |
| 中文表达润色 | 只改表达，不改学术事实 | [de-ai-rewrite.md](references/de-ai-rewrite.md) |
| 英文表达检查 | 检查时态、引用、统计报告与措辞 | [empirical-style.md](references/empirical-style.md) |

起草任何章节前先读取对应指南。不要为了单节任务加载全部 references。

## 全文起草工作流

### 阶段 0：收集信息并提炼核心问题

从用户材料提取以下信息；不能从材料确认的内容不得推断：

- 核心理论框架；
- 自变量、因变量、中介、调节变量及其操作化；
- 研究设计、样本量、数据来源与分析策略；
- 关键统计结果，包括统计量、自由度、p 值、效应量和置信区间；
- 目标期刊或学位类型、语言和引用格式。

厘清四项核心内容：

1. 核心困惑属于理论冲突、理论与现实冲突，还是现实冲突；
2. 核心观点能否用一句话表达；
3. 既有研究如何处理该困惑，仍遗漏了什么；
4. 理论、实证与实践贡献分别是什么。

用户材料缺失超过 3 项，或用户主动要求引导时，读取 [interactive-diagnosis.md](references/interactive-diagnosis.md)。

### 阶段 1：标题、摘要与引言

读取 [opening-craft.md](references/opening-craft.md)。标题、摘要和引言共享同一核心困惑与核心观点。避免以宏观背景或空泛意义起笔。所有事实、数据和引用都要通过事实与证据门禁。

### 阶段 2：文献综述与假设

读取 [lit-review-guide.md](references/lit-review-guide.md)。按概念和命题组织文献，不按作者名单堆叠。每个假设都要有可追溯的理论和引用支持；引用缺失时保留 `[CITATION NEEDED]`。

### 阶段 3：研究方法

读取 [method-results-guide.md](references/method-results-guide.md)。依次写研究设计、数据与样本、变量测量和分析策略。只写用户材料明确提供的设计与参数，缺失项用 `[INPUT NEEDED]`。

### 阶段 4：研究结果

继续使用 [method-results-guide.md](references/method-results-guide.md)。按假设顺序汇报，区分结论、统计量与具体方向。每个数字必须能定位到统计输出；信息不全时保留 `[RESULT NEEDED]`，不得套用指南中的示例数字。

### 阶段 5：讨论与结论

读取 [discussion-guide.md](references/discussion-guide.md)。解释结果而不重复统计数字；贡献必须与已有发现对应。不能由结果支持的机制解释要标为可能解释，并说明需要验证。

### 阶段 6：表达润色

- 中文论文读取 [de-ai-rewrite.md](references/de-ai-rewrite.md)。只改表达，不改变数据、引用、结论和术语。
- 英文论文读取 [empirical-style.md](references/empirical-style.md)。按目标期刊优先、通用规范补充的顺序检查。

### 阶段 7：终检

- [ ] 核心困惑与核心观点一致；
- [ ] 各章节结构与任务要求一致；
- [ ] 文献综述按概念组织，假设有完整论证链；
- [ ] 方法可审计，结果按假设顺序汇报；
- [ ] 非显著结果被诚实呈现；
- [ ] 贡献与发现逐项对应，局限具体；
- [ ] 所有数字均能定位到用户材料或可验证来源；
- [ ] 所有引用均可核对，缺失引用已标记；
- [ ] 未把格式示例、截图或推断写成真实证据；
- [ ] 缺失项均使用统一占位标记。

## 输出形式

- 全文起草：按章节输出正文，并附 3 至 6 条结构性编辑说明。
- 单节起草：只输出目标章节，不扩写用户未要求的部分。
- 修改诊断：列出结构缺陷、证据缺口和建议改法，再改写用户指定段落。
- 交互式诊断：输出论文信息卡，请用户确认后再写作。
- 对照润色：用户明确要求时使用“原文 / 改写”形式，否则只输出改写稿。
- 任何缺失信息都使用 `[INPUT NEEDED]`、`[RESULT NEEDED]` 或 `[CITATION NEEDED]`。

## 失败与降级

- 材料不足：先列出缺失项；可完成的结构先写，事实位置保留占位标记。
- 目标章节不明确：只追问目标章节、语言和已有材料，不一次加载全部资源。
- 统计结果不完整：只描述可由现有输出支持的结果，其余标记 `[RESULT NEEDED]`。
- 引用不可核验：保留论证骨架并标记 `[CITATION NEEDED]`，不生成作者、年份或 DOI。
- 用户未提供可选范文全文：按方法层面的通用写作范式降级，不声称读过或复现某篇论文。
- 文件不可读或内容截断：说明未读取的范围，请用户重新提供可读文本或对应页，不对缺失部分下结论。
- 请求超出适用范围：简要说明边界，只处理可支持的实证写作部分。
- 用户要求虚构：拒绝虚构，并将对应位置保留为缺失标记。
