# 演示文稿变更与交付检查清单

## 编辑前
- [ ] 已通过 `ppt` 读取最新版本和页面标识。
- [ ] 已确认目标页、保留项、替换/删除项、不做项和交付形式。
- [ ] 重排/覆盖任务已有可回滚副本。

## 编辑后
- [ ] 页数、页序、标题和目录一致。
- [ ] 年份、金额、数量、币种等关键数字与确认口径一致。
- [ ] 正文、备注、隐藏页、母版和关键词残留已按任务范围检查。
- [ ] 没有明显溢出、遮挡、重复页面或整页图片冒充可编辑页面。

## 交付
- [ ] 本地文件通过 `verifier-hub` 和 `artifact-preview`。
- [ ] 链接/文件可打开，使用 Profile 当前交付方式返回。
- [ ] 摘要包含修改范围、总页数、核验项和未确认点。
