## 1. 法条-条款完整性复核（三阶校验）

**目的**：防止遗漏重要条款，确保法条要求全部落实到合同中。

**复核流程**：

**第一阶：法条读取清单 → 合同重点清单**
对照第三步中确定的法条选取范围，确认合同重点清单是否已覆盖所有触发的法条要求：
```
法条清单                          合同重点清单                    覆盖状态
─────────────────────────────────────────────────────────────────────────
个保法第21条（委托处理）    →    处理指示、保密、安全措施         ☑ 已覆盖
个保法第28-32条（敏感信息） →    敏感信息处理条款                 ☑ 已覆盖
个保法第21条第2款（转委托） →    分包控制条款                     ☑ 已覆盖
...
```

**第二阶：合同重点清单 → 最终合同条款**
逐项核对合同重点清单是否已落实为具体条款：
```
合同重点清单                      最终合同条款              落实状态
───────────────────────────────────────────────────────────────
处理指示                    →    第三条 处理目的、方式          ☑ 已落实
保密与安全措施              →    第九条 安全保障措施            ☑ 已落实
分包控制                    →    第十三条 转委托管理            ☑ 已落实
敏感信息处理                →    第X条 敏感个人信息处理         ☑ 已落实
...
```

**第三阶：起草指南必备章节 → 最终合同条款**
对照对应类型起草指南的"必备章节"清单，确认是否全部纳入：
```
必备章节（委托处理）              最终合同条款              纳入状态
───────────────────────────────────────────────────────────────
委托处理关系确认            →    第二条                         ☑ 已纳入
处理目的、方式与处理事项    →    第三条                         ☑ 已纳入
个人信息种类、范围          →    第四条                         ☑ 已纳入
...
```

**复核结果处理**：
- 发现遗漏：立即补充相应条款
- 发现重复：合并或删除冗余条款
- 发现矛盾：调整表述确保一致性

## 2. 基础条款校验

- [ ] 条款之间是否存在角色冲突
- [ ] 是否有重复义务或实质重叠
- [ ] 交叉引用是否准确
- [ ] 是否有无法落地或明显过硬的表述
- [ ] 是否遗漏期限、通知、争议解决、附件效力等基础条款
- [ ] 是否保留了必要例外与合法留存空间
- [ ] 是否将应由一方独立承担的法定义务错误转嫁给另一方
- [ ] 是否存在通过合同条款排除法定强制义务的情形（如排除数据主体权利、排除监管检查权、约定免除共同处理场景下的连带责任）
- [ ] 委托处理协议中是否将委托人的法定义务（如告知、取得同意、PIA）不当转嫁给受托人
- [ ] 涉及"单独同意"的条款是否正确区分了合同授权（甲乙之间）与法定单独同意（处理者对主体）
- [ ] 各角色术语是否分别定义、全文使用唯一名称（受托处理方/子处理者/独立处理者/共同处理者/境外接收方无合并或多种称谓）
- [ ] 安全措施是否误写乙方系统未知的具体数值（扫描频率、修复时限、具体认证或算法），应改为控制目标 + 等效控制 + 【待补】清单
- [ ] 尚未上线或需另行签署协议的活动是否仅保留接口性条款，未预先写入具体责任分配与数据范围
