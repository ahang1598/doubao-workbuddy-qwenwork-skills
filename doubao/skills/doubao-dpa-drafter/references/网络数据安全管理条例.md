## 一、核心术语定义

### 1.1 网络数据

通过网络处理和产生的各种电子数据。

### 1.2 网络数据处理活动

网络数据的收集、存储、使用、加工、传输、提供、公开、删除等活动。

### 1.3 网络数据处理者

在网络数据处理活动中自主决定处理目的和处理方式的个人、组织。

### 1.4 重要数据

特定领域、特定群体、特定区域或者达到一定精度和规模，一旦遭到篡改、破坏、泄露或者非法获取、非法利用，可能直接危害国家安全、经济运行、社会稳定、公共健康和安全的数据。

### 1.5 委托处理

网络数据处理者委托个人、组织按照约定的目的和方式开展的网络数据处理活动。

### 1.6 共同处理

两个以上的网络数据处理者共同决定网络数据的处理目的和处理方式的网络数据处理活动。

### 1.7 单独同意

个人针对其个人信息进行特定处理而专门作出具体、明确的同意。

### 1.8 大型网络平台

注册用户5000万以上或者月活跃用户1000万以上，业务类型复杂，网络数据处理活动对国家安全、经济运行、国计民生等具有重要影响的网络平台。

## 二、网络数据处理者义务

### 2.1 一般安全义务（第9条）

网络数据处理者应当：
- 依照法律、行政法规和国家标准强制性要求，在网络安全等级保护基础上加强防护
- 建立健全网络数据安全管理制度
- 采取加密、备份、访问控制、安全认证等技术措施和其他必要措施
- 保护网络数据免遭篡改、破坏、泄露或者非法获取、非法利用
- 处置网络数据安全事件
- 防范针对和利用网络数据实施的违法犯罪活动
- 对所处理网络数据的安全承担主体责任

### 2.2 产品服务安全义务（第10条）

- 网络产品、服务应当符合相关国家标准的强制性要求
- 发现安全缺陷、漏洞等风险时，应当立即采取补救措施
- 按照规定及时告知用户并向有关主管部门报告
- 涉及危害国家安全、公共利益的，**应当在24小时内**向有关主管部门报告

### 2.3 安全事件应急处置（第11条）

**应急预案要求**：
- 建立健全网络数据安全事件应急预案
- 发生安全事件时，立即启动预案
- 采取措施防止危害扩大，消除安全隐患
- 按照规定向有关主管部门报告

**通知义务**：
对个人、组织合法权益造成危害的，应当及时通知利害关系人：
- 安全事件和风险情况
- 危害后果
- 已经采取的补救措施
- 通知方式：电话、短信、即时通信工具、电子邮件或公告

### 2.4 委托处理与共同处理（第12条）⭐

#### 委托处理

向其他网络数据处理者提供、委托处理个人信息和重要数据的，应当：
- 通过合同等与网络数据接收方约定处理目的、方式、范围以及安全保护义务等
- 对网络数据接收方履行义务的情况进行监督
- 处理情况记录应当**至少保存3年**

**网络数据接收方义务**：
- 履行网络数据安全保护义务
- 按照约定的目的、方式、范围等处理个人信息和重要数据

#### 共同处理

两个以上的网络数据处理者共同决定个人信息和重要数据的处理目的和处理方式的，应当**约定各自的权利和义务**。

### 2.5 数据转移（第14条）

因合并、分立、解散、破产等原因需要转移网络数据的：
- 网络数据接收方应当继续履行网络数据安全保护义务

### 2.6 为国家机关等提供服务（第16条）

为国家机关、关键信息基础设施运营者提供服务，或参与其他公共基础设施、公共服务系统建设、运行、维护的：
- 应当依照法律、法规和合同约定履行网络数据安全保护义务
- 提供安全、稳定、持续的服务
- **未经委托方同意，不得**：
  - 访问、获取、留存、使用、泄露或向他人提供网络数据
  - 对网络数据进行关联分析

## 三、个人信息保护规定

### 3.1 个人信息处理一般规定（第19条）

按照个人信息保护法的规定处理个人信息。

### 3.2 向他人提供个人信息（第21条）⭐

网络数据处理者向其他网络数据处理者提供个人信息的，应当：
- 向个人告知接收方的名称或者姓名、联系方式、处理目的、处理方式和个人信息种类
- 取得个人的**单独同意**

**例外情形**：
- 法律、行政法规规定应当保密或者不需要告知的情形
- 应告知事项发生变化时，应当重新告知

### 3.3 处理敏感个人信息（第22条）⭐

处理敏感个人信息的，应当：
- 取得个人的**单独同意**
- 法律、行政法规规定应当书面同意的，从其规定

### 3.4 个人信息查阅复制权（第23条）

个人请求查阅、复制其个人信息的，网络数据处理者应当：
- 及时提供
- 例外情形：法律、行政法规规定应当保密或者不需要告知的情形

### 3.5 个人信息更正补充权（第24条）

个人发现网络数据处理者处理的个人信息不准确或不完整的，有权请求更正、补充。
网络数据处理者应当：
- 及时核实
- 更正、补充相关信息
- 通知涉及的相关网络数据处理者

### 3.6 个人信息删除权（第25条）

**个人有权请求删除个人信息的情形**：
- 处理目的已实现、无法实现或为实现处理目的不再必要
- 停止提供产品或服务，或保存期限已届满
- 个人撤回同意
- 个人信息处理者违反法律、行政法规或违反约定处理个人信息
- 法律、行政法规规定的其他情形

**网络数据处理者义务**：
- 应当及时删除个人信息或进行匿名化处理
- 通知涉及的相关网络数据处理者

**例外**：
法律、行政法规规定的保存期限未届满，或删除个人信息从技术上难以实现的，应当：
- 停止除存储和采取必要安全保护措施之外的处理

### 3.7 个人信息转移权（第26条）

符合下列条件的，个人请求将个人信息转移至其指定的网络数据处理者：
- 基于个人同意或订立、履行合同作为一方当事人而处理个人信息
- 个人请求转移的个人信息是基于本人同意或本人作为合同一方而提供的

**网络数据处理者义务**：
- 应当为个人转移个人信息提供必要途径
- 处理条件发生变化的，应当及时告知

### 3.8 个人信息处理活动记录（第27条）

网络数据处理者应当：
- 记录下列个人信息处理活动：
  - 处理个人信息的目的、种类、数量
  - 个人信息流向
  - 处理个人信息的方式
  - 个人信息保存期限
  - 个人信息相关投诉和处理结果
- 处理活动记录应当**至少保存3年**

## 四、重要数据安全规定

### 4.1 重要数据识别与目录（第28条）

**重要数据处理者义务**：
- 应当识别其处理的重要数据
- 形成重要数据目录
- 不得泄露重要数据目录

**主管部门职责**：
- 国家网信部门统筹协调有关部门制定重要数据识别指南
- 各地区、各部门按照规定组织确定本地区、本部门以及相关行业、领域的重要数据具体目录

### 4.2 重要数据处理者义务（第29条）⭐

重要数据处理者应当：
- 明确网络数据安全负责人和网络数据安全管理机构
- 网络数据安全负责人应当具备网络数据安全专业知识和相关管理工作经历
- 网络数据安全管理机构应当履行网络数据安全保护责任

**报告义务**：
- 向有关主管部门报送网络数据安全负责人姓名、联系方式等信息
- 信息发生变更的，应当自变更之日起**3个工作日内**重新报送

### 4.3 重要数据安全风险评估（第30条）

**风险评估频次**：
- 每年至少开展一次

**风险评估内容**：
- 重要数据处理活动的开展情况
- 重要数据的种类、数量、流向、保存期限
- 安全保护措施的落实和有效性
- 安全风险和处置情况

**报告要求**：
- 风险评估报告应当网络数据安全负责人签字
- 报送所在地省级网信部门
- 地市级网信部门应当将情况报送省级网信部门

### 4.4 重要数据出境安全评估（第31条）

**需要申报安全评估的情形**：
- 重要数据出境

**不需要申报安全评估的情形**：
- 海关、边防检查、刑侦、航空管理等依法需要向境外提供重要数据的
- 境外军事机关、国际军事组织从境外接收我方军事机关重要数据的

### 4.5 重要数据安全事件报告（第32条）

重要数据处理者：
- 发生重要数据泄露、篡改、丢失等安全事件的，应当立即采取处置措施
- 按规定及时告知可能受到影响的用户
- 按照规定向有关主管部门报告

**报告内容**：
- 重要数据的种类、数量
- 安全事件原因、危害程度
- 可能造成的影响范围
- 已采取的补救措施
- 处置情况

## 五、数据跨境安全规定

### 5.1 网络数据处理者向境外提供个人信息（第35条）

应当遵守下列规定：
- 通过国家网信部门组织的数据出境安全评估
- 按照国家网信部门的规定经专业机构进行个人信息保护认证
- 按照国家网信部门制定的标准合同与境外接收方订立合同，约定双方的权利和义务
- 法律、行政法规或者国家网信部门规定的其他条件

### 5.2 不需要申报安全评估的情形（第36条）

符合下列情形之一的，不需要申报数据出境安全评估：
- 未达到国家网信部门规定数量的个人信息向境外提供
- 不包含个人信息和重要数据的网络数据向境外提供
- 海关、边防检查、刑侦、航空管理等依法需要向境外提供个人信息的
- 境外军事机关、国际军事组织从境外接收我方军事机关个人信息的
- 法律、行政法规、国家网信部门规定的其他情形

### 5.3 跨境传输合同必备条款（第37条）⭐

向境外提供个人信息，合同等文件应当包括以下内容：
- 向境外提供个人信息的目的、方式、范围
- 个人信息的种类、数量
- 境外接收方使用个人信息的目的、方式
- 个人信息在境外的保存地点、期限
- 个人向境外接收方行使个人信息权利的方式和途径
- 境外接收方的义务以及履行义务的保障措施

### 5.4 个人信息保护影响评估（第38条）

**需要开展评估的情形**：
- 向境外提供个人信息

**评估内容**：
- 个人信息处理的目的、方式是否合法、正当、必要
- 个人信息权益受到的影响
- 境外接收方所在国家或地区的个人信息保护政策、法律法规对个人信息权益的影响
- 个人信息保护措施的可行性、有效性

### 5.5 境外接收方的义务（第39条）

- 应当按照约定处理个人信息
- 不得违反约定将个人信息再向第三方提供
- 应当采取必要措施保护个人信息安全

### 5.6 数据跨境安全事件报告（第40条）

向境外提供个人信息或重要数据过程中，发生数据泄露等安全事件的，网络数据处理者应当：
- 立即采取处置措施
- 向所在地省级网信部门报告

### 5.7 境外机构处理境内个人信息（第41条）

在中华人民共和国境外处理中华人民共和国境内自然人个人信息的活动，有下列情形之一的，应当依法在境内设立专门机构或者指定代表，负责处理个人信息保护相关事务，并报送相关个人信息保护情况：
- 以向境内自然人提供产品或服务为目的
- 分析、评估境内自然人行为

## 六、网络平台服务提供者义务

### 6.1 大型网络平台服务提供者定义（第42条）

注册用户5000万以上或月活跃用户1000万以上，业务类型复杂，网络数据处理活动对国家安全、经济运行、国计民生等具有重要影响的网络平台。

### 6.2 一般义务（第43条）

网络平台服务提供者应当：
- 制定平台网络数据安全管理制度
- 对平台内的网络数据处理活动进行监督和管理

### 6.3 大型网络平台特殊义务（第44条）⭐

大型网络平台服务提供者应当：
- 建立健全网络数据安全管理制度
- 建立健全网络平台规则
- 设立独立的社会监督机构
- 发布年度网络数据安全社会责任报告

**社会监督机构职责**：
- 对网络数据处理活动进行监督
- 监督情况应当向社会公开

**停止服务的特别规定**：
停止提供平台服务的，应当：
- 提前6个月向社会公告
- 向有关主管部门报告
- 依法处置网络数据

### 6.4 个人信息保护合规审计（第45条）

大型网络平台服务提供者应当：
- 每年发布个人信息保护社会责任报告
- 接受独立专业机构对其个人信息保护情况的审计
- 审计结果应当向社会公开

### 6.5 禁止性行为（第46条）

网络平台服务提供者不得利用网络数据以及平台规则等从事下列活动：
- 通过误导、欺诈、胁迫等方式处理用户在平台上产生的网络数据
- 无正当理由限制用户访问、使用其在平台上产生的网络数据
- 对用户实施不合理的差别待遇，损害用户合法权益
- 法律、行政法规禁止的其他活动

## 七、法律责任

### 7.1 一般违法行为责任（第55条）

违反第12条、第16-20条、第22条、第40条第1-2款、第41-42条的：
- 责令改正，给予警告，没收违法所得
- 拒不改正或情节严重的：**处100万元以下罚款**
- 可责令暂停相关业务、停业整顿、吊销相关业务许可证或吊销营业执照
- 对直接负责的主管人员和其他直接责任人员：**处1万元以上10万元以下罚款**

### 7.2 国家安全相关违法责任（第56条）

违反第13条（国家安全审查）的：
- 责令改正，给予警告
- 可并处**10万元以上100万元以下罚款**
- 对直接负责的主管人员和其他直接责任人员：可处**1万元以上10万元以下罚款**
- 拒不改正或情节严重的：**处100万元以上1000万元以下罚款**
- 可责令暂停相关业务、停业整顿、吊销相关业务许可证或吊销营业执照
- 对直接负责的主管人员和其他直接责任人员：**处10万元以上100万元以下罚款**

### 7.3 重要数据相关违法责任（第57条）

违反第29条第2款、第30条第2-3款、第31-32条的：
- 责令改正，给予警告
- 可并处**5万元以上50万元以下罚款**
- 对直接负责的主管人员和其他直接责任人员：可处**1万元以上10万元以下罚款**
- 拒不改正或造成大量数据泄露等严重后果的：**处50万元以上200万元以下罚款**
- 可责令暂停相关业务、停业整顿、吊销相关业务许可证或吊销营业执照
- 对直接负责的主管人员和其他直接责任人员：**处5万元以上20万元以下罚款**

### 7.4 其他违法行为责任（第58条）

违反本条例其他有关规定的，由有关主管部门依照《网络安全法》《数据安全法》《个人信息保护法》等法律的有关规定追究法律责任。

### 7.5 从轻减轻处罚情形（第59条）

网络数据处理者存在下列情形的，依照《行政处罚法》规定从轻、减轻或不予行政处罚：
- 主动消除或减轻违法行为危害后果
- 违法行为轻微并及时改正且没有造成危害后果
- 初次违法且危害后果轻微并及时改正

### 7.6 国家机关责任（第60条）

国家机关不履行本条例规定的网络数据安全保护义务的：
- 由其上级机关或有关主管部门责令改正
- 对直接负责的主管人员和其他直接责任人员依法给予处分

### 7.7 民事、行政、刑事责任（第61条）

违反本条例规定：
- 给他人造成损害的，依法承担民事责任
- 构成违反治安管理行为的，依法给予治安管理处罚
- 构成犯罪的，依法追究刑事责任

## 八、合同起草要点速查

### 8.1 委托处理合同必备内容

依据第12条，委托处理个人信息/重要数据的合同应包含：
```
✓ 处理目的
✓ 处理方式
✓ 处理范围
✓ 安全保护义务
✓ 处理情况记录保存（至少3年）
```

### 8.2 共同处理协议必备内容

依据第12条第3款，共同处理协议应包含：
```
✓ 各方的权利
✓ 各方的义务
```

### 8.3 向他人提供个人信息的告知内容

依据第21条，向他人提供个人信息时应告知：
```
✓ 接收方的名称或姓名
✓ 接收方的联系方式
✓ 处理目的
✓ 处理方式
✓ 个人信息种类
✓ 取得单独同意
```

### 8.4 跨境传输合同必备内容

依据第37条，跨境传输合同应包含：
```
✓ 向境外提供个人信息的目的、方式、范围
✓ 个人信息的种类、数量
✓ 境外接收方使用个人信息的目的、方式
✓ 个人信息在境外的保存地点、期限
✓ 个人向境外接收方行使个人信息权利的方式和途径
✓ 境外接收方的义务以及履行义务的保障措施
```

### 8.5 关键时限期速查

| 义务事项 | 时限要求 | 条款依据 |
|---------|---------|---------|
| 安全缺陷、漏洞报告（危害国家安全、公共利益） | 24小时内 | 第10条 |
| 重要数据安全负责人信息变更报告 | 3个工作日内 | 第29条 |
| 重要数据安全风险评估 | 每年至少1次 | 第30条 |
| 委托处理情况记录保存 | 至少3年 | 第12条 |
| 个人信息处理活动记录保存 | 至少3年 | 第27条 |
| 大型网络平台停止服务公告 | 提前6个月 | 第44条 |

### 8.6 关键术语对照表

| 条例术语 | 对应合同表述 |
|---------|-------------|
| 网络数据处理者 | 数据处理方/受托方/委托方（根据角色确定） |
| 单独同意 | 针对特定处理的专门同意 |
| 委托处理 | 数据委托处理协议 |
| 共同处理 | 数据共同处理协议 |
| 重要数据 | 需根据目录识别，合同中应明确标注 |
