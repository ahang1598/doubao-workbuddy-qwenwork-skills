# 个人信息保护影响评估（PIA）触发规则

> **核心定位**：PIA是法定义务，非可选合规动作。当触达法定情形时，必须开展PIA并在合同中体现相关安排。

## 一、法定触发情形

根据《个人信息保护法》第55条，有下列情形之一的，个人信息处理者应当事前进行个人信息保护影响评估：

| 序号 | 触发情形 | 适用场景示例 |
|-----|---------|-------------|
| 1 | **处理敏感个人信息** | 处理医疗健康、金融账户、行踪轨迹、生物识别、未满十四周岁未成年人信息等 |
| 2 | **利用个人信息进行自动化决策** | 算法推荐、精准营销、用户画像、信用评分、风险定价等 |
| 3 | **委托处理个人信息** | 外包客服、云服务托管、数据分析服务、技术支持等 |
| 4 | **向他人提供或公开个人信息** | 数据共享、数据对外提供、联合运营、合作方接入等 |
| 5 | **向境外提供个人信息** | 跨境传输、境外存储、境外远程访问、境外集团管理等 |
| 6 | **其他对个人权益有重大影响的处理活动** | 大规模处理、高风险新技术应用、跨行业数据融合等 |

### 重要提示

**上述第3、4项意味着：几乎所有DPA协议（委托处理协议、对外提供协议、共同处理协议）都触发PIA义务！**

## 二、PIA开展主体判断

### 2.1 委托处理场景

| 角色 | PIA责任 |
|-----|---------|
| 委托方（甲方） | 作为个人信息处理者，负责开展PIA |
| 受托方（乙方） | 提供必要协助，包括处理流程说明、技术措施资料、风险说明等 |

### 2.2 对外提供场景

| 角色 | PIA责任 |
|-----|---------|
| 提供方 | 作为个人信息处理者，就"向他人提供"行为开展PIA |
| 接收方 | 如后续处理涉及敏感个人信息、自动化决策等，需另行开展PIA |

### 2.3 共同处理场景

| 角色 | PIA责任 |
|-----|---------|
| 各共同处理方 | 均为个人信息处理者，应协商确定由谁主导开展PIA，另一方配合 |

### 2.4 跨境场景

| 场景 | PIA责任 |
|-----|---------|
| 跨境提供 | 由个人信息处理者开展PIA，作为跨境合规路径的前置步骤 |

## 三、合同条款体现方式

### 3.1 PIA条款必备要素

| 要素 | 内容 |
|-----|------|
| 开展主体 | 明确由谁负责开展PIA |
| 触发情形 | 说明PIA的触发原因（委托处理/对外提供/敏感信息/跨境等） |
| 协助义务 | 另一方应提供的协助内容（资料、信息、技术说明等） |
| 配合时限 | 协助方提供资料的时间要求 |
| PIA结果处理 | 如PIA显示高风险，如何处理（补充措施/暂停处理） |

### 3.2 示范条款（委托处理场景）

```
第X条 个人信息保护影响评估

X.1 甲方作为个人信息处理者，负责根据适用法律要求开展个人信息保护影响评估，包括但不限于本协议项下的委托处理活动涉及的评估。

X.2 乙方应配合甲方开展个人信息保护影响评估，包括：
（1）提供处理流程、技术措施、安全控制措施的说明；
（2）提供个人信息处理系统的架构图、数据流向图；
（3）说明已采取的风险防控措施和剩余风险；
（4）提供甲方要求的其他必要资料。

X.3 乙方应在收到甲方评估协助请求后【X】个工作日内提供相关资料。

X.4 如个人信息保护影响评估结果显示处理活动对个人权益存在高风险且无法通过补充措施消除，甲方有权暂停或终止相关处理活动，乙方应予以配合。
```

### 3.3 示范条款（对外提供场景）

```
第X条 个人信息保护影响评估

X.1 甲方作为个人信息处理者，负责就向乙方提供个人信息的行为开展个人信息保护影响评估。

X.2 如乙方后续处理活动涉及敏感个人信息、自动化决策或其他法定触发情形，乙方应自行开展个人信息保护影响评估，并向甲方提供评估报告副本（如甲方合理要求）。

X.3 双方应相互配合，提供开展评估所需的必要信息和资料。
```

### 3.4 示范条款（跨境场景）

```
第X条 个人信息保护影响评估与跨境合规

X.1 如本协议项下涉及个人信息跨境提供，甲方负责开展个人信息保护影响评估，并作为跨境合规路径的前置步骤。

X.2 乙方应配合甲方完成个人信息保护影响评估、标准合同签署（如适用）、安全评估申报（如适用）等跨境合规义务，包括提供必要资料、技术说明、境外接收方信息等。

X.3 如个人信息保护影响评估或跨境安全评估结果显示存在高风险，双方应协商补充安全措施或调整处理安排。
```

## 四、常见遗漏场景

### 4.1 容易被忽略的PIA触发情形

| 场景 | 是否触发PIA | 原因 |
|-----|------------|------|
| 委托外包客服处理普通个人信息 | **是** | 委托处理个人信息 |
| 向合作方提供用户数据用于联合营销 | **是** | 向他人提供个人信息 |
| 集团内部数据共享（不同法人主体） | **是** | 向他人提供个人信息 |
| 处理用户行踪轨迹数据 | **是** | 敏感个人信息 |
| 处理未满14周岁未成年人信息 | **是** | 敏感个人信息 |
| 基于用户画像进行个性化推荐 | **是** | 自动化决策 |
| 向境外母公司传输员工数据 | **是** | 跨境提供 + 可能涉及敏感信息 |

### 4.2 PIA与合同起草的关系

```
PIA触发判断 → 应在"规则触发分析"中明确列出 → 合同条款中体现PIA相关安排

具体流程：
1. 识别PIA触发情形（委托处理/对外提供/敏感信息/跨境/自动化决策）
2. 确定PIA开展主体
3. 在合同中写入PIA条款：
   - 开展义务
   - 配合义务
   - 资料提供
   - 高风险处理
```

### 4.3 Skill工作流程中的PIA检查点

| 工作步骤 | PIA相关动作 |
|---------|------------|
| 第一步：识别风险信号 | 识别是否涉及敏感个人信息、跨境、委托处理、对外提供 |
| 第三步：规则触发分析 | 明确判断是否触发PIA义务，说明触发原因 |
| 第三步：法条选取 | 如触发PIA，必须读取个保法第55条、第56条 |
| 第四步：起草合同 | 在合同中纳入PIA条款，明确开展主体和配合义务 |

## 五、PIA评估内容（参考）

根据《个人信息保护法》第56条，PIA应当包括以下内容：

| 评估内容 | 具体要求 |
|---------|---------|
| 个人信息处理目的、处理方式 | 是否合法、正当、必要 |
| 对个人权益的影响 | 可能对个人权益造成的影响及安全风险 |
| 保护措施 | 所采取的保护措施是否合法、有效并与风险程度相适应 |

**PIA报告应保存至少三年**。
