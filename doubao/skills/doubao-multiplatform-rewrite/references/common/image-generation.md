# 生图与封面提示词 Reference

负责**生图策略、素材优先级、提示词、生图质检、无法安全生图时的替代**。图片排版由 `distribution-package-format.md` 负责；更精细的封面设计方法、爆款封面类型、Prompt 模板由 `cover-design-methodology.md` 负责（可选加载）。

## 1. 什么时候读

- 标准分发包默认每个平台实际生成 **2 张** 图。
- 用户要求生成图片、封面、配图、视觉 prompt、海报、观点卡、事实卡、关键镜头图。
- 素材涉及品牌 / 产品 / 门店 / 真实人物 / 真实截图 / 数据报告，需判断能否安全生成。

用户明确"不要图"时不读此文件也不生成，在统一发布检查记录"用户已排除图片"。

## 2. 生图总原则

图片从文本长出来。先读母稿、平台标题正文，再决定图像任务：

1. 明确用途：封面点击 / 信息解释 / 收藏清单 / 观点传播 / 关键镜头预演。
2. 判断真实素材约束：是否涉及真实品牌 / 产品 / 人物 / 地点 / 数据 / 截图 / 授权。
3. 一图一任务：一张图只承接一个核心信息。
4. 选类型：实拍感 / 信息图 / 对比图 / 流程图 / 结构图 / 场景示意 / 视频封面 / 关键镜头。
5. 写提示词：主体、构图、风格、色彩、文字、比例、禁止项。
6. 实际出图并插入对应位置（放置见 `distribution-package-format.md`）。
7. 生成后质检（§7）。

## 3. 素材优先级

**用户真实素材 > 官方/授权 > 可商用 > AI 生成**。

- 涉及真实产品、包装、logo、门店、菜单、价格、证书、检测报告、截图证据时优先真实或官方授权素材。
- 无真实素材时不停止出图；优先概念化视觉 / 场景示意 / 中性信息图 / 结构图，但不伪造真实证据。
- 不生成假评论 / 假热搜 / 假销量 / 假媒体报道 / 假聊天记录 / 假系统 UI / 假检测报告。
- 真实姓名、手机号、工牌、车牌、订单号、地址必须打码或不出现。
- 仅当用户明确要求真实素材且无法安全替代时标 `blocked`。

## 4. 平台生图策略

| 平台 | 图 1 | 图 2 | 任务 | 推荐画面 | 图上文字 | 比例 |
| --- | --- | --- | --- | --- | --- | --- |
| 小红书 | 封面图 | 场景图 | 点击 + 收藏 | 竖版、强标题、生活化场景、清单分层 | 4-14 字，关键词前置 | 3:4 |
| 公众号 | 封面头图 | 文中结构图 | 建立主题 + 解释逻辑 | 横版/宽幅头图、时间线、流程图 | 克制不塞满 | 16:9 或 2:1 |
| 短视频 | 视频封面 | 关键镜头图 | 停留 + 可拍 | 竖版强钩子、人物动作、道具冲突 | 一句强钩子 | 9:16 |
| 微博 | 场景图 | 内容图 | 转发 + 评论 | 核心判断 + 讨论问题 | 一句判断或问题 | 1:1 或 16:9 |

平台差异：小红书生活化明亮、可收藏；公众号克制、解释、低饱和；短视频动态、冲突、竖版花字；微博观点、少字、传播感。

## 5. 提示词要素

每条提示词包含：**平台用途 / 比例 / 主体 / 核心动作 / 构图 / 风格 / 色彩 / 图上文字 / 禁止项**（水印、二维码、无关 logo、乱码、假 UI、平台标识、尺寸标注、额外文字）。

## 6. 通用提示词模板

**封面图**：为【平台/用途】生成一张【比例】封面。主题【主题】，主体【主体/场景】，采用【构图】，突出【读者收益/冲突/结果】。风格【风格】，主色【颜色】，留白充足。图上只出现"【图上文字】"。不要水印、二维码、假界面、无关 logo、英文乱码、尺寸标注、平台标识或额外文字。

**信息图 / 关键镜头图**：把上述结构中的"主体 + 构图"替换为"清单/步骤/对比/时间线/变量关系 + 分区方式"（信息图）或"人物 + 可拍动作 + 情绪 + 景别 + 具体环境"（关键镜头），其余尾缀相同。

## 7. 生成前后统一质检

**生成前风险**：需要真实素材才成立？（是→不 AI 伪造，改概念/结构/场景图）；图上文字 >14 字？（缩短或改后期排版）；涉及品牌/价格/功效/排名/用户评价/前后对比未核实？（改中性表达）；像真实截图/聊天/报告/热搜？（改概念化信息图）；含个人隐私？（删除或打码）。

**生成后质检**：中文清晰无错别字乱码；图中严禁出现平台规格 / 尺寸标注 / 模型签名 / 水印 / 二维码 / logo等相关内容；人脸手部产品不畸变；主体和关键文字未被裁切；色彩不塑料不廉价渐变；未伪造真实证据 / UI / 评论 / 报告 / 榜单；与同文档其他图片视觉统一。

## 8. 无法安全生图时的替代

- 真实产品缺失：生成中性场景 / 非品牌化信息图，不画具体 logo、包装细节和官方背书。
- 数据报告缺失：做"概念结构图"，不写具体数字和来源。
- 截图证据缺失：做流程 / 信息图，不生成假截图。
- 品牌授权不明：避免 logo、包装细节和官方背书。
- 人物授权不明：不生成可识别真人肖像；改背影、手部动作、物品场景或抽象剪影。

只有真实素材是必要条件且无法用概念图、结构图、信息图、场景图替代时，才写 `blocked` 并说明所需素材类别。
