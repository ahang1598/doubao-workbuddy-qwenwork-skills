# 封面与图片设计方法库

> 定位：承接 `image-generation.md` 的生图流程，负责"整组图如何建立统一视觉系统、封面怎么抓点击、内页怎么承接正文、每张图用哪类画面方法、怎样转成 prompt"。**仅在需要精细封面 / 高端视觉时读取**；一般场景使用 `image-generation.md` 即可。
> 
> **四平台第二张图类型**：小红书 = 封面 + 场景；公众号 = 封面头图 + 文中结构图；短视频 = 视频封面 + 关键镜头；微博 = 场景 + 内容。

## 一、设计工作流

1. **接收需求**：确认图片任务、素材来源（真实素材 / AI 生成 / 版式文字页）、是否含零容错信息。
2. **定视觉系统**：按「视觉基准」提炼一张视觉卡（主色/点缀色 / 字体气质 / 背景质感 / 网格 / 高亮方式）。同组图共用。
3. **先封面定调**：写封面文案 → 从「爆款封面方法论」选一个主类型；不同时堆多类型。
4. **再排内页**：判断递进式 / 单点展开式；每张内页只承接一个正文要点。
5. **按单张选方法**：实拍 / 底图再设计 / 插画 / 版式文字 / 图表 / 真实 UI / 产品 → 对应读「按画面风格选择专业方法」。
6. **转 prompt**：AI 生成用「Prompt 转换」九要素填槽；真实素材页写裁切、调色、排字要求；零容错文字/品牌/价格/参数优先后期排字。
7. **回主流程自检**：见 `image-generation.md §7`。

## 二、视觉基准

### 2.1 七维拆解

- **主题文案**：主标题一眼抓核心钩子；辅文退居其次，不平均用力。
- **视觉主体**：核心图抓眼且紧贴主题，讲同一件事。
- **色彩搭配**：主色 + 1 个点缀色，明度/饱和拉开层次不刺眼。
- **排版布局**：留白引导视线，阅读路径顺畅。
- **字体规范**：标题粗体醒目 / 辅助字号弱化拉开层级；≤2-3 种字体；忌花体扭曲。
- **辅助元素**：logo / 边框 / 贴纸 / 手写涂鸦只作点缀，宁少勿多。
- **核心信息**：时间 / 地点 / 人群 / 诉求等关键信息完整直观。

> 用法：找 1-3 篇同品类高赞封面提炼共性作视觉卡；出图后按七维自检。

### 2.2 质检底线

文字层级清楚（主标题一眼可读，副标题只补充人群/场景/结果）；字体服务内容气质；只强调 1-2 个关键词；色彩有主次；真实信息用真实载体（聊天/备忘录/UI/包装/价格/证书优先真实素材或可控模板）；实拍保持真实质感（自然光影、真实材质）；画面干净高清（3:4 竖版优先 1080×1440 起，图片中不得添加水印/规格文字/乱码/假 logo等内容）。

### 2.3 优质封面设计原子

主视觉标题（一句最强钩子占最大权重）；副标题（补充人群/场景/结果，不重复主标题）；品牌/身份标识（仅真实授权可用）；视觉载体（决定封面第一眼是"可信/好看/有用/有情绪"）；色彩系统（底色 + 主文字色 + 点缀色）；版式构图（大标题压顶 / 主体居中 / 底部利益条 / 四宫格拼贴 / 纸卡叠放 / 海报留白 / 对角动线）；字体规范（1 主 + 1 辅，≤3 字号层级）；细节辅助（描边、胶带、箭头、圈注只用来指路强调）；真实质感（真人/穿搭/探店/美食优先实拍）；密度控制（干货可高密度但要清晰分组，情绪/高级感低密度靠留白）。

## 三、封面设计

### 3.1 封面是第二个标题

信息流里用户先看到图再看到字。封面任务：让人 1 秒判断"这和我有关，值得点开"。

### 3.2 五项核心原则

- **尺寸合规**：小红书 3:4（1080×1440）；公众号 16:9 或 2:1；短视频 9:16（1080×1920）；微博 1:1 或 16:9。顶部 200px、底部 300px 为安全区留白；核心元素放中间 60% 区域。
- **0.3 秒抓眼**：主体占 70% 以上，居中构图；画面元素 ≤5 个；用生动表情/前后对比/成品高光传递"好看/有用/省钱"。
- **信息极简**：默认带大标题（4-14 字，加粗醒目，放痛点/数字/结果）；只保留 1 主标题 + 1-2 行副标题；封面与正文一致，不图文不符。
- **构图聚焦**：居中 / 对角 / 上下分割 / 包围式 / 散点 / C 字型等；一张图只用一种主构图。
- **合规避坑**：禁低俗、夸张医美、医疗功效、虚假宣传、二维码、微信、价格诱导、导流话术、搬运网图。

### 3.3 封面文案

**呼应正文标题、措辞可异**：从正文标题/核心钩子提炼，可换更短更画面化的说法，但承诺一致。**错位互补**：标题铺信息、封面给钩子（如标题"敏感肌平价面霜测评，我试了 18 支"，封面压"18 支只留 5 支"）。**关键词呼应**：与标题共用 1-2 个核心关键词。

**重写要点**：短、狠、具体；一张封面一个钩子（主标题 ≤14 字）；关键词加粗 + 亮色高亮；善用反问 / 共情 / 痛点 / 数字 / 身份指向 / 利好承诺起势；可留悬念但承诺与正文一致。

### 3.4 爆款封面方法论（按内容任务选 1 个主类型）

| 类型 | 适用 | 视觉核心 | 慎用 |
| --- | --- | --- | --- |
| **真人大字截停型** | 美妆、保险科普、考试、装修避坑、职场干货、观点提醒 | 真人半身居中 + 手势 + 顶部超大标题（白描边）+ 底部利益句 | AI 生成人像不冒充真实达人 |
| **纯文字大字报型** | 职场、求职、学习、观点、避坑、方法论、强情绪 | 白/浅/纯色底 + 超粗黑体/手写粗字 + 亮色高亮关键词 + 手做感箭头圈注 | 文案必须重新压成一句强判断 |
| **纸卡便签 / 手写笔记型** | 冷知识、职场观察、情绪观点、清单、学习、求职经验 | 米白纸/横线纸/便签 + 胶带 + 回形针 + 手写字 | 信息多时优先分成清单卡片 |
| **极简观点卡型** | 认知观点、品牌/AI/职场深度、情绪克制型 | 大量留白 / 深色纯底 + 一处关键词高亮 + 极少装饰 | 靠文案判断力，文案弱不用 |
| **拼贴型**（旅行 / 穿搭合集 / 探店菜单 / 产品广告） | 城市攻略、OOTD、探店、好物、新品促销 | 多张实物/实拍拼成杂志感 + 主标题居中色块 + 定位 pin/Look 编号/菜品标签 | 地点/菜品/产品必须真实，不 AI 冒充；避免搬运他人图 |
| **实拍大片型**（食物 / 单品平铺 / 产品质感） | 菜品本身好看、单品审美、产品质感 | 主体占大画面，靠色泽/光影/纹理吸引，文字很少 | AI 生成食物质感易假；具体品牌 logo 需真实授权 |
| **图表 / 结构化信息型** | 学习成长、金融科普、职场方法、决策、测评、教程 | 顶部主判断 + 3-5 个信息块 + 编号/勾选统一 + 单一亮色标重点 | 数据/价格/时间/比例必须有事实依据 |
| **真实 UI / 对话截图型** | 聊天故事、备忘录清单、软件教程、社群问答、求助复盘 | 真实系统界面 + 隐私打码 + 中性化头像昵称 + 短气泡节奏 | 不让 AI 凭空画 UI，避免假按钮乱码 |

**其他类型**（插画情绪 / 猎奇创意反差）作为辅助选择：插画情绪型适合自媒体、亲子、心理、轻松科普，用扁平手绘统一线条；猎奇创意型用夸张字形 + 反常识画面 + 强对比色（不低俗、不擦边、不恐吓）。

> 类型选择口诀：真人说重话走真人大字；观点强判断走纯文字/极简卡；清单走纸卡便签；城市/穿搭/探店走拼贴；菜品/单品/产品走实拍大片；硬核干货走图表；聊天备忘录走真实 UI。手绘注解/描边/箭头/圈注可叠加在多类型上作为设计层。

## 四、整组内页设计

**默认封面与内页共用视觉系统**：同色调、同字体、同版式骨架、同滤镜；内页可比封面信息更密、留白更少（封面钩人靠留白，内页讲透靠信息量），但底层视觉不换。真实截图/实拍对比证据页可跳出版式卡片直接铺满，仍用统一标题条/角标收进系列。

**辅图铺开选一种主线**：

- **递进式**：每张图讲一个独立要点，张张平行推进（清单合集、教程步骤、横向测评、避坑）。用统一卡片版式 + 编号（No.1-N / Step1-N）。
- **单点展开式**：围绕一个主题层层深入（是什么→为什么→怎么做→效果→结论）。适合深度测评、方法拆解、观点论证。
- **混合式**：先单点展开立论，再递进式收尾。

## 五、平台差异化设计

| 平台 | 图 1 | 图 2 | 色彩风格 | 禁忌 |
| --- | --- | --- | --- | --- |
| 小红书 | 封面图（3:4 竖版，强标题 4-14 字，生活化，清单分层） | 场景图（承接正文，展现使用场景/细节） | 明亮生活化、卡片分层 | 不伪造真实截图/评论/销量/测评/授权 |
| 公众号 | 封面头图（16:9 或 2:1，建立主题氛围，不塞太多字） | 文中结构图（结构图/时间线/对比/流程图，帮解释文章逻辑） | 低饱和专业感、横向构图 | 不塞满字、不用低质渐变、不伪造数据 |
| 短视频 | 视频封面（9:16，强钩子、人物动作、道具冲突） | 关键镜头图（看出动作、景别、情绪，不静态海报化） | 强对比、竖版、动作瞬间 | 不伪造真实 UI/推荐/评论/前后对比 |
| 微博 | 场景图（1:1 或 16:9，核心观点场景） | 内容图（一句判断或一个讨论问题） | 观点感留白，文字少态度明确 | 不伪热搜/评论/媒体报道 |

## 六、按画面风格选择专业方法

- **插画/手绘/卡通**：明确画风流派（扁平 / 厚涂 / 线稿淡彩 / 治愈 / 国潮），统一线条 + 上色 + 光影；适合知识科普、情绪向、教程示意、抽象概念可视化。
- **真实人物/场景/产品**：写清机位与景别、光线（自然/柔光/侧逆光）、景深（大光圈虚化）、真实质感；美食大片、OOTD 全身强依赖真拍，优先真实/免版权实拍。
- **手绘注解层**：叠加在其他类型上的设计层，用描边/箭头/虚线/圈注/短句注解建立视线引导和人感；美食写口感香气，穿搭写版型搭配，好物写材质使用感，攻略写路线避坑。
- **色彩体系**：参考经典名画/电影调色/优质海报的配色（莫兰迪低饱和、孟菲斯撞色、青橙电影调）；给 AI 写明"参考 XX 配色：主色+辅色+点缀色"。
- **排版布局**：学习海报/杂志排版语言（网格对齐、字号层级、留白节奏、信息分组）；大字报/图表尤其要照海报级排版结构生成。

> 口诀：先定图片任务和封面类型，再定风格（插画/实拍/版式），最后判断是否叠加手绘注解层、配色法或海报排版法。

## 七、Prompt 转换

### 7.1 生成顺序

1. 定执行方式：完整文生图 / 真实素材再设计 / AI 背景+后期排字 / 模板排版；判断是否需手绘注解层。
2. 选封面类型（§3.4）。
3. 填设计原子（§2.3）。
4. 写画面主体（具体到人/物/场景/食物/纸卡/图表，不只写"小红书风格"）。
5. 规划可叠加设计层（如需注解：`对象 → 注解角度 → 短句 → 指向方式 → 摆放位置`）。
6. 写可控边界：只出现指定文字；不出现平台规格/尺寸标注/页眉角标/用户名/水印/二维码/logo 乱码/假英文/模型签名。尺寸比例只放工具参数。
7. 写后期要求：需精准中文时预留文字区 → 后期叠字。

### 7.2 九要素填槽

| # | 要素 | 填什么 |
|---|---|---|
| ① | 主视觉标题 | 一句核心钩子，最大视觉权重；可预留标题区或只生成短字 |
| ② | 次级说明 | 人群、场景、结果、数量、方法；可后期排字 |
| ③ | 行动引导 | 轻量号召；不出二维码/微信/价格诱导 |
| ④ | 品牌标识 | 仅真实授权 |
| ⑤ | 视觉载体 | 真人/产品/菜品/场景/真实 UI/图表/插画/纸卡/拼贴 |
| ⑥ | 色彩系统 | 底色 + 主文字色 + 点缀色，2-4 色 |
| ⑦ | 版式构图 | 大标题压顶/主体居中/底部利益条/拼贴/海报留白/对角动线 |
| ⑧ | 字体规范 | 主字体气质 + 副字级 + 描边/阴影/手写感；≤2-3 种 |
| ⑨ | 细节辅助 | 白描边、胶带、箭头、圈注、贴纸；只用来指路强调 |

### 7.3 参数与通用尾缀

尺寸与比例只在工具参数中设置（如 `3:4 竖版，1080×1440`），不写进画面 prompt。

每条画面 prompt 加通用尾缀：`画面干净，只出现指定文案；无多余水印、logo、用户名、二维码、引用出处、尺寸标注、平台字样、风格标签、页眉角标、模型签名、乱码英文、假 UI 文本；顶部和底部边缘无任何非内容所需小字；图上中文用词准确、字形清晰；高分辨率，文字边缘干净，主体不畸变。`

### 7.4 核心 Prompt 模板（三选一）

**真人大字截停型**：
```
封面类型：真人大字截停型。
主体：<真人半身/上半身>位于画面中部，<手势/动作>，真实摄影质感，自然光，真实肤质衣物纹理，背景为<居家/办公室/店铺/学习场景>，轻微虚化或压暗。
版式：顶部预留超大标题区，底部预留利益句区域。
文字：只出现「<主标题>」「<副标题>」，核心词「<关键词>」用<亮色>强调。
细节：1-2 个手写箭头/圈注/勾选框指向重点。
通用尾缀。
```

**纯文字/纸卡/极简观点卡型**：
```
封面类型：<纯文字大字报/极简观点卡/纸卡便签>。
载体：<浅色纸感/便签/深色纯底/米白留白>，真实纸张纹理或轻微颗粒感。
版式：主标题占最大权重，最多 3 层级；关键词用<亮色高亮/下划线/圈注>强调。
文字：只出现「<主标题>」「<次级说明>」；长句预留后期排字空间。
字体：<超粗黑体/手写粗字/克制细黑体/衬线大字>；全图不超过 2 种字体气质。
通用尾缀。
```

**拼贴/图表/实拍大片型**（按需替换主体和版式）：
```
封面类型：<旅行拼贴/穿搭合集/探店菜单/产品广告/食物实拍/单品平铺/图表结构>。
载体：使用<真实地点图/真人穿搭图/菜品图/产品图/信息卡片>，主体有自然白描边或纸贴边。
版式：主标题压在<顶部/中心色块/白底贴纸>，主要主体最大，其他元素环绕。
文字：只出现「<主标题>」「<短标签>」；地点/菜名/单品/数据必须来自真实素材。
色彩：<主色>统领全图，<点缀色>用于标题高亮。
通用尾缀。
```

**可叠加设计层：手绘注解**
```
在既有主类型上增强信息指向、人感和笔记感，不改主体，不重画真实素材。
对象识别：先识别真实可见的 <对象1><对象2>，只标与正文钩子有关的对象。
注解规划：<对象1> → <注解角度> → <短句> → <位置>；<对象2> → …
线条系统：同一手绘线条语言（白/奶白/品牌点缀色），细、轻、略手绘不均匀。
文字规则：中文为主，每条 4-8 字符；整图 3-6 条注解。
装饰控制：热气/闪光/爱心/星星只放空白处，不比主体抢眼。
通用尾缀。
```

**真实 UI / 对话截图型**：优先使用真截图或可控模板，不让 AI 凭空画 UI。

**内页/辅图**：沿用封面主色/点缀色/字体气质/边距网格；一图一要点；只出现本页短标题和必要短标签。

### 7.5 文字与后期排版

- 主标题、短标签可让模型尝试；长句/品牌名/价格/参数/地点/UI 文本/表格数据优先后期排字。
- 占位比乱码好：需精准文字但模型不稳时，先生成干净背景+留白区，再后期排字覆盖。
