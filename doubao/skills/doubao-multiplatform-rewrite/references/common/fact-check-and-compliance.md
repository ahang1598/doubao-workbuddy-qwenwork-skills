# 事实核查与合规边界

只负责事实、风险和合规。

## 1. 必须核查或降级

以下内容先核查；无法核查则降级并标"发布前确认"：近期新闻、政策、热搜、趋势、活动时间、榜单、报告、价格、财报、产品参数；医疗、法律、金融、教育、食品、母婴、减肥、功效承诺等高风险领域；公司、人物、地点、机构、奖项、认证、销量、排名、用户评价；需要引用外部数据、截图、媒体报道或研究结论。

## 2. 禁止编造

不得新增或伪造：用户评价、评论截图、媒体报道、检测报告、研究论文、证书、销量、排名；产品功效、价格优惠、限时政策、活动名额、报名结果；人物经历、采访、现场画面、内部数据、权威背书；真实 UI、聊天记录、热搜榜、平台推荐、官方合作关系。

## 3. 降级表达

| 高风险 | 降级 |
| --- | --- |
| 一定有效 | 可能有帮助 / 适合部分场景 |
| 官方认证 | 如有认证材料，发布前补充 |
| 用户都说好 | 适合强调使用体验，需补充真实评价 |
| 排名第一 | 需确认来源和时间 |
| 立刻见效 | 效果因人和场景而异 |

## 4. 文档中的事实边界写法

在"统一发布检查"或各平台验真区写：已基于用户材料改写、未额外核实的事实不写成确定背书；价格、时间、名额、政策、参数、外部数据发布前需用户确认；图片如需真实产品/店铺/人物/logo/截图/报告需用户提供授权素材。

## 5. 合规质检

发布前确认：无绝对化词（最、第一、唯一、保证、必然、立刻、永久）；无未经证实的权威背书；不把个人体验写成普遍结论；敏感行业有边界表达；各平台无相互矛盾的时间、价格、结论、限制条件。
