# 输出标准 SSOT（Single Source of Truth）

> 本文件是**全 skill 唯一的通用排版/格式/Block/编号/缩进/空行/图片/发布检查**权威规则来源。`SKILL.md` 与 `platforms/*.md` 只引用本文件，不重复。若与其他文件冲突以本文件为准。平台专属细节（如小红书视觉锚点空行、公众号三级层级）在各平台文件中以"§X 引用 output-standard 后追加平台专属"形式表达。

## 1. 平台最低交付标准

> 3 个及以上平台时每个平台只保留核心模块；1-2 个平台时可加 1-2 个扩展模块（详见 `distribution-package-format.md §3.2`）。

- **小红书**：笔记配图 2 张（封面 + 场景，3:4，二栏）+ 标题 3-5 个备选 + 正文 ≤1000 字符（标签和互动收在正文末尾）。
- **公众号**：一篇**可直接复制发布的完整文章**（不拆分编号模块）；主标题 + 文末 2-3 个备选标题；封面头图紧跟标题后；文中结构图插入正文对应小节；短段落 + 加粗信息量小标题；围绕一个核心问题递进。
- **短视频**：封面图 2 张（视频封面 + 关键镜头，9:16，二栏）+ 创意策略（引用块：创意切入 / 前 3 秒钩子 / 情绪弧线 / 视觉关键词）+ 7 列分镜表（镜号/时长/景别/机位/画面/台词/音效花字）。
- **微博**：微博配图 2 张（场景 + 内容，1:1 或 16:9，二栏）+ 微博正文（2-3 条单条备选或 3-4 条连发版，均在同一模块内）。

## 2. Block 层级与缩进（全文档强约束）

### 2.1 唯一原则

**全文档所有 Block 的 `indent_level` 统一为 0（根级）**，视觉层级**只靠字号 / 字重区分，绝不靠缩进区分**。任何情况下都不允许对 Block 使用飞书 `indent` 缩进属性。

### 2.2 Block 类型 → 缩进映射表（唯一）

| Block 类型 | 内容举例 | `indent_level` | 父级 |
| --- | --- | --- | --- |
| H1 文档标题 | `# 多平台改写分发方案｜xxx` | **0** | 文档根 |
| H2 大章节 | `## 一、母稿拆解` / `## 四、公众号版本` | **0** | 文档根 |
| H3 平台内模块 | `### 1. 笔记配图` | **0** | 文档根 |
| H4 细分项 | `#### （1）拍摄准备` | **0** | 文档根 |
| 公众号 H2 文章主标题 | `**标题：xxx**` | **0** | 文档根 |
| 公众号 H3 章节 | `**1. xxx**` | **0** | 文档根 |
| 公众号加粗段落小标题 | `**(1) xxx**` | **0** | 文档根 |
| 正文段落 | 普通段落文字 | **0** | 文档根 |
| 图片 Block | 各类图片 | **0** | 文档根 |
| 分割线 | `---` | **0** | 文档根 |
| 引用块 | `> 备选标题：xxx` | **0** | 文档根 |

### 2.3 禁止事项

- ❌ 任何 Block 使用飞书 `indent` 缩进属性；
- ❌ 用连续半角/全角空格前缀模拟缩进（标题与正文必须首字符顶格）；
- ❌ 标题类 Block 被嵌套到 table / grid / callout / 引用块 / 列表 内制造隐式缩进；
- ❌ 同级 Block 缩进不一致（同为 `(1)(2)(3)` 小标题，前半有缩进、后半左对齐）；
- ❌ 父级 Block 缩进大于子级（如 H3 章节缩进 > 其下 `(1)` 加粗段落小标题缩进，视觉层级倒置）；
- ❌ 正文段落中途首行缩进变化（前半左对齐无首行缩进、后半突然首行缩进两字符）；正文全篇统一左对齐、首行不缩进、段间距区分。

### 2.4 写入自检

写完任一大章节后遍历所有 Block：任一 `indent_level > 0`、任一标题类 Block 出现在非根级容器中、任一同级 Block 缩进不一致，均视为排版错误 → 回滚并重新以根级 Block 写入。

## 3. 大章节 Block 独立性（表格逃逸强制执行步骤）

每个 `##` 大章节必须作为独立顶级 Block 插入，不得嵌套在 table / grid / callout / 引用块 内。

**每次写入新 `##` 大章节或"紧跟表格 / 分栏 / 引用块之后的任何内容"前必须完整执行**：

1. **STEP 1 — 强制脱离父容器**：调用一次写入 API，在上一个 Block（尤其是 table）之后创建一个空的顶级段落 Block（空字符串或单空格）。**不可跳过**。
2. **STEP 2 — 验证脱离**：确认新空段落 Block 父级为文档根；若仍在父容器中，继续插入根级空段落直到成功。
3. **STEP 3 — 输出分隔标记**：在根级追加独立段落 `---`。
4. **STEP 4 — 插入新章节**：再插入 `## 一/二/三…` 一级标题 Block。

**典型错误**（视为执行错误，必须回滚）：微博正文串入短视频分镜表最后一列；大章节标题被写进 table / grid / callout / 引用块；表格 / 分栏 / 引用块结束后没有空段落 + `---` 就贴下一大章节。

## 4. 标题层级与编号规范（全文档 SSOT）

### 4.1 分发包外层大纲（唯一）

| 层级 | 格式 | 用途 |
| --- | --- | --- |
| 文档标题 | `# 标题` | 全文标题 |
| 一级（大章节） | `## 一、名称`（中文数字 + 顿号） | 母稿拆解、分发策略总览、各平台版本、统一发布检查 |
| 二级（平台内模块） | `### 1. 名称`（阿拉伯数字 + 小数点） | 平台核心模块与扩展模块 |
| 三级（细分项） | `#### （1）名称`（括号数字） | 模块内细分 |

### 4.2 公众号文章内部（独立三级，与外层不冲突）

| 层级 | 格式 | 编号 | 飞书样式 |
| --- | --- | --- | --- |
| 文章主标题 | `**标题：xxx**` | 无 | H2 加粗 |
| 文章章节 | `**1. xxx**` | 阿拉伯 + 小数点 | H3 加粗 |
| 文章小标题 | `**(1) xxx**` | 括号阿拉伯 | 加粗独立段落 |

### 4.3 编号唯一性铁律（重点，防止层级倒置）

**同一编号格式在全篇文档内只能代表同一层级，禁止在不同位置代表不同层级**：

- `一、二、三、`（中文数字 + 顿号）**仅**用于分发包外层大章节（`## 一、母稿拆解` 等）；**任何平台内部**（含公众号文章内、小红书正文、短视频分镜、微博正文）**严禁**再次使用；
- `1. 2. 3.`（阿拉伯数字 + 小数点）**仅**用于两处：① 分发包平台内模块（`### 1. 笔记配图`）、② 公众号文章章节标题；**禁止**同时作为"备选标题列表""附录子项"等其他层级序号出现（会与顶层章节序号视觉混淆）；
- `(1) (2) (3)`（括号阿拉伯数字）**仅**用于两处：① 分发包 `#### （1）` 细分项、② 公众号文章内小标题；不再作为其他层级用途；
- **备选标题、备注、附录** 一律不使用编号，改用**引用块** `> 备选标题 A：xxx`（详见 §7）；
- 任何情况下混用（如公众号文章内出现 `一、xxx`、"备选标题"下又用 `1. 2.`）→ 视为排版错误必须回滚重写。

### 4.4 视觉层级递减（无缩进、只靠字号字重）

`# H1` > `## H2 大章节（一、）` > `## H2 公众号主标题（标题：）` > `### H3（1.）` > `**加粗段落 (1)**` > 正文；共 6 级视觉层级，**只靠字号 / 字重递减区分，禁止靠缩进区分**。任意两级不得使用相同格式。

## 5. 空行与段落间距（通用底线）

### 5.1 通用（全平台适用）

- 段落之间：**恰好一个空段落 Block**分隔，不允许零空行贴连、不允许连续 ≥2 个空段落 Block；
- 小节标题（H2/H3/H4/加粗段落小标题）前后各**恰好一个空行**；
- 表格 / 分栏 / 引用块 / 图片 Block 与前后段落之间**恰好一个空行**，不加倍；
- 分割线 `---` 与前后段落之间**恰好一个空行**；
- 大章节首个 Block 之前、最后一个 Block 之后（如末尾标签、末尾发布检查表格后）**禁止**存在空段落 Block；
- 同一段落 Block 内软换行最多 2 个（一段最多 3 行），超出必须拆成独立段落 Block；
- 禁止用堆多个软换行制造"大间距"视觉。

### 5.2 平台专属补充

- 小红书视觉锚点组（✅💡⚠️📌✨）的条目间距、不同符号锚点组之间的间距见 `platforms/xhs.md §段落间距`。
- 公众号短段落节奏见 `platforms/wechat.md`。

## 6. 图片配文与图片规格标注（强约束）

### 6.1 图片规格 / 用途标注禁止写入正文

图片规格 / 尺寸 / 用途 / 版式描述**只能作为给执行者/绘图 AI 的内部注释**，**绝不写入飞书文档正文任何 Block**（读者可见即视为违规）。

**判定关键词**（正文中一旦出现视为违规，必须删除）：`16:9`、`9:16`、`3:4`、`4:3`、`1:1`、`横版`、`竖版`、`宽幅`、`封面头图`、`文中结构图`、`对比信息图`、`时间线图`、`信息图`、`800×`、`1080×`、`px`、"xxx 规格"等含尺寸/比例/用途字样、且明显是给执行者看的描述性标注。

内部注释写在 skill 文档、绘图 prompt、交付说明、Meta 备注中即可，不写入飞书正文 Block。

### 6.2 图片下方配文规则

- **公众号**：图片下方**一律不加任何配文 / 说明 / 图注 / 素材边界 / 状态标签**，图片作为独立 Block 直接进入下一段。风险类信息统一收敛到"七、统一发布检查"。
- **其他平台**（小红书 / 短视频 / 微博）：图片下方允许保留 1 行短说明（用途 · 素材边界），作为独立段落 Block 紧跟图片，不写进 table 单元格；说明与下一小节标题之间恰好一个空行。

### 6.3 图片排版

- 默认每平台 2 张图；非公众号用二栏或紧凑表格；公众号封面头图紧跟主标题后、文中结构图插入正文对应小节；
- 只 1 张图时不分栏；
- 不出现空白说明栏、大图纵向平铺、末尾集中视觉区、重复图片模块；
- 图片紧跟对应平台内容，不集中堆到文末。

## 7. 备选标题 / 附录块的写法（防止编号层级混乱）

"备选标题""备注""附录"等**附属信息块**统一使用**引用块（Quote Block）** 或**分割线 + 引用块**隔离，**不使用普通段落 + 缩进**，**不使用 `1. 2. 3.` 或 `(1) (2)` 序号**（避免与正文章节 / 小标题的同格式编号混淆）：

```
---

> **备选标题**
> - 备选 A：xxx
> - 备选 B：xxx
> - 备选 C：xxx
```

或：

```
---

> 备选标题 A：xxx
> 备选标题 B：xxx
> 备选标题 C：xxx
```

- ✅ 备选标题使用引用块 + 无序列表 或引用块 + 每行一条；不用 `1.` `2.` 数字编号；
- ✅ 与正文用分割线 `---` 隔离；
- ❌ 禁止把"备选标题"当作普通加粗段落 + 缩进子项写入正文流；
- ❌ 禁止使用 `1. 2. 3.` 或 `(1) (2)` 作为备选标题编号（会与章节 / 小标题编号视觉混淆）。

## 8. 统一发布检查表

在文档末尾输出：

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 事实一致 | 待填 | 各平台是否保留同一事实边界 |
| 联网/来源 | 待填 | 是否进行了必要联网；外部事实是否有来源或待确认 |
| 平台差异 | 待填 | 是否落实各平台角色 |
| 图片生成 | 待填 | 除用户明确不要图外，各平台是否实际生成并插入图片 |
| 图片排版 | 待填 | 单图不分栏、多图未大图平铺；公众号图片下方无配文；正文无图片规格关键词残留 |
| 结构 & Block | 待填 | 结构唯一无重复；大章节独立顶级 Block；全部 Block `indent_level=0` |
| 编号层级 | 待填 | 同一编号格式全篇代表同一层级；无跨层级混用 |
| 风险边界 | 待填 | 是否存在夸大、绝对化、敏感行业或授权素材缺口 |

## 9. 禁止退化

- 禁止把"单平台 + 无母稿/素材 + 从零创作/自由发挥"误判为多平台改写分发；此类请求应边界说明，不创建飞书文档；
- 禁止因用户说"使用本 Skill / 使用我上传的 skill"而忽略适用边界；论文、学术论文、毕业论文、开题报告、文献综述、研究计划、研究报告等学术写作请求不创建分发包；
- 禁止对"不同平台 / 全平台 / 平台化处理"随机选平台；未指定平台时固定默认小红书、公众号、短视频、微博；
- 禁止把"适合哪些平台 / 发哪里更合适"这类纯平台建议问题强行扩写成完整分发包；
- 禁止简化文档 / 只给正文的聊天答复；
- 禁止把聊天内 Markdown 当最终交付（除飞书失败兜底）；
- 禁止不同平台写成同一段文字的长短版；
- 禁止新增无法证实的事实、功效、评价、价格、截图、排名、背书；
- 禁止把图片提示词、图片方案或"用户二次要求后再出图"当交付结果；
- 禁止图片集中堆到文末或大图纵向平铺；单图强行分栏或制造空白说明栏；
- 禁止在正文暴露内部文件名、规则、检查过程、图片规格标注；
- 禁止对任何 Block 使用飞书 `indent` 缩进属性；
- 禁止跨层级复用同一编号格式。
