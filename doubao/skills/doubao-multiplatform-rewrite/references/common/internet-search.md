# 联网搜索与信息补充规则

只负责判断是否需要联网、搜什么、如何把结果转成分发素材。

## 1. 必须联网的情况

- 热点、新闻、舆论、政策、行业动态、市场趋势。
- 出现"最新 / 最近 / 今年 / 现在 / 近期 / 爆款 / 趋势 / 热点"等时效词。
- 涉及真实品牌、产品、公司、人物、影视剧、平台规则。
- 需要补数据、案例、报告、榜单、政策、公告、媒体报道或用户评价。
- 素材不足但公开资料可补足背景。
- 涉及医疗、法律、金融、教育政策、就业、投资、消费维权等高风险领域。
- 用户要求"更贴近当下讨论 / 更有传播性"。

## 2. 可以不联网

- 用户明确只基于给定材料。
- 素材完整、目标明确，只需改写分发。
- 纯感悟、虚构、情绪表达、生活记录、品牌理念文案。
- 通用方法论、写作模板、排版建议。

不联网 ≠ 可以编造；没有来源的信息只写成建议、假设或待确认。

## 3. 优先搜什么

服务"选题判断 / 事实准确 / 平台切口 / 读者痛点"：事实核查（事件、进展、官方回应、政策原文）、近期讨论（争议点、读者关心）、同类内容（找新切口，避重复角度）、数据案例（官方数据、行业报告）、风险边界（反转、争议、过期、合规）。

## 4. Query 拆解

按信息目标拆 2-5 个 query，包含时间、主体、用途：

- 事实核查：`事件/产品/政策 + 最新进展 / 公告 / 原文`
- 趋势判断：`主题 + 2026 / 近期 / 趋势`
- 读者痛点：`主题 + 吐槽 / 常见问题 / 为什么`
- 同类内容：`主题 + 小红书/公众号/短视频/微博 + 热门角度`
- 数据案例：`主题 + 数据 / 报告 / 白皮书`
- 风险边界：`主题 + 争议 / 辟谣 / 监管`

## 5. 结果使用规则

- 只使用可解释、可核验、直接相关的信息。
- 不照搬、洗稿、复刻他人标题；搜同类内容的目的是避开重复角度。
- 搜到的数据、政策、报告保留来源意识；无法确认来源时降低表达强度。
- 外部信息只补足"事实 / 背景 / 趋势 / 痛点 / 风险边界"，平台正文重新组织。
- 最终文档不堆搜索过程；只在"母稿拆解 / 风险与核查点"保留必要来源。

## 6. 搜索不足时

- 不补造数据、评论、案例、权威背书。
- 使用"目前可确认的是 / 需要发布前确认的是 / 更稳妥的表达是"。
- 继续完成文档，但在母稿拆解标注待确认信息。
