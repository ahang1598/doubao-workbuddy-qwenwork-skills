# 母稿资产拆解

只负责把用户素材整理成可分发的"母稿资产"。不生成平台成品。

## 1. 最小输入

满足任一即可：完整母稿 / 文章 / 口播 / 新闻 / 活动 / 产品 / 报告 / 访谈；主题 + ≥3 个信息点 + 目标受众或平台；已有某平台稿 + 目标改写平台；散乱素材但能抽出事实、观点、目标和约束。

缺关键事实时不编造，先基于已知信息产出，缺口列入"待确认信息"。

## 2. 母稿资产卡

| 字段 | 内容要求 |
| --- | --- |
| 原文主题 | 一句话说明母稿讲什么 |
| 核心主线 | 本次分发必须保留的中心判断或叙事线 |
| 目标受众 | 谁会关心，为什么关心 |
| 关键信息 | 事实、数据、时间、地点、产品、人物、政策、活动 |
| 可分发切口 | 可被不同平台拆开的角度 |
| 情绪/冲突 | 共鸣、反差、问题、焦虑、期待、讨论点 |
| 方法/建议 | 可转成清单、步骤、口播动作或观点的内容 |
| 视觉资产 | 可做成封面、场景图、关键镜头的内容；缺真实素材优先转概念图、信息图、结构图 |
| 必须保留 | 品牌、活动、时间、价格、限制、CTA 等不可改动信息 |
| 风险与核查点 | 未核实事实、敏感承诺、可能夸大的表达 |

## 3. 平台切口映射

| 母稿资产 | 小红书 | 公众号 | 短视频 | 微博 |
| --- | --- | --- | --- | --- |
| 事实/背景 | 只取与读者直接相关部分 | 保留完整事实链 | 转字幕/画面提示/一句台词 | 压缩为判断依据 |
| 数据/报告 | 做清单、卡片、自查点 | 用于论证 | 做图示/花字/屏幕画面 | 提炼一句传播点 |
| 案例/故事 | 生活化、经验化 | 展开叙事或证据 | 场景化、动作化 | 一句话概括为观点支撑 |
| 情绪/冲突 | 强化共鸣 | 克制使用 | 放到开场钩子和转折 | 强化态度和讨论入口 |
| 方法/建议 | 收藏清单和步骤 | 完整方法论 | 可展示动作 | 短建议或互动问题 |
| 视觉元素 | 封面、场景图 | 头图、结构图 | 封面、关键镜头 | 场景图、内容图 |

## 4. 分发母稿草案

散乱素材时先整理内部草案：150-300 字写清主题 / 背景 / 核心观点 / 主要信息；保留原始事实，不扩写成未经证实的结论；用"可能 / 适合 / 建议 / 可考虑"降低确定性；最终文档可展示"默认假设"和"待确认信息"，不暴露内部推理。

## 5. 缺口处理

- 缺平台：默认四平台（小红书、公众号、短视频、微博），除非内容明显不适合。
- 缺受众：使用稳妥的通用受众并标注"默认假设"。
- 缺图片素材：不停止出图；优先概念化视觉 / 场景示意图 / 信息图 / 结构图。只有用户明确要求必须真实素材且无法安全替代时才 `blocked`。
- 缺事实来源：不写"已核实"；高风险内容标"发布前需确认"。
- 缺 CTA：按内容目标给低风险 CTA（收藏、评论、预约、查看详情、报名链接待补充）。
