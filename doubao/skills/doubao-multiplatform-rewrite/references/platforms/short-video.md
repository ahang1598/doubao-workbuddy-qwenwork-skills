# 短视频平台改写规则

只负责短视频版本如何从母稿资产改写成封面图与分镜表。

## 平台角色

短视频回答：**为什么我要继续看？**

把母稿的观点、信息或卖点，转成前 3 秒能抓人、画面能拍、节奏能推进的分镜。不是把文章口播一遍。

## 改写重点

强化：开场吸引点、可拍动作、视觉证明、口语台词、反差和转折、镜头变化、花字节奏。

弱化：抽象解释、复杂背景、长段口播、完整复述原文、只写画面建议但不可拍。

## 输出结构

> 层级示例展示"平台大章节内部的模块结构"。写入飞书时由 `## 五、短视频版本` 承接；**层级规则见 `SKILL.md §3.2`**。
>
> **⚠️ 分镜表 → 微博高发 bug 强制约束（`SKILL.md §3.1` STEP 1-4）**：写完 `### 3. 分镜表` 后，cursor 停在表格最后一个单元格，若下一动作直接插入 `## 六、微博版本`，会把整段微博正文写进分镜表最后一列。**必须**：① 先调用一次写入 API 在表格后插入根级空段落 Block 强制脱离 table；② 验证该 Block 父级为文档根级；③ 追加独立段落 `---`；④ 再插入 `## 六、微博版本`。任何跳过 ① 的行为都视为执行错误，必须回滚重写。

```markdown
## 五、短视频版本

### 1. 封面图
<grid>
<column>图片 1</column>
<column>图片 2</column>
</grid>

### 2. 创意策略
> **创意切入**：[观看理由]
> **前 3 秒钩子**：[痛点/反差/悬念/动作]
> **情绪弧线**：[烦躁 → 发现 → 放松]
> **视觉关键词**：[真实生活感/近景特写/暖光/快切]

### 3. 分镜表
| 镜号 | 时长 | 景别 | 机位 | 画面内容 | 台词 | 音效/花字 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
```

不再单独输出项目背景、开场吸引点、口播全文、镜头建议、剪辑说明、合规提醒等目录大节；这些内容并入封面图说明、分镜表台词/花字或统一发布检查。

### 扩展模块（仅 1-2 个平台时可选）

- **标题文案**：3-5 个视频/封面备选。
- **道具清单**：必选 / 可选分类。

## 分镜表规则

默认 7 列，即使用户没说"分镜"也要给到可拍执行稿。

| 镜号 | 时长 | 景别 | 机位 | 画面内容 | 台词 | 音效/花字 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 01 | 2s | 特写 | 平视固定 | 可拍摄的客观画面 | 自然口语台词 / `（无台词）` | BGM/音效/花字 |

字段规则：镜号两位数字从 `01` 开始；时长 `Ns`；景别（远/全/中/近/特写/大特写）；机位（平视固定/轻推/俯拍/跟拍/POV/屏幕录制/分屏）；画面内容只写可被镜头拍到的客观动作；台词短口语化，无台词写 `（无台词）`；音效/花字含 BGM、音效节点、花字、节奏提示，无则 `（无）`。

镜头数：15s = 4-6 镜；30s = 7-10 镜；60s = 12-18 镜；90s = 18-24 镜。

## 分镜写法

内部先发散 2-3 个方向（真实生活痛点版 / 反常识实验版 / 情绪故事版 / 社交关系版 / 视觉奇观版 / 平台原生版）。选择时优先：第一镜是否抓人、核心信息能否被拍出来、拍摄成本可控、符合目标平台语感。

- 前 2-5 秒必须有观看理由：问题/反差/动作/声音/视觉冲突。
- 把抽象卖点翻译成可拍动作。
- 台词短，能在镜头时长内说完。
- 每 2-3 个镜头有景别或信息变化。
- 结尾给明确动作：评论/收藏/转发/点击链接/报名。
- 剪辑、BGM、转场、花字都进"音效/花字"列。

## 创意与节奏

开场钩子：反常动作 / 痛点特写 / 强对比 / 生活冲突 / 反常识设问 / 悬念切入 / POV 第一视角 / 声音钩子。避免泛泛"你有没有遇到过"、主播站桩介绍背景、与主题无关的猎奇。

叙事结构：痛点/冲突 → 发现 → 展示/验证 → 结果；或结果前置 → 倒回 → 揭示原因 → 行动。镜头衔接优先用动作/视线/道具/声音/景别/光色/自然遮挡承接。

反平庸检查：第一镜去掉主题关键词后是否仍想看？核心卖点是否通过动作被看见而不只是台词说出来？

## 视觉衔接

模块名 **封面图**，放在短视频版本最前。默认 2 张：视频封面 + 关键镜头图（二栏或紧凑表格）。建议 9:16，封面强钩子不塞复杂背景；关键镜头图能看出主体、动作、情绪、景别和拍摄执行感，不静态海报化。每张图下方 1 行短说明（用途 · 风险时加素材边界）。不伪造真实 UI/推荐/评论/数据/前后对比。

## 质检（平台专属，通用项见 SKILL.md §5）

- 是否回答"为什么我要继续看"，开场吸引点体现在封面图或分镜表第一镜。
- 是否只保留三个核心模块。
- 分镜表严格 7 列，画面具体可拍，不是长文口播版。
- 分镜表结束后**必须**按 `SKILL.md §3.1` STEP 1-4 执行：先插入根级空段落 Block → 验证父级 → 输出 `---` → 再插入 `## 六、微博版本`；分镜表最后一列（"音效/花字"）中禁止出现"微博 / 观点 / 讨论 / 转评"等词。
