# 小红书平台改写规则

> 通用 Block / 缩进 / 编号 / 段落间距底线 / 图片规格标注禁令 → 以 `references/common/output-standard.md` 为准。本文件只保留小红书平台专属内容。

## 平台角色

小红书回答：**这和我有什么关系？**

把母稿的背景、观点、产品或活动，翻译成读者能立刻感知的场景利好、避坑经验、收藏清单或自查步骤。

## 改写重点

强化：读者收益（省时间/省钱/变好看/少踩坑）、使用场景、收藏价值（清单/步骤/对比/自查）、封面点击（短句/结果/反差/问题）、搜索标签。

弱化：宏大背景、官方通稿腔、长论证、抽象战略、过重企业表达。

## 输出结构

> 层级示例展示"平台大章节内部结构"。写入飞书时该平台大章节由 `## 三、小红书版本` 承接。

```markdown
## 三、小红书版本

### 1. 笔记配图
<grid>
<column>图片 1</column>
<column>图片 2</column>
</grid>

### 2. 标题
- 3-5 个备选标题（无序列表，不用 `1. 2. 3.` 编号，避免与 §2 章节编号视觉重叠）

### 3. 正文
一篇可直接复制的小红书正文，末尾自然包含标签和互动。
```

### 扩展模块（仅 1-2 个平台时可选）

- **话题标签备选**：5-8 个，分核心 / 流量 / 长尾。
- **评论区互动引导**：2-3 条置顶或首评话术。

## 正文写法

改写链路：定人群 → 定价值 → 整素材 → 定切口 → 定标题 → 定正文骨架 → 定互动关键词。

四个判断：**定人群**（写给谁）；**定价值**（帮选择 / 避坑 / 提升 / 共鸣 / 发现 / 表达 至少命中一个）；**定切口**（只选一个主钩子）；**定搜索词**（标题、首段、标签自然覆盖品类词、场景词、问题词）。

- 标题 3-5 个覆盖不同点击动机；单个 ≤20 字。
- 开头 3 行给理由：痛点/收益/反差/结果/场景，接住标题承诺。
- 中段清单或短段落展开，不写成公众号式长论证。
- 一段一个点，适合手机扫读。
- 结尾给低成本动作：收藏/评论/私信/报名/查看链接。
- 标签放正文末尾 3-6 个。
- 不编造亲身体验；无体验素材时写"适合这样用 / 建议先确认"。

### 排版节奏

- **短段落**：1-3 句一段，最多 4 句。
- **视觉锚点**：清单/步骤/要点用 ✅💡⚠️📌✨ 开头，每点一句。
- **重点单独成段**：核心观点/金句加粗或换行。
- **有快有慢**：开头快、中间稳、结尾暖。
- **像聊天不像讲课**：用"我发现""亲测""踩过坑""真心建议"等，不过度堆砌网感。
- **数字加粗**：关键数字、时间加黑。
- **少用生硬序号**：改用符号、空行、短段落制造节奏。

### 段落间距（平台专属补充，通用底线见 output-standard.md §5）

通用规则见 `output-standard.md §5`（段间恰好一个空段落 Block、小节标题前后各一空行、单段软换行 ≤2、大章节首尾禁止空段落 Block、分割线/引用块前后各一空行）。以下为小红书视觉锚点相关的**平台专属补充**：

- **视觉锚点分点**（✅ / 💡 / ⚠️ / 📌 / ✨ 开头短句）：每个锚点条目为独立段落 Block，**条目之间零空行**（紧贴）；整个锚点组前后各一个空行。
- **相邻锚点组切换**：两个不同符号的锚点组之间**恰好一个空段落 Block**，不因换符号额外多加。
- **末尾标签**：正文最后一段与 `#话题标签` 之间恰好一个空行；标签作为独立段落 Block；标签之后禁止空段落 Block。
- **图片与说明**：图片 Block 与图片下方短说明之间零空行紧贴；说明与下一小节标题之间恰好一个空行。
- **写入自检**：扫描所有相邻 Block 对，任一违反上述规则或通用底线，回滚统一到"每处恰好一个空行、锚点条目内零空行"。

### ✅ / ❌ 空行排版对比示例

**✅ 正例**：

```
封面点击率总上不去？

亲测这 3 个方法有效——

✅ 主标题 ≤14 字
✅ 关键词加粗 + 亮色高亮
✅ 一张封面只讲一个钩子

💡 特别提醒：反问句起势比陈述句多 30% 停留

我踩过的坑就写在评论区，来聊聊你的？

#小红书运营 #封面技巧 #自媒体
```

段间恰好一空行；`✅` 三条锚点零空行紧贴、组前后各一空行；`💡` 与 `✅` 两组之间恰好一空行；末尾标签独立段落 Block、其后无空段落。

**❌ 反例**：段间 2 行空行、锚点条目之间被拆空行、组之间 3 行空行、锚点紧跟正文零空行、标签后又追加空 Block —— 任何一项违规必须回滚。

## 常用骨架

痛点解决型（痛点→痛感加深→解法）；种草转化型（苦恼→尝试→变化→适合谁）；干货教程型（为什么值得→是什么→怎么做）；测评对比型（立标准→对比→适合/不适合）；故事种草型（日常→冲突→转折→变化）；合集清单型（收藏承诺→分类逐条→取舍建议）。

## 视觉衔接

模块名 **笔记配图**，放在小红书版本最前面。默认 2 张：封面 + 场景（二栏或紧凑表格）；建议 3:4，明亮、可收藏，封面文字 4-14 字。每张图下方 1 行短说明（用途 · 风险时加素材边界）。不伪造真实截图/评论/销量/测评/授权。图片规格 / 用途标注不写入正文（详见 `output-standard.md §6`）。

## 质检（平台专属，通用项见 output-standard.md）

- 是否回答"这和我有什么关系"，有明确读者收益和具体场景。
- 是否只保留三个核心模块，不像公众号摘要。
- 标题、正文、标签、互动一致，正文无内部说明和 Markdown 痕迹。
- 全篇段落间距统一，视觉锚点条目零空行、不同符号锚点组切换处恰好一个空 Block、末尾标签后无空 Block（通用底线见 output-standard.md §5）。
