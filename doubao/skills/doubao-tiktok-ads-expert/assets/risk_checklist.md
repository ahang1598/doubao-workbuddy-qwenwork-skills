# 🔒 风控检查清单（平台关联模式）

> 每次执行广告搭建或批量调控前必须检查的安全项

## 一、凭据安全（零容忍）

### 1.1 授权安全
- [ ] **Access Token** 绝不在聊天中发送
  - 风险等级：🔴 极高
  - 处理方式：平台关联模式下 Token 由平台统一管理，脚本和 Agent 均不接触；聊天中检测到立即拦截警告
- [ ] **Refresh Token** 绝不在聊天中发送
  - 风险等级：🔴 极高
  - 处理方式：由平台安全存储和自动刷新；任何场景下检测到立即拦截
- [ ] **授权码（auth_code）** 绝不在任何场景明文出现
  - 风险等级：🔴 极高
  - 处理方式：OAuth 授权流程由平台在浏览器中完成，不经过对话
- [ ] **Client Secret** 绝不在聊天中发送
  - 风险等级：🔴 极高
  - 处理方式：由平台统一保管，脚本和 Agent 均不接触

### 1.2 平台关联模式凭据规则
1. ✅ **平台统一 OAuth**（唯一授权方式）
   - 授权由豆包平台统一管理，无需手动配置
   - Token 不落地、不缓存、不出现在脚本或日志中
2. ❌ **本地配置文件**（不需要）
   - 平台关联模式无需 config.json、无需本地 Token 文件
3. ❌ **环境变量**（禁止）
4. ❌ **命令行参数传递凭据**（禁止）
5. ❌ **聊天对话中传递任何凭据**（绝对禁止）

## 二、账户信息安全

### 2.1 敏感字段分级
| 字段 | 风险等级 | 传输 | 输出 |
|------|----------|------|------|
| access_token | 🔴 极高 | 禁止 | 禁止 |
| refresh_token | 🔴 极高 | 禁止 | 禁止 |
| auth_code | 🔴 极高 | 禁止 | 禁止 |
| client_secret | 🔴 极高 | 禁止 | 禁止 |
| advertiser_id | 🟡 中等 | 可正常传输 | 部分脱敏（****1234） |
| pixel_id | 🟢 低 | 可正常传输 | 可正常展示 |
| 广告数据 | 🟡 中等 | 可正常传输 | 可正常展示 |

### 2.2 脱敏规则
- advertiser_id：保留后4位，前面用 **** 替代
  - 示例：`ADV-1234567890` → `****7890`（示例 ID，非真实数据）
- 账户名称：可正常展示
- 任何凭据类字段：禁止输出，如意外获取到只显示后4位
  - 示例：`abc123def456` → `****456`

## 三、操作安全

### 3.1 写操作确认
- [ ] 所有写操作（创建、修改、删除）必须有明确的用户确认
- [ ] 新建广告默认状态为 **DISABLE（暂停）**
- [ ] 启用广告前必须二次确认
- [ ] 预算设置必须明确告知用户
- [ ] DELETE 操作在预演时有明确警示

### 3.2 频率控制
- [ ] 遵循 API 限流规则
- [ ] 遇到 429 错误自动退避重试
- [ ] 批量操作分批进行（每块 ≤100 ID）

### 3.3 错误处理
- [ ] 认证错误提示重新关联连接器
- [ ] 权限不足错误提示检查授权范围
- [ ] 参数错误给出明确的修正建议

## 四、连接器安全

### 4.1 平台连接器
- [ ] 只使用豆包官方「TikTok for Business」连接器
- [ ] 不连接未知或第三方 MCP 端点
- [ ] 不通过 shell 命令、直接 HTTP 调用或手写 JSON-RPC 模拟 MCP Server
- [ ] 官方文档：https://business-api.tiktok.com/portal/docs/tiktok-ads-mcp-server/v1.3

### 4.2 授权范围
- [ ] 遵循最小权限原则
- [ ] 只读场景只授权 read 权限
- [ ] 写操作场景才授权 write 权限
- [ ] 定期在平台连接器管理中审查授权范围

### 4.3 连接状态
- [ ] 执行任何操作前必须先通过 tool_search 校准连接器状态
- [ ] 连接器未连接时输出关联引导并暂停操作
- [ ] 核心工具缺失时提示检查授权权限

## 五、数据安全

### 5.1 数据处理
- [ ] 脚本不缓存、不存储、不转发任何广告数据
- [ ] 日志中不记录敏感信息
- [ ] 不向 TikTok 分享敏感事件数据

### 5.2 输出安全
- [ ] 所有输出自动脱敏敏感字段
- [ ] 不输出完整的 Token 或授权码
- [ ] 不输出 client_secret
- [ ] 敏感商业数据提醒用户注意保密

## 六、应急响应

### 6.1 凭证泄露
1. 立即在平台连接器管理中撤销授权
2. 检查账户操作日志
3. 通知安全团队

### 6.2 异常调用
1. 立即暂停操作
2. 检查连接器授权状态
3. 验证操作范围和目标
4. 必要时撤销授权并重新关联

### 6.3 授权异常
1. 检查连接器连接状态
2. 断开后重新关联连接器
3. 检查授权范围
4. 联系平台技术支持
