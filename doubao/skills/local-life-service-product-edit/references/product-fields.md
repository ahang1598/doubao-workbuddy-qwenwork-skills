# 商品字段能力矩阵与映射指南

> **重要原则**：本文件提供字段能力的参考矩阵，但**运行时必须以实际页面为准**。不同类目（美食、丽人、休闲娱乐、住宿等）的字段存在性、可编辑性差异很大，不得凭记忆假设某字段一定存在或可编辑。进入编辑页后必须先读取真实页面结构，生成字段能力快照，再建立修改计划。

## 字段能力五态定义

运行时每个字段必须判定为以下五种状态之一：

| 状态 | 标识 | 含义 | 处理方式 |
|---|---|---|---|
| 可编辑 | `editable` | 页面存在直接输入控件，可直接修改 | 正常执行修改，写入后回读 |
| 只读 | `readonly` | 页面存在但为只读展示，无输入控件 | 明确告知商家不可修改，停止该字段 |
| 派生 | `derived` | 页面展示为计算/派生值，由其他字段计算得出 | 先定位来源字段，展示计算关系，修改来源字段间接变更 |
| 关联 | `relation` | 需通过独立关联流程/弹窗修改 | 走关联字段独立流程，不直接写入 |
| 缺失 | `absent` | 当前类目页面不存在该字段 | 停止并说明类目限制，不得声称可改 |

## 审核驳回常见原因 → 字段映射

| 驳回原因关键词 | 对应字段 | 常见能力状态 | 修改建议方向 |
|---|---|---|---|
| 图片不清晰 / 模糊 / 有水印 / 有二维码 / 有其他平台logo | 商品主图 / 详情图 | `editable` | 更换清晰、无水印、无二维码的真实图片 |
| 图片与商品不符 / 盗图 / 非实拍 | 商品主图 / 图片集 | `editable` | 使用本商品真实拍摄图片 |
| 图片数量不足 / 需至少X张图 | 商品图片集 | `editable` | 补充图片至要求数量 |
| 标题含极限词 / 违规词 / 虚假宣传 | 商品名称 / 标题 | `editable` | 删除"最""第一""顶级""全网最低"等词，写入前硬校验 |
| 详情页含极限词 / 违规承诺 / 绝对化用语 | 商品详情 | 部分类目 `absent` | 修改违规表述，改为客观描述；如字段缺失需核对类目 |
| 价格异常 / 与实际不符 / 价格虚高或过低 | 团购价格 / 原价 | 售卖价 `editable` / 原价多为 `derived` | 核对真实价格；原价需通过修改套餐/服务项目来源字段调整 |
| 套餐内容描述不清 / 缺失 / 与图片不符 | 套餐内容 / 商品详情 | `editable` | 补充完整、准确的套餐内容描述 |
| 使用规则不明确 / 有歧义 / 缺失 | 使用规则 | `editable` | 明确可用时间、预约要求、限制条件等 |
| 有效期不合理 / 过期 / 未设置 | 使用有效期 | `editable` | 设置合理的有效期 |
| 适用门店错误 / 门店不存在 / 门店未关联 | 适用门店 | `relation` | 核对并选择正确的门店，走关联流程 |
| 资质缺失 / 需补充资质 / 行业资质不符 | 行业资质 / 商品资质 | 部分类目 `absent` | 需商家上传对应资质文件；如字段缺失需核对类目是否选错 |
| 类目错误 / 品类不符 / 选错分类 | 商品类目 | — | 调整至正确的商品类目（类目变更可能影响字段能力矩阵） |
| 商品名称与类目不符 | 商品名称 / 类目 | — | 调整名称或类目使之一致 |

## 字段分类与能力说明

### 基础信息
- **商品名称/标题**：商品在前台展示的名称，有字数和合规限制。`editable`。写入前校验字数限制和极限词/绝对化用语。
- **商品类目**：商品所属分类，影响审核规则和前台展示。类目变更后需重新读取字段能力矩阵。
- **商品主图（首图）**：第一张展示图，通常有尺寸、内容规范要求。`editable`。需商家提供真实素材。
- **商品图片集（轮播图）**：多张展示图，有数量下限要求。`editable`。

### 价格与库存
- **原价（划线价/门市价）**：商品标注的原价。多数类目为 `derived`，由套餐/服务项目总价计算，无直接输入控件。如需修改，需调整来源字段（套餐内容/服务项目）。
- **售卖价/团购价**：用户实际购买价格。`editable`。写入前硬校验：正数、精度、类目上下限、与原价的价格关系（售卖价不得高于原价）。
- **库存数量**：可售卖的**最终总份数**，不是增量。`editable`。写入前校验非负整数。区分 `set`（设为目标值）和 `increment`/`decrement`（增量调整，需先读原值计算）。
- **限购规则**：每人/每账号限购数量。`editable`。必须为正整数或"不限"。

### 商品内容
- **套餐内容/规格**：团购包含的具体项目、数量。`editable`。变更可能影响派生的划线价。
- **商品详情（图文详情）**：详细介绍，支持图文混排。部分类目（如美发）为 `absent`。写入前校验极限词/绝对化用语/不实承诺。
- **商品标签/卖点**：前台展示的亮点标签。部分类目（如美发）为 `absent`。

### 使用规则
- **可用时间**：工作日/周末/节假日/全天等可用时段。`editable`。
- **使用有效期**：购买后多长时间内有效。`editable`。
- **适用门店**：可核销的门店范围。`relation`，需通过独立关联弹窗操作，不直接写入。
- **预约要求**：是否需要预约、提前多久。`editable`。
- **退款规则**：是否支持随时退、过期退、有条件退。多数类目为 `readonly`，仅展示不可编辑。

### 资质与其他
- **行业资质**：特殊行业需上传的许可证等。部分类目（如美发）为 `absent`。需商家提供真实资质文件。
- **商品资质**：特定商品需补充的证明材料。部分类目（如美发）为 `absent`。需商家提供真实资质文件。
- **客服电话**：商家联系电话。部分类目（如美发）为 `absent`。
