# Trigger Boundaries

## Should Trigger
- 距离六级还有 60 天，听力很差，每天 1.5 小时，帮我安排。
- 考研英语阅读总错，帮我复盘错题并调整计划。
- 软考还有 30 天，帮我做冲刺日历。
- 用户要求交付：备考日历、每日任务、错题复盘、阶段检测
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我找泄题答案。
- 帮我写社团推文。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 目标分数与时间明显不现实。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
