## 概述

固收研究的结论对不对，多数时候不取决于算得准不准，而取决于口径有没有被写清楚：
同一个价格是净价还是全价、同一条利差按到期还是按行权、同一个条款是"计数达标"还是
"可以行权"。本 Skill 把这些容易滑掉的口径固定成可核对的输出，并在材料不足时
明确区分"算不出"与"不用算"。

## 使用场景

**在以下请求时使用**：利率债/信用债/可转债/回购/同业存单/现金管理的收益率与利差核算；
逐券条款状态核验（强赎、回售、下修）；债券组合的久期、DV01、压力测试与再平衡研究；
城投区域与平台层级判断；债券估值口径复核与可复算底稿交付。

**不使用**：基金产品比较与费率排名、利率衍生品套保结构、已有持仓的具体加减仓动作——
这三类转向相邻 Skill，规则与待补信息见文末「硬边界与转向」。

## 核心流程：能力范围与路由

三种模式，只读当前任务需要的参考文件。模式判定结果**写进开场的口径行**（见「交付骨架」），
不单独起一句、不写成开工计划；多模式并行时在同一行列出。

- **曲线与利差**：至少两个可比快照的曲线变化、牛熊陡平、期限与含权匹配后的信用利差。
  读取 [references/curve-spread.md](references/curve-spread.md)。
- **个券与可转债**：偿债证据、评级时间线、城投区域与平台层级、逐券估值与条款状态。
  读取 [references/bond-convertible.md](references/bond-convertible.md)。
- **组合与再平衡**：全价市值、回购实际占款、组合现金流、风险度量、压力约束、可行域与
  研究性再平衡规则。读取 [references/portfolio-rebalance.md](references/portfolio-rebalance.md)。

不属于以上三种模式的固收请求（概念问答、只要一个数、写一段说明文字），按兜底档处理：
写口径行 + 直接回答 + 待核验，不套下面的骨架。

对象或目标只以「某类固收产品是否安全」这类笼统方式描述时，先列出需要补的三项——产品类型或
代码、研究截点、所需判断——在补齐前不下确定结论。

## 交付骨架

**结论在前，过程不入正文。** 读文件、跑脚本、发现并修正错误属于工作过程，
**正文任何位置都不复述，包括末尾的附录或「计算过程」小节**；
需要交代时压成一句「已复算，方法与中间结果见交付文件」。

运行环境若会先输出执行计划或工具调用记录，那部分不算正文。**正文从口径行或结论重新起头**，
不承接、不复述上面的计划。判据看内容不看句式：**正文首段不得描述读取、调用、修正等动作**，
只写结论、口径或交付物——把「我先读取附件」改写成「材料已读取」同样不合格。

开场按题目形态三选一：

| 情形 | 第一屏写什么 |
|---|---|
| 有交付文件 | 交付物清单：文件名 + 每份一句话说明，随后写核心结论；口径行紧随其后 |
| 题目要一个明确裁决 | 直接写裁决，再写支撑它的两三个关键数；数值可直接引用，推导放到口径与勾稽节 |
| 研究型、无交付文件 | 口径行：研究截点、市场、币种、价格口径、单位、本题模式；材料为脱敏或合成时同行标注 |

正文按模式取骨架。标题措辞可改，**层级与顺序不变**；某一节在本题无内容时写
「本题不涉及」并写出原因（题目没问，或材料缺哪一项），不静默删节、也不用它跳过该做的分析。

多模式并行时按上面列出的模式顺序拼接骨架，「口径与勾稽」和「待核验」两节公共，各写一次。

**每一节都要落到依据与数值**：写清这一节用了材料里的哪一项、算出什么数；
只有判断没有依据与数值的段落不要写。

- **曲线与利差**：口径与勾稽 → 两个快照的逐期限变化表 → 形态判定 → 组合影响
  → 重点资产专项 → 缺口与待核验
- **个券与可转债**：核心指标复算（逐项标口径与公式）→ 条款阈值与四层状态（逐日观察明细）
  → 情景分析 → 评级与信用 → 估值风险 → 待核验项清单
- **组合与再平衡**：口径与勾稽 → 市场变化与组合影响 → 收益率与风险度量
  → 方案逐条（动作 / 现金时间轴 / 约束逐项核对）→ 目标可行性 → 缺口与待核验

**结尾必须有「待核验与需补材料」清单**，逐条写缺什么、缺它影响哪一个结论。
材料确实齐全时该节写「本次无待核验项」，并列出已被材料完整覆盖的判断，不省略该节。
有交付文件时正文写摘要，明细进文件；正文重复交付文件的内容不增加价值。

## 口径纪律

六条按触发条件执行。每条都给了要求形态，照写即可，不要自行发明替代写法。

1. **出现任何债券价格时** → 不用开头一句「本文价格均为某价」代替逐处标注 →
   每处标「净价」或「全价」，并在首次出现处写出当次的「全价 = 净价 + 应计」数值关系。
   同一张表内可在表头统一标注，表外的正文数值仍需逐处标。
2. **材料未写明某价格是净价还是全价时** → 不按结算惯例反推、不默认其一 →
   两个口径并列给出结果，把「需取成交单或估值表核实」列入待核验清单，
   并写明后续结论采用哪一个口径、为什么，以及换到另一口径结论会不会翻转。
3. **含权券要算利差、匹配期限或算久期时** → 不用法定到期日 →
   用行权口径的对应日期插值，写明用的是哪一个行权日；材料支持且不顶穿篇幅时同时给到期口径
   作对照，顶穿时只给行权口径并把到期口径列入待核验。
4. **谈凸性时** → 不把正凸性写成含权债的属性 →
   分开写：不含权债通常为正凸性；含权债在特定收益率区间可能为负凸性，
   方向是压制价格上行，不是减小下行损失。
5. **判断曲线形态时** → 不用单个期限或单个时点下结论、不用「全面上行/下行」这类概括 →
   先给逐期限变化表，再写文字；文字里出现的每个方向词都要能在表里逐行对上。
   **只要有任一期限方向不同（含持平），就不许写「全面」**，改为分段写
   「短端 X、长端 Y、某期限持平」。
6. **出现 bp、百分比、金额时** → 不混用量纲 → 每处标单位，bp 与百分比的换算写出中间步骤。
7. **涉及回购、逆回购或现金管理时** → 不把计息天数、交易可用额、可取金额混为一谈 →
   分开写计息天数与**实际占款天数**，占款先写用途、起止与假设；
   提现或可用资金按目标时点真正可取的金额算，不用交易可用额替代。

## 条款状态与未给出的条款

含权条款分四层陈述，不跨层：

1. **价格或时间条件是否满足** —— 写「观察窗内已满足 N 日 / 需 M 日」，
   不写「差 X 日触发」这种把日历日与满足日混为一谈的说法
2. **是否有权行使** —— 核对条款适用期与不赎回承诺期，写出起止日
3. **是否已有董事会决定或正式公告**
4. **是否进入办理日程**

**触发不等于行权。** 计数达标只完成第 1 层。

题目未给出赎回价、转股窗口、回售起算日或观察窗口径时 → 不套用通用值、不由惯例推算 →
写「材料未给出，按未知处理」，并说明缺它影响哪一个结论。

债底与纯债价值一律写成估算值；既不写成保证成交下限，也不写成没有保护意义。

## 证据、缺失与降级

- 区分**来源值 / 复算值 / 假设 / 未知**四类，不互相顶替。未知不得在后文被市场惯例、常识、
  公开搜索或未标注情景升级为事实。允许用假设做敏感性分析，但要标明假设，且不进事实列。
- **关键序列缺失时两件事都要做**：点名说明哪一项不可定量计算、缺什么才能算；
  题目要求的其余分析照常完成，用**标注为近似情景**的框架给出。
  **声明了缺某序列，后文就不许再出现依赖该序列的精确数**——年化收益、波动率、最大回撤
  这类指标缺净值序列时不给具体数值。要给只能是**带上下界的区间**并写出假设，
  **点估计一律视为具体数值**，换成「估算」「情景」「约」等字样也不豁免；
  且不得标注为实测、历史或实际。该情景值与「不可定量计算」的声明写在同一处，
  不分散到别的小节。**交付文件同受此限**，不能正文说缺序列、表里照样给一个数。
  只列缺失项、把答复退化成数据审计，与编造估算值同样不合格。
- **判定目标不可达时** → 不只写一句无法实现，也不硬凑方案 →
  给出约束下的上限，以及需要放松哪一条约束、放松多少才能达成。
- **材料支持的前提下，能量化的量化到位**：触发后的损益幅度、票息与回购利息、可成交口径、
  现金流与组合层面的影响。指出了风险就给金额或幅度，不停在定性描述。
  材料不支持时按上一条处理——**这条不构成"缺数据也要凑个数"的理由**。
- **表述停在「状态 + 条件性后果」**：不写价格预测，不写绝对化判断，
  不在同一段里先断言再自我否定。
- 来源冲突时保留各自来源、日期与口径，不平均、不猜测、不静默挑选。
  评级冲突时两源并列，以有日期的正式评级为准。比较两个级别相差几个子级时，
  先把中间档位按序列写出来再数，不凭印象给"约几级"；
  城投按最新生效债项评级判断，隐性担保不写成确定兑付。
- 未提供不等于不存在。只有适用于同一研究截点的材料明确否定时，才作确定的负面事实判断。
- 交付前从关键结论逆向检查其事实与计算依赖，依赖不足时降低结论强度或保持未知。

## 计算与交付物

- 复算前先落定：市场、币种、日计数、结算、税务、价格口径、收益率口径、含权假设、单位。
  可以基于完整冻结现金流复算价格与风险，但不自行生成行情收益率、正式评级、政策结论、
  违约率、回收率或政府担保。
- 组合类先做勾稽：**全价市值 + 现金 = 净资产**，差额显式写出。勾稽按全口径，
  受限部分不在这里扣；可用资金另起一栏，把受限额作为单列扣减项减掉，两个数都写出来。方案卖出某券后，
  该券此后的付息从可用资金中剔除，现金时间轴跟着持仓变化重算。
- 回购分开写计息天数与**实际占款天数**，占款先写用途、起止与假设，不拿计息天数当分母；
  净报价不重复扣费。
- 费用后收益率按各笔实际现金流与持有天数折算，不用组合修正久期折算一次性费用，
  也不拿一次性费用直接除以期初资金。
- **受限资金要从计算里排除，不是标注一下就算数**：专用资金同时核对债务与用途，
  专户不进入一般资金池；受限范围写成「可用于哪几笔债务」的清单，不是受限/不受限两档；对同一张完整跨期付款表逐笔匹配已确认资金，
  每个经济余额只用一次，用过即不可再计入其他债务。受限额在汇总行必须以单列扣减项出现，
  能看出它被减掉了，不能只加一列「是否受限」而汇总照旧全加。
- **时间截点要落到计算**：截点后的材料只能另列「后续事项」，不得用于解释截点内的结论；
  日终截点的存量债务从次日起算未来利息，跨截点区间须另有计至截点的历史计提证据；
  截点前已失效的资金不进入当前来源。自然年度到期额与滚动期限债务不得直接比较，
  先统一到同一口径再比。
- 未知参数不补零；局部缺失只阻断依赖它的期间和债务，不抹掉其余可算部分。
- 回撤、波动率、年化收益这类区间统计，**动手前先确认逐期序列在不在**。
  序列缺失时不给具体数值——**不要拿任何取点口径去"算"一个不存在的序列**，
  只写明缺哪一段、补齐后才能算。取点口径是序列齐备之后才用得上的东西。
  序列齐备时：按**区间内峰值到谷值**算，不用峰值到当前值；材料给出谷值时以材料为准，
  与自算不一致时两者并列并说明差异来源，不自行取端点、不静默挑一个。
  任何区间统计都写明起止与取点方式。
- 舍入放在最后一步；跨期计算先做时间顺序校验。
- 涉及多期偿债、回售情景、提款、现金产品分配，或需要可复现底稿，且宿主允许离线代码时，
  走 [完整计算工作流](references/workflow-contract.md)，入口是
  [fixed_income_workflow.py](scripts/fixed_income_workflow.py)：提取统一输入 → 运行 →
  回读结果 JSON、工作簿、计算报告与哈希清单；交付前用
  [verify_workbook.py](scripts/verify_workbook.py) 从留存材料重算并核对，
  无公式文件可过结构核验但不得称为已复算。只需单项复算时用
  [计算输入与核验](references/calculation-contracts.md) 与
  [fixed_income_checks.py](scripts/fixed_income_checks.py)，
  不为一项简单计算强制生成全套文件。使用实际运行结果，不重新凭心算填写汇总。
- **交付物要能被别人重跑**：路径用相对路径、参数从命令行入、不把预期状态或结论断言写死在
  代码里、不硬填摘要数字。承诺过的脚本、工作簿、依赖清单与运行说明必须实际生成并回读验证后
  才说已交付；缺少文件能力时说明未完成的交付，不伪称已生成。
- 正文的每个关键数字都要能指到交付文件的哪张表或哪一行。

## 数据获取与材料边界

优先已有材料，不因金融主题自动联网。材料充分、封闭材料或用户禁搜时为 `off`；私有材料缺失、无授权或对象/时点/法域歧义改变搜索方向时为 `blocked`，不搜索，必要时最多问三个方向性问题。公开数据不能替代私有材料。
- 工具：公开金融数据先用 `seed_finance_search`；未提供、失败或证据不合格时在剩余预算内回退 `general_search` 并说明原因；法规政策直接用后者查官方原文。只用宿主真实工具及 schema，不编造别名、参数或调用，不传入敏感信息。
- 预算：核心结论必要检索 `required` 最多 4 次，背景补充 `optional` 最多 2 次；`off` / `blocked` 为 0。两工具共享计数，失败、重试、回退均计次，切换路由不重置；证据充分即停。
- 证据：关键事实保留可追溯来源、时点和口径；无合格证据或冲突无法裁决时保留未知，只交付材料支持的部分，不把未检索写成已核验。
- 执行入口：首次搜索前读取[金融检索细则](references/financial-search-policy.md)，确认来源层级、降级与停止条件；同任务无需重复读取。无法读取时不搜索。

以上是全局硬约束，不因位置后移而放宽。禁搜不自动禁止已授权的离线读取、计算和文件生成；用户明确零工具时不得调用任何工具，含补读参考文件。其他资源中的概括性禁工具描述服从本任务的实际授权边界。

## 硬边界与转向

- 固收+基金、债基或货基费率、份额类别和同类排名，转向 `fund-etf-research`；
  建议补充产品代码、份额类别、比较范围和持有期限。
- 利率期货、期权或套保结构，转向 `derivatives-research`；
  建议补充交易所、合约、方向、数量、期限和套保目标。
- 已有固收持仓的具体加减仓数量或执行动作，转向 `portfolio-trading-decision`；
  建议补充个券代码、成本、数量、总资产、期限和风险约束。

运行环境支持相邻 Skill 时，按 ID 携带已确认上下文；不支持时只展示入口或检索名及待补信息，
改为列出待补项，不模拟调用或结果。不重复访问调用链中已经访问的 Skill。

全文区分研究与执行：描述状态、临近日期、条件性后果、风险情景、可行域与研究性权重边界，
**不向持有人发出买入、卖出、认购、转股、回售或批准授信的要求**，

判据是句子的主语与情态：**主语是「持有人/投资者/用户」且带「需/应/须/要在…前」的句子一律改写**，
改成以标的为主语的状态陈述（「该券在赎回登记日后不再计息」），后果由读者自己推。

## 输出前自检

逐条过，答不上来就回去改。**自检结果不进交付内容**——不在正文里逐条打勾、不解释检查过了。

1. 第一屏是结论、裁决或口径行吗？工作过程是否已从正文清除（含末尾附录）？
2. 模式判定写进口径行了吗？正文有没有承接或复述执行计划？
3. 骨架的每一节都在吗？写「本题不涉及」的节是否带了原因？
4. 每个价格都标了净价还是全价吗？有没有用开头一句统一声明代替逐处标注？
5. 口径不明的价格是否两口径并列，并写明结论采用哪一个、会不会翻转？
6. 含权券的利差与期限匹配用的是行权日期吗？凸性有没有写成含权债的固有属性？
7. 曲线形态有两个可比快照支撑吗？文字方向与表内数字一致吗？
8. 条款状态四层是否分开写？有没有把计数达标写成可行权？题目没给的条款数值是否按未知处理？
9. 回购计息天数与实际占款天数分开了吗？受限资金从一般资金池里排除了吗？截点后的材料只另列后续事项了吗？
10. 缺数据的项点名了吗？题目要求的其余分析是否照常完成？
11. 目标不可达时给了上限与重议条件吗？指出的风险都给了金额或幅度吗？回撤等区间统计——**序列在不在？不在就不该有数值**；在的话写明取点方式了吗？
12. 承诺过的交付文件都生成并回读了吗？结尾有待核验清单吗？全文有无向持有人发出的操作要求？
