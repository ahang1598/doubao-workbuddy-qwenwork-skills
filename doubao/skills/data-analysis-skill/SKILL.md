## 基本信息

- 发布名称：`data-analysis-skill`

本 Skill 采用逐步确认的研究协作流程。论文是否存在、复现材料是否公开、脚本是否运行成功、结果是否与论文一致，属于不同事实；分别核验并分别报告，避免把“找到论文”“静态看过代码”误写成“复现通过”。

## 触发与不触发

### 应触发

在用户明确提供或准备提供数据、研究问题或目标论文，并要求完成以下一项或多项时使用：

- 分析 `.dta`、`.csv`、`.xlsx` 面板或截面数据并设计实证方案。
- 匹配同主题、相近数据结构或识别策略的可复现论文。
- 核验公开复现包并迁移固定效应、DID、IV、事件研究、异质性或稳健性分析。
- 生成或修改 Python/Stata 代码，输出回归表、系数图或事件研究图。
- 建立包含来源、命令、日志、退出码和结果差异的可复现证据链。

### 不应触发

以下请求不进入完整工作流：

- 只询问“什么是固定效应”等一般概念，且不要求处理数据或复现研究。
- 只做文案润色、论文摘要、翻译、引用格式调整或非数据型文献综述。
- 只处理图片、音视频、网页设计或生产系统监控数据。
- 未经授权要求获取、推断或披露个人敏感信息。
- 把相关性结果包装为因果结论，或要求编造论文、数据、显著性、日志、运行截图。

遇到“既解释概念又分析数据”的复合请求时，仅对数据分析和复现部分启用本工作流，并先确认交付范围。

## 工作原则

1. **一次确认一个决策点**：在数据口径、候选论文、复刻范围、关键模型调整和最终运行前暂停，等待用户选择。
2. **先核验再陈述**：引用论文时记录可访问来源；声称代码或结果可复现前必须实际运行并保留原始证据。
3. **区分模板与结论**：模板展示方法结构，不代表适用于当前数据；模型设定需由研究问题、变量定义和识别假设支持。
4. **最小化处理数据**：只读取完成任务必需的列和样本，不把原始数据、个人标识或个人路径写入搜索词、示例、日志和公开产物。
5. **不伪造运行状态**：没有对应运行环境时标记“未实跑”；仅语法或结构检查时标记“静态检查”，不得标记“通过实跑”。

## 核心工作流

### 1. 建立任务契约

先收集并复述：

- 数据文件、数据来源授权与敏感级别。
- 研究问题、分析单位、时间范围和预期交付物。
- 因变量、核心解释变量、控制变量、聚类层级及候选识别变量。
- 目标软件、可用运行环境、截止时间和允许的外部检索范围。

缺少数据文件、变量字典或研究问题时，只输出缺口清单并暂停，不猜测变量含义。

### 2. 检查数据并让用户确认

读取最少必要信息，检查文件格式、行列数、字段类型、缺失、重复、唯一键、时间覆盖和面板平衡性。对潜在个人标识只报告字段类别和风险，不展示原值。

汇报识别到的分析单位、面板键、候选因变量/解释变量和异常，并请用户确认。未经确认，不进入论文匹配和建模。

### 3. 检索并核验候选论文

先给 2–3 篇候选简表，每篇包含标题、作者、期刊、年份、研究问题、数据、方法、匹配理由和来源链接。优先级依据主题、数据结构、识别策略和复现材料可用性，而不是期刊名本身。

用户选中候选后，再核验：

- 题名、作者、期刊、年份、DOI 或稳定链接是否一致。
- 论文全文、代码、数据和说明文档分别是否可获得。
- 数据访问是否需要申请，依赖和软件版本是否明确。
- “可下载”“可读取”“可运行”“结果一致”分别处于哪一证据等级。

用户明确确认目标论文后，才获取复现材料。

### 4. 拆解并确认复刻范围

按论文实际结构列出样本筛选、变量构造、描述统计、基准回归、事件研究、异质性、稳健性、内生性和机制分析。每项标注原文表图位置、所需变量、识别假设及对用户数据的可行性。

让用户选择具体编号；只处理确认的步骤。原研究的变量、冲击或样本口径无法映射时，解释差异并请求用户选择替代方案或跳过。

### 5. 验证原分析

仅在具备授权材料和对应运行环境时执行。记录：

- 输入文件相对路径与校验值。
- 软件、版本、依赖和执行命令。
- stdout、stderr、退出码、开始/结束时间和产物相对路径。
- 原文值、复跑值、容差、差异及判定。

退出码为 0 也不能单独证明结果一致；必须对比目标统计量。环境缺失时进入[失败降级](#失败降级)。

### 6. 映射到用户数据并执行

逐项形成“直接迁移 / 需调整 / 不可迁移”清单，说明样本、变量、固定效应、聚类、权重和识别假设差异。运行前复述将执行的步骤、模型、输出和数据处理范围。

Python 面板模板见 [scripts/panel_reg_template.py](scripts/panel_reg_template.py)，Stata 模板见 [scripts/stata_reg_template.do](scripts/stata_reg_template.do)。模板中的相对输入、输出路径和变量名必须显式传入或替换，不得写个人主目录。

### 7. 汇报结果

交付以下内容：

- 数据口径、模型公式、固定效应和标准误说明。
- 系数、标准误、置信区间、样本量、拟合指标及经济/实质意义。
- 与目标论文的相同点、差异、调整原因和剩余限制。
- 代码、日志、环境清单、表图和证据索引的相对路径。
- 清楚区分已执行、静态检查、未验证和失败项。

不得仅凭显著性给出因果解释；DID、IV、RDD 等结论需同时讨论相应识别假设和诊断结果。

## 事实核验与证据分级

采用以下状态，不混用：

1. `SOURCE_VERIFIED`：书目信息或材料来源已由稳定来源核验。
2. `FILE_INSPECTED`：文件存在且内容已读取，但未执行。
3. `STATIC_CHECK_ONLY`：只完成语法、结构或关键命令检查。
4. `EXECUTED`：实际命令已运行，并有环境、日志和退出码。
5. `RESULT_COMPARED`：已将复跑结果与预期或论文值按预设容差比较。
6. `NOT_VERIFIED`：证据不足，不能下结论。

截图只能辅助说明界面或图表外观，不能替代输入、命令、日志、退出码和可定位产物。详细核验规则见[事实与证据检查清单](references/evidence-and-fact-checking.md)。

## 隐私与数据安全

- 处理前确认用户有权使用数据，并识别直接标识符、准标识符和敏感字段。
- 默认在工作区内处理；外部检索只使用脱敏研究主题和方法关键词，不上传原始数据或样本行。
- 示例、日志和报告使用相对路径，如 `inputs/panel.dta`、`outputs/run-01/`；不记录用户名、个人主目录或访问令牌。
- 输出最小必要的聚合结果；小样本分组可能重识别时先聚合、抑制或征得用户确认。
- 发现凭据、个人身份信息或未预期敏感字段时暂停，说明风险并请求处理决定。
- 发布包不得包含用户数据、运行日志、截图、临时结果或 Owner 自测证据。

详细规则见[隐私与合规](references/privacy-and-compliance.md)。

## 失败降级

- **文件不可读或格式错误**：报告具体文件和解析错误，要求提供可读副本；不继续推断。
- **变量含义或面板键不明**：给出候选字段与冲突，等待变量字典或用户确认。
- **论文或复现包不可得**：保留已核验书目信息，降级为方法映射；不得声称原论文已复现。
- **依赖安装失败**：记录失败命令和错误，提供环境修复或不依赖该组件的替代方案。
- **Stata 不可用**：只允许报告 `STATIC_CHECK_ONLY`；生成待 Owner 在授权环境执行的命令和用例，不报告运行通过。
- **代码运行失败**：保留原始 stderr 和退出码，定位到步骤；不使用截图或手工抄写结果替代。
- **结果与论文不一致**：报告差异和可能原因，标记 `EXECUTED` 但不得标记 `RESULT_COMPARED` 通过。
- **数据敏感性超出约定**：停止外部操作，先完成脱敏、最小化或权限确认。

## 交付清单

结束前检查：

- [ ] 用户已确认数据口径、候选论文、复刻范围和关键调整。
- [ ] 每个论文与复现材料声明都有来源和证据等级。
- [ ] 每个“已运行”声明都有命令、环境、日志、退出码和产物。
- [ ] 每个“结果一致”声明都有目标值、复跑值和容差。
- [ ] 路径均为相对路径或显式参数，不含个人主目录。
- [ ] 输出未泄露原始记录、个人标识、凭据或小样本敏感信息。
- [ ] 失败项和未实跑项已如实降级。
- [ ] 发布包不含自测报告、截图、日志、数据和运行产物。
