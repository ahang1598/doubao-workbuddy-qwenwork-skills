## 统一证据格式

每个用例在包外证据目录创建 `runs/<case-id>/`，至少保存：

- `input.md`：原始请求与输入说明；
- `environment.txt`：系统、软件和依赖版本；
- `command.txt`：完整命令和工作目录；
- `stdout.log`、`stderr.log`、`exit-code.txt`；
- `expected.md`、`actual.md`、`verdict.json`；
- `outputs/`：产物及 `sha256.txt`；
- `privacy-review.md`：敏感信息检查结果。

所有路径使用相对于证据根目录的写法。包含真实敏感数据时，仅保存经批准的脱敏摘要或校验信息。

## 测试数据

准备至少三类不含真实个人信息的合成数据：

1. `fixtures/balanced-panel.csv`：平衡面板，含已知固定效应和已知处理效应。
2. `fixtures/staggered-did.csv`：错位处理时点，含事件时间变量。
3. `fixtures/cross-section.csv`：截面数据，含连续结果、分类变量和缺失值。
4. `fixtures/malformed.csv`：引号未闭合或列数不一致。
5. `fixtures/empty.csv`：只有表头、没有记录。

记录生成脚本、随机种子、字段字典、预期参数和文件 SHA-256。
