# 实证论文复现与输出规范

本文件提供默认检查项，不替代目标期刊指南、目标论文设定或研究设计论证。使用前核对论文原文、复现说明和数据生成过程。

## 表格

1. 优先使用清晰的三线表，不使用无信息价值的竖线和装饰。
2. 统一报告系数、标准误或置信区间、样本量和拟合指标。
3. 在表注中明确：
   - 标准误类型与聚类层级；
   - 固定效应、权重和样本限制；
   - 显著性符号及阈值；
   - 变量变换、缩尾和缺失处理。
4. 基准回归逐列变化设定时，每一列只做可解释的改变，并注明控制项。
5. 异质性和稳健性结果不得只保留显著分组；报告预先约定的完整比较。

## 图表

1. 默认输出可编辑矢量格式；需要位图时使用至少 300 dpi。
2. 使用可区分的点、线和置信区间，确保黑白打印和色觉差异下可读。
3. 事件研究图应标明基准期、事件期、置信区间和估计窗口。
4. 图注说明样本、模型、固定效应、标准误和数据处理。
5. 不通过截断坐标轴、选择性展示时期或隐藏不确定性夸大效果。

## 固定效应与标准误

- 固定效应由识别策略决定，不把“双向固定效应”当作所有面板数据的自动默认答案。
- 聚类层级通常至少与处理赋值或误差相关层级一致；聚类数较少时评估小样本修正或替代推断。
- 不随时间变化的变量可能被个体固定效应吸收，需在解释中说明。
- 添加固定效应和控制变量前检查共线性、样本变化和吸收变量。

## 常见识别策略核验

| 策略 | 最低核验项 |
|---|---|
| 固定效应 | 面板键、组内变异、固定效应选择、聚类层级 |
| DID | 处理定义、时间点、平行趋势、动态效应、同期冲击、错位处理时点估计风险 |
| IV | 相关性、排除限制、第一阶段、弱工具诊断、推断方式 |
| RDD | 运行变量、阈值、带宽、函数形式、操纵检验、协变量连续性 |
| 事件研究 | 基准期、窗口、预趋势、置信区间、多期处理方法 |
| 机制/中介 | 时间顺序、识别假设、直接与间接效应定义、多重检验 |

## 变量与样本处理

- 变量变换必须由定义和分布支持；不得机械使用 `ln(x+1)` 或固定比例缩尾。
- 保留样本筛选流程和每一步样本量变化。
- 明确缺失值处理、异常值规则、重复记录和合并匹配率。
- 分类变量、权重和单位换算写入可执行代码与数据字典。

## 复现差异表

每个目标结果至少记录：原文表图位置、目标统计量、原文值、复跑值、绝对/相对差异、容差、状态和解释。没有原文机器可读结果时，注明人工录入来源与复核人。
