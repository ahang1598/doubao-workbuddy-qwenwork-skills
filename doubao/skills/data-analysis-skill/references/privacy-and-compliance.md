# 隐私与合规

## 数据最小化

- 只读取完成分析所需的文件、行和列。
- 变量检查优先输出类型、缺失率和分布摘要，不展示原始身份信息。
- 外部论文检索使用脱敏主题、方法和公开元数据，不携带用户数据样本。

## 敏感数据

发现姓名、证件号、手机号、地址、精确位置、健康、财务或其他敏感字段时：

1. 暂停外部传输和公开展示。
2. 报告字段类别，不复制字段值。
3. 询问是否删除、脱敏、聚合或在受控环境继续。
4. 对小样本分组评估重识别风险。

## 路径与日志

- 使用 `inputs/`、`outputs/`、`logs/` 等相对路径或命令行参数。
- 不写入用户名、个人主目录、访问令牌、Cookie、私有链接或环境变量值。
- 日志仅保留复现所需信息；错误栈中含敏感路径时先脱敏再分享。

## 发布边界

发布包只包含 `SKILL.md`、`.skillignore`、必要的 `scripts/`、`references/` 和 `assets/`。不得包含：

- 用户数据、抽样数据或变量值；
- Owner 自测报告、截图和独立证据 JSON；
- 运行日志、回归输出、缓存和临时文件；
- 凭据、令牌、个人路径和机器专属配置。

## 依赖与运行说明

Python 模板依赖 pandas、NumPy、statsmodels、linearmodels 和 matplotlib。Stata 模板使用 Stata，并通过 `esttab` 输出表格；`esttab` 来自 estout 包，不能描述为“无第三方依赖”。软件和依赖可用性必须在每次实跑证据中记录。
