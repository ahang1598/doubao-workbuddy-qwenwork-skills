# 开题报告书与学术计划书写作要求

本文件用于帮助 Agent 根据中国学生常见学术场景调整写作策略。它不是固定模板，而是文体识别、章节重心和风险控制参考。

## 总体原则

- 先判断文体：开题报告、研究计划、套磁构想、访学计划。
- 开题报告重在证明“论文可以启动”。
- 学术计划书重在证明“研究值得做，申请人适合做”。
- 硕士强调范围可控和方法清楚。
- 博士强调问题意识、理论贡献和原创性。
- 用户提供学校模板时，优先遵循学校模板。
- 缺少个人成果、文献、数据或导师信息时，使用 `【待补充：...】` 占位。

## 学位论文开题报告

### 核心关注
选题价值、研究边界、文献基础、研究问题、方法路线、创新程度、可行性。

### 硕士侧重点
- 题目宜小不宜大。
- 方法要具体，范围要可控。
- 创新可以是对象、材料、案例或方法组合上的相对创新。
- 进度安排要能支撑按期完成论文。

### 博士侧重点
- 从现象上升到学术问题或理论问题。
- 文献综述要体现学术史、关键争议和前沿进展。
- 创新点要体现知识增量。
- 研究内容要围绕统一主线递进，避免拼盘式章节。

### 章节级提醒
- 选题背景：从大背景收束到具体问题。
- 文献综述：分类综述，最后必须有述评。
- 研究问题：具体、可回答、可论证。
- 研究内容：章节之间要有递进关系。
- 研究方法：每种方法都要对应具体问题。
- 技术路线：体现研究推进过程。
- 创新点：避免“首次”“填补空白”等绝对化表述。
- 可行性：说明资料、能力、时间和条件。
- 进度安排：写阶段任务和阶段产出。

### 常见风险
- 题目过大。
- 文献综述只有罗列，缺少述评。
- 方法只有名称，没有具体用法。
- 创新点夸大。
- 技术路线与研究问题脱节。

## 学术研究计划书

### 核心关注
研究问题是否明确，计划是否有学术价值，方法是否可行，申请人与目标导师、院校或项目是否匹配。

### 通用写作重点
- 开头快速说明研究主题、核心问题和研究价值。
- 文献基础不宜过长，但要显示基本研究脉络。
- 研究问题建议列出 2-3 个。
- 方法部分说明对象、资料、方法和路径。
- 预期成果要具体可信。
- 匹配度要结合目标导师、院系平台或项目要求。
- 不得虚构论文、项目、数据或导师联系经历。

### 按用途调整

| 用途 | 写作重心 | 特别注意 |
|---|---|---|
| 保研/考研复试 | 基本学术潜力、方向理解、读研计划 | 不要写得像成熟博士 proposal |
| 博士申请 | 原创性、文献前沿、导师匹配、个人基础 | 不要一稿多投，要定制化 |
| 导师套磁 | 简短研究构想、方向契合、相关经历 | 避免群发痕迹和过度吹捧 |
| 研究型硕士申请 | 初步问题意识、方法意识、学习潜力 | 不要夸大研究成熟度 |

### 常见风险
- 写成个人陈述，缺少研究设计。
- 题目太大。
- 文献基础不足。
- 方法部分空泛。
- 与目标导师或院校没有关联。
- 夸大个人成果。

## 访问学者与联合培养计划

### 核心关注
出访必要性、合作匹配度、研究计划可执行性、阶段成果和回国延续。

### 写作重点
- 说明为什么需要到目标院校或实验室开展研究。
- 说明派出单位基础与接收单位资源如何互补。
- 研究任务应符合访学期限。
- 时间安排按月或阶段写清楚。
- 预期成果应包括论文、合作研究、数据库、学术报告或后续项目。
- 回国计划要说明如何延续合作或服务后续研究。

### 常见风险
- 写成“学习先进经验”，缺少具体研究任务。
- 出访理由空泛。
- 研究内容过多，访学周期内无法完成。
- 与接收导师方向匹配不足。
- 预期成果不可衡量。

## 默认判断规则

- 用户说“开题报告”但未说明阶段：先判断硕士/博士；无法判断时按通用开题结构生成，并提示可进一步调整。
- 用户说“研究计划/学术计划”：默认按申请型研究计划处理。
- 用户说“套磁”：默认生成短版研究构想，不写完整开题报告。
- 用户说“保研/复试”：降低研究成熟度要求，突出潜力与方向匹配。
- 用户说“申博/博士申请”：提高文献前沿、原创性和导师匹配权重。
- 用户提供学校模板：优先使用学校模板。
