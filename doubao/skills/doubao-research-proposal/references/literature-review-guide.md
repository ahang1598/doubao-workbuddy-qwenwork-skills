# 文献综述与材料理解指南

## 目标

文献综述不是简单罗列论文，而是帮助评审理解：该领域已经解决了什么、仍然卡在哪里、用户的研究为什么能推进问题。

## 强制材料摄取顺序

1. **用户已提供材料**：论文正文、参考文献、BibTeX、文献笔记、已有草稿、实验计划、评审意见、CV/成果清单。用户论文中已引用且与项目相关的文献应优先系统利用。
2. **主动检索材料**：在用户材料之外，必须主动调用已有文献调研/检索类 Skill（如`doubao-academic-researcher` skill 或 scholar_search 工具等）补充真实可核验文献，优先覆盖近5年工作，重点检查近2-3年前沿进展。
3. **占位材料**：只有当无法确认具体文献、来源或事实时，才使用 `【待补充：请填写...】` 占位。

通过检索工具获得的主动检索材料，只用于核验来源和整理参考文献，严禁以 Markdown 链接（如 `[题名](URL)`）或裸链接形式保留在正式申请书正文中；交付前应将其转换为 GB/T 7714 或用户指定的标准学术引用，并同步到文末参考文献与 `references.bib`作为来源线索，同步更新 `FACTS_AND_SUGGESTIONS.md`。

## 每篇文献的抽取字段

阅读或整理文献时，至少抽取：研究问题、方法/数据、核心发现、局限性、与用户课题的关系、可支撑的论点。只要 Agent 已经调研过该文献、了解其内容，就直接视为已确认文献正常使用，不需要额外标注"待核验"。文献记录与综述草稿默认使用 GB/T 7714 引用格式和 `references.bib` 元数据，不要把参考文献保存成 Markdown 链接；URL、检索页或系统来源标签只作为核验线索保存，不进入正式正文。

## 综述组织方式

优先使用主题分组，并在每组内部体现方法演进。必要时可按时间线或方法流派组织。每个子方向应包含经典奠基工作、近年代表性工作、与用户课题直接相关的工作，以及尚未解决的问题。

## 深度标准

默认覆盖近5年文献，重点补充近2-3年的高相关工作。每个主要子方向通常应包含2-4篇代表性文献；如果用户材料中已有大量高相关引用，应优先充分利用。文献综述不能只引用用户自己的工作，也不能只列经典文献而缺少最新进展。

## 研究缺口提炼

研究缺口应从文献演进中自然引出，避免生硬地写“现有研究不足”。推荐结构为：已有工作解决了A，但在B场景下仍存在C限制；近年方法D尝试改进，但仍缺少E；因此本项目聚焦F问题。

## 批评前人工作的原则

对已有研究保持客观、公正和克制。可以指出适用范围、数据条件、任务设定、方法假设或评估指标的限制，但不要贬低前人工作，也不要使用“完全没有研究”“填补空白”“首次提出”等无法证明的绝对化表述。

## 机构偏好

国自然等基金通常重视申请人对领域前沿的全面把握。文献综述应体现对国内外代表性工作、最新进展、关键争议和自身切入点的清楚理解，而不是只堆砌引用或只强调自己的成果。
