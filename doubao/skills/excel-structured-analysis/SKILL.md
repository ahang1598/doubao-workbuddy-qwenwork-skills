# Excel 结构化分析方法

## 概述
这是 sheet / doubao-data-analysis 的分析方法扩展，不自行实现另一套文件读写。

## 使用场景
### 应使用
- 多 Sheet 数据需要统一字段、主键、时间和单位。
- 需要分组汇总、TOP N、异常检查或跨表匹配。
- 用户要求可追溯的分析结论和口径说明。

### 不应使用
- 仅创建、编辑、格式化或导出表格。
- 仅设计或修复单元格公式。
- 物流供应链专属指标。

## 核心流程
### 1. 由基础 Skill 读取结构
先用 sheet 获取 Sheet、字段、类型、公式、样本和数据范围。

### 2. 声明统计口径
确认主键、去重、时间窗、金额单位、缺失值、分母和异常规则。

### 3. 清洗与构造指标
保留原始值和转换记录；日期、文本数字和枚举映射需可复核。

### 4. 分析与交叉校验
汇总结果与源表合计、样本行和业务恒等式交叉核对。

### 5. 交付
实际表格写回由 sheet 完成；报告说明字段、筛选范围、公式和未处理异常。

## 工具与协作
- 表格读取/写回/公式/格式必须使用 sheet。
- 跨材料经营分析可由 doubao-data-analysis 主导，本 Skill提供表格口径模块。

## 安全边界
- 只陈述已读取、已执行或有来源支持的结果；未验证项必须明确标注。
- 涉及删除、覆盖、发布、系统设置、生产数据或不可逆操作时，先展示目标、影响、回滚方式并取得明确确认。
- 不得记录或输出密钥、Cookie、访问令牌、身份证号、银行卡号等敏感信息；示例使用脱敏占位符。

## 输出与验收
- 数据字典和口径
- 清洗日志
- 汇总/异常结果
- 校验记录与表格链接

## 冒烟用例
### Should trigger
- Excel 已读取，请定义去重口径并做门店分组汇总
- 跨三个 Sheet 匹配字段并检查异常

### Should not trigger
- 把 A 列公式改成 XLOOKUP
- 创建一个空白 Excel 模板

### 边界输入
- 主键重复、金额单位不一致、合计与明细不等
