# 病历文书独立写作分支

本文件用于按已有资料起草病历、入院记录、住院病程、查房、会诊和出院记录。它只定义写作模式、内容模块及缺口优先级；专业文书模板、排版和真正 `.docx` 生成交给 `word` Skill，优先采用用户医院及适用专科模板。

本分支按文种整理原始资料，不套用常规循证诊疗报告流程。用户同时要求新的诊断或治疗判断时，另按临床决策流程处理，不能把新推断直接写成已经发生的诊疗事实。

内容模型主要参考卫生部正式版[《病历书写基本规范》（2010，卫医政发〔2010〕11号）](https://www.nhc.gov.cn/wjw/c100175/201002/b1bec53d90f243e0861529723f00221a.shtml)及[《医疗机构病历管理规定（2013年版）》](https://www.nhc.gov.cn/yzygj/c100068/201312/c9955f0471c04450a9f9ab74648fbdd4.shtml)。2002年《病历书写基本规范（试行）》已被2010正式版废止。下述模块是便于整理的内容框架，按具体文种及医院模板展开。

## 1. 先选择真实资料或模拟模式

### 真实资料模式：整理已有，未知留空

- 用户提供真实病例，或未明确要求虚构时，使用真实资料模式。资料充分时只整理、归并和规范表达；缺失部分保留占位，不因模板有字段而补造内容。
- **所有未知字段使用 `____`**，包括未知病史、体征、检查、诊断依据、处置、时间和结局。不能用“正常”“否认”“无”或模型推断填补。仅用户资料明确记载的正常、否认或无异常才可据实写入。
- 基础身份在草稿中可以去标识化；正式使用所需身份、医师签名和实际记录时间由用户或医师补齐确认，不能编造签名、倒填时点或假装已签署。
- 保留资料的病例归属、就诊/住院阶段和原始时点；疑诊、初步诊断、临床诊断、病理诊断及已明确的最终诊断分别保留，不擅自升级。不同患者或不同次住院的资料不拼接成一段病史。
- 外院辅助检查保留实际检查日期、机构名称及检查号；缺失项仍填 `____`。已发生处置、拟议方案、未执行计划分别表达，查房意见、会诊意见、执行情况和讨论共识均以真实记录为准。

本分支的真实病历空白字段使用 `____`，是普通临床输出表格缺失值显示 `-` 的文书例外。确实不适用的项目可按医院模板写“不适用”；未提供不等于不适用。

### 模拟模式：仅在明确要求时使用

只有用户明确要求虚构病历、模拟病例或教学示例时，才可构造模拟内容。**标题下醒目标注精确文案：**

**虚构病历，仅供学习**

使用明确的示例身份和模拟情境，不冒充真实患者记录或真实医师签署。签署栏保留教学占位，模拟日期与意见按模拟属性呈现。真实材料的局部缺口不自动转成模拟补全。

## 2. 缺失信息分级与继续起草

以下 A/B/C 是本分支的写作缺口优先级，属于起草和完成所需信息的分类，不是国家法定分级，也不代替医院模板的字段要求。

- **A：本类完成前必须补充或确认。** 涉及文种、病例归属、记录所对应时点及本类主要事实、医师实际判断或处理。缺 A 也先给可填写草稿，相关位置保留 `____`，再集中列出完成前需由用户/医师补齐确认的信息。
- **B：建议补充。** 有助于叙述完整、前后衔接或准确表达的资料；先按已有内容起草，未知字段保留 `____`。
- **C：可留空或不适用。** 与本次记录无关、尚未启用或确实不适用的扩展模块，按医院模板省略或保留；固定字段未知时仍用 `____`，不为 C 例行追问。

用户已提供的内容不重复索取。各文种共同的病例身份/归属、实际记录时点和签署信息均需据实处理；下文列出各类主要模块及特有 A、B 缺口。

## 3. 常用文种的内容与缺口

### 3.1 门（急）诊病历：区分初诊与复诊

**初诊模块**：就诊时间、科别、主诉、现病史、既往史、阳性体征及必要阴性体征、辅助检查、已有诊断及治疗意见、医师签名。

**复诊模块**：就诊时间、科别、本次主诉、间期病史或变化、必要体检及辅助检查、已有诊断、处理意见、医师签名。以前的检查和体征注明原时点，不直接当作本次复查结果。

如包含急诊留观，再整理观察期病情变化、实际诊疗措施和真实去向。

- **A**：本次初诊/复诊或留观类型与时点；主要症状及持续时间、本次经过/变化；已有体检和检查资料；医师已形成的诊断及实际治疗/处理意见。留观还需确认是否结束及实际去向。
- **B**：更完整的相关既往诊疗资料、用药与反应、过敏或风险背景、既有复诊与随访安排；涉及本次实际用药等关键处理的名称、剂量、途径、频次不明时，提升为 A。

### 3.2 入院记录：展开本次住院的初始资料

**模块**：一般情况（姓名、性别、年龄、民族、婚姻状况、出生地、职业、入院及记录时间、病史陈述者）、主诉、现病史、既往史、个人史、婚育/月经史及家族史、体格检查、专科情况、辅助检查、已有初步诊断、书写医师签名。待查病例据已记录的临床判断列出考虑的诊断，未知诊断留 `____`。

- **A**：本次入院归属与日期、主诉及现病史关键经过；已有主要病史、查体/专科所见和检查；已形成的初步诊断及其疑诊状态。影响本次记载的关键病史、过敏史或外院检查出处缺失时列为待补。
- **B**：各病史的进一步细节、既往病历和检查原件、完整用药变更经过及一般情况补充；字段保留与医院模板一致。

“住院病历”是多种记录和资料的集合。用户只说住院病历时，先按已有材料给出适用文种与可填写草稿，不一次虚构整套住院记录。再次/多次入院、24小时内入出院等特殊文种，按实际情形和用户医院模板扩展。

### 3.3 首次病程记录：病例特点、拟诊讨论和计划

**模块**：记录时点、病例特点（含有鉴别意义的阴性发现）、已有拟诊讨论（初步诊断、依据、诊断未明时的鉴别分析及下一步诊治分析）、已确定的具体诊疗计划、记录医师签名。分析和计划来自现有医师记录；未提供的判断不代写成已形成意见。

- **A**：支撑病例特点的入院事实；医师已有诊断/依据及适用的鉴别讨论；已确定的诊疗计划与记录时点。
- **B**：支持或反对鉴别的补充资料、前期诊疗反应、原记录中计划的进一步说明。

### 3.4 日常病程与查房记录：连续记录变化和实际判断

**日常模块**：记录时点、病情变化、重要辅助检查及已记录的临床意义、医师分析、实际措施与效果、医嘱调整及理由、上级/会诊意见和执行情况、重要告知事项、签名。

**查房模块**：实际查房医师姓名和专业技术职务、补充病史与体征、病情及诊断/鉴别分析、当前治疗效果、下一步意见或计划。主治医师首次查房应整理已有补充病史体征、诊断依据/鉴别和计划；日常及更高级别查房按实际内容记录。

- **A**：本次病程或查房的实际时点；新增或变化的事实、重要检查；实际采取的措施、医嘱变化与理由；若记载查房，需相应医师身份及真实意见。
- **B**：连续指标、症状与疗效趋势，相关沟通、复评和执行反馈的更完整资料。

未发生的查房先给可填写记录框架，不编造某医师发言或“继续原治疗”等意见。

### 3.5 会诊记录：申请与实际意见分开

**申请模块**：患者病情和已有诊疗情况、申请会诊的理由与目的、申请科别/对象、申请医师签名及实际时间等医院字段。

**实际意见模块**：已发生的会诊意见、会诊医师所在科别或医疗机构名称、实际会诊时间、会诊医师签名。申请方后续在病程中据实记录会诊意见的执行情况。

- **A**：申请时需明确病例与当前问题、申请理由/目的及已有诊疗；书写实际意见时，另需真实意见、会诊科别/机构、时点与医师信息。
- **B**：便于会诊理解的完整病史、用药、检查报告，以及已发生的补充沟通和执行反馈。

意见尚未形成或会诊尚未发生时，只生成会诊申请模板；实际意见、执行、签字或已讨论共识不补造。

### 3.6 出院记录：总结本次实际住院经过

**模块**：入院日期、出院日期、入院情况、入院诊断、诊疗经过、出院诊断、出院情况、已有出院医嘱、医师签名。实际用药、复查或随访安排按原资料记录，不自动生成新的治疗方案。

- **A**：本次入院与实际出院时点；入院/出院诊断及其状态；主要诊疗经过；实际出院情况与已确定的出院医嘱。
- **B**：更完整的检查、治疗调整与反应、待回报结果及已有后续安排。

尚未出院或结局未知时，先给出院记录草稿，对应字段保留 `____`；截至某日的病情不改写为已出院、治愈或随访结局。

## 4. 交给 Word 完成专业载体

将选定文种、已有事实、原始日期与出处、真实/模拟模式、`____` 占位字段、A/B 待补清单及用户医院模板交给 `word`。由该 Skill 按适用专业文书模板组织版式并生成 `.docx`，保留用户仅本地、禁止上传等要求。

先交付可填写草稿；正式完成前由用户或医师补齐、确认相应事实和签署信息。最终文件的可打开性按 `word` 当前流程确认，并按本任务交付约定使用 `present_files` 提供实际文档。
