# 证据检索与评价标准

本文件只定义证据来源、检索顺序、预算、内部文献记录、全文阅读和质量评价。执行顺序见 `core-workflow.md`，图表见 `clinical-diagrams.md`，报告结构和交付 见 `output-and-qa.md`。

## 1. 来源追溯

完整报告使用一份 6 列内部 CSV 保存来源编号、题名、机构/期刊、年份、原始链接和期刊级别匹配结果。研究结果、适用性、证据解释与病例分析直接用于正文，台账承担来源追溯和期刊级别复用。

## 2. 检索顺序和来源优先级

`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch。需要更细致的信息时，细化 Query，多次调用 `seed_medical_search` 获取推荐条文和上下文；也可使用 `general_search` 检索对应内容，再 fetch `general_search` 返回的可读取页面或 PDF URL。根据实际取得的内容进行分析和引用。

同一轮相互独立的搜索尽量直接同步并行发出，统一等待结果后综合；依赖上一轮结果的查询再顺序执行。PubMed MCP 调用仍遵循本文件的条件性轮数要求。

`seed_medical_search` 直接调用，无需 `tool_search`；首次使用 `scholar_search` 前先通过 `tool_search` 获取工具。用户已安装且当前可用的 PubMed MCP 可补充较新论文题录检索，按其当前工具合同设置关键词、发表日期范围等参数，并核对题名、期刊、日期、研究类型及可点击来源；PubMed 收录本身不代表证据质量。

用户未提及 PubMed 时，同一请求内 PubMed MCP 工具执行累计最多 5 轮；每次 PubMed MCP 工具调用计 1 轮，包括检索、题录和摘要读取等调用。该上限适用于 `quick_answer` 与 `full_report`，常规检索预算按需扩展时仍遵守该上限。

论文检索深度按临床问题和病例需要确定，选取重要且高度相关、能支持或改变当前判断的论文即可。主要精力放在病例分析、指南的深度理解和病例适用性，关键论文按实际需要补充。

重要指南优先核对国家最新规范及同病种较新版本，领域核心指南与论文重点提及。搜索片段用于定位证据；实际引用前获取来源正文、完整摘要或相关章节上下文，核对人群限定、统计口径、分母和时间窗。关键阈值、量表、分期、阶段定义与程度分级回到指南/共识原文和量表核实，保留官方用词；官方英语分级保留原文。

片段不足时多次更换 Query 或参数；重要搜索按工具实际支持的 snippet、max length 参数扩大返回内容。重要指南和论文主动使用 fetch 读取相关章节、表格和必要上下文；上下文或关键事实不足时按需扩展检索与深读。

### Quick Answer

`quick_answer` 先按以下顺序获取足够回答问题的证据：

1. `seed_medical_search`：查找高质量中国指南、本土共识、国家/学会规范和必要国际指南；每次 Query 必须包含 `filetype:guideline`。
2. 按当前问题需要使用 `scholar_search` 查找重要且高度相关的研究论文，优先系统综述、RCT、队列或诊断研究等高质量证据。
3. 涉及药品时，按下方“全模式药品说明书”规则补充说明书；必要时用 `general_search` 补充官方或正式原文入口。
4. 指南、按需纳入的关键论文和相关说明书已覆盖结论、适用边界与关键风险时停止。

### 全模式药品说明书

说明书检索与 `quick_answer`、`full_report` 的模式判定和药品数量无关：

1. 使用 `seed_medical_search`；每次说明书 Query 必须包含 `filetype:drug`。
2. 只采用药品名称、剂型、规格、生产企业/上市许可持有人及所需说明书字段匹配，且结构化结果中带 `url/link` 的记录。
3. 首轮结果缺失、字段不完整或不能定位权威入口时，再用 `general_search` 补充监管机构、药品上市许可持有人或其他权威正式来源。

### 完整报告

完整报告先初始化内部文献记录，再按以下顺序检索：

1. `seed_medical_search`：先搜中国临床指南、本土专家共识、国家/学会规范，再补充国际权威指南；每次 Query 必须包含 `filetype:guideline`。优先接受国家卫生健康部门、国家监管机构、中华医学会及其专科分会、国际权威学会、指南发布机构或正式期刊页面；核对题名、发布机构、年份/版本、适用人群和可访问原文链接。
2. `scholar_search`：根据临床问题和病例需要，适度检索重要且高度相关的关键论文，补充指南依据、更新证据或回答指南尚未解决的问题；优先系统综述/Meta、RCT、大型队列、诊断研究和高质量期刊论文。论文深度和数量服从当前临床判断的需要。
3. 涉及药品时，按上方“全模式药品说明书”规则补充说明书。
4. `general_search`：补充监管页、发布机构页面、正式原文入口；PPT 任务另用其检索该题材常见结构、风格和合适图片。医学结论仍采用可核验的高质量来源。
5. 环境提供的 fetch、PDF 或 OCR：主动阅读重要相关指南和论文，定向核对推荐条文、入排标准、效应量、亚组、禁忌、安全边界和完整上下文；获取能力及参数以当前工具为准。

完整报告的基础搜索优先级为 `seed_medical_search 指南与说明书 → 按需 scholar_search 关键论文 → 按需 general_search 补充正式入口`。`seed_medical_search` 可按疾病、药品或资料类型多次查询；指南使用 `filetype:guideline`，说明书使用 `filetype:drug`，同时需要两类资料时分开查询。以指南深度理解和病例分析为主，关键论文按需补充，PubMed MCP 适度补充较新论文。说明书无论来自哪条路径，都必须记录标题、来源和可访问链接。

当已获得可追溯的权威指南/共识，并按当前问题需要核对重要且高度相关的论文，现有证据对目标人群、当前问题、关键风险和适用边界已作出清楚回答，且没有会改变结论的证据冲突，在关键阈值、分期、用药禁忌和重要引用的完整上下文均已核实后，可停止扩展检索。是否取得全文不作为证据角色的机械分组条件，也不为补齐阅读状态继续检索。

来源准入与用途：

| 来源 | 使用边界 |
|---|---|
| 最新中国或国际权威指南/共识、Cochrane 或高质量系统综述、方法学可靠且与问题高度匹配的关键研究、药品说明书、FDA/EMA/NMPA 等监管来源 | 可支撑核心结论；仍需结合研究设计、偏倚风险、适用人群和病例匹配度判断 |
| 质量较好的观察性、真实世界或诊断研究，权威教材/专著、卫生政策、技术报告和专科规范 | 补充核心证据、实践背景或本土可实施性 |
| 小样本单中心研究、病例系列/报告、会议摘要、预印本、质量一般的叙述性综述、机制/动物/体外研究 | 用于罕见情况、前沿线索、机制解释或低确定性补充；不能单独支撑关键疗效或安全性结论 |
| 自媒体、营销软文、问答社区、搜索结果页、来源不明转载、疑似垃圾期刊或无法核验页面 | 不作为依据，也不进入可见来源列表 |

中国临床实践问题优先查最新版中国指南、本土共识和国内规范，再用国际指南和高质量研究互证。经典里程碑研究不受年份限制；“最新进展”默认优先近 1-5 年。

关键词按问题需要覆盖疾病中英文名/缩写/分型、干预或药物通用名/商品名、对照、关键结局、特殊人群和研究类型，不用大量同义词反复搜索同一问题。

## 3. 检索预算和覆盖

预算是常规工作量参考，用于控制上下文，不用于降低医学质量，也不用于判定 `response_mode`；问题聚焦或只问一个问题不等于 `quick_answer`。搜索片段、关键事实、适用前提或安全边界尚未核实时，按需增加检索批次、扩大工具实际支持的 snippet/max length 并 fetch 更多原文；以下数量不构成完成必要核实的上限；PubMed MCP 仍遵循本文件的条件性 5 轮调用上限。

| 场景 | search_budget | fetch_budget | 停止条件 |
|---|---:|---:|---|
| 简单、直接、风险低的快速回答 | 完成指南、按需关键论文及说明书的必要批次 | 0-1 份定向核验 | 权威指南/共识、相关研究和必要说明书已直接回答并覆盖必要风险 |
| 范围单一但仍需专业分析的问题，如单药安全或单检查选择 | 1-3 个批次 | 0-2 份定向核验 | 已覆盖最新指南、必要说明书或关键研究，且无明显冲突 |
| 常见复杂病例、多合并症或多方案比较 | 2-4 个批次 | 1-4 份定向核验 | 指南/共识、必要关键研究和安全来源已覆盖，新证据不再改变结论 |
| 罕见病、证据冲突、高风险安全问题或指南缺失 | 可按需超过 | 可按需超过 | 只扩展可能改变结论或安全边界的来源 |

完整报告按问题需要覆盖，不为达到数量继续搜索：

- 指南/共识优先中国指南和本土共识，通常保留 1-3 条直接且权威的来源。
- 关键论文按问题需要适度检索，保留重要且高度相关的系统综述、RCT、队列或诊断研究，深度和数量以支撑当前临床判断为准。
- 涉及药品、禁忌或特殊人群时，安全/说明书/监管来源 1-3 条。
- 本土实践、真实世界或机制证据按需补充。

证据不足时直接披露，不用低质量来源补数量。

## 4. 内部文献记录字段

完整报告使用 `assets/literature-log-template.csv` 创建一份内部 CSV，保留 6 列：

| 字段 | 含义 |
|---|---|
| `citation_number` | 去重后按记录顺序分配的稳定数字编号 |
| `original_title` | 来源原标题 |
| `journal_or_institution` | 期刊或发布机构 |
| `year` | 发表、发布或更新年份 |
| `url` | 工具返回的原始来源链接 |
| `journal_rank_2025` | 期刊匹配脚本写入的 2025 中科院分区/北大核心；新增记录先留空 |

如果需要写 CSV 文件，先 Read 再 Write；新建时先 Read 模板，手动批量写入已有文件前先 Read 当前内容，再 Write。随后按同一列顺序批量追加；同一文献保留一行，新增记录的 `journal_rank_2025` 留空交给脚本填写。期刊匹配脚本会自行读取 CSV 后再写回，已满足先读后写要求，直接使用其返回结果即可。题名和原始链接用于追溯，研究结果和病例分析直接用于正文。字段含逗号、换行或双引号时使用标准 CSV 转义。

类型、证据级别、关键结果和适用性从实际已核实的原文提炼，直接用于正文；期刊级别和参考文献展示格式也按正文需要组织。过程 CSV、报告 XML 和素材在任务结束后保留。

`quick_answer` 直接使用可追溯来源，通常无需创建台账。

## 5. 证据准入和原文阅读

镜像链接可以作为引用链接，保留原始镜像 URL，无需替换为主站链接；聊天引用和正式文档超链接均可使用。

可点击来源入口包括 PubMed、PMC、DOI 解析页、期刊官网、Semantic Scholar，以及搜索工具返回的第三方存储或索引中的原始 PDF 资料。使用工具返回的原始 URL，不因第三方存储或索引域名而排除资料，也不要求另换主站链接。除用户明确要求外，不额外检索核对卷号；已取得的题录信息可直接使用。

核心证据必须同时满足：

1. 有可点击原文、摘要、PubMed、PMC、DOI、期刊官网、Semantic Scholar 或搜索工具返回的第三方 PDF 存储/索引入口。
2. 已打开正文、指南原文、说明书或其他可核验来源页面；`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch，此类资料可通过多次定向搜索取得可定位的条文与足够上下文，或读取 `general_search` 返回的对应页面或 PDF。
3. 能定位到支持当前结论的推荐、表格、段落、摘要结果或论文正文位置。
4. 与病例人群、疾病阶段、干预/对照和关键结局直接相关。

只有题名、DOI/PMID 字符串或搜索片段而没有链接时，不能作为核心证据。核心或辅助角色按研究质量、来源权威性、问题匹配度和时效性判断，不按全文可及性机械分组；未阅读全文时只使用实际可核验的页面或摘要内容，不推断未见的全文细节。低级别、不权威、方法学薄弱或相关性不足的资料归为辅助参考，不得单独支撑关键疗效或安全性结论。

定向阅读重点：

- 指南/共识：推荐条文、推荐强度/证据等级、适用与排除人群、禁忌、监测、安全性、推荐理由和更新日期。
- 系统综述/Meta：PICO、检索范围、纳入研究、偏倚、异质性、主要结果、敏感性分析和结论边界。
- RCT/队列/真实世界研究：样本量、入排标准、干预/暴露、对照、主要终点、效应量、置信区间、安全性、亚组和局限。
- 诊断研究：目标人群、指标检查、参考标准、敏感度、特异度、LR、AUC、PPV/NPV 和误判后果。
- 说明书/监管来源：适应证、禁忌、剂量、特殊人群、相互作用、警示和更新时间。

长网页或 PDF 先定位章节、页码、表格或关键词；按需充分阅读后直接用于正文，引用时核对原文位置。重要计算数据同时核对分母、时间窗、计算口径和人群限定。原入口无法访问时，可使用搜索工具返回的可点击 PDF 存储或索引入口、Semantic Scholar 或其他可用原文入口，使用实际取得且上下文完整的内容。

## 6. 快速质量评价与 Oxford CEBM 2009 分级

核心/辅助用途仍按来源权威性、方法学质量、问题匹配度、时效性和可核验程度综合判断，不由某个数字等级机械决定。正式文档需要展示研究证据级别时，统一使用 Oxford CEBM 2009；聊天 Quick Answer 和最终产物入口回复不展开该分级或分级说明。

### 研究价值判断

Oxford CEBM 2009 描述研究设计层级，期刊级别描述发表载体；两者都不能替代对当前问题的具体研究价值判断。筛选和利用关键研究时，将以下六个维度作为方法层思维，不计算总分、不设置固定权重，也不要求在正文逐项列成表格：

- **问题匹配度**：人群、疾病阶段、干预/暴露、对照、结局、随访和场景是否直接对应当前病例与临床问题。问题不直接时，即使研究设计层级高，也只能谨慎外推。
- **研究设计适切性**：研究设计是否适合回答治疗、诊断、预后、安全性或真实世界问题，不机械认为某一种设计在所有问题上都更优。
- **信息量与精确性**：结合样本量、事件数、效应量、置信区间、失访和亚组规模判断；大样本不自动等于低偏倚，小样本也不自动等于无价值。
- **偏倚风险**：按研究类型检查随机化、分配隐藏、盲法、结局测量、缺失数据、选择性报告、混杂控制和利益冲突，重点评价实际支撑当前结论的结果。
- **endpoint 质量**：判断是否为预设主要终点、患者重要结局或可靠替代终点，随访是否充分，并区分统计学差异与临床意义。
- **一致性与可重复性**：考察独立队列、多中心或外部验证、研究间方向和效应是否一致，以及异质性、敏感性分析和与既有指南/研究的关系。

“×”表示任一关键短板都可能限制研究用途，不表示数学乘法。六个维度用于判断研究对当前临床决策的贡献，不用于给研究排座次。综合时依次明确：该研究能支持当前病例中的哪项具体判断，哪些匹配的人群、设计、主要终点、效应量或一致性结果构成依据，以及哪项偏倚、精确性或外推限制阻止更强结论。单项新颖结果在缺少独立重复时应标明“有前景但尚待验证”。

样本量、随访时长、期刊级别、发表时间和“首个”等信息只作为解释精确性、罕见事件捕获、时效性或适用范围的事实，不独立构成研究价值。研究价值短评按“可支持的具体判断 + 关键依据 + 主要边界”写成自然语言，只使用非排序表述，不做最高级或名次式评价。确需说明规模、随访或覆盖范围时，在研究设计或结果段写明实际样本量、事件数、随访时长和适用范围；短评只说明这些事实如何影响判断。用户明确要求跨研究比较时，可另设有明确范围和数据依据的比较段，不在短评中完成排名。

按临床问题类型使用 Oxford 原表；治疗/预防/病因/伤害问题可快速参照：

| 证据级别 | 典型研究设计 |
|---|---|
| 1a | 同质 RCT 系统综述 |
| 1b | 单个高质量 RCT，置信区间较窄 |
| 1c | 全或无证据 |
| 2a | 同质队列研究系统综述 |
| 2b | 单个队列研究，或随访不足等低质量 RCT |
| 2c | 结局研究或生态学研究 |
| 3a | 同质病例对照研究系统综述 |
| 3b | 单个病例对照研究 |
| 4 | 病例系列，或低质量队列/病例对照研究 |
| 5 | 未经明确批判性评价的专家意见、机制/基础研究或第一原理推断 |

推荐意见仅在需要综合一组证据形成推荐时使用：A 为一致的 1 级研究；B 为一致的 2/3 级研究或由 1 级证据外推；C 为 4 级研究或由 2/3 级证据外推；D 为 5 级证据，或任一级别但结果严重不一致/结论不确定的证据。不得把单篇论文的 Oxford 证据级别直接写成推荐意见。

| 证据类型 | 重点评价 |
|---|---|
| 指南/共识 | 机构权威性、系统检索、证据等级、推荐强度、适用范围、利益冲突和更新时间 |
| 系统综述/Meta | PICO、检索充分性、纳入研究质量、异质性、发表偏倚、敏感性分析和稳健性 |
| RCT | 随机、分配隐藏、盲法、样本量、主要终点、ITT、安全性和失访 |
| 观察性/真实世界研究 | 数据源、混杂控制、暴露/结局定义、选择偏倚、缺失数据、随访和外推性 |
| 诊断研究 | 参考标准、代表性、盲法、诊断性能和误判后果 |
| 机制/基础研究 | 模型与临床人群差异，不直接外推临床疗效 |

指南/共识的原文推荐等级与研究的 Oxford 证据级别分别表达。指南/共识不套用 Oxford 等级，表格该栏显示 `-`；原文采用 GRADE 或其他体系时，保留体系名称和原始等级。研究没有足够设计或方法学信息时，表格该栏同样显示 `-`。

### 期刊级别本地匹配

拟纳入文献整理后，使用本地索引 `assets/journal-rank-index.json` 对 CSV 中的期刊一次批量匹配：

`node scripts/match-journal-rank.js --csv <literature-log.csv> --in-place`

脚本直接读取 `journal_or_institution`，将匹配结果写入或更新同一行的 `journal_rank_2025`；题名、编号、年份和原始 URL 保持不变。同时作为工具结果返回逐条 JSON，包含 `citation_number`、`journal_or_institution`、`url`、`journal_rank_2025`、匹配状态和命中期刊，正文与参考文献可直接按编号和 URL 使用返回值，无需再 Read CSV 获取分区。后续新增需匹配的期刊时再按需执行。仅展示明确匹配的结果；期刊级别与研究的 Oxford 证据级别分别表达。

## 7. 引用、图表和文档展示

台账用于正文来源、图表和参考文献的统一追溯：

1. 正文使用 `original_title + url` 生成可点击题名或研究简称；需要时补充期刊、年份及经核实的证据级别。
2. 图表节点与同一条来源记录对应，图例保留来源链接；病例适用性和关键限制从实际读到的原文提炼。
3. 参考文献仍按正文需要展示 `标题｜来源｜类型｜年份｜期刊分区｜链接`；类型和证据级别从已核实内容提取，期刊分区采用 CSV 的 `journal_rank_2025` 或脚本返回的同一匹配结果。

正文首次提及具体指南、共识、研究、说明书或监管来源时，名称本身使用超链接。台账编号用于稳定追溯，正式文档是否展示编号按用户要求和文种处理。

模型综合结论的强度与当前证据和病例适用性相匹配，可按实际情况说明确定性、争议、备选或限制。引用指南/共识的正式程度、分级或推荐强度时，忠实保留官方原词，包括“强推荐”及英语等级；不得把来源的推荐等级直接转成当前病例的无条件指令。
