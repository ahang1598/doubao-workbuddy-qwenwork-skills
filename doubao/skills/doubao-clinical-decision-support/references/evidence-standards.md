# 证据检索与评价标准

本文件只定义证据来源、检索顺序、预算、内部文献记录、全文阅读和质量评价。执行顺序见 `core-workflow.md`，图表见 `clinical-diagrams.md`，报告结构和交付 QA 见 `output-and-qa.md`。

## 1. 单一证据源

literature-log CSV 是完整报告唯一的内部结构化纳入证据源，同时承担：

- 核心证据和辅助参考记录。
- 正文引用和图表节点映射。
- 实际取得的摘要或关键片段记录。
- 纳入理由、病例适配性与主要局限的紧凑记录。

不要再创建独立 JSON 证据表、citation map、第二张筛选表或第二套引用映射。正文中的指南/关键研究卡片、段落或简表只是从核心记录生成的展示视图，不是新的数据文件。

## 2. 检索顺序和来源优先级

### 简单说明书查询

当 `quick_answer` 只查询 1-3 个药品的适应症、用法用量、禁忌、不良反应、相互作用或特殊人群等说明书信息，且不涉及复杂病例、疗效排序或方案比较时：

1. 优先使用 `medical_search` 搜索药品说明书。
2. 只采用药品名称和说明书内容匹配、且结构化结果中带 `url/link` 的记录；回答中以 `[药品说明书标题](URL)` 提供可点击入口。
3. 若没有带链接的可用结果或所需字段不完整，再用 `general_search` 补充权威说明书页面。
4. 说明书信息已经覆盖用户问题时停止，不强制检索指南或研究论文。

### 完整报告

完整报告先初始化内部文献记录，再按以下顺序检索：

1. `general_search`：先搜中国临床指南、本土专家共识、国家/学会规范，再补充国际权威指南。优先接受国家卫生健康部门、国家监管机构、中华医学会及其专科分会、国际权威学会、指南发布机构或正式期刊页面；核对题名、发布机构、年份/版本、适用人群和可访问原文链接。
2. `scholar_search`：完整报告在指南/共识检索后的必经步骤，用于主动检索与问题直接相关的关键研究论文，丰富证据类型并核对推荐依据；优先系统综述/Meta、RCT、大型队列、诊断研究和高质量期刊论文。按问题选择研究类型，不为凑数量扩展。
3. `general_search` 说明书补充：药品问题优先按“`小荷医典 + 药品通用名 + 药品说明书`”检索，并核对药品名称、剂型、来源和链接。
4. `medical_search`：只用于药品说明书的最后补充；仅当上一步找不到、打不开或无法核验所需说明书时调用。
5. WebFetch/`web.fetch`、PDF 或 OCR：仅当现有信息不足以核对关键推荐、入排标准、效应量、亚组、禁忌或安全边界时，定向阅读相关章节或表格，不默认遍读全文。

完整报告的搜索优先级为 `general_search 指南/共识 → scholar_search 关键研究 → general_search 说明书 → medical_search 说明书补充`。前两步共同构成完整报告的基础证据检索；不为凑数量运行额外搜索。说明书无论来自哪一步，都必须记录标题、来源和可访问链接。

当已获得可追溯的权威指南/共识，并已通过 `scholar_search` 覆盖相关系统综述或关键原始研究，两类证据对目标人群、当前问题、关键风险和适用边界已作出清楚回答，且没有会改变结论的证据冲突时，即视为信息足够：可停止扩展检索，也无需详细阅读整篇指南或论文；只核验能支撑结论的官方推荐页或必要关键章节。是否取得全文不作为证据角色的机械分组条件，也不为补齐阅读状态继续检索。

来源优先级：

| 等级 | 来源 | 使用边界 |
|---|---|---|
| A | 最新中国或国际权威指南/共识、Cochrane 或高质量系统综述、高质量 RCT/大型队列、药品说明书、FDA/EMA/NMPA 等监管来源、顶级或核心期刊关键研究 | 可支撑核心结论 |
| B | 质量较好的观察性、真实世界或诊断研究，权威教材/专著、卫生政策、技术报告和专科规范 | 补充证据与实践背景 |
| C | 小样本单中心研究、病例系列/报告、会议摘要、预印本、质量一般的叙述性综述、机制/动物/体外研究 | 前沿线索或低确定性补充 |
| D | 自媒体、营销软文、问答社区、搜索结果页、来源不明转载、疑似垃圾期刊或无法核验页面 | 不作为依据 |

中国临床实践问题优先查最新版中国指南、本土共识和国内规范，再用国际指南和高质量研究互证。经典里程碑研究不受年份限制；“最新进展”默认优先近 1-5 年。

关键词按问题需要覆盖疾病中英文名/缩写/分型、干预或药物通用名/商品名、对照、关键结局、特殊人群和研究类型，不用大量同义词反复搜索同一问题。

## 3. 检索预算和覆盖

预算用于控制上下文，不用于降低医学质量，也不用于判定 `response_mode`；问题聚焦或只问一个问题不等于 `quick_answer`。

| 场景 | search_budget | fetch_budget | 停止条件 |
|---|---:|---:|---|
| 简单、直接、风险低的快速回答 | 1-2 个高价值批次 | 0-1 份定向核验 | 权威指南/共识与相关研究已直接回答并覆盖必要风险 |
| 范围单一但仍需专业分析的问题，如单药安全或单检查选择 | 1-3 个批次 | 0-2 份定向核验 | 已覆盖最新指南、必要说明书或关键研究，且无明显冲突 |
| 常见复杂病例、多合并症或多方案比较 | 2-4 个批次 | 1-4 份定向核验 | 指南/共识、必要关键研究和安全来源已覆盖，新证据不再改变结论 |
| 罕见病、证据冲突、高风险安全问题或指南缺失 | 可按需超过 | 可按需超过 | 只扩展可能改变结论或安全边界的来源 |

完整报告按问题需要覆盖，不为达到数量继续搜索：

- 指南/共识优先中国指南和本土共识，通常保留 1-3 条最直接、最权威的来源。
- 关键研究必须进行专门检索；按问题保留最相关的系统综述、RCT、队列或诊断研究，丰富证据类型，但不强制凑足固定数量。
- 涉及药品、禁忌或特殊人群时，安全/说明书/监管来源 1-3 条。
- 本土实践、真实世界或机制证据按需补充。

证据不足时直接披露，不用低质量来源补数量。

## 4. 内部文献记录字段

完整报告开始时，从 `assets/literature-log-template.csv` 创建 UTF-8 with BOM 的：

`literature-logs/{{YYYYMMDD}}-{{case_slug}}-literature-log.csv`

文件名和内容不得包含患者姓名、身份证、手机号、住院号等敏感信息。

CSV 只保留 8 个业务字段和 1 个必要链接字段，与医学文献检索 Skill 使用同一表头：

| 字段 | 含义 | 填写规则 |
|---|---|---|
| `evidence_id` | 内部稳定主键 | 仅在 CSV 内首次写入时分配并保持稳定，如 `G1`、`R1`、`S1` 或既有 `E001`；不得渲染到用户可见产物 |
| `original_title` | 文献原标题 | 填官方页面或原文显示的完整原标题，不擅自翻译或缩写 |
| `publication_type` | 类型 | 指南、共识、系统综述、Meta、RCT、队列、诊断研究、安全监管、说明书等 |
| `journal_or_institution` | 期刊或机构 | 论文填期刊；指南、共识、说明书和监管文件填发布机构 |
| `year` | 年份 | 填发表、发布或更新年份；无法核验时写 `未核验` |
| `evidence_level` | 级别 | 沿用来源 A/B/C/D 初步级别；原文有正式分级时可在同一格如实补充 |
| `abstract_or_excerpt` | 摘要或片段（如有） | 可留空；只写实际读取到的摘要、推荐条文或关键结果短片段 |
| `inclusion_reason` | 纳入理由 | 必填；合并记录核心/辅助用途、纳入理由、病例适配和主要局限 |
| `url` | 可访问链接 | 必填；用于真实性回查、正文链接和图表追溯 |

填写规则：

1. 每轮先筛掉明显无关、重复和低质量结果，再把拟纳入正文、图表、参考文献或保留为辅助参考的证据写入 CSV；排除项不占用 CSV 列，可在报告“检索策略与证据覆盖”中汇总排除原则和数量。
2. `inclusion_reason` 推荐使用 `用途：核心证据/辅助参考；纳入理由：...；病例适配：...；主要局限：...`，以单列保留原有适配与评价要求。
3. `abstract_or_excerpt` 可留空；按实际获取内容记录摘要、推荐条文或关键片段。仅对确实阅读全文的重要论文标注 `已阅读全文`，其他资料不标阅读状态。`inclusion_reason` 根据研究质量、来源权威性、问题匹配度和时效性标记核心或辅助用途。
4. `evidence_level` 可写为 `A 级来源；原文 1A`；原文未分级时写 `A 级来源；原文未报告`，不得把初步来源级别冒充正式 GRADE。
5. `url` 必须是可点击 HTTP(S) 原文、摘要、PubMed、期刊页、DOI 解析页或官方入口；DOI 不单独设列，需要时写成 `https://doi.org/...`。生成文档时不新增 CSV 列，而是根据已有 URL 派生 `link_label`：当前 URL 直接指向 PDF，或已有结果明确标识为 PDF 资源时写 `PDF`，其他期刊页、PubMed、DOI、指南官网或摘要页统一写 `原链接`；不为判定标签额外逐条打开网页。
6. 除可选 `abstract_or_excerpt` 外，其他字段全部必填；不得新增检索批次、筛选状态、锚文本、图表用途或适配性等过程列。
7. 含逗号、换行或双引号的字段按标准 CSV 规则转义。

`quick_answer` 不创建 CSV；优先使用足以回答问题的高质量来源，不预设可见来源篇数。回答中实际提到的每个外部证据都必须有各自的可点击 URL。禁止引用或展示自媒体、营销软文、健康博客、问答社区、聚合转载、搜索结果页及来源不明页面；缺少合格来源时如实说明，不用上述页面补位。

## 5. 证据准入和原文阅读

核心证据必须同时满足：

1. 有可点击原文、摘要、PubMed、期刊页、DOI 解析页或官方入口。
2. 已打开正文、指南原文、说明书或其他可核验来源页面。
3. 能定位到支持当前结论的推荐、表格、段落、摘要结果或论文正文位置。
4. 与病例人群、疾病阶段、干预/对照和关键结局直接相关。

只有题名、DOI/PMID 字符串或搜索片段而没有链接时，不能作为核心证据。核心或辅助角色按研究质量、来源权威性、问题匹配度和时效性判断，不按全文可及性机械分组；未阅读全文时只使用实际可核验的页面或摘要内容，不推断未见的全文细节。低级别、不权威、方法学薄弱或相关性不足的资料归为辅助参考，不得单独支撑关键疗效或安全性结论。

定向阅读重点：

- 指南/共识：推荐条文、推荐强度/证据等级、适用与排除人群、禁忌、监测、安全性、推荐理由和更新日期。
- 系统综述/Meta：PICO、检索范围、纳入研究、偏倚、异质性、主要结果、敏感性分析和结论边界。
- RCT/队列/真实世界研究：样本量、入排标准、干预/暴露、对照、主要终点、效应量、置信区间、安全性、亚组和局限。
- 诊断研究：目标人群、指标检查、参考标准、敏感度、特异度、LR、AUC、PPV/NPV 和误判后果。
- 说明书/监管来源：适应证、禁忌、剂量、特殊人群、相互作用、警示和更新时间。

长网页或 PDF 先定位章节、页码、表格或关键词；每份核心来源只保留 1-3 条可定位关键片段或摘要性提炼，不把整份文档塞入上下文。全文不可访问时不反复 Fetch。

## 6. 快速质量评价

`evidence_level` 中的“来源等级”是初筛评价，不等于原文 GRADE 或正式证据等级；若原文报告分级，在同一字段中原样记录，没有则写 `原文未报告`。

| 证据类型 | 重点评价 |
|---|---|
| 指南/共识 | 机构权威性、系统检索、证据等级、推荐强度、适用范围、利益冲突和更新时间 |
| 系统综述/Meta | PICO、检索充分性、纳入研究质量、异质性、发表偏倚、敏感性分析和稳健性 |
| RCT | 随机、分配隐藏、盲法、样本量、主要终点、ITT、安全性和失访 |
| 观察性/真实世界研究 | 数据源、混杂控制、暴露/结局定义、选择偏倚、缺失数据、随访和外推性 |
| 诊断研究 | 参考标准、代表性、盲法、诊断性能和误判后果 |
| 机制/基础研究 | 模型与临床人群差异，不直接外推临床疗效 |

不要声称完成正式 GRADE 评级，除非原文采用 GRADE 或等价体系；无原文分级时只能写“按研究设计和偏倚风险初步判断”。

## 7. 引用、图表和文档展示

CSV 直接驱动三个出口：

1. 正文引用：使用 `original_title + url` 生成可点击原标题或稳定简称，并标注期刊/机构、年份和级别。
2. 图表节点：仅使用 `inclusion_reason` 标记为核心证据或辅助参考的记录；图表不展示阅读状态。节点显示可读文献简称，并通过内部 `evidence_id` 反查 URL。
3. 完整参考文献：从 CSV 按核心证据、辅助参考分组，必要时另列排除/待核验，展示 `标题｜来源｜类型｜年份｜链接`；链接列使用派生的 `link_label`。

指南与关键研究章节可以自由使用段落、卡片或简表呈现核心发现、病例适配性和局限性，但内容必须来自已纳入的核心证据记录。

正文首次提到具体指南、共识、研究、说明书或监管来源时，名称本身必须是超链接；不得显示 CSV 的 `evidence_id`。citation 样式组件可以使用，但必须承载同一个可点击来源。

结论采用条件性表达：`相对确定`、`倾向支持`、`可作为备选`、`需谨慎讨论`、`存在争议`、`证据不足` 或 `当前不支持`。避免写成直接医嘱或使用“强推荐”“强烈支持”“强烈建议”等高程度措辞。
