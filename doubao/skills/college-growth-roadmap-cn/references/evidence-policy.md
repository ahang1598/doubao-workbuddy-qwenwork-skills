# 外部事实与证据规则

## 1. 需要强制核验的内容

- “今年/最新”的报名、考试、申报日期；
- 资格条件、学历/专业/年龄/工作年限；
- 竞赛主办方、报名对象、赛制；
- 学校竞赛认定、推免/奖学金加分；
- 国家职业资格或职业技能等级；
- 落户、人才引进、就业手续；
- 用人单位是否具备申报资格。

## 2. 来源优先级

### 一级：官方规则

1. 国务院 / 部委 / 地方政府；
2. 人社、教育、公安、考试主管部门；
3. 高校教务处、学生处、研究生院、创新创业学院等正式通知；
4. 赛事官方主办单位；
5. 法定考试/资格实施机构。

### 二级：官方解释

官方 FAQ、办事指南、政策解读。

### 三级：非官方经验

论坛、社交媒体、培训机构、经验帖只能帮助发现问题或提供待核验线索，不得用于确认硬门槛。

## 3. 每条硬节点的最小证据

至少记录：官方机构、文号/通知标题或页面标题、发布/更新日期、适用届别或对象、关键条件、访问方式、授权状态、获取时间、有效期、证据能力和最后核验日期。

## 4. Tool 与逐来源授权

- Tool 状态只能记录为 `available_authorized`、`available_authorization_pending`、`unavailable` 或 `not_used`。平台名称、可见按钮或公开 URL 不能证明 Tool 已授权。
- 每个外部来源都必须分别记录 `access_method`、`authorization_status`、`retrieved_at`、`valid_until` 和 `capabilities`；不得用一次 Tool 授权推定所有网站都允许访问、保存或再分发。
- `public_web + authorized` 仅当当前环境的页面读取能力实际可用、授权已确认且正文已打开时才允许使用。受限、需登录或授权不明的页面保持 `pending` 或 `restricted`。
- 用户提供的材料使用 `user_provided + not_applicable`，只能证明材料本身写了什么和用户目标，不能自动证明当年政策仍有效。
- 搜索摘要的证据能力只能是 `discovery_only`，用于发现官方入口，不得确认截止时间、资格、认定、流程或主管部门职责。
- 形成“已核验”结论前，运行 `scripts/validate_evidence_ledger.py`。只有输出中的 `claim_verified=true` 且来源能力覆盖具体结论时，才允许写“已核验”；`exit_code=0` 只说明结构有效。

## 5. 失效处理

若官方页面无法访问、需要登录、只有搜索摘要、文件已废止或当前年度通知未发布，则标记 `待核验`。

历史规则可以作为准备参考，但必须写成“历史参考”，不得写成当前确定要求。

## 6. 年度制度处理

职业资格考试计划、应届毕业生就业与户籍申请、积分落户等制度通常按年度发布或调整。每次回答都要查适用年度的官方通知；没有当年通知时，只能把往年规则标为“历史参考”，不能据此确认未来规则。
