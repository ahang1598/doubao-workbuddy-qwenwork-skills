# 相邻 Skill 路由边界

先看用户要求的主交付物，而不是关键词。只有主交付物是从当前学期到毕业的跨学期路线图、现有路线图体检或把某项机会放入长期主线的取舍时，本 Skill 才主导。

## 1. 与新生报到和迎新执行

“录取后要准备哪些证件、缴费、到校路线、注册步骤和迎新材料？” → 新生报到与材料清单能力主导。

“我刚入学，想从大一到毕业安排项目、实习和升学节点” → 本 Skill 主导。

混合请求若核心仍是报到执行清单，则不触发本 Skill；只有用户明确另要长期路线图时，才把长期部分作为独立交付物处理。

## 2. 与开学采购

“开学要买什么电脑、生活用品或数码设备？” → 开学采购与数码决策能力主导。

“预算有限，大学四年项目和实习怎么安排？” → 本 Skill 主导；采购只作为预算约束，不自动生成购物清单。

## 3. 与住宿和租房

“宿舍和校外租房怎么选、合同怎么看？” → 新生住宿与租房决策能力主导。

“住宿已经确定，想规划从当前学期到毕业的升学和就业节点” → 本 Skill 主导；住宿只作为时间或经济约束。

## 4. 与选课决策

“这三门课选哪门、是否冲突、怎么退补选” → 选课决策能力主导。

“为了保研/就业，大学四年课程、科研、竞赛、证书怎么整体安排” → 本 Skill 主导；具体课程比较可委托选课能力。

“我未来想做数据分析，现在只比较两门课，不要四年规划” → 选课决策能力主导。用户明确限制交付物时，不因背景中出现长期目标而触发本 Skill。

## 5. 与职业规划

“我适合什么职业？” → 职业规划主导。

“已经想做数据分析，大一到大四应该完成哪些项目、竞赛、实习和证书节点？” → 本 Skill 主导。

## 6. 与竞赛辅导

“帮我做数学建模这道题” → 竞赛/学科辅导主导。

“数学建模竞赛什么时候适合参加，如何和科研/实习排进四年计划？” → 本 Skill 主导。

“这个比赛是否真实、主办方是谁？”且不要求放入跨学期主线 → 普通事实核验主导。

## 7. 与证书考试辅导

“教我法考民法” → 考试辅导主导。

“我是否符合报名条件，应该大几开始准备，是否值得放进职业路线？” → 本 Skill 主导。

“这个证是否还在目录中？”且只要当前事实 → 普通事实核验主导。

## 8. 与政策查询

“2026 上海应届生落户什么时候截止？”且只要事实 → 普通搜索/政策查询即可。

“我是 2028 届，想留上海，大学期间哪些节点需要提前准备并每年复核？” → 本 Skill 主导。

## 9. 与简历/申请写作

本 Skill 可以指出“什么时候需要简历/作品集/申请材料”，但不负责完整代写。

## 10. 未收录的相邻 Skill

当前包不声明掌握平台上的完整同场景 Skill 库。遇到未列出的相邻能力时，按用户明确要求的主交付物保守判断：不能确认是跨学期路线图，就不让本 Skill 主导；禁止用“其他语义相近场景”扩大触发。新增相邻 Skill 后，应补 should-trigger、should-not-trigger 和 boundary Case，再更新本文件。
