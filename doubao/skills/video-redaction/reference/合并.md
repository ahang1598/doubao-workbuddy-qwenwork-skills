# 最终合并

由 Agent 按顺序直接执行 `mediakit-cli`。Cloud 步骤：`query-task --poll-complete`，约 9 分钟退出则用同一 `task_id` 再查。
**本节所有真实的 `mediakit-cli` 业务调用都固定前缀 `DOUBAO_MEDIAKIT_RUNTIME=scene-video-redaction`。** 不要省略,不要改值,也不要写成 `--DOUBAO_MEDIAKIT_RUNTIME` 业务 flag。

**URL 直传**:`mux-audio-video` / `add-subtitle-to-video` 的 `--video-url` 支持 **HTTP/HTTPS URL、本地文件路径**两种。擦除产物、合流产物都是 mediakit 的 `result.video_url`,**原样传给下一步即可,不用下载中间视频**;只有 ffmpeg 产的 `output.m4a` 是本地文件,和最终成片交付才需要落盘。

**完成条件先确定**：输入有硬字幕时 `MUST_REBUILD_SUBTITLES=true`，最终成片必须来自 `add-subtitle-to-video.result.video_url`。擦除后视频和 mux 后视频都不能交付，也不能先宣布“处理完成”再询问是否压字幕。

1. Gate 1 收到用户下一条消息明确确认敏感词后：有硬字幕则提交擦除任务并使用其 `result.video_url`；无硬字幕则使用原视频 URL。擦除任务若还在 poll，继续同一 `task_id`。

2. 按 [敏感词音频处理.md](敏感词音频处理.md) 分别生成 `base.wav`、sine `beep.wav`,再二次混音得到本地 `output.m4a`。所有轨等长,与原音频严格同步。`beep.wav` / `output.m4a` 生成后直接进入下一步合流,不做 volumedetect 自检、不提交 MP3 试听片段给用户确认。

3. 用新音轨替换原音轨（`--video-url` 传擦除产物 URL，`--audio-url` 传本地 `output.m4a`）：

   ```bash
   DOUBAO_MEDIAKIT_RUNTIME=scene-video-redaction mediakit-cli editing mux-audio-video \
     --video-url <擦除后视频的 result.video_url 或原视频 URL> \
     --audio-url <输出目录>/output.m4a \
     --is-audio-reserve=false \
     --is-video-audio-sync=true \
     --sync-mode video \
     --sync-method trim
   ```

4. 压制去敏字幕（用 Step 8 产出的 `subtitles.json`，不要 `--subtitle-url`）：
   - 前置探测判定“有硬字幕”时强制执行，不得询问是否需要；
   - 前置探测判定“无硬字幕”时，仅在用户明确要求新字幕时执行；
   - `subtitles.json` 为空、缺字段或未完成敏感词 `*` 替换时不得提交。
   - **执行前必须先读 `byted-mediakit-editing/reference/add-subtitle-to-video.md`**，特别是 `subtitle_pos_preset` / `subtitle_font_size` 的约束说明；禁止继续沿用固定 `45`。

   字号、位置必须与 [前置探测.md](前置探测.md) 记录一致（`--video-url` 直接传上一步合流的 `result.video_url`）：

   ```bash
   DOUBAO_MEDIAKIT_RUNTIME=scene-video-redaction mediakit-cli editing add-subtitle-to-video \
     --video-url <合流后的 result.video_url> \
     --subtitles '<subtitles.json 数组>' \
     --subtitle-font-color "#FFFFFFFF" \
     --subtitle-font-size <前置探测记录的像素字号> \
     --subtitle-pos-preset <bottom_center|top_center|lower_third>
   ```

   Windows PowerShell：

   ```powershell
   $env:DOUBAO_MEDIAKIT_RUNTIME="scene-video-redaction"
   mediakit-cli editing add-subtitle-to-video --video-url "C:\path\muxed.mp4" --subtitle-font-color "#FFFFFFFF" --subtitle-font-size <subtitle_font_size_px> --subtitle-pos-preset bottom_center --% --subtitles "[{\"start_time\":0,\"end_time\":3,\"subtitle_text\":\"大家好\"}]"
   ```

   Windows 必须直接内联实际完整字幕数组；禁止 `$json`、`Get-Content`、`@file.json` 或把 JSON flag 放在 `--%` 前。若默认值 `50` 已满足 reference 约束，可省略 `--subtitle-font-size`；只有默认值会超限时才显式传入前置探测算出的 `subtitle_font_size_px`。

有硬字幕时，只有第 4 步终态的 `result.video_url` 可下载交付；第 4 步失败就报告失败并重试，不得降级交付第 3 步的无字幕视频。无硬字幕且用户明确不要新字幕时，才以第 3 步结果作为成片。
