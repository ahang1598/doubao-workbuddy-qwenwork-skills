# 环境安装

**不做独立前置环境探测。** ffmpeg、CMake 和 FunASR 的检查/安装全部内聚在 setup；会话 t=0 按平台执行一次安装入口，并与 probe/抽帧并行。具体见 [环境准备.md](环境准备.md)。

## 依赖清单

| 依赖 | 用途 | 说明 |
| --- | --- | --- |
| mediakit-cli | 人声分离、asr-subtitles、抽帧、字幕擦除、合流、字幕压制、视频理解 | 由宿主提供;按文档直接执行,不额外探测;缺了自然报错 |
| ffmpeg + ffprobe | 打哔混音 | setup 缺失时自动安装：macOS 用 Homebrew，Windows 用 winget |
| CMake + Ninja | Windows fbank 安装兜底 | `setup.ps1` 自动安装到 FunASR Python 环境 |
| torch (CPU) + funasr + modelscope + **kaldi-native-fbank** | FunASR 词级时间戳 | 会话 t=0 独立命令安装,阶梯:系统能装 → 装不上建 venv → 再失败告知用户;**venv 建在 `~/.local/share/funasr_env`(mac/Linux)或 `%LOCALAPPDATA%\funasr_env`(Windows)**,跨会话复用 |

**不装 `torchaudio`**——`kaldi-native-fbank`(229KB)完全替代其 fbank 提取功能,轻 2000×。

## 硬性规则

1. **不由调用方修 PATH 或单独探测依赖**：setup 内部检查 ffmpeg/ffprobe、Windows CMake/Ninja 与 FunASR；混音阶段读取 setup 写入的 `.ffmpeg` 路径。
2. 会话 t=0 按平台只调用一次安装入口(纯本地、不花钱),作为独立工具调用与 probe/抽帧并行：mac/Linux 用 `/bin/bash "$SKILL_DIR/scripts/setup.sh"`；Windows PowerShell 用 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$SKILL_DIR\scripts\setup.ps1"`。不要外加后台任务或 guard；脚本会在内部持久化安装进程并快速返回。装不上**不静默降级**,先问用户(修环境 / 降级句级插值,降级=不准)。
3. FunASR 调用必须使用 `.python` 中记录的解释器：mac/Linux 用 `"$FUNASR_PY" scripts/asr_funasr.py ...`，Windows PowerShell 用 `& $FUNASR_PY scripts/asr_funasr.py ...`；**禁止**裸 `python` / `python3` 调用(可能回落到没装依赖的系统解释器)。
4. FunASR 安装支持 mac/Linux shell 和 Windows PowerShell，不要求 Windows 安装 Bash、Git Bash 或 WSL。
5. 不要在脚本里封装 `mediakit-cli`。鉴权由宿主每次调用工具时下发,token 约 9 分钟。
