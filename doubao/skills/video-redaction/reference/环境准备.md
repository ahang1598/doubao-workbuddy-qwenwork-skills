# 本地环境：ffmpeg + FunASR（会话启动即准备，与 probe/抽帧并行）

**核心原则:这不是拦在所有操作前的硬 Gate,不做前置环境探测。** 安装是纯本地环境准备,与视频内容无数据依赖,所以在会话启动时就和 `probe-video-metadata`、雪碧图抽帧一起并行发起 —— 它是全流程最长的一根杆(pip 装依赖 + 拉 ~1GB 模型),越早起总时长越短。这里的"不探测"仅指不额外插一层独立预检,不是允许先跑错一遍再看文档。FunASR 的具体环境处理统一交给 mac/Linux 的 `scripts/setup.sh` 或 Windows 的 `scripts/setup.ps1`,不要把它扩展成全流程通用前置检查。

- 视频线(`probe-video-metadata` / `extract-frames` / `video-ocr` / `erase-video-subtitle-pro` / `mux-audio-video` / `add-subtitle-to-video`)**不依赖** FunASR,也不依赖本节任何东西 —— 先读对应 reference 后直接执行,工具缺了再自然报错。
- ffmpeg/ffprobe 由 setup 内部检查并安装：macOS 使用 Homebrew，Windows 使用 winget；Linux 仅在 root 且存在 apt/dnf 时自动安装，否则在 setup 日志中明确停止。
- **安装时机**:会话一启动就把本节脚本作为一个**独立命令进程**执行,与 probe/抽帧三个工具调用并行。**不用等 probe 返回**——不要用同一段 shell 的 `&` 做后台化,也不要把三步串进一个长 shell。若 probe 判无音轨则 skill 终止,安装进程可自然结束并留下跨会话缓存;有音轨时安装耗时会被 `separate-voice`/OCR 等云任务掩盖。

> **⚠️ 只调用一次,禁止每步重复调用/重复播报。** FunASR 安装在会话开头**按当前平台调用一次就够**,`setup.sh` / `setup.ps1` 会启动后台安装进程，由后台进程检查已就绪和安装中状态。**不要**在 probe 之后、抽帧之后、OCR 之前重复调用。`.ready` / `.installing` 幂等和陈旧锁清理全部由脚本内部负责。
>
> macOS / Linux:
>
> ```bash
> # SKILL_DIR 必须是当前 video-redaction/SKILL.md 所在目录的绝对路径。
> # 路径始终放在双引号中,兼容 Application Support 等含空格目录。
> SKILL_DIR="<video-redaction skill 绝对目录>"
> /bin/bash "$SKILL_DIR/scripts/setup.sh"
> ```
>
> Windows PowerShell（不依赖 Bash、Git Bash 或 WSL；`setup.ps1` 随 skill 分发，一定存在，不要先 `Test-Path` 核验或臆断其缺失）:
>
> ```powershell
> $SKILL_DIR = "<video-redaction skill 绝对目录>"
> powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$SKILL_DIR\scripts\setup.ps1"
> ```
>
> 对应平台的命令必须作为独立工具调用与 probe/抽帧并行执行。调用方不要再添加外部后台任务或 guard。`setup.sh` 会在内部用 `nohup`、`setup.ps1` 会在内部用 `Start-Process` 启动持久化安装进程，因此入口命令会快速返回，不受宿主长命令超时影响。后台日志分别写入 `~/.local/share/funasr_env/setup.log` 或 `%LOCALAPPDATA%\funasr_env\setup.log`；只有 `.ready`、`.python`、`.ffmpeg` 同时存在才表示 setup 完成。
>
> 后续要用 `FUNASR_PY` 时读取解释器路径。macOS / Linux:
>
> ```bash
> FUNASR_HOME="$HOME/.local/share/funasr_env"
> if [ -f "$FUNASR_HOME/.ready" ] && [ -r "$FUNASR_HOME/.python" ]; then
>   IFS= read -r FUNASR_PY < "$FUNASR_HOME/.python"
> fi
> if [ -r "$FUNASR_HOME/.ffmpeg" ]; then
>   IFS= read -r FFMPEG_BIN < "$FUNASR_HOME/.ffmpeg"
> fi
> ```
>
> Windows PowerShell:
>
> ```powershell
> $FUNASR_HOME = Join-Path $env:LOCALAPPDATA "funasr_env"
> if ((Test-Path "$FUNASR_HOME\.ready") -and (Test-Path "$FUNASR_HOME\.python")) {
>   $FUNASR_PY = Get-Content "$FUNASR_HOME\.python" -TotalCount 1
> }
> if (Test-Path "$FUNASR_HOME\.ffmpeg") {
>   $FFMPEG_BIN = Get-Content "$FUNASR_HOME\.ffmpeg" -TotalCount 1
> }
> ```
>
> 三个状态文件任一不存在就查看 setup 日志并等待会话开头启动的安装进程，**不是重复调用 setup**。`.ffmpeg` 记录实际 ffmpeg 可执行文件路径；后续本地混音应优先读取该路径，避免 Windows 当前宿主进程尚未刷新 PATH。全程对用户最多提一次“已开始安装本地环境”。

**调用方不修 PATH、不单独探测 ffmpeg。** 只根据宿主操作系统选择 `setup.sh` 或 `setup.ps1`，其余检查和安装都由脚本内部完成。Windows setup 会把 ffmpeg 目录写入用户 PATH，同时写 `.ffmpeg` 供当前会话直接读取。

## 降级阶梯:系统 → 虚拟环境 → 告知用户

需要 FunASR 时按这个阶梯走,命中任一级即停:

| 级别                        | 动作                                                            | 命中                                                |
| --------------------------- | --------------------------------------------------------------- | --------------------------------------------------- |
| **L1 系统直接可用**         | 用系统 Python 导入 `torch/funasr/modelscope/kaldi_native_fbank` | 过 → `FUNASR_PY=<系统 Python 绝对路径>`             |
| **L2 系统能装**             | 往系统 Python 装依赖                                            | 装完 import 过 → `FUNASR_PY=<系统 Python 绝对路径>` |
| **L3 系统装不上 → 建 venv** | 家目录建虚拟环境装                                              | venv 里 import 过 → `FUNASR_PY=<venv>/.../python`   |
| **L4 venv 也失败 → 停**     | 贴报错,让用户二选一                                             | 见下                                                |

**L4 两条路(让用户选,别默认降级):**

- **修环境(推荐,打哔准)**:按报错装缺失依赖 / 换 Python 版本后重跑。
- **降级句级插值(不准)**:跳过 FunASR,用 `asr-subtitles` 句级时间戳做**均分插值**定位敏感词 —— 误差可达 ±150ms,**可能漏词或打偏**。仅在用户**明确接受「不准」**时启用,并在 `sensitivity_candidates.json` / `sensitivity.json` 中将时间戳来源标记为 `asr_sentence_interpolated`。

> **降级 = 不准。** 不要 Agent 自己偷偷降级,必须先把问题甩给用户决定。

## 依赖清单

必装(三端统一):

| 包                   | 用途                 | 说明                                                           |
| -------------------- | -------------------- | -------------------------------------------------------------- |
| `torch` (CPU)        | 神经网络后端         | 从 `https://download.pytorch.org/whl/cpu` 装,避开 CUDA(~200MB) |
| `funasr`             | 主库                 | pure Python                                                    |
| `modelscope`         | 模型下载             | pure Python                                                    |
| `kaldi-native-fbank` | fbank 特征提取       | **必装**;funasr 推理时缺它会崩,只装 funasr 不够                |
| `cmake` + `ninja`    | Windows 构建工具兜底 | Windows setup 自动安装；fbank 仍强制优先使用二进制 wheel       |
| `ffmpeg` + `ffprobe` | 本地打哔混音与验收   | macOS 用 Homebrew、Windows 用 winget 自动安装                  |

**不装** `torchaudio`(体积 ~500MB,fbank 提取被 `kaldi-native-fbank`(229KB)完全替代,轻 2000×,精度差异 1e-6);**不装** CUDA 版 torch(打哔用不到 GPU)。

## 安装(system → venv 两级)

**会话 t=0 只执行当前平台的单一入口命令。** 已安装检查、系统解释器复用、系统安装、venv 创建与复用、依赖校验、并发锁和状态文件都内聚在 `scripts/setup.sh` / `scripts/setup.ps1` 中,不要在 Agent 命令里复制这些逻辑。

安装阶段负责准备 ffmpeg/ffprobe 与 `torch(CPU)` / `funasr` / `modelscope` / `kaldi-native-fbank`。Windows 只选择 Python 3.10-3.13（优先 3.12/3.11），先安装 CMake/Ninja，再用 `--only-binary=:all:` 安装 fbank，避免落入源码编译。成功后写入 `.ready`、`.python` 和 `.ffmpeg`。

## 跨平台差异速查

| 项          | mac / Linux                 | Windows PowerShell                                 |
| ----------- | --------------------------- | -------------------------------------------------- |
| 安装入口    | `scripts/setup.sh`          | `scripts/setup.ps1`                                |
| venv python | `${venv}/bin/python3`       | `${venv}\Scripts\python.exe`                       |
| venv 位置   | `~/.local/share/funasr_env` | `%LOCALAPPDATA%\funasr_env`                        |
| 模型缓存    | `~/.cache/modelscope`       | `%LOCALAPPDATA%\modelscope`                        |
| ffmpeg 安装 | `brew install ffmpeg`       | `winget`（优先 LGPL 构建）                         |
| torch whl   | 全平台 x64/arm64 都有       | win_amd64 有;win_arm64 缺 → 只能降级句级插值(不准) |

## 模型缓存

首次跑 FunASR 拉 `paraformer-zh` ~1.1GB,后续复用。缓存放家目录跨会话共享,**不要放 WORK_DIR**(清工作区就重下 1GB):

```bash
export MODELSCOPE_CACHE="${HOME}/.cache/modelscope"
export HF_HOME="${HOME}/.cache/huggingface"
```

Windows 换 `%LOCALAPPDATA%\modelscope`。

## 常见报错

| 报错                                                    | 原因                       | 处理                                                                                            |
| ------------------------------------------------------- | -------------------------- | ----------------------------------------------------------------------------------------------- |
| `ModuleNotFoundError: No module named 'torch'`          | 系统 pip 装不上            | 走 L3 建 venv                                                                                   |
| `ImportError: kaldi_native_fbank` / 首次真推理崩        | funasr 装了但 fbank 后端缺 | `pip install kaldi-native-fbank`;仍失败告知用户修环境或降级                                     |
| `CMake executable is not found` / `No CMAKE_C_COMPILER` | Windows 回退了源码构建     | 新版 setup 自动安装 CMake/Ninja、重建不兼容 venv，并强制 fbank 二进制 wheel；重新执行一次 setup |
| `ERROR: Could not find a version...torch`               | Python 版本太新(3.15+)     | L3 挑 python3.13/3.12                                                                           |
| `Killed` / OOM                                          | 误装 CUDA 版               | 严格用 `--index-url .../cpu`                                                                    |
| Windows arm64 无 torch/fbank whl                        | Snapdragon 笔记本          | 不回退源码编译；让用户修环境或接受句级插值降级，并标记 `asr_sentence_interpolated`              |

## 兼容性契约

- **不做前置环境探测**:视频线 / ffmpeg 打哔不等 FunASR,直接跑;FunASR 的具体环境处理由当前平台的 `scripts/setup.sh` 或 `scripts/setup.ps1` 负责。
- **调用方不修 PATH、不单独探测 ffmpeg**:安装脚本内部检查、安装并记录实际 ffmpeg 路径。
- FunASR 就绪走 **系统 → venv → 告知用户** 三级,装不上**不静默降级**,先问用户。
- venv **不跟 WORK_DIR 走**,首装一次跨会话复用;依赖版本不锁死,用 latest。
