# 量化研究

## 概述

把一个明确的研究假设，做成**可复现、可独立验收**的因子／事件／组合研究：
冻结口径 → 按 point-in-time 取数 → 可成交回测 → 成本与容量 → 样本外隔离 →
稳健性与独立复算 → 按契约交付。

研究结论**只用于离线评估，不直接生成实盘指令**。只使用当前材料和本轮真实取得的数据；
禁止虚构行情、成本、hash、源码、复跑结果或显著性。

## 使用场景

**应当触发（should-trigger）**

- 「用 2018–2024 的 point-in-time 财务数据做质量因子 IC、行业中性分层和样本外检验」
- 「对公告事件做 T+1、不可成交顺延、成本和参与率约束下的组合回测与容量分析」
- 「V46 这版回测还能不能复现？给我 manifest、独立复算和差异清单」

**不应触发（should-not-trigger，near-miss）**

- 「根据今天的 K 线判断某股票明天是否该买」→ 属当前技术诊断，转
  `equity-technical-analysis`
- 「按这个研究结论帮我调一下持仓」→ 属持仓动作，转 `portfolio-trading-decision`

**与相邻能力的边界**（四要素对比，避免抢触发）

| | 本 Skill | equity-technical-analysis | portfolio-trading-decision |
|---|---|---|---|
| 触发语义 | 研究假设的验证与复现 | 当前行情的技术诊断 | 持仓该怎么动 |
| 用户目标 | 知道「这个信号站不站得住」 | 知道「现在这只票什么形态」 | 知道「买/卖/调多少」 |
| 交付物形态 | 研究报告 + 可重跑工件 + manifest | 形态与指标判读 | 持仓动作建议 |
| 执行路径 | 冻结口径→回测→复算→交付契约 | 读当前行情、算技术指标 | 读持仓、约束与偏好 |

**优先级**：同一 query 同时沾边时，看用户要的是**结论的可信度**（本 Skill）
还是**当下的动作**（另两个）。要动作的一律转交，本 Skill 不输出买卖或上线建议。

## 核心流程

### 选择模式

- 因子构建、IC、分层、中性化与衰减：读取 [references/factor-research.md](references/factor-research.md)
- 事件研究、组合回测、成交与容量：读取 [references/backtest-contract.md](references/backtest-contract.md)
- 版本恢复、holdout、敏感性与验收：读取 [references/version-governance.md](references/version-governance.md)

所有模式先执行 [references/data-manifest.md](references/data-manifest.md)，最终执行 [references/delivery-contract.md](references/delivery-contract.md)。需联网时读取 [references/search-policy.md](references/search-policy.md)；封闭材料题禁止搜索，只用题内材料，缺什么就写进缺口清单。

### 开工第一件事：冻结口径

先写死唯一数据源、标的数量、时间范围，再写研究问题、信号公式、可知时点、股票池、样本划分、参数、成本、基准、随机种子、停止规则，以及**门禁 11 要求的那组替代规格**（替代分组数／替代窗口／替代聚类层级之一）。之后不得根据测试结果暗改。

冻结的不只是**参数**，还包括**算法口径**：分组排名、标准化中性化、再平衡、取整，四类一律按题设原文执行，题设未给的标为待业务输入并写出所选默认值。换一种"等效"算法会改变成分，进而改变单调性、胜率这类结论，不是小数位差异。逐类口径见 [references/data-manifest.md](references/data-manifest.md)。

### 不可跳过的门禁

1. 财务数据使用实际披露时间/vintage，不用报告期末、也不用报告日充当可知日；股票池使用历史生效成分，不用当前名单回看。可交易交集因此变小是结论要承受的事实，不是放宽口径的理由。
2. 信号在完整数据形成后才可使用；收盘后形成的信号只能下一交易时点执行。warmup、停牌、涨跌停、退市、公司行动和不可成交必须进入状态机。
3. 窗口内观测不足时标记该窗口"不可用"并从对应统计里剔除，不得用实际存在的观测求和冒充完整窗口。
4. 筛选或匹配在给定规格下得到零个结果是合法结论，如实报告；不得为提高覆盖率事后放宽阈值，也不得对零方差截面改写标准化方式来制造匹配。
5. 现金、持仓、成交、延期、撤单、费用与公司行动必须逐日勾稽；成交量不是开盘可成交量，容量按参与率与未成交规则逐日模拟，不用静态 ADV 比例证明。
6. 样本漏斗逐级写出：从原始条数到最终样本，每级写明条数与排除依据，并能定位到具体是哪几条被排除。只给最终条数不够。
7. 关键结果要有独立复算：从原始输入重新实现一遍口径再比对，写出差异；未通过项如实保留，不得改写成通过。复算不得读取主实现的输出、不得 import 或复制主实现的函数——共享实现的复算查不出口径错误。
8. 被查看、调参或比较过的数据永远不再是未见 holdout。预注册敏感性可以查看一次，但查看后不得继续搜索参数或称永久最优。
9. 只报告可由当前数据计算的结果。未提供价格不得反事实计算旧代码收益；未提供源码/hash 不得声称恢复成功；未计算统计量不得声称显著。
10. 阈值、成本、容量和继续/停止条件如果不是题设提供，必须标为"待预注册/业务输入"，不得包装成事实。
11. 结论必须附至少一组**在冻结时就写明**的替代规格（替代分组数、替代窗口、替代聚类层级之一）。看到主结果之后才挑的规格不算，那是参数挖掘。替代规格与主规格结论不一致时，主动下调结论置信度并写明不一致在哪；**替代规格的结果不得替换主规格结论**，也不构成放宽主规格的理由。

### 结论强度：四级，不许越级

每条结论落在且只落在一级，全文（正文、摘要、交付文件）用同一级：

| 级别 | 什么时候用 | 升到这一级需要什么 |
|---|---|---|
| 已验证事实 | 可从原始附件复算出来的数 | 复算路径写出来了 |
| 当前计算 | 算出来了，但只对本区间成立 | 只描述该区间差异，不称永久、最优或机制成立 |
| 条件性推断 | 有方向性证据，缺关键验证 | 写明缺什么证据才能升级 |
| 数据不足以判断 | 样本量或字段不足 | 写明缺口与所需样本量 |

**把差异归给某一个原因，必须有该原因的分项贡献数据。** 只排除了若干候选解释，只能写"这些处理没有消除该现象"或"若干因素共同造成，各自贡献无法从当前材料分解"；未给出分项贡献数据时，不得对候选原因做强弱排序。把阶段表现归给风格，必须有独立风格序列做归因，否则只能标为条件性推断。

样本量不足时的合法结论是"当前数据不足以判断有效性"，**不是**"该因子无效/不值得继续研究"。

研究结论不得转写成买卖或上线建议；要写只能写成"在哪些条件满足后可进入下一步验证"。

### 承诺与交付：二选一

**触发**：正文任何一处出现交付物名称——代码、脚本、manifest、台账、工作簿、报告、清单、图表。

**判断标准只有一条：有没有把内容当场给全。** 不是「提没提这个词」。

- 正文里**直接写全**的可复制 JSON/YAML（典型是 manifest）**即是交付**，不需要另附文件
- 代码同理：正文里给出**完整、可直接运行**的脚本即是交付；
  只给片段、只给标题、或写「完整版见附件」而附件不存在，都不算
- 只要你**承诺了文件**，或用户**点名要文件**，就必须产出真实文件并写出文件名

**禁止**：该名称在交付清单里没有对应的真实文件；或文件存在但正文没写出文件名；或主入口脚本 import 了没有一并交付的模块；或标题下面是空的、是占位段落。

**要求**：二选一，没有第三种。

- 要么**产出真实文件**，并在正文写出文件名以及它回答哪个问题；
- 要么**删掉这句承诺**，并写明这一项本轮为什么不交付。

「删掉承诺」只适用于自己额外许诺的东西。**用户点名要的交付物不在可删范围内**：做得出就产出，做不出就写明卡在哪一步、给出可运行骨架与待补输入，不得靠删承诺绕过。

提交前做一次对账：把正文里出现过的全部文件名与实际交付清单逐个对齐，对不上的按上面二选一处理完才能提交。

主结论涉及的关键统计量必须出现在正文里，不能只写"详见某工作表"——附件是证据，不是正文的替代。

边界按**粒度**划，不按重要性划：正文放**主结论直接引用的那几个数**（样本量、主指标、分档汇总、结论阈值），交付文件放**逐条/逐日/逐笔的明细**。两边都不放不行，明细搬进正文也不行。

### 提交前机械检查

1. 逐条走完上一节的对账。空标题、占位段落、引用了未交付模块的脚本，三者任一存在即不得提交。
2. 用户要求 manifest 时，直接在回答里输出可复制的 JSON/YAML，**写全即算交付，不必另附文件**；
   只有承诺了文件或用户点名要文件时才产出文件并写出文件名。
   未知值写 `null` 并写原因。**结果字段里出现"待补""示例 hash""TBD"这类占位文字，与编造等同**，不得出现
   （示例文本里的脱敏假名不在此列，见「数据与合规边界」）。
3. 工具或取数失败时，最终回答仍须给出附件静态审计、数据源尝试与错误、逐数据集状态 manifest、降级规则、缺口清单、可运行代码骨架和阻塞点。禁止以"已委派、后台处理中、稍后交付"结束。
4. 声称代码就绪前核对文件名、imports、README 命令、实际输出和测试结果；未运行就写"未执行"。
5. 封闭题只用题内成本和数据，删除题外税率/费率/阈值；描述差异不得升级为噪声、显著、可控或机制归因。
6. 正文首段写冻结口径与结论方向，不描述读取、调用、修正等动作。审计发现与修复过程放在其后的专门段落，不占首段。

若关键历史数据不可得，先完成代码审计、修订实现、manifest 模板和缺口清单，在数据入口停止；不得填模拟收益。

## 工具与脚本

### 内置脚本：[scripts/event_backtest.py](scripts/event_backtest.py)

事件纳入判定 + 单期净收益的确定性计算。无随机、不联网、不写文件。
**看这张表就能调用，不需要读源码。**

```bash
python3 scripts/event_backtest.py events.json --cost 0.0037
python3 scripts/event_backtest.py events.json --round-trip-cost 0.0074   # 与上一行等价
```

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `events.json`（位置参数）| 是 | — | 事件列表 JSON，数组 |
| `--cost` | 二选一 | — | **单边**成本，[0,1)：买入侧加、卖出侧扣，一次往返实际收 2 倍 |
| `--round-trip-cost` | 二选一 | — | **一次往返合计**成本，[0,1)，内部按一半分摊到两侧 |

⚠ `--cost` 与 `--round-trip-cost` **互斥且必须给一个**。换算关系是
**往返合计 = 2 × 单边**：题设给「双边合计 R」就传 `--round-trip-cost R`，
给「单边 r」就传 `--cost r`。
**把「双边合计」直接传给 `--cost` 会把成本收成两倍**，这正是门禁里点名的成本口径错误。

**输入**（每个事件对象）

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `name` | 是 | str | 事件标识 |
| `in_universe` | 是 | bool | 信号日是否在**历史**股票池内（不是当前池）|
| `buy_open` | 是 | number > 0 | 买入价 |
| `sell_close` | 是 | number ≥ 0 | 卖出价（退市清零可为 0）|
| `buyable` | 否 | bool，默认 `true` | 买入日是否可成交 |

**输出**：与输入等长的数组。`included=false` 时给 `reason`，取值只有两个——
`not_in_point_in_time_universe`、`buy_open_unavailable`，与样本漏斗的对应级别一致；
`included=true` 时给 `buy_cost` / `sell_proceeds` / `net_return`。空数组合法，输出 `[]`。

**错误处理**：参数与字段不合法时以退出码 2 + 一行可读消息返回，不抛栈、不静默算错——
成本越界、`buy_open<=0`、`sell_close<0`、NaN/inf、缺字段、未知字段、非数组、
非法 JSON、文件不存在，各自给明确消息。

### 外部工具

本 Skill 的核心流程**不依赖任何外部 Tool**：冻结口径、门禁、结论强度分级与交付契约
都只作用于用户提供的材料。只有在**需要公开金融数据且题目允许联网**时才用下面两个：

| Tool | 什么时候用 | 入参 | 出参 | 失败怎么办 |
|---|---|---|---|---|
| `seed_finance_search` | 需要公开金融数据时的首选 | 检索词 + 标的/时间范围 | 数据条目与来源 | 取不到关键数据就**停止**，写进缺口清单，不估算不模拟 |
| `general_search` | 基金/大宗等覆盖不足时，定向交易所、监管机构、指数公司、公司 IR 或官方源 | 同上 | 同上 | 同上，并标注这是降级来源 |

**禁用边界**：封闭材料题**禁止调用任何搜索工具**，只用题内材料，缺什么写进缺口清单。
搜索**不能替代授权历史数据接口**——搜来的数不进回测主口径，只作来源标注。
详见 [references/search-policy.md](references/search-policy.md)。

## 数据与合规边界

- 数据只来自**用户提供的附件**，或题目明确授权的公开数据源；不绕过登录、反爬、
  权限或任何安全机制取数。
- 取不到高优先级数据时按附件降级并记录缺失，**不用当前成分、估算或模拟值补齐**。
- 示例与文档里的标的、账号、路径一律用**脱敏假名**（如 `SYN001.SH`、`/data/<dataset>.csv`）；
  不嵌入生产数据或内部文档全文。这与下一条不冲突：**假名用在示例里可以，占位文字用在结果字段里不行**。
- 输出中若出现手机号、身份证号、银行卡号等敏感信息，一律打码后再呈现。
