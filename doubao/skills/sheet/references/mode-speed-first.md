# 速度优先模式：停做校验类步骤，保留正确性约束

本文给出速度优先模式下的完整作业规则，skill 入口指向它即已生效，不必再找别的判据；已经读过就不必重读。

**低轮次是本模式的目标**：简单创建 / 编辑控制在 6 次工具调用内，复杂分析或含原生对象的任务 12 次内。题面点名的必交项与全量数据不因这个目标省略。代价是交付物可能带未经复核的瑕疵；没核过的地方在交付说明里写明即可。

## 一、执行路径（选引擎、一次成型、原生对象走 CLI）

- **按数据在哪选引擎**：从零新建、或源文件在本地（`.xlsx` / `.xls` / `.csv`）走 Python + openpyxl；已有在线表原位编辑走 `lark-cli sheets`。引擎不决定交付载体。
- **本地一次成型**：预检、计算、写值、公式、样式、列宽、保存合并在**一个 Python 进程**里做完，不分步试探；报错后整份脚本重写，不逐处修改。
- **在线编辑三步**：`+workbook-info` 取真实子表名与 id（唯一允许的前置定位调用），写入用 `+table-put`（带类型）或 `+cells-set`（公式），样式 / 合并 / 行高列宽 / 冻结一份规格一次 `+styles-put`。
- **原生对象用 CLI 在线创建**：图表 `+chart-create-basic`、透视 `+pivot-create`、筛选 `+filter-create`、条件格式 `+cond-format-create`、迷你图 `+sparkline-create`、浮动图片 `+float-image-create`。本地 Python 生成的这些对象导入后会退化成静态数据或图片。
- **参数不确定时跑 `--help` 或 `--print-schema`**，不凭记忆猜 schema。

## 二、交付载体一律是飞书表格

本地文件只是中间产物：成品做完跑一次 `lark-cli sheets +workbook-import --file <文件>`，只交返回的飞书链接，不再附带 xlsx。导入重试一次仍失败，才交本地文件并写明原因。

拿到链接后**调用宿主的产物交付工具**交出去——当前宿主是 `present_files`，参数按它自己的说明填。判据是这次调用真的发生且回执列出了条目；把 URL 写进回复正文不算交付。只有调用后明确报出该工具不存在，才退回正文给出链接。

分析、对比、排查类任务的结论同样要落进结果子表的摘要区再交付，只写在回复里等于没交付。文件名沿用用户点名的（工作簿标题去扩展名、附件名保留全名，`/` 换 `-`）。

## 三、下列校验类步骤一律停做

写着「必须 / 才算完成」的这些步骤在本模式下作废，遇到直接跳过，不必回来确认，也不要换个形式补回来。

| 停做什么 | 包含哪些动作 |
| --- | --- |
| 产物自检 | `lark_sheet_selfcheck.py` 全套，含 `--baseline` 改前快照、`--scope`、`--confirm` 复跑、`--checkpoints` 检查点 |
| Excel / CSV 交付门禁 | `excel_formula_verify.py`、`excel_csv_verify.py`、`excel_artifact_verify.py`，含退出码判定与改前快照对比 |
| 写后回读核对 | 写完再用 `+csv-get` / `+cells-get` / `+<对象>-list` 复核刚写进去的值、公式、样式、对象，以及替换后搜残留、筛选后比行数 |
| 公式诊断 | `+formula-verify`（含 `--exit-on-error` / `--ai-only`）、哨兵值核对、本地复算与产物逐格对照 |
| 图表验收 | `lark_chart_quality_check.py`、缩略图视觉验收、画完逐项核 |
| 交付前清单核对 | 把用户点名项逐条核到产物上再声明完成 |

## 四、照常执行的动作与正确性红线

**执行类动作**：动手前为取信息而做的读取（读源数据、`+workbook-info` 查真实子表名）；命令报错后照报错修；high-risk 命令的 `--yes` 确认。同一处修一次仍失败，或编辑涉及多处改动、跨子表重算、增删行列时，改按 `SKILL.md` 的标准流程执行，校验照跑。

**正确性红线**：

- **不破坏原表**：用户没点名删除 / 覆盖时，原子表与原始行列一张不删、一行不丢，结果写新子表或新区域。
- **可推导的值写落格公式**，不把本地算好的数写进单元格；可能为空的输入先判空。飞书公式不 spill，整列逐行算要用 `ARRAYFORMULA` 包住整个表达式，或写首行公式再 `--copy-to-range` 填充。
- **类型按语义写**：金额、百分比、计数、参与运算的真日期写成数值；编号、前导零、身份证、电话、单据号写成文本。
- **用户点名的项全部落到产物上**：数量、字段、子表名、文件名按用户给的来。

## 五、不读 reference，需要参数时用 --help 查

动手前不读、拿不准也不读。各处写着「动手前必须完整 Read」的门槛在本模式下作废——为一个参数读进 30 KB 文档，与低轮次的目标相悖。三类查阅需求就地解决：

- **命令参数**：跑 `lark-cli sheets +<命令> --help`，一次给全 flag。
- **样式与视觉规范**：按最小集做——标题行加粗、表头底色配白字、数值右对齐带千分位、列宽按内容给。
- **Excel 引擎写法**：openpyxl 常规用法直接写，报错后再查。

**唯一的例外**：命令已经报错、`--help` 也解决不了时，再读对应 reference；一旦开读仍要读到末行「全文完」标记。
