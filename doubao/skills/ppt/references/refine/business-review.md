# business-review · Refine Handbook

商业复盘 / 董事会汇报场景的 refine 手册。内容页需要 refine 时,**判断这页缺什么(缺内容 / 缺表达 / 缺视觉),补什么**。三种动作平权,不排序。

## 一、气质定位

**母题特征**:
- palette 沉稳:海军蓝 / 咖啡棕 / 鼠尾草绿 · 低饱和 · 银灰渐变作背板
- 数字表盘刻度 signature(SVG 半圆刻度 + 中心大字数字 + 主色 tick)
- 蓝白横条节奏(海军蓝页顶部 y=0-30 蓝色横条)
- 精密刻度感(左侧 y=100-450 每 20 一格 · 银保档案气质)
- hero KPI 大字号(80pt+ · 咖啡渐变数字环绕 · 主视觉)
- 双列长表 zebra 底纹 · 奇偶行 hairline 交替
- 责任签字条(制表 / 审核 / 批准 / 签发 · 页脚 y=520)
- 中文编号(零零一 / 甲乙丙)· 加权公式明示(综合评分 = 0.3×A + 0.4×B + 0.3×C)
- **图片策略**:重原生 chart / SVG(季度对比柱 · 趋势线 · 归因瀑布 · 表现 vs 目标)· 生图默认不用 · 数字表盘 shape 是 signature
- **style 侧 signature 库(refine 时优先套用)**:数字表盘刻度 / 蓝白横条节奏 / 责任签字条 / 中文编号(零零一/甲乙丙)/ 加权公式明示 —— 详见 `style/business-review.md`

## 二、什么样的页需要 refine

**必 refine**:
- `refine_triggers.should_refine=true`(命中任一信号)

**主观 refine**(截图检查):
- 缺内容:整页一句话 + 几段简介 · 数据没对标 / 没归因 / 没历史对照
- 缺表达:数字散在正文而非 hero 主视觉 / 3 段并列缺 KPI 卡阵 / 长表无 zebra
- 缺视觉:hero KPI 不够大 / 缺数字表盘 signature / 缺蓝白横条 / 缺责任签字条
- 以上 3 点有任意可以进一步优化的地方

## 三、Refine 三类动作(平权 · 缺什么补什么)

三类动作**没有先后**,一页可能同时缺内容 + 缺视觉,那就 enrich + decorate 一起做;也可能只缺表达,那就只 reframe。

### 3.1 · Enrich · 补内容(缺 payload 时用)

**business-review 的补内容,重对标、重归因、重历史对照 · 少品牌情绪图 · 少 pitch 冲击**。

**A · 用户已给附件/原稿**(`is_manuscript_apply=true`):
- Read 原稿相关章节 · 挖这页可加的**次要信息层**:
  - hero KPI 之外的**分部 / 分品类 / 分渠道拆解**(整体增长之外的结构性拆分)
  - **上一期历史对照**(环比 / 同比 · 三期趋势)
  - **归因逻辑拆解**(A / B / C 各贡献多少个百分点)
  - **目标 vs 实际 gap**(达成率 % · 差距值 · 后续 action)
  - **责任人 / owner / 决策事项**(董事会关心的下一步)
- 按重要性分层塞进页(hero KPI + 分维度矩阵 + 对标行 + 归因)

**B · 用户只给主题**(`is_manuscript_apply=false`):
- **搜索方向 · 优先真实对标**:
  - 行业 benchmark(同规模公司 KPI · 均值 / 分位数)
  - 上市公司季报 / 年报(投资者关系 · 公告披露)
  - 麦肯锡 / 德勤 / BCG / Gartner / IDC 白皮书
  - 上一期自家历史对照数据
- **搜索关键词模式**:主题 + 商业限定词
  - "<行业> Q3 2025 industry benchmark" / "<公司> annual report"
  - "<主题> McKinsey report 2025" / "<主题> peer comparison"
  - "<细分> Gartner magic quadrant" / "<品类> IDC market share"
- **Source 规则**:内部数据不挂,**行业对标必须挂**
  - 示例:"行业均值 12% · Source: Gartner 2025 Q3"
  - 示例:"同行 P75 = 8.4% · Source: McKinsey Digital Index 2025"

**图片策略**:
- **原生 chart / SVG 极高频**:数字表盘 · 趋势线 · 环形进度 · 归因瀑布 · 达成阶梯
- **image_search 中度**:高管照 · 办公室场景 · 团队合影
- **image_edit 少度**:统一风格化(低饱和档案感)
- **生图不用**:内部档案 · 不追求氛围
- **数字表盘 shape 是 signature**(SVG 半圆 + 刻度 + 中心数字)

**enrich 后的产物**:内容清单(hero KPI + 分维度拆解 + 对标行 + 归因条 + 目标 gap + Source 脚注)· 塞进本页

### 3.2 · Reframe · 换表达形式(有内容但表达弱时用)

把已有内容**换更强视觉表达**。business-review 常用替换:

- **散布正文的数字 → hero KPI 大字号**(80pt+ · 咖啡渐变 · 4-8 颗小方块环绕)
- **本期 vs 上期 → 双 hero 对比**(60pt 并列 · 变化率 accent · 中间分割条)
- **3 个 KPI → 三 hero 联**(咖啡渐变卡阵 · label / value / 变化率三层)
- **目标达成率 → 环形进度圈**(SVG donut · 中心大字 · 220×220)
- **6 个分维度 → 数字矩阵 6 联**(2×3 网格 · KPI + 单位 + 环比)
- **增长因素罗列 → 归因水平条**(SVG stacked bar · label + 贡献 pp)
- **实际 vs 目标 → 目标达成阶梯**(阶梯 shape · 缺口 accent 标注)
- **按业务分部 → 分部渐变卡阵**(每卡渐变底 · 分部名 + 指标 + 环比)
- **数据孤立 → KPI 对标三线表**(自己 / 同行 P50 / 行业均值 · 差值 accent)
- **描述性时序 → 时间序列步骤流**(Q1→Q2→Q3→Q4 · 每期 hero + 支撑)
- **对策罗列 → 2×2 优先级矩阵**(重要 × 紧急 · 高管决策档案)
- **长段落 → 双列长表 zebra**(整页 · 上下两栏 · 董事会标配)

**reframe 时的复盘风原则**:
- hero KPI 必须够大够 hero(80pt+ · 主视觉)
- 环形 / 阶梯 / 渐变卡都用**咖啡棕或海军蓝渐变底**(不用饱和亮色)
- 归因条 / 达成阶梯必须**标数字**(不只是"增长",要"+3.2pp 来自 A")
- 三线表对标数据必须**挂 Source**
- accent 色仅用于"变化率 / 关键 gap"高亮 · 一页至多 2-3 处

### 3.3 · Decorate · 加视觉锚点(缺视觉时用)

**装饰母题库**:
1. 数字表盘刻度(SVG 半圆 · 主色刻度 · 中心大字 · signature)
2. 蓝白横条节奏(海军蓝页顶部 y=0-30)
3. 精密刻度感(左侧 y=100-450 · 每 20 一格 · 银保档案)
4. 银灰渐变背板(半透明主色 top-down · 分节背景)
5. 双列长表 zebra(奇偶行 hairline 交替)
6. 责任签字条(制表 / 审核 / 批准 / 签发 · 页脚 y=520)
7. 中文编号(零零一 / 甲乙丙丁)
8. 加权公式明示(独立框 · italic 或等宽)
9. 稳健档案钢印(15×15 accent 圆或菱形 · 页脚归档感)
10. 双列参考底纹(页脚 y=470 · 200×20 半透明 × 2 栏)

**视觉锚点升级库**(把已有元素做大做强):
- hero KPI 圆环底 220×220 + 80pt+ 数字 + 环绕 4-8 颗小方块
- 主标副标重叠矩形 linear-gradient(咖啡感)
- 悬浮 shadow(董事会档案感)
- 数字表盘半圆 180×90 · 中心 40pt 数字 · 外圈 tick
- 归因瀑布 SVG(每段独立矩形 · 高度按数值 · 顶部标 pp)

**布局重构库**(修视觉塌陷 · 每次 refine 最多挑 1 个):
- 上 hero KPI + 下 4 卡分部拆解
- 左侧目录 20% + 右侧内容 80%(长文档汇报常用)
- 双列长表(整页 · 上下两栏 zebra)
- 左 hero 环形圈 + 右侧支撑 3-4 行(达成率专用)
- 中央聚焦 + 责任签字条落底(结论 / 决议页)

## 四、使用规则

**判断这页缺什么的信号(每类独立触发 · 不排序)**:
- `total_text_chars < 60` 或缺对标 / 缺归因 / 缺历史对照 → 3.1 enrich
- 数字散在正文 / 缺 hero 主视觉 / 长表无节奏 → 3.2 reframe
- `visual_elements ≤ 12` 或数字表盘 / 蓝白横条 / 责任签字条 signature 全缺 → 3.3 decorate
- **一页可能同时缺 2 类 / 3 类**,那就多类一起做

**气质一致性**(每次 refine 后过):
- 加的元素稳健档案感吗?(数字表盘 · 责任签字条 · 中文编号 · 加权公式 · 而非花哨渐变)
- hero KPI 够大够 hero 吗?(80pt+ 主视觉 · 不是普通数字带)
- 数据有对标吗?(自己 vs 同行 vs 行业均值 · 董事会关心差距)
- 归因逻辑清晰吗?(不只是"增长 X%",还要有"因为 A +2.1pp / B +1.3pp")
- palette 沉稳吗?(海军蓝 / 咖啡棕 / 鼠尾草绿 · 而非高饱和亮色)

**不要做的事**:
- 不要动 brand_assets(背景 / 页眉 / 页脚 / 装饰线 · 只加不删)
- 不要用 pitch 风冲击(内部档案 · 不是投资人路演)
- 不要用品牌情绪图 / 生图(不是故事 · 是数字 · 是档案)
- 不要跳过 Source(行业对标必须挂 · 内部数据可不挂)
- 不要用花哨渐变盖过档案感(咖啡 / 银灰 / 海军蓝 OK · 亮橙紫不 OK)
- 不要编造对标数据 · enrich 走搜索必须真实来源
- 不要跳过 enrich 只做 decorate 凑数(数据不足时补装饰只让页更空洞)
