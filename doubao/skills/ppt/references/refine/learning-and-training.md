# learning-and-training · Refine Handbook

学习培训场景的 refine 手册。当内容页需要 refine 时,**判断这页缺什么(缺内容 / 缺表达 / 缺视觉),补什么**。三种动作平权,不排序。

## 一、气质定位

**母题特征**:
- palette 偏温和亲和(课堂靛蓝 / 珊瑚粉温和 / 草地绿田野 · 主色不锋利)
- 课时编号方块(1./2./3. · 20×20 主色 · 阿拉伯数字 + 点号 · 教科书档案感)
- 圆角软性 shape(borderRadius 4-6 · round-rect · 医院手册温和感 · 不用硬直角)
- 装饰图腾偏"教科书 / 图鉴":拉线章节标注 / 图鉴左上叶片 tick + 右下 L 形品名条 / hairline 树状分支
- 拉丁双名 italic span 常挂(生物 / 医学 · muted 色小字)
- **图片策略**:面向学习者 / 患者 / 学生,追求理解友好 + 亲和。**IconPark 高频**(step / 医疗十字 / 生物图腾);**生图中度**(抽象概念可视化);**image_search 教科书插图 / 图鉴 / 医学示意**;**原生 chart 少用**;**real photo 少用**;全页图片风格统一,不混

**style 子风格分支**:style/learning-and-training.md 定义了 4 种子风格 —— A-1.1 MBE 风(圆体 · 粗描边 3-5px) / A-1.2 儿童绘本水彩卡通风 / A-2 问题牵引 / A-3 专业版。**refine 时先看 page-plan 落定的子风格 · 再走本手册的三段决策树**:
- MBE / 水彩卡通(儿童场景) → decorate 用大圆角 / 手绘感描边 / 高饱和色 · **不套本手册的"课堂靛蓝 + 珊瑚粉"教师风 palette**
- 问题牵引 / 专业版 → 走本手册默认(靛蓝 + 珊瑚粉 · 编号方块 · 三线表 KPI)

## 二、什么样的页需要 refine

**必 refine**:
- `refine_triggers.should_refine=true`(命中任一信号)

**主观 refine**(截图检查):
- 缺内容:整页就一句话 + 几段简介 · 信息量撑不起一页
- 缺表达:3 段纯文字堆砌 / 步骤散在正文 / 长段落无编号无层级
- 缺视觉:一角挤另一角空 / 缺 hero 视觉锚 / 圆角软性 shape 全缺 / 课时编号缺
- 以上 3 点有任意可以进一步优化的地方

## 三、Refine 三类动作(平权 · 缺什么补什么)

三类动作**没有先后**,一页可能同时缺内容 + 缺视觉,那就 enrich + decorate 一起做;也可能只缺表达,那就只 reframe。

### 3.1 · Enrich · 补内容(缺 payload 时用)

**learning 风重教材权威、重学习目标、重案例 Q&A · 少数据密度、少氛围图**。

**A · 用户已给附件/原稿**(`is_manuscript_apply=true`):
- Read 原稿相关章节 · 挖这页可加的**次要信息层**:
  - hero 之外的**学习目标 / 掌握度分层**(布鲁姆:记忆 / 理解 / 应用 / 分析 / 评价 / 创造)
  - **常见误区 / 易错点 / 边界条件**(教材"注意"框)
  - **案例故事 / 病症说明 / 学生 Q&A**(例题 / 病案 / 常见问答)
  - **术语对照 / 中英双名 / 拉丁学名**(消歧)
- 按重要性分层塞进页(hero 概念 + 步骤支撑 + Q&A + 脚注)

**B · 用户只给主题**(`is_manuscript_apply=false`):
- **搜索方向 · learning 优先教材与权威**:
  - 教材权威 / 课程标准(K12 / 高等教育 / 职业培训认证)
  - 学习目标 · 掌握度分层(布鲁姆 / SOLO)
  - 病症说明 / 用药 / 案例 Q&A(WHO / CDC / NIH / 卫健委)
  - 分类学 · 术语对照 · 中英双名(生物 / 医学 / 法律 / 语言)
- **搜索关键词模式**:
  - "\<主题\> curriculum standard" / "\<主题\> learning objectives"
  - "\<病症\> patient education" / "\<物种\> taxonomy Latin binomen"
  - "\<主题\> common misconceptions" / "\<主题\> Q&A"
- **搜完必须标 Source**:引文挂教材 / 论文;病症挂权威指南;脚注一行 "Source: WHO Patient Education Guideline 2024"

**图片策略**:
- **IconPark 极高频**:step 编号 · 医疗十字 · 生物图腾 · 学习图标(书本 / 灯泡 / 问号)· 每页 4-8 个
- **生图中度**:抽象概念可视化(如"细胞分裂过程")· 一页 1-2 张 hero 位
- **image_edit 统一插画风格**:同一 deck 生成图必须过一遍统一风格
- **image_search** 教科书插图 / 医学示意 / 生物图鉴
- **原生 chart 少用**:若用则圆环 KPI 展"进度 3/10 步"这类
- **real photo 少用**:除非教学器材 / 科学家肖像

**enrich 后的产物**:一份"内容清单"(hero 概念 + step 支撑 + Q&A + 术语框 + 脚注)

### 3.2 · Reframe · 换表达形式(有内容但表达弱时用)

把已有内容**换更强视觉表达**。learning 风常用替换:

- **步骤 → 编号阶梯 1./2./3./4.**(前提:有先后 · 每步 hero 一 icon)
- **概念 → 术语框 + italic 学名 + 中文对照**(前提:术语需消歧)
- **段落 → 图文卡阵**(前提:内容平权 · 左 icon / 中 title / 右 说明)
- **对照 → 三线表 + accent 差异标注**(前提:多方对照 · 初级 vs 中级 vs 高级)
- **时序 → 生活史时间线**(前提:有生命周期 · 配子 → 孢子 → 成体)
- **分类 → 分类树 3-4 层**(前提:有层级归属 · 界门纲目科属种)
- **注意事项 → 4 卡阵 · 每卡一 icon + 一句 warning**(前提:医疗手册感)
- **Q&A → 折叠卡阵**(前提:多组问答 · Q 卡 + A 卡上下叠或分栏)
- **hero 数据 → 圆环 KPI**(前提:进度类数字 · 不追 pitch 冲击)
- **长段落 → 分点 bullet + 首句加粗**(前提:段内 3-5 个平行观点)
- **公式 / 定理 → 独立居中大字号 + 边注**(前提:配一句人话解释)

**reframe 时的 learning 风原则**:
- 圆角软性 shape 优先(round-rect · borderRadius 4-6 · 不用硬直角)
- 卡阵克制(4 卡最多 · 卡内 3 层:icon / title / 说明)
- accent 色仅用于"结论词 / 关键术语 / warning"高亮 · 一页至多 1-2 处
- 术语必配拉丁双名 italic 或中英对照
- 步骤必配课时编号(1./2./3.)

### 3.3 · Decorate · 加视觉锚点(缺视觉时用)

**装饰母题库**:
1. 课时编号方块(20×20 主色 · 1./2./3. · 步骤卡左上或主标左侧)
2. 教科书档案图腾(hairline 拉线 + "Ch.1 §2.3" · 页边距外侧)
3. 圆角软性 shape(borderRadius 4-6 · round-rect · 卡片 / 边框全圆角)
4. 医疗十字图腾(红色 / 珊瑚色 · 加号 12-16px · 患者教育页)
5. 图鉴档案卡角标(左上叶片 tick + 右下 L 形品名条)
6. 分类学连线(hairline 树状分支 · 1px 主色)
7. 眉标短线(2-3px × 24-32px 主色 · y=88-94 · 配英文 eyebrow)
8. 编号圆点(6×6 主色 · 步骤节点)
9. hairline 分割线(1px 极浅主色 · 分节 / 分列)
10. signature 竖装饰条(2-3px × 60-100px 主色 · 卡内侧或整页左侧)
11. italic 拉丁双名 span(生物 / 医学 · muted 色小字)

**视觉锚点升级库**(把已有元素做大做强):
- hero step 大图标 + 大字号 title(icon 60-80px + title 40pt+)
- hero 术语大字号 + 拼音 / 音标(语言学习 · 主字 60pt+ · 下配音标 24pt italic)
- hero 数据圆环("当前进度 3/10 步" · 220×220 圆环 · 中心大字 3/10)
- 拉丁双名 italic hero(中文常名 48pt + 下方 italic 拉丁名 20pt muted)

**布局重构库**(修视觉塌陷 · 每次 refine 最多挑 1 个):
- 上 hero(概念 icon + title)+ 下 3-4 步支撑
- 左侧目录导航(章节 / 课时)+ 右侧内容(20/80 分)
- Q + A 上下分栏(Q 卡上 30% · A 卡下 70%)
- 分类树中央 + 案例四周(生物 / 分类学页)

## 四、使用规则

**判断这页缺什么的信号(每类独立触发 · 不排序)**:
- `total_text_chars < 60` 或截图看整页几句话就完 → 3.1 enrich 补内容
- 文字够但堆砌成段落 / 步骤散在正文 / 无课时编号 → 3.2 reframe 换表达
- `visual_elements ≤ 12` 或截图看装饰全缺、圆角软性 shape 缺 → 3.3 decorate 加视觉锚
- **一页可能同时缺 2 类 / 3 类**,那就多类一起做

**气质一致性**(每次 refine 后过):
- 加的元素亲和吗?(圆角 / 温和主色 / IconPark 图标 · 不用学术冷硬 hairline)
- 学习友好吗?(有 step 编号 · 有概念定义框 · 有 Q&A)
- 图片风格统一吗?(一致插画风 or 一致照片风 · 不混 Q 版 + 写实 + 线稿)
- 术语准确吗?(拉丁双名 · 医学术语 · 教材权威 · 不自造)

**不要做的事**:
- 不要动 brand_assets(背景 / 页眉 / 页脚 / 装饰线 · 一律保留 · 只加不删)
- 不要用 pitch 冲击力(learning 不是路演 · 不要 60pt 数字砸脸)
- 不要用学术冷峻(不用罗马数字 / 金石印章 / 图纸网格)
- 不要用品牌情绪图代替教学示意(氛围图对学习无帮助)
- 不要混不同插画风(一页 Q 版 + 写实 + 线稿 就是灾难)
- 不要编造术语和数据:拉丁双名不能臆造 · 病症数据必带权威 Source
- 不要跳过 enrich 只做 decorate 装饰凑数
