# academic-research · Refine Handbook

学术研究场景的 refine 手册。当内容页需要 refine 时,**判断这页缺什么(缺内容 / 缺表达 / 缺视觉),补什么**。三种动作平权,不排序。

## 一、气质定位

**母题特征**:
- 眉标偏纤细(2-4px 细短线)· 顶部或左侧竖排
- 编号方块偏正式(罗马数字 I/II/III 或阿拉伯 01/02 · 20-30px 小方块)
- 装饰图腾偏"档案感":金石印章方块 / 双栏底纹 / 图纸网格 / 信号灯 / 尺寸引线
- 数据溯源脚注**每页必挂**(小字号 · 底部单行 · Source/N=/CI 等)
- **图片策略**:学术风重数据不重图片。真实照片、生图、image_edit **默认少用**(除非人物合影 / 实地场景需要);优先用 SVG 数据可视化(chart / diagram / 时间线)、IconPark 图标(方法学示意)、双栏参考文献底纹

## 二、什么样的页需要 refine

**必 refine**:
- `refine_triggers.should_refine=true`(命中任一信号)

**主观 refine**(截图检查):
- 缺内容:整页就一句话 + 几段简介 · 信息量撑不起一页
- 缺表达:3 段纯文字堆砌 / 数字散在正文 / 长段落无层级
- 缺视觉:一角挤另一角空 / 缺 hero 视觉锚 / 装饰母题全缺
- 以上 3 点有任意可以进一步优化的地方

## 三、Refine 三类动作(平权 · 缺什么补什么)

三类动作**没有先后**,一页可能同时缺内容 + 缺视觉,那就 enrich + decorate 一起做;也可能只缺表达,那就只 reframe。

### 3.1 · Enrich · 补内容(缺 payload 时用)

**学术风的补内容,重数据、重文献、重方法学 · 少图片、少氛围**。

**A · 用户已给附件/原稿**(`is_manuscript_apply=true`):
- Read 原稿相关章节 · 挖这页可加的**次要信息层**:
  - hero 之外的**次要指标 / 分维度数据**(整体 KPI 之外的分组、时间序列、置信区间)
  - **相关引文 / 学者观点 / 已有研究**(原稿参考文献列表里跟本页主题相关的 2-3 篇)
  - **对照 / 反例 / 边界条件**(实验设计里的对照组 / 敏感性分析)
  - **方法学细节**(样本 N / 时间窗口 / 计算方法 / 显著性水平 p 值)
- 按重要性分层塞进页(hero + 支撑数据 + 引文脚注)

**B · 用户只给主题**(`is_manuscript_apply=false`):
- **搜索方向 · 学术优先真实来源**:
  - 权威机构统计(WHO / IMF / OECD / 教育部 / IEEE / NIST)
  - 高被引论文关键结论(Google Scholar / arxiv 引用数排序)
  - Meta-analysis / 系统综述结论(effect size / confidence interval)
  - 官方 benchmark(ImageNet / GLUE / MMLU 等)
- **搜索关键词模式**:主题 + 学术限定词
  - "K12 AI tutoring effect size 2024" / "urban heat island meta-analysis 2023"
  - "\<主题\> systematic review" / "\<主题\> benchmark result"
- **搜完必须标 Source**:脚注一行 "Source: WHO Global Health Estimate 2023, N=193 countries" · 不占主视觉

**图片策略**:
- **优先原生图表或 SVG 数据可视化**: 学术风的"图片"就是"数据可视化"
- **IconPark 图标少量点缀**:方法学示意 · 流程节点 · 每页至多 2-3 个
- **真实照片仅用于**:实验场地 / 器件实物 / 人物合影 / 历史文献扫描
- **生图 / image_edit 默认不用**:学术风不追求氛围感

**enrich 后的产物**:一份"内容清单"(hero + 支撑数据 + 引文 + 脚注)· 直接塞进本页

### 3.2 · Reframe · 换表达形式(有内容但表达弱时用)

把已有内容**换更强视觉表达**。学术风常用替换:

- **3 段纯文字 → 三线表**(前提:内容天然分层 · 有"维度 × 值"结构)
- **3 段纯文字 → 卡阵**(前提:内容平权 · 每项独立)
- **长段落 → 分点 bullet + 首句加粗**(前提:段内有 3-5 个平行观点)
- **散布正文的数字 → hero KPI 数字带**(前提:数字是本页 payload)
- **时序描述 → 横向时间线 / 竖向阶段带**(前提:有明确时间节点)
- **对照句子 → 二列对照表 / 2×2 象限 / SWOT**(前提:两方视角对峙)
- **列举 → 编号阶梯 / 逻辑箭头链 / CoT 流程图**(前提:有先后 / 因果 / 递进)
- **例证 → 引文块 + 作者归属 + 年份**(前提:名家 / 权威说法)
- **公式 / 定理 → 独立居中大字号 + 边注**(前提:是本页 payload)
- **实验结果 → 数据表格 + 显著性标注 (\*\*\* p<0.001)**(前提:是实证研究)
- **概念定义 → 术语框 + italic 学名 + 中文对照**(前提:多学科交叉需消歧)

**reframe 时的学术风原则**:
- 三线表优先(顶线 + 表头下线 + 底线 · 全 hairline · 无竖线)
- 卡阵克制(4 卡最多 · 卡内 3 层:label / value / 脚注)
- accent 色仅用于"结论词 / 关键数字"高亮 · 一页至多 1-2 处
- 引文格式:作者. 标题. 期刊, 年 · italic 期刊名

### 3.3 · Decorate · 加视觉锚点(缺视觉时用)

**装饰母题库**:
1. 顶部眉标短线(主色 2-4px × 20-40px · y=88-94 · 配英文 eyebrow label · letterSpacing 3+)
2. 编号方块(20-30px · 罗马数字或阿拉伯 · 主色底白字或反色 · 卡内左上或主标左侧)
3. hairline 分割线(1px · 极浅主色 · 分节 / 分列 / 段间)
4. signature 竖装饰条(2-3px × 60-100px · 主色 · 卡内侧或整页左侧)
5. 金石印章方块(15-25px · 深色底白字单字"论/析/证" · 档案考据感)
6. 图纸网格底(极浅 hairline · 20×20 方格 · 理工答辩常用)
7. 信号灯 / 状态灯(6-8px 圆点 · 3 色表示状态或进度节奏)
8. 尺寸引线(1px 虚线 + 端点 tick + 中间数字标签)
9. 参考文献双栏底纹(页脚 y=470 · 200×20 半透明 × 2 栏)
10. 顶部朱砂细线(深墨底页专用 · 1px × 940 · 深红 y=68)

**视觉锚点升级库**(把已有元素做大做强):
- hero KPI 提到 60pt+ · 加 220×220 圆环底(主色 1-2px 边框)
- 主标下加半透明主色色块 · 做视觉分区
- 关键结论 accent span 高亮(深墨底页 + 朱砂红最强)
- hero 引言块(24-32pt · 上下 hairline 夹 · 左右各留 100px 白)

**布局重构库**(修视觉塌陷 · 每次 refine 最多挑 1 个):
- 左右对称分栏(60% 主 + 40% 支撑 · 中间 hairline)
- 上 hero + 下支撑 3 卡
- 左侧目录 + 右侧内容(20/80 分)
- 中央聚焦 + 四周留白(结论页 / 关键发现页)

## 四、使用规则

**判断这页缺什么的信号(每类独立触发 · 不排序)**:
- `total_text_chars < 60` 或截图看整页几句话就完 → 3.1 enrich 补内容
- 文字够但堆砌成段落 / 数字散在正文 → 3.2 reframe 换表达
- `visual_elements ≤ 12` 或截图看装饰全缺、视觉重心塌陷 → 3.3 decorate 加视觉锚
- **一页可能同时缺 2 类 / 3 类**,那就多类一起做

**气质一致性**(每次 refine 后过):
- 加的元素是学术风吗?(hairline 而非 gradient · 罗马数字而非花体 · 纤细而非粗块状)
- 强调色克制吗?(一页至多 1-2 处 accent 色高亮)
- 数据有溯源吗?(hero KPI 下必配 Source 脚注)
- 图片没滥用吗?(SVG 数据可视化 > IconPark 图标 > 真实照片 > 生图)

**不要做的事**:
- 不要动 brand_assets(背景 / 页眉 / 页脚 / 装饰线 · 一律保留 · 只加不删)
- 不要编造数据:enrich 走搜索时必须真实来源 · 带 Source 脚注
- 不要用氛围图代替数据(学术风不追求情绪,追求信噪比)
- 不要跳过 enrich 只做 decorate 装饰凑数(内容不足时补装饰只会让页更难读)
