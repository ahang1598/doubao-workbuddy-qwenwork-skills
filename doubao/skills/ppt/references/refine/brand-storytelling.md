# brand-storytelling · Refine Handbook

品牌叙事场景的 refine 手册。当内容页需要 refine 时,**判断这页缺什么(缺内容 / 缺表达 / 缺视觉),补什么**。三种动作平权,不排序。

## 一、气质定位

**母题特征**:
- palette 偏暖:深胡桃 / 亚麻 / 石灰墨 / 茶白 / 松烟 · 低饱和 · 避免冷色数据蓝
- 字体族:headline 宋体(仪式感 / 编辑刊感) · body 黑体 · italic 眉标做编辑刊呼吸
- 圆角软性 shape 为主(borderRadius 4-8 · round-rect · 极少直角硬线)
- 装饰图腾偏"匠心考据感":印章方块 / 火漆封蜡 / 竖排箴言侧边条 / 大字号中文编号 / 双 hairline 夹眉标
- 引文必须归属(作者 · 年份 · 出处)· Source 相对轻
- **图片策略**:重氛围重情绪。**优先生图 / image_edit** 营造情绪(工艺细节 / 场景产品 / 品牌视觉世界);真实照片用于创始人 / 匠人 / 历史节点;stock photo 挑高质量情绪图;**少用 SVG chart 或 IconPark**

**style 家族与版式装置**:style/brand-storytelling.md 定义了 6 大家族(F1 纸墨东方 / F2 深空精密 / F3 暖土手作 / F4 澄澈商务 / F5 高张力表达 / F6 提案画册)· 每家族有独立 palette / 字距 / 版式装置(L01-L26)。**refine 时先看 page-plan 落定的家族 · 沿用该家族的 palette 和装置**:本手册的三段决策树(enrich/reframe/decorate)在家族约束内做视觉拔高 · **不跨家族混色 / 混字体**。

## 二、什么样的页需要 refine

**必 refine**:
- `refine_triggers.should_refine=true`(命中任一信号)

**主观 refine**(截图检查):
- 缺内容:整页就一句话 + 几段简介 · 品牌故事没讲透 · 情绪浓度不够
- 缺表达:3 段纯文字堆砌 / 引文散在正文 / 长段落无仪式感
- 缺视觉:一角挤另一角空 / 缺 hero 情绪锚 / 装饰母题全缺 / 氛围没起来
- 以上 3 点有任意可以进一步优化的地方

## 三、Refine 三类动作(平权 · 缺什么补什么)

三类动作**没有先后**,一页可能同时缺内容 + 缺视觉,那就 enrich + decorate 一起做;也可能只缺表达,那就只 reframe。

### 3.1 · Enrich · 补内容(缺 payload 时用)

**brand-storytelling 的补内容,重故事、重氛围、重视觉世界 · 少罗列、少堆砌**。

**A · 用户已给附件/原稿**(`is_manuscript_apply=true`):
- Read 原稿相关章节 · 挖这页可加的**故事纵深层**:
  - **创始人自述 / 匠人访谈 / 品牌史节点**(hero 之外)
  - **文化背景 / 工艺沿革 / 材料溯源**(把产品放回历史坐标)
  - **名家 quote / 用户评价 / 权威推荐**(挑一句做竖排引文)
  - **视觉素材清单**(附件产品图 / 场景图 / 老照片 · 后续 image_edit 统一风格)
- 按情绪浓度分层塞进页(hero 引文 + 故事支撑 + 视觉锚)

**B · 用户只给主题**(`is_manuscript_apply=false`):
- **搜索方向 · 优先文化 / 故事 / 匠心线索**:
  - 品牌历史节点 / 创始人故事 / 匠人访谈
  - 文化背景 · 相关历史 · 手工艺沿革 / 非遗记录
  - 视觉参考图(生图前需要参考 · 例如"日式茶道 minimalist 情绪图 2024")
  - 名家 quote / 名句 / 诗词(适合竖排引文)
- **搜索关键词模式**:
  - "<主题> heritage story" · "<主题> craftsman interview"
  - "<品牌> founder quote" · "<主题> 匠人手记" · "<主题> 非遗沿革"
- **引文归属**:必须挂作者 · 年份 · 出处(格式偏散文 · 不像学术那么硬)

**图片策略**:
- **重度用生图**(image_generate)营造品牌视觉世界 · hero 情绪图占 40-60%
- **重度用 image_edit** 把附件产品图 / 场景图统一风格化:宋体标题 / 胡桃色调 / 暗角 / 纸质纹理 / 印章角标
- **image_search 补历史照片 / 匠人肖像 / 品牌档案**
- **SVG 数据可视化 / IconPark** 默认少用 · 除非做工艺流程示意或参数带

**enrich 后的产物**:一份"故事清单"(hero 引文 + 情绪图 + 故事支撑 + 参数)· 直接塞进本页

### 3.2 · Reframe · 换表达形式(有内容但表达弱时用)

把已有内容**换更强视觉表达**。brand-storytelling 常用替换:

- **3 段纯文字 → 卡阵**(前提:内容平权 · 卡内圆角 + 宋体标 + italic 眉标)
- **段落 → hero 引文块**(前提:有代表性 quote · 大字号 · 上下 hairline 夹)
- **列举 → 竖排 4 字箴言侧边条**(前提:可提炼成 4 字 · 篆刻感 · 每格一字)
- **时序描述 → 陈化 / 沉淀阶段带**(前提:讲究"时间积淀"叙事 · 岁月长卷隐喻)
- **对照 → 前世今生双联页**(前提:讲传承 / 演变 · 左老照片 vs 右现代产品)
- **产品罗列 → 图文混排**(前提:主视觉够强 · 左产品图 60% · 右 quote + 参数)
- **例证 → 引文块 + 作者归属 + 年份**(前提:名家 / 大师说法)
- **概念定义 → 术语框 + 中文名 + italic 洋名**(前提:讲工艺 / 材料学名)
- **产品参数 → hero 大字号数字 + 单位小字 + 情绪图背景**(前提:数字是本页 payload)

**reframe 时的 brand-storytelling 风原则**:
- 卡内层级:italic 眉标 / 宋体标题 / 短描述 / 可选印章角标 · 圆角 4-8
- accent 色仅用于"火漆封蜡 / 结论词高亮"· 一页至多 1 处 accent 红
- 引文格式:横排全屏 quote 或竖排 4 字箴言 · 归属"—— 作者 · 年份"
- 大字号中文编号(壹 / 贰 / 叁 / 肆)可替代数字 01/02 · 唱主角

### 3.3 · Decorate · 加视觉锚点(缺视觉时用)

**装饰母题库**:
1. 圆角软性 shape(borderRadius 4-8 · 卡片 / 引文块 / 参数带全用圆角)
2. 竖排引文侧边条(3-4 字箴言 · 手写宋体感 · 单字 24-36pt)
3. 印章图腾方块(15-25px 深色底白字单字"品/艺/心/序")
4. 火漆封蜡符号(直径 30-40px 圆形或菱形 · 红色 / 金色 · 一页 1 处)
5. italic 编辑刊眉标(细字号 · 主色 · 顶部 y=80 附近)
6. 大字号中文编号(48-72pt · 主色重块背景 · 壹 / 贰 / 叁 / 肆)
7. 双 hairline 夹眉标(上下各 1px · 极宽 letterSpacing 5-6)
8. 竖排诗词 / 名句 shape(4-8 字 · 单字独立 · 主色宋体)
9. 纸质纹理背板(极淡 alpha · 全页或局部)
10. 章印角标(卡片右下角 · 20×20 · 单字或双字)

**视觉锚点升级库**(把已有元素做大做强):
- hero 引言块变全屏 quote 页(整页留白 · 中央大字号 32-48pt · 四角配签名 / 火漆封蜡)
- 匠心分级阶梯(壹 / 贰 / 叁 / 肆 · 大编号 48-60pt + 小字描述)
- 单人聚焦大产品图 + quote 交叉排版(产品图 60% · quote 悬浮或错位)
- 大字号中文编号铺满主色重块 · 一角一块

**布局重构库**(修视觉塌陷 · 每次 refine 最多挑 1 个):
- 上 hero 引文 + 下 4 卡支撑
- 左右分栏 · 左 60% 主视觉图 · 右 40% quote + 参数
- 中央聚焦 · 大字号 quote 独占页面(结尾页 / 转场页 / 品牌宣言页)
- 前世今生双联(左老照片 + 右现代产品 · 中间竖 hairline)

## 四、使用规则

**判断这页缺什么的信号(每类独立触发 · 不排序)**:
- `total_text_chars < 60` 或截图看整页几句话就完 → 3.1 enrich 补故事纵深
- 文字够但堆砌成段落 / 引文散在正文 / 参数无仪式感 → 3.2 reframe 换表达
- `visual_elements ≤ 12` 或截图看装饰全缺、氛围没起来 → 3.3 decorate 加视觉锚
- **一页可能同时缺 2 类 / 3 类**,那就多类一起做

**气质一致性**(每次 refine 后过):
- 加的元素是品牌故事风吗?(圆角 / 宋体 / italic · 而不是学术 hairline 直角)
- 主色偏暖吗?(深胡桃 / 亚麻 / 茶白 · 而不是学术冷色数据蓝)
- 情绪浓度是否到位:留白够大 · 一张 hero 情绪图
- 图片有统一气质吗?(所有图经过 image_edit 风格化 · 不能一张日系一张欧美)
- accent 红克制吗?(一页至多 1 处火漆封蜡感)

**不要做的事**:
- 不要动 brand_assets(背景 / 页眉 / 页脚 / 装饰线 · 只加不删)
- 不要在同一页混学术 / 商务 / 品牌风(比如品牌页突然加 hero KPI 数字环绕 / 三线表)
- 不要用花哨渐变盖过品牌辨识度(暖色 palette 是底色 · 不是舞台效果)
- 不要滥用 accent 红(火漆封蜡感 · 一页 1 处足够 · 多了变廉价促销)
- 不要跳过 enrich 只做 decorate 装饰凑数(故事不够时补装饰只会让页更空)
- 不要用低质 stock photo · 不要冷漠地铺 SVG chart(数据可视化不是本 style 强项)
