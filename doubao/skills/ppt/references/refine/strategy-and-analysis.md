# strategy-and-analysis · Refine Handbook

战略咨询 / 分析报告场景的 refine 手册。当内容页需要 refine 时,**判断这页缺什么(缺内容 / 缺表达 / 缺视觉),补什么**。三种动作平权,不排序。

## 一、气质定位

**母题特征**:
- palette 严肃厚重:勃艮第酒红 / 墨玉青 / 赭石橙 · 沉稳不轻浮
- 大字号差异化极强(hero 80pt+ 洞察数字 · 主标 40pt+)· letterSpacing 3-4 极宽 · BCG / 麦肯锡感
- 竖细线骨骼(2×20 眉标 / 3×80 signature)· 岩层堆叠(4-5 层 hairline)
- 编号方块偏正式(20-30px 深色底白字 · 罗马 I/II/III 或阿拉伯)
- 装饰图腾偏"咨询档案感":BCG 气泡圆环 / 波特小图腾 / 6×6 档案钉 / L 角标 / 结论条 / 天干甲乙丙丁
- **图片策略**:咨询重框架、重分析、少氛围。真实照片、生图默认不用;优先 SVG 战略框架(波特五力 / BCG / SWOT / 金字塔 / 漏斗 / 7S)、原生 chart(市场份额 / 增长曲线 / 归因瀑布 / 敏感性)、image_search / image_edit 仅用于客户与案例公司 logo

## 二、什么样的页需要 refine

**必 refine**:
- `refine_triggers.should_refine=true`(命中任一信号)

**主观 refine**(截图检查):
- 缺内容:整页就一句战略结论 · 无数据 · 无归因 · 无对标
- 缺表达:3 段纯文字堆砌 / 战略要素散在正文 / 竞品对比只用文字而不上矩阵
- 缺视觉:一角挤另一角空 / 缺 hero 洞察数字 / 装饰全缺 / 该上框架却只有文字
- 以上 3 点有任意可以进一步优化的地方

## 三、Refine 三类动作(平权 · 缺什么补什么)

三类动作**没有先后**,一页可能同时缺内容 + 缺视觉,那就 enrich + decorate 一起做;也可能只缺表达,那就只 reframe。

### 3.1 · Enrich · 补内容(缺 payload 时用)

**咨询风的补内容,重经典框架、重行业分析、重竞品动态 · 少氛围、少 pitch 冲击**。

**A · 用户已给附件/原稿**(`is_manuscript_apply=true`):
- Read 原稿相关章节 · 挖这页可加的**次要信息层**:
  - hero 之外的**分维度数据**(细分品类 / 区域 / 时序增长率)
  - **竞品动态 / 战略事件**(收购 · 融资 · 产品线扩张)
  - **归因 / 对策 / 敏感性**("为什么 · 怎么办" · 咨询核心)
  - **对标 benchmark**(行业中位数 / Top3 集中度 / 头部标杆指标)
- 按重要性分层塞进页(hero 洞察 + 框架图 + 支撑数据 + Source 脚注)

**B · 用户只给主题**(`is_manuscript_apply=false`):
- **搜索方向 · 咨询优先经典框架 + 权威机构**:
  - 咨询公司经典框架(麦肯锡 / BCG / 贝恩 / 罗兰贝格 / 埃森哲)
  - 行业分析(Gartner / IDC / CB Insights / 艾瑞 · 增长率 · 集中度)
  - 竞品动态(Crunchbase 融资 / 年报 / 财报电话)
  - 经典框架(波特五力 / SWOT / 4P / 3C / 7S / Ansoff)
- **搜索关键词模式**:
  - "\<主题\> Porter's Five Forces" / "\<主题\> BCG matrix"
  - "\<行业\> Gartner Magic Quadrant 2024" / "\<主题\> McKinsey framework"
  - "\<行业\> market concentration HHI" / "\<行业\> top3 market share"
- **搜完必须标 Source**:数据挂 "Source: McKinsey Global Institute 2024" · 竞品挂 CB Insights / Crunchbase · 编造 = 报告作废

**图片策略**:
- **原生 chart + SVG 框架图 极高频**:BCG / 波特五力 / 7S / 金字塔 / 漏斗 / SWOT / 象限 —— 咨询页面核心视觉几乎全是框架
- **image_search 中度**:客户 logo / 案例公司 logo
- **image_edit 少度**:logo 尺寸与背景统一
- **真实照片默认不用**(咨询不是 pitch)· **生图不用**(咨询要严谨)
- 一页最多 1 张主视觉(框架图 or chart)· 支撑图 1-2 张

**enrich 后的产物**:一份"内容清单"(hero 洞察 + 框架图 + 支撑数据 + Source 脚注)

### 3.2 · Reframe · 换表达形式(有内容但表达弱时用)

把已有内容**换更强视觉表达**。咨询风常用替换:

- **段落 → 战略 2×2 象限**(BCG · Ansoff · GE · 优先级 · 前提:两轴可度量)
- **列表 → 3×3 战略矩阵**(GE 麦肯锡九宫格 · 前提:两轴各 3 档 · 定位业务组合)
- **多要素 → 7S 星形 / 花瓣**(战略 / 结构 / 系统 / 风格 / 员工 / 技能 / 共同价值 · 7 要素协同)
- **对照 → 战略金字塔 5 层**(愿景 → 使命 → 战略 → 目标 → 行动)
- **步骤 → 转化漏斗 5 阶**(意识 → 兴趣 → 考虑 → 购买 → 复购)
- **对比 → 波特五力**(SVG · 5 方向箭头指向中心)
- **优劣 → SWOT 四宫格**(S/W/O/T · 2×2)
- **数据带 → 3 数字表头 + 详情**("Top3 洞察" · 咨询标配)
- **对手分析 → 4 竞品三线表**(自己 vs 3 家竞品 · 关键维度对比)
- **战略路径 → 3 阶段步骤**(现状 → 过渡 → 目标)
- **分类 → 分类树 / issue tree**(问题拆解 · MECE 原则)
- **散布数字 → hero 洞察大字号**(80pt · 不是 KPI · 是"70% 市场集中在 3 家")

**reframe 时的咨询风原则**:
- 框架图必须**用对**:BCG 用于产品组合 / 波特用于竞争 / SWOT 用于战略 · 用错比不用还糟
- 三线表优先(顶线 + 表头下线 + 底线 · 全 hairline · 无竖线)
- accent 色仅用于"关键结论词 / 洞察数字"高亮 · 一页至多 1-2 处
- 数字必带对标:"70%" 无意义 · "70%(行业中位数 45%)" 才是咨询语言

### 3.3 · Decorate · 加视觉锚点(缺视觉时用)

**装饰母题库**:
1. 编号方块(20-30px 深色底白字 · 罗马 I/II/III 或阿拉伯 · 咨询正式感)
2. signature 竖装饰条(3×80 主色 · 卡内侧或整页左侧)
3. 咨询框架图腾(GE / 波特 / 金字塔 / BCG / 7S 小图 · 页边角)
4. 竖细线眉标(2×20 · letterSpacing 2 · 骨骼感)
5. 粗短线眉标(40×4 · letterSpacing 4 · 岩层堆叠稳重感)
6. 中央档案钉(6×6 · accent 色 · 4 角对称)
7. 岩层堆叠图腾(4-5 层 hairline 横条)
8. L 角标(左下 / 右下 · 咨询报告角标)
9. BCG 气泡装饰(圆环 · 表示"象限位置")
10. 天干编号(甲乙丙丁戊 · 中式咨询感)
11. 结论条(底部一整条 accent · 关键结论明示)

**视觉锚点升级库**(把已有元素做大做强):
- hero 洞察数字提到 80pt · **不是 KPI 感** · 是"关键洞察数字"("70% 市场集中在 3 家")
- 主标副标重叠矩形 · 咨询感
- 关键结论 accent 短横锚点 · 结论条明示
- Overall 森林 accent 大圆(元分析感)
- 主标下加半透明主色色块 · 做视觉分区

**布局重构库**(修视觉塌陷 · 每次 refine 最多挑 1 个):
- 中央框架图 + 四周洞察(BCG / 波特五力 · 单一框架大居中)
- 左侧问题 + 右侧对策(SWOT 双列 · 60/40 或 50/50)
- 上 hero 洞察 + 下 3 段支撑(executive summary)
- 全页金字塔 / 漏斗(单一框架 · 中央大 · 层层收窄)

## 四、使用规则

**判断这页缺什么的信号(每类独立触发 · 不排序)**:
- `total_text_chars < 60` 或整页只有一句战略结论 → 3.1 enrich
- 文字够但堆砌成段落 / 竞品对比只用文字 → 3.2 reframe 换矩阵 / 框架图
- `visual_elements ≤ 12` 或装饰全缺 / 缺 hero 洞察数字 / 该上框架却没上 → 3.3 decorate
- **一页可能同时缺 2 类 / 3 类**,那就多类一起做

**气质一致性**(每次 refine 后过):
- 加的元素是咨询感吗?(经典框架 / 大字号 letterSpacing 3-4 · 不是 pitch 冲击 · 不是学术 hairline)
- 分析深度够吗?(不是"数字大" · 是"数字背后的洞察 · 有对标有归因")
- 框架用得对吗?(BCG 用于产品组合 / 波特用于竞争 / SWOT 用于战略 · 用错比不用还糟)
- 强调色克制吗?(一页至多 1-2 处 accent 高亮结论词)
- Source 有挂吗?(数据必挂 McKinsey / BCG / Gartner / CB Insights)

**不要做的事**:
- 不要动 brand_assets(背景 / 页眉 / 页脚 / 装饰线 · 只加不删)
- 不要用 pitch 冲击(咨询不是路演 · 大字号是为了洞察不是为了炸)
- 不要用品牌情绪图 / 团队合影(氛围图对分析无帮助)
- 不要跳过 Source(咨询数据必须真实 · 编造 = 报告作废)
- 不要滥用框架(不是每页都要 SWOT · 场景不匹配就别硬套)
- 不要跳过 enrich 只做 decorate 凑数(无数据支撑的装饰只会让页更空洞)
