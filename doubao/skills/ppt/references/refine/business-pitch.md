# business-pitch · Refine Handbook

商业路演场景的 refine 手册。当内容页需要 refine 时,**判断这页缺什么(缺内容 / 缺表达 / 缺视觉),补什么**。三种动作平权,不排序。

## 一、气质定位

**母题特征**:
- 眉标短线粗细各变(20×2 / 20×3 / 24×3 / 40×4)· 主色饱和
- 双竖线 ‖ 分隔符签名(眉标里 · 折衷艺术张力)
- 商务档案图腾:"NO. 01" / "PART I" 编号方块(20×20 主色底白字)
- 陶土工业标签(35×18 主色圆角 rect + 内嵌数字)
- palette 沉稳 + 亮色点睛:深森林绿 / 葡萄紫 / 波尔多酒红 / 陶土橙 · accent 仅用于结论词与 hero 数字
- 字体族:headline 黑体加粗 · body 黑体
- **图片策略**:重专业 + 适度冲击。**重度用 logo 图**(客户 / 合作方 / 投资方 logo 墙)· **image_edit 关键**(产品去背景 / 团队合影统一色调)· **真实照片**(团队 / 办公室 / 产品)· **原生 chart / SVG 重度**(TAM 漏斗 / 增长曲线 / 财务预测)· **不用氛围情绪图 / 不用手绘插画**

## 二、什么样的页需要 refine

**必 refine**:
- `refine_triggers.should_refine=true`(命中任一信号)

**主观 refine**(截图检查):
- 缺内容:整页一句话 · 关键数字没挂 Source
- 缺表达:纯文字堆砌 / 数字散在正文 / KPI 未做大 / 竞品写成段落
- 缺视觉:一角挤一角空 / 缺 hero 数字锚 / 客户 logo 未整齐 / pitch 冲击力不足
- 以上 3 点有任意可以进一步优化的地方

## 三、Refine 三类动作(平权 · 缺什么补什么)

三类动作**没有先后**,一页可能同时缺内容 + 缺视觉,那就 enrich + decorate 一起做;也可能只缺表达,那就只 reframe。

### 3.1 · Enrich · 补内容(缺 payload 时用)

**pitch 风的补内容,重市场数据、重竞品情报、重客户背书**。

**A · 用户已给附件/原稿**(`is_manuscript_apply=true`):
- Read 原稿相关章节 · 挖可加的**次要信息层**:
  - hero KPI 之外的**分维度指标**(分行业 / 分地区 / 分产品线)
  - **客户案例细节**(客户名 / 场景 / ROI / 上线周期)
  - **团队履历补充**(创始人前公司 / 关键成员 / 顾问团)
  - **融资历史 / 估值路径 / 资金用途**(pitch 必挂)
- 按投资人视角分层(hero + 支撑证据 + 客户背书 + Source)

**B · 用户只给主题**(`is_manuscript_apply=false`):
- **搜索方向 · 优先商业情报**:
  - 竞品估值 / 融资历史 / 客户案例(Crunchbase / PitchBook / IT 桔子)
  - TAM / SAM / SOM 市场数据 · 行业增长率(Gartner / IDC / CB Insights / 艾瑞)
  - 权威机构行业报告(Frost & Sullivan / McKinsey / BCG / Deloitte)
  - 客户 logo 收集 · 用户 quote · media 报道
- **搜索关键词模式**:
  - "\<行业\> market size 2024" / "\<竞品\> valuation series B"
  - "\<客户\> logo" / "\<主题\> Gartner Magic Quadrant"
  - "\<行业\> CAGR 2024-2030" / "\<赛道\> top players"
- **关键数据必挂 Source**:如"TAM $50B · Source: Gartner 2024" · 只挂关键承诺性结论

**图片策略**:
- **image_search 重度**:客户 logo / 团队照 / 产品实物 / 办公室照
- **image_edit 关键**:统一 logo 墙 / 产品去背景 / 团队照统一色调
- **原生 chart / SVG 重度**:TAM 三层漏斗 / 增长曲线 / 财务预测双轴柱线 / 市场份额饼图
- **生图不常用**(pitch 需真实感)· **不用手绘插画**(不专业)

**enrich 后的产物**:一份"内容清单"(hero 数字 + 客户证据 + 市场数据 + Source)· 塞进本页

### 3.2 · Reframe · 换表达形式(有内容但表达弱时用)

把已有内容**换更强视觉表达**。pitch 风常用替换:

- **散布正文数字 → hero KPI 3 联**(3 数字并列 · 每个 60-80pt · 主色 220×220 圆环底)
- **市场规模描述 → TAM-SAM-SOM 三层漏斗**(从大到小递减 · 每层数字 + Source)
- **竞品段落 → 竞品矩阵 2×2**(自己 vs 3 家 · 自己列 accent)
- **团队介绍段 → 创始团队 4 卡阵**(照片 + 姓名 + 履历 + 前公司 logo)
- **发展历程 → 路演路径 5 步链**(节点 → 箭头 → 里程碑 · 编号方块起头)
- **财务表述 → 财务预测双轴柱线**(左轴 revenue · 右轴 growth rate)
- **风险讨论 → 风险 vs 对策双列**(左风险 hairline · 右对策 accent)
- **投资亮点 → 大字号 4 卡**(Why Now / Why Us / Why This / Why Big)
- **客户列表 → 客户 logo 墙**(6-12 个 · 网格或横条 · 灰度统一或原色整齐)
- **融资阶段 → 融资进度阶梯**(种子 → A → B → C · 大编号 + 圆点连线 · 当前 accent)
- **3 段并列观点 → 卡阵**(内容平权 · 3-4 卡最多)
- **对照句子 → 二列对照表**(我们 vs 他们)

**reframe 时的 pitch 风原则**:
- hero 数字不吝啬:60-80pt · 加圆环底 · 主色饱和
- 4 卡上限:5 卡以上不做
- accent 仅用于"结论词 / hero 数字 / 当前进度"· 一页 2-3 处
- 客户 logo 统一处理:全灰或原色整齐 · 不能一彩一黑白
- Source 挂关键数据:TAM / 增长率 / 客户数 / ARR

### 3.3 · Decorate · 加视觉锚点(缺视觉时用)

**装饰母题库**:
1. 顶部眉标短线(主色 · 20×2 / 20×3 / 24×3 / 40×4 · y=88-94 · 配英文 eyebrow · letterSpacing 3+)
2. 双竖线 ‖ 分隔符签名("PITCH ‖ 2026 ‖ VOL.01" 折衷张力)
3. 编号方块(20×20 主色底白字 · "NO. 01" / "PART I")
4. 陶土工业标签(35×18 主色圆角 rect · 4-6px 圆角 · 内嵌数字)
5. signature 竖装饰条(3×80 主色 · 卡内侧或整页左侧)
6. 三色签名短条(primary / primary_dark / accent 各 12×2 · 页脚)
7. hero KPI 圆环底(220×220 · 主色 1-2px 边框 · 数字 60-80pt)
8. 主标副标重叠矩形(主标下半透明主色 · 40% 透明度)
9. 页脚 signature 三段(公司名 · 日期 · 页码)
10. 商务档案图腾方块(15-25px · 深色底白字 "PITCH" / "DECK")

**视觉锚点升级库**(把已有元素做大做强):
- hero KPI 提到 60-80pt · 加 220×220 圆环底 · pitch 最强锚点
- 客户 logo 单行连排(6-12 个 · 每个 100×60 · 灰度统一 · 整齐间距)
- 融资进度阶梯(种子 → A → B → C · 大编号方块 + 圆点连线 · 当前 accent)
- Why Now / Why Us / Why This 三段大 header 分屏(header 32-40pt)
- 主标副标重叠色块(主标下半透明主色 · 40% 透明度)

**布局重构库**(修视觉塌陷 · 每次 refine 最多挑 1 个):
- 左右分栏(左 40% 主视觉/产品图 · 右 60% 3-4 个 KPI)
- 上 hero 数字带 + 下 3 支撑卡(pitch 最常用)
- 全 width hero 数字 + 底部 signature 三段
- 客户 logo 墙满屏(hero 页 · 6-12 logo 网格 + 顶部 tagline)
- 竞品矩阵 2×2 居中(四角四家 · 中心留白放主标)

## 四、使用规则

**判断这页缺什么的信号(每类独立触发 · 不排序)**:
- `total_text_chars < 60` 或整页几句话就完 → 3.1 enrich 补内容
- 文字够但堆砌成段 / 数字散在正文 / 竞品写成段落 → 3.2 reframe 换表达
- `visual_elements ≤ 12` 或截图看装饰缺、hero 数字未做大 → 3.3 decorate 加视觉锚
- **一页可能同时缺 2 类 / 3 类**,多类一起做

**气质一致性**(每次 refine 后过):
- 加的元素专业吗?(不用萌图 / 手绘 / 氛围情绪图)
- 有 pitch 冲击力吗?(hero 数字 60-80pt / logo 墙密集 / accent 明显)
- Source 挂上了吗?(TAM / 增长率 / ARR 等承诺数据)
- 客户 logo 统一处理了吗?(灰度或原色整齐)
- palette 沉稳 + 亮色点睛吗?(主色饱和 · accent 一页 2-3 处)

**不要做的事**:
- 不要动 brand_assets(背景 / 页眉 / 页脚 / 装饰线 · 一律保留 · 只加不删)
- 不要用氛围情绪图代替真实数据(pitch 不是品牌故事)
- 不要用手绘插画(不专业 · 投资人不买账)
- 不要在一页塞太多 KPI(hero 3 联最多 · 再多变审计报告)
- 不要用学术风 hairline 主导(pitch 要更强节奏 · 主色饱和 + hero 数字大)
- 不要编造数据:enrich 搜索必须真实来源 · 关键数据带 Source
- 不要跳过 enrich 只做 decorate 装饰凑数(内容不足加装饰更难读)
- 不要让客户 logo 一彩一黑白(必须 image_edit 统一处理)
