# 字体

字体通过 `fontFamily` 写入 Slides XML。选择或修改字体、用户用风格描述要求换字体，或排查字体回退时，使用本文件。

### 拉丁

| 字体名称 | 字体类型 | 风格与特点 | 适用场景 |
|---|---|---|---|
| `Inter` | 无衬线 | 屏幕优先，小字号清晰 | 通用、数据密集页 |
| `IBM Plex Sans` | 无衬线 | 理性，兼具工程感和人文感 | 技术、工程、研究 |
| `Nunito` | 圆角无衬线 | 亲和、柔和 | 教育、科普、消费 |
| `Montserrat` | 几何无衬线 | 大写醒目，招牌感强 | 提案、营销、封面 |
| `Josefin Sans` | 几何无衬线 | 复古装饰感，字面偏小 | 创意、文化 |
| `Bebas Neue` | 窄体全大写 | 冲击力强，只适合短文本 | 海报、封面、巨字 |
| `Anton` | 超粗窄体 | 视觉重量大 | 口号、关键数据、巨字页 |
| `Barlow Condensed` | 窄体无衬线 | 微方、紧凑，数据感强 | 技术、工业、指标 |
| `EB Garamond` | 古典衬线 | 人文、典雅，长文舒适 | 学术、人文、文化 |
| `Lora` | 衬线 | 曲线柔和，书卷气明显 | 研究、品牌叙事 |
| `Merriweather` | 衬线 | 字形结实，小字号易读 | 报告、教育、正文 |
| `Playfair Display` | 高对比衬线 | 杂志感强，适合大字号 | 品牌、时尚、封面 |
| `Roboto Mono` | 等宽 | 字符对齐清楚，技术感强 | 代码、指标、表格 |
| `ZCOOL Addict Italic` | 倾斜展示字体 | 动感、装饰性强，适合短文本 | 创意、潮流、品牌标题 |

### 常用搭配

| 目标风格 | 标题候选 | 正文候选 |
|---|---|---|
| 专业、汇报、数据 | `思源黑体` | `思源黑体` |
| 学术、正式、人文 | `思源宋体`、`寒蝉锦书宋` | `思源宋体`、`思源黑体` |
| 国风、历史、传统文化 | `钟齐志莽行书`、`马善政毛笔楷体`、`有字库龙藏体` | `思源宋体` |
| 儿童、亲和、生活方式 | `寒蝉团圆体 圆体`、`霞鹜 975 圆体` | `思源黑体` |
| 科技、工程、数字化 | `Inter`、`Barlow Condensed` | `思源黑体`、`Inter` |
| 文化、艺术、品牌 | `寒蝉锦书宋`、`Playfair Display` | `思源宋体`、`Inter` |

## XML 示例

从本文清单中选择字体时，必须使用其中的准确写法：

```xml
<shape type="text" topLeftX="80" topLeftY="100" width="800" height="96">
  <content textType="title" fontSize="64" fontFamily="钟齐志莽行书" color="rgba(45, 43, 40, 1)" wrap="false">
    <p>北京四合院</p>
  </content>
</shape>
```
