# 写入结果与按需读取

页面写入默认传 `--no-lint`；不主动运行本地或独立服务端 lint，不建立 lint 基线，不逐条阅读、比较或清零报告，也不要求 lint 验证记录。

## 写入结果

- `ok: true` 且返回预期页面 ID：记录 ID、版本和页序，继续流程。附带 `issues` / `slide_issues` 不触发额外 lint 工作。
- `ok: false`：不能标记已写入。`4000153` 表示服务端仍拒绝本次提交，`--no-lint` 并不保证服务端跳过全部检查；保留失败，不自动重试或进入 lint 修复循环。
- 返回不完整或状态不明：先只读确认实际状态，避免重复创建。参数、权限和网络等失败按 [error-handling.md](error-handling.md) 处理。

## 按需读取

1. 用 `+xml-get --output <CWD 内相对路径>` 获取待编辑原稿、定位编辑对象或恢复不明确的写入状态。纯 XML 与响应中的 ID、版本分开保存。
2. `xml_inspect.py` 的 summary 用于页序和内容导航，content 读取完整文字与数据，raw 提取可编辑 XML。使用 XML 解析器并读取实际命名空间。
3. 编辑任务保留原稿 XML 和内容快照，后续读取另存。后续编辑依赖最新页序时，按需刷新页清单；明确的单页操作可只读目标页。
4. 回读响应可能附带 lint 报告；不为它运行 `lint_inspect.py`、追加请求或修复循环。
