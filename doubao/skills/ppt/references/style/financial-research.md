# 高密度专业金融 PPT（阅读型）

**适用**：供会前预读、邮件传阅、投委会细读或报告留档的行业研究、公司深度、投资分析和经营诊断。页面脱离讲解仍能回答：结论是什么、证据在哪、如何解释、在什么条件下成立。

**气质**：白底、克制、精确、可核验。用可比较的证据表达结构、趋势、差距和贡献，用图形呈现对象之间的关系。密度来自相关信息的联读；不仿冒咨询机构署名，不把水印、转载标题或截图外框当成设计。创建、模板、素材、写入与交付沿用主 SKILL；本文件只约定研究与表达，不增加默认检查、预览或导出流程。

## 通用表达补充

- **成稿直接说结论**：标题写有证据的判断；证据不足时用准确的业务或指标名称。图表名称明确对象、指标、期间与口径，不加“图1／表1／Figure 1／Table 1”等编号。研究问题、证据、机制、承接关系等只用于内部组织，不做栏目或小标签；删除“本页说明”“关键洞察”“怎么读这张调节表”等元话术，必要条件直接写成分析。主标题下不另放重复数值的摘要小字。
- **图上突出重点**：局部高亮、关键值加粗或差值括号指向标题依赖的比较；短注只补具体原因、差异或条件，已有标题和图形说清时省去。其余信息保留可读的辅助层级，不重复抄数，不让所有元素同时抢眼。
- **字体与字号**：中文及中文标点用华文楷体，英文、数字及相随符号用 Georgia；混排分段设置，继承同级字号与字重。以 960×540 最终有效 px 为准：主标题 24/26/28，正文、模块标题、表格、图例和轴刻度 14，主要结论 16，脚注／来源／页码 12；均用偶数整数。XML 与图表显式设字体、关闭自动缩字，正文左对齐并顶对齐；图内文字也不能随缩放低于对应字号。用户明确指定字体或要求保真编辑时从其要求。
- **语言与间隔**：中文默认简体，用户要求或资料语境为繁体时除外。中文用全角标点，英文、数字、代码、URL 与技术标识用半角；序号与文字、小标题与正文保留清楚间隔。
- **分区与关联**：先确定对象、主次与关系，再用位置、共享行列、分支、包含或连接表达。形状只包围实体、步骤或真实集合，不逐句套框；禁止装饰性竖条及编号后的“｜”，也不批量改成粗横条。数据柱、坐标轴、表格分隔和有语义的连接线保留。具体构图见第一节，图表与解释的对齐见第三节。
- **图表与数表**：数值几何复用原 Exhibit，关系图用 Drawing 或原生 shape/line，输出可编辑元素，调用见第四节。数表用细线与文本组织行列；编辑已有原生表格时可保留。默认不用原生 chart 自动样式，不把 Markdown 表格直接写进幻灯片文案或 XML。
- **公司与竞品识别**：矩阵、坐标图、生态与比较表中的公司、产品和平台优先用可靠官方 Logo／产品图标，保持原比例与同等视觉尺寸；有歧义时加短名称，找不到可靠标志时用名称。抽象类别按需用语义图标，不伪造标志。图标承担身份识别，数值、单位与判断仍用文字；素材按主 SKILL 处理。
- **来源与口径**：页脚一行简短真实来源，详细出处、链接和计算口径集中末页，见第二节。读数所需的单位、期间、实际／预测身份及结论成立条件仍随证据保留，不移成小字或侧栏说明框。

## 一、质量标尺与整页构图

### 一页围绕一个判断，多份证据各有职责

| 内部职责 | 要解决的问题 | 内容如何承载 |
|---|---|---|
| 主命题 | 读者应接受什么判断？ | 1–2 行标题，包含对象与有意义的变化、差距、贡献或条件；框架页可用明确问题 |
| 子命题 | 各区分别支持哪一部分？ | 证据区用短判断小标题；同组比较也可共用指标名 |
| 证据 | 读者需要比较什么？ | 图、数表、同构矩阵或机制图，明确对象、期间、单位、分母与数据身份 |
| 解释 | 事实为什么支持判断？ | 具体经营机制、异常与边界贴近其对象，不另排脱离证据的清单 |
| 追溯 | 数据和算法从哪里来？ | 简短页脚与末页出处按页码或图题对应，完整基表可链接追溯 |

按一个分析问题组织内容，可同时展示规模、结构、变化贡献和质量。相邻页若只在分别讲同一对象的金额、比率与解释，优先合成一页；有新的机制或边界再展开。摘要也需要可比较的证据，不默认四张 KPI 卡。每个图区增加一个有联系的比较，不为密度重复同组数值或填充图数。

### 证据组合与起排建议

先从真实资料取齐可比期间、对象明细与必要质量指标。两期金额可计算增速、份额和增量贡献，但这些派生量不能替代经营原因的独立证据；不可加的分部口径先处理抵销或改为分部金额比较。缺数据就缩小问题、补查或并页，不编数字填满版面。

下表比例只指**标题与来源之间的证据区**，是可调整的起排建议，不是模板或必填结构。先确定证据组合与对应关系，再按对象数、文字容量和字号分配空间；同级对比可等宽，主次不同则不必均分。放不下先重排或拆页，不以缩字保住比例。无需每页套一种，也不要求一套报告集齐五种。

| 适用问题 | 排版起点 | 同一页怎样联读 |
|---|---|---|
| 业务如何创造利润 | 左约 45% 为业务×经营环节结构区，右约 55% 放收入与利润两个紧邻图区；利润率等指标按对应年份对齐 | 业务做什么、金额与利润贡献、盈利差异相互对应；业务说明进入结构格，避免一张收入图配三段泛泛解释 |
| 增长结构为何改变 | 左约 35% 多期结构柱，中约 15% 增速／贡献窄列，右约 50% 按同一行业或业务组排经营解释 | 主图、窄列与解释共用分组；总额、组合、变化速度和经营事件联读。解释补原因，不复述金额；需要归因时可用结构柱＋贡献桥 |
| 总额为何变化 | 全宽上约 55% 为可闭合贡献桥，中约 15% 为期间对齐的量／价数据行，下约 30% 为对应驱动解释 | 桥解释有符号贡献，数据行给必要基数，解释连接经营变化；口径不匹配时不能强拆量价或编造残差含义 |
| 同业／模式的经济性差异 | 对象共用行；左约 30% 放身份／业务结构，中约 30% 放同尺度效率比较，右约 40% 放成本收益桥或回报比较 | 同一对象的身份、效率、结果横向对应；例如三对象×两项指标可形成六个紧凑小图，共用列头和图例，不拆成互不对应的单公司卡片 |
| 周期或阶段机制 | 全宽上约 60% 放年度堆叠柱＋占比折线与阶段标记，下约 40% 按对应时间区间排经营解释 | 总量、结构、比率和阶段驱动上下对应；阶段宽度服从时间范围，不另开脱离时间轴的解释栏 |

### 分区让对应关系可见

研究推理是**证据 → 解释 → 判断**，成稿可由标题先给出有支持的判断。每段解释定位到同一对象、期间、指标或调节项。机构与职责是对应，时间与事件是阶段解释；有独立依据的经营传导才画因果箭头，同页出现、同色或同时变化均不能代替证据。

直接支撑标题的图文获得主要面积，明细、驱动与条件围绕它安排；主区可以是一组共用坐标的图。组内间距小于组间间距，解释靠近对应对象；只有必要时才加局部边界或引线。面积表达论证主次，数据图内的长度、面积仍按真实数值。跨区连接从明确端点出发，在留白带绕行，不穿过数值或正文。

### 通用图形表达：把对象与关系画出来

先在原有逐页内容里明确“对象有哪些、关系是什么、证据落在哪里”，再选下表的几何结构。图中放短名称和必要数据，完整解释贴对应行、节点或阶段；不能只给整段文字换外框。以下名称用于选型，不印成页面上的方法标签。

| 需要表达的关系 | 可采用的 shape 结构 | 证据与解释的落点 |
|---|---|---|
| 整体—部分、机构—职责、业务层级 | 树形分支、展开括号或适度嵌套；多重归属用矩阵 | 子项贴所属分支，职责沿同一对象行对齐；包含边界只包真实成员，分项可加时才写合计 |
| 多项输入汇聚、共同因素分叉 | 分支接共同环节，必要时用 ＋／−／×；共用因素只画一次再分叉 | 输入值与条件贴对应分支，结果贴终点；没有可加口径不画加总，没有机制证据不画因果 |
| 品牌／对象 × 可比维度 | 品牌为行、客群／价格／渠道／能力等为列的矩阵；也可按真实类别分泳道 | Logo／名称作行标，事实、指标或已证实的覆盖关系落交叉格；同列同口径、同尺度，未知写未披露，不凭空评分或填热力色阶 |
| 有数值依据的定位或方案对比 | 同口径二维坐标、区间或同轴点位；现状与目标沿用相同分类和尺度 | 轴有真实含义与单位，点贴品牌与关键证据；只在真实迁移时连接现状和目标。只有定性分类时用矩阵，不画任意精确坐标 |
| 双向协同、客户转介或经营闭环 | 主体分泳道，正向路径与回流路径分别连接明确节点；按实际分支展开 | 指标与承接条件贴对应环节，回流线从实际终点接回实际起点；单向链条不称闭环，不能用一句“反哺”代替图上的回流关系 |
| 事件顺序、发展历程或阶段 | 时间轴节点、持续区间条、阶段括号；并行事项分泳道 | 日期与事件贴对应位置，趋势图与下方解释共用时间轴；表达时长时按时间比例，仅表示先后时注明顺序示意，时间先后不自动证明因果 |
| 多主体的渠道、服务或产业链网络 | 主体节点＋连接线＋必要集合边界；有已证实方向时加箭头 | 节点放身份和规模，边写真实交换或承接内容；不同关系可分线型，没有流量数据就用等线宽，不伪装成有数量的桑基图 |
| 条件分叉与方案后果 | 条件节点分叉到对应动作或结果，方案按共同维度并列 | 条件写在分支，资源代价与结果相邻；预测由明确假设计算，目标与实际分清，不把普通分类画成决策分叉 |
| 多组证据对应判断或观察变量 | 共用行的“具体证据—业务解释—判断／观察项”，必要时用归组括号或短引线 | 每行的证据支持同一判断，观察变量接回该判断；不把左侧结论和右侧另一套清单平排后强行连线 |

节点尺寸可按文字容纳，同级对象保持一致；只有有数量依据时才用节点面积、带宽或位置编码大小。漏斗需要真实阶段及可比人数／量。形状应让读者在读长段落前看见分组、分支、对应、循环或传导；纯精确查阅页可用表格，不为图形数量强行转图。

## 二、研究深度、整篇叙事与文字调性

### 从值得解释的问题出发

用户只给公司、期间和“财报分析”时，也应形成有业务解释的研究，不能把短 query 理解为只摘录几个总数。先从资料中找出最影响判断的变化、分歧或矛盾，例如收入与利润不同步、份额提升而回报承压、增长业务与现金来源分离。用它提出核心问题；没有明显矛盾时，围绕价值创造的主要来源展开，不硬造冲突。初步判断只是研究假设，证据不支持时调整或放弃。

**研究范围由问题决定**：以目标报告期为主，取足以判断基数、周期或拐点的可比历史；有必要且有披露时再展开季度、分部或同业。明确财年结束日，区分报告期表现与期后进展。优先深读年报/监管文件、分部附注、现金流附注、业绩演示和经营指标披露；管理层解释与外部行业数据用来补机制和背景，不将管理层说法直接当成已证实的因果。用户限制资料来源时遵守范围。

### 先锁定事实与比较口径

取数时把“数值＋指标/对象范围＋报告期＋单位/币种＋累计或单期＋报告或调整口径＋实际/预测/测算身份＋原始出处定位”放在一起，沿用现有资料笔记或数据基表，不另建登记流程。正文图表、表格、标题及解释从同一份已核验数据取值；原始值与展示值分开，派生量按未舍入数计算，再统一展示精度；换算保留公式、分母及对应输入。只有来源名称而找不到原始数据，不能据此填数。

比较前先对齐期间、分类、会计口径与单位；跨币种换算保留汇率时点，跨财年说明实际覆盖窗口。重述或分部调整采用披露的可比基期；分红回购区分归属期、宣派与支付状态。不能对齐时分开展示并收窄比较结论。多季度累计转单季需同口径累计值相减，缺前期不能直接当单季；首个财季的累计值本身即该季值。缺失不填零，预测不混入历史；缺数先补查，仍无披露就改问题或呈现已知部分，不以假设数字补真实财报。详细出处与计算收末页，读数必需的身份和实质条件随图文保留。

### 把经营事实连接到财务结果

按本次核心问题选择下列方向深入，不要求每项成页，也不把它们变成必填清单：

| 要解释的问题 | 需要向下追到什么证据 | 能得到什么判断 |
|---|---|---|
| 变化究竟由谁贡献 | 可比期间的业务、产品、地域或客户明细，金额增量、抵消项及可比口径 | 区分公司总量与贡献来源，判断增长是扩散还是集中；份额提升不等于金额增长 |
| 这些业务为什么变化 | 与收入对应的数量、变现/价格、产品组合、成本、利用率或订单指标，以及相关经营事件 | 把经营变化接到财务结果；只披露部分因素时保留残差，不能强拆完整量价桥 |
| 增长或利润的质量如何 | 分部盈利、一次性损益、税项、营运资本和现金回款；必要时联系风险与资本占用 | 区分持续经营改善、会计/基数影响与现金兑现；一张表里的增速差不能独立证明原因 |
| 为增长付出了什么，约束在哪里 | 与主命题有关的研发、获客、资本开支、产能、资金或信用风险；同期产出与投资兑现时滞 | 说明当前收益、投入代价和回收条件，不能把当期投入直接当作当期增长的原因 |
| 当前判断在什么条件下延续 | 同口径历史/同业参照、最有力的反例、已披露的约束和可观察经营指标 | 给出有条件的结论，并说明哪种变化会使判断转弱或转强；不凭空给精确阈值 |

商业模式决定驱动变量：制造业可沿销量—单位收入—单位成本—产能利用展开；平台业务可沿用户/交易—变现—履约或获客成本展开；银行可沿生息资产—收益与融资成本—信用成本—资本占用展开。这些是取证方向，按真实披露取舍；不能把不同业务硬套进同一组指标，也不能把单位收入直接称为价格。

**把结果、解释和推断分开**：金额贡献说明“变化来自哪里”，经营指标及事件支持“为什么变化”，持续性还需要需求、竞争、投入回报或风险证据。机制判断尽量让财务数据与相应经营证据相互支持；仅有同时变化时写关联或管理层解释。涉及工程或产业链时，可把真实的产品/工艺线稿与成本、性能、产能等图区对齐，让结构说明约束所在；没有数量依据时只作定性机制图，不虚构比例或流量。

缺信息时先定位会改变结论的缺口，定向补查附注、业绩材料或可靠行业来源。仍无披露就缩小判断范围，呈现已知关系和关键未知；定性机制可用线稿说明。真实财报分析不以假设数字填充缺失事实，也不为凑图种、密度或页数扩写无关市场故事。

### 让每一页推动同一个判断

研究时让事实检验假设；成稿时可把已得到支持、带成立条件的核心判断前置。先明确这份材料帮助读者解决什么问题，再决定需要哪些页面。公司概况、行业、财务、估值等资料放在最能解释当前判断的位置。正文可沿下列疑问推进，按任务合并、跳过或调整顺序；这些是内部思考方向，不是固定七页模板，也不以左列标签作为可见标题。

| 读者接下来需要解决什么 | 这一段研究应完成什么 |
|---|---|
| 判断是什么，为什么值得研究 | 提出最影响决策的变化或分歧，给出证据支持的答案及主要条件；没有分歧时不硬造市场冲突 |
| 凭什么这样判断 | 展示可比事实、变化幅度和比较基准，明确什么是已披露结果、什么是解释或推断 |
| 变化由谁贡献，怎样传导 | 用分部/量价/成本拆解定位贡献，再用经营事实连接收入、利润、现金与资本回报；区分一次性影响 |
| 改善能持续吗，与什么相比 | 用历史、同业、订单、竞争、投入约束及最有力的反例检验机制，比较业务结构与风险差异 |
| 财务或决策影响有多大 | 任务需要且输入有依据时，以假设计算情景和敏感性；经营汇报落到资源配置或观察重点 |
| 预期与估值是否已反映 | 投资研究需要时才讨论；标明价格截至日、预测版本与估值假设。没有可核验的预期基准，不写“市场低估”或“预期差” |
| 什么变化会推翻判断 | 将具体反证、监测变量和适当复核窗口接回原假设；阈值由披露、历史或模型支撑，不编精确数字 |

每页明确自己在立论、拆解、对照或限定判断中承担什么作用即可，不规定配比或轮换次数；这些角色不出现在页面上。标题连读应形成论证，正文给出支持与限制。前页提出利润改善，后页可解释驱动，再检验持续性和影响幅度；用业务内容自然承接，不印“上一页/下一页”“本页证明”。同一个收入数字换成同比、占比和卡片重复展示，不算深化。最有力的反例放在相关判断旁边，调整结论强度；财报分析不自动扩成评级或目标价。

**组织示例，仅展示推理方式，不是预设公司事实**：若资料显示“收入增长，但自由现金流下降”，先判断它主要来自再投资增加还是经营现金创造走弱。用增长贡献与分部盈利定位扩张来源，接经营量价或客户结构说明驱动，再按披露口径分开解释经营现金流、营运资本与资本开支的影响，最后回到回款、利用率或投入回报等有依据的观察变量。若下降主要来自回款延迟，就应转向回款质量，而不能继续讲预设的“主动投入换增长”。没有完整现金调节数据时，用已披露项目及不能解释的差额限定结论。

图表组合服从这条论证：趋势定位变化，结构与贡献定位来源，经营机制图连接财务结果，现金/回报对照呈现代价。相邻图区各回答一个有联系的子问题，标注指出决定判断的差异；不强制每页使用不同图种，也不把丰富度等同于更多图表。

### 先写完整论证，再选择承载方式

在原有逐页内容中先写清判断、对应事实、解释及影响判断的条件，用可以直接上屏的完整句子表达；需要表格时确定实际表头与行值，需要图表时确定对象、系列、期间、单位及数据。不要只写“成本优化、结构升级、现金改善”等标签，也不要先画框再让文字凑框。已在图中清楚呈现的数值不必逐个复述，正文写它们如何支持判断。

完整性以本次研究问题和用户材料范围为准：保留实质判断、关键数据、因果依据及重要反例；用户要求概括或限制页数时可压缩重复与次要细节。不能为少页、留白或套版静默删掉成立条件，也不能把关键解释只放演讲备注，让阅读稿失去独立可读性。先调整图文分区、合并共用标签或换承载方式，独立命题放不下再拆页；不把完整内容误解为逐段照搬原文或必须填满画布。

### 文字直接说判断与依据

- 连读标题应成为有递进的短论证：现象 → 来源 → 机制 → 判断边界。正文不能只是把标题扩写三遍。
- 标题写“对象 + 变化/关系 + 关键解释或条件”，不要求数字开头。少用“赋能、布局、持续向好、确定性强”等无指标判断；超出证据的因果改为“与……同时发生”“可能与……有关”，并说明推断依据。
- 正文解释机制、异常与条件，通常一段 1–3 句，同层级语法一致；加粗关键词与关键数字，不整段加粗。删去“从图中可以看出”等空转引导。标题、图表和解释沿用相同业务名称；简称与财报分类不同时首次说明对应关系。
- “主要、最快、持续、高于”等判断写明期间、对象与比较集合，保留影响结论的反例。“增速最快”比较增速，“贡献最大”比较有符号金额增量；贡献率以总体增量为分母，增长拉动以基期总额为分母，分别标明。翻倍指本期达到基期两倍，加速指同口径增速上升；规模增长不直接证明业务量、利润率或现金转化改善，反向贡献不能写成下滑原因。
- 来源不同的估计保留简短对象标签，具体出处在末页对应列明，不取平均后冒充共识。未披露、推算、预测、示意分别用短标签标明，解释收末页；没有依据不凑目标价、评级、行业门槛或预测值。总资本开支不能直接改称 AI 资本开支；利润率提升需区分分部内部改善与业务组合变化，不能仅凭盈利增速较高就认定后者。
- 标题中的每个实质判断都有页内证据：“向高毛利业务倾斜”需要可比业务毛利率及结构变化，只有收入与增量不能证明“高毛利”；“收入与利润双位数增长”要求两者都成立。缺少对应证据就补资料或删去该判断，不靠形容词提高结论强度。

**写法对照（仅为表达示例，数字为演示假设）**：

| 弱写法 | 更好的写法 | 变化 |
|---|---|---|
| 业务发展情况 | 收入增长主要来自客户扩张，客均收入仍承压 | 给出待验证的量价关系 |
| A 公司持续领先 | A 的利润率高于同组中位数，但现金转化率落后 | 同时呈现优势、边界与比较基准 |
| 费用管控成效显著 | 费用率下降 2 个百分点，主要来自收入增长摊薄 | 不把费用率下降直接写成绝对费用削减 |
| 市场前景广阔 | 基准情景依赖渗透率提升；若获客成本回升则回收期延长 | 明确条件与可证伪变量 |

净差小不代表调节项小，利润或现金总额增长也不直接证明转化质量改善。调节表应让读者看清起点、带正负号的调整项与终点，按披露口径使“起点＋各项调整＝终点”闭合；未披露完整调节项时只比较已知口径，不编差额桥。正文解释对应到具体调节行，说明哪些项造成主要差异、其性质及必要限制；不能把非 IFRS 自动等同于现金利润或纯经营利润。标题有证据时写实际判断，无足够证据时用“IFRS 与非 IFRS 归母利润调节”等准确业务图题，不强凑结论，更不用“怎么读这张调节表”。

### 简短页脚，详细来源与口径集中末页

- 每页左下角仅放一行真实简短来源，例如“来源：公司财报、文献整理”，与右侧页码使用同一基线；字号按通用表达补充，不列长 URL、完整报告标题、披露日期或口径解释。
- 最后一页统一为“来源与口径说明”：按正文页码或图题对应原始报告、文献与短超链接，合并重复出处，集中说明披露范围、会计口径、计算方法和可比性限制；完整基表或长方法用链接承接，不把小字塞回正文。
- 正文不设“口径说明”“证据与口径边界”或来源说明框，也不把这些说明改名后移回侧栏。图表仅保留读数必需的单位、期间、指标身份（如 GAAP / 非 IFRS）和估计标识；经营证据、实质风险与结论成立的条件仍作为分析呈现。腾出的区域用于相关图表与论据，不保留空框或重复数字摘要。

### 正式封面：咨询报告的编辑质感

新建成套报告用独立正式封面：研究题目、一行副标题／期间、日期与官方标识形成清楚层级，主视觉按主 SKILL 选真实素材或品牌视觉，实质结论与财务证据放摘要或正文。目录只在有导航价值时保留。用户只要若干内容页或编辑片段时尊重原范围。

## 三、图表、数表与解释共用坐标

- **同对象共用行，同期间共用列**：规模、贡献、效率与解释比较同一组业务时，保持相同顺序与颜色，只留一组行标签；时序图从左到右。图下数值要对齐真实的类别／年份中心，不能只保证顺序相同；指标名另留空间，避免挤偏数据列。无坐标轴的摘要表也应有明确期间列头。
- **图与表提供互补信息**：趋势、结构、差距与贡献优先用图；调节项、假设和多维精确查询可用表作主体。图已完整标值时，伴随表只补新指标、假设或核对关系，完整查值表可移附录。图不增加比较价值时不必强加。
- **数字行形成可读表格**：两行以上指标或需要横纵交叉读取时，用细线与文本明确行名、列头、单位、分组和合计。文字左对齐，数字右对齐，同列小数位统一；相关行与主图共用年份或分类。局部细线和关键格高亮足够，不用粗重满格边框。
- **解释写出证据增量**：保留具体产品、客户、订单、成本或经营事件，以及必要限制；同一数值不在图、表和段落反复出现。解释可按内容占 3–6 行，不受图上短注的两行限制。单个少类别图按实际标签收紧，把空间让给相关证据与可读文字。

## 四、用图表库自由组合：先查能力，再按论证选图

### 1. 用 help 了解图表、组合与图上标注

使用随包的 Exhibit 图表库。先完整查看 `exhibit_help()` 的图表与组合路由，再看 `exhibit_help('api')` 的图区函数、表列与标注能力；不要只记住最熟悉的条形图。选择之后按需查 `exhibit_help('方案名')` 取得数据条件、独立图区代码和标注参数，或查 `exhibit_help('函数名')` 取得真实签名。方案名不一定对应同名 Python 函数。

- 独立图形生成与保存：`exhibit_help('standalone')`。
- SVG 转可编辑元素、多个图区与 XML 合页：`exhibit_help('atomize')`。
- 图上比较与解释：从所选方案的“标注参数”读取；需要更多能力时查 `callout`、`band`、`span_bracket`、`relate` 等具体函数的 help。没有名为 `annotations` 的通用帮助入口。
- 柱状与折线叠加：查 `columns`、`Axes`、`polyline`；`shared_time` 是上下两图区，不能当作同一图区的柱线组合。`pareto` 是金额柱＋累计占比线，仅用于集中度。库内 `NativeChart(kind='combo')` 走原生图表，不作为本风格默认入口。

图表、组合与标注是可自由选用的能力，不是整页模板。模型自行确定每个图区的位置、比例及关联元素；不套固定成页脚本，不限制为左图右栏或固定数量的图。数据图由 Exhibit 输出可编辑形状、线条和文字；工程结构与流程可用 Drawing，标题、表格、图片和解释用原页面 XML，最后按主 SKILL 合页发布。默认不用原生图表自动样式，不把整页贴成图片。

**接入主流程**：本路由用原 `scripts.svg_lib.exhibit` 作图，不改走 `chart_slide`；help 只取图区能力，不引入整页 frame 或旧发布流程。以实际图框设置 `w/h`，用 `ex.to_slide(x=…, y=…, check=False)` 转换，再交公共 `scripts.svg_lib.atomize_svg_to_slide.publish_slide` 合页写入。help 中的保存、预览和检查示例不成为额外默认步骤。

### 2. 按数据关系选图

| 想表达的判断 | 优先查询的方案 / 能力 | 数据条件与组合方向 |
|---|---|---|
| 收入、利润或经营指标如何演进 | `trend_lines`、`forecast_columns`；关联指标用柱线组合 | 年份/季度/日期从左到右，财务数表以期间为列；非连续季度不能当连续环比。单一指标用柱或线，金额与比率需要联读时优先叠加，拥挤时再用 `shared_time` 对齐小图 |
| 规模与效率/增长是否同步变化 | `columns`＋`Axes`＋`polyline` | 收入柱＋利润率线、销量柱＋均价线、资本开支柱＋资本开支/收入线：同一对象、期间及范围，一套横轴；同单位同尺度可共用纵轴，不同单位分别标明左右轴 |
| 增长由哪些业务或因素贡献 | `bridge`、`variance_bridge`、`waterfall` | 起点＋有符号贡献＝终点；抵销与未分配项保留。与份额图、增速列或业务解释组合，不能只画本期规模就称贡献 |
| 总额和内部结构如何共同变化 | `stacked_columns`、`area_stack`、`marimekko` | 成分互斥可加；份额图保留总额，变宽图明确宽度/高度/面积的含义。可并列金额贡献，不能由份额增长直接推断金额增长 |
| 规模优势是否转化为盈利优势 | `profit_pool`、`bubble_map`、`row_table` | 收入、利润率及规模同口径；气泡面积与利润池面积含义明确。可与价值链线稿、利润率行和公司 logo 联读 |
| 同期竞品谁领先、差多少 | `rank_table`、`row_table` 的 Bar/Text 列、无连线点图 | 具名对象、统一期间与指标；差距单列，份额差用百分点。静态竞品之间不画移动连线；可加 logo 和同尺度质量指标 |
| 同一对象两期规模与增减 | `columns` 的分组柱、`plain_bars`，或规模条形＋增量条形 | 标清基期、本期与差值；规模图共用零基线，增量图正负分向并单独标尺度。时间从左到右；业务为行时两期并列成列 |
| 同一对象排名改变 | `slope`、`bump` | 仅在位次变化本身是论点时连接同一对象的各期排名；不把不同公司的静态排名画成迁移 |
| 多对象的模式或经济性差异 | `small_multiples`、`shared_rows`、`row_table` | 统一对象顺序，按列比较同指标；共享尺度的小图与精确数值、机制解释可混排。`shared_rows` 是方案入口，函数调用以其 help 为准 |
| 汇总中的某项需要展开解释 | `expand_row`、`expand_bar`、`expand_segment` | 从真实行、柱或堆叠段展开到相应细分；用 `expand`/`relate` 表示实际分解关系，不用装饰连线 |
| 集中度、客户或市场结构 | `pareto`、`share_bars`、`treemap` | Top N 来自完整排序，明确总体与累计分母；少类别单期结构才用饼/环。可接客户清单、logo、地域或业务明细 |
| 估值区间、预测与敏感性 | `dot_range`、`fan`、`sensitivity`、Range 列 | 写清区间、样本与截至日，区分实际/预测；情景结果由假设计算，与假设表及证伪条件相连 |
| 转化、资金或产品如何流动 | `funnel`、`flows` | 同总体窗口、同单位，流向守恒；只有步骤或合作关系时用流程/关系线稿，不用流宽伪装数量 |

**不使用两点连线的哑铃图**：包括 `dumbbell_table`、`Dumbbell` 列及手画同类图。两期点位接近时，圆点和数值拥挤，细微变化难辨；改用并列柱/条形，或同序的“本期规模＋有符号增量”组合。数值放在清楚的标签位或对齐数据列，增量用独立尺度表达，不夸大规模图的差距。库 help 提到该图型时，也按此选型要求换图，不改动库依赖。

**柱线组合不要默认拆开**：需要一起读的规模与比率共享一个绘图区，柱从零起，折线点落在同一期间的柱组中心。用 `columns` 返回的 `ax` 与 `bands` 确定实际图区和横坐标；同单位复用该轴，不同单位用同位置、同宽高的 `Axes` 映射折线值，再以 `polyline` 绘线，右侧刻度与单位显式写出。等间距的 n 个期间可设折线轴 `xmin=-0.5, xmax=n-0.5`，传入 `range(n)`，经 `ax.sx` 映射到柱组中心；不能直接把像素中心当数据值传入。只画一套时间标签和主要网格；左右轴标题、线/柱标识清楚，按真实范围定刻度，不调轴制造重合、交叉或相关性。两期也只画两期，不插值补点；没有连续含义的类别不连趋势线。系列过多、遮挡或不同观察窗口才拆为对齐小图，不为增加图数把关联指标分开。

突出比较时对应准确指标：毛利额贡献指向金额列，毛利率改善指向比率或变化列，不能随意圈最长柱代替论据。高亮与短注的通用取舍见开头。

比较跨期增长可用 `cagr`/`yoy`，差距用 `diff`/`delta`，目标用 `target`/参考线，份额或分组用括号，阶段用 `band`，异常点用 `callout`，机制说明用引线或局部短注。按真实比较选择，不要求每图凑标注数量；短注最多两行，不遮挡数值、坐标或相邻图形，不用复杂箭头装饰整页。CAGR 只用于真实年距与可比正基期；比例变化用百分点。具体参数与锚点按 help 返回的定义设置。

### 3. 图表与工程线稿、表格及其他证据怎样组合

| 分析任务 | 可以组合的元素 | 如何让元素相互解释 |
|---|---|---|
| 产品/系统结构如何影响价值量、成本或性能 | 工程线稿或结构剖面＋成本/价值量堆叠、性能对比图＋部件明细 | 线稿解释“是什么、作用在哪里”，图表证明“影响多大”；部件、路径与数据用相同名称/编号/颜色对应，关键参数有来源 |
| 工艺与产能约束如何传导至盈利 | 工艺线稿/流程＋产能、利用率、良率或单位成本图＋同阶段数据行 | 按真实工序对应，瓶颈与财务证据相邻；不把流程位置画成数量，也不由产能推造销量或收入 |
| 产业链中价值与利润由谁获取 | 价值链线稿＋公司 logo＋利润池/份额图＋同环节比较表 | 同一环节共享行列，结构图交代关系、数据图交代规模与回报；没有数量的关系箭头不带流量宽度 |
| 产品组合如何改变公司增长结构 | 产品图/架构线稿＋多期份额＋金额贡献桥＋业务明细 | 同业务跨图同色、同序，说明新增、替代与抵消；真实图片负责识别，贡献由数据计算 |
| 财务表现背后的经营机制 | 金额柱＋利润率折线，或利润桥＋局部机制线稿/短段 | 用期间、对象或调节项把结果与解释连接；新增精确指标可用数据行，没有机制资料时不为拼图补故事 |
| 同业差异为何值得关注 | logo＋并列图/区间/细线表＋业务模式线稿或行末解释 | 每行是同一公司，各列提供规模、增长、质量或机制证据；重点格支持标题，静态对比不画移动连线 |

按本页问题选择相关元素，不要求每页同时出现线稿、图表和表格。技术、产品或工艺机制决定财务判断时，工程线稿可以成为核心证据区；一般财务页无需装饰性技术插画。已知结构用可编辑线条绘制，复杂实物可用高质量无文字线稿图并配原生标签；示意线稿注明“示意，非精确比例”，不得冒充官方工程图。方向、部件与参数以公开资料或用户资料为依据。

### 比较与编码的边界

- 观测有多少就画多少，缺失不填零；数据不足时收窄结论，不为复杂图编造分解项。
- 金额、份额与体量比较用线性尺度，柱从零起，瀑布起止总额以零为基线。`row_table` 的 `Bar` 默认可能压缩极大值；比较非负金额时显式传 `domain=(0, 上限)`，上限覆盖全部值，保留真实长度比例。小业务用精确数值列或同尺度局部比较补充，不靠默认断轴或对数条形放大；对数轴只服务明确的倍数/跨数量级命题，并显式标注。
- 同单位不等于同身份：存量、流量、收入、利润、承诺及目标分别标清。负贡献须在几何方向上成立；不同量纲不混用同一数轴，断轴、预测、排除项须可见。
- 图例的名称、颜色、线型与实际系列一致。气泡大小图例使用 `size_legend(..., to_r=ex.bubble_to_r)`，与主图共用数值到半径的映射；面积表达数值，半径按平方根变化，不能用相同大小的圆代表不同金额。解释图例含义的单位文字可用灰色，图题仍保持小标题层级。

## 五、版面与文字落地

### 随内容安排栅格与留白

- 默认 16:9、960×540。左右边距约 24–30px，图区间距约 14–20px，组内标签与数据约 4–8px，小标题后约 6–10px；均为起排参考。标题、正文与来源按实际高度安排，不再叠加固定证据区占比或统一 50/50 分栏。
- 主标题、模块标题与主要结论加粗深色并左对齐；并列模块标题首行基线对齐，一侧换行时按较高标题区统一正文起点。图例、单位与来源保持辅助层级，不随标题一起放大加粗。
- 正文靠近所属对象并顶对齐，行距通常为字号的 1.25–1.4 倍，容器随实际行数给高度。图形共用标签、单位和图例；标题条、Logo 与识别元素不挤占证据。主要结论靠近支持它的图文，不在底部再复述标题。
- 表格先为最长完整数字留列宽，再分行名与解释；符号、小数、百分号不拆行，行名换行时同时增高该行。标题或表格换行后重排下方内容，不能与解释、来源重叠。跨页对比保持相同对象的位置与顺序。

### 字体规则如何落实到元素

按开头“字体与字号”统一设置所有 XML、图表和表格。`<content>` 默认中文字体，英文数字用 `<span fontFamily="Georgia">` 分段并继承字号、字重，纯数字框直接设英文字体；正文用 `autoFit="no-auto-fit" textAlign="left" verticalAlign="top"`。使用平台字体名称，不把本地字体文件名当作 `fontFamily`。

Exhibit／Drawing 显式设置 `font` 与文字尺寸，中文节点和混排子段同步使用对应字体。按最终图框作图，计入画布、viewBox、transform 和落页缩放；1920×1080 上的 28px 正文等效于本风格 14px，px 与 pt 不混用。空间不足先调布局、去重复或拆页，不缩小实质正文，也不单纯放大文字遮挡数据。封面与强调数字可用更大的偶数字号；无法使用指定字体时说明限制，不自行换成无衬线。

### 配色与线条

- 公司研究按官方品牌色确定主色、Logo 和关键强调；多公司比较用中性底色、稳定的对象识别色。无可用品牌规范时可用深绿 `#1F4D3A`／赭金 `#B08035` 或海军蓝 `#17324D`／酒红 `#8B2842`。默认白底、深灰正文、浅灰辅助线，保持足够对比度。
- 颜色稳定绑定对象或状态；历史／基期可用灰色，本期用品牌色，实际／预测也可用线型或填充区分。类别较多时扩展低饱和色，图例的名称、颜色与实际系列一致；同色深浅须足以区分。
- 无数值含义的背景轨道删除，`Bar` 列用 `track=False`；目标、总量或余量轨道有明确含义时才保留。线条只承担基准、分组、连接、区间和分隔；粗箭头、圈注与边框不能遮挡数据，不复制组件附带的装饰。

## 六、沿主流程组织页面

在主 SKILL Step 4 原有逐页内容中写清判断、完整论据、已核验数据与条件，再选第一节的证据组合／关系结构，安排分区和对应位置，随后按第三至五节落成元素。记录实际需要的对象、数据与连接即可，不新增规划文件、版式配额或检查流程；默认制作与交付遵从主 SKILL，用户明确要求评审时再检查成稿。
