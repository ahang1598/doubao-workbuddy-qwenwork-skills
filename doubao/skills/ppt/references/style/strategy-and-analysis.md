# 分析与决策

**路由条件**：行业研究报告、咨询报告、战略分析、决策支持文档、竞品分析、市场分析、投资与财务分析；数据密集型内容；除非明确说明用于登台演讲，一律按阅读型演示文稿处理。

**用户上传 ppt 附件原则**：附件模板中没有可直接复用的页面时，按当前设计系统的指导自行搭建，并参考 `workflow/template-editing.md` 工作流。

## 内容密度原则

1. 除非明确用于演讲，一律按阅读型演示文稿设计——整份围绕阅读体验组织，对标顶级研究报告与头部咨询公司的成品质量。
2. 每一页要有真正的信息深度：核心结论一眼可见，通读全页需要约 5 分钟。
3. 论证从结论向证据逐层展开：标题给出判断，页面承载数个能独立成立的支撑性小判断，每个小判断都配一句可核验的证据。
4. 正文页标题优先写成陈述句（如"核心市场份额三年内从 34% 降至 19%——渠道老化与定价失位是主因，非需求萎缩"），但也要结合内容性质酌情决定。

## 数据与图表原则

1. 数据是论证的骨架：围绕主题充分检索真实数据，用合适的图表把它们呈现清楚；每一项数据必须注明来源，绝不杜撰。
2. 图表要素齐全（坐标轴、单位、图例、来源、计量口径），做到脱离正文也能独立看懂。
3. 图上必须标出关键拐点与关键值并解释其含义；每张图表旁配文字说明其证明的判断、图中可见的发现、对决策的启示、以及数据来源与边界。
4. 内容间存在结构关系（顺序、对比、循环、因果）时，优先用结构图可视化，而非文字描述。
5. 鼓励绘制并组合图形做出复杂图表和 SmartArt，避免纯文字堆砌以强化视觉表达；注意线条止于节点边缘，禁止文字穿线。
6. 同一份演示文稿内所有图表使用同一色系的深浅梯度，不引入第二色族；饼图等多类别图表在同色系内保证图例明显可辨、避免颜色过近；严禁使用软件默认的坐标轴、网格线、图例框、彩虹配色、粗黑表格边框、3D 柱形、渐变填充和投影，一律重做。

## 配色

**第一原则——品牌主色优先**：用户明确给出 VI 主色时直接采用；提到品牌名或提供 logo 时，必须先搜索并查看 logo，从中提取主色作为全篇主题色，首页可插入品牌 logo，围绕主色的透明度梯度构建整套配色。

**无品牌指定时自主取色**：结合内容气质，要使用"高端、极致专业、克制"的配色，如果涉及党政和宏大叙事可以使用勃艮第红、深酒红、赭石，其他的可以自主选择一些高级的颜色，要出乎用户意料之外又情理之中。选定后**整份演示文稿只沿用一个主色**，用它承载全部结构性表达。

**梯度层级**：主色以 15% / 30% / 60% 三级透明度做出深浅阶梯，用于图表系列色阶、表头深浅、背景色块；严禁超过三级。

**中性灰**：分隔线 #D8D8D8 · 辅助文字 #767676 · 浅背景块 #F4F4F4。

**强调色**：仅用于单点高亮（最高值、关键差距、风险标注）；从主色的对比方向取一个低饱和度色，例如暖赤 #B84C3A 或琥珀 #C8861A；全篇最多出现 3 次，不用于装饰。

**背景**：正文页统一纯白 #FFFFFF；正文页禁止有色背景或渐变背景；封面若需放品牌 logo 图，一律白底。

## 视觉规格

**配色应用骨架**：主色承载结构性元素——标题强调、表头、章节导航高亮、主图表系列、编号标记；其余交给梯度灰；同一页面绝不引入第二种主色。

**标题规范**：每页主标题写成完整的判断句；标题格式（引题 → 主标题 → 副标题）全篇固定；加粗衬线体标题与无衬线体正文形成两种界限分明的角色，层级严格一致。

**页面骨架**：章节导航始终可见（当前章节高亮，章节间靠位置区分而非颜色切换）；页脚固定含"来源："行与页码；所有元素在页与页之间坐标一致，翻页不跳动。

**密度节奏**：正文页高密度铺排，以图表 / 表格 / 结构图为主体，文字服务于证据；封面页、章节页、结论页以留白作为呼吸点。

**信息分区**：结论置于顶部标题；证据置于中部图表 / 表格；解读放图旁注释或侧栏；来源与口径置于底部来源行；行动建议只出现在收尾页。各类信息各安其位，全篇保持一致。

**图表规范**：

- 所有系列颜色重新指定为主色梯度 + 灰色；去除纵向网格线，最多保留极淡的横向线。
- 数据标签只标关键点与端点；实际值与预测值用实线与虚线（或斜纹）区分。
- 每张图表正下方放置来源与计量口径说明。

**图表标注**：关键总量用大数字直接标注；拐点、差距、增长率用箭头或引线加一句注释；评级用哈维球（Harvey balls）或徽章直接落在图表区域，不写进正文段落。

**表格规范**：深色表头配白字；极细横向分隔线（禁止纵向线与粗边框）；数字右对齐，文字居中对齐；第一列主体名称加粗；大型表格旁配解读面板。

**对齐纪律**：所有元素对齐到统一的左边缘和隐形分栏线；分隔只用极细线；强调只用主色短条或粗竖条，绝不使用粗框；面板直角、无阴影；仅小型标签允许圆角。

**洁净原则**：无阴影、无渐变、无纹理、无发光、无默认色；质感完全通过留白、对齐、单一色相的色阶、线条纪律来实现。

**目录原则**：参照头部咨询报告的目录样式，既要有品质感，也要保证信息清晰。

## 禁止项

- 用圆角矩形或矩形卡片构建层级与对齐——一律用线段、留白与字号差异替代。
- 单个基础图表占据页面一半或更多宽度。
- 圆形裁剪图片；任何图片都不允许因为被裁切而信息残缺。
- 均分构图（三等分、四等分、2×2 矩阵、"三栏 + 标题 + 结论"套路）。
- 任何默认设置——配色、对齐、图表样式全部须重新指定。
- 彩虹色或多色系图表——图表系列颜色只允许主色梯度 + 灰色。
