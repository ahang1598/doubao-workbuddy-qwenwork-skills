# 教育与科普

场景路由：仅在演示的主要任务是系统教会知识、方法或技能，且有明确学习目标时使用。适用于课程、培训、实训、复习、自学及具有教学目标的科普或专题讲座，围绕学习者要理解、判断或完成的事情组织讲解与学习过程。普通生活分享、个人或产品介绍、面向公众的主题展示，不能仅因包含知识说明或“科普”等字眼就进入本档；没有明确教学任务时优先用[品牌叙事与通用展示](brand-storytelling.md)。


**合理的教学设计是教育课件的核心。** 制作和设计时要贴合具体学段和实际受众，依据学习者的年龄、已有知识、理解能力与学习目标，确定讲解深度、语言、例子、提问和视觉表达。让学习者能够理解、参与并逐步学会，是组织内容与设计页面的首要依据。

用户指定的教材、教案、讲稿、教学顺序、模板和品牌要求优先。**充分、合理地使用用户附件中的内容与素材**，结合教学目标组织讲解，保留必要的信息、例题、图片与活动。已有完整教案时，遵循其教学安排。补充或引申应紧扣原内容、符合学段与受众，并有可靠依据，不得编造。

## 核心要求

- **字号是硬性底线：所有页面文字必须不小于 18 pt。** 标题、正文、题干、选项、表格、图内标签、拼音、单位、脚注和来源均适用，以元素放入页面并完成缩放后的实际字号为准；不得因内容多、自学阅读、模板默认值或注释身份降低字号。**先定字号，再排版，禁止缩字塞内容。** 放不下就精简重复内容、扩大主材料区域或拆页；图片中需要阅读的文字也须达到同等可读尺寸，必要时放大或另排标签。学前与 K12 投屏正文通常用 22—32 pt，成人教学正文参考 20—28 pt，标题参考 32—44 pt；18 pt 是最低限度，不是推荐正文大小。
- **整课有主线，内容连贯完整**：围绕明确的学习重点组织内容，完整保留达成教学目标所需的知识、材料与关键讲解，按学习者理解所需的教学逻辑安排顺序。前后内容衔接自然，必要的前置知识、推理过程与适用条件交代清楚，避免知识点拼接、逻辑跳步或关键内容缺失，让讲解与练习共同支持预期的学习结果。
- **单页聚焦，留出思考空间**：一页聚焦一个主要学习任务，保持低密度，保留必要材料与观察、作答空间，复杂内容分段或跨页展开。提出问题时不同页内呈现答案，将解答与解析放在后续页面；只有配置了实际可用的元素动画、让答案在思考后揭示时，才允许同页承载问题与答案。
- **配图有优先级，实体与关系分开表达**：能找到与教学内容匹配、清晰准确的**权威教材配图，必须优先使用教材配图**，包括用户附件中的教材素材；其次选可靠来源的实物照片或专业图解。搜不到合适素材时，可用生图补足客观实体或情境，并核对知识细节，不冒充真实记录。**shape 仅用于表达逻辑关系，如分类、层级、流程和推理；不要用形状拼画或简陋手绘代替客观实体。** 讲对象就展示准确的对象图，讲关系再用分组、连线和箭头辅助说明。面向 K12，尤其是低龄学生，重视图文并茂；视觉风格贴合学段与课题，不能为统一手绘风而舍弃可用的权威教材配图。
- **以完整画册的标准设计整套课件，禁止卡片堆叠。** 不把每段文字、每个知识点都装进卡片，不用平铺卡片网格或多层套框代替内容组织；优先用主图、文字、对齐、留白和必要连线建立层次，让构图随教学内容变化。围绕课题本身提取有辨识度又别出心裁的色彩、形态与质感，让字体、插图、图形、线条和留白共同形成贯穿全课的视觉语言。从封面到正文、练习与结尾，都保持同样的设计完成度。每页围绕主要学习对象构图，通过大小、位置、疏密与对齐组织层次，让文字与图像相互呼应：标题的位置呼应主体，解释贴近观察细节，留白为视线和思考留出空间。艺术感落实到准确适配而精美的主图、讲究的字体搭配、克制的材质和细致的边缘、线条与间距；让每页值得停留欣赏，也让学习对象清楚可见、必要文字轻松可读。


## 一、整课设计：确定重点与顺序

从用户材料中确认受众、已有知识、课时和使用方式，确定学完后希望学习者能解释、辨别或完成什么。围绕这一结果选择重点：必要的前置知识安排在使用之前，核心难点留出充分的讲解与练习时间，拓展材料按相关性和课时取舍。页面标题要符合受众直接表达具体教学内容、问题或任务，不照搬教学设计术语。

按内容之间的依赖关系安排顺序，让后面的学习用到前面的所得。概念之间有递进关系，就逐步展开；几种方法需要比较，就围绕共同任务组织；完整操作需要协同使用多个知识点，就让实际任务串起内容。遵循材料与课型的特点，不预设固定阶段，也不强求所有课程都套成一条故事。

整课始终围绕同一个学习重点，避免材料各自精彩却彼此脱节。开头让学习者知道要学习的重点并引起兴趣，结束时通过解释、判断或实际成果看出学会了什么；前后可以对应同一案例，也可以通过新情境检查能否运用。

### 按使用方式调整

- **课堂讲授**：为观察、书写、讨论和反馈留时间。教师备注承接预期回答、追问、错因处理与操作提醒。
- **自学与复习**：提供独立理解所需的说明、可定位的解析与自查依据。复习可先尝试回忆，再按表现补讲或进入迁移。
- **实验、实训与项目**：交代目的、材料、完成标准与必要操作条件，安排实际产出、结果验证和修订机会。
- **家庭教育与学术讲座**：围绕具体情境或专业问题，讲清方法、证据和适用条件，按听众基础决定术语与推理深度。

公众科普用通俗语言解释必要原理，保留结论依据与适用条件。外部事实和数据按主流程核对来源，示意案例与真实记录明确区分。

## 二、讲解设计：补上理解中的关键一步

针对具体知识点，先判断学习者容易在哪里误解或停住，再选择材料和讲法。把原本需要学习者自行猜出的观察依据、推理步骤或选择理由讲清楚，避免只列定义、结论和操作口诀。

| 具体难点 | 讲解怎样展开 |
| --- | --- |
| 概念抽象，认不出实例 | 先通过典型例与近似例指出决定性特征，用准确且适合受众的语言解释含义；例子保留辨别所需的条件 |
| 结论知道，但不明白为何成立 | 回到原文、现象或数据，指出观察到了什么、依据什么作出推断，以及结论成立的条件；不从材料直接跳到结论 |
| 能模仿步骤，却不会独立选择做法 | 用完整示例呈现关键决策：此处为什么这样做、怎样判断结果是否正确。再让学习者补做或独立尝试，逐步撤去提示 |
| 条件稍变，就误用原方法 | 对照只改变关键条件的例子，说明变化影响了哪一步、原方法为什么适用或不再适用，再尝试修正 |

选例要能帮助看清难点。熟悉情境保留与知识有关的细节，类比说明对应关系与局限；定义、事实、模型和推测保持区别。例如解释“面积相同，周长未必相同”，可以用相同数量的方格拼成不同长方形，让学习者对照面积与边界长度，而不只呈现一句结论。

练习承接刚才的难点，给出必要材料、明确任务与完成标准；反馈解释依据和错因，提供可自行检查的方法。需要支持时提供观察提示、部分步骤或表达支架，已有基础时增加条件变化或方法比较。按需要选用，保留学习者自己完成关键思考的机会；问题与答案的展示方式统一按第三节执行。

## 三、页面设计：低密度地呈现逻辑

### 一页聚焦一个任务

每页明确让学习者看什么、想什么或做什么，把主材料做大、关键关系讲清，保留观察、作答和批注空间。封面和导航页只需交代课题与进度。

同时考虑新概念、段落、图片、图内标签、表格与推理步骤的数量。字少但关系复杂仍可能过载；将不同任务拆开，长推理逐步展开。详细讲述放在教师备注，自学必需的解释另页提供，不靠缩小文字或删除条件压缩版面。课程必须完整，不要偷懒缩减必要的页面帮助学习者理解概念间的逻辑过渡

### 用配图与图形组合表达关系

先按核心要求中的配图优先级选素材，再根据需要理解的关系组织图文。让学习者看清观察对象、比较维度及推理依据，说明该看哪里、它能支持什么判断。

| 需要表达的内容 | 合适的视觉表达 |
| --- | --- |
| 对象、细节与现象 | 实物图、作品细节、实验照片或局部放大，标注当前观察位置 |
| 相同与不同 | 对照图、同尺度排列或叠合比较，保留一致条件，突出关键变化 |
| 逻辑结构、层级与整体关系 | 用形状、分组、连线和标签表达关系；实体结构仍以准确的教材配图或专业图解为主体 |
| 过程、顺序与变化 | 流程图、时间轴或连续状态图，标清方向、阶段和变化条件 |
| 数量、规律与推理 | 数轴、图表、算式与对应图形，将数值、单位和证据关联起来 |

解释和标注靠近对应对象。形状大小、连接方向、尺度与分组反映真实关系；省略或夸张的部分作必要说明。平等比较可用等宽布局，主次不同的对象按信息作用分配空间。

**禁止用卡片堆叠或嵌套组织层级。** 不把每段文字或每个知识点都包进卡片，也不用多层套框代替信息关系。优先通过位置、对齐、留白、字号、分组、形状和必要连线表达主次与联系；卡片仅在确有独立任务、作答区或成组比较等明确用途时使用。

跨页保留对象、符号、数值和位置的对应，方便回看与比较。图中直接揭示答案的标注按“问题与答案分开呈现”一节延后呈现；改变题目条件时明确标出变化。

### 保证阅读与投影清楚

- 学前与小学低年级使用大配图对象、短指令和明确指代；中学突出材料与推理；大学、职教和成人讲解兼顾定义、条件和验证。
- 所有页型与图表执行核心要求中的 **18 pt 字号硬性下限**，导出前核对实际字号，尤其检查图内标签、拼音与缩放素材；不能混用 px 与 pt，也不能直接沿用组件默认小字。
- 使用清楚的文字对比、对齐与行距。强调色在同稿中含义一致，并配合标签、符号或线型，避免仅靠颜色传递信息。
- 正文、题目、答案与教学图示按工具能力保留可编辑性。真实作品、实验记录与档案使用可信素材；生成示意图核对知识细节，并与真实记录区分。

视觉主题延续同一套配色、字体与导航，将主要空间留给学习对象。书页和纸条可承载例题与比较，绘本情境可支持观察与计数，诗文和历史材料可结合题签与批注，专业教学可使用清晰网格组织图表。根据课题、年龄、学科和用户要求选择，装饰不挤占教学空间。

### 问题与答案分开呈现

只要页面提出问题，包括题干、提问式标题或作答任务，就与答案分开呈现。静态问题页只放问题、必要条件、材料与作答空间；答案、结论和直接揭示答案的标注放在后续解答页。解答页用题号或主题标签对应前页，可保留必要图形和数据，不重复完整问题。示范、自学和速查中的问答同样适用。

**同页呈现的唯一例外是元素动画**：答案及泄露答案的标注初始隐藏，留出思考时间后由教师或学习者触发揭示。页面切换动画、分栏、色块遮挡或“稍后看答案”的文字提示不能代替答案元素的延后显示。当 PPT 不支持元素动画、动画未验证或交付静态 PDF／图片时，将问题与答案拆成不同页面。其他音频、计时、提交与链接也只在实际可用时作为功能呈现。

## 四、学科参考：按内容选材料

以下按当前学科取用，补充前面的教学与页面原则。学科差异主要体现在观察对象、证据与推理方式。

| 学科或领域 | 重点展示 |
| --- | --- |
| 数学 | 对应实物、图形、数轴、表格与算式；标清整体、单位和条件，让学生解释图中各部分对应的量 |
| 语文 | 保留字形、完整语句、段落和语境；识字关注部件与用法，阅读通过圈词、比较和引用原文说明理解；深入浅出，学过去的课文应该要回应当前时代完成德育任务，内容有深度但又有来源 |
| 英语及其他外语 | 对应情境、语音、词句与交际任务；听辨先听后揭示文本，表达练习按需要撤去提示并换情境 |
| 物理 | 对应现象、测量、模型与关系图；区分观察与解释，标明变量、单位和条件 |
| 化学 | 联系宏观现象、粒子表示与方程式；核对粒子、化学式和方程式，示意比例不冒充真实尺度 |
| 生物 | 联系结构、功能、尺度与过程；标清方向和阶段，避免把功能解释成有意图的行动 |
| 地理 | 使用准确的地图呈现空间位置、区域特征与地理过程；可标注位置、路线、范围，或挖空地名、图例和关键标注开展识图与填图练习，保留必要的方向、比例尺与边界 |
| 历史、道德与法治 | 使用有语境的史料与事实清楚的案例；区分事实、解释与判断，检查规则适用条件 |
| 信息科技、工程与课程实训 | 对应输入、关键操作、系统状态与输出；保留界面上下文和版本信息，讲清结果验证及常见异常 |
| 艺术、音乐、体育 | 用作品细节、音频或关键动作示范，再安排完整表现与针对性重试；静态画面说明展示局限 |

专业教学保留必要术语、公式和复杂材料，首次使用时交代含义与条件。实验、工具和动作示范的必要操作条件与注意事项随任务保留。

### 备注：书写教学

田字格使用正方形，每格一个汉字，按教材范字核对部件、笔画和字形重心。注音放在对应格子上方，音节与汉字对应，声调清楚，与格线保留间距。

英语字母和汉语拼音按各自四线三格规范安排占格，核对大小写、升部、降部及声调位置。可使用准确素材、字体与可编辑格线，必要时使用生成工具；生成结果逐项核对。按任务留出临写、批注或比较空间。

## 五、视觉参考：按主题与受众选择

以下方向用于启发设计，可按学段、主题与素材调整。精致感来自优质主图、清楚的大小关系、协调的色彩和细致的对齐，不需要增加固定数量的装饰或套用统一版式。

**先定整课气质。** 选定底色、正文色、主色与强调方式，以及相容的字体和插图风格。浅色承托内容，深色保证文字清楚，强调色引导观察；有学校或品牌规范时优先沿用。

**让主材料成为视觉中心。** 情境页可用大场景配短标题，结构页用放大的主体配对齐标注，阅读页让原文与批注相邻，对照页保持同尺度，过程页沿阅读方向展开状态变化。先安排最值得看的对象，再放解释和任务。标签靠近对象、引线避开文字，同组内容靠近，组间留白；不要先画几个等大的框再填内容。

**让素材和细节经得起看。** 人物、物件与器材要有可辨认的形态，使用合适的照片、插画或准确示意图，不用通用方框代替需要观察的细节。相关插图保持相近的视角、描线和质感；纸纹、轻阴影与角色动作可以营造气氛，但正文区保持干净。图片中的关键文字尽量用页面文字排入，便于修正并保证字号。

| 可选风格 | 怎样结合课件设计 |
| --- | --- |
| MBE 卡通风 | 圆润造型配清楚的深色轮廓、明快填色与少量偏移色块。把计数、分类或观察的物件配图做大，短指令紧邻对象；同一角色或物件贯穿任务，描边与用色一致，不必每页出现 |
| 手绘课本风 | 暖白纸面、深墨文字配一种批注色，轻量使用铅笔线与纸张纹理。原文、算式或实验记录占主区，圈画和边注紧跟讲解位置；手写体用于少量批注，不把每段内容都装进便签 |
| 像素游戏风 | 用像素场景、地图和关卡标记串联探索、复习或编程任务。地图定位进程，任务页放大当前材料；像素字体用于短标识，正文和公式保持清晰字体，关卡对应真实学习进展 |
| 故事绘本风 | 环境色形成基调，连续场景与人物带出观察和问题。情境页可用大幅插画，在天空、墙面等安静区域留出旁白；讲解时切近景，比较时并置对象，不要求每页满幅背景或加气泡 |
| 剪贴风 | 干净底色配协调的剪贴纸片、轻微纸边与叠层阴影，文字放在平整区域，装饰性错位不改变几何关系 |
| 科学漫画风 | 稳定的描线与角色，分镜沿现象或推理顺序展开，关键瞬间放大，短对白提出困惑或提示观察。保留实验与动作细节，区分真实材料与示意画面，不通过对白提前泄露答案 |
| 图鉴与专业图解 | 浅底、深色文字配少量强调色，以实物图、剖面、模型、原文或操作界面为主体。整体图配局部放大，标签有序对齐，保留尺度、条件与关键细节；适合自然科普、中学及专业教学 |

整套课件保持配色、字体、角色与标注方式连贯，正文构图随情境、观察、推理、练习变化。引题可以开阔，讲解聚焦材料，练习留出作答区，反馈沿用原图增加关键解析。保持低密度和清楚的阅读顺序，不把所有科普做成低龄卡通风。问题页中的图像和对白同样遵守问答分开规则。

完成后按最终阅读尺寸看整页：主对象是否足够大，必要文字是否清楚，图文是否对应，对齐与间距是否整齐。正文也应保持与封面相当的素材质量，避免只有封面精致。
