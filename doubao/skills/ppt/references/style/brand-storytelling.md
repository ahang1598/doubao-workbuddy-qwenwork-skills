# 品牌叙事与通用展示

适用于以介绍、展示、分享、吸引兴趣或传达体验为主的演示，包括品牌故事与企业形象、产品与服务介绍、发布推广、个人介绍与作品集、人物故事、生活方式、旅行美食、兴趣文化、活动及面向消费者或公众的主题分享。**不要求有品牌、Logo 或商业目的，也作为未明确命中其他专门场景的通用展示指南。** 通过文字、图像和版式，让观众了解对象、感受特点、理解价值或作出选择。

**与教育场景区分**：普通知识介绍、经验分享和公众话题不自动归为教学；只有以系统教会知识、方法或技能为主要任务、具有明确学习目标时，才转用教育指南。工作进展与业绩汇报、金融研究与咨询报告、党政任务仍按主 SKILL 路由选择对应指南。

本指南提供设计原则与可选参考，按任务需要使用。用户给定的品牌规范、模板和参考风格优先；已有明确设计方向时，围绕该方向完成设计或局部修改。

## 内容与视觉表达

从本题的产品、人物、经历、文化和生活场景中寻找视觉依据。有品牌时结合用户素材与官方资料确认视觉特征；无品牌时围绕主题、受众和素材建立统一视觉，不虚构品牌定位、VI 或 Logo。需要补充信息时，再查阅相关可靠资料。

- **主题识别**：有品牌时延续已有视觉特征，无品牌时突出对象与主题自身的特点。识别度可以来自色彩、字体、产品形态、摄影或图形，不必依赖重复装饰。
- **叙事重点**：围绕本次演示要介绍的对象、分享的经验或传达的价值与故事组织内容，用具体产品、经历、场景和证据支撑表达。
- **受众与场合**：根据观众的阅读需求、信息熟悉程度和观看环境调整表达。投屏演讲重视远距离阅读，供人细读的提案可以承载更多说明。
- **整体一致**：配色、字体层级、图像处理和辅助标识保持连贯。页面结构随内容变化，系列产品和案例可以沿用同一版式，便于比较。

## 视觉原则

### 配色

以品牌色和内容需要建立色板，明确背景、正文、强调与数据分类的颜色用途。同一语义尽量使用同一颜色。

颜色数量、饱和度和明暗由品牌气质决定。蓝白、黑白、高饱和色、材料色或渐变都可以使用，重点是与品牌相符、层级清楚、对比足够。多色图表保留必要的分类差异，并与整稿协调。

品牌色可用于标题、背景、图形或局部强调。选择面积与位置时，注意突出重点，避免大面积强色影响阅读。

### 字体与文字

优先使用品牌指定字体，并结合可用字体与展示环境选择替代方案。可用字体见 [字体参考](../xml/fonts.md)。

- 通过字号、字重、间距和位置区分标题、正文与注释；同一字体族也可以形成清晰层级。
- 按内容长度和观看距离确定字号。信息拥挤时，可压缩重复表述、重组内容或拆页，保留必要事实与说明。
- 中文按语义断行，避免孤字和不自然的字间空隙。正文以自然阅读方向为主。
- 双语标签、衬线标题、超大字或竖排短语可用于符合品牌的场景；英文应有实际含义和使用目的。
- 图片上的文字应清楚可读，可利用画面留白、调整文字位置，或按需使用遮罩与底色。

### 图像与图形

按内容选择产品图、人物照、场景图、档案素材、插画、图表或纯文字表达。图像数量与占比由信息和构图决定。

- 真实产品、人物和历史事件使用可信素材，保留关键细节与真实含义。概念图和生成图用于氛围或构想表达，不充当真实记录。
- 摄影的光线、色温、裁切和处理方式应与品牌协调。历史档案与现代摄影可以保留差异，用于说明时间或语境变化。
- 多图页面通过大小、位置、间距或明暗组织阅读；平等比较的对象可以使用等大图片。
- 图表、图标和示意图适合解释数据、结构或流程，其形式与整稿视觉语言协调。
- 纹理、色块和装饰用于支持主题、分组或导航。纯色底、单图和纯文字页面都可以形成完整表达。

### 构图与整稿节奏

每页围绕主要信息建立阅读顺序，让标题、图像和说明形成清楚的关系。

卡片、分栏、矩阵、拼贴和大留白都可按内容采用。并列信息适合规则排列，主次信息适合差异化布局；避免把不同关系的内容套入同一种结构。

跨页节奏由叙事推进决定。章节转换、重要观点和信息密集处可以调整构图或密度，必要时使用转场页。连续页面也可以保持相同明暗与版式，以形成连贯阅读和系列感。

页码、章节标签、细线等辅助标识按导航需要设置，保持位置与样式稳定。Logo 的使用遵循品牌规范、用户要求及主流程约定，保持原始比例。

## 可选视觉参考

以下方向用于寻找视觉语言，可选用、组合或自行设计。它们不限定行业和受众，也没有默认选项。组合时保持色彩、字体与图像处理的整体协调。

| 方向 | 可参考的视觉特征 | 适用表达 |
| --- | --- | --- |
| F1 纸墨东方 | 纸墨色调、书刊式排版、器物细节、疏密对比；可选衬线字与局部竖排 | 文化、空间、器物及重视传统语境的故事 |
| F2 深空精密 | 深浅对比、精确网格、产品特写、清晰参数、金属或工业材质 | 技术能力、性能、工程和精密制造 |
| F3 暖土手作 | 温暖色调、自然材质、人物动作、生活场景、近距离细节 | 手作、食物、在地生活与人的经验 |
| F4 澄澈商务 | 清晰网格、简洁字体、真实业务摄影、易读图表、适量品牌色 | 企业介绍、平台能力、业务价值与合作提案 |
| F5 高张力表达 | 鲜明色彩、大字、强烈尺度差、动态构图、直接的摄影或插画 | 潮流、创意、运动、文化活动与个性表达 |
| F6 提案画册 | 编辑式图文关系、充足留白、摄影叙事、细致排版、连贯的章节设计 | 品牌提案、生活方式、产品理念与作品展示 |

例如，提案画册可使用品牌主色与中性色、精简导航和大画幅摄影；字体、点缀色与图片处理随品牌调整。独立杂志方向可参考双色印刷、剪贴构图、半色调和纸张质感，适合具有出版或实验气质的主题。

参考品牌手册、年报、杂志或设计机构案例时，关注其图文关系、阅读顺序和品牌识别方式，选择与当前任务相关的做法。

### 风格激发词

可从以下词语寻找灵感，结合品牌定位、受众与素材选用，也可以设计变体。风格体现在排版、色彩、影像和图形的共同处理上；已有品牌规范时，在其范围内发挥。 表中的配色、字体、材质和适用表达均为参考，可随品牌调整；透明、阴影、纹理与复杂图像保持必要的文字对比和阅读层级。

| 可选风格 | 激发词与视觉提示 | 可支持的品牌表达 |
| --- | --- | --- |
| 极简雅致风（Minimalism） | 克制用色、单一重点、充足留白、精细字形、材质微距 | 品质、精致、安静、自信 |
| 瑞士排版风（Swiss） | 网格、无衬线、大字、不对称平衡、清楚对齐 | 理性、秩序、专业、现代 |
| 杂志编辑风（Editorial） | 栏目、衬线标题、图文混排、大画幅摄影、细致注释 | 人物、文化、生活方式、长篇品牌故事 |
| 包豪斯几何风 | 基础几何、构成、色块、线与面、形状间的呼应 | 创造力、功能意识、设计文化 |
| 独立杂志拼贴风（Collage） | 剪贴、纸张扫描、双色印刷、半色调、错位标题、照片混排 | 独立、实验、文化感、鲜明态度 |
| 当代东方风 | 纸墨、器物、书刊排版、疏密、局部竖排、现代摄影 | 文化传承、东方空间、当代生活方式 |
| 自然手作风 | 亚麻、陶土、木纹、手部特写、自然光 | 温度、材料触感、工艺、在地经验 |
| 手绘插画风（Hand-drawn） | 手绘线条、笔触、自由轮廓、角色、图文注记 | 亲和、创作者气质、亲子、温暖的品牌故事 |
| 拟物主义（Skeuomorphism） | 真实材质、物件形态、纸张与皮革、光影、实体标签 | 熟悉感、器物文化、工艺、真实使用体验 |
| 电影叙事风 | 远景与特写、光影、场景切换、情绪色调、短句字幕 | 人物故事、品牌历程、体验与情感 |
| 玻璃拟态（Glassmorphism） | 半透明叠层、磨砂质感、透光、柔和渐变、背景景深 | 轻盈、通透、数字产品与未来感 |
| 新拟态（Neumorphism） | 同色表面、柔和内外阴影、凸起与凹陷、浅浮雕 | 触感、柔和、简洁的产品与控制界面表达 |
| 实验粗野风（Brutalism） | 巨字、强对比、直接排版、外露网格、硬边裁切、原始质感 | 锐利、先锋、街头文化、挑战常规 |
| 新粗野主义（Neo-Brutalism） | 粗描边、高饱和色块、偏移硬阴影、粗体、平面图形 | 大胆、玩趣、独立产品与年轻品牌 |
| 复古互联网（Retro Web） | 早期网页、系统窗口、链接式标记、低分辨率图标、复古界面 | 怀旧、极客文化、数字记忆、独立创作 |
| Y2K 千禧未来风 | 银色镜面、液态金属、半透明彩色、圆润立体、实验字体 | 千禧数码、潮流、时尚、年轻文化 |
| 复古未来主义（Retrofuturism） | 太空时代、复古科幻插画、老式仪表、流线外形、旧海报质感 | 对未来的想象、探索、航天与复古科技 |
| 赛博朋克（Cyberpunk） | 霓虹夜景、暗色城市、技术符号、故障效果、密集局部细节 | 科技幻想、游戏世界、夜间文化、强烈戏剧性 |
| 黑色科技极简（Dark Tech） | 近黑底、精简排版、细微冷色渐变、局部光线、产品特写 | 科技能力、精密、专业、沉静的未来感 |
| 立体沉浸风（3D / Immersive） | 大画幅立体场景、空间纵深、环境光、产品渲染、镜头视角 | 空间体验、汽车、建筑、旅行与产品世界 |
| 立体玩趣风 | 黏土、软质立体、夸张比例、角色、产品小场景 | 亲和、想象力、IP 与年轻化表达 |
| 孟菲斯风 | 明快撞色、几何图案、波点、曲线、跳跃构图 | 活力、趣味、创意消费、个性表达 |
| 极繁主义（Maximalism） | 丰富色彩、多层图像、字体混排、贴纸、纹样、强烈视觉节奏 | 艺术、潮流、文化活动、丰盛与热闹；保留清楚焦点 |
| 像素游戏风（Pixel） | 点阵图形、像素角色、方块场景、复古游戏界面、关卡意象 | 游戏、怀旧、探索、数字社群；正文保持易读 |

同一方向可随品牌调整：科技品牌可以用浅底瑞士排版呈现精密感，也可以用复古未来风表达想象力；生活方式品牌可以用自然手作风突出材料，也可以用独立杂志风突出文化态度。组合时可让一种语言主导，再借用相关细节，例如“瑞士排版＋产品微距”或“当代东方＋编辑画册”，并贯穿整稿。

### 可选构图

| 内容需要 | 可采用的构图 | 选择依据 |
| --- | --- | --- |
| 品牌宣言、核心观点 | 大字、单图配短句、留白构图 | 让观众迅速抓住主要信息 |
| 品牌故事、人物经历 | 图文分栏、引文、档案与当代照片对照 | 保持叙事顺序，突出真实细节 |
| 产品或作品展示 | 单个主体大图、等大系列图、细节特写、图文目录 | 便于观察、比较与理解产品特点 |
| 多场景或材料展示 | 图像拼贴、规则网格、局部放大 | 表达对象之间的关系，保留关键细节 |
| 数据、成果与证据 | 重点数字、图表、表格、案例对照 | 准确呈现口径、差异与结论 |
| 历程、工艺或合作过程 | 时间轴、流程图、阶段分栏 | 清楚表现先后、联系与阶段重点 |
| 章节转换与结尾 | 章节标题、代表图、总结或行动建议 | 配合叙事转折与演示目的 |
| 多项功能或内容概览 | Bento Grid 便当盒布局：不同尺寸模块共享网格与间距，主要信息占据较大区域 | 适合模块化概览；模块大小对应信息主次，不用多层圆角卡片堆叠层级 |


### 图表与实现参考

数据图表按信息关系选择，可通过 `chart_help('<slug>')` 查看用法；品牌架构、价值层级等关系图可通过 `relation_help('<slug>')` 查看用法。正式 Slides 的此类图表使用 atomized 可编辑输出，不用 `<embed>` 作为主体。

`tea_ceremony`、`stone_ink`、`candlelight`、`linen_plum` 等 palette 可供参考，按品牌需要选择其他配色或调整颜色；同稿图表保持一致的颜色语义。

视觉描述中的 CSS 属性不能直接写入 Slides XML。按 [XML 速查](../xml/xml-schema-quick-ref.md) 使用支持的属性；竖排短语可通过窄文本框逐字换行实现，并检查实际排版。
