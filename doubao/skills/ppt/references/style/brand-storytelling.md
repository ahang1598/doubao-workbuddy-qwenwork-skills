# 品牌 / 创意展示

**标杆参考**：顶级杂志（Monocle、Wallpaper、Vogue）；国际设计机构（Pentagram）；优秀的品牌年报、品牌手册与创意提案；高完成度品牌设计案的量化拆解基准——编辑级画册、奢侈品牌手册、建筑事务所提案的水准。

**本文档如何使用**：

- **A 部分（第 1–2 节）**：任务受理前必须完成的主题识别与硬性禁令。任何一条不满足则不得进入 B 部分。
- **B 部分（第 3–7 节）**：从主题到成品的五步执行流水线，按顺序执行。
- **C 部分（第 8–11 节）**：执行过程中随取随用的四大视觉纪律（配色 / 字体 / 图像 / 构图）。
- **D 部分（第 12 节）**：视觉参考库——五大风格家族速查表
- **验收（第 13 节）**：交付前四轮通读清单。

---

## A. 前置条件

### 1. 主题识别（必做的第一步）

对每一份任务，先做两件事。

**1.1 识别主题的视觉基因**

如果主题是具体的品牌 / 产品 / 公司 / 人物 / 城市 / 建筑 / 事件 / IP:

- 从用户上传的参考素材中提炼图标、品牌理念等视觉识别元素。
- 搜索并访问官方网站、官方发布的年报、创意手册与图标；不要只读文字——更要多参考、多研究页面的视觉效果以帮助理解风格。
- **验证标准**：即便把所有文字内容都拿掉，也应当能通过其他视觉特征找到与该主题的关联。

**1.2 判断主题的审美等级（取其精华，去其糟粕）**

并非每个主题的审美都与 Monocle / Wallpaper / Vogue 一致：

- 达到标杆水准的：继承其视觉基因。
- 未达标杆水准的：必须明确禁止，宁可不用。
- 品牌本身缺乏设计质感的：只保留品牌主色作为主题色或强调色，或只保留图标作为装饰。



### 2. 硬性禁令（贯穿全稿；除用户明确另有要求外，一条都不得违反）

**通用构图与色彩红线**：

1. **默认不使用卡片**：严格禁止用圆角矩形或矩形卡片来构建层级或对齐关系——线段、留白以及字体/字号差异是更好的解决方案。
2. **禁止均分构图**：除非没有其他可用版式，不要默认使用三等分、四等分或 2×2 矩阵——包括「三栏 + 标题 + 结论」这类三段式套路。
3. **禁止平庸、常见或 AI 味的配色**：严格禁止蓝白搭配、蓝紫渐变、青紫霓虹、彩虹光晕、玻璃拟态卡片、发光描边。
4. **禁止与整体风格冲突的元素**：不得出现所选风格之外的样式，例如在锋利风格中使用圆角图标或圆角矩形。

**编辑级出品红线**（作为品牌创意稿的底线）：

1. **色彩越界**：色板超过「1 主色 + 中性轴 + 至多 1 强调色」即失控。硬禁 Material / Flat UI 默认色（#4CAF50 / #FF9800 / #2196F3 / #E91E63 及其近邻），以及说不出材料来源、饱和度 > 70% 的纯 RGB 色。
2. **彩色标题**：标题不套彩色——只用炭黑、暖白（深底时）或主色深化版。「绿色加粗字体」式的彩色标题是一级反例。
3. **组件思维**：图标 + 短语的卡片阵列、圆角小卡片海、进度条、胶囊标签、emoji、剪贴画、阴影浮雕渐变描边等 PPT 默认效果——一律禁止。
4. **平色底 + 两层内容**：连续两页出现「平色底 + 标题 + 正文 + 右侧一张图」即为失败。
5. **同构失败**：连续三页同构 = 硬失败。
6. **同脸失败**：不同行业成稿缩略图并排看不出行业与气质差异——该稿判废重排。
7. **文字造假**：装饰性假英文、lorem ipsum、乱码——一律禁止；所有英文必须有真实语义。
8. **家具层缺失**：全稿没有 3–5 件位置一致的页面家具——这是「设计过」与「生成的」分水岭，不许省略。

## B. 执行流水线（严格按序执行）



### 3. 步骤 1 — 选定风格家族并写下差异化决定

**没有全局默认风格。** 每一份稿都必须先从第 12 节的五大家族中选一个（F1 纸墨东方 / F2 深空精密 / F3 暖土手作 / F4 澄澈商务 / F5 高张力表达）。家族决定底层处理、字体行为、版式语法、影像签名、家具集与色板逻辑——不是只换色值。

选定后立即写下 **「本稿区别于其他家族的三个可见决定」**：

- 例：深色氛围底而非纸白底 / 竖排巨字而非横排标题 / 满版电影感大图占四成页面。
- 这三个决定必须能在成稿缩略图上一眼看到。

**冲突时优先级**：用户明示 > 受众调制 > 行业默认家族。

### 4. 步骤 2 — 受众调制

家族回答「这个行业长什么样」，受众回答「这群人看什么才对」。同一行业面向不同人群必须产出缩略图可区分的两稿——按第 12.2 节受众档表调制字号、色板、影像与密度。

**受众同脸测试**：假想同一行业换一档受众，如果当前方案不需要任何改动仍然成立，说明受众调制没做，回到第 12.2 节重打三个差异化决定。

### 5. 步骤 3 — 每页按五层结构展开

每页自下而上按五层构思与描述，缺层即失败。


| 层          | 内容                                                             | 必读要求                                                |
| ---------- | -------------------------------------------------------------- | --------------------------------------------------- |
| **L0 底层**  | 底色 / 纹理资产 / 满版影像 / 色域拼接                                        | 全稿 ≥ 60% 页面底层不是纯平色；纯平色底页必须靠巨字构图或大画幅影像撑住             |
| **L1 图形层** | 幽灵巨字（120–400pt，6–12% 透明度，可被上层图片部分遮挡）、放大出血的品牌符号、整块色域分割          | 不是每页都有；章节页与视觉页的主要武器                                 |
| **L2 影像层** | 本页 1–6 张图                                                      | 每张写明 URL、裁切比例、位置、占比、出血边；多图时主图面积 ≥ 最小图 2.5 倍，共享一条对齐轴 |
| **L3 文字层** | 标题（逐字 + 字号 + 断行）、正文（逐字 + 栏宽 + 行距）、双语配对、竖排指令                    | 竖排一律写成「窄栏 + 每行一个汉字」，不依赖宿主竖排功能                       |
| **L4 家具层** | 全稿固定 3–5 件微装饰：章节标签 / 页码 / 页缘英文 rail / 印章块 / 圆点 / 角标 / 细 rule 线 | 每件在固定位置、固定字号、全稿一致                                   |




### 6. 步骤 4 — 选择版式装置与跨页节奏

**核心版式装置（编辑级画册的常客，平庸稿的缺席者）**：


| 装置              | 构图机制                                    | 使用要点                                   |
| --------------- | --------------------------------------- | -------------------------------------- |
| **L21 多图编辑拼贴**  | 3–6 张不同裁切比例（竖条 / 方 / 横幅）错落排布，1–2 张贴边出血  | 共享一条对齐轴，主图面积 ≥ 最小图 2.5 倍，图间距统一 12–20px |
| **L22 幽灵巨字**    | 单字/单词 150–400pt、6–12% 透明度置于底层，实内容压其上    | 幽灵字取章节主题字或品牌首字母；每 4–6 页一次              |
| **L23 竖排文字带**   | 页面一侧 8–14% 宽窄带，竖排短标题（每行一个汉字）+ 极小英文      | 只承担 ≤ 8 字短语；F1 / F3 专属                 |
| **L24 竖条切片带**   | 3–6 条等高竖图并排（原料 / 材质 / 细节），条间 8–14px     | 每条独立主体；配 9–11pt 条目名                    |
| **L25 巨号章节页**   | 超大编号（阿拉伯或壹贰叁，120–220pt）+ 章节名 + 一张代表图或色域 | 同稿各章节页共享骨架但轮换图片与明暗                     |
| **L26 满版氛围换气页** | 满版影像 + 一行短句（或无字），置于高密度页之后               | 每 4–6 页安排一次；文字 ≤ 20 字                  |


**跨页节奏配方（示例）**：

- **F1 纸墨东方**：`L01 → L25 → L21 → L23+L04 → L11 → L26 → L21 → L16 → L25 → … → L01`，竖排带与拼贴交替，每章一次满版换气。
- **F2 深空精密**：`L01 → L08 → L26 → L04 → L02 → L16 → L12 → L26 → L07 → L20`，暗调贯穿，参数页做浅色换气。
- **F3 暖土手作**：`L01 → L25 → L13 → L14 → L24 → L02 → L12 → L26 → L15 → L20`，远中近镜头推进，竖条切片承担原料证据。
- **F4 澄澈商务**：`L01 → L08 → L07 → L04 → L10 → L12 → L26 → L20`，英雄图只在章首与结尾，深色页压数据高潮。
- **F5 高张力表达**：`L01 → L03 → L18 → L02 → L21 → L26 → L12 → L20`，低密度宣言与高密度拼贴剧烈交替。

（L01–L20 为通用版式基础套件：hero-full / hero-object / manifesto-type / split-evidence / metric-poster / timeline-ribbon / comparison-stage / matrix-with-proof / material-board / object-catalog / triptych-lens / process-strip / floorplan-callout / detail-zoom / portrait-quote / collage-field / chapter-index / decision-roadmap 等——按页面角色选取。）

### 7. 步骤 5 — 版式门禁与文字预算校验

对成稿逐项校验：

**版式门禁**：

- 22 页以上至少使用 8 个布局指纹；任一指纹不超过全稿 20%。
- 10 页以上必须有 2–4 张章节/换气页（L25 / L26 / L03）；平铺直叙无换挡即失败。
- 图片拼贴必须有主次：主图面积至少为最小图的 2.5 倍，或以位置/明暗形成唯一焦点。
- 高密度研究页后必须安排低密度页换气。
- 全稿至少 30% 页面为多图页（≥ 2 张图）；至少 25% 页面图像面积 ≥ 70%。
- 图片尺寸由内容决定：人物动作要完整肢体、产品微距要材质、空间图要入口/动线/人尺度，不为填框硬裁。

**文字预算**：

- 每页可见文字：章节页 ≤ 40 字；视觉主导页 ≤ 120 字；论证页 ≤ 180 字；全稿中位数 ≤ 160 字；任何页 > 220 字先删改或拆页。
- 版心外整块留白 ≥ 30% 页面面积；标题周围必须有成片负空间。
- 容量不足先删、拆、换结构，不缩字号。

**连续页节奏**：连续两页至少改变构图轴、图像占比、锚点、密度、明暗中的两个维度。

## C. 规则库（执行过程随取随用）



### 8. 配色纪律：材料色而非屏幕色

- 全稿色板 = **1 主色 + 一条近黑近白的中性轴 + 至多 1 强调色**，超过即失控。
- 主色必须能说出它来自主题世界的哪种材料（茶汤、木、石、陶、织物、金属、植物、土壤、机身漆面……），饱和度通常 ≤ 60%。
- 中性轴禁用纯黑纯白：正文炭黑 #2A2A2A–#3A3A3A；浅底暖白 / 米白 / 纸灰；深底 #101216–#1E1B18 一类。
- 强调色面积 < 5%，只做视线锚点。
- 不使用渐变、多色图表、多色状态块；每种颜色承担稳定语义。



### 9. 字体纪律：display 与 body 必须异质

- **字号层级（16:9 编辑级）**：封面主题 80–130pt；章节页巨字 90–200pt；页标题 28–44pt；导语 18–22pt；正文 14–16pt；注释 / 来源 / 页码 9–12pt。相邻层级之间至少 **1.8 倍尺度差**。
- **数字与单位分层**：大数字用细字重超大字号；单位与口径退到 10–12pt。
- **双语配对是编辑感的标配**：中文大字下方或旁边配一行 8–11pt 拉丁文全大写、字距加宽 200–300 的微标签——必须有真实语义。
- 中文断行按语义断，不出孤字；`title_lines ≤ 3`。
- 竖排 / 旋转只承担短标题、索引或年代等短语义；长正文永远按自然阅读方向。
- 叠图文字必须落在低信息区并验证最亮 / 最暗处对比；每页写清阅读顺序（01 → 02 → 03）。



### 10. 图像纪律：图像是主角，而且不止一张

- A 级参考稿**单页图像面积中位数为 55%–75%，平均每页 2–5 张图**。全稿图像面积中位数 < 45% 的方案先补图再写页。
- 单图页用全出血或 ≥ 50% 版面的大画幅；多图页用 L21 拼贴规则。**一排小图配一排小字 = 电商详情页，判废。**
- 全稿共享同一个影像世界（统一光线、色温、镜头语言、后期质感）。
- 图片自带的构图留白要与文字区咬合：主体朝向的负空间就是标题的家。



### 11. 构图与视觉逻辑：做极致的选择

- **做极致的选择**：超大字号、巨幅图片、强烈留白、高密度多栏、单一鲜明色彩、粗重线条。打造一种极致的风格：旧报纸头版、Memphis（孟菲斯）、Constructivism（构成主义）、Swiss style（瑞士风格）等。**拒绝一切安全、平庸、保守的选项：宁可丑，也不要平庸。**
- **让页面各不相同**：封面页、观点页、数据页、图片页各有不同的构图。无需严格遵循同一套「页面骨架」，但整份稿的一致性仍应能通过配色、字体、字号、装饰元素与网格对齐被识别出来。
- **视觉逻辑必须有出处**：视觉语言必须来自演示文稿的主题、品牌、行业、时代或材质，并且必须帮助观众理解内容。
- **每页从版式库选一个构图机制**；连续两页至少改变构图轴、图像占比、锚点、密度、明暗中的两个维度。
- 页码小而弱（9–10pt 中性灰）；Logo 只出现在封面 / 封底 / 章节页。

## D. 视觉参考



### 12. 五大风格家族（家族基因速查表）+一个参考样式

如果没有合适的风格家族可以路由，可以使用兜底参考样式。


#### 12.1 家族总表与参考样式


| 家族           | 适用主题                             | 底层 L0                                       | 字体                     | 影像签名                           | 色板                                        |
| ------------ | -------------------------------- | ------------------------------------------- | ---------------------- | ------------------------------ | ----------------------------------------- |
| **F1 纸墨东方**  | 文化 / 东方空间 / 文旅 / 器物 / 禅意         | 宣纸 / 绢布纹理 + 局部窗棂光影                          | 中文衬线 + 竖排巨字            | 晨雾、留白、低饱和墨调                    | 纸灰米白 + 炭墨 + 材料色（木棕 / 黛青 / 苔绿 / 赭石）+ 朱砂印章  |
| **F2 深空精密**  | 硬科技 / 航天能源 / 汽车 / 高端装备           | 深色 ≥ 60%，深空渐变 / 金属或碳纤维纹理                    | 现代无衬线，极端级差，等宽数字        | 单一强光源 rim light + 尺度参照物 + 大气要素 | 深空黑灰 + 暖白 + 产品色（引擎橙 / 信号红 / 钛金 / 电光蓝）     |

| **F5 高张力表达** | 时尚 / 潮流生活方式 / IP 潮玩 / 创意消费       | 高对比底色轮换 + 胶片颗粒 / 纸张扫描                       | 超大字贴边裁切；中英大小反差极端       | 直闪 / 硬光抓拍、真实街头或房间、动作瞬间         | 高饱和主色（可 > 60% 饱和度，此家族豁免）+ 黑白轴             |


**家族硬禁**：

- F1：祥云龙纹贴片、乱码书法、大红大金、干净白底 + 细线框的「性冷淡」错译。
- F2：伪 HUD、霓虹电路线、随机粒子、蓝紫渐变、浅米色底当主场、图小字多的「说明书感」。
- F3：白底电商杯图、高饱和糖果色、可爱贴纸、塑料质感、居中大标题海报腔连续使用。
- F4：卡片海、图标阵列、三栏平均、彩色标题、装饰性插画。
- F5：平均九宫格、假英文、彩虹渐变、幼儿园素材感。




#### 12.2 受众调制层（家族之上的第二旋钮）


| 受众档                    | 家族倾向                       | 关键调制                                                                                            | 硬禁                         |

#### 12.3 参考样式

**核心视觉**：整个slides 感觉就像一本手工修剪、扫描和装订的独立杂志。厚海报类型、双色叠印、半色调图像、剪切和粘贴块以及轻微倾斜。保留纸张和印刷的缺陷，而不是追求数字界面的华而不实。

**调色板**：
- 纸张：暖米色#F1E2C2。
- 主墨水：钴蓝#1646B8。
- 第二专色：荧光粉色#FF4F87。
- 文本和规则：墨水黑色#171512。
- 橙黄色 #F1A51B 可能仅出现在一个或两个部分页面上，且在 5% 的区域内。
- 无透明渐变；颜色仅以平面、套印和半色调的形式出现。

**类型**：
- 封面标题：超重压缩海报类型，88–120 pt，允许旋转 -3 度并穿过画布边缘。
- 页面标题：42–58 pt，可以黑底反白。
- 正文：14–17 pt，采用清晰的无衬线或衬线字体。
- 注释：10–12 pt 等宽，模仿打字机标签。

**网格和几何**：
- 使用不等宽的两列和三列以及剪切和粘贴模块。
- 图像和文本块可以旋转 -4 到 +4 度。
- 主要规则 2–3 分；裁剪标记 0.75 pt。
- 色块保持直角；允许局部溢出和相互重叠。

**图像处理**：
- 所有照片首先转换为高对比度黑白，然后进行蓝色或粉色半色调处理。
- 半色调网点大小保持一致；允许 2-4 个像素的色彩重合失调。
- 人物和建筑物可能会被粗暴地裁剪，但永远不会超过失去可识别主题的程度。
- 切勿直接放入全彩照片。

**页面语法**：
1、封面：标题占据图片一半以上；底部是印刷机或书店的蓝粉色双色调照片；右上角贴有倾斜的小标签。
2. 目录页：五张彩色纸条，每条仅包含一个章节编号和一个简短标题。
3.历史页面：时间线看起来像夹在纸上的门票；年使用 40–56 磅粗体。
4. 工艺页：水平展开五个台阶，每个台阶包含一个半色调图像、一个数字和一行说明。
5、城市案例页：一张大图占60%；文本像报纸侧边栏一样压在图像的一侧。
6.地图页面：地图保持黑色线条；主要城市均标有粉红色实心圆圈。
7. 结束页：四个大数字圆圈表示操作步骤；底部有一条黑色宣言线。

**重复出现的图案**：套印错误的蓝色和粉色套印、左上角的裁剪线以及固定的卷/期号。

**禁止**：玻璃形态、柔和的阴影、光滑的渐变、精致的圆角、全彩摄影、商务剪辑图标和完美对称的网格。


## 13. 交付验收：四轮通读

1. **标题通读**：只读标题能否讲通因果与决策闭环。
2. **缩略图通读**：
  - 有没有视觉高潮与节奏换挡？
  - 有没有连续三页同构、连续两页「平色底单图右置」？
  - 有没有重复图片？
  - **眯眼测试**：缩略图整体的明暗分布、底层质感与家具层是否与所选风格家族一致？是否能与其他行业、其他受众档的稿一眼区分？（同行业换一档受众而方案不用改 = 受众调制没做）
3. **全尺寸逐页**：对照第 2 节硬性禁令逐页打钩——色板越界？彩色标题？卡片阵列？层级差 < 1.8 倍？文字超预算？图像面积不足？底层纯平色超标？家具层缺失或漂移？任何一项失败即修。
4. **复述测试**：不了解项目的人看完能否说出核心矛盾、定位和三个设计动作。

修订后必须对受影响页复验；未做最终回读不得声称完成。
