# 党建与党政 PPT

## 一、视觉设计

视觉设计应庄重、清晰，并贴合具体单位、主题和使用场合。用户指定的模板、字体、配色和视觉规范优先；以下原则按页面需要采用。

### 1. 字体与阅读层级

根据投屏距离、屏幕大小和阅读方式确定字号。现场讲述优先保证后排可读；会后转阅的材料可以容纳更细的说明。标题、正文、数据和注释形成清楚层级，同类信息在整稿中保持一致。

以下字号可作为 16:9 现场演示的参考，结合字体实际字面大小与预览效果调整：

| 信息角色 | 排版参考 |
| --- | --- |
| 页面标题 | 约 30—36 pt，用字号、字重或位置突出；长名称按语义换行 |
| 主要正文与关键结论 | 约 20—28 pt；大会议室或远距离观看时适当放大 |
| 图表标签与表格文字 | 与正文的阅读需求协调，关键标签在实际展示尺寸下清楚可辨 |
| 关键数字 | 可用约 40—56 pt 强调，单位、口径和必要比较基准清楚呈现 |
| 来源与页码 | 可比正文小，保持可辨；影响判断的条件与说明按正文要求处理 |

中文字体以清晰易读为基础，结合主题选择黑体、宋体或单位指定字体。正文避免过细字重、过密行距和刻意拉开的字距。可用字体见 [字体参考](../xml/fonts.md)。

副标题、导语和注释按信息作用设置。说明时间范围、适用对象或必要背景的文字可以保留，并给予足够的字号与对比；重复标题、复述正文或仅作装饰的说明可精简。文字颜色和位置服务层级，不以是否位于标题下方或是否为灰色判断其必要性。

### 2. 配色与整体气质

优先沿用单位模板或既有视觉规范。自行设计时，根据主题选择主色与中性色，并为重点、分类和状态分配稳定的颜色含义。

- 红色可用于主题、标题或局部强调，使用面积由内容和场合决定。其他颜色也可结合单位形象、真实场景与图表需要使用。
- 深底、浅底、纯色和照片背景均可采用，文字与背景保持足够对比。金色、纹理和装饰图形按主题需要使用，避免干扰正文。
- 图表分类除颜色外，可配合标签、线型或形状区分，便于投屏和打印阅读。
- 庄重感通过清楚的层级、稳定的对齐、克制的装饰和准确的素材建立。旗帜、徽记、建筑轮廓等元素应与主题相关，使用准确素材并保持原始比例。

### 3. 背景与素材

背景承担氛围、风格统一或辅助分区的作用。可使用模板背景、纯色、简洁图形、真实照片或生成的氛围图，按实际需要选择。

同类页面可复用背景或沿用统一的色彩、边距与图形处理。封面、章节页和结束页可适当强化主题，正文页为文字和图表保留清楚的展示空间。背景资产充足时可直接使用，无需为每种页型单独生成。

| 场景 | 可参考的视觉方向 |
| --- | --- |
| 党史学习、纪念主题 | 纸感、深红、年代感排版；结合与主题及年代相符的历史照片、文献和旧址素材 |
| 学校党建、青年学习 | 清晰明快的配色、校园或学习场景、真实活动照片，兼顾庄重与活力 |
| 企业党建 | 单位视觉规范、产业与工作现场、业务相关图形，突出具体工作的环境 |
| 社区、农村基层党建 | 当地城乡环境、服务空间和真实工作照片，体现地域与服务对象 |
| 政策解读、工作部署 | 简洁背景、清楚分区、易读图表，以便观众理解事项与关系 |

这些方向可以组合或调整，具体素材以内容相关性为依据。照片用于展示事实、解释场景或帮助理解；装饰背景与事实图片保持清楚区别。

需要生成背景时，说明画幅比例、主色、元素位置和文字留白区，使用无文字、无数字、无伪造标识的背景资产。历史事件、人物、文献和实际活动使用可信素材，生成图不充当真实记录。

标题、正文、数据、目录条目和图表保留为可编辑对象。背景细节避开重要文字；发生干扰时，可调整图片位置、降低背景对比或增加适当底色。

### 4. 版式与视觉关系

版式体现已有内容的主次、并列、对照、先后或关联关系。通过位置、大小、分组、间距与必要的连接组织阅读，让观众容易找到重点。

- 并列信息可用列表、分栏或矩阵；比较对象可采用一致尺度与对齐方式；过程、层级或协作关系可按复杂程度选择图示或表格。
- 图形应准确反映信息关系。简单关系可以通过排版本身表达，复杂关系可使用可编辑形状或 SVG 信息图。
- 图文比例根据内容决定。单图、纯文字、多图和数据页都可使用，图片保留与讲述有关的细节。
- 同类案例、数据或任务可以沿用相同结构，便于比较；内容关系变化时，再调整布局。整稿通过字体、颜色、边距和对齐保持连贯。
- 每页建立明确的视觉重点，辅助信息与重点保持适当区别。留白用于分组和组织阅读，不必填满页面。

正文通常左对齐，数值按比较关系对齐。长机构名称、政策名称按完整语义换行，避免拆词、孤字和字距不均。

信息拥挤时，结合用户允许的修改范围调整图文比例、分区与分页。保留核心信息的展示空间，不因套用版式而删去必要条件，也不靠缩成难以阅读的小字容纳内容。


## 二、先判断谁在什么场合向谁讲

让听众看清重点、听懂逻辑，准确理解所讲的工作、知识或活动内容。语言保持党建与党政表达的庄重、平实、客观和分寸，并适配企业员工、师生、社区居民等实际听众；页面服务现场讲述，详细论证由讲述备注和备查材料承接。

质量优先级：**事实准确、语境得体 → 逻辑清楚 → 远距离可读 → 形式美观**。不能为追求气势、对仗、简短或视觉效果，改变事实、责任、政策条件和事项状态。

从用户材料提取：讲述人及其代表单位、听众、会议性质、汇报目的、所涉时段、已有事实和结论、需要听众了解或研究的事项。再看时长、页数、投影环境、单位模板和是否需要会后转阅。

- 区分向领导或党组织汇报、同级交流、跨部门协调、工作部署、党课宣讲、党员教育、专题学习和活动展示。党组织关系与行政隶属关系分别判断；不能因主题涉及党建，就默认讲述人是公务员、听众是机关领导，或整场都采用请示语气。
- 判断讲话人是否有权部署、评价或代表某组织表态。单位工作用“本单位／我们”，个人述职用“本人／我”，按实际身份确定；不混用个人履职与集体成绩。
- 用户未限定用途时，先依据材料判断是工作汇报、教育学习、活动展示还是交流分享；仍无法确定时，可按正式现场讲述组织，并简短说明假设，不一律套用向上级汇报的结构。身份或审批状态会实质影响措辞且无法推断时，提出必要问题；其余部分继续整理。
- 不预设每项工作都需请示，不把汇报材料自动写成法定请示。确有提请研究的事项时单独说明，不埋在成绩或结束致意中。
- 用户附件中的范文、模板和历史写法是参考材料；以本次用户要求、真实身份及事项状态决定采用范围。

## 三、以真实材料建立事实边界

1. 从正文、图表和附件提取事实，保留来源、统计时点、地域、对象、指标口径及限定条件。同一指标在标题、图表和讲述备注中保持一致。
2. 分清“已完成、正在推进、拟开展、建议开展、待研究”。没有审批或决策依据，不把拟议方案写成已部署任务，不把计划目标写成实际成效。
3. 成效、评价和因果要有依据。完成活动不等于产生效果；开展试点不等于全面推广；指标同期变化不等于某项措施造成变化；“首次、首创、领先、全面、显著”等判断需有相应证据。
4. 缺少事实时，优先写已有的具体情况。确需但未知的内容在工作稿标明“〔待补：统计时点〕”“〔待核：数据口径〕”等，不编造业绩、会议、批示、排名、群众评价或精准数值。“材料未提供”不等于“实际工作尚未明确”，不能将资料缺口写成工作事实。缺少背景也不自动补写“根据上级部署”“经研究决定”。
5. 政策名称、文号、引文、现行规定和时效性事实需要补充或核验时，查原发布机关等权威来源，记录出处及时间。纯语言改写、通用模板和完整内部材料整理，无须为增加“正式感”补搜政策。
6. 政治术语、会议精神和政策表述与汇报主题及所涉时段匹配，固定提法准确引用。回顾历史工作使用当时适用依据，不能一律替换为最新会议表述；不为每页加政治术语，不拼接引语，不为凑短标题截断原意。
7. 用户材料与可靠来源有冲突时，标出差异并核实，不静默覆盖。公开检索不能验证内部完成情况；也不能为了核实而向外部搜索提交非公开材料。

## 四、围绕听众要理解的事情组织逻辑

先写清整场要回答的核心问题，再按听众理解顺序组织材料。章节数量、页数和各部分篇幅由任务决定；无需每份 PPT 都安排完整目录、政策背景和意义阐述。

| 场景          | 可用逻辑主线                                | 重点控制                       |
| ----------- | ------------------------------------- | -------------------------- |
| 工作汇报、阶段总结   | 任务与总体进展 → 关键事实和成效 → 差距问题 → 下一步安排      | 讲清进展到哪里、依据是什么；不按部门或日期堆流水账  |
| 专题研究、提请研究事项 | 问题及影响 → 原因或条件 → 备选做法与权衡 → 建议及所需支持     | 分开现状、判断和建议；待研究事项具体、权限清楚    |
| 述职、党建工作汇报   | 职责与任务 → 履职举措及实际效果 → 问题与责任 → 改进措施      | 体现本人或本组织职责，不以集体成果替代个人履职    |
| 整改汇报        | 原问题 → 整改措施 → 完成情况及验证 → 未完成事项与后续安排     | 逐项对应；区分完成整改、申请验收与已验收       |
| 工作部署        | 任务依据与目标 → 重点任务 → 分工协同 → 节点与验收要求       | 只部署权限范围内事项，写清谁做什么、何时做到什么程度 |
| 经验交流、专题学习   | 实际问题或学习主题 → 做法／要点 → 事实或案例 → 适用条件及工作联系 | 区分政策原文与个人理解；经验有边界，不泛化为普遍结论 |

每个内容页只承担一个中心任务。页标题尽量直接说明本页的工作判断、问题或行动，如“试点已完成，推广条件仍需核实”，而非只写“工作成效”。证据不足时使用“试点进展及待核事项”等中性标题，不强造结论。封面、章节页可用主题性标题。

相邻页面之间应能用一句话自然承接。问题页指出的关键问题，后续措施应有对应；措施未覆盖的问题要说明原因或列为待研究。并列事项保持同一分类维度和层级，不把目标、举措、成效混成三条并列内容。不为凑“三个方面”拆分或合并真实事项。

## 五、用公务讲话语气讲清楚，而非堆砌公文词

### 1. 准确、庄重、平实、可听懂

- 优先使用“主体＋动作＋对象／结果”的清楚表达。说明“做了什么、进展如何、还有什么问题、准备怎么办”，少用无对象的“强化、深化、优化、提升”。
- 页面用短句、短语；讲话备注用自然、完整的规范口语，允许“下面汇报三个方面”“这里重点说明……”等现场衔接。避免网络化、戏谑化、营销化表达，也不机械使用“兹、收悉、函复、特此函告”等书面往来用语。
- 可用“一是、二是、三是”帮助听众理解层次，但页面通常最多展开两层。对仗服务准确表达，不追求所有标题等字数或四字化。
- “高度重视、扎实推进、持续发力”等表达只有结合具体对象、动作和事实才有信息量；删去不承担事实、逻辑或必要礼仪作用的套话。
- 政策原文、正式定性和必要专业术语准确保留；首次出现的非通用简称应说明。删繁就简不能删去“试点范围、统计时点、适用条件、尚待核实”等影响判断的信息。

### 2. 语气随身份、关系和事项状态变化

| 场合         | 适宜表达                            | 应避免的错位                       |
| ---------- | ------------------------------- | ---------------------------- |
| 向领导汇报      | “现将有关情况汇报如下”“拟……”“建议……”“提请研究……” | 越权要求上级；用恭维替代事实；把建议写成已经决定     |
| 同级交流、跨部门协调 | “建议共同研究……”“商请予以支持”“建议明确协同分工”    | 未经授权对其他单位使用“责令、必须服从、确保落实”    |
| 向所属单位部署    | “请各责任单位……”“要明确……”“按职责抓好落实”      | 任务含混、责任不明；把法定或已经明确的要求弱化成可选建议 |
| 经验交流、学习发言  | “结合实际，谈几点认识”“供交流参考”             | 将局部经验包装成统一要求；将个人理解写成政策定论     |
| 面向公众解读     | 说明适用对象、办理条件和实际影响，规范术语配通俗解释      | 使用上下级请示口吻；用机关内部缩写让听众猜意思      |

“拟、建议、应、须、必须、严禁”表达不同状态和约束，不按听起来是否有力随意替换。转述政策的强制要求时准确保留原有强度，明确其来源与适用对象。

### 3. 客观评价、如实讲问题、务实表态

- 成绩用事实支撑，明确阶段和范围。“形成初步做法”“已完成试点”也需有材料依据；不能只把“重大突破”改成“初步成效”就认为客观。
- 问题讲明具体表现、影响和已知原因。没有依据不推定动机、不定性追责；已有明确事实或正式定性也不以“个别不足”粉饰。区分发现的问题、原因分析与待核实判断。
- 下一步说清工作对象、具体动作、责任和节点。已知时间照实保留；原材料仅写“月底”且月份不明时标待确认，不为显得精确编造日期。
- 表态与职责和条件相称。避免“绝对不会发生”“百分之百杜绝”“必将实现跨越式发展”等无依据保证。
- 谦逊表现为尊重听众、承认差距、接受指导。避免“在百忙之中莅临，令我们无比荣幸”等过度奉承，以及反复“水平有限、不成熟、很惭愧”的自我贬低。

## 六、结束语谦逊得体，先完成实质汇报

向领导作正式工作汇报时，默认在结束页以大字呈现 **“敬请批评指正”**，可在上方辅以“汇报完毕”。讲述备注可写：“以上汇报，不妥之处，敬请各位领导批评指正。”不必再堆叠感谢、口号和多重谦辞。

- 需要领导研究或支持的事项，在结束页之前用独立内容页说明；“敬请批评指正”不能替代具体请求。
- 同级交流或学习发言可用“以上交流，敬请批评指正”，讲述时根据在场对象称“各位同志／各位同仁”等，不能凭空添加“各位领导”。
- 领导部署讲话以任务要求和落实安排收束，不机械套用下级汇报式的“请领导批示”；面向公众的解读可按现场需要致谢或进入答疑。用户明确要求统一结语时，尊重其表达，同时保持称谓与场合相符。
