# 促销物料质量门槛

## 目录

1. 硬门槛
2. 视觉评分
3. 自动重试策略
4. 交付状态

## 1. 硬门槛

以下任一失败即不得交付：

- 产品外观与参考图不一致；
- 多出或缺少吸管、手柄、杯盖、泵头等结构；
- Logo错误、镜像、变形或位置偏移；
- 缺少真实Logo或仍使用Logo占位符；
- 只有产品/场景底图，没有宣传语和完整排版；
- 缺少主标题、辅助卖点、促销/活动信息或CTA；
- 商品名称、价格、折扣、赠品或活动时间错误；
- 中文乱码、错字、数字错误；
- 使用未经资料支持的功能或功效；
- 尺寸与渠道要求不符；
- 未授权赛事Logo、人物肖像或联名元素。

## 2. 视觉评分

每项0—2分，总分低于10/12则调整：

| 维度 | 2分标准 |
|---|---|
| 产品主次 | 产品是第一视觉主体 |
| 构图 | 有明确焦点、平衡和留白 |
| 光影材质 | 真实、清透、无廉价HDR |
| 字体排版 | 字体组合统一、层级清晰、对齐精准、有品牌感且手机可读 |
| 场景可信 | 道具正确、空间与透视合理 |
| 系列一致 | 色盘、字体、价格卡、产品比例统一 |

## 3. 自动重试策略

第一轮错误按类别修：

- 结构错误：加强参考图权重、减少重绘产品区域；
- 文字错误：移除生成文字，改用独立文本层；
- 构图杂乱：减少道具、扩大留白、固定产品位置；
- 风格廉价：移除爆炸贴、描边、斜体和高饱和渐变；
- 排版普通：重建网格与信息层级，调整字号比例、字距、行距、对齐和留白；
- 系列不一致：复用母视觉色盘、字体和价格卡。

第二轮仍失败：保留最佳无字底图，停止生成错误文字，标记需人工排版项。

## 4. 交付状态

- `Final`：通过全部硬门槛和视觉评分；
- `Review`：事实准确但需用户选择创意方向；
- `Intermediate only`：底图合格但尚未完成Logo和文字排版，不能作为宣传物料交付；
- `Blocked`：缺少产品图、授权或关键价格，无法安全生成。
