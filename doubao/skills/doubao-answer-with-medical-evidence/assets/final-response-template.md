# 完整报告骨架

必须严格使用七个一级标题：一、结论与回答；二、临床问题分析和解答；三、分析依据与注意事项；四、指南与共识依据；五、关键学术研究证据；六、完整参考文献；七、免责声明。

第二章必须使用自然、具体的二级标题组织分析，并覆盖用户的核心问题。标题可以是陈述式、结论式、原因式、影响式、行动式或问题式，可混合使用、合并相关问题，不机械套用“问题—回答”格式；标题数量、顺序和篇幅按内容调整。完整报告应优先、尽量生成一张真正有助理解的证据关系图或决策逻辑图，放在第二章一级标题之后、首个二级标题之前；只有内容过于简单、信息不足以形成可靠关系，或图示反而降低清晰度时才省略，不为形式堆叠多图。用户多轮补充后，图要使用最新信息并用文字标记“你当前的情况”或待确认节点；交付前逐项核对图中的事实、分支、行动和正文一致，图文不符时先修正或删除。第三章固定为 `3.1 病例信息梳理` 和 `3.2 风险评估与注意事项` 两个小节。第四章开头用“以上分析和判断综合参考了下方的高质量医学文献资料。”共同引出第四、五章；每引用一条来源，都要在相邻位置用患者能懂的话说明它与用户当前情况或所问问题的直接关系。可按需要使用重点块、独立一行、加粗短句或无序列表，不套固定字段、不要求固定条数。第六章列完整可点击来源；文档全文所有超链接都用来源标题或“查看原文”等可读文字，真实 URL 只放在链接目标中，不显示裸 URL。第七章结束即全文结束。
