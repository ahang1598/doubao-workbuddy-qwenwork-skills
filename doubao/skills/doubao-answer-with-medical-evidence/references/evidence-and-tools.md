# 证据与工具

本文件只负责来源优先级、检索工具、核验、证据日志、确定性和冲突处理。

已知信息明确需要立即行动时先直接给行动，不等待检索；如继续解释或生成完整文档，后续医学内容必须先完成检索和原文核验。其他回答不得先写结论再回填来源。未得到用户明确请求或同意时只交付简明回答，不因检索结果很多而自动创建文档。

## 1. 来源优先级

根据问题和适用人群优先使用：

1. 最新中国临床指南、国家/监管规范和相关全国性学会指南。
2. 与当前问题直接相关的中国专家共识；明确其共识属性和局限。
3. 与具体通用名、剂型、规格和人群匹配的药品说明书及监管安全信息。
4. 中国资料不足时使用国际权威指南，并说明地区和适用性差异。
5. 围绕整体核心结论或少量关键证据目标定向检索匹配研究：优先系统综述或 Meta 分析，没有合适综述时查关键随机试验、队列或诊断研究。

指南、共识、说明书和研究承担不同角色，不能互相冒充。说明书用于核对批准适应证、禁忌、警示、用法边界和特殊人群；指南用于解释临床路径和获益风险权衡；研究层用于核对指南方向是否仍适用，并补充直接疗效、伤害、预后和新证据。单篇研究不能轻易推翻更权威、更适用的指南。

### 指南层与研究层都要查

- 先查规范层，确定当前行动、适用条件和安全边界。
- 再查研究层，核对获益、风险、预后、诊断准确性或近期新证据。
- 简单、结论稳定的问题可只纳入一份最直接的高层研究综述；复杂问题再按证据目标增加必要研究。
- 某一层没有匹配的合格原文时，具体说明缺少哪类可核验依据，以及这会限制哪些判断；不为满足双层形式而引用低质量材料。

禁止把自媒体、营销软文、健康博客、问答社区、聚合转载、搜索结果页、新闻报道、第三方文档分享/下载文库、指南/共识二次解读或图解、PPT/课件/讲义/培训材料/会议幻灯或来源不明页面作为依据；低质量信源的这类内容尤其不得使用。它们只能用于定位原始来源，不能替代原文，不得进入回答、完整文档、证据日志或参考文献，也不得作为其他用户可见的引用链接。发布机构官网、同行评议期刊原文页或官方指南库中的正式最终版 HTML/PDF 仍是合格候选；按发布者、内容角色和正式发布状态判断，不按 URL 关键词、`.pdf` 扩展名或标题含“指南”机械判断。

征求意见稿、意见征求版、草案或其他尚未正式发布的指南、共识、规范，不得标记为正式来源，也不得支持患者结论或行动建议。搜索遇到这类页面时直接排除，继续查找正式最终版；找不到时具体说明没有核验到正式最终版，因此哪些判断暂时不能确定，不引用或展示草案。

### 一手来源硬门槛

- 指南、共识和规范：链接必须落到发布它的政府/监管机构、全国性专业学会、同行评议期刊原文页或官方指南库，并核对为已正式发布的最终版；机构不明的转载、镜像、下载站、第三方文档分享/下载文库、指南二次解读、PPT/课件/讲义、征求意见稿或草案不合格。即使解读页标注了指南名称、年份、页码或推荐原文，也必须转到并核验正式原文后才能引用；解读者新增的观点不得写成原指南推荐。
- 药品说明书与安全信息：优先监管机构或上市许可持有人官方原文，并核对通用名、剂型、规格和发布日期；商业药品库或科普页不能替代。
- 系统综述和研究：使用期刊出版页、DOI、PubMed/PMC、正式注册平台或研究机构原始页面；新闻稿和营销页面不能证明疗效。
- 打开链接后核对页面标题、发布机构、版本/日期与正文是否相符，并确认发布日期不晚于当前日期。搜索结果标题或摘要不能通过此门槛。
- 找不到可点击的一手原文时，改用适用的国际权威一手来源；仍找不到则自然说明尚未核验到哪类可靠原文，以及这对结论把握度的影响，不要引用镜像或二次材料来填空。

## 2. 固定工具顺序

1. 使用 `general_search` 检索最新版中国指南、本土共识、国家/学会规范和官方原文；不足时补国际权威指南。
2. 涉及药物时使用 `medical_search` 核对通用名、剂型、适应证、禁忌、特殊人群和重要警示；必要时再用 `general_search` 定位监管或官方说明书入口。
3. 围绕整体核心结论或少量关键证据目标，使用 `scholar_search` 查直接匹配的系统综述或 Meta 分析；没有合适综述时查关键随机试验、队列或诊断研究。同一组高质量来源能支持多个相关子问题时，不重复检索。
4. 使用网页读取、PDF 或 OCR 定向核验指南与研究原文的推荐/结果、适用人群、版本/发布日期、研究设计和安全边界。搜索摘要只用于筛选，不能替代原文核验。

若环境没有上述具体工具，使用同类的官方网页检索、医学数据库检索或原文读取能力；不得降低来源标准。没有合格原文或 http(s) 链接时，具体说明哪些依据没有完成核验、因此哪些结论仍不能确定，不要凭记忆补齐。

每轮检索只解决一个证据目的，例如“判断就医时限”“核对某药孕哺警示”“比较两种方案的获益风险”。在核心判断、适用边界和风险已清楚且没有重要冲突后停止扩展，避免堆文献。

## 3. 查询与核验

检索式至少包含问题核心、目标人群和版本/机构线索；药品检索必须使用通用名并核对剂型。对每个拟采用来源核对：

- 来源类型和发布机构。
- 标题、年份或版本、发布日期和正式发布状态；“最新版”必须通过当前检索确认，不能把征求意见稿、草案或未正式发布版称为指南/共识。
- 适用地区、适用人群、疾病阶段和排除条件。
- 直接支持的结论以及不能支持的结论。
- 原始 http(s) URL；不要从展示文本手抄无协议地址。
- 当前用户的病例适配与外推限制。
- 页面本身是否是一手来源，而不是把“转载自”“解读”“新闻”“科普”“文库”“PPT”“课件”误当原始指南、说明书或研究。

具名来源首次出现时就地使用 `[来源名称](https://...)`。URL 只作为链接目标保存，用户看到的链接文字使用来源名称或能说明去向的短语；不得只在文末放链接，不得直接显示裸 URL，也不得把 URL 本身作为链接文字。无法获得可点击一手入口的候选不得作为具名核心依据；用户只提供了第三方文库、指南二次解读或 PPT/课件/讲义时，继续查正式原文，找不到就具体说明正式原文尚未核验以及由此仍不能判断什么，不展示该候选的标题、结论或链接。用户要求“最新版”时还要核对当前日期前是否已有更新版，不能凭标题年份推断。

生成完整文档时，把已经核对过的病例适配和证据局限转成患者能理解的说明，紧邻第四、五章对应的具名来源。每条说明都要让用户看懂“这条证据为什么和我的情况或问题有关”。可以按内容使用重点块、独立一行、加粗短句或无序列表，不为统一版式重复同一套句型。

## 4. 从简明回答扩展为完整文档

简明回答已经完成规范层和研究层检索。用户随后明确要求生成完整文档，或在补充信息时同时提出生成要求时：

1. 复用本轮已经打开、核验且仍适用于同一问题的来源，不机械重跑相同查询。
2. 按七章需要补查尚未覆盖的指南条文、说明书安全字段、研究结果或人群适配；如果时间敏感信息可能已更新，重新核验版本。
3. 按需整理可选证据记录，帮助第四章说明规范层依据、第五章说明研究层依据、第六章收齐全文实际采用的可点击来源；该记录不是交付前置条件。
4. 如果某一证据层确实没有合格原文，在对应章节中明确检索局限；若本轮使用了可选证据记录，可按需同步记录。不得为填满七章降低来源标准。

用户只补充医学信息、没有明确报告意图时，不建立文档，也不为了预备文档扩展无关检索；先结合新信息继续回答。用户明确要求生成后，不再重复简明回答或再次询问。关键资料仍缺失时可以复用已核验来源生成条件化报告，但必须把证据适用条件、病例缺口和不能直接外推的内容写清，不以补齐七章为由提高确定性。

## 5. 可选证据记录

需要整理来源时，可以从 `assets/evidence-log-template.json` 初始化一份记录，用于避免遗漏来源及病例适配信息。不执行字段、格式、时间或完整性校验；字段按实际需要填写，不因为记录不完整阻断回答或文档交付。

有实际帮助时可记录：

- `source_type`：`guideline`、`consensus`、`drug_label`、`regulatory`、`systematic_review` 或 `key_study`。
- `title`、`organization`、`version_or_year`、`population`、`url`。
- `certainty`：用简短事实记录哪些依据、局限或冲突影响判断把握度；不预设用户可见的固定评级标签。
- `supports`：本来源直接支持的核心主张。
- `case_fit`：对应用户已经提供的哪些事实、直接回答哪个问题，以及有哪些不匹配或资料缺口。
- `limitations`：不能外推到哪里、尚缺什么。

证据记录不替代正文核验。进入用户回答或完整文档的具名来源仍须满足本文件前述的一手来源、适用性和链接要求；缺少某层合格证据时，如实降低确定性，不为补齐记录而伪造条目。

## 6. 自然说明判断把握度

根据现有信息和已核验证据自然说明判断的把握程度。优先说清现有信息更支持什么、支持它的关键事实是什么、哪些地方仍需确认，以及这些未知会怎样改变判断。不要把证据把握度做成固定分档，不使用固定评级标签或“标签：结论”的段首前缀；简单明确的问题无需单独标注证据强度。

把握度由来源权威性、与当前人群和问题的直接性、研究质量与数量、不同来源是否一致，以及病例关键信息是否完整共同决定。证据存在局限时，直接说明具体局限，例如研究人群与用户哪里不同、缺少哪类直接研究或哪项病例信息尚未确认；没有核验到合格原文时，说明未核验到什么以及因此不能确定什么；来源存在重要差异时，说明哪些来源在什么问题上不同，以及这会怎样影响当前行动。不要只给抽象等级而不解释原因。

仅当原始指南的推荐等级已从原文核验且对理解有实际价值时，保留其原等级并用普通语言解释。不要自行换算 OCEBM，不强制展示期刊分区或影响因子。

结论确定性不得高于其最关键依据；类似病例、单篇研究或机制推理不能提升指南或比较研究的证据等级。

## 7. 冲突与超说明书边界

指南、共识、说明书或研究不一致时，分别说明：

1. 各来源具体说了什么，以及版本、地区和人群。
2. 差异可能来自批准范围、发布时间、人群或临床路径，而不是强行合并成一个答案。
3. 是否可能涉及超说明书使用；没有核验时不得下结论。
4. 当前用户不能据此自行采取的动作。
5. 需要哪类医生或药师结合哪些资料、在什么时间内确认。

存在冲突时自然说明差异及其对当前判断的影响；除非能由更高权威且更适用的新来源明确解决，否则不能把冲突掩盖成单一确定结论。
