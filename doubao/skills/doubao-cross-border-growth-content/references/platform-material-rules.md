# Platform Material Rules

Choose platform rules before writing scripts or briefs.

| Platform / scene | Content logic | Material checks | Best outputs |
|---|---|---|---|
| TikTok Shop | Native, dynamic, product-in-use, creator-style commerce | avoid mostly static visuals; show actual product; match product listing; check content policy, live/video quality, creator authorization | short-video script, livestream script, Spark Ads brief, TTS/caption pack |
| Instagram / Facebook Reels | Vertical, mobile-first, safe-zone messaging, audio, fast first frame | 9:16 where relevant; avoid copyrighted music for ads; check boost/ad eligibility; keep key message visible | Reels script, UGC ad brief, static-to-video brief, cover and caption |
| Meta static / carousel | Fast visual proof, strong first card, product and offer clarity | catalog/PDP consistency; no unsupported claims; mobile legibility | static ad concepts, carousel copy, creative test matrix |
| Amazon Store / Posts / Video | Trust, product accuracy, site language, brand quality | primary site language; no external contact/URLs; no misleading claims; avoid aggressive urgency unless allowed | product video brief, Store tile brief, seasonal/gift angle |
| Google Shopping / Merchant Center | Accurate product image and feed/landing consistency | image must show actual product; no placeholder; size/file/background/product-occupancy requirements; feed diagnostics | product image brief, feed image checklist, landing-page creative |
| Shopify / DTC | Creative-to-landing-page match, trust, offer, brand differentiation | match PDP claims; clear shipping/returns if used; mobile readability; UTM naming | landing creative brief, ad image/video brief, email/social content |
| Shopee / Lazada / AliExpress / Ozon | Local marketplace detail content, promo mechanics, language, live/short video | site language, local price/units, promo claims, logistics claims, platform media specs | detail image brief, local promo creative, livestream script |

## Output-Specific Checks

| Output | Check |
|---|---|
| Short video | hook in first 1-3 seconds, scene sequence, product demo, subtitle language, CTA, no unsupported claims |
| Livestream | host role, product order, demo flow, interaction prompts, objection handling, offer wording, compliance notes |
| TTS/voiceover | local language, pronunciation notes, pacing, subtitle alignment, not a literal translation |
| Main/product image | product fidelity, background, size/ratio, product occupies enough frame, no extra unreceived accessories |
| Selling-point image | evidence-backed claims, mobile legibility, local language, no prohibited overlays for the platform |
| Creator brief | deliverables, must-show, must-say, no-go claims, usage rights, whitelist/Spark/Partnership authorization, tracking |

## Platform Mistakes To Avoid

- Using TikTok-style lo-fi storytelling for Google Shopping feed images.
- Using Google product image rules as if they were UGC video rules.
- Adding urgency, price, external URLs, or claims to Amazon creative without checking policy.
- Producing a beautiful image that changes the product, color, accessories, package, or material.
