# Creator Brief

Use this for UGC, KOL/KOC, influencer, affiliate, Spark Ads, Partnership Ads, and whitelisting-ready content.

## Brief Template

| Field | Content |
|---|---|
| Product | name, category, what buyer receives |
| Market | country/site, language, audience |
| Goal | awareness, education, conversion, Spark/ads, review seeding |
| Required scenes | unboxing, demo, close-up, use case, result, CTA |
| Must say | only verified claims and product facts |
| Must show | product, size, included accessories, key use |
| No-go | unsupported claims, unsafe scenes, competitor logos, copyrighted music/IP, misleading before/after |
| Tone | native, casual, premium, practical, humorous, etc. |
| Deliverables | count, length, ratio, raw footage, edited version, captions, cover |
| Usage rights | organic only, paid ads, whitelisting, Spark/Partnership authorization, duration, regions |
| Tracking | UTM, discount code, affiliate link, content ID |
| Review process | draft review, compliance check, revision count |

## Creator Selection Fields

| Field | Why |
|---|---|
| Audience geography | avoids reach outside target market |
| Category relevance | better trust and demo quality |
| Content style | must match platform native expectations |
| Engagement quality | comment quality beats vanity likes |
| Commerce history | indicates ability to sell, not only entertain |
| Usage rights willingness | required for paid amplification |

## Evaluation

- Content quality: hook, product clarity, demo, authenticity.
- Sales readiness: CTA, tracking, product card/link, offer accuracy.
- Risk: claims, music, IP, disclosure, usage rights.
- Reuse potential: can this become Spark/Partnership/Meta/TikTok ad creative?
