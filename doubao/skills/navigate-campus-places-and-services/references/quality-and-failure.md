# 质量门禁与失败处理

## 交付前检查

1. **范围**：主目标确实是高校校内地点或办事导航。
2. **学校**：学校全称已确认；同名学校、分校和独立学院已消歧。
3. **校区**：校区会改变答案时已确认，否则明确未知。
4. **来源**：每个关键结论有原始来源；搜索摘要不是证据。
5. **时效**：活动、报名、社团临时地点和考试安排绑定日期、批次或场次；来源未给日期时标记 `unknown`，
   不得编造。动态来源只有在其适用日期、截止时间、批次或场次仍覆盖用户请求时才允许支撑当前结论。
6. **层级**：校区、楼宇、楼层和房间分别标记，不把楼宇定位冒充房间定位。
7. **功能**：常设用途与本次事件用途分开。
8. **地图**：地图只支持空间事实，并已标注第三方路线风险。
9. **隐私**：没有复述或搜索无关个人标识。
10. **状态**：`verified`、`verified_with_caveat`、`partial` 或 `unresolved` 与证据一致。

## 常见失败与处理

| 失败 | 不要做 | 正确处理 |
| --- | --- | --- |
| 学校未知 | 猜测用户学校 | 只追问学校全称 |
| 多校区同名建筑 | 任选一个校区 | 追问或展示候选及差异 |
| 只有搜索摘要 | 直接引用摘要 | 打开原始页；打不开则降级 |
| 只有旧通知 | 当作当前安排 | 标注日期，继续找更新来源或设为 `verified_with_caveat` |
| 登录墙 | 绕过登录或声称已读取 | 给出入口、责任部门和公开信息边界 |
| 社团活动地址 | 当作常驻办公室 | 绑定活动日期，标为临时地点 |
| 报名点已过期 | 仍描述为可报名 | 标注已截止，寻找当前批次 |
| 教室代码无映射 | 按字母数字猜楼层 | 保留原文并标记未解析 |
| 地图只找到楼宇 | 编造房间路线 | 终点停在楼宇，楼内信息用第一方来源 |
| 官方来源冲突 | 静默拼接 | 比较适用范围并显式列出冲突 |

## 降级输出

无法完整回答时，仍可输出：

- 已确认的学校、校区、责任部门或楼宇；
- 官方入口、校园地图或公开咨询方式；
- 尚未确认的字段及原因；
- 用户下一步最小行动，例如提供完整地点原文、当前通知或向哪个部门确认。

不要用“应该是”“大概在”掩盖证据缺失。
