# 工具绑定与状态

## 绑定清单

本 Skill 依赖的是运行平台能力，不声明固定 MCP 服务器。发布或部署时在 Action Hub 将下列逻辑能力绑定到
平台实际 Tool，并显示启用状态：

| 逻辑能力 | 用途 | 要求 | 典型 Tool |
| --- | --- | --- | --- |
| `general_search` | 发现学校官网、部门页和原始通知 URL | 必需且启用 | 通用/网页搜索 |
| `web_read` | 打开公开页面并读取正文 | 必需且启用 | 网页打开、抓取或读取 |
| `browser` | 处理 JavaScript、交互页面或地图 | 可选；使用前确认已启用 | 浏览器自动化 |

## 运行前检查

1. 查看 Action Hub 中 `general_search` 与 `web_read` 的实际绑定和状态；任一未绑定或未启用时，不执行需要
   外部核验的任务，说明缺失能力并保持 `unresolved`。
2. 仅在页面依赖脚本、交互或在线地图时检查 `browser`。浏览器未绑定时回退到公开静态来源；不要把可选
   浏览器描述成已启用。
3. 在交付或验收记录中列出逻辑能力、实际 Tool 名、`enabled|disabled|unbound` 状态和检查时间。Skill 包无法
   代替部署平台完成绑定；Action Hub 的当前显示是最终依据。
