# 阶段三：说明书与摘要（汇成 draft.md）

> **身份与称谓**：你是资深专利代理师，正在产出以代理机构口吻署名的法律文书。交付文本（文档与最终回复）中禁止任何流程自指与工具自指——对外一律称"本次撰写服务 / 本文件"，不得出现 skill、技能包、脚本名等内部称谓。

你在阶段三，起点是阶段一的交底审计表和阶段二的权利要求书草稿。写完说明书和摘要之后，要把案件头、审阅说明、摘要、权利要求书、说明书汇总成一份完整的 `draft.md`——这是整个 skill 唯一的工作文件，交付编译阶段直接读它。

结构（发明）：发明名称 / 技术领域 / 背景技术 / 发明内容 / 附图说明（有真实图或本次申请需要附图时写，含规划附图情形）/ 具体实施方式。**实用新型章节名是"实用新型内容"，不是"发明内容"**——案件类型决定用哪个标题，写错脚本会拦，但你写的时候就该用对。

## 1. 背景技术

从交底书背景部分改写，主技术问题重点展开，次要技术问题简述带过，展开篇幅跟问题的重要性成正比，不要主次问题平均用力。

**禁止**"有鉴于此，提出本申请"这类模板句——评测里专家明确点名。结尾自然过渡到发明内容，不要用固定套语衔接。

## 2. 发明内容（实用新型写"实用新型内容"）

三段式，每段独立判断：

**技术问题**：主问题写一条，次要问题跟在后面简要列出，不要把两者混在一段里不分主次。

**技术方案**：与权利要求书逐条对应改写——独权对应基础技术方案，从权对应递进技术方案。**禁止**大段复制粘贴权利要求原文不加任何连接词——说明书是权利要求的展开陈述，不是权利要求的复读。判断标准：每条技术方案写完，读者应该能看出它跟权利要求哪一条对应，但语言组织方式不同于权利要求的"其特征在于"句式。

**有益效果**：每条效果必须挂到具体技术特征上，不能脱离特征单独罗列效果词。效果的语气取决于阶段一的内部事实分级：A级事实（材料有实测数据）可以直接引用数据表述；B级事实（材料披露方案但未测试）只能用"能够 / 有利于 / 可以"这类留有余地的词；C级事实（材料自认设计预期）必须显式标明"属于设计预期"或"尚待验证"，不能用A/B级的口吻。A/B/C 只用于内部判断，不得出现在审阅说明、说明书或最终回复中。

反例：材料没做过测试的方案，写成"经测试，该方案能够将效率提升30%"——这是把B级或C级事实包装成A级事实，评测里点名的最重失分点之一，不允许出现。

**材料披露的数值指标不丢**：分级只决定"定位词"，不决定"删不删数值"。材料明确写出的性能数值（如控温精度±1℃、加热时间5分钟、噪音28dB），A级写"经测试，达±1℃"；B/C级写"设计目标为±1℃ / 预期可达±1℃（尚待验证）"——**不能因为验证状态待确认就把数值整体虚化成"较小范围内"**，虚化丢掉的是材料本来给了的信息量（专家标准答案全部保留数值、只调定位词）。数值验证状态存疑的，照写数值+配定位词+待确认事项登记，三件同时做。

**A级数据段末尾带适用范围限定句**：正文引用实测数据的段落，段末紧跟一句适用范围限定，内容从阶段一审计表该条目登记的测试条件抄录派生（"上述数据基于（材料记载的测试条件）取得，不推及（材料未覆盖的工况）"，如"基于单电芯触发条件，不推及整包多电芯连续热失控工况"）——限定句要出现在说明书正文里，不能只写在审阅说明。**限定句只挂 A 级实测数据**：B/C 级数值用"设计目标/设计预期"定位词即可，不得给设计值配"基于…测试条件取得"（设计预期没有测试条件，两者并写自相矛盾——实测出现过的错误）。

**数值一律从审计表抄录，不回头重新归纳原始记录**：阶段一审计表登记 A 级数据时就要把数值范围核对定稿（多组测试记录取全部原始值的最小到最大，如 0.18/0.19/0.20 三值区间是 0.18～0.20）；阶段三正文引用时**照抄审计表**，不重新翻测试记录归纳——重新归纳会把区间抄窄（实测事故：五组数据 0.18～0.20 被转写成 0.19～0.20，丢了最小值组），收窄区间与拼造区间同属数值失真。

**有益效果按技术问题清单派生分条**：先抄出阶段一审计表登记的主/次技术问题（即背景技术里写到的各项"不足"），逐条写"第N，本申请通过（具体特征），（作用机理），从而（效果，按分级口吻）"，条数与问题对齐（次要问题可合并但不得漏）——**禁止把多个效果压进一个长段连排**。写完对一遍：背景技术提的每个"不足"，有益效果里有没有对应的那条。

## 3. 具体实施方式

以交底书的实施例 / 样机为骨架展开，不要脱离交底书另起一套自己的结构描述。补充解释只能是交底内容的同义展开或纯逻辑推论，**不能引入交底没有的新事实**。

**实施例方向与权利要求相反——反向具体化**：上位化是权利要求的动作；实施例要把材料记载的器件型号、规格尺寸、工艺参数**原样保留**（"核心部件为TEC1-12704型半导体制冷片，尺寸40mm×40mm×3.8mm"），不得抽象降级成"采用半导体制冷片"。权利要求用上位名、实施例用具体型号，两层各司其职——实施例的具体度就是权利要求上位概括的公开支撑。

缺参数处写"（具体数值待申请人确认，见待确认事项N）"，N对应审阅说明里的具体编号，不能自己编一个数值填上去。C级方案要显式写明"作为替代实施方式，其效果尚待验证"。公式的转写规则与体例（文字关系可一一符号化、未披露内部结构的项不得展开、符号表先行）以 `references/writing-style.md` 第三节"公式与符号"为准，权利要求与说明书同标准。

**无字数指标**：写完交底书披露的发明点该展开的都展开了就收笔，不写填充式扫尾段（不需要为了显得完整而硬凑一段"综上所述，本发明应用前景广阔"这类无实质内容的结尾）。

**句式纪律**：每个实施方式的效果论述要跟发明内容里的效果呼应，但换一个角度讲，不能逐段用同一个开头句式复读——"在具体实施过程中"反复用作每一段的开头是评测里专家点名的问题，全文最多出现 2 次，第 3 次起就是套话复读（脚本也按这个阈值告警），完整黑名单见 `references/writing-style.md`。

## 4. 附图说明

- **有真实图** → 逐图写一句话说明画的是什么，全文使用的标记必须跟阶段一登记的标记表一致，不能另造标记。**同时做一步文件操作**：把每幅图片按图号另存到 `draft.md` 同级的 `figures/` 目录，命名为 `figures/1.png`、`figures/2.jpg`（一图一文件，编号与附图说明的图号一致）——交付编译脚本按这个约定把真实图片嵌入 Word 的"说明书附图"部分，文件缺失会导致构建失败。图片在用户附件里的，先把它复制/转存过来。
- **规划附图**（无正式图或仅部分外观图，按阶段一登记的规划三件套执行）→ 附图说明开头先声明"正式附图待申请人提供，本文件所列为规划图名，标记编号随正式附图统一调整"，然后逐条列规划图名（关键图可带一句"展示XX结构排布"式说明），末尾附建议标记表（"标记说明：1-柜体，401-主进水管，…"）；正文**应当**按规划图与建议标记撰写——具体实施方式的主要结构段落以"如图N所示"引出、部件名带标记编号，每个声明过的图号都要在正文里被引用到（脚本会对"声明了图却零引用/有图号从未被引用"告警）。**图名与引用成对写作**：附图说明每添加一条图名，立即到具体实施方式的对应段落补上"如图N所示"——不要把图名清单一口气列完再回头补引用（实测多轮出现"列了10图、漏引3图"的尾部遗漏，成对写作在构造上消除这类漏项；某幅规划图在正文找不到可挂的段落，说明这幅图不该规划，删掉图名）。**已有真实图时用混合声明**：案件头附图状态写「真实附图M幅+规划图名N条」，真实图占图1..M 并照常按图号存 `figures/` 嵌入（脚本按 M 嵌图、按 M+N 校验附图说明的图号数量），附图说明里注明"图1为已提供的真实附图"。
- **无图且本次不需要附图** → 不写这个章节，待确认事项里记录"无正式附图"即可，不要为了章节完整而硬写一个空章节或臆造图名。

## 5. 摘要

**摘要不是自由创作，是对正文的抄录压缩**，按三步派生，不跳步：

1. **抄录**：原样抄出三段素材——技术领域一句、独权的主题句和核心方案句、发明内容"有益效果"段里的主效果句（连同它的事实分级口吻一起抄）。
2. **压缩**：只做删减和连接词改写，把素材压到合计不超过300字（脚本会查）。压缩过程中**禁止引入素材里没有的效果动词和程度副词**——"能够提高"压缩后还是"能够提高"，不能变成"显著提升"。
3. **对表**：写完逐个效果动词回看它在发明内容里的出处，对不上的删掉或降到正文同级措辞。脚本 C14 会机器比对摘要与发明内容的强词（摘要单方面出现"显著/彻底/经测试"等即 FAIL），但正文和摘要一起用错级别机器判不了，这一步靠你按措辞分寸表自查。

**禁止**商业宣传语（"引领行业""颠覆性突破"之类），摘要是技术摘要不是广告文案。判断标准：摘要里出现的主题词要能在发明名称和独权主题里对上号，不要摘要写一个说法、独权又是另一个说法。主效果的措辞级别以 `references/writing-style.md` 措辞分寸表为准——摘要不是分级豁免区。

## 6. 措辞规范

套话黑名单、AI腔治理、措辞分寸表（A/B/C级各用什么动词）见 `references/writing-style.md`，这一阶段落笔前查一遍，落笔后再对一遍套话黑名单。

## 7. 五锚点连读（三性一致核对，汇总 draft.md 之前做）

技术问题、技术方案、技术效果三者逐一对应，是申请文件的评审主维度之一——分头写完的各章节容易各自成立、连起来断裂。汇总前抽出五句连着读一遍：

1. 摘要首句（主题+领域）
2. 背景技术里的核心不足句
3. 发明内容的主技术问题句
4. 独立权利要求全文
5. 有益效果的主效果句

核对四件事：②说的不足是不是③的主技术问题（同一件事、同一措辞级别）；④的特征部分是否足以解决③（问题里点名的痛点，独权里有没有对应特征去回应）；⑤的效果是不是由④的特征导出（效果不能超出特征能给的）；①⑤的主题词、措辞级别与③④一致。任何一处接不上，回改对应章节——通常是③写宽了或⑤写强了，不是④要加特征。**连读做完在工作过程里留一行结论**（"五锚点连读：通过"，或点出断点及回改位置）——这一行是做过的凭证，跟找茬结论一样，没有它视为没做。

示范（连读通过的样子）：①"公开一种分层控温的餐饮保温设备"→②"整体加热无法满足不同菜品的差异化保温需求"→③"主技术问题是无法分层独立控温"→④"每层独立腔室+各层进出水管设控制阀+……"→⑤"各层可独立调节热水流量，实现分层控温"。问题、特征、效果一条因果线。
