# 论文骨架设计

骨架不是章节名称的集合，而是读者接受论文核心判断前必须经过的论证路径。不要先套目录。先确定论文承诺什么、材料能支持什么、各项判断依赖什么，再翻译成章节。

## 一、首次执行只走六步

1. **冻结任务**：确认用户要分级提纲、详细蓝图、草稿重排还是章内蓝图。用户措辞跨类时按其要求的展开度就高判定；只涉及整篇某一部分（如学位论文的某几个主体章节）时，按该部分的章级粒度交付，并说明其余部分另置。
2. **确定主张上限**：根据材料状态决定只能提出问题、设计验证，还是可以写已有发现。
3. **选择主推理路线**：验证、估计、解释、综合、整合、理论建构或决策。
4. **组装论证单元**：为每个主要判断配材料、推理、边界和前后依赖。
5. **按依赖排序**：读者必须先知道什么，后面的判断才能成立。
6. **翻译成章节并反查**：给每章一个不可替代的任务，删除重复和无材料章节。

六步是内部工作流。用户只要提纲时，不打印任务卡、证据表和检查过程。

## 二、冻结任务与主张上限

在内部确认：

| 字段 | 内容 |
|---|---|
| 交付物 | 提纲、蓝图、重排方案或段落蓝图 |
| 论文阶段 | 想法、设计、材料、结果或完整草稿 |
| 目标文本 | 期刊、学位论文、课程论文、综述、案例或政策分析 |
| 目标读者 | 学科同行、跨学科读者、课程评阅者或决策者 |
| 研究边界 | 对象、分析单位、时间、地点、样本或语料范围 |
| 用户材料 | 数据、实验、访谈、史料、文献、政策、案例、已有结果 |
| 用户点名内容 | 必须进入主体的变量、主题、理论或材料 |
| 外部约束 | 目标语言、期刊、字数、学校模板、报告规范 |

能在不编造的情况下给出带边界的骨架就直接完成。只有不同答案会改变整条结构时才询问。

目标期刊的字数、栏目和固定顺序，只有用户提供或通过官方来源核实后才能写成硬要求。用户要求“基于现有文献、核心期刊、最新研究”来决定骨架时，先判断所需范围：只需支撑研究定位和章节逻辑时，使用可用检索工具定向核实少量关键来源，明确检索范围、来源身份及每项来源能支持什么；需要摸清整个方向、系统综述或穷尽式检索时转外部文献调研能力。无法完成所需核实时，明确阻塞文献性结论，只给不依赖具体文献共识的任务型骨架，不凭记忆生成作者年份、共识或研究空白。此时仍可交付不依赖文献的结构骨架，并说明文献层需用户另行提供材料或转外部文献调研补齐，不因无法完成文献层而拒绝交付整个结构。

材料状态决定标题和章节能说多满：

| 当前材料 | 允许 | 禁止 |
|---|---|---|
| 只有想法 | 问题、比较目标、待验证命题、所需证据 | 已发现、证明、显著提升 |
| 有设计无结果 | 方法、实验顺序、分析计划、判定标准 | 最优参数、机制成立、优于现有方法 |
| 有材料未分析 | 材料说明、计划分析、竞争解释 | 把预期趋势写成结果 |
| 有真实结果 | 与结果一致的发现和解释候选 | 超出范围的因果或普遍结论 |
| 有史料/访谈 | 有材料支撑的解释及反例 | 虚构引语、人物属性、行为或史实 |
| 有完整草稿 | 保留核心论点后重排 | 借重排改成另一篇论文 |

没有结果时用任务型标题，不用结果型标题。

材料落在相邻两档之间时（如已有方向与候选方案但设计未锁定、已指定理论但材料尚未采集、实践已运行但未提供运营数据），就低取较严的一档定主张上限，把未锁定的设计、待采集材料和未测成效写成任务型占位或待验证命题，不按更满的一档预写结果。

## 三、选择主推理路线并锁定承诺

论文类型是外壳，主推理路线决定骨架。选一条主路线，其余只能辅助。多条路线看似都适用时，按论文要回答的核心问题选主线：问为什么或如何发生走解释与过程追踪，问差异关系或数量走描述与估计，问概念如何重构走理论建构，其余只作辅助或框架约束。

| 主路线 | 核心问题 | 常见研究 |
|---|---|---|
| 验证或构建 | 设计是否成立，怎样实现和验证 | 实验、工程、算法 |
| 描述、比较或估计 | 有什么差异、关系或数量特征 | 定量实证、测量、预测 |
| 解释或过程追踪 | 为什么发生，过程和条件是什么 | 质性、案例、历史 |
| 综合或重分类 | 现有知识怎样关联、分歧在哪里 | 综述 |
| 多证据整合 | 不同数据怎样共同回答问题 | 混合方法 |
| 概念或理论建构 | 怎样重新定义、连接或解释概念 | 理论论文 |
| 决策或建议 | 按什么标准选择什么行动 | 政策、实践案例 |

选定后在内部写两句话：

> **论文承诺**：本文使用[材料/方法]回答[核心问题]，目标是建立[主张层级]的判断。

> **不作主张**：基于当前材料，本文不声称[无法识别的因果、未验证机制或不能外推的结论]。

后续章节必须服务论文承诺并遵守不作主张。用户要求一句红线时，把论文承诺改写成自然的一句话。

## 四、组装论证单元并排序

先形成三至七个论证单元。每个单元在内部写成：

> 功能 → 问题/主张 → 材料 → 推理 → 边界 → 前后依赖

每个进入正文的主要部分都要回答：

1. 读完后，读者多知道了什么？
2. 哪些材料支撑这个判断？
3. 材料怎样通向判断，中间是否缺环？
4. 还不能推出什么？
5. 为什么必须放在当前位置？

用户指定理论时，额外建立“理论概念 → 可观察材料/变量 → 分析动作 → 可支持解释”映射。无法对应材料的概念只作背景，不为体现理论完整性强行设章。“尚未采集”不等于“无法对应”：原则上可操作化、只是材料待采集的概念，按上节相邻两档之间的处理写成待采集映射留在正文，不因当前没有材料就降为背景。

以下证据纪律适用于所有路线，不限于某一学科：跨来源或跨时段材料先确认口径能否在目标单位与时间上对齐，无法对齐时前置约束并降低主张层级；以阶段或趋势作论点时，阶段须由跨时段材料本身产生，不把少数案例或起止不齐的序列外推为整体阶段。

按依赖关系而非工作时间排序：

- 对象和问题先于方法。
- 概念先于测量、编码或比较。
- 数据和分析单位先于结果。
- 设计原理先于组件或参数优化。
- 基本事实先于分解、机制和情景推演。
- 证据先于解释，解释先于推广。
- 比较标准先于方案比较，比较结果先于建议。

每增加一章都问，删除它后哪个后续判断无法成立。答不出的章节应合并或删除。

## 五、路线卡

路线卡是判断工具，不是固定目录。

### 1. 实验、工程与技术

先判定工作属于概念验证、性能比较、参数优化、机理研究、测量表征、预测建模还是系统设计。

- 电化学、催化和反应工程任务先冻结目标半反应、电子数、反应物与产物所在界面、主要竞争反应、产物降解或跨越路径及质量守恒。装置、膜、电极和催化层的比较必须回到这些反应与传输量，不能只列材料和性能指标。
- 双极膜、多层离子膜或异质结任务必须先画清阴阳极位置、各选择层的朝向、外加场方向、界面反应及每种载流离子的迁移方向，再写局部pH机制。要区分“膜堆配置在电极侧形成的环境”和“界面水解离产物沿电场迁移”两种解释；方向未经守恒关系和权威来源核实，不得写成目标机理。
- 新架构常按“问题与设计要求 → 原理 → 关键组件 → 系统集成 → 性能与失效证据 → 机制/边界”推进。
- 参数优化先验证基线，再安排决定可行性的一级变量，之后处理依赖变量，性能成立后才安排机制和外部验证。
- 分类变量与连续变量可能交互。材料种类、厚度、构型和工艺不能默认串行单因素优化，应根据依赖采用交叉、嵌套或分阶段设计。排序的最高判据是“是否决定可行性”：决定可行性的变量先排，无论它是分类还是连续；可行性确立后，再按分类外层、连续内层嵌套优化，疑有交互时用交叉子集验证。
- 用户提出多个方向时，先判断它们是互斥方案、互补组件、先后步骤还是不同层级。判据是能否同时施加、是否共享同一控制变量、是否改变同一物理量；材料不足以判定时按最可能的关系搭建并标注待用户确认，不擅自定为互斥或串行。
- 算法论文常按“任务与数据 → 基线 → 模型 → 公平评估 → 消融/误差 → 边界”推进。

研究只做表征、测量或工程实现时，不强行补机制、消融或普适性章节。没有真实结果时不填写最优值、性能、测试时长或核心发现。

### 2. 定量与社会科学实证

先判定任务是描述、测量、预测、关联、因果效应还是结构建模。所有实证研究先统一：

> 对象 + 分析单位 + 时空范围 + 暴露/核心变量 + 结果变量 + 比较对象 + 允许的主张

常见路径是“问题 → 制度/理论 → 数据与单位 → 测量 → 分析设计 → 基本事实 → 主分析 → 必要的稳健性/机制/异质性 → 边界”。

- 所有估计任务都要说明目标量；因果或结构任务还要明确识别假设以及保护这些假设的稳健性检查。
- 描述不伪装因果，预测精度不等于机制，分解残差不能自动命名为机制。
- 不按方法名称预设证据等级。准实验不自动等于结构参数，结构模型也不自动具备因果性或外推效度。
- 稳健性、机制、异质性只在保护核心判断或回答研究问题时设置。
- 跨数据源研究先解决样本、变量定义和统计口径能否在目标单位上对齐。无法对齐时，约束应前置并降低主张层级。

### 3. 质性、访谈与过程研究

先判断目标是经验描述、意义理解、过程解释、理论生成还是案例比较。通常围绕问题和目标组织，不强行提出方向性假设。

常见路径是“现象与问题 → 情境和研究者位置 → 案例/参与者与材料产生方式 → 分析步骤 → 主题或过程发现 → 关系/反例 → 理论解释与边界”。

- 按主题依赖、阶段转折、研究问题或重要性选择发现顺序。
- 阶段模型必须由跨时材料产生。阶段可以重叠，家庭或案例可以走不同轨迹，不把少量案例外推为全国阶段。
- 每个主题需要材料锚点、内部差异或反例。
- 不虚构访谈原话、人口属性、编码频率、招募过程或田野细节。

### 4. 历史与人文

先确定论文是在解释变化、重新分期、比较案例、重释文本、追踪概念，还是修正既有叙事。

常见路径是“研究问题与史学争论 → 时空/概念边界 → 史料基础与来源批判 → 分论点/阶段 → 反证与竞争解释 → 回答”。

- 时间变化本身是论点时按阶段，多个因素解释同一结果时按机制，不同地区或行动者需要比较时按统一维度。
- 不按航运、沉船、馆藏等史料类型各设资料仓库式章节；用多类史料共同回答问题。
- 制度文本只能证明规则和话语，沉船、馆藏、报刊、统计和私人记录都是有偏代理。
- 不能先决定“衰落其实是转型”再挑材料证明，也不用现代价值替代历史语境。

草稿重排时可抽取每段首句形成反向提纲。主题在时间、对象或解释层面来回跳转时，说明顺序仍需调整。

### 5. 文献综述

先判断是论文内综述，还是独立叙述综述、系统综述、范围综述、整合综述或元分析。

- 系统综述和元分析呈现检索、纳排、筛选、偏倚和综合方法；叙述综述不伪装系统检索。
- 论文内综述只保留支撑研究问题、理论和方法定位的内容。
- 主题决定分歧时按主题，方法决定结论时按方法，观点演变明显时按时间，理论阵营决定关系时按争议。
- 不按方法名称排列证据高低。比较的是研究对象、识别来源、估计对象、假设、情境和可支持主张。
- 每节综合多项来源的共识、分歧、方法和边界，不一篇文献一个段落。
- 研究空白从综合结果推出，“研究较少”本身不是贡献。

### 6. 混合方法

骨架由设计类型决定，不能把定量论文和质性论文前后拼接。

- 汇聚式设计并行呈现后明确整合。
- 解释型顺序设计先定量，再用质性解释特定结果。
- 探索型顺序设计先质性，再开发变量、工具或定量检验。
- 嵌入式设计以主方法为骨架，辅助方法只解决子问题。

方法、结果和讨论顺序应镜像研究设计。必须说明两类证据在哪里一致、分歧或互补，以及整合后产生了什么单一方法无法得到的判断。

### 7. 概念与理论

先判断属于理论综合、理论迁移、概念澄清、类型学、概念模型/命题，还是既有理论修正。

常见路径是“共同认识 → 现有解释的矛盾 → 理论/概念选择及角色 → 重新定义或连接构念 → 模型/类型/命题 → 理论增量 → 边界与可检验含义”。

理论选择必须解释“为什么是它”和“它在分析中做什么”。图示、命题和正文推理逐一对应，不能把概念论文写成描述性综述。

### 8. 案例、实践与政策

先区分任务：

- **学术案例**：“案例边界和问题 → 选择与材料 → 情境 → 分析框架 → 案例内证据 → 解释 → 可迁移条件”。
- **管理实践案例**：“现实问题 → 原流程和约束 → 实施决策 → 运行证据 → 作用机制 → 局限与复制条件”。
- **政策分析**：“问题和受众 → 现状证据 → 备选方案 → 评价标准 → 同标准比较 → 推荐 → 实施风险”。

单个案例不自动提供普遍性。“领先、首家、显著提升、根本解决”必须有可核实证据。SaaS、AI等技术名词不能替代流程变化和实际效果。用户“体现领先性、贡献”等诉求本身缺可核实证据时，不替其坐实，改写为“在何条件下改变了什么、相对原状况有何不同”的可核实表述与可迁移条件；面向行业或实务期刊可调整行文，但不降低“未经证实不写成事实”的底线。政策研究若目标是解释机制而非选择方案，应改走实证或过程解释路线。

## 六、报告规范只做完整性检查

报告规范说明该设计必须交代什么，不替作者决定论证主线。先确定研究设计，再按需查CONSORT、STROBE、PRISMA、STARD、CARE或JARS。期刊、学校或课程模板优先。

## 七、翻译成章节并审查

章节标题描述当前任务，不抢先宣布未经证实的结果。每个一级章节只承担一个主要功能；二级标题拆分不同证据、步骤、比较维度或分论点。

详细蓝图中，每个一级章节写清：

1. 论证任务。
2. 主要材料。
3. 与下一章的关系。

交付前检查：

- **承诺**：引言的问题在后文有方法和回答，只有一个主要贡献主线。
- **证据**：每个分论点能指出材料，没有补造实验、访谈、史实、政策、引用或数据。
- **推理**：分析单位、方法和主张层级一致，相关、预测、分解、机制和因果没有混写。
- **顺序**：每章依赖前文并为后文准备，相邻章节不重复，理论在分析中真正使用。
- **负荷**：篇幅按论证任务分配，材料不足的内容不独立成章，次要检验进入附录。

## 八、输出合同

- **分级提纲**：直接给题目和指定层级标题，必要边界用短括注。
- **详细蓝图**：先给一句论文主线，再给分级结构；每个一级章节用一段连贯说明交代功能、材料、必要边界和承接，不把这些内容拆成每节重复的“任务、证据、边界、过渡”字段。用户明确要求逐节列出证据、过渡或字段化蓝图时，按其要求展开，不再受本条限制。
- **结构诊断**：先定位最影响论证的断点，再给重排方案。
- **章内蓝图**：按段落功能列问题/主张、证据、推理和承接，不代写正文。

交付分成两层：

1. **核心骨架**：研究对象、论文承诺、章节顺序、每章任务和关键过渡，始终优先。
2. **审计附录**：证据矩阵、图表计划、风险清单、must-not-argue、kill criteria等只在用户明确要求或当前风险确实触发时提供。

控制长度和拼凑感：

- 普通分级提纲通常控制在中文1200至3000字或英文800至1800词。
- 用户只说“先勾勒”“先给框架”或“先搭大纲”时，详细蓝图通常控制在中文1800至4000字或英文1200至2200词。只有用户明确要求逐节证据、过渡、矩阵、kill criteria或接近写作说明书的蓝图时，才扩展到中文7000字或英文3500词。该字数是常规上限而非硬顶；交付项与子节数确实很多时，先以“每子节字段简至一行、同类信息集中一处”压缩，压缩后仍显著超出的分块交付并标明第几块，不为守字数牺牲用户明确要求的逐节完整性。
- 默认只展开到二级标题。只有变量、步骤或分论点确有独立依赖时才使用三级标题，不为让结构显得完整而细分。
- 详细蓝图中，一级章节通常含二至五个二级部分；同一章节内只有真实并列的材料、步骤或指标才列点，其余写成短段。若大多数标题下只有一两句或都跟着同构列表，说明切分过细，应合并。用户明确要求逐小节字段化蓝图时，此项同样不适用。
- 详细蓝图完成后做一次密度检查：包含说明文字时，平均每个标题应承载约120个中文字符或80个英文词以上。低于该密度不自动补字，而是优先合并标题和重复清单。用户明确只要标题式提纲，或明确要求逐小节字段化蓝图时，不适用此项。
- 同一信息只出现一次，不在主线、章节说明、图表计划和风险清单中反复改写。
- 过渡理由集中说明，除非某一节的顺序存在争议，不在每个小节重复“为什么放这里”。
- 标题优先使用当前学科的研究对象和论证动作，不机械复用“红线、主张边界、证据门槛”等跨学科同构标题。
- 只输出当前材料实际触发的风险，不默认附完整禁止清单。

只有缺少决定结构的材料时才列待确认项。不要默认输出评分或写作教程。
