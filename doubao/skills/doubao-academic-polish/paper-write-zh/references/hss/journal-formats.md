# 目标期刊格式核实协议

本文件不保存《中国社会科学》《经济研究》或其他期刊的静态格式模板。投稿要求会变更，
把作者信息、匿名要求、引用体例、篇幅和图表数量硬编码在Skill中，会让豆包在规则更新后
继续生成错误稿件。

## 启用条件

只有用户明确指定目标期刊，且当前任务已打开该期刊的官方投稿须知、格式模板或投稿系统
说明时，才启用期刊专属格式。二手转载、往年经验、其他期刊范文和模型记忆都不能代替
当前官方要求。

用户未指定期刊时，依次使用用户提供模板、学校或课程模板、通用学术格式。不得按学科
自动套用某一标杆期刊。

## 冻结格式合同

在写正文前，把已核实要求整理为当前任务的格式合同，并记录来源URL、页面标题和核实日期。
只冻结官方页面明确规定的字段：

|字段|需要记录的内容|
|---|---|
|稿件类型|研究论文、综述、评论、书评等|
|匿名要求|正文、文件名、致谢和元数据是否需要去作者信息|
|语言组件|中英文题名、摘要、关键词是否必需|
|篇幅|总字数及各部分限制，未规定则留空|
|标题层级|允许层数和编号方式|
|引用体例|正文标注、脚注或尾注、文末参考文献格式|
|图表与公式|数量、格式、颜色、分辨率和补充材料要求|
|声明|基金、伦理、利益冲突、数据与AI辅助声明|
|文件格式|Word、LaTeX、PDF及模板要求|

官方页面未说明的字段不得自行补成“期刊要求”。不同页面冲突时，优先采用发布时间更近、
且明确针对当前稿件类型的规则；仍无法判断时向用户确认。

## 与工作流的关系

1. 引用体例写入`meta.json.citation_style`，全文只执行这一种体例。
2. 明确篇幅写入`meta.json`的`min_chars`和`max_chars`，不依赖一次性命令行变量。
3. 匿名投稿时，交付稿不得含作者姓名、单位、基金、致谢或可识别文件元数据；另行准备
   投稿系统要求的作者信息页。
4. 期刊规则只能约束呈现，不能覆盖`paper-shape/references/structure.md`推导的论证依赖，
   也不能要求添加材料不支持的理论、机制、政策意义或结论。
5. 生成Markdown无法兑现字体、页边距等Word版式时，明确标记为后续排版要求，不声称已经完成。

## 交付前复核

- 当前使用的是官方、可访问且面向本稿件类型的规则。
- 匿名要求与作者信息呈现没有同时启用。
- 正文引用、注释和文末条目与冻结体例一致。
- 篇幅、图表和声明要求都有来源，没有从其他期刊迁移。
- 无法在当前输出格式兑现的要求已如实说明。
