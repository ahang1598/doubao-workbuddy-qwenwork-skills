# 投稿格式与合规自检清单

交付前对照本清单逐项核对。

## 结构完整性
- [ ] 当前官方格式合同要求的标题、摘要、关键词、作者信息和声明均已提供，未要求的组件没有为凑格式添加
- [ ] 匿名稿已移除正文和文件中的作者、单位、基金、致谢等身份信息；非匿名稿按合同提供
- [ ] 摘要、关键词的语言、篇幅和数量只执行当前已核实模板，没有使用本Skill中的静态经验数值
- [ ] 引言或问题提出准确界定当前研究问题，不强制宣称创新
- [ ] 需要文献综述时完成综合评述；不需要时不补空洞综述
- [ ] 研究方法或材料说明与问题匹配
- [ ] 结论回应研究问题并交代适用边界；局限与展望仅在材料和任务需要时加入

## 文献综述专项（对照失败模式反向自检，详见 `review-question-framing.md`）
- [ ] 未照搬他人综述，评述均基于阅读原文
- [ ] 有自己的分类、归纳与评述，而非罗列堆砌
- [ ] 文献选择有明确范围，研究性著作为主（知识性材料未混入）
- [ ] 综述与主题紧密相关，结论已回应综述提出的问题
- [ ] 围绕关键词聚焦重点，主线清晰
- [ ] 重要概念已追溯源头（最早提出者）
- [ ] 批评他人时引用了原作者/原著，未据二手或译本妄断

## 结论与建议专项（溯源原则，详见 `section-templates.md` 第 9 节）
- [ ] 每条结论都能追溯到正文（第 8 节）的检验结果或论证，无凭空结论
- [ ] 结论未引入新数据、新变量、新论点
- [ ] 结论表述不夸大（未把相关说成因果、未把局部显著说成普遍成立）
- [ ] 每条建议逐条对应某条结论，未超出论证范畴
- [ ] 无"应加强、应重视"式脱离本文证据的空泛套话
- [ ] 若写研究局限或未来展望，其内容具体、可追溯且不引入前文没有的新任务

## 引用与注释
- [ ] 默认采用 GB/T 7714—2015 顺序编码制（文内 [1]、文末按引用序号著录）；仅目标期刊明确要求时才用其他体例
- [ ] 全文统一使用一种体例
- [ ] 文内标注与文末著录一一对应
- [ ] 无遗漏、无编造引文
- [ ] 直接引用加引号并标页码
- [ ] 文献类型标识（[M]/[J]/[C]/[D]/[N]/[EB/OL]）、标点符合 GB/T 7714 规范

## 语言与格式
- [ ] 学术语言客观严谨，无口语化
- [ ] 术语前后一致
- [ ] 图表有编号与标题，正文有引述
- [ ] 数字、标点、计量单位规范
- [ ] 篇幅符合目标期刊要求

## 期刊格式专项（仅用户明确指定且官方要求已核实时使用）
- [ ] 没有按学科自动映射《中国社会科学》《经济研究》或其它“标杆期刊”
- [ ] 题名、摘要、关键词、图表、公式、参考文献和篇幅均来自目标期刊官方要求或用户模板
- [ ] 目标期刊未规定的项目使用通用学术格式，没有从其它期刊借规则补齐
- [ ] 已说明本文与相关文献的学术承启与区别
- [ ] 排版细则符合已核实范本

## 输出格式专项（防 AI 生成稿常见排版问题，详见 `formatting-output.md`）
- [ ] 公式渲染为正式数学格式并编号，无 `_{i,t}`、`β_0`、`<sub>`、`<sup>` 等未渲染痕迹
- [ ] 公式符号解释与公式中系数完全一致（无"γ 和 γ"式重复/简写）
- [ ] 指标体系/描述性统计/相关性矩阵/回归结果均为标准表格，未串成正文或字符串
- [ ] 表格数字不粘连，显著性星号紧跟系数、未被换行拆散
- [ ] 各级标题（一、/（一）/1.）独立成行，未与正文或表题/表注/下节标题粘连
- [ ] 变量定义按被解释/解释/机制/控制变量分层编号
- [ ] 中文正文无必要英文普通词；术语首现给中文译名+英文括注
- [ ] 参考文献逐条换行、条目内部完整，无硬换行拆断
- [ ] 已清除"由 AI/豆包生成""请谨慎参考"等生成提示与占位符；如需 AI 声明按期刊规范处理

## 学术诚信
- [ ] 转述已改写并标注来源
- [ ] 数据/史料真实可溯源
- [ ] 查重通过（如有要求）

## 文献真实性专项（涉及联网检索/补充文献时必查，以 `prepare` 阶段来源核验为最高优先级）
- [ ] 中文正式参考文献已有知网导出引用原文或等价可追溯的完整引用与页面证据；仅有CNKI页面题名、作者、来源和年份时仍标记待核验。英文来源按`literature-review`规定的证据层级处理；普通搜索和API元数据只作为候选线索
- [ ] 无任何凭记忆或推测"生成"的文献（作者、篇名、期刊、年份、卷期、页码、DOI/URL 逐项真实）
- [ ] 题录信息与检索结果逐项一致，无臆造或张冠李戴
- [ ] 无法核实的文献已剔除，未"宁滥勿缺"
- [ ] 关键文献保留了可回溯的检索路径（数据库 + 检索词 / 链接 / DOI）
- [ ] 转述他人观点忠于原文，未为论证需要曲解或夸大
