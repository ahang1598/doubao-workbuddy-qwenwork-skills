# Chicago 18 格式指南

当前 `paper-write-en` workflow只启用 Chicago 18 author-date。本文的notes-bibliography内容仅作知识参考，不得用于当前任务的正式输出或门禁判断。

## 来源与适用范围

本指南根据 University of Pittsburgh Library System 的 Chicago 18th / Turabian 9th citation help 页面整理，并转化为本学术写作 skill 可执行的规则。用于起草、修改和检查使用 Chicago 18 格式的英文论文。

来源页面：`https://pitt.libguides.com/citationhelp/chicago`

Chicago style 有两套主要文献系统：

1. Notes and bibliography。
2. Author-date。

根据学科、教师要求或期刊指南选择系统。

## 选择系统

### Notes And Bibliography

notes-bibliography 系统常用于人文学科，包括 literature、history 和 arts。它在 footnotes 或 endnotes 中呈现文献信息，并通常包含 bibliography。

以下情况使用该系统：

- 来源类型多样，包括 archival、historical、literary、artistic、legal 或 primary materials。
- 需要 discursive notes。
- 作业或期刊明确要求 Chicago notes and bibliography。

### Author-Date

author-date 系统常用于 physical sciences、natural sciences 和 social sciences。它在正文中使用简短括号引用，并在 reference list 中提供完整文献信息。

以下情况使用该系统：

- 论文更接近社会科学或科学写作。
- 用户要求 Chicago author-date。
- 作业或期刊使用 parenthetical author-date citations。

除非明确要求，不要混用 notes-bibliography 和 author-date。

## Notes-Bibliography 系统

### 一般规则

- 使用编号 notes 进行引用。
- 某一来源第一次出现在 note 中时提供完整信息。
- 后续引用使用 shortened note。
- 即使 notes 已包含完整信息，仍可能需要 bibliography。
- Bibliography 条目按作者姓氏字母顺序排列。

### 纸质图书

完整 note：

```text
1. Michael Pollan, The Omnivore's Dilemma: A Natural History of Four Meals (New York: Penguin, 2006), 99-100.
```

缩短 note：

```text
2. Pollan, Omnivore's Dilemma, 3.
```

Bibliography：

```text
Pollan, Michael. The Omnivore's Dilemma: A Natural History of Four Meals. New York: Penguin, 2006.
```

### 纸质期刊论文

完整 note：

```text
1. Joshua I. Weinstein, "The Market in Plato's Republic," Classical Philology 104 (2009): 440.
```

缩短 note：

```text
2. Weinstein, "Plato's Republic," 452-53.
```

Bibliography：

```text
Weinstein, Joshua I. "The Market in Plato's Republic." Classical Philology 104 (2009): 439-58.
```

### 电子期刊论文

完整 note：

```text
1. Gueorgi Kossinets and Duncan J. Watts, "Origins of Homophily in an Evolving Social Network," American Journal of Sociology 115 (2009): 411, accessed February 28, 2010, doi:10.1086/599247.
```

缩短 note：

```text
Kossinets and Watts, "Origins of Homophily," 439.
```

Bibliography：

```text
Kossinets, Gueorgi, and Duncan J. Watts. "Origins of Homophily in an Evolving Social Network." American Journal of Sociology 115 (2009): 405-50. Accessed February 28, 2010. doi:10.1086/599247.
```

### Website

完整 note：

```text
1. "Google Privacy Policy," last modified March 11, 2009, http://www.google.com/intl/en/privacypolicy.html.
```

缩短 note：

```text
"Google Privacy Policy."
```

Bibliography：

```text
Google. "Google Privacy Policy." Last modified March 11, 2009. http://www.google.com/intl/en/privacypolicy.html.
```

## Author-Date 系统

### 一般规则

- 正文使用作者姓氏、年份和必要页码的括号引用。
- 在 reference list 中提供完整文献信息。
- Reference list 按作者姓氏字母顺序排列。
- 不要在 reference list 中使用 notes-bibliography 格式。

### 图书

正文引用：

```text
(Pollan 2006, 99-100)
```

Reference list：

```text
Pollan, Michael. 2006. The Omnivore's Dilemma: A Natural History of Four Meals. New York: Penguin.
```

### 纸质期刊论文

正文引用：

```text
(Weinstein 2009, 440)
```

Reference list：

```text
Weinstein, Joshua I. 2009. "The Market in Plato's Republic." Classical Philology 104:439-58.
```

### 电子期刊论文

正文引用：

```text
(Kossinets and Watts 2009, 411)
```

Reference list：

```text
Kossinets, Gueorgi, and Duncan J. Watts. 2009. "Origins of Homophily in an Evolving Social Network." American Journal of Sociology 115:405-50. Accessed February 28, 2010. doi:10.1086/599247.
```

### Website

正文引用：

```text
(Google 2009)
```

Reference list：

```text
Google. 2009. "Google Privacy Policy." Last modified March 11. http://www.google.com/intl/en/privacypolicy.html.
```

## 实用格式差异

### Notes-Bibliography

Notes 中：

- 使用 first name then last name。
- 图书出版信息放在括号中。
- 页码放在结尾。
- 后续引用使用 shortened notes。

Bibliography 中：

- 第一作者使用 last name, first name。
- 出版信息不放在括号中。
- 条目按字母顺序排列。

### Author-Date

正文中：

- 使用 `(Author Year, page)` 格式。
- 引文和具体断言使用页码。

Reference list 中：

- 年份紧跟作者名之后。
- 提供完整文献信息。

## Access Dates、DOI 与 URL

遵循教师或出版社要求。Pitt guide 示例为电子期刊论文提供 access date，为网站提供 last modified date。有 DOI 时加入 DOI。引用网站时，提供稳定 URL，并在需要时加入 publication date、last modified date 或 access date。

## 最终检查清单

最终输出前检查：

1. 论文是否始终使用 notes-bibliography 或 author-date 中的一种？
2. 若使用 notes-bibliography，第一次 note 是否提供完整信息，后续 note 是否使用缩短形式？
3. 若使用 author-date，所有正文引用是否匹配 reference list 条目？
4. bibliography 或 reference list 是否按字母顺序排列？
5. 引文和具体断言是否包含页码？
6. DOI、URL、access date 或 last modified date 是否在需要时提供？
7. 图书、期刊论文、电子期刊论文和网页条目是否符合所选 Chicago 系统？
8. 所选 Chicago 系统是否适合学科和作业要求？
