# 方法论指南

## 用途

当英文论文需要设计或审查 methodology、research design、data source、sampling、corpus、variables、measurement、coding、experimental setup、model specification、analytical procedure、validity、reliability、robustness 或 ethics 时，使用本文件。

所有论文都需要清楚说明分析或设计逻辑，但不都需要独立理论框架。纯测量、描述、数据集说明、工程实现或方法短文可以用评价目标、设计原则、计算模型或方法逻辑承担该功能。方法论部分必须具体、可理解，并在适用时可复现。

## 理论框架原则

### 按研究问题选择框架

只有研究问题确实需要独立框架时，才从下列类型中选择；纯测量、描述、数据集说明、
工程实现或方法短文可直接使用评价目标、设计原则、计算模型或方法逻辑：

- theoretical framework
- conceptual framework
- analytical framework
- computational framework
- experimental framework
- mechanism model
- domain-specific model
- interpretive lens

不要因目录完整性强制添加理论框架；也不要因论文类型标签自动省略当前问题确实需要的分析框架。

### 理论选择

理论、模型或框架必须：

1. 直接关联研究问题。
2. 解释研究对象、关系或机制。
3. 指导变量选择、概念定义、材料分析或假设构建。
4. 连接 methodology 和 analysis。
5. 不只是装饰 introduction。
6. 足够具体，可以操作化。

### 避免单独使用过宽理论

不要只依赖下列模糊宏观概念：

- modernity
- globalization
- postmodernism
- capitalism
- neoliberalism
- social change
- technological determinism
- humanism
- 泛泛的 culture theory

这些概念只有在搭配更具体的中层理论、领域模型或可操作概念时才适合使用。

### 优先使用中层或领域框架

优先使用：

- middle-range theory
- field-specific theory
- mechanism-based framework
- conceptual model
- analytical categories
- measurable constructs
- established disciplinary frameworks

框架应回答：

- 研究对象是什么？
- 核心概念是什么？
- 概念之间有什么关系？
- 为什么该理论适合研究问题？
- 理论如何指导分析？

## 写 theoretical framework

应包含：

1. 理论选择：使用什么理论、模型或框架。
2. 适配理由：为什么适合本研究。
3. 核心概念：哪些概念重要。
4. 操作化：概念如何变成变量、指标、编码维度、分析类别或实验设计要素。
5. 与研究问题连接：框架如何帮助回答问题。
6. 与方法论连接：框架如何指导样本选择、材料分析、变量、编码或模型设计。

论文正文中不必机械列为 bullet，应融合成连贯学术段落。

可用表达：

- This study draws on X theory to examine...
- X theory is particularly useful because...
- In this study, the concept of X is operationalized as...
- This framework guides the analysis in three ways...
- Rather than treating X as a broad background condition, this study examines its specific mechanisms through...

## 方法论原则

### 方法论边界

Methodology 部分应直接说明研究如何执行，而不是重复说明研究为什么重要、案例为什么有意义或研究问题为什么值得研究。案例意义、选题价值、理论贡献、研究空白和问题重要性应放在 introduction、literature review 或 theoretical framework 中。

如果论文已经有单独的 theoretical framework 部分，methodology 不得重复解释理论来源、理论适配性、迁移合理性或核心概念定义，只需说明该理论或框架如何被操作化为研究程序。例如，methodology 可以说明理论概念如何变成变量、指标、coding categories、材料筛选标准、实验条件、模型组件或评价指标，但不要重新论证为什么选择该理论。

如果用户只要求写 methodology，且没有提供单独的 theoretical framework，可以用 1-2 句简短说明研究依赖的理论、模型或分析框架，目的是让方法完整可读；但重点仍应放在数据、样本、语料、测量、编码、实验、模型和分析步骤。

方法论开头应优先用连贯段落交代 research design、case 或 research object、corpus/sample/data source、selection criteria、analytical procedure，以及 coding 或 measurement strategy。正文呈现、列表禁令和表格格式遵循 `format-guide.md`；信息复杂时改用符合目标引用格式的表格。

避免在 methodology 中写：

- The case is theoretically meaningful because...
- This study is important because...
- This research fills a gap because...
- A qualitative design is appropriate because the research question is important...

如需解释方法选择，只保留与方法执行直接相关的简短理由，例如该研究使用 qualitative historical case study because it analyzes policy documents and institutional process, not survey outcomes。不要展开研究意义或案例价值。

### Methodology 输出白名单

Methodology 只写研究如何执行。输出内容必须限定在以下信息内：research design、research object、data source、time frame、sample or corpus、dataset/materials presentation、sampling or selection criteria、inclusion/exclusion criteria、variables、measurement、coding procedure、analytical procedure、software/tools、validity/reliability/robustness procedures 和 ethics。

写作时只描述程序，不评价研究设计的优劣、不讨论研究结果的意义、不提出后续章节的内容。若草稿中出现超出执行程序的评价性句子，必须删除。

### Methodology 禁止内容

Methodology 部分绝对禁止出现方法局限、研究局限、适用边界、推广限制、样本不足、数据不足、方法弱点、取舍评价、未来研究建议或任何对方法优劣的讨论。相关内容即使真实存在，也必须放在 discussion 或 conclusion，而不是 methodology。

写 methodology 时应删除或改写包含下列含义的句子：`limitations of the methodology`、`methodological limitations`、`limited generalizability`、`the sample is too small`、`the data are incomplete`、`this method cannot fully capture...`、`a weakness of this approach is...`、`future research should...`、`because of limited access...`、`due to constraints...`。

Methodology 可以说明数据性质和程序条件，例如 `the survey component is presented as a proposed design` 或 `no interview responses are treated as empirical evidence unless actual transcripts are provided`；但不能接着评价这种数据条件带来的研究缺陷、推广限制或改进方向。

### 正文呈现

正式论文正文中的 methodology 应以连贯自然段说明研究步骤、数据来源、纳入标准、排除标准、变量、编码类别或分析流程；信息复杂、需要比较/映射/分类时使用符合目标格式的表格。具体列表禁令和表格格式执行 `format-guide.md`。

### 与理论框架合并

如果研究方法是 theoretical framework 的直接延续，且方法部分主要说明选择了哪些文献、政策文件、文本、案例或数据作为分析材料，以及这些材料如何按照理论框架被编码或解释，可以不单独设置完整的 `Methodology` 大节。

在这种情况下，可将方法内容并入 theoretical framework 或 analytical framework 部分，用不同小标题区分，例如：

- `Theoretical Framework`
- `Core Concepts of the Framework`
- `Operationalization and Materials`
- `Corpus and Coding Strategy`

合并时仍须说明：

- corpus、sample、documents 或 data source
- inclusion criteria 和 exclusion criteria
- time frame
- 分析单位
- coding categories 或 analytical dimensions
- 选择这些材料的直接方法理由

不要因为并入 theoretical framework 就省略方法信息。合并的目的只是避免文章结构过碎，尤其适用于文献型、政策文本型、历史文本型、概念型或理论驱动的定性研究。

### 可复现性

方法论应具体到另一位研究者能理解并大致重复研究过程。应包括：

- research design
- research object
- data source
- sample 或 corpus
- sampling strategy
- inclusion criteria
- exclusion criteria
- time frame
- variables、indicators、coding categories 或 analytical dimensions
- procedure
- analytical method
- tools、software 或 instruments
- validity、reliability、robustness 或 trustworthiness procedures
- ethical considerations

### 数据、语料或材料呈现

Methodology 必须让读者理解研究的材料基础，但不等于所有论文都要单独设置数据呈现节。文献型、概念型、理论型或普通政策文本研究，只要 methodology 已经说明文献来源、corpus、筛选标准、时间范围和分析路径，就可以直接进入 analysis，不需要额外设置 `Data and Materials` 或 `Corpus and Materials` 独立部分。

如果研究涉及 qualitative coding、content analysis、thematic analysis、policy-document coding、systematic review、scoping review、bibliometric analysis、定量数据、问卷、访谈、实验、模型、工程或数据科学数据，则应在 analysis、results 或 findings 之前呈现必要的数据结果、编码结果、样本结构、变量表、描述统计、材料分布或证据矩阵。该内容可以放在 methodology 内部，用 `Coding Results`、`Data and Materials`、`Corpus and Materials`、`Dataset`、`Participants and Instruments`、`Materials and Measures` 等小标题呈现；也可以作为 methodology 之后、analysis 之前的独立短节。

这类数据或材料呈现只回答“本研究分析了什么、材料如何分布、编码或变量如何组织”，不回答“这些材料说明了什么”。它应描述数据、材料、语料、样本、变量、案例、文本、实验材料或工具的来源、范围、筛选标准和组织方式；不得提前解释 findings、讨论意义或评价方法选择。

不同研究类型的呈现重点：

- 文献型、政策文本型、法律、历史或人文学科研究：在 methodology 中列出或概括进入分析的核心 corpus，包括政策文件、法规、档案、学术文献、书籍、报告、案例、演讲、文本版本或其他 primary texts。若只是 narrative、conceptual、theoretical 或 interpretive analysis，说明来源逻辑后可直接进入 analysis。若使用编码、系统筛选、内容分析或证据矩阵，则应先呈现编码结果、材料分布或核心材料表。
- 定量研究、数据科学、AI、工程、医学或自然科学研究：呈现 dataset、sample、variables、measurement、instruments、materials、devices、algorithms、baseline methods 或 evaluation metrics。必要时用表格说明变量定义、数据来源、样本量、时间范围和测量方式。
- 访谈、问卷、焦点小组或实验研究：呈现 participants、sample frame、recruitment、instrument、protocol、questionnaire、interview guide、实验材料或实验条件。若没有真实收集数据，必须明确写成 proposed、simulated、constructed、hypothetical 或 placeholder data，不得把设计写成已经完成的真实证据。
- 混合方法研究：分别呈现 qualitative 和 quantitative 两类数据，并说明二者在后续分析中如何对应或整合。

当信息较多时，优先使用符合所用格式的表格，而不是工作文档式写法。表格格式执行 `format-guide.md` 和对应 reference 文件。表格之后应用一小段文字说明该数据或材料如何进入后续编码、测量或分析程序。

分析章节不得使用 methodology、corpus 说明或数据结果呈现中没有说明过的数据、材料、变量、编码类别、访谈内容、实验结果或统计指标。若写作时发现编码型、定量型或实证型研究缺少必要的数据或编码结果呈现，应先补足 `Coding Results`、`Data and Materials` 或同等功能内容，再进入 analysis。若是普通文献研究，则补足 methodology 中的 source logic 和 corpus 说明即可。

### Qualitative coding 的呈现

如果 methodology 涉及 qualitative coding、content analysis、thematic analysis、policy-document coding、discourse coding 或理论驱动的文本编码，优先使用表格呈现 coding scheme、coding map 或 coding matrix，而不是只用段落文字说明。

正文段落负责说明 coding 的流程、分析单位、编码步骤、可信度处理和与理论框架的关系；表格负责呈现编码映射，使读者能清楚看到理论概念如何转化为可识别的文本证据。

coding 映射表通常应包括：

- theoretical concept、analytical category 或 research dimension
- code 或 sub-code
- operational definition
- inclusion criteria
- exclusion criteria，如有必要
- evidence indicators 或 textual markers
- source type 或 data source
- example evidence 或 paraphrased example，如有必要

表格不应替代方法说明。表格之后仍需用正文解释 coding 如何执行、如何比较不同材料、如何处理模糊案例，以及如何避免把研究者判断伪装成文本证据。若使用 APA 7，表格需编号、给出斜体标题，并在正文中明确引用和解释。

### 避免空泛方法声明

不要只写：

- This paper uses qualitative analysis.
- This study adopts a mixed-methods approach.
- This research uses literature analysis.
- This study analyzes data.
- This paper uses case study method.

必须说明方法如何实施。

## 不同方法规则

### 社会科学方法选择

社会科学论文不应默认只使用 literature-based analysis。根据研究问题和用户提供的数据条件，可以选择或组合下列方法：

- literature-based qualitative design
- policy document analysis
- archival or historical document analysis
- survey research
- semi-structured interviews
- focus groups
- content analysis
- discourse analysis
- case study
- mixed-methods design

如果用户没有提供真实问卷、访谈、焦点小组或实验数据，`mode=draft`时只能写成proposed design、simulated data、constructed data、hypothetical data或placeholder data，并清楚标注数据性质。`mode=final`不得保留这些内容，只能阻塞或改为不声称已有数据的研究方案。

可用表述：

```text
Because no original survey dataset is available at this stage, the survey component is presented as a proposed design. Any numerical examples should be treated as constructed data for demonstration purposes and replaced with actual collected data before submission.
```

```text
The interview component is designed as a proposed qualitative protocol rather than a report of completed fieldwork. No interview responses are treated as empirical evidence unless actual transcripts are provided.
```

方法选择应匹配研究问题。如果某一方法明显不能回答研究问题，应优先选择更合适的方法。若因时间、数据可得性、伦理审批、课程任务或其他客观条件只能采用某种折中方法，methodology 只说明该方法如何执行；对方法选择的评价、取舍原因的影响和后续研究建议应放到 discussion，不写进 methodology。

### 定性研究

适用于 interviews、textual analysis、discourse analysis、case study、ethnography、archival research、observation 等设计。

应包括：

- research design
- case 或 participant selection
- data source
- sampling criteria
- corpus size 或 participant number
- data collection procedure
- coding method
- coding categories
- analytical framework
- reliability 或 trustworthiness strategy
- 涉及 human subjects 时的伦理说明

涉及 qualitative coding 时，应优先提供 coding map、coding scheme 或 coding matrix。该表应把理论概念、编码类别、操作定义、证据指标和来源类型对应起来，尤其适用于用 MSA、thematic analysis、content analysis、discourse analysis、policy analysis 或 conceptual framework 指导材料分析的论文。

文本分析、话语分析、内容分析或 close reading 应说明：

- texts 或 corpus
- 文本来源
- 时间范围
- 选择标准
- 排除标准
- 分析单位
- 编码类别
- 分析程序
- 编码逻辑示例
- 如何控制或论证解释的可靠性

访谈研究应说明：

- participant recruitment
- sample size
- participant characteristics
- interview type
- interview guide
- interview length
- recording and transcription method
- coding process
- consent and ethics
- anonymity strategy

不要编造访谈内容。若用户没有提供访谈数据，应写成拟议访谈设计或占位 interview protocol。

案例研究应说明：

- case selection rationale
- case definition and case selection procedure
- data sources
- triangulation strategy
- analytical framework
- 案例是 typical、extreme、critical 还是 theoretically meaningful

### 定量研究

适用于 surveys、experiments、secondary data analysis、statistical modeling 和 econometric research。

应包括：

- research design
- data source
- sample size
- population
- sampling strategy
- variables
- operational definitions
- measurement instruments
- model specification
- statistical methods
- software
- assumptions
- robustness checks
- time frame, inclusion/exclusion criteria, and procedural assumptions

变量应定义：

- independent variables
- dependent variables
- control variables
- mediating 或 moderating variables
- measurement scale
- data coding
- missing data handling

统计分析应说明：

- model type
- estimation method
- 必要时给出 equation
- hypothesis testing
- confidence interval 或 significance level
- robustness checks
- interpretation rules

不要编造显著性结果。没有真实数据时，只能使用清楚标注的模拟数据。

### 实验研究

适用于 psychology、education、medicine、engineering、computer science、natural sciences 等领域。

应包括：

- research objective
- hypothesis
- experimental design
- participants、samples、materials 或 devices
- treatment and control conditions
- independent and dependent variables
- procedure
- measurement instruments
- randomization，如适用
- control variables
- data collection
- analysis method
- ethical approval，如适用
- time frame, inclusion/exclusion criteria, and procedural assumptions

如果用户没有真实实验数据：

- 写成拟议实验设计。
- 仅用模拟数据展示分析。
- 清楚标注 simulated 或 placeholder data。
- 不得将模拟结果当作真实发现。

### 混合方法研究

应说明：

- mixed-methods design type
- qualitative component
- quantitative component
- order of methods
- integration strategy
- 为什么必须使用 mixed methods
- 一种方法如何补充另一种方法
- time frame, inclusion/exclusion criteria, and procedural assumptions

常见设计包括：

- explanatory sequential design
- exploratory sequential design
- convergent parallel design
- embedded design

不要只是把两种方法并列放置；必须解释整合逻辑。

### 基于文献的研究

适用于 literature review、systematic review、scoping review、conceptual paper 和 theoretical paper。即使论文主要基于文献，也需要方法论部分。

应包括：

- databases searched
- keywords
- search period
- inclusion criteria
- exclusion criteria
- screening process
- reviewed studies 的数量或类型
- 纳入分析的 texts、documents、policies、cases、articles、books、archives 或其他材料清单
- analytical strategy
- synthesis method

在人文、政策、法律、历史、文化研究和其他文本型论文中，所选文献、文件或原始文本就是研究的分析材料，应被视为数据。方法论不能含糊地说论文“uses literature”，而应说明 corpus。

当 corpus 可控时，提供简洁表格或清单，列出纳入分析的材料。可包含：

- 作者或发布机构
- 年份
- 标题
- 来源类型，如 policy document、journal article、book、archive、legal case、speech、report 或 primary text
- 纳入理由
- 在分析中的作用

如果 corpus 很大，应按类别概括，并提供纳入和排除规则，同时列出最核心材料。

#### 基于文献研究的写作范例

以下范例可用于 literature-based、policy-document-based、conceptual 或 theoretical research 的 methodology。使用时应替换主题、时间范围、数据库、关键词、材料类型和分析框架，不要机械照抄。

```text
This study uses a literature-based qualitative design. The analytical corpus consists of peer-reviewed journal articles, academic books, official policy documents, and institutional reports that directly address [research topic] between [start year] and [end year]. Sources were identified through [databases/platforms], using combinations of the following keywords: [keyword 1], [keyword 2], [keyword 3], and [keyword 4]. Additional sources were located through backward and forward citation tracking from frequently cited studies.

Sources were included if they met three criteria: first, they directly addressed [core concept/case/policy/problem]; second, they provided theoretical, empirical, historical, or policy evidence relevant to the research question; and third, they were published by peer-reviewed journals, academic presses, government agencies, international organizations, or other identifiable authoritative institutions. Sources were excluded if they were opinion pieces, unsourced online materials, student papers, duplicate reports, or texts that mentioned the topic only in passing.

The selected materials were treated as the study's corpus rather than as background references only. Each text was read for its contribution to [analytical focus], with attention to [dimension 1], [dimension 2], and [dimension 3]. The analysis proceeded in three stages. First, the materials were grouped by source type and relevance to the research question. Second, key claims, policy definitions, empirical findings, and theoretical concepts were coded according to [theoretical/analytical framework]. Third, the coded materials were synthesized to identify patterns, tensions, and explanatory mechanisms across the literature.

When the analysis uses qualitative coding, the methodology should include a coding map. The coding map links each theoretical or analytical category to its operational definition, evidence indicators, and source type. For example, an MSA-based policy study may map "problem stream" to evidence that frames an issue as urgent or inadequate, "policy stream" to evidence of feasible solutions and institutional design, and "politics stream" to evidence of political climate, administrative reform, or stakeholder support. The text should then explain how the table was used during coding rather than leaving the table as a decorative summary.

To strengthen interpretive credibility, the study compared claims across different source types and avoided relying on a single document or author for major conclusions. Official documents were used to establish policy language and institutional design, while academic studies were used to interpret the broader scholarly context and analytical implications. Because the study relies on publicly available texts and published scholarship, no human-subject data were collected.
```

如果研究对象是政策文本，可将 `peer-reviewed journal articles, academic books...` 改为 `official policy documents and supporting scholarly literature`，并在正文或表格中列出进入分析的核心政策文件。

systematic review 或 scoping review 应说明：

- database list
- search strings
- publication years
- language restrictions
- study type restrictions
- screening stages
- inclusion and exclusion criteria
- coding dimensions
- synthesis method

如果无法完成真正的 systematic review，应称为 narrative review 或 conceptual review，不要假装是系统综述。

### 人文学科研究

适用于 literature、history、philosophy、cultural studies、art history 等领域。

应包括：

- primary texts、archives 或分析对象
- selection rationale
- interpretive framework
- theoretical lens
- historical or cultural context
- analytical procedure
- evidence standard
- time frame, inclusion/exclusion criteria, and procedural assumptions

不要写成个人感想或宽泛文化评论。

文学分析应说明：

- primary text
- relevant edition 或 translation
- interpretive focus
- theoretical lens
- 关键 motifs、narrative devices 或 rhetorical features
- close reading procedure
- 与既有研究的关系

历史研究应说明：

- primary sources
- archives 或 document collections
- time period
- source selection criteria
- historiographical context
- method of interpretation
- source type, time period, and document collection procedure

### 商科与管理研究

适用于 management、marketing、organizational behavior、consumer research、strategy、human resources 等领域。

应包括：

- business 或 organizational problem
- theoretical model
- case、sample 或 dataset
- method
- analytical dimensions
- managerial implications
- time frame, inclusion/exclusion criteria, and procedural assumptions

不要写成商业宣传、品牌策略或咨询式建议。实践意义必须建立在学术证据和分析上。

### STEM 与工程研究

适用于 computer science、engineering、natural sciences、medicine、AI、data science 等领域。

应包括：

- research problem
- related work
- computational、experimental、analytical 或 methodological framework used to execute the study
- materials、instruments、datasets 或 algorithms
- experimental setup
- evaluation metrics
- baseline methods，如适用
- reproducibility details
- results
- robustness 或 error analysis
- time frame, inclusion/exclusion criteria, and procedural assumptions

使用算法或模型时，应说明：

- dataset
- preprocessing
- model architecture 或 method
- parameters
- evaluation metrics
- comparison baseline
- hardware 或 software environment，如相关

不要编造真实实验结果。没有真实数据时，只能使用清楚标注的 simulated data 或 placeholders。

## 数据规则

### 真实数据

使用真实数据时说明：

- data source
- collection method
- time frame
- sample size
- inclusion criteria
- exclusion criteria
- variables
- measurement
- missing data handling
- reliability 或 validity
- time frame, inclusion/exclusion criteria, and procedural assumptions

### 模拟数据

用户没有提供真实数据但需要展示分析时，只有`mode=draft`可以将模拟数据用于示范；`mode=final`不得使用。

必须清楚标注为：

- simulated data
- hypothetical data
- placeholder data
- for demonstration purposes only

推荐表述：

```text
This section uses simulated data for demonstration purposes. The data should be replaced with actual empirical data before submission.
```

### 禁止的数据做法

不得编造：

- 真实问卷结果
- 实验数据
- 访谈材料
- 统计显著性
- 样本来源
- 数据集

不得把模拟数据当成真实 findings。

## 与 Analysis / Discussion 的边界

本文件只指导 methodology 或 research design 的写作。Data analysis、results、findings、discussion 和 implications 不在本文件中展开。

写完 methodology 后，若需要继续写 analysis、findings、discussion 或 implications，应切换到 `subskill/analysis-discussion-guide.md`。
