# 理论框架指南

## 用途

当英文论文需要撰写、修改或审查 theoretical framework、conceptual framework、analytical framework、mechanism model、computational framework、experimental framework 或 interpretive lens 时，使用本文件。

理论框架的目的不是给论文贴上一个理论标签，而是说明为什么某一理论或模型适合当前研究问题，并展示它如何塑造概念、证据、方法和分析。

最终论文正文的列表、表格、标题和非英语术语处理遵循 `format-guide.md`。下文列表只用于内部写作指导；正式输出应写成连贯学术段落，必要时使用符合指定格式的表格呈现概念映射。

## 核心原则

### 先判断是否需要独立框架

每篇论文都需要清楚的分析逻辑，但不都需要独立的理论框架章节。只有研究问题、解释目标、目标期刊或学科惯例确实需要时，才使用下列框架之一；纯测量、描述、数据集说明、工程实现或方法短文可以用设计原则、评价目标或方法逻辑承担该功能，不得为形式完整补装饰性理论。

- theoretical framework
- conceptual framework
- analytical framework
- computational framework
- experimental framework
- mechanism model
- domain-specific model
- interpretive lens

不要因为论文是技术类、文学类、应用类、政策类或数据驱动研究，就省略框架。

### 理论选择

所选理论、模型或框架必须：

1. 直接关联研究问题。
2. 能解释研究对象、关系、机制或阐释难题。
3. 能指导变量选择、概念定义、案例解释、证据编码、模型设计或假设建构。
4. 与 methodology 和 analysis 有可见连接。
5. 足够具体，可以操作化。
6. 避免只作为宽泛背景标签。

### 避免只用过宽理论

不要单独依赖下列模糊宏观概念：

- modernity
- globalization
- postmodernism
- capitalism
- neoliberalism
- social change
- technological determinism
- humanism
- 泛泛的 culture theory

这些概念可以使用，但应搭配更具体的中层理论、领域模型、操作性概念或成熟分析框架。

## 基于文献论证理论适配性

解释理论为什么适合本研究时，不要只靠内部逻辑或常识推理。理论选择需要文献支撑。

有力的理论框架应引用：

- 定义该理论的奠基性作品。
- 在同一领域中应用该理论的研究。
- 将该理论用于相似政策、制度、社会、技术、文化或经验问题的研究。
- 将该理论跨情境迁移且迁移方式与当前项目相似的研究。
- 说明该理论如何支持当前研究问题、研究对象、证据选择和分析路径的方法文献或综述文献。

不要只写：

```text
The Multiple Streams Approach is suitable because this study examines policy change.
```

应说明理论适配性，并且只使用当前任务`verified_refs`中的来源。合格段落先说明已验真
框架能够区分哪些可观察维度，再限定它只承担当前研究中的哪项分析职责；跨情境迁移必须
由已验真来源和当前材料共同支持。缺少相应来源时省略该判断，不用示例中的作者、年份、
数字或模型记忆补齐。

## 必要内容

理论框架部分通常应包含：

1. 理论选择：使用什么理论、模型或框架。
2. 学术基础：哪些奠基性和应用性研究支撑该选择。
3. 适配理由：为什么该理论适合当前研究问题。
4. 应用或迁移合理性：如果理论来自不同情境、学科或国家，应重点说明它为什么可以用于当前研究。论证应聚焦于该理论的核心概念与当前研究问题之间的契合、既有研究中的相似应用、当前案例与既有应用之间的共同机制，以及该理论如何帮助组织证据和解释研究对象。
5. 原始核心概念：该理论在经典文献中的核心概念、基本构成和概念关系，以及这些概念如何运用到本研究中。
6. 操作化：概念如何转化为变量、指标、编码维度、分析类别、模型组件或解释视角。
7. 方法连接：框架如何指导来源选择、抽样、编码、测量、案例分析、实验设计、模型设计或解释。

这些内容不一定要作为小标题出现。多数论文中，应将它们融合为连贯的学术段落。

如果论文另有 methodology 或 research design 部分，theoretical framework 只需说明理论概念如何为后续操作化提供方向，不要展开写完整的数据来源、样本筛选、实验步骤、编码流程、模型参数或软件工具。这些执行细节应留给 methodology。若用户只要求写 theoretical framework，可以简要预告方法连接，但不要把 theoretical framework 写成 methodology。

除非用户、学校或期刊明确要求，theoretical framework 部分不需要专门讨论理论迁移过程中的注意事项、潜在风险或理论局限。若确有必要提及，也应简短自然地融入适配性论证，不能让理论框架变成局限性讨论。

## 内容整合逻辑

理论框架应按论证功能组织，而不是把相近内容拆成多个并列小标题。凡是都在回答“为什么这个理论适合本研究”的内容，应放在同一论证单元中，不要拆成 `Theoretical Fit`、`Adapting the Framework to X Context`、`Transferability` 等彼此重复的部分。

推荐顺序：

1. 理论选择原因：先说明本研究选择哪个理论，以及研究问题为什么需要这个理论。
2. 理论适配本研究的原因：结合奠基文献和相关应用文献，说明该理论为什么能解释当前研究对象、政策情境、机制或关系。如果涉及跨国家、跨学科或跨制度情境迁移，也应在此处一起说明，而不是单独另设小节。
3. 理论原始核心概念介绍：必须先交代理论在原始或经典文献中的核心概念、基本构成和概念之间的关系，再说明本研究如何使用这些概念。不要一开始就把概念改写成本研究语境下的操作化定义，否则读者无法判断理论迁移是否成立。
4. 操作化与方法连接：说明理论概念如何根据当前研究对象被具体化，并转化为变量、编码维度、分析类别、证据类型、模型组件或解释路径，最后自然连接到 methodology 和 analysis。

操作化与方法连接应保持在理论层级：说明“哪些概念将转化为什么类型的证据或分析维度”即可。不要在此处重复 methodology 中应出现的 corpus 表、coding map、变量表、实验 protocol、模型超参数或数据处理步骤，除非用户只要求这一部分且没有单独 methodology。

如果使用小标题，小标题应对应以上功能差异，而不是把同一功能拆开。例如：

- 可用：`The Multiple Streams Approach and Policy Motivation`、`Core Concepts of the Multiple Streams Approach`、`Operationalization for This Study`
- 避免：`Why MSA`、`Adapting MSA to China`、`Transferability of MSA` 三个部分连续出现，因为它们通常都在重复论证理论适配性。

相邻小节必须功能互斥，不能内容重复：

- 理论适配性小节：回答“为什么这个理论适合本研究”，重点是选择理由、文献支撑和研究问题契合。
- 理论核心概念小节：回答“这个理论原本由哪些概念构成，以及这些概念之间是什么关系”，重点是原始理论说明，而不是本研究的证据编码。
- 操作化小节：回答“这些理论概念在本研究中如何被具体化、识别和使用”，重点是变量、指标、文本证据、编码维度、分析类别或模型组件。
- 若概念调整是必要的，通常应并入操作化小节，因为调整的目的就是说明理论概念如何在本研究中被具体化和使用。只有当概念调整本身非常复杂、需要独立论证时，才单独设置小节。
- 不要让概念调整和操作化两个小节都重复写“为了适配本研究，本文将 X 理解为 Y”。

## 操作化

操作化必须具体。说明理论概念如何在证据中被识别。

示例：

- 政策框架：为 problem stream、policy stream、political stream、coalition、policy image、venue、policy window、feedback 或 entrepreneurship 等概念定义可观察指标。
- 社会科学理论：定义变量、机制、中介、调节变量或可观察推论。
- 人文学科框架：定义分析类别、解释程序、文本特征、档案证据或概念视角。
- STEM 或计算框架：定义模型假设、组件、方程、参数、评估标准或系统架构。

## 避免

不要：

- 引用某个理论但分析中完全不用。
- 大段定义理论却不操作化。
- 只是因为理论“听起来相关”就使用它。
- 只用常识论证理论选择。
- 在用户未要求时用大量篇幅讨论理论局限或迁移风险。
- 同时使用多个理论但不解释彼此关系。
- 让 theoretical framework 变成 literature review 的重复。

## 可用表达

- This study draws on X theory to examine...
- X theory is particularly useful for this study because...
- Prior studies have applied X to similar questions of...
- The framework can be transferred to this case because...
- In this study, X is operationalized as...
- This framework guides the analysis in three ways...
- Although X was developed in Y context, its emphasis on Z makes it useful for analyzing...
