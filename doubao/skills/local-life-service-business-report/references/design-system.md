## 设计原则
1. **清爽专业**：参考数据平台平台的卡片式布局，白底浅灰背景，信息层次清晰。
2. **数据优先**：数字突出、标签明确，让商家一眼看到关键指标。
3. **色彩丰富但不杂乱**：以数据平台蓝为主色调，辅以绿/橙/红/紫/青等语义色，不同模块可用不同主题色区分。
4. **移动端优先**：所有布局在 375px 宽度下可读可用，桌面端自适应扩展。
5. **单文件自包含**：所有 CSS 内联，不依赖外部 CDN/字体/图片，文件可直接转发他人打开。

| 用途 | 色值 |

## 字体与字号

### 字体栈
```css
font-family: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC', -apple-system, BlinkMacSystemFont, 'Helvetica Neue', sans-serif;
```

| 卡片标题 | 15-16px | 600 | 1.4 |
| 核心数据数字 | 24-32px | 700 | 1.2 |
| 次级数据数字 | 18-20px | 600 | 1.3 |
| 正文 | 14px | 400 | 1.7 |
| 表格内容 | 13-14px | 400 | 1.5 |

| 辅助说明/注释 | 12px | 400 | 1.5 |
| 标签/badge | 11-12px | 500 | 1.3 |
| 页脚 | 11px | 400 | 1.5 |

## 布局与间距

### 页面容器
- 最大宽度：`max-width: 960px`（桌面端），移动端自适应 100%。
- 页面左右内边距：桌面 `20px`，移动端 `12px`。
- 页面上下内边距：`20px`。

### 卡片
- 圆角：`12px`。
- 阴影：`box-shadow: 0 2px 12px rgba(0, 0, 0, 0.06);`
- 内边距：`20px`（桌面），`16px`（移动端）。
- 卡片间距：`16px`。
- 可选边框：`border: 1px solid #E5E6EB;`（阴影足够时可省略边框）。

### 模块间距
- 模块之间：`24px`。
- 模块标题与内容：`14px`。
- 卡片内元素间距：`12px`。

## 核心组件

### 1. 页面头部（Header）
```
┌─────────────────────────────────────────┐
│  [商家名] · 经营分析报告          [周期] │
│  城市 · 品类 · 门店数 · 生成时间         │
└─────────────────────────────────────────┘
```
- 白底卡片，左侧商家信息，右侧周期/时间。
- 商家名 20px bold，下方信息 12px `#86909C`。
- 右上角可放报告类型标签（如"经营亮点"/"经营体检"）。

### 2. AI 解读区
- 浅蓝渐变背景（见颜色体系），圆角 12px，边框 `#BEDAFF`。
- 标题前缀 `AI ✨ 解读`，14px semibold，主色 `#165DFF`。
- 右上角标注"注：基于算法&大模型得出，仅供参考"，11px `#86909C`。
- 内容为项目符号列表，14px 正文，行高 1.8。
- 关键数据加粗，可用主题色高亮。

### 3. 核心指标卡（KPI Cards）
- 网格布局：桌面 4 列，平板 2 列，手机 2 列。
- 每个卡片：指标名（12px `#86909C`）+ 数值（24-28px bold）+ 变化（12px，绿涨红跌，带 ↑↓）。
- 卡片之间用细边框或背景区分。
- 数值单位用较小字号（14px）附在数字后。

### 4. 数据表格
- 表头：背景 `#F7F8FA`，文字 12px semibold `#4E5969`，左对齐。
- 表行：14px 正文，行高 40-48px，底部边框 `#F2F3F5`。
- 悬停行：背景 `#F7F8FA`。
- 排名列：TOP1-3 用渐变徽章，4+ 用灰色圆形数字。
- 胜/平/败标签：绿/灰/红圆角 pill。
- 数字列右对齐。

### 5. 横向条形图
- 标签左对齐（固定宽度），条形图在右，百分比标注在条形末端或内部。
- 条形高度：16-20px，圆角 4px。
- 多商家对比用不同主题色区分。
- 背景轨道：`#F2F3F5`。

### 6. 迷你趋势图（Sparkline）
- 蓝色折线 `#165DFF`，线宽 2px，下方浅蓝填充 `rgba(22,93,255,0.1)`。
- 高度 32-40px，宽度自适应。
- 用于表格内或指标卡下方展示趋势。

### 7. 标签/徽章（Badge）
- 圆角 pill：`border-radius: 12px`，padding `3px 10px`，字号 11-12px。
- 类型：
  - 主色标签：蓝底白字或浅蓝底蓝字。
  - 语义标签：绿/橙/红底白字或浅底深字。
  - 排名徽章：圆形或圆角方形，渐变背景白字。
  - 热度标签：浅红底 + 🔥 + 红字。

### 8. 行动建议卡
- 左侧优先级标签（P0/P1/P2，红/橙/蓝），右侧内容。
- 内容包含：行动标题（bold）、问题描述、具体动作、预期效果、验收指标。
- 卡片底部可放"基线→目标"KPI 行。

### 9. 时间轴（下季度预测用）
- 垂直时间轴，左侧日期节点，右侧内容卡片。
- 节点用主题色圆点，连线用 `#E5E6EB`。
- 每个节点卡片：日期 + 热点名 + 适配建议 + 置信度标签。

### 10. 页脚
- 文字 11px `#86909C`，居中或左右分布。
- 内容：数据来源说明 + 生成时间 + 免责声明。
- 背景透明，上方细分割线。

## 响应式规范

### 断点
| 断点 | 宽度 | 布局调整 |
|------|------|----------|
| 桌面 | ≥ 768px | 多列网格、表格完整展示 |
| 平板 | 576-767px | 4列→2列，表格可横向滚动 |
| 手机 | < 576px | 2列→1列或2列，卡片内边距缩小，表格横向滚动 |

### 移动端具体规则
1. **页面容器**：`padding: 12px`，`max-width: 100%`。
2. **卡片内边距**：`16px`（从 20px 缩小）。
3. **KPI 网格**：保持 2 列，不降到 1 列（数字卡片 2 列更紧凑可读）。
4. **表格**：外层包 `overflow-x: auto`，允许横向滑动；最小宽度设为内容所需宽度。
5. **字体**：页面大标题降到 20px，核心数据降到 20-24px，正文保持 14px。
6. **AI 解读区**：padding 缩小到 14px，项目符号间距缩小。
7. **时间轴**：保持垂直布局，节点卡片宽度自适应。
8. **导航栏**（如有）：变为可横向滚动的标签栏，不换行。
9. **图片**：`width: 100%; height: auto;`，不固定高度。
10. **按钮/链接**：最小点击区域 44px × 44px。

### 媒体查询模板
```css
@media (max-width: 767px) {
  .container { padding: 12px; }
  .card { padding: 16px; border-radius: 10px; }
  .kpi-grid { grid-template-columns: repeat(2, 1fr); }
  .page-title { font-size: 20px; }
  .kpi-num { font-size: 22px; }
  .table-wrap { overflow-x: auto; }
  .table-wrap table { min-width: 480px; }
}
@media (max-width: 380px) {
  .kpi-num { font-size: 20px; }
  .card { padding: 14px; }
}
```

## 可分享性要求

1. **单文件自包含**：所有 CSS 内联在 `<style>` 中，不引用外部 CSS 文件。
2. **无外部字体依赖**：使用系统字体栈，不加载 Google Fonts 等外部字体。
3. **图片处理**：
   - 商家真实门店图：使用 `https://` 公网可访问 URL（确保接收方也能加载）。
   - 图标/装饰元素：优先使用 CSS 绘制、emoji 或内联 SVG，不依赖外部图片 CDN。
   - 如必须用外部图片，确保 URL 为公网可访问且长期有效。
4. **无 JS 依赖**：报告为纯静态 HTML+CSS，不依赖 JavaScript 渲染核心内容。如有交互（如 tab 切换），用 CSS `:target` 或 `<details>` 实现，不依赖 JS 库。
5. **文件命名**：使用中文有意义的文件名，如 `{商家名}-经营分析报告.html`，便于接收方识别。
6. **打印友好**：可选添加 `@media print` 样式，确保打印时背景色、卡片阴影正常显示（`-webkit-print-color-adjust: exact; print-color-adjust: exact;`）。
7. **编码**：`<meta charset="UTF-8">`，确保中文在任何设备上不乱码。
8. **Viewport**：`<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=5.0">`，允许用户缩放。

## 通用 HTML 骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=5.0">
<title>{报告标题}</title>
<style>
  /* 详见各技能模板中的完整 CSS */
  * { margin: 0; padding: 0; box-sizing: border-box; }
  body {
    font-family: 'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC', -apple-system, BlinkMacSystemFont, 'Helvetica Neue', sans-serif;
    background: #F5F7FA;
    color: #1D2129;
    line-height: 1.7;
    -webkit-font-smoothing: antialiased;
  }
  .container { max-width: 960px; margin: 0 auto; padding: 20px; }
  .card {
    background: #FFFFFF;
    border-radius: 12px;
    box-shadow: 0 2px 12px rgba(0,0,0,0.06);
    padding: 20px;
    margin-bottom: 16px;
  }
  /* ... 更多组件样式 ... */
  @media (max-width: 767px) {
    .container { padding: 12px; }
    .card { padding: 16px; border-radius: 10px; }
  }
</style>
</head>
<body>
<div class="container">
  <!-- 页面头部 -->
  <!-- AI 解读区 -->
  <!-- 核心指标 -->
  <!-- 各模块卡片 -->
  <!-- 行动建议 -->
  <!-- 页脚 -->
</div>
</body>
</html>
```
