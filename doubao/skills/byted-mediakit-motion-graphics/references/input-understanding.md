# 输入理解

## 工具选择

- 按 `byted-mediakit-shared` 的指引发现当前 CLI 能力，确认执行模式、参数格式（含布尔参数）、返回字段及单位；异步任务读取成功终态的结果。
- ASR 优先使用宿主已安装的 mediakit-cli；能力不可用时由宿主选择其他可用工具。原片元信息的工具选择见下节。
- 先检查宿主提供的素材路径或素材清单，复用同一原片的可用本地文件；即使同时有 URL，也不重复下载。已有本地文件时优先使用 FFmpeg 抽帧并拼雪碧图；仅有 URL 且无可用本地副本时，优先使用 mediakit-cli 云端抽帧，能力不可用或调用失败时才下载后使用 FFmpeg。后续补帧继续优先本地，已有可用帧直接复用。
- 图片理解按下方规则执行，适用于内容理解与候选时段布局观察。

### 图片理解

优先使用宿主自带图片理解工具；调用失败或因用户拒绝下载而无法使用时，回退到 MediaKit CLI 的图片理解能力（如 `video-understand-router`支持图片理解），具体命令与参数按当前工具说明获取。

## 原片基本信息

- 本地文件：直接使用 FFprobe 获取视频宽高、帧率与总时长。
- URL：优先使用 MediaKit CLI 的云端视频元信息探测能力；能力不可用、调用失败或必要信息缺失时，按工程接口的本地素材复用规则取得原片，再使用 FFprobe 补齐。
- 按当前工具说明读取结果并确认单位，宽高使用像素、帧率使用 fps、总时长换算为秒，核对所需数值为有效正数。
- 云端探测、ASR 和云端抽帧可直接使用原片 URL；工程准备时复用已有本地原片，仅缺少可用副本时才下载。工程要求见 [工程接口](project-contract.md#planjson)。

## 1. 执行 ASR

- 默认直接对原片执行 ASR，获取原语言文本与起止时间；工具支持时启用说话人区分。
- 保留工具返回的 Speaker ID；无可靠依据不映射姓名。
- 确认无语音：转第 3 步画面理解。工具失败时换可用工具，不当作无语音。

有语音时先完成 ASR 校对与内容分析；已足够确定主题和候选动效内容时直接进入规划，选定候选时段后再看图判断风格与布局。

## 2. 校对并分析

1. 通读 ASR 文本，修正依据明确的同音词、专名、标点及断句，概括保留关键含义、否定和人物指代。不默认抽帧、裁切或识别硬字幕来核对 ASR。
2. 仅对影响动效内容的专名、关键数值、否定、身份等疑点局部听音或重识别；未能确认则保留原文、标记疑点，动效避开不确定信息。个别非关键疑点不触发提前抽帧。
3. 保留时间和 Speaker ID；对截取的音频进行识别时，将识别时间加上该片段在原片中的起始时间。没有词级时间不构造逐字时间戳。
4. 将同一份校对结果保存为 `transcript.srt` 和 `transcript.json`，不另存多个工作版本；JSON 另记工具实际返回的说话人和置信度，以及必要修正依据和疑点。
5. 判断主题、视频类型、语言、段落与信息需求。已足够选点则进入 [规划](planning.md)；仅有影响选点且无法从 ASR 确定的具体画面疑问时，进入第 3 步。

## 3. 按需补充画面理解

仅在确认无语音，或存在影响选点且无法从 ASR 确定的具体画面疑问时执行。先明确要解决的疑问及相关时段；不以“了解画面风格”或“寻找留白”为由单独粗抽全片，这些判断与规划阶段的候选时段看图合并完成。

1. **粗抽雪碧图**：疑问能定位时只覆盖相关时段；无语音或影响选点的疑问无法定位时才覆盖全片。默认每 5 秒取一帧，包含范围首尾附近的有效时刻；首轮总计最多 48 帧，超出时均匀增大间隔，短片不补足配额。按每张最多 12 帧批量查看雪碧图，不默认逐张读取单帧。
2. **看图**：实际查看全部粗抽雪碧图，对照字幕确定主题、类型、段落与信息需求，记录仍有疑问的时间段。
3. **细抽**：每个疑问时段先均匀取最多 12 帧，生成一张雪碧图；仍不明确时缩小到具体疑问范围补抽。同一时间点已有可用图片时直接复用，避免重复抽取。
4. **停止**：信息足够即结束。补抽不再增加有效信息时记录疑问，动效避开未确认内容。

粗抽和细抽均使用 4 列 × 3 行的雪碧图；单帧长边建议 640 像素，不超过原片，保持原始比例和时间顺序。

输出主题、类型、段落及未解决问题，交给 [规划](planning.md)。后续布局抽帧由规划阶段在选定候选时段后执行。

## 4. 帧索引交接

用 `frames.json` 记录实际看过的雪碧图或单帧，不逐帧重复 URL：

```json
{"schemaVersion":2,"sheets":[{"id":"s1","url":"<实际图片URL>","timesMs":[2000,3000,4000,4967]}]}
```

- `timesMs` 按从左到右、从上到下记录原片毫秒，忽略填充空格；严格递增。
- 默认 `columns:4`、`timeBasis:"requested"`。工具报告时间用 reported，按已确认间隔推算用 interval；只有实际解码时间才用 actual。
- 本地图片把 `url` 换成 `path`；单帧用 `columns:1` 和一个时间点。
- 动效 `views:["s1"]` 表示看过整张图；只看过部分时写 `views:["s1:1","s1:3"]`，格子从 1 开始。保护区用同样的格子引用。
- 看过后保留观察和索引即可，不要求图片永久保存或 URL 持续有效。
