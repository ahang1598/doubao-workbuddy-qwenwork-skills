# 场景选型

按已理解的内容选类型和意图；混合节目按片段处理。仅添加有明确功能的节点，根据节点需求设计图形并编写自定义动效。

## 选择思路

以下映射是设计参考，不是固定模板或穷举清单。Agent 可按内容自由组合、改编或设计其他表现，具体构图、样式和动作由 Agent 决定。

1. **内容决定表达形式**：先判断节点是介绍身份、强调观点、解释关系、呈现数据还是烘托情绪，再选择有助于观众理解的图形。
2. **视频风格决定表现方式**：结合用户要求、原片气质和当前片段情绪安排配色、质感与动作。例如同样是数字强调，财经访谈可用简洁数字与轻淡入，综艺可用放大弹出与反应装饰。
3. **实际画面决定落点与可行性**：先按 [大小与视觉分量](motion-authoring.md#大小与视觉分量) 保证清晰可见，再依据留白、背景和主体位置选择落点；空间不足按 [位置与保护区](motion-authoring.md#位置与保护区) 处理。

优先选择有信息价值或情绪依据的节点：普通陈述不必句句花字；严肃片段通常不适合搞笑反应；单个数值可直接强调，有比较或趋势依据时再考虑对应图表。按 [分组设计](motion-authoring.md#分组设计) 覆盖不同表达需求并统看全片表现分布，不为凑种类添加无关特效。

## 视频类型

| 视频类型 | 优先考虑的表达 | 强度与适用条件 |
| --- | --- | --- |
| 访谈 | 人物条、作品与故事背景、关键词、金句、章节、数据 | 正式访谈克制；娱乐访谈可结合综艺反应，不能因“访谈”二字一律压低表现 |
| 综艺 | 反应花字、动态图文、贴纸、拟声文字、人物标注、段落标题 | 情绪节点可高表现，频率随有效笑点而定，给表演留白 |
| 视频播客 | 说话人标识、人物条、金句、章节、背景解释 | 强调对话结构；身份已清楚时不重复标识每次切镜 |
| 口播短视频 | 开场标题、重点字幕、大字、数据、行动引导 | 节奏可快，Hook必须来自真实内容；字幕与CTA按任务需要 |
| 教程 / 科普 | 步骤、示意图、流程、标注、数据、公式 | 清晰优先，动作呈现顺序和因果，避免装饰抢步骤 |
| 产品视频 | 功能引线、热点、操作路径、参数、对比、产品名 | 避让关键产品细节；移动目标需要可靠位置依据 |
| 企业宣传片 | 人物条、数据、时间线、章节、地点、品牌片尾 | 稳定可信，品牌素材及数据需有来源 |
| 纪录片 | 身份、地点、日期、来源、时间线、地图、引用 | 通常克制，保护原片情绪，不擅加综艺反应 |
| 新闻 | 来源、地点、日期、人物条、地图、数据、标题 | 准确、清楚；区分事实、引用和编辑概括 |
| 体育分析 | 位置、轨迹、战术图、比分、数据 | 标记须与目标和时间匹配；不能虚构运动轨迹或热力数据 |
| 游戏视频 | UI提示、角色标记、反应、比分、成就、地图路径 | 区分娱乐实况和战术分析；不遮关键游戏HUD |
| 广告 | Hook、产品重点、卖点、报价、品牌、行动引导 | 围绕明确利益点；价格、优惠、链接等必须有依据 |


## 节点与表现

下表提供图形结构与动画方式的参考。Agent 可参考其中的建议，也可根据内容和视频风格自行设计更合适的表现，不限于表中形式。选定方案后自行编写 HyperFrames，字号遵守 [大小与视觉分量](motion-authoring.md#大小与视觉分量)。

| 场景 / 触发事件 | 图形与构图建议 | 动作与揭示建议 |
| --- | --- | --- |
| 人物首次出现、身份易混淆 | 姓名与身份分层的人物条、人物旁名牌 | 强调线先展开，姓名进入，身份随后显现；不必固定底部 |
| 提到未出镜人物、人物关系影响理解 | 人名与相关身份短注，或人物关系示意 | 提到姓名时出现，关系随讲述展开；与出镜人物名牌明确区分，不让指向误认对象 |
| 提到电影、小说、音乐剧等作品 | 作品名与一句相关背景；有已确认匹配的海报或封面时可配图，无素材可纯文字 | 名称先出现，再补与当前谈话有关的角色、创作或情节背景；不提前揭晓故事包袱 |
| 讲述往事、故事或事件，需要交代背景 | 时间地点短注、人物关系图或简短事件梗概 | 跟随讲述补齐理解所需的信息；复杂关系逐步展开，避免同时铺满说明 |
| 提到典故、文化梗或不熟悉的知识 | 关键词与一句释义，必要时配来源或简图 | 在相关表达后补充含义，再回到谈话；不把解释抢在笑点或揭晓之前 |
| 产品亮相、核心结论、开场利益点 | 大小字分层标题，短眉题与主字错位；底板按背景需要选择 | 主字先建立焦点，再展开强调线、补充说明；避免所有层同时淡入 |
| 新章节、新话题 | 编号、主题字与段落标记，可用无底板大字 | 编号先出现，标题上移，线条展开；在话题切换处完成揭示 |
| 关键词、短促情绪 | 描边花字、偏移色影、纸贴或印章；可轻微倾斜 | 短促放大或转正落定；装饰响应重音，随后静止 |
| 惊讶、尴尬、吐槽 | 惊讶用爆炸字或放射线，尴尬用省略号/停顿，吐槽用旁白气泡 | 惊讶快速弹出，尴尬延迟揭晓，吐槽可短抖一次；不要都用同一弹入 |
| 纠正、反转、改口 | 原词、划线、替换词组成同一构图 | 先铺垫原词，到真实改口时划掉并替换；不能预告答案或编造原话 |
| 递进短句、悬念揭晓、连续重音 | 分拍大字，可逐行左右错位，末项重点放大 | 按语义依次揭示，最后一拍完成结论；不是无词级依据的逐词字幕 |
| 金句、完整观点 | 引号、正文与署名分层；可开敞排字或局部引用纸片 | 引号引入，正文显现，署名后置；阅读期保留完整句子 |
| 陌生术语、专业概念 | 术语与一句释义，或概念图配短注 | 先术语后释义；有关系或机制可画图解释，不只叠一张说明卡 |
| 单项数量、金额；并列规格 | 大数字与单位，或等层级的多项数字组 | 数字可递增至真实值；多项按口播错峰展开，结束后稳定显示准确值 |
| 有依据的百分比、完成度 | 条形、圆环与数值 | 填充至真实比例；填充仅作视觉揭示，不暗示真实过程或虚构评分 |
| 并列卖点、原因、收纳清单 | 图标清单、散排纸签或要点列；各项可有独立位置 | 随信息逐项加入、勾选或重点变色；不把所有项提前一次亮出 |
| 真实操作步骤 | 节点与连接线、步骤轨道 | 随实际操作推进连线，高亮当前步骤，已完成项降弱 |
| 两个方案、前后变化、观点对照 | 左右或上下对照、中心分界，共用信息层级 | 两侧先后展开，差异处再强调；同口径比较，不自动宣布胜负 |
| 历史复盘、里程碑 | 时间线、日期节点 | 依事件顺序展开节点和连线；等距排布只表示顺序，不表示时间跨度 |
| 指出部件、按钮、局部细节 | 轻量圈选、框选、下划线 | 沿轮廓描出或横向展开，必要时再补短标签；保持目标细节可见 |
| 功能解释、空间指向 | 目标端点、引线与旁侧短注 | 端点定位、引线伸展、说明揭示；移动目标须有可靠轨迹或缩短标注时段 |
| 日期、地点、出处 | 紧凑背景标签、来源标记 | 类别与正文短距错峰出现，不扩成无必要的大卡片 |
| 材质、穿搭配色、款式选择 | 色样组合、材质局部纹理、对应物件的小插画 | 色样逐个落定并组成搭配，图标与文案呼应；不是给每条贴同一底板 |
| 抽象机制、因果、公式 | 节点图、分层示意、公式推导 | 沿解释顺序连接、拆解或替换，动作表达关系 |
| 战术、路线、排行、趋势 | 轨迹、站位、排行或图表 | 高亮关键路径、差距或转折；须有相应位置与数据依据 |
| 原片确需字幕或歌词同步 | 动态字幕、重点词着色 | 句级切换；有可靠词级时间时再逐词强调，不重复叠加已有字幕 |
| 真实评论、账号、话题；明确行动引导 | 评论气泡、账号条、按钮或链接 | 评论逐条揭示；账号图标或按钮可强调一次，在自然停顿或片尾出现 |
| 栏目、品牌、片头片尾 | 标志揭示、短段落标识、片尾落版 | 由品牌形状或线条形成标志，再出现名称；不擅加未提供的品牌素材 |
| 任务明确需要的提醒、声明 | 清晰提示条或文字区 | 稳定显现并留阅读时间，避免娱乐化抖动 |

### 避免只有“不同外观的文字卡”

- 同一段素材有不同需求时，优先改变信息的组织与揭示方式：对比用两项对照，顺序用分步推进，细节用标注，反转用划词替换；不要全部做成图标加文字再整体淡入。
- 同组保持字体、配色和质感一致，动作按语义选变体；同类内容仍可复用。底板可有可无，构图可错位或倾斜，阅读阶段保持稳定。
- 例如种草视频可用开场大字 → 工艺圈注 → 收纳示意 → 物品逐项归入 → 配色色样；娱乐访谈可用人物名牌 → 分拍铺垫 → 反转改词 → 数字强调 → 开敞金句。只选有内容和画面依据的形式，不照顺序套用或凑种类。

## 写入计划

- 类型与目的写入 `plan.style.referenceReason`；每条的主要意图写入 `plan.effects[].reason`，名称不受枚举限制。
- 数值、引用、身份、价格和行动引导使用有依据的内容。
- 逐词字幕需要词级时间；移动标签需要可靠轨迹。缺少时改用句级强调、短时固定标注或独立示意图。
- 按节点的信息需求与视频风格确定图形结构，按 [动效编写](motion-authoring.md) 实现。
