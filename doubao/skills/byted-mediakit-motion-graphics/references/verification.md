# 执行与交付

前置：规划与工程已完成，Agent 已按 [规划](planning.md#4-写计划) 核对频次、覆盖率及偏离原因。实际工程测量须通过后再渲染；修复只修改受影响条目的计划和源码。

全部复测完成后关闭测量服务，调用一次 render，再 compose；禁止多个 render 命令同时处理同一任务清单。

## 1. 必要检查

- prepare 和 render 都会在读取计划时校验字段、参数、时间、画幅内范围、保护区与同期动效重叠。
- render 确认原工程存在、原片画幅、帧率和时长均与计划一致、自定义代码已完成，再生成局部副本或回退整帧渲染。
- 运行错误由渲染命令报告；渲染及后续检查发现的问题由主 Agent 修复。修改布局或时间时同步更新并校验计划，内容或排版变化后重测受影响条目，再继续渲染。

### 渲染前视觉检查

新样式选一条代表动效，在稳定阅读时刻截图并叠到同一时刻的源帧，检查文字对比与实际位置；同样式且背景条件相近时复用样式判断，背景明暗或布局明显变化时补查对应条目。引线或圈注另检查各自目标是否准确，目标移动时补看相关时刻。只修正并复查受影响项，不先编码整段透明视频来做静帧检查。此检查与下方几何诊断不同。

### 可选诊断

仅在文字溢出、位置或运行异常需要定位时执行：

```bash
node <skill>/scripts/preview.mjs <task>/plan.json --effect intro --browser "<浏览器可执行文件路径>"
```

preview 仅输出诊断 JSON，不生成预览图片。它检查阅读期开始、中间、结束前三个时刻的文字与边界，不代替静帧视觉检查或全程运动检查。

## 2. 渲染与合成

```bash
node <skill>/scripts/render.mjs <task>/plan.json --browser "<浏览器可执行文件路径>"
node <skill>/scripts/compose.mjs <task>/artifacts.json <output>/final.mp4
```

默认 `--jobs 2`，最多同时渲染两条动效，每条固定 1 worker，较长动效优先。可用 `--jobs 1|2|3` 手动调整。

默认按 `motionBounds` 加 32 像素安全余量生成局部渲染副本，向外按 16 像素对齐并限制在原片内。原工程与测量保持原片坐标，合成使用清单中的局部 `x/y`。仅支持标准 `shellHTML` 结构；缺少范围、覆盖全屏、非标准结构，或检测到 viewport 单位、fixed/sticky 定位、媒体查询及屏幕尺寸读取时回退整帧。静态检测无法识别所有自定义代码依赖；不能确认局部渲染安全时，给该条设置 `canvasMode:"full"`。`motionBounds` 必须覆盖全程阴影、装饰与进退场；安全余量不能弥补错误范围。需要额外余量可设置 `canvasPadding`（0–1024 像素）。

失败后保留已成功素材，等待在途任务结束后修复并重试。任务目录的 `.render.lock` 阻止重复启动；异常终止遗留锁时，确认 owner.json 中的进程及其渲染子进程已退出，再移除锁目录后重试。

默认重复运行 render 会复用原片路径、工程代码、渲染参数、局部尺寸与坐标未变化且素材文件摘要一致的成功素材，只补渲染缺失或变化的条目。失败后修复对应工程，再执行同一命令继续。保留 artifacts.json、成功素材和未修改工程，不为单条修复重建全部工程或强制重渲全部条目。仅改叠加起点或层级且工程未变时，运行 render 更新清单并复用素材，再 compose。

强制重渲染指定条目（可重复传 `--effect`）：

```bash
node <skill>/scripts/render.mjs <task>/plan.json --effect intro --browser "<浏览器可执行文件路径>"
```

指定条目以外的素材必须仍可复用，否则命令提示需补渲染的条目。全部完成后才生成可合成的完整清单；重渲染成功后替换对应素材，失败保留此前文件，未完成清单不可合成。

- render 在每条素材渲染后、compose 在合成前，均在脚本内部调用本地 FFprobe 检查编码、ProRes 4444 profile、带 alpha 的像素格式、尺寸和时长；render 还检查帧率。
- render 遇到等比例整数倍的超采样输出时，自动缩放回该素材的目标画布尺寸并保留 ProRes 4444 透明通道，再校验素材；其他尺寸不匹配仍报错。
- compose 使用生成的 artifacts，合成后确认命令成功、文件存在且非空。
- 保持原片分辨率、帧率和音轨，质量优先编码并控制体积；具体编码规则见 [工程接口](project-contract.md#最终成片压缩)。
- 仅排查透明度异常时，用 `check-alpha.mjs effect.mov width height --bounds '<矩形JSON>'` 检查逐帧范围与末帧；尺寸和 bounds 使用素材局部坐标，原片坐标先扣除清单 x/y。

## 3. 按需查看成片

仅在用户要求测试或评估成片，或遇到视觉异常时，查看相关叠加画面及切镜前后，必要时播放对应短片段。记录实际观察与未验证项；修复只重做受影响条目。不默认增加全片逐帧检查。

## 4. 交付

- 返回最终 MP4 链接；不默认附字幕、工程或报告。
- 保留任务计划、字幕、源帧索引、动效工程、透明素材及日志，成功或失败均不自动清理。
- 仅在用户明确要求清理时执行，避免删除用户输入、最终视频或未知文件。
