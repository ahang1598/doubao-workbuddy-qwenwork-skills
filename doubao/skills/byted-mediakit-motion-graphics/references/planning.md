# 动效规划

前置：已完成 [输入理解](input-understanding.md)。本阶段确定什么时候添加动效、表达什么、全片风格和分组；具体样式与动作留到编码时设计。

## 1. 选节点

1. 根据已理解的内容判断视频类型；确定各节点的表达目的；选型不明确时参考 [视频类型](scenario-selection.md#视频类型)，具体动作建议在实现时读取。
2. 依据用户要求或 [密度参考](#密度参考)，先确定目标频次、总量和覆盖率，写入 `plan.style.motion`。总量按原片时长换算取整；混合类型按段落时长分别计算。用户明确指定的频次或数量不得自行下调。
3. 遍历全片，逐条确定动效要帮助识别、理解、比较还是表达情绪；只有重复字幕、没有强化作用的候选可合并或替换。保留有关联的铺垫、对比和揭晓，不只摘取孤立关键词。
4. 判断观众是否需要人物身份、作品、故事事件或典故背景才能理解当前对话；需要时纳入候选节点。只补与当前话题有关的一两句，不因每次提到名称就重复介绍。
5. 写候选节点与时间范围，核对数量和分布后再抽帧，一并判断画面风格、可用空间与保护区，不先增加一轮全片风格粗看。

写入 `plan.nodes`，例如：

```json
{"id":"intro","startMs":2000,"endMs":5000,"summary":"新品登场","evidence":"字幕3–5","priority":"key"}
```

`priority` 可填 `key`（重点）、`optional`（可选）或 `leave`（不添加）；未入选节点填写 `omissionReason`。

背景补充先确认人名、作品名及所指对象；原片之外的事实用可靠资料核实，在节点 `evidence` 中简记来源。不确定时只使用已确认的信息，或省略该补充，不把猜测写成事实。

### 触发与结束

- 情绪与包袱贴合实际反应或揭晓短语，不提前亮出答案；名称和术语跟随实际提及。
- 多项内容按各自口播揭示；金句覆盖完整表达并留阅读时间，不在原话未结束时提前退出。
- 标注仅在目标清楚可见时出现；跨切镜是否保留，在实现时依据源帧确定。
- 字幕时间过粗时仅复听相关短句或局部重识别，不把整段起点当作关键词时间。不确定的时间不伪称词级对齐。
- 将触发依据简记在节点 `evidence`；具体揭示时序直接写入代码。

### 密度参考

以下数值供参考，不是硬性上下限；编码前核对节点数量、时段与分布，合理偏离简记原因。

| 节目类型 | 每分钟事件数 | 动效显示覆盖率 |
| --- | --- | --- |
| 纪录片、严肃采访 | 1–3 次 | 5%–20% |
| 深度访谈、长播客 | 2–4 次 | 10%–25% |
| 娱乐访谈、脱口秀 | 4–8 次 | 20%–45% |
| 真人秀、游戏综艺 | 6–12 次 | 30%–60% |
| 知识口播、短内容 | 5–10 次 | 25%–55% |
| 教程、科普 | 3–6 次 | 30%–65% |
| 产品测评 | 3–7 次 | 20%–45% |
| 企业介绍 | 2–5 次 | 15%–35% |
| 新闻资讯 | 2–5 次 | 15%–40% |
| 体育、游戏的比赛与操作段 | 1–3 次 | 5%–20% |
| 体育、游戏的复盘分析段 | 4–8 次 | 25%–55% |
| 广告、预告 | 6–12 次 | 35%–70% |

- 按语义段落选择倾向，混合类型分段处理；用户要求优先。
- 只计新增动效事件；覆盖率取显示时段并集。普通字幕、常驻标识和原片包装不计入统计。
- 大字、强运动、长文案及拥挤原画面降低频次；短反应可局部集中，说明图可少次长停留。
- 不按固定间隔撒点。数量不足先检查遗漏的有效信息与情绪节点；过密先合并重复表达；同镜头相邻不构成必须合并的理由，不为凑参考数值合并条目。确实无合适节点或空间时，记录具体时段和原因，不用“克制”“留白”笼统代替。
- 将类型、时长、目标频次、总量和覆盖率、各段分布及运动强度写入 `plan.style.motion`，完成布局后补上实际值及偏离原因。用户指定的目标无法满足时说明阻碍，不改成表中参考值。

示例：`娱乐访谈，300秒；目标4–8次/分钟、20–40条、覆盖20%–45%；最终26条、5.2次/分钟、覆盖31.2%；按各话题笑点分布，短促弹出，保留听述与表演。`

## 2. 看候选时段

候选时段确定后，按 [工具选择](input-understanding.md#工具选择) 抽帧并输出雪碧图。

各候选时段的抽帧请求可按宿主允许的并发执行。单条动效先取得并查看源帧，再确定布局；主 Agent 汇总观察并统一写入 `plan.json`、`frames.json`。统一风格后的分组制作见 [编写与测量流程](motion-authoring.md#编写与测量流程)。

1. **初采样**：先取各候选时段的起点、中点、结束前有效帧，复用已看过且适用的帧。批量生成整帧雪碧图，每张最多 12 帧，可合并多个候选时段并标明时间。
2. **看图识别空间**：按 [图片理解](input-understanding.md#图片理解) 的工具选择规则理解各时段雪碧图，确认风格、人物、手势、原字幕、关键文字与产品细节，结合移动和切镜记录可用空间及保护区；动效尺寸与最终位置在下一阶段确定。
3. **局部补帧**：初采样不能证明全程无遮挡；长时段、移动目标、切镜或遮挡不确定时，加密相关时段，必要时播放短片段。仅对看不清的细节查看清晰单帧或裁切，不默认再做裁上部、整帧并排等重复检查；信息足够即停止。

保持图片比例，记录每格原片时间；布局坐标使用原片像素。索引格式见 [帧索引交接](input-understanding.md#4-帧索引交接)。

## 3. 定风格与表现

依次参考用户要求、认可样片、已看过的候选时段源帧；缺少局部信息时补帧。

### 风格匹配

| 场景 | 表现倾向 |
| --- | --- |
| 新闻、正式访谈 | 稳定对齐、清楚分层、克制运动 |
| 综艺、娱乐访谈 | 主体附近的花字、错位、倾斜、气泡、短促弹出 |
| 种草、生活方式 | 手账贴纸、材质色片、局部标注、轻弹或甩入 |

用户和原片风格优先；只在内容需要时使用对应表现，不机械套用。

### 写入 style

- `referenceReason`：视频类型、用户参考及原片特征。
- `fontFamily`、`palette`、`layoutLanguage`：全片字体、配色与视觉基调。
- `motion`：全片目标与实际密度、分布和运动强弱，不写逐条动作设计。
- `groups`：按相同表达需求分组，简记用途；每条用 `group` 引用。不同需求不为复用方便强行合组。

具体字号、构图、底板和动画由 [实现阶段](motion-authoring.md) 设计并写入共用代码，不在计划里复述。脚本所需的 `minFontSize` 与布局数据在实现时补齐。

## 4. 写计划

`plan.json` 记录节点时间、要表达的内容、表达目的、全片风格与分组；`frames.json` 记录已看源帧。用节点 `summary` 或单条 `reason` 简记内容及目的，不另写详细设计稿。

进入 [动效编写](motion-authoring.md) 后，在同一计划中补齐工程所需字段，prepare 前使用可用候选矩形，测量后回填最终位置、范围和阅读期。字段与完整示例在实现时读取 [工程接口](project-contract.md)。

编码前完成节点密度与重复表达判断；执行字段补齐后运行 `validate-plan.mjs plan.json`，将实际频次、覆盖率及各段分布写回 `style.motion`，合理偏离简记原因。后续增删动效、改变时间或布局时同步计划并重新校验。

取默认值的可选字段可省略，公共信息只写一次，使用 JSON 序列化写文件，不另写中间配置副本。
