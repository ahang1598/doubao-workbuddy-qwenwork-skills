# Compare and Summarize Metrics

先锁定范围和口径，再从明细提取、对齐、复算并解释差异。任何结论都应能回到来源位置、计算式和可见边界。

## 流程

### 1. 锁定目标与数据覆盖

1. 明确分析对象、商家或个人视角、目标周期、比较维度、输出形式及问题。
2. 逐个文件列出来源、工作表、覆盖日期、粒度和可见范围；目标月份或维度不足时，先列已具备项与缺失项，只分析现有范围并请求补充。
3. 涉及首期与上一期比较时，额外取得边界参照期。例如展示期从 `25081期` 开始，计算重号必须补取 `25080期`，不能把首个展示期的比较值留空或拿自身作参照。
4. 飞书表格只圈选 `耕地面积数据!B4:G13` 时，分析范围必须标为该区域；`A23` 返回空值不能被解释为不存在整张表或不存在某年度数据。

### 2. 冻结指标口径

1. 建立口径表：指标、分子、分母、单位、日期字段、分组字段、去重键、过滤条件、来源位置。口径未确认，不直接下结论。
2. 不得把 `获客渠道` 与 `添加渠道` 当成同一个分组字段；复算 `互动率` 前要写清分子、分母，并按同一字段重算总计与关键分组。
3. `耕地面积（万亩）` 按调查口径分段：2015—2017年的“统计年鉴口径”、2019年的“三调/国土变更调查”和2024年的“国土变更调查”不可直接串成同口径同比序列；跨段跳变先标为口径变化，段内才计算趋势。
4. 订单月度汇总必须明确采用哪一个订单日期字段。若结果被质疑，分别按相关日期字段复算，并列出跨月归属发生变化的订单后再请用户确认口径。
5. 仅有 `M±SD` 时，ANOVA 必须先取得每组样本量 `n`；证据上下文中的 `n=30` 只能在同一任务已明确沿用时使用，不能推广到新数据。

### 3. 提取、清洗并保留血缘

1. 从表格、报告正文、截图或文档表格抽取字段，同时保留 `来源文件`、`工作表/页码`、`单元格区域` 或 `截图编号`；汇总结果必须可回查明细。
2. 将金额千分位、百分号和文本数字转成数值后统一单位，再汇总 `消耗`、`转化`、`留存`、`ROI`；“—”表示缺失，不按 `0` 参与求和、均值或增减率。
3. DOCX 先解析 `word/document.xml` 中的正文和表格；若数据只存在于嵌入图片，应标为图片型数据并转入 OCR/读图流程，不得把未识别图片冒充已提取表格。
4. OCR 后逐格复核影响计算的 `花费`、`转化`、`CPA`、`CTR`，并记录截图可见范围；模糊单元格保留缺失标记，不猜值。
5. 口径以原始明细为准；已有汇总结果仅作交叉校验。二者不一致时，以明细复算结果为真，并报告差异行、差异额及可能的刷新或口径原因。

### 4. 建立可比主键并对齐

1. 只在时间范围、单位、分组规则与对象粒度一致后比较；对齐表至少保留 `比较主键`、`本期值`、`上期值`、`来源` 和 `可比状态`。
2. 两月广告素材必须先按 `ID` 匹配共有素材；新增或消失的 `ID` 单列为结构变化，不混入“同素材环比”。
3. 人机工位不得混用 `单机C/T` 与 `1人3机工位C/T`：先拆人工时间和机器时间，再按设备数折算工位节拍，并用人工负荷检查瓶颈。
4. 对耕地表按“省份 + 年份 + 调查口径”对齐；相同省份但不同调查口径的行标记为“不可直接同比”，不能仅按省份和年份强行连接。

### 5. 复算核心指标

1. 同口径下计算：增减额 = 本期值 − 上期值；增幅 = 增减额 ÷ 上期值；占比 = 分项 ÷ 同口径总计。上期值为 `0` 或缺失时，增幅记为不可计算而不是 `0%`。
2. `ROI`、转化率、`UPH` 等派生指标必须展示分子、分母和单位；`UPH` 使用已确认的工位节拍，不得拿 `单机C/T` 直接替代 `1人3机工位C/T`。
3. 签约窗口价格按 `10月31天、11月30天、12月5天` 加权，并与“次年年度长协价”对应后计算溢价；正常年份与触限年份分开汇总。
4. 用 `M±SD` 做单因素 ANOVA 时，依次计算组间/组内 `SS`、`df`、`MS`、`F`、`P`，并在结果旁披露各组 `n` 和仅有汇总统计量这一假设。
5. 重号类指标先写出集合交集等统计公式，再批量计算；用首期、末期和随机中间期抽检，确保边界参照期已纳入。

### 6. 定位异常与解释差异

1. 先做勾稽检查和量级检查：统一税率、币种、面积单位及百分比尺度后再归因。数值异常若可由“元/万元”“亩/万亩”或百分数/小数转换解释，应归为单位差异，不写成业务变化。
2. 区分绝对规模与环比增速；“规模最大”不能改写为“增长最快”。`耕地面积（万亩）` 在“三调”切换点的跳变只能先解释为调查技术或认定标准变化，除非另有业务证据。
3. 数据被质疑时，回查原文和页码，区分“直接披露”“由公式推算”“可能原因”；无法验证的异常原因只列可能性及所需证据，不伪造因果。
4. 汇总值与明细复算不一致时，列出所用日期字段、分组字段、过滤条件和差异订单或差异行；不要只用一句“口径不同”结束解释。

### 7. 输出结论并支持迭代

1. 按“总体结论—关键对比—异常与口径差异—机会点/建议—待补数据”组织；每个数字带周期、单位、对象及来源位置。
2. 先给可复核对比表，再写结论。表中把“缺失”“不可比”“OCR待核”与数值 `0` 分开表示。
3. 用户多轮删改列时锁定最终表头，每轮只做最小变更并保持行顺序与统一结构。例如用户将表头收敛到 `套餐名称`、`售价`、`销量`、`售卖金额` 后，不再恢复已删除的“原价”“折扣”或“包含内容/说明”，总计只对 `售卖金额` 求和。
4. 若用户纠正目标（如从“指出不足”改为“只讲解吉林省耕地面积”），保留已核验的数据与口径，只改分析范围和措辞，不重做无关部分。

## 工具使用

- 表格读取：先检查工作表、表头、日期列、公式值和隐藏单位；金额与百分比清洗后再计算，原值另列保留。
- 文档解析：优先提取正文表格及页码；DOCX 的图片型指标进入 OCR，不把 `word/document.xml` 未返回内容视为零值。
- OCR/截图：记录图片编号和可见区域，逐格核验进入 `花费`、`转化`、`CPA`、`CTR` 计算的值；截图外数据一律标缺失。
- 基础计算：使用脚本或表格公式复算时，保存公式、过滤条件和抽检样本；至少核验总计、首尾期及异常行。

## 边界与禁止事项

- 不在口径未确认时下结论，不混用不同日期字段、单位、调查口径或分组字段。
- “—”、空白单元格、缺页和截图外区域都是缺失，不得按 `0` 填补；目标月份不足时明确请求补充。
- 不将 `获客渠道`/`添加渠道`、`单机C/T`/`1人3机工位C/T`、统计年鉴/三调口径互换。
- 不把无法验证的异常原因写成事实；医疗、投资等高风险材料只做数据层面的描述和核验，不替代专业判断。
- 多轮修改保持统一表结构；除用户明确要求，不改变已确认公式、单位和比较主键。

## 示例

用户要求解释吉林省多年耕地面积时：先从 `耕地面积数据!B4:G13` 提取年份、吉林值和口径列，把“—”保留为缺失；仅在“统计年鉴口径”内部计算同比，将“三调/国土变更调查”起点单列为口径断点；最后输出同口径趋势、口径切换说明、可见范围和待补年份，不把跨口径跳变写成真实扩张。
