# 环境特有故障

## 锁定失败

为失败与对照执行建立可比较画像：实际命令与工作目录、运行时或工具链、依赖解析、配置、权限、系统能力、缓存和前置产物。区分能改变当前错误预测的差异与无关差异。

## 做有区分力的比较

选择成功样本或可重放环境，只比较画像中会改变当前错误预测的条件。可以一次控制一个条件，也可以比较不可拆分的条件组，但必须说明不同结果分别支持什么解释。

## 判定和复验

- 匹配环境后仍沿同一代码路径失败，继续按代码原因处理。
- 只有某个环境事实改变才触发，并在恢复后让同一命令通过，修复可复现的声明、锁定或兼容路径。
- 失败位于不可见的外部系统时，保留可用身份和首个错误，说明当前边界，不猜测内部原因。

修复后同时确认需要继续支持的对照环境没有被破坏。
