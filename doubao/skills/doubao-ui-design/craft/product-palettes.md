# 产品/后台配色库（dashboard / console / SaaS 专用）

> 写 **dashboard / 后台 / 工作台 / console / 数据 App / SaaS** 界面配色前必读（F13 / F14，及 F19 的仪表盘屏）。
> 品牌页（landing / campaign / 内容站）走 `aesthetic-baseline.md` §2 的**四槽 + 材料推导**即可；
> 但**一块仪表盘大部分像素是中性灰**，四槽太粗，需要本文件的扩展 token 契约。
>
> **本文件存在的唯一理由**：`aesthetic-baseline.md` 禁了框架默认三件套（`#3B82F6` 蓝 + `#22C55E` 绿 + `#F97316` 橙），
> 但**只禁不给替代品 = 模型还是会伸手去够蓝**。从这里选一套锁死,"扁平白卡 + 蓝按钮"在结构上就写不出来了。

## 1. 扩展 token 契约（产品register；CSS 里不许出现裸 hex）

```css
:root{
  /* 基底 —— 见 §2 中性阶 */
  --page:      ;  /* 页面底。永不 #fff/#000，向 accent 色相微染 */
  --bg:        ;  /* 卡片/面板，浮在 --page 上 */
  --panel-2:   ;  /* 内嵌：图标底、表头、代码块、输入框 */
  --border:    ;  /* 发丝线，3–8% ALPHA —— 绝不用硬 #ccc/#333 */
  /* 墨（三级，dashboard 的关键） */
  --ink-1:     ;  /* 标题、大数字 */
  --ink-2:     ;  /* 正文、表格单元 */
  --ink-3:     ;  /* 标签、caption、坐标轴字 —— 仍须 ≥4.5:1 on --bg */
  /* 品牌 —— 见 §3 accent */
  --accent:    ;  /* 唯一。主按钮、当前导航、关键序列 */
  --accent-2:  ;  /* 可选伙伴色：第二序列/第二 CTA。单色套则省略 */
  --accent-soft:; /* 8–16% 淡染：chip、badge、选中行、focus ring */
  --on-accent: ;  /* accent 填充上的字：白或近黑，见 §3 */
  --glow:      ;  /* rgba(accent,.28–.40)，仅主 CTA/关键卡，每屏一次 */
  /* 语义 —— 功能色，不是身份色 */
  --up: ; --down: ; --warn: ;
}
```

> 与品牌四槽的桥接：`--page≈--canvas`、`--accent≈--accent`、`--ink-1≈--ink`。产品模型只是**补上仪表盘需要的粒度**
> （三级墨、面板抬升、语义涨跌），不是另一套体系。

## 2. 中性阶 —— 真正干活的那一层（选 1 套 = 页面已经贵了）

**仪表盘大部分是灰。** 纯灰阶（`#f5f5f5 / #e5e5e5 / #737373`）就是"扁平廉价"的默认;**带微染**的中性阶是产品 UI 单点杠杆最高的一手。
**选与你 accent 色相匹配的那套**：暖 accent 配暖阶，绿 accent 配鼠尾草阶。

| 阶 | 50 / 100 / 200 / 300 / 400 / 500 / 600 / 700 / 800 / 900 / 950 | 配哪些 accent |
|---|---|---|
| **冷石板 Cool Slate** | f6f7f9 eceff3 dde2e9 c4ccd8 97a2b3 6f7c91 566175 454e5e 333a46 23272f 14171c | 蓝/靛/紫/天空 |
| **真中性 True Neutral** | f7f7f6 efefee e2e2e0 cbcbc8 9d9d99 777773 5c5c59 4a4a47 373736 262625 171716 | 任意（品牌很吵时的安全选） |
| **暖石 Warm Stone** | f8f6f2 f0ece5 e3ddd2 cec5b5 a39885 7f7462 63594b 4f473c 3b352d 29241e 191612 | 橙/琥珀/砖/玫瑰/金 |
| **鼠尾草 Sage** | f2f5f2 e7ece7 d6ded6 bcc8bc 8fa192 6a7d6e 536357 435046 333d36 232a25 141815 | 绿/翡翠/青/柠 |
| **紫丁香 Lilac** | f6f5fa eeecf5 e0dcee c8c2de 9d95bb 776f96 5d5678 4b4561 393449 282433 17141e | 紫/violet/品红 |

**接进 token 契约：**
```
浅色：--page:{100} --bg:#fff --panel-2:{50} --border:rgba({900_rgb},.07) --ink-1:{950} --ink-2:{700} --ink-3:{500}
深色：--page:{950} --bg:{900} --panel-2:{800} --border:rgba(255,255,255,.07) --ink-1:{50} --ink-2:{300} --ink-3:{400}
```
两条最常出错的暗色规则：
- **暗色面板越往前越亮**（page 950 → 卡 900 → 内嵌 800）。暗色上阴影几乎无效,**明度**才是深度线索。
- **暗色 `--ink-3` 用 400 档不是 500**。暗卡上的小灰标签字是本register最常挂的对比度检查；对 `--bg` 验 4.5:1，不是对 `--page`。

## 3. Accent 库（16，与任一 §2 阶混用，尊重色相匹配）

每行给浅色值（用于白/近白卡）、暗色值（用于 900 面板,永远更亮更饱和,不复用浅色值）、填充上能活的字色。

| Accent | 浅 | 暗 | on-accent | 备注 |
|---|---|---|---|---|
| 靛 Indigo | `#4A46C9` | `#7B77F0` | 白 | SaaS 主力。配珊瑚，别配绿 |
| Violet | `#5B4BD1` | `#9B85FF` | 白 | 扁平 violet ≠ 被禁的"AI 紫**光晕**"；SPECTACLE ≤4 |
| 紫 Purple | `#7C3F9E` | `#B57BD8` | 白 | 比 violet 更深更编辑感 |
| 钴 Cobalt | `#2D5BD8` | `#5E8CFF` | 白 | 刻意的平台蓝，用前想清楚是不是又回到默认蓝 |
| 天空 Sky | `#0E7FA8` | `#3FC5E8` | 白 | 比钴更轻更友好 |
| 青 Teal | `#176C6B` | `#2FD3C5` | 白 | 冷但不蓝 —— 最好的"逃离蓝"出口 |
| 翡翠 Emerald | `#1E8A5F` | `#3FCB86` | 白 | ⚠ 与 `--up` 撞色，把 `--up` 挪到蓝绿或换 accent |

## 4. 现成套装（collision-checked，直接粘）

```css
/* 鼠尾草账本 —— 森林绿 on 鼠尾草纸（浅）· 财务/税务/采购/供应链 B2B 后台。非蓝版信任 SaaS */
:root{ --page:#eef0ec;--bg:#fff;--panel-2:#f3f5f1;--border:rgba(20,32,26,.07);
  --ink-1:#14201a;--ink-2:#3c4a43;--ink-3:#6d7d74; --accent:#2F6B4F;--accent-2:#C08A3E;
  --accent-soft:rgba(47,107,79,.10);--on-accent:#fff;--glow:rgba(47,107,79,.32);
  --up:#2C7A8C;--down:#C0453C;--warn:#B77A16; } /* --up 挪到蓝绿：accent 已是绿 */

/* 琥珀运营 —— 焦橙 on 暖纸（浅）· 商家工作台/电商后台/物流/订单。商家 admin 最强默认 */
:root{ --page:#f4f0e9;--bg:#fff;--panel-2:#faf6f0;--border:rgba(48,32,20,.07);
  --ink-1:#1f1710;--ink-2:#4a3f34;--ink-3:#82715f; --accent:#D9642A;--accent-2:#2E6B63;
  --accent-soft:rgba(217,100,42,.11);--on-accent:#fff;--glow:rgba(217,100,42,.34);
  --up:#2F7A55;--down:#C0453C;--warn:#B77A16; }

/* 青与陶 —— 青 + 陶土 on 冷纸（浅）· CRM/项目资源/SaaS 中台。冷暖对，图表不用第三色 */
:root{ --page:#e9eeed;--bg:#fff;--panel-2:#f1f5f4;--border:rgba(16,38,38,.07);
  --ink-1:#0f2322;--ink-2:#3a4b4a;--ink-3:#6b7d7c; --accent:#176C6B;--accent-2:#C4633F;
  --accent-soft:rgba(23,108,107,.10);--on-accent:#fff;--glow:rgba(23,108,107,.30);
  --up:#2C7A62;--down:#C0453C;--warn:#B77A16; }

/* 石板深控制台 —— 靛 on 冷石板 950（暗）· AI/数据/ML 工具、监控。暗色面板越前越亮 */
:root{ --page:#14171c;--bg:#23272f;--panel-2:#333a46;--border:rgba(255,255,255,.07);
  --ink-1:#f6f7f9;--ink-2:#c4ccd8;--ink-3:#97a2b3; --accent:#7B77F0;--accent-2:#3FC5E8;
  --accent-soft:rgba(123,119,240,.16);--on-accent:#fff;--glow:rgba(123,119,240,.36);
  --up:#3FCB86;--down:#F07C93;--warn:#E8A33D; }
```

## 5. 语义色与身份色必须分开（最常见的仪表盘 bug）

`--up / --down / --warn` 是**功能**不是身份。绿 accent 的页面上,涨跌的绿必须和品牌绿**不同**（把 `--up` 挪到蓝绿 `#2C7A8C`），
否则用户分不清"这是品牌强调还是数据在涨"。红 accent 同理避让 `--down`。**图表配色从 §3 accent + accent-2 派生，不新引第三高饱和色。**

## 6. 自检
- [ ] 中性阶是**带微染**的,不是纯灰;`--page` 不是 `#fff`/`#000`
- [ ] accent 恰好 1 个（+可选对面伙伴色）;不是框架默认蓝/绿/橙三件套
- [ ] `--border` 是 3–8% alpha 发丝线,不是硬 `#ccc`/`#333`
- [ ] `--up/--down` 与 accent 不撞色
- [ ] 暗色：面板越前越亮;`--ink-3` 用 400 档且对 `--bg` 过 4.5:1
