# 反模式

护栏只打无依据的默认值，**不打有依据的表现力**。

## 一、画面反模式

数值判据见 `aesthetic-baseline.md`，此处是语义描述：

- 无品类依据的万能皮肤（紫白渐变皮、奶油衬线+赤陶皮、蓝紫科技皮）
- 主底色停留在纯白 / 纯黑，或直接用框架默认色板
- 单层纯黑阴影；全局同一圆角；三套互不相关的阴影
- 单一字体家族且无尺度断崖，标题只是"大一点的正文"
- 一页同时堆：光球 + 网格 + 噪点 + 星点 + 渐变线 + 玻璃 + blob
- 强调色同时出现在标题、卡底、按钮、icon、边框上
- 全页在同一 z 平面，没有任何咬合与遮挡
- 用 emoji、CSS 圆球、icon font、占位图服务冒充主视觉
- Web 卡片用整张设计稿背景冒充网页（没有真实 DOM 文本、响应式结构和实际视频）；
  doc-only 的移动关键屏用整屏设计图装进设备画框是**默认做法**，不属于本条
- 生图承担 Logo、卡号、长文案（整屏图里的短标签不在此列）

## 二、结构反模式

- 交差模板：导航 + 三列卡片 + 页脚了事
- 连续 3 段同结构，全程没有换气
- 有真实证据可用，却用 icon + 短语卡代替
- 移动端只是把桌面块竖排，未重构图
- 低对比正文、不可达点击区、缺 `focus-visible`
- 缺空态 / 加载态 / 错误态却声称完成

## 三、动效反模式

- 每个区块同一套无编排 `fade-up`
- 有 motion 能力却交纯静态页
- 忽略 `prefers-reduced-motion`
- 用 `top` / `left` / `width` 做位移动画
- 入场动画把元素卡在 `opacity: 0`，关掉动效后首屏空白

## 四、流程反模式

- 把大部分回合花在读清单、打勾上，导致实现变浅
- 启用了对标品牌文档或家族 token，却只抽 1 个色值
- 凭印象"像某某"，没读文档就抄错气质
- 主资产没生成成功就先写页面，打算"以后补图"
- Hero 没过门 C 就开始写后续区块，导致错误语言被复制 6 次
- widget 用相对路径引图就上传，飞书预览碎图
- 默认应走方案文档，却只丢一个无预览、无主图的空文档
- 用户未要求时省略满意度询问与分层导出选项
- 用户明确"只要图片"，却强行附送长文档

## 五、版权与合规

- 盗用真实品牌 Logo、吉祥物、角色、商标
- 把含第三方 IP 的参考图原图当作导出层交付
- 生图 prompt 里拿具体品牌或作品当风格锚点

对标只学**构图与材质逻辑**，不复制受保护资产。

## 六、不再禁止（有依据时该用就用）

下面这些是正当做法，护栏明确放行：

- 毛玻璃 / `backdrop-filter`（导航、主面板、沉浸家族）
- 渐变标题、光球、光晕、声波、唱片旋转
- 低饱和渐变、白站框、软 3D 飘带、圆形写真压边
- 品牌巨字压底、角色遮挡巨字、场景马赛克
- 深色沉浸页与高饱和品牌强调色
- 多段微动效与滚动触发动画
- 手机设备框、播放器、界面切换演示

判据是**有没有依据**，不是效果本身黑白名单。依据写在 `art-direction.json` 的
`visibleDecisions` 里；写不出依据的效果就是装饰噪音。

## 七、AI 出图痕迹清单（跨语言通用 tell，默认避开，除非需求点名）

这些是「模型想让画面看起来被设计过」时的条件反射，缩略到 200px 也认得出。它们不是绝对禁令，
是**默认不要伸手去够**；需求或参考图明确要某一条时，写进 `visibleDecisions` 再用。

**版式脚手架**

- **每个 section 上都顶一条小号大写字距标签（eyebrow）**：`ABOUT` / `PROCESS` / `精选` 之类。
  一条命名 kicker 作为品牌系统是声音；每段都放就是 AI 语法。**上限：每 3 段最多 1 条 eyebrow**（Hero 算 1）。
- **给每个 section 编号做装饰**（`01 / 02 / 03`、`001 · 能力`）。编号只在**真的是序列**
  （3 步流程、有序时间线）且顺序承载信息时才用；给并列 section 编号 = 脚手架反射。
- **左大标题 + 右上角浮一段小字解释**（split-header / 角落浮字）。一个 section 一个焦点信息；
  要副说明就竖排在标题下（行宽 ≤65ch），不要在角落浮一段没有对齐关系的小字。

**假内容**

- **用 `<div>` 拼假截图/假仪表盘/假终端**冒充产品界面——AI 设计第一 tell。要展示产品用真实截图、
  生成图或真的迷你组件；做不到就留占位并说明，不要拿方块拼。
- **编造精确到不合理的数字**（`92.4%` `4.1×` `48k` `13.4 lb`）冒充工程精度。数字要么来自真实数据，
  要么明确标注是示例，不要伪造品牌并不主张的精度。
- **假名字 / 假头像 / 万能创业名**（John Doe、Acme、Nexus、SmartFlow）。用具体、可信、符合语境的名字。

**装饰噪音**

- **渐变文字**（`background-clip:text` + 渐变）作大标题装饰——用单色，强调靠字重/字号。
- **卡片/列表项左侧那条 >1px 的彩色竖条**（side-stripe）——几乎从不是有意的。改用整边框、背景染色或前导数字/图标。
- **到处撒彩色状态圆点**（导航项前、每个 badge 前）——只在表达真实语义状态（在线/可约）且稀疏时才用。
- **滚动提示**（`Scroll` `↓ 向下滚动`、鼠标滚轮图标）——用户看着 Hero 就知道能滚，底部不需要标签。
- **地点/时间/天气条**（`LIS 14:23 · 18°C`、城市名 atmospheric strip）——只在真的是全球分布团队/在地品牌时用。

**配色 tell**

- **奶油/米/沙/beige 暖近白底 + 黄铜/赤陶/酱红 accent + espresso 深文字**——这是「高端消费/手作/wellness」
  品类的 AI 默认皮，写什么品类都长一个样，品牌因此消失。暖意应由 accent + 字体 + 影像承载，不是靠底色默认染暖。
  真要暖时从项目真实物料推导一个暖色（`aesthetic-baseline.md` §2），不要伸手就抓这套。
- **AI 紫/蓝光晕**（紫按钮外发光、随机霓虹渐变）——见 §一，默认避开。

> 这一节与 `aesthetic-baseline.md` 的九条红线互补：红线管**物理量**（底色/阴影/圆角/字阶），
> 本节管**版式与内容里的懒惰反射**。两者都服从「有依据就能用」。
