05

他会怎么走完这一趟

从打开首页到下单，一共六个版面。 每一段我们都先想清楚"他在这里想干什么"，再决定放什么。

他刚点进来，还不确定这是谁。 所以整块画面让给一张照片，标题压在人身上，只留一个按钮。 这一屏不解释面料、不列参数，只让他判断"这是不是我的牌子"。
他认了，开始想看看有什么。 八件单品用同一场影棚照片连成一片，缝隙只留一线。 鼠标停下来才浮出尺码——先让他看造型，别一上来就让他做选择题。

购买本身做得很直接：选码 → 加袋 → 改数量 → 结账， 全程不跳页、不强制注册。满额免运费的提示出现在他改数量的那一刻， 而不是等到结账页才告诉他。

06

为什么这对你有效

成交路径更短

从"认了这个牌子"到"加进购物袋"只隔一屏。 我们把说服放在首屏，把决策放在第二屏，中间不插入任何需要阅读的内容。

资产可以复用

首屏那句话和那个橙色不只属于网站。 它们可以直接搬到门店橱窗、包装、短片和联名物料上——一次设计，多处使用。

复购有抓手

城市训练队是一个不花预算的复购引擎： 每周三固定夜跑，跑完在便利店门口拍合照。 它同时解决了内容素材和到店理由。

同一批影像可以横跨官网、社媒和门店，不需要为每个渠道重拍。
