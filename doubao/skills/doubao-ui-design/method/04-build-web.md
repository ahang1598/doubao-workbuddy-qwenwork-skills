# 4 · 做（宽屏网页）

> 网页这一侧拼的是**时间与画面**：满版影像、滚动驱动的连续状态、巨字。
> 做错的样子是：只有入场动画播一次，图小、留白匀、每段一样高。

骨架 `ui.py start` 已经按合同拷好了（`site/index.html`）。**直接改它。**

## 版面节奏

明暗轮换，别一个调子到底。`gold/web-pulse` 的实际节奏：

```
深（满版摄影首屏）→ 墨色跑马灯 → 浅（商品网格）
→ 深（品牌主张 + 四个数值）→ 浅（横向大片轨）
→ 浅（面料科技，左图右规格）→ 深（社群满版）→ 强调色整块（会员招募）→ 墨色页脚
```

八个段，没有两段结构相同。每段先答 `job/proof/geometry/move`
（[craft/page-grammar.md](../craft/page-grammar.md)）。

## 首屏

- **一个主角 + 一个主行动。** 不要三张等大的图，不要两个同权重的 CTA。
- 门会量首屏画面占比 ≥40%（含 CSS/SVG 画的画面）。参考站实测 40–100%。
- 压在图上的文字：底下要有可控暗场。门会跳过"背景不可信"的文字，
  **跳过不等于安全**，你得自己保证读得出来。

## 商品/内容网格

- 缝隙可以小到 **4px**，让一组同场拍摄的照片连成一张接触印相，而不是一堆卡片。
- 悬停再出尺码/操作，别一开始就把所有控件摊开。
- 筛选要真的过滤（断言会查）。

## "支持直接购买"是一条链路，不是一句文案

如果 query 说了能买，就得能点：
选码 → 加购物袋 → 改数量 → 满额免运费 → 下单 → 反馈。
`gold/web-pulse/assertions.py` 里有 11 条针对这条链路的断言，照抄改。

## 动效三条硬约束

1. **加性**——绝不 `opacity:0` 起手当唯一手段（关掉动效会白屏）
2. **绑真实内容**——挂在图/标题/分隔线上，不新建装饰层
3. **可降级**——`prefers-reduced-motion` 全关

入场只播一次；**滚动驱动的连续状态**才是"大屏很酷"和"像 PPT"的分界。
详见 [craft/motion-quality.md](../craft/motion-quality.md)。

## 常见返工（都在 gold 里真实发生过）

| 症状 | 真因 | 修法 |
|---|---|---|
| 长图里某几张图是空的 | `loading=lazy` 在长图拼接时来不及解码 | 改**截图工具**不是改页面（shoot.py 已处理） |
| 两块颜色打架 | 照片背景色和强调色同族但不同相 | 换片或转黑白。滤镜救不回来 |
| 横向轨第一张贴边 | `.rail` 忘了 `padding-inline` | 加 `padding-inline` + `scroll-padding-left` |
| 文案数字和版面对不上 | 文案先写、版面后改 | 定稿后回头对一遍所有数字 |
