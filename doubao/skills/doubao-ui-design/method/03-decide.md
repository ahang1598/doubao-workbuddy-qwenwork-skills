# 3 · 定

> 四组数值 + 一份拒绝清单。写完之后，任何一屏都能从这五样里推出来。

## 四组数值

### 色板
- 底色**不停在纯白/纯黑**（框架默认色是"廉价"的第一来源）
- 强调色**只给一个角色用**。它同时充当"这里可以点"的视觉提示
- **同一块面积里只允许一个强调色**
- 弱信息色对底色要 ≥4.5:1（例：`#8E8A7E` 在骨色上只有 2.92:1，不够）
- 参考站首屏底色数实测 1–3 种

### 字阶
- 要有**断崖**。标题不能只是"大一点的正文"
- 5 档就够：微标签 / 说明 / 正文 / 小节 / 大标题（+ 首屏）
- 字阶比实测区间 2.25–4.5，**2.25 也能得奖**——不能拿它当硬门

### 圆角
- 3 个角色值，不要全局一值
- 一条好用的规则：**只有可点的东西才是圆的**

### 栅格
- 页面留白用 `clamp` 跟视口走
- 卡片缝隙**可以小到 4px**，让同场拍摄的照片连成一片
- 图片比例定死（例：商品 3:4、大片 4:5），不要每张不一样

## 拒绝清单

把你决定**不做**的写下来。这比正面描述更管用，因为丑的产物几乎都是滑进了默认值。

`gold/web-pulse` 的拒绝清单：

- 三卡片 feature 区——"年轻化"最容易滑进去的模板
- 玻璃拟态与通用渐变背景——会让任何品牌看起来像同一个 SaaS 落地页
- 大圆角 + 珊瑚粉——最容易滑进去的默认联想
- 首屏放商品——先认调性再看货

完整反模式清单见 [craft/anti-patterns.md](../craft/anti-patterns.md)。

## 风格从哪来

**从本轮请求原文里的词来**，不从风格家族倒推页面。

打分语料只取用户来源：原话、主体、must-keep/avoid、参考图。
流程自己生成的句子一字不参与——否则所有 query 会收敛到同一种样子。

命名品牌/主题时先查 `craft/` 里有没有对应的品牌设计语言资料。

## 完成标准

一份 `art-direction.json`（或写在骨架的 `:root` 里也行），包含：

```json
{"palette": {...}, "typeScale": [...], "radius": {...}, "grid": {...},
 "photoTypes": ["影棚白底全身", "现场强色光"],
 "rejected": ["三卡片 feature 区", "玻璃拟态", "通用渐变背景"]}
```

`photoTypes` 长度必须 ≤2。`rejected` 至少 3 条。
