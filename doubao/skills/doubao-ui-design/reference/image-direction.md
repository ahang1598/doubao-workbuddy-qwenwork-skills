# 影像艺术指导与镜头机制库

> 当项目需要生成、补充或深度重排影像时阅读。项目先通过 `content-and-evidence.md` 确定“需要什么证据”，再用本文件确定“如何拍、如何生成、如何放置”。
>
> 镜头、光线、材质反应、语义匹配、负空间、使用槽位和裁切安全是通用质量要求；资产数量、统一后缀长度、画幅比例、满版比例与变量差异数量由当次 `adaptive_quality_contract` 决定。跨载体资产合同见 `asset-direction.md`。

低质 PPT 的图片问题在生图之前就发生了，而且有**两种**失败模式。第一种人尽皆知，第二种更隐蔽、也更致命。

**失败一：内容描述式 prompt** —— 没有镜头、光线方向、色彩世界、构图留白，模型只能回吐图库均值：

```text
四款水果奶茶产品并排展示……透明塑料杯，白色杯盖，木质桌面背景，自然光线，清新风格，高品质商业摄影
```

**失败二：统一后缀退化成同一张照片** —— 高频事故。正确写了 60–90 字统一后缀并逐字追加到每条 prompt，结果整组图全部是「产品居中摆在木桌上、暖光从左上侧窗斜射、浅景深虚化背景」。后缀统一了，但每条 prompt 只换了主体名词，没有换场域、机位、距离与被摄关系，整组图就成了同一张照片拍十几遍，成稿毫无信息量与节奏。

**统一后缀负责"看起来是一个世界"，变量矩阵负责"每张都是新的一眼"。缺任何一半都出不了编辑级。**

## 1. 先立影像世界（一次，全项目共享）

生成第一张图之前冻结与项目有关的艺术指导事实：品牌/项目命题、主体关系、材料、光线、镜头语言、色彩与后期质感；识别母题和精确色板只在项目确有需要时加入。

由此产出一段简洁的**共享影像世界说明**。它可以作为 prompt 后缀，也可以拆成结构化字段；长度由模型和项目需要决定。共享部分只负责色彩分级、光线性格、后期质感与禁止项——**不要把「木质台面」「浅景深」「产品居中」这类场景与构图决定写进共享部分**。

共享影像世界从本项目生成，不从家族模板选择：

```yaml
image_world:
  project_thesis: ""
  subject_identity: []
  material_reactions: []
  light_character: ""
  color_sources: []
  grading: ""
  continuity_rules: []
  prohibited_defaults: []
```

`light_character / color_sources / grading` 必须指向 query、附件、参考差值或项目材料。只有这些共享；场域、机位、距离、动作和主体位置由每张资产的页面职责决定。

**受众修饰句**：统一后缀之后再追加一句 15–30 字受众修饰，全稿一致。示例——儿童亲子：`高调明快光线，真实儿童动作物理，道具圆润安全，色彩明度高但不荧光`；银发长者：`温暖侧光，真实皮肤纹理与神态，平视机位，环境整洁稳定`；Z 世代：`直闪高反差，动作瞬间感，环境真实不摆拍`；高净值：`暗调仪式感静物，档案质感，光比大但过渡细腻`。

摄影图只用摄影语言；精确字标、长文案由 PPT 原生叠加。**例外**：`page-grammar.md` §4 的 L27 预合成版面图，其版面关系写进 prompt，但图内仍不得含需要精确控制的可读文字。

### 1.1 身份保真分流

已有 IP、人物、产品、建筑或 Logo 时，先声明：

```yaml
identity_fidelity:
  level: exact|source_anchored|conceptual
  anchor_source: 原始源图或已批准母资产
  immutable_anchors: [轮廓, 比例/拓扑, 面部几何, 标志性部件, 色彩关系]
  allowed_changes: [动作, 服装叠加, 道具, 场景, 镜头]
  fallback_if_unstable: source_native_compose|concept_label|stop
  comparison_ref: 并排复核引用
```

- `exact`：每次编辑都直接引用原始源图或已批准母资产，逐项比对不可变锚点；不得把上一次的生成图作为唯一参考。
- `source_anchored`：允许媒介或服装变化，但轮廓、比例/拓扑和身份识别点必须保持。
- `conceptual`：允许探索，但必须在页面标注概念，不得冒充官方形象或真实产品。

若当前工具没有参考图编辑能力，或连续两轮仍发生脸型、轮廓、产品拓扑漂移：`exact` 任务停止自由生成，改用源图原生编排、非破坏性裁切、图形/服装/道具叠加，或明确降级为概念。画面更漂亮不能抵消身份错误。

## 2. 变量矩阵（按叙事职责控制变化）

列资产清单时可用下表检查重复。变化不是目的：同系列产品、工艺步骤或档案证据可以有意保持同机位；叙事转场、空间尺度或情绪变化则应改变足够多的维度。具体差异要求写入页面角色或资产批次合同。

| 维度 | 取值域（每张图选一个，全稿轮换） |
|---|---|
| **场域** | 产地/原野 · 工坊/后厨 · 门店/空间内 · 街头/户外 · 室内生活场景 · 纯背景棚拍 · 材质微观 · 俯拍平面 |
| **机位与距离** | 大远景（环境为主） · 中景（人与物关系） · 近景（单主体 45–65%） · 微距（材质充满画面） · 俯视平铺 · 低角度仰视 · 平视人眼 1.5–1.7m |
| **被摄关系** | 静物独处 · 人手动作中 · 人物穿戴/使用中 · 产品阵列同视角 · 局部裁切（只见手/腿/边角） · 环境中的偶遇（产品不居中） |
| **光质** | 硬光直射投影明确 · 侧窗漫射 · 逆光轮廓 · 顶光平铺 · 暗调单点 · 阴天均匀 |

**参考库实证**：一份 A 级时尚稿的产品图分别落在鹅卵石路面、石墙、椅子、地毯、木地板上，距离从微距到全身，光从硬投影到阴天漫射；把它们放在一起仍是一个世界，靠的是统一的色彩分级与「随手抓拍」的态度，不是靠同一张桌子。

**反例（禁止）**：全稿每张产品图都是「主体居中放在木质台面上，暖光从左上方斜射，浅景深虚化背景，旁边散落一两个配料」。这是外卖商家实拍模板，出现两次以上即判废重写。

### 2.1 影像内容从证据职责推导

不要给所有项目套同一套“场所＋工艺＋材料＋人物＋产品”的摄影配比。先选择 `image_strategy`，再由内容覆盖决定资产：

| 策略 | 主证据 | 常见补充 | 不应被迫加入 |
|---|---|---|---|
| `identity_led` | 人物、IP、产品或空间身份 | 动作、视角、应用 | 与身份无关的氛围图 |
| `evidence_led` | 来源、过程、结构、图纸、实物 | 局部、对照、标注 | 为“高级感”制造的泛生活方式图 |
| `product_led` | 产品家族、使用场景、材料与结构 | 细节、包装、尺度 | 无产品关系的风景 |
| `data_led` | 图表、数字、原生示意 | 少量背景或来源证据 | 装饰性生成图 |
| `atmosphere_led` | 场域、人物关系、光线与情绪 | 物件、局部、环境证据 | 机械产品阵列 |
| `minimal` | 单一必要证据或纯原生图形 | 仅在缺口明确时补充 | 为凑图制造的任何资产 |

策略由 query、受众、附件、页面角色和编辑性要求决定，可混合但必须写明每种影像证明什么。高级感来自真实证据、可信物理和明确艺术指导，不来自固定题材组合。

## 3. 资产计划与画幅策略（先列职责，再开机）

写页前列出全稿资产清单：页面归属、证明对象、画幅、景别、变量矩阵、组成类型、载体用途和身份级别。资产数量等于覆盖图中的视觉缺口，不按页数或视觉等级套固定配额。

按页面 `evidence_box` 的实际几何生成画幅：

- 宽证据区 → 横图或超宽图；
- 窄竖证据区 → 竖图；
- 图形符号、头像或局部标本 → 方图；
- 满版/分屏 → 按最终出血比例生成；
- 数据或准确结构可由原生图表证明时，不额外生成装饰图。

同一项目若所有资产都自动落成同一方图、同一居中机位、同一桌面和同一光线，说明模型先验接管；但某些阵列、档案或技术型 query 可以有理由保持相同视角。判断依据是证据职责，不是固定比例。

画幅服务于载体：Slides 按页面槽位生成；文档正文中的竖图按 `carrier-documents.md` 的可读性规则处理。同一资产 `carrier_intent=both` 时分别验证。

### 3.2 组成类型、可拆分性与放置冻结

生成或绑定前，每张资产必须声明：

```yaml
composition_type: singleton|contact_sheet|family_array|texture|composed_canvas
panel_count: 1
panel_semantics: []
carrier_intent: slides|document|both
allowed_placements: [single_hero|sheet_whole|…]
variation: {场域, 机位与距离, 被摄关系, 光质}
```

1. **先冻结 placement，再生成/裁切。**页面需要 N 个外部槽与 N 个标签时，必须规划 N 个独立 `singleton`；不要先生成 contact sheet 再指望宿主拆槽。
2. `contact_sheet` 默认只能 `sheet_whole`。只有真实拆分并为每个 panel 生成独立 `asset_id/runtime_ref/source_fingerprint` 后才能进入 `slot_array`。
3. `family_array` 是整体陈列，不承诺可逐项裁切；误当可拆分单品 = 硬失败。
4. `texture` 只用于底层或材料裁片，不能冒充产品/身份证据主角。
5. `composed_canvas`（L27）只能满版铺 L0，不得缩小当插图使用。
6. `carrier_intent=document` 的证据图不得保留无功能的 PPT 叠字负空间。
7. 高风险页的 `media_placement` 与满版/分屏页的 `canvas_coverage` 在写页前冻结，字段见 `schemas.md`。
8. `composed_canvas` 不得包含标题、正文、Logo、色值、规格、数据或需校对的标签；这些信息由载体原生层完成。
9. 角色设定板、VI 系统板与产品说明板若需要多项可读信息，必须拆成独立视觉资产再由页面原生组装；禁止生成一张带大量伪文字的“完成板”后缩小置入。

## 4. 底纹与母题资产配方（L0/L1 专用）

底纹的职责是「安静地存在」：无主体、无焦点、低对比，铺满后不与内容抢戏。

```text
生成 16:9 纸张纹理底图：宣纸/绢布的细腻纤维肌理，均匀受光，无任何主体与图案，
颜色为暖纸灰 #F2EDE3 附近，对比度极低（明暗差 <8%），四角有极轻微的自然暗角；
可作为版面底层平铺。禁止褶皱阴影、水渍、文字、边框和任何可辨识物体。
```

底纹颜色由本项目 `surface_logic` 与真实材料决定，不是一律浅米白或深黑。明暗、饱和与纹理显著度写入当次合同；不能从行业或风格标签直接选择。

同法可生成泥灰、亚麻、拉丝金属、涂料、纸张、胶片颗粒或其他真实材料表面，但必须说明与项目的关系。

母题图形示例：

```text
生成 1:1 枝影图：一枝松/梅的剪影投在浅灰纸面上的柔和影子，影子为深灰色（不是黑色），
边缘因光线漫射而柔化，构图偏画面一角、大面积留白；除影子与纸面外无任何元素。
禁止真实枝条实体、文字、印章和高对比硬边。
```

母题图形以低透明度或小面积用于页角/页缘，全稿 ≤4 次，位置有节奏地轮换。

## 5. L27 预合成无字视觉底板

把版面关系写进生图指令，一次生成整幅 16:9。要点：写清分割比例、每个区块的内容与明度、装饰构成、**留给原生文字的低信息区位置**，并声明图内不含可读文字。

```text
生成 16:9 品牌手册章节版面：画面左 55% 为深陶土棕整版色域，右 45% 为亚麻织物微距影像上下出血；
色域内偏左上有一个超大数字「3」的形态（占色域高度约 60%，比底色提亮 12%，边缘干净），
色域下半部留出大片干净低信息区供后期叠加标题文字；
页面顶缘有一条极细的浅色横线跨全宽，右下角有一个小方块色标；
整体为印刷品质感，纸面微颗粒，无渐变光效。
画面中除那个数字形态外不出现任何可读文字、字母或标点。
```

约束：图内不得出现任何标题、正文、Logo、色值、规格、数据或需校对标签；合成图仍须服从共享影像世界与受众要求；它只能作为满版无字视觉关系或背景，不能缩小后冒充一张设计系统页。

## 6. 门 A：发送前八项自检与措辞底线（MUST）

每条 prompt 发送前逐项打钩，**缺任一项不发送**：

1. 主体＋至少 2 个可见材质反应（反射、织纹、颗粒、冷凝、磨损……）；
2. 构图空间词＋主体占比＋留字负空间位于哪侧；
3. 镜头（焦段/景别/机位）；
4. 光线（方向＋软硬＋色温＋作用）；
5. 色彩世界（HEX 或材料色名）；
6. 统一后缀＋受众修饰句逐字在末尾。

**外加两项批次级自检：**

7. **变量矩阵**：本批每条 prompt 的四维取值已填写，且与已生成资产不重复；
8. **画幅与槽位**：本批画幅符合已冻结的页面槽位、关键主体安全区与裁切合同；若项目采用编辑型拼贴，可参考 §3.1 检查画幅是否过度单一。

Prompt 长度不是质量门。只要主体、证据目的、构图、镜头、光线、材料反应、色彩世界、禁止项与使用槽位已被清晰表达，就可以采用更短或结构化的 prompt。

**生图前必须实跑**：


`prompts.json` 形如 `["prompt1", …]` 或 `[{"prompt": "...", "asset_id": "a01", "width": 2048, "height": 1152, "variation": {...}}, …]`。批量模式额外校验**统一后缀逐字一致**、**画幅配比**与**变量矩阵重复度**。任一条失败即禁止发送该批。

无终端时把八项自检逐条打钩粘贴在 prompt 上方，缺项不发送。**脚本不可用不豁免门 A。**

### 6.1 内容描述式 prompt 的识别特征

出现以下组合即为内容描述式，必然回吐图库均值，重写后再发：

- 只有题材 + 风格形容词（「简约现代」「清新自然」「ins 风」）；
- 只有质量词（「高品质」「高清」「大师级」「精致」）；
- 只有背景词（「干净的背景」「纯白背景」「浅色背景」）；
- 全篇没有任何焦段、光线方向、色温、材质反应词；
- 长度 < 80 字。

这类 prompt 的问题不在于写错了什么，而在于**没有做任何艺术指导决定**——把所有可见结果的选择权交还给了模型的先验均值。

其他措辞底线：

- 锁定项（主体外形、数量、结构、品牌色、准确文案）放前半段，结尾用「保持……」重申。
- 构图用空间词：左侧/右上/前景/中景/背景/占画面约 60%/负空间位于左侧供标题使用。
- 光线写「方向＋软硬＋补光＋作用」；材质写可见反应（反射、织纹、颗粒、磨损、折射、接触阴影），不写「高级材质」。
- 空词翻译：高级感→克制色板＋单一焦点＋精确留白＋真实材质；氛围感→具体光线方向色温＋5–12 个环境细节名词；质感拉满→至少两个可见材质属性；「大师级/杰作/高品质」→删除。
- 每条 prompt 自包含，不写「同上一张」；交付前花括号变量清零。

## 7. 九类资产配方

所有示范末尾都要追加 §1 统一后缀。

### 7.1 Logo 与识别资产（特殊规则）

生图模型不能可靠输出精确字标。正确路径分三步：

1. **图形符号**：单独生成，要求「极简平面矢量语言、几何构成可用语言描述、单色也成立」，1:1 白底与深底反白各一张；禁止渐变、光效、复杂插画和任何文字。优先产出一个可编辑矢量 master，再声明多个 `render_instance`，而不是五个视觉相同的位图副本。
2. **中英文字标**：由 PPT 原生文字排版完成（选定字体、字距、大小写与图形符号的锁定比例），不进生图。
3. **标识系统页**：构造网格、单色、反白、小尺寸、禁用示例全部用已通过资产＋原生变换/排版拼装；每个变体必须有可观察的 `transform`（反白＝深底浅符）。**灰色空占位框或五格同图出现在标识页 = 一票否决。**

**符号的"设计感"来自约束而不是描述**：写明构成逻辑（正负形／单线等宽／几何母题的重复与旋转／字母骨架的结构改造），而不是「简洁大方的 logo」。避免「一片叶子＋一个圆」这类可被任何品牌套用的通用组合——那是平庸稿最典型的标识产出。

```text
生成一枚品牌图形符号：以三片堆叠的茶叶轮廓构成向上的螺旋，正负形干净、单线粗细一致，
可在 12mm 尺寸下辨认；纯平面矢量语言，深绿 #2F4A3C 单色，纯白背景，居中，四周留大量空白；
画面中不出现任何文字、渐变、阴影与光效。
```

### 7.2 品牌主视觉 KV

封面/章节页用。单一强主体、明确的低信息区（约 1/3 画面）留给标题；写明光线方向与时刻；禁止把品牌名交给生图。

### 7.3 产品英雄图

单主体占 45–65%，85–100mm 近摄；至少两个可见材质反应；真实接触阴影；主体朝向的负空间留给文字。**每张必须换一个 §2 场域**——不得所有产品图都用同一张桌子。

### 7.4 产品家族 / SKU 阵列

**一次生成一张多主体阵列图**（同视角、同光源、同比例、同底面），不要四张独立图后期拼贴；写明数量、排列轴线和规格差异变量。

### 7.5 包装系统

展示结构、材料与工艺（折线、咬口、覆膜、压纹），不生成文字——标签信息层由 PPT 原生叠加；**巨大空白标签像占位 = 判废**，用材料肌理或结构细节占据标签区。

### 7.6 空间（外立面 / 室内）

1.5–1.7m 人眼机位、24–30mm 建筑镜头；入口、动线、停留区清楚，1–3 人提供尺度；材料显示真实接缝、边缘、反射；至少一个品牌触点可辨但不写具体文字。禁止空旷样板间、无功能曲线、廉价 3D。留白、格栅光影、雾、逆光或其他氛围元素只在项目语法明确需要时加入。

### 7.7 工艺 / 过程

手部中景 50mm；动作必须符合真实工序力学，工具与物料状态可信；环境保留 5–12 个具体细节名词；禁止摆拍手势和无来源的「实验室感」。

### 7.8 人物 / 生活方式

抓拍感、明确动作、身体力学可信、肢体完整；40–50mm 近距离；环境保留真实生活线索；人物运动方向朝向留字区。**允许并鼓励局部裁切**（只见手、腿、肩背），这是编辑感的重要来源。禁止正面站姿棚拍、网红滤镜、过度磨皮。

### 7.9 材料 / 质感微距与细节切片

90mm 微距、单一材料、至少两个可见物理属性（织法与垂坠、拉丝方向与边缘高光、纸纤维与压痕）；**按 §3 规划 6–10 张不同主体的切片，画幅优先竖图**，供拼贴页（L21）、竖条带（L24）与换气页使用。

```text
生成竖构图（3:4）材质切片：一段胡桃木格栅的局部，正侧光从左侧掠过表面，
榫卯接缝与木纹走向清晰，暗部保留木色层次；主体充满画面，无环境干扰。
```

## 8. 母资产与系列一致性

- 仅当多页必须保持同一产品/角色/包装/空间身份时建立母资产：先锁定身份不变量（拓扑、比例、材料、色板），实际查看通过后，再基于同一参考生成**不同镜头、动作、场景**的独立资产。
- 系列一致 ≠ 重复贴图。复用的判据是**职责**，不是张数（与 `SKILL.md` §8 硬停止 5 一致）：
  - **必须唯一**：承担「这一页要证明什么」的**主体证据图**——产品英雄、空间、工艺动作、人物、家族阵列。同一源图换裁切、镜像、调色仍算同源，默认只能用于一页。
  - **应当复用**：承担「全稿是一个系统」的背景与家具——① 底纹/氛围资产（铺 L0，同一纹理全稿 ≤2 种）；② 页缘超宽横条/材质带（L30）；③ 品牌图形符号与母题图形（幽灵图形、印章、角标）；④ Logo/标准字。
  - 编辑级稿的典型比例约为 1:2（25 页稿 70+ 张唯一图撑起 130+ 个位置），单张底纹跨十余页是常态。**这正是版面密度与系列感的来源**——一刀切禁止复用会直接把每页图像数压到 1，是"平、空、重复"的成因之一。
- 每张图生成前写 `locked_requirements`（主体、数量、身份、构图、材料、文字策略），实看后逐项写 `locked_results`；任一锁定项失败即 `REVISE/REJECT`，只修具体偏差，不同 prompt 盲抽。

## 9. 每张图的验收

逐项记 `通过/失败`：页面职责、主体数量与比例、系列身份、构图与裁切、光线一致性、材质物理、品牌色材、文字/Logo 策略、背景干扰、清晰度、**变量矩阵四维是否与既有资产重复**。

**一票否决**：第三方品牌风格锚点；主体类别/数量/结构错误；空白标签或灰色占位；随机 Logo/乱码文字；与统一后缀不符的光线或色板；通用行业图库感（白底电商图、木桌自然光摆拍、婚礼花墙）；**与已有资产在变量矩阵四维上完全相同**；画幅与页面槽位不匹配；`composition_type` 与 `media_placement` 不兼容；文档用途图保留无功能 PPT 留白；生成后未实际查看就宣称合格。

终端可用时运行 （该职责已并入 SKILL.md §6 的三条命令） 做措辞、后缀一致性、画幅配比与变量重复度检查；不可用时按 §6 人工逐条打钩后再发送。
