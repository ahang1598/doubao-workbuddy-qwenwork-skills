# Windows 游戏帧率优化参考

用户典型诉求:"提升三角洲行动的帧率"、"平时 120 帧,战斗掉到 80,想要稳"。注意区分两种目标:**提高平均帧率** 和 **稳定帧率(改善低帧/1% low)**——线上用户说"卡顿""掉帧"多半要的是后者,优化手段不同。

## 诚实原则

帧率的上限由硬件决定。软件优化通常带来 5-15% 的改善和更稳定的帧生成时间,不会把 60 帧变 144 帧。扫描配置后先判断瓶颈,如实告知:

- 集成显卡 / MX 系列 / 显存 ≤4GB 玩大型 3A:优化余地很小,主要靠降画质和分辨率,直说
- 16GB 以下内存 + 大型游戏 + 后台开一堆:内存是瓶颈,关后台比调参数有效
- 笔记本:先确认电源模式(必须插电+性能模式)和散热(积灰导致的热降频比任何设置都影响帧率),CPU 温度可从任务管理器或让用户装 HWiNFO 看
- 显存读数:`Win32_VideoController.AdapterRAM` 对 NVIDIA 卡经常错报(如 8GB 读成 4GB),以 `nvidia-smi` 输出为准,别基于错误显存量给建议

## 优化层次(按效果从大到小,逐层进行)

### 第 1 层:游戏内设置(效果最大,但你无法直接改)

游戏内设置通常存在反作弊保护的配置或云端,不要试图直接改配置文件。让用户截图设置界面发给你,逐项给建议。通用原则:

- **上限锁帧**:这是"稳帧"的核心。把帧率上限设为战斗场景低帧附近(如平时 120 战斗 85 → 锁 90),帧生成时间平稳,体感远好于波动的高帧
- **DLSS/FSR/XeSS**:N 卡开 DLSS(稳帧目标选"质量",提帧目标选"性能");有帧生成(Frame Generation)且基础帧 >60 时可开,但会略增延迟,竞技射击游戏酌情
- **NVIDIA Reflex**:竞技游戏建议开(开+加速),降低操作延迟
- 首先降的画质项(对画面影响小、对帧率影响大):阴影质量、体积云/体积雾、环境光遮蔽、反射质量、粒子效果;抗锯齿用 TAA/DLAA 而不是 MSAA
- 显示模式用**独占全屏**(或全屏,不是无边框窗口),关垂直同步(用锁帧代替)
- 渲染分辨率/渲染倍率保持 100%,靠 DLSS 缩放而不是直接降渲染倍率(画质差很多)

常见游戏速查(给建议时结合用户实际配置):
- **三角洲行动**:UE 引擎,吃显存和 CPU;战斗掉帧多因粒子+阴影,重点降这两项;开 DLSS 质量档 + Reflex;16GB 内存建议关闭浏览器再进游戏
- **CS2**:吃 CPU 单核和内存频率;画质影响小,主要靠系统层(电源计划、核心隔离关闭)和启动项 `-high`;别指望画质设置大幅提帧
- **暗区突围:无限 / 逃离塔科夫类**:吃内存和硬盘,确保游戏在 SSD 上、物理内存充足
- **无畏契约**:帧率通常足够,重点是稳定和延迟,开 Reflex、锁帧

### 第 2 层:显卡驱动与控制面板(L2,可回滚)

- 驱动版本:`nvidia-smi` 查看;落后超过半年建议更新。**引导用户用 GeForce Experience/NVIDIA App 或官网安装**,不要替用户静默装驱动(驱动安装有黑屏风险,需用户在场)。别用第三方"驱动管家"类工具
- NVIDIA 控制面板(引导用户操作或确认后用注册表等价项):电源管理模式=最高性能优先;低延时模式=开;着色器缓存=开;垂直同步=关(游戏内锁帧代替)
- 不要动:图像锐化之外的全局 3D 设置大改、超频工具

### 第 3 层:Windows 系统设置(L2,用 win_game_boost.ps1,自带备份和撤销脚本)

`scripts/win_game_boost.ps1` 包含以下项,全部可逆,执行前自动建还原点+导出注册表备份+生成撤销脚本:

| 项目 | 做法 | 说明 |
|------|------|------|
| 电源计划 | 切到"高性能"(检测已有 GUID,没有则创建) | 笔记本提醒插电;"卓越性能"与高性能差异极小,家庭版机器上别折腾解锁 |
| 游戏模式 | 注册表 `AutoGameModeEnabled=1` | Win10 1703+ |
| Game DVR/后台录制 | `GameDVR_Enabled=0`、`AppCaptureEnabled=0` | 关闭 Xbox 后台录制,对低配机有感 |
| HAGS 硬件加速GPU计划 | Build ≥19041 且独显才改;默认**建议开** | 改后需重启生效,告知用户 |
| 全屏优化 | 保持默认。逐游戏禁用全屏优化的老偏方在新版本 Win11 上常起反作用 | |
| 视觉效果 | 性能优先(仅用户同意,会明显改变系统外观) | 对游戏帧率影响很小,主要改善桌面流畅度 |

**不做**(黑名单,收益存疑且有翻车案例):bcdedit 系列(useplatformclock、disabledynamictick、tscsyncpolicy)、禁用内存压缩、禁用页面文件、"卸载" Xbox 全家桶、注册表"网络优化/降延迟"偏方、禁用 Windows Defender。

**核心隔离/内存完整性(VBS/HVCI):不主动提、绝不代关。** 关闭虽可能提帧 5-10%,但会让恶意/有漏洞的驱动更容易攻击系统内核、削弱整条安全防线,且普通用户几乎不会记得改回来——长期风险远大于收益。仅当用户**主动问起**时:如实说明上述风险、建议优先更新或移除冲突驱动等替代手段、明确倾向保持开启;用户听完仍坚持关闭的,给出路径(设置→隐私和安全性→Windows 安全中心→设备安全性→内核隔离)由用户**自己操作**,并建议玩完游戏后改回。

### 第 4 层:后台与启动项(L2)

见 `references/windows-tuning.md` 的进程/启动项白名单。游戏场景要点:游戏时关闭浏览器(尤其 Chrome 多标签)、网盘同步、直播/录屏软件;国产全家桶的"游戏加速球"类功能本身就占资源,建议退出而不是用它"加速"。**杀毒实时防护不在"后台负担"处理范围**:不建议关闭或暂停(L3);若确认杀毒扫描抢占资源,引导用户在杀毒软件里给游戏目录/进程加白名单或开启"游戏免打扰"模式。
