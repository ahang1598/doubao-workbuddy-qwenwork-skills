# 国内高校适配说明

## 目录

1. 适配目标
2. 常见差异
3. 学校级建档
4. 不应硬编码的内容

## 1. 适配目标

本 Skill 面向中国大陆普通高校的本科与研究生选课场景。它不预置某一学校的数据，而是用通用字段适配不同学校的教务制度。真实建议必须绑定学校、适用培养方案和目标学期。

## 2. 常见差异

核验时注意各校术语和制度并不统一：

- 课程属性：公共必修、专业必修、专业限选、任选、通识、模块课、学位课、非学位课；
- 学分规则：总学分、模块最低学分、限选名单、跨院学分、重复课程不计入；
- 选课机制：预选、正选、抽签、志愿、候补、补退选、教师审批、跨院审批；
- 时间表达：周次、单双周、节次、短学期、多校区、线上线下混排；
- 资格规则：先修、共修、互斥、年级/专业限制、容量、绩点或已修学分门槛；
- 退课后果：成绩单记载、学费、最低学分、奖助/评优、学籍与毕业进度；
- 评价制度：百分制、等级制、优秀率限制、过程性考核、考试/论文/项目占比。

不得把一所学校的术语直接映射到另一所学校。先建立字段映射，再进行计算。

## 3. 学校级建档

用户只给学校名时，按以下顺序建档：

1. 确认校区、学院/专业、培养层次、入学年级和目标学期。
2. 找到官方教务处/研究生院选课通知与日历。
3. 找到该专业对应版本培养方案。
4. 找到目标学期课程目录、教学班和时间。
5. 记录官方链接、发布日期、适用对象与访问日期。
6. 输出已确认规则、未确认字段和建议用户上传的材料。

只有建档完成后，才能可靠比较具体课程。若官方网页需登录，请用户导出或截图相关页面；不要索取登录凭据。

## 4. 不应硬编码的内容

- 具体课程号、教师、学分、开课学期、容量、截止日期；
- 某门课“水”“神课”“必拿高分”等评价；
- 某校永久不变的培养方案结构；
- 某教师跨学期不变的给分风格；
- 保研、奖学金、推免、毕业资格的确定结论。

可硬编码的是流程、字段结构、证据规则、冲突算法与风险表达方式。
