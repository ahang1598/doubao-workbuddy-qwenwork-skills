## 飞书文档中的表格与结构化展示

本文件用于飞书文档分支；回答正文可视化使用 [answer-visualization.md](answer-visualization.md) 及其随包子 skill。

报告使用飞书原生表格、callout、分组标题、列表和文字说明呈现指标及管理建议。

## 展示方式

| 内容 | 展示形式 | 建议字段 |
|---|---|---|
| 历年数值指标 | 历年对比表及文字趋势分析 | 日期、结果、单位、参考范围、变化方向、管理含义 |
| 单次异常指标 | 异常汇总表 | 项目、结果、参考范围、偏高/偏低、解读要点 |
| 风险分层 | 风险等级表 | 风险领域、等级、证据、建议动作 |
| 复查计划 | 时间安排表 | 时间窗口、项目、优先级、注意事项 |

风险等级单元格使用递进底色：低 `light-green`、中 `light-yellow`、较高 `light-orange`、高 `light-red`。

数值来自用户报告或明确计算；缺失内容写“暂无”，文字说明不确定性。影像、病理和内镜结论保留原文含义。趋势分析有两个及以上可比较时间点时采用；只有单时间点时汇总本次异常。

飞书文档内使用表格和文字呈现数据，不调用飞书图表助手或插入其图表卡片。该限制不禁止支持图表展示的聊天宿主在回答正文生成有用的数据图。

## SVG 示意与步骤

需要非诊断性的家庭监测、餐盘搭配或复查流程图解时，读取 [SVG 可视化规范](svg-visualization.md)，由 [结构图子 skill](atomic-skills/answer-structure-diagram/SKILL.md) 用 SVG 图形、文字与连线表达。动作结构不确定或不适合简图表达时，使用可靠的步骤说明。

不调用生图或图片编辑工具，不生成栅格图，不用 SVG 内嵌图片或将 SVG 转为 PNG/JPEG。飞书文档仅在宿主原生支持 SVG 时展示；不支持时使用文字步骤和表格，保留已有风险分层底色。

每份非诊断性示意说明“仅用于健康管理理解，不替代医生或专业人员指导”。不得表现伪造医学影像、侵入性操作或治疗承诺。

## 严肃 emoji 规则

可以少量使用 emoji 做章节锚点和风险提示：

- `🩺` 医学证据、医生确认。
- `📈` 趋势和历年对比。
- `⚠️` 重要异常或需限期就医。
- `📅` 复查计划。
- `🧪` 检验指标。
- `❤️` 心血管风险。
- `🥗` 营养饮食。
- `🏃` 运动管理。
- `🌙` 睡眠和生活方式。

使用限制：

- 每个一级章节标题最多 1 个 emoji。
- 不在具体疾病名称前使用夸张 emoji。
- 不使用庆祝、玩笑、恐吓或营销感 emoji。
- 高风险提示使用 `⚠️` 时，语气保持医学谨慎，不制造恐慌。
