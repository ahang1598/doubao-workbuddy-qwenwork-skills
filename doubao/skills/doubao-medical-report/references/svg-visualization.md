# SVG 可视化规范

## 载体与范围

本包的可视化优先使用程序化 SVG，适用于精确数据图、结构关系、非诊断性步骤示意与轻量符号。保留各子 skill 的可视化收益、数据准确性、交互及移动端要求。本规范统一绘图载体，不恢复飞书图表助手或已移除的数值确认、外链校验、交付 QA 强制流程。

- 静态 SVG 是默认。用 `<rect>`、`<line>`、`<path>`、`<circle>`、`<polygon>`、`<text>` 等表达真实比较和关系；不把等大文字卡片当作有效数据图。
- 有实际理解收益时，可以使用 HTML 控件与最少脚本更新 SVG 节点；初始状态就能读懂核心结论，失败时保留静态 SVG 和文字。
- 不调用图片生成或图片编辑工具；不生成或导出 PNG、JPEG、WebP 等栅格图，不截图、不将 SVG 光栅化，不以 Canvas 或 base64 位图替代 SVG。SVG 中不使用 `<image>` 或外部图片背景。用户上传的图片仍可读取为报告证据。
- 不使用外部素材、字体、图标或脚本作为 SVG 的必需依赖；符号可复用已存在且允许使用的矢量资源，或用简单几何图形表示。

## 执行与确认边界

- 静态图优先直接构造 SVG 标记，用数值计算坐标与标签；不为普通报告解读创建绘图项目，不要求先创建或修改 `build_svg.py` 等文件。SVG 的实际正文展示是目标，单独的“图表预览项目”不是前置交付。
- 确有计算或 XML 校验需要，且当前工具已允许时，可在当前任务的临时工作目录使用临时辅助代码或资源。用户请求报告解读与可视化后，这类范围内的可逆内部步骤直接执行，不另发“是否允许修改脚本并生成预览”等对话确认，不把内部实现选择转交用户。
- 不改写已安装技能、原始报告、用户项目脚本或其他已有文件来完成绘图；不默认将临时脚本加入技能包。现有文件需要变更时先判断是否属于用户明确请求的范围，能通过直接 SVG 或临时资源完成则使用该路径。
- 上述规则不替代平台权限。平台或工具强制要求审批时必须遵守，不将“已请求可视化”视为已取得平台权限，不绕过审批。执行被拒绝或能力不足时说明具体限制，采用可用的直接 SVG 或正文/表格回退，不反复发起同一脚本修改与授权请求。
- 预览优先使用现有的非浏览器 SVG 展示能力；不因“需要核对”默认启动浏览器。浏览器 UI、无头浏览器和截图仍须用户对当前任务的明确许可。没有实际预览时，只说明完成了 XML/数据检查，不声称已完成视觉检查。

## 按内容绘图

- 数据：使用 [SVG 数据图规范](atomic-skills/answer-data-chart/references/mode-svg-chart.md)，数值与轴位置由同一数据和尺度计算，不靠手工估计位置。
- 结构与步骤：节点、连线、方向和条件有依据；区分事实、可能解释和示意。家庭监测或管理步骤只画可可靠确认的关系，不绘制医疗操作或诊断性医学影像。
- 同一指标有两个及以上可比较时间点才表达趋势。单时间点可展示结果相对参考区间的位置，不补造历史数据。
- 不用不同单位原始值在同一尺度排名，不用偏离幅度代替医学风险；图中保留指标、数值、单位、日期和必要的参考范围或计算说明。

## 响应式、文字与可访问性

- 使用有效 SVG 命名空间、`viewBox` 和响应式宽度；高度按内容比例适配。为标题、坐标轴、图例、标签和注释预留空间，避免依靠裁切遮盖溢出。
- 标题、标签、图例、数值保持实际显示尺寸下可读；窄屏优先减少同图信息密度、缩短并解释标签或拆图，不把整张大图缩成小字。
- 中文使用系统字体；明确换行用 `<tspan>` 或拆行，不指望 SVG 文本自动换行。用户输入中的 `&`、`<`、`>` 等按 XML 规则转义。
- 图形配 `<title>` 和必要的 `<desc>`，按宿主能力提供可访问标签。状态同时配文字、形状或线型，不只依赖颜色；风险颜色不表达诊断结论。
- 沿用清新蓝绿色的健康管理风格与克制的 emoji；数据图需要强调风险时附文字依据。数值与来源可在正文或精简表格补充，不把长段解释挤进图里。

## 展示与回退

使用宿主实际支持的内联 SVG、SVG 原生预览或在受支持 renderer 中嵌入 SVG。HTML 只作为承载和控件层，不默认另外交付网页文件。原始 SVG 代码、本地路径或未渲染代码块不等于已在正文展示。

宿主不支持 SVG 或无法验证展示时，继续给出准确的正文、表格或步骤，并如实说明限制；不启动生图、截图或转位图作为回退。飞书继续使用原生表格、callout 和文字，只有文档宿主原生支持 SVG 时才插入矢量示意，不调用图表助手。

不为本任务自动启动浏览器。必须进行浏览器 UI、无头浏览器或截图自动化时，先说明必要性并取得用户对当前任务的明确许可。

## 输出前核对

核对 XML 结构有效、ID 和引用匹配、标签不越界，图形与正文的数值/单位/日期一致；计算位置、合计、比例和时间间隔与数据相符。不得宣称未执行的实际渲染、视觉检查或平台写入已经通过。
