# HTML/SVG 专项设计规则

仅在高密度排版、特殊视觉结构、专用库或 3D 确有必要时读取。触发和模式选择由 `SKILL.md` 完成，本文件不重复路由。

## 设计原则

- 视觉骨架由内容关系决定，不把“标题 + 等大卡片”当默认模板。
- 流程强调方向，架构强调层级与连接，时间线强调顺序，比较强调共同尺度。
- 默认透明、无阴影、少装饰；颜色服务于分组、状态和因果。
- 所有节点、连线和图例必须帮助识别实际关系；时间线若只按日期重列已有编号清单，改回表格。只有需要比较间隔、并行或密度时才用相应时间编码。
- 可读性优先于全量展示；过密时分组、拆图或缩短标签。

## 基础令牌

| 用途 | 建议值 |
| --- | --- |
| 主文本 | `#1A1B1C` |
| 次文本 | `#5F6670` |
| 分隔线 | `#E4E3DD` |
| 中性背景 | `#F7F7F5` |
| 主强调 | `#4F6B9A` |
| 成功 | `#35705A` |
| 警告 | `#9A6A2F` |
| 错误 | `#A14E50` |
| 正文 | 14px / 1.5 |
| 次要文本 | 12px / 1.5 |
| 圆角 | 4-8px |
| 间距 | 8px 的倍数 |

- 关键文本与背景对比度至少 4.5:1。
- 不用浅色小字承担关键信息。
- 同一模块主强调色不超过一个，语义状态色按需使用。
- 不使用径向渐变、装饰性光斑或大面积单色铺场。

## 布局

- 阅读方向明确：左到右、上到下或沿单一主轴。
- 多列使用 `flex-wrap` 或 `repeat(auto-fit,minmax(...))`，窄屏自然变单列。
- 固定格式元素使用明确的 `aspect-ratio`、轨道或 min/max 约束，避免内容变化引发布局跳动。
- 连接线尽量短且少交叉；复杂关系先分层、分组或拆图。
- 文本允许换行；长词仍无法容纳时再截断，并在正文保留完整信息。

## 图形技术选择

1. SVG：节点连线、几何、路径、参考区间、数值比较和步骤示意。
2. HTML/CSS：承载 SVG 所需的最小布局、文字及必要控件；不能用卡片清单代替图形。
3. 连续状态：SVG 关键帧、步骤切换或更新图形属性；不能可靠表达时保留静态 SVG 和文字。

不引入 ECharts、Three.js 或 Canvas 分支，不依赖外部绘图库；图形与数据计算在当前可用能力范围完成。不得调用未经确认的构造器、插件或私有接口。

## 高密度处理

- 标签优先缩短、分层或编号，不靠持续减小字号解决。
- 节点多时只展示首层或关键路径，完整信息放正文或点击状态。
- 图例只解释视觉编码，不重复正文。
- 关系线使用颜色时同时配合线型、箭头或文字。
- 任何状态下不得出现文字覆盖、越界、裁切或控件遮挡主体。

## 交付检查

- 视觉结构是否直接对应内容语义？
- 主次层级和阅读顺序是否明确？
- 节点、文字、连线和图例是否无冲突？
- 窄屏是否自然换行且不改变核心关系？
- 专用库失败时是否仍保留静态主结构？
