# 依赖与交付协议

## 正式交付边界

本轮正式交付只保留一种格式、默认一份成品。内容、图表及说明的位置按原任务和宿主能力处理，不要求将说明、记录或图表合并进文档。配置、底稿、预览及运行依赖继续内部生成和核验，不默认另附下载文件；宿主必需的资源上传/写入照常执行。额外格式、源文件或独立文档仅按用户明确要求提供。保留实际显示/插入及内容核验，不以少交文件代替检查。

## SVG 正文与文档交付

- 回答正文优先使用当前宿主支持的内联 SVG 或 SVG 预览。仅在宿主明确支持 renderer 时，使用 HTML 容器承载 SVG 和必要控件；SVG 中不内嵌位图，不输出只可读取的配置冒充图形。
- 飞书文档继续使用原生表格、callout、分层底色和文字；只有宿主原生支持时才插入 SVG，不恢复图表助手，不将 SVG 转成图片上传。
- 不调用图片生成或图片编辑工具，不生成栅格图片，不使用截图或 Canvas 回退；不能展示 SVG 时保留准确的正文与表格。用户上传的原报告图片仍可作为输入证据。
- 正式成品的载体、份数和格式服从主 skill；内部 SVG 资源支持正文展示，不默认另附下载件。原始代码、路径、XML 或本地草稿不能冒充已展示、已插入或已上传的结果。

## 能力发现

lark-doc、online-doc、general_search 等名称来自来源包。先发现实际可用的官方工具、连接器、CLI 和参数；本包没有附带这些远端服务，也未声明固定 MCP 地址。文件、脚本、模板和随包参考可在本目录独立读取。需要权限或认证时报告实际阻塞，不猜测私有接口或复制其他任务的凭据。

API/连接器/官方 CLI 优先；浏览器 UI、headless 自动化、截图和地图启动检查中的浏览器行为均需本次用户明确许可。纯语法、JSON、文件和资源哈希检查无需启动浏览器。外部事实按需核验，私有内容的上传、发布和遥测须处于用户授权范围；原包中的 --publish 或遥测默认不自动扩大授权。

## 回读与失败

以真实返回标识回读；超时结果未知时先核实已有产物，避免重复创建。分别记录本地已生成、云端已写入、已回读、已视觉检查；没有实际执行不声称完成。脚本/外链失败保留可读文字和已完成文件。
