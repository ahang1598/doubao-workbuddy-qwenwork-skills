# 回答中的 SVG 数据图

执行时遵守 [SVG 执行与确认边界](../../svg-visualization.md#执行与确认边界)：静态图直接构造 SVG，不以修改绘图脚本为前置；已有工具权限内的临时计算与检查不另发对话授权确认，平台强制审批及浏览器许可仍须遵守。


## 输入与输出

输入：用户资料中的数值、单位、参考范围、日期和目标宿主。输出：在当前回答中实际展示的 SVG 数据图及必要的结论、口径与局限。保留精确查值所需的表格，避免重复整份数据清单。

不调用生图或图片编辑工具，不生成栅格图，不以截图或位图导出作为回退。不用于医学影像重绘、诊断或治疗建议。

## 执行

1. 先读 [可视化取舍](references/visual-value.md)，确定图形能帮助比较什么；短表已清楚时保留短表。
2. 读 [SVG 共用规范](../../svg-visualization.md) 和 [SVG 数据图规范](references/mode-svg-chart.md)，选择共同尺度的点/条、参考区间标记、真实时间位置或分布图，不用文本卡片代替数据编码。
3. 数值和位置从同一数据计算；单位、日期、口径、参考范围及缺值保持对应。不要混用不同临床意义的尺度，不把偏离程度当风险评分。
4. 按 [依赖与交付协议](references/delivery-contract.md) 在宿主中展示 SVG；不输出只可查看配置的代码来冒充图形。无法展示时交付正文与必要表格。
5. 核对轴、图例、标签、数值、来源和窄屏可读性；静态状态应表达核心结论。交互有收益时再读取随包交互子 skill。

数据和交付的其他要求服从主 skill，飞书文档仍不用图表助手。
