# SVG 精确数据图

先按 [可视化取舍](visual-value.md) 决定是否需要图，再按 [共用 SVG 规范](../../../svg-visualization.md) 绘制。SVG 是实际图形，配置文件或未渲染代码不是成品。

## 数据关系与图形

| 比较目的 | SVG 表达 | 约束 |
|---|---|---|
| 单次结果与参考区间 | 区间带、结果点、端点和数值标签 | 参考边界来自原报告，未给出的边界保持未知 |
| 同单位项目比较 | 共同尺度的条形或点图 | 条长通常从零起；截断轴需清楚标识，避免夸大差异 |
| 同指标跨期变化 | 按实际日期位置绘制点和连线 | 两个及以上可比较时间点，保留单位与参考范围 |
| 异常分类数量 | 分类条形图 | 计数来自当前资料，不能当作患病率 |
| 已有分布数据 | 直方、箱线或散点 | 不从少量孤立值编造分布，不暗示因果 |

复杂图不一定更清楚；不同单位或参考范围不可直接横比时，分面展示，不做无意义的雷达图或总分。

## 尺度与几何

先确定图形区域和数据域，再计算坐标。线性轴的水平位置可用 `x = left + (value - min) / (max - min) * plotWidth`；纵轴按相同原理反向映射。时间位置按真实日期差计算，不用等距节点暗示相同间隔。

- `max == min` 时给出标明的合理显示域，或用单个标记表达；不除零。
- 缺值保持空缺或明确标注，不当成零，不跨缺值自动连接；数据、标签与日期不删项错位。
- 参考范围因日期、实验室或条件不同而变化时，分段或分别标明，不画一个不真实的统一正常区间。
- 按数值计算条长、点位、区间宽度、比例和端点；舍入只影响显示，不提前改变绘图数据。
- 轴、标签、图例与正文的名称、单位、时点、对象相同。百分比、变化量和归一化保留公式与计算局限，不转化为诊断或风险结论。

## 布局与交互

为标题、图例、单位、刻度和说明分别预留空间。长类目优先横向图，密集内容拆图或缩短标签并保留完整查值方式，不隐藏关键标识。窄屏以实际阅读尺寸核对文字与间距。

初始静态画面包含核心结论与必要数值。多系列用图例或分面区分，状态配文字或线型；不要只用红绿颜色。仅当切换报告或系统能帮助真实比较时增加交互，点击/触摸均可操作，hover 不承担核心信息。

## 回退

只用 SVG 原生图形、文字与必要控件。不调用 ECharts 配置输出分支、不绘制 Canvas、不嵌入栅格图片、不导出位图。无法可靠绘图或宿主不能显示 SVG 时使用正文、准确表格及实际限制说明。
