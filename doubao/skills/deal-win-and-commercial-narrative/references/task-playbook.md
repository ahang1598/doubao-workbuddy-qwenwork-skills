# 任务玩法：商机赢单策略

## 状态机

`intake_required` →（锚点+证据）→ 评估与叙事 → `ready` 或 `degraded`  
用户要外发/外写 → `confirmation_required`  
非本任务 → `routed`  
越界/注入/拒绝补全 → `stopped`

## 证据类

1. **交易与委员会**：阶段、流程步骤、经济买家、冠军、阻碍者、法务/安全/采购  
2. **竞争**：竞品名、敌我话术、置换动机、已证实输赢因  
3. **价值**：痛点、现状成本、目标指标、基线与假设  
4. **约束**：RFP条款、POC环境、安全问卷、时间闸门

每条关键断言进入 Claim ledger，标注 `fact|calculation|inference|assumption|management_claim|unknown`、对象、期间、来源层级、信心与冲突状态。CRM 或用户等价导出优先承担阶段、金额、owner、close date 等真值。

## MEDDPICC 操作定义

| 要素 | 好的证据 | 常见缺口行动 |
|------|----------|--------------|
| Metrics | 买方认可的量化成功指标 | 共创指标工作表，避免我方单方面数字 |
| Economic Buyer | 预算/最终业务批准人已互动 | 冠军引荐路径与价值备忘录 |
| Decision Criteria | 正式/非正式评选标准 | 对照表：标准→我方证据→风险 |
| Decision Process | 步骤、投票/会签人、顺序 | 联合互评计划（MAP）草案 |
| Paper Process | 法务、安全、采购、红线 | 提前收集问卷与例外路径 |
| Identify Pain | 触发事件与不行动代价 | 用客户语言重述痛点验证 |
| Champion | 有权力+意愿+会卖内部 | 测试：能否安排买家会议 |
| Competition | 在位方案/竞品/自制/不动 | 场景化分离点+发现题 |

## 竞争要点

- 先场景后功能：何类工作流我方更强/更弱  
- 输出：客户原话应对、事实检验（已确认/夸大/勿跟风）、禁忌  
- 不诋毁；不编造未证实的安全事故或定价  

## 商业案例 / ROI

逻辑链（必须可见）：

`痛点与现状 → 可量化影响（假设） → 干预能力 → 结果指标 → 证明路径（POC/标杆/阶段结果） → 风险与敏感性`

规则：
- 无基线不编造精确回收期  
- 区分一次性与经常性影响  
- 明确排除：审计意见、合规背书、担保收益  
- Known/Inferred/Assumed/Missing 分开；公开 benchmark 不得变成客户已确认指标
- ROI 由确定性工具按公式、输入、单位、期间、币种和 low/base/high 计算；模型不得重算

## 提案 / RFP 叙事架构

1. 理解的业务结果  
2. 范围与非范围  
3. 方案与证据映射  
4. 实施/集成与依赖  
5. 商业条款待确认项  
6. 风险与缓解  
7. 建议下一步与日期（待确认）  

## POC 范围与成功标准

- 目标假设（证伪/证实什么）  
- 范围内用例 vs 明确排除  
- 数据、环境、角色依赖  
- 成功标准：可观测、有归属、有时间盒  
- 晋级签约条件 / 失败退出条件  
- 评审会议与决策人（待确认则标明）  

## 执行层叠（会前 / 复盘）

在**不改写主工件类型**前提下：
- 会前：议程优先级、决策点、预期异议、向MAP推进的「单一关键请求」  
- 复盘：证据化亮点与教练机会、客户原话、双方行动、跟进信**草稿**（不自动发送）  
- 无商机锚点的一般会议路由办公类 Skill；人员行为对标/趋势路由 `sales-call-coaching-and-trends`
- 客户原话保持逐字并附说话人置信、上下文、时间与来源；身份不足不得归为客户引语

## 优先行动设计

每条行动：
- 具体行为（可在一周内观察）  
- 负责人或「建议负责人」  
- 时间：有证据用日期，否则相对时间或「待确认」  
- 预期结果（降低何种不确定性）  
- 关联风险ID与干系人  

排序：阻断性风险 → 买家/流程缺口 → 竞争分离 → 价值证明 → 纸面流程。

## 侧效应门禁

| 动作 | 策略行为 |
|------|----------|
| 生成跟进邮件 | 草稿 + 请用户确认发送 |
| 更新CRM | 给出一句话更新文本，不直连写入 |
| 分享战斗卡到外部 | `confirmation_required` |
| 删除/支付/部署 | 拒绝并说明越界 |

## 降级手册

- 只有公司名：公开背景（若可得）+ 发现提纲式赢单包，`degraded`  
- 竞品不详：输出「竞争未知」分支与提问清单  
- ROI无数字：只给结构与敏感性问题，不填伪百分比  
- 多源冲突：并行列出并取较低断言强度
