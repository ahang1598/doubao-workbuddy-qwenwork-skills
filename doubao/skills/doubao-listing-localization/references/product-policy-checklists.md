# Platform Policy Checklists

Use these checklists to compare current product state against official product requirements. If exact policy details matter, verify the latest official page for the target country/site.

## Amazon Product Page And Offer Checklist

| Area | Check | Evidence path |
|---|---|---|
| Product identity | Product type, brand, GTIN/product ID, category, variation family are correct | Seller Central Add Products / Manage Inventory |
| Title | Informative, readable, includes key product facts, not promotional or stuffed | Product Detail Page Rules / listing guide |
| Images | Main image accurate, high quality, white/plain background where required, enough images, zoomable where applicable | Images tab / PDP / official image requirements |
| Bullets | Enough bullets, concise, factual, no price/promo/contact/review requests | Description tab / PDP rules |
| Description / A+ | Useful product explanation, no unsupported claims | Description tab / A+ Content Manager |
| Search terms | Relevant terms, no repetition or subjective claims | Keywords tab / search term guidance |
| Price | Offer price, coupons, discounts, VAT/tax display, external competitive price, Featured Offer eligibility | Manage Pricing / Pricing Health / Offer tab |
| Inventory | Quantity, fulfillment channel, stranded inventory, restock status | Manage Inventory / Inventory Performance Dashboard |
| Featured Offer | Offer status, competitive price, shipping speed, seller metrics | Pricing Health / Featured Offer report |
| Suppression | Missing required attribute, image issue, policy violation, safety complaint | Account Health / listing quality / suppression notice |

## Walmart Marketplace Checklist

| Area | Check | Evidence path |
|---|---|---|
| Item Spec | Latest Item Spec version and category attributes are used | Walmart Item Spec / Seller Center |
| Product name | Matches product type and key attributes | Seller Center / PDP |
| Images | Actual product images, main image compliant, no stock photos, no watermarks/text overlays, sufficient quality | Marketplace Learn image requirements |
| Attributes | Required and recommended attributes completed | Item setup / Item Spec |
| Price / inventory | Price, stock, variant values, WFS/shipping fields correct | Seller Center |
| Unpublished reason | Content, policy, image, attribute, or operational cause identified | Seller Center notifications |

## TikTok Shop Checklist

| Area | Check | Evidence path |
|---|---|---|
| Title | Accurate, concise, essential identifying information, no ALL CAPS, no seller name/link, no subjective claims | Product Listing Policy |
| Description | Clear, useful, specific, enough detail, required warnings/disclosures included | Product Listing Policy |
| Brand | Brand provided correctly and authorized when using third-party IP | Product Listing Policy / IP Policy |
| Images/videos | Product accurately represented; main image white background; no overlays/watermarks/text; size and count meet policy | Product Listing Policy / Listing Quality Guidelines |
| Category | Correct category and approvals where required | Seller Center category guidance |
| Variations | Size, color, flavor and other variations accurately represented | Product Listing Policy |
| Listing quality | Poor/Fair/Good tier and missing fields addressed | Listing Quality tool/guidelines |
| Prohibited/restricted | Product not prohibited or restricted without approval | Prohibited / Restricted Product Policies |

## Shopify / Independent Store Checklist

| Area | Check | Evidence path |
|---|---|---|
| PDP completeness | Title, media, description, variants, price, inventory, shipping/returns info | Shopify Admin / PDP |
| Variant accuracy | Variant names, images, SKU, inventory, price and availability match | Shopify product admin |
| Price consistency | Product page, checkout, discounts, feed, ads landing page all match | Shopify / GMC diagnostics |
| Media | Images show actual product/variant, not misleading | Shopify media / PDP |
| Feed readiness | GMC required fields: id, title, description, link, image_link, price, availability, brand, gtin/mpn when applicable | Google Merchant Center |

## Cross-Platform Diagnosis Rules

- A competitor doing something is not proof that it is allowed.
- If a policy page is country-specific, do not apply it globally without caveat.
- Backend states such as suppression, listing quality score, Featured Offer, inventory health, and ads eligibility require Seller Center evidence.
- Public PDP is enough to diagnose visible content gaps but not backend cause.
- For safety, IP, certification, tax, or customs questions, hand off to the relevant risk/logistics skill.
