# 工具实现与验收

仅在编写或复核测试、采样器、比较器、CI 守卫时读取。业务实现和执行权限遵守用户范围；本 Skill 不附带必须安装的工具。

## 把合同变成执行行为

将硬要求对应到实际运行入口及失败动作，配置声明不能代替执行。优先复用一个受控运行入口，供行为检查、预热、正式采样和重试调用；不能让外围阶段绕过合同。

| 合同要求 | 实现与可观察验收 |
|---|---|
| 任一进程资源上限 | 适用的正确性、预热、正式、重试与诊断运行都检查。任一越限后不再启动后续工作；若峰值仅退出后可得，说明只能事后阻断，不能宣称能即时杀进程。实时硬限由已有隔离机制实现或列未落实项。 |
| 关闭诊断 | 核对实际 argv 和子进程继承环境，清除或拒绝合同冲突的诊断开关，保留业务必需环境；不能只在报告写“关闭”。 |
| 同一存储/指定文件系统 | 校验真实输入与输出的解析路径及挂载属性，必要时复制输入后校验字节一致。不满足或不能验证时阻止正式比较，不能警告后仍放行。 |
| 总进程/时间预算 | 按合同计数单位在总入口预分配或共享计账，涵盖合法配置的行为检查、预热、采样、单独曲线和重试；失败尝试也扣额度。同进程附带曲线不重复扣。排除出性能分布不等于排除出预算；独立子命令不能重置同次实验预算。 |
| CI失败动作 | 输出机读状态且返回合同规定的非零码；包装器透传。超限后检查不再 spawn，不能仅打印失败仍退出成功。 |

## 采样、漂移与比较

采集顺序原样保存；按时间前后段检查漂移，另用排序副本算分位数。均匀交错的高低样本不应被排序后假造成前慢后快。

比较器使用[实验合同](experiment-contract.md)的受控条件与版本身份分离。字段缺失、同名矩阵实际参数改变、采样/有效性/统计口径变化时拒绝比较；仅版本身份变化不得误报环境漂移。

行为验证是性能结论的前置依赖，可串在总入口，或由采样器核验同版本的成功行为报告。保留无效样本及原因；按预登记规则失败或重测，不能静默过滤后返回可发布的 PASS。SLO 单元缺失标未覆盖；样本无效或行为未验证时不能称 SLO 通过。

## 最小验收与交付

在许可范围内检验实际控制路径：正常路径、每类硬门的失败路径及停止行为、预算边界、比较条件变化。测试门禁用同一 oracle 验证“基线通过、错误候选失败、等价副本通过”；缺陷诊断快照与候选验收分离。最小桩测只证明控制逻辑，不证明业务性能或目标操作系统行为。

交付完整可保存文件、目录结构、入口命令、依赖、结果位置和失败含义，简单请求不增加多余入口。分别说明静态检查、局部执行与目标环境运行；受环境或用户范围限制时仍完成文件，并明确剩余验证，不以示例数据冒充正式结果。
