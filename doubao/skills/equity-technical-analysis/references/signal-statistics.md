# 信号后表现统计

冻结信号定义、参数、确认时点、历史股票池、样本区间、观察窗口、收益字段、基准和成本状态。逐事件列纳入/排除理由。题面要求信号时点的股票池而未提供该数据时，记为证据不足并降级输出，禁止以当前成分股回看历史代替。

同股票持有窗重叠按预设规则去重；窗口未完成记为右删失，不进入该窗口统计；预热不足或字段缺失不补值。报告样本量、覆盖率、胜率定义、均值、中位数、极值、可计算分位数、MFE/MAE 均值及符号口径，并量化去重前后差异。

不能在未计算时声称置信区间或显著性。样本很小时可报告单个事件翻转对胜率的影响。MFE/MAE 是事后路径极值，不是可实现盈亏比。分别讨论小样本、时间聚类、横截面相关、无基准、未计成本、右删失、幸存者和前视偏差，不混用术语。

用户要求显著性、参数寻优、成本后净值或样本外验证时，先完成描述统计，再转 `quant-research` 并携带所需口径。
