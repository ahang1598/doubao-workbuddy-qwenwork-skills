# 输出契约

先给口径抬头，再给实质结论。

单标的：主导信号与冲突、分周期证据、量价/均线、关键位及来源、价格/量能/时间失效条件、待核验项。

选股：条件定义、股票池覆盖、通过/未通过/证据不足逐项矩阵、接近条件候选与差距、数据缺口。

信号统计：纳入/排除台账、样本与去重定义、样本量/胜率/均值/中位/极值/分位数/MFE/MAE、去重对比、独立性/基准/成本限制、量化研究路由。

使用可正常渲染的 Markdown 表格，不输出“表格”等占位字样。不得说已创建未实际存在的文件；自检只列客观待确认项，不做自我背书。

## 正文自含性

回复正文必须自含关键结果，附件和交付文件只作证据备份，不是正文的替代。筛选类正文列出标的名单与逐条件通过摘要；统计类正文列出样本量、胜率、均值及题目要求的全部窗口结果；诊断类正文列出分周期结论与关键位数值。禁止以“已生成/已交付/验收对照”或文件清单替代结果本身；遮住全部附件后，正文仍须能独立回答题目。

正文结论必须由证据矩阵直接计数或计算得出，并与所有交付文件中的同名数字一致；任一不一致即视为未交付。筛选结果为空时，逐证券给出首要失败条件与差距，使零结果可复算，并附最接近候选。

交付前做数值闭合核对：正文每个日期-价格对与原始数据交叉验证；分项之和等于总计；同一数字在正文与附件中取值相同。不附加与证据无关的免责声明或元信息脚注。

## 交付真实性与质检输出

交付文件必须同时满足：实际存在、可打开、内容与题目字段对应、关键结果可定位。若任一条件不满足，写“未交付/无法核验”，不要写“已生成”“已验收”或用本地路径代替文件。

若需要对多个匿名回复排序，先单列技术失败和硬门禁，再比较证据、计算、完整性与决策价值。新增 F 时保留已校准 A-D 的相对顺序，并在理由中说明 F 的插入位置和证据；不按篇幅、图表数量、文件名数量或语气评分。
