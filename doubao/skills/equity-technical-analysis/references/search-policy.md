# 线上搜索工具约定

封闭材料、仅用附件/题内数据、用户禁搜或搜索路由为 `off/blocked` 时不得联网。

确需公开市场行情等结构化数据时优先使用 `seed_finance_lookup`；公告、研报等文本优先使用 `seed_finance_search`，不可用或无结果时回退 `general_search` 并标注降级。只使用宿主实际提供的工具和参数。

回退使用 `general_search` 时应定向发布方或权威常用来源：交易所、巨潮资讯、公司 IR、基金公司官网、中国基金业协会、人民银行、统计局、外汇局、证监会、期货交易所、行业主管机构、SEC 和对应海外交易所。财经媒体只用于发现线索和交叉核验，不能替代一手来源支撑关键结论。

搜索只补公开事实，不能替代用户私有材料或附件。记录来源、数据时点/发布日期与检索时间；无一手证据的关键事实标为待核。
