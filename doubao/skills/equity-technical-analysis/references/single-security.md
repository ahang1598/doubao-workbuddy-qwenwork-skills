# 单标的技术诊断

1. 完成口径抬头与数据审计。
2. 各周期分别分析趋势、均线、动量、量价和结构，再解释冲突；长周期描述结构，短周期描述路径与触发。
3. 背离须列两个可比摆动点的日期、价格、同参数指标值，并说明摆动点选择依赖规则。价格创新高而指标未创新高不等于必然反转。
4. MACD 写明参数、零轴位置和确认时点；均线粘合仅表示压缩。成交量应与明确有效窗口量化比较。
5. 支撑压力标注来源（前高低、平台、缺口、均线、成交密集区）、窗口和日期。无筹码数据不得称筹码峰。
6. 失效条件覆盖价格、量能和时间；同时给支持证据、反证和替代解释。
7. 缠论第三类买点需要中枢、离开、回调不回中枢的结构证据，MACD 金叉不能替代。仅散点或 OHLC 不足时直接写无法确认。

输出：口径抬头、条件性结论、分周期证据、冲突来源、关键位、三维失效条件、待核验项。不得用“操作含义”包装交易建议。
