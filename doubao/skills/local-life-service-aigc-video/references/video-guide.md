## 类型选择
### 探店种草型
适合餐饮、美业、休闲娱乐、亲子、酒旅等需要建立真实到店感的商家。重点呈现门头、进店、环境、服务、产品体验和顾客反应。
爆款要素：
- 前 3 秒给出明确钩子，如低价套餐、排队门店、隐藏菜单、周末好去处。
- 多用第一人称手持视角、推门进店、桌面开餐、产品特写。
- 保留真实烟火气，字幕表达要短，卖点集中。
Prompt 模板：
```text
竖屏9:16，第一人称探店vlog风格，节奏明快。0-3秒：镜头从街道推向[商家名]门头，字幕"[开头钩子]"。3-8秒：推门进店，展示[门店环境/特色区域]，服务员热情引导入座，暖色灯光，有真实到店氛围。8-13秒：快速切换[招牌商品/套餐]特写，热气、色泽、制作动作和顾客试吃表情，字幕依次出现"[卖点1]""[卖点2]"。13-15秒：展示团购套餐画面和门店定位信息，字幕"[真实价格/活动]，点击左下角抢购"。整体暖黄光、真实探店、轻快BGM、无其他平台水印。
```
### 产品展示型
适合主推单品、新品、招牌菜、服务项目或高客单套餐。重点呈现产品质感、制作过程和核心差异。
爆款要素：
- 开头直接给出产品视觉冲击，不绕弯。
- 多用微距特写、慢动作、环绕、制作过程闪回。
- 字幕围绕 1-3 个核心卖点，不堆信息。
Prompt 模板：
```text
竖屏9:16，高级产品广告风格。0-3秒：[招牌产品]在聚光灯或干净桌面上出现，镜头缓慢推近，字幕"[最强产品钩子]"。3-9秒：微距展示食材纹理/服务细节/产品质感，穿插制作过程，如火焰、切开、拉丝、摆盘、护理步骤或体验动作。9-13秒：镜头环绕展示成品和使用场景，字幕"[卖点1]""[卖点2]"。13-15秒：画面定格在[商家名]与[真实价格/套餐]，字幕"现在上抖音抢团购"。画质清晰，光影精致，节奏有冲击力。
```
### 促销引流型
适合团购大促、限时活动、开业、节日营销和淡季拉客。重点是价格、套餐内容、紧迫感和转化路径。
爆款要素：
- 第一屏直接露出价格或优惠力度。
- 1-2 秒一镜，信息密度高但字幕清晰。
- 结尾必须有明确行动号召。
Prompt 模板：
```text
竖屏9:16，快节奏信息流广告风格。0-2秒：大字字幕"[真实价格/优惠]"冲击出现，背景快速闪现[商家名]门头和热闹到店画面。2-8秒：快速蒙太奇展示[套餐内容/核心服务/招牌产品]，每个镜头1-2秒，字幕依次出现"[套餐亮点1]""[套餐亮点2]""[适合人群]"。8-12秒：展示顾客消费场景、排队或热闹氛围，突出真实到店感。12-15秒：门店门头、定位和团购权益同屏，字幕"点击左下角，立即抢购"。色调明亮，节奏紧凑，避免夸张极限词。
```
### 氛围品牌型
适合咖啡、酒吧、民宿、摄影、SPA、茶饮、轻奢餐厅等需要塑造调性的商家。重点呈现空间、情绪、生活方式和品牌记忆点。
爆款要素：
- 开头用场景情绪抓人，如夜景、窗边、灯光、香气、安静角落。
- 慢镜头、平移和局部特写比例更高。
- 文案偏生活方式，不要过度促销。
Prompt 模板：
```text
竖屏9:16，氛围感生活方式短片。0-3秒：镜头缓慢掠过[门店特色场景]，柔和光线，字幕"[情绪钩子]"。3-8秒：展示空间细节、品牌元素、服务动作和顾客放松状态，运镜以慢推、平移、局部特写为主。8-12秒：出现[核心产品/体验项目]，画面干净有质感，字幕"[卖点1]""[卖点2]"。12-15秒：门店名和团购/预约信息自然出现，字幕"[行动号召]"。整体高级、克制、真实，无夸大承诺。
```
### 剧情转化型
适合解决具体消费场景，例如约会去哪、朋友聚餐、周末遛娃、下班放松。重点是人物动机、场景痛点和转化理由。
爆款要素：
- 开头用一句场景化问题或冲突。
- 人物动作要简单可拍，不设计复杂台词。
- 最后把商家作为解决方案呈现。
Prompt 模板：
```text
竖屏9:16，轻剧情短视频风格。0-3秒：人物在[目标场景]中出现，字幕"[场景痛点/问题]"。3-7秒：朋友/情侣/家庭成员决定去[商家名]，镜头切到门头和进店动作。7-12秒：展示[产品/服务/环境]如何解决问题，包含人物自然互动和满意表情，字幕"[核心卖点]"。12-15秒：团购套餐或预约信息出现，字幕"[真实优惠]，点击左下角到店体验"。剧情简洁，节奏清楚，人物动作自然。
```
## 热门视频拆解记录格式
每看一个参考视频，按以下格式记录，交付时保留：
```text
标题：
作者：
点赞数：
链接：
适用原因：
借鉴点：（仅抽象镜头语言/节奏/钩子，不复制独创内容）
落地到 prompt 的镜头：
```
## 广告与内容约束
- 不使用"最""第一""顶级""全网最低"等广告法高风险极限词。
- 不承诺治疗、收益、身份效果或无法验证的体验结果。
- 不出现其他平台水印、竞品 Logo 或无授权 IP。
- 不展示与商家实际经营不一致的产品、价格、门店环境或服务。
- 用户提供素材时优先使用真实素材，但仍需说明 AI 生成可能与实物有差异。
- 借鉴参考视频只抽象通用表达（钩子类型、节奏、镜头语言），不得复制独创台词、画面序列、人物形象、音乐或品牌素材。
