# 任务方法手册：管道拓客经营

## 1. 状态与责任

| 状态对象 | 典型负责人（由用户环境定义） | 完成证据 |
|----------|------------------------------|----------|
| 线索分层与外呼 | SDR/AE | 清单日期、分层理由、下次动作 |
| 拓客序列 | SDR/Growth | 序列步骤、退出条件 |
| 管道健康 | 销售负责人 | 覆盖缺口、老化清单 |
| 商机干预 | AE/经理 | 干预动作与期限 |
| 扩建保有 | CSM/AE | 风险等级、QBR 日期待确认 |

本 Skill **不代替**系统状态机写回；证据落在交付包与用户确认后的自执行动作。

## 2. Fit / Intent 与可解释分层

先冻结用户或组织提供的 ICP、字段、权重、分层规则、容量和禁售/suppression 规则。不得套用固定分数、阈值、沉寂天数或行业默认赢率。

- **Fit**：只使用已定义且可观察的行业、规模、地域、角色或其他硬条件。
- **Intent**：只使用有来源和时间窗的行为、组织、采购或续约信号。
- 缺任一必需字段时保留 `unknown/unscored`，不得把 unknown 当低分或高潜。
- 只有可比字段完整且规则可检查时，才输出用户定义的层级；否则给无序待核池。
- 每账户只进入一个行动桶：`优先跟进|持续观察|暂停触达`，并说明规则、证据、容量约束与安全下一动作。
- 跟进队列的逾期/沉寂定义必须来自用户口径；未知则写待确认。

执行顺序固定为：稳定账户身份 → owner 归属 → suppression → 在跑商机 → 渠道容量 → 信号 → 动作。前五项任一失败，信号再强也只能进入内部核验、内部协调或暂停触达，不得生成外联建议。

话术要点必须绑定**具体行为或字段**，禁止万能话术冒充个性化。

## 3. 信号驱动序列

原则：每个信号族对应假设→价值主张→证据请求→明确 CTA；步数 3–7；渠道受 ICP/合规/日触达配额裁剪。

示例结构（通用，非厂商）：
1. 信号共鸣开场（引用可验证事实）
2. 相关案例或结果区间（无客户授权数据则用行业中性表述）
3. 资源/评估邀请
4. 多线程抄送/替换联系人
5. 退出：拒绝、无响应阈值、或转 Nurture

不代发；输出为逐步文案草稿与建议间隔（工作日）。

## 4. 管道健康与收入情景

关注通用指标（有数据才算）：
- 各阶段金额/数量 vs 配额或目标（缺配额则只描述结构）
- 阶段停留/老化
- 无下一动作或空阶段
- 头部依赖集中度

**预测规则**
- 有历史阶段转化与周期：给 mid/low/high 情景并列出假设
- 无历史：禁止单点「将完成 XX」；状态 `degraded`
- 不得使用虚构赢单率；未知写「待确认」
- 未知阶段从完整预测中排除并单列，但已映射加权金额仍须显示；未知不得按 0。阶段敏感性分别显示相邻一级差额与跨级端点差额。
- 配额存在时计算已映射预测、达成率和缺口；缺财季日历时不根据自然日期自行判定财季。
- 集中度至少给 Top1、Top2、HHI 和剔除最大单笔后的金额。

## 5. 干预商机清单

列：对象、阶段、金额（未知则待确认）、风险/机会类型、建议动作、建议期限、所需内部支持。
只有比较口径齐备时才按用户定义的影响、紧急度与续约规则排序；否则保持无序并列并标证据缺口。

## 6. 大客户扩建与保有

输入：使用深度、席位/模块渗透、合同时间、反馈主题与情绪（聚合即可）。

输出：
- 健康：稳固 / 观察 / 风险（须理由）
- 扩建：可能路径（模块、席位、业务线）+ 证据缺口
- 保有：续约风险缓解动作
- QBR 框架：目标回顾、价值证据、路线图对齐、商业条款开放项、下次承诺

单笔客诉不在此结案；可上送「需服务协同」标记。

## 7. 副作用与确认

| 副作用 | 门禁 |
|--------|------|
| 邮件/短信/外呼任务 | confirmation_required + 对象列表 + 幂等键 |
| CRM 阶段/备注写回 | 字段级确认 + 审计 |
| 批量>用户阈值 | 强制二次确认 |

所有 CRM、建单、关单和触达动作都分四项记录：当前事实、建议动作、是否需审批、完成证据。未见审批或执行记录时写“当前未见记录，后续状态未知”，不得推断已持续多少天未处理，也不得把建议写成已执行。

## 8. 渠道预算、漏斗与事件

- 渠道方案先按稳定 ID 去重，再校验 suppression、在跑商机和容量；容量与预算总额不守恒时只给修正草案，不给最终分配。
- 有效询盘率始终写成“有效询盘/询盘总数”，意向等级不等于有效询盘；CPL 使用有效询盘作分母并同时保留原始分子分母。
- 点击、访客、询盘的分母不同，除非输入给出同一 cohort 的转换关系，否则不得跨口径相乘。CTR 只能进入未来实验设计。
- 耗时同时列起点到告警、起点到最终冻结；样本记录只支持样本结论，不代表总体。

## 9. 部分失败

单个附件、连接器或分析分支失败时，先交付已读取数据的核心表和结论，再列暂缓范围、业务影响与补件方式。不得输出内部路径、payload、schema 或调试日志。

## 10. 与相邻任务分界

- 买量：受众广告预算与版位不在范围
- 主数据：合并账号规则工程不在范围
- 内容战役：长周期内容日历若为主需，可弱引用语言点但不替代本包主干
