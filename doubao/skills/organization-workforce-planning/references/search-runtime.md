# Search Runtime

冻结组织范围、规划期、能力口径和内部基线后自主选择：

- `required`：当前官方劳动规则、披露或公开法定成本要求是情景必要输入。
- `optional`：补充非关键公开行业背景，并明确其不等于内部目标或阈值。
- `off`：用户提供的封闭组织/HC/成本数据建模。
- `blocked`：缺内部组织、人员、薪酬、预算、工作量、技能供需、审批或 mandate。

公开资料不能替代内部基线，也不能创建固定 span、岗位配比、面积效率、占用率、缓冲比例或“健康组织”阈值。关键规则优先官方一手源；行业案例仅作背景/假设线索，必须标明样本、期间和适用边界，不能直接生成编制结论。来源必须与辖区、期间、对象和字段对齐，先进入 Claim ledger；冲突未解则 unknown/degraded。

供应商框架、公开外包能力和行业产能只说明潜在选项。没有内部工作包拆分、可承担范围、提前期和授权状态时，不得把公开或供应商宣称的上限写成已可用资源。
