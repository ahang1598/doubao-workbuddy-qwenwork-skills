# Verify and Match Citations

把“文献是否真实、题录是否准确”与“文献是否支持正文论点”作为两个独立结论。只有真实性与相关性都过关的候选，才能作为替换或补引文献。

## 1. 固定任务对象与引用映射

1. 判断任务是核验指定条目、检查正文引文编号、为论点补引，还是替换引用；保留用户指定的引用样式。
2. 定位目标句及前后文，把正文编号或作者—年份标注映射到文后条目；不能只核验孤立的参考文献表。
3. 建立工作记录，至少包含 `citation_id`、`claim_id`、`authors`、`title`、`journal_or_publisher`、`year`、`volume`、`issue`、`pages_or_article_number`、`doi`、`pmid`、`language`、`file_source` 与 `context`。页码和文章号写在同一字段时仍须保留原始形态，不把 article number 猜成页码。
4. 一句包含多个可证伪断言时拆为多个 `claim_id`；同一引文可映射多个主张，但每个主张必须单独判定。

## 2. 核验真实性与书目信息

1. 以 DOI 解析页、期刊或出版社官网、PubMed 等权威记录为 `L1`；本地 PDF 首页、页眉页脚及全文为 `L2`；搜索结果摘要、Google Scholar 条目或二手参考文献为 `L3` 线索。
2. 逐项比对 `title`、`authors` 及顺序、`journal_or_publisher`、`year`、`volume`、`issue`、`pages_or_article_number`、`doi`、`pmid`。题名相似不等于同一文献，不能把候选记录的 DOI、卷期页自动填给目标条目。
3. 状态只用 `已确认`、`存疑`、`未找到`、`疑似错误`：至少有 `L1` 且核心字段一致才标 `已确认`；只有本地全文时写“本地全文确认，外部元数据未独立确认”；只有 `L3` 时必须标 `存疑`。
4. DOI 查询无结果时写“未发现 DOI”；若 PMID 已确认可单列 `pmid`，不得据此构造 DOI。数据库记录冲突时逐字段列出冲突值和来源，不自行拼成一条“完整”题录。

## 3. 提炼内容并判断论点匹配

1. 从可访问的摘要或全文提取 `population_or_object`、`design_or_method`、`variables`、`main_findings`、`scope`、`limitations`；只看题名时不得输出内容结论。
2. 对每个 `claim_id` 比较研究对象、条件、方向、指标或数值和结论，匹配状态只用 `直接支持`、`部分或间接支持`、`不支持`、`无法判断`。
3. `直接支持` 要求文献结果覆盖该原子主张的关键对象、关系方向和限定条件；只提供背景、机制延伸、相邻人群或方法来源的，均归 `部分或间接支持`，不能包装成直接证据。
4. 无全文且摘要不足以覆盖关键数值或条件时标 `无法判断`，并注明“仅见摘要”；真实存在的文献也可判为 `不支持`。

## 4. 计算覆盖并决定处置

1. 文献去重时，同一标准化 `doi` 计作 1 篇；无 DOI 时，仅当规范化 `title` + 首作者 + `year` 三者一致才计作 1 篇。分别报告“文后条目数”和“唯一文献数”，不把重复条目误算为多篇证据。
2. 引用覆盖率按 `正文至少出现一次的唯一文献数 / 文后唯一文献数` 计算；文后存在但正文未出现的条目列为“未引用”，不计入分子。
3. 严格匹配率按 `直接支持的 claim_id 数 / 已判断的 claim_id 数` 计算；`已判断`只含直接、部分或间接、不支持，不含无法判断。若用户要宽口径，另报 `(直接支持 + 部分或间接支持) / 已判断`，不得混用两种结果。
4. `已确认 + 直接支持` 可保留；`已确认 + 部分或间接支持` 应拆句、降低措辞、移动标注或补主引文；`不支持` 应替换或删除；真实性为 `存疑`、`未找到` 或 `疑似错误` 时，不因内容看似相关而保留为确定引用。

## 5. 定向补引、格式化与交付

1. 补引检索式同时包含论点概念以及人群/场景、量表或指标、机制、研究类型；中英文并行检索，并对每个候选重新执行第 2、3 节，不能只追求题录完整。
2. 输出核验表，至少给出 `citation_id`、规范题录、真实性状态与来源、`claim_id`、匹配状态与理由、建议动作、推荐插入位置。建议动作限定为“保留、改写、移动、补引、替换、删除”。
3. 本地文献注明 `【本地PDF：原文件名或文件夹编号，核验页码，信息层级】`，其中信息层级明确写“首页”“摘要”或“全文”；仅从文件名获得的信息写“文件名线索”，不得提升为已确认。数据库外补文献另标 `【PubMed补充：PMID …】` 或相应权威来源，不能误称为本地发现。
4. 按用户指定格式输出；未指定时采用一种清晰一致的格式并保留 DOI/PMID。任何缺失字段保持“未确认”，不得生成作者、卷期页或标识符。

## 工具与来源选择

- 已有 DOI：先查 DOI 解析记录与出版社页，再用 Crossref 或学科数据库交叉比对 `doi` 和题名。
- 医学与生命科学：用 PubMed 核对 `pmid`、题名、作者、期刊与摘要；内容匹配仍以摘要或全文实际表述为限。
- 无唯一标识符：以题名精确短语、首作者、年份组合检索期刊官网、索引库或学术搜索引擎；索引库命中只算 `L3`，直到取得 `L1` 或明确的 `L2`。
- 本地 PDF：读取首页、摘要和必要的结果/讨论页，记录实际页码；扫描件 OCR 不清时标注无法确认具体字段。

## 边界与禁止事项

- 不编造文献、作者、DOI、PMID、年份、卷期页；查无结果就是 `未找到`，信息冲突就是 `存疑` 或 `疑似错误`。
- 不用题名相似度替代真实性核验，也不把综述中的二手转述当作原始研究已核实。
- 不把背景性、方法性或延伸性证据写成 `直接支持`；替换文献必须同时通过真实性和论点匹配两道检查。
- 不声称读过未访问的全文。来源只能写实际查看过的 `L1`、`L2` 或 `L3`，本地 PDF 必须细分首页、摘要、全文或文件名。

## 精简示例

用户要求核验正文“干预显著改善指标 B[12]”及条目 `[12]`。先拆成“实施干预”和“指标 B 显著改善”两个 `claim_id`，再核对题录。若 PubMed 与出版社页确认题名、作者、年份和 PMID，但摘要仅支持实施干预、不报告指标 B，则输出：

> `[12]`〔真实性：`已确认`，来源：PubMed/出版社页；匹配：`部分或间接支持`——支持干预背景，不支持指标 B 的显著改善；建议：保留作背景引文，并为指标 B 补充主引文或删除“显著”〕

若同时发现本地文件，应追加 `【本地PDF：study12.pdf，第1页与摘要，信息层级：摘要】`，而不是把未读结果页表述成全文依据。
