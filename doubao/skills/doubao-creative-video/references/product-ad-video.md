# 产品广告视频

## 文件说明与索引

本文件只负责产品广告、电商带货、商品展示、产品功能演示、场景种草、体验测评、教程演示、促销转化、产品大片和产品 launch 的专属策略。参数确认、阶段确认、目录、阶段上屏、工具和成片规则读取 `references/production-control.md`；通用创意方向读取 `references/creative-core.md`；通用视听语言读取 `references/audiovisual-craft.md`；视觉效果、叙事节点和转场同步读取 `references/visual-motion-playbook.md`。

## 适用边界

使用本策略的场景：

- 商品展示型：电商主图视频、产品功能演示、产品细节特写、360 展示。
- 场景种草型：场景化种草、家居/生活场景植入、模特试穿试用、使用前后对比。
- 体验测评型：产品测评、开箱展示、试用体验、食品制作过程展示。
- 教程演示型：产品使用教程、功能操作演示、多产品合集展示。
- 促销转化型：限时促销视频、直播切片商品展示、爆品合集推荐。

如果核心是达人对镜口播，优先 UGC；如果核心是品牌理念和形象记忆，优先品牌 TVC；如果核心是企业事实和 B2B 信任，优先商务视频。

## 确认阶段重点

参数确认阶段必须讲清：

- 产品主体：具体 SKU、包装版本、颜色、规格、数量。
- 产品信息：核心卖点、使用场景、适用人群、优惠/价格/活动信息。
- 素材职责：产品图是否作为唯一产品参考；场景图、风格图是否只参考调性。
- 证明方式：功能演示、材质/质地证明、使用前后对比、开箱、结果状态、规格展示。
- 产品造成的异常结果：把主卖点翻译成一个可见的物理结果、行为结果或空间结果，并说明它如何被产品动作触发、如何回收为真实证明。
- 主角/主体：产品、人物、宠物、手部、使用场景或视觉母题谁负责带动观看。
- 色彩策略：产品色、背景色、品类情绪色和 packshot 收束色。
- 文案策略：默认从信息型旁白、数字否定式、参数重复、网感花字、尾帧 slogan 或节庆祝福中选择；无旁白纯音乐只在用户已明确要求无人声时可选。
- 音效策略：开盖、倒入、水滴、磁吸、咔嗒、宠物反应、噪音切断、鼓点卡点和品牌短音。
- 台词/旁白：默认选择信息型、诗性或用户提供文案并形成完整可听文本；纯音乐只在用户已明确要求无人声时可选。
- 字幕：默认无字幕；广告大字不等于字幕。
- 创意生成方式：用户没有给参考视频时，不追问参考视频；必须基于产品信息、品类、平台和目标用户内部发散，并择优收束成一个完整建议方案。无论用户是否明确说“更有创意”，都要先用 `creative-core.md` 建立产品真相和产品结果，用 `audiovisual-craft.md` 补齐运镜、布光、构图、色彩、转场、声音和文案，用 `visual-motion-playbook.md` 选择主视觉效果、辅助效果、转场效果、异常规则、叙事节点和可复述画面，再翻译成产品专项分镜。

分镜表节拍默认覆盖：hook/产品登场/卖点证明/使用结果/packshot 收束。用户未指定总时长时，按主 SKILL 在 4-15秒内选择能完成“产品介入 -> 可见证明 -> 结果/packshot 收束”的最短成立时长，不得由策略自行扩展到 15-30秒。只有用户明确要求总时长超过 15秒时才进入长视频拆段；只有用户明确指定“一条/单条/这个视频/每段”为 16-30秒，才按主 SKILL 触发 `seedance 2.5`。

产品广告每个视频片段必须先锁一个产品核心：这一段到底证明哪一个主卖点、解决哪一个问题、建立哪一种购买理由或记住哪一个产品资产。短片直出压缩链路尤其不能只做“有创意的画面集合”；创意机制、动效和镜头都要围绕一个产品核心服务。写 PE 前内部用一句话自检：

```text
这一段让观众相信：[产品/服务] 能带来 [具体结果]，因为他们看见 [具体证明动作或结果状态]。
```

如果这句话写不出来，先重写主卖点、证明动作和开场，不进入生成。

产品广告大片、产品 launch、TVC 化产品广告和商业氛围片仍按主规则先看模型和时长：`2.0` 系列 15秒以内、`2.5` 30秒以内走短片直出链路；超过单条时长、长视频、需要分段连续生成或用户明确要求完整成片链路时，走完整链路。不要向用户点名内部模式。

## 产品广告主线

每条产品广告只选一个主传播目标：

| 主线 | 重点 | 执行 |
|---|---|---|
| 品质证明 | 材质、工艺、口感、肤感、结构 | 微距、慢推、质地/结构证据、稳定 packshot |
| 功能卖点 | 效率、性能、体验提升 | 问题 -> 操作 -> 结果，避免堆参数 |
| 促销转化 | 新品、优惠、限时、爆品 | 强 hook、产品高频露出、短 CTA，促销事实必须确认 |
| 场景种草 | 生活方式、向往场景 | 场景痛点 -> 产品进入 -> 使用动作 -> 结果状态 |
| 感官体验 | 食品、饮品、美妆、香氛、面料 | 水、冰、泡沫、质地、布料、拟音和近景证明 |
| 教程演示 | 步骤、操作、功能组合 | 步骤清楚，每步一个动作，避免一镜塞太多 |
| 对比证明 | 新旧方法、竞品替代、升级款 | 对比维度必须真实可确认，不贬损未核实竞品 |
| 社会证明 | 评价、案例、销量、奖项 | 只能使用用户提供或已核实证明，不编造口碑 |
| 意象证明 | 护肤、香氛、健康、情绪价值产品 | 荒漠到新芽、水滴到焕活、果香世界、光粒到真我，隐喻必须回到产品 |
| 节庆节点 | 春节、新年、节日礼赠、生肖主题 | 节日色彩、祝福文案、产品阵列、礼盒/包装和节点 CTA |

传播主线是决策锚点，不是模板。镜头设计必须结合品类、平台、产品资料和素材状态。

卖点处理遵守用户指令：用户明确提供的卖点必须覆盖，不能为了“精简”擅自删掉；卖点很多时分成主卖点和辅助卖点，主卖点用核心镜头证明，辅助卖点用短镜头、画面细节、旁白或尾帧承载。用户没有提供卖点时，可以结合产品品类、使用场景和可见证据提炼，最多 5 个；不得自行编造功效、参数、认证、销量、价格、奖项、医疗/安全声明或客户背书。

## 产品核心与玩法转译

产品广告最容易失败在“展示了产品，但没有让观众记住为什么需要它”。每条产品广告先把产品核心压成一句话，再选玩法。内部句式：

```text
这条片让观众相信：[产品] 在 [使用场景/情绪场景] 中带来 [一个具体结果]，
因为他们看见 [一个可见证明动作/结果状态]。
```

常用产品核心：

| 核心 | 证明方式 | 适合玩法 |
|---|---|---|
| 新品值得期待 | 局部线索逐步揭示，最终完整产品和发布信息 | 光影揭幕、轮廓显影、倒计时、局部到整体 |
| 天然新鲜 | 源头、种子、牧场、原料、灌装或生长过程进入产品 | 生长生成、源头到产品、自然意象关联 |
| 感官好 | 质地、声音、液体、咬合、泡沫、光泽、人物反应 | 微距、ASMR、材质幻变、物理小高潮 |
| 分量足/选择多 | 产品数量、形态、SKU 或礼盒内容逐步增多 | 自动填充、悬浮阵列、错峰弹出、家族阵列 |
| 设计高级 | 结构、材质、开合、旋转、多角度、手部拿起 | 极简旋转、纯 3D 开合、光影巡航、稳定 packshot |
| 功能有效 | 使用动作导致状态改变，前后差异清楚 | 痛点到解决、即时分解、旧新争夺、进度完成 |
| 便携适配 | 真实场景里随手拿出、开合、饮用、穿上、收纳 | 第一视角动作链、生活化开箱、场景种草 |
| 情感礼赠 | 节日、晚餐、生日、举杯、礼盒打开和人物反馈 | 情境仪式、暖光叙事、产品作为情感载体 |

玩法转译时先选一个主创意系统或全局玩法，不要把所有技巧无关系地混在一条片里。一个主系统可以包含多个相关创意节点，但它们必须由同一产品动作、包装/Logo 规则、使用流程、空间规则、声音节拍、材质逻辑或卖点证明串起来：

- 光影揭幕适合汽车、3C、香氛、硬件、发布预热。它的重点是“逐步释放信息”，不能全程黑暗到看不清产品。
- 生长生成适合鲜奶、护肤、天然食品、包装动态和品牌名带自然含义的产品。它必须让元素逐步变成包装、成分或产品价值，不只是长藤蔓。
- 语义幻变适合月饼/饼干、食材/宠物粮、容器/花朵、鱼/粮、旧状态/新状态。变身后要给产品解释和识别停留。
- 产品自编舞适合巧克力、耳机、礼盒、多 SKU、模块化产品和 UI 卡片。动作要精致、有节拍、有落点。
- 物理小高潮适合饼干堆叠、面料拉伸、清洁分解、开盖弹出、泡泡转场。小高潮后必须回到稳定产品或结果。
- 第一视角动作链适合开箱、咖啡、运动饮料、防晒、露营、服饰上脚和手部演示。手、产品、环境和声音必须同步。
- 情境仪式适合节庆啤酒、巧克力礼盒、生日蛋糕、咖啡晨间、香氛海边和户外装备。产品必须参与仪式动作，不当纯摆拍。

上述适配关系是可选方向，不是品类默认答案。产品广告尤其要避免“品类一出现，玩法就自动落到第一感官”：食品不默认咬下碎裂、咔嚓声波、碎屑爆炸或口味光波；饮品不默认水花、冰块、瓶身结露慢镜；护肤不默认水光扩散、蓝绿光波和花瓣；汽车不默认雪山光轨；3C 不默认黑场光扫和参数粒子。若这些感官元素确实来自真实使用动作，可以只作为声音、质地或局部反馈；主创意系统必须另有一个当前产品独有的因果系统，例如包装机关、Logo/字形规则、角色视角、场景任务、使用流程、对比证明、社交反应、产品内部世界或品牌资产回收。

选择主创意系统/主玩法前必须先问：

```text
如果不用本品类最常见的声音/光/水/粒子，这条片还能用什么机制证明同一个卖点？
这个玩法是否由当前产品结构、包装、品牌资产、使用动作或目标人群触发？
这个玩法出现 2-3 次时，每次是否推进新的证明、选择、反应或回收，而不是一次特效后结束？
```

回答不出来时，不进入分镜；先回到 `creative-core.md` 的品类套路排雷重新发散。

如果产品资料很少，也不能默认“产品旋转 + 卖点字 + packshot”。先从品类推一个最小证明动作：吃喝要有入口/倒入/咬下；美妆要有质地/上脸/光泽；服饰要有上身/走动/拉扯；3C 要有开合/连接/界面状态；清洁要有污渍前后；宠物食品要有宠物行为和食材来源；户外要有搭建/穿越/休憩。

品类不等于唯一玩法。产品广告要先根据核心表达发散多个可用方向，再收束成一个最优方向。示例逻辑：

- 鲜奶如果核心是天然可信，可以走牧场源头、灌装流程或种子/草地生长；如果核心是活力，可以让奶牛、杯中奶浪和早餐桌按音乐轻快起舞；如果核心是纯净，可以让包装信息像嫩叶一样从空白盒身长出。
- 跑鞋如果核心是百搭，可以分屏汇聚多人物；如果核心是复古态度，可以用城市公园、旧胶片色和同步系鞋带；如果核心是轻盈，可以让脚步触发地面线条和风的路径。
- 护肤如果核心是焕活，可以水光花影绽放；如果核心是科研可信，可以实验室到居家使用；如果核心是质地舒服，可以用膏体微距、涂抹声和肌肤光泽证明。

最终只能让一个方向做主叙事，其它方向作为辅助镜头或直接舍弃。凡是不能服务主卖点、不能回到真实产品、或会增加生成风险的创意，宁可不用。

## 产品广告专项玩法选择器

同一个产品可以用不同视觉玩法，但每种玩法必须证明不同购买理由。选择时先问“这个产品为什么非得这样拍”，再决定主创意系统/主玩法。

| 玩法 | 适合证明 | 执行方式 | 风险 |
|---|---|---|---|
| 巨型画布/巨型道具 | 创作空间大、品牌存在感强、功能被放大 | 产品被放大到人或建筑尺度，真人、手部或环境作为比例尺；产品屏幕、包装或结构承载真实功能演示 | 只做大不做功能，观众只记得奇观 |
| 城市地标装置 | 品牌声量、活动发布、年轻化占领感 | 把产品/包装/活动装置放进真实街区、广场、商场或地标，用 FPV/航拍进入并环绕 | 城市识别太强时，产品不能被地标吃掉 |
| 文字产品化 | 信息解释、概念发布、产品命名或单卖点记忆 | 用一个大字、产品名、功能词或数字成为主体，字形长出图形、配件、产品局部或动效 | 字体动效漂亮但没有产品证明 |
| 拼贴预热 | 节日、会员日、活动、限定款、年轻品牌 | 品牌色背景、台历/便签/撕纸/标签逐张贴上，短文案用符号暗示而非说破 | 信息太隐晦导致观众不知道行动 |
| 生活方式浅景深 | 饮品、香氛、美妆、3C、通勤用品 | 产品前景清晰，城市/办公室/海边/家居背景柔焦；微距细节和光线证明感官 | 只剩氛围，产品价值不清 |
| 小物冒险通道 | 食品、宠物粮、清洁、SaaS、物流、制造流程 | 一个原料、数据、灰尘或零件进入流程通道，每个关卡对应一个处理步骤 | 流程像游戏但没说清成品价值 |
| Logo/包装变道具 | 品牌记忆、视觉梗、轻幽默、活动传播 | logo 几何形状、包装轮廓或品牌色在现实场景里不断换载体，最后稳定成品牌资产 | 不能伪造或变形真实 logo；没有品牌素材时做抽象符号 |
| 通感冲击 | 冰爽、酥脆、顺滑、柔软、清香、安静、速度 | 用水珠、冰、碎裂、慢动作、流体、布料、光线、静默或拟音把感官可视化 | 夸张不能冒充真实功效或参数 |
| 道具线索悬念 | 品牌后置、故事感、引导完播 | 一根线、一个光点、一粒豆、一张纸或一个颜色穿过多场景，终点揭示产品/品牌 | 线索终点必须解释前面所有动作 |
| 纸媒/报纸化包装 | 运动纪实、文化品牌、活动快报、教程方法 | 分栏、大标题、版面、翻页和日期让视频像一份动态报纸或报告 | 信息密度要分层，不能满屏小字 |

玩法和品类的关系是“证明任务”而不是固定配对：

- 饮品不只可做生活方式，也可做通感冲击、巨型空投、道具线索、纸媒快报或城市地标。
- 3C 不只可做光影揭幕，也可做巨型画布、文字产品化、UI 接管现实、微距机械美学或速度可视化。
- 食品不只可做微距试吃，也可做小物冒险、加工通道、通感冲击、语义幻变、拼贴节庆或道具贯穿。
- 服饰鞋包不只可做试穿，也可做低角度阔感、遮挡换装、分屏汇聚、城市路线、技术流标注或时尚硬光。

短 brief 扩充时，发散 `3` 个不同主机制候选，每个候选配 `1-3` 个同源辅助机制，再选 `1` 个主机制进入方案：

```text
候选 A：主机制 + 1-3 个辅助机制，优先直接证明产品卖点
候选 B：主机制 + 1-3 个辅助机制，优先停滑和记忆
候选 C：主机制 + 1-3 个辅助机制，优先平台、场景和品牌调性
最终选择：按用户匹配、核心证明、连续性和生成稳定性选择一个主机制
```

这 3 个主机制候选必须是机制家族差异，不是同一感官套路的三个外观版本。每个候选的辅助机制必须共享触发、产品事实、视觉语言或回收路径，并写清停滑、转场、证明补强、情绪、记忆或收束职责。候选如果都依赖同一个触发词、同一种扩散方式或同一种结尾定版，视为没有完成发散。批量、同品类连续任务或同一用户反复生成相似产品时，主动轮换机制家族，并在内部把最近用过的主创意系统列为避开项。

进入分镜后不要把三个候选都原样拍进去；先确定一个主创意系统。允许保留多个有关联的创意节点，例如同一包装机关连续展开、同一声音规则触发不同空间反应、同一字体系统逐步变形、同一产品世界完成多个任务；其它候选只能提供能融入该系统的开场、转场、证明补强或尾帧。

## 环境代替产品演示

产品广告可以让真实环境替产品做一次夸张演示。桌面、厨房、街道、商场、城市建筑、运动场、牧场、办公室、卧室和浴室都可以被产品动作触发，成为一个更大、更直观的证明装置。这类玩法适合让短 brief 产生惊喜，但必须服务一个产品核心。

内部转译句式：

```text
产品真实卖点：[卖点]
  -> 夸张但可理解的空间反应：[环境变化]
  -> 观众能读出的结果：[购买/使用理由]
  -> 回到真实产品的方式：[packshot/使用动作/尾帧]
```

常用转译：

下表每行只给一个示例环境反应，不是唯一答案；同一卖点/任务可有多种成立的环境演示。结合本条产品、品牌资产、平台和世界规则挑选或重组，不要每次都取同一条；反复只出同一种画面即为套模板，必须换方向或换触发/扩散/回收方式。批量或同品类多条时轮换。

| 卖点/任务 | 环境反应 | 收束方式 |
|---|---|---|
| 清洁力强 | 油污像潮水从桌面/街面退去，留下干净路径 | 喷雾瓶回到手中，干净表面稳定停留 |
| 顺滑/柔顺 | 扭曲线条、头发状道路或弯折楼体被一划拉直 | 回到发丝、衣料或真实使用部位的近景 |
| 吸力/抓取 | 灰尘、碎屑或杂乱模块被吸成规整轨迹 | 产品工作口、尘杯或整理结果可见 |
| 轻盈/速度 | 脚步触发地面线条、风轨或人群同步奔跑 | 鞋底、上脚动作和人物状态定格 |
| 补水/清爽 | 运动场热浪被一口饮料切开，罐体水珠扩散成凉感 | 开罐、饮用反应和罐体 packshot |
| 天然/新鲜 | 牧场、种子、晨光或奶浪从包装/杯口长出 | 包装正面和真实倒入动作收束 |
| 高端/精致 | 空间光线随产品开合而变得有秩序，细节被逐个点亮 | 稳定产品英雄角和品牌字标 |
| 丰富/多选 | 街区橱窗、礼盒格子或桌面槽位被产品自动填满 | 完整阵列停留，避免产品飞走看不清 |

边界：

- 环境演示是创意隐喻，不替代真实证据。功效、参数、价格、认证和医疗安全声明仍需用户材料或明确确认。
- 环境必须先让观众看懂“真实基底”，再发生异常；一开场就全虚拟会降低证明感。
- 产品动作必须是触发源，例如喷、按、开盖、穿上、咬下、倒入、点击、靠近或节拍落下；不要让空间无缘无故变化。
- 夸张演示后必须回到真实产品或真实使用结果，让观众知道买的是什么。

## 产品大片与 Launch

产品大片、产品 launch、TVC 化产品广告和商业氛围片仍然以“产品为什么不可缺席”为核心，不因为画面高级就转成品牌 TVC。规划时先锁定：

| 决策项 | 要求 |
|---|---|
| 产品身份 | 品牌名、产品名、SKU、颜色、规格、包装版本和真实外观锚点 |
| 发布任务 | 新品揭幕、功能证明、版本升级、系列扩展、价格感建立或转化承接，只选一个主任务 |
| 品类证明 | 观众必须看到哪些外观、材质、结构、功能、使用结果或场景，才会相信产品价值 |
| 产品资产 | 产品图、包装、logo、UI、参数和标签来自用户素材或已确认资料，不让模型凭空发明 |
| 创意机制 | 感官放大、结构揭示、功能触发、生活方式进入、发布会质感、问题反转或英雄镜头复位 |
| 尾帧收束 | 最终必须回到清晰完整的产品正面、黄金角、packshot、购买/预约入口或发布信息 |

产品大片可更电影化，但不能牺牲产品一致性：

- 前段可以用材质、声音、光线或使用场景建立价格感，但前 1/3 必须出现产品线索。
- 超现实、悬浮、爆炸图、微缩世界和穿越镜头必须有触发原因，例如打开、按压、佩戴、启动、碰撞或节拍重拍。
- 每个视觉奇观都要证明一个卖点：材质、结构、速度、稳定、便携、口感、肤感、降噪、清洁、连接或情绪价值。
- 字符、logo、参数、海报、包装文字和 UI 必须来自真实素材或后期可控资产；需要清晰可读时，安排稳定正面镜头和足够停留时间。
- 产品形态、颜色、比例、包装、logo 和关键部件不得为了创意被改错；最终必须回到可识别、可购买、与参考素材一致的形态。

常用高规格产品结构：

| 结构 | 写法 |
|---|---|
| 新品揭幕 | 局部线索 -> 材质/结构 -> 功能触发 -> 完整产品揭示 -> 发布信息/预约 |
| 功能证明大片 | 痛点或高压场景 -> 产品动作 -> 机制可视化 -> 结果状态 -> packshot |
| 感官沉浸 | 声音或材质钩子 -> 微距放大 -> 使用动作 -> 人物反应 -> 产品定版 |
| 生活方式产品片 | 理想状态 -> 产品自然进入 -> 多场景体验 -> 产品成为状态入口 -> 轻 CTA |
| 发布会质感 | 黑/白/品牌色空间 -> 产品升起/旋转 -> 参数锚点 -> 使用证明 -> 极简尾帧 |
| 工具解救元广告 | 制作/使用危机 -> “还好有产品/AI/工具”转折 -> 产品生成或带来理想结果 -> 用结果本身证明价值 |

## 类型策略库

产品广告先判类型，再发散创意。不同类型的观看动机、产品出现时机、证明方式、镜头密度、文字策略和画幅都不同，不能共用同一套脚本模板。用户只说“做产品广告”“电商带货”“商品视频”时，先按下表选择主类型；若一条用户指令同时命中多类，只选一个主类型，另一个作为辅助段落，不要把五类硬塞进一条短片。

| 主类型 | 子场景 | 默认比例 | 核心任务 | 不适合 |
|---|---|---|---|---|
| 商品展示型 | 电商主图视频、产品功能演示、产品细节特写、360 展示 | 默认 `9:16`；商品卡/主图可 `1:1`、`3:4` | 让观众快速看清“是什么、长什么样、怎么用、关键细节在哪” | 复杂故事、过多人物戏、抽象品牌理念 |
| 场景种草型 | 场景化种草、家居/生活场景植入、模特试穿试用、使用前后对比 | 默认 `9:16`；小红书可 `3:4` | 让观众想象“我也需要这个生活状态” | 纯参数堆叠、硬促销、无场景的摆拍 |
| 体验测评型 | 产品测评、开箱展示、试用体验、食品制作过程展示 | 默认 `9:16`；深度测评可 `16:9` | 建立可信体验、真实过程和结果判断 | 夸张功效、无过程的结论、假用户评价 |
| 教程演示型 | 产品使用教程、功能操作演示、多产品合集展示 | 真人演示默认 `9:16`；横版教程可 `16:9` | 让观众学会步骤或看懂功能机制 | 情绪空镜、步骤跳跃、同时塞太多动作 |
| 促销转化型 | 限时促销视频、直播切片商品展示、爆品合集推荐 | 默认 `9:16`；商品承接可 `1:1` | 快速解释利益、优惠和行动路径 | 未确认价格/库存/稀缺、长铺垫、高概念慢片 |

类型判定规则：

- 商品展示型看“物”：产品形态、结构、细节和基础功能是主角。
- 场景种草型看“人和生活”：产品改变空间、穿搭、氛围或日常状态。
- 体验测评型看“过程和判断”：开箱、试用、反应、对比和主观体验组成可信链。
- 教程演示型看“步骤和可复制”：观众看完知道第 1 步、第 2 步、第 3 步怎么做。
- 促销转化型看“现在为什么要行动”：优惠、节点、直播间、组合套装或爆品理由必须成立。

### 商品展示型策略

商品展示型适合电商主图、商品卡、详情页、搜索承接和新品基础介绍。产品要早出现、清楚出现、反复出现；创意不是把产品藏起来，而是用设计让产品更好看、更可信、更可购买。

可选创意路线：

| 路线 | 结构 | 设计重点 |
|---|---|---|
| 英雄亮相 | 材质钩子 -> 产品完整揭示 -> 细节巡航 -> 功能动作 -> packshot | 适合新品、单品主推；灯光、台面和背景服务产品形态 |
| 细节微距 | 局部纹理 -> 结构/工艺 -> 手部触碰 -> 整体回收 | 适合美妆、香氛、硬件、服饰配件；微距必须说清拍哪个细节 |
| 360 展示 | 正面 -> 侧面 -> 背面/接口 -> 顶部/底部 -> 正面定版 | 适合外观差异明显的商品；运镜稳定，避免产品漂移变形 |
| 功能动作 | 产品静态 -> 单一操作 -> 反馈变化 -> 结果状态 | 适合小家电、工具、3C、收纳；每个镜头只证明一个功能 |
| 家族阵列 | 主推 SKU -> 多色/多规格排布 -> 差异特写 -> 主推回收 | 适合多 SKU；不能让模型随机生成不存在的颜色和型号 |
| 发布会质感 | 黑/白/品牌色空间 -> 产品升起/旋转 -> 参数锚点 -> 极简尾帧 | 适合科技、硬件、设计感产品；参数必须来自用户确认 |

镜头原则：

- 前 1-2 秒至少出现产品局部、轮廓、包装或使用状态之一。
- 产品占画面视觉中心；若平台是商品卡或详情页，产品可占 50%-80% 视觉面积。
- 背景要帮产品分离，不做过度复杂场景；反光、阴影和道具不能遮挡 logo/标签。
- 文字只保留产品名、核心卖点、规格或 CTA；长参数表和包装小字优先后期叠加。

### 场景种草型策略

场景种草型卖的是“产品带来的生活状态”。它不是单纯摆拍，要让产品进入真实动线：被拿起、穿上、放入空间、改变结果、被人物自然使用。

可选创意路线：

| 路线 | 结构 | 设计重点 |
|---|---|---|
| 理想一天 | 生活片段开场 -> 产品自然出现 -> 使用动作 -> 状态变松弛/体面/高效 -> 产品尾帧 | 适合家居、个护、服饰、香氛、咖啡器具 |
| 痛点到改造 | 旧状态混乱/不便 -> 产品介入 -> 空间或人物状态变化 -> 前后对照 | 适合收纳、清洁、效率工具、小家电 |
| 模特试穿/试用 | 人物出场 -> 产品上身/上手 -> 走动/转身/近景细节 -> 场景适配 | 适合服饰、鞋包、配饰、美妆；避免身材和效果夸大 |
| 情绪氛围 | 场景光线/声音先行 -> 产品成为氛围源 -> 人物反应 -> 生活主张 | 适合香氛、灯具、饮品、家居软装 |
| 社交场景 | 聚会/通勤/办公室/旅行 -> 产品解决一个小需求 -> 他人反应或关系变化 | 适合礼赠、食品饮品、便携产品 |
| 意象种草 | 现实场景 -> 产品触发视觉隐喻 -> 回到真实使用 | 适合高审美路线；隐喻必须回收为真实产品动作 |

镜头原则：

- 场景不能抢走产品；每 2-3 镜给一次产品锚点。
- 人物和产品必须有物理关系：拿、穿、用、放、开、闻、喝、整理、分享。
- 前后对比要同场景、同角度或同任务，避免“换了房子/换了人”造成虚假证明。
- 小红书/种草语气偏具体生活经验，少写硬广口号；可用“这个瞬间”“这个角落”“通勤前 5 分钟”等场景词。

### 体验测评型策略

体验测评型的核心是可信，不是结论先飞出去。必须呈现“看到产品 -> 做了什么 -> 观察到什么 -> 给出判断”的过程。没有真实资料时，只能写体验型感受和可见现象，不能编造亲测时长、评分、销量、医生/达人背书。

可选创意路线：

| 路线 | 结构 | 设计重点 |
|---|---|---|
| 开箱初印象 | 包裹/包装 -> 开箱 -> 配件/质感 -> 第一次使用 -> 初步判断 | 适合新品、礼盒、3C、服饰配件 |
| 三点测评 | 第一观察点 -> 第二观察点 -> 第三观察点 -> 适合谁/不适合谁 | 适合理性种草；每点都要有画面证据 |
| 食品制作过程 | 原料/包装 -> 开封/烹饪/冲泡 -> 质地/声音 -> 入口反应 -> 产品定版 | 适合食品饮品；食欲靠微距、蒸汽、气泡和拟音 |
| 真使用挑战 | 设定一个真实任务 -> 产品完成任务 -> 展示过程阻力和结果 | 适合清洁、工具、运动、户外产品 |
| 对比体验 | 旧方法或普通状态 -> 产品方法 -> 差异观察 -> 谨慎结论 | 不能贬损竞品，不能做未核实性能比较 |
| 长测预告 | 今日开箱 -> 关键体验点 -> 后续观察计划 -> 引导关注/详情页 | 适合不能立刻证明长期结果的产品 |

镜头原则：

- 让观众看见手、产品、包装、质地、结果，不要只有人脸结论。
- 测评语气保留犹豫、观察和限制条件，比“全网第一”“闭眼入”更可信。
- 数字、时长、评分、排名、成分含量、优惠和认证必须来自用户资料或可核实来源。
- 深度测评可用 16:9，但短视频版仍要把第一观察点放在前 3 秒。

### 教程演示型策略

教程演示型必须让步骤清楚。它的创意来自“步骤设计、视角设计和反馈设计”，不是把操作说得更玄。复杂操作要拆镜头，高风险细节要给特写。

可选创意路线：

| 路线 | 结构 | 设计重点 |
|---|---|---|
| 三步教程 | 目标结果 -> Step 1 -> Step 2 -> Step 3 -> 完成状态 | 最通用；每步一个动作和一个反馈 |
| 错误示范纠正 | 常见错误 -> 为什么失败 -> 正确操作 -> 结果 | 适合工具、软件、厨房、美妆、清洁 |
| POV 操作 | 第一人称任务 -> 手部/屏幕操作 -> 产品反馈 -> 完成 | 适合 App、SaaS、3C、小工具 |
| 多功能连招 | 功能 A -> 功能 B -> 功能 C -> 组合结果 | 适合多功能产品；避免一镜塞太多 |
| 多产品合集 | 场景需求 -> 产品 1/2/3 分别解决 -> 最终组合 | 适合套装、收纳、厨房、美妆；主推产品必须最清楚 |
| 专家/店员演示 | 专业人物给任务 -> 标准动作 -> 注意事项 -> 结果 | 适合需要信任的品类；专业身份不能伪造 |

镜头原则：

- 每个步骤写清手怎么动、产品哪里变、观众怎么判断成功。
- UI、按钮、参数和说明文字优先用真实截图或后期叠加，避免生成假界面和乱码。
- 横版教程可用于桌面、厨房、软件屏幕或长流程；竖版教程要把手、产品和关键文字放在安全区。
- 结尾可以给“保存/收藏/照着做”的 CTA，但不要和购买 CTA 同时抢信息。

### 促销转化型策略

促销转化型目标是行动，不是完整讲品牌故事。它要快速回答：现在有什么、为什么划算、为什么可信、怎么行动。所有促销事实必须由用户提供或确认；没有事实时，只能用“新品推荐、组合展示、活动氛围”替代具体优惠。

可选创意路线：

| 路线 | 结构 | 设计重点 |
|---|---|---|
| 限时促销 | 优惠钩子 -> 产品清楚出现 -> 核心利益 -> 活动规则 -> CTA | 价格、日期、折扣、赠品必须确认 |
| 直播切片 | 主播/手部动作 -> 产品展示 -> 卖点快证 -> 口播 CTA -> 商品卡承接 | 适合强转化；节奏快但产品不能糊 |
| 爆品合集 | 主题钩子 -> 产品 1/2/3 快速亮相 -> 主推产品停留 -> CTA | 不能编造“爆品/热销/销量” |
| 套装组合 | 使用场景 -> 套装逐个出现 -> 组合价值 -> packshot | 适合礼盒、美妆、食品、家清 |
| 节点礼赠 | 节日/人群/场合 -> 产品礼赠理由 -> 包装/祝福 -> CTA | 文案短，画面保留礼盒和品牌 |
| 库存/上新提醒 | 新品/补货钩子 -> 重点 SKU -> 适合谁 -> 立即行动 | 稀缺、库存、售罄必须用户确认 |

镜头原则：

- 前 1 秒给“产品或利益”，不要用慢 logo 和长空镜。
- CTA 只保留一个主动作：进店、领券、下单、预约、直播间、了解更多。
- 商品承接版可做 `1:1`，但主产品和核心文字必须适配裁切。
- 强促销也要完成最小证明：至少一个使用动作、材质/规格特写或结果状态，避免只有大字叫卖。

### 类型混合规则

混合不是叠加，而是主次组合：

| 主类型 | 可辅助 | 组合方式 |
|---|---|---|
| 商品展示型 | 功能演示/促销 | 先看清产品，再给一个功能证明或价格 CTA |
| 场景种草型 | 商品展示/体验 | 先建立生活状态，再用产品特写和使用动作证明 |
| 体验测评型 | 教程/促销 | 先做真实过程，再给适合人群或行动建议 |
| 教程演示型 | 商品展示/合集 | 步骤为主，产品信息只作为步骤中的证据 |
| 促销转化型 | 商品展示/测评 | 行动为主，证明只保留最短可信闭环 |

当用户要求多条广告时，优先按类型生成差异，而不是只换文案：一条商品展示、一条场景种草、一条测评体验、一条教程演示、一条促销转化，分别承担不同投放位置和用户意图。

## 主动发散与产品结果

用户只给产品信息、商品链接、卖点表、产品图或一句需求时，默认主动发散，不追问参考广告。先锁产品真相，再把主卖点翻译成一个“产品造成的可见结果”，最后选择一个主创意系统/主玩法。

发散前先锁底盘信息：

```text
产品真相：产品是什么，外观/结构/包装/UI 哪些不能变，哪些卖点已确认
产品结果：主卖点造成什么异常结果，触发动作是什么，最后如何回到真实证明
用户情境：谁在什么时候需要它，当前不便、渴望或决策阻力是什么
受众洞察：观众在乎爽感、安心、效率、身份、陪伴、仪式、好奇、信任还是价格利益
证明任务：本条片必须让观众看见什么，才会相信主卖点
平台语境：在哪里看，是否静音，前 3 秒是否必须停滑，是否需要强 CTA
节奏与声音：快慢、重拍、停顿、拟音、BGM、静默和声音桥如何参与推进
镜头与美术：机位、景别、运镜、构图、光线、色彩、材质、道具和产品陈列如何统一
品牌/产品记忆：观众最后记住哪个颜色、轮廓、包装、logo、声音、动作或符号
风险边界：功效、价格、销量、折扣、认证、客户评价、临床结果和竞品比较是否有来源
```

产品广告的创意可以发散，产品不能发散。没有产品图片时可以先规划概念，但涉及真实外观的生成必须请求产品图、官网链接或明确授权资料；不能只凭品牌名生成“看起来像”的商品。

### 产品事实锁

真实产品出现时必须锁住以下事实，但不另填一张卡；把相关内容合并到导演总控卡的“事实与素材”以及分镜风险项。

| 项目 | 写法 |
|---|---|
| 产品身份 | 品牌名、产品名、SKU、颜色、规格、包装版本 |
| 外观锚点 | 轮廓、比例、材质、颜色、透明度、反光、纹理、按钮/接口/瓶盖/结构 |
| 文字锚点 | logo 位置、标签布局、口味/型号/规格；细小文字优先作为后期可编辑文字 |
| 使用机制 | 打开、倒入、喷洒、佩戴、点击、连接、启动、清洁、收纳等真实动作 |
| 已确认卖点 | 用户提供或素材可见的卖点；数字和声明必须保留来源 |
| 不改内容 | 不换色、不换包装、不新增 logo、不虚构 UI、不生成未确认功效 |
| 可创作内容 | 场景、光线、道具、人物关系、镜头、声音、节奏、转场和视觉母题 |

### 按需产品结果转译

只有卖点仍然抽象、无法直接拍成动作或结果时，才做产品结果转译。可直接用真实操作、前后状态、结构或 UI 证明的产品不另填此卡。需要转译时只回答：

```text
卖点与用户问题：
触发动作：
可见变化与反馈：
真实证明：
结尾回收与风险：
```

使用规则：

- 异常结果是卖点的视觉翻译，不是玄幻装饰。保湿不是拍水滴，而是干燥纹理被水光路径填平；酥脆不是拍零食旋转，而是咬下引发的连锁反应，可以是声波让空间按节拍响应、碎屑重组、断面结晶生长或咀嚼卡点，任选一条，不默认声波；续航不是写续航长，而是时间流逝时设备仍保持工作状态。
- 异常结果必须由真实产品动作触发，例如开袋、咬下、按压、喷洒、涂抹、启动、连接、放入、擦拭、吸入、拖拽或点击。
- 异常结果必须回到证明锚点：质地、声音、断面、肤感、界面反馈、前后状态、人物选择、场景秩序、包装/logo 或真实使用结果。
- 夸张可以作为隐喻，但不能写成未经证实的功效、医疗结论、安全保证、销量背书、价格优势、竞品比较或长期效果。
- 下表每行的“异常结果”是并列示例方向，不是唯一答案。同一卖点要结合本条产品、品牌资产和平台在多条方向间挑选或重组，不要每次都取第一条；若某卖点反复只出同一种画面（例如酥脆永远是咬下声波涟漪），即为套模板，必须换方向或换触发/扩散/回收方式。

常见卖点转译：

| 卖点/价值 | 异常结果 | 证明回收 |
|---|---|---|
| 酥脆/爆汁 | 任选一条：咬下声波让桌面、灯光、碎屑按节拍响应；碎屑弹起重组成造型或符号；断面沿裂纹结晶/拉丝/爆汁生长；咀嚼节拍驱动剪辑切换；咬合一刻环境短暂转成同款酥脆材质 | 断面、碎屑、咀嚼声、包装 |
| 清爽/补水 | 开盖气泡或饮用动作切开热浪，凝出水珠和冷雾路径 | 倒入、冰块、入口反应、罐体/瓶身 |
| 保湿/肤感 | 涂抹处的干燥纹理被透明光膜覆盖，反光变柔和 | 手背/上脸质地、自然光泽、瓶身 |
| 香气/记忆 | 喷雾颜色轨迹把日常空间短暂打开成记忆场景 | 喷洒动作、瓶身、人物靠近后的情绪 |
| 清洁/收纳 | 污渍退潮、灰尘撤离、杂物沿轨道归位 | 同机位前后状态、产品工作口/结构 |
| 速度/效率 | 点击后等待时间被折叠，任务卡片归队 | 真实 UI、完成状态、通知或导出结果 |
| 宠物吸引 | 包装声或食材气味形成可见路径，引导宠物靠近 | 嗅闻、食用/玩耍、主宠互动和包装 |

需要结果转译时，转译成立后再选择创意机制；不需要超现实转译时，直接以真实动作和结果进入分镜。机制可以跨品类使用，但必须改写触发动作、体验外化、场景反应和证明回收。

### 六层发散法

无参考视频时，用“策略层 -> 证明层 -> 叙事调性层 -> 视觉效果层 -> 品类/场景语义适配层 -> 表达层”发散。叙事结构和视觉效果先作为通用机制自由选择，再根据当前产品翻译；不要按品类把机制预先锁死。

| 层级 | 可选变量 | 选择规则 |
|---|---|---|
| 策略层 | 停滑转化、功能证明、感官沉浸、生活方式、教程、开箱、对比、产品 launch、节庆礼赠 | 先匹配传播目标和平台 |
| 证明层 | 产品异常结果、问题前置、结果先给、真实操作、before/after、材质微距、结构分解、人物反应、场景变化、声音证明 | 必须证明主卖点；先把卖点翻译成结果，再决定拍产品本体 |
| 叙事调性层 | 异常入侵、连锁反应、规则揭示、平行碰撞、倒计时升级、循环破局、默片反差、谜题揭示、尺度反转、语义变形、材质隐喻、空间门户、数据实体化、动作可视化、文字成为画面 | 为每个主机制候选选择一种主叙事结构；辅助透镜只按具体职责选 1-3 个 |
| 视觉效果层 | 悬浮、FPV、微缩变实体、强迫透视、折叠空间、时间冻结、快闪、停格、延时、形状蒙版、2.5D、实景动画、双重曝光、Morphing、粒子聚合、匹配转场、色彩蔓延、投影映射 | 只为三个主机制候选补充对应效果，不另起一轮 3-5 个候选 |
| 品类/场景语义适配层 | 触发动作、感官外化、结构转译、包装/瓶口/屏幕入口、品牌色/声音/轮廓资产、使用结果、风险边界 | 把通用机制翻译成当前产品自己的画面事件 |
| 表达层 | UGC 原生、干净电商、TVC 质感、ASMR、桌面开箱、第一人称 POV、专家演示、超现实隐喻、快剪卡点 | 必须可执行、可剪辑、符合产品气质 |

每个候选方向都要能填完整机制适配器：

```text
通用机制：
当前产品的语义入口：
产品造成的异常结果：
触发动作：
体验外化：
场景响应：
证明锚点：
动态路线：
产品/品牌回收：
为什么不是普通展示：
```

如果无法填写“证明锚点”或“动态路线”，说明只是视觉装饰，不进入最终分镜。候选机制还必须填写“用户指令匹配点”和“卖点融合方式”：前者说明它响应了用户的哪句话、哪张素材、哪个产品事实或哪个平台目标；后者说明产品卖点如何进入画面因果，而不是先播一个创意片段、再用旁白补一句卖点。缺少这两项时，不管画面多新奇都不选。

候选整合规则：

- 三个候选只用于比较和取舍，不默认全部入片。
- 最终方案只保留一个主创意系统；其它候选中只有与主机制共享触发、视觉语言或回收路径的内容可以被吸收，最终按实际需要保留 `1-3` 个辅助机制，并逐个限定为开场钩子、转场、文案、证明补强、情绪、记忆或收束中的单一职责。
- 被吸收的局部必须服从主机制的触发、材质、节奏和回收方式，不能让观众感觉突然换了一支片。
- 每个创意节点都要影响下一个节点：留下形状、声音、文字、材质、动作方向、人物反应、产品状态或场景结果。没有后续影响的节点必须删除或降级为小反馈。

内部发散时，从下面变量各选一个主项即可，不要全堆：

| 变量 | 候选 |
|---|---|
| 主钩子 | 痛点瞬间、结果先给、反常画面、声音先行、手部动作、产品局部、人物表情、倒计时、开箱悬念、场景反差 |
| 主体视角 | 产品自己、使用者、手部、宠物/孩子/家人、专家/店员、第一人称 POV、桌面俯拍、场景空间、UI 屏幕 |
| 证明动作 | 打开、倒入、喷洒、擦拭、佩戴、点按、折叠、连接、装入、对比、复位、重复使用、环境变化 |
| 视觉母题 | 水滴、光束、风、磁吸、轨迹线、镜面、果切、布料、烟雾、颗粒、城市线条、桌面秩序 |
| 结尾收束 | packshot、使用后状态、人物反应、before/after 同机位、产品阵列、品牌尾帧、单一 CTA |

AI 工具、创作工具、效率软件和 SaaS 可使用“工作流危机 -> 产品/工具介入 -> 理想结果 -> 界面/成果回收”的元广告结构。前半段用秩序混乱、手持、冷灰、杂乱和焦虑声音表现问题；后半段用稳定构图、清晰界面、干净声音和完整结果证明价值。

同一产品要按观众认知状态改变钩子：未意识到问题时先放大生活小麻烦；知道问题但不知道方案时让产品介入；知道方案但未选择品牌时证明独特机制；知道产品但未购买时解除顾虑或给行动理由；已熟悉或复购时强调新场景、新组合或节点提醒。

### 创意探索方向格式

只有用户明确要求头脑风暴、多方向、A/B 创意、多个版本或暂不生成时，才向用户展示多个方向。用户要求生成视频、制作广告或下一步可能提交生成时，用户可见输出必须直接给一个完整方案，并回到主 `SKILL.md` 的视频生成参数确认。

```text
方向 A：一句话概念
适合平台/比例/时长：
主钩子：
产品登场方式：
主卖点证明：
画面风格与声音：
风险与所需素材：

方向 B：...
```

即使用户要求直接生成，也必须先按主 SKILL 做参数确认；确认文案不必长篇解释全部策略，但最终分镜必须体现所选方向、产品真相卡和证明动作。

## 平台策略映射

平台不是发布参数，而是创意策略。无参考视频时，先按平台选择默认节奏：

| 平台/场景 | 默认策略 | 关键规则 |
|---|---|---|
| 抖音/TikTok/Reels/Shorts | Hook -> Body -> Close，竖屏原生、动作先行 | 前 1-3秒给产品、问题、结果、反差或声音；主体放安全区；静音播放也要看懂 |
| 电商搜索/商品详情页 | 产品功能视频，产品和证明优先 | 产品尽早出现且占比高；展示真实使用、功能、细节和结果；少讲品牌故事 |
| YouTube/贴片广告 | Attention/Branding/Connection/Direction | 早建立品牌或产品归属；中段让观众感到或理解；结尾给明确行动 |
| 小红书/种草内容 | 真实体验、场景价值、审美记忆 | 少广告腔；用生活情境、细节、步骤和结果建立可信感 |
| 官网/发布会/大屏 | 产品 launch、质感、品牌记忆 | 可以更电影化，但前段仍要埋入产品轮廓、材质、UI、声音或品牌色 |
| 直播间/促销切片 | 快速转化、优惠和产品高频露出 | 促销事实必须确认；CTA 清楚，不编造稀缺和价格 |

平台通用规则：

- 第一眼要有价值承诺：问题、结果、产品、人物反应、感官动作或视觉事件至少一个成立。
- 黄金三秒要快给承诺：0-1 秒用痛点、结果、声音、手部动作、产品局部、UI 状态或人物反应停滑；1-2 秒让产品/服务线索进入；2-3 秒给第一个可见反馈或继续看的问题。高端产品可以慢，但不能空，必须有材质、产品轮廓、品牌色、使用动作或感官声音。
- 品牌和产品不要只在最后出现；转化广告尤其要早锚定产品。
- 静音播放也能理解核心信息；开声时让拟音、口播或音乐增强记忆。
- 画面文字只做锚点，不替代证明动作；画面能证明的内容不要全靠大字说明。

## 演示、B-roll 和图形系统

产品广告中的辅助画面必须承担证明或情绪职责。B-roll 优先拍真实使用、手部操作、材质微距、结果状态、生活场景、屏幕流程或人物反应；它可以覆盖旁白或口播，但不能替代产品证明本身。每条片至少有一个“黄金证明动作”，让观众看见产品如何造成变化。

图形和 MG 只在能帮助理解、比较或记忆时使用。对比板用于前后状态或竞品替代，进度条用于效率和步骤，卡片用于卖点锚点，图标用于品类或功能识别。动效必须表示到达、替换、积累、比较、揭示或完成，不做纯装饰飞入。

产品动效要先把功能映射到运动语法：输入、点击、筛选、生成、导出、锁定、连接、同步、装入、打开、归位、完成，分别对应不同动作，不要所有卖点都写成卡片飞入。一个镜头只展示一个主要产品动作；同一种高存在感动效如堆叠、翻页、粒子聚合、发牌式飞入、扫光等，一条片里不要反复当主角。

产品动效在 PE 里必须绑定产品核心和时间段。不要写“产品周围出现科技动画”；要写成“几秒、哪个操作触发、哪个 UI/产品部件/卡片/材料发生什么变化、这个变化证明什么卖点、最后停在哪个产品状态”。如果动效不能证明主卖点、解释功能、制造感官记忆或引导 CTA，就删掉。

SaaS、App、桌面产品和平台类广告尤其要保护真实页面：真实 UI 优先，产品模块可以裁切、放大、2.5D、错峰入场或与实景叠合，但落点必须是输入框、列表行、看板列、数据卡、通知区、结果面板、导出按钮等真实或可解释槽位。不要用随机假 dashboard、乱码微文案、占位骨架、过密整页后台或每帧同款居中玻璃卡冒充产品能力。

批量产品模块入场要有节奏和物理隐喻，例如任务卡像发牌归位、数据行按筛选结果嵌入列表、通知沿真实队列堆叠、对比项替换旧方案、进度条随步骤完成。满板、归位、锁定、导出或确认之后要给短暂停留，让观众看清“完成了什么”。

## 产品广告 PE 编译

不再填写独立 PE 策略卡。直接从唯一导演总控卡和完整分镜编译，保留六项：产品事实、核心证明、动作链、镜间承接、声音/文字同步、结尾回收与禁区。其它策略名、候选过程和重复字段不进入 PE。

视频 PE 编译前读取 `references/asset-generation.md`，统一执行其中的固定格式；在单个镜头或时间段内按“产品真相 -> 当前镜头职责 -> 具体动作 -> 证明结果 -> 镜头/光线/声音 -> 保持与禁止”压缩。不要只写“高级感、震撼、转化强”；必须写清高级感来自什么材质、什么光、什么镜头和什么动作。

成功标准要可检查，例如：

- 产品外形、颜色、包装和 logo 位置稳定。
- 前 3秒能看懂产品或问题。
- 前 3秒已有价值承诺，不是只有慢镜、空镜、抽象光效或无信息铺垫。
- 主卖点有可见动作证明，不只靠旁白。
- 每个动效都写在具体秒段里，并有触发、路径、状态变化和落点。
- 每次切镜都有叙事理由和至少一个承接锚点；硬切写清职责，不作为默认切法。
- 手部、人物、产品状态、动作方向和空间轴线连续；人物或场景切换有明确动机。
- 景别和镜长形成建立、靠近、证明、回看、收束的主次变化，不机械等长，不连续堆无关特写。
- 画面文字与对应动作/结果同步，能被下一镜继承或自然退场，不突然弹出。
- 每 2-3 个镜头回到产品锚点。
- 尾帧产品、品牌或 CTA 稳定停留。
- 没有乱码、假 logo、额外产品、错误 UI、夸大声明和无来源数字。

## 短转化结构

食品、饮品、宠物零食、快消和短信息流广告优先使用 AIDA 转化链路，但要写成画面，不要只写营销术语：

```text
注意 Attention：人设、反应、强声音、夸张道具或结果前置
兴趣 Interest：主体表情、卡通花字、口味/原料悬念、产品局部
欲望 Desire：原料、质地、结构、口感、使用动作和结果状态
行动 Action：核心卖点承诺、产品包装、品牌尾帧或 CTA
```

宠物食品可用：

```text
拟人化宠物人设 -> 情绪语音/花字 -> 原料或口味展示 -> 产品特写 -> 核心安全卖点 -> 使用场景 -> 品牌 Logo
```

人设要服务产品，不只是好玩。墨镜、链条、沙滩椅、玩具、餐具、训练道具、沙发、背包等都属于道具资产，必须在基础资产或分镜里锁定职责。宠物表情和产品动作要形成递进：高冷/挑剔 -> 被吸引 -> 认可/享用 -> 包装记忆。

## 产品登场策略

产品广告通常比 TVC 更早让产品成为主体，但“早出现”不等于第一帧静态摆拍。根据目标选择登场节奏：

| 目标 | 开场 | 产品登场 | 重点 |
|---|---|---|---|
| 转化信息流 | 痛点、结果、声音或动作强停滑 | 前 1-3秒清楚出现 | 快速建立“这是什么、解决什么” |
| 商品主图/详情页 | 产品局部、材质或使用状态 | 前段完整出现 | 产品准确、包装清楚、卖点可见 |
| 高端质感 | 材质、光线、手部、空间或声音先行 | 中前段延迟揭示 | 价格感和仪式感先于说明 |
| 教程演示 | 任务目标或旧方法问题 | 产品随步骤进入 | 每步一个动作，结果可检查 |
| SaaS/App launch | 真实任务、用户状态或结果面板 | UI/产品流程尽早成为主角 | 不造假界面，用真实截图或确认 UI |

高端产品可以先拍产品气质：材质反光、开盖声、手部靠近、空间陈列、使用前的理想生活状态；但产品不能缺席到最后。转化型广告必须更早给产品锚点，避免观众只记住氛围或痛点。

产品广告开头不能用静态产品摆拍、固定机位或慢推空镜吃掉黄金三秒。0-3 秒至少完成三个信息事件并发生一次有意义切镜/观看关系变化：`0-0.7 秒异常结果、强动作或声音停滑`、`0.7-1.6 秒产品/人物主动进入并建立身份`、`1.6-3 秒第一个证明反馈或未完成悬念`。高端路线可以克制，但也必须靠材质动作、遮挡揭示、结构变化、声音触发或构图反转制造推进，不能只靠光线移动和缓慢展示。

开头如果用 packshot，必须让 packshot 发生动作：包装被放下、瓶盖打开、屏幕亮起、标签被手指指向、光线扫过真实 logo、口味卡片从包装边缘弹出、产品从使用场景里落定。开头 packshot 不等于结尾 packshot；开头负责提出问题或诱因，结尾才负责稳定记忆和 CTA。

## 通用视觉策略

产品广告的创意要把卖点变成“看得见的动作或状态”。默认先选 1 个主创意玩法机制，再选 1-2 个辅助视觉策略；不要先写卖点列表再随手加特效，也不要把所有特效和转场塞进同一条视频。

产品广告必须有玩法判断。玩法不影响介绍产品，前提是玩法承担了产品真相、功能证明、使用情绪、品牌记忆或购买理由。没有玩法的广告也可以成立，但必须说明为什么当前品类更适合朴素证明；否则默认至少选择一个主机制，并把它写进 0-3 秒、证明段和结尾回收。

### 产品广告玩法机制库

先定世界规则，再选一个主机制，最后写进 0-3 秒、证明段和结尾回收；辅助策略只负责补强，不改主叙事。

常见广告世界规则适配：

| 世界规则 | 产品广告用法 |
|---|---|
| 产品内藏世界 | 产品的瓶口、表盘、屏幕、耳罩、包装、杯口成为入口；内部世界承载场景、口感、香气、性能或生活方式，结尾必须退出回真实产品 |
| 风格化动画世界 | 乐高、黏土、像素、纸模、玩具沙盘等把卖点变成拼装、通关、修复、奖励或归位；必须保留产品身份锚点 |
| 时间规则 | 冻结、加速、倒流或 speed ramp 用来展示材质、结构、佩戴/使用瞬间和产品高光；不能只炫技 |
| 证明流程世界 | 清洁、收纳、工具、食品试喝、穿搭换装等按真实步骤证明：发现问题、产品介入、过程可见、结果对照、尾帧记忆 |
| 奢华陈列世界 | 高端产品用花材、织物、喷雾、粒子、光斑和机械轨道镜头建立价格感；每个运动都要克制、慢、有物理依据 |
| 口播第四面墙 | AI、工具、服务、幕后型广告可让角色承认生成、分身、偷懒、替身或工作流关系，用幽默解释效率价值 |

常见玩法机制：

| 玩法机制 | 适合 | 广告落地方式 |
|---|---|---|
| 巨物化产品 | 3C、日用、食品、汽车、发布感产品 | 产品变成城市、街头、房间或桌面的巨大物体，用车、人、桌椅、建筑、手部等尺度参照证明影响力、容量、存在感或沉浸感 |
| 产品入口穿梭 | 包装、瓶口、杯口、屏幕、卡片、车门、包袋 | 镜头从真实结构进入产品世界，中段看到卖点外化，结尾从同一结构回到真实产品 |
| 界面接管现实 | App、SaaS、AI 工具、3C、效率工具、潮流产品 | 下拉框、滑块、按钮、进度条、卡片、地图或任务面板进入真实场景，并改变物体、人物动作或结果状态 |
| 手势/道具控制世界 | 口播带货、教程、穿搭、工具、轻娱乐广告 | 手指、剪刀、鼠标、笔、遥控器、包装撕口或产品按键触发现实切换；每次操作都要带来产品相关结果 |
| 拼贴/纸艺/贴纸世界 | 年轻化品牌、教育、文创、轻食品、生活方式 | 人物、产品、建筑、文字、票据、包装像剪贴画分层移动；元素来自产品素材、场景证据或品牌资产 |
| 风格化动画世界 | 产品亮点需要故事化、任务化或年轻化表达 | 乐高、黏土、像素、纸模、玩具沙盘、漫画分格等把模块化、易用、收纳、口感层次翻译成拼装、通关、归位或奖励 |
| 文字空间化 | 品牌主张、地名、活动、产品名、核心卖点 | 大字成为建筑、地面、屏幕、海报层、光带、路标或包装透视面；字体、位置、材质、投影和遮挡关系必须写清 |
| 声音可视化 | 食品、饮品、香氛、3C、机械、开箱 | 开盖、咬下、点击、磁吸、喷雾、拉链、启动声变成波纹、裂纹、路线、反应字、灯带或空间震动 |
| 材质外化 | 美妆、食品、香氛、家居、服饰、科技 | 清爽变水膜，酥脆变裂纹，香气变色带，柔软变布料波，速度变拖影；材质必须来自真实卖点 |
| 混乱到秩序 | 收纳、清洁、SaaS、AI、效率工具、服务流程 | 开场呈现可理解的混乱，产品动作触发物体、数据、任务卡、房间或流程归位；前后状态可比 |
| 旧新争夺 | 替代型产品、工具、家居、SaaS、服务 | 旧方法和新产品在同一画面抢空间，产品动作让新状态占据画面 |
| 游戏化任务 | 教程、工具、App、食品、潮流消费 | 使用过程变成闯关、解锁、收集、评分、连击或任务完成；每关对应真实步骤或卖点 |
| 反向揭示 | 清洁、护肤、食品、效率、服务、悬念广告 | 开场先给异常结果或完成状态，中段沿痕迹倒推，结尾揭示产品是触发原因 |
| 视角置换 | 包装、屏幕、口袋、车内、杯中、产品内部 | 从产品内部、物体背后、屏幕里或包装夹层看世界，最后拉回真实产品结构 |
| 海报化空间折叠 | 城市、文旅、门店、品牌活动、高规格产品 | 真实空间逐层变成海报：色彩、倒影、前景剪影、大字、品牌标识依次入场，最终停成可读海报态 |
| 生活方式模拟 | 服饰、美妆、食品、家居、通勤用品 | 让产品进入通勤、居家、送礼、旅行、办公室等生活流程；重点是体验理由和真实细节 |
| 虚实融合 | 游戏、AI、AR、工具、教育、潮流产品 | 虚拟对象与真实环境相互影响，现实完成任务或出现反馈；虚拟层必须服务产品能力 |

玩法选择规则：

- 转化广告：优先声音可视化、混乱到秩序、旧新争夺、界面接管现实、游戏化任务、反向揭示。
- 种草广告：优先生活方式模拟、材质外化、拼贴/纸艺/贴纸世界、声音可视化、产品入口穿梭。
- 发布/TVC 感广告：优先巨物化产品、产品入口穿梭、海报化空间折叠、文字空间化、视角置换、虚实融合、风格化动画世界。
- SaaS/App/AI 工具：优先界面接管现实、游戏化任务、混乱到秩序、旧新争夺、虚实融合、反向揭示。
- 高风险品类：玩法可以用，但只表现体验、流程、材料、适合边界和概念状态，不伪装医学、金融、教育或安全结论。

进入 0-3 秒的最低要求：

```text
0-0.7 秒：异常、动作、声音、手势、结果或界面状态先起手
0.7-1.8 秒：产品/品类/人物/问题线索进入，观众知道广告在说什么
1.8-3 秒：主创意系统规则启动，出现第一个产品相关反馈或证明入口
```

前三秒不只要切镜，还要启动玩法规则。不能写成“产品特写 + 标题字 + 卖点字幕”；要写成“谁触发了什么，现实或图形系统如何变化，变化为什么和产品有关”。

逐时间段保持“产品信息 + 玩法反馈 + 场景变化”三者至少命中两项。不能连续写普通产品特写、普通使用动作或普通卖点旁白；每个节拍段都要让观众看到新变化，例如包装局部变成入口、手势把场景切开、声音推开图形、气泡/水纹/光线沿产品路径移动、UI 状态落到真实桌面、产品让旧状态退场、文字贴到真实结构上、人物反应反向揭示产品效果。趣味不是随机特效，而是产品造成的可见后果。

15 秒短片建议至少包含 `1 个异常起手 + 1 个产品身份锚点 + 2 个不同证明动作 + 1 个场景/情绪反馈 + 1 个玩法回收 + 1 个稳定 packshot`。延迟揭示、材质隐喻、动作重复、匹配剪辑、前景遮挡、声音先行、定格锚点都是辅助策略；它们必须落到具体秒段，不能替代主创意系统。

这六项必须组成因果链，而不是六种展示镜头。人物片至少讲清“谁遇到什么 -> 产品怎样介入 -> 人物做了什么 -> 环境或人物怎样改变 -> 品牌为什么被记住”；无人物片至少讲清“初始缺口 -> 产品触发 -> 系统/空间响应 -> 可见证明 -> 产品回收”。通用失败结构是“主体出现 -> 产品出现 -> 重复使用或重复特写 -> 尾帧”，以及在固定机位中只让主体做轻微反应、只靠换角度重复同一动作、只让视觉效果继续扩散却不产生新结果。改写时必须让每个节点改变一个实质变量：问题升级、产品介入、操作发生、场景或系统响应、人物/对象反馈、证明成立、品牌回收；相邻节点不能只增加运动量而不增加信息。

单一视觉奇观、尺度变化、环绕主体、重复产品特写和固定机位都不能单独充当玩法。任何异常或视觉机制都必须回答：为什么发生、由谁或什么触发、改变了哪个人物/场景/系统状态、产生了什么可见反馈、如何回到产品或品牌。环绕、推拉、旋转、放大、悬浮、粒子扩散等手法每继续一拍都必须揭示不同信息或进入新的叙事状态，否则只保留最有效的一小段。

执行规则：

- 快剪不是乱切。每 2-3 个快切后给 0.4-0.8 秒产品清晰画面；高端路线可以更慢，但不能只剩空镜。
- 手部、人物、宠物、空间和特效都服务产品。观众看完要能说出产品是什么、解决什么、为什么可信。
- 同一条片只保留一个主转场逻辑，例如同色、同形、动作接动作或声音先行；多种转场混用会稀释记忆点。
- 开场画面可以是痛点、结果、声音、材质或奇观，但前三秒内必须建立产品或品类线索。

## 产品一致性和证明链

有用户原始产品图时，它是最高优先级参考。生成图好看但产品不准也必须丢弃。

产品图必须锁定：

- 产品数量、外形结构、尺寸比例、颜色、材质、透明度、反光、纹理。
- logo/品牌标识位置、标签形状、主文字布局、SKU、口味/规格。
- 包装开合方式、瓶盖/泵头/盒身/接口/屏幕/配件。

涉及产品的镜头都要回到同一产品主体。不要换颜色、换包装、生成新 logo、新标签、假文字或多余产品。手部不能遮挡 logo、标签和关键卖点区域。

用户上传图片时先判断用途：

| 用途 | 判断 | 执行 |
|---|---|---|
| 只锁产品 | 白底图、商品图、详情页截图、普通产品照 | 只继承产品外观，场景重新设计 |
| 产品 + 场景 | 用户明确要求参考环境，或原图空间对调性重要 | 继承空间材质、光线、陈列关系 |
| 只参考风格 | 竞品广告、moodboard、非同款产品图 | 只抽象色调、光影、构图、节奏 |
| 不做视觉参考 | 聊天截图、表格、低质 UI、水印图 | 只提取文字信息 |

多宫格、详情页拼图或分镜图要按阅读顺序拆成多个镜头，不把整张图当作单一画面。竞品广告和 moodboard 只作为节奏、光影、构图和镜头组织参考。

每条广告至少完成一次证明闭环：

```text
产品出现 -> 人/手/环境交互 -> 可见证明 -> 结果状态 -> 产品记忆点
```

证明动作按品类选择：

- 食品饮品：开封、倒入、气泡、切开、咬开、入口反应、分享。
- 美妆护肤：取用、推开、吸收、上脸/上手、妆前/睡前场景。
- 3C/家电：按键、连接、响应、使用前后效率、场景结果。
- 服饰配饰：上身、走动、搭配、材质细节、佩戴舒适度。
- 家居日用：旧方案到新方案、清洁/收纳/整理结果、真实使用动线。
- SaaS/App：输入、点击、生成、导出、协作、通知和结果面板；真实 UI 优先，禁止乱码假界面。

食品、零食和饮品如果卖点包含“轻盈、快乐、适合分享、仪式感或治愈感”，可以采用“发现 -> 品尝 -> 共享”的递进结构：先用包装、原料或质地建立好奇；再用切开、咬下、拉丝、气泡、蒸汽、脆响或入口反应证明感官；最后让人数、餐桌、空间或产品阵列递增，完成分享和情绪扩散。这个结构要由产品动作推动，不只是拍一群人开心。

声明风险不得编造或夸大：医疗、功效、治疗、抗老、瘦身、金融收益、教育保证、销量第一、全网爆款、权威认证、临床数据、客户评价、达人推荐、限时优惠、价格、赠品、库存或直播活动。没有用户资料或公开核实时，用体验型、场景型或视觉证明替代确定声明。

## 品类证明动作库与玩法发散

品类策略不是把产品塞进固定模板，而是先找“这个品类什么动作才算证明”。每个品类都要先选一个最小证明动作，再从多个玩法方向中挑一个主创意系统/主玩法；其它方向只能作为相关节点、辅助镜头或舍弃。用户 brief 很短时，默认用本库完成发散和收束。

内部推导：

```text
品类
  -> 用户给的卖点/默认可见卖点
  -> 最小证明动作
  -> 3 个不同主机制候选，每个附带 1-3 个同源辅助机制
  -> 按用户匹配、核心证明、连续性和生成稳定性选择主机制
  -> 哪个反常识一拍能让它变得可复述

```

## 品类垂直策略

品类决定“什么才算证明”。同样是产品广告，食品靠质地、蒸汽、咀嚼声和入口反应；3C 靠接口、屏幕响应、连接状态和手部操作；SaaS 靠真实 UI、任务流和结果面板。规划时先判主品类，再把主卖点翻译成该品类可见证据。

本节只约束证明证据和风险边界，不限制叙事结构或视觉效果选择。强创意时仍按“通用机制 -> 品类/场景语义适配”处理。

| 品类 | 画面重点 | 证明动作 | 声音/文字 | 避免 |
|---|---|---|---|---|
| 食品饮品 | 包装、原料、质地、水/冰/气泡、蒸汽、入口反应 | 开封、倒入、切开、咬开、冲泡、分享 | 开盖、气泡、咀嚼、满足短语；文字只写口味/原料/卖点 | 把不可食用品拍成食品，虚构健康功效 |
| 美妆护肤 | 瓶身、质地、肌肤纹理、自然光泽、上脸/上手状态 | 取用、滴落、推开、吸收、上妆、卸除 | 滴管、涂抹、水声；少量成分/肤感词 | 医疗夸张、一秒变脸、塑料磨皮、虚构成分功效 |
| 香氛礼赠 | 瓶身、雾气、布料、礼盒、托举仪式、空间氛围 | 喷洒、开盒、摆放、靠近、赠送 | 喷雾、盒盖、布料声；文案诗性但短 | 花海空镜过多、产品缺席、气味拟人过度 |
| 3C 数码/硬件 | 屏幕、接口、按键、灯效、材质、桌搭、响应 | 连接、点按、切换、开合、佩戴、携带、充电 | 点击、磁吸、提示音、低频电子；参数需确认 | 假 UI、乱码参数、过度蓝光、凭空发明功能 |

| 服装配饰 | 上身效果、材质、廓形、五金、搭配和走动 | 试穿、佩戴、转身、近景触摸、开合扣件 | 布料摩擦、链条/拉链；文字写材质/场景 | 身材/尺码承诺夸大，模特抢走商品 |
| 宠物用品/食品 | 宠物反应、食用/玩耍动作、包装、主人互动 | 嗅闻、追逐、咀嚼、靠近、训练、清理 | 包装声、咀嚼声、轻快拟音；卖点需谨慎 | 编造兽医背书、健康功效、过度拟人 |
| 母婴/健康感产品 | 安心、温柔、清洁、家庭照护、手部操作 | 取用、擦拭、穿戴、喂养、整理、照护 | 柔和环境声、轻声旁白；声明需保守 | 焦虑营销、疾病恐吓、医疗/安全保证 |
| 汽车/出行 | 外观、车灯、内饰、空间、路况、驾驶体验 | 低角度跟拍、开门、坐入、车内主观、细节特写 | 引擎/电机、风声、胎噪；配置需确认 | 只有风景没有车，车标/车身变形，危险驾驶 |

| 教育/课程/内容产品 | 课程结果、学习过程、资料结构、讲师可信度 | 翻页、屏幕录制、练习、批改、前后作品 | 讲解清楚；CTA 为试听/报名/领取资料 | 保证提分/就业/收益，假学员评价 |

品类策略规则：

- 一条片只选一个主品类；跨品类礼盒或合集按主推 SKU 决定画面重心。
- 品类证明优先于抽象风格。食品没有质地和入口，护肤没有取用和肌肤，SaaS 没有真实 UI，汽车没有车身和驾驶关系，都不算合格。
- 食品饮品的情绪递进可以通过空间和人数推进：单人发现、近景品尝、两人交换、多人共享、桌面俯拍阵列或 packshot 收束。空间和人数递进必须服务产品“可分享/有仪式/口感快乐”的卖点，不能变成无关群像。
- 高风险品类如母婴、健康、护肤、金融、教育和宠物营养，默认使用“体验、场景、材料、使用方式”表达，不主动写确定疗效、保证结果或权威背书。

## 行业风险与可说/不可说

创意可以夸张，事实不能夸张。涉及功效、安全、健康、价格、销量、认证、客户、收益、教育结果和医疗相关内容时，先判断哪些可以视觉隐喻，哪些必须来自用户材料或可靠来源。

## 类型 x 品类矩阵

同一个品类在不同视频类型下应采用不同策略。生成多版本时，优先从矩阵里选不同组合，而不是只换文案和配色。

| 品类 | 商品展示型 | 场景种草型 | 体验测评型 | 教程演示型 | 促销转化型 |
|---|---|---|---|---|---|
| 食品饮品 | 包装 + 原料 + 质地微距 + packshot | 早餐/聚会/办公室场景，入口反应 | 制作过程、开封、口感观察 | 冲泡/烹饪/搭配步骤 | 口味合集、节日礼盒、限时活动 |
| 美妆护肤 | 瓶身 + 质地 + 上手光泽 | 晨间/通勤/约会前状态 | 半脸/手背试用、肤感描述 | 正确用量、手法、上妆步骤 | 套装、节点礼赠、新品组合 |
| 香氛礼赠 | 瓶身、喷雾、礼盒开合 | 空间氛围、送礼瞬间 | 留香感受只能定性，避免时长编造 | 喷洒位置、搭配场景 | 节日礼盒、限定包装、祝福尾帧 |
| 3C 数码 | 接口、屏幕、材质、结构分解 | 桌搭、通勤、游戏、办公效率 | 开箱、连接、响应、发热/便携观察 | 配对、设置、功能切换 | 新品发布、套装配件、预约/首发 |
| 家居日用 | 产品结构、容量、材质 | 房间改造、收纳前后、清洁结果 | 真实任务挑战、使用阻力和结果 | 安装、折叠、清洁、保养步骤 | 家庭套装、囤货、节点大促 |
| 小家电/厨具 | 机器外观、配件、食材变化 | 厨房日常、招待朋友、家庭早餐 | 做一道具体食物，看过程和结果 | 从准备到清洗的完整步骤 | 爆款厨房神器、组合购、直播演示 |
| 服装配饰 | 廓形、面料、五金、上身定版 | 穿搭场景、通勤/旅行/聚会 | 开箱、面料触摸、版型观察 | 多种搭配、佩戴/保养方法 | 多色合集、上新、节日穿搭 |
| 宠物用品 | 包装、颗粒/玩具/结构 | 主宠互动、日常训练、清洁轻松 | 宠物反应、嗅闻/玩耍/食用过程 | 喂食、清洁、训练步骤 | 多口味合集、囤货、节日宠物礼 |
| 母婴/健康感 | 材质、柔软度、开合、清洁细节 | 家庭照护、夜间/外出场景 | 使用便利和舒适观察，声明克制 | 正确穿戴、取用、清洁步骤 | 礼盒、囤货装、家庭场景 CTA |
| 汽车/出行 | 外观、车灯、内饰、细节 hero shot | 通勤、周末、户外、家庭出行 | 车内空间、细节体验、功能观察 | 功能设置、储物、座椅/屏幕操作 | 试驾预约、上市、金融政策需确认 |
| SaaS/App/AI | 真实界面、核心模块、结果面板 | 用户任务场景、团队协作、创作者工作流 | 任务前后、效率感受、功能边界 | 从输入到导出的一条完整路径 | 试用/预约演示、模板/课程包；免费权益必须来自用户材料 |
| 教育/课程 | 课程包、讲义、页面、作品示例 | 学习场景和阶段变化 | 试听体验、内容结构观察 | 一节课怎么学、作业怎么做 | 公开课、试听课、资料领取 |

15秒短广告可选结构：高端揭示型、证明转化型、感官沉浸型、教程演示型或模块快剪型。30秒以上长视频扩展成章节：需求背景、产品介绍、功能/卖点分层、真实场景、证明结果、购买/行动收束。每个片段只推进一个章节。

## 执行收口

产品广告最终落到一条镜头逻辑，而不是卖点列表：

```text
停滑/异常 -> 产品身份 -> 材质/结构/功能证明 -> 场景或人物反馈 -> packshot/CTA
```

转化型可把功能证明前置；高端大片可把材质和视觉母题前置；食品、饮品、宠物可把反应、声音和入口动作前置。每条片至少有一个“黄金证明动作”，让观众看见产品如何造成变化。

产品广告大片或 TVC 化产品广告要先确定一套视听方法，再写当前产品的镜头方案：

- 运镜：微距推镜用于材质、logo、质地和结构证据；环绕用于 360 展示和完整外观；固定机位用于电商干净感、前后对比和宠物/食品稳定证明；低角度用于汽车、户外、运动和力量感；手持微晃用于开箱、测评和真实使用感。
- 布光：侧逆光勾勒浮雕、瓶身、金属和轮廓；顶部柔光展示包装和桌面阵列；环形多光源展示金属/磨砂/透明材质；正面柔光展示食品、饮品、人物亲和力和肤感。
- 构图：中心对称做 packshot 和发布感；45 度角展示产品体积和厚度；爆炸图分层展示结构；POV/画框构图展示佩戴、使用和界面关系；俯拍阵列制造“多、丰盈、合集、礼盒”。
- 色彩：纯白背景适合电商、3C 和干净食品；黑底适合科技和高级质感；红金适合节庆和礼赠；粉黄适合甜感饮品和少女向产品；绿/金/蓝适合自然、科技或清洁隐喻。色彩必须服务产品识别，不能把包装色吃掉。
- 转场：优先用动作接力、遮挡揭示、同物/同形匹配、视线方向和声音桥连接原料、产品、使用和结果；硬切只用于有共享锚点的冲击对比、结果揭示、节拍重击或章节断点；闪白和黑场也必须承担明确的冲击或分段职责；粒子和光斑只在能解释功能、材质或情绪时使用。
- 声音：产品功能要音效化，例如密封=水滴或扣合声，磁吸=咔嗒声，降噪=噪音切断，开瓶=开盖气声，食欲=咀嚼/碎裂/倒入，效率=点击/完成提示。

视听方法按证明任务选择：

| 任务 | 镜头和美术 | 声音和文字 |
|---|---|---|
| 材质/质地 | 微距推镜、侧逆光、浅景深、手部触碰 | 轻拟音、短关键词或质感花字 |
| 结构/设计 | 360 环绕、开合闭环、爆炸图分层、中心对称 packshot | 咔嗒、磁吸、低频点题、少量参数锚点 |
| 功能/效率 | 固定机位对比、POV 操作、UI 状态、前后同机位 | 操作音、完成提示、短 CTA |
| 感官/食欲 | 入口、断面、气泡、水珠、碎屑、人物反应 | 开盖、倒入、咀嚼、满足短语、拟声字 |
| 高端/发布 | 黑白或品牌色空间、克制环绕、局部延迟揭示 | 低频氛围、少字主张、尾帧稳定 |

画面文字、花字和图形层只承担钩子、卖点锚点、情绪反应、声音外化、促销信息或尾帧 CTA；不是逐句字幕。15 秒内通常 1-3 次，每次短、准、贴近动作，并写清位置、字体气质、颜色、入场动效和退出方式。禁止用随机贴纸、乱码、小字参数堆叠或长句滚动遮挡产品 logo、包装关键信息、手部证明动作和人物眼睛。

产品 launch、SaaS、App、AI 工具和平台类视频优先用真实截图或用户提供 UI 作为产品真相。不要整页照搬；把关键模块、输入框、确认状态、数据卡片、流程节点或结果面板做成清楚的产品-motion 镜头。抽象概念必须回到真实任务、真实界面或真实结果，避免假 dashboard、乱码微文案、占位骨架和过挤表格。

### 平台 / SaaS 产品宣传结构

当产品不是单一 SKU，而是广告平台、AI 工具、企业软件、数据服务或开发者平台时，可以采用五段内容结构，而不是普通电商卖点顺序。

```text
概念钩子 -> 业务转译 -> 产品演示 -> 实力证明 -> 价值或使命收束
```

| 段落 | 职责 | 画面写法 |
|---|---|---|
| 概念钩子 | 用一个问题、隐喻或结果打开注意力 | 自然规律、连接、流动、增长、路径、世界尺度等抽象画面，但不超过全片前 20%-30% |
| 业务转译 | 把抽象概念落到真实用户和业务场景 | 开发者、运营、销售、广告主、团队协作或客户使用场景 |
| 产品演示 | 证明平台怎么工作 | 真实 UI、操作路径、模块切换、数据卡片、结果面板、通知和导出状态 |
| 实力证明 | 建立可信度 | 团队、服务、覆盖范围、案例、数据、稳定性或安全能力，事实必须确认 |
| 价值收束 | 回到品牌判断或行动 | 品牌名、产品名、主张、下载/咨询/试用 CTA 或发布会主题 |

执行规则：

- 抽象概念必须服务产品机制。水流可以转成数据流，星球可以转成全球连接，城市灯线可以转成网络，但最终要落到真实任务、真实界面或真实结果。
- UI 段要稳定、清楚、可读，优先后期叠加真实截图；动态镜头只展示重点模块，不把整张复杂后台塞进一秒。
- 生活场景和技术界面要交替证明“人为什么需要它”和“产品如何做到”，不要只拍数据光效。
- 品牌名或产品名建议在概念落地、产品演示、尾帧各出现一次，形成记忆，而不是只压在最后一帧。
- 声音可用“悬念低频 -> 电子节拍 -> UI 提示音 -> 升华音乐”的曲线；核心转场可用 whoosh、提示音或短暂停顿卡住。

## 镜间因果与转场编排

镜头数量不是目标，连续观看关系才是目标。产品广告进入逐镜分镜前，必须先写出一条可顺着动作复述的主链，例如：

```text
发现问题 -> 手拿出产品 -> 产品被放入/打开/佩戴 -> 完成一次关键操作 -> 产品或环境反馈 -> 人物确认结果 -> packshot
```

多卖点不能直接写成“功能 A 特写 -> 功能 B 特写 -> 功能 C 特写”。先按用户任务、产品结构或体验顺序分组，再让前一动作触发后一信息：

```text
任务顺序：为什么需要 -> 怎么介入 -> 核心功能怎样生效 -> 辅助功能怎样补强 -> 最终得到什么
结构顺序：整体识别 -> 操作区域 -> 关键部件 -> 材质证据 -> 回到整体
体验顺序：拿起/佩戴 -> 启动 -> 使用场景 -> 身体或环境反馈 -> 产品回收
```

每次切镜前必须同时回答两个问题：

1. **为什么现在切**：新动作开始、前一动作产生反馈、视线发现新信息、功能进入下一步、情绪发生转折，或章节确实结束。
2. **靠什么接过去**：动作、运动方向、主体位置、视线、构图形状、色彩/光线、声音、文字/图形、遮挡或产品状态中至少一个锚点被下一镜继承。

如果只有“换个角度更丰富”“切特写展示细节”“切到另一个人/场景”而没有上述因果和锚点，不得切镜。应删除该镜头、补中间动作，或改成一个连续镜头内的推进/跟随/摇移/焦点转移。

### 转场选择优先级

转场先服务因果，再服务风格。优先级如下：

1. **动作接动作**：前镜拿起、推出、打开、佩戴、按下、转身；后镜从同一动作的中段或结果继续。动作方向、速度和接触物一致。
2. **遮挡揭示**：手、产品、包装、人物身体或前景物擦过并覆盖画面，下一场景从同方向揭开。遮挡物必须来自当前动作，不凭空飞入。
3. **同物/同形匹配**：产品圆角、耳机轮廓、瓶口、按钮、货架层板、文字字形或 UI 卡片在相近位置和尺度上对齐后切换。
4. **视线/方向承接**：人物看向、走向或手伸向画面一侧，下一镜的信息从同一侧进入；不得无理由反轴或让运动方向突然相反。
5. **声音桥**：下一动作的咔嗒、风声、脚步、提示音、旁白关键词或音乐重拍提前进入，再切到声源；声音必须能解释新镜头。
6. **文字/图形接管**：字母、关键词、参数或图形由产品动作触发，扩大或移动覆盖画面，再以相同形状、位置或方向揭示下一场景。不能只把文字叠在画面上。
7. **明确硬切**：只用于冲击对比、结果揭示、喜剧反应、节拍重击或章节断点。硬切前后仍需共享主体、动作方向、构图位置、声音或语义中的至少一个锚点；不得把硬切当默认转场。

同一条短片先选一个主转场语法，例如“手部动作接力”“产品轮廓匹配”“字母遮挡揭示”或“声音先行”，贯穿开场、中段和回收。辅助转场最多 1-2 种，只在叙事需要时使用；不能每镜换一种花活，也不能所有镜头都直接硬切。

### 连续性硬约束

- **空间与道具连续**：产品、人物、手、桌面和关键道具的位置变化必须能由画面中的动作解释。空架不能下一镜无过程瞬间装满；若用魔法归位，也必须由手势、声音或产品结构明确触发，并让归位过程可见。
- **手部动作连续**：连续操作默认锁同一只手、袖口/服装、肤色、饰品、进入方向、握法和产品朝向。前镜结束姿势应能成为后镜开始姿势；不能从第二层拿物后无动作跳到第三层，再跳回第一层。
- **人物连续**：短片默认只设一个体验主角。新增人物必须承担明确职责，例如不同场景并行证明、不同受众对照或群像汇聚，并通过同动作、分屏、视线、传递物或共同声音规则建立关系。不能为“画面丰富”随机女 -> 男 -> 女切换。
- **场景连续**：换场必须对应功能阶段、时间推进、任务升级或人物移动。室内降噪 -> 户外抗风 -> 运动音质可以成立，但要由佩戴动作、开门/迈步、风声先行或功能文字接管完成迁移；场景不能随机播放。
- **产品状态连续**：开/合、空/满、干/湿、未连接/已连接、未佩戴/已佩戴等状态变化必须有触发动作和过程镜头，或有清楚的概念化转场规则。状态不得凭空跳变。
- **景别连续**：景别变化围绕观看任务组织。默认用全景/中景建立空间与关系，用近景证明操作，用特写确认细节，再回中景或全景看结果。允许全景直切特写，但必须由动作切点、视线目标、同构图锚点或声音重拍驱动；不能连续用多个无关系特写代替过程。
- **轴线与方向连续**：同一动作链保持人物朝向、产品正反、手部进入方向和屏幕运动方向。需要越轴时，用正面中性镜头、跟随移动或明确转身完成，不让主体瞬间镜像。
- **材质特写有上下文**：微距必须先由整体镜头指出它属于产品哪个部位，或在微距后立刻拉回整体说明它证明什么。无法定位、不能证明材质/工艺/功能、前后也无承接的纯纹理镜头是废镜头，必须删除。

### 景别、节奏与文字同步

- 一条 15 秒产品广告通常按“建立关系 -> 靠近操作 -> 细节证明 -> 拉回结果 -> 稳定收束”形成景别呼吸，不按固定次数机械执行。连续三个以上特写必须属于同一个可跟随动作链，否则插入中景重建空间或合并镜头。
- 镜长必须有层级。过场/动作切点可短到 `0.4-0.8` 秒，常规证明通常 `0.8-1.5` 秒，核心结果或关键结构可停 `1.5-2.5` 秒，packshot 按可读信息留足时间。不得为了镜头数把每镜机械切成同一时长，也不得用重复拉远填满结尾。
- 同一功能连续给两镜时，第二镜必须补充新证据，例如“操作方式 -> 结果反馈”或“整体效果 -> 关键细节”；第三个同类镜头若没有新反应、升级或结果，删除或合并。
- 画面文字只能由对应动作、结果或声音触发：放入完成时出现“分类收纳”，按压稳定后出现“稳固”，噪声被切断后出现“降噪”。文字应随触发物移动、落位或退场，可作为下一镜遮挡/形状/声音锚点；不得提前弹出卖点，也不得在无关动作上解释另一功能。
- 功能切换处先完成前一功能的“动作 -> 反馈 -> 结果停留”，再由结果中的物体、声音、视线或文字带入下一功能。若找不到桥，说明两个功能不属于同一短片主链，应删掉次要功能、改由旁白/尾帧承载，或拆成另一条视频。

逐镜完成后，按相邻镜头两两检查：

```text
前镜结束状态：
本次切镜的叙事理由：
承接锚点：
后镜开始状态：
继承了什么：
新增了什么：
```

任一对相邻镜头写不出“叙事理由 + 承接锚点 + 新增信息”，即判定为生硬切换，必须返工。最终还要做一次静音顺看：关闭旁白和音乐后，观众仍应仅凭动作、视线、产品状态和场景变化看懂“为什么进入下一镜”；声音与文字只能增强逻辑，不能替剪辑补漏洞。

典型改写示例：

- **收纳/厨房类**：杂乱台面全景，手拿起碍事油瓶 -> 油瓶掠过镜头形成遮挡，揭开已放到台面的空置物架 -> 同一只手把油瓶放入底层，镜头跟随上移再依次放入常用调料 -> 中景回看三层分类结果 -> 手按压台面/轻推架体，稳定反馈后“稳固”文字落位 -> 手顺势从侧边挂回砧板或勺具，证明侧边区 -> 回到与开场同机位的整洁台面和 packshot。安装、收纳、稳定、侧边功能按使用顺序推进；不允许空架瞬间变满、手在层间跳跃、孤立金属纹理或结尾重复拉远。
- **耳机/穿戴 3C 类**：耳机盒打开 -> 同一只手取出耳机 -> 产品轮廓匹配切到单一主角完成佩戴 -> 环境噪声在按压/触控动作后被切断，功能文字随噪声图形收拢 -> 主角推门走向户外，门框遮挡与风声先行带入抗风场景 -> 跑步动作和脚步节拍带入音质/律动段 -> 耳机圆形结构或字母图形覆盖画面，匹配切入单元微距并立即拉回佩戴状态 -> 主角停步取下耳机，产品回到盒中完成 packshot。若需要多人，只在同功能的并行证明或结尾群像中出现，并用同动作/分屏/共同节拍建立关系；不做女 -> 男 -> 女的随机轮换。

## 镜头设计

15秒内参数确认分镜表必须按连续秒段展示，通常写 `4-7` 行；每行是用户确认用的叙事节拍，可以包含一个完整动作链或必要的内部切镜。内部正式分镜最低 `8` 镜，按产品动作、证明、反应和节奏需要增加；不为满足下限拆断拿取、递送、佩戴、涂抹、放下等连续动作。下面的 5 个节拍只用于检查信息结构是否完整，不能替代正式动作与剪辑设计：

| 段落 | 职责 | 画面 |
|---|---|---|
| 1 | hook/蓄势 | 痛点、材质、声音、局部轮廓或结果前置 |
| 2 | 产品揭示 | 产品第一次清楚出现，包装/logo/SKU 稳定 |
| 3 | 卖点证明 | 质地、操作、结构、功能、使用动作或对比 |
| 4 | 结果/情绪价值 | 使用后的可见状态或生活场景收益 |
| 5 | packshot | 产品正面、logo/包装可见，最后 1秒稳定 |

镜头规则：

- 每个镜头只安排一个主动作目标和一个主运镜；主动作目标内部必须保留完成它所需的连续步骤，例如“拿起 -> 送向嘴边 -> 咬下”可在一个连续镜头完成，不能误解为每镜只允许一个孤立动词。
- 每个镜头必须新增一个首次出现的信息；“继续吃、继续看、继续旋转、继续环绕、继续变大、换角度再展示一次”不算新增信息。
- 镜头密度下限不等于固定切镜频率。只有出现新动作、新反馈、新观看关系或新叙事状态时才切；动作变化、镜头变化和剧情推进至少同时满足两项，不能只为凑镜头数切换景别。
- 每 2-3 个快切后必须给一次产品清晰锚点。
- 产品至少清楚出现 3 次：开场或早段、证明动作、结尾。
- 前 3 秒必须写清至少 `3` 个可见信息事件和 `1` 次有意义切镜或观看关系变化，不能用一个“产品静态展示/慢推/环绕”概括；如果同一机位超过约 1.2 秒，镜头内部必须持续发生手部动作、产品反馈、文字落位、构图升级、声音重拍或证明状态变化。
- 使用动作要有接触点、重量感和停稳，不让产品悬浮、穿模或忽大忽小。
- 最终 packshot 不塞新信息，只做产品和记忆点收束。
- 固定镜头适合电商和宠物食品：让主体动作、文字弹出、食材悬浮、碎片飞溅和产品进入画面承担节奏，降低漂移风险。
- 双原料、双口味或双卖点可用左右对称构图，主体从中间经过或产品居中压轴，既展示信息又保持画面稳定。
- 需要 TVC 质感时，每条至少设计一个“视觉亮点”镜头，例如水滴透镜、倒置倒影、产品爆炸图、黑底 360 旋转、同物匹配转场、低角度涉水或隧道光影。
- 需要产品卖点梳理时，在分镜中把每个卖点写到镜头职责里，例如“密封防漏证明”“镜片结构证明”“全景天窗情感证明”“0 添加事实锚点”。

产品图、包装图和真实 UI 是视觉事实源。外部参考广告只借节奏、构图、光线、材质或转场，不借对方文案、产品概念、Logo、UI 结构和专属符号。画面文字只使用用户确认的卖点、标题、促销或 CTA；细小包装文字、长参数表和密集 UI 文本默认降低生成风险，必要时作为后期可编辑文字处理。

## 音频与文字

产品广告默认有旁白，除非用户明确要求无旁白、纯音乐或纯鼓点。信息型/功能型/促销型通常使用 3-5 句主体旁白 + 1 句结尾 slogan；诗性/高端/香氛/珠宝/礼赠路线通常使用 2-3 句主体旁白 + 1 句 slogan。实际句数必须服从已确认时长和主 `SKILL.md` 的台词密度上限；放不下时优先减少句数、转为画面证明或后期文字，不硬塞口播。

BGM 跟主线和品类统一：高端用低频氛围/弦乐/钢琴，快剪用鼓点/电子，感官用低音量氛围 + 拟音，科技用合成器和清晰节拍。人声优先级高于 BGM。

常用文案策略：

- 数字否定式 + 感受式：适合食品、宠物、母婴和健康感产品，例如“0X 0Y + 更安心/更坦荡/更轻负担”。数字和事实必须由用户确认。
- 参数重复：适合科技硬件，核心参数最多重复 2-3 次，分别落在悬念、证明和结尾回扣。
- 关键数字标注：只把最重要数字写成广告大字，避免满屏参数。
- 首尾呼应：开场一个关键词，结尾升级为品牌主张，例如“看见 -> 不止看见”。
- 视觉主导文案：适合高端车、香氛、珠宝和形象向产品，用视觉证明卖点，用旁白、关键词、尾帧 slogan 或 CTA 完成表达收束。
- 网感短语：适合食品、宠物、饮品、生活方式和轻娱乐表达，短语、拟声、反应字或花字最多重复 2-3 次；必须贴合动作、声音、表情或卖点。
- 节庆祝福：适合节点广告，把产品名、节点祝福和品牌标识集中在尾段，避免全片文字过多。

文字层级建议：

| 层级 | 职责 | 写法 |
|---|---|---|
| 情绪语音 | 建立“好吃/好用/认可”的记忆 | 1 句短语重复 2-3 次，跟画面递进同步 |
| 氛围花字/贴纸 | 制造反应、拟声、轻喜剧节拍和动作强调 | WOW、LIKE、脆、爆汁、箭头、圈注、印章感标签等短小元素 |
| 产品信息 | 说明原料、口味、型号、规格或版本 | 只放最重要信息，优先来自包装或用户确认 |
| 核心卖点 | 给出购买理由 | 事实型卖点需确认；体验型卖点要对应画面证明 |
| 品牌尾帧 | 完成记忆和转化 | 品牌名、产品名、slogan、发布信息或单一 CTA |

声音设计必须和卖点绑定：

- 食品饮品：开盖、倒入、气泡、水花、碎裂、咀嚼、吞咽、满足反应。
- 护肤美妆：滴管、液体滴落、轻柔涂抹、水声、呼吸感音乐。
- 3C 硬件：磁吸、点击、合成器、噪音切断、低频鼓点和品牌短音。
- 汽车/户外：电机或低频轰鸣、风声、水花、胎噪、脚步、布料和音乐递进。
- 清洁/收纳：喷雾、擦拭、吸附、归位、抽屉闭合、环境噪音从乱到静。
- 节庆礼赠：包装开合、举杯、烛光空间声、轻快鼓点、祝福人声和结尾品牌短音。

广告大字、花字、贴纸、手绘标注、拟声字和反应字都可以作为场景化信息层使用，用于 hook、卖点锚点、促销信息、情绪反应、声音外化、动作强调、轻喜剧节拍、转场承接或结尾记忆点；不是字幕，不逐句复述旁白。15秒内通常 1-3 次，每次 2-8 个中文字符或短小图形元素，写成 `“...”`。

广告大字、花字和贴纸必须写清出现位置、时机、颜色、字体气质和动效；必须符合品类、平台语境和品牌调性，不遮挡产品 logo、包装关键信息、手部证明动作、人物眼睛。写法必须包含“某种字体/字重/字形的某个具体字或短词”，不能只写“加一个脆字/爽字/省字”。例如食品可写“手写粗圆体橙黄色的‘脆’字从咬合点弹出，带白色描边和碎屑小线条”；科技产品可写“窄体无衬线白字的‘已连接’贴在屏幕右上状态槽，0.4 秒淡入并停稳”。禁止长句、滚动字幕、乱码、字幕框、水印、无关表情、随机流行语、密集贴纸和逐句复述旁白。

## 长视频产品广告

功能演示、教程、深度测评、系列商品、场景种草合集可进入长视频。长视频先把全片拆成“需求 -> 产品 -> 证明 -> 场景 -> 结果 -> 转化”，再按片段生成。

每个片段只承担一个职责，不重复完整短广告闭环。中间段可以做功能证明、场景拓展、品类对比或细节解释；最终段再做完整 packshot、CTA 和品牌/产品收束。
