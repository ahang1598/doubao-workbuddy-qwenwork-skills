# 资产生成与 Prompt 合同

## 职责与读取

本文件管理真实输入与身份保持、按需资产的 Prompt、已有图板的使用和最终视频五段式。创意内容先在[创意底盘](creative-core.md)写成立，完整分镜是唯一内容母版；不在这里重新构思另一条剧情。

制作顺序按[统一生产流程](production-control.md#统一制作流程与阶段确认)执行；是否生成独立人物/产品/音色资产按其中的一致性资产门处理，只插入必要准备。不生成关键帧预览；独立资产仅在第三阶段按需制作。按已知产物需求，将本文件对应章节与其他相关规则提前成组并行读取，不等实际制作该产物时才逐文件读取。构图/声音查视听工艺，复杂效果查视觉方法库，不因进入本文件加载所有方法。

## 通用 Prompt 与留档规则

PE 在本 skill 中指提交给生成模型的 Prompt。图片用自然语言描述，视频用下文五个固定标题组织自然语言；不写成 YAML、工具参数表或内部执行说明。默认使用中文导演描述；仅用户明确要求其他语言时切换，素材原文与已锁台词不擅自翻译。模型、任务类型、生成模式、工具名和调用参数留在执行记录；比例由调用参数设置，只有解释图板布局、画幅裁切或视觉空间确有必要时才在创作描述中写出。

每次真实生图、图片编辑、生视频、视频编辑或版本派生前，静默保存实际使用的完整 Prompt 原文、输入顺序、职责和版本到对应阶段目录。默认不随媒体交付，不在聊天粘贴完整 Prompt，也不展示 Prompt 文件入口；只有用户明确要求查看、排查或交接时才直接文件交付。Prompt 和其他文档不写入画布。

### 示例与默认产物边界

示例中的“拾光咖啡”是虚构教学项目；素材编号和“已确认”仅为示例成立前提，不表示本轮已有真实素材、用户授权或已生成媒体。实际任务必须替换成当前真实输入、确认文案与当前有效母版，不能复制示例品牌、功能、人物或事实。代码块是 Prompt 正文，块外的输入前提、镜头映射和说明只用于理解，不发送给媒体模型。

本文件提供人物、产品、音色和视频示例。广告封面、宣传海报、场景图、风格图或其他普通图片，仅在用户明确提出对应图片任务时按通用图片 PE 规则执行；它们不是视频生产默认阶段，也不增加默认产物数量。

共享要求可在开头统一写明；视频各镜仍须写清本画面的主体、状态、构图与变化，不能用“同上”替代。图片允许“总述 + 分点描述”，视频保持五段式；不得把自然语言描述误写成调用参数表。

## 真实输入与全链路身份锁

先扫描当前画面涉及的真实素材。用户本轮明确上传、指定或批准的参考优先，其次为已确认标准资产，最后才是临时风格板、概念图或旧版本图。每次调用只传当前画面需要、工具能够消费的原始素材或确认标准资产，不把全片素材池全塞进去；不能只写“保持一致”或依赖模型记忆。素材数量或模态超出能力时，先按已定职责取舍、调整执行安排；其他素材可按其职责裁剪或合成。调用 image_to_video 时，用户提供的视觉锚点必须原图传入。工具无法接收原图时，说明具体限制并暂停该调用，不能静默漏掉身份基准，也不能假称传入成功。

每张真实输入图按传入顺序逐张点名用途、采用项和剥离项，分别判断人物身份、服装状态、场景结构、道具结构、姿势、构图、色彩、光线、材质和媒介。人物身份只来自身份参考，服装状态只来自服装参考，场景结构只来自场景参考，全局风格只来自已确认风格合同；不能让一张图的人脸、背景、文字、杂物、姿势或临时光线污染其他资产。不给不出场的人物传人物参考，不漏传实际出场产品参考。

| 锁定对象 | 不可擅自改变的事实 |
|---|---|
| 产品/包装 | 轮廓、比例、结构、开孔、按键、部件位置、包装形制、材质、固有色、Logo 位置、包装原文和识别细节 |
| Logo/品牌 | 字形、图形、比例、颜色、组合关系和安全区；不得重绘、翻译、拼错或替换 |
| 人物/角色 | 身份、脸型、五官、年龄感、发型轮廓、肤色、身形比例和身份标记；服装、表情、姿势只按用户要求或已确认分镜改变 |
| UI/场景/道具 | 已确认结构、布局、层级、尺寸关系、识别点；角度和状态变化仍应指向同一对象或空间 |

用户没有上传对应素材时，不得直接声称还原真实人物、产品或品牌。命中按需资产门，或用户明确要求单独生成标准资产时，第三阶段只准备实际必要且已授权的资产并展示确认；首个确认版本成为后续唯一外观基准。若用户已明确选择“无素材概念方案”，默认不额外生成独立标准资产，也不通过分镜预览图建立外观基准；由参数确认、完整分镜、对应内部创意规划和最终 Prompt 的视觉合同共同锁定本条概念视频的虚构外观，并在后续秒段中保持一致。该基准不得被描述成真实产品、真实人物或官方品牌外观。持续引用已确认文件，不得凭同一段描述生成近似替代。更换外观时先确认新资产版本，再按生产控制规则使旧版本下游失效。不得凭空补齐用户素材中未见的真实产品结构或包装事实；未能核实的角度先补充来源或改为明确的概念表达。

创意可以改变已规划的动作、姿势、镜头、尺度、空间、环境材质、光线和世界规则，不能改变身份事实。产品变世界、材质转译、共生融合等手法通过环境、概念层和空间关系实现，真实产品识别面保持准确。相关视频调用共享同一标准资产，同时继承已确认的剧情状态。

参考图忠实度优先于自由发挥。辨不清的元素只描述可见形状、颜色和位置，不命名推断，不补全或纠错原文。排除平台水印、手机状态栏、播放按钮、导出角标、账号水印和分享界面；真实产品 UI、已确认场景中的搜索框或叙事信息框按职责保留，不能与平台覆盖层混淆。截图按用途判断：只用于读取脚本、指令、文字或事实的截图不进入视觉输入；明确用于呈现真实界面、表格布局、操作状态或画面构图的截图可以作为视觉输入，注明保留区域与剥离项。读取截图上的制作指令不等于把它画进视频。

Logo、包装字和精确 UI 无法稳定保真时，优先使用原素材合成或后期可编辑层。复杂文字在分镜中写清原文、位置和时机，执行时核实合成排版能力；没有可用能力时说明具体缺口，不能仅写“后期添加”就视为已经解决。不得默认新增概念图阶段，也不得用乱码占位图进入视频。

## 按需一致性资产

生成条件唯一见[生产控制的一致性资产门](production-control.md#按需一致性资产门)。这里仅规定命中条件后的资产写法与真实输入要求；用户明确要求独立图片/音色任务时按该任务执行。

真实人物、产品或品牌还原缺少有效依据时，先补真实素材或由用户明确改为概念方案，不能用生成标准图冒充真实还原。按需资产须可复用：明确风格、参考采用/排除、用途、结构、状态、一致性锚点和禁止项。

### 产品

命中产品资产门后，依已确认参考或明确授权的概念外观建立标准资产。真实产品不能仅因缺图就凭空设计。优先做多角度图，至少包含正面，只有存在真实结构依据时才补背面、侧面、顶部、开合或关键使用状态；不得凭空设计看不到的结构。各视图必须是同一产品、比例、材质、颜色和品牌元素。Logo、包装字、屏幕字或铭文写清原文、所在面、方向和可见程度，精确文字用中文全角引号，如“品牌名”“500ml”“一键启动”。产品资产是全片外观合同，不自动等于视频 0 秒首帧。

#### 完整示例：缺少产品素材时生成标准图

输入前提：用户没有产品图片，但已确认要为虚构“拾光咖啡”生成一只后续跨片段保持一致的外带杯；字标原文、主色和结构均已在参数确认中锁定。首个确认版本将成为唯一产品资产，不是首帧。

```text
杯身为上宽下窄的象牙白纸杯，顶部覆盖哑光白塑料杯盖，杯盖右前方只有一个椭圆饮口；杯身中段包裹一圈墨绿色瓦楞纸杯套，杯套高度约占杯身三分之一，正面中央竖排白色“拾光咖啡”，使用中等字重人文无衬线字、四字等距、整组高度约占杯套六成。背面视图显示杯套纵向接缝和无字背面；右侧三分之四视图让杯盖饮口、杯套厚度和杯身锥度同时可见，正面文字仅按真实转角部分露出，不复制到侧面。

主光从左上方照入，右侧用弱白色反光补足暗部，杯盖边缘保留窄而柔的高光，杯套保持墨绿固有色而非荧光绿。背景不出现装饰、咖啡豆、蒸汽或人物，不生成视图名称、尺寸线、额外标签、水印、二维码和随机小字；不增加把手、吸管、杯盖孔或不存在的包装结构。
```

### 人物

同一人物需要跨多个片段反复或长时间出现，且缺少可用参考、命中生产控制资产门时，才按授权生成稳定身份设定图；不因短片有人物就补图。默认 16:9 图板、干净中性背景：左侧正面头部近景，头部端正、直视前方；右侧同一角色全身正面、严格 90 度侧面、背面三视图，等高对齐。需要近景身份稳定或多人同框时补头部锚点。

Prompt 写清角色名、年龄、身份、气质、脸型、下颌/头骨、眼睛、眉形、鼻子、嘴、发际线、发型、身形比例、身份标记、服装剪影、装备、材质和颜色。设定图保持中性表情、放松肌肉、自然睁眼闭嘴，不提前表演剧情。这个要求只用于身份设定图，不进入视频的表演禁区；视频按分镜完成说话、反应、情绪和动作。禁止无关文字、水印、字幕和 Logo；真实身份标记或服装上的已确认品牌仍按素材合同保留。

使用角色参考时，继承身份、脸型、五官、发型、身形、服装结构和身份标记，不继承姿势、表情、背景、光线、原画幅、其他人物、无关文字与水印。三视图呈现同一个角色，不得生成多个独立人物。

#### 完整示例：品牌广告中的咖啡师人物资产

输入前提：本条视频中阿宁会跨多个片段长时间出现，相关镜头需要稳定的全身外观；目前经确认的头部身份照 `<图片1>` 不足以承担该外观基准，`<图片2>` 为品牌咖啡师制服参考，且已按生产控制的资产门取得这份人物资产的制作授权。人物是品牌生活场景中的服务者，不沿用悬疑短剧中的对峙、压迫或惊恐表演。没有人物参考图时，仅在同样命中资产门且取得制作授权后，才去除真实图片引用，按已定概念外观制作；缺图或多段出现本身不替代授权，也不要求给单次概念人物补图。

```text
统一为自然写实的咖啡品牌广告摄影，皮肤纹理真实、色彩干净，柔和中性棚光，服装保留棉布与帆布的质地，不使用美颜磨皮或戏剧性阴影。

参考<图片1>继承咖啡师阿宁的脸型、五官、年龄感、黑色低马尾、发际线、肤色和身形；参考<图片2>只继承米白棉质长袖衬衫、墨绿色无字帆布围裙、深灰直筒裤和白色平底鞋，不继承制服模特的脸、身材、姿势和表情。两图的背景、光线、画幅、其他人物、无关文字和水印全部剥离。

生成约二十五岁的咖啡师阿宁的角色设定图，用于咖啡广告、门店服务和品牌短片保持同一人物。画面为16:9横向图板、浅灰中性背景，左侧是正面头部近景，头部端正、直视前方；右侧依次为同一角色的全身正面、严格90度侧面和背面，三视图等高对齐，头顶和鞋底基线一致，各视图之间留出干净间距。

脸型为柔和鹅蛋脸、下颌自然收窄、平直眉、深棕眼睛、鼻梁轮廓清楚、唇形自然，具体比例以<图片1>为准，不美化成另一张脸。黑发在后脑偏下位置束成低马尾，耳侧少量碎发贴近脸颊，不加耳饰、痣、疤痕或新身份标记。身形匀称，双肩放松，手臂自然垂在身侧，五指完整且分离清楚。

米白衬衫袖口收至腕部，墨绿围裙的颈带、腰带与前方单个方形口袋均采用<图片2>的结构；布料有细小褶皱和真实织纹，服装洁净、无破损、无字标，白鞋保持同一鞋型。正、侧、背面的围裙系带、马尾长度和身形厚度符合同一人物，不把三视图画成三名咖啡师。

所有视图保持中性表情，面部肌肉放松、眼睛自然睁开、嘴自然闭合；不微笑、皱眉、张嘴、露齿、哭泣、愤怒、惊恐、卖萌或做推销手势。不拿咖啡杯、不提前演绎剧情，不出现角色名、说明字、字幕、Logo、水印或装饰边框。
```

### 音色

是否制作样音唯一按[生产控制的音色资产门](production-control.md#按需一致性资产门)。新创作已选有人声、且单次视频无跨视频声线一致性要求时，由视频模型直接生成正式人声，在视频 Prompt 写清说话者、声线、语气与台词；不先制作音色。多个相关或连续视频中同一说话者需要一致时，已有可用且已采用样音就复用，否则在真实能力支持时用 `text_to_audio` 制作样音，后续调用都引用同一文件，不每句、每段重制。

每位需要保持一致的说话者使用一份约 **5 秒、1-2 句短台词**的样音。先选择正常语速下约 5 秒能自然说完的短句，再生成；约 5 秒是样音目标，不是必须填满的精确时长。保持正常交谈或符合角色的正常讲述速度，不拖长音节、放慢句尾、重复台词、增加长静默，也不把过长台词加速或截成半句。正式台词另写在视频 Prompt，样音只提供声音身份，不是全片配音，不把样音台词重复播放进成片。

音色 Prompt 具体写清以下内容，提交时替换占位符：

1. 谁的声音、用于旁白/口播/对白中的哪种表达，性别表达、年龄感、语言/口音。
2. 音高/音域、共鸣位置、明暗、厚薄、颗粒与气息；各项与身份相容，不同时要求尖细与低沉浑厚。
3. 正常语速、自然停顿、重音、咬字与句尾习惯；不用“慢慢说满 5 秒”控制长度。
4. 基准情绪和允许的情绪变化，以及情绪变化时不变的音域、共鸣和音质。正式视频可按句改变情绪，不换说话者身份。
5. 与角色相符的表演边界；要求干净近讲、响度稳定，无背景音乐、音效、噪声与混响，便于后续参考。
6. 1-2 句实际样音台词，用自然完整短句，不使用正式长稿，也不要求一次念出全片台词。

#### 模板与示例

```text
为“[说话者名称]”制作约5秒的[旁白/口播/对白]音色参考，使用[语言/口音]。
[身份、性别表达、年龄感]；[音域、共鸣、明暗、厚薄、颗粒、气息]。
使用正常[交谈/讲述]速度，[自然停顿、重音、咬字和句尾习惯]；按短句自然完成，不为达到5秒拖慢、重复或增加长静默。
基准情绪[ ]，可变化为[ ]；变化时仍保持[稳定声线特征]。
[具体表演禁区]；干净近讲，响度稳定，无音乐、音效、噪声和混响。
样音台词：[1-2句自然短句]
```

```text
为“阿宁”制作约5秒的对白音色参考，使用自然普通话。
约二十五岁的咖啡师女性，中音域、口腔共鸣，明亮温和、厚度适中，气息自然。
正常交谈速度，接话利落，饮品选择处重音清楚，句尾自然收住；按短句自然完成，不拖长音节、重复或用长静默凑满5秒。
基准情绪亲切专注，可覆盖确认、提醒与轻松打趣；变化时保持同一音域和共鸣。
不使用播音腔、机械朗读或夸张促销腔；干净近讲，响度稳定，无音乐、音效、噪声和混响。
样音台词：热的还是冰的？这杯是你的，拿稳了。
```

#### 实际传入与声音绑定

每次使用该说话者的 `media_to_video` 调用，都将同一已采用样音的真实音频句柄放入实际音频输入；按本次音频顺序映射为 `<音频1>` 等引用。不能只复制声线形容词、在正文虚写音频编号，或把前一个视频当成已传样音。第一部分按下文说明样音归谁、只采用哪些声音特征及不采用什么；第二部分集中描述说话者的稳定声线；第三部分逐声句绑定身份、表达形式、正式原文、语气和口型职责，不在每句重抄整段声线描述。

**每次 `media_to_video` 实际传入的全部音频总时长不得超过 15 秒**，样音、音乐、其他音频一起计算，并以宿主更严格的真实限制为准。提交前取得文件实际时长并求和，不把“约 5 秒”视为必定恰好 5 秒；三份样音也可能超过 15 秒。只传当前段需要的说话者样音和其他必要音频，已有同一说话者文件不重复传。超限时先去掉无关或重复音频；必要音频仍超限，就回分镜按出场/发声边界重排，并按现有变更规则处理，不能漏掉必要说话者、将多人混成一个声音、加速样音或绕过上限。实际输入时长无法核实时不把预算当成已核实。

样音用于参考音高、共鸣、音质、咬字和说话习惯，不要求复刻当句情绪，不作 BGM、音效或成片音轨。支持音频输入不自动保证音色克隆；需要新样音却无法制作，或后续无法实际参考时，按生产控制说明一致性限制，不虚构资产或保证。

## 图片 Prompt 共用规则

按需人物图、产品图或用户另行要求的独立图片共用以下写法：

1. 先写统一风格和媒介，再写生成目标。
2. 有参考图时逐张说明采用什么、排除什么；无真实输入不得虚构 `<图片N>`。
3. 写清主体、场景、构图、视角、动作瞬间、光色、材质、文字和禁止项。
4. 图片只冻结一个时刻；连续动作和镜头运动写进视频 Prompt。

画面文字统一写成：`位置 + “原文” + 字体形态 + 字号层级 + 颜色材质 + 排版路径 + 遮挡关系`。品牌名、价格、参数、日期和 UI 原文必须有来源；禁止乱码、随机小字和假 Logo。

## 已有参考图与图板

视频流程不生成分镜效果图或关键帧预览。第二阶段用文字分镜确定构图、光色、动作与声音，并转写完整 Prompt；第三阶段视频确认前完成可预先取得的真实输入准备和绑定，确认后直接委派生成，计划内真实依赖到位后再委派对应后段。已有的人物、产品、风格图和用户提供的分镜图板仍可作为参考，按真实内容指定采用与剥离项，不把参考图当作新的剧情母版。

用户提供真实四宫格图时，按从左到右、从上到下引用 `<图片X-第1格>` 至 `<图片X-第4格>`；只有实际传入且工具支持才使用。裁出单格另作输入时改用其新的真实图片编号。其他图板按实际工具能力解析，不编造格位协议。

各格可以承担身份、构图、场景、风格或某一事件状态参考，不自动代表四个镜头或四步连续剧情。说明对应的镜头/时段与职责，剥离边框、格号、批注、箭头和平台覆盖层。只有被明确采用为首帧的真实图片才决定 0 秒画面；概念图不能替代已生成视频的真实尾帧。

## 视频 Prompt 五段式

完整分镜是镜头与台词的事实源。新创作的长短视频都先按创意底盘的[短视频内容展开](creative-core.md#短视频内容展开)或[长视频内容展开](creative-core.md#长视频内容展开)落实当前任务；转写时保留实际采用的具体介绍、解释、条件、演示反馈、人物回应与视觉变化，不能缩成“展示产品”“丰富画面”或一段慢推。模型依据当前有效分镜直接撰写自然、具体、可执行的 Prompt；分镜默认内部完成；只有用户要求时提前交付指定内容，不增加默认分镜审阅。已有参考图板只辅助对应视觉职责，用户简表仅为摘要，都不能代替完整镜头设计。

### 从分镜转写，不另写一条片

转写时同时保留“内容变化”和“拍摄变化”：本镜新的观察／理由／条件／反馈及其可见载体要进入第三部分，机位只负责把它拍清。分镜写“展示多种用途”或“快切”却没有实际动作时，先在同一母版补清；不能让 OrganizerAgent 或视频模型临时补故事。mainagent 确认前留档、委派时实际提供的完整 Prompt 应能直接看出每段在发生什么、谁在说什么、为何接下一镜及具体新增的观看内容；必须完整承接母版的内容发展与有效变化，不能只给“15 秒至少 10 次变化”的指标让模型自由凑镜，也不能把用户侧精简展示当作实际生成 Prompt。OrganizerAgent 可读取完整原文，摘要只用于定位任务，不替代完整内容。数量标准仍按视听工艺，不在本文件另设指标。

例如已定的“收纳摆件”片段，不能压成“3–9 秒：快速切换钥匙、糖果、手表，镜头灵动”。应分别保留：钥匙在同一托盘内落稳的反馈；切到另一款时两款同框定位，再看另一托盘里的糖果；同一只手从第一款取钥匙离开，第二款仍在原处。旁白连续说明这一组场景的选择理由，而非每镜换一句口号。尺寸、容纳能力及用法须有依据；这只是转写粒度示例，不强制替当前影片增加这些道具。

在视频生成确认前按以下顺序写好并留档单次或全部生成段的完整 Prompt；待前段真实依赖的后段提前写完整模板，明确来源、用途和输入顺序，只为实际依赖绑定保留位置，不留空事件、拍法或台词。必要独立资产采用后先同步绑定，之后再确认视频；确认后不重新编写或压缩 Prompt，只按计划绑定后来取得的真实依赖。结论进入同一份 Prompt 与现有执行记录，不增加策略卡、第二份剧本、逐段检查或用户确认轮次：

1. **取出本次内容**：从母版取本生成段的全部镜头、对应声句、入场状态与结束状态。单次短片取全片；多段视频只取当前段，补足理解当前动作所需的前情，不把后续事件、完整开场或独立 CTA 搬进来。
2. **对齐本次时间**：将全片时间减去本段起点，画面、声句、音乐变化和音效触发一起换算为本次局部时间。例：全片 15–30 秒的一段，原 18–20 秒改为本次 3–5 秒。画面时间连续覆盖调用时长；声音可以跨镜、重叠或留白，各自区间须清楚，不能强迫一句话对应一个镜头。源视频取用区间与输出时间分开说明。工具时长不足以容纳既定内容时先回分镜重排，不靠删句、倍速念完或偷偷延时解决。
3. **保留具体拍法**：逐镜写谁处于什么状态、做什么、导致什么可见结果，怎样取景和运动、何时切出；保留第二阶段已定的表演、光色、材质、转场与声音落点。“惊讶”“电影感”“科技感”“卡点”等词不能替代具体反应、光线、运动或同步关系。主动作和关键视觉关系先写清，共用风格只写一次；辅助细节不能淹没谁先做什么、观众随后发现什么。关键画面过载时回分镜简化同时发生的事，保留看点、动作因果与既定节奏，不靠更多形容词提高执行概率。产品/品牌身份、具体特点、演示条件和推荐理由也是母版内容，不能为缩短 Prompt 删成泛称、纯操作或一句“突出卖点”；完整连贯的口播按声句保留，不重新为每镜造一个短句。不能把多个有推进的分镜合成一段数秒慢推拉；逐镜保留时间、切点和后镜入点，片头片尾也不额外加慢速包装。已有完整动作不要缩成“演示产品”；镜头内先后发生的变化也不能合并成同时发生。
4. **绑定真实输入与声音原文**：按本次各模态真实顺序编号，写清采用/剥离；把声音表的原文展开一次，去掉内部 ID。按已定时间对应画面、声句与证明结果；发现母版缺动作、台词接不上或时间装不下，回修对应内容；补充既定内容的执行细节不重新策划。待补素材、能力核实与授权提醒留在执行记录，提交前由主代理解决，不把“如果有素材就使用”“后续再确认”等条件执行说明交给视频模型。

模型生成/编辑均执行以上转写。纯技术裁切、拼接及字幕／水印后期不写视频生成 Prompt；音频变化按[素材工具路由](media-cond-video-ref.md#多轮编辑与重新生成)走重新生成并编写对应 Prompt；混合任务只为实际生成部分转写。局部模型编辑保护原片，在修改时段写清替换对象、变化和保留项，不重新铺一套广告。

五段式表示五个固定部分，第 3 部分可包含多个镜头段落和声音时间轴，不是只能写五个自然段。实际成稿按以下五个二级标题依次组织：

```markdown
## 1. 输入资产定位与 0 秒基准
## 2. 参考主体绑定与生成目标
## 3. 逐时间段动作、声音与脚本
## 4. 转场与尾态收束
## 5. 全片一致性与禁区
```

1. **输入资产定位与 0 秒基准**：逐项说明实际素材的用途、采用与剥离项，以及本次 0 秒的可见状态。音色输入要明确写“<音频N>仅作为[说话者]的音色参考，采用其音高、共鸣、音质、咬字与说话习惯；正式台词按第三部分生成，不复读样音台词，不作配乐或成片音轨”；多人逐一对应，不能笼统写“参考声音”。只有真实首帧/状态帧被用于起始约束时才这样称呼；没有输入就说明纯文本创作。身份图、产品标准图、风格图不自动决定 0 秒构图。
2. **参考主体绑定与生成目标**：说明本段要完成的事件及必要前情，集中写本段共用的主体保持项、风格和各说话者声线。无参考的概念角色也直接描述。只写影响当前生成的上下文；后续段继续剧情，不重新介绍，不让模型提前演出后续段。
3. **逐时间段动作、声音与脚本**：画面逐项用“X–Y 秒：具体动作与拍法”书写，**每次调用从局部 0 秒开始，按顺序无空档、无重叠覆盖到本次调用时长**，不使用全片累计秒数。按镜头和镜内先后变化展开，不把方案中的粗略大段直接写成一个慢镜；同一连续镜头可有多个秒段，切镜时明确写切点和后镜入点，不能把每个秒段误作必须切镜。逐项保留主体起始状态、动作路径/接触、反馈与结果、景别/角度、必要光色与运动速度；不是每秒硬拆一行。另用明确起止秒数的声音时间轴或对应时段说明说话者、表达形式、完整声句、当句语气、音乐变化和音效触发；声音可以跨镜、重叠或留白，跨镜声句完整写一次。画面文字写位置、原文、出现/退出和可读时间；已定后期叠字只留在后期记录，不交给视频模型生成。
4. **转场与尾态收束**：交代段间承接方式、最终可见状态和声音退出/承接。中间段为下一步留好状态，最后段按母版完成回收；不再复述逐镜动作和台词，不额外增加片尾定格时间。
5. **全片一致性与禁区**：仅补当前任务容易出错的限制，如不改变真实结构、不提前展示结果、不加入逐句字幕、不播放声线样音。已在前文说清的风格与身份不整段复写；禁区不能禁止母版需要的表情、运动或声音。

正文使用自然导演语言和真实素材引用，不含 Bxx/SHxxx/SEGxx/AUxxx 或资源句柄。动作、台词、素材职责发生变化时同步分镜，避免母版和最终 Prompt 不一致。默认中文；用户要求其他语言时按要求表达，逐字台词不擅自翻译。

物理续接在第 1 部分点名上一段真实状态帧及其保持项；计划内换场说明因果/章节/声音承接，不强制传上一场景尾帧。原生台词在自然短语处避开生成段边界，跨段的真实后期配音由音轨流程管理，不让两段重复朗读整句。

### 不同内容，转写时保住什么

这里保留已定场景的具体实现，不再选择新的叙事结构；混合内容按实际镜头使用，不要求每片填全表。

| 当前内容 | Prompt 中不能丢的具体内容 |
|---|---|
| 商品演示、教程、真实 UI | 操作前状态、手/工具接触位置、操作顺序、可见结果与核对时间；对比条件不变。真实操作步骤不能靠闪光、跳切或虚构界面替代 |
| UGC、测评、答疑 | 当前人在回答什么、看哪里、何时拿起或查看物品、判断来自哪个细节；补充画面承接同一声句，不让人物每切一镜重新开口。原文没有的亲测经历不补写 |
| 人物互动、品牌故事 | 谁对谁说、这句话要对方怎样回应、当句语气与必要的反应、动作后果；机位与切换保留关系，不把人物对白改成宣传旁白。宣言蒙太奇仍按已定意象和声音展开 |
| 企业、采访、案例 | 原素材呈现的真实工作与证据、说话身份、原声保留范围、数据原文与对应位置；不把资料改成虚构受访者的亲历陈述 |
| MV、ASMR、风景、简单动态、一镜到底 | 已定运动与变化过程、真实声源或音乐节点；有实际音乐才据其安排同步，只有音乐意向时不编造已分析的拍点。一镜到底明确连续调度，不插入“切到特写”；纯环境声方案不补营销人声 |

声音输入也按职责区分：声线参考不播放样音台词，配乐参考不自动变成成片音轨，实际成片音轨不交给模型重新作词或改写。写清采用区间、用途及与人声/现场声的关系；能否精确保留或同步须核实真实工具能力。原生生成的跨段配乐即使用同一描述也不保证是同一首，连续音轨的实现唯一按[生产控制的声音与接缝规则](production-control.md#旁白口播对白音轨与字幕)。

### 秒段与音色绑定示例：长片中的一次调用

示例前提：虚构台灯广告的全片 15–23 秒对应本次 8 秒调用；产品已明确为虚构概念，图片1是已采用的产品标准图，音频1是同一旁白已采用的约5秒样音。本次实际传入这两份文件；其实际音频总时长已核实不超过15秒。已定特点仅为灯头角度可调、旋钮调节亮度，不新增功效。以下五段式只演示当前段；其他段继续复用同一旁白样音，不把“音频1”理解为跨调用固定编号。

```text
## 1. 输入资产定位与 0 秒基准
<图片1>锁定同一台灯的轮廓、固有色、灯头转轴和旋钮位置，不继承背景与构图。<音频1>仅作为旁白“讲解者”的音色参考，采用其音高、共鸣、音质、咬字与说话习惯；正式台词按第三部分生成，不复读样音台词，不作配乐或成片音轨。0秒为书桌侧前方，台灯与展开的书同时可见，右手已扶住灯头，灯亮着；本段为计划内换场，不使用上一场景尾帧。

## 2. 参考主体绑定与生成目标
继续介绍这盏概念台灯怎样调整照明位置与亮度，先看灯头角度，再看旋钮操作后的变化。同一浅木书桌、同一展开的书和台灯，侧前方中近景，柔和自然环境光，灯光变化可辨。讲解者为自然普通话旁白，稳定声线按<音频1>，正常讲述速度，清楚亲切；不安排出镜人物开口。

## 3. 逐时间段动作、声音与脚本
0–2秒：侧前方中近景，固定机位，右手以正常速度沿灯头转轴向下调整，灯头方向逐步转向书页，底座不移动。
2–3秒：延续同一镜头，手松开灯头，灯头停稳，书页与光照位置同时可见，让观众看清调整结果；不切镜、不慢放。
3–5.5秒：硬切到旋钮与书页同框的侧俯近景，接右手已到旋钮旁。手指接触后正常转动旋钮，保持环境光与机位不变，书页上的灯光随操作渐亮；不加夸张光波。
```
