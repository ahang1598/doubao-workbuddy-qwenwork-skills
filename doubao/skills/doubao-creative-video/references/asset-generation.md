# 资产生成与 Prompt 合同

## 职责与读取

本文件只管理这些产物：按需人物资产、按需产品资产、按需音色资产、短片直出的内部创意规划、完整链路必做的可见视觉关键帧，以及由这些产物进入的五段式视频 Prompt。普通短片使用内部四格创意线，General 简单动态任务使用轻量运动线。场景、Logo、包装、道具、UI、风格图和参考视频可以作为用户输入被登记、继承和锁定，但不默认生成独立资产。

因此默认可能生成的图片只有三类：人物图、产品图、视觉关键帧；人物图和产品图仅完整链路按条件生成，视觉关键帧仅完整链路或用户明确要求关键帧/概念图时生成。短片直出默认只创建文本型内部创意规划，不产生图片关键帧。音色是音频资产，不计入图片数量；完成这些前置产物后直接进入五段式视频 Prompt。

- 创意方向、核心表达、受众与证明逻辑：`references/creative-core.md`。
- 视觉发动机、世界规则、运动与转场机制：`references/visual-motion-playbook.md`。
- 构图、配色、文字排版创意库、字体、光影、运镜和声音设计：`references/audiovisual-craft.md`。
- 分镜唯一母版、节拍/镜头/生成段映射及客观校验：`references/storyboard-contract.md`。
- 阶段顺序、生成授权、素材登记、文件交付、工具、接缝和版本失效：`references/production-control.md`。本文件的“资产生成”是规则分类，不把基础资产、关键帧、视频合并成同一个生产阶段。

## 通用 Prompt 与留档规则

Prompt 使用自然创作语言或完整字段化 PE，不写成 YAML、参数表、字段堆叠或内部执行说明。默认使用纯中文导演描述；仅用户明确要求其他语言时切换，素材原文不擅自翻译。模型、任务类型、生成模式、工具名和调用参数留在执行记录；比例由调用参数设置，只有解释图板布局、画幅裁切或视觉空间确有必要时才在创作描述中写出。

每次真实生图、图片编辑、生视频、视频编辑或版本派生前，静默保存实际使用的完整 Prompt 原文、输入顺序、职责和版本到对应阶段目录。默认不随媒体交付，不在聊天粘贴完整 Prompt，也不展示 Prompt 文件入口；只有用户明确要求查看、排查或交接时才直接文件交付。Prompt 和其他文档不写入画布。

### 示例与默认产物边界

示例中的“拾光咖啡”是虚构教学项目；素材编号和“已确认”仅为示例成立前提，不表示本轮已有真实素材、用户授权或已生成媒体。实际任务必须替换成当前真实输入、确认文案与已校验分镜，不能复制示例品牌、功能、人物或事实。代码块是 Prompt 正文，块外的输入前提、镜头映射和说明只用于理解，不发送给媒体模型。

本文件只保留人物、产品、视觉关键帧和视频示例。广告封面、宣传海报、场景图、风格图或其他普通图片，仅在用户明确提出对应图片任务时按通用图片 PE 规则执行；它们不是视频生产默认阶段，也不增加默认产物数量。

先按任务检查全部维度，再把实际相关维度写入 Prompt：没有人物不填表情，没有上屏文字不编排版，没有真实音频不写音频编号。共享要求可在开头统一写明；视觉关键帧各格和视频各镜仍须写清本画面的主体、状态、构图与变化，不能用“同上”替代。图片允许“总述 + 分点描述”，视频保持五段式；不得把自然语言描述误写成调用参数表。

## 真实输入与全链路身份锁

先扫描当前画面涉及的真实素材。用户本轮明确上传、指定或批准的参考优先，其次为已确认标准资产，最后才是临时风格板、概念图或旧版本图。每次生图、生视频、编辑、续写和版本派生，都必须重新传入当前画面需要的原始素材或确认标准资产；不能只写“保持一致”或依赖模型记忆。

每张真实输入图按传入顺序逐张点名用途、采用项和剥离项，分别判断人物身份、服装状态、场景结构、道具结构、姿势、构图、色彩、光线、材质和媒介。人物身份只来自身份参考，服装状态只来自服装参考，场景结构只来自场景参考，全局风格只来自已确认风格合同；不能让一张图的人脸、背景、文字、杂物、姿势或临时光线污染其他资产。不给不出场的人物传人物参考，不漏传实际出场产品参考。

| 锁定对象 | 不可擅自改变的事实 |
|---|---|
| 产品/包装 | 轮廓、比例、结构、开孔、按键、部件位置、包装形制、材质、固有色、Logo 位置、包装原文和识别细节 |
| Logo/品牌 | 字形、图形、比例、颜色、组合关系和安全区；不得重绘、翻译、拼错或替换 |
| 人物/角色 | 身份、脸型、五官、年龄感、发型轮廓、肤色、身形比例和身份标记；服装、表情、姿势只按用户要求或已确认分镜改变 |
| UI/场景/道具 | 已确认结构、布局、层级、尺寸关系、识别点；角度和状态变化仍应指向同一对象或空间 |

用户没有上传对应素材时，不得直接声称还原真实人物、产品或品牌。完整模式命中按需资产门，或用户明确要求单独生成标准资产时，先生成必要标准资产并展示确认；首个确认版本成为后续唯一外观基准。短片直出若用户已明确选择“无素材概念方案”，不额外生成独立标准资产，也不默认用四宫格图片建立外观基准；由参数确认、完整分镜、对应内部创意规划和最终 Prompt 的视觉合同共同锁定本条概念视频的虚构外观，并在后续秒段中保持一致。该基准不得被描述成真实产品、真实人物或官方品牌外观。持续引用已确认文件，不得凭同一段描述生成近似替代。更换外观时先确认新资产版本，再按生产控制规则使旧版本下游失效。不得凭空补齐用户素材中未见的真实产品结构或包装事实；未能核实的角度先补充来源或改为明确的概念表达。

创意可以改变已规划的动作、姿势、镜头、尺度、空间、环境材质、光线和世界规则，不能改变身份事实。产品变世界、材质转译、共生融合等手法通过环境、概念层和空间关系实现，真实产品识别面保持准确。所有四宫格和视频共享同一标准资产；跨图时还要继承已确认的剧情状态。

参考图忠实度优先于自由发挥。辨不清的元素只描述可见形状、颜色和位置，不命名推断，不补全或纠错原文。排除平台水印、手机状态栏、播放按钮、导出角标、账号水印和分享界面；真实产品 UI、已确认场景中的搜索框或叙事信息框按职责保留，不能与平台覆盖层混淆。文档截图、表格截图、OCR 图只做文字与事实来源，不进入视觉输入清单。

Logo、包装字和精确 UI 无法稳定保真时，使用原素材合成或后期可编辑层，不让模型重画。复杂文字仍须先通过准确字形与合成排版呈现可确认的概念图；不得用乱码占位图进入视频。

## 按需一致性资产

短片直出不默认生成独立人物、产品、音色资产或可见四宫格视觉关键帧，只使用用户已有素材和对应内部创意规划；用户明确要求单独生成资产、关键帧或概念图时例外。真实人物、真实产品或真实品牌外观是硬要求但缺少可用素材时，不得靠内部概念描述或概念四宫格冒充还原，必须等待有效素材或由用户明确改为无素材概念方案。完整模式仅在下列条件成立时生成：

- 人物：同一人物需要跨多个片段反复或长时间出现，且没有可用、已确认的人物参考。
- 产品：视频必须持续呈现同一产品，但用户没有提供可用产品素材，需要先生成并确认唯一产品外观。
- 音色：同一口播者、旁白或角色需要跨多个视频或片段保持声音一致，且确有可生成或可消费的音色能力。

除此之外不建立独立图片资产。场景、Logo、包装、道具、UI、风格图只登记用户素材职责并在视觉关键帧与视频 Prompt 中继承；不得自动生成场景四视图、道具状态图、风格图、品牌图或其他资产。按需资产 Prompt 必须写成可复用合同，包含统一风格、参考继承/排除、用途、结构、状态、一致性锚点和禁止项。

### 产品

只有完整模式缺少产品素材、且产品需要跨片段稳定出现时，才新建产品标准资产。优先做多角度图，至少包含正面，只有存在真实结构依据时才补背面、侧面、顶部、开合或关键使用状态；不得凭空设计看不到的结构。各视图必须是同一产品、比例、材质、颜色和品牌元素。Logo、包装字、屏幕字或铭文写清原文、所在面、方向和可见程度，精确文字用中文全角引号，如“品牌名”“500ml”“一键启动”。产品资产是全片外观合同，不自动等于视频 0 秒首帧。

输入前提：用户没有产品图片，但已确认要为虚构“拾光咖啡”生成一只后续跨片段保持一致的外带杯；字标原文、主色和结构均已在参数确认中锁定。首个确认版本将成为唯一产品资产，不是首帧。

### 人物

只有完整模式中同一人物需要跨多个片段反复或长时间出现，且缺少可用参考时，才生成稳定身份设定图。默认 16:9 图板、干净中性背景：左侧正面头部近景，头部端正、直视前方；右侧同一角色全身正面、严格 90 度侧面、背面三视图，等高对齐。需要近景身份稳定或多人同框时补头部锚点。

Prompt 写清角色名、年龄、身份、气质、脸型、下颌/头骨、眼睛、眉形、鼻子、嘴、发际线、发型、身形比例、身份标记、服装剪影、装备、材质和颜色。表情中性、肌肉放松、眼睛自然睁开、嘴自然闭合；禁止微笑、皱眉、张嘴、露齿、哭泣、愤怒、惊恐、卖萌或夸张表演。禁止无关文字、水印、字幕和 Logo；真实身份标记或服装上的已确认品牌仍按素材合同保留。

使用角色参考时，继承身份、脸型、五官、发型、身形、服装结构和身份标记，不继承姿势、表情、背景、光线、原画幅、其他人物、无关文字与水印。三视图呈现同一个角色，不得生成多个独立人物。

### 音色

仅完整模式中同一口播者、旁白或角色需要跨视频或片段保持一致时建立 `VOICExxx`。能力可用时生成约 `5秒` 样音并确认，否则只保存文本音色锚点。

音色 Prompt 必须覆盖：

1. 主体身份、表达功能、性别表达、年龄感、语言/口音。
2. 音高/音域、共鸣、明暗、厚薄、颗粒与气息，维度不得互相矛盾。
3. 语速、节奏、停顿、重音、咬字和句尾习惯。
4. 基准情绪、可覆盖情绪，以及极端情绪下不变的声线特征。
5. 禁止播音腔、机械感、过度夹音、夸张气声等不合角色的表演；要求近讲、响度稳定、无噪声、混响和音乐。
6. 样音只用 `1-2` 句短台词；同一主体始终复用同一描述。视频支持音频输入时传入确认样音，否则在每句台词附近复写同一音色描述。

#### 精简模板

```text
为声音主体“[名称]”设计专属音色
[身份/功能]，[性别表达与年龄感]，使用[语言/口音]
[音高音域、共鸣、明暗、厚薄、颗粒、气息]
[语速节奏、停顿、重音、咬字、句尾]
基准情绪[ ]，可覆盖[ ]；即使[极端情绪]仍保持[声线锚点]
禁止[ ]；近距离干净收音，响度稳定，无噪声、混响和音乐
样音台词：[短台词1]／[短台词2]
```

提交前替换全部占位符。样音只用于确认音色，不替代正式台词。

#### 精简示例

```text
为声音主体“林远”设计专属音色
28岁男性调查记者，冷静追查真相，使用自然中性普通话
中低音域、胸腔共鸣、偏冷、厚度适中、轻微颗粒、气息克制
语速偏慢、节奏稳定，关键信息前短停，重音克制，咬字清楚，句尾下沉
基准情绪冷静警觉，可覆盖怀疑与克制愤怒；恐惧时仍保持中低音域和清晰咬字
禁止播音腔、机械朗读、刻意气泡音、夸张哭腔；近讲、响度稳定、无噪声混响和音乐
样音台词：你终于来了／这扇门不该开着
```

## 图片 Prompt 共用规则

人物图、产品图和视觉关键帧共用以下写法：

1. 先写统一风格和媒介，再写生成目标。
2. 有参考图时逐张说明采用什么、排除什么；无真实输入不得虚构 `<图片N>`。
3. 写清主体、场景、构图、视角、动作瞬间、光色、材质、文字和禁止项。
4. 图片只冻结一个时刻；连续动作和镜头运动写进视频 Prompt。

画面文字统一写成：`位置 + “原文” + 字体形态 + 字号层级 + 颜色材质 + 排版路径 + 遮挡关系`。品牌名、价格、参数、日期和 UI 原文必须有来源；禁止乱码、随机小字和假 Logo。

## 视觉关键帧

视觉关键帧就是**提前用图片生成的视频分镜效果图**：从完整分镜里提炼出这条片最重要的一组创意，把准备在视频里实现的视觉效果、创意玩法、构图、排版和主体状态先画出来，按创意之间的关系排成 `2×2` 四宫格，供用户确认并引导视频模型生成。

**什么是创意线（先想清楚再动手画）**

四格是同一条视频里连起来的一组创意状态，构成一条能用一句话读通的创意线，而不是同一主体转四个拍摄角度，也不是四个互不相干、视频里用不上的独立奇观。四格优先展示**创意的顺序**，不是机械展示叙事的开场、发展、高潮、结尾；叙事信息要融进创意状态的触发、演化、对照、升级或收束里。一条成立的创意线必须同时满足三件事：① 每格都是一个能一句话复述的具体创意状态，可以来自同一个玩法的不同阶段，也可以来自 2-4 个互相接得住的玩法（材质外化、结构爆炸、产品变世界、巨物化、微缩世界、液体飞溅冻结、界面接管、入口穿梭、动力学排版、语义幻变、光影揭幕、字体气质切换等），而不是"某某特写""换个角度"；② 相邻两格之间有一个明确的创意演化，用一个**具体关系或转化动词**说清上一格的什么元素、状态、字形、材质、空间或信息怎么影响下一格（化成、裂开、缠上、放大成、收束成、穿过、长出、翻转成、压缩成、加重为、褪成、对照、升级、回收……），而不是"切到／然后／接着"这种纯剪切；③ 观众能从这条创意演化里读到核心表达，不需要再另铺一层普通线性叙事来解释。

**按这四步设计（顺序、玩法组合、谁打头都由本片决定，不套任何固定模板）**

1. 用一句话定这条片的核心创意表达（例：一抹樱桃红、丝滑水润、从混乱到清楚）。
2. 先定 2-4 个能互相接住的创意节点；可以是四个不同玩法，也可以是 2-3 个玩法展开成四个状态，还可以四格都属于字体/排版创意但用字体气质、字重、尺度、空间关系和运动方式递进。
3. 把它们排成一条创意线：每相邻两格之间写一个具体关系或转化动词，让整条线读起来是"格1创意状态 →(关系/转化)→ 格2创意状态 →(关系/转化)→ 格3创意状态 →(关系/转化)→ 格4创意状态"。顺序、谁起手（画面、字体、声音可视化、UI、材质或人物动作都可以）、是否 packshot 收尾，全按本片目标自定。
4. 落格：把创意线按左上→右上→左下→右下填进四格，每格记下"本格创意状态 + 承接上一格的关系/转化 + 本格承担的信息"，带进下面逐格 Prompt 的对应字段。

**直接判死（动笔时就要避开，命中任一条就重排创意线再画，不靠事后补救）**

- 四格拆开看是"英雄全景 + 侧面 + 开盖／使用 + packshot 定版"这类只换机位、景别、角度的巡览。
- 任意两格只是同一个玩法换角度、换景别、换背景或换文案；若同一玩法拆成两格，必须写成不同阶段，例如"文字裂开露出空间"和"文字碎片收束成品牌锁版"，且承接动词、主体状态和视频职责都不同。
- 有任意一格只写得出机位、景别、构图，却写不出创意状态或玩法职责。
- 相邻两格之间填不出具体关系或转化，只能用"切到／然后／接着／下一个"连接。
- 有格只为好看，在最终视频对应秒段里根本用不到。
- packshot 或英雄定版占了两格及以上。

文字排版／字体设计是完整创意方向，不是附属装饰，不强制、也不限定它出现在哪一格。可以某一格用文字创意、可以四格全是字体创意（不同字体、字重、尺度、排版切换来递进传达同一主题）、也可以由字体创意打头，还可以整组四格完全不用文字创意。一旦某格采用文字创意，就要把它当成真正的设计来做：把品牌主张、产品名、关键词、slogan 或活动主题做成动力学排版、环境巨字、字体尺度接力、图形化文字空间、字形材质变化或字体性格对照，按 `references/audiovisual-craft.md` 的“文字排版创意库”和字体形态表写清具体字体气质、字重、字号层级、构图关系和与主体的遮挡/参与关系；不能只把一行小字摆在角落充数。

创意线可以有很多种结构，以下示例互相之间结构完全不同，用来说明顺序、玩法组合和起手创意都不固定，不是要照抄的模板：

- 示例A｜变身链（一个创意长出下一个）：第1格真实樱桃悬浮纯白空间 → 第2格樱桃化开成红色唇釉丝带（语义幻变）→ 第3格丝带缠上悬浮瓶身、露出内部质感（材质外化）→ 第4格丝带尾端写成品牌主张并定版（动力学排版）。相邻格靠"上一格的东西变成下一格主角"接龙。
- 示例B｜四格全字体（不同字体切换递进传达同一主题）：四格都是文字/字体创意，围绕同一句主张分层展开——第1格极细衬线字轻描主题一角、留白克制；第2格换成超粗无衬线巨字撑满画面、字重骤增；第3格文字碎裂/位移成图形化排版承接情绪；第4格所有字收束成最终 slogan 与品牌锁版。靠字体气质、字重、尺度、排版节奏的变化递进，不依赖实拍画面。
- 示例C｜字体打头引出画面（文字先行，再长出实拍创意）：第1格一个巨型关键词占满画面作为钩子（字体创意起手）→ 第2格关键词的笔画裂开、透出后方真实场景（文字与画面咬合）→ 第3格镜头穿过文字进入完整产品/场景创意 → 第4格产品英雄定版，关键词缩回角标呼应开头。起手是字体，收尾是画面。
- 示例D｜两组创意节点展开四格（不是四种玩法）：第1格混乱任务卡堆满屏幕（UI 接管现实）→ 第2格任务卡被同一个光标归拢成三列（同玩法第二阶段）→ 第3格三列压缩成一条清晰进度线（信息图形化）→ 第4格进度线回收成产品界面与 slogan。只有两个大创意节点，但四格都有不同状态、职责和承接。

生成前必须读取：

- `references/visual-motion-playbook.md`：选择视觉发动机、玩法和效果。
- `references/audiovisual-craft.md`：选择构图、配色、字体排版、光线、材质和镜头视角。

不能只画普通摆拍或换姿势分镜；每格必须明确展示一个准备交给视频模型实现的视觉设计，并写清视频里从哪里开始动、什么保持不变。

### 数量与四格规划 / 四宫格规格

- General 简单动态任务：不创建内部四格创意线，只建立一条轻量运动线，固定记录 `用户锁定项 -> 一个主动作 -> 最多两个因果次级运动 -> 摄影机策略 -> 声音/台词 -> 落定或回环`，直接映射完整分镜和五段式 Prompt。
- 其他短片直出：默认生成 0 张四宫格视觉关键帧图片；必须创建文本型内部四格创意线，不额外按时长增加，也不向用户展示为图。用户明确要求看关键帧/概念图，或转入完整链路时，才生成可见四宫格。
- 完整链路少于 30 秒：1 张四宫格。
- 完整链路 30-59 秒：2 张四宫格。
- 完整链路 60 秒：3 张四宫格。
- 完整链路超过 60 秒：之后每多 30 秒新增 1 张；公式为 `1 + floor(总时长秒数 / 30)`。
- 多视频项目逐条独立计算，不用一张图服务多条不同创意主线。

按从左到右、从上到下编号：

```text
第1格 | 第2格
第3格 | 第4格
```

可见四宫格的格位按创意线顺序排列：`<图片1-第1格>` 至 `<图片1-第4格>`，再到 `<图片2-第1格>`。短片直出的内部四格创意线只使用 `内部格1` 至 `内部格4` 或自然语言标签，不得写成 `<图片X-第N格>`。四格不是四个候选方案，也不是同一主体的四个拍摄角度；它们是同一条视频里连起来的一组创意状态，可以换场景、景别、构图和效果，也可以连续使用同一大类字体、材质、UI 或空间玩法的不同阶段，但相邻格之间要保留可追踪的主体、品牌、色彩、形状、母题、字形、材质、信息层或创意演化关系。

四格也不是首帧、尾帧或普通分镜图的默认集合。Agent 必须先根据完整分镜判断哪几个时刻最需要视觉锁定：可能是开场、玩法触发、证明高潮、转场接口、字体/图形状态、产品回收或尾帧定版；不必按视频先后平均抽样，也不必把第1格当真实0秒首帧。只有明确承担首帧职责的格位才可写为0秒基准；其余格位必须写清对应秒段和职责。若四格只是“环境远景 -> 主体靠近 -> 主体侧面 -> 主体特写”这类普通镜头顺序，而没有玩法状态、创意转化或产品/品牌证明递进，视为不合格。

四格创意必须从当前产品/品牌/人物/卖点中长出。每格至少命中以下一项：产品结构或材质造成的视觉变化、品牌资产显影、卖点被外化成可见规则、人物动作触发现实变化、声音/文字/界面进入空间、环境对产品产生反馈、旧状态被产品替换或收束。雪山、城市、海浪、光束、粒子、花瓣、烟雾、慢动作等只算场景或质感，不能单独充当创意；必须说明它们和当前主体的关系，例如由车灯、轮胎、风阻、座舱、品牌主张或驾驶状态触发并回收。

四格创意线必须继承 `creative-core.md` 的品类套路排雷结论。格位里的“本格创意状态/玩法”不得直接采用当前品类最常见的第一联想，除非已经完成反套路转译：它由当前产品/品牌/卖点触发，改变了具体规则，连续影响下一格或最终回收，并承担证明职责。若四格只是把同一个默认感官套路拆成“触发 -> 光波/声波/粒子 -> 扩散 -> packshot”，没有机制家族变化或品牌资产绑定，视为不合格。默认感官元素只能作为局部反馈；四格主线必须能读出更具体的空间、视角、文字、包装、流程、角色行为、材质或时间机制。

四格不是把“叙事”和“创意”拆开摆放，而是把叙事融入创意状态。每格都必须写清本格来自用户指令、素材事实、产品/品牌卖点、人物关系或平台语境中的哪一项；本格如何让观众新增一个判断；下一格继承本格的哪个形状、字形、材质、动作方向、声音、信息层、产品状态或人物反应。若四格之间只有剪辑顺序，没有创意接力；或某格创意无法解释为什么属于当前产品/品牌/故事，必须重排。

可见四宫格比例一致，共享角色/产品/品牌、视觉语言和色彩合同；允许景别、视角、构图、空间、环境材质和强弱变化。每格是可独立裁出的完整画面，细窄干净分隔；禁止编号、说明文字、水印、手机界面、无关边框、跨格文字、跨格肢体和连续背景污染。每格不得被分隔线切断主体。内部四格创意线不需要画面分隔要求，但仍必须锁定同一视觉合同和相邻承接。

每格必须映射到当前 `video_N` 命名空间内的具体 `Bxx/SHxxx/SEGxx`，同一格可以服务多个相邻镜头；跨视频记录时使用 `video_id + 局部 ID`，不得只用裸 ID 关联。四宫格只锁重点视觉效果，不能替代完整分镜；真实片段接缝仍使用视频抽帧。

### 四格创意线 / 四宫格 Prompt

本模板同时服务两种情况：短片直出时，它是内部文本规划，不作为图片 Prompt、不展示给用户；完整链路或用户明确要求关键帧/概念图时，它同时作为可见四宫格图片 Prompt 的结构。先写全局统一项：画幅、媒介风格、人物/产品/品牌锁定、共享色板和禁止项。全局段必须先写一行 `四格创意线`，用一句话串起四个格位创意状态和相邻关系；写不出这行时先重排创意线，不进入逐格 Prompt。再按第1格至第4格逐格写，每格开头先锁死这格在创意线里的位置、视频职责和分镜映射，再写画面：

```text
四格创意线：（格1创意状态 → 具体关系/转化 → 格2创意状态 → 具体关系/转化 → 格3创意状态 → 具体关系/转化 → 格4创意状态；可由 2-4 个创意节点展开）

本格创意状态/玩法：（从玩法库、字体排版、材质、UI、空间、声音可视化等迁移来的具体状态，一句话复述这格干什么）
承接上一格：（第1格写"起手创意"；第2-4格写一个具体关系或转化，说清上一格什么元素/状态/字形/材质/信息怎么影响本格）
对应分镜：（Bxx/SHxxx-SHxxx/SEGxx + 对应视频秒段）
本格职责：（停滑/证明/解释/情绪/记忆/收束中的实际职责，写清它让观众新增理解什么）
画面效果：（本格创意状态触发了什么可见变化，最终停在哪个可画出的状态）
主体与参考：
场景与构图：
光色、材质与文字：
视频运动提示：（触发动作 -> 运动方向/速度/反馈 -> 落点；第1-3格同时写清如何把动态把手留给下一格）
```

`四格创意线`、`本格创意状态/玩法`、`承接上一格`、`对应分镜`、`本格职责` 五项是硬必填，不能空、不能写“待定”“创意展示”“高级质感”“氛围铺垫”“展示卖点”这类空话；第2-4格的“承接上一格”必须是化成/裂开/缠上/放大成/收束成/穿过/长出/翻转成/切换成/加重为/褪成/对照/升级/回收一类的具体关系或转化，出现“切到/然后/接着/另一个镜头”即视为创意线断裂，需重排。`对应分镜` 必须包含当前视频命名空间内的 `Bxx/SHxxx/SEGxx` 和实际秒段；`本格职责` 必须说明本格在视频中承担的信息、证明、情绪、记忆或收束责任，不能只写审美风格。

“画面效果”必须具体，例如巨型产品成为山体、咖啡液和原料悬浮拆解、液体飞溅冻结、巨型文字参与空间、产品与自然场景融合；不能只写“高级”“有创意”。同时必须写清本格创意由什么真实动作或产品/品牌元素触发，证明或放大了什么信息，如何影响下一格或最终回收。“视频运动提示”必须能直接进入后续视频 Prompt：写清触发动作、首先运动的对象、运动方向/速度、反馈、落点和保持项；第1-3格还要写清下一格继承什么动态把手，避免四宫格只停在静态美术稿。

产品是视频核心主体时，四格中至少两格必须清楚出现产品。已有产品图或已确认产品标准资产时，凡产品实际出现在某格，该格都要重新写 `参考<图片N>` 及本格采用项，不能只在全局写一次后用“同上”代替。只有用户已明确选择无素材概念方案且不存在真实产品图时，才不虚构 `<图片N>`；此时每个产品格都要完整复写同一套概念产品轮廓、结构、比例、材质、固有色、字标位置和禁止变化项，并明确这是概念外观，不得宣称真实还原。人物、Logo、关键道具同理；真实 Logo 没有来源时不得虚构。

生成后检查：分镜映射正确、创意效果真实画出或写入可执行视频动作、人物/产品/品牌准确、四格构成一条能读出关系的创意线（创意间有接力/递进/演化/翻转关系，而非纯叙事节拍或互不相干的奇观）且每格都对应最终视频里的真实秒段、四格视觉统一但不重复；可见四宫格还必须每格可以独立裁出。四格承载不同的创意状态、设计阶段、信息职责或玩法机制，而非同一主体的四个拍摄角度；若采用了文字/字体创意格，该格要达到设计水准。若检查发现某格只是普通远景、主体靠近、侧面展示、局部特写、慢动作摆拍或环境航拍，不含产品/品牌触发、创意状态、证明职责和承接关系，即使画面美也必须重写。任一项不成立就先修改内部创意线或图片，再进入视频。

反套路检查也在此阶段执行：如果把产品名替换成同品类其他品牌后，四格主体玩法几乎不用改；如果任意一格的创意只能解释为“好看特效、声波、光晕、粒子、飞溅、花瓣、慢动作”；如果四格没有把默认感官转译成当前产品专属的证明或回收关系；如果某格不能说明来源、职责和对下一格的影响，都必须重排创意线，不进入图片生成或视频 Prompt 编译。

四宫格视觉关键帧是图片产物，只在完整链路、用户明确要求或其他规则明确进入可见关键帧阶段时生成。每次 `image_gen`／`image_edit` 调用前核对当前 Workspace ID，有唯一有效 ID 时按实际工具契约显式透传；字段无法确认、不支持或校验失败时停止调用，不省略已有 ID 降级重试。默认非 Mobile 通过工具传参关联画布；mainagent 将每张成功图片的原始结果对象立即单项交给 `present_files`，成功即完成该张图片的媒体交付，不再执行 `+create`／`+create-batch` 创建 IMAGE Item，也不在交付前插入媒体 `+get`、下载、复制或重新上传。多张四宫格逐张直接交付，不等全部生成后再批量交付；本轮已确认批次全部直交后，非 Mobile 再按 [媒体直接交付与产后目录整理](media-delivery.md) 定位真实对象、读取内容、仅更新 `path` 并再次核验。system 命中 `Device platfrom:Mobile` 时，仅直接交付图片；已有有效 ID 只作工具上下文透传，无 ID 不创建，禁止全部 Canvas CLI／Workspace 操作和产后目录整理。短片直出的内部四格创意线或轻量运动线都不是图片产物，不执行交付、画布写入或图片确认；可静默保存为分镜或 Prompt 编译记录。Workspace 初始化和目录命令读取 `references/cli/README.md`；用户可见话术不点名画布、CLI 或交付工具。

## 视频 Prompt 五段式

最终视频 Prompt 必须从已校验的完整分镜 Markdown，以及已确认可见格位、内部四格创意线或 General 简单动态任务的轻量运动线编译。内部执行包、Prompt 留档元数据和片段清单必须标明 `SEGxx` 及覆盖的全部 `SHxxx`，保持 `Bxx -> SHxxx -> SEGxx` 一致；实际发送给媒体模型的五段式 Prompt 正文只写连续时间、自然导演语言和真实素材引用，不写内部 `Bxx/SHxxx/SEGxx`。除 General 简单动态任务和用户明确要求的真实一镜到底外，15 秒视频最低 `8` 镜，并按动作、证明、反应和节奏需要增加；不能为满足下限拆断动作。General 简单动态任务允许一个或少量镜头，照片动起来固定 5 秒；真实一镜到底必须只有一个连续镜头。分镜与台词客观校验读取分镜合同；不能重新发明镜头、台词或素材关系。

四格创意线和用户确认简表里的 `Bxx` 粗节拍都不能直接成为最终视频 Prompt 的段落数量。四格只提供创意状态、动态把手和相邻承接；General 简单动态任务的轻量运动线只提供单一动作因果和摄影机约束；`Bxx` 只帮助用户理解大段走向。最终 Prompt 的第 3 段按完整分镜的真实镜头和动作链展开：需要切镜时明确写切点，不需要切镜时在一个镜头里写完整连续动作。一个内部格位或一个 `Bxx` 可以覆盖一个或多个镜头，但不得把完整动作机械拆碎，也不得把全片压成几段静态画面。

使用五段式连续文本，顺序不可调整、合并、拆分或省略。本轮关于动作桥和镜间连续性的修改只作用于第 3 段的逐时间段表述与第 4 段的转场验收，不改变五段式结构：

多生成段按下面的唯一编译顺序执行：

同一 `video_N` 的多个 `SEGxx` 是同一条连续视频的分段生成，不是独立创意。每份五段式 Prompt 都必须继承同一核心主线、人物身份与服装、产品/包装与品牌资产、场景结构、光色材质、声音系统、视觉机制和已经发生的剧情状态；当前段只能继续推进自己负责的下一段剧情，不能重新介绍主体、重启钩子、重置状态或另做一条完整短片。

1. 按 `SEGxx` 把完整分镜分组；每组只能包含时间连续的 `SHxxx`，每个镜头必须且只能进入一个生成段。
2. 每个 `SEGxx` 独立编译一份完整五段式 Prompt，不把多个生成段合并成一份 Prompt，也不把一个生成段拆成多份互相重叠的 Prompt。
3. 第 1 段只写当前 `SEGxx` 实际传入的素材、对应格位和非首段真实尾帧；第 2 段只绑定当前段实际出现的主体及本段生成目标。
4. 第 3 段按当前 `SEGxx` 内的 `SHxxx` 顺序逐镜投影时间、动作、镜头、声音、文字、新增信息和尾态，不新增、不遗漏、不重复镜头或台词。
5. 第 4 段由当前段内相邻镜头的“前镜尾态 -> 切镜理由 -> 承接锚点 -> 后镜起态”编译；非最终 `SEGxx` 还必须留下可供下一段消费的明确尾态。
6. 第 5 段继承全片一致性与禁区，再叠加当前生成段特有风险。
7. 编译后核对覆盖守恒：全部 `SHxxx` 恰好出现一次、时间连续、台词逐字一致、素材编号真实、非首段物理连续时存在上一段真实尾帧输入；任一项不成立时并入唯一一次集中修订。

1. **输入资产定位与 0 秒基准**：按真实输入顺序解释图片、视频和音频用途；区分全片继承的基础资产、确认格位、声音参考与真正的首帧/上一段尾帧。基础资产不自动承担 0 秒画面。关键帧写清锁定哪秒/哪段的主体、构图、世界规则、空间、光影、材质和文字；非第一段必须说明真实上一段尾帧、状态帧或视频的承接职责，写成 `<图片N> 是 SEGxx 的真实尾帧/状态帧，作为本段首帧/状态参考，锁定……`。禁止只有“承接 SEGxx 尾态”“接上一段某某特写”而没有真实输入编号；无法传入真实尾帧时，必须改写为已确认的时间省略、概念转场或跳切方案。
2. **参考主体绑定与生成目标**：绑定主要主体、产品、人物、品牌、场景及来源；逐项说采用和剥离什么，排除无关人物、字幕、水印、二维码、平台覆盖层、乱码、竞品专属视觉与未授权元素。
3. **逐时间段动作、声音与脚本**：连续覆盖全时长。每段先写如何接住上一段的主体位置、动作姿态、视线、道具状态、运动方向或声音，再写主体/来源/状态、场景与道具位置、触发、完整动作链、反馈、景别/机位/角度、一个主运镜、光色材质、旁白/口播/对白原文、BGM、拟音、画面文字/图形、信息增量和切出落点。跨镜动作必须同时写前镜动作发起和后镜动作续接；不可省略关键空间位移。实际生成并传入可见四宫格时，每个秒段都必须显式引用它所承接或复现的四宫格格位，写成 `<图片X-第N格>` 并说明本格锁定的构图、世界规则、主体状态、光影、材质或文字，绝不能整片只在开头引用一次整图或 `<图片1>`、`<图片2>` 后各段不再点名格位；一格可服务多个相邻秒段，但每个秒段都要写清它对应哪一格。短片直出没有生成可见四宫格时，每个秒段改写成自然导演语言，引用内部格位的创意状态和动态把手，例如“承接内部格2的文字裂开状态”，不得写 `<图片X-第N格>`、不得声称存在图片输入。所有可听语言必须写明形式和主体，再把逐字原文完整放入 `{}`，例如 `旁白：{这一刻，城市重新醒来}`、`口播（主播）：{先看它真正解决了什么}`、`人物对白（阿宁）：{我准备好了}`；不得只写“有人声”“人物发声”“配旁白”或“加入解说”。画面内字幕才使用 `【】`，上屏标题、品牌字和图形标签使用 `“”`。用户明确要求无人声，或品牌 TVC 按三级声音优先级判断采用无旁白时，按已确认策略写无旁白/无台词及信息承载方式，不留默认旁白占位。
4. **转场与尾态收束**：独立描述本段能生成和验收的转场、画面落点、声音余韵；逐个切点写成“前镜结束状态 -> 切镜理由 -> 承接锚点 -> 后镜开始状态”，不能只列转场名称。中间生成段留可承接尾态，不重复完整开场或最终品牌收束；单条短片和最终段写完成动作、产品/人物/品牌落点及自然声音收束。开头与结尾构图相似时必须明确可见状态差异和新意义。
5. **全片一致性与禁区**：复写统一风格的可观察特征、主体/产品/人物/品牌/场景/道具/光线/音色/尾态保持项；按当前风险限制随机字幕、乱码、水印、二维码、平台 UI、额外主体、产品变形、身份漂移、手部异常、抖动、闪烁和无来源光效。

### 每个时间段的导演维度

时间段按可执行镜头或连续动作段组织，不强制切成 0.5 秒。若为了可读性合并相邻内容，必须保留原有动作顺序、观看关系、信息增量和转场落点；内部微拍可以是同镜动作，不要求至少一次切镜。若一个动作跨越两个镜头，必须把前镜结束姿态和后镜开始姿态写成同一个连续动作桥，不能让人物、手、产品或道具瞬移。

每条视频的最终 Prompt 至少安排一个完整“动作桥”或“信息桥”：写清前一状态、触发动作、运动路径、切点或镜内调度、后一状态和反馈。例如“手捏住薯片 -> 手向左上送向嘴边，薯片保持同一朝向 -> 在手腕越过下巴时动作中切到侧面中近景 -> 同一只手继续移动并把薯片送到唇前 -> 咬合发生”。动作桥优先于蒙太奇；只有并行比较、节奏冲击、观点列举或反应接力确实需要时才使用三镜蒙太奇。

最终 Prompt 要显性写出观看路径，而不是追求镜头多变。景别、机位、视角、运镜、遮挡和焦点只在观看任务变化时改变：先建立空间/主体关系，再靠近动作或证据，最后回看反馈/结果。相邻镜头不得无锚点地在全景和特写之间往返；需要跨级时，用动作中切、视线目标、主体同位置、遮挡峰值、形状匹配或声音重拍连接。连续同类镜头若属于同一动作链可以保留，否则合并。

最终 Prompt 必须有可执行的节奏语法。除 General 简单动态任务和用户明确要求的真实一镜到底外，15 秒及以内视频前三秒至少包含 `3` 个可见信息事件和 `1` 次有意义切镜/观看关系变化，第一镜通常不超过 `1.2` 秒；开场必须有异常、冲突、主动入场、声音触发或问题与证据并置，禁止静止产品、固定人物和诗集式单画面。General 简单动态任务不强制切镜，首秒启动可见运动并在 4-8 秒内完成状态发展，照片动起来固定 5 秒；真实一镜到底只写一个连续镜头，通过主体路线、摄影机路线、空间变化和动作反馈持续推进。存在普通静态尾帧时只保留 `0.6-1.0` 秒；Loop 或持续运动到结束时可以不设静态尾帧。快来自事件推进和加速度，不来自无锚点硬切。

最终 Prompt 不允许用一个孤立动词撑满长时间段。单个时间段超过 `1.5` 秒，至少写出一个主动作及其二级变化或反馈；超过 `2` 秒，必须写成至少三个连续事件组成的小过程，并说明每一步如何改变画面信息。若一个长段落只有“旋开、探入、涂抹、拉远、停住”这类单一动作，优先补齐动作前后路径与反馈；只有观看任务确实变化时才拆镜。动作链优先使用人物、产品、手、皮肤、界面、文字、材质、光线和环境之间的因果接力，而不是让同一动作慢慢完成。

每段至少有“触发 -> 变化 -> 反馈 -> 落点”。只旋转产品、转头、抬手、推镜、环绕而没有改变问题、因果、证明、反应、场景结果或品牌归属，只算运动。除尾帧定版、关键证明与可读停留，不允许静态姿态、无信息慢推或同一动作换角度填时长。需要执行黄金三秒切镜规则的视频，前 3 秒至少写 `3` 个连续信息事件和 `1` 次有意义切镜/观看关系变化；General 简单动态任务改写为首秒启动及连续状态变化；真实一镜到底禁止切镜并按连续空间与动作节点推进。超过 2 秒的段落写清至少三个实质动作或状态阶段，事件可在同镜完成。眼神、呼吸、灯闪只能作为辅助，除非用户明确要求的就是对应轻微动作或氛围变化。

当前场景状态逐段更新：主体站位、道具相对位置、光源变化、背景运动、空间声源、地面/桌面/屏幕/包装/界面状态，以及上一段尾态如何延续。不能只列“停车场”“厨房”“办公室”；要写灯管闪动、积水倒影、任务卡归列、水珠滑落等可见状态，并让它服务人物心理、产品证明、品牌情绪或信息关系。

画面细节至少达到图片 PE 的主视觉级别，再补起始状态、动作细节与手/眼/身体接触点、运动路径、速度/缓动、中间状态、镜头跟随、声音卡点、图形入退场和可承接尾态。每个秒段都要写到这个密度，不允许把一段压成“切到某某特写，展示质感”“镜头横移露出细节”这类只有景别加一句意图的简写；单薄的一句话秒段视为不合格，必须补齐主体状态、空间、动作链、光色材质、声音卡点和对应格位。策略必须在具体秒段发生，不在段外空写“科技感”“专业”“加动效”。一个主视觉世界和少量有职责的动作优先，不能堆特效。

切镜写“何时切、因何切、切到哪里、切后首次看到什么”。动作切、视线切、声音桥、形状匹配、遮挡切或因果切均须有锚点。例如“包装撕口声先响，切袋内极近景，碎屑冲向镜头遮挡，切到街道灯牌逐个亮起”。相邻段不能只是换景别或文案，要改变位置、方向、视角来源、图形状态、规则、光线动机、节拍、反馈、心理、信息层级或叙事压力。

每个玩法段写一个具体小惊喜：入口如何打开、声音如何变成力量、手势如何改变现实、文字如何进入空间、界面如何接管场景、旧状态如何退场；最后回到信息或情绪判断。禁止“证明冷藏清爽”“环境扩展”“体现专业能力”等意图句替代可见动作。

声音写层级：BGM 的乐器/音色、速度、情绪职责与人声避让，拟音绑定真实动作。画外旁白、解说或内心独白注明画面人物不开口；对白/口播明确说话者与口型。台词密度服从主入口的声音约束，不靠加速规避。

画面文字逐条应用图片文字合同，再补出现时机、职责、入场/退场、停留时长、描边/阴影/底板和安全区。例如：`右上安全区显示窄体无衬线中黑白字“已连接”，贴在屏幕状态槽内，0.2 秒淡入，停 0.6 秒后随切镜消失`。数值、分数、比例、排名、用时、价格、温度、库存、步数、进度和图表必须有来源，写清起止值、单位、路径、中间状态触发、数字字体和可读停留；无来源只用“未完成”到“完成”等概念状态，不编造数据。

内部句式仅用于确保维度完整，最终仍写自然导演语言：

```text
X-Y 秒，[主体及参考来源] 在 [当前场景状态] 中由 [动作/声音/台词] 触发 [具体变化]；
镜头以 [景别/机位/角度/一个主运镜] 拍摄，[光色/材质/构图] 指向 [可见证明锚点]；
[图形/文字] 从 [起点] 沿 [路径/速度/缓动] 到 [真实落点] 并停留 [时长]；
声音为 [人声原文/音乐/拟音]，在 [动作节点] 同步；
段尾停在 [尾态]，新增 [信息/关系/结果]，保持 [锚点] 并避免 [当前风险]。
```

### 视频 Prompt 合同与格位引用

确认图、内部四格创意线或轻量运动线锁定身份、产品结构、世界规则和关键时刻的视觉关系。核心构图、光影与空间层级在对应时刻成立，不要求全段摄影机静止；允许按已确认分镜切换景别、视角、主体位置和有动机的光影变化，不得擅自更换产品、主视觉规则或另起风格。视频补进入、触发、运动对象/方向/速度/缓动、物理反馈、镜头跟随、声音卡点和离开后的尾态。每个运动从确认图已有动态把手、内部格位的触发与承接关系，或轻量运动线的主动作与因果次级运动中长出；无起点的粒子、扫光、环绕、漂浮不得添加。多图或多格控制写清上一格哪个对象、方向、形状、遮挡、字形、信息层或材质连接下一格。

视频第 1 段与需要复现的具体秒段都要再次引用素材或内部格位。实际生成并传入了可见四宫格时，每一个秒段都点名它对应的格位，写 `<图片X-第N格>`，如 `<图片1-第3格>`，并说明该格锁定哪些项；不得只写“参考四宫格”“参考图片1”“同上”，也不得只在 Prompt 开头引用一次整图后各秒段不再点名格位。短片直出没有生成可见四宫格时，每个秒段改写成自然导演语言，例如“承接内部格2的文字裂开状态”或“延续内部格3的液体圆环动态把手”，不得写 `<图片X-第N格>`、不得声称存在图片输入、不得让执行包等待概念图确认。明确指定承担首帧的真实图片格位才是 0 秒基准；内部格位只能作为创意与动作约束，不能作为真实首帧。若能力仅能消费单帧，则裁出已确认格位作为实际输入，保留来源图/格位到裁出文件与当前输入编号的映射；不得传整张四宫格冒充单幅首帧，也不得引用未传入的整图编号。裁出后用实际 `<图片N>` 定位，并注明来源格位。

有视频输入时只继承所需连续性、主体、场景、风格或运动，不复刻源片完整剧情、字幕、水印与界面。真实接缝帧是已生成视频的事实，不能用概念图伪装；接缝执行统一读取生产控制文件。

完整链路最终 Prompt 存档和派发前，mainagent 必须自行核对片段接缝事实。凡同一片段块里写“承接 SEGxx”“延续 SEGxx”“上一段”“接续”“接上”或类似物理连续表述，就必须在该片段的输入资产说明里点名对应的真实 `FRMxxx` 或 `<图片N> 是 SEGxx 的真实尾帧/状态帧`；只在全片开头泛写、只写四宫格格位、只写“承接某段尾态”、或用普通概念图代替真实抽帧都不合格。短片直出没有真实可见四宫格和分段尾帧要求，不做这种真实尾帧承接核对。

### 完整示例：十五秒咖啡品牌 TVC

本例独立演示五段式视频 Prompt，与上方饮料四宫格示例不是同一项目。假设咖啡项目已有另一张确认四宫格，以及产品、人物、门店和旁白参考。

编译映射示例：`SEG01` 覆盖 `SH001-SH011`，用户确认简表里的粗节拍映射为 `B01 -> SH001-SH003`、`B02 -> SH004-SH006`、`B03 -> SH007-SH009`、`B04 -> SH010-SH011`。这里的 `B01-B04` 不是最终 Prompt 的四个段落；下方第三部分必须按 `SH001-SH011` 展开为连续镜头时间段。正式任务仍由完整分镜母版产生映射并校验，示例不替代母版。内部映射留在执行记录，交给媒体模型的正文使用具体时间和自然语言。

```text
<图片1>是已确认的四宫格概念图，<图片1-第1格>作为本片0秒首帧视觉基准，锁定咖啡杯将要落在胡桃木吧台上的起始构图、阿宁的右手位置、左前方空白纸带和左侧晨光；<图片1-第2格>锁定纸带折成微缩拱门的中间状态，<图片1-第3格>锁定杯旁半环形纸街的展开状态，<图片1-第4格>锁定纸街收回平整纸环后的品牌尾态。<图片2>是咖啡杯标准资产，锁定象牙白杯身、墨绿杯套、白色杯盖、正面竖排“拾光咖啡”的原字形与位置，作为全片产品依据，不作为另一张0秒首帧；<图片3>是咖啡师阿宁的身份和制服资产，锁定她的手部肤色、米白袖口、墨绿围裙和人物外观；<图片4>是门店空间参考，锁定左侧墨绿拱窗、胡桃木吧台、奶白墙、右后出入口与晨光方向。<音频1>为已确认的成年女性画外旁白音色，声音温和、清楚、气息自然，语速从容，不使用播音式重音或夸张气声。

参考<图片2>中的咖啡杯、<图片3>中的阿宁和<图片4>中的门店，生成“杯子落下，空白纸带折出一条小街，再收回杯旁”的咖啡品牌短片。主体是咖啡杯和由同一条纸带形成的短暂停留空间；阿宁负责真实的落杯动作，不对镜推销。采用<图片1>的四个连续视觉状态与纸艺规则，但按下面的分镜切换机位，不把整张四宫格直接放进视频画面。保留真实产品结构、包装原文、人物身份和空间，不继承资产图的中性图板背景、说明字、其他人物、水印、平台界面或多角度拼图。纸街是品牌想象，不出现功效、销量、价格或未经确认的功能声明。

0.0-1.0秒，开场三镜快切的第一镜，以<图片1-第1格>为起始画面，近景三分之四平视略高机位，阿宁按<图片3>的制服从右侧握住<图片2>杯套侧面，把杯底从吧台上一厘米处压下；左前方无字纸带末端被落杯气流带起，杯套正面字标被<图片4>左窗晨光扫亮。<纸杯轻落木台的闷响>在接触点出现，(轻木质敲击与柔和钢琴开始铺底，速度中等，音量低)，无台词，不加画面文字；动作切在纸带端头弹起的位置。
```

## 符号和输入硬门

| 信息类型 | 写法 | 使用边界 |
|---|---|---|
| 旁白/口播/人物对白/画外音/解说 | `旁白：{具体原文}`、`口播（人物）：{具体原文}`、`人物对白（角色）：{具体原文}` | `{}` 只包逐字可朗读内容，前面必须写清形式和声音主体；不自动生成字幕 |
| 音乐 | `(具体音乐)` | 描述风格、乐器/音色、速度、情绪和层次 |
| 音效/拟音 | `<具体声音>` | 如 `<开罐声>`、`<细密气泡声>`、`<脚步声>`，贴近触发动作 |
| 画面内生成字幕 | `【具体字幕】` | `【】` 只表示用户明确要求模型直接画进视频的字幕；不是旁白或对白，后期/外挂字幕不写进生成 Prompt |
| 画面文字 | `“具体文字”` | 标题、包装、图形标签、真实界面、品牌主张和行动文案；不等于逐句字幕 |
| 图片/视频/音频/主体引用 | `<图片N>`、`<视频N>`、`<音频N>`、`<主体N>` | 仅引用本次真实传入或真实绑定的资产，顺序与输入一致 |
| 四宫格引用 | `<图片X-第N格>` | 指向本次真实输入图的确定格位，裁出单格的输入另保留来源映射 |

用户明确要求英文 Prompt 时，资产标记对应 `<IMGN>`、`<VIDN>`、`<AUDN>`、`<SUBJN>` 和 `<IMGX-PanelN>`；台词、音乐、音效、字幕和画面文字仍保持各自符号边界，素材原文不改写。

- 未真实传入的资产不得写成编号引用；工具不能消费时，不登记假输入，不伪称音色或视频锁定。需要保真的输入不可用时按生产控制处理阻塞，不能通过文本替代硬身份锁。
- `<音频N>` 只指真实音频文件，可用于人物音色、音乐、环境录音或指定声音素材；普通开罐、气泡、键盘、风、门和转场声写 `<具体声音>`。没有上传音乐时可直接写 `(背景中播放着……)`。
- `{}` 只用于旁白、口播、人物对白、画外音、解说或主播念词的逐字可听原文，不能包“温柔女声”“有人声”“说产品卖点”等声音说明或占位词。音色、语速和情绪写在 `{}` 外，例如 `旁白（温和、从容）：{慢一点，也很好}`。
- 音色参考必须在对应台词附近同时绑定声音形式、主体和口型职责。旁白写成 `旁白（按照<音频1>的声音，画面人物不开口）：{具体原文}`；出镜对白写成 `人物对白（阿宁，按照<音频1>的声音，驱动阿宁口型）：{具体原文}`；口播写成 `口播（主播，按照<音频1>的声音，驱动主播口型）：{具体原文}`。非 TVC 默认至少使用其中一种；只有用户明确要求无人声时允许为空。品牌 TVC 还允许按“完整旁白 -> 少量旁白 -> 无旁白”的优先级判断，采用无旁白时逐段写清替代表达，不能用“加入解说”等占位词。
- 未要求画面内字幕时不写 `【】`；不得用 `【旁白原文】` 代替 `旁白：{旁白原文}`。所有画面文字短、准、位置明确，禁止随机小字、假英文、乱码和无关装饰。

## 生成前一次性 Prompt 预检

五段式 Prompt 完整编译后、提交生成前，只执行一次集中预检。这是第二道防线；第一道防线是规划和分镜已经前置设计正确。

1. **五段式**：五段齐全、顺序未变，真实输入编号与职责一致。
2. **核心与主题**：0-3 秒建立核心问题/诱因，中段证明或升级，结尾明确回收；看完能用一句话说出在讲什么。
3. **镜头与节奏**：除 General 简单动态任务和用户明确要求的真实一镜到底外，15 秒视频不少于 `8` 镜，前三秒至少三次信息事件和一次切镜；General 简单动态任务为 4-8 秒且照片动起来固定 5 秒；真实一镜到底只有一个连续镜头；各自均有明确节奏变化和必要收束。
4. **切镜/连续运动地图**：多镜头视频每次切镜都写明时间点、切镜原因、承接锚点和切后新增信息；General 简单动态任务写清启动、发展、反馈和落定/回环；真实一镜到底确认没有任何剪辑，并写清主体路线、摄影机路线、空间节点和连续反馈。
5. **动作桥**：跨镜拿取、递送、佩戴、涂抹、行走、放下和场景移动具有动作起点、路径、匹配动作相位、接触点和反馈。
6. **重复与相关性**：没有同职责、同动作阶段、同构图结果的重复镜头；所有人物、道具、场景和 B-roll 都服务核心、证明、反应、转场或回收。
7. **特效**：既定特效具备叙事节点、触发、变化、反馈、证明和回收；没有临时追加的无来源特效。
8. **文字与声音**：拟声字、功能字、标题和图形与动作/结果同步；台词、BGM、拟音和声音桥不互相冲突。
9. **事实与收束**：产品、人物、品牌、UI 和事实保持；结尾不新增未铺垫信息。

发现问题时，汇总全部问题，只允许一次集中修订：先回写完整分镜，再重新编译受影响的五段式 Prompt；按“用户锁定内容与事实 -> 核心主线 -> 时长与镜头结构 -> 动作连续 -> 声音文字 -> 视觉细节”的顺序尽量一次修订成功，不得只手改 Prompt 导致母版不一致，也不得边检查边多轮重写。修订后只运行一次最终客观校验；除工具无法执行、合规、授权、真实性或必要输入缺失等硬阻塞外，即使仍有未完全解决的内部检查项，也使用当前修订版提交生成，不再继续修改或停止。

该预检不分析生成后的视频画面，不触发自动重生。生成结果按正常流程交付；只有用户明确要求修改或重生时，才按新版本重新确认和执行。

需要压缩 Prompt 时，优先删重复形容词、次要装饰、无来源光效和多余辅助动作，保留核心、镜头地图、动作桥、声音文字和真实输入；不得删除已确认事实、台词或导演必需维度。

错误：`增加数据卡动画，突出效率。`

有效：`3.0-4.2 秒，鼠标点下筛选按钮，灰色列表的三张任务卡依次亮起并向右嵌入“已完成”列，相邻卡片间隔 0.1 秒；第三张落位时状态圆环闭合，轻点击声和短促确认音同步，停 0.4 秒让完成状态可读。` 完整生成继续应用文字、光影与参考合同。

错误：`人物把早餐盘推近，环境从单品证明扩展到早餐场景。`

有效：`7.8-8.6 秒，左手把白色陶瓷早餐盘从画面右边推入，盘沿停在玻璃杯后方约 12 厘米处，吐司边缘冒出两缕细热气，瓶身右侧一颗水珠沿标签边缘滑下；镜头从杯口微距拉到 45 度侧前方中近景，盘沿上方浅绿色圆角标签中的白色粗圆体字“早餐刚好”停留 0.5 秒后淡出。`
