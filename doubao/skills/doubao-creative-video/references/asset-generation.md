# 资产生成与 Prompt 合同

## 职责与读取

本文件管理按需人物/产品/音色资产、写入完整分镜的逐镜视觉与运动执行，以及由母版编译的五段式视频 Prompt。场景、Logo、包装、道具、UI、风格图和参考视频可作为用户输入登记、继承和锁定，不默认生成独立资产。

默认可能生成的图片仅有按条件确需的人物或产品标准资产；它们用于跨片段身份一致性，不承担逐镜画面设计。音色属于音频资产。画面效果直接通过完整分镜和视频 Prompt 的构图、空间、动作、光色材质、摄影机与声音指令实现，不插入预先生图与图片确认环节。

- 创意方向、核心表达、受众与证明逻辑：`references/creative-core.md`。
- 视觉发动机、世界规则、运动与转场机制：`references/visual-motion-playbook.md`。
- 构图、配色、文字排版创意库、字体、光影、运镜和声音设计：`references/audiovisual-craft.md`。
- 分镜唯一母版、节拍/镜头/生成段映射及客观校验：`references/storyboard-contract.md`。
- 阶段顺序、生成授权、素材登记、文件交付、工具、接缝和版本失效：`references/production-control.md`。本文件的“资产生成”是规则分类，不扩大基础资产的生成条件，也不新增视觉设计生产阶段。

## 通用 Prompt 与留档规则

Prompt 使用自然创作语言或完整字段化 PE，不写成 YAML、参数表、字段堆叠或内部执行说明。默认使用纯中文导演描述；仅用户明确要求其他语言时切换，素材原文不擅自翻译。模型、任务类型、生成模式、工具名和调用参数留在执行记录；比例由调用参数设置，只有解释图板布局、画幅裁切或视觉空间确有必要时才在创作描述中写出。

每次真实生图、图片编辑、生视频、视频编辑或版本派生前，静默保存实际使用的完整 Prompt 原文、输入顺序、职责和版本到对应阶段目录。默认不随媒体交付，不在聊天粘贴完整 Prompt，也不展示 Prompt 文件入口；只有用户明确要求查看、排查或交接时才直接文件交付。Prompt 和其他文档不写入画布。

### 示例与默认产物边界

示例中的“拾光咖啡”是虚构教学项目；素材编号和“已确认”仅为示例成立前提，不表示本轮已有真实素材、用户授权或已生成媒体。实际任务必须替换成当前真实输入、确认文案与已校验分镜，不能复制示例品牌、功能、人物或事实。代码块是 Prompt 正文，块外的输入前提、镜头映射和说明只用于理解，不发送给媒体模型。

本文件保留按需人物、产品和视频示例。广告封面、宣传海报或其他普通图片仅在用户明确提出对应图片任务时处理，不是视频生产默认阶段。

先按任务检查全部维度，再把实际相关维度写入 Prompt：没有人物不填表情，没有上屏文字不编排版，没有真实音频不写音频编号。共享要求可在开头统一写明；视频各镜仍须写清本画面的主体、状态、构图与变化，不能用“同上”替代。图片允许“总述 + 分点描述”，视频保持五段式；不得把自然语言描述误写成调用参数表。

## 真实输入与全链路身份锁

先扫描当前画面涉及的真实素材。用户本轮明确上传、指定或批准的参考优先，其次为已确认标准资产，最后才是用户提供的风格参考或明确采用的旧版本素材。每次生图、生视频、编辑、续写和版本派生，都必须重新传入当前画面需要的原始素材或确认标准资产；不能只写“保持一致”或依赖模型记忆。

每张真实输入图按传入顺序逐张点名用途、采用项和剥离项，分别判断人物身份、服装状态、场景结构、道具结构、姿势、构图、色彩、光线、材质和媒介。人物身份只来自身份参考，服装状态只来自服装参考，场景结构只来自场景参考，全局风格只来自已确认风格合同；不能让一张图的人脸、背景、文字、杂物、姿势或临时光线污染其他资产。不给不出场的人物传人物参考，不漏传实际出场产品参考。

| 锁定对象 | 不可擅自改变的事实 |
|---|---|
| 产品/包装 | 轮廓、比例、结构、开孔、按键、部件位置、包装形制、材质、固有色、Logo 位置、包装原文和识别细节 |
| Logo/品牌 | 字形、图形、比例、颜色、组合关系和安全区；不得重绘、翻译、拼错或替换 |
| 人物/角色 | 身份、脸型、五官、年龄感、发型轮廓、肤色、身形比例和身份标记；服装、表情、姿势只按用户要求或已确认分镜改变 |
| UI/场景/道具 | 已确认结构、布局、层级、尺寸关系、识别点；角度和状态变化仍应指向同一对象或空间 |

用户没有上传对应素材时，不得直接声称还原真实人物、产品或品牌。完整模式命中按需资产门，或用户明确要求单独生成标准资产时，先生成必要标准资产并展示确认；首个确认版本成为后续唯一外观基准。短片直出若用户已明确选择“无素材概念方案”，不额外生成独立标准资产；由参数确认、完整分镜和最终 Prompt 的视觉合同共同锁定本条概念视频的虚构外观，并在后续秒段中保持一致。该基准不得被描述成真实产品、真实人物或官方品牌外观。持续引用已确认文件，不得凭同一段描述生成近似替代。更换外观时先确认新资产版本，再按生产控制规则使旧版本下游失效。不得凭空补齐用户素材中未见的真实产品结构或包装事实；未能核实的角度先补充来源或改为明确的概念表达。

创意可以改变已规划的动作、姿势、镜头、尺度、空间、环境材质、光线和世界规则，不能改变身份事实。产品变世界、材质转译、共生融合等手法通过环境、概念层和空间关系实现，真实产品识别面保持准确。所有片段共享当前已确认的标准资产；跨片段同时继承已发生的剧情状态。

参考图忠实度优先于自由发挥。辨不清的元素只描述可见形状、颜色和位置，不命名推断，不补全或纠错原文。排除平台水印、手机状态栏、播放按钮、导出角标、账号水印和分享界面；真实产品 UI、已确认场景中的搜索框或叙事信息框按职责保留，不能与平台覆盖层混淆。文档截图、表格截图、OCR 图只做文字与事实来源，不进入视觉输入清单。

Logo、包装字和精确 UI 无法稳定保真时，使用原素材合成或后期可编辑层，不让模型重画。文字的原文、字体、位置、层级、出现时间和可读停留直接写进分镜与执行计划；不得用乱码占位进入视频。

## 按需一致性资产

短片直出不默认生成独立人物、产品或音色资产，只使用用户已有素材和完整分镜；用户明确要求单独生成标准资产时按该任务授权处理。真实人物、真实产品或真实品牌外观是硬要求但缺少可用素材时，必须等待有效素材或由用户明确改为无素材概念方案。完整模式仅在下列条件成立时生成：

- 人物：同一人物需要跨多个片段反复或长时间出现，且没有可用、已确认的人物参考。
- 产品：视频必须持续呈现同一产品，但用户没有提供可用产品素材，需要先生成并确认唯一产品外观。
- 音色：同一口播者、旁白或角色需要跨多个视频或片段保持声音一致，且确有可生成或可消费的音色能力。

除此之外不建立独立图片资产。场景、Logo、包装、道具、UI、风格图只登记用户素材职责并在完整分镜与视频 Prompt 中继承；不得自动生成场景四视图、道具状态图、风格图、品牌图或其他资产。按需资产 Prompt 必须写成可复用合同，包含统一风格、参考继承/排除、用途、结构、状态、一致性锚点和禁止项。

### 产品

只有完整模式缺少产品素材、且产品需要跨片段稳定出现时，才新建产品标准资产。优先做多角度图，至少包含正面，只有存在真实结构依据时才补背面、侧面、顶部、开合或关键使用状态；不得凭空设计看不到的结构。各视图必须是同一产品、比例、材质、颜色和品牌元素。Logo、包装字、屏幕字或铭文写清原文、所在面、方向和可见程度，精确文字用中文全角引号，如“品牌名”“500ml”“一键启动”。产品资产是全片外观合同，不自动等于视频 0 秒首帧。

#### 完整示例：缺少产品素材时生成标准图

输入前提：用户没有产品图片，但已确认要为虚构“拾光咖啡”生成一只后续跨片段保持一致的外带杯；字标原文、主色和结构均已在参数确认中锁定。首个确认版本将成为唯一产品资产，不是首帧。

```text
统一为自然商业产品摄影，象牙白纸杯、墨绿色纸杯套和哑光白杯盖呈现真实纸纤维与细微压纹，色彩中性清洁，柔和侧光，不加复古滤镜。

生成同一只咖啡杯的横向标准图板，浅中性灰背景，从左到右为正面、背面和右侧三分之四视图，三只视图等高、同一水平基线、间距一致，杯底都真实接触台面并投下短而柔的浅灰阴影。每个视图展示同一件产品，不能改变杯口宽度、杯身收束、杯套高度或杯盖厚度。

杯身为上宽下窄的象牙白纸杯，顶部覆盖哑光白塑料杯盖，杯盖右前方只有一个椭圆饮口；杯身中段包裹一圈墨绿色瓦楞纸杯套，杯套高度约占杯身三分之一，正面中央竖排白色“拾光咖啡”，使用中等字重人文无衬线字、四字等距、整组高度约占杯套六成。背面视图显示杯套纵向接缝和无字背面；右侧三分之四视图让杯盖饮口、杯套厚度和杯身锥度同时可见，正面文字仅按真实转角部分露出，不复制到侧面。

主光从左上方照入，右侧用弱白色反光补足暗部，杯盖边缘保留窄而柔的高光，杯套保持墨绿固有色而非荧光绿。背景不出现装饰、咖啡豆、蒸汽或人物，不生成视图名称、尺寸线、额外标签、水印、二维码和随机小字；不增加把手、吸管、杯盖孔或不存在的包装结构。
```

### 人物

只有完整模式中同一人物需要跨多个片段反复或长时间出现，且缺少可用参考时，才生成稳定身份设定图。默认 16:9 图板、干净中性背景：左侧正面头部近景，头部端正、直视前方；右侧同一角色全身正面、严格 90 度侧面、背面三视图，等高对齐。需要近景身份稳定或多人同框时补头部锚点。

Prompt 写清角色名、年龄、身份、气质、脸型、下颌/头骨、眼睛、眉形、鼻子、嘴、发际线、发型、身形比例、身份标记、服装剪影、装备、材质和颜色。表情中性、肌肉放松、眼睛自然睁开、嘴自然闭合；禁止微笑、皱眉、张嘴、露齿、哭泣、愤怒、惊恐、卖萌或夸张表演。禁止无关文字、水印、字幕和 Logo；真实身份标记或服装上的已确认品牌仍按素材合同保留。

使用角色参考时，继承身份、脸型、五官、发型、身形、服装结构和身份标记，不继承姿势、表情、背景、光线、原画幅、其他人物、无关文字与水印。三视图呈现同一个角色，不得生成多个独立人物。

### 音色

仅完整模式中同一口播者、旁白或角色需要跨视频或片段保持一致时建立 `VOICExxx`。能力可用时生成约 `5秒` 样音并确认，否则只保存文本音色锚点。

音色 Prompt 必须覆盖：

1. 主体身份、表达功能、性别表达、年龄感、语言/口音。
2. 音高/音域、共鸣、明暗、厚薄、颗粒与气息，维度不得互相矛盾。
3. 语速、节奏、停顿、重音、咬字和句尾习惯。
4. 基准情绪、可覆盖情绪，以及极端情绪下不变的声线特征。
5. 禁止播音腔、机械感、过度夹音、夸张气声等不合角色的表演；要求近讲、响度稳定、无噪声、混响和音乐。
6. 样音只用 `1-2` 句短台词；同一主体始终复用同一描述。视频支持音频输入时传入确认样音，否则在每句台词附近复写同一音色描述。

#### 精简模板

```text
为声音主体“[名称]”设计专属音色
[身份/功能]，[性别表达与年龄感]，使用[语言/口音]
[音高音域、共鸣、明暗、厚薄、颗粒、气息]
[语速节奏、停顿、重音、咬字、句尾]
基准情绪[ ]，可覆盖[ ]；即使[极端情绪]仍保持[声线锚点]
禁止[ ]；近距离干净收音，响度稳定，无噪声、混响和音乐
样音台词：[短台词1]／[短台词2]
```

提交前替换全部占位符。样音只用于确认音色，不替代正式台词。

#### 精简示例

```text
为声音主体“林远”设计专属音色
28岁男性调查记者，冷静追查真相，使用自然中性普通话
中低音域、胸腔共鸣、偏冷、厚度适中、轻微颗粒、气息克制
语速偏慢、节奏稳定，关键信息前短停，重音克制，咬字清楚，句尾下沉
基准情绪冷静警觉，可覆盖怀疑与克制愤怒；恐惧时仍保持中低音域和清晰咬字
禁止播音腔、机械朗读、刻意气泡音、夸张哭腔；近讲、响度稳定、无噪声混响和音乐
样音台词：你终于来了／这扇门不该开着
```

## 图片 Prompt 共用规则

以下写法仅用于确实命中条件的人物图或产品标准资产：

1. 先写统一风格和媒介，再写生成目标。
2. 有参考图时逐张说明采用什么、排除什么；无真实输入不得虚构 `<图片N>`。
3. 写清主体、场景、构图、视角、动作瞬间、光色、材质、文字和禁止项。
4. 图片只冻结一个时刻；连续动作和镜头运动写进视频 Prompt。

画面文字统一写成：`位置 + “原文” + 字体形态 + 字号层级 + 颜色材质 + 排版路径 + 遮挡关系`。品牌名、价格、参数、日期和 UI 原文必须有来源；禁止乱码、随机小字和假 Logo。

## 逐镜视觉与运动执行

视觉设计与叙事共用完整分镜，不新增设计卡、独立图板或确认阶段。先读视觉机制与视听工艺，在分镜既有字段中把“要表达什么”落实成“观众在何时看见什么发生”。创意节点数量由内容、时长和动作可执行性决定，不套固定数量，也不为每镜制造新奇观。

### 将画面与运动写进同一母版

- `主体与场景/素材`：明确谁在何处，屏幕左右、朝向、相对距离、前中后景及遮挡；真实素材逐项说明采用/剥离。无素材时写明确的虚构外观与空间，不声称真实还原。
- `画面动作`：写起始状态 -> 触发 -> 运动路径与速度/缓动 -> 接触或变化 -> 可见反馈 -> 结束状态。例如手指先接触按钮再按下，按钮下沉后状态灯亮；不让结果凭空出现。光、纸、液体、文字等概念运动也须有来源、方向、形变规则和落点。
- `镜头语言`：指定景别、机位高度、视角与一个主摄影机动作；写清为何移动、起止位置、跟随对象及焦点转移。固定机位同样有效，不无故叠加推、绕、升、变焦。
- `画面设计`：给出主体的大致画面占比、视觉中心、留白/遮挡、主光方向与软硬、阴影/反射、背景与强调色、材质细节及受光反馈；保持产品、Logo、肤色等真实固有色。用可观察特征替代“高级、电影感、质感很好”。
- `声音与文字`：按动作节点同步拟音和音乐重拍，台词逐字写明说话者及口型职责。需要文字时写原文、位置、字形/字重、层级、入退场、停留及安全区；精确 Logo 或复杂排版用真实素材或后期可编辑层实现。
- `转场/尾态`：写切镜时间、切镜原因、继承的动作相位/方向/视线/形状/声音和下一镜首先看见的状态；同一产品、手部、接触点和轴线不无解释改变。视觉高潮应有前置触发、可见过程、结果反馈和必要停留。

上述内容填写在原有十四列表中，不增加表头，不另存一份平行“视觉母版”。全片共享特征可放在创意说明中，再在各镜写有职责的变化。分镜确认后直接编译视频 Prompt；只在需要更改已确认方向、事实或素材职责时按现有规则重新确认。

### 控制可执行性与观看节奏

每个时间段围绕一个主要观看任务安排一个主动作，次级运动必须由它触发。先保证拿取、递送、折叠、佩戴、开合等过程有足够时间与清楚接触点，再安排切镜；不能用高密度小数秒指令强塞多个复杂形变、换装或空间穿越。共享世界规则、人物/产品身份和物理尺度贯穿全片，局部变化只服务当前信息。General 简单动态任务保留一个主动作与最多两个因果次级运动，写清启动、发展、落定或回环，不强加高潮与多镜头。

在单次生成段内使用从 0 秒开始的局部时间连续覆盖该段时长；全片时间与局部时间的偏移映射保存于执行记录。逐镜持续时间、动作顺序与台词对应保持母版一致，避免把第二段的全片时间误当生成起点。内部 ID 留在执行记录，模型正文仅使用自然导演描述与真实素材编号。

### 写法示例

空泛：镜头推近杯子，展示高级质感。

具体：0.0–1.2 秒，咖啡杯位于画面右侧三分之一、占画面高度约一半，左前方一条无字奶白纸带平贴胡桃木台面；左侧窗户的柔光让杯套纸纹可见，台面反光克制。右手将杯底从台面上一厘米落下，接触时纸带自由端轻抬，杯底阴影由分离变为贴合；固定近景对焦接触点，落杯闷响与接触同步。纸端抬起形成弧线时按同一方向切向其低机位近景，下一镜继续纸端的上弯动作。

这段写法直接进入对应分镜字段和视频 Prompt；纸艺变化只适用于已确认的虚构品牌想象，不扩写成真实产品功效。

## 视频 Prompt 五段式

本节只用于需要创意规划与 Prompt 编译的任务，包括 `media_to_video` 创作新视频。`video_edit` 以及 `media_to_video` 的指定素材修改/用户明确要求原文透传分支，执行工具路由的原文与确认合同，不套本节或额外生成人声、分镜和资产。

最终视频 Prompt 必须从已校验的完整分镜 Markdown 与当前生成段真实素材编译。内部执行包、Prompt 留档元数据和片段清单标明 `SEGxx` 及覆盖的全部 `SHxxx`，保持 `Bxx -> SHxxx -> SEGxx` 一致；提交给模型的正文只写连续时间、自然导演语言和真实素材引用，不写内部 ID。除 General 简单动态任务、用户明确要求的真实一镜到底，以及用户明确要求的慢节奏方案外，15 秒视频最低 `8` 镜，按动作、证明、反应和节奏需要增加，不能为下限拆断动作。General 简单动态任务允许一个或少量镜头，照片动起来固定 5 秒；真实一镜到底只有一个连续镜头。分镜与台词校验读取分镜合同，不能重新发明镜头、台词或素材关系。

用户确认简表的 `Bxx` 是粗节拍，不决定最终镜头或段落数量。最终 Prompt 第 3 段逐镜展开母版内的真实时间与动作链：有观看任务变化才明确切镜；连续动作则保留完整过程，不把全片压成少数静态画面，也不把单一动作机械拆碎。逐镜画面设计直接体现在各时间段的自然导演语言中，不引用内部设计编号。

使用五段式连续文本，顺序不可调整、合并、拆分或省略；逐镜动作与镜间连续性分别落实在第 3 段和第 4 段。

多生成段按下面的唯一编译顺序执行：

同一 `video_N` 的多个 `SEGxx` 是同一条连续视频的分段生成，不是独立创意。每份五段式 Prompt 都必须继承同一核心主线、人物身份与服装、产品/包装与品牌资产、按方案继承或变化的场景与光色材质、声音系统、视觉机制和已经发生的剧情事实；当前段只能继续推进自己负责的下一段剧情，不能重新介绍主体、重启钩子、重置状态或另做一条完整短片。

1. 按 `SEGxx` 把完整分镜分组；每组只能包含时间连续的 `SHxxx`，每个镜头必须且只能进入一个生成段。
2. 每个 `SEGxx` 独立编译一份完整五段式 Prompt，不把多个生成段合并成一份 Prompt，也不把一个生成段拆成多份互相重叠的 Prompt。
3. 第 1 段只写当前生成段实际传入的素材，以及非首段在物理连续接缝中必需的真实尾帧；第 2 段只绑定当前段实际出现的主体及本段生成目标。
4. 第 3 段按当前 `SEGxx` 内的 `SHxxx` 顺序逐镜投影时间、动作、镜头、声音、文字、新增信息和尾态，不新增、不遗漏、不重复镜头或台词。
5. 第 4 段由当前段内相邻镜头的“前镜尾态 -> 切镜理由 -> 承接锚点 -> 后镜起态”编译；非最终 `SEGxx` 还必须留下可供下一段消费的明确尾态。
6. 第 5 段继承全片一致性与禁区，再叠加当前生成段特有风险。
7. 编译后核对全部镜头恰好覆盖一次、时间连续、台词逐字一致、素材编号真实，非首段物理连续时存在上一段真实尾帧输入；核对构图、光色材质、动作路径、摄影机和声音节点没有在编译时丢失。问题按分镜合同分类：硬门修正并复核或暂停，创意建议并入最多一次集中优化。

1. **输入资产定位与 0 秒基准**：按真实顺序解释当前段实际传入的图片、视频和音频用途；标准资产只锁定身份/结构，不自动充当开场画面。用具体文字写清 0 秒主体位置、占比、朝向、姿态、空间层级、光源与道具状态。无图片时直接描述，不编造引用。非首段需要物理连续时，注明 `<图片N>` 是上一段视频的真实尾帧/状态帧及其承接职责；没有可消费的真实输入时，按生产控制改为已确认的时间省略或跳切方案，不能仅凭文字假称连续。
2. **参考主体绑定与生成目标**：绑定主要主体、产品、人物、品牌、场景及来源；逐项说采用和剥离什么，排除无关人物、字幕、水印、二维码、平台覆盖层、乱码、竞品专属视觉与未授权元素。
3. **逐时间段动作、声音与脚本**：连续覆盖当前段全时长。按母版逐镜写起始状态及对上一镜的承接、主体与空间、触发、运动对象/方向/路径/速度、接触与反馈、结束状态、景别/机位/一个主运镜、构图占比、光色材质、声音节点、文字及新增信息。跨镜动作同时写前镜发起与后镜续接，不能省略空间位移。有真实参考时在对应镜头说明采用的外观或空间约束；无参考则直接具体描述。可听语言标明形式和主体，逐字原文完整放入 `{}`，例如 `旁白：{这一刻，城市重新醒来}`；画面内字幕才使用 `【】`，标题、品牌字和标签使用 `“”`。采用已确认的无人声策略时逐镜写清替代表达，不留旁白占位。
4. **转场与尾态收束**：独立描述本段能生成和验收的转场、画面落点、声音余韵；逐个切点写成“前镜结束状态 -> 切镜理由 -> 承接锚点 -> 后镜开始状态”，不能只列转场名称。中间生成段留可承接尾态，不重复完整开场或最终品牌收束；单条短片和最终段写完成动作、产品/人物/品牌落点及自然声音收束。开头与结尾构图相似时必须明确可见状态差异和新意义。
5. **全片一致性与禁区**：复写统一风格的可观察特征、主体/产品/人物/品牌/场景/道具/光线/音色/尾态保持项；按当前风险限制随机字幕、乱码、水印、二维码、平台 UI、额外主体、产品变形、身份漂移、手部异常、抖动、闪烁和无来源光效。

### 每个时间段的导演维度

时间段按可执行镜头或连续动作段组织，不强制切成 0.5 秒。若为了可读性合并相邻内容，必须保留原有动作顺序、观看关系、信息增量和转场落点；内部微拍可以是同镜动作，不要求至少一次切镜。若一个动作跨越两个镜头，必须把前镜结束姿态和后镜开始姿态写成同一个连续动作桥，不能让人物、手、产品或道具瞬移。

每条视频的最终 Prompt 至少安排一个完整“动作桥”或“信息桥”：写清前一状态、触发动作、运动路径、切点或镜内调度、后一状态和反馈。例如“手捏住薯片 -> 手向左上送向嘴边，薯片保持同一朝向 -> 在手腕越过下巴时动作中切到侧面中近景 -> 同一只手继续移动并把薯片送到唇前 -> 咬合发生”。动作桥优先于蒙太奇；只有并行比较、节奏冲击、观点列举或反应接力确实需要时才使用三镜蒙太奇。

最终 Prompt 要显性写出观看路径，而不是追求镜头多变。景别、机位、视角、运镜、遮挡和焦点只在观看任务变化时改变：先建立空间/主体关系，再靠近动作或证据，最后回看反馈/结果。相邻镜头不得无锚点地在全景和特写之间往返；需要跨级时，用动作中切、视线目标、主体同位置、遮挡峰值、形状匹配或声音重拍连接。连续同类镜头若属于同一动作链可以保留，否则合并。

最终 Prompt 必须有可执行的节奏语法；本节全部事件数量、镜长与尾帧阈值均服从主 Skill 的慢节奏例外。除 General 简单动态任务、用户明确要求的真实一镜到底，以及用户明确要求的慢节奏方案外，15 秒及以内视频前三秒至少包含 `3` 个可见信息事件和 `1` 次有意义切镜/观看关系变化，第一镜通常不超过 `1.2` 秒；开场必须有异常、冲突、主动入场、声音触发或问题与证据并置，禁止静止产品、固定人物和诗集式单画面。General 简单动态任务不强制切镜，首秒启动可见运动并在 4-8 秒内完成状态发展，照片动起来固定 5 秒；真实一镜到底只写一个连续镜头，通过主体路线、摄影机路线、空间变化和动作反馈持续推进。存在普通静态尾帧时只保留 `0.6-1.0` 秒；Loop 或持续运动到结束时可以不设静态尾帧。快来自事件推进和加速度，不来自无锚点硬切。

最终 Prompt 不允许用一个孤立动词撑满长时间段。单个时间段超过 `1.5` 秒，至少写出一个主动作及其二级变化或反馈；超过 `2` 秒，必须写成至少三个连续事件组成的小过程，并说明每一步如何改变画面信息。若一个长段落只有“旋开、探入、涂抹、拉远、停住”这类单一动作，优先补齐动作前后路径与反馈；只有观看任务确实变化时才拆镜。动作链优先使用人物、产品、手、皮肤、界面、文字、材质、光线和环境之间的因果接力，而不是让同一动作慢慢完成。

每段至少有“触发 -> 变化 -> 反馈 -> 落点”。只旋转产品、转头、抬手、推镜、环绕而没有改变问题、因果、证明、反应、场景结果或品牌归属，只算运动。除尾帧定版、关键证明与可读停留，不允许静态姿态、无信息慢推或同一动作换角度填时长。需要执行黄金三秒切镜规则的视频，前 3 秒至少写 `3` 个连续信息事件和 `1` 次有意义切镜/观看关系变化；General 简单动态任务改写为首秒启动及连续状态变化；真实一镜到底禁止切镜并按连续空间与动作节点推进。超过 2 秒的段落写清至少三个实质动作或状态阶段，事件可在同镜完成。眼神、呼吸、灯闪只能作为辅助，除非用户明确要求的就是对应轻微动作或氛围变化。

当前场景状态逐段更新：主体站位、道具相对位置、光源变化、背景运动、空间声源、地面/桌面/屏幕/包装/界面状态，以及上一段尾态如何延续。不能只列“停车场”“厨房”“办公室”；要写灯管闪动、积水倒影、任务卡归列、水珠滑落等可见状态，并让它服务人物心理、产品证明、品牌情绪或信息关系。

逐镜画面直接写清可观察特征：主体占比与站位、前中后景、主光方向/软硬/投影、固有色与环境色、材质纹理及受光变化；再写起始状态、手/眼/身体接触点、运动路径、速度/缓动、中间状态、镜头跟随、声音同步、文字入退场和尾态。避免“高级感、科技感、展示质感、镜头横移露出细节”等空泛意图。维度按本镜职责取舍，共享特征可在第 5 段集中声明，关键差异仍须落到对应时间段；一个主视觉规则和少量有因果的动作优先，不能为密度堆叠特效。

切镜写“何时切、因何切、切到哪里、切后首次看到什么”。动作切、视线切、声音桥、形状匹配、遮挡切或因果切均须有锚点。例如“包装撕口声先响，切袋内极近景，碎屑冲向镜头遮挡，切到街道灯牌逐个亮起”。相邻段不能只是换景别或文案，要改变位置、方向、视角来源、图形状态、规则、光线动机、节拍、反馈、心理、信息层级或叙事压力。

每个玩法段写一个具体小惊喜：入口如何打开、声音如何变成力量、手势如何改变现实、文字如何进入空间、界面如何接管场景、旧状态如何退场；最后回到信息或情绪判断。禁止“证明冷藏清爽”“环境扩展”“体现专业能力”等意图句替代可见动作。

声音写层级：BGM 的乐器/音色、速度、情绪职责与人声避让，拟音绑定真实动作。画外旁白、解说或内心独白注明画面人物不开口；对白/口播明确说话者与口型。台词密度服从主入口的声音约束，不靠加速规避。

画面文字逐条写清原文、位置、字形、层级与遮挡关系，再补出现时机、职责、入场/退场、停留时长、描边/阴影/底板和安全区。例如：`右上安全区显示窄体无衬线中黑白字“已连接”，贴在屏幕状态槽内，0.2 秒淡入，停 0.6 秒后随切镜消失`。数值、分数、比例、排名、用时、价格、温度、库存、步数、进度和图表必须有来源，写清起止值、单位、路径、中间状态触发、数字字体和可读停留；无来源只用“未完成”到“完成”等概念状态，不编造数据。

内部句式仅用于确保维度完整，最终仍写自然导演语言：

```text
X-Y 秒，[主体及参考来源] 在 [当前场景状态] 中由 [动作/声音/台词] 触发 [具体变化]；
镜头以 [景别/机位/角度/一个主运镜] 拍摄，[光色/材质/构图] 指向 [可见证明锚点]；
[图形/文字] 从 [起点] 沿 [路径/速度/缓动] 到 [真实落点] 并停留 [时长]；
声音为 [人声原文/音乐/拟音]，在 [动作节点] 同步；
段尾停在 [尾态]，新增 [信息/关系/结果]，保持 [锚点] 并避免 [当前风险]。
```

### 视频 Prompt 覆盖与真实输入

编译后，完整分镜内的主体、起止状态、动作路径、构图、光色材质、摄影机路线、文字与声音均须在对应时间段找到落点；全片共享要求可以统一写在第 5 段，但不能因此省略触发、过程、反馈与镜间承接。禁止把细分镜压缩成“照分镜生成”“同上”或几句抽象风格词。

参考素材只锁定其已确认职责。人物/产品标准资产不自动承担开场构图；用户明确提供起始画面时才说明 0 秒的真实图像依据。需要从多视图素材采用某个外观时，提取对应干净图并按实际输入编号绑定，保留来源映射，不把拼图布局带入视频。无图片输入时直接描述 0 秒画面与后续运动，禁止虚构编号或让任务等待图片确认。

有视频输入时只继承所需连续性、主体、场景、风格或运动，不复刻完整剧情、字幕、水印与界面。跨生成段需要物理连续时，使用前段真实视频或从其抽取的真实状态帧；在当前段输入中点名并锁定主体位置、朝向、接触点与光线。文字中的“延续上一段”不能替代真实输入。接缝执行读取生产控制规则；单段视频无需建立跨段接缝。


### 完整示例：无参考素材的五秒简单动态

输入前提：用户已确认虚构纸艺场景、5 秒、一个固定镜头、无人声和无画面文字；本例为 General 简单动态任务，没有真实媒体输入。以下五段直接用于视频生成，无需图片准备。主体、构图、动作和声音描述都来自同一完整分镜。

```text
0 秒，一架无字朱红色纸飞机已处于画面左侧半空，机头朝右，机翼展开，占画面宽度约五分之一；奶白桌面贯穿下半画面，中央偏右立着一个无字奶白纸拱门，飞机与门洞处于同一高度。前景仅有机身投影，后景为浅暖灰墙，左上方大面积柔光投下短软影，纸面折痕可见，画面无人物与其他物品。

生成红纸飞机沿一条连续路线滑过纸拱门、最后落在门后桌面的纸艺短片。固定略俯的中景，飞机形状、尺度和纸色保持一致，拱门位置与门洞尺寸不变，沿途都能看清飞机和门洞关系。

0.0–0.8 秒，轻微气流推动纸飞机从左向右进入门前区域，机头平稳向前，软影在桌面同方向滑行，传来低而轻的风声。0.8–3.8 秒，机头先越过门洞，双翼保持水平并依次通过，纸拱门先遮住机头再遮住尾部；机尾离开门洞后飞机略向下滑，投影与机身距离逐渐缩短，气流声减弱，左侧受光与背光面的层次保持一致。3.8–5.0 秒，飞机减速，机腹在 4.2 秒接触门后桌面，纸翼轻颤一次后于 4.4 秒落稳；纸面接触的轻响与落点同步，保持最后 0.6 秒完整构图。全程无切镜、无台词、无音乐、无画面文字。

整体保持真实纸纤维、可见折痕、朱红主体与奶白环境、左上柔光和固定空间尺度。禁止额外飞机、文字、水印、无来源粒子、飞机穿过拱门实体、纸翼变形、随机镜头移动和亮度闪烁。
```

| 画面文字 | `“具体文字”` | 标题、包装、图形标签、真实界面、品牌主张和行动文案；不等于逐句字幕 |
| 图片/视频/音频/主体引用 | `<图片N>`、`<视频N>`、`<音频N>`、`<主体N>` | 仅引用本次真实传入或真实绑定的资产，顺序与输入一致 |

用户明确要求英文 Prompt 时，资产标记对应 `<IMGN>`、`<VIDN>`、`<AUDN>`、`<SUBJN>`；台词、音乐、音效、字幕和画面文字仍保持各自符号边界，素材原文不改写。

- 未真实传入的资产不得写成编号引用；工具不能消费时，不登记假输入，不伪称音色或视频锁定。需要保真的输入不可用时按生产控制处理阻塞，不能通过文本替代硬身份锁。
- `<音频N>` 只指真实音频文件，可用于人物音色、音乐、环境录音或指定声音素材；普通开罐、气泡、键盘、风、门和转场声写 `<具体声音>`。没有上传音乐时可直接写 `(背景中播放着……)`。
- `{}` 只用于旁白、口播、人物对白、画外音、解说或主播念词的逐字可听原文，不能包“温柔女声”“有人声”“说产品卖点”等声音说明或占位词。音色、语速和情绪写在 `{}` 外，例如 `旁白（温和、从容）：{慢一点，也很好}`。
- 音色参考必须在对应台词附近同时绑定声音形式、主体和口型职责。旁白写成 `旁白（按照<音频1>的声音，画面人物不开口）：{具体原文}`；出镜对白写成 `人物对白（阿宁，按照<音频1>的声音，驱动阿宁口型）：{具体原文}`；口播写成 `口播（主播，按照<音频1>的声音，驱动主播口型）：{具体原文}`。非 TVC 默认至少使用其中一种；只有用户明确要求无人声时允许为空。品牌 TVC 还允许按“完整旁白 -> 少量旁白 -> 无旁白”的优先级判断，采用无旁白时逐段写清替代表达，不能用“加入解说”等占位词。
- 未要求画面内字幕时不写 `【】`；不得用 `【旁白原文】` 代替 `旁白：{旁白原文}`。所有画面文字短、准、位置明确，禁止随机小字、假英文、乱码和无关装饰。

## 生成前一次性 Prompt 预检

五段式 Prompt 完整编译后、提交生成前，集中预检；硬门修正后的复核不受一次创意优化次数限制。这是第二道防线；第一道防线是规划和分镜已经前置设计正确。

1. **五段式**：五段齐全、顺序未变，真实输入编号与职责一致。
2. **核心与主题**：0-3 秒建立核心问题/诱因，中段证明或升级，结尾明确回收；看完能用一句话说出在讲什么。
3. **镜头与节奏**：除 General 简单动态任务、用户明确要求的真实一镜到底，以及用户明确要求的慢节奏方案外，15 秒视频不少于 `8` 镜，前三秒至少三次信息事件和一次切镜；General 简单动态任务为 4-8 秒且照片动起来固定 5 秒；真实一镜到底只有一个连续镜头；各自均有明确节奏变化和必要收束。
4. **切镜/连续运动地图**：多镜头视频每次切镜都写明时间点、切镜原因、承接锚点和切后新增信息；General 简单动态任务写清启动、发展、反馈和落定/回环；真实一镜到底确认没有任何剪辑，并写清主体路线、摄影机路线、空间节点和连续反馈。
5. **动作桥**：跨镜拿取、递送、佩戴、涂抹、行走、放下和场景移动具有动作起点、路径、匹配动作相位、接触点和反馈。
6. **重复与相关性**：没有同职责、同动作阶段、同构图结果的重复镜头；所有人物、道具、场景和 B-roll 都服务核心、证明、反应、转场或回收。
7. **特效**：既定特效具备叙事节点、触发、变化、反馈、证明和回收；没有临时追加的无来源特效。
8. **文字与声音**：拟声字、功能字、标题和图形与动作/结果同步；台词、BGM、拟音和声音桥不互相冲突。
9. **事实与收束**：产品、人物、品牌、UI 和事实保持；结尾不新增未铺垫信息。

发现问题时按 `references/storyboard-contract.md` 分类处理：可执行性硬门必须修正并复核或暂停，不受一次创意优化次数限制；创意、审美和内部密度建议最多集中优化一次。先回写完整分镜，再同步编译受影响的五段式 Prompt，禁止擅改用户台词；只有普通创意建议未达标时才可继续，不把未通过记为通过。已确认方案实质变化重新确认；不因本节增加媒体重试或生成后重生。

该预检不分析生成后的视频画面，不触发自动重生。生成结果按正常流程交付；只有用户明确要求修改或重生时，才按新版本重新确认和执行。

需要压缩 Prompt 时，优先删重复形容词、次要装饰、无来源光效和多余辅助动作，保留核心、镜头地图、动作桥、声音文字和真实输入；不得删除已确认事实、台词或导演必需维度。

错误：`增加数据卡动画，突出效率。`

有效：`3.0-4.2 秒，鼠标点下筛选按钮，灰色列表的三张任务卡依次亮起并向右嵌入“已完成”列，相邻卡片间隔 0.1 秒；第三张落位时状态圆环闭合，轻点击声和短促确认音同步，停 0.4 秒让完成状态可读。` 完整生成继续应用文字、光影与参考合同。

错误：`人物把早餐盘推近，环境从单品证明扩展到早餐场景。`

有效：`7.8-8.6 秒，左手把白色陶瓷早餐盘从画面右边推入，盘沿停在玻璃杯后方约 12 厘米处，吐司边缘冒出两缕细热气，瓶身右侧一颗水珠沿标签边缘滑下；镜头从杯口微距拉到 45 度侧前方中近景，盘沿上方浅绿色圆角标签中的白色粗圆体字“早餐刚好”停留 0.5 秒后淡出。`
