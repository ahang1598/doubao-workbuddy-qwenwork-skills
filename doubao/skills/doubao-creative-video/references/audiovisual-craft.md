# 视听工艺：把既定内容拍清、听清

## 文件说明与索引

本文件只维护摄影、美术、表演、文字、剪辑与声音的具体做法，以及成片的有效变化与叙事密度。内容选什么、文案怎样连写见[第一阶段](creative-core.md)及类型文件；镜头的时间安排、人声选择与正式声音时间轴见[分镜合同](storyboard-contract.md)；效果运动见[视觉方法](visual-motion-playbook.md)。按当前问题查，不把所有手法叠进同一条片。

| 当前问题 | 章节 |
|---|---|
| 拍得平、重点没被看见 | 节奏与重心、构图、运镜、布光 |
| 有效果但看不清、没有力度 | 关键画面的注意与力度 |
| 切换突兀、动作与空间混乱 | 镜间因果与剪辑连续性、转场和剪辑 |
| 字太多、读不清、像装饰 | 画面文字、排版创意、真实 UI 与层级 |
| 音乐无作用、音效生硬 | 声音结构 |
| 人像念稿、动作机械 | 表演和人物动作；语言本身先回第一阶段改 |

## 视听诊断索引

写作与分镜设计按具体需要查下表方法；

| 维度 | 必问 | 失败信号 |
|---|---|---|
| 运镜 | 镜头运动是否推进信息、证明或情绪？ | 只有推进、环绕、展示、定格 |
| 布光 | 光线是否服务质感、氛围、证据或主体分离？ | 无来源光效、主体和背景糊在一起 |
| 构图 | 视线重点、产品、人物和文字是否清楚？ | 主体不稳、产品被遮、文字压住关键信息 |
| 色彩 | 颜色是否服务品牌、情绪或节奏变化？ | 每镜乱变，或所有视频都套同一种流行色 |
| 转场 | 内容、动作、对照、论据或时间关系能否承接，需要时再用视听匹配？ | 花哨但不承接内容，或为加转场补无效动作 |
| 连续性 | 物理动作是否接续，章节、时间变化或并置是否可理解？ | 连续动作状态凭空跳变，或新场景缺少理解必要的关系 |
| 相关性 | 每个主体、道具和插镜是否服务当前主线？ | 为丰富画面加入无关物品、人物或环境 |
| 重复度 | 再次出现的画面是否改变了意义或状态？ | 同画面停留、重复反应、回到开场但没有变化 |
| 音效 | 声音是否绑定动作和节奏重拍？ | 音乐只是背景，拟音无触发点 |
| 文案 | 文字是否增加记忆、解释或行动？ | 重复画面、广告腔、长句、乱码风险 |

## 节奏与重心设计规则

### 默认变化与叙事密度

用户没有明确要求舒缓、慢节奏或一镜到底时，默认采用利落、持续推进的多镜表达，尽量每 1–2 秒出现一次清晰可感知的有效镜头变化或信息推进。高端、电影感、治愈、诗性、ASMR、观察、极简等类型或风格标签本身不构成放慢或一镜到底的授权。以下数量是成片内容与表现标准，不改变分镜表格式、制作阶段或生成段安排。

- **15 秒：至少 10 次有效镜头变化或信息推进。** 切入有新观看收益的镜头，或同镜内出现清楚的新证据、动作阶段、结果、人物回应、观看关系与信息揭示，均可计入；不要求交付 10 个卖点。
- **30 秒：默认按 22 个有效分镜规划。** 每个分镜是实际镜头，均须有具体观看职责与合理承接；同一镜内的多个推进不能折抵分镜数量。镜内仍可继续增加有效变化。
- **其他时长：尽量保持每 1–2 秒一次有效变化。** 不按整齐秒点机械切镜，不将上述两种时长的数量机械套到所有片长。

有效变化要让观众比上一刻多看清、知道或感受到一项具体内容，并服务同一条动作、论述、情绪或视觉主线，例如整体定位后看关键接触，接触后看结果，结果后看人物取舍；音乐、感官与纯视觉内容可通过可辨认的材质、运动关系、层次、节律变奏或视觉发现推进，不强加新事实和剧情。多种效果同时服务同一次揭示，只计一次推进；把同一次动作改名成多个阶段也不能重复计数。相邻阶段需在画面或声音中实际可辨，不能只在分镜说明里声称有变化。

**合理保留与变化计数分开判断。** 必要的阅读、观察、反应和节律积累可以保留，但同一信息的持续阅读、同一状态的覆盖角度或同一反应的延续，不因拆镜、改名或增加装饰就多算一次推进。新增的证据、观看关系、反馈、发现或可辨认的感官与节律变奏可以计数，不要求每次变化首次交付知识。30 秒的实际分镜也须逐镜提供具体的观看增益与承接，不能把无差别覆盖镜头计入 22 镜；必要停留按其作用安排时间，其他镜头补足相关有效内容。

本文件的密度标准与分镜合同的观看任务、正常对白、完整动作和必要阅读要求共同适用：前者约束成片的有效内容数量与分布，后者约束这些内容如何合理占用时间。不能因合同正文未列数字而忽略密度，也不能用密度数字覆盖关键过程或阅读需要；数量不足时回到相关内容和表达补足，不机械拆动作或减掉主要信息。

无观看增益的换角度、同一结果反复特写、随机插镜、重复口号、装饰花字、闪白、光扫、匀速推拉与发光，均不能凑数。数量不足时先增加与主线有关的证据、对照、反馈、发现或必要动作阶段，再选择能成立的切点；不得编造产品事实、添加无关卖点、打断关键过程或牺牲理解来增加数量。

1–2 秒是推进节奏，不是每镜的硬性上限。关键动作、结果辨认、文字阅读和人物回应确需更长时可保留必要时间，期间有合理的新阶段就安排镜内推进，并从其他内容处压缩无效停留；不能让较长停留成为全片默认舒缓的理由。达到总数后仍须检查分布，不能开头密集凑完、后半段长时间无推进；人声可以跨镜连续表达，画面变化不要求台词逐镜重起。

**例外只由用户指令启用。** 用户明确要求舒缓或慢节奏时，可按所需观察、感受与阅读时间降低密度；明确要求一镜到底或全程连续展示时，保留连续拍摄，免于切镜数量要求，以镜内动作、状态与发现推进。只要求一镜到底不自动等于舒缓，只要求舒缓也不自动改成一镜到底；两者都保留合理变化，不能空转。局部慢动作、短暂停顿或一个较长镜头本身不构成全片豁免。简单动态与局部编辑保留用户指定的动作、构图和编辑范围，不因题材简单自动套用舒缓或一镜到底例外。用户明确限定“保持同一构图，只让指定动作或循环全程连续发生”等具体内容时，按其明确的连续展示意图保留范围；不强求用户必须说出“一镜到底”四字，也不为默认镜数添加无关剧情和切镜。仅说“自然动起来”、固定机位或某种风格，不单独构成全程连续或舒缓的要求。

### 理解、承接与内容充实同时成立

**理解和承接是有效变化的前提，内容充实与变化密度也必须同时满足。** 观众无法定位主体、缺少理解必要的前提、不知道前后关系或来不及看清关键结果时，即使画面发生变化也不计入有效推进。不得为了凑镜头数牺牲连贯性；也不得以“让观众看懂”为由，默认放慢、减少有效镜头、削掉主要信息或把有发展的内容改成一个简单动作。沿用上文的数量、分布和用户明确指令例外，不另开降低密度的例外。

- **全片有可跟随的主线。** 仅凭实际画面、人声与可读文字，应能概括这条片在讲什么、核心判断或体验如何形成。多卖点、多人物与并行叙事可以保留，但需围绕共同任务、主题或明确关系展开；不把“主线清楚”解释成只留一个卖点或强制编成单一人物故事。每个变化都能说明与当前主线的关系；概括用于内容判断，不另交说明表。
- **每个推进节点有主要注意对象。** 关键动作、新观点和需要逐字阅读的复杂文字错开主导时刻；画面、声音与文字可共同表达同一意思，补充信息不能争抢理解。优先调整出现顺序、主次与保持时间，不靠删掉主要信息解决负担。
- **新信息有必要前提与消化时间。** 关键人物和物件可辨认，反应有对象，结果有可理解的来源；新地点、时间省略或并行线切换有必要线索。可以悬念、反转与结果前置，但应有可跟随的线索并兑现解释。关键证据、动作反馈和必要文字看清后再转移重点，不用突然补设定、闪白或音效遮掩缺环。
- **承接可以直接而清楚。** 因果、对照、回应、论据递进、时间或章节关系成立即可直切；物理连续动作另保护方向、相位与状态。形状匹配、同色和卡点只能辅助，不能代替内容联系；不为“过渡自然”补一串无效走路、拿放与环境空镜。
- **保留主要信息与内容发展。** 保留用户锁定内容、主要卖点或观点、关键证据、必要条件、人物选择与回应、视觉或感官的发展层次。可以压缩套话、重复结论、重复角度和无关装饰；不能把有依据的不同信息一并删掉，或用一句口号替代解释与证明。
- **通过重写提高可理解密度。** 先重排相关信息、补足最短的必要前提、把抽象说法换成具体证据、让声画分工并用连续人声跨镜连接，再压缩无效停留。删并无效镜头后，应以相关的新证据、对照、发现、反馈、选择或结果补足有效内容和密度。不得虚构事实或把同一次动作细分改名；也不把全部信息挤到旁白、花字或结尾。

设计完成时同时判断：观众此刻已知道什么、下一步还需知道什么、此次变化如何承接、信息是否可感知，以及全片是否达到数量与分布要求。数量达标不自动代表叙事成立；关系顺畅也不自动代表内容充实。发现缺口就改受影响的内容与表达，不新增审片、确认或执行步骤。

### 重心与内容展开

承接第一阶段写法已确定的事件顺序，下面把它转成强弱和停留；实际声画无法传达看点时，按[阶段分工](creative-core.md#第一阶段确定到什么程度)回改同一方案。表中“悬念揭幕、证明链路”等名称是对应关系，具体快慢可在下一节波形中细化，不要求两张表各选一套。

| 节奏曲线 | 适合 | 时间推进 |
|---|---|---|
| 悬念揭幕 | 新品发布、高端产品、品牌预热、汽车/3C | 局部线索 -> 细节释放 -> 完整揭示 -> 信息落版 |
| 动作闭环 | 产品演示、UGC、教程、开箱、运动饮品 | 触发动作 -> 产品反馈 -> 结果状态 -> CTA/记忆 |
| 生长递进 | 天然、食材、鲜奶、护肤、包装生成、品牌生命力 | 微小起点 -> 逐步生成 -> 尺度打开 -> 产品收束 |
| 奇幻转合 | 零食、宠物食品、美妆、节庆、童趣创意 | 熟悉场景 -> 异常触发 -> 语义变身 -> 产品解释 |
| 证明链路 | 科研、清洁、企业服务、SaaS、源头产地 | 问题/源头 -> 过程证据 -> 使用落地 -> 可信结论 |
| 情绪升温 | 露营、徒步、香氛、服饰、品牌形象 | 有效动作/关系进入 -> 情绪随事件变化 -> 结果或回应完成即收 |
| 并行汇聚 | 多人物、多场景、多 SKU、活动预热 | 各线准备 -> 同步推进 -> 合流高光 -> 群像/产品尾帧 |

构思节奏时先找开场、核心成立点和收束职责，再按完整事件安排中段，不套固定秒数。按分镜合同写全逐镜内容与声音时间：

```text
开场：尽快给刺激、承诺、主体、问题、产品线索或异常规则，不能空。
动作展开：让主动作从起点连续走到接触、触发或第一次结果。
核心成立：在最适合当前内容的位置给最强证明、最大视觉变化或情绪高点。
结果回收：高光之后给反馈，再回收产品、品牌、人物状态、主题字或行动。
```

黄金三秒用于建立观看承诺。开场的动作、承接和时间安排执行 `storyboard-contract.md`，有效变化与叙事密度执行上文标准。可用异常结果前置、强动作冲突、主体主动入场、声音触发画面变化或问题与证据并置来落实已定开场，不把这些选项当作所有内容的必填类别。General 简单动态任务首秒启动可见运动并持续产生状态变化，不为满足密度编造剧情；是否采用连续镜头或舒缓节奏以用户明确指令为准。真实一镜到底通过主体行动、可见状态或必要的空间关系变化推进，不要求移动摄影机。任何视频都禁止无意义静止、空转慢推或只靠发光撑满前三秒。

视频超过 15 秒时延续全片已定结构，增加新的证据、反应与升级，不把多个独立短片简单拼接。

重心检查：

- 每个镜头都要写一句“本镜头推进什么”。推进可以是判断、操作、理解、观察发现、音乐段落、感官层次、人物关系、情绪、品牌识别或行动；按本片任务判断，不把它们变成每镜必填标签。
- 在文字分镜设计时，相邻两镜不能只换角度展示同一件事。第二镜应承担更近的证据、更清楚的动作、更强的反应、更明确的文字或必要的主体辨认，否则合并或回改内容；不另建“镜头地图”。
- 按当前内容检查主体动作、观看位置、画面状态、剧情/信息或音乐发展中哪些正在变化，不要求每镜同时满足四层。单纯让人物抬手、产品变大/旋转、镜头慢推/环绕/拉远、边框发光或背景轻微变化，只算低信息运动，不能替代观看关系和叙事状态变化。按分镜合同落实局部推进与镜长；变化可以在镜内发生，不要求机械切镜。
- 镜头较长时，按分镜合同检查镜内是否形成可分辨的动作或状态阶段，例如“发现 -> 靠近 -> 接触 -> 反馈”，让观众能跟随动作、观看关系或信息状态的实际变化。General 简单动态任务可用“启动 -> 发展 -> 落定/回环”，真实一镜到底可用连续动作、空间节点或观看目标变化形成这些阶段，固定机位也可以成立。没有具体观察、阅读或反应职责，只靠匀速推拉、主体渐大、发光增强、人物微动、悬浮或静态停留撑时长，判定为拖沓，必须重写调度；只有多镜头方案才通过拆镜解决。
- 慢镜头必须有实质观看职责：动作触发新状态、视线发现新对象、空间关系改变、证据逐层显露、文字与结果同步落位，或完成已说明的观察、阅读与回应。光扫、轻推、轻微表情和环境音变化只能作为辅助，不能单独算一个新节拍。所有任务都不留无职责的缓慢空镜；空间建立、证据消化、情绪转折、声音桥或品牌资产显影确有需要时，按分镜合同保留必要时间，快慢取决于观看职责。
- 快剪必须有保留点：产品名、包装、UI 状态、价格/优惠、品牌主张、人物反应和 CTA 必须有可感知停留。
- 尾帧的时长与信息边界按分镜合同；把必要结果反馈放在收束之前，复杂发布或合规文字另按明确阅读职责安排。

## 短片节奏与切镜导演法

按上文的默认变化与叙事密度，以及分镜合同的动作、阅读和尾态要求，先找主动作完成点、证明成立点、高光点和结果回收点，再用下面波形分配中间时间。它们是不同内容的替代排法，不套固定秒段，也不要求使用全部变化；一镜到底、舒缓排法仅在用户明确要求相应形式或节奏时采用：

| 波形 | 适用内容 | 排法 |
|---|---|---|
| 快起 -> 稳证 -> 快收 | 信息流、产品证明、UGC | 开场快速建立问题和主体；中段给完整动作与可读证据；结果出现后迅速回收 |
| 逐级加速 -> 高光 -> 短停 | 发布、运动、变化升级 | 每次动作或场景变化缩短间隔并增加信息；高光后立即给短暂结果停留 |
| 快慢交替 -> 汇聚 | 多人物、多功能、多场景 | 快镜提出不同线索，较慢镜解释关键关系，最后让线索汇聚到同一结果 |
| 连续推进 -> 节点变速 | 一镜到底、跟拍、空间旅程 | 不切镜；在转身、开门、接触、进入新空间或环境反馈处改变速度、距离和观看目标 |
| 结果前置 -> 倒推线索 -> 原因揭示 | 悬念、清洁、效率、产品结果 | 先给异常结果，再沿痕迹、动作或状态逐步倒推，最后揭示产品、人物或关键操作 |
| 稳态建立 -> 突然打断 -> 连续应对 -> 新稳定 | 喜剧、反差、问题解决、生活方式 | 先让正常秩序可读，一个事件打破它，随后用连续动作解决并建立新的结果状态 |
| 单点触发 -> 层层扩散 -> 整体响应 -> 回收到点 | 材质、声音、空间和品牌视觉 | 从一个接触点、声音或文字开始，让变化扩大到主体和环境，再收回产品、人物或符号 |
| 两线交替 -> 节奏对齐 -> 同场汇合 | 对比、多人物、多地点、多状态 | 两条线分别建立差异，交替缩短间隔，在动作、声音、形状或目标一致时汇合 |
| 问题脉冲 -> 回答脉冲 -> 证据停留 | 教程、问答、UGC、SaaS | 每个问题立即接动作或画面答案，关键证据放慢看清，再进入下一组问题与回答 |
| 克制积累 -> 局部释放 -> 完整爆发 -> 余韵 | 高端、情绪、运动、发布 | 蓄力阶段仍持续增加线索和压力，先释放一处反馈，再给全片高光，最后短暂收气 |
| 建立规则 -> 两次变奏 -> 打破规则 -> 新规则收束 | 概念片、视觉实验、品牌片 | 先让观众学会同一规则，两次重复都升级信息，随后有理由地改变规则并回收主题 |
| 起点 -> 偏离 -> 回归 -> 无缝接回起点 | Loop、单图动态、循环展示 | 主动作离开初态，次级运动延迟响应，回程消解变化，末态在姿态、速度、光线和机位上接回首帧 |

已有内容需要细化节奏时，可按这些节点检查：先标主动作的起点和终点 -> 标证明或情绪真正成立的时刻 -> 把高光放在核心最清楚的位置 -> 在动作中点、反馈点或观看任务变化处安排切镜 -> 最后检查镜长是否形成长短对比。15 秒视频也按分镜合同的观看任务、完整动作、自然语速和必要阅读安排镜头，但镜头不能机械落在同一秒点；不得把“正常或稍快”理解成每秒硬切，也不得把“动作完整”理解成长时间不切。

上表不是完整枚举，也不是固定模板。没有一条现成波形适配时，按下面方法从当前内容推导新波形：

1. **列不可移动节点**：先标出用户明确要求的动作、台词、产品证明、人物反应、场景变化、高潮和结尾；这些节点决定波形，不能为了套模板改写。
2. **给每个节点判断三种需求**：信息密度高低、动作强度高低、看清所需时间长短。信息密集或关键证据需要更稳定、更长的可读段；动作冲击、过门和反应可以更短，但不能丢掉起点和反馈。
3. **确定注意重点**：短片围绕最重要的发现、证明或情绪成立处组织强弱，其他节点帮助铺垫、升级、对照或回收。较长内容按章节设局部落点，同时让主线继续发展；不强制全片只有一次高潮，也不把每个小动作都配成同样强烈的重拍。
4. **连接节点**：按本文件“通用镜间因果与剪辑连续性”判断。动作、视线、声音等可以承接，因果、对照、论据或章节关系也可以直接切换；没有切镜理由时保持镜内连续，不为制造锚点添加动作。
5. **分配时长**：先给完整动作和可读证明所需时间，再把剩余时间分给过门和呼吸；短镜服务触发和转折，长镜服务完整动作、证据读取或情绪落定。不得先平均分秒再填内容。
6. **检查强弱关系**：多个节拍同强度不直接判为平淡，要看理解、任务或情绪是否变化；全高导致重点不清时再调整。优先改内容顺序、观看距离、声音与停留，不先加特效或评分。

需要重新规划波形的信号与改法：

- 开场到 3 秒仍不知道主体或看点：把结果、异常、强动作、关键问题或第一证据前移。
- 核心证明太快看不清：压缩前后过门，把时间让给完整操作、结果状态和必要文字。
- 多镜同长度、同强度且内容重复：按触发、证明、反应等实际职责重分时间；内容持续推进时不为制造波形硬改。
- 高光出现两三次且互相竞争：先区分重复强化同一结论，还是分别承载必要的不同证据、特点或回应。重复部分可降为铺垫或局部反馈；不同的有效内容保留，通过主次、先后和强弱安排突出重点，不为只留一次高光删掉主要信息。
- 中段信息堆满：先重排顺序、错开注意重点、用具体证据替代抽象长句，再压缩重复表达和无关装饰。相关的主要观点、证据和必要条件保留；辅助说明可由连贯人声或简短图形分担，但需要亲眼判断的证据不能只靠旁白代替。尾帧只承接前文已交代且可读的必要信息，不接收一批首次出现的新观点；不靠减信息或机械加镜头解决。
- 动作被切断或人物/产品瞬移：移动切点到动作中点、接触点、遮挡峰值或反馈点；仍接不上时合并镜头并重新安排摄影机路线。
- 结尾突然或拖长：提前在前一镜完成结果反馈，只把最终识别、主题或 CTA 留给必要收束时间。
- 用户要求的节奏与推荐波形不同：以用户要求为准，保留其速度和情绪方向，只修正无信息停留、动作断裂和不可读节点。

切镜优先落在七类节点：

1. **动作中点**：拿起正在送向目标、转身正在完成、门正在打开时切，后镜从相同动作相位继续。
2. **接触/反馈点**：按下、咬下、放入、落桌、连接、涂到皮肤后，切到结果或反应。
3. **视线落点**：人物看向某物，切到其看到的证据；证据出现后切回反应。
4. **遮挡峰值**：手、产品、门框、衣料、前景物遮满画面时切到下一角度或场景。
5. **形状/位置匹配**：相似轮廓、同一主体位置、相同运动方向连接产品、场景或结构。
6. **声音重拍/声音桥**：下一场景声音先进入，或在咔嗒、咬合、落地、提示音、鼓点处切。
7. **状态改变**：空到满、乱到整、未连接到完成、问题到结果时切换观看关系。

多镜头方案中，镜头既无观看增益又找不到切点时，先补与主线有关的观察发现、证据、必要动作、反馈或状态变化，再选合理切点；不靠添加无职责的遮挡物、声源或小动作制造切换借口。仍无职责则删除或合并，再用相关有效发展补足内容和密度。已有完整镜内推进的长镜及 one_take 不为凑切点强行拆开。

运镜需要可观察的目标；长短由当前动作、揭示与理解决定。选择后写成能执行的路径：从什么景别/位置开始，跟随或揭示哪个对象，向何方向走、速度怎样变化，到哪里停止，终点要看清什么；拉焦另写焦点从谁转给谁。例如“从手与旋钮同框的侧俯近景开始，随手横移到书页，灯光稳定后停住看结果”，比“高级感横移”明确。若操作证据更适合固定同一角度，就固定，不为复杂运镜遮掉手与接触点。较长视频依不同内容选择跟随、横移、升降、揭示、拉焦、固定观察等拍法，不把整片写成同速推拉或环绕，也不机械要求每种拍法都出现。

动作与摄影机默认按正常现实速度运行，人物拿取、转身、走动、回应要利落完成，不每一步都缓缓启动或结尾空停。先写触发、实际路径/接触、可见反馈与终态，再按看清需要分配时间；速度变化仅用于明确需要观察的瞬间或已定表达，写明在哪一秒放慢、为何需要、何时恢复。时长较长时增加有意义的内容，不把动作整体放慢；希望节奏更丰富时优先调整内容、镜内变化、切点与声音，不把全片加速或每秒硬切当作解决办法。

按职责选择：

- **快速推近**：在动作启动或证据出现时靠近关键部位，终点必须可读；不做无终点慢推。
- **跟随/横移**：跟着手、人物、产品、数据或道具完成空间位移，让路径本身交代逻辑。
- **短拉远**：动作完成后揭示整体结果、人物关系或环境反馈，不用于重复展示。
- **拉焦**：同一空间中从前景主体切到后景证据，或从产品切到人物反应。
- **摇镜/甩镜**：主体快速转移视线或位置时使用，方向必须由前一动作决定。
- **环绕**：只有每个角度揭示不同结构、证据或场景变化时使用；只绕圈却没有观看所得时改路线；完整外观、材质或空间关系本身可以是展示任务。

运镜和节奏的关系：

- 推近负责聚焦核心，不负责“显得高级”；推近终点必须是证明点、产品局部、人物反应或文字落位。
- 拉远负责揭示关系或规模；拉远后必须出现新场景、新人群、新系统或完整产品。
- 横移/跟拍负责动作链，必须让观众跟着产品、人物、宠物、光点、数据卡或手部动作发现信息。
- 环绕/旋转负责全维度认知或仪式感；每转到一个角度要看到新结构、新材质、新状态或光线变化。
- 固定机位负责可信和可读；固定不等于静止，画面内要有堆叠、开合、试用、拉扯、反应、图形落位或声音重拍。

## 通用镜间因果与剪辑连续性

本节适用于通用创意、UGC、产品广告、品牌 TVC、企业商务以及所有长短视频。镜头多不等于剪辑成立，运镜连续也不等于内容有推进。逐镜设计前先写一条可复述的动作/信息主链，逐镜写清每一对相邻镜头的承接；

每次切镜必须同时成立：

1. **切镜理由**：新动作开始、前一动作产生反馈、人物视线发现信息、观点/证据切换、空间关系改变、情绪转折、章节结束或结果揭示。
2. **承接关系**：动作、视线、状态、形状或声音可以连续；蒙太奇也可由因果、对照、论据递进、时间或章节关系连接，不强求同一物体或特殊转场。
3. **观看价值**：后一镜增加证据、关系、反应、结果、情绪判断、品牌归属或行动信息，或承担必要的阅读、观察、节律积累与感官发展。音乐复现、喜剧重复与固定版式变奏可以保留，不要求每镜首次交付知识；只换角度、重复已知结论且没有观看作用时才合并或改写。

在正式分镜中说明这三项；关系不清时补必要前提、动作、观察或反馈，再定切点。语义接续已经清楚时可直接切换，不强加触发动作或花式转场。

先区分同一时空的连续动作与计划内的时间省略、并列对照、图形或概念蒙太奇。下面的姿态、位置和动作相位锁只适用于物理连续的部分；换时空仍保护身份、事实和故事状态，用明确的内容关系说明省略，不要求拍全无关的拿取和走路。

连续性按主体类型分别锁定：

- **人物/手部**：身份、服装、姿态、视线、手势起止、进入方向、轴线和互动对象连续。随机切脸、随机换模特、连续无关系反应镜头都不成立；多人必须通过对话、同一事件、传递物、分屏、共同动作或群像汇聚建立关系。
- **物体/产品/道具**：同一连续事件中的位置、朝向、比例、开合、空满、完好/变化等状态应由动作或已建立的规则解释。省略时间后可以呈现新状态，但不能省掉决定产品证明、包袱或理解的步骤。概念图形与音乐蒙太奇可以由语义、节律或并置组织，不必另演一次物理触发。
- **场景**：换场对应人物移动、时间推进、任务升级、观点变化或功能阶段。下一场景可由门框、前景遮挡、声音先行、同形、同色、共同方向或线索道具带入，不能随机换背景。
- **景别**：景别服务观看任务，可按“建立空间/关系 -> 靠近动作 -> 特写证据 -> 回看反馈/结果”组织。全景可直切特写，靠清楚的动作、证据或观看关系承接，不强制匹配形状或音乐重拍；连续特写要能定位主体并形成动作、证据或对照关系，空间不清时才补中景重建关系。
- **声音与文字**：声音可先于画面进入形成 J-cut，或延续到下一镜形成 L-cut。结果、参数与功能声明须紧贴对应证据，不能提前把未出现的结果当事实；问题或步骤标题可以提前引导观看，并保持到读完。拟声字对齐声音与接触点，不把所有文字都限制在动作瞬间进入。

- **长镜假变化**：同一全景或人物镜头持续 `5-8` 秒，只做慢推、拉远、渐大、发光或轻微动作。
- **随机特写串**：连续切人物脸、手、材质、道具或功能，却没有共同事件、动作接力或信息递进。
- **无关插镜**：画面里的物品、人物、场景或 B-roll 无法回答“它证明/解释/推进什么”，例如饮品片突然展示没有叙事职责的化妆品。
- **重复镜头填时长**：同一动作、表情、构图或结果连续停留/重复，第二次没有升级、反应或新含义。
- **叙事回收无变化**：故事结尾回到开场构图，却没有回答前面的疑问或呈现状态/关系的新含义。纯运动循环另以运动相位、光线和环境声能否平滑接回为准，不强加剧情变化。
- **物理事件缺因果**：需要理解原因的物体飞出、空间变化或人物惊讶，缺少前提、触发或反馈。音乐、对照、文字与概念蒙太奇按各自关系组织，不要求都先演一个物理触发。

高频动作桥示例：以下保留需要连续看清时的完整调度，不要求每次使用都拍齐全部过程。已交代时间省略、结果前置或阶段切换时可直接切入新状态；不能省掉本片必须看见的接触、关键步骤或反馈。

- **拿取到入口**：手进入并捏住食物 -> 手腕带着食物向嘴边移动，镜头从物体特写拉到能同时看见手和脸的中近景 -> 在手腕越过下巴时动作中切 -> 后镜保持同一只手、食物朝向和移动速度，继续送到唇前 -> 咬合触发碎裂与拟音。要表现同一次连续送入口时，不能让拿取与唇前状态之间缺少可理解的运动承接。
- **刷头到涂抹**：旋开瓶盖 -> 刷头沿瓶口刮去余量 -> 一滴质地在刷头尖端形成并立刻被带向使用部位 -> 镜头跟随手部移动或用刷头越框遮挡切换 -> 后镜从相同方向接住刷头并完成第一笔涂抹。瓶口上方悬停、滴落和涂抹各只保留能看清变化的必要时长。
- **取料到上脸再放回**：手指触碰质地 -> 取出少量 -> 手从产品位置连续移动到脸颊，使用中景交代空间路径 -> 指腹接触脸颊后切近景看涂开与肤感反馈 -> 镜头拉回中景，手离开脸颊并拿起/放下产品 -> 产品落桌的接触声和稳定位置带入尾帧。同一连续动作不能让手从嘴边瞬移到脸颊；涂抹已完成、接下来的产品镜承担结果辨认或品牌收束时，可以直接切，不强补放回动作。
- **特效触发**：真实接触点已经足够有冲击力时优先放大材质、碎裂、液体、声音或环境反馈；不额外添加与视觉系统无关的闪电、光波、粒子或爆炸。特效必须继承当前色板、材质和运动方向。

知识、观点和复杂因果不必在静音时交付全部信息；单个状态或构图写清不代表运动和声音关系已经成立。只有微调且无新增职责的镜头优先删除。不在生成后观看视频、试听或抽帧验收；真实状态帧仅按已定续接需要取得。

## 生成式镜头和剪辑描述

常用镜头效果写法：

| 效果 | 画面职责 | 生成描述重点 |
|---|---|---|
| FPV 穿越 | 让观众冲入场景，快速揭示空间奇观 | 低视角、高速度、路径从远到近、围绕主体或穿过粒子群；转弯和加速有运动模糊，揭示主体时短暂放慢 |
| 产品特写 + 浅景深 | 把产品从生活场景中分离出来，同时保留氛围 | 焦点锁定 logo、杯身水珠、质地、按压口、鞋面纹理或 UI 关键区；背景可辨但柔焦，光斑和环境色服务情绪 |
| 固定机位 + 元素动效 | 让信息清楚，靠画面内动作制造节奏 | 机位稳定，主体不漂移；纸片、手指、文字、产品模块、UI 卡片或手部动作按节拍进入、落位、停留 |
| 2D/平面虚拟运镜 | 在扁平插画、排版、拼贴和信息图中模拟推拉平移 | 推近、横移、缩放要有缓动、惯性和停顿；不要匀速滑动，避免像 PPT |
| 尺度揭示运镜 | 先给正常参照，再揭示巨大或微缩主体 | 开场先看见人、车、手、桌面或建筑；随后推拉、上摇、航拍或低机位揭示尺度反差 |
| 贴地/低角度跟拍 | 放大速度、压迫感、脚步、滚动和巨物 | 镜头贴近地面纹理，主体从画面边缘掠过；背景拖影和地面线条强化方向 |
| 90 度俯拍 | 让纸张、桌面、食物、文字和流程变成平面图形 | 垂直俯视，纸张/产品/手部在桌面上完成翻开、折叠、摆放、标注或对比；光从侧方形成纹理 |
| 超低仰拍/广角 | 让人物、产品或建筑产生巨人感、阔感或时尚张力 | 主体脚部或底部贴近画面下缘，天空/建筑留出大面积背景；广角拉伸要服务气势，不让产品变形失真 |
| 微距细节 | 放大质地、温度、声音和触感 | 明确拍哪个细节：水珠、冰块、墨迹、纸纤维、咖啡液、饼干屑、面料纤维、接口、手指触点 |
| 手持纪实微动 | 建立真实在场感和创作者视角 | 轻微呼吸感、近距离动作、自然跳切；不要剧烈晃动到看不清主体 |

剪辑节奏写法：

- 按动作、理解和情绪需要安排速度。开场及时进入值得看的事情，中段持续增加有效内容，结果完成后及时收束；开场、镜长和尾帧边界按分镜合同。需要看清操作、阅读或人物回应时，才在对应位置保留必要时间，不默认中段放慢，也不让开头、结尾靠缓慢铺垫或定格填时长。
- 快不等于乱。快剪每个镜头仍要有主语、动作和新增信息；高速运动中要用产品、颜色、线索道具或声音保持连续。
- 慢镜头须让观众跟随实际动作、证据、关系或情绪的发展。例如翻开纸张后读到改变判断的信息，或人物发现对方的举动后改变回应。水珠滑落、光扫过 logo、轻微表情或声音渐停可以辅助质感与情绪，不能单独证明一个长镜头值得保留；具体观察任务仍按分镜合同相应例外执行。
- 关键动作可以用速度变化：正常速度进入，触发瞬间放慢，结果落定后恢复正常；不要整条片都慢动作。

转场要从画面逻辑里长出来：

| 转场 | 写法 | 适合 |
|---|---|---|
| 遮挡转场 | 手、纸片、衣料、糖果、包装、门框或产品边缘完全遮满画面，在遮挡峰值切换 | 换装、开箱、场景跳转、真实+卡通混搭 |
| 运动模糊转场 | FPV、甩镜、奔跑、滚动或高速粒子在最模糊瞬间切到下一场景，方向保持一致 | 城市穿越、运动、速度感、道具贯穿 |
| 文字转场 | 字体缩放、裁切、反相、弹入、拆散重组或字重变化完成镜头切换 | 极简大字、新闻解释、歌词/标题片 |
| 纸张/翻页转场 | 便签飘落、纸张翻开、撕纸覆盖、报纸翻页或台历页替换 | 拼贴、活动预热、纸媒美学、教程揭秘 |
| 焦点转场 | 焦点从背景拉到产品，或从产品推到环境反应 | 咖啡、香氛、美妆、生活方式产品 |
| 框架穿越 | 镜头推入画框、屏幕、包装开口、门框、杯口或纸洞，再从另一层世界出来 | 画中画、包装入口、艺术活化、产品内部世界 |

按转场职责选择声音：遮挡可用轻 whoosh，纸张用摩擦/啪，文字用 click/pop，液体和冰用飞溅/低频；也可以延续原有音乐、环境声、对白或有意静默，不为每次切镜新增音效。转场音效不能盖过人声和核心信息。

## 画面文字和图形信息层

有阅读、识别、比较、定位或解释任务时，选择文字与图形；画面和声音已交代清楚就不用。默认无逐句字幕，仍可用有依据的产品名、卖点短语、标题、步骤或图形标签传递重要信息；逐项写清原文、位置、出现/退出与可读时间。不能把完整旁白或口播换成花字、贴纸、轮播卡片上屏，也不能用连续短词变相逐句转录；用户明确要求字幕时才按字幕规则处理。口播、采访、街采也可以采用信息文字，不因此把逐句字幕换成连续卡片。图形怎样变化见[视觉库](visual-motion-playbook.md#图形构成和状态变化)，本节只管文字职责、层级和可读性。

| 文字职责 | 具体处理 |
|---|---|
| 标题、章节、主题 | 先读的内容清楚，大小、留白与位置形成注意顺序，不默认每镜都配 |
| 产品、品牌、主体身份 | 可以在包装、招牌、真实界面中，也可以独立设计；实际位置应可辨，不强制物理化 |
| 说明、步骤、参数 | 在当前需要理解的位置出现，指向明确；关键核对可以与人声同步，不堆全部字段 |
| 人物、观点、问题标签 | 降低指代与语境成本，保留说话关系，不把原意切成散点金句 |
| 手绘、反应、拟声字 | 强调当前动作、观察或幽默；贴近对象和时机，不随机撒表情 |
| 行动、参与信息 | 任务需要才用；字段可在中段开始展示，不全挤最后一秒 |
| 歌词、标题实验、文字主视觉 | 阅读顺序与语义决定观看，文字本身可以是全部画面，不强制另找实景 |

先让主信息显著，其次安排解释与查阅字段。层级不按固定三层或四层计数；需要同时阅读的内容过多时分开呈现。字号、停留、屏幕尺寸、距离和遮挡共同决定可读性，不以小字“出现过”当作已交付。

字体、字重、对比度、行长、行距和底板帮助读清。重要信息避开实际平台遮挡与裁切；未知平台按画幅留合理边距，不将固定安全区百分比当作所有展示位的真实规范。主体身份、关键动作与决定性界面不要被字盖住；有意遮挡形成构图时保留必要识别。

静态标题可以成立，动字也不必每次与手势或鼓点绑定；需要同步强调时写清对应动作/声音。物理空间中的字遵从载体的透视、光影与遮挡，编辑叠层按版式处理。不要把两种层混为角色都能触碰的实体。

精确原文、字幕符号与素材输入按[资产合同](asset-generation.md)；字幕采用按主入口，本文不再维护另一套符号格式。以下排版库补充具体造型，不默认增加文字。

## 花字类型选择器

花字不是字幕的同义词。先判断它在本镜头承担什么职责，再决定字形、位置、动效和密度。能用画面动作讲清时少用字；需要降低理解门槛、建立系列感、解释创意动作、强化品牌资产或完成行动收束时再用。

| 花字类型 | 作用 | 写法 | 避免 |
|---|---|---|---|
| 主标题大字 | 停滑、城市/主题/系列识别，文字成为构图核心 | 1-3 个词，粗体或强设计字，放在下三分之一、左上或大留白区；可带倒影、投影、纹理、透视或遮挡 | 像普通字幕贴在画面上，和构图、色彩、主体无关系 |
| 功能说明文字或步骤标签 | 解释当前创意动作或教程步骤 | 使用 `“具体说明文字”`，在动作发生时同步出现；可用黄底黑字、步骤标签或素材清单。它属于画面文字或图形信息层，不是逐句字幕；只有用户明确要求画面内字幕时才使用 `【】` | 动作已经清楚还重复解释，或比动作晚出现 |
| 品牌/产品文字 | 商业露出和资产识别 | 优先让 logo/产品名出现在产品、包装、建筑招牌、屏幕或道具本身；透视、光影、遮挡跟随载体 | 后期硬贴漂浮 logo，遮挡产品证明 |
| 素材清单/工程信息 | 教程、拆解、方法分享 | 字体/音乐/特效/滤镜/工具等用细体小字分栏，通常在工程截图、对比图或讲解段出现 | 在纯展示片里塞教程信息 |
| 趣味反应花字 | 强化网感、情绪、拟声、表情反应 | 粗圆体、手写体、贴纸、箭头、弹动，贴近触发动作 | 密集堆满、遮脸、遮产品、抢走主线 |
| 尾帧行动字 | 回收核心和引导下一步 | 产品/品牌/结果稳定后出现一句主张或一个 CTA，位置清楚、停留可读 | 最后一秒新增复杂卖点、多个 CTA 抢戏 |
| 极少字/无字 | 纯视觉叙事、高端质感、艺术氛围 | 只保留尾帧主题字或品牌字；其余由动作、声音、母题承担 | 为了显得完整强行加解释字 |

花字可按以下职责分层，不把层数当上限；下列层级与后文 L1–L4 字号例子都是设计参考：

```text
第一层：主标题/核心概念，最大最醒目，1-2 个词或一句极短判断
第二层：功能说明/步骤/卖点，跟动作同步，短句
第三层：素材清单/补充说明/辅助信息，小字号低干扰
```

多个层级同时出现时，先读内容最显著，辅助信息降低干扰并有足够查阅时间。教程清单与当前步骤或稳定结果相对应；尾部避免同时新增 CTA 与复杂解释，必要信息可提前呈现。

花字大小按“信息权重 + 停留时间 + 屏幕比例”决定。1080p 画面可参考：L1 主标题约占画面高度 10%-20%，L2 副标题约 5%-10%，L3 说明字约 3%-5%，L4 合规/辅助小字约 1%-2%。竖屏文字通常比横屏更需要大字号和更明确安全区；小字必须给更长停留。层级差不明显时，观众会把所有文字都当噪音。

### 构图文字与结构标注

| 当前需要 | 具体实现 | 保留条件 |
|---|---|---|
| 地名、主题或构图大字 | 将文字安排在留白、背景带或透视面；线条、色彩、倒影、阴影与主体呼应 | 先读什么要明确；编辑文字不强制变成可触碰实体，不把大字当逐句字幕 |
| 尺寸、参数、三视图 | 主体先稳定可辨，标注线从对应结构边缘伸出；数字可用等宽字体，正/侧/背或多角度补全结构 | 角度切换保留对应关系；尺寸和参数来自实际材料，不用好看的图纸编数据 |
| 文字主视觉、动力学排版 | 按词义与信息层级使用遮罩、反色、裁切、出画、递归形状、单点彩色与留白 | 文字是主体时可占全部画面；阅读顺序及必要停留成立，不逐字套同一种弹入 |

一般标题、品牌字、标签与反应贴纸沿用上表；以上补充的是构图和结构标注的实现，不再建一套图形流程。

## 花字字体、颜色和动效

字体性格要等于视频性格：

| 场景 | 字体倾向 | 颜色倾向 | 动效倾向 |
|---|---|---|---|
| 城市/工业/硬核/建筑 | 粗体无衬线、等宽、窄粗体、工业感字形 | 金黄、橙、白、黑底高对比 | 逐字入场、重击落位、透视贴合、倒影波纹 |
| 潮玩/可爱/年轻 | 粗圆体、手写体、卡通体 | 高饱和橙、黄、绿、粉，配深色描边 | 缩放弹动、轻微回弹、贴纸跟随 |
| 艺术/时尚/高级 | 细体衬线、窄体无衬线、可变字体、克制字重 | 白、黑、银、低饱和品牌色 | 慢显、裁切、轻微位移、和构图线对齐 |
| 功能说明/教程 | 中性无衬线、系统感黑体、等宽数字 | 黄底黑字、白字黑描边、黑字白底 | 渐显渐隐、步骤替换、卡点打勾 |
| UI/SaaS/数据 | 产品设计系统字体、等宽数字、状态标签 | 继承真实 UI 色板和状态色 | 到达、替换、完成、锁定 |

颜色优先保证可读，再考虑风格。复杂实景里常用高对比组合：白字加细阴影、黑字黄底、橙/金黄大字配暗背景、黑底白字或品牌色底板。描边、阴影、底板和半透明蒙层只为提升可读性和风格统一，不为了花哨叠满。

需要强调动作的文字可同步；独立标题、歌词与排版按语义、乐句和阅读安排：

- 物品碰撞、落地、开盖、点击、咬下时，文字可以短促弹动或印章式落位。
- 场景切换、规则改写、步骤替换时，文字跟着替换，不滞后解释。
- 水面、玻璃、金属、建筑、包装等载体上的字要有对应倒影、反光、透视或遮挡。
- 文字跟随运动物体时，要写清绑定对象、透视变化、遮挡关系和退出方式。
- 不要为每个词做不同动效；一条片只选一套主花字动效语言。

## 花字位置和安全区

花字先避开实际展示位的界面、字幕区与裁切。未知平台时，竖屏可先为上下和右侧留足边距，横屏留意底部遮挡；约10%的上下留边只作构图起点，不能当作所有平台的真实规范。实测版式可读性优先，不让重要信息贴边。

常用位置：

| 位置 | 适用 | 注意 |
|---|---|---|
| 下方三分之一居中 | 主标题、动作说明、城市/活动名 | 避免遮挡产品和手部证明动作；可与地面、水面、建筑轴线形成构图 |
| 左上角 | 系列标题、平台标签、问题卡 | 小而醒目，不压主体脸和产品 |
| 右下角 | 低干扰辅助信息、角标、章节标记 | 只在确有信息职责时使用，字号和透明度服从主体 |
| 底部居中 | 素材清单、工程信息、功能说明 | 字号小但可读，适合教程、拆解和方法展示 |
| 跟随物体 | 产品名、招牌、包装字、建筑字 | 必须匹配透视、光影、运动模糊和遮挡 |

如果文字是画面的一部分，必须像实体一样处理：贴在墙面就跟墙面透视，落在水面就有波纹倒影，印在包装上就被手和包装边缘遮挡，挂在建筑上就受光照和距离影响。做不到时，降级为后期平面标题或尾帧可编辑文字。

## 外发标题与社媒文案

仅当用户要求标题、封面文案、发布文案，或当前任务明确包含发布素材时查本节，不默认多交付附件。它们承接已定视频内容，在封面、信息流、活动页或作品集中承担吸引、解释、系列识别或行动作用。不要只写“高级感、太绝了、创意视频”等空标签。

标题先确定一个钩子动作：

```text
谁/什么东西
  -> 在哪里/什么场景
  -> 做了什么反常识动作或解决了什么问题
  -> 观众为什么要看
```

常用标题展开方法：

| 标题类型 | 结构 | 适用场景 |
|---|---|---|
| 痛点反问 + 解决方案 | 别再问/别再踩/还在为 X 头疼？直接看 Y | 教程、工具、服务、知识、企业解决方案 |
| 情绪惊叹 + 核心机制 | 超酷的 X / 这个 Y 脑洞太上头 | 创意展示、产品玩法、技术作品、发布预热 |
| 拟人化叙事 + 场景设定 | 当 X 进入/占领/滚过 Y，结果 Z | 城市超现实、产品功能隐喻、物品动态片 |
| 概念定义 + 系列标签 | 中文概念｜English Subtitle：本期主题 | 系列作品、品牌栏目、人物图鉴、活动主题 |
| 空间/城市再定义 | X 像一座 Y / 这条街被 Z 改写 | 城市创意、文旅、门店、展会、空间片 |
| 结果前置 + 留白 | 这不是 X，是 Y 完成后的样子 | 教程、前后对比、产品证明、企业案例 |
| 受众筛选 + 边界 | 如果你正好是 X，这条先看完 | UGC、服务顾问、B2B 获客、课程内容 |
| 主张短句 + 视觉证据 | X 不是口号，是 Y 这一刻 | 品牌 TVC、企业商务、公益倡导 |

迁移方式：

- 产品广告：标题写产品造成的结果，不只写产品名。例如 `当清洁喷雾落下，油污像退潮一样让路`。
- 品牌 TVC：标题写品牌主张的可见瞬间。例如 `希望不是光效，是有人把灯一次次点亮`。
- 企业商务：标题写决策者关心的证据事件。例如 `一张订单如何从设计走到交付现场`。
- 通用创意：标题写异常规则和尾态。例如 `这座城市被一个字慢慢折起来`。
- 教程拆解：标题写学习收益和关键证据。例如 `别再问这个转场怎么做，关键其实是这三层`。
- 活动预热：标题写悬念和行动信息。例如 `倒计时开始前，先看主题如何出现`。

Emoji、英文副标题和话题标签都可以用，但必须有信息职责。颜色 emoji 对应画面色彩，物品 emoji 对应主体，表情 emoji 对应语气转折；英文副标题用于系列感、国际感或设计感，不替代核心中文信息；话题标签按“大流量词、精准品类/技术词、场景词、品牌/活动词”分层，品牌、合作、活动和权益没有材料时不编造。

视频内花字和外发标题要分工：

- 外发标题负责停滑和解释为什么值得看。
- 视频内主标题负责建立概念、系列或主题识别。
- 功能说明花字负责让观众看懂当前动作。
- 素材清单和工程信息只用于教程、拆解或方法展示。
- 尾帧文字负责回收核心；本片有行动任务时再给相应入口，不为结尾另加转化目标。

新设计的画面文字要具体到可执行，按实际需要写：`时段 + 进入依据/触发 + 字体气质/字重/字形 + 具体文字 + 位置/安全区 + 色彩/描边/阴影/底板/材质 + 入场路径/缓动 + 保持 + 退场或随切镜消失`。这是可查维度，不是每条文字必填全部效果；固定标题可直接出现、随切镜消失，没有描边、底板、材质或物理触发就不补。真实包装、Logo、原片及 UI 内已有文字依原素材保留，不重新设计字体或入场。不能只写“出现一个 XX 字”“加 XX 字”“屏幕上显示 XX”。“XX 字体的 XX 字”要具体到可执行：例如“粗圆体白字的‘省’字”“窄体无衬线银白字的‘FAST’”“手写马克笔风的‘别急’”“等宽数字字体的‘03’”。字体描述要服务内容和场景：UGC 可用手绘、手机贴纸、粗圆体或平台原生标签；产品广告可用品牌包装、海报标题、无衬线大字、印章或拟声花字；SaaS/UI 沿用真实产品设计系统里的无衬线、等宽数字和状态标签。这些是选法，不按类型强制同一种字体。

构图大字不是字幕。使用时要写清文字出现的时段、位置、字号关系、入场方式、和主体的几何关系，以及是否有倒影、投影、纹理、遮挡或与环境互动。例如地名大字可以在下三分之一随鼓点淡入，底部被水面反射拉长，最后和建筑中轴线一起形成定版；产品名可以贴着包装透视面滑入，边缘被真实包装遮挡。不能只写“加大标题”。

不同场景的迁移方式：

- UGC / talking head：人物继续说话，图形卡片、关键词、反应贴片或 B-roll 覆盖负责证明；跳切发生在短语边界，图形变化发生在观点切换或证据出现时。
- 口播/创始人/员工出镜：可用问题卡、进度条、步骤卡、观点卡、反对意见卡、数据卡和图标状态点承接口播结构；卡片出现、替换、打勾、归位或锁定必须对应一句话的信息变化。
- Presenter-led explainer：讲解者带着图形、演示和比较对象推进；图形要跟随手势、视线或讲解节拍，不一次性铺满。
- Narration-led demo：旁白作为脊椎，产品、手部、屏幕、卡片、进度条和 B-roll 给视觉答案；画面切走时旁白可以继续。
- Ranking/listicle：排名板或对比表负责记住前面判断，每一项用态度、图标和证据镜头推进，新项目进入时改变位置、高亮或补证据。
- Street interview / podcast / two-person：可用说话人颜色、角色标签、观点卡、反应镜头和 J-cut 建立关系；说话人标签不是逐句字幕。
- 产品广告：对比板证明前后变化，进度条展示效率，卡片承接卖点，图标标注功能，尾帧 CTA 完成行动。
- 企业商务：时间轴、地图、流程线、数据卡、组织结构和客户案例卡必须对应真实材料；动效表现节点亮起、流程闭环、区域扩展或项目完成。
- 技术流三视图：人物或产品属于物理场景，尺寸线、数字、箭头、单位、网格、图例属于编辑合成层；先拍/生成干净稳定的主体，再给图形层留足左右和上下空间。
- 动力学排版：没有物理主体时，字体、图形、底色和音乐就是全部画面层级；先确定字体气质、字号权重、关键词层级与阅读顺序。反相节拍、单一强调色、黑场或定版是可选手法，按语义和音乐采用，不要求凑齐，也不以黑场或静帧结尾作为完成条件。

图形、物理场景与摄影构图的分层见“画面层级和合成空间”，需要互动时再按世界设定说明。

图形和 UI 动效自检：

- 本镜头是不是只有一个主动效，其他变化都在辅助它？
- 卡片、数据行、图标或 UI 模块落定后，有没有真实槽位或清楚状态？
- 批量元素是否非线性、错峰或带物理隐喻，而不是匀速排队飞入？
- 关键数字、品牌字标、完整 UI 状态或 CTA 是否有可感知停留？
- 光效、粒子、扫光是否只给主角或关键节点，且没有盖住文字和证据？
- 信息密集或文字多的画面是否足够正视、清楚、可读？

## 视听策略迁移适配

运镜、布光、构图、色彩、转场、声音和文案是所有类型视频都能用的通用方法，但每次都要根据内容重写。不要把“低角度冲击、蓝橙电影感、匹配转场、ASMR 拟音”当成固定套餐；先判断它们在当前片里负责什么，再转成具体镜头。

内部适配顺序：

```text
P0 主目标
  -> 当前主体和证明锚点
  -> 本维度承担的职责
  -> 选择一个主策略
  -> 改写为当前对象、动作、空间和声音
  -> 写进分镜秒段
  -> 检查是否抢戏、失真或不可生成
```

各维度适配要求：

| 维度 | 先问职责 | 适配方式 |
|---|---|---|
| 运镜 | 跟随、揭示、证明、压迫、沉浸还是收束？ | 产品用微距/环绕/固定机位证明细节；UGC 用手持微动和近景保真实；企业用稳定移动和大景别建信任；TVC 用克制运动和仪式化停留 |
| 布光 | 让主体分离、建立价格感、制造真实感还是突出证据？ | 食品要干净高光和食欲质感；护肤要柔光和肤感；3C 要轮廓光和屏幕动机；企业要真实空间光和可信环境 |
| 构图 | 观众第一眼该看哪里？ | 产品/Logo/手部证明不能被遮；人物关系用前后景；企业事实用空间层级；高端片可留白但关键信息必须稳定 |
| 色彩 | 情绪、品类、品牌和节奏谁优先？ | 先保护真实产品色和肤色，再用品牌色或冷暖段落承接；不要每镜换滤镜 |
| 转场 | 两镜之间靠什么因果相连？ | 动作、形状、颜色、材质、声音桥或空间入口只选一个主逻辑；强转场要回到 `visual-motion-playbook.md` |
| 声音 | 哪个动作需要被听见？ | 拟音绑定开盖、咬下、点击、吸入、拖拽、脚步、门、键盘等触发点；音乐服务节奏曲线而不是盖住信息 |
| 文案 | 画面哪里说不完、需要文字或图形补足？ | 在旁白、口播、标题卡、图形标签、排名板、对比板、进度条、UI 面板、尾帧 slogan 或 CTA 中选择合适形态；不要逐句复述旁白 |

如果某个维度无法说清“为什么用于当前视频”，就删掉或降级。专业感来自各维度共同服务同一主线，不来自技法数量。

## 共享视觉语言

多镜头视频在分镜前先锁共享视觉语言：

- 色彩：当前内容实际需要的主色与色彩关系，含品牌色、背景色、强调色和状态色。
- 光线：主光方向、色温、软硬、来源和场景动机。
- 镜头质感：手持、定机、推轨、微距、产品巡航、2.5D 页面相机、纪实手机感或电影感稳定机。
- 视觉概念与版式系统：沿用已定内容，确定主体与空间关系；采用异常效果时再锁变化规则、主导构图骨架、色彩面积、材质、留白、裁切和图像层级；文字只在确有职责时补充字体、字重和空间关系，不默认出现。将这些要求写入文字分镜母版；实际输入与必要资产按生产控制准备，不增加概念图或图片确认前置环节。
- 材质与空间：产品材质、UI 层级、包装反光、真实环境纹理、前中后景和尺度参照。
- 声音世界：人声、BGM、环境声、拟音、声音桥和静默使用边界。
- 禁止项：假 Logo、乱码文字、无关主体、风格漂移、复制参考概念、过度装饰、产品变形、人物撞脸。

如果参考素材或用户要求的是强审美风格，先把风格升格为共享视觉语言，而不是只在单个镜头写“某某风格”。不得另建强风格系统卡；只按下列维度提取会改变画面的结论，并写回分镜母版的共用设计与对应镜头，不另存平行规范：

```text
构图规则：
视觉概念/版式规则：
运镜规则：
色板：
表演/动作尺度：
美术/道具陈列：
声音节奏：
反差/转场：
回收锚点：
剥离项：
```

强风格系统必须可观察、可复用、可剥离。例如“作者电影式复古对称”可以转写为：绝对中心对称、平面化正立面、固定机位、横向轨道移动、垂直俯拍、少量 90 度甩镜、低饱和粉蜡笔色板、机械克制表演、道具网格化陈列、复古轻快音乐和精确拟音。不要只写导演名、片名或“某某风格”；也不要复制参考里的专属角色、台词、标志性桥段、完整剧情或可识别受保护表达。

强风格在与内容有关的构图、空间、材质、运动、光色、声音或表演中保持一致，不是套滤镜。各镜共享主体和识别锚点，构图随动作、证据、人物关系或信息职责变化；不设相邻镜必须改变两项的配额，也不固定英雄镜/人物镜/世界规则镜交替。类型文件可以决定强风格服务什么：品牌 TVC 可让“风格即内容”，产品广告可让风格显出品类质感。UGC 可借固定构图、栏目动作、色彩识别，也可在已定的创作者表达中采用更强的图形或概念效果；保持人的连续表达，区分演绎、解释与实测，不让风格伪造可信证据。

每个镜头都继承共享视觉语言，并有当前内容所需的观看作用：推进动作、信息、关系、状态或情绪，也可承担观察、阅读、节律与感官积累。统一可以保留同一构图，是否变化取决于内容，不靠逐镜换版式证明丰富。

## 关键画面的注意与力度

已有内容值得看、但画面仍显平时，先处理最重要的动作、发现或产品呈现。下面用于细化实际采用的镜头，不要求每镜全用，也不以添加特效替代内容：

- **把关键关系放在可见的位置。** 手、操作部位与结果需要同看时，选择能同时交代三者的角度；揭示依赖遮挡时，让遮挡真正挡住待发现部分，再在运动中打开。不要让关键接触藏在背面、画外或文字下面，再靠音效宣布完成。
- **让变化前后有可辨差异。** 同一参照下的尺度、位置、形态或声音差异，比不断换背景更容易看懂。可以保留稳定的轮廓、地平线、桌面边缘或图形锚点，让观众读出变化；不为比较伪造产品性能。
- **把运动写出重量与层次。** 根据材质安排受力、加速、接触、形变、余动和停稳，刚性部件与柔软布料的反馈应不同。次级运动跟随主动作、有合理延迟，不让所有元素同时同速起停；匀速也可用于传送、机械规律或有意的图形节律，不一概改成弹跳。
- **为关键时刻让出注意。** 新文字、镜头大幅运动、复杂手部动作与强音效不要同时争抢焦点。关键接触、表情转变或证据出现时，可减少背景运动、保持观看角度或让音乐退开；结果可在继续运动中被看清，无需一律定格。
- **用空间与光线显出质感。** 前后景的相对位移、尺度参照与遮挡使运动有深度；焦点和明暗将注意引到当前部位。材质依靠相应的高光、粗糙度、透光、纹理和接触声区分，不把一切都做成光滑塑料，也不为亮眼牺牲真实产品色与识别。

一处动作足够有力时，其他拍法可以克制。镜头、主体、图形与声音的强弱共同决定注意，不要求四者同时达到最大；纯排版按语义与阅读设计，观察和简单动态保留所需的细微变化。

## 构图策略库

构图决定观众怎样看见既定内容。本库用于文字分镜与视频画面；效果过程查[视觉方法](visual-motion-playbook.md)，资产与转写查[资产合同](asset-generation.md)。按观看目标确定构图；沿用骨架时由动作、证据或意义变化提供推进，不为求异破坏连贯。

| 构图策略 | 组织方式 | 适用效果 |
|---|---|---|
| 中心英雄 + 背景系统 | 产品或人物稳定占据中心，文字、图形、纹样或光影在后方形成完整舞台 | 产品定版、发布、品牌识别 |
| 极端前景冲击 | 一个物体贴近镜头占据大面积，主体和环境在后景建立动作因果 | 体育、食物、第一视角、速度 |
| 中心放射 | 主体位于圆心，文字、零件、光线、人物或轨迹向外放射 | 能量、声场、技术、聚焦 |
| 环形轨道 | 元素沿同心圆或椭圆轨道包围中心主体，前后大小制造纵深 | 循环、续航、选择、沉浸 |
| 水平双世界 | 通过水线、镜面、桌面、地平线或色块把画面分成上下两种状态 | 倒影、入水、前后对比、时空交接 |
| 垂直双世界 | 上下场景由手、产品、光柱、瀑布或动作穿过边界连接 | 来源到结果、现实到想象、跨时空 |
| 左右对答 | 两个人物、状态、产品或色场相向/背向组织，中心留给冲突或连接物 | 对话、选择、对比 |
| 对角线阵列 | 产品、人物或图形沿斜线和透视方向重复排列，形成速度与方向 | 包装阵列、运动、节拍 |
| 不对称大留白 | 主体压在一侧或角落，另一侧留给方向、标题、动作路径或悬念 | 高端、编辑感、人物情绪 |
| 满版裁切 | 产品、脸、材质或文字超出画幅，只保留最有辨识度的局部 | 感官、冲击、材质、时尚 |
| 框架群/屏幕群 | 多个不等尺寸画框、屏幕或窗口围绕主体，形成信息层和时间层 | 回忆、平台、内容、复杂叙事 |
| 编辑网格 | 图像、产品、标题、留白和信息块按规则分栏，视觉重心跨格移动 | 品牌网页、杂志、服务、系列内容 |
| 一点透视走廊 | 道路、文字、货架、光带或建筑共同指向单一消失点 | 穿越、速度、流程、空间入口 |
| 顶视几何 | 俯拍利用球场、桌面、餐盘、道路或阵列几何组织人物与动作 | 运动、食品、流程、秩序 |
| 剪影与色场 | 人物或产品以暗色轮廓压在纯色/高对比背景上，文字或图形承担第二层信息 | 态度、音乐、宣言、戏剧 |
| 前中后景穿插 | 前景遮挡制造临场，中景主体完成动作，后景视觉事件提供结果或尺度 | 电影感、空间、产品使用、沉浸 |

构图必须在实际画面中成立：主体占比、裁切位置、视线方向、消失点、前后遮挡、留白用途和文字安全区都要可见。不得只写“采用高级构图”。允许非常规裁切、超大字号、越界主体、极端近景、鱼眼形变、负空间、平面与真实影像混合，但必须保住产品结构、人物身份、核心文字和叙事可读性。

### 景别与空间关系

| 景别/构图 | 作用 | 常用场景 |
|---|---|---|
| 大远景/远景 | 建立环境、尺度、孤独或自由 | 旅行、汽车、企业空间、品牌情绪 |
| 全景 | 展示完整动作、穿搭、人物和产品关系 | 服饰、运动、人物出场、门店 |
| 中景/中近景 | 自然沟通、可信表达 | UGC 口播、采访、人物互动 |
| 近景/特写 | 情绪、产品细节、手部证明 | 美妆、食品、工具、开箱 |
| 三分法 | 自然、有呼吸感 | 日常、人物、生活方式 |
| 对称构图 | 稳定、庄重、仪式感 | 产品正面、发布会、高端品牌 |
| 引导线 | 聚焦、纵深、方向感 | 道路、货架、办公室、车内 |
| 框架构图 | 聚焦、层次、故事感 | 门窗、屏幕、车窗、货架、手部 |
| 前景遮挡 | 临场、层次、真实 | 探店、家居、人物跟拍、转场 |
| 留白/负空间 | 高级、安静、想象空间 | 高端产品、情绪片、静态尾帧 |

空镜不能凑时间。每个空镜都必须承担情绪、环境、转场、品牌资产或节奏呼吸。主要观看对象处在视觉重心；产品承担证明时，特写给材质和结构留空间，人物反应镜则让反应清楚；多人构图用前后景拉层次，不排成一条线；对话和访谈可用过肩镜头建立空间关系。

超宽屏构图适合横向空间、群像游行、建筑中庭、露台庆典和艺术空间巡游。电影参考中的 2.35:1 只描述构图感觉，不是本技能新增的合法调用比例；实际比例按入口与真实工具，已定画幅不为“电影感”擅改。使用超宽屏时，构图要主动利用左右运动、前中后景和引导线，不只是加黑边；横移、跟拍和群像站位要让宽幅带来信息增量。画框、窗框、门框、展柜和邀请函边框可以形成“画中画/入口”体系，但每个框架都要承担聚焦、穿越、揭示或收束职责。

黑白到彩色、记录感到海报感可以表现状态、音乐段落或观看关系变化。采用时写清起点、影响区域与落定结果，不强制人物触发；画幅遵循已确认规格，不擅自加黑边改变有效构图。

## 色彩设计策略

色彩在分镜中写成具体关系，生成确认前落实到完整 Prompt，第三阶段按已确认内容制作，不把“高级配色”“电影色调”“品牌感”留给模型猜。先保护用户产品、Logo、包装、人物肤色和真实场景的固有色，再设计背景色、辅助色、强调色、明暗关系和跨镜色彩变化。

需要细化色彩时，在已有共用设计中写清以下实际关系；面积比例只作起点，不另建合同，不要求每项都有，主体固有色不因比例被强行调色：

```text
固有色：[用户素材中不可偏移的产品色/Logo 色/包装色/肤色]
主背景色：[占画面约 50%-70%]
主体支持色：[占画面约 20%-35%，用于人物、道具或环境]
强调色：[占画面约 5%-15%，只落在视觉焦点、文字关键词或触发物]
中性色：[黑/白/灰/金属/纸色，用于留白、可读性和材质平衡]
明暗结构：[高调/低调/明暗切割/逆光轮廓/局部聚光]
色彩剧情：[镜头如何建立、增强、反转或回收颜色]
```

常用配色不是固定模板，必须按产品真相和叙事职责迁移：

| 配色结构 | 画面方法 | 适用气质 |
|---|---|---|
| 品牌单色 + 黑白 | 大面积品牌色统一世界，黑白负责层级和文字可读性 | 发布、科技、强识别 |
| 单色深浅阶 | 同一色相通过明度、饱和度和透明度建立前中后景 | 极简、高端、产品英雄 |
| 类比色 | 相邻色相平滑过渡，强调材质、氛围和连续运动 | 治愈、自然、美妆、生活方式 |
| 互补撞色 | 主体与背景使用对立色，控制一主一辅，不平均分配 | 年轻、运动、食品、强停滑 |
| 分裂互补 | 一个主色搭配两个邻近对比色，既醒目又比纯互补更稳定 | 潮流、娱乐、活力品牌 |
| 黑白 + 唯一强调色 | 大部分画面克制为黑白灰，只让产品、关键词或触发物带色 | 高级、技术、悬念、排版 |
| 冷暖叙事 | 问题段偏冷、触发点冷暖碰撞、结果段转暖；或按主题反向使用 | 转变、情绪、功能证明 |
| 糖果高饱和 | 多种明亮色由统一明度和干净背景约束，避免脏乱 | 零食、饮料、儿童、快乐 |
| 低饱和 + 材质色 | 灰、雾蓝、灰绿、裸粉等低饱和背景承托真实木、布、金属、皮肤 | 生活方式、家居、品质感 |
| 暗底珠宝色 | 深黑、炭灰或深色空间配少量宝石色、金属高光和轮廓光 | 奢华、汽车、香氛、硬件 |
| 自然来源色 | 从原料、土地、植物、水、天空和食物本身提取色板 | 食品、农业、环保、户外 |
| 数字界面色 | 继承真实 UI 的品牌色、状态色和中性色，不另套霓虹科技皮肤 | 软件、应用、数据、企业服务 |

不能每镜随机换色。颜色可以组织空间、人物、信息层级、音乐段落、时间或情绪关系，不必都承担人物剧情。跨镜或跨段按既定内容保持或改变主色、光源色和强调色；换场与情绪变化有明确理由，不要求所有场景同色；产品固有色和 Logo 色始终保持准确。

### 颜色联想与调性适配

先保护产品、肤色、原作和既定品牌识别，再按情绪及信息重心设计环境色。下表是颜色联想参考，不能用行业惯例覆盖当前品牌色板。

| 颜色 | 正向联想 | 常用场景 |
|---|---|---|
| 红 | 热情、食欲、力量、节日、紧急 | 食品、促销、运动、春节 |
| 橙 | 温暖、活力、亲和 | 快餐、家居、年轻品牌 |
| 黄 | 阳光、快乐、注意力 | 儿童、快乐向、提醒信息 |
| 绿 | 自然、健康、安全、成长 | 食品健康、环保、护肤修护 |
| 蓝 | 信任、专业、冷静、科技 | 科技、金融、医疗、企业服务 |
| 紫 | 奢华、神秘、创意 | 美妆、香氛、艺术 |
| 粉 | 温柔、浪漫、甜感 | 美妆、甜品、女性向 |
| 黑 | 高端、力量、经典 | 奢侈品、汽车、高端科技 |
| 白 | 纯净、简约、安全 | 医疗、科技、电商 |
| 金 | 尊贵、品质、胜利 | 高端、礼盒、节日 |

配色方法包括单色系、类比色、互补色、冷暖对比、高饱和和低饱和。避免把所有视频都调成同一种流行色；如果场景切换多，至少保留品牌色、产品色、光源或材质作为连续锚点。用户给出作者电影、年代感或特定胶片调性时，必须把色彩写成具体组合和质感，例如黄绿高饱和、暖黄与橙红火光、复古服装色块、35mm 胶片颗粒、轻微褪色或干净糖果色；不要只写“电影感滤镜”。文化艺术空间常用冷蓝/深灰环境承载神秘和空间深度，用暖金、纸艺粉彩、串灯、烟花或魔法粒子做情绪焦点；涉及名画、馆藏、产品或真实艺术品时，先保护原作/原物主色，再让环境光和特效色服务统一。音乐混搭可以让 A/B 两个参考先各有色系，再在融合段形成第三套混合色；动力学排版可以长期克制在黑白灰里，把唯一彩色留给最高权重关键词，形成延迟满足。

## 文字排版创意库

文字很重要，但不是默认叠加层。只有文字的形态、位置、尺度、路径、材质或空间关系本身参与创意时，才把它作为主视觉或辅助视觉。同一画面的主要文字作用与阅读顺序应清楚；组合字效时写明主次和关系，避免互相争抢，不以数量代替判断。本库负责可见造型；前文花字规则负责表达职责、可读性与安全区，运动生命周期读取 `references/visual-motion-playbook.md`，逐字 Prompt 描述与保真执行读取 `references/asset-generation.md`。

| 文字机制 | 画面设计方法 | 适合表达 |
|---|---|---|
| 环形字/螺旋字 | 文字围绕产品、人物或孔洞形成同心圆、轨道、漩涡或隧道，主体位于中心或穿过圆环 | 循环、续航、沉浸、声音、聚焦 |
| 文字透视隧道 | 字句沿消失点逐级缩小、放大或弯曲，形成镜头可穿越的深度通道 | 梦境、速度、进入意识、空间转场 |
| 文字从主体发射 | 字句从人物嘴部、产品开口、扬声器、屏幕或动作接触点向外扩张 | 声音、表达、能量、功能触发 |
| 透视锥形字 | 文字从人物嘴部、手势或产品触发点向镜头方向急剧放大，字面随透视压缩成喇叭或锥体 | 宣言、喊话、冲击、控制感 |
| 径向旋转字 | 关键词围绕中心主体形成圆盘、放射轮或旋转叶片，近端放大并带方向性模糊 | 运动、眩晕、循环、节拍 |
| 对答分屏字 | 两组文字分别占据上下或左右色块，配合相向/背向人物形成提问、回应、冲突或选择 | 观点、剧情对白、反差、互动 |
| 文字速度场 | 重复字沿镜头前后形成拖影、缩放模糊、压缩或拉伸，中心主体保持相对清晰 | 速度、失控、运动、音乐 |
| 文字地毯/建筑字 | 巨字产生纵深厚度并延伸为地面、墙体、台阶、柱体或舞台，主体真实站在其上 | 宣言、人物态度、发布、品牌空间 |
| 文字轮廓成像 | 文字沿人物剪影、产品轮廓、瓶身曲线或地标边缘排布，共同完成主体识别 | 人物观点、产品形态、城市品牌 |
| 巨型裁切字 | 单词或汉字放大到越出画幅，只保留局部笔画，人物或产品在字内、字前或负形中出现 | 强主张、尺度、发布感、潮流 |
| 拼贴字 | 字母、汉字、照片碎片、材质块和主体局部共同组成网格或撕贴画面 | 年轻、音乐、时尚、信息爆发 |
| 爆炸结构字 | 文字沿产品结构、零件、液滴或碎片向外放射，形成技术爆炸图或能量中心 | 技术、性能、速度、配方 |
| 路径字 | 文字沿道路、跑道、水流、衣摆、光带、声波或运动轨迹弯曲排列 | 运动、旅行、流程、方向 |
| 透视地面字 | 巨字贴合地面、墙面、建筑、球场或桌面透视，人物和产品真实站在或越过文字 | 空间、行动、场景沉浸 |
| 遮挡穿插字 | 笔画在主体前后交替穿插，被人物、产品、液体或道具部分遮挡 | 层次、真实合成、时尚 |
| 文字容器 | 字形内部装入人物、产品、城市、食材、自然或另一层世界 | 主题、地点、品牌世界 |
| 文字变物体 | 笔画成为楼梯、门、桥、跑道、管道、货架、波浪或可触碰装置 | 功能可视化、互动、叙事 |
| 材质文字 | 文字由冰、奶油、液体、烟雾、金属、玻璃、布料、植物、糖果或产品零件构成 | 感官、工艺、品类属性 |
| 动作字/拟声字 | 文字形态对应声音和动作，压缩、拉伸、碎裂、弹跳、震动或被风吹散 | 节奏、冲击、幽默、声音 |
| 重复字阵 | 同一词按大小、疏密、明暗或方向重复，形成背景、速度线、空间纵深或节拍 | 强调、递进、速度、洗脑记忆 |
| 描边/实心接力 | 同一大字在背景中纵向或横向重复，轮廓字与实心字交替，主体遮住部分笔画但保留整体识别 | 产品定版、节奏递进、年轻品牌 |
| 主体压字/字托主体 | 巨字位于产品或人物背后形成背景墙，或在底部成为稳定承托；通过遮挡明确前后关系 | 产品主角、海报感、发布感 |
| 信息框/对话框 | 搜索框、问答框、聊天气泡、标签和按钮成为漫画分镜或场景中的叙事物件 | 服务、平台、功能、社交传播 |
| 编辑网格/漫画框 | 文字、人物、产品和场景被组织进不等宽分栏、连续漫画框或杂志网格，跨框动作形成阅读顺序 | 多场景、服务流程、故事递进 |
| 斜切/旋转字 | 文字沿对角线、垂直轴、倾斜平面或旋转透视进入画面，与主体运动方向一致 | 速度、运动、潮流、转场 |
| 正负形字 | 主体轮廓、留白和字形互相借形，一眼既能读到字也能识别产品或物体 | 极简、双关、品牌识别 |
| 镜像/倒影字 | 文字只在水面、镜面、金属、玻璃或阴影中完整出现 | 反转、高级感、双重意义 |
| 字体尺度接力 | 同一关键词从小标签升级为环境巨字、空间装置，最后回收到品牌定版 | 递进、高潮、品牌回收 |
| 数据/参数造型 | 经确认的数据或参数组成轮廓、结构、波形、计量刻度或技术空间 | 性能、企业、科技、可信证明 |

字体选择必须具体到可观察形态，不写“高级字体”“艺术字体”：

| 字体形态 | 可观察特征 | 适用方向 |
|---|---|---|
| 超粗几何无衬线 | 笔画粗、字面宽、圆角或硬直切角、黑白块面强 | 产品名、发布主标题、巨型裁切字 |
| 窄体无衬线 | 字面窄长、紧凑排列、纵向张力 | 运动、潮流、参数层级 |
| 宽体无衬线 | 字面横向展开、重心稳定、占据大面积 | 科技、速度、横向空间 |
| 高对比衬线 | 粗细笔画反差大、衬线清楚、细部锐利 | 时尚、美妆、高端编辑 |
| 人文无衬线 | 笔画有书写感、开口舒展、比例温和 | 生活方式、服务、亲和表达 |
| 粗圆体 | 圆润端点、饱满字腔、亲和且有弹性 | 食品、儿童、娱乐、趣味花字 |
| 等宽机械体 | 每字等宽、结构规整、数字辨识稳定 | 参数、界面、工程、数据 |
| 模板喷字/工业字 | 断笔、镂空、硬边、印刷或喷涂痕迹 | 户外、机能、工业、运动 |
| 手写马克笔 | 笔压明显、边缘不规则、速度感强 | 口播、批注、情绪、年轻表达 |
| 粗笔刷字 | 墨迹、飞白、方向性笔触和夸张收尾 | 力量、国风、节庆、动作高潮 |
| 像素/点阵字 | 方格或点阵结构、低分辨率边缘 | 游戏、数字、复古科技 |
| 膨胀立体字 | 软体充气、凝胶、糖果、金属或塑料体积 | 潮玩、食品、产品材质联动 |
| 轮廓线框字 | 只有描边或多重轮廓，可与实心字交替 | 背景字阵、空间层级、产品托底 |
| 可变形字 | 宽度、粗细、倾斜或曲率随动作连续改变 | 动力学排版、音乐、速度、转场 |

先用主字体的字重、大小、描边和实心变化建立层级；参数或小字可用协调的辅助字体。多字体拼贴若是既定风格，应让阅读顺序清楚，也不要为“丰富”随机加入英文、伪品牌字或无意义小字。

大多数商业画面里的文字应与产品、人物或场景共同出现。优先选择一种关系：

- 包围：文字环绕、框住、托住或形成产品的视觉舞台。
- 遮挡：文字与产品形成明确前后层级，局部被遮但仍可识别。
- 贴合：文字印在包装、屏幕、墙面、地面、水面、玻璃或产品曲面上，服从真实透视和光影。
- 延伸：文字笔画延伸成产品轮廓、液体、道路、声波、零件、植物或功能结构。
- 触发：产品开盖、点击、碰撞、喷洒、移动或人物动作使文字出现、变形、碎裂、扩散或归位。
- 证明：文字、数字或参数与爆炸结构、刻度、波形、对比、路径或可见结果共同证明功能。

纯文字可作为标题、章节、宣言、品牌收束，也可构成整条歌词、信息解释或文字视觉实验。相邻段可以由语义、章节、色彩、形状、材质、运动方向或声音关系承接，不强制额外设计转场接口；普通字卡在阅读、解释或章节职责明确时也可使用。若去掉文字后画面仍完整，文字只是辅助；文字承担主视觉时，其选词、语义、造型与运动应共同完成本次主题，不以“所有其他产品都不能用”作门槛。

在分镜中具体描述本片实际采用的最终构图、字体尺度、字重对比、行距字距、裁切、旋转、路径、透视、遮挡、与产品接触关系、留白、安全区和视觉层级；不涉及的效果无需补入。不能只写“后续加环形字”“做杂志排版”让视频模型猜。

合格示例：`产品后方纵向重复四层超粗几何无衬线大字“鲜感”，上两层仅保留半透明白色细描边，下两层为实心白字；字宽约占画面 85%，上下越出画幅，产品罐体遮住中间约三分之一笔画，文字仍可辨认；背景字与罐体共用冷青色环境光，不覆盖包装上的真实 Logo。`

不合格示例：`背景加入有设计感的大字。`

品牌名、型号、参数、日期、价格、行动文案、包装字和界面字以准确可读为先，只使用有来源或已确认原文；保真生成和合成规则统一读取 `references/asset-generation.md`。

构图、配色、文字与运动服务当前镜头职责，不逐镜另填一套视觉机制。采用特殊效果时，其局部变化服从已定规则；前后镜头通过内容、主体、动作、形状、颜色、材质或声音关系承接，不重启无关创意。

## 运镜选择

运镜先看职责，不按“高级感”堆动作。

| 运镜 | 心理效果 | 适用场景 | 使用边界 |
|---|---|---|---|
| 推近 | 聚焦、强调、进入情绪或细节 | 产品揭示、人物情绪、关键信息 | 慢推偏情绪，快推偏冲击；不要每镜都推 |
| 拉远 | 揭示环境、释然、宏大、孤独 | 结尾升华、空间关系 | 拉出后必须出现新信息 |
| 摇/俯仰 | 扫视、跟随注意力、从局部到整体 | 环境介绍、从 A 揭示 B | 结尾要有落幅，不做无目的扫场 |
| 横移/跟拍 | 陪伴、流动、沉浸、真实 | 人物行走、探店、通勤、产品线条 | 主体要稳定，不让观众追丢 |
| 固定机位 | 清楚、可信、让动作自己发生 | UGC 口播、产品操作、食品、教程 | 靠内部运动和切近景制造节奏 |
| 手持微动 | 真实、临场、生活感 | UGC、探店、测评、纪实 | 轻微即可，过度晃动会显得低质 |
| 环绕 | 仪式感、360 展示、人物/产品高光 | 产品大片、穿搭、发布会 | 必须展示不同侧面或光影变化 |
| 微距 | 质感、专业、细节放大 | 材质、食物纹理、肌肤、接口、logo | 必须写清具体细节 |
| 慢动作 | 强调瞬间、仪式感、情绪放大 | 水滴、拉丝、开盖、决胜瞬间 | 只给关键动作 |

运镜可以跟随动作、引导发现、表达情绪、展示形体与空间，或参与音乐/图形编排。选定观看位置、运动起止与揭示内容；运镜本身不代替信息推进，固定机位也能因表演、材质或图形变化形成吸引。

进阶运镜可按需使用：甩镜用于快节奏和喜剧点缀；稳定器长跟用于空间沉浸；航拍/升降用于格局打开；一镜到底用于连续变化；速度变化用于产品落地、运动瞬间、开盖、旋转和时间冻结。任何进阶运镜都必须有明确动作链和节奏节点。

艺术空间、展览与文旅按观看路线选择跟拍、横移、固定观察或细节接近，让人理解位置、尺度与内容关系；活动片可另安排人群和主题。不是每次移动都要活化展品或升级庆典，观察本身也要有具体对象与发现。

## 布光和画面质感

| 光线策略 | 效果 | 适用 |
|---|---|---|
| 自然窗光 | 真实、柔和、亲近 | UGC、居家、母婴、生活方式 |
| 高调柔光 | 干净、清新、安全、年轻 | 美妆、医疗感、食品、电商产品 |
| 低调局部光 | 高端、悬疑、力量、质感 | 奢华、科技、汽车、硬件 |
| 侧逆光/轮廓光 | 主体从背景中分离，突出形体 | 人物、车、瓶身、金属、宠物黑毛 |
| 硬光切割 | 戏剧、科技、建筑感、紧张 | 工业、城市、运动、反差叙事 |
| practical 现场光 | 真实空间动机 | 台灯、烛光、路灯、车灯、屏幕光 |

自检：主体和背景是否分离、阴影是否有细节、产品是否有干净高光、人物眼睛是否有眼神光、色温是否有明确动机。

基础光位：主光决定主体形态，辅光控制阴影深度，轮廓光分离主体，背景光建立空间层次，现场光解释光源。人像可用环形光/45 度侧光、蝴蝶光、伦勃朗光、分割光或高调均匀光；场景按家庭、办公、户外、产品、食品、夜景分别选择光线动机。

## 转场和剪辑

先确定此刻为什么切、下一镜让人理解什么。论述接续、证据、对照、章节或音乐关系清楚时可以直接切换，不必共享形状或制造物理动作；同一动作和空间的接续才保护方向、视线与状态。动作切、匹配剪辑、声音桥、遮挡或叠化按实际作用采用，不要求逐镜特殊转场，也不另设种类与次数配额。

| 转场 | 适合 | 注意 |
|---|---|---|
| 直切/硬切 | 信息接续、冲击对比、结果揭示、观点切换、节拍或章节断点 | 写清内容关系；只有物理接续才要求状态与方向连续，不为直切制造形状锚点 |
| 匹配剪辑 | 形状、颜色、动作相似的镜头 | 两个镜头的锚点要清楚 |
| 动作切 | 抬手、开门、倒入、转身、走动 | 在动作中途切最顺 |
| 视线匹配 | 人物看向产品、结果或异常 | 适合人物驱动和轻剧情 |
| 方向匹配 | 运动方向连续 | 适合车、人、产品飞行、横移 |
| 遮挡转场 | 空间转换、时间跳跃、连续换装 | 遮满瞬间切 |
| 叠化/淡入淡出 | 回忆、时间流逝、段落收束 | 用多了会拖慢 |
| 声音桥 | 情绪连接、跨空间切换 | 比花哨画面转场更稳 |
| 静默转场 | 强调、反转、产品揭示 | 静默后必须有有力进入点 |

转场的目标是让观众感到流畅，而不是让观众注意“转场很炫”。强视觉转场的叙事规则读取 `visual-motion-playbook.md`。

艺术活化、穿越和空间巡游优先使用主题化匹配剪辑：画中椅子到真实椅子、画框到窗框、邀请函边框到门框、展品轮廓到投影轮廓、手伸出画面到现实手接住物件。匹配点可以是形状、颜色、方向、动作或声音，但必须服务“静态变动态、平面进入现实、局部打开整体”的主题，不做无意义炫技。

音乐混搭和工具实验可按既定内容用波形、色彩或图形变化连接。技术三视图与排版先守住指代、阅读顺序及运动延续；可用标注线、遮罩、缩放或元素延续，不强制反色、故障与定格。切点可以服从语义、动作或音乐；重要同步点须有实际音频依据，不把所有转场卡在鼓点上。

空间折叠、海报化和效果教程可以用“展示 -> 升级 -> 分层 -> 定版 -> 揭秘”的剪辑节奏：开场先给完成态或最强前后对比，随后在重拍上让背景、倒影、光源、前景剪影和构图大字逐层入场，定版停留后再切到图层、时间线或素材清单。声音设计要对应层级变化，例如色彩打开给低频进入，倒影出现给水波或反射声，文字落位给短促冲击，教程揭秘段降低音乐密度让信息可读。

剪辑点优先落在意义变化处：观点切换、证据出现、状态变化、人物反应、情绪落点、声音重拍或 CTA 收束。画面切走不等于声音切走；A-roll 的人声、旁白或环境声可以继续承载语义，下一句声音也可以先进入，再由画面切过去承接。

口播社交视频适合在短语边界做自然跳切，让表达更紧凑。跳切不是错误，而是创作者剪辑感的一部分；但每次切换都要保持人物身份、场景、声音和表达态度连续。反应镜头、B-roll 覆盖、J-cut、声音桥和短暂静默都属于信息交接方式，必须说明它们交接了什么：观点、证据、情绪、悬念还是行动。

## B-roll 和辅助画面

B-roll 是辅助画面，不是随手配图。它可以覆盖 A-roll 的画面，但 A-roll 的人声、旁白或语义仍可继续。每个 B-roll 镜头必须承担至少一个职责：证明、解释、情绪、幽默、生活感、节奏呼吸或转场交接。

B-roll 中出现的每个醒目主体都要能追溯到当前话题、人物、场景、品牌或视觉母题。若观众会误以为视频换了商品、人物或主题，即使画面好看也必须删除。为了填满横移、推拉或空镜而扫过的无关道具不算生活感。

不要按口播里的每个名词机械配画面。先判断这句话需要观众相信什么、理解什么或感受到什么，再选择辅助画面：

| 职责 | 画面方式 | 常见场景 |
|---|---|---|
| 证明 | 手部操作、真实 UI、产品反馈、前后状态、材质特写 | 产品广告、测评、SaaS、教程 |
| 解释 | 屏幕流程、步骤拆解、结构剖面、图形演示 | 功能讲解、企业服务、课程引流 |
| 情绪 | 生活场景、人物反应、环境空镜、节奏留白 | UGC、品牌片、生活方式 |
| 幽默 | 反差插入、夸张反应、视觉比喻 | 口播、榜单、评论回应 |
| 生活感 | 通勤、使用中、桌面、门店、家庭、工作现场 | 种草、服务、本地生活 |
| 转场 | 动作接动作、声音桥、同形同色、遮挡切换 | 多段口播、长视频、产品流程 |

B-roll 可以比对应台词略早或略晚出现。视觉终点不必和一句话的最后一个字完全对齐；如果最后一个辅助画面还在贡献证据或情绪，可以让下一句声音先进入，再切回人物、产品或图形系统。长视频中连续 B-roll 必须共享边界，避免短暂露出无意义的 A-roll 或空白画面。

## 表演和人物动作

人物动作要有理由，不按每句话分配手势。先定人物对内容的态度：怀疑、兴奋、克制、调侃、认真权衡、亲切分享、专业判断或真诚提醒；再选择少量关键反应：眉毛、停顿、点头、手掌、侧看、身体前倾、语气落点。

表演要服务观点落地。数字、步骤和卖点可以交给画面文字、图形标签或 B-roll；人物手势负责态度、强调和可信感。一个关键反应通常比连续小动作更有力：价格处眉毛上扬，反对意见处短暂停顿，结论处轻点头，调侃处侧看或耸肩。避免每个词都有动作，也避免全程僵硬看镜头。

## 声音结构

商业视频可用音乐、环境声、拟音/产品音效和人声；按本片职责组织，不要求始终叠满。声音也能承载观察视角、人物状态、悬念或反差，不只是背景和动作确认。

- 人声清晰度优先级最高；有旁白时，音乐和音效都要避让人声。
- 音乐在剪辑细化前参与安排；写清音色、节奏特点，以及在具体事件处进入、改变或退出的理由。不要所有片都套“轻起、渐强、高潮、淡出”，也不要每个节拍都切。已有指定音乐时以实际段落为准，未取得音频时不编造精确拍点。
- 声音的距离、方位与遮挡随空间关系变化：门外声音可以先引出画外事件，近处小动作可短暂成为注意中心；切近景不等于一律放大所有声音。连到下一镜的声音应有明确声源或叙事联系。
- 人物状态可以体现在脚步、动作力度、呼吸和停顿的变化里；音乐、拟音与表演共同完成当前变化，旁白不必再解释一次情绪。教程、测评等需要判断真实反馈时，配乐退让，不用合成确认音冒充原始声音。
- 产品出现时可以做声音特写，例如开盖、倒入、快门、磁吸、拉链、落地、咬开、启动。
- 静默也是声音设计。必要时短暂降下配乐、保留环境或动作声，让观众听到决定性细节；完全静默只在内容需要时使用，不把每次揭示都做成同样的停顿。
- 动效声音要和动作链成句：蓄势可用 riser、入场或撞击用 impact/click、落定可用短促确认音、余韵可用 sparkle/空气感；不要给每个小元素都配同样的提示音，连发要有强弱和间隔。
- UI 和数据类声音优先找带物理感的 click、pop、纸张、机械、键盘、磁吸或轻开关声；合成 notification、bleep、success tone 只在系统播报、报错、AI 回执等明确风格需要时使用。
- UGC 可以保留自然呼吸、停顿和轻微环境声；过度配乐和过度降噪会削弱真实感。
- 反差奇观可以用声音并置制造幽默或高级感：音乐保持优雅、轻快或仪式化，环境声真实表现火山、陨石、海浪、风压、玻璃轻响、布料摩擦等外部压力；音乐不必跟着灾难惊慌，音效要贴近具体触发动作。
- 无对白内容按已有事件设计声音的变化与落点，不固定探索、群像或高潮结构。例如奇幻空间巡游可让入口配纸张/铃声、探索配空间混响、活化对应触发音、庆典逐渐加厚乐器；这只适用于已定的奇幻空间内容。自然观察可保留连续环境声，人物无对白片可用动作声和停顿推进；不用魔法声或全编制音乐替代其本来内容。声音选择仍按分镜合同。
- 多参考音乐或声音混搭要先区分来源：A 的 BPM/情绪/音色/色彩，B 的旋律/人声/文化或年代符号，再写两者如何对齐、叠加和融合。不能只说“混搭音乐”，要说明过渡段、drop 点、融合高潮和尾音如何影响画面。
- 数据图形可用轻机械、测量或纸张声帮助分清层级，不要求每个数字卡拍或结尾定格音。需要读懂与比较时，让声音和运动减少争抢。
- 歌词排版可按实际音节和音乐乐句发展，口语排版可跟随语义重音与停顿；视觉主导文字也可自行组织节律。最大字号、反色与唯一彩色只在强调需要时采用，不把每个关键词都做成高潮。

| 层级 | 职责 | 用法 |
|---|---|---|
| 音乐 | 情绪基底和节奏骨架 | 先确定情绪曲线，再剪画面节点 |
| 环境声 | 建立空间真实 | 街道、办公室、厨房、森林、门店、车内 |
| 拟音/SFX | 强化动作重量和质感 | 开盖、脚步、布料、拉链、点击、倒入 |
| 产品音效 | 让产品有可记忆的声音 | 快门、磁吸、启动、引擎、气泡、咬开 |
| 人声/旁白 | 传递信息、观点和情绪 | 必须最清楚，语气像对人说话 |

音乐可选纯音乐、带歌词音乐、钢琴/弦乐、吉他/轻打击、电子/低频或强鼓点，也可由实际环境声与产品声组织节律。按内容、品牌与现有音轨选择，不因时长固定音乐或旁白篇幅；人声时间只按分镜合同。

## 真实 UI、Logo 和文本策略

产品和品牌视频的画面可信度优先级高于“好看”：

- 真实页面、App、SaaS 或桌面产品默认以真实截图、官网、设计稿或用户素材为视觉事实源；非复刻场景可以抽象化，但不能生成假 UI 冒充真实产品。
- 从产品素材中提取视觉语言：字体气质、字号层级、圆角、间距、卡片密度、按钮形状、品牌色、状态色、材质、图标风格和动效气质。
- 表现既有页面、后台、App、官网、报表或产品功能时，优先使用真实截图、录屏、设计稿或用户确认素材；如需 2.5D 运镜或模块飞入，内部把整页、关键模块、空白底板、目标槽位和状态变化拆清楚。没有真实素材时，只能做概念演示或抽象界面，不写成真实产品页面。
- 非复刻场景可规划概念 UI、独立组件和品牌段图形，明确表达对象、信息层级、字体与状态色；生成前判断其可实现性，难以保证清楚准确时，改用真实截图或更抽象的图形解释。实际生成与资产准备遵循生产控制，不由本方法库增加调用。
- 真实 Logo 和商标来自用户上传、品牌文件或可靠公开素材；生成前明确外观依据、识别区域和保留方式，不让模型凭空重画真实商标。需要精确后期叠加时，先确认真实 Logo 文件和实际可用工具。精确文字若需后期，须在生成前选定可执行路径；生成后不为此审片或自动返修、重生，也不承诺一定能后期修好。用户另行明确提出修改时按[版本与修改规则](production-control.md#上游修改与新版本)处理。
- 画面文字默认少而准；卖点、企业口号、品牌主张、活动主题、标题卡、尾帧 slogan、CTA 和真实 UI 原文可以作为设计性上屏文字，不是逐句字幕。
- 需要文字时只用短、准确、可确认的标题字、卖点字或真实 UI 原文；避免长段落、假占位、乱码、小字密集表格和不可控字幕。
- 客户、个人、内部、密钥、实时数据和敏感业务数据必须脱敏、虚构或冻结口径后再进入画面。

| 文本模式 | 使用场景 | 规则 |
|---|---|---|
| 无画面文字 | 氛围片、产品质感、后期另加字幕 | Prompt 禁止随机文字和字幕 |
| 少量精确大字 | Hook、卖点锚点、企业口号、品牌主张、CTA、发布主题 | 每条短文本必须可确认，不逐句复述口播 |
| 真实 UI 原文 | 页面/产品功能演示 | 只保留真实截图或用户确认的 UI 文本 |
| 后期可编辑文字 | 投放、多语言、频繁改文案 | 视频生成尽量做 textless plate |

## 画面层级和合成空间

生成画面时区分三层，避免把后期图形误写成物理场景里的真实物体：

| 层 | 负责什么 |
|---|---|
| 物理场景 | 人、产品、道具、真实互动、屏幕或空间中实际存在的东西 |
| 摄影构图 | 镜头怎么拍、主体在哪、景别、机位、留白、视线和产品位置 |
| 编辑合成 | 字幕、广告大字、MG、图标、卡片、小窗、排名板、进度条 |

需要叠加图形时，先在摄影构图中给人物、产品和图形留出空间；需要真实屏幕或 UI 证据时，优先使用截图、录屏或用户素材。后期卡片、排名板、进度条和标签可以影响构图留白，但不能要求生成主体去触碰一个并不存在于物理场景里的编辑层。

## 视听设计转入生成

本文件确定可见造型和可听表达；第二阶段写清文字分镜与声音并转写完整 Prompt，第三阶段必要资产沿用原授权并在视频确认前完成采用和绑定，视频确认后直接委派执行；相关资产及 Prompt 合同章节按任务需求提前同批并行读取，阶段与授权只按生产控制。已确认的媒介、影调、镜头语言、色板、字体、材质、声音和主视觉规则必须在真实图片与视频中成立。

文字分镜同时确定构图、层级、空间关系、时间、触发、运动、反馈与结束状态，直接指导后续视频生成，不经过分镜预览图。已有首帧参考、真实尾帧和跨片段接缝由 `references/production-control.md` 调度，不在本文件重复维护生成格式与阶段门。

## 文字成为画面

通用创意、城市超现实、教程分享、标题实验、产品广告、品牌片和企业片中，文字可以是画面的主角，而不是后期说明。使用前先判断文字承担哪种角色：

| 文字角色 | 适用 | 执行 |
|---|---|---|
| 空间结构 | 城市名、活动名、系列标题、海报风定格 | 大字与建筑轴线、道路、水面、天空或主体轮廓对齐；可有倒影、投影、透视和遮挡 |
| 动作解释 | 功能隐喻、教程、技术分享 | 动作发生时同步出现短说明，优先高对比底板，不抢主体动作 |
| 系列识别 | 图鉴、法则、挑战、栏目 | 中文概念 + 英文副标题或编号形成固定视觉系统 |
| 辅助信息 | 教程、拆解、工程信息、章节角标 | 小字号、低干扰，只在确有解释职责时出现 |
| 语义运动 | 歌词、态度、关键词、标题实验 | 字体运动方式表达含义，例如坠落、裁切、反相、弹动、吞没、显影 |

文字主导时，阅读顺序、语义与运动共同组织观看：可以一次成形、固定版式内替换、逐步建立关系，或随乐句持续变化。建立规则、中段升级、结尾定版只是可选排法；动作完成、明确截断和循环接回也可结束。写清必要的进入、变化、保持与退出，让人读懂；放大、静止或单一动作已经准确表达时可以保留，不为补叙事另加剧情。

## 视听专项规则

通用创意可以更自由，但不能失去生成可控性：

- 运镜：按观众需要发现什么来选慢推、拉远、横移、环绕或固定观察，不因概念片就默认慢；视觉实验采用 FPV、穿越、速度变化时要有入口和落点；人物时尚用跟拍、环绕、低角度或镜前遮挡时，守住人物身份和姿态。
- 布光：情绪片以光源动机为先，自然窗光、逆光、硬光切割、局部光和现场光都要解释来自哪里；不要随机发光。
- 构图：抽象片也要有视觉重心；留白、对称、框架、引导线和前景遮挡都必须服务主体或情绪，不用空镜凑时间。
- 色彩：确定适合本片的主要色彩关系；内容需要变化时，说明变化怎样发生，例如冷到暖、低饱和到强调色、黑白到彩色、自然色到霓虹。自然观察可以保持原有色彩，不为凑变化而变色，也不无缘由地每镜换风格。
- 作者电影式风格：不要只写导演名或“某某风格”。必须落到可观察规则，例如对称构图、固定机位、横向平移、90 度正立面、90 度 whip pan、垂直俯拍、复古胶片色、统一服装色块、平面化表演、干净道具陈列、轻微颗粒、优雅音乐和荒诞事件的反差。若使用韦斯安德森式审美，优先写绝对中心对称、平面化正立面、一点透视、横向轨道移动、固定机位、垂直俯拍、粉/蓝/绿/金/奶油/红等低饱和粉蜡笔色板、机械规整表演和复古管弦/木琴节奏；只抽取视听方法，不复制专属角色、台词、镜头、服装或剧情。
- 极端视角：仰拍、俯拍、鱼眼、水下、倒置和推到局部符号特写都可以用来建立超现实身份；每次极端视角必须有构图职责，例如放射框架、圆环中心、引导线通道、尺度压缩或与观众直接接触。
- 艺术空间：优先用框架构图、引导线、对称仪式感、横移展示、跟拍探索、低角度/升降打开建筑尺度；画框、窗框、门框、展柜、拱廊和邀请函边框都可以成为“入口”，但每次入口后必须出现新信息，不只做漂亮转场。
- 音乐混搭：先给不同参考各自的节奏、色彩和视觉母题，再用波形、故障、色彩溶解、缩放冲击或粒子脉冲表现叠加；高潮段用较长镜头或连续运动展示融合结果，结尾可回到操作、评价或可复现玩法。
- 技术流三视图：固定机位、中心对称、转盘/旋转、纸张或蓝图质感、等宽数字、标注线生长、错位入场、三视图并置是核心语法；如果是商业产品或真实人物数据，参数必须来自用户材料或改写成概念化标签。
- 动力学排版：可以用黑白反相、遮罩裁切、递归矩形、同心圆、放射线、单点彩色、运动模糊、出画文字和极端留白；字体、色彩和节律保持联系，构图随语义、阅读或强调需要变化。固定构图中的替换、重复与细微变奏同样有效，不要求每镜换构图。
- 转场：优先用动作、声音、光线、形状、材质或同一物件承接；视觉实验可用形状蒙版、材质转化和空间门户。前后联系应可辨认，可以是空间、语义、节奏或形式关系，不把匹配剪辑伪写成事件因果。
- 声音：沿分镜合同的人声默认与省略条件，按本片职责安排环境声、拟音、音乐、静默、尾音或声音桥；不要求全部声音手法同时使用，也不能只写“配电影感音乐”。
- 文案：按主线选择具体可听文本或必要的片名/关键词/章节字；不强求每片有 slogan 或 CTA。字幕与人声分别决定，选择规则只按分镜合同，符号只按资产合同。

## 视觉系统

建立适合本片的视觉联系：物理连续段保持主体、空间、时间、光线与声音状态接续；跨地点、时段或音乐段落可以变化，以路线、主题、视觉线索或声音帮助理解关系。统一不等于各镜保持相同场景与色调，每个节点应推进当前内容。

- 主体必须有一眼可辨的视觉锚点，如特殊轮廓、材质反差、发光结构、运动轨迹或标志性姿态。
- 动作遵循“触发 -> 运动过程 -> 环境响应 -> 状态结果”，写清方向、速度、力度、惯性和结果。
- 场景要回应主体动作，例如水面涟漪、尘埃被气流带动、光线被遮挡、植物被风压弯。
- 同一时刻的运镜应可执行且不矛盾；复合运动写清先后、路径和主次，不机械限制为两个动词。
- 转场从动作、形状、色彩、光线、材质、声音或概念因果中选择一个主要桥接维度。
- 采用贯穿效果时，让观众理解其规则与发展，例如重力改变、空间折叠或材质变形。局部强调、标识成形与转场可以只出现一次，职责明确即可，不要求所有视频全程加特效。
- 开场、结尾及实际采用的高光、反转、转场各有具体职责；不为凑齐这些节点添加变化，也不只把没有发展的氛围场景顺着拍完。
- 做“从容主体 + 失控世界”时，按事件安排外部变化和有理由的主体反应，二者的反差形成看点；不每个秒段都安排升级与微笑，不让灾难动作抢走人物状态，也不把人物写成无动于衷的木偶。
- 采用“艺术空间奇遇”时，可以用观众视点、角色或引路物连接空间；每次进入新区域应带来发现，不只换门框。展品活化与庆典只在所选创意需要时采用，普通导览按真实展品关系展开，节奏按分镜合同。
- 做“多参考混搭”时，必须让每个参考先有可识别的声音、颜色、节奏或画面符号，再安排冲突、叠加、对齐和融合后的新结果。不要把参考元素随机拼贴；融合段要能听见或看见 A 与 B 各自留下的特征。
- 做“技术流数据展示”时，主体姿态、旋转角度、标注线、数字标签和背景材质必须服务同一套信息秩序。标注优先少而准，按身体/产品/空间结构逐层出现，不用无法核实的真实参数冒充事实。
- 做“动力学排版”时，文字可成为主体。选择真正要强调的词与关系，用裁切、反色、尺度、聚合或停顿组织阅读；其余文字可以保持稳定。运动对应语义、层级或声音结构，不要求每个词都动，也不每个词都卡拍。
- 做“符号贯穿”时，先确定符号的主题职责，例如观察、警告、身份或边界。在表达需要的位置再次使用，让关系、意义或韵律发展，不按开中结凑次数。手掌、镜面、屏幕、服饰纹样或道具都可承载，但不能随机堆符号。
- 做“共生缩放”时，必须明确主体和环境如何接缝：头饰与背景花朵对齐、衣料延伸成花瓣、身体位于巨大物件中心、妆容色彩呼应场景。尺度变化要服务身份叙事，不只是把人变大变小。
- 做“框架首尾闭环”时，开场框架负责邀请或打破观看关系，结尾框架负责关闭、遮挡、反向凝视或意义反转。手掌遮镜、门框合拢、花瓣闭合、窗帘拉上、镜头被物体覆盖都可以作为闭环动作；音效峰值要卡在触碰、遮挡或闭合动作上。

让观众能指出具体值得看的变化；内容需要强调节拍、揭示或情绪时再设计视听同步，不为满足高光数量额外加效果或声音。
