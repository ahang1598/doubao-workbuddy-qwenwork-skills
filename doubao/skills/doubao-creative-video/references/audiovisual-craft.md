# 视听工艺通用层

## 文件说明与索引

本文件是每条视频都必须读取的视听工艺层。它解决“怎么拍、怎么听、怎么剪、怎么写”。传播目标、受众张力、证明锚点、创意亮点和风险边界读取 `references/creative-core.md`；视觉效果、运动母版、开场、高光、反转、结尾和转场创意读取 `references/visual-motion-playbook.md`；流程和生成门读取 `references/production-control.md`；类型专属策略读取当前唯一命中的类型文件。

## 每次必检维度

每条视频都要内部检查以下维度，不能只在用户点名时才处理：

| 维度 | 必问 | 失败信号 |
|---|---|---|
| 运镜 | 镜头运动是否推进信息、证明或情绪？ | 只有推进、环绕、展示、定格 |
| 布光 | 光线是否服务质感、氛围、证据或主体分离？ | 无来源光效、主体和背景糊在一起 |
| 构图 | 视线重点、产品、人物和文字是否清楚？ | 主体不稳、产品被遮、文字压住关键信息 |
| 色彩 | 颜色是否服务品牌、情绪或节奏变化？ | 每镜乱变，或所有视频都套同一种流行色 |
| 转场 | 转场是否来自动作、形状、材质、声音或因果？ | 花哨但不承接信息 |
| 连续性 | 前镜为何在此结束，后镜继承了什么？ | 无锚点硬切、动作/人物/场景凭空跳变 |
| 相关性 | 每个主体、道具和插镜是否服务当前主线？ | 为丰富画面加入无关物品、人物或环境 |
| 重复度 | 再次出现的画面是否改变了意义或状态？ | 同画面停留、重复反应、回到开场但没有变化 |
| 音效 | 声音是否绑定动作和节奏重拍？ | 音乐只是背景，拟音无触发点 |
| 文案 | 文字是否增加记忆、解释或行动？ | 重复画面、广告腔、长句、乱码风险 |

## 节奏与重心审片规则

节奏不是镜头快慢本身，而是信息、动作、证明和情绪的密度变化。每条视频进入分镜和 PE 前，必须先选一条主节奏曲线，并把核心表达放在曲线的重拍上。

| 节奏曲线 | 适合 | 时间推进 |
|---|---|---|
| 悬念揭幕 | 新品发布、高端产品、品牌预热、汽车/3C | 局部线索 -> 细节释放 -> 完整揭示 -> 信息落版 |
| 动作闭环 | 产品演示、UGC、教程、开箱、运动饮品 | 触发动作 -> 产品反馈 -> 结果状态 -> CTA/记忆 |
| 生长递进 | 天然、食材、鲜奶、护肤、包装生成、品牌生命力 | 微小起点 -> 逐步生成 -> 尺度打开 -> 产品收束 |
| 奇幻转合 | 零食、宠物食品、美妆、节庆、童趣创意 | 熟悉场景 -> 异常触发 -> 语义变身 -> 产品解释 |
| 证明链路 | 科研、清洁、企业服务、SaaS、源头产地 | 问题/源头 -> 过程证据 -> 使用落地 -> 可信结论 |
| 情绪升温 | 露营、徒步、香氛、服饰、品牌形象 | 环境进入 -> 人物/产品动作 -> 情绪扩展 -> 安静定格 |
| 并行汇聚 | 多人物、多场景、多 SKU、活动预热 | 各线准备 -> 同步推进 -> 合流高光 -> 群像/产品尾帧 |

短片直出只锁开场、核心成立点和收束职责，不固定中段秒数：

```text
开场：尽快给刺激、承诺、主体、问题、产品线索或异常规则，不能空。
动作展开：让主动作从起点连续走到接触、触发或第一次结果。
核心成立：在最适合当前内容的位置给最强证明、最大视觉变化或情绪高点。
结果回收：高光之后给反馈，再回收产品、品牌、人物状态、主题字或行动。
```

黄金三秒不是建立静态气氛，而是完成停滑承诺。除 General 简单动态任务和用户明确要求的真实一镜到底外，15 秒及以内视频的 0-3 秒至少发生 `3` 个可见信息事件并有 `1` 次有意义切镜或观看关系变化；第一镜通常不超过 `1.2` 秒。开场至少使用异常结果前置、强动作冲突、主体主动入场、声音触发画面变化、问题与证据并置中的一种。General 简单动态任务不强制切镜或三个叙事信息事件，首秒启动可见运动并持续产生状态变化；真实一镜到底通过连续摄影机路径、主体行动和空间关系变化推进。任何视频都禁止无意义静止、空转慢推或只靠发光撑满前三秒。

如果视频超过 15 秒，仍按“建立规则 -> 证明升级 -> 高光揭示 -> 稳定收束”组织，不要把多个 15 秒短片简单拼接。

重心检查：

- 每个镜头都要写一句“本镜头推进什么”。推进对象只能是核心判断、证明动作、情绪弧线、品牌资产、产品识别、人物关系或行动入口。
- 在镜头地图阶段，两个连续槽位不能只换角度展示同一件事。第二镜必须预先承担更近的证据、更清楚的动作、更强的反应、更明确的文字或更稳定的主体露出，否则不创建该槽位。
- 短片的动态必须同时从四层判断：主体动作、镜头/景别切换、场景或画面状态切换、剧情/信息推进。单纯让人物抬手、产品变大/旋转、镜头慢推/环绕/拉远、边框发光或背景轻微变化，只算低信息运动，不能替代观看关系和叙事状态变化。通常每 `0.8-1.5` 秒至少出现一次实质信息变化；它可以在镜内发生，不要求机械切镜。
- 15 秒及以内视频中，一个镜头若超过 `2` 秒，必须在镜内形成至少三个可分辨的动作或状态阶段，例如“发现 -> 靠近 -> 接触 -> 反馈”，并改变动作、观看关系和信息状态中的至少两项。General 简单动态任务可用“启动 -> 发展 -> 落定/回环”，真实一镜到底可用连续空间节点和摄影机路线形成这些阶段。只靠匀速推拉、主体渐大、发光增强、人物微动、悬浮或静态停留撑满 `2-8` 秒，判定为拖沓，必须重写调度；只有多镜头方案才通过拆镜解决。
- 慢镜头必须有实质变化：动作触发新状态、视线发现新对象、空间关系改变、证据逐层显露、文字与结果同步落位。光扫、轻推、轻微表情和环境音变化只能作为辅助，不能单独算一个新节拍。短片直出的每个片段都不允许缓慢空镜；完整版也尽量少用空镜，只有空间建立、证据消化、情绪转折、声音桥或品牌资产显影这类明确职责成立时才短暂保留。
- 快剪必须有保留点：产品名、包装、UI 状态、价格/优惠、品牌主张、人物反应和 CTA 必须有可感知停留。
- 结尾前 1 秒不再引入新卖点，除非它是唯一 CTA；普通单产品、单主张或单 CTA 尾帧控制在 `0.6-1.0` 秒。复杂发布信息、活动日期或合规文字可更长，但必须明确阅读职责。

## 15 秒节奏与切镜导演法

15 秒视频不得套用固定的 `3-7／7-11.5／11.5-14` 分段。只锁两个边界：需要黄金三秒的视频在 0-3 秒完成停滑、主体线索和首次反馈；存在普通静态尾帧时只占最后 `0.6-1.0` 秒。中间时间先找主动作完成点、证明成立点、高光点和结果回收点，再按内容选择一条波形：

| 波形 | 适用内容 | 排法 |
|---|---|---|
| 快起 -> 稳证 -> 快收 | 信息流、产品证明、UGC | 开场快速建立问题和主体；中段给完整动作与可读证据；结果出现后迅速回收 |
| 逐级加速 -> 高光 -> 短停 | 发布、运动、变化升级 | 每次动作或场景变化缩短间隔并增加信息；高光后立即给短暂结果停留 |
| 快慢交替 -> 汇聚 | 多人物、多功能、多场景 | 快镜提出不同线索，较慢镜解释关键关系，最后让线索汇聚到同一结果 |
| 连续推进 -> 节点变速 | 一镜到底、跟拍、空间旅程 | 不切镜；在转身、开门、接触、进入新空间或环境反馈处改变速度、距离和观看目标 |
| 结果前置 -> 倒推线索 -> 原因揭示 | 悬念、清洁、效率、产品结果 | 先给异常结果，再沿痕迹、动作或状态逐步倒推，最后揭示产品、人物或关键操作 |
| 稳态建立 -> 突然打断 -> 连续应对 -> 新稳定 | 喜剧、反差、问题解决、生活方式 | 先让正常秩序可读，一个事件打破它，随后用连续动作解决并建立新的结果状态 |
| 单点触发 -> 层层扩散 -> 整体响应 -> 回收到点 | 材质、声音、空间和品牌视觉 | 从一个接触点、声音或文字开始，让变化扩大到主体和环境，再收回产品、人物或符号 |
| 两线交替 -> 节奏对齐 -> 同场汇合 | 对比、多人物、多地点、多状态 | 两条线分别建立差异，交替缩短间隔，在动作、声音、形状或目标一致时汇合 |
| 问题脉冲 -> 回答脉冲 -> 证据停留 | 教程、问答、UGC、SaaS | 每个问题立即接动作或画面答案，关键证据放慢看清，再进入下一组问题与回答 |
| 克制积累 -> 局部释放 -> 完整爆发 -> 余韵 | 高端、情绪、运动、发布 | 蓄力阶段仍持续增加线索和压力，先释放一处反馈，再给全片高光，最后短暂收气 |
| 建立规则 -> 两次变奏 -> 打破规则 -> 新规则收束 | 概念片、视觉实验、品牌片 | 先让观众学会同一规则，两次重复都升级信息，随后有理由地改变规则并回收主题 |
| 起点 -> 偏离 -> 回归 -> 无缝接回起点 | Loop、单图动态、循环展示 | 主动作离开初态，次级运动延迟响应，回程消解变化，末态在姿态、速度、光线和机位上接回首帧 |

排法固定遵循五步：先标主动作的起点和终点 -> 标证明或情绪真正成立的时刻 -> 把高光放在核心最清楚的位置 -> 在动作中点、反馈点或观看任务变化处安排切镜 -> 最后检查镜长是否形成长短对比。除 General 简单动态任务和真实一镜到底外，15 秒视频通常形成 `8-10` 镜，但镜头不能机械落在同一秒点；不得把“正常或稍快”理解成每秒硬切，也不得把“动作完整”理解成长时间不切。

上表不是完整枚举，也不是固定模板。没有一条现成波形适配时，按下面方法从当前内容推导新波形：

1. **列不可移动节点**：先标出用户明确要求的动作、台词、产品证明、人物反应、场景变化、高潮和结尾；这些节点决定波形，不能为了套模板改写。
2. **给每个节点判断三种需求**：信息密度高低、动作强度高低、看清所需时间长短。信息密集或关键证据需要更稳定、更长的可读段；动作冲击、过门和反应可以更短，但不能丢掉起点和反馈。
3. **确定主重拍**：全片只选一个最重要的证明、高光或情绪落点作为最高点；其他节点只能铺垫、升级、对照或回收，不能连续争抢高潮。
4. **连接节点**：相邻节点有动作、视线、声音、形状、遮挡或状态锚点时可以切镜；没有切镜理由时保持镜内连续，并通过跟随、推拉、横移、焦点或前后景变化改变观看关系。
5. **分配时长**：先给完整动作和可读证明所需时间，再把剩余时间分给过门和呼吸；短镜服务触发和转折，长镜服务完整动作、证据读取或情绪落定。不得先平均分秒再填内容。
6. **画出强弱序列**：用 `1-5` 表示每个节拍的视听强度。连续三个节拍同级说明节奏平；连续全高说明没有高光；强度变化与核心无关说明波形失焦。调整时优先移动、压缩或合并节拍，不先增加特效。

需要重新规划波形的信号与改法：

- 开场到 3 秒仍不知道主体或看点：把结果、异常、强动作、关键问题或第一证据前移。
- 核心证明太快看不清：压缩前后过门，把时间让给完整操作、结果状态和必要文字。
- 连续三个镜头同长度、同强度：把其中一个改为短触发、一个改为完整证明、一个改为反应或结果。
- 高光出现两三次且互相竞争：只保留最能证明核心的一次，其余降为铺垫或局部反馈。
- 中段信息堆满：删除不服务核心的辅助机制，或把次要信息交给旁白、图形层和尾帧，不机械增加镜头。
- 动作被切断或人物/产品瞬移：移动切点到动作中点、接触点、遮挡峰值或反馈点；仍接不上时合并镜头并重新安排摄影机路线。
- 结尾突然或拖长：提前在前一镜完成结果反馈，只把最终识别、主题或 CTA 留给必要收束时间。
- 用户要求的节奏与推荐波形不同：以用户要求为准，保留其速度和情绪方向，只修正无信息停留、动作断裂和不可读节点。

切镜优先落在七类节点：

1. **动作中点**：拿起正在送向目标、转身正在完成、门正在打开时切，后镜从相同动作相位继续。
2. **接触/反馈点**：按下、咬下、放入、落桌、连接、涂到皮肤后，切到结果或反应。
3. **视线落点**：人物看向某物，切到其看到的证据；证据出现后切回反应。
4. **遮挡峰值**：手、产品、门框、衣料、前景物遮满画面时切到下一角度或场景。
5. **形状/位置匹配**：相似轮廓、同一主体位置、相同运动方向连接产品、场景或结构。
6. **声音重拍/声音桥**：下一场景声音先进入，或在咔嗒、咬合、落地、提示音、鼓点处切。
7. **状态改变**：空到满、乱到整、未连接到完成、问题到结果时切换观看关系。

若当前镜头找不到切点，不允许继续停留。先为主体补一个真实动作、观察目标、反馈、遮挡物、声音来源或状态变化，再在上述节点切；仍找不到时说明该镜头没有推进职责，应回到镜头地图重写，而不是减少切镜。

运镜必须短而有目标：

- **快速推近**：在动作启动或证据出现时靠近关键部位，终点必须可读；不做无终点慢推。
- **跟随/横移**：跟着手、人物、产品、数据或道具完成空间位移，让路径本身交代逻辑。
- **短拉远**：动作完成后揭示整体结果、人物关系或环境反馈，不用于重复展示。
- **拉焦**：同一空间中从前景主体切到后景证据，或从产品切到人物反应。
- **摇镜/甩镜**：主体快速转移视线或位置时使用，方向必须由前一动作决定。
- **环绕**：只有每个角度揭示不同结构、证据或场景变化时使用；单纯绕主体转圈禁止。

运镜和节奏的关系：

- 推近负责聚焦核心，不负责“显得高级”；推近终点必须是证明点、产品局部、人物反应或文字落位。
- 拉远负责揭示关系或规模；拉远后必须出现新场景、新人群、新系统或完整产品。
- 横移/跟拍负责动作链，必须让观众跟着产品、人物、宠物、光点、数据卡或手部动作发现信息。
- 环绕/旋转负责全维度认知或仪式感；每转到一个角度要看到新结构、新材质、新状态或光线变化。
- 固定机位负责可信和可读；固定不等于静止，画面内要有堆叠、开合、试用、拉扯、反应、图形落位或声音重拍。

## 通用镜间因果与剪辑连续性

本节适用于通用创意、UGC、产品广告、品牌 TVC、企业商务以及所有长短视频。镜头多不等于剪辑成立，运镜连续也不等于内容有推进。逐镜设计前先写一条可复述的动作/信息主链，逐镜设计后再检查每一对相邻镜头。

每次切镜必须同时成立：

1. **切镜理由**：新动作开始、前一动作产生反馈、人物视线发现信息、观点/证据切换、空间关系改变、情绪转折、章节结束或结果揭示。
2. **承接锚点**：动作、视线、运动方向、主体位置、构图形状、颜色/光线、声音、文字/图形、遮挡、道具或状态至少一项连续。
3. **信息增量**：后一镜第一次增加证据、关系、反应、结果、情绪判断、品牌归属或行动信息，而不是只换角度。

这三项必须在镜头地图和分镜写作时同时设计，不等 Prompt 完成后再删除。缺少任一项时，先补触发动作、观察目标、反馈或状态变化，再确定切点；花式转场只能美化已经成立的逻辑，不能创造本来不存在的逻辑。

连续性按主体类型分别锁定：

- **人物/手部**：身份、服装、姿态、视线、手势起止、进入方向、轴线和互动对象连续。随机切脸、随机换模特、连续无关系反应镜头都不成立；多人必须通过对话、同一事件、传递物、分屏、共同动作或群像汇聚建立关系。
- **物体/产品/道具**：位置、朝向、比例、开合、空满、完好/变化等状态必须由动作解释。物体突然变大、飞出、装满、破裂、归位或发光前必须有可见或可听触发，除非已提前建立该世界规则。
- **场景**：换场对应人物移动、时间推进、任务升级、观点变化或功能阶段。下一场景可由门框、前景遮挡、声音先行、同形、同色、共同方向或线索道具带入，不能随机换背景。
- **景别**：景别服务观看任务，通常按“建立空间/关系 -> 靠近动作 -> 特写证据 -> 回看反馈/结果”组织。全景可直切特写，但必须有动作点、视线目标、同构图位置、声音重拍或明确冲击职责；连续三个以上特写必须属于同一动作链，否则需要中景重建空间。
- **声音与文字**：声音可先于画面进入形成 J-cut，或延续到下一镜形成 L-cut。花字、标题、参数和图形必须在对应动作/结果发生的瞬间进入；拟声字不得晚于声音与接触点，功能字不得出现在无关动作上。

六类失败必须在镜头地图阶段前置排除，最终 Prompt 预检只作为第二道防线：

- **长镜假变化**：同一全景或人物镜头持续 `5-8` 秒，只做慢推、拉远、渐大、发光或轻微动作。
- **随机特写串**：连续切人物脸、手、材质、道具或功能，却没有共同事件、动作接力或信息递进。
- **无关插镜**：画面里的物品、人物、场景或 B-roll 无法回答“它证明/解释/推进什么”，例如饮品片突然展示没有叙事职责的化妆品。
- **重复镜头填时长**：同一动作、表情、构图或结果连续停留/重复，第二次没有升级、反应或新含义。
- **伪回环**：结尾回到开场构图，但主体、状态、关系和意义几乎没有改变。真正回环必须让观众一眼看出前后差异或答案。
- **无因果高光**：物体突然飞出、场景突然变形、人物突然惊讶。高光前必须出现触发或蓄力，高光后必须出现反馈和结果停留。

高频动作桥示例：

- **拿取到入口**：手进入并捏住食物 -> 手腕带着食物向嘴边移动，镜头从物体特写拉到能同时看见手和脸的中近景 -> 在手腕越过下巴时动作中切 -> 后镜保持同一只手、食物朝向和移动速度，继续送到唇前 -> 咬合触发碎裂与拟音。不得从“手捏住”直接跳到“牙齿前”。
- **刷头到涂抹**：旋开瓶盖 -> 刷头沿瓶口刮去余量 -> 一滴质地在刷头尖端形成并立刻被带向使用部位 -> 镜头跟随手部移动或用刷头越框遮挡切换 -> 后镜从相同方向接住刷头并完成第一笔涂抹。瓶口上方悬停、滴落和涂抹各只保留能看清变化的必要时长。
- **取料到上脸再放回**：手指触碰质地 -> 取出少量 -> 手从产品位置连续移动到脸颊，使用中景交代空间路径 -> 指腹接触脸颊后切近景看涂开与肤感反馈 -> 镜头拉回中景，手离开脸颊并拿起/放下产品 -> 产品落桌的接触声和稳定位置带入尾帧。不得从嘴边瞬移到脸颊，也不得从涂抹特写直接硬切桌面产品。
- **特效触发**：真实接触点已经足够有冲击力时优先放大材质、碎裂、液体、声音或环境反馈；不额外添加与视觉系统无关的闪电、光波、粒子或爆炸。特效必须继承当前色板、材质和运动方向。

最终以静音顺看和抽帧检查双重验收：静音时仍能从动作、视线、构图和状态看懂推进；按关键帧抽看时，相邻帧不能只是同画面微调，也不能在全景与特写之间无锚点往返。若去掉任一镜头后信息完全不受影响，优先删除该镜头。

## 生成式镜头和剪辑描述

常用镜头效果写法：

| 效果 | 画面职责 | 生成描述重点 |
|---|---|---|
| FPV 穿越 | 让观众冲入场景，快速揭示空间奇观 | 低视角、高速度、路径从远到近、围绕主体或穿过粒子群；转弯和加速有运动模糊，揭示主体时短暂放慢 |
| 产品特写 + 浅景深 | 把产品从生活场景中分离出来，同时保留氛围 | 焦点锁定 logo、杯身水珠、质地、按压口、鞋面纹理或 UI 关键区；背景可辨但柔焦，光斑和环境色服务情绪 |
| 固定机位 + 元素动效 | 让信息清楚，靠画面内动作制造节奏 | 机位稳定，主体不漂移；纸片、手指、文字、产品模块、UI 卡片或手部动作按节拍进入、落位、停留 |
| 2D/平面虚拟运镜 | 在扁平插画、排版、拼贴和信息图中模拟推拉平移 | 推近、横移、缩放要有缓动、惯性和停顿；不要匀速滑动，避免像 PPT |
| 尺度揭示运镜 | 先给正常参照，再揭示巨大或微缩主体 | 开场先看见人、车、手、桌面或建筑；随后推拉、上摇、航拍或低机位揭示尺度反差 |
| 贴地/低角度跟拍 | 放大速度、压迫感、脚步、滚动和巨物 | 镜头贴近地面纹理，主体从画面边缘掠过；背景拖影和地面线条强化方向 |
| 90 度俯拍 | 让纸张、桌面、食物、文字和流程变成平面图形 | 垂直俯视，纸张/产品/手部在桌面上完成翻开、折叠、摆放、标注或对比；光从侧方形成纹理 |
| 超低仰拍/广角 | 让人物、产品或建筑产生巨人感、阔感或时尚张力 | 主体脚部或底部贴近画面下缘，天空/建筑留出大面积背景；广角拉伸要服务气势，不让产品变形失真 |
| 微距细节 | 放大质地、温度、声音和触感 | 明确拍哪个细节：水珠、冰块、墨迹、纸纤维、咖啡液、饼干屑、面料纤维、接口、手指触点 |
| 手持纪实微动 | 建立真实在场感和创作者视角 | 轻微呼吸感、近距离动作、自然跳切；不要剧烈晃动到看不清主体 |

剪辑节奏写法：

- 快慢要形成呼吸。开场 0-3 秒给异常、结果、关键产品线索或强动作；中段放慢让观众看懂主机制或证明动作；收尾快速回收或稳定定格。
- 快不等于乱。快剪每个镜头仍要有主语、动作和新增信息；高速运动中要用产品、颜色、线索道具或声音保持连续。
- 慢不等于空。慢镜头必须有内部变化，如水珠滑落、纸张翻开、文字落位、手指靠近、光扫过 logo、主体眼神转向或声音渐停。
- 关键动作可以用速度变化：正常速度进入，触发瞬间放慢，结果落定后恢复正常；不要整条片都慢动作。

转场要从画面逻辑里长出来：

| 转场 | 写法 | 适合 |
|---|---|---|
| 遮挡转场 | 手、纸片、衣料、糖果、包装、门框或产品边缘完全遮满画面，在遮挡峰值切换 | 换装、开箱、场景跳转、真实+卡通混搭 |
| 运动模糊转场 | FPV、甩镜、奔跑、滚动或高速粒子在最模糊瞬间切到下一场景，方向保持一致 | 城市穿越、运动、速度感、道具贯穿 |
| 文字转场 | 字体缩放、裁切、反相、弹入、拆散重组或字重变化完成镜头切换 | 极简大字、新闻解释、歌词/标题片 |
| 纸张/翻页转场 | 便签飘落、纸张翻开、撕纸覆盖、报纸翻页或台历页替换 | 拼贴、活动预热、纸媒美学、教程揭秘 |
| 焦点转场 | 焦点从背景拉到产品，或从产品推到环境反应 | 咖啡、香氛、美妆、生活方式产品 |
| 框架穿越 | 镜头推入画框、屏幕、包装开口、门框、杯口或纸洞，再从另一层世界出来 | 画中画、包装入口、艺术活化、产品内部世界 |

每个转场都要绑定声音：遮挡可用轻 whoosh，纸张用摩擦/啪，文字用 click/pop，液体和冰用飞溅/低频，焦点切换可以短暂降噪或用环境声桥。转场音效不能盖过人声和核心信息。

## 真实与虚拟合成可信度

当视频使用实景合成、城市超现实、C4D/AI 物体植入、2D 卡通贴片、建筑变形、巨型产品、粒子幻变或虚拟 UI 进入真实空间时，创意能否成立取决于“接触感”。不要只写“真实场景中出现一个巨型物体”；必须写清它如何和真实世界发生关系。

合成镜头必检：

| 维度 | 要求 | 失败信号 |
|---|---|---|
| 透视 | 虚拟物体的消失点、地平线和镜头高度匹配实景 | 物体像贴纸漂在画面上 |
| 光源 | 主光方向、色温、明暗层次和高光位置一致 | 虚拟物体亮得不属于现场 |
| 接触阴影 | 落地、贴墙、压住、穿过、靠近时有阴影或环境遮挡 | 巨型物体没有重量 |
| 遮挡关系 | 人、栏杆、树、桌沿、门框、手部等可遮住虚拟元素 | 元素永远浮在最上层 |
| 运动模糊 | 快速移动、甩镜、穿越、变形时有对应模糊和拖影 | 实景在动，虚拟物体过分清晰 |
| 材质反应 | 金属、玻璃、水、布料、皮肤、食品等有合理反光和纹理 | 所有材质都像同一种塑料 |
| 声音触发 | 碰撞、开合、弯折、弹出、退潮、生成、归位都有声音反馈 | 画面很大，声音没有重拍 |

合成玩法要先定机位策略：

- 真实手持/UGC：允许轻微晃动和不完美，但虚拟元素必须跟随相机运动和焦点变化；适合一个关键超现实反馈。
- 稳定广告机位：适合产品开合、悬浮、阵列、空间变形和 packshot；要求透视、光影、遮挡更干净。
- FPV/航拍/穿越：适合城市、展厅、工厂、牧场和大空间；每次穿越必须揭示新关系，不只是炫镜头。
- 等距/微缩：适合把城市、工厂、桌面、货架或流程变成可读模型；信息层要清楚，避免小字和主体混在一起。

音画同步规则：

- 弯折、碰撞、弹出、吸入、退潮、拉直、填满、开合和定格，都要落在音乐或音效的可感知拍点上。
- 大动作只给少数重拍；小粒子、小标签、小光点可以用弱拍错峰，不要每一拍都全画面冲击。
- 超现实镜头完成后给一个短停顿，让观众看清“变化后的结果”和“产品/品牌在哪里”。

## 文案和表达策略

文案策略先于具体句子。每条视频先定一句内部表达锚点：观众看完应该理解、相信、感到、记住或去做什么；再决定这些信息由口播、旁白、画面文字、图形标签、真实 UI、产品动作、声音或尾帧承担。默认无字幕不等于没有文案策略。

常用文案职责：

| 职责 | 形式 | 用法 |
|---|---|---|
| 停滑 | 首句口播、标题卡、强动作短字 | 1-3 秒内给问题、结果、反差、承诺或异常 |
| 解释 | 旁白、讲解口播、章节字、图形标签 | 把画面看不出的逻辑说清楚，避免长段说明 |
| 证明 | 参数短字、步骤标签、真实 UI 原文、前后状态字 | 只写可被素材、动作或已确认事实支撑的信息 |
| 记忆 | slogan、关键词、产品声音、品牌色文字 | 让观众能复述一个词、一句话或一个画面 |
| 行动 | CTA、尾帧按钮感文字、口播收束 | 只保留一个主动作，和传播目标一致 |

文案形态选择：

- 口播适合 UGC、讲解、测评、创始人表达、知识引流和需要真人可信感的内容；台词要像人对人说话。
- 旁白适合产品广告、品牌片、企业片、纪录片感和无出镜讲解；句子少而准，必须对应画面证据或情绪变化。
- 画面文字适合停滑、卖点锚定、章节转换、尾帧收束和静音可读；每条短字只承担一个信息点。
- 图形标签适合排行榜、对比、进度、步骤、功能演示和数据可视化；文字要随状态变化出现、替换、积累、比较、揭示或完成。
- 真实 UI、包装和屏幕文字只使用用户素材、真实截图或明确确认的文本，不让模型随机生成小字。
- 非 TVC 的纯视觉方案只在用户明确要求默剧、无旁白、无台词、纯音乐、静音、无声或纯画面时启用，不能由 Agent 自行触发。品牌 TVC 允许 Agent 按“完整旁白优先、少量旁白其次、无旁白最后”判断；只有画面因果、品牌识别、情绪推进和结尾主张已经完整可读时才采用纯视觉，并用音乐、环境声、拟音、短标题、关键词或尾帧定版承担表达。其他场景必须至少使用旁白、口播、对白、画外音或解说中的一种可听人声。

写文案时先压缩成“一个主句 + 少量证明词 + 一个收束”。不要同时堆痛点、卖点、品牌理念、促销、下载、关注和预约。画面已经能证明的内容不重复读；画面无法直接表达的因果、选择理由和行动指令交给文字或人声。

文案必须和当前画面、产品、卖点或主玩法发生关系，不能在画面之外另写一首抽象诗。每一句旁白、口播、标题字或尾帧 slogan 都要回答三个问题之一：为什么此刻出现、它指向画面里的哪一个可见证据、它让观众新增了什么判断。重复同一句抽象判断、把“远方、热爱、答案、未来、自由、从容、想象”这类词连续堆叠，或删掉后完全不影响理解的句子，都要删除或改成和产品动作、品牌资产、场景压力、人物选择、声音母题或结尾回收有关的具体表达。

## 文案动作和语感

文案不是把卖点描述出来，而是在视频里做一件事。每一句口播、旁白、画面文字、花字、图形标签、尾帧 slogan 或 CTA，都要先判断它的动作：它是在筛选观众、挑衅、放大卖点、换视角说话、制造留白、把两个不相关的概念撞在一起、和画面形成反差，还是用轻微陌生的语法制造停顿。没有动作的句子会变成说明书。

写文案前先定三件事：

- 说话关系：朋友提醒、主播催单、专家解释、创始人自述、品牌旁白、旁观者讲故事、产品自述、问题/痛点的反派口吻，或角色之间的对话。
- 句子动作：这句话要挑起好奇、筛选身份、反驳常识、夸张放大、给证据、留下半句、制造反差、外化声音、推动行动，还是完成记忆。
- 画面关系：这句话是在补画面没有说出的意义，还是故意和画面对着干；不能把画面已经清楚展示的内容再复述一遍。

常用文案动作：

| 文案动作 | 用法 | 边界 |
|---|---|---|
| 身份命名 | 不先夸产品，先说“谁会需要/配得上/正在经历它” | 不能羞辱用户或制造歧视，身份要和产品真实场景有关 |
| 挑衅筛选 | 用“你敢不敢、别用除非、不是给所有人”的张力制造停滑 | 适合短视频和强态度品牌；企业、医疗、母婴、公益要克制 |
| 荒谬放大 | 把一个卖点夸张到可视化，让观众记住核心属性 | 夸张必须明显是创意表达，不能变成虚假功效、价格或数据承诺 |
| 换口吻 | 让产品、痛点、敌人、旁观者、未来用户或物件说话 | 换口吻要带来新鲜判断，不要只把主语换掉 |
| 说半句 | 留出悬念，让观众自己补完结果或情绪 | 信息型和合规型内容不能故意含糊关键事实 |
| 概念碰撞 | 把产品和不相关的动作、名词、空间或职业相撞 | 碰撞后必须能回到产品机制或观众情绪，不做纯怪词 |
| 文画反打 | 画面负责事实，文案负责意义；画面美时文案可以狠，画面狼狈时文案可以亮 | 不能反到看不懂；反差要服务主线 |
| 语法陌生化 | 用轻微“不正常但能懂”的表达让大脑停一下 | 只用于短句；不能造成乱码、病句堆叠或品牌低质感 |

文案动作要迁移适配，不是套固定语气。同一个动作在不同视频类型、行业风险、品牌调性、平台语境和观众关系里，要改强度、改身份、改说法；不合适时直接换动作。挑衅、荒谬放大、文画反打和语法陌生化不能默认使用，也不能为了“有创意”破坏信任、事实边界或品牌安全。

类型适配：

| 场景类型 | 更适合的动作 | 慎用或降级 |
|---|---|---|
| UGC / 信息流 / 带货 | 朋友提醒、吐槽、反问、挑衅筛选、即时花字、证据句 | 不要全程怼人；功效、价格和稀缺不能夸张 |
| 产品广告 / 商品短片 | 感官放大、拟声、概念碰撞、使用前后、荒谬可视化、尾帧记忆 | 荒谬必须明显是创意表达，不能冒充真实效果 |
| 品牌 TVC / 高端形象 | 留白、文画反打、隐喻、短句回收、声音母题 | 少用网感挑衅和密集花字；不要把每句都写成 slogan |
| 企业商务 / SaaS / 工具 | 事实转译、任务前后、问题反问、流程状态、概念碰撞 | 避免攻击竞品、夸张承诺和空泛“赋能” |
| 教育 / 知识 / 解释器 | 反常识提问、误区纠正、步骤揭示、类比碰撞 | 不用故意神秘化关键结论 |
| 医疗健康 / 母婴 / 公益 / 政企 | 提醒、证据、克制隐喻、真实处境、温和行动 | 避免恐吓、羞辱、强挑衅、焦虑营销和过度玩梗 |

同一个动作可以迁移成不同强度：

- 挑衅在零食里可以是“别眨眼，它会碎得很响”；在企业片里应降级为“效率不是口号，是每个节点少等一次”。
- 荒谬放大在跑鞋里可以把速度写成风和地面反应；在 SaaS 里更适合写成“月底才发现的问题，现在提前亮红”，把夸张改成任务状态。
- 换口吻在护肤里可以让黑眼圈说话；在母婴里更适合让“夜里的一次少打扰”说话，而不是制造敌人。
- 文画反打在品牌片里可以更诗性；在教程和企业演示里要清楚服务结论，不能让观众猜错。

反 AI 感改写规则：

- 少写“开启、赋能、焕新、极致、沉浸式、品质生活、重新定义、不止于、全新体验、每一个瞬间、让生活更美好”这类通用抽象词；除非它来自用户品牌原文，或后面立刻接具体动作和画面证据。
- 把抽象形容词改成可看见、可听见、可感到的东西：动作、材质、声音、时间差、前后状态、人物反应、使用场景或一个具体结果。
- 不要让每句话都像 slogan。前段可以像人话，中段给证据，结尾再允许一句更收束的品牌句。
- 口播保留一点判断过程：犹豫、反问、吐槽、转折、让步、限制条件或观察细节，比全程完美夸赞更可信。
- 旁白可以诗性，但每句都要落在画面上；不能只写“高级、自由、热爱、远方、未来”。
- 同一句旁白或同类口号不得无意义重复。若使用回环句，第二次出现必须因为画面状态改变而获得新意思，例如从问题句变成答案、从个人动作变成品牌收束、从局部线索变成完整定版；否则视为填时长。
- 花字可以更即时、更口语、更有反应感，例如拟声、短叹词、圈注、反问、状态锁定，但必须和动作、声音、表情或状态变化绑定。

每条核心文案写完后做“换品牌测试”：如果换成另一个品牌、产品或城市仍然成立，这句话通常太通用。重写时从产品独特结构、材质、味道、声音、使用阻力、目标观众的隐秘情绪、当前画面的异常机制或结尾回收点里长出来。好文案不是填模板，是长在当前产品、观众和画面机制上的一句话。

## 画面文字和图形信息层

画面文字可以是单个标题，也可以是图形信息层。排名板、对比板、进度条、时间轴、卡片、图标、UI 面板、数据标签、状态提示、动态图表、手绘标注和尾帧 CTA 都是通用表达工具，任何类型视频都可以用；关键是把它们改写成当前场景里可理解、可确认、可生成的对象。

所有视频都要做一次动态信息层判断：这条片是否需要用图形、数据卡、UI 状态、手绘标注、动态图标、MG 或动力学排版来帮助观众看懂关系、比较、过程、结果或行动。判断结果可以是“使用”，也可以是“不用，由镜头/声音/剪辑承担”，但不能默认忽略。口播、采访、街采和创始人视频也可以使用这些层，只要它们覆盖的是观点切换、证据补充、问题归类、步骤推进或 CTA，而不是把逐句字幕换成花哨卡片。

图形和 UI 动效必须继承当前主体的视觉语言。涉及 App、SaaS、平台、桌面产品、官网或已有品牌系统时，先从真实素材里提取字体气质、字号层级、间距、圆角、卡片密度、按钮形状、品牌色、状态色、边框、阴影、渐变和图标风格；标题字、数据卡、进度条、转场线条、粒子、光效和尾帧都复用或克制扩展这些 tokens。不要另套一张“宣传片皮肤”，也不要把所有产品都做成同一种玻璃卡片、霓虹科技线或居中大卡。

先决定观众的信息路径：

```text
第一眼看哪里
  -> 正在比较什么
  -> 哪个状态发生变化
  -> 下一拍新增、替换、积累、揭示或完成什么
  -> 结尾保留哪个记忆或行动
```

图形信息层的动效必须服务语义，不写“酷炫进场”“科技感飞入”这类空动作。常用语义动作：

| 语义动作 | 画面含义 | 适合使用 |
|---|---|---|
| 到达 | 一个对象进入当前判断范围 | 新功能、新人物、新产品、新证据出现 |
| 替换 | 旧状态被新状态取代 | 使用前后、旧流程/新流程、错误/正确 |
| 积累 | 信息逐步增加形成判断 | 清单、排行榜、步骤、证据链 |
| 比较 | 两侧或多项差异被看见 | A/B、竞品替代、方案选择、前后对照 |
| 揭示 | 被遮住的信息变成结论 | 价格、结果、答案、隐藏卖点、原因 |
| 完成 | 任务闭环、状态锁定或 CTA 落定 | 进度条完成、订单完成、报告导出、尾帧定版 |
| 失败回弹 | 错误方式被否定 | 教程纠错、误区、旧方法低效 |
| 状态锁定 | 最终选择被确认 | 排名第一、推荐项、品牌主张、购买动作 |

常用图形系统：

| 图形系统 | 适合表达 | 设计方式 |
|---|---|---|
| 排名板/清单 | 排行、清单、测评、观点顺序 | 已出现项保持可见，新项进入时高亮、换位或补证据 |
| 对比板 | 前后、A/B、旧/新、问题/解决 | 两侧信息量可比较，结论落在差异，不堆满文本 |
| 进度条/时间轴 | 步骤、效率、流程、升级、等待缩短 | 每次推进对应真实步骤或叙事节点，不空转 |
| 卡片/标签 | 卖点、证据、人物身份、对象识别 | 短词、位置稳定，跟随对象但不遮挡证明动作 |
| 图标/状态点 | 抽象概念、功能模块、数据类别 | 图标只做扫读结构，不冒充真实数据 |
| UI 面板 | SaaS、App、工具、任务流、结果状态 | 真实 UI 用素材；概念 UI 只做解释，不伪装成真实产品 |
| 数据卡/动态图表 | 指标、对比、进展、成绩、案例信息 | 数字和来源必须可确认；变化表现为计数、归位、亮起、增长、完成或锁定 |
| 手绘标注/圈注 | UGC、教程、测评、探店、轻喜剧 | 像创作者临场指出重点，跟随动作或证据出现，不随机涂鸦 |
| 标题卡/大字 | 停滑、章节转换、品牌主张 | 字少、时机准、留足安全区，不能逐句复述旁白 |
| 构图大字/地名标题 | 城市、品牌、产品、活动主题、海报风定格 | 文字作为画面结构，占据下三分之一、背景带、透视面或留白区，和主体线条、色彩、倒影、阴影、材质呼应，不做普通字幕 |
| 尺寸标注/三视图 | 人物、穿搭、产品、装备、空间参数 | 主体先稳定居中，标注线从结构边缘长出，数字用等宽字体，正/侧/背或多角度视图补全信息；真实参数必须来自用户材料 |
| 动力学排版 | 歌词、标题、品牌关键词、活动口号 | 文字是主体，按语义运动；用遮罩、反色、裁切、出画、递归图形、单点彩色和留白建立节奏层级 |
| 趣味花字/贴纸/手绘标注 | 情绪反应、拟声、网感、动作强调、轻喜剧节拍 | 贴近动作、声音、表情或状态变化，符合场景和品牌语气，不随机漂浮 |

花字和贴纸可以主动使用，但它们属于表达工具，不是填空装饰。适合在咬下、点击、开盖、加载完成、表情反应、观点反转、产品反馈或节奏重拍上，用短词、拟声、手绘圈注、反应贴片、箭头、印章感标签或轻量图标让画面更有趣。不要为了“热闹”加入无关表情、流行语、密集贴纸、假促销、未确认数据或与品牌调性冲突的花字；任何花字都不能盖住人脸、产品、Logo、真实 UI、手部证明动作或关键画面文字。

## 花字类型选择器

花字不是字幕的同义词。先判断它在本镜头承担什么职责，再决定字形、位置、动效和密度。能用画面动作讲清时少用字；需要降低理解门槛、建立系列感、解释创意动作、强化品牌资产或完成行动收束时再用。

| 花字类型 | 作用 | 写法 | 避免 |
|---|---|---|---|
| 主标题大字 | 停滑、城市/主题/系列识别，文字成为构图核心 | 1-3 个词，粗体或强设计字，放在下三分之一、左上或大留白区；可带倒影、投影、纹理、透视或遮挡 | 像普通字幕贴在画面上，和构图、色彩、主体无关系 |
| 功能说明文字或步骤标签 | 解释当前创意动作或教程步骤 | 使用 `“具体说明文字”`，在动作发生时同步出现；可用黄底黑字、步骤标签或素材清单。它属于画面文字或图形信息层，不是逐句字幕；只有用户明确要求画面内字幕时才使用 `【】` | 动作已经清楚还重复解释，或比动作晚出现 |
| 品牌/产品文字 | 商业露出和资产识别 | 优先让 logo/产品名出现在产品、包装、建筑招牌、屏幕或道具本身；透视、光影、遮挡跟随载体 | 后期硬贴漂浮 logo，遮挡产品证明 |
| 素材清单/工程信息 | 教程、拆解、方法分享 | 字体/音乐/特效/滤镜/工具等用细体小字分栏，通常在工程截图、对比图或讲解段出现 | 在纯展示片里塞教程信息 |
| 趣味反应花字 | 强化网感、情绪、拟声、表情反应 | 粗圆体、手写体、贴纸、箭头、弹动，贴近触发动作 | 密集堆满、遮脸、遮产品、抢走主线 |
| 尾帧行动字 | 回收核心和引导下一步 | 产品/品牌/结果稳定后出现一句主张或一个 CTA，位置清楚、停留可读 | 最后一秒新增复杂卖点、多个 CTA 抢戏 |
| 极少字/无字 | 纯视觉叙事、高端质感、艺术氛围 | 只保留尾帧主题字或品牌字；其余由动作、声音、母题承担 | 为了显得完整强行加解释字 |

花字层级最多三层：

```text
第一层：主标题/核心概念，最大最醒目，1-2 个词或一句极短判断
第二层：功能说明/步骤/卖点，跟动作同步，短句
第三层：素材清单/补充说明/辅助信息，小字号低干扰
```

三层不能同时长期存在。主标题出现时，功能说明先让位；教程清单出现时，主画面应是工程截图、步骤图或已稳定的结果画面；尾帧 CTA 出现时不再新增解释性花字。

花字大小按“信息权重 + 停留时间 + 屏幕比例”决定。1080p 画面可参考：L1 主标题约占画面高度 10%-20%，L2 副标题约 5%-10%，L3 说明字约 3%-5%，L4 合规/辅助小字约 1%-2%。竖屏文字通常比横屏更需要大字号和更明确安全区；小字必须给更长停留。层级差不明显时，观众会把所有文字都当噪音。

## 花字字体、颜色和动效

字体性格要等于视频性格：

| 场景 | 字体倾向 | 颜色倾向 | 动效倾向 |
|---|---|---|---|
| 城市/工业/硬核/建筑 | 粗体无衬线、等宽、窄粗体、工业感字形 | 金黄、橙、白、黑底高对比 | 逐字入场、重击落位、透视贴合、倒影波纹 |
| 潮玩/可爱/年轻 | 粗圆体、手写体、卡通体 | 高饱和橙、黄、绿、粉，配深色描边 | 缩放弹动、轻微回弹、贴纸跟随 |
| 艺术/时尚/高级 | 细体衬线、窄体无衬线、可变字体、克制字重 | 白、黑、银、低饱和品牌色 | 慢显、裁切、轻微位移、和构图线对齐 |
| 功能说明/教程 | 中性无衬线、系统感黑体、等宽数字 | 黄底黑字、白字黑描边、黑字白底 | 渐显渐隐、步骤替换、卡点打勾 |
| UI/SaaS/数据 | 产品设计系统字体、等宽数字、状态标签 | 继承真实 UI 色板和状态色 | 到达、替换、完成、锁定 |

颜色优先保证可读，再考虑风格。复杂实景里常用高对比组合：白字加细阴影、黑字黄底、橙/金黄大字配暗背景、黑底白字或品牌色底板。描边、阴影、底板和半透明蒙层只为提升可读性和风格统一，不为了花哨叠满。

动效必须和画面动作同步：

- 物品碰撞、落地、开盖、点击、咬下时，文字可以短促弹动或印章式落位。
- 场景切换、规则改写、步骤替换时，文字跟着替换，不滞后解释。
- 水面、玻璃、金属、建筑、包装等载体上的字要有对应倒影、反光、透视或遮挡。
- 文字跟随运动物体时，要写清绑定对象、透视变化、遮挡关系和退出方式。
- 不要为每个词做不同动效；一条片只选一套主花字动效语言。

## 花字位置和安全区

花字位置先服务主体和平台安全区，再服务设计。竖屏重要文字默认避开上下约 10% 和右侧互动区；横屏下方字幕和 CTA 默认避开底部遮挡区。重要文字不要贴边。

常用位置：

| 位置 | 适用 | 注意 |
|---|---|---|
| 下方三分之一居中 | 主标题、动作说明、城市/活动名 | 避免遮挡产品和手部证明动作；可与地面、水面、建筑轴线形成构图 |
| 左上角 | 系列标题、平台标签、问题卡 | 小而醒目，不压主体脸和产品 |
| 右下角 | 低干扰辅助信息、角标、章节标记 | 只在确有信息职责时使用，字号和透明度服从主体 |
| 底部居中 | 素材清单、工程信息、功能说明 | 字号小但可读，适合教程、拆解和方法展示 |
| 跟随物体 | 产品名、招牌、包装字、建筑字 | 必须匹配透视、光影、运动模糊和遮挡 |

如果文字是画面的一部分，必须像实体一样处理：贴在墙面就跟墙面透视，落在水面就有波纹倒影，印在包装上就被手和包装边缘遮挡，挂在建筑上就受光照和距离影响。做不到时，降级为后期平面标题或尾帧可编辑文字。

## 外发标题与社媒文案

标题和发布文案是视频方案的一部分，负责在封面、信息流、活动页、作品集或投放素材中承接核心表达。产品广告、品牌 TVC、企业商务、通用创意、教程分享、活动预热、作品展示和短视频切条，都要先判断发布场景，再决定标题如何承担停滑、解释玩法、建立系列感、筛选受众或引导行动。不要只写“高级感、太绝了、创意视频”这类空标签。

标题先确定一个钩子动作：

```text
谁/什么东西
  -> 在哪里/什么场景
  -> 做了什么反常识动作或解决了什么问题
  -> 观众为什么要看
```

常用标题发动机：

| 标题类型 | 结构 | 适用场景 |
|---|---|---|
| 痛点反问 + 解决方案 | 别再问/别再踩/还在为 X 头疼？直接看 Y | 教程、工具、服务、知识、企业解决方案 |
| 情绪惊叹 + 核心机制 | 超酷的 X / 这个 Y 脑洞太上头 | 创意展示、产品玩法、技术作品、发布预热 |
| 拟人化叙事 + 场景设定 | 当 X 进入/占领/滚过 Y，结果 Z | 城市超现实、产品功能隐喻、物品动态片 |
| 概念定义 + 系列标签 | 中文概念｜English Subtitle：本期主题 | 系列作品、品牌栏目、人物图鉴、活动主题 |
| 空间/城市再定义 | X 像一座 Y / 这条街被 Z 改写 | 城市创意、文旅、门店、展会、空间片 |
| 结果前置 + 留白 | 这不是 X，是 Y 完成后的样子 | 教程、前后对比、产品证明、企业案例 |
| 受众筛选 + 边界 | 如果你正好是 X，这条先看完 | UGC、服务顾问、B2B 获客、课程内容 |
| 主张短句 + 视觉证据 | X 不是口号，是 Y 这一刻 | 品牌 TVC、企业商务、公益倡导 |

迁移方式：

- 产品广告：标题写产品造成的结果，不只写产品名。例如 `当清洁喷雾落下，油污像退潮一样让路`。
- 品牌 TVC：标题写品牌主张的可见瞬间。例如 `希望不是光效，是有人把灯一次次点亮`。
- 企业商务：标题写决策者关心的证据事件。例如 `一张订单如何从设计走到交付现场`。
- 通用创意：标题写异常规则和尾态。例如 `这座城市被一个字慢慢折起来`。
- 教程拆解：标题写学习收益和关键证据。例如 `别再问这个转场怎么做，关键其实是这三层`。
- 活动预热：标题写悬念和行动信息。例如 `倒计时开始前，先看主题如何出现`。

Emoji、英文副标题和话题标签都可以用，但必须有信息职责。颜色 emoji 对应画面色彩，物品 emoji 对应主体，表情 emoji 对应语气转折；英文副标题用于系列感、国际感或设计感，不替代核心中文信息；话题标签按“大流量词、精准品类/技术词、场景词、品牌/活动词”分层，品牌、合作、活动和权益没有材料时不编造。

视频内花字和外发标题要分工：

- 外发标题负责停滑和解释为什么值得看。
- 视频内主标题负责建立概念、系列或主题识别。
- 功能说明花字负责让观众看懂当前动作。
- 素材清单和工程信息只用于教程、拆解或方法展示。
- 尾帧文字负责回收核心和引导一个行动。

所有画面文字都必须写完整字体对象。最低描述单元是：`时段 + 触发动作 + 字体气质/字重/字形 + 具体文字 + 位置/安全区 + 色彩/描边/阴影/底板/材质 + 入场路径/缓动 + 停留 + 退场或随切镜消失`。不能只写“出现一个 XX 字”“加 XX 字”“屏幕上显示 XX”。“XX 字体的 XX 字”要具体到可执行：例如“粗圆体白字的‘省’字”“窄体无衬线银白字的‘FAST’”“手写马克笔风的‘别急’”“等宽数字字体的‘03’”。字体描述要服务内容和场景：UGC 更像手绘、手机贴纸、粗圆体或平台原生标签；产品广告更像品牌包装、海报标题、无衬线大字、印章或拟声花字；SaaS/UI 更像真实产品设计系统里的无衬线、等宽数字和状态标签。

构图大字不是字幕。使用时要写清文字出现的时段、位置、字号关系、入场方式、和主体的几何关系，以及是否有倒影、投影、纹理、遮挡或与环境互动。例如地名大字可以在下三分之一随鼓点淡入，底部被水面反射拉长，最后和建筑中轴线一起形成定版；产品名可以贴着包装透视面滑入，边缘被真实包装遮挡。不能只写“加大标题”。

不同场景的迁移方式：

- UGC / talking head：人物继续说话，图形卡片、关键词、反应贴片或 B-roll 覆盖负责证明；跳切发生在短语边界，图形变化发生在观点切换或证据出现时。
- 口播/创始人/员工出镜：可用问题卡、进度条、步骤卡、观点卡、反对意见卡、数据卡和图标状态点承接口播结构；卡片出现、替换、打勾、归位或锁定必须对应一句话的信息变化。
- Presenter-led explainer：讲解者带着图形、演示和比较对象推进；图形要跟随手势、视线或讲解节拍，不一次性铺满。
- Narration-led demo：旁白作为脊椎，产品、手部、屏幕、卡片、进度条和 B-roll 给视觉答案；画面切走时旁白可以继续。
- Ranking/listicle：排名板或对比表负责记住前面判断，每一项用态度、图标和证据镜头推进，新项目进入时改变位置、高亮或补证据。
- Street interview / podcast / two-person：可用说话人颜色、角色标签、观点卡、反应镜头和 J-cut 建立关系；说话人标签不是逐句字幕。
- 产品广告：对比板证明前后变化，进度条展示效率，卡片承接卖点，图标标注功能，尾帧 CTA 完成行动。
- 企业商务：时间轴、地图、流程线、数据卡、组织结构和客户案例卡必须对应真实材料；动效表现节点亮起、流程闭环、区域扩展或项目完成。
- 技术流三视图：人物或产品属于物理场景，尺寸线、数字、箭头、单位、网格、图例属于编辑合成层；先拍/生成干净稳定的主体，再给图形层留足左右和上下空间。
- 动力学排版：没有物理主体时，字体、图形、底色和音乐就是全部画面层级；必须提前锁定字体气质、字号权重、关键词层级、反相节拍、唯一强调色和黑场/定版收束。

图形层必须和物理场景、摄影构图分开设计：人、产品、手部动作和真实屏幕属于物理场景；镜头怎么拍、主体在哪、留白多少属于摄影构图；排名板、卡片、图标、进度条和广告大字属于编辑合成。需要图形时，先在摄影构图中给它留空间，不要求人物去触碰后期才存在的图形。

图形和 UI 动效自检：

- 本镜头是不是只有一个主动效，其他变化都在辅助它？
- 卡片、数据行、图标或 UI 模块落定后，有没有真实槽位或清楚状态？
- 批量元素是否非线性、错峰或带物理隐喻，而不是匀速排队飞入？
- 关键数字、品牌字标、完整 UI 状态或 CTA 是否有可感知停留？
- 光效、粒子、扫光是否只给主角或关键节点，且没有盖住文字和证据？
- 信息密集或文字多的画面是否足够正视、清楚、可读？

## 视听策略迁移适配

运镜、布光、构图、色彩、转场、声音和文案是所有类型视频都能用的通用方法，但每次都要根据内容重写。不要把“低角度冲击、蓝橙电影感、匹配转场、ASMR 拟音”当成固定套餐；先判断它们在当前片里负责什么，再转成具体镜头。

内部适配顺序：

```text
P0 主目标
  -> 当前主体和证明锚点
  -> 本维度承担的职责
  -> 选择一个主策略
  -> 改写为当前对象、动作、空间和声音
  -> 写进分镜秒段
  -> 检查是否抢戏、失真或不可生成
```

各维度适配要求：

| 维度 | 先问职责 | 适配方式 |
|---|---|---|
| 运镜 | 跟随、揭示、证明、压迫、沉浸还是收束？ | 产品用微距/环绕/固定机位证明细节；UGC 用手持微动和近景保真实；企业用稳定移动和大景别建信任；TVC 用克制运动和仪式化停留 |
| 布光 | 让主体分离、建立价格感、制造真实感还是突出证据？ | 食品要干净高光和食欲质感；护肤要柔光和肤感；3C 要轮廓光和屏幕动机；企业要真实空间光和可信环境 |
| 构图 | 观众第一眼该看哪里？ | 产品/Logo/手部证明不能被遮；人物关系用前后景；企业事实用空间层级；高端片可留白但关键信息必须稳定 |
| 色彩 | 情绪、品类、品牌和节奏谁优先？ | 先保护真实产品色和肤色，再用品牌色或冷暖段落承接；不要每镜换滤镜 |
| 转场 | 两镜之间靠什么因果相连？ | 动作、形状、颜色、材质、声音桥或空间入口只选一个主逻辑；强转场要回到 `visual-motion-playbook.md` |
| 声音 | 哪个动作需要被听见？ | 拟音绑定开盖、咬下、点击、吸入、拖拽、脚步、门、键盘等触发点；音乐服务节奏曲线而不是盖住信息 |
| 文案 | 画面哪里说不完、需要文字或图形补足？ | 在旁白、口播、标题卡、图形标签、排名板、对比板、进度条、UI 面板、尾帧 slogan 或 CTA 中选择合适形态；不要逐句复述旁白 |

如果某个维度无法说清“为什么用于当前视频”，就删掉或降级。专业感来自各维度共同服务同一主线，不来自技法数量。

## 共享视觉语言

多镜头视频在分镜前先锁共享视觉语言：

- 色彩：3-5 个主色或色彩关系，含品牌色、背景色、强调色和状态色。
- 光线：主光方向、色温、软硬、来源和场景动机。
- 镜头质感：手持、定机、推轨、微距、产品巡航、2.5D 页面相机、纪实手机感或电影感稳定机。
- 视觉概念与版式系统：先锁可复述视觉事件、被改变的世界规则、主体与空间关系、主导构图骨架、色彩面积、材质、留白、裁切和图像层级；文字只在确有职责时补充字体、字重和空间关系，不默认出现。按 `references/asset-generation.md` 把设计落成真实概念图并确认，再进入图生视频。
- 材质与空间：产品材质、UI 层级、包装反光、真实环境纹理、前中后景和尺度参照。
- 声音世界：人声、BGM、环境声、拟音、声音桥和静默使用边界。
- 禁止项：假 Logo、乱码文字、无关主体、风格漂移、复制参考概念、过度装饰、产品变形、人物撞脸。

如果参考素材或用户要求的是强审美风格，先把风格升格为共享视觉语言，而不是只在单个镜头写“某某风格”。不得另建强风格系统卡；只按下列维度提取会改变画面的结论，并全部写回 `creative-core.md` 唯一导演总控卡的“视觉风格”字段：

```text
构图规则：
视觉概念/版式规则：
运镜规则：
色板：
表演/动作尺度：
美术/道具陈列：
声音节奏：
反差/转场：
回收锚点：
剥离项：
```

强风格系统必须可观察、可复用、可剥离。例如“作者电影式复古对称”可以转写为：绝对中心对称、平面化正立面、固定机位、横向轨道移动、垂直俯拍、少量 90 度甩镜、低饱和粉蜡笔色板、机械克制表演、道具网格化陈列、复古轻快音乐和精确拟音。不要只写导演名、片名或“某某风格”；也不要复制参考里的专属角色、台词、标志性桥段、完整剧情或可识别受保护表达。

强风格不是滤镜，必须在视觉概念、构图、空间、材质、运动、色彩、声音和表演上同时约束。关键帧序列必须“同系统、不同创意状态”：共享主体、色板、材质和品牌锚点保持一致，相邻帧至少在景别、构图、尺度、空间或明暗中的两项发生变化；产品英雄帧、人物动作帧、世界规则帧、结构/材质微距帧和按需使用的排版帧交替出现，不能整组都是居中产品、半身人物或同一背景上的换姿势。类型文件可以决定强风格服务什么：品牌 TVC 可让“风格即内容”，产品广告可让风格证明品类质感，UGC 只能轻量借用固定构图、固定栏目动作或色彩识别，不能牺牲真实感和可信证明。

每个镜头都必须继承共享视觉语言，同时推进一个新的动作、信息、关系、状态或情绪阶段。统一不等于重复构图。

## 构图策略库

视觉发动机决定“发生什么”，构图策略决定“观众怎样看见”。本库用于分镜、概念图和视频画面；视觉发动机读取 `references/visual-motion-playbook.md`，生成设计卡与验收读取 `references/asset-generation.md`。每格除一个主视觉发动机外，还必须选择一个主构图；相邻格不得连续使用完全相同的骨架。

| 构图策略 | 组织方式 | 适用效果 |
|---|---|---|
| 中心英雄 + 背景系统 | 产品或人物稳定占据中心，文字、图形、纹样或光影在后方形成完整舞台 | 产品定版、发布、品牌识别 |
| 极端前景冲击 | 一个物体贴近镜头占据大面积，主体和环境在后景建立动作因果 | 体育、食物、第一视角、速度 |
| 中心放射 | 主体位于圆心，文字、零件、光线、人物或轨迹向外放射 | 能量、声场、技术、聚焦 |
| 环形轨道 | 元素沿同心圆或椭圆轨道包围中心主体，前后大小制造纵深 | 循环、续航、选择、沉浸 |
| 水平双世界 | 通过水线、镜面、桌面、地平线或色块把画面分成上下两种状态 | 倒影、入水、前后对比、时空交接 |
| 垂直双世界 | 上下场景由手、产品、光柱、瀑布或动作穿过边界连接 | 来源到结果、现实到想象、跨时空 |
| 左右对答 | 两个人物、状态、产品或色场相向/背向组织，中心留给冲突或连接物 | 对话、选择、对比 |
| 对角线阵列 | 产品、人物或图形沿斜线和透视方向重复排列，形成速度与方向 | 包装阵列、运动、节拍 |
| 不对称大留白 | 主体压在一侧或角落，另一侧留给方向、标题、动作路径或悬念 | 高端、编辑感、人物情绪 |
| 满版裁切 | 产品、脸、材质或文字超出画幅，只保留最有辨识度的局部 | 感官、冲击、材质、时尚 |
| 框架群/屏幕群 | 多个不等尺寸画框、屏幕或窗口围绕主体，形成信息层和时间层 | 回忆、平台、内容、复杂叙事 |
| 编辑网格 | 图像、产品、标题、留白和信息块按规则分栏，视觉重心跨格移动 | 品牌网页、杂志、服务、系列内容 |
| 一点透视走廊 | 道路、文字、货架、光带或建筑共同指向单一消失点 | 穿越、速度、流程、空间入口 |
| 顶视几何 | 俯拍利用球场、桌面、餐盘、道路或阵列几何组织人物与动作 | 运动、食品、流程、秩序 |
| 剪影与色场 | 人物或产品以暗色轮廓压在纯色/高对比背景上，文字或图形承担第二层信息 | 态度、音乐、宣言、戏剧 |
| 前中后景穿插 | 前景遮挡制造临场，中景主体完成动作，后景视觉事件提供结果或尺度 | 电影感、空间、产品使用、沉浸 |

构图必须在图片中真实成立：主体占比、裁切位置、视线方向、消失点、前后遮挡、留白用途和文字安全区都要可见。不得只写“采用高级构图”。允许非常规裁切、超大字号、越界主体、极端近景、鱼眼形变、负空间、平面与真实影像混合，但必须保住产品结构、人物身份、核心文字和叙事可读性。

## 色彩设计策略

色彩必须在概念图阶段真实呈现，不把“高级配色”“电影色调”“品牌感”留给视频模型猜。先保护用户产品、Logo、包装、人物肤色和真实场景的固有色，再设计背景色、辅助色、强调色、明暗关系和跨镜色彩变化。

每条视觉序列先锁一套共享色彩合同；下列面积比例为取值参考，实际可见色块归一到完整画面，主体固有色不得被强行调色：

```text
固有色：[用户素材中不可偏移的产品色/Logo 色/包装色/肤色]
主背景色：[占画面约 50%-70%]
主体支持色：[占画面约 20%-35%，用于人物、道具或环境]
强调色：[占画面约 5%-15%，只落在视觉焦点、文字关键词或触发物]
中性色：[黑/白/灰/金属/纸色，用于留白、可读性和材质平衡]
明暗结构：[高调/低调/明暗切割/逆光轮廓/局部聚光]
色彩剧情：[镜头如何建立、增强、反转或回收颜色]
```

常用配色不是固定模板，必须按产品真相和叙事职责迁移：

| 配色结构 | 画面方法 | 适用气质 |
|---|---|---|
| 品牌单色 + 黑白 | 大面积品牌色统一世界，黑白负责层级和文字可读性 | 发布、科技、强识别 |
| 单色深浅阶 | 同一色相通过明度、饱和度和透明度建立前中后景 | 极简、高端、产品英雄 |
| 类比色 | 相邻色相平滑过渡，强调材质、氛围和连续运动 | 治愈、自然、美妆、生活方式 |
| 互补撞色 | 主体与背景使用对立色，控制一主一辅，不平均分配 | 年轻、运动、食品、强停滑 |
| 分裂互补 | 一个主色搭配两个邻近对比色，既醒目又比纯互补更稳定 | 潮流、娱乐、活力品牌 |
| 黑白 + 唯一强调色 | 大部分画面克制为黑白灰，只让产品、关键词或触发物带色 | 高级、技术、悬念、排版 |
| 冷暖叙事 | 问题段偏冷、触发点冷暖碰撞、结果段转暖；或按主题反向使用 | 转变、情绪、功能证明 |
| 糖果高饱和 | 多种明亮色由统一明度和干净背景约束，避免脏乱 | 零食、饮料、儿童、快乐 |
| 低饱和 + 材质色 | 灰、雾蓝、灰绿、裸粉等低饱和背景承托真实木、布、金属、皮肤 | 生活方式、家居、品质感 |
| 暗底珠宝色 | 深黑、炭灰或深色空间配少量宝石色、金属高光和轮廓光 | 奢华、汽车、香氛、硬件 |
| 自然来源色 | 从原料、土地、植物、水、天空和食物本身提取色板 | 食品、农业、环保、户外 |
| 数字界面色 | 继承真实 UI 的品牌色、状态色和中性色，不另套霓虹科技皮肤 | 软件、应用、数据、企业服务 |

不能每镜随机换色。颜色变化必须承担剧情：建立世界、触发异常、放大高潮或回收到品牌。跨多张四宫格时，下一张延续上一张第 4 格的主色、光源色或强调色，再逐步变奏；产品固有色和 Logo 色始终保持准确。

## 文字排版创意库

文字很重要，但不是默认叠加层。只有文字的形态、位置、尺度、路径、材质或空间关系本身参与创意时，才把它作为主视觉或辅助视觉。每个画面最多选择一个高存在感文字机制，避免多种字效互相争抢。本库负责可见造型；前文花字规则负责表达职责、可读性与安全区，运动生命周期读取 `references/visual-motion-playbook.md`，逐字 Prompt 描述与保真执行读取 `references/asset-generation.md`。

| 文字机制 | 画面设计方法 | 适合表达 |
|---|---|---|
| 环形字/螺旋字 | 文字围绕产品、人物或孔洞形成同心圆、轨道、漩涡或隧道，主体位于中心或穿过圆环 | 循环、续航、沉浸、声音、聚焦 |
| 文字透视隧道 | 字句沿消失点逐级缩小、放大或弯曲，形成镜头可穿越的深度通道 | 梦境、速度、进入意识、空间转场 |
| 文字从主体发射 | 字句从人物嘴部、产品开口、扬声器、屏幕或动作接触点向外扩张 | 声音、表达、能量、功能触发 |
| 透视锥形字 | 文字从人物嘴部、手势或产品触发点向镜头方向急剧放大，字面随透视压缩成喇叭或锥体 | 宣言、喊话、冲击、控制感 |
| 径向旋转字 | 关键词围绕中心主体形成圆盘、放射轮或旋转叶片，近端放大并带方向性模糊 | 运动、眩晕、循环、节拍 |
| 对答分屏字 | 两组文字分别占据上下或左右色块，配合相向/背向人物形成提问、回应、冲突或选择 | 观点、剧情对白、反差、互动 |
| 文字速度场 | 重复字沿镜头前后形成拖影、缩放模糊、压缩或拉伸，中心主体保持相对清晰 | 速度、失控、运动、音乐 |
| 文字地毯/建筑字 | 巨字产生纵深厚度并延伸为地面、墙体、台阶、柱体或舞台，主体真实站在其上 | 宣言、人物态度、发布、品牌空间 |
| 文字轮廓成像 | 文字沿人物剪影、产品轮廓、瓶身曲线或地标边缘排布，共同完成主体识别 | 人物观点、产品形态、城市品牌 |
| 巨型裁切字 | 单词或汉字放大到越出画幅，只保留局部笔画，人物或产品在字内、字前或负形中出现 | 强主张、尺度、发布感、潮流 |
| 拼贴字 | 字母、汉字、照片碎片、材质块和主体局部共同组成网格或撕贴画面 | 年轻、音乐、时尚、信息爆发 |
| 爆炸结构字 | 文字沿产品结构、零件、液滴或碎片向外放射，形成技术爆炸图或能量中心 | 技术、性能、速度、配方 |
| 路径字 | 文字沿道路、跑道、水流、衣摆、光带、声波或运动轨迹弯曲排列 | 运动、旅行、流程、方向 |
| 透视地面字 | 巨字贴合地面、墙面、建筑、球场或桌面透视，人物和产品真实站在或越过文字 | 空间、行动、场景沉浸 |
| 遮挡穿插字 | 笔画在主体前后交替穿插，被人物、产品、液体或道具部分遮挡 | 层次、真实合成、时尚 |
| 文字容器 | 字形内部装入人物、产品、城市、食材、自然或另一层世界 | 主题、地点、品牌世界 |
| 文字变物体 | 笔画成为楼梯、门、桥、跑道、管道、货架、波浪或可触碰装置 | 功能可视化、互动、叙事 |
| 材质文字 | 文字由冰、奶油、液体、烟雾、金属、玻璃、布料、植物、糖果或产品零件构成 | 感官、工艺、品类属性 |
| 动作字/拟声字 | 文字形态对应声音和动作，压缩、拉伸、碎裂、弹跳、震动或被风吹散 | 节奏、冲击、幽默、声音 |
| 重复字阵 | 同一词按大小、疏密、明暗或方向重复，形成背景、速度线、空间纵深或节拍 | 强调、递进、速度、洗脑记忆 |
| 描边/实心接力 | 同一大字在背景中纵向或横向重复，轮廓字与实心字交替，主体遮住部分笔画但保留整体识别 | 产品定版、节奏递进、年轻品牌 |
| 主体压字/字托主体 | 巨字位于产品或人物背后形成背景墙，或在底部成为稳定承托；通过遮挡明确前后关系 | 产品主角、海报感、发布感 |
| 信息框/对话框 | 搜索框、问答框、聊天气泡、标签和按钮成为漫画分镜或场景中的叙事物件 | 服务、平台、功能、社交传播 |
| 编辑网格/漫画框 | 文字、人物、产品和场景被组织进不等宽分栏、连续漫画框或杂志网格，跨框动作形成阅读顺序 | 多场景、服务流程、故事递进 |
| 斜切/旋转字 | 文字沿对角线、垂直轴、倾斜平面或旋转透视进入画面，与主体运动方向一致 | 速度、运动、潮流、转场 |
| 正负形字 | 主体轮廓、留白和字形互相借形，一眼既能读到字也能识别产品或物体 | 极简、双关、品牌识别 |
| 镜像/倒影字 | 文字只在水面、镜面、金属、玻璃或阴影中完整出现 | 反转、高级感、双重意义 |
| 字体尺度接力 | 同一关键词从小标签升级为环境巨字、空间装置，最后回收到品牌定版 | 递进、高潮、品牌回收 |
| 数据/参数造型 | 经确认的数据或参数组成轮廓、结构、波形、计量刻度或技术空间 | 性能、企业、科技、可信证明 |

字体选择必须具体到可观察形态，不写“高级字体”“艺术字体”：

| 字体形态 | 可观察特征 | 适用方向 |
|---|---|---|
| 超粗几何无衬线 | 笔画粗、字面宽、圆角或硬直切角、黑白块面强 | 产品名、发布主标题、巨型裁切字 |
| 窄体无衬线 | 字面窄长、紧凑排列、纵向张力 | 运动、潮流、参数层级 |
| 宽体无衬线 | 字面横向展开、重心稳定、占据大面积 | 科技、速度、横向空间 |
| 高对比衬线 | 粗细笔画反差大、衬线清楚、细部锐利 | 时尚、美妆、高端编辑 |
| 人文无衬线 | 笔画有书写感、开口舒展、比例温和 | 生活方式、服务、亲和表达 |
| 粗圆体 | 圆润端点、饱满字腔、亲和且有弹性 | 食品、儿童、娱乐、趣味花字 |
| 等宽机械体 | 每字等宽、结构规整、数字辨识稳定 | 参数、界面、工程、数据 |
| 模板喷字/工业字 | 断笔、镂空、硬边、印刷或喷涂痕迹 | 户外、机能、工业、运动 |
| 手写马克笔 | 笔压明显、边缘不规则、速度感强 | 口播、批注、情绪、年轻表达 |
| 粗笔刷字 | 墨迹、飞白、方向性笔触和夸张收尾 | 力量、国风、节庆、动作高潮 |
| 像素/点阵字 | 方格或点阵结构、低分辨率边缘 | 游戏、数字、复古科技 |
| 膨胀立体字 | 软体充气、凝胶、糖果、金属或塑料体积 | 潮玩、食品、产品材质联动 |
| 轮廓线框字 | 只有描边或多重轮廓，可与实心字交替 | 背景字阵、空间层级、产品托底 |
| 可变形字 | 宽度、粗细、倾斜或曲率随动作连续改变 | 动力学排版、音乐、速度、转场 |

同一画面通常只设一个主字体家族，通过字重、大小、描边和实心变化建立层级；最多再配一个用于参数或小字的辅助字体。不要同时混用三种以上高存在感字体，也不要为“丰富”随机加入英文、伪品牌字或无意义小字。

大多数商业画面里的文字应与产品、人物或场景共同出现。优先选择一种关系：

- 包围：文字环绕、框住、托住或形成产品的视觉舞台。
- 遮挡：文字与产品形成明确前后层级，局部被遮但仍可识别。
- 贴合：文字印在包装、屏幕、墙面、地面、水面、玻璃或产品曲面上，服从真实透视和光影。
- 延伸：文字笔画延伸成产品轮廓、液体、道路、声波、零件、植物或功能结构。
- 触发：产品开盖、点击、碰撞、喷洒、移动或人物动作使文字出现、变形、碎裂、扩散或归位。
- 证明：文字、数字或参数与爆炸结构、刻度、波形、对比、路径或可见结果共同证明功能。

纯文字镜头只用于标题开场、章节转场、情绪重拍、核心宣言或品牌收束。它必须继承前后镜头的色彩、形状、材质、运动方向或声音锚点，并为下一镜留下转场接口；不能因为缺少画面创意而退回普通字卡。若去掉文字后画面仍完整，文字只是辅助；若文字承担主视觉，则必须证明它与当前主题或产品不可替换。

所有复杂文字布局都必须在概念图里真实画出来，直接呈现最终构图、字体尺度、字重对比、行距字距、裁切、旋转、路径、透视、遮挡、与产品接触关系、留白、安全区和视觉层级；不能只写“后续加环形字”“做杂志排版”让视频模型猜。

合格示例：`产品后方纵向重复四层超粗几何无衬线大字“鲜感”，上两层仅保留半透明白色细描边，下两层为实心白字；字宽约占画面 85%，上下越出画幅，产品罐体遮住中间约三分之一笔画，文字仍可辨认；背景字与罐体共用冷青色环境光，不覆盖包装上的真实 Logo。`

不合格示例：`背景加入有设计感的大字。`

品牌名、型号、参数、日期、价格、行动文案、包装字和界面字以准确可读为先，只使用有来源或已确认原文；保真生成和合成规则统一读取 `references/asset-generation.md`。

每个画面按 `一个主视觉发动机 + 一个构图策略 + 一套配色结构 + 可选的一个文字机制 + 一个动态把手` 组合。格位中的局部机制服从全片同一主规则；允许变奏，但必须通过主体、动作、形状、颜色、材质或声音中的至少一个锚点承接，不能每格重启一套创意。

## 运镜选择

运镜先看职责，不按“高级感”堆动作。

| 运镜 | 心理效果 | 适用场景 | 使用边界 |
|---|---|---|---|
| 推近 | 聚焦、强调、进入情绪或细节 | 产品揭示、人物情绪、关键信息 | 慢推偏情绪，快推偏冲击；不要每镜都推 |
| 拉远 | 揭示环境、释然、宏大、孤独 | 结尾升华、空间关系 | 拉出后必须出现新信息 |
| 摇/俯仰 | 扫视、跟随注意力、从局部到整体 | 环境介绍、从 A 揭示 B | 结尾要有落幅，不做无目的扫场 |
| 横移/跟拍 | 陪伴、流动、沉浸、真实 | 人物行走、探店、通勤、产品线条 | 主体要稳定，不让观众追丢 |
| 固定机位 | 清楚、可信、让动作自己发生 | UGC 口播、产品操作、食品、教程 | 靠内部运动和切近景制造节奏 |
| 手持微动 | 真实、临场、生活感 | UGC、探店、测评、纪实 | 轻微即可，过度晃动会显得低质 |
| 环绕 | 仪式感、360 展示、人物/产品高光 | 产品大片、穿搭、发布会 | 必须展示不同侧面或光影变化 |
| 微距 | 质感、专业、细节放大 | 材质、食物纹理、肌肤、接口、logo | 必须写清具体细节 |
| 慢动作 | 强调瞬间、仪式感、情绪放大 | 水滴、拉丝、开盖、决胜瞬间 | 只给关键动作 |

运镜动机只有三类：跟随主体动作、引导观众注意新信息、表达情绪变化。没有动机的运镜是噪音。

进阶运镜可按需使用：甩镜用于快节奏和喜剧点缀；稳定器长跟用于空间沉浸；航拍/升降用于格局打开；一镜到底用于连续变化；速度变化用于产品落地、运动瞬间、开盖、旋转和时间冻结。任何进阶运镜都必须有明确动作链和节奏节点。

艺术空间、展览、文旅和周年庆片可以使用“快跟拍 + 慢固定”的波浪式调度：跟拍用于导览角色穿过走廊、露台、中庭或人群，固定镜头用于让展品、投影、画中人物或空间内部动作自己发生。推镜负责进入作品或细节，横移负责展示宽阔空间和群像关系，升降/仰拍负责打开建筑尺度；每种运镜都必须对应一次发现、活化、揭示或庆典升级。

## 布光和画面质感

| 光线策略 | 效果 | 适用 |
|---|---|---|
| 自然窗光 | 真实、柔和、亲近 | UGC、居家、母婴、生活方式 |
| 高调柔光 | 干净、清新、安全、年轻 | 美妆、医疗感、食品、电商产品 |
| 低调局部光 | 高端、悬疑、力量、质感 | 奢华、科技、汽车、硬件 |
| 侧逆光/轮廓光 | 主体从背景中分离，突出形体 | 人物、车、瓶身、金属、宠物黑毛 |
| 硬光切割 | 戏剧、科技、建筑感、紧张 | 工业、城市、运动、反差叙事 |
| practical 现场光 | 真实空间动机 | 台灯、烛光、路灯、车灯、屏幕光 |

自检：主体和背景是否分离、阴影是否有细节、产品是否有干净高光、人物眼睛是否有眼神光、色温是否有明确动机。

基础光位：主光决定主体形态，辅光控制阴影深度，轮廓光分离主体，背景光建立空间层次，现场光解释光源。人像可用环形光/45 度侧光、蝴蝶光、伦勃朗光、分割光或高调均匀光；场景按家庭、办公、户外、产品、食品、夜景分别选择光线动机。

## 构图和景别

| 景别/构图 | 作用 | 常用场景 |
|---|---|---|
| 大远景/远景 | 建立环境、尺度、孤独或自由 | 旅行、汽车、企业空间、品牌情绪 |
| 全景 | 展示完整动作、穿搭、人物和产品关系 | 服饰、运动、人物出场、门店 |
| 中景/中近景 | 自然沟通、可信表达 | UGC 口播、采访、人物互动 |
| 近景/特写 | 情绪、产品细节、手部证明 | 美妆、食品、工具、开箱 |
| 三分法 | 自然、有呼吸感 | 日常、人物、生活方式 |
| 对称构图 | 稳定、庄重、仪式感 | 产品正面、发布会、高端品牌 |
| 引导线 | 聚焦、纵深、方向感 | 道路、货架、办公室、车内 |
| 框架构图 | 聚焦、层次、故事感 | 门窗、屏幕、车窗、货架、手部 |
| 前景遮挡 | 临场、层次、真实 | 探店、家居、人物跟拍、转场 |
| 留白/负空间 | 高级、安静、想象空间 | 高端产品、情绪片、静态尾帧 |

空镜不能凑时间。每个空镜都必须承担情绪、环境、转场、品牌资产或节奏呼吸。产品必须在视觉重心，特写要给材质和结构留空间；多人构图用前后景拉层次，不排成一条线；对话和访谈可用过肩镜头建立空间关系。

超宽屏或 2.35:1 宽银幕适合横向空间、群像游行、建筑中庭、露台庆典和艺术空间巡游。使用超宽屏时，构图要主动利用左右运动、前中后景和引导线，不只是加黑边；横移、跟拍和群像站位要让宽幅带来信息增量。画框、窗框、门框、展柜和邀请函边框可以形成“画中画/入口”体系，但每个框架都要承担聚焦、穿越、揭示或收束职责。

黑白到彩色、普通画幅到宽银幕、记录感到海报感，适合表达“原始素材/现实记录 -> 设计完成态/电影化结果”的状态升级。使用时必须绑定具体触发点，例如音乐重拍、手指点下、图层打开、主体抬头或光源出现；PE 里写清黑白保留多久、彩色从哪里蔓延、黑边何时压入、升级后新增了什么信息。不要把画幅黑边当作无理由的电影感装饰。

## 色彩和调性

色彩先服务情绪，再服务品类，最后服务品牌识别。产品色和肤色是底线：任何调色都不能让真实产品颜色偏离到不可识别，也不能让肤色异常。

| 颜色 | 正向联想 | 常用场景 |
|---|---|---|
| 红 | 热情、食欲、力量、节日、紧急 | 食品、促销、运动、春节 |
| 橙 | 温暖、活力、亲和 | 快餐、家居、年轻品牌 |
| 黄 | 阳光、快乐、注意力 | 儿童、快乐向、提醒信息 |
| 绿 | 自然、健康、安全、成长 | 食品健康、环保、护肤修护 |
| 蓝 | 信任、专业、冷静、科技 | 科技、金融、医疗、企业服务 |
| 紫 | 奢华、神秘、创意 | 美妆、香氛、艺术 |
| 粉 | 温柔、浪漫、甜感 | 美妆、甜品、女性向 |
| 黑 | 高端、力量、经典 | 奢侈品、汽车、高端科技 |
| 白 | 纯净、简约、安全 | 医疗、科技、电商 |
| 金 | 尊贵、品质、胜利 | 高端、礼盒、节日 |

配色方法包括单色系、类比色、互补色、冷暖对比、高饱和和低饱和。避免把所有视频都调成同一种流行色；如果场景切换多，至少保留品牌色、产品色、光源或材质作为连续锚点。用户给出作者电影、年代感或特定胶片调性时，必须把色彩写成具体组合和质感，例如黄绿高饱和、暖黄与橙红火光、复古服装色块、35mm 胶片颗粒、轻微褪色或干净糖果色；不要只写“电影感滤镜”。文化艺术空间常用冷蓝/深灰环境承载神秘和空间深度，用暖金、纸艺粉彩、串灯、烟花或魔法粒子做情绪焦点；涉及名画、馆藏、产品或真实艺术品时，先保护原作/原物主色，再让环境光和特效色服务统一。音乐混搭可以让 A/B 两个参考先各有色系，再在融合段形成第三套混合色；动力学排版可以长期克制在黑白灰里，把唯一彩色留给最高权重关键词，形成延迟满足。

## 转场和剪辑

动作切、匹配剪辑、视线匹配、方向匹配和声音桥是优先转场，因为它们能把前后镜头组织成同一条观看路径。直切/硬切不是无条件默认项：它只有在镜头职责已经转换且前后共享动作、主体位置、构图、方向、声音或语义锚点时才成立。遮挡、甩镜、叠化、淡入淡出、划像和光圈只能少量使用。

| 转场 | 适合 | 注意 |
|---|---|---|
| 直切/硬切 | 冲击对比、结果揭示、观点切换、节拍重击、章节断点 | 写清为何此刻切以及共享锚点；不能只写“直接切到” |
| 匹配剪辑 | 形状、颜色、动作相似的镜头 | 两个镜头的锚点要清楚 |
| 动作切 | 抬手、开门、倒入、转身、走动 | 在动作中途切最顺 |
| 视线匹配 | 人物看向产品、结果或异常 | 适合人物驱动和轻剧情 |
| 方向匹配 | 运动方向连续 | 适合车、人、产品飞行、横移 |
| 遮挡转场 | 空间转换、时间跳跃、连续换装 | 遮满瞬间切 |
| 叠化/淡入淡出 | 回忆、时间流逝、段落收束 | 用多了会拖慢 |
| 声音桥 | 情绪连接、跨空间切换 | 比花哨画面转场更稳 |
| 静默转场 | 强调、反转、产品揭示 | 静默后必须有有力进入点 |

转场的目标是让观众感到流畅，而不是让观众注意“转场很炫”。强视觉转场的叙事规则读取 `visual-motion-playbook.md`。

艺术活化、穿越和空间巡游优先使用主题化匹配剪辑：画中椅子到真实椅子、画框到窗框、邀请函边框到门框、展品轮廓到投影轮廓、手伸出画面到现实手接住物件。匹配点可以是形状、颜色、方向、动作或声音，但必须服务“静态变动态、平面进入现实、局部打开整体”的主题，不做无意义炫技。

音乐混搭和工具实验可以用波形匹配、色彩溶解、故障撕裂、RGB 分离、缩放冲击和黑场评价收束表现“预期违背”。技术流三视图优先用旋转遮挡、标注线生长、数字弹出和定格完成转场；动力学排版优先用黑白反相、扫线、遮罩裁切、缩放收束和元素延续，转场点必须落在鼓点、歌词音节或音乐换气处。

空间折叠、海报化和效果教程可以用“展示 -> 升级 -> 分层 -> 定版 -> 揭秘”的剪辑节奏：开场先给完成态或最强前后对比，随后在重拍上让背景、倒影、光源、前景剪影和构图大字逐层入场，定版停留后再切到图层、时间线或素材清单。声音设计要对应层级变化，例如色彩打开给低频进入，倒影出现给水波或反射声，文字落位给短促冲击，教程揭秘段降低音乐密度让信息可读。

剪辑点优先落在意义变化处：观点切换、证据出现、状态变化、人物反应、情绪落点、声音重拍或 CTA 收束。画面切走不等于声音切走；A-roll 的人声、旁白或环境声可以继续承载语义，下一句声音也可以先进入，再由画面切过去承接。

口播社交视频适合在短语边界做自然跳切，让表达更紧凑。跳切不是错误，而是创作者剪辑感的一部分；但每次切换都要保持人物身份、场景、声音和表达态度连续。反应镜头、B-roll 覆盖、J-cut、声音桥和短暂静默都属于信息交接方式，必须说明它们交接了什么：观点、证据、情绪、悬念还是行动。

## B-roll 和辅助画面

B-roll 是辅助画面，不是随手配图。它可以覆盖 A-roll 的画面，但 A-roll 的人声、旁白或语义仍可继续。每个 B-roll 镜头必须承担至少一个职责：证明、解释、情绪、幽默、生活感、节奏呼吸或转场交接。

B-roll 中出现的每个醒目主体都要能追溯到当前话题、人物、场景、品牌或视觉母题。若观众会误以为视频换了商品、人物或主题，即使画面好看也必须删除。为了填满横移、推拉或空镜而扫过的无关道具不算生活感。

不要按口播里的每个名词机械配画面。先判断这句话需要观众相信什么、理解什么或感受到什么，再选择辅助画面：

| 职责 | 画面方式 | 常见场景 |
|---|---|---|
| 证明 | 手部操作、真实 UI、产品反馈、前后状态、材质特写 | 产品广告、测评、SaaS、教程 |
| 解释 | 屏幕流程、步骤拆解、结构剖面、图形演示 | 功能讲解、企业服务、课程引流 |
| 情绪 | 生活场景、人物反应、环境空镜、节奏留白 | UGC、品牌片、生活方式 |
| 幽默 | 反差插入、夸张反应、视觉比喻 | 口播、榜单、评论回应 |
| 生活感 | 通勤、使用中、桌面、门店、家庭、工作现场 | 种草、服务、本地生活 |
| 转场 | 动作接动作、声音桥、同形同色、遮挡切换 | 多段口播、长视频、产品流程 |

B-roll 可以比对应台词略早或略晚出现。视觉终点不必和一句话的最后一个字完全对齐；如果最后一个辅助画面还在贡献证据或情绪，可以让下一句声音先进入，再切回人物、产品或图形系统。长视频中连续 B-roll 必须共享边界，避免短暂露出无意义的 A-roll 或空白画面。

## 表演和人物动作

人物动作要有理由，不按每句话分配手势。先定人物对内容的态度：怀疑、兴奋、克制、调侃、认真权衡、亲切分享、专业判断或真诚提醒；再选择少量关键反应：眉毛、停顿、点头、手掌、侧看、身体前倾、语气落点。

表演要服务观点落地。数字、步骤和卖点可以交给画面文字、图形标签或 B-roll；人物手势负责态度、强调和可信感。一个关键反应通常比连续小动作更有力：价格处眉毛上扬，反对意见处短暂停顿，结论处轻点头，调侃处侧看或耸肩。避免每个词都有动作，也避免全程僵硬看镜头。

## 声音结构

商业视频声音通常由四层组成：音乐是情绪基底，环境声建立空间，拟音/产品音效证明动作，人声/旁白传递信息。

- 人声清晰度优先级最高；有旁白时，音乐和音效都要避让人声。
- 音乐选择先于剪辑细化：节拍、停顿、上升音和尾音决定剪辑节点，但不要每个节拍都切。
- 产品出现时可以做声音特写，例如开盖、倒入、快门、磁吸、拉链、落地、咬开、启动。
- 静默也是声音设计。高潮前 0.5-1 秒降音或静默，可以让产品揭示、主张或 logo 更有力量。
- 动效声音要和动作链成句：蓄势可用 riser、入场或撞击用 impact/click、落定可用短促确认音、余韵可用 sparkle/空气感；不要给每个小元素都配同样的提示音，连发要有强弱和间隔。
- UI 和数据类声音优先找带物理感的 click、pop、纸张、机械、键盘、磁吸或轻开关声；合成 notification、bleep、success tone 只在系统播报、报错、AI 回执等明确风格需要时使用。
- UGC 可以保留自然呼吸、停顿和轻微环境声；过度配乐和过度降噪会削弱真实感。
- 反差奇观可以用声音并置制造幽默或高级感：音乐保持优雅、轻快或仪式化，环境声真实表现火山、陨石、海浪、风压、玻璃轻响、布料摩擦等外部压力；音乐不必跟着灾难惊慌，音效要贴近具体触发动作。
- 无对白纯视听叙事必须让音乐、环境声和拟音承担结构：入口或邀请用轻音乐和细小纸张/铃声，探索段用空间混响和魔法粒子声，活化段用明确触发音，群像段用节奏加速和乐器增厚，高潮段用全编制或强节拍，尾帧让音乐自然落下。不能只写“奇幻配乐”，要写每个叙事节点的音画同步点。
- 多参考音乐或声音混搭要先区分来源：A 的 BPM/情绪/音色/色彩，B 的旋律/人声/文化或年代符号，再写两者如何对齐、叠加和融合。不能只说“混搭音乐”，要说明过渡段、drop 点、融合高潮和尾音如何影响画面。
- 技术流数据展示的声音要让图形“可触摸”：标注线出现可用咔哒、叮声、纸张摩擦、测量工具声或轻机械声；数字错位入场要卡在鼓点上，收尾用短促定格音确认完成。
- 动力学排版必须把歌词/文字和音乐结构绑定：文字入场对应音节，黑白反相对应强拍，间奏可用纯图形填充听觉空白，高潮词对应最大字号、唯一彩色或黑场收束。

| 层级 | 职责 | 用法 |
|---|---|---|
| 音乐 | 情绪基底和节奏骨架 | 先确定情绪曲线，再剪画面节点 |
| 环境声 | 建立空间真实 | 街道、办公室、厨房、森林、门店、车内 |
| 拟音/SFX | 强化动作重量和质感 | 开盖、脚步、布料、拉链、点击、倒入 |
| 产品音效 | 让产品有可记忆的声音 | 快门、磁吸、启动、引擎、气泡、咬开 |
| 人声/旁白 | 传递信息、观点和情绪 | 必须最清楚，语气像对人说话 |

音乐可选纯音乐、歌词、钢琴/弦乐、吉他/轻打击、电子/低频、强鼓点。15 秒旁白通常不超过 40 个中文字，30 秒通常不超过 80 个中文字，60 秒通常不超过 150 个中文字；实际密度仍服从主 `SKILL.md` 的台词规则。

## 文案和卖点转换

文案不是把功能读出来，而是把功能翻译成用户能感到的利益。

| 层级 | 问题 | 写法 |
|---|---|---|
| Feature 功能 | 它是什么 | 材料、结构、参数、功能名；必须来自用户资料或可见事实 |
| Advantage 优势 | 它能做到什么 | 更快、更稳、更轻、更清楚、更省心 |
| Benefit 利益 | 对用户意味着什么 | 省时间、少焦虑、更体面、更安心、更自由、更舒服 |

卖点处理：

- 用户明确给出的卖点必须覆盖；卖点很多时分成 P0 主卖点、P1 辅助卖点、P2 背景信息。
- 用户没有给卖点时，可以从外观、材质、使用体验、场景价值和情绪价值中合理提炼，最多 5 个，不编造参数、功效、认证、销量、奖项或价格。
- 主表达通常只突出 1 个 P0 卖点和最多 2 个前台 P1 卖点；其他信息放到尾帧、后期可编辑文字、旁白或产品细节。
- 卖点必须可视化：快用等待对比，持久用时间跨度，轻便用尺度参照，安静用噪音消失，清晰用放大细节，容量用不断放入，食欲用微距、拟音和反应。

文案自检：念出来是否顺口，是否太像广告腔，是否有行业术语，是否可删字，是否把“我们”改成了“你”，是否足够具体，是否能被画面证明。

表达自检：关掉逐句字幕后，观众是否仍能通过旁白、口播、画面文字、图形标签、CTA、主体动作和声音理解视频要表达什么；如果只能看见漂亮画面却说不出主张、证明或行动，就必须补文案抓手。

视频文案必须和节奏一起写，不在画面完成后再补广告词。15 秒及以内的广告默认使用短句、动作句和画面应答句：开场一句负责停滑或提出任务，中段一句压住证明或反转，尾段一句完成记忆或行动；除教程、口播和强信息流外，不用连续长句解释。每句出现前先判断当前画面已经证明了什么、还缺哪层理解；文案只补缺口，不复述画面。

文案弱或平淡时，按以下顺序重写：

```text
普通卖点句
  -> 用户场景里的具体问题
  -> 产品动作或创意机制造成的可见变化
  -> 观众能带走的一句判断
```

不要把“高级、治愈、自由、热爱、未来、想象、从容、焕新、轻盈、清爽”这类抽象词连续堆成文案。可以使用这些词，但同句必须绑定当前画面证据、产品动作或品牌资产，例如某个按钮落位、包装打开、材质改变、人物反应、场景规则改变或尾帧定版。若一句文案删掉后不影响理解，也不制造记忆点、节奏点或行动理由，就删除。

## 真实 UI、Logo 和文本策略

产品和品牌视频的画面可信度优先级高于“好看”：

- 真实页面、App、SaaS 或桌面产品默认以真实截图、官网、设计稿或用户素材为视觉事实源；非复刻场景可以抽象化，但不能生成假 UI 冒充真实产品。
- 从产品素材中提取视觉语言：字体气质、字号层级、圆角、间距、卡片密度、按钮形状、品牌色、状态色、材质、图标风格和动效气质。
- 表现既有页面、后台、App、官网、报表或产品功能时，优先使用真实截图、录屏、设计稿或用户确认素材；如需 2.5D 运镜或模块飞入，内部把整页、关键模块、空白底板、目标槽位和状态变化拆清楚。没有真实素材时，只能做概念演示或抽象界面，不写成真实产品页面。
- 非复刻场景可以手写或生成概念 UI、独立组件和品牌段图形，但必须一眼看懂它表达什么，且视觉质量、信息密度、字体和状态色与产品调性相容；达不到时退回真实截图或更抽象的图形解释。
- 真实 Logo 和商标来自用户上传、品牌文件或可靠公开素材；模型生成的 Logo 若变形、拼错或变成假标，必须返修或降级为后期添加。
- 画面文字默认少而准；卖点、企业口号、品牌主张、活动主题、标题卡、尾帧 slogan、CTA 和真实 UI 原文可以作为设计性上屏文字，不是逐句字幕。
- 需要文字时只用短、准确、可确认的标题字、卖点字或真实 UI 原文；避免长段落、假占位、乱码、小字密集表格和不可控字幕。
- 客户、个人、内部、密钥、实时数据和敏感业务数据必须脱敏、虚构或冻结口径后再进入画面。

| 文本模式 | 使用场景 | 规则 |
|---|---|---|
| 无画面文字 | 氛围片、产品质感、后期另加字幕 | Prompt 禁止随机文字和字幕 |
| 少量精确大字 | Hook、卖点锚点、企业口号、品牌主张、CTA、发布主题 | 每条短文本必须可确认，不逐句复述口播 |
| 真实 UI 原文 | 页面/产品功能演示 | 只保留真实截图或用户确认的 UI 文本 |
| 后期可编辑文字 | 投放、多语言、频繁改文案 | 视频生成尽量做 textless plate |

## 画面层级和合成空间

生成画面时区分三层，避免把后期图形误写成物理场景里的真实物体：

| 层 | 负责什么 |
|---|---|
| 物理场景 | 人、产品、道具、真实互动、屏幕或空间中实际存在的东西 |
| 摄影构图 | 镜头怎么拍、主体在哪、景别、机位、留白、视线和产品位置 |
| 编辑合成 | 字幕、广告大字、MG、图标、卡片、小窗、排名板、进度条 |

需要叠加图形时，先在摄影构图中给人物、产品和图形留出空间；需要真实屏幕或 UI 证据时，优先使用截图、录屏或用户素材。后期卡片、排名板、进度条和标签可以影响构图留白，但不能要求生成主体去触碰一个并不存在于物理场景里的编辑层。

## 分镜节奏和镜头职责

根据平台和时长决定节拍与镜头密度，不机械套固定数量。正式详细分镜密度以 `production-control.md` 为准。

| 场景 | 分镜表节拍 | 结构 |
|---|---|---|
| 15 秒信息流广告 | 5-8 个连续时间段，每段保留一个主动作并写 2-4 个内部微拍 | Hook -> 产品/主体 -> 证明 -> 结果 -> CTA |
| General 简单动态任务 | 4-8 秒；照片动起来固定 5 秒；允许 1 个镜头 | 起始状态 -> 动作启动 -> 细节/环境响应 -> 落定或回环 |
| 真实一镜到底 | 1 个连续镜头；按动作和空间节点划分内部阶段 | 目标建立 -> 连续移动/行动 -> 环境与关系变化 -> 连续落点 |
| 30 秒广告或 Reel | 8-12 个连续时间段，每段按节拍段写清内部动作链 | Hook -> 问题/背景 -> 产品/方案 -> 证明 -> 收束 |
| 60 秒 Shorts/品牌短片 | 8-12 段 | 建立 -> 展开 -> 变化 -> 证明/情绪高潮 -> 行动或品牌记忆 |
| 1 分 30 秒解释/企业片 | 10-18 段 | 问题 -> 方案 -> 机制 -> 证据 -> 价值 -> CTA |
| 5-10 秒产品动效 | 3-6 个节拍 | 入场 -> 产品动作 -> 系统/场景响应 -> 确认 -> 品牌 |

镜头规则：

- 开场镜头必须能在静音播放状态下读出“为什么继续看”；前 3 秒不得只有空镜、慢推、抽象光效、无信息产品剪影或铺垫音乐。
- 0-3 秒必须写成具体动作链：0-1 秒给刺激或异常，1-2 秒给主体/产品/问题线索，2-3 秒给承诺、反差、结果或任务推进；如果采用慢节奏，慢动作里也必须已经出现证明锚点或品牌/产品线索。
- 每个镜头写清目的、主体、动作、景别/机位、一个主运镜、声音/台词、素材引用和尾态。
- 从第二镜开始，每镜都要写清承接上一镜的锚点和本镜新增信息；只写“硬切到全景/特写”“叠化到人物”“镜头移回”不合格。
- 15 秒及以内视频的单镜超过 `2` 秒时，必须拆出至少三个实质节拍；单纯推近、拉远、放大、发光、旋转、漂浮、微笑或手臂微动不得占满长镜。
- 相同动作、表情、构图或结果不得连续重复；再次出现必须升级状态、提供反应、形成对照或完成有意义的首尾回环。
- 景别变化先建立空间，再靠近动作与证据，最后回看结果；全景与特写之间可以跨级，但必须由动作、视线、构图或声音锚点驱动，不得反复无逻辑跳跃。
- 插入主体和 B-roll 必须服务当前镜头职责；无法说明其证明、解释、情绪、转场或回收作用时直接删除。
- 运镜只能有一个主家族；推、拉、摇、移、环绕、手持、固定等不要互相打架。
- 关键信息落定后给 0.4-1 秒呼吸；品牌字标、产品正面、结果状态和 CTA 需要稳定停留。
- 快剪每 2-3 镜后要回到主体或产品锚点，避免观众只记得效果不记得东西。
- 高风险动作要拆小：吃喝、复杂手部、快速转身、多人互动、细小文字、屏幕操作、产品开合和真实 UI 跳转。

## 视听设计转入生成

本文件确定可见造型和可听表达；进入生成时，统一读取 `references/asset-generation.md` 的图片 PE、概念图设计卡、图片确认门和视频五段式。已确认的媒介、影调、镜头语言、色板、字体、材质、声音和主视觉规则必须在真实图片与视频中成立。

图片先呈现确定瞬间中的构图、层级、空间关系和动态把手；视频再补时间、触发、运动、反馈与尾态。首帧、真实尾帧和跨片段接缝由 `references/production-control.md` 调度，不在本文件重复维护生成格式、图数和阶段门。
