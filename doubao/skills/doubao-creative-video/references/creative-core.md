# 创意核心底盘

## 文件说明与索引

本文件是每条视频都必须读取的通用创意底盘。它解决“为什么拍、给谁看、凭什么信、记住什么、风险在哪里”。流程、确认、素材、目录和交付读取 `references/production-control.md`；运镜、布光、构图、色彩、转场、音效和文案读取 `references/audiovisual-craft.md`；视觉效果、运动母版、开场、高光、反转、结尾和转场创意读取 `references/visual-motion-playbook.md`；类型专属策略读取当前唯一命中的类型文件。

## 唯一必填导演总控卡

每条独立视频、每个平台版本或每个交付单元，在进入参数确认、脚本、分镜或 PE 前，只内部完成这一张总控卡。其它文件中的“结果卡、运动卡、性格卡、策略卡、匹配卡、概念转译”均为按需推导方法，不再作为独立必填表单；选中的结论必须合并回本卡，并直接落实到完整分镜与五段式 Prompt。

```text
核心判断：观众看完应相信/感到/记住/去做什么
主体与受众：谁在什么观看场景中被打动
事实与素材：哪些真实锚点必须继承，哪些不可编造
因果主线：问题/诱因 -> 触发 -> 过程 -> 反馈 -> 结果
证明与记忆：最关键的可见证据和一个可复述画面
黄金三秒：前三个信息事件、首次切镜/观看关系变化、继续观看理由
视觉风格：媒介形态、构图骨架、光线方向、色彩关系、材质、镜头质感、字体/版式及明确剥离项
视觉运动：一个主视觉规则、连续运动路径、主转场锚点
节奏与声音：镜长层级、动作重拍、人声/音乐/拟音职责
收束与禁区：结尾状态、品牌/产品/主题回收、风险和禁止项
```

总控卡不是交付物，也不要求逐字段展示。判断完成后只保留能改变镜头、动作、声音、文字或风险控制的结论；无法落到具体秒段的字段和术语删除。

## 规划前置锁

总控卡完成后、参数确认前，必须先把策略变成下面五个可执行结果。它们是预防错误的第一道防线，不允许留到 Prompt 阶段临时补：

1. **核心锁**：用一句话写清“这条片让谁因为看见什么而记住/相信什么”。开场、中段和结尾都必须能回指这句话。
2. **镜头地图**：除 General 简单动态任务和用户明确要求的真实一镜到底外，15 秒视频先规划至少 `8` 个镜头槽位，每镜提前分配唯一主职责、首次新增信息、景别/观看任务、切入理由和切出点。General 简单动态任务改为连续状态地图；真实一镜到底只规划一个镜头及其主体路线、摄影机路线、动作节点和空间变化。两个槽位或动作阶段职责相同就先改写，不进入分镜。
3. **节奏曲线**：需要执行黄金三秒切镜规则的视频先分配开场、展开、证明/升级、高光、结果和按需 `0.6-1.0` 秒静态尾帧，再填镜头；General 简单动态任务按“首秒启动 -> 发展 -> 落定/回环”分配 4-8 秒，照片动起来固定 5 秒；真实一镜到底按连续动作和空间节点分配节奏。不把每镜或每阶段写成同一长度，也不让任一段只承担等待。
4. **连续性地图**：涉及拿取、递送、佩戴、涂抹、行走、放下或跨场景移动时，先画出动作起点、路径、接触点、反馈和可切位置，避免分镜中出现瞬移。
5. **特效计划**：需要特效时，先确定它由什么真实动作触发、改变什么、谁反馈、如何证明核心、如何退出或回收；答不全就不用该特效。适合的特效应在规划时主动加入，不在 Prompt 末尾临时追加。

镜头地图不是最终分镜，但完整分镜必须逐项兑现。后续如果发现某镜头重复、无关或无因果，优先重排规划，不以“写完再删除”作为常规流程。

## 表达意图和文案总控

每条视频先判断它到底想让观众理解、相信、感到、记住或行动什么，再决定镜头、文案和声音。不能只把视频写成“好看的画面集合”，也不能因为用户没有提供文案就让全片没有表达抓手。

内部表达句式：

```text
这个视频想让 [目标观众] 在 [观看场景] 中相信/感到/记住/去做 [核心结果]，因为他们看见/听见了 [可见证明或情绪回报]。
```

表达意图必须落到四个可执行位置：

- 主线：全片按什么顺序把意思讲清楚。
- 证明锚点：观众看见什么才相信这个意思。
- 文案承担方式：口播、旁白、画面文字、图形标签、尾帧 slogan 或 CTA 分别负责哪一层信息；非 TVC 默认必须由至少一种可听人声承担核心表达，品牌 TVC 按“完整旁白 -> 少量旁白 -> 无旁白”的优先级判断。
- 收束目标：结尾让观众记住产品、品牌、人物、企业、主题还是行动。

每个视频片段都必须有一个片段核心，尤其是广告、产品大片、品牌 TVC、企业宣传和短片直出压缩链路。片段核心不是“画面很有创意”，而是一句能被画面验证的判断：

```text
这一段要让观众记住/相信：[一句核心内容]
它用 [具体画面动作/证明锚点/人物反应/产品结果] 来证明
它不能偏离到：[容易被特效或氛围带跑的方向]
```

如果一段视频删掉品牌/产品/主题后仍然成立，说明核心不够具体；如果看完只能说“很漂亮、很有趣、很高级”，但说不出卖点、主张、情绪判断或行动结果，必须重写片段核心。

广告、品牌片、产品片和带人物的创意短片必须先写出一条可复述的因果叙事句，再进入分镜：

```text
[谁/什么主体] 因为 [具体问题、欲望或缺口]，在 [产品/品牌/关键触发] 介入后，通过 [可见行动] 让 [人物、场景或系统] 从 [前状态] 变成 [后状态]，最终记住 [产品/品牌/主张]。
```

这句话不是对外固定模板，但其中的“主体、问题、介入、变化、结果、归属”必须能在时间轴上找到对应镜头。纯产品展示或无人物片也不能免除因果，只是把主体改成产品、空间、界面、材料或声音。如果无法写出这句话，说明当前只有画面陈列，没有故事；先补齐因果再选风格和镜头。

每条短片还必须内部建立信息增量账本。每个镜头只登记一个首要新增信息，例如“女孩因无聊踢石子”“包装从货架滑到手边”“撕口触发整条街亮灯”“路人被咔嚓声吸引转头”“门头回收品牌”。连续镜头如果新增信息相同，只是换景别、换角度、继续环绕、继续吃、继续摆拍或让同一特效再发生一次，必须删除或合并。镜头数量合格不代表叙事合格；所有镜头都必须改变观众对人物、问题、产品、证明、结果或品牌归属中的至少一项理解。

文案不是字幕。默认无字幕不等于没有文案策略；字幕只负责逐句同步显示，文案负责停滑、解释、证明、记忆和行动。非 TVC 默认必须由旁白、口播、对白、画外音或解说中的至少一种承担核心表达，再由画面文字、标题卡、关键词、图形标签、包装/UI 原文、尾帧 slogan 或 CTA 补强。品牌 TVC 可以由 Agent 判断使用完整旁白、`1-3` 句少量旁白或无旁白，但无旁白优先级最低，且必须由可见动作、产品/品牌反馈、画面文字、音乐、拟音和结尾回收独立完成理解。

每条广告必须指定一个主信息载体。非 TVC 使用人物对白、旁白或口播；用户明确要求无人声时，才改用递进画面文字或完全可复述的纯视觉因果链。品牌 TVC 按三级声音优先级判断，采用无旁白时必须把完全可复述的纯视觉因果链设为主信息载体。主信息载体要覆盖至少三个不同节点，例如“问题/欲望 -> 产品介入或方法 -> 结果/品牌”；只有产品名、氛围词、拟声字、BGM 或尾帧 slogan 不算完整信息载体。无旁白分镜必须逐节点写明哪一个动作、反应、场景变化、品牌资产或图形状态替代语言完成理解；无法做到就回退到少量旁白或完整旁白，并重新确认声音方案。

用户没有给任何可听文本、也没有要求无人声时，由 agent 根据内容类型主动起草合适的口播、旁白、人物对白、画外音或解说，并按需补充画面文字、图形标签、尾帧 slogan 或 CTA。用户给了台词、旁白、口播、对白、画外音或解说原文时，全部逐字锁定；未经用户明确要求，不得新增、删减、改写、合并或另补其他人声内容。若原文字数超过时长承载能力，必须在参数确认中指出并让用户决定改文案或改时长，不能静默压缩。文案不是描述卖点，而是在画面里做动作：筛选观众、挑衅常识、放大感受、换口吻、留悬念、制造概念碰撞、和画面形成反差，或用短句完成记忆。这些动作要按视频类型、行业风险、品牌语气、平台语境和观众关系迁移改写；挑衅、荒谬、强反差或网感语气不适合时，改用提醒、证据、事实转译、轻隐喻、留白或温和行动。涉及功效、数据、客户案例、价格、优惠、认证、身份或企业事实时，文案只能使用用户材料、可靠来源或明确的概念化表达。

## 用户指令预检

规划前先整理或推断这些要点，默认直接形成完整方案；brief 简短、没给脚本、没选风格或规格不全时，由 agent 自行补齐可修改假设。素材询问和执行确认以 `references/interaction-ask-video-clarification-ref.md` 为准；真实性、授权、工具可执行性或交付会被阻断时，才说明缺失条件：

- 目标：成片生成、视频提示词、分镜规划、关键帧/首帧图、可交给其他工具的 motion handoff，或创意变体。
- 类型：UGC 口播、产品广告、品牌 TVC、企业商务、通用创意或多交付混合型。
- 平台和时长：抖音、快手、TikTok、Reels、YouTube、B 站、官网、大屏、投放平台，以及总时长、单段上限和比例。
- 传播目标：停滑、解释、证明、转化、品牌记忆、招商、招聘、活动预热、教学或情绪氛围。
- 表达意图：观众看完应该理解、相信、感到、记住或采取什么行动。
- 主体与素材：产品、人物、品牌、企业、场景、UI、Logo、音频、参考图/视频各自职责。
- 事实与证明：哪些声明、数据、客户、奖项、效果、价格、优惠或身份需要用户材料或检索核实。
- 文本策略：口播、旁白、画面文字、图形标签、尾帧 slogan、CTA、真实 UI 原文、用户要求时的后期可编辑字幕/花字，或用户明确要求的视频内字幕；非 TVC 的纯视觉表达只在用户明确要求无人声后采用，品牌 TVC 还可按三级声音优先级判断。
- 交付策略：单条成片、长视频连续成片、多个独立变体、分平台版本，或只输出方案。

如果目标不清，不要盲目承诺固定镜头数或生成批次；先在参数确认中写出推进假设，让用户能改。缺少参考视频不是阻塞项：应先用本文件和通用视听/视觉策略主动生成方向；需要真实品牌、产品、企业或人物事实时，不填造事实，用可修改假设、概念化表达或技术阻塞说明处理。

用户未指定时长时，先按叙事节点计算“最短成立时长”，再在模型合法范围内取值，不默认使用 15 秒。一个问题、一次产品介入、一个可见变化和一个品牌收束如果 5-8 秒已经成立，就用 5-8 秒；只有新增了不同的证明、反应、升级或结果节点，才延长到 9-15 秒。不得用重复展示、慢推、环绕、同场景小动作、冗余氛围或延长尾帧把 5 秒内容拉成 15 秒。

## 短 brief 自动扩写

用户常常只给一句很短的需求，例如“做个鲜奶广告”“给这双鞋做个视频”“生成一个品牌预热视频”。不能因为 brief 短就输出普通展示片，也不能反复追问参考视频、脚本或风格。除非真实性、授权、素材或工具执行被阻断，否则默认由 agent 主动扩写成一个完整、有惊喜但仍贴合用户指令的视频方案。

短 brief 扩写顺序：

```text
用户原句
  -> 推断主类型和平台默认值
  -> 提炼一个可修改的核心表达
  -> 推断受众张力和观看场景
  -> 找一个最小证明动作
  -> 发散 3-5 个可用创意玩法
  -> 选择一个主创意系统 + 1-2 个辅助职责
  -> 组合成一条清楚叙事线
  -> 写入参数确认、分镜和 PE
```

扩写原则：

- 贴合用户原意，不擅自改变品类、品牌、真实产品外观、核心任务或交付目标。
- 主动补足平台、比例、时长、节奏、文案、声音、视觉机制和尾帧收束，但把不确定事实写成可修改假设。
- 惊喜来自“熟悉主体的新观看方式”，不是凭空加入无关剧情、角色或过度复杂世界观。
- 先把简短需求翻译成一个具体观看承诺，例如“鲜奶不只是出现，而是让观众看见新鲜从牧场跳进杯子里”；再决定创意。
- 不因缺少素材而退回“产品静态旋转 + 卖点字”。没有素材时，使用概念化产品、场景化动作和可替换视觉规则；真实 logo、包装、价格、认证和功效仍需用户确认或素材支持。

短 brief 的输出不能只给一个安全方案。除 General 简单动态任务外，内部发散 `3` 个不同主机制候选，每个候选附带 `1-3` 个同源辅助机制，再按用户匹配、核心证明、连续性和生成稳定性收束成最适合当前目标的一组；用户要求多方案时才展示候选。没有要求多方案时，只展示最终选中的 `1` 个主机制和按需 `1-3` 个辅助机制。General 简单动态任务不做多方向发散，只从用户指定内容和原图可成立的运动中选择一个主动作、最多两个因果次级运动和一个摄影机策略。

内部候选不是随意脑暴，但不再逐个填写完整匹配卡。每个候选只比较以下五项：

```text
来源：
证明：
触发：
推进与回收：
主要风险：
```

三条主机制候选必须共享同一个核心表达或同一个传播目标，只是在机制、视角、节奏或证明路径上不同；不能一条讲产品功能、一条讲无关剧情、一条讲纯视觉奇观。每个候选的 `1-3` 个辅助机制必须先说明具体职责，并与该候选共享触发、视觉语言或回收路径。收束时按用户匹配、核心证明、连续性和生成稳定性选择一个主机制，再从三个候选中只吸收与它兼容的 `1-3` 个辅助机制。主机制可以由多个相关创意节点组成，例如同一包装机关的连续展开、同一字体规则的多次变形、同一产品世界里的多关任务、同一声音/动作触发的空间连锁反应；这些节点必须同源、同目标、互相承接。若某个创意没有来源、没有证明职责、不能贯穿前中后或不能回收，它不是候选，只是装饰。

## 完整 brief 的增补边界

用户给得很完整时，仍要在满足用户指令的前提下做导演层增补。完整 brief 是地基，不是天花板；不要因为用户已经写了卖点、脚本或镜头，就只机械复述。agent 应该补足用户通常没有明说但会决定成片质感的部分：核心表达压缩、主玩法选择、节奏曲线、镜头运动、转场因果、声音触发、证明动作、尾帧收束和生成控制。

增补顺序：

```text
用户已给内容
  -> 锁定不可改的事实、限制和必须覆盖项
  -> 压成一个核心表达
  -> 判断已有内容是否有重心、主玩法和节奏曲线
  -> 保留用户明确要求的情节/卖点/风格
  -> 补强停滑、视觉事件、证明动作、声音和收束
  -> 删除或降级会抢主线的额外想法
```

增补规则：

- 不改变用户明确指定的产品、品牌、人物、事实、卖点、风格、镜头、口播、时长、比例、平台和禁用项。
- 用户给了多卖点时，先选一个主卖点做核心表达，其余作为辅助证明、画面细节、口播短句或尾帧信息，不让它们平均抢戏。
- 用户给了完整脚本时，可以优化镜头调度、节奏停顿、声音设计、视觉隐喻和过渡方式；不要擅自改成另一个故事。
- 用户给了参考片时，迁移其“作用机制”，例如尺度反转、光影揭幕、第一视角动作链、分屏汇聚、语义幻变或城市空间合成；不要照搬具体角色、画面、文案或商业事实。
- 增补必须让成片更聚焦、更可看、更可复述。不能为了惊喜加入和核心无关的新角色、新世界观、复杂支线或未经确认的品牌声明。

每次增补后做一句自检：

```text
我新增的创意/镜头/声音让观众更清楚地相信或感到：[核心表达]，因为它让他们看见/听见：[具体变化]。
```

## 创意推导顺序

下列维度只用于发现遗漏，不再形成第二张必填卡；结论合并到唯一导演总控卡：

```text
传播策略
  -> 受众洞察
  -> 产品真相/证明逻辑
  -> 平台语境
  -> 品牌/产品资产记忆
  -> 视听节奏
  -> 镜头语言
  -> 声音设计
  -> 美术与材质系统

然后进入：
叙事结构 -> 视觉效果 -> 生成控制
```

前四层决定方向，中间五层决定观看体验，最后三层决定表达和落地。专项类型只改变证明逻辑、风险边界、素材优先级和默认节奏，不重新发明这套底盘。

## 策略迁移适配总则

通用策略可以用于任何场景和类别，但不能原样套用。迁移适配不另填表，只确认五件事并直接改写进镜头：

```text
服务目标：
当前主体：
触发动作：
可见/可听结果：
证明、回收与风险：
```

迁移规则：

- 保留策略作用，替换表层对象。不要把一个食品广告里的“咬下声波”照搬到 SaaS；应迁移成“点击后任务卡片按节拍归队”。
- 先问策略服务什么：停滑、解释、证明、种草、品牌记忆、信任、情绪还是 CTA。服务不清的策略不用。
- 每个维度都要和主线发生关系。构图要引导观众看证明点，色彩要服务情绪或品牌，声音要绑定动作，转场要承接因果，文案要补足画面无法直接说清的信息。
- 类型文件负责适配边界：产品广告回到产品真相和证明链；UGC 回到人的可信表达；品牌 TVC 回到品牌主张和资产记忆；企业商务回到事实证据和受众决策；通用创意回到概念变化和情绪回环。
- 好的迁移会让策略换到别的产品或类型后必须重写。如果只替换产品名还成立，说明它仍是通用空话。

策略落地自检：

```text
观众第一秒看见什么？
中段看见什么新信息或新证明？
最可复述的画面是什么？
声音在哪个动作上加分？
构图和色彩如何帮助理解？
结尾回收到哪个真实资产或结果？
哪些内容因为事实、授权、文字或模型风险不能写？
```

策略进入 PE 时必须变成秒段动作，不能停在策略名。凡使用叙事策略、视觉母题、动效、转场、声音设计、文案动作或强风格，都要在对应时间段写清：

```text
时段：
触发点：
谁/什么在动：
怎么动：
为什么这样动：
观众看见的新信息：
镜头/构图/光线：
声音或静默：
落点/停留：
禁止项：
```

禁止只写“加一个动画效果”“增加动感”“使用高级转场”“做品牌化表达”“体现科技感”“突出产品卖点”。这些句子必须改写为可生成、可检查的动作，例如“0.8-1.4 秒，手指点下真实 UI 的导出按钮，三张任务卡从右侧以错峰减速嵌入列表行，最后一张落位时有轻 click，列表顶端状态从处理中变为完成，停 0.4 秒让完成状态可读”。

## 跨案例通用母题

从参考视频和用户给出的创意例子里，先抽取能迁移的母题，再决定是否落到具体类型文件。母题不是案例名，也不是可直接粘贴的 prompt；它回答“这个创意为什么能被记住”，再改写成当前主体、证明锚点、声音和收束方式。

| 母题 | 核心作用 | 可迁移写法 |
|---|---|---|
| 从容反差 | 用稳定主体对抗失控环境，制造荒诞、优雅、幽默或高级掌控感 | 主体保持克制动作，外部压力逐级升级；结尾回到主体状态、产品结果、人物气质或品牌姿态 |
| 导览奇遇 | 用一个角色、物件、声音或光点带观众穿过信息/空间，降低理解成本 | 引路物每到一站触发新发现；适配到产品可变成包装、光标、数据卡或手部动作，适配到企业可变成一条流程线 |
| 静物活化 | 让艺术品、展品、包装、UI、文字、数据或工具从静态对象变成行动者 | 先保留真实识别点，再让局部突破边界并影响现实；结尾解释它为什么属于当前主题 |
| 多源融合 | 两种声音、风格、文化、年代、角色或使用场景先各自成立，再融合出第三种结果 | A/B 各有颜色、节奏、符号或动作；中段对齐、叠加、冲突；高光给融合后的新状态 |
| 数据化观看 | 把人、穿搭、产品、空间或流程变成可测量、可比较、可拆解的对象 | 用标注线、角度、编号、图纸、UI 面板或分层卡片解释结构；真实数据缺失时只写概念标签 |
| 文字成为主体 | 文字、歌词、口号、标题或关键词不再解释画面，而是直接参与运动和构图 | 关键词运动等于语义本身；字号、颜色、反相、遮罩、裁切和留白都服务节拍或主张 |
| 文字入构图 | 地名、品牌词、产品名或主张成为画面结构的一部分 | 文字占据下三分之一、背景带或透视面，和主体线条、色彩、倒影、阴影或材质呼应；它不是字幕，必须帮助观众记住主体 |
| 框架入口 | 画框、窗框、门框、屏幕、包装口、杯口或输入框成为进入下一层世界的门 | 每次穿过框架都出现新信息，不能只做漂亮转场；入口最终要回收为真实资产或主题边界 |
| 逐级升级 | 从单点变化扩展到群像、空间、系统或庆典，让观众感到规模变大 | 每一级必须新增信息、证明或情绪，不只是更多特效；高潮后要有稳定识别落点 |
| 空间折叠/海报化世界 | 把真实地点、建筑、产品或空间折叠进一张强风格视觉海报 | 先保留稳定熟悉锚点，再分层替换背景、地面/倒影、前景剪影、光源和大字；结尾回到主体身份、地点名称、品牌资产或教程机制 |
| 展示→揭秘 | 先用完成效果停滑，再解释它如何被做出来 | 开头直接给最终视觉或结果；中后段揭示图层、素材、时间线、核心参数或操作逻辑，揭秘必须教会关键机制，不能只甩一张界面截图 |
| 首尾回环 | 结尾回到开场物件、动作、声音、颜色或构图，但意义已经改变 | 开场埋线索，中段让线索变形或升级，结尾用同一元素完成答案、记忆或 CTA |

母题迁移时优先问四件事：

- 它负责停滑、解释、证明、情绪、记忆还是转化。
- 当前视频里哪个真实主体能承接它，不能只用抽象特效承接。
- 它的声音同步点在哪里，是节拍、动作、拟音、静默还是人声。
- 结尾回到什么：产品、人物、品牌、企业事实、活动主题、空间身份或一个可复述画面。

同一条片只选一个主母题，并按实际需要选择 `1-3` 个辅助母题；不需要时不为凑数量硬加。母题之间要有主从关系，例如“导览奇遇”为主，“静物活化”和“框架入口”服务空间发现；“多源融合”为主，“文字成为主体”和“首尾回环”服务音乐节拍。不要把所有母题堆进一条片。

## 创意推导顺序

拿到任意用户指令后，先按下面顺序推导，再进入参数确认和五列分镜表：

1. 定 P0 传播目标：停滑、种草、解释、证明、转化、品牌记忆、发布预热、招商信任、教学中只选一个主目标。
2. 找受众张力：观众正在逃避什么、期待什么、担心什么或想证明什么；开场必须击中这个张力。
3. 锁证明锚点：观众必须看见什么才相信，如质地、声音、动作反馈、前后状态、真实 UI、数据来源、人物选择或场景变化。
4. 找结果转译：产品、品牌、人物或主题介入后，现实发生什么不正常但能理解的变化；保湿、控油、续航、速度、酥脆、香气、秩序、效率、安心等抽象价值必须变成可见结果。
5. 选记忆资产：品牌色、产品轮廓、包装结构、logo 位置、声音、动作、符号或短文字至少在开场线索、中段证明或结尾回收中出现两次。
6. 定叙事骨架：结果先给、异常入侵、连锁反应、规则揭示、平行碰撞、循环破局、谜题揭示、生活方式探索、问题到解决等只选一个主骨架。
7. 定创意机制和视觉规则：选择物理规则篡改、尺度错位、视角置换、虚实融合、线索贯穿、逐级升级、反差美学或互动式展示等主机制，并说明哪条现实规则被改变。
8. 定运动母版：用冲入入口、追随移动物、遮挡揭示、下坠/上升、环绕压力、逐拍升级、倒推痕迹、同物穿史等连续动作骨架承载创意。
9. 做品类/场景适配：同一机制可以用于任何品类，但触发动作、体验外化、场景响应、证明锚点、风险边界和回收方式必须因当前内容改变。
10. 排节奏曲线：标出开场、高光、反转/揭示、结尾四个重拍，再安排镜头密度、台词密度、声音进入、静默、切镜和留白。

如果推导后仍然只能写出“主体出现、展示卖点、用户满意、结尾 logo”，说明底盘未完成，必须重做受众张力、证明锚点、结果转译和记忆资产。

## 商业广告通用决策

产品广告、品牌 TVC、产品 launch、商业氛围片、高规格信息流广告和企业商务传播都先完成这条决策链，再进入对应类型文件的专属策略：

```text
平台语境 -> 传播目标 -> 证明任务 -> 叙事骨架 -> 创意机制 -> 视听语法
```

每条商业视频都必须先写清：

| 决策项 | 要判断什么 |
|---|---|
| 平台语境 | 展示位置、比例、观看状态、声音状态、安全区、是否需要平台原生表达 |
| 传播目标 | 品牌认知、产品转化、新品发布、情绪种草、信息流停滑、活动预热或信任证明，只选一个主目标 |
| 证明任务 | 观众必须看见什么证据，才会相信产品、品牌、服务或行动主张 |
| 叙事骨架 | 全片按什么顺序推进，只选一个主骨架，不把多套结构硬拼 |
| 主创意机制 | 本片最核心的创意动作、视觉机制或声音机制，只选一个主机制 |
| 视听语法 | 运镜、布光、构图、色彩、转场、声音、文案和镜长如何统一 |
| 事实边界 | 哪些卖点、数据、价格、客户、认证、奖项、活动信息或功效声明需要用户材料 |

通用规则：

- 品类不决定模板，品类只决定证明任务。食品可以做发布会感，手机可以做生活方式，香氛可以做品牌实体化，工具可以做强互动；但创意必须回到当前产品、品牌或服务。
- 一条片只保留一个主传播目标、一个主叙事骨架和一个主创意机制。辅助机制最多 0-2 个，服务节奏、卖点或结尾。
- 除 General 简单动态任务和用户明确要求的真实一镜到底外，视频前 1-3 秒必须有停滑信息：人物动作、产品线索、强场景、问题瞬间、声音钩子或画面反差至少有一个成立。General 简单动态任务首秒必须启动可见运动；真实一镜到底前三秒必须建立主体目标、运动方向、环境变化或观看悬念。
- 黄金三秒不能慢铺。广告、TVC、产品 launch、UGC 信息流和企业短片必须在 0-3 秒内完成“看点承诺”：0-1 秒给可识别刺激，1-2 秒给主体/问题/产品线索，2-3 秒给继续看的理由。高端、诗性或电影化也可以慢，但不能空：慢镜头里必须已经有产品线索、品牌色、人物处境、异常规则、声音钩子或核心动作。General 简单动态任务和真实一镜到底不强制切镜或三个叙事信息事件，按各自连续状态规则推进。
- 品牌和产品不要只留到最后。认知和转化视频要早出现；高端形象片可以含蓄，但前段仍要有产品形态、品牌色、包装、材质、声音或视觉母题作为线索。
- 声音不能是唯一信息通道。移动端视频要做到静音播放也能看懂核心信息；声音负责增强节奏、情绪和记忆。
- CTA 只保留一个主动作。购买、下载、预约、咨询、关注和了解更多不能同时堆满；主 CTA 要和传播目标一致。
- 健康、安全、功效、环保、产地、认证、奖项、销量、客户背书、价格优惠和收益承诺必须来自用户资料或可靠来源。
- “大片感”不是慢镜头、黑底、低频音乐和最后 logo，而是单一概念、强识别资产、明确情绪曲线和主体不可替代。

## 核心表达压舱石

每条视频都必须先有一个能被观众复述的中心，而不是先有风格、特效或场景。中心不是主题词，也不是卖点清单，而是一句“看完后应该留下的判断”。进入分镜前必须内部锁定：

```text
核心判断：观众看完要相信/感到/记住什么
证明动作：哪个可见动作让这个判断成立
创意机制：哪条现实规则或观看方式被改写
情绪残留：最后留下安心、向往、爽感、惊喜、信任还是行动冲动
回收资产：产品、品牌、人物、企业事实、主题字或 CTA 如何把意思收住
```

如果只剩“画面高级、很可爱、很治愈、很有科技感”，但说不出观众要记住哪一个产品利益、品牌判断、人物状态或行动理由，必须重写。视频可以少文字、慢节奏或极简；非 TVC 只有用户明确要求无人声时才可以无旁白，品牌 TVC 还可在三级声音优先级判断通过后采用无旁白。任何无旁白方案都必须由动作、声音、转场、尾帧和产品/品牌回收共同讲清核心。

核心表达落地规则：

- 一个视频只保留一个主核心。辅助卖点、情绪和玩法都服务它，不把天然、科技、高级、优惠、礼赠、生活方式和品牌理念平均塞满。
- 除 General 简单动态任务和用户明确要求的真实一镜到底外，视频前 3 秒给出“看点承诺”：问题、结果、产品线索、异常规则、人物动作、声音钩子或品牌世界入口至少一个清楚成立。General 简单动态任务首秒启动主动作，真实一镜到底前三秒建立连续行动目标，不为满足通用模板擅自增加用户没有要求的冲突、角色或场景。
- 中段必须新增证明，不只是换景。每一次转场、特写、变形、分屏、堆叠、生长或口播跳切都要让观众多相信一点。
- 高光必须是核心最清楚的一刻。可以是产品完成变身、礼盒填满、污渍消失、屏幕结果落定、人物汇聚、光影揭幕、源头进入产品或一句品牌主张落下。
- 结尾不新增复杂信息，只回收核心：稳定产品/品牌/人物/企业事实/主题字/行动入口，让观众知道刚才的创意属于谁、证明什么、下一步是什么。

## 从卖点到影片发动机

卖点是名词或形容词，影片发动机必须是一个带动作、带因果、带画面结果的句子。不要把“天然新鲜、高级质感、补水修护、清洁力强、轻盈百搭、专业可靠”直接当核心表达；它们只能作为输入。进入玩法选择前，必须把卖点翻译成能推动镜头的动态表达。

转译公式：

```text
静态卖点：[形容词/功能词]
观众默认理解：[他们以为会看到什么普通展示]
反常识改写：[哪条现实规则被轻轻改写]
触发动作：[产品/人物/声音/场景如何启动]
可见结果：[画面中发生什么变化]
回收方式：[如何回到真实产品/品牌/行动]
发动机句：[一句能指导整条片的动态表达]
```

示例写法不是固定模板，而是推导方法：

| 静态卖点 | 弱核心 | 发动机句 |
|---|---|---|
| 天然新鲜 | 鲜奶来自牧场 | 新鲜不是被说出来的，是清晨牧场沿着奶浪一路跳进杯子里 |
| 轻盈 | 跑鞋很轻 | 每一步落下，城市的线条都慢半拍，让脚步先到 |
| 清洁力强 | 喷一下很干净 | 油污像退潮一样被喷雾赶出画面，桌面露出原本的光 |
| 高级质感 | 产品很高级 | 光不是照在产品上，而是被产品开合重新整理成秩序 |
| 补水 | 肌肤更水润 | 干燥纹理被一滴水光从边缘点亮，最后回到真实涂抹后的自然光泽 |
| 效率 | 工具提高效率 | 杂乱任务卡被一次点击按节拍归队，结果面板稳稳落下 |

发动机句必须让后续选择自然长出来：

- 运镜知道追什么：跟随奶浪、脚步、污渍退潮、光线归位、任务卡归队。
- 声音知道卡哪里：倒入、落步、喷雾、开合、点击、归位。
- 高光知道是什么：牧场进入杯口、城市慢半拍、油污退净、光线成形、结果面板落定。
- 尾帧知道收什么：杯中鲜奶、上脚跑鞋、干净桌面和清洁喷雾、产品英雄角、真实 UI 结果。

## “非它不可”玩法选择器

玩法不是“这个品类常用什么”，而是“当前核心如果不用这个玩法是否还成立”。选择玩法前，先发散 3-5 个方向；选择时用以下四问筛掉普通方案：

```text
1. 这个玩法是否由当前产品/品牌/人物/场景的独特结构触发？
2. 这个玩法是否让核心表达比直说更清楚？
3. 这个玩法是否能产生一个观众可复述的画面？
4. 如果换成另一个品类或品牌，玩法是否仍几乎不变？
```

判断结果：

- 前三问都能回答，且第四问答案是“不太能换”，才是强主玩法。
- 前三问能回答，但第四问“换谁都行”，它只能做辅助玩法或需要再改写。
- 只能回答“好看、梦幻、高级、治愈、科技感”，不是玩法，是风格词。

改写方法：

| 弱玩法 | 为什么弱 | 改成强玩法 |
|---|---|---|
| 鲜奶做牧场生长 | 同类产品都能用 | 牧场从杯口长出，奶浪把清晨、草地、包装信息一路带回餐桌 |
| 跑鞋多人奔跑 | 任何跑鞋都能用 | 每位主角的脚步触发不同城市线条，最后线条汇成鞋身复古蓝白纹 |
| 护肤水光花影 | 很多护肤都能用 | 面霜罐的圆形边缘变成水面涟漪，涂抹路径让干纹区域逐步透亮 |
| 清洁前后对比 | 直白但普通 | 污渍先占领桌面边界，喷雾落点像指挥线一样让污渍退潮归零 |
| 3C 产品悬浮 | 常见展示 | 开盖瞬间声音被可视化切开，左右声场以产品结构为轴归位 |

## 反常识一拍

每条有创意诉求的视频都要寻找一个“正常世界被轻轻改写的瞬间”。它不是随机奇观，也不是越怪越好；它是让观众停一下、同时更理解核心表达的一拍。

反常识一拍的生成步骤：

```text
观众默认预期：他们以为会看到什么
反向动作：把默认预期中的一个物体、尺度、因果、视角或时间关系反过来
产品/主题因果：为什么是当前主体触发
证明回报：它让核心表达更清楚的地方
安全边界：它不能暗示未经证实的真实功效或事实
```

可改写变量：

| 变量 | 普通预期 | 反常识一拍 |
|---|---|---|
| 尺度 | 产品在场景里展示 | 场景被产品尺度改写，产品最后回到真实尺寸 |
| 因果 | 人使用产品后有结果 | 环境先对产品动作产生反应，再回到真实结果 |
| 来源 | 原料被介绍 | 原料或源头从产品内部、杯口、包装或屏幕里出现 |
| 时间 | 按步骤演示 | 先给结果，再让画面倒回触发动作 |
| 视角 | 旁观产品 | 从包装、液滴、脚步、污渍、光标或声音的视角看世界 |
| 材质 | 真实物体保持原样 | 世界按产品质地重构，例如毛毡、积木、奶油、金属、纸模 |
| 语言 | 文字解释卖点 | 文字、logo、参数或 UI 自己行动并完成证明 |

反常识一拍必须落到分镜里，不能只写在创意阐述里。至少明确：

- 出现在哪一秒。
- 谁触发。
- 画面怎么变化。
- 声音怎么配合。
- 变化后观众多相信了什么。
- 下一个镜头如何回到产品/品牌/人物/行动。

## 创意强度审片器

进入参数确认、分镜或 PE 前，内部用 6 项给当前方案过一遍。不是为了打分展示给用户，而是为了发现哪里普通、哪里散、哪里不像一条片。

| 检查项 | 强方案表现 | 弱方案信号 | 修法 |
|---|---|---|---|
| 核心表达 | 一句话能说清观众记住什么 | 只剩卖点词或氛围词 | 改写成发动机句 |
| 玩法必要性 | 玩法由当前主体触发，不易替换 | 换成任何产品都成立 | 找产品结构、使用动作、场景阻力重新触发 |
| 可复述画面 | 观众能说“那个视频里……” | 只有好看镜头，没有事件 | 设计一个变身、退潮、归位、汇聚、揭幕或反转 |
| 证明因果 | 产品/人物动作导致结果 | 结果凭空发生 | 加触发动作、接触点和结果停留 |
| 节奏高光 | 高光压在核心最清楚处 | 从头到尾平均展示 | 前段铺垫规则，中段升级，7-11 秒给最大变化 |
| 收束落点 | 结尾知道属于谁、证明什么、做什么 | 看完只记得特效 | 稳定产品/品牌/人物/结果/CTA，尾帧不再新增卖点 |

强度不足时，不要简单加特效。按优先级修：

```text
核心太虚 -> 重写发动机句
玩法太泛 -> 找产品专属触发动作
画面不记忆 -> 加一个可复述视觉事件
因果断裂 -> 增加触发、接触、反馈、结果停留
节奏平 -> 调整为铺垫-升级-高光-收束
结尾散 -> 删除新信息，回到一个稳定落点
```

## 主创意系统收束

“一个核心表达、一个主创意系统、一个主节奏”不是要求视频单薄，而是要求所有创意有同一套因果和主从。每条片可以有多个相关创意节点、辅助玩法、辅助策略和局部小高潮，但它们必须围绕主核心服务，不能各讲各的。多个创意可以成立，只要它们属于同一个全局规则、同一条任务链、同一种字体/包装/空间/声音/材质系统，或同一个产品/品牌触发后的连续反应。

内部先写：

```text
主核心：
主创意系统/全局规则：
主节奏：
相关创意节点：
辅助职责 1：
辅助职责 2：
辅助职责 3（按需）：
哪些镜头不服务主核心，需要删除或降级：
```

主创意系统负责建立观众记住的视觉事件；相关创意节点负责把这个系统分阶段建立、升级、转译和回收；辅助职责只负责停滑、过渡、证明补强、情绪升温、尾帧记忆或平台适配。例如鲜奶可以用“牧场源头到产品”做主系统，奶牛节拍、奶浪路径、包装显影都围绕“源头进入产品”递进；也可以用“包装生长生成”做主系统，牧场晨光和奶牛只作为源头证明。不能同时让奶牛舞蹈、种子发芽、包装生成、牧场全流程、产品悬浮和家庭早餐都互不承接地争当主线。

主辅关系判断：

- 主创意系统删掉后，视频核心就不成立；辅助职责删掉后，视频仍成立但少了一层趣味、节奏或证明。
- 主创意系统贯穿开场、中段和结尾；相关创意节点按建立、升级、转译、反应或回收承担不同职责。
- 主创意系统和主节奏必须一致。悬念揭幕就不要中途变成过快测评；生活方式沉浸就不要突然塞满促销大字。
- 辅助机制按实际需要保留 `1-3` 个，且每个只承担停滑、解释、证明、情绪、记忆、转场或 CTA 中的一项明确职责；不需要时不得为了凑数量硬加。
- 创意必须和叙事在同一条因果链里：产品/人物/场景动作触发玩法，玩法改变画面或信息状态，变化反过来证明卖点、推进选择或改变人物/空间关系，最后回到产品/品牌/主题。不能一边讲普通故事，一边随机插入独立特效；也不能让特效结束后对后续镜头没有影响。

## 参考玩法的深层迁移

参考视频里的“玩法”不能作为示例照搬，也不能在方案里单独列一个案例栏。它们要被拆成深层机制，再长到当前主体身上。常用机制按职责选择：

| 机制 | 负责的核心表达 | 迁移写法 |
|---|---|---|
| 光影揭幕 | 发布、预热、高端、神秘感 | 用遮挡、轮廓光、布料/雾/反射逐步释放局部信息，结尾完整揭示产品或主题 |
| 自然生长 | 天然、长期主义、纯净、生命力 | 从种子、水滴、藤蔓、纹理或信息元素长出产品资产，让“来源”变成“结果” |
| 形态幻变 | 焕活、升级、食材来源、节庆联想 | 一个真实物件顺着形状、材质或语义变成产品，不靠硬切解释 |
| 自主编舞 | 产品丰富度、精致感、模块能力 | 产品、零件、巧克力、耳机、建筑模块或 UI 卡片自己运动、归位、填满或悬浮 |
| 材质世界化 | 感官、童趣、治愈、风格记忆 | 把产品或主题所在世界统一改成羊毛毡、积木、黏土、纸模、零食田园等材质规则，并让任务在这个世界里完成 |
| 行为触发魔法 | 宠物、人物、手部、用户动作带出产品 | 好奇、开盖、点击、捞起、喷洒、咬下、拉扯、系鞋带等动作触发变化，变化必须回到卖点 |
| 物理小高潮 | 酥脆、弹性、稳定、分量、清洁力 | 堆叠、微晃、弹出、拉伸、分解、回弹、归位制造短促爽点，再稳定展示结果 |
| 源头到产品 | 新鲜、可信、工艺、供应链 | 从牧场、原料、实验室、工序、冲泡、灌装或服务流程线性走到产品和结果 |
| 并行汇聚 | 多人、多场景、多 SKU、多身份适配 | 分屏或多线并行展示不同使用者/场景，最后汇聚到同一产品、品牌主张或行动 |
| 沉浸体验 | 户外、香氛、咖啡、运动、露营、生活方式 | 用第一视角、真实动作、环境声和身体节奏，让观众感觉自己正在使用而不是观看广告 |

选择机制后必须完成三句转译：

```text
它由当前主体的哪个真实动作触发？
它证明或放大哪一个核心判断？
它最后如何回到真实产品/品牌/人物/行动？
```

如果无法回答，就不要使用该玩法。创意机制不是“再加一点有趣”，而是表达核心的主语法；它要替代空泛讲述，让观众凭一个画面记住“为什么是这个产品/品牌/主题”。

## 吸引力机制、角度和钩子

吸引力不是“更炸、更电影感、更反常”的堆叠，而是观众愿意继续看的理由。每条视频至少要有一个主吸引力机制，且它必须和后续证明或情绪回报连上。

| 机制 | 适合解决 | 使用方式 |
|---|---|---|
| 未完成信息 | 停滑、悬念、揭示 | 开场给结果、异常或问题，中段补原因，结尾回收答案 |
| 感官承诺 | 食品、美妆、材质、空间、生活方式 | 用声音、光线、微距、触感和动作让观众感到“看得见体验” |
| 身份投射 | 品牌、时尚、生活方式、招聘 | 让观众看见自己想成为的人、状态或圈层，不只展示物 |
| 反差纠正 | 教学、评测、转化、B2B | 先呈现误区或旧方式，再用可见证据完成转向 |
| 世界规则 | 概念片、TVC、产品大片、AI 视频 | 改变一条现实规则，让产品/主题成为触发原因 |
| 任务推进 | SaaS、工具、企业服务、教程 | 一个动作带来一个反馈，观众能跟着完成判断 |

角度先于脚本。先定“从哪里看这件事”，再写台词、镜头和 prompt：

| 角度 | 适用 | 执行重点 |
|---|---|---|
| 痛点解决 | 转化、工具、个护、家电 | 开场给真实问题，证明要具体，结尾给单一行动 |
| 结果前置 | 短视频广告、爆款剪辑 | 先给变化后补过程，避免结果和产品因果断裂 |
| 第一人称体验 | UGC、旅行、运动、游戏、空间 | 镜头和声音要像身体在场，不能只写旁观描述 |
| 物品视角 | 产品广告、包装、餐饮、家居 | 让产品/包装/空间成为见证者，最后回到真实主体 |
| 专家/创始人 POV | B2B、教育、科技、专业服务 | 可信表达优先，视觉创意辅助解释，不伪造资质 |
| 生活方式切片 | 品牌、香氛、服饰、食品 | 场景和人物选择要传递气质，卖点融入动作 |
| 反常事件 | 概念片、TVC、停滑广告 | 反常必须有规则，不能只靠随机奇观 |

钩子要同时回答三件事：谁被打中、看见什么、为什么继续看。不要把钩子写成一句空泛标题；要落成首镜动作、首句台词、首个声音或首个画面规则。

## 叙事节奏与重点

叙事节奏不是固定快慢，而是观众感受到的推进方式。每条视频必须先确定一个主叙事曲线，再让镜头长度、切换频率、运镜强度、音乐、台词密度和留白共同服务它。

| 曲线 | 适用 | 节奏写法 |
|---|---|---|
| 快速证明 | 产品广告、工具、短视频转化 | 1-3 秒给问题或结果，随后每个镜头只证明一个点 |
| 逐级升级 | TVC、产品大片、概念片 | 每段视觉强度、声音层次或空间规模上升，结尾收束 |
| 先慢后快 | 发布、开箱、揭示、仪式感产品 | 前段建立期待，中段触发，后段加速兑现 |
| 快后留白 | 停滑广告、情绪片、品牌记忆 | 前段抓住注意力，尾段让主张、产品或 logo 稳定停留 |
| 平行碰撞 | 对比、前后变化、多受众 | 两套状态交替推进，必须在结尾合流 |
| 循环回环 | 品牌片、概念片、音乐卡点 | 结尾回到开场物件、动作、声音或颜色，但意义变化 |

节奏规则：

- 快慢选择由目标决定，不由类型名决定。同是品牌片，可以热血发布、温暖叙事或克制高端；同是产品广告，可以强转化快节奏，也可以用材质、仪式和留白建立价格感。
- 镜头密度和信息密度要分开判断。可以快剪但信息少，也可以慢镜但证明强；不能把快剪当创意，或把慢镜当高级。
- 镜头数量和剪辑成立也要分开判断。每次切镜必须有叙事理由，并让下一镜继承动作、视线、方向、构图、颜色、声音、文字、遮挡、道具或状态中的至少一个锚点；直切/硬切不豁免。若只为了换景别、换人物、换场景或增加镜头数，应删除、合并或改为镜内调度。
- 15 秒及以内视频里，单镜超过 `2` 秒必须持续增加动作、观看关系和信息状态；慢推、拉远、主体渐大、环绕、发光、悬浮或人物微动只能作为辅助，不能单独支撑 `2-8` 秒长镜。慢节奏可以降低切镜频率，但不能降低事件密度。
- 相同动作、表情、构图或结果再次出现时，必须带来升级、反应、对照、答案或新意义。结尾回到开场只有在主体状态、人物关系、空间秩序或观众理解已经改变时才叫回环，否则是重复画面。
- 每个醒目人物、物品、场景和 B-roll 必须服务核心表达、证据、关系、情绪、转场或回收。无法回答“为什么此刻看它”的插镜即使好看也要删除，不能用无关道具或随机人物制造表面丰富。
- 视觉高光必须形成“铺垫/触发 -> 变化 -> 反馈 -> 结果停留”。异常物体、飞出动作、人物惊讶或空间变化不能凭空发生，也不能刚出现就切走。
- 声音不是贴底音乐。BGM、环境声、拟音、静默和人声要参与推进：加速、停顿、声音桥、短暂静默或品牌声标都应落在叙事节点上。
- 高光要有前置铺垫。没有前置的爆点只是特效展示；没有回收的反转只是随机变化。
- 结尾要留出识别时间。产品、Logo、CTA、人物表情、关键画面或主题句至少有一个稳定落点。

## 传播目标与受众张力

一条视频只保留一个主传播目标，一个核心受众判断，一个主行动结果。辅助目标只能服务主线。

| 目标 | 观众状态 | 核心兑现 |
|---|---|---|
| 停滑 | 无意刷到，随时划走 | 前 1-3 秒给问题、结果、人物动作、产品线索、声音钩子或反常画面 |
| 种草 | 有兴趣但未决策 | 让观众靠近一种生活、体感、审美或身份状态 |
| 解释 | 想理解机制 | 用清楚路径、步骤、UI、结构或流程把复杂内容变简单 |
| 证明 | 需要相信 | 给出可见证据，不只靠旁白和形容词 |
| 转化 | 临门一脚 | 产品清楚、利益明确、CTA 单一，事实必须确认 |
| 品牌记忆 | 愿意被情绪带入 | 一个主张、一个母题、一个资产回收 |
| 招商信任 | 主动评估合作 | 企业身份、证据链、流程和风险可控优先 |
| 教学 | 想学会 | 每步一个动作，一个反馈，一个完成标准 |

钩子必须服务后续证明。不要用无法兑现的“震惊”“爆火”“全网都在”等空泛停滑词。CTA 只保留一个主动作，购买、下载、预约、咨询、关注和了解更多不能同时堆满。

## 按需结果转译

只有核心价值仍是“高级、清爽、专业、治愈、效率”等抽象词，无法直接形成可拍动作时，才使用结果转译。产品广告写“产品造成的结果”；品牌、企业、文旅、知识、公益和通用创意写“主题造成的结果”。转译完成后只把触发、可见变化、证明与回收写回导演总控卡和分镜，不保留独立卡。

```text
原始卖点/主题价值：
观众在乎的心理：
现实异常结果：
物理化载体：
触发动作：
扩散路径：
旁观者/空间/物体反应：
证明锚点：
结尾回收：
风险边界：
```

异常结果必须同时满足四点：观众一眼觉得不对劲；它能由当前产品、人物、品牌或主题触发；它能证明一个真实主张或情绪价值；结尾能回收到真实资产或明确结果。只写“更高级、更诱人、更水润、更高效”不算结果。

常用转译方向：

| 抽象价值 | 可视化结果 |
|---|---|
| 保湿/滋润 | 干燥纹理像河床被水光填满，最后回到真实取用、涂抹和自然光泽 |
| 控油/清爽 | 过亮反光被逐格收束成柔和哑光，最后回到真实妆面或手背状态 |
| 酥脆/爆汁 | 任选或组合以下并列方向：咬下声波向环境扩散并让空间按节拍响应；碎屑弹起后重组成新造型或品牌符号；断面暴露的瞬间沿裂纹结晶、拉丝、爆汁生长；咀嚼节拍直接驱动画面剪辑和场景切换；咬合一刻主体所在世界短暂转成同款酥脆材质。最后都回到断面、拟音和包装 |
| 香气/氛围 | 看不见的气味变成颜色轨迹、记忆房间或布料波动，最后回到喷洒、杯口或人物靠近 |
| 续航/稳定 | 时间、天气或任务流持续推进，但设备状态稳定，最后回到屏幕、电量或使用场景 |
| 速度/效率 | 空间被拉长、路径缩短、任务卡片归队，最后回到真实操作结果 |
| 清洁/秩序 | 灰尘退潮、杂物归位、混乱空间恢复边界，最后回到清洁或收纳动作 |
| 静音/降噪 | 噪声变成颗粒后被切断、吸收或落下，人物和环境从紧张变安静 |
| 从容/掌控 | 外部世界越混乱，主体动作越稳定，最后回到人物气质、产品稳定性或品牌姿态 |
| 艺术/文化生命力 | 静态作品、展品、建筑细节或传统符号开始行动，最后回到空间身份、活动主题或文化主张 |
| 融合/跨界 | 两种风格、声音、文化或使用场景先冲突再对齐，最后形成第三种统一结果 |
| 专业/可读 | 主体被拆成参数、结构、步骤或多视图，最后定格成可理解、可比较、可复用的图纸或界面 |
| 上头/吸引 | 文字、几何、声音和运动形成无法摆脱的循环、反相、裁切或节拍牵引，最后回到关键词或主题句 |

夸张结果可以作为创意隐喻，但不能伪装成未经证实的真实功效、医疗结论、安全保证、销量背书或竞品比较。

本文件与所有参考文件里的对照表——包括“价值/卖点 -> 可视化”“概念 -> 画面”“品类 -> 玩法”“世界规则/机制/视觉发动机”等——都是示例方向库，不是唯一正确答案的查表；同一个价值、概念或品类都可以有多种成立的转译和机制。规划时必须在该行列出的并列方向里，结合本条产品、品牌资产、人物、平台和世界规则主动挑选或重组，而不是每次都取第一条或最眼熟的一条。选机制同理：不要因为品类或卖点就默认锁定同一个机制（例如零食=物理小高潮、清洁=退潮归位、护肤=水光绽放、SaaS=任务卡归队），先看本条真正要证明什么，再在多个机制间选择。判断“这条创意是否和最近同类片子撞车”：如果一个卖点、概念或品类反复只用同一种画面或同一个机制，说明是在套模板，必须换方向，或换触发、扩散、机制与回收方式。批量或同品类多条时，主动在不同方向和机制间轮换。

## 品类套路排雷

结果转译后、机制选择前，必须内部完成品类套路排雷。它不是给用户看的固定表，而是防止模型把最先想到的品类联想误当成创意。

```text
本品类最容易套用的默认画面：
本卖点最容易套用的默认特效：
本素材最容易套用的默认镜头：
本片明确避开的套路：
可保留为细节的感官元素：
候选机制家族 A：
候选机制家族 B：
候选机制家族 C：
最终选择及原因：
```

候选 A/B/C 必须属于不同机制家族：例如视角置换、空间规则、行为反转、文字语义、包装/Logo 机关、流程闯关、材质世界、负空间显形、时间规则、社会反应、产品内部世界、证明流程世界等。不能把“咬下声波”“咬下光波”“咬下粒子扩散”当成三个候选；它们本质上仍是同一个感官扩散机制。默认感官触发只能回答“声音、口感、肤感或速度是什么”，不能单独回答“这条片为什么有新意”。

若选择了品类最直观的触发动作或感官元素，必须通过至少一个维度完成反套路转译：

- 换载体：声音不只是声波，而是改变包装结构、字体排版、空间规则或旁观者行为。
- 换视角：从产品、包装、食材、液滴、文字、界面节点或环境物体的视角看结果。
- 换任务：让创意承担证明、选择、比较、记忆或行动引导，而不是只制造爽感。
- 换时间：把瞬间感官拆成预备、触发、后果、回收，而不是一个爆点后结束。
- 换回收：最终落回当前品牌资产、产品结构、卖点证据或用户行动，不落回通用漂亮画面。

禁止把以下内容当作主创意的默认答案：食品只做咬下碎裂/声波/爆浆；饮品只做冰块飞溅/水花慢动作；护肤只做水光、花朵、蓝光蔓延；汽车只做雪山、灯带、光轨和漂移；香氛只做花瓣、烟雾和光晕；软件只做数据卡片自动归位；清洁只做污渍退潮。它们可以作为局部真实细节或辅助感官，但主玩法必须进一步绑定当前产品、品牌、场景、卖点和叙事因果。

## 机制选择器

有了结果转译，再选创意机制。机制不是品类限制，任何品类都能使用；区别在于触发动作、体验外化、场景响应、证明锚点和回收方式。

### 世界规则

世界规则是创意机制之前的独立判断点。风格回答“看起来像什么”，世界规则回答“这个片子里的现实如何运转”。没有世界规则时，乐高、黏土、像素、CG、鱼眼、子弹时间、花瓣、微缩场景和 UI 动效都只会变成装饰；有世界规则时，产品亮点、人物口播、品牌主张和视觉效果会共享同一套因果。

每条片先选 1 条主世界规则，最多 1 条辅助规则。世界规则必须写清：

- 规则源：由产品动作、人物动作、声音、按钮、包装、屏幕、道具、空间或一句口播触发。
- 规则范围：影响产品内部、桌面、房间、城市、屏幕、微缩世界、时间、重力、材质、文字还是角色行为。
- 规则证明：它具体证明哪个卖点、品牌态度、流程价值或人物判断。
- 规则回收：结尾如何回到真实产品、真实人物、真实界面、品牌资产、结果状态或 CTA。
- 规则边界：不能伪造功效、参数、医学/金融/安全结论、真实优惠、销量背书或竞品比较。

| 世界规则类型 | 适合 | 可执行写法 |
|---|---|---|
| 产品内藏世界 | 手表、香水、饮品、食品、包装、屏幕、汽车、耳机 | 产品结构成为入口，内部世界承载场景、感官或功能；镜头进入和退出都要回到真实产品结构 |
| 微缩沙盘世界 | 家居、收纳、城市、本地生活、工具流程、复杂服务 | 桌面、表盘、瓶盖、屏幕或包装上出现微缩场景；每个微缩动作对应一个真实步骤或卖点 |
| 风格化动画世界 | 乐高积木、黏土定格、像素游戏、纸模、漫画分格、玩具模型 | 风格本身变成规则，例如拼装、修复、通关、升级、展开、折叠；不能只把产品卡通化 |
| 时间规则 | 运动装备、3C、耳机、时尚、发布感产品 | 加速、冻结、倒放、子弹时间或节拍恢复必须服务产品展示、材质证明或人物状态变化 |
| 物理规则 | 悬浮、坠落、吸回、膨胀、折叠、喷雾、粒子、花瓣、液体 | 每个物理异常都要有触发点、受力方向、速度/阻力、落点和证明职责 |
| 口播第四面墙 | 数字人、AI 工具、幕后、创作者、服务说明 | 说话者承认视频生成、分身、幕后或拍摄关系，用幽默或自揭建立信任，最后回到产品/工具价值 |
| 证明流程世界 | 测评、清洁、收纳、穿搭、食品、工具 | 世界按“发现问题 -> 真实操作 -> 结果对照 -> 边界说明”运行，创意只强化证据，不遮挡证据 |
| 奢华陈列世界 | 香水、美妆、珠宝、高端消费品 | 花材、织物、喷雾、反光和慢节奏围绕材质、香气或仪式感运转；所有运动克制且物理可信 |
| 任务闯关世界 | App、SaaS、课程、效率工具、年轻化消费品 | 使用流程被写成关卡、解锁、计分、奖励或失败回弹；每关必须对应真实操作或产品价值 |
| 角色代理世界 | 产品、食材、数据、灰尘、毛发、衣服、任务卡获得简单动机 | 被处理对象像角色一样行动，但产品必须是规则源或解决者，不让拟人化抢走卖点 |

从参考视频迁移时，只迁移世界规则，不复制对方的产品、品牌、角色、台词、符号和完整桥段。例如“表盘里切换雪山/丛林/峡谷”可迁移为“产品内部按场景切换证明多场景能力”；“耳机子弹时间 360 展示”可迁移为“时间冻结让产品材质和结构被看清”；“香水花瓣与喷雾”可迁移为“物理可信的气味/材质外化”；“AI 分身口播”可迁移为“第四面墙解释工具价值”。

| 机制 | 使用方法 | 适配时必须改写 |
|---|---|---|
| 物理规则篡改 | 悬浮、倒流、冻结、重力反转、材质变形 | 哪条规则被改、谁触发、改变后证明什么 |
| 尺度错位 | 人进入产品世界、产品放大成空间、世界微缩 | 尺度变化必须揭示结构、质地、体验或场景 |
| 视角置换 | 用产品、宠物、灰尘、液滴、食材、UI 节点看世界 | 新视角要带来新信息，并最终回到真实主体 |
| 虚实融合 | 真实场景里长出 UI、动画、数据、手绘线或游戏界面 | 虚拟层必须解释真实动作或体验，不能遮挡证明 |
| 线索贯穿 | 一个物体、声音、颜色、动作或符号穿过多场景 | 线索每次出现都推进信息，结尾落回品牌/产品/主题 |
| 逐级升级 | 异常效果或旁观反应一层比一层强 | 每级必须有新证明或新情绪 |
| 反差美学 | 高级/粗粝、日常/史诗、优雅/荒诞并置 | 反差要服务定位和记忆，不损害可信度 |
| 互动式展示 | 手、光标、门、盒盖、擦拭、拖拽等动作改变画面 | 互动动作必须产生可见结果，并和真实操作或主题有关 |
| 导览引路 | 角色、光点、票据、数据卡、声音或手势带观众穿过空间/流程 | 每一站都要触发新信息，结尾回到空间身份、流程结果或主题 |
| 静物活化 | 展品、包装、文字、UI、图标、数据或工具获得动作身份 | 先保留识别点，再突破边界；动作必须解释主题或证明点 |
| 多源融合 | 两个以上参考、风格、声音或场景叠加成新结果 | 先分别建立 A/B 特征，再写冲突、对齐、融合和收束 |
| 数据标注化 | 主体被视作图纸、参数、三视图、结构层或仪表盘 | 标注必须少而准；真实数值没有材料时只能概念化 |
| 文字语义可视化 | 文字运动方式直接表达含义、节拍或态度 | 关键词、字体、颜色、反相、裁切和留白要有统一规则 |
| 框架穿越 | 框、门、屏、洞口、包装或输入框成为空间入口 | 穿过后必须出现新信息；最后回到真实边界或资产 |

## 平台语境

平台不是发布参数，而是创意策略。规划时先判断观众在哪里看、是否静音、是否主动了解、是否需要转化，以及画幅安全区。

| 场景 | 开场策略 | 主体登场 | 节奏倾向 |
|---|---|---|---|
| 信息流 UGC | 真人、问题、结果或动作直接停滑 | 人先于产品，产品在证明开始处进入 | 近景、真实停顿、信息密度高 |
| 转化型产品广告 | 痛点、材质、声音、局部轮廓或结果前置 | 产品早出现并反复锚定 | 清楚、可证明、快慢结合 |
| 高端产品大片 | 材质、光线、空间和声音建立价格感 | 可延迟揭示，但前段有产品线索 | 克制、微距、呼吸感 |
| 品牌 TVC | 产品气质、理想状态、人物和世界 | 品牌/产品中后段成为主角，尾帧稳定 | 母题化、情绪曲线 |
| 企业商务片 | 行业场景、问题或可信环境 | 企业身份早说明，产品/服务随证明进入 | 稳重、证据优先 |
| 官网/产品 launch | 使用场景、结果状态或核心交互 | 产品/UI 是主角，以任务流登场 | 干净、聚焦、可理解 |
| 会议大屏/发布会 | 空间、声音、节奏和主题能量聚场 | 品牌/主题逐步显影 | 大景别、音乐递进、尾帧停留 |

不能把一种场景的开场套到所有视频：TVC 不默认第一秒产品正面怼脸，UGC 不默认漫长空镜，企业片不默认抽象光效，转化广告不默认只讲品牌理念。

常见平台专项：

| 平台/场景 | 观众状态 | 创意重心 | 节奏写法 | 尾帧倾向 |
|---|---|---|---|---|
| 抖音/快手信息流 | 快速滑动、强竞争、常静音 | 前 1 秒给异常、结果、口播判断或动作冲突 | 0-3 秒不空，3-10 秒证明，最后 1-2 秒 CTA；画面文字短而有反应 | 产品/人脸/结果 + 单一行动 |
| 小红书 | 主动种草、看审美和可信生活感 | 截图感、真实体验、生活方式和细节质感 | 不必全程高能，但首屏要有“值得收藏/想靠近”的画面；镜头干净，文字像笔记而非硬广 | 产品在真实场景中稳定，保留可截图画面 |
| TikTok/Reels/Shorts | 跨语言、强节奏、动作先行 | 视觉钩子、节拍、反转、挑战感或可复制动作 | 更依赖动作、声音和大画面关系，减少长中文信息；反常识一拍要早 | 视觉记忆点 + 品牌/产品短字 |
| B 站/中长视频 | 主动观看、接受铺垫和解释 | 观点、过程、幕后、知识密度或故事完整性 | 可以章节化，但每段都要有新信息；不每 15 秒重启一次 hook | 结论、作品/结果、关注或下一集入口 |
| 官网/落地页 | 主动了解、需要理解产品价值 | 产品结构、任务流、使用场景、可信结果 | 清楚、克制、可暂停截图；避免信息流式夸张吆喝 | 产品/UI/核心结果 + 预约/了解更多 |
| 电商主图/商品卡 | 决策近、看清商品 | 商品身份、材质、规格、用法和结果 | 快速进入产品，少故事，多证明；每个卖点对应一个可见动作 | 正面 packshot、核心卖点短字、活动/购买入口 |
| 会议大屏/发布会 | 远距离观看、需要气势和统一节奏 | 空间能量、品牌主张、阶段揭幕、群体情绪 | 大景别、大字少字、音乐递进；关键信息停留更久 | 主题字、品牌、发布信息稳定可读 |
| 广告投放素材 | 目标明确、审核严格、需转化 | 单一利益、强证据、清楚 CTA | 避免复杂隐喻遮挡卖点；前后状态和产品露出要稳 | 产品 + 核心利益 + CTA，事实可追溯 |

同一个创意母版改平台时，先改“观看关系”，再改比例：

```text
平台观看状态
  -> 首 3 秒承诺
  -> 字幕/画面文字密度
  -> 主体露出频率
  -> 镜头停留和安全区
  -> 尾帧行动
```

## 尾帧与收束专项

很多视频“不知所以然”不是中段没有创意，而是结尾没有把创意归还给核心表达。尾帧不是附加 logo，也不是最后再塞一个新卖点；它要回答观众最后一秒的三个问题：这是给谁看的、刚才证明了什么、下一步是什么。

尾帧选择：

| 类型 | 必须回收 | 好尾帧 | 坏尾帧 |
|---|---|---|---|
| 产品广告 | 产品身份、主卖点结果、购买/了解动作 | 产品清晰正面或使用结果稳定，短字只写一个核心利益 | 最后一秒新增多个卖点、产品太小、只有抽象氛围 |
| UGC 口播 | 人设判断、行动理由、产品/链接/关注 | 人或手持产品稳定，口播落在一句人话 CTA | 口播还在铺垫，突然切 logo 或大促字 |
| 品牌 TVC | 品牌主张、视觉母题、情绪残留 | 母题回到品牌资产，主张短句稳定可读 | 情绪很美但不知道品牌想说什么 |
| 企业商务 | 企业身份、可信结论、合作入口 | 企业名称/业务结果/可信证据简洁落定 | 抽象口号、无事实、无服务指向 |
| 通用创意 | 主题、人物/场景状态、记忆画面 | 开场符号以新意义回归，画面有留白 | 只停在漂亮画面，没有主题变化 |
| 活动/发布预热 | 时间地点、预约/发布信息、悬念资产 | 主视觉 + 发布信息 + 一个行动入口 | 悬念过度，看不清时间和主体 |

尾帧写法：

```text
尾帧主体：[产品/品牌/人物/企业/主题字]
尾帧状态：[刚才变化后的结果]
尾帧文字：[一句核心回收或一个 CTA]
声音落点：[音乐停顿/声标/拟音归位/人声最后一句]
停留时间：[短片至少可感知稳定，长片按平台留足阅读]
不再新增：[新的卖点/新角色/新场景/新事实]
```

收束检查：

- 如果尾帧去掉产品/品牌仍然像一张通用海报，重写。
- 如果尾帧出现的信息前面没有铺垫，删掉或移到前段证明。
- 如果尾帧只剩 CTA 但没有行动理由，回到前一镜补结果状态。
- 如果尾帧只剩漂亮画面但无主张，增加短主题字或让母题回到品牌资产。

## 事实与素材边界

真实产品、真实 UI、真实 Logo、真实人物、真实数据、客户案例、优惠价格、奖项资质、功效声明和活动信息必须来自用户素材、可靠来源或用户明确确认。缺失资料不阻止创意规划，但只能作为可修改假设，不能写成确定事实或进入生成输入。

只有用户上传或提供视频、链接、片段、截图、广告案例、moodboard 或竞品资料，并明确要求“参考、借鉴、分析、迁移、类似效果、同类风格”时，才启用参考迁移分析。普通第一轮 brief 不主动要求参考视频，也不因为缺少参考视频而停止规划。

参考内容里的视觉创意、叙事骨架、玩法触发与回收、运镜结果、剪辑节奏、光线方向、构图方式、色彩段落、转场锚点、声音结构、文案节奏、花字职责、卖点排序和露出逻辑，都要重新绑定到当前主体、当前事实和当前核心表达上。

迁移参考时先判断元素在原片中的职责，再替换成当前项目能成立的表达：

- 人物不只是脸，也可能是口播者、反应者、见证者、图形身份、CTA 发起者或可信边界的承担者。
- 产品不只是道具，也可能是证据、演示对象、UI、触发动作、状态改变原因或结尾回收点。
- 风格不只是滤镜，而是镜头、画面文字、图形、音效、表演、节奏和转场共同形成的系统。

参考片的开场要拆成“它如何抓注意力”：人物反应、问题瞬间、结果前置、声音先行、异常规则、图形状态或产品局部。视觉系统要拆成生命周期：第一次出现建立规则，中段重复或升级，结尾退出或回收。任何可复用的符号、颜色、声音、图形、手势、UI 状态或空间规则，每次再次出现都必须带来新信息，不能只作为装饰反复闪现。

分析参考视频时，内部按以下结构提炼，不在用户可见正文里机械展示全部字段：

```text
可迁移关系：
不可迁移表面：
A-roll / 主表演：
B-roll / 辅助画面：
MG / 图形和文字系统：
声音和剪辑交接：
开场、重复、变化、退出：
改写到当前项目的方式：
```

常见表达结构可以作为创意骨架，但不作为固定分类：

| 结构 | 适合场景 | 迁移方式 |
|---|---|---|
| UGC / talking head | 口播、带货、观点、创始人解释 | 稳定人物视角 + 自然跳切 + 画面文字/图形标签/MG/B-roll 辅助证明 |
| Presenter-led explainer | SaaS、工具、企业服务、复杂概念 | 讲解者带着图形、演示和比较对象一起推进 |
| Narration-led demo | 产品演示、教程、功能说明、视觉散文 | 旁白作为脊椎，产品、手部、屏幕、MG、B-roll 作为视觉答案 |
| Ranking/listicle | 排行、清单、对比、测评 | 排名板或比较表记住前面判断，每一项用态度、图标和证据镜头推进 |
| Street interview / podcast / two-person | 采访、播客、街采、观点碰撞 | 用视线轴、反应镜头、角色颜色、说话人标签和声音交接建立关系 |

## 创意变体

用户要多条广告或测试方向时，变体必须在实质维度上不同，不能只换几个词：

- Hook：痛点、反差、结果、提问、动作、证明、误区、比较、场景。
- 角度：测评、问题解决、教程、开箱、对比、生活方式、专家/创始人 POV。
- 开场画面：人脸口播、手部动作、产品局部、结果前置、场景冲突、声音先行。
- 证明点：材质、功能、前后状态、案例、流程、数据、使用动作。
- 受众：新手、进阶、价格敏感、品质敏感、礼赠、企业客户、候选人、投资人。
- CTA：收藏、了解、预约、试用、直播间、官网、下载、到店、报名。
- 节奏和声音：快剪、舒缓讲解、纪实、电影感、信息密集、少词高端。

每个变体都必须可拍、可执行、可交付，并遵守事实和授权边界。

## 方法来源与适配边界

这些策略来自通用广告创意、短视频信息流、产品发布、品牌 TVC、AI 视频运动语法、UGC 表达和企业商务传播的共同方法。任何参考文件、参考视频或工具案例都要被改写成当前项目的“功能”：它负责停滑、证明、解释、情绪、记忆、转化还是信任。只有当这个功能被当前主体、素材、事实边界和类型策略重新承载后，才能进入脚本、分镜和 PE。

模型选择、会员逻辑、时长、比例、生成批次、参数确认、字幕规则、委派 agent、PE 格式、分镜数量和阶段确认，以 `SKILL.md`、`production-control.md` 和 `references/interaction-ask-video-clarification-ref.md` 为准；本文件只补创意和策略判断，不覆盖执行规则。
