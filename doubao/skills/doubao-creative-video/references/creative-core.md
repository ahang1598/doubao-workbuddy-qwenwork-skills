# 第一阶段：把内容、文案与关键声画写成同一套方案

本文件是所有视频任务统一使用的创作流程。先按主入口选当前任务文件；类型文件只讲不同用途怎样取材与表达，本文件只讲共同写作方法。第一阶段完成 **按需研究 → 连写完整内容、文案与关键声画**，不增问卷、卡片、研究报告或审批。以下具体方法用于正常写作；

## 第一阶段：创作方案

### 用户说得少时，主动展开内容

简短需求是创作起点。广告、UGC、TVC、企业与空间介绍需要在用户意图内补齐值得看的内容，不能把“介绍一下”落实成产品转一圈、房间平移一遍、人物拿着商品说一句好用。用户只上传一张图或指令很短，不等于只要求轻动态；按实际观看目的选类型。内容补充、逐镜展开与完整 Prompt 均在生成确认前完成，展示从该母版提炼；确认后只执行既定方案和绑定计划内真实依赖，不趁生成时另加卖点或更换事件。用户逐字台词、指定动作、局部保留、仅让原图轻动等锁定项优先，不把开放创作规则套到这些任务上。

从已有事实和实际可见材料中找能展开的东西：观众在什么场景需要它、要判断什么、看哪个细节、这个结构怎样使用、动作后得到什么反馈、什么条件影响选择。由这些关系写出中段的发展，既要有主要记忆点，也要有支持它的不同内容。不是先列机位再往里填商品；也不是把一个拿放动作拆成伸手、接触、抬起三项就算充实。用户未提供卖点时，先从材料提炼可支持的设计特点与使用意义，不自动只留外观。

| 可主动补充的内容 | 怎样落到画面、人声或声音 | 事实边界 |
|---|---|---|
| 真实外观与结构的不同观察 | 整体识别后看确实存在的局部，说明它在当前使用中的作用 | 图片能支持颜色、形状、可见纹理；不能据此认定材质成分、尺寸、耐热、承重或功效 |
| 围绕同一任务的相关演示 | 操作前状态、关键接触、结果、取用或后续使用相互承接；保留真正有判断价值的阶段 | 用法须与已知结构及说明一致；不暗示未经确认的自动化、性能或极限条件 |
| 观众做选择需要的信息 | 具体对象、使用位置、依据、适用条件或取舍；画面示范，人声解释为什么关注 | 不发明优惠、体验史、用户证言、认证和数据；品类常识不自动等于本品能力 |
| 产品、人物与环境的关系 | 手与材质接触、空间中真实摆放、人物基于眼前结果回应，环境声确认动作 | 不让真实产品凭空变形、活动或获得新功能；超现实设定须符合用户本次创意方向 |
| 感官、情绪与视觉的进一步发现 | 同一材料在不同接触下的可辨声音或质感、人物选择造成的变化、线索在后文得到回收 | 感受不能冒充客观性能；相关内容不足时换取材角度，不以随机空镜、粒子和口号填充 |

规划时具体写出：这一处比上一处多交付什么，观众为什么现在需要它，下一处怎样接住。几处内容只重复“漂亮、方便、很有质感”时，应补相关的具体观察、解释、示范、条件或回应。事实边界约束声明，不能变成“没资料就只能慢推”的理由；已有事实可从使用、比较维度、空间关系和感官层次充分展开。确实无法支持的产品事实不写，改用有依据的内容，不要求用户补一轮创意问卷。

**内容必须在实际声画里发生。** “快切蒙太奇、信息丰富、展示多种用途”仍是待写内容。把实际物件、动作、关键状态及完整拟用台词展开；不只在导演说明里宣称丰富。广告给理由与依据，UGC 让一个完整判断随演示展开，TVC 让主题经行为或视觉发展获得新含义，企业片让同一业务对象经过有据可循的环节，空间片让观众形成对布局与使用的具体认识。不能把理解与承接解释为减少内容，也不能只靠增加切镜完成密度。

**在确认前把内容充实落实到母版与 Prompt。** 沿同一主线写清每一处让观众新增看清、理解或感受到什么，以及它与前后内容的关系；再把实际动作、证据、发现、选择、回应、条件或视觉／声音发展落实到分镜和完整 Prompt。连续几处只是在重复同一特点或感官印象、换角度、推拉旋转或一句口号时，先补相关内容的发展，再安排镜头，不用拆分同一次动作凑数。营销任务保留有依据的产品身份、具体特点和使用意义；没有事实依据时，从可见设计、概念情境或有发展的感官机制展开，不虚构性能、水源、体验或资质，也不退成慢速空镜。按既定密度补足全程及分布，理解与承接仍是有效变化的前提；不以补丰富度为由强加用户未要求的营销剧情、声音或改动锁定项。用户侧可以精简叙述，内部母版与提交 Prompt 不随展示一起缩水。以上融入原有写作，不另交计数表、评分表或新增审片步骤。

**内容决定运镜和转场。** 看清接触与结构可用固定近景、侧拍或移焦；揭示前后景关系才用移动和拉开；让观众比较同一部位就保持相近构图；动作完成后看结果可用动作接切；跨空间延续同一解释可用人声或环境声先行。写出移动终点新增看见什么、切点由什么触发、后镜接哪项信息。直切可以清楚有力；环绕、甩镜、遮挡和匹配转场只有在新内容需要时才用，不轮流堆手法。人声解释原因、条件或选择，拟音确认真实动作，音乐发展跟随内容进展；不要把“丰富”全部交给旁白、满屏字幕或强节拍。

下述内容要求适用于所有任务；实际制作工作按需要展开，不降低内容标准，展示与授权时机按生产控制执行。

先分清两件事：“商品详情页”是观众看视频的地方，“家门口”是故事发生的地方。写法取决于观众的具体任务与观看条件，不能只凭故事发生在哪里判断：

- **观众已经知道什么？** 在商品页看包的人通常已经认出商品，不必再花几秒揭晓它是什么。
- **他现在想知道什么？** 想选购，就给判断依据；想学操作，就教关键步骤和核对方法；刷到陌生内容，先给他愿意继续看的具体事情。
- **谁在对谁说？** 顾问介绍、朋友分享、角色交谈和品牌旁白，用词与说话原因不同，不能只换人称。

从需求和已有材料判断；没有指定展示位置时，选择符合任务的写法，并说明这是本次假设。不发问卷，不只凭平台名猜所有观众的想法。静音、小屏、远距离或中途进入会影响理解时，让这些观看条件实际改变内容与声画安排，不默认每条都有人从头专心看到尾。

确定本片主要让观众明白、学会、相信或感受到什么，再据此分配内容主次，不把所有资料平均展示。用户要求多项内容时保留全部锁定项，安排重点与辅助信息；普通资料中的功能不自动成为必讲清单。这是取舍依据，不另交一张目标卡，也不先把它写成口号。

**营销内容从推广对象取材，再选择表现方式。** 先从已有资料确定本次要让谁在意哪件产品、服务或哪个品牌的什么，再据此选具体内容。把资料里的特点写成观众能理解的价值：它具体是什么或怎样工作，在当前场景有什么用、感受或取舍，片中用什么演示、细节、条件或事实支持。普通操作只说明怎样用；营销演示还要让人明白为何值得注意或选择，不能用开合、拿放和一句“方便”代替产品介绍。把好处归给实际产生它的特点或用法，说明二者怎样关联；不能把人物换了摆放位置带来的结果说成产品性能，也不能把先后出现的镜头当成因果。不要求独占技术或虚构竞品缺点；已有的结构、口味、设计或服务方式也能构成有依据的理由。剧情、幽默、演示、比较、感官、音乐和视觉创意都可采用；不能先找一段好玩的生活情节，再挑产品充当道具。正式任务不编商品事实；资料不足时先补查已有来源，或收窄到可支持的表达。离线测试可明确给定虚构商品事实，但不为迁就故事临时添加功能或品牌理念。上述决定合入现有方案，不另填卡片或增加审批。

**产品露出、产品参与和产品被理解是三件事。** 只凭成片中的画面、人声与可读文字，陌生观众应知道推广的是哪件产品或服务、它的品类及本次要记住的特点；已知商品名、型号或品牌按本片需要清楚交代，不能只写在方案标题、素材说明或 Prompt 里。营销口播应在自然的表达中说明谈论的产品或品类、自己的具体判断及理由，不整段只说“它、这个、这里”，也不因避免广告腔就删除产品信息。视觉、感官或品牌主导的片可以让产品形态、包装、实际服务与识别资产承担相应信息，不强制每句报品牌。有包装、有使用动作、能触发笑点，都不自动等于完成推广。看实际内容是否让观众理解或感受到本次要介绍的特点，以及它值得当前人群在意的原因；不要求这些意思都靠台词直说。情节的等待、转折和结果应帮助认识商品，而不是让商品只负责开启一段与它无关的互动。感官片可以让口味、质地或声音成为主要吸引力；品牌片可以形成态度、审美和身份联想，但应来自已确认的品牌定位、资产或行为，不能因故事温暖就推定适合这个品牌。无需每条证明功能、比较竞品或劝购。

**先选具体用途，再按该用途写内容。** 用途来自用户要达到的目的，不从自己已经写出的情节倒推分类；营销片采用教程、知识或生活片段时，仍须完成本次产品/品牌传播，不能换成普通操作练习来回避购买理由与产品介绍。用户明确要纯教程或记录时保留其目标。先读当前类型文件中匹配用途的写法；下面只用于识别需要完成什么，不是每条都套同一顺序，也不另交一张分类表。用途与形式可以组合：TVC 可以卖货，UGC 可以教学；按用户本次要求确定内容主次，不把名称当成互斥类别。用途不同，主要取材、语言作用和篇幅重点就应不同，不能只换场景、人物与片尾名称。

| 本次用途 | 先落实什么内容 | 不能据此认定已完成 |
|---|---|---|
| 商品销售、带货、信息流转化 | 目标人群的具体需要、产品的购买理由及依据、影响选择的必要条件；优惠与行动按实际任务安排 | 一段生活互动加包装，或演示一个动作后只在结尾补卖点 |
| 品牌或产品 TVC | 明确传播重点，用适合本片的剧情、产品呈现或视听创意形成品牌或产品记忆 | 只有剧情或视听形式，观众无法把看点与推广主体联系起来 |
| UGC 营销口播 | 创作者向具体人群表达的推荐、取舍或品牌观点，为什么这样说，哪些观察、解释或演示支持 | 第一人称说明书，或只讲相关知识却没有完成本次推荐或品牌表达；教学本身可以是营销方式 |
| 教学、知识、操作讲解 | 要教会的具体内容，解释、完整例子、操作与核对方法 | 只报步骤名，或把推广产品当成教会方法 |
| 企业介绍、能力或客户案例 | 当前企业任务所需的定位、业务事实、具体做法与可信依据，按材料组织重点 | 泛化职场困难、假成功故事或公司形象空镜 |
| 活动、招聘等参与决策 | 为什么值得参与或适合加入，已确认的内容、条件与必要行动信息 | 通用品牌宣言，或无事实支持的热闹、感动和向往 |
| 音乐、风格、空间与简单动态 | 用户要求的观看体验、声音与画面变化、主体动作或视觉规则 | 强加产品证明、购买理由或人物冲突 |

人物剧情只是可选表达方式。有合适的叙事任务、真实处境与足够内容时再用；它需要服务本片用途，不能成为所有视频的默认外壳。创意也可以直接发生在论述、演示、比较、产品呈现、声音与视觉组织中，不需要另编一件生活小事。采用哪种方式，就把它充分展开：演示让关键差异可判断，宣言让论点逐步展开，喜剧让期待与回应成立，感官片让声音和材质产生可辨变化。不要用一点剧情、一点参数、一点奇观分别占一段，代替一条有特点的完整表达。

**营销片的看点要与推广主体一起被记住。** 在实际内容里安排观众何时认出品牌/商品、何处把它与核心看点联系起来、怎样结束；合入现有剧本，不增露出表。可以产品先出场、使用中识别、旁白提名、包装参与笑点、品牌签名结尾或延迟揭示，不要求开中结都放 logo。品牌色、普通场景和音乐气质本身未必足以指认品牌；延迟揭示后应能理解前面的内容为何属于它。只有最后贴名字、去掉名字后整条与推广对象无关时，先改表达关系。非营销的教程、记录、艺术片与简单动态不套品牌任务。

**开头交付一个具体的观看理由，中段继续兑现并增加值得看的内容，结尾完成本次任务。** 观看理由可以是一个待验证判断、值得听的说法、正在发生的动作、材料与声音的吸引力或有辨识的视觉；不必都设谜或制造冲突。中段接着回答、比较、展开、发现或改变感受，不能靠“接下来更精彩”延迟答案。结尾可完成操作、落到判断、留下回应、交付参与方式、形成品牌签名或接回循环，不强制口号、购买引导或静态落版。有效变化与叙事密度按[视听工艺](audiovisual-craft.md#默认变化与叙事密度)，动作、对白与阅读的时间安排按分镜合同，不把这种内容关系变成固定三段秒数。

构思时就安排足够的证据、动作阶段、发现、反应与结果，使短片能持续推进；密度不足先丰富同一主线，不靠增加无关卖点或反复展示一个结果延长内容。默认节奏利落，以多镜表达组织观看；舒缓或一镜到底仅在用户明确要求时采用，不能从高端、治愈、极简等标签自行推断。

**让继续观看的理由随内容发展。** 开场让人想知道的事情，后面要实际交付；交付之后，可以顺势带出新的条件、选择或感受，不反复吊住同一个答案。例如已看清产品能装下什么，接下来若要继续，就回答取用、摆放或适配上的实际问题，而不是换三个角度再证明“装得下”。人物内容中，前一次行动改变对方能做的选择，下一次回应再改变关系；观点内容中，依据使判断更具体，必要时也可以修正最初看法。音乐、观察与感官内容的发展可来自节律积累、观看距离、触感层次或声音关系，不要求每次变化都增加知识或升级冲突。

**控制观众何时知道什么。** 理解动作、关系和证明所需的前提及时给出；为了发现而暂缓的信息，应留下能跟随的线索。结果前置后要兑现过程，延迟揭示后应使前面的细节获得意义；不能靠隐藏操作条件制造产品优势，也不靠角色突然知道新信息推进故事。悬念不等于一直不让人看清主体，反转也不等于最后补一个此前毫无线索的设定。

**清楚与充实同时设计。** 实际声画应让观众能概括全片在讲什么，并跟上各次变化；多项内容围绕共同任务或明确关系展开，不因强调主线就只剩一个简单动作或一句结论。保留主要观点、卖点、关键依据、必要条件和内容发展，优先通过重排、具体化证据与声画分工提高可理解密度。理解不清、承接缺失的变化不计数；删并无效内容后补足相关发展，数量和变化分布仍按[视听工艺](audiovisual-craft.md#理解承接与内容充实同时成立)，不能以连贯为由默认减信息、减镜头或放慢。

第一阶段写成一套能想象出成片的完整内容方案，完成范围见下表；剧本包含具体画面、人声原文、画面文字与声音安排。内容已讲清全程，就不另抄梗概；复杂故事缺少背景会看不懂时，补短梗概。随后在内部完成第二阶段正式分镜、声音时间轴和完整 Prompt，解决可预先解决的输入与实现问题，再按[方案展示要求](interaction-ask-video-clarification-ref.md#先用普通文本展示完整参数)提炼展示并取得本批生成确认。不能先拿空泛概述取得授权，再希望 OrganizerAgent 或视频模型补足内容；提前准备完整不增加默认文件交付、分镜表展示或阶段审阅。

用户给了完整脚本，只补实际缺口；只改一句话或一个片段，就处理相关部分，不重写全片，也不因此启动一次全片审查。锁定内容保留。简单图片动态直接写动作变化，不扩写复杂剧情。

### 前 3 秒给目标观众一个继续看的理由

写开场时，先想这条片是拍给谁的，以及什么细节会让这个人愿意多看一镜。把答案直接写进方案的第一段：0–3 秒观众看到什么动作或变化，听到哪句话、哪一声响，或者这一刻有意留静；下一镜沿着同一个物件、动作、声音或尚待解释的结果往下讲。纯视觉已经足够吸引人时，可以全程无问句、无开场旁白。

按题材选一种自然的开法。下面是写法示例，拍摄内容随本片替换：

| 题材与观众 | 0–3 秒的画面与声音 | 下一镜如何接 |
|---|---|---|
| 修复教程，给家里也有松动抽屉的人看：先给结果，让人想学做法 | 一只手轻推，原本歪斜的抽屉第一次合得严丝合缝。只听见木头轻轻碰上的一声。 | 同一只手把抽屉拉开，镜头贴近刚调过的导轨螺丝，从这里开始教。 |
| 通勤收纳，给常在闸机前翻包的人看：让人认出自己的麻烦 | 闸机前，一只手在包底摸卡，后面已经响起下一位乘客的脚步声。 | 切包内近景，手指从钥匙串下面抽出卡。接下来展示卡换到外侧袋后，同一个人怎样刷过去。 |
| 悬念短片，给爱观察细节的人看：让一个动作留下疑问 | 空房间里，一枚硬币沿地板滚到柜门前，停了一瞬，又从门缝里被轻轻推回来。只留滚动声。 | 镜头贴地跟住滚回的硬币，一根手指从同一条门缝探出，延续刚才的动作。 |

一镜到底时，让接下来的动作在同一镜内发生；长片分段时，后续片段沿已建立的内容继续。用户指定开场画面、台词或素材时，就从指定内容里找值得继续看的细节。

### 第一阶段确定到什么程度

“第一步”可能是检索，不必在检索前定死写法；下表是第一阶段的完成范围，不是依次填表的步骤。所有任务按适用范围完成。按任务处理适用项，不为凑齐项目增加人物、对白、画面文字或特效；声音是否使用仍按分镜合同。结论合入同一方案，不另交人物表、场景表或逐项自评，不增加审批。

| 内容 | 第一阶段写清什么 | 第二阶段细化什么 |
|---|---|---|
| 观看任务与内容重点 | 给谁看、在哪里看、已知什么；本片主要交付什么，信息怎样分主次 | 沿用任务与重点，落实画幅、可读性和观看条件 |
| 事实、素材与参考 | 用户锁定项、可用事实与素材用途；按需研究并说明实际采用什么，区分概念设定与真实资料 | 核对素材职责与缺口，列明第三阶段需取得的输入，保留来源与采用边界 |
| 创意与完整展开 | 具体看点与表达形式；开头、中段、结尾怎样接续，品牌、产品或主题怎样参与；从完整内容概括一句话主线 | 拆成镜头，安排画面先后与停留，保留内容和看点 |
| 人物与说话关系 | 有人物时，说明理解事件所需的身份、关系、当下目的和已知信息，行为与说法由此成立 | 细化表演、调度和外观一致性；不另改人物动机 |
| 场景与关键物件 | 交代理解关键动作需要的地点、物件来源和位置关系，确认它们支持事件发生 | 细化空间布局、道具外观、人物走位与镜间状态 |
| 台词、口播、旁白 | 全部拟用文案，谁说、为什么说、前后怎样接 | 发声时间、停顿和跨镜衔接；需要修改时同步回写方案，不另编一套台词 |
| 画面文字 | 实际拟用的标题、例句、标签、数据和行动提示；怎样配合人声，出现在哪段、是否读得完 | 字体、位置、层级及准确进入、保持与退出时间 |
| 整体风格与表演 | 从真人或动画、写实或夸张、表演语气、主要光色与画面感觉中，选出会影响本片的具体做法 | 各镜头的构图、布光、色彩和表演细节，保持或按已定过程改变风格 |
| 关键运镜、转场与效果 | 影响理解或看点的拍法和变化，例如拉开才发现另一人、同一次抬手接到成年；指定一镜到底时写清连续路线与事件 | 逐镜景别、角度、运动起止、切点与效果实现，普通切换不必在第一阶段逐个设计 |
| 音乐与音效 | 按下文说明声音怎样参与事件，哪里进入、停止或形成笑点 | 准确时间、音量关系、声音延续与退出 |
| 粗时长与节奏 | 各段大致时间，哪里快、哪里需看清或停顿；说、做、回应与阅读能否完成；有效变化密度与创作节奏例外按视听工艺，具体时间安排按分镜合同 | 在既定节奏内落实准确秒段、镜头数、生成段和声音时间轴 |
| 制作可行性 | 关键设计是否符合已知结构、可用素材和实际能力；生成任务按交互合同拟定可执行参数与制作路径 | 核验制作细节，编写分镜与声音脚本、完整 Prompt 或真实依赖模板；必要资产准备仍按第三阶段原有授权执行，并在视频确认前绑定完成，不虚构工具能力 |

整体风格简短说明，关键做法直接写进内容。商品展示让结构、操作和结果可辨；创作者口播保留人的判断、语气和必要演示；人物片让关系与反应看清；音乐片让声音和画面怎样呼应可想象。选出本片真正起作用的构图、光色、运动、表演或声音关系，不只写“自然写实、高级、电影感”，也不要求填齐所有选项。用户已有风格或参考时沿用，只补缺口；风格变化应有内容依据。

**决定内容能否成立的拍法和声音，第一阶段就写进事件。** 遮挡后的揭示、镜头移动带来的发现、声音造成的误会，都可能是创意本身；删掉后笑点、理解或视觉变化就不成立，不能留给分镜阶段临时补。若创意主要来自视觉或音乐，就先把这段声画怎样开始、变化、结束写出来，不强加人物故事；普通对白和操作演示也不为凑项目添加特殊运镜、转场或特效。需要时查相关摄影、剪辑或视觉方法，不必把整本方法库执行一遍。

构思时就排除已知做不到的关键设计：不靠未提供的产品结构、虚构的输入素材或不可用的配音/后期能力让故事成立。需后续制作的素材按生产控制列为计划，不假称已经具备。缺真实资料可明确写成概念方案或收窄表达，不能把设想当事实；用户锁定的设计若确实无法实现，说明具体障碍与可行取舍，不擅自删除。事实与素材边界按[生产控制](production-control.md#来源与事实锁)，这里只判断它们是否足以支持内容。

第二阶段承接这些决定，把它们安排到具体镜头和声音时间里，不无故重选故事。若细排时发现动作做不完、素材或工具无法实现，或看点只存在于方案解释、实际画面和声音无法传达，就回改受影响的事件、文案或拍法，并同步方案、分镜与 Prompt；不能静默删掉关键设计，也不能只因第一阶段已经写完就保留无效设计。用户锁定项与是否需要重新确认仍按生产控制，不增加新的确认步骤。

## 主动创意参考研究

### 是否启动

| 当前需求 | 怎么做 |
|---|---|
| 只有产品名或少量资料，要从零写广告、TVC、品牌或企业视频 | 默认主动检索，不等用户给样片 |
| 要新颖、有趣、抓人，或明确参考爆款、某个平台的写法 | 主动找相关内容，研究它开头讲什么、中间怎样让人继续看 |
| 现有剧本普通、口播散、场景不合适 | 围绕具体问题检索，不重新搜所有方面 |
| 不熟悉品类、职业或使用场景 | 先了解人实际怎样做事、怎样描述问题，再找合适的表达参考 |
| 完整脚本、明确参考或项目内已看过的材料足够 | 通常不再检索；只补新缺口，过时材料另查 |
| 简单图片动态、指定动作、局部编辑、文字替换 | 通常不做创意检索 |
| 用户明确不检索 | 按要求使用已有信息，不编造研究过程 |

是否检索由代理判断，不增加用户必填项。创意参考和事实核实是两件事：不找创意参考，也仍须按生产控制核实需要核实的真实产品、企业、时效资料和 IP 形象。要求生成豆包角色/IP 时，核实真实角色资料。遵循用户的检索限制；无法核实的内容不写成确定事实。

### 找什么与选什么

按缺口找，不要求每次搜齐：

| 不清楚什么 | 去哪里找 | 学什么，不能混用什么 |
|---|---|---|
| 不知道讲什么、场景不像真的 | 电商问答与评价、社媒讨论、用户求助、实际使用过程 | 找具体疑问、做法和用户用词；个别评论不代表所有人，也不能冒充本品用户证言 |
| 不知道怎样让判断可信 | 操作演示、同条件比较、测试、教程、可核实资料 | 看操作、条件和结果；竞品表现不能当成本品事实 |
| 有内容，但故事和台词普通 | 匹配观看用途的成片、完整文案、具体创作拆解 | 看开头、中段、结尾怎样接，整段语言怎样写；只看一个标题不够 |

搜索词应包含实际任务。商品详情可搜“通勤包门禁卡怎么放”“通勤包收纳演示”；新品发布则找完整发布广告、创作者项目或制作拆解，研究怎样由结构、材质或声音形成辨识。用户评价帮助找事情，成片帮助找表达，二者不能互相替代。跨品类参考要说明当前产品的什么特征能承接该方法；只搜“高级 TVC”“爆款脚本”容易得到泛例。

先找观看用途相近的参考，再补其他品类的好方法。商品页参考怎样帮助选购，教程参考怎样教会操作，人物片参考怎样写行动与回应。不要因为都是包的广告，就把品牌形象片照搬到商品页。

参考范围不限于营销片。MV 先找相近音乐段落和表演/概念表达；知识科普找完整解释与可视化；旅行、展览和时尚分别找经历、观看路线与主体呈现；活动、公益、招聘、年度片找其实际信息任务。搜索词同时带用途和当前问题，不因主体都是城市、人物或产品就共用同一种文案。只有生成工具或剪辑流水线的项目可以帮助制作，不能代替对应内容的研究。

相关性比播放量重要。明星、账号基础、投放和促销也会影响热度，不能仅凭播放量认定剧本有效。没有可靠数据就叫“参考案例”；引用数据注明来源和时间，不编造爆款。

优先看实际内容。逐字稿可以研究台词，不能证明画面、剪辑和音效；标题、海报、摘要也不能证明整片怎样展开。GitHub 项目可补充创意推导、脚本和工作流参考，要读相关规则及实际示例输出，判断是否适合当前问题；只有 README 的能力介绍、固定模板或调用链，不能证明剧本质量与广告效果。借鉴创作方法，不自动迁移其模型、工具、审批、镜数或生成流程。原片打不开就换可访问的来源，只说明实际看到了什么。

### 怎样研究并转入写作

使用教程能教会产品怎样用，未必能教会广告怎样吸引人。当前问题是剧情普通或口播不合场景时，还要找相应的完整文案、成片或具体拆解；不要看完几篇功能说明就结束表达研究。同一材料能解决两个问题时可以共用，不凑两套资料。

看参考时，沿实际时间顺序追踪：开头凭什么值得看；中段怎样接着展开，哪次变化带来新判断或感受；后一句怎样接前一句；此时的画面、声音、表演与剪辑各起什么作用；何时认出推广对象、看点怎样与它关联；结尾完成什么。再判断方法有效所需的条件：已有品牌认知、演员关系、真实产品特征、音乐段落或展示位置。研究台词要读一段完整表达，分清实际说出的话、画面标签、独立广告语和作者解说；一组分别投放的短广告不是一条连续旁白，不能将其中的金句串起来照搬。自动转写中的错词和断句须结合上下文核对，拿不准的句子不作写法依据。尤其看中段，不只抄开头一句。不逐项输出拆解表。

通常先看 2–3 个互补参考，数量不是门槛。判断够不够，要看当前写作问题是否有了具体解法：例如学到了怎样让中段继续变化、怎样把解释接到操作上，而不只是找到“同品类也这样拍”。只有平台通用建议、标题或功能介绍，还不能声称研究了完整剧本。足够支撑当前展开就开始写；写到具体难题再补查。结果无关或打不开，换关键词或来源；仍找不到就依据已知信息继续写，说明实际研究范围，不无限搜索，也不让用户代找。

在同一方案中保留采用来源和简短说明，例如“借用先给结果、再展示操作的顺序；本片改为先看卡片归位，再展示怎样分类”。说明必须对应具体改动，不能只写“借鉴电影感”。对外仅展示创意研究的来源网页链接和简短采用理由，不另交报告；来源说明与视频、图片交付的边界及格式统一按[交付合同](media-delivery.md)执行。

综合参考中的不同解法，提炼适用条件，再为当前内容写一条连贯方案；不把几条参考的开头、金句和结尾拼起来，也不因参考用了慢镜、密集卡点或无旁白就一并采用。借展开方法，重写当前人物、行动和台词，不逐句改写原片，不移用未经核实的产品主张。参考链接不等于可直接使用的媒体素材；实际输入仍按资产合同登记。只使用实际可用的工具，不编造案例、访问记录或数据。

## 按用途组织内容与文案

### 先找到具体切入点

从当前用途真正需要交付的内容落笔。选购片先找需要支持的购买判断，营销口播先明确创作者要讲的产品或品牌观点及理由，教学先确定要教会的内容，品牌广告先明确传播中心与表达依据。这个内容应足够具体，能决定接下来讲什么、展示什么；“年轻人追梦”“产品很好用”“生活需要仪式感”不足以组织一条片。

传播重点还要落实为具体的观察或判断：当前受众容易忽略什么、正在权衡什么，哪项已知细节值得重新看待，或怎样的声画关系能使这个特点被感到。根据资料选真正有内容的一处，不逐项配齐。“方便”“自由”“这里很美”只是主题；写出便利发生在哪里、态度怎样影响选择、此地怎样被体验，才能决定拍什么、说什么。没有依据的差异不能编造；共有特点也可以通过具体观察与表达成立，不要求发明独占卖点。

**传播内容与影片写法要一起成立。** 一个功能结论、一句品牌主张或一个出游理由，说明要传达什么，还没有说明这条片怎样值得看。产品信息齐全后，找到当前对象值得多看一眼的具体之处：容易忽略的使用取舍、能亲眼判断的差别、可发展的结构/材质/声音，或能让人认出的品牌行为；让它决定开头与后续展开。普通演示加一句总结仍然平淡时，改变观察问题、呈现顺序或声画关系，而不是多报几个功能、多换机位或换一个夸张形容词。继续写成实际的声画安排：观众从哪个角度进入，什么先被看见或听见，怎样逐步理解其意义，最后留下什么。产品介绍本身也可以是看点：把相关事实写成能理解的关系，例如结构怎样改变用法、同一商品的口感怎样先后变化、两种使用需要怎样由不同设计满足；按资料选择，不把关系名称当固定模板。记忆来自片中实际建立的具体认识、体验或品牌联系，不必再造一句金句；把主要意思落到一个能想起的具体画面、声音、行动或说法，并在展开中使它获得意义，不能只在方案解释里说“有记忆点”。只剩形容词、谐音或品类都通用的动作时，继续找值得展开的产品内容，不能靠押韵补救。可以用演示、人物、视觉、音乐或语言完成，不必都造剧情。若删去创意说明，剩下的仍只是常规操作与一句总结，就继续改观看角度和展开；教程、准确展示和指定动作以完成本职为先。

有人物时，先在展开中交代观众理解行为需要的身份、关系、当下目的，以及人物已经知道什么，不写与本片无关的传记。**先按人物的目的和常识写他会怎么处理，再从真实限制、选择和回应中找看点。** 不先预设笑点，再倒推人物犯错。构思行为时把人物换成一个知道同样信息、具有普通判断力的人：他还会这样做、这样说吗？如果不会，且片中没有成立的原因，就放弃这处看点，改事件，不能只修物理条件或在旁边补“他忘了”。允许疏忽、误会、笨拙和夸张，但起因应能从处境、线索、性格或关系中理解；明确荒诞的创意按已建立的虚构规则成立，不把角色的无故失常当幽默。不能为产品登场，强迫人物反复失败或说不合身份的话。场景与物件也要支持关键动作，例如隔着柜台递东西，要知道谁拿着、能否够到；不为接顺临时多出道具。演绎可以压缩时间，但不能把虚构处境说成普遍痛点。

默认直接写一条完整方案，把开头、中段、结尾和关键语句连起来；内部也不先凑多套方案再选优，不把同一想法换风格标签拆成几案。只有用户明确要求多个方向或版本时才分别创作。核心确实不成立时才重写切入点。修改不是再建一组备选，也不另做优秀程度评分或普通版对比。

开头、中段、结尾是内容的先后位置，不是统一的剧情模板。具体进入方式与展开依据沿用所选用途：营销内容逐步建立产品或品牌判断，营销口播继续展开当前观点及理由，教学补足理解与操作，故事才推进人物行动与回应。可以从关键主张、可见结果、具体疑问、操作或当前事件进入，不能只因某种写法适合一个案例就迁移到所有类型。已锁定的主张、事实与内容仍保留；用户允许的视觉、音乐和形式创意可以大胆展开，变化规则应可理解，也不能冒充功效证据。

**先写内容怎样发展，再拆机位。** 第一处展示成立后，后面可继续改变理解、增加有分量的依据、让人物作出回应，或使同一声画形式出现新的层次。例如论述中一个理由改变了结论，感官表达中原先孤立的声音与后面的动作形成整体。根据用途采用，不要求每片升级冲突、隐藏答案或结尾反转。让前一处内容影响后一处，而不是每段重新介绍一次主题；重复能积累节奏、比较或情绪时保留，重复已知结论的覆盖镜头则删减。形状匹配和声音接拍只能接镜，不能替代内容关系。

选定的表达须与当前主体有实际联系。换产品后主体事件仍完全通用时，回到本品特点和具体处境重新取材；同品类共有的真实用法可以成立，不要求独占卖点。幽默可以改变观众对处境的理解，人物仍按自己掌握的信息正常做事；视听夸张可以表达感受，不冒充实际性能。先让看点成立，再看结尾是否把它归到当前主体，不能只靠片尾解释挽救无关内容。

想让观众相信什么，就给能支持这个判断的依据：真实操作、可见反馈、已核实数据、同条件比较、人物选择都可以。解释设计、方法或建议时，放进一个实际任务：为什么需要这样做，操作或选择带来什么结果，什么条件会改变选择。演出“手能伸进去”只证明能伸进去，还要让人明白为什么此时需要伸手；不能把特征换句话就当理由。依据仍弱，就换例子、改演示或收窄结论，不为成立而编造失败、经历或数据。想让观众感动或会心一笑，则写能产生这种感受的行动和回应，不能只标“温暖”“搞笑”。

### 写出完整内容与声画展开

按当前用途写完整内容，文案与承担表达的画面、声音一起构思。营销广告看购买或品牌判断怎样逐步成立，创作者口播看观点与理由怎样接续，教学看观众怎样由不懂到会做，企业片看事实怎样支持业务判断；采用人物故事时再核对目的、行动与回应的因果。不要把同地发生的一串动作当作所有视频的完整展开，也不把视觉或音乐创意变成先念文案、再配插图。

- **开头进入当前任务。** 让观众认出主体、价值、问题或值得继续看的具体内容。商品已经被认识时，不反复揭晓是什么；人物背景只交代理解需要的部分。不先演一段与观看任务无关的铺垫。
- **中段展开本片需要的内容。** 补具体理由、证据、条件、解释、视听发现或人物回应。丰富度按对任务的贡献判断，不能只数事件、功能或镜头；同一内容的近景、慢镜与换词不自动增加信息。
- **结尾完成本片的交付。** 广告形成清楚的品牌/产品识别与已建立的判断，需要行动时给适当引导；教学给可执行的结果与核对；故事完成人物行动或回应；视觉/音乐任务完成已定变化。不能最后补一句口号，才解释前面为什么要看。

篇幅和注意力给主要任务。商品入镜不代表正在说明购买理由，人面对镜头不代表已有创作者视角，画面精致也不代表形成品牌记忆。生活互动、操作准备、铺垫与装饰占用了主要时间，而关键理由、解释或品牌表达只靠片尾一句时，应重新分配内容；不规定统一露出秒数，也不要求每镜报卖点。

准备、展开、调整、拿放，虽然能拆成很多镜头，可能只说明“东西放好了”。按它们实际帮助观众理解的程度分配时间；关键操作要看清，无关准备可以删。不能擅自增加未提供的解锁、拆卸等步骤。

内容丰富，是交代本片真正重要的条件、依据、选择、后果或人物反应，不是多换形容词、多列功能、多切镜头。逐段追问为何需要这次展开；一次操作拆成接近、接触、抬起和换角度，若观众只得到同一个结论，仍只算一处展示，不能作为中段丰富的依据。先按观众需要理解或判断的问题组织内容，再为每处安排必要镜头；取物、操作、结果和反应可以共同讲清一件事，不因各有一行镜头职责就算多项信息。下一处应回答尚未解决的疑问、给出新的有用依据、使用条件或体验变化；已经明白后仍重复归位、换角度和走开，就删掉，不靠新增机位或拉长口播撑时长。关键步骤与结果必须给足，次要取放、准备和过门可以剪辑省略；短片撑不住既定时长时先回选材，不通过延长同一过程或擅改用户时长补齐。人物片可以让一次尝试引出意外回应，回应又让人物改做法；演示可以先看结果，再看造成结果的关键操作与适用条件；知识片可以解释例子中哪一步改变了判断。只取本片需要的内容，不把这些全部塞进短片，也不强迫每段悬念、每条反转。

第一阶段先写观众能看到、听到的事实，少用作者的判断代替事件。“她被温暖打动”还没写出发生什么；“她看见对方把仅剩的一把椅子推来，收起包坐下”才给出了可见依据。若一段以发现、误会或决定推动后续，写清触发它的具体线索，以及后续行动怎样由此发生。核对谁在现场、谁隔着设备，角色实际上能看到或听到什么；笑点、误会与揭示不能依赖角色收不到的信息，也不能靠音效或剪辑越过空间替角色知情。角色为什么这么做、关键物件是什么，按理解需要及时交代；需要观众猜时也给线索，不能到最后靠一段说明补完前情。

**按前后状态连续写动作，上一段的结果就是下一段的起点。带着这些状态读下一段，核对他是否真的能做后面的动作，一直读到片尾。卡已在袋里，没再取出就不能又“插回袋里”；优先删掉不必要的重复动作，不为接顺而多加一次取放。片尾文字后面仍在发生的动作也要这样检查，不能当作装饰略过。回放、同时发生或隔了一段时间，要让读者知道，不必另填状态表。

**先按分镜合同选择节奏，再逐段粗排时间，不只看全片台词总量。** 每段先按正常语速读台词，再按动作先后走一遍：换人、等回应、笑、看清操作、取物和坐下都需要时间。能同时做的写“边说边做”；必须说完才做的留出先后。无需展示的过程可以明确写“切到两人已经坐好”或“稍后”。不要把装衣、启动、换位置、坐下和多轮对话全塞进一个短段；超时就删次要句、简化动作或重新分配时间，不要求演员加速念完，也不把明显做不完的问题留给正式分镜。实际生成任务在方案中估计镜头数与拆段，不靠凑镜数增加内容；正式秒段、镜头安排、自然发声时间与适用例外仍按分镜合同。

一句话主线从实际写好的内容中概括。广告说明要形成的产品或品牌判断及其展开，营销口播说明当前观点与理由，教学说明教会什么，故事说明谁怎样行动与结果，视觉/音乐片说明变化怎样发展。不要都填成“谁遇到问题、怎样解决”，也不只写“传递高级感”。同一主体换用途时，取材、先后、语言职责或结尾应实际改变；需要方法时查[策略迁移适配总则](creative-methods.md#策略迁移适配总则)，再用当前类型的具体写法调整。

### 连写文案及声音职责

口播、旁白要写出整段，全部对白要能连读，放入对应的内容段落。先用这个说话人平常会用的话讲通当前内容，再删赘句、调节节奏和提炼品牌句；不要先造几句漂亮短句，再设法把它们接上。对白随人物行动写，依赖演示、画面或音乐的表达一起构思，不能为了连续念稿而删掉必要的画面信息、声音或对方的反应。不要每镜单编一句广告词。

画面文字也写实际文案，放入对应事件或随方案列一次，不只标“出现卖点、显示例句”。先分清信息职责：理解当前内容必需的身份、条件与关系及时交代；日期、地点、规格、岗位要求等供查阅的字段，按观看环境安排可读的文字或信息画面，人声按需要读出关键项，不默认把全部字段串成旁白。静音、远距离或无文字任务按已定观看条件调整。再核对观众此刻要听什么、看什么、读什么；一边讲新概念、一边操作、同时读另一段长文会互相争注意，就错开或删减。文字保持时间计入所在段，不靠分镜阶段临时挤入。

**先确定说话原因。** 顾问解释选购条件，教程提醒怎么做和怎么看结果，分享者说自己的观察和取舍，品牌旁白可以提炼感受。人物开口往往是想请人帮忙、问清事情、拒绝、提醒、掩饰或打趣，先看他此刻想让对方怎么回应。不是每句都要写意图标签，但句子应能让对方自然接话或采取行动。角色不能聊着洗衣服，忽然替品牌讲“让生活更美好”，也不能知道他尚未获知的事。

**让说法符合说话关系。** 同一件事，顾问可能说“常拿的卡放外侧，取卡不用开主仓”；朋友正要翻主仓，问“卡呢？”，对方边从外侧取卡边答“这儿，别翻了”。两种写法都以已确认的结构为前提，不能把说明书加个“我”就当生活对白。人物差别也可以来自想要什么、注意什么、怎样回应，不靠口头禅、方言或每人一句金句制造人设。

**围绕同一件事接着说。** 口播和解说先明确观众当前要判断或弄懂什么，后一句接着回答尚未说完的疑问、解释依据、补条件或修正判断；不用每句提出一个新主题。新提到的人、物、功能和结论须有必要的引入；主语、称呼、时间和说话立场不能无故变换。“它、这里、这一步”要能指到前文或当前画面。人物对白则接对方刚说或做的事，允许回避、误会和换话题，但要让观众察觉原因。发现断裂就改这一段的顺序、前提或回应；补“所以、不止、更”不等于补上理由。

**说出具体意思，删掉不帮忙的句子。** “取哪件，拿哪件”没有解释怎样取或为何这样放；可改成当前真正需要的说明，例如“常拿的卡放外侧，不用开拉链”。如果画面已经足够，直接删这句也可以。“省心、从容、全新体验”要有本片实际内容支撑，不能轮换夸奖填时间。

口播有信息不等于逐项念参数。篇幅先给最影响本次观看或选择的内容，再补理解本品、实际使用或选购还需要知道的信息；有一个重点，不等于只讲一个事实，或要求其他特点都证明同一句结论。相关特点按作用接起来：一个解释另一个、满足不同需要，或补充条件与取舍；不要每句换卖点又不交代联系。产品/服务介绍、演示和理由要互相支持，不把三者各写一段互不相干的话。仅说出外观、动作或包装形式时，还要按本次用途讲清其中值得在意的体验、设计原因或使用意义；资料支持不了的关系不能编。能从画面直接看出的操作不必逐步复述，把语言留给此时有用的身份、判断、原因或条件；不是一律删除动作说明，也不能因此把产品名、口感、结构原理或必要说明都删掉。先写成一个人能顺着讲下去的完整意思：正在介绍什么、注意到什么、为何这样判断，证据或演示在需要时接上；由语义决定停顿与切镜，不按镜头数把一句话切成几个没主语的标签。普通回应、停顿和笑点也有用，不要求每句都提供新卖点。结尾已有识别、判断或行动时，直接结束，不用“喜欢就买、想用就用”等可替换套话填空；需要行动引导时给实际下一步。教程可以一边演示一边提醒关键操作；有意义的回扣也可以重复。判断一句话是否帮助理解、行动、人物关系或感受，而不是机械禁止声画说同一件事。

按文案用途再核对：

- **建议、选购和比较：** 说明对谁、在什么条件下适用，理由或比较依据是什么；不从一个功能跳到未经证明的效果。
- **教学：** 给够例子和操作信息，让观众知道从哪一步开始、怎样判断做对了。例子应真正用到所教的方法，不能只报步骤名。
- **生活对白：** 看对方刚说了什么、自己为什么这样回。允许省略、打断和误会，只要观众跟得上；不为解释而互相复述已知信息。
- **诗性旁白：** 可以借画面、意象和重复表达感受，但整段要有共同线索，不能无缘无故从“远方”跳到“热爱”再跳到“未来”。不要求句句报功能或论证。

**分别写好说的话与看的字。** 参数标签、活动标题、品牌广告语不自动成为下一句口播。人声的意思要完整，句法按说话关系处理：口语可省略已知主语、用半句回应、接着眼前动作往下说，不必每句都像书面说明。需要解释的关系仍交代清楚，不靠切碎句子制造速度。品牌句可以提炼，标签可以简短，二者不能代替必要解释；也不用反常搭配、翻译腔或刻意省字制造“高级感”。

再带着画面读：依赖指物、表情或动作才能成立的句子，所需线索是否及时出现？允许声画共同表达，不要求对白脱离场景仍自足。展示型内容不必持续发出“看、听、感受”的指令，人声可补判断、态度或关系；关键操作也可以直说。连续几句只在夸奖或表态，就改成实际观察、理由或回应。人物与创作者按当前说话关系判断自然度；品牌旁白可以提炼、排比和押韵，但整段仍须讲通，不能拿朋友闲聊的标准抹掉其广告表达。卡住时先用日常完整句说清意思，再提炼；不加语气词掩饰断裂，也不为凑尾句突然拔高主题。用户锁定原文仍保留。

押韵、隐喻和金句不能牺牲正常搭配和意思。创意说明是给制作者看的，不能因其中的比喻漂亮，就直接交给人物或旁白念。先判断声音此刻还需要补什么：事实、判断、回应、态度或感受；画面已表达的意义可以让观众自己得到，不再解说一次。需要广告语时再从已成立的内容中提炼；任务已完成，可以停在自然回应、动作或品牌识别，不为结束视频另外编一条人生道理。遇到断裂或刻意表达时查[语言怎样改](creative-methods.md#语言怎样改)与[文案动作和语感](creative-methods.md#文案动作和语感)，不套固定语气。

事实限制用来约束创作，不自动变成台词里的免责声明清单。只有影响观众当前选择、操作或理解的必要边界才写进内容，用户明确要求的提示保留；重要限制也不能隐藏。没有真实体验，不写成“我用了一个月”；指定逐字台词则保持原文。实际视频制作中，用户提供的台词明显放不下时，按[制作方案选择](interaction-ask-video-clarification-ref.md#制作方案选择)统一询问保留全文、精简或时长取舍，不精确计算朗读用时来触发询问，不静默删改；代理自写或已获准改写的文案在授权范围内自行改好。

### 把画面和声音一起想清楚

第一阶段就决定声音怎样参与：谁说上面的全文；音乐怎样帮助情绪或节奏；哪些动作需要声音让人听清，哪些停顿要留出来。例如卡片刷过的提示音可以接下一次动作，角色听见一句话后的停顿可以形成笑点。不要只写“配高级 BGM、丰富音效”。

按当前内容一起写画面、台词、表演和声音，不先写普通故事，再各加一层“大片感”。人物片例如角色嘴上说“不用等我”，手却放慢收拾，另一人把已经穿好的外套又放下；对白、动作和回应共同让观众理解关系，旁白不必再解释“他们彼此关心”。演示片则让镜头看清动作，操作声确认接触或完成，人声解释为什么这一步重要。不是每片都用潜台词；指导操作时应直说清楚。

配乐从当前内容的动作速度、人物态度、观看环境和情绪选择，不能把“轻打击乐、关键处停一拍、结尾收束”用于所有类型。先判断观众应紧张、想动、会心、沉浸还是集中理解，再写出相应的音色、律动与变化；所选声音应支撑具体事件，而非替平淡内容制造虚假的高潮。写到能想象出声音的程度：例如干脆的拨弦与轻打击衬托一本正经的忙乱，人物发现误会时停下伴奏，只留现场一句回应；不要给所有片都安排“钢琴起、弦乐升、高潮全编制”。声音可以提前引出下一处空间、随距离远近改变，也可以让同一个动作前后听出人物状态变化。只采用对本片有作用的设计，音乐、台词和音效争抢注意时，错开它们的重点；不要求全片始终满配。

静音时要保留主要观看线索；正常播放时，人声、音乐和动作声仍应承担实际作用。是否允许无人声、具体声音密度统一按分镜合同，不在这里另设例外。第一阶段说清用途，分镜再安排准确时间；同一方案里的人声全文只展示一次，不因跨镜重复抄写。

画面也可以直接带出创意：看不见的声源突然揭晓、换视角才发现的细节、同一物件前后不同的用法。写清观众会看见、听见什么，不只写“制造反差”。需要视觉变化时，让触发动作、变化和结果有关联，不设特效数量配额，也不按固定间隔插产品。

内容较长时按[长视频内容展开](#长视频内容展开)继续发展同一任务；实际生成段不是内容章节，不在每段重新介绍、制造钩子或总结。

已有稿件的观点、词汇和重点也是用户选择。能成立的表达保留，围绕具体问题改，不把所有句子改成代理偏好的口吻。精确、具体来自真实对象、条件与动作，不靠补造数字、效果或经历；也不将某种句式列成全场景禁词表。

可参考 [marketingskills 的 copywriting](https://github.com/coreyhaines31/marketingskills/blob/main/skills/copywriting/SKILL.md)与[copy-editing](https://github.com/coreyhaines31/marketingskills/blob/main/skills/copy-editing/SKILL.md)中对既有表达、具体事实、可理解性和朗读的检查；它们主要面向网页营销文案。不得照搬逐句多候选、专家打分、多轮审阅、强制 CTA、固定禁句或“竞品也能说就失败”的门槛，也不能为了具体而补造数字。

## 短视频内容展开

短片优先保住一处完整、值得记住的观看经历，不把压缩理解为只留结论。关键内容可以由“预期如何建立、观众实际看见什么、结果怎样影响判断或感受”连起来；直接展示、平行对照与纯运动也可成立，不强制套成三个段落。篇幅有限时，先减背景介绍、重复解释与无关过门，把必要前提、决定性过程和结果留清楚。具体诊断可查[叙事节奏与重点](creative-methods.md#叙事节奏与重点)。

短视频减少展开范围，不降低内容、动作与声音的完成度。新创作的4-15秒短片先按本次任务选最值得交付的内容，再将它写成能看懂、听懂的完整表达；不是只选一个词、一个慢推或一句泛泛口号。正常语速、动作接触与反馈、必要阅读和人物回应都要留得下。按已有事实补充有用细节，不因为片长短就主动删去产品身份、解释、证明或关键反应；也不把所有资料挤进短片。

| 当前任务 | 短片里怎样形成有内容的表达 | 信息不足时具体改哪里 |
|---|---|---|
| 产品广告、营销口播 | 让观众认出当前产品/品类，看清与本次购买或使用有关的特点及依据，并理解其意义；身份可由包装与简短介绍共同承担，解释可以跨镜继续 | 把“拿起、转一圈、放下，真方便”改为一项看得清的特点或实际操作及结果，让台词补使用理由、条件或取舍。相关结构、结果和意义足够简洁时可以同时交付，不限定只能讲一个事实 |
| 品牌TVC、人物与情感表达 | 用具体选择、行为与回应，或有发展的视觉/声音表达形成品牌联想；保留让这一联系成立的细节，声音路线仍按分镜合同 | 若只剩人物微笑、慢镜与片尾口号，就补让感受发生的行动、差异或回应，或重新选择能在当前时长成立的表达；不强行加剧情和销售清单 |
| 企业、服务、活动 | 直接交付当前最有用的能力、服务过程、参与体验或已核实依据；身份和必要行动信息及时可辨 | 将办公楼、开会、握手配泛化赞美，改为具体工作、服务节点、可判断结果或实际参与内容；不以未核实数字代替内容 |
| 知识、操作、问答 | 回答一个界定清楚的问题，保留必要例子、关键过程与结果核对；步骤较多时选其中能完整教清的部分并说清范围 | 若只有步骤名，就补会影响做对或理解的操作细节与反馈；不将完整过程压成闪过画面、加速台词或省略关键条件 |
| 音乐、风景、视觉创意、简单动态 | 通过动作、空间发现、材质细节、音乐变化或视觉关系持续交付观看内容；按原任务决定是否有人声、文字与切镜 | 简单动态在首秒启动有效变化，后续按正常速度发展并落到明确状态；不能只用静止、重复循环或匀速慢推撑满，也不强加营销台词和多镜剧情 |

时间优先给本片要讲清、看清、感受到的内容。删减无用开场包装、重复取放与已经完成后的空停，把可省略的准备明确剪辑省略；必要动作、证据、阅读和反应不能一并删掉。可同时进行的画面与人声可以并行，例如画面展示结构与操作，台词解释为何这样用，短标签定位关键部位；不要同时加入另一段需要阅读的新信息。运镜跟随当前发现或动作，连续镜头内部可以推进多个状态，切镜也应接住新信息，不以换角度假装增加内容。

已有内容明显稀少时，先从当前事实和观看任务补一个尚未回答的问题、相关细节、可见结果、条件或回应；内容已足够时就保持清楚，不为丰富度堆功能、每秒硬切或重复念稿。未指定时长时，在主入口范围内按正常速度选择合适时长；已指定时长则在原时长内重组选材，不擅自延长。单图自然动起来仍默认5秒，简单动态仍默认4-8秒；它们按运动与观察任务展开，不因本节升级为产品广告。保留原片的局部编辑仍保护未要求改变的部分。

例如10秒概念收纳广告，已知事实只有“外侧卡袋取卡不需开主仓”：可让卡袋与商品同框建立身份，再完整展示取卡过程与结果，口播解释眼前的使用意义，最后在识别已清楚时结束。主仓不是本次操作对象，不反复开合或归位；没有依据就不补防盗、耐用或效率数字。该例只说明身份、特点、依据与意义如何共同成立，不固定三段秒数、镜头数或统一开场。

## 长视频内容展开

片长增加时，相应增加观众真正获得的内容。先按全片时长写开头、中段各部分和结尾，在现有方案中说明每部分交付什么，以及承接前文后继续回答什么；正式分镜再落实到镜头和时间。不要先把短片拉长，再给同一动作补角度；也不新增策略卡或固定章节数量。

先从当前资料找出已有内容，再判断观众还需要了解哪一层：对象本身、为什么这样设计/选择、实际怎样发生、怎样判断结果、哪些条件会改变判断、人与组织怎样回应、这对后续有什么影响。根据可用依据选择能继续展开的方向，把相关方向连成完整段落；不要求每类都出现，也不把下表当固定目录、任务问卷或已完成的内容。

| 当前任务 | 可按资料继续深入的具体方向 | 怎样形成有用的声画内容 |
|---|---|---|
| 产品、商品、营销 | 身份与设计取舍；结构/材料/成分/工艺及其作用；实际操作、过程与反馈；不同场景、对象或搭配；同条件比较、选购条件与限制；规格版本差异、维护与服务；感官细节的部位、先后及产生条件 | 按本次观看任务选取，解释“是什么、怎样发生、为什么值得注意、在什么条件下成立”；演示给可判断的过程和结果，台词补理由与条件，标签定位关键部位。不把所有方向改成参数播报，比较与功效须有依据 |
| 品牌TVC、品牌故事 | 已确认的定位、历史节点与设计选择；人物在不同处境中的行动、关系、代价与回应；品牌实际参与的服务/活动；资产、意象与声音在前后不同语境中的含义；同一态度的不同实践 | 让段落从一处行动走到回应或新的处境，从一个可辨资产走到新的认识；感受靠具体内容形成，旁白按既定声音路线讲清必要联系。不能换人换景重说同一句主张，也不凭故事替品牌发明长期理念 |
| 企业、商务、案例 | 服务对象与业务问题；从需求、方案、执行到交付的实际流程；岗位协作、关键决策与交接；质量控制、异常处理、后续服务；有来源的研发/生产/运营细节；案例条件、方法、结果及适用范围；与主题相关的文化、招聘或责任行动 | 把能力落实为具体工作与依据，解释关键一步为何重要、上下游如何配合、结果如何判断。公司历史、资质、客户、经营和责任数据须有来源；不反复办公楼、开会、握手配“专业高效” |
| UGC、采访、测评、观点 | 当前问题与说话者立场；当场观察、选择标准及理由；同一对象在不同条件下的表现；评论疑问与具体回答；比较中的取舍、不适合情形、观点变化；已有资料支持的长期体验或不同参与者的观察 | 让后一句回答前文留下的疑问，演示或资料在需要时接上，同一意思可跨镜持续。保留真实个人表达和必要反应，不伪造亲测经历、用户评价或受访者原话；营销任务仍交付产品/品牌内容 |
| 知识、教程、方法 | 关键原理与前置条件；从简单到具体的例子；完整操作与判断结果的方法；常见误区、失败原因及纠正；不同情形下的应用、边界和方法选择 | 逐步解决尚未理解或不会操作的部分，用过程、例子和核对支持解释；可回到同一例子增加新理解，不只报步骤名，不靠信息图飞动代替推理 |
| 服务、门店、文旅、活动 | 参与前的具体需要与条件；到达、接待、体验和离开的关键节点；不同空间/路线/服务的选择与差异；人员如何提供服务；可体验的细节、问题处理与有依据的后续安排 | 沿实际体验或问题展开，让观众知道能做什么、怎样选择、为什么值得参与；地点、开放时间、费用、预约与服务承诺只用有效资料。推广与个人记录按本次用途取舍，不把环境空镜当完整介绍 |
| 纪录、旅行、人物记录 | 事件背景与当前处境；过程中的选择、困难、调整、观察与关系；人物或空间前后变化；细节与整体的联系；真实结果及尚未解决的问题 | 用真实时间、空间、原声和行动组织经历，不为发展内容虚构冲突或结局；同一地点再次出现应帮助理解新变化，不能只增加风景覆盖镜头 |
| 音乐、时尚、风景、视觉创意 | 动作组合与力度；表演者与空间关系；观看距离、遮挡与尺度发现；材质、色彩、形体规则的不同结果；音乐段落、声源、节律与视觉的呼应；已有意象在新语境中的变奏 | 把观看体验发展成可辨的变化，写清触发、过程、结果和相互关系；不强加营销或知识解说，也不以同一推拉、发光或循环动作重复撑长。无实际音乐不声称已精确卡拍 |

可在同一方向向深处讲，也可按任务连接互补方向。深入时，让前面的结果产生后续要回答的问题：例如展示结构后解释操作条件，演示后补为什么出现该结果，成功案例后说明适用范围，人物回应后呈现其下一次选择。补充另一方向时，说明它与当前判断的关系；只是报出“工艺、服务、文化、未来”等名称，没有对应的具体事实、动作、解释或感受发展，仍未展开。
一个卖点可以深入讲清，不要求随时长机械增加卖点数量；每一段至少要有当前任务需要的新事实、解释、证据、条件、回应或可辨的观看变化。再次呈现前文内容时，必须承担新的比较、阅读、反应或回收作用。段落时长由这些内容以正常速度完成所需时间决定，不能把“细节更多”写成“动作更慢”。

例如将产品短片扩成 60 秒：若已有资料支持，可从认识产品，展开一项特点的结构原因和实际演示，再处理另一使用场景或适用条件，最后完成识别与必要行动。只演一次操作、反复换角度、重复同一结论，即使有很多镜头也未完成扩写。若只支持一个特点，就深入其机制、过程与条件；材料仍不足时收窄可支持的内容或说明具体缺口，不编卖点、品牌历史、企业成绩或亲测经历。示例说明内容如何扩展，不是固定章节、秒数或必讲清单。

章节先后由内容决定，再按工具上限安排生成边界；一章可跨多次调用，一次调用也可包含多个相接事件。前章的结果成为后章的起点，只有全片需要的地方开场和收束。

## 关键声音与画面怎样参与内容

采用人声、音乐、拟音的判断只按[分镜合同](storyboard-contract.md#声音选择)，不以静音也能看懂推导声音可有可无。第一阶段说明声音的内容作用，第二阶段再定准确时间与混音。

写到能想象的程度：什么音色与律动支撑当前态度，哪次动作、关系或发现使它进入、改变、退出；现场声怎样显示距离与状态，操作声怎样帮助判断，人声何时让位。关键声音可以带来幽默、悬念或感官变化，但不每条都轻打击、停一拍、高潮收束。未取得实际音轨时不声称精准卡拍，工具能力不虚构。

摄影揭示、遮挡、声音源或音乐关系若是看点本身，第一阶段就写清起因、变化与结果；普通机位与切点留给分镜。工艺具体办法按需查[视听工艺](audiovisual-craft.md)，效果过程按需查[视觉方法](visual-motion-playbook.md)。

## 方法词的使用

主线是本片具体怎样展开，结构是信息先后，节奏是注意和时间，风格是可观察的声画做法。这些只帮助创作，不是再交多套文档的要求。卡住时查[创作难题](creative-methods.md)，对用户直接讲具体内容。
