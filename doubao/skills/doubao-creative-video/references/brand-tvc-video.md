# 品牌宣传与 TVC 视频

## 文件说明与索引

本文件只负责品牌宣传、品牌 TVC、形象大片、品牌故事、品牌理念、品牌联名、发布会预热、年度回顾、公益责任和社会议题倡导的专属策略。参数确认、阶段确认、目录、阶段上屏、工具和成片规则读取 `references/production-control.md`；通用创意方向读取 `references/creative-core.md`；通用视听语言读取 `references/audiovisual-craft.md`；视觉效果、叙事节点和转场同步读取 `references/visual-motion-playbook.md`。

本类型的声音路线按“完整旁白优先 -> 少量旁白其次 -> 无旁白最后”判断。品牌主张、事实或因果靠画面无法准确理解时使用完整旁白；画面承担大部分叙事时，仅在开场、转折或收束保留 `1-3` 句；只有视觉因果、品牌识别、情绪推进和结尾主张均能由画面动作、文字、音乐、环境声与拟音独立讲清时，Agent 才能主动采用无旁白。该规则优先于本文件下方任何把无旁白限制为“仅用户明确要求”的旧表述。

## 适用边界

使用本策略的场景：

- 品牌形象型：品牌故事片、品牌形象片、品牌 TVC、品牌联名宣传。
- 人物故事型：创始人故事、员工故事、用户故事。
- 事件预热型：品牌发布会预热、品牌年度回顾、活动预热视频。
- 公益倡导型：消费品牌公益广告、社会议题倡导、品牌价值表达。

企业宣传、ESG、CSR、年度责任报告和公益项目汇报中，如果重点是企业能力、业务事实、组织行动、项目成果、招商、招聘或客户案例，优先商务视频。产品转化目标强时，优先产品广告。

如果同一需求同时包含品牌价值、企业能力和产品转化，先确定主目标：

- 让观众记住消费品牌态度、审美和世界观：品牌宣传/TVC 优先。
- 让观众相信企业能力、组织气质、产业实力、战略形象或项目事实：企业商务优先，即使参考片很电影化、无旁白或高端光影。
- 让观众购买、预约、理解单品或相信单品功能：产品广告优先。
- 让观众相信真人体验、创作者推荐或口播讲解：UGC 优先。

品牌宣传视频不只是“好看”，而是在有限时间内让观众形成一个稳定判断：

```text
这个品牌是谁 -> 为什么与我有关 -> 它凭什么可信 -> 我该记住什么
```

每条品牌宣传视频先收敛四件事：

- 一个核心主张：一句话讲清观众看完要记住的品牌判断。
- 一个受众洞察：观众为什么会在乎这个品牌判断，是身份认同、情绪共鸣、价值观、审美向往、信任还是行动号召。
- 一个情绪锚点：看完后残留的情绪，例如向往、信任、温暖、力量、好奇、行动感。
- 一个可见证据：人物、产品、行动、场景、数据或真实项目，用来支撑主张。
- 一个品牌不可替换瞬间：颜色、声音、动作、道具、空间、视觉母题或尾帧，让换成竞品后不成立。

品牌宣传场景判定：

| 大类 | 典型场景 | 传播目标 | 主要证据 | 创意入口 |
|---|---|---|---|---|
| 品牌形象型 | 消费品牌故事片、消费品牌形象片、品牌 TVC、品牌联名宣传 | 建立品牌态度、审美和记忆 | 品牌资产、产品世界、人物状态、品牌历史、联名双方共同点 | 视觉母题、反差命题、品牌资产显影、强定格画面 |
| 人物故事型 | 创始人故事、员工故事、用户故事 | 用人承载品牌价值和真实情感 | 人物选择、困境、行动、改变、与品牌关系 | 前后状态对比、关键选择、真实细节、少量旁白 |
| 事件预热型 | 品牌发布会预热、年度回顾、活动预热视频 | 制造期待、说明参与理由、聚拢注意力 | 时间地点、主题、嘉宾、产品线索、历史片段、现场空间 | 悬念揭示、倒计时、局部线索、能量递进 |
| 公益倡导型 | 消费品牌公益广告、社会议题倡导、品牌价值表达 | 让议题被看见并引导温和行动 | 真实议题、真实行动、产品/品牌行动或参与方式 | 具体处境、改变细节、社区声音、克制 CTA |

## 确认阶段重点

参数确认阶段必须讲清：

- 品牌主张：用户看完最该记住的一句话。
- 主题：把品牌主张翻译成可见命题，例如“女性不是被照亮的对象，而是光源本身”。
- 主角/主体：人物、产品、品牌资产、空间或视觉母题谁是第一主角，谁是辅助证明。
- 传播目标：形象、发布、联名、年度回顾、公益倡导、故事沉淀或社媒传播。
- 品牌资产：logo、品牌色、VI、品牌语气、禁用词、可用产品/人物/场景素材。
- 情绪路线：高端、温暖、年轻、科技、公益、人文、先锋、节日等。
- 产品/服务卖点：TVC 可以少说卖点，但必须知道哪些卖点会被画面证明，哪些只作为背景资料。
- 文案策略：视觉主导文案、少词旁白、尾帧一击、核心宣言、用户要求时的双语字幕或社媒花字；视觉主导方案仍要用旁白、画面文字、声音母题或结尾定版讲清品牌主张。
- 色彩策略：主色、辅助色、品牌色、冷暖段落变化和结尾收束。
- 声音路线：少词旁白、品牌 slogan、音乐递进、环境声或拟音。
- 音效分析：BGM 情绪、节拍峰值、拟音、人声位置、静音/黑场和 Logo 品牌短音。
- 运镜/布光/构图/转场：主运镜、主光源、构图母题和转场锚点。
- 视频节奏：平均镜长倾向、快慢交替、长镜头情绪点和快切信息点。
- 字幕：默认无字幕；品牌大字和片名不等于逐句字幕。

声音路线必须按顺序判断，不能一开始就为了“高级感”删除旁白：先判断完整旁白能否最准确地建立主张与因果；画面已承担大部分信息时，再压缩为仅在开场、转折或收束出现的 `1-3` 句少量旁白；只有画面因果、品牌识别、情绪推进和结尾主张均可独立读懂时，才使用无旁白。无旁白是第三优先级，不是 TVC 默认风格。

分镜表节拍默认覆盖：世界建立、品牌/人物/产品进入、情绪或证明展开、主张抬升、品牌收束。长视频必须先拆成全局主线和阶段职责。

## 阶段产物关注点

阶段推进、确认点和片段批次遵守主 `SKILL.md` 与 `references/production-control.md`，本文件只规定品牌宣传/TVC 在各阶段要重点写什么：

| 产物 | 品牌宣传/TVC 重点 |
|---|---|
| 规划 | 明确品牌主张、传播目标、视觉母题、情绪弧线、品牌资产和产品/人物/事件关系 |
| 脚本 | 先给全片理解，再写分段脚本；无旁白时也要写音乐、拟音、静默和画面文字位置 |
| 基础资产 | 明确人物、产品/道具、场景、品牌资产、视觉母题、声音母题和参考素材职责 |
| 分镜 | 每个镜头写清镜头职责、景别、机位、光影、运镜、转场、声音、品牌或产品关系 |
| 关键帧 | 锁定开场钩子、视觉高潮、产品/品牌露出和尾帧定妆 |
| 视频片段 | 确认段落承接、母题延续、品牌资产不变形、尾态能衔接 |
| 成片 | 检查节奏、声音、logo/packshot、主张记忆点和平台版本适配 |

## 产品登场策略

TVC 不默认一上来展示产品正面。除非用户明确要求电商转化、开屏硬广或极短社媒 cutdown，品牌 TVC 的开场应先建立“这个产品属于什么世界”，再让产品成为主角。

常用顺序：

```text
产品气质 -> 人物/生活状态 -> 品牌或产品线索 -> 产品登场 -> 品牌主张收束
```

产品气质可以先由这些元素承担：

- 陌生空镜：不常见但可信的空间、材质、天气、光线、声音或动作线索。
- 高级人物：克制表情、明确身份感、自然姿态、服装和环境共同服务品牌气质。
- 理想生活状态：用户想进入的生活、工作、社交、旅行、仪式或审美状态。
- 克制镜头：少量慢推、固定机位、横移、微距或景深变化，不用急促解释。
- 广告质感：精确光线、材质细节、声音母题、尾帧呼吸和少量文字。

“不漏产品”不是“开场硬塞产品”，而是全片始终让观众感到这个世界属于该品牌或产品：颜色、形状、材质、动作、声音、人物状态或场景选择都要提前为产品登场铺垫。产品正式登场后必须足够清楚，不能只给模糊剪影、局部反光或被遮挡的 logo。

产品登场时机按目标决定：

| 目标 | 登场节奏 | 避免 |
|---|---|---|
| 高端形象 | 前 30%-50% 建立气质，中段揭示产品 | 第一秒硬广感、产品缺席到最后 |
| 发布预热 | 前段给局部线索，中后段出现产品轮廓或主题 | 提前泄露未确认信息、假日期 |
| 品牌故事 | 产品可作为行动结果或价值证据出现 | 只讲情绪没有品牌关系 |
| 社媒切条 | 前 2秒给视觉钩子或人物状态，尽早给品牌线索 | 慢到看不出主体 |
| 会议大屏 | 先聚场和建立主题，中后段品牌/产品显影 | 尾帧太短、主题不稳 |

黄金三秒规则：TVC 可以不在第一秒硬露 logo，但 0-3 秒必须有品牌世界的入口。入口可以是人物关键动作、产品材质/轮廓、品牌色、声音母题、主题字、冲突瞬间、异常视觉规则或强构图。不要用三秒空镜、纯慢推环境、无信息光影或泛泛人物微笑开场；如果开场慢，慢镜头里也必须已经埋入品牌判断或视觉母题。

## TVC 原则

品牌 TVC 的核心不是把卖点说满，而是让观众记住一个品牌判断。

每条先确定：

- 一个品牌主张。
- 一个视觉母题。
- 一个情绪弧线。
- 一个品牌资产锚点。
- 一个最终记忆点。

每个 TVC 片段都必须有片段品牌核心：这一段要让观众相信、感到或记住哪一句品牌判断。尤其是短片直出和 15 秒以内 TVC，不允许只有漂亮镜头、酷炫转场和情绪氛围；每个镜头都要服务品牌主张、人物行动、产品/服务价值、事件主题或资产记忆中的至少一项。

品牌/产品 TVC 不允许把自然景观、城市街道、光影、慢动作、航拍、粒子、花瓣、烟雾当成默认创意。先问这个品牌或产品为什么必须在此场景中成立：场景压力、产品结构、材质反馈、使用动作、声音母题或品牌资产如何触发变化。汽车、高端硬件、香氛、美妆等形象片尤其容易退化为“风景 + 主体多角度 + 诗性旁白”；这种结构只有在每段都证明一个产品/品牌判断时才成立。否则必须选择一个主视觉规则，例如车灯切开风雪、轮胎轨迹重写道路、座舱光线改变环境、香气把街角植物唤醒、瓶身线条组织空间、品牌字形成为路径，并让它在开场、中段、结尾递进回收。

内部句式：

```text
这一段让观众记住：[一句品牌判断]
它通过 [人物行动/产品线索/视觉母题/声音母题/场景变化] 证明
最后回到 [品牌资产/产品/主题字/人物状态/行动信息]
```

画面要克制但有推进。不能连续空镜、抽象光效和泛泛人物表情；每 2-3 个镜头必须回到品牌资产、产品、人物行动、事件主题或可见价值。

孤立创意必须降级或删除。若某个创意只在一个小片段里出现，既没有被前文触发，也没有影响后文，更没有在尾帧回收到产品、品牌资产、人物状态或主张文字，它不能作为主玩法；最多作为转场或质感细节使用。主玩法必须至少完成“建立规则 -> 产品/人物/场景动作推动升级 -> 回收到品牌或产品判断”的三段关系。

## 品牌片发动机

品牌主张通常是抽象的，不能直接拿来拍。进入分镜前，必须把主张改写成一个“品牌世界如何运转”的动态命题。

转译公式：

```text
品牌主张：[希望/自由/长期主义/专业/年轻/团圆/突破/自然]
受众关系：[观众为什么在乎它]
品牌专属资产：[颜色/产品形态/声音/人物/历史/空间/动作]
世界规则：[本片中现实如何被品牌主张改写]
不可替换瞬间：[换成别的品牌就不成立的画面]
尾帧回收：[品牌资产/产品/主题字/发布信息/行动]
```

示例推导：

| 抽象主张 | 弱写法 | 品牌片发动机 |
|---|---|---|
| 希望 | 阳光、微笑、奔跑 | 黑暗空间不是被照亮，而是被人物一次次点亮；光最后回到品牌符号 |
| 长期主义 | 慢镜头、实验室、旁白 | 同一滴水从研发、使用到用户日常反复出现，每次都让状态更稳定 |
| 团圆 | 月亮、餐桌、举杯 | 产品成为传递动作：一杯/一盒/一束光从独处走到群像 |
| 年轻活力 | 快剪、彩色、舞蹈 | 品牌资产按节拍感染环境，静态城市逐步加入同一节奏 |
| 高端克制 | 黑底、慢推、钢琴 | 空间光线被产品结构重新组织，少量动作让材质自己说话 |
| 突破自我 | 登山、汗水、远景 | 每一次身体细节都改写环境阻力，最终不是登顶而是人物状态改变 |

## TVC 核心表达转换器

用户给的 TVC brief 往往很短，不能只补“高级感、大片感、情绪感”。先把 brief 扩成一个能驱动画面、节奏和收束的核心表达：

```text
用户 brief -> 品牌想被记住的判断 -> 观众默认预期
-> 本片轻轻打破哪个默认预期 -> 品牌资产/产品动作如何触发变化
-> 一个可复述高光画面 -> 尾帧回到品牌/产品/行动
```

核心表达必须带动作，不能只是卖点或形容词：

| 弱核心 | 可拍的核心表达 |
|---|---|
| 咖啡很提神 | 城市不是自然醒来的，是被第一口咖啡从窗格、街灯和人群表情里逐层点亮的 |
| 香水很清新 | 香味不是被喷出来的，是一阵海风从瓶口经过皮肤、衣摆和街角植物 |
| 跑鞋很轻 | 每一步都让城市慢半拍，脚步经过的地面先安静，再弹回节奏 |
| 护肤很焕活 | 一滴精华落下，皮肤光线里的花影从闭合到绽放 |
| 节庆礼盒很有心意 | 礼盒不是被打开，而是把分散的人、光和声音一点点合到同一张桌上 |
| 科技很智能 | 产品不是展示参数，而是让杂乱场景自动找到秩序和下一步动作 |

如果这个核心表达换成别的品牌或品类也成立，要继续加品牌资产、产品动作、受众洞察或场景关系，直到它具备“非它不可”的理由。每条 TVC 只保留一个核心表达、一个主创意系统/主玩法、一个主节奏；主创意系统可以包含多个相关创意节点，但它们必须共享同一品牌主张、视觉规则或情绪推进；辅助玩法只能强化这个核心，不另开新片。

## 产品角色选择器

TVC 里的产品不是“露出一下”就算完成任务。先决定产品在故事里的角色，再决定登场时机、景别和尾帧。

| 产品角色 | 适合目标 | 写法 |
|---|---|---|
| 主角 | 新品发布、强设计、强包装、单品记忆 | 产品开场就有轮廓或材质线索，中段完成一次完整动作，尾帧给清晰 packshot |
| 触发器 | 饮品、香氛、美妆、科技、汽车、运动 | 开盖、喷洒、启动、倒入、点亮、踩下等动作触发世界变化 |
| 信物 | 节庆、礼赠、家庭、情感、联名 | 产品在人与人之间传递，承载关系变化，不只是桌面摆件 |
| 证据 | 功效、工艺、科技、品质、专业 | 产品细节、使用结果、材质变化或真实场景证明主张 |
| 入口 | 品牌世界、城市奇观、艺术空间、梦境视觉 | 镜头从包装、屏幕、瓶口、车灯、鞋底或品牌形状进入另一个视觉世界 |
| 收束物 | 人物故事、公益倡导、品牌价值片 | 前段以人物/情绪为主，产品在尾段承接主张并稳定落版 |

产品角色选择规则：

- 强转化或新品发布：产品至少承担“主角”或“触发器”，不能只做尾帧露出。
- 情感和节庆：产品更适合做“信物”，通过传递、打开、分享、靠近完成情绪闭环。
- 高端形象：产品可以晚出现，但前段必须有材质、颜色、声音、轮廓或动作线索。
- 公益和社会议题：产品不能硬抢议题中心，优先作为行动支持、参与方式或品牌责任的收束物。

## 表现主体和高光主场面

TVC 的表现不一定靠演员。高级的影像表达会先决定“谁在表演品牌主张”，再围绕它设计一个主场面，而不是把人物、产品、环境、材质、文字平均剪在一起。

### 表现主体选择器

每条片只选一个主要表现主体，最多一个辅助主体。主体一旦选定，镜头、转场、声音和尾帧都围绕它推进。

| 表现主体 | 适合表达 | 写法 |
|---|---|---|
| 产品在表演 | 新品、科技、设计、包装、强功能 | 产品通过开合、悬浮、变形、释放、回归完成主张；人物和环境只负责反应或承托 |
| 环境在表演 | 城市、生活方式、品牌世界、节庆、场景心智 | 城市被点亮，房间开始呼吸，海风穿过街道，餐桌逐渐聚合；产品是触发或收束 |
| 材质在表演 | 美妆、香氛、食品、酒饮、家居、高端工艺 | 水、布、玻璃、金属、奶油、巧克力、纸张或木纹发生状态变化；材质变化就是卖点和情绪 |
| 人物在表演 | 人物故事、情感、运动、公益、品牌态度 | 动作、眼神、走位、触摸、递送完成情绪；产品不抢戏，但必须改变人物状态 |
| 文字在表演 | 发布预热、活动主题、城市营销、联名、强概念片 | 主题字长成空间、倒影、路牌、包装信息或人群队形；文字不是字幕，而是场景结构 |

表现主体的选择要服务核心表达：

- 产品在表演时，避免人物口播解释；让产品状态变化自己完成信息。
- 环境在表演时，避免场景空转；每次环境变化都要由品牌资产、产品动作或声音母题触发。
- 材质在表演时，避免只做漂亮微距；材质必须经历“触发、变化、结果”。
- 人物在表演时，避免泛泛微笑、奔跑和凝视；动作要造成关系、状态或情绪变化。
- 文字在表演时，避免贴片花字；文字要有透视、遮挡、倒影、材质或空间位置。

### 高光主场面设计

高级 TVC 往往不是很多小点子，而是一个主场面撑住全片。主场面是观众能复述的画面，也是片子的叙事重心。

```text
主场面 = 一个表现主体 + 一个异常但合理的变化 + 一个品牌/产品回收
```

主场面要能用一句话讲清：

| 品类/任务 | 主场面写法 |
|---|---|
| 香水 | 瓶口喷出的不是雾，而是一条海边清晨的风路；风经过皮肤、衣摆和植物，最后回到瓶身 |
| 鲜奶 | 杯口里长出清晨牧场，镜头拉远才发现牧场被收束在早餐桌的一杯奶里 |
| 跑鞋 | 四个城市空间被同一步伐同步折叠到同一条跑道，最后回到鞋底落地 |
| 护肤 | 面霜容器不是展示，而是像花苞一样展开成水光花影，最后回到膏体和肌肤光泽 |
| 巧克力 | 礼盒不是被打开，而是自己生长出一整盒惊喜；造型、香气和金箔逐步填满画面 |
| 汽车 | 光线不是照车，而是沿车灯、轮毂和车身线条追踪，最终把整车从暗场中揭开 |
| 饮品 | 一声开盖让沉默的空间进入节奏，冰块、气泡、人群动作和品牌色同步被唤醒 |
| 发布预热 | 黑暗中先出现声音和局部轮廓，主题字像真实装置一样被光线拼出来 |
| 节庆礼赠 | 礼盒打开后不是静物陈列，而是把分散的人、灯、餐桌和祝福合到同一场仪式 |
| 公益倡导 | 一个小行动被放大成可参与路径；画面从个人处境转向真实行动和温和倡议 |

主场面不要和片头、片尾割裂。它应该按三段推进：

```text
铺垫：先埋入表现主体和视觉规则
发生：主场面产生清晰变化，形成高光
回响：变化后的结果回到产品、品牌资产、人物状态或行动信息
```

如果一条片写出了三个以上互不相干的高光，优先删到一个主场面。其它镜头只负责铺垫、升级、呼吸和回收。

## 品牌世界改写的一拍

TVC 需要一个让观众停一下的轻反常识瞬间：正常世界被品牌主张轻轻改写。它不是随机奇观，而是把核心表达变成可见规则。

| 品牌任务 | 世界被如何改写 | 回收方式 |
|---|---|---|
| 发布预热 | 黑布、雾、水面或暗场被产品轮廓和声音一点点揭开 | 产品局部、主题字、发布信息稳定落版 |
| 自然清新 | 风、海水、叶影或花瓣从产品动作里向外扩散 | 回到产品材质、香调/成分意象或人物状态 |
| 节庆团圆 | 月亮、灯光、桂花、餐桌或礼盒互相转化，把分散人物聚到一起 | 产品和人物关系同框，祝福短句收束 |
| 年轻活力 | 品牌色或声音节拍感染静态街区，人群和物体逐步加入节奏 | 回到品牌色、产品动作或群像定格 |
| 科技智能 | 混乱的线条、声音或场景被产品动作整理成清晰路径 | 回到真实产品界面、功能状态或品牌主张 |
| 高端质感 | 光线被产品结构重新切分，空间像为产品让出舞台 | 回到材质微距、完整产品和克制 logo |
| 运动突破 | 地面、水面、风或城市速度被脚步/身体动作改写 | 回到人物状态、产品细节和一句精神主张 |
| 食品零食 | 天体、植物、城市或玩具世界被食物形态轻轻替换 | 回到真实产品、口感/场景价值和品牌记忆 |

这一拍必须能一句话复述，例如“月亮穿过云层变成夹心饼干”“一声开盖让沉默聚会进入节奏”“鞋底踩过后城市慢半拍”。复述句越清楚，分镜越不容易散。

## 时长节奏模型

TVC 的结构按时长收敛，不要把 60 秒故事塞进 15 秒，也不要把 15 秒玩法拉成长片。

| 时长/版本 | 节奏模型 | 重点 |
|---|---|---|
| 6-10 秒 bumper | 品牌线索 -> 高光一拍 -> logo/产品定版 | 只保留一个动作和一个记忆点，尾帧必须清楚 |
| 15 秒 TVC | 停滑钩子 -> 主玩法发生 -> 产品/品牌回收 | 前 2-3 秒就给视觉规则或产品线索，中段不铺太多背景 |
| 30 秒 TVC | 世界建立 -> 玩法升级 -> 情绪/产品高光 -> 主张收束 | 最适合一个完整品牌世界规则，旁白少而准 |
| 45-60 秒品牌片 | 人物/世界进入 -> 多段递进 -> 情绪峰值 -> 品牌价值落点 | 可以有人物或场景层次，但仍只围绕一个核心表达 |
| 发布预热 | 局部线索 -> 悬念加深 -> 主题显影 -> 时间/行动 | 信息未确认时只做氛围和主题，不编日期、嘉宾或卖点 |
| 公益倡导 | 具体处境 -> 行动介入 -> 微小改变 -> 温和倡议 | 克制，不消费痛苦，品牌行动要真实或明确待确认 |
| 社媒切条 | 强画面/强动作开场 -> 快速解释规则 -> 明确收束 | 首秒不能空，尾帧可短但行动信息要读得清 |
| 官网/大屏 | 气质建立 -> 母题递进 -> 视觉高潮 -> 稳定定版 | 保留空间感、音乐层次和尾帧停留 |

节奏只有一个主轴。快慢可以交替，但不能同时追求悬念、种草、公益、发布、人物故事和产品功能全讲满。

## TVC 文案和花字策略

TVC 的文字要像画面的一部分，承担叙事、转折或品牌记忆，不要用满屏解释代替画面。

| 文字类型 | 用法 | 避免 |
|---|---|---|
| 主题大字 | 品牌主张、活动主题、城市/节日/联名关键词；可成为空间、光影、纸张、水面或建筑的一部分 | 像后期贴纸一样浮在画面上，和构图无关 |
| 片中短句 | 只在转折点出现，推动情绪或解释核心动作 | 每个镜头都配一句抽象金句 |
| 产品信息字 | 新品名、规格、发布时间、预约、CTA；仅在需要清楚行动时出现 | 未确认信息、参数堆满、遮挡产品 |
| 功能说明字 | 产品动作不易理解时，用短句同步解释 | 动作已经清楚还重复说明 |
| 尾帧 slogan | 画面已经证明主张后落下，成为记忆钉 | 用 slogan 替代前文叙事 |

风格选择：

- 高端片：文字少、字号稳、留白足，颜色和材质跟随品牌系统。
- 年轻活力片：文字可以更有节拍、弹性和色彩，但必须跟动作同步。
- 发布预热：主题字和倒计时可以更强，但信息必须来自用户确认。
- 公益倡导：文字克制、具体，不用夸张恐惧和道德压迫。
- 无旁白片：用户明确要求时，或 Agent 按“完整旁白优先 -> 少量旁白其次 -> 无旁白最后”的三级规则判断无旁白更有效时可选；此时用少量主题字、声音母题和尾帧定版承担理解，不等于无表达。

## 尾帧和 Packshot 策略

很多 TVC 看完不知所以然，是因为尾帧没有把前面的情绪和玩法收成一个品牌判断。尾帧至少完成三件事：

```text
识别：这是哪个品牌/产品/活动
回收：前文核心表达如何落到品牌资产
行动：观众下一步记住、预约、购买、参与或继续关注什么
```

| 类型 | 尾帧写法 |
|---|---|
| 品牌形象 | logo/品牌名 + 一句主张 + 视觉母题稳定回收 |
| 新品发布 | 产品完整露出 + 新品名/发布日期/预约信息 + 品牌资产 |
| 产品 TVC | packshot + 核心卖点短句 + 使用场景或行动入口 |
| 联名 | 双方资产同框 + 共同主题 + 联名产品或活动信息 |
| 节庆 | 产品/人物关系定格 + 节日祝福或主题短句 + 品牌识别 |
| 公益倡导 | 品牌行动/参与方式 + 温和倡议 + 真实或待确认信息 |
| 发布会/活动 | 主题字 + 时间地点/预约/报名/直播信息 + 主办方资产 |

普通品牌或产品尾帧只稳定停留 `0.6-1.0` 秒。只有发布日期、活动时间地点、报名方式或必须阅读的合规文字较复杂时，才可按已确认阅读需求延长；背景可以继续轻微运动，但不能干扰 logo、产品名、日期、CTA 或 slogan 的可读性。

## 不可替换瞬间选择器

品牌 TVC 必须至少有一个观众能复述的品牌瞬间。它不能只是“漂亮”“高级”“感人”，而要让观众说得出“那个品牌片里，某个动作/符号/空间变化代表了品牌主张”。

选择步骤：

```text
品牌资产里有什么可被动起来：logo 形状、包装轮廓、品牌色、声音、产品动作、历史物件、人物姿态
品牌主张需要观众感到什么：信任、温暖、力量、好奇、认同、期待
把资产和情绪相撞：资产如何触发环境、人群、光线、声音或时间变化
检查不可替换性：换成竞品后是否还成立
写入高光秒段和尾帧回收
```

常见品牌瞬间：

| 品牌任务 | 可复述瞬间 | 回收方式 |
|---|---|---|
| 发布预热 | 黑暗中只有产品轮廓和声音先出现，最后完整显影 | 发布信息、预约或主题字稳定落版 |
| 品牌焕新 | 旧 logo/旧空间被新视觉规则自然替换 | 新品牌色、字标和一句主张收束 |
| 联名 | 两个世界先各自成立，再在一个动作里对齐 | 联名双方资产同框，不能一方变装饰 |
| 公益倡导 | 抽象议题落到一个人的具体处境和一个可参与动作 | 品牌行动/参与方式克制出现 |
| 年度回顾 | 档案、项目、人群和未来任务被同一线索串起 | 从过去回到当下品牌主张 |
| 节庆情感 | 产品参与仪式动作，而不是摆在桌上 | 人和产品的关系定格，祝福短句收束 |

品牌瞬间的失败信号：

- 去掉 logo 后像任何品牌都能用。
- 主张只在旁白里出现，画面没有承担。
- 产品/品牌资产只在最后 1 秒突然出现。
- 高光很美，但和品牌主张没有因果关系。

## 品牌资产参与叙事

品牌资产不能只在尾帧露出，也不能像贴纸一样压在画面上。优秀品牌片会让 logo 形状、品牌色、包装轮廓、产品动作、品牌短音、主题字或活动符号成为世界规则的一部分：它触发变化、组织空间、引导人物行动，最后再回到清晰的品牌识别。

选择品牌资产时先问：

```text
这个资产能变成什么动作？
它能改变哪个空间、人物、物体、声音或时间关系？
观众能否在品牌露出前感到“这就是这个品牌的世界”？
结尾如何回到真实、稳定、可识别的品牌资产？
```

常用资产叙事方式：

| 方式 | 适合 | 写法 |
|---|---|---|
| Logo 形状变道具 | 品牌焕新、年轻品牌、创意广告 | logo 的圆、线、箭头、缺口或字母结构先作为真实道具/空间结构出现，推动一次动作，结尾归位成完整 logo |
| 品牌色入侵 | 发布预热、节庆、社媒停滑 | 品牌色从一个小物件、光源、衣料或文字开始扩散，逐步改写环境情绪，不能只是整片套色 |
| 包装/产品轮廓成建筑 | 产品强识别、城市营销、发布装置 | 产品轮廓被放大成城市地标、门店装置、舞台或入口，让人物和镜头穿行其中 |
| 品牌声音触发 | 科技、汽车、运动、饮品 | 开盖声、启动声、脚步、引擎、通知音或品牌短音先出现，画面随声音同步启动、加速或收束 |
| 主题字成为空间 | 活动、文化、城市、预热 | 主题字不是字幕，而是建筑、水面、道路、纸张、屏幕或人群队形的一部分，有透视、遮挡、倒影和光影 |
| 纸媒/档案化包装 | 体育胜利、年度回顾、文化事件、品牌历史 | 把信息包装成报纸、票根、档案、日历、手账或展签，让文字和影像共同讲述事件 |
| 悬念后置揭牌 | 高端片、发布片、公益倡导 | 前 70%-80% 用品牌资产的局部线索建立规则，尾段完整揭示品牌；品牌后置不是品牌缺席，前段必须有颜色、声音、形状或动作线索 |

如果没有真实 logo 或 VI 素材，只能使用“品牌色方向、抽象几何、产品轮廓、主题字气质”等可修改假设；不要擅自改造真实商标，也不要生成近似竞品的未授权标志。品牌资产可以被艺术化，但结尾必须回到真实、稳定、可识别的品牌或主题信息。

## 品牌主张的可见化

品牌片不能只把“希望、长期主义、自由、自然、高级、热爱、突破、团圆”写成旁白或尾帧。每个品牌主张都要变成一个可见动作、一套视觉规则或一个情绪仪式：

| 主张类型 | 可见化方式 | 节奏写法 |
|---|---|---|
| 发布期待 | 局部线索、光影揭幕、倒计时、主题字显影、产品轮廓逐步完整 | 悬念 -> 局部 -> 轮廓 -> 主题/发布信息 |
| 高端质感 | 克制人物、材质微距、镜面/倒影、少量精准运动、尾帧呼吸 | 气质建立 -> 产品/人物入场 -> 质感证明 -> 稳定定版 |
| 自然焕活 | 水、风、花、叶、种子、晨光与产品形态互相转译 | 静置 -> 自然触发 -> 形态绽放 -> 品牌主张 |
| 节庆团圆 | 月、桂、灯、举杯、礼盒、餐桌、群像和产品仪式动作 | 产品线索 -> 场景漫游 -> 人物关系升温 -> 产品定格 |
| 运动精神 | 环境压力、身体细节、汗水、踏水、登顶、群体奔跑 | 环境铺垫 -> 动作推进 -> 细节坚持 -> 远景升华 |
| 科研可信 | 实验室、原料、研发动作、质地特写、用户使用连接 | 探索 -> 研发 -> 产品落地 -> 理念收束 |
| 品牌律动 | 自然微观、声音节拍、运动动作、画面同步变化 | 轻柔律动 -> 多场景响应 -> 爆发动感 -> slogan |

品牌 TVC 的创意玩法要像品牌世界的规则，而不是单个特效。使用光影、布料、水流、花瓣、镜面、分屏、极简空间或风格化动画时，必须写清它和品牌主张的关系：

```text
视觉规则代表什么品牌判断？
它第一次出现时建立什么期待？
中段如何升级或转向？
结尾回收到哪个品牌资产、产品、主题字或人物状态？
```

用户明确要求无旁白，或 Agent 按三级声音优先级确认画面与声音设计已经能独立讲清时，才进入无旁白品牌片；该路线仍要有表达脊椎，可以用以下方式承担意思：

- 声音母题：一组鼓点、呼吸、开盖、脚步、水声或品牌短音，随情绪升级回归。
- 画面文字：少量主题字、品牌主张、发布信息或尾帧 slogan，位置和字体稳定。
- 产品/品牌线索：颜色、轮廓、材质、包装、空间符号或动作母题前中后至少出现三次。
- 情绪仪式：举杯、行走、奔跑、开盖、托举、凝视、合拢、点亮等动作完成主张。

审片时做“去 logo 测试”：拿掉 logo 后，如果观众完全不知道这是在讲哪个品牌、哪种产品、哪类态度，说明品牌资产铺垫不足；如果加上任何品牌 logo 都成立，说明主张和视觉母题不够不可替换。

## 高质量 TVC 方法

用户提供 TVC、广告片、广告分析报告或参考视频时，必须整理成当前品牌自己的视频方案：

- 可提炼：运镜节奏、平均镜长、光线方向、构图方式、色彩段落、转场锚点、声音结构、文案节奏、卖点排序和产品露出逻辑。
- 写清“为什么适合本品牌”：例如水面倒影服务“真我释放”，低角度跟拍服务汽车力量感，噪音切断服务降噪证明，黑场尾帧服务 slogan 记忆。
- 参考里的视觉机制要换成当前品牌自己的资产、主张、产品关系和场景逻辑，不能停留在相似风格。
- 如果参考资料里有具体镜号、时长或文案，只能作为节奏和技法样本；不能照搬成当前成片的事实。

TVC 详细方案至少要落到这些可执行项：

| 维度 | 要求 |
|---|---|
| 主题 | 写成一句可被画面验证的命题 |
| 传播策略 | 明确主目标是品牌记忆、发布预热、联名认知、公益倡导、年度回顾还是社媒停滑 |
| 受众洞察 | 写清观众为什么在乎这件事，以及他们进入片子的情绪门槛 |
| 主角/主体 | 明确人物、产品、空间和视觉母题的主次 |
| 叙事结构 | 七幕、六段、三幕、视觉主导文案或旅行动机等只选一个主结构 |
| 视觉亮点 | 至少一个可被记住的神来之笔，例如 180 度倒置、水滴透镜、镜头内世界、隧道条形光 |
| 音效分析 | 写 BGM、人声、拟音、峰值和 Logo 收束；无旁白时记录三级判断依据和替代表达 |
| 产品卖点 | 卖点必须映射到画面，不只写参数 |
| 文案策略 | 少词旁白、视觉主导文案、尾帧一击、参数重复或数字否定式必须明确 |
| 色彩 | 写主色、辅助色、品牌色和段落变化 |
| 节奏 | 写快慢交替、平均镜长倾向、长镜和快切各自职责 |
| 平台语境 | 明确是信息流、官网、发布会大屏、贴片广告、门店屏还是社媒切条，并据此调整首秒信息、镜头密度和尾帧停留 |

## 叙事弧线和视觉母题

| 弧线 | 适用 | 结构 |
|---|---|---|
| 品牌故事 | 品牌沉淀、创始初心、长期主义 | 现实问题 -> 初心/选择 -> 行动证据 -> 当下价值 -> 品牌收束 |
| 形象大片 | 高端品牌、联名、焕新 | 视觉世界建立 -> 品牌资产显影 -> 情绪升级 -> 记忆点回归 |
| 发布预热 | 新品发布、活动、会议 | 悬念 -> 局部线索 -> 主题显影 -> 时间/行动信息 |
| 年度回顾 | 品牌年度、周年庆 | 时间线 -> 关键节点 -> 人群/成果 -> 面向未来 |
| 文化机构周年/艺术奇妙夜 | 美术馆、博物馆、展览、文旅空间、文化品牌周年 | 邀请/召唤 -> 导览角色或物件入场 -> 馆藏/空间逐级活化 -> 人群或作品群像汇合 -> 周年/品牌尾帧 |
| 人物故事 | 创始人、员工、用户 | 人物日常 -> 选择/挑战 -> 品牌关系 -> 价值落点 |
| 公益倡导 | 消费品牌公益广告、社会议题、品牌价值表达 | 真实议题 -> 人的处境 -> 品牌行动或参与方式 -> 温和倡导 |
| 七幕意象 | 高端美妆、香氛、时尚、自我表达 | 序章意象 -> 入场/世界建立 -> 主角动作 -> 超现实升华 -> 核心宣言 -> 产品露出 -> Logo |
| 视觉主导文案 | 汽车、运动、奢侈品；三级判断通过后的纯音乐形象片 | 细节启动 -> 空间气质 -> 动作证明 -> 情绪高点 -> 品牌主张/尾帧定版 |
| 强风格即内容 | 审美标签本身能带来传播、品牌需要建立鲜明世界观、产品/服务价值与风格规则同构 | 风格规则建立 -> 产品/人物进入风格世界 -> 风格机制证明品牌价值 -> 风格记忆回收到品牌资产 |
| 旅行动机 | 汽车、户外、家庭、生活方式 | 出发动机 -> 多场景陪伴 -> 产品细节 -> 情感价值 -> slogan |
| 工艺借喻 | 高端酒饮、家居、器物、老字号、匠心品牌 | 匠人/材料 -> 跨工艺并置 -> 自有工艺/原料 -> 产品升华 -> 品牌金句 |

视觉母题只选 1 个主母题，最多 1 个辅助母题。母题必须在开场、中段和收束至少各出现一次，且每次有信息推进；不能只是重复同一个漂亮画面。

| 母题 | 适用 | 执行方式 |
|---|---|---|
| 品牌色递进 | 品牌识别、焕新、发布预热 | 从环境低饱和色、局部反光或道具色开始，中段让品牌色进入主体，尾帧稳定到品牌色系统 |
| 形状母题 | 有明确 VI、包装轮廓、空间符号的品牌 | 圆形、弧线、切面、网格、对称结构或产品轮廓在构图和转场中反复出现 |
| 光线母题 | 科技、希望、舞台、城市、公益和发布会 | 晨光、追光、光扫、逆光、城市灯火或舞台灯承担情绪推进，不用无意义光效堆叠 |
| 材质母题 | 高端、香氛、美妆、酒饮、家居、器物 | 金属、玻璃、纸张、织物、水、雾、颗粒或木质服务品牌气质，并和产品/空间发生关系 |
| 动作母题 | 人物故事、品牌故事、生活方式 | 打开、传递、奔赴、注视、点亮、合拢、握持等动作要在故事中升级，不做空泛摆拍 |
| 声音母题 | 三级判断通过后的无旁白 TVC，或发布会、年度片中的辅助声音设计 | 一组音符、心跳、机械声、环境声、掌声或低频鼓点在关键转折处回归，形成记忆点；只有无旁白条件成立时才能替代人声 |
| 审美体系母题 | 风格强、审美标签强、需要社媒传播的话题型品牌片 | 构图、运镜、色板、表演、道具陈列、音乐节奏和转场共同遵守一套规则，让观众记住“这个世界就是这个品牌” |

母题选择规则：

- 母题必须来自品牌资产、产品形态、传播主题或用户素材；不要为了高级感临时发明无关符号。
- 同一母题每次出现要承担不同职责：开场负责识别，中段负责转折，尾段负责记忆。
- 如果母题和品牌关系弱，要在方案里解释“为什么换成竞品就不成立”；解释不出来就换母题。
- 长视频里母题可以变奏，但不能每段都重置一套视觉语言。

强风格即内容适合把“风格本身就是看点”的传播机会转成品牌资产，但必须回答“这个风格为什么属于当前品牌”。例如绝对对称、平面化正立面、横向轨道、固定机位、垂直俯拍、低饱和粉蜡笔色板、复古音乐和克制表演，可以服务“秩序、精致、治愈、可控、童话化”的品牌判断；手持晃动、倾斜构图、冷灰现场声和快切混乱，可以作为前置反差，衬托后段品牌世界的稳定与完成度。不要只借热门风格标签吸引眼球；风格规则必须和品牌主张、产品结果或受众情绪同构。

强风格执行清单：

- 构图规则：中心对称、平面化正立面、一点透视、圆环/放射、天然框架、负空间或极端视角，只选一套主规则贯穿。
- 运镜规则：横向轨道、固定机位、90 度 whip pan、缓慢推镜、垂直俯拍、稳定拉远或手持反差；每种运镜要有叙事职责。
- 色彩规则：3-6 个主色形成稳定色板，常见为粉、蓝、绿、金、奶油、红等低饱和粉蜡笔色；品牌色必须能进入这套色板或作为强调色。
- 表演和美术规则：人物姿态、服装色块、道具陈列、空间正立面和产品位置都遵守同一秩序；产品不能被风格吞掉。
- 声音规则：音乐节拍、拟音峰值和转场动作同步；强审美片也要有声音记忆，不只靠画面好看。
- 回收规则：结尾必须回到品牌资产、产品、活动主题、logo、slogan 或可行动信息；不能停在无归属的漂亮空镜。

工艺借喻适合把“品质、时间、坚持、传承、精品感”从抽象词变成可感知画面。它可以先拍人、手、工具、火、水、木、陶、金属、布料、原料等，再把这些动作逻辑转回品牌自身的产品或服务。

文化机构、艺术展览、文旅空间和周年庆可以采用“奇妙夜/空间活化”表达，但必须先锁定真实事实：机构名称、周年年份、活动主题、logo、主视觉、馆藏/展品是否可使用、艺术家/作品名称是否可出现、合作方和版权边界。未确认时只能写概念化的“艺术作品、展品、导览角色、庆典空间”，不能冒充真实馆藏、真实艺术家或真实活动信息。

文化机构周年执行规则：

- 导览角色是观众替身，可以是小角色、门票、邀请函、光点、纸花、声音线索或品牌 IP；它负责串联空间和情绪，不抢走机构或活动主题。
- 展品活化要遵循“先识别原物 -> 局部动作 -> 突破边界 -> 影响现实空间 -> 回到主题”的顺序；不能直接把所有作品变成随机奇幻特效。
- 每 3-5 秒安排一次新发现，例如画框突破、投影剪影、展柜光线、雕塑悬浮、地面倒影、群像游行、露台庆典或烟花符号；惊喜要逐级升级，不平铺堆彩蛋。
- 画面文字少而准，适合邀请函文字、展签、活动主题、年份、logo 和片尾制作信息；无对白版本也要靠动作、音乐和尾帧让观众理解这是机构/活动传播。
- 结尾必须回到可确认的品牌资产或活动资产，例如 logo、周年数字、主视觉、建筑外观、庆典群像或一句已确认主题语。

工艺借喻执行规则：

- “以人带物”不是不拍产品，而是先用人的专注和材料变化建立信任，再让产品作为这条价值链的结果出现。
- 跨工艺并置要有共同主题，例如精度、时间、打磨、选择、传承或重生；不能把无关工艺混剪成文化堆砌。
- 产品可以后段完整登场，但前段要埋入产品相关线索：主色、材质、原料、瓶身/器物轮廓、品牌语气或声音母题。
- 文案适合短句、排比、对仗和三字诀；每句要能对应画面动作，不用长篇解释匠心。
- 布光通常以暗调暖金、侧逆光、顶光、轮廓光和空气粒子塑形；构图多用手部微距、面部特写、中心对称、俯拍阵列和仪式性走廊。
- 声音以音乐为底，关键工艺动作做环境音点描；碎裂、敲击、滴落、火焰、倒入等声音可短暂突出，作为真实质感锚点。

品牌资产使用规则：

- logo、品牌色、VI、IP、产品包装、活动主视觉必须来自用户素材或已确认资料。
- 不生成假 logo、假口号、假活动名、假代言人、假联名对象。
- logo 不要过早压满全屏；可先用颜色、形状、材质和产品局部建立期待。
- 最终尾帧必须稳定，适合承载 logo、slogan、活动主题或行动信息。
- 品牌资产可以晚出现，但不能全片缺席。前段至少要有品牌色、产品轮廓、包装材质、空间符号、声音母题或人物关系作为线索。
- 联名片要同时尊重双方资产：不要让一个品牌只做背景板，也不要混出不存在的第三套 VI。
- 年度回顾、周年庆和发布会必须锁定活动名、年份、主视觉、时间地点和禁用信息；未确认时只做主题氛围，不写具体事实。
- 尾帧要能单独成立：logo/主题/CTA/日期必须清楚，背景运动不能干扰识别。

公益和社会议题要谨慎：不编造数据，不消费痛苦，不用夸张恐惧；能用具体行动和真实帮助表达，就不要用空泛口号。

公益责任片优先使用这条证明线：

```text
真实议题 -> 具体处境 -> 品牌/组织做了什么 -> 人或社区发生什么变化 -> 温和行动倡议
```

公益片不要把受助者拍成工具人，也不要用极端苦难画面制造冲击。能拍行动现场、服务流程、社区反馈和长期陪伴，就不要只拍慢动作眼泪、空镜和大口号。

## 事件和长视频

发布预热要确认具体日期、地点、主题、产品/活动名、可公开信息和禁用信息。未确认时只做氛围预热，不写具体日期和承诺。

常用结构：

```text
悬念线索 -> 主题局部 -> 场景能量 -> 品牌/活动显影 -> 时间或 CTA
```

会议大屏或发布会开场可用更宽比例和更强音乐递进；社媒预热要在前 2秒给主题或视觉钩子。

发布预热执行要点：

- 信息未公开时，用局部线索、倒计时、空间能量和主题情绪，不泄露未确认产品、嘉宾、价格、时间和合作方。
- 活动预热要把“为什么值得来/看/预约”说清，不只是堆舞台、灯光和人群。
- 会议大屏片可以更强调仪式和节拍，但仍要在前段出现会议主题、主视觉或主办方资产。
- 社媒切条要更早给主题或悬念，尾帧给预约、直播、报名、发布日期或继续关注，但具体行动信息必须来自用户确认。

30-180秒品牌片先规划全局情绪曲线：

```text
建立世界 -> 品牌出现 -> 证明/人物/事件展开 -> 情绪抬升 -> 品牌主张收束
```

中间片段不要重复最终 slogan。每段结尾要留给下一段承接的动作、光线、声音或视觉母题。

长视频品牌片的段落职责：

- 开场段：建立世界观、问题、情绪或视觉母题，不能只用无意义空镜凑氛围。
- 中段一：让品牌资产、人物、产品或事件进入，回答“这是谁/和我有什么关系”。
- 中段二：用行动、证据、故事或场景升级情绪，避免每段都重复同一句品牌主张。
- 收束段：让母题、主张、品牌资产和行动信息汇合，尾帧稳定可识别。
- 接缝：每段结尾必须留下动作方向、光线、声音或视觉母题给下一段承接。

## 文字与叙事确认

TVC 旁白默认少而准：

- 15秒：1-3 句主体旁白 + 1 句 slogan。
- 30-60秒：3-6 句主体旁白 + 1 句 slogan。
- 1-3分钟：按章节写旁白，保留音乐和画面呼吸。

实际句数必须服从主 SKILL 的台词密度和总时长上限；放不下时优先减少句数、转为画面或后期文字，不硬塞旁白。

旁白必须可朗读、可落到画面，不写“高级旁白”“突出品牌调性”这种空指令。公益和社会议题避免利用苦难、夸张恐惧或无来源数据。

独立脚本不是默认必经阶段。用户要求先审脚本，或旁白、对白、事实声明、公益表达、客户案例、功效/责任主张复杂到必须先锁文字时，才单独输出脚本文件；否则这些内容并入分镜脚本文件开头的“创意说明”和完整分镜表。

分镜脚本必须先给“全片理解”，其中包含主题、主角/主体、叙事结构、视觉母题、文案策略、声音策略、色彩策略和产品/品牌卖点映射。分段说明里每段都要写清画面推进、声音推进和品牌/产品关系；用户明确要求或三级声音判断通过时，无旁白 TVC 才改写为音乐、拟音、静默和画面文字的位置。

分段说明不能只写“建立氛围、情绪递进、品牌露出”。每段都要补一句“本段品牌核心”，并在镜头里写清它由什么证明：一个动作、一句画面文字、一个产品线索、一个声音母题、一次人物选择、一个服务结果或一个视觉规则变化。没有证明的情绪段必须合并、压缩或改写。

文字与叙事确认不能只写旁白文案。完整 TVC 分镜脚本必须同时写：

- 画面脚本：每段看见什么、谁在做什么、产品/品牌如何进入。
- 声音脚本：BGM、拟音、人声、静默和声音峰值在哪。
- 文案脚本：旁白、广告语、画面大字、尾帧 slogan 或明确“无中间文案”。
- 情绪脚本：每段情绪从哪里来，到哪里去。
- 证明脚本：产品卖点、品牌主张或服务价值如何被画面证明。

## 分镜阶段

详细分镜要强调：

- 视觉母题如何贯穿，例如品牌色、形状、动作、材质、光线方向、声音节拍。
- 品牌资产何时出现、出现多清楚、是否会被遮挡。
- 人物/产品/场景如何共同服务品牌主张。
- 转场是否来自同形、同色、同动作、声音先行或情绪递进。
- 最终尾帧是否适合品牌 logo、slogan、发布会主题或活动信息稳定停留。
- 每个镜头的声音职责：BGM、拟音、人声、静默、音量峰值或声音转场。
- 每个产品/服务卖点对应的画面证明，尤其是外观、材质、结构、配置、功能、场景和情感价值。
- 关键视觉亮点的具体执行方式，例如倒置构图、水中倒影、镜头内微缩世界、黑底微距、低角度跟拍、隧道条形光或产品爆炸图。
- 品牌动效的性格和呼吸：高端品牌少而准，年轻品牌可更快更弹，公益/政企更克制；扫光、粒子、字卡、图标和品牌形状只在品牌母题、高光或尾帧承担记忆时使用，不给每个元素群发特效。
- 品牌高光是否有完整动作弧和稳定落点：品牌符号、主题字、产品轮廓或核心人物反应出现后，要有可感知停留，不能刚出现就切走。
- 品牌动效必须写进具体秒段：由哪个品牌资产、人物动作、声音母题或产品线索触发；怎么运动；运动表示什么品牌判断；最后落到哪个资产或画面状态。不要只写“加入品牌动效”。
- 色彩是否按段落递进，不能整片只是一种单调色块。

社媒切条版要保留前 2秒停滑点；横版大屏版要保留空间感和尾帧稳定性。

## 关键帧阶段

TVC 的关键帧是在完整链路或用户明确要求中间产物时，把核心创意、品牌世界、构图、材质和高潮状态先画出来的正式概念图。短片直出 TVC 默认不展示四宫格图，而是把同一套四格创意线内化到分镜和最终 Prompt；完整链路必须按 `references/asset-generation.md` 的统一数量、分镜格位与图片合同生成四宫格，逐张展示并确认后再进入视频生成。本类型重点检查品牌主张和记忆资产是否在画面中成立。

- 分镜图：只用于辅助理解镜头结构，不能替代完整链路中真实生成的四宫格视觉关键帧。
- 关键帧：每格锁定一个可复述视觉事件、人物/产品/品牌锚点、世界规则、构图、光线、材质和动态把手；后续只有真实生成并传入图片时才以 `<图片X-第N格>` 精确引用，短片内部格位只转译为自然导演语言。
- 尾帧承接：多片段连续生成时，上一段生成完成后抽取真实尾帧，作为下一段 0 秒起始图和状态锚点。

每张图或关键帧说明必须包含：所属镜头/片段、主体、产品/品牌资产、构图、机位、光线、色彩、动作状态、声音/情绪职责、禁止项和承接关系。

## 片段和成片阶段

批次参数确认在提交生成前完成；本节说的是生成完成后的片段产物展示。视频片段阶段展示的是已生成片段，不是用“准备生成”的说明冒充结果。每段至少说明：

- 本段职责：开场、建立、证明、转折、高潮、过门或收束。
- 本段覆盖时间：例如 00:00-00:15。
- 片段结果：视频预览或可用文件。
- 承接关系：上一段尾态、本段首态、本段尾态、下一段如何接。
- 声音关系：BGM 是否延续，是否有声音桥、静默、拟音或 Logo 声。
- 尾帧承接：非最终段抽取哪一帧作为下一段 0 秒起始图。

成片阶段完成拼接、用户已要求的字幕/花字、平台版本或封装后直接交付完整视频。成片阶段不得临时重写脚本或新增卖点；如果用户指出上游问题，回到对应阶段返修。
