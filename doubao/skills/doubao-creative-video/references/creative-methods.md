# 创作难题查阅：改内容，不另跑一套流程

先按[第一阶段](creative-core.md)与当前类型写同一套方案；只有遇到具体困难时查本文件，把方法直接用于相应段落。不新增卡片、评分、多方案选优或必配机制；效果如何实现查[视觉方法](visual-motion-playbook.md)，怎样拍与听查[视听工艺](audiovisual-craft.md)。

## 内容怎样往下发展

先判断是哪种连续关系，再改断点：

| 关系 | 后段应接什么 | 不要误用 |
|---|---|---|
| 论述 | 前段的疑问、理由、条件、例子或修正 | 不能用“更、不止、因此”掩盖跳题 |
| 人物行动 | 前段结果、人物已知信息及现在的目的 | 不让道具瞬移、人物突然知情，不能无故重复失败 |
| 演示与判断 | 同一任务里的后续操作、可判断结果或影响选择的新条件 | 多机位拍一次取放不算多层证明 |
| 解释与学习 | 关键关系、推理步骤、表示对应或适用变化 | 不能靠报术语、快动画替代解释 |
| 蒙太奇与对照 | 同一主题的不同侧面或可比较差异 | 不必假称前一人动作物理触发后一人 |
| 音乐与视觉 | 段落、动作组合、声音关系、感官层次或空间发现 | 不把每拍切镜当推进，不强制情绪三段或反转 |

先改选材和关系，再分配时间。重复能积累理解、节律或情绪时可以保留；仅重复已知结论就合并。多个相关看点可以共存，先后有联系即可，不设主辅数量和每镜单一职责配额。局部完成作用后可以结束，不强求所有元素贯穿或片尾回扣。

## 语言怎样改

断裂先补意思，不先润色。把实际人声连读：谁在讲什么，后句为什么现在出现，省略的对象能否找到，当前的结论有没有理由。拿不准时先用普通完整句说清，再按当前说话关系提炼。

对白检查对方会如何回应，而非两个人轮流报主题。口播检查判断、观察与解释是否接续；品牌旁白允许提炼、排比和诗性，但整段仍发展同一个意思；教程需要的动作与核对可以直说，不为避免“说明书”而删关键信息。

句子刻意时，找作者额外加的意图：是不是为了押韵改变搭配、为了金句突然总结人生、为了“真实”假装犹豫或惊讶、为了低广告感聊无关生活。去掉这层加工，保留当前人真想说的内容；不靠全句变短、塞语气词修补。更完整的语言规则只在[连写文案](creative-core.md#连写文案及声音职责)维护。

## 短 brief 自动扩写

用户常常只给一句很短的需求，例如“做个鲜奶广告”“给这双鞋做个视频”“生成一个品牌预热视频”。不能因为 brief 短就输出普通展示片，也不能反复追问参考视频、脚本或风格。除非真实性、授权、素材或工具执行被阻断，否则默认由 agent 主动扩写成一个完整、有惊喜但仍贴合用户指令的视频方案。

短 brief 先按[第一阶段](creative-core.md#第一阶段创作方案)写成立；以下只补充寻找具体切入点的方法。合理推断保留为可修改假设。

扩写原则：

- 贴合用户原意，不擅自改变品类、品牌、真实产品外观、核心任务或交付目标。
- 主动补足平台、比例、时长、节奏、文案、声音、拍法和结尾。展示位置、受众等创作条件需要推断时，说明这是本次假设；未知的产品功能、材质、体验和企业事实不能靠假设补成真实卖点。
- 惊喜来自“熟悉主体的新观看方式”，不是凭空加入无关剧情、角色或过度复杂世界观。
- 先试写具体内容，再概括这条片讲什么。例如写早餐桌上的鲜奶，就继续写谁在倒、另一人怎样回应、这个细节怎样改变接下来的早餐；不能只把“新鲜”改成一句漂亮口号。未确认的产地、工艺和口感不补成事实。
- 不因缺少素材而退回“产品静态旋转 + 卖点字”。没有素材时，使用概念化产品、场景化动作和可替换视觉规则；真实 logo、包装、价格、认证和功效仍需用户确认或素材支持。

内容仍普通时，按第一阶段定位当前方案缺少的具体观察、解释或回应，直接改写相关段落；不另跑多方向筛选。简单图片动态从指定内容和原图中选择可成立的动作，不额外编故事。

给当前方案增加细节时，看它们能否与已有内容接上。例如同一个包装机关连续打开、同一个动作引起接下来的空间变化，都可以连用；另一个不相关的奇观只会打断原来的内容，就不要加入。不是每个细节都必须贯穿全片，但每个留下的细节都应帮助当前事件、解释、笑点或情绪。不要为了“有创意”加入无法交代前因后果的东西。

## 完整 brief 的增补边界

用户给得完整时，先判断是否还缺事件前提、证据、自然表达或制作信息。只补实际影响理解与执行的部分；已经成立的脚本不另加玩法、曲线或剧情，明确锁定的内容保持原样。

沿用用户已经成立的核心、情节与表达，只补实际缺口；先锁必须覆盖项，再补导演细节，并删除会抢主线的增补。

增补规则：

- 不改变用户明确指定的产品、品牌、人物、事实、卖点、风格、镜头、口播、时长、比例、平台和禁用项。
- 用户明确要求覆盖多个卖点时，选一个主卖点作核心，其余按作用接入辅助证明、画面细节或连贯口播；尾帧仅保留已经交代且来得及读清的必要信息，不集中首次介绍新卖点；普通产品资料按观看任务取材，不自动逐项展示。
- 用户给了完整脚本时，可以优化镜头调度、节奏停顿、声音设计、视觉隐喻和过渡方式；不要擅自改成另一个故事。
- 用户给了参考片时，迁移其“作用机制”，例如尺度反转、光影揭幕、第一视角动作链、分屏汇聚、语义幻变或城市空间合成；不要照搬具体角色、画面、文案或商业事实。
- 增补必须让成片更聚焦、更可看、更可复述。不能为了惊喜加入和核心无关的新角色、新世界观、复杂支线或未经确认的品牌声明。

增补是否有效，用下面的关系判断；

```text
我新增的创意/镜头/声音让观众更清楚地相信或感到：[核心表达]，因为它让他们看见/听见：[具体变化]。
```

## 策略迁移适配总则

通用策略可以用于任何场景和类别，但不能原样套用。迁移适配不另填表，只确认五件事并直接改写进镜头：

```text
服务目标：
当前主体：
触发动作：
可见/可听结果：
证明、回收与风险：
```

迁移规则：

- 保留策略作用，替换表层对象。不要把一个食品广告里的“咬下声波”照搬到 SaaS；应迁移成“点击后任务卡片按节拍归队”。
- 先问策略服务什么：停滑、解释、证明、种草、品牌记忆、信任、情绪还是 CTA。服务不清的策略不用。
- 视听各项服务当前内容：构图组织注意，色彩建立关系，声音可参与动作、论述或感受，切换可承接信息、对照、章节或物理动作。文案也可主导表达，不固定为画面的补充说明。
- 类型文件负责适配边界：产品广告让人认识产品并留下本次要传达的印象，涉及功能主张时有依据；UGC 回到人的连续、可信表达；品牌 TVC 让表达与品牌建立联系；企业商务按能力、招聘、回顾、会议等实际用途组织事实与主题；知识讲解按理解与操作任务组织；通用创意按音乐、观察、艺术、记录或循环完成体验，不强制情绪回环。
- 好的迁移会让策略换到别的产品或类型后必须重写。如果只替换产品名还成立，说明它仍是通用空话。

策略落地自检：

```text
观众第一秒看见什么？
中段看见什么新信息或新证明？
最可复述的画面是什么？
声音在哪个动作上加分？
构图和色彩如何帮助理解？
结尾回收到哪个真实资产或结果？
哪些内容因为事实、授权、文字或模型风险不能写？
```

策略进入 PE 时必须变成秒段动作，不能停在策略名。凡使用叙事策略、视觉母题、动效、转场、声音设计、文案动作或强风格，都要在对应时间段写清：

```text
时段：
触发点：
谁/什么在动：
怎么动：
为什么这样动：
观众看见的新信息：
镜头/构图/光线：
声音或静默：
落点/停留：
禁止项：
```

禁止只写“加一个动画效果”“增加动感”“使用高级转场”“做品牌化表达”“体现科技感”“突出产品卖点”。这些句子必须改写为可生成、可检查的动作，例如“0.8-1.4 秒，手指点下真实 UI 的导出按钮，三张任务卡从右侧以错峰减速嵌入列表行，最后一张落位时有轻 click，列表顶端状态从处理中变为完成，停 0.4 秒让完成状态可读”。

## 跨案例通用母题

从参考视频和用户给出的创意例子里，先抽取能迁移的母题，再决定是否落到具体类型文件。母题不是案例名，也不是可直接粘贴的 prompt；它回答“这个创意为什么能被记住”，再改写成当前主体、证明锚点、声音和收束方式。

| 母题 | 核心作用 | 可迁移写法 |
|---|---|---|
| 从容反差 | 用稳定主体对抗失控环境，制造荒诞、优雅、幽默或高级掌控感 | 主体保持克制动作，外部压力逐级升级；结尾回到主体状态、产品结果、人物气质或品牌姿态 |
| 导览奇遇 | 用一个角色、物件、声音或光点带观众穿过信息/空间，降低理解成本 | 引路物每到一站触发新发现；适配到产品可变成包装、光标、数据卡或手部动作，适配到企业可变成一条流程线 |
| 静物活化 | 让艺术品、展品、包装、UI、文字、数据或工具从静态对象变成行动者 | 先保留真实识别点，再让局部突破边界并影响现实；结尾解释它为什么属于当前主题 |
| 多源融合 | 两种声音、风格、文化、年代、角色或使用场景先各自成立，再融合出第三种结果 | A/B 各有颜色、节奏、符号或动作；中段对齐、叠加、冲突；高光给融合后的新状态 |
| 数据化观看 | 把人、穿搭、产品、空间或流程变成可测量、可比较、可拆解的对象 | 用标注线、角度、编号、图纸、UI 面板或分层卡片解释结构；真实数据缺失时只写概念标签 |
| 文字成为主体 | 文字、歌词、口号、标题或关键词不再解释画面，而是直接参与运动和构图 | 关键词运动等于语义本身；字号、颜色、反相、遮罩、裁切和留白都服务节拍或主张 |
| 文字入构图 | 地名、品牌词、产品名或主张成为画面结构的一部分 | 文字占据下三分之一、背景带或透视面，和主体线条、色彩、倒影、阴影或材质呼应；它不是字幕，必须帮助观众记住主体 |
| 框架入口 | 画框、窗框、门框、屏幕、包装口、杯口或输入框成为进入下一层世界的门 | 每次穿过框架都出现新信息，不能只做漂亮转场；入口最终要回收为真实资产或主题边界 |
| 逐级升级 | 从单点变化扩展到群像、空间、系统或庆典，让观众感到规模变大 | 每一级必须新增信息、证明或情绪，不只是更多特效；高潮后要有稳定识别落点 |
| 空间折叠/海报化世界 | 把真实地点、建筑、产品或空间折叠进一张强风格视觉海报 | 先保留稳定熟悉锚点，再分层替换背景、地面/倒影、前景剪影、光源和大字；结尾回到主体身份、地点名称、品牌资产或教程机制 |
| 展示→揭秘 | 先用完成效果停滑，再解释它如何被做出来 | 开头直接给最终视觉或结果；中后段揭示图层、素材、时间线、核心参数或操作逻辑，揭秘必须教会关键机制，不能只甩一张界面截图 |
| 首尾回环 | 结尾回到开场物件、动作、声音、颜色或构图，但意义已经改变 | 开场埋线索，中段让线索变形或升级，结尾用同一元素完成答案、记忆或 CTA |

母题迁移时优先问四件事：

- 它负责停滑、解释、证明、情绪、记忆还是转化。
- 当前视频里哪个真实主体能承接它，不能只用抽象特效承接。
- 它的声音同步点在哪里，是节拍、动作、拟音、静默还是人声。
- 结尾回到什么：产品、人物、品牌、企业事实、活动主题、空间身份或一个可复述画面。

使用母题组织记忆时，保留一个主要回收线索，辅助母题只按职责采用，不另设数量配额。母题之间要有主从关系，例如“导览奇遇”为主，“静物活化”和“框架入口”服务空间发现；“多源融合”为主，“文字成为主体”和“首尾回环”服务音乐节拍。不要把所有母题堆进一条片。

## 本片要交付的核心内容

本节帮助把“高级、温暖、专业”等宽泛词写成具体内容。只在意思仍不清楚时查，不另交一张表，也不要求所有视频都改写现实规则：

```text
想讲什么：观众看完明白或感到什么
根据是什么：什么操作、事实、人物行动或回应支撑它
怎么呈现：直接演示、人物故事还是其他方式；需要特别拍法时再选
结尾是什么：哪个结果、回应或画面接住前文，观众怎样认出当前主体
```

如果只剩“画面高级、很可爱、很治愈、很有科技感”，但说不出观众要记住哪一个产品利益、品牌判断、人物状态或行动理由，必须重写。视频可以少文字或极简；声音路线及节奏例外按分镜合同。采用无旁白时，动作、声音、转场和产品/品牌回收仍需共同讲清核心。

核心表达落地规则：

- 一个视频建立可跟随的共同任务、主题或核心表达，相关卖点、人物、情绪和玩法按作用连接。核心不等于只留一个卖点，也不要求不同特点都证明同一句结论；保留与当前任务相关的有效信息，安排主次，不把天然、科技、高级、优惠、礼赠、生活方式和品牌理念无联系地平均塞满。
- 开场看点可以来自问题、结果、产品线索、异常规则、人物动作、声音钩子或品牌世界入口。按当前节奏 profile 检查，不为套商业模板擅加冲突、人物或场景。
- 中段不能只换景。按片子需要增加依据、操作结果、发现、人物回应或情绪变化；不要求每次切镜都证明一个卖点。
- 关键内容要有足够注意力，可以在发现、结果、回应或连续的声画体验中成立；不必另造一次变身、集体汇聚或片尾金句来充当高光。
- 结尾不临时堆入需要重新解释的复杂信息；必要的新条件、观点或证据前移到相关内容处展开，再回收产品/品牌/人物/企业事实/主题字/行动入口，让观众知道刚才的创意属于谁、说明什么、下一步是什么。不能为简化结尾直接删掉本片应保留的信息。

## 从产品特点到具体展开

本节只在广告已有特点、却仍不知道怎样拍得值得看时使用。“展开方法”指内容怎样展开，不是一句必须写出的修辞、口号或另一份策略卡。其他用途按第一阶段和对应类型写法处理。

先把特点放回本次观众的生活、判断或感官里：它在什么具体时刻值得注意，什么结果或感受值得亲眼看见。围绕这一处组织观看，可以让观众等一个结果、跟一次选择、发现被忽略的关系，或进入一段由商品形态和声音形成的体验；不要求都先演困难再解决。

再写实际呈现：谁正常地做什么，观众先知道什么、后知道什么，哪些动作或声音共同使这项特点被理解或感到。角度可以来自人物与观众的知情差、尺度、观看位置、画面与说话的关系，或者声音来源；选当前内容成立的一种，不逐项叠加。一个直接演示已经足够吸引且支持判断时就保留，不能为了“展开方法”再加幻想。

用普通工作语言把这条展开讲清，能指导拍摄即可。创意阐述、图形隐喻和实际人声分开写：观众通过画面看懂的变化不必再变成一句抽象旁白。画面仍只有常规操作、文案却声称世界或生活发生巨变时，回改取材或呈现，不继续润饰那个说法。

不能只靠包装触发一次笑点就认定产品关系已成立。视觉化可以表达主观感受，不能代替实际功能、来源、功效或成果的依据；物理过程、比较与 UI 能力按当前事实保留。不要因为一种比喻容易连镜头，就把它当成所有品类的首选。

## 产品与表现方式的适配

玩法不是“这个品类常用什么”，而是“当前核心如果不用这个玩法是否还成立”。已有表达准确时直接深化；表达不清或缺乏记忆点时，用以下四问找当前写法的具体问题并修改：

```text
1. 这个玩法是否由当前产品/品牌/人物/场景的独特结构触发？
2. 这个玩法是否让核心表达比直说更清楚？
3. 这个玩法是否能产生一个观众可复述的画面？
4. 拿掉当前主体的使用、结构、资产或主题条件，玩法是否仍几乎不变？
```

判断结果：

- 前三问能回答，且当前主体的具体条件确实决定触发、发展或回收，可以作为主玩法；不以同品类能否借鉴判断绝对独占性。
- 前三问能回答，但第四问显示主体只被贴在结尾，应改写实际联系，或仅保留为辅助表现。
- 只能回答“好看、梦幻、高级、治愈、科技感”，不是玩法，是风格词。

改写方法：

| 当前写法的问题 | 缺了什么 | 可以怎样改 |
|---|---|---|
| 鲜奶只有牧场空镜与包装 | 观众不清楚这些景物与当前产品有什么关系 | 有已确认来源时展示相应过程；要做视觉片，可把来源沿杯口或奶流引到包装，不凭空造产地 |
| 跑鞋只是轮流换人跑 | 人数增加了，动作、体验或观点没有变化 | 围绕已知结构或本片主题写不同的实际反馈、人物选择；视觉化脚步时说明它怎样改变后续画面 |
| 护肤只有水光花影 | 没看清质地、使用，意象还可能暗示未证实效果 | 展示取用、延展等已知过程；需要意象时围绕可见质地设计，不用花影代替功效依据 |
| 清洁画面直接从脏切到干净 | 缺少操作、条件与可判断的结果，不是因为前后对比不够新奇 | 展示同一处污渍的实际处理和结果，保留影响判断的步骤；真实证明已清楚有效时，不强加“污渍退潮”特效 |
| 3C 只是悬浮旋转配夸奖 | 没让观众看清本次真正要讲的结构、动作或特点 | 选择相关细节、实际操作或可感声音组织揭示；外观展示本身就是任务时，保留能看清设计的镜头，不强行编功能故事 |

## 反常识一拍

当当前内容需要打破预期或加强记忆时，可寻找一个“正常世界被轻轻改写的瞬间”。真实演示、清楚证明或人物选择已有效时不强加这一拍；采用时既要让观众停一下，也要更理解核心表达。

反常识一拍的生成步骤：

```text
观众默认预期：他们以为会看到什么
反向动作：把默认预期中的一个物体、尺度、因果、视角或时间关系反过来
产品/主题因果：为什么是当前主体触发
证明回报：它让核心表达更清楚的地方
安全边界：它不能暗示未经证实的真实功效或事实
```

可改写变量：

| 变量 | 普通预期 | 反常识一拍 |
|---|---|---|
| 尺度 | 产品在场景里展示 | 场景被产品尺度改写，产品最后回到真实尺寸 |
| 因果 | 人使用产品后有结果 | 环境先对产品动作产生反应，再回到真实结果 |
| 来源 | 原料被介绍 | 原料或源头从产品内部、杯口、包装或屏幕里出现 |
| 时间 | 按步骤演示 | 先给结果，再让画面倒回触发动作 |
| 视角 | 旁观产品 | 从包装、液滴、脚步、污渍、光标或声音的视角看世界 |
| 材质 | 真实物体保持原样 | 世界按产品质地重构，例如毛毡、积木、奶油、金属、纸模 |
| 语言 | 文字解释卖点 | 文字、logo、参数或 UI 自己行动并完成证明 |

反常识一拍必须落到分镜里，不能只写在创意阐述里。至少明确：

- 出现在哪一秒。
- 谁触发。
- 画面怎么变化。
- 声音怎么配合。
- 变化后观众多相信了什么。
- 下一个镜头如何回到产品/品牌/人物/行动。

## 具体问题与改写

方案出现“普通、散、不像一条片”时，查对应问题并修回当前母版；不设优秀程度、分数或与另一版本比较的环节，也不逐阶段重复检查。

| 问题位置 | 当前内容需要做到什么 | 出错信号 | 修法 |
|---|---|---|---|
| 核心表达 | 一句话能说清观众记住什么 | 只剩卖点词或氛围词 | 回到具体观看内容，重写实际展开 |
| 玩法必要性 | 玩法由当前主体触发，不易替换 | 换成任何产品都成立 | 找产品结构、使用动作、场景阻力重新触发 |
| 可复述内容 | 观众能说出具体发现、选择、反应或画面事件 | 只有好看镜头，没有值得记住的内容 | 找有辨识度的观察、演示、回应、关系变化或视听事件，不默认添加变身或反转 |
| 证明关系 | 行动、过程或论据支持相应结果 | 结论无依据、行动无后果 | 补缺失的验证、前提或反馈；物理作用才检查触发与接触过程 |
| 节奏重点 | 关键证明、发现或情绪有清楚落点 | 内容没有主次，重复停留 | 删无效过门，把时间与视听重点让给关键内容，不强求最大特效变化 |
| 收束落点 | 结尾知道属于谁、证明什么、做什么 | 看完只记得特效 | 稳定产品/品牌/人物/结果/CTA，尾帧不再新增卖点 |

对应问题仍未解决时，直接修改内容，不简单加特效：

```text
核心太虚 -> 选出当前任务值得讲的具体内容与依据
玩法太泛 -> 让当前主体的特点或处境实际影响表达
内容不记忆 -> 找具体观察、有效发现、人物回应或视听事件
因果断裂 -> 补前提、行动后果或论据，物理变化再补触发与过程
节奏平 -> 检查是否真有发现、选择、验证或情绪变化，再安排强弱与停留
结尾散 -> 把必要新信息前移到相关内容处展开，去掉无关增补与重复，再完成稳定落点
```

## 多种手法怎样围绕同一内容

创意收束要求相关内容围绕可跟随的共同任务、主题或明确关系安排主次，不要求整片只有一种速度、一个情绪或一种手法。每条片可以有多个相关创意节点、辅助玩法、辅助策略和局部小高潮；它们与当前任务或主题有清楚联系即可，不要求不同特点都证明同一句结论。多个创意可由同一任务链、相关论据、人物回应、明确对照或连续反应连接；采用统一字体、包装、空间、声音或材质系统可以帮助识别，但形式相同不能代替内容关系。

主辅关系混乱时，可用下面的提问整理已有内容，结论回到同一方案，不另建独立卡。辅助项全部按需，没有就省略，不要求配齐三项或另造全局世界规则：

```text
主核心：
主创意系统/全局规则：
强弱与节奏变化：
相关创意节点：
辅助职责 1（按需）：
辅助职责 2（按需）：
辅助职责 3（按需）：
哪些镜头只是无关增补或重复，需要删并；哪些相关信息需要重排或补足：
```

主创意系统负责建立观众记住的视觉事件；相关创意节点负责把这个系统分阶段建立、升级、转译和回收；辅助职责只负责停滑、过渡、证明补强、情绪升温、尾帧记忆或平台适配。例如鲜奶可以用“牧场源头到产品”做主系统，奶牛节拍、奶浪路径、包装显影都围绕“源头进入产品”递进；也可以用“包装生长生成”做主系统，牧场晨光和奶牛只作为源头证明。不能同时让奶牛舞蹈、种子发芽、包装生成、牧场全流程、产品悬浮和家庭早餐都互不承接地争当主线。

主辅关系判断：

- 主创意系统删掉后，视频核心就不成立；辅助职责删掉后，视频仍成立但少了一层趣味、节奏或证明。
- 主创意系统贯穿开场、中段和结尾；相关创意节点按建立、升级、转译、反应或回收承担不同职责。
- 节奏可随线索、证明、情绪和结果变化；从悬念转演示时解释观看任务怎样承接，不无缘由插入另一种片子或促销信息。
- 辅助机制按实际需要使用，说明它主要帮助停滑、解释、证明、情绪、记忆、转场还是 CTA；同一手法可以兼具相关作用，不拆成多个机制凑数，也不为数量硬加。
- 创意与当前表达有清楚关系：物理事件保住因果，论述保住推理，音乐/图形保住段落与视觉联系。局部效果可完成职责后结束，不要求都触发世界变化或在结尾再现；不能以无关特效填充内容。

## 参考玩法的深层迁移

参考视频里的“玩法”不能照搬；方案可以列来源和采用理由，故事本身须重新创作。它们要被拆成深层机制，再长到当前主体身上。常用机制按职责选择：

| 机制 | 负责的核心表达 | 迁移写法 |
|---|---|---|
| 光影揭幕 | 发布、预热、高端、神秘感 | 用遮挡、轮廓光、布料/雾/反射逐步释放局部信息，结尾完整揭示产品或主题 |
| 自然生长 | 天然、长期主义、纯净、生命力 | 从种子、水滴、藤蔓、纹理或信息元素长出产品资产，让“来源”变成“结果” |
| 形态幻变 | 焕活、升级、食材来源、节庆联想 | 一个真实物件顺着形状、材质或语义变成产品，不靠硬切解释 |
| 自主编舞 | 产品丰富度、精致感、模块能力 | 产品、零件、巧克力、耳机、建筑模块或 UI 卡片自己运动、归位、填满或悬浮 |
| 材质世界化 | 感官、童趣、治愈、风格记忆 | 把产品或主题所在世界统一改成羊毛毡、积木、黏土、纸模、零食田园等材质规则，并让任务在这个世界里完成 |
| 行为触发魔法 | 宠物、人物、手部、用户动作带出产品 | 好奇、开盖、点击、捞起、喷洒、咬下、拉扯、系鞋带等动作触发变化，变化必须回到卖点 |
| 物理小高潮 | 酥脆、弹性、稳定、分量、清洁力 | 堆叠、微晃、弹出、拉伸、分解、回弹、归位制造短促爽点，再稳定展示结果 |
| 源头到产品 | 新鲜、可信、工艺、供应链 | 从牧场、原料、实验室、工序、冲泡、灌装或服务流程线性走到产品和结果 |
| 并行汇聚 | 多人、多场景、多 SKU、多身份适配 | 分屏或多线并行展示不同使用者/场景，最后汇聚到同一产品、品牌主张或行动 |
| 沉浸体验 | 户外、香氛、咖啡、运动、露营、生活方式 | 用第一视角、真实动作、环境声和身体节奏，让观众感觉自己正在使用而不是观看广告 |

选择机制时，用下面三个问题检验适配；答案直接进入现有事件和镜头：

```text
它由当前主体的哪个真实动作触发？
它证明或放大哪一个核心判断？
它最后如何回到真实产品/品牌/人物/行动？
```

如果无法回答，就不要使用该玩法。创意机制不是“再加一点有趣”，而是表达核心的主语法；它要替代空泛讲述，让观众凭一个画面记住“为什么是这个产品/品牌/主题”。

## 吸引力机制、角度和钩子

吸引力不是“更炸、更电影感、更反常”的堆叠，而是观众愿意继续看的理由。先找到当前观看承诺，再按需用下面方法补强；它和后续证明或情绪回报连上即可，不另设一个必填“主吸引力机制”。

| 机制 | 适合解决 | 使用方式 |
|---|---|---|
| 未完成信息 | 停滑、悬念、揭示 | 开场给结果、异常或问题，中段补原因，结尾回收答案 |
| 感官承诺 | 食品、美妆、材质、空间、生活方式 | 用声音、光线、微距、触感和动作让观众感到“看得见体验” |
| 身份投射 | 品牌、时尚、生活方式、招聘 | 让观众看见自己想成为的人、状态或圈层，不只展示物 |
| 反差纠正 | 教学、评测、转化、B2B | 先呈现误区或旧方式，再用可见证据完成转向 |
| 世界规则 | 概念片、TVC、产品大片、AI 视频 | 改变一条现实规则，让产品/主题成为触发原因 |
| 任务推进 | SaaS、工具、企业服务、教程 | 一个动作带来一个反馈，观众能跟着完成判断 |

角度先于脚本。先定“从哪里看这件事”，再写台词、镜头和 prompt：

| 角度 | 适用 | 执行重点 |
|---|---|---|
| 痛点解决 | 转化、工具、个护、家电 | 开场给真实问题，证明要具体，结尾给单一行动 |
| 结果前置 | 短视频广告、爆款剪辑 | 先给变化后补过程，避免结果和产品因果断裂 |
| 第一人称体验 | UGC、旅行、运动、游戏、空间 | 镜头和声音要像身体在场，不能只写旁观描述 |
| 物品视角 | 产品广告、包装、餐饮、家居 | 让产品/包装/空间成为见证者，最后回到真实主体 |
| 专家/创始人 POV | B2B、教育、科技、专业服务 | 可信表达优先，视觉创意辅助解释，不伪造资质 |
| 生活方式切片 | 品牌、香氛、服饰、食品 | 场景和人物选择要传递气质，卖点融入动作 |
| 反常事件 | 概念片、TVC、停滑广告 | 反常必须有规则，不能只靠随机奇观 |

钩子要同时回答三件事：谁被打中、看见什么、为什么继续看。不要把钩子写成一句空泛标题；要落成首镜动作、首句台词、首个声音或首个画面规则。

## 叙事节奏与重点

本节判断内容怎样递进，具体镜长与强弱波形在视听工艺中安排。下面是可替代的推进方式，已有清楚结构时不再另选一条“主叙事曲线”。

叙事薄弱时，先改相邻内容的关系，不先增加事件数。按当前缺口选用下表，不要求每条片配齐这些手法，也不另产诊断表：

| 当前缺口 | 改写内容关系 | 成立的依据 |
|---|---|---|
| 开场抓人，后面却像另一条片 | 让后续回答开场引出的具体疑问，或发展同一种感官、动作与声音关系 | 开场的吸引力在后文得到实际兑现，不靠无关奇观引流 |
| 中段一直在说明同一件事 | 前一结果带出尚未回答的条件、下一次选择或新的观察；材料只够一次展示时就把这次展示讲透 | 观众的判断、期待或体验继续发展，而非只换机位和形容词 |
| 人物轮流做事，情绪却不成立 | 写清当下目的、对方的具体回应，以及这次回应怎样影响下一步选择 | 人物行为之间有影响；不为冲突让角色无故犯错，也不强加牺牲或煽情 |
| 证明像预先宣布答案 | 先让人明白判断对象和必要条件，再看关键过程；结果可以确认、限制或修正原判断 | 观众能从依据得到结论，而非只听到人物赞叹或成功提示音 |
| 反转突兀，靠片尾解释 | 将必要线索放进前面的动作、构图或声音；揭示改变线索的理解，而非推翻已发生事实 | 回想前文能说通，角色知情范围和真实事实仍成立 |
| 结尾只剩通用口号 | 结束当前操作、选择、论述或乐句；需要品牌归属时让已建立的联系在此清楚 | 观众得到本片承诺的结果或感受，无需临时增加人生总结 |

例如虚构的人物片中，“一人说不用等，另一人还是等了”只是结果概括；可以让前者嘴上催促、手里却还在整理两人的物件，后者已经走到门边，看到后把钥匙放回桌上。动作、注意与回应使关系可见，不必再加一句“陪伴就是答案”。广告采用这类写法时，产品或品牌仍须与本次任务建立有依据的联系，不能用一段温暖小事替代产品介绍。

| 曲线 | 适用 | 节奏写法 |
|---|---|---|
| 快速证明 | 产品广告、工具、短视频转化 | 1-3 秒给问题或结果，随后按当前判断组织证据，不以每镜一个点限制连续动作 |
| 逐级升级 | TVC、产品大片、概念片 | 让选择的后果、证据力度、任务难度或对规则的理解递进；视听强弱服务变化，结尾收束 |
| 先慢后快 | 发布、开箱、揭示、仪式感产品 | 前段建立期待，中段触发，后段加速兑现 |
| 快后留白 | 停滑广告、情绪片、品牌记忆 | 前段抓住注意力，尾段让主张、产品或 logo 稳定停留 |
| 平行碰撞 | 对比、前后变化、多受众 | 两套状态交替推进，在当前内容需要时汇合，也可用对照关系结束 |
| 循环回环 | 品牌片、概念片、音乐卡点 | 叙事回环让同一物件、动作、声音或颜色出现新含义；纯运动/音乐循环按末首相位与声音能否接回判断 |

节奏规则：

- 理解、承接与内容充实须同时成立，具体按[视听工艺](audiovisual-craft.md#理解承接与内容充实同时成立)。每次变化都能定位当前主线、说明前后关系，并让必要信息可被感知；密度不足先重排和丰富相关内容，不增加无关支线。删并无效镜头后补足有效发展，保留主要信息和原有密度要求，不靠减内容、减镜数或默认舒缓获得表面连贯。
- 默认采用利落、持续推进的多镜节奏；舒缓或一镜到底仅在用户明确要求时采用，不由类型名决定。温暖叙事、克制高端、材质、仪式和留白仍可成立，但须有持续的发现、回应或状态变化，不能自行降低全片密度。
- 镜头密度和信息密度要分开判断。可以快剪但信息少，也可以慢镜但证明强；不能把快剪当创意，或把慢镜当高级。
- 镜头数量和剪辑成立也要分开判断。切镜须有内容理由；物理连续动作保护身份、方向与状态，蒙太奇可以用因果、对照、论据递进、时间或章节关系直接承接，不强加同物锚点或特殊转场。具体按视听工艺的镜间连续性规则；只为凑数换角度时应合并或改为镜内调度，再补足主线所需的有效内容，不能用合并回避[默认变化与叙事密度](audiovisual-craft.md#默认变化与叙事密度)。
- 长镜的具体时长边界按分镜合同；慢推、拉远、主体渐大、环绕、发光、悬浮或人物微动只能辅助有意义的状态变化，不能单独支撑停留。
- 叙事中相同动作、表情、构图或结果再次出现时，应带来升级、反应、对照、答案或新意义。音乐复现、感官节律与纯运动循环可以依重复成立，检查变奏、观看职责或末首接续，不强加剧情改变；无职责地重复已知结论才合并。
- 每个醒目人物、物品、场景和 B-roll 必须服务核心表达、证据、关系、情绪、转场或回收。无法回答“为什么此刻看它”的插镜即使好看也要删除，不能用无关道具或随机人物制造表面丰富。
- 物理因果或人物反应构成的高光保住“前提/触发 -> 变化 -> 反馈”，需要辨认的结果给看清时间。概念、文字、音乐与对照高光保住语义、观看或节律关系，不额外编物理触发；结果可在继续运动中看清，不强制全部定格。
- 声音不是贴底音乐。BGM、环境声、拟音、静默和人声要参与推进：加速、停顿、声音桥、短暂静默或品牌声标都应落在叙事节点上。
- 高光所需的前提要成立；结果前置、感官展示或直接进入视觉事件也可作为开头，后续按当前用途展开，不强制每片先铺垫再揭示。反转若改变前文理解，要让新信息能解释原来的线索。
- 结尾让当前表达完成，需要辨认的产品、Logo、CTA、人物反应或主题句给看清时间；可在动作、声音或循环中结束，不强制静帧。稳定尾帧时长只按分镜合同。

## 传播目标与受众张力

先明确观众看完要形成的核心认识、感受或行动。下表是可配合的表达职责，不是同一层级的互斥目标：停滑负责获得注意，解释与证明支撑理解和信任，品牌记忆与行动体现传播结果。按当前主任务取用，不要求每条都有转化 CTA，也不把“停滑”当整片目的。

| 表达职责/结果 | 观众状态 | 核心兑现 |
|---|---|---|
| 停滑 | 无意刷到，随时划走 | 前 1-3 秒给问题、结果、人物动作、产品线索、声音钩子或反常画面 |
| 种草 | 有兴趣但未决策 | 让观众靠近一种生活、体感、审美或身份状态 |
| 解释 | 想理解机制 | 用清楚路径、步骤、UI、结构或流程把复杂内容变简单 |
| 证明 | 需要相信 | 给出可见证据，不只靠旁白和形容词 |
| 转化 | 临门一脚 | 产品清楚、利益明确、CTA 单一，事实必须确认 |
| 品牌记忆 | 愿意被情绪带入 | 一个主张、一个母题、一个资产回收 |
| 招商信任 | 主动评估合作 | 企业身份、证据链、流程和风险可控优先 |
| 教学 | 想学会 | 每步一个动作，一个反馈，一个完成标准 |

钩子必须服务后续证明。不要用无法兑现的“震惊”“爆火”“全网都在”等空泛停滑词。CTA 只保留一个主动作，购买、下载、预约、咨询、关注和了解更多不能同时堆满。

## 从表达目标选择具体看点

当前主体与任务已明确，仍不知道拍什么时查此表。它提供取材方向，不重选方案；同一表达可组合，不按品类套唯一玩法。

| 希望形成的认识或感受 | 可发展的具体看点 | 选择时核对 |
|---|---|---|
| 新鲜或自然来源 | 有依据的源头流程、原料近看、生长隐喻、晨间观察、包装与来源的形态联系 | 哪个让来源或质地更可感；动画生长不证明真实产地、有机或更新鲜 |
| 精致、丰富、适合送礼 | 礼盒开合、产品排列、开箱仪式、微距发现、不同物件的协调动作 | 看清的是哪些结构、份量或送礼体验；不凭悬浮阵列虚构套装内容 |
| 高效解决 | 同一任务从混乱到秩序、关键步骤减少、真实操作及结果状态、旧新流程比较 | 当前动作支持少哪一步、解决哪一处；速度效果不能当实测依据 |
| 舒服、陪伴、愿意靠近 | 材质与接触声、第一视角体验、具体照料动作、光线和空间关系、小任务的完成 | 观众得到什么细节与感受；不默认慢镜、治愈空镜或人人微笑 |
| 发布期待 | 局部显影、轮廓线索、空间开启、声音先行、已知信息逐步披露 | 等待中是否持续有发现，主体是否有线索，未公开内容是否守住边界 |

## 按需结果转译

只有核心价值仍是“高级、清爽、专业、治愈、效率”等抽象词，无法直接形成可拍动作时，才使用结果转译。产品广告写“产品造成的结果”；品牌、企业、文旅、知识、公益和通用创意写“主题造成的结果”。转译完成后只把触发、可见变化、证明与回收写回分镜母版的创意说明和分镜，不保留独立卡。

```text
原始卖点/主题价值：
观众在乎的心理：
现实异常结果：
物理化载体：
触发动作：
扩散路径：
旁观者/空间/物体反应：
证明锚点：
结尾回收：
风险边界：
```

采用异常结果路线时检查：观众一眼觉得不对劲；它能由当前产品、人物、品牌或主题触发；它能帮助理解一个已知特点、情绪或关系；幻想本身不作为功效与事实证据；结尾能回收到真实资产或明确结果。只写“更高级、更诱人、更水润、更高效”不算结果。

常用转译方向：

| 抽象价值 | 可视化结果 |
|---|---|
| 保湿/滋润 | 干燥纹理像河床被水光填满，最后回到真实取用、涂抹和自然光泽 |
| 控油/清爽 | 过亮反光被逐格收束成柔和哑光，最后回到真实妆面或手背状态 |
| 酥脆/爆汁 | 任选或组合以下并列方向：咬下声波向环境扩散并让空间按节拍响应；碎屑弹起后重组成新造型或品牌符号；断面暴露的瞬间沿裂纹结晶、拉丝、爆汁生长；咀嚼节拍直接驱动画面剪辑和场景切换；咬合一刻主体所在世界短暂转成同款酥脆材质。最后都回到断面、拟音和包装 |
| 香气/氛围 | 看不见的气味变成颜色轨迹、记忆房间或布料波动，最后回到喷洒、杯口或人物靠近 |
| 续航/稳定 | 时间、天气或任务流持续推进，但设备状态稳定，最后回到屏幕、电量或使用场景 |
| 速度/效率 | 空间被拉长、路径缩短、任务卡片归队，最后回到真实操作结果 |
| 清洁/秩序 | 灰尘退潮、杂物归位、混乱空间恢复边界，最后回到清洁或收纳动作 |
| 静音/降噪 | 噪声变成颗粒后被切断、吸收或落下，人物和环境从紧张变安静 |
| 从容/掌控 | 外部世界越混乱，主体动作越稳定，最后回到人物气质、产品稳定性或品牌姿态 |
| 艺术/文化生命力 | 静态作品、展品、建筑细节或传统符号开始行动，最后回到空间身份、活动主题或文化主张 |
| 融合/跨界 | 两种风格、声音、文化或使用场景先冲突再对齐，最后形成第三种统一结果 |
| 专业/可读 | 主体被拆成参数、结构、步骤或多视图，最后定格成可理解、可比较、可复用的图纸或界面 |
| 上头/吸引 | 文字、几何、声音和运动形成无法摆脱的循环、反相、裁切或节拍牵引，最后回到关键词或主题句 |

夸张结果可以作为创意隐喻，但不能伪装成未经证实的真实功效、医疗结论、安全保证、销量背书或竞品比较。

本文件和其他参考文件中的对照表都是示例，可以用表外的方法。不要看到品类就选第一项，例如零食总是碎屑爆炸、护肤总是水光绽放、软件总是任务卡归队。先看本片具体要讲什么，再选适合的写法。多条内容需要有区别时，改变具体观察、展开或呈现方法，不只是更换颜色和特效外观；已经准确有效的真实演示不必为了避重强改。

## 品类套路排雷

| 常见自动落点 | 重新找什么 | 边界 |
|---|---|---|
| 食品碎屑、饮料冰水、奶品牧场 | 当前配方、质地、包装、吃法、声音与分享关系 | 自然画面不证明原料、产地、新鲜与健康 |
| 美妆花瓣、水光、瞬间焕新 | 实际妆色、使用取舍、材质与光线下的可辨变化 | 不以幻想、磨皮或夸张反应暗示未知功效 |
| 3C 黑底光扫、参数粒子 | 结构、交互、操作反馈、使用条件或设计比例 | 不造参数、接口、屏幕与能力 |
| 企业航拍握手、流程报错再成功 | 真实业务的限制、取舍、对象关系与有依据的结果 | 不为戏剧性发明失败、警报、客户或 ROI |
| UGC 困扰自白、三大优点、真香总结 | 这个人当前为何要讲、实际注意到什么、怎样取舍 | 不编经历、评论与亲测，不把口语词当观点 |
| TVC 追梦亲情、世界升级、人生口号 | 品牌已知立场、资产、行为与受众的具体联系 | 不用温暖或壮阔自动推定品牌适配 |
| 知识“三个技巧”、强造误区 | 当前学习难点、完整例子与关键关系 | 不以短平快省掉解释，不羞辱观众 |

常见手法本身可以有效，不因被用过就禁用；问题是它有没有从当前内容产生、是否充分发展。发现只剩手法名或通用赞美，就回当前类型取材，不能换一个同样空泛的效果名。

## 机制选择器

需要特别的呈现方法时再查本节，不必先做一遍“结果转译”。同一种方法可用于不同品类，但要重写由什么动作开始、发生什么变化、怎样结束；不能只换产品名。

### 世界规则

采用世界化、超现实或规则驱动的表现时，用本节细化已选机制，不在通用推导前再加独立关卡。风格回答“看起来像什么”，世界规则回答“这里的现实如何运转”；让乐高、黏土、像素、CG、子弹时间、微缩场景或 UI 动效共享因果，避免只有外观装饰。真实操作、纪实和人物选择不必另设世界观。

需要世界规则时保持一条主规则，确有职责时再补兼容规则，不与主机制各选一套。对采用规则写清：

- 规则源：由产品动作、人物动作、声音、按钮、包装、屏幕、道具、空间或一句口播触发。
- 规则范围：影响产品内部、桌面、房间、城市、屏幕、微缩世界、时间、重力、材质、文字还是角色行为。
- 规则证明：它具体证明哪个卖点、品牌态度、流程价值或人物判断。
- 规则回收：结尾如何回到真实产品、真实人物、真实界面、品牌资产、结果状态或 CTA。
- 规则边界：不能伪造功效、参数、医学/金融/安全结论、真实优惠、销量背书或竞品比较。

| 世界规则类型 | 适合 | 可执行写法 |
|---|---|---|
| 产品内藏世界 | 手表、香水、饮品、食品、包装、屏幕、汽车、耳机 | 产品结构成为入口，内部世界承载场景、感官或功能；镜头进入和退出都要回到真实产品结构 |
| 微缩沙盘世界 | 家居、收纳、城市、本地生活、工具流程、复杂服务 | 桌面、表盘、瓶盖、屏幕或包装上出现微缩场景；每个微缩动作对应一个真实步骤或卖点 |
| 风格化动画世界 | 乐高积木、黏土定格、像素游戏、纸模、漫画分格、玩具模型 | 风格本身变成规则，例如拼装、修复、通关、升级、展开、折叠；不能只把产品卡通化 |
| 时间规则 | 运动装备、3C、耳机、时尚、发布感产品 | 加速、冻结、倒放、子弹时间或节拍恢复必须服务产品展示、材质证明或人物状态变化 |
| 物理规则 | 悬浮、坠落、吸回、膨胀、折叠、喷雾、粒子、花瓣、液体 | 每个物理异常都要有触发点、受力方向、速度/阻力、落点和证明职责 |
| 口播第四面墙 | 数字人、AI 工具、幕后、创作者、服务说明 | 说话者承认视频生成、分身、幕后或拍摄关系，用幽默或自揭建立信任，最后回到产品/工具价值 |
| 证明流程世界 | 测评、清洁、收纳、穿搭、食品、工具 | 世界按“发现问题 -> 真实操作 -> 结果对照 -> 边界说明”运行，创意只强化证据，不遮挡证据 |
| 奢华陈列世界 | 香水、美妆、珠宝、高端消费品 | 花材、织物、喷雾、反光与运动围绕材质、香气或仪式感组织；速度按内容，真实动作遵守受力与材质关系 |
| 任务闯关世界 | App、SaaS、课程、效率工具、年轻化消费品 | 使用流程被写成关卡、解锁、计分、奖励或失败回弹；每关必须对应真实操作或产品价值 |
| 角色代理世界 | 产品、食材、数据、灰尘、毛发、衣服、任务卡获得简单动机 | 被处理对象像角色一样行动，但产品必须是规则源或解决者，不让拟人化抢走卖点 |

从参考视频迁移时，只迁移世界规则，不复制对方的产品、品牌、角色、台词、符号和完整桥段。例如“表盘里切换雪山/丛林/峡谷”可迁移为“产品内部按场景切换证明多场景能力”；“耳机子弹时间 360 展示”可迁移为“时间冻结让产品材质和结构被看清”；“香水花瓣与喷雾”可迁移为“物理可信的气味/材质外化”；“AI 分身口播”可迁移为“第四面墙解释工具价值”。

| 机制 | 使用方法 | 适配时必须改写 |
|---|---|---|
| 物理规则篡改 | 悬浮、倒流、冻结、重力反转、材质变形 | 哪条规则被改、谁触发、改变后证明什么 |
| 尺度错位 | 人进入产品世界、产品放大成空间、世界微缩 | 尺度变化必须揭示结构、质地、体验或场景 |
| 视角置换 | 用产品、宠物、灰尘、液滴、食材、UI 节点看世界 | 新视角要带来新信息，并最终回到真实主体 |
| 虚实融合 | 真实场景里长出 UI、动画、数据、手绘线或游戏界面 | 虚拟层必须解释真实动作或体验，不能遮挡证明 |
| 线索贯穿 | 一个物体、声音、颜色、动作或符号穿过多场景 | 线索每次出现都推进信息，结尾落回品牌/产品/主题 |
| 逐级升级 | 异常效果或旁观反应一层比一层强 | 每级必须有新证明或新情绪 |
| 反差美学 | 高级/粗粝、日常/史诗、优雅/荒诞并置 | 反差要服务定位和记忆，不损害可信度 |
| 互动式展示 | 手、光标、门、盒盖、擦拭、拖拽等动作改变画面 | 互动动作必须产生可见结果，并和真实操作或主题有关 |
| 导览引路 | 角色、光点、票据、数据卡、声音或手势带观众穿过空间/流程 | 每一站都要触发新信息，结尾回到空间身份、流程结果或主题 |
| 静物活化 | 展品、包装、文字、UI、图标、数据或工具获得动作身份 | 先保留识别点，再突破边界；动作必须解释主题或证明点 |
| 多源融合 | 两个以上参考、风格、声音或场景叠加成新结果 | 先分别建立 A/B 特征，再写冲突、对齐、融合和收束 |
| 数据标注化 | 主体被视作图纸、参数、三视图、结构层或仪表盘 | 标注必须少而准；真实数值没有材料时只能概念化 |
| 文字语义可视化 | 文字运动方式直接表达含义、节拍或态度 | 关键词、字体、颜色、反相、裁切和留白要有统一规则 |
| 框架穿越 | 框、门、屏、洞口、包装或输入框成为空间入口 | 穿过后必须出现新信息；最后回到真实边界或资产 |

## 平台语境

平台名提供分发环境线索，不能替代具体展示位和观看任务。同一平台有刷到的信息流、主动搜索的答疑、已进入商品页的展示；同一企业视频也可能用于官网、销售会谈、展会循环或会议开场。内容取材与文案按第一阶段写法和当前类型的第一阶段写法选择，本节不再维护一套按平台分配剧情的表。按[策略迁移适配总则](#策略迁移适配总则)改变取材、顺序、语言与收束，再查当前类型的具体写法。

跨展示位改编时先重看观众已知、未知与想获得的收益，再改信息先后、说话关系、主体露出和收束；不能只裁画幅、加“姐妹们”或换一个CTA。用户锁定的内容保留，只调整获准范围。

制作时再处理与观看条件有关的差异：

- **手机小屏/信息流**：近景与关键信息清楚，留意实际界面遮挡和安全区；音画能迅速建立主体与观看线索，不等同于所有平台都要同一种夸张钩子。
- **主动搜索/教程/官网**：给关键步骤、页面和对照足够辨认时间，人声交代判断；不把“可暂停”作为小字堆满画面的理由。
- **可能静音的商品展示/展会循环**：用可见过程、结果和必要短文字保留理解，中途进入也能认出主题；声音路线及省略条件仍按分镜合同。
- **会议大屏/发布现场**：按观看距离减少小字、增强主体/主题可读性；音乐与聚场节奏服务现场任务，重要发布信息留足阅读。不能直接把手机口播放大当会场开片。
- **中长内容**：围绕同一任务持续增加信息，可章节化；不随模型拆段每15秒重启一次钩子。

研究依据可参考 [TikTok广告形式与展开方法](https://ads.tiktok.com/business/en/guides/video-advertising-guide) 与 [Google按传播目标调整视频表达的说明](https://support.google.com/google-ads/answer/14783551?hl=en-GB)。这些是方法参考，不是所有平台的固定脚本、效果承诺或对实际成片的替代分析；具体主体仍需按当前任务找参考并重写。

## 尾帧与收束专项

很多视频“不知所以然”不是中段没有创意，而是结尾没有把创意归还给核心表达。尾帧用于让已展开的内容落定，不能只附加 logo 或最后再塞一个新卖点。按当前任务保留主体、已经成立的判断/感受或操作反馈；有后续行动才交代入口，不要求所有片子结尾转化。

尾帧选择：

| 类型 | 必须回收 | 好尾帧 | 坏尾帧 |
|---|---|---|---|
| 产品广告 | 产品身份、主任务结果；转化任务才给购买/了解动作 | 产品清晰正面或使用结果稳定，短字只写一个核心利益 | 最后一秒新增多个卖点、产品太小、只有抽象氛围 |
| UGC 口播 | 已交付的判断、体验或操作；有引导任务再给入口 | 人物/操作结果稳定，最后一句接住前文，必要CTA自然落定 | 口播还在铺垫，突然切 logo 或大促字 |
| 品牌 TVC | 品牌主张、视觉母题、情绪残留 | 母题回到品牌资产，主张短句稳定可读 | 情绪很美但不知道品牌想说什么 |
| 企业商务 | 当前任务的结论、主题或现场衔接；合作入口按需要 | 企业/业务结果可辨，或明确接入下个现场环节 | 抽象口号、无事实、用销售结尾覆盖其他用途 |
| 通用创意 | 当前解释、体验、动作或音乐段落完成 | 结果看清、动作落定、乐句结束或循环连续 | 尚未完成就截断，或已结束仍无内容拖延 |
| 活动/发布预热 | 参与理由及本次需要的真实行动信息 | 体验或主题连到必要发布信息与行动入口 | 悬念过度，看不清主体或怎样参与 |

需要具体设计最后画面时，可按下面维度写入既有分镜，不另填尾帧卡。文字、静态停留与行动提示只在实际采用时写，持续运动、乐句结束或循环按其真实结束方式描述；时长边界按分镜合同：

```text
尾帧主体：[产品/品牌/人物/企业/主题字]
尾帧状态：[刚才变化后的结果]
尾帧文字：[一句核心回收或一个 CTA]
声音落点：[音乐停顿/声标/拟音归位/人声最后一句]
辨认/停留时间：[按当前动作、识别或阅读需要；无专门稳定尾帧不加停顿]
不再新增：[新的卖点/新角色/新场景/新事实]
```

收束检查：

- 营销尾段若无法与本次推广对象建立联系，回改前文关系与识别；同类可共用手法，不要求每张尾帧独占一种构图。
- 如果尾帧出现的信息前面没有铺垫，删掉或移到前段证明。
- 如果尾帧只剩 CTA 但没有行动理由，回到前一镜补结果状态。
- 如果尾帧只剩漂亮画面但无主张，增加短主题字或让母题回到品牌资产。

## 事实与素材边界

真实产品、真实 UI、真实 Logo、真实人物、真实数据、客户案例、优惠价格、奖项资质、功效声明和活动信息必须来自用户素材、可靠来源或用户明确确认。缺少事实就按已有信息写，不靠猜测补齐。可以拟定观看位置、受众和表达方式；概念外观、虚构人物或演示场景须说清，不冒充真实资料。

参考可以由用户提供，也可以由代理主动查找。是否检索、怎样研究统一按[第一阶段的参考研究](creative-core.md#主动创意参考研究)，不要求用户先提供样片，不因缺少参考停下创作。

参考内容里的视觉创意、叙事骨架、玩法触发与回收、运镜结果、剪辑节奏、光线方向、构图方式、色彩段落、转场锚点、声音结构、文案节奏、花字职责、卖点排序和露出逻辑，都要重新绑定到当前主体、当前事实和当前核心表达上。

迁移参考时先判断元素在原片中的职责，再替换成当前项目能成立的表达：

- 人物不只是脸，也可能是口播者、反应者、见证者、图形身份、CTA 发起者或可信边界的承担者。
- 产品不只是道具，也可能是证据、演示对象、UI、触发动作、状态改变原因或结尾回收点。
- 风格不只是滤镜，而是镜头、画面文字、图形、音效、表演、节奏和转场共同形成的系统。

参考片的开场要拆成“它如何抓注意力”：人物反应、问题瞬间、结果前置、声音先行、异常规则、图形状态或产品局部。视觉系统要拆成生命周期：第一次出现建立规则，中段重复或升级，结尾退出或回收。任何可复用的符号、颜色、声音、图形、手势、UI 状态或空间规则，每次再次出现都必须带来新信息，不能只作为装饰反复闪现。

分析参考视频时，内部按以下结构提炼，不在用户可见正文里机械展示全部字段：

```text
可迁移关系：
不可迁移表面：
A-roll / 主表演：
B-roll / 辅助画面：
MG / 图形和文字系统：
声音和剪辑交接：
开场、重复、变化、退出：
改写到当前项目的方式：
```

常见表达结构可以作为创意骨架，但不作为固定分类：

| 结构 | 适合场景 | 迁移方式 |
|---|---|---|
| UGC / talking head | 口播、带货、观点、创始人解释 | 稳定人物视角 + 自然跳切 + 画面文字/图形标签/MG/B-roll 辅助证明 |
| Presenter-led explainer | SaaS、工具、企业服务、复杂概念 | 讲解者带着图形、演示和比较对象一起推进 |
| Narration-led demo | 产品演示、教程、功能说明、视觉散文 | 旁白作为脊椎，产品、手部、屏幕、MG、B-roll 作为视觉答案 |
| Ranking/listicle | 排行、清单、对比、测评 | 排名板或比较表记住前面判断，每一项用态度、图标和证据镜头推进 |
| Street interview / podcast / two-person | 采访、播客、街采、观点碰撞 | 用视线轴、反应镜头、角色颜色、说话人标签和声音交接建立关系 |

## 创意变体

用户要多条广告或测试方向时，变体必须在实质维度上不同，不能只换几个词：

- Hook：痛点、反差、结果、提问、动作、证明、误区、比较、场景。
- 角度：测评、问题解决、教程、开箱、对比、生活方式、专家/创始人 POV。
- 开场画面：人脸口播、手部动作、产品局部、结果前置、场景冲突、声音先行。
- 证明点：材质、功能、前后状态、案例、流程、数据、使用动作。
- 受众：新手、进阶、价格敏感、品质敏感、礼赠、企业客户、候选人、投资人。
- CTA：收藏、了解、预约、试用、直播间、官网、下载、到店、报名。
- 节奏和声音：快剪、舒缓讲解、纪实、电影感、信息密集、少词高端。

每个变体都必须可拍、可执行、可交付，并遵守事实和授权边界。

## 方法来源与适配边界

这些策略来自通用广告创意、短视频信息流、产品发布、品牌 TVC、AI 视频运动语法、UGC 表达和企业商务传播的共同方法。任何参考文件、参考视频或工具案例都要被改写成当前项目的“功能”：它负责停滑、证明、解释、情绪、记忆、转化还是信任。只有当这个功能被当前主体、素材、事实边界和类型策略重新承载后，才能进入脚本、分镜和 PE。

模型选择、会员逻辑、时长、比例、生成批次、参数确认、字幕规则、委派 agent、PE 格式、分镜数量和阶段确认，以 `SKILL.md`、`production-control.md` 和 `references/interaction-ask-video-clarification-ref.md` 为准；本文件只补创意和策略判断，不覆盖执行规则。

## 叙事结构选择器

下面是视觉组织与既定故事的对应方法；内容已有清楚结构时不另选一套骨架：

| 骨架 | 时间推进 | 适合 | 关键控制 |
|---|---|---|---|
| 蓄力 -> 爆发 -> 余韵 | 慢、暗、静地积累压力；触发点前短暂停顿；高光爆发；尾帧收气 | 运动、速度、发布、通感冲击、品牌燃向 | 蓄力中持续增加线索或压力，不预设占比；爆发给音画重拍，余韵回到品牌/产品；不得以本行绕过分镜节奏合同 |
| 悬念 -> 揭示 | 正常场景中出现具体异常；异常扩大；最后解释异常来源 | 巨型开箱、道具线索、品牌后置、超现实广告 | 悬念要具体可追问，例如“这栋楼为什么会打开”；不能只是抽象氛围 |
| 线索贯穿 | 一个道具、颜色、光点、文字或声音穿过多场景，到终点解释意义 | 毛线、土豆、数据流、物流、路线、品牌色线索 | 线索在每个场景都必须一眼可见；终点必须产生产品/品牌/行动结果 |
| 问题 -> 方案 -> 效果 | 先给观众关心的问题，再拆解方法，最后给前后对比或成品 | 教程、工具、拍摄方法、SaaS、低成本高质感 | 问题要真实；步骤只留关键；效果要有对比证据 |
| 正常 -> 包袱 -> 反转 | 正常铺垫，异常元素制造笑点，品牌或结果二次揭示 | 幽默广告、Logo 玩法、轻喜剧 UGC | 反转必须同时解释前面异常和品牌/产品，不只为了搞笑 |
| 双线并行 -> 汇聚 | 时间线、地点线、人群线或状态线交替推进，最后合流 | 运动纪实、活动预热、品牌群像、企业案例 | 每条线要有共同符号或节拍，避免像拼素材合集 |
| 纯展示节奏编排 | 没有剧情，靠远近、快慢、动静、角度、文字和声音组织观看 | 极简排版、镜头角度合集、产品巡航、视觉实验 | 按观看或音乐关系形成持续体验；等节拍、固定构图与重复可以成立，避免无观察所得的堆镜头，结束方式服从当前动作、乐句或循环 |

结构选择后，分镜必须把每个节点写进秒段：哪一秒建立、哪一秒触发、哪一秒高光、哪一秒收束。结构不能只写在方案概述里。

## 通用创意尾态

通用创意结尾要完成当前体验，不等于必须停成静帧：可以动作落定、解释完成、声音收止、段落明确结束或无缝回环。需要辨认结果时给看清的时间；MV、循环与观察片按音乐、动作和观看关系结束，不强制改变主体状态或添加意义反转。

常用尾态：

| 创意类型 | 尾态 |
|---|---|
| 概念氛围片 | 主体姿态、光线、空间边界或声音世界发生可感知改变 |
| 视觉实验片 | 异常规则完成闭环，最终形态停留可看清 |
| MV/卡点片 | 按当前乐句、动作或指定音乐截点结束，可落拍、延音、明确截断或循环，不统一收成静态画面 |
| 风景/空间片 | 视角抵达一个新发现，不停在无意义空镜 |
| 人物时尚片 | 人物状态被一个动作、眼神、衣料或构图定住 |
| 物体动态片 | 物体完成一次性格动作，回到可识别形态 |
| 弱叙事片 | 一个动作完成情绪转折，不开启新剧情 |

## 风格世界的变化与观看任务

风格化不止是材质或动画皮肤。羊毛毡、积木、黏土、玩具沙盘、纸模、模块化建筑等可通过主体行动或状态变化展开；技术图纸与动力学排版通过信息和语义递进。采用超现实机制时才补世界规则，观察、音乐和情绪表达不强求闯关任务。

采用超现实风格世界且规则不清时，用下面问题补具体设计；答案合入现有事件，不另交任务卡，观察、音乐与情绪表达不强加主体任务：

```text
风格世界：
真实锚点：
这套世界里什么可以动/变/生长/拼装/折叠：
主体要完成的任务：
任务如何表达核心概念：
结尾回到什么可识别尾态：
```

常用风格世界规则：

| 风格世界 | 不能只写 | 必须写成 |
|---|---|---|
| 毛毡/毛绒 | “治愈可爱毛绒风” | 所有物体有柔软纤维，主体通过苏醒、觅食、摆动或被风轻推完成温柔动作 |
| 乐高/积木 | “乐高风” | 世界由颗粒拼装，角色通过搭建、清洁、拼合、升级或完成任务来表达主题 |
| 黏土/定格 | “黏土动画” | 手工质感角色一拍一拍完成揉、烤、拿、打开、跳跃等可见动作 |
| 移轴/微缩 | “移轴可爱” | 镜头像看小模型，人物或物体在微缩场景中完成清楚路径，景深服务玩具尺度 |
| 模块折叠 | “未来建筑变形” | 模块按机械逻辑弯折、拼接、堆叠或重组，每次动作让结构更完整 |
| 纯白 3D | “高级极简” | 产品开合、悬浮、旋转、回收形成完整物理闭环，细节有稳定停留 |
| 技术流图纸 | “很多标注” | 主体保持标准姿态，标注线按结构逐条出现，旋转/三视图补全隐藏信息 |
| 动力学排版 | “文字卡点” | 关键词的运动方式等于语义本身，字体、反相、裁切、留白和节拍共同叙事 |
| 城市主标题 | “城市名大字” | 地名、主题字或系列标题融入建筑、水面、道路、天空或海报构图，成为空间结构的一部分 |
| 教程信息层 | “增加步骤说明文字或图形标签” | 使用 `“步骤1：导入素材”` 等画面文字、素材清单、工程信息和关键参数跟动作或工程截图同步出现，帮助观众复现方法；这不是逐句字幕，只有用户明确要求画面内字幕时才使用 `【】` |

风格世界的任务要简单：清洁一颗巨型牙、烤出一只面包、让玉米地变成毛绒童话、让建筑自己长高、让文字完成一次语义动作。任务越简单，风格越容易被记住；任务不清时，风格只会变成漂亮但空的画面。

## 文案和表达策略

沿用第一阶段写法已确定的核心判断，再决定信息由口播、旁白、画面文字、图形标签、真实 UI、产品动作、声音或尾帧承担。本节解决表达分工，不重新建立一个中心；默认无字幕也需要表达策略。

常用文案职责：

| 职责 | 形式 | 用法 |
|---|---|---|
| 停滑 | 首句口播、标题卡、强动作短字 | 1-3 秒内给问题、结果、反差、承诺或异常 |
| 解释 | 旁白、讲解口播、章节字、图形标签 | 把画面看不出的逻辑说清楚，避免长段说明 |
| 证明 | 参数短字、步骤标签、真实 UI 原文、前后状态字 | 只写可被素材、动作或已确认事实支撑的信息 |
| 记忆 | slogan、关键词、产品声音、品牌色文字 | 让观众能复述一个词、一句话或一个画面 |
| 行动 | CTA、尾帧按钮感文字、口播收束 | 只保留一个主动作，和传播目标一致 |

文案形态选择：

- 口播适合 UGC、讲解、测评、创始人表达、知识引流和需要真人可信感的内容；台词要像人对人说话。
- 旁白适合产品广告、品牌片、企业片、纪录片感和无出镜讲解；句子按需要讲完整，与画面、论述或情绪变化相接。
- 画面文字适合停滑、卖点锚定、章节转换、尾帧收束和静音可读；每条短字只承担一个信息点。
- 图形标签适合排行榜、对比、进度、步骤、功能演示和数据可视化；文字要随状态变化出现、替换、积累、比较、揭示或完成。
- 真实 UI、包装和屏幕文字只使用用户素材、真实截图或明确确认的文本，不让模型随机生成小字。
- 人声与无旁白的采用条件统一按[分镜合同](storyboard-contract.md#声音选择)。选定路线后，文字和声音补足画面无法表达的意义；不把少字、视觉主导或诗性风格当作省略人声的理由。

先按[第一阶段写法](creative-core.md#连写文案及声音职责)写好整段台词，再决定哪些意思由画面、声音或文字交代。不固定主句数量，也不规定开头、中间、结尾各一句。教程提醒观众核对当前动作时，可以说画面正在演示的事；其他地方不必逐个念出画面中的物件。

### 从事实卖点到利益句

文案不是把功能读出来，而是把功能翻译成用户能感到的利益。

| 层级 | 问题 | 写法 |
|---|---|---|
| Feature 功能 | 它是什么 | 材料、结构、参数、功能名；必须来自用户资料或可见事实 |
| 使用结果 | 这个结构或功能怎样影响当前操作 | 例如已知外侧袋无拉链，可以演示“拿卡不用开拉链”；不能直接推成未经比较的“取物更快” |
| 对人的用处 | 这个结果为什么与他有关 | 接实际任务说明，例如进门要取卡、再放回去；不从普通功能直接推出“省时间、少焦虑”等效果承诺 |

事实与用户必讲项按[事实锁](production-control.md#来源与事实锁)和[产品内容写法](product-ad-video.md#产品广告主线)，本节不再设卖点数量、主辅配额或重复事实清单。

关掉逐句字幕后，再看实际画面和声音能否讲清内容。若只能看见漂亮画面，仍不知道在讲什么，就补必要解释或改画面；不要靠加一句口号解决。

## 文案动作和语感

整段文案怎样写、怎样检查连贯与口语，统一按[连写文案及声音职责](creative-core.md#连写文案及声音职责)。这里的技巧只加工已经讲通的内容，不另设话术流程，不以用了修辞代替写好台词。

先看当前句在对谁说、接什么事、与画面怎样配合，再按需要选择：

| 表达技巧 | 什么时候有用 | 怎样避免写怪 |
|---|---|---|
| 具体处境与称呼 | 让观众认出这与自己的任务有关 | 说实际需要和情境，不靠“配得上”“真正懂的人”等身份评判 |
| 提问或反问 | 提出值得回答的疑问，或回应人物的选择 | 后文真正回答；不默认挑衅、怼人或用“你敢不敢”代替内容 |
| 荒谬放大 | 通过明显虚构的场景放大一个可理解的产品特点 | 观众能认出夸张与特点的关系，不能暗示虚假功效、价格或数据 |
| 换叙述者 | 产品、物件或旁观者有不同信息与观察角度 | 新身份要带来新的说法与观察，不只换主语，不让人物知道尚未发生的事 |
| 留白 | 眼前动作、表情或下一次回应能补出未说的话 | 不能省掉关键前提、操作条件和句间关系；不是把正常句子截断 |
| 类比与隐喻 | 熟悉的事物能帮助理解特点，或同一意象能展开感受 | 对应关系能从片中看懂；不任意拼接名词、故意破坏语法或堆陌生词 |
| 文画对照 | 人物嘴上说的与实际行动不同，或画面让一句话产生另一层意思 | 观众有线索理解差异；不把“画面负责事实、文案负责意义”当固定分工 |
| 回环 | 同一句话在新的事件后有了不同意思 | 再次出现应带来判断、关系或情绪变化，不把重复口号当中段推进 |

按场景选择强度：

| 场景类型 | 优先从哪里取内容 | 技巧的适用边界 |
|---|---|---|
| UGC / 信息流 / 带货 | 当前观察、取舍、疑问和可见依据 | 让人用自己的话说，不强加反问、犹豫、语气词或网感；画面标签不拼成口播 |
| 产品广告 / 商品短片 | 已知结构、感官、使用动作与具体结果 | 可以放大声音、改变尺度或夸张呈现；产品特点应控制创意，不只在结尾点题 |
| 品牌 TVC / 形象片 | 人物选择、品牌态度、同一意象的逐步展开 | 可以诗性和留白；整段仍有共同线索，人物不忽然变成品牌发言人 |
| 企业商务 / SaaS / 工具 | 业务任务、依据、状态改变和实际结果 | 解释要准确，类比帮助理解；不能借修辞扩大能力、攻击竞品或许诺效果 |
| 教育 / 知识 / 解释 | 当前误区、有效例子、操作和核对依据 | 可以先问后答，不神秘化关键结论，不以顺口口诀代替解释 |
| 医疗健康 / 母婴 / 公益 / 政企 | 具体处境、可靠信息、实际行动 | 克制使用夸张和反问，不靠恐吓、羞辱或焦虑推动行动 |

需要更有特点时，改观察角度、人物回应、具体用词和声音配合，不使用“语法陌生化”制造吸引力。“赋能、极致、重新定义”等词不能代替具体意思，也不机械禁用：用户锁定原文保留，必要的品牌表达要有本片内容支撑。花字可承担圈注、拟声和状态提示，但不再把缺失的解释转嫁给花字。
