# 视觉叙事与运动效果

## 文件说明与索引

本文件合并视觉效果机制、Higgsfield 启发效果语法和叙事视觉同步规则。它不是案例合集，也不是特效名词表，而是每条视频都要使用的视觉叙事方法：这个视频最容易被记住的画面是什么，它如何运动，如何进入开场、高光、反转、结尾，最后如何回收到产品、品牌、人物或主题。

传播目标、受众、证明锚点和风险读取 `references/creative-core.md`；运镜、布光、构图、色彩、声音和文案读取 `references/audiovisual-craft.md`；流程和生成门读取 `references/production-control.md`；专项约束读取当前唯一类型文件。

## 按需视觉运动补充

只有视频使用超现实规则、复杂动效、空间变化、图形主导或明确视觉高光时，才补充本节。普通口播、纪实、教程和朴素证明不单独填写视觉运动卡。选中的结论合并到 `creative-core.md` 的唯一导演总控卡和完整分镜，不再形成平行文档。

```text
真实锚点与避开项：
触发动作：
可见规则变化：
连续运动路径：
场景/人物反馈：
开场与高光：
证明与回收：
风险：
```

如果只能写出“产品出现、镜头推进、产品旋转、场景变好、结尾定格”，说明还没有运动母版，必须重写动作压力、镜头路径和异常扩散。

## 特效前置设计

特效不是默认禁用项。产品体验、剧情转折、情绪放大、空间变化、品牌记忆或声音外化需要时，应在规划和分镜阶段主动选择合适特效，而不是等 Prompt 写完再装饰：

```text
叙事节点：特效出现在哪个动作或信息点
触发：谁做了什么
变化：哪种材质/形状/空间/文字/光线发生什么
反馈：人物、物体、环境或声音如何回应
证明：它让观众更清楚相信或感到什么
回收：如何退出并回到真实主体、结果或品牌
```

每条片最多一个主特效系统和 `1-2` 个低存在感辅助效果。主特效至少完成“首次建立 -> 中段升级/变体 -> 结果回收”；辅助效果只服务切镜、声音重拍或局部反馈。真实动作和材质已经足够有冲击力时，不强加闪电、粒子、光波、扫光或爆炸；但如果特效能清楚放大当前任务和叙事，就应提前规划并写进具体镜头。

特效是否合适由规划和分镜决定。最终 Prompt 预检只检查既定特效是否具备触发、反馈、证明和回收，不在该阶段临时新增另一套效果。

## 从核心表达转译视觉事件

先消费 `references/creative-core.md` 已确定的核心表达和证明锚点，再补可见规则，不重新做一轮传播策略：

```text
核心表达：[观众最终要感到、理解或记住什么]
真实锚点：[产品/人物/食材/建筑/界面/道具/地点]
创意改写：[哪条尺度、空间、材质、重力、结构或因果规则被改变]
可复述画面：[一句话说清画面，例如“饮料瓶成为一座有瀑布流出的山”]
冻结瞬间：[最能同时看清锚点与创意规则的单一时刻]
可信依据：[光影、接触、遮挡、倒影、投影、尺度参照和材质]
动态把手：[下一秒从哪里开始运动、沿什么路径、哪些锚点保持不动]
回收关系：[创意最终如何归还给产品、人物、品牌或主题]
```

若可复述画面只能写成“高级产品展示”“人物开心使用”“画面很有设计感”，说明尚未形成创意。先解决视觉事件，再补摄影细节。文字与尺度、空间、材质、结构、视角、真实与插画融合并列，是可选手法。

本文件负责视觉机制和运动；构图、色彩与文字排版库读取 `references/audiovisual-craft.md`。实际生成必须按 `references/asset-generation.md` 把机制画成可确认的真实概念图，再交给视频模型运动；设计卡、数量、素材锁和图片确认门只在资产生成文件维护。

## 核心原则

有趣不是多加特效，而是：

```text
熟悉的东西 + 一个不对劲的变量 + 合理触发器 + 有回收的结果
```

熟悉锚点让观众秒懂，不对劲变量打破预期，触发器让它情理之中，回收结果让它服务产品、人物、品牌或主题。每条片只选一个主视觉机制，并按实际需要选择 `1-3` 个不冲突的辅助机制；每个辅助机制只承担一个局部职责。转场效果服务连续性，不抢主视觉。

本文件其他位置若仍出现“辅助效果最多 1-2 个”或“辅助母版最多 1-2 个”，统一以主 `SKILL.md` 为准：最终按实际需要保留 `1-3` 个与主机制不冲突的辅助机制，不需要时不为凑数量硬加。

视觉效果必须对应一条现实被改变的规则，而不是孤立出现。常见规则包括重力、时间、声音、气味、空间、尺度、材质、物体行为、因果链、平行状态和环境身份转换。

视觉系统必须有生命周期：第一次出现建立规则，中段重复、变化或升级，结尾退出或回收。系统可以是一个颜色、声音、动作、图标、排名板、进度条、产品轮廓、手势、UI 状态或空间规则。每次重复都必须带来新信息，不能只作为装饰闪现。

默认感官效果不能直接当主视觉系统。声音波形、光波、粒子、飞溅、花瓣、烟雾、冰裂、水光、速度线和爆炸感都只是材料；只有当它们被当前产品动作触发、改变了现实规则、持续推进证明并最终回收到产品/品牌/主题时，才可升级为主玩法。否则它们只能作为辅助反馈，主视觉必须改用更具体的空间、视角、文字、包装、流程、行为或时间机制。

## 可复述视觉事件

每条视频至少设计一个观众能用一句话复述的视觉事件。视觉事件不是“高级光影”“可爱动画”“丝滑转场”，而是“某个主体因某个动作发生了一个有意义的变化”。它必须同时满足：

- 一秒能看懂熟悉锚点：产品、人物、宠物、食材、UI、建筑、衣物、包装、空间或手部动作。
- 一个不对劲变量：长出、变形、悬浮、折叠、分屏合流、材质统一、自动归位、从源头流入产品等。
- 一个清楚触发：开盖、点击、举杯、捞鱼、倒入、喷洒、拉扯、系鞋带、种下、点亮、行走、声音重拍。
- 一个表达职责：证明卖点、外化情绪、建立品牌世界、解释流程、制造期待或促成行动。
- 一个回收尾态：产品定版、品牌字标、人物状态、真实结果、主题字或 CTA 稳定落下。

写分镜时优先把视觉事件拆到时间轴，而不是另写概念说明。例如不要写“产品自然生长创意”，要写“0.8 秒手指把一粒种子放进奶白包装轮廓，嫩绿藤蔓沿包装边缘长出，品牌名和成分信息像叶脉一样逐步显影，最后包装正面停稳”。

## 玩法运动母版

以下母版可以迁移到通用创意、产品广告、品牌 TVC、UGC 和企业商务；使用时只能保留运动逻辑，必须替换成当前主体、卖点、品牌资产和事实边界。

| 母版 | 运动逻辑 | 适合表达 | 分镜写法 |
|---|---|---|---|
| 光影揭幕 | 暗场/遮挡物先隐藏主体，轮廓、局部、材质和关键部件依次被光扫出 | 发布预热、高端产品、汽车、3C、品牌神秘感 | 先给局部线索，镜头推拉或横移追随光线，最后完整产品/主题稳定落版 |
| 生长生成 | 元素从空白、种子、液体、纹理、数据或包装边缘逐步长成完整资产 | 天然、纯净、有机、长期主义、包装生成、品牌生命力 | 每次生长新增一个可读信息，最终回到真实包装、产品或品牌名 |
| 语义幻变 | A 物体因形状/材质/含义接近，顺滑变成 B 产品或 B 结果 | 食材到产品、月亮到饼干、容器到花、鱼到宠物粮、旧状态到新状态 | 先保留 A 的识别点，中段用粒子/液体/形状匹配完成转化，尾段说明 B 的产品价值 |
| 产品自编舞 | 产品或模块不靠人手自己弹出、悬浮、旋转、堆叠、归位、填满 | 精致、丰富、分量、结构、科技、系列感 | 每个动作都有物理小反馈；群体运动后留停顿，让观众看清完整阵列 |
| 材质统一世界 | 真实场景整体被一种材质或制作方式重构 | 毛毡、积木、黏土、玩具沙盘、纸模、童趣治愈、非写实品牌世界 | 先建立材质规则，再让角色或产品完成一个简单任务，结尾回到产品/主题 |
| 微观到宏观 | 从质地、局部、种子、零件、界面按钮或材料开始，逐步拉开到完整产品/场景/系统 | 工艺、汽车、护肤、食品、企业能力、自然来源 | 每次拉开都新增层级，不只是放大缩小；最后给完整认知 |
| 物理小高潮 | 主体出现短暂失衡、拉伸、弹出、碎裂、分解、回弹或归位 | 酥脆、弹性、清洁力、稳定、分量、爽感 | 小高潮必须可控，发生后给结果停留；不要让失控破坏产品美感 |
| 第一视角动作链 | 镜头像观众的身体，跟随手、脚、杯口、门、包装或屏幕动作推进 | 开箱、运动补水、咖啡冲泡、户外露营、真实种草 | 声音和镜头跟动作同步，少用旁观空镜，多用接触点和反馈 |
| 分屏并行汇聚 | 多人物、多场景、多 SKU 或多状态同时推进，结尾合流 | 跑鞋百搭、多身份适配、活动人群、功能多场景 | 每条线先有独立动作，再用共同节拍、方向或产品资产汇聚 |
| 科研到使用 | 实验室、原料、测试、生产或工艺流程过渡到消费者使用 | 专业背书、可信护肤、鲜奶、企业服务、工艺品牌 | 前段证据克制真实，中段产品落地，后段用户结果或品牌理念收束 |
| 情境仪式 | 节日、礼赠、晚餐、举杯、生日、露营、山顶日落等仪式动作承载产品 | 情感价值、节庆、礼盒、生活方式、品牌温度 | 产品不是摆件，要参与仪式动作；结尾回到人和产品的关系 |

## 通用视觉发动机库

将可见造型和运动机制接在同一条创意上：本表先选“画面发生什么”，后文运动母版与效果语法再补触发、路径、反馈和回收。同名机制共用一个规则，不因分镜、生图和生视频重新选择。每条视频一个主发动机，每格最多增加一个低存在感辅助机制；所有变化服从同一主线。

| 视觉发动机 | 可见画面与机制 | 适用表达 |
|---|---|---|
| 产品变世界 | 包装、瓶子、设备或食物成为山体、建筑、岛屿、游乐场、赛道或城市 | 品牌世界、户外、清爽、丰富、探索 |
| 世界装进产品 | 包装开口、屏幕、杯中、瓶身或盒内出现完整微缩世界 | 原料来源、功能生态、想象力、沉浸 |
| 尺度反转 | 产品巨物化，人物、车辆、动物、树木或建筑成为尺度参照；先建立正常尺度，再揭示巨大主体的接触、投影与功能互动 | 强冲击、地标感、产品主角 |
| 语义融合 | 两个形状或含义相关的对象融合成一个新物体，如球与水果、车轮与井盖 | 双关、跨界、功能联想、概念广告 |
| 材质转译 | 环境或概念层变成冰、水、奶油、玻璃、布料、金属、纸张、像素或植物；真实产品的锁定材质不被替换 | 口感、肤感、温度、轻盈、坚固 |
| 结构拆解 | 产品、饮品或系统按层级悬浮拆开，清楚展示组成和关系 | 原料、工艺、技术、功能解释 |
| 真实与插画融合 | 真实产品进入手绘、漫画、拼贴、涂鸦或纸张世界并产生接触；真实底层保持可信，二维元素只外化一种感受 | 趣味、年轻、故事感、信息表达 |
| 角色进入主题世界 | 人物或角色进入由地点、产品、文化元素组成的完整幻想空间 | 文旅、角色、活动、品牌故事 |
| 感官高潮 | 液体飞溅、冰裂、拉丝、果肉、气泡、粉末、风或声音波形冻结在最强瞬间；声音与画面只强化一种目标感官 | 食品饮料、美妆、清洁、声音 |
| 极端视角 | 鱼眼、顶视、贴地、微距、第一视角、小星球或强迫透视改变空间理解，让角度提供新信息 | 运动、旅行、潮流、沉浸 |
| 球形世界/空间卷曲 | 城市、景区、建筑或道路沿球面环绕主体，地平线弯曲成可探索的小世界 | 文旅、城市、冒险、全景体验 |
| 平面入口展开世界 | 地图、卡片、票据、包装或书页在前景被手持或打开，后方真实世界从平面内容中生长出来 | 文旅、活动、导航、故事入口 |
| 鱼眼动作场 | 超广角或顶部鱼眼把球场、房间、街道变成环绕动作舞台，主体肢体与地面几何共同制造冲击 | 运动、潮流、饮料、音乐 |
| 手绘能量附着 | 手绘线、涂鸦、火花、波纹或符号紧贴手势、饮用、奔跑、击打等真实动作生长，不随机撒满画面 | 能量、口感、情绪、年轻表达 |
| 感官仪式化 | 开盖、舀取、倾倒、饮用、喷洒或触摸成为有花瓣、晶体、光斑、飞溅和环境回应的完整仪式 | 食品、美妆、香氛、生活方式 |
| 道具引导叙事 | 地图、球、瓶、勺、线、门票或包裹成为注意力和换场接力物；经过孔洞、门缝、屏幕或画边触发换场，终点解释产品或主题 | 旅行、流程、探索、连续剧情 |
| 运动路径实体化 | 运镜轨迹、人物路线或物体抛物线变成可见光带、液体、文字、道路或结构 | 速度、运动、旅程、转场 |
| 单动作多状态预演 | 同一核心动作在连续画面中按准备、触发、峰值、落定展开，每幅冻结一个明确阶段 | 产品演示、体育、食物、效果展示 |
| 图形与文字空间化 | 几何、界面或少量文字成为地面、轨道、门、阴影、遮挡或空间结构；文字大小、粗细、裁切和生长承担语义动作 | 科技、功能信息、品牌排版 |
| 功能变环境 | 降噪成为寂静结界，续航成为无尽道路，清洁成为污渍退潮，效率成为自动运转的城市 | 抽象功能、软件、科技、服务 |
| 物理规则改写 | 重力反转、时间冻结、液体向上流、物件自动归位、影子先于主体行动 | 惊奇、性能、效率、魔法感 |
| 产品自编舞 | 产品、零件、食材或包装自动弹出、排队、堆叠、旋转、拼合或归位 | 系列产品、丰富度、结构、节奏 |
| 重复增殖 | 单一产品、符号或动作按规律复制成阵列、波浪、螺旋、隧道或人群 | 规模、选择多、节奏、记忆 |
| 门户穿越 | 从瓶口、包装开口、屏幕、镜面、文字孔洞、门窗或产品结构进入另一空间 | 探索、功能入口、世界切换 |
| 框中世界 | 画框、手机、屏幕、包装窗、展柜或纸面内部拥有独立空间并回应外层；拉回外层时解释内外关系 | 虚实关系、内容平台、艺术、叙事 |
| 倒影双世界 | 主体与水面、镜面、玻璃、金属反射中的另一状态同时成立 | 对比、身份、反转、高级感 |
| 前后状态共存 | 同一画面通过切面、镜面、左右空间或主体两侧同时呈现问题与结果 | 前后对比、功能证明、转变 |
| 时间切片 | 同一动作的多个阶段被冻结在一个空间，形成轨迹、残影、连续姿态或时间层 | 速度、运动、过程、成长 |
| 多屏记忆场 | 多块悬浮屏幕、相框、窗口或画面碎片围绕人物分布，每块承载不同时间、地点、选择或信息 | 回忆、内容平台、人生片段、信息过载 |
| 物件悬浮星座 | 产品、食物、工具或生活物件围绕人物按轨道、层级或因果关系悬浮，主体视线连接其中关键物 | 选择、想象、丰富度、超现实日常 |
| 容器释放世界 | 包装盒、杯子、袋口、抽屉、屏幕或门持续涌出产品内容、原料、人物、场景或符号 | 丰富、发现、开箱、功能展开 |
| 中轴倒影定版 | 建筑、产品或人物沿水平轴与水面/镜面形成上下对称，倒影区可承载标题或第二状态 | 城市、品牌、仪式、高级收束 |
| 色块对答空间 | 两个高纯度色场、人物方向或状态形成上下/左右问答，靠姿态和文字完成冲突与回应 | 态度、选择、对比、人物表达 |
| 主体静止/世界运动 | 人物或产品稳定居中，周围屏幕、物件、光影、文字或环境持续运动 | 内心世界、专注、控制、沉浸 |
| 跨时空交接 | 上下、左右或前后两个地点通过同一只手、同一产品或同一动作递交，来源端直接把结果送入使用端 | 原产地、供应链、品牌故事、服务连接 |
| 镜头冲击物 | 球、液滴、产品、食材或道具高速逼近镜头成为超大前景，人物动作和环境透视在后方展开 | 体育、速度、冲击、第一视角 |
| 水线双层世界 | 水面、液面、玻璃或透明界面把画面切成上下两层，同时看见入水冲击与水下产品状态 | 饮料、护肤、清洁、清凉感 |
| 产品阵列编舞 | 同一产品按对角线、棋盘、波浪、环形或透视队列排列，并用旋转、正反面或状态差形成节拍 | 系列感、包装展示、节奏、规模 |
| 编辑型产品生态 | 产品、原料、几何软体、棋盘格、色块、标题和小型信息组件组成杂志封面或品牌网页式的完整视觉系统 | 新消费、食品、潮流、品牌视觉 |
| 光影造型 | 光束、投影、阴影或高光直接组成产品轮廓、人物关系、标志形状或路径 | 高端、悬念、品牌识别 |
| 负空间显形 | 空白、缺口、剪影或被移除的部分组成第二个主体、文字或产品轮廓 | 极简、环保、双关、公益 |
| 共生融合 | 人物、自然、建筑、产品或机械结构彼此生长、嵌合、穿戴或共享轮廓 | 可持续、联名、人与科技、生命力 |
| 剖面透视 | 切开产品、建筑、食物、设备或空间，同时看到外观与内部运行世界 | 工艺、成分、技术、空间解释 |
| 数据实体化 | 数据、波形、路线、进度、关系网或界面状态变成可触碰的实体空间 | 软件、人工智能、企业、科技 |
| 图案接管 | 包装纹样、品牌图形、原料形状或文化符号从局部扩散并重组整个场景 | 品牌资产、包装、节庆、文化 |
| 风格入侵 | 写实空间被像素、漫画、纸艺、黏土、针织、低多边形或手绘逐步接管 | 创作工具、年轻品牌、风格展示 |
| 动作过程可视化 | 气味、声音、温度、速度、压力、触感或情绪通过轨迹、颜色、形变和环境反馈显现 | 感官、运动、音乐、情绪 |
| 系统世界化 | 工作流、供应链、服务流程、产品模块或企业能力被建成运行中的微缩世界 | 企业、平台、流程、复杂系统 |
| 首尾形状闭环 | 开场物体、孔洞、轮廓或动作经过变形后，在结尾回到产品、标志或主题形状 | 品牌记忆、完整叙事、循环短片 |
| 城市地标装置化 | 品牌资产或产品结构成为真实城市里的临时地标，航拍、低机位或穿越不断新增尺度、材质和人群信息 | 城市、活动、发布、地标记忆 |
| 纸张/拼贴信息剧场 | 便签、撕纸、胶带、报纸栏、台历与手指组成信息层；纸片有边缘、纹理、投影、角度和落位声，按氛围、线索、关键词、行动释放 | 信息表达、手作、年轻、活动 |
| 生活方式焦点 | 清晰产品进入虚化但可辨的办公、厨房、海边或通勤背景；水珠、冰块、肤感、布料、标志和手部动作证明感官 | 日常状态、生活方式、质感 |
| 小物冒险通道 | 食材、液滴、灰尘、数据卡、线头或零件进入巨大流程通道，低机位或微距跟随加工、净化、传输、整理、连接，每关证明一个过程 | 流程、技术、食品、探索 |
| Logo/品牌形状变道具 | 品牌标志、轮廓、色块或主张字形成为自然场景中的物体、错觉、道具或机关，最后稳定成真实标志、包装或主张 | 品牌识别、悬念、记忆回收 |

本表不是封闭菜单。后文的悬浮、时间冻结、折叠空间、无限镜像、投影映射、双重曝光、粒子聚合、形状蒙版、色彩蔓延等效果均可参与；选择标准是能否把当前核心表达变成可看懂、可确认、可运动的画面。涉及产品变世界、材质或共生时，创意层不得篡改已确认的真实产品、人物、标志和文字。

母版选择规则：

- 同一条短片只让一个母版做主视觉；另一个母版最多作为开场钩子、转场或尾帧辅助。
- 母版要和核心表达发生因果关系。例如巨型屏幕证明创作画布被放大，纸张拼贴证明活动信息被手工组装，浅景深咖啡证明城市生活方式的专注时刻。
- 凡是可以换成任意品牌仍然成立的母版，都必须补一个当前主体独有的触发：产品结构、品牌色、logo 轮廓、使用动作、场景人群、声音或尾帧主张。

## 玩法选择器

玩法选择器不是模板匹配器，而是发散和筛选工具。同一个产品可以承载多种玩法，同一种玩法也可以迁移到不同品类；选择时看它是否服务当前核心表达，而不是看品类表里有没有“推荐”。例如鲜奶可以做牧场源头、生长生成、包装信息萌发、奶牛节拍舞、早餐第一视角或杯中奶浪幻变；最终只选最能证明“新鲜/天然/活力/治愈/亲子早餐”等当前核心的一条做主玩法，其余最多作为辅助节点。

选择器必须先避开当前品类的自动联想，再看是否需要把某个自动联想改造成非默认机制。改造标准是：同一素材换成别的品牌时玩法是否会明显失效；去掉产品结构、Logo、包装、使用动作或卖点证据后，画面是否还剩普通特效。如果仍然成立，说明玩法没有长在当前视频里，必须重选。

选择顺序：

```text
核心表达
  -> 受众为什么会在意
  -> 最小证明动作
  -> 可发散玩法候选
  -> 哪个玩法最能把核心变成视觉事件
  -> 哪些辅助玩法能补停滑、证明或记忆
  -> 生成可执行秒段
```

玩法候选要先发散再收束：

| 当前核心 | 可发散方向 | 收束判断 |
|---|---|---|
| 天然新鲜 | 源头全流程、生长生成、动物/原料拟人、晨间第一视角、包装萌发 | 哪个方向最能让观众相信“新鲜从哪里来” |
| 精致丰富 | 礼盒自编舞、悬浮阵列、开箱仪式、物理填满、微距巡航 | 哪个方向最能让观众看清“多、精、好送” |
| 高效解决 | 痛点即时消失、混乱到秩序、进度条完成、旧新争夺、屏幕结果前置 | 哪个方向最能证明“少一步/快一步/更干净” |
| 情绪治愈 | 材质世界、慢动作仪式、第一视角体验、暖光生活切片、角色小任务 | 哪个方向最能留下舒服、陪伴或想靠近的感觉 |
| 发布期待 | 光影揭幕、局部显影、倒计时、轮廓线索、声音先行 | 哪个方向既保留悬念又不让主体缺席 |

选择器禁止两种极端：

- 机械套品类：鲜奶只能生长、汽车只能光影、巧克力只能悬浮、鞋只能奔跑。品类只是证明任务，不是创意上限。
- 过度发散失焦：为了惊喜加入多个互不相关的奇观，导致观众记不住产品为什么好。

母版使用限制：

- 15 秒以内只保留一个主母版，并按实际需要选择 `1-3` 个辅助机制；辅助机制只能分别服务停滑、过渡、证明补强、情绪升温、尾帧记忆或收束中的一个职责，不能和主母版抢核心，也不能为凑数量硬加。
- 母版必须和品类证明绑定。护肤的水光花影要证明焕活或肤感；跑鞋的多人奔跑要证明百搭和动感；巧克力悬浮要证明精致和丰富；清洁喷雾的消失要证明清洁力。
- 极简产品展示也要有运动事件。360 旋转、开盖收纳、手部拿起、纯白悬浮不是偷懒；要写清旋转顺序、细节停留、声音触发和尾态闭环。
- 风格化世界不能只换材质。乐高、黏土、毛毡、卡通和移轴必须让产品核心变成这个世界里的任务、互动或奖励。

## 现实空间超现实合成

城市、街区、室内、商场、办公室、厨房、运动场、牧场和展厅都可以变成创意舞台。不要只把产品摆在场景里；可以让场景被产品机制影响、被品牌风格入侵、被物体尺度改写，或成为功能证明的巨型演示板。使用前仍然先问：这个超现实变化证明什么、让观众记住什么。

常用机制：

| 机制 | 作用 | 写法 |
|---|---|---|
| 尺度反转 | 让普通物件或产品资产突然变成城市/空间级主角 | 巨型口红擦过楼面、耳机盒像地铁站开合、饼干月亮落进街口；最后回到真实产品尺寸，避免只剩奇观 |
| 环境功能隐喻 | 用建筑、地面、房间、道路或桌面演示功能 | 吸力让建筑柔性弯折、直发器让扭曲高楼归正、清洁喷雾让油污街区退潮；必须明显是创意隐喻，不能冒充真实功效 |
| 风格入侵 | 品牌图案、材质或艺术风格逐步接管真实空间 | 波点、积木、毛毡、奶白包装纹理、品牌色线条从产品触点蔓延；入侵范围随叙事升级，结尾回收到品牌/产品资产 |
| 视角突破 | 用不常规视角让熟悉空间重新可看 | FPV 穿街、低机位城市峡谷、航拍俯冲、等距微缩、从杯口/包装内看外部世界；视角变化必须带来新信息 |
| 拟人化响应 | 物体、建筑、包装或食材获得反应和意图 | 橙子在路口表情变化、苹果沿街奔跑、楼体随节拍起伏；反应要服务情绪或卖点，不做无意义卖萌 |
| 虚实接触 | 虚拟物件和实景发生可感知的碰撞、遮挡或投影 | 巨型产品压出接触阴影、卡通元素绕过路灯、粒子被人物手势拨开；接触点越可信，奇观越成立 |

使用这类玩法时，只选一个主机制：如果主玩法是尺度反转，风格入侵只能作为视觉铺垫；如果主玩法是环境功能隐喻，拟人化只能帮观众看懂反馈。不要在 15 秒内同时做巨型化、城市变形、卡通入侵、FPV 穿越和剧情反转。

场景合成的叙事线必须有触发动作：

```text
真实场景建立
  -> 产品/人物/声音/节拍触发异常
  -> 空间按一个规则变化
  -> 变化证明核心表达
  -> 回收为产品、品牌、人物状态或行动入口
```

常见迁移：

- 产品功能：让环境替产品承受夸张效果，例如清洁、顺滑、吸力、弹性、速度、稳定、降噪或补水；结尾再回到真实使用动作。
- 品牌调性：让城市或空间被品牌审美改写，例如高端光影、童趣材质、国风纹样、运动节拍、科研秩序或自然生长。
- 活动传播：把城市地标、街口、人流、橱窗或大屏变成参与感入口，例如倒计时、路线追踪、群像汇聚或巨型装置揭幕。
- UGC 种草：保留真实手持和口语感，只在一个关键动作上发生超现实反馈，例如喷一下、拉一下、咬一口、开盖、点击或走出一步。

现实空间玩法的失败信号：

- 只做了炫技合成，但观众说不出产品/品牌为什么出现。
- 巨型物件没有重量、阴影、遮挡、透视和接触反馈。
- 城市/空间被改造得太满，产品、人物或核心文字反而不可读。
- 异常规则每镜都变，观众无法预测下一步，也无法记住主玩法。

通用视觉母题可以跨通用创意、产品广告、品牌 TVC、企业片和 UGC 使用，但必须换成当前主体自己的触发动作和回收方式：

- 符号贯穿：一个符号在不同载体上反复出现，例如眼睛、圆环、窗口、手势、按钮、花心、屏幕状态或产品轮廓。第一次负责建立主题，中段负责升级关系，结尾负责消失、反向凝视或回到品牌/产品/人物状态。
- 共生融合：人物、产品、自然、空间或数据在边缘处无缝接合，例如头饰接入背景花朵、衣料延伸成场景、产品轮廓变成空间结构、UI 卡片进入真实桌面。重点是身份关系，不是单纯拼贴。
- 尺度容器：主体被放入巨大或微缩的容器中，例如花心、掌心、屏幕、包装、杯口、车内、城市模型或数据空间。尺度变化必须说明主体和容器的关系，并在结尾回到真实尺寸或可理解身份。
- 框架闭环：用同一个框架、遮挡物或动作开场和收束，例如手掌伸入/遮镜、门框打开/合上、花瓣展开/闭合、屏幕亮起/熄灭、包装开合。框架负责建立观看关系，不只是转场花活。
- 混乱到秩序：前段用手持、倾斜、冷灰、现场噪声、杂乱动线建立失控；后段用稳定机位、对称、统一色彩、清晰主体、干净声音和完整结果建立解决。它适合工具、AI、效率、收纳、服务和流程改造，但前后对比必须对应真实能力。

## 图形构成和状态变化

排名板、对比板、进度条、卡片、图标、数据标签、数据卡、动态图表、UI 面板、手绘标注和大字标题不是装饰，也不是某一类视频的专属模板。它们是通用表达工具，UGC、产品广告、解释器、排行榜、品牌片、企业商务、采访和教程都可以使用；使用前必须适配当前主体、场景、受众和事实边界。它们必须让观众一眼看出当前关系：谁被比较、什么状态改变、下一拍新增了什么信息。

每条视频都要判断是否加入动画效果或动态信息层。动画效果包括两类：一类是实景视觉效果，例如实景动画、粒子聚合、材质转译、形状蒙版、物理规则变化和空间穿越；一类是编辑/图形动效，例如卡片、图标、进度条、排名、数据卡、状态提示、动力学排版和 UI motion。两类都必须服务同一条主线，不能互相抢戏。

动效要先有性格，再有招式。只有 UI、MG、动力学排版或批量元素是主要表达时，才按下列维度判断；不单独填写卡片：

```text
动效能量：低 / 中 / 高
动效调性：严肃 / 克制 / 亲和 / 活泼 / 大胆
主时长倾向：短促 / 标准 / 舒缓
路径：直线 / 弧线 / 轨道 / 物理抛物线 / 手势路径
缓动：干净减速 / 对称 ease / 轻微回弹 / 强过冲
批量元素：错峰 / 加速 / 发牌式 / 波纹式 / 阶梯式
次级动作：无 / 轻微呼吸 / 轻弹 / 阴影变化 / 光感变化
hold/rest：关键画面停留多久
声音句式：静默 / click / whoosh / riser -> impact / sparkle
禁用感：廉价 PPT / 过度 glint / 抖屏 / 假 UI / 乱码
```

动效性格从主体和场景推导，不凭手感套模板：金融、政企、医疗和 B2B 默认更克制、路径更直、过冲更少；消费、社交、娱乐和运动可以更快、更弹、更错峰；奢侈品、时尚和高端产品可以更慢、更稳、更少次级动作。用户明确品牌调性或参考素材时覆盖默认推断。

每个镜头只让一个主动效当主角。飞入、堆叠、翻页、粒子聚合、扫光、震动、滚动、卡点切换等手法可以复用为辅助语法，但不要在同一镜头同时抢主角；同一种高存在感手法在一条片中也不要反复当主角。关键信息落定后要给观众看清的呼吸位：品牌字标、核心数据、完整 UI 状态、产品结果、重要人物反应和尾帧 CTA 都应有短暂停留；批量元素归位、排名落定或进度完成后至少留出可感知静止，不要刚到位就切走。

速度感来自加速度和节奏组织，不来自匀速快移。批量卡片、数据行、图标、照片、产品模块和排行榜入场时，优先用非线性缓动、错峰、越来越快/越来越密的节奏或物理隐喻；满板后给静止确认。匀速直线、逐个同速飞入、每张卡都闪一下、每个图标都发光，会显得像低质模板。

卡点时只把节拍当时机，不把每个鼓点都变成全画面冲击。强 BGM 下可以把 kick 当作大冲击候选、snare 当作替换或切换候选、hihat 当作微动密度参考；全画面缩放、震屏、闪帧、负片、slam 只给全片少数最强节点，其余拍点优先作用在主角元素、图形层或声音上。

UI、数据卡和产品模块的运动终点必须有真实或可解释的槽位：输入框、列表行、卡片网格、结果面板、通知区、导出状态、包装结构、货架位置或人物手部动作。元素不能永久悬浮在页面上方冒充产品能力；信息密集和文字多的 UI 优先正视或轻微透视，文字特写避免大角度仰拍/俯拍。

光效和粒子只服务主角、转场或结果，不群发。glint、扫光、泛光、火花、粒子和高亮边缘最多给主角或关键节点使用；在圆角卡片、按钮、包装边缘或屏幕模块上出现时，必须符合边界、材质和光源逻辑，不能溢出、糊成一片或盖住文字。

设计图形时先确定三件事：

1. 观众第一眼看哪里。
2. 观众正在比较什么。
3. 下一拍什么进入、替换、积累、揭示或完成。

图形动效不是单纯进场动画。每个动效都必须属于一种语义动作：到达、替换、积累、比较、揭示、完成、失败回弹、状态锁定、路径追踪、计数递增、权限解锁、选择聚焦、分组归类、风险阻断或结果定格。

| 图形系统 | 主要职责 | 使用方式 |
|---|---|---|
| 排名板/清单 | 记住前面判断，承接当前项目 | 已有项保持状态，新项进入时改变位置、高亮或补充证据 |
| 对比板 | 让前后、A/B、旧/新关系一眼可读 | 两侧信息量和视觉权重要可比较，结论动作落在差异上 |
| 进度条/时间轴 | 展示步骤、效率、升级或流程推进 | 每次变化对应真实步骤或叙事节点，不空转 |
| 卡片/标签 | 识别对象、卖点、证据或 CTA | 文本短、位置稳定，不遮挡人脸、产品和证明动作 |
| 图标/数据点 | 把抽象信息变成可扫读结构 | 数据和客户事实必须来自材料；概念图标不能冒充真实指标 |
| 数据卡/动态图表 | 把结果、指标、案例或流程变化变成状态 | 数字、客户、成绩和指标必须有来源；没有来源时只能做概念状态，不冒充真实数据 |
| UI 面板 | 说明任务流、状态变化或结果 | 真实 UI 用素材，概念 UI 明确服务解释，不伪装成真实产品界面 |
| 手绘标注/反应贴片 | 强调口播观点、动作反馈或幽默节拍 | 贴近触发动作、表情或声音出现，短促、轻量、不遮挡证明 |
| 路径追踪线 | 展示路线、流程、因果、物流、服务链 | 线条从真实起点长出，到真实节点停止；每到一站必须新增信息 |
| 状态锁/徽章 | 表示通过、完成、安全、合规、已连接 | 徽章只在状态被动作触发后出现，不能先贴一个认证感图标冒充事实 |
| 错误回弹/阻断 | 表示旧方法失败、风险被拦截、输入不合格 | 回弹要短促且有原因，随后给正确路径或产品解决动作 |
| 聚焦放大镜/裁切窗 | 解释细节、材质、UI 局部或证据 | 放大区域来自真实画面，边缘和指向清楚，不虚构不存在的细节 |
| 扫描/识别框 | 展示检测、识别、选择、锁定目标 | 扫描必须有目标和反馈，避免无意义科技线；敏感/医疗/安全判断不得伪装成真实结论 |
| 分层剖面/堆叠展开 | 解释结构、成分、流程层级或产品组合 | 每层对应真实结构或概念层级，展开后要回到整体，不永久散架 |
| 计数器/步进器 | 展示数量、进度、倒计时、效率变化 | 数字必须有来源或明确概念化；计数结束要有完成状态 |
| 光标/手势轨迹 | 表示操作意图和 UI 因果 | 轨迹从真实手势、鼠标或触点开始，落到按钮、输入框、滑块或结果区 |

产品广告可用对比板证明前后变化，用进度条展示效率，用卡片承接卖点；解释器用图形对象跟随口播逐步变化，而不是一次性铺满；口播、采访、创始人和员工出镜可以用观点卡、问题卡、步骤条、反对意见卡、数据卡和图标状态点承接表达结构；排行榜用排名板保留已判断状态，新项目进入时改变位置或高亮；企业数据可视化中的数字、地图、节点和流程线必须对应真实事实。

动效进入 PE 的最小表达单元是“触发 -> 运动 -> 状态变化 -> 落点停留”。不要把动效写成统一后缀；必须嵌入时间轴。例如：

```text
0.6-1.2 秒，包装被撕开时，口味标签不是直接飞入，而是从撕口边缘弹出 3 个小卡片，沿包装弧线错峰滑到右上角，第一张停住后第二张才出现，轻 pop 声跟随每次落位，最后 0.3 秒停在包装旁边，不遮挡品牌名。
```

如果写不出触发动作、路径、语义和落点，说明这个动效不该加。

## 视觉效果优先链路

不要从“卖点”直接进入“分镜”。先走：

```text
产品/主题真相
  -> 核心感受或核心能力
  -> 熟悉锚点
  -> 不对劲变量
  -> 运动母版
  -> 主视觉效果
  -> 异常规则
  -> 可复述视觉事件
  -> 分镜和 PE
```

视觉效果的职责按传播目标选择：

| 传播目标 | 视觉职责 | 优先画面事件 |
|---|---|---|
| 停滑 | 第一秒制造异常、结果或未解释变化 | 产品未完整出现前，空间、声音、材质或物体行为已被改写 |
| 种草 | 把抽象感受变成想靠近的体验 | 味道、肤感、香气、舒适、陪伴、仪式感被外化 |
| 解释 | 把复杂功能变成可理解路径 | 数据流、空气流、清洁路径、吸收路径、任务链路 |
| 证明 | 让卖点有可见证据 | 前后变化、过程细节、材质反应、真实 UI 结果、动作反馈 |
| 转化 | 强化产品识别和购买理由 | 产品早出现、动作清楚、结果稳定 |
| 品牌记忆 | 把品牌资产做成可复述符号 | 品牌色、轮廓、声音、logo 形状、包装结构反复变奏 |
| 发布预热 | 制造未揭示期待和规模感 | 局部资产、倒计时、空间开启、能量聚合、轮廓显影 |
| 信任/招商 | 把能力、规模和秩序视觉化 | 系统运行、真实场景、数据实体、流程闭环、客户/行业证据 |

选定目标后，用同一主视觉效果贯穿开场、中段和结尾：开场让观众追问，中段证明或升级，结尾把奇观收回到产品、品牌、人物状态或行动结果。

## 不对劲变量生成法

保留一个熟悉锚点，只改一条现实规则。不要同时改尺度、材质、时间、空间、视角和 UI。

| 变量 | 适合钩子 | 适配方式 |
|---|---|---|
| 视角不对 | 从产品内部、包装夹层、屏幕后、门缝、眼神反光看 | 入口来自真实结构，镜头最终拉回入口主体 |
| 尺度不对 | 小物巨大化、世界微缩化、局部成为地形 | 尺度变化证明影响范围、精密结构或感官强度 |
| 物理不对 | 重力、时间、声音、惯性、方向被改变 | 产品动作成为规则源，场景按新规则完成任务 |
| 材质不对 | 物体变液体、冰、金属、纸、光、雾、颗粒 | 隐喻来自真实质地、声音、温度或触感 |
| 系统不对 | 日常空间被游戏、地图、操作系统或电商规则接管 | UI 必须改变现实行为，不只是贴屏 |
| 时代不对 | 同一物件穿过不同年代、版本或风格 | 用同一线索保持连续性 |
| 因果不对 | 微小动作触发夸张后果，后果解释产品 | 开场给后果，中段追溯触发，结尾回到产品真相 |
| 身份不对 | 产品、数据、食材、灰尘、衣物或空间像角色行动 | 给对象简单动机，最终让产品解决或统领 |

## 运动母版

运动母版有用，但它是“整条片如何连续运动”的单一结论，不是另一张必填表。需要强运动设计时，从下列维度选择必要项，压成一句连续路径并写回总控卡；普通视频直接使用真实动作链。

需要运动母版时只写一句：`[第一动作] 触发 [主体] 沿 [路径] 连续经过 [关键变化]，在 [声音/剪辑重拍] 产生 [反馈]，最后回到 [产品/品牌/人物/主题]`。写不成一句连续路径时，不使用运动母版术语，回到真实动作链。

| 运动母版 | 好看原因 | 适合入口 | PE 句法 |
|---|---|---|---|
| 冲入入口 | 从熟悉开口高速进入陌生内部世界 | 包装袋、瓶口、屏幕、杯口、吸口、衣柜、车门 | 近景动作打开 X，镜头被吸入入口，穿过卖点外化世界，最后从真实产品处冲出 |
| 追随移动物 | 观众跟着一个物体穿过连续场景 | 碎片、水滴、光点、数据卡片、衣物、快递 | 镜头贴近跟随 X 移动，每经过节点触发一次变化 |
| 前景遮挡揭示 | 遮挡物擦过镜头，每次露出新信息 | 手部、包装、门框、屏幕、衣物、蒸汽 | 前景遮挡画面，擦过后场景状态改变，最后露出产品真相 |
| 下坠/上升事件 | 垂直运动带来重力爽点和层级变化 | 食材、液滴、零件、礼盒、服饰、家电部件 | 主体沿垂直方向穿过不同层级，每层证明一个卖点 |
| 环绕压力 | 镜头围绕主体，背景同时变化 | 美妆、珠宝、家电、3C、人物时尚、品牌符号 | 镜头环绕主体，背景随角度切换不同状态或证据 |
| 一拍一变 | 每个音乐重拍触发一个变化 | 多 SKU、零食、服饰、活动预热、潮流品牌 | 每个重拍只改变一个变量，动作、声音和结果同步 |
| 对抗/争夺 | 两个状态在画面内抢空间 | 使用前后、旧流程/新流程、混乱/秩序 | 两种状态挤压，产品动作让目标状态占据全画面 |
| 倒推痕迹 | 开场给异常结果，再沿痕迹回到触发 | 清洁、护肤、食品、SaaS、家居、悬念 | 镜头沿痕迹倒退，逐步看到过程线索，最后找到触发点 |
| 同物穿史 | 一个真实物件贯穿时代、版本或场景 | 3C、周年、经典包装、老字号、新品发布 | 同一物件保持位置/运动不变，只让环境和版本变化 |
| 人物反应接力 | 先拍反应制造好奇，再揭示原因 | 食品、香氛、娱乐、活动、门店、UGC | 连续反应后反向揭示每个人被同一动作影响 |
| 冷静中心/失控背景 | 人物的稳定姿态和外部失控形成反差 | 作者电影荒诞、灾难奇观、人物时尚、默片喜剧 | 固定或平移镜头守住人物中心，背景灾难逐级升级，人物只用微表情和小动作回应，结尾回到人物享受或掌控的状态 |
| 导览角色巡游 | 观众跟随一个角色或物件连续穿过空间 | 文旅、展览、美术馆、品牌空间、周年庆 | 角色从邀请函、门票、光点或入口出发，每到一个节点触发展品、建筑或人群变化，最后带观众抵达群像庆典或主题尾帧 |
| 框架入口接力 | 一个个框架成为进入下一层空间的门 | 画中画、空间穿越、展览活化、奇幻空间 | 画框、窗框、门框、展柜或屏幕先作为构图边界，随后被动作、光线或主体突破，镜头穿过框架进入下一场景 |
| 符号换载体 | 同一视觉符号不断换物理载体 | 时尚概念、品牌记忆、无台词隐喻、产品轮廓记忆 | 符号先出现在 A，随后转移到 B/C，每次出现关系升级，结尾让符号回到主体、品牌或产品锚点 |
| 共生缩放 | 主体和环境在尺度与边界上互相吞吐 | 自然主题、人物肖像、产品感官世界、空间身份 | 主体先与环境边缘对齐，再进入巨大/微缩容器，经历包裹、吞没、重生或复位，最终回到真实关系 |
| 混乱秩序切换 | 视听系统从失控跳到高度规整 | 工具解救、AI 生成、收纳清洁、效率软件、流程服务 | 前段手持和杂乱声音制造压力，触发动作后切入稳定、对称、统一色彩和清晰结果，用风格对比证明能力 |
| 音源碰撞融合 | 两个声音/风格先分开，再被节拍统一 | AI 音乐 MV、创意实验、工具玩法、跨文化混搭 | 先分别展示 A/B 的声音、颜色和视觉符号，随后用波形、色彩、故障或粒子把两者叠加，对齐节奏后进入融合场景 |
| 转盘三视图 | 主体旋转替代摄影机环绕 | 穿搭、人物介绍、产品展示、好物参数、技术流短视频 | 固定机位守住中心轴，主体在转盘上缓入缓出旋转，侧面或背面作为换装/切换盲区，最后正/侧/背或多角度并置定格 |
| 排版节拍器 | 文字和几何图形作为虚拟摄影机运动 | 歌词 MV、标题片、AE 动力学排版、品牌关键词 | 用黑白反相、缩放、横移、旋转、遮罩和递归图形卡住鼓点，关键词在高潮获得最大尺寸、唯一彩色或最强构图权重 |
| 静机位层叠折叠 | 固定真实主体，逐层把现实空间改造成海报化世界 | 城市地标、建筑空间、门店、展馆、产品场景、特效教程 | 固定机位保留主体位置，先做色彩或画幅升级，再按背景、地面/水面倒影、光源、前景剪影、大字和签名/标识的顺序入场；动态元素独立运动，最终停在可读的海报态 |

短片直出转写节奏参考：

```text
15秒：0-2 秒锚点和第一动作；2-5 秒进入母版；5-9 秒异常扩散；9-12 秒高光或揭示；12-15 秒回收。
30秒：0-3 秒异常停滑；3-8 秒建立规则；8-14 秒规则升级；14-20 秒反转或尺度扩展；20-26 秒证明和回收；26-30 秒尾帧稳定。
```

最终 PE 仍必须按 `references/storyboard-contract.md` 的镜头密度与映射、`references/asset-generation.md` 的逐秒段合同写足。

## 创意机制和效果语法

效果名只是入口，真正要复用的是深层语法。

先写世界规则，再写效果。世界规则决定本片中什么东西可以违反现实、什么东西必须保持真实、异常从哪里开始、扩散到哪里、怎样收回。效果只是在这个规则里的运动表现。没有世界规则时，不要直接写“乐高风格、子弹时间、CG 微缩、花瓣漂落、鱼眼运镜、界面接管现实”；必须改写成“谁触发了什么规则，哪个元素怎样变化，产品/人物/品牌信息如何因此更清楚”。

世界规则落到 PE 时至少包含 5 个元素：规则源、受影响对象、运动/变化方式、证明职责、回收尾态。例如“手指按下耳机侧键，房间时间冻结，纸片和发丝悬停，耳机从人物头上脱离到画面中心 360 度慢旋，证明耳罩材质和铰链结构，最后时间恢复并回到人物佩戴状态”。这类句子比“子弹时间展示耳机”更可生成。

| 创意机制 | 不对劲变量 | 适合解决 | PE 落地句法 |
|---|---|---|---|
| 视角置换 | 观众不是从人眼看 | 停滑、趣味、反差、沉浸 | 镜头从 X 内部向外看，先看见异常反应，再揭示 X 是入口/原因 |
| 尺度错位 | 小物变巨大，大场景变微缩 | 震撼、发布感、卖点放大 | 微小动作先改变局部，再拉远看到影响范围，最后回到真实尺寸 |
| 实物线索贯穿 | 真实物件穿过时间/空间/版本 | 品牌历史、系列感 | X 经过每次切换都保持真实形态，只让环境和版本变化 |
| 蒙版故事 | 产品轮廓、洞口、屏幕成为取景框 | 抽象感受空间化 | 镜头靠近 X 轮廓/开口，内部出现卖点世界，最后合回真实产品 |
| 系统世界化 | 日常场景被游戏/地图/UI 规则接管 | 年轻感、复杂流程解释 | 场景按 UI 规则移动、升级、解锁或归位 |
| 产品结果可视化 | 不拍卖点名词，拍产品造成的后果 | 证明、转化、种草 | 触发动作后，结果从接触点沿路径扩散 |
| 反向揭示 | 先给异常结果，后给原因 | 悬念、记忆 | 开场异常，中段追溯，结尾揭示产品/人物是规则源 |
| 虚实融合 | 真实环境和动画/数据互相影响 | 抽象功能、年轻化、科技 | 虚拟元素碰到真实物体并改变位置、光影、质地或动作 |
| 材质换译 | 情绪或卖点变成液体、冰、雾、颗粒、光 | 护肤、食品、香氛、科技 | 材质变化从真实材质或使用动作长出来，结束恢复识别 |
| 规则入侵 | 外来规则迫使物体重新行动 | 强停滑、喜剧、爽感 | 熟悉场景正常运行，产品动作让一条规则失效或改写 |
| 灾难从容反差 | 外部世界越失控，主体越优雅克制 | 荒诞幽默、人物状态、电影氛围 | 镜头把主体放在稳定构图中，背景火山、陨石、洪水、人群骚动或物理异常逐段升级，主体以喝酒、整理衣角、抬眼、微笑等微动作回应，声音用优雅音乐和真实灾难声并置 |
| 艺术品活化 | 静态作品或展品获得动作身份 | 美术馆、博物馆、文旅、艺术品牌 | 先用特写锁定作品/展品的真实识别点，再让局部动作突破平面或展柜边界，进入现实空间并影响角色、光线、道具或人群 |
| 光影剪影造型 | 物体投影生成隐藏形象或关系 | 艺术感、悬念、空间诗意、品牌隐喻 | 侧光、投影、反射或体积光让普通物体在墙面、地面或雾中显出人物、动物、符号或情绪线索，随后回到真实物体解释来源 |
| 多参考融合 | 两个或多个参考源碰撞后生成第三种风格 | AI 实验、音乐混搭、视觉风格测试、玩法教程 | 参考 A 和参考 B 分别建立识别，再通过节拍对齐、色彩混合、构图叠加或故障转场进入融合结果，结尾回到玩法、素材或主题 |
| 数据标注化 | 主体被转译成可测量对象 | 技术流、穿搭、产品拆解、教程、参数展示 | 主体保持标准姿态或稳定角度，尺寸线、箭头、数字、图例和分层标签逐条出现，旋转或多视图补全隐藏信息 |
| 文字语义可视化 | 文字运动等于含义本身 | 动力学排版、歌词 MV、品牌口号、标题视觉 | 关键词的运动方式直接翻译语义，例如滑动对应下坠/滑入，螺旋对应眩晕，裁切对应危险或不完整，单点彩色对应核心隐喻 |
| 海报化空间折叠 | 真实空间被折叠成强图形世界 | 城市宣传、地标短片、门店活动、空间发布、效果教程 | 稳定真实主体 -> 黑白/低饱和原始态或普通记录态 -> 色彩/画幅升级 -> 背景或天空替换 -> 地面/水面倒影建立上下结构 -> 前景剪影、光源和大字分层入场 -> 最终海报态停留；教程片可在尾段切到图层/时间线揭秘 |
| 符号贯穿 | 一个符号在多载体中建立主题 | 品牌记忆、人物身份、图鉴式展示、无台词叙事 | 先定义符号职责，再让它在手势、道具、空间、产品或 UI 上换载体出现，最后通过消失、反向凝视或产品定版完成闭环 |
| 共生身份 | 主体与环境边界被故意模糊 | 人物时尚、自然主题、品牌世界观、产品感官隐喻 | 服装、妆容、产品形态或 UI 结构与背景元素对齐，让观众看见主体属于这个世界，结尾回到可识别主体 |
| 框架首尾扣 | 同一框架动作打开和关闭观看关系 | 第四面墙、探店入口、包装开合、屏幕演示、空间导览 | 开场框架邀请进入，中段框架接力推进信息，结尾用同一物体遮挡、合拢或反转，音效卡在触碰或闭合点 |
| 混乱到秩序 | 视听风格本身证明解决能力 | AI 工具、SaaS、家居收纳、流程服务、拍摄/设计工具 | 先把失控状态拍得可理解，再通过真实触发动作切换到规整世界，结尾回到工具、产品、结果或品牌资产 |
| 并置碰撞 | 两个世界、状态或风格相撞 | 使用前后、升级、选择 | 旧状态和新状态在同一空间争夺画面，最终被产品统一 |
| 互动式展示 | 手势、按钮、鼠标或镜头像操作界面一样控制现实 | UGC、电商、SaaS | 一个明确交互动作改变现实 |
| 过程拟人/拟物 | 食材、灰尘、数据、衣物像角色行动 | 解释、喜剧、功能 | 被处理对象有简单动机，产品是规则源或解决者 |
| 缺席证明 | 先通过痕迹证明产品存在 | 高级感、悬念、信任 | 观众先看见结果痕迹，结尾看到产品或品牌资产 |
| 文字成为画面 | 标题字、数字或 UI 文案成为实体 | 信息解释、品牌记忆 | 文字变成主体经过、触摸、破坏或重组的物理对象 |
| 一镜到底变规则 | 同一次连续拍摄中世界规则逐层变化 | 沉浸、流畅、大片感 | 全片只有一个镜头，不使用遮挡隐藏切、匹配剪辑或时间跳跃；摄影机连续跟随主体经过动作与空间节点，空间/材质/尺度递进变化 |
| 循环/首尾扣 | 结尾回到开场但意义改变 | 记忆、反转、系列 | 同一画面或声音在结尾再次出现，由产品解释原因 |

## 节点创意

叙事节点和视觉效果必须互相证明，而不是各写各的。

| 节点 | 叙事职责 | 视觉职责 |
|---|---|---|
| 风格 | 决定观众以什么心情理解 | 限定光色、材质、镜头、声音和表演尺度 |
| 开场 | 制造停滑、悬念或异常 | 立刻出现异常规则、缺席痕迹、声音钩子或符号 |
| 产品/主体登场 | 解释异常来源或第一次触发规则 | 产品、人物、包装、UI、动作或品牌资产成为规则源 |
| 高光 | 让核心卖点或主题被记住 | 把卖点放大成可复述视觉事件 |
| 反转/揭示 | 改变观众对前面画面的理解 | 用语义变形、因果倒置、尺度切换或主体揭示完成 |
| 结尾 | 回到产品、品牌、人物状态或主题 | 把奇观压缩回清晰锚点 |
| 转场 | 让镜头之间有因果和节奏 | 用形状、动作、材质、声音、空间门或数据流连接 |

可用叙事结构：异常入侵式、连锁反应式、规则揭示式、平行碰撞式、倒计时升级式、循环破局式、默片反差式、灾难从容式、导览奇遇式、艺术活化式、发现实验式、数据图纸式、歌词排版式、谜题揭示式、符号贯穿式、共生缩放式、混乱秩序式、空间折叠式、展示揭秘式。每条片只选一个主结构。

可用创意透镜：符号凝练、尺度反转、语义变形、材质隐喻、空间门户、并置碰撞、叙事瞬间、系统世界化、文字成为画面、文字入构图、数据实体化、动作/过程可视化、缺席与负空间、共生身份、框架闭环、风格反差、海报化世界。每次选择 2-3 个作用在不同节点，不要全堆进一条片。

## 叙事结构选择器

视觉玩法必须套进一条清楚的叙事骨架。不同骨架解决不同问题：

| 骨架 | 时间推进 | 适合 | 关键控制 |
|---|---|---|---|
| 蓄力 -> 爆发 -> 余韵 | 慢、暗、静地积累压力；触发点前短暂停顿；高光爆发；尾帧收气 | 运动、速度、发布、通感冲击、品牌燃向 | 蓄力约占前半到三分之二；爆发必须有声音和画面重拍；余韵回到品牌/产品 |
| 悬念 -> 揭示 | 正常场景中出现具体异常；异常扩大；最后解释异常来源 | 巨型开箱、道具线索、品牌后置、超现实广告 | 悬念要具体可追问，例如“这栋楼为什么会打开”；不能只是抽象氛围 |
| 线索贯穿 | 一个道具、颜色、光点、文字或声音穿过多场景，到终点解释意义 | 毛线、土豆、数据流、物流、路线、品牌色线索 | 线索在每个场景都必须一眼可见；终点必须产生产品/品牌/行动结果 |
| 问题 -> 方案 -> 效果 | 先给观众关心的问题，再拆解方法，最后给前后对比或成品 | 教程、工具、拍摄方法、SaaS、低成本高质感 | 问题要真实；步骤只留关键；效果要有对比证据 |
| 正常 -> 包袱 -> 反转 | 正常铺垫，异常元素制造笑点，品牌或结果二次揭示 | 幽默广告、Logo 玩法、轻喜剧 UGC | 反转必须同时解释前面异常和品牌/产品，不只为了搞笑 |
| 双线并行 -> 汇聚 | 时间线、地点线、人群线或状态线交替推进，最后合流 | 运动纪实、活动预热、品牌群像、企业案例 | 每条线要有共同符号或节拍，避免像拼素材合集 |
| 纯展示节奏编排 | 没有剧情，靠远近、快慢、动静、角度、文字和声音组织观看 | 极简排版、镜头角度合集、产品巡航、视觉实验 | 必须有节奏变化和收束尾态；不能同强度连续堆镜头 |

结构选择后，分镜必须把每个节点写进秒段：哪一秒建立、哪一秒触发、哪一秒高光、哪一秒收束。结构不能只写在方案概述里。

## 风格、开场、高光、反转、结尾、转场

风格不是“高级、电影感、年轻”这类形容词，而是一套可执行的观看规则。常用调性包括一本正经的荒诞、微观科学奇观、感官冲击、极简高端、生活魔法、系统感/科技感、谜题感、品牌符号感、灾难中的优雅从容。

作者电影或具体导演式参考必须转写成可观察的视听规则：构图是否对称或平面化，机位是否固定、横移或俯仰，色彩是复古高饱和、低饱和、冷暖对撞还是单一强调色，表演是克制、夸张还是纪录片式，音乐和环境声如何制造反差。不要只写“某导演风格”；也不要复制参考中的专属角色、台词、标志性场面或完整剧情。

开场优先用异常，不优先用产品平铺：异常先行、结果先给、缺席痕迹、符号钩子、空间入口、声音先行。

高光必须是全片最可复述的画面，不是最漂亮的特写：卖点具象爆发、尺度翻转、材质转换、数据/过程实体化、并置碰撞。

高光必须有可见因果弧：先让观众看到触发物、动作压力或异常征兆，再发生核心变化，随后给主体/人物/环境反馈和结果停留。物体突然飞出、空间突然变形、人物突然惊讶而前后没有触发与反馈，属于孤立效果，不得作为高光。15 秒短片不能用前 `5-8` 秒静止等待来“铺垫”唯一高光；铺垫本身也要每 `0.8-1.5` 秒增加线索、压力或状态变化。

反转要改变观众对前面视觉的理解：原因揭示、视角揭示、尺度揭示、语义变形、价值反转。不能为了反转而反转。

结尾不能只是机械 packshot。可以用符号回收、世界复位、余波定格、反向揭示、循环回扣；产品广告可以 packshot，但要回收开场符号、异常规则、声音或视觉余波。回到开场机位不自动等于首尾呼应：主体状态、人物关系、空间秩序、信息理解或品牌归属必须发生可见变化；若末镜与首镜几乎相同且没有新意义，就是重复镜头。

转场是叙事语法，不只是花活。每条片最好只选一个主转场逻辑：符号转场、材质转场、空间门户、动作接动作、声音桥、数据路径。每次切镜都要写清叙事理由和承接锚点；直切/硬切、叠化和黑场只能执行已经成立的关系，不能替代动作、视线、声音、形状或状态上的连接。

真实一镜到底的定义以主 `SKILL.md` 和 `references/general-creative-video.md` 为准：全片只有一个连续镜头，不使用遮挡隐藏切、匹配剪辑或时间跳跃。上表“一镜到底变规则”中的“经过遮挡物”只表示摄影机在同一连续拍摄中绕过真实前景，不表示可在遮挡处剪辑；主体行动、空间关系和摄影机路径必须从头到尾连续。

## 品类/场景语义适配

所有视觉效果和叙事逻辑都是通用机制，不按品类锁死。品类、场景和卖点只决定如何把同一个机制翻译成可信、可记住、可回收的画面事件。

适配器：

```text
原始机制：
产品/主题真相：
受众感受：
触发动作：
体验外化：
场景响应：
证明锚点：
动态路线：
回收方式：
风险边界：
```

不同品类的语义入口：

- 食品/零食：开袋、咬下、气泡、拉丝、碎裂、温度、香气、分享动作、包装图形。
- 护肤/美妆：按压、滴落、涂抹、吸收、肤感、光泽、质地、瓶身、使用前后。
- 香氛/礼赠：喷雾、瓶口、礼盒、布料、记忆空间、季节房间、托举仪式。
- 宠物用品：宠物路线、进食节奏、嗅闻、追逐、窝垫、牵引、主人互动。
- 家电/家居：启动、吸入、烘干、净化、收纳、开合、模式切换、噪音变化、空间秩序。
- 3C/SaaS：点击、连接、通知、界面任务流、数据流、响应速度、文件变化、结果面板。
- 服饰/配饰：拉链、纽扣、镜面、面料纤维、五金、走动、搭配场景。
- 汽车/出行：车门、车灯、后备箱、导航界面、道路、风、光轨、车身细节。
- 文化/艺术/展览：邀请函、门票、画框、展柜、展签、雕塑轮廓、建筑中庭、地面倒影、观众路线、导览角色、馆藏色彩和庆典符号。
- 音乐/MV：波形、唱片封面、歌词关键词、节拍器、鼓点、旋律线、光脉冲、舞步、粒子和色彩段落。
- 穿搭/人物/好物：标准姿态、转盘旋转、正侧背视图、尺寸线、箭头、图纸背景、等宽数字、材质/轮廓/结构标签。
- 排版/图形：字体粗细、黑白反相、遮罩、递归矩形、同心圆、十字分割、运动模糊、单点彩色和负空间。

同样是空间门户：零食通向口感世界，护肤通向肌肤微观层，家电通向灰尘或空气路径，SaaS 通向任务数据空间。不能只把包装袋、瓶口、吸口、屏幕都写成“打开一个奇幻世界”。
文化艺术类的空间门户要来自真实空间或艺术载体：画框通向画中动作，展柜通向展品细节，窗框通向城市夜景，中庭通向尺度高潮，邀请函通向活动主题。活化必须尊重原作/原物可识别特征；若涉及真实馆藏、艺术家、活动年份、logo 或展览名称，必须来自用户材料或明确确认。

## AI 视频效果语法启发

常见效果族：

| 效果族 | 代表语法 | 深层语法 | 可迁移用途 |
|---|---|---|---|
| 镜头运动型 | Earth Zoom Out、Flying Cam Transition、Wild ride、3D Rotation | 镜头速度和尺度变化制造信息揭示 | 停滑、发布感、速度感、从局部到全局 |
| 入口穿越型 | Eyes In、Mouth In、Hole Transition、Display Transition、Cutout | 熟悉开口、屏幕或轮廓变成空间入口 | 感官入口、UI 入口、包装入口、反转 |
| 材质转化型 | Melt Transition、Water Bending、Air Bending、Smoke Transition、Freezing | 主体被翻译成另一种物质状态 | 肤感、味觉、净化、科技、质感升级 |
| 数据建模型型 | Point Cloud、Wireframe、Polygon、X-Ray、Lidar | 真实世界短暂变成可计算/可透视结构 | 科技解释、结构证明、智能识别、企业能力 |
| 物理规则型 | Levitation、Stop World、Frozen in Motion、Bullet Time | 重力、时间、惯性或空间方向被改写 | 强停滑、关键瞬间、防护、轻盈、控制 |
| 数量身份型 | Clones、Infinite Clones、Duplicate、Selfception | 同一主体复制、并列、递归或自我观看 | 多场景、多任务、多口味、多身份 |
| 场景世界型 | World Morphing、Multiverse、Wonderland、Street Colossus | 一个现实空间被另一个世界或尺度系统入侵 | 品牌世界观、前后状态、活动主题 |
| 社媒拼贴型 | Scrapbook Collage、Comic、Palette、Studio Slide | 平台原生、拼贴、滑动、版式或图形节奏组织画面 | 信息流、潮流感、系列展示 |

效果语法通常只承担一个节点职责：开场停滑、产品/主体登场、卖点证明、高光、反转/揭示或结尾回收。不要把某个 preset 当作完整视频。

## 方向发散矩阵

探索阶段只发散 `3` 个不同主机制候选。每个候选从下表选择一个主方向，并提出 `1-3` 个与它共享触发、运动路径、视觉语言或回收方式的辅助机制；不要把下表逐项遍历，也不要把同一机制换颜色或场景冒充不同候选。随后按用户匹配、核心证明、连续性和生成稳定性筛选，最终只保留 `1` 个主机制贯穿全视频，并按实际需要吸收 `1-3` 个不冲突的辅助机制。

| 起点 | 方向句式 |
|---|---|
| 从产品内部看 | 镜头从 X 内部向外看，外部世界因为 Y 动作发生异常，最后拉回 X 的真实结构 |
| 从结果倒推 | 开场先出现一个不合理结果，镜头沿痕迹倒推，发现是 X 的某个动作造成 |
| 从微小动作放大 | 一次 X 动作被放大成场景级事件，变化沿 A->B->C 扩散，最后收回产品 |
| 从真实物件贯穿 | 一个真实物件保持不变，穿过多个时代/场景/版本，让变化围绕它发生 |
| 从 UI 接管现实 | 熟悉 UI 的每次操作都会改变真实空间和人物行为 |
| 从材质隐喻 | X 的质地转成某种材料规则，材料沿使用路径改变场景或状态 |
| 从尺度错位 | 主体保持日常动作，但周围空间被放大/缩小成不合常理的尺度 |
| 从反向视角 | 被处理对象或旁观物拥有视角，观众先站在它那边，再被产品动作改写理解 |
| 从世界碰撞 | 两个状态在同一空间互相挤压，产品动作让其中一个吞并另一个 |
| 从声音触发 | 一个真实声音变成可见力量，推动物体、光线、场景或 UI 按节奏变化 |
| 从多参考混搭 | 两个风格源分别建立预期，随后在节拍、色彩或场景中碰撞，生成一个能同时看见二者来源的新结果 |
| 从数据标注 | 主体以标准姿态出现，线条和数字逐步测量它，旋转或拆解揭示隐藏侧面，最终形成完整说明图 |
| 从歌词变形 | 选一个关键词，把它的语义翻译成运动、构图、颜色和转场，让文字自己完成表演 |

候选筛选顺序固定为：先淘汰违背用户指令或事实边界的候选 -> 再淘汰无法证明核心或无法形成连续路径的候选 -> 在剩余项中选择生成最稳定且一秒能懂的主机制 -> 最后只吸收有明确局部职责且不改变主机制的辅助机制。

## 机制到分镜/PE 的转写

本文件只决定视觉机制如何进入画面，不定义最终 PE 固定格式；图片与视频 Prompt 统一服从 `references/asset-generation.md`。

```text
机制名
  -> 当前品类/场景语义
  -> 运动母版
  -> 触发动作
  -> 连续运动路径
  -> 场景反馈
  -> 证明/情绪结果
  -> 产品/品牌/主题回收
  -> 对应秒段
```

秒段里的视觉效果应写成清楚因果动作：主体或产品因某个触发动作改变一条现实规则；观众能看到变化从哪里开始、经过哪里、如何影响场景；变化证明或外化一个卖点、感受或情绪；镜头以具体机位和运动跟随变化，并在切出点回收到产品、品牌、人物状态或真实结果。

转写失败信号：

- 只写效果名，没有触发动作。
- 只写氛围和风格，没有连续运动路径。
- 用慢推、渐大、发光、旋转、悬浮或人物微动撑满长镜，却没有新的动作、观看关系和信息状态。
- 多个特写、人物反应或场景之间随机硬切，没有共同事件和承接锚点。
- 高光突然发生，前面没有蓄力/触发，后面没有反馈/结果停留。
- 结尾回到开场画面，但主体状态、关系和意义没有改变。
- 视觉效果不证明卖点、不外化感受，也不改变叙事理解。
- 同一句换成任何产品都成立，只是替换产品名。
- 效果结束后没有回到产品、品牌资产、人物状态、真实结果或 CTA。
