# UGC 与创作者表达：让一个具体的人把事情讲通

## 适用边界与读取

用于创作者口播、推荐、使用记录、测评、开箱、观点、探店、问答、访谈与创始人/员工表达。用户明确要 UGC 口播时，主体必须是对观众讲话的具体的人，不能改写成两个人演剧情或无口播的生活蒙太奇。

先读“第一阶段的 UGC 写法”，再查对应形式。以学会知识/操作为主的任务，无论是否出镜都用[知识讲解](explainer-video.md)；以正式企业事实为中心的片用[企业商务](business-video.md)。UGC 的创作者视角可以用于广告，不把真人、竖屏、第一人称或手持风格当作内容已成立。

真实用户内容、委托创作者广告、演员及生成角色的 UGC 风格演绎要区分。不能编造真实购买、长期使用、粉丝评论、专业身份或第三方证言。共同写作与制作规则见[入口职责表](../SKILL.md#入口与规则权威)。

## 先明确具体内容形式

UGC 不等于口播。真实用户内容、受委托的创作者广告与生成的 UGC 风格演绎要准确区分，不把演员或生成角色包装成真实购买者。下表决定写法，不新增主类型或工作流；用户明确要求 UGC 口播时采用对应口播形式，不自动改成生活记录。

| 本次形式 | 第一阶段实际写什么 | 怎样判断没有写偏 |
|---|---|---|
| 创作者口播/讲解 | 具体的人面对观众，说清自己为何关注当前问题、怎样观察或判断；全部口播与必要演示一起写 | 人物有自己的视角与用词，展示在需要支持判断时出现；不把品牌说明书换成第一人称配一组手部镜头 |
| 使用记录/开箱/生活片段 | 使用任务中的选择、发现、过程与反应；说话可以是当场短句或回看解说 | 主体在实际做事，叙述来自此时能知道的内容；不强塞连续对镜讲解 |
| 测评/比较 | 待判断的问题、条件、操作、结果及由此形成的取舍 | 不预先写好赞美再剪证明，不把产品介绍假称测评 |
| 评论回复/问答 | 有来源的问题与当前回应，按实际情况补解释或演示 | 回应同一个问题；无真实来源则明确是演绎，不编用户反馈 |
| 采访/访谈片段 | 按真实问题、完整回答和必要语境选内容；策划待拍访谈时写提问方向，不替真人预写证言 | 保留受访者的原意与说话对象，选段后仍能听懂指代、条件与理由；不把零散金句拼成新主张 |

品牌推广任务仍按[营销内容的共同要求](creative-core.md#第一阶段创作方案)写清推广对象和判断依据。真人画面、手持拍摄、口语词或一段人声只能是形式，不能单独证明 UGC 视角成立。

## 第一阶段的 UGC 写法

### 让完整口播持续得到新依据

用户只给产品与大致方向时，主动写完整口播与相关示范，按[共同展开规则](creative-core.md#用户说得少时主动展开内容)取材；不要只写“展示产品—说好用—微笑结尾”。口播应顺着一个人当前的观察继续讲：正在介绍什么、关注哪里、为什么、画面给了什么依据、自己如何选择或回应。不同内容用“先看这里”“这处区别是……”等自然关系承接，措辞按人物与语言调整，不强制句式。删去广告腔后要补回具体意思，不能删成几个空泛短句。

例如用户上传深卷发束图：能看见的黑色、卷曲纹理和顶部 loop 可以作为三个相关观察，先让观众认出整束，再近看 loop、顺同一束发丝看卷曲细节，回人脸表达基于这些外观的造型偏好。真人手持、局部插镜与人脸回应交替，人声完整跨镜连续；不能把同一束左右摇动十次当十条内容。只有已确认安装方式、材质或真实佩戴资料时，才加入对应过程和判断；不因黑色深卷外观推断真发、耐热、不打结、轻盈或长期亲测。用户提供逐字口播时保留原文，在相关画面与表演上丰富，不自行扩写台词。

动作服务说话：说结构时让关键部位可见，说区别时给对应对照，形成判断后给自然回应。不要在核心观察处突然换衣服、地点或无关生活 B-roll；不靠密集手势、跳切、字幕与音效制造口播信息量。

先想清这个人在做什么、为什么要拍或讲、观众为什么要看，再按选定形式写过程、对白、口播或回看解说。有讲解时按下表确定说话关系：朋友分享可以讲取舍，老师要解释到学生会做，顾问要回答当前疑问，不能都念同一份宣传稿。人物身份、经历与反馈须真实，虚构角色或示例要说清，不冒充亲测。

### 前 3 秒：从这个人眼前的事讲起

先选一个和目标观众有关、创作者此刻能指给人看的细节。让手里的动作、眼前的结果或一句有来由的判断先出现。观众看懂「这跟我有什么关系」以后，下一镜就沿着刚才那件事给出依据、条件或回应。第一句可以晚于第一个动作；用户要求口播时，创作者仍要亲自把话讲下去。

下面是待拍示例，具体结论随实拍结果确定：

| 形式与目标观众 | 前 3 秒看见什么、听见什么 | 下一镜怎样把话讲下去 |
|---|---|---|
| 通勤包分享，给常单手刷卡的人 | 创作者一手拎咖啡，一手从包侧袋抽出交通卡，卡贴上读卡器时响一声。开头可以没有台词。 | 她把镜头转向自己：“我挑通勤包，先看拿卡要不要把咖啡放下。”随后把卡放回原处，让观众看清袋口的位置。 |
| 工具测评，给在卧室录音的人 | 两段录音念同一个“早上好”，第一段能听见风扇。第二段播完，创作者的手停在播放键上，让观众先听差别。 | 镜头拉宽，露出桌上的风扇和麦克风。他交代：“风扇没关，麦克风也没挪。我只切了这个开关。”接着播放同一句的尾音，让观众听背景声和人声分别有什么变化。 |
| 创作者观点，给自己剪访谈的人 | 播一小段对话，受访者刚吸气，画面就切走。创作者按下暂停：“我想把这口气留回来。” | 时间线上，把刚才那个切点向前移，放回吸气和随后的回答，再播一次。创作者结合这句回答，讲清这次为什么值得保留停顿。 |

真实测评以同条件素材为依据，采访用受访者实际说过的话。手上只有产品资料时，可以把开头写成一次现场演示，把观察留给镜头；“我用了半年”“粉丝都在问”等经历需要有来源。自然陈述、动作声或一瞬安静都可以开场。

| 说话关系/观看任务 | 中段拿出什么 | 台词、反应与画面怎样接下去 |
|---|---|---|
| 种草分享：观众借一个人的观察判断是否适合自己 | 当前使用中的具体发现、取舍与反馈；先确定生活任务，再挑能说明判断的细节 | 用自己的取舍接具体细节，像回答“你为什么这样选”；不每句都向观众推荐。关键结构、操作或结果有对应可见依据，保留实际拿取、犹豫或调整的反应，不把所有话逐字图解；未亲测不编“用了三个月”等经历 |
| 测评比较：观众等一个有依据的结论 | 同条件操作与结果，说明比较标准和样本范围；怀疑应被实际检验 | 先给观众看到结果，再解释它是否改变原判断；可以有真实的迟疑和修正，不每看一项都喊惊喜。关键测试不靠快剪跳过；需要判断实际声音时降低配乐 |
| 知识讲解：观众想弄懂或学会一件事 | 解释原理时用具体对象建立关系，操作教学时演示关键步骤和核对依据；根据观众已有知识取舍 | 不把所有知识都写成纠错或“三个技巧”。例子必须帮助解释当前问题，复杂动作先提醒看哪里，再展示和解释；不能只报步骤名，也不一边换页一边塞三条新知识 |
| 人物观点/行业评论：观众想听这个人怎样判断 | 明确主张，用相关事实、观察或例子展开理由，再说明适用条件与取舍 | 后一句继续解释前一句；区分事实与个人判断。不强行加入商品推荐，也不把态度词当论据 |
| 问答/评论回复：观众带着明确疑问或反对意见来 | 直接处理对方的疑问、误解与条件，只补回答所需的依据 | 先给对方真正问的答案，再解释条件。例如问“必须买大号吗”，应回答多大物品、何种用法才需要；不能接成“今天介绍三大优势”。提问与回应保留同一语境；评论无来源时只作演绎提问 |
| 探店/现场体验：观众借现场判断值不值得去 | 实际任务与过程中的决定性细节，例如怎么选、实际遇到什么、结果怎样 | 语言跟随当场的选择与发现，询问、店员回答和试用后的反应彼此接续。背景声保留空间，决定性细节拍清；不把门头、装修、摆盘串成空泛夸赞，也不预先编好真实店员的回答 |
| 员工/顾问/工具讲解：观众需要内部取舍、服务判断或可操作流程 | 当前角色能知道的细节、依据与演示；复杂任务拆到观众真正卡住的一步 | 按角色讲能知道的原因、取舍和下一步。顾问先接住当前顾虑，员工解释实际决定，工具讲解跟随屏幕状态；不用同一套“家人们”或官方宣言。提到的操作、依据或结果用对应画面支撑，不伪造资历 |

开头建立的问题、观点或观察，中间就围绕它继续。整段保持同一个人的说话立场，用解释、操作、条件或回应接着讲，不突然改成品牌宣言、卖点清单或几条独立标题。营销口播可用答疑、教学、测评、幽默或生活片段展开；让观众理解这个人为什么这样推荐或判断，不能只因出现商品和购买引导就认定完成。普通分享不必变授课，专业解释不硬加夸张语气。推荐可依据当场展示，不必都写成使用后见证；未提供真实经历时，不编先前购买、长期使用、朋友追问或用户评论。按交互合同展示内容和完整口播，不再列一套“洞察、钩子”等标签。

**分享先确定值得讲的产品内容，再写这个人怎样讲。** 营销口播从本次商品与受众的关系里选一件想说清的事：为什么关注它、具体怎么用、哪处值得选或不适合谁；按已选形式展开，不要求逐项回答。推荐与分享要让人听出这个人为何在意、怎样取舍或想提醒别人什么，让产品事实解释他的判断；只讲按钮在哪、东西怎样放，即使正确也可能仍是功能讲解。教程和明确的工具教学保留讲解职责，不强加个人感受。当前反应可以保留，但“好吃、再来点、样子怪”等反应不能替代本次产品介绍。普通日常动作放在任何商品旁边都成立时，先换取材，不能靠语气随意来冒充真实分享。非营销知识与人物观点仍按各自任务写，不硬塞产品。

把选定内容连着说清，再改成当前人物会用的词和句子。不先写一段无关闲聊等最后报商品，也不先排成“困扰自白、功能解释、态度总结”再加口语词。自然分享可以直接讲产品、解释理由和给建议，不必为了躲开广告感而删掉有用信息。先明确此刻有什么具体内容值得讲给这个观众：眼前用法、值得解释的细节、真实选购问题或已有体验均可；没有真实经历时，可基于已知产品事实写当下观察、选择理由或偏好，再用展示支持，不自动退成只讲操作，也不补购买史。概念演绎可以设定与场景一致的当下需求和取舍，不能伪装成真实买家经历或效果见证。人物可以直接指给人看、解释为什么这样用、补一个影响选择的条件。具体的选品标准和结尾取舍，只要与当前生活条件、商品特点和演示相连，就保留；不把有用的个人理由误删成“广告腔”。不要每条都先宣布原则、夸大苦恼，再给一句空泛态度；也不把一个有效开场扩成所有产品的固定句式。营销口播先连写一段这个人确实想告诉观众的话：谈的是哪件产品或服务、哪个细节值得讲、这对当前用法或选择有什么意义；顺序随表达变化，不填三句模板。让后一句接上这个观众此时还想知道的内容，产品信息通过解释自然增加，不是一句功能后接一句泛泛夸奖。讲结构时接具体用处，讲好用时给眼前依据，讲推荐时让观众知道适合什么需求；只报“我放哪、我拿哪”是操作播报，不是完整推荐。人物已知偏好和眼前依据可以使用，身份、经验与反馈仍须遵守来源边界。

按说话过程中实际知道的内容往下讲：本来就知道的可以直接说，正在展示的让观众看清，新的反应须由刚才真正发生的事引出。不要求惊讶、反转或列齐优缺点，也不为一句俏皮回应临时造一个巧合。拍摄可以事先策划，口播仍要符合这个人当下会注意、会判断、会回应的事，不装作所有结论都临场发现。

自然度看说话时是否成立，不看句子是否工整。具体的人应有一个可理解的关注点或判断，后一句接着说明，而不是把“特点一、特点二、建议购买”换成三句短口语。日常说法可以包含正常因果、转折与完整名称；不故意省词，不靠“家人们、真的、绝了”、结巴或反复惊讶制造真人感。起草时先按正常词序把意思说够，再删赘词；连着读像几条广告标题时，改回解释或回应，不只加连接词。可以省略已知对象、顺口插一句当前细节、停下来做事后再接着说；意思跟得上即可，不把它们全部润成对称短句或总结句。语气与重点可以在说到具体内容时自然变化，不让每句都像重点、每处都要停一下展示。保留有作用的普通反应与呼吸，不故意结巴，也不为每个词安排手势。若一句像作者替人物总结意义，先改回他眼下想说的具体意思；讲完这件事就可以结束。

商品名、品类、功能和购买提醒按需要直接说。陌生观众首次听到核心判断时，应能从当前话语与画面知道在说什么产品；不能把只出现在方案标题里的商品身份当成片内已交代。包装与画面可补品牌/型号，但连续营销口播默认在一句自然的话里交代产品或品类，不整段只剩“这边、那个、主仓”等零散指代；不要求每句报全名，也不为口头报品牌破坏整句。名称随当前介绍自然进入，不固定先报全称再列功能；复杂型号可由片内清楚可读的产品信息承担，人声保留准确的品牌或品类称呼和有用解释，不能两边都省掉。补充画面在需要时展示依据，声音可跨镜持续，也可给操作和反应留空。回到人脸时接上同一意思，不重新开场。配乐让位于人声、现场判断与真实反应，不每句加提示音。A-roll、B-roll、切点和屏幕状态由分镜细化，不安排无关动作凑镜头。

上述原生表达与声音配合可查 [TikTok Creative Codes](https://ads.tiktok.com/business/en/creative-codes)；[fal-ai-community 的 UGC 写法](https://github.com/fal-ai-community/skills/blob/main/skills/ugc/SKILL.md)可参考说话背景、产品呈现与具体依据怎样接续，不照搬固定段数；[Pika 的品类表达](https://github.com/Pika-Labs/Pika-Plugins/blob/main/skills/ugc-ads/SKILL.md)可参考按品类改变展示与声音重点，不把固定节拍、情绪或台词套路扩成通用要求。教学取舍可查 [Georgia Tech 的教程脚本指南](https://libguides.library.gatech.edu/videotutorialguidelines/writing)。采用受众已有知识、友好语言和声画配合的做法，不移植其英语语速数值，也不把所有 UGC 写成课堂。

采访选段可参考 [Documentary Junior Editor](https://github.com/SB-Jeff/documentary-junior-editor/blob/main/SKILL.md)对原话与连读逻辑的区分：逐字真实仍可能因剪接而失去语境。使用真实素材时保留原意、指代和必要前提，不借重新排序制造原话没有的因果；没有采访素材则写待拍问题或明确演绎，不能声称已有受访者回答。只取这些编辑方法，不引入其多代理流水线。

## 类型谱系

下表细分口播与互动讲解的用途；使用记录、开箱等非对镜形式沿用前面的形式选择，不强制变成口播。先判断用户要的是哪一种“人对人表达关系”，再选择脚本策略、证明动作和画面比例；不要把所有需求都写成同一套带货话术。

| 类型 | 典型场景 | 核心任务 | 常见误区 |
|---|---|---|---|
| 带货口播型 | 带货讲解、真人测评讲解、达人推荐、开箱种草 | 把卖点变成可见证明和自然购买理由 | 只喊卖点、虚构亲测、过度叫卖 |
| 知识引流型 | 知识付费引流、课程预告、经验分享、方法论拆解 | 先交付一个可用认知，再自然引出方法/课程 | 一上来卖课、空泛成功学 |
| 人设 IP 型 | 个人 IP 日常输出、行业观点、粉丝互动、创作者系列 | 强化稳定人设、观点口味和系列识别 | 每条都换人设、只讲鸡汤不兑现观点 |
| 场景采访型 | 探店口播、街头采访、门店体验、真实场景观察 | 用现场细节和人物互动建立真实感 | 编造店铺事实、只拍环境不讲体验 |
| 问答互动型 | 评论区答疑、粉丝问答、直播预告、反对意见回应 | 把用户问题转成内容入口和转化理由 | 自问自答太假、问题和产品无关 |
| 创始人/员工型 | 创始人解释产品、员工视角、幕后开发、品牌小故事 | 用内部视角建立动机、专业度和可信边界 | 讲成企业宣传片、口吻太官方 |
| 服务顾问型 | 本地服务、咨询、医美/教育/装修/企业服务线索获取 | 降低决策焦虑，解释流程、风险和适合人群 | 承诺结果、制造恐慌、隐藏限制 |
| App/SaaS 演示型 | App、工具、AI 产品、B2B 软件、效率工作流 | 让屏幕动作证明“它真的能做什么” | 口播列功能，屏幕只当背景 |

上表是 UGC 内的表达用途，不是入口主类型的第二套路由。以理解或会做为主的课程/方法讲解读知识文件；以创作者推荐、选课判断或营销表达为主时，才在这里借知识引流写法。“创始人卖产品”可借内部视角，“探店团购”可借场景采访；仍按本次主要任务组织内容。组合时只迁移相关方法，不把多个开场、多个 CTA 和多个证明链硬塞进一条短片。

## 口播画面组织

对镜口播保持稳定人物身份，姿态、反应、必要手势和短语边界切点随实际表达变化，不把这些表面形式当作自然感的保证。人物动作来自当前态度、判断与任务，不为每个词安排手势，也不要求使用记录中的人持续看镜头。

B-roll、屏幕录制、手部特写、产品细节、门店环境和生活方式镜头用于证明、解释、情绪、幽默或节奏呼吸，不按口播名词逐个配图。人物声音可以在 B-roll 上继续；下一句声音可以先进入，再切回人脸或产品。口播分镜要标清哪些段落是 A-roll，哪些段落由 B-roll 覆盖，以及覆盖画面证明了什么。

开头先让观众认出当前问题、判断或情境，而不是只听招呼和预告。可用人物直接说出具体问题、手部操作、例句、屏幕结果或现场发现；选择能帮助理解的方式，不为首秒有动作而硬加表情、道具或跳切。证据在需要支持判断时进入，不能只为凑开头而一闪而过。

开头与后续的具体时间、切点按[分镜合同](storyboard-contract.md#时长与节奏的唯一规则)，有效变化的密度和舒缓、一镜到底的启用条件按[视听工艺](audiovisual-craft.md#默认变化与叙事密度)，本文件不另设逐秒动作配额。

### 检索和素材怎样用于口播

主动找参考沿用共同研究规则；UGC 额外看同类内容怎样把当场观察、原有经验与判断分开，如何让操作、现场细节和问答支撑说法，不能只收集“爆款开头”。参考中的评论、身份、体验、价格或反馈不迁移成本片事实。真实采访保留原意，不为了连贯重写结论；策划问答可以明确作为讲解形式，但不伪装成已有热评。

没有真实体验材料时采用当场演示、流程解释或明确概念表达，不补“用了三个月”之类的背书。复杂服务和 B2B 口播仍可直接从具体问题、关键判断或现场动作进入；复杂不等于先长篇介绍公司，也不靠加快语速省去适用条件。

## 说话依据与可信边界

本节只在来源或判断站不住时查，不是口播结构。核对当前说话人凭什么知道、观察来自哪里、画面或资料能支持到哪一步；需要哪些条件才能成立，就交代哪些条件。不要把身份、观众顾虑、论据、边界和行动引导全部念成一份自证材料。

具体细节比空泛赞美更能支撑分享，但不要求先造一句同时包含结论与依据的“核心句”。可以先给观众看、边做边说或从一个明确看法往下解释；只要整段的对象、意思与依据可跟随即可。“好用”“喜欢”可以是正常反应，单靠它们则不够；后面需要当前具体内容，而不是再换一组形容词。

真实购买、使用时长、用户评论、店员回答、资历和比较结果不得编造。没有真实经历时可以介绍已知信息、做当场演示或明确的演绎，不冒充真实买家见证。演示指物要让镜头看见，不能让不在现场的观众执行此刻不可能做的触摸、闻味等动作；人的主观反应也不能当作可量化功效证据。

## 黄金证明动作

演示、测评与种草优先安排能看见依据的关键动作，不能把所有证据都留到结尾。知识、观点和问答则给有效论据、示例或解释，不强求表演动作。下表提供不同证明载体。

| 类型 | 黄金动作 | 画面配合 | 失败信号 |
|---|---|---|---|
| 带货种草 | 开箱、拉扯、上脸、倒入、喷一下、咬开、穿上走两步 | 手部近景 + 人物一句判断 + 结果停留 | 全程人脸念卖点，产品只在尾帧出现 |
| 测评体验 | 在明确条件下检验当前问题，结果可以支持、限定或改变原判断；有可比对象时同条件对照 | 保留关键过程与可判断结果，不预设旧方法必须失败 | 换条件比较、跳过决定性步骤，或演出未经依据的优劣 |
| 知识引流 | 写下一个判断公式、圈出一个错误、演示第一步 | 白板/屏幕/纸张/图形卡跟口播同步 | 只讲道理，没有可带走的方法 |
| 服务顾问 | 展示流程节点、材料清单、预约前自检 | 图形步骤少而清楚，口播讲边界 | 制造焦虑但不给判断标准 |
| SaaS/App | 输入 -> 点击 -> 结果面板落下 | 屏幕动作是主证据，人声解释为什么重要 | 口播讲功能，屏幕模糊或假 UI |
| 探店/本地生活 | 进门、点单、体验、结账/离店一句判断 | 门头/环境/细节/反应形成动线 | 只拍装修和氛围，不给真实体验 |
| 创始人/员工 | 拿出一个设计取舍、用户反馈或后台流程 | 幕后细节和一句坦诚解释 | 讲愿景太多，缺具体选择 |

关键动作后给观众看清需要判断的结果；人物确实会有反应时再保留。结果可以是颜色、形态、完成状态或实际使用关系，不必每次补一句评价、一个笑脸、提示音或花字。已看清结果就继续，不为证明“真人感”安排赞叹。

## 口播与画面分工

口播与画面怎样配合，按[整段文案的用途](creative-core.md#连写文案及声音职责)判断：教学指令、关键核对可以与动作同步；解释可以补原因和条件；对白可以回应眼前发生的事。两者只在重复夸奖或没有增加理解、关系、感受时才删减，不机械禁止说出正在做的动作，也不让 B-roll 只按名词配图。

分工规则：

- 人声按当前意思承担观察、解释、评价或回应，不必每句都说明购买理由。
- 补充画面让相关材质、动作、状态、屏幕或空间可见，也可承接感受与幽默，不逐词给口播配证据。
- 花字说“记住”：只提炼关键词、反问、状态锁定、步骤名或 CTA，不逐字铺满。
- 拟音说“发生了”：开盖、点击、拉链、喷雾、咬下、归位、消息提示等和动作绑定。

UGC 可以用图形或超现实表达辅助理解，但须保持说话关系，让观众分清解释、感受与实际效果；不设效果数量配额，也不用幻想替代操作或实测。是否采用取决于当前内容，不因有口播就默认加一处奇观。

口播的吸引力可以来自“这个人怎样形成判断”，不必另演一段剧情。让观察、疑问、依据与取舍有实际联系：一个细节使他注意，演示或解释使判断更具体，必要时承认原先想法不适用；这些是可组合的关系，不固定成先质疑后夸赞的模板。下一句接观众此刻仍需要知道的内容，而不是换一个卖点重新起头。没有真实经历时，依据来自已知事实、当下可见信息或明确演绎，不补购买史和效果见证。

人物正在说出关键判断或改变看法时，可保留脸、眼神与自然停顿；操作和屏幕需要看清时再把注意交给相应画面。B-roll 回来以后继续同一意思，不重新报题；不为保持动态而让人物反复举放产品、换手或每句指屏。手持、跳切和贴纸只是选法，可信感来自内容与人的反应相符，而非人为制造犹豫或惊讶。

## 类型策略库

不同 UGC 类型按实际观看任务组织，不先写通用口播模板再替换品类词。先选主类型，只查当前内容缺口对应的策略，不固定主辅策略数量；已有完整表达时不再另选。批量视频按人群、情境、依据或视角形成有意义的差异，不只轮换策略名。

### 带货口播型

带货的核心不是“喊购买”，而是让观众相信这个产品解决了一个具体购买理由。

可选策略：

- 痛点解决：先给一个具体麻烦，再用产品动作证明它少了哪一步。
- 开箱第一印象：从包装、材质、手感、尺寸、上身或上桌状态进入，适合新品和低决策成本商品。
- 结果前置：先展示成品、效果状态或使用后场景，再解释关键卖点；必须避免夸大功效。
- 对比替换：旧方法/旧产品的问题 -> 新产品动作 -> 差异特写；适合家居、3C、日用和工具。
- 细节控种草：围绕一个小细节展开，例如拉链、杯口、按键、面料、气味、声音；适合小红书和高质感商品。
- 反对意见回应：先承认贵、不确定、怕踩雷、不知道怎么选，再用事实和边界回答。
- 组合场景：展示 2-3 个使用场景，强调“为什么留在生活里”，不把卖点列成说明书。

带货 CTA 按本次投放目的、用户原文与已兑现的理由选择；可以直接购买，也可轻邀请，不默认降为收藏或强行另加行动。具体选择见“平台、场景和人物”。

### 知识引流型

知识引流先给观众一个小收益，再引出课程、服务、资料或后续内容。

可选策略：

- 误区纠正：指出一个常见错误，给判断标准，再自然引出系统方法。
- 三点清单：3 个避坑、3 个判断、3 个动作；每点都要有画面锚点或手势/白板/屏幕支持。
- 案例拆解：用一个匿名或用户提供的案例讲清原因、方法和下一步，不能编造案例。
- 步骤示范：直接演示第一步怎么做，让课程/资料成为继续深入的承接。
- 观点反差：提出反常识判断，再用逻辑拆开；适合行业观点和专业 IP。
- 价值先行：给一个模板、公式、检查表或判断问题，CTA 指向领取/预约/继续看；只有用户明确提供免费权益时，才写“免费领取”或类似承诺。
- 课程预告：先讲本节能解决什么，不夸大学完结果；强调适合人群和不适合人群。

知识引流的 CTA 要像学习路径：收藏、评论关键词、领取资料、看下一条、预约诊断。不要一开头硬卖课。

### 人设 IP 型

人设 IP 的核心是稳定识别和观点兑现，不是每条都重新包装一个广告。

可选策略：

- 固定栏目：固定一句开场或固定问题形式，变量是本期主题；适合系列。
- 行业判断：用专业经验给一个清晰立场，后面必须给判断依据。
- 日常切片：从工作、生活、门店、会议、通勤中的真实瞬间引出观点。
- 粉丝互动：回应评论、私信、常见问题；问题可以概括，但不能伪造具体截图。
- 反面清单：什么不要做、什么不适合、什么会踩坑；适合建立可信边界。
- 幕后复盘：讲一次选择、失败、改版、选品或服务经验，增强人格真实感。
- 价值观表达：适合品牌主理人和专家 IP，但必须落到具体事件或判断，不写空泛态度。

人设 IP 的每条不一定都要出现产品；如果出现产品，也要服从本期观点，不要突然变成带货广告。

### 场景采访型

场景采访用现场感和互动建立可信度，重点是“人在真实空间里发现了什么”。

可选策略：

- 探店动线：门头/入口 -> 核心体验 -> 细节 -> 适合人群/注意事项。
- 街头快问快答：一个问题问 2-3 人或一个人连续追问；适合活动、趋势和本地生活。
- 店员/顾问一句话：让现场工作人员解释一个关键信息；必须避免编造身份和优惠。
- 体验前后：进店前期待 -> 体验中动作 -> 体验后一句判断；适合餐饮、娱乐、服务。
- 现场问题解决：在真实场景遇到一个困扰，当场用产品/服务/路线解决。
- 路人反应/同伴视角：用反应增强真实感，但不能伪造用户评价。
- 横版合集：多个门店/多个点位/多个采访对象组合时可用 `16:9`，但每段仍要有具体信息。

场景采访必须写清事实来源：营业时间、价格、优惠、地址、排队情况、体验结果都需要用户提供或确认。

### 问答互动型

问答互动适合承接评论、售前疑虑、直播预告和高频问题，重点是“先听见用户，再回答一个点”。

可选策略：

- 单问单答：只回答一个问题，短视频最稳。
- 连环追问：同一问题拆成 2-3 个追问，适合复杂服务和课程。
- 反对意见回应：贵不贵、适不适合、有没有必要、和竞品差在哪。
- 直播预告：用一个高频问题引出直播会讲的重点，而不是只报时间。
- 评论续集：上一条评论引发下一条内容，适合系列互动。
- 二选一判断：A 和 B 怎么选，给适用条件，降低决策成本。
- 错误提问纠正：先改写用户问题，让观众理解真正该问什么。

问答型不能假装有真实评论来源。没有评论素材时，用“很多人会问/常见问题是”这种概括方式。

### 创始人/员工型

创始人/员工型靠内部视角建立可信度，适合解释产品动机、设计取舍和服务承诺。

可选策略：

- 为什么做：从一个真实动机或行业问题进入，讲清产品存在理由。
- 设计取舍：解释为什么保留/砍掉某个功能、材质、流程或服务方式。
- 幕后一天：用工作现场切片串起产品或服务能力。
- 失败复盘：讲一次踩坑、改版或用户反馈后怎么调整；适合建立信任。
- 员工视角：客服、设计、研发、门店人员讲一个常见细节。
- 透明报价/流程：解释费用、周期、交付、售后或适合边界；适合服务类。
- 给新用户的一句话：低压邀请，不把自己包装成权威广告主。

创始人/员工型可以更坦诚，但不能变成企业宣传片。少讲愿景，多讲具体选择和证据。

### 服务顾问型

服务顾问型的任务是降低焦虑和帮助判断，不是制造恐惧或承诺结果。

可选策略：

- 适合/不适合：先划边界，反而更可信。
- 流程透明：第一步做什么、需要准备什么、多久反馈、哪里容易误解。
- 避坑提醒：告诉用户下单/咨询前要看什么，适合教育、装修、医美、本地服务。
- 案例抽象：用“某类情况”讲方法，不编造客户故事和结果。
- 费用解释：解释费用组成或影响因素，不虚构价格。
- 风险说明：主动讲限制、注意事项和需要确认的信息。
- 预约前准备：列 2-3 个准备材料或自检问题，让 CTA 更自然。

敏感行业必须克制：不做治疗、收益、升学、变美、变富等保证，不用恐吓式话术。

### App/SaaS 演示型

App/SaaS 的功能演示与操作主张需要对应屏幕证据；按本次主张看清必要的输入、处理和输出，不为每项介绍重演全流程。创始人观点、选型判断或业务解释可用相关事实、资料与例子支撑，不因主题是软件就强制改成录屏教程。

可选策略：

- 工作流前后：旧流程需要几步 -> 现在怎么做 -> 输出结果是什么。
- 屏幕结果前置：先给生成结果/看板/完成状态，再倒回展示关键一步。
- 一分钟任务：设定一个小任务，看工具如何完成；避免讲成全功能介绍。
- 角色场景：创作者、销售、运营、学生、开发者各自的一条工作流。
- 对比替换：替代 Excel、手工整理、多工具切换、重复沟通等旧方法。
- 功能拆一招：需要聚焦时围绕一个具体用法展开，不把产品官网搬进口播；用户明确要求多个功能时按主次覆盖，不用此方法删锁定项。
- 创始人/用户教育混合：复杂 B2B 可以先讲为什么需要，再用屏幕证明。

屏幕里如果没有真实 UI 素材，只能写抽象界面或概念演示；不要生成假数据、假客户、假后台指标或无法证实的数字。

## 目标分层策略

以下目标分层用于营销口播，不把普通分享、人物观点与纯答疑重新定为带货任务。先沿用已有观看任务；确为营销且目标未明确时，才从本次指令里的行动词推断，在方案中自然说明采用的目标假设，不要求出现固定话术“按默认推断”。

| 视频目标 | 适用意图 | 节奏重点 | 证明重点 | CTA |
|---|---|---|---|---|
| 种草 | 让观众产生兴趣、收藏、愿意继续了解 | 生活化开场，细节和体感多一点，少压迫 | 场景、材质、使用瞬间、审美理由 | 收藏、看看链接、适合的人了解 |
| 转化 | 让观众下单、领券、试用或点击 | 前 3秒说清问题和利益，中段快速证明，结尾行动清楚 | 产品动作、价格/权益、适合人群、反对意见 | 去链接、领券、立即试用、直播间下单 |
| 获客 | 让观众咨询、预约、留资 | 先降低焦虑，再解释流程和适合边界 | 服务流程、准备材料、案例类型、顾问判断 | 私信/预约/填写表单/先做评估 |
| 涨粉 | 建立账号关注理由 | 观点更鲜明，结尾留系列感 | 专业判断、稳定栏目、下期承诺 | 关注、评论问题、看下一条 |
| 直播预约 | 把兴趣转移到直播间 | 抛出一个直播会解决的问题，不在短片里讲完 | 高频问题、福利或演示预告、时间信息 | 预约直播、直播间见 |
| 私域导流 | 引导加群、领资料、进私域 | 先给明确价值，再给领取理由 | 模板、清单、资料截图、适用人群 | 评论关键词、私信、领取资料 |
| 品牌信任 | 让观众相信人、团队或品牌 | 讲清动机、取舍和边界，按理解与回应安排速度 | 幕后、流程、真实材料、专业判断 | 了解品牌、看主页、预约沟通 |
| 复购 | 面向老客、粉丝、已购买人群 | 不重复基础介绍，直接讲新场景、新用法或提醒 | 使用技巧、补充搭配、维护、周期提醒 | 复购、补货、收藏用法、加入会员 |

默认推断规则：

- 已明确推广对象、只说“做口播/种草/小红书感觉”且无其他目标时，可按种草或品牌信任拟定；只有口播形式或平台名、不含营销任务时，不据此添加产品推荐与 CTA。
- 用户说“带货/卖货/信息流/投放/转化”：默认转化。
- 用户说“获客/线索/咨询/预约/到店”：默认获客。
- 用户说“涨粉/IP/日常输出/栏目”：默认涨粉或品牌信任。
- 用户说“直播/开播/预热”：默认直播预约。
- 用户说“私域/社群/领资料/加微信”：默认私域导流。
- 用户说“老客/复购/会员/回购提醒”：默认复购。

目标冲突时只保留一个主目标，一个副目标。例如“种草 + 转化”可以先种草、结尾轻转化；不要同时要求强购买、强关注、强私域和强直播预约。

## 主体登场策略

UGC 的第一主体通常是“可信的人”或“真实动作”，不是品牌世界。开场要让观众相信这个人为什么现在要说这件事。

| 场景 | 开场主体 | 产品/方法进入 | 避免 |
|---|---|---|---|
| 带货讲解 | 人脸、手部动作、痛点物件或结果状态 | 证明开始处进入，包装清楚 | 先铺品牌空镜、过度摆拍 |
| 测评/开箱 | 第一印象、拆封动作、结果前置 | 开箱或结论后快速出现 | 编造亲测和夸张反应 |
| 知识引流 | 问题、误区、判断标准 | 方法或课程作为解决方案后进入 | 一上来硬卖课 |
| 探店/街采 | 门店/街头互动、人物问题 | 场景体验自然带出 | 编造店铺事实和优惠 |
| IP 观点 | 人设判断、专业场景、真实语气 | 不一定有产品，重点是观点兑现 | 套广告腔和空泛鸡汤 |

UGC 可以直接、轻微粗糙、像临场记录，但不能乱。真实感来自场景理由、动作证据、语气停顿和细节，而不是低质画面、夸张表情或口头禅堆叠。

## UGC 创意设计器

UGC 的创意不是大片化，而是让“真人为什么此刻说、观众得到什么、画面怎样帮助表达”成立。设计之间有主次且不争抢内容，不按主辅数量凑策略；需要观众相信的主张有依据，创意不能替代事实。

口播也可以加入玩法和创意，但玩法必须像创作者自然想出来的表达方式，而不是把产品广告大片硬套到人脸口播上。口播玩法的核心是“这个人用一个动作、道具、屏幕、测试、评论、场景或小规则把话说清楚”。先判断说话关系，再决定玩法强度；不是所有口播都默认生硬种草，也不是所有创意都要变成夸张特效。

口播同样可以有世界规则，但它必须服务“说话关系”。达人、数字人、创始人或顾问不是在旁边念广告，而是在使用一个可理解的小规则讲清楚观点：桌面变成微缩沙盘、乐高小人完成任务、屏幕 UI 接管现实、数字人承认自己是 AI 分身、同机位前后对照证明结果、购物袋匹配剪辑完成换装。规则越强，越要让人物用自然口播承接它，例如“我用这个小模型给你拆一下”“先看这个前后对照”“我直接试给你看”“这个分身现在替我上班”。

常见自然说话关系：

| 说话关系 | 适合 | 口播语气 | 玩法承接 |
|---|---|---|---|
| 朋友提醒 | 种草、避坑、生活方式、本地生活 | 轻松、具体、有边界 | 手绘圈注、对比小卡、生活 B-roll、反应花字 |
| 现场实验 | 测评、工具、食品、家居、App | 直接试给你看，少铺垫 | 小测试、计时器、挑战条、前后对照、失败回弹 |
| 观察判断 | IP、知识、专业建议、选品 | 先给判断，再给理由 | 观点卡、证据卡、分屏比较、关键词锁定 |
| 反对意见回应 | 高客单、B2B、服务、功效存疑 | 先承认顾虑，再解释边界 | 评论卡、疑虑卡、旧新争夺、流程透明图 |
| 设计拆解 | 产品结构、AI 工具、课程、3C | 解释“为什么这样设计” | 爆炸图、结构标签、屏幕手势联动、放大镜裁切 |
| 创始人/员工 | 幕后、品牌信任、服务说明 | 坦诚、克制、讲取舍 | 幕后 B-roll、流程线、材料卡、版本对比 |
| 顾问判断 | 教育、医美、装修、咨询、本地服务 | 先帮用户判断适不适合 | 适合/不适合卡、步骤条、风险提示、准备清单 |
| 旁观吐槽 | 年轻化、轻娱乐、低风险消费 | 反差、吐槽、包袱，但不造假 | B-roll 包袱、拟声花字、荒谬小道具、反向揭示 |

### 口播核心玩法

口播围绕“观众为什么信”的依据展开；动作、操作、案例、论据或现场观察均可。下表列可选载体，不要求每条先设计一个表演动作：

| 黄金动作 | 适合品类/目标 | 证明什么 |
|---|---|---|
| 空管/用旧/快用完 | 美妆、个护、日用品、咖啡等复购品 | 有真实使用记录时谈频率、取舍或复购理由；空容器本身不证明长期使用或喜爱度 |
| 开箱拿近镜头 | 服饰、礼盒、3C、家居、食品 | 第一印象、质感、包装和期待感 |
| 上脸/上唇/上脚/上身 | 美妆、鞋服、配饰 | 效果不是口头承诺，而是看得见 |
| 拉扯/按压/开合/喷洒 | 面料、家清、个护、工具、小家电 | 功能反馈、弹性、清洁力、便携或操作感 |
| 屏幕结果落定 | App、SaaS、AI 工具、课程资料 | 工具真的完成一个任务 |
| 价格递进板 | 直播引流、促销、货架带货 | 原价、直降、券后或行动理由层层清楚 |
| 场景痛点反应 | 防晒、运动饮料、祛痘、家居、服务 | 需求不是编的，是当下场景自然发生 |
| 试吃/饮用/闻香反应 | 食品、咖啡、香氛、饮料 | 感官体验和人物真实反馈 |
| 评论/问题卡入场 | 问答、售前疑虑、知识引流 | 先听见用户，再回答一个点 |

开场按当前说话关系给出问题、判断、结果或动作，再及时给相关解释与依据；秒段按分镜合同，不固定三个逐秒槽位。

口播台词要围绕黄金动作写，不围绕卖点表读稿。比如先展示上唇效果，再说显色和质地；先拉扯面料，再说高弹轻薄；先出现评论疑问，再解释适合边界；先给屏幕完成状态，再倒回关键操作。画面已经证明的内容不要重复念，台词负责补原因、边界、适合人群和行动。

价格、优惠、库存、宝妈圈口碑、销量、空管经历、亲测时长、专业身份和用户反馈须有相应来源；明确虚构的角色背景不能冒充真实资历、长期使用、热评或用户证言。没有材料时，可以写成“假设型演示/概念口播”，不能伪装真实背书。

| 设计 | 适合 | 执行 |
|---|---|---|
| 动作开场 | 产品、教程、探店、工具 | 第一秒直接做一个手部、屏幕或现场动作，口播随后解释这个动作为什么重要 |
| 评论变脚本 | 问答、直播、售前、IP 互动 | 把一个常见问题作为开头；没有真实评论时写“常见问题”，不要伪造评论截图 |
| 小测试/挑战 | 测评、家居、工具、食品饮品 | 设置一个能当场完成的小任务，展示执行过程、结果和边界 |
| 同机位前后 | 清洁、收纳、效率、服务流程 | 保持光线、角度和主体一致，让旧状态和新状态清楚对比，不夸大变化 |
| 屏幕手势联动 | App、SaaS、AI 工具、课程工具 | 人物一句话提出任务，手势或点击接入屏幕流程，屏幕完成输入、生成、筛选或导出，人物回镜解释价值 |
| 图形状态层 | 口播、问答、榜单、测评、知识、服务顾问 | 用问题卡、观点卡、步骤条、进度条、对比板、数据卡、图标状态点承接口播结构；卡片的出现、替换、打勾、归位或锁定必须对应一句信息变化 |
| 展示揭秘 | 教程、剪辑/设计/AI 工具、创作者方法、案例复盘 | 前 1-3 秒先展示最终效果、前后对比或最强结果，再切回时间线、图层、素材清单或关键操作；揭秘只讲核心机制，最后回到结果验证 |
| B-roll 包袱 | 观点、知识、带货、榜单 | 人脸给判断，B-roll 给反差、证据或幽默点，声音不断线 |
| 道具隐喻 | 知识、服务、复杂产品 | 用一个简单物件解释抽象流程，结尾必须回到真实页面、产品、服务节点或行动 |
| 现场阻碍解决 | 探店、本地服务、家居、流程服务 | 现场遇到一个具体麻烦，当场用产品、服务、路线或方法解决 |
| 系列固定识别 | IP、栏目、批量内容、直播预热 | 固定开场动作、构图、道具或问题格式，本期变量提供新信息 |
| 反广告开场 | 高警惕受众、高客单、B2B、敏感品类 | 先承认限制、不适合人群或常见顾虑，再给证据和适用边界 |
| 现实界面化 | App、SaaS、工具、效率、知识解释 | 把按钮、下拉框、进度条、任务卡或播放器样式轻量叠进真实画面，由手势或口播短句触发状态变化 |
| 小道具控制 | 生活方式、穿搭、探店、好物、教育 | 用剪刀、便签、遥控器、卡片、杯子、包装撕口等真实道具触发转场或观点变化，结尾回到真实产品/方法 |
| 拼贴讲解 | 知识、课程、城市、品牌故事、年轻化种草 | 用照片、票据、纸片、产品图、手写字和箭头组成可移动讲解层，像创作者临场整理思路 |
| 风格化小世界讲解 | 产品结构、工具流程、食品饮品、生活方式、品牌故事、复杂卖点 | 主播旁边或 B-roll 中出现乐高积木、黏土定格、像素游戏、纸模、玩具沙盘或漫画分格小世界；小世界里的拼装、闯关、修复、归位、奖励必须对应一句口播信息或一个真实卖点，最后切回主播手里的真实产品/屏幕/场景 |
| 文字参与场景 | 标题感口播、栏目、品牌/IP 识别 | 关键词不是字幕，而是贴在桌面、墙面、屏幕、包装旁或人物身后，跟随手势、视线或证据落位 |
| 结果倒推 | 测评、清洁、效率、食品、课程 | 先给结果或完成状态，口播说“倒回看关键一步”，再用 B-roll 或屏幕流程解释原因 |

UGC 可以轻量借用通用视觉母题和动态信息层：符号贯穿可以是固定道具、手势、贴纸、栏目动作或屏幕状态；混乱到秩序可以是桌面、任务流、收纳、清洁或屏幕流程的前后变化；框架闭环可以是开门/关门、开盒/合盒、打开 App/退出结果页、手掌遮镜/移开；展示揭秘可以是先甩结果再讲图层、参数或步骤；图形状态层可以用卡片、图标、进度条、排名板、对比板或手绘圈注承接观点和证据。借用时保持手机原生质感，不把画面做成脱离真实场景的大片。

风格化小世界也可以用于口播，但必须是“说话的人正在借它解释”，不是让动画抢走可信关系。乐高积木、黏土、像素、纸模和玩具沙盘都要被当成讲解工具：主播一句话提出问题，小世界用一个动作演示机制，主播再回到真实产品或真实界面做判断。不要连续十几秒只放动画，也不要让动画承诺现实中无法证明的结果。

UGC 的动效节奏跟人声走，不跟炫技走。图形卡、贴纸、圈注、步骤条和小图标只在短语边界、观点转折、证据出现、点击完成、产品反馈或 CTA 落定时出现；出现后要短暂停住让观众读完。口播仍然是主线，动效只帮观众记住结构、看见证据或感到反应，不做全屏复杂转场、连续扫光、逐字大字幕和密集粒子。

口播玩法执行规则：

- 玩法从第一句或第一动作开始，不等口播讲完半段再补花字。
- 玩法不能替代事实。没有真实体验、数据、评论、价格或优惠时，只能写概括问题、概念演示或可确认素材。
- 玩法须接住当前人声或动作；只有理解确需时才加具体承接句，不默认补“关键在这一步”等空预告，动作已清楚可以直接继续。
- 手机原生感优先：手持、跳切、贴纸、圈注、屏幕录制、道具遮挡、桌面俯拍都可以比大特效更自然。
- 口播自然度优先于广告腔。允许短停顿、让步、反问、轻微自我修正和边界提醒；不要每条都写成“痛点喊话 + 卖点罗列 + 立即购买”。

UGC 的声音可以保留真实环境声，并给关键动作少量拟音：开盒、点击、拖拽、按压、咬下、倒入、翻页、拿起和放下。不要把每个图形卡都配同一种电子提示音；轻微 click、pop、纸张声、手机触感声或真实产品声比合成 notification 更可信。

UGC 创意自检：

- 这个设计是否让观众更相信，而不是只觉得更花？
- 第一秒是否能靠动作、问题、结果或反差停滑？
- 创意是否由真实产品、屏幕、场景、人物身份或服务流程触发？
- 结尾是否回收到产品、方法、观点、适合人群或行动？
- 是否伪造了体验、评论、数据、客户反馈、优惠或专业背书？

## 可选组合维度与结构

当现有口播角度单一时，从下面维度找当前缺口；已有明确写法时跳过，不按八项再执行一轮策划：

1. 主类型：带货、知识、人设、采访、问答、创始人、服务顾问或 App/SaaS。
2. 受众阶段：陌生停滑、痛点共鸣、比较决策、信任补强、行动转化、老粉互动。
3. 受众洞察：怕踩雷、想省事、想变好、想学习、想被理解、想省钱、想确认适不适合。
4. 主钩子：痛点、结果、反差、提问、动作、经验、误区、反对意见、内幕、挑战或清单。
5. 证明机制：可见动作、前后对照、屏幕流程、细节特写、第三方材料、现场互动、口播拆解或边界说明。
6. 视听节奏：快问快答、自然停顿、B-roll 插切、环境声垫底、关键拟音放大、屏幕提示音或短静默。
7. 收束方式：软 CTA、评论互动、收藏复看、直播间预告、预约咨询、去链接了解、继续看系列。
8. 创意设计：动作开场、评论变脚本、小测试/挑战、同机位前后、屏幕手势联动、图形状态层、B-roll 包袱、道具隐喻、现场阻碍解决、系列固定识别或反广告开场。

不要默认固定为“痛点 -> 产品 -> 卖点 -> CTA”。同一个产品可以根据策略变成多条不同 UGC：

- 痛点解决：从具体困扰讲清当前做法能改变什么，用真实条件与过程支撑；旧方法不必失败，角色也不必先犯错。
- 结果前置：先给变化/成品/结论 -> 倒回解释关键动作 -> 承认限制 -> 自然行动。
- 拆误区：指出常见错误 -> 给判断标准 -> 产品/方法作为其中一步 -> 总结可执行建议。
- 体验日记：真实场景开始 -> 过程观察 -> 细节体感 -> 不夸大结论 -> 轻 CTA。
- 对比选择：A 做法和 B 做法并置 -> 关键差异 -> 谁适合/不适合 -> 低压行动。
- 挑战/测试：设定小测试 -> 展示执行 -> 结果或失败边界 -> 下次/链接/直播承接。
- 清单速讲：按实际内容组织判断点、避坑或使用场景，数量不固定。涉及操作、外观差异或效果证明时给必要画面；观点与建议可以由清楚论据、口述例子和人物表达讲通，不为每点硬配动作或插镜，也不只报没有解释的标题。
- 反对意见回应：先说用户顾虑 -> 给事实或演示 -> 说明边界 -> 让观众自己判断。
- 幕后/来源：为什么做这个、怎么选品、怎么开发、怎么服务；适合创始人、员工和服务顾问。
- 互动续集：引用评论/问题 -> 回答一个具体点 -> 留下下一条的问题，不把所有问题塞进一条。

用户明确要多条不同方向时，用下面的变体维度检查内容差异；同一投放目标可保留共同人物、行动与识别，不要求每条都换全部要素。独立视频分别按其任务写。

## 创意矩阵策略

当用户要多条 UGC、批量脚本、A/B 版本或投放测试时，先做创意矩阵，再写脚本。不要把同一条脚本换几个同义词当作多版本。

基础矩阵：

```text
人群角度 x 场景角度 x 痛点角度 x 证明动作 x CTA
```

维度选择：

- 人群角度：新手、进阶用户、忙碌人群、价格敏感、品质敏感、专业用户、老客、送礼人群、门店附近人群、某职业/身份场景。
- 场景角度：早上/晚上、通勤/办公室/家里/门店/户外/课堂/直播前、第一次使用、复购补货、节日前后、问题发生当下。
- 痛点角度：太麻烦、太贵、怕踩雷、不知道怎么选、不信效果、时间不够、看不懂、旧方法低效、售后担心、隐性焦虑。
- 证明动作：开箱、上身/上脸/上手、前后对比、屏幕操作、现场体验、白板演示、材料特写、流程节点、第三方材料、同伴互动。
- CTA：收藏、评论、关注、看链接、预约、直播间、领资料、私信、试用、复购。

批量写作按用户数量与已定投放目的选择有意义的差异，不按条数另加流程或擅改目标。实际视频模型调用的批次上限、确认与分组只按[生产控制](production-control.md)，本节矩阵不授权生成。

矩阵输出可以使用这组简表：

| 视频 | 主类型 | 视频目标 | 人群角度 | 场景角度 | 痛点/欲望 | 证明动作 | CTA |
|---|---|---|---|---|---|---|---|

矩阵去重检查：

- 重点检查观察、理由、问题与依据是否重复；相同系列可以保留有效开场句式，不只为了换句式强改内容。
- 同一证明动作可以在不同问题、解释或对照中复用；不能只换同义词而无新内容。
- CTA 随投放目标保持一致或调整，不为变体强行更换用户要的行动。
- 如果素材只支持一种动作，要改变人群、场景或叙事策略，不伪造新证明。

## 口播与分镜脚本

第一阶段按[第一阶段写法](creative-core.md#连写文案及声音职责)写完整人声，保持整段话题、指代和说话关系清楚，再随方案展示；正式分镜细化表演、画面与声音时间。脚本单独交付的时机只按生产控制，不在本节另设一套文案流程。

脚本要求：

- 口播的解释与依据逐步交付；人物回应、关系和情绪变化也可以推进，不要求每句新增卖点或设计钩子。
- 按实际说话关系选择人称：讲解可以直接对观众说，问答先回应问题，体验分享才用有依据的个人观察；不伪造“我亲测”“回购”“朋友追问”等经历，除非用户提供或确认。
- 禁止编造功效、数据、客户反馈、达人身份、真实测评结果和医学/金融/教育保证。
- 避免低质网感套话，如“宝子”“家人们”“无脑冲”“闭眼入”“yyds”，除非用户明确要这种风格。
- 人声、字幕与素材符号在 Prompt 阶段统一按资产合同，不由口播段落自动要求生成字幕。

口播分镜按完整意思安排 A-roll、演示与补充画面，不要求每个短句配一个手势、音效、花字或切镜。人脸段写清本段的态度、重音、视线和必要反应；谈结构、过程或结果且观众需要亲眼判断时，给看得清的对应画面。可以让同一句话跨镜继续，先提醒看哪里，再展示，最后接着解释刚看到的结果；不把台词切成各镜独立口号。变化密度执行视听工艺的默认标准，时间安排执行分镜合同；新的论据、例句、判断或回应实际展开可以构成信息推进，重复同一句话、机械手势和装饰花字不能计数。连续几镜既没展开意思也没改变观看重点时，先改内容与调度，不靠无关 B-roll 遮盖。

## 钩子与口播节奏

口播的清楚与充实按[视听工艺](audiovisual-craft.md#理解承接与内容充实同时成立)：完整意思持续展开，判断有依据、例子有归属、条件与结论能对应；每次换画面能接住当下说的内容，不因连续跳切打断解释。新观点、关键示范和复杂文字错开注意重点，同一句人声可跨镜连接。保留主要观点、论据、例子与必要条件，先重排句序、把抽象话说具体，再去掉赘语；不把整段压成口号或只留反复手势，也不因怕跳切降低变化密度。新的有效推进补在相关论据、示范、比较或判断中，不靠随机 B-roll 和装饰花字凑数。

开头选当前内容足以进入的一处，后面接着交付；不用先命名一个“主钩子”再给人物配句子。下表按需要查，不把其句式作为所有分享的开场。

| 钩子 | 适用 | 写法 |
|---|---|---|
| 痛点直击 | 带货、教程、知识引流 | 先说具体困扰，再给产品/方法进入理由 |
| 结果前置 | 测评、开箱、功效型产品 | 先展示使用后状态或结论，再解释为什么 |
| 反差开场 | 低关注品类、年轻化信息流 | 用一句违反预期的话或动作停滑，但后续必须证明 |
| 提问开场 | 问答、粉丝互动、直播预告 | 用用户可能真的会问的问题进入 |
| 场景动作 | 探店、家居、食品、教程 | 开场直接做动作，让画面先抓住注意力 |
| 经验判断 | IP 输出、知识付费、行业观点 | 用专业观察进入，后续给方法或证据 |
| 误区纠正 | 教程、测评、低关注品类 | 先指出常见错误，再给出正确方法或产品进入理由 |
| 反对意见回应 | 高客单、效果存疑、B2B 转化 | 先承认顾虑，再给证据或适用边界 |
| 内幕/幕后 | 创始人、员工、服务、课程、B2B | 从“为什么这样设计/服务/交付”切入，给可信背景 |
| 挑战/测试 | 产品测评、工具效率、家居日用、食品饮品 | 设一个小测试，让画面自己证明 |
| 清单判断 | 知识引流、服务顾问、IP 观点 | 按任务所需判断点展开依据与条件；2–3 点只是一种示例，不是信息上限，不为套数量删掉有效观点；压缩赘语与重复，保留必要解释 |

用户要求不同方向的批量内容时，按实际选材改变进入方式，避免只换词。已定系列的开场识别、共同问题格式或用户锁定句式可以保留；本期给新内容，不为轮换钩子破坏栏目识别。

人声承载统一按[分镜合同](storyboard-contract.md#声音方案与声音脚本)核对实际发声区间、正常语速、重音、换气、问答响应、数字/外语读法与操作时间，不另设 UGC 全片总字数预算；不能因为总字数少就判为能自然完成，也不能把快读当感染力。

可选展开示例，不固定句数：

- 短口播：明确判断/问题，给足关键依据，说明结果或适用人群，再自然收束；不为凑句数硬加 CTA 或重复体感。
- 30–60 秒：按当前判断发展问题、依据、回应或操作；需要推荐时说明适合条件，不固定证明点数量或强加总结行动。
- 1-3分钟：观点或测评主线先行，分段讲清证据，不每 15秒重启一次短视频节奏。

中段确有新疑问、证据或判断时可用 re-hook，时机由内容决定；先交付具体新内容，不在固定秒点塞“真正有用的是这里”等空预告，也不伪造“我一开始不信”的经历。没有新内容先重写中段，不靠预告句拖住答案。

真人感首先来自这个人有理由这样说、接着前文继续说。缺了哪层意思就补哪层，不能只加连接词或删成长串短句。开头直入本次判断或观察，中间拿出让它成立的细节，结尾完成回答或推荐，不强制反转、优缺点清单与购买口号。重音、停顿、自然垫词和动作在此基础上细化，不靠故意磕巴表演真实。

口播执行要点：

- 台词先像人说话，再像广告。可以有短句、转折和轻微自我修正，但不能靠大量“真的”“姐妹们”“绝了”填满信息。
- 第一人称可表达已知偏好、当前观察与演示中的选择；购买、长期使用、回购、效果与他人反馈仍须有来源。虚构演绎要准确说明，不冒充真实买家见证。
- 高能带货可以更快，关键结构、过程与可判断结果仍要看清；其他已知信息可以由人声或文字交代，不为每个卖点再配一个动作。
- 知识/IP 类从本期值得听的判断、问题、例子或观察进入，后面完成解释；不铺无关背景，也不把“先结论、再理由”固定成每期句式。
- 直播预告只抛出一个值得进直播间的问题，不要把直播内容在短片里讲完。

## UGC 素材规则

本节只补充 UGC 的素材职责，不自行插入独立资产阶段；是否生成按需人物、产品或音色资产统一服从 `references/production-control.md` 与 `references/asset-generation.md` 的选择门。缺少人物图时，不得仅因本节自动生成人物标准资产。

- 人物：用户给人物图时锁定身份、妆发、服装和体态；用户明确选择无素材概念方案时，可在分镜母版中设计符合品类和平台的概念创作者，不用夸张网红脸或同质化数字人脸，也不得描述成真实达人或指定人物。人物标准图仅按生产控制的资产门及授权制作。
- 产品：产品图是最高优先级参考，锁定包装、logo、SKU、颜色、比例和材质；不得重绘包装或生成假标签。
- 场景：真实生活场景优先，例如桌面、浴室、厨房、客厅、门店、街头、办公室、车内、课程场景。
- 道具：帮助操作、解释、人物关系或真实场景成立，不添加无关摆件抢主体。
- 音频：说话内容清楚，BGM 可以组织段落、情绪与反差；重要现场声和动作反馈留出听见的空间，具体声音职责按分镜合同与视听工艺。

批量 UGC 沿用前面的矩阵去重：不只换衣服或同义词；同一创作者、场景、有效句式或操作可在系列中保留，差异来自本条值得讲的内容及其组织。

## 卖点证明链

销售推荐、测评和效果主张需要把依据写进脚本及相应画面。知识讲解用能实际说明方法的例子，观点和人物表达交代观察与理由，不都套卖点证明链。涉及真实产品、服务结果、课程效果、客户反馈、数据和功效时，只能使用用户提供或已确认的事实。

需要判断卖点依据时可查下表，结论合入已有内容，不另建内部表：

| 维度 | 问题 | 输出到脚本/分镜 |
|---|---|---|
| Feature | 产品/服务客观有什么 | 包装、材质、功能、流程、服务节点、课程模块、页面状态 |
| Benefit | 这项特点为什么值得本次人群在意 | 可以是使用便利，也可以是想要的妆感、口味、搭配、感官或身份表达，不都改写成“更省事” |
| Visual Proof | 画面怎么证明 | 开箱、试用、对比、前后状态、屏幕录制、现场互动、资料页、手部特写 |
| Trust Boundary | 哪些不能说太满 | 不承诺结果、不伪造体验、不替用户下结论、不暗示普遍效果 |

依据是否有效，看它能否支持当前主张，不按“有动作比解释强”统一排序。结构、操作和可见结果用看得清的过程支持；原料、规格、服务条件等看确认资料或实际信息；个人偏好说明当前选择，不假称普遍效果。拿起、涂抹、开箱本身不证明品质，人物解释也不因没有手部动作而只能讲背景。

需要判断实际表现时，不能只靠口头夸奖；缺真实素材就明确写成概念演示，不冒充测评或体验。画面已让人判断的颜色、形态或搭配，不必再口头解释一遍“它带来什么好处”；保留对当前选择有用的话，不为证明等级强加 B-roll。

可信动作清单：

- 产品拿近镜头，停半秒让包装、logo、SKU 或关键结构清楚。
- 手部操作展示关键功能、质地、开合方式、屏幕流程或使用步骤。
- 开箱、闻、试、穿、吃、按、擦、倒、对比、清理、收纳、导出等动作要和卖点一一对应。
- 街采、探店和本地生活场景必须与环境发生互动，例如门头、动线、菜单/服务、体验动作或现场问题。
- 知识口播用白板、电脑、资料页、流程图或案例片段做支撑，不只拍人脸讲道理。
- App/SaaS 口播要让屏幕动作成为证明：输入、生成、筛选、导出、协作或通知至少出现一个。

可信动作必须服务已确认事实。没有用户确认时，不写“临床证明”“销量第一”“三天见效”“客户都说”“全网都在买”等确定声明。

## 平台、场景和人物

用户明确平台与展示位时沿用；未指定时依据当前任务做可修改假设，不新增平台偏好询问。素材询问与必要澄清只按[交互合同](interaction-ask-video-clarification-ref.md#商业素材询问与必要澄清)的具体条件执行。平台名不能直接决定人设、语气与结构：同一平台里的搜索答疑、信息流种草和商品页讲解，观众已知与想获得的内容不同。取材和说话关系按本文件第一阶段写法，画幅、节奏、声音与字幕按各自合同；观看条件的处理按需查[平台语境](creative-methods.md#平台语境)。

跨展示位改编时，先重看首句接住什么问题、中段给什么依据、收束交付什么，再决定沿用哪些原文；不能只给同一口播加语气词、换CTA或调快剪辑。用户锁定的内容保持原样，不根据“英文、小红书、视频号”等单一线索擅自推定完整平台与受众。

场景服务“为什么这个人此刻会推荐/讲解”：

- 美妆护肤：浴室、梳妆台、窗边自然光、手背/脸颊试用；避免食品化和医疗夸张。
- 食品饮品：厨房、餐桌、办公室下午茶、户外野餐、便利店；动作重点是开封、倒入、入口反应、分享。
- 3C/家电：桌面、通勤、客厅、厨房、办公场景；动作重点是按键、连接、响应、前后效率。
- 服饰配饰：试衣镜、街头、通勤、约会/运动场景；动作重点是上身、细节、搭配、走动。
- 家居日用：真实家务动线、收纳、清洁、睡眠、家庭场景；动作重点是旧方案到新方案。
- 课程/知识：书桌、白板、电脑、会议室、线上课程界面抽象；动作重点是讲清方法和价值。
- 探店/街采：门店招牌、环境、体验动作、人物反应；必须避免编造店铺事实和优惠。
- App/SaaS/AI 工具：手机或电脑屏幕、桌面工作流、前后任务状态；动作重点是输入、生成、筛选、导出或协作，不让屏幕只做装饰背景。
- 本地服务/咨询：接待、测量、方案沟通、流程节点、材料或工具；动作重点是解释流程和适合人群，不承诺结果。
- B2B/专业服务：会议桌、白板、后台界面、报告片段、流程图；动作重点是降低决策不确定性，不把复杂服务讲成万能解法。
- 母婴/健康/金融/教育敏感品类：只讲已确认事实、流程和适用边界；避免功效保证、收益保证、治疗暗示和焦虑施压。

没有人物参考图时，默认在分镜母版中建立“符合目标受众和品类的概念创作者”，不另生人物资产，也不把概念角色描述成真实达人或指定人物。只有命中[生产控制的人物资产门](production-control.md)或用户明确要求单独人物资产，并取得相应制作授权后，才生成并确认人物标准图；只插入实际必要的资产准备，不增加其他阶段审阅。人物差异来自脸型、年龄感、气质、穿搭、场景、表达方式和动作习惯，不默认具体种族、国籍或受保护特征，也不用面部痣、穿孔、大面积纹身或夸张配饰强行区分人物。

只有当前传播任务需要行动时才选择自然CTA；纯答疑、教程和完整观点可以停在已交付的判断或操作结果，不默认索要关注、收藏或购买。需要CTA时可按下表选：

| 目标 | CTA 写法 |
|---|---|
| 带货 | 适合的人可以看看链接、先收藏、直播间会细讲 |
| 知识引流 | 想要清单/模板/课程的可以继续看下一条、预约或领取资料 |
| IP/观点 | 评论区可以聊你的情况，或关注后看系列下一条 |
| 探店/本地生活 | 想去的话先看营业时间、预约方式、交通或注意事项 |
| App/SaaS | 可以先试一个具体功能、预约演示、下载试用或看案例 |
| 直播预告 | 预约直播、直播间见，但时间和福利必须来自用户确认 |

CTA 不要过度叫卖，不要用虚假紧迫感。促销、价格、库存、福利、直播时间和领取条件必须来自用户确认。

## 人设与声音变量

人设要服务信任关系，而不是只换外观。没有用户指定时，按产品和平台选择自然身份：

| 人设 | 适用 | 口播气质 | 画面要点 |
|---|---|---|---|
| 普通消费者 | 大众商品、低客单、生活方式 | 轻松、具体、少术语 | 家里、通勤、桌面、真实使用 |
| 专业讲解者 | 课程、工具、B2B、复杂品类 | 清楚、克制、有判断标准 | 白板、屏幕、资料、步骤 |
| 创始人/员工 | 新品牌、SaaS、服务、品牌故事 | 直接、解释动机、承认取舍 | 办公室、工作台、幕后 |
| 达人推荐 | 美妆、服饰、食品、好物集合 | 有审美、有筛选理由 | 试用、搭配、开箱、合集 |
| 门店/现场体验者 | 探店、本地生活、活动 | 像在现场说话，信息具体 | 招牌、动线、服务、体验动作 |
| 评论区答疑者 | 粉丝互动、直播预告、售前疑问 | 回答感强；问题不清楚时简述，已清楚时直接回答 | 评论/问题来源可抽象，不伪造真实截图 |

AI 数字人或虚拟出镜要更重视台词自然度：句子短一点、转折明确一点、避免依赖复杂表情和微妙讽刺。真人或真实素材出镜可以保留更多停顿、口误感和临场动作。

## 分镜阶段

正式分镜沿用已定内容安排镜头职责，下列按本条任务选用，不要求五项配齐或每项各占一镜：

- 停滑钩子：前 1-3秒给痛点、反差、结果、动作或问题。
- 信任建立：人物自然停顿、眼神回镜、手部操作、真实语气。
- 产品证明：产品清晰出现，手部或场景证明卖点。
- 体验反馈：把功能翻译成“对我有什么好处”。
- 行动引导：本片确有该目标时，采用可执行且有内容承接的下一步；分享或答疑已经完成，可以自然结束，不默认补“收藏、试试、看链接”。

UGC 镜头不宜过度复杂。单镜只做一个主动作，运镜以手持微动、轻推、切近景、俯拍或定机位为主。不要在同一镜头堆推拉摇移环绕。

UGC 创意设计保持创作者在具体场景中说话、操作或回应的关系。动作开场、小测试、评论变脚本、屏幕手势联动、框架闭环等设计，落实到 A-roll、B-roll、屏幕或手部动作；复杂调度、风格化美术与图形也可采用，但不能让人物只剩无关的报幕。当前输入与工具无法支撑，或设计挤掉必要解释和操作时，改成真实演示、道具类比或口播观点；不可证实的前后结果不能当作真实体验或功能证据。

人物出镜 UGC 要优先真实生活感：具体环境、自然光、轻微手持、正常皮肤质感、非完美摆拍、口播前后的呼吸和停顿。产品在镜头中的出现由内容职责决定：B-roll 只传产品或场景参考，人物出镜才传人物参考；产品证明镜头必须让包装、logo、SKU 或关键使用动作足够清楚。

已有内容需要安排先后时，可参考下表的节点关系，不另选第二套结构。节点不是镜头数量；有效变化密度与创作节奏例外按[视听工艺](audiovisual-craft.md#默认变化与叙事密度)，具体时间安排按分镜合同。每镜有具体信息、观察、反应或阅读职责，不要求每镜另报一条卖点；同一信息的持续阅读和同一反应的延续不因拆镜重复计数。表中的行动、邀请与互动仅在本片确有该任务时采用；本段是长片中段时不另补开场或收束：

| 结构 | 适用 | 节点逻辑 |
|---|---|---|
| 4 节点带货 | 15秒带货、开箱、测评 | 停滑 -> 产品进入 -> 证明动作 -> 反馈/CTA |
| 3 段知识 | 15-30秒知识引流 | 具体问题 -> 方法/判断标准与例子 -> 完成判断；有后续任务再接行动 |
| 问答切入 | 评论答疑、售前疑问 | 可直接给核心回答，必要时简述问题 -> 理由/演示 -> 必要适用边界 |
| 场景跟拍 | 探店、本地生活、家居日用 | 现场入口 -> 体验动作 -> 关键细节 -> 总结建议 |
| 屏幕工作流 | App/SaaS/AI 工具 | 人物设问 -> 屏幕操作 -> 输出结果 -> 人物解释价值 |
| 对比测试 | 测评、服务、工具、家居 | 旧方案/竞品状态 -> 新方案动作 -> 差异特写 -> 判断边界 |
| 创始人解释 | 新品牌、服务、复杂产品 | 为什么做 -> 解决什么 -> 关键证据 -> 本次判断；有行动任务再邀请了解 |
| 系列 IP | 观点、人设、长期栏目 | 已定开场识别可与有效内容同时出现 -> 本期变量 -> 观点兑现；需要回应时再留互动 |

需要实物证明时，用手部操作、开箱、试穿/试吃或现场互动；知识/观点可用白板、资料或示例支撑。画面动作服务内容和已确认事实，不把产品靠近镜头本身当成证明。

UGC 的行动强度与具体收束统一见“平台、场景和人物”，不在分镜段落再次建立一套 CTA 规则。

演示类分镜标明最关键的证明动作和特写目标，例如包装、材质、屏幕结果或服务流程；观点、知识和问答可以靠清楚论据与示例成立，不强求“一秒动作”证明复杂观点。缺少依据时补论据，不用更多口号掩盖。

## 长视频 UGC

知识引流、课程预告、深度测评、完整探店和系列 IP 内容可进入长视频。长视频不是多个短口播拼接：

- 全片先确定一条观点或体验主线。
- 分段接续同一内容与说话关系，边界按自然语义、动作与实际时长安排；不为凑“开题、痛点、证明、总结”等阶段拆散完整意思或重新开场。
- 每段口播承接上一段，不重复开场招呼和 CTA。
- 同一人物、场景基调、声音和表达节奏保持连续。
- 最终段完成当前主线；复杂内容按需要复核要点，有实际行动任务才加入引导，不机械补总结与 CTA。

## 营销口播的产品关系

先明确本次为什么要讲这件产品，再让这个人讲他的观察与判断。日常小反应可以保留，但“好吃、再来点、这个颜色怪”不能独自替代本次产品内容。删去本次特点后，主要话题和结论完全不变时，回改取材，不靠加品牌名弥补。

推荐依据可以来自当场演示、可核实产品信息、明确个人偏好或真实使用资料；不要求全部拍成实测，也不发明使用史。产品名、功能和购买提醒可以自然直接说，包装与画面也可以完成识别，不硬把每项信息念出来。

知识引流先交付一个真实有用的解释或做法，后续课程/服务承接本次内容；不能故意讲不完整逼人咨询。权益、价格和领取方式必须真实。强转化、普通分享、答疑各有行动强度，不默认每条都收藏关注、评论和点链接。

### 行业敏感内容的补充

共通功效、价格、认证与行业事实边界查[行业风险](product-ad-video.md#行业风险与可说不可说)。UGC 还须单独核对说话人身份、经历与证言来源：当场演示不能改写成长期使用，演员不能写成真实购买者，策划问题不能冒充热门评论；真实采访不预写受访者结论。
