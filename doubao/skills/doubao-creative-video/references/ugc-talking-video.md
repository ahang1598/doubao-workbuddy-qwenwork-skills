# UGC 口播视频

## 文件说明与索引

本文件只负责 UGC 口播、带货讲解、测评、开箱、教程、达人推荐、知识引流、人设 IP、探店采访、问答互动和直播预告的专属策略。参数确认、阶段确认、目录、阶段上屏、工具和成片规则读取 `references/production-control.md`；通用创意方向读取 `references/creative-core.md`；通用视听语言读取 `references/audiovisual-craft.md`；视觉效果、叙事节点和转场同步读取 `references/visual-motion-playbook.md`。

## 适用边界

使用本策略的场景：

- 带货口播讲解、真人测评讲解、达人推荐。
- 知识付费引流、课程预告宣传、经验分享口播。
- 个人 IP 日常输出、行业观点输出、粉丝互动口播。
- 探店口播、街头采访、真实场景体验。
- 问答互动口播、直播预告口播。
- 创始人/员工出镜、服务顾问讲解、本地生活推荐、App/SaaS 工作流演示、B2B 轻量获客口播。

如果核心不是“人对人解释/推荐/体验”，而是纯产品大片、品牌 TVC 或企业宣传，回到入口改选唯一对应类型文件，不在 UGC 文件内继续分流。

## 类型谱系

UGC 口播不是单一模板。先判断用户要的是哪一种“人对人表达关系”，再选择脚本策略、证明动作和画面比例；不要把所有需求都写成同一套带货话术。

| 类型 | 典型场景 | 默认比例 | 核心任务 | 常见误区 |
|---|---|---|---|---|
| 带货口播型 | 带货讲解、真人测评讲解、达人推荐、开箱种草 | 默认 `9:16`；商品承接可 `1:1` | 把卖点变成可见证明和自然购买理由 | 只喊卖点、虚构亲测、过度叫卖 |
| 知识引流型 | 知识付费引流、课程预告、经验分享、方法论拆解 | 默认 `9:16`；课程长版可 `16:9` | 先交付一个可用认知，再自然引出方法/课程 | 一上来卖课、空泛成功学 |
| 人设 IP 型 | 个人 IP 日常输出、行业观点、粉丝互动、创作者系列 | 默认 `9:16`；小红书可 `3:4` | 强化稳定人设、观点口味和系列识别 | 每条都换人设、只讲鸡汤不兑现观点 |
| 场景采访型 | 探店口播、街头采访、门店体验、真实场景观察 | 默认 `9:16`；横版合集可 `16:9` | 用现场细节和人物互动建立真实感 | 编造店铺事实、只拍环境不讲体验 |
| 问答互动型 | 评论区答疑、粉丝问答、直播预告、反对意见回应 | 默认 `9:16` | 把用户问题转成内容入口和转化理由 | 自问自答太假、问题和产品无关 |
| 创始人/员工型 | 创始人解释产品、员工视角、幕后开发、品牌小故事 | 默认 `9:16`；官网/路演切片可 `16:9` | 用内部视角建立动机、专业度和可信边界 | 讲成企业宣传片、口吻太官方 |
| 服务顾问型 | 本地服务、咨询、医美/教育/装修/企业服务线索获取 | 默认 `9:16`；复杂讲解可 `16:9` | 降低决策焦虑，解释流程、风险和适合人群 | 承诺结果、制造恐慌、隐藏限制 |
| App/SaaS 演示型 | App、工具、AI 产品、B2B 软件、效率工作流 | 默认 `9:16`；桌面录屏可 `16:9` | 让屏幕动作证明“它真的能做什么” | 口播列功能，屏幕只当背景 |

类型可以组合，但必须有主类型。例如“课程带货”主类型通常是知识引流，“创始人卖产品”主类型通常是创始人/员工型，“探店团购”主类型通常是场景采访型。组合时只迁移策略，不把多个开场、多个 CTA 和多个证明链硬塞进一条短片。

## 口播画面组织

UGC 的自然感来自稳定人物身份、轻微姿态变化、短语边界跳切、真实反应和少量强调手势。人物动作必须来自态度和观点：怀疑、惊喜、认真权衡、调侃、亲切分享或专业判断；不要为每个词安排一个手势，也不要全程僵硬看镜头。

B-roll、屏幕录制、手部特写、产品细节、门店环境和生活方式镜头用于证明、解释、情绪、幽默或节奏呼吸，不按口播名词逐个配图。人物声音可以在 B-roll 上继续；下一句声音可以先进入，再切回人脸或产品。口播分镜要标清哪些段落是 A-roll，哪些段落由 B-roll 覆盖，以及覆盖画面证明了什么。

UGC 开头不能只是“主播面对镜头完整说完第一句”。0-3 秒必须把人、问题和证明线索同时拉起来：可以是手部先做动作、产品先进入画面、屏幕先显示结果、评论/问题卡先弹出、人物先给强判断、或 B-roll 先给结果前置。若开场使用 A-roll 人脸，第一秒内必须有明确表情、手势、道具、问题卡或跳切，1-3 秒内必须出现产品/方法/屏幕/场景证据之一；不能让一个固定中景口播镜头拖完整三秒。

短 UGC 的开头节奏按短语和动作拆分，不按自然段拆分。15 秒内视频的前 3 秒至少拆成 3 个信息拍：`0-0.7 秒停滑动作或问题`、`0.7-1.6 秒人物判断或结果`、`1.6-3 秒产品/屏幕/场景证据进入`，并至少发生一次有意义跳切、B-roll 插切或观看关系变化。如果同一机位连续超过约 1.2 秒，必须在画面内加入可见动作与构图升级。

## UGC 可信发动机

UGC 的“创意”不是把口播包装得更像广告，而是让观众觉得这个人有理由这么说、这个动作真的证明了这句话。每条 UGC 先建立可信发动机，再写台词。

内部推导：

```text
说话人身份：为什么由这个人讲
观众顾虑：观众为什么不立刻相信
一句判断：这条视频只想让观众接受什么
黄金动作：哪个动作能让判断变得可见
反应证据：人物、物体、屏幕、环境或结果如何反馈
适用边界：哪些人适合/不适合，哪些事实待确认
行动收束：观众下一步只做什么
```

UGC 的核心句要像人话，不像标题党。不要把“好用、平价、高级、闭眼入、姐妹们冲”当脚本中心；它们只能作为语气。真正的中心应带判断、场景和理由：

| 弱口播 | 更可执行的中心句 |
|---|---|
| 这个真的很好用 | 我以为它只是好看，结果最省事的是这一步 |
| 姐妹们一定要买 | 如果你每天出门前最烦补这一步，这个可以先看 |
| 性价比超高 | 我愿意留它，不是因为便宜，是因为这三个场景都用得上 |
| 科技感很强 | 它厉害的不是功能多，而是点一下后结果直接归位 |
| 宝妈必备 | 不是所有孩子都需要，但遇到这种场景先别慌，流程是这样 |

## 黄金证明动作

UGC 每条至少有一个“黄金证明动作”。它可以很小，但必须让口播从“我说”变成“你看”。黄金动作通常出现在 1-8 秒之间，不能只留到结尾。

| 类型 | 黄金动作 | 画面配合 | 失败信号 |
|---|---|---|---|
| 带货种草 | 开箱、拉扯、上脸、倒入、喷一下、咬开、穿上走两步 | 手部近景 + 人物一句判断 + 结果停留 | 全程人脸念卖点，产品只在尾帧出现 |
| 测评体验 | 旧方法先失败，新方法完成；或同一任务前后对照 | 对比画面要同场景、同角度、同条件 | 换场景做前后对比，像作弊 |
| 知识引流 | 写下一个判断公式、圈出一个错误、演示第一步 | 白板/屏幕/纸张/图形卡跟口播同步 | 只讲道理，没有可带走的方法 |
| 服务顾问 | 展示流程节点、材料清单、预约前自检 | 图形步骤少而清楚，口播讲边界 | 制造焦虑但不给判断标准 |
| SaaS/App | 输入 -> 点击 -> 结果面板落下 | 屏幕动作是主证据，人声解释为什么重要 | 口播讲功能，屏幕模糊或假 UI |
| 探店/本地生活 | 进门、点单、体验、结账/离店一句判断 | 门头/环境/细节/反应形成动线 | 只拍装修和氛围，不给真实体验 |
| 创始人/员工 | 拿出一个设计取舍、用户反馈或后台流程 | 幕后细节和一句坦诚解释 | 讲愿景太多，缺具体选择 |

黄金动作后要给反应，而不是立刻切走。反应可以是人物表情、产品状态、屏幕完成、环境改变、同伴一句话、拟音落点或花字锁定。没有反应，动作就只是摆拍。

## 口播与画面分工

口播负责判断、边界和人味；画面负责证明、质感和节奏。不要让口播把画面已经证明的内容重复念一遍，也不要让 B-roll 只按名词配图。

分工规则：

- 口播说“为什么”：为什么我会留下它、为什么这个问题常被忽略、为什么这个流程更稳。
- B-roll 说“你看”：材质、动作、前后状态、屏幕结果、门店动线、真实使用阻力。
- 花字说“记住”：只提炼关键词、反问、状态锁定、步骤名或 CTA，不逐字铺满。
- 拟音说“发生了”：开盖、点击、拉链、喷雾、咬下、归位、消息提示等和动作绑定。

UGC 可以有超现实反馈，但只能发生在一个关键动作上，帮助观众理解卖点。例如喷雾让油污短暂退潮、点击让任务卡片归位、拉开衣料让弹性线条出现。它必须保持真实口播关系，不能中途变成完整 TVC 大片。

## 类型策略库

不同 UGC 类型必须使用不同策略池；不要先写一个通用口播模板再替换品类词。每次生成先选主类型，再从该类型里选 1 个主策略和 1 个辅助策略。批量视频要在同一类型内轮换策略，或跨类型组合成内容矩阵。

### 带货口播型

带货的核心不是“喊购买”，而是让观众相信这个产品解决了一个具体购买理由。

可选策略：

- 痛点解决：先给一个具体麻烦，再用产品动作证明它少了哪一步。
- 开箱第一印象：从包装、材质、手感、尺寸、上身或上桌状态进入，适合新品和低决策成本商品。
- 结果前置：先展示成品、效果状态或使用后场景，再解释关键卖点；必须避免夸大功效。
- 对比替换：旧方法/旧产品的问题 -> 新产品动作 -> 差异特写；适合家居、3C、日用和工具。
- 细节控种草：围绕一个小细节展开，例如拉链、杯口、按键、面料、气味、声音；适合小红书和高质感商品。
- 反对意见回应：先承认贵、不确定、怕踩雷、不知道怎么选，再用事实和边界回答。
- 组合场景：展示 2-3 个使用场景，强调“为什么留在生活里”，不把卖点列成说明书。

带货 CTA 默认低压：先收藏、适合的人看看链接、直播间再细讲。只有明确强转化投放时才使用更直接行动。

### 知识引流型

知识引流先给观众一个小收益，再引出课程、服务、资料或后续内容。

可选策略：

- 误区纠正：指出一个常见错误，给判断标准，再自然引出系统方法。
- 三点清单：3 个避坑、3 个判断、3 个动作；每点都要有画面锚点或手势/白板/屏幕支持。
- 案例拆解：用一个匿名或用户提供的案例讲清原因、方法和下一步，不能编造案例。
- 步骤示范：直接演示第一步怎么做，让课程/资料成为继续深入的承接。
- 观点反差：提出反常识判断，再用逻辑拆开；适合行业观点和专业 IP。
- 价值先行：给一个模板、公式、检查表或判断问题，CTA 指向领取/预约/继续看；只有用户明确提供免费权益时，才写“免费领取”或类似承诺。
- 课程预告：先讲本节能解决什么，不夸大学完结果；强调适合人群和不适合人群。

知识引流的 CTA 要像学习路径：收藏、评论关键词、领取资料、看下一条、预约诊断。不要一开头硬卖课。

### 人设 IP 型

人设 IP 的核心是稳定识别和观点兑现，不是每条都重新包装一个广告。

可选策略：

- 固定栏目：固定一句开场或固定问题形式，变量是本期主题；适合系列。
- 行业判断：用专业经验给一个清晰立场，后面必须给判断依据。
- 日常切片：从工作、生活、门店、会议、通勤中的真实瞬间引出观点。
- 粉丝互动：回应评论、私信、常见问题；问题可以概括，但不能伪造具体截图。
- 反面清单：什么不要做、什么不适合、什么会踩坑；适合建立可信边界。
- 幕后复盘：讲一次选择、失败、改版、选品或服务经验，增强人格真实感。
- 价值观表达：适合品牌主理人和专家 IP，但必须落到具体事件或判断，不写空泛态度。

人设 IP 的每条不一定都要出现产品；如果出现产品，也要服从本期观点，不要突然变成带货广告。

### 场景采访型

场景采访用现场感和互动建立可信度，重点是“人在真实空间里发现了什么”。

可选策略：

- 探店动线：门头/入口 -> 核心体验 -> 细节 -> 适合人群/注意事项。
- 街头快问快答：一个问题问 2-3 人或一个人连续追问；适合活动、趋势和本地生活。
- 店员/顾问一句话：让现场工作人员解释一个关键信息；必须避免编造身份和优惠。
- 体验前后：进店前期待 -> 体验中动作 -> 体验后一句判断；适合餐饮、娱乐、服务。
- 现场问题解决：在真实场景遇到一个困扰，当场用产品/服务/路线解决。
- 路人反应/同伴视角：用反应增强真实感，但不能伪造用户评价。
- 横版合集：多个门店/多个点位/多个采访对象组合时可用 `16:9`，但每段仍要有具体信息。

场景采访必须写清事实来源：营业时间、价格、优惠、地址、排队情况、体验结果都需要用户提供或确认。

### 问答互动型

问答互动适合承接评论、售前疑虑、直播预告和高频问题，重点是“先听见用户，再回答一个点”。

可选策略：

- 单问单答：只回答一个问题，短视频最稳。
- 连环追问：同一问题拆成 2-3 个追问，适合复杂服务和课程。
- 反对意见回应：贵不贵、适不适合、有没有必要、和竞品差在哪。
- 直播预告：用一个高频问题引出直播会讲的重点，而不是只报时间。
- 评论续集：上一条评论引发下一条内容，适合系列互动。
- 二选一判断：A 和 B 怎么选，给适用条件，降低决策成本。
- 错误提问纠正：先改写用户问题，让观众理解真正该问什么。

问答型不能假装有真实评论来源。没有评论素材时，用“很多人会问/常见问题是”这种概括方式。

### 创始人/员工型

创始人/员工型靠内部视角建立可信度，适合解释产品动机、设计取舍和服务承诺。

可选策略：

- 为什么做：从一个真实动机或行业问题进入，讲清产品存在理由。
- 设计取舍：解释为什么保留/砍掉某个功能、材质、流程或服务方式。
- 幕后一天：用工作现场切片串起产品或服务能力。
- 失败复盘：讲一次踩坑、改版或用户反馈后怎么调整；适合建立信任。
- 员工视角：客服、设计、研发、门店人员讲一个常见细节。
- 透明报价/流程：解释费用、周期、交付、售后或适合边界；适合服务类。
- 给新用户的一句话：低压邀请，不把自己包装成权威广告主。

创始人/员工型可以更坦诚，但不能变成企业宣传片。少讲愿景，多讲具体选择和证据。

### 服务顾问型

服务顾问型的任务是降低焦虑和帮助判断，不是制造恐惧或承诺结果。

可选策略：

- 适合/不适合：先划边界，反而更可信。
- 流程透明：第一步做什么、需要准备什么、多久反馈、哪里容易误解。
- 避坑提醒：告诉用户下单/咨询前要看什么，适合教育、装修、医美、本地服务。
- 案例抽象：用“某类情况”讲方法，不编造客户故事和结果。
- 费用解释：解释费用组成或影响因素，不虚构价格。
- 风险说明：主动讲限制、注意事项和需要确认的信息。
- 预约前准备：列 2-3 个准备材料或自检问题，让 CTA 更自然。

敏感行业必须克制：不做治疗、收益、升学、变美、变富等保证，不用恐吓式话术。

### App/SaaS 演示型

App/SaaS 的口播必须让屏幕动作成为证明；观众要看到输入、处理和输出。

可选策略：

- 工作流前后：旧流程需要几步 -> 现在怎么做 -> 输出结果是什么。
- 屏幕结果前置：先给生成结果/看板/完成状态，再倒回展示关键一步。
- 一分钟任务：设定一个小任务，看工具如何完成；避免讲成全功能介绍。
- 角色场景：创作者、销售、运营、学生、开发者各自的一条工作流。
- 对比替换：替代 Excel、手工整理、多工具切换、重复沟通等旧方法。
- 功能拆一招：每条只讲一个功能，不把产品官网搬进口播。
- 创始人/用户教育混合：复杂 B2B 可以先讲为什么需要，再用屏幕证明。

屏幕里如果没有真实 UI 素材，只能写抽象界面或概念演示；不要生成假数据、假客户、假后台指标或无法证实的数字。

## 目标分层策略

同一 UGC 类型会因为视频目标不同而使用完全不同的节奏。生成前先判断目标；用户没说目标时，从用户指令里的行动词推断，并在参数确认里写明“按默认推断”。

| 视频目标 | 适用意图 | 节奏重点 | 证明重点 | CTA |
|---|---|---|---|---|
| 种草 | 让观众产生兴趣、收藏、愿意继续了解 | 生活化开场，细节和体感多一点，少压迫 | 场景、材质、使用瞬间、审美理由 | 收藏、看看链接、适合的人了解 |
| 转化 | 让观众下单、领券、试用或点击 | 前 3秒说清问题和利益，中段快速证明，结尾行动清楚 | 产品动作、价格/权益、适合人群、反对意见 | 去链接、领券、立即试用、直播间下单 |
| 获客 | 让观众咨询、预约、留资 | 先降低焦虑，再解释流程和适合边界 | 服务流程、准备材料、案例类型、顾问判断 | 私信/预约/填写表单/先做评估 |
| 涨粉 | 建立账号关注理由 | 观点更鲜明，结尾留系列感 | 专业判断、稳定栏目、下期承诺 | 关注、评论问题、看下一条 |
| 直播预约 | 把兴趣转移到直播间 | 抛出一个直播会解决的问题，不在短片里讲完 | 高频问题、福利或演示预告、时间信息 | 预约直播、直播间见 |
| 私域导流 | 引导加群、领资料、进私域 | 先给明确价值，再给领取理由 | 模板、清单、资料截图、适用人群 | 评论关键词、私信、领取资料 |
| 品牌信任 | 让观众相信人、团队或品牌 | 节奏可稍慢，讲动机、取舍和边界 | 幕后、流程、真实材料、专业判断 | 了解品牌、看主页、预约沟通 |
| 复购 | 面向老客、粉丝、已购买人群 | 不重复基础介绍，直接讲新场景、新用法或提醒 | 使用技巧、补充搭配、维护、周期提醒 | 复购、补货、收藏用法、加入会员 |

默认推断规则：

- 用户只说“做口播/种草/小红书感觉”：默认种草或品牌信任。
- 用户说“带货/卖货/信息流/投放/转化”：默认转化。
- 用户说“获客/线索/咨询/预约/到店”：默认获客。
- 用户说“涨粉/IP/日常输出/栏目”：默认涨粉或品牌信任。
- 用户说“直播/开播/预热”：默认直播预约。
- 用户说“私域/社群/领资料/加微信”：默认私域导流。
- 用户说“老客/复购/会员/回购提醒”：默认复购。

目标冲突时只保留一个主目标，一个副目标。例如“种草 + 转化”可以先种草、结尾轻转化；不要同时要求强购买、强关注、强私域和强直播预约。

## 确认阶段重点

参数确认阶段必须把 UGC 的可执行方向讲清楚：

- 出镜形式：真人、数字人、手部出镜、第一视角、街采、探店、问答或无人物旁白。
- 人设：真实创作者身份、年龄感、职业/生活场景、表达气质；没有人物参考时只做“符合品类和目标受众的真实创作者”，不默认具体种族或受保护特征。
- UGC 类型：从类型谱系选择主类型，必要时补一个副类型；不要只写“营销口播”。
- 视频目标：种草、转化、获客、涨粉、直播预约、私域导流、品牌信任或复购；用户没说时按用户指令推断。
- 受众阶段：陌生停滑、已知痛点、正在比较、临门一脚、老粉互动或复购提醒。
- 受众洞察：观众为什么会停下、相信或行动，是焦虑、怕踩雷、想省事、想变好、想被理解、想省钱、想学会还是想获得身份认同。
- 台词来源：用户提供、参考资料提取，或由 agent 起草。
- 可信证明：产品试用动作、开箱、对比、真实反馈、场景体验、课程价值、知识点、流程透明或屏幕操作。
- 关键证明动作：每条视频至少规划一个可见的“黄金动作”，证明核心卖点，而不是只靠口播解释。
- 视听节奏：口播快慢、停顿、B-roll 插入、拟音、环境声、屏幕提示音或静默如何增强可信感。
- 平台语境：用户明确平台优先；未说明平台时默认竖屏短视频通用策略，并按产品和目标推断最可能的平台。

参数确认里的分镜表默认 3-5 个叙事节拍：钩子、证明、体验、补充信息、软 CTA；这只是用户确认方向，不等于正式详细分镜的镜头数量。15 秒 UGC 正式分镜最低 `8` 镜，按口播短语边界、黄金动作、B-roll 证据和反应需要增加；自然口播可保持人物身份与场景稳定，但要用有意义跳切、动作近景、证据插切或观看关系变化满足节奏，不能固定中景拖满。最终视频 Prompt 只能从校验通过的完整分镜按 `Bxx -> SHxxx -> SEGxx` 编译，不得省略动作桥、必要切点和信息增量。

确认阶段不要机械列满所有策略。根据用户指令选择“主类型 + 视频目标 + 受众阶段 + 一个核心证明 + 一个主 CTA”，并说明为什么这样组合；批量视频再轮换类型、钩子和证明动作。

## 主体登场策略

UGC 的第一主体通常是“可信的人”或“真实动作”，不是品牌世界。开场要让观众相信这个人为什么现在要说这件事。

| 场景 | 开场主体 | 产品/方法进入 | 避免 |
|---|---|---|---|
| 带货讲解 | 人脸、手部动作、痛点物件或结果状态 | 证明开始处进入，包装清楚 | 先铺品牌空镜、过度摆拍 |
| 测评/开箱 | 第一印象、拆封动作、结果前置 | 开箱或结论后快速出现 | 编造亲测和夸张反应 |
| 知识引流 | 问题、误区、判断标准 | 方法或课程作为解决方案后进入 | 一上来硬卖课 |
| 探店/街采 | 门店/街头互动、人物问题 | 场景体验自然带出 | 编造店铺事实和优惠 |
| IP 观点 | 人设判断、专业场景、真实语气 | 不一定有产品，重点是观点兑现 | 套广告腔和空泛鸡汤 |

UGC 可以直接、轻微粗糙、像临场记录，但不能乱。真实感来自场景理由、动作证据、语气停顿和细节，而不是低质画面、夸张表情或口头禅堆叠。

## UGC 创意设计器

UGC 的创意不是大片化，而是让“真人为什么此刻说、观众为什么相信、画面为什么比口播多一层”成立。每条最多选 1 个主设计和 1 个辅助设计；创意必须服务可信证明，不能替代事实。

口播也可以加入玩法和创意，但玩法必须像创作者自然想出来的表达方式，而不是把产品广告大片硬套到人脸口播上。口播玩法的核心是“这个人用一个动作、道具、屏幕、测试、评论、场景或小规则把话说清楚”。先判断说话关系，再决定玩法强度；不是所有口播都默认生硬种草，也不是所有创意都要变成夸张特效。

口播同样可以有世界规则，但它必须服务“说话关系”。达人、数字人、创始人或顾问不是在旁边念广告，而是在使用一个可理解的小规则讲清楚观点：桌面变成微缩沙盘、乐高小人完成任务、屏幕 UI 接管现实、数字人承认自己是 AI 分身、同机位前后对照证明结果、购物袋匹配剪辑完成换装。规则越强，越要让人物用自然口播承接它，例如“我用这个小模型给你拆一下”“先看这个前后对照”“我直接试给你看”“这个分身现在替我上班”。

常见自然说话关系：

| 说话关系 | 适合 | 口播语气 | 玩法承接 |
|---|---|---|---|
| 朋友提醒 | 种草、避坑、生活方式、本地生活 | 轻松、具体、有边界 | 手绘圈注、对比小卡、生活 B-roll、反应花字 |
| 现场实验 | 测评、工具、食品、家居、App | 直接试给你看，少铺垫 | 小测试、计时器、挑战条、前后对照、失败回弹 |
| 观察判断 | IP、知识、专业建议、选品 | 先给判断，再给理由 | 观点卡、证据卡、分屏比较、关键词锁定 |
| 反对意见回应 | 高客单、B2B、服务、功效存疑 | 先承认顾虑，再解释边界 | 评论卡、疑虑卡、旧新争夺、流程透明图 |
| 设计拆解 | 产品结构、AI 工具、课程、3C | 解释“为什么这样设计” | 爆炸图、结构标签、屏幕手势联动、放大镜裁切 |
| 创始人/员工 | 幕后、品牌信任、服务说明 | 坦诚、克制、讲取舍 | 幕后 B-roll、流程线、材料卡、版本对比 |
| 顾问判断 | 教育、医美、装修、咨询、本地服务 | 先帮用户判断适不适合 | 适合/不适合卡、步骤条、风险提示、准备清单 |
| 旁观吐槽 | 年轻化、轻娱乐、低风险消费 | 反差、吐槽、包袱，但不造假 | B-roll 包袱、拟声花字、荒谬小道具、反向揭示 |

### 口播核心玩法

UGC 也必须有重心。每条口播先锁一个“观众为什么信”的黄金动作，再决定台词。黄金动作可以很小，但必须可见、可听或可读：

| 黄金动作 | 适合品类/目标 | 证明什么 |
|---|---|---|
| 空管/用旧/快用完 | 美妆、个护、日用品、咖啡等复购品 | 高频真实使用和喜爱度 |
| 开箱拿近镜头 | 服饰、礼盒、3C、家居、食品 | 第一印象、质感、包装和期待感 |
| 上脸/上唇/上脚/上身 | 美妆、鞋服、配饰 | 效果不是口头承诺，而是看得见 |
| 拉扯/按压/开合/喷洒 | 面料、家清、个护、工具、小家电 | 功能反馈、弹性、清洁力、便携或操作感 |
| 屏幕结果落定 | App、SaaS、AI 工具、课程资料 | 工具真的完成一个任务 |
| 价格递进板 | 直播引流、促销、货架带货 | 原价、直降、券后或行动理由层层清楚 |
| 场景痛点反应 | 防晒、运动饮料、祛痘、家居、服务 | 需求不是编的，是当下场景自然发生 |
| 试吃/饮用/闻香反应 | 食品、咖啡、香氛、饮料 | 感官体验和人物真实反馈 |
| 评论/问题卡入场 | 问答、售前疑虑、知识引流 | 先听见用户，再回答一个点 |

开场不必每次都吼卖点。更有效的口播开场通常是“动作先行 + 一句判断 + 证据进入”：

```text
0-0.7 秒：手/脸/屏幕/场景先出现一个动作或问题
0.7-1.6 秒：人物给一句强判断或反问
1.6-3 秒：产品、屏幕、价格板、效果或 B-roll 进入证明
```

口播台词要围绕黄金动作写，不围绕卖点表读稿。比如先展示上唇效果，再说显色和质地；先拉扯面料，再说高弹轻薄；先出现评论疑问，再解释适合边界；先给屏幕完成状态，再倒回关键操作。画面已经证明的内容不要重复念，台词负责补原因、边界、适合人群和行动。

价格、优惠、库存、宝妈圈口碑、销量、空管经历、亲测时长、专业身份和用户反馈都必须来自用户材料或明确设定。没有材料时，可以写成“假设型演示/概念口播”，不能伪装真实背书。

| 设计 | 适合 | 执行 |
|---|---|---|
| 动作开场 | 产品、教程、探店、工具 | 第一秒直接做一个手部、屏幕或现场动作，口播随后解释这个动作为什么重要 |
| 评论变脚本 | 问答、直播、售前、IP 互动 | 把一个常见问题作为开头；没有真实评论时写“常见问题”，不要伪造评论截图 |
| 小测试/挑战 | 测评、家居、工具、食品饮品 | 设置一个能当场完成的小任务，展示执行过程、结果和边界 |
| 同机位前后 | 清洁、收纳、效率、服务流程 | 保持光线、角度和主体一致，让旧状态和新状态清楚对比，不夸大变化 |
| 屏幕手势联动 | App、SaaS、AI 工具、课程工具 | 人物一句话提出任务，手势或点击接入屏幕流程，屏幕完成输入、生成、筛选或导出，人物回镜解释价值 |
| 图形状态层 | 口播、问答、榜单、测评、知识、服务顾问 | 用问题卡、观点卡、步骤条、进度条、对比板、数据卡、图标状态点承接口播结构；卡片的出现、替换、打勾、归位或锁定必须对应一句信息变化 |
| 展示揭秘 | 教程、剪辑/设计/AI 工具、创作者方法、案例复盘 | 前 1-3 秒先展示最终效果、前后对比或最强结果，再切回时间线、图层、素材清单或关键操作；揭秘只讲核心机制，最后回到结果验证 |
| B-roll 包袱 | 观点、知识、带货、榜单 | 人脸给判断，B-roll 给反差、证据或幽默点，声音不断线 |
| 道具隐喻 | 知识、服务、复杂产品 | 用一个简单物件解释抽象流程，结尾必须回到真实页面、产品、服务节点或行动 |
| 现场阻碍解决 | 探店、本地服务、家居、流程服务 | 现场遇到一个具体麻烦，当场用产品、服务、路线或方法解决 |
| 系列固定识别 | IP、栏目、批量内容、直播预热 | 固定开场动作、构图、道具或问题格式，本期变量提供新信息 |
| 反广告开场 | 高警惕受众、高客单、B2B、敏感品类 | 先承认限制、不适合人群或常见顾虑，再给证据和适用边界 |
| 现实界面化 | App、SaaS、工具、效率、知识解释 | 把按钮、下拉框、进度条、任务卡或播放器样式轻量叠进真实画面，由手势或口播短句触发状态变化 |
| 小道具控制 | 生活方式、穿搭、探店、好物、教育 | 用剪刀、便签、遥控器、卡片、杯子、包装撕口等真实道具触发转场或观点变化，结尾回到真实产品/方法 |
| 拼贴讲解 | 知识、课程、城市、品牌故事、年轻化种草 | 用照片、票据、纸片、产品图、手写字和箭头组成可移动讲解层，像创作者临场整理思路 |
| 风格化小世界讲解 | 产品结构、工具流程、食品饮品、生活方式、品牌故事、复杂卖点 | 主播旁边或 B-roll 中出现乐高积木、黏土定格、像素游戏、纸模、玩具沙盘或漫画分格小世界；小世界里的拼装、闯关、修复、归位、奖励必须对应一句口播信息或一个真实卖点，最后切回主播手里的真实产品/屏幕/场景 |
| 文字参与场景 | 标题感口播、栏目、品牌/IP 识别 | 关键词不是字幕，而是贴在桌面、墙面、屏幕、包装旁或人物身后，跟随手势、视线或证据落位 |
| 结果倒推 | 测评、清洁、效率、食品、课程 | 先给结果或完成状态，口播说“倒回看关键一步”，再用 B-roll 或屏幕流程解释原因 |

UGC 可以轻量借用通用视觉母题和动态信息层：符号贯穿可以是固定道具、手势、贴纸、栏目动作或屏幕状态；混乱到秩序可以是桌面、任务流、收纳、清洁或屏幕流程的前后变化；框架闭环可以是开门/关门、开盒/合盒、打开 App/退出结果页、手掌遮镜/移开；展示揭秘可以是先甩结果再讲图层、参数或步骤；图形状态层可以用卡片、图标、进度条、排名板、对比板或手绘圈注承接观点和证据。借用时保持手机原生质感，不把画面做成脱离真实场景的大片。

风格化小世界也可以用于口播，但必须是“说话的人正在借它解释”，不是让动画抢走可信关系。乐高积木、黏土、像素、纸模和玩具沙盘都要被当成讲解工具：主播一句话提出问题，小世界用一个动作演示机制，主播再回到真实产品或真实界面做判断。不要连续十几秒只放动画，也不要让动画承诺现实中无法证明的结果。

UGC 的动效节奏跟人声走，不跟炫技走。图形卡、贴纸、圈注、步骤条和小图标只在短语边界、观点转折、证据出现、点击完成、产品反馈或 CTA 落定时出现；出现后要短暂停住让观众读完。口播仍然是主线，动效只帮观众记住结构、看见证据或感到反应，不做全屏复杂转场、连续扫光、逐字大字幕和密集粒子。

口播玩法执行规则：

- 玩法从第一句或第一动作开始，不等口播讲完半段再补花字。
- 玩法不能替代事实。没有真实体验、数据、评论、价格或优惠时，只能写概括问题、概念演示或可确认素材。
- 每个玩法都要有口播承接句，例如“我直接试一下”“关键不是这里，是这一步”“先别急着买，先看你是不是这种情况”。
- 手机原生感优先：手持、跳切、贴纸、圈注、屏幕录制、道具遮挡、桌面俯拍都可以比大特效更自然。
- 口播自然度优先于广告腔。允许短停顿、让步、反问、轻微自我修正和边界提醒；不要每条都写成“痛点喊话 + 卖点罗列 + 立即购买”。

UGC 的声音可以保留真实环境声，并给关键动作少量拟音：开盒、点击、拖拽、按压、咬下、倒入、翻页、拿起和放下。不要把每个图形卡都配同一种电子提示音；轻微 click、pop、纸张声、手机触感声或真实产品声比合成 notification 更可信。

UGC 创意自检：

- 这个设计是否让观众更相信，而不是只觉得更花？
- 第一秒是否能靠动作、问题、结果或反差停滑？
- 创意是否由真实产品、屏幕、场景、人物身份或服务流程触发？
- 结尾是否回收到产品、方法、观点、适合人群或行动？
- 是否伪造了体验、评论、数据、客户反馈、优惠或专业背书？

## 策略组合方法

UGC 口播必须像真实创作者的内容判断，不像固定表单。生成方案时按下面维度组合，每条只选少量高相关项：

1. 主类型：带货、知识、人设、采访、问答、创始人、服务顾问或 App/SaaS。
2. 受众阶段：陌生停滑、痛点共鸣、比较决策、信任补强、行动转化、老粉互动。
3. 受众洞察：怕踩雷、想省事、想变好、想学习、想被理解、想省钱、想确认适不适合。
4. 主钩子：痛点、结果、反差、提问、动作、经验、误区、反对意见、内幕、挑战或清单。
5. 证明机制：可见动作、前后对照、屏幕流程、细节特写、第三方材料、现场互动、口播拆解或边界说明。
6. 视听节奏：快问快答、自然停顿、B-roll 插切、环境声垫底、关键拟音放大、屏幕提示音或短静默。
7. 收束方式：软 CTA、评论互动、收藏复看、直播间预告、预约咨询、去链接了解、继续看系列。
8. 创意设计：动作开场、评论变脚本、小测试/挑战、同机位前后、屏幕手势联动、图形状态层、B-roll 包袱、道具隐喻、现场阻碍解决、系列固定识别或反广告开场。

不要默认固定为“痛点 -> 产品 -> 卖点 -> CTA”。同一个产品可以根据策略变成多条不同 UGC：

- 痛点解决：具体困扰 -> 旧方法失败 -> 新方法/产品进入 -> 一个证明动作 -> 适合人群。
- 结果前置：先给变化/成品/结论 -> 倒回解释关键动作 -> 承认限制 -> 自然行动。
- 拆误区：指出常见错误 -> 给判断标准 -> 产品/方法作为其中一步 -> 总结可执行建议。
- 体验日记：真实场景开始 -> 过程观察 -> 细节体感 -> 不夸大结论 -> 轻 CTA。
- 对比选择：A 做法和 B 做法并置 -> 关键差异 -> 谁适合/不适合 -> 低压行动。
- 挑战/测试：设定小测试 -> 展示执行 -> 结果或失败边界 -> 下次/链接/直播承接。
- 清单速讲：3 个判断点、3 个避坑、3 个使用场景；必须每点有画面或动作，不做纯口播清单。
- 反对意见回应：先说用户顾虑 -> 给事实或演示 -> 说明边界 -> 让观众自己判断。
- 幕后/来源：为什么做这个、怎么选品、怎么开发、怎么服务；适合创始人、员工和服务顾问。
- 互动续集：引用评论/问题 -> 回答一个具体点 -> 留下下一条的问题，不把所有问题塞进一条。

批量创作时优先做“策略矩阵”，例如同一产品生成 6 条：痛点解决、结果前置、拆误区、对比选择、评论答疑、场景体验。每条的主钩子、人物状态、证明动作和 CTA 都要不同。

## 创意矩阵策略

当用户要多条 UGC、批量脚本、A/B 版本或投放测试时，先做创意矩阵，再写脚本。不要把同一条脚本换几个同义词当作多版本。

基础矩阵：

```text
人群角度 x 场景角度 x 痛点角度 x 证明动作 x CTA
```

维度选择：

- 人群角度：新手、进阶用户、忙碌人群、价格敏感、品质敏感、专业用户、老客、送礼人群、门店附近人群、某职业/身份场景。
- 场景角度：早上/晚上、通勤/办公室/家里/门店/户外/课堂/直播前、第一次使用、复购补货、节日前后、问题发生当下。
- 痛点角度：太麻烦、太贵、怕踩雷、不知道怎么选、不信效果、时间不够、看不懂、旧方法低效、售后担心、隐性焦虑。
- 证明动作：开箱、上身/上脸/上手、前后对比、屏幕操作、现场体验、白板演示、材料特写、流程节点、第三方材料、同伴互动。
- CTA：收藏、评论、关注、看链接、预约、直播间、领资料、私信、试用、复购。

批量生成规则：

- 2 条：同目标下做不同钩子和不同证明动作。
- 3-5 条：固定产品，轮换人群、场景、痛点和 CTA。
- 6-10 条：至少覆盖 2 个视频目标或 2 个主类型；每条必须有唯一的策略标签。
- 10 条以上：先输出矩阵规划和批次优先级，再按批次生成，避免一次性铺满低质量同质稿。

矩阵输出可以使用这组简表：

| 视频 | 主类型 | 视频目标 | 人群角度 | 场景角度 | 痛点/欲望 | 证明动作 | CTA |
|---|---|---|---|---|---|---|---|

矩阵去重检查：

- 连续两条不能使用同一句式开头。
- 同一批次中同一个证明动作最多重复 2 次，除非用户指定统一动作。
- 同一批次 CTA 不能全部相同，除非用户明确是单一投放目标。
- 如果素材只支持一种动作，要改变人群、场景或叙事策略，不伪造新证明。

## 口播与分镜脚本

UGC 必须给出完整可朗读口播。短片直出时，最终口播直接进入参数确认；完整链路默认在分镜脚本中确认。只有用户要求先审文字，或口播包含高风险事实、功效、数据、客户反馈、课程承诺等内容时，才单独输出脚本文件。台词要像真人表达，不像产品说明书或广告播报。

脚本要求：

- 每句都推进信息：痛点、发现、证明、体感、人群、行动。
- 口播使用第一人称或真实观察视角，但不伪造“我亲测”“回购”“朋友追问”等经历，除非用户提供或确认。
- 禁止编造功效、数据、客户反馈、达人身份、真实测评结果和医学/金融/教育保证。
- 避免低质网感套话，如“宝子”“家人们”“无脑冲”“闭眼入”“yyds”，除非用户明确要这种风格。
- 口播进入视频 prompt 时用 `{具体台词}`，只表示人声和口型，不自动生成字幕。

口播分镜必须逐段说明“这句话由什么画面接住”。每个台词短句至少对应一种画面承载：A-roll 表情/手势、B-roll 产品动作、屏幕流程、手部特写、场景互动、问题卡/观点卡、手绘圈注、花字反应或声音重拍。不能连续多句只写“主播继续口播”；连续 A-roll 必须写清景别变化、跳切点、手势、停顿、视线、道具或文字层变化。

## 钩子与口播节奏

每条 UGC 只选一个主钩子，不要同时堆满。

| 钩子 | 适用 | 写法 |
|---|---|---|
| 痛点直击 | 带货、教程、知识引流 | 先说具体困扰，再给产品/方法进入理由 |
| 结果前置 | 测评、开箱、功效型产品 | 先展示使用后状态或结论，再解释为什么 |
| 反差开场 | 低关注品类、年轻化信息流 | 用一句违反预期的话或动作停滑，但后续必须证明 |
| 提问开场 | 问答、粉丝互动、直播预告 | 用用户可能真的会问的问题进入 |
| 场景动作 | 探店、家居、食品、教程 | 开场直接做动作，让画面先抓住注意力 |
| 经验判断 | IP 输出、知识付费、行业观点 | 用专业观察进入，后续给方法或证据 |
| 误区纠正 | 教程、测评、低关注品类 | 先指出常见错误，再给出正确方法或产品进入理由 |
| 反对意见回应 | 高客单、效果存疑、B2B 转化 | 先承认顾虑，再给证据或适用边界 |
| 内幕/幕后 | 创始人、员工、服务、课程、B2B | 从“为什么这样设计/服务/交付”切入，给可信背景 |
| 挑战/测试 | 产品测评、工具效率、家居日用、食品饮品 | 设一个小测试，让画面自己证明 |
| 清单判断 | 知识引流、服务顾问、IP 观点 | 用 2-3 个判断点压缩信息，避免长篇讲课 |

批量视频要轮换钩子类型，不能每条都用相同句式。

中文普通口播约 4-4.8 字/秒，高能带货约 4.5-5 字/秒，舒缓讲解约 3.2-4 字/秒；总字数必须再预留 10%-20% 给换气、动作和镜头停顿。15秒默认控制在约 55-67 字，67 字作为可听正文硬上限；不能用 75 字或理论语速上限作为默认脚本长度。

口播结构：

- 15秒：钩子 1 句，证明 2-3 句，体感/结果 1 句，软 CTA 1 句。
- 30-60秒：钩子，问题拆解，产品/方法进入，2-3 个证明点，适合人群，总结行动。
- 1-3分钟：观点或测评主线先行，分段讲清证据，不每 15秒重启一次短视频节奏。

短片可以有 re-hook：5-7秒处用第二个微钩子防止掉线，例如“但真正有用的是这里”“我一开始也不信这个点”“别急，差别在下一步”。re-hook 必须承接第一钩子，不另开一个主题。

真人感来自重音、断句、轻微垫词和动作配合，不来自拖慢或机械快读。品牌语气可以影响用词和边界，但最终表达必须保留个人观察、停顿、动作和具体场景。

口播执行要点：

- 台词先像人说话，再像广告。可以有短句、转折和轻微自我修正，但不能靠大量“真的”“姐妹们”“绝了”填满信息。
- 第一人称只能用于真实或用户授权的体验；没有授权时，用“我会这样判断”“可以看到”“适合这类场景”替代“我亲测”“我回购”。
- 高能带货可以更快，但每个卖点后必须有画面或动作接住；不要让观众只听见词，看不见证据。
- 知识/IP 类口播要先给判断，再给理由；不要从背景铺垫讲起。
- 直播预告只抛出一个值得进直播间的问题，不要把直播内容在短片里讲完。

## UGC 素材规则

本节只补充 UGC 的素材职责，不自行插入独立资产阶段；是否生成按需人物、产品或音色资产统一服从 `references/production-control.md` 与 `references/asset-generation.md` 的选择门。短片直出缺少人物图时，不得仅因本节自动生成人物标准资产。

- 人物：用户给人物图时锁定身份、妆发、服装和体态；用户明确选择无素材概念方案时，可在短片内部四格创意线或完整链路视觉关键帧中设计符合品类和平台的概念创作者，不用夸张网红脸或同质化数字人脸，也不得描述成真实达人或指定人物。只有完整模式命中人物资产门，或用户明确要求单独人物资产时，才生成并确认人物标准图。
- 产品：产品图是最高优先级参考，锁定包装、logo、SKU、颜色、比例和材质；不得重绘包装或生成假标签。
- 场景：真实生活场景优先，例如桌面、浴室、厨房、客厅、门店、街头、办公室、车内、课程场景。
- 道具：只服务证明动作，不抢产品主体。
- 音频：人声清楚高于 BGM，BGM 只衬托节奏。

批量 UGC 要避免人物撞脸、场景撞型、钩子撞句、证明动作重复。差异来自身份、场景、表达方式、证明动作和镜头组织，不靠随意换衣服。

## 卖点证明链

脚本、资产和分镜必须把卖点拆成可见证据。涉及真实产品、服务结果、课程效果、客户反馈、数据和功效时，只能使用用户提供或已确认的事实。

优先建立这张内部判断表，不一定完整展示给用户：

| 维度 | 问题 | 输出到脚本/分镜 |
|---|---|---|
| Feature | 产品/服务客观有什么 | 包装、材质、功能、流程、服务节点、课程模块、页面状态 |
| Benefit | 观众因此少了什么麻烦或多了什么收益 | 更省事、更清楚、更安心、更快判断、更适合某场景 |
| Visual Proof | 画面怎么证明 | 开箱、试用、对比、前后状态、屏幕录制、现场互动、资料页、手部特写 |
| Trust Boundary | 哪些不能说太满 | 不承诺结果、不伪造体验、不替用户下结论、不暗示普遍效果 |

证明动作按强度排序：

- 强证明：真实产品清晰出现，动作直接展示卖点，例如倒、抹、穿、接、开、扫、点、拖、对比、试用前后。
- 中证明：人物解释配合 B-roll，例如屏幕流程、课程目录、服务流程、门店环境、包装细节。
- 弱证明：只有口播描述，没有画面支持。弱证明只能用于背景信息，不能承载核心卖点。

每条 UGC 至少有一个强证明或中证明。没有足够素材时，先把脚本降级为“概念讲解/品牌演示/使用场景想象”，不要写成真实测评或真实体验。

可信动作清单：

- 产品拿近镜头，停半秒让包装、logo、SKU 或关键结构清楚。
- 手部操作展示关键功能、质地、开合方式、屏幕流程或使用步骤。
- 开箱、闻、试、穿、吃、按、擦、倒、对比、清理、收纳、导出等动作要和卖点一一对应。
- 街采、探店和本地生活场景必须与环境发生互动，例如门头、动线、菜单/服务、体验动作或现场问题。
- 知识口播用白板、电脑、资料页、流程图或案例片段做支撑，不只拍人脸讲道理。
- App/SaaS 口播要让屏幕动作成为证明：输入、生成、筛选、导出、协作或通知至少出现一个。

可信动作必须服务已确认事实。没有用户确认时，不写“临床证明”“销量第一”“三天见效”“客户都说”“全网都在买”等确定声明。

## 平台、场景和人物

用户明确平台时按平台写；用户没说平台时，不要追问平台，除非平台会明显改变事实、比例、语言或交付方式。默认使用“竖屏短视频通用策略”：`9:16`、前 1-3秒有停滑、真人/动作优先、一个核心证明、自然 CTA、默认无字幕。若用户指令明显指向某平台，按下表推断并在参数确认中说明“平台未指定，按 X 语境处理”。

平台推断：

- 强投放、信息流、转化、线索：按信息流广告。
- 小红书、种草、笔记、避坑、真实分享、审美细节：按小红书。
- 抖音、快手、直播、带货、强节奏：按抖音/快手。
- TikTok、美国市场、英文口播、跨境电商：按 TikTok。
- 视频号、私域、熟人、长辈、企业主、社区传播：按视频号。
- Reels、Instagram、海外审美、生活方式：按 Reels。
- Shorts、YouTube、搜索型教程、英文知识：按 YouTube Shorts。

| 平台 | 画面 | 口播 | 节奏 | CTA |
|---|---|---|---|---|
| 抖音/快手 | 开场强停滑，动作先行，近景和 jump cut 多 | 直接、短句、结果前置 | 快，每 2-4秒有变化 | 直播间、链接、评论、收藏 |
| 小红书 | 生活化、自然光、审美细节、真实场景 | 像朋友认真分享，避坑和细节更多 | 中速，可有停顿 | 收藏、评论、看主页、适合的人了解 |
| TikTok | 表情和动作更强，开场更直接，手机感明显 | 英文短句、情绪明确、少铺垫 | 快，前 1秒要有动作或强句 | Shop/link/bio/try it |
| Instagram Reels | 干净生活方式、视觉统一、封面感更强 | 简洁、有审美判断，不要太吵 | 中快，转场顺 | link in bio、save、DM |
| YouTube Shorts | 强第一帧，知识或演示可更清楚 | 标题感、搜索感、教程感更强 | 中快，结构清晰 | subscribe、watch next、description |
| 视频号 | 家庭/熟人/专业可信感，画面稳 | 稳重清楚，少夸张，多解释 | 中速，重点信息稳定 | 咨询、转发、预约、了解详情 |
| 信息流广告 | 痛点、产品、证明、行动都清楚 | 更转化，但不低质叫卖 | 紧凑，视觉锚点频繁 | 点击、领取、预约、试用 |

跨平台通用稿可以保持同一核心脚本，但平台化处理画面、首句、CTA 和节奏。不要为所有平台生成完全相同的口播和分镜。

场景服务“为什么这个人此刻会推荐/讲解”：

- 美妆护肤：浴室、梳妆台、窗边自然光、手背/脸颊试用；避免食品化和医疗夸张。
- 食品饮品：厨房、餐桌、办公室下午茶、户外野餐、便利店；动作重点是开封、倒入、入口反应、分享。
- 3C/家电：桌面、通勤、客厅、厨房、办公场景；动作重点是按键、连接、响应、前后效率。
- 服饰配饰：试衣镜、街头、通勤、约会/运动场景；动作重点是上身、细节、搭配、走动。
- 家居日用：真实家务动线、收纳、清洁、睡眠、家庭场景；动作重点是旧方案到新方案。
- 课程/知识：书桌、白板、电脑、会议室、线上课程界面抽象；动作重点是讲清方法和价值。
- 探店/街采：门店招牌、环境、体验动作、人物反应；必须避免编造店铺事实和优惠。
- App/SaaS/AI 工具：手机或电脑屏幕、桌面工作流、前后任务状态；动作重点是输入、生成、筛选、导出或协作，不让屏幕只做装饰背景。
- 本地服务/咨询：接待、测量、方案沟通、流程节点、材料或工具；动作重点是解释流程和适合人群，不承诺结果。
- B2B/专业服务：会议桌、白板、后台界面、报告片段、流程图；动作重点是降低决策不确定性，不把复杂服务讲成万能解法。
- 母婴/健康/金融/教育敏感品类：只讲已确认事实、流程和适用边界；避免功效保证、收益保证、治疗暗示和焦虑施压。

没有人物参考图时，短片直出只在内部四格创意线和视频 Prompt 中建立“符合目标受众和品类的概念创作者”，不生成独立人物资产，也不把概念角色描述成真实达人或指定人物。只有完整链路命中人物资产门，或用户明确要求单独人物资产时，才生成并确认人物标准图；人物差异来自脸型、年龄感、气质、穿搭、场景、表达方式和动作习惯，不默认具体种族、国籍或受保护特征，也不用面部痣、穿孔、大面积纹身或夸张配饰强行区分人物。

CTA 默认自然收束：

| 目标 | CTA 写法 |
|---|---|
| 带货 | 适合的人可以看看链接、先收藏、直播间会细讲 |
| 知识引流 | 想要清单/模板/课程的可以继续看下一条、预约或领取资料 |
| IP/观点 | 评论区可以聊你的情况，或关注后看系列下一条 |
| 探店/本地生活 | 想去的话先看营业时间、预约方式、交通或注意事项 |
| App/SaaS | 可以先试一个具体功能、预约演示、下载试用或看案例 |
| 直播预告 | 预约直播、直播间见，但时间和福利必须来自用户确认 |

CTA 不要过度叫卖，不要用虚假紧迫感。促销、价格、库存、福利、直播时间和领取条件必须来自用户确认。

## 行业敏感策略

敏感行业要用“事实、流程、适合边界、咨询提醒”替代“保证、恐吓、绝对化、结果承诺”。遇到母婴、医美、健康、金融、教育、本地服务、招聘、法律、保险、减肥、保健品等内容，默认提高事实门槛。

| 行业 | 禁止或谨慎表达 | 替代表达 |
|---|---|---|
| 母婴 | 绝对安全、宝宝一定喜欢、解决发育问题、替代医生建议 | 材质/使用方式来自已确认信息；建议按年龄、说明书和专业建议判断 |
| 医美/美容功效 | 保证变美、几天见效、治疗皮肤病、夸张前后对比 | 展示流程、体验感、适合咨询的问题；效果因人而异，先面诊/咨询 |
| 健康/保健 | 治疗、治愈、降血糖/降血压、替代药物、医学保证 | 日常管理、使用习惯、营养/成分事实；具体健康问题咨询专业人士 |
| 金融/投资 | 保本、高收益、稳赚、内幕、收益承诺 | 风险提示、信息整理、适合了解的指标；不构成投资建议 |
| 教育/升学 | 保证提分、包过、逆袭名校、焦虑施压 | 学习方法、课程结构、适合基础；结果取决于投入和实际情况 |
| 本地服务 | 绝对最低价、百分百满意、马上解决、虚假排队/优惠 | 服务流程、报价影响因素、预约方式、注意事项 |
| 装修/房产 | 保证增值、零甲醛、绝对无坑、虚假案例 | 材料、工艺、流程节点、验收注意、预算边界 |
| 招聘/副业 | 月入保证、轻松赚钱、无门槛暴富 | 岗位要求、学习成本、适合人群、风险和时间投入 |
| 法律/保险 | 保证胜诉、一定理赔、替代专业意见 | 流程科普、材料准备、常见误区；具体情况咨询专业人士 |

替代表达规则：

- 把“保证结果”改成“适合先了解/先咨询/看自己情况/按说明使用”。
- 把“恐惧施压”改成“常见误区/需要确认的信息/提前准备更省心”。
- 把“虚假体验”改成“产品演示/流程说明/使用场景想象”。
- 把“夸张前后对比”改成“同光线、同角度、已确认素材下的真实状态对比”，素材不足时不做前后承诺。
- 把“专家背书”改成“专业讲解者/顾问视角”，除非用户提供真实资质和授权。

敏感行业 CTA 也要降压：优先“先咨询、先了解、预约评估、收藏自查、看说明、问专业人士”，少用“马上冲、闭眼入、不买亏、最后机会”。

## 人设与声音变量

人设要服务信任关系，而不是只换外观。没有用户指定时，按产品和平台选择自然身份：

| 人设 | 适用 | 口播气质 | 画面要点 |
|---|---|---|---|
| 普通消费者 | 大众商品、低客单、生活方式 | 轻松、具体、少术语 | 家里、通勤、桌面、真实使用 |
| 专业讲解者 | 课程、工具、B2B、复杂品类 | 清楚、克制、有判断标准 | 白板、屏幕、资料、步骤 |
| 创始人/员工 | 新品牌、SaaS、服务、品牌故事 | 直接、解释动机、承认取舍 | 办公室、工作台、幕后 |
| 达人推荐 | 美妆、服饰、食品、好物集合 | 有审美、有筛选理由 | 试用、搭配、开箱、合集 |
| 门店/现场体验者 | 探店、本地生活、活动 | 像在现场说话，信息具体 | 招牌、动线、服务、体验动作 |
| 评论区答疑者 | 粉丝互动、直播预告、售前疑问 | 回答感强，先复述问题 | 评论/问题来源可抽象，不伪造真实截图 |

AI 数字人或虚拟出镜要更重视台词自然度：句子短一点、转折明确一点、避免依赖复杂表情和微妙讽刺。真人或真实素材出镜可以保留更多停顿、口误感和临场动作。

## 参考视频与竞品迁移

用户给对标视频、截图、广告库案例或口播参考时，先拆结构再迁移，不能照抄原话、角色、品牌符号、专属创意或未授权画面。

拆解维度：

- Hook：前 1-3秒靠什么停滑，是话术、动作、结果、反差、人物还是场景。
- Product Demo：产品/方法/服务什么时候进入，观众看到的第一个证明是什么。
- Trust：信任来自真人、细节、数据、第三方材料、现场环境、专业判断还是评论互动。
- Value：核心利益是省钱、省时、变美、安心、效率、身份、情绪、社交还是避坑。
- CTA：行动是购买、收藏、预约、评论、直播间、继续看、下载或试用。
- Rhythm：几秒一个信息变化，是否有 jump cut、近景特写、屏幕切入或现场转场。

迁移原则：

- 可迁移：结构路径、节奏密度、证明动作类型、景别组织、CTA 强弱、钩子类型。
- 不迁移：原视频台词、达人身份、真实经历、品牌视觉、专属梗、客户反馈、优惠和数据。
- 如果参考视频靠“真实体验”成立，而当前没有真实体验素材，只能迁移成“产品演示/创作者讲解/概念测评”，不能伪造体验。
- 如果参考视频节奏很强，但当前产品需要解释复杂服务，保留强开场和信息变化，不照搬过快语速。

## 分镜阶段

详细分镜必须让每个镜头都有一个目的：

- 停滑钩子：前 1-3秒给痛点、反差、结果、动作或问题。
- 信任建立：人物自然停顿、眼神回镜、手部操作、真实语气。
- 产品证明：产品清晰出现，手部或场景证明卖点。
- 体验反馈：把功能翻译成“对我有什么好处”。
- 软 CTA：收藏、看看链接、适合的人可以试试、直播间见等自然收束。

UGC 镜头不宜过度复杂。单镜只做一个主动作，运镜以手持微动、轻推、切近景、俯拍或定机位为主。不要在同一镜头堆推拉摇移环绕。

UGC 创意设计不能增加镜头负担。动作开场、小测试、评论变脚本、屏幕手势联动、框架闭环等设计，都要拆进 A-roll、B-roll、屏幕或手部动作里完成；如果一个设计需要复杂调度、大片级美术或不可证实的前后结果，优先降级成真实演示、道具类比或口播观点。

人物出镜 UGC 要优先真实生活感：具体环境、自然光、轻微手持、正常皮肤质感、非完美摆拍、口播前后的呼吸和停顿。产品在镜头中的出现由内容职责决定：B-roll 只传产品或场景参考，人物出镜才传人物参考；产品证明镜头必须让包装、logo、SKU 或关键使用动作足够清楚。

UGC 可以使用多种叙事节点结构，但节点不是正式镜头数量。按类型选择节点后，必须继续展开为满足统一下限且具有独立信息增量的 `SHxxx`：

| 结构 | 适用 | 节点逻辑 |
|---|---|---|
| 4 节点带货 | 15秒带货、开箱、测评 | 停滑 -> 产品进入 -> 证明动作 -> 反馈/CTA |
| 3 段知识 | 15-30秒知识引流 | 误区/问题 -> 方法/判断标准 -> 下一步行动 |
| 问答切入 | 评论答疑、售前疑问 | 问题复述 -> 核心回答 -> 适用边界/行动 |
| 场景跟拍 | 探店、本地生活、家居日用 | 现场入口 -> 体验动作 -> 关键细节 -> 总结建议 |
| 屏幕工作流 | App/SaaS/AI 工具 | 人物设问 -> 屏幕操作 -> 输出结果 -> 人物解释价值 |
| 对比测试 | 测评、服务、工具、家居 | 旧方案/竞品状态 -> 新方案动作 -> 差异特写 -> 判断边界 |
| 创始人解释 | 新品牌、服务、复杂产品 | 为什么做 -> 解决什么 -> 关键证据 -> 邀请了解 |
| 系列 IP | 观点、人设、长期栏目 | 固定开场识别 -> 本期变量 -> 观点兑现 -> 留下互动 |

每条 UGC 至少安排一个可信动作，例如产品靠近镜头、手部操作、开箱、试穿、试吃、探店互动、白板/电脑/资料页支撑。可信动作必须服务已确认事实。

UGC CTA 默认自然收束：带货可说“适合的人可以看看链接/先收藏/直播间会讲”；知识引流可引导继续看、预约或领取资料；IP/观点可引导评论交流；探店可提醒先看营业时间或预约方式。CTA 不要过度叫卖，不要用虚假紧迫感。

详细分镜里要标出“黄金动作”和“特写目标”。黄金动作是 1 秒内能看懂核心价值的动作；特写目标是包装、材质、屏幕结果、服务流程、手部操作或现场细节。没有黄金动作时，脚本要回退重写，不能用更多口播弥补。

## Prompt 编译提醒

编译 UGC 视频 prompt 时，保留口播、动作和镜头的自然导演语言，不写成字段堆叠。

- 人声台词用 `{}`，不自动生成字幕。
- 默认禁止随机字幕、乱码、二维码、水印、平台 UI 和无来源品牌字。
- 产品图、人物图、门店图、屏幕图必须先说明素材职责；产品和人物一致性高于风格迁移。
- 可读品牌名、价格、规格、优惠、课程名或服务承诺必须来自用户确认；视频模型不可靠生成清晰文字时，写成后期文字或不要求模型硬生成。
- 手机感可以来自手持、近景、自然光、轻微构图不完美、呼吸停顿和现场声音；不能通过低清晰度、畸变手指、脏镜头或混乱画面来冒充真实。
- 多条变体要改变钩子、证明动作、人物状态或场景，不只替换同义词。

## 长视频 UGC

知识引流、课程预告、深度测评、完整探店和系列 IP 内容可进入长视频。长视频不是多个短口播拼接：

- 全片先确定一条观点或体验主线。
- 每段只承担一个信息阶段：开题、痛点、方法、证明、案例、总结、行动。
- 每段口播承接上一段，不重复开场招呼和 CTA。
- 同一人物、场景基调、声音和表达节奏保持连续。
- 最终段再做完整总结和行动引导。
