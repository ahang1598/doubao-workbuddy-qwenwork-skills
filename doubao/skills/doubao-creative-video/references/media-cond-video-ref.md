# 带素材视频：创作意图与工具选择

## 适用与职责

实际输入含视频/音频，或用户明确引用上下文已有视频时读取本文件。时长、比例、内容关键词或“修改”动词都不证明素材存在。引用只有在上下文可绑定真实附件/句柄时才能作为实际输入；多素材指向不清时按交互合同澄清。

本文件管理工具及其硬限制，不独占创作流程，不禁止读取类型策略。默认模型、规格及会员说明唯一来自主 SKILL；所有未指定模型的路径都使用 fast。事实、逐字台词和禁用项锁定，普通用户描述允许转写为导演指令。

## 先判断意图

| 意图 | 应做的规划 |
|---|---|
| 参考素材创作新片 | 正常主线、信息事件、分镜、声音与五段式；说明参考内容取什么、剥离什么 |
| 保留原画面的素材剪辑/重组 | 只裁切、拼接或叠字时按生产控制记实际对象、区间与保留项；需要多素材重组时才用 local_edit 排清现有内容的主线与素材职责，再安排源取用区间、成片位置、承接与声音，不另编故事；无需生成的行不编 SEG |
| 参考多素材重新创作/改写 | 按新创作规划，明确保留哪些参考特征、重新生成哪些内容 |
| 局部编辑现有片 | 仅围绕原片和明确修改范围，使用 local_edit；保护未要求变化的内容、剪辑、台词与声音，不擅自重写全片 |

用户说“参考这个广告”不等于“直接编辑原片”。上传 BGM 不会取消创作规划，也不会自动授权删除原有人声或改成音乐 MV。

## 再选工具

先分离字幕、水印后期及保留既有内容的必要技术处理；需要生成或重建内容的部分，先判断创作/编辑意图，再按实际输入选择工具。输入含视频或音频时通常使用 media_to_video；只有恰好一个视频、无其他必需媒体，且意图与次数、规格全部满足下述 video_edit 限制时，才使用 video_edit。单视频参考创作新片仍走 media_to_video。不能只凭“修改”一词选择 edit，也不能丢弃必要输入迁就工具。

| 实际输入与意图 | 工具 |
|---|---|
| 保留既有内容，仅截取、裁剪、重排、拼接、字幕、水印或封装 | 核对生产控制中的 MediaKit 等真实处理能力；不新增或重混声音，不借技术处理改变画面内容与意图；无能力则说明缺口 |
| 只有文字，新创作 | text_to_video |
| 只有图片，新创作 | image_to_video |
| 视频＋图片/音频/其他模态 | media_to_video |
| 多视频互参后生成新片，或单视频参考创作新片 | media_to_video |
| 音频作为输入，无视频，可同时有图片 | media_to_video |
| 明确指定一个视频，仅修改具体主体、人物、物体或场景；本次无其他必需媒体，且满足全部限制 | video_edit |
| 多视频分别独立编辑 | 逐条按 edit 的意图、输入、规格与成功次数判断，每次一个视频；不能合并输入 |

先判断是否需要重新生成画面，再按输入选择生成工具；保留原画面的后期操作优先适用表首行。实际调用前按宿主 schema 核对工具可用性、参数和限制。不能消费的参考只可作为研究资料，不伪装成输入。视频生成/模型编辑每批最多两项，独立视频与长视频生成段均计入；授权与依赖顺序按生产控制执行。

## media_to_video

既有工具契约包含 prompt、input_image_ids、input_video_ids、input_audio_ids、ratio、duration、model_version、output_video_id；实际字段以宿主 schema 为准。图片/视频/音频分开传入，无素材的模态传空数组（schema 需要时）；保留每个模态的实际顺序，不传无关素材。

素材句柄放参数字段，正文使用资产合同规定的自然引用，不泄漏原始资源 ID。每份 Prompt 依据分镜直接撰写，说明各素材锁定/参考/剥离维度；音频可承担 BGM、声音风格、声线或环境参考，不能无依据覆盖全部声音。

时长、比例先沿用用户要求，否则按入口与故事需求给出确定方案，在最终参数中确认；不增加一轮单独时长问卷。命中[交互合同的制作方案选择](interaction-ask-video-clarification-ref.md#制作方案选择)条件时，先选择制作方式及必要的台词取舍；该选择不改变工具路由。超过所选模型单次上限时按生产控制拆段，不静默截断、不自动升级模型。

### 音色参考与音频时长

多个相关或连续视频需要同一说话者时，按[音色合同](asset-generation.md#音色)复用或生成约5秒、1-2句正常语速的样音，逐次实际传入 `media_to_video`；正式台词由各次视频 Prompt 指定，不用样音代替正式配音。新创作已选有人声、且单次生成无需跨视频声线一致时使用视频模型原生人声，不为此额外生成音色。

每次实际输入的所有音频总时长上限为 **15秒**，包含样音、音乐及其他音频；宿主实际限制更严格时遵循宿主。用文件真实时长求和，只传当前段所需音频，超限处理见音色合同。音色参考、配乐参考与固定成片音轨须分别说明职责；不能仅凭“音频输入”承诺克隆或精确同步。长视频本身不决定工具，实际传入样音等音频后才按本文件路由使用 `media_to_video`。

## 多轮编辑与重新生成

结合完整意图和上下文识别目标视频，先处理字幕、水印后期及纯技术操作，再判断生成部分：

- `video_edit` 只处理主体、人物、物体、场景等具体画面内容的替换、删除或修改，保留其余内容。整体调色、风格、转场、运镜、动作、表演节奏或音频变化均走重新生成，不走 edit 或后期混音。原有素材纯技术重排、拼接与其原声衔接仍按生产控制执行，不增加声音内容或改变声音意图。
- 另创故事、仅参考原片创作新视频，也属于重新生成。用户明确要求“重来／再来一版”且无新要求时，沿用上次 edit／重新生成判断，但每次提交前重新核对输入、规格、成功次数与本次授权。单纯评价不触发重做。
- 未要求改变的时长、比例、声音与画面保留项继续有效。空间裁剪、截短时长、改比例、改分辨率、改字幕与改对白分别判断；不能用相似措辞静默更换路径。
- **同一视频任务重新生成时，以第一轮原始素材和生成指令为基础，合并此前已确认且仍有效的修改、本轮新增要求及素材，一并交给 OrganizerAgent 和实际生成工具。不能只传本轮修改，也不能用刚生成的视频替代原始素材。** 用户明确替换的旧要求或素材不再采用；冲突按交互合同澄清，必需原始素材不可访问时先补齐。参考原片另创新视频属于另一创作目标，不借此重置原任务的 edit 次数。
- 没有可执行路径时停止受影响步骤并说明具体限制，不擅自换模型、延长、截短或舍弃要求。所有新生成、生成式编辑与重试均按交互合同取得本批 `interaction.ask` 授权。

### 已有镜头顺序与素材重排

用户只要求调整已有镜头或片段的先后顺序，现有素材足以完成目标且无需新增或重建画面内容时，属于技术重排：按实际正式能力截取、重排或拼接既有素材，保留各取用区间的原画面与原声，不因此调用 video_edit 或重新生成，也不启动视频生成确认；既有技术处理及最终拼接的授权要求保持不变。

需要新增动作、画面、人物关系或承接内容，现有素材不能完成目标时，仅对需新增或重建的内容按本文件选择可执行生成路径，并取得对应生成授权；已有且仍适用的素材保留，不因顺序变化自动重生全片。不能用技术重排冒充缺失动作或连续性，也不能因技术能力不足自动改走生成。内容与音频的其他修改仍按原有规则判断。

## video_edit

以下条件必须全部满足：用户明确指定一条视频，仅替换、删除或修改其中具体主体、人物、物体、场景；不涉及上节禁用目标；本次媒体输入只需该视频；本最终成片任务尚未成功调用过 video_edit；规格与真实工具能力均支持。

### 输入与成功次数

- `input_video_ids` 只传一个视频；本次需要图片、音频或其他视频时重新选择工具，不丢弃素材。历史用过但本次不需引用的图片等不算额外输入。例如图生视频后，仅删除原片中的物体，可以核对首次 edit 条件。
- **同一最终成片任务最多成功调用 1 次 video_edit；用户分别要求的独立视频分别计数。** mainagent 在现有制作记录保留第一轮原始素材、指令与累计成功次数，并随派发传递；OrganizerAgent 逐项回传实际调用结果。片段、修订版本、新输出 ID、更换 OrganizerAgent 或重新确认均不重置计数；不能把同一成片的多个片段各当作一次独立可用次数。
- 成功以工具实际完成视频编辑为准，不以受理、内部回传或卡片交付成功计数。编辑完成但交付失败仍已用掉成功次数，只恢复交付。运行中或结果未明时不重复提交。
- 失败不计成功次数，但再次提交必须重新核对条件并取得本次 `interaction.ask` 生成确认，不自动重试。工具返回异步任务时持续跟进原任务，不能因暂时无结果视为失败。
- 首次 edit 允许使用用户明确指定的刚生成视频；此前文生、图生或其他生成不计入 edit 成功次数。成功 edit 一次后，后续修改不得再次 edit，按上节回溯原始素材并选择其他可执行生成路径；无路径则说明阻塞并停止。

### 原时长与比例

先从宿主真实元数据取得原时长和比例；不足时按既有分工使用正式能力进行必要探测，不猜数据，不启动生成确认。取得真实数据后再完成生成方案和确认。

- 输出保持原时长。原片不足 4 秒时，唯一例外是工具输出设为 4 秒；必须在生成确认前明确展示工具输出与目标成片时长的区别，并核实后续正式截取可恢复用户要求的成片时长；用户未接受所需安排或路径未解决时不提交，不静默补长。
- 原片超过 15 秒不使用该 edit 路径；即使其他模型支持更长生成，也不能借此绕过 edit 的 15 秒限制，不自动升级、截断或拆片规避。
- 输出保持原比例，且原比例须属于主入口六种合法比例并受真实工具支持。用户要求改变时长或比例时，该 edit 路径不支持；先解决可执行方案，不静默裁切、拉伸或更换参数。
- 模型仍遵循主入口 fast 默认与用户明确选择规则。工具真实限制更严格时遵循实际能力，不据此主动切换模型。
- local_edit 母版仅描述原片保留项、修改区间和目标结果；五段式第三部分写清保留／修改指令，不套新广告镜头下限，不擅自添加旁白、BGM、字幕或新故事。

## 执行与交付

素材询问、方案展示与生成确认读取 [交互合同](interaction-ask-video-clarification-ref.md)；阶段与委派读取 [生产控制](production-control.md) 和 [资产合同](asset-generation.md)；最终媒体展示读取 [交付合同](media-delivery.md)。不得原样透传短 brief 绕过当前有效的内容与分镜设计，也不得对逐字台词擅自改写；不因此增加用户分镜确认。

执行使用已确认范围内的准确编辑指令或生成 Prompt 与真实媒体输入，保留实际请求记录；需模型生成/编辑时由 OrganizerAgent 按生产控制执行。OrganizerAgent 先按[交付合同](media-delivery.md)逐项直接交付并说明真实结果，再内部同步原始视频引用和已交付状态，再完成已定后期并展示最终成片，不审片或自动修复；失败不假报成功，不未经授权自动重跑。
