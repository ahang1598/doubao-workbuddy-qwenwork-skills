# 企业商务视频

## 文件说明与索引

本文件只负责企业宣传、企业品牌宣传、企业形象、央国企形象、产业品牌、招商路演、客户案例、B2B 服务、会议活动、ESG、投融资、渠道招商、出海和内部动员的专属策略。参数确认、阶段确认、目录、阶段上屏、工具和成片规则读取 `references/production-control.md`；通用创意方向读取 `references/creative-core.md`；通用视听语言读取 `references/audiovisual-craft.md`；视觉效果、叙事节点和转场同步读取 `references/visual-motion-playbook.md`。

## 适用边界

当主体是企业、组织、园区、项目、产业能力、B2B 解决方案、会议活动、雇主品牌、公益责任、投融资披露或内部组织沟通时，优先使用本策略。即使参考片有电影感、高端广告感、AIGC 视觉、无旁白或消费级审美，只要核心目标是证明企业、组织、项目或商业能力，就不要自动转 TVC。

使用本策略的典型任务：

- 企业传播：企业宣传片、企业形象片、企业文化片、企业品牌宣传片、周年庆、创始人/企业家精神片、内部动员片。
- 商务转化：招商片、路演片、客户案例、客户证言、B2B 服务介绍、渠道招商、加盟招募、采购转化片。
- 产业和组织形象：央国企形象、产业集团、制造企业、能源/基建/交通装备、园区、供应链、物流、平台/SaaS。
- 专项沟通：投融资、IPO、年报、股东沟通、ESG/可持续发展、海外市场/出海品牌、展会循环片、发布会现场片。
- 会议活动：会议开场、峰会预热、年会开场、启动仪式、活动报名转化。

只有核心目标是消费品牌态度、单品商业广告、产品 launch、用户种草转化或用户明确要求 TVC 化商业广告时，才转品牌 TVC 或产品广告。

## 策略使用顺序

命中企业商务视频后，按五层推进：

```text
传播目标层 -> 商务决策证明层 -> 叙事骨架层 -> 创意机制层 -> 视听语法层
```

五层不是五个章节堆料，而是一条决策链：先定传播任务，再定主受众和证明任务，再选叙事骨架，再给每段配置创意机制，最后落实为运镜、布光、构图、色彩、转场、声音、文案、节奏和 CTA。

任何新场景都先拆成 8 个变量，再组合出策略：

```text
传播目标 + 主受众 + 决策阶段 + 企业/组织类型 + 证明主题 + 素材状态 + 分发渠道 + 片长
```

场景配方只是组合案例，不是穷举边界。遇到新场景时，先按核心策略拆解，不要因为没有同名配方就改走 TVC 或通用创意。

## 参数确认重点

参数确认阶段必须讲清：

- 企业身份：公司/品牌、行业、主营业务、发展阶段、地区和目标受众。
- 传播任务：建立认知、建立信任、促成转化、组织动员、信息披露、活动引爆中的哪一种为主。
- 观众判断：观众看完要相信什么，或下一步要做什么。
- 事实边界：哪些来自用户材料，哪些已核实，哪些待确认，哪些不能写成确定声明。
- 证据材料：logo、VI、工厂/办公室/团队/产品/客户/项目/资质/数据/活动信息/采访素材。
- 旁白：企业商务视频默认需要完整旁白，除非用户明确要求无旁白或纯音乐。
- 字幕：默认无字幕；会议标题字、章节大字和展会屏大字不等于逐句字幕。

分镜表节拍默认覆盖：行业/场景、企业身份、能力证明、人物/客户/服务、价值结果、品牌收束。

## 事实底线

企业商务视频不能编造客户、奖项、认证、融资、上市、营收、市场份额、员工规模、工厂规模、专利数量、案例结果、政府合作、头部客户、行业第一、唯一、领先、会议日期、发布信息、招聘福利、薪资、收益、回本周期或投资回报。没有来源或用户确认时，用中性表达替代。

参考片的镜头语言、叙事结构、证明方式和视听规律，要转译成当前企业自己的事实、能力证据和品牌表达。

### 资料核实和来源优先级

只要用户给出公司名、品牌名、官网、项目名、产品名或活动名，就优先使用可用检索能力核实公开信息。搜索目标优先级：

1. 官方网站、官方新闻、官方公众号/社媒、官方招聘页、官方产品页。
2. 权威媒体、工商/证券/监管披露、行业协会、展会/活动官网。
3. 用户提供的链接、文档和图片。
4. 其他第三方内容只作辅助，不能替代官方信息。

如果当前环境没有可用搜索能力，必须说明无法公开核实，并要求用户提供或粘贴企业资料。不能把模型记忆、行业常识或猜测写成已核实事实。

企业商务视频至少确认：

- 公司/品牌全称、行业、主营业务、目标客户、地区和发展阶段。
- 核心产品/服务、优势能力、公开数据、项目案例和可展示成果。
- 宣传主题、主宣传语、CTA、禁用词、必须出现/不得出现的信息。
- logo、品牌色、VI、IP、办公室/工厂/团队/产品/客户/项目素材。
- 旁白语言、声线、语速、语气、是否逐字保留用户文案。

缺失资料可以先给建议稿，但必须标注待用户确认。涉及客户名称、合作成果、资质认证、数字、排名、政策、投资收益、招聘待遇和活动信息时，没有来源就不能写成确定事实。

常用中性替代表达：

| 高风险表达 | 替代表达 |
|---|---|
| 行业第一、唯一领先 | 持续深耕该领域、形成稳定服务能力 |
| 服务头部客户 | 服务多个业务场景或行业客户，客户名称待确认 |
| 专利/认证/奖项众多 | 以用户提供或公开材料为准，画面先呈现研发/质检流程 |
| 年增长/收益保证 | 展示业务逻辑、服务流程和公开可核实数据，不承诺结果 |
| 政府合作/重大项目 | 如无材料，改为“参与区域/产业相关项目沟通或服务场景” |
| 招聘高薪/快速晋升 | 改为“提供成长路径、团队协作和岗位实践场景” |

### 旁白和文案策略

企业商务视频默认需要完整旁白，除非用户明确要求无旁白、纯音乐或展会静音循环屏。旁白不是口号堆叠，每句都要落到企业身份、能力证据、业务价值或行动收束。

常用旁白结构：

```text
行业/场景问题 -> 企业定位 -> 能力证据 -> 服务/产品价值 -> 人物/客户结果 -> 品牌收束
```

旁白写法：

- 不只写一句 slogan，也不用“乘风破浪”“砥砺前行”“赋能未来”堆满全片，除非用户明确要求这种语气。
- 有事实声明时标注来源或待确认状态；不能把愿景、行业常识和猜测写成事实。
- 有客户案例时确认客户名称、logo、成果数据和授权范围；未授权时做匿名行业场景。
- 长视频先写全片旁白逻辑，再按片段分配。中间段不要重复最终口号，最终段再承担完整品牌收束。
- 会议开场和年会片可以更有情绪，但仍要让每句旁白能对应画面动作或组织事实。

## 1. 传播目标层

企业商务视频必须先选一个主目标，再配置次目标。不要把认知、招商、招聘、投融资、年会和 ESG 全部塞进同一条主片。

| 传播目标 | 核心任务 | 视频写法 |
|---|---|---|
| 企业/品牌认知 | 让观众记住这是一家什么企业，代表什么能力或价值 | 企业身份早出现，行业场景先行，结尾回到清晰品牌主张 |
| 信任建立 | 让观众相信企业可靠、专业、可交付 | 少抽象形容，多真实流程、现场、团队、资质、案例和客户证据 |
| 商务转化 | 让观众咨询、采购、入驻、加盟、报名或预约 | 受众痛点前置，方案和收益路径清楚，结尾给明确行动入口 |
| 组织动员 | 让员工、伙伴或参会者形成共同方向感 | 用历史、人物、关键项目和未来任务建立情绪递进 |
| 信息披露 | 面向股东、投资人、监管、公众解释经营逻辑 | 事实、数据、治理、风险意识优先，语气克制，避免夸张承诺 |
| 活动引爆 | 给会议、展会、发布会、峰会制造现场气氛 | 主题字、节拍、倒计时、现场空间和观众反应比完整企业史更重要 |

目标选择规则：

- 只有一个主目标。主目标决定片头、证明密度、旁白语气和结尾 CTA。
- 次目标最多两个。比如“品牌认知 + 招商转化”可以共存，但不能同时又讲招聘、ESG、投融资和周年史。
- 官网主片可以更完整；销售拜访版要更直接；会议大屏要更有节奏；展会循环屏要静音可读；信息流切条要 3 秒内给判断。
- 企业商务视频默认不是单品种草片。即使画面高级、电影化或广告感强，策略中心仍是企业、组织、项目、产业能力或商务信任。

## 2. 商务决策证明层

企业商务不是证明产品好不好吃、妆效好不好看，而是证明组织能力、交付能力、合作价值和风险可控。

| 主受众 | 观众真正关心 | 优先证据 |
|---|---|---|
| B2B 采购方/企业客户 | 能否稳定交付，质量是否可靠，售后是否跟得上 | 产线、质检、认证、交付流程、服务网络、客户案例 |
| 招商客户/入驻企业 | 能否降本、增效、拿资源、获得增长 | 区位、空间参数、产业配套、政策边界、入驻流程、已入驻生态 |
| 政府/园区领导 | 是否带动产业、就业、治理、公共价值和区域协同 | 产业定位、重大项目、公共服务、生态治理、区域协作、社会价值 |
| 投资人/股东 | 增长逻辑是否成立，治理是否清楚，风险是否可控 | 商业模式、公开数据、客户结构、管理团队、合规和风控体系 |
| 渠道商/加盟商 | 能不能卖，能不能运营，总部支不支持，回报是否可信 | 品牌声量、产品矩阵、培训体系、供应链、门店/渠道支持、政策说明 |
| 求职者/员工 | 值不值得加入，能否成长，有没有组织认同 | 真实工作场景、团队协作、成长路径、文化行动、员工故事 |
| 公众/终端消费者 | 企业是否可信、有温度、和我有关 | 使用场景、人物关系、社会责任、品牌资产、真实服务触点 |
| 海外客户/合作伙伴 | 是否符合国际标准，能否跨区域交付和本地响应 | 国际认证、海外项目、本地团队、多语言服务、物流与售后网络 |

证据强度从高到低：

```text
已核实数据/资质/公开事实 > 授权客户/案例/项目 > 真实流程/质检/交付 > 真实设备/团队/空间 > 人物情绪/现场氛围 > 抽象视觉/空镜/光效
```

关键判断必须有高强度证据支撑。比如“可靠交付”不能只靠厂房空镜和旁白形容；情绪画面只能放大已经成立的证据，不能替代证据。

常见证明主题：

| 证明主题 | 可见证据 | 适合场景 |
|---|---|---|
| 规模与区位 | 航拍、园区、地图、楼宇、交通节点、空间参数 | 园区、总部、地产、物流、平台招商 |
| 研发与技术 | 实验室、工程师、测试、原型、专利文件、研发流程 | 制造、AI/SaaS、医疗教育、硬科技 |
| 制造与工艺 | 原料、设备、工序、产线、手工细节、车间管理 | 工厂、家居、酒饮、茶、装备制造 |
| 质量与可靠 | 检测、抽检、追溯、认证、故障测试、售后闭环 | B2B 采购、供应链、设备、医疗教育 |
| 服务与交付 | 咨询、部署、培训、客服、维修、项目复盘 | SaaS、B2B 服务、渠道、出海 |
| 市场与客户 | 客户场景、案例片段、行业覆盖、复购、口碑 | 客户案例、路演、品牌升级 |
| 历史与传承 | 老照片、旧设备、里程碑、创始人、员工记忆 | 周年、企业文化、老字号、工艺品牌 |
| 数字化与平台 | UI、看板、流程自动化、数据链路、协作场景 | SaaS/AI、平台、物流、园区运营 |
| 治理与责任 | 制度、环保设施、员工安全、公益行动、披露口径 | ESG、央国企、上市公司、公共议题 |
| 出海与本地化 | 海外项目、外语界面、认证、海外仓、本地团队 | 外贸制造、跨境服务、国际展会 |

## 商务证明发动机

企业商务视频的核心不是“企业很强”，而是让某一类决策者相信一个可行动判断。先把企业优势翻译成决策者关心的证明事件，再进入叙事和画面。

内部推导：

```text
主受众：谁在看
决策问题：他担心什么、需要相信什么
企业能力：用户材料中真正能证明什么
证据事件：哪个流程/项目/动作能让能力可见
风险边界：哪些数据、客户、资质、承诺不能编
行动收束：咨询、入驻、采购、报名、加入、了解更多中的一个
```

示例：

| 企业说法 | 弱表达 | 商务证明事件 |
|---|---|---|
| 我们很专业 | 实验室空镜 + 口号 | 一个样品从测试、复核到出具结果的完整路径 |
| 我们交付稳定 | 厂房航拍 + 员工工作 | 订单节点从设计、排产、质检、出库到售后闭环连续点亮 |
| 我们有生态 | 园区大景 + 政策旁白 | 一个企业从入驻、配套、协同到业务落地的路线被可视化 |
| 我们数字化 | 数据光效 + 大屏 | 一条真实任务从现场设备进入系统，再回到业务人员决策 |
| 我们适合加入 | 团队微笑 + 福利口号 | 新员工一天的协作、学习、反馈和成长路径 |

## 企业商务片的证明叙事

企业商务片不是“介绍我们是谁”，而是改变某一类观众的商业判断。开写前先形成一句内部判断句：

```text
这条片让 [主受众] 相信：[企业/组织/项目] 能在 [具体业务场景] 中做到 [一个可信结果]，
因为他们看见了 [一个可追踪的证据事件]，
最后愿意 [咨询/采购/入驻/报名/加入/认同/继续了解]。
```

如果这句话只能写成“让大家觉得我们很厉害、很专业、很有温度”，说明核心还没成立；继续追问“厉害在哪里、谁需要相信、看见什么才会信、信了以后做什么”。

### 企业传播专项映射

不同企业片不是换标题，而是换观众判断、证明事件和收束方式。

| 场景 | 要改写的观众判断 | 主线索/证据事件 | 节奏与收束 |
|---|---|---|---|
| 企业宣传片/形象片 | 这家公司是否可信、清楚、值得合作 | 一条代表业务从需求到结果的路径 | 身份早出，中段用流程和案例证明，结尾回到主能力判断 |
| 企业文化片 | 价值观是否真实发生在组织里 | 一次协作任务、一个员工选择或一个长期习惯 | 少口号，多行动；从个人细节升到组织方法 |
| 招聘/雇主品牌 | 我能否成长、被支持、做有价值的事 | 一个新人、岗位任务或项目日的一天 | 人物早出现，真实任务推进，尾段给加入理由 |
| 周年庆/年度片 | 过去如何走到今天，下一步去哪 | 旧物、老照片、旧设备或里程碑穿过过去与现在 | 今昔同机位/同动作匹配，最后落到未来任务 |
| 创始人/企业家精神 | 企业为什么做出这些选择 | 一个关键取舍、一次长期坚持或一个创业原点 | 个人经历只作入口，必须回到组织方法和企业价值 |
| 员工故事 | 价值观如何落到岗位动作 | 一个岗位任务从开始到完成 | 人物行动证明组织，不把员工写成口号复读者 |
| 用户/客户故事 | 企业价值是否改变真实业务场景 | 客户问题从提出、选择、实施到结果 | 先讲客户困境，再讲企业介入，最后讲变化和合作理由 |
| ESG/公益责任 | 责任是否是持续行动，不是一次作秀 | 一个议题从发现、记录、处理到回访 | 制度和人共同回应，结尾给持续承诺或可追踪行动 |
| 会议/发布会/活动预热 | 为什么值得来、值得看、值得参与 | 主题从幕后搭建到台前点亮 | 倒计时、聚场、主题显影，尾帧给时间/地点/参与方式 |

### 主线索选择器

企业片最容易散，因为能力太多。每条片只选一个主线索带路，其它能力作为这个线索经过的节点出现。

| 主线索 | 适合证明 | 推进方式 |
|---|---|---|
| 一张订单/一份需求单 | 交付、协同、响应速度 | 客户提出 -> 方案确认 -> 排产/部署 -> 质检/上线 -> 反馈 |
| 一个样品/一个原型 | 研发、工艺、质量 | 设计 -> 测试 -> 报警/问题 -> 复核调整 -> 通过 |
| 一块工牌/一张门禁卡 | 员工成长、组织文化、岗位一天 | 进入空间 -> 接到任务 -> 协作 -> 汇报/交付 -> 成长收束 |
| 一条任务卡/工单 | 数字化、服务闭环、运营效率 | 现场问题 -> 系统生成 -> 多角色接力 -> 状态归位 -> 结果可见 |
| 一份图纸/一张蓝图 | 工程、制造、园区建设、空间规划 | 图纸线条 -> 结构显影 -> 真实空间 -> 使用场景 |
| 一通客户电话/一条消息 | 服务、售后、B2B 信任 | 问题进入 -> 诊断 -> 解决 -> 回访 -> 客户继续使用 |
| 一个包裹/一辆货车 | 供应链、物流、出海、本地响应 | 出库 -> 分拣 -> 运输 -> 到达 -> 场景应用 |
| 一本旧档案/一张老照片 | 周年、传承、品牌升级 | 翻开过去 -> 同动作切到今天 -> 能力升级 -> 未来主题 |
| 一个园区沙盘/会议桌模型 | 招商、产业生态、区域协同 | 模型点亮 -> 交通/配套/企业节点展开 -> 入驻路径 |
| 一块真实屏幕/UI | SaaS、平台、AI、数据治理 | 业务动作进入系统 -> 状态变化 -> 决策输出 -> 回到现场 |

没有真实物件时，可以用“概念主线索”，例如光线、路线、主题字、流程线或一枚点亮的节点，但它必须一直服务同一个证明，不要变成随机动效。

### 证据戏剧化

证据不是摆出来，而是推进出来。把“参观式罗列”改成“一个证据事件正在发生”，观众才知道重点在哪里。

```text
弱：研发中心 + 产线 + 质检 + 团队 + 客户
强：一个样品进入测试 -> 报警灯亮起 -> 工程师复核参数 -> 产线按新方案运行 -> 质检绿灯 -> 客户场景稳定使用
```

| 抽象说法 | 可见的组织动作 |
|---|---|
| 创新 | 第 7 版方案、原型迭代、测试曲线变化、工程师在同一问题上复核 |
| 可靠 | 质检复查、故障单闭环、交付节点亮起、设备在压力测试中稳定运行 |
| 协同 | 多部门围绕同一任务卡接力，设计、生产、运营、服务都推动同一结果 |
| 责任 | 现场记录、安全检查、环保设施运行、社区/客户回访、整改闭环 |
| 成长 | 新人旁听、被指导、参与协作、独立汇报或完成一个小交付 |
| 国际化 | 多语言界面、海外仓/本地团队响应、认证文件、跨时区服务节点 |
| 数字化 | 现场问题进入系统，状态变化可见，结果回到业务人员决策 |
| 生态 | 单个企业节点点亮，上下游、服务配套和公共资源围绕它形成路径 |

### 系统显形的一拍

企业片也需要“反常识的一拍”，但不是无关奇观，而是让观众平时看不见的组织系统突然可见。这个瞬间要轻、准、可回收：它打破正常世界一下，然后马上回到事实证据。

| 要证明的能力 | 轻改写画面 | 回收证据 |
|---|---|---|
| 交付响应 | 客户需求化成一条发光任务线，穿过设计、排产、质检和物流节点 | 回到真实工单、产线节点或交付场景 |
| 组织成长 | 工牌刷开一天路线，会议室、工位、项目现场依次亮起 | 回到岗位任务、导师反馈或团队协作 |
| 园区生态 | 桌面沙盘展开成楼宇、交通、配套和企业节点的立体网络 | 回到真实区位、空间参数和入驻路径 |
| 数字化运营 | 现场杂乱信息被系统提示音整理成任务卡和状态看板 | 回到真实 UI、设备屏或业务看板 |
| 周年传承 | 老照片里的人、设备或街景与今天同机位重叠 | 回到真实档案、今日现场和未来主题 |
| ESG/公益 | 一个现场问题进入制度流程，处理、复查、回访节点依次亮起 | 回到行动过程、记录材料或持续承诺 |
| 客户价值 | 客户的难题像一团线被流程节点逐步理顺 | 回到方案实施、服务人员和结果场景 |

系统显形只能显形已确认或概念化的结构。数据、地点、客户、政策、资质和结果没有来源时，不写成真实事实。

### 企业节奏模型

企业片节奏不能一味宏大，也不能全程平铺。主节奏由主目标决定：

| 类型 | 节奏写法 |
|---|---|
| 信任型 | 稳定开场，证据密度逐步增加，关键节点给停留，结尾稳住品牌判断 |
| 商务转化/招商型 | 问题前置，路径清楚，利益和政策边界克制表达，CTA 明确 |
| 招聘型 | 人物早出现，任务带着观众走，成长转折要具体，结尾给加入理由 |
| 周年/年度型 | 旧物或旧影像开场，今昔匹配切换，中段人物/项目升温，尾段面向未来 |
| 会议/发布会型 | 倒计时起势，主题字显影，空间聚场，音乐递进，最后定版关键信息 |
| ESG/公益型 | 具体问题进入，行动过程可见，受益关系清楚，结尾承诺持续而不夸张 |
| 客户案例型 | 客户困境先成立，企业方案介入，实施过程有阻力，结果回到客户判断 |

### 企业收束策略

企业商务片的结尾不是只出现 logo，而是形成一个商业判断：

```text
我们是谁 + 已证明什么 + 下一步是什么
```

| 场景 | 收束方式 |
|---|---|
| 企业宣传片 | 企业名/品牌名 + 主能力判断 + 品牌主张 |
| 招商/园区 | 适合谁入驻/合作 + 已展示的配套价值 + 咨询/预约入口 |
| 招聘 | 岗位/团队/组织气质 + 一个具体加入理由 + 招聘行动 |
| 周年庆 | 年度主题 + 已走过的关键变化 + 下一阶段任务 |
| ESG/公益 | 已行动的议题 + 可持续机制 + 长期承诺 |
| 客户案例 | 客户问题已如何解决 + 合作价值 + 继续沟通入口 |
| 会议/活动 | 主题 + 时间地点/预约/报名/参会方式 |

## 证据事件选择器

先按上方证明叙事锁定商业判断和主线索，再选择证据事件。每条企业商务视频至少要有一个“证据事件”。证据事件是观众能复述的组织能力画面，例如“那个片子里一张订单从客户需求一路走到交付现场”。它比抽象航拍、会议镜头和光效更重要。

| 传播任务 | 优先证据事件 | 辅助画面 |
|---|---|---|
| 企业认知 | 一个代表性业务场景从问题到结果 | 总部、团队、品牌墙、行业场景 |
| B2B 获客 | 客户任务从提出到交付闭环 | 产线、质检、项目会、售后 |
| 招商/园区 | 企业入驻路径或产业链上下游连接 | 区位、空间、配套、地图 |
| 路演/投融资 | 商业模式中一笔业务如何成立 | 团队、产品、公开数据、治理 |
| 招聘/雇主品牌 | 一个人如何在组织里完成成长任务 | 办公环境、同事协作、培训 |
| ESG/公益责任 | 一个具体议题如何被制度和行动回应 | 设施、社区、员工、安全流程 |
| 会议/展会 | 主题如何从倒计时走到现场共同动作 | 舞台、人群、主题字、嘉宾信息 |
| 出海 | 一个海外客户/项目如何被本地化服务 | 认证、物流、外语界面、当地团队 |

证据事件的写法：

```text
起点：[客户/员工/项目/订单/设备/议题/活动]
过程：[3-5 个真实或待确认节点]
关键证明：[最能说明能力的一步]
结果：[交付、完成、入驻、上线、协作、报名、行动]
回收：[企业名称/主张/CTA]
```

企业商务也可以有创意，但创意要让证据更清楚：

- 地图网络只能展示已确认地区或概念覆盖，不写假节点。
- UI 和数据卡必须来自真实素材或概念化，不能生成乱码后台。
- 微观奇观要连接到宏观能力，例如材料细节拉开到产线和应用。
- 品牌实体化、空间折叠、光线显影可以用于开场和收束，但中段必须回到证据事件。

## 3. 叙事骨架层

企业商务视频先选一个主骨架，再按片长删减。骨架是逻辑，不是场景清单。

| 叙事骨架 | 推进方式 | 适合任务 |
|---|---|---|
| 总分总能力片 | 企业定位 -> 能力模块 -> 价值收束 | 企业形象、集团介绍、产业品牌 |
| 问题到解决 | 行业痛点 -> 企业方案 -> 落地过程 -> 结果变化 | SaaS、B2B 服务、园区运营、供应链 |
| 能力到信任 | 身份 -> 证据 -> 流程/团队 -> 合作理由 | 制造实力、客户拜访、采购转化 |
| 时间到未来 | 过去积累 -> 今日能力 -> 人物/项目 -> 未来方向 | 周年片、品牌升级、企业文化 |
| 战略到项目 | 宏观主题 -> 战略关键词 -> 真实项目 -> 社会/行业价值 | 央国企、能源基建、政府汇报 |
| 场景包裹产品 | 真实工作/生活场景 -> 功能介入 -> 人或业务结果 | 平台、SaaS、家居空间、医疗教育 |
| 数据披露 | 事实基线 -> 经营逻辑 -> 风险意识 -> 长期价值 | 年报、IPO、投融资、股东沟通 |
| 责任体系 | 议题 -> 制度 -> 行动 -> 数据/案例 -> 透明承诺 | ESG、公益责任、可持续发展 |
| 人物驱动 | 人物选择 -> 行动细节 -> 组织方法 -> 企业价值 | 创始人、员工故事、客户证言 |
| 源头到品牌 | 原料/源头 -> 工艺/供应链 -> 产品价值 -> 品牌记忆 | 酒饮、茶、家居、工艺制造 |
| 微观到宏观 | 材料/部件/工艺 -> 产线 -> 应用场景 -> 行业价值 | 装备制造、半导体、精密加工 |
| 事件引爆 | 主题 -> 氛围 -> 关键信息 -> 行动/标识收束 | 会议开场、展会、发布会、活动预热 |
| 无旁白感知（仅用户已明确要求无人声时） | 环境 -> 手部/材料 -> 流程 -> 短字卡 -> 品牌定版 | 工艺、空间、茶酒、艺术化企业片 |

混合需求 先判定主目标，再把其它目标变成段落或切条。比如周年 + 招商以“时间到未来”为主，招商证据放在“今日能力/未来布局”段，不把全片变成回忆录；展会 + 销售转化以“事件引爆”为主，销售拜访版另做深证据。

## 4. 创意机制层

企业商务的创意机制必须服务证明链，不能只做漂亮空镜。

| 创意机制 | 创意逻辑 | 适用段落 |
|---|---|---|
| 真实流程链 | 把订单、设计、生产、质检、交付、服务串成可见链路 | 制造、供应链、B2B 服务 |
| 数据可视化 | 用地图、计数器、仪表盘、动态图表解释真实事实 | 园区、年报、物流、平台、ESG |
| 战略关键词章节 | 每章一个动词或关键词，并配一个真实项目证明 | 央国企、集团片、品牌升级 |
| 新旧对比 | 老照片/旧设备/旧空间与当下能力匹配切换 | 周年、转型、城市更新、工艺传承 |
| 照片资产运动化 | 档案墙、视差、照片翻页、时间轴，让静态资料可叙事 | 历史资料多、现场素材少的项目 |
| 客户证言/采访原声 | 用客户问题、选择理由和结果反馈建立第三方信任 | 客户案例、B2B 转化、服务介绍 |
| 一天时间线 | 用早中晚或一个任务周期展示平台如何持续运作 | SaaS、园区运营、物流、本地服务 |
| UI 嵌入/匹配入屏 | 从真实设备场景进入界面，再回到业务现场 | SaaS、AI、平台、数字化服务 |
| 微观技术奇观 | 用火花、液体、切削、传感器、材质微距吸引注意 | 精密制造、工艺、设备、材料 |
| 供应链溯源 | 从源头、原料、仓储、运输到终端应用建立可信链 | 食品、茶酒、家居、物流、外贸 |
| 地图网络 | 用节点、线路和覆盖区域表现服务范围 | 出海、物流、能源、直营网点 |
| 现场聚场 | 用人群、灯光、倒计时、舞台和主题字制造现场势能 | 会议、展会、年会、发布会 |
| 手部和器物线索 | 用手、工具、材质和动作代替直白说明 | 工艺、茶酒、家居、非遗、匠心片 |
| 品牌实体化 | 把 logo、主题字或版本号变成空间里的真实物体 | 品牌升级、活动预热、峰会主题片 |
| 首尾回扣 | 开场埋问题、物件、动作或视觉母题，结尾升级回答 | 所有企业商务视频 |

执行规则：

- 一条片只选一个主机制，最多搭配两个辅助机制。
- 创意机制必须回答证明任务：这个机制证明了什么，而不只是“好看”。
- 真实 UI、logo、客户名、地图节点、参数和用户要求的字幕必须来自用户材料或后期可控资产；不要让生成模型凭空写字。
- 参考片只迁移方法，客户、数据、资质和品牌资产必须来自当前企业材料。
- 复杂机制要降级到可执行、可剪辑、可复核的镜头。企业商务片宁可稳，也不要用无法控制的乱码文字、虚假屏幕和不可信场景。

企业商务的 B-roll 优先承担证据职责：真实现场、流程节点、设备动作、团队协作、客户使用、屏幕状态、地图网络、数据看板或活动现场。旁白可以继续，但画面必须让观众看见组织能力、服务过程或结果证据。抽象空镜只能用于段落呼吸、空间建立或品牌情绪，不能替代事实证明。

企业商务也要有可复述视觉事件，但视觉事件必须更稳、更可信。不要把企业片写成“航拍园区、员工微笑、数据光效、logo 尾帧”的模板；先确定一个证明主轴，再让视觉事件服务这个主轴：

| 证明主轴 | 可用视觉事件 | 回收方式 |
|---|---|---|
| 从源头到交付 | 原料、设计、生产、质检、物流、服务节点连续传递 | 回到完整产品、客户场景或交付结果 |
| 从混乱到秩序 | 旧流程杂乱，触发系统/团队/服务后任务归位 | 回到看板完成、现场稳定或客户决策理由 |
| 从微观到宏观 | 材料、零件、代码、数据点或工艺细节拉开到系统规模 | 回到企业能力、行业价值或项目全貌 |
| 从实验到应用 | 实验室、测试、研发动作过渡到真实使用场景 | 回到产品落地、服务场景或品牌理念 |
| 从节点到网络 | 单个客户/项目/站点亮起，线路扩展成服务网络 | 回到覆盖范围、区域协同或行动入口 |

每个企业视觉事件都必须有事实边界：数据、客户、地图节点、认证、项目名称和结果数字没有材料时，只能做概念化状态，不冒充真实事实。创意负责让证据更好懂，不负责替代证据。

企业图形系统要可追溯：时间轴、地图、流程线、数据卡、组织结构、客户案例卡和对比板都必须对应用户材料或可确认事实。动效服务状态变化，例如节点亮起、流程闭环、指标归位、区域扩展或项目完成，不用随机科技线条冒充能力。

企业和 B2B 动效默认克制、清楚、可信。数据卡、地图节点、流程线、组织结构、客户案例卡和真实 UI 可以运动，但每次运动都要说明一个事实状态：区域覆盖扩展、流程进入下一环、指标归位、项目完成、客户问题被解决、风险被拦截或服务闭环。不要把线条乱飞、粒子扩散、蓝色 HUD 和玻璃面板当作“数字化能力”的替代证据。

企业片也可以有高能收尾，但必须来自前文证据的集合：已展示过的业务线、产品模块、服务节点、客户价值或品牌资产可以在尾段汇聚成一张“能力合影”；没有在前文建立过的元素不要突然飞入。尾帧前给品牌、主题字或核心数据短暂停留，保证大屏、会议和无声播放都能读清。

## 5. 视听语法层

视听语法用于承载前四层，不单独决定策略。

| 手法 | 用法 |
|---|---|
| 稳定推进 | 企业可信感、空间进入、品牌主张揭示 |
| 横移/跟拍 | 展示流程、产线、团队协作、参观动线 |
| 航拍/俯瞰 | 园区规模、区位、城市关系、工程体量 |
| 低角度仰拍 | 装备、建筑、人物精神和现场仪式感 |
| 微距/滑轨 | 材质、工艺、检测、产品细节 |
| POV/屏幕视角 | SaaS、平台、服务流程、客户使用路径 |
| 快切蒙太奇 | 展会、会议开场、周年高光、能力集合 |

构图优先级：真实主体清楚 > 证据可读 > 空间关系明确 > 氛围高级。不要用过多空镜、背影、剪影和抽象光效冒充企业实力。

企业商务文案按“事实锚点 + 结构推进 + 价值收束”写，不要堆宏大词：

- 从 A 到 B：从一张图纸到一座工厂，从一次咨询到一次交付。
- 一个动词统领章节：深耕、连接、智造、守护、共建、抵达。
- 事实先行，价值后置：先给项目/流程/数据，再说意义。
- 客户视角：客户遇到什么问题，为什么选择我们，变化在哪里。
- 时间量化：十年、一代产品、一个订单周期、一个服务闭环。
- ESG 写法：议题 -> 制度 -> 行动 -> 可核实结果 -> 持续承诺。

禁用倾向：

- 没有依据的“领先、第一、唯一、最大、最强、标杆、头部、国家级、世界级”。
- 只升华不证明的空话，如“以梦为马、奔赴未来、改变世界”，除非前面已有足够事实承托。
- 把招商、招聘、投融资和客户采购都写成同一种“愿景结尾”。

## 场景组合

场景只是五层策略的组合案例，不是边界。没有同名场景时，按“目标、受众、证明、骨架、机制、视听”重新组合。

| 场景 | 推荐组合 |
|---|---|
| 园区/平台招商 | 商务转化 + 招商客户 + 区位/配套/政策/生态证明 + 问题到解决或总分总 |
| 制造实力片 | 信任建立 + 采购方 + 工艺/质检/交付证明 + 微观到宏观或能力到信任 |
| SaaS/AI/平台 | 商务转化 + 企业客户 + 真实任务流/UI/结果证明 + 问题到解决 |
| 周年/企业文化 | 组织动员 + 员工/伙伴/公众 + 历史资料/人物/项目证明 + 时间到未来 |
| ESG/公益责任 | 信息披露 + 政府/公众/投资人 + 制度/行动/数据证明 + 责任体系 |
| 出海/国际化 | 信任建立 + 海外客户 + 标准/认证/本地服务证明 + 能力到信任 |
| 展会循环片 | 现场触达 + 采购方/观众 + 产品/能力/参数证明 + 事件引爆，静音可读 |
| 投融资/年报 | 信息披露 + 投资人/股东 + 公开事实/治理/增长逻辑 + 数据披露 |
| 渠道/加盟 | 商务转化 + 渠道商 + 产品矩阵/培训/供应链/政策证明 + 问题到解决 |
| 招聘/雇主品牌 | 组织转化 + 求职者 + 工作场景/成长/团队证明 + 人物驱动 |
| 会议开场/峰会预热 | 活动引爆 + 参会者 + 主题/议程/嘉宾/时间信息 + 事件引爆 |
| 客户案例/证言 | 信任建立或决策行动 + 采购方 + 问题/选择/实施/结果证明 + 人物驱动 |

## 创意准出自检

提交生成前逐项自检：

- 是否已经明确主传播目标和主受众。
- 是否把观众要相信的判断写成了可证明命题。
- 是否只有一个主线索带路，而不是把部门、业务、年份和口号平均铺陈。
- 关键证据是否来自用户材料、公开事实或明确待确认项。
- 是否存在用抽象空镜、漂亮光效或宏大旁白替代证明的问题。
- 叙事骨架是否单一清楚，没有把多个结构硬拼。
- 创意机制是否服务证明链，而不是只服务风格。
- 系统显形或反常识一拍是否能回收到证据事件，而不是独立炫技。
- 是否有独特叙事钩子、核心证明动作和可记忆视觉母题。
- 结尾是否形成明确商业判断和下一步行动，而不是只出现 logo 或 slogan。
- 是否为混合需求 设定了主目标优先级，而不是平均塞满。
- 片长、渠道和 CTA 是否匹配。
- 客户、数据、认证、奖项、排名、收益、回本周期、政府合作和招聘承诺是否没有被编造。
