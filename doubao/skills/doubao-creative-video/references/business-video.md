# 企业商务：让事实回应具体观众的判断

## 适用边界与读取

用于企业介绍、能力证明、B2B 方案、客户案例、招商、路演、招聘、会议、年度/周年、内部沟通与 ESG。核心是业务、组织或项目事实时，即使画面像广告大片也保留本策略。消费品牌态度用品牌文件，单品营销用产品文件；创始人对观众分享可用 UGC，但实际业务事实仍须有依据。

先读“第一阶段的商务写法”和对应用途，缺复杂流程或客户资料处理时再查后文。来源核实、授权、分镜和执行由[入口职责表](../SKILL.md#入口与规则权威)维护，本文件只决定事实怎样成为内容。

## 第一阶段的商务写法

### 用具体任务补足内容，而非堆企业空镜

用户仅说“介绍企业／平台”时，从现有资料选择与本次受众有关的具体业务对象和环节，按[共同展开规则](creative-core.md#用户说得少时主动展开内容)主动展开。订单、图纸、样件、服务请求或已确认业务记录都可以贯穿：谁接到什么、做了哪项判断、交给谁、状态如何变化、结果支持什么认识。展示不同环节时持续标明同一对象，让岗位、设备和界面各自增加依据，不能只用工厂航拍、员工微笑、握手、发光地图与“赋能未来”占满中段。

例如已有资料确认“接需求—设计—制作—检测—交付”的企业，可跟随同一样件看需求中特定要求、图纸对应部位、实际加工接触点、检测对象与最终交接；缺哪个环节依据就换成已确认内容，不虚构工厂、自动化、认证或结果数字。没有量化收益仍能讲清已确认的做法与交接；不因缺少业绩数据就退回空镜。旁白解释环节为什么与客户任务有关，画面给当前证据；新地点用对象、角色或声音承接，不靠飞线暗示未确认的系统自动联动。

按[第一阶段写法](creative-core.md)从企业资料、观众用途和展示位置选内容，不另发问卷。企业、业务或服务是传播核心，访谈、客户案例、纪实、演示、图形动画与人物剧情均可按内容采用。工作流演示要讲清谁要做什么、原来怎样处理、当前方案具体改变什么、结果怎么看；向业务决策者解释价值，向实际使用者解释工作变化，向技术评估者展示相关能力与接入条件，只取当前任务所需部分。不用“打工人忙、流程乱、信息多”代替实际任务；组织故事、会议开场和主题表达则按各自内容展开，不都改成业务操作课。

| 当前用途 | 内容怎样展开 | 应交付的观看收益 |
|---|---|---|
| 官网/销售演示：主动了解产品怎样处理自己的任务 | 演示一件具体工作。例如申请提交后谁收到、看到什么、怎样处理、申请人从哪里看结果；只使用已确认功能 | 知道当前在哪一步、谁来处理、下一步怎么做。界面显示状态，人声解释意思；关键核对可以重复，不必把每个按钮都念一遍 |
| 信息流获客：尚未意识到该了解这套方案 | 从一个可辨识的工作卡点或错误判断进入，尽早说明是什么方案，再给足以支持进一步了解的过程证据 | 识别与自己相关的问题和解决路径；不把完整操作培训挤进广告，也不只喊“高效协同” |
| 客户案例/能力证明：需要判断能否胜任 | 用真实资料说清原任务、限制、做法和结果。关键取舍要有原因；没有案例依据就不编成功故事 | 观众知道在哪些条件下做成了什么、资料支持到哪里；微笑和无来源的百分比不能当结果 |
| 招聘/组织传播：关心怎样工作、为何参与 | 用岗位的具体任务、团队如何作决定或共同完成什么来表达组织特点 | 从行动理解工作与组织，不把产品功能稿换成员工主语 |
| 展会循环：可能从中途开始，远距离或静音观看 | 按声画条件组织可独立理解的能力片段，需要时重复主体识别与关键词 | 中途进入仍认得主体和本段能力，不依赖看过片头；静音展屏不靠完整旁白传递关键意思 |
| 会议开场：观众已在现场，需要进入共同主题 | 用本次主题、真实业务/人物内容与声音动作聚拢注意，结尾衔接现场环节 | 知道为何相聚、接下来关注什么，不重复售票预告的报名话术，也不把灯光高潮当全部内容 |

招商/路演、周年/年度、内部动员与责任传播的用途差异查下文[企业传播专项映射](#企业传播专项映射)，不统一改成产品功能演示；映射提供取材方向，实际资料与本次目的决定结构。

业务演示让观众跟着同一件工作走：人声说清当前角色为什么这样处理，画面让人看到输入、关键动作与状态变化；屏幕细节看不清时换局部，不把完整界面缩成背景。可以先给结果再回到过程，但要交代如何得到；申请退回也可展示原因与下一步，不必都演成功成交。并置旧、新做法时要让观众分得清：图形可以说明对象关系，不能用飞线、无缝变形或省略操作，暗示未提供的自动识别、导入、同步或处理能力。提示音只确认真实操作，不能用一声“叮”代替交接、处理或结果依据。

能力片先从真实资料找本项目值得讲的难题：具体处理什么对象，限制在哪里，哪项选择改变了结果，证据能支持到哪一步。“发现问题、调整、复核、通过”只是流程骨架，行业、对象、做法与依据都未落实时，不能当作已完成剧本。资料不足就明确这是待资料支持的概念结构，或改用已知事实组织可成立的内容，不虚构成功案例。再把规模和难度变成可看的关系：同一个任务怎样跨岗位交接，某项真实限制怎样影响决定，一个细节怎样影响整体结果。镜头可由局部工作打开到实际系统，或并列展示有依据的协作，再回到同一任务的结果；不把无人机厂区、会议握手和数据飞线当作默认大片。资料不足以展示的流程和规模不虚构，片中情绪由真实取舍与结果支撑。

客户案例从真正参与的人讲起：他当时负责什么、哪项限制影响任务、为何采用这个做法、过程发生什么变化。采用原资料中的具体表达和可核实结果，工作画面支撑相应叙述；不能用会议、握手与微笑垫满全部证言。资料只有第三人称说明时就用解说，不擅自改成客户逐字采访，也不把配乐高潮当作成功证明。

商务内容的吸引力不只来自流程走通，也来自让原先难看清的关系变得可见：一条意见究竟对应哪个对象，一项限制为什么影响后续决定，一个岗位的判断怎样改变共同任务。选择与本业务相关、资料支持的一处展开，不能把所有项目都拍成“输入、点击、成功”。角色对话可以直接暴露当前疑问，图形可整理复杂关系，镜头可跟随同一对象穿过真实环节；其余内容围绕这处关键认识接续。面向决策者时把变化接回工作价值，面向使用者时把必要步骤交代清，不把两种内容全部堆进短片。回到同一页面或场景须有推进，功能限制不自动变成片尾清单。

客户案例的当事人、具体问题、行动与依据，参考 [Wistia 的证言视频策略](https://wistia.com/blog/creating-a-video-testimonial-strategy)。[B2B Marketing Skills 的 demo-storyline](https://github.com/adam-lagerhausen/b2b-marketing-skills/blob/main/skills/demo-storyline/SKILL.md)可参考按买方角色组织同一业务任务、让产品操作对应实际价值；其现场提问和销售停顿不照搬到短视频。[customer-story-engine](https://github.com/adam-lagerhausen/b2b-marketing-skills/blob/main/skills/customer-story-engine/SKILL.md)可参考从旧做法、改变与真实结果提炼案例。参考案例不能当成本企业的客户、成果或承诺；并非所有商务片都需要客户证言、成功故事或 CTA。

声音与结束方式也随用途变化：业务演示让讲解与屏幕状态同步，关键操作保留可辨反馈；客户故事保住原话与必要停顿；招聘用岗位动作、协作对话和具体选择体现团队；会议开场以主题和声音段落接现场，展屏循环则让每个模块的主体与意思独立可读。音乐可以建立规模和共同感，不能盖过证据或把普通流程宣布成胜利。下文传播目标、商务证明、叙事骨架、创意机制和视听语法是查询资源，按缺口查，不逐层再策划一遍。事实核实读下一节，声音/节奏、方案字段和确认沿用分镜、交互和生产合同。

## 事实底线

企业商务视频不能编造客户、奖项、认证、融资、上市、营收、市场份额、员工规模、工厂规模、专利数量、案例结果、政府合作、头部客户、行业第一、唯一、领先、会议日期、发布信息、招聘福利、薪资、收益、回本周期或投资回报。没有来源或用户确认时省略具体声明，或明确写成概念演示；把“领先”换成“稳定专业”也不能使无依据事实成立。

参考片的镜头语言、叙事结构、证明方式和视听规律，要转译成当前企业自己的事实、能力证据和品牌表达。

### 资料核实和来源优先级

先读取本轮及历史已采用的企业材料与用户锁定项，区分已支持的事实、待核实声明和创作要求。只有名称或零散资料、关键公开事实缺依据、信息有时效性或来源互相冲突时，主动用可用检索能力补核；已有材料足以支持本片且无上述缺口时，不为出现了公司名再完整搜一遍。创意参考是否研究仍按第一阶段写法判断，与事实补核分开。

需要外部核实时，公开来源按下列顺序查：

1. 官方网站、官方新闻、官方公众号/社媒、官方招聘页、官方产品页，以及用户提供的对应官方链接。
2. 权威媒体、工商/证券/监管披露、行业协会、展会/活动官网。
3. 其他第三方内容只作辅助，不能替代相关官方信息。

用户材料中的当前产品版本、内部流程和明确创作要求不因排在搜索列表之外就被旧网页覆盖；公开来源也不能仅凭用户确认便改写为相反事实。冲突时核对对象、日期、版本与适用范围，无法解决的声明不写成确定事实；澄清只按交互合同，不另开资料问卷。

无可用搜索能力时，不声称完成公开核实；已有用户材料足够就继续，未核实部分省略或明确写成概念设定。确实缺少支撑关键内容的必需事实时，说明具体缺口；素材询问仍按交互合同，不因没有搜索工具自动增加一轮索材。不能把模型记忆、行业常识或猜测写成已核实事实。

企业资料核实重点如下；缺项按事实锁处理，不逐项向用户发问：

- 公司/品牌全称、行业、主营业务、目标客户、地区和发展阶段。
- 核心产品/服务、优势能力、公开数据、项目案例和可展示成果。
- 宣传主题、主宣传语、CTA、禁用词、必须出现/不得出现的信息。
- logo、品牌色、VI、IP、办公室/工厂/团队/产品/客户/项目素材。
- 旁白语言、声线、语速、语气、是否逐字保留用户文案。

缺失资料可以先给建议稿，但必须标注待用户确认。涉及客户名称、合作成果、资质认证、数字、排名、政策、投资收益、招聘待遇和活动信息时，没有来源就不能写成确定事实。

缺少依据时的改写方向；表内替代事实同样需要已有材料支持，不直接抄成承诺：

| 高风险表达 | 替代表达 |
|---|---|
| 行业第一、唯一领先 | 改讲已确认的具体业务和操作，不保留排名暗示 |
| 服务头部客户 | 有可用案例才讲案例；否则明确做概念场景，不暗示已有客户 |
| 专利/认证/奖项众多 | 有研发/质检材料才展示相应过程，不用实验室画面暗示认证 |
| 年增长/收益保证 | 展示业务逻辑、服务流程和公开可核实数据，不承诺结果 |
| 政府合作/重大项目 | 无依据就删除合作声明，不换成模糊的“参与相关项目” |
| 招聘高薪/快速晋升 | 只写已确认的工作、协作或培养安排，不补待遇与成长保证 |

### 旁白和文案策略

人声采用按分镜合同执行。需要旁白时，围绕本次用途把内容连续讲通：能力片解释业务判断与依据，招聘讲具体工作和取舍，回顾讲真实变化，会议内容发展共同主题。企业身份、能力证据、业务价值和行动引导不是每条片的台词必填项，不把人物原话与岗位细节全改成公司介绍。

当前业务状态、角色和下一步要有明确指向，不能用“因此赋能协同”等泛句跳过关键交接。下列结构只适合需要完整交代定位与能力的介绍片；演示、答疑、客户案例与会议片按第一阶段用途取材，不强塞全部环节：

```text
行业/场景问题 -> 企业定位 -> 能力证据 -> 服务/产品价值 -> 人物/客户结果 -> 品牌收束
```

旁白写法：

- 不只写一句 slogan，也不用“乘风破浪”“砥砺前行”“赋能未来”堆满全片，除非用户明确要求这种语气。
- 有事实声明时标注来源或待确认状态；不能把愿景、行业常识和猜测写成事实。
- 有客户案例时确认客户名称、logo、成果数据和授权范围；未授权时做匿名行业场景。
- 长视频先写全片旁白逻辑，再按片段分配。中间段不要重复最终口号，最终段再承担完整品牌收束。
- 会议开场和年会片可以更有情绪，但仍要让每句旁白能对应画面动作或组织事实。

## 1. 传播目标层

企业商务视频必须先选一个主目标，再配置次目标。不要把认知、招商、招聘、投融资、年会和 ESG 全部塞进同一条主片。

| 传播目标 | 核心任务 | 视频写法 |
|---|---|---|
| 企业/品牌认知 | 让观众记住这是一家什么企业，代表什么能力或价值 | 企业身份早出现，行业场景先行，结尾回到清晰品牌主张 |
| 信任建立 | 让观众相信企业可靠、专业、可交付 | 少抽象形容，多真实流程、现场、团队、资质、案例和客户证据 |
| 商务转化 | 让观众咨询、采购、入驻、加盟、报名或预约 | 受众痛点前置，方案和收益路径清楚，结尾给明确行动入口 |
| 组织动员 | 让员工、伙伴或参会者形成共同方向感 | 用历史、人物、关键项目和未来任务建立情绪递进 |
| 信息披露 | 面向股东、投资人、监管、公众解释经营逻辑 | 事实、数据、治理、风险意识优先，语气克制，避免夸张承诺 |
| 活动引爆 | 给会议、展会、发布会、峰会制造现场气氛 | 主题字、节拍、倒计时、现场空间和观众反应比完整企业史更重要 |

目标选择规则：

- 只有一个主目标。主目标决定片头、证明密度、旁白语气和结尾 CTA。
- 按本次用途分清主次；相关次目标可以保留，不能为凑完整企业介绍并列无关任务。用户必讲项不因目标数量被删。
- 官网主片可以更完整；销售拜访版要更直接；会议大屏要更有节奏；展会循环屏要静音可读；信息流切条要 3 秒内给判断。
- 企业商务视频默认不是单品种草片。即使画面高级、电影化或广告感强，策略中心仍是企业、组织、项目、产业能力或商务信任。

## 2. 商务决策证明层

企业商务不是证明产品好不好吃、妆效好不好看，而是证明组织能力、交付能力、合作价值和风险可控。

| 主受众 | 观众真正关心 | 优先证据 |
|---|---|---|
| B2B 采购方/企业客户 | 能否稳定交付，质量是否可靠，售后是否跟得上 | 产线、质检、认证、交付流程、服务网络、客户案例 |
| 招商客户/入驻企业 | 能否降本、增效、拿资源、获得增长 | 区位、空间参数、产业配套、政策边界、入驻流程、已入驻生态 |
| 政府/园区领导 | 是否带动产业、就业、治理、公共价值和区域协同 | 产业定位、重大项目、公共服务、生态治理、区域协作、社会价值 |
| 投资人/股东 | 增长逻辑是否成立，治理是否清楚，风险是否可控 | 商业模式、公开数据、客户结构、管理团队、合规和风控体系 |
| 渠道商/加盟商 | 能不能卖，能不能运营，总部支不支持，回报是否可信 | 品牌声量、产品矩阵、培训体系、供应链、门店/渠道支持、政策说明 |
| 求职者/员工 | 值不值得加入，能否成长，有没有组织认同 | 真实工作场景、团队协作、成长路径、文化行动、员工故事 |
| 公众/终端消费者 | 企业是否可信、有温度、和我有关 | 使用场景、人物关系、社会责任、品牌资产、真实服务触点 |
| 海外客户/合作伙伴 | 是否符合国际标准，能否跨区域交付和本地响应 | 国际认证、海外项目、本地团队、多语言服务、物流与售后网络 |

证据按当前判断匹配，不作通用高低排序。交付能力看相关项目、交接和结果；工作文化看真实行为与员工原话；规模、资质与经营指标需要对应资料。相关性、条件、来源与能支持的结论比材料形式更重要。下文按受众和证明任务选择。

关键判断必须有高强度证据支撑。比如“可靠交付”不能只靠厂房空镜和旁白形容；情绪画面只能放大已经成立的证据，不能替代证据。

常见证明主题：

| 证明主题 | 可见证据 | 适合场景 |
|---|---|---|
| 规模与区位 | 航拍、园区、地图、楼宇、交通节点、空间参数 | 园区、总部、地产、物流、平台招商 |
| 研发与技术 | 实验室、工程师、测试、原型、专利文件、研发流程 | 制造、AI/SaaS、医疗教育、硬科技 |
| 制造与工艺 | 原料、设备、工序、产线、手工细节、车间管理 | 工厂、家居、酒饮、茶、装备制造 |
| 质量与可靠 | 检测、抽检、追溯、认证、故障测试、售后闭环 | B2B 采购、供应链、设备、医疗教育 |
| 服务与交付 | 咨询、部署、培训、客服、维修、项目复盘 | SaaS、B2B 服务、渠道、出海 |
| 市场与客户 | 客户场景、案例片段、行业覆盖、复购、口碑 | 客户案例、路演、品牌升级 |
| 历史与传承 | 老照片、旧设备、里程碑、创始人、员工记忆 | 周年、企业文化、老字号、工艺品牌 |
| 数字化与平台 | UI、看板、流程自动化、数据链路、协作场景 | SaaS/AI、平台、物流、园区运营 |
| 治理与责任 | 制度、环保设施、员工安全、公益行动、披露口径 | ESG、央国企、上市公司、公共议题 |
| 出海与本地化 | 海外项目、外语界面、认证、海外仓、本地团队 | 外贸制造、跨境服务、国际展会 |

## 业务能力怎样成为可看的内容

企业商务视频的核心不是“企业很强”，而是让某一类决策者相信一个可行动判断。先把企业优势翻译成决策者关心的证明事件，再进入叙事和画面。

内部推导：

```text
主受众：谁在看
决策问题：他担心什么、需要相信什么
企业能力：用户材料中真正能证明什么
证据事件：哪个流程/项目/动作能让能力可见
风险边界：哪些数据、客户、资质、承诺不能编
行动收束：咨询、入驻、采购、报名、加入、了解更多中的一个
```

示例：

| 企业说法 | 弱表达 | 商务证明事件 |
|---|---|---|
| 我们很专业 | 实验室空镜 + 口号 | 一个样品从测试、复核到出具结果的完整路径 |
| 我们交付稳定 | 厂房航拍 + 员工工作 | 订单节点从设计、排产、质检、出库到售后闭环连续点亮 |
| 我们有生态 | 园区大景 + 政策旁白 | 一个企业从入驻、配套、协同到业务落地的路线被可视化 |
| 我们数字化 | 数据光效 + 大屏 | 一条真实任务从现场设备进入系统，再回到业务人员决策 |
| 我们适合加入 | 团队微笑 + 福利口号 | 新员工一天的协作、学习、反馈和成长路径 |

## 企业商务片的证明叙事

能力证明与商务转化需要改变具体观众的业务判断，可以用下句检查事实与目标是否接得上；组织沟通、周年纪念与会议开场按各自任务展开，不另填此句：

```text
这条片让 [主受众] 相信：[企业/组织/项目] 能在 [具体业务场景] 中做到 [一个可信结果]，
因为他们看见了 [一个可追踪的证据事件]，
最后愿意 [咨询/采购/入驻/报名/加入/认同/继续了解]。
```

采用此句时，若只能写成“让大家觉得我们很厉害、很专业、很有温度”，就继续落实具体能力、观众与依据；这不是所有企业视频通用的剧情模板。

### 企业传播专项映射

不同企业片不是换标题，而是换观众判断、证明事件和收束方式。

| 场景 | 要改写的观众判断 | 主线索/证据事件 | 节奏与收束 |
|---|---|---|---|
| 企业宣传片/形象片 | 这家公司是否可信、清楚、值得合作 | 一条代表业务从需求到结果的路径 | 身份早出，中段用流程和案例证明，结尾回到主能力判断 |
| 企业文化片 | 价值观是否真实发生在组织里 | 一次协作任务、一个员工选择或一个长期习惯 | 少口号，多行动；从个人细节升到组织方法 |
| 招聘/雇主品牌 | 这份工作、工作方式与团队是否适合我 | 岗位任务、协作方式、实际挑战与支持；员工自述须有来源 | 招聘广告给足职位与申请信息；雇主形象表达可侧重工作体验。不虚构福利或让每位员工都夸公司，不固定拍新人一天 |
| 招商/加盟/路演 | 合作怎样发生、我承担什么、资料能支持什么判断 | 已知业务机制、合作角色、资源条件与有依据的结果；取本次评估所需部分 | 以可理解的合作判断收束，行动信息按用途安排，不把市场规模直接写成个人回报 |
| 周年庆/年度片 | 过去发生了什么重要变化，为何与当前有关 | 从真实记录选择能说明同一主题的事件、行动与结果 | 按变化组织而非逐年报数；周年可表达共同记忆，年度成果要让结果有依据，不强制都落到宏大未来 |
| 内部动员/战略沟通 | 变化为何发生、与自己的工作有什么关系 | 已确认的变化、原因、角色责任与下一步 | 把共同方向接到具体行动，不能只有外宣口号或擅自许诺政策 |
| 创始人/企业家精神 | 企业为什么做出这些选择 | 一个关键取舍、一次长期坚持或一个创业原点 | 个人经历只作入口，必须回到组织方法和企业价值 |
| 员工故事 | 价值观如何落到岗位动作 | 一个岗位任务从开始到完成 | 人物行动证明组织，不把员工写成口号复读者 |
| 用户/客户故事 | 企业价值是否改变真实业务场景 | 客户问题从提出、选择、实施到结果 | 先讲客户困境，再讲企业介入，最后讲变化和合作理由 |
| ESG/公益责任 | 企业实际做了什么，影响与边界是什么 | 有依据的行动、参与者、范围与结果；保留当事人的能动性 | 区分已完成、持续开展与计划，指标有口径；不替企业新造承诺，不以感动替代事实 |
| 活动预热/报名 | 为什么值得来、值得看、值得参与 | 实际主题、内容、嘉宾或参与体验；未公开信息按边界处理 | 逐步形成期待并交付必要参与信息，不只倒计时或拍舞台搭建；会议开场与循环展屏按第一阶段各自用途展开 |

### 主线索选择器

需要贯穿复杂流程时，可用一个主线索带路，其它能力成为相关节点。企业定位、主题开场、招聘或回顾也可由论述、多人观察或主题章节组织，不强制让订单、工牌或光线穿过全片。

| 主线索 | 适合证明 | 推进方式 |
|---|---|---|
| 一张订单/一份需求单 | 交付、协同、响应速度 | 客户提出 -> 方案确认 -> 排产/部署 -> 质检/上线 -> 反馈 |
| 一个样品/一个原型 | 研发、工艺、质量 | 设计 -> 测试 -> 报警/问题 -> 复核调整 -> 通过 |
| 一块工牌/一张门禁卡 | 员工成长、组织文化、岗位一天 | 进入空间 -> 接到任务 -> 协作 -> 汇报/交付 -> 成长收束 |
| 一条任务卡/工单 | 数字化、服务闭环、运营效率 | 现场问题 -> 系统生成 -> 多角色接力 -> 状态归位 -> 结果可见 |
| 一份图纸/一张蓝图 | 工程、制造、园区建设、空间规划 | 图纸线条 -> 结构显影 -> 真实空间 -> 使用场景 |
| 一通客户电话/一条消息 | 服务、售后、B2B 信任 | 问题进入 -> 诊断 -> 解决 -> 回访 -> 客户继续使用 |
| 一个包裹/一辆货车 | 供应链、物流、出海、本地响应 | 出库 -> 分拣 -> 运输 -> 到达 -> 场景应用 |
| 一本旧档案/一张老照片 | 周年、传承、品牌升级 | 翻开过去 -> 同动作切到今天 -> 能力升级 -> 未来主题 |
| 一个园区沙盘/会议桌模型 | 招商、产业生态、区域协同 | 模型点亮 -> 交通/配套/企业节点展开 -> 入驻路径 |
| 一块真实屏幕/UI | SaaS、平台、AI、数据治理 | 业务动作进入系统 -> 状态变化 -> 决策输出 -> 回到现场 |

没有真实物件时，可以用“概念主线索”，例如光线、路线、主题字、流程线或一枚点亮的节点，但它必须一直服务同一个证明，不要变成随机动效。

### 证据戏剧化

证据不是摆出来，而是推进出来。把“参观式罗列”改成“一个证据事件正在发生”，观众才知道重点在哪里。

```text
弱：研发中心 + 产线 + 质检 + 团队 + 客户
强：一个样品进入测试 -> 报警灯亮起 -> 工程师复核参数 -> 产线按新方案运行 -> 质检绿灯 -> 客户场景稳定使用
```

| 抽象说法 | 可见的组织动作 |
|---|---|
| 创新 | 第 7 版方案、原型迭代、测试曲线变化、工程师在同一问题上复核 |
| 可靠 | 质检复查、故障单闭环、交付节点亮起、设备在压力测试中稳定运行 |
| 协同 | 多部门围绕同一任务卡接力，设计、生产、运营、服务都推动同一结果 |
| 责任 | 现场记录、安全检查、环保设施运行、社区/客户回访、整改闭环 |
| 成长 | 新人旁听、被指导、参与协作、独立汇报或完成一个小交付 |
| 国际化 | 多语言界面、海外仓/本地团队响应、认证文件、跨时区服务节点 |
| 数字化 | 现场问题进入系统，状态变化可见，结果回到业务人员决策 |
| 生态 | 单个企业节点点亮，上下游、服务配套和公共资源围绕它形成路径 |

### 系统显形的一拍

当组织关系难以直接看见时，可用下面的视觉解释方法。它是表达选择，不是每条企业片必备的反常识瞬间；真实工作中的精确细节、清楚的论述与有分量的原声同样能形成看点。

| 要证明的能力 | 轻改写画面 | 回收证据 |
|---|---|---|
| 交付响应 | 客户需求化成一条发光任务线，穿过设计、排产、质检和物流节点 | 回到真实工单、产线节点或交付场景 |
| 组织成长 | 工牌刷开一天路线，会议室、工位、项目现场依次亮起 | 回到岗位任务、导师反馈或团队协作 |
| 园区生态 | 桌面沙盘展开成楼宇、交通、配套和企业节点的立体网络 | 回到真实区位、空间参数和入驻路径 |
| 数字化运营 | 现场杂乱信息被系统提示音整理成任务卡和状态看板 | 回到真实 UI、设备屏或业务看板 |
| 周年传承 | 老照片里的人、设备或街景与今天同机位重叠 | 回到真实档案、今日现场和未来主题 |
| ESG/公益 | 一个现场问题进入制度流程，处理、复查、回访节点依次亮起 | 回到行动过程、记录材料或持续承诺 |
| 客户价值 | 客户的难题像一团线被流程节点逐步理顺 | 回到方案实施、服务人员和结果场景 |

系统显形只能显形已确认或概念化的结构。数据、地点、客户、政策、资质和结果没有来源时，不写成真实事实。

### 企业节奏模型

企业片节奏不能一味宏大，也不能全程平铺。主节奏由主目标决定：

| 类型 | 节奏写法 |
|---|---|
| 信任型 | 尽早给与观众有关的具体能力或事实，中段展开关键做法与依据，结果看清即收，不用稳定开场代指慢铺垫 |
| 商务转化/招商型 | 问题前置，路径清楚，利益和政策边界克制表达，CTA 明确 |
| 招聘型 | 从岗位任务、工作取舍或团队协作形成加入判断；不强制新人一天或成长反转，申请信息按用途呈现 |
| 周年/年度型 | 用已发生的关键变化说明走到了哪里，可按主题而非年份排列；没有未来任务资料就不新造承诺 |
| 会议/发布会型 | 用当前主题与真实人物/业务内容聚拢注意，声音和图形形成段落，最后接现场环节；不固定倒计时与粒子汇聚 |
| ESG/公益型 | 具体问题进入，行动过程可见，受益关系清楚，结尾承诺持续而不夸张 |
| 客户案例型 | 围绕客户的实际任务、限制、选择与变化组织证据；不编阻力或胜利，结论回到有来源的客户判断 |

### 企业收束策略

按当前用途选择结束：销售片形成合作判断，招聘片完成加入判断，回顾片完成主题，会议开场接现场。下面只供商务转化参考，不要求每片都说三项或给 CTA：

```text
我们是谁 + 已证明什么 + 下一步是什么
```

| 场景 | 收束方式 |
|---|---|
| 企业宣传片 | 企业名/品牌名 + 主能力判断 + 品牌主张 |
| 招商/园区 | 适合谁入驻/合作 + 已展示的配套价值 + 咨询/预约入口 |
| 招聘 | 岗位/团队/组织气质 + 一个具体加入理由 + 招聘行动 |
| 周年庆 | 年度主题 + 已走过的关键变化 + 下一阶段任务 |
| ESG/公益 | 实际行动与已发生的影响；持续机制或下一步只用已有依据 |
| 客户案例 | 客户问题已如何解决 + 合作价值 + 继续沟通入口 |
| 会议/活动 | 主题 + 时间地点/预约/报名/参会方式 |

## 证据事件选择器

需要观众相信组织能力或业务结果时，沿用第一阶段判断选择证据事件，例如“一张订单从客户需求走到交付现场”，而非用航拍、会议和光效代替依据。会议开场、组织情绪和主题表达可以由具体人物、主题变化或节奏承载，不强制插入业务交付闭环；提出事实主张时仍须有依据。

| 传播任务 | 优先证据事件 | 辅助画面 |
|---|---|---|
| 企业认知 | 一个代表性业务场景从问题到结果 | 总部、团队、品牌墙、行业场景 |
| B2B 获客 | 客户任务从提出到交付闭环 | 产线、质检、项目会、售后 |
| 招商/园区 | 企业入驻路径或产业链上下游连接 | 区位、空间、配套、地图 |
| 路演/投融资 | 商业模式中一笔业务如何成立 | 团队、产品、公开数据、治理 |
| 招聘/雇主品牌 | 一个人如何在组织里完成成长任务 | 办公环境、同事协作、培训 |
| ESG/公益责任 | 一个具体议题如何被制度和行动回应 | 设施、社区、员工、安全流程 |
| 会议/展会 | 主题如何从倒计时走到现场共同动作 | 舞台、人群、主题字、嘉宾信息 |
| 出海 | 一个海外客户/项目如何被本地化服务 | 认证、物流、外语界面、当地团队 |

证据事件的写法：

```text
起点：[客户/员工/项目/订单/设备/议题/活动]
过程：[当前任务需要的真实节点；未确认处标明，不用虚构补齐]
关键证明：[最能说明能力的一步]
结果：[交付、完成、入驻、上线、协作、报名、行动]
回收：[企业名称/主张/CTA]
```

企业商务也可以有创意，但创意要让证据更清楚：

- 地图网络只能展示已确认地区或概念覆盖，不写假节点。
- UI 和数据卡必须来自真实素材或概念化，不能生成乱码后台。
- 微观奇观要连接到宏观能力，例如材料细节拉开到产线和应用。
- 品牌实体化、空间折叠、光线显影可以用于开场和收束，但中段继续发展本次品牌、业务、组织或现场任务所需的具体内容；采用能力主张时给相应依据。

## 3. 叙事骨架层

企业商务视频先选一个主骨架，再按片长删减。骨架是逻辑，不是场景清单。

| 叙事骨架 | 推进方式 | 适合任务 |
|---|---|---|
| 总分总能力片 | 企业定位 -> 能力模块 -> 价值收束 | 企业形象、集团介绍、产业品牌 |
| 问题到解决 | 行业痛点 -> 企业方案 -> 落地过程 -> 结果变化 | SaaS、B2B 服务、园区运营、供应链 |
| 能力到信任 | 身份 -> 证据 -> 流程/团队 -> 合作理由 | 制造实力、客户拜访、采购转化 |
| 时间到未来 | 过去积累 -> 今日能力 -> 人物/项目 -> 未来方向 | 周年片、品牌升级、企业文化 |
| 战略到项目 | 宏观主题 -> 战略关键词 -> 真实项目 -> 社会/行业价值 | 央国企、能源基建、政府汇报 |
| 场景包裹产品 | 真实工作/生活场景 -> 功能介入 -> 人或业务结果 | 平台、SaaS、家居空间、医疗教育 |
| 数据披露 | 事实基线 -> 经营逻辑 -> 风险意识 -> 长期价值 | 年报、IPO、投融资、股东沟通 |
| 责任体系 | 议题 -> 制度 -> 行动 -> 数据/案例 -> 透明承诺 | ESG、公益责任、可持续发展 |
| 人物驱动 | 人物选择 -> 行动细节 -> 组织方法 -> 企业价值 | 创始人、员工故事、客户证言 |
| 源头到品牌 | 原料/源头 -> 工艺/供应链 -> 产品价值 -> 品牌记忆 | 酒饮、茶、家居、工艺制造 |
| 微观到宏观 | 材料/部件/工艺 -> 产线 -> 应用场景 -> 行业价值 | 装备制造、半导体、精密加工 |
| 事件引爆 | 主题 -> 氛围 -> 关键信息 -> 行动/标识收束 | 会议开场、展会、发布会、活动预热 |
| 无旁白感知（仅符合分镜合同的省略条件时） | 环境、手部/材料与流程承接同一观看任务；短字卡、品牌定版按需要采用 | 工艺、空间、原声观察、静音展屏；不能仅因“艺术化”省人声 |

混合需求 先判定主目标，再把其它目标变成段落或切条。比如周年 + 招商以“时间到未来”为主，招商证据放在“今日能力/未来布局”段，不把全片变成回忆录；展会 + 销售转化以“事件引爆”为主，销售拜访版另做深证据。

## 4. 创意机制层

企业商务的创意机制服务当前用途。能力/案例片帮助理解证据；组织、主题开场与回顾片可组织事实、观点和共同体验，不强制改成卖点证明。

| 创意机制 | 创意逻辑 | 适用段落 |
|---|---|---|
| 真实流程链 | 把订单、设计、生产、质检、交付、服务串成可见链路 | 制造、供应链、B2B 服务 |
| 数据可视化 | 用地图、计数器、仪表盘、动态图表解释真实事实 | 园区、年报、物流、平台、ESG |
| 战略关键词章节 | 每章一个动词或关键词，并配一个真实项目证明 | 央国企、集团片、品牌升级 |
| 新旧对比 | 老照片/旧设备/旧空间与当下能力匹配切换 | 周年、转型、城市更新、工艺传承 |
| 照片资产运动化 | 档案墙、视差、照片翻页、时间轴，让静态资料可叙事 | 历史资料多、现场素材少的项目 |
| 客户证言/采访原声 | 用客户问题、选择理由和结果反馈建立第三方信任 | 客户案例、B2B 转化、服务介绍 |
| 一天时间线 | 用早中晚或一个任务周期展示平台如何持续运作 | SaaS、园区运营、物流、本地服务 |
| UI 嵌入/匹配入屏 | 从真实设备场景进入界面，再回到业务现场 | SaaS、AI、平台、数字化服务 |
| 微观技术奇观 | 用火花、液体、切削、传感器、材质微距吸引注意 | 精密制造、工艺、设备、材料 |
| 供应链溯源 | 从源头、原料、仓储、运输到终端应用建立可信链 | 食品、茶酒、家居、物流、外贸 |
| 地图网络 | 用节点、线路和覆盖区域表现服务范围 | 出海、物流、能源、直营网点 |
| 现场聚场 | 用人群、灯光、倒计时、舞台和主题字制造现场势能 | 会议、展会、年会、发布会 |
| 手部和器物线索 | 用手、工具、材质和动作代替直白说明 | 工艺、茶酒、家居、非遗、匠心片 |
| 品牌实体化 | 把 logo、主题字或版本号变成空间里的真实物体 | 品牌升级、活动预热、峰会主题片 |
| 首尾回扣 | 开场埋问题、物件、动作或视觉母题，结尾升级回答 | 所有企业商务视频 |

执行规则：

- 方法围绕同一任务连贯使用，关系清楚即可，不以主/辅机制数量判断质量。
- 说明当前方法让事实、关系、主题或体验怎样更容易理解与记住；能力声明仍须有证据。
- 真实 UI、logo、客户名、地图节点、参数和用户要求的字幕必须来自用户材料或后期可控资产；不要让生成模型凭空写字。
- 参考片只迁移方法，客户、数据、资质和品牌资产必须来自当前企业材料。
- 复杂机制要改写为可执行、可剪辑、可复核的镜头。事实、文字和操作保持准确，不等于画面保守或节奏放慢；不要用乱码文字、虚假屏幕和不可信场景冒充创意。

企业商务的 B-roll 按当前用途选择。能力和案例片用真实现场、流程、设备、客户使用与屏幕状态支持声明；招聘片让人看清工作关系；回顾片组织已发生的事实；会议开场可用图形、动作和声音发展主题。旁白跨镜继续时，画面应补充正在说的内容，而不是逐词配图库。抽象画面可以承担主题表达和空间建立，但不能被当作经营数据、能力或结果的证据。

需要视觉解释时，可用真实动作、对照或组织关系形成可复述的画面，不要求每条都有异常视觉事件。不要把企业片写成“航拍园区、员工微笑、数据光效、logo 尾帧”的模板；以下只供能力证明查询：

| 证明主轴 | 可用视觉事件 | 回收方式 |
|---|---|---|
| 从源头到交付 | 原料、设计、生产、质检、物流、服务节点连续传递 | 回到完整产品、客户场景或交付结果 |
| 从混乱到秩序 | 旧流程杂乱，触发系统/团队/服务后任务归位 | 回到看板完成、现场稳定或客户决策理由 |
| 从微观到宏观 | 材料、零件、代码、数据点或工艺细节拉开到系统规模 | 回到企业能力、行业价值或项目全貌 |
| 从实验到应用 | 实验室、测试、研发动作过渡到真实使用场景 | 回到产品落地、服务场景或品牌理念 |
| 从节点到网络 | 单个客户/项目/站点亮起，线路扩展成服务网络 | 回到覆盖范围、区域协同或行动入口 |

每个企业视觉事件都必须有事实边界：数据、客户、地图节点、认证、项目名称和结果数字没有材料时，只能做概念化状态，不冒充真实事实。创意负责让证据更好懂，不负责替代证据。

企业图形系统要可追溯：时间轴、地图、流程线、数据卡、组织结构、客户案例卡和对比板都必须对应用户材料或可确认事实。动效服务状态变化，例如节点亮起、流程闭环、指标归位、区域扩展或项目完成，不用随机科技线条冒充能力。

数据、UI 和业务流程解释的动效先保证关系清楚、内容可信：数据卡、地图节点、流程线、组织结构、案例卡的变化应对应实际事实或操作。会议主题与组织表达可以采用更大胆的图形、色彩、构图和音乐组织，不必伪装成仪表盘。线条、粒子、蓝色 HUD 和玻璃面板都不能替代“数字化能力”的证据。

企业片也可以有高能收尾，但必须来自前文证据的集合：已展示过的业务线、产品模块、服务节点、客户价值或品牌资产可以在尾段汇聚成一张“能力合影”；没有在前文建立过的元素不要突然飞入。尾帧前给品牌、主题字或核心数据短暂停留，保证大屏、会议和无声播放都能读清。

## 5. 视听语法层

视听语法用于承载前四层，不单独决定策略。

| 手法 | 用法 |
|---|---|
| 稳定推进 | 企业可信感、空间进入、品牌主张揭示 |
| 横移/跟拍 | 展示流程、产线、团队协作、参观动线 |
| 航拍/俯瞰 | 园区规模、区位、城市关系、工程体量 |
| 低角度仰拍 | 装备、建筑、人物精神和现场仪式感 |
| 微距/滑轨 | 材质、工艺、检测、产品细节 |
| POV/屏幕视角 | SaaS、平台、服务流程、客户使用路径 |
| 快切蒙太奇 | 展会、会议开场、周年高光、能力集合 |

构图优先级：真实主体清楚 > 证据可读 > 空间关系明确 > 氛围高级。不要用过多空镜、背影、剪影和抽象光效冒充企业实力。

企业商务文案按“事实锚点 + 结构推进 + 价值收束”写，不要堆宏大词：

- 从 A 到 B：从一张图纸到一座工厂，从一次咨询到一次交付。
- 一个动词统领章节：深耕、连接、智造、守护、共建、抵达。
- 事实先行，价值后置：先给项目/流程/数据，再说意义。
- 客户视角：客户遇到什么问题，为什么选择我们，变化在哪里。
- 时间量化：十年、一代产品、一个订单周期、一个服务闭环。
- ESG 写法：议题 -> 制度 -> 行动 -> 可核实结果 -> 持续承诺。

禁用倾向：

- 没有依据的“领先、第一、唯一、最大、最强、标杆、头部、国家级、世界级”。
- 只升华不证明的空话，如“以梦为马、奔赴未来、改变世界”，除非前面已有足够事实承托。
- 把招商、招聘、投融资和客户采购都写成同一种“愿景结尾”。

## 场景组合

场景只是五层策略的组合案例，不是边界。没有同名场景时，按“目标、受众、证明、骨架、机制、视听”重新组合。

| 场景 | 推荐组合 |
|---|---|
| 园区/平台招商 | 商务转化 + 招商客户 + 区位/配套/政策/生态证明 + 问题到解决或总分总 |
| 制造实力片 | 信任建立 + 采购方 + 工艺/质检/交付证明 + 微观到宏观或能力到信任 |
| SaaS/AI/平台 | 商务转化 + 企业客户 + 真实任务流/UI/结果证明 + 问题到解决 |
| 周年/企业文化 | 组织动员 + 员工/伙伴/公众 + 历史资料/人物/项目证明 + 时间到未来 |
| ESG/公益责任 | 信息披露 + 政府/公众/投资人 + 制度/行动/数据证明 + 责任体系 |
| 出海/国际化 | 信任建立 + 海外客户 + 标准/认证/本地服务证明 + 能力到信任 |
| 展会循环片 | 现场触达 + 采购方/观众 + 产品/能力/参数证明 + 事件引爆，静音可读 |
| 投融资/年报 | 信息披露 + 投资人/股东 + 公开事实/治理/增长逻辑 + 数据披露 |
| 渠道/加盟 | 商务转化 + 渠道商 + 产品矩阵/培训/供应链/政策证明 + 问题到解决 |
| 招聘/雇主品牌 | 组织转化 + 求职者 + 工作场景/成长/团队证明 + 人物驱动 |
| 会议开场/峰会预热 | 活动引爆 + 参会者 + 主题/议程/嘉宾/时间信息 + 事件引爆 |
| 客户案例/证言 | 信任建立或决策行动 + 采购方 + 问题/选择/实施/结果证明 + 人物驱动 |

## B2B 演示怎样避免功能漫游

选一份能贯穿的任务、记录、订单或文件，使观众跟得上同一对象的变化。起点交代角色与目标，重点放在会影响判断的操作和状态；结果可以先出现，再解释必要过程。不预设每次任务都需要先失败。

一个有价值的演示时刻包含实际需要的关系：当前看到什么、据什么判断、接下来怎样处理、这对工作意味着什么。不是每步都念这四句；界面可展示状态，人声补意义。需要跨角色或系统时交代交接，不靠飞线和完成音略过未知的能力。

演示数据与真实客户数据分开。策划中的示例字段可以明确是示意；不得暗示已发生的客户、指标或业绩。真实 UI 只放相关区域，保留必要上下文；不能同时快速翻页、解释新业务又让人读密集小字。真实销售中的停顿与提问不能照搬为预录短片的等待。

## 客户资料怎样成为案例

先分清资料中哪些是已记录事实、当事人原话、推断和缺口。原做法、变化与结果之间有记录才建立联系；不为完整故事补阻力、失败、客户赞美或量化收益。没有结果数字也可以讲清已证实的变化，不编 ROI。

采访素材按问题和原意选段。重新排序后仍须知道代词指谁、结果适用于什么范围、谁在表达判断；一句原话真实不代表剪成的因果真实。待拍访谈写具体提问和可能追问，不替受访者预写肯定证言。来源、授权与事实限制统一按[生产控制](production-control.md#来源与事实锁)。

资料不足以写成功案例时，可以明确做概念方案、只介绍有依据的业务，或指出阻塞当前任务的具体缺口；不把无依据的声明改成更模糊的形容词继续暗示。

## 证据如何支持当前判断

不设“数据一定高于过程、过程一定高于人物”的通用排名。先看材料是否与主张相关、是否真实、范围是否匹配：一份认证不能证明任意交付稳定，规模数据不能证明岗位体验，授权客户的话也不能代表全部客户。

| 要说明什么 | 可用的相关材料 | 必须保留的判断条件 |
|---|---|---|
| 研发、技术、工艺 | 真实取舍、原型、测试方法、工序及相关结果 | 展示的测试支持哪项结论，不能凭实验室镜头暗示认证 |
| 质量、交付、服务 | 质检、追溯、交接、部署、服务记录与客户任务 | 对象、范围、环节关系可跟随；一次完成不能推全局保证 |
| 区位、配套、产业生态 | 已确认地图、空间参数、参与角色、服务与项目 | 地理位置、政策资格和已落实条件准确，不造通勤时间与收益 |
| 数字化、平台、AI | 真实输入输出、业务操作、状态变化与接入条件 | 说明谁操作、谁判断，避免图形暗示未确认的自动化 |
| 组织文化、招聘 | 岗位行动、协作对话、实际支持与员工材料 | 不虚构经历、福利或成长承诺；感受与全公司事实区分 |
| 经营、责任与治理 | 有来源的数据、口径、制度、行动记录与范围 | 区分累计与当期、计划与成果、局部与整体，视觉面积不误导 |

人物、现场、图形、空镜与音乐可以帮助理解和感受，但不能补出材料没有的事实。需要显出复杂关系时，可跟随同一对象、并置相关岗位、由局部工作打开到整体系统，或用清楚图形定位；不强制光线穿过每个部门。
