# 输出契约与准出门槛

## 权威输出

Markdown 清单是默认权威版本。Word、PDF、表格或消息摘要均为派生展示文件；与 Markdown 冲突时，修正权威版本后重新生成。

## 必需结构

输出至少包含以下一级或二级标题：

1. `适用范围与结论`
2. `关键缺口`
3. `分阶段执行清单`
4. `材料总表`
5. `冲突与待确认项`
6. `来源台账`
7. `Tool 与数据授权状态`
8. `隐私与使用限制`

每个结构化事项前写稳定标记：`<!-- item:事项ID -->`。事项至少显示状态、要求类型、适用对象、动作、完成证据、失败备选和来源。

## 表达规则

- 使用 `[已确认]`、`[用户提供]`、`[待确认]`、`[不适用]` 四种状态，不创造近义状态。
- “必须、禁止、截止、金额、地点”只能用于已有匹配证据的内容。
- 无匹配的当年官方来源时，只能列“待核验字段/问题”和官方获取路径；禁止用“可提前准备”“通常需携带”“建议带上”输出具体材料。
- 冲突信息并列展示，注明发布主体、日期、适用对象和确认路径。
- 所有来源使用稳定编号；公开网页附直接链接，文件附文件名/页码或截图标签。
- 每个具体材料、金额、日期、地点和系统入口必须关联匹配来源 ID；没有来源时删除该行。
- 明示本次实际联网 Tool 状态，并对每个来源显示获取方式、授权状态和获取时间；不得用“来源公开”代替授权核验。

## 一句话结论模板

`基于【来源范围】，已整理【适用对象】的报到清单；其中已确认 X 项、待确认 Y 项，最先需要完成的是【动作】，关键缺口为【缺口】。`

没有官方来源时改为：

`当前只能生成通用准备框架，尚不能确认本年度日期、地点、金额或必带材料；需补充【资料】后再完成通知级核对。`

## 准出检查

- 学校、校区、年份、培养层次和学生类别未串用；
- 每个已确认事项至少有一个适用的官方来源；
- 日期、地点、金额和材料要求可追溯；
- 必做事项包含前置条件、动作、完成证据和失败备选；
- 条件事项说明触发条件；
- 材料总表没有自行补份数；
- 没有把通用经验或往届信息改写为当前材料、日期、地点、费用或动作；
- 冲突和关键未知未隐藏；
- Tool 状态和来源授权状态已显示，授权待确认/受限来源未被用于确认事项；
- 输出不含账号、密码、验证码、证件号码和非必要个人信息；
- 没有承诺录取、资助、落户、免训或报到成功。

任一强制项失败时，交付“可安全使用的部分＋问题清单＋最少补充资料”，不得标注“已核验完成”。
