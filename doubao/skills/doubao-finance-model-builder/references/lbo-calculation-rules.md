# LBO计算规则

## Sources & Uses

用途至少包括收购股权价款、需偿还原债务、需偿还优先股及其他类债务项目、交易费、融资费和期初最低现金。

来源至少包括新债务、目标现金使用、管理层滚存及财务投资人股权。财务投资人股权为平衡项，但不得为负。来源与用途差额必须在容差内为零。

## 进入估值

    进入企业价值
    = 收购股权价值
    + 进入净债务
    + 少数股东
    + 优先股
    + 其他类债务项目

进入倍数等于进入企业价值除以进入EBITDA。进入EBITDA必须为正。

## 年度现金流

    还债前可用现金
    = EBITDA
    - 现金税
    - 资本开支
    - 营运资本增加
    - 其他必要现金支出
    - 现金利息

现金利息以期初与期末平均债务为基础迭代计算。PIK计入本金而不扣减当期现金。浮动利率应把基准利率、下限和利差合成为逐年全包利率输入，不得默认全预测期利率不变。

先执行强制摊还，再按cash_sweep_priority偿还可选债务。到期年度要求偿还该层全部本金及PIK；循环额度到期后不得继续提款。现金不足时先提款仍有效的循环额度；超过承诺额度或债务到期无法偿还的部分列为流动性缺口或再融资需求，未偿本金必须继续保留在期末债务中。

默认只允许使用偿债后的超额现金进行股权分配。请求分红超过可用超额现金时，回报计算只计入实际可分配金额并发出警告；债务融资分红等结构必须另行扩展模型。

## 退出

    退出企业价值 = 退出EBITDA × 退出倍数
    退出股权价值 = 退出企业价值 - 退出净债务 - 退出类债务调整 - 退出费用

股权价值最低按零处理，但保留未截断的原始值用于显示损失严重程度。财务投资人退出回收按其持股比例计算，并加入此前分红。

## 回报

    利润 = 全部正向股权现金流 - 全部股权投入
    MOIC = 全部正向股权现金流 ÷ 全部股权投入

使用实际日期计算XIRR。只有全部现金流严格按整年间隔且无中间流量时，才可用MOIC的持有期幂公式作校验。

## 回报桥

在总股权层面拆分：

- EBITDA增长贡献；
- 进入至退出倍数变化贡献；
- 净债务偿还贡献；
- 少数股东、优先股及其他类债务变化；
- 退出费用；
- 中期分红与追加投资。

回报桥必须与退出股权价值勾稽。若不能勾稽，标记为计算错误。

同时计算各项对“退出原始股权价值减进入股权购买价”的贡献比例。分母接近零时比例标记为NA并保留金额；贡献项可能一正一负，不得把净额比例误写为概率或收益率。

## 经营改善对比

用户给定零增长或受压Base Case时，不修改Base。另建 `management_case`，输入完整年度EBITDA、现金税、资本开支、营运资本和其他现金成本路径，并在相同退出年份和退出倍数下重跑债务计划。对比必须来自完整重算，不能只把退出EBITDA乘增长率后静态调整股权价值。

## 默认保守性

- Base退出倍数不得高于进入倍数，除非有清晰依据。
- 不自动加入协同效应。
- 不把所有现金视为可用于交易。
- 不假设到期债务能够无条件再融资。
- 不允许现金税长期为零而无税盾或亏损结转依据。
