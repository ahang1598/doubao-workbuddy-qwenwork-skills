## 阶段识别

把公司归入以下一种主阶段，并披露混合状态：

| 阶段 | 主要特征 | 主估值处理 |
|---|---|---|
| `pre-commercial biotech` | 无稳定产品销售，价值主要来自临床资产 | 通常缩小或拒绝纯交易可比结论；现金跑道和管线里程碑仅作边界 |
| `commercializing biopharma` | 已有产品销售但利润尚未成熟，销售和研发投入高 | NTM EV/Revenue 为主，LTM EV/Revenue及商业化效率为辅 |
| `scaling biopharma` | 产品销售快速增长，利润或EBITDA接近转正 | NTM EV/Revenue与NTM EV/EBITDA并列，检查经营杠杆 |
| `profitable biopharma` | 多产品、利润和现金转化稳定 | NTM P/E、EV/EBITDA为主，EV/Revenue辅助 |

不得把已有大规模产品销售的公司笼统归为“亏损Biotech”后只讨论管线价值。

## 收入质量拆分

至少拆分：

| 收入类型 | 经常性 | 可比处理 |
|---|---|---|
| 自营产品销售 | 高 | 主收入分母，核对净额/总额、渠道和医保价格 |
| 合作产品分成 | 中至高 | 核对收入确认、利润分成和地域权利 |
| 版税 | 中至高 | 单列，依赖合作方销售但可形成持续收入 |
| 授权首付款 | 低 | 单列，不与持续产品销售直接同倍数比较 |
| 研发/监管里程碑 | 低 | 单列并说明触发条件和确认时点 |
| 研发服务 | 视合同而定 | 根据持续性单列 |
| 投资收益或公允价值变动 | 非经营 | 从经营收入和EV分母中剔除或单列 |

对目标和同行同时披露“产品销售/总收入”。当授权及里程碑占比超过 20% 时，必须给出产品销售口径的辅助倍数；超过 50% 时，原则上不得进入 Commercial Core。

## 角色化同行

- `Commercial Core`：治疗领域、客户、产品销售模式和商业化阶段接近。
- `Stage Core`：收入规模、增长、亏损和融资阶段接近，可用于解释经营杠杆。
- `Mature Boundary`：展示成熟销售效率、利润率和现金转化边界。
- `Pipeline/Model Boundary`：技术平台或授权能力相似，但收入主要来自 BD、里程碑或海外合作。
- `Global Scale Boundary`：全球商业化平台或地域结构显著不同，只解释上限和风险溢价。

只有 Commercial Core 和满足全部硬门槛的 Stage Core 默认进入主统计。Mature、Pipeline 和 Global Boundary 不为凑样本并入 Core。

## 主辅估值锚

### Commercializing biopharma

- 主锚：NTM EV/Revenue。
- 辅助：资本结构和净现金水平接近时使用 NTM/LTM P/S，同时参考 LTM EV/Revenue、产品销售增长、产品销售毛利率、销售费用率、研发费用率和现金跑道。
- 转盈利交叉检查：NTM EV/EBITDA或NTM P/E，仅在分母稳定为正时使用。
- 弃用：负利润P/E、负EBITDA倍数、无收入公司的EV/Revenue。

成长超过 20% 或适应症、医保、产能导致预期切换时，禁止只用 LTM 得出总股权价值。真实 NTM 不可得时，用基准日前 FY1/FY2 日历化，并明确数据等级为 C。

### 增长与溢价证据

合理溢价必须连接到：

- 产品销售的同比与未来两年增长。
- 核心产品集中度和适应症扩张。
- 商业毛利率与净价稳定性。
- 销售费用率和经营杠杆。
- 医院覆盖、医保准入或关键渠道指标。
- 临床差异化、监管状态和地域可复制性。
- 现金跑道、融资需求和潜在稀释。

不把“平台稀缺性”本身量化为任意倍数溢价。

## 资产负债表与权利边界

### 现金桥

分别取得现金等价物、定期存款、短期金融资产、受限现金和经营所需现金。现金流量表期末现金不等于 EV 可扣现金。并列展示：

```text
报告现金及流动投资
- 受限现金
- 经营所需现金准备
= 可扣现金 [A]
```

若经营所需现金无法可靠估计，同时展示标准市场EV和保守调整EV，不用单点假设掩盖不确定性。

### 合作与地域权利

取得核心资产在中国、美国、欧洲、日本及其他地区的开发、生产和商业化权利。区分：

- 自营产品收入。
- 合作方承担的研发和商业化成本。
- 潜在首付款、里程碑和版税。
- 持有合作方股权或其他证券投资。

股权投资只有在可分离、未贡献目标收入且可合理估值时从EV扣除；对战略大宗持股考虑流动性、锁定、税项和控制权折价，并做敏感性。

## 市场隐含预期

优先反推：

1. 当前价格在合理 NTM EV/Revenue 下要求的 NTM 收入。
2. 若 FY1 预测固定，要求的 FY2 收入及相对现有预测差异。
3. 维持当前倍数所要求的产品销售增长、毛利率或经营杠杆方向。

没有分产品模型时停止在收入层，不伪造峰值销售或适应症概率。

## 禁止性规则

- 没有 rNPV 或资产级模型时，不把市值残差称为“管线价值”。
- 不把一次性授权收入与产品销售用同一EV/Revenue倍数机械估值。
- 不因计算更简单而用 P/S 替代 EV/Revenue；商业化生物科技的现金储备、融资需求和净现金差异显著时，P/S 只能作辅助验证。
- 不因公司有热门平台或全球首创标签就自动进入估值上四分位。
- 不把合作方海外产品销售视为目标公司产品销售。
- 不把现金等价物下降直接解释为现金消耗，必须先核对定期存款和金融资产重分类。
- 不在没有组合约束、流动性和风险预算时给出具体仓位比例。

## 三项失效证据

优先从以下选择三项并给出阈值和时间点：

1. 产品销售或核心品种销售相对预期的偏差。
2. 商业毛利率、销售费用率、研发费用率或调整后 EBITDA 的经营杠杆。
3. 关键适应症审批、OS/PFS、地域一致性或安全性。
4. 医保净价、医院准入、竞争产品份额和处方渗透。
5. 现金跑道、融资规模和完全稀释股本变化。
6. 同行整体估值制度从收入切换到利润或现金流。

每项说明触发后需要重做收入预测、同行角色、主锚、EV bridge还是合理倍数。
