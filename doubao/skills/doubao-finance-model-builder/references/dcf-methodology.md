# DCF 方法论与计算纪律

## 1. 估值对象

FCFF 折现得到企业价值（Enterprise Value），适合经营资产与融资结构可区分的非金融公司。金融机构的债务更接近经营原材料，监管资本决定可分配现金，不得机械套用 FCFF。

## 2. FCFF

标准公式：

```text
NOPAT = EBIT × (1 - 边际现金税率)
FCFF = NOPAT + D&A - Capex - ΔNWC + 其他非现金调整 - 其他经营性投资
```

符号约定：收入、EBIT、D&A、FCFF 为正流入；Capex、营运资本增加和其他投资以正数输入、在公式中扣除。营运资本释放可为负数。

优先从经营驱动预测每一项，不使用 EBITDA 减固定比例 Capex 的永久捷径。资本化研发、内容资产、合同取得成本等具有持续投资性质的项目需要在 EBIT 和再投资中一致重述。

## 3. 折现时点

- 年中折现：第 1 至第 N 年 FCFF 默认折现指数为 `0.5, 1.5, ..., N-0.5`。
- 年末折现：指数为 `1, 2, ..., N`。
- 终值默认位于第 N 年末并按 `N` 折现；若采用年中终值约定，必须明确说明并使用 `N-0.5`。
- 存在非完整首期时，使用从估值日至现金流中点的实际年分数，不硬套整数年度。

折现因子：

```text
DF_t = 1 / (1 + WACC)^t
PV(FCFF_t) = FCFF_t × DF_t
```

## 4. 终值

Gordon Growth：

```text
TV_N = FCFF_(N+1) / (WACC - g)
FCFF_(N+1) = 稳态 FCFF_N × (1 + g)
```

必须满足：

- `WACC > g`，默认至少保留 50–100 个基点安全垫。
- 稳态税率、利润率、资本强度、增长和再投资回报相互一致。
- 永续期再投资率与增长满足经济关系：`再投资率 ≈ g / ROIC`。
- 对终值计算隐含 EV/EBITDA、EV/EBIT 和 FCF Yield，检查是否偏离成熟期经济特征。

退出倍数法只作为交叉检查，或在用户明确要求时作为辅助终值；倍数必须对应稳态指标和同一时点。

## 5. 企业价值与股权价值桥接

```text
Enterprise Value
+ 可扣现金及现金等价物
+ 非经营投资和可单独估值资产
+ 联营/合营权益价值（若未进入经营现金流）
- 有息债务
- 债务性质租赁负债
- 未拨备养老金或类似债务
- 优先股
- 少数股东权益
- 其他非普通股索取权
= 普通股权益价值
÷ 完全稀释股份数
= 每股价值
```

每项只出现一次。若经营利润包含非全资子公司 100% EBIT，企业价值桥接必须扣除对应少数股东权益；若只计归属经营现金流，则不得重复扣除。

## 6. 完全稀释股本

从基准日前最近可得的法律发行在外股份出发，处理：

- 已结算但尚未反映的发行和回购。
- 期权的库存股法增量股份。
- RSU、PSU及其他股份支付工具。
- 可转债在债务和股本之间的互斥处理。
- ADR 与普通股换算比例。

不得用损益表加权平均股数替代期末完全稀释股份数。

## 7. 情景与敏感性

悲观、基准、乐观情景分别连接到收入、利润率、税、资本开支、营运资本、WACC 和终值增长。敏感性表至少使用 WACC × 永续增长率，并从底层现金流和终值重新计算每股价值。

## 8. 反向 DCF

由当前完全稀释市值反推市场隐含企业价值，再求解隐含永续增长率、稳态利润率或显性期现金流规模。只有当求解变量具有经济意义且其他条件固定时才报告单一隐含值；否则给出二维组合。

反向 DCF 是预期检查，不是独立目标价。

## 9. 强制检查

- FCFF 组成项勾稽差为零。
- 折现因子单调下降且均在 0 与 1 之间。
- WACC 高于永续增长率。
- 终值占企业价值过高时警告，默认阈值 75%。
- 显性期末增长、利润率和再投资不存在无解释跳变。
- EV 到股权价值桥接和每股计算可复算。
- 敏感性方向正确：其他条件不变时，WACC 上升通常降低价值，g 上升通常提高价值。
