# 会计与估值口径统一

## 股权价值

从基准日股价乘以完全稀释股份数开始。逐项处理期权、RSU、PSU、可转债、库存股及不同股份类别。不得直接混用期末基本股数和实时股价。

## 企业价值

通常使用：

    企业价值
    = 股权价值
    + 债务
    + 优先股
    + 少数股东
    + 其他类债务项目
    - 可用现金及等价物

受限现金、客户资金、监管资本、经营必需现金和无法上划现金不得自动全额扣除。

## EBITDA

从营业利润或净利润桥接至EBITDA，并列出每项调整。区分报告EBITDA、公司调整后EBITDA和分析师调整后EBITDA。

允许考虑有证据且可持续的正常化调整；不得自动加入未承诺协同、重复发生的“非经常”费用或纯估值目的调整。

## 租赁

选择并保持一致：

- 将租赁视为融资：债务包含租赁负债，EBITDA口径相应排除租赁费用；
- 将租赁视为经营：不把经营租赁全部作为债务，现金流保留租赁支出。

说明PRC GAAP、IFRS和US GAAP的列报差异，避免跨公司比较时口径错配。

## 自由现金流

从EBITDA扣除现金利息、现金税、资本开支、营运资本增加及必要现金支出。区分维持性与增长性资本开支，但在无证据时不得只扣维持性资本开支来夸大偿债能力。

## LTM

若最新披露为季度或半年：

    LTM = 最近年度 + 最新年初至今 - 上年同期年初至今

确保三个期间会计口径一致。并购、处置或会计政策变化导致不可比时，使用备考数据或明确调整。
