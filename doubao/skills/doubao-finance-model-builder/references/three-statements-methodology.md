## 1. 预测层级

按可得信息选择最细但仍可维护的层级：

- 有经营 KPI：使用底层驱动并汇总到分部和公司；
- 只有分部披露：预测分部收入、毛利或贡献利润；
- 只有合并报表：使用增长率、利润率和周转率，但明确为简化模型；
- 存在重大并购、处置、产能投产或会计变化：先构建桥接，再计算可比增长。

优先将历史趋势拆为数量、价格、组合、汇率、并购和会计口径影响。预测变化必须能够回到一个可观察事实或一个显式假设。

## 2. 利润表

### 收入

常用公式：

- 产品：销量 × 平均售价；
- 订阅：期初客户 + 新增 - 流失，乘以 ARPU；
- 制造：产能 × 利用率 × 良率 × 售价；
- 零售：期初门店 + 净开店，乘以同店销售和新店爬坡；
- 项目型：期初在手订单 + 新签 - 取消，按履约/交付节奏确认；
- 纯历史法：上期收入 × (1 + 增长率)。仅在无更好数据时使用。

分开预测内生增长、并购、处置和汇率。季度模型要考虑工作日、季节性和基数效应。

### 成本与费用

将成本分为可变、半固定和固定：

- 可变成本：单位成本 × 数量，或收入 × 成本率；
- 人员费用：平均 FTE × 人均薪酬；
- 销售费用：收入、客户获取或渠道活动的函数；
- 研发费用：项目组合、研发人数或收入比例；
- 一次性费用：单列并设置结束期，不延续为长期 run-rate。

使用毛利率/费用率时，将变化解释为价格、产品组合、原料、规模效应、产能利用率、汇率或效率。不要仅用“利润率改善”作为原因。

### 折旧摊销、利息与税

- 折旧摊销优先来自资产类别滚动；简化模型可用期初净固定资产 × 折旧率或资本开支队列；
- 利息费用来自债务余额、利率和借款时点；利息收入来自现金余额和收益率；
- 税率使用法定税率桥接有效税率，单列亏损不确认税益、税收优惠、地域组合和不可抵扣项目。

## 3. 资产负债表

### 营运资本

保持分母定义一致：

- 应收账款 = 收入 × DSO / 期间天数；
- 存货 = 销售成本绝对值 × DIO / 期间天数；
- 应付账款 = 销售成本绝对值 × DPO / 期间天数；
- 预收/合同负债可使用新增订单、账单或收入比例；
- 其他经营资产负债按明确驱动预测，避免全部按收入比例。

季度使用季度天数或基于年化流量；年度通常使用 365/366 天。存在明显季节性时，期末余额不得简单使用全年平均周转天数。

### 长期资产与资本结构

- 期末净固定资产 = 期初净固定资产 + 资本开支 - 折旧 - 处置 ± 汇率/并购；
- 商誉和无形资产需考虑并购、摊销、减值和处置；
- 期末债务 = 期初债务 + 新增借款 - 偿还 ± 汇兑/重分类；
- 期末留存收益 = 期初留存收益 + 净利润 - 分红 ± 直接计入权益项目；
- 期末股本/资本公积结合发股、回购、股权激励和转换事项滚动。

## 4. 现金流量表

默认采用间接法：

`CFO = 净利润 + 非现金费用 - 经营资产增加 + 经营负债增加`

`CFI = -资本开支 + 资产处置收入 - 收购支出 + 其他投资现金流`

`CFF = 新增借款 - 偿还债务 + 发股 - 回购 - 分红 + 其他融资现金流`

`期末现金 = 期初现金 + CFO + CFI + CFF + 汇率影响`

定义自由现金流时标明口径。默认企业经营分析可用 `CFO - 资本开支`；估值使用无杠杆自由现金流时，应从 EBIT 税后利润出发并排除利息与融资现金流。

## 5. 循环与配平

优先避免循环：

- 利息使用期初余额；
- 或使用不依赖本期现金的平均余额近似；
- 将现金清扫和循环授信作为单独融资模块。

现金是现金流量表的结果，不是随意配平项。循环授信可以是最低现金政策下的透明融资工具，但必须有明确公式、额度、利率和偿还顺序。不得用留存收益、其他资产、其他负债或未解释的现金行掩盖错误。

## 6. 情景和敏感性

情景应改变因果链上游：销量、价格、客户、流失、利用率、毛利率驱动、招聘、周转天数、资本开支和融资条件。不要直接把净利润乘以情景系数。

Base 反映最可能路径；Bull 和 Bear 应保持内部一致。例如 Bear 情景不能同时假设需求下降、库存天数不变、应收改善且无需融资，除非有明确经营行动支持。

敏感性优先选 2–4 个真正高影响变量，展示其对收入、EBITDA、自由现金流、期末现金或净债务的影响。

## 7. 结果解释

用桥接方式解释变化：

- 收入：销量、价格、组合、并购、汇率；
- 利润：收入增量毛利、成本通胀、效率、固定成本杠杆、一次性项目；
- 资产负债：营运资本、资本开支、并购、融资、分红回购；
- 现金：净利润、非现金项目、营运资本、资本开支、融资。

结论同时说明预测方向、幅度、时点、主要驱动、证据等级和失效条件。
