# A 股、港股和美股数据获取与口径规则

1. 工具优先级

## 1. 工具优先级

先按强制读取完整性协议完整读取 `references/source-tool-priority.md`，再按本文件处理市场差异：

1. 对每个数据项目先调用用户明确指定的工具、网站、文件和字段；用户给出来源顺序时严格按其顺序尝试。
2. 用户未指定该项目来源时，检查并优先调用 `seed_finance_search` 查询证券标识、历史三表、分部/KPI、公司指引、一致预期、股本、债务和公司行动；只请求任务需要的字段和期间。
3. 检查实际返回的币种、单位、财年、报表类型、准则、合并口径、调整口径和更新时间。任何字段不清时，不直接入模。
4. 使用原始监管文件或公司披露核验关键财务锚点。`seed_finance_search` 是高效入口，不是覆盖原始披露的最终证据。
5. 指定来源或默认工具不存在、调用失败、覆盖不足或结果冲突时，记录尝试和降级原因，再回退到下列权威来源。不得静默换源、编造工具调用或伪造数据。

## 2. A 股权威来源

优先级：

1. 巨潮资讯网（cninfo.com.cn）法定公告、年度/半年度/季度报告；
2. 上海证券交易所、深圳证券交易所、北京证券交易所公告与问询回复；
3. 公司投资者关系网站、业绩说明会材料和官方公告；
4. 中国证监会及其他主管部门文件；
5. 具备清晰来源和更新时间的专业数据服务，仅作为补充并需回溯原始披露。

重点口径：合并报表、归母净利润、少数股东损益、扣除非经常性损益后的归母净利润、政府补助、公允价值变动、信用/资产减值、资本化研发、应收票据/款项融资、合同资产负债和受限资金。

## 3. 港股权威来源

优先级：

1. 港交所披露易（hkexnews.hk）年报、中报、业绩公告、通函和持续披露；
2. 公司投资者关系网站、演示材料和官方公告；
3. 香港证监会及其他主管机构文件；
4. 具备清晰来源的专业数据服务，仅作补充。

重点口径：HKFRS/IFRS、股东应占溢利、非控股权益、持续经营/终止经营、投资物业重估、生物资产、租赁、联营/合营损益、派息币种以及不同股份类别。

## 4. 美股权威来源

优先级：

1. SEC EDGAR 的 10-K、10-Q、8-K、20-F、40-F、6-K、S-1 等文件及 XBRL；
2. 公司投资者关系网站、财报新闻稿、业绩演示和电话会材料；
3. 交易所与其他监管机构文件；
4. 具备清晰来源的专业数据服务，仅作补充。

重点口径：US GAAP、GAAP 与 Non-GAAP 对账、股票薪酬、递延收入、经营租赁、商誉与无形资产、税务估值备抵、回购、稀释股数、持续经营/终止经营及 52/53 周财年。

对外国私人发行人，根据其实际文件使用 IFRS 或其他准则，不因为在美国上市就强制按 US GAAP 重构。

## 5. 跨市场口径统一

- 以公司法定合并报表为历史基准，单独保存管理层调整口径；
- 不把 A 股扣非归母净利润、港股调整后股东应占利润和美股 Non-GAAP net income 当作完全可比指标；
- 保留原币模型；需要跨市场比较时，在独立展示层用明确汇率换算，不在底层三表混用币种；
- 对双重上市/ADR，核对同一经济实体、股份类别、ADR 比例、报告币种和每股口径，避免重复计数；
- 使用公司财年，不把非自然年财务直接塞入自然年列；需要日历化时单独建立桥接；
- 历史期间发生会计准则变化、重述、并购或处置时，保留报告值并建立可比口径桥接。

## 6. 证据与冲突处理

为每个关键输入保存：证券代码、市场、科目、数值、币种/单位、期间、报告类型、准则、来源类型、来源链接、访问日期和备注。

最低核验锚点包括：收入、归母/股东应占净利润或净利润、总资产、总负债、现金及现金等价物、经营现金流、资本开支、债务和稀释股数（适用时）。

冲突处理顺序：

1. 法定监管文件或交易所披露；
2. 公司正式公告/年报/季报；
3. 公司演示与电话会材料；
4. `seed_finance_search` 或专业数据服务；
5. 新闻、聚合网站和二手资料。

对币种、单位、期间或口径无法解释的冲突，不取平均值；保留差异、选择更高等级证据，并在 `来源` 与结论中说明。
