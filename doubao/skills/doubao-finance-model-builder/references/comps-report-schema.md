# 专业研究报告结构

本文件仅在用户明确要求独立可比公司报告时使用。默认交付仍为单一公式Excel，报告结构不得导致第二套计算或减少工作簿公式与审计内容。

报告首页先显示 `model_status_code`。只有 `PASS` 才能展示推荐倍数、隐含每股价值或目标价；`INCOMPLETE` 必须展示阻断事项，并将数值区间标为计算底稿。

## 表达规则

生成一份完整研究报告，在正文嵌入同行、数据、调节表、估值和敏感性表，不依赖另一个未交付的 Excel。默认使用简体中文；用户明确要求其他语言时再切换。

金融指标首次出现时必须使用“中文全称（英文缩写，简明口径）”，报告结尾必须附“指标释义与口径”。不得在面向用户的标题、表头、结论、脚注、单位和警告中单独使用英文术语。`Core/Secondary/Excluded`、`Pass/Limited/Fail` 等内部枚举值必须翻译为中文。一般行业的企业价值（Enterprise Value）与保险行业的内含价值（Embedded Value）必须消歧。

先给结论，再给证据。严格区分：

- 可验证事实、公司行动和报告数据。
- 第三方一致预期。
- 计算推导与口径调整。
- 行业阶段、同行分类、主辅锚、溢折价和隐含预期等分析判断。

金额、股数、每股值、倍数、收益率和日期使用一致格式。保留底层未舍入值用于复算。不得给出来源或计算无法支持的伪精确结论。

## 固定章节

1. **结论摘要**：核心可比公司、主锚、辅助锚、合理溢折价方向、隐含每股价值区间、基准日股价、上涨/下跌空间，并用一句话标记高、中或低置信度。
2. **范围与时点**：证券身份、估值日、价格日、报告币种、信息截止日、预期持有期和关键限制。
3. **行业、经营阶段与估值路由**：说明经济模式、阶段、主辅锚和弃用指标。
4. **目标公司经营画像**：呈现影响可比性的业务、收入结构、规模、盈利、资本密集度、现金转化和风险。
5. **同行池与分类**：展示四维评分、数据质量、核心/辅助/排除分类及逐家公司理由。
6. **数据口径与来源**：说明实际工具、专业数据供应商、替代关系、标签、最近十二个月（LTM）、未来十二个月（NTM）、汇率、数据缺口和就近引用。
7. **股本、公司行动、股息与企业价值标准化**：展示从最近可靠股本日至估值日的公司行动滚存、完全稀释股本调节表、股价×估值日股数与独立市值反向校验、除息后每股净资产调节表（如适用）和企业价值至股权价值调节表。
8. **可比公司数据与倍数**：嵌入完整数据、经营指标和交易倍数。
9. **核心可比公司统计与合理溢折价**：披露第25百分位数（P25）、中位数、第75百分位数（P75）、样本数、目标定位和建议倍数。
10. **隐含每股价值**：从主锚到企业价值、股权价值和每股价值完整推导；银行等市净率（P/B）路径直接从调整后每股净资产（BVPS）推导。
11. **市净率—净资产收益率交叉检查**：仅在银行或资产型金融机构适用且样本充分时展示回归、残差和限制。
12. **当前价格隐含预期**：反推当前价格要求的收入、息税折旧摊销前利润（EBITDA）、净利润、自由现金流（FCF）或每股净资产（BVPS），并与现有预期比较。
13. **敏感性与情景**：展示二维敏感性及悲观/基准/乐观情景，明确驱动项。
14. **三项失效证据**：观察指标、方向、阈值或时间点，以及触发后需要重做的环节。

不适用章节可简化，但不得删除主锚选择、调节表、隐含预期、敏感性和失效证据。

## 可比公司倍数表

保持公司顺序一致，按行业适用性选择字段。非金融公司默认三组连续子表：

1. **市场与资本结构**：股价、稀释股本、市值、净债务/净现金、EV 和日期。
2. **收入与 EBITDA**：LTM/NTM 收入、EBITDA、利润率、P/S、EV/Revenue 和 EV/EBITDA。
3. **盈利与现金流**：LTM/NTM 净利润或 EPS、P/E、FCF 和 FCF Yield。

银行等 P/B 主导公司改用：

1. **市场与股本**：股价、价格日、基本/稀释股本、市值。
2. **权益与股息**：报告普通股权益、股息调整、调整后 BVPS、平均权益。
3. **盈利与回报**：LTM/NTM 净利润或 EPS、P/B、LTM/NTM P/E、ROE、资产质量和资本充足率等解释变量。

在单元格、字段名或脚注清楚标示 `[R]`、`[A]`、`[E]`、`[D]`。用 `NA` 表示缺失，用 `NM` 表示无经济意义。每个 LTM/NTM 数值注明期间和估计快照日。

## 来源与审计

- 将引用放在其支持的事实、数值或判断附近，不只列文末清单。
- 记录实际金融工具、数据供应商、替代关系、覆盖字段、上游来源和快照日。
- 报告值优先链接基准日前监管文件或公司正式披露。
- 第三方估计注明供应商、估计快照日、预测期间、口径和覆盖度（如可得）。
- 对 `[A]` 与 `[D]` 提供公式和源字段。
- 在数据口径章节披露缺失、冲突、降级来源和脚本警告。
- 只在结论摘要标记总体置信度；用一句话说明最主要限制。
