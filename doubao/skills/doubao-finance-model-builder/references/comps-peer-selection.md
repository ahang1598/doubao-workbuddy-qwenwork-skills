## 原则

依据经济实质选择同行，不把行业标签、指数成分或相似市值视为充分条件。先完成目标公司经营画像与行业阶段路由，再形成候选池。同行选择必须独立于希望得到的估值结果。

用户点名的公司必须评估，但不自动进入 Core。不得预先固定任何公司的分类。目标公司自身不进入同行统计。

## 候选池构建

从以下来源建立宽口径池：

- 直接产品、服务和客户竞争者。
- 争夺相同预算、交易、流量或工作负载的替代方案。
- 具有相似订阅、平台、广告、交易、制造、金融或资产运营模式的公司。
- 收入组合、规模、增长、利润率、资本密集度或现金转化相似的公司。
- 公司披露、行业材料和投资者实际使用的公开市场对标对象。
- 用户要求评估的公司。

候选池先宽后窄。记录每家公司进入初始池的事实依据和最终分类变化理由。避免同一经济实体的不同上市证券重复计入。

## 同行角色

先赋予经济角色，再决定是否进入 Core 统计：

- **Commercial Core**：收入形成、客户预算、渠道和商业化模式最接近。
- **Stage Core**：增长、利润率、现金转化、资本需求和发展阶段最接近。
- **Mature Boundary**：业务相关但已进入成熟盈利阶段，用于观察利润与估值边界。
- **Pipeline/Model Boundary**：平台、管线、授权、分部或其他局部模式可比，但不适合作主统计。
- **Global/Scale Boundary**：规模、地域、会计或监管结构差异显著，只用于解释市场上限或折价。
- **Excluded**：结构性不可比、数据失败、特殊状态或重复证券。

分类与角色分开：`Core/Secondary/Excluded` 决定统计资格，角色解释该公司为何有分析价值。报告中同时展示两者，避免把成熟公司、亏损公司和授权驱动公司混成单一同质集合。

## 四维评分

对每家公司按 0–5 分评分，并提供事实证据。默认总分：

```text
总分 = 业务重叠度 × 35%
     + 商业模式 × 25%
     + 收入结构 × 25%
     + 市值区间 × 15%
```

### 1. 业务重叠度（35%）

- **5**：核心产品、客户、采购预算和竞争集合高度重合。
- **4**：主要业务直接重合，存在少量地区或产品差异。
- **3**：部分直接重合，仍共享重要客户预算或价值主张。
- **2**：仅相邻业务或替代关系，竞争证据有限。
- **1**：只有宽泛行业关联。
- **0**：无实质业务重叠。

### 2. 商业模式（25%）

比较定价方式、合同期限、收入确认、客户获取、交付方式、资本密集度、监管和单位经济性。

- **5**：收入形成、成本结构、资本需求和主要估值驱动高度相似。
- **4**：核心模式相同，个别渠道、地区或资本结构不同。
- **3**：模式大体相似，但利润或现金转化机制存在可解释差异。
- **2**：共享部分模式，另一主要模式造成结构差异。
- **1**：经济模式明显不同。
- **0**：无法形成有意义比较。

### 3. 收入结构（25%）

比较分部、经常性收入、订阅/交易/广告/产品/服务占比、客户与地区集中度。

- **5**：主要收入分部与占比高度一致。
- **4**：主收入驱动一致，组合差异较小。
- **3**：部分分部可比，差异可以分部数据解释。
- **2**：只有少数收入来源可比或相关分部过小。
- **1**：收入组合结构性不同。
- **0**：缺少分部信息或完全不相似。

### 4. 市值区间（15%）

用估值基准日同币种股权市值比率打分：

| 同行市值/目标市值 | 得分 |
|---:|---:|
| 0.50×–2.00× | 5 |
| 0.25×–<0.50× 或 >2.00×–4.00× | 4 |
| 0.10×–<0.25× 或 >4.00×–10.00× | 3 |
| 0.05×–<0.10× 或 >10.00×–20.00× | 2 |
| <0.05× 或 >20.00× | 1 |
| 市值不可可靠取得 | 0 |

市值只反映规模、流动性和成熟度的近似差异，权重不得高于业务和收入维度。对银行或地产等资产型行业，可在说明后用普通股权益、总资产或 NAV 规模作辅助，但仍保留市值分数。

评分展示最多保留一位小数。不得使用 `4.13` 或 `3.73` 等精度暗示判断具有统计测量基础。建议在精简报告中显示 `业务/模式/收入/市值 → 总分`，例如 `4/4/3/5 → 3.9`。

## 数据质量门

评分完成后再通过数据质量门。至少检查：

- 证券身份和股价时点可靠。
- 主估值锚的分母可得且经济含义成立。
- 股本、除息状态或 EV bridge 能够合理复原。
- LTM 或 NTM 与目标公司的期间和口径一致。
- 不存在无法处理的重大并购、分拆、困境或会计断点。

数据质量分为：

- **Pass**：主锚和关键 bridge 可复核。
- **Limited**：可用于解释或敏感性，但不足以进入 Core 主统计。
- **Fail**：缺少基准日可用的关键字段或经济含义失真。

四维高分不能覆盖 `Fail`；低分也不得因估值倍数“看起来合适”而升级。

## 分类规则

### Core

默认同时满足：

- 加权总分不低于 3.5/5。
- 业务重叠度、商业模式、收入结构均不低于 3。
- 数据质量为 Pass。
- 主估值驱动差异可以解释，而非结构性不可比。

Core 用于中位数、四分位数、P/B–ROE 回归和主估值区间。通常争取四至八家，最低三家；不得为凑数量降低门槛。

### Secondary

通常满足以下之一：

- 总分 2.3–<3.5。
- 总分虽高，但一个关键维度低于 3。
- 数据质量为 Limited。
- 局部业务可比，但规模、地区、综合集团或经营阶段差异显著。

Secondary 用于解释估值边界、投资者对标和敏感性，不默认并入 Core 统计。

### Excluded

出现以下任一情况时通常排除：

- 总分低于 2.3，且缺少足够局部可比性。
- 数据质量为 Fail。
- 业务、收入模式、资本密集度或监管结构不可比。
- 处于困境、清算、重大重组或非常规交易状态。
- 主锚分母持续无经济意义且没有可比替代锚。
- 与另一候选证券代表同一经济实体，构成重复计入。

Excluded 仍出现在分类表中并说明排除理由。

阈值是默认审计规则，不是机械分类器。偏离阈值时必须说明哪项经济事实足以覆盖分数结果；不得以估值结果作为偏离理由。

## 特殊情形

- **综合集团**：评估相关分部占收入、利润和估值驱动的比例。分部过小或无法独立观察时通常为 Secondary 或 Excluded。
- **高增长亏损公司**：业务高度相似时可保留，但对 EBITDA 或 P/E 标记 `NM`，改评估 EV/Revenue、增长、毛利和现金转化。
- **跨市场公司**：市场不同不自动排除，但需解释会计、监管、流动性、税制和风险溢价差异。
- **重大并购或分拆**：基准日前已公告但尚未完成时区分现状和备考画像；备考信息不足则降低分类。
- **金融机构**：银行、保险、证券不可与工业企业因市值或利润规模相近而直接归入 Core。
- **同一集团多地上市**：选择与目标证券最可比且数据最完整的一种证券，其他证券排除为重复实体。

## 样本与异常值纪律

- 只用 Core 有效值计算主统计和回归。
- 披露每个指标的有效样本数；不同指标允许样本数不同。
- 不静默删除、缩尾或改分类来消除异常值。
- 数据错误应修正并保留审计记录。
- 真实异常值应保留并解释；只有经济含义失真时才将该指标标为 `NM`。
- Core 少于三家时，不把四分位数描述为稳健市场基准。
- P/B–ROE 回归少于四家、ROE 离散度不足或受单点显著驱动时，只作定性检查。
