# 输出模式与视觉规范

所有正式模式默认只交付一个通过审计的公式工作簿。以下模式定义工作簿结论页和可选辅助报告的内容深度；只有用户明确要求时才额外输出飞书文档、Markdown或其他文档格式，且这些文档不得替代Excel。

## 目录

- 模式选择
- 中文表达与指标释义
- 决策摘要
- 完整报告
- 审计包
- 表格与数字规范
- 结论表达规范

## 模式选择

默认使用 `decision-brief`，并把其内容写入Excel结论页。只有用户明确要求正式研究报告、投委会长文或完整底稿时，才在工作簿之外额外使用 `full-report` 或 `audit-pack`。

| 模式 | 使用场景 | 目标长度 | 必需内容 |
|---|---|---:|---|
| `decision-brief` | 基金经理、交易或快速复盘 | 1–2 页 | 结论卡、核心同行、企业价值调节表、估值、隐含预期、情景、触发器 |
| `full-report` | 正式研究、投委会、外部交付 | 6–15 页 | 决策摘要加经营画像、完整同行、数据口径、调整与来源 |
| `audit-pack` | 用户明确要求的数据复核、模型审计、历史归档 | 不限 | 公式工作簿、输入 JSON、计算 JSON、来源台账、脚本警告；独立报告按需 |

若用户没有指定模式，不询问，直接交付通过审计的Excel并使用`decision-brief`结论页；标准化输入、计算输出和审计文件作为复核附件，不默认生成独立文档。

## 中文表达与指标释义

面向用户的产物默认使用简体中文。内部 JSON 字段、程序参数和证券代码可以保留英文；标题、表头、正文、脚注、警告、分类、数据质量和单位必须使用中文。公司名称优先使用官方中文名称；没有官方中文名称时保留法定英文名称并附证券代码。

所有模式先显示 `model_status_code`。`INCOMPLETE` 时报告只展示计算底稿和阻断事项，不显示推荐倍数、隐含价值区间或目标价；补齐同行理由、来源、分析摘要和有效核心样本后重新计算。

金融指标首次出现时使用“中文全称（英文缩写，口径）”。报告结尾必须附“指标释义与口径”小节，至少覆盖正文实际出现的指标：

| 缩写 | 中文名称 | 最低口径说明 |
|---|---|---|
| LTM | 最近十二个月 | 截至估值基准日前最近已公开期间滚动计算的十二个月数据 |
| NTM | 未来十二个月 | 以估值基准日当时可得预测构造的未来十二个月数据 |
| P/E | 市盈率 | 完全稀释股权价值除以归属于普通股股东的净利润 |
| P/B | 市净率 | 股价除以完成股息口径匹配后的每股净资产 |
| P/S | 市销率 | 完全稀释股权价值除以同期间营业收入；仅在资本结构足够可比时作为主锚 |
| EV/Revenue | 企业价值/营业收入倍数 | 企业价值除以同期间营业收入 |
| EV/EBITDA | 企业价值/息税折旧摊销前利润倍数 | 企业价值除以口径匹配的 EBITDA |
| FCF Yield | 自由现金流收益率 | 自由现金流除以完全稀释股权价值；收益率越高通常对应估值越低 |
| ROE | 净资产收益率 | 归属于普通股股东的净利润除以平均普通股权益 |
| BVPS | 每股净资产 | 归属于普通股股东的净资产除以匹配股本 |
| P/NAV | 市值/净资产价值倍数 | 股权市值除以同一估值日、同一权益口径的净资产价值 |
| P/EV（保险） | 市值/内含价值倍数 | 此处 EV 指内含价值（Embedded Value），不是企业价值 |
| P/FFO | 股价/运营资金倍数 | 股价或市值除以房地产投资信托基金口径的运营资金 |
| NA | 数据缺失 | 相关数据无法可靠取得，不代表数值为零 |
| NM | 指标无经济意义 | 分母为零、负值或指标经济含义失真 |

同行分类统一显示为“目标公司、核心可比公司、辅助可比公司、排除公司”；角色统一显示为“商业核心、阶段核心、成熟边界、管线/模式边界、全球/规模边界”；数据质量统一显示为“通过、受限、不通过”。内部值 `Target/Core/Secondary/Excluded`、`Pass/Limited/Fail` 可保留在审计 JSON 中。

## 决策摘要

严格按以下顺序输出。

### 1. 一句话结论

用一句话回答用户的实际问题，同时包含估值方向和关键条件。例如：

> 国内商业化基准情形已充分反映；现价还要求未来十二个月（NTM）营业收入较当前预测高约 13%，或海外注册风险进一步下降。

不要用“基本合理”“存在一定空间”等没有比较基准的模糊结论。

### 2. 投资判断卡

最多七行：

| 判断项 | 结论 |
|---|---|
| 基准日价格 |  |
| 主估值锚 |  |
| 当前交易倍数 |  |
| 核心可比公司中位数/第75百分位数 |  |
| 合理价值区间 |  |
| 市场隐含预期 |  |
| 数据等级与置信度 |  |

### 3. 核心证据

用三至五个短段落解释：

- 经营进展及收入质量。
- 核心可比公司与目标公司的关键差异。
- 企业价值调节表中最重要的调整。
- 合理溢折价的可观察依据。

### 4. 精简同行表

不要在聊天窗口放十列宽表。使用：

| 公司 | 角色 | 四维分 | 增长/净资产收益率（ROE） | 主倍数 | 关键差异 |
|---|---|---:|---:|---:|---|

四维分写成 `4/4/3/5 → 3.9`。顺序为业务重叠、商业模式、收入结构、市值区间。

### 5. 估值与反向预期

把核心可比公司统计、建议锚、隐含价值和现价差异放在一张表。紧接着说明当前价格要求基本面比未来十二个月（NTM）预期高或低多少。

### 6. 情景与失效证据

用一张情景表和三项触发器收尾。风险清单不是失效证据。

## 完整报告

在决策摘要后追加：

1. 范围、证券身份与时点。
2. 行业、阶段与估值路由。
3. 目标公司经营画像。
4. 宽口径同行池与角色分类。
5. 数据工具、数据等级、来源和降级关系。
6. 完全稀释股本、现金、股息和企业价值调节表。
7. 完整可比公司数据与倍数。
8. 核心可比公司统计、合理溢折价和辅助锚交叉检查。
9. 隐含价值、市场隐含预期、敏感性和情景。
10. 三项失效证据、来源和局限。

不适用章节可合并。不要为满足目录而重复同一数字或判断。

## 审计包

只有用户明确要求审计包时，才在通过审计的公式工作簿之外附以下复核文件：

- `comps-model.xlsx`：中文、可编辑、公式驱动且通过专属审计的主要工作簿。
- `report.md`：仅在用户同时明确要求独立报告时生成的Markdown源文件。
- `normalized-comps.json`：标准化输入。
- `calculated-comps.json`：计算输出。
- `source-ledger.csv` 或等价表：来源 ID、类型、公开日、快照日、URL、覆盖字段。
- 脚本警告及未解决事项。

用户明确要求飞书文档或其他独立报告时，正文仍先给决策摘要；该报告必须引用同一计算结果和工作簿单元格追溯，不得形成第二套数值或取代Excel。

## 表格与数字规范

- 正文金额默认使用亿元或十亿；审计底稿使用百万。
- 股价保留两位小数；倍数保留两位；收益率保留一位；四维总分保留一位。
- 同一张表只用一种金额单位，并在标题注明。
- 正文表格原则上不超过六列；超过六列时拆成连续子表。
- 首次出现时写明“数据缺失（NA）”和“指标无经济意义（NM）”，后续可使用缩写，不用 `-` 混代。
- `[R]/[A]/[E]/[D]` 优先写在字段名、脚注或调整项上，不在每个单元格机械重复。
- 只突出基准情景和最重要的现价差异，避免整表加粗。
- 敏感性矩阵的列为倍数或收益率，行为财务指标；表下注明净债务和稀释股本假设。

## 结论表达规范

结论必须区分：

1. 已实现经营事实。
2. 当前一致预期或卖方预测。
3. 当前价格额外要求的预期差。
4. 只有进一步去风险才成立的期权价值。

不得：

- 用当前市场价格反证当前市场价格合理。
- 把估值残差直接称为管线、品牌、平台或协同价值。
- 用无模型支持的精确百分比拆分溢折价。
- 在没有用户风险预算、持有期和组合信息时给出具体仓位比例。
- 因报告篇幅完整而掩盖数据等级低、核心可比公司样本少或调节项目大的事实。
