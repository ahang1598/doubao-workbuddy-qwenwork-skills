# 中文输出与审计包

## 中文决策摘要

按以下顺序输出：

1. 估值基准日、证券、币种、价格日和数据等级。
2. 基准每股价值、悲观/乐观区间、当前价格和隐含上涨/下跌空间。
3. 核心经营预测：收入、息税前利润率（EBIT利润率）、企业自由现金流（FCFF）、增长和稳态收敛。
4. 加权平均资本成本（WACC）组成、永续增长率、终值占比和隐含退出倍数。
5. 企业价值（EV）到普通股权益价值的桥接。
6. WACC × 永续增长率敏感性和悲观/基准/乐观三情景。
7. 反向现金流折现（Reverse DCF）与市场隐含预期。
8. 关键风险、三项失效条件、数据缺口与结论置信度。

首次出现英文金融术语时，按照 `terminology-zh.md` 给出中文全称、英文全称或缩写及一句解释。表格中可使用“中文全称（缩写）”，不得使用英文单词或缩写作为唯一表头。

## Excel 工作簿

最低工作表：

- “封面”：公司、基准日、模型状态、场景和关键输出。
- “执行计划”：范围、证据、计算、工作簿、交付审计和结论发布阶段；不保存第二套估值结果。
- “数据来源”：来源台账和字段映射。
- “股本与市值桥”：公司行动检索区间、逐项股数滚存、分证券估值日股数、不复权收盘价、独立市值及反向勾稽。
- “估值假设”：场景、WACC、终值和股权桥接输入。
- “经营预测”：历史、预测驱动和 FCFF。
- “DCF估值”：折现、终值、企业价值、股权价值及每股价值。
- “敏感性分析”：动态 WACC × 永续增长率表和三情景。
- “模型检查”：实际值、预期值、差异、容差、状态和说明。
- “术语说明”：中文全称、英文全称/缩写、经济含义和模型位置。

工作表名、标题、场景、状态、警告、注释和图表标签使用简体中文。场景使用“悲观/基准/乐观”，状态使用“通过/警告/错误”。输入蓝字、同工作簿链接绿字、公式黑字、外部链接红字；来源或报告值不因是硬编码就涂成蓝字。隐藏网格线，单位和期间明确，公式可复制，关键输出位于顶部。可见工作表不展开WACC、FCFF、终值等教学式公式，只显示组成项、采用值、计算结果、口径和来源；实际计算公式必须保留在对应计算单元格中。缺失输入显示空白或 `NA`，不得用静态0掩盖缺失。

## 审计包

至少包含：

- `execution-plan.json` 与 `execution-plan-validation.json`：建模范围、证据要求、质量门和计划验证结果。
- `normalized-dcf.json`：标准化机器输入。
- `calculated-dcf.json`：未舍入计算结果。
- `validation.json`：中文检查名称、状态和说明。
- `delivery-validation.json`：Excel、报告、情景、敏感性和确定性计算的一致性检查。
- `report.md`：中文估值报告。
- `dcf-formula-model.xlsx`：中文公式工作簿。
- `run-record.json`：实际执行阶段和最终状态。
- `artifact-manifest.json`：主要交付物和审计附件的大小及SHA-256。
- `cell-lineage.json`：关键输入、公式、检查和输出到工作表单元格的映射。
- 来源台账及必要的原始披露引用。

JSON 可以保留英文机器键，但枚举、警告和用户可见说明应提供中文。JSON 与 Excel 的基准情景每股价值必须一致；验证警告应在报告局限性中对应披露。

报告渲染时传入计算验证结果。状态不是 `PASS` 时，摘要不得显示目标价、上涨空间或投资结论，只能展示待修复计算底稿和阻断事项。Excel与报告中的模型状态必须引用验证结果，不得手填。

## 引用

报告中的关键事实和外部假设就近引用。Excel 在“数据来源”表保存可点击的纯文本 URL；关键硬编码输入使用来源编号或单元格批注。工具名称本身不是充分引用。
