## 工具选择与授权边界

目标公司及进入倍数统计的同行，股本与公司行动必须先执行 `references/equity-evidence-acquisition.md`。数据库股数字段只能作为线索或交叉检查，不能替代本地冻结的官方基准股本、官方检索结果和公告正文。

先按强制读取完整性协议完整读取 `references/source-tool-priority.md`。对每个数据项目优先调用用户明确指定的工具、网站、文件、字段和历史时点口径；用户未指定的项目再优先调用环境中的 `seed_finance_search`。指定来源或默认工具不存在、权限不足或覆盖不足时，记录实际尝试、不可用状态和替代理由，再按能力选择替代工具：

1. 证券身份和跨市场代码映射。
2. 指定历史日期的价格、市值和公司行动。
3. 财务报表、股本与 EV bridge 组成项。
4. 带历史快照日的分析师一致预期。
5. 监管文件、交易所公告与公司投资者关系材料。

允许组合多个工具分别覆盖行情、报告财务和一致预期。适配实际工具参数，不猜测不存在的字段，不因 `seed_finance_search` 缺失而停止；不得静默用其替换用户指定来源。

若环境已授权 FactSet、Bloomberg、LSEG、S&P Capital IQ 或其他专业数据源，优先取得带快照日、预测期间、会计口径和贡献者覆盖数的历史一致预期。没有相应连接器或订阅时，不得声称已“对接”或引用不可访问的数据。使用公开替代数据时明确标记覆盖和置信度下降。

## 数据能力等级

在检索开始后、形成结论前确定数据等级：

| 等级 | 最低条件 | 结论边界 |
|---|---|---|
| A | 同一专业供应商的历史时点一致预期，快照、期间、口径和覆盖数完整 | 可形成高置信度前瞻相对估值 |
| B | 多家基准日前卖方预测或可靠结构化数据，关键口径已核对 | 可形成前瞻区间，披露供应商差异 |
| C | 单一卖方预测、公开 FY1/FY2 日历化或部分字段替代 | 中等置信度，扩大敏感性并突出缺口 |
| D | 无可靠前瞻数据、关键 bridge 缺失或只能使用 LTM | 只做方向性定位，不给伪精确目标价 |

总体置信度不得高于数据等级允许的上限。同时披露 Core 数量、估计新鲜度和调整强度，不用一个“中等”标签覆盖全部缺口。

## 查询计划

先确认证券身份，再查询数值。对每家公司确定：

- 法定名称、ticker、交易所、ISIN（如可得）和股本类别。
- A 股、H 股、ADR 或普通股身份及 ADR 比率。
- 估值基准日、最近交易日、报告币种和展示单位。
- 最近可用资产负债表、LTM 构成期间、NTM 期间和估计快照日。
- 需要的股价、股本、股息、EV bridge、损益、现金流、权益、ROE、NAV、保险内含价值或行业 KPI。

批量能力可用时，分别按“身份与公司行动”“市场数据”“报告财务”“前瞻估计”批量查询目标公司和候选同行。先取得原始组成项，再自行计算股本、EV 和交易倍数。

为每次查询保存：工具或供应商名称、查询时间、条件、返回数据日期、上游来源、字段定义和替代理由。工具名本身不是充分引用。

建立来源台账，保存 `source_id`、来源类型、公司、标题、URL或文件位置、财务期末日、公开日、估计快照日、查询日、覆盖字段和备注。每个 `[R]`、`[E]` 和关键 `[A]` 至少能回溯至一个 `source_id`。

## 时点纪律

所有输入必须满足 point-in-time 可得性：

- **股价**：使用目标证券在价格日的收盘价；基准日非交易日时使用此前最近交易日并披露。
- **股本**：使用基准日前最近一次公开的基本股份，加入截至基准日已发行或经济上稀释的工具，并处理已经结算的发行或回购。
- **资产负债表**：使用基准日前已经公开的最近一期报表，不得使用后来发布但财务期末更早的报表。
- **LTM**：只使用基准日前已公布的季度或年度数据滚动计算。
- **NTM**：使用基准日当时可得的一致预期快照；历史估值不得用当前预期回填。
- **公司行动**：只有基准日前已公开且已生效、已结算或足以可靠量化的事项才可调整。
- **除息**：判断价格日在除权日前还是后，并检查使用的股东权益是否已扣除该股息。

分别记录“财务期末日”“公开发布日期”“价格日”“公司行动生效或结算日”“估计快照日”和“查询日”。任一关键信息的公开日或快照日晚于基准日时，不得用于该时点估值。

## 来源层级与数据标签

按以下优先级处理：

1. 监管申报、审计财报、交易所文件及公司正式公告。
2. 公司业绩材料、股本或公司行动通知和电话会补充材料。
3. 可识别上游来源的行情或专业一致预期数据库。
4. 可靠第三方数据库、卖方汇总或研究材料。
5. 新闻与其他二手资料，仅用于线索和辅助核验。

数据标签：

- `[R]`：原始报告值、监管申报值、公司行动事实或对应证券原始市场价格。
- `[A]`：为可比性进行的分析调整，包括股息口径匹配、备考并购、租赁或一次性项目。
- `[E]`：第三方一致预期、卖方预测或其他前瞻估计。
- `[D]`：由 `[R]`、`[A]`、`[E]` 计算、日历化、插值或汇率换算得到的数值。

同一字段存在报告与调整口径时并列展示。不得因为金融工具返回某个字段就自动把它标为 `[R]`。

## 最低字段集

对目标公司及每家 Core、Secondary 至少记录：

| 类别 | 字段 | 日期或定义 |
|---|---|---|
| 身份 | 公司、ticker、交易所、股本类别、ADR 比率 | 基准日身份 |
| 市场 | 收盘价、基本股本、完全稀释股本、市值 | 价格日、股本日、稀释方法 |
| 稀释 bridge | 期权、RSU、PSU、可转证券、其他稀释、已结算回购、未结算 ASR | 授予/发行、归属、结算和披露日 |
| EV bridge | 债务、现金、优先股、少数股东权益、租赁或其他债务类项目、非经营投资 | 期末日、公开日、可动用性 |
| LTM | 收入、EBITDA、净利润或 EPS、CFO、资本开支、FCF | 构成期间、最后公开日 |
| NTM | 收入、EBITDA、净利润或 EPS、FCF | 供应商、快照日、预测期间 |
| 权益估值 | 普通股权益、平均普通股权益、BVPS、ROE | 期初/期末、归属口径 |
| 除息 | 股息类型、DPS、币种、除权日、支付日、权益是否已扣除 | 对应证券与股份权利 |
| 行业 KPI | 保险内含价值、地产 NAV、装机或产能、交易额等 | 指标定义、期间、来源 |
| 单位 | 币种、金额单位、股份单位、FX | 汇率日期与来源 |

同时记录 SBC、SBC/收入、回购授权与实际结算，以判断现金流质量和股本稀释。

跨币种估值必须记录 FX 币种对、汇率、汇率日期、来源 ID 和换算方向。FX 日期原则上等于价格日；若价格日为假日或来源只提供前一交易日，披露偏差。不得使用当前汇率回填历史估值。

## 一致预期

对每个 `[E]` 字段记录：

- 供应商和上游口径。
- 快照日与查询日。
- 预测期间：季度、FY1、FY2 或真正 NTM。
- GAAP、IFRS、调整后或供应商标准化口径。
- 贡献者数量或覆盖度（如可得）。
- 与同行是否采用同一供应商、同一快照规则和同一会计口径。

优先使用真正 NTM。若只有 FY1/FY2，按估值日至财年末的时间权重构造 NTM，并标记 `[D]`；保留原始 FY1/FY2、财年结束日和权重。不得把目标公司的 NTM 与同行的 LTM 放入同一统计，也不得混合不同供应商而不做口径核对。

当供应商之间差异显著时，优先解释口径、快照或异常贡献者。无法解释时保留两组估计，并披露对主倍数和价值区间的影响。

## 股本、回购与股息事件

### 股本与回购

从最近公开的期末或最新股份数出发，逐项核对：

- 基本发行在外股份是否为期末数、加权平均数或实时数。
- 期权是否按库存股法只计入增量股份。
- RSU/PSU 是否按可实现条件和基准日状态计入。
- 可转债是否已经在股本和净债务 bridge 中重复计入。
- 回购是否只是授权、已经执行、已经交割，或属于未完成的 ASR。

只有截至基准日已经回购并结算、且尚未反映在起点基本股本中的股份才从 bridge 扣减。不得扣减未执行授权，不得把 ASR 初始交付和最终预计交付同时扣减，也不得再次扣除已反映在最新股份数中的回购。

### 股息与 BVPS

取得股息类型、每股金额、币种、记录日、除权日、支付日、股东批准状态和会计确认状态。只有同时满足以下条件时，才对用于 P/B 的普通股权益或 BVPS 扣除股息：

1. 价格日不早于除权日，价格已经不含该股息权利。
2. 所用普通股权益或 BVPS 尚未反映该项股息减少。
3. 对应证券和股本口径确有权获得同一股息。
4. 未在其他调整中重复扣除。

会计确认通常取决于宣派或股东批准，而非单纯除权日；因此必须核对报表附注和公司行动公告。若状态不清楚，报告原始与调整后 BVPS 两种口径并做敏感性，不进行无依据的单点扣减。

## 冲突、缺失与降级

发生冲突时：

- 报告值以基准日前已公开的监管文件或正式财报为准。
- 股价以对应证券交易所的历史收盘价为准。
- 股份数以法律发行在外股份与稀释工具 bridge 复核供应商数值。
- 一致预期保留供应商、快照和口径，不用当前估计替换历史估计。
- 无法解释的冲突保留两组数值，并量化对倍数和每股价值的影响。

发生缺失时：

- 先用公司名、ticker、交易所和证券类别重新定位。
- 可可靠推导时标记 `[D]` 并披露公式。
- 不可可靠取得时标记 `NA`，不得猜测。
- 分母为零、负值或经济含义失真时标记 `NM`。
- Core 少于三家或主锚少于三项有效值时降低结论置信度。

只有历史时点无法复原、主锚无法形成有效样本或关键 bridge 无法合理建立时，才停止相应部分或缩小结论范围。

## 跨市场检查

- 不得把同一公司的 A 股、H 股、ADR 和普通股重复作为独立同行。
- 明确 ADR 与普通股换算比例及每股指标口径。
- 在公司本币计算倍数；绝对价值汇总时使用基准日可得汇率并标记 `[D]`。
- 核对中国会计准则、IFRS 和 US GAAP 下租赁、研发、SBC、无形资产摊销、少数股东权益和股息确认差异。
- 对银行、保险和证券公司区分客户资金、监管资本、金融投资和可分配股东权益，不套用工业企业净债务定义。
