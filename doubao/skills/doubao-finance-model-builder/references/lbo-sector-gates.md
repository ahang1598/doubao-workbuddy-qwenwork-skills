# 标准LBO适用性门槛

## 可直接进入标准模型

同时满足以下大部分条件：

- EBITDA为正且口径可重建；
- 自由现金流为正或有可信改善路径；
- 资本开支与营运资本可预测；
- 债务可由经营现金流偿还；
- 进入与退出估值有可比基准；
- 没有使股权价值高度二元化的单一事件。

## 需要专门框架

- 银行、保险、券商：使用资本充足率、账面价值、内含价值或监管资本框架。
- 房地产开发：使用项目现金流、土地储备、预售和NAV框架。
- 早期生物科技：使用研发成功概率和里程碑情景。
- 资源周期公司：加入商品价格、储量和维持性资本开支情景。
- 持股平台与投资公司：使用穿透NAV及控股折价。
- 基础设施与项目公司：使用契约现金流、DSCR和期限匹配。

## 停止条件

关键报表不可得、债务结构无法重建、EBITDA长期为负且无可信改善路径、现金流高度依赖无法建模事件时，停止给出精确IRR。改为说明数据缺口、可行性和需要补充的证据。
