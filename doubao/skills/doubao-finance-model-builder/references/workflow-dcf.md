# DCF 估值建模

## 目标

以时点一致、会计口径一致、来源可追溯、公式可复算和假设可解释为原则，完成非金融上市公司的企业自由现金流（FCFF）估值。把报告事实、分析调整、外部预测、模型推导和自主假设分开，不为贴近市场价格反向选择参数。

## 默认用户体验

- 只把目标证券、估值基准日和重大范围选择视为可能阻塞的信息；其余缺失项采用合理默认值并披露。
- 用户要求“当前估值”时，使用最近一个已完成交易日；不得用基准日后才公开的信息回填历史估值。
- 默认预测 5 年；行业周期、产能释放或商业模式需要时延长至 10 年，直至收入增长、利润率、资本强度和再投资回报趋于稳态。
- 默认采用企业自由现金流（FCFF）、名义现金流、与现金流币种匹配的加权平均资本成本（WACC）、年中折现和戈登永续增长法（Gordon Growth）；对终值另做退出倍数交叉检查。
- 默认生成中文决策摘要、可复算 Excel、标准化输入 JSON、计算输出 JSON、来源台账和模型检查；用户只要简报时仍保留可审计底稿。最终 Excel 审计通过后导入为飞书在线表格交付。
- 所有用户可见内容默认使用简体中文，包括标题、表头、工作表名、场景名、状态、警告、脚注和图表标签；机器接口字段可以保留英文键。
- 首次出现英文金融术语时采用“中文全称（英文全称，英文缩写）：一句经济含义或计算口径解释”；后续可以使用统一缩写。完整读取 `references/dcf-terminology-zh.md`。

执行完整估值前完整读取：

5. `references/dcf-accounting-normalization.md`：中国企业会计准则、IFRS、US GAAP、租赁、股权激励、现金和跨市场股本。

## 工作流

### 1. 锁定证券、时点和范围

确认法定公司名、ticker、交易所、证券类别、主要上市地、ADR 比率、报告币种、估值币种、估值基准日和信息截止日。分别记录价格日、财务期末日、公开日、股本日、汇率日、估计快照日和查询日。

先锁定最近可靠股本披露日，再把该日至估值日定义为强制“公司行动检索窗”。不得因为已有年报股数而跳过估值日前的权益分派实施、送转、拆合股、增发、回购、转换或A/H/ADR变动公告。

识别经济实质。银行、保险、券商及以监管资本而非经营投入资本驱动价值的金融机构不得强行使用 FCFF；停止标准流程，说明应改用股权自由现金流（FCFE）、股利折现或剩余收益框架。房地产、REIT、资源、临床阶段生物科技或控股公司可以做 DCF，但必须说明行业特有调整和辅助估值方法。

### 2. 制定检索计划并取得数据

先完整执行 `references/equity-evidence-acquisition.md`。取得官方基准股本、官方公司行动检索结果和公告正文并保存本地证据后，才能建立股数桥。运行 `validate_equity_evidence.py` 通过前，不得准备 `normalized-dcf.json`、历史财务模型或估值计算。

先按强制读取完整性协议完整读取 `references/source-tool-priority.md`。对每个数据项目优先调用用户明确指定的工具、网站、文件、字段和历史时点口径；用户未指定的项目再优先定位并调用环境中的 `seed_finance_search`，适配实际参数模式，不猜测不存在的字段。指定来源或默认工具不存在、未连接、权限不足或无法覆盖所需字段时，记录实际尝试和降级原因，再按数据能力组合监管文件检索、交易所公告、公司投资者关系材料、官方宏观与市场数据工具；明确披露替代关系和置信度下降，不静默换源，不声称接入不存在的数据源。

先取得原始报表、股本和市场组成项，再自行计算 LTM、净债务、完全稀释股本、WACC 与估值。关键报告值用监管文件、交易所文件或公司正式披露核验。为每个关键字段保存来源编号和 `[R]/[A]/[E]/[D]/[H]` 标签。

来源映射必须逐字段核验实际数值，不以“来源台账非空”代替。价格、股数、汇率、无风险利率、Beta、风险溢价和财务报表分别记录日期；冲突值保留原始记录和选择理由。

股本检索必须覆盖公司行动检索窗，保存公告日、生效日、变动前股数、变动股数、变动后股数、是否计入估值日股数和本地证据ID。只有URL、搜索摘要或自行填写的“无公司行动”不得通过。证据验证后，以不复权近端收盘价乘估值日股数，并与同日独立市值来源反向勾稽；若差异超过2%，返回证据和股数桥排错，不得继续估值。

### 3. 标准化历史财务与价值桥

统一币种、单位、财年、会计准则和符号。至少建立 3 个完整历史年度；周期性或资本密集型公司优先建立 5 年或覆盖一个周期。拆分持续经营与非持续经营、经常性与一次性、经营性与融资性项目。

明确处理税率、折旧摊销、资本开支、营运资本、资本化研发、股权激励、租赁、养老金、少数股东、联营投资、受限现金、超额现金、税损结转和稀释工具。不得把资产负债表现金默认全部视为可扣现金。

### 4. 建立经营预测

先用公司业务驱动预测收入，再预测利润率、税、折旧摊销、资本开支和经营性营运资本。优先使用销量 × 价格、用户 × ARPU、门店 × 单店收入、产能 × 利用率 × 单价或订单 × 转化等可观察驱动；缺少数据时才使用收入增长率。

建立悲观、基准、乐观情景。每个情景同时改变相互关联的经营驱动、利润率、再投资和资本成本，不只调整最终估值。长期增长、利润率、资本周转和再投资率必须向经济可持续稳态收敛。

对收入、利润或估值贡献达到10%的产品、分部或地区分别建立驱动并与公司合计勾稽。每个情景保存叙述、相对基准变化、事实/历史依据、来源ID和失效条件；缺少解释时不得形成情景估值结论。

### 5. 计算 WACC 与终值

按估值币种选择无风险利率，而非按上市地点机械选择。展示无风险利率、Beta、股权风险溢价、国家风险溢价、其他溢价、税前债务成本、边际税率和目标资本结构。Beta 需要时执行去杠杆和重新加杠杆。

同时展示公司基准日实际D/E和估值采用D/E。使用目标或行业资本结构时，记录替代公司实际结构的理由和敏感性；不得把行业数据写成公司披露。WACC只计算一次，摘要、DCF、情景和敏感性均引用同一结果；情景确需改变WACC时必须完整提供该情景的组成项和理由。

终值默认使用 Gordon Growth，并用退出倍数交叉检查。确保 `WACC > g` 且留有合理安全垫；永续增长率不得无解释地高于估值币种长期名义经济增长。分别披露终值占企业价值比例和隐含退出倍数。

终值占比按以下分级处理：不高于75%为常规；75%—85%为警告并扩大敏感性；高于85%必须延长显性期或提供稳态过渡、隐含倍数和充分解释，状态至多为 `INCOMPLETE`；高于90%不得输出点估值结论，除非先重建预测期使其降至90%以内。

### 6. 运行确定性计算

正式任务先按 `references/execution-plan-schema.md` 完成并验证执行计划。计划中分别冻结标准化输入、计算输出、公式工作簿和交付验证文件名；不得在看到估值结果后修改质量门或终值上限。

按照 `references/dcf-input-schema.md` 准备 JSON，然后运行：

```bash
python3 scripts/dcf/calculate_dcf.py normalized-dcf.json --output calculated-dcf.json
python3 scripts/dcf/validate_dcf.py normalized-dcf.json --calculated calculated-dcf.json --output validation.json
python3 scripts/dcf/render_dcf_report.py normalized-dcf.json calculated-dcf.json --validation validation.json --output report.md
```

不得在报告或 Excel 中手工覆盖脚本产生的估值结果。保留未舍入中间值；只在展示层舍入。若 Excel 与脚本不一致，先定位期间、折现时点、终值或桥接差异，不选择性采用更符合预期的结果。

A+H、ADR或多证券类别公司在 `equity_bridge.share_classes` 中逐项记录证券、估值日股数、股数日、不复权价格、价格日、币种、汇率、独立市值和来源。总市值必须为逐证券市值之和，禁止用一种证券价格乘全部股数。资本行动发生时保存从最近可靠股本日至估值日的逐项股数滚存；即使没有公司行动，也必须保存检索范围和“无遗漏”确认。

### 7. 生成 Excel 模型

调用电子表格能力。默认使用 `assets/dcf/dcf-model-template.xlsx` 和确定性公式物化器，不从空白工作簿临时拼装估值结果：

```bash
python3 scripts/common/materialize_formula_contract.py \
  assets/dcf/dcf-model-template.xlsx formula-contract.json dcf-formula-model.xlsx
```

先从同一`normalized-dcf.json`和`calculated-dcf.json`生成`formula-contract.json`、`cell-map.json`和`workbook-contract.json`，再使用OpenPyXL物化公式工作簿；不得把计算结果硬编码为派生值。

无论使用哪种引擎，先从业务字段和公式语义树生成`formula-contract.json`，再冻结模板布局并生成`cell-map.json`。WACC、FCFF、折现、终值、股权桥和每股价值公式不得由语言模型直接手写A1坐标。布局冻结后禁止插行、删行、移动区块或重排关键列；需要调整时从合约完整再生成。

脚本读取标准化输入，填充中文公式模板，逐情景写入收入、利润率、折旧摊销、资本开支、营运资本、其他非现金调整、其他经营性投资、逐年税率、显性期折现时点、WACC、永续增长率、终值折现时点和可选终值FCFF覆盖值，生成全表预览、`workbook-build-audit.json`、`cell-lineage.json`、`run-record.json` 和 `artifact-manifest.json`。`calculated-dcf.json` 为必填；生成器逐项比较基础企业价值/股权价值/每股价值、三情景每股价值和5×5敏感性矩阵，任何差异超过容差即失败。不得把生成器未运行的普通表格称为公式模型。

输入值可以硬编码在黄色假设区，但必须来自标准化输入并带来源或假设依据；缺失的可选输入保持空白，不得为方便计算静默填0。收入、EBIT、NOPAT、FCFF、WACC、折现因子、终值、企业价值、股权价值、每股价值、情景结果及敏感性结果必须是Excel公式。生成器对这些范围执行公式合约检查；发现任一派生单元格被脚本结果覆盖为静态值时直接阻断。正式模型必须以WACC组成项计算，不得直接硬编码最终WACC；直接WACC只允许用于明确标记的示例模型。

当前公式模板接受5期显性预测、5×5敏感性和最多3类证券/3条公司行动。需要更长预测期、其他敏感性维度、更多证券或更多公司行动时，生成器必须明确失败；先扩展生成器和模板并重新运行公式、差分及视觉测试，严禁截断真实记录或静默回退到模板默认值。

保持输入、跨表链接和公式的行业颜色约定：可编辑假设蓝字、同工作簿链接绿字、公式黑字、外部链接红字。所有关键历史输入引用“数据来源”表中的来源编号，预测和估值假设引用“假设依据”表中的假设编号；所有预测列使用可复制的一致公式。“历史数据与口径”披露原始值、调整值、期间、单位、币种、统计口径和调整理由。Excel可见区域只保留必要计算链、口径和来源，不展示WACC、FCFF或终值的教学式推导公式；方法说明放在报告、参考文档或单元格批注，不能替代实际计算公式。

至少包含：“封面”“执行计划”“数据来源”“历史数据与口径”“股本与市值桥”“假设依据”“经营预测”“DCF估值”“敏感性分析”“模型检查”和“术语说明”。“假设依据”逐项展示收入增长、利润率、税率、资本开支、营运资本、WACC组成项和永续增长率的历史区间、业务逻辑、来源编号及失效条件。“股本与市值桥”必须显示公司行动检索窗、逐证券股数与价格日期、不复权口径、独立市值、反向差额及股数滚存。工作表名、状态值和注释不得只使用英文；常用缩写必须在“术语说明”中解释。渲染每个用户可见工作表进行视觉检查，扫描公式错误，并对代表性估值输出追溯公式依赖。

摘要、DCF、三种情景和敏感性不得保存独立硬编码结果。完成Excel后建立 `delivery-audit.json`，完整读取 `references/dcf-delivery-audit-schema.md`。在运行交付验证前，使用生成器输出的 `workbook-contract.json` 直接审计最终Excel：

```bash
python3 scripts/common/audit_formula_workbook.py model.xlsx workbook-contract.json artifact-audit.json --recalculate required
python3 scripts/dcf/validate_delivery.py normalized-dcf.json calculated-dcf.json delivery-audit.json --workbook-audit artifact-audit.json --output delivery-validation.json
```

不得继续使用未带 `--workbook-audit` 的旧命令。直接审计必须验证企业价值、股权价值、每股价值、三情景和5×5敏感性均为公式且与确定性计算一致。

只有 `delivery-validation.json` 为 `PASS` 才能形成估值结论。

### 8. 形成中文投资结论

先给估值区间、基准每股价值、相对当前价格的隐含空间、数据等级和结论置信度，再解释经营驱动、WACC、终值、反向 DCF、情景和风险。把事实与判断分开，避免把小数位数当作精确度。

至少定义三项可观察的模型失效条件，每项包含指标、方向、阈值或时间点、来源和触发后应重做的模型环节。

## 中文化与术语质量门

- 标题和正文先写中文全称，再给必要英文缩写；禁止用缩写堆砌代替解释。
- 报告首次出现 DCF、FCFF、NOPAT、WACC、Beta、ERP、CRP、EBIT、D&A、Capex、ΔNWC、EV、TV、ROIC、ADR、LTM、NTM 或 bps 时，给出一句中文解释。
- Excel 行项目采用“中文全称（缩写）”，场景使用“悲观/基准/乐观”，检查状态使用“通过/警告/错误”。
- 英文 JSON 键、脚本参数和文件名属于机器接口，不直接作为用户可见表头；报告和 Excel 必须映射为中文。
- 英文原始来源标题可以保留，但来源类型、字段含义、警告和结论必须用中文说明。

## 强制质量门

完成原子验证后按`references/model-and-artifact-controls.md`运行统一质量门，工作流参数为`dcf`。G3必须纳入WACC组成与采用值、FCFF、终值、企业价值到股权价值桥、敏感性基准交叉点和三情景一致性；G5的`release-decision.json`未允许结论时，报告不得显示每股价值、目标价、上涨下跌空间或“市场定价合理”。

- 所有输入在估值基准日可得；历史估值未使用未来信息。
- FCFF 与 `NOPAT + D&A - Capex - ΔNWC ± 其他调整` 勾稽。
- WACC 组成项、币种、税率和资本结构可复算；`WACC > g`。
- 预测期足以达到稳态；终值现金流与显性期最后一年无不合理跳变。
- 终值与显性现金流使用一致的折现时点；年中/年末约定已披露。
- 企业价值到普通股权益价值桥接无遗漏或重复计入。
- 合并经营现金流包含非全资子公司时已扣除少数股东权益；不适用时有明确依据。
- 完全稀释股本、ADR 比率、回购和可转证券处理一致。
- 公司行动检索从最近可靠股本日覆盖至估值日；只读取年报或遗漏估值日前公告时为 `FAIL`。
- A/H或多证券股数、价格、汇率和总市值逐项勾稽；股数日为估值日，价格为不复权近端收盘价，资本行动使用估值日已生效股数。
- 每个证券的“股价 × 估值日股数 × 汇率”与同日独立市值来源在容差内一致；价格日之后若发生已生效公司行动则不得通过。
- 敏感性表重新计算底层 DCF，不是对最终价值做静态加减。
- 来源台账能追溯每个关键 `[R]`、`[E]`、`[A]` 和关键 `[H]`。
- 脚本验证无错误；警告已修复或在结论中明确解释。
- 交付审计为 `PASS`；摘要、Excel、报告、情景和敏感性关键结果一致。

## 分析边界

- 不给出自动交易指令，不执行下单。
- 数据等级不足时给区间或方向性结论，不给伪精确目标价。
- 无可靠市场一致预期时建立并标记自主预测，不把模型预测称为“一致预期”。
- 仅当用户提供投资期限、风险承受能力和持仓背景且证据充分时，才给条件化投资建议；否则交付估值判断与监测条件。
