# 目标平台真人验收

填写测试人、日期、系统版本、架构、显示器与缩放比例。每项只标记 `通过 / 失败 / 待确认`，失败附日志或截图路径。

- [ ] 从 `release/*-ready-to-run/` 启动，正常退出、再次启动；没有把 EXE 单独移出目录。
- [ ] 托盘能显示/隐藏桌宠、打开角色面板、关闭鼠标穿透并正常退出。
- [ ] 左键点击与拖拽不混淆；多屏、负坐标显示器、100%/150%/200% DPI 下不跳变。
- [ ] 待机有轻微呼吸，点击有压缩/回弹；脚底不漂移，动作恢复到待机。
- [ ] 右键菜单和面板展示 2–4 个与当前角色匹配的互动；逐项触发真实动作、反馈文案与好感度变化。
- [ ] 联系表中的每个状态都有实际入口；素材目录没有未被引用的交付 PNG。
- [ ] 面板和提醒窗无系统标题栏，圆角、配色、层级、长文案与滚动均正常，无横向溢出。
- [ ] 快捷提醒和自定义时间均可创建；到点弹窗、删除与重启恢复正常。
- [ ] 置顶、贴边、探头状态和桌宠大小设置生效。
- [ ] 文件口袋开启时：拖入文件、同名自动编号、路径正确；关闭时不显示入口也不生成专属素材。
- [ ] 全局打字响应默认关闭；授权后不记录键值；拒绝权限或缺依赖时主程序可用。
- [ ] `release/manifest.json` 的版本、架构、模式、大小和 SHA-256 与实际文件一致。
- [ ] 安装版或便携版按用户选择单独构建；失败时保留 `release/build.log`，未手工压 ZIP 冒充目标产物。
- [ ] 未签名安全警告已在交付说明中明确告知。
- [ ] 60 分钟稳定性：无未处理异常、窗口丢失、监听器泄漏、持续增长的定时器或内存明显单向增长。
