# 短视频脚本需求澄清

## 概述
只负责把不完整的创作请求收敛成可执行 brief，并产出结构化脚本草案。账号长期策略转 short-video-content-strategy；最终视频制作转 doubao-creative-video 或 doubao-creative-drama。

## 使用场景
### 应使用
- 脚本目标明确，但受众、卖点、时长、平台或语气缺失。
- 需要拆解参考文案、PPT、视频或图片后再写脚本。
- 用户反馈后需要保留已确认约束并局部重写。

### 不应使用
- 账号定位、内容日历和长期运营策略。
- 直接生成视频、关键帧或音频。
- 信息充分的短文本润色。

## 核心流程
### 1. 判断脚本类型
区分口播、带货、投流、论坛话术、分镜或参考改写。

### 2. 一次性补齐关键缺口
只追问会改变脚本的受众、目标、卖点证据、平台、时长、风格、禁用词和 CTA。

### 3. 读取参考素材
先读取真实素材，区分可复用结构、必须保留事实和禁止照抄内容。

### 4. 输出结构化脚本
按时间段、画面、台词/字幕、动作、证据和合规备注组织；不写死某个生成模型的版本或参数。

### 5. 迭代与转交
反馈后只改相关约束；需要成片时将确认后的脚本转 doubao-creative-video/drama。

## 工具与协作
- 中文新媒体文档交付可转 doubao-newmedia-writing。
- 视频执行参数以目标视频 Skill 和在线 Tool schema 为准，不在本 Skill 固化。

## 安全边界
- 只陈述已读取、已执行或有来源支持的结果；未验证项必须明确标注。
- 涉及删除、覆盖、发布、系统设置、生产数据或不可逆操作时，先展示目标、影响、回滚方式并取得明确确认。
- 不得记录或输出密钥、Cookie、访问令牌、身份证号、银行卡号等敏感信息；示例使用脱敏占位符。
- 不得编造产品功效、销量、资质、用户证言或品牌授权。
- 参考内容只学习结构和公开事实，不进行近似抄袭。

## 输出与验收
- 创作 brief
- 可拍摄脚本或分镜草案
- 待确认事实和合规风险

## 冒烟用例
### Should trigger
- 先问清受众和卖点，再写 30 秒口播
- 基于这份 PPT 拆解成投流分镜脚本

### Should not trigger
- 给账号做 30 天内容日历
- 直接帮我生成视频

### 边界输入
- 用户只给一句产品名，没有卖点证据和时长
