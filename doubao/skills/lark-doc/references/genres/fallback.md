# 通用在线文档（兜底）

**使用方法**：确认兜底范围 → 明确读者任务与材料关系 → 组织内容并按需选用图解 → 生成后交付。

## 适用范围与路由自检

- 仅在已按 [SKILL.md](../../SKILL.md) 确定由本 skill 交付在线文档，且不匹配现有体裁时使用，例如未被现有体裁覆盖的知识说明、对象介绍、事实脉络整理或材料整合。
- 已匹配某个体裁、但未列出对应细分场景时，仍按该体裁的总原则执行，不转入兜底。
- 本指南不改变交付载体选择；仅创建空文档或原样导入完整内容时，仍按创建工作流的 Shortcut 执行。

## 第一部分 内容组织

1. **明确读者要获得什么。** 先确定核心问题，以及读者需要理解、判断或完成的任务，按实际用途决定内容重点和展开顺序。
2. **按内容关系组织材料。** 识别对象、组成、时间变化、比较维度和作用关系，围绕一条主线整合材料；不按来源顺序逐份摘要，也不强套分析报告、执行方案或传播文案的固定结构。
3. **保留支持理解的必要信息。** 事实、解释、推断与待确认事项清楚区分，保留关键依据、条件和明细；篇幅按创建工作流规划，删除不改变理解的背景、重复结论和无关扩展。

## 第二部分 排版与可视化选用

### 2.1 可视化选用

- 默认使用原生段落、列表和表格；HTML block 仅在[创建工作流](../lark-doc-create-workflow.md) Step 3.2 判断为必要时使用，不因出现流程、比较或数据自动启用。
- 已确定需要图解时，再参考下列选型与排版要求；不按章节设置图数或要求可视化覆盖率。

### 2.2 常见场景与表达分工

| 内容场景 | 确需图解时的表达参考 | 图中必须表达的信息 | 保留的文字或表格明细 |
| --- | --- | --- | --- |
| 知识说明中的概念、分类与边界 | HTML 概念关系图、分类树、对比图 | 概念之间的包含、并列、交叉或区别，以及分类依据 | 准确定义、适用条件、例子与来源 |
| 对象介绍中的组成与运行机制 | HTML 结构图、分层图、机制图 | 对象由什么组成，各部分如何连接、传递信息或共同起作用 | 部分属性、运行条件、具体说明与证据 |
| 事件沿革、人物经历与阶段变化 | HTML 时间轴、阶段演变图 | 关键节点、变化及前后联系；区分时间先后与有依据的因果关系 | 时间、事件细节、出处与必要背景 |
| 地点、实体或设施的空间说明 | HTML 布局图、空间示意图；已有真实地图或原图时优先保留 | 相对位置、区域边界、入口、路径或空间对应关系 | 地点名称、距离、尺寸、使用条件与原始依据 |
| 多来源材料中的对应、交叉印证与分歧 | HTML 材料关系图、证据关系图、时间对照图 | 哪些材料说明同一对象，分别支持什么，差异来自时间、范围还是口径 | 原文、来源、版本、详细比较与未解决分歧 |
| 事实汇总中的数量、变化与构成 | HTML 条形图、折线图、堆叠图、分布图 | 读者需要识别的高低、变化、占比或集中位置；比较基准与统计口径明确 | 精确数值、数据来源、计算方法与限制 |

以上是进入兜底体裁后的表达参考，不作为改判体裁的依据。是否使用图解按创建工作流 Step 3.2 判断。

按材料中真实存在的关系选图：分类依据决定层级，事件时间决定位置，连接表示可说明的关系，数量编码依据可核对的数据。没有数量或精确位置依据时，使用明确标注的结构或空间示意，不补造比例、距离或坐标。

### 2.3 呈现风格

默认使用 `presentation_mode: "rich"`。原生标题与正文组织阅读层级，图解呈现关键关系和数据模式，表格与列表保留查阅明细。图中文字与正文互补，不把长文搬进卡片，也不按章节凑图数。

配色、组件样式和图文分工统一沿用创建工作流；HTML 的文字、布局与交互按 [HTML block 指导](../lark-doc-html-block.md) 执行，不另设一套视觉系统。
