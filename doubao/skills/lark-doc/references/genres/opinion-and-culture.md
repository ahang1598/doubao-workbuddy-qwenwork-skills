# 观点与文化评论

**使用方式：** 先确认评论对象与用户要解决的问题，再按路由进入专项场景；完成后只交付用户需要的成品，不展示内部判断过程。

本指南处理围绕社会事件、公共议题或具体文化作品的解释、评价与评论。核心不是复述材料或堆砌立场，而是基于可确认的事实、作品细节或用户提供材料，形成有依据的理解或判断。

## 第一部分 总原则

### 总原则

1. **判断必须落在明确的对象和材料上。** 新闻、热点评论先确认事件主体、时间、经过、争议与信息来源；文化评论先确认作品、作者或创作者、版本、片段与必要语境。材料不足时，只就已知内容作有限判断，不补造情节、台词、数据、官方回应、作者意图或动机。

2. **把可确认材料与评论判断分开。** 已发生或有公开依据的信息、作品中的具体细节，与对它们的解释、评价和立场不能混写。对尚未核实的新闻信息保留边界；对文化作品的判断，以情节、人物选择、场景、语言、意象、镜头、声音或结构等具体材料支撑。

3. **评论要回答问题，而不是复述对象。** 背景、剧情、案例和外部知识只在帮助回答当前问题时使用。热点解释要讲清事件、争议与具体影响；新闻评论要提出中心观点并说明问题何在；文化评论要说明作品如何产生意义、矛盾或审美效果。

4. **判断可以明确，但不能以空话、煽动或拔高代替论证。** 评论可以批评、反思、推荐或评分，但不能把猜测写成结论，不能以情绪、辱骂、群体攻击或宏大口号代替分析。

5. **深度和形式服从用户任务。** 用户只需快速理解时，优先信息效率，不为“深度”强行扩展；用户要求评论文章、长文或深度分析时，再展开原因、影响、作品细读或必要的现实语境。用户指定字数、平台、语气、角度、材料和禁用内容时，以其为准；未指定时，不为凑篇幅增加背景铺陈、重复结论或与核心判断无关的内容。

## 第二部分 分场景规则

### 路由

下表三类场景提供专项指导，但不是穷举。用户的任务不在表内时，仍适用本部分总原则，并按用户指定的交付形式写作。

| 评论对象与读者任务 | 进入的场景 |
| --- | --- |
| 社会热点、网络事件、民生消费、公共政策或行业争议；读者需要快速看懂、理解争议、获得分析或实用判断 | 社会热点解读与分析 |
| 新闻事件、公共议题或时事材料；读者需要一篇有明确立场和公共讨论价值的评论 | 新闻与公共议题评论 |
| 小说、诗歌、电影、剧集、戏剧、音乐、游戏、展览、动画、漫画等具体文化作品；读者需要解读、评价、比较、评分或评论文章 | 文化作品评论 |

不属于本指南的任务：纯新闻报道、仅作事实查询或时间线整理，不写成评论；产品参数、价格、风险和购买选择为核心的消费评测，进入“分析报告与决策支持”；纯传播文案、活动通知或种草内容，进入“媒体传播”或“营销策划”。

### 社会热点解读与分析

#### 内容规则

- **先匹配任务，再选择写法。** 用户要“发生了什么”“快速看懂”时，按事实顺序讲清事件、争议、具体影响和后续观察点；用户要求“怎么看”“深度分析”时，再依次展开事实与争议、原因或矛盾、影响或风险、出路或边界；用户问普通人怎么办时，给可执行的实用判断。
- **先讲清楚，再表达判断。** 不把“引发争议”笼统带过，要具体说明争议围绕公平、知情、安全、成本、规则、平台责任或其他什么问题；影响要说明影响到谁、如何影响、确定到什么程度。
- **不把所有热点写成社评。** 普通解释型内容少用官腔、宏大升华和抽象概念；结尾回到核心问题、后续观察点或克制判断，不喊口号。

#### 篇幅

- 用户指定字数、平台或交付形式时，以其为准。
- 常规热点分析或观点短文控制在 1,500 字以下。
- 仅在用户明确要求深度评论、公众号长文或申论素材，且材料足以支撑原因、影响和边界分析时，扩展至 2,000—3,500 字。
- 事件简单或用户只需快速理解时，不为显得有深度而扩展制度、产业或社会心理分析。

#### 可视化与排版

- 必须使用 `presentation_mode: "formal"`。
- 以自然段和清楚的小标题组织，便于连续阅读；并列事实、时间节点或比较确需结构化时，可使用列表、原生表或必要图解，不为装饰增加组件。
- 开头直接进入核心问题或判断；需要独立摘要时按通用规则处理，不强制或重复添加 callout。
- 如果用户提供了图片或者搜索信息过程中有相关的典型图片可以用`img`插入。源图片优先按 **1080px 宽**准备，以用户下载清晰；写入飞书云文档时，使用 `<img>` 的 `width` 属性控制显示宽度并保留原始比例。默认文档宽度约 820px，因此封面、横向场景、产品主图和信息图的显示宽度不超过 `800`；竖版使用 `520–680` 内的具体整数；品牌标识、二维码等小型素材按需使用 `240–360` 内的具体整数。
- 用户指定平台发布时，可参考 [`media-and-communication.md`](media-and-communication.md)，按该平台的表达视觉需要调整。


### 新闻与公共议题评论

#### 内容规则

- **事实先于观点。** 不编造新闻细节、当事人身份、官方回应、数据、司法结论或政策内容；不把网传信息、单一信源和对当事人动机的猜测写成确定事实。关键事实不足时，只评论已知材料能够支持的判断。
- **提出明确而可论证的观点。** 评论不能只复述新闻，也不能只说“值得深思”。应说明关键问题、责任边界、读者为何需要关心，以及个案反映的是何种规则、制度、行业或公共讨论问题。
- **让论证递进并回应复杂性。** 可用事实、规则、利益相关者、可靠对比或必要的反方回应支撑中心观点；不把个案无限扩大为对整个群体或行业的结论，不因谨慎而回避基本判断。
- **表达有力度但不煽动。** 不以仇恨、歧视、侮辱、阴谋论或网暴式审判推动文章；避免官话、套话、伪中立和廉价情绪。

#### 篇幅

- 按用户要求输出短评、千字评论、深度评论、口播稿、提纲或标题备选。
- 未指定时，篇幅以把中心观点和必要依据讲清为限，不自动扩写。一般内容不超过 2,000 字。

#### 可视化与排版

- 必须使用 `presentation_mode: "formal"`。
- 评论文章以自然段连续叙述，段落间空行。500 字以内不使用小标题；500 字以上最多使用一层小标题。重点句可少量加粗；不用有序或无序列表、高亮块、引用格式、下划线、表情或花哨色块。
- 如果用户提供了图片或者搜索信息过程中有相关的典型图片可以用`img`插入。源图片优先按 **1080px 宽**准备，以用户下载清晰；写入飞书云文档时，使用 `<img>` 的 `width` 属性控制显示宽度并保留原始比例。默认文档宽度约 820px，因此封面、横向场景、产品主图和信息图的显示宽度不超过 `800`；竖版使用 `520–680` 内的具体整数；品牌标识、二维码等小型素材按需使用 `240–360` 内的具体整数。
- 用户指定平台发布时，可参考 [`media-and-communication.md`](media-and-communication.md)，按该平台的表达视觉需要调整。

### 文化作品评论

#### 内容规则

- **用中心判断统领分析。** 先建立针对当前作品或问题的清楚判断，背景、例子和分论点都服务该判断，不写成散乱的知识介绍、人物标签罗列或剧情梗概。
- **以作品内部细节为主要论据。** 优先使用情节节点、人物选择、关系变化、场景、语言、意象、叙事结构、镜头、声音、表演或媒介形式解释作品；历史、社会、心理学、美学和类型传统等外部知识，只在能解释作品时使用。
- **分析多于复述。** 解读片段或引文时，先交代出处和必要语境，再分析其字词、修辞、语气、节奏、画面或思想情感。比较和评分时，必须给出明确的比较结论、评分或排序，并说明标准和理由。
- **影视评论遵循单一主轴。** 写电影、剧集或影像评论时，只选主题、人物、叙事、视听、类型或现实议题中的一个主分析维度；其余内容只能作为论据。不得为凑字数并列展开多个主题，情节、镜头和台词只用于支撑主轴。

#### 篇幅

- 用户给出字数时，减少背景铺陈，集中回答问题；
- 未指定时，以中心判断得到充分论证为限。影视评论宁可短而集中，也不为凑段数或字数增加过多边界内容。


#### 可视化与排版

- 必须使用 `presentation_mode: "formal"`。
- 以自然段连续论述，默认单栏；标题与小标题按内容层次组织，重点可少量加粗，必要引文使用引用格式。
- 比较或评分需要逐项核对时可使用原生表，行列以必要比较维度为限；结果与依据清楚，不固定列数或行数，也不强制表后再次复述。
- 图片、关系图和其他组件只在帮助理解作品、证据或差异时采用，不增加装饰性卡片和提示框。
- 如果用户提供了图片或者搜索信息过程中有相关的典型图片可以用`img`插入。源图片优先按 **1080px 宽**准备，以用户下载清晰；写入飞书云文档时，使用 `<img>` 的 `width` 属性控制显示宽度并保留原始比例。默认文档宽度约 820px，因此封面、横向场景、产品主图和信息图的显示宽度不超过 `800`；竖版使用 `520–680` 内的具体整数；品牌标识、二维码等小型素材按需使用 `240–360` 内的具体整数。
- 用户指定平台发布时，可参考 [`media-and-communication.md`](media-and-communication.md)，按该平台的表达视觉需要调整。

## 第三部分 交付前检查

### 内容检查

- [ ] 评论对象、材料边界和用户问题已明确；没有编造新闻事实、数据、作品细节、引文、作者意图或评价。
- [ ] 已区分可确认材料与评论判断；新闻或热点没有把未核实信息、猜测和情绪写成事实。
- [ ] 热点解释已讲清事件、争议和具体影响；新闻评论有中心观点、依据和必要复杂性；文化评论以作品细节支撑判断，分析多于背景或复述。
- [ ] 没有用官话、空话、情绪煽动、群体攻击、伪中立或无依据的宏大结论代替论证。

### 格式与视觉检查

- [ ] 已按用户任务和命中场景交付一种合适的成品，未无故同时输出多个版本或暴露内部判断过程。
- [ ] 篇幅符合用户要求；未为凑字数增加无关背景、重复结论或脱离主线的分支。
- [ ] 连贯论述与必要的标题、列表、比较表、引文或图解分工清楚，未以组件形式替代分析。
- [ ] callout 未被当作固定开篇或装饰，使用时符合通用浅灰样式。
