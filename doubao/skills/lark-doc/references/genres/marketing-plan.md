# 营销策划方案

**使用方法**：确认营销任务与交付用途 → 明确业务问题和主要营销链路 → 收集依据并组织方案 → 统筹规划文本排版与强制可视化 → 生成并检查后交付。

**路由条件**：用户需要营销策划全案、品牌认知、产品上市、内容种草、活动战役、增长转化、客户经营、渠道动销或整合营销方案，并期望交付可用于内部研讨、向上汇报、对外提案或拆解执行的完整飞书云文档时使用。

不适用于：单条广告语、标题、海报、口播稿、评论区话术或单篇对外媒体宣传文案。这些成稿应按内容任务选择适用内容 contract；目标为指定平台时，再按照 [`media-and-communication.md`](media-and-communication.md) 中的小红书或者微信公众号排版要求呈现。

## 第一部分 理解内容目标与方案组织内容要求

### 1.1 核心目标：从业务问题到传播与转化闭环

营销策划不是创意、热点或渠道动作的拼盘。先定位业务问题和机会，再明确目标、人群、核心信息、增长路径与资源取舍；最终让读者知道**为什么做、为谁做、做什么、如何推进、投入多少、如何判断有效**。完整方案应支持下一步研讨、批准和执行，而不是停在概念或口号。应通过以下方面定位业务问题：

- 先识别任务（What）、目的（Why）、读者（Who）和深层诉求；围绕人（目标用户）、货（产品/品牌）、场（渠道/场景）形成最小必要假设。
- 预算、时间、资源、KPI、品牌规范、法域与平台规则是硬约束，优先于创意偏好；预算作为投资，区分必须、建议、可选投入，并说明边际效用。
- 策略、排期、承诺和资源规模须符合常识：预留调研、策略确认、物料制作、审核和校准缓冲；不生成伪排期、无责任主体的动作或无法支撑的效果预估。
- 产品优势必须拆为事实证据、用户利益、适用场景、差异化理由与可转述话术；不以泛化形容词或营销黑话代替购买理由。

### 1.2 先选择主要营销链路

| 营销链路 | 方案应优先解决的问题 | 重点输出 |
| --- | --- | --- |
| 品牌认知 | 让谁记住什么主张，凭什么相信 | 定位、核心主张、品牌资产、传播路径 |
| 产品上市 | 为什么现在购买，如何完成首发转化 | 卖点翻译、首发节奏、首购机制、渠道承接 |
| 内容种草 | 如何进入目标人群的真实场景与讨论 | 内容切口、内容矩阵、KOL/KOC 分层、平台分工 |
| 活动战役 | 如何预热、引爆、承接并延续 | 核心事件、机制、阶段节奏、互动与转化链路 |
| 增长转化 | 漏斗哪一环最值得优化 | 流量来源、关键动作、ROI、测试与迭代 |
| 客户经营 | 如何提升留存、复购与转介绍 | 用户分层、生命周期触达、权益与复盘指标 |
| 渠道动销 | 如何让渠道和终端共同完成销售 | 渠道分工、终端物料、激励、线上线下协同 |
| 整合营销 | 多模块如何围绕同一目标协同 | 总策略、资源统筹、预算大盘、组织推进 |

用户同时命中多个链路时，以整合营销统筹，但必须明确主战场和优先级，不能平均铺开。

### 1.3 行业与品牌调性适配

- 快消、食饮、美妆：场景驱动、情绪共鸣、种草与即时转化；强调高频触达、视觉体验和热点/内容效率。
- 3C、家电、耐消：产品参数的用户化翻译、专业背书和长决策链信任；强调比较、案例与售后保障。
- 互联网、平台：以拉新、留存、裂变和行为漏斗为核心；强调指标拆解、路径优化与实验。
- B2B、企服：以多角色决策链、线索孵化和专业背书为核心；强调内容体系、案例、销售—市场协同。
- 本地生活、零售、餐饮：以商圈、社群、到店核销和即时行动为核心；强调利益点、信任与区域协同。
- 文旅、娱乐、IP：以体验、情绪价值、社交货币和 UGC 裂变为核心；强调话题、共创和跨界联动。
- 医疗、教育等强合规行业：以用户教育、权威背书和风险控制为核心；不得夸大承诺或使用煽动性表达。

行文同时适配业务规模：小微商家聚焦低成本试错和单点转化；成长品牌强调资源取舍、品效协同和可复用资产；大型企业强调跨部门协同、里程碑、风险预警与预算管控。品牌调性一经确定不得漂移：高端克制，年轻鲜活，B2B 理性，本地生活亲和，强合规行业审慎。

## 1.4 资料收集：搜索、竞品与热点

完整方案默认检索并核验目标竞品近期营销动作、传播打法和市场反馈；用户已经提供充分可信的竞品材料时，仅补充核验。平台规则、行业政策、节点节庆、价格、产品配置/成分、门店和专业知识等时效或精确事实必须联网核实；纯框架梳理、内部逻辑搭建且不涉及上述信息时，不强制检索。

涉及热点、借势、流行内容或圈层话题时，检索近 3 个月内真实、可查且与方案相关的内容，并从人群、内容形式、情绪文化、审美趋势、时间节点、营销转化六个视角寻找线索。检索目标是形成洞察、机会、风险或可执行动作，不是堆砌新闻。

- 根据种草/带货、破圈/涨粉、热点借势、品牌曝光、新品上市或渠道动销，分层检索竞品动作、用户痛点、爆款案例、内容/视觉范式、转化机制与渠道玩法。
- 优先检索平台和行业真实案例；官方平台、主管部门、品牌官方渠道用于事实与授权核验，第三方榜单/数据工具只用于补充。
- 热点需记录账号、标题、平台、链接与时间，仅作为内部证据；除非用户要求，不把检索过程、原始链接或“某博主/爆款”泛称写入成稿。
- 不编造传播数据、短链、价格、产品、案例或平台规则；无法核验的数据标记为待补，不据此下确定结论。
- 不借势政治敏感、灾难事故、争议社会事件、违法违规、低俗擦边、医疗金融夸大或品牌高风险热点；无法自然转化为核心信息、内容选题、视觉符号、渠道玩法、促销机制或互动话术的热点不使用。

## 1.5 方案结构与内容要求

从业务问题起手，按 **背景与机会 → 目标与判断指标 → 核心策略 → 传播/渠道与内容动作 → 节奏与资源 → 预算 → 效果评估与下一步** 组织。目录随业务调整，不机械照搬；完整方案须形成从策略到执行的闭环。

1. **背景与机会**：只分析直接影响项目的宏观变量、行业/市场、竞争、消费者与企业自身，归纳“最需要解决的问题”和“最值得抓住的机会”。
2. **目标与指标**：目标清晰、量化、可拆解、可验证；区分经营、转化、传播、互动、流量等指标，并让每项动作服务一个明确目标。
3. **营销策略**：回答在哪打、打给谁、怎么配、凭什么、怎么转；可按需使用 STP、4P/4C、AIPL、AARRR、IMC、RFM 等方法，但方法名不能代替判断。
4. **传播策略**：建立“一条主信息 + 多条支撑信息”；为消费者、媒体、达人、渠道伙伴、内部员工明确不同沟通任务，统筹自有、付费、赢得媒体及事件、话题、达人、共创、搜索和私域承接。
5. **排期与执行**：按筹备、预热、引爆、转化、延续、复盘安排节奏；明确里程碑、任务依赖、负责人、交付标准和风险缓冲。
6. **预算与效果预估**：按目标倒推，拆分调研、创意制作、媒介投放、达人、公关活动、促销、技术和数据等投入；说明渠道成本、用户质量、转化效率与长期价值，建立传播、互动、流量、转化、经营五层指标及动态调整机制。
遵循用户要求与通用篇幅规划，完整覆盖当前营销任务，不为“全案”补齐无关章节，复杂执行明细按需要展开。**一般没有用户明确要求的情况下，篇幅以3000-5000字左右为宜。如果超过这个数值，需要在`outline.md`说明理由。**

- 不得：把无证据的“最佳、第一、保证、稀缺”写成主张；隐藏价格、资格、期限、自动续费或限制；伪造库存、倒计时、评价、案例、引语、图片或活动结果；用复杂视觉掩盖价值和证据缺口。
- 外部事实、数据、竞品动作、产品信息和政策依据统一在文末以灰色“资料与数据来源”区列出来源机构、页面/报告名称和核验日期。需要保留可点击来源时，使用 `<a type="url-preview" href="URL">来源名称</a>`，不自行发明普通链接语法。
- 方案建议、目标值、预算比例和 ROI 测算须明确为建议、目标或假设，不可直接写为事实。


## 第二部分 排版与强制可视化要求

### 2.1 强制可视化要求

- **只要文档内容涉及流程与顺序、比较、构成或分布、机制、架构、空间结构、趋势、预测，或者定量分析与多因素分析，就应默认采用可视化表达，并将其视为强制要求，优先使用 HTML block。**
- 这也适用于对材料、文档、报告、表格和附件进行解读、分析或总结：应主动提取其中的关键关系、模式、差异与结论并进行可视化，无需用户另行提出画图要求。后续内容调整时同步更新。
- **命中触发条件时，最终文档必须实际呈现承载核心关系、证据、步骤或结论的可视化。** 文字、表格和列表可以补充，但不能替代已触发的可视化交付；品牌配图或装饰性图片不能替代策略关系与数据模式的表达。
- 本体裁完整执行[创建工作流](../lark-doc-create-workflow.md) Step 3.1—3.4，统筹选择文本排版组件与可视化组件；两类组件都适合时，优先使用可视化组件。具体例外、选型、图文分工、制作要求、通用视觉样式与大纲记录均按创建工作流执行。

### 2.2 营销常见场景与表达分工

| 内容场景 | 优先可视化表达 | 保留的文字或表格明细 |
| --- | --- | --- |
| 市场差异、竞品定位与机会判断 | HTML 对比图、定位矩阵；定位轴须有依据 | 产品特点、比较口径、证据与来源 |
| 营销目标、策略与动作的承接关系 | HTML 目标拆解图、策略关系图 | 目标定义、策略依据、动作说明与指标 |
| 目标人群、需求场景与触点路径 | HTML 用户旅程图、触点路径图 | 人群特征、需求证据、触点内容与承接方式 |
| 内容传播、渠道分工与线上线下协同 | HTML 泳道图、关系图、汇合图 | 渠道职责、内容清单、负责人和交接要求 |
| 获客、转化、留存、复购与转介绍 | HTML 流程图、循环图；有可核对数量时使用漏斗图 | 阶段定义、转化条件、运营动作和测算假设 |
| 活动阶段、任务排期与依赖 | HTML 时间轴、甘特图 | 日期、负责人、交付物、验收标准和风险缓冲 |
| 预算分配、资源投入与配置重点 | HTML 条形图、堆叠图；涉及有数量依据的资源流转时可用桑基图 | 金额、单价、数量、用途、测算依据和预算明细 |
| 效果评估、实验对比与目标偏差 | HTML 趋势图、对比图、目标对照图 | 指标口径、数据来源、样本、归因限制和调整动作 |

以上用于识别常见可视化机会，不要求每篇覆盖全部场景，但是出现这些机会的时候必须使用html；未列出的内容仍按创建工作流 Step 3.2 判断。

### 2.3 营销文档的补充要求

- **策略关系需要可见**：呈现目标、动作、渠道与转化之间的实际联系；总览应让读者看清方案如何起作用，正文各部分共同支撑同一业务目标。
- **全文保持统一视觉方向**：配色与强调方式贯穿文本排版组件和可视化组件，同一渠道、阶段、指标或策略在图文中保持同名、同口径。
- 禁止在全文多处使用彩色的 `callout`，默认只能在标题后使用一个；样式按创建工作流执行。
- **禁止在 HTML block 中使用 emoji。**
