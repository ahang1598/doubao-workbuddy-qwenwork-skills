# 教学与学习支持

- **工作主线**：1. 完整读取材料并确认事实与学习边界 → 2. 选择子类型、读者任务和学习目标 → 3. 规划内容、任务、评价与必要图示 → 4. 选择并应用模板或通用 DOCX 格式 → 5. 检查内容覆盖、学习有效性与版式。

## 路由条件与子类型

命中：只要主产物是教学方案、教案、公开课或说课材料、单元设计、导学案、课程或讲义，并且其核心任务是帮助学习者或培训对象学习、练习、掌握、评价或改进，就进入本领域；读者可以是学生、教师、教研人员、教育评审人员或企业培训对象。

不命中：市场、行业、经营和竞品研究不因含有“课程”或“调研”字样进入本领域；仅提取、转换、排版或摘要材料而不新建实质内容时，不进入本领域；其他情况返回 [`Word 写作分类指导`](writing-taxonomy.md) 重新判断。

先完整读取用户附件，再执行本文件的共性规定和子类型选择；不要只凭文件名、题目标题、年级或用户的一句描述路由，也不要先套教案、试卷或学习计划结构。

| 路由类型 | 子类型 | 适用任务 |
|-|-|-|
| 教学与学习支持 | 教学设计与课程材料 | 教案、公开课、说课、单元设计、导学案、课程建设、课程讲义、教研材料 |
| 教学与学习支持 | 学习、练习与评价支持 | 学习计划、复习笔记、练习题、试卷、答案解析、作业讲评、成绩分析、知识体系图 |

在内容规划中关注子类型、读者任务、范围、证据使用、目标与路径一致性、可视化需求和交付前检查。用户指定有效 DOCX 模板时，保留模板格式与结构，但模板不能取代本文件的内容判断。

## 高优先级原则：附件先读透，再设计交付

1. **读取用户材料是具体事实的基础**
- 用户上传或提供的一切材料是本次任务的第一手事实来源，优先级高于联网搜索和先验知识。附件中的关键信息常藏在图、表、公式里，仅靠文本提取会丢失；如果之前读取附件时只获得了文本信息或没有读取附件，必须再次解析。
  - **禁止只用摘要替代附件信息细节**：用户附件不能只在任务开始时被概括或摘要。开始写作前，必须回到原始附件核对将要采用的细节，避免因早期压缩理解而遗漏限定条件、数据口径、图表信息、例外情况或原文措辞。
  - **完整读取**：DOCX、PDF、图片和表格均须读取其文字与视觉信息；图、表、公式、扫描页、批注和嵌入对象中的相关内容不得因初步提取而遗漏。
  - **DOCX 附件**：必须按正文顺序读取段落、表格内容及表格的物理单元格、逻辑列和合并关系；再运行摘要并按提示读取页眉页脚等部件。文本框、内容控件、嵌套表格、图片表格、浮动对象和扫描页必须结合逐页视觉检查，不能仅凭结构化提取认定已读完整。
  - **PDF 附件**：必须提取文本，并盘点页面视觉对象，渲染或查看每页；含图表、表格、图片或扫描信息的页面必须查看清晰页面图。
  - **图片/表格**：插入 Word 时必须保留原图表的所有信息，不允许裁剪，但可以缩放大小来适配排版布局。

2. **多附件信息处理**：
  - **附件角色**：**多附件时**，先明确每份材料的用途。模板只决定结构和格式；上下文材料用于理解任务背景；素材和事实材料用于支持具体内容；示例只用于学习结构、粒度或表达。
  - **按问题整合**：不要按附件顺序分别摘要或写作。应围绕同一对象、时间、事项或结论，将分散在不同附件中的相关信息匹配、补全和整合。
  - **冲突处理**：附件信息不一致时，先区分其对象、时间、地区、口径和角色；不能确认时明确保留差异或待确认，不得自行拼接、混算或选择性采用。

3. **超长附件处理**：用户上传整本教材、整套试卷、完整教辅或长篇 PDF，并要求“根据文件/书中内容”生成时，必须完整阅读与任务相关的文字、图片、表格和题目，先建立材料索引：已学内容、待学内容、知识点、题目、数据、能力差异和可复用素材分别在哪里。不得只读目录、首页、少量段落或已提取文本，就用年级、学科常识补写通用内容；也不得按附件顺序复述而遗漏用户指定范围。

4. 在创建文档前，必须完成附件中嵌入文字、图片、表格等信息的完整阅读；生成后回查用户要求的范围是否均有附件依据，并记录实际采用位置和有理由的排除项。

## 顶层目标与内容质量

写作目标是让读者能直接完成学习、教学、诊断或改进任务，而不是套出一份“看起来完整”的教案、试卷或计划。动笔前只需想清楚：

1. **读者最后要做到什么**：要掌握、讲清、解决、完成、判断或改进什么？
2. **材料真正提供了什么**：哪些具体内容、题目、数据、图片或学情必须进入交付，哪些事实不能补造？
3. **怎样证明这份文档有用**：读者能通过什么任务、答案、作品、操作、评价依据或下一步行动得到结果？

以此选择子类型、内容、图示和格式；不能因已有模板或常见栏目反向填充。全文保持高信息密度：每段推进新的事实、判断、方法、证据、示例、行动或限制，段间有清楚的逻辑关系；重复、套话、空泛目标和不能回答读者“所以呢”的内容应删去。

## 长篇材料的全局导航

当产物是单元复习、课程讲义、成套学习资料、完整试卷讲评、多课时教学设计，且存在三个及以上实质内容单元时：

1. 正文开头先用简短导语说明对象、范围、使用方式和推荐阅读或学习顺序；
2. 给出一个全局路线，使读者先理解各部分关系，再进入分项内容；
3. 知识递进或概念关系使用知识地图、概念图或流程图；阶段安排使用时间轴或阶段表；题型、任务或知识点覆盖使用总览表或矩阵；
4. 只有简单阅读提示时，用一段“本材料按……组织”的说明即可；不得用线性标题列表冒充关系图；
5. 进入一个大模块前，只有该模块包含三个及以上下级单元，或内部存在明确学习顺序、判断逻辑时，才增加一至三句模块导语或小型关系图。不得为每个知识点重复写概览。

短教案、单页讲义、少量习题、约百字的计划/总结和用户明确要求简洁的产物不强制增加导语、路线图或目录。

## 子类型 1：教学设计与课程材料

### 路由条件

用于教学方案、教案、一节课、一组课、单元、公开课、说课、导学案、课程建设方案、课程讲义或教研材料。课程建设方案、培训方案或教案类交付物，只要核心是目标、内容、活动、学习支持和评价设计，均进入本领域；只有核心是招生、预算、师资、场地、采购、排期或组织执行时，才进入 [`企业和职场文书`](workplace-formal-documents.md)。若同时要求课程教学设计，分别规划两个交付部分，不能用其中一方替代另一方。

### 目标

帮助教师或学习者围绕具体内容达成明确、可验证的学习结果，并提供足以直接实施或使用的材料、任务和证据。先简明说明：学习者完成后能做什么、如何证明做到、材料显示的关键起点或障碍、以及为什么选择这一路径。目标不是“讲完本课”或“开展活动”，也不要求把这四项写成固定章节。

### 内容规划

先按“目标结果 → 达成证据 → 起点与障碍 → 学习路径”组织，再判断交付深度；不要把规范教案的全部栏目当作每一次交付的默认目录。

- **简案、家教备课、单课提纲**：说明学习者本次要完成什么、用什么材料或任务达成、怎样快速确认是否掌握即可；不补写完整学情分析或大表格。
- **详细教案、公开课、说课**：在必要时补充内容在单元中的位置、学生已有基础与可能卡点、目标、学习任务、支架、评价证据和延伸。内容分析应说明本课承接什么、解决什么难点、为后续什么铺垫，而不是复述教材目录；活动设计应解释“为什么这样安排能帮助学生达成目标”，而不是只罗列教师话术。
- **单元/课程建设与课程讲义**：先给学习者看见总目标、阶段关系和每阶段可验证成果，再展开课次、材料、练习和反馈。阶段不必均分，详细程度服从用户要解决的重点。
- **教研计划、总结或反思**：围绕真实问题、实践、证据、发现和调整组织；没有真实课后记录时，不得写成已验证的成效。

表格优先用于课程、阶段、知识点、目标或评价的**总览和对照**。教学过程可用表格呈现简明环节概览；当过程需要写清探究、游戏、故事、项目、语言互动或实验推理的具体展开时，优先改用连贯分段、阶段卡或“任务—支持—证据”短条目，避免以冗长的“教师活动—学生活动”表格替代设计本身。简案、复习课和短活动可只写“本段目标 + 学习者任务 + 必要支持或观察点”。活动数量和环节名称由目标决定，不能为了完整性机械补导入、总结、作业等环节。

无论采用何种形式，每个实质活动至少能看出：学习者做什么、教师或材料提供何种必要支持、产出什么可见证据；“教师讲解/学生讨论/观看视频”本身不能作为活动价值的说明。

### 可视化与表格

| 信息关系 | 推荐呈现 | 使用条件 |
|-|-|-|
| 单元知识结构、概念联系 | 知识地图、概念图 | 用户需要理解前后联系或概念关系 |
| 多课次课程设计 | 课次总览表、阶段时间轴 | 有明确课次、阶段或时间安排 |
| 目标、活动、评价证据对应 | 对应表 | 多项目标需逐项核对，避免目标悬空 |
| 课堂任务递进 | 流程图 | 顺序、分支或任务衔接本身影响理解 |
| 板书、实验、操作过程 | 板书示意、步骤图 | 图示能降低文字歧义，不替代必要文字说明 |
| 教材图片、学生作品、实验素材 | 原图插入并配简短说明 | 图片承担教材或事实证据职责；不得裁剪信息 |

先明确“不需要视觉化”或“需要什么图、它帮助学习者看见什么关系、放在何处”。按内容选择，而不是按版式凑图：叙事、语文、历史或道法的结构、时序和观点推进，可用提纲式结构图、时间轴或因果链；数学、物理、化学及地理的规律、推导、数量或空间关系，可用公式关系图、数轴、模型图、实验装置图、数据图或地图；生物、科学、信息科技的系统、分类、因果或包含关系，可用概念网络、结构图或流程图。文档本身需要读者借图理解，或用户要求附图、图片、教具、课件或可直接使用素材时，生成并插入相应图片；普通教案仅提及使用图片、地图或模型时，说明它服务的学习任务即可，不强制附入。

### 总览图优先，局部支架按需

先判断读者是否需要在进入细节前看见整体关系。命中下列任一条件时，明确图名、帮助读者看见的关系和放置位置，并在正文实际插入对应图片：三个及以上相互关联的单元、课次或知识模块；空间方位、结构关系、因果过程或操作步骤是核心学习难点；用户明确要求附图、课件、可打印材料或知识体系图。其余情况按读者任务判断是否需要图；不插图时，确认文字或实物教具已足以支持理解。图应替代或压缩一段以上的关系说明，不能只是把目录画成图。

再判断某一局部是否存在必须借图理解的卡点；只有图能明显降低理解或操作难度时，才在相关内容旁加入一张局部支架图。每张图只回答一种关系，先确定中心对象、节点文字、节点关系和颜色含义：

| 内容关系 | 图形模板 |
|-|-|
| 先后步骤、操作顺序 | 横向或纵向流程图 |
| 概念包含、分类、单元结构 | 树状图、概念网络或知识地图 |
| 因果、条件、判断路径 | 单向因果链、条件分支图 |
| 空间方位、区域位置 | 地图、方位箭头或区域示意图 |
| 周期或循环过程 | 环形流程图 |
| 多模块整体关系 | 中心主题加分支的总览图 |
| 多方案或多对象比较 | 对照表，不强行画流程图 |

视觉也可以作为**最小有效支架**：仅当抽象概念、运算原理、空间方位、操作顺序或表达组织成为明确学习卡点时，选择一至两种最能解决该卡点的图示、数轴、结构图、面积模型、步骤图或句式框架；不能因“更好看”堆叠多种图。学习者能够独立理解时，减少支架；不能只写“见图”或用线性标题代替真实图示。文字解释足以完成目标时不强行加装饰图。

### 图表与图示配色

所有图表、地图、流程图、概念图和结构图必须先说明颜色分别表示什么；颜色只编码类别、状态、先后、风险或重点，不承担装饰。默认采用“浅底 + 深色正文/轮廓 + 1 个强调色 + 必要时 1 个辅助色”，保持打印可读，并同时使用文字标签、线型或形状，不能只靠颜色区分。

- **理科、数据、公式关系**：深靛蓝 `#1A2E4B` 为主，冷灰底 `#F0F2F5`，强调橙 `#E8720C`；用深色表示主关系，橙色只标关键变量、异常或结论。
- **人文、叙事、历史与道法**：墨黑 `#2B2B2B` 为主，暖白底 `#FAF7F2`，赭石 `#9C5C38` 标出关键节点或论证转折。
- **生物、科学、地理与环境**：深绿 `#2F4A3B` 为主，浅草底 `#F3F7F0`，土黄 `#C8A44A` 标出重点；地图可额外用低饱和蓝 `#5A8FB8` 表示水域或流向，并配图例。
- **小学及低龄学习材料**：可在上述主色外加入不超过两种低饱和辅助色，但仍保持深色文字和清晰轮廓；不用彩虹配色、渐变、荧光色或只靠色块传达答案。

图表必须保留标题、标签、必要单位/时间范围、图例与来源；删除不承担阅读意义的网格线、阴影和装饰。无可靠数据时只画明确标注为“示意”的结构图，不生成看似精确的数据图。

## 子类型 2：学习、练习与评价支持

### 路由条件

用于学习计划、复习材料、知识整理、试卷、练习、答案解析、作业讲评、成绩诊断、评分量规和思维导图。仅提取、转换、排版或摘要材料时不进入本题材。

### 目标

帮助学习者获得可执行的掌握路径，或帮助教师、家长和学习者准确判断掌握情况并采取下一步行动。学习计划要落到阶段成果和调整依据；讲义、练习和试卷要落到可核验的理解与答案；评价或成绩分析要落到真实数据支持的发现和对应改进，不能停留在知识罗列、题目堆砌或泛化评语。

### 内容规划

- **学习计划**：先写清最终能做到什么、当前基础和可用时间，再安排阶段任务与可验证成果；根据范围、考试节点或掌握情况安排复盘、检测和缓冲，不机械套用固定比例、每日时段或学习法。每天任务只保留完成当日目标所需内容，计划要能据完成情况调整。
- **复习笔记或讲义**：范围与使用方式 → 知识全局路线 → 知识点/例题/易错点 → 练习与答案。知识点较多时，先让读者看见递进顺序和薄弱点定位方式。
- **试卷或练习**：先核对年级、范围、题型、数量、难度和要检验的能力，再生成题目、答案及必要解析或评分依据；不把通用题目替代用户附件指定的题目范围。题目难度的变化应服务同一能力目标，而不是把不同学生固定归类。
- **作业讲评**：题目或情境 → 思路/示范 → 常见错误 → 迁移练习。存在多种合理答案时说明判断依据和可行变体。
- **成绩分析**：数据范围与口径 → 总体与分项发现 → 可验证原因 → 学习或教学调整。缺少数据不能写成确定的成绩结论。
- **知识体系图**：中心主题 → 分支概念 → 关系和例子；用户明确要求思维导图、概念图或关系图时，必须交付真实图形化关系，不能用线性标题列表替代。

### 可视化与表格

| 信息关系 | 推荐呈现 | 使用条件 |
|-|-|-|
| 学习路径、复习周期与阶段成果 | 阶段表、时间轴 | 用户给出周期、投入或明确阶段目标 |
| 知识点的包含、并列、因果或步骤关系 | 思维导图、概念图、流程图 | 用户明确要求图示，或关系图明显优于线性文字 |
| 题目与知识点、能力目标的覆盖关系 | 题目—知识点矩阵 | 题量或知识点较多，需要检查覆盖和遗漏 |
| 分数、正确率、能力维度诊断 | 条形图、分布图、对照表 | 有可核验的真实数据、单位和范围 |
| 解题、实验或写作过程 | 步骤图或编号流程 | 顺序或分支会影响完成结果 |
| 评分、观察与反馈标准 | 评分量规表、观察记录表 | 需要多人一致评价或学习者自查 |

图表与图示遵循本文件“图表与图示配色”要求：以颜色表达关系，保留文字标签与图例，不能仅靠颜色区分。无可靠数据时不生成带精确数值的图表；短而结构明确的材料优先用正文、短列表或顶格加粗标签，不为“目标、内容、练习”逐项设置 Heading。

## 通用 DOCX 格式配置
- **格式优先级**：前述“Word 格式”中的条款结构、签署区、目录、封面、标题颜色和页眉规则，是本文件对一般格式要求的明确覆盖，应优先执行。用户明确要求、有效模板、组织规范或法定文种要求与本文件或一般格式要求冲突时，按 [`Word 写作分类指导`](writing-taxonomy.md) 中的“格式规则优先级”处理。

- 一般格式要求：除上述明确规定的项目外，必须完整读取 [`writing-taxonomy.md`](writing-taxonomy.md) 中“## 一般Word排版格式要求”及“## 交付前回读与校验”；除本指南明确覆盖的项目外，按其中规则执行

- 一般情况下，除非用户有明确要求，这类文档超过5页时可以添加页码显示，具体方式按照“一般格式要求”执行。

## 交付前检查
- 用户要求的对象、学段、主题、附件范围、题目数量、答案、字数、图示与交付形态均已满足；
- 目标结果、达成证据、起点/障碍与学习路径一致：没有把活动、教材标题或教师行为当作目标；分层时没有降低共同核心目标或给学习者贴固定标签；
- 结构与任务匹配：简案不膨胀，长课程或长讲义有全局导航，试卷不缺答案，思维导图不退化为标题列表；
- 图表、表格和图示均有信息职责；标为需要插入的图，成品正文中必须存在实际可见且可阅读的对应图片，不能以“出示某图”“见图”或板书文字代替；普通教案中仅提及图片、地图或模型时，已说明其服务的学习任务；没有可靠数据时不虚构数值图；
- 教学过程的呈现方式与读者使用任务相符：不存在把长段教学过程固定塞进表格、为短标签滥设 Heading，或为了凑完整结构新增无目标的环节；
- 完成后进入通用 Word 格式回读，检查真实 Heading、黑色标题、编号层级、表格分页、图片完整性及目录触发条件；
- 长文或正文超过 5,000 字时，按通用格式规则生成可刷新的 Word 原生目录。
