# 营销策划方案

**路由条件**：用户需要营销策划全案、品牌认知、产品上市、内容种草、活动战役、增长转化、客户经营、渠道动销或整合营销方案，并期望交付可用于内部研讨、向上汇报、对外提案或拆解执行的完整飞书云文档时使用。

## 目标：从业务问题到传播与转化闭环

营销策划不是创意、热点或渠道动作的拼盘。先定位业务问题和机会，再明确目标、人群、核心信息、增长路径与资源取舍；最终让读者知道**为什么做、为谁做、做什么、如何推进、投入多少、如何判断有效**。完整方案应支持下一步研讨、批准和执行，而不是停在概念或口号。

### 静默判断与硬约束

- 先识别任务（What）、目的（Why）、读者（Who）和深层诉求；围绕人（目标用户）、货（产品/品牌）、场（渠道/场景）形成最小必要假设。
- 预算、时间、资源、KPI、品牌规范、法域与平台规则是硬约束，优先于创意偏好；预算作为投资，区分必须、建议、可选投入，并说明边际效用。
- 策略、排期、承诺和资源规模须符合常识：预留调研、策略确认、物料制作、审核和校准缓冲；不生成伪排期、无责任主体的动作或无法支撑的效果预估。
- 产品优势必须拆为事实证据、用户利益、适用场景、差异化理由与可转述话术；不以泛化形容词或营销黑话代替购买理由。

### 先选择主要营销链路

| 营销链路 | 方案应优先解决的问题 | 重点输出 |
| --- | --- | --- |
| 品牌认知 | 让谁记住什么主张，凭什么相信 | 定位、核心主张、品牌资产、传播路径 |
| 产品上市 | 为什么现在购买，如何完成首发转化 | 卖点翻译、首发节奏、首购机制、渠道承接 |
| 内容种草 | 如何进入目标人群的真实场景与讨论 | 内容切口、内容矩阵、KOL/KOC 分层、平台分工 |
| 活动战役 | 如何预热、引爆、承接并延续 | 核心事件、机制、阶段节奏、互动与转化链路 |
| 增长转化 | 漏斗哪一环最值得优化 | 流量来源、关键动作、ROI、测试与迭代 |
| 客户经营 | 如何提升留存、复购与转介绍 | 用户分层、生命周期触达、权益与复盘指标 |
| 渠道动销 | 如何让渠道和终端共同完成销售 | 渠道分工、终端物料、激励、线上线下协同 |
| 整合营销 | 多模块如何围绕同一目标协同 | 总策略、资源统筹、预算大盘、组织推进 |

用户同时命中多个链路时，以整合营销统筹，但必须明确主战场和优先级，不能平均铺开。

### 行业与品牌调性适配

- 快消、食饮、美妆：场景驱动、情绪共鸣、种草与即时转化；强调高频触达、视觉体验和热点/内容效率。
- 3C、家电、耐消：产品参数的用户化翻译、专业背书和长决策链信任；强调比较、案例与售后保障。
- 互联网、平台：以拉新、留存、裂变和行为漏斗为核心；强调指标拆解、路径优化与实验。
- B2B、企服：以多角色决策链、线索孵化和专业背书为核心；强调内容体系、案例、销售—市场协同。
- 本地生活、零售、餐饮：以商圈、社群、到店核销和即时行动为核心；强调利益点、信任与区域协同。
- 文旅、娱乐、IP：以体验、情绪价值、社交货币和 UGC 裂变为核心；强调话题、共创和跨界联动。
- 医疗、教育等强合规行业：以用户教育、权威背书和风险控制为核心；不得夸大承诺或使用煽动性表达。

行文同时适配业务规模：小微商家聚焦低成本试错和单点转化；成长品牌强调资源取舍、品效协同和可复用资产；大型企业强调跨部门协同、里程碑、风险预警与预算管控。品牌调性一经确定不得漂移：高端克制，年轻鲜活，B2B 理性，本地生活亲和，强合规行业审慎。

## 资料、竞品与热点

完整方案默认检索并核验目标竞品近期营销动作、传播打法和市场反馈；用户已经提供充分可信的竞品材料时，仅补充核验。平台规则、行业政策、节点节庆、价格、产品配置/成分、门店和专业知识等时效或精确事实必须联网核实；纯框架梳理、内部逻辑搭建且不涉及上述信息时，不强制检索。

涉及热点、借势、流行内容或圈层话题时，检索近 3 个月内真实、可查且与方案相关的内容，并从人群、内容形式、情绪文化、审美趋势、时间节点、营销转化六个视角寻找线索。检索目标是形成洞察、机会、风险或可执行动作，不是堆砌新闻。

- 根据种草/带货、破圈/涨粉、热点借势、品牌曝光、新品上市或渠道动销，分层检索竞品动作、用户痛点、爆款案例、内容/视觉范式、转化机制与渠道玩法。
- 优先检索平台和行业真实案例；官方平台、主管部门、品牌官方渠道用于事实与授权核验，第三方榜单/数据工具只用于补充。
- 热点需记录账号、标题、平台、链接与时间，仅作为内部证据；除非用户要求，不把检索过程、原始链接或“某博主/爆款”泛称写入成稿。
- 不编造传播数据、短链、价格、产品、案例或平台规则；无法核验的数据标记为待补，不据此下确定结论。
- 不借势政治敏感、灾难事故、争议社会事件、违法违规、低俗擦边、医疗金融夸大或品牌高风险热点；无法自然转化为核心信息、内容选题、视觉符号、渠道玩法、促销机制或互动话术的热点不使用。

## 方案结构与内容纪律

从业务问题起手，按 **背景与机会 → 目标与判断指标 → 核心策略 → 传播/渠道与内容动作 → 节奏与资源 → 预算 → 效果评估与下一步** 组织。目录随业务调整，不机械照搬；完整方案须形成从策略到执行的闭环。

1. **背景与机会**：只分析直接影响项目的宏观变量、行业/市场、竞争、消费者与企业自身，归纳“最需要解决的问题”和“最值得抓住的机会”。
2. **目标与指标**：目标清晰、量化、可拆解、可验证；区分经营、转化、传播、互动、流量等指标，并让每项动作服务一个明确目标。
3. **营销策略**：回答在哪打、打给谁、怎么配、凭什么、怎么转；可按需使用 STP、4P/4C、AIPL、AARRR、IMC、RFM 等方法，但方法名不能代替判断。
4. **传播策略**：建立“一条主信息 + 多条支撑信息”；为消费者、媒体、达人、渠道伙伴、内部员工明确不同沟通任务，统筹自有、付费、赢得媒体及事件、话题、达人、共创、搜索和私域承接。
5. **排期与执行**：按筹备、预热、引爆、转化、延续、复盘安排节奏；明确里程碑、任务依赖、负责人、交付标准和风险缓冲。
6. **预算与效果预估**：按目标倒推，拆分调研、创意制作、媒介投放、达人、公关活动、促销、技术和数据等投入；说明渠道成本、用户质量、转化效率与长期价值，建立传播、互动、流量、转化、经营五层指标及动态调整机制。

不得：把无证据的“最佳、第一、保证、稀缺”写成主张；隐藏价格、资格、期限、自动续费或限制；伪造库存、倒计时、评价、案例、引语、图片或活动结果；把广告伪装成独立报道；用多个 CTA 争抢一次行动；用复杂视觉掩盖价值和证据缺口。主张、图片、评价、案例和引语须真实、可核且获授权；关键交易条件和商业关系应让读者在行动前理解。法规、平台与品类规则会变化，交付前核验适用要求。正文不出现裸 URL、方括号链接或参考文献编号；外部事实、数据、竞品动作、产品信息和政策依据统一在文末以灰色“资料与数据来源”区列出来源机构、页面/报告名称和核验日期。需要保留可点击来源时，使用 `<a type="url-preview" href="URL">来源名称</a>`，不自行发明普通链接语法。方案建议、目标值、预算比例和 ROI 测算须明确为建议、目标或假设，不伪装为外部事实。

## 场景级 Block 与工作台规则

飞书云文档承担方案阅读、评审和协作；可持续维护的排期、预算、投放数据与负责人信息进入 Sheet/Base，文档中只呈现当前决策需要的结论和快照。素材来源、待确认项、评审意见和执行任务可留在工作台，不混入面对客户或决策者的方案正文。**不要求使用所有 Block**：正文默认以标题、段落、列表、`table`、`img` 与 `<grid>` 完成；只有数据或协作确有需要时才加入其他能力。

| 信息关系 | 首选表达 | 使用边界 |
| --- | --- | --- |
| 核心判断、策略方向、单个待决事项 | `callout` | 全篇最多 1 次，放在开头的策略结论或结尾的待决/下一步 |
| 人群、产品、渠道、内容或卖点的精确对照 | `table` | 只保留支撑判断的行列；表前写目的，表后写结论、来源和边界 |
| 阶段节奏、执行排期、预算、KPI、负责人 | 文档 `table` 或 Sheet/Base | 持续维护、行列较多或多人填写时使用 Sheet/Base，不截图 |
| 漏斗、预算构成、渠道效率、增长趋势、方案权衡 | `html5-block` | 使用真实数据，显示单位、期间、口径和来源；不做伪数据看板 |
| 传播链路、用户旅程、渠道协同、机制、依赖与风险 | `html5-block` 或 SVG `whiteboard` | 需要切换、展开或探索时用 HTML5；需要静态、一图讲清且可编辑的结构关系时，用 `<whiteboard type="svg" path="@./file.svg"/>`。默认不使用 Mermaid，简单关系仍用标题、段落、列表或 `table` |
| 产品、包装、品牌资产、活动现场、场景、主视觉和传播物料 | `img` | 图片承担真实证据或传播创意职责；遵循下文图片规则 |
| 评审项、素材收集、制作清单 | `checkbox`、任务、表格 | 仅用于工作台；最终提案正文不堆叠待办 |

表格用于排期、执行、预算、产品矩阵、卖点—场景映射和产品/功能对比。阶段型排期可按“时间节奏｜传播重点｜Social｜PR｜内部渠道”，执行型排期可按“日期｜动作｜渠道｜内容｜负责人”，复杂项目再补交付物、审核节点与风险预案；预算至少包含“费用项｜金额/占比｜说明”。表格独立完整展示，避免宽表压缩、截断或把长篇洞察塞进单元格。

## 图片与视觉创作

图片从策略、核心信息和传播内容中生长，服务于建立真实观感、降低理解成本或承接传播命题，不作装饰。产品定位、封面/传播主画面、活动预热倒计时、场景种草、包装/材质/套装/前后对比等产品证据页，必须配图。用户明确不要图片时遵守用户要求，不搜索、不生成、不插入图片，并在文字中保留相应视觉制作建议。

### 视觉创作输入与决策顺序

出图、搜图或编排图片前，先锁定五类输入：用户指令（主题、品类、品牌/产品、人群、平台、数量、真人出镜和指定风格）、方案标题（封面钩子与承诺）、核心策略（定位和传播命题）、传播内容（每张图对应的内容要点）和事实素材（产品参数、价格、品牌资产、官方/电商图、截图证据）。只有真实性、产品识别或交付安全会受影响时才追问，其余按同品类高质量视觉与方案场景补齐。

按以下顺序决策：先将传播命题压成“谁在什么场景下，因为哪个利益点而行动”；再从产品差异、用户痛点、情绪反差、场景冲突、节点符号或利益结果中选择**一个**最强视觉钩子；将钩子转为主体、动作、对比、结果或证据的画面关系；最后才选择封面/主视觉类型和版式方法。不得从一个流行风格倒推策略。

### 图片来源与真实性

- 真实品牌、产品、门店、服务或可核实事件：先检索官方品牌视觉、logo 规范、包装/产品形态、官方海报与真实产品图；再使用官方/授权电商商品图或用户已授权实拍。品牌名、logo、型号、SKU、价格、店名、地址、包装形态和组合关系零容错，不能由 AI 生成冒充。
- 官方素材不足时，可从官方店铺、授权经销商和合规电商获取产品本体、包装、材质和组合关系；剔除或不使用价格角标、促销贴片、券、平台水印、用户头像、二维码、销量标签等内容。无法净化则弃用。
- 理念、情绪、氛围等不承载事实证明的非商业视觉，可搜索高质量对标或生成插图/氛围图；不得用生成图伪造真实产品、真实人物、真实门店、真实新闻现场、证书、榜单、评论或界面。
- 插图或搜索图在写入前均应预览，确认来源/授权边界、无水印/台标/二维码/文字覆盖、主体与内容相符、清晰度及裁切适配；图注归因不替代图片使用许可。

### 整组视觉系统与分镜

默认图片成组使用：至少 4 张，优先 4、6 或 8 张的偶数数量；用户指定数量或明确只需要单张主视觉时按用户要求。先完成可用素材的搜索、核验或生成，再写正文 XML；不得以“待配图”、文字描述、表格或 `<grid>` 代替 `<img>`。先确定封面/主视觉，再为每张图指定唯一任务，形成以下分镜清单：`序号 → 图片任务 → 主文案/主体 → 素材来源 → 设计方法`。

同组图片共享一张视觉卡：主色/点缀色、背景质感、构图网格、字体气质、关键词强调方式和去 AI 味要求；统一比例、色调与版式语言，只保留一种主气质。竖版默认 1080×1440（3:4），横版默认 1920×1080（16:9）；明确渠道时按平台规格覆盖。尺寸、比例和分辨率作为生成参数，不写进画面文案。

每张图片都按七项检查：主标题/副文层级是否清晰，产品/人物/场景是否是绝对主体，主色/辅助色/点缀色是否有主次，留白与阅读路径是否清楚，字体气质是否符合品牌，logo/贴纸/注解等辅助元素是否不抢主角，时间/地点/人群/产品名/系列/卖点等关键信息是否准确可读。快消与年轻化可更轻快，高端或严肃主题须克制；每张只强调少数关键词，不做彩虹盘或平均用力。

封面/主视觉遵循“0.3 秒法则”：只讲一个能截停读者的钩子，主角唯一、构图聚焦、文案与方案主张同源。封面主标题优先不超过 14 字；价格、参数、成分、SKU 等零容错信息若没有真实载体，放入内页证据图或后期排字，不交给生成模型。

可按传播命题选一种主视觉方法并贯穿整组：

| 主视觉方法 | 适合任务 | 画面重点 |
| --- | --- | --- |
| 真实人大字截停 | ToC、年轻化、达人视角 | 人物表情/姿态与大字钩子 |
| 纯文字大字报 / 极简观点卡 | 强观点、节点、品牌主张 | 单一结论、留白、少量关键词 |
| 纸卡便签 / 插画情绪 | 轻咨询、种草、节日与情绪价值 | 亲近感、手写注解或氛围 |
| 广告拼贴 / 海报大片 | 新品、功能传播、高势能发布 | 实物主体、品牌资产、光影与卖点标签 |
| 图表结构化 / 证据对比 | 机制解释、产品矩阵、功效/差异证明 | 清单、矩阵、前后对比或真实证据 |
| 产品质感 / 套装矩阵 | 产品、礼盒、系列推荐 | 真实包装、材质、SKU 组合关系 |
| 场景实拍 | 种草、生活方式、活动氛围 | 真实人物、使用时刻、场景代入 |
| 节点倒计时 | 预热、发售、活动节奏 | 数字与一条单一信息的系列延展 |
| 真实证据载体 | 背书、可信度建设 | 真实界面、证书、评论、榜单或报道 |

每张图只组合 1–2 个设计原子：利益结果、痛点反差、产品证据、场景代入、节点符号、品牌资产；禁止同组混搭广告拼贴、极简观点、手绘便签和赛博科技等多个主气质。

### 生图 Brief 与禁止项

生成前按以下顺序写 Brief，而非堆砌风格词：**图片任务 → 主标题 → 主体 → 真实素材约束 → 画面方法 → 色彩 → 构图 → 字体气质 → 细节辅助 → 去 AI 味要求**。其中依次填入九项：主视觉标题、次级说明、行动引导、品牌标识、视觉载体、色彩系统、版式构图、字体气质、细节辅助。图中文字仅在用户明确要求且可逐字校验时生成；真实品牌、价格、SKU、地址、参数和产品包装不交由生成模型重画。

- 产品/广告拼贴：突出一个产品或系列及其核心利益，使用品牌色和点缀色；画面采用居中大图、左文右图或对角构图。真实 logo、包装结构和产品外观必须来自真实素材，不得改形。
- 真人/场景实拍：人物表情、动作和场景服务传播命题；要求自然光影、真实生活痕迹、合理景深与摄影感，避免假笑、过度磨皮和塑料皮肤。
- 极简观点/大字：一个核心标题、充足留白、极少次级信息和单一强调色；标题与主体关系紧密，不堆叠卖点或装饰。
- 结构化/矩阵：只表达一个清单、对比、步骤或矩阵问题；信息层级清楚、主次分明、色彩克制，适合产品矩阵、护理步骤、功能对比或机制说明。
- 倒计时：突出数字和单一信息；系列内仅替换数字/当日重点，保持统一品牌色、构图和视觉识别。
- 套装/矩阵：明确展示每个真实 SKU 的包装、外观和组合关系，不将不同产品生成为同一外形。

禁止：塑料蓝紫渐变、全图高饱和、塑料反光、悬浮无影、过度磨皮、畸形人手/人脸/产品、假 UI、假 logo、假品牌/产品界面、乱码、伪文字、水印、平台 logo、用户名、二维码、模型签名、尺寸/规格字和边缘残留小字；不使用与正文无关的装饰图或混搭多种视觉气质。真实图片可保留自然纹理、纸张褶皱、桌面痕迹、轻微环境变化和适度留白，不追求过度对称或满画面；少量手写箭头、圈注、便签或框线只在符合品牌调性时作为点缀。

## 视觉标杆与审美等级

营销策划方案以成熟商业提案、品牌年度营销方案、消费品牌 Campaign Proposal 与高质量广告公司策略提案为基础标杆：清晰呈现业务判断、证据、创意、预算与执行路径，避免模板化商务文档。

**大型品牌及高感知项目**：大型品牌、大型文旅、IP、时尚、美妆、重要新品发布或高势能 Campaign，可对标顶级杂志（Monocle、Wallpaper、Vogue）、国际设计机构（Pentagram）、优秀品牌年报、品牌手册与创意提案。视觉需建立统一影像世界、明确材料感、强主视觉和编辑级留白；图片、色彩和版式均服务品牌识别与传播命题。

**中小品牌与小型营销项目**：对标高质量独立品牌、精品门店、专业工作室、轻量咨询提案和真实活动案例。视觉优先真实、聚焦、可执行：使用真实产品、门店、人物、活动和成果素材；以统一色彩、干净图文和清晰执行表建立品质，不伪造“大品牌大片感”，不使用廉价模板、泛化图库拼贴或过度装饰。

### XML 能力边界与配色系统

| 原生对象 | 合法做法 |
| --- | --- |
| 章节编号或短语强调 | `<span text-color="blue">01</span>`；只强调短语，不给整段上色 |
| 表头 | `light-gray` 或 `medium-gray`；状态单元格按语义使用 `light-blue`、`light-green`、`light-orange`、`light-red` 等 |
| `callout` | 使用 `light-*` 背景和同色相基础色边框；强提醒才使用适用的 `medium-*` |
| HTML5 / SVG / 图片 | 可使用品牌精确色值，但同一资产系统保持一套主色与语义一致的风险色 |

- 文档标题采用“营销策划方案｜主题或 Slogan”；正文不重复标题。最深使用两级正文标题：一级标题将两位数编号和文字写在同一个 `<h1>` 中，例如 `<h1><span text-color="blue">01</span> 市场机会</h1>`；二级标题使用无编号短标题。不得把一个章节拆成相邻的两个同级标题，也不混用 `1.1`、中文编号和括号数字。
- 开头可用一个 `callout` 承接核心判断或策略方向，例如 `<callout background-color="light-blue" border-color="blue"><p>核心判断</p></callout>`。关键词、策略主线、关键指标和关键动作可加粗或使用全文唯一的原生强调色，不整段着色。
- 表格使用清晰表头、右对齐数值列和有限的状态色强调；不要求 XML 未定义的边框颜色、投影或渐变。表格前用一段话概述读表目的，表格后给出结论。强叙事、逻辑推导、单列数据、单元格差异极大或核心洞察不使用表格，改用段落、列表、图片或图表。
- 全篇视觉按“业务问题/结论 → 策略与证据 → 传播及执行动作 → 节奏、预算和评估”建立节奏。图片、HTML5、SVG 画板和表格各自承担信息职责；结论与相邻证据对齐，来源与口径在正文中用简短归因表达、在文末统一归档，不把视觉当装饰。HTML5 可用于可切换的人—货—场路径、用户旅程、渠道协同、战役机制、情景取舍等复杂逻辑；SVG 画板只用于一图讲清的静态品牌/传播架构、机制或依赖关系。两者都必须回答一个明确决策问题，不能重复转写正文或表格。
- **首屏品牌锚点**：除用户明确不要图片外，标题与必要元信息之后、第一段策略/背景文字之前，必须出现一张封面或品牌主视觉。真实品牌方案优先使用官方 KV、真实产品、品牌 Logo 所在的官方视觉资产或已授权场景图；封面必须一眼识别品牌/产品或本次 Campaign，不得使用无品牌名、无产品关系的泛化氛围图。之后的首个策略章节再放至少一张真实品牌/产品/活动证据图，不能整篇只出现概念图。
- **分段图文节奏**：图片必须进入对应模块而非集中堆在文末：品牌/产品图放首屏与策略/核心信息区，主视觉和营销海报放传播策划区，场景/达人/活动图放对应内容动作区，倒计时图放排期区，数据/证据图放相邻判断之后。每张图紧邻其解释段落，并明确它在证明、解释、建立场景或承接哪项传播动作；无法说明作用的手机屏幕、泛化场景图或装饰图不使用。
- 除单张封面主视觉外，使用 `<grid>` 与 `<column>` 并排落图：2 张图各 `width-ratio="0.5"`；3 张图依次使用 `0.3333`、`0.3333`、`0.3334`，确保每行总和为 1。分栏内图片省略 `width`，由列宽自适应；单张横图显示宽度不超过 `800`，竖图或海报不超过 `560`，并只设置宽度以保留原始比例。

## Presentation Decision

`visual_plan.reason` 必须包含：`营销策划方案｜品牌/视觉系统｜业务问题与核心策略；首屏品牌锚点与图片分镜；表格/HTML5/SVG 的分工`。用户未明确拒绝图片且方案包含品牌、产品、传播主画面、活动/场景或产品证据时，`visual_plan.blocks` 必须记录所需 `img` 的最低数量与用途，且至少包含首屏品牌锚点；该数量是成稿 XML 的硬下限，正文必须实际插入对应 `<img>`，不能用表格、文字或 `<grid>` 替代。有真实趋势、漏斗、预算构成、渠道效率、方案权衡，或需要切换/展开理解的复杂策略逻辑时记录 `html5-block`；需要静态、一图讲清的品牌/传播架构、机制或依赖关系时记录 `whiteboard`，并使用 `type="svg"`，不使用 Mermaid。`table`、`grid` 和一次 `callout` 不计入最低数量。仅有表格且无上述硬性数量需求时可使用 `"blocks": []`。

示例：

```json
{
  "genre_contract": "marketing-plan",
  "adapter": null,

  "visual_plan": {
    "reason": "营销策划方案｜资产使用品牌酒红体系，原生 XML 映射为 red、light-red 与 gray｜解决新品首购不足；以场景化购买理由和达人种草推动转化；首屏使用官方品牌 KV，6 张分镜覆盖产品证据、场景和倒计时；表格呈现排期与预算，HTML5 呈现人—货—场路径，SVG 呈现战役协同机制。",
    "blocks": [
      {"type": "img", "min_count": 6, "purpose": "覆盖封面主视觉、产品证据、使用场景与活动倒计时"},
```
