# Changelog · questionnaire-designer

## v1.1.1 — 深访追问覆盖率门槛下调

- **M2 访谈提纲**:深访追问覆盖率下限由 **≥ 60% 下调为 ≥ 30%**(M2.6 第 6 条)。关键决策链路题须 100% 配结构化追问的要求保持不变。
  - 原因:60% 门槛偏高,30% 更贴合实际交付预期。

## v1.1.0 — 第一层评测反馈优化(低风险 · 纯 criteria/准出/输出模板)

基于两轮评测反馈,落地 4 项低风险、高收益的判定口径/准出/输出模板调整。均只改 reference 内的 criteria,不动路由与全局准入的主干逻辑。

- **M2 访谈提纲**:新增"深访关键决策链路题强制结构化追问"约束(首次发现 / 值得继续 / 差点放弃 / 取舍对比等题必须配 ≥2 轮结构化追问);M2.6 红线新增"深访追问覆盖率"准出门槛(初始 ≥ 60%,v1.1.1 下调为 ≥ 30%),关键决策链路题须 100% 配追问。
  - 对应反馈:深访场景追问覆盖率偏低(如仅 19%),关键决策链路缺乏深挖设计。
- **M4 定量问卷分析**:详细发现与关键交叉分析中,未加权 N 必须在每个被解读数字旁"就地"呈现,不能只写在方法章节;30 ≤ N < 50 的小样本分群结论须在正文就地标注"仅方向性"。同步更新 M4.8 分群规则与 M4.10 QA Checklist。
  - 对应反馈:样本量透明度、小样本可靠性提示需在正文可见。
- **M1 问卷设计**:Step 6 定稿前新增"选项/量表强制自检"四项关卡(复合提问 / 量表区间重叠 / 缺兜底项 / 缺锚点),逐题过一遍、命中即修正并留痕;M1.6 好结果准出同步新增该项。
  - 对应反馈:选项/量表质量不足、交付物不可直接使用。
- **M3 开放题原声打标**:标注统计输出补齐"二级标签分布统计"(每个一级下各二级的频次+占比),支持分层解读。
  - 对应反馈:交付物整体性/可分层性不足。
