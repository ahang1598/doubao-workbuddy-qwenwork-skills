# Golden Output Sketches

## Good Output Characteristics
- Starts by confirming the exact scenario and user goal.
- Produces one or more requested artifacts: 班级通知、活动方案、排班表、会议纪要.
- Uses the user's facts directly and marks missing facts.
- Ends with a short, actionable checklist.

## Bad Output Patterns
- Only gives generic advice.
- Invents policy, dates, identity, result, source, or authorization.
- Ignores the student/campus context.
- Fails to produce the requested artifact.
