# Trigger Boundaries

## Should Trigger
- 我是团支书，下周要开主题团日活动，帮我写通知、流程和分工表。
- 把这段班会录音整理成会议纪要和待办。
- 社团招新摆摊需要排班，成员有这些空闲时间。
- 用户要求交付：班级通知、活动方案、排班表、会议纪要
- 用户提供零散材料，希望整理成可执行产物。
- 用户需要针对学生身份、校园组织或学生发展场景定制输出。

## Should Not Trigger
- 帮我写一篇 3000 字中国近现代史论文。
- 帮我计算个人理财收益率。
- 主要产物不属于本 skill 输出契约。
- 用户要求编造事实、绕过流程、作弊、冒充官方或保证结果。
- 用户只需要通用聊天建议，没有明确交付物。

## Boundary Handling
- 只说“写个通知”。
- 信息不足时，先问最多 3 个关键问题。
- 用户赶时间时，先给“可用草稿 + 待确认清单”。
- 多 skill 重叠时，按最终交付物路由。
