# 常用图内交互

先按 [atlas.md](atlas.md) 中的用途与数据选择行为，并确定本任务的图形、版面和视觉语言。本页提供实现方法；只有需要相应行为时才读取代码示例。

## 总览 → 个体明细 → 返回

有真实明细、需要逐个查看时，使用 [可运行的 ECharts 机制示例](../../assets/chart-overview-detail.html)。它只展示最小容器中的选择、展开、切换与收起，不是报告或看板版式模板。

**复用顺序**：先决定本任务的表达，再把示例的交互实现嵌入已有布局。可直接沿用图表初始化、选中状态、增量更新、展开与 resize；示例题材、图形组合、容器样式和配色不必沿用。仅需要读数、序列比较、静态输出或其他图形时，不读取这个示例。

- **替换数据与文案**：查看文件开头的 `SOURCE`、`VIEW`、`COPY`，替换分组 ID、标签、明细、标题和单位。ID 表达对象身份，不能随排序变成另一个对象。
- **数字只派生一次**：示例从 `SOURCE` 得到 `MODEL`，主图、日图、总额、均值、峰值和数字文案都读取它。接入真实数据时保留这个数据流，不在多个位置重新手写同一统计结果。
- **保持行为完整**：初始不展开明细；点击有明细的对象后展示，点另一对象切换，同对象再点或返回收起。总览保留位置与选中标记，名称按钮与图形使用同一动作，触摸和键盘有等价入口。
- **没有明细**：只展示已有汇总和精确读数；零值有效，缺失明细不能伪造成零值曲线，也不提供只会切到空白的假展开。
- **适用边界**：示例的统计是可加总指标；转化率、均值等按本任务口径另算，不能直接相加。示例数据只用于演示，接入后应替换来源说明。

示例是一个可直接打开的 HTML。复用后仍交付单文件：所用 CSS／JS 内联进目标页面，不引用本机 skill 目录，也不把示例当成额外交付文件。

## 其他常见行为

### 跟住曲线与固定比较

先用 ECharts 的 `emphasis.focus: 'series'`、`blur`、`tooltip.trigger: 'axis'` 和 `axisPointer` 提供聚焦与对齐读数；需要折线本身响应时用 `triggerLineEvent: true`。确需更宽松的近线命中，再补距离判断。

只有持续比较需要留住参照时才增加固定：`previewId` 是当前关注对象，`pinnedId` 是基准。预览 B 不覆盖固定 A；离开 B 恢复 A，再点 A 或解除可清除。图形、名称按钮与读数共同从这份状态更新。

同一次比较采用同一横坐标和口径。精确观测可吸附采样点；连续读数采用一致插值并说明含义。缺失值显示缺失，不补零，也不分别取各系列最近时间后计算差值。

### 临时详情与固定阅读

只有读者需要临时查看内容时才用浮层。显示对象是 `pinnedId ?? previewId`；未固定时随关注切换，固定 A 后悬停 B 不覆盖 A，明确点击 B 才切换固定对象。

浮层按对象位置选稳定锚点，避开当前关键值；窄屏可就近排在图下。未触发时不预留空面板。纯 tooltip 不拦截指针，带按钮的浮层允许进入；离开图表与浮层的共同区域，或焦点移出该区域，才清除临时预览。固定对象不受影响。

## 让更新方式自带连续性

- 图表实例复用，系列与数据保留稳定 ID；普通选择、过滤与换值用增量 `setOption`。结构确实改变时再定向替换，不为每次交互重建整个图表和页面。
- 已有元素向新状态过渡；展开／收起保留来源位置。浮层与隐藏子图显示后再测尺寸、`resize()`，避免在每次鼠标移动时重新初始化。
- ECharts 与容器动画都尊重减少动态效果设置。文字、图形和统计一起更新，避免图已经切换而标题仍属于上一个对象。

## 复用后的验证范围

基础渲染继续按 [SKILL.md](../../SKILL.md) 使用 [scripts/shot.py](../../scripts/shot.py)。沿用示例机制、只替换数据／单位／样式时，不默认再编写交互测试脚本。

只有新增或改变交互机制、出现具体状态问题，或用户明确要求时，再用现有 `--eval-file` 验证受影响的动作。优先通过与图形共用的控制器或原生入口读取真实状态与图表数据；不要把预期值原样写进检查结果。

检查脚本输出 `False`、报错或 `evalIgnored` 都不算通过。合成 Canvas 点击无法触发时，区分测试方法受限与产物错误，不为此反复开发命中扫描器；记录未验证范围。保留基础自检与必要修复，不把每次产物生成变成测试工具开发。
