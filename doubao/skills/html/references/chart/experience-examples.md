# 图表体验示例

本页补充两类任务：从同一批记录中选出群体做跨图比较，以及有明确计算关系的教学推演。普通“总览 → 某个对象的明细”使用 [reading-interactions.md](reading-interactions.md)，不因有两张图而切换到本页。示例用于理解信息关系，题材、布局和视觉语言按当前任务设计。

## 选一群对象，比较它们有什么不同

**问题**：哪些航班更容易延误？各视图来自可关联的同一批航班记录。

**初始画面**：以延误分布为主图，起飞时段与航程分布作为较小的关联视图。用同一强调色表示当前关注的航班，全量分布作为浅色背景；标题标明统计周期与样本量。最显著的差异直接注在图上。

**操作后**：读者选中「延误超过一小时」的航班，关联视图显示这批航班的分布，并保留全量参照。读者能比较它们是否更集中于晚间或长途；需要核实时，再展开匹配的航班记录。当前条件与样本量始终可见，可以移除单个条件或恢复总览。

**设计理由**：一次选择贯穿多个维度，产生新的比较信息。比较群体分布时采用可比的比例或统一尺度，并标明分母；样本数多寡不能冒充发生率高低。关联性只作为线索，原因须有额外证据。

**实现语义**：按稳定记录 ID 联动；选中分桶时先映射回该桶的记录，不能把分桶的 `dataIndex` 直接当原始行号。刷选零命中保留空结果，清除筛选才恢复全量。分布、样本量与明细由同一组记录派生。

**迁移**：用户群分析、质量检测、经营诊断中，都可用「选择群体 → 与整体比较 → 核对明细」。

## 改一个条件，理解结果为什么变化

**问题**：少数异常点会怎样影响一条拟合线？页面面向初学者，计算关系明确。

**初始画面**：一个主要实验图展示数据点、拟合线和误差。旁边只给开始实验所需的解释，拖动入口直接贴近可操控的点。数据点、拟合线与误差使用稳定的视觉编码。

**操作后**：拖动一个点，拟合线和误差即时重新计算；保留一条淡色的初始拟合线帮助比较，并用一句随结果更新的解释指出变化。读者可恢复初始数据，再试另一个位置。触屏或键盘也有等价的输入方式。

**设计理由**：动作对应真实计算，变化揭示参数和结果之间的关系。基线帮助读者分辨改动造成的影响；重点围绕当前实验组织，其余说明按理解顺序展开。视觉过渡保持对象对应，操作完成后结果稳定可读。

**迁移**：预算规划、物理演示、收益测算等主题，都可用「调整条件 → 观察结果及解释 → 与基线比较 → 重置」。只提供现有数据或公式能支持的推演。

## 用到当前任务

只采用当前分析或实验需要的机制。复杂度随数据与目的决定，保持当前群体／参数、比较口径与返回方式清楚可见。
