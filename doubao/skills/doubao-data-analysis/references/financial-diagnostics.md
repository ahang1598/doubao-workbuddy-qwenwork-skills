# 财务诊断的证据边界

只在任务涉及财务报表、资金、融资、偿债、估值或经营财务诊断时读取。

- **进入本文件后先执行最低勾稽门禁**：列出所涉报表和期间，识别明细、小计、净额/期末额的层级关系，机械重算会影响本题的恒等式，再开始解释业务。即使用户只问一个融资金额、成本或毛利数字，也不能在读到目标科目后跳过这一步。
- **勾稽结果不得停留在分析过程**：对每个非尾差异常记录“报表/期间/行项目、源表原值、纳入的明细、重算值、差异、本题采用值及影响”。只要异常会影响用户所问数字、结论可信度或建议，最终答案必须逐项点名；不得合并成“部分小计有差异”或只给修正后的数字。
- 勾稽前先统一币种、单位、正负号约定、合并范围和期间。比较值按源表展示精度设置四舍五入容差；差异不超过由展示精度产生的合理尾差时标为“尾差”，不判为公式异常。口径无法统一时分别报告，不强行勾稽。
- 财务报表能直接支持规模、结构、同比、勾稽和现金流方向；机制性、排他性或生存期结论还需债务期限、账龄、减值、订单/合同、资金用途、最低现金需求及表外安排等对应证据。缺失时写成风险信号或显式情景，且只披露会改变决策的限制。
- 使用整张利润表、资产负债表或现金流量表支持结论时，按所涉期间批量扫描关键小计、净额和期末额恒等式，不只核对用户点名的单一科目；最终只披露会改变本题数字、口径或可信度的异常。
- 现金流量表至少检查：各活动流入小计是否覆盖所属流入明细、流出小计是否覆盖所属流出明细、活动净额是否等于流入减流出、现金期末额是否等于期初额加现金净增加额。利润表至少检查收入至毛利、营业利润和净利润的关键桥接；资产负债表至少检查资产等于负债加所有者权益以及重要小计。仅检查实际存在且与本题相关的层级，不因缺少某张报表而补造结构。
- 输入为 `.xlsx` 现金流量表时，必须先运行
  `python scripts/cashflow_audit.py <source.xlsx> --output <audit.json>
  --markdown-output <anomalies.md>`，让脚本扫描全部 Sheet 的本期金额。
  最终答案必须原样包含 `anomalies.md` 的逐期异常表；不得把多期合并成
  “全部年度”、把重算值写成“均非零”，或省略期间、原值、重算值和差异。
  活动净额不等于流入减流出会直接影响整张报表可信度，因此无论用户问经营、
  投资还是融资，均属必须披露异常；不能因其不在目标活动中而省略。
- 遇到原表小计或净额异常时，同时保留“源表原值、按明细重算值、差异和本题采用口径”；不能静默修正，也不能因汇总异常否定仍可由直接科目支持的事实。
- 同一异常同时影响小计、净额和总额时，沿层级向上重算到用户真正使用的最高一级，用一条异常血缘说明各层影响，避免把同一根因重复算成多项；涉及的金额按不重叠构成拆分，不能只报最显眼的一层。
- 用户使用“融资金额、筹资额、资金来源”等可能包含多种来源的词时，先列出报表中所有不重叠来源并消歧。涉及股权稀释时，以股权融资作为估值主口径，同时分列债务融资、其他融资和现金筹资合计；不得把股权融资合计直接命名为全部融资。
- 由连续持股比例与每轮新增股权资金反推估值时，使用未四舍五入比例计算：`本轮稀释=1-本轮融资后持股/上轮融资后持股`，`投后估值=本轮新增股权资金/本轮稀释`，`投前估值=投后估值-本轮新增股权资金`。明确该推导假设持股下降由本轮增发造成，且现金流入与该轮增发一一对应；老股转让、期权池、可转工具或多笔交易会使估值失真。融资现金额本身来自直接科目时，不受这项估值假设影响。
- 净资产跨期大幅变化时做权益桥：`期末权益 - 期初权益 = 当期净利润 + 其他综合收益 + 股东投入/分配 + 其他权益变动`。附件缺少桥接项时，量化权益变动、已知部分和未解释残差；增资、债转股、重组等只能列为待核验原因。
- 同一期间在汇总图片、主表或不同口径中数值冲突时，先判断合并范围、时点和单位是否一致。比率比较优先使用同一张主表中可勾稽的分子分母；其他口径单列差异，不混用或任选。
- 现金余额除以某期现金净流出只能作为线性敏感性测算，须写明净流出不变、无新增融资、无季节性和最低现金需求等假设，不能直接表述为企业只能维持某个期限。
- 周转天数由不足一年的期间数据年化时，标注年化假设；没有账龄、回款条款或历史坏账率时，不把周转慢直接等同于坏账。
- 暂停、砍掉、折价处置、大幅裁撤等高影响建议，需要项目级盈利/现金流、合同约束和可逆性证据；仅凭汇总报表时改为专项核验、情景测算和分阶段止损条件。
- 资产、产能、在建工程或固定资产增长只能直接证明相应余额或投入增加；战略意图需要管理层说明、产能数据或项目用途支持。某一期已列筹资来源不能自动代表全部融资来源或长期结构。

## 完成前的最小答案合同

融资、筹资或稀释估值任务在最终答案中至少包含以下内容；缺一项时继续补算或明确缺失证据，不能直接结束：

1. 分期列出不重叠的股权融资、债务融资、其他融资和现金筹资合计，并增加
   **覆盖表中全部展示期间**的累计行；累计必须等于表内各期加总。若融资轮次
   区间与附件全期间不同，同时列“融资轮次区间累计”和“附件全期间累计”，
   不能把轮次前已经发生的债务融资从“总筹资”中静默排除。主答案明确采用哪一种
   “融资金额”口径。
2. 涉及持股稀释时，同时列本轮未四舍五入稀释率、投前估值、投后估值和推导假设。
3. 对会影响上述数字或可信度的勾稽异常，至少给“期间/项目、源表数值、重算数值、差异、采用值”；逐期数值不同时须逐期列出，不能只写“仅含某项”代替可复算数字。同一根因跨层影响可合并成一条血缘。
4. 明确区分直接取自报表的融资现金额与依赖交易假设反推的估值，不把后者的不确定性扩散到前者。
