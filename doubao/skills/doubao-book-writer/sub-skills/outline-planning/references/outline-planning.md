# 大纲规划与冻结

本文件只处理长篇结构：从需求推导章节关系，经用户确认后冻结，作为正文与整体改写的锚点。长稿的 `make prepare` 会调用大纲结构门禁强制校验本文件描述的结构。

## 1. 何时做大纲规划

- 长篇项目（>3 万字或需要分章）：完成需求冻结后、进入正文写作前。
- 整体改写：结构需要调整时，先走变更单再冻结新版本。
- 短稿跳过本阶段；需要段落规划时直接在 `manuscript.md` 内组织，不创建伪长篇台账。

## 2. 大纲必须包含

1. **全书核心主张**：一句话，从需求继承。
2. **目标读者与语气**：从需求继承，不重新询问。
3. **章节列表**：每个章节条目写清：
   - 编号与标题
   - 该章要回答的核心问题（1 句）
   - 用户收获点（1-2 句）
   - 预估字数区间
4. **章节依赖关系**：标注哪些章节是后续章节的前置。
5. **全书字数目标**：目标总字数，与需求清单字数契约一致。

### 2.1 标准 Schema

`outline.md` 必须包含以下 `##` 级章节：

```markdown
## 核心主张
## 作者声音标签
## 目标读者
## 章节规划
## 章节依赖关系
## 总字数目标
```

章节规划表必须包含列：`章节 | 标题 | 核心问题 | 用户收获 | 目标字数`

章节依赖关系表必须包含列：`章节 | 前置章节`

`chapter-ledger.md` 的章节 ID、标题和目标字数必须与大纲逐行一致。

## 3. 确定性结构门禁

结构检查由长稿 `make prepare` 现场执行（内部调用 `outline-structure-gate.mjs`）；需要提前定位问题时也可单独运行：

```bash
node scripts/gates/outline-structure-gate.mjs --workspace <书稿根> --json
```

检查器验证：

- 必需章节和表头完整
- `ch01` 起连续、唯一
- 章节标题唯一
- 核心问题和用户收获非空
- 目标字数为正数
- 各章字数之和完整分配全书目标
- 全书目标落在需求清单字数契约区间内
- 依赖章节存在、位于当前章之前，无自依赖和循环
- 章节台账与大纲一致

报告写入 `.doubao-book-writer/reports/outline-structure-check.json`。长稿 `make prepare` 必须通过此门禁才能进入写作。

## 4. 写入位置

| 文件 | 内容 |
|---|---|
| `outline.md` | 用户可读的大纲真源，章节标题、核心问题和收获点 |
| `chapter-ledger.md` | 章节台账：编号、标题、状态、计划字数、已写字数 |

## 5. 冻结含义

- **冻结**：章节标题、章数、各章核心问题和收获点已确认，写入 `outline.md` 与 `chapter-ledger.md`，并通过长稿 `make prepare` 的结构门禁。
- **冻结后**：不得静默改结构；任何章数或标题变化须先与用户确认再改文件并重跑 `make prepare`。
- **冻结标记**：三阶段模型以产物文件为状态，`outline.md` 与 `chapter-ledger.md` 通过 `make prepare` 即为已冻结，不再单独记录版本号或时间戳。

## 6. 变更单

大纲冻结后需要调整结构时，创建变更单：

| 字段 | 填写 |
|---|---|
| 变更 ID | OC-001 |
| 日期 | ISO 时间戳 |
| 原因 | 用户要求 / 事实约束 / 结构优化（一句话） |
| 变更前 | 原章数和标题摘要 |
| 变更后 | 新章数和标题摘要 |
| 字数影响 | 增 / 减 / 不变（估算） |
| 确认状态 | 已同意 / 待回复 |

变更单写入 `.doubao-book-writer/outline-changes/outline-change-{YYYYMMDD}.md`。变更确认后同步修改 `outline.md` 与 `chapter-ledger.md`，重跑 `make prepare` 通过即完成重新冻结。

## 7. 相关脚本

- `scripts/gates/outline-structure-gate.mjs` — 确定性结构门禁，校验大纲 Schema、依赖关系、台账一致性。

## 8. 质量要点

- 每章只回答一个核心问题，避免章节间内容重叠。
- 章节顺序遵循"从问题到方案"或"从整体到细节"的逻辑。
- 预估字数总和应与全书目标一致，偏差过大时调整章数或目标。
- 大纲是写作的锚，不是写作的替代；冻结后仍可在正文中调整段落级结构。
