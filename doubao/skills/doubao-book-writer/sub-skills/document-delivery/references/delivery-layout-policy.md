# 中文长文交付版式策略

## 先保证可读，再做装饰

交付版式按三个层次处理：内容结构不可破坏；中文阅读参数保持合理；颜色、边框等视觉选择允许按项目调整。不要把英文网页排版习惯直接套到中文书稿。

## 内容结构红线

- 章、节正式标题必须保留 `第一章 → 一、 → （一）` 三层结构，不能用加粗段落替代正式标题。三级标题下经写作形态检查通过的少量无编号加粗小标题属于局部导航，应保留但不进入正式目录。
- 正文默认左到右、两端对齐；纸质版正文可首行缩进两个汉字。
- 标题不得与后续第一段分离，表格、图片和代码块尽量避免跨页断裂。
- 引用、代码、表格必须与普通正文有可辨识差异，但不能靠花哨渐变表达层级。
- A4 导出时必须检查页边距、页码、孤行和寡行。

## 推荐参数区间

| 对象 | 字号 | 行高 | 前后间距 |
|---|---:|---:|---:|
| 正文 | 15–18px | 1.6–2.0 | 0.8–1.2em |
| 章标题 | 24–32px | 1.3–1.6 | 1.5–2.5em / 0.8–1.2em |
| 节标题 | 20–24px | 1.3–1.6 | 1.0–2.0em / 0.5–1.0em |
| 表格 | 13–15px | 1.4–1.6 | 0.8–1.5em |
| 引用 | 14–16px | 1.5–1.9 | 随正文节奏 |

## 中文标点与混排

- 中文句子使用全角标点；英文代码和 URL 保持原样。
- 中文破折号使用“——”，省略号使用“……”。
- 中文引文优先使用弯引号或项目约定的书名号体系，并保持全书统一。
- 中英文、数字与中文之间是否留空格遵循项目模板，不在同一本书中混用两套规则。

## 页面与分页基线

```css
@page { size: A4; margin: 25mm 20mm; }
h1 { break-before: page; break-after: avoid; }
h2, h3 { break-after: avoid; }
table, pre, figure { break-inside: avoid; }
p { orphans: 2; widows: 2; }
```

若交付平台不支持这些 CSS，以平台实际渲染为准，不得为了模拟样式破坏 Markdown 结构。

## 表格处理

- 表头必须明确，数据列保持相同对齐逻辑。
- 六列以上优先拆表；移动端不能只依赖横向滚动。
- 单元格长文本优先改写或换行，不统一强制 `nowrap`。
- 表格中的来源、单位和时间范围必须保留。

## 代码与图示

- 多行代码使用围栏代码块，行内命令使用行内代码。
- 代码块允许横向滚动，但不得缩小到不可读字号。
- 图示节点文字保持简短，颜色数量受控，并提供文本解释。
- 图片必须有替代文字；图表编号与正文引用保持一致。

## 交付前查看

至少检查桌面阅读、窄屏阅读和打印/PDF 三种结果。发现截断、标题孤立、表格溢出或字号过小，应修正版式后重新读回交付文档。
