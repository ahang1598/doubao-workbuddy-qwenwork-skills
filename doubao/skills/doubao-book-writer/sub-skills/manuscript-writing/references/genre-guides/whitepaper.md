# 行业白皮书写作包

## 适用范围

`whitepaper` 用于行业研究、政策解读和组织级专题报告。它通过透明的方法、可追溯数据和明确假设形成洞察，不能写成品牌宣传册，也不能沿用调查报道对单一事件追责的叙事方式。

## 研究定义

立项时冻结行业边界、地域、时间范围、目标读者、发布主体和需要回答的核心问题。对“市场规模”“用户”“渗透率”等关键指标给出操作性定义，避免不同章节使用不同分母。

研究方法说明样本、数据期间、采集方式、估算模型、缺失值处理和已知限制。发布主体存在商业立场时，应在适当位置披露，不用中性研究口吻掩盖利益关系。

## 内容骨架

| 部分 | 核心产出 |
|---|---|
| 执行摘要 | 关键发现、证据强度、主要风险和建议 |
| 定义与方法 | 研究边界、指标、样本、来源和限制 |
| 现状分析 | 规模、结构、参与者、驱动与约束 |
| 趋势推演 | 变化信号、基准情景、替代情景和假设 |
| 机会与风险 | 受益主体、触发条件、影响和优先级 |
| 实施建议 | 面向不同角色的行动、资源、里程碑与指标 |

结构应形成“现状—变化—选择”的推理链。摘要只呈现正文已经证明的结论；正文更新后同步刷新摘要和图表。

## 数据与结论

每项关键数字注明来源、年份、单位和统计口径。使用二手研究时尽量追到原始数据，并识别多个报告是否共享同一来源。至少覆盖公共或监管资料、专业研究、行业主体披露等不同来源类型，而不是用同类转载制造交叉验证。

趋势判断区分观察事实、模型推断和作者判断。预测采用区间或情景，列出关键假设与失效条件。无法量化的结论说明依据，不强行生成精确百分比。

重要主张应能沿“结论—图表或证据—原始来源”回溯。来源冲突时展示差异、可能原因和采用口径；不得挑选单一有利数字而省略相反证据。

## 建议质量

建议必须对应前文问题，并说明适用对象、行动、时间、资源、依赖和衡量指标。政策建议区分现行规则、拟议变化和作者意见。商业建议同时写出风险、成本与停止条件，避免只有乐观机会清单。

## 搜索与更新

写作前至少从行业定义、规模结构、关键趋势等三个方向检索，检查缺口后继续补搜。优先采用政策原文、政府统计、行业协会、上市公司披露、原始研究和可信专业机构资料。时效敏感指标应尽量使用最近数据，并记录访问日期；无法获得新数据时明确披露。

## 图表规范

时间变化使用折线或区间图，类别比较使用柱状图，产业关系使用结构图，风险或优先级可以使用定义清楚的矩阵。图题、坐标、单位、样本期和来源必须完整。视觉效果不能夸大微小差异，也不能截断坐标误导判断。

## 放行条件

研究边界明确，方法可复核，关键数字可追溯，预测假设可见，结论之间无冲突，建议能够执行且发布立场已披露后，白皮书才可进入终审和交付。
