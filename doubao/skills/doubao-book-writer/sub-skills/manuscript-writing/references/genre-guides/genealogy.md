# 家族谱牒写作包

## 任务性质

`genealogy` 用于家谱、支系谱、家族人物志和迁徙记录。谱牒的首要责任是保存可追溯关系，不是补齐一个看似完整的故事。证据不足时保留空缺、异说和“不详”，不得推算成事实。

## 建档准备

立项时记录主修姓氏、郡望或堂号、修谱目的、覆盖支系、起止年代、族源地与现居分布。盘点旧谱、碑记、方志、档案、户籍材料、墓志、访谈和照片，并为每件材料登记持有人、版本、形成时间和可使用范围。

涉及在世成员时先确认隐私边界。身份证件、联系方式、精确住址、健康和财务信息不进入公开稿；未成年人信息从严处理。口述材料应取得授权，并允许受访者确认敏感表述。

## 卷目设计

| 卷目 | 主要内容 |
|---|---|
| 源流 | 得姓、郡望、祖居与已证实的迁徙线索 |
| 世系 | 世代关系、支系分合、配偶与子女记录 |
| 人物 | 生卒、经历、事迹及相应证据 |
| 家风 | 原始家训、形成背景和当代说明 |
| 大事 | 带地点和来源的家族事件时间线 |
| 附录 | 资料目录、异文对照、索引与图版说明 |

卷目可按材料调整，但世系编号、人物标识和支系名称必须贯穿一致。

## 证据等级

原始档案和同期记录通常优先于后世转述；旧谱也是历史材料，仍需检查版本、续修时间和抄录错误。口述可以保存家族记忆，但应标明讲述者、采访时间和未经其他材料证实的部分。

同一事实存在不同版本时并列记录出处，不擅自合并。引用旧谱写明谱名、卷次、页码或影像编号；引用地方志和档案写明版本及馆藏信息。网络资料只能作为查找线索，不能成为关键世系关系的唯一证明。

## 年代与关系校验

检查生年早于卒年、父母与子女年龄差是否可能、同代关系是否自洽、人物活动是否落在相应朝代和地域。常见年龄范围只能触发复核，不能据此否定有证据支持的特殊情况。

每个人物使用稳定 ID，记录父母、配偶、子女、支系和来源。发现兄弟长幼、过继、复婚或同名异人时，明确说明判定依据。无法确定的关系标为待考，不强行连接。

## 迁徙记录

迁徙节点至少包含迁出人物或支祖、出发地、目的地、时间范围、原因、证据和后续支系。时间只能确定到朝代或时期时使用“约”“此前”“不晚于”等限定词。路线图中的每条线都要能回到文字记录和来源。

## 编辑与索引

人名、地名、官职、纪年和公历换算采用统一格式。历史人物的评价尽量放回当时语境，并区分资料记载与编者判断。成稿提供人名、地名、支系和事件索引，方便后续续修纠错。

## 放行条件

世系关系无未解释冲突，年代异常已复核，来源可追溯，异说得到保留，在世成员隐私已处理，迁徙分支与正文一致后，谱稿才可进入全书终审。
