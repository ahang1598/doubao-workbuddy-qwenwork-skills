# 企业学习与培训写作包

## 使用范围

`training` 用于课程教案、员工学习手册和内部知识库。判断质量的核心不是信息数量，而是学员能否在规定场景中完成目标行为，并通过练习证明已经掌握。

## 课程输入

开课前确定培训主题、岗位与经验水平、现有能力缺口、培训时长、班级规模、授课方式和可用内部案例。明确是否需要练习、评分、讲师提示、工具模板及课后追踪。

学习目标使用可观察的动词，例如识别、判断、演示、完成或改进。避免只写“理解”“熟悉”而没有可验证表现。每个目标应说明条件和合格标准，并与业务场景相关。

## 内容组织

一门完整课程通常由导入、知识讲解、示范、练习、反馈和迁移任务构成。知识不是独立终点：概念后应紧跟适用条件、示例和反例；操作技能需要展示步骤、常见错误和纠正方法。

| 内容单元 | 最小产出 |
|---|---|
| 课程导入 | 学员问题、学习目标、使用场景 |
| 知识单元 | 定义、原理、适用边界、例子 |
| 案例 | 背景、决策点、证据、结果与复盘 |
| 练习 | 任务说明、输入条件、参考答案或评分量规 |
| 工具 | 可直接使用的模板及填写示例 |
| 迁移 | 课后行动、检查时间和反馈方式 |

章节标题遵守汉字编号规则。正文用自然段解释为什么和何时使用某方法；清单只承担步骤、检查或评分功能，不能代替教学论述。

## 练习与测评

每个关键学习目标至少由一项练习覆盖。选择题说明正确与错误选项的理由；情境题提供判断依据；实操题写明输入、完成标准和评分维度。题目不能考查正文从未讲解的内容。

课程开始前可用诊断题确定基础，学习过程中用低风险练习及时反馈，结束时用综合任务验证迁移。若目标是行为改变，还应设计课后观察指标，而不是只统计满意度。

## 案例与来源

企业案例优先使用经授权的一手材料；需要脱敏时保留决策条件和因果关系，不拼接成虚构成功故事。外部案例记录来源、时间和适用限制。行业标准、官方指南、专业教材和研究资料优先于无出处的培训文章。

## 一致性与难度

术语在全课程保持同一含义，前置概念早于复杂任务出现。难度从识别和解释逐步进入应用、判断与综合。章末练习必须回扣章首目标；调整目标后同步更新题目、答案和讲师说明。

## 可视化

学习路径图解释先后关系，流程图展示操作，决策表帮助判断，能力量规描述不同水平，示例模板展示合格产物。图表需要讲解和练习，不作为装饰页面。

## 完成条件

目标可测量、内容支持目标、练习覆盖目标、答案与量规可执行、案例可追溯且术语一致后，培训材料才可进入质量审计与交付。
