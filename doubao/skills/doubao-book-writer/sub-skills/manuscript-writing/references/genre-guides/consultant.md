# 咨询与商业分析写作包

## 适用任务

`consultant` 面向创业顾问、投资分析、孵化辅导和商业决策材料。成果可以是行业分析、投资备忘录或商业计划框架，但必须服务于明确决策，不能只堆积市场数据和通用框架。

## 需求冻结

开始前确认核心决策题、目标读者、输出类型、分析范围、币种与统计单位、可用内部数据、截止时间及保密要求。还要明确读者需要作出的决定，例如进入市场、投资、调整产品或暂缓行动。

关键术语与计算口径在项目简报中锁定。CAGR、ROI、IRR 等缩写首次出现时解释含义；历史值、预测值和目标值使用不同标签。

## 建议结构

| 部分 | 需要回答的问题 |
|---|---|
| 执行摘要 | 建议是什么，依据和主要限制是什么 |
| 竞争格局 | 谁在竞争，壁垒、替代方案和空白在哪里 |
| 市场与客户 | 市场如何定义，需求来自谁，规模怎样测算 |
| 商业模型 | 收入、成本、获客、留存和单位经济是否成立 |
| 风险与情景 | 哪些假设最脆弱，不同情景会怎样影响结论 |
| 行动路线 | 谁在何时完成什么，里程碑和停止条件是什么 |

竞争分析通常应早于市场机会结论，让读者先理解现有玩家和替代方案。各部分篇幅由决策重要性和证据量决定，不设机械均分。

## 证据与推理

每项核心结论都要连接到可核验数据、用户材料或明确假设。市场规模同时说明定义、时间、地域、数据来源和推导方法。预测给出基准情景，并解释关键变量，而不是只报一个精确数字。

多来源不等于简单凑数。优先使用监管披露、上市公司公告、原始统计、学术研究和可靠行业资料，并检查它们是否引用同一底层数据。证据相互冲突时呈现差异及采用某一口径的理由。

风险分析必须写出发生条件、概率或不确定性、影响范围、监测信号与应对动作。建议需要对应责任人、时间、资源和验收指标；泛泛的“加强建设”不能作为可执行结论。

## 一致性检查

全稿统一币种、单位、市场边界和预测周期。同一指标跨章出现时引用同一台账；更新数据后同步修改摘要、图表和建议。观点发生变化时说明是新增证据还是假设变化导致。

## 图表

市场趋势可用折线或区间图，竞争关系可用有明确坐标定义的矩阵，商业模式可用价值流或单位经济表，风险适合概率—影响矩阵。图表注明来源、日期、单位和计算口径，不能模仿权威图形却缺少可验证尺度。

## 放行标准

结论可追溯到证据或假设，数字口径一致，风险包含应对，行动路线可以执行，并且限制条件已向决策者说明后，材料才可进入终审。
