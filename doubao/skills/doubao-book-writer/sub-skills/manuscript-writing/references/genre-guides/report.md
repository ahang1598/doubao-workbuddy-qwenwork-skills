# 调查报告写作包

## 场景边界

`report` 适用于新闻调查、事实核查、深度报道和非虚构调查长文。它首先回答“发生了什么、证据能证明到什么程度、相关方如何回应”。行业白皮书则侧重现状、趋势和策略推演；不能把后者的概括性结论直接套入调查报告。

本包是远端配置不可用时的本地规则。用户材料、法律要求和正式编辑规范优先于本文件。

## 调查立项

开稿前冻结核心议题、时间与地域边界、涉及主体、已有证据、拟采访对象、发布平台、篇幅和交付格式。涉及个人指控、未公开材料、匿名信源或潜在诉讼时，另行记录法律敏感点、匿名理由和信息保护要求。

材料盘点必须区分：已核实事实、待核实线索、当事方说法、作者分析和无法确认的信息。不得把线索或推断改写成确定事实。

## 叙事骨架

报告可以按以下逻辑组织，但各部分长度由证据量决定：

| 部分 | 写作任务 |
|---|---|
| 核心发现 | 先说明最重要且已得到支持的事实，并声明调查范围与限制 |
| 背景 | 建立时间线、主体关系和既有公开记录 |
| 调查发现 | 展示文件、数据、采访和交叉验证过程 |
| 相关方回应 | 完整呈现回应；未回应时说明联系时间、渠道和结果 |
| 影响分析 | 区分已发生影响、可能影响和作者判断 |
| 方法与来源 | 交代样本、统计口径、证据限制和引用目录 |

标题继续遵守全局汉字编号规则。正文以证据推进，不用整齐的模板段落制造“调查感”。

## 证据规则

重要事实原则上由两个相互独立的来源支持。所谓独立，是信息并非共同转述同一原始消息。只能获得单一来源时，明确标记证据状态和局限，不能用模糊复数掩饰。

数字旁边应交代发布方、统计时点、覆盖样本和计量单位。人物姓名、机构名称、职位、日期与直接引语逐项核对。使用匿名信源时，要说明匿名理由，并避免泄露可反向识别的信息。

所有针对个人或机构的不利事实都应给予合理回应机会。正文区分对方确认、否认、部分回应、拒绝回应和截至发稿未回应，不把沉默解释为承认。

## 公平与一致性

事实句、引语和评论应让读者可以辨别。直接引语保留原意并注明说话者；概述他人观点时避免强化语气。跨章时间线、数字和主体称谓保持一致，新增证据与早期结论冲突时，更新结论并解释变化。

报告结尾回到开篇问题，说明哪些结论已经得到支持、哪些仍待验证。不得为追求闭环而虚构确定性。

## 搜索与记录

优先查找原始文件、法院或监管记录、政府与机构公开数据、当事方声明、学术研究和具有采编责任的媒体资料。网络百科只能提供线索，不能作为关键事实的唯一依据。每次检索都把链接、访问日期、结论、证据等级和使用位置写入来源台账。

## 可视化

时间线用于还原事件顺序，关系图用于展示主体联系，数据表用于比较证据口径，地图用于解释地域分布。图表不得超出证据能够支持的范围；图注中写明来源、日期和必要限制。

## 放行条件

关键事实已核实，回应权记录完整，事实与观点可以区分，匿名和法律风险得到处理，来源台账可追溯后，报告才可进入全书质检与交付阶段。
