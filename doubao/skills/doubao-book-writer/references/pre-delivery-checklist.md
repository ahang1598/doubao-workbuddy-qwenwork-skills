# Pre-delivery Checklist

最终交付前逐项确认。程序可验证的项目以现场 `make` 检查结果为准，不手写自称通过。

- [ ] 写作意图与当前用户任务一致；既有项目从磁盘恢复，未重建布局
- [ ] 需求清单字段合规，所有 `in_scope: yes` 已填写 `resolution`（`make prepare` 通过）
- [ ] 长稿大纲已冻结并通过结构检查；`outline`、`chapter-ledger` 与章节文件一致
- [ ] 目标 Markdown 非空且已读回，无截断
- [ ] 未指定范围保持不变；需要保护的原稿已备份
- [ ] 字数来自程序实测，满足需求清单字数契约
- [ ] 可见标题只使用 `第一章 → 一、 → （一）` 三层，编号后有具体语义标题，无 `第一节`、阿拉伯层级或重复 `（一）` 伪四级标题
- [ ] 表格和加粗数量适度且承担比较、查阅或提示功能，没有替代正文论述
- [ ] 正文无列表拼凑、装饰性 callout、TODO/TBD 和模板占位符
- [ ] 正文形态、字数、占位符清洁通过（`make write` 为 `status: pass`）
- [ ] 深度质检按需完成（`make quality`），发现问题已回正文修复
- [ ] 终稿已生成；飞书读回校验有效，或用户显式 `SKIP_LARK=1`
- [ ] `make status` 返回 PASS
