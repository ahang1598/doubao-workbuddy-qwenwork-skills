# 营销素材审核

对营销素材（广告宣传语、海报文案、社媒推广文案、直播话术等**文字内容**）进行合规风险审查，逐条识别违规点、分类分级、给出修改建议，并以飞书文档形式输出一份完整的审查报告。

## 本技能不做什么（先读，避免越界）

- 不撰写营销文案，仅审查已有文案的问题并给出修改建议。
- 不对宣传内容是否真实进行证实，仅识别哪些主张需要证实、以及应由谁提供数据。
- 不审查素材设计或图像，仅审核文字内容。
- 不审查营销素材的知识产权实体合规（无数据比对素材来源、是否存在权利瑕疵）；仅在活动名称/标识层面做商标风险提示。

## 审查流程（五步）

### 第 1 步：对宣传文案逐条拆解

通读文案，列出每一个**宣传主张和事实性陈述**。精确引用原文，不要概括或改写，以免遗漏违规点。

### 第 2 步：检索适用规则并做来源标记

基于每条宣传主张所涉及的分类，按下文「适用规则检索与来源标记」检索所适用的法律法规与规则，并对每条引用做来源标记。

### 第 3 步：分类并检查

结合适用规则，对每条宣传逐条分析，给出**素材风险分类**（见下文「素材风险分类」）和**风险分级**（高/中/低风险），以表格形式呈现如下内容：

- **宣传文案**：[直接引用对应的宣传文案原内容]
- **类型**：[活动名称商标风险排查 / 模糊主观宣传 / 虚假宣传或夸大宣传 / 绝对化用语 / 引用数据 / 比较性宣传 / 暗示性宣传 / 文案不健康 / 未成年人定向 / 格式条款 / 数据对外披露 / 风险行业营销合规 / 过度承诺或效果保证 / 歧义性措辞 / 价格合规 / 有奖促销 / 其他]
- **是否违反审核规则**：[是 — 来源链接 | 否 | 未知]
- **审核结论**：[可保留 | 待核实 | 需修改 | 需删除]
- **修改后的文案**：[在保持宣传力度的同时的替代措辞]
- **修改原因**：[一句话描述修改原因]

### 第 4 步：对照产品检验

提示用户就产品功能、性能、效果等宣传描述向产品经理核实，对照产品本身的能力，确认宣传主张是否超出产品能力范围或与事实不符。

### 第 5 步：输出审查报告

以**一份飞书文档**形式输出完整报告（模板见下文「输出报告模板」）。

## 适用规则检索与来源标记

### 1. 检索适用规则

检索用户上传营销素材所适用的法律法规与规则，可能包括：《广告法》《消费者权益保护法》《反不正当竞争法》《反垄断法》《价格法》《互联网广告管理办法》《规范促销行为暂行规定》、市场监管总局广告执法指南、金融/医疗/三品一械/特殊化妆品/教育培训等风险行业的监管规则和营销合规要求、营销素材发布平台关于营销内容合规的平台规则、广告违法行政处罚案例、广告文案相关舆情报道。

**关键：仅引用真正适用的规则。** 素材不涉及引证推荐 → 不引用引证/推荐规则；不涉及数据对外披露 → 不引用数据披露规则；不涉及特殊风险行业 → 不引用风险行业监管规则。避免堆砌无关依据。

### 2. 来源标记

对检索到的每条引用规则标注来源并附来源链接。**逐一检查链接是否可打开、是否为过期失效链接，不得编造来源或链接。** 同时按可靠性分级标记：

- **【已确认适用规则】** 稳定、必须参考的法律法规规定。例如《广告法》关于虚假广告、绝对化用语、禁止发布广告的规定，市场监管总局的广告执法指南或指引。
- **【需核实是否适用规则】** 引用来源有待用户核实。例如广告违法案例、平台营销内容审核规则、司法案件判决、地方市场监管部门执法行动或广告指引等——此类来源可能频繁更新，或不适用于具体地域/平台/营销产品，应由用户单独核实是否可引用。
- **【用户提供规则】** 用户自主上传提供的审核规则或标准。

### 3. 加强审查标记

如果营销素材包含**暗示性宣传**或**比较性宣传**，标记为「加强审查」。

## 素材风险分类

营销素材涉及以下维度时，按对应规则开展风险排查与分类。

### 活动名称商标风险排查

素材涉及营销活动、产品运营活动名称时，对名称做命名风险排查。短期一次性活动应使用**通用/描述性**名称（如"XX 平台食品饮料双十一激励活动"），相关文案也用通用/描述性名称，不得使用包含他人在先商标的活动名称。

判定存在商标风险的标准：
1. 使用了非通用/描述性、具有一定显著性的活动名称（如"掘金计划""一城一味"）；
2. 重要活动——用户在提示中明确提示为重要活动、S 级活动，需提示触发用户单独开展商标风险排查；
3. 素材涉及使用 IP 形象、图形、商业标识，该标识可能与在先商标存在相似性。

### 模糊 / 主观宣传

无可衡量、无具体内容的主观断言；是否可用取决于语境和受众。

| 反面素材示例 | 不建议使用的原因 |
|---|---|
| "比 XX 竞争对手快一倍" | 缺乏比较的基准数据、统计周期 |
| "深受千万用户信赖" | 模糊性表述用户数量 |
| "保障数据公正" | 谁来保障？ |
| 价格优势类描述，如"低于市面 30%-50%""市面最低价" | 数据是否有依据和公信力？ |
| "权威认证/权威平台/权威内容/权威专家/权威背书" | 权威标准是什么？谁来认定？ |

### 比较性宣传（加强审查）

直接或暗示与竞争对手比较，审查前应充分检索适用的比较广告规则。

| 反面示例 | 修改方向 |
|---|---|
| "比 XX 工具更快" | 用权威数据引证做对比，或抽象为"比传统工具更快"并附引证数据 |
| "唯一能做 X 的平台" | 若别的平台也能做，则涉嫌虚假宣传，应删除"唯一" |
| "[竞争对手]做不到这个" | 通过功能展示和描述，让观众自己比较 |

### 暗示性宣传（加强审查）

未明确陈述但理性受众会推断的内容。暗示性宣传通常承担与明示宣传相同的证实负担。

| 反面示例 | 暗示 | 修改方向 |
|---|---|---|
| 展示无上下文的品牌 logo 或品牌名称 | 这些品牌/企业为产品背书或是产品用户 | "我们的用户/客户包括……""受到……品牌的信赖" |
| "银行级安全" | 获得金融监管机构认可 | 除非获得金融监管机构有效认证，否则该宣传易误导消费者 |

### 绝对性宣传（加强审查）

是否涉及《广告法》、市场监管总局《广告绝对化用语执法指南》中的绝对化用语。

| 反面示例 | 修改方向 |
|---|---|
| "最受欢迎""遥遥领先" | 使用"顾客至上""力争最有价值品牌"等表示经营理念和目标诉求的用语 |
| "销量第一""顶级""第一品牌" | 客观表述可查证的销量、销售额、市占率，并提供引证数据 |
| "保证" | 应避免效果承诺或过度承诺 |
| "始终"/"每个"/"永久" | "通常"/"大部分" |

### 文案内容不健康

应以健康的表达形式呈现，避免激进表述、不健康网络流行语、企业内部黑话，避免对用户或特定人群进行物化、分级或歧视。

| 反面示例 | 修改方向 |
|---|---|
| "抢占/抢夺/捕获/占领用户认知""认知运维永不宕机" | "激发用户兴趣/获取用户青睐""99.9% 正常运行时间"（附定义该指标的 SLA） |
| "收割/捕获用户""100% 准确" | "转化用户"；一个具体、附证实的百分比并绑定到基准 |
| "逼格保证" | "格调"；"保证"仅当确实提供附条款保证——会创设担保责任 |
| "高价值人群/低价值人群/优质人群/低质量人群/高价值线索""洗脑""始终/每个" | "高潜力人群/高意向人群/高兴趣人群""通常/大部分" |

### 未成年人定向广告投放

不得向未满 18 周岁未成年人投放酒类广告或其他可能导致未成年人沉迷、引发不良嗜好等风险的广告；不得宣传在中小学校、幼儿园内及周边进行精准广告推送。

| 反面示例 | 修改方向 |
|---|---|
| "寒暑假就要到啦" | 暗示目标人群为学生，存在风险 |
| "受众年龄区间：18 岁以下" | 删除该内容 |

### 数据对外披露

应符合用户所在企业的对外公关数据口径要求，提示用户结合企业对外公关数据审查要求进行复核。可参考的对外口径原则：

- 满足真实性、必要性和最小化原则；
- 可公开的数据范围：企业此前已公开披露的数据；基于公开数据平台的数据；可置信的第三方发布的公开信息（需标注数据来源）；
- 涉及合作方（合作商家、达人、供应商）的数据，需获得合作方授权；
- 禁止对外或需单独评估后方可对外的数据：企业内部不可对外数据；未成年人数据；用户画像（需单独法务评估）；合作方未经授权数据；不可置信的研究机构数据；可能存在参与不正当竞争争议的排名。

### 格式条款

不得使用"解释权归 XX 所有"等格式条款内容。

### 有奖销售

抽奖活动最高奖金额/实物价值不超过人民币 5 万元。需明示：活动介绍、活动时间、参与条件、奖项的获奖条件、每一用户获奖次数、奖品发放者和发放方式、弃奖说明、免责条款、反作弊条款。

### 价格宣传违规

促销涉及价格描述、折扣、优惠计算的，不得虚构原价、虚假优惠折价、虚假宣传降价。

| 示例 | 修改模式 |
|---|---|
| "原价"及同义表述（原售价、券前价、券后价、吊牌价、扫码价、厂商指导价、专柜价、正品零售价、批发价、现价、划线价、折扣价、优惠价、特价、一口价、促销价、新品折、成交价、极品价、最低价等） | "原价"指本平台内、本次降价活动前七日内有交易票据证明的最低交易价格；前七日内无交易的，以本次降价活动前最后一次交易价格作为原价。须以有交易记录可证明的"原价"为依据，否则涉嫌"价格欺诈"。 |
| 降价促销 | 应说明降价期限、降价基准、降价条件等；没有确定的原价和降价基准时，避免随意使用"降价""折扣"等词。 |

## 触发额外的合规审查

素材涉及以下内容时，提示用户进行额外的合规审查：明星或达人推荐/评价、消费者评价、免费试用/自动续费。

## 输出报告模板

以**一份飞书文档**形式呈现，标题命名格式为「XX营销素材审查报告」。报告应包含：

1. **报告标题**：`XX营销素材审查报告`
2. **免责声明**（置于显著位置，每次输出自动展示，原文如下）：
   > 本内容仅为法律参考工具，不构成律师执业意见，不能替代执业律师专业咨询，具体案件请结合实际案情咨询专业法律人士。
3. **文案逐条分析**：对第 1 步提取的每条宣传，按第 3 步的结构逐条呈现（宣传文案/类型/是否违反审核规则/审核结论/修改后的文案/修改原因）。
4. **风险类型汇总**：按类型归类本次发现的问题。
5. **整体风险等级**：对全篇或各条给出风险等级（🔴 高 / ⚠️ 中 / ✅ 低）。
6. **修改后的完整内容**：给出整合后的合规版文案。
7. **发布前待核实事项清单**：列出发布前需由业务/产品/数据方证实的主张及应提供数据的责任方。
8. **引用检查**：列出本次引用的规则及其来源标记（【已确认适用规则】/【需核实是否适用规则】/【用户提供规则】）与链接，并确认链接有效。

## 输出注意事项

- **免责声明必须每次自动展示**，不得省略。
- 引用规则的来源链接必须真实有效、可打开，**不得编造**；无法确认有效性的标为【需核实是否适用规则】。
- 仅引用适用的规则，不堆砌无关法条。
- 保持宣传力度：修改建议应在合规前提下尽量保留原文案的营销效果，而非简单删除。
- 输出语言匹配用户使用的语言。
