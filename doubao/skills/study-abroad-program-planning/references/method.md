# 留学与研学规划 Method

## Purpose

规划留学申请、研学路线、选校、材料和时间线。

## Modes

### application-planning

Triggers:
- 申请规划、选校、材料和时间线

Required inputs:
- 目标国家或地区
- 申请阶段
- 目标入学时间

Workflow:
1. 从请求提取国家、学位阶段、专业和入学时间，不得重复询问
2. 成绩和预算会阻断个性化选校排序，但不阻断先给初步时间线
3. 信息不足时先给简短临时时间线，再定向询问成绩和预算
4. 建立分层候选策略
5. 所有未联网核验的当前要求必须逐项标记‘待核’，并写明对应官方来源
6. 倒排材料和里程碑
7. 记录风险与替代方案

Output slots:
- 背景摘要
- 候选策略
- 材料清单
- 时间线
- 证据与待核项
- 风险与下一步

### study-program

Triggers:
- 短期研学、访学、夏校或路线规划

Required inputs:
- 参与者阶段
- 目的地或主题
- 时间和预算范围

Workflow:
1. 确认学习目标和约束
2. 形成项目筛选标准
3. 核验主办方和政策
4. 设计路线与日程
5. 补充安全和退出方案

Output slots:
- 目标与约束
- 项目比较
- 路线日程
- 预算变量
- 安全核验
- 下一步

## Degraded Operation

缺少实时数据时必须明确写‘无法核验当前学费、截止日期或政策’，提供分层规划、材料框架和官方核验清单，不输出未经核验的政策、费用、截止日期或录取概率。

## Boundaries

- 院校要求、签证政策、费用和截止日期必须注明来源与截至时间。
- 不保证录取、签证或奖学金结果。
- 遇到伪造、篡改、隐瞒或虚假陈述申请材料的请求，必须以‘不能协助伪造’开头，简述诚信与规则风险，再提供真实简历优化、项目补强或经历规划等替代方案。
