# T2A

***使用 tools: `text_to_audio`***

用一段自然语言描述直接生成目标音频。描述可以是人声台词、环境声、音效、背景音乐，或它们的复合场景。

通用原则（原样保留用户描述、复杂场景单次调用、不篡改不拆分等）见 [`SKILL`](../SKILL.md)，本篇只说明 T2A 的调用与构造。

## 调用

`text_to_audio` 必填 `prompt`，可选 `duration`：

- `prompt`：用户的音频描述本体（去掉「给我生成一段音频」之类的意图前缀后的内容），原样传入。
- `duration`（可选，integer，1~120）：生成目标音频的时长，单位秒。**不推荐默认使用**——仅当用户直接说明要生成多少秒的音频时才设置此字段；用户未明确指定时长时不要传 `duration`，交由模型自行决定时长。

## tool input 构造示例

单句台词：

```json
{
  "prompt": "男性 (青年): \"你好呀!\""
}
```

带环境与音效的复合场景（整段作为一个 prompt）：

```json
{
  "prompt": "在一个安静的咖啡馆，背景音乐是舒缓悠扬的钢琴。一阵高跟鞋走路的声音，伴随推开门的声音，青年女性说到：\"你好，让你久等了\". 紧接着一个青年男性：\"没事，我也没等多久\", 紧接着是咖啡杯在桌面上推动的轻轻的摩擦声，青年男性：\"这是给你点的拿铁，慢点喝，热\""
}
```

`duration` 不是音频描述的硬分界符（见 [SKILL](../SKILL.md)）：时长可以是 `prompt` 的一部分，同时从用户意图中提取时长值进 `duration`；只有当用户用明确话术划出描述结束处时，描述才到那里为止。下面用「用户原始输入 -> tool input」展示映射。

用户原始输入：「生成一段优雅的交响乐，时长 30 秒」

```json
{
  "prompt": "生成一段优雅的交响乐，时长 30 秒",
  "duration": 30
}
```

用户原始输入：「海边清晨，海浪轻拍沙滩，远处有海鸥叫声。备注：时长 20 秒。」

```json
{
  "prompt": "海边清晨，海浪轻拍沙滩，远处有海鸥叫声",
  "duration": 20
}
```

后续轮次若用户只调整时长（如「再长一点，至少 30 秒」）而未给新描述，则 `prompt` 沿用上一轮、仅更新 `duration`。

## 描述形态示例

以下都是 prompt 的合理形态，构造时**原样使用**：

- 单句台词：

  ```
  男性 (青年): "你好呀！"
  ```

- 带环境与音效的复合场景：

  ```
  在一个安静的咖啡馆，背景音乐是舒缓悠扬的钢琴。一阵高跟鞋走路的声音，伴随推开门的声音，青年女性说到："你好，让你久等了". 紧接着一个青年男性："没事，我也没等多久", 紧接着是咖啡杯在桌面上推动的轻轻的摩擦声，青年男性："这是给你点的拿铁，慢点喝，热"
  ```

- 纯环境/音效（无人声）：

  ```
  雨夜，远处偶尔传来几声犬吠，雨点打在铁皮屋顶上
  ```

- 纯人声旁白：

  ```
  沉稳的中年男性，语速缓慢，像在念独白："那一年，我第一次见到海"
  ```
