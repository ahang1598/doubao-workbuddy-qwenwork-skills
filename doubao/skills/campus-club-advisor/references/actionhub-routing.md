# 豆包 ActionHub 路由与挂载

## 1. 发布元数据

发布时以 `agents/openai.yaml` 为准：

```yaml
display_name: 校园社团匹配与面试准备
short_description: 按新生兴趣、性格偏好、时间与技能匹配真实社团并准备招新面试
```

不要把展示名改成“面试助手”“校园推荐”或“生涯规划”，这些名称会扩大召回并与求职、
升学和校园检索能力冲突。

## 2. 所需工具

学校定向推荐需要 ActionHub 挂载：

- `general_search`：发现学校官网、校团委/学生工作部门、官方名录和招新线索；
- `web.fetch`：打开原始页面并核验标题、正文、发布日期与来源关系。

Skill 不自带搜索引擎、浏览器、TasteRay API 或学校数据库。普通用户不提供 API key；密钥、
权限和服务条款由应用发布者管理。无工具时按 SKILL.md 降级，不得把模型记忆包装成实时查询。
具体学校请求的来源优先级、证据字段、时效状态和停止条件见
[学校社团真实性核验协议](school-club-verification.md)。

## 3. 正反例

| 测试表达 | 期望路由 |
| --- | --- |
| 我喜欢摄影，性格慢热，每周 4 小时，适合什么大学社团 | 本 Skill，通用类型探索 |
| 我是 X 大学 Y 校区新生，查真实存在的社团并推荐 | 本 Skill，先学校核验 |
| 摄影协会和青年志愿者协会哪个更适合我 | 本 Skill，先判断是否为具体学校候选 |
| 帮我准备学校辩论队招新面试 | 本 Skill，先核验选拔形式 |
| 帮我准备字节跳动产品经理实习面试 | 求职面试能力 |
| 帮我选适合申请的研究生学校 | 院校/项目匹配能力 |
| 我是内向型，给我做完整人格测试 | 心理测评能力 |
| 帮我规划毕业论文题目 | `paper-research-opening` |
| 查今天学校有哪些讲座和活动 | 校园活动检索能力 |
| 给社团写一份秋季招新推文 | `build-club-recruitment-kit` |
| 给社团写章程、财务制度或全年运营方案 | 通用写作/运营能力 |

混合请求“推荐社团并说明如何写进求职简历”：本 Skill 先完成社团匹配；简历包装必须由用户
确认切换后交给求职材料能力，不能自动跨路由。

## 4. 平台验收

每条正反例至少运行三次，记录实际命中、工具链、最终交付物和是否误触其他 Skill。重点检查：

- “社团面试”不被求职面试 Skill 抢占；
- “报名者准备回答”和“负责人设计题目”分别命中本 Skill 与 `build-club-recruitment-kit`；
- “学校 + 推荐”不被升学选校能力抢占；
- “兴趣 + 性格”不被人格测评能力抢占；
- “真实社团”触发联网核验，工具缺失时按规定降级；
- 学校名未唯一定位时不会生成具体名单。

如果平台仍无法稳定区分，应由发布者调整 ActionHub 优先级或设置主交付物分流；不能继续靠
在 Skill 正文中堆关键词解决。
