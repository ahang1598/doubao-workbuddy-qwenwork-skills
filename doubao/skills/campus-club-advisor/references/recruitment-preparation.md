# 社团招新准备

## 1. 先确认选拔形式

从已核验来源确定：开放报名、面试、试演、作品集、笔试、体能测试或混合流程。来源没有
说明时写 `unknown`，把后续问题标记为“通用预测”。不要把求职面试题原样套给学生社团。

## 2. 证据故事库

围绕以下六类真实经历各准备 1 个，允许来自课程、小组作业、兴趣练习、志愿活动、家庭
事务或个人项目：

1. 兴趣起点：为什么愿意持续投入，而不是“因为好玩”。
2. 合作：如何倾听、分工、处理分歧或帮助队友。
3. 主动性：在没有人催促时做过什么具体行动。
4. 挫折反思：哪里没做好，后来如何调整。
5. 技能或作品：能展示什么，下一步想提高什么。
6. 时间承诺：如何安排固定活动、训练、排练和考试周。

使用 `背景-行动-结果-反思`（CARR）组织：

- 背景：一句话说明场景和目标；
- 行动：重点说“我”实际做了什么；
- 结果：使用可观察变化，数字只有真实存在时才写；
- 反思：说明学到了什么，以及如何用于该社团。

没有经历时诚实说明，改用小型练习或入社后的学习计划，不能编造角色、奖项、作品或指标。

## 3. 45-60 秒自我介绍

结构：

1. 简短身份：年级/专业仅在用户愿意提供时使用；
2. 与社团相关的兴趣或经历；
3. 可贡献的一项能力；
4. 想学习的一项能力；
5. 可持续投入的时间与加入动机。

避免背诵简历、空泛夸奖社团、过度承诺时间或使用并不掌握的专业术语。

## 4. 问题生成

只有官方来源、用户提供的招新说明或明确的社团活动可以支持“定向问题”。其他问题必须标为
“通用预测”。常见问题范围：

- 为什么选这个社团，而不是同类社团；
- 对近期一项公开活动/作品的理解；
- 能贡献什么、最需要学习什么；
- 团队分歧、任务拖延或临时变化如何处理；
- 固定训练/值班/排练与考试冲突怎么办；
- 对试用期、基础工作和反馈的态度；
- 一个真实作品、练习或兴趣经历。

为每题提供回答要点和证据故事映射，不提供需要逐字背诵的虚假“满分答案”。

## 5. 模拟与反馈

一次只问一题并等待回答。反馈维度各 1-5 分：

| 维度 | 检查点 |
| --- | --- |
| 相关性 | 是否回答了问题，并连接到该社团 |
| 具体性 | 是否有具体行动或可观察细节 |
| 真实性 | 是否与用户已提供经历一致，没有夸大 |
| 表达 | 是否结构清楚、时长合适、口语自然 |

反馈顺序：先复述有效信息，再指出一个最高优先级改进点，给出一个更好的组织示例，然后让
用户重答。不要一次倾倒所有问题和长篇标准答案。

## 6. 非面试流程

- 试演/体能：核验项目、时长、服装器材和安全要求，设计短周期练习，不提供危险训练。
- 作品集：选择 3-5 个真实作品，写清个人贡献、过程、限制和想改进之处。
- 笔试：按官方范围整理知识点和练习；范围未知时不猜真题。
- 开放报名：准备简短自我介绍、时间确认和向社团提问的问题，无需制造面试压力。

## 7. 用户反问

优先询问：新人培养、真实周投入、考试周安排、试用期、退出机制、费用、跨校区活动、
无障碍需求、作品归属和安全责任。不要问官网已明确且无需澄清的基本信息。
