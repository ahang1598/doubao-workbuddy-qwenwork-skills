# 证据来源、检索与评价

本文件只管“按什么顺序查、优先查什么、哪些证据可用、如何记录和评价”。问题拆解、检索批次和预算见 `core-workflow.md`；图表见 `synthesis-and-visualization.md`；最终文档结构和交付 QA 见 `output-and-qa.md`。

## 1. 检索顺序

`full_report` 先初始化内部 literature-log CSV，再调用检索工具。以下是用户未限定证据类型时的默认顺序；每一步只围绕当前检索批次和子问题，不做无目的的全库扩展。

用户明确强调“最新”“近期”“刚发布”或“最新进展”时，适度前移并提高 `general_search` 的优先级，先补充检索 `scholar_search` 可能尚未及时收录的最新指南更新、期刊在线发表、学会公告和监管信息；这些结果仍须核验发布机构、日期与正式入口，并继续用 `scholar_search` 覆盖相关研究证据。

1. `scholar_search`：优先检索近 5 年学术文献以及最新版指南/共识，覆盖中国和国际指南、系统综述、Meta 分析、RCT、大型队列、诊断研究、真实世界研究、里程碑研究和高影响力期刊论文。
   - 临床实践相关主题先定位最新版中国临床指南、本土专家共识、国家卫健委、中华医学会、中国医师协会或专科学会文件，再补国际权威指南和关键研究。
   - 指南/共识任务可按用户需求寻找推荐所依据的关键研究和更新证据；若用户明确只查指南或共识，停留在该范围，不扩展研究论文。
   - 综述、课题、研究进展或论文写作任务以本步骤为主要检索阶段。
2. `general_search`：其次用于前述工具未返回的学会官网、政府/监管页面、期刊原文入口、DOI 页面、临床试验注册或公开 PDF。需要核对药品适应证、禁忌、剂量、特殊人群、相互作用或说明书警示时，先按“`小荷医典 + 药品通用名 + 药品说明书`”检索可访问说明书页面，并核对药品名称、剂型和来源；找到可访问且可核验的小荷医典说明书后，正文、安全性分析和参考文献优先引用该页面链接。
3. `medical_search`：搜索工具中的最后补充，只能用于药品说明书。仅当 `general_search` 按上述方式仍找不到、打不开或无法核验说明书时调用；不得用于检索指南、共识、论文、一般医学知识、监管新闻或器械资料。不涉及说明书时跳过。
4. WebFetch/`web.fetch`、PDF 解析或 OCR：候选文献完成初筛并记录后，对 1-3 份最能支撑结论、图表或正式引用的资料定向读取正文。
   - 只读取推荐条文、摘要、研究设计、主要结果、关键表格、安全性、亚组和局限。
   - 搜索结果片段只能用于初筛，不能冒充正文或原文引用片段。

若某个具名工具在当前环境不可用，使用具备同等能力的工具替代，但仍遵循“学术文献与指南 → 权威网页及小荷医典说明书检索（按需）→ 最后补充说明书检索 → 核心全文阅读”的顺序。内部工具名不得出现在报告、PPT、Word、CSV 或最终回复中。

默认搜索工具优先级为 `scholar_search → general_search → medical_search`；用户明确强调最新性时，按上方规则前移 `general_search`。可核验的小荷医典说明书是药品说明书的优先引用入口；只有其缺失或不可用时，才引用 `medical_search` 补充获得的说明书。没有药品说明书核对需求时直接跳过。无论说明书来自哪一步，纳入时都必须立即记录原标题、机构、级别、纳入理由和可访问链接。WebFetch/PDF/OCR 不得在高相关候选完成初筛和记录前用于漫无目的浏览，也不为凑轮次强行调用无关工具。

用户明确限定证据类型时，该边界优先于默认覆盖顺序。只查指南/共识时，`scholar_search` 和 `general_search` 仅用于定位、核对和读取指南/共识及其官方入口，不启动系统综述、RCT、队列或其他研究论文批次；参考文献也只纳入限定范围。其他“只查某类文献”的要求按同样原则执行。

用户明确指定期刊、学会、机构或数据库时，先完整覆盖并突出该范围；仅在补充必要背景、关键证据缺口或核验结论时少量扩展其他来源，扩展结果不得替代、稀释或挤占用户指定范围。

### 医学资讯跟踪链路

当用户要求“医学资讯跟踪”“近期动态”“最新消息”“最近发布”或持续关注某领域时：

1. 先用 `general_search` 按用户指定时间窗检索权威机构、专业学会、监管部门、期刊官网/在线优先、会议官网和临床试验注册平台；未指定时间窗时优先最近 3-12 个月，并记录检索截止日期。
2. 对每条动态记录事件/发布日期、发布主体、资讯类型和可点击正式入口；同一研究的新闻稿、期刊页、会议摘要和注册更新合并为一个事件链，不重复计数。
3. 再用 `scholar_search` 定位对应论文、指南或既往关键证据，说明该动态是正式发表、在线优先、会议摘要、试验注册变化、监管/学会公告还是机构新闻稿。
4. 正式来源尚未覆盖非常新的主题时，可通过 `scholar_search` 或 `general_search` 少量补充与问题高度相关的 `arXiv`、`medRxiv` 或 `bioRxiv` 预印本。记录平台、发布日期和可点击入口，显式标注“预印本/未同行评议”，不为了增加新颖性批量搜集预印本。
5. 按时间或主题整合“发生了什么、对应证据是什么、证据成熟度如何、对领域有何增量意义”。新闻稿、媒体报道和预印本可作为动态或前沿线索，但不能脱离更成熟证据写成已确立的疗效与安全性结论。
6. 若只有预印本、公告或会议消息而尚无正式论文，明确写“尚待同行评议/正式发表/进一步核验”，不推断未披露的方法和结果。

医学资讯跟踪仍遵守总检索预算；它是最新性补充链路，不要求为每条资讯额外增加检索轮次，也不把普通媒体报道扩展成无边界新闻汇编。

### 任务起始边界

| 任务重点 | 必须优先覆盖 | 后续重点 | 不应扩展到 |
|---|---|---|---|
| 指南/共识查新 | 最新中国指南/本土共识；再查国际指南 | 指南更新依据、关键研究和差异点 | 无关疾病、旧版替代新版、非权威解读 |
| 疗效、诊断或干预证据 | 权威指南用于界定人群和结局 | 系统综述、RCT、队列、诊断研究 | 与目标人群或结局无关的机制研究 |
| 药品、器械和安全性 | NMPA/说明书/国家或学会规范；必要时 FDA、EMA | 高质量安全研究、特殊人群证据 | 自媒体药品解读、商业宣传页 |
| 研究进展、热点或综述 | 近 1-5 年高质量综述和关键研究 | 指南更新、注册研究、争议与空白 | 只凭标题词频推断热点 |
| 医学资讯跟踪 | 近期权威机构、学会、监管、期刊和会议正式页面 | 对应论文/指南/注册记录；少量高度相关的 arXiv、medRxiv 或 bioRxiv 预印本；证据状态和时间线 | 无来源转载、营销新闻、批量堆叠预印本、把新闻稿或预印本当作成熟研究结论 |
| 里程碑与证据脉络 | 奠基性研究和经典高被引研究 | 后续验证、指南采纳和最新进展 | 用“近 5 年”机械排除经典研究 |
| 课题或论文写作 | 与论点直接相关的综述、原始研究和方法来源 | 争议证据、研究空白和可引用段落 | 为凑引用加入不支持论点的文献 |
| 教学或学习资料 | 最新指南、高质量综述和权威教材 | 经典研究和实践资料 | 用教材旧观点替代最新证据 |

中国来源优先适用于中国临床实践、药品可及性、本土人群和国内规范相关问题；全球研究进展、基础机制或国际课题不机械要求中国证据占主导，但用户涉及中国实践时必须补充本土证据。经典里程碑研究不受年份限制；“最新进展”默认优先近 1-5 年。

## 2. 证据准入与覆盖

### 核心证据准入

核心证据必须同时满足：

1. 有可点击原文、官方指南页、监管页、期刊页、PubMed/PMC、PDF 或 DOI 解析入口。
2. 已打开正文、指南原文、期刊页或其他可核验官方入口。
3. 能定位到支持结论的推荐、结果、表格、章节、摘要结果或研究数据。
4. 与用户的主题、人群、干预/暴露、对照、结局或论文论点直接相关。

只有题名、PMID/DOI 字符串、搜索结果片段、二次转载或无可点击入口时，不得作为核心证据。核心或辅助角色按研究质量、来源权威性、主题匹配度和时效性判断，不按全文可及性机械分组；未阅读全文时只使用实际可核验的页面或摘要内容，不推断未见的全文细节。低级别、不权威、方法学薄弱或相关性不足的资料归为辅助参考，不得单独支撑关键疗效或安全性结论。

### 默认证据覆盖量

引用数量以覆盖问题和用户指定范围为目标，不机械凑数。用户未限定证据类型时，`full_report` 通常覆盖：

| 证据类型 | 建议范围 | 主要用途 |
|---|---:|---|
| 指南/共识 | 2-6 条 | 推荐、适用人群、更新点和实践边界 |
| 系统综述/Meta | 2-6 条 | 总体方向、异质性和确定性 |
| 关键研究 | 4-12 条 | 里程碑、核心 RCT、队列、诊断或真实世界证据 |
| 最新进展 | 3-10 条 | 近年新证据、新技术、新药物或争议 |
| 安全/监管 | 1-4 条 | 禁忌、警示、特殊人群和监管变化 |
| 本土/专科证据 | 按需 | 中国规范、人群差异和实践背景 |
| 教材/实践资料 | 按需 | 学习框架、概念和实践解释 |

`quick_answer` 只需 1-2 个高价值批次，优先使用足以回答问题的高质量来源，不预设可见来源篇数；回答中凡提到具体外部证据，都必须给出该来源自己的可点击 URL，并确保每项核心检索结论可追溯。无法取得 URL 的候选不得作为具名依据写入回答；没有可核验链接时明确检索限制并降低确定性。`full_report` 定向精读 1-3 份核心资料；证据角色由质量、权威性、问题匹配度和时效性决定，不由访问层级决定。用户限定范围内某类证据缺失时明确披露，不用范围外文献或低质量来源补数。

### 来源等级

CSV 的 `evidence_level` 沿用本 Skill 的 A/B/C/D 来源与证据初步级别，不等同于原文 GRADE 或正式推荐等级。

| 等级 | 来源 | 使用边界 |
|---|---|---|
| A | 最新中国或国际权威指南/共识、监管机构和说明书、Cochrane/高质量系统综述、高质量 RCT、大型队列、顶级或核心期刊关键研究 | 支撑核心结论 |
| B | 质量较好的观察性、真实世界或诊断研究，卫生技术评估、权威教材/专著、临床路径和可靠专科资料 | 补充证据与实践背景 |
| C | 小样本单中心研究、病例系列/报告、会议摘要、预印本、低质量叙述性综述、机制/动物/体外研究 | 前沿线索或低确定性补充 |
| D | 自媒体、营销软文、问答社区、搜索结果页、来源不明转载、疑似垃圾期刊或无法核验页面 | 禁止作为依据 |

## 3. 内部文献记录

`full_report` 开始时创建：

`literature-logs/{{YYYYMMDD}}-{{topic_slug}}-literature-log.csv`

从 `assets/literature-log-template.csv` 复制 UTF-8 with BOM 表头。文件名和内容不得包含患者姓名、身份证、手机号、住院号等敏感信息。CSV 只保留 9 个业务字段和 1 个链接字段，不记录检索批次、完整 query、筛选状态、图表用途、内部工具名、DOI/PMID 等过程字段。

| 字段 | 含义 | 填写规则 |
|---|---|---|
| `evidence_id` | 内部稳定主键 | 仅在 CSV 中使用 G/SR/R/N/S/T/C 前缀并保持稳定；不得渲染到用户可见产物 |
| `citation_number` | 顺序编号 | 文献去重并确定保留后，按写入 CSV 的行顺序直接填下一个 `1, 2, 3...` 纯数字；不按正文顺序规划或回填 |
| `original_title` | 文献原标题 | 填官方页面或原文显示的完整原标题，不擅自翻译或缩写 |
| `publication_type` | 类型 | 指南、共识、系统综述、Meta、RCT、队列、诊断研究、安全监管、教材等 |
| `journal_or_institution` | 期刊或机构 | 论文填期刊；指南、共识、说明书、监管文件填发布机构 |
| `year` | 年份 | 填发表、发布或更新年份；无法核验时写 `未核验` |
| `evidence_level` | 级别 | 填本 Skill 的 A/B/C/D 初步级别；不冒充原文 GRADE 或推荐强度 |
| `abstract_or_excerpt` | 摘要或片段（如有） | 可留空；只写实际读取到的摘要、推荐条文或关键结果短片段，不用搜索结果片段冒充原文 |
| `inclusion_reason` | 纳入理由 | 必填；说明该资料为何纳入本次正文、图表、参考文献或辅助证据 |
| `url` | 可访问链接 | 必填；用于真实性回查和正文可点击引用 |

写入规则：

- 每轮先完成题名、来源、类型和相关性初筛，再把拟纳入正文、图表、参考文献或保留为辅助参考的记录及时追加到 CSV。
- 默认每批次初筛 4-10 条候选；CSV 只保留纳入或辅助记录。排除项不占用 CSV 列，在“检索策略与证据范围”中汇总排除原则和数量即可。
- 同一文献只保留一行；按题名、官方入口或研究身份合并重复结果后再编号，避免同一来源获得多个 `citation_number`。
- `url` 必须是可点击 HTTP(S) 原文、摘要或官方入口；只有 DOI/PMID 线索时继续补充 URL。生成文档时不新增 CSV 列，而是根据已有 URL 派生 `link_label`：当前 URL 直接指向 PDF，或已有结果明确标识为 PDF 资源时写 `PDF`，其他期刊页、PubMed、DOI、指南官网或摘要页统一写 `原链接`；不为判定标签额外逐条打开网页。
- 使用标准 CSV 转义。含逗号、换行、双引号、长摘要或原文片段的字段用英文双引号包裹；字段内双引号写成两个双引号。
- 文献去重并确定保留后，立即按 CSV 当前行顺序写入下一个 `citation_number`；不等待全文规划，不按首次出现顺序回填，也不因章节顺序变化而重编号。
- 生成文档、PPT 或 Word 时，可见 `[n]` 直接复用同一行已有的 `citation_number`；禁止为不同章节或图表另建一套文献编号。
- 写正文前，为每条将进入用户可见产物的记录补齐除可选 `abstract_or_excerpt` 外的全部字段；不得使用 `anchor_text`、`citation_role`、`supports_conclusion` 等额外 CSV 列。

## 4. 初筛与原文阅读

### 初筛顺序

1. 是否直接回答当前子问题或论文论点。
2. 人群、干预/暴露、对照、结局和研究场景是否匹配。
3. 来源机构、年份、期刊和研究设计是否可靠。
4. 摘要或简介是否提供可用结果，而非只讨论背景。
5. 是否有可点击原文、摘要、官方入口、期刊页或 DOI 页面。

### 原文阅读边界

只对会进入核心结论、图表或正式参考文献的高价值证据定向精读，不重复 Fetch 同一页面，不把整页网页或整篇 PDF 塞入上下文。

- 指南/共识：推荐条文、推荐强度、证据等级、适用人群、更新日期、排除范围、推荐理由和指南差异。
- 系统综述/Meta：PICO、检索范围、纳入研究、偏倚、异质性、主要结果、敏感性分析和作者结论边界。
- RCT/队列/真实世界研究：样本量、入排标准、干预/暴露、对照、主要终点、效应量、置信区间、安全性、亚组和局限。
- 诊断研究：目标人群、指标检查、参考标准、敏感度、特异度、LR、AUC、PPV/NPV 和误判后果。
- 热点/趋势：主题簇、年份和研究类型变化、代表性研究；没有完整文献计量数据时，不声称完成正式 bibliometric 分析。
- 论文写作：逐句核对文献是否真的支持拟写论点，不为补引用扩大原文结论。

## 5. 证据评价

| 证据类型 | 重点评价 |
|---|---|
| 指南/共识 | 机构权威性、系统检索、证据等级、推荐强度、利益冲突、更新日期和适用范围 |
| 系统综述/Meta | PICO、检索充分性、纳入研究质量、异质性、发表偏倚、敏感性分析和稳健性 |
| RCT | 随机、分配隐藏、盲法、样本量、主要终点、ITT、安全性和失访 |
| 观察性研究 | 混杂控制、暴露/结局定义、选择偏倚、随访和因果推断边界 |
| 诊断研究 | 参考标准、代表性、盲法、诊断性能和误判后果 |
| 真实世界研究 | 数据源、缺失数据、混杂校正、外推性和可重复性 |
| 机制/基础研究 | 模型与临床人群差异，不直接外推临床疗效 |
| 教材/实践资料 | 仅用于概念和路径解释，并与最新版指南和研究互证 |

不要声称完成“正式 GRADE 评级”，除非原文采用 GRADE 或等价体系；无原文分级时只能写“按研究设计和偏倚风险初步判断”。

## 6. 引用映射与诚信

证据 ID 统一使用：`G` 指南/共识、`SR` 系统综述/Meta、`R` 原始研究、`N` 最新进展、`S` 安全/监管、`T` 教材、`C` 中国/本土证据。同一资料在内部记录中保持同一 `evidence_id`，用于稳定追踪；不得显示在用户可见产物中。`citation_number` 是另一个只存纯数字的展示序号，不替代、不改写 `evidence_id`；渲染时才加方括号形成 `[1]`、`[2]`。同一文献在正文、两张主图、图例和文末参考文献中始终使用同一行 CSV 的 `citation_number`。

正文首次出现具体来源时，使用内部记录的 `original_title + url` 生成可点击原标题或稳定简称，并标注期刊/机构、年份和级别，例如：

`[DAPA-CKD]({{url}})（NEJM，2020，A 级来源/高质量 RCT）`

不得只写编号、PMID、DOI、纯文本题名或裸 URL。采用 `[1]` 等展示序号时，序号必须与同句的可点击文献名或紧邻的可点击来源共同出现。飞书 XML 不使用 HTML 上标标签；直接使用可点击文献名，citation 样式组件也必须承载可点击来源。

引用诚信要求：

- 每个引用只支撑原文实际能支撑的句子，区分背景、核心结论、安全、争议、方法和研究空白用途。
- 不根据摘要扩展未报告的数据，不把来源类型写错，不把方向不一致的研究笼统写成“研究均显示”。
- 直接引用只保留必要短片段并标注来源；不复制长段原文。
- 正文出现的每个文献名或研究简称都能通过同一行 CSV 的 `evidence_id`、`citation_number` 和 `url` 追溯到同一可点击来源与参考文献条目。
- 无论用户要求 Vancouver、AMA、APA 或 GB/T 7714，最终展示的每条文献仍必须有可点击来源入口；具体参考文献表结构见 `output-and-qa.md`。

## 7. 单一内部证据源

literature-log CSV 是检索、筛选、编号、正文引用、图表节点和参考文献的唯一结构化内部证据源，不另建 JSON 证据表。报告中的对照表、证据矩阵和参考文献表均从同一 CSV 派生，避免重复维护和字段漂移。

仅对确实阅读全文的重要论文，可在正文解读的类型或来源后标注 `已阅读全文`；其他资料不设置阅读状态字段。
