# 证据来源、检索与评价

本文件只管“按什么顺序查、优先查什么、哪些证据可用、如何记录和评价”。问题拆解、检索批次和预算见 `core-workflow.md`；图表见 `synthesis-and-visualization.md`；最终文档结构和交付 QA 见 `output-and-qa.md`。

用户要求国标著录或可投稿综述时，引用、论文格式及证据等级的稿件展示按 `review-manuscript-and-citations.md`；本文件的检索、评价和内部六列 CSV 流程继续适用。

## 1. 检索顺序

`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch。需要更细致的信息时，细化 Query，多次调用 `seed_medical_search` 获取推荐条文和上下文；也可使用 `general_search` 检索对应内容，再 fetch `general_search` 返回的可读取页面或 PDF URL。根据实际取得的内容进行分析和引用。

`full_report` 先初始化内部 literature-log CSV，再调用检索工具。`seed_medical_search` 直接调用；`scholar_search` 先用 `tool_search` 发现并读取合同。相互独立的搜索调用同批并行、批量发出并统一等待结果，不同资料方向可放在同一批。以下是用户未限定证据类型时的默认分工；每一步只围绕当前检索批次和子问题，不做无目的的全库扩展。

用户明确强调“最新”“近期”“刚发布”或“最新进展”时，指南/共识仍先用带 `filetype:guideline` 的 `seed_medical_search`，随后适度前移 `general_search`，补充可能尚未被医学或学术检索及时收录的最新指南更新、期刊在线发表、学会公告和监管信息；这些结果仍须核验发布机构、日期与正式入口，并继续用 `scholar_search` 覆盖相关研究证据。

1. `seed_medical_search`：检索临床指南/共识和药品说明书，可按主题或资料类型多次查询。
   - 指南 Query 必须包含 `filetype:guideline`，先定位最新版中国临床指南、本土专家共识、国家卫健委、中华医学会、中国医师协会或专科学会文件，再补国际权威指南。
   - 说明书 Query 必须包含 `filetype:drug`，并核对药品通用名/商品名、剂型、规格、生产企业或上市许可持有人、适用地区和版本日期。
   - 同时需要指南和说明书时分开查询，不用一个无类型限制的 Query 混查。
   - 指南/共识任务可按用户需求寻找推荐所依据的关键研究和更新证据；若用户明确只查指南或共识，停留在该范围，不扩展研究论文。
2. 研究论文优先使用 `general_search`、`scholar_search`；`scholar_search` 先用 `tool_search` 发现工具并读取实际参数合同。优先检索近 5 年学术论文，覆盖系统综述、Meta 分析、RCT、大型队列、诊断研究、真实世界研究、里程碑研究和高影响力期刊论文；综述、课题、研究进展或论文写作任务以本步骤为主要论文检索阶段。
   - 用户已安装且可用 PubMed MCP 时，仅在需要补充较新论文题录时适度调用其搜索/题录读取工具；使用当前合同实际支持的参数，并核对发表/更新日期、研究人群、样本与分母口径、效应指标及预印本状态。
3. `general_search` 同时用于定位学会官网、政府/监管页面、期刊原文入口、DOI 页面、临床试验注册、公开 PDF 或其他权威正式入口。
4. WebFetch/`web.fetch`、PDF 解析或 OCR：候选文献完成初筛并记录后，通常先对 1-3 份最能支撑结论、图表或正式引用的资料定向读取正文；只有缺口可能改变核心结论或存在明确关键事实缺口时，再定向补充。
   - 重点读取推荐条文、摘要、研究设计、主要结果、关键表格、安全性、亚组和局限；关键指南或论文读取足以解释结论的完整上下文及相关脚注。
   - 片段不足时换用更聚焦的 Query；仅在工具当前合同支持时扩大 `snippet`、`max_length` 等片段参数。
   - 论文搜索片段用于初筛；`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch，内容细节通过多次定向搜索获取，或 fetch `general_search` 返回的页面或 PDF，并按实际取得的条文及上下文分析和引用。

其他具名工具不可用时使用具备同等能力的工具替代，但仍遵循“医学检索覆盖指南/说明书 → 通用与学术检索覆盖论文 → 按需定位权威网页入口 → 核心全文阅读”的顺序。内部工具名不得出现在报告、PPT、Word、CSV 或最终回复中。

默认按内容分工：`seed_medical_search` 负责指南、共识和药品说明书；研究论文优先使用 `general_search`、`scholar_search`；可用的 PubMed MCP 仅适度补充较新论文题录。`general_search` 同时定位权威正式入口；用户明确强调最新性时，按上方规则优先覆盖最新正式发布信息。没有指南或说明书核对需求时跳过对应医学检索。无论说明书来自哪一步，纳入时都必须立即记录原标题、机构、年份和原始链接，级别与纳入判断直接用于正文。WebFetch/PDF/OCR 不得在高相关候选完成初筛和记录前用于漫无目的浏览，也不为凑轮次强行调用无关工具。

用户明确限定证据类型时，该边界优先于默认覆盖顺序。只查指南/共识时，使用带 `filetype:guideline` 的 `seed_medical_search` 优先定位指南，`general_search` 仅按需补充和核对官方入口，不启动系统综述、RCT、队列或其他研究论文批次；参考文献也只纳入限定范围。其他“只查某类文献”的要求按同样原则执行。

用户明确指定期刊、学会、机构或数据库时，先完整覆盖并突出该范围；仅在补充必要背景、关键证据缺口或核验结论时少量扩展其他来源，扩展结果不得替代、稀释或挤占用户指定范围。

### 医学资讯跟踪链路

当用户要求“医学资讯跟踪”“近期动态”“最新消息”“最近发布”或持续关注某领域时：

1. 先用 `general_search` 按用户指定时间窗检索权威机构、专业学会、监管部门、期刊官网/在线优先、会议官网和临床试验注册平台；未指定时间窗时优先最近 3-12 个月，并记录检索截止日期。
2. 对每条动态记录事件/发布日期、发布主体、资讯类型和可点击正式入口；同一研究的新闻稿、期刊页、会议摘要和注册更新合并为一个事件链，不重复计数。
3. 再用 `scholar_search` 定位对应论文、指南或既往关键证据，说明该动态是正式发表、在线优先、会议摘要、试验注册变化、监管/学会公告还是机构新闻稿。
4. 正式来源尚未覆盖非常新的主题时，可通过 `scholar_search` 或 `general_search` 少量补充与问题高度相关的 `arXiv`、`medRxiv` 或 `bioRxiv` 预印本。记录平台、发布日期和可点击入口，显式标注“预印本/未同行评议”，不为了增加新颖性批量搜集预印本。
5. 按时间或主题整合“发生了什么、对应证据是什么、证据成熟度如何、对领域有何增量意义”。新闻稿、媒体报道和预印本可作为动态或前沿线索，但不能脱离更成熟证据写成已确立的疗效与安全性结论。
6. 若只有预印本、公告或会议消息而尚无正式论文，明确写“尚待同行评议/正式发表/进一步核验”，不推断未披露的方法和结果。

医学资讯跟踪仍遵守总检索预算；它是最新性补充链路，不要求为每条资讯额外增加检索轮次，也不把普通媒体报道扩展成无边界新闻汇编。

### 任务起始边界

| 任务重点 | 必须优先覆盖 | 后续重点 | 不应扩展到 |
|---|---|---|---|
| 指南/共识查新 | 最新中国指南/本土共识；再查国际指南 | 指南更新依据、关键研究和差异点 | 无关疾病、旧版替代新版、非权威解读 |
| 疗效、诊断或干预证据 | 权威指南用于界定人群和结局 | 系统综述、RCT、队列、诊断研究 | 与目标人群或结局无关的机制研究 |
| 药品、器械和安全性 | NMPA/说明书/国家或学会规范；必要时 FDA、EMA | 高质量安全研究、特殊人群证据 | 自媒体药品解读、商业宣传页 |
| 研究进展、热点或综述 | 近 1-5 年高质量综述和关键研究 | 指南更新、注册研究、争议与空白 | 只凭标题词频推断热点 |
| 医学资讯跟踪 | 近期权威机构、学会、监管、期刊和会议正式页面 | 对应论文/指南/注册记录；少量高度相关的 arXiv、medRxiv 或 bioRxiv 预印本；证据状态和时间线 | 无来源转载、营销新闻、批量堆叠预印本、把新闻稿或预印本当作成熟研究结论 |
| 里程碑与证据脉络 | 奠基性研究和经典高被引研究 | 后续验证、指南采纳和最新进展 | 用“近 5 年”机械排除经典研究 |
| 课题或论文写作 | 与论点直接相关的综述、原始研究和方法来源 | 争议证据、研究空白和可引用段落 | 为凑引用加入不支持论点的文献 |
| 教学或学习资料 | 最新指南、高质量综述和权威教材 | 经典研究和实践资料 | 用教材旧观点替代最新证据 |

中国来源优先适用于中国临床实践、药品可及性、本土人群和国内规范相关问题；全球研究进展、基础机制或国际课题不机械要求中国证据占主导，但用户涉及中国实践时必须补充本土证据。经典里程碑研究不受年份限制；“最新进展”默认优先近 1-5 年。

## 2. 证据准入与覆盖

### 原文核实与临床适用

优先使用最新国家诊疗规范、权威指南和核心论文。关键阈值、分级及官方措辞回到原始条文核实；比较结果同时核对研究人群、入排标准、观察窗口、分母和统计口径。综合时明确哪些是证据本身、哪些是推断或建议，结论强度与证据质量匹配。涉及临床应用时核对指南框架、禁忌和用药安全；病例事实以用户资料为准。

### 核心证据准入

镜像链接可以作为引用链接，保留原始镜像 URL，无需替换为主站链接；聊天引用和正式文档超链接均可使用。

搜索工具返回的第三方存储/索引 PDF 资料可以引用和展示；PubMed、PMC、DOI 解析、期刊官网和 Semantic Scholar 均可。保留工具返回的原始 URL，不因第三方域名改换到主站；按内容真实性、研究质量与问题相关性判断来源。

已返回题录可直接使用，卷号仅在用户要求时额外核对，不为补卷号增加搜索。

核心证据必须同时满足：

1. 有工具返回的可点击原始 URL，包括原文、第三方存储/索引 PDF、PubMed/PMC、DOI 解析、Semantic Scholar、期刊页和指南等资料入口。
2. 已打开正文、指南原文、论文摘要、PDF 或其他可核验的资料入口；`seed_medical_search` 返回的指南、共识内容 URL 不能 fetch，此类资料可通过多次定向搜索取得可定位的条文与足够上下文，或读取 `general_search` 返回的对应页面或 PDF。
3. 能定位到支持结论的推荐、结果、表格、章节、摘要结果或研究数据。
4. 与用户的主题、人群、干预/暴露、对照、结局或论文论点直接相关。

仅有题名、标识符、无法支持结论的简短片段或未核实二手解读时，需要进一步取得支持结论的内容；工具返回的原始 PDF 和索引入口按其中实际内容判断，不因承载域名被归为转载。核心或辅助角色按研究质量、来源权威性、主题匹配度和时效性判断，不按全文可及性机械分组；未阅读全文时只使用实际可核验的页面或摘要内容，不推断未见的全文细节。低级别、不权威、方法学薄弱或相关性不足的资料归为辅助参考，不得单独支撑关键疗效或安全性结论。

### 默认证据覆盖量

引用数量以覆盖问题和用户指定范围为目标，不机械凑数。按问题选择所需证据类型，已有充分结果即可停止；不同资料方向可同批查询，相互独立的查询同批并行。下表数量是覆盖参考，不是分类配额，不能为凑分类或数量另开批次；只有可能改变核心结论或明确关键事实缺口才定向补查。用户未限定证据类型时，`full_report` 可按需覆盖：

| 证据类型 | 建议范围 | 主要用途 |
|---|---:|---|
| 指南/共识 | 2-6 条 | 推荐、适用人群、更新点和实践边界 |
| 系统综述/Meta | 2-6 条 | 总体方向、异质性和确定性 |
| 关键研究 | 4-12 条 | 里程碑、核心 RCT、队列、诊断或真实世界证据 |
| 最新进展 | 3-10 条 | 近年新证据、新技术、新药物或争议 |
| 安全/监管 | 1-4 条 | 禁忌、警示、特殊人群和监管变化 |
| 本土/专科证据 | 按需 | 中国规范、人群差异和实践背景 |
| 教材/实践资料 | 按需 | 学习框架、概念和实践解释 |

`quick_answer` 进行必要的高价值检索，围绕结论和相关风险引用最重要依据。搜索工具返回的第三方存储/索引 PDF 资料可以引用和展示；PubMed、PMC、DOI 解析、期刊官网和 Semantic Scholar 均可。保留工具返回的原始 URL，不因第三方域名改换到主站；按内容真实性、研究质量与问题相关性判断来源。 `aka.doubaocdn.com` 域名的内容可以引用，也可以展示。`full_report` 定向阅读支撑结论的核心资料；只有缺口可能改变核心结论或存在明确关键事实缺口时，再定向补充；证据用途由内容质量、相关性和时效性决定。

### 来源准入与用途

内部来源准入不使用 A/B/C/D 等级。核心证据与辅助参考按来源权威性、研究方法学、主题匹配度、时效性和可核验程度综合判断：

| 来源 | 使用边界 |
|---|---|
| 最新中国或国际权威指南/共识、监管机构和说明书、Cochrane/高质量系统综述、方法学可靠且高度匹配的关键研究 | 可支撑核心结论；仍需评价适用人群、偏倚风险和结论边界 |
| 质量较好的观察性、真实世界或诊断研究，卫生技术评估、权威教材/专著、临床路径和可靠专科资料 | 补充核心证据、实践背景或本土可实施性 |
| 小样本单中心研究、病例系列/报告、会议摘要、预印本、低质量叙述性综述、机制/动物/体外研究 | 用于前沿线索、机制解释或低确定性补充；不能单独支撑关键疗效或安全性结论 |
| 营销软文、无法核实的二手解读、疑似垃圾期刊或内容来源无法核验的材料 | 不作为医学依据；工具返回的原始 PDF 与学术索引按实际内容判断 |

## 3. 内部文献记录

`full_report` 使用 `assets/literature-log-template.csv` 初始化 UTF-8 BOM 文件：`literature-logs/{{YYYYMMDD}}-{{topic_slug}}-literature-log.csv`。如果需要写 CSV 文件，先 Read 再 Write；新建时先 Read 模板，已有文件每次批量写入前先 Read 当前内容，再 Write。随后按同一六列结构批量追加，新行 `journal_rank_2025` 先留空供脚本匹配；`quick_answer` 不创建 CSV。

| 字段 | 记录内容 |
|---|---|
| `citation_number` | 去重后按记录顺序递增的稳定数字编号 |
| `original_title` | 来源实际显示的原标题 |
| `journal_or_institution` | 期刊或发布机构 |
| `year` | 发表、发布或更新年份 |
| `url` | 工具实际返回的原始 URL，可为 PDF、摘要或索引入口 |
| `journal_rank_2025` | 新行先留空，由脚本写入明确命中的 2025 期刊级别 |

上述六列是内部 CSV 字段；普通调研报告的参考文献默认按“标题｜来源｜类型｜年份｜期刊分区｜链接”六列展示，用户指定国标或投稿格式时按其格式著录。

同一文献保留一行，正文、图表和参考文献复用 `citation_number`；类型、级别和结果解读直接依据实际核实的原文用于正文。含逗号、换行或双引号的字段按标准 CSV 转义。本次拟纳入文献整理后一次批量匹配，使用脚本 stdout 结果直接写入正文与参考文献表。过程文件保留，无需在结束时清理。

## 4. 初筛与原文阅读

### 初筛顺序

1. 是否直接回答当前子问题或论文论点。
2. 人群、干预/暴露、对照、结局和研究场景是否匹配。
3. 来源机构、年份、期刊和研究设计是否可靠。
4. 摘要或简介是否提供可用结果，而非只讨论背景。
5. 是否有可点击原文、摘要、官方入口、期刊页或 DOI 页面。

### 原文阅读边界

只对会进入核心结论、图表或正式参考文献的高价值证据定向精读，不重复 Fetch 同一页面，不把整页网页或整篇 PDF 塞入上下文。

- 指南/共识：推荐条文、推荐强度、证据等级、适用人群、更新日期、排除范围、推荐理由和指南差异。
- 系统综述/Meta：PICO、检索范围、纳入研究、偏倚、异质性、主要结果、敏感性分析和作者结论边界。
- RCT/队列/真实世界研究：样本量、入排标准、干预/暴露、对照、主要终点、效应量、置信区间、安全性、亚组和局限。
- 诊断研究：目标人群、指标检查、参考标准、敏感度、特异度、LR、AUC、PPV/NPV 和误判后果。
- 热点/趋势：主题簇、年份和研究类型变化、代表性研究；没有完整文献计量数据时，不声称完成正式 bibliometric 分析。
- 论文写作：逐句核对文献是否真的支持拟写论点，不为补引用扩大原文结论。

## 5. 证据评价与 Oxford CEBM 2009 分级

正式文档需要展示研究证据级别时统一使用 Oxford CEBM 2009；聊天 Quick Answer 和最终产物入口回复不展开该分级或分级说明。按临床问题类型使用 Oxford 原表；治疗/预防/病因/伤害问题可快速参照：

### 研究价值判断

Oxford CEBM 2009 描述研究设计层级，期刊级别描述发表载体；两者都不能替代对当前检索问题的具体研究价值判断。筛选和利用关键研究时，将以下六个维度作为方法层思维，不计算总分、不设置固定权重，也不要求在正文逐项列成表格：

- **问题匹配度**：研究人群、疾病阶段、干预/暴露、对照、结局、随访和场景是否直接回答用户问题。匹配不足时，即使设计层级高，也只能谨慎外推。
- **研究设计适切性**：研究设计是否适合回答治疗、诊断、预后、安全性、机制或真实世界问题，不机械认为某一种设计在所有问题上都更优。
- **信息量与精确性**：结合样本量、事件数、效应量、置信区间、失访和亚组规模判断；大样本不自动等于低偏倚，小样本也不自动等于无价值。
- **偏倚风险**：按研究类型检查随机化、分配隐藏、盲法、结局测量、缺失数据、选择性报告、混杂控制和利益冲突，重点评价实际支撑当前结论的结果。
- **endpoint 质量**：判断是否为预设主要终点、患者重要结局或可靠替代终点，随访是否充分，并区分统计学差异与医学或临床意义。
- **一致性与可重复性**：考察独立队列、多中心或外部验证、研究间方向和效应是否一致，以及异质性、敏感性分析和与既有指南/研究的关系。

“×”表示任一关键短板都可能限制研究用途，不表示数学乘法。六个维度用于判断研究对当前检索问题的贡献，不用于给研究排座次。综合时依次明确：该研究能支持当前问题中的哪项具体判断，哪些匹配的人群、设计、主要终点、效应量或一致性结果构成依据，以及哪项偏倚、精确性或外推限制阻止更强结论。单项新颖结果在缺少独立重复时应标明“有前景但尚待验证”。

样本量、随访时长、期刊级别、发表时间和“首个”等信息只作为解释精确性、罕见事件捕获、时效性或适用范围的事实，不独立构成研究价值。研究价值短评按“可支持的具体判断 + 关键依据 + 主要边界”写成自然语言，只使用非排序表述，不做最高级或名次式评价。确需说明规模、随访或覆盖范围时，在研究设计或结果段写明实际样本量、事件数、随访时长和适用范围；短评只说明这些事实如何影响判断。用户明确要求跨研究比较时，可另设有明确范围和数据依据的比较段，不在短评中完成排名。

| 证据级别 | 典型研究设计 |
|---|---|
| 1a | 同质 RCT 系统综述 |
| 1b | 单个高质量 RCT，置信区间较窄 |
| 1c | 全或无证据 |
| 2a | 同质队列研究系统综述 |
| 2b | 单个队列研究，或随访不足等低质量 RCT |
| 2c | 结局研究或生态学研究 |
| 3a | 同质病例对照研究系统综述 |
| 3b | 单个病例对照研究 |
| 4 | 病例系列，或低质量队列/病例对照研究 |
| 5 | 未经明确批判性评价的专家意见、机制/基础研究或第一原理推断 |

推荐意见仅在综合一组证据形成推荐时使用：A 为一致的 1 级研究；B 为一致的 2/3 级研究或由 1 级证据外推；C 为 4 级研究或由 2/3 级证据外推；D 为 5 级证据，或任一级别但结果严重不一致/结论不确定的证据。不得把单篇论文的 Oxford 证据级别直接写成推荐意见。

| 证据类型 | 重点评价 |
|---|---|
| 指南/共识 | 机构权威性、系统检索、证据等级、推荐强度、利益冲突、更新日期和适用范围 |
| 系统综述/Meta | PICO、检索充分性、纳入研究质量、异质性、发表偏倚、敏感性分析和稳健性 |
| RCT | 随机、分配隐藏、盲法、样本量、主要终点、ITT、安全性和失访 |
| 观察性研究 | 混杂控制、暴露/结局定义、选择偏倚、随访和因果推断边界 |
| 诊断研究 | 参考标准、代表性、盲法、诊断性能和误判后果 |
| 真实世界研究 | 数据源、缺失数据、混杂校正、外推性和可重复性 |
| 机制/基础研究 | 模型与临床人群差异，不直接外推临床疗效 |
| 教材/实践资料 | 仅用于概念和路径解释，并与最新版指南和研究互证 |

正文中指南/共识的 Oxford 证据级别写 `不适用`；正式表格对应单元格显示 `-`。原文采用 GRADE 或其他体系时，保留体系名称和原始等级，不得擅自换算；正文中研究没有足够设计或方法学信息时可据实写 `暂未分级`，正式表格对应字段显示 `-`。

### 期刊级别一次批量匹配

本次拟纳入文献整理后，默认运行 `node scripts/match-journal-rank.js --csv <literature-log.csv> --in-place`。脚本读取 `assets/journal-rank-index.json`，按期刊全称、规范化名称或常见缩写一次批量匹配，并写入 CSV 的 `journal_rank_2025`。后续新增需要匹配的期刊时，再按需执行。

脚本自行读入 CSV 再写入，已满足先 Read 再 Write 的要求，不必在调用脚本前额外 Read。 脚本 stdout 返回 JSON，其中 `results` 与 CSV 逐行对应，包含 `citation_number`、`journal_or_institution`、`url`、`journal_rank_2025`、`status`、`matchedJournal`；可直接按编号和 URL 用于正文与参考文献表，无需额外 Read CSV 获取期刊级别。

明确匹配的结果用于正文及参考文献表；未命中或匹配不唯一时，正文省略期刊级别，正式表格对应字段填 `-`。

期刊级别与 Oxford 证据级别是两个独立维度，不改变研究的证据用途。期刊论文可写为 `[DAPA-CKD]({{url}})（NEJM，2020；Oxford CEBM 2009：1b；期刊级别：中科院 1 区）`。

## 6. 引用映射与诚信

`citation_number` 是稳定的内部文献编号，普通调研报告中同一来源在正文、图表、图例和参考文献中使用同一 `[n]`。国标或稿约要求首次引用排序时，保留内部编号与展示编号映射，各处引文使用一致展示编号。类型、证据级别与结果解读直接依据实际已核实原文用于正文，台账仅保存题录与链接。

正文首次出现具体来源时，使用内部记录的 `original_title + url` 生成可点击原标题或稳定简称。正式文档中的研究标注期刊/机构、年份和 Oxford CEBM 2009 证据级别，已明确核实期刊级别时再追加该信息，例如：

`[DAPA-CKD]({{url}})（NEJM，2020，RCT；Oxford CEBM 2009：1b；期刊级别：中科院 1 区）`

不得只写编号、PMID、DOI、纯文本题名或裸 URL。采用 `[1]` 等展示序号时，序号必须与同句的可点击文献名或紧邻的可点击来源共同出现。飞书 XML 不使用 HTML 上标标签或 `<ref>` 标签；直接使用可点击文献名，citation 样式容器保留可点击来源超链接。

引用诚信要求：

- 每个引用只支撑原文实际能支撑的句子，区分背景、核心结论、安全、争议、方法和研究空白用途。
- 不根据摘要扩展未报告的数据，不把来源类型写错，不把方向不一致的研究笼统写成“研究均显示”。
- 直接引用只保留必要短片段并标注来源；不复制长段原文。
- 正文出现的每个文献名或研究简称都能通过同一行 CSV 的 `citation_number`、`original_title` 和 `url` 追溯到同一可点击来源与参考文献条目。
- 无论用户要求 Vancouver、AMA、APA 或 GB/T 7714，最终展示的每条文献仍必须有可点击来源入口；具体参考文献表结构见 `output-and-qa.md`。

## 7. 题录与正文衔接

CSV 维护文献编号、题名、期刊/机构、年份、完整原始链接和 `journal_rank_2025`。脚本 stdout 返回的逐行结果可直接用于正文和参考文献表。正文中的类型、证据级别、研究结果与局限来自实际核实的原文及工具读取结果；对照表、证据矩阵和参考文献按任务需要组织，以稳定编号与题名链接保持对应。原文、查询结果等过程文件可保留。
