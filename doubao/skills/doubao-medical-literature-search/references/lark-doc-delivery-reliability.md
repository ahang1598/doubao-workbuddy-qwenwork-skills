# 平台飞书文档交付

## 产物路由

- 飞书在线文档：平台 `lark-doc` 的 `online-doc`。
- Word/docx：平台 `word` Skill。
- PPT/幻灯片：平台 `ppt` Skill。
- Mermaid 或复杂画板：按 `lark-doc` 当前流程插入，已有复杂画板按其路由处理。

## 创建与交付

正式表格单元格的缺失、未核验、未匹配、空值及不适用证据等级统一显示 `-`；单元格中实际医学分析和风险说明保留。

读取 `assets/feishu-doc-template.xml`，按用户问题组织总结、直接回答、证据与参考文献。飞书 XML 使用 `<title>` 开头；表格按平台示例按需使用 `<colgroup>` 定义列宽，以 `<thead><tr><th>` 放表头，以 `<tbody><tr><td>` 放数据。来源使用可点击超链接，含来源超链接的 citation 样式容器可继续使用。

调用当前平台 `lark-doc` 创建或更新，参数按其实际合同。完整内容可一次创建；遇到长度限制时再按实际内容分块。XML 已包含标题时使用单一标题来源；`--content @file` 使用工作目录下的相对文件路径。

`full_report` 默认交付聊天回答和飞书文档链接。XML、CSV 和原始草稿仅作内部过程文件保留，`present_files` 不选择这些文件；用户明确要求 PPT、Word 等最终格式时继续按相应路由交付最终产物。 `present_files` 参数按当前环境工具合同。过程文件保留，无需结束清理。创建遇到实际问题时说明原因，聊天中给出已核实的回答与关键依据，草稿内部保留。
